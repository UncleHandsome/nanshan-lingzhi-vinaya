# 校閱材料　第1271檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1271-0001】資持記/13b_下一#3
【原文】準《戒疏》四句簡之，一明去暗還〔日未沒去，夜分還界，諸律不犯。〕，二暗去明還〔《僧祇》不犯，通夜會故；《四分、十誦》成犯，隔明相故。〕，三明去明還〔日未沒去，隔明方還，諸部同犯。《僧祇》唯此一句犯。〕，四暗去暗還〔諸部非犯〕。次明今用。注示取意，見上次句。分品中。
【譯文】依照《戒疏》提出的四句來簡別：第一句是「白天離去、天黑返回」（太陽未落山即離開，夜分之內就返回界內，各大部律都判定不犯戒）；第二句是「天黑離去、破曉返回」（《僧祇律》判定不犯戒，因為貫通夜分相會之故；《四分律》、《十誦律》則判定犯戒，因為跨越了明相之故）；第三句是「白天離去、破曉返回」（太陽未落山就離開，跨越明相之後才返回，各部律一致判定犯戒，《僧祇律》唯獨在這一句判定犯戒）；第四句是「天黑離去、天黑返回」（各部律都判定不犯戒）。接著說明現今的行持方法。夾註中點明所取的用意，參見前文的第二句。在品別分類中：

【1271-0002】資持記/13b_下一#4
【原文】初明大衣。正即本位之衣，從謂缺於本衣，用別衣當數。正十八品者，割截揲葉，各有九故。從有六者，七條二品〔割揲〕，五條三品〔割揲襵〕，縵衣一品。正從合論，則二十四品；三衣互為正從，各二十四品，總七十二矣。縵通三者，隨用分故；合為一者，據體同故。《義鈔》缺文，《業疏》具顯。
【譯文】首先說明大衣。「正」是指本位應有的衣，「從」是指缺乏本衣時，用別的衣物頂替其數。「正」有十八品，是因為無論割截縫製還是重疊條葉，各有九品的緣故。「從」有六品，包括七條衣的二品（割截、疊葉）、五條衣的三品（割截、疊葉、褶疊），以及縵衣的一品。正從合併論述，就是二十四品；三衣彼此互為正從，各有二十四品，總共就是七十二品。縵衣能通於三衣，是隨順用途來區分的；將它合為一品，則是據其本體同一的緣故。《義鈔》中缺少這段文字，而在《業疏》中則有詳盡的說明。

【1271-0003】資持記/13b_下一#5
【原文】加下衣中，初句示先後。前下，合有加字。《業疏》云：前令持鉢，後乃持衣，儀相非便。〔此斥古也。〕意以先問內衣，如名加受，便著之也；次受欝多羅，隨上披體；後受伽梨，乍可揲襆。鉢為第二，衣服既被，方可手執。坐具第三，最後加持，疊置肩上。〔此約三衣鉢具一時加者，不從著法，以明次第；或不同時，隨緣不定。〕此下，示品數。
【譯文】在加持下衣的章節中，第一句指出了前後次第。在「前」字下方，應當補入一個「加」字。《業疏》說：先令加持缽具，後面才加持衣服，這種威儀相貌並不合宜（這是斥責古人的作法）。其用意是認為應當先加持內衣，依其名稱受持之後，就立即穿上它；接著受持中價衣（鬱多羅僧），隨即披在身上；最後受持大衣（僧伽梨），暫且可以疊好包裹。缽作為第二順位，衣服既然已經披好，才可以動手拿著。坐具排在第三順位，放在最後加持，疊好放置在肩膀上（這是針對三衣、缽與坐具同時加持的情況，不依著穿著的順序，而是辨明其儀軌的次第；如果不是同時加持，就隨順因緣而不一定了）。從「此」字以下，指明了品類的數量。

【1271-0004】資持記/13b_下一#6
【原文】加正衣中，初正加割截。亦下，例通餘二。前段注中，教揲葉法；上邊須刺，下邊須開，令同割截；餘同者，即指上餘詞出《十誦》故。後注中，遮非。揲葉尚令倣同割截；今時割截，例皆縫合。時開寸許，古記相傳，謂之明孔；或云明相，又號漏塵；舉世傳訛，于今未省。
【譯文】在加持正衣的章節中，開頭先正式加持割截衣。「亦」字以下，比照通達其餘二衣。前一段的夾註中，傳授了疊葉的作法：上邊必須縫刺固定，下邊則必須敞開，讓它如同割截縫製一樣；「餘同」這句話，就是指其餘的文詞出自《十誦律》的緣故。後面的夾註中，遮止了錯誤的做法。疊葉尚且要求仿照割截的形式；現今割截的衣，往往全都縫合死。有時敞開一寸左右，古記相傳稱之為「明孔」，或者稱作「明相」，又叫做「漏塵」；舉世輾轉訛傳，至今仍然不知省悟。

【1271-0005】資持記/13b_下一#7
【原文】今按《章服儀》云：裁縫見葉，表其截相；今並縫合，無相可分。〔如此明文，人猶執諍，愚之甚矣。〕是知今時不開葉相，即同下眾服縵衣耳。從衣中。牒下衣名者，以名是通，隨用分故。牒上衣條數者，由體是定，如實稱故。〔有云五條衣受者，非。
【譯文】如今查閱《章服儀》所說：剪裁縫製時能見到葉相，是為了表彰其割截的法相；現今全都縫合在一起，就沒有外相可以分別了（有這樣明白的文據，世人還固執爭論，實在是愚癡到了極點）。由此可知，如今若不敞開葉相，就如同下眾所穿著的縵衣一般了。在「從衣」章節中，提及下衣的名稱，是因為名稱屬於通稱，隨順用途而有所區分；提及上衣的條數，是因為實體是固定的，必須如實稱呼之故（有人說是五條衣受，這是錯誤的）。

【1271-0006】資持記/13b_下一#8
【原文】注云乃至七條，應云此安陀會七條衣受，兩長一短截割衣持。縵衣注中，初點前從法。縵下，正標縵法。上衣注中，初句例通揲葉。以下，點詞中若干。結歎中，初文，上句結前。律下，示數。彼律即《十誦》。恐疑未割以為衣財，故注決之。次科，前引論文。
【譯文】夾註說「乃至七條」，應當表述為：「此安陀會七條衣受，兩長一短截割衣持。」在縵衣的夾註中，開頭先指出前面從衣的作法；從「縵」字以下，正式標明縵衣的作法。在加持上衣的夾註中，第一句比照通達疊葉之法；從「以」字以下，點明受持詞中稱「若干」的緣由。在總結讚歎的章節中，第一段文字，上一句總結前文；從「律」字以下，指出數量。那部律就是指《十誦律》。唯恐有人懷疑布料未曾剪割就直接當作衣材，所以用夾註加以判定。下一個科判，前面先引述論典的文字。

【1271-0007】資持記/13b_下一#9
【原文】則下，斥非法，前斥白色。如下，次斥四色。人所喜著，故云多有。白色非孝僧不用，故云無多白者。〔近時禪者黲色漸淡，則白者又多矣。〕正言即指上論。今下，傷歎。苦受猶言堅執也。一生無衣，乖法制故。死負聖責，違教結犯故。何慮無惡道分，定墮苦趣故。
【譯文】從「則」字以下，斥責非法的行為，前面先斥責純白色。從「如」字以下，接著斥責四種正色（黑、青、赤、黃）。因為是人們喜好穿著的，所以說「多有」。白色若不是守孝僧人一般不會穿用，所以說「沒有太多純白的」（近來修禪的人所用的雜色漸漸變淡，那麼純白的又多起來了）。「正言」就是指前面的論典。從「今」字以下，表達哀傷歎息。「苦受」是形容頑固堅執的意思。「一生無衣」，是因為違背了佛法正制；「死負聖責」，是因為違犯了教法、結成了罪愆；「何慮無惡道分」，是必然要墮入痛苦惡趣之意。

【1271-0008】資持記/13b_下一#10
【原文】上二句是現業，次一句即來報，下二字歎詞。今時有以布衣為喪服者，且布衣是如來正制，三乘道標，豈意一朝反成凶服；加以素帶長垂，或復麁麻表異〔《五杉集》、《釋氏要覽》、《輔教編》並謂僧無服制，但布麁為異〕；或緇巾纏項，或白布兜頭；鄙俗之風，盛傳于世；
【譯文】上面兩句是指現世造作的業因，下一句是指來世應受的果報，最後兩個字是歎息之詞。如今世上有人把布衣當作喪服，然而布衣本是如來的正制、三乘聖道的表徵，豈能料想有朝一日反而變成了凶喪之服！再加上垂著長長的白帶，或者用粗麻布來標榜奇異（《五杉集》、《釋氏要覽》、《輔教編》都認為僧人沒有固定的喪服制度，只是以布料粗糲作為區別）；或者用黑巾纏繞頸項，或者用白布包裹頭部；這種粗鄙低俗的風氣，在世間廣為流傳；
