以下按「義理／邏輯錯誤（必改）→ 詞義偏移與增譯（宜改）→ 行文與術語統一（可改）」分層列出，並附建議譯法，方便你直接對號修改。整體說來譯筆流暢、可讀性好，主要毛病是 **「濫／通」的判教邏輯被譯糊了**，以及**成語、科判動詞的誤讀**與**過度增譯**。

---

## 一、義理／邏輯錯誤（必改）

### 1. 【0005】「聯類已窮」譯錯（最嚴重）
- 譯文：「其**邏輯推演的漏洞**已經被窮究完畢」
- 問題：「聯類」不是「邏輯推演」。依【0006】記文自釋：「彼乃**去短取長**，以立斯判，故云『聯類』等」——「聯類」指第三師**牽聯、比類前二家（化行、制聽）之說**而拼合成立。「已窮」是說前二家已被展轉破斥窮盡，故不必再破。
- 建議：「這只是因循前人舊說，**牽聯比類（將前二家去短取長拼合而成）**，其義已被破斥窮盡，不值得再加徵責考覈。」

### 2. 【0006】「去短取長」誤作「截長補短」
- 「截長補短」是「拿長的補短的、湊平均」，與「**去除缺失、選取長處**」意思不同，且正好把「去短」誤讀成「截長」。
- 建議：「他只是**去除前二家之短、取其長處**來安立這個教判。」

### 3. 【0003】【0004】「即遮通制／遮戒通制」講反了
- 譯文：「遮戒之中同樣**通於制罪**」／「遮戒同樣**包含佛制之罪**」
- 問題：遮罪本身就是佛所制之罪，說「遮戒包含制罪」是循環且不通。原文論證是：**「遮戒」也通於「制」這個名義**，所以「制教」之名不能只收性戒（記文結語「故知制名，不獨收性」正是此意）。
- 建議：疏文「再者，**即使是遮戒也通於『制』名**，例如在家戒中的遮戒戒相」；記文「次難**遮戒亦通於『制』名**，故不應把制教局限於性戒」。

### 4. 【0003】「還漏昔非」誤作「偏狹錯誤」
- 依記文：「此師斥前行教**通濫**，自立制教，**還復濫俗**」——「昔非」指的是**前家「名義混濫（過寬）」之非**，不是「偏狹」。譯成「偏狹」把過失方向弄反了。
- 建議：「自己卻又墮入前人**混濫**的過失之中。」

### 5. 【0004】「還復濫俗」譯為「混濫了世俗」
- 「濫俗」＝**濫及在家眾（的戒法）**，不是「混淆世俗／世間」。
- 建議：「結果**又濫及在家戒**」。

### 6. 【0001】「豈偏戒律，局推行攝」
- 「偏」是**偏局、單偏**，不是「偏私」（無偏袒義）；且譯文把一句拆成「劃歸戒律」＋「推由行教收攝」兩件事，語意重複。
- 建議：「哪裡可以**偏將戒律局限地推為『行教』所攝**呢？」
- 另「此則有濫」宜點明方向：「『行』的名義便**與化教混濫**（經論化教亦明觀行，非律宗獨有）」，否則讀者不知「濫」從何來。

### 7. 【0010】「座上無數百千人」
- 譯文「**法座之上**無數百千人」——法座是佛座，不會坐上千百人。「座上」指**法會座中（聽眾）**。
- 建議：「**法會座中**有無數百千人遠離塵垢、得法眼淨。」

### 8. 【0009】「因見聖迹」
- 記文自釋「**獲果證也**」，故是「**證得聖果**」，不是「親見聖道」（能見≠證獲）。
- 建議：「眾生因此**證得聖果**」。

### 9. 【0004】「則制通經論」的語氣
- 譯文「制戒**應當**通於經論二藏」——這是**推導出的過失結論**（制名就變成通於化教了），不是規範性的「應當」。
- 建議：「如此則『**制教之名**』**便通於經論（化教）了**」。

## 二、詞義偏移與增譯（宜改）

| 出處 | 譯文 | 問題／建議 |
|---|---|---|
| 0001,0002,0003 | 徵＝「審核／審視」 | 「徵」在此是**徵責、詰難**（記文「別斥」「難」「躡破」可證），「審核」太中性。建議統一作「**責破／徵責**」 |
| 0005 | 「三**舉**化、制」→「第三**審視**」 | 「舉」是**舉出、列出**第三家，與前面「徵」不同層次，宜照原文作「第三舉出『化制二教』」 |
| 0002 | 「故無所取」→「不足採信」 | 是**疏主不取用此判**（判攝不当），非真偽「採信」問題。建議「故（疏主）於此判**無所取用**」 |
| 0003 | 「退一步就制教來審核」 | 「就」是**再就…而言**的推進，非讓步；「退一步」誤加讓步語氣 |
| 0003 | 「經論盛張」→「極具規模的闡述」 | 「盛張」＝**廣為張設、盛說**，建議「經論中**廣為開演**」 |
| 0003 | 「如俗戒相」→「在俗戒律的**行相**」 | 「戒相」是**戒條條目之相**，非「行相」；建議「如**在家戒中的（遮戒）戒相**」 |
| 0003 | 「彈劾」 | 現代司法語感太重，宜作「**彈斥／指責**」 |
| 0008 | 「但**後**『憶念』」→「**後來**對於憶念輪」 | 「後」指三輪中的**後一輪**，非時間的「後來」。建議「只是**後一『憶念輪』**立義未圓」 |
| 0009 | 「其義不無」→「**律藏之中**並非沒有這些內涵」 | 原句只說「（前二輪）並非沒有令人得道之義」，「律藏」是下句才出現的，宜後移 |
| 0010 | 「本律」→「《四分律》**本體**」 | 「本律」即**本部律（四分律）**，無「本體」義 |
| 0011 | 「不待加勸」→「無須再額外施加**勤苦**的勸勉」 | 「勤苦」為無據增譯，刪 |
| 0011 | 「託境流言」→「依託於**事理**之境」 | 「境」是**具體事境／境緣**（如犯緣、事相），「事理」是下句「念通事理」才有的，宜刪 |
| 0011 | 「念通事理」→「憶念**通達**於事相與理體」 | 「通」是**兼通、通貫**，非「通達（精通）」 |
| 0011 | 「同遣縛緣」→「繫縛身心的**罪緣**」 | 「縛緣」＝**繫縛之因緣（煩惱縛著）**，加「罪」字窄化 |
| 0011 | 「無非為道」→「成就**無上**道業」 | 「道」通三乘聖道，加「無上」偏向佛乘，宜作「成就道業／證道」 |
| 0011 | 「情則浮疎」→「浮躁粗疏」 | 「浮疎」＝**浮泛疏略（疏於檢束）**，非「浮躁」 |

另【0011】一句**語法斷裂**：「單憑泛泛宣說法義尚無法明了之人，所以必須在心中時常憶念修持」——前半是名詞短語，後半接「所以」不成句。建議：「**對於泛泛說法仍不能明白的人，就須要憶念記持**」。
又「故懷記憶」主語可兩讀（眾生憶持／如來憶念機宜而別示），譯文偏取前者可以，但建議保持中性：「**所以須要憶念記持**」，並可加註說明另一讀法。

## 三、需要加註或覆核之處

1. **【0010】「佛於臘月十五日，從初一日至十五日」**
 譯文照抄後變成自我矛盾（「在十五日那天，從初一到十五」）。此處應指**臘月（十二月）的神變期間**，「十五日」疑為節期標目或衍文。建議：**回查《四分律》卷五十一原文**，並加譯註，如「〔按：此指十二月一日至十五日佛現神變之期，記文『十五日』疑為標舉節期〕」，不要讓白話出現明顯時序矛盾。

2. **【0004】「八戒後四」宜出註**
 已正確注出「五戒後一＝不飲酒」，建議一併注八戒後四＝**不飲酒、不著香華鬘不香塗身（不歌舞觀聽）、不坐高廣大床、不非時食**（即除殺盜淫妄四性戒外的四支，皆遮戒；華鬘與歌舞或合為一支，故計數略異）。如此「遮戒亦通制名」的論證才看得懂。

3. **【0010】「用此兩通，攻前二局」宜譯實**
 現譯「這兩種皆具共通性的論點…兩方面的偏局」太含糊。建議明說：**「兩通」＝二輪通於律藏、二輪通於證道；「二局」＝三輪師執二輪唯在經論、唯是開化不能得道**（若你對「二局」所指另有判定，至少在註中交代所指，不要留白）。

## 四、術語統一建議

- **濫／通濫**：一律譯「**（名義）混濫、濫涉、濫及**」，並在首次出現處點明「名不稱實、跨涉他教」，勿只寫「混淆泛濫」。
- **通**：「化通道俗」＝通於道俗；「念通事理」＝兼通事理；「制通經論」＝通及經論。避免時而「通行」、時而「通達」。
- **漏**：記文自訓「猶墮也」，譯「墮入」正確，前後保持一致（0003 用「墮入」，0004 亦用「墮／落入」）。
- **性罪／遮罪**：0003 用「自性之罪」，0004 用「性戒」，建議統一為「性罪（性戒）／遮罪（遮戒）」並首次加短註。
- **科判語**：「初科／次科／結斥／躡破」建議固定句式，如「第○段…中，此為第一科」，0008 現譯「在第三、確立正當合理的義旨，顯明所選取的立場中，此為第一科」略拗口，可作「**第三科『立正義』中，『明所取』的第一小科**」。

## 五、示範改譯（最需重寫的兩則）

**【0005】**
「第三舉出『化制二教』。這只是因循前人舊說，牽聯比類（把前二家去短取長拼合而立），其義已被破斥窮盡，不值得再加以徵責考覈了。」

**【0003】後半**
「……再就制教責問：若說制教唯約性罪而立，然性罪通於道俗，並不偏局出家，如五戒、八戒，經論中廣為開演。再者，即使遮戒也通於『制』名，如在家戒中的遮戒戒相。如此，此師雖彈斥前家的過失，自己卻又墮入前人混濫之非，怎能將教門分判得如此混濫呢？」

---

**小結**：必改的是 0005「聯類」、0006「去短取長」、0003/0004「遮通制」與「昔非＝偏狹」、0010「座上」，以及 0001「偏私」；其餘多為增譯與術語精度問題。修好這幾處，整段的「破立邏輯」（名義是否通貫道俗、是否濫涉他教）就能清楚呈現。
