# 校閱材料　第428檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【428-0001】02_戒疏/05a_卷二上之一#53
【原文】【疏】問：「口業不得獨成殺盜。云何呪物過關、殺人，既得成重，曾未身助？」
【譯文】【疏文】問：「若口業不能單獨成辦殺生與偷盜，為何以咒術將物品運過關卡、以咒術殺人，既然能構成重罪，卻未曾見其動用自身的色身去相助呢？」

【428-0002】02_戒疏/05a_卷二上之一#54
【原文】【疏】答：「如論所陳，凡有呪法，皆使鬼神扶物過關，及以斷命。假彼身助，方成業也。」
【譯文】【疏文】答：「如同各部論典所說，凡是使用咒法，皆是驅使鬼神用神力扶助物品通過關稅，以及用鬼神力斷絕彼人性命。都是藉助了彼鬼神的身業相助，才成辦這項罪業的。」

【428-0003】02_戒疏/05a_卷二上之一#55
【原文】【記】初難中。初牒前，「云」下，立難。「呪物過關」，即盜王稅；「呪物殺人」，謂符祝厭禱。《律》皆結重。此並口作，俱不假身，故引為難。答中。「如論」，即指《多》、《雜》。既憑鬼神，還同身助。
【譯文】【記文】第一道難問中。先提認前文，「云何」以下正式發難。「咒物過關」，即偷漏國王關稅；「咒物殺人」，是指符祝厭勝詛咒，律中皆結重罪。這些全憑口說咒語，皆不藉助自身之力，所以舉此為難。答覆中說「如論」，即指《薩婆多論》、《雜阿毗曇心論》。既然憑藉了鬼神的身力，仍然等同於有身業相助。

【428-0004】02_戒疏/05a_卷二上之一#56
【原文】【疏】「若爾，須身方成業者，如師子吼殺獸，壯夫咄殺人，豈有鬼神身業相助？」
【譯文】【疏文】「如果真是那樣，必須依賴身業方能成辦罪業者，那麼像獅子一吼震殺百獸，勇壯之夫大喝一聲嚇死人，難道也有鬼神的身業在旁相助嗎？」

【428-0005】02_戒疏/05a_卷二上之一#57
【原文】【疏】解云：「亦由人畜身壯聲大，不乖前義。」
【譯文】【疏文】解答說：「這也是由於人與野獸自身形體壯大、發聲雄猛之故，並不違背先前身業助成的道理。」

【428-0006】02_戒疏/05a_卷二上之一#58
【原文】【記】次難中。「師子」，《爾雅》謂之「狻猊」，食虎豹，或一吼則令獸死。引畜類人，明無他助。解中。「身壯聲大」，雖即自身，義同他助。
【譯文】【記文】第二道難問中。「獅子」，《爾雅》稱為「狻猊」，專吃虎豹，往往一吼就能讓小獸斃命。引野獸來比照人類，說明並無其他形體相助。解題中說「身壯聲大」，這雖是自身之色力，但在義理上同於借身助口。

【428-0007】02_戒疏/05a_卷二上之一#59
【原文】【疏】「若爾，深河誑淺，口造身業，彼依而死，何必身壯？無學著衣，身造口業，彼依其言，何有口助？」
【譯文】【疏文】「如果真是這樣，在深水河邊騙人說水淺，口業造作身業之殺，對方依言渡河溺死，何須自身形體勇壯？又如未證聖果之人為了獲取供養而穿著三衣，以身業造作口業之妄，受騙的施主只是依著自己所立之言而信以為真，比丘自身何曾有口業相助？」

【428-0008】02_戒疏/05a_卷二上之一#60
【原文】【疏】「今釋此義，亦由問答。身業渡河，死方成業。口業亦爾，亦須他助，無獨成義。」
【譯文】【疏文】「如今解釋這個義理，也是要依問答兩端而論。對方藉由身業渡河，直到落水死亡才成殺業；身造口業也是如此，亦須仰賴他人（施主言語）的口業助成，絕無單獨一種業就能成辦之理。」

【428-0009】02_戒疏/05a_卷二上之一#61
【原文】【記】後難中。初約口成殺業，而無身助。「無學」下，約身造妄業，而無口助。或人施物問言「是聖人者，須著三衣」，貪施即著，則犯重罪。釋中。並約所殺所誑，以明身口兩助。此應古解，於義未顯，疏家助成，故標「今釋」。
【譯文】【記文】後一道難問中。先就口業成辦殺業而無身業相助來發難；「無學」以下，再約身業造作大妄語而無口業言語相助來發難。若有人拿供養物問道「若是聖人，應當穿著三衣受供」，凡僧貪戀供養便穿衣現相，即犯大妄語重罪。解答之中，皆是以被殺者、被欺騙者的身口二相，來明晰身、口互助之義。這應當是古人的解釋，因法義尚未透徹，大師特予補足成全，所以標上「今釋」。

【428-0010】02_戒疏/05a_卷二上之一#62
【原文】【疏】若依《多》、《雜》等論，三業不互。所以者何？業性異故。事不究竟。言雖了了，未得成業，要由身助。又云：「如自在者語，仙人意嫌，必須人鬼，相助成業。」
【譯文】【疏文】如果依循《薩婆多論》、《雜心論》等有部論典，身、口、意三業是不能互相造作的。為什麼呢？因為業的體性截然不同。事情尚未究竟時，話語雖然說得清清楚楚，卻不能單獨構成重罪，必定要由身業助成。論中又說：「如同具有大威勢者發號施令，仙人內心嫌惡詛咒，都必須透過凡人或鬼神的身力相助，罪業方得究竟成辦。」

【428-0011】02_戒疏/05a_卷二上之一#63
【原文】【記】次明互造。初文為三。初示宗。「《多》、《雜》等論」，皆有部所計。「所」下，出不互所以，則有二意。初約業異釋。若約能造色，身是可見有對，口即不可見有對；若據所造過，身造婬、盜、殺，口作誑、妄；若約所發，業性不混；若取來報，感果不同。「事」下，次約事不竟釋。初句立義；「言」下，釋成。「又」下，引類。「自在者語」，如王大臣遣使殺戮，此證口互。「仙人意嫌」，如下所引，此明意互。身造口業，例亦如是。「是聖者起」，必假他語，即是口助。
【譯文】【記文】接下來說明三業互造。第一段分為三層。先明宗派立場。「多、雜等論」，都是有部宗義的主張。「所」字以下，說明不能互造的原因，共有兩層意思：先就業性相異來解釋。若就所發能造的色法而言，身業是可見有對色，口業是不可見有對色；若依所造的過咎而言，身業造淫、盜、殺，口業作欺誑妄語；若就業力發起而言，業性不可混淆；若論未來招報，所感果報亦大不相同。「事」字以下，其次約事情尚未究竟來解釋。首句立義，「言」字以下釋成其義。「又」字以下，引同類之例。「自在者語」，如國王大臣差遣使者去行刑殺戮，這證明了口業造身殺；「仙人意嫌」，如下文所引，這說明了意業互造。以身造口業，也是依此類推；如施主言「若是聖人應當起立」而凡夫起立，必定藉助他人所說之話，這即是口業相助。

【428-0012】02_戒疏/05a_卷二上之一#64
【原文】【疏】若依本律，《成論》所通，三業互造，各自成業。故彼文云：「殺不善業，身亦可造，隨以自身，殺害眾生；口亦可造，或教人死，或以呪殺；心亦可造，有人發心，能令他死。」故彼論云：「如《和利經》說，外道神仙，起一瞋心，殺那羅國。如檀特等諸險難處，皆諸仙人瞋心所作。」
【譯文】【疏文】如果依循《四分律》本律及《成實論》所通達的義理，身、口、意三業是可以互相通造的，並且各自皆能自成罪業。所以《成實論》文中說：「殺生的不善業，身業可以造作，即隨意以自身殺害眾生；口業也可以造作，或者教唆他人去死，或者用咒術殺人；心意同樣可以造作，有人一動惡念發心，就能令對方死亡。」所以該論又說：「如同《和利經》中所說，外道仙人只動了一個瞋恚之心，就誅殺了那羅國整國之人。像檀特山等種種險難之境，全都是古代諸仙人以瞋恨心所化作造成的。」

【428-0013】02_戒疏/05a_卷二上之一#65
【原文】【記】今宗中，初科為三。初示宗。「各自成」者，隨約能造，結業成罪，不同《多》、《雜》從所作事判定身口。「故彼」下，引示。且明殺業，餘可準知。初通明三業。身口意三，如文次列，而身是正，口意為互。云「教死」者，《論》云「教勅」，即是遣使，文無歎死，義亦同之。「故」下，別示心造。《論》文二節，初引經證。「那羅國」者，具云那羅千陀羅國。「如」下，次舉事證。言「檀特」者，即西土山名。《經音義》云，或言單多羅迦山，此云蔭山。此明仙人心業強猛，證上起心即能害故。
【譯文】【記文】在今宗大乘分通教的闡發中，第一節分為三層。首先指出宗意立場。「各自成業」，是隨從能造的當下業行即結罪論過，不同於《多論》、《雜心論》非要依所作的事相去硬定身業或口業不可。「故彼」以下，引論證明。此處暫且指陳殺業，其餘盜、妄等戒可以比照而知。起初普遍明示三業。身、口、意三者依文陳列，而身業是正位，口與意是互造。「教人去死」，論中稱為「教敕」，即是差遣使者，文中雖無「讚歎致死」，法理上亦等同。「故」字以下，特別說明心意造業。論文分為兩截，先引經為證。「那羅國」，全名為那羅千陀羅國。「如」字以下，舉具體事蹟為證。「檀特」，是西天竺的山名；《經音義》說，或稱單多羅迦山，此處譯為「蔭山」。這是用來顯明仙人的心業強烈威猛，印證上面動念即能殺害生命之說。
