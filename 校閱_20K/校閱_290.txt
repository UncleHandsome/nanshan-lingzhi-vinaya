# 校閱材料　第290檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【290-0002】02_戒疏/10d_卷三上之一#157
【原文】【律】彼比丘應三諫，捨是事故。乃至三諫，捨者，善；不捨者，僧伽婆尸沙。
【譯文】【律文】那些比丘應當三次規勸他，為了讓他捨棄這件事的緣故。乃至經過三次規勸，如果肯捨棄的，那就很好；如果仍然不肯捨棄的，犯僧伽婆尸沙（僧殘）罪。

【原文】【疏】「彼比丘應三諫」下，正僧諫也。「不捨」者，拒僧諫也。
【譯文】【疏文】「彼比丘應三諫」以下，是僧團正式作法公眾規勸的相狀。「不捨者」，是說明抗拒僧團公眾規勸的相狀。

【290-0004】02_戒疏/10d_卷三上之一#159
【原文】【疏】本翻律人，簡語不淨，致令彼此通濫，能所不知。若不義求，難辨邪正也。
【譯文】【疏文】最初翻譯律典的人，在文字的推敲簡別上不夠精純乾淨，以致造成「彼」、「是」這兩個代名詞彼此混淆含混，讓人難以分清誰是能勸者、誰是被勸者。如果不深入探求義理，就極難辨析哪一方代表邪妄、哪一方代表正直。

【290-0005】02_戒疏/10d_卷三上之一#160
【原文】【記】點示中。以「彼」、「是」二字，能所不分。前所諫事中，「彼比丘」即所諫，「是比丘」為能諫。及拒屏中，「是比丘」乃是所諫。僧諫中，「彼比丘」又是能諫。此謂「通濫」也。準《刪定戒》，並以能諫為「彼」，所諫為「是」，則邪正可分也。
【譯文】【記文】提示說明當中。因為「彼」、「是」這兩個字，把主動能勸者與被動受勸者混淆不分。在前面被規勸的事由中，「彼比丘」是指被規勸的提婆達多同夥，「是比丘」是指能勸的正法僧眾。而到了抗拒私下規勸這一段，「是比丘」卻又成了被規勸者。到了僧團公眾規勸這一段，「彼比丘」又反過來成了能勸的正法僧眾。這就是疏文所說的「通濫混淆」。依照唐代道宣律師《刪定戒本》的規範，凡是主動能規勸的人一概統譯為「彼」，凡是被規勸的人一概統譯為「是」，這樣邪與正的界限就能清楚分明了。

【原文】【疏】四、解謗僧意。由僧治擯，迹涉愛憎，似有不平，致彼言謗。
【譯文】【疏文】第四、解釋毀謗僧團的用意。由於僧團對其執行驅逐處分，行跡上容易讓人聯想到偏愛或憎惡，看似處事不公，因而招致該犯僧出言毀謗。

【290-0014】02_戒疏/11a_卷三上之二#9
【原文】【疏】五、解須諫意。由前擯時，六人同犯。二人逃走，身不現前，不得治擯，相似有怖；二人逆路，改過伏從，無罪可治，相似有愛；二人現在，非走非懺，僧作法擯，相似有恚。今反前意，非僧有怖、有愛、有恚。依法舉治，何癡之有？若不諫喻，無由自曉，是故諫彼，表內無瑕。
【譯文】【疏文】第五、解釋必須進行勸諫的用意。由於先前執行驅逐時，共有六人一同犯過。其中兩人逃跑，人未在現場，僧團無法當面作法驅逐，看似僧團有所畏懼；有兩人半路迎來，認錯服從，已無罪可罰，看似僧團對其有所偏愛；另兩人留在現場，既不逃跑也不懺悔，僧團便依法作羯磨將其驅逐，看似僧團心懷忿恨。現在要扭轉先前的誤解，僧團絕非心存恐懼、偏愛或忿恨，而是完全依法揭發並懲治，哪有愚癡之舉？如果不用道理勸導曉喻，他就無從自行明白，因此對其勸諫，正是為了表明僧團內部清白無瑕。

【譯文】【疏文】第六、結定罪名的用意。僧團秉持慈悲心，依照正理對他勸導諫誡。在是非曲直已經講明之後，他若是頑固執著而不肯罷休，違背僧團如法勸諫達到三次圓滿，在義理上就應判定為犯僧伽婆尸沙罪。

【290-0016】02_戒疏/11a_卷三上之二#11
【原文】【記】十二，制意，有六。初中，「二利」，初即自利，二即利他。二中，翻上二利，即成兩損。三中。初總示。「內外」，即道俗。「若」下，別釋。初釋損道，「又」下，次釋損俗。四中，「迹涉愛憎」，緣見次意。五中。初敘𢷤謗。「二人逃走」，即三聞達及摩醯沙，走入王宮迴避。「二人改過」，即迦留陀夷及闡陀。「逆」，迎也。「二人現在」，即阿濕卑與富那婆蹉。「今」下，正彰須諫。六中，「自理」者，明非憎愛。「諫彼」者，令止謗僧也。
【譯文】【記文】第十二條，制戒用意，共有六點。在第一點中，所謂「兩種利益」，第一項即是利益自身，第二項即是利益他人。在第二點中，反轉了上述兩種利益，就變成了兩相損害。在第三點中，首先是總體開示。「內外」指的就是佛門與俗世。「若」字以下，是分別解釋。先解釋損害道法，「又」字以下，接著解釋損害俗世。在第四點中，「行跡牽涉愛憎」，其原因可見於下一點用意。在第五點中，首先敘述驅逐與毀謗的緣起。「兩人逃走」，指的就是三聞達與摩醯沙，兩人逃入王宮躲避。「兩人改過」，指的就是迦留陀夷與闡陀。「逆」，即是迎向僧團之意。「兩人現在」，指的就是阿濕卑與富那婆蹉。「今」字以下，正式彰顯必須勸諫的理由。在第六點中，所謂「依照正理」，是表明並無憎惡或偏愛；所謂「勸諫彼人」，是為了令他停止毀謗僧團。

【290-0017】02_戒疏/11a_卷三上之二#12
【原文】【疏】第二，釋名。坌汙淨士，名曰「汙家」；過與理違，名為「惡行」；舉過顯眾，名之為「𢷤」；無罪橫加，名「謗」；以理喻彼，名「諫」。此是所防，「戒」是能治。如上可知。
【譯文】【疏文】第二項，解釋名稱。汙損良善的清淨人士，稱為「汙家」；行為過失違背正理，稱為「惡行」；舉發過失並向大眾昭示，稱為「擯」（驅逐）；對方無罪卻橫加誣指，稱為「謗」；用正理開導曉喻對方，稱為「諫」。這些是戒律所要防範的過失，「戒法」則是能夠治罰對治的法規。其餘如同上述即可明白。

【290-0018】02_戒疏/11a_卷三上之二#13
【原文】【記】釋名中。「淨士」，謂有信俗人。「無罪」，謂僧非愛恚。「汙」、「惡」「謗」三屬犯人，「擯諫」在僧。
【譯文】【記文】解釋名稱中。所謂「淨士」，是指具有信心的在家俗人。所謂「無罪」，是指僧團並無偏愛或忿恨之情。「汙」、「惡」、「謗」這三者屬於犯戒之人，「驅逐與勸諫」則是由僧團來執行。

【290-0019】02_戒疏/11a_卷三上之二#14
【原文】【疏】第三，具緣有六：一、作汙家惡行；二、心無改悔；三、作法治擯；四、非理謗僧；五、如法設諫；六、三法竟，罪至。
【譯文】【疏文】第三項，具足條件（具緣）共有六條：一、做出汙損白衣家庭的惡劣行徑；二、內心毫無改悔之意；三、僧團依法作羯磨施行驅逐；四、無端非理毀謗僧團；五、依循戒律法度對其進行勸諫；六、三番羯磨作法完畢，罪名正式成立。

【290-0020】02_戒疏/11a_卷三上之二#15
【原文】【記】具緣中。「汙家惡行」，乃是本緣。第四「謗僧」，正當所諫。「罪至」，謂刑及於身也。
【譯文】【記文】具足條件中。「汙損家庭之惡行」，乃是根本的罪緣。第四項「毀謗僧團」，正屬於被勸諫的對象。「罪名成立」，是指懲罰裁決加諸於其身。

【290-0021】02_戒疏/11a_卷三上之二#16
【原文】【疏】闕緣，可知。
【譯文】【疏文】欠缺條件（闕緣）的情況，依此類推即可明瞭。

【290-0022】02_戒疏/11a_卷三上之二#17
【原文】【記】闕緣中。闕初緣，如以衣食與父母、病人，採華供三寶等，兩不成故；闕第二，如逆路求悔，不須諫故；闕第三，舉擯非法；闕第四，或不反謗；第五，諫不如法；六、中間捨悔，竝非正犯。
【譯文】【記文】欠缺條件中。欠缺第一項條件，例如將衣食供給父母、病人，或是採花供養三寶等，汙家與惡行兩者皆不成立；欠缺第二項條件，例如半途迎向僧團求哀悔過，便不需要勸諫；欠缺第三項條件，指舉發驅逐的程序不合法度；欠缺第四項條件，指對方並未反過來毀謗；欠缺第五項條件，指勸諫的作法不如法；第六項，若在勸諫過程中放棄執著並悔改，這些全都不屬於僧殘的正犯。

【290-0023】02_戒疏/11a_卷三上之二#18

【290-0029】02_戒疏/11a_卷三上之二#24
【原文】【律】依聚落若城邑住，汙他家。
【譯文】【律文】依傍聚落或是城鎮居住，汙損他人良善家庭。

【290-0030】02_戒疏/11a_卷三上之二#25
【原文】【註】家者，有男有女。汙家者，有四種。一，依家汙家。一家得物，又與一家。所得物處聞之不喜，所與物處思當報恩，即作是言：「有與我者，我當報之；若不與我，我何故與？」二者，依利養汙家。如法得利，及鉢中餘，或與一居士，得者生念：「當報其恩。若不與我，我何故與？」三者，依親友汙家。若比丘依王、大臣，或為一居士，或不為一居士。便生念言：「其為我者，我當供養；不為我者，我不供養。」四者，依僧伽藍汙家。若比丘取僧華果與一居士，不與一居士。彼有得者思「當供養；若不與者，我不供養」也。
【譯文】【註文】所謂良善家庭（家），包括男子與女子。汙損家庭的情形共有四種：第一，依憑世俗人情而汙家。從某一戶人家獲得財物，轉手又送給另一戶人家。原本送出財物的施主聽聞此事心生不悅，而接受轉贈的家庭則心想應當報恩，於是便說：「只要有出家人給我好處，我就報答供養他；如果不出資給我，我又為何要供養他？」第二，依憑信施供養而汙家。依法托缽獲得利養，以及缽中所剩的飲食，有時送給某個居士，得到的人便動念：「我應當報答其恩德。若是不給我，我又為何供養他？」第三，依仗親屬朋友勢力而汙家。如果比丘依附國王、大臣的權勢，私下袒護某個居士，而不偏向另一個居士。受其關照者便動念說：「為我出力的人，我應當供養；不為我出力的人，我不供養。」第四，依仗僧團寺院財物而汙家。如果比丘私自拿僧眾的花果贈送給某位居士，而不給另一位居士。那位獲得好處的人便想「我應當供養他；如果拿不到，我就不供養」。

【290-0034】02_戒疏/11a_卷三上之二#29
【原文】【註】時有比丘，於彼止宿，著衣持鉢，入村乞食，法服齊整，行步庠序，低目直前，不左右顧視，以次行乞。居士見已，自相謂言：「此是何人？低目而行，既不顧視，亦不言笑，不相周接、善言問訊。我等不應與其飲食。不如阿濕婆等，與人周接——及上所言——應與供養。」時彼乞食，困乃得之。往至佛所，問言：「住止樂不？僧和合不？不以飲食為苦耶？」彼具白佛。便遙訶責，令往設擯。
【譯文】【註文】當時有如法守戒的比丘，在該地投宿留止，整齊穿戴袈裟並持缽，走入村落乞食，戒衣整肅齊整，步伐安詳莊重，垂眼正視前方，不隨意左顧右盼，依照門戶次序行乞。居士們見到後，私下彼此議論說：「此是何人？低垂著眼睛走路，既不左右看人，也不言談微笑，更不與大家酬酢應對、以好話問候慰勉。我們不該拿飲食供養他。還不如阿濕婆等人，與人熱情往來——就像上面說的種種討好舉止——我們才該給予供養。」當時那位如法乞食的比丘，受盡冷落艱難才勉強乞得食物。回去見到佛陀，佛陀問他：「住在那裡安樂嗎？僧團和睦團結嗎？不致於為了飲食而受苦吧？」該比丘便詳細向佛陀稟告。佛陀隨即在遠方嚴厲斥責，並派人前往執行驅逐羯磨。

【290-0035】02_戒疏/11a_卷三上之二#30
【原文】【疏】二、「依聚落」下，諫所諫事也，就中分三：初明依聚落造過；二、「諸比丘語言」下，至「不須住此」，正明牒過治擯；三、「是比丘」下至「不驅者」，明非理謗僧，此正所為事也。
【譯文】【疏文】第二部分，從「依聚落」以下，是勸諫所針對的具體事項，此中分為三段：首先說明依傍村落製造過失；第二段自「諸比丘語言」以下到「不須住此」為止，是正式說明揭發過犯並施以驅逐處分；第三段自「是比丘」以下到「不驅者」為止，說明犯僧無端毀謗僧團，這正是引發此戒所要處罰的核心事件。
