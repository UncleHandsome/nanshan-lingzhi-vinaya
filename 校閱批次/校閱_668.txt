# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【668-0002】資持記/10a_中三下#27
【原文】通列四時。前後三種，大約不定。日中一種，佛佛常法；以住中道，假事表理故；凡所化儀，無不皆中。佛制下，正顯教意。上有三趣，地獄同鬼類。欲超三界，必斷六因。故制比丘不同彼食，令依極聖，出離可期。嗟彼愚人，多食晚食；肯斆諸佛，而甘同鬼畜，不知何意乎！
【譯文】通盤列出四個時段。前後三種時段，大概來說並不固定。唯獨正午這一種，是過去諸佛與未來諸佛永恆不變的法則；因為安住於中道，藉由世事來表徵真理的緣故；凡是教化的威儀，無一不是契合於中正之道。從「佛制」以下，正式顯明教戒的深意。上面有三惡道，地獄與餓鬼同類。想要超越三界，必須斷除六道的業因。故制比丘不同於那樣進食，令其依止至極的大聖，解脫出離才指日可待。可歎那些愚癡的人，大多喜歡在晚間進食；不肯效法諸佛，反而甘心等同於餓鬼畜生，真不知心裡是怎麼想的！

【668-0003】資持記/10a_中三下#28
【原文】三中，《多論》，初釋時非時。四義中，初約日明出沒，餘三約乞食合宜不宜。二三約他事，第四就己行。又下，明時分不定。晝夜各九時〔且約相等〕，《增輝》引古解云：晝夜都十八時，一時有五十臘縛，十八時總九百臘縛，三十臘縛為一須臾。〔三百為十須臾，九百為三十須臾。〕事同者，同下《僧祇》故。〔《俱舍》一百二十剎那為一怛剎那。
【譯文】第三部分中，《多論》首先解釋適當時限與非適當時限。四種義理中，第一種是依據太陽來說明升起與落下，其餘三種是就乞食合不合適來說明。第二和第三種是就他人之事來說，第四種是就自己的行持而言。從「又」字以下，說明時間劃分並不固定。白天和夜晚各分為九個時辰〔暫且依照相等的時間來論〕，《增輝記》引用古人的解釋說：白天夜晚總共十八個時辰，一個時辰有五十臘縛，十八個時辰總共九百臘縛，三十臘縛為一個須臾。〔三百臘縛為十個須臾，九百臘縛為三十個須臾。〕事情相同，是因為與下文的《僧祇律》相同。〔《俱舍論》說一百二十個剎那為一個怛剎那。

【譯文】六十個怛剎那為一個臘縛。三十個臘縛為一個須臾，三十個須臾為一晝夜。〕太陽落至接近地面的說法，依照《俱舍論》，太陽和月亮在須彌山半腰，距離地面有四萬由旬；依照這個說法就沒有落至地下的意義，只是太陽運行到最南邊時，看起來好像落了下去；因為天上南北相距有一百八十條運行軌道，太陽就在這當中來回運行，以此劃分出八個節氣；

【668-0005】資持記/10a_中三下#30

【668-0006】資持記/10a_中三下#31
【原文】從北却迴至立春春分立夏夏至，各經四十五道；還至極北，如是終而復始。四十。《時非時經》即《阿含》別品，是以雙標。彼約脚影定一年中日夜長短，須者尋之。準俗者，此方亦以十五日為一氣，一氣有三候，一候有五日，三氣為一節〔四十五日〕，一年有四時八節二十四氣七十二候三十六旬。

【668-0007】資持記/10a_中三下#32
【原文】《僧祇》脚影者，立日中以脚步影也。刻漏者，量水為數，隨時增減，滴漏定時，謂之刻漏。釋初緣中，引律定時。云至中者，此明極限，食必中前。四天下者，《俱舍》云：日轉四天下，正照一面，傍照兩面，長背一面，又云：北洲夜半，東洲日沒，南洲日中，西洲日出。
【譯文】《僧祇律》的腳影法，是在正午時分站立，用腳步來測量影子。刻漏，是量度水滴的數量，隨時令增減，靠水滴漏定出時間，這叫做刻漏。在解釋最初因緣中，引用戒律來確定時間。所說「至中」，這是指時間的極限，進食必須在正午前結束。四天下的說法，《俱舍論》說：太陽輪流照耀四天下，正照著一個洲，側照著兩個洲，長久背對著一個洲。又說：北俱盧洲是半夜時，東勝神洲是日落，南瞻部洲是正午，西牛賀洲是日出。

【668-0008】資持記/10a_中三下#33
【原文】四洲皆約從明至中，故云亦爾。下引《僧祇》。正中犯吉，故知受食必在中前；經中食時，乃當辰已；古德卯齋，護之彌急；有聞諸佛日中食，便謂中前非法，蓋不知教也。又有訛云不過鍾食，便聽鍾奉戒；況打鍾不定，何足為準！瞬即動目少時，髮謂影移少地。
【譯文】四大部洲都是以從天亮到正午為進食時段，所以說「也是如此」。下面引用《僧祇律》。正午時分受食犯突吉羅罪，由此可知接受食物必定要在正午之前；經中所說的進食時間，正相當於辰時和巳時；古德實行卯時用齋，防護得更為急切；有人聽聞諸佛是在正午進食，便認為正午前進食不合教法，這大概是不懂教理吧。又有人訛傳說只要鐘聲未過就可以進食，便完全聽從鐘聲來奉持戒律；何況敲鐘時間本就不確定，哪裡足以作為準則呢！「瞬」就是眼睛眨動的極短時間，「髮」是指影子移動如同一根頭髮般細微的距離。

【原文】比丘問佛，佛言：過去恚母布施，鎖母房中，母從索食，答云：何如飡砂飲水，七日母死；其子命終墮獄，罪畢為人，故受此報；由昔供佛，故今得道。〔目連緣如後篇具引。〕然下，顯僧福。大下，歎所修。經下，勸憶持。即《淨名經》。淨命，謂無邪求。
【譯文】眾比丘向佛陀請示其中的緣故，佛陀說：『他在過去世時曾因恚怒母親布施僧寶，便將母親鎖在房間裡，母親向他討要食物，他卻回答說：何不吞食細砂、飲用冷水？過了七天母親便活活餓死；那個兒子命終之後墮入地獄，罪業報盡轉生為人，因此招感這種飢困之報；因為過去生中曾供養佛陀的緣故，所以今生得以悟道證果。』（目連尊者的因緣，在後面的章篇中將會完整引述。）從「然而」以下，顯明敬事僧眾的大福德。從「大」字以下，讚歎所修持行門的功德。從「經」字以下，勸勉病患應當憶持善念。指的便是《維摩詰經》。所謂「清淨活命」，是指斷除一切邪命求利的心態。

【668-0011】01_行事鈔/12a_卷下之四#11
【原文】其瞻病者，隨其前人，病有強弱，心有利鈍，業有麁細，情有去取；當依志願，隨後述之。或緣西方無量壽佛，或兜率彌勒佛，或靈鷲釋迦本師；或身本無人，妄自立我；或外相似有，實自空無，如至焰處，則無水相；或為說唯識無境，唯情妄見。各隨機辯而誘導之。
【譯文】那照看病人的人，應當隨順對方具體情況：病勢有沉重或輕微，心智有利根或鈍根，所造業行有粗淺或細微，情感執著各有取捨；應當依循他平日的志願發心，順應其意願在旁開導陳述。或者引導他繫念西方阿彌陀佛（無量壽佛），或者繫念兜率天彌勒佛，或者繫念靈鷲山的釋迦本師；或者引導他體會色身本來無有真實人相、只因妄想而假立為我；或者觀照外境表面看似實有、實質自性本空，就像走到陽焰之處，便了知實無水相可得；或者為他說唯識無境、一切皆是情執虛妄所見之理。各自隨順其根機與言辯來善加引導誘化。

【668-0012】資持記/16a_下四#23
【原文】作惡生善道者，準天台《十疑論》，三義通之：一者約心，以造罪時，從虛妄顛倒心生，是虛；今因知識勸導，改心是實故。二者造罪時，由癡暗虛妄為緣，是偽；今遇知識，得聞佛名，發菩提心是真故。三決定者，前造罪時，心有間斷；今臨終時，心猛利故；
【譯文】一生造作惡業卻能在臨終轉生善道者，依照天台智者大師《淨土十疑論》的說法，可以從三個義理層面來貫通融會：第一是就「心念的真偽」而言，造作罪業之時，是從虛妄顛倒的攀緣心所生起，本質是虛妄的；如今臨終因善知識的開導勸誘，洗心革面，這種悔悟之心是真實的緣故。第二是就「境界的真偽」而言，過去造作罪業，是因愚癡暗昧的妄想作為助緣，其境是偽造的；如今值遇大善知識，得以親聞諸佛名號，所發出的菩提心是真實不虛的緣故。第三是就「心力的強弱決定」而言，先前造作罪業時，其心念時斷時續；如今面臨死亡關頭，心念猛烈專注無比的緣故；

【668-0014】01_行事鈔/12a_卷下之四#12
【原文】《四分》：當問病者，持何等衣？彼病人受不好衣鉢，及送與他，恐瞻病者得，應準告云：「此三衣鉢具，佛所制畜，有披著者，出世因緣；乃至未來受生，常著三衣而生，如面王比丘。未知持何等衣鉢坐具？當見告示，為取著之；現在未來，為佛所讚。」若見貪物，心無大志者，告云：「此衣物等，並是幻有；大德儲積來久，為之疲勞；及至病苦，眼看不救，乃至脫死，亦無一隨。大德生從胎出，亦不將一財來；脫至後世，亦不將去，經云：往昔國王，為寶所誑；及至臨終，無一隨己，可不實乎！不須憂念，幻假錢財，但須存勝業耳！亦不須付囑餘人，此則妄行顏面，終非送大德死法。但用佛語，普召十方凡聖，大眾羯磨分之，如法受用；令大德乘此功力，必生善處，此是佛勅，可不好也！」如是種種，軟言諫喻；不得違逆，又非順意。以臨終妄業競集，多無立志；此是一期大要，善惡升沈天隔。
【譯文】《四分律》記載：應當詢問病人，平素受持的是何等衣物？如果那病人故意手持粗劣的衣缽示人，而把好的衣缽轉送寄託給他人，唯恐被照料者得到，瞻病者應當依律勸告說：「這三衣一缽及坐具，是佛陀制定蓄持的法物，凡是披搭受持之人，皆具足出離世間的因緣；乃至於未來轉生時，常常生來便身披三衣，就像面王比丘那樣。不知道大德受持的是何種衣缽與坐具？請明白告示於我，我替您取來穿戴受持；無論現世或未來，這都是為佛所稱許讚歎的。」如果見到病人貪戀財物，心中沒有宏大的出離志向，則勸告說：「這些衣物等物，全都是虛幻假有的；大德長久以來蓄積這些，為此勞心勞力；及至如今身遭病苦，眼看醫藥難救，乃至一旦命終，也沒有一件東西能隨身帶走。大德從娘胎出生時，未曾帶來一分財物；一旦前往後世，也無法帶走分毫。經中說：往昔的國王被珍寶所誑騙，到了臨終時無一物能跟隨自己，這難道不是真實之言嗎！不必憂慮掛念這些虛幻不實的錢財，心中只要存念殊勝道業即可！也不必私下託付交代給其他人，這只是虛妄講求人情世面，終究不是引導大德解脫往生的如法正路。只要遵照佛陀教誡，普遍召集十方凡聖僧眾，由大眾僧作羯磨如法分配受用；使大德依憑此分物功德之力，必定能往生善處，這是佛陀的明敕，豈不是最好的安排！」像這樣以種種柔和的言辭勸勉開導；既不可生硬違抗其心意，也不可放任順從其貪執。因為臨終之際妄想業緣紛然競起，病人多半缺乏堅定心志；這是此期生命解脫的最關鍵樞要，升沉善惡判若天淵。
