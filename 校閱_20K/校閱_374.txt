# 校閱材料　第374檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【374-0001】02_戒疏/18b_卷四上之三#50
【原文】【疏】戒本三句：一、人；二、若他二種足食已；三、「不作餘食法」下，明勸結罪。
【譯文】【疏文】戒本分為三句：一、人（能犯的人）；二、「若他二種足食已」；三、「不作餘食法」以下，說明勸人進食而結罪。

【374-0002】02_戒疏/18b_卷四上之三#51
【原文】【記】戒本分句。二中，「二種足」者，即僧自食及他請食也。
【譯文】【記文】這是分判戒本的文句。第二句中的「二種足」，就是指在僧團中自己進食，以及受他人邀請而食這兩種。

【374-0003】02_戒疏/18b_卷四上之三#52
【原文】【疏】言「非餘」者，非是注解不犯足餘。將不犯望於犯，不犯是犯家餘。
【譯文】【疏文】所說的「非餘」，「非」是指排除註解中「不犯足」的各項情況；「餘」，是把不犯對照於犯來看，不犯正是正犯之外的其餘情況（例外）。

【374-0004】02_戒疏/18b_卷四上之三#53
【原文】【記】釋非餘中。初釋「非」字。「非注解不犯足」者，通指注中八種也。「將」下，釋「餘」字。
【譯文】【記文】這是解釋「非餘」的部分。先解釋「非」字；所謂「非注解不犯足」，是通指註中的八種情形。「將不犯望於犯」以下，是解釋「餘」字。

【374-0005】02_戒疏/18b_卷四上之三#54
【原文】【疏】就解「令他犯」中，與病人食，本不名犯，但能與者，心懷不善，實開謂閉，愚教故與。前噉不犯，能勸吉羅。
【譯文】【疏文】在解釋「令他犯」這一段中：把食物給病人，本來不算犯戒；但能給食的人心懷不善，實際上是開許的，他卻當作遮禁，因為愚昧於教法而給與。對方（受食者）吃了不犯，能勸食的人則結突吉羅。

【374-0006】02_戒疏/18b_卷四上之三#55
【原文】【記】釋令他中。注文，初明犯重。「若與」下，次示犯輕，又二。初三種所勸不食。「若彼」下，三種所勸雖食，於教無違，故能勸但吉。
【譯文】【記文】這是解釋「令他」這一段。註文中，開頭說明犯重的情況。「若與」以下，其次顯示犯輕的情況，又分兩層：先說三種被勸的人不吃；「若彼」以下，說三種被勸的人雖然吃了，但於教法無違，所以能勸的人只得突吉羅。

【374-0007】02_戒疏/18b_卷四上之三#56
【原文】【律】三十七、非時食戒。
【譯文】【律文】第三十七、非時食戒。

【374-0008】02_戒疏/18b_卷四上之三#57
【原文】【疏】非時食戒三十七。
【譯文】【疏文】非時食戒第三十七。

【374-0009】02_戒疏/18b_卷四上之三#58
【原文】【疏】凡食資身，事須節約，數則致患。故限之令定。始於清旦，終至中前，事順應法，不生過罪，名之為「時」。過則非儀，長貪妨道，招機納謗，事不應法，名之「非時」。故所以制。
【譯文】【疏文】凡是飲食滋養身體，此事必須有所節制，次數多了就會招致過患，所以限定它使之有一定。從清晨開始，一直到日中之前，行事順合常軌、契合教法，不會產生過失罪愆，這就叫作「時」。超過了就不合儀軌，增長貪欲、妨礙修道，招致譏嫌、蒙受謗議，行事不合教法，這就叫作「非時」。因此才制定這條戒。

【374-0010】02_戒疏/18b_卷四上之三#59
【原文】【記】三十七，制中。初敘食緣利害。「故」下，次示制法順違。初明順益。「事順」，謂世俗常儀，皆多朝食。「應法」，謂三世諸佛，並不過中。「過則」下，次明違損，通及自他。言「招譏」者，如《律》緣起：「女人恚言：『沙門釋子，寧自破腹，不應夜食。』」
【譯文】【記文】三十七戒的制意部分。開頭敘述飲食因緣的利害。「故限之令定」以下，其次顯示制戒之法中的順與違。先說明順的好處：「事順」，是說世俗通常的儀節，大多在早晨進食；「應法」，是說三世諸佛都不過中而食。「過則非儀」以下，其次說明違逆的損害，通涉自身與他人。所說「招譏」，就像《律》中緣起所說：「女人忿怒地說：『沙門釋子，寧可自己剖開肚子，也不應該在夜間進食。』」

【374-0011】02_戒疏/18b_卷四上之三#60
【原文】【疏】據《阿含》中《時非時經》明，一年二十四半月，月十五日。準此俗中二十四氣。故彼冬分四月，以八月十六日為始，終於臘月十五日。春分十六日為始，至四月十五日。夏分不言自曉。
【譯文】【疏文】依據《阿含》中的《時非時經》所說，一年有二十四個半月，每個半月十五日。這相當於此方世俗所說的二十四節氣。所以那經中冬分四個月，從八月十六日開始，到臘月十五日結束；春季四個月從臘月十六日開始，到四月十五日；夏分則不必說明也能明白。

【374-0012】02_戒疏/18b_卷四上之三#61
【原文】【記】引示中。《時非時經》出阿含部，今亦別行，在「竟」字函，文近兩紙，廣分三時步影之數，須者尋之。初引經以示。「月十五日」，白、黑分也。「準」下，次會同此方。「俗中二十四氣」，一年十二月中，每一月有兩節氣，大約亦以十五日為一氣。「故」下，三、引三時以證。既以黑月為三時之始，則知西竺月分黑、白，不同此方白、黑共為一月也。
【譯文】【記文】這是「引經顯示」的部分。《時非時經》出自阿含部，現今也有單行本，收在「竟」字函中，文字將近兩紙，詳細分判三時測影的度數，需要的人可以自己尋檢。開頭是引用經文來顯示。「月十五日」，是指白分、黑分各十五日。「準此俗中二十四氣」以下，其次會通此方的曆法。所謂「俗中二十四氣」，一年十二個月之中，每個月有兩個節氣，大約也是以十五日為一個節氣。「故彼冬分」以下，第三是引用三時來證明。既然以黑月作為三時的開端，就可知道印度的月份分為黑分、白分，不同於此方把白分、黑分合為一個月。

【374-0013】02_戒疏/18b_卷四上之三#62
【原文】【疏】然今此國三種日月：一、天上日月；二、人中日月；三、陰陽日月。上二不定，陰陽剋時，楷定無爽。至如佛法，春分以臘月十六日為始者：須準陰陽曆家，大寒是十二月中氣，如是類例，十六日便為立春，剋定步數，可知時分。故《僧祇》中「令作脚影」，此即是也。《多論》晝夜各分九時，《僧祇》日夕三十須臾，唐國晷漏，箭為百刻。
【譯文】【疏文】然而現今此國有三種日月：一、天上日月；二、人中日月；三、陰陽日月。前二種不固定，陰陽曆法所刻定的時刻，則準確固定而沒有差錯。至於佛法中說春分以臘月十六日為開始，這就必須依準陰陽曆家：大寒是十二月的「中氣」，照此類推，十六日便成為立春；刻定測影的步數，就可以知道時分。所以《僧祇律》中說「令作脚影」，就是指這件事。《多論》說晝夜各分為九時，《僧祇》說一日一夜有三十須臾，唐國的晷漏則以箭刻分為一百刻。

【374-0014】02_戒疏/18b_卷四上之三#63
【原文】【記】會通中。初示日月不同。「天上」者，《增輝》云「今所見者」。「人中」者，即今幾時為日，幾日為月。「陰陽」者，即曆數之家剋定分抄以為算數，故云「無爽」。「爽」，差也。「至如」下，次明前經準俗之相。二氣之間，名為「中氣」。然其相準未必全同，但取一月兩分之數耳。「故」下，引證。初證「脚影」同。「多」下，次證時刻同。《多論》「晝夜各分九時」，此據春、秋兩分，晝夜相等，冬、夏兩至，例有增減。《僧祇》「須臾」者，日極長十八，極短十二，晝夜等各十五。「唐國晷漏」者，「晷」即時刻，夏至日六十刻、夜四十，冬至日反上，春、秋分各五十刻。謂以竹箭竪於壺中，水漏箭浮，以分刻數。
【譯文】【記文】這是「會通」的部分。首先顯示三種日月的不同。「天上日月」，是指《增輝》所說的「現今所見的日月」。「人中日月」，就是現在以幾個時辰為一日、幾日為一月。「陰陽日月」，就是曆算之家刻定分秒作為推算的數值，所以說「無爽」；「爽」就是差錯的意思。「至如佛法」以下，其次說明前面所引經文依準世俗的情況。兩個節氣之間，叫作「中氣」。然而兩者相準未必完全相同，只是取一個月分為兩半的數目罷了。「故《僧祇》」以下，是引用證據：先證明「脚影」一法相同；「《多論》」以下，其次證明時刻相同。《多論》說「晝夜各分九時」，這是根據春分、秋分晝夜相等時而說，冬至、夏至則照例各有增減。《僧祇》所說的「須臾」，是白日最長時十八須臾、最短時十二須臾，晝夜相等時各十五須臾。「唐國晷漏」，晷就是時刻，夏至白天六十刻、夜間四十刻，冬至則相反，春分、秋分各五十刻。這是把竹箭豎立在壺中，水漏出而箭浮起，用來分辨刻數。

【374-0015】02_戒疏/18b_卷四上之三#64
【原文】【疏】出家時節，知何不須？然於一食，日別常法。但用步晷一法，足定方隅，縱在山澤，有迷依步，無不立曉。必時陰暗，以鏡映之。寧早不晚，是持護法。
【譯文】【疏文】出家人在時節上，怎能不知道呢？尤其對於一食，這是每日固定的常法。只要用測影（步晷）這一種方法，就足以判定方位與時刻；縱使在山林澤藪之中，有所迷惑時依此法測影，沒有不立刻明白的。如果正逢陰暗，就用鏡子映照來測。寧可早一些，不要晚；這就是持守、保護戒法。

【374-0016】02_戒疏/18b_卷四上之三#65
【原文】【記】結告中。初示須知。「但」下，令準前經。「陰時以鏡映」者，未詳其事。「寧」下，次勸急護。古之高德，奉敬律儀，一食卯齋，用為常務。今時濁惡，噉食無時，設有營齋，遲留至暮，禪師講匠，坐受安然。唯知取適於穢軀，豈念公違於聖教！糞蟲餓鬼，即此心成；銅汁鐵丸，豈從他得？有識高達，宜乎勉之。

【374-0029】02_戒疏/18b_卷四上之三#78
【原文】【記】戒本。第二，注中，先明「時」限，以釋「非時」。「四天亦爾」者，合云「皆爾」。雖四天下日夜不同，並取明相至中為時，已後為非時。南州日午，北州半夜，東沒西出，如是輪轉。若約比丘互相來往，還約本處以判持犯。如南人往北，半夜前食，不犯非時，餘方亦爾。如《拾義鈔》據《伽論》說。
【譯文】【記文】這是戒本的部分。第二，註文中先說明「時」的時限，用來解釋「非時」。「四天下食亦爾」，應當說「皆爾」，都是如此。雖然四天下的日夜不同，但都取明相出現到日中為「時」，此後為「非時」。南洲日中的時候，北洲正是半夜；東方日落，西方日出，如此輪轉不停。如果就比丘彼此往來而言，還是要依原本所在之處來判定持犯。例如南洲的人前往北洲，在北洲半夜之前進食，此時正值南洲日中之前，不犯非時；其餘各方也是這樣。如《拾義鈔》依據《伽論》所說。

【374-0032】02_戒疏/18b_卷四上之三#81
【原文】【疏】就辨相中，三藥解者。謂諸漿等，手、口二受，明相未出，受法不失，名之為「時」；明出法失，得罪，不應服，名「非時」也。蘇油口法未失，名「時」；八日時過失法，名「非時」。盡形壽藥有病加服，名為「時」；無病輒服，名「非時」。若非口法，從時食論。餘「殘宿」、「不受」例之，至彼便略。
【譯文】【疏文】在辨明戒相的部分，就三種藥來解釋。所謂種種漿水等，經過手受、口受兩種受法，在明相未出時，受法不失，這就叫作「時」；明相一出，受法喪失，就得罪，不應再服，這就叫作「非時」。蘇油等七日藥，口法未失時叫作「時」；到第八日時限已過而失法，就叫作「非時」。盡形壽藥有病時加法服用，叫作「時」；沒有病而隨便服用，就叫作「非時」。如果沒有加受口法，就依時食來論。其餘「殘宿」、「不受」等戒，也照此類推，到那時便從略。

【374-0033】02_戒疏/18b_卷四上之三#82
【原文】【記】釋第四中。三藥次列，竝約加法分時、非時者。前二望限，盡形對病。故知若加口法，非時號時；限過病差，時名非時。
【譯文】【記文】這是解釋第四句的部分。三種藥依次列出，都是就「加法」來分別時與非時的。前二種是就期限而言，盡形壽藥則是對病而言。所以可知：若加了口法，本來非時的也可稱作「時」；期限已過或病已痊癒，本來是「時」的也就叫作「非時」了。
