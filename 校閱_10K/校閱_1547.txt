# 校閱材料　第1547檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】問：和尚若懷疑弟子年齡不滿二十，既然只是懷疑，理應犯輕罪，為何卻定為重罪？答：受戒的人是有情眾生，完全可以當面詢問，為何不安詳仔細地查問實情？既然自己心中已有懷疑，卻輕慢戒律法度而為他授戒，導致對方無法得戒，對他人造成的惱害極深，因此其罪責與明知故犯相同。問：如果說有情可以詢問而不問就得重罪、與明知故犯相同，那麼受託建造僧房的人，若懷疑前人界定的處所是否合法，前來作羯磨的人也是有情可以詢問，他若慢法造作，是否也應得重罪？答：受戒是極為重大的事，而且是根本大事；心裡既然懷有疑慮，就是輕慢戒法、惱害大眾並損害他人，造房則不涉及根本戒體，所以不能相比。此處過去的解釋認為：在原本受戒時，如果弟子的世俗年齡不滿二十歲，且月份日數又缺少，就不開許計算胎月與閏月；如果受戒時世俗年齡已滿二十歲，僅月份日數不滿，則開許計算，若有懷疑也是如此處理。現在的合理解釋是：只要加上胎月和閏月能滿二十歲，即便世俗年齡原本不足，開許又有何過失？另一種解釋是：此地三年置一閏月，便可度化出家。首師解釋沙彌計算胎月與閏月的方法是：姑且以極限最小的臘月最後一日出生為例，到滿二十歲那一年的正月初一日受具足戒，總計年與月，實質上只有十八年又兩天。以在母胎中二百七十天計算，折合為九個月又四天，加上之前的時間，共有十八年九個月零六天。接著計算閏月：俗稱十九年為一章，其中有七個閏月；計算十八年九個月零六天，共有六個月又二十七天的閏月，連同前面合計有十九年四個月零三天。接著計算連續的大月：將先前的年歲全部折算為二百三十二個月零三天；四十九個月為一章，其中必定有三個連續大月，一百九十六個月折成四章，便多出十二天；剩下的三十六個月中還有兩個連續大月，加上前面共多出十四天。接著計算十四日布薩：一年下來可累積多出十八天；總計十九年四個月可得多出三百四十八天，以三百三十六天算作一年，還餘下十二天；將這十二天補貼進連續大月的十四天中，再補貼到胎月與閏月的餘數三天中，便形成一個月零一天，連同前面累積計算，便達到了二十年五個月零一天。計算這位沙彌在二十歲受戒，以十二個月為一年，還多出五個月零一天。假使沙彌在臘月最後一天出生，剛滿十九歲，到八月十二日受戒：縮減前面所說的五個月零一天，扣除七個大月布薩減少的七天，又減去閏月餘數略微得到的五天，再扣除連續大月略微折半的一天，總共約減少十三天；從先前的五個月零一天中扣除，還剩下四個月又十八天。照此計算，這位沙彌在臘月最後一天出生、年滿十九歲而在八月十二日受戒，依然是合法的。所以《毘尼摩得伽論》問：應從何處開始計算成年？答：從母胎開始計算，並計入所有的閏月。《五分律》記載：當時童子迦葉年齡不滿就受了具足戒，事後才生起疑慮，乃至佛陀詢問比丘：「童子迦葉有所證悟嗎？」比丘回答：「已證得須陀洹果。」佛說：「此人是以上法得第一受具，不稱為白四羯磨如法受戒。從今以後，聽許計算母胎中的月份；如果仍不足，聽許計算閏月；如果計算胎閏後已經滿足，就聽許受具；若仍不足，聽許以沙門年（沙彌年資）補足年齡。」《毘尼母論》說：年齡不滿者，聽許計算胎中的年歲；若仍不滿，聽許計算閏月；若再不滿，聽許計算十四日布薩；若還是不滿，但確實證得阿羅漢果，這屬於上法受具，雖然不滿二十歲，依然得受具足戒，不算犯戒。論義說：雖然《五分律》師沒有保存計算十四日布薩與二十三種法的次第，但《毘尼母論》特別論述了十四日與二十歲的演算法，由此可知十四日布薩確實可以計入。《僧祇律》說：冬天出生就在冬天受戒，春天出生就在春天受戒，前安居時出生就在前安居受戒，後安居時出生就在後安居受戒，這四種情況都尚未經過一個完整的安居，都算作年齡未滿；若冬天出生、經過一次安居之後才受戒，或者春天出生、前安居出生、後安居出生，這四種都是經過安居之後受戒，全部算作年齡已滿。如果不滿二十雨（夏），僧眾中半數人認為已滿，這半數人無犯；半數人明知或認為不滿，這半數人便犯波逸提；受戒人仍算得受具足戒，這稱為受具足戒的判定。解釋說：按照此文，必須滿二十雨（夏安居）才算年齡圓滿，所以前文說不滿二十歲、扣減二十年，即使滿二十年或超過二十年，若未達標準都稱不滿；如果滿了二十雨，扣減或超過二十年都稱作滿，詳細情形如該律所說。《十誦律》說：如果年齡不滿二十歲，自己以為不滿，或者遺忘不知道不滿，僧團詢問年齡滿不滿時回答「滿」，則得戒；乃至若年齡已滿二十歲，無論知道滿、不知道滿或心懷疑慮，回答僧團說「不滿」，就不得戒；如果回答「不知道」或說「懷疑」，都得戒，但僧團因沒有詳細盤問而犯吉羅罪。此外，《五分律》原本規定五年一閏，《十誦律》則聽許依頻婆娑羅王的曆法六年置一閏。
