# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【416-0001】03_業疏/01b_卷一之一#76
【原文】答中，初通敘對事分法。「隨分三位」謂三品事中皆可分三，則於對首離出一品，故為九品；約事分法，法亦有九，故云「同也」。「何」下次別列品位又三：初明心念，但念為下下，對念為下中，眾念為下上；二明眾法，單白為上下，白二為上中，白四為上上；三對首中，如文自列。偷蘭三品，重蘭攝在眾法，輕者自歸中下，今立中上，唯局次蘭。然據作法，還即但對，而居眾法對首之上，故諸問答自此而生。「上」下會通，初決前合意；「今」下顯今離意
【譯文】在回答中，起初通論敘述針對事相而劃分作法。「隨分三位」是指在三品事相中皆可再析分為三，於是在對首法中析出一個品位，所以成為九品；依據事相來劃分作法，作法也有九種，所以說「同也」。自「何」以下接著分別列舉品位，又分為三部分：第一說明心念，純心念為下下，對首心念為下中，眾法心念為下上；第二說明眾法，單白為上下，白二為上中，白四為上上；第三在對首法中，如原文自身所列。偷蘭遮罪有三品，重品偷蘭遮收攝在眾法中，輕品偷蘭遮自然歸於中下，現在所立的中上品，唯獨局限於次品偷蘭遮。然而就作法而言，終究還是純對首，卻位居眾法對首之上，所以隨後的各番問答便由此產生。自「上」以下是融會貫通，起初裁決前面合併的用意；自「今」以下顯明現在分立的用意。

【416-0003】03_業疏/01b_卷一之一#78
【原文】轉難中，悔蘭小眾，制問邊人，亦不許別，即與懺捨理不當異
【譯文】在進一步問難中，向少數僧眾懺悔偷蘭遮罪，戒律規定必須詢問身邊的人，也不允許離眾另作，那麼在義理上理應與懺悔捨墮沒有差異。

【416-0004】03_業疏/01b_卷一之一#79
【原文】答：據非別眾，說恣應上；悔蘭限三，應歸中品。然以捨墮通對一人，故名中中；悔蘭其必問邊，理歸中上。以十誦云「重者界內，輕者界外」，四分下文「小眾」故也。及時加法，界亦通收，與前說恣葢是同也。對人多少，故有階級
【譯文】答：若依據不得離眾另作而言，說戒與自恣應當位居上品；懺悔偷蘭遮罪人數限定為三人，應當歸於中品。然而因為捨墮罪可以通於只對一人懺悔，所以稱為中中品；懺悔偷蘭遮罪則必定要詢問身邊之人，義理上應歸為中上品。這是因為《十誦律》說「重者界內，輕者界外」，《四分律》下文也說「少數僧眾（小眾）」的緣故。到了作羯磨法時，界內的僧眾也通通收攝在內，這與前面的說戒、自恣大概是相同的。正是因為面對人數的多寡不同，所以才有品位階級的差異。

【416-0005】03_業疏/01b_卷一之一#80
【原文】答中，初斥奪前難。捨、懺但制別集，說恣通収內外，若取別眾，須推說恣，不體今意，故且奪之。「然」下伸今所立：初對捨墮以顯通局，捨墮下通一人，中蘭局定三、二，據分品次，於理顯然。《十誦》三階：初篇生重界內大眾懺，二初篇生輕、二篇生重應界外四比丘眾中悔，三僧殘生輕一比丘前悔。《四分》即滅諍犍度，故云「下文」，彼云「小眾二三人」也。「及」下次對說恣以明同異，上約別眾明同，下據對人顯異。「界亦通收」者，以界有人亦不得別。然說恣眾法，僧私必集；悔蘭別法，不集亦成。今此且據制必問邊，一往言同，次科自見。「對人多少」者，說恣不定，下通一人，則顯悔蘭人位揩定，故為上矣
【譯文】在回答中，起初駁斥並破除前一個問難。懺捨墮與悔偷蘭只是規定不得離眾另行集會，說戒與自恣則通通收納界內界外之人，如果僅以不得離眾為準則，就必須推崇說戒與自恣，這樣沒有體會當前的立意，所以暫且破除之。自「然」以下闡發當前所確立的觀點：起初是比對捨墮以顯明通達與局限，捨墮向下通於面對一人，次品偷蘭遮則局限定為三人或二人，依此劃分品階次序，在義理上十分顯然。《十誦律》有三個階次：第一篇波羅夷所生出的重偷蘭遮在界內大眾僧中懺悔；第二，第一篇所生出的輕偷蘭遮、第二篇僧殘所生出的重偷蘭遮，應在界外四位比丘僧中懺悔；第三，僧殘所生出的輕偷蘭遮在一比丘面前懺悔。《四分律》指的就是〈滅諍犍度〉，所以稱為「下文」，那裡說「小眾二三人」。「及」以下接著比對說戒與自恣以明辨同異，上面就不得離眾說明相同之處，下面依據所對人數顯明差異。「界亦通收」是指界內若有人也不得離眾另作。然而說戒與自恣是眾法，公私都必須全體集合；懺悔偷蘭遮是個別行持之法，即使不集合也能成辦。此處暫且依據戒律規定必須詢問身邊的人，籠統地說相同，下一科自然會見分曉。「對人多少」是指說戒自恣的人數不固定，向下可通於一人，這就彰顯出懺悔偷蘭遮在人數規格上是有嚴格規定的，所以列為上品。

【416-0019】03_業疏/01b_卷一之一#94
【原文】三中初據文立義。「以三羯磨攝一切」者，此正律文。「若」下斥古局數，律文所出且據緣起，非止此數，事既無量，不可隨事以定法數。「以」下顯今從法，結集等白並諸羅漢準法裁之，則彰三法統攝多事，不可如古據律定數。「不具舒」者，異前諸師細尋等也；「且約略」者，指前列數，非限定也
