# 校閱材料　第543檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【543-0001】02_戒疏/09b_卷二下之二#8
【原文】【疏】《善見論》，夢有四種：「一、四大不和故夢，如見山崩地動，飛騰虗空，虎狼賊逐等。二、先見故夢，如晝見青黃男女，夜則夢見。三、天人與夢，或有善惡天子，為現善惡兩夢。四、想心故夢，此人前身為福，則有善夢，誦經禮佛等；若為惡者，則見殺盜等。」前二不實，經云「如夢幻」等是也。後二為實，經云「但取夢相」，如《方等》、《佛名》所說。
【譯文】【疏文】《善見律毘婆沙》說，夢境有四種：「第一、因體內地水火風四大不調和而做夢，例如夢見山崩地裂、在虛空中飛騰、被虎狼盜賊追趕等。第二、因白天所見而做夢，例如白天看見青黃色彩或男女形象，夜晚便夢見。第三、由天人給予夢境，或是善天子、惡天子，為其顯現善或惡兩種夢相。第四、因內心造作思惟而做夢，這人如果前世積福，就會做善夢，如誦經禮佛等；若前世造惡，就會夢見殺生、偷盜等事。」前兩種夢境虛妄不實，正如佛經所說「如夢幻泡影」之類即是。後兩種夢境則具有實效，經中說「只看取夢中徵兆」，就像《方等陀羅尼經》、《佛名經》中所說的那樣。

【543-0002】02_戒疏/09b_卷二下之二#9
【原文】【記】第三句，釋注，引教中，初科。前列四種，後總判虗實。「如夢」等者，經中多取喻，法不實故。「如《方等》」者，悔法有三：一、無生，二、作法，三、取相。彼明取相，故令求夢以表罪滅。此皆聖人所示，如上第三是也。
【譯文】【記文】第三句解釋註文、引用經教之中，這是第一段。前面列出四種夢，後面總體判定其虛妄或真實。「如夢」等說法，經中大多作為比喻，是說明諸法虛妄不實。「如《方等》」等說法，懺悔法門有三種：一是觀無生，二是如法作法，三是取相懺。該經闡明取相懺，所以讓人祈求夢境以驗證罪業消滅。這都是聖人所感召顯現，如同上述第三種情況。

【543-0003】02_戒疏/09b_卷二下之二#10
【原文】【疏】如《善見》云：「夢通三性。若見禮誦，是善性。乃至見青黃赤白，為無記也。」
【譯文】【疏文】正如《善見律》所說：「夢境通於善、惡、無記三種性質。若夢見禮拜誦經，屬於善性。乃至夢見青黃赤白等色彩，則屬於無記性。」

【543-0006】02_戒疏/09b_卷二下之二#13
【原文】【疏】「如《成實》，夢中成業如蛐蟻等。是以《律》中五種過失，豈非罪也？如《五分》中『不攝而眠，五吉羅也』。此云『不犯』，開於殘耳。」
【譯文】【疏文】答道：「如同《成實論》所說，在夢中造作也會形成業力，例如招感投生為螻蟻等果報。因此《律》中提到五種過失，難道不算是罪嗎？又如《五分律》說『心念不收攝而入睡，結五個輕垢罪』。此處說『不犯』，只是開許免除僧殘重罪而已。」

【543-0007】02_戒疏/09b_卷二下之二#14
【原文】【記】徵釋中。躡上惡性，以難今開。「如」下，釋通。初引《成論》，明結業。「如蛐蟻」者，示感報也。次引二律，明違制。「《律》中」者，如注所引。「過失」即罪，但無罪目，故引《五分》決之。《義鈔》明夢業不感總報，不無別報。
【譯文】【記文】提出詰問並解釋之中。承接上面的惡性夢境，來質疑當前開許不犯之理。「如」字以下，予以解通。首先引用《成實論》，說明夢中結成罪業。「如螻蟻」一句，說明感召果報之相。接著引用兩部律典，說明違背佛制。「《律》中」一詞，正如註文所引。「過失」就是罪過，只是沒有列出具體罪名，所以引用《五分律》來裁斷。《義鈔》（即《四分律拾毘尼義鈔》）闡明夢中業力不會感召總體的引業果報，但並非沒有個別的滿業果報。

【543-0017】02_戒疏/09b_卷二下之二#24
【原文】【疏】佛所以制者。《多論》云：「有六義：一者，出家之人，飄然無所依止，今制此戒，與之作伴，有所依怙故；二者，息諍根本故；三、為息疑嫌心，不但為捉而已，言即作大惡故；四、為斷大惡之源，禁微防著故；五、為護正念，若捉女人，失正念故；六、比丘出家，理應跡絕塵染，標心累外，為世軌則，若捉女人，則喪世人崇敬心故。」
【譯文】【疏文】佛陀制立這條戒的原因。《薩婆多論》說：「有六種深意：第一、出家之人飄然獨立無所依靠，如今制定這條戒，如同與他作伴，讓他有所依憑持守；第二、用來平息爭端糾紛的根源；第三、為了止息他人的懷疑譏嫌，別人不認為只是牽碰而已，會認定即刻就作了大惡行；第四、為了斬斷大惡淫行的源頭，禁止細微動作以防範執著深陷；第五、為了守護內心正念，如果牽碰女人，就會喪失正念；第六、比丘出家，理應斷絕塵俗染著，立心於塵勞物累之外，作為世間的軌範準則，若牽碰女人，就會喪失世人尊崇敬仰之心。」

【543-0018】02_戒疏/09b_卷二下之二#25
【原文】【記】二、摩觸戒，制意中。一、五、六生善意，二、三、四滅惡意。「息諍」者，人多妬色故。「息疑心」者，疑謂作婬，故云「大惡」。「失正念」者，以著欲樂，不能攝故。
【譯文】【記文】第二條摩觸戒的制定本意之中。第一、第五、第六條屬於生起善法的制意，第二、第三、第四條屬於滅除惡法的制意。「平息爭端」，是因為人大多會嫉妒美色。「止息疑心」，懷疑是指進行淫事，所以稱為「大惡」。「喪失正念」，是因為耽著欲樂，無法收攝心神的緣故。
