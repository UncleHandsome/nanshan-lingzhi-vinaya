## 一、比較確定要改的

### 【1550-0002】「行草」不是「鋪草」

* 原文「**行草**中，初科為四」——「行」是**分發**（如「行籌」），此科講「行草（分草）」之法，所以第四科才是「四明**敷布**」。
* 譯文開頭作「在鋪設草座的段落中」，第三又作「依次**鋪**行」，都把「分發」誤成「鋪設」，且與第四科「鋪設排列」重複、層次錯亂。
* 建議：
  * 首句→「在**行草（分發草）** 的段落中，第一科分為四部分……」
  * 第三→「『至』字以下，第三說明**依次分發**。」

### 【1550-0002】「人別一剪」的主語

「人別一剪」是「**每人各一份（一剪即一握）**」，由備草／行草者剪好分給各人，不是「每人各自去剪取」。
建議：「每人各給一剪（一束），用意是讓各人各自敷設，恐怕草鋪得彼此相連成一片。」（「連綿散布在一起」語意也偏含糊。）

### 【1550-0004】「不以𭣋藉」——「藉」不是「借」

「儭藉（襯藉）」＝**襯墊、墊在身下**。譯文「都不得襯墊**鋪借**」的「鋪借」是把「藉」讀成「借」了，屬明顯誤譯。
建議：「褥墊、席子、坐具，**都不能拿來墊在身下**。」

### 【1550-0005】「疏云」逕譯「戒疏說」——出處待核

《資持記》中的「疏」或指《四分律含註戒本疏》（戒疏），或指《隨機羯磨疏》（業疏）。此處引的是**自恣作法的制意**（離座捨慢、布草防損），性質上偏羯磨疏一路。若未核對出處，建議先譯作「**疏中說**」，或查明後再定名，以免誤標書名。（下文「請以疏驗」同樣處理。）

## 二、宜再斟酌（不算硬傷，但影響準確度）

| 段 | 譯文 | 問題與建議 |
|---|---|---|
| 0001 | 「（如此傳欲）」 | 這是譯者補的括號，原文只說「《僧祇》等律並不開」。**不開的究竟是「與欲」還是「欲淨並傳」，須對鈔文確認**；不確定時可先作「都不開許（此法）」或逕譯「都不開許」。 |
| 0001 | 「在**問訊**僧眾是否和合的段落中」 | 「問訊」在佛教語境是合掌鞠躬之禮，易誤會。建議：「在『**問和**』（詢問僧眾是否和合）的段落中」。 |
| 0001 | 「通例的回答／特別的回答」 | 「通答／別答」實指問和時的**答詞**（通用的答法／就自恣各別的答法），可點明為「通用的答詞」「就本法各別的答詞」。 |
| 0001 | 「隨宜主持作法也可以」 | 「隨作亦得」重點在「**隨（誰）作皆得**」，「隨宜」多了「酌情」的意思。建議「隨便由誰來作也可以」。 |
| 0001、0004 | 「**世人**普遍浮濫行事」「**世人**大多錯誤理解」 | 「世」「人」在此指**當時僧界的流俗作法**，不是世俗人。建議改「當時（僧中）行事浮濫」「今人多半錯解」。 |
| 0002 | 「首先說明**草座**的出處」 | 「初示所出」指**行草之法的出處／依據**（故下云「如前所明」）。 |
| 0002 | 「對上座應當跪著奉遞，其餘之人則不需要」 | 主語是**行草者**，易被讀成「其餘的人不必跪」。建議：「（行草的人）到上座前須跪下授草，給其餘的人則不必跪。」 |
| 0002 | 「長**約**二尺**左右**」 | 「約」「左右」重複，留一即可。 |
| 0004 | 「就如同那些**囚徒**一般」 | 原文「罪囚」，補「罪」字更貼（「如同待罪的囚犯」）。 |
| 0004 | 「才從座位站起」 | 可補「（起身互跪）」，與上文「非謂合眾即皆互跪」呼應，讀者才明白錯解在哪。 |
| 0005 | 「五色相間、**爭奇鬥豔**」 | 「間鬪」本義是**五色交錯拼湊（鬥合）**，「爭奇鬥豔」屬引申過頭。建議「五色交雜拼湊」。 |
| 0005 | 「經管事務的僧人／淨人」 | 「管句」即「管勾」（知事、營事僧），「淨人」是為僧執事的未受戒俗役，首見可加短註。 |
| 0006 | 「我**善於**講說」 | 原文「我能講說」，作「我能講經說法」即可，「善於」是加義。 |
| 0006 | 「挺直身子隨手拋擲」 | 可補「（不跪不躬）」，凸顯與「上座跪授」的對比。 |
| 0006 | 兩處「更何況」 | 原文兩個「況」是層層遞進的責語，第二處可改「更有甚者」，語氣較順。 |

## 三、處理得好、可保留的

* 0003 全段基本無誤：「受已前敷，待唱即坐」「辨＝布草備擬坐處」「就草座＝即時離本座」都譯對了；只建議「辨」下補「（即『辦』）」。
* 0004「互跪」譯為「單膝跪地（互跪、胡跪）」**正確**（右膝著地），沒有誤成雙膝長跪，這點很關鍵。
* 0006「揭起坐具，投之於下」譯為「掀起坐具，將草投入坐具之下」正確，與上文「不以襯藉」的批評正好扣合。
* 「夢海」「氷情固執」等比喻保留並稍作疏通，處理得宜。
