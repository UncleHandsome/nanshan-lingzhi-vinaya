# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【13-0001】03_業疏/17a_卷三之六#104
【原文】問：為知足立種？為少欲耶？答：《雜心》云：知足現在境起，故立聖種；少欲未來處起。故知現在不取一錢難，未來捨輪王易也。即《涅槃》云「於未得財不生貪」，故云知足也。
【譯文】問：是為了「知足」而確立聖種，還是為了「少欲」呢？答：《雜阿毗曇心論》說：知足是針對現在當前的境界而生起，所以確立為聖種；少欲則是針對未來之處而生起。由此可知，在當下連一文錢都不妄取是困難的，在未來捨棄轉輪聖王之位反而是容易的。這也就是《大般涅槃經》所說的「對於未得之財不生貪著」，所以稱作知足。

【13-0002】03_業疏/17a_卷三之六#105
【原文】次問少欲、知足二法差別，今此四依為何而立。答中，初正答。知足現境起，對有不貪故；少欲未來起，對無不求故。論云知足立聖種，非少欲故。「故下」，比校二行難易。今依難立，則知行勝。引《涅槃》證，未得財即現在境，但未入手，故云未得。
【譯文】第二個問答是探討少欲與知足兩種法的區別，現今這四依究竟是依哪一種而確立。回答中，首先正面作答。知足是針對現前境界而生起，因為對已有的不生貪著；少欲是針對未來境界而生起，因為對沒有的不去追求。論典說是依知足確立聖種，而不是依少欲之故。自「故下」句起，比較校量兩種修行的難與易。如今依難能之行而確立，就知道其戒行殊勝。引用《大般涅槃經》作證，「未得財」是指眼前的境界，只不過尚未到手，所以稱為未得。

【13-0003】03_業疏/17a_卷三之六#106
【原文】所言體者，就前境論，四塵也；依《毗曇》，八微也。就內心論，無貪善根性；約眷屬論，善五陰性也。
【譯文】所謂其體性：若就所對的境界來論，是色、香、味、觸四塵；依據《阿毗曇》而言，是八微。若就內心而論，屬於無貪善根之體性；若就伴隨而生的眷屬心所來論，屬於善五陰之體性。

【13-0004】03_業疏/17a_卷三之六#107
【原文】出體中，初標。「就下」，釋有二：初約境。色塵該四境，香、味收食、藥，觸塵有通別，通竝觸對，別但收衣、樹。《毗曇》、《有部》、《雜心》、《俱舍》，並明八微，謂四塵各起於極微故有四微，四塵之麤假四微所成，故通名八微。「就下」，次約心者，心即是行。《雜心》云：聖種何等性？答：無貪善根性，約眷屬論善五陰性。
【譯文】在顯明體性的段落中，起初標明。自「就下」句起，解釋分為兩部分：首先依境界而論。色塵涵蓋四種依怙的境界，香塵與味塵收攝飲食和藥品，觸塵則有通與別之分，共通而言皆能觸對，差別而言則僅收攝衣服與樹木。《阿毗曇》、《有部》、《雜心論》、《俱舍論》，都闡明八微之說，也就是色香味觸四塵各自生起於極微所以有四大極微，四塵粗顯之相假借四種微細極微所構成，所以通稱為八微。自「就下」句起，其次依自心而論，自心也就是內在修行。《雜心論》說：聖種是什麼體性？答：是無貪善根的體性，若就隨行眷屬而言，則是善五陰的體性。

【13-0006】03_業疏/17a_卷三之六#109
【原文】衣則無時不須，資身最要，理先明之。既得覆形，內惱須濟，故次乞食。身雖得立，威儀須託，故第三明樹下坐。無病三足，病起不救，則無治能，故立腐藥為第四也。

【13-0008】03_業疏/17a_卷三之六#111

【13-0009】資持記/15d_下三#17
【原文】問：此與呪願何別？答：約事似同，究義須別。呪願則別陳所為，達嚫則通為說法；今或營齋，事須雙用。次科，初引緣起。一令生疑，二令起謗。檀越，亦云檀那，並訛略也；義淨三藏云：具云陀那鉢底，此翻施主。佛下，次引佛制。注文指上，即若為利故施等偈。
【譯文】有人問：這與「祝願」有何差別？回答：就外在事相來看似乎相同，但窮究其內在涵義則必須加以區分。祝願是個別陳述所祈求的功德方向，達嚫則是通貫普遍地為眾人說法；現在若是營辦齋會，兩者必須兼併運用。下一科首先引用制戒的緣起。一是為了避免信眾心生懷疑，二是避免招惹世人毀謗。「檀越」也稱為「檀那」，都是梵文的音訛或省稱；義淨三藏說：完整的梵文是「陀那缽底」，中文翻譯為「施主」。「佛下」接著引用佛陀的制約。注文指涉上文，就是指「若為利故施」等偈頌。

【13-0010】資持記/15d_下三#18
【原文】說時餘聽去者，有緣須往，無緣應住。三中。四益，前二利己，後二利他。四中。契經修多羅，華梵各出。種種義者，令隨機而舉。開撮文者，不必盡誦也。五中，《五分》簡德，初引緣。破戒無行，邪見無慧，根不具無威儀。惡人得勢，謂假此興謗。佛下，立制。
【譯文】說法的時候開許其餘僧眾先行離去，是指有要事者必須前往，若無要事則應留下來聽法。第三段內容中提到四種益處，前兩種利益自己，後兩種利益他人。第四段中，「契經」與「修多羅」，是中文與梵文的並列對稱。「種種義」是指讓說法者能夠隨應聽眾根機而靈活開示。開許「撮要而講」，是指不必將經文從頭到尾完全背誦完畢。第五段中，《五分律》甄別說法者的德行，首先引用緣起。破戒者缺乏德行，邪見者缺乏智慧，諸根殘缺者缺乏威儀。所謂「惡人得勢」，是指惡人會藉此挑起譏嫌與毀謗。「佛下」確立制度規範。

【13-0011】資持記/15d_下三#19
【原文】《伽論》選能。文明誦唄，例準說法，必取堪能。六中，初標律偈。《增一》下，引解。初句即身口二業，次句心業，三是正慧，四即正信。七中，初斥世。若下，次勸說。準《五分》者，即呪願中引云四足汝安隱等。華侈，謂綺飾之詞；侈，尺紙反，奢也。十中。八人即留兩眾，餘開前去，同上有緣。
【譯文】《薩婆多部毘尼摩得勒伽》要求選拔有才能的人。律文表面上雖指誦經唱唄，依此類推到登座說法，也必定要選取具有相應能力的人才。第六段中，首先標出律藏中的偈頌。「《增一》下」引用經義進行解釋。第一句對應身、口二業，第二句對應意業，第三句是指正智慧，第四句就是指堅固的正信。第七段中，首先斥責世俗的弊病。「若下」接著勸勉應當如法說法。準照《五分律》的意旨，就是在祝願中引用「四足汝安隱」等語句。「華侈」是指浮華綺靡的修飾言詞；「侈」的讀音是「尺紙反」，意思是奢侈誇大。第十段中，「八人」是指留下僧、尼兩眾各四人，其餘僧眾則開許先行離去，這與前面有要事離去的情況相同。

【13-0013】01_行事鈔/11b_卷下之三#20
【原文】夫道俗相資，有逾影響；雖形法兩別，而所趣攸同。是故沙門處世，道緣須立；若不假彼外護，則無附法之心；既能受供資身，理須以法濟俗。故得光顯佛日，住持像運，使正法隱而重流，僧徒滅而更立者，其在茲乎！而澆末寡識寔多，明律知時人少。凡厥施化，止出喉心；於彼正教，都無詮述。所以事起非法，言成訛濫；反生不善，何名引接？皆由自無方寸，師心結法。故《善見》云：隨逐惡者，皆由無智；妄解佛教，誹謗如來；作諸惡業，廣生邪見。今以箴誨未聞，顯揚聖旨，初明說法軌儀，受戒方法；次辨生緣奉敬；後明士女入寺正式。
【譯文】出家修道之士與世俗信眾相互依託資助，其緊密關聯甚至超越形影相隨、音響相應；雖然外在形貌與生活軌則兩相分別，但內心所歸趣的解脫正道卻毫無二致。因此沙門出家人生活於世間，修道辦道的助緣必須確立安立；如果不借助世俗居士的外在護持，信眾便難以生起依附正法的虔敬之心；既然出家人接受了信施供養以資益色身，按理就必須以殊勝法雨來周濟救度世俗凡愚。由此才能光大顯揚佛陀的慧日，住持流傳正法與像法的運祚，使沉淪隱沒的正法得以重新流布弘揚，使遭受毀滅的僧團得以再度建立重振，其關鍵就在於此啊！然而在世道澆漓的末法時代，淺陋寡聞無識之徒實在極多，真正通曉戒律、識得時代機宜的人至為稀少。凡有所謂的弘化布教，全只憑自己喉嚨與凡夫私心胡亂發揮；對於佛陀的清淨正教，全然沒有正確認識與闡發宣述。以致引發的事情皆不合佛法，所說的話語皆淪為錯謬濫調；不僅未能使人獲益，反而滋長不善惡念，這又怎能稱得上是接引眾生呢？這全是由於自己胸中本無真才實學與定見，一味剛愎自用、胡亂編造佛法所致。因此《善見律》說：隨逐於惡道惡法之人，皆是由於沒有智慧；盲目妄加曲解佛教，實質上是在誹謗如來；因而造作種種惡業，廣泛滋長邪知邪見。如今為了以戒規箴言教誨那些孤陋寡聞之人，闡明發揚世尊的聖教宗旨，以下首先說明說法的軌度威儀、以及為在家人傳授戒法的方式；其次辨析如何對待生身父母親緣的奉養與禮敬；最後闡明世俗士人與婦女進入寺院的如法正式規則。

【13-0014】資持記/15d_下三#20
【原文】貧道，亦云乏道，皆謙收之稱。今僧受齋，但知飽食接嚫而已。律儀法度，無一可觀。將何發彼善心，消他信施，悲失！次科。引經佛在說法，令後倣之。晡即申時。24 釋導俗篇(下三)釋導俗篇導，謂能化之法；俗，即所化之機。以法接機，必遵正教；備舒軌度，故曰化方。
【譯文】「貧道」也稱為「乏道」，都是出家人自謙退讓的謙稱。現在的僧人應邀受齋，只知道飽餐一頓和收取利養而已。舉手投足間的律儀法則，沒有一樣拿得出手。這將憑藉什麼來啟發信眾的善心、消受他人的信施供養呢？實在太令人悲嘆慚愧了！下一科引用經典說明佛陀在世時的說法儀軌，令後世弟子依循仿效。「晡」就是申時（下午三點至五點）。第二十四篇「釋導俗篇」。「導」是指教化引導的法門；「俗」是指被教化的世俗機根。用法門去接引根機，必須完全遵從佛陀正教；其中詳盡展現了各種軌範度數，所以稱為「化導之方」。

【13-0015】資持記/15d_下三#21
【原文】來意中，初科，前四句通標。影逐形生，響由聲發；形影聲響，不可相離，故取喻焉。形別可解；言法別者，或約戒釋，或約福智二分釋；或可世出世教，制法不同。所趣同者，謂道修解脫因，俗結解脫緣；行分遲速，求脫不殊；或可同歸三寶，共弘正化，而為所趣，頗合下文。
【譯文】在說明「來意」的內容中，第一科的前四句是通盤標明大旨。影子隨著形體而產生，回響由聲音震動而發出；形體與影子、聲音與回響，是絕對無法分離的，所以以此作為比喻。出家與在家在外形上的差別容易理解；至於說「法制差別」，可以從戒律層面來解釋，或是從福德與智慧兩方面來解釋；也可以說是世間法教與出世間法教的制定規則互不相同。所謂「所歸趨的方向相同」，是指僧道修持出離解脫之因，俗人結下解脫之緣；兩者修行步調有快慢之別，但追求解脫的目標沒有不同；又或者可以說雙方同歸三寶、共同弘揚正法，這正是彼此一致的歸宿，相當契合下文的意涵。

【13-0016】資持記/15d_下三#22
【原文】是故下，廣釋，初釋相資，前四句明道假俗資。附，謂親附。後二句明俗須道濟。故下，次釋所趣。初句是佛寶，下二句即法僧二寶；住持一句，通貫上下。僧徒滅者，僧宗行缺，即為滅矣。次科中，初敘妄作。澆末是時，寡識是人。明律謂有解，知時謂有智。
【譯文】「是故下」進行詳細解釋，首先解釋相互資助的關係，前四句說明道法需要依賴世俗的物資供養。「附」是親近依附的意思。後兩句說明世俗大眾需要依靠道法來濟度拯救。「故下」接著解釋最終的歸趣。第一句指佛寶，下兩句指法寶與僧寶；「住持」這一句貫穿上下。所謂「僧徒滅」，是指僧團的正宗行持出現殘缺遺失，這便等同於滅亡了。下一科中，首先敘述末世的妄誕作為。「澆末」是指時代衰微，「寡識」是指人心見識淺薄。通曉戒律是指具有正解，知曉時宜是指具備智慧。

【13-0017】03_業疏/17a_卷三之六#112
【原文】對簡中，初指前。「不下」，簡異。恐謂同彼十二頭陀，故特點之。機教列相，謂因機設教。離坐為五，《鈔》云：於處立五，一、蘭若，二、塜間，三、樹下，四、露坐，五、隨坐。此明多人各行之行，豈可一身而分五處？
【譯文】在對比揀擇的段落中，起初指陳前文。自「不下」句起，揀除差異。這是恐怕有人誤以為與那十二頭陀行相同，所以特別點明。「機教列相」，是指因應根機施設教法。將坐處分為五種，《戒本疏鈔》說：就處所設立五種，第一、阿蘭若，第二、塚間，第三、樹下，第四、露天而坐，第五、隨處坐。這是指由多個人各自實踐不同之行，怎能一個人分身在五處呢？

【13-0019】03_業疏/17a_卷三之六#114
【原文】良由大聖識達根性，稱機授藥。報力增上，制前四法，即有資身長道獲益；中下力劣，事假眾緣，若不開聽著施衣等，則有退道，寧堪涉苦？若唯制者，報劣絕分；若唯開者，上行慢求。由有開遮，三人通備，皆能會正，故曰聖種。
【譯文】這確實是因為大聖佛陀通達了知眾生的根性，稱合其根機而施與藥方。對於果報根力增上者，制定了前述四種嚴格行法，就能資助形體、增長道業並獲得實益；中下根性者根力微劣，行事必須假借眾多外緣，若不開許准聽穿著施主所布施的衣服等，就會退失道心，哪裡堪忍經受苦行？如果一味加以遮制，根器微劣的人就斷絕了修道的份額；如果一味開許，行持上乘之行的人就會懈怠放任並滋生貪求。正因為有開許與遮制，三類根性的人都能被顧及兼備，皆能契會正道，所以稱為聖種。

【13-0020】03_業疏/17a_卷三之六#115
【原文】第五門正法中，初科初敘聖意。「報下」，次明開遮，遮即是制。初敘四制，專被上根；「中下」，次明四開，即攝中、下二根，且舉施衣，餘三類說。「若下」，三明二教相成，不可闕一。備合作被，會正即證果。
【譯文】在第五門說明正法的段落中，初科起初敘述佛聖之意趣。自「報下」句起，接著說明開遮，「遮」也就是「制」。起初敘述四種根本制法，專門普被上等根器；自「中下」句起，接著說明四種開許，也就是統攝中、下兩類根器，暫且以施主衣為例，其餘三種依此類推。自「若下」句起，第三說明制與開這兩類教法相輔相成，不可或缺其一。「備」字應作「被」（覆蓋、加被之意），「會正」就是指證得聖果。
