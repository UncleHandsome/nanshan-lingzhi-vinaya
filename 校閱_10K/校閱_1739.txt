# 校閱材料　第1739檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1739-0001】03_業疏/12b_卷三之一#18
【原文】一善來者，先白衣聖人，佛呼「善來比丘，修行清淨梵行，正說正法」，作是說已，髮落衣變，便得戒也。善比丘者，許其出家，許與大戒。來者，從白衣位來入出家位，從無戒位入具戒位。清淨梵行者，斷一切惡，修一切善也，《四分》云「快修梵行，盡苦源」即此是也。正說正法者，是梵行所依處也
【譯文】第一是善來受戒：原為在家的白衣聖人，佛呼喚道：「善來比丘，修行清淨梵行，如實宣說正法。」佛作此宣說後，其鬚髮自然脫落，俗服化為袈裟，便得戒了。「善比丘」，是准許他出家，准許授與他大戒。「來」，是指從白衣之位來到出家之位，從無戒之位進入具足戒之位。「清淨梵行」，是指斷除一切惡、修持一切善，《四分律》所說的「善巧修行梵行，窮盡苦之根源」即是此意。「正說正法」，則是梵行所依止的教法依處。

【1739-0002】03_業疏/12b_卷三之一#19
【原文】僧善來中，初引論。「善」下，牒釋。斷惡是清淨，修善即梵行。引《四分》證，「快修梵行」證修善，「盡苦源」證斷惡。正說正法，言所說當依正教，行須憑教，故是所依
【譯文】在比丘善來一科中，首先引用論典。自「善」字以下，標舉原文逐詞解釋。斷惡即是清淨，修善即是梵行。引用《四分律》為證：「快修梵行」印證修善，「盡苦源」印證斷惡。所謂正說正法，是說所宣講的應當依循正教，修行必須依憑教法，所以是梵行的所依處。

【1739-0013】03_業疏/12b_卷三之一#30
【原文】獨覺有量、佛無量者，三僧祇劫廣修萬行，於最後生有菩薩戒，悉性得也。苦法忍時，得出家具戒；盡無生智起，一切佛法一時圓滿，三種功德無有邊量也
【譯文】所謂獨覺有量、佛陀無量：在三大阿僧祇劫中廣泛修持萬行，於最後一生中自然具備菩薩戒，全都是自性任運而得的。在證得苦法忍之時，獲得出家具足戒；在盡智與無生智生起之時，一切佛法同一時刻圓滿無餘，這三種功德廣大而沒有邊際限量。

【1739-0014】03_業疏/12b_卷三之一#31
【原文】次二受中。文牒二種，不釋有量，反佛無量自可知故。若據餘部，通歸自然；今取位別心境廣狹，故分二焉。阿僧祇劫翻無數時，而言三者，且約釋迦修菩薩道時以論分齊：從古釋迦至尸棄佛，值七萬五千佛，名初僧祇；次從尸棄至然燈佛，值七萬六千佛，名第二僧祇；又從然燈至毗婆尸佛，值七萬七千佛，名三僧祇。若望聲聞，當內凡位。萬行者，萬是數之通名，行實無量，不必一萬。最後生，謂王宮所生也。菩薩戒者，謂久修菩薩行，習性自然，遠惡住善，故云性得。若爾，前云小戒為大方便，今何倒耶？答：此菩薩戒亦即小乘義說為戒，非從他受，不同《梵網》善戒受者方獲。苦法忍時，即證見道無漏聖慧斷惑之時，準此初果即得具戒。「盡無生智起」句絕，謂盡智與無生智，二智發起，即證無學道時。謂證滅諦，結惑斷盡，故名盡智；從盡智後，無漏智起，一切結惑無再生理，名無生智。三種功德者：一菩薩戒、二出家具戒、三佛法圓滿。前二是因，後一是果，皆徧生境，故無邊量。然此且據小教明佛；若約大乘，出生成道無非示現，隨緣垂應，非實爾也
【譯文】在其次兩種受戒中。疏文標舉這兩種，未解釋「有量」，是因為相對照佛陀的「無量」，獨覺的有量自然即可反推明了。若依其餘律部，都總括歸為「自然得戒」；此處則取名位差異與心境的廣狹不同，所以分為兩種。阿僧祇劫翻譯為「無數時」，而說「三」者，且依釋迦牟尼佛修行菩薩道時來界定階段：從古釋迦佛至尸棄佛，值遇七萬五千尊佛，稱為第一僧祇；其次從尸棄佛至燃燈佛，值遇七萬六千尊佛，稱為第二僧祇；又從燃燈佛至毘婆尸佛，值遇七萬七千尊佛，稱為第三僧祇。若對望聲聞位次，相當於內凡位。所謂萬行，「萬」是數量的通稱，行持實屬無量，未必剛好是一萬。最後生，是指在王宮中所受生的一世。菩薩戒，是指久遠修習菩薩行，習性已成自然，遠離諸惡而安住善法，所以說是自性本得。若是如此，前文說小乘戒是大乘戒的前行方便，如今為何顛倒過來？答：此處所謂的菩薩戒，也是依小乘義理假稱為戒，並非從師受得，不同於《梵網經》或《菩薩善戒經》那樣必須受戒方能獲取。苦法忍時，即是證入見道位、以無漏聖慧斷除疑惑之時，照此看來證初果時即獲得具足戒。「盡無生智起」此句斷句，是指盡智與無生智這二種智慧生起之時，即是證得無學道之位。意謂證得滅諦，結縛疑惑斷盡，所以稱為盡智；在盡智之後，無漏聖智現起，一切惑業絕無再生之理，稱為無生智。三種功德是指：第一菩薩戒、第二出家具足戒、第三佛法圓滿。前二者是因，後一者是果，皆遍及一切眾生之境，所以沒有邊際限量。然而這只是且就小乘教理來說明佛陀；若依大乘教理，降生王宮、出家成道無非皆是方便示現，隨眾生機緣而垂跡應化，並非實有如此歷程。
