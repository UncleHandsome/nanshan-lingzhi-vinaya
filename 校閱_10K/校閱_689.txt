# 校閱材料　第689檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【689-0001】02_戒疏/15a_卷三下之三#47
【原文】【記】第三。體如中，木鉢同外道，寶鉢同俗流，石鉢僭如來，皆不應法。色如中。「油」字去呼，謂以桐荏油塗已燒之。「掍」合作璭，謂揩磨出光也。量如中。「諸部言多」，謂出量不一而無分齊，唯《母論》同今《四分》，故引示之。「三斗」、「斗半」，並準姬周為定。五中，「披擯」即法隔，「顛狂、心亂」，即病緣。準例，長衣亦應同此。
【譯文】【記文】第三點。在質料如法中，使用木鉢等同於外道，使用金銀寶鉢等同於世俗凡流，使用石鉢則是僭越了如來的器皿，全都與法度不合。在顏色如法中，「油」字讀作去聲，是指塗上桐油或荏油之後拿去火燒。「掍」字應當作「璭」，是指擦拭研磨出光澤。在容量如法中，「各部派說法眾多」，是指提出的容量標準不一且缺乏統一尺度，唯獨《毘尼母論》與現今這部《四分律》相同，所以引來作為說明。「三斗」與「一斗半」，都是以姬周時期的斗秤度量為準定奪。在第五點中，「被擯除」就是指僧法上的隔絕隔離，「癲狂、心亂」則屬於疾病事故。按照這條規則推衍，長衣戒也應當適用同樣的規定。

【689-0002】02_戒疏/15a_卷三下之三#48
【原文】【記】六中。《善見》約直明犯。初據未還，由未屬已，縱語非長。「若」下，次據已還，主報即犯，餘報不犯，未委實故。《僧祇》，「知友邊」者，即淨主也。「十日一易」，此據不畜長人，一受一捨，更互加用。今引此文，但取不得過十日耳。
【譯文】【記文】在第六點中。《善見律》是以價金是否付清來界定是否犯戒。一開始是依據未付清而言，因為物品尚未正式屬於自己，縱使主人開口應允也不算自己的長鉢。「如果」以下，接著是依據已經付清的情況而言，主人親自通知就開始算期限犯戒，若是其他人通知則不算犯戒，因為情況尚未證實明確。《僧祇律》中說「在知心朋友處」，就是指說淨的對象。「十天輪換一次」，這是針對不蓄留多餘物品的人而言，一個受持、一個捨去，互相輪流替代使用。現在引用這段文字，只是取其不得超過十天的規定罷了。

【689-0005】02_戒疏/15a_卷三下之三#51

【譯文】【疏文】又問：「衣服如果過長或過短，都還可以折衷截補而受持，鉢為什麼反而與此不同呢？」

【689-0006】02_戒疏/15a_卷三下之三#52
【原文】【疏】《論》答云：「衣可截續，是以成受。鉢無此義，成量成持。」
【譯文】【疏文】論典解答說：「衣服可以截短或拼接，所以能作成合乎標準的受持物。鉢則沒有這種改製的可能，唯有本身容量符合法度才能成立受持。」

【689-0007】02_戒疏/15a_卷三下之三#53
【原文】【記】次料簡中。《多論》，初問答中，衣染必成色，鉢熏不必成。次問答中，衣過可截，衣減可續，鉢則不爾，故成不成別。
【譯文】【記文】在接下來的辨析討論中。《薩婆多論》的第一個問答中，衣服染色一定能成功變色，鉢熏烤卻不一定能成功保持完好。第二個問答中，衣服過大可以裁剪，衣服過小可以拼接，鉢卻無法這樣做，所以兩者能否成立受持的規定有所不同。

【689-0008】02_戒疏/15a_卷三下之三#54

【譯文】【註文】佛陀在舍衛國時。六群比丘蓄留了許多的鉢，品質差的就扔在一旁，經常到處尋覓好的鉢，蓄積的數量於是越來越多。居士前來精舍遊覽觀賞，便譏嫌說這跟陶工的瓦器店舖沒有什麼兩樣。比丘們檢舉這項過錯，佛陀便嚴厲訶責，進而制定了這條戒律。

【689-0023】02_戒疏/15a_卷三下之三#69
【原文】【疏】答：「衣有三種不同，對多以明長。鉢則制一受持，餘則是長，非惑故不明本制。」

【689-0024】02_戒疏/15a_卷三下之三#70
【原文】【記】戒本，第二。問中，衣鉢俱長，開制合同，故發諸問以彰兩異。答中，「對多明」者，以竟即是足，多可論足，一不須論。「惑」，猶亂也。
【譯文】【記文】戒本正文的第二句。在提問中，衣和鉢同樣都有限定件數與多餘的情況，其開許與制戒的條例應當相通，所以提出種種問題來凸顯兩者的差異。在回答中，「相對於多數才能辨明」，是因為戒文中的「竟」字就是「足」（齊備）的意思，件數多才可以討論是否充足，而鉢只有一個，完全不需要多作討論。「惑」的意思就如同混亂。
