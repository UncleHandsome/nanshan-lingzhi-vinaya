# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【697-0001】01_行事鈔/00_卷首#62
【原文】第五文義決通意。夫理本絕名，故立名標其宗極；名隨事顯，故對事而備斯文。然考斯律藏，言事並周，但為年代渺邈，聲彩靡追；法為時移，事多殘缺；加以五師捃拾，情見不同；重由翻譯失旨，妄生構立；又為抄寫錯漏，相承傳濫。所以至於尋究，紛慮良多。今總會之，以通其大見。
【譯文】第五，文義決斷貫通的用意。理本來是絕於名言的，所以安立名稱來標示其宗旨極致；名稱隨事相而顯現，所以對事相而具備這些文字。然而考核這律藏，言語與事相都周備，只因為年代久遠渺茫，音聲光彩已無法追尋；法隨時代而轉移，事相多有殘缺；加上五師收集拾取，情見各有不同；更由於翻譯失去原旨，妄自生起構立；又因為抄寫錯誤脫漏，師資相承而傳成濫誤。所以到了尋求探究的時候，紛雜的疑慮很多。現在總會貫通它們，以通達其大體見解。

【697-0002】01_行事鈔/00_卷首#63
【原文】若文義俱闕，則可舉一以例諸；或就理有，而成前事；或在文雖具，而於義有闕，便以義定之。故論言以理為正故也！或義雖必立，當部無文，則統關諸部，以息餘謗。
【譯文】如果文與義都欠缺，就可以舉一例來類推其餘；或者就義理上應有的，來成立前面所說的事；或者文字雖然具足，但在義理上有欠缺，便以義理來判定。所以論中說「以理為正」的緣故！或者義理雖然一定應成立，而本部沒有文字，就統攝關涉諸部，以止息其餘的謗議。

【697-0003】01_行事鈔/00_卷首#64
【原文】然文義決通，誠難廢立；自非深明律相，善達開遮；不然，便有累於自心，固無益於他境。故律云：文義俱同、文同義異、文異義同、文義俱異，具舒進止，不勞敘釋。
【譯文】然而文義的決斷貫通，實在難以取捨建立；如果不是深深明了律相、善於通達開與遮，不然的話，就會有累於自己的心，固然也無益於他人的境界。所以律中說：文義俱同、文同義異、文異義同、文義俱異，都詳細舒展其進止取捨，不必勞煩敘述解釋。

【697-0004】01_行事鈔/00_卷首#65
【原文】然決判是非者，必總通律藏之旨，并識隨經之文；如上六師所明，乃可究斯教迹。故《十誦》云：比丘有三事決定知毘尼相：一本起，二結戒，三隨結。應思惟觀察二部戒律，并及義解、毘尼、增一，開遮輕重。如五大色，是不淨，遮；非色，淨，不遮。如是等，籌量本末已用也！《明了論》亦云：比丘能知五相，名解毘尼，不看他面。文略同上，廣如彼說。
【譯文】然而要決斷判定是非的人，一定要總體通達律藏的宗旨，並且認識隨順經文的文字；像上面六類律師所闡明的，才可以探究這教法的蹤跡。所以《十誦律》說：比丘有三件事能決定知道毘尼的相狀：一是本起（制戒的起因），二是結戒（制立戒條），三是隨結（隨事增結）。應當思惟觀察僧、尼二部的戒律，以及義解、毘尼、增一，開遮輕重。譬如五大色是不淨的，就遮止；非色是清淨的，就不遮。像這樣等，籌量其本末之後再運用！《明了論》也說：比丘能知道五相，名為解毘尼，不必看他人臉色。文字大略同上，詳細如那部論所說。

【697-0005】01_行事鈔/00_卷首#66
【原文】第六教所詮意。詮教之文，文雖浩博，撮其大趣，止明持犯。然持犯之境，境通內外；內謂行心之結業，外謂情事之順違。但令教行相循，始終無犯，則為持也。若生來不學，於法無聞，修造善惡，義兼福罰。今欲科罪，但使與教相應，不問事情虛實，並名犯也。此通名持犯也！
【譯文】第六，教法所詮釋的用意。詮釋教法的文字，文字雖然浩瀚廣博，撮取其主要旨趣，只在於說明持與犯。然而持犯的境界，境界通於內外；內是指行心所結成的業，外是指情事上的順與違。只要使教法與行持互相依循，從始至終沒有違犯，那就是「持」。如果生來不學，對法沒有聽聞，所修造的善惡，其義兼有福與罰。現在要判科其罪，只要與教法相應，不問事情的虛實，都名為「犯」。這是通稱的持犯！

【697-0006】01_行事鈔/00_卷首#67

【譯文】如果是結成篇聚的正罪，窮究各種治罰，一定要約束其方便（前方便），總攬成為業果；使衡量的依據能考核其實情，輕重都能符合義理與教法；那麼判斷就清楚明白，還有什麼雜亂氾濫呢。這是別稱的持犯！

【697-0009】01_行事鈔/00_卷首#70
【原文】二謂行教。唯局於內眾。定其取捨，立其網致，顯於持犯，決於疑滯；指事曲宣，文無重覽之義；結罪明斷，事有再科之愆。
【譯文】第二是行教。只局限於內眾（出家眾）。確定其取捨，建立其綱要，顯示持犯，決斷疑滯；指對事相而委曲宣說，文字沒有需要反覆再看才能明白的情形；結罪判決明確，事有再科（重複判罪）便有過失。

【697-0010】01_行事鈔/00_卷首#71
【原文】然則，二教循環，非無相濫；舉宗以判，理自彰矣。謂內心違順，託理為宗，則準化教；外用施為，必護身口，便依行教。然犯化教者，但受業道一報；違行教者，重增聖制之罪。故經云：受戒者罪重，不受者罪輕，文廣自明。所以更分者，恐迷二教之宗體，妄述業行之是非；故立一門，永用蠲別。
【譯文】然而這兩種教法循環相關，並非沒有互相混濫；舉出宗旨來判定，道理自然彰顯。就是說：內心的違與順，寄託於義理為宗，就依準化教；外用的施為，必須守護身口，便依行教。然而違犯化教的人，只承受業道的一種果報；違犯行教的人，更加上聖人所制之罪。所以經中說：受戒的人罪重，不受戒的人罪輕，文字廣說自然明白。之所以再加以分別，是恐怕人迷惑於二教的宗體，妄自敘述業行的是非；所以建立這一門，永遠用來區別。

【697-0016】資持記/10a_中三下#51
【原文】文取解知，必具三種，不具不成。《多論》。人中不通非畜，謂多人處；反知無人方開異類。次科，《五分》。既無淨人而令安米者，或是年小，或可暫倩。文中但開自煮惡觸二吉羅耳。《僧祇》。牛上，亦據無人，開從畜受。但授受非儀，須加口法。引即牽也。《十誦》。
【譯文】文中要求能理解通曉，必須具備這三種條件，如果不具備就不能成立。《多論》說。人中不通於非人和畜生，是指在人多的地方；反過來可知在沒有人的地方，才開許從異類眾生處受食。下一個段落，《五分律》。既然沒有淨人而讓年幼者放米，或許是因為年紀小，或許是可以暫時雇請。文中只開許自己煮食和惡觸碰兩種突吉羅罪罷了。《僧祇律》。在牛背上，也是依據無人的情況，開許從畜生身上受食。但授受不合威儀，必須附加口頭法事。「引」就是牽引的意思。《十誦律》。

【697-0017】資持記/10b_中三下#56
【原文】自餘隨身道具，例傳自藏。五十九。〔佛在舍衛，六群真施親厚比丘；後不語取著，因制。〕釋疑中。犯不犯者，僧尼同重；下三眾並輕，不犯正罪。辨相具解，指律廣解。疏云：為明五眾俱有犯相；雖輕重異，淨施義同，故通列名；至於淨法，自從律法。〔謂真實淨主各對本眾，不得互為。〕簡異中。
【譯文】至於其餘隨身所用的修道道具，則全都依例准許私自妥善收藏。第五十九條戒。〔佛陀在舍衛國時，六群比丘把衣物真正布施給了平素親厚友善的比丘；事後卻未經告知便逕自拿去穿著，佛陀因而制定此戒。〕在釋疑的科判中。針對究竟犯戒還是不犯戒的界限，比丘與比丘尼若是違犯同樣結重罪；下方的沙彌、沙彌尼、式叉摩那三眾則全都結輕罪，不構成根本的正罪。詳細辨識其行相的內容，指引參閱律典中的詳細解釋。《戒疏》說道：這是為了明示出家五眾弟子全都存在著犯戒的行相；雖然罪責有輕重的差別，但「淨施」以防私蓄的法理意涵是完全相同的，所以通盤列出五眾的名位；至於具體的轉手作淨之法，自當依照各眾自部的律法規定來遵行。〔也就是說真實的受淨施之主，必須各自面對本眾同法之人，不得跨眾相互替代。〕在簡別異同中。

【697-0018】資持記/10b_中三下#57
【原文】淨施有二，真實淨者，物過主邊，故有輒取；展轉不爾，取用通得。六十。〔佛在舍衛，六群著白色衣行，俗譏因制。〕名中。且約初作不染為言。不妨體故，亦入犯科；下引《十誦》，於義可見。釋第三中，初科，《四分》，初定色相。彼下辨犯，分二，初明不染。若重下，次明不作淨，上列餘衣。
【譯文】淨施有兩種，真實淨施者，物品所有權已移交對方施主，所以若未經告知而私自拿取便會犯戒；展轉淨施則不如此，取用在法理上全都可以。第六十條戒。〔佛陀在舍衛國時，六群比丘穿著雪白色的衣服行走，世俗之人譏嫌，佛陀因而制定此戒。〕戒名中。暫且是依據最初裁製新衣時未加染色破色來說。因為不損壞衣服的質地本體，所以也歸入犯戒的科條之中；下文引用《十誦律》，從法義上便能明瞭。在解釋第三項中，第一科《四分律》開頭先確定合律的三種壞色相狀。彼處以下辨析犯戒的行相，分為兩部分，首先說明全然不予染色的過失。隨後說明如果不作淨染壞的過失，上方列出了三衣以外的其餘衣服。

【697-0019】資持記/10b_中三下#58
【原文】重謂被褥，輕即助身。下示非衣。其相可解。若未下，明寄俗舍。注有二意，初至染壞，明作淨之法必須通染。言成色者，即已染也。物貼點著，此二種淨，隨一即成。非下，例通餘衣。若下，準文決犯。以前文但云得衣不壞者墮，則知通該一切。若據列緣，唯約三衣；
【譯文】重謂被褥毯子之類，輕即貼身助身衣物。下文指示了何者非屬衣服。其外觀相狀容易理解。隨後說明暫時寄放在世俗人家中的情形。附註中含有兩層深意，第一層到「染壞」為止，說明作淨壞色之法必須通體予以染色。所謂「成色」，就是指全衣已經染成如法之色。用小塊異色布料貼補，或是用異色汁液點染作記號，這兩種作淨之法，只要隨意採用一種便算做成。隨後將此法依例推廣通用到其餘各類衣物。隨後依照律文決斷犯戒情節。因為前文只是說得到新衣不染壞顏色者結墮罪，由此可知通盤涵蓋一切衣服。若據犯緣所列，卻唯獨針對三衣；

【697-0020】資持記/10b_中三下#59
【原文】或可彼從緣制，或是此就急論，思之。然餘衣染壞，但據助身可染者為言；故《戒疏》云：非謂巾屣以三色染更成驚俗，可笑之甚。〔故知巾襪但須點淨。〕次科。《五分》二意：一異外道，二異俗，三防失。三種記者，即三色也。三中，《多論》分四，初明本染非法。
【譯文】或者這條戒是順應起戒的特定因緣而制定，又或者此處是純粹針對三衣這項緊要之事來論述，後學應當深入深思。然而其餘衣物的染色破壞，也只是針對那些助身且可染色的布料而言；所以《戒疏》說道：絕非指連面巾與鞋履都要用三種壞色去染色，那樣做反而更加驚駭世俗，可笑到了極點。〔由此可知面巾、襪子這類物件，只需要在角落點染作淨即可。〕次一科。《五分律》說明制戒有兩種用意：一是為了有別於外道，二是為了有別於世俗，三是為了防備失脫混淆。所謂「三種記識」，就是指青、黑、木蘭這三種顏色。第三項中，《多論》分為四個部分，開頭先說明最初染色的染料若不如法便屬非法。
