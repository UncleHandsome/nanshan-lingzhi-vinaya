# 校閱材料　第550檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【550-0001】04_比丘尼鈔/06a_卷下之下#36
【原文】第七雜法者此別對首法若能所滿四人已下但使無僧不問作法自然界中並成對首若能所滿五人已上作法界內及戒場上不合對首應作眾法捨之縱自然界及白衣舍亦不合對首捨以正懺悔時尼唯是所懺不落僧攝餘尼展轉懺竟還墮僧數又餘懺尼雖未捨懺以體是大尼豈非僧攝既成僧故何得對首捨懺若知不易眾法復難欲得受多尼捨懺之時令諸懺悔尼總向大界內坐懺主尼一一喚來入自然界內如是展轉作法乃受無量皆成如法不爾之時徒自費功財還不淨虗為獨善數見僧尼共行此法別疏記之。
【譯文】第七項是雜項規定：此處特別說明對首懺法。如果能懺與受懺者加起來在四人以下，只要沒有比丘僧在場，無論是在結界作法之處或自然界中，都能成就對首懺法；如果人數達到五人以上，在作法界內以及戒場上，就不合乎對首懺的規定，應當作僧眾法來捨罪。縱然是在自然界以及在家人房屋中，也不合乎對首捨法；因為正懺悔的時候，受懺比丘尼只是受懺對象而不落入羯磨僧數，其餘比丘尼輾轉懺悔完畢又算入僧數之中。再者，其餘求懺比丘尼雖然尚未捨罪懺悔，但本質上是具足戒尼，豈能不算在僧數之內？既然已經構成僧團，如何能進行對首捨懺呢？如果深知這不容易，而僧眾大眾法又很繁複難行，想要接受多位比丘尼捨懺的時候，可讓各位要懺悔的比丘尼全都坐在大界內，懺悔主比丘尼將她們一一叫出進入自然界內，如此輾轉作法，即便接受無量之人也全都合乎戒法；不這樣做的話，徒然白費工夫，財物依舊不合淨法，成了虛妄的自求清淨。我屢次見到僧尼共同誤行此法，因此特別記錄在此予以辨正。

【550-0025】04_比丘尼鈔/06a_卷下之下#60
【原文】第三供侍者僧祇云若病人衣鉢外有醫藥直者取之供給無者眾僧應與若僧無者彼有貴價衣鉢當貿賤者受持餘者供給若病人惜者應白僧云此病人不知無常慳惜衣鉢不肯貨易白僧已輭語說使得開解然後為貨易若復無者應外求覓與之若僧中取好食與看病人不得愛惜自業而不瞻視五分云無淨人處聽比丘自洗燒器看水令淨人淘米著中比丘然火使熟更從淨人受取持與病人不犯五分云每僧行粥時應問別有病人粥否若無應先與病人然後行與僧十誦云當隨病所須問病因緣覓師求藥日別到僧厨問有病人食否若無取僧所供給庫中物無者當為外求應從善好名聞福德比丘索又病人得藥差者但是僧中不淨殘宿惡捉不受內宿並得服之善生云瞻病人不應生厭若自無物出外求之不得者貸三寶物差已依法十倍償之五百問事云看病人將病人物為病人所須供給不問病者或問起嫌並不得用若已取應償不還者犯重比丘病困不得闕衣鉢而作功德若不即有故弊衣鉢受持者犯墮此律當問病人持何等衣彼病人又受不好衣鉢及送與他恐看病人得佛言不應爾。
【譯文】第三項照料服侍：《僧祇律》說：如果病僧在衣鉢之外還有醫藥經費，就取這筆錢供給開銷；如果沒有，全體僧團應當資助給予；如果僧團也缺乏物資，而該病僧有高價的衣鉢，應當拿去折換成平價廉價的衣鉢留著受持，其餘剩餘的錢財用來供給醫療開銷。如果病人吝惜不捨，應當向僧團稟白說：「這位病人不明白無常道理，慳吝愛惜衣鉢而不肯變賣交易。」向僧團報告之後，再以柔和的話語勸導開示，使他心開意解，然後替他變賣交易；如果病僧確實身無長物，僧團應當向外求取募化以給予他。如果僧團中取了美味飲食給予照護之人，看護者不得顧惜自己的修持課業而不去照料病人。《五分律》說：在沒有清淨傭人的處所，允許比丘自己清洗生火器具，檢查洗米水讓淨人掏米放入鍋中，比丘生火煮熟，再由淨人手中受取，拿去給予病人，這不犯戒。《五分律》又說：每次僧團分發熱粥時，應當先問有沒有其他病人的專用粥？如果沒有，應當先盛給病人，然後再分發給僧眾。《十誦律》說：應當隨病人所需，詢問得病因由，尋找良醫求討藥物；每天必須到僧團大廚房詢問有沒有病人專用的飲食，若沒有，就領取僧團供給的庫存物資；若庫房沒有，應當替他向外求討，可以向品德完好、有名望有福德的比丘索求。另外，如果病僧得到某種藥便能痊癒，那麼凡是僧團中屬於不淨、隔夜殘宿、惡捉觸、未經授受、存放在宿處內的藥食，都允許給其服用。《善生經》說：照料病患的人不應生起厭煩懈怠之心，如果自己沒有物資，就外出求索；求索不得時，可以借貸三寶物資使用，病癒之後依戒法十倍償還。《五百問事》說：看病的人拿病人的物品作為病人所需開銷供給，如果沒有事先過問病人，或者過問之後病人生起嫌隙，一律不得擅自動用；如果已經取用，事後應當償還，若不償還者犯重罪。比丘病危之際，不得為了做功德而短缺了隨身必備的衣鉢；如果手邊沒有立刻可替補的舊衣鉢來受持，便將原有的給予他人，犯波逸提墮罪。本律中提到，應當問病人要受持何種衣物；如果那病人又接受不好的衣鉢，並把原物送給別人，唯恐看病的人貪得此物，佛陀說不應當這麼做。
