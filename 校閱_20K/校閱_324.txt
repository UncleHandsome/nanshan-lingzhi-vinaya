# 校閱材料　第324檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【324-0001】02_戒疏/14b_卷三下之二#133
【原文】【記】第三句，牒釋中。初定名體。「如上」，即列緣中。「如」下，引緣證。既在外披，顯是袈裟。俗中釋名，上者曰「衣」，下者曰「裳」。今是上者，故非下裳。裳猶非犯，褥非著用，故云「何況」。
【譯文】【記文】在解釋第三句的文義中。首先考定名稱與物質形體。「如同上面」，就是指前面所列舉的因緣之中。「正如」以下，引用緣起故事作為鐵證。既然是用來披覆在身體外面，顯然就是指袈裟。世俗在解釋名稱時，穿在上面的叫做「衣」，穿在下面的叫做「裳」。現在既然是穿在上面的，自然就不是下身的裙裳。連裙裳尚且都不構成犯本戒，褥子根本不是穿在人身上的，所以才說「何況」。

【324-0002】02_戒疏/14b_卷三下之二#134
【原文】【疏】昔以此等為「五敷具」，故制戒云：「此毛貴物，無宜下用，作無用之費，此言是也。」今所不同。竝上義中時為敷具者，欲改恐迷，且存古耳。讀者知非，則無大過。
【譯文】【疏文】過去的學者把這些戒條全都看作是「五種鋪設在地的敷具」，所以古人解釋制戒意旨時說：「這種羊毛極為珍貴，不適合拿來作為下等鋪地的用途，是徒作無益的浪費。」這話固然是對的，但我現在的看法有所不同（認為臥具指法衣而非敷具）。至於前面義理門中偶爾還會寫到「敷具」等詞，是因為如果要大幅修改恐怕會讓讀者產生迷惘混亂，所以暫且保留了古人的習慣稱呼。讀者只要心裡明辨是非，就不會有太大的過失了。

【324-0003】02_戒疏/14b_卷三下之二#135
【原文】【記】點古中。初引示。四臥具並不揲坐具，總號「五敷」。「制戒」，即古疏中敘制戒之意。彼謂被褥，故云「下用」。「今」下，顯非。初句標簡。「然」下，點前文。準古本，多上「竝」字，或是「然」字，傳文之誤。謂前義門，多云「五敷」，乃是循古，示須知之。
【譯文】【記文】在評核古人註解之中。首先引述古人的說法。四條臥具戒連同不揲坐具戒，過去總稱為「五敷」。「制戒」，是指古老義疏中敘述佛陀制戒的初衷。古德以為這些都是指被褥墊被，所以說是「身下鋪墊之用」。「但我現在」以下，顯發古人的錯誤。第一句標明簡別。「然而」以下，提點前面的經文。按照古本，多半作「竝」字，或者原本是個「然」字，屬於傳抄時的文字訛誤。這是說前面的通論義理門中，往往還保留著「五敷」的說法，那只是順應古老習慣，大家應當要有所體會識別。

【324-0006】02_戒疏/14b_卷三下之二#138
【原文】【疏】注釋云「若得已成」者，是開文也。不同前戒，若得已成，即加斬壞，此戒是開，故無文斬。又云「若割截壞」者，謂本作時，擬後壞故；本不壞心，作成即犯。下諸戒中，細薄重披，例同兩解。
【譯文】【疏文】注釋中說「如果得到別人已經做好的成品」，這是屬於開許不犯的條文。這與前面一條蠶綿戒不同，那條戒如果得到做好的成品，就必須加以砍碎毀損；這條戒則是開許受用，所以律文中根本沒有砍碎毀壞的字眼。注釋又說「如果剪裁割截毀壞」，是指一開始製作的時候，心裡就預先打算事後要把它裁剪割破；若是原本沒有剪破割毀的打算，一旦全件做成便立即犯戒。在後面的各條戒中，針對細薄雙層等開許，也都比照這兩種心理狀態來作同樣的雙重解析。

【譯文】【記文】在解釋律注之中。首先解釋「成品受用」。「注釋又說」以下，接著解釋「割截毀壞」。這是從製作當下究竟「有沒有打算割毀」的心念，來辨別犯戒與開許這兩種不同的行相。「在後面的各條戒」以下，是預先提點後面的戒條。

【324-0010】02_戒疏/14b_卷三下之二#142
【原文】【疏】制意同前。《五分》、《十誦》中，以見前戒不得黑故，便以小小白尨參之，遂制三毛參作。
【譯文】【疏文】制戒的用意與前面相同。《五分律》、《十誦律》中記載：因為眾人見到前一條戒不許純用黑毛，便用少許白毛、雜色毛摻雜進去，於是佛陀制立三種毛相參而作的規定。

【324-0011】02_戒疏/14b_卷三下之二#143
【原文】【記】十三，制意中。初句指同。體雖非貴，長貪營造，妨業不殊，故須制約。「五」下，示異。本宗緣於純白，乃制相參，二律因彼微參，故制分齊。「小小白尨」，謂不多也。「尨」，莫江反，若依字書，則犬多毛。有云合作「牻」，訓雜者，此乃雜色牛名，非訓雜也。今準注中，頭脚等處即是「麤毛」，倉黃色者謂之「尨毛」。
【譯文】【記文】第十三條，在制戒意旨中。第一句是指涉意旨相同。白毛材質雖然沒有純黑毛那麼昂貴，但貪心滋長、營造營求、妨害修道本業的情形是完全相同的，所以必須加以約束限制。「《五分》」以下，展示各部律典的差別。本宗《四分律》是針對比丘使用「純白毛」而引發譏嫌，才制定相雜配比的限制；《五分》、《十誦》二部律典則是因為比丘稍微摻入一點點雜毛來規避前戒，所以才制定嚴格的比例分寸。「微量的一點點白毛與雜毛」，是指數量極少。「尨」字讀作「莫江反」，如果依照字書字典的解釋，是指長著很多長毛的狗。有人說這個字應當寫成「牻」，解釋為雜色，但那其實是雜色牛的名稱，並不是解釋為顏色龐雜。現在依照律注中的定義，羊頭部、腳部等處的粗糙毛髮就是「粗毛」，顏色呈灰黃蒼黃色的就稱為「尨毛（雜色毛）」。
