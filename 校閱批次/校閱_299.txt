# 校閱材料　第299檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【299-0001】02_戒疏/19a_卷四下之一#109
【原文】【疏】答：「僧中諫者，眾命是重，違情過深，隨諫結犯。此一人諫，反上可知。要待成結，若不作事，便成受勸。故不同彼。」
【譯文】【疏文】回答：「在僧眾大會中所作的勸諫，僧團的公意法命最為隆重，違抗公眾意願的過失極其嚴重，所以勸諫儀式一結束就結犯重罪。而這只是一介個人的私下勸諫，情勢與前者相反，這很清楚。所以必須等待惡事辦成才結定墮罪，如果在勸阻後最終沒有去做這件事，便算是接受了勸導。所以處理方式與僧團羯磨不同。」

【299-0002】02_戒疏/19a_卷四下之一#110
【原文】【記】次問中。對前僧諫結犯兩異，故問通之。答中，初示僧諫即犯；「此」下，二、明別諫待成。
【譯文】【記文】第二個提問中。針對違抗僧團大眾諫言與個人諫言在結罪時機上的兩相差異，因而發問求通。回答中，起初指出僧團勸諫告竣便立即結罪；從「而這只是」以下，第二步說明個人勸諫必須等待惡事成就方能結定。

【299-0003】02_戒疏/19a_卷四下之一#111
【原文】【疏】「若爾，下勸學中亦是一人，無僧法違，何為諫竟即犯者？」
【譯文】【疏文】「如果這樣的話，後文規勸學戒那一條同樣也只是一個人出面勸勉，並沒有違抗僧團如法羯磨的程序，為什麼卻是勸諫完畢便立即結罪呢？」

【299-0004】02_戒疏/19a_卷四下之一#112
【原文】【疏】答：「彼諫止犯，先是不學之人發言拒諫，道已不學即是止犯，違諫義成。此諫作犯，雖發言拒諫未是作犯，違諫未成，要待作事，違諫義足。故不相並也。」
【譯文】【疏文】回答：「那一條是規勸他停止『止犯』的過失，原本就是不學戒的人，開口出言抗拒規諫，聲稱自己就是不學，這本身當下就是『止犯』，違逆勸諫的罪名已經完全成立。而本條戒是規勸他不可去『作犯』，雖然開口拒絕勸諫，但惡事尚未真正造作出來，違抗勸諫以致成罪的行相還沒完足，必須等到把惡事做成了，抗拒勸勉的罪責才算充分完備。因此兩者不能相提並論。」

【299-0005】02_戒疏/19a_卷四下之一#113
【原文】【記】轉難中。由下勸學同是別人，諫竟即犯，則違上義。答中，諫止則因止故勸，故止在先。諫作則欲作便可，故作在後。是以諫止即結，諫作待成。
【譯文】【記文】在轉折問難之中。由於下文勸學戒同樣是面對單獨一人，勸諫完畢就立即結罪，這就違背了上面的說法。在答覆中：若是勸諫『止犯（不肯學戒）』，是因為對方已經有了消極不學的行為而後才加勸勉，所以『止犯』已發生在先；若是勸諫『作犯（動手作惡）』，則是見對方想要作惡便可以勸阻，所以惡事的『作』還在後頭。因此，勸諫止犯當下便結罪，勸諫作犯則須等待事情做成才結罪。

【299-0010】02_戒疏/19a_卷四下之一#118
【原文】【疏】出家之士，理宜迭相將護，許無觸惱。今以六塵等相，恐怖前人，令生惶悸，廢修正業，惱深過重，故制。
【譯文】【疏文】出家修道之士，在理法上應當相互護持體恤，承諾絕不彼此觸怒驚擾。如今竟然藉由色、聲等六塵的幻異假相，恐嚇驚嚇同修道友，使人心生驚恐惶怖，荒廢修持正業，帶給人極深惱亂而過患深重，所以必須制定此戒。

【299-0011】02_戒疏/19a_卷四下之一#119
【原文】【記】五十五，制意中。初敘所宜。「今」下，顯過狀。「六塵」，如下釋。「惶」，懼也。「悸」，其季反，心驚動貌。
【譯文】【記文】第五十五條，在制戒用意中。起初敘述出家人應有的相處原則。從「如今竟然」以下，彰顯過咎的實態。「六塵」，如後文所作解釋。「惶」，就是恐懼。「悸」，音同季，是內心受驚動盪不安的神態。

【299-0012】02_戒疏/19a_卷四下之一#120
【原文】【註】佛在波羅犁毗國。那迦波羅侍佛左右。諸佛常法，若經行時，供養人在經行道頭立。彼初、中、後夜白佛令還，便反披拘執怖佛。明旦集僧，因制此戒。
【譯文】【註文】佛陀住在波羅犁毗國時。那迦波羅比丘侍奉在佛陀身旁。諸佛世尊行持的常規法則，經行修法時，隨侍侍奉的人應肅立在經行道路的端頭。該比丘在初夜、中夜、後夜時分，屢次稟白佛陀請佛回室就寢，佛陀依然經行，他便反披著獸皮裝神弄鬼恐嚇佛陀。隔天清晨佛陀召集僧眾，因而制定了此戒。

【299-0013】02_戒疏/19a_卷四下之一#121
【原文】【疏】戒緣，「怖佛」者，欲明輕怖，極聖尚遭，況餘下例，義須滅迹。又顯佛無怖心，怖在能怖，約同人相，無論怖與不怖，皆結重提。
【譯文】【疏文】在制戒因緣中，提到「恐嚇佛陀」，是為了闡明即使是輕微的恐嚇行徑，連至高無上的大聖佛陀都會被人施加，何況其餘資質較差的凡流，在義理上必須徹底禁絕這種惡劣行跡。另外也顯示佛陀具備圓滿清淨，心中絕無絲毫恐懼之念，恐嚇的罪過全在能行恐嚇之人的惡念惡行，只要對象符合人類同修的形貌標準，無論對方受驚或未受驚，恐嚇者一律結犯重波逸提。

【299-0014】02_戒疏/19a_卷四下之一#122
【原文】【記】戒緣中二。初約舉況釋。「例」，猶類也。「滅迹」，謂須制斷也。「又」下，次約判犯釋。謂此戒中舉佛為緣，欲明此犯不論所怖，以佛無怖故。
【譯文】【記文】制戒因緣中包含兩層意思。起初依據舉出聖者以比況凡夫來作解釋。「例」，就如同「同類」之意。「徹底禁絕」，是指必須立法嚴禁斷絕。從「另外也顯示」以下，次要是依據定罪標準來作解釋。也就是說在此條戒中以佛陀作為制戒緣起，是為了闡明此罪的成立並不取決於受害者到底害不害怕，因為佛陀本來就沒有恐懼之心。

【譯文】【疏文】回答：「不能這樣類比。殺凡人戒是以凡人為制戒因緣（戒緣）。律中是因為闡明破和合僧，才順帶說明殺佛（出佛身血）之事，並未直接以此作為殺戒的制戒因緣。」

【299-0017】02_戒疏/19a_卷四下之一#125
【原文】【記】釋難中。以怖例殺，不應別故。釋中，緣起不同，故不可例。注中，「那迦波」即比丘名。「供養人」亦即侍者。「白佛令還」，謂請佛還臥室也。「拘執」即獸皮。
【譯文】【記文】在化解詰難中。質疑者試圖拿恐嚇戒的例子來比附殺人戒，認為兩者不該有差別待遇。解釋中說明，兩者的緣起機制截然不同，所以絕不能硬行類比。隨律註解中，「那迦波羅」是當事比丘的名字。「隨侍供養人」也就是侍者。「請佛回室」，是指敦請佛陀回臥室安歇。「拘執」就是野獸的皮毛。

【原文】【註】若以色、聲、香、味、觸、法恐怖人，彼怖以不怖，皆一一墮；彼不知，吉羅。若說色、聲等六塵恐怖，說而了了者，波逸提；不了了，突吉羅。不犯者：或闇無火，或大小便處，謂是惡獸便怖，乃至行聲、咳聲、觸聲而恐怖；若以色等示人，不作恐意；若實有是相，或夢見當死、罷道、失物，和尚、父母重病若死，語彼令知；若戲，若誤——一切無犯。

【299-0029】02_戒疏/19a_卷四下之一#137
【原文】【記】制意中。初敘開意。「摶食」亦名段食，由食此食，脂膩外流，積聚塵垢，故成「不淨」。「澡」、「沐」者，並洗濯之異言，如俗字書「濯頭曰沐」，今取通意，不局身、首。清身去患，故能「增道」；外無垢染，故能「生善」。「但」下，二、明制意。數洗有二過：一、「翫著色相」，即樂世也；二、「無心厭背」，即違道也。
【譯文】【記文】制戒用意中。起初敘述開許沐浴的深意。「摶食」也稱為段食，由於攝取這種粗重食物，體內油脂膏汗不斷向外滲流，積聚在體表成為塵垢，所以導致身體「多不淨」。「澡」與「沐」，都是清洗濯除的不同用語，如同世俗字書所言「洗頭稱為沐」，如今律宗取其廣義通指，並不局限在洗頭或洗身。洗淨身軀祛除疾病隱患，所以能夠「增長修道」；外表去除垢濁染污，所以能夠「生長善法」。從「然而」以下，第二步說明制戒設限的用意。頻繁洗浴有兩種深重過患：第一、「貪玩愛著色相肉體」，這是貪戀世俗享樂的表現；第二、「內心無意厭離背棄生死」，這是完全違背解脫正道的。

【原文】【註】佛在曠野城。六群相謂：「我等在上座前，不得隨意語言。」即出露地，拾諸柴草，然火向之。株內毒蛇，火氣逼出，遂驚擲火，燒佛講堂。比丘舉過，佛因訶制。

【299-0047】02_戒疏/19b_卷四下之一#1
【原文】【疏】緣起中，由不得隨意語故，出外聚向，遂燒講堂，輕致重害，不可不慎。故世中所壞，多為火損，不爾久存。世界亦爾。火為凡貪，不可觸也。此是觀行，如何著之？
【譯文】【疏文】在緣起這一段中，由於不能隨意發言的緣故，便走到外頭聚集烤火，因而燒毀了講堂；輕忽而招致重大的損害，不可不謹慎。所以世間被毀壞的，大多是火造成的損失，否則就能長久保存。世界也是這樣。火為凡情所貪愛，不可去觸碰。這是觀行的內容，怎麼可以反而去執著它呢？

【299-0048】02_戒疏/19b_卷四下之一#2
【原文】【記】戒緣中。初牒文誡慎。「故」下，示過勸離。初指現事，故云「世中」等。次舉灾劫，故云「世界亦爾」，如大三灾起時，火灾壞至初禪天。三、明性烈，寒月雖貪，觸則爛體。「是觀行」者，謂觀火能變壞，了世無常而生猒捨。或可經論多舉為喻，或以三界喻火宅，或以世間喻無常，或令遠惡如避火坑，或云瞋心甚於猛火。斯等甚眾，略舉一二耳。
【譯文】【記文】在戒緣這一段中：最初是牒出文句、告誡要謹慎。「故」字以下，是指示過失、勸人遠離。首先指眼前的事實，所以說「世中」等語；其次舉出災劫，所以說「世界亦爾」，就像大三災生起時，火災一直壞到初禪天。第三、說明火的性質猛烈，寒月裡雖然貪求暖和，一碰觸就會燒爛身體。「是觀行」的意思是：觀火能變壞一切，從而了解世間無常，生起厭離、捨棄之心。或者經論中多舉火作譬喻：有的以三界譬喻火宅，有的以世間譬喻無常，有的教人遠離惡事如同躲避火坑，有的說瞋心比猛火更猛烈。這類說法非常多，這裡只是略舉一二而已。
