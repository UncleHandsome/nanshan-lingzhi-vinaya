# 校閱材料　第139檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【139-0001】01_行事鈔/07a_卷中之三#15
【原文】覆處敷僧物戒十五。五緣：一是僧物，二是屏處，三自使人敷，四不自舉、不教人舉，五或出界、或過三宿犯。律中，彼應語舊住比丘言，與我牢舉。若無人不畏失，當移床離壁，高搘床脚，持枕褥臥具置裏，以餘麁者重覆。若恐敗壞，當取臥具，置衣架上，竪床而去。若不作如是，出界外犯墮。若即還不久，聽二宿界外；第三宿明相未出，若自至房中，若遣使語知事人；不者明相出犯墮。
【譯文】覆處敷僧物戒十五。具備五緣成犯：一是屬於常住僧物，二是在有屋頂遮蔽的室內隱蔽處，三是自己親自鋪設或差使他人鋪設，四是離去時自己不收拾也不教人收拾，五是離開結界界外、或者超過三夜不歸便成犯。律中說：該比丘離開前應當對房內的常住舊住比丘說：「請代我穩妥收拾收整。」如果房內空無一人，且無失竊之虞，應當將床榻移開脫離牆壁，將床腳墊高懸空（防蟲蟻濕氣），把枕頭、褥墊等臥具收拾放在床鋪內側，用其他粗劣布席重重覆蓋好。如果唯恐受潮蟲蛀敗壞，應當取下臥具懸掛在衣架高處，把床板立起來豎靠妥當，然後方可離去。如果不按照這樣處理，一走出僧界之外便犯波逸提（墮）。如果是暫時外出且不久即回，開許在結界之外逗留兩夜；到了第三夜天明晨光（明相）尚未顯現之前，或者自己趕回房中，或者派遣使者轉告寺院知事人代為照看；若不如此，第三夜明相顯現之際便結犯波逸提（墮）。

【139-0002】01_行事鈔/07a_卷中之三#16
【原文】強敷戒十六。五緣：一他先借得，安止已定；二知他先住；三作惱意；四強敷中間；五隨坐臥犯。律云：中間者，若頭邊脚邊兩脇邊。臥具者，草敷葉敷下至地敷臥氈。若知他先得而彊宿者墮。《十誦》：若為惱他故，開戶閉戶、然火滅火，若唄呪願、讀經說法，隨他不樂事作，一一墮。律中不犯者：先不知；若語已住，先與開間；若間寬不相妨；若親舊教言，但敷，我自語主；若倒地；若病，轉側墮上，命梵等難，一切不犯。
【譯文】強敷戒十六。具備五緣成犯：一是該住處已由他人預先借得，且已經安居居住確定；二是明知他人已先入住；三是存有故意惱亂排擠他人之心；四是強行在他人身邊狹小間隙處鋪設臥具；五是隨坐下或躺臥即成違犯。律中說：所謂「中間」，是指他人的床頭邊、床腳邊、或是左右兩側緊挨之處。所謂「臥具」，包括草席、樹葉鋪墊，下至鋪在泥地上的毛氈等。如果明知他人已經先分配獲得該鋪位，卻強行闖入共同歇宿者，犯波逸提（墮）。《十誦律》說：若是為了故意惱亂他人，在房內故意開門關門、點火熄火，或是高聲梵唄祝願、誦經說法，凡是專挑對方不喜歡的事情故意去做，每做一事逐一結犯一個波逸提（墮）。律中不犯的情形：起初不知此處已有先住之人；或者事先已徵得對方同意而入住，先住者主動為他騰出空間；或者房間空間寬敞互不妨礙；或者老朋友、親近道友勸告說「你儘管鋪設，我自會去跟房主說」；或者是失足跌倒在地；或者是因病翻轉身軀無意跌落在他人物件上；以及面臨生命危難、梵行危難等，一切不犯。

【139-0003】01_行事鈔/07a_卷中之三#17
【原文】牽他出僧房戒十七。四緣：一是僧春冬房；以夏房入己牽出，犯吉。二先安止定。三作惱亂意。四牽出犯。律中，若自作、教人牽，隨所牽多少，隨出房，一切墮。若牽多人出一戶，多墮；一人出多戶，多墮。若持他物擲著戶外，閉他戶外，皆吉。《僧祇》：牽他出時，若抱柱捉戶倚壁，一一墮。若呵叱，隨語一一離，一一墮。若瞋蛇鼠驅出，越；若云此無益物，驅出無罪。《十誦》：若喜鼾眠，應起經行；不能經行，應起屏處，不應惱他。《五分》：若降伏弟子而牽出者，不犯。若將不喜人來，欲令自出，出不出吉羅。牽下四眾亦吉。律不犯者：無恚恨心，隨次出；共宿過限，遣未受具人出；若破戒見威儀為他舉及擯應擯；因此故有命梵難驅出，一切不犯。前戒是俗處，不簡淨穢；此是僧處，故簡穢也。
【譯文】牽他出僧房戒十七。具備四緣成犯：一是房舍屬於僧團共有的春季或冬季房舍；若是安居期分得的夏季專用房舍（已歸屬個人管轄），強行把他人牽出，結突吉羅（吉）。二是他人已經在此預先合法入住安定。三是存有故意惱亂排斥之心。四是強行動手牽拽逐出即成犯。律中說：若是自己動手、或是差使他人牽拽，隨所牽拽的人數多寡、只要隨其被逐出房門，一律結犯波逸提（墮）。如果將多人牽拽逐出同一個門戶，結多個墮罪；若把同一個人牽拽逐出多重門戶，也結多個墮罪。如果拿取他人的衣缽物品扔到門外、或將他人反鎖關在門外，皆結吉羅。《僧祇律》說：在拉拽他人出門時，對方若抗拒而抱住柱子、抓住門扇、背靠牆壁，比丘強行撕扯分離，每一個動作皆逐一結墮罪。若是厲聲訶斥驅逐，隨所說的每一句驅逐之語致使對方移離，每說一句即結一個墮罪。如果因為瞋恨而驅逐房中的蛇鼠，結越毘尼；如果只是說「這是對僧房無益的動物」而將其驅離，無罪。《十誦律》說：若是睡覺容易打鼾（鼾眠），應當自覺起身經行；若無法經行，應當起身前往無人之處歇息，不應當在房中惱亂同修。《五分律》說：若是為了調伏管教犯錯弟子而將其逐出，不犯。若是故意帶對方厭惡之人前來，意圖逼迫對方自行搬出，不論對方最終搬出與否，皆結吉羅。若是強行牽逐下位四眾（比丘尼、式叉摩那、沙彌、沙彌尼），亦結吉羅。律中不犯的情形：內心毫無瞋恨怨懟之心，而是依照床位編次更替而請其遷出；或者因為共宿超過期限，遣派未受具足戒之人離去；或者對方破壞禁戒、正見、威儀，或者因此被他人舉發，以及已被僧團擯黜或理應被擯黜的人（將此等污穢之人驅逐出房）；或者因為對方留在房中會引發生命危難、梵行危難而將其驅趕離開，一切不犯。前一條強敷戒是指在世俗居士處所，不區分戒體清淨或垢穢；本條戒是指在僧團常住處所，故嚴格簡別戒行之垢穢與否。

【139-0004】01_行事鈔/07a_卷中之三#18
【原文】坐脫脚床戒十八。三緣：一是重屋，二脫脚床，三在上坐臥犯。
【譯文】坐脫脚床戒十八。具備三緣成犯：一是在雙層或多層樓閣房屋之上（重屋），二是床腳未經木榫卯緊或活絡易脫落的脫腳床（脫脚床），三是在這種床上坐下或躺臥即成違犯。

【139-0005】01_行事鈔/07b_卷中之三#1
【原文】用蟲水戒十九。四緣：一是蟲水，二知有蟲，三不作漉法，四隨所用犯。律云：若以草土擲蟲水中。若蟲酪漿、清酪漿、若漬麥漿、若醋，有蟲，以澆泥草，若以草土擲中，一切皆墮；教人亦同。《五分》：隨用蟲，一一墮。律中若以草土擲水中，隨河池中魚蟲，一一提。《大集》云：畜生身細猶如微塵十分之一，乃至大者百千萬由延。《僧祇》：蟲細者，三重漉，猶有者，捨去。若用水者，日日諦視，無蟲便用；以蟲生無定，或先無今有故。《五分》：蟲水者，漉囊所得，肉眼所見；若用水，蟲蟲墮。無漉囊不得半由旬行，若無者用衣角漉之。律不犯中：不知有蟲，作無蟲想；若蟲大，以手動水令蟲去；若漉水洒地，若教人漉者，一切不犯。
【譯文】用蟲水戒十九。具備四種緣成犯：一、確實是有蟲的水；二、明知水中含有蟲；三、不依律法進行過濾（漉水）；四、隨著使用該水而結罪。《四分律》說：如果將草木或泥土丟擲到有蟲的水中；或者生了蟲的酪漿、清酪漿、浸麥漿或是醋，其中生有蟲，卻拿來澆灌泥土和草木，或者將草土擲入其中，所有這些行為皆結波逸提（單墮罪）；教唆他人去做也是同樣結罪。《五分律》說：隨所使用的水中每一隻蟲，每有一蟲便各結一個波逸提（單墮罪）。《四分律》中說：如果將草木泥土擲入水中，隨著江河池沼中受害的魚類與微蟲，每一條生命皆各結一個波逸提（提）。《大集經》說：畜生的身體細小者，猶如微塵的十分之一，乃至巨大者可達百千萬由延（由旬）。《僧祇律》說：如果蟲體極其細小，應當用三層濾水囊過濾，若過濾後依然有蟲，則應將水捨棄不用。如果要用水，每天都必須仔細端詳審視，確認無蟲便可使用；因為蟲類的生長沒有定規，或許先前沒有而如今卻生出了。《五分律》說：所謂蟲水，是指濾水囊過濾所得、肉眼所能見到的微蟲；若使用含有這類蟲的水，每害一蟲皆結一個波逸提（單墮罪）。比丘若無濾水囊，不得出行半由旬；若實在沒有濾水囊，應當使用衣角來過濾水。《四分律》所定不犯的情況包括：不知道水中有蟲，作無蟲想而使用；如果蟲體較大，用手撥動水流使蟲自行離去；如果是過濾之後的水用來灑地；或者教人依律過濾者，一切都不結罪。
