# 校閱材料　第1297檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1297-0001】資持記/14a_下二#7
【原文】而殺而食者，即殺我父母是也。二恐食其同類，非仁心也。三謂禽畜交合精血所成，腥臊穢物，自內於口，深可惡也。四者由多噉肉，易其血氣；眾生聞之，知是殺者。五即《涅槃》所謂斷大慈種也。六中由是愚癡不淨者所為，故有食噉，無善名稱。七謂或持呪術，必須精潔；尚誡葷辛，何況血肉。
【譯文】若是殺害並且食用，就等於殺害我自己的父母。第二是唯恐吃了自己的同類，這不合乎仁慈之心。第三是認為禽畜交合是由精血所生成，屬於腥臊汙穢之物，自己納入口中，極為令人厭惡。第四是由於吃多了肉，會改變自身的血氣；眾生嗅到這種氣味，便知道這是個殺生者。第五就是《涅槃經》所說的斷絕大慈悲種性。第六是因為這是愚痴不淨之人的作為，所以雖然食肉，卻得不到善名聲。第七是指若修持咒術，必須保持潔淨；尚且要戒除五辛葷菜，何況是血肉之物。

【1297-0002】資持記/14a_下二#8
【原文】八謂凡遇畜形，即思其味故。九中三過，天報清淨，所以捨棄；不習善法，故多惡夢；身同畜氣，故為虎狼所食。十謂由此相因，遂噉同類。斑足王者，其父遊獵至山，染師子而生；人形斑足，後紹王位，一日掌膳者闕肉，求得小兒肉以充之，王覺味殊，因勅常供；
【譯文】第八是指凡是見到禽畜的身形，就會貪求其滋味。第九中包含三種過失：天界的果報清淨，所以會捨棄這種人；不修習善法，所以常做惡夢；身上帶有禽畜的臊氣，所以容易被虎狼吞食。第十是指由這種惡業輾轉相因，最終導致互相噉食同類。所謂斑足王，他的父親出外打獵來到山中，與雌獅交媾而生下他；身具人形卻有斑點之足，後來繼承了王位。有一天掌廚的人缺少肉食，找來小兒之肉充數，國王覺得滋味殊美，便下令廚子常常供應；

【1297-0003】資持記/14a_下二#9
【原文】殺害既多，眾欲殺王，王變為飛行羅剎，十二年中常食人肉。申誡中，初明過重。如向列故。故下，次明業深。同屠殺故。引小中，初科。為一眾殺而制七眾者，以同沾佛戒，意所通故。彼律得食三種淨肉，謂不見、不聞、不疑為我故殺者。是知雖云得食，還同禁斷。下引《四分》，其意益明。
【譯文】殺害的人多了，大眾想要殺死國王，國王便化身為飛行羅剎，在十二年之中常常吃人肉。在申明告誡之中，首先說明過失極重，就如同上述所列一般。從「故」字以下，接著說明業障極深，因為與親手屠殺沒有兩樣。在引用小乘律的段落中，這是第一科。為七眾中某一眾殺生而禁制全體七眾受食，是因為同受佛戒，制戒的本意是相通的。該律中准許食用三種淨肉，即不見殺、不聞殺、不懷疑是為我而殺。由此可知，雖然說可以吃，實際上等同於禁斷。下文引用《四分律》，其意旨就更加清楚了。

【1297-0004】資持記/14a_下二#10
【原文】次科，初明學戒。多不食者，此指祖師之世奉持者耳。若今學戒，食肉飲酒，猶為細行；更行麁惡，不足言之。中國學大乘者，皆依《梵網》、《楞伽》、《涅槃》等制；既修大行，慈濟為先，安有大乘方行殺戮。皇唐之世，華竺交通；或梵眾東來，或此僧西邁；彼方風化，可得傳聞。
【譯文】下一科，首先說明學戒的情況。「多不食」這句話，是指祖師那個時代依教奉持之人。若是現今學戒之人，飲酒吃肉還被視為細微的行持；至於更粗惡的破戒行徑，更是不值一提。中印度修學大乘的人，都依循《梵網經》、《楞伽經》、《涅槃經》等經的制戒；既然修習大乘行，自當以慈悲濟度為首要，哪裡有修大乘法反而行殺戮食肉之事？大唐盛世，中土與印度往來頻繁；或有印度僧人東來，或有此地僧人西行；彼方（中天竺）的教化風規，皆可聽聞傳述。

【1297-0005】資持記/14a_下二#11
【原文】且如此土稟大高僧，至有身不服於繒綿，足不履於皮革，葷辛乳蜜，多不沾甞；蚤虱蚊虻，從之咂齧；斯之學大，豈非大乎。有下，指斥。行謂為之無恥，解謂執之不疑。二教不收者，以大小俱制，反不依行，教所不被故。教既不被，非佛弟子；無慈好殺，宜入屠行。天魔報勝，淨因所克；
【譯文】況且此方受持大乘的高僧，甚至達到身上不穿絲綿、腳下不穿皮鞋，葷辛乳蜜多不沾唇嘗受；蚤虱蚊虻任由牠們叮咬吸血；這樣的修學大乘，難道不正是偉大的大乘嗎？從「有」字以下，進行指責痛斥。「行」是指做這件事而不知羞恥，「解」是指固執這種知見而深信不疑。說大小二教皆不收攝，是因為大乘小乘皆有明文禁制，反而不依教奉行，因此不為教法所被攝。既然不為教法所被，便非佛弟子；毫無慈悲而喜好殺生，應當歸入屠夫之列。天魔福報殊勝，尚由清淨之因而得；

【1297-0006】資持記/14a_下二#12
【原文】外道苦行，飡風自餓等；故知噉肉比丘，未及魔外。閻羅將吏，信是同倫。具云閻摩羅，此云雙王，苦樂竝受故。又云兄治男事，妹治女事，故云雙王。將吏，謂夜叉鬼卒之類。三中，《四分》，初明制斷。為我、大祀，二皆不淨。今下，顯意。毘下，指同。次明開食。前與肉者，須行十善；
【譯文】外道修苦行，亦能餐風自餓等；因此可知食肉的比丘，連天魔與外道都比不上。閻羅王的部將獄卒，確實是他們的同類。「閻摩羅」具足而言，此處譯為「雙王」，因苦報與樂報一同承受的緣故。又有一說是兄長治理男性之事，妹妹治理女性之事，所以稱為雙王。「將吏」是指夜叉、鬼卒這一類。在第三科中，《四分律》首先說明制止斷除。為我殺與為大祭祀殺，兩者都是不淨肉。從「今」字以下，顯露深意。「毘」字以下，指出義理相同。接著說明開許食用之處。先前准許給肉的施主，必須是修行十善之人；

【1297-0007】資持記/14a_下二#13
【原文】豈有行十善者而有肉耶？故云何由得肉等。鳥殘，《多論》犯吉。通禁中。酒肉兼五辛，文缺與渠。或謂阿魏，或云自有興渠，根如蘿蔔。䔉音算，韮音久，薤胡介反，竝葷菜也。《梵網》云：一切食中不得食。
【譯文】哪裡有修行十善的人身邊還會有肉呢？所以說憑藉什麼而能得到肉呢。鳥獸殘食之肉，《薩婆多論》判定食用犯吉羅罪。在總體禁戒之中，酒肉兼帶五辛，文句中缺少「興渠」。有人說興渠是阿魏，也有人說自有興渠這種植物，根部如同蘿蔔。蒜音算，韭音久，薤是胡介反，都屬於葷菜。《梵網經》說：在一切食物之中皆不得食用。

【1297-0008】資持記/14a_下二#14
【原文】《楞嚴》云：熟食發婬，生噉增恚，如是世界食辛之人，縱能宣說十二部經，十方天仙嫌其臭穢，咸皆遠離；諸餓鬼等，因彼食次，舐其脣吻；常與鬼住，福德日消，長無利益等。舉況中。《論語．鄉黨》說孔子凡祭祀預齊，不飲沽來之酒，不食市得之脯。
【譯文】《楞嚴經》說：熟食會引發淫欲，生吃會增長瞋恚，如此世間吃辛辣葷菜之人，縱然能宣說十二部經，十方天仙也厭惡其臭穢，全都遠遠避離；各類餓鬼等，會趁著那人用餐之際，舔舐他的嘴唇；長久與鬼同住，福德日漸消損，長劫沒有利益等。在舉例比況中，《論語．鄉黨》記載孔子凡是參加祭祀齊戒，就不飲用市集買來的酒，不吃市集買來的乾肉。

【1297-0009】資持記/14a_下二#15
【原文】為僧嗜此，希貪口腹，情無遠趣，故云所懷可見。引斥中，初引示。今下，斥非。二途即上貪美棄惡；凡庸之情，故可知也。非時漿中，《僧祇》。豆等頭不破者，破即時漿，非時不得飲。
【譯文】身為僧人卻嗜好這些，貪圖口腹之欲，心志沒有崇高的追求，所以說其胸懷意趣便可想而知了。在引文斥責之中，首先引文提示。從「今」字以下，斥責其非。所謂「二途」，就是指上述貪圖美味而唾棄粗惡；這是庸俗之人的性情，所以理應明知。在「非時漿」之中，《僧祇律》說：豆類等若表皮未破即可，表皮破裂就是時漿，非時便不得飲用。

【1297-0010】資持記/14a_下二#16
【原文】十四種者，一菴羅漿，二拘梨，三安石榴，四巔哆梨，五蒲桃，六波樓沙，七犍犍，八芭蕉，九罽伽提，十劫頗羅，十一婆籠渠，十二甘蔗，十三呵梨陀，十四呿波梨。〔上多列梵言，未見翻譯，竝果名耳。〕要水淨等，壞好味故。次科，初引文。火淨壞種，水淨壞味。準下，例通。三淨中，《善見》。
【譯文】十四種漿分別是：一是菴羅漿，二是拘梨漿，三是安石榴漿，四是巔哆梨漿，五是蒲桃漿，六是波樓沙漿，七是犍犍漿，八是芭蕉漿，九是罽伽提漿，十是劫頗羅漿，十一是婆籠渠漿，十二是甘蔗漿，十三是呵梨陀漿，十四是呿波梨漿。（以上大多列出梵音，未見翻譯，都只是果實的名稱而已。）必須經過水淨等程序，是為了破壞其純美滋味。下一科，首先引用經文。火淨破壞種子生長力，水淨破壞濃郁美味。從「準」字以下，例推通用。在第三科（簡諸漿）中，引《善見律》處（見下段）。
