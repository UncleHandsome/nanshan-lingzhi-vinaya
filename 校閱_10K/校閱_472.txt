# 校閱材料　第472檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【472-0001】02_戒疏/06b_卷二上之二#48
【原文】【疏】就初所以將罪以況「斷頭」者，過之重也。如俗極刑，勿過「大辟」，謂斬首也。約刑制戒，兩以通之。故《鈔》引云，如人有頭，受諸塵也，若不毀重，能有見諦，反此毀壞，永不能見，故以類也。
【譯文】【疏文】首先在第一部分，之所以拿「斷頭」來比喻這種重罪，是因為這項過失極為嚴重。好比世俗人間最極端的重刑，沒有大過於「死刑大辟」的，也就是斬首示眾。戒律依照世俗的刑罰精神來建立規範，兩者在義理上是相通相融的。因此《事鈔》中引用說明：好比人只要有了頭部，才能完整接納六塵的感知；修道者如果不毀犯重戒，才能具備見到四聖諦真理的能力；反過來說一旦毀壞了根本大戒，就永遠不能洞見真理，因此才用斷頭來做比喻。

【472-0002】02_戒疏/06b_卷二上之二#49
【原文】【記】釋注，罪名中，初文。前明舉喻所以。「如」下，引俗刑比釋。準俗制道，事義相類，故云「兩通」。「故」下，引示。即《標宗篇》引《婆沙》文「人之頭首，具納六塵，戒法亦爾，能通諸法」，故以比之。故彼論云：「戒名為『頭』，能見苦諦等色，聞名身等義，嗅覺意花，嘗出離三菩提味，覺禪定解脫等觸，知色陰等法。」廣如《鈔記》委釋。
【譯文】【記文】在解釋小註罪名的開頭文句中。前面說明舉出比喻的緣由。「如」字以下，是引用世俗的刑罰來對比解釋。依照世俗之法來制定僧團道規，在法義事相上非常相似，所以說「兩相通融」。「故」字以下，是引用文證說明。也就是在《標宗篇》中引用了《大毘婆沙論》的文句：「人的頭部具足容納六塵，戒法也是如此，能通達一切善法」，所以才以此做比喻。因此那部論典說：「戒律被稱為『頭部』，有了它才能看到苦諦等無漏色法，聽聞名身、句身等正法義理，嗅聞到七覺支的心靈妙花，品嘗超脫三界的無上菩提滋味，覺受到禪定解脫等殊勝觸感，澈見五蘊等諸法實相。」詳細情形如《事鈔記》所作的精細解釋。

【472-0003】02_戒疏/06b_卷二上之二#50
【原文】【疏】人又解云：「犯二篇罪，可有上起。若犯初篇，如人頭斷，不可復起。縱有開懺，障於地獄。然於僧用，則無成法。故文云：『若作法已，僧說戒時，來與不來，皆無犯矣。』」
【譯文】【疏文】另外有人解釋說：「如果違犯了第二篇（僧殘罪），還有機會向上懺悔恢復僧籍。但如果違犯了第一篇（波羅夷極重罪），就好比人頭已經被斬斷，絕對不可能再復活。縱使在特別開許下允許他發露懺悔，也頂多只能障蔽免墮地獄之苦；然而對於僧團的一切羯磨法事，他已經完全失去正式僧人的資格。所以律文說：『如果作了（與波羅夷治罰羯磨）法之後，僧團在舉行布薩說戒時，他來不來參加，都完全不構成僧團犯戒了。』」

【472-0004】02_戒疏/06b_卷二上之二#51
【原文】【記】他解中。即以初、二兩篇，對顯喻意。二篇有餘，懺已復本，如人被斫，殘有咽喉。初篇永弃，眾不容受，故如斷頭，不可復活。「故」下，引《律》證成無用。僧無別眾，故云「無犯」。
【譯文】【記文】在轉述其他法師的解釋中。就是拿第一篇與第二篇的戒罪，相對照來凸顯斷頭比喻的深意。第二篇的罪過還有挽救餘地，懺悔之後就能恢復清淨本體，好比人的脖子被砍了一刀，但咽喉氣管尚存未斷。第一篇重罪則是永遠遭到唾棄革除，僧團再也無法包容接納，所以如同斷了頭，斷不可能再次復活。「故」字以下，引用《律藏》來證實他已完全失去僧團的僧人功能。因為僧團中不再算他為獨立的一員僧數，所以說「不構成犯戒」。

【472-0005】02_戒疏/06b_卷二上之二#52
【原文】【註】「若方便欲行不淨，成者波羅夷，不成者偷蘭遮。若教比丘行，若作，教者偷蘭遮；不作，突吉羅。除比丘、比丘尼，餘眾相教，作、不作盡突吉羅。若屍半壞，若一切壞，若骨間，若地孔、泥孔，行不淨者，並偷蘭。若道，作道想，若疑，若非道想，並波羅夷。若非道，道想，道疑，並偷蘭遮。比丘尼波羅夷。式叉摩那、沙彌、沙彌尼，突吉羅，滅擯。是謂為犯。不犯者，若睡眠無所覺知，不受樂，一切無有婬意。不犯者，最初未制戒，癡狂、心亂、痛惱所纏。」
【譯文】【註文】「如果有行淫的預備手段而企圖行不淨行，最後真正得逞者構成波羅夷罪，未得逞者構成偷蘭遮（重罪未遂）。如果唆使其他比丘去行淫，對方若去做了，唆使者犯偷蘭遮罪；對方若沒有做，唆使者犯突吉羅（輕垢罪）。除了正式的比丘與比丘尼之外，其餘沙彌等大眾互相唆使行淫，無論最後做與不做，全都一律犯突吉羅罪。如果所侵犯的屍體已經腐爛了一半、或者全身完全腐爛、或者是對骨骸骨縫、乃至在泥土孔洞、爛泥窟孔中行不淨行者，全都構成偷蘭遮罪。如果在正常的器官管道上，心裡也認為是正常管道；或者心中懷疑；或者誤以為是非正常管道，只要侵入，全數構成波羅夷罪。如果在非正常的器官部位，誤以為是正常管道；或者心中有所懷疑，全都構成偷蘭遮罪。比丘尼犯此戒同樣是波羅夷罪。正學女（式叉摩那）、沙彌、沙彌尼違犯此過，犯突吉羅罪，並應被驅逐出僧團（滅擯）。以上所說的情況都構成犯戒。至於不算犯戒的情況：如果是在睡眠中完全沒有知覺、自始至終沒有感受快感，一切身心都沒有絲毫淫欲的念頭。另一種不犯的情況，是最初佛陀尚未制定這條戒律之時的當事人，或者是處於極度愚癡發狂、心神散亂、劇烈病痛逼惱糾纏的狀態，都不算犯戒。」

【472-0006】02_戒疏/06b_卷二上之二#53
【原文】【疏】二、「若方便行不淨」下，成犯相中，文分為二：初明成犯相；後明不犯者，開犯法也。初人分二：初明比丘犯相，後明四眾犯相。諸戒同爾，下更不解。就前分二：前明自作、教他成犯相；二、「屍壞」已下，境想相對成犯相。就前又二：初、自作明輕重；二、「教比丘行」下，教作明輕重。文可解耳。
【譯文】【疏文】第二部分、從小註「若以預備手段想要行淫」以下，在構成犯戒的行爲態樣中，內容分為兩個大段落：前半段闡明構成犯戒的具體條件；後半段說明不犯戒的情況，這是屬於開許免罰的法規。在前半段論及當事人的部分又分為兩種：先說明比丘犯戒的行爲態樣，再說明其餘四眾犯戒的行爲態樣。其餘各條戒律也都是這個原則，以下就不再重複解釋。在比丘犯戒的內容中又分為二：前面先說明自己親自造作、以及唆使他人造作所構成的罪相；第二部分、從「屍體腐爛」以下，則是說明行淫時內心想念與客觀環境互相對照所構成的罪相。在前面自作與教他的部分又分為二：第一是自作時區分情節輕重；第二是從小註「教比丘行」以下，說明教唆他人作惡時的罪行輕重。文字意思很容易理解。

【472-0007】02_戒疏/06b_卷二上之二#54
【原文】【記】犯相中，總分。凡四重，初、約法簡，二、就人分，三、心、境不同，四、自他兩異。一一對注，分節文句。
【譯文】【記文】在解釋犯戒形態中，做總括的分段。大體上分為四重層次：第一、依照法規本體加以簡別；第二、依照犯戒者的身分進行區分；第三、辨析內心想念與外在境界的異同；第四、區分親自造作與唆使他人的差別。將這四重層次一一對應小註，把文句章節梳理得非常清楚。

【472-0009】02_戒疏/06b_卷二上之二#56
【原文】【疏】答：「有二緣。若唯重婬意，入便偷蘭，縱出不淨，不犯僧殘。若欲喜樂意者，如《十誦》、《五分》『乃至骨間，出不淨，殘；不出止，蘭。』此是大婬戒，不就僧殘結，以不作出意故。」
【譯文】【疏文】答：「這有兩種前因緣由。如果單純只是出於極重的淫欲心思，只要剛一侵入就結判為偷蘭遮罪，縱使最後洩出了不淨之物，也不結判為僧殘罪。如果心中帶有追求快感樂受的自慰念頭，那就如同《十誦律》、《五分律》所規定的：『乃至在骸骨骨縫之間，若洩出不淨之物，結犯僧殘罪；若未洩出便停止，結犯偷蘭遮罪。』而現在這一條是屬於第一篇的大淫戒，不依照僧殘罪來結罰，因為當事人自始就不是單純為了自我洩精而動念的緣故。」
