# 校閱材料　第1531檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1531-0001】05_拾毗尼義鈔/03b_卷中之一#2
【原文】第二犯人同異者一人盡犯此即易知四方僧一向不犯同活人中五戒一向不同二離衣六年臥具不揲坐具雨衣何者此戒皆別人受持無共受義何有我離令彼得罪七戒不定長衣一月衣鉢藥過後畜浣衣奪衣等如長衣同主人俱現前不說皆有情過是故同犯若一人遠去敕在者說而彼不說在者有犯行者無過是故不定餘四亦然若受持衣浣奪亦不共犯若共有長共浣共奪亦得同犯餘十八中若不同作己為他亦不同犯如一人在道遇賊打失奪三衣居士為奪故施而過知足受在家者不知可有同犯今言同者共行皆失共計過取故言同犯餘者易知約現前僧應犯七戒謂共作綿褥黑白臥具共擔過三畜寶易寶共奪衣。
【譯文】第二門、探討犯人同異者：一人全犯，此即容易理解；十方常住僧一向不犯。同活共住人中，有五戒一向不同犯：二離衣、六年臥具、不疊坐具、雨衣。何以故？此等戒皆屬各別之人受持，無共同受持之義，哪有我離宿而令彼得罪之理？有七戒違犯情況不定：長衣、一月衣、長缽、急施衣過後蓄留、長藥過後蓄留、使洗故衣、奪衣等。例如長衣，同住主人俱現前而不說淨，皆有縱情過失，是故同犯；若一人遠去，囑託在者說淨而彼未說，在者有犯，遠行者無過，是故不定，其餘四戒亦然。若是受持之衣，洗衣、奪衣亦不共犯；若是共有長衣，共洗、共奪，亦得同犯。其餘十八戒中，若不同時造作、己為他人作，亦不同犯。如一人在道中遇賊劫奪失去三衣，居士為其被奪之故而布施，彼卻過量知足而受，在家同伴若不知情，豈可同犯？今言同犯者，謂同行皆失衣，共計過量索取，故言同犯。其餘容易理解。就現前僧而言，應同犯者有七戒：共作綿褥、共作黑臥具、共作白臥具、共擔羊毛過三由旬、共蓄寶、共易寶、共奪衣。

【1531-0002】05_拾毗尼義鈔/03b_卷中之一#3
【原文】第三自作教他同異者自作一向正犯教人同異不定者直教他十七戒能教者一向輕以無財潤己故但不應教他為惡故犯吉羅有十三戒教人為己得物潤己與至作無殊準三性心中不善無作任運起異何者十三謂五敷具奪衣受寶取尼衣浣故衣染擗毛過反索衣自乞縷織讚織師如是等知。
【譯文】第三門、探討自作教他同異者：自作一向是正犯；教人作之同異則不定。單純教他作之十七戒，能教者一向結罪較輕，因無財物潤益於己，純粹是不應教他作惡，故犯突吉羅。有十三戒教人為己作，得物潤益於己，與親自作無殊；准照善惡無記三性心中，不善之無作任運生起而有異。何者為十三戒？謂五敷具、奪衣、受寶、取尼衣、洗故衣、染擗羊毛、過三反索衣、自乞縷使織師織衣、讚織師，如是等應當了知。

【1531-0003】05_拾毗尼義鈔/03b_卷中之一#4
【原文】第四重犯有無者四戒得重犯浣故衣擔羊毛擗羊毛用雨衣此物現前容了更作故重也自餘二十六皆無重犯又解浣衣更使浣打但犯小罪而文云浣打染三尼薩耆者非謂一衣生於三罪各使為一婆論云一時作三事亦得一捨若使浣不淨染不成色打不熟皆吉浣染相別尚無重犯何有二浣得重犯乎善見亦無重犯文義相似諸部云云不須廣引。
【譯文】第四門、探討重犯有無者：有四戒得重犯：洗故衣、擔羊毛、擘羊毛、提前敷用雨浴衣。此物現前，容許作了再作，故重複犯。其餘二十六戒皆無重犯。又解：洗衣更使洗、打，但犯小罪；而經文說洗、打、染三尼薩耆者，非謂一衣生於三罪，而是各別指使結為一罪。《薩婆多論》云：一時作三事，亦只得一捨墮。若使洗不淨、染不成色、打不熟，皆犯吉羅。洗衣與染衣相狀各別，尚且不重犯，何有一衣洗二次即得重犯？《善見律》亦主張無重犯，文義相似，諸部律各有所說，不須廣引。

【1531-0004】05_拾毗尼義鈔/03b_卷中之一#5
【原文】第五捨懺方法者三捨如上且論捨財有五門第一對境者綿褥是壞息貪故對境無也畜易二寶由體長貪僧受亦犯故對俗捨其對僧境通別一二三等可解第一全壞如上可解第三處所處所無遮第四集眾三戒不集第五還財還財五例一壞還主二入俗反體還主三入僧還主不復本用四入僧入俗不復本用五一向還主四分如之十誦云易寶畜寶販賣得寶少者永捨多者付同意淨人作四方僧臥具要僧中悔餘一同四分五分五捨一入僧永捨畜寶等捨與僧差人永棄若僧不爾令淨人為僧貿衣食與僧食用唯本主不得食恐遂本心故二永入僧捨五敷具入常住用唯本主不得坐三入僧俗捨藥入僧僧捨與俗人沙彌塗足然燈本主不得用一切比丘不得食餘二同此祇律五捨一捨入僧無盡物謂畜寶貿寶若出息利作僧房舍中衣僧不得分用及食為折伏本主貪心故二捨入僧用謂五敷具迴僧物隨僧作何等用其中純黑憍奢耶僧不得著用得作地敷及作嚮㡘帳幔等六年不揲不得作地敷僧得著用俱不襯身白毛臥具中好如前解不好如後解餘三亦同此若存重犯還法者綿褥畜寶貿寶不對僧二十七中四戒即日歸主二離二毛非相染故七日藥雖相染以還主制身外用故亦即日還有四戒要經宿餘十八戒別捨不須經夜若二十三戒共長月過合捨之時六戒即日歸主二離二毛藥鉢若以二十三戒共長鉢合捨唯乞鉢一戒共長鉢經宿餘皆即日歸若以二十三戒共長藥合捨一切即日歸以內外資別衣鉢不同皆不相染故廣如大鈔其罪中綿褥二寶捨財不集眾故悔於別眾得成自餘諸戒捨財及罪皆悉盡集別作不成論其捨心有五戒長月鉢藥過由相續儲貪若欲還財畜心須斷所捨長財體不得即日歸主要須經夜若有遠行急難開即日展轉自餘諸戒皆無經日相續畜過但使財罪已捨即歸無染此中婆多云即日得受異財不犯長以心斷故非如本財曾經畜過故若心未斷皆不得受唯除七日歸主塗足然燈以不得作藥服故即日得受異藥不染以心斷故此約不得即日歸主。
【譯文】第五門、探討捨懺方法者：三捨如上所明。暫且論捨財，有五門：第一對境者，綿褥是斬壞以息貪心，故對境無所捨；蓄寶、易寶二戒，由於體質能助長貪心，僧受亦犯，故對俗人捨；其對僧之境，通於全體僧眾或別眾一人、二人、三人等，下文可解。第一門全壞，如上可解。第三處所，處所無所遮礙。第四集眾，有三戒不集結大眾。第五還財，還財有五種條例：一是壞後還主；二是入俗改變體質後還主；三是入僧後還主，不復本用；四是入僧入俗，皆不復本用；五是一向直接還主。《四分律》大意如此。《十誦律》云：易寶、蓄寶、販賣得寶，少者永捨，多者付與同意淨人作四方僧臥具，且要於僧中懺悔；其餘一同《四分律》。《五分律》有五種捨：一是入僧永捨，蓄寶等捨與僧，僧差人永遠棄擲；若僧不棄擲，令淨人為僧買賣衣食供僧食用，唯本主不得食，恐遂其本貪心之故。二是永入僧用之捨，五敷具入常住使用，唯本主不得坐。三是入僧俗捨，過期之藥入僧，僧捨與俗人沙彌塗足、燃燈，本主不得用，一切比丘不得食。其餘二種捨同此。《僧祇律》有五種捨：一捨入僧為無盡物，謂蓄寶、貿寶，若出利息以作僧房舍、寺中資具，僧不得分用及食用，為折伏本主貪心之故。二捨入僧用，謂五敷具歸僧物，隨僧作何等用；其中純黑羊毛臥具與憍奢耶臥具，僧眾不得著用，得作地敷及門簾帳幔等；減六年臥具與不揲坐具，不得作地敷，僧眾得著用，但俱不得貼身；白毛臥具中好者如前解，不好者如後解；其餘三捨亦同此。若依主張有重犯之還財法：綿褥、蓄寶、貿寶不對僧捨。二十七戒中，四戒即日歸還本主：二離衣、二毛，非轉相染污故；七日藥雖相染污，以還主後制令作身外之用，故亦即日歸還；有四戒要經過一夜方還；其餘十八戒若各別捨，不須經夜。若二十三戒與長衣、一月衣、急施衣過後蓄三戒合併捨時，六戒即日歸主：二離衣、二毛、長藥、長缽。若二十三戒與長缽合併捨，唯乞缽一戒與長缽須經宿，其餘皆即日歸還。若二十三戒與長藥合併捨，一切皆即日歸還，因為內外資身不同、衣缽各別，皆不相染污，廣如《大鈔》所明。在罪過方面，綿褥、二寶捨財不集眾，故於別眾前懺悔得成；其餘諸戒捨財及懺罪皆悉全集大眾，別眾作法則不成。論其捨心，有五戒（長衣、一月衣、長缽、七日藥、急施衣過後畜），是由於相續蓄儲貪心，若欲還財，蓄心必須斬斷，所捨之長財體質不得即日歸主，要須經過一夜；若有遠行急難，則開許即日展轉給與。其餘諸戒皆無經日相續蓄儲之過，只要財物與罪業已捨，即刻歸還無所染污。此中《薩婆多論》云：即日得受其餘財物，不犯蓄長，因貪心已斷，非如本財曾經蓄過故；若心未斷，皆不得受。唯除七日藥歸主後塗足燃燈，因不得作藥服用，故即日得受其餘藥物而不染，以服藥貪心已斷之故；此約不得即日歸主而論。
