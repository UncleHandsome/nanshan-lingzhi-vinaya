# 校閱材料　第495檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【495-0001】02_戒疏/07b_卷二上之三#47
【原文】【記】五種心中，初文又二。初通示心相。引《律》「隨作犯」者，則知此心通犯諸戒。又云「更增無知罪」，則不學無知，亦同此耳。「即」下，別指盜業。即前三寶境中已明。
【譯文】【記文】在「五種心」的解釋中，第一段文字又分為兩層。首先整體揭示心相。引用《四分律》「隨作隨犯」的說法，就能明白這種愚癡心普遍會違犯各種戒律。律中又說「更增添不學無知之罪」，可見不肯修學導致的無知，也同樣歸於這類愚癡。「即如」以下，特別指出盜戒的具體業相。這在前面辨析三寶財物的境界中已經說明過了。

【495-0002】02_戒疏/07b_卷二上之三#48
【原文】【記】二中，初示名。「邪命」，謂邪求養命。「貪」下，列相。「規」謂希求，「度」即籌慮。規度說法，事同治生販易，故云「即是」等也。「故」下，引證。
【譯文】【記文】在第二種心相中，首先點明名稱。「邪命」是指以不正當的手段謀生。「貪心」以下，列出具體行相。「規」是指非分希求，「度」是指暗中算計。帶著謀求盤算的心去說法，性質如同經商買賣營利，所以說「即是以利求利」等。「故」以下，引用經論證明。

【495-0003】02_戒疏/07b_卷二上之三#49
【原文】【記】三中，初釋名。「曲」謂非理，「戾」即忿怒。「與」下，示相。「嫌恨」約內心。「威怒」約色相。
【譯文】【記文】在第三種心相中，首先解釋名稱。「曲」是指違背事理，「戾」是指忿恨暴怒。「與少」以下，展示具體行相。「嫌恨」是就內心而言，「威怒」是就外在神色而言。

【495-0004】02_戒疏/07b_卷二上之三#50
【原文】【記】四中，示名。「迫」，謂以事逼切。「喝」，謂說時作其大聲，或可作「遏」，謂抑遏也。「或」下，顯相。「說地獄」，謂濫託聖法。「王官」，謂倚恃豪勢。「如」下，引證。
【譯文】【記文】在第四種心相中，指出名稱。「迫」是指在事態上苦苦逼迫。「喝」是指說話時故意發出巨大聲響恐嚇，或者可以作「遏」，也就是壓制阻止的意思。「或說」以下，顯發具體行相。「說地獄」是指濫用神聖教法威嚇，「王官」是指倚仗豪強官府勢力。「如」以下，引論為證。

【譯文】【記文】第五種心相，文義淺顯易懂。

【495-0006】02_戒疏/07b_卷二上之三#52
【原文】【疏】又變此心云「五種取」者，「取」是其業，對境行事也。
【譯文】【疏文】：又將這內在的心念轉化為外在事相而說為「五種奪取方式（五種取）」，所謂「取」就是具體的造作行動，是面對境界時所進行的事態作為。

【495-0007】02_戒疏/07b_卷二上之三#53
【原文】【記】次釋五取，標簡中。前五約心，不出三毒。若就通說，莫非希物，五並貪心。若約別論，如文乃異：初二及四，並是癡心，三即瞋心，五是貪心。又前五種，外相非盜，故約心論；後之五種，內外俱盜，故從外事。
【譯文】【記文】其次解釋五種取相，在標示簡別的科判中。前五種是就心念來說，總歸離不開貪瞋癡三毒。如果通泛地講，全都是為了圖謀財物，五種全屬於貪心。如果分開來辨析，文理各有不同：第一、第二及第四種，全屬於愚癡心；第三種屬於瞋恨心；第五種屬於貪心。又因為前五種心在表面外相上看起來不像行盜，所以專就內心來論斷；後面的五種取相，則是內心與外相都具備盜相，所以依循外在的事相來判斷。

【譯文】【疏文】：所說的「決意奪取（決定取）」，是指心思意慮已經篤定，勢必如期奪得，所以這樣說。

【495-0009】02_戒疏/07b_卷二上之三#55

【495-0013】02_戒疏/07b_卷二上之三#59
【原文】【記】第二引《十誦》文。「輕慢」，謂倨傲；「抵突」，謂觸犯。四中，「慢藏」，謂不勤收舉；「陽作」，謂詐作餘事；「陰伏」，即潛藏他物。五中二相，「假名德」，則通自他；「恃親友」，則唯在於他。「形勝」，謂位貌過人者，如王、臣、貴族等。
【譯文】【記文】在第二種取相中引用了《十誦律》的文字。「輕慢」是指倨傲無禮；「抵突」是指頂撞冒犯。在第四種取相中，「慢藏」是指不勤於收拾收存；「陽作」是指偽裝做其他事情；「陰伏」是指暗中隱匿他人物品。在第五種取相中有兩種形態：「假借名德」則通於自身或他人；「依恃親友」則專指仰仗他人。「形勝」是指地位門第或相貌超越常人的人，例如君王、顯貴官員、豪門貴族等。

【495-0014】02_戒疏/07b_卷二上之三#60
【原文】【疏】餘注云「或依親友」下，《律》中，隨諸相下，皆引此言。當今季世，多弊斯犯，故聖制有以也。文相易耳。
【譯文】【疏文】：隨文注後文所說的「或者依仗親友」以下，《四分律》中在每一種盜竊行相之下，都引用了這段話。當今末法時代，多數人都陷溺於這類違犯之中，所以佛陀立下戒律是有其深刻緣由的。文句的意涵顯而易見。

【原文】【記】餘相中。初示律文。《律》列物處，十三種別，一一處後，皆出此二相。「當」下，顯制意。「弊」，猶滯也。下句點文，以其事顯，不勞釋故。
【譯文】【記文】在解釋其餘行相的科判中。首先提示律文。《四分律》列出了物品處所共有十三種差異，每一處之後，都附帶提出了這兩種行相。「當今」以下，顯明立戒的用意。「弊」等同於滯留、陷溺。最後一句指點文意，因為事情很淺顯，不需要多作贅述解釋。

【495-0017】02_戒疏/07b_卷二上之三#63
【原文】【疏】文言「隨不與取法」者，結罪分齊，釋成重相也。「不與取」者，犯名也。「法」者，盜刑也。滿五便入死位，故是「法」攝。謂比丘行盜，準此以判，故言「隨」也。
【譯文】【疏文】：律文說「依照不與取之法」，是用來斷定結罪的界限標準，藉以闡明構成不可悔重罪的罪相。「不與取」是這個罪名的稱謂。「法」是指國法中懲辦盜賊的刑罰。盜竊財物滿了五個錢就列入死罪的層級，所以屬於「國法」所管轄的範疇。意思是比丘行竊，應當參照這個標準來判定，所以說「依照（隨）」。

【495-0018】02_戒疏/07b_卷二上之三#64
【原文】【記】三中，釋文。初總示，「不」下，牒釋。初釋「不與取」，次釋「法」義，「謂」下，釋「隨」義。「準此判」者，即準國家滿五入死之法。
【譯文】【記文】在第三個科判中，解釋律文。首先整體提示；「不與」以下，依文句逐一解釋。先解釋「不與取」，其次解釋「法」的涵義；「謂」以下，解釋「依照（隨）」的涵義。「依照這個標準來判定」，就是參照國家法令中盜竊滿五錢判處死刑的法規。

【495-0019】02_戒疏/07b_卷二上之三#65
【原文】【註】以王立法「若取五錢，若直五錢物，罪應至死」，佛隨王法，盜滿制重也。
【譯文】【註文】：這是因為依照國王的法令「如果偷取五個錢，或者偷取值五個錢的財物，罪行應當判處死刑」，佛陀便順應王法的標準，制定了盜竊滿五錢即結犯不可悔重罪。
