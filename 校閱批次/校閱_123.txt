# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【123-0001】02_戒疏/05c_卷二上之一#79
【原文】【記】犯相，呵意中。初牒問。「欲」下，釋通，又二。初約察知前後釋。「三達」等者，明佛非不先知。化物之相，示同後知。「三達」，《智論》云：「過去、未來、現在，此三種智，通達無礙故。」、「又」下，次約勸誡前後釋。初示聖意難測。謂其堅不可鑽研，其高不可仰視，故云「絕」也。「今」下，約義以求。初敘比丘呵。「後」下，明佛呵。「玄軌」，即所制戒法。「高範」，即佛之所行。「切磋」，喻規諫短失。此謂朋儔職在諫諭，師長主乎教誨。若不先呵，直爾白佛，顯同友無相成之義。律緣世相，法爾須然。上約立教須後。「亦」下，次明彰前故後。「餘」下，略指。上句略去餘說，下句指後例同。以下諸戒，多有二呵，大同此釋。
【譯文】【記文】在辨明犯相中呵責用意的段落。首先提出問題。「欲顯」以下進行解答會通，又分兩層意思。第一是依據察知時間的先後來解釋。「三達」等句，說明佛陀並非不能先知，但在化導眾生的外相上，示現如同常人般在同儕反映後才處理。「三達」，《大智度論》說：「對過去、未來、現在，具備這三種圓滿智慧，能夠通達無礙。」「又解」以下，接著從勸諫教誡的角度來解釋。前半段說明聖者的心意深不可測。如同堅硬之物無法鑽研，高山無法一眼望盡，所以說是「絕於鑽仰」。「今為」以下從事理的意義來探究。先說明同修比丘的呵責。「後明」以下說明佛陀的呵斥。「玄軌」就是佛陀所制定的戒律法則。「高範」就是佛陀本身的聖者行儀。「切磋」比喻互相規勸提醒缺失。這是說明同儕道友的職責在於勸導告誡，師長與佛陀則主持根本教誨。如果不先由同修呵責，直接跑去向佛稟告，就顯得道友之間缺乏互相成就勉勵的道義。戒律的緣起必須合乎世間人情事理，法爾如是自然應當如此。以上是從確立戒教必須置於最後來論述。「亦彰」以下進一步說明佛的呵斥是為了彰顯前面同修呵責的正確性。「餘語」以下略過不提。上一句是略去其餘紛紜的說法，下一句是指明後文各戒皆依此類推。以下各條戒多有兩次呵責，大體都符合這種解釋。

【123-0003】02_戒疏/05c_卷二上之一#81
【原文】【疏】初中，「於如來清淨法」者，略教法也。略教法意，總舉行體，莫非喪苦集，求滅道也。言「於欲無欲」者，思前貪境，名之為「欲」，察知妄起，名「無欲」也。言「斷渴愛」者，思後重貪，追境不捨如「渴」也。觀如此渴，非由境生，但是自心，如犬咬骨，故能斷也。此二集諦，世結之因。「破壞巢窟」者，世結果也。集因既傾，苦果自滅，故曰也。「除眾結縛」者，修道法也。「愛盡涅槃」者，證滅諦也。「乃作惡事」者，總結前辭以用訶也。
【譯文】【疏文】在第一部分中，「在如來的清淨教法中」，指的是佛陀最初所宣說的簡略戒教法門。略示戒教的意旨，是總括標舉修行的體系，無非是滅除苦諦與集諦，以求證滅諦與修持道諦。所謂「於愛欲中心無愛欲」，回思先前引發貪愛的境界，就稱作「欲」；覺察觀照到妄念生起而能自拔，就稱作「無欲」。所謂「斷除渴愛」，回思後續滋生的強烈貪戀，追逐外境不肯捨離，就像飢渴一樣，稱為「渴」。觀照到這種飢渴之感並非是由外境所產生，純粹是自己的妄心在作祟，就像狗啃乾骨頭自以為有肉味一樣，明白了這個道理就能夠斷除了。這兩句屬於苦集二諦中的「集諦」，是繫縛世間生死的根源。所謂「破除輪迴的巢穴」，指的是世間的苦果。招感苦難的集因既然已經被摧毀，痛苦的果報自然跟著熄滅，所以這樣說。所謂「消除一切煩惱纏縛」，是指修習出世聖道之法（道諦）。所謂「貪愛永盡的涅槃」，是指證悟清淨寂滅之理（滅諦）。所謂「竟然做出這種惡事」，是總結前面的言詞來予以深切責備。

【123-0004】02_戒疏/05c_卷二上之一#82
【原文】【記】弟子，呵詞。初釋總舉者，總四諦故。略教一偈半，初一偈「喪苦集」，後半偈「求滅道」。「言」下，釋別相，別配四諦故。文有五句。初釋前二句。上句始起貪。「境」即五塵，「欲」即五識。下句相續貪。二皆有出過、對治二門，「欲」、「愛」是過，「無」、「斷」即治。此中治法至要，用意深思。如何思邪？因言得理，以理觀念。見念隨塵，取塵為欲，欲熾為愛。諦觀欲愛所生所在，然後可治。此乃心行，何由盡言？聞而不思，徒多何益？「世結」者，即三界繫。「破」下，釋第三句。「巢窟」，喻六道依正。苦不假斷，故云「自滅」。《經》云「苦若滅者，即是因滅，因滅故果滅」是也。「除」下，釋第四句。「眾結」，總收業惑。「道法」，不出三學、八正。「愛」下，釋第五句。「涅槃」，即眾結盡處，所證空理。「乃」下，釋總結。
【譯文】【記文】在門徒比丘的呵斥言詞中。首先解釋總括標舉的文句，因為它涵蓋了苦、集、滅、道四聖諦。略教偈頌有一偈半，前面一偈是「滅除苦集」，後半偈是「求證滅道」。「言於欲」以下分別解釋各句行相，分別配對四聖諦。文中共有五句。首先解釋前兩句。上一句是指初起的微細貪心。「境」是指色聲香味觸五塵，「欲」是指受引誘的眼耳鼻舌身五識。下一句是指相續生起的粗重貪愛。兩句都包含揭露過失與施予對治這兩個層面，「欲」與「愛」是過失，「無」與「斷」就是對治。這裡面的對治方法最為緊要，應當用心深思。如何深思呢？透過語言理解義理，依憑義理觀照念頭。察見妄念順著塵境奔馳，執取外塵生起愛欲，愛欲熾盛轉為貪愛渴求。審慎觀察貪愛究竟從何而生、究竟落於何處，然後才能予以對治。這是內心的觀照實踐，哪裡是用語言能說得盡的？如果聽聞之後不去思維修證，就算知道再多又有什麼益處？所謂「世結」，就是指三界的一切繫縛。「破壞」以下解釋第三句。「巢窟」比喻六道輪迴中的依報環境與正報身軀。痛苦的果報本來不需要刻意去斷除，因斷了果自然就熄滅，所以說是「自滅」。佛經說「苦果若能熄滅，正是因為苦因已經熄滅，因滅故果滅」，就是這個意思。「除眾」以下解釋第四句。「眾結」總括了一切業障與煩惱惑。「道法」不超出戒定慧三學與八正道。「愛盡」以下解釋第五句。「涅槃」就是一切煩惱繫縛完全斷盡之處，所證得的真如空性之理。「乃作」以下解釋最後的總結責備。

【123-0008】02_戒疏/05c_卷二上之一#86
【原文】【疏】就初「集僧」，《多論》五意：「一、現佛不自專輙故；二、眾量結戒，犯者心伏故；三、凡事眾和，令法久住故；四、為肅將來，倣佛成規，眾量不專故；五、諸佛法爾，於法有儀故。」
【譯文】【疏文】就第一項「召集僧眾」而言，《薩婆多論》提出了五種深意：「一、顯明佛陀不自作主張、獨斷專行；二、透過大眾共同商量結集戒律，使犯戒者心服口服；三、凡事依賴僧團和合決定，能使正法長久住世；四、為了整肅未來的秩序，讓後人效法佛陀樹立的規範，凡事由大眾公議而不專斷；五、這是過去諸佛法爾如是的通例，於戒法處分上本有威儀制度。」

【123-0009】02_戒疏/05c_卷二上之一#87
【原文】【記】釋佛呵，集僧中。《論》約五義，求佛本懷，成濟弘遠，不專一事故也。
【譯文】【記文】在解釋佛陀呵責、召集僧眾的段落中。該論依據五種深廣的義理，來探求佛陀內心的本懷，這是為了成就深遠廣大的化度事業，絕非單純處理眼前一件事而已。

【123-0010】02_戒疏/05c_卷二上之一#88
【原文】【疏】言「知時義合」者，量機教也。
【譯文】【疏文】經文說「知時義合」，是指審查弟子的根機與教化的時機是否契合。

【123-0011】02_戒疏/05c_卷二上之一#89
【原文】【記】次科，總釋中。知時是「量機」，義合即「量教」。
【譯文】【記文】第二段科判、總相解釋之中。「知時」就是審查受教者的根機；「義合」就是審酌教法的時機與功用。

【123-0012】02_戒疏/05c_卷二上之一#90
【原文】【疏】問：「如來明見，知犯非虗，有何義故，不證他犯？」
【譯文】【疏文】提問：「如來具有洞照一切的明徹知見，明知犯戒之事絕非虛假，到底有什麼理由，不直接出面指證他的罪過呢？」

【123-0013】02_戒疏/05c_卷二上之一#91
【原文】【疏】《多論》解云：「有四種過：一、不順諸佛常法；二、違自言治法；三、令眾生怖，不安之相；四、逆說人過，非大人體。」是以商度，故名為「知」。
【譯文】【疏文】《薩婆多論》解釋說：「隨意直接定罪有四種過患：第一、違背了十方諸佛一貫的教化常法；第二、違背了僧團必須依照嫌犯自己親口招認才能治罪的法規；第三、會引發眾生恐懼，造成僧團不安的氣氛；四、主動直接揭發別人的隱私過失，並非偉大聖者的大人風範。」因此佛陀必須審慎衡量思慮，所以稱之為「知」。

【123-0014】02_戒疏/05c_卷二上之一#92
【原文】【疏】所言「時」者，《多論》解云：「要在比丘眾集時問，二、結廣時問。反此不問。」
【譯文】【疏文】至於所謂的「時」，《薩婆多論》解釋說：「其一、必須在全體比丘大眾集會時審問；其二、必須在準備制定廣大詳細戒規的時機成熟時審問。不符合這兩個條件就不會審問。」

【123-0015】02_戒疏/05c_卷二上之一#93
【原文】【記】別釋，知時中。初立問徵意，佛既先知，不當取彼自言故。「多」下，次引論以釋。初釋「知」字。「四過」中：初謂佛佛皆爾；二謂如來於滅諍中，制取自言；三是安眾；四現尊相。「所」下，次釋「時」字。《論》解二義：「眾集」，即約人明時；「結廣」，即從教明時。
【譯文】【記文】在分別解釋「知時」的段落中。首先提出問題探究原由，認為佛陀既然早就洞悉一切，就不應當還非要取得對方的自白不可。「多論」以下引用論典來作解釋。首先解釋「知」這個字。「四種過失」之中：第一是指歷代諸佛皆是如此行事；第二是指如來在七滅諍法中，親自制定必須「取自言治」的原則；第三是為了安撫大眾情緒；第四是為了示現佛陀崇高的威德身分。「所言時」以下接著解釋「時」字。《薩婆多論》解釋了兩重涵義：「眾集」是就集會的人數與因緣來說明時機；「結廣」則是從教法制度的完備來界定時機。

【123-0016】02_戒疏/05c_卷二上之一#94
【原文】【疏】雖復機起，深應於時。若訶責制戒，不能滅惡生善，亦不宜問。以是次明「知時義合」。若非此義，不合故問。如《多論》解：「以制戒故，有四種益：一、先作無犯，得除憂惱；乃至第四，十利功德。」如上說也。
【譯文】【疏文】雖然受教的因緣已經引發，也深深合乎時機，但如果呵斥與制戒並不能達到「滅惡生善」的實質效果，那也不適宜審問處置。因此經文接著說明「知時義合」。如果不是符合這個標準，就不相合，佛陀便不會提問處理。正如《薩婆多論》所解釋的：「因為制定這條戒律，能帶來四種利益：第一、使在制戒之前犯過的人免除犯罪負擔，得以消除內心的憂愁與煩惱；乃至第四、具足成就十種殊勝功德。」這就如同上文所說明的那樣。

【123-0017】02_戒疏/05c_卷二上之一#95
【原文】【記】釋義合中。初躡前，「若」下，正釋。初敘非義，「以」下，明是義。然制戒之義，有總有別。別即隨戒，制意不同，總則無非滅惡生善。今釋「義合」，且就總論。「合」，猶當也。「如」下，引證。文見制意，故略二、三。「除憂」，止非、決疑，並「滅惡」義。「十利」，即「生善」義。
【譯文】【記文】在解釋「義合」的段落中。首先承接前面的論述，「若訶責」以下進行正式解釋。前半段說明不合的情形，「是以」以下闡明符合的意義。然而制戒的意義，有總體原則與個別目的。個別是指隨著每一條戒，制定的由來目的各不相同；總體則無非都是為了滅除惡業、生發善法。現在解釋「義合」，暫且從整體的原則來論述。「合」就是應當、適宜的意思。「如多論」以下引用論典為證。律文中列出了制戒的目的，所以省略了中間的第二與第三條。「除憂」包含止息非行、斷決疑惑，都屬於「滅惡」的範疇；「十利」則完全屬於「生善」的範疇。

【123-0018】02_戒疏/05c_卷二上之一#96
【原文】【疏】光律師云：「『知』者，藥病之差；『時』者，應機之趣；『義合』，修成契會為要。」大如上也。
【譯文】【疏文】慧光律師說：「『知』是指洞悉藥劑與病症的差別；『時』是指契合機緣的趨向；『義合』是指修持後能切實獲得實益作為要歸。」大體意思如同前面的解釋。

【123-0019】02_戒疏/05c_卷二上之一#97
【原文】【記】古解中。「差」，謂差別。「趣」，即趣向。「修成契會」，謂令他獲益。語異意同，故云「如上」。
【譯文】【記文】在古德的解釋中。「差」是指千差萬別的病情。「趣」是指教化的方向歸宿。「修成契會」是指能讓對方得到出世解脫的實益。雖然用語不同，精神卻完全一致，所以說「大如上」。

【123-0020】02_戒疏/05c_卷二上之一#98
【原文】【疏】三、「取自言」者。如《五分》云：「五百金剛常隨侍衛，若佛三問，不如實答，便杵碎頭以為七分。」情怖故答。
