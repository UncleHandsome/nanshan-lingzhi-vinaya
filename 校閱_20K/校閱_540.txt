# 校閱材料　第540檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【540-0001】資持記/07d_中一下#43
【原文】注中，準負債人，以決世疑；疑謂度王稅人，出家成犯盜故。如〈受戒篇〉說。盜奴重者，主為守親故。次科，前引二律。開意大同。守邏者，舊云遊兵禦𡨥者。所以下，徵上《十誦》之意。所盜物中，論文，初標示廣相。且下，次約塵界統收，初明六塵。三業成盜，名不如法行。食毒等相，如下疏解。
【譯文】注文中，比照負債之人的例子，來決斷世人的疑慮；世人懷疑剃度逃避官府賦稅之人出家會構成犯盜戒。正如〈受戒篇〉中所說。偷盜奴婢罪過極重，是因為主人即是其守護親屬。下一科前面引用兩部戒律。開許的意旨大致相同。所謂「守邏」，古人說是防禦寇賊的巡遊衛兵。接著「所以」以下，追究上述《十誦律》的深意。在「被盜之物」中，論典文句起初標明展示廣泛相狀。接著「暫且」以下，其次依照六塵與六界總攝概括，起初說明六塵。身口意三業構成偷盜，稱為「不如法行」。偷食毒藥等相狀，正如戒疏後文的解釋。

【540-0002】資持記/07d_中一下#44
【原文】螫，音釋，虫行毒也。若人下，次明六界。疏解，初六塵中，前標所盜。胸行者，謂蛇以胸當前而行；毒藥者，一切害人命者；謂諸仙人，能治上二毒，故號為師。作下，列示盜相；初至亦爾，眼盜色也。書字者，如今之符籙。若誦下，耳盜聲也。偷下，略指三塵。類上說之。若祕下，意盜法也。
【譯文】「螫」，音釋，是指毒蟲爬行時噬咬下毒。接著「若人」以下，其次說明六界。戒疏解釋中，起初在六塵之內，前面標明所盜的對象。「胸行」，是指毒蛇挺著胸部向前爬行；毒藥，是指一切危害人命之物；諸位仙人能夠醫治上述兩種毒性，所以被稱為大師。接著「作」字以下，列舉說明偷盜的相狀；從開頭到「亦爾」句為止，是眼睛偷盜色塵。所謂「書寫文字」，就如同現今的符咒圖籙。接著「若是背誦」以下，是耳朵偷盜聲塵。接著「偷」以下，簡略指出其餘三塵。可依上述類推說明。接著「若祕密」以下，是意根偷盜法塵。

【540-0003】資持記/07d_中一下#45
【原文】六界中，前三易解，故不出之。有下，盜風。若下，盜空。論下，明盜識。注云智用者，伎倆藝術，並依識起，則簡識體非可盜故。三結指中，初示廣。但下，舉要統收。廣下，指略。文在第二，彼隨文釋，顯相極繁；須者尋之，不復重引也。非人物中，初文，先定犯。《五分》下，引二律以證。
【譯文】在六界之中，前三種容易理解，所以不再列出。接著「有」以下，是偷盜風界。接著「若」以下，是偷盜空界。接著「論」以下，說明偷盜識界。注文所說「智用」，是指技巧手藝各類才藝，全都是依憑識心生起，藉此揀除心識本體並非可以偷盜之物。第三結語指引中，起初顯示廣泛內容。接著「但」以下，列舉綱要總括統攝。接著「廣」以下，指明簡略之處。文句詳見於卷二，那裡隨文釋義，顯示的相狀極其繁雜；有需要的人自行去探尋，此處不再重複引述。在「非人物產」中，最初文句先判定犯罪。接著「五分」以下，引用兩部戒律作證。

【540-0004】資持記/07d_中一下#46
【原文】他護他心，並顯護主。《僧祇》文漫，但約結重，可驗有主。無護中，初科，上二句定犯。言隨境者，望非人犯也。故下，引示有三。《十誦》、《多論》，示相可解。《善見》無罪，故加註釋。次科。當時有行糞掃衣者，故有取之。得不如上者，即前所明有主無主；又無主中，神護不護。必下，示其取法。
【譯文】「他護」與「他心」，都顯現出有守護的主人。《僧祇律》文意簡略，但從判定重罪這點，即可證驗是有主人的。在無人守護的情況中，最初一科，上面兩句判定罪名。所謂「隨其境界」，是指對著非人構成犯罪。接著「所以」以下，引導告示有三處。《十誦律》與《薩婆多論》所顯現的相狀容易理解。《善見論》說沒有罪過，所以特別加以注釋。下一科中，當時有人修持「糞掃衣」的苦行，所以有人會去撿取。到底算不算犯戒正如上文所說，也就是前面說明的有主還是無主；又在無主之中，神明守護還是不守護。接著「必定」以下，指出其拿取的方法。

【540-0005】資持記/07d_中一下#47
【原文】擲卜，即投杯珓，卜問於神也。捨吝，謂非人護不護也。畜物中，初文。律中，比丘取鳥巢中物，及鼠穴中物，比丘疑，佛言：畜生無用，無犯，而不應受如是物。〔準不應，得吉，但文不顯。〕引古中，初解，上句判犯。故下，引據。律云：時去寺不遠有村，諸鼠往村中，取胡桃來寺內，成大聚；
【譯文】「擲卜」，就是投擲杯珓，占卜叩問神明。「捨吝」，是指非人願意捨棄還是吝嗇守護。在「畜生物產」中，最初文句。戒律中，比丘拿取鳥巢中的物品，以及老鼠洞穴中的物品，比丘心生懷疑，佛陀說：畜生無法受用，不犯重罪，但不應該接納這類物品。〔依準「不應該」這一點，應得突吉羅罪，只是文句沒有明說。〕引證古說中，最初的解釋，上一句判定罪名。接著「所以」以下，引用依據。戒律說：當時離寺院不遠處有一座村莊，諸多老鼠跑到村中，將核桃搬進寺院裡，積聚成一大堆；

【540-0006】資持記/07d_中一下#48
【原文】六群盜心取食，彼疑；佛言：波羅夷。正解中，初通本律犯重之意。以言六群盜心取故，顯知是彼村人之物，故判成重。鼠疑豫者，畜心難辨；但約未藏，或復未食，可以知耳。餘下，引他部定犯。《十誦》中：師子殘不犯者，舊云：此獸不食冷肉，所遺不繫故。第二緣中。律有四句：有主想犯重〔初句〕；
【譯文】六群比丘存著偷盜之心拿來吃，事後懷疑；佛陀說：犯波羅夷罪。正統解釋中，起初通達本律判定重罪的深意。因為說六群比丘是存著「盜心」去拿取，顯然知道那些核桃是村裡人的財物，所以判定構成重罪。至於老鼠猶豫不決，是因為畜生的心思難以辨識；只能從未曾藏妥、或是尚未食用的跡象，來加以推知罷了。接著「其餘」以下，引用其他部派戒律判定罪名。《十誦律》中說：吃獅子殘食不犯戒，古人解釋說：這種野獸不吃冷肉，所遺留下來的肉已經不再心生繫著。第二種因緣中，戒律包含四句：認定有主而取犯重罪〔第一句〕；

【540-0007】資持記/07d_中一下#49
【原文】若疑偷蘭〔次句〕；無主物，有主想疑偷蘭〔三四兩句〕；略無第三無主想句；準下〈持犯〉，義必具之。文中，初標成犯緣，即第一句。若下，簡闕緣，即第三句，初約本迷無犯。前下，據轉想。前作有主想，後轉無主，犯蘭；前作無主想，後轉有主，結夷，故云互得輕重也。疑及境差二句，並見後篇。
【譯文】如果心中懷疑犯偷蘭遮〔第二句〕；無主之物，認定有主或心存懷疑犯偷蘭遮〔第三與第四句〕；文中略去了第三種「認定無主」的文句；依準下文〈持犯篇〉，義理上必須具備此句。文句中，起初標明構成犯罪的因緣，就是第一句。接著「若」字以下，揀選缺少因緣的情況，也就是第三句，起初是就原本誤認而判不犯。接著「前」字以下，依據念頭轉換來判定。先前認定為有主，後來轉變為無主，犯偷蘭遮；先前認定為無主，後來轉變為有主，判定犯波羅夷，所以說「互為輕重之罪」。懷疑以及境界有差錯這兩句，都見於後面的篇章。

【540-0008】資持記/07d_中一下#50
【原文】第三緣，敘意中，初明難護。以貪染積深，觸物起念；麁心不覺，豈識邪緣；不體妄情，終羅罪網；實德尚當未免，庸流沒在其中；凡在同心，彌須勵志。但下，示結業。不望境是非者，境即前物；三寶互用，物無私涉為是，入己惡用為非；二皆結重，故知不簡也。故下，引證。
