# 校閱材料　第273檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【273-0001】03_業疏/16a_卷三之五#32
【原文】三、舉因果中，先知來意。眾生識體本自清淨，離諸塵染，由妄想故，翻成煩惱；又復本來自在，具足方便智慧威神德用，由妄相故，翻成結業；又復本來平等，無有彼此愛憎差別，由妄想故，翻成生死。今欲反本，故立三誓：一者、斷惡誓，受攝律儀戒，修離染行，趣無作解脫門，復本清淨，證法身佛，名為斷德；二者、立修善誓，受攝善法戒，修方便行，趣空解脫門，復本自在，證報身佛，名為智德；三者、立度眾生誓，受攝眾生戒，修慈悲行，趣無相解脫門，復本平等，證應身佛，名為恩德。然此三誓、三戒、三行、三脫、三佛、三德，隨舉一誓，三誓具足，乃至三身、三德，一一皆爾。言有前後，理無各別。如是心受，即發圓體；如是心持，即成圓行。《華嚴》云「戒為無上菩提本」，《淨名》云「能如此者是名奉律」，《涅槃》云「欲見佛性，證大涅槃，當須持戒」等，皆此意也。初科初句召今受者；次句勸令思修。「此行」謂白四所受聲聞戒也，此二句該下三聚。初攝律儀又二：初標因果。「即」之一字，點小為大，乃是圓宗融會之意。《智論》以八十誦即尸羅波羅蜜，《勝鬘》謂毗尼即大乘學，須得此意，可通彼文。律儀禁惡，止業破惑，徹至究竟。「清淨心」者，即法身體。「以」下次明所以。初二句敘昔迷，不明淨者，貪染所障，失本淨故；次二句顯今悟，須修顯者，稟戒破障，即能顯之因，法身即所顯之果
【譯文】第三、「舉因果」這部分中，首先應當明了其用意由來。眾生的識體本來清淨，遠離一切塵垢染污，但由於妄想的緣故，反而轉變成了煩惱；又本來自在，具足善巧方便的智慧、威德與神通力用，但由於妄相的緣故，反而轉變成了結業；又本來平等，沒有彼此與愛憎的差別，但由於妄想的緣故，反而轉變成了生死輪迴。如今想要返本還源，所以立下三種誓願：第一是斷惡誓，受持攝律儀戒，修習離染之行，趣向無作（無願）解脫門，回復本有的清淨，證得法身佛，稱為斷德；第二是立修善誓，受持攝善法戒，修習方便之行，趣向空解脫門，回復本有的自在，證得報身佛，稱為智德；第三是立度眾生誓，受持攝眾生戒，修習慈悲之行，趣向無相解脫門，回復本有的平等，證得應身佛，稱為恩德。然而這三誓、三戒、三行、三解脫門、三身佛、三德，隨便舉出一誓，三誓便全然具足，乃至三身、三德，一一也都是如此。言詞上雖有前後之分，理體上卻無各自分隔。以此種心來納受，便發起圓滿的戒體；以此種心來持守，便成就圓滿的戒行。《華嚴經》說「戒為無上菩提本」，《維摩詰經》（淨名）說「能如此者是名奉律」，《涅槃經》說「欲見佛性，證大涅槃，當須持戒」等，都是這個意思。第一科的第一句是呼召當今的受戒者；第二句是勸勉令其思惟修習。「此行」是指透過白四羯磨所受的聲聞戒，這兩句涵蓋了下文的三聚淨戒。第一種「攝律儀戒」中又分為兩部分：首先標明因與果。「即」這一個字，點化小乘為大乘，正是圓教融會之意。《大智度論》認為八十誦律即是尸羅波羅蜜，《勝鬘經》說毗尼即是大乘之學，必須體會這個深意，才能通達那些經文。律儀能禁制惡行，止息惡業並破除惑障，一直通達究竟。「清淨心」，就是法身之體。自「以」字以下，接著說明其所以然。前兩句敘述過去的迷妄，所謂「不明淨」，是因為被貪染所障蔽，喪失了本有的清淨；後兩句顯明如今的覺悟，所謂「須修顯」，受持戒法以破除障礙，就是能顯發法身的因，法身就是所顯發的果。

【273-0002】03_業疏/16a_卷三之五#33
【原文】以妄覆真，絕於智用，故勤觀察，大智由生，即攝善法，名報身佛
【譯文】因為以妄相覆蔽真性，斷絕了智慧的妙用，所以應當精勤觀察，大智慧便由此生起，這就是攝善法戒，名為報身佛。

【273-0003】03_業疏/16a_卷三之五#34
【原文】二、明攝善法。初二句敘迷，絕智用者，愚癡所障，遺本明故；「故」下顯悟，勤觀察者，修善破障，此即是因，報佛是果
【譯文】第二、說明攝善法戒。前兩句敘述迷妄，所謂「斷絕智用」，是被愚癡所障蔽，遺失了本有的光明；自「故」字以下顯明覺悟，所謂「精勤觀察」，是指修習善法以破除障礙，這就是因，報身佛就是果。

【273-0004】03_業疏/16a_卷三之五#35
【原文】以妄覆真，妄緣憎愛，故有彼我生死輪轉。今返妄源，知生心起，不妄違惱，將護前生，是則名為攝眾生戒。生通無量，心護亦爾。能熏藏本為化身佛，隨彼心起，無往不應，猶如水月，任機大小
【譯文】因為以妄相覆蔽真性，妄自攀緣愛憎，所以有了彼此人我與生死輪轉。如今返歸妄想之源，了知眾生皆由心所生起，不妄自違逆惱害，善加護念眼前的眾生，這就名為攝眾生戒。眾生通於無量無邊，內心護念也是如此。這能熏發本識（阿賴耶識）之根本而成化身佛，隨順眾生之心而生起，無處不相感應，就像水中的月影一樣，任憑根機的大小而隨機顯現。

【273-0005】03_業疏/16a_卷三之五#36
【原文】三、明攝眾生，亦名饒益有情。初敘迷，憎愛即障，忘本平等故；由有彼我分別故，受生死雜報。「今」下顯悟。初二句開平等解，知生心起，亦唯識變，彼我同體，無高下故；次二句修平等行，將護之言，通含四弘誓、四等心、四攝行。「是」下二句結名，上是修因。「生通」下即感果。初二句心境相應；次二句慈熏成果；次四句明隨緣起應。「如水月」者，水喻機感，月喻埀應，月不入水，水不溷月，隨器大小，波澄影現，慈善根力，感應難思。問：三聚、三身，為同為別？答：語異義一。隨舉一戒，三聚具足；隨舉一聚，互具亦然。故知初受圓發三誓，隨中奉持圓修三行，成因感果，圓證三身。三誓即是三聚、三身，三聚亦即三身、三誓，三身亦即三誓、三聚。心佛無差，因果不二。能如此者，始名圓戒，是波羅蜜，即究竟木叉也。是知行人若發此心、若獲此體，當知即是三佛之種，如何自輕，不加珍敬？然雖三戒彼此互具，至於修奉，恒用攝生，則能任運含攝一切，豈止餘聚耶？問：教有分齊，何須此示？答：為成本宗分通義故。何以然耶？如前善戒，五、十、具等迭為方便，是故受五習十、受十習具、受具習大，故前三戒並名方便。假宗知權，不住方便，符通深之部意，為稟大之先容。所以《鈔》敘發心為成三聚，此明隨行次對三身，願行相扶，彼此交映。彼則期心後受，此乃即行前修，方見圓宗深有來致。若爾，既顯分通，何須別立？答：義雖通大，教終局小，不可濫通，故須別立。隨意盡理，不亂宗途。請觀前明實宗無一「心」字，次述假宗無一「種」字，始見聖師深體權實，自餘凡愚未足擬議也

【273-0011】03_業疏/16a_卷三之五#42
【原文】引證中，《百論》「罪福俱捨」是正教也，彼云「有漏淨福無常故尚應捨，何況雜罪」；「福為天持戒」，明求福之過，彼云「持戒有二：一者不淨，二者淨。何等不淨？謂持戒求樂報，一者生天，二者人中富貴。何等為淨？行者作念：一切善法，戒為根本；持戒則心不悔，心不悔則歡喜，歡喜則心樂，心樂則得一心，得一心則生實智，智生則得厭，得厭則離欲、得解脫，解脫則得涅槃，是名淨持戒」；《成論》但是畏罪，還無所詣，據彼為是，今引彰過；《佛藏》「我倒」即本惑，不為除惑，非求解脫。「故」下指廣者，彼喻蝙蝠入穴為鼠、飛空為鳥，既不入說恣僧眾不名出家，復不入王者役使不名白衣等，如《資持記》具引。今準《事鈔·持犯篇》四種分齊，可括諸文：一、賊分齊，即上名利諂詐等；二、罪分齊，即《成論》不樂為罪；三、福分齊，即《百論》為天持戒；四、道分齊，道通三乘，無非出離。前令返妄，下誡域心，必指佛道，是今分齊。
【譯文】在引證部分，《百論》的「罪福俱捨」是正統教義，該論說「有漏的純淨之福尚且因無常而應當捨棄，何況夾雜惡念的罪業」；「為天持戒」，說明求福的過失，該論說「持戒有兩種：一是不清淨，二是清淨。什麼是不清淨？是指持戒求取安樂果報，一是求生天上，二是求人間富貴。什麼是清淨？修行者作這樣的思惟：一切善法以戒為根本；持戒則內心不後悔，心不後悔則生歡喜，歡喜則身心安樂，心樂則得一心定境，得一心則生真實智慧，智慧生起則生起厭離，得厭離則能離欲並得解脫，解脫則得證涅槃，這名為清淨持戒」；《成實論》所說只不過是畏懼罪業，依舊無所歸趣，就該論立場而言固然是對的，如今引來則是為了彰顯其局限與過失；《佛藏經》所說的「我倒」就是根本惑，持戒若不是為了斷惑，就不是求解脫。自「故」字以下指明經文廣博呵責之處，經中比喻蝙蝠進入洞穴就假充老鼠，飛入空中就假充鳥兒，既不參與說戒自恣的僧眾因而不算真正出家，又不承擔國王的徭役因而不能稱為在俗白衣等，如《資持記》中所具體引述。如今依照《事鈔·持犯篇》中的四種分齊，可以概括諸多文句：第一是賊分齊，就是指上述為了名利而諂媚欺詐等；第二是罪分齊，就是《成實論》所說的不樂於造罪；第三是福分齊，就是《百論》所說的為了求生天而持戒；第四是道分齊，道通於聲聞、緣覺、菩薩三乘，無非是求出離。前面令人返妄歸真，下文告誡應當安立心意，必定是指向成佛之道，這就是本門（今家）的分齊。

【譯文】在接下來的問答中，為了彰顯業相，所以承接兩者看似混淆之處作為問端。在解答中，首先通體開示動念即造業。業體無非都是心，所以說「虛通」等；心念倏忽生起而無定，所以說「間雜（難）」。自「同時」以下文句，姑且舉出一緣來說明彼此交雜並起的情況。若是知道心念隨緣起滅、變動無常，那麼善惡邪正，或分離或聚合，一剎那間有萬千差異，哪裡止於此處所說的幾種呢！自「且」字以下分別列出，前面是把作俱列在最初，這裡歸入第五種，其餘都與前面相同，順著文句尋讀自能明了。問：隨動作而起業與隨施用而感業，兩者畢竟容易混淆，該如何區分？答：作俱通於一切境界，從用則局限於特定事物。由於具備了事物，或者使用、或者不用，因此在使用時必定同時兼具這兩種業。所以知道，作俱未必有從用，而從用則必定兼具作俱，無非都是具足了這兩種心，致使業力隨心而發起。然而下文的隨心業原本是依據禪定與智慧而論，這裡說惡念未絕，則是順應文義而引申說明罷了。自「故」字以下指明類例，上面說明八種業，姑且是依據全部具足而言，必須知道業的理趣隨著心念動態而無定準，所以說「知有無也」。況且如今受戒之體，最初具足了作俱、形俱同時生起，也有要期，必須戒師秉承羯磨法式這就是助緣，能牽引後來的修習這也就是隨心。若論及隨戒之行，作俱是必定有的；身口互造、教唆他人則是異緣與助緣；衣缽資具則是事在與從用；功德成就而不泯滅，無非都是隨心。像這樣類推列舉，其中具足多少自然可見。

【273-0050】03_業疏/16b_卷三之五#28
【原文】如《成論》云：有人言入定入道有禪無漏律儀，出定則無，是事云何？論云：出入常有，常不為惡，善心轉勝。何以然耶？有人計背支入本，背麤向細，得發無作；入支向麤，不發無作。今解不然，出入常有，雖在事亂，無作不失。今言隨心者，不隨定慧，隨生死心恒有無作，入無餘已則無業也。別脫不爾，隨形非心。故經云：「初果生惡國，道力無惡業」是矣
【譯文】正如《成實論》所說：有人說入定、入道時才有禪定律儀與無漏律儀，出定後就沒有了，這事究竟如何？論中說：無論出定入定都恆常存在，恆常不作惡事，善心轉而更加增勝。為什麼會這樣呢？有人執計違背枝末而契入根本、背離粗相而趣向細微，才能發起無作業；若契入枝末而趣向粗相，便不能發起無作業。如今解釋並非如此，出定入定都恆常存在，即使處於世俗紛擾的雜務中，無作業也不會喪失。現在所說的隨心，並非單指隨順定心慧心，而是隨逐生死心而恆常具有無作，直到進入無餘依涅槃之後才沒有業。別解脫戒則不是這樣，它是隨形命而立而非隨心。所以經中說：「證初果者生於邪惡之國，由道力的緣故而不起惡業」，就是這個道理。

【273-0051】03_業疏/16b_卷三之五#29
【原文】成論》四節：初、牒異宗以問；「論」下立義相反，出入常有者，不局入定入道也；「何」下重徵所以。初徵，「有」下釋，又二：初敘他計，背支入本等，戒禁身口為支，定慧治心為本，淨戒不住，故名背支，而得禪定，故云入本；背麤向細，如初禪為麤，二禪為細，乃至四禪四空，迭論麤細，次第漸深，以論背入；出定住戒為背本入支，出深住淺為背細向麤，入有出無，其相如此。「今」下示正義，又四：初破執；「今」下正釋，隨生死者，死此生彼恒不失故；「入」下示盡處，謂化火焚身，入無餘依涅槃，身淪空寂，此時方無，爾前恒有，故名隨心；「別」下揀別脫。「故」下引經證，即《涅槃》說初果生殺羊家，父令殺羊，乃牽羊與刀閉之一室，竟不肯殺以至自盡，此由宿生道定戒力，可證隨生死心也
