整體看下來，多數文句理解正確（能證／所證、師資位分、非學非無學法、四異、類知等都掌握得不錯），但有幾處**斷句錯誤**與**義理走樣**必須改，另有一批用語可以再精準。依輕重分列如下。

---

## 一、必須修正（會誤導讀者）

### 1. #92「佛弟子」斷句錯誤（兩處，最嚴重）
原文應讀作「若師教言**佛**，**弟子**不正而言弗者」／「若師教言**佛**，**弟子**答言爾」。
《記》文「弟子言弗，**師正資謬**」正是明證：師父教念「佛」，弟子音訛念成「弗」。譯文把「佛弟子」當成所教的詞句，整段意思全非。

建議改：
> 若師父教念「佛」，弟子發音不正而念成「弗」，仍成受三歸；若師徒二人都念成「弗」，則不成受。若師父教念「佛」，弟子卻只答「爾（是）」，或不出聲，或稱念不具足，都不成三歸。

### 2. #100「六道」與本文「五趣」自相矛盾
「六、對趣者」的「六」是**第六門**，不是六道；下文與《記》都明說「修羅徧在五道，故但云五趣」。
建議：「第六、對趣分別（就五趣眾生論能否受三歸）。」

### 3. #101 括注「（六道除去阿修羅或攝於五趣）」語意混亂
應作：「（阿修羅遍攝於五道，故不別開為六趣）」。

### 4. #87「欲明互倒何意不得？」譯成敘述句，問難語氣消失
這是**問者的質疑**：既然三寶同體無別，那次第顛倒為什麼不行？譯文「便想辨明為什麼念誦互換倒置就不成就」變成作者要說明理由，主客顛倒；且「互倒」指受歸時三寶次第顛倒，不限於「念誦」。
建議：「既然如此，那麼受三歸時三寶次第互相顛倒，為什麼不可以呢？」

### 5. #93「傖」的今音括注與反切不合
「仕衡反」上字仕（崇母）、下字衡（庚韻平聲），拼出來近 **chéng（ㄔㄥˊ）**，即《廣韻》助庚切一讀；今字典音 cāng 出自另一反切（千剛切）。逕注「（cāng）」與原文反切衝突。
建議：「音仕衡切（依反切當讀如『成』音；今字典別讀 cāng）」，或索性不加今音。

### 6. #98「損葉」疑為訛字，譯文逕改宜出註
《記》所引經喻作「譬如**樹葉**」，故「損葉」很可能是「樹葉」之訛。譯文直接作「樹葉轉變的比喻」雖合理，但屬校改，建議加註：「原作『損葉』，依下《記》所引疑為『樹葉』之訛。」

### 7. #102「別簡下趣」易被讀成「排除整個三惡趣」
實義是：這句**只針對下趣**而說（簡除其中報重者），因輕獄、鬼、畜仍可受。
建議：「『除報重者』是別就下趣（三惡道）加以簡除——簡掉其中罪報深重者，因人天二趣本自可受。」

## 二、義理／用語偏差（建議改）

| 段 | 譯文 | 問題與建議 |
|---|---|---|
| #87 | 「偏向自利」 | 「專自利」是**專於自利、唯求自利**，非「偏向」。 |
| #87 | 「簡別排除佛與僧皆屬於修證造作」 | 「簡異」是**區別**不是排除；「修證」加「造作」略帶貶義。改：「是為了區別於佛、僧二寶——二者皆是修證而成的有為功德。」 |
| #87 | 「就外相而論」 | 「相」指相狀／差別義，非「外表」。改「就相狀（差別）而論」。 |
| #87 | 「暫且就教理界限而言」 | 「教限」指**本教（四分小乘教）的分限**，宜點明。 |
| #87 | 「該論又說」 | 「彼論」宜依前文補出論名（前後多引《薩婆多論》，請核對出處後補註）。 |
| #90 | 「制定新律之後」 | 「制後」指**佛制（白四羯磨受具）之後**，「新律」語意含混。 |
| #90 | 「這難道不是循序漸進嗎」 | 「漸」在此是**少分、漸次而受**（帶貶義的問難），「循序漸進」是褒義成語，語感不合。改「難道不是可以少分、漸次而受嗎？」 |
| #90 | 「等等。」 | 原文「等」是等取餘文／餘難，白話單獨成句很怪，建議作「……等（此類問難）」或加註處理。 |
| #90 | 「增添法益」 | 「更增法」指重受而**增益戒法（戒體）**，「法益」偏離。 |
| #91 | 「寧可事後重新增益」 | 宜補足對比：「寧可（先具足受）之後再重受增益，不宜一開始就減少不具足。」 |
| #92 | 「北方傖地與南方吳地」 | 「傖」不是地名，是吳人對北方（中原）人的稱呼。改「如傖（北方人）、吳（南方人）語言風俗不同、彼此不能理解者」。 |
| #94 | 「三位法師」 | 此處是**授三歸的師父**，非講經法師，改「三位師父／三位授歸依師」。 |
| #96 | 「隨日期的多寡」 | 「隨日多少」是**日數長短**，非日期。 |
| #97 | 「該宗派」 | 可點明「彼（薩婆多）宗」，並略註五戒盡形壽、八戒一日一夜，讀者才懂「局時」。 |
| #99 | 「是唯恐懷疑期限滿了之後師弟的名義便斷絕」 | 中文不順。改：「因為恐怕有人懷疑：期限屆滿之後，為師之義（師徒關係）就斷絕了。」 |
| #101 | 「除了不通曉理解的人之外」 | 「除不解者」通五趣，不限於人，改「除了不能理解語義的眾生」。 |
| #101 | 「拘禁較輕的地獄眾生」 | 「輕繫」指**罪報較輕、繫縛較輕的地獄**（邊地獄、孤地獄之類），可略作說明。 |
| #102 | 「甄別」 | 「簡」是**簡除／排除**，「甄別」語意太中性，兩處建議改「簡除」。 |

## 三、處理得當、可保留

- #87「一體局大乘、理體通大小」「能證／所證」「師資位分」「非學非無學法（無為法）」——準確。
- #93「師質俱謬」判為「師資俱謬」並譯作師徒皆訛，處理正確（可加一字校註）。
- #93「若師下次」讀為「自『若師』以下，其次……」，斷句無誤。
- #98「故是師不」譯「仍然是師父嗎」，「故」作「還」解，正確。
- #99「樹葉之相雖然相異，但始終是同一片樹葉」，補「之相」得宜。
- #102「文舉輕獄，鬼畜類知」的推論關係譯得清楚。

## 四、體例建議

1. **「受」的譯法**：全篇作「領受／成就領受」略生硬，三歸語境宜統一作「成就受（三歸）」「得成三歸」，如 #88「不成受也」→「不能成就受歸」。
2. **訛字一律出註**（損葉／師質），避免讀者以為原文如此。
3. **反切與今音**要嘛不加，要嘛兩者並存並說明差异（見 #93）。
4. **引號補足**：#87 原文末缺下引號，譯文已補，可加校註一筆。
5. 「一語、二語」建議加短註（依《記》作受具解，重點在「少分而受」），讀者較易接上下文的「豈非漸耶」。

改動優先順序：**#92 斷句 → #100/#101 五趣 → #87 問難語氣 → #93 音注 → #98 校註 → #102 別簡下趣**，其餘屬潤飾層次。
