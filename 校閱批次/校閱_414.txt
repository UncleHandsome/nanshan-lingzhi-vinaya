# 校閱材料　第414檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【414-0001】資持記/03c_上二#62
【原文】兩結盜罪，並約知事。既下，明人多少。多則均之，少則留之。注決論文，豐必不爾。次若下，明受須均等。不得過分。下引律論，意亦同之。論中偏食，彼約眾僧偏與故輕；不病索食，正入盜科，兼復妄語，理得二罪。餘下，指經。
【譯文】這兩種情況都要結犯偷盜罪，這全都是針對主管僧事的知事人員而言。在「既」字以下，說明隨眾人人數多寡而調整。如果來集的人多就應當平均分派，如果來集的人少就應當留作後用。註文中決斷論點的意涵，物資豐裕時必定不至於如此緊繃。接著在「若」字以下，說明領受僧食必須絕對均等。絕對不得逾越分額私自多取。下文引述的律文與論典，意旨也與此完全相同。論典中提到的「偏私飲食」，那是針對全體僧眾共同偏袒給予特定人，所以罪名較輕；若是無病之人卻詐稱有病索求特設飲食，這就直接打入偷盜科條，同時又兼犯了妄語戒，在法理上當即招致兩重罪咎。在「餘」字以下，指示參閱相關經典。

【414-0002】資持記/03c_上二#63
【原文】彼說迦葉佛時比丘，為僧上座，不能禪誦，不解戒律，飽食熟睡，但能論說無益之語；精餚供養，先僧飲食；以是因緣，入地獄中作大肉瓮，火燒受苦，至今不息；彼經事廣，須者尋之。今時眾主，多有斯過；雖傳經律，不識因果；別修異饌，對眾獨飡；縱恣貪心，侵虧常住；豈念違於佛教，傷彼眾情。
【譯文】那部經記述迦葉佛時有一位比丘，身為僧團中的上座，卻無法靜坐禪修也無法諷誦經文，根本不通曉戒律條規，吃飽之後只管沉睡，開口便只能妄論世間無益的雜話；凡有精緻美好的佳餚供養，必定要搶先在全體眾僧之前自顧食用；以此惡劣因緣，死後墮入地獄之中化為一尊巨大的肉瓮，飽受烈火焚燒之苦，這份酷刑至今都未曾停息；那部經所記載的事相極為詳備，需要的人應當親自去尋覓研讀。當今時代的諸多寺院住持眾主，大多染有這種嚴重的罪過；雖然口中也在講傳經文律典，心裡卻根本不深信因果報應；私自備辦特殊的美味佳餚，公然對著大眾獨自吞嚥；放縱貪婪之心，大肆侵蝕虧損常住的資產；哪裡還會顧念到這早已違背了佛陀的教誨，深深傷害了全寺大眾的感情。

【414-0003】資持記/03c_上二#64
【原文】著少頃之甘肥，為長夜之苦楚；深嗟鄙悋，知復何心。義決中。明破戒者，唯據四重，財法絕分；僧殘已下，皆不可別。下九十中論別眾者，約施主食，故犯提罪；此明常住，別他成重；虧彼自分，成盜損故。供外道中。不自手與，提中制故。伺即候也。僧次中，初示非法。簡謂簡除。
【譯文】為了貪戀片刻咽喉間的甘美肥甘，卻種下了漫長暗夜中受無窮苦楚的地獄深淵；深深悲嘆這等卑劣吝嗇之輩，真不知心中究竟在作何打算。在義理決斷的段落中。所謂明辨破戒之人，唯獨以違犯波羅夷四重罪者為準，此類人徹底喪失了財利受用與聽聞共修佛法的資格；至於犯僧殘罪以下者，一概不得與常住大眾分離割裂。下文九十單墮罪中談到「別眾食」，是針對俗家施主所專門供養的飲食而言，所以只犯單墮罪；此處所說的是常住大眾所有的財物，若私自排除他人份額就會構成嚴重的偷盜重罪；因為私自剝奪虧欠了他應得的份額，就構成了實質上的偷盜損害。在供養外道眾人的規定中，不得親自用雙手給予，這是單墮篇中所明文制定的戒規。「伺」就是等候窺視的意思。在僧團常軌次序中，起初顯示非法的弊端。「簡」就是指非法挑選揀除。


【414-0004】資持記/03d_上二#1
【原文】即下，結犯。上三句結眾主，下二句結合眾。又下，顯過。不名僧所者，同俗舍故。住處中分二，初至德海，明法師如法，前明住處。五人能成邊隅受戒，住持之本，故偏舉之。鳴下，明待客。初下，明修業。若下，次明庇覆破戒。如下，指廣；今在二十八卷。明瞻待中。列六種人。
【譯文】從「即」字以下，是在判定其違犯罪名。前三句判定寺院住持獲罪，後二句判定全體僧眾獲罪。從「又」字以下，是在揭示其過失。之所以稱作「不算是僧團道場」，是因為其情況等同於俗人房舍。在「住處」這一科中分為兩部分：從開頭到「德海」，說明法師行事合乎戒律法度；前面則是說明居住處所。五位比丘便能成辦偏遠地區的受戒法事，這是住持佛法的根本，因此特別舉出。從「鳴」字以下，說明接待客僧的規矩。從「初」字以下，說明進修道業的法度。從「若」字以下，接著說明包庇覆藏破戒之人的過失。從「如」字以下，指引參照更詳盡的內容；現今收錄在《大集經》第二十八卷中。在「說明照顧款待」（明瞻待）這一部分，列出了六種人。

【414-0005】資持記/03d_上二#2
【原文】指隨相者，下引《十誦》；供給王臣，用十九錢，不須白僧，更索須白僧；作人者，量功與之；惡賊者，隨時將擬〔上四人出《十誦》〕；俗人者，《五分》：悠悠無信者，好器與食；達識信士，說食難消等；淨人者，《善見》：分番上下者，當番與食；長使者，常供衣食；
【譯文】所謂「指隨相」的情況，後面引述了《十誦律》的規定：供養侍奉王公大臣，動用十九個錢以內，不需要向僧團白告，若對方再索取就必須白告僧團；對於受雇的工人，要衡量其工作勞績來給予報酬；對於惡賊，則隨順時宜準備應對物資〔以上四種人均出自《十誦律》〕；對於俗人，依《五分律》規定：如果是行事隨便且沒有信仰的人，就用較好的食器盛盛食物給他；如果是明理有見識的信士，就向他開導「信施難消」的道理；對於「淨人」（寺院執役人），依《善見律》規定：輪班上下工的人，輪到當班時供給飲食；長期役使的人，則長年供應衣食；

【414-0006】資持記/03d_上二#3
【原文】撮略引之，並廣如後。約法中。初云別作羯磨者，謂懺罪受日之類。舉罪中，初明來舉。所告人即目犯者。先下，明勘覈。不出三種：一根，二處，三罪；根處舉見以問，聞疑準同，罪中文略邪命。如下，明酬對；前明能答依作。有智人，即眾主也。若不下，明妄舉反治。
【譯文】此處只是簡略摘引，詳細規範正如後文所述。在「依循法度」（約法）這一科中。開頭所說的「個別舉行羯磨」，是指懺悔罪過、請求受日出界等一類法事。在「舉發罪過」（舉罪）中，開頭說明前來舉發的情形。「所告人」就是指犯戒的人。從「先」字以下，說明勘驗審核。審核範圍不出三種：一是罪根，二是處所，三是罪名；針對根與處，是舉出親見之事來詢問，若是聽聞或懷疑則依此類推，罪名部分在經文中略去了邪命一項。從「如」字以下，說明應答對質；前面說明能據實回答者便依律處置。「有智慧的人」，就是指僧團的主事者。從「若不」以下，說明胡亂妄加舉發者反要受到處分。

【414-0007】資持記/03d_上二#4
【原文】舉重治殘，舉殘治提，舉提治吉，故云依法也。下引證中。無餘罪即四重，此謂實犯，但無根故，即犯謗罪。不成遮者，謂能舉本意，遮他說恣故。文亦下，以義決文。謂對答雖差，情容虛實；故誡斟酌，未可一向。就時中，初舉事誡慎。所為重者，前篇所謂拔群迷重累，出界分深根是也。闇下，示作法時節；
【譯文】若檢舉重罪不實則治以僧殘罪，檢舉僧殘罪不實則治以波逸提罪，檢舉波逸提罪不實則治以突吉羅罪，所以說是「依法處理」。後文引證之中，「無餘罪」就是指四波羅夷重罪，這裏是指實有其事，但因舉發者沒有憑據，舉發者便犯了誣謗之罪。「不能構成遮止」的意思，是說舉發者的原本意圖，是想遮止對方參與自恣等僧事。從「文亦」以下，是用法義來裁決經文。這是說對質應答雖然有所偏差，但情實上容有真有假；因此告誡必須審慎斟酌，不可一概而論。在「審時」（就時）這一科中，開頭舉出事實來告誡謹慎。「所牽涉的事情極為重大」，就是前一篇所說的「拔除眾生執迷的沉重包袱，截斷三界生死的幽深根柢」這類大事。從「闇」字以下，開示舉行法事的時間節候；

【原文】五不善中：一是斷已生善，二即起未生惡，三違教，四障道，五來報。諫將罰中，初以僧德勸。又云下，以治舉勸。又不下，以奪行勸。餘文可知。明攝眾中，初明益。牽字去呼，猶引也；課牽也，引而率之者，言導誘無倦，令眾獲益也。必下，彰損；初正示。年雖老邁，於法無知，同年小也。故下，引證。
【譯文】「五種不善」之中：第一是斷絕已經生起的善法，第二是生起尚未生起的惡業，第三是違背佛陀的教誡，第四是障礙修證道果，第五是招感未來的苦報。在「勸諫將受處罰者」（諫將罰）中，開頭以僧眾的德相來勸導。從「又云」以下，以依法治辦舉發來勸導。從「又不」以下，以剝奪修行權益來勸導。其餘文句意思容易明白。在「說明統領攝受僧眾」（明攝眾）這一科中，開頭說明其利益。「牽」字讀作去聲，相當於「引導」的意思；「課」即是督課程限，「牽」即是引領率導，引導誘導而率領大眾，是指教導誘導不知疲倦，讓大眾獲得利益。從「必」字以下，彰顯其損害；開頭正式開示。年紀雖然老邁，但對佛法卻一無所知，這與年輕後輩沒有差別。從「故」字以下，引述經文作證。
