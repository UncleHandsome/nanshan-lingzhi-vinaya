# 校閱材料　第892檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【892-0001】03_業疏/18b_卷四之一#84
【原文】今解云：法有通塞，約緣故開，不可一例。但界無人，即得自念。雖有非數，豈得對首？如結小界及以戒場，為勞動人，故開別作；對首捨墮，未勞待僧。不同說恣，彼此通奉，任情安也。此之獨受，一往即成；後人重至，更不勞作。不同說淨，言中不了，值人更說，文如後也
【譯文】如今解釋道：律法有通融與局限，是依據具體因緣而開許的，不可一概而論。只要界內確實無人，就可以自行心念作法。即使身邊有人但若不合僧數（如沙彌等），又怎能對首作法？如同結小界以及結戒場，是為了避免勞動大眾，所以開許少數人另行結作；又如對首捨墮，也無須勞煩等待全體僧眾。這不同於說戒、自恣，必須彼此共同遵奉，由大眾同心安住。這種獨自心念受持，一旦作法立即成就；其後縱然有其他人再次到來，也不需重新作法。這不同於說淨法，因言詞中未指明特定淨主，遇到人時還須重新說淨，其文見於後文。

【892-0002】03_業疏/18b_卷四之一#85
【原文】次科初立義，說戒、說淨則須待人，加衣不須，故云「通寒」。「如」下二、舉例，有二：一、引小界戒場例，行法取成，但恐煩眾，豈須待耶？二、引別人懺捨例，由本對僧，若須相待，不應開別。「不同」下三、釋妨，初釋說恣須待眾別異故；「此」下二釋心念說淨須待，受淨別故，漫指淨主，故言不了。
【譯文】在次一科中，首先確立義理：說戒與說淨則必須等待他人，加持衣法無須等待，所以說「通塞各異」（文作「通寒」）。自「如結小界」以下第二、舉例說明，分為兩點：第一、引結小界與戒場之例，行法但求成就，只恐煩擾大眾，哪裡需要苦等呢？第二、引個人對首懺除捨墮之例，本來屬於對僧作法，如果必須等待僧眾，就不應開許個別作法。自「不同說恣」以下第三、解釋疑難：首先解釋說戒、自恣必須等待，因為眾法與別法性質相異的緣故；自「此之獨受」以下第二解釋心念說淨必須等待，因為加受衣法與說淨法有所不同，心念中泛指淨主，所以說言中未了。

【892-0006】03_業疏/18b_卷四之一#89
【原文】二者、染礙，以男女同處，性相染汙，譏謗由生，故制須離。律諸戒約，多有斯例，如同坐、同宿、同行、同乘、與衣、作衣，無論道俗，是女皆犯。故《多論》中除村界者，為護梵行也。以義而推，無男有女，是為染礙
【譯文】第二種是染礙（染污嫌疑的障礙），因為男女同處一處，情性相染污，容易引生世人的譏嫌誹謗，所以制定必須離開。律中諸多戒條約束，多有這類例子，例如同坐、同宿、同行、同乘一車船、與衣、作衣等戒，無論是出家尼眾還是世俗女子，只要是女性都會犯戒。所以在《薩婆多論》中將村界排除在衣界之外，是為了守護梵行。依義理推尋，若無男子而有女子，即構成染礙。

【892-0018】03_業疏/18b_卷四之一#101
【原文】長周尺量者，律云長佛二搩手，廣一搩手。佛在人倍，人長八尺，佛則丈六，並依周尺以定律呂也。更增半搩者，謂截竟加半搩耳，非謂相連說增也。故佛滅度後一百年之時，毗舍離國擅行十事，「不割縷淨」是其一擅。今世盛有，即䟦闍風，妄情難信，但準聖言，自無咎也
【譯文】以周朝長尺來度量坐具，律中說長度為佛的二搩手，寬度為一搩手。佛的身量是常人的兩倍，常人身長八尺，佛的身長則是一丈六尺，這都是依周尺來配合律呂（法定準則）而制定的。「更增半搩」是指裁剪完成後另外加上半搩手的緣邊，並不是指連同布料主體直接說加大。所以佛滅度一百年時，毗舍離國跋闍子比丘擅自推行十事非法，其中妄執「坐具不裁截邊緣亦屬合律之淨法（不割縷淨）」便是其擅自行事之一。如今世間盛行這種作法，正是跋闍之遺風，凡夫妄情難以憑信，只要遵照聖人的教言，自然就沒有過咎。

【892-0019】03_業疏/18b_卷四之一#102
【原文】二中初明初量。佛一搩手長二尺，人止一尺。律呂猶準則也，六律六呂，氣候不差故。「更下」，次明增量。初示增法。「故下」，引斥妄行。䟦闍十事，《資持》具引。「擅」謂專輙。「不割縷淨」，謂統同增量，如法無過
【譯文】在第二部分中，首先說明最初的應量。佛的一搩手長二尺，常人只有一尺。「律呂」猶如準則，因為六律、六呂與天地節氣時候絲毫不差。自「更增」以下，其次說明增量的規定。先指示增量之法。自「故佛滅度」以下，引古例斥責妄行。跋闍十事，《資持記》中有詳細引述。「擅」是指專擅妄為。「不割縷淨」，是指彼等妄執將坐具統同一體加大尺寸，是合於戒律而無過錯的淨法。

【892-0035】03_業疏/18b_卷四之一#118
【原文】受鉢制意中，初敘食緣。《論語》云「君子謀道不謀食」。「俗下」，二明異俗。「方丈列鼎」，言其奢侈；「種」猶多也。「然下」，三示聖制。「諸佛標幟」，出《十誦》文。軍中旗幟，有所別故。注引《五分》，彼云：佛在蘇磨國，自作鉢坏，令窑師燒。初成金鉢，次成銀鉢。佛言：王若聞者，謂我能燒金銀，竝令埋之。後成鐵鉢，青如閻浮樹，佛令用之，號蘇摩鉢
【譯文】在受鉢的制定立意中，首先敘述求食進食的因緣。《論語》說「君子謀道不謀食」。「俗則」以下，第二說明與世俗有別。「方丈列鼎」是形容世俗飲食奢侈揮霍；「種」就是多種的意思。「然而」以下，第三指示聖人制定之由。「諸佛標幟」出自《十誦律》文。軍隊中的旗幟，是為了有所識別之用。夾注引《五分律》，那裡說：佛在蘇摩國時，親自製作鉢的坯胎，讓陶師燒製。最初燒成金鉢，其次燒成銀鉢。佛說：國王如果聽聞此事，會以為我能燒煉出金銀，於是都叫人把它們埋掉。後來燒成了鐵鉢，色澤青潤如閻浮樹葉，佛陀便令大眾使用，稱作蘇摩鉢。
