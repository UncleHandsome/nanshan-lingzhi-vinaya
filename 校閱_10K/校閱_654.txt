# 校閱材料　第654檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【654-0001】02_戒疏/13b_卷三下之一#86
【原文】【記】四中，《十誦》、《五分》，同明不開時節。前安居人除三月，後安居人除四月。義準中安居隨滿即開，除則不定。次引《見論》，明開中病差未差。「遇難不失」者，彼云：「路險不得還，恒作還意，雖差不失。」後引《多論》，明餘雜相，有三。初明後用前法，不須再乞。「若化」下，次明事難不犯。「化未盡」者，往彼教化，或是人多，或約處遠，故有「未盡」。「而月盡」者，九月八月滿也。「緣訖」，謂取事辦，出於月外，以事緣故，亦開夏限也。「若死」下，明亡過所屬。隨在外死，有看病者，索往賞之。
【譯文】【記文】第四點中，《十誦律》與《五分律》同樣說明了不開許離衣的時節。前安居的人扣除三個月，後安居的人扣除四個月。依義理推論中安居的人則是安居期滿隨即開許，扣除的月份則不固定。接著引用《善見論》，說明開許期間疾病痊癒與否。「遭遇險難不失衣」，是指該論說：「道路險阻無法返回，只要心中常存返回之意，即使病好了也不失衣。」最後引用《薩婆多論》，說明其餘雜項規定，共有三點。首先說明後續可以沿用先前的羯磨法，不需再次乞請。從「如果教化」以下，說明因事務艱難而不算犯戒。「教化未盡」，是指前往彼處教化眾生，或者因為人數眾多，或者因為路途遙遠，所以有「尚未結束」的情況。「而月份已滿」，是指九個月或八個月期限已滿。「因緣結束」，是指把事情辦妥為止，即使超出了月份期限，因為是公事的緣故，也開許突破安居期限。從「如果身亡」以下，說明亡僧遺物的歸屬。隨身在外身亡，若有照料病人的人，應索取這件大衣來賞賜給他。

【654-0009】02_戒疏/13b_卷三下之一#94
【原文】【註】不犯者：僧作羯磨；明相未出，若手捉衣，若捨衣，若至擲石所及處。若奪想，若水陸道斷急難，若賊，惡獸，強者所執，或命、梵難——若不捨衣及不至擲石所及處，不犯也。
【譯文】【註文】不犯戒的情況包括：僧眾已為其作羯磨法開許；天明破曉之前，或者親手捉持衣物，或者將衣物捨棄，或者走到了投擲石塊所及的勢分之內。或者誤以為衣物已被掠奪，或者水路陸路斷絕遇到急難，或者遭遇盜賊、惡獸、強梁之人所拘禁，或者遭遇生命危險、梵行難保的危難——在這些情況下，即使不捨棄衣物以及未走到擲石所及之處，也不算犯戒。

【654-0010】02_戒疏/13b_卷三下之一#95
【原文】【疏】「不犯」之中，通明不犯有七。一、別人作法離，或對首及心念。二、對僧作法離，有二：初有緣乞法，如上所明；二共作迦絺那法離。三者，對處作法離，即不失衣界，廣如《羯磨疏》、《鈔》中。四、蘭若恐怖離。五、王路隔塞命梵等緣，如下開說。六、迦提賞勞離。七、如《五分》「僧塔勝緣」也。
【譯文】【疏文】在「不犯戒」的規定中，通盤說明不犯的離衣情況共有七種。第一、對著個別僧人作法離衣，或者透過對首法，或者透過心念法。第二、對著僧團作法離衣，這有兩種情況：一是因有事故而乞求羯磨法，如同前面所說；二是全僧共同舉行受功德衣（迦絺那衣）法而開許離衣。第三、對著特定處所作法離衣，也就是結成不失衣界，詳細內容如《羯磨疏》與《事鈔》中所述。第四、身處阿蘭若因恐怖而離衣。第五、因官道阻塞以及危及生命、梵行等因緣，如後文所開許的說明。第六、受迦提衣作為賞勞而開許離衣。第七、如《五分律》所說的「僧團造塔等殊勝因緣」而開許離衣。

【654-0011】02_戒疏/13b_卷三下之一#96
【原文】【記】次釋不犯，七離中，初文。言「通明」者，統括諸緣，不專此故。第一，即注中「若捨衣」也。二、「對僧有二」，「乞法」即注「僧作羯磨」，「迦絺」即前開緣。三、「對處離」者，即結攝衣界也。未結之前，但依藍院；加結已後，通藍內外，彼此無失故也。今此不明，故指如別，《疏》在《結界》，《鈔》見《二衣》。第四、第七，並出當篇第二十九戒，如後委釋。第五如注。第六，出安居法。
【譯文】【記文】接著解釋不犯條款，在七種離衣之中，屬於第一段文字。所謂「通盤說明」，是指統籌囊括各種因緣，並不專限於本戒的緣故。第一種，就是注文中所說的「或者將衣物捨棄」。第二種「對著僧眾有兩種」，「乞求羯磨法」就是注文所說的「僧眾已為其作羯磨法」，「受功德衣」就是前面提到的開緣。第三種「對著處所離衣」，就是結成收攝衣物的界域。在結界之前，只能依附寺院院落；在加法結界之後，便涵蓋寺院內外，彼此分離都不會失去衣物。此處不再細說，所以指示參見他書，《疏》見於《結界》篇，《鈔》見於《二衣》篇。第四種與第七種，都出自本篇第二十九戒，留待後文詳細解釋。第五種如注文所載。第六種出自安居法中。

【654-0012】02_戒疏/13b_卷三下之一#97
【原文】【疏】就此七離有法無法者。前三得法離。後三無法離。中間蘭若，六夜送村中，無法離；恐失遙捨者，是有法離。
【譯文】【疏文】就這七種離衣情況來辨別是有法還是無法：前三種屬於「得法離衣」（透過如法羯磨儀軌而開許離衣）；後三種屬於「無法離衣」（不需儀軌而直接開許離衣）。中間第四種阿蘭若離衣，若是六夜之內把衣物送到村落中，屬於無法離衣；若是唯恐失衣而預先在遠處捨衣，則屬於得法離衣。

【654-0013】02_戒疏/13b_卷三下之一#98
【原文】【記】料簡中，初文。「前三有法」，須辨不同：別人作法，乃是捨衣失法，非是開離；迦絺自為受衣，對處自緣結界；唯乞法者，是作法許離耳。又「七離」名同，自有三別：第一即捨為離，第三以不失為離，餘五並約異處不失乃是開離。學者細詳，無宜一混。
【譯文】【記文】在辨別料簡之中，屬於第一段文字。「前三種屬於得法」，必須辨析其不同之處：對著個別僧人作法，本質上是透過捨衣而失去受持之法，並非開許離衣；受功德衣本身是為了受納新衣，對處作法本身是為了結界；唯有乞法離衣這一種，才是透過羯磨作法正式開許離身不犯。此外，「七種離衣」雖然名稱相同，本質上卻有三種差別：第一種是以「捨衣」當作離衣，第三種是以「不失衣」當作離衣，其餘五種都是在異處不失去衣物，這才真正是開許離衣。修學者應當細緻推詳，萬萬不可混為一談。

【654-0014】02_戒疏/13b_卷三下之一#99
【原文】【疏】得罪有無者，第二、四、五、六、七，一向無罪，以有緣故。第五隔塞，或忘斷故，失不如文中解。
【譯文】【疏文】至於犯罪的有無：第二、第四、第五、第六、第七這五種，一概沒有罪過，因為有正當因緣的緣故。第五種因道路隔絕，或者因為取回衣物的希望斷絕之故，至於失法或不失法，正如疏文下文所解釋的那樣。
