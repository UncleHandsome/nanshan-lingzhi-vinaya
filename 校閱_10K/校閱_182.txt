# 校閱材料　第182檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【182-0001】01_行事鈔/08b_卷中之四#58
【原文】又行覆者，多不滿日；諸師立理，互加同異。今取盛行之師傳授云：此依教懺法，大小乘中，校量心行，折伏為先；若考別住事業，則大成殷重。若準《十誦》，不行別住，六夜出罪，佛並誠斷得罪、得出。用彼徵此，理須相準。雖然，恐事不稱法，則改張舊習。羯磨者云：「某甲比丘，已行覆藏日，今從僧乞六夜。」若後諸白羯磨，並須準改。當於乞六夜前，上座集僧已，白云：「此某甲比丘，行僧殘覆藏，已經若干日，極意勤苦；餘有若干日未行者，此既於僧陳謝，僧今已受之，可放其餘日。」和僧已，眾若默然者，當與六夜法。若行日滿者，依法誦之。
【譯文】再者，修行覆藏別住的人，多有未能圓滿完成應行日數的情形；歷代諸律師立論闡發義理，互有同異諍論。如今採取普遍盛行的大德名師傳授之說：這種依照戒教的懺法，無論在小乘或大乘之中，考量其心地的造詣修行，皆以折伏驕慢為首要；如果考察別住時的諸般勞役奉事，那確實是極其懇切殷重了。如果依照《十誦律》的規定，即使不修別住，直接進行六夜摩那埵而出罪，佛陀都曾明確判定：行者犯突吉羅罪，但出罪依然有效（得出）。拿彼處律文來引證此處，義理上自當相互準照。話雖如此，若擔心行事不合佛制，就應修改舊習。羯磨師應當在羯磨文中念道：「某甲比丘，已經奉行了覆藏日數，如今向僧團乞求六夜。」其後續的各番羯磨文句，也都必須照此準則修改。應當在乞求六夜之前，由上座召集僧眾完畢後，宣白道：「此某甲比丘，奉行僧殘覆藏，已經過了若干日，極其勤懇辛勞；其餘尚有若干日未奉行者，此人既然已經向僧團陳情謝過，僧團如今也已接受，可以寬免其剩餘的日數。」僧眾和合商定之後，大眾如果默然同意，就應當授與他六夜摩那埵法。若行滿規定日數的人，則完全依照原有法式讀誦羯磨。

【182-0002】01_行事鈔/08b_卷中之四#59
【原文】二明與摩那埵法。初明乞法：「大德僧聽！某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜已，從僧乞百夜覆藏羯磨，僧已與我百夜覆藏羯磨。我某甲比丘，已行覆藏日，今從僧乞六夜摩那埵，願僧與我六夜摩那埵。慈憫故！」
【譯文】第二、說明給與摩那埵之法。首先說明乞法：由犯僧殘的比丘在僧前稟白乞求說：「大德僧聽！我某甲比丘，犯了故意漏失不淨、摩觸女人、向女人說麁語這三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜；先前已向僧團乞求了一百夜覆藏羯磨，僧團已經給與我一百夜覆藏羯磨。我某甲比丘，如今已經行了覆藏的日數，如今向僧團乞求六夜摩那埵，願僧團給與我六夜摩那埵。慈愍我的緣故！」

【182-0003】01_行事鈔/08b_卷中之四#60
【原文】上座如前作法安慰之訖。白言：「大德僧聽！某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜，已從僧乞百夜覆藏羯磨，僧已與彼百夜覆藏羯磨；彼已行覆藏日，今從僧乞六夜摩那埵。若僧時到僧忍聽：僧今與彼六夜摩那埵。白如是。」「大德僧聽！此某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜已，從僧乞百夜覆藏羯磨，僧已與某甲比丘百夜覆藏羯磨。此某甲比丘，已行覆藏日，今從僧乞六夜摩那埵；僧今與某甲比丘，六夜摩那埵。誰諸長老忍，僧與某甲比丘六夜摩那埵者，默然；誰不忍者，說。是初羯磨。」「僧已忍，與某甲比丘六夜摩那埵竟。僧忍，默然故。是事如是持。」
【譯文】上座如同前面一樣如法勉勵安慰他完畢。隨後作白宣示：「大德僧聽！某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜，先前已向僧團乞求一百夜覆藏羯磨，僧團已經給與他一百夜覆藏羯磨；他如今已經行完覆藏日數，如今向僧團乞求六夜摩那埵。若僧團適宜的時間已到，僧團也贊同許可：僧團如今給與他六夜摩那埵。這是所白告之事。」「大德僧聽！此某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜，先前已向僧團乞求一百夜覆藏羯磨，僧團已給與某甲比丘一百夜覆藏羯磨。此某甲比丘，如今已經行完覆藏日數，如今向僧團乞求六夜摩那埵；僧團如今給與某甲比丘六夜摩那埵。各位長老凡是贊同僧團給與某甲比丘六夜摩那埵的，請默然；有不贊同的，請說話。這是初番羯磨。」「僧團已經贊同，給與某甲比丘六夜摩那埵完畢。因為大眾贊同而默然故。這件事就這樣遵行受持。」

【182-0004】01_行事鈔/08b_卷中之四#61
【原文】彼得羯磨已，即於僧中白言：「大德僧聽！我某甲丘丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜，已從僧乞百夜覆藏羯磨，僧已與我百夜覆藏羯磨。我比丘某甲，已行覆藏日，已從僧乞六夜摩那埵，僧已與我六夜摩那埵；我某甲比丘，從今日行，白大德僧知，我行摩那埵。」若行經一夜者，餘詞同上。乃至「僧已與我六夜摩那埵；我某甲比丘，已行一夜，未行五夜，白大德僧知，我行摩那埵。」若客比丘來，唯改大德僧為異，餘詞並同。
【譯文】該比丘領受羯磨完畢之後，隨即在僧眾之中稟白說：「大德僧聽！我某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜，先前已向僧團乞求一百夜覆藏羯磨，僧團已經給與我一百夜覆藏羯磨。我比丘某甲，如今已經奉行完覆藏日數，已經向僧團乞求六夜摩那埵，僧團已經給與我六夜摩那埵；我某甲比丘，從今天起開始奉行，稟白大德僧知曉，我正在行摩那埵。」如果奉行經過了一夜，其餘文詞如同上面所述。乃至說到「僧已與我六夜摩那埵；我某甲比丘，已行一夜，未行五夜，白大德僧知，我行摩那埵。」如果有外來客比丘抵達，只將大德僧改換稱謂為異，其餘文詞全都相同。

【182-0005】01_行事鈔/08b_卷中之四#62
【原文】律云：行六夜比丘，亦同行別住覆藏法；唯常在僧中宿、日日白，為異。《僧祇》：因數數犯僧殘，如波逸提乃至越毘尼悔，故便制六夜懺悔，二十人中出罪。此上二行中，若覆，與前法；不覆，與後法；同俱出罪。若二法中重犯者，各壞二法，皆重與本日治之。餘如別述。
【譯文】律中說：奉行六夜摩那埵的比丘，其行持儀軌與奉行別住覆藏法大致相同；唯一不同之處，在於他平時常在清淨僧大眾之處住宿、且每日必須向大眾稟白發露。《摩訶僧祇律》說：因為有人頻頻毀犯僧殘罪，卻輕慢地像悔波逸提乃至越毘尼（惡說罪）那樣隨意求悔，所以佛陀便制定了六夜專精懺悔之法，並規定必須在二十位清淨大僧之中才能作成出罪羯磨。在這兩種行法之中：若有覆藏，便給與前法（別住）；若無覆藏，便給與後法（摩那埵）；最後同樣都需經過羯磨出罪。若在遵行這兩種懺法期間再度犯下僧殘罪，則各自破壞了這兩種行法，都必須重新依本日治之。其餘的細則如別處章疏中所詳細論述。

【182-0006】01_行事鈔/08c_卷中之四#1
【原文】三與出罪法。先教乞云：「大德僧聽！我某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜已，從僧乞百夜覆藏羯磨，僧已與我某甲比丘百夜覆藏羯磨；我某甲比丘，已行覆藏日，已從僧乞六夜摩那埵，僧已與我六夜摩那埵；我某甲比丘，已行六夜摩那埵竟，今從眾僧乞出罪羯磨，願僧與我出罪羯磨。慈憫故！」
【譯文】三與出罪法。先教導求出罪者祈請道：「大德僧伽請聽！我某甲比丘，犯了故意出精、摩觸女人、向女人說粗惡淫語三條僧殘罪（僧伽婆尸沙），每一條都不記得犯了多少次，或者隱瞞掩蓋了一夜乃至一百夜；之後向僧團祈求百夜覆藏羯磨（別住法），僧團已經給予我某甲比丘百夜覆藏羯磨；我某甲比丘已經行完了覆藏日數的行法，又已向僧團祈求六夜摩那埵（意喜法），僧團也已經給予我六夜摩那埵；我某甲比丘如今已經行完六夜摩那埵，現在向眾僧祈求出罪羯磨（阿浮呵那），祈願僧團給予我出罪羯磨。請大德僧慈悲愍念！」
