# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【490-0001】03_業疏/09a_卷二之三#15
【原文】次廣斥中，初、通示。若大小相望，小乘是不了義教，大乘即了義教；今望淨地，大小皆斷，通為了教。但在小則前開後廢，在大則一向不立，此為異耳。「如」下，別引。《涅槃》即〈四依品〉文。初三句即引前段，彼具云「聲聞僧者，無所積聚，所謂奴婢、僕使、庫藏、穀米、鹽䜴、胡麻、大小諸豆，若自手作食、自磨自舂，種種非法故。若有說言如來聽畜非法之物，舌則卷縮」。「若諸」下，即引後段。「時世」等四句，即是開緣，必具此緣，方開受畜；雖開受畜，要須淨施篤信檀越。「四法依止」，即依法不依人等法四依也。《楞伽》、《十誦》，文見前科。祇桓無厨，事出《僧祇》，阿難為佛溫飯在祇桓門邊，所謂煑藥也。《涅槃》「聖行」即〈聖行品〉，彼明菩薩聞是經已，遠離八不淨物，出家求道，堅持佛戒，是佛菩薩所行，故名聖行。乃至云「不畜穀米麥豆生熟食具，常受一食，不曾再食；若行乞食及僧中食，當知止足，常為諸天世人恭敬供養」等。《華嚴》「正願」，〈淨行〉偈云「若得食時，當願眾生，為法供養，志存佛道；若不得食，當願眾生，遠離一切諸不善法」。諸律受戒，竝制先說四重、四依，令遵上行。「元」即初也。「雖」下，遮妨。律開僧常，明有淨地，然是廢前，後不可用。「不」下，正斥
【譯文】在其次廣泛斥責中，首先通論開示。若以大小乘相對而言，小乘是不了義教，大乘則是了義教；如今就淨地這一點來看，大小乘皆主張斷除，所以通通屬於了義之教。只是在小乘中是前開而後廢，在大乘中則是一向不設立，差別只在此處而已。「如」字以下，分別引證。《大般涅槃經》即是〈四依品〉的經文。前三句即是引述前段，彼處具體說道：「聲聞僧眾，無所積聚，所謂奴婢、僕役、庫藏、穀米、鹽豉、胡麻、大小諸豆，若親手做飯、親自推磨舂米，皆是種種非法之故。若有人說如來聽許蓄存非法之物，他的舌頭必當卷縮。」自「若諸」以下，即是引述後段。「時世」等四句，就是開許的因緣，必須具備這種因緣，才開許接受貯蓄；雖然開許接受貯蓄，也必須以淨施法布施給篤信的檀越。「四法依止」，就是依法不依人等四種法四依。《楞伽經》與《十誦律》的文句，見於前一科。祇洹無廚之事，出自《摩訶僧祇律》，阿難為佛熱飯是在祇洹大門旁邊，也就是經中所說的煮藥。《大般涅槃經》的「聖行」即指〈聖行品〉，該品闡明菩薩聽聞此經後，遠離八種不淨物，出家修道，堅持佛戒，這是諸佛菩薩之所行，所以稱為聖行；乃至說道「不蓄積穀米麥豆與生熟飲食器具，常受一食，不曾再次進食；如果行乞食以及僧眾中受食，應當知止知足，常為諸天與世人恭敬供養」等等。《華嚴經》的「正願」，是指〈淨行品〉偈頌說：「若得食時，當願眾生，為法供養，志存佛道；若不得食，當願眾生，遠離一切諸不善法。」各部律典在授戒時，都規定必須先宣說四重、四依，令其遵行上等行持。「元」，就是最初的意思。「雖」字以下，遮止疑難。律中開許常住僧食，固然說明曾有淨地，然而這是被廢止之前的規定，後世不可採用。「不」字以下，則是正面斥責。

【490-0012】03_業疏/09a_卷二之三#26
【原文】今解：言界者，是院周界，豈局作法？縱結攝僧，無僧坊院，不成儲畜，譏過則無；院雖周成，不結攝僧，亦是宿攝，能生過故。所以律云持食露地，賊所持去，因開寺內；若約界成，不應四淨半有籬障，非唯自然，義通作法
【譯文】今家的理解是：經律中所說的「界」，是指院落周圍的邊界，哪裡局限於作法所結之界呢？縱然作法結了統攝僧人的大界，如果沒有僧坊院牆，就構不成封閉儲蓄之相，譏嫌過咎也就不會產生；院牆雖然周匝完備，即使沒有作法結為攝僧大界，也屬於內宿所統攝的範圍，因為能夠滋生過咎的緣故。所以律中說把食物放在露天之地，被賊人偷走，佛陀因此開許移入寺院之內；如果是依作法結界來判定內宿，那麼四種淨地中就不應當有一半是依籬笆屏障來定，可見這不僅僅是指自然界，義理上也通於作法之界。

【490-0013】03_業疏/09a_卷二之三#27
【原文】今解中初科為三：初、立義。「是院周界」，謂律論云界，乃是院相周帀之界；至於成宿，但取院相，故云「豈局作法」。準文三句：初「院周界」者，即院、界俱有，成犯可知。「縱結」下，即有界無院，縱畜無過，與古不同。「院雖」下，即有院無界，攝相義強，故有宿過。「所」下，引證。既因露地，開移寺內結作淨地，可驗露處無過明矣。「若」下，反質。律有四淨，若不約院，則缺不周，但有三耳；又復不周通於兩界，故知不爾
【譯文】在今家解釋的第一科中分為三部分：第一是立論。「是院周界」，是說律、論中所稱的界，乃是指院相圍繞周匝之界；至於構成內宿之過，只取院落相狀，所以說「豈局限於作法之界」。依準文義有三種情況：第一「院周界」，即是院相與作法界兩者俱備，構成犯戒是顯而易知的。「縱結」以下，即是有作法界而無院落，縱然儲存也沒有過失，這與古師見解不同。「院雖」以下，即是有院落而無作法界，由於封閉統攝的相狀義理顯著，所以產生內宿之過。「所」字以下，引證。既然是因為放在露天之地，佛才開許移入寺內結為淨地，可驗知在露地儲存並無過咎，這是極為明白的。「若」字以下，反詰質問。律中列有四種淨地，如果不就院落而言，那麼就會欠缺「院相不周」這一條，而只剩下三種了；而且不周淨通於自然界與作法界兩者，所以可知古師之說並不合理。

【490-0014】03_業疏/09a_卷二之三#28
【原文】問：有界無院，不集別眾；無界有院，如何犯宿？答：僧、食兩異，何得例也？由方相合，儲過譏生，故有罪也；法事取和，不從譏過，故有斯異
【譯文】問：如果境內有界而無院落，界內不集合僧眾便成別眾之罪；那麼無界而有院落，又怎麼會犯內宿呢？答：僧眾之事與飲食之事兩者本質不同，怎能混為一談來比照呢？由於四方院相合圍封閉，儲存的過咎與譏嫌便隨之產生，所以結成有罪；而僧中行法事求取的是僧眾和合，並不取決於外界有無飲食儲蓄的譏嫌，因此兩者有這樣的差異。

【490-0018】03_業疏/09a_卷二之三#32
【原文】一者、檀越淨。文中由是他物，貪儲不生，故直開也。義分為三：初、處所是他物，食具是自許，既是俗家，我固絕起；二、處是僧坊，食具俗有，律云聽作檀越食，令淨人掌舉，不應自受，所須隨索之；三、處、食俱他，如今俗設噉會者是也
【譯文】第一是「檀越淨（施主淨）」。經文中因為屬於他人的財物，比丘貪著儲存之心不起，所以直接開許。義理上分為三種情況：第一，處所是他人物品，食具與食物是自己所有；既然是在俗人家中，我自當絕不起貪心執著；第二，處所是僧坊，而食具與食物屬於俗人所有；律中說聽許製作施主供僧飲食，令淨人掌管收藏，比丘不應當親自接受，有所需要時隨時向其索取；第三，處所與食物全都是他人所有，如同現今俗人所設的齋會供僧便是這種情形。

【490-0019】03_業疏/09a_卷二之三#33
【原文】檀越淨中初科，初敘意；「義」下顯相。初云「食具」，即通器物、生熟之者；「許」，猶有也；「固」，即是執。二中「不自受」者，恐成己物故。三中一時齋供，謂之噉會
【譯文】在檀越淨的第一科中，首先敘述立教用意；自「義」字以下顯明其相狀。第一條所說的「食具」，通指盛食器物以及生熟食物；「許」，相當於「有」；「固」，就是執持不捨。第二條中所說的「不自受」，是恐怕變成自己所屬之物的緣故。第三條中一時所設的齋糧供養，就稱為噉會。
