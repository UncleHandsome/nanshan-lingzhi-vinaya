# 校閱材料　第632檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【632-0001】資持記/14b_下二#35
【原文】又心曾服食，八日成犯，後受相染；今由不服，故得間受。立法有以，故令準用。五中。正可者，藥恰盡也。雖無染犯，不許續加。結中。決上相續，須約同藥。下引《僧祇》，一體轉易；可證異味，不妨續受。自作中。第二然燈塗足，由非服食，義無加受。
【譯文】再者，若是曾經服食過，到了第八天該藥就會構成犯長之罪，其後新受的藥也會受到相染（而法不成）；現在由於並未服食，所以得以間隔一日後重新受持。立法的背後有其深意，所以才要求依準施行。在第五種過失中，「正可」的意思，是指藥物剛好用完。這時雖然沒有染污犯戒的情形，但律法不允許連續加受。在結尾這段中，決斷上面的連續受持，必須針對同一種藥物而言。下面引用《僧祇律》，藥物一旦本體改變；就可以證明換成不同的味道，並無礙於接續受持。在「自作」這一段中，第二種用來點燈或塗腳的情況，因為不是拿來服用的，在道理上就不需要加受。

【632-0002】資持記/14b_下二#36
【原文】〔古云油以除風，塗足能履水，西竺多用。〕下指所出，義須依準。第三記識，用舍不定，故注示之。四中注釋展轉之義。油蜜不轉經煮不失，是以文中唯簡二酥。得自煮者，以生酥先熟，非變生故。二煮即上自他。
【譯文】（古代說用油塗腳可以祛除風寒，還能夠踏水行走，西印度地區經常使用。）下面指引其出處，在道理上必須依據奉行。第三種「記識」，採用或捨棄並不固定，所以註文特別予以說明。在自作四法中的第四法中，註文解釋了「展轉」的涵義。油和蜜不會變質，經過烹煮也不會失去受持力，所以鈔文中唯獨挑出生酥和熟酥這二酥（來說明展轉烹煮）。自己可以烹煮的原因，是因為生酥本來就是熟物，並不是把生食煮成熟食。所謂「二煮」，就是指上面提到的自己煮或請他人煮。

【632-0003】資持記/14b_下二#37
【原文】據本生酥，限滿有觸，味轉失受，事同新物，再受而捉，故不成觸。下引《婆沙》反證，可解。正加中。注安淨地，離內宿也。須自取者，免觸失也。古謂七日藥開內宿，故持點之。文舉風病油藥為法；餘皆準改，故云類準。盡形中四，初位指前。次科。初須火淨，且據生者為言。
【譯文】依照本來的生酥，期限滿了就會產生污觸，味道一旦變質就失去了受持法，其性質就如同全新的物品一樣，再次受持之後去拿，因此不會構成污觸。下面引用《婆沙論》從反面來作證，這點是可以理解的。在正式加受這一段中，註文提到安置在清淨之地，是為了遠離內宿的過失。必須自己去拿，是為了避免受到污觸而失去受持。古代有人認為七日藥開許內宿，所以這裡特別加以點明糾正。鈔文中列舉風病所用的油藥作為範例；其餘的藥物都依此標準修改，所以說「各種類推」。在「盡形壽藥」的四項法度中，第一項指引前面所說。第二科中，開頭說必須用火作淨，這暫且是針對生鮮藥物而言。

【632-0004】資持記/14b_下二#38
【原文】二與餘別，必約藥分相雜。三中。體謂正藥，分即餘助。二法者，即手口二受。〔有云即體分二藥，屬法所收，故云二法。〕別來謂不同時買，別受謂隨得隨加。第四，總受中。注牒諸藥，此約藥味未和合者。必是成現丸散，單牒藥君；如云黃芪散阿魏丸等。若下，指例。
【譯文】第二點要與其他藥物區分，必定是針對不同藥物的成分互相雜揉的情況。在第三部分中，「體」是指主要藥物，「分」就是其餘的輔助藥物。「二法」的意思，就是指手受與口受兩種受法。（有人說是指藥體與藥分這兩種藥物，都屬於作法所含攝，故云二法。）「別來」是指不在同一個時間買來，「別受」是指隨得隨加。第四部分，在「總受」這一段中，註文詳細列舉各味藥物，這是針對藥味尚未調和在一起的情況。如果已經調配成現成的藥丸或藥散，就只要單純列出主要藥物的名稱；例如稱作「黃芪散」或「阿魏丸」等。「若」字以下，指引類推的標準。

【632-0005】資持記/14b_下二#39
【原文】隨何藥病，準上改牒。指如前者，即指上注別標藥目；或可同上須辨體分，或可指相和體文；彼云隨以藥首標目，餘則藥分稱之是也。別受中，初敘有緣別來。而下，明別受。又二，初加藥體。同上不出。若下，次加藥分。注中上八物是時藥，下三物即七日藥。遇緣謂他事所阻。
【譯文】隨著得了什麼病、用了什麼藥，依照上述格式修改並列出名稱。指引如同前面的內容，就是指上面註文中所特別標明的藥物名稱；或者也可以如同上面那樣必須辨別主體與輔助成分，或者也可以指前文『四藥相和』門中論述藥體的文句；那裡說隨意以主要藥物來標明名稱，其餘的就稱為藥分，就是這個意思。在「別受」這一段中，首先敘述因為特殊因緣而分別送達的情況。「而」字以下，說明分別受持的作法。這裡又分為兩部分，首先是藥體的加法，文句與上述相同故鈔中不另寫出。「若」字以下，其次是藥分的加法。註文中上面的八種物品屬於時藥，下面的三種物品屬於七日藥。「遇緣」是指被其他事情所耽誤阻礙。

【632-0006】資持記/14b_下二#40
【原文】盡形藥頭，即藥體之君。文中且舉一味時藥，餘可例牒，故注示之。三中。令淨人斷價，離販賣故。得自選者，由非己物不成觸故。即覓比丘加者，有則就市，無則還寺；不然，且令淨人持還，後從手受，事則容緩。不過限者，時內不過中，非時不過須臾。斥世中，初敘恣情慢法。
【譯文】盡形壽藥的藥頭，也就是藥物本體中的君藥。經文中暫且列舉了一味時藥，其餘的可以依此類推並列出名稱，所以註文特別予以說明。在第三部分中，吩咐淨人去評定價格，是為了遠離親自買賣的過失。可以親自挑選的原因，是因為那還不是屬於自己的東西，不會構成污觸。這時立刻尋找比丘來加持受法，如果市場上有比丘就就地作法，如果沒有就帶回寺院；再不然，就姑且讓淨人拿著帶回去，事後再從淨人手中接受，這樣事情就可以稍作寬限。所謂「不超過期限」，在時食限內不能超過正午（日中），在非時之內則不能超過須臾片刻。在「斥世」這一段中，首先敘述放任私情、輕慢戒法的現象。

【632-0007】資持記/14b_下二#41
【原文】希有一二，言其極小；斯時尚爾，於今可知；聖制不行，即是滅法，故云抑挫。抑謂抑遏，挫謂摧挫。高談下，斥有言無行。高談謂超世之語。虛論謂言過其實。攝心則動無自任，順教則專奉律儀。此明好大者，據說則超出世表，撿行即混迹常流。
【譯文】希罕只有一兩個人能遵守，是說能守法的人極其稀少；在那個時代尚且如此，到了現今社會就更可想而知了；聖人的制規不能推行，這就是毀滅佛法，所以說是「抑挫」。「抑」就是壓制遏止，「挫」就是摧折削弱。「高談」以下，斥責只有空言卻沒有實際修行。「高談」是指超脫世俗的言論。「虛論」是指言過其實的空談。收攝身心就應當舉止動靜都不放任自流，隨順教法就應當專心奉行戒律威儀。這是在說明那些好大喜功的人，論說法時好像超脫於塵世之外，檢點行為時卻混同於凡夫俗子。

【632-0008】資持記/14b_下二#42
【原文】一事行之不徹，則無量法行滅於身矣。此徒滿眼，實為寒心；真誠出家，幸無自屈。焉知丁，嗟其愚迷。上句謂迷果，下句即造因。有下，勸其詳審。鏡，鑒也。第五門，正明中，初明七日又二，前明口受須說。文列三義，即體力味，三皆強勝，故多貪著。後明手受不須。
【譯文】只要有一件事貫徹實行不了，那麼無量的法門修行就會在自己身上喪失殆盡。這種人放眼望去滿地皆是，實在令人寒心；真正發心出家的人，萬萬不要讓自己也淪落到那種地步。自「焉知」以下，感嘆他們愚昧執迷。上一句是說迷失了因果的果報，下一句就是說正在造作惡因。「有」字以下，勸勉大家要詳細審察。「鏡」就是借鑑省察的意思。在第五門「正明」這一段中，首先說明七日藥又分為兩部分，前半段說明口受（七日藥）必須說淨。經文中列出三種意義，就是藥物的體質、效力與味道，這三種都非常強烈殊勝，所以容易讓人產生貪著。後半段說明手受則不須說淨。

【632-0009】資持記/14b_下二#43
【原文】雖具三義，止齊中前故時少，貪畜心薄故過希；希亦少也。餘下，二明三藥不須。時藥有第三義，非時有初義，盡形有第二義；或復兼二，但不具三，故云反義等。指法中。藥鉢二淨，詞句無別，唯改一衣字耳。第六手受中。一不對病，二不題名，故通自他。口法中，初句標同。

【原文】若下，示義，初約縱奪以明。謂據法雖局，論藥則通。注示二通。味通者，資身治病，兼彼此故。手通如上。何下，引文為證。即長藥戒文。彼明捨有三別，六日藥還主得服，七日如鈔引，八日藥捨與淨人。《義鈔》、《戒疏》並見三十。七中，手受。可解。口受中，初示得否。

【原文】《戒疏》止生四罪，彼云有人立五，謂服此藥今解，不然，服則有罪，不服無過；不同上四不服罪生。故知今鈔猶存昔解。問答中。《戒疏》云：有人復立生於不受。今不標古，直示今義。答中，初明不生之意。非謂無不受罪，但不因口法而生故耳。不同下，舉非殘對顯。盡形中。

【632-0016】資持記/14b_下二#50
【原文】口生六罪者，牒古解也。古謂生不受故，同上防罪，名數可知。無病下，顯今義。即《戒疏》云：口不生罪，由聖開加，法不失故；縱令被觸，亦不失受。律中無病服但吉羅，以有法也；若不加法，還同墮矣。準此但結違教一吉，既不失法，則不生罪也。餘下，指證。
【譯文】口受會產生六種罪的說法，是轉述古代的解釋。古代律師認為會產生未受持的罪，所以與上面防罪的情況相同，罪名的數量是可以推知的。「無病」以下，顯明當今正確的義理。這也就是《戒疏》所說的：口受不產生罪過，是因為既然蒙佛陀聖教開許加持，受法就不會失去；縱使遭受到污觸，也不會失去受持的效力。律中規定無病而服用只結吉羅罪，是因為還有受法的緣故；如果沒有作加持法，就還是等同於犯墮罪了。依照這個道理，這裡只是結犯一條違背佛陀教誡的吉羅罪，既然沒有失去受法，也就不會額外產生罪過。「餘」字以下，指引文獻作證。
