# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【550-0001】03_業疏/14b_卷三之三#123
【原文】三、結斷中，初通結八緣必須圓具。「十」下別點遮難，初明重難，「諸」下次簡輕遮。三種須具，餘通增減。「丈夫」即年滿。若準《鈔》文「名字、年歲、衣鉢」，今此衣鉢在增減中，必應問前累示已曾加法，略之無損；通人情者，臨事自裁也。「如」下引況，《僧祇》遮多，開略如上所示。《四分》列遮，並云「未受不應受，已受得戒」，故知除前三外，改轉廣略，一切皆通。
【譯文】在第三、結語判斷中，首先通結八緣必須圓滿具備。「十」字以下分別點出遮與難，先說明嚴重的十三難，「諸」字以下其次揀別輕遮。有三種必須具備，其餘則通融增減。「丈夫」就是指年齡已滿二十歲。如果依照《事鈔》的文句所列是「名字、年歲、衣鉢」，現在這裡把衣鉢歸在可增減之列，必定是在問遮之前已再三指示受持衣鉢並加法完畢，所以省略了也不妨礙；所謂「通人情者」，是指臨事時自行裁量裁決。「如」字以下引用情況作比況，《僧祇律》遮難繁多，但開許省略如上文所揭示。《四分律》列出遮難時，都說「未受戒者不應給受，若已受戒則得戒」，由此可知除前述三種之外，改換措辭、或廣或略，一切都可以變通。

【550-0002】03_業疏/15a_卷三之四#1
【原文】初緣標指中，「廣如鈔」者，彼明三品發心并示緣境。發心則終依上品，緣境則徧該十界，如《資持》委釋。「有師出戒方便」者，未詳何人，《鈔》文亦云別抄有三十餘紙。「末代如來」者，以其知法，替補佛處故。「同十誦」者，彼云知布薩法者盡應供養，以無佛時，是人補處是也
【譯文】在第一項標示指明受戒之緣中，所謂「廣如鈔所說」，是指《事鈔》中闡明了三品發心並指示發心所緣的境界。發心則最終須依據上品心，所緣境界則普遍涵蓋十法界，如同《資持記》中所詳細解釋的。所謂「有位法師撰出受戒方便」，不知具體是哪一位法師，《事鈔》的文中也提到另外抄錄有三十多紙。所謂「末代如來」，是因為他通達戒法，替代並補處於佛位之故。所謂「與《十誦律》相同」，是指《十誦律》中說通達布薩之法的人都應當受到供養，因為在無佛之時，此人就是補處之位。

【550-0003】03_業疏/15a_卷三之四#2

【550-0004】03_業疏/15a_卷三之四#3

【譯文】在牒引解釋中，第一科首先明示所依據之處。「凡」字以下，其次說明必須依賴師長開導的原因。因為出家本務是聖道的根本基石。「素」相當於事先、向來。「懷大」有兩種：如果是為了斷除生死，就是約所斷的煩惱妄業而言；如果是為了證得聖果，就是約所趣向的極果而言。「深有由」，是點明論典的意旨。

【550-0005】03_業疏/15a_卷三之四#4
【原文】文令境上起慈悲者，以行慈救攝眾生故。如《善戒經》菩薩戒本，即七眾所受者是也。向不緣慈，如何容大？意在後也
【譯文】文中令受戒者在一切境界上生起慈悲心，是因為要實踐慈悲以救度攝受一切眾生。如同《菩薩善戒經》的菩薩戒本，也就是七眾所受的菩薩戒。假使先前不緣於慈悲，如何能夠容納大乘道法？其用意是著眼於受大戒在後。

【550-0006】03_業疏/15a_卷三之四#5
【原文】次科初釋文。「如下決疑」，疑云：今受小戒，那云徧境行慈攝眾生耶？故此通之。《善生經》即菩薩戒法，言菩薩戒以七眾戒為本者，彼云菩薩若欲受持菩薩戒者，先當淨心受七種戒，如人欲請大王，先當淨治所居屋宅等，即五、十、具三戒，約人為七耳。準此經意，凡為比丘，必受菩薩大戒。今受小戒，向前緣慈，為受大戒，故云意在後也。準知具足且就小宗，若望菩薩，猶是方便。問：《多論》有部，而云起慈，斯即分通，何殊本律？答：施小為大，無非分通，故諸部之中，時有斯意；但《四分》立教宗旨灼然，五義證成，下文具引
【譯文】在次一科中，首先解釋文句。「如下決疑」中，有人懷疑說：現在受的是小乘戒，為什麼說要遍緣一切境界行慈悲來攝受眾生呢？所以在此予以通達釋疑。《優婆塞戒經》（善生經）就是菩薩戒法，其中說菩薩戒以七眾戒為基礎，經中說菩薩若想受持菩薩戒，應當先以清淨心受持七種戒，好比有人想迎請大王，應當先將所住的房舍屋宅打掃乾淨等，這就是指五戒、十戒、具足戒三種戒，就受持之人而言分為七眾罷了。依照這部經的意旨，凡是出家作比丘，必定要進受菩薩大戒。如今受小乘戒，預先遍緣慈悲，是為了受大戒作準備，所以說「意在後也」。據此可知具足戒暫且依小乘宗義而言，若對望菩薩戒，則仍是前行方便。問：《薩婆多論》屬於有部，卻說要生起慈心，這也就是分通大乘了，與本部《四分律》有何不同？答：施設小乘作為大乘的前導，無非都是分通之意，所以各部律論之中，時常有此意旨；只不過《四分律》立教的宗旨極為明晰，有五種義理可以證成，下文將會詳細引述。

【譯文】問：羯磨作法圓滿之際得戒，在受戒者的心態上通於善、惡、無記三性嗎？

【550-0022】03_業疏/15a_卷三之四#21
【原文】答：《多論》云一切皆得。故《十誦》、《伽論》云：「知時犯，不知時清淨」者，如犯殘懺，聞出罪白後，睡不覺羯磨竟者是也。準此以通，前聞白已，後睡得戒
【譯文】答：《薩婆多論》說善、惡、無記一切心都能得戒。因此《十誦律》、《僧伽羅叉論》說：「知時犯，不知時清淨」，這好比犯了僧殘罪進行懺悔，聽聞出罪的白文之後，便睡著而沒有察覺羯磨何時念完，這種情況依然算清淨出罪。依照這個道理來融通，受戒者先前聽聞了白文之後，隨後即使睡著也能得戒。
