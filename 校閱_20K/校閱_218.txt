# 校閱材料　第218檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【218-0001】02_戒疏/05d_卷二上之一#50
【原文】【記】別釋，初中，又二。初標簡。「如」下，示相。「『婬』、『摩』開淨、授」者，「淨」對淫戒，《律》中怨逼三時無染；「授」對「摩觸」，《律》中若有所取與，相觸不犯。「離衣念捨」者，《律》中明相未出，若捨衣，或心念捨，或對首捨。又如「毀呰」開慈救，「掘」「壞」開不故，「觀軍」開有緣之類。言「失念」者，非謂染著前事，但遇此緣，彌須謹護。忘念即犯，攝意成持，故通二行。
【譯文】【記文】個別解釋中，第一種不犯又分為兩層：首先標示並簡別定義。自「如」字以下顯明行相。「淫戒、摩觸戒開許淨與授」的意思是：「淨」對應淫戒，指律中規定若遭怨家強逼，只要三時之中內心毫無染著，即不犯戒；「授」對應「摩觸」，指律中若因遞接物品而無意相觸，不犯。「離衣念捨」是指律中規定天明之前，如果要捨棄三衣，可以透過心念捨置，或對著同修捨置。又好比「譏毀戒」開許為了慈悲救護，「掘地」與「壞生草」開許非故意造作，「觀看軍陣」開許因正當事緣而前往之類。所謂「失念」，並不是指對先前的事物生起貪染，而是遇到這種因緣時，更必須謹慎護持。一旦忘失正念便構成輕微違犯，若能攝斂心意便能成就持戒，所以這一條通於犯行與不犯行兩種狀況。

【218-0007】02_戒疏/05d_卷二上之一#56
【原文】【疏】答：「深有旨也。若為鈍根，無由離惡，且勸持戒，徙惡從善，故舉世樂，以勸彼持，如文是也。若又樂福，無心涉道，非佛本意，故又訶毀。如上《涅槃》，即《戒本》末『戒淨有智慧，便得第一道』。轉鈍為利，豈不然乎？依此修行，不名為利。是於二法，立不犯行。」
【譯文】【疏文】回答：「這其中有極深奧的旨趣。如果是針對根性鈍劣的眾生，他們無從遠離惡業，便暫且勸勉他們受持戒律，遷改惡習以趨向善行，所以提出世間的安樂來勸勉他們持守，正如戒本中的文句所言。但如果一味耽溺於世間福報，全無心志趣向解脫聖道，這便違反了佛陀的本意，所以經中才會予以呵斥非議。正如前文所引《大涅槃經》，即對應戒本末尾的『持戒清淨而具備智慧，便能證得第一聖道』。使鈍根轉化為利根，難道不是這個意思嗎？若僅依此世樂而修行，就不能稱為利根（不名為利）。這就是從世樂與對治這兩種法門上，安立不犯之行。」

【218-0008】02_戒疏/05d_卷二上之一#57
【原文】【記】問中。引《戒本》偈，並上經文，呵、歎相違，故須通會。答中分三。初句總歎，「若」下，別釋。初釋戒文。「徙」，猶改也。「世樂」，即名、利、生天。「若又」下，次出《經》意。初正釋。引《戒本》以合《經》文。準知《經》局利根，《戒》通利鈍。利根捨福從道，故云「轉鈍」。非出離道，故「不為利」。「是」下，三、結示。「二法」，即以世樂、對治為不犯法。「鈍」對世樂立不犯行，「利」就對治立不犯行。是知世樂，鈍者成持，利者名犯。
【譯文】【記文】提問中，引用戒本中的偈頌，與前面引用的經文相對照，兩者一呵斥、一讚歎，彼此互相矛盾，所以必須加以會通解釋。回答分為三部分：第一句總括讚歎教旨；自「若」字以下個別解釋：首先解釋戒本文義，「徙」是改換的意思，「世樂」即指名利與投生天界。自「若又」以下，進一步道出佛經的真意：先作正面解釋，引用戒本以契合經文，由此可推知經文局限於對利根者說，戒本則通於利根與鈍根兩類人。利根之人捨棄世福而歸向聖道，所以說是「轉鈍為利」；因為追求世樂並非出離之道，所以疏文說「不名為利（不能算作利根之行）」。自「是」字以下，第三、作結語示明。「二法」就是指將世間安樂法與出世對治法當作不犯之法：對「鈍根」而言，追求世樂便能安立不犯之行；對「利根」而言，唯有專修對治才能安立不犯之行。由此可知世間安樂，對鈍根人來說算作持戒，對利根人來說便算違犯。

【218-0014】02_戒疏/05d_卷二上之一#63
【原文】【記】違順中，犯法為二。初約作犯，明犯行。注中。初示「順法」，作犯之行，與教合故；「聖」下，明「違意」，戒本顯犯，意在持故。「舉」下，次約止持，明不犯行。注中。示上「違法」，止持之行，反犯相故。不釋順意。
【譯文】【記文】在分析違背與順從的科判中，犯戒之法分為兩部分：首先針對「作犯」來說明犯戒之行。注文中：起初說明「順應法義」，因為作惡犯戒的行為與教文所描述的相符；自「聖」字以下，說明「違背制意」，因為戒本揭示犯相，本意是讓人持守。自「舉」字以下，接著針對「止持」來說明不犯之行。注文中：說明上面的「違背法義」，因為止惡持戒的行徑，與犯戒之相截然相反。此處沒有再贅述順應聖意。

【218-0015】02_戒疏/05d_卷二上之一#64
【原文】【疏】二、舉不犯法，明二行者。
【譯文】【疏文】第二、舉出不犯之法，用以說明兩種行持。

【218-0016】02_戒疏/05d_卷二上之一#65
【原文】【疏】先解開犯為不犯者。舉此不犯法，明犯行者，順不犯法成，違聖制意。二、不犯行者，佛意乃至戲笑，亦不許故。此不犯法，明不犯行，違不犯法成，順聖制意。
【譯文】【疏文】首先解釋開許違犯為不犯的狀況：若舉出這項不犯之法，用來說明犯戒之行，則是順應了不犯之法而成立，卻違背了聖者制戒的本意。第二種不犯戒之行：因為佛陀的本意，甚至連戲笑言論都不允許，所以若舉出這項不犯之法用來說明不犯之行，雖然違逆了不犯之法的寬鬆界線，卻深切順應了聖者制戒的本意。

【218-0017】02_戒疏/05d_卷二上之一#66
【原文】【記】「不犯法」中，三位同前。初中，又二。前明犯行。即諸戒「不犯」文中，或結小罪者，則有犯行，違順同前。二中不犯行。即約攝念現前，不違小罪故。
【譯文】【記文】在「不犯法」的範疇中，三種層次與前面相同。第一部分又分為兩點：前半說明犯戒之行，也就是各戒「不犯」的條文中，若仍有結判細微過失的，就存在著犯行，其違逆與順應的道理與前述相同；後半說明不犯之行，就是指保持正念現前，連細微罪過也不去違犯。

【218-0018】02_戒疏/05d_卷二上之一#67
【原文】【疏】二、就起對治行，明犯不犯。三、就前制不犯法，明犯不犯者。順法即順意，違法即違意，並可解耳。
【譯文】【疏文】第二、就生起對治修行，以闡明犯戒與不犯戒；第三、就前面制定的不犯之法，以闡明犯戒與不犯戒。這兩項都是順應了教法即是順應了聖意，違背了教法即是違背了聖意，這些道理都是容易理解的。

【218-0019】02_戒疏/05d_卷二上之一#68
【原文】【記】次、合明中。前別列二位，後合示違順。由此二不犯法，即是止作二持，是故順則法意兩順，違則法意俱違。
【譯文】【記文】接著在「合明」的科判中：前半個別列出兩種情況，後半合併展示其違逆與順從。由於這兩種不犯之法就是止持與作持兩種修持，因此只要順從，就是法義與本意兩皆順從；只要違背，就是法義與本意全數違背。

【218-0020】02_戒疏/05d_卷二上之一#69
【原文】【疏】上解違順，次明難易。初舉犯法，以明不犯。此行易成，離重過故。次舉不犯法，明不犯行。此行難成，自非專至，何由不犯？如戲笑等，可以情求。
【譯文】【疏文】上面解釋了違背與順從，接下來闡明困難與容易。首先舉出犯戒之法，用以說明不犯之行，這種行持容易成就，因為只需遠離粗重的過失即可。其次舉出不犯之法，用以說明不犯之行，這種行持難以成就，自己若非極其專注誠懇，憑藉什麼才能做到毫無違犯？好比戲笑等事（為何難以不犯），可以依常理推求得知。

【218-0021】02_戒疏/05d_卷二上之一#70
【原文】【記】次、難易中。以順法持戒，可有難易，是以但明不犯行耳。違法毀戒，本非所論，故無犯行。文中，初結前總標，「初」下，舉法別釋。初、明犯法。「易成」，可解。次、不犯法。「行難成」者，離輕過故。
【譯文】【記文】接著在「難易」的科判中：由於唯有順應教法來持守戒律，才談得上困難與容易，所以這裡只探討不犯之行。違背戒法而毀壞規矩，本來就不在修持的討論範圍內，所以不提犯行。文句中，起初總結前面並標示大綱；自「初」字以下，舉出法則個別解釋。先說明犯戒之法，「容易成就」這一點很容易明白。其次說明不犯之法，「難以成就」是因為必須斷除極細微過失的緣故。

【218-0022】02_戒疏/05d_卷二上之一#71
【原文】【疏】三、明輕法生二行者。
【譯文】【疏文】第三、說明輕微之法所衍生出的兩種行持。

【218-0023】02_戒疏/05d_卷二上之一#72
【原文】【疏】或有輕法生輕行，如具緣殺草木，輕心卒爾作等。或輕法生重行，害心殺蟻子等。
【譯文】【疏文】或者有輕微之法衍生出輕微之行，好比各項因緣具備下砍伐草木，只是以輕率忽視的心態倉促造作等；或者有輕微之法衍生出粗重之行，好比懷著殘害狠毒的心去殺害蟻蟲等。

【218-0024】02_戒疏/05d_卷二上之一#73
【原文】【記】三、輕中。初總標。「或」下，別釋。壞生、殺畜，同是「提」篇，俱名「輕法」。「率爾」、「害心」，業有輕重，故分二行。《成論》云「害心殺蟻，重慈心殺人」是也。
【譯文】【記文】第三、在「輕法」的科判中：首先總體標示；自「或」字以下個別解釋。損壞生草與殺害畜生，同樣屬於波逸提篇，全稱為「輕法」。「倉促率爾」與「狠心殘害」，在業道上有輕重的差異，所以區分為兩種行持。如同《成實論》所說：「懷著殘害心殺害蟻蟲，其罪業重於以慈悲心殺人」，正是這個道理。

【218-0025】02_戒疏/05d_卷二上之一#74

【218-0026】02_戒疏/05d_卷二上之一#75
【原文】【疏】具緣行四重，三時無悔心，是名重法生重行。或本無方便，後無隨喜，事不得已，此重法生輕行。

【218-0028】02_戒疏/05d_卷二上之一#77

【218-0032】02_戒疏/05d_卷二上之一#81
【原文】【疏】言通制者。元聖制戒，為止業因。造業已來，必由三毒。無以卒制，且約身口。二業既清，心自沈靜，能見過本。望其本意，為防心也。未了心性，約相遣塵，故制四重，以為道體。對四制餘，並號「深防」，恐犯四本，制餘令護。何以知然？配篇種類，可以知也。
【譯文】【疏文】談到通泛的制戒原理：當初聖者佛陀制立戒律，是為了止息造業的因由。自從眾生造業以來，必定是由於貪瞋癡三毒所引發。因為無法一下完全斷除，所以暫且先約束外在的身口二業。身與口兩種行業既然清淨了，內心自然沈靜專一，便能夠照見過失的根本。回顧佛陀最初的用意，根本在於防護自心。由於凡夫未能徹底了悟清淨心性，只能依照事相遣除世塵的染著，所以佛陀制定四條根本重戒，以此作為聖道的根本主體。相對於這四條重戒而制定其餘各篇戒律，全都可以稱為「深切防範」；這是深恐僧眾違犯了四根本罪，所以制定其餘條文來令人警惕防護。怎麼知道是如此呢？只要對照各篇所收納的戒律種類，就可以明白了。
