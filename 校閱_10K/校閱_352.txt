# 校閱材料　第352檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【記】二中，初斥釋義。「即」下，斥反切。《字林》，作丘竭反；《毛詩》音義，去謁反；《漢書》音義，其逝反。故知音「竭」殊無所據。「撿」下，總責。
【譯文】【記文】在第二段中，首先駁斥錯誤的字義解釋。「即」字以下，駁斥反切讀音的錯誤。《字林》作「丘竭反」；《毛詩音義》作「去謁反」；《漢書音義》作「其逝反」。由此可知將其讀作「竭」音是完全沒有根據的。「查檢」以下，進行總體的指責。

【352-0002】02_戒疏/02c_卷一上之二#39
【原文】【疏】又尋翻經，古譯則云「偈他頌」，今云「伽陀頌」。斯則「伽」「偈」兩聲相近，省略本故，後所出者，但云「偈言」。故知「偈他」翻為「頌」也。故今所翻無序之頌，則云「伽陀」，有序之文，便為「頌曰」，可以分也。
【譯文】【疏文】進一步探尋翻譯經典的歷史，古代的翻譯稱作「偈他頌」，現在則稱作「伽陀頌」。這說明「伽」與「偈」兩個字音非常相近，由於省去了原本詞尾的緣故，後來出產的譯本，往往只寫成「偈言」。由此可知，「偈他」翻譯為漢語就是「頌」。所以現在所翻譯的、前面沒有散文長行的孤起偈頌，就稱為「伽陀」，若前面有長行散文的重複重頌之文，就翻譯為「頌曰」，這兩者是可以清楚劃分的。

【352-0003】02_戒疏/02c_卷一上之二#40
【原文】【記】三中，先出古今不同。應法師云：「『偈』者，梵言也，正云『伽陀』，或云『室廬迦』，謂三十二字，此方當『頌』、『攝』。」、「斯」下，究存略所以。「故知」下，示華梵。「故今」下，明兩分。「今翻」謂唐翻也。「無序」即孤起偈，「有序」謂牒前重頌。此約華梵以分，義無別也。
【譯文】【記文】在第三段中，首先指出古今翻譯名稱的不同。玄應法師說：「所謂的『偈』，是梵語音譯，正音應作『伽陀』，或者稱作『室廬迦』，意思是三十二個字，在我們這裡相當於『頌』或『攝』。」「這說明」以下，探究留存與簡略的緣由。「由此可知」以下，對照漢語與梵語。「所以現在」以下，說明兩者的劃分。「現在所翻譯」指的是唐代的最新翻譯。「無序」指的就是孤起頌，「有序」則是指承接前文再次重述的重頌。這是依據梵漢兩種體例來作劃分，義理上其實沒有差別。

【352-0005】02_戒疏/02c_卷一上之二#42
【原文】【疏】就解「眾法教行喻」中，亦有兩行。初舉教為明鏡喻，顯作犯止持之人，準教立行，要由說、聽之功也。後舉教為神解喻，顯作持止犯之人，內省智略，殷鑒淨穢也。又解云：「前喻戒體，若毀若護，其果兩成；後喻戒緣，若縱若防，其因兩就。故篇聚雙列，因果具含，意可見也。」

【352-0006】02_戒疏/02c_卷一上之二#43
【原文】【記】次眾法喻，初科。由偈文云「好醜」、「勇怯」，通含持、毀，故以兩喻各對二人。據後從文，合云「兵戰喻」，今取𩰖戰必用智謀，故言「神解」耳。「又」下，復伸一判。「戒體」即五篇根本。「毀」約究竟，「護」取行成，故云「果」也。「戒緣」即「蘭」、「吉」方便。「縱」謂起心，「防」據警察，故言「因」也。「故」下，雙結如上。
【譯文】【記文】在接下來的「眾法喻」中，這是第一科。由於偈頌經文說「好與醜」、「勇與怯」，這全面涵蓋了持戒與毀戒，所以用這兩個比喻各自對應持與犯這兩種人。如果依照後文順應經文脈絡，應當稱作「兵陣作戰的比喻」，如今取其在戰場交戰中必定要運用智謀之意，所以稱之為「神解」（神妙明智）。「另一種」以下，又提出了另一種判定標準。「戒體」指的就是五篇戒律的根本究竟（根本戒法）。「毀損」著眼於造罪至究竟，「防護」著眼於戒行得以圓成，所以稱作「果」。「戒法的緣起行持」指的是偷蘭遮、惡作等前方便犯罪行為。「放縱」是指動念起心，「防範」是指警覺察省，所以稱作「因」。「所以」以下，如同上面所作的雙向結語。

【352-0013】02_戒疏/02c_卷一上之二#50
【原文】【疏】如譬所明，作持戒者，妙在方便，約止非緣，對境相陵，同「兩陣」也。強弱相傾，如「共戰」也。正智達過，明白無違，如「勇」者「進」也。癡墮居懷，無心遮約，如「怯」者「退」也。
【譯文】【疏文】正如比喻中所闡明的，修習「作持」戒法的人，其精妙之處在於善巧方便，透過自我約束來止息非理之緣，在面對外境誘惑時彼此相抗衡，這如同「兩軍對陣」。力量的強弱相互對決傾軋，如同「雙方交戰」。以正知正見明達自己的過咎，心思明白清朗而絕不違犯，如同「勇敢之人挺身前進」；愚癡放逸常駐心懷，毫無遮止約束之心，如同「膽怯之人臨陣退縮」。

【352-0014】02_戒疏/02c_卷一上之二#51
【原文】【記】次科，喻中。「約止」即能持心，「非緣」是所防過。能持、所防，則為「兩陣」。「正智」等者，謂心強過弱，持心勝也。「癡墮」等者，過強心弱，非境勝也。
【譯文】【記文】在第二科說明譬喻的段落中。「約束止息」指的是能持戒的心念，「非理之緣」是指所要防範的過失。能持戒的心與所防範的境，便構成了「兩軍對陣」。「正知正見」等語，是指持戒的心力強大而罪過微弱，持戒之心佔了上風。「愚癡放逸」等語，是指惡境力量強大而持戒心力羸弱，被非理的外境所壓制。
