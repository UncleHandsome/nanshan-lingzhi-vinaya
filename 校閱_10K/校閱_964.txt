# 校閱材料　第964檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【964-0001】資持記/02f_上一下#50
【原文】如是五法，默然者非法〔非法有罪，又不同意可訶不訶，復是默妄。〕；又云：有五法應默然，見他非法默然〔即舍利弗〕，不得伴〔亦同《母論》，鈔云大同唯伴二句耳。〕，犯重〔眾有犯重，僧體已壞，訶無益故。〕，同住〔非別界也〕，在同住地〔非場上也，此二處如，故不應訶。
【譯文】在像這五種情況下，保持沉默的人就屬於非法〔非法作法會獲罪，而且意見不同原本可以呵責卻不呵責，這又構成了盲目沉默的妄語之過〕；經文又說：有五種情況「應當保持沉默」：看見別人施行非法而保持沉默〔指的就是舍利弗尊者當時的情形〕；找不到同伴〔這也與《毘尼母論》相同，《行事鈔》所說的大體相同，指的只是關於同伴這兩句話罷了〕；大眾中有人犯了重罪〔大眾之中有人犯了根本重罪，僧團的清淨體性已經壞滅，出言呵責也毫無益處〕；處於同住的界內〔不是指界外的別界〕；在同住的大界之內〔不是在戒場之上，這兩個處所是合乎戒法的，所以不應當出言呵責〕；

【964-0002】資持記/02f_上一下#51
【原文】如是五法應默然〔此雖不同，由是開故，則非默妄。〕；又有五事應和合，若如法和合〔應來者來，三業俱集。〕，若默住之〔得訶不訶〕，若與欲〔應與欲者與欲〕，若從可信人聞〔自不違故，他云如法，我亦同和。〕，先在眾中默然而坐〔前約作法時和，此明先在眾中忍可所作。〕。下文指廣，彼亦略示。
【譯文】像這五種情況，就應當保持沉默〔這雖然意見不同，但因為是戒律所開許的特殊情況，所以不構成盲目沉默的妄語之過〕；此外又有五件事「應當共同和合」：如果羯磨如法且大眾和合〔應當來的人全都到齊，身語意三業完全集聚〕；如果默然安住其中〔雖然可以呵責卻選擇不出言呵責〕；如果依法受與欲意〔應當託付欲意的人如法託付〕；如果是從完全可信賴的人口中聽聞〔自己內心不生違逆，既然他人說合乎戒法，我也隨同大眾和合〕；預先在大眾之中默然而坐〔前面是就正式作法時的和合而言，這裡是指預先在大眾之中認可並忍受所進行的事〕。下文指引參閱詳盡的說明，那裡其實也只是提綱挈領作了精要的提示而已。

【964-0003】資持記/02f_上一下#52
【原文】第五問。欲明分齊，知法成處故。答中，初句指繁。凡有三解：一盡結文，二至說字，三至竟字。今下，判定。即第三解。破古中，初標今異古。故下，引文質非。必下，旁存舊解。故云兩得。然不訶可爾，訶則非成；若從竟字，則無此妨。下指《義鈔》，即上卷發戒時節中；
【譯文】第五個發問。是想要探究清楚羯磨完成的極限邊界，以便準確知曉戒法到底在何處才算真正成就。在解答的內容中，第一句指出了古德眾說紛紜非常繁複。大體上有三種解釋：第一種認為必須唸完整個結尾文句，第二種認為只要唸到「說」字為止，第三種認為只要唸到「竟」字為止。下文「現在（今）」字以下，作了正式的判定。指的就是採用第三種解釋。在破除古舊說法的段落中，首先標示出今人的見解與古德不同。下文「因此（故）」字以下，引用文獻質疑其錯誤之處。下文「必定（必）」字以下，兼顧保留了古舊的解釋，所以說「兩種都可以採用（兩得）」。然而只要不出言呵責固然可以成就，但若是有人出言呵責則非法之過隨即坐實；如果以唸完「竟」字作為邊界，就不會產生這種妨礙。下文指引參閱《義鈔》，就是指上卷中論述感發戒體的時節那一章；

【964-0005】資持記/03a_上二#1
【原文】四分律行事鈔資持記上二6 釋結界篇(上二)釋結界篇結謂白二限約，即能被之法。界謂分隔彼此，即所加之處。疏云：加法約處，除彼局此，故曰界也。律云：界者作羯磨唱制限者是。又《了論疏》解，本音四摩，此云別住。謂此住作法，與餘住不相通，各不取欲，故得名也。
【譯文】《四分律行事鈔資持記》卷上二之六（釋結界篇）：【釋結界篇】
「結」是指透過一次宣告、一次表決的羯磨程序（白二羯磨）來確立限制與約定，屬於能加持運用的法則。「界」是指劃分此處與彼處的界限，屬於被加持劃定的處所。《業疏》中說：以法則加持於處所，排除界外而限定界內，所以稱為「界」。律藏中說：所謂界，就是經由羯磨唱告並制定限制範圍的處所。另外《律二十二明了論疏》解釋，「界」的梵語原本音四摩，此處翻別住，意思是居住在該處進行作法，與其他住處互不相通，彼此不用取得對方的委託同意（不取欲），因此獲得這個名稱。

【964-0006】資持記/03a_上二#2
【原文】方亦訓法，連綿為語，即下四門；為後世依承，悉名方法。然題中界字，若望初結，似通自然；今約結成，即是作法。作法有三，僧及衣食。今正明僧，餘二如後。僧復三種，大小及場。大小各三，則為七種。如是知之。敘意，初科。元始者，推制法本因。秉法者，明立界所為。然律假緣興，雖因布薩；
【譯文】「方」字在此訓釋為法，連綴成詞，就是指下文開列的四個門類；為了讓後世有所遵循，全部統稱為「方法」。然而篇題中的「界」字，如果對照最初未結的狀態，似乎涵蓋自然界；如今依據結界成立而言，指的就是作法界。作法界共有三種：僧界、衣界和食界。現在主要說明僧界，其餘兩種留待後文。僧界又細分為三種：大界、小界以及戒場。大界和小界又各分為三種，合起來共有七種。應當這樣理解。敘述制定義理的部分，為第一科。「最初由來」是探尋制定戒法的根本起因；「遵行戒法」則是說明設立界限的實際作用。然而戒律是憑藉因緣而興起的，雖然表面上起因於布薩（誦戒）；

【964-0007】資持記/03a_上二#3
【原文】至論制意，實通眾務。疏云：結界眾同之本，理須通和。餘法眾同之末，並因後起。是知除結界外，一切羯磨，並依法地。次科，釋上二句，發下制意。初敘羯磨。僧以和為義，和但在心，非言不顯，故須聲教表示僧情；人法二同，水乳無別，故云綱要。
【譯文】但深入探討佛陀制定的用意，實際上通達一切僧團事務。《業疏》中說：結界是僧團和合的根本，按理必須全體通融和睦；其他僧法則是僧團和合的枝末，都是依循結界之後才生起的。由此可知，除了結界之外，一切羯磨僧事都必須依托如法的界地才能成就。下一科，是解釋上面的兩句，以啟發下文制定的用意。首先敘述羯磨僧法。僧團是以「和合」為實質內涵，而和合存於內心，若不透過言教就無法彰顯，因此必須仰賴音聲言教來表白僧團的心意；人與僧法兩者完全和同一致，宛如水乳交融無可分別，所以稱為維繫僧團的綱要。

【964-0008】資持記/03a_上二#4
【原文】受說治諫，僧綱既舉，佛法可存；匡救之功，亦由羯磨。若據住持，實通三時；今云像運，通語滅後。於此者，即指羯磨。上二句舉三寶以彰德，下二句約時以顯功。理宜下，次明和同。以法既高勝，人必齊遵。十方者，且據閻浮。許猶使也。發起緣中分二，初二句明境廣。剡浮、閻浮、贍部，皆音轉也；
【譯文】受戒、誦戒、治罰、諫斥等僧團綱紀一旦建立起來，佛法便能長久留存於世；匡正挽救僧倫的功效，也完全依憑羯磨。如果就護持正法而言，實際上貫通於佛世的正法、像法、末法三時；如今此處提及「像法運期」，是統括佛滅度後的時期。「於此」二字，指的就是羯磨。上面兩句舉出三寶來彰顯德行，下面兩句則是就時代來顯揚功能。「理宜」以下，接著說明和合同心。因為法式既然崇高殊勝，眾人便必須齊一遵循。「十方」在此處暫且依據閻浮提（南瞻部洲）而言。「許」字在此作「使」字解。在發起因緣中分為兩段，最初兩句說明界境廣大。「剡浮」、「閻浮」、「贍部」，都是語音轉變的譯名；
