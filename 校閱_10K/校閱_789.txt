# 校閱材料　第789檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【789-0001】02_戒疏/18c_卷四上之三#34
【原文】【記】列緣中。初緣，「在家小罪」者，即汙家犯吉。三、引《僧祇》，彼不開親，還須遣置，今何引者？一、彰部別，二、令兼用，欲使暫加折辱，冀彼迴邪。五中，「食味通」者，容兼濟故。
【譯文】【記文】在列舉犯戒條件中。第一項條件提到「給予在家外道犯小罪」，指的是這種行為類似於阿諛世俗的「汙家」之失，結犯突吉羅罪。第三項引用《僧祇律》，那部律典並未開許親屬例外，依然必須吩咐他人代送或放在地上，那麼此處為何要引用呢？第一是為了彰顯各個部派律典的細部差別，第二是為了讓本宗修行者能兼融運用，藉此暫時給予外道親屬一些折服與羞辱，希望能引導他們悔改回頭、摒棄邪道。在第五項條件中提到「食物美味通於大眾」，是因為食物容許有分甘濟貧、照顧弱小的餘地。

【789-0002】02_戒疏/18c_卷四上之三#35
【原文】【註】佛將弟子從拘薩羅遊至舍衛。佛及眾僧大得餅食，令阿難分與餘乞人。遂以黏餅與女人。又以外道得食，號「禿頭居士得」。佛集僧以所聞告，因制此戒。
【譯文】【註文】佛陀帶領弟子們從拘薩羅國遊化行腳到了舍衛國。佛陀和僧團大眾獲得了信眾供養的大量餅食，佛陀吩咐阿難尊者將多餘的餅分發給其他乞討的人。阿難隨後將黏在一起的餅拿給了一位外道婦女。後來外道乞食得到這份食物後，便四處張揚宣稱：「這是光頭居士給予的。」佛陀召集僧眾並將聽到的譏評告知大家，便順應此事制定了這條戒律。

【789-0003】02_戒疏/18c_卷四上之三#36
【原文】【疏】就戒緣起中，初與女人起過，後與男食反為譏弄，是以便制。
【譯文】【疏文】在探討戒律的緣起過程時，一開始是因給予外道婦女而引發了譏嫌過失，其後又因給予外道男子食物而反遭他們的調侃戲弄，佛陀因此隨即制定了這條戒律。

【789-0004】02_戒疏/18c_卷四上之三#37
【原文】【記】戒緣，有二。初緣「女」者，《律》云是「裸形外道家女，顏貌端正」。注云「黏餅」者，阿難分餅，人各與一，二餅相黏謂是一餅，與此女人。餘乞人云：「彼與女私通，何得不與二也！」
【譯文】【記文】制戒緣起包含兩件事。第一件涉及「女子」的緣起，《四分律》記載她是「裸形外道家中的女兒，容貌極為美麗端正」。隨文註解中提到「黏在一起的餅」，是指阿難在分發餅食時，原本每人都只發給一個，但有兩張餅黏結在一起，阿難誤以為只是一個，就順手給了這位女子。其餘乞討的人見狀便起鬨造謠說：「阿難肯定與那女子有私情，不然怎會平白無故給妳兩個餅呢！」

【譯文】【註文】包括咀嚼類的「佉闍尼」食物，即從植物根莖類食品一直到果實類食品，乃至磨成細粉所製成的各類乾糧。可食用的「食」共有五種正食，如同前文各戒所詳細說明的。

【789-0010】02_戒疏/18c_卷四上之三#43
【原文】【註】尼等吉羅。不犯者，若捨著地與，若使人與，若與父母，與塔、別房作人計作食價與，若力勢強奪去，無犯。
【譯文】【註文】比丘尼等其餘出家眾違犯此條則結犯突吉羅罪。不構成犯戒的情況包括：如果把食物扔在或放置在地上讓外道自己拿取；如果派遣他人代為轉交；如果給予的是自己的親生父母；如果是給予佛塔或常住個別僧房的僱工，折算充當他們做工的伙食酬勞而給付；如果是外道仗著強大勢力強行搶奪奪走——這些情況均不算犯戒。

【789-0011】02_戒疏/18c_卷四上之三#44
【原文】【疏】戒本四句：一、犯人；二、外道士女；三、自手與食；四、結犯。
【譯文】【疏文】此條戒本的文句分為四個部分：第一、指出犯戒的主體；第二、指出對象是出家的外道男女；第三、說明親自動手遞與食物的行為動作；第四、正式判定其違犯的罪名。

【789-0012】02_戒疏/18c_卷四上之三#45
【原文】【疏】《多論》云：「外道本唯六師，一師教十五弟子，各各受行異見。六師各別有法，與資不同。師及資通數九十六。如是相傳，常有不絕。」
【譯文】【疏文】《薩婆多論》記載：「外道原本只有六位大宗師，每位宗師各自傳授十五名得力弟子，師徒各自奉行不同的偏狹邪見。六位宗師各有其獨特的修法規矩，而且與門資弟子所奉之見亦互不相同。連同師長與門資徒弟通盤計算共有九十六種派別。這種邪見門徑代代相傳，世世代代從未間斷。」

【789-0013】02_戒疏/18c_卷四上之三#46
【原文】【記】戒本，釋第二中。引《論》示數。若準《僧祇》，但云「九十六道」，佛道在中，則九十五屬外道。此則各從所出，不須和會。然今此方但約李張之徒，及南方多有未魔之家，即為犯境。注「裸形」者，且標一種，實有多類。「波私婆羅闍」，即外道通名，未詳所譯。第三句，注中，先列九種不正，同前「足食」，故略舉之。「食者」下，即明五正。前犯緣中，唯衣犯吉，故知此戒制通四藥。
【譯文】【記文】在解釋戒本第二部分的文句中。引證《多論》以闡明外道門派的具體數字。如果依照《僧祇律》的說法，只籠統提到「九十六種道」，若將佛道也算在其中，則屬於邪門外道的正好有九十五種。這只是各個部派律典傳承的記述不同，並不需要強求融通一致。然而在如今東土漢地，凡是指老莊道家、方士之流，以及南方廣泛存在的各類妖妄左道之家，只要面對他們，便構成本戒所禁止的對象境界。註解中提及的「裸形外道」，只是舉出一種最醒目的典型類別，實際上外道的派別非常多樣。「波私婆羅闍」，即是古印度對出家異學外道的梵語通稱，具體的意譯內涵尚待進一步考證。第三句的註解中，先列舉了九種不正當的雜嚼類食物，與前面「足食戒」所列的名稱相同，所以此處只是簡略提過。「可食用的食」以下，則是說明五種正統的正食。依照前面的犯戒要件，只有布施衣服算作突吉羅小罪，由此可知本條戒律所禁止的範圍，通貫涵蓋了四種不同期限的所有藥食。

【789-0014】02_戒疏/18c_卷四上之三#47
【原文】【疏】尼犯亦提。今結吉羅，取方便耳。作異戒故。
【譯文】【疏文】比丘尼若是違犯本戒，依律也應當結犯波逸提墮罪。此處暫且判定為突吉羅罪，只是權宜採取方便結罪的方式罷了，目的是為了區別兩部僧團所受持的條文差異。

【789-0015】02_戒疏/18c_卷四上之三#48
【原文】【記】尼犯中，尼戒兼制白衣男子，與僧不同，故云「異戒」。
【譯文】【記文】在解釋比丘尼犯戒的段落中，比丘尼戒的條文同時連帶嚴格禁止向在家的白衣男子布施，規範對象與比丘僧截然不同，所以才稱作「異戒」。

【789-0017】02_戒疏/18c_卷四上之三#50
【原文】【疏】食前後至他家戒四十二。
【譯文】【疏文】食前、食後前往其他人家（的戒），是第四十二條。
