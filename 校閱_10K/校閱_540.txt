# 校閱材料　第540檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【540-0001】02_戒疏/09a_卷二下之二#99
【原文】【記】下品，釋迷疑中。「迷」即不識。言「約犯」同者，「疑」謂為殘、為蘭、為無罪等，「迷」謂直犯蘭、吉等。
【譯文】【記文】下品中，解釋迷惘與疑慮。「迷」就是不通曉。所謂「對照犯相也是相同的」，「疑」是指懷疑這到底構成僧殘、偷蘭遮還是無罪等，「迷」則是指根本不知而誤以為只犯偷蘭遮、突吉羅等罪。

【540-0002】02_戒疏/09a_卷二下之二#100
【原文】【疏】既無識兼，不及中故，名為「下品」。若論法犯俱有迷者，最是下下之人。而名「持」者，由於僧殘有乞無犯。
【譯文】【疏文】下品四句既然完全沒有「通曉」相兼其中，水準不及中品，所以稱為「下品」。若要論及法度與犯相全都陷入迷惘的人，那更是下品中最低劣的人。而他們之所以仍可稱為「持戒」，是因為就僧殘重罪而言，他們實質上經過了乞法且沒有犯下僧殘重過。

【540-0003】02_戒疏/09a_卷二下之二#101
【原文】【記】示品位中。初三句正示。「無識兼」者，異前中品半識相兼故。「若」下，別簡末句。「而」下，結行。
【譯文】【記文】品位高下的評定中。前三句作正面提示。「完全沒有通曉相兼」，是為了區別中品尚有一半通曉相互兼帶的特徵。「若要論及」以下，個別甄別最後一句。「而他們」以下，總結其戒行。

【540-0004】02_戒疏/09a_卷二下之二#102
【原文】【疏】問：「等同不學，疑、迷二相，結罪不同者？」
【譯文】【疏文】提問：「同樣屬於怠惰不學，為何『疑』與『迷』兩種行相，結罪卻有所不同？」

【540-0005】02_戒疏/09a_卷二下之二#103
【原文】【疏】答：「『疑』兩緣生，故是解律分有智性，故結吉羅。『不識』不爾，癡故昏迷同於黑業，故結提也。如上廣之。」
【譯文】【疏文】回答：「『疑』是因內心在兩端搖擺而生，這代表他對戒律至少還保有一分理解反省的智性，所以只結突吉羅罪。『不通曉』則不然，那是出於冥頑愚癡而全然昏昧，等同於造作黑暗惡業，所以結波逸提罪。如同前面所詳細說明的。」

【540-0006】02_戒疏/09a_卷二下之二#104
【原文】【記】門中，但問無知兩結之意。答中。初明疑相。由半涉是非，故云「兩緣生」也。「不」下，釋迷相。「黑業」，經論明白黑二業，即善惡也。此雖非惡，由癡暗心，縱毒成業，故云「同」也。
【譯文】【記文】這一門中，只是問「無知」結成兩種罪（突吉羅與波逸提）的用意。回答部分：首先說明「疑」的相狀，由於一半涉及是非，所以說「兩緣生」。「不」字以下，解釋「迷」的相狀。「黑業」：經論中說明白業、黑業兩種，就是善與惡。這裡所說的「不識」雖然不是惡，但由於愚癡暗昧的心，放縱煩惱之毒而成為業，所以說「同」於黑業。

【540-0007】02_戒疏/09a_卷二下之二#105
【原文】【疏】第七，僧尼不同門者，輕重分戒，有六不同。
【譯文】【疏文】第七，比丘僧與比丘尼戒律不同之門，若依罪罰輕重來劃分戒條，共有六種不同之處。

【540-0008】02_戒疏/09a_卷二下之二#106
【原文】【記】僧尼中，尼十七戒，今約僧中十三，對明同異。
【譯文】【記文】僧尼對照中，比丘尼僧殘有十七戒，如今就比丘僧殘的十三戒而言，相對照來說明兩眾的同異。

【540-0009】02_戒疏/09a_卷二下之二#107
【原文】【疏】言漏失者，僧重尼輕。如《多論》解：「女人煩惱染重，難拘難制，若制與重罪，惱眾生故也。」又云：「女作在屏，苦乃盈流，故輕。男子不爾，隨事能出，故重。」
【譯文】【疏文】關於故出精液這條戒，僧重而尼輕。如同《薩婆多論》的解釋：「女人的煩惱染著深重，極難約束禁制，若是制立太重的罪罰，反而會過度惱亂眾生。」論中又說：「女人自慰是在隱蔽之處，備歷艱辛費力才得以分泌流溢，所以判輕。男子則非如此，隨其施作動作便能排出，所以判重。」

【540-0010】02_戒疏/09a_卷二下之二#108
【原文】【記】明異中，初科。言「尼輕」者，但犯提故。《多論》二義，初約染心，男輕女重，教必隨教。「又」下，次約難易，則男易女難，教則緩急。
【譯文】【記文】說明相異之處，這是第一段。所謂「尼輕」，是指比丘尼只犯波逸提罪。《薩婆多論》提出兩種義理：第一是就染污心而言，男染心輕而女染心重，教化制定必定隨順其情執特性。「論中又說」以下，是就事情難易而言，男易而女難，教法因此有寬急之分。

【540-0011】02_戒疏/09a_卷二下之二#109
【原文】【疏】摩觸一戒，尼重僧輕。所以然者？尼則煩惑情重，既受摩捉必為陵逼，成大過故，方便之內，制與重名。丈夫摩捉必無陵壞，不假深防，但就限分，故制輕也。又女人貪觸情重，《律》有背夫從觸之相，如彼《賢愚》，試蛇以㲲，女住男去，情有著故。
【譯文】【疏文】摩觸這一條戒，比丘尼犯之極重而比丘犯之較輕。何以如此呢？因為女人煩惱迷惑的習性沉重，一旦接受撫摩抓捉必定會遭進一步凌辱逼迫，從而促成破戒的大過失，因此在加行方便階段，就直接安立重罪之名。而成年男子施作摩捉，通常不會隨即被侵犯破壞淨行，不需防範得如此深嚴，只需就碰觸的部位與界限來論，所以制罪較輕。再者，女人貪著撫觸的情執更為濃厚，《律藏》中記載有背棄丈夫而順從他人撫觸的記載，就像《賢愚經》中以細軟毛毯試驗兩條蛇的公案，雌蛇靜臥不動而雄蛇游移離去，正因為女人的情感對此更為執著。

【540-0012】02_戒疏/09a_卷二下之二#110
【原文】【記】摩觸中。初正示。「尼重」，即八夷之一。「所」下，顯意，兩義明之。初約陵壞有無。「又」下，次約觸情輕重。「律」下，引證。《律》明女人有十種惡業，第六謂體背夫主，若見端正男，無羞追逐，下至從彼受於觸樂。《賢愚》云：「時特叉尸梨、舍衛二國不和。特叉王欲試舍衛有聖智否，遣使送二蛇，麤細長短相似。能別雌雄，斯為大善。波斯匿王及諸群臣，無能識者。時梨耆彌歸問兒婦，婦言：『以一端細㲲，敷置於地，取此二蛇著上。雌者靜然，雄則搔擾。何以知之？女之為性，愛著細滑，得軟生染，不欲動搖；男子性剛，轉側不安，故可別也。』」疏云「女住男去」，即雌者靜然、雄者搔擾也。
【譯文】【記文】摩觸戒中。起初作正面標示。「尼重」是指直接列為八波羅夷重罪之一。「何以」以下顯明深意，從兩種法理來探討。首先是就日後被凌辱破戒的可能性。「再者」以下，是就觸覺貪染的情執輕重。「律藏」以下引文為證。《律藏》指出女人有十種惡業，第六種就是背棄夫主，若見到相貌端正的男子便不知羞恥地追逐，甚至只求從對方獲得撫觸的快感。《賢愚經》記載：「當時特叉尸梨與舍衛兩國交惡。特叉王想要試驗舍衛國是否有大智慧者，便派使者送來兩條粗細長短極為相似的蛇。若能分辨雌雄便算過關。波斯匿王與滿朝大臣無人能識。大臣梨耆彌回家詢問兒媳，兒媳說：『只要拿一匹極細的細毛毯鋪在地上，將這兩條蛇放上去。靜臥不動的是雌蛇，煩躁爬動的是雄蛇。何以得知呢？女人的天性貪愛細滑軟觸，接觸到軟物便生起染著不願動彈；男人的天性剛烈，在軟物上翻轉難安，所以能藉此分辨。』」疏文所說「女住男去」，就是指雌蛇安靜、雄蛇躁動的現象。

【540-0013】02_戒疏/09a_卷二下之二#111
【原文】【疏】言二麤語，僧重尼輕。男則剛獷無羞，為之事數，故重；女則輭弱多恥，為之義稀。又趣重果方便，縱造但結蘭罪。
【譯文】【疏文】關於兩種粗語戒，比丘僧犯之較重而比丘尼較輕。男子的天性剛暴粗獷且少羞恥，造作這種事的次數頻繁，所以罰重；女人的天性柔弱且多羞恥，造作這事的機率稀少。再者，這純粹是趣向根本淫罪的前方便，比丘尼縱使造作也僅結偷蘭遮罪。

【540-0014】02_戒疏/09a_卷二下之二#112
【原文】【記】二麤，「尼輕」，但犯蘭故。亦約二義釋之，初約稀數，「又」下，次就趣果。
【譯文】【記文】二種粗語戒，「比丘尼較輕」，是因為只犯偷蘭遮罪。同樣從兩種法理來解釋：首先是就造作的頻率多寡，「再者」以下則是就趣向果罪的性質。
