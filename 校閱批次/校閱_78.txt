# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【78-0001】02_戒疏/03b_卷一下之一#99
【原文】【疏】既犯十罪，欲令眾人知我行淨。我若露者，知我行非，不齒錄我。故望多人，還得多罪。如妄語法，一言誑多，隨人人聞，聞皆得罪。對首、心念，例如上分。
【譯文】【疏文】既犯十罪，心裡想要讓大眾都誤以為自己行持清淨。我若發露坦白，大家便會知道我的劣跡，不再將我當作同道齒列看待。所以面對多數人，相應地也會結得重重多罪。正如妄語的定罪法則一樣，一句話欺誑了多人，隨著每個人聽聞知曉，每有一人聽聞便皆結成一罪。至於對首說戒與心念說戒的情況，其條理分析皆如同前述。

【78-0002】02_戒疏/03b_卷一下之一#100

【78-0006】02_戒疏/03b_卷一下之一#104
【原文】【疏】如昔解云：「七聚之罪，六罪三處犯，或云八罪者，謂婬、觸、二麤，屏、露二處通尼及女。斯之八罪，各在當篇、二不定并初序三處犯。以不定中尼女合制，九十便離，各有其致。若欲發露，唯一處得。偷蘭一品，但是序犯。唯惡滅諍，此一偷蘭，序中、七毗尼中犯。」

【78-0007】02_戒疏/03b_卷一下之一#105
【原文】【記】六、明經處，昔解中。初總明諸聚，後別示偷蘭。初中。「六罪」約屏、露，「八罪」分尼、女。「謂」下，列罪目。「斯」下，示犯處。古謂序中通問，當篇別問，通諸篇聚，並有二罪。唯二不定，含此八罪，故涉三處。「以」下，別簡屏露離合之致，如後自辨。「若」下，示發露。一露俱無，不必三處。次偷蘭中，初二句通示，「唯」下，別簡。「惡滅諍」者，即多人語毗尼。調達破僧，辨定邪正，隨邪破正，則有蘭故。
【譯文】【記文】第六、明辨歷經篇處多少的章節中，先錄古德之解。前半段總明各聚，後半段特別指示偷蘭遮。前半段中，「六罪」是就屏處與露處而言，「八罪」則是細分比丘尼與非比丘尼婦女。「謂」字以下列出罪目。「斯」字以下說明違犯之處。古德認為戒序通問一切，各篇則專問本篇，貫通所有篇聚時各自都有兩處犯罪；唯獨二不定法涵蓋了這八種罪，所以涉及三處。「以」字以下，分別簡擇在屏處、露處離合立戒的緣由，後文自會辨析。「若」字以下，說明發露方式。在一處發露，所有重犯皆消除，不必在三處重複懺除。次偷蘭遮中，前兩句通明原則，「唯」字以下特作簡擇。「惡滅諍」是指多數人語滅諍法。提婆達多破僧時，僧團依律辨明邪正，若隨順邪黨破壞正法羯磨，則結犯偷蘭遮罪。

【原文】【疏】答：「序中問者，將說八篇，恐有犯者，乖於說聽。四事中問，例亦如之。欲說後戒，故先陳問，恐有忘悞，謂言行淨。隨篇重問，為成正說，由有犯者，不合聞故。」

【78-0014】02_戒疏/03b_卷一下之一#112
【原文】【記】問答中。初問。躡上所立，既不隨篇，則序中已具，自餘八處，過在繁累，故須通之。答中。初明序問，「四」下，釋後諸問。且舉「四事」，殘下準說。「後戒」者，通指七篇。十三中問，則指六篇。如是第論，義無別矣。「成正說」者，淨行同聞，不乖法故。
【譯文】【記文】在問答章節中。首問承接上面所立的正義，既然不侷限於當篇，則戒序發問便已具足，其餘八處豈不是顯得繁複贅餘，所以必須加以通解。回答中，前半段說明戒序發問，「四」字以下解釋後續諸篇提問。暫且以「四波羅夷法」為例，僧殘以下皆準此推論。「後戒」是通指隨後的七篇。十三僧殘後的提問，則指向後面的六篇。依此遞減類推，法理前後一貫無違。「成正說」是指清淨之人共同聽聞，法事才不致違背律規。

【78-0015】02_戒疏/03b_卷一下之一#113
【原文】【記】考今所釋，與昔天乖。「是中」則言屬在僧，問「淨」則罪通七聚。將說先問，故云問後。九處並爾，學者精詳。
【譯文】【記文】考察今師此處的闡發，與古德天差地別。「是中」兩字語法上是指在座「僧團之中」，詢問「清淨」其範圍則通達七聚所有罪過。即將說戒之前先行提問，所以稱為「問後（為說後戒而問）」。九處提問全都貫徹此一原則，研學者當細細深研。

【78-0016】02_戒疏/03b_卷一下之一#114
【原文】【疏】問：「七滅之後，無戒可說，何故復問？」
【譯文】【疏文】提問：「七滅諍法宣說完畢之後，後續已經沒有戒文可說，為何還要再次提問清淨與否？」

【78-0017】02_戒疏/03b_卷一下之一#115
【原文】【疏】答：「罪相如塵，細看細見，憶識之心，前後紛擾。隨有解悟，即須首露，靜則對人，眾則心念。尼律、法聚，七佛略教，其相如此，何得言無？故文云『更有餘佛法，應當學之』，知何不攝也？」
【譯文】【疏文】回答：「罪相細微如塵埃，唯有細細省察才能看得真切，而人心中憶念省察的狀態，往往前後紛擾不定。隨有解悟，即須發露，環境清靜人少時則對首發露，大眾僧多時則當座心念發露。比丘尼律、各犍度法聚、七佛略教戒本，其中罪相繁多，怎能說後續無戒可說？所以戒本結文中說『更有其餘佛法，皆應當善加修學』，又有什麼佛法未被包攝其中呢？」

【78-0018】02_戒疏/03b_卷一下之一#116
【原文】【記】次問中。答文為三。初通敘重問。「靜」謂人少，容可對首。「眾」謂僧多，即座心念。「尼」下，別指所說。以廣律中僧戒本後，次列尼戒，後列犍度即是法聚，皆有犯相。如言人、遊行、五衣離宿等，僧結吉羅，並出「尼律」。「法聚」可知。「略教」亦吉，如後自明。「故」下，引證。「應當學」者，即罪名也。
【譯文】【記文】在第二個提問中。回答文分為三段。前半段通盤說明重復提問的必要。「靜」是指人數少，容許即時對首發露。「眾」是指僧眾多，只能當座在心中發露悔過。「尼」字以下，具體指出後續所涵蓋的法門。因為在廣律中，比丘戒本之後依次陳列比丘尼戒，隨後陳列各篇犍度法聚，處處皆有犯戒之相。例如請人傳話、隨意遊行、五衣離宿等，比丘結犯突吉羅，皆出自「尼律」。「法聚」之相顯而易見。「略教」亦有違犯吉羅之處，後文自明。「故」字以下引律文為證。「應當學」本身就是一條罪名。

【78-0019】02_戒疏/03b_卷一下之一#117
【原文】【記】問：「略教可爾，尼律、法聚，既不列相，有何所聞而須問淨？請為通之。」
【譯文】【記文】疑問：「略教固然可說有戒相，但比丘尼律與法聚犍度，在說戒會上既然未曾逐一宣讀其相，究竟有何內容需要聽聞而必須問淨？祈請給予通釋。」

【78-0020】02_戒疏/03b_卷一下之一#118
【原文】【疏】問：「露罪為義，不藏為先。但一序問，隨問便露。何須鄭重三說九反？」
【譯文】【疏文】提問：「發露罪過的本意，以不隱藏為優先。只要戒序提問一次，隨即發露便清淨了。何苦要如此慎重其事地重複宣說三次、反覆經歷九個處所？」

【78-0021】02_戒疏/03b_卷一下之一#119
【原文】【記】第三問。似與前濫。前對序問，難後無用。此彰三九重疊之意。
【譯文】【記文】第三個提問。看似與前問相似。前問是針對戒序提問，難破後續提問無用；此處則是專門彰顯為何要「三度提問、歷經九處」層層重疊的深意。

【78-0022】02_戒疏/03b_卷一下之一#120
【原文】【疏】答：「欲明戒誥，警敕行人。如諫一事，尚有僧屏七通。露罪多惱，何為不經九處？」
【譯文】【疏文】回答：「這是為了宣明佛陀戒律敕誥，用以嚴格警惕勉勵修行之人。如同僧團勸諫破僧破戒一事，尚且要經歷私屏三度、僧中四番共七回通告。發露罪過本就伴隨著內心極大羞愧與懊惱，又為何不能歷經九個處所的反覆提問磨練？」

【78-0023】02_戒疏/03b_卷一下之一#121
【原文】【記】初答中。上二句正答。「如」下，舉況。「七通」謂屏三僧四。「通」猶徧也。
【譯文】【記文】在最初回答中。前兩句正面回答。「如」字以下舉例作比況。「七通」是指屏處三次、僧中四番。「通」在此處是「遍及」的意思。

【78-0024】02_戒疏/03b_卷一下之一#122
【原文】【疏】「或可前問有拒，或致迷妄，忽聞後問，豁然披露，時來不一，故致多翻。聖說不徒，深有其旨，因言長理，須知發露。有罪皆藏，九處成默。序中一露，下問非罪，以無重隱之愆故也。若序中問，露已還覆，隨經問處，還須露罪，以覆隨心，不由言說。如《人法》中前露後藏，文證可解。」
【譯文】【疏文】「或者有人在先前的提問中心存抗拒，或者一時陷入迷妄，忽然聽聞後續各篇的提問，豁然開朗徹底發露隱私；機緣成熟往往因時而異，所以才需要安排多次提問。聖人的制教絕非虛設，其中深含精微旨趣，藉由言教而顯發真理，修行者必須明了發露的可貴。凡有罪過一概隱藏，經歷九處便相應成就九重沉默妄語之罪。若在戒序中發露了一次，後續各篇的提問便不再構成犯罪，因為已不存在再次隱匿的過失。但若在戒序提問時發露之後，隨後又心生反悔轉為覆藏，那麼隨著後續所經歷的提問處，依舊必須重新發露罪過；因為隱覆罪過純粹隨心念而定，並不由言語形式所局限。正如《人法犍度》中所說『先發露而後又覆藏』的記載，其律文證據十分明確易解。」

【78-0025】02_戒疏/03b_卷一下之一#123
【原文】【記】次正答中。初明重問。「豁」即開發之貌。「聖」下，示制意。初通示。「有」下，別釋。初明覆經多處。「序」下，明露唯一處。「若」下，明重覆重犯。初立義，「如」下，引證。「如人法」者，彼云「有比丘犯二殘罪，覆一露一，彼罷道已，還受大戒已，先所覆後發露，先發露後覆藏，僧應與彼隨所覆二罪與覆羯磨，隨後所覆第二罪與覆羯磨」是也。
【譯文】【記文】在進一步的正面回答中。前半段說明重複提問的用意。「豁」是心地豁然開展之意。「聖」字以下揭示制教旨趣。首先作總體說明。「有」字以下作分別解釋。首先說明覆藏者罪過會歷經多處。「序」字以下說明發露只需在一處即可。「若」字以下說明重新覆藏則重新結罪。先確立理論，「如」字以下引經據典為證。「如人法者」是指律中記載「有比丘犯了兩條僧殘罪，一條覆藏、一條發露；該人還俗罷道之後，重新受了大戒，將先前所覆藏的罪予以發露，將先前已發露的罪反而加以覆藏；僧團應當針對他所覆藏的兩條罪給予防覆藏羯磨，隨其後續所覆藏的第二條罪再給予覆藏羯磨」，正是此意。

【78-0026】02_戒疏/03b_卷一下之一#124
【原文】【疏】「若爾，露罪還成覆者，首陳何益？」
【譯文】【疏文】「如果是這樣，發露了罪過竟然還可能重新變成覆藏，那麼當初在戒序首度陳白又有何益處？」

【78-0027】02_戒疏/03b_卷一下之一#125
【原文】【疏】答：「披露肝膽，慎終如始。一露不覆，隨問何愆，豈非益也！」
【譯文】【疏文】回答：「發露乃是坦露肝膽肺腑，必須貫徹慎終如始的精神。只要一次徹底發露而不再隱覆，隨後面對各處提問何來罪愆可言，這難道不就是極大的利益嗎！」

【78-0028】02_戒疏/03b_卷一下之一#126
【原文】【記】轉難中。躡前重覆，徵露無功。答中。顯前律制，意令盡露。「肝膽」即目犯心。
【譯文】【記文】在轉進詰問中。順著前文「重覆則重犯」之說，質疑最初發露毫無功德。回答中，彰顯前文佛制本懷，意在令行者徹底傾倒發露。「肝膽」是用來形容內心犯罪的隱祕心念。
