# 校閱材料　第429檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【429-0001】資持記/01b_上一上#28
【原文】第二明今述作，初文為二，初明覽古。聽采暇者，在首師講席習學之時。顧眄者，明非正學也。〔迴觀曰顧，斜視曰󱌁，音麵。〕群篇，通指前代所流也。撰集雖眾，一無可取，故曰通非等。屬音燭，訓當。非當意者，不契祖心也。上句示無取，下句出所以。問：劣則可爾，優何不契？
【譯文】第二部分是說明如今這部著作的緣起，最初一段分為兩層，第一層說明遍覽古籍。「聽采暇」是指在智首律師的講席下研習學戒的空閒時間。「顧眄」是說明並非正式正軌的研習。〔回頭看叫做「顧」，斜眼看叫做「眄」，音讀作面。〕「群篇」是通稱前代所流傳下來的著述。撰述集錄雖然眾多，卻沒有一本值得採取，所以說「通非」等語。「屬」音讀作燭，訓釋為恰當。「非屬意」是指不合祖師的心意。上句顯示毫無可取，下句指出其中的緣由。有人問：劣等的著作固然不可取，優良的又為何不契合心意呢？

【429-0002】資持記/01b_上一上#29
【原文】答：以群篇中優劣互見，優雖有取，劣不可存；欲得全優，未之有也。云非屬意，其義如斯。慈訓所興，良由於此。斐然下，次明撰述。斐然者，文章駁雜之貌，文出《論語》。〔孔子在陳思魯，乃云：吾黨之小子狂簡，斐然成章。
【譯文】回答說：因為各篇著作中優點與缺點交相參見，優點雖然可以攝取，缺點卻萬萬不可存留；若想尋得一部全盡優善的著作，那是從未有過的。說「不合心意」，其道理就在於此。慈悲的訓誨之所以興起，確實就是由於這個緣故。「斐然」以下，接著說明正式撰述。「斐然」是文章錯雜成章的樣子，文句出自《論語》。〔孔子在陳國時思念魯國，便說：「我同鄉的年輕人志向狂放而行事簡略，斐然成章。」〕

【429-0003】資持記/01b_上一上#30
【原文】作命即撰文，命謂典章之異號，即目今鈔也。〔《論語》云：為命，裨諶草創之等。正義曰命，謂政令之詞，為即作也。〕直筆者，即後批云不事虬文。此有三意：一顯行事故，二被新學故，三彰謙意故。具謂委陳行相，舒謂演布文詞，一部之文，盡於此句。〔有科此為刪四分繁，包下為引他文補，非也。
【譯文】「作命」就是撰寫篇章，「命」是典籍規章的別名，就是指如今這部《行事鈔》。〔《論語》說：「撰作政令，裨諶草創之」等。孔穎達正義說「命」是指政令之辭，「為」就是製作。〕「直筆」就是後文批註所說的「不追求典雅華麗的文辭」。這有三層深意：第一是為了顯現實踐行事的緣故，第二是為了攝受初心後學的緣故，第三是彰顯自謙心意的緣故。「具」是指委細陳述法事的行持相貌，「舒」是指敷陳鋪排語言文字，一部《行事鈔》的文字體裁，完全盡在這一句之中。〔有人把這句科判為刪除《四分律》的繁雜，把下句科判為引用其他文獻補足，那是錯誤的。〕

【429-0004】資持記/01b_上一上#31
【原文】次科，引用中為二，先列所引文。有四句。初句統収諸律，即五十祇等。次句收大小乘經。經中談律，名為隨經之律，故云隨說。第三收大小乘論。第四總諸師疏鈔，及《布薩儀》、《高僧傳》、《師資傳》、《寺誥》等。此之四句，括盡一部引用之文，是則貫攝兩乘，囊包三藏；
【譯文】接下來的科判，在論述引用的內容中分為兩層，先列出所引用的文獻。共有四句。第一句總括收錄諸部律藏，也就是《十誦律》、《五分律》、《僧祇律》等。第二句收錄大乘與小乘的經典。經中談及戒律的，稱為「隨經之律」，所以說「隨說」。第三句收錄大乘與小乘的論典。第四句總結諸位律師的疏鈔，以及《布薩儀》、《高僧傳》、《師資傳》、《寺誥》等。這四句話，概括了一部書中所引用的所有文獻，這便是貫穿攝受了大小兩乘，囊括包容了經律論三藏；

【429-0005】資持記/01b_上一上#32
【原文】遺編雜集，𭟎聚成宗；以鈔標題，義見於此。搜下，次明取捨又二，初二句取捨三藏。搜謂摘取，駁即簡除。言同異者。初約本宗他部同異相對以明搜駁，有四句。一與本宗同故搜〔《十誦》持衣加藥，諸部不足數人，《婆論》三衣局量，《五分》通量，《母論》轉欲之類。〕，二同故駁〔魚肉正食，小教咸爾，今鈔用後廢之。
【譯文】將散失的篇章雜亂的集成，網羅聚合而自成一家宗脈；以「鈔」字作為標題，深意就顯現在這裡。「搜」字以下，接著說明取捨，又分為兩層，前兩句是取捨三藏教典。「搜」是指採摘獲取，「駁」就是簡別剔除。說到「同異」：首先是就本宗與他部律之間的同異相對來說明搜求與駁除，共有四種情況。一是與本宗相同因而搜取〔如《十誦律》的持衣加持藥物、諸部律中不足數之人、《薩婆多論》三衣有固定量度、《五分律》通容衣量、《毘尼母論》轉達欲法之類。〕；二是雖然相同卻予以駁除〔如吃魚與肉當作正食，小乘教法全都如此，如今本鈔用後來的教意廢除了它。〕

【429-0008】資持記/01b_上一上#35
【原文】三他部異故搜〔《善見》三衣內穿失法，《婆論》緣斷，《雜寶藏》，俱盧舍五里，《多論》二里，竝取用之。〕，四異故駁〔《十誦》受三十九夜，《僧祇》事訖。委如〈別行〉中尋之。〕。長見下，取捨諸師文紀。何以知然？以三藏聖言，豈論短濫，義可見矣。初二句明取者。
