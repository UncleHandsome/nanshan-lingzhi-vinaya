# 校閱材料　第1804檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1804-0001】03_業疏/16b_卷三之五#25
【原文】次問中，欲彰業相，故躡相濫以為問端。答中，初通示動念成業。業體皆心，故曰「虗通」等；瞥起不定，故曰「間難」。「同時」下文，且舉一緣以明間雜。若知心念隨緣起滅，動變不恒，則善惡邪正，或離或合，剎那萬異，何止於此哉！「且」下列示，前則作俱在初，此歸第五，餘竝同前，尋文自見。問：隨動起業與隨作感業畢竟相濫，如何以分？答：作俱通一切，從用局事物。由具物故，或用不用，是以用時必兼二業。故知作俱未必有從用，從用其必兼作俱，莫非具此二心，致使業隨心發。然下隨心本據定慧，此云惡念未絕，乃是隨義明之。「故」下指例，上明八業，且據全具為言，須知業理隨念不定，故云「知有無也」。且今受體初具作俱、形俱同起，亦有要期，須師秉法即是助緣，能牽後習亦即隨心。若論隨行，作俱定有，互造、教他異緣助緣，衣鉢資具事在縱用，功成不滅，莫非隨心。如是類舉，多少可見。
【譯文】在接下來的問答中，為了彰顯業相，所以承接兩者看似混淆之處作為問端。在解答中，首先通體開示動念即造業。業體無非都是心，所以說「虛通」等；心念倏忽生起而無定，所以說「間雜（難）」。自「同時」以下文句，姑且舉出一緣來說明彼此交雜並起的情況。若是知道心念隨緣起滅、變動無常，那麼善惡邪正，或分離或聚合，一剎那間有萬千差異，哪裡止於此處所說的幾種呢！自「且」字以下分別列出，前面是把作俱列在最初，這裡歸入第五種，其餘都與前面相同，順著文句尋讀自能明了。問：隨動作而起業與隨施用而感業，兩者畢竟容易混淆，該如何區分？答：作俱通於一切境界，從用則局限於特定事物。由於具備了事物，或者使用、或者不用，因此在使用時必定同時兼具這兩種業。所以知道，作俱未必有從用，而從用則必定兼具作俱，無非都是具足了這兩種心，致使業力隨心而發起。然而下文的隨心業原本是依據禪定與智慧而論，這裡說惡念未絕，則是順應文義而引申說明罷了。自「故」字以下指明類例，上面說明八種業，姑且是依據全部具足而言，必須知道業的理趣隨著心念動態而無定準，所以說「知有無也」。況且如今受戒之體，最初具足了作俱、形俱同時生起，也有要期，必須戒師秉承羯磨法式這就是助緣，能牽引後來的修習這也就是隨心。若論及隨戒之行，作俱是必定有的；身口互造、教唆他人則是異緣與助緣；衣缽資具則是事在與從用；功德成就而不泯滅，無非都是隨心。像這樣類推列舉，其中具足多少自然可見。

【1804-0003】03_業疏/16b_卷三之五#27
【原文】八中，即明定慧心中所發無作。兩宗不同，故須並出。初釋隨定慧者，入定發慧則有，出則皆無
【譯文】在第八種中，就是說明在定心與慧心當中所發起的無作戒。有部與成實兩宗的主張不同，所以必須並列提出。首先解釋隨定心與慧心者，入定發慧時便有，出定之後則都沒有。

【1804-0004】03_業疏/16b_卷三之五#28
【原文】如《成論》云：有人言入定入道有禪無漏律儀，出定則無，是事云何？論云：出入常有，常不為惡，善心轉勝。何以然耶？有人計背支入本，背麤向細，得發無作；入支向麤，不發無作。今解不然，出入常有，雖在事亂，無作不失。今言隨心者，不隨定慧，隨生死心恒有無作，入無餘已則無業也。別脫不爾，隨形非心。故經云：「初果生惡國，道力無惡業」是矣
【譯文】正如《成實論》所說：有人說入定、入道時才有禪定律儀與無漏律儀，出定後就沒有了，這事究竟如何？論中說：無論出定入定都恆常存在，恆常不作惡事，善心轉而更加增勝。為什麼會這樣呢？有人執計違背枝末而契入根本、背離粗相而趣向細微，才能發起無作業；若契入枝末而趣向粗相，便不能發起無作業。如今解釋並非如此，出定入定都恆常存在，即使處於世俗紛擾的雜務中，無作業也不會喪失。現在所說的隨心，並非單指隨順定心慧心，而是隨逐生死心而恆常具有無作，直到進入無餘依涅槃之後才沒有業。別解脫戒則不是這樣，它是隨形命而立而非隨心。所以經中說：「證初果者生於邪惡之國，由道力的緣故而不起惡業」，就是這個道理。

【1804-0005】03_業疏/16b_卷三之五#29
【原文】成論》四節：初、牒異宗以問；「論」下立義相反，出入常有者，不局入定入道也；「何」下重徵所以。初徵，「有」下釋，又二：初敘他計，背支入本等，戒禁身口為支，定慧治心為本，淨戒不住，故名背支，而得禪定，故云入本；背麤向細，如初禪為麤，二禪為細，乃至四禪四空，迭論麤細，次第漸深，以論背入；出定住戒為背本入支，出深住淺為背細向麤，入有出無，其相如此。「今」下示正義，又四：初破執；「今」下正釋，隨生死者，死此生彼恒不失故；「入」下示盡處，謂化火焚身，入無餘依涅槃，身淪空寂，此時方無，爾前恒有，故名隨心；「別」下揀別脫。「故」下引經證，即《涅槃》說初果生殺羊家，父令殺羊，乃牽羊與刀閉之一室，竟不肯殺以至自盡，此由宿生道定戒力，可證隨生死心也
【譯文】《成實論》這段文分為四個小節：第一、牒述異宗的觀點來發問；自「論」字以下確立相反的宗義，說「無論出定入定恆常存在」，是不局限於入定與入道；自「何」字以下重新探究其所以然。首先徵問，自「有」字以下解釋，又分為兩層：第一敘述他宗的計執，所謂「背支入本」等，戒律禁制身口為枝末，定慧調治自心為根本，不住於清淨戒律，所以稱為背支，而證得禪定，所以稱為入本；所謂「背麤向細」，如初禪為粗、二禪為細，乃至四禪、四空定，互相論其粗細，次第漸深，以此來論說背離與契入；出定而安住於戒律就是背本入支，出離深定而安住於淺定就是背細向粗，入定則有而降出則無，其相狀就是如此。自「今」字以下開示正義，又分為四層：第一破除執著；自「今」字以下正式解釋，所謂「隨生死」，是死於此處生於彼處皆恆常不失的緣故；自「入」字以下指示窮盡之處，是指以三昧火焚身，進入無餘依涅槃，色身歸於虛空寂滅，此時才沒有無作，在此之前恆常存在，所以稱為隨心；自「別」字以下簡別別解脫戒；自「故」字以下引經作證，也就是《涅槃經》說初果須陀洹生於殺羊之家，父親命令他殺羊，便把羊與刀牽送進來並將他關在一間屋子裡，他終究不肯殺羊以至於自刎身亡，這是由於過去生中道戒與定戒的力量所致，由此可以證明戒體隨逐生死心。

【1804-0010】03_業疏/16b_卷三之五#34
【原文】答曰：言受戒者，創發要期，緣集成具，納法在心，名之為受。即此受體，能防非義，故名為戒。謂壇場起願，許欲攝持，未有行也
【譯文】回答說：所謂受戒，是指最初發起要期誓願，因緣和合聚集具足，將戒法納受於自心之中，稱之為「受」。也就是這所納受的戒體，具有防禦非違之惡的功用，所以稱之為「戒」。這是說在戒壇道場發起誓願，承諾想要攝持戒法，此時尚未有實際的隨行。

【1804-0011】03_業疏/16b_卷三之五#35
【原文】釋受名中，初釋受義，要期是心，緣集即境，納法在心即心境相應；「即」下次示戒義；「謂」下結斷分齊
【譯文】在解釋「受戒」之名中，首先解釋「受」的含義，要期是指心，緣集就是指境，納法在心就是指心與境相互相應；自「即」字以下接著開示「戒」的含義；自「謂」字以下結定其界限分齊。
