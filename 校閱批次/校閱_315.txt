# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【315-0002】02_戒疏/16b_卷四上之一#151
【原文】【記】次緣相中。初點文。「初同俗宿」，即六群緣。「後因羅睺」者，具云羅睺羅，此云障蔽，以障佛出家，猶修羅障蔽日月故。《律》因佛制戒已，諸比丘言「當遣羅云出」。時羅云無屋住，往廁上宿。佛知之，往廁所問已，便云：「愚癡比丘，無有慈心，乃驅小兒出！況是佛子，不護我意耶？」《十誦》下，次引示。前敘未具。下明二利，即通俗流。
【譯文】【記文】在第二個緣起相貌中。首先點明文句。「最初與俗人同宿」，就是指六群比丘的這段因緣。「後來因為羅睺羅」，全稱是羅睺羅，翻譯為「障蔽」，因其出生障礙了佛陀出家，如同修羅障蔽日月一般。《四分律》記載因為佛陀制定了這條禁止同宿的戒律之後，比丘們便說「應當把羅雲趕出去」。當時羅雲年幼沒有地方可住，便跑到廁所裡過夜。佛陀知道了這件事，親自前往廁所詢問過後，便責備說：「愚癡的比丘，毫無慈悲之心，竟然把小孩子趕出房間！何況這還是我的佛子，你們怎麼一點都不體貼我的心意呢？」從「十誦律」以下，接著引證說明。前半段敘述對待未受具戒的沙彌。後半段說明兩種利益，這就涵蓋了世俗一般信眾。

【315-0006】02_戒疏/16b_卷四上之一#155
【原文】【疏】一、是未受具人男女。昔云：「男犯非女犯，以制隨宿罪，義無三夜開。」今解二俱犯，故《伽論》云：「曾前與男二夜，第三夜與女宿，隨臥轉側犯二墮也。」
【譯文】【疏文】一、對方是未受具足戒的男子或女人。過去有人主張：「此戒只在對方是男子時才犯，若是女人則不犯，因為對女人同宿隨時都會犯前一條同室宿戒，在法理上絕沒有開許過夜三宿的道理。」如今的正確解釋是兩者都犯，所以《摩得勒伽論》說：「先前如果已經與男子同宿了兩夜，第三夜又與女人同宿，那麼隨著躺臥與翻身轉側，同時觸犯兩個波逸提墮罪。」

【315-0007】02_戒疏/16b_卷四上之一#156
【原文】【疏】二、室相成。三、同宿。四、知同。五、過三夜犯。《多論》四句，人一室異，乃至人室俱異，皆犯。
【譯文】【疏文】二、房舍隔間的格局成立。三、同處在一室中過夜。四、心中明知同處。五、超過了三夜的期限便構成犯罪。《薩婆多論》提出四句分析：人同而房間換了，乃至人換了而房間也換了，全都構成犯罪。

【315-0008】02_戒疏/16b_卷四上之一#157
【原文】【記】犯緣，列示中。初緣通男女。昔謂女人自犯前戒，故局男犯。彼以意裁，今憑教斷，《伽論》二墮，豈非明據？下引《多論》，四句並犯者，恐謂人室同犯，異不犯故。人一室異，室一人異，二俱，比上可會。
【譯文】【記文】在列舉說明的犯罪因緣中。第一項因緣通於男性與女性。過去的人認為女人自身已經在前一條戒中規範了犯相，所以本戒只局限於男性對象。那是他們憑藉私意裁決，如今我們是依憑佛經論教來判定，《摩得勒伽論》明文判定結犯兩個墮罪，這難道不是最確鑿的明證嗎？下文引述《薩婆多論》，指出四種分析情況通通算犯戒，這是擔心有人誤以為必須人與房間都完全相同才算犯戒、只要有一項變換就不犯的緣故。人相同而房間換了，房間相同而人換了，人與房間全都換了，拿上述道理來對照即可完全理解。

【315-0010】02_戒疏/16b_卷四上之一#159
【原文】【疏】問：「如此宿戒，初令禁宿，後開三夜，同制一戒。何故『觀軍』初制直見，後開三夜，別立戒本，直見還犯者何邪？」
【譯文】【疏文】有人問：「如同這條過限宿戒，起初是全面禁止同宿，後來開許可以同宿三夜，將開遮統攝在同一個戒條中。為什麼『觀軍戒』最初是制定只要去看就犯戒，後來雖然開許可以停留三夜，卻另外單獨成立一條戒本，而直接去看依然算犯戒，這又是為什麼呢？」

【315-0011】02_戒疏/16b_卷四上之一#160
【原文】【疏】答：「未受同宿戒，本犯由於宿，後開二、三夜，永無初宿犯。軍本由觀犯，後緣開三夜，別戒過三犯。觀軍不是宿，猶有觀軍犯。」
【譯文】【疏文】回答：「未受具戒人同宿這條戒，最初犯戒的根源全在於『同宿』這件事，後來開許了二至三夜，在開許範圍內就永遠不再有最初同宿便犯戒的情形了。觀軍戒最初犯戒的根源是在於『觀看』軍隊這件事，後來因為特殊因緣開許可以停留三夜，另外立了一條超過三夜才犯的戒。然而觀看軍隊本來就不是住宿，所以在開許停留期間，隨意觀看軍陣依然保有犯觀軍戒的過失。」

【315-0012】02_戒疏/16b_卷四上之一#161
【原文】【記】開合中，初問。「同宿」、「觀軍」二戒，先制後開既同，此合彼離何別？答中，初明同宿開中無犯，所以合制。「軍」下，次顯觀軍開中有犯，所以別立。
【譯文】【記文】在開合的辨析之中，首先提問。「同宿」與「觀軍」這兩條戒，先全面禁止、後給予開許的過程既然相同，為什麼此處將開遮合為一戒，而彼處卻將開遮分為兩條戒呢？回答之中，首先說明同宿戒在開許的期限內是完全不構成犯罪的，所以合併在同一條戒中。「觀軍」以下，接著顯現觀軍戒在開許的期限內依然有其犯戒的行為，所以必須另外單獨建立一條戒。

【315-0013】02_戒疏/16b_卷四上之一#162

【315-0014】02_戒疏/16b_卷四上之一#163
【原文】【疏】答：「文列人處俱，去則無有犯，故兩列在文。『屏敷』去故犯，以有暫、永不同，濫故不入。」

【315-0015】02_戒疏/16b_卷四上之一#164
【原文】【記】次問。「三戒」，即上二戒及後「屏敷」。開限既同，出沒何異？答中，初明二戒，去則無犯，故列在文。次明「屏敷」，去則有犯。「暫」去即還，則開三夜；作意永去，出門即犯。文中若列，恐謂永去亦三夜犯，故云「濫」也。
【譯文】【記文】接著發問。「三條戒律」，就是指上述兩條戒以及後面的「在露天敷設臥具戒」。這三條戒開許的期限既然同樣都是三夜，在根本經文中的顯現與隱沒為什麼會有差別？回答之中，首先說明前兩條戒，只要人離開了就不算犯戒，所以直接列在律文正文中。接著說明「敷設臥具戒」，是人離開了反而構成犯罪。「暫時」離開隨後就回來，那麼就開許可以放置三夜；若是起心動念「永久」離去，只要一走出寺門就立刻犯戒。如果在根本律文中列入三夜的開許，恐怕會讓人誤以為永久離去也可以放寬到三夜才算犯戒，這樣就會產生「混淆濫用」，所以不列入正文之中。

【315-0019】02_戒疏/16c_卷四上之一#1
【原文】【註】若共二宿，若三宿，明相未出，應起避去。至第四宿，若自去，若使未受者去。
【譯文】【註文】如果與未受具足戒者同住兩宿，或到了第三宿，天亮前的晨光尚未顯現時，就應當起身離開迴避。若是到了第四宿，或者自己離去，或者讓未受具足戒的人離去。

【315-0022】02_戒疏/16c_卷四上之一#4
【原文】【疏】戒本五句：一、犯人；二、未受具；三、室相成；四、知同室；五、結罪。
【譯文】【疏文】戒本文句共有五句：第一是能犯戒的人；第二是未受具足戒的人；第三是同室的條件構成；第四是明知處於同一室內；第五是結定罪名。

【315-0023】02_戒疏/16c_卷四上之一#5
【原文】【記】戒本，分文中。三四二句，合云「三、共宿，四、過夜」，疑是文誤，詳之。
【譯文】【記文】科判解釋戒本。在分章段落中，第三句與第四句合併說成「第三、共同住宿，第四、度過長夜」，懷疑這是傳抄文字的訛誤，應當詳細審核。

【315-0024】02_戒疏/16c_卷四上之一#6
【原文】【疏】就注解第二句，「除僧尼餘」者，並通三趣也。罪雖階降，無不有犯。
【譯文】【疏文】關於註文解釋第二句「除去比丘與比丘尼之外的其餘對象」，這是通於（除人道外之）天、鬼、畜等三趣的。雖然所結罪名有輕重品階的降減，但無一例外都算犯戒。

【315-0025】02_戒疏/16c_卷四上之一#7
【原文】【記】釋第二中。「通三趣」者，《律》列天、修、鬼、畜，皆同吉罪，故云「階降」。
【譯文】【記文】科判解釋第二句中。所謂「通於三趣」，是指《律》本中列出了天人、阿修羅、鬼神、畜生，全都同樣結突吉羅罪，所以說是罪位「階降」。

【315-0026】02_戒疏/16c_卷四上之一#8
【原文】【疏】就「過宿」中，約戒本犯，「至三宿」者墮。剋相為言，入第三夜，臥即是犯。故《十誦戒本》「過二夜，提」。致使解者，依戒本文，有緩急也。
【譯文】【疏文】關於「超過住宿時限」當中，依循戒本來判定犯相，所謂「到了第三宿」就結墮罪。若嚴格依犯相的時間點來說，只要進入第三夜的時段，一躺下睡覺就是犯戒。所以《十誦律戒本》說「超過兩夜，便犯波逸提」。這導致後來的解釋者，依據戒本文句而有判定寬緩與嚴格的不同。

【315-0027】02_戒疏/16c_卷四上之一#9
【原文】【記】第四中，釋文為三。初約戒定犯，謂入第三初夜即犯。「故」下，會同《十誦》。「致」下，斥異解。「有緩急」者，急則同上所釋，緩謂執後廣解，謂過三夜，第四夜犯。此由不曉二處文相不同，故成紛諍。今據戒本，仍會《十誦》，入三夜犯。《鈔》依廣解，同彼《善見》，並至四夜。《鈔》、《疏》不同，下為會釋。
【譯文】【記文】科判第四句中，將疏文分為三段。最初依戒文定犯，指進入第三夜初夜即犯。「故」字以下，會合印證《十誦律》。「致」字以下，駁斥不同的異解。所謂「有緩急」，嚴格的見解就如同上方所作的解釋；寬緩的見解則是執著後文的廣解，認為必須超過三夜，到了第四夜才算犯戒。這全是由於不明白這兩處的文義行相本就不同，所以造成紛爭。如今依據戒本，並參照《十誦律》，主張進入第三夜就犯戒；《行事鈔》則依據廣解，如同《善見律》，都認為到了第四夜才犯。《行事鈔》與《戒本疏》說法不同，下文會加以會通解釋。

【315-0028】02_戒疏/16c_卷四上之一#10
【原文】【疏】注中「三夜明相未出，應起避去」，順戒本犯，不去便墮。《母論》解云：「無去處，加坐至明。」、「第四宿」時，《律》、《論》俱明自他定離。諸制開相，《鈔》中具之，大如前戒。
【譯文】【疏文】註文說「第三夜天亮前晨光尚未顯現，就應當起身離開迴避」，這是順應戒本判定犯戒的標準，若不離開便犯墮罪。《毘尼母論》解釋說：「若實在沒有可去之處，可以端坐加行直到天明。」到了「第四宿」的時刻，《律》本與論典都明確規定自己與對方必定要分離。各種制定與開許的面相，《行事鈔》中已經詳盡記載，大體都與前一條戒相同。
