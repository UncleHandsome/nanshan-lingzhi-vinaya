# 校閱材料　第823檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【823-0001】03_業疏/10b_卷二之四#24
【原文】問：前歸三寶，後更舉者？答：以三寶名通九十六道，後須顯正，非同前濫，故重別列
【譯文】問：前面已經歸依三寶，為何後面又要再次舉出？答：因為「三寶」之名通於九十六種外道，後面必須彰顯純正之佛，不同於前面可能產生混濫，所以重新各別列出。

【823-0002】03_業疏/10b_卷二之四#25
【原文】問中，正列三歸，後重舉佛，遮疑故問。答文可解。九十六者，外道通數
【譯文】在問答中，前面已正列三歸，後面又重複舉佛，為了斷除疑惑所以提問。回答的文字容易理解。所謂九十六，是外道宗派的總數。

【823-0003】03_業疏/10b_卷二之四#26
【原文】言如來者，乘如實道來成佛也；至真者，體悟無邪也；等正覺者，道同三世也。此實我歸，餘非敬也
【譯文】所謂「如來」，就是乘著真如實相之道來成正覺佛果；所謂「至真」，就是體悟真實而無偏邪；所謂「等正覺」，就是所證大道平等貫通於過去、現在、未來三世。這才是我真正歸投依止的對象，其餘的外道都不值得尊崇敬禮。

【823-0004】03_業疏/10b_卷二之四#27
【原文】牒釋中，初釋如來。乘謂能證智，如實道即所證理，悟理起修，從因至果，故云「來成佛也」。若《金剛般若》云：「無所從來，亦無所去，故名如來」，此乃就理為言。當知理無去來，修有始末，故須兩會，不可偏求。次釋正覺，真簡邪偽，等簡偏小
【譯文】在牒文解釋中，首先解釋如來。「乘」是指能證的智慧，「如實道」就是所證的真理，悟理而發起修行，從因位到達果位，所以說「來成佛也」。如果是《金剛般若經》所說：「無所從來，亦無所去，故名如來」，這則是就法性之理而言。應當知道，法性之理沒有來去，修證行持卻有始終，所以必須將理事兩方面加以會通，不可偏執一邊。接著解釋正覺，「真」揀別了偏邪偽妄，「等」則揀別了偏頗與小乘。

【823-0005】03_業疏/10b_卷二之四#28
【原文】言三授者，前受既輕，三加誓願。不同律文一說便獲，竝由機有利鈍，故使受緣多少，可以知矣
【譯文】所謂「三授」，是因為先前領受心意較為浮淺微弱，所以必須三次加強立誓立願。這不同於律文所載利根者說一次便得戒體，都是由於受戒者的根機有利有鈍，所以才導致受戒作法的繁簡多少不同，由此可以得知了。

【823-0006】03_業疏/10b_卷二之四#29
【原文】釋三授中，「前受輕」者，謂心浮薄，即鈍根者；「律文一說」謂最初開化利根之者。竝下會通，可知
【譯文】在解釋「三授」的段落中，「先前領受較輕」是指心思浮泛淺薄，也就是鈍根之人；「律文所說一次即得」是指最初度化開導利根之人的情形。自「竝由機」以下加以會通，其理便可知曉。

【823-0007】03_業疏/10b_卷二之四#30
【原文】告令戒體者，令知得時節，不比由來說後戒相方云受戒也。依此文中，開第四門義
【譯文】明白宣告戒體這件事，是為了讓受戒者明了得戒的時節，不同於從來有人誤以為要在說完後續的戒相之後才算得戒。依照這段文意，便開展出第四個義門的內容。

【823-0008】03_業疏/10b_卷二之四#31
【原文】次發戒時節中初科，初示意。「不下」遮非。《多論》云：「有言三歸竟，說一不殺戒，爾時得戒，以勢分相著，本意受五故；有言說五戒竟得戒。」恐有執此，故特揀之。彼論自云：「諸說中，受三歸已得者，此是定義」，即今所取也。「依下」點義門
【譯文】在接著論述發戒時節的第一科中，首先說明用意。自「不比由來」以下，是破斥非理執見。《薩婆多論》說：「有人說三歸依結束，戒師宣說第一條不殺生戒時，受戒者便在此時得戒，因為前勢與後續相連，本意也是要受五戒的緣故；又有人說宣說完五戒之後才得戒。」唯恐有人執著這些說法，所以特別加以揀別排除。彼論自身說道：「在諸家說法中，受完三歸依即得戒體者，這才是定論」，這正是如今所採納的觀點。自「依此文中」以下，點出所對應的義門。

【823-0009】03_業疏/10b_卷二之四#32
【原文】多論問曰：不受三歸，得五戒不？答：不得也，要先授歸方得戒矣。所以說戒名者，欲使知名，令護行故。後三結者，付囑也。八戒、十戒例亦同此。如具戒法，要用白四方得，後說四依、四墮、十三僧殘，但為知故
【譯文】《薩婆多論》提問說：若不受三歸，能得五戒嗎？回答說：不能，必須先傳授三歸才能發得戒體。之所以宣說各條戒的名目，是為了讓受戒者明了其名相，好令其如法守護戒行的緣故。後面的三次結告，是付囑叮嚀。八戒、十戒也照此例相同。就如同具足戒法，必須經過白四羯磨才能得戒，後續宣說四依法、四波羅夷（四墮）、十三僧殘，只是為了讓受戒者知曉遵守而已。

【823-0010】03_業疏/10b_卷二之四#33
【原文】引論中初科，《多論》問答。初定發體必在三歸。「所以下次」明說相結歸，別有所為。下例二戒，仍舉具戒通證說相。四墮，彼宗謂夷為墮故，論釋云：「犯四重者，由與魔鬪，墮在負處故。」又彼說前二篇是戒分故，《四分》唯說四重，據根本故
【譯文】在引述論文的第一科中，是《薩婆多論》的問答。首先確立發得戒體必定是在受三歸之時。自「所以說戒名」以下，說明宣說戒相與三歸結告乃是各自另有所用。底下以八戒、十戒二戒為例，並進一步舉出具足戒來普遍證明宣說戒相之意。「四墮」，是因為薩婆多宗將波羅夷稱為「墮」的緣故，該論解釋說：「犯四重禁者，是由於與魔相鬥，墮落在戰敗負方之處的緣故。」又彼論主張前兩篇（波羅夷與僧殘）都屬於戒分，而《四分律》則只宣說四重戒，那是依據根本要務而言的。

【823-0011】03_業疏/10b_卷二之四#34
【原文】凡具戒者，不以三歸得也，要由多緣多力、白四羯磨、功德深廣故。此據制後為言，八年已前亦由三歸發具戒也
【譯文】凡是具足戒，都不是藉由三歸依而得的，必須仰賴多種因緣、強大力量，藉白四羯磨成立，其功德深廣的緣故。這是依據佛陀制定羯磨之後的情況而言；在成道八年以前，比丘具足戒也是藉由三歸依而發得戒體的。

【823-0012】03_業疏/10b_卷二之四#35
【原文】次科，初引論釋，以三歸少緣少力，故須羯磨方發具戒。多緣力者，論云三師十僧、白四羯磨等是也。「此下」疏判，如上所解，且據八年已後為言
【譯文】下一科，首先引述論文解釋，因為三歸依屬於緣力微少，所以必須藉羯磨法才能發起具足戒。所謂多種緣力，論中說是指三師七證十位僧眾、白四羯磨等便是。自「此據制後」以下是疏主的判定，如上面所解釋，這只是就成道八年以後的情形而言。

【823-0013】03_業疏/10b_卷二之四#36
【原文】三、明示相者，即第五門義。約文為二
【譯文】第三、明示戒相，這就是第五門的義理。依照文意分為兩部分。

【823-0014】03_業疏/10b_卷二之四#37
【原文】初就相告令，隨戒分五。「盡形壽」，明所期也；「不殺生」者，所制境也；「是汝戒」者，能防本也，結以屬人；「能持不」者，牒緣問也；「答言能」者，明自誓也。一戒既爾，餘竝例同
【譯文】首先就戒相宣達告誡，隨著五戒分為五條。「盡形壽」，是表明所誓約的期限；「不殺生」，是佛所制戒的境緣；「是汝戒」，是能防非止惡的戒體根本，以此結告令其歸屬於受戒者個人；「能持不」，是就著境緣而發問；「答言能」，是受戒者親自立誓。一條戒既然如此，其餘四戒也都依此類推。

【823-0015】03_業疏/10b_卷二之四#38
【原文】第三明相告令中初文。隨戒分五，一一戒下，五句竝同，唯境為別。三云「能防本」者，釋下「戒」字；「結屬人」者，釋「是汝」字
【譯文】在第三門明示戒相宣達告誡的第一篇文字中。隨著戒法分為五條，每一條戒之下，這五句全都相同，只有所緣之境有所分別。第三句說「能防本」的，是解釋後面的「戒」字；「結屬人」的，則是解釋「是汝」二字。

【823-0016】03_業疏/10b_卷二之四#39
【原文】約此問答，從他受也。律中云：「世尊，我今歸依佛法僧，盡形不殺乃至不飲酒」，此令自誓。八戒既開，此應得也。觀時進不，義非抑塞，接俗之化，隨機而舉可也
【譯文】按這種問答作法，是屬於從他受戒。律中說：「世尊，我如今歸依佛、法、僧，盡形壽不殺生乃至不飲酒」，這是讓人自己立誓受戒。八戒既然開許自誓受，此五戒也應當可以自誓受。觀察時節因緣而決定進退，在義理上並非定要堵塞不通；接引世俗的化導之法，隨順眾生根機而推行即可。

【823-0026】03_業疏/10b_卷二之四#49
【原文】初名云戒、云齋、云關者，眾名乃異，莫不攝淨歸心也。言八戒者，八即所防之境，戒則能治之業。言八齋者，齋謂齊也，齊一其心；或言清也，靜攝其慮，如世閑室亦號齋也。言關齋者，即禁閉非逸，靜定身心也
【譯文】起初，名稱或稱為「戒」、或稱為「齋」、或稱為「關」，各種名稱雖然不同，但無不是為了攝持清淨歸於內心。稱作「八戒」者，「八」就是所防範的八種過患境界，「戒」就是能對治過非的戒行造作。稱作「八齋」者，「齋」是齊整劃一的意思，指齊一其心念；或者說是清淨的意思，指寂靜攝持其思慮，如同世間幽靜的居室也稱為「齋」。稱作「關齋」者，就是禁閉非分放逸的惡法，使身心靜止安定。
