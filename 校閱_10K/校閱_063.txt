# 校閱材料　第063檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【063-0001】01_行事鈔/04b_卷上之四#8
【原文】初中，律列四種：初對首者，此通諸界。今且就伽藍加法。當對一比丘具儀云：「大德一心念！我比丘某甲，依某僧伽藍，前三月夏安居；房舍破，修治故。」《五分》，彼人告云：「知！莫放逸！」答言：「受持！」義加：「依誰持律者？」答云：「依某律師。」告云：「有疑當往問。」若依聚落、林野等，改前伽藍住處，隨名牒入。料理修治，隨事有無。不同昔愚，皇帝聚落也。問：依寺所以料理資具者？答：修治僧房，用通三世；前人料理，得今受用；今復修理，以補將來；若闕不修，三世不續。問：持律五種，定須何者？答：《四分》云：春冬制依四種：一謂誦戒至三十，二至九十，三誦比丘戒本，四二部戒本；夏中多緣故，須善通塞也，制依第五，謂廣誦二部律。所以須者，《五分》云：有比丘自不知律，又不依持律安居，夏中生疑，又無問處。乃至佛言：往持律處安居。若房舍迮者，聽近持律師七日得往反處，於中安居；心念遙依，有疑往問。若已結前夏，遇緣破者，隨日結成。《四分》云：比丘夏中不依第五律師，得波逸提；春冬不依，突吉羅。中安居法，律有名無法，世中通用後安居法。然律列三時分明，三名顯別，準義，三法不無。既明前後，中間例準。應云：「我某甲比丘，依某巖，中三月夏安居。」必用舊法，理亦應成。後安居者，於五月十六日，同前所對之法，唯改前置後之一字。二明心念者。當具儀至靈廟前，發願乞安隱修道等，心念口言：「我某甲，依某僧坊，前三月夏安居；房舍破，修治故。」住處多種，準前對首；若中若後，亦隨二改。三明忘成。謂先要期此界，今從外來，與本心境相應；雖忘，開成。律云：忘不心念者，若為安居故來，便成安居。故知住人不入開例，由本無心。必若有要，理在通限。外來為事，不為修安，雖忘不開，以非為安故來也。四明及界與園。一脚入內，明相即出，佛開為安來者，成。餘廣如《疏》。
【譯文】初中，律列四種：第一是對首安居，這通行於各類結界之中。現在暫且就伽藍（僧院）的加法作法來說明。應當面對一位比丘具足威儀說道：「大德一心念！我比丘某甲，依某僧伽藍，前三月夏安居；房舍破，修治故。」《五分律》說，對方應告知說：「知！莫放逸！」回答說：「受持！」在義理上應加上：「依誰持律者？」回答說：「依某律師。」告知說：「有疑當往問。」若是依止聚落、林野等處，則改換前面「伽藍」住處，隨其名稱填入宣告。照料修繕房舍之語，隨事情之有無而說。不同於過去愚人的做法，竟將皇帝當作聚落名填入。問：依止寺院為何一定要照料修繕資具？答：修繕僧房，功用通於過去、現在、未來三世；前人照料，今人方得受用；今人再次修理，以補益將來；若缺漏不修，三世法事便無法相續。問：持律者有五種，必定需要哪一種？答：《四分律》說：春冬二季規定依止前四種：一是能誦戒本至三十捨墮，二是至九十單墮，三是能誦比丘戒本，四是能誦二部戒本；夏安居中事緣繁多，必須善於通達開遮通塞，故規定依止第五種，也就是能廣博背誦二部律藏者。之所以必須如此，《五分律》說：有的比丘自己不知曉戒律，又不依止持律者安居，夏中對戒律生起疑難，又無處請教。乃至佛陀說：前往有持律者之處安居。若是房舍狹隘，准許在距離持律師七天路程得以往返之處安居；在心中遙遠依止他，有疑問時前往請教。若是已經結了前安居，遇到因緣而破夏者，可隨當日重新結成。《四分律》說：比丘夏中不依止第五種律師，結波逸提（單墮罪）；春冬不依止，結突吉羅（輕垢罪）。中安居之法，律中有名稱而無具體作法，世間通常沿用後安居之法。然而律中列出三時非常分明，三種名稱顯著有別，依據義理推準，三種作法不可能沒有。既然前後安居已經明確，中間自然照此類推。應當說：「我某甲比丘，依某巖，中三月夏安居。」如果一定要用舊法，於理亦應當成就。後安居者，在五月十六日，如同前面對首所用的文法，唯獨將「前」字改置為「後」字。第二是心念安居。應當具足威儀來到靈廟（佛塔殿堂）前，發願乞求安穩修道等，心中思維口中說道：「我某甲，依某僧坊，前三月夏安居；房舍破，修治故。」住處有多種，照前文對首安居的方式類推；若是中安居或後安居，亦隨此二時相應改換字句。第三是忘記而成就（忘成）。是指原先已約定以此界為安居處，如今從外處歸來，與原本的心願與境相相應；雖然忘記作法，亦開許成就。律中說：忘記而沒有作心念者，若是為了安居之故而來，便成就安居。由此可知原住此處之人不在此開許之例，由於原本並無預先要期安居的心念。如果他原本有誓願期約，於理應當通融在開許限度內。若是自外地來是為了辦事，而非為了修習安居，即使忘記也不得開許成就，因為並非為了安居而來的緣故。第四是及時趕到僧界與僧園（及界與園）。一隻腳踏入界內，破曉明相隨即升起，佛陀開許凡是為安居而來者，即得成就。其餘詳細如《疏》所述。

【063-0002】01_行事鈔/04b_卷上之四#9
【原文】二明用法分齊。上四安居法，約時，通三位；約處，通二界；約人，通五眾。《十誦》：佛制五眾安居，乃至沙彌尼等；《四分》亦爾。約法者：對首、心念，始終三十一日結，有閏六十一日；忘成、及界，人云，唯得前後二日，中間二十九日不得用。以初二法，容預而作，故月一日結之。後二曲開，畏失前後，故局一日；中間之日，已不及前，何畏失後，故不開也。又云：唯在後夏一日。以佛開成有益；若不結者，一夏便失；餘隨憶作法，以時容預。並非聖言，以意用也。
【譯文】二明用法分齊。上述四種安居法：就時間而言，通於前、中、後三位；就處所而言，通於自然界與作法界二界；就人員而言，通於出家五眾。《十誦律》說：佛陀制定五眾安居，乃至沙彌尼等；《四分律》也是如此。就安居作法而言：對首、心念二法，自始至終有三十一天可以結安居，若遇閏月則有六十一天；至於忘成、及界二法，有人說，僅能在前安居與後安居的這兩日使用，中間二十九天不得使用。因為前兩種法可以從容寬裕地舉行，所以這一個月內的每一天都得以結安居。後兩種法是委曲開許，唯恐失卻前後安居的期限，所以局限在當日；中間的日子，既然已經趕不上前安居，又何必擔憂失去後安居，所以不開許。又有人說：只在後夏安居的那一天適用。因為佛陀開許成就極有利益；如果不結安居，整個夏安居便喪失了；其餘日子只要隨回憶起來便補作法，因為時間上尚有寬裕。這些說法都並非佛陀聖言，只是憑私意推用罷了。

【063-0003】01_行事鈔/04b_卷上之四#10
【原文】四夏中遇緣失不者。初明有難移夏，後受日逢難。
【譯文】第四、安居期內遇到事緣是否失夏。首先說明遭遇災難而遷移安居，其次說明請受受日法而遭遇災難。
