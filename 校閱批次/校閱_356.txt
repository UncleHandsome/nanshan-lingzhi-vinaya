# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【356-0001】02_戒疏/19a_卷四下之一#48
【原文】【記】戒緣。注中，初敘「降龍」，生過之由；「後遊其國」，正明犯制。初釋前段。特舉聖德以為緣起，意令凡鄙知非遠離，即舉聖況凡也。「故」下，釋次段。「草滴口中」，舉少況多也，《律》云「若以我為師者，乃至不以草木內酒中滴口」是也。注中十過：一、顏色惡；二、少力；三、眼視不明；四、現嗔恚相；五、壞業資生；六、增疾病；七、益鬪訟；八、無名稱；九、智慧少；十、命終墮三惡道。
【譯文】【記文】制戒因緣。隨律註解中，起初敘述「降伏惡龍」，這是日後生起過失的原由；「後來遊歷該國」，正式說明違犯戒制的情況。起初解釋前一段。特別舉出具備聖德的高僧作為制戒發端，用意在於令庸俗凡夫明了過非而深加遠離，這就是以聖者為例來警醒凡夫。從「因此」以下，解釋下一段。「用草葉沾酒滴入口中」，是以極少微量來比喻不可大量取用，《四分律》中記載「若是依我為師的人，甚至連用草木沾取酒液滴入口中都不可以」，指的就是這個意思。隨律註解中提到的飲酒十種過失：第一、容顏氣色枯槁醜惡；第二、身體氣力衰退；第三、眼睛昏花視物不明；第四、容易顯露嗔恨憤怒之相；第五、敗壞正業與謀生資財；第六、增加滋生身體疾病；第七、助長紛爭訴訟爭端；第八、失去清譽美名；第九、減損智慧明達；第十、命終之後墮入三惡道中。

【356-0005】02_戒疏/19a_卷四下之一#52
【原文】【註】若是酒，非酒色、香、味；若非酒，而有酒色、香、味——並不得飲。若酒煑、和合，食飲，一切墮。若飲甜味酒、酢味酒，食麴、酒糟，一切吉羅。想、疑三句墮。不犯者：若有病，餘藥治不差，以酒為藥；若以酒塗瘡——一切不犯。

【356-0009】02_戒疏/19a_卷四下之一#56
【原文】【記】次科，初釋酒相中。初通示。「故」下，指廣。彼云「《四分》中但使是酒，乃至草木作者，皆犯」，又引《十誦》「若飲似酒、醋酒、甜酒、糟醷、若麴，能醉人者，咽咽墮」，故云「皆陷刑犯」也。「疎而不漏」，出《老子》，如前已引。
【譯文】【記文】下一科判，起初解釋酒的行相。起初全面概括說明。從「所以」以下，指引更詳盡的內容。《事鈔》中說「在《四分律》中只要性質是酒，乃至是由草木所釀成的，飲用全都犯戒」，又引述《十誦律》說「如果飲用看似酒的液體、酸酒、甜酒、沉澱的糟汁、或是發酵酒麴，只要含有酒力能使人致醉的，每一口嚥下都犯墮罪」，所以說「皆會深陷罪罰」。「廣大綿密而無所脫漏」，語出《老子》，在前面已經引述過了。

【356-0010】02_戒疏/19a_卷四下之一#57
【原文】【疏】境想三句皆重。諸師云：「約心從境制。」余意不同。聖制有以，文少不了。豈有智人由來不嗅，須漿悞飲，可結提邪？此謂重者，先有方便，欲飲此酒，及舉向口，乃生非酒想、疑。約後心邊，止吉羅耳；成前方便，非重如何？《十誦律》中有此誠致。
【譯文】【疏文】對應境想的分辨中，三種判斷句均結犯重罪。許多律師主張：「這是完全依循心念是否順應客觀實境來制罪。」我的看法則有所不同。佛陀聖教制定戒律必有其深厚緣由，經律文字偶有欠缺明晰之處。世上哪有明達事理的智者，平生從不聞嗅酒氣，因口渴需要飲水而誤喝了酒，竟然也要結犯墮罪的道理？此處所指的重罪，是指先前已經動了心思手段，打算要喝這種酒，等舉杯靠近嘴邊時，內心才轉而生起這不是酒的猜想、或是起疑。如果單就後來的猶疑心念而言，原本只需結犯突吉羅罷了；但因為成就了先前打算飲酒的企圖，若不判為重罪又能如何結罪？《十誦律》中確實含有這種真實切實的道理意趣。

【356-0011】02_戒疏/19a_卷四下之一#58
【原文】【記】次科。境想中，初牒。《律》有五句。一、酒作酒想，二、非酒想，三、非酒疑，三句並提，不開迷、忘，故想、疑並重。四、非酒酒想，五、非酒酒疑，二句吉。「諸」下，古今兩判。初示古判，彼據《律》文，「約心從境」，同婬不開。「余」下，出今解，又三。初句明聖制本通。次句點結集之缺。「豈」下，舉事酌情不可如《律》。「由」，從也。「此」下，釋通《律》意。下云「《十誦》有誠致」者，彼云為恐冷發，和酒與之，不看即飲，故制。若看知非而是者開之。準此開迷，頗符今判。「誠」，即實也。「致」謂理趣。
【譯文】【記文】下一科判。辨別心境相符的情形中，起初摘出條文。《四分律》列有五種情境判斷句。第一、明知是酒而作酒想，第二、是酒而誤認為非酒想，第三、是酒而懷疑是否為酒，這三句均判處重罪，不開許糊塗迷惘或遺忘，所以無論錯想、起疑都以重罪論處。第四、實非酒而誤作酒想，第五、實非酒而懷疑是酒，這兩句則結犯突吉羅。「許多律師」以下，列出古來與現今的兩種判定。起初展示古代律師的判決，他們依據《律》文表面，主張「心念與客觀境界相符即判」，如同淫戒一樣不開許無知者。從「我的看法」以下，提出當前的理解，又分為三層。第一句說明聖人制戒原本通達情理。第二句點出律藏結集文字傳承可能有遺漏缺欠。從「世上哪有」以下，舉出實際事理並審酌常情，認為不可死板照字面理解。「由」，即是「從」的意思。從「此處所指」以下，解讀通達《四分律》的真實旨意。下文所說「《十誦律》中含有真實意趣」，是指該律記載，若為恐風寒發作，調和了酒給病僧，那人看都不看就直接喝了，因此而制戒。如果是細看之後誤以為不是酒而喝下（客觀上其實是酒），則予以開許。依照這種對迷誤者的開許，十分契合如今的判斷。「誠」，就是真實。「致」，是指道理趣旨。

【356-0012】02_戒疏/19a_卷四下之一#59
【原文】【疏】開中，「餘藥不治，酒為藥」者，非謂有病即得飲也，故須徧以餘藥治之不差，方始服之。廣如《鈔》解。
【譯文】【疏文】在開許不犯的條文中，所謂「其餘藥物無法醫治，必須以酒為藥引」，並不是指只要生病就可以隨意飲酒，必須要先普遍嘗試過其他藥物治療而無起色之後，才可以開始服用。詳細內容如《事鈔》中的解釋。

【356-0013】02_戒疏/19a_卷四下之一#60
【原文】【記】三中。恐謂病開而輒爾妄飲，故示文意，不容倚濫。「廣如《鈔》」者，彼引《五百問》云「若醫言必差，得和藥服，不得空服」等。
【譯文】【記文】第三部分。這是擔心有人藉口生病獲得開許，便輕率胡亂飲用，所以特別闡明條文真意，不容許依附藉口產生濫用弊端。「詳細內容如《事鈔》」之處，是引述了《五百問》說「如果醫生斷言必定能醫治，才得以將酒和藥一同服用，絕對不可空腹單獨飲酒」等規範。

【原文】【疏】水中戲戒五十二。
【譯文】【疏文】在水中遊戲戒，為第五十二條。

【356-0016】02_戒疏/19a_卷四下之一#63
【原文】【疏】《多論》四意。一、佛法尊重，理宜敬奉；今入水遊戲，損壞不輕。二、理應威儀庠序，外長信敬；入水遊戲，動越威容，招世譏過。三、比丘懷意，息緣修道；入水游戲，妨廢正業。四、宜修正念；入水遊戲，令心散亂，失正念故。光師云：「水性漂蕩，不可常淺，在中戲笑，上流忽增，容損身命故。」
【譯文】【疏文】《薩婆多論》提出四種制戒用意。第一，佛法無上尊貴，理應恭敬奉持；如今跳入水中嬉鬧遊戲，對佛法威儀的損害極為嚴重。第二，出家人理應威儀安詳莊重，在外令信眾增長崇敬信仰之心；入水嬉戲嬉鬧，動止超越輕浮了威儀儀態，容易招致世人的譏嫌過咎。第三，比丘內心所懷抱的志願，應當是平息外緣以專心修持道業；入水嬉戲玩樂，必定妨礙荒廢了出家正業。第四，理當修持守護正念；入水遊戲嬉鬧，會使心神散亂掉舉，從而失去正念。慧光律師說：「水性動盪漂流，深淺並非恆常不變，在水中嬉笑打鬧，倘若上游突然山洪暴發水位驟增，極有可能喪失身家性命。」

【356-0017】02_戒疏/19a_卷四下之一#64
【原文】【記】五十二，制意中。《多論》「四義」：初損辱佛法；二、乖越威儀；三、違道廢業；四、掉散失念。下引「光師」，加損命義，通前為五。
【譯文】【記文】第五十二條，在制戒用意中。《薩婆多論》的「四種用意」：第一損害侮辱佛法；第二乖違越軌威儀；第三背離修道廢棄正業；第四浮躁散亂失卻正念。下文引述「慧光律師」，增補了可能傷及性命的考量，連同前述合為五點。

【356-0018】02_戒疏/19a_卷四下之一#65
【原文】【疏】論犯三緣：一、是水，不論深淺，如弄鉢中，可是水內；二、無因緣；三、戲，便犯。
【譯文】【疏文】論述構成犯戒的三種條件：第一，確實是水，不論水域深淺，例如在缽中撥水玩弄，也算是在水裡；第二，沒有正當因緣；第三，嬉鬧戲玩，便構成犯戒。

【356-0019】02_戒疏/19a_卷四下之一#66
【原文】【記】犯緣。第一，但體是水，不論在處。二、「無緣」者，下開度水等緣，則不犯故。
【譯文】【記文】犯戒條件中。第一點，只要本質是水，不論處在何處容器。第二點「沒有正當因緣」，是因為後文開許渡水等正當因緣，此時便不算犯戒。

【356-0020】02_戒疏/19a_卷四下之一#67
【原文】【註】佛在舍衛。十七群在阿耆羅婆提河中嬉戲澆灒，波斯匿王與末利夫人在樓上見，王言：「看汝所事者。」夫人言：「是始出家，或癡無知也。」即以石蜜奉佛，便訶責制戒。
【譯文】【註文】佛陀住在舍衛國時。十七群少壯比丘在阿耆羅婆提河中嬉鬧戲水、相互潑水潑濺，波斯匿王與末利夫人在高樓上遠遠望見，國王譏諷說：「看看妳平日所事奉恭敬的人。」夫人回答說：「這些僧人是剛剛出家，或者是年輕愚鈍不知禮數罷了。」隨即派人以石蜜供養佛陀，佛陀便訶責並制定了戒律。

【356-0021】02_戒疏/19a_卷四下之一#68
【原文】【疏】戒緣中，如餘三律云，十七群並得無學，水中戲笑，生世譏過。何論下凡？故舉上聖，以約凡下也。
【譯文】【疏文】在制戒緣起中，如同其他三部律典所記載，十七群比丘其實皆已證得無學阿羅漢果，在水中嬉笑打鬧，尚且會招致世俗的譏嫌過失。何況那些低劣的下品凡夫？所以特別舉出證果的聖者為例，以此約束規整一般凡夫後學。

【356-0022】02_戒疏/19a_卷四下之一#69
【原文】【記】戒緣中。「三律」，即《五》、《十》、《祇》也。注中，初明起過。年少新學十七人共為群黨，事同六群，比上可解。「匿王」已下，次明制戒之由。王見譏嫌，夫人對王恐生輕易，又令奉蜜請佛立制。大權護法發起斯教，非凡所擬也。
【譯文】【記文】制戒因緣中。「三部律」，即指《五分律》、《十誦律》、《僧祇律》。隨律註解中，起初說明生起過失的原由。年少新受戒的十七人結為同夥群黨，行徑與六群比丘類似，對照上文即可明白。從「波斯匿王」以下，接著說明制定戒律的緣由。國王看見後產生譏嫌輕視，夫人在國王面前唯恐他因此輕視三寶，又命人敬奉石蜜請佛立法。大權菩薩護持佛法以促成這條教規的建立，絕非凡夫常情所能揣度。

【356-0026】02_戒疏/19a_卷四下之一#73
【原文】【註】除水已，若酪漿、苦酒、麥汁，器中弄，一切吉羅。不犯者：若道行渡水；或從此岸至彼岸；或水牽竹木𥱼，順流上下。若取石沙，若失物沈入水底，此沒彼出；或學知浮法，而擢臂畫水、灒水者，無犯。

【356-0027】02_戒疏/19a_卷四下之一#74
【原文】【疏】戒本三句，文相易耳。入中為洗，不戲難哉。
【譯文】【疏文】戒本條文共有三句，文字意義十分淺顯易懂。跳入水中原本是為了洗澡沐浴，若要不生嬉鬧玩樂之心實在太難了。

【356-0028】02_戒疏/19a_卷四下之一#75
【原文】【記】戒本。「三句」，大同前戒。「入」下，誡慎。此土南方入水者稀，然水性清冷，人多喜弄，準上鉢中，弄者皆犯。注不犯中，「𥱼」音牌；「擢」合作；「掉」音調，振也。
【譯文】【記文】戒本條文。「三句」，與前一條戒律大致相同。從「跳入」以下，告誡修道者應審慎提防。此地南方入水游泳的人很少，然而水性澄澈清涼，人們多半喜歡戲水玩弄，依照上文連在缽中撥水都屬違犯，嬉戲者皆會觸犯戒律。隨律註解不犯條文中，「𥱼」字音同牌（意為竹筏）；「擢」字應當作「掉」字，音調，是搖動振臂的意思。
