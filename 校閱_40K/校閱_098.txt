# 校閱材料　第098檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【098-0001】02_戒疏/04c_卷一下之二#144
【原文】【疏】問：「如殺盜等，論罪有無，人非人想，主無主想，有何義故律判不定？」
【譯文】【疏文】有人問：「例如殺生、偷盜等戒，在討論罪業成立與否時，律文中對於『是人想作非人想、有主人之物想作無主之物想』，究竟是什麼緣由，律文的判決卻往往寬嚴不定呢？」

【098-0002】02_戒疏/04c_卷一下之二#145
【原文】【疏】答：「大有意也。或緣罪境，人非人想故，但結心罪。或緣非罪境，有主無想故。然彼迷心，並不結犯，皆約前心方便為言。」
【譯文】【疏文】回答：「這當中具有非常深刻的意旨。有時心念所攀緣的是罪境，因為將活人誤想為非人（殺非人亦結罪）的緣故，所以只判定心念罪（方便罪）。有時心念所攀緣的是非罪境，因為將有主之物誤想為無主之物（取無主物無罪）的緣故，所以律判無罪。然而在真正心識陷入迷亂的當下，律文全都不判定為犯下根本大戒，那些判罪全都只是針對在迷亂之前所發起的預備謀劃心念（方便罪）而言的。」

【098-0003】02_戒疏/04c_卷一下之二#146
【原文】【記】第二難中。上云迷事聖不制犯，而律境想，結不結異，故引為問。答文，初句歎教通答。「或」下，別示有無。「然」下，結成開意。謂正迷時並無犯故，還歸事開。
【譯文】【記文】在第二個難題中。前面說對事相迷惘佛陀慈悲不判定犯戒，但律文中關於境想的規定，判罪與不判罪卻各不相同，所以引來質疑。回答的文字中，第一句讚嘆戒律的深意以作總答。「有時」以下，分別指出有罪與無罪的情況。「然而」以下，總結成立開許免罪的深意。這是指正當心念陷入迷惘的當下完全沒有真正犯戒，終究還是歸屬於事相開許免罪的原則。

【098-0004】02_戒疏/04c_卷一下之二#147
【原文】【疏】二、明作犯。
【譯文】【疏文】第二、說明作犯。

【098-0005】02_戒疏/04c_卷一下之二#148
【原文】【疏】可學事法，如初九句；不可學者，如後九句。結罪多少、輕重皆同，但犯根本以為別耳。
【譯文】【疏文】可以修學的事相與法規，如同前面的第一組九句；不可修學的，則如同後面的第二組九句。所判定的罪名多寡與輕重等級都完全相同，只是以是否觸犯了「根本大戒」作為差別而已。

【098-0006】02_戒疏/04c_卷一下之二#149
【原文】【記】作犯中，初科。可學則有九根本罪。不可學中，三識並至根本。三疑半涉本境，無不有罪，但重輕為別，如殺盜等，可以思之。三不識句，除「淫」、「酒」犯根本，餘戒轉想並有方便，本迷一切無犯。
【譯文】【記文】在作犯中，首先是第一科。若是可以修學的，就必然產生九個根本大罪。若是不可修學的，前三句凡是有「明識事相」者，毫無疑問都直接觸犯根本罪。中間三句凡是「心生疑惑」者，因為心態一半牽涉到原本的犯戒對象，所以無不獲罪，只是有輕罪與重罪的分別，例如殺生、偷盜等戒，可以深思推敲這個道理。最後三句「全然不識事相」中，除了犯「淫戒」與飲「酒戒」只要境合就一律觸犯根本罪之外，其餘戒條只要心念轉變產生誤想，都只判定為預備行為罪（方便罪），若是自始至終根本迷糊無知，則一切都不判定犯罪。

【098-0007】02_戒疏/04c_卷一下之二#150
【原文】【疏】就此根本不識事中。始終無心，如悞殺人等，不結其罪。前則有心，中後無心，但轉想疑，除婬、酒戒，餘結方便。若不差者，還結根本。若心了境，不造前事，則無罪也。
【譯文】【疏文】就這個根本的「完全不識事相」的類別中。如果自始至終完全沒有造惡的意圖，例如誤殺他人等情況，戒律完全不判定結罪。如果是起初有造惡的心思，進行中或到最後卻失去了造惡的心思，只是中途轉變了想法或生起疑惑，那麼除了淫戒與酒戒之外，其餘戒條都只判定預備行為的方便罪。如果想法沒有產生偏差，依然會判定觸犯根本大罪。如果心念已經清楚明了眼前境界，毅然停止不再造作先前預謀的惡事，那就完全沒有任何罪過了。

【098-0008】02_戒疏/04c_卷一下之二#151
【原文】【記】料簡中，初科為二。初標品位。三識三疑，俱有罪故，不須辨之。唯三不識，有無不定，故此委示。「始」下，正簡有四。初明本迷。「前」下，明轉想。「除淫、酒」者，該上本迷。「若不」下，於不可學，轉為可學。「若心」下，如善心息也。
【譯文】【記文】在辨析簡別中，第一科分為兩部分。首先標明品位層次。因為前六句的三個明識與三個疑惑全都必然獲罪，所以不需額外辨析。唯獨最後三個全然不識，罪業的有無無法一概而論，所以在此詳細說明。「自始」以下，正式辨析出四種情況。第一、說明始終完全迷惘。「起初」以下，說明中途轉變想法。「除了淫戒與酒戒」，這項例外規定涵蓋了前面所說的始終迷惘。「如果想法」以下，是指從不可學的迷惘，又轉回成了可學的清醒狀態。「如果心念」以下，是指善心生起而使惡行止息的情況。

【098-0009】02_戒疏/04c_卷一下之二#152
【原文】【疏】問：「有何等義，分二九句？」
【譯文】【疏文】有人問：「究竟是基於什麼道理，要特別劃分為這兩組九句呢？」

【098-0010】02_戒疏/04c_卷一下之二#153
【原文】【疏】答：「欲使持犯相易也。」
【譯文】【疏文】回答：「是為了讓持戒與犯戒的各種相貌，能夠容易互相比對看清。」

【098-0011】02_戒疏/04c_卷一下之二#154
【原文】【記】次科，問答。云「相易」者，謂階品差降，則結罪有無多少可見，如次所顯。
【譯文】【記文】第二科，進行問答。所謂「容易看清」，是指品位階梯的高低順序井然排列，那麼所結罪名之有無與多寡便能一目了然，正如接下來所展示的。

【098-0012】02_戒疏/04c_卷一下之二#155
【原文】【疏】故前九中，上品一句，中下各四者，由緣一事，帶疑不識，交絡互明，出其犯相。九句就事，皆結究竟。緣而不了，愚教之罪，自結不學無知也。其愚教罪，亦是究竟，無果可趣。有識無疑，則非罪攝。
【譯文】【疏文】所以在前一組九句中，上品只有一句，而中品與下品各自有四句，這是由於面對同一件事相，夾帶著疑惑與全然不識，相互交織錯綜說明，從而顯露出犯戒的各種相貌。這前九句就事相本身的發展而言，最後全都結成了圓滿犯戒的究竟根本罪。而在面對境界時卻懵懂不明，這份愚昧於教法的罪過，自然要另外判定結下不學無知罪。這份愚教之罪本身也是獨立的究竟罪責，並非還要引申趨向於其他罪果。若能清清楚楚認識教法而毫無疑惑，自然就不屬於罪過所收攝的範疇了。

【098-0013】02_戒疏/04c_卷一下之二#156
【原文】【記】明前九中。初明立句。以識等三心歷於事犯，上下不定，故云「交絡」。「九句」下，明根本罪。「緣」下，示枝條罪。古師謂是方便，故特點之。
【譯文】【記文】在闡明前一組九句中。首先說明立句的結構。因為是以明識等三種心態歷經事相與罪相，層次高低排列不定，所以稱為「相互交織」。「這前九句」以下，說明根本罪的成立。「在面對」以下，指出枝末連帶的罪名。古德誤以為這只是預備階段的方便罪，所以在此特別嚴正點出。

【098-0014】02_戒疏/04c_卷一下之二#157
【原文】【疏】論後九句，三品各三。由不識事，境非可學。不妨於犯，是可學故。致列其相，事總而罪別也。
【譯文】【疏文】論及後一組九句，上、中、下三品各有三句。這是由於全然不識事相，當前的情境並非事前修學所能避免的。但這並不妨礙對於罪名法規而言，依然屬於應當修學的範疇。因此羅列出這些相貌，呈現出事相心態統括為一、而罪相心態各自有別的局面。

【098-0015】02_戒疏/04c_卷一下之二#158
【原文】【記】次明後九，初中。略舉「不識」，必該疑心。是則三識非不可學，句法相因，故可知矣。此中立句，事但一心，且如上品上半，皆云「識事」，故云「事總」。下半犯中，識、疑、不識，三心不同，故云「罪別」。
【譯文】【記文】其次闡明後一組九句，首先是第一部分。此處文字簡略只列出「全然不識」，但必定也同時涵蓋了疑惑的心態。這樣看來，前面三句的明識事相就不屬於不可學的範疇，句型的推演互為因果，由此就可以明白了。在此處的立句架構中，事相在各品中都只固定維持一種心態，姑且以上品的前半段為例，全都稱為「明識事相」，所以稱為「事相統括為一」。後半段的罪相中，明識、疑惑、不識這三種心態各不相同，所以稱為「罪相有別」。

【098-0016】02_戒疏/04c_卷一下之二#159
【原文】【疏】問：「若據此論，識、疑二事，分句為六，可是犯攝。不識等三，便是無犯。云何說言『作犯九句』？」
【譯文】【疏文】有人問：「如果按照這種說法來推論，對事相具有明識與疑惑的心態，分開立句共有六句，確實可以被犯戒的範疇所收攝。但對於全然不識事相的三句，根本就沒有犯罪。怎麼可以籠統地宣稱這是『作犯的九句』呢？」

【098-0051】02_戒疏/05a_卷二上之一#3
【原文】【記】題中。上三字是《律》題，標所宗故。次四字是《戒本》題，示所解故。「疏」之一字，正目今文。若約人以簡，「律」及「戒本」，二並佛言。上加「四分」，則起於部主。「含注」及「疏」，乃始於南山。餘如前卷。
【譯文】【記文】題目之中，前三個字是《四分律》的律名，用來標明所宗依的根本聖典；接下來四個字是《戒本》的名稱，用來顯示本疏所要解釋的對象；「疏」這一個字，正是指眼前這部注釋之作。如果就造作之人來簡別區分：「律」與「戒本」，兩者都是佛陀親口所說；冠在前面的「四分」，則源於曇無德部主之傳承；「含注」與「疏」，乃開創於終南山道宣律師。其餘名稱義理，皆如前一卷所明。

【098-0066】02_戒疏/05a_卷二上之一#18
【原文】【記】釋初篇，敘生起中。初句指後，「且」下，顯今。上二句總標，「前」下，正敘。文為十段。初段創起，文不因前，後九皆有躡前生後，就文尋之。
【譯文】【記文】此處解釋第一篇，敘述十門生起的脈絡。開頭一句指向後面各篇，「且」字以下顯示當前正題。前兩句為總綱標示，「前」字以下為正式敘述，文意共分十段。第一段是起首初發，文字不承接前文，後面九段則各自承接前意而引發後文，順著文理即可探尋其意。

【098-0067】02_戒疏/05a_卷二上之一#19
【原文】【記】初言「戒犯」者，謂於戒有犯，或可寫倒。言「有因」者，業依惑起，故指毒為因。
【譯文】【記文】初門中說「戒犯」，是指於戒律有所違犯，或者本是「犯戒」而筆錄倒置。說「有因」，是因為惡業依煩惱而生起，所以指出三毒就是造罪的根源。

【098-0079】02_戒疏/05a_卷二上之一#31
【原文】【疏】婬之一戒，無始染本，起因三毒，成必在貪。故《善生》云：「若為自樂，是名從貪；婬怨眷屬，是名從瞋；於所生母行非梵行，是名從癡。」境交內順，非貪不辨。以癡不遂，瞋是相違，故兩不成。
【譯文】【疏文】淫欲這一條戒，是無始以來生死染著的根本，發起的根由雖然通於貪、瞋、癡三毒，但成辦之業必定在於貪愛。所以《善生經》說：「如果是為了自身受樂而行淫，這稱為從貪心生起；若是為了報復而淫亂怨家眷屬，這稱為從瞋心生起；若是對於親生母親行非梵行，這稱為從癡心生起。」境界交會而內心順從受樂，若非貪愛就無法成辦淫事。由於愚癡心難以遂行歡樂，瞋恚心更是與歡喜相違背，所以依純粹的瞋、癡兩者無法單獨成辦究竟淫罪。

【098-0080】02_戒疏/05a_卷二上之一#32
【原文】【記】配毒中，婬戒分三。初明起成。「起」即據始，「成」即取終。「故」下，引經證起；「境」下，約義辨成。
【譯文】【記文】在配屬三毒的文段中，淫戒分為三部分。首先說明罪業的起因與成辦。「起」是指造作之初，「成」是指結罪之終。「故」字以下，引用經文來印證起因；「境」字以下，依照法理來辨析成辦。

【098-0081】02_戒疏/05a_卷二上之一#33
【原文】【疏】殺盜二戒，犯通損、益，終因三事，互起相成。
【譯文】【疏文】殺生與偷盜二戒，所犯皆通於損人與益己，其究竟成辦皆由貪、瞋、癡三種緣由，彼此相互發起而共同成辦。

【098-0082】02_戒疏/05a_卷二上之一#34
【原文】【記】殺盜中，標。云「損、益」者，謂損他益己。以婬唯適己，而非惱他，殺盜兩兼，故云「通」也。
【譯文】【記文】殺、盜二戒中，先作標題。所謂「損、益」，是指損害他人、利益自己。因為淫戒只是讓自己適悅受樂，並非直接惱害他人；殺戒與盜戒則兼具損與益，所以說「通」。

【098-0083】02_戒疏/05a_卷二上之一#35
【原文】【疏】何以明之？即《善生》云：「若為己身，及諸眷屬，而取他物，是名從貪；若盜怨物，是名從瞋；劫奪下姓，是名從癡。」如《律本》中「燒、埋、壞色」，不益己故，名瞋起成。如《僧祇》中「摩摩帝互用佛、僧之物，皆犯夷」者，癡心起成。三毒互成，可以顯也。
【譯文】【疏文】何以明了這一點？《善生經》說：「如果為了自身及諸親眷屬而奪取他人物品，這稱為從貪心生起；如果偷盜仇怨之人的財物，這稱為從瞋心生起；如果是劫奪下賤種姓的財物，這稱為從癡心生起。」又如《律本》中所說「燒毀、埋沒、敗壞他人財物之顏色」，因不能利益自己，故稱為瞋心發起且由瞋心破壞而成；如《僧祇律》中說「執事人（摩摩帝）將佛物與僧物互相混用，皆犯波羅夷罪」，這是愚癡心發起並由癡心而成辦。由此可見，三毒相互資助而成業的道理便很顯明了。
