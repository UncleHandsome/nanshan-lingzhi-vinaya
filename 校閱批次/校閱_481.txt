# 校閱材料　第481檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【481-0001】資持記/09a_中三上#57
【原文】餘人，即天仙。佛印可者，還同佛說。本宗但通四人，故注以示之。《善見》，初明佛說。若下，簡餘人說；《十誦》下，次決結犯分齊。品及章段，名異義同；隨經所立，故具列之。一部多品，隨得多罪。此下，點律通漫。釋第四中，初開俱利。非始授故。若下，次開從下受法。則通同誦。
【譯文】其餘的人，就是指天人與仙人。只要受到佛陀印可認同的，就等同於佛陀親自所說。本宗戒律只通涉四種人，所以特別加注加以指明。《善見論》，首先說明佛陀宣說的範疇。從「若」以下，簡別其他人所說的法；從《十誦律》以下，接著裁決結罪的界限與分齊。所謂「品」以及「章段」，名稱雖然不同但實質意義相同；都是隨著各部經典所建立的段落，所以完全予以列出。一部經典如果有許多品，就會隨著章段的多寡而獲得多次罪過。從此以下，點出戒律文義通泛散漫之處。在解釋第四條犯緣中，首先開許對雙方都有利益的情形。因為這並不是初次啟蒙傳授的緣故。從「若」以下，接著開許向地位低下的人請教受法。這時就通融可以齊聲合誦。

【481-0002】資持記/09a_中三上#58
【原文】如是例者，以學有先後，故開從受；位有尊卑，必無師奉；故令消息，不可乖儀。然則上下亂倫，師資義倒；必有本眾，未可從他。近世愚徒，牽從儒士求學俗書。白衣高座，可恕無知；比丘行列，殊無慚色。毀辱佛法，無過於此；有智聞之，切宜深誡。不犯中三。初即口授書授，二並如法。
【譯文】像這樣的特例，是因為學問在於聞道先後，所以開許依從受學；但僧俗位次有尊卑之別，比丘絕不可將其尊奉為師（不得稱其為阿闍梨）；因此必須斟酌調度，不可違失出家威儀。既然如此，那麼尊卑上下名分錯亂，師道尊嚴蕩然無存；若僧團內部本有同眾可以請教，絕不可輕易依附外人。近代那些愚昧的無知之輩，拉拉扯扯跟隨儒生去求學世俗書籍。在家人高高坐在講台上，還可以原諒他們無知狂妄；比丘們隨眾整齊排列聽講，臉上竟然毫無羞愧慚赧之色。侮辱損毀佛門法度，沒有比這更嚴重的了；有智慧的人聽到了，切切應當深以為戒。不犯戒的條款有三種。第一是口頭傳授與書寫傳授，兩者都合乎法度規範。

【481-0003】資持記/09a_中三上#59
【原文】二同業者，謂同受學；疏云：非師資位，故曲開耳。二錯說，可解。第七。〔佛在羅閱城，有行別住比丘在下行坐，六群以所犯事向白衣說；餘比丘皆慚，故制。〕明過中。破法身者，亦同《大集》，若打破戒，罪同出萬億佛身血；疏云：豈非形服異世，為聖道標；若加輕毀，則三寶通壞；
【譯文】第二是同業道友，是指共同受教學習的同學；律疏說：這並非處在師長與弟子的名分地位，所以才曲加變通予以開許。第三是說錯（口誤），這很容易理解。第七條戒。〔佛陀在羅閱城時，有位正在修行別住罰法的比丘坐在末席，六群比丘把那位比丘所犯的罪事向在家人說出；其餘比丘都深感羞愧，佛陀因此制定此戒。〕在闡明過失中。所謂「破壞法身」，也如同《大集經》所說，若是打擊破戒僧人，罪過等同於出萬億佛身之血；律疏說：難道不是因為他們的形象與服飾有別於世俗，是通往聖道的標幟；如果對他們橫加輕慢毀辱，那麼整個三寶體系都會隨之毀壞；

【481-0004】資持記/09a_中三上#60
【原文】故雖破戒，乃是法身之器。制罪雖輕，業道尤重。緣中。第四，律因調達破僧，佛令白二差身子遍告白衣，即戒本中除僧羯磨也。釋中，初科。尼說太僧，違八敬法。不問輕重，與僧不同，故引示之。次文，《僧祇》三節，初是無法不答。若已下，明有法開答。因下，引緣誡約。
【譯文】所以即便犯戒破戒，他也依然是承載法身的尊貴器物。這在律法上制定的罪責雖然輕微，但在業道上所招感的果報卻極其深重。犯戒條件中。第四條，戒律中是因為提婆達多企圖分裂破壞僧團，佛陀才下達白二羯磨派遣舍利弗尊者傳遍告知在家人，這就是戒本中所說「除非僧團舉行如法羯磨特准」的例外。解釋之中，第一科。比丘尼若向人說大僧比丘的過失，就違犯了八敬法的規定。無論罪過輕重都不允許說，這一點與男眾比丘不同，所以特別引述出來明示。接下來的經文，《僧祇律》包含三個段落，首先是僧團沒有如法羯磨時絕不可回答。從「若已」以下，說明僧團已有如法羯磨則開許回答。從「因」以下，引用公案事緣來警誡約束。

【原文】女人偈詞，上半明所應作不作，下半示不應作反作，此言深切；有信聞之，能無愧乎！《十誦》中答詞。乃是護法綱紀，遮俗輕慢故也。三中，律文前明說犯。疏云：所以不列偷蘭名者，猶含輕重。〔重者犯提，輕則犯吉。〕若列蘭名，謂輕亦提，避濫不出也。又下，次明指人。

【481-0006】資持記/09a_中三上#62
【原文】衣服房舍，即示所說之人服篩住處。不犯中三。初不知者，反第三緣，謂迷教也。不麁想者，謂迷心也。迷重為輕，說亦犯吉；迷有為無，則無有犯。白衣先聞者，非由我說故。律中更列若眾差說。第八。〔佛在毘舍離，以前大妄語緣；集僧呵責已，便制。
【譯文】衣服房舍，就是指點出所說之人的衣服與住處。不犯戒的條款有三種。第一是不知道是粗罪者，這與第三條犯緣（知犯）相反，是指對戒教條文無知（迷教）。所謂心中不作粗罪想，是指主觀心念產生差錯（迷心）。如果誤把重罪當作輕罪，說出去也還是犯吉羅罪；若是誤把有罪當作無罪，那就完全沒有犯戒。在家人自己早已聽聞知道的，因為並不是由於我說出口才被得知的緣故。戒律中更列出如果是受僧團派遣去宣說的也不犯。第八條戒。〔佛陀在毘舍離國時，因為承接了前面大妄語戒的事由因緣；召集大眾僧團嚴厲呵責之後，便制定了這條戒。

【481-0007】資持記/09a_中三上#63
【原文】名云實得道者，此據初果已上，是戒所制。《多論》，二義故制：一大人法者，功德覆藏，諸惡發露；今稱德匿過，是小人法。二自顯聖德，賢愚各異。若有聞者，偏心專敬，失本平等淨善之心。末世事稀，故不備解。今引疏文略知緣相：一內實得道，除增上慢；二自言已證；三向未具人說；四言了；
【譯文】戒名所謂「確實證得聖道」，這是依據證得初果以上而言，正是這條戒所規範管束的對象。《薩婆多論》指出，基於兩種義理所以制定此戒：第一是大人之法，應當是將自身的功德予以隱藏覆蔽，種種過惡則要徹底發露懺悔；如今卻稱揚功德而掩蓋過失，這完全是市井小人的行徑。第二是自己彰顯超凡的聖德，世間賢明與愚鈍之人的看法各自不同。如果有人聽聞了，就會生起偏頗的心念專門敬奉這一人，因而喪失了原本平等普敬的清淨善心。末法時代這種證果之事極為罕見，所以這裡不作詳細完備的解釋。如今引用律疏的文句，讓人大致了解犯戒條件的面貌：第一是內心確實證得聖道，排除了未證言證的增上慢人；第二是親口宣說自己已經證果；第三是向尚未受具足戒的人宣說；第四是話語清晰表達完畢；

【481-0008】資持記/09b_中三上#1
【原文】五聞解。問答之意，恐疑此戒被物無功，故敘本制，知非徒爾。答中。聖既無犯，說即知凡。若不制者，世人無識，謂為實證。故雖制聖，還成制凡，故為要也。注戒云：並如初篇。若言業報〔自言業報得通〕，若戲錯，並不犯。第九。〔佛在舍衛，迦留陀夷在姑前與兒婦耳語說法因制，後開五六語及有智男也。

【481-0021】資持記/09b_中三上#14
【原文】若野火下，示緣開。《五分》中。但引作相召眾。下指諸部，同開掘壞，重故不引。釋第四緣，論文前明僧犯。僧尼作淨語者，法不對人，作不成故。餘眾不作者，有人無法，違佛制吉；掘即犯提。下明三眾。無緣犯者，有緣開故。《五分》緣開，有淨人則犯。剉草，斬乾草以和泥也。《僧祇》下注文。
【譯文】「若野火」以下，指出開許的因緣。《五分律》中。僅僅引用在地上劃出記號召集僧眾。下文指出其餘各部派律典，同樣開許掘地破壞，因為文意重複所以不再引出。解釋第四個犯戒條件，論典文字前面先說明僧人犯戒。僧人與尼僧若對彼此說清淨口令，在法理上對象不合，口令無法成立。若指使未受具戒的其餘人等而不說清淨口令，是有合格受話人卻未依法說淨語，比丘違背佛制結吉羅；受使者若動手挖掘，比丘即犯提罪（波逸提）。以下說明沙彌等三眾。無正當事由而掘地算犯戒，有正當事由則開許。《五分律》開許的因緣是，若現場有淨人指使而不指使，自己動手就犯戒。剉草，是指把乾草斬碎來攪拌泥土。《僧祇律》底下的注文。
