現行：【疏文】《了論》解釋說：「所謂粗惡有兩種：第一是意念粗惡，第二是罪行粗惡。翻對此（意粗與）罪粗，即為非粗惡。」意念上的粗惡有四種情況：第一是固執邪見而撥無善惡因果；第二是不相信苦報與樂報等業力感應；第三是放逸不知愛惜所受的清淨戒律，任由心意造作惡業；第四是深沉濁重的貪欲、瞋恚與愚癡。接下來用四句分別來判定：第一、由於起心動念粗惡，而不是由於罪行本身粗惡，例如基於上述四種粗惡意念去砍伐草木等；第二、由於罪行本身粗惡，而不是由於起心動念粗惡，例如並非出於上述四種惡念，僅是輕忽漫不經心就殺害了畜生；第三、既由於起心動念粗惡，也由於罪行本身粗惡，例如懷抱著上述四種惡念去造作殺生等重大罪行；第四、既不是由於起心動念粗惡，也不是由於罪行本身粗惡，例如遠離上述四種惡念去砍伐草木。至於「非粗惡」也有四句：第一、由於意念非粗惡，而不是由於罪行非粗惡；第二、由於罪行非粗惡，而不是由於意念非粗惡；第三、既由於意念非粗惡，也由於罪行非粗惡，如漫不經心輕忽折損了草木；第四、既非由於意念非粗惡，亦非由於罪行非粗惡，如以深重惡心造作殺害生靈的大罪。
[594] 整體看下來，這批譯文的**義理骨架大致正確**（尤其 0004／0005 的四句對應完全無誤，很難得），主要毛病集中在三類：**情緒性與程度性增譯**、**術語與體例前後不一致**、**少數術語理解不到位**。以下逐則列出。
[594] ### 【594-0004】 / 1. **「翻此罪麤」原文簡省（疑有省略）**，譯文補「（意粗與）」屬推測。建議保留原句面貌，另加譯註說明「翻＝翻對，反面即非麤」，不要把推測混入正文。 / 2. 「不信苦樂等報」→「不相信苦報與樂報等**業力感應**」：「感應」一詞帶本土信仰色彩，應作「**苦樂等果報**」。 / 3. 「用前四意行殺等罪」加「**重大**」二字可省（第二句以殺畜為罪麤，可見「罪麤」不必即重罪）。 / 4. 「所受戒」加「清淨」、四意加「深沉」等，均屬可省的修飾。 / 5. 四句的邏輯與 0005 的配對完全吻合，這部分處理得很好。
[594] ### 【594-0005】 / 1. **「次科」＝第二科（《了論》那一段）**，不是「接續上一科段」。0003 已作「初科＝第一小段」，此處應作「第二科」。 / 2. **術語跳換**：0002／0004 用「粗惡」，此則忽然改「粗重」。「麤重」在唯識學另有所指，**務必統一為「粗惡」**。 / 3. 「相翻互歷」→「彼此反轉**互為經歷**」不成話。建議：「**互相翻對、交錯配列**」。 / 4. 「孰不由斯」→「哪一個不是由此而起」指涉不清，宜作「哪一樣不是由這四心造成的呢？」 / 5. 「初即前二／二即前一」用「即」（就是），「三對前四」用「對」（相對），譯文一律作「對應」，微失分別，可斟酌。

=== 【587-0006】#20 score=8
原文：【記】八中。初明異，羯磨但違制教，法輪制、業俱犯。「何故」下，釋異所以。《多論》九義，對明重輕。文或不具，一一宜以「羯磨」、「法論」標其上，並用「故輕」、「故重」結其下。又唯第三上重下輕，餘竝上輕下重。一、二、四、八，並約法論，而有邪正、事理之別。三、五及七，並就人辨，須分師資、道俗之殊。六及後九，則兼人、法，宜辨人情、三寶之異。後偈收束，臨時配對，攝繁從要，照對易明。有本除去
現行：【記文】在第八項中。開頭先說明兩者的差異，羯磨破僧僅僅是違背了僧制戒律，法輪破僧則同時違犯了戒律制罪與業道逆罪。「何故」以下，解釋造成差異的緣由。《多論》提出九種涵義，兩兩相對辨明罪之輕重。文字若有未完全交代之處，每一條都應當在前端標示「羯磨」或「法輪」，並在文末以「所以罪輕」或「所以罪重」來作結尾。此外，唯獨第三條是前重後輕，其餘各條都是前輕後重。第一、第二、第四與第八條，都是就法義層面來論述，存在著邪正與事理的差別。第三、第五與第七條，都是就人物層面來辨析，必須區分師徒身分與道俗差異。第六條以及最後的第九條，則是兼具人與法兩方面，應當辨別僧俗人情與三寶整體的不同。後面的偈頌是用來提綱挈領，閱覽時相互配對，能夠刪繁就簡，對照起來一目了然。有的版本將此偈刪除，不知是何用意。

[587] **【587-0006】** / - 「九**義**」譯「九種**涵義**」不順，宜「九條義理／九點理由」。 / - 「一一宜以『羯磨』、『法輪』標其上」——每條是**兩者並標**，譯成「『羯磨』**或**『法輪』」語意偏了；下同「故輕」「故重」亦然。 / - 原文「法**論**」是訛字（應作「法輪」），譯文逕改可接受，但校勘本宜出註。 / - 「攝繁從要」譯「**刪**繁就簡」不妥：「攝」是收攝，不是刪除；而且緊接下文元照才批評「有本除去（刪偈）」，用「刪」字自相矛盾。宜作「統攝繁複、歸於簡要」。

=== 【592-0014】#117 score=8
原文：【疏】「律」者。八正真能調身口，離於七非，稱律，彼為非律。五邪反前，彼說為律。《了論》解：「五正道分是法，五邪道分非法。」彼說反前可知。「三正道分是毗尼，三邪道分非毗尼。」彼說反之可知。
現行：【疏文】所謂「律」。八正道切實能夠調伏身口惡業，徹底遠離七種身口過非，這才符合律的意義，提婆達多卻說這不是律。五邪法恰恰與此相反，他卻宣稱五邪法才是真正的正律。《了論》解釋說：「五正道分屬於法，五邪道分屬於非法。」提婆達多顛倒是非的說法正好與此相反，這是很容易明白的。「三正道分屬於毗尼正律，三邪道分屬於非毗尼邪律。」提婆達多顛倒反駁的說法與此相反，同樣可以想見。
[592] **【592-0014】「反駁」與「非毗尼邪律」** ⚠️ / - 「彼說反之可知」只是說**調達的說法與此相反**（正說為非、邪說為是），不是「反駁」。建議刪「反駁」，作「提婆達多的說法與此相反，可以想見」。 / - 「三邪道分**非**毗尼」＝「不是毗尼」，譯成「屬於非毗尼**邪律**」易被讀成另有一種叫「非毗尼邪律」的東西。建議：「三邪道分則不是毗尼。」

=== 【594-0001】#131 score=5
原文：【記】釋疑中。以下諸聚總歸四重，種類相通，可有破義，理無通該異種之戒。答文，亦出《多論》。「四處」謂腦、咽、心、腰也。
現行：【記文】在釋疑的段落中。既然下位各聚最終歸屬於四大重戒，在同種類的性質上相通，還可以說具有連帶破壞的含義，但法理上不可能跨越不同種類的戒條而連帶破除。回答的文字，也是出自《多論》。「四處」是指人的腦袋、咽喉、心臟以及腰部。
[594] ### 【594-0001】 / 1. **「連帶」是譯者加的**。原文只說「可有破義」「理無通該異種之戒」，沒有「連帶破壞／連帶破除」的意思。建議：「……種類相通，故可說有『破』義；但按理並不通及不同種類的戒。」 / 2. **「不可能」語氣過強**：「理無」是「按理沒有／不會」，非「不可能」。 / 3. 「既然……最終歸屬於」的因果句式是譯者補的，原文是平敘「以下諸聚總歸四重」。 / 4. **「四大重戒」宜作「四重戒（四波羅夷）」**；「四處」下加「人的」也是贅字（原文只列四處）。 / 5. 《多論》此處保留簡稱，0006／0008 卻展開為《薩婆多論》——**體例不一**（見下表）。 / 6. 「破義」的「破」究竟指破戒或破僧，須依上文確定；譯文逕以「破除」帶過，建議查證後再定詞。
