# 校閱材料　第1738檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1738-0001】03_業疏/12b_卷三之一#5
【原文】問答中。初示名義。作法久者，謂三語也。漓即是薄，故下引文證。《多論》宿業，謂往緣也；三歸亦然，亦宿業也。梵云憍梵波提，此翻牛呞，亦云牛跡，過去為牛，故口有牛呞，足有牛跡。呞，音詩，《說文》云「吐而噍也」。彼云兄弟七萬詣諸比丘所，諸比丘各盡以三語受戒。《四分》三語亦有加結，今云本無，未詳何意。有云：《四分》雖有結歸，而得戒在於三語，不同彼宗結歸方獲
【譯文】在問答之中。首先指示名相之義。「作法既久」，是指三語法。「漓」就是薄，所以下文引文為證。《薩婆多論》所說的「宿業」，是指過去世的宿緣；「三歸亦然」，也是宿業所致。梵語憍梵波提，此處翻譯為牛呞，也稱牛跡，因過去世曾轉生為牛，所以口有牛反芻咀嚼之相，足有牛蹄之跡。呞，音同「詩」，《說文解字》說：「反芻吐出而咀嚼。」該論說牛呞兄弟七萬人前往眾比丘處，眾比丘各自全都以三語為其授戒。《四分律》的三語法中其實也有加上結句，如今說本無結句，尚不清楚是何意趣。有人說：《四分律》中雖然也有結句歸依，但得戒在於說三語之時，不同於彼宗要到結句歸依時才獲取戒體。

【1738-0003】03_業疏/12b_卷三之一#7
【原文】伽論》問答即論義，三歸同上《多論》，故在局也。下《善見》亦同前《十誦》，三歸即是三語，故在通也
【譯文】《薩婆多部毘尼摩得伽論》中的問答即是論義受，三歸與上述《薩婆多論》相同，所以列入局限。下文《善見律》（之三歸）也是如此（列入局限）。前文《十誦律》的三歸即是指三語，所以列入相通。

【1738-0004】03_業疏/12b_卷三之一#8
【原文】善見》有八：一教授者，謂自誓也；三歸、問答，此三局也；善來、重法（即八敬也）、遣信、八語（即二十眾，僧尼俱白四也，五是羯磨），竝通也
【譯文】《善見律》列有八種：第一是「教授」，即是指自誓受；三歸、問答，這三種屬於局限；善來、重法（即八敬法）、遣信、八語（即二十眾，僧尼二部各自作白四羯磨，共有八番言辭；第五即是羯磨受），這些都與《四分律》相通。

【1738-0005】03_業疏/12b_卷三之一#9
【原文】善見》自誓云教授者，謂從佛聞法故。論云佛告迦葉：「汝應如是學，言我於上中下座發慚愧心，應聽一切善法置於我心」等，迦葉以教授故即得具足，是佛神力得也。八敬云重法，重即尊敬，或云八尊，義亦同也。八語謂尼中本法、僧中正受兩番白四，故云八語
【譯文】《善見律》將自誓稱為「教授」，是指從佛聽受教法的緣故。該論說佛告訴迦葉：「你應當這樣修學，發言『我對上座、中座、下座皆發慚愧心，應當聽聞一切善法置於我心』」等，迦葉因承受佛的教授開導便即得具足戒，這是依佛的神力而得的。八敬稱為「重法」，「重」即是尊敬之意，或稱為「八尊法」，意思也是相同的。八語是指尼眾本法羯磨、僧中正式納受的兩度白四羯磨，所以稱為「八語」。

【1738-0006】03_業疏/12b_卷三之一#10
【原文】母論》有七：善來、建立受具（即破結也）、三語、羯磨、隨師教者（即八敬也）、遣信，為六通也；勑聽一受（即解義者），是局也
【譯文】《毘尼母論》列有七種：善來、建立受具（即破結得戒）、三語、羯磨、隨師教者（即八敬法）、遣信，這六種屬於相通；敕聽這一種受戒（即解義得戒者），屬於局限。

【1738-0007】03_業疏/12b_卷三之一#11
【原文】母論》破結名建立者，彼文正名上受具，即同《四分》上法。而論云「從今已去，聽汝等立善根上受具」，準約文意，名為建立。八敬名隨師教，謂從阿難邊受佛教故。解義名勑聽者，彼論佛告蘇陀沙彌：「從今已往，若有疑惑，恣汝來問」，亦即與戒，故得名也。聽，字平呼
【譯文】《毘尼母論》將破結稱為「建立」，是因為該論正式名稱為「上受具」，即等同於《四分律》所說的「上法受具」。但論中說「從今以後，聽許你們安立在善根之上受具足戒」，依準文意，因而稱為「建立」。八敬法稱為「隨師教」，是指從阿難那裡承受佛陀教誡之故。解義得戒稱為「敕聽」，是因彼論中佛告訴蘇陀沙彌：「從今以後，若有疑惑，聽憑你隨時來問」，同時即授與具足戒，所以得此名稱。「聽」字讀平聲。

【1738-0011】03_業疏/12b_卷三之一#15
【原文】俱舍》第十四列數之下，一一出人名，故云「各下列人也」。初即佛與獨覺。二即五拘鄰，彼正名得入正性離生，在言頗隱，故此易之；得世間定名邪定聚，初果入聖名正定聚。三即大迦葉。四即蘇陀夷。五即六十賢部共集受具。六即那舍等。七即大生主。八即法授尼。九、十但分中邊，不出人號

【1738-0012】03_業疏/12b_卷三之一#16
【原文】明了論》云：依他圓德有七種，比丘有四，尼有三也。獨覺有量，佛無量，波羅蜜合說有九
【譯文】《律二十二明了論》說：依仗他人而成就圓滿德行（戒體）的受戒共有七種，比丘有四種，比丘尼有三種。獨覺是有量的，佛陀是無量的，合上這兩種圓滿極致（波羅蜜）的受戒，總共說有九種。

【1738-0013】03_業疏/12b_卷三之一#17
【原文】了論》總示中。七種從師受，故云依他。獨覺與佛二種自然感發，則非依他。獨覺小乘境局大千，故猶有量；佛無量義如後自釋。究竟果滿，故稱波羅蜜
【譯文】在《律二十二明了論》總體提示中。七種受戒是從師長處領受，所以稱為「依他」。獨覺與佛陀這兩種是自然感發得戒，便不屬於依他。獨覺屬於小乘，心境局限於三千大千世界，所以仍屬「有量」；佛陀「無量」的涵義如後文自行解釋。修證究竟果位圓滿，所以稱為「波羅蜜」。
