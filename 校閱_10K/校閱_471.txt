# 校閱材料　第471檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【471-0001】02_戒疏/06b_卷二上之二#29
【原文】【記】離合中，初問。以六趣中，人、畜各位；餘四或合，通號「非人」故。言「論開」者，亦且通指，今據《智論》云「復次善惡故有六道：善中有上、中、下，故有三善道；惡中有上、中、下，故有三惡道」也。
【譯文】【記文】在分析拆分與合併的段落中，首先提出疑問。因為在六道之中，人道與畜生道各自獨立為一類；其餘四道有時合併，通稱為「非人」。這裡所說的「論典展開」，也是通盤泛指，現在是依據《大智度論》所說：「再者，由於善惡業力的差異而有六道的分別：善業分為上、中、下三品，所以感得三種善道；惡業也分為上、中、下三品，所以感得三種惡道。」

【471-0002】02_戒疏/06b_卷二上之二#30
【原文】【疏】論據善惡故分，律據通用故合。
【譯文】【疏文】論典是依照善惡業報的性質差異來分門別類，戒律則是依據彼等皆具神通（通用）的特點而加以合併。

【471-0003】02_戒疏/06b_卷二上之二#31
【原文】【記】答中，初文。「善惡」即業報。「通用」謂神通。
【譯文】【記文】在回答內容的第一部分。「善惡」就是指因果業報，「通用」是指具有神通變化的共同特質。

【471-0004】02_戒疏/06b_卷二上之二#32
【原文】【疏】故《律》人、畜不異。由來解釋「非人」，乃云「鬼」也。若論此戒，但說「非人」，天等不列，可非犯也？然下《律》中「天子、阿修羅子、餓鬼子」，地獄無文，義是鬼攝。此之四趣，通用是齊，故合為一「非人趣」也。
【譯文】【疏文】因此在《律藏》當中，人道與畜生道並無異說。向來的解釋在談到「非人」時，往往只說是「鬼神」。但如果就這條淫戒而言，經文只說「非人」，天人等卻未列出，難道犯了就不算違犯嗎？然而在下文的《律藏》中提到了「天子、阿修羅子、餓鬼子」，唯獨地獄眾生沒有明文，在法義上則是歸屬於鬼道所攝。這四種趣向的眾生，在神通變化與非凡人的特點上是相同的，所以合併統稱為一種「非人趣」。

【471-0005】02_戒疏/06b_卷二上之二#33
【原文】【記】次科，指《律》廣解。上明人、畜，同諸經論，故云「不異」。「由來」下，釋非人，示其偏局。「若」下，點當戒義含。「然」下，引後文以證。即「同宿戒」及受戒問難中，彼云「非人難」者，謂「八部鬼神、天子」等，如文所引。而不出地獄，故云「無文」，義同餓鬼，故攝鬼趣。「此」下，結成上文合之所以。
【譯文】【記文】接下來的科判，是指明《律藏》中的「廣解」。上面說明人道與畜生道，與各大經論完全一致，所以說「並無異說」。「向來」以下，是解釋過去對非人的說明，點出其解釋過於狹隘侷限。「若」字以下，是點出本條戒律所蘊含的完整法義。「然」字以下，是引用後文來加以印證。也就是在「同宿戒」以及受具足戒的問難儀軌中，那裡所說的「非人難」，是指「天龍八部鬼神、天子」等人，正如同疏文所引用的內容。雖然文中沒有單獨列出地獄，所以說「沒有明文」，但在法義上與餓鬼道相通，所以歸納在鬼道之中。「此」字以下，是總結說明上文之所以將其合併的真正原因。

【471-0006】02_戒疏/06b_卷二上之二#34
【原文】【疏】二、「復有五」下，明以五報分三。離分三趣，有十五種，是所犯境也。
【譯文】【疏文】第二部分、從小註「又有五種」以下，說明用五種生理形態來配屬於三種趣向。若將三種趣向各自拆解展開，便形成十五種情形，這全都是可能構成犯戒的對象境界。

【471-0007】02_戒疏/06b_卷二上之二#35
【原文】【記】明報中。「五報離分三趣」者，謂以婦、女、形、黃、男子，別歷人、非人、畜，故有十五。若開非人，則有三十。
【譯文】【記文】在說明生理果報的段落中。「用五種形態拆分三種趣向」，是指拿成年婦女、幼童少女、具有雙性特徵者、無生殖機能者、一般男子這五種形態，分別對應到人道、非人道、畜生道，因此共有十五種。如果再將非人道細分為天、鬼等四類，則會擴展出三十種情況。

【471-0008】02_戒疏/06b_卷二上之二#36
【原文】【疏】就自趣境。初約覺境，以明犯相；二、「若向睡眠」已下，舉後三境，以對覺境，同成犯相。
【譯文】【疏文】在主動侵犯對象的境界中。首先是就對象處於清醒狀態，來闡明犯戒的行爲態樣；第二部分、從「如果面對熟睡者」以下，列出後面三種狀態，拿來與清醒狀態對照，說明同樣都構成犯戒。

【471-0009】02_戒疏/06b_卷二上之二#37
【原文】【記】自造中。「三境」，並不覺境。「對覺境」者，此戒四境齊犯。又四境中，上二生境，下二死境。
【譯文】【記文】在主動造作犯境的段落中。「三種境界」都是指非清醒的狀態。「拿來對照清醒狀態」，是指在這條戒律裡，無論對象處於哪四種狀態，只要侵入都同樣構成重罪。另外在這四種狀態中，前兩種屬於活體境界，後兩種則屬於屍體境界。

【471-0010】02_戒疏/06b_卷二上之二#38
【原文】【疏】就後怨逼，復分二緣：前明怨捉，將向前境；後明怨捉，就身行犯。
【譯文】【疏文】至於遭到仇敵強迫的情形，又細分為兩種緣由：前半段說明被仇敵強行捉住、帶往行淫對象（前境）處；後半段則說明被仇敵強行捉住、在比丘自己身上強行施加犯行。

【471-0011】02_戒疏/06b_卷二上之二#39
【原文】【記】怨逼中，由開身合，故約心論。
【譯文】【記文】在遭受外敵逼迫的段落中，由於戒律開許身體的接觸，所以完全以內心是否感受快感來判定罪過。

【471-0012】02_戒疏/06b_卷二上之二#40
【原文】【疏】問：「所以自身造境，但明侵境，不問其心；後怨家逼，乃問樂者？」
【譯文】【疏文】問：「為什麼比丘自己主動去接觸行淫對象時，只要侵入就算犯戒，而不追問他內心有沒有受樂；但後面受到仇敵逼迫時，卻一定要查問他是否有感受到快感呢？」

【471-0013】02_戒疏/06b_卷二上之二#41
【原文】【疏】答：「適化無方，意在無逸。若俱禁者，事難常行。怨但逼身，心唯佛制，故開境合，無樂不犯。文相可解。」
【譯文】【疏文】答：「佛陀順應機緣教化眾生並沒有固定的教條，核心宗旨只在於防止弟子放逸沉淪。如果兩種情況全都一概嚴格禁止，在現實的急難中將窒礙難行。仇敵所能強迫的僅限於肉體，但內心的把持唯有靠佛陀的教誡來約束，所以戒律開許在無可奈何的肉體接觸下，只要內心絲毫不生快感就不算犯戒。文句的意涵很容易明白。」

【471-0014】02_戒疏/06b_卷二上之二#42
【原文】【記】問詞，躡前兩判，欲彰開意。答中。初敘制必須開。以大聖設教，不定一端，故曰「無方」。「禁」即是制。謂若唯一制，不濟機緣，故曰「難常」。「怨」下，明開中復制。
【譯文】【記文】提問的文字，是承接前面兩種判決標準，想要闡明戒律特別開許的真正用意。在回答當中，首先敘述制定戒律之時必須同時具備通融的開緣。因為大聖佛陀施設教法，不會拘泥於單一端點，所以說「沒有固定教條」。「禁」就是指制定嚴禁的條規。也就是說，如果只有死板的一律禁止，就無法救濟特殊機緣下的受難者，所以說「難以長久實行」。「怨」字以下，是說明在開許通融之中又再次設立了微細的嚴格禁約。

【471-0018】02_戒疏/06b_卷二上之二#46
【原文】【註】佛言：「譬如斷人頭，不可復起，比丘亦如是，犯此法者不復成比丘，故名也。」
【譯文】【註文】佛陀開示：「這就好比將人的頭顱斬斷，就再也不可能復活站立起來，比丘也是如此，凡是違犯了這條戒律的人，就永遠不再是合格的比丘，因此才這樣命名。」

【471-0019】02_戒疏/06b_卷二上之二#47
【原文】【疏】就注解中分二：初釋罪名；後「方便欲行」下，釋成不相。
【譯文】【疏文】在小註的解釋中分為兩個部分：前半段解釋罪名的意義；後半段從「若以預備手段想要行淫」以下，解釋犯戒究竟成立或不成立的具體情形。
