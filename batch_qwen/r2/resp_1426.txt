整體讀來通順、體例一致，白話化程度也恰當；但有幾處**律學關鍵詞判讀錯誤**與**無據增譯**，會影響讀者對儀軌的理解。以下按「必須改」「宜斟酌」「體例一致性」分層列出。

---

## 一、必須修正（語意錯誤）

### 1. #95「不來者說欲」→「必須傳達欲令」
- 「說欲」是律制專名（**與欲**，因病等不能出席者囑託他人代為傳達同意與清淨），「欲令」並非律典用語，且譯文寫成「不能前來的大尼必須傳達欲令」，變成病者自己去傳達，方向反了。
- 建議：**「因病等不能前來者，須囑託他人代為『說欲』（與欲、與清淨）。」**

### 2. #95「著衣服具」→「法器資具具備」
- 「著衣服具」指**衣著（三衣）齊整具足**，與法器資具無關，屬誤讀。
- 又「若尼賢善**自入無事**」一句被吞掉未譯。「自入無事」是說自行入內不致生譏嫌事故。
- 建議：**「若該尼賢善、自行入內無有事故、衣著齊整具足，便聽許進入；反之則不許。」**

### 3. #95「先白比丘」→「先向**值門**比丘通報」
- 原文只作「比丘」，「值門」為譯者臆加，律中未必設守門執事。建議刪去，作「先向比丘稟白」。

### 4. #96「請教授尼人」→「祈請……之**律師**」；「無教授已人」→「並無**專職**教誡師」
- 「教授尼人」即受差派的**教誡師**，不必限定為律師；「專職」尤誤——教誡師是每半月**臨時白二差派**，非固定職位。
- 建議：**「前往比丘僧中，求請能教授教誡比丘尼的人；而僧中並無能教授教誡尼眾者，也沒有善於說法的人。」**
- 另：「無教授**已**人」之「已」疑為「尼」之形訛，宜出校注（譯文已按「尼」理解，可保留但加注）。
- 「僧差我」之「僧」指**尼僧團**，與下句「大僧僧團」易混，宜補「（尼）僧團差派我」。

### 5. #97「若別眾眾不滿」→「出現**別眾分裂**」★重點
- 「別眾」是羯磨過失名：同界內僧未全集合（或未到者未與欲），致作法不成，**不是破僧分裂**。譯成「分裂」語意過重且錯誤。
- 同一篇 #99「豈非別眾等過」譯文保留「別眾」是對的，前後不一致。
- 建議：**「若僧眾別眾（不合集、作法不成）或人數不足……」**，並統一保留「別眾」加括注。

### 6. #101「禮謝／敬謝」→「禮拜**致謝**」★重點
- 這段是誦戒畢的**自謙懺謝文**：「三業不勤，多有舛錯，願眾慈悲布施歡喜」，明顯是**謝過（懺謝）**，不是道謝。
- 建議：「說戒師下座後，到大眾中**禮拜謝過**說：『……敬向眾僧懺謝：蒙僧差派誦律，某甲三業未能殷勤，多有舛錯，願眾慈悲，布施歡喜（寬容見恕）。』」
- 連帶 #102「說已」譯「致謝完畢」→ **謝過完畢**。

### 7. #107「一人告清淨」→「由一人代表通報個人戒行**是否**清淨」★重點
- 下一段白文明言「某甲等若干人，**竝清淨**」，是**宣告清淨**，不是询问或通報「是否」。
- 建議：**「長跪而住，由其中一人代為宣告清淨說：」**

### 8. #109「若不清淨者」→「如果有**破戒**不清淨的人」
- 此指**有犯未懺、戒不清淨**（含輕罪），未必是破根本重戒；觀 #110「犯某罪……未得懺悔」即知。
- 建議：**「若有犯戒而未清淨者，則須一一各別稟白說：」**

### 9. #107「恐破他說戒」→「恐**妨礙**他人說戒」
- 「破」指令說戒羯磨被破壞、不成作法，「妨礙」語意太輕。
- 建議：**「以免破壞他眾的說戒（致作法不成）。」**

## 二、宜斟酌（增譯、窄化、方向不明）

| 段 | 譯文 | 問題與建議 |
|---|---|---|
| #95 | 「目前尚不知是否有人能**前往**」 | 「未知有否」只說有無其人，「前往」是推加。可作「不知僧中有無能教誡的人」。 |
| #95／#97 | 「頂戴持」分別譯「唯諾，至誠頂戴受持」／「**敬承聖教**，至誠頂戴奉持」 | 同一套語應統一；且「上座有勅」是上座告誡，抬為「聖教」過度。建議統一作「頂戴受持（依教奉行）」。 |
| #95／#97 | 「上座**特別**有敕命」 | 「特別」為贅加，可刪。 |
| #97 | 「這種**省略教誡**的略法」 | 略法仍是請教授，只是儀軌從略，非「省略教誡」。建議「這種簡略的請教授法（略法）」。 |
| #97 | 「當代**各寺**多半奉行」 | 「各寺」無據，可刪。 |
| #97 | 三處「遣使問訊」 | 前二（比丘僧盡病／別眾／眾不滿）依律脈應是**僧遣使至尼寺**；後一（尼僧病／眾不滿）才是**尼遣使至僧寺**。譯文前二未標方向、第三卻逕加「前往比丘寺院」，宜統一並依律文覈定，避免讀者誤以為三句同向。 |
| #97 | 「僧若不足」→「如果比丘**人數**不足」 | 原文「不足」應兼指「人數不足」與「無二十夏可任教誡者」兩種，譯文窄化。建議「若上述條件不具」。 |
| #99 | 「豈非別眾的過失」 | 漏「等」字，宜作「別眾**等**過失」。 |
| #99 | 「說戒**羯磨圓滿**時」 | 「說戒竟」即誦戒完畢，用「說戒結束時」較貼切（羯磨專指前作法）。 |
| #99 | 「**戒序結尾**的偈頌」 | 「律序下偈」宜作「律序末後的偈頌」；此偈（「已說戒利益」）實為說戒竟所用，譯成「戒序結尾」易生誤解，可加注。 |
| #102 | 「**各自齊誦**」 | 「各」與「齊」自相矛盾。原文「各說」，宜作「各各自說自慶偈」（或注明實為眾同聲誦）。 |
| #106 | 「禮**佛**散席」 | 原文但云「禮散」，作「作禮而散」較穩。 |
| #107 | 「結界外來到的**作客**比丘尼」 | 语句贅，建議「從界外來的客比丘尼（外來暫住尼）」。標題「第五、客舊僧尼的處置（客舊）」括注重複，可刪。 |
| #107 | 「尚未誦戒序唱問……之前」 | 原文「未誦序」與「未唱『是中清淨不』」是兩個時點，宜分寫：「若尚未誦戒序、尚未唱問『是中清淨不』時，客尼來到……」。 |
| #108 | 「**身心**並皆清淨」 | 「身心」為增譯，此處專指戒行；建議「（戒行）都清淨」。 |
| #110 | 「事後**必定**會如法懺除」 | 「後當如法懺」是「之後當如法懺悔」，「必定」為添加語氣。 |

## 三、體例與一致性

1. **偈頌未白話**：#100、#103、#105 三段譯文與原文全同，等於未譯。若全書體例是「原文保留＋白話隨附」，至少要加白話或注釋（如 #103「快」＝喜樂、殊勝快意；#100「神仙五通人」指外道仙人具五通、以呪術護慚愧者，反襯如來制戒之勝）。
2. **稱名混用**：同一篇中「客僧／客尼」「大尼／比丘尼」「大僧僧團／僧團」交替出現，建議固定：比丘僧稱「大僧（比丘僧團）」、比丘尼一律「比丘尼／尼眾」，客尼不寫作「客僧」。
3. **羯磨白文風格**：#96、#108、#110 屬正式白文，譯文加入「祈請」「至誠」「身心」等修飾，稍失白文質直之體；建議白文從直譯，莊嚴語放在注釋。
4. #98、#104、#106 等短段無明顯問題。

## 四、優先處理順序建議

1. 「說欲」→ 誤造詞「欲令」（#95）
2. 「別眾」→ 誤作「分裂」（#97）
3. 「禮謝」→ 誤作「致謝」（#101、#102）
4. 「告清淨」→ 誤作「是否清淨」（#107）
5. 「著衣服具」→ 誤作「法器資具」＋漏譯「自入無事」（#95）
6. 「專職教誡師」「律師」「值門比丘」等無據增譯（#95、#96）
7. 「破戒不清淨」語意過重（#109）

前四項屬律制理解錯誤，會直接誤導讀者對作法成敗、儀軌性質的判斷，建議務必改；其餘多為潤飾過度與體例問題。
