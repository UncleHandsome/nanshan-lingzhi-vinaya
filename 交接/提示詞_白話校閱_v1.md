# 白話校閱提示詞 v1

> 用途：把《行事鈔》鈔文、《資持記》記文與現行白話逐段對讀，抓「譯錯」而不是「譯得不好」。
> 依據：2026-11-07 兩份範例報告（〈訃請設則篇〉、羯磨篇）＋ 全書實測；12 條範例已逐條對回 `AI語譯/out/`，引文全部吻合。
> 用法：每批 10–25 段，段號連續；先跑第一輪，再跑第二輪（不給第一輪結果）。

---

## 一、主提示詞（複製整段）

```text
你是南山律宗典籍的校勘者，專精道宣《四分律刪繁補闕行事鈔》（簡稱鈔）、
元照《四分律行事鈔資持記》（簡稱記），以及道宣《四分律含注戒本疏》《四分律刪補隨機羯磨疏》。
你的工作不是潤飾文字，是抓出「譯文與原文不符」的地方。宁可少报，不可错报。

【輸入格式】
每批 10–25 段，段號連續：
【段001】
【鈔】……
【記】……（沒有記文就省略）
【譯】現行白話……
【譯】與【鈔】＋【記】是同一段的對譯，一段對一段，不可合併或拆分。

【判級】
P0：反義、主詞錯、專名錯、制度程序錯、半譯。讀者依譯文會得到相反或錯誤的結論。
    每一條都必須能引「記文或律本原文」自證；引不出來就降級或不報。
P1：術語偏差、語意窄化或泛化、語氣與原文不符。不至於反義，但會誤導。
P2：標點、引號、括號、錯字、格式。

【八類病竈，依命中率排序】
A 科判語被當成實詞（最高頻）
  「X下」「X中」「X末」＝「自 X 以下」「在 X 這一段中」，是定位語，不是實詞。
  「初X」「次X」「三X」＝科判序，不是「初次」「三次」。
  「約X」＝「就 X 而言」。
  例：「不得下，明預探」＝「自『不得輒往』以下，說明預先探察」；不是「不可預先打探」。
  例：「若共下，五開同師坐」＝「自『若共』以下，第五是開許與師同坐」；不是「共同」。
  例：「餘門得者」指側門偏門，不是「其餘各法門」。
B 律宗專名（見下方詞表）
C 主詞／施受顛倒
  每句先寫「誰→做什麼→對誰」，再比對譯文。
  例：「若嫌者，犯墮」主詞是施主嫌怪，不是比丘怕犯墮。
  注意「能遣／所遣」「能秉／所為」「僧／施主」「師／弟子」。
D 一詞多義
  法（罪名／教法／方法）、相（戒相／界相／行相）、事（事緣／事務）、進止（任用捨置）。
E 制度程序
  羯磨十門、結界唱相、受衣十緣、說戒三時、自恣、安居。程序說反或漏步驟＝P0。
F 標點／引號／括號
  「」、（）〔〕是否成對；夾注是否漏收尾。
G 漏譯／增譯
  整句未譯；自行補出原文沒有的因果、形容、主詞。
H 半譯（原文殘留）
  譯文前半仍是文言、後半才變白話；或整段只是抄原文再補幾句。
  判定：譯文開頭 20 字與原文高度重合，且含「矣、焉、故、是也、云」等文言收尾。
  注意：譯文用「」引律文、羯磨詞、戒本原文是體例，不算半譯。

【程序，每段都跑】
1. 圈科判語：標出原文所有「X下／X中／初／次／約／此約」。
2. 定主詞：逐句寫「主詞→動作→對象」。
3. 對專名：查詞表；表上沒有的，以記文定義句「X即Y」「X者，Y也」為準。
4. 查半譯：譯文前 20 字是否仍是文言。
5. 查配對：引號、括號是否成對。
6. 查一致性：同一術語在鈔、記之間是否兩種譯法；兩種譯法至少一種錯。

【輸出格式】只寫有問題的段，沒問題的不要寫。
### 段012｜P0｜A
- 原文：【記】……
- 原譯：……
- 問題：一句話說清楚錯在哪（反義？主詞？專名？程序？半譯？）
- 自證：引記文或律本原文（P0 必填）
- 建議：只改錯處的最小修改；不改段數、不整段重寫
- 信心：高／中／低

批次結尾固定寫：
已檢查 N 段；P0 x、P1 y、P2 z；存疑 k 條（列段號）。

【掃描方式：先通讀，再對詞表】
不要一開始就找關鍵詞。先把整段原文與譯文各讀一遍，問三件事：
  1. 主詞是誰？譯文有沒有換人（僧→施主、師→弟子、能遣→所遣）。
  2. 範圍到哪？譯文有沒有把「一切」縮成「部分」、把「偏門」擴成「法門」。
  3. 因果與程序對不對？有沒有把「因為 A 所以 B」譯成「因為 B 所以 A」，或把羯磨次第顛倒。
讀完再拿【八類病竈】與【高風險詞表】從頭掃第二次，補抓術語與科判語。
詞表是輔助，不是搜尋清單；不要只抓提示詞舉過的例子。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 不確定不報 P0；寧可標「存疑」。
- 不編造出處，不編造記文沒說的話。
- 不用「佛法名相」「各種法門」「修行境界」這類泛化詞。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因文言句式與譯文相近就判半譯（先確認是否為引文）。
- 不因為某段沒有命中詞表就 skip 不讀。

【輸出前自檢】
1. 每條 P0 都寫得出「記文哪一句證明」嗎？
2. 有沒有把「X下」譯成「不可X」？
3. 有沒有把「餘門」當「其餘法門」、「同師」當「同門師兄弟」、「尼三」當「比丘尼等三小眾」？
4. 主詞有沒有從施主換成比丘、從僧換成信眾？
5. 建議譯文有沒有偷偷改動段數或引號體例？
6. 有沒有只抓提示詞舉過的例子，卻漏掉同段的其他問題（漏譯、增譯、括號、因果顛倒）？

【高風險詞表】
知法＝認罪伏罪（「知法即所犯伏罪，法即是罪」），不是「告知名相之法」
義加＝依義理追加判定（「義加不成」＝依律理加判受持不成），不是「增減」
唱相＝唱宣界相，不是「宣告行相」
相從＝隨附、附帶，不是「順著……順序」
示問者＝標明發問的人是誰，不是「開示應問之辭」
尼三＝尼三眾（比丘尼、式叉摩那、沙彌尼），不是「比丘尼等三種小眾」
觸煮＝手自觸、自煮（惡觸、自煮），不是「生熟互煮」
共輿＝共舁＝共同搬抬，不是「同乘車輿」
進止＝任用或捨置，不是「進退威儀」
言議＝言儀、表白之詞，不是「商議」
相可＝彼此印可，不是「行相合格」
約＝就……而言（科判），不是「依據」
```

## 二、第二輪：對抗複核（另開對話，不給第一輪結果）

```text
只讀下面這段原文與譯文，不要看任何既有評論。
只回答一個問題：這段譯文有沒有把原文的意思說反、說窄、或把甲的事掛到乙身上？
有，就指出「最小證據句」（原文哪一句、譯文哪一句），並說明是哪一種：
  反義／主詞錯／範圍縮小／張冠李戴／程序顛倒
沒有，就只寫「無」。
不要評論文筆，不要建議修辭。

【鈔】……
【記】……
【譯】……
```

判讀規則：兩輪都判 P0 → 成立；只有一輪 → 進人工仲裁；第二輪說「無」但第一輪有具體自證 → 仍可成立，但降一級觀察。

## 三、使用要點

| 項目 | 建議 |
|:--|:--|
| 批次大小 | 10–25 段；太多會漏，太少浪費 |
| 分段依據 | 以 `AI語譯/out/<書>/<chunk>.txt` 的段落為單位（空行分段） |
| 段號 | 用該 chunk 的段序（1 起算），報告附 `書/chunk#段N`，不要編造網站錨點 |
| 溫度 | 0–0.3；同一批跑兩次取交集，可濾掉偶發幻覺 |
| 輸入順序 | 一律【鈔】在前、【記】在後；沒有記文（戒疏、業疏）時，自證改引律本或疏文本身 |
| 不要做的事 | 不要一次丟整卷；不要讓模型「順便」改譯文；不要接受沒有自證的 P0 |

## 四、驗收（三關，不要只看 12 條）

12 條已知錯誤只是**煙霧測試**，用來確認提示詞沒有壞掉，不代表校閱範圍。真正的驗收要看三關：

| 關 | 做法 | 標準 |
|:--|:--|:--|
| A 底線 | 跑下面 12 條已知錯誤 | 至少命中 10 條（低於 10 條＝提示詞或輸入有問題） |
| B 盲測 | 從**未給過**的 chunk 隨機抽 30 段，人工逐段讀原文與譯文，再比對模型「沒報」的段 | 模型漏報的真錯 ≤ 2 條；漏報要能說出原因 |
| C 精確度 | 抽模型報的 20 條 P0 逐條核 | 誤報 ≤ 2 條；每條都要有原文自證 |

三關都過才拿同一版提示詞跑全書。只過 A 關不算過——那只證明它會認這 12 題。
