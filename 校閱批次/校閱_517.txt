# 校閱材料　第517檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【517-0001】資持記/13a_下一#32
【原文】余下，引親見為證。可驗《僧祇》翻傳失旨。蜀部即川中，準知木蘭乃是華語。指《善見》者，即如次科赤色鮮明是也。斥濫中，初斥用偽經。彼經分五部衣色，謂僧祇著黃，五分著赤，四分著皂，迦葉遺著木蘭，十誦著絳色。〔以《僧祇》入五部，本枝不分；又五部中闕婆麁部。
【譯文】自「余」字以下，作者引述親身經歷作為見證。由此可以驗證《僧祇律》在翻譯傳播時失卻了原本的意旨。「蜀部」就是指四川地區，由此推知木蘭本是華夏漢語。引述《善見律》之說，就是指下一科中所說的「赤色鮮豔明亮」的情況。在「斥濫」（斥責混濫之說）中，首先斥責引用偽經之過。那部偽經妄分五部的衣色，說是僧祇部穿黃色，五分部穿赤色，四分部穿皂色，迦葉遺部穿木蘭色，十誦部穿絳色。〔該偽經把僧祇部混入五部之中，根本派與枝末派不分；且五部中又漏掉了婆粗富羅部。

【517-0002】資持記/13a_下一#33
【原文】此雖指斥，《義鈔》復引，未詳何意。又《舍利弗問經》，僧祇、迦葉遺同上，四分著赤，十誦著皂，五分著青。然服飾隨時，未必一定；兩經互說，不足致疑；縱用彼文，止是名濫；如諸部青黑，豈得正色乎！《四分》下，引律論證非。《四分》三色隨壞，《善見》謂為遭賊，明知五大本非如法。
【譯文】這段經文雖然在此予以指斥，但《行事鈔義記》（《義鈔》）中又曾引述，不知祖師有何深意。又如《舍利弗問經》說，僧祇部、迦葉遺部的說法與上述相同，而四分部穿赤色，十誦部穿皂色，五分部穿青色。然而服飾本隨時代環境而改變，未必有固定標準；兩部經說法互異，並不值得起疑；縱然使用那段經文，也僅是名相混濫而已；如諸部所說的青、黑，難道能算作五方正色嗎！自《四分》以下，引述正統律論以證明其非。《四分律》規定青黑木蘭三色中任選一種壞色，而《善見律》把穿五大色衣者說成是遭賊失去法衣的比丘，由此明知五大正色根本不合戒法。

【517-0003】資持記/13a_下一#34
【原文】注文兩段，前定色相，以名濫故；後準文決，恐妄執故。結斷中，初指諸教。純色謂五方正間。必下，示成否。〈隨相〉即九十新衣戒。定量中，《四分》有通局二量，初示定量。安陀會長七尺二寸，廣三尺六寸，此謂下衣，道行作務，故不宜大。
【譯文】注釋共有兩段：前半段考定律色名相，是為了破除名稱混濫之弊；後半段依準正文予以裁決，是唯恐學者妄加固執之故。在「結斷」（最後裁斷）中，首先指明諸部教法。所謂「純色」，是指五方的正色與間色。自「必」字以下，說明其受戒持衣的成就與否。〈隨相〉就是指九十單墮中的「新衣戒」。在衣服的定制尺寸（定量）中，《四分律》有局限尺寸與相通尺寸這兩種標準。首先標示局限的標準尺寸：安陀會（五條衣）長七尺二寸，寬三尺六寸，這是作為下衣穿著，為了便於長途行走和勞作雜務，所以不適宜做得太大。

【517-0004】資持記/13a_下一#35
【原文】《業疏》云：諸部極小唯《四分》文，出家貧乏，故是常也。餘二衣長九尺，廣五尺四寸。然下，出通量。但云下衣極小，準餘二衣非小明矣。然恐身量短長不定，是故三衣俱準通量。言度身者，此有二法。一準《多論》。佛身丈六，衣長丈八，廣丈二。常人半之，衣長九尺，廣六尺。
【譯文】《業疏》說：各部律中最小的尺寸唯有《四分律》的記載，這是考慮到出家人生活貧乏簡樸，所以將其立為常規。其餘兩件衣（七條與大衣）長九尺，寬五尺四寸。自「然」字以下，引出通用的彈性尺寸。文中只說下衣極小，由此推知其餘二衣並非極小，這是很明白的。然而唯恐每個人的身軀身材長短不一，因此三衣都准許參照通用的尺寸來裁製。所謂「依照身材裁度」，這裡有兩種方法。第一種依準《薩婆多論》：佛的身軀長一丈六尺，衣服長一丈八尺，寬一丈二尺。普通人的身材折半計算，衣服長九尺，寬六尺。

【517-0005】資持記/13a_下一#36
【原文】〔與《四分》小異。〕據此以算，人身長一尺，則長邊得一尺一寸二分半，廣邊得七寸五分。如是增之，則八尺之人，可著長九廣六之衣也。更增至佛量亦無差。設或身相長短不稱，減成儉約，過須說淨。二準《業疏》。就身裁度。疏云：從肩下地踝上四指以為衣身，餘分葉相，足可相稱。
【譯文】〔這與《四分律》的尺寸略有差異。〕依據這個比例計算，人身長若為一尺，衣服長邊應得一尺一寸二分半，寬邊應得七寸五分。照此等比例增加，那麼身高八尺之人，便可以穿著長九尺、寬六尺的衣服。若再依此增加至符合佛陀身量的比例也不會有差錯。設若身材長短比例不勻稱，尺寸減小則合乎簡約之德，但若超過限制便必須行「說淨」之法。第二種依準《業疏》所說，直接就著身體來裁剪量度。《業疏》說：從肩膀向下垂至腳踝上四指之處作為衣身長度，剩餘分割縫綴的葉相條塊，自然能相稱合度。

【517-0006】資持記/13a_下一#37
【原文】此謂人身多是長短不定，尠有肥羸；縱有肥羸，不妨服用；是故但出廣量，不明長法。〔有云餘分葉相，即是長量；今謂葉相廣長齊有，何獨長邊。〕且今時人少至八尺，但取九尺已內，足可相稱；良由袈裟右角，本在左肩；或垂腋下，是故九尺之服，頗宜八尺之身。
【譯文】這是說人的身形大多是長短高矮不定，很少有單純肥胖或消瘦的極端；縱然體型肥瘦有別，也不妨礙穿著使用；因此律中只定出寬度的標準量法，沒有死板規定長度的標準。〔有人說「剩餘分割的葉相」就是長度的量法；如今我認為葉相的寬度與長度同樣具備，豈能單指長邊呢。〕況且現今之人身高很少能達到八尺，只要取九尺之內，便足以相稱合度；這全是因為袈裟的右角原本是收搭在左肩上，或者垂在左腋之下，所以九尺長度的衣服，極為適宜八尺高的人穿著。

【517-0007】資持記/13a_下一#38
【原文】今則右角前垂，著用乖法；遂使長邊何啻丈二，廣邊不滿五尺。長拕象鼻，動越威儀；習久迷深，何由諫諭。必懷奉法，夫復何言。文中節量等語，本是誡節貪求，令知止足，故云取足而已。今此引用，意顯隨宜，故云準此等。度字入呼，謂裁度也。取字去呼，謂粗略也。
【譯文】現今有些人卻把袈裟的右角向前垂垂掛落，穿用方式完全違背戒法；以致使衣服長邊何止一丈二尺，而寬邊卻連五尺都不到。多餘的部分像長長的象鼻子一樣拖曳著，動輒超越律儀威範；這種習氣由來已久、執迷極深，又從何去勸諭諫正呢！倘若是存心奉持戒法之人，又何須我多言！文中「節量」等言詞，原本是告誡節制貪求之念，令知止足，所以說「取足而已」。如今此處引用，意在顯明隨機便宜制宜，所以說「準此」等語。「度」字讀入聲，是指裁剪量度。「取」字讀去聲，是指大概推求。

【517-0008】資持記/13a_下一#39
【原文】引諸文中，初二字躡上通文。亦下一句，生後引用。然《四分》下衣雖云窄小，而諸部中三衣或等，足可準繩。恐見度身，便即任意廣長無法，故云雖爾等。〔今執丈二長衣，便云《律》有通文者，正墮此過。〕故下，引示諸文，初指二律。《十誦》。上衣長五肘，廣三肘〔同上《四分》〕；
【譯文】在引證諸經律文句中，前兩個字承接上面的通融律文。「亦」字下一句，引導引生後文的引證。然而《四分律》的下衣雖然說極其窄小，而在其餘各部律中三衣的尺寸或者均等，足以作為立規的繩墨規範。唯恐有些人一看到依隨身量，便隨心所欲使廣狹長短全無章法，所以說「雖然如此」等語。〔現今執持一丈二尺長衣的人，便聲稱「律中有相通的條文」，這正是墮入了這種過失。〕自「故」字以下，引述並昭示諸部律文：首先指明兩部律藏。《十誦律》規定：上衣長五肘，寬三肘〔與上述《四分律》相同〕；

【原文】既非本制，非無著著之失。問：下引《多論》，摘分持行，豈非多衣重沓邪？答：祖師爾前並依論作，垂終感聖，方復改之。故此傳文，決了三藏不明之事；如坐具四增安左臂等，世並行之，何獨疑此。縱欲通縵，準論應得，但非截多重之難，無以通之。問：大衣單作，加受成否？
【譯文】這既然不符合最初的制度，在穿著時便難免有違犯威儀之過失。有人問：下文引用《薩婆多論》，允許將重疊的衣拆分開來隨身攜帶，這難道不就是多層衣服重疊累積嗎？回答：祖師道宣在此之前都是依照論典製作，晚年將終感得聖天降臨，這才加以修改糾正。所以這部《感通傳》的文字，解決斷定了三藏經律中未曾明朗之事；如同坐具四面各予增廣（四邊增接）、將袈裟安放在左臂等行儀，世間全都遵行，為何唯獨對這項做法心生疑惑呢？縱然想要通體襯布，依照論典雖說應該可行，但面對「非經割截」與「多層重疊」這兩項難題，便無法圓融解釋了。有人問：大衣若單層製作，行受持法能成就嗎？
