# 校閱材料　第255檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【255-0001】01_行事鈔/11c_卷下之三#6
【原文】《毘尼母》云：既聽說十二部經，欲示現此義，復有疑心；若欲次第說文，眾大文多，恐生疲厭；若抄撰好辭，直說；不知如何？佛言：聽引經中要言妙辭，直顯其義。《涅槃》云：若有受持讀誦，書寫演說，莫非時、非國、不請而說、輕心、輕他、自歎、隨處而說，及滅佛法、熾然世法而說。何以故？由非時非處等而說法者，令無量人死墮地獄，則是眾生惡知識也。《雜寶藏》：為俗人說七種施法，不損財：一眼、二色、三言、四身、五心、六床座、七房舍；各各果報，乃至佛尚無盡。《智論》：佛說法已，常教諸比丘入禪定；己之所說，身亦自行。《大集》云：若四真諦，是一念證者；則為一切眾生，說一行一法。乃至種種因緣，調伏不一，故便說種種法，八萬法聚差別。
【譯文】《毘尼母經》說：佛既然已經准許宣說十二部經，想要向眾人闡明其義理，卻又生起疑慮；如果想按部就班順著經文逐字講說，大眾人數眾多且經文繁複，唯恐大眾生起疲累厭倦；如果摘錄優美精妙的文辭直接宣說，不知是否可行？佛陀說：准許引用經典中的精要妙辭，直接顯明其義理。《大般涅槃經》說：如果有人受持、讀誦、書寫、演說佛法，切莫在不合適的時間（非時）、不合適的國度（非國）、未受邀請時說法、帶著輕慢之心說法、輕蔑他人、自讚自誇、隨便在不當處所說法，以及帶著滅除佛法、助長世俗法的心態而說法。為什麼呢？因為在不合適的時間、地點等情況下說法，會令無量眾生死後墮入地獄，這樣說法者就成了眾生的惡知識。《雜寶藏經》說：為在家人宣說七種無損財物的布施法：一是眼施（慈眼觀眾生）、二是顏容色相施（和顏悅色）、三是言辭施（柔和善語）、四是身施（端正謙恭、行禮引路）、五是心施（慈心善念）、六是床座施（讓座於人）、七是房舍施（留宿接待）；每一種布施所感的果報無量無邊，乃至成佛之後都受用不盡。《大智度論》說：佛陀說法之後，經常教導諸比丘入於禪定；自己所說的法，自己也親身實行。《大集經》說：如果四聖諦能夠於一念之中證悟，佛陀就會只為一切眾生宣說一種行門、一種法門。但因為眾生根機有種種因緣，調伏教化之法各不相同，因此才宣說種種法門，開顯了八萬四千法門的差別。

【255-0002】01_行事鈔/11c_卷下之三#7
【原文】《毘尼母》云：若為在家人作師，教化作福，有五事：一不應檀越舍止住；二不繫心貪利；三為別別說法，布施、持戒、八齋等；四不與共娛樂；五不繫心常欲相見。又五事為檀越尊重恭敬：一非親舊處不往返；二不求形勢，料理檀越家業；三不共竊語，令家中生疑；四不教良時吉日，祠祀鬼神；五不過度所求。入俗家五法：一入時語小；二斂身口意；三攝心卑恭而行；四收攝諸根；五威儀庠序生善。有九事不應俗家坐：一雖為禮拜，心不恭敬；二雖往迎逆，心不慇重；三雖讓令坐，而心不實；四在不恭敬處令坐；五有說法言，心不採錄；六雖聞有德，不信受之；七知有甚多，若求與少；八知有美食，反設麁者；九雖供給與，如市易法。並不應坐，反此便坐。若入聚落，應卑恭慚愧；不著六塵，攝心行之。如高山，懸巖絕險；方寸之處，而足蹈之；念念生怖，更無餘念。臨淵亦爾。如月行世，動手於空，四方無著等。
【譯文】《毘尼母經》說：如果作為在家人的師長，教化他們修造福德，有五件事要注意：第一，不應在施主家過夜留宿；第二，不存心貪戀利養；第三，為他們分別宣說相應的法門，如布施、持戒、八關齋戒等；第四，不與他們共同嬉戲玩樂；第五，不繫心常常想與他們相見。又有五件事能令施主尊重恭敬：第一，不是親戚熟人之處不隨意頻繁往返；第二，不求取世俗權勢，不過問料理施主的家業；第三，不與人私下竊竊私語，以致令其家人起疑；第四，不傳授擇定吉日良辰、祠祀鬼神之術；第五，不過度有所索求。進入在家人家中有五種法則：一是進入時說話聲音要小；二是收斂身、口、意三業；三是攝心謙卑恭敬而行；四是收攝諸根；五是威儀從容安詳，令見者生起善心。有九種情況不應在俗人家中坐下：一是對方雖然行禮參拜，內心卻不恭敬；二是雖然前來迎接，內心卻不慇切厚重；三是雖然謙讓請坐，內心卻不真誠；四是安排在不恭敬的處所請坐；五是有宣說法語，對方內心卻不採納領受；六是雖然聽聞有德行，卻不信服接納；七是明明知道對方物資充裕，有所乞求時給予得極少；八是明明知道有美食，反而拿粗劣的食物來供設；九是雖然有所供給給予，卻如同市場交易一般計較。這些情況下都不應坐下，反之情況良好時方可坐下。如果進入村落聚落，應當謙卑恭敬、懷抱慚愧；不貪著六塵境界，攝持心念而行。應當如同身處懸崖絕壁的高山險境，僅在方寸微小之地以足踩踏，念念生起戒懼怖畏，再無其他雜念。面臨萬丈深淵時也是如此。又應當如同明月穿行世間，如手在空中拂動毫無滯礙，在四方境界中皆無執著。

【255-0003】01_行事鈔/11c_卷下之三#8
【原文】《十誦》：說法人者，應一心說，生慈愍心、利益心，莊嚴語言、次第相續，辯才無盡，隨順諸法實相；為法故說，不為利養。此中上座，應觀察所說；若不如法說，應呵止。又聽取佛經義，莊嚴言辭，次第解說；其佛經本，當直讀誦，莫雜論議。《五分》：白衣說法，歡喜布施者，聽之。《十誦》：說法呪願讚法時，不得食。
【譯文】《十誦律》說：說法的人，應當一心專注宣說，生起慈愍心、利益眾生心，文飾莊嚴語言、講述井然有序連貫相續，具備無盡的辯才，隨順諸法的實相；應純粹為了正法而說，不可為了利養而說。在場的上座比丘，應當審視觀察說法者所說的內容；如果說法不如法，應當及時呵責終止。此外，准許採取佛經的深義，修飾莊嚴言辭，依序逐層解說；但若是佛經的本文，應當直接讀誦，不要夾雜世俗的雜論辯議。《五分律》說：為白衣說法，若白衣心生歡喜而行布施，准許（比丘）接受布施。《十誦律》說：在說法、祝願、讚頌佛法時，不得進食。

【255-0004】01_行事鈔/11c_卷下之三#9
【原文】《薩婆多》：若檀越欲作大房舍，應開解示語，令小作，順少欲法；若為容多人故作者，不應違意。《四分》：不得將世俗呪術教化。當語云：莫向如來塔大小便，及除糞掃盪器不淨水等；若起房舍，及耕田種作，當向如來塔。又宜於八日十四日、十五日，入塔寺供養比丘僧，受齋法。佛告檀越，若人慈心，以米泔汁、盪滌汁，棄著不淨蟲水中，使蟲得此食氣，得無量福，況復與人。《智論》：佛申鉢受老母臭澱汁。佛受億耳羹殘，度與頻婆娑羅王。《善見》：不得受白衣使；若令禮佛、讀經、呪願、集眾，種種善事，不犯；餘惡使者，吉羅。
【譯文】《薩婆多部折摩得勒伽》（薩婆多論）說：如果施主想要建造宏大的房舍，應當向其開導曉諭，令其建造得小一些，以隨順少欲之法；但如果純粹是為了容納大眾僧而建造的，則不應違逆施主的意願。《四分律》說：不得使用世俗的咒術符法去教化大眾。應當告誡眾人說：不可朝著佛塔大小便溺，以及傾倒糞便垃圾、潑灑洗器不淨之水等；若建造房舍以及耕田勞作，應當面向如來塔（以示崇敬）。此外，宜於每月的初八、十四、十五日，前往塔寺供養比丘僧，受持齋法。佛陀告訴施主說，如果有人以慈悲之心，將淘米水、洗滌器具的水，傾倒在有小蟲的污水坑中，使水蟲能得到這食物的氣味資養，都能獲得無量福報，何況是布施供養給人呢！《大智度論》說：佛陀曾伸鉢接受貧窮老母所供養的發臭淘米泔汁。佛陀接受億耳供養的美羹後，將食剩的殘羹轉賜給頻婆娑羅王。《善見律毘婆沙》說：比丘不得接受在家人隨意差遣使喚；但如果是請比丘禮佛、誦經、祝願、召集大眾等種種善事，則不犯戒；至於其他世俗非法的差使，若聽從則犯突吉羅（輕垢罪）。
