整體看下來，多數文句通順、意思也掌握得住，但有**幾處實質性的錯譯／前後矛盾**，另有若干用語與增譯問題。以下按輕重分列。

---

## 一、必須修正（意思錯或前後自相矛盾）

**1. 【0007 / #83】「自說成重」譯成「唯有親口自說才構成重罪」——與後文衝突**

後文【0011 / #87】明說「遣人說己得聖……犯齊究竟」，即遣使宣稱自己得聖也成究竟重罪，並非「唯有親口自說」。
建議：「大妄語戒，自己宣說（己證聖法）即成重罪。」（去掉「唯有／親口」的排他限定）

同句「教人稱聖」譯作「教唆別人去宣稱**自己**得了聖法」——這個「自己」极易被讀成「教者自己」，那就變成下文的「遣」了。此處正是「他自稱得聖，名利歸他」，故應明確：
建議：「若教他人宣稱**他自己**已證聖法，名利全歸彼人，於我毫無潤益，故能教者不與彼同犯（重罪）。」

**2. 【0009 / #85】「教他稱己」的「己」指能教者，譯文含混**

原文問意是：教他人去宣稱「**我（能教者）**已證聖」，名利歸我，豈不犯重？譯文「宣稱自己已證聖，使自己得到名利」兩個「自己」指涉不清。
建議：「若教他人宣稱『我（能教者）已證聖』，因而使自己獲得名利，難道不犯重罪嗎？」

**3. 【0011 / #87】與【0012 / #88】對「離／利」的處理互相打架**

- #87 依原字譯為「教唆別人是**利益遠離自身**」；
- #88 卻說「『離』字應改作『利』，是傳抄之誤」。

既然採用元照的校勘，疏文译文就不該仍按「離」字講。
建議二者統一：#87 依校改譯為「教他（雖亦）利益於己，其義猶疏；遣人（直接）趣向自身，其義則親」，並加注「原作『離己』，今依記改『利己』」；或保留原字而在 #87 加同樣的校注。

**4. 【0006 / #82】「即不定早晚等也」譯成「不限定**對象**的早晚、坐立等情況」——「對象」是誤添**

「早晚」屬時間，「坐立」屬姿態，與「對象」無關。
建議：「即不限定時間早晚、（被害者）坐立姿態等。」

**5. 【0015 / #91】「後以趣分罪」譯為「以三趣的不同來劃分罪品的輕重」——與記文相違**

#92 記文明說：「初即以罪歷趣，以辨重輕；後謂將趣歷戒，以簡**通局**。」可見「輕重」屬前段，「通局」屬後段，譯文把後段也講成輕重了。
建議：「先以所犯之罪歷對三趣，辨其輕重；後以三趣歷對諸戒，分別其通局（何趣通犯何戒、何戒局限何趣）。」

**6. 【0001 / #77】「緣闕」被吞掉，五異之數不彰**

原文「或互顛狂、捨戒，**緣闕**」，記文（#78）明白點出「且列五異」，且「時節、坐立、緣闕」三者約所教。譯文把「緣闕」化成「等緣境闕漏」的總結語，讀者就數不出五項，也與 #78 對不上。
建議：「……或雙方任一方癲狂、捨戒，或（成犯的）因緣闕缺——只要稍有一點差違……」，並讓五項並列清楚。

**7. 【0001 / #77】「隨作相應」譯成「隨便殺盜相應成辦」——語意偏移**

「隨作」是「隨其所作」，不是「隨便」。
建議：「不論所使者如何造作，只要與其漫心相應而成辦殺盜，教者皆犯（重）。」

**8. 【0001 / #77】「能教者剋」只譯「限定了特定對象」——過窄**

剋心所剋不限對象，兼含時節早晚、坐立姿態等（下文即如此列）。譯成「特定對象」會與後面「漫心不限對象」形成錯誤對應。
建議：「能教者心有所限定（剋心）」；「漫心無寄」則作「心不專寄於某一境（不限定對象、時間、姿態等）」。

## 二、建議調整（不算錯，但表述失準或生硬）

**【0011 / #87】**
- 「義理上**最**為親近」：原文只「義親」，是疏／親相對，「最」為增添 → 「義理上較為親近」。
- 「遣人就己行婬」譯「差遣他人就著自身行淫」：誰的「自身」不明 → 「差遣他人前來與自己行淫」。
- 「犯齊究竟」譯「犯戒程度與究竟重罪齊等」語意浮泛 → 「所犯與自作齊等，同成究竟重罪」。

**【0002 / #78】**
- 「故云『互』也」譯成「所以說『彼此互有』」：原文是釋疏中「互」字，宜保留 → 「所以疏文說『互』（通能教、所教雙方）」。
- 「初通明犯相」宜白話 → 「先總明（自作、教人的）犯戒之相」。

**【0001 / #77】**
- 「於此犯法，教者不犯」譯「在這犯戒的法規判定上」生硬 → 「就此所犯（根本重罪）之法而言，教者不犯重」。（補「重」字是對的，#79 的「云何非重」可證。）
- 「過通損益」：記說「不殊前釋」，宜核對前文「損益」的釋義再定；若前釋即「損他／益己」（殺為損他、盜為益己），現譯可通，但建議加短注，避免讀者以為「過失」本身分損益兩種。

**【0014 / #90】**
- 「罪不至果」宜明確為「（能教／被殺的自己）所犯不至究竟果罪（自殺不成波羅夷）」，「究竟極罪」用語與他處「究竟重罪」不一。
- 「遣重教輕」的「輕」易被誤讀為「犯輕罪」；實指教他不犯重 → 建議加注「教他不犯根本，故云輕」。
- 「豈有令他盜取我物」可略加點破：己物非他物，故不成盜。

**【0016 / #92】**
- 「四條重戒」是合理補充（淫殺盜妄），可保留，但屬譯者補足，宜一致處理。
- 「通局」宜白話化：「通（諸趣共通）／局（局限某趣）」。
- 「標分中」可作「標舉門名與分科之中」。

**【0012 / #88】**「初分示」→「先分別顯示（教與遣的差別）」較貼切。

## 三、用語統一

1. **剋心／漫心**：現有「特定心／普遍心」「刻定的限定心／泛泛不特定」多套。「**普遍心**」易誤解為「遍一切」，建議統一作「**剋心（限定心）／漫心（漫泛、不限定心）**」，全文首次出現時釋義，其後沿用。
2. **教／遣**：宜固定為「教他（他自作，利歸他）／遣使（為我作，利歸我）」，並在 #83、#85、#87 三處保持同一組譯法，讀者才看得出「教輕遣重」的對比。
3. **三趣**：#91 首次出現宜加注（一般指人、非人、畜生）。
4. **究竟重罪／根本重罪**：#87「究竟重罪」、#90「究竟極罪」宜統一。

## 四、無問題者

#79、#80、#81、#84、#86、#89、#92（除上述小建議外）意思與文脈皆合，可維持。
