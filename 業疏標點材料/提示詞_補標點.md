# 業疏 17a 補標點

## 這批是什麼

`17a_未標點.txt` 有 119 段，是程式無法從句讀檔投影到標點的段落（其他 35 段已完成）。

**只缺標點，文字完全正確、不要改字、不要翻譯。**

## 提示詞（複製整段）

```text
你是古籍標點整理者。下面每段是《四分律刪補隨機羯磨疏》的原文，文字本身正確，只是缺少標點。

請只做一件事：加上現代標點（，。、；：？！「」《》〈〉（）），不要改動、增刪任何一個字。

規則：
1. 一段對一段，【段NNN】原樣保留，後面接加好標點的同一段文字。
2. 不可合併、拆分、增刪段落。
3. 不可把文言改成白話，一個字都不可以換。
4. 書名用《》，篇名用〈〉，引文用「」；夾注用（）。
5. 輸出格式：
   【段001】
   加好標點的文字……

只輸出【段NNN】與標點後的文字，不要加說明。
```
