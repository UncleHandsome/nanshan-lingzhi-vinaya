# 校閱材料　第924檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【924-0001】03_業疏/22b_卷四之五#165
【原文】次達教中，初敘略意。教本導行，時既不行，言亦何益？仍引《成論》以證隨宜。「必」下，次彰不盡。暇景，謂餘時也。本文前就本宗有五：初明五持律，二持律五德，三四種斷諍，四五種滅法，五五種對答，已上皆本宗也。他部中：初《僧祇》五利；二《十誦》初勸學戒，「佛告」下十種滅法（彼列二五法，今合為十：第一五法，「有比丘」下四句為第一法，「又不解了」即第二法，「不能」下二句為第三法，「乃至」者略第四「有說法者不能如法教鬪諍相言」，「不樂」下即第五法；「又不」下第二五法，初句即第一法，下略第二云「不隨忍法隨不忍法」，「不敬」下即第三法，「令後」下即第四法，「致令」下即第五法）；「好作」下即彼五怖畏中文（一不修身戒心智，二與尼相近，三好作文頌等，即如文引，四為衣食故捨練若入聚落，五為衣食故多所求覓）；《善見》五種住法（毗婆沙即翻為論）；《多論》毗尼四義勝餘二藏；四廣說出《四分》，彼明比丘論法毗尼，必須詳審，詳句以三藏教法印定是非，《十誦》名為四墨印（初從佛聞，二從眾僧聞，三從二三人聞，四從一人聞，所聞有四，撿勘並同）。餘如《鈔》、《記》，尋對可知
【譯文】接著在通達教法中，首先敘述省略的意旨。教法原本是用來引導行持的，當時既然無人遵行，說再多又有何益？於是引《成實論》來證明說法當隨宜應機。自「必欲兼明」以下，接著表明未能完全闡明之意。「暇景」，是指其餘空閒的時間。疏文正文在前面就本宗列有五項：第一說明五種持律，第二持律五德，第三四種斷諍，第四五種滅法，第五五種對答，以上都出自本宗。在他部律典中：首先是《僧祇律》的五種利益；其次是《十誦律》中最初勸勉學戒，自「佛告」以下列出十種滅法（彼律中列出兩個五法，此處合併為十種：第一個五法中，「有比丘」以下四句為第一法，「又不解了」即第二法，「不能」以下二句為第三法，「乃至」是省略了第四法「有說法者不能如法教鬪諍相言」，「不樂」以下即第五法；自「又不知」以下是第二個五法，首句即第一法，後面省略了第二法所說的「不隨忍法隨不忍法」，「不敬」以下即第三法，「令後」以下即第四法，「致令」以下即第五法）；自「好作」以下，即是彼律五種怖畏中的文句（一是不修習身戒心慧，二是與比丘尼親近，三是喜好寫作文章偈頌等，即如本文所引，四是為了衣食而捨棄阿蘭若進入村落，五是為了衣食而多所尋求索取）；引《善見律》中的五種令法住世之法（「毗婆沙」即翻譯為論）；引《薩婆多論》說明毘尼以四種意義殊勝於其餘經、論二藏；四大廣說出自《四分律》，該律說明比丘討論法與毘尼時，必須詳細審察，詳審文句並以三藏教法來印證判定是非，《十誦律》中稱之為四黑墨印（第一親從佛聞，第二從眾僧所聞，第三從二三人所聞，第四從一人所聞；所聞之處雖有這四種，檢驗核對都與三藏教法相合）。其餘內容如《事鈔》及《事鈔記》中所載，尋訪對照即可明白。

【924-0002】03_業疏/22b_卷四之五#166
【原文】曾以貞觀九年春，因遊方次，於泌部綿上縣鸞巢村僧坊出疏兩卷，諸用講解，為文句略指，非學未知。至二十二年春，於終南山豐德寺，三五德舊，更請重出。余不獲已，輒復疏之。昏朽之情，薄得披約，至於要玅，所未盡也。二月二十七日為讀訖，更待重修，知復何日？約卷則前輕而後重，就義則前重而後輕，據理前後未聞，附辭始終易識。舊五十紙，今二倍增，想披尋者無嫌不隱
【譯文】我曾於貞觀九年春季，在遊歷參方之際，於沁部綿上縣鸞巢村的僧坊撰出疏文兩卷，多半是用於講授解說，只是文句的大略指引，非深入學者尚不能知曉。到了貞觀二十二年春季，在終南山豐德寺，有三五位同道耆德老友，再次敦請我重新撰寫。我不得已，便冒昧再次為之作疏。以我昏邁衰朽之心境，微薄地披閱裁約，至於精要玄妙之處，實在未能闡發殆盡。二月二十七日方才講讀完畢，若還要等待重新修訂，不知又要到何年何月？若按卷數篇幅而言，則是前本少（輕）而後本多（重）；若就文義深奧而言，則是前本難解（重）而後本暢達（輕）；依據法理來說，前後兩本皆有未曾發揮聽聞之處；依附文辭來看，則始終都更為通俗易識。舊本只有五十張紙，如今增加為兩倍以上，想來披閱探尋的人，不要嫌棄它過於淺顯直白而不夠深奧隱微了。

【924-0003】03_業疏/22b_卷四之五#167
【原文】批文初敘初製前本。「至」下，次明重撰今本。「絕筆」即講因記時日。「約」下，三對校二本，有四：初句明卷，前二故輕，後四故重；次句明義，前本文略故義重，後本文廣故義輕；第三句顯理；第四句示文。後出紙數，以釋輕重
【譯文】跋文最初敘述當初初次撰寫前一本疏文。自「至二十二年春」以下，接著說明重新撰寫現在這個本子。「絕筆」即講授完畢因而記錄時日。自「約卷」以下，第三是對校前後兩個本子，共有四點：第一句說明卷數篇幅，前本只有兩卷所以算輕，後本增為四卷所以算重；第二句說明文義，前本文辭簡約難通所以義理顯得沉重晦澀，後本文辭詳廣明暢所以義理顯得輕易易解；第三句顯明法理；第四句開示文辭。最後列出紙頁數量，用來解釋篇幅數量的輕重。
