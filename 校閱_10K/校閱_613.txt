# 校閱材料　第613檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【613-0001】02_戒疏/11b_卷三上之二#22
【原文】【記】今解中。初斥非。言「本無」者，非典據也。言「浪立」者，任𦙄臆也。此但略斥，餘如《義鈔》。「但」下，顯正。「二」字同前，故但釋「不定」。謂俗女心疑，故云「若波羅夷」等。犯未定實，故云「不定」。次引《律》證。「無定法」，即目犯也。次《十誦》中，彼云「不知犯」，「不知何處起」，「不知犯名字」，餘同所引。
【譯文】【記文】在今師的新解中。首先斥責古德的錯誤觀點。說「原本沒有」，是指沒有正統經律作為依據。說「隨意安立」，是指僅憑個人的主觀臆想。這裡只是簡略批評，其餘詳盡辨析如同《戒疏義鈔》所述。「只是」以下，顯發正確的觀點。「二」這個字的定義與前面相同，所以此處只單獨解釋「不定」。意思是可信賴的女人心中起疑，所以說「若是犯了波羅夷」等等。所犯的實情尚未確定，所以稱為「不定」。接著引用《律本》為證。「沒有定法」，指的就是犯戒之相。接下來是《十誦律》的記載，那裡說「不知道所犯何罪」、「不知道從何處生起」、「不知道罪過名稱」，其餘文義與此處所引用相同。

【613-0002】02_戒疏/11b_卷三上之二#23
【原文】【記】「若爾，與古『犯不定』何別？」
【譯文】【記文】「如果是這樣，這與古德所說的『所犯不定』有何不同？」

【613-0003】02_戒疏/11b_卷三上之二#24
【原文】【記】答：「彼謂二三、單並不定，此乃事未審實不定，所以異也。」
【譯文】【記文】回答：「古德是指二罪或三罪、單犯或兼犯的數量不確定；這裡則是強調在事實審核清楚之前真相未明，這就是兩者不同的地方。」

【613-0004】02_戒疏/11b_卷三上之二#25
【原文】【疏】言出體者，亦有多師。
【譯文】【疏文】論及指明戒體這一點，過去也有眾多律師的不同主張。

【613-0005】02_戒疏/11b_卷三上之二#26
【原文】【疏】有人言：「如法自言能治行，非法自言所防罪。」
【譯文】【疏文】有人主張：「如法地自我坦白發露是能治的善行，違法的自我陳白則是此戒所防堵的罪過。」

【613-0006】02_戒疏/11b_卷三上之二#27
【原文】【記】次出體中，古解。彼謂《戒本》中比丘言「我犯是罪」，二三不定，即「非法自言」，此即戒家「所防過」。制令「如法自言」，即「能治行」。
【譯文】【記文】在接下來標明戒體的段落中，先列出古德的見解。那位法師認為《戒本》中比丘說「我犯了此罪」，在二罪三罪之間游移不定，這就是「違法的陳白」，正是戒法所要「防範的過失」。佛陀規定僧人必須「如法地坦白陳說」，這就是「能治罰的善行戒體」。

【613-0007】02_戒疏/11b_卷三上之二#28
【原文】【疏】有人云：「屏錄三罪，露收兩罪，此即是罪為不定體。」
【譯文】【疏文】又有人說：「屏處涵蓋三種罪嫌，露處則涵蓋兩種罪嫌，這幾種罪名本身就是不定的戒體。」

【613-0008】02_戒疏/11b_卷三上之二#29
【原文】【記】次師中。準《義鈔》，先難初師云：「若爾，我亦七聚罪，皆有非法自言，何獨此三，餘四不彰？又復尼亦有非法自言，何無不定？」次師乃以《戒》文所疑之罪即「不定體」。《義鈔》甚廣，且直示耳。
【譯文】【記文】在第二位律師的觀點中。參照《戒疏義鈔》，古人先詰難第一位律師說：「如果是這樣，我們佛門的七聚罪過之中，都有可能存在非法的陳白，為何偏偏只挑這三篇，其餘四聚卻不彰顯？再者，比丘尼也有非法陳白的情況，為何比丘尼戒中就沒有不定法？」第二位律師於是將《戒經》經文所懷疑涉嫌的罪名直接當作「不定的戒體」。《義鈔》的論述非常寬廣，此處僅直接指陳其要旨。

【613-0009】02_戒疏/11b_卷三上之二#30
【原文】【疏】今解不然。二三罪體，名種各別，如何束之以為一戒？今云房室私禮，俗所常行。而比丘無侶，獨一女人同處麤語，於三罪中令他疑怪，犯相難分，故言「不定」。
【譯文】【疏文】我們現在的理解並非如此。二罪或三罪的罪體，其名稱與種類各自有別，怎麼能勉強包裹在一起當成同一條戒？現在應當解釋為：房室之內的私密行徑，是在家俗人日常習以為常的事。然而比丘身邊毫無同伴，獨自與一名婦女在同一處所說麤惡淫穢的言語，在三種罪嫌之中引發了他人的懷疑怪罪，犯戒的真實相狀極難分清，因此稱為「不定」。

【613-0010】02_戒疏/11b_卷三上之二#31
【原文】【記】今解，初科，又二。初斥非。初師已如次師所破，今略不引，但斥次師耳。「今云」下，立義。準《義鈔》，即首解也。
【譯文】【記文】在今師的解釋中，這是第一科，又分為兩層。首先駁斥前人的錯誤。第一位律師的觀點已經如第二位律師所破除的那樣，現在略過不再引述，只駁斥第二位律師的看法。「如今應當說明」以下，樹立正確的義理。依照《義鈔》，這正是智首律師的解釋。

【613-0011】02_戒疏/11b_卷三上之二#32
【原文】【疏】何須禁者？出家遊棲，或入聚落，因事交涉，汙辱彼此。所損非輕，故宜須制。
【譯文】【疏文】為什麼必須制定此戒來禁制？出家人遊化棲息，有時會進入村落聚落，因世事往來交涉，極易招致彼此的污損與羞辱。這所造成的毀損非同小可，所以極有必要立法禁制。

【613-0012】02_戒疏/11b_卷三上之二#33
【原文】【記】次科，「入聚交涉」者，則知此篇犯在俗舍，如戒緣說。
【譯文】【記文】下一科中，「進入村落往來交涉」，便可知曉本篇所犯的戒境多是在俗人的房舍之中，就如同制定本戒的緣起所記載的一樣。

【613-0013】02_戒疏/11b_卷三上之二#34
【原文】【疏】所以須取三罪疑事者，此之疑心，由來未制，故得從疑，以為戒本。若取三罪，諸篇已結，何假此中方言「最初」？
【譯文】【疏文】之所以必須以牽涉三罪的起疑之事為本戒，是因為這種引起懷疑的心思，自古以來未曾立法禁止過，因此可以順應這種嫌疑，將它立為本戒的戒條。如果直接取三種罪作為戒體，其他各篇早已制定結罪，何須假借在此處才說是「最初制定」呢？

【613-0014】02_戒疏/11b_卷三上之二#35
【原文】【記】三中。「三罪」是所疑事，俗女即能疑人，由於屏露生彼疑心，故結為戒。「若下」，重點古非。
【譯文】【記文】在第三點中。「三種罪」是引人懷疑之事，可信賴的女人就是生起疑心的人，由於在屏處或露處引發了對方的猜疑心，因此結定為戒。「如果」以下，再次重點點破古德見解的謬誤。

【613-0015】02_戒疏/11b_卷三上之二#36
【原文】【疏】故《毗䟦律》云：「『如何此戒作不定說？』答云：『此未來中事，容有無實犯故。』」《四分》云：「坐既非處，生不信心。」故知疑定也。
【譯文】【疏文】所以《毘跋律》說：「『為何這條戒要作不定的說法？』回答說：『這是針對未來可能發生的事，容許有並未實際犯戒的情況。』」《四分律》也說：「同坐既然是在不合宜的地方，就會令俗人生起不信任的心思。」由此可知，生起懷疑這一點是千真萬確、固定不移的。

【613-0016】02_戒疏/11b_卷三上之二#37
【原文】【記】四中。初引《毗䟦律》。「未來中事」，恐犯預制故。「容無實犯」，顯示不定故。次《四分》中。「坐非處」者，謂屏、露也。「不信心」即是疑也。所疑雖不定，而生疑是定，即是戒家所防體也。
【譯文】【記文】在第四點中。首先引用《毘跋律》。「未來之事」，是指恐怕後人犯錯而預先防範制定。「容許沒有實犯」，是為了顯明情況的不確定性。接著引用《四分律》。「坐於非處」，指的是屏處或露處。「不信敬心」指的就是懷疑。所懷疑的內容雖然不固定，但是「引起了懷疑」這件事卻是確定無疑的，這也就是戒法所要防範的實體。

【613-0017】02_戒疏/11b_卷三上之二#38
【原文】【疏】問：「既無實犯，何須制者？」
【譯文】【疏文】提問：「既然沒有真正犯下重罪，為何還要特地制定這條戒？」

【613-0018】02_戒疏/11b_卷三上之二#39
【原文】【疏】答：「三戒染分，外涉必多。故制生疑，即是違戒。令諸不犯，用清道俗。」
【譯文】【疏文】回答：「這三條戒律涉及男女貪染的情分，對外涉足世俗的機會必然極多。因此制定：只要引人起疑，就等於是違背了戒律。好讓所有僧眾都不去觸犯，藉以維持僧俗兩界的清淨。」

【613-0019】02_戒疏/11b_卷三上之二#40
【原文】【記】五中，初問。躡前所引，以求制意。答中。初二句敘制緣。「故」下，次明正制。「令」下，顯制意。
【譯文】【記文】在第五點中，首先是提問。承接前文所引用的律文，以探討佛陀制戒的深意。在回答之中，前兩句敘述制戒的因緣。「所以」以下，進一步說明正式制戒的內容。「使令」以下，顯明制戒的最終目的。
