# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【187-0002】02_戒疏/09b_卷二下之二#60
【原文】【疏】又云：「盜有續成重，故作方便名，再觸非大婬，如何結究竟？如《律》云：『再盜不滿五，佛言相續夷。』」
【譯文】【疏文】又說：「盜竊有可能前後累積相續而構成重罪，所以立為方便罪的名稱；再次摩觸並不會累積變成大淫，如何能結成大淫的究竟重罪呢？正如《律》中說：『再次偷盜雖然每次不滿五錢，佛說心念相續合算就算犯斷頭重罪。』」

【187-0003】02_戒疏/09b_卷二下之二#61
【原文】【記】次釋，引《律》。此據初盜期心未遂，必作斷心，多反亦蘭。
【譯文】【記文】第二種解釋，引用《律》文。這是依據最初偷盜時預期的目標尚未達成，如果本來就存有中止之心，即使分多次偷盜也只是偷蘭遮。

【187-0004】02_戒疏/09b_卷二下之二#62
【原文】【疏】「又內外起心異，故分因果別。」
【譯文】【疏文】「再者，由內心或外在境緣生起的心態不同，所以因罪與果罪的劃分有別。」

【187-0005】02_戒疏/09b_卷二下之二#63
【原文】【記】後釋中。婬為內觸，心期婬事，觸則因蘭。摩是外觸，即成殘果，故云「因果別」。盜唯外起，無別因果。
【譯文】【記文】最後的解釋中。大淫屬於體內交會，若本心追求淫事，觸碰只是前奏的偷蘭因罪。摩觸是體外的觸碰，著體當下就獨立成就僧殘果罪，所以說「因果有別」。盜竊純粹由對外物貪求而起，並無另外的獨立果罪。

【187-0006】02_戒疏/09b_卷二下之二#64
【原文】【註】佛在舍衛國。迦留比丘，以佛前制，便在內外伺諸婦女，將至房中，手捉捫摸，樂者便笑；有不樂，瞋恚罵辱。諸比丘舉過白佛，便集僧制戒。
【譯文】【註文】佛陀在舍衛國時，迦留比丘因為佛陀先前已制定戒條，便在僧房內外窺伺婦女，把她們帶到房中，用手捉持撫摸；婦女中歡喜的就笑，不歡喜的就生氣責罵侮辱。諸比丘把這件事報告佛陀，佛陀於是集合僧眾制定戒條。

【187-0007】02_戒疏/09b_卷二下之二#65
【原文】【疏】就戒緣中，俗女譏笑有二相者，如《薩婆多》云：「諸女何以來者？一、以世俗怱務，出家住靜安樂故；二、善友知識聞法故；三、僧房嚴飾可觀故。何故入房者？謂出家人斷欲清淨，信無疑故。何為笑、罵者？一、有欲心多少故；二、為知識非知識故；三、樂覆樂露故；四、有親有難，無者無故。」如是應知。
【譯文】【疏文】在制戒因緣中，俗家女人的譏笑有兩種面向，如同《薩婆多論》所說：「這些婦女為何前來呢？第一、因為世俗事務繁忙勞碌，見出家人住處寂靜安樂的緣故；第二、因為跟隨善友知識前來聽聞佛法的緣故；第三、因為僧房莊嚴修整值得觀賞的緣故。她們為何進入僧房呢？因為認為出家人已斷除貪欲身心清淨，深信無疑的緣故。她們為何有的笑、有的罵呢？第一、因為各人心中欲念多寡不同的緣故；第二、因為與僧人熟識或不熟識的緣故；第三、因為有的喜歡隱蔽、有的喜歡公開的緣故；第四、有親屬在場便畏懼指責而斥罵，無親屬在場則無所顧忌而歡笑的緣故。」這些情況都應當明瞭。

【187-0008】02_戒疏/09b_卷二下之二#66
【原文】【記】戒緣引《論》，次列三意。初女來意，復有三別。次入房意。言「無疑」者，信彼出家必無欲故。後笑罵意中，四句雙列，分配笑、罵：上二可知；三中，樂覆則笑，樂露則罵；四中，有親則畏難故罵，無親則無畏難故笑。
【譯文】【記文】戒緣引用《論》文，接著列出三層意思。首先是女子前來的動機，又分三種。其次是進入室內的動機。所說「毫無懷疑」，是相信出家人必定沒有欲念。最後是笑與罵的原因，以四句相互對列，分別配屬笑與罵：前二句顯而易見；第三句中，歡喜隱蔽的就笑，喜好公開的就罵；第四句中，有親人在場則心懷顧忌而斥罵，無親人在場則無所忌憚而發笑。

【187-0028】02_戒疏/09b_卷二下之二#86
【原文】【律】若捉手，若髮。
【譯文】【律文】若抓手，若抓頭髮。

【187-0029】02_戒疏/09b_卷二下之二#87
【原文】【疏】言「相觸」者，《律》明觸相，乃有十種，易解。「若捉手、髮」者，「手」謂犯起先由，「髮」謂釋除疑結也。時有疑云：「捉手身肉，則有適樂細滑。髮是身分，何業之有，而結罪耶？」故今以「髮」入於《戒本》，但著則犯，由染汙心。
【譯文】【疏文】所謂「相觸」，《律》中說明的接觸形態，有十種之多，容易理解。「若抓手、抓頭髮」，「手」是指最先引發犯行的端緒，「頭髮」是為了破除世人的疑惑。當時有人懷疑說：「握手或撫摩皮肉，有舒適滑細之感。頭髮只是身體的角質附件，有何業用可言，為什麼也要判罪？」所以現在將「抓頭髮」列入《戒本》，只要沾觸就算犯戒，都是因為出於染污之心的緣故。

【187-0030】02_戒疏/09b_卷二下之二#88
【原文】【記】觸相中，初科。前指《律》中十種者，如注所列。今引《律》釋之：一、「捉摩」者，摩身前後；二、「重摩」；三、「牽」者，牽前；四、「推」者，推後；五、「逆摩」者，從下至上；六、「順摩」者，從上至下；七、「舉」者，捉舉上；八、「下」者，若立捉令坐；九、「捉」者，捉前捉後，捉乳捉髀；十、「捺」者，以手按也。「若」下，次點戒文二相。「時」下，別釋除疑，初敘疑情。「故」下，示出意。
【譯文】【記文】觸相之中，第一段。前面指明《律》中所列的十種形態，如同註文所載。現在引用《律》來解釋：第一、「抓握摩弄」，是摩擦身體的前胸後背；第二、「用力重摩」；第三、「牽拉」，是往前拉；第四、「推拒」，是往後推；第五、「逆摩」，是從下往上擦；第六、「順摩」，是從上往下摸；第七、「舉起」，是抓住抬高；第八、「放低」，若是站著則按壓令其坐下；第九、「抓握」，是摸前摸後，摸乳房摸大腿；第十、「按捺」，是用手重壓。「若」字以下，其次提示戒文列舉的兩種代表相狀。「當時」以下，分別破除疑難，首先敘述懷疑的情態。「所以」以下，顯示戒文特意列出的用意。

【187-0031】02_戒疏/09b_卷二下之二#89
【原文】【疏】今《四分》中不分其相。應以四句，明其輕重，覺不覺境，如是分之。故《善見》云：「髮髮相著，爪爪相觸，悉得偷蘭，俱無覺故。」若互觸者，理結僧殘，同《戒本》也。
【譯文】【疏文】如今《四分律》中沒有細分觸相。應當以四種情況，辨析罪相輕重，依照能覺知與無覺知的對境，這樣來劃分。所以《善見律》說：「頭髮觸碰頭髮，指甲觸碰指甲，全都結偷蘭遮罪，因為雙方都沒有知覺接觸。」如果是互有觸感者，按理當結僧殘罪，這與《戒本》是一致的。

【187-0032】02_戒疏/09b_卷二下之二#90
【原文】【記】歷句中。初指句。一、覺觸不覺，二、不覺觸覺，三、覺觸覺，四、不覺觸不覺。「故」下，次引《善見》，別證第四句。「若互」下，後約義意，決前二互。《鈔》引《十誦》，互觸並蘭；今據《戒本》，捉髮成重，故云「理結僧殘」等。
【譯文】【記文】依句式分析之中。首先列出句型：第一、知覺處碰觸無知覺處；第二、無知覺處碰觸知覺處；第三、知覺處碰觸知覺處；第四、無知覺處碰觸無知覺處。「故」字以下，其次引用《善見律》，特別印證第四種情況。「若互」以下，最後根據法義旨趣，斷決前面兩種交互情況。《事鈔》引用《十誦律》，主張交互觸碰都算偷蘭；現在依據本宗《戒本》，認為抓住頭髮就已構成重罪，所以說「按理當結僧殘」等。

【187-0036】02_戒疏/09b_卷二下之二#94
【原文】【註】若觸四女，著便僧殘。女觸比丘，動身同犯；若不動身，但犯吉羅；先有染心，偷蘭。互觸有依，偷蘭；俱有衣者，吉羅。若與二形相觸，偷蘭。若以欲心觸男子身，或衣、坐具，乃至自觸及以畜生，一切突吉羅。尼，波羅夷。下三眾，吉羅。不犯者，有所取與、戲笑相觸是也。
【譯文】【註文】若是觸碰四類女人，只要肌膚相著就犯僧殘罪。若是女人來碰觸比丘，比丘主動動身迎合則同犯重罪；若是不動身，只犯突吉羅罪；若是預先已起染心，犯偷蘭遮罪。雙方有一方隔著衣服相觸，犯偷蘭遮罪；雙方都穿著衣服相觸，犯突吉羅罪。若是與陰陽人相觸，犯偷蘭遮罪。若是帶著欲心觸碰男人的身體，或其衣服、坐具，乃至撫弄自身以及觸碰畜生，一切都犯突吉羅罪。比丘尼犯波羅夷罪。其餘下三眾犯突吉羅罪。不犯戒的情況是：為了取物或遞給東西，或者無心嬉戲相撞而碰觸之類。

【187-0037】02_戒疏/09b_卷二下之二#95
【原文】【疏】就注解，人女中三位。初二俱無衣，分二。初明比丘觸四女相，後明女來觸比丘相。犯有輕重，可解耳。二、明互觸有衣相。計應約身動不動、約心樂不樂分輕重，以偷蘭含，故文中不分也。對後俱衣，例同下斷。
【譯文】【疏文】就註文而言，人女這一對象中包含三種位階。首先是雙方都無衣服隔著，分兩層：第一說明比丘觸碰四類女人的情形，第二說明女人前來觸碰比丘的情形。犯戒輕重顯而易見。第二、說明有一方隔著衣服相觸的情形。照理應當根據身體動與不動、內心受樂與不受樂來區分輕重，因為偷蘭遮罪名涵蓋範圍廣，所以文中沒有細分。這與後面雙方都穿衣服的情況相比，可比照後文的判斷方式。
