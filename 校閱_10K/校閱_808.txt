# 校閱材料　第808檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【808-0001】02_戒疏/19b_卷四下之一#81
【原文】【記】六十三，制意中。初敘出家本志。「今」下，次出疑惱過狀。「生年等六」，如下自列。
【譯文】【記文】第六十三條，制意中。開頭敘述出家的本志。「今」以下，其次指出疑惱的過失相狀。「生年等六」一項，如下文自己所列。

【808-0002】02_戒疏/19b_卷四下之一#82
【原文】【疏】論有五緣：一、是大比丘，《多論》「十三難，顛狂比丘，吉羅；學悔、六夜別住、四羯磨、僧尼互疑，並是提，具自性故」；二、作疑惱意；三、六事隨說一相；四、言詞了了；五、前人聞知。
【譯文】【疏文】論犯有五個條件：一、是大比丘，《多論》說：「十三難（之人）和顛狂比丘，犯突吉羅；學悔、六夜別住、四羯磨（之人），以及僧尼互相疑惱，都是波逸提，因為他們具足自性（有戒體）的緣故」；二、有令人生疑惱亂的心意；三、於六件事中隨說其中一相；四、言詞清楚明白；五、對方聽到並了解。

【808-0003】02_戒疏/19b_卷四下之一#83
【原文】【記】犯緣。第一，簡下三眾。《多論》復簡本眾，「十三難人」無受體，「顛狂」人失正念，故此二並輕；「學悔」已下，反上故重。「學悔」即犯重人。「六夜別住」，即懺殘人。「四羯磨」即呵責等人。「具自性」者，有戒體也。顛狂雖具，然由心亂，而不自知是比丘故。
【譯文】【記文】犯緣。第一項，是簡別下三眾（沙彌、沙彌尼、式叉摩那）。《多論》又從本眾中再作簡別：「十三難人」沒有受戒的戒體，「顛狂」的人失掉正念，所以這兩類都輕（犯突吉羅）；「學悔」以下的人，與上面相反，所以犯重（波逸提）。「學悔」就是犯重罪後懺悔的人；「六夜別住」就是懺悔僧殘的人；「四羯磨」就是被呵責等羯磨處分的人。「具自性」的意思是有戒體。顛狂的人雖然有戒體，但因為心智昏亂，不能自知自己是比丘的緣故。

【808-0014】02_戒疏/19b_卷四下之一#94
【原文】【註】尼同犯。不犯者：其事實爾，不故作，彼非爾許時生，恐後疑悔，無故受他利養，受大比丘禮敬，便語言「汝非爾許時生；如餘人生，知汝非爾許時生」；其事實爾，彼無爾許歲，恐後疑悔，受他利養、敬奉，語言「汝無爾許歲；如餘比丘，知汝未爾許歲」；其事實爾，若年不滿二十、界內別眾，恐後疑悔，受利養、禮敬，語令知，還本處更受戒故；其事實爾，白不成、羯磨不成、非法別眾，恐後疑悔，受利養、禮敬，語彼令知，還本處更受戒故；其事實爾，犯波羅夷乃至惡說，恐後疑悔，受人利養，受持戒比丘禮敬，欲令知如法懺悔，故語知犯乃至惡說；又為性麤踈，不知言語，便言「汝所說者，自稱上人法」。若錯，若戲笑者，無犯。
【譯文】【註文】比丘尼同樣犯。不犯的情況：事情確實如此，不是故意，對方並非在那個時候出生，恐怕他日後心生疑悔，無緣無故接受他人的利養、受大比丘的禮敬，便對他說：「你並非在那個時候出生；像其餘人出生那樣，我知道你不是在那個時候出生的。」事情確實如此，對方沒有那麼多歲，恐怕他日後疑悔，接受他人的利養、敬奉，便對他說：「你沒有那麼多歲；像其餘比丘一樣，我知道你還沒有那麼多歲。」事情確實如此，或者年歲不滿二十、在界內別眾而受戒，恐怕他日後疑悔，接受利養、禮敬，便告訴他讓他知道，應該回到本處重新受戒的緣故；事情確實如此，白羯磨不成、羯磨不成、非法別眾，恐怕他日後疑悔，接受利養、禮敬，便告訴他讓他知道，應該回到本處重新受戒的緣故；事情確實如此，犯了波羅夷乃至惡說，恐怕他日後疑悔，接受他人的利養、受持戒比丘的禮敬，想讓他知道而如法懺悔，所以告訴他知道犯了波羅夷乃至惡說；又或者因為他天性粗疏，不懂得言語分寸，便說「你所說的，是自稱得上人法」。若是說錯了，或者是開玩笑，都不犯。

【808-0016】02_戒疏/19b_卷四下之一#96
【原文】【記】戒本。第二，注釋「故」字，引示本緣，反上非犯。次釋「惱他」，注列六事：一、「生年」，謂惱他云「汝非爾許時生」；二、云「歲」者，即是夏臘，如云「汝無爾許夏臘」；三、「受戒」者，如云「汝年未滿，諸緣非法，受戒不得」；四、「羯磨」者，如云「汝受戒時白羯磨不成」等；五、「犯」者，如云「汝犯七聚罪」等；六、「法」者，如云「汝自稱上人法」等。
【譯文】【記文】戒本。第二句，注文註釋「故」字，引述顯示本來的緣起，反顯上面的情況不是犯。其次解釋「惱他」，注文列出六件事：一、「生年」，就是惱亂他人說「你不是在那個時候出生的」；二、說「歲」的，就是夏臘，如說「你沒有那麼多夏臘」；三、「受戒」的，如說「你年紀未滿，種種條件不如法，受戒不得」；四、「羯磨」的，如說「你受戒時白羯磨不成」等；五、「犯」的，如說「你犯了七聚之罪」等；六、「法」的，如說「你自稱得上人法」等。

【808-0017】02_戒疏/19b_卷四下之一#97
【原文】【疏】就不犯中，次等開緣。「生」、「夏」兩種，無本處文。若「受戒羯磨令本處」者，以受戒託緣，非相難識，必於事法有疑，還本受戒處，審詳知過，方可受之，則於後無濫，故云爾也。餘可解耳。
【譯文】【疏文】在「不犯」這一段中，接著是等同的開緣。「生」（不知年歲）與「夏」（不知夏臘）這兩種情形，註文中沒有『令還本處更受戒』的文句。至於「受戒羯磨令本處」這一句，是說受戒必須依託種種因緣，它的相貌不容易辨識，如果對事相與作法有所疑惑，就回到原來受戒的地方，詳細審問，明白其過失所在，才可以為他授戒，這樣日後才不會混濫，所以經文才這樣說。其餘的照文理解即可。
