# 校閱材料　第277檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【277-0001】資持記/08e_中二#12
【原文】第四引《善見》，若未還直不成受犯者，猶屬他故；若度價己，他邊亦犯，即己物故。指略中。即前八門轉降相染等義，同故不出，廣在疏中。二十二。〔佛在舍衛，跋難陀鉢破求眾多畜，招譏故制。〕列緣中。五綴者，律云：相去兩指間一綴〔中人一指面一寸，即取痕脈長二寸許，即為一綴；
【譯文】第四項引用《善見律》，如果尚未償還價款就不構成接受犯戒，因為財物仍屬於對方；如果已經作價結算完畢，就算放在他人那邊也算犯戒，因為已經屬於自己的物品。指出省略的部分。也就是前面八門中各自分降、互相染著等義理，因為相同所以不再列出，詳細內容在戒疏之中。第二十二條戒。〔佛陀在舍衛國時，跋難陀的鉢破了，藉機索求許多鉢來蓄積，招致譏嫌因而制戒。〕列出的犯戒條件中。五道補綴，律中說：相距兩指之間就算一道補綴〔普通人一指寬約一寸，也就是裂痕長約二寸左右，便算一道補綴；

【277-0002】資持記/08e_中二#13
【原文】五綴共一尺也。〕，綴者，即以鉛錫等補。今時鉢損，未必待綴；但約破脈滿尺，即開他求。不漏吉者，緣不具故。事下指疏，彼文廣明捨法；鈔本行事，時既不行，不復多引；但知一鉢趣養餘生，勿事多求，則符聖教矣。不犯八緣。五綴漏者，此開吉罪。
【譯文】五道補綴加起來總共一尺。〕，「綴」就是用鉛、錫等金屬修補。現在這時代鉢損壞了，不一定非要等到五綴；只要破裂的痕跡累計滿一尺，就開許向他人求取。不漏水卻犯輕罪（吉羅）的情況，是因為犯戒條件不具備。從「事」以下指引參照戒疏，那裡的文句詳細說明捨棄的方法；《行事鈔》主要是推行日常實修，當時既然已經無法實行，就不再多加引用；只要明白一個鉢是為了勉強維持餘生，不要去多方索求，就符合聖人的教導了。不犯戒的八種情況。滿五道補綴而漏水，這是開許免除輕罪（吉羅）。

【277-0003】資持記/08e_中二#14
【原文】自有買者，注戒作若自有價買畜者，文相方顯，謂不從他乞也。二十三。〔佛在舍衛，難陀縫衣乞線多；持線使織自作繀，招譏因制。〕制意中。捨惡法者馳求涉俗，長貪壞行故。止謗者，如戒緣說。犯緣。第三，反知雇人不犯正罪，與下《五分》不同。釋中，初緣，《十誦》。無衣乞縷情諂故吉。
【譯文】自己有能力買的，在戒本的注文中寫作如果自己有錢購買蓄積的，文意才算明顯，是指不是向別人乞討。第二十三條戒。〔佛陀在舍衛國時，難陀縫製衣服索求了過多的線；拿著線役使他人紡織，自己還搖車抽線，招致譏嫌因而制戒。〕制戒用意中。捨棄惡法，是因為向外奔馳索求涉及俗務，會滋長貪欲並損壞道行。止息譏謗，就如同制戒緣起所說。犯戒條件。第三項，反推可知僱用他人並不犯這條正罪，這一點與後面的《五分律》不同。在解釋中，第一個犯戒條件引自《十誦律》。沒有衣服而乞討絲線，心懷諂媚所以犯輕罪（吉羅）。

【277-0004】資持記/08e_中二#15
【原文】隨缺直乞，如下所開。《五分》。雇人酌情結墮。準緣不具，今宗應吉。釋第二中，上明開親。疏云以離損謗之緣故。義準四句，初二俱是親〔不犯如上〕；二二俱非親；三與線者親，織師非親〔二句並墮〕；四與線非親，織師是親〔如下結吉〕。與下，明輕犯。
【譯文】隨著所缺損的直接乞求，就像下面所開許的那樣。《五分律》中。僱用他人則斟酌情節判定為波逸提。按照條件不具備的法則，本宗應當判定為輕罪（吉羅）。在解釋第二項中，上面說明開許向親屬乞求。《戒疏》說是因為脫離了損害他人與招致譏謗的緣由。在義理上推准有四種情況，第一種兩方都是親屬〔不犯戒如上面所說〕；第二種兩方都不是親屬；第三種給線的是親屬，織布師不是親屬〔這兩種情況都判墮罪〕；第四種給線的不是親屬，織布師是親屬〔如下面判定為輕罪（吉羅）〕。從「與」以下，說明犯輕罪的情況。

【277-0005】資持記/08e_中二#16
【原文】看織下，準律合有自織。繀，蘇內反，謂著絲於車也。不犯中。開自織者，疏云：但為小細，過非深故；至於妨道，非不是損。二十四。〔佛在舍衛，居士出線與跋難陀作衣，乃往彼家擇取好線與織師織，又許與價，因譏而制。〕列緣中。第四正是業本。
【譯文】從「看織」以下，依照律文應當也包含自己紡織。「繀」音蘇內切，意思是將絲線穿掛在紡車上。在不犯戒中。開許自己紡織的，戒疏說：這只屬於微細小節，過失並不嚴重；至於妨礙修道，則不能說沒有損害。第二十四條戒。〔佛陀在舍衛國時，居士出線準備給跋難陀做衣服，跋難陀竟跑到居士家挑揀好線交給織布師織，又答應加給工錢，因而招致譏嫌而制戒。〕在列出的犯戒條件中。第四項正是造成罪業的本體。

【277-0006】資持記/08e_中二#17
【原文】許直者，《戒本》云：乃至一食直。《四分》下，別釋第六，此結方便。《多論》云：前戒憑勢遣織，作成即犯；此戒自求，領受便結。疏問此戒損縷，與前一二居士何異？答：前面對縷主，此屏勸織師，故兩制也。不犯中。親里及出家人，皆約縷主。若勸織師，豈無小過！思之。
【譯文】允諾給工錢，《戒本》說：乃至一頓飯的工資。從《四分律》以下，分別解釋第六項，這是判定預備的前方便罪。《多論》說：前一條戒是依仗威勢打發人去織，織好就犯戒；這一條戒是自己主動索求，接受成品時就定罪。《戒疏》提問這條戒讓絲線耗損，與前面有一位或兩位居士有何不同？回答：前戒是當面面對絲線的主人，此戒是私下背地勸說織布師，所以分別制定兩條戒。在不犯戒中。親屬以及出家人，都是針對絲線主人而言。如果私下去勸說織布師，難道會沒有小過失嗎！應當深入省思。

【277-0007】資持記/08e_中二#18
【原文】二十五。〔佛在舍衛，跋離陀欲與難陀弟子共行，先與衣，後不隨彼意，即奪衣，因制。〕緣中。初緣簡下位，準疏云奪但犯吉。三中，總有四句，初句此戒正緣；四下二句，歸前盜攝；若下一句，緣闕故輕。第五準律奪而藏者犯，奪未藏者吉，謂對面奪。若非對奪，離處即犯。
【譯文】第二十五條戒。〔佛陀在舍衛國時，跋離陀想與難陀的弟子同行，先給了他衣服，後來對方不順從他的心意，跋離陀隨即將衣服奪回，因而制戒。〕條件中。第一個條件排除了下位之人，依照戒疏所言，奪取只犯輕罪（吉羅）。第三項中，總共有四種情況，第一句是本戒的正緣；四句之中的下兩句，歸入前面的盜戒所收攝；「若」以下的一句，因為條件不齊全所以從輕發落。第五項依照律文搶奪後藏匿起來的犯戒，搶奪後未藏匿的犯輕罪（吉羅），這是指當面搶奪。如果不是當面搶奪，離開原處就犯正罪。

【277-0008】資持記/08e_中二#19
【原文】不犯有八。初開善取，餘七並以若字分之。彼知悔者，謂自知即還，不待他索。命梵者，因與致難，奪取則免。一下，總結。傳文訛脫，古今疑之。準注戒云：一切奪取不藏舉者，皆不犯。以律面奪藏舉方結；今明不犯，意顯諸緣並是可奪，不必須藏；即以此語，通結上緣，故云一切。
【譯文】不犯戒的有八種情況。首先開許善意取回，其餘七種都用「若」字來區分。對方知錯悔改，是指對方自己知道就歸還，不等待他人索討。喪失性命或梵行的危難，是因為給了衣服引來災難，奪取回來就能免除。從「一」以下，進行總結。流傳的文字有訛誤脫漏，古往今來的人對此都有疑問。依照戒本的注文說：凡是奪取而不藏匿存放的，全都不犯戒。因為律文中當面搶奪且藏匿起來才定罪；現在說明不犯，用意是顯明這些情況全都是可以奪回的，並不一定非要藏匿；這就是用這句話，通貫總結上面的諸種條件，所以說「一切」。
