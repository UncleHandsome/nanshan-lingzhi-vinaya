# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【18-0001】資持記/16e_下四#5
【原文】三入俗僧者，先捨與僧，僧與俗故。餘同者，四乞鉢入厨，五諸衣還主，同《四分》也。《僧祇》。寶藏名無盡財。息利作衣，不得分者，恐彼獲分，故云為折伏等。二中。五臥具，即上五敷。初總示。其下，別簡。純黑，即黑毛；憍奢耶，即蠶綿。〔有將為一，非也。〕嚮，即門戶。
【譯文】第三類歸入俗人或僧團的情況，是指先將財物捨給僧團，再由僧團轉交給俗人。其餘規定相同者，是指第四項將乞來的鉢入廚、第五項將各類過限衣物歸還原主，這些都與《四分律》相同。《僧祇律》將庫藏物資稱為「無盡財」。用其孳生的利息來做僧衣，犯戒者不得分得，是因為擔心他參與分配，因此說這是為了折伏其貪心。在第二段中，「五臥具」就是指上述的五種敷具。起初先作總體說明；在「其」字以下，再分別加以甄別。純黑，指的就是黑羊毛；憍奢耶，指的就是蠶綿。（有人將這兩者混為一談，那是錯誤的。）「嚮」，指的就是門窗門戶。

【18-0002】資持記/16e_下四#6
【原文】六年不揲得著者，上二細者，止得麁用，故不許著；不𭣋身者，恐壞僧物故。白毛好者，如前，同黑毛等；不好如後，同六年等。餘同者。諸衣乞鉢長藥等三，同本宗也。《善見》。金銀，即二寶也。五法，不愛恚怖癡，知可擲不可擲。《了論》七段。初段七戒：轉車衣，即二離衣；待一月，即月望。受下，次段一戒；
【譯文】六年（減六年敷具）與不揲（新敷具未縫貼舊布）之所以得以敷設使用者，是因為前述兩種質地細軟者，只准作粗用，所以不准正式敷設使用；不直接襯藉在身體之下的原因，是擔心損壞了常住僧物。白色羊毛品質優良者，依循前例，與黑羊毛等同看待；品質粗劣者則依後例，與使用六年未縫貼者同等處理。其餘相同者，是指各種過限衣物、乞鉢以及多蓄的長藥等三項，都與本宗的規範一致。《善見律》所說的金銀，指的就是金銀二寶。五種法，是指能遠離貪愛、瞋恚、恐懼、愚癡，並且明瞭何物可以丟擲、何物不可丟擲。《律二十二明了論》共有七段。第一段包含七條戒：轉移車乘之衣，即指兩種離衣戒；等待一月，即指滿一個月之期。在「受」字以下，是第二段的一條戒；

【18-0003】資持記/16e_下四#7
【原文】本尼無者，或死反道遠行等。使下，第三段二戒。從下，第四段三戒；一二居士，即勸增二戒。過下，第五九戒；過足，即過知足戒。三反，即怱切索衣戒；一切敷具，通收五敷；使織師，更含勸織。奪衣為第六。七日為第七；二用，即與僧俗。
【譯文】所依止的比丘尼若已不在，可能是因為死亡、還俗或遠行等緣故。在「使」字以下，是第三段的兩條戒。在「從」字以下，是第四段的三條戒；其中提到的一位或兩位居士，就是指勸說居士增加布施衣料的兩條戒。在「過」字以下，是第五段的九條戒；超過限度，即指違背知足戒。三次索討，即指急迫索取衣料戒；「一切敷具」則通括了前述五種坐臥具；指使織師，更包含了勸誘織師增織質料之戒。搶奪僧衣是第六段。蓄藥七日是第七段；所謂兩種用途，就是指布施給僧團或俗人。

【18-0004】資持記/16e_下四#8
【原文】己上收二十四戒，二寶、販賣、乞鉢、擔羊毛、染羊毛、並如〈隨相〉。《多論》，明販賣，初明入僧。若下次明不入佛有二意，初為止謗。瞿曇，此云地最勝，謂在地人中最勝故，此即如來因地之姓，人猶稱之；佛昔於劫初，作國王禪位師瞿曇仙修道，因以為姓。又下，次彰福勝。
【譯文】以上共收錄了二十四條戒，至於金銀二寶、經商販賣、非法乞鉢、自行擔運羊毛、非法染羊毛等戒條，都詳細記載在〈隨相釋罪篇〉中。《薩婆多論》說明經商販賣戒，先說明所得財物歸入僧團。在「若」字以下，次說明不歸入佛陀的兩種用意：第一是為了止息外人的毀謗。「瞿曇」，漢語譯為「地中最勝」，是指在一切大地人類之中最為尊勝，這本是如來在因地時的家族姓氏，世人仍以此相稱；佛陀在過去初劫之時，曾作國王，禪讓王位後，拜瞿曇仙人為師修道，便以此作為姓氏。在「又」字以下，次說明僧團的福田最為殊勝。

【18-0005】資持記/16e_下四#9
【原文】不問等者，顯僧海深，廣無不攝也。不受法，即無戒也。七中。〈隨相〉事多，且出一條特異之者。初明行懺違法開成。更下，次開不懺，直得清淨。此六種人，初二恐壞眾信，為護法故；三四身心怯弱，為接引故；五六行法闕緣，為命難故。心念懺悔，即復本淨，後不須悔；
【譯文】經文中說「不論」等語，是為了彰顯僧海的深廣，浩大得無所不包。所謂「不受法」，就是指沒有受持戒法。在第七部分中，〈隨相釋罪篇〉的事項非常繁瑣，此處暫且列出一條極為特殊的規定。首先說明懺悔作法雖有違律制，但仍開許其懺罪成立。在「更」字以下，接著開許不須經由懺罪程序，直接恢復清淨。這六種人當中，前兩種是擔心敗壞信眾對佛法的信心，為了護持大局之故；第三、第四種是由於身心怯弱，為了接引攝受之故；第五、第六種是因為行持懺法時缺少外在因緣，為了避開生命危難之故。他們只要在內心起念懺悔，就能恢復本有的清淨，日後也不需要重新發露懺悔；

【18-0006】資持記/16e_下四#10
【原文】若準《四分》，一切不成。律下，引注伸誡，遮後倚濫；唐，虛也。第三批文，為三；初年月等，記其時也；且閉戶者，即終南苧麻蘭若，此記處也；但下，即彰述作之本。祖師降生於隋世，弘化于唐朝；高祖神堯皇帝受隋恭禪位，始號唐國，改元武德。九年六月，絕筆時也。
【譯文】如果依照《四分律》的通則，這些作法全都不算成立。在「律」字以下，引述夾注來申明誡勉，以防後人隨意依傍而濫用開緣；「唐」字的意思是虛設。第三段題跋的文字，分為三個層次：首先說明年代與月份等，是記錄寫作的時間；所謂「暫且閉門」，是指在終南山的苧麻蘭若，這是記錄寫作的地點；在「但」字以下，則是表明撰寫這部論著的根本旨趣。道宣祖師誕生於隋代，並在唐朝弘揚教化；唐高祖神堯皇帝接受隋恭帝禪讓皇位，建國號為唐，改年號為武德。武德九年六月，正是此書最終撰畢停筆的時間。

【18-0007】資持記/16e_下四#11
【原文】爾前太史傅奕，黨助道宗，誣謗釋氏，奏請沙汰，高祖依之；於是抱道碩德，遁于巖野；故祖師隱于終南苧麻蘭若，首撰此鈔；至九年，太宗復興吾教，搜揚有德；祖師是輔相之子，道德著聞，皆被搜選，故云爾時等。俗譽，此謂俗中聲譽，無所傷也。言閉戶者，明避難也。依所學者，彰有承也。
【譯文】在此之前，太史令傅奕偏袒道教，誣蔑毀謗佛教，奏請高祖淘汰沙門，高祖准許了他的奏請；於是懷抱道風的大德高僧，紛紛隱匿於深山荒野之中；因此道宣祖師隱居在終南山的苧麻蘭若，開始撰寫這部《行事鈔》；到了武德九年，唐太宗重新興隆佛教，搜訪提拔有德行的高僧；祖師原是宰相之子，道德學問顯著聞名，也被朝廷搜訪選拔，所以才說「在那個時候」等語。文中所稱的「俗譽」，是指世俗間的聲望名譽，並無損於道業。所說的「閉門」，是說明為了避開教難。提到「依照所學」，是彰顯自己的傳承有憑有據。

【18-0008】資持記/16e_下四#12
【原文】但下二句，述本志也。直筆書者，不演義章；刪除異論，離諸曲碎故。不下二句，示謙損也。龍身有文彩者，謂之虬。語澁故蹇，文鄙則陋。想下二句，囑審悉。有識謂智高，通士謂鑒遠。文多記字，疑是傳錯。
【譯文】在「但」字以下的兩句，是記述原本的志向抱負。所謂「直率下筆書寫」，是指不鋪陳瑣碎的義理章句；直接刪除歧異紛雜的言論，遠離各種曲折繁碎的枝節。在「不」字以下的兩句，表現出謙遜退讓的美德。龍身上有彩色斑紋的，稱為「虬」。言語蹇澀所以顯得遲鈍，文字質樸就顯得簡陋。在「想」字以下的兩句，是囑咐後人詳細審度明察。有識之士是指智慧高超的人，通達之士是指見識遠大的人。傳本文字中多帶有「記」字，懷疑是傳抄過程中所產生的訛誤。

【18-0009】02_戒疏/00_卷首#1

【原文】【序】觀夫太虗寥廓，既絕諸過於寂滅之津；真心靈鑑，固具眾德於常樂之域。斯之謂法佛本性之尸羅，萬德圓備，其至矣哉！雖然，境風震烈，心海鼓動，隨緣流變，逐塵而封執，遂使戴角披毛，劇苦無盡期焉。懷此明珠，竛竮六趣，難辛疲乏，實可悲傷也！我大雄氏之出震于竺乾，遠本渺茫焉。證道於寂光，垂影於心土。則於寂滅道場，初結菩薩戒，稱法性之體而斷惡修善，隨真如之用而絕應無方。體用一源，顯微潛通，謂之菩薩三聚淨戒，萬行悉備。嗚呼，偉哉！然而人性不齊，氣稟質殊，如何其堪于菩薩大行耶？
【譯文】【序文】審視那廣大無涯的太虛之境，既然在寂滅的究竟彼岸斷絕了一切過失；而真心靈妙的照鑑，本就圓滿具足眾多功德於常住安樂的實相界。這指的就是法身佛本性所具的清淨戒律，一切功德圓滿具足，真是達到了至高無上的境地啊！雖然如此，境界之風猛烈吹拂，心靈之海掀起巨浪，心念隨著外緣流轉遷變，追逐塵世境界而生起執著，終於使眾生淪落為披毛戴角之流，遭受無窮無盡的劇烈痛苦。懷抱著這顆自性明珠，卻在六道之中孤獨顛沛，受盡辛勞困乏，實在令人深感悲痛！我們大雄釋迦世尊在天竺降生顯現，其久遠本跡實在渺茫難測。在常寂光土證悟大道，隨緣垂投影跡於眾生的心靈國土。於是在寂滅道場中，最初制定菩薩大戒，依稱法性的本體來斷惡修善，隨順真如的妙用而神妙感應無方。體與用出自同一源頭，幽微與顯著暗中融通，這就稱為菩薩的三聚淨戒，涵蓋了萬種修行。唉，多麼偉大啊！然而眾生的人性參差不齊，所稟賦的氣質根機各不相同，又怎能普遍承擔菩薩的廣大行業呢？
