# 校閱材料　第158檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【158-0001】02_戒疏/02a_卷一上之二#60
【原文】【記】初明理寶，文出《多論》。「五分」者，戒、定、慧，從因受名，解脫、解脫知見，從果彰號。由慧斷惑，惑無之處，名解脫。出纏破障，反照觀心，名解脫知見。「滅理」，四諦、滅諦、涅槃。「學、無學」者，初果已去，同見真諦，名理和僧。然此理寶，亦即同體，但望佛、僧證理邊為別。故《多論》云：「佛亦是法，法亦是佛，僧亦是法。止是一法，相有差別，故分三寶。」
【譯文】【記文】首先說明理體三寶，經文出自《薩婆多論》。「五分」法身，戒、定、慧是從修行的因位而獲得名稱，解脫與解脫知見則是從證悟的果位而彰顯名號。由於智慧能斷除煩惱惑業，煩惱不復存在之處，就稱為解脫。跳脫纏縛、破除障礙，迴光反照審觀自心體性，就稱為解脫知見。「滅理」，是指苦、集、滅、道四聖諦中的滅諦涅槃。「學、無學」，是指從初果須陀洹以上，同修共見真空真諦之理，稱為理和同體僧。然而這種理體三寶，本質上也即是同體三寶，只是對照佛陀與僧伽證悟真理的角度而有所區別。所以《薩婆多論》說：「佛也就是法，法也就是佛，僧也就是法。其實只是一個法體（同一法性），由於顯現的相狀有所差別，因此劃分為三寶。」

【158-0002】02_戒疏/02a_卷一上之二#61
【原文】【記】化相中。「三千」者，所化之境。「諦教」即四諦，法門雖多，而以首者言之。又四諦統攝凡聖因果，大小教門，廣略異宜，無出此四。「拘鄰」此云「本際」，即鹿苑中初度五人：首曰拘隣，即憍陳如也，二曰頞陛，三曰䟦提，四曰十力迦葉，五曰摩訶拘利。
【譯文】【記文】在化相三寶之中。「三千」是指佛陀所教化化導的依報國土世界。「諦教」就是指四聖諦，佛門教法雖然浩瀚無量，但以四諦作為一切教法的首領與核心。此外，四聖諦總括統攝了一切凡夫與聖人的前因後果，一切大乘與小乘的教門，無論廣說或略說隨機設教，都超不出這四諦的範圍。「拘鄰」在此方翻譯為「本際」，就是指佛在鹿野苑中最初度化的五位比丘：第一位是拘隣，就是憍陳如；第二位是頞陛；第三位是䟦提；第四位是十力迦葉；第五位是摩訶拘利。

【158-0007】02_戒疏/02a_卷一上之二#66
【原文】【疏】四種之中，初「理」為本，餘三從相，故為末也。如毀佛出血，據相無罪，化佛無心，非情無惱也；以損法身所依，故結重逆。法僧損益，本末例然。故《大集》云「若打破戒、無戒比丘，罪重出萬億佛身血」者，豈不以形服出世，為聖道標，若加輕毀，則三寶通壞故也。
【譯文】【疏文】在這四種三寶之中，最初的「理體」是根本，其餘三種都是從外相而衍生顯現的，所以是枝末。例如毀壞佛身導致出血，單純就外在色相而言原本無罪，因為應化佛身沒有凡夫血肉的心識，無情之物受損不會產生惱害；然而因為損壞了無漏法身所依託的器質，所以結成最重的逆罪。法寶與僧寶的受損與增益，本末的道理也是如此。因此《大集經》說「如果毆打破戒、無戒的比丘，其罪更重於使萬億尊佛的身軀出血」，這難道不是因為其形相與法服代表了超脫世俗的表徵，作為出世聖道的標誌旗幟，如果對其施加輕賤侮辱，那麼就等於將整個三寶的尊嚴全都毀壞殆盡的緣故嗎？

【158-0008】02_戒疏/02a_卷一上之二#67
【原文】【記】總明中。初正示。「如」下，舉事以顯，先明佛寶。此明化相，以理為本，化相應身，故云「化佛」。《多論》：「問：『何以出色身血，得逆罪耶？』答：『以色身是法身器故，法身所依故。』」、「法」下，例餘二寶。如破法輪，正望真諦無證入故；如殺羅漢，亦望證理，福田極故。是則化相，皆望理寶以論罪福。「故」下，別證僧寶，即約住持以證化相。初引經文，破戒無戒，打業極重，故知不取儀相論僧。「豈」下，推經意。「形服」是住持僧。「聖道」即理寶僧。住持佛、法，由僧弘顯，是故毀僧則兼佛、法，故云「通壞」。又《智論》云：如泥銅等，體是無記，非感罪福，以成法身相，隨前敬慢有罪福也。一體在迷，迷從理起，悟還復理，本末可知。
【譯文】【記文】在總體說明的科判中。首先正面提示。「如」字以下，列舉具體事例來顯明，先說明佛寶。這是指化相三寶是依據理體為根本，化現的應身，所以稱為「化佛」。《薩婆多論》：「提問：『為什麼使佛陀的色身出血，會獲致無間重逆的大罪呢？』回答：『因為色身是法身的器皿寄託，是法身所依持顯現之處的緣故。』」「法」字以下，比照其餘兩種寶。例如破壞轉正法輪，主要是因為它障礙了眾生證入真諦的可能；又如殺害阿羅漢，也是因為阿羅漢已徹證真理，作為最極致的福田。由此可知化相三寶，都是以理體三寶為根本基準來評斷罪過與福報的。「故」字以下，特地用引證來確立僧寶，也就是透過住持僧寶來佐證化相僧寶的道理。首先引用佛經原文，指出毆打即便破戒或無戒的僧人，其惡業罪報都極為沉重，由此可知並非單取外在形相來論斷僧寶（而是因其標示理寶聖道）。「豈」字以下，推敲經文深義。「形服」代表的是世間住持僧。「聖道」代表的則是理體聖僧。住持世間的佛寶與法寶，全賴僧寶加以弘揚顯發，因此毀損僧寶就連帶損害了佛與法，所以說「通通毀壞」。又《大智度論》說：例如泥塑銅鑄的佛像，本身實質是無知無記的材質，原本不會招感罪障或福德，但因為它成就了法身莊嚴之相，隨著瞻仰者內心的敬奉或怠慢輕視，而分別獲得福報或招致罪衍。一體自性三寶在迷妄之時，迷妄也是依託理體而生起，一旦覺悟又回歸理體本源，本末的層次自然清楚可知。

【158-0011】02_戒疏/02a_卷一上之二#70
【原文】【疏】答：「諸家都隱，今試舉之。此由常懷，何得不識？且如住持三寶，圖寫佛形，峙然端拱，為佛寶之本也；自餘賢聖、八部周列，為佛寶之末也。故殿宇廊廟，神鬼禽獸，斯非寶尚，何得福生？但是莊嚴至聖，同崇尊德，所以若作若損，皆望本緣。法、僧住持，非無本末，例上說也。」
【譯文】【疏文】回答：「歷來各家論師都隱蔽不談，現在嘗試提出說明。這本來就是心中常應思維之理，怎麼能不明白認識？例如住持三寶之中，繪製雕塑佛陀的形像，巍然端正安坐拱手，這是住持佛寶的根本；至於圍繞羅列在旁的諸賢聖僧、天龍八部等，則是住持佛寶的枝末。所以宮殿、寺宇、廊廡、廟堂，以及護法神鬼、雕飾禽獸，這些本非至高之寶，敬奉它們又何以能產生功德福分？只不過是用來莊嚴至高無上的聖境，共同尊奉崇仰至尊的德行，所以無論是造作供養還是加以毀壞，其罪福全都歸屬於根本的主體因緣。法寶與僧寶在住持位階中，也不是沒有本末之分，完全可以比照上面所述來推論。」

【158-0022】02_戒疏/02a_卷一上之二#81
【原文】【疏】二、明化相，佛先、法次、僧後者。以釋迦初證，唯佛獨尊，非尊不可在初，故為首也。大聖雖現，止得動其耳目，至於煩惑，要假法除，次演聲教，用滌心惱。教之所及，行是所歸，雖說無證，還同不說，故拘鄰會正，方僧寶現。此則化儀次第，不可乖也。
【譯文】【疏文】第二、說明化相三寶中，佛寶在先、法寶次之、僧寶在後的理由。這是因為釋迦牟尼佛最初成道證悟之時，全宇宙唯有佛一人最為獨尊，非至尊者不可位居初始，所以立為首位。大聖佛陀雖然示現於世間，但如果只是端坐世間，頂多只能震撼引動眾生的耳目聽聞，至於眾生內在幽深的煩惱惑業，必定要憑藉法寶才能斷除，所以緊接著演說音聲言教，用以洗滌眾生心中的塵勞熱惱。然而言教的化導力量所至，實踐行持才是歸宿，如果光有說法而沒有人起行證得，那就如同沒有說法一樣，直到拘鄰會入正道，此時僧寶才正式顯現。這就是化相示現教儀的先後秩序，是絕對不能混淆違背的。

【158-0026】02_戒疏/02a_卷一上之二#85
【原文】【疏】四、一體者，法先、僧次、佛後。體是心體，本來無染；妄覆迷倒，故興邪正。今了法本，理實無三；隨相用分，一方行化。故照理邊，即為「覺」義；體離名言，即「法」義；至理無滯，「和合僧」義。非法不知，故須在初；非佛不曉，故後說也；僧居中者，體未純淨，如雜血乳，分有所遣，豈喻醍醐？故不同佛也。
【譯文】【疏文】第四、一體自性三寶之中，法寶居初、僧寶次之、佛寶在後。其本體就是眾生現前的一念心體，本來清淨毫無染著；只是被妄想覆蓋、顛倒迷妄，所以才生起種種邪道與正法的分別。如今徹底了悟心法本源，在究極真理上本無三寶的差別；只不過是隨順外相功用而作劃分，用以在世間化導眾生。所以自心照見真理的能觀智慧，就是「覺悟（佛）」的意涵；心體本自寂滅、脫離一切名言思維，就是「法則（法）」的意涵；自性至理通融圓融、毫無滯礙隔閡，就是「和合僧」的意涵。如果沒有透澈的心法本體，根本無從生起覺悟，所以法寶必須居於最初；而若非徹底成佛就無法究竟圓滿通曉此法，所以佛寶排列在最後；僧寶居於中間，是因為修行者自體尚未達到純粹至極的究竟清淨，就像參雜了血液的牛奶，在斷惑層次上仍有所殘留與逐步除遣，哪裡能夠比喻為純熟的醍醐？所以其境界不能等同於究竟佛果。
