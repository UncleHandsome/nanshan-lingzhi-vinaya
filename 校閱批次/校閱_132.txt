# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【132-0014】02_戒疏/05d_卷二上之一#133
【原文】【記】滅惡中。初釋難調，引《論》顯相。文列三句，上句身口業，下二句意業。三業不善，則名「難調」。「佛」下，顯益。七、九治罸，隨犯治之。文中略舉「呵責」，餘可準知。次釋慚愧，謂惡者折辱，善人無惱故。文舉「說、恣」，由此二法，必取行淨；若羯磨僧，則通持毀。三、釋「現漏」。言「不覆」者，「覆」猶護也。遭打橫死，惡疾迍難，皆為現報。四、斷未漏。「生業無窮」者，此通生、後二報。「盡形行學」者，且約上篇犯重為言。餘篇悔法，俱障來報，義可知也。
【譯文】【記文】在滅除惡業的科判中：首先解釋「難調伏」，引用《善見論》彰顯行相。文中列出三句話，第一句是身業與口業，後兩句是意業；三業皆不善，就稱為「難調伏」。自「佛」字以下說明利益，七羯磨與九種制罰，隨順所犯予以制裁；文中只是簡略舉出「呵責」，其餘懲罰皆可比照了知。其次解釋「慚愧」，是指惡人受到折服羞辱，善人便不再受到惱害擾亂；文中舉出「說戒」與「自恣」，是因為這兩種僧事作法必須要求持行徹底清淨，若是一般的羯磨集會，則通於持戒者與毀戒者共同參與。第三解釋「現漏」，所謂「不覆」，「覆」是防護隱藏的意思；遭受毒打、橫死暴斃、惡病纏身、困厄災難，全都屬於現世的惡報。第四解釋「斷未漏」，「受生之業無窮無盡」，這通於來生受報與後世受報兩種果報；「盡形壽依律修學」，暫且是依據初篇犯根本重罪的角度來立論，其餘各篇的懺悔法門，全都能夠阻絕未來的果報，箇中道理自然可知。

【132-0015】02_戒疏/05d_卷二上之一#134

【132-0017】02_戒疏/05d_卷二上之一#136
【原文】【記】釋興建中，引《善見》三相。第一約教，非學不解；第二是行，非信不行。是以前二首標「學」、「信」。第三約果，則明教行，功不虗設。
【譯文】【記文】在解釋「興建正法」的科判中，引用了《善見律》的三種行相：第一項是著眼於教法，若不修學就無法理解；第二項是著眼於行持，若無信仰就無法實踐；因此前兩項一開始就標示「學」與「信」。第三項是著眼於證果，由此彰顯出教法與行持的功德絕非虛妄設立。

【132-0018】02_戒疏/05d_卷二上之一#137
【原文】【疏】就此三相，前後為言，初教次行，後明果也。人多讀教，少有依行，以無信故。如《大論》云「信為道源功德母」也。若無信者，雖入佛法，都無所益，以不依行，無所得故。若依教修，必剋聖果。即是制戒，功德道興，誠不虗設也。
【譯文】【疏文】針對這三種行相的前後順序來說：最初是教法，其次是實踐，最後才說明證果。世人多半只會讀誦教典，很少有人能夠依教奉行，這是因為內心缺乏真切信心的緣故。如同《大智度論》所說：「信為道源功德母」。如果沒有信心，即使進入了佛門，也完全得不到任何真實利益，因為不肯依教起行，便什麼都無法證得。如果能依循教誨精進修持，必定能剋期證得聖果。這正是由於制定了戒律，廣大功德與無上聖道才得以興盛，這項制戒的恩澤確實是絕非虛設的。

【132-0019】02_戒疏/05d_卷二上之一#138
【原文】【記】明次第中。初、正指次第。「人多」下，釋其所以。初句明教。「少」下，示行。「《大論》」，即《智論》。聖道從始，故喻如「源」。眾善由生，故同於「母」。「若」下，明果。三法相須，一不可闕。今時學教，唯事講說，身履非惡，略無慚愧。請詳祖訓，少警內懷。不爾，則妄認祖宗，實非苗裔矣。
【譯文】【記文】在闡明次第的科判中：首先正面指出先後的次序。自「人多」以下，解釋其中的緣由：第一句說明教法；自「少」以下揭示行持。「《大論》」就是指《大智度論》，聖道由信心開啟肇始，所以比喻為「源」；一切善法由信心滋養生發，所以比喻為「母」。自「若」以下說明證果。教、行、果三法相互依存，缺一不可。如今這個時代研習教理的人，往往一味忙於講經說法，自身行為卻深陷非理惡行之中，內心毫無慚愧之色。請大家務必詳加體察祖師的誡訓，多在自心深處自我警惕警省；若不這樣做，那就是盲目攀附認同祖師宗風，實質上根本算不上是祖師門下的真正傳人！

【132-0022】02_戒疏/06a_卷二上之二#3
【原文】【疏】言「釋名」者。何謂戒本？由犯制戒，戒為緣本也。又約緣雖制，文略未顯，更以辨相，廣張行體，略為廣本。又云，即是半月說之所本，所以文云「欲說戒者，當如是說」。餘同前卷。
【譯文】【疏文】談到「解釋名稱」：什麼叫做「戒本」？因為有人犯錯才制定戒律，所以戒律是一切因緣與戒條的根本。又從因緣制定的戒文雖然簡略尚未明顯，進一步藉此辨明罪相、廣泛鋪展修行的實體，這簡略的戒文就是廣泛行相的根本。又有一種說法，戒本就是每半個月誦戒時所依據的根本文本，所以經文說「想要說戒的人，應當這樣說」。其餘的涵義與前一卷相同。

【132-0023】02_戒疏/06a_卷二上之二#4
【原文】【記】釋名中。初標問，「由」下，釋通，有三。初、約緣起釋，「又」下，次、約廣解釋。《律》敘緣起，發後制戒，後列廣相，釋前戒文。故約前、後，以彰「本」義。即前五義中，「教本」一義。「又云」下，三、約說戒釋。欲近取證，故重舉耳。道、行、聽三，前已廣，故略指之。
【譯文】【記文】在解釋名稱的段落中。一開始標出問題，「由犯制戒」以下共有三種解釋來貫通：第一、從緣起角度解釋；「又」字以下，第二、從簡略與廣泛角度解釋。《律藏》敘述犯戒的緣起，才引發後續制定戒律，後續列出廣泛的犯相，用來解釋前面的戒文。因此依據前與後的關係，來彰顯「本」的意義。這就是前面五種涵義中的「教本」這一層意思。「又云」以下，第三、從每半月說戒的角度解釋。這是為了就近取得經文為證，所以再次提出罷了。至於「道」、「行」、「聽」這三種涵義，前面已經廣泛論述，所以在此簡略帶過。
