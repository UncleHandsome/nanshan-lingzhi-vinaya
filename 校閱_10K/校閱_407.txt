# 校閱材料　第407檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【407-0010】02_戒疏/04b_卷一下之二#43
【原文】【疏】答：「此由境差，方便罪也。由非人來，人想不捨，殺張心成，而境乖異，望張方便。望非人邊，本無罪也。具足五緣殺非人者，但偷蘭遮，如何其因已是方便？義不然也。」
【譯文】【疏文】答：「這是由於境界差錯所產生的方便罪。因為非人前來，殺人的心想並未捨棄，殺害張三的心意已經具備，但面對的境界卻相違背，相對於張三而言是方便罪。相對於非人這邊，原本是沒有罪的。具備五種條件殺害非人，也只犯偷蘭遮罪，怎能說殺它的起因階段就已經結為方便偷蘭遮呢？這樣的道理是說不通的。」

【407-0011】02_戒疏/04b_卷一下之二#44
【原文】【記】他師釋中，初科。上二句定罪，「由」下，釋所以。彼謂《律》結蘭罪，還從本境，不望非人。「具」下，引殺非人罪，質成上義。「五緣」者：一是非人，二非人想，三有殺心，四興方便，五命斷。「如何」等者，以非人作人想，在人為境差，望非人為想差，故是殺非人「因」也。謂果罪但蘭，豈得因罪即結方便蘭耶？以非人方便但吉羅，故「方便」字合作「偷蘭」。此明《律》結蘭罪，不望非人，斥他異解，故云「不然」也。
【譯文】【記文】他宗律師的解釋中，此為初科。前兩句判定罪名，「由」字以下，解釋其緣由。彼方認為《律》文判定為偷蘭遮罪，依然是從原本的對象張三來定罪，並非針對非人。「具」字以下，引用殺非人的罪名，質對證成上述義理。「五緣」是：一是非人，二是非人想，三有殺心，四起方便，五斷其命。「如何」等語，是因為把非人當作人，就人而言是境差，就非人而言是想差，所以這是殺非人的「起因」。意思說殺害非人究竟成果也只是偷蘭遮，豈能因位方便就判定為方便偷蘭遮呢？因為非人的方便罪只是突吉羅，所以文中的「方便」字應作「偷蘭」。這是在說明《律》文判定偷蘭遮罪並非針對非人，以此駁斥他人的異解，所以說「不然」。

【407-0012】02_戒疏/04b_卷一下之二#45
【原文】【疏】有人言：「上立異境，想疑心中，想則決徹，人差結重，餘則無心，但屬本境。疑則不爾，緣兩境生，故就兩境雙結二罪。」
【譯文】【疏文】有人主張：「上面所立的異境，在誤想與疑惑的心態中，誤想則是決定明了的，若替代境界是人便結重罪，其餘三種境則無殺心，罪責只屬於原本的對象。若是疑惑之心則不如此，因為疑惑是攀緣兩個境界而生起的，所以應當對著兩個境界同時結出兩種罪。」

【407-0013】02_戒疏/04b_卷一下之二#46
【原文】【記】斥疑心中，初文。彼謂想心同上，疑心不同，以未決徹，本異二境，並有心故。云「二罪」者，本境方便蘭；人異境是夷，餘三異境，並疑心蘭。
【譯文】【記文】在駁斥疑心論調之中，此為初文。彼方認為誤想之心如同前述，疑心則不同，因為尚未明確斷定，對於原本與替代兩個對象，都存在著疑惑關照的心念。所說的「二罪」，是指對本境結方便偷蘭遮；若異境是人則結波羅夷，其餘三種異境則皆依疑心結偷蘭遮。

【407-0014】02_戒疏/04b_卷一下之二#47
【原文】【疏】今解不然，但列本境。縱使四異來差本境，若強若疑，皆列本境。何以明之？畜是小愆，杌非生罪，如何來差，俱犯偷蘭？豈不望人從本境結？
【譯文】【疏文】如今的解釋並非如此，律文僅僅列出本境。縱使有四種替代境界前來差錯本境，無論是境強或是生疑，全都在本境上論列。用什麼來證明這點？畜生本是招致小罪的境，枯木根本不能產生罪過，它們前來差錯時，怎麼會全都犯下偷蘭遮？難道不是相對於人、順著本境來結罪嗎？

【407-0015】02_戒疏/04b_卷一下之二#48
【原文】【記】次科。還即古義，對破前解，故云「今」耳。下云「今明正解」，始是今義。文中，初判定。云「但列」者，即指《律》文境想句中。「何」下，徵釋。且舉畜、杌難破前義。據此破詞，則知前解異境皆蘭。
【譯文】【記文】第二科。這裡仍是承襲古義來駁斥前一種見解，所以才說「今」。下文說到「今明正解」，才是此處真正的主張。文中最初做出判定。所謂「但列」，就是指《律》文境想句法之中。「何」字以下，徵問並解釋。暫且舉出畜生與枯木來駁難前者的主張。根據這段駁詞，便可知前一種解釋將所有異境都結偷蘭遮。

【407-0018】02_戒疏/04b_卷一下之二#51
【原文】【記】三、問中。據上已明強從本境，更欲別示，故問所屬。答中。「強」是異境，「想」緣本境，故云「強想」。「如」下，例通。據此立義，不問疑想，異境之上，永無罪也。
【譯文】【記文】第三，提問中。根據前文已經說明境強是從本境結罪，此處想進一步明確指示，所以詢問歸屬。回答中，「強」是異境強，「想」是執著本境，所以稱作「強想」。「如」字以下，通盤類推。按照這種立論，不論是疑或想，在異境之上永遠不構成犯罪。
