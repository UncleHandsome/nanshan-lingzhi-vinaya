# 校閱材料　第1272檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1272-0001】資持記/13b_下一#11
【原文】法滅之相，果現於茲矣。捨法中。注準《僧祇》者，《十誦》缺文故。《注羯磨》云：一說便止。所以前受不取《僧祇》者。以加受為持，持護既別，故須取類。捨是棄背，彼此無乖，隨用通得。一時受捨者，謂三衣一併加也。但得小罪，理應法成。尼法，初科又二，初總示。十下，列法。
【譯文】正法滅亡的徵兆，果然在此刻顯現出來了。在捨法當中，夾註說明準照《僧祇律》者，是因為《十誦律》缺漏了這段文字。《注羯磨》說：只要說一遍就告成立。之所以在前面受持時不採用《僧祇律》，是因為加受是為了持守，各部律對持護的規範既然不同，所以必須選用同類的律文；而捨棄則是放棄防護，彼此的理路並無違背，隨選哪一部律通用都可以。所謂「一時受捨」，是指將三衣一併加持受持。雖然會結得輕微的小罪，但在道理上羯磨法事依然是成就的。在尼法中，第一科又分兩節，開頭先總體指示。從「十」字以下，依序列出法式。

【1272-0002】資持記/13b_下一#12
【原文】厥修羅，即《四分》僧祇支，故云國語不同。《經音義》翻為掩腋衣，謂覆左腋著帶繫右腋下，長七尺二，廣四尺五。次加覆肩，文略初二句，例上加之。注中以上二法，並牒肘量，當時製造多乖本式，故須改張，則事法相稱；
【譯文】厥修羅，就是《四分律》所稱的「僧祇支」，所以說各國的語言有所不同。《經音義》將它翻譯為「掩腋衣」，是指覆蓋左邊腋下、附帶繫帶綁在右邊腋下，長度為七尺二寸，寬度為四尺五寸。接著加持覆肩衣，文中省略了前兩句，比照前面的通例補上即可。夾註中指出，以上兩種作法都提到了以肘量為準，當時的製造多半違背了原有的法式，所以必須加以改革調整，才能使名實相符；

【1272-0003】資持記/13b_下一#13
【原文】故《業疏》云：尼受二衣，覆肩肘量，薄有所承；祇支全改，文雖約量，漸訛變也。準《羯磨》改云：大姉一心念！我比丘尼某甲，此僧祇支如法作，我受持。〔覆肩同此。〕問：此是尼衣，僧開畜不？答：準尼戒中，尼離五衣俱提。僧離二衣犯吉，明知得作百一受持。但尼是制物，僧入聽衣。
【譯文】因此《業疏》說：比丘尼受持這兩件衣，覆肩衣的肘量尚且稍微有一點承傳的依據；僧祇支則完全被改樣了，雖然文句上限定了尺寸，實際上卻漸漸訛誤變形了。依照《羯磨》應當改為：「大姊一心念！我比丘尼某甲，這件僧祇支如法縫製，我現在受持它。」（覆肩衣也比照這個格式。）有人問：這是比丘尼的衣服，比丘開許蓄積嗎？回答：依照尼戒的規定，比丘尼離開五衣都要結波逸提罪；比丘離開這兩件衣只犯突吉羅，由此明白可知比丘可以將它們作為百一物來受持。只是比丘尼屬於規定必須具備之物，比丘則是列入聽許蓄積的衣物之中。

【1272-0004】資持記/13b_下一#14
【原文】問：僧得著否？答：準《住法圖贊》，阿難容質姝好，女見生愛，故獨聽之。古來僧徒，亦多著者，故《圖贊》斥云：今時僥倖而妄服者濫矣，是也。問：今僧為可著不？答：雖有此斥，而不全廢。然西土袒露為禮，此方服飾成儀。若據方土所尚，不可不著。問：若爾，今學律者，何以不著？
【譯文】有人問：比丘可以穿著嗎？回答：依照《住法圖贊》，阿難尊者相貌秀麗美好，女子見到容易生起愛欲之心，所以佛陀唯獨聽許他穿著。自古以來的僧眾，也有很多人穿著，所以《圖贊》斥責說：「現今心存僥倖而胡亂穿著的人，實在是太混亂了」，說的就是這種情況。有人問：現在的僧人究竟可不可以穿著呢？回答：雖然有這種斥責，但也沒有完全廢除。然而西方印度是以袒露肩膀為禮節，東土此地則以整齊服飾作為威儀。如果依照當地的風尚習慣，就不可以不穿著。有人問：若是這樣，現今學習律宗的人，為什麼不穿著呢？

【1272-0005】資持記/13b_下一#15
【原文】答：是人皆著，敦云不著。但世人不識褊衫，即是祇支覆肩二物，故復於其上重更覆耳；當知褊衫右邊，即是覆肩；但順此方，縫合兩袖，截領開裾，猶存本相，豈不然耶。今有堅執重著者。應須問曰：覆肩本為露膞，故令覆之；子今內有衫襖，上有褊衫，有何露處，苦欲更覆。
【譯文】回答：大家都在穿著，是誰說不穿的呢？只是世人不明白「褊衫」其實就是由僧祇支與覆肩衣這兩樣東西合演而成的，所以又在褊衫之上重複披覆而已；應當知道褊衫的右半邊，就是原來的覆肩衣；只是順應此地的風俗，將兩隻袖子縫合，剪裁衣領並開叉下襬，卻依然保留著原本的形貌，難道不是這樣嗎？如今有人固執己見非要重複穿著覆肩衣，就應當質問他：「覆肩衣本來是為了遮掩袒露的肩膀，所以才令其覆蓋；你如今裡面有內衫夾襖，外面有褊衫，還有哪裡是裸露的，非要苦苦去重複覆蓋？」

【1272-0006】資持記/13b_下一#16
【原文】有云著之生善者。若爾，是僧須著，何獨新戒！聽律之人，則須生善。餘宗不著，應生不善。況輕紗紫染，儀相囂浮；人興流俗之譏，教有婬女之責；塵翳釋門，何善之有！又云：律學須著，要分宗途者。且同稱釋氏，稟佛為師；三學齊修，威儀一制。機緣徵薄，不可通弘；
【譯文】有人說穿上它能夠生起善心。如果是這樣，只要是僧人都應當穿著，何必唯獨限於剛受新戒的人！聽聞律法的人固然必須生起善心，那麼其餘宗派不穿著的人，難道就該生起不善嗎？何況輕薄的輕紗染成紫色，儀態相貌顯得浮躁奢華；世人因此生起流俗的譏諷，教法中也有如同婬女般的責難；這只會染污障蔽釋迦法門，哪裡談得上什麼善法！又有人說：學習律法的人必須穿著，這是為了劃分宗派的門庭。然而大家同樣稱為釋迦弟子，稟承佛陀為師尊；戒定慧三學齊整修習，威儀風範依照統一的制度。眾生的根機淺薄，無法普遍弘揚通融；

【1272-0007】資持記/13b_下一#17
【原文】是故三藏分宗，三師競化。而云服飾標異，未之前聞。但由不學愚癡，任情妄述。聞義不徙，斯妄何窮。顯部別中，《僧祇》，初明制畜不同。若準今宗，不畜二衣俱提。尼下，示祇支制量。彼律一磔長二尺四，則計九尺六，廣四尺八。與前頗異。尼下，總列五衣。同別可見。心念中，《五分》，初示緣。
【譯文】所以三藏教法才分立宗門，各派祖師競相教化。而如果說要靠服飾來標新立異，這可是從未聽聞的事。這全都是由於不加研習而愚昧無知，任憑個人情執胡亂撰說所致。聽到了正理卻不肯歸向改正，這種妄執何時才有窮盡！在「顯示各部派差異」的章節中，《僧祇律》開頭先說明規定蓄積的要求不同。若依照本宗《四分律》，不蓄積這兩件衣都要結波逸提罪。從「尼」字以下，指出僧祇支的規定尺寸。彼律規定一磔手長二尺四寸，那麼折算下來就是長九尺六寸，寬四尺八寸，這與前面所說的大為不同。從「尼」字以下，總體列出五衣的名稱，相同與相異之處自然顯而易見。在「心念受法」中，《五分律》開頭先說明因緣。

【1272-0008】資持記/13b_下一#18
【原文】言獨住者，不問村野，但據無人。疏云：但界無人，即開心念；雖有非數，豈得對首。應下，出法，初示捨法。三說者，且依彼文。準《注羯磨》，亦同一說。然下，次出受法。雜料簡，初門，借衣中。不得捨者，非畜積故。次科。先三衣說淨者，後衣法成，前衣自失，即入淨故。不捨吉者，違制罪也。
【譯文】所謂「獨自居住」，不論是在村莊還是荒野，只要是沒有同伴僧人即可。律疏說：只要界內沒有人，就可以開許用心念法受持；雖然有人卻不具備出家人之數，又怎能進行對面授受呢？從「應」字以下，列出具體行法，開頭先指示捨衣法。說三遍的做法，暫且是依照彼律的文字；若依照《注羯磨》，也同樣只要說一遍即可。從「然」字以下，接著列出受持法。在「雜項辨析」的第一門「借衣」中，不能捨棄的原因，是因為它不屬於自己蓄積之物的緣故。在下一科中，若先將原有的三衣做說淨，則後面的衣法受持成就時，前面的衣自然失法，隨即歸入說淨物中；若不作捨衣而直接受持，犯突吉羅，這是違犯制度的過失。
