整體讀來通順，科判（初科／次科／某某下）的處理方式也一致。但有**幾個律學專名被譯錯**，屬於會誤導讀者的硬傷，另外有一些用詞不夠精確。以下按輕重分列。

---

## 一、必須改的錯誤

### 1.「重物／輕物」誤譯（#2、#5）— 最嚴重
- #2「持**重物**與餘寺」→ 譯作「將**貴重物品**送給其他寺院」
- #5「斷**重**歸**輕**，夷；斷**輕**歸**重**，蘭」→ 譯作「判定**重大財物**歸於輕物……**輕微財物**……」

律中「重物／輕物」不是價錢高低或重要與否，而是**可否分割**：
- **重物**＝不可分的常住物（房舍、田園、床褥、廚庫、僕畜等），永歸四方僧；
- **輕物**＝可分物（衣缽、藥品等），可分給現前僧。

所以「斷重歸輕」是把該歸常住的重物判成可分的輕物而分掉了 → 盜常住物，滿五錢成**夷**；「斷輕歸重」是把該分的輕物判歸常住，令現前僧不得分 → **蘭**。譯成「重大／輕微財物」，整段的判罪邏輯就講不通了。

建議：「把重物（不可分的常住物）判歸輕物（可分物）而分掉，犯波羅夷；把輕物判歸重物，犯偷蘭遮。」#2 則作「把（本寺的）重物送給其他寺院」。

### 2.「西竺」≠西印度（#5）
「西竺」是相對於中國而言的「西方天竺」，即**印度**，不是「西印度」。應譯「在印度（西土天竺），三寶各自設有無盡財」。

### 3.「別人貸」≠他人借貸（#6）
「別人」是律中專名，指**個人**，與「僧眾／眾僧」相對（如「別人食」「別人受用」）。此處是「僧貸」之後的「**個人**借貸（三寶物）」。譯成「他人借貸」會失去僧／別的對照。

### 4.「在文可見」的「文」不是經文（#1）
《資持記》是解釋《行事鈔》的，書中單說「文」幾乎都指**鈔文**。譯成「在經文中清晰可見」不對，應作「在鈔文中可以看出」。

### 5.「決通」不是「通融」（#3）
「下準文決通」＝下文依（經律之）文**決疑會通**。「通融」在現代漢語是「破例遷就」，意思正好走樣。建議：「下文依文決疑會通」。

### 6.「更互／各自論」不是「論斷」（#4）
「或二種更互，或各自論」講的是**互用（挪轉使用）**：或兩種現前物互相轉用，或各自內部互用。譯成「交互論斷／單獨論斷」變成在討論判罪，錯了。同段末「十方現前自論互」譯成「自身的相互論轉」也生硬，宜作「十方現前物自身內部的互用」。

### 7.「不學無知」是罪相名（#5）
〔有云：不學無知，非也〕是元照破斥他人：有人主張這裡兼結「**不學罪、無知罪**」（兩種突吉羅）。譯成「有人說是無知未學」既顛倒詞序，也變成泛泛的「沒學問」。建議：「有人說是兼犯不學、無知二罪，這是不對的。」

### 8.「受」應是「受用」，非「接受布施」（#3、#4）
「若許賣者，必應開受；既不合受，驗不可賣」——論證是「若可賣，理應先開許受用；連受用都不許，何況變賣」，下文《五百問》「得**受使用**，不得賣」正是同一組對照。譯成「接受布施」「不合規定去接納」偏了，應統一作「受用」。

## 二、用語可再精確

| 出處 | 現譯 | 建議 |
|---|---|---|
| #1 | 常住物與現前物等四個範圍 | 明列四位：常住常住、十方常住、現前現前、十方現前（並註明「四方常住」即常住常住、「十方常住」即供僧常食） |
| #1 | 起初說明**個別受用** | 「別用」是說**二位各別的用途**，非個人受用；下句「二位用別」正是註腳 |
| #1 | 《善見論》 | 可補全名《善見律毘婆沙》 |
| #2 | 就是指同類互用之中 | 保留專名：「屬於『當分互』（三寶各自同分內的互用）」 |
| #2 | 減省園林果實 | 「減園果」宜作「挪用（減取）園中果實充作僧食」，語意較清楚 |
| #3 | 僧事作法不同而伙食相同 | 「法別食同」直譯太籠統，宜加註（各處作法有別而僧食相通），並再核原文所指 |
| #3 | 所以才說「可不可以」 | 應點明是鈔文「得不（否）」的設問：「所以鈔文以『得不（能否互用）』作結」 |
| #3 | 選取義理 | 「取義」＝依義理推判 |
| #3、#6 | 「第三點」「第二點」 | 與他處「初科／次科」不一致，建議一律用「科」 |
| #4 | 亡僧遺留的物品 | 「亡物」通指**亡五眾**（比丘、比丘尼、式叉、沙彌、沙彌尼）遺物 |
| #4 | 罪名如同前面所述 | 「罪如上」宜作「結罪輕重同上」 |
| #5 | 宣讀帳目通告僧眾 | 「歷帳」有逐項之意：「依帳簿逐條宣讀，告白大眾」 |
| #6 | 永久留存供養，滋生利潤取之不盡 | 「（本金）常存以供養三寶，（利息）滋生不竭」，主客分明 |
| #6 | 兩處文獻都予以允許 | 「兩段律文都開許」 |

## 三、語氣與行文中可斟酌處

1. **#1「地獄罪人，何可語也」**：現譯「哪裡值得對他多說」偏輕。原意近於「（這種人）簡直是地獄罪人，還有什麼好說的呢！」——是無可奈何的痛斥。
2. **#1「不超出……四個範圍所統攝」**：「不超出」與「所統攝」語意重複，改「不外乎常住、現前四位所攝」即可。
3. **#3「唯明四方常住」**：「唯」是「只就……而言」，非「專門闡明」，語氣略有出入。
4. **#5「券即契書」**：可作「券就是借貸的契約文書」，比「借契文書」自然。
5. **#6「彼經云」**：宜作「上文所引的那部經說」，並補出經名（此處所引應即前文出處，建議回查確定）。
6. **#6「畜出家弟子」**：「蓄養」略帶貶義，宜作「收蓄（攝受）出家弟子」。

## 四、譯得好的地方

- 「時／非時」依日中前後判、「非法用者，主掌過也」歸責知事，準確。
- 「以錢出利，如母生子，故名息」的比喻保留完整，很好（可加註「息即子息，引申為利息」）。
- 「賣房治房」「施佛牛奴，得受使用，不得賣」「病者尚須倍還，況不病者」等，理解無誤。
- 「和僧則開，不和則閉」「雙結」「讀疏」等處理方向都對。

**總結**：優先修訂「重物／輕物」「別人」「西竺」「不學無知」四個專名，以及「文＝鈔文」「決通＝會通」「更互＝互用」「受＝受用」四處語意，其餘屬潤色。
