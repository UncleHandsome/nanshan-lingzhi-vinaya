# 校閱材料　第1559檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1559-0001】03_業疏/01a_卷一之一#4
【原文】原夫大雄御㝢，豈惟拯拔一人；大教膺期，總歸為顯一理。但由羣生著欲，欲本所謂我心，故能隨其所懷，開示止心之法。然則心為生欲之本，滅欲必止心元；止心由乎明慧，慧起假於定發；發定之功，非戒不弘。是故特須尊重於戒。故經云：「戒為無上菩提本，應當一心持淨戒。」持戒之心，要唯二轍：止持則戒本最為標首，作持則羯磨結其大科。後進前修，妙宗斯法。故律云：「若不誦戒羯磨，盡形不離依止。」自慧月西隱，法水東流，時兼像正，人通淳薄。初則二部五部之殊，中則十八五百之別，末則眾鋒互舉，各競先驅。人或從緣，法無傾墜。然則道由信發，弘之在人；人幾顛危，法寧澄正。所以羯磨聖教，綿歷古今，世漸增繁，徒盈卷軸。考其實錄，多約前聞；覈其宗緒，略無本據。師心制法者不少，披而行誦者極多。輕侮聖言，動𦁊形網，皆務異同之見，競執是非之迷，不思返隅，更增昏結，致使正法與時潛地矣。故佛言：「若作羯磨，不如白法作白，不如羯磨法作羯磨，如是漸令正法疾滅。當隨順文句，勿令增減，違法毗尼，當如是學。」慈誥若此，妄指實難。昔已在諸關輔撰《行事鈔》，其羅種類，雜相畢陳。但為機務相詶，卒尋難了，故略舉羯磨一色，別標銓題。若科擇出納、興廢是非者，彼鈔明之；此但約法被事、援引證據者，在卷行用。然律藏殘缺，義有遺補，故統關諸部，撮略正文；必彼此俱無，則理通決例，並至篇具顯，便異古藏迹。夫羯磨雖多，要分為八，始從心念，終乎白四，各有成濟之功，故律通標一號。敢就其時用顯要者，類聚編之：文列十篇，義通七眾，豈今傳諸學司，將以自明恒務也
【譯文】探究本原，大雄世尊統御化育天下，豈只為了救拔一人；至大之教感應時代根機而興現，總括歸結起來都是為了彰顯一個真理。只是由於群生耽著欲望，而欲望的根本就是所謂的「我心」，所以世尊隨順眾生心中所存的執著，開示止息妄心的方法。既然如此，心是生起欲望的根本，滅除欲望必須止息心念的源頭；止息心念在於明敏的智慧，智慧的生起有賴於禪定的引發；而發起禪定的功德，若沒有戒律就無法廣大建立。因此，特別需要尊重戒律。所以佛經說：「戒為無上菩提本，應當一心持淨戒。」 持戒的要領，主要只有兩條軌道：止持則以〈戒本〉居於首位，作持則以〈羯磨〉總結為大綱。無論後學還是前賢，都以這項法則為玄妙的宗要。所以律中說：「如果不誦戒、不誦羯磨，盡形壽不得離開依止師。」 自從佛陀慧月隱落西方，佛法之水東傳以來，時代經歷了正法與像法，人心歷經淳樸與澆薄。最初有二部與五部分裂的差異，中期有十八部與五百部各立的區別，末期則諸部競相立說，各自爭先競進。雖然人會隨緣遷變，但佛法本身並未傾覆墜落。然而，修道是由信心引發，弘揚佛法則在於人；若人幾近顛倒顛覆，佛法豈能清澄純正？ 所以羯磨這項聖教，延續歷經古今，歷代相傳逐漸增多繁雜，徒然充斥著卷軸篇幅。考察那些舊作的實際記錄，多半只是依憑先前的傳聞；考核其宗義統緒，大多缺乏根本依據。自憑己意製作法度的人不少，翻開依憑念誦的人極多。輕慢聖人之言，動輒觸犯戒網刑戮，大家都致力於爭論異同的成見，競相固執是非的迷執，不思反求探究根本，反而更增添昏昧結縛，導致正法隨著時日而沉沒入地。所以佛陀說：「如果作羯磨時，不依照白法作白，不依照羯磨法作羯磨，如此將逐漸使正法迅速滅亡。應當隨順文句，不可任意增減，切莫違背法度毗尼，應當這樣修學。」佛陀慈悲的教誡如此嚴切，後人豈能妄加指指點點！ 往昔我已在關輔地區撰寫了《行事鈔》，其中羅列各種品類，雜多的行相全部鋪陳。但由於事務繁冗對應，突然翻檢難以立刻了達，因此簡略挑出「羯磨」這一門，另外標立書名標題。若是辨析揀擇、取捨開遮、興廢是非等義理，在《行事鈔》中已經闡明；本篇則只是針對教法以被覆僧事、援引文句作為證據，便於開卷立即推行使用。 然而律藏有些殘缺不全，在義理上有待遺補，因此統合查照各部律典，摘錄精選其正文；若彼此律部都缺乏明文，則依循理路通融裁決通例，這些都寫到各篇中詳細顯發，這就不同於古代藏匿出處的做法。 羯磨法雖然繁多，概要分為八種，從「心念」開始，到「白四羯磨」為止，各自具有成辦濟事的功能，所以律典統稱同一個名稱。我斗膽就當時實用顯要的法事，依其種類匯聚編排：正文列為十篇，義理通貫七眾弟子，這難道是為了流傳給各學館司署嗎？只不過是用來自己明了日常僧務罷了。
