## 第二部分：程式與提示詞必須修正的地方（開跑前必改）

把順序改為 `裁決 → 二審 → 修訂` 後，直接跑現有程式碼會觸發**兩個隱蔽的實作 Bug**（會導致二審與修訂階段的前後背景全部抓空），加上本次實驗暴露的三項品質缺陷，共須修改 5 個檔案：

### 1. `_src/mk_audit_materials.py` 與 `_src/mk_revise_materials.py`（必改 Bug）

- **Bug ①：背景區塊正則抓不到裁決材料，會直接丟失前後 4 段背景**
  - **原因**：`mk_review_materials.py` 標題寫 `【前文背景（僅供參考，不需校對）】`；但 `mk_judge_materials.py` 寫的是 `【前文背景（僅供參考）】`（少了「，不需校對」）。若直接把 `--src` 或 `--r1` 指向 `測試/批次_裁決`，兩個腳本的 `pre` 與 `post` 都會回傳 `None`。
  - **改法**（兩檔同步修改）：
    ```python
    pre = re.search(
        r'【前文背景[^】]*】\s*\n+(.+?)\n+\n*(?:【本次待審單元】|【原文】)',
        t, re.S,
    )
    post = re.search(r'【後文背景[^】]*】\s*\n+(.+?)\s*\Z', t, re.S)
    ```
- **Bug ②：`col3(rt)` 切欄在例外時會切成 1 個字元**
  - **原因**：`mk_audit_materials.py` 的 `rt[rt.rfind('修正後的譯文'):]` 在找不到字串時索引為 `-1`，會變成 `rt[-1:]`；此外，裁決稿第 3 欄若遇到 `【疏文】` 單獨換行，現在的 `re.sub` 會把標記整行刪掉，不利二審區分疏記邊界。
  - **改法**：
    ```python
    def col3(rt):
        m = re.search(
            r'(?:^|\n)\s*[#*\s]*(?:第\s*)?(?:3|三)?\s*(?:欄\s*[｜|：:]|[.、．：:]|\*\*)*\s*修正後的譯文[^\n]*\n?',
            rt,
        )
        if m:
            body = rt[m.end():]
        else:
            i = rt.rfind('修正後的譯文')
            if i < 0:
                raise ValueError('回覆檔找不到「修正後的譯文」欄位')
            body = rt[i:].split('\n', 1)[1] if '\n' in rt[i:] else rt[i:]
        return re.sub(r'\n{3,}', '\n\n', body).strip()
    ```
    *(註：建議保留 `【疏文】`/`【記文】`/`【鈔文】` 標籤給二審看，二審才會核對疏記是否互洽；最終合稿時再依體例決定去留。)*
- **Bug ③：輸出檔名用 `n + 1` 重編，缺檔會造成整批錯位**
  - **改法**：`mk_audit_materials.py`、`mk_blind_materials.py`、`mk_judge_materials.py` 寫檔時全部改用原檔名 `fn`（`os.path.join(out, fn)`），不要用 `'%02d.md' % (n + 1)`。
- **提示詞補強（`AUDIT_PROMPT` 改為接在裁決之後，維持一階通用原則）**：
  - 在第 1、2 條補明：「**特別核對正反方向詞與括號消歧義（如界內外移動方向、行為是否免責或構成違犯）有無與原文及平行律典相反；並檢查《疏》《記》科判『門／科／節』層級有無誤升或拆錯。**」
  - 在第 4、5 條補明：「**遇疑為底本形近訛字者不可強順訛字擴寫釋義；並檢查有無殘留檢索網址、辭典附註、斷裂引號或遺漏應留原字之直接引文。**」

## 一、純網搜「最佳效果」的流水線設計

#### (1) 修復 `_extract_window` 的「標點／異體字失準」Bug（最重要）
目前 `_extract_window` 直接拿未去標點、未正規化異體字的原文比對網頁內容。CBETA 網頁常夾帶標點或通假字（如查詢 `唯攝宿煑不攝別眾`，網頁是 `唯攝宿煮，不攝別眾`），結果完全匹配不到，**直接退化成只回傳網頁最頂端的目錄標題列（`僅示開頭`）**！

請將 `_extract_window` 改為「去標點＋異體字正規化定位，再映射回原文位置」：

```python
_VAR_MAP = str.maketrans('煑竪虗汙竝説爲於着衆', '煮豎虛污並說為于著眾')
_STRIP_RE = re.compile(r'[^\u4e00-\u9fffA-Za-z0-9]')


def _norm_with_map(s):
    chars, idx_map = [], []
    for idx, ch in enumerate(s):
        if _STRIP_RE.match(ch):
            continue
        chars.append(ch.translate(_VAR_MAP))
        idx_map.append(idx)
    return ''.join(chars), idx_map


def _extract_window(text, query, radius=1800, max_len=3600):
    """去標點＋異體字正規化後定位最密視窗，同分取較後位置避開網頁頂端標題列。"""
    if not text:
        return ''
    if len(text) <= max_len:
        return text

    clean_q = re.sub(r'site:\S+|["「」『』《》〈〉、，。；：？！\s]+', ' ', query or '').strip()
    raw_tokens = [t for t in clean_q.split() if len(t) >= 2]
    norm_tokens = [_STRIP_RE.sub('', t).translate(_VAR_MAP) for t in raw_tokens]
    norm_tokens = [t for t in norm_tokens if len(t) >= 2]
    if not norm_tokens:
        return text[:max_len] + '\n…（無查詢詞，僅示開頭）'

    plain_text, idx_map = _norm_with_map(text)
    positions = []
    for t in norm_tokens:
        start, hit = 0, 0
        while hit < 20:
            i = plain_text.find(t, start)
            if i < 0:
                break
            positions.append((idx_map[i], t))
            start = i + len(t)
            hit += 1

    # 若整詞因個別異字未命中，退回 3 字切片探針避免盲抓網頁開頭
    if not positions:
        probes = []
        for t in norm_tokens:
            if len(t) >= 4:
                probes.extend(t[k:k + 3] for k in range(0, len(t) - 2))
        for p in probes[:12]:
            start, hit = 0, 0
            while hit < 10:
                i = plain_text.find(p, start)
                if i < 0:
                    break
                positions.append((idx_map[i], p))
                start = i + len(p)
                hit += 1
        if not positions:
            return text[:max_len] + '\n…（未定位到關鍵字，僅示開頭）'
        norm_tokens = list(dict.fromkeys(probes))

    best_lo, best_hi, best_score, best_center = 0, min(len(text), max_len), -1, -1
    for i, _t in positions:
        lo = max(0, i - radius)
        hi = min(len(text), i + radius)
        win_norm = _STRIP_RE.sub('', text[lo:hi]).translate(_VAR_MAP)
        score = sum(1 for t in norm_tokens if t in win_norm)
        center = (lo + hi) // 2
        if score > best_score or (score == best_score and center > best_center):
            best_lo, best_hi, best_score, best_center = lo, hi, score, center

    if best_hi - best_lo > max_len:
        center = min(positions, key=lambda p: abs(p[0] - (best_lo + best_hi) // 2))[0]
        best_lo = max(0, center - max_len // 2)
        best_hi = min(len(text), best_lo + max_len)

    prefix = '…（前略）\n' if best_lo > 0 else ''
    suffix = '\n…（後略）' if best_hi < len(text) else ''
    return prefix + text[best_lo:best_hi] + suffix
```
