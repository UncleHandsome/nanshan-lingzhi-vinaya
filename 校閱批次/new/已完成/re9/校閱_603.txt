# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【603-0001】04_比丘尼鈔/04a_卷中之下#13
【原文】販賣戒具六緣犯一在俗家人二共相交貿三決價四為己五自貿易六領受便犯十誦云若可捨物食噉口口吉作衣著著提若須是物審思言我以爾所物買若彼不肯更應再語若復不肯應三語索不得者覓淨人使買淨人不知市易當教以爾所物買是物應好量議教買得者無犯若買得物此賤彼貴有利不犯僧祇云市肆上衣先有價定比丘持價來買置地時語言此直知是衣若不語默持去者越毗尼罪有國土買物常法先有價定齎直來著物邊物主搖頭當知與相比丘亦應語言此直知是物前人若解要須語己持去若默持去者越毗尼罪若賈客物直五十而索百錢比丘以五十知者不犯十誦云若私賣買前人悔取本物七日內聽還若過不應婆論云若眾僧衣未三唱得益價若三唱已不應悔設悔不應還五分云使淨人易時應心念寧使彼得我利我不得彼利三千威儀云教人入市買物有五事一當教莫與人諍二當教買淨者三莫使侵人四不得走促人五當護人意五百問事云有求利者販賣作福此人尚不免地獄何況得福由不隨佛語故非供養請他食者受人犯墮窮厄無食處彼應使白衣作食治生尼白僧云是白衣物若爾可食二三人亦白得食不白犯墮使人言非我物亦可食婆論云此販賣戒一切提中最重寧作屠兒不作販賣何以故屠兒止害一生販賣者一切俱害不問道俗賢愚持戒毀戒無往不欺常懷惡心設若居穀恒希天下荒儉霜雹災變若居鹽及餘物欲使四遠反亂王路隔塞故重於屠兒此物作塔作像皆不得向禮設與僧作食若作僧房持戒比丘不應食用住中得罪中問若死得羯磨分僧祇云一切九十六種出家人邊不諍語買無罪此律雖許出家五眾互易仍不得如市道法許價上下。
【譯文】販賣戒具備六個條件即構成犯罪：一是對象為俗家人；二是雙方互相交易；三是議定價格；四是為了自己；五是親自買賣交易；六是接受領取財物便犯戒。《十誦律》說：如果是應當捨棄的非法所得之物，拿去吃了，每一口都得突吉羅罪；做成衣服穿在身上，每穿一次都犯波逸提罪。如果確實需要此物品，應審慎考慮後說：『我想用這麼多物資換買此物。』如果對方不答應，應當再說一次；如果還是不答應，應說第三次索求；若仍買不到，應當尋找淨人代為購買。若淨人不懂市場交易，應當教導他說『拿這麼多東西去買這個物品』，應當妥善商量指示淨人買得，這樣便不犯戒。如果買進的物品在此處便宜而彼處昂貴、從中產生利潤者，不犯販賣戒。《僧祇律》說：市集店鋪上的衣服事先已有固定價格，比丘帶著價款前來購買，將錢放在地上時說：『這是價款，你知曉這是衣服。』若是不說話默默拿走衣服，犯越毗尼罪。有些國家的買賣常規，事先都有固定公定價，買方攜帶價款前來放在貨物旁，物主點頭示意，便知成交同意給予；比丘也應當對他說：『這是價款，你知曉這是貨物。』對方如果明白，必須在說過之後再拿走貨物；若默默拿走，犯越毗尼罪。如果商人的貨物原本價值五十錢，卻索價一百錢，比丘出價五十錢成交且心知其價者，不犯。《十誦律》說：如果是私下買賣，對方後悔想贖回原物，七天之內准許退還；若超過七天則不應退還。《薩婆多論》說：若是眾僧的衣物拍賣，未唱價三次之前，可以加價買進；若是三次唱價已過，就不應悔改退還，即便反悔也不應退給他。《五分律》說：指派淨人交易時，內心應想著：『寧可讓對方賺取我的利益，我絕不賺取對方的利益。』《三千威儀》說：教導淨人入市集購物有五條準則：一應教導切莫與人爭執；二應教導購買潔淨無瑕之物；三切莫壓榨佔人便宜；四不得在市場奔跑急躁催促他人；五應當顧及他人的心意情緒。《五百問事》說：有人為了牟求私利而經商販賣來求功德修福，這種人尚且免不了墮入地獄，更何況能求得福報？因為這完全不順應佛陀教誨之故，並非清淨供養。若接受這種人請託供齋，吃的人犯波逸提墮罪。在窮困艱危無處覓食的地方，比丘應讓白衣備辦食物以營生度日；比丘尼向僧團稟白說『這是白衣營辦之物』，如果是這樣就可以吃；兩三人互相稟告後也能吃；如果不稟告便擅自食用，犯波逸提墮罪。若是差遣他人並聲明『這不是我的物產』，也可以食用。《薩婆多論》說：這條販賣戒，在所有的波逸提罪中罪過最為嚴重，寧可去做屠夫，也不做買賣交易！為什麼呢？屠夫僅僅危害眾生的一生肉體，做買賣的人卻將所有善法都敗壞殆盡；不論出家在家、賢達愚笨、持戒犯戒，做生意的人無時無處不在欺瞞誆騙，心中常懷惡意；若是屯積穀糧，便時常期盼天下大旱荒年、降霜落雹等自然災變；若是囤積食鹽及其他貨物，就巴望四方生亂、官道阻斷隔絕。所以販賣之罪比屠夫更為嚴重！用販賣所得之物來建造佛塔、塑造佛像，都不應前去禮拜敬奉；若是拿來供僧作飯食或建造僧房，持戒清淨的比丘絕不應當食用其飯菜、入住其中，否則獲罪。此人若死，其遺物僧眾得以作羯磨分配。《僧祇律》說：向所有九十六種外道出家人購買物品，只要不起爭執言詞，買進無罪。本律雖然准許出家五眾互相調劑交換物品，但仍然不得像世俗商市做法那樣隨意討價還價、抬高壓低價格。

【603-0002】04_比丘尼鈔/04a_卷中之下#14
【原文】迴僧物入己戒具四緣一是通與僧物二許想三迴入己四入手便犯此律云僧物有三一已許僧物謂通明僧物未分僧別此迴犯捨二未許僧物迴入己無犯何意得知故律未許想尚得吉故知未許還作未許想何容得罪三已捨與僧此定屬僧物勸迴入已犯重五分云迴向餘人者犯提向餘僧眾多人者越此彼畜生物迴者越心悔見論云欲供養此像迴與彼像吉此律若許僧物迴與塔許現前僧物迴與四方僧許僧物迴與尼並吉故文言許異處也若入塔不應還取即屬塔用以福同故乃至入尼亦爾十誦婆論云若檀越施此自恣僧物迴與彼自恣僧者物應此分其比丘作吉懺若不還此僧計錢犯重乃至此彼一人物迴亦重僧祇云尼眾乞供乃至偏心曲受者重為眾乞物與餘眾眷屬者重此律迴僧物者還竟得互用罪。
【譯文】轉移僧物入己戒具備四個條件即構成犯罪：一是本為通泛供養全體僧眾的僧物；二是心知對方已應許供僧；三是轉移歸入自己私用；四是財物到手即犯本戒。本律說：僧物有三種：一是已許諾給僧眾的物資，指明確通泛供養僧眾但尚未分給大眾或個別僧人的物品，轉移此物犯捨墮罪；二是尚未許諾給僧眾之物，轉移歸己不犯，何以得知？因律中規定若是未應許之物誤以為已應許尚且得吉羅罪，可知本未應許而如實作未許想，怎會獲罪？三是已經捨施交付給僧團的財物，這已確定屬於常住僧物，若勸誘轉歸自己，則犯重罪。《五分律》說：轉移給其他個別人的犯波逸提罪，轉給其他眾多僧人的犯越毗尼罪，此處彼處的蓄養動物被轉移的犯越毗尼罪，需作心念悔過。《善見論》說：原本欲供養此尊佛像，轉移去供奉彼尊佛像，得突吉羅罪。本律規定：若已應許給僧眾之物轉給佛塔，或應許給現前僧物轉給四方僧，或應許給僧眾轉給比丘尼，均得突吉羅罪，所以經文稱為『許異處』；如果已經歸入佛塔，不應再拿回來，即屬於塔廟專用，因為福田相同的緣故；乃至歸入比丘尼眾也是如此。《十誦律》與《薩婆多論》說：若施主布施給此處自恣僧眾之物，被轉移給彼處自恣僧眾，物品應在此處僧眾中分配，違犯的比丘須作突吉羅懺悔；若不歸還給此處僧眾，折算價款達到盜戒標準即犯重罪；乃至將此人或彼人個別之物轉移，也是犯重罪。《僧祇律》說：比丘尼眾托缽乞求供養，乃至偏心曲從私自領受者犯重罪；為大眾乞得物資卻私自轉給其他僧眾或眷屬者犯重罪。本律說：轉移僧物之人，即便後來如數歸還，仍舊要結互用挪用之罪。
