# 校閱材料　第1464檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1464-0001】04_比丘尼鈔/05a_卷下之上#5
【原文】第二簡知事德者今此一門總述諸德若能綱紀量過而行償違斯法舉不知時諍事由生惡法難息故律云汝等數數舉他罪恐壞正法故必具此德恕而不治正法亦滅律云能舉罪人當具五德一知時不以非時二真實不以虗妄三利益不以損減四柔輭不以麤獷五慈心不以瞋恚能斷事人亦具五德一持戒清淨二多聞三廣誦二部戒律四能問能答五如法教訶及作滅擯今五德善能滅鬬諍事治斷非業亦具五德一觀前事是實否二觀合是時宜否三觀僧不令生塵垢否四觀有利益否五觀得善伴否處判他事亦具五德一善知不犯二善知犯三善知輕四善知重五善知決斷無疑毗尼母論云能諫之人無五法不須受一無慚愧二不廣學三常覓人過四憙鬬諍五欲捨道寶梁經云二種人得為知事一阿羅漢二須陀洹人所以爾者餘諸比丘戒不具足心不平等是人不合為知事也復有二人得當知事一能淨持戒識知業報二畏後世罪有諸慚愧及以悔心如是二人自無瘡疣亦護他人若不具此德率以庸情輙處判他反成自累何匡益他也故律云我說此人愚癡故犯波羅夷謂不諳教綱冥犯大罪既知不易誠為大誡宜詳聖意省己為人也。
【譯文】第二「選拔領眾執事者的德行」（簡知事德）：這一門總括論述各種應具備的德行。如果能綱紀分明，審量過失而依法處置，若違背這個原則，舉發不知時機，諍訟就會由此產生，惡法就很難止息。所以戒律說：「你們頻頻舉發他人的罪過，恐怕會敗壞正法。」因此必須具備舉罪的德行；但若一味姑息寬恕而不予懲治，正法同樣會滅亡。戒律說明：能舉發他人罪過者應當具備五種德行，一是知曉適當時機而非不合時宜，二是基於真實而非虛妄，三是能帶來利益而非損減，四是用語柔軟而非粗暴，五是出於慈悲心而非瞋恚忿怒。能斷決事端的人也必須具備五德：一是持戒清淨，二是廣學多聞，三是能廣泛誦習比丘與比丘尼二部戒律，四是能善巧問答，五是能如法教誡呵責以及執行滅擯（驅逐出教）。如今善於平息鬥諍、懲治斷決非理罪業者，也當具備五德：一要審察先前之事是否屬實，二要審察是否合乎時機，三要審察是否能使僧眾不生染污煩惱，四要審察是否有實質利益，五要審察是否能得到良好的善伴同心協力。裁決評斷他人是非者，同樣具備五德：一是善於了知不犯的情況，二是善於了知犯戒的情況，三是善於了知輕罪，四是善於了知重罪，五是善於果決斷定而無所猶豫疑慮。《毘尼母論》指出：前來勸諫的人若具備五種無德之法，便不須採納其規諫：一是無慚愧心，二是不廣學教理，三是常窺尋他人過失，四是喜好爭端鬥諍，五是心存退道還俗之念。《寶梁經》說：有兩種人可以擔任知事，一是阿羅漢，二是初果須陀洹；原因在於其他比丘戒律尚不圓滿、心不平等，這些人都不適合擔任執事。經中又說還有兩種人可以擔任知事：一是能清淨持戒、深知善惡業報的人，二是畏懼後世受報罪過、心懷慚愧並常具悔改之心的人；這兩種人自己沒有過患瑕疵，也能守護他人。如果不具備這些德行，憑藉庸俗的私情隨意處置評斷他人，反而成為自身的累贅業障，哪裡能匡正利益大眾呢？所以戒律說：「我說這種人是因為愚癡而觸犯波羅夷（極重罪）。」這就是指不熟悉教理綱要，暗中犯下重大罪過。既然知道執事不易，實為極大的警誡，理當詳審聖人深意，省察自己以成就他人。
