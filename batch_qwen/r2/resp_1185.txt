整體看下來，八則譯文的骨架大多正確，但有一個**系統性毛病：增字衍義太多**（形容詞、程度副詞、現代法律用語大量加入），其中有幾處已經造成義理偏差；另外有 **4～5 處是實質誤譯**，建議優先修正。以下逐則列出。

---

## 【1185-0001】

| 問題 | 說明／建議 |
|---|---|
| 「在**邪命**外道中出家」 | 原文只作「於外道出家」，「邪命（阿耆毘迦）」是譯者自行指定的學派，無據。刪去「邪命」。 |
| 「次**別證**中」→「別立**見證**中」 | 「別證」是科文用語，指「分別引經作證」（相對於通證），不是「見證」。建議：「接著在『別引經證』一段中，前面先引《增一阿含》。」 |
| 「據本受意」→「依照最初領受衣物時的**心念**」 | 「意」是意趣、用意，不是「心念」。此句歷來讀法有出入，建議保守譯為「依其本來的受（衣）意趣，有長短之別」，不要坐實成「領受衣物時的心念」。 |
| 〔短即四分作衣〕→「**親手**縫製衣服的期間」 | 「親手」為添加（作衣時重在「作衣」之期間，不論是否親手）。 |
| 「設齋供養…特予開許」 | 可補一句說明所開為何（沙門施食時得別眾食），讀者才好銜接下文「作衣／衣時」的問答。 |

## 【1185-0002】

| 問題 | 說明／建議 |
|---|---|
| **「金色㲲」譯成「金色的細毛氈」** ★ | 㲲（dié）是**棉布／細棉布**（劫貝、白㲲），不是「氈」（氈是毛製品）。譯文前面才說「紡紗織布」，後面又說「這端布匹」，前後自相矛盾。應作「一匹金色棉布（㲲布）」。 |
| **「十六具足」譯成「十六位具足戒德的僧眾」** ★ | 依括注《增輝》「僧尼各有四果四向」，十六＝**比丘、比丘尼各八（四向四果）共十六類聖眾**，不是「十六位受具足戒的僧人」。建議：「若只布施給十六類具足聖德者（僧尼各有四果四向）」。 |
| 「五百位**大阿羅漢**」 | 原文只作「五百人」，「大阿羅漢」是添加。 |
| 「雖得一人」→「哪怕只迎請到一位**凡夫**僧人」 | 原文無「凡夫」；且「就等於**實質**供養」語氣過強，記文是就**福報**說等同供僧。建議：「即使只請到一位僧人，也已等同供養十方凡聖。」 |
| 「師子下」 | 「師子」是**師子長者**（人名，即上文那位長者），譯文只作引文標記，讀者易誤以為法義名詞，宜補注。 |
| 「為聖所讚」→「佛陀**聖眾**的讚歎」 | 「聖」此處指佛（聖人），不必擴成「佛陀聖眾」。 |

## 【1185-0003】

| 問題 | 說明／建議 |
|---|---|
| 「《五分》簡人，**精**也；賢愚取人，**麁**也」 | 這是一組對比：**精＝精細嚴揀／麁（粗）＝粗泛不揀**。譯成「嚴格精純」對「寬廣博大」，把貶義的「粗」美化成褒義，且「著眼於施主攝受對象」是自行添加。建議：「《五分》揀擇受施之人，標準精細；《賢愚》取人則粗泛（不作揀別）。」 |
| 「未足為多」→「根本稱不上廣大」 | 原意是**相較於普施大眾僧**仍不算多，是比較語，不是全盤否定。建議補「（比起普施僧眾）仍不算多」。 |
| 「且取外生物信」→「藉由**僧相**在外表上引發世人信心」 | 「僧相」雖屬合理推衍，仍為增譯，可保留但宜加括號或刪。 |

## 【1185-0004】

| 問題 | 說明／建議 |
|---|---|
| 「對施興治，能所俱墮」→「對於濫受布施而興起的對治懲處，**讓**施受雙方通通墮入惡道」 ★ | **因果講反了**。原文是「就受施之事興起治罰，（律說明）能施、所受二者俱墮」，不是「懲處使雙方墮落」。建議：「就布施之事興起治罰，說明能施與所受雙方都將墮落。」 |
| 「《五分》除惡戒」→「嚴厲**剔除**破戒僧徒」 | 語境是**供僧揀眾時排除惡戒者**，不是僧團滅擯驅逐，易生誤解。建議：「《五分》（受施時）揀除惡戒之人」。 |
| 「不周則**所施無福**」→「所布施**之物**將無福可言」 | 無福的是**施主**，不是物品。建議：「若不普周，施者便得不到福報。」 |
| 「受須戒淨」→「**受請者**必須**保證**戒行清淨」 | 「受」泛指受施、受供者，不限受請；「保證」為現代語，宜作「受施者必須戒行清淨」。 |
| 「不消杯水」→「無法**消受消融**」 | 疊詞贅語，作「連一杯水的信施都消受不了」即可。 |
| 「自招枉墜」→「平白招來枉墮惡道的**奇禍**」 | 「奇禍」是添加且用語怪異，作「白白招致墮落之報」。 |

## 【1185-0005】

| 問題 | 說明／建議 |
|---|---|
| 「其相可解」→「其**犯戒**相貌極為顯明易懂」 ★ | 「相」指該八緣的行相、內容，**與犯戒無關**，「犯戒」是憑空添加。建議：「注文顯示八種事緣，其內容容易理解。」 |
| 「制令白入」→「才能**進入別處受食**」 ★（待核） | 依下一則「白入者，護**內比丘**意故」「隨**上座次**入」，「入」應是**入於僧眾（僧次）中受食**，不是「到別處」。方向恐相反，建議改「須先向大眾宣白才能入眾受食」，並核對鈔文。 |
| 「若據大眾，亦是通眾」 | 此「大眾」很可能指九緣中的「**大眾集時**」，譯成「就全體僧眾的角度而言」語意浮泛。此句建議對照鈔文再定，暫勿坐實。 |
| 「且能自益」→「暫且能夠獨自獲得**法益開許**」 | 「法益開許」生造複詞。作「有開緣的人，姑且是為自身之益」。 |
| 「九種」 | 由下則「不犯指前**本異**九種」可證確為九種開緣，此處譯法無誤，可放心。 |

## 【1185-0006】

| 問題 | 說明／建議 |
|---|---|
| 「不白吉者」→「若不宣白就**私自行動**便結突吉羅」 ★ | 從緊接的問答（「無緣白出，不白犯不？」需另行討論）可知，**此「不白吉」專指「不白入」**；譯成「私自行動」把出、入混為一談，後文的問答就變得多餘。建議：「不宣白而入者結突吉羅，因違教故。」 |
| 問句譯法重複矛盾 | 「沒有特殊事緣**而宣白外出**，若是不向大眾宣白就私自跑出去」——一下說白、一下說不白。應作：「無緣者依制應宣白外出，若不宣白就出去，犯不犯？」 |
| 「入則反之」→「**嚴重破壞了僧倫秩序**」 | 原文只有「入則反之」四字，這句是大幅增譯。 |
| 「故制與罪」→「**科處罪刑**」 | 現代刑事用語，與律家「結罪」語感不合，建議「所以才制定（白入）並結罪」。 |
| 「本異九種」 | 譯為「本律與各部律典所載的九種開緣」——正確，此處處理得好。 |

## 【1185-0008】

| 問題 | 說明／建議 |
|---|---|
| **「列緣」→「這是列出制戒緣起」** ★ | 「列緣」是**列具犯緣（成犯條件）**。證據：下文「第一指上標名」「第三＝無病」「第四＝鉢量過限」都是成犯要件；且前面括注已敘述制戒緣起，此處另起。應改：「以下是列出成犯的諸緣。」 |
| **「又取商客食分路中數施」→「婦人又拿了客商的食物…布施」** ★ | 這是**第二個獨立緣起**：比丘取商客（估客）的食分，商客於途中屢次施食，致（商客）為賊所劫。主語不是那位婦人。譯文把兩緣串成同一人，故事就錯了。建議：「又（比丘）取商客的食物分，商客在路途中屢次布施，結果被盜賊搶劫。」 |
| 「中三下**三十四**」→「第三十**四條**」 | 「三十四」應是版本的**卷次通號**（非「條」）。建議保留原樣或作「（通計第三十四卷）」，並請核對所用底本。 |
| 「疏」的譯名不一致 | 前七則一律作「義疏」，此則忽作「戒疏」。資持記所引「疏」一般指道宣《戒本疏》（或《業疏》），宜全篇統一（例如一律作「《疏》（戒本疏）」）。 |
| 「上鉢取一無罪，二鉢是犯」 | 譯法正確（《薩婆多論》上鉢一、中鉢二、下鉢三之制），無問題。 |

## 綜合建議

1. **先改五個硬傷**：㲲（棉布非毛氈）、十六具足（十六類聖僧尼非十六位受具戒者）、列緣（犯緣非制緣）、第二緣主語（商客非婦人）、不白吉（專指不白入）。
2. **收斂增譯**：凡「嚴厲、實質、保證、奇禍、時時刻刻、嚴重破壞僧倫秩序、科處罪刑」等原文所無的修飾與現代法律語彙，建議一律刪除或改為括注補充，避免把註解當原文。
3. **保留科文標記的原貌**：「別證」「總判」「告白」「列緣」「師子下」「佛讚下」這類是鈔記的科段用語，直譯並略加說明即可，不要意譯成「別立見證」這類會誤導的詞。
4. **兩處存疑待考**：「據本受意」與「若據大眾，亦是通眾」，建議對照《行事鈔》本文與《戒本疏》再定譯， presently 的譯法都偏向自行坐實。
