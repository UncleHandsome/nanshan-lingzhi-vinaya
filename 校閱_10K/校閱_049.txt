# 校閱材料　第049檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【049-0001】01_行事鈔/03b_卷上之三#27
【原文】三簡師德。因明諸師不同。《四分》五種：一出家闍梨，所依得出家者。二受戒闍梨，受戒時作羯磨者。三教授闍梨，教授威儀者。四受經闍梨，所從受經，若說義，乃至四句偈也。五依止闍梨，乃至依止住一宿也。和尚者，從受得戒者是。和尚等者，多己十歲；阿闍梨等者，多己五歲，除依止。若準此文，四種闍梨，要多己五歲，方號闍梨；餘未滿者，雖從受誦，未霑勝名。若準，九歲和尚，得戒，得罪；此雖未滿。得名何損。又上四闍梨，不得攝人而替依止和尚處；由一席作法，非通始終；若作師者，更須請法。律中二師，行德三種：一簡年十歲已上，二須具智慧，三能勤教授弟子。有七種共行法，更相攝養，如和尚法中。《摩得伽》云：凡欲依止人者，當好量宜，能長善法者；及問餘人，此比丘戒德何似？能教誡不？眷屬復何似，無有諍訟不？若都無者，然後依止。《僧祇》：不得趣爾請依止，成就五法：一愛念，二恭敬，三慚，四愧，五樂住。《四分》：諸比丘輒爾依止，不能長益沙門道行。佛令選擇取依止。即師有破戒見威儀等，並不合為依止。因二歲比丘，將一歲弟子往佛所。佛訶責云：汝身未斷乳，應受人教授，云何教人耶？若師有非法，聽餘人誘將弟子去。《五百問》云：其師無非法，而誘將沙彌去，犯重。因說老病比丘死緣。《善見》云：若不解律，但解經論，不得度沙彌及依止。《僧祇》：成就四法，名為持律：謂知有罪、知無罪，知輕、知重；下至知二部律，得作和尚。《三千威儀》多有請二師方法，及攝受共行之儀。
【譯文】第三、甄別師長的德行（簡師德）。因而闡明各類師長的名目差異。《四分律》列出五種阿闍梨：一、出家阿闍梨，即依託其剃度得以出家者。二、受戒阿闍梨，即受具足戒時宣告羯磨者（羯磨師）。三、教授阿闍梨，即受戒前在隱處教授威儀與問難事者。四、受經阿闍梨，即跟從其學習讀誦經文，或聽其講解義理，乃至只學四句偈頌者。五、依止阿闍梨，即依託其安住，乃至僅隨其依止住過一夜者。「和尚」者，是指從其座下稟受而獲得具足戒體的大師。通常和尚的戒臘，多長於自己十歲（十夏）以上；阿闍梨等，多長於自己五歲（五夏）以上，依止阿闍梨則除外（無須多己五歲）。如果依照這段律文，前四種阿闍梨必須多出自己五夏戒臘，方才稱得上是阿闍梨；其餘夏臘不滿多出五夏者，縱使從其受經讀誦，也尚未能冠上此殊勝德名。但若依律制比照：九歲夏臘的比丘作和尚為人受戒，受戒者得戒，但和尚結犯戒之罪；此四種阿闍梨戒臘雖未滿多己五夏，但獲得阿闍梨之名又有何妨損呢（如同九歲和尚雖未滿十夏亦得和尚名，僅是結罪而已）。再者，上述前四種阿闍梨，不得藉由一次作法便全面取代依止師或和尚的地位；因為受戒或教經只是一座席間的特定作法，不能貫通於自始至終的長久依止；若要真正成為日常依止師，必須另外專門舉行求請依止法度。律中規定和尚與依止師這二師，必須具備三種德行：第一、檢擇其戒臘須在十夏以上；第二、必須具足深明通達之智慧；第三、能勤懇不倦地教授訓勉弟子。並且具有七種共行法度，彼此展轉攝持資養，如和尚法中所述。《摩得伽》說：凡是想要依止他人為師者，應當好好衡量審度，必須是能使自己增長善法的人；並且向其他人探問打聽：「這位比丘戒行德操如何？具有教導規誡的能力否？他的徒弟眷屬行誼又如何，寺中是否有諍論爭鬥呢？」若是確知全無過失瑕疵，然後才可正式請求依止。《僧祇律》說：不可隨便草率請求依止，須弟子於師成就五法：一愛念，二恭敬，三慚，四愧，五樂住。《四分律》說：當初諸比丘隨意草率找人依止，不能增長進益沙門的修道之行。佛陀因此命令比丘必須審慎選擇而後求取依止。如果為師者有破犯戒律、破壞正見、壞失威儀等過咎，全都不適合為其作依止師。當時曾有受戒僅兩歲夏臘的比丘，帶著一個一夏戒臘的弟子前往佛陀住處。佛陀當即訶責他說：「你自身尚未斷奶（未脫依止幼弱之年），尚且應當接受他人教授引導，怎麼反而去教導別人呢？」如果師父自身存在非法非律之事，律中允許其他人把其弟子勸誘帶走引導向善。《五百問》說：若是師父並無非法惡行，而有人擅自將其沙彌弟子誘拐帶走的，犯重罪；經中是因老病比丘致死的因緣（方判定誘走沙彌者犯重罪）。《善見論》說：如果不懂毘尼律藏，僅僅懂得經藏與論藏，也不得為人剃度沙彌及作為依止師。《僧祇律》說：成就四種法，方可稱為持律者：即知有罪、知無罪，知罪輕、知罪重；乃至最起碼通達比丘、比丘尼二部律藏，方能作和尚。《三千威儀》（《大比丘三千威儀》）中對於請求二師之方法，以及師徒攝受共行之威儀，有更為詳盡的記載。

【049-0002】01_行事鈔/03b_卷上之三#28
【原文】四明請師法。《律》中，由和尚命終，無人教授，多壞威儀；聽有依止，如上和尚法；令法倍增益流布。《僧祇》亦得名師為尊。請文云：「大德一心念！我某甲比丘，今請大德為依止阿闍梨。願大德為我作依止阿闍梨。我依大德故，得如法住！」彼言：「可爾！與汝依止，汝莫放逸。」《五分》云：「我當受尊教誡！」不者不成。先不相識者，應問和尚闍梨名字，先住何處、誦何經等。若不如法，應語云：「汝不識我，我不識汝，汝可往識汝處受依止。」若疑，應語小住，六宿觀之，合意為受。若依止師不答許可者，不成。《四分》云：彼遣使受依止，遣使與依止，皆不成。
【譯文】第四、明示請師法度。《律》中記載，由於受戒和尚命終圓寂之後，無人教導傳授，比丘們多有壞失威儀軌範的現象；因此佛陀開許求請依止阿闍梨，其地位與承事如同上述和尚之法；以此令正法加倍增益流傳布散。《僧祇律》中也稱依止師為「尊」。求請依止的儀文說：「大德一心念！我某甲比丘，如今迎請大德為依止阿闍梨。願大德為我作依止阿闍梨。我依靠大德教導的緣故，得以如法如律安住！」（三說）。被請的師父應回答說：「可以！與你作依止師，你切莫放逸散漫。」《五分律》說：弟子應當回答：「我當接受尊者的教誡！」若不如此答則依止不成。如果彼此原本不相結識，為師者應當審問其原受戒和尚及阿闍梨的法名叫什麼，先前住在哪裡、平時讀誦什麼經典等。如果發現其行儀不如法，應當對他說：「你既不了解我，我也不了解你，你大可前往熟悉了解你的住處去求受依止。」若是心中尚有疑慮，應當對受依止者說「暫且住下」，以六夜時間留心觀察他，如果性行合宜契意，方才為其收受依止。如果依止師自始至終不正面回答許可承諾，則依止便不成立。《四分律》說：若是派遣使者代為求受依止，或者為師者派遣使者傳達同意給予依止，這些都不成立依止法。
