# 校閱材料　第1866檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1866-0001】03_業疏/20a_卷四之三#29
【原文】五行住者：對、念二法，無問行住，俱得用之。忘成等五，以是行人先有要故，文云「為安居來」，非舊人也。必舊有要，例亦開之
【譯文】第五、行人與住人：對首、心念二種法，無論是路上行人還是常住之人，都可以使用。忘成等五種法，是因為出行之人預先有了期約，所以律文說「為了安居而來」，指的並不是舊住之人。如果舊住之人事先也有期約，照例也可以開許。

【1866-0002】03_業疏/20a_卷四之三#30
【原文】五中，「行」即外客，「住」即舊住。「要」即要期。上引他解，「必」下今判
【譯文】在第五門中，「行」是指外來的客僧，「住」是指原有的舊住僧。「要」是指預先立下的期約。上面引述的是他人的見解，自「必」以下是今家宗師的判定。

【1866-0003】03_業疏/20a_卷四之三#31
【原文】六據法不同者：對、念作法，以容預故；忘等開成，恐乖前後，直爾便得。若直爾得，後用加法何為？答：制開義立，何得不有
【譯文】第六、依據作法的不同：對首與心念作法，是因為時間寬裕從容；忘成等法之所以開許成就，是唯恐違背了前後安居的期限，當下直接即可成立。問：如果當下直接就能成立，事後為何還要補加作法呢？答：教制的常則與隨緣的開許，二者義理並立，怎麼可能沒有後續的加行作法呢？

【1866-0004】03_業疏/20a_卷四之三#32
【原文】六中初正明。「若」下釋妨，以忘成等初即開成，後須加法故。答中初成從開，後加稟制
【譯文】在第六門中，首先正面闡明。自「若」以下解釋妨難，因為忘成等法起初便開許成立，隨後卻又必須補作加法。答文中說明：起初成就乃是依從開緣，隨後補加則是承秉教制。

【1866-0005】03_業疏/20a_卷四之三#33
【原文】二明結時前後者
【譯文】第二、說明結夏時節的前後。

【1866-0006】03_業疏/20a_卷四之三#34
【原文】問：安居修道，何時不須，偏約在夏者？答：夏過多故，如上標舉。濕熱鬱蒸，散亂乖道，生譏致謗，因斯故制。使修自行，行滿德成，事須益物，是以春冬隨緣外化
【譯文】問：安居修道，什麼時候不需要，為何偏偏限定在夏季？答：夏季的罪過極多，正如上面所標舉列出的那樣。暑熱潮濕蒸郁，容易令人身心散亂而違乖聖道，招致世人的譏嫌與毀謗，正是因此緣故而制定安居。此法旨在令人精修自身道行；修持圓滿、功德成就之後，事業上必須利益群生，所以春冬二季任由隨順因緣出外化導。

【1866-0007】03_業疏/20a_卷四之三#35
【原文】二結時初問答中，初敘夏月制意。指如上者，即三種過。然前後敘致，並附權意，託緣立法。究論聖戒，莫非為道，毗尼開制大要在茲。「行滿」下次明春冬開意
【譯文】在第二結夏時節的最初問答中，首先敘述夏季制定安居的本意。「指如上者」，即是指前面提到的三種過患。然而前後所鋪敘的文辭，都寄附著權巧之意，依託外緣而建立戒法。推究聖者戒法的真諦，無一不是為了趣向聖道，毘尼的開許與制止大要就在於此。自「行滿」以下，次說明春冬兩季開許外出的意旨。

【1866-0008】03_業疏/20a_卷四之三#36
【原文】若爾，成化何局春冬？夏中受日，隨益開往；春冬有過，亦通制者？答：受日深益，待量方赴；春冬過少，故任不結。各有義也
【譯文】問：如果這樣的話，成辦教化何必局限在春冬？夏天受日法准假，只要隨順利益有情便可開許前往；春冬若有罪過，也應當一併通制安居才是？答：受日請假須有重大的法益，審度因緣之後才前往；春冬的過患稀少，所以聽任不必結夏安居。這兩者各有其道理。

【1866-0009】03_業疏/20a_卷四之三#37
【原文】次科轉難中，論化益則夏中亦開，據有過則春冬亦制，是則三時同等，開制無功。答中，緣分急緩，故量不量殊；過有少多，故結不結異
【譯文】在其次一科的輾轉發難中，對方以為：若論教化利益則夏季亦有開許，若論招致罪過則春冬亦應通制，這樣一來春夏冬三時就毫無差別，戒律的開制也就失去功用了。答文中說明：事緣有急迫與遲緩之分，所以衡量與否有所不同；過患有多與少之別，所以結夏與否各有差異。

【1866-0010】03_業疏/20a_卷四之三#38
【原文】問：夏有四月，何但結三？答：待形須濟，事須開捨，故制前三，特開後一。迦提賞勞，使作衣服，受用資身，弘道利俗也。又解云：四月通結，唯初日成。必有緣礙，則不名歲。教急機緩，不名智人，不可常行，攝生不盡，故開前一月續結成歲，豈不然耶
【譯文】問：夏季共有四個月，為何只安居結夏三個月？答：維持色身需要資養救濟，事務上也必須有所開許與放捨，所以制定前三個月安居，特意開許最後一個月。在迦絺那衣月犒賞辛勞，讓比丘裁製衣服，受用物資以資養色身，從而弘揚正道、利樂世俗。又有一種解釋說：若夏季四個月通通都結安居，那就只有在第一天結夏才能成就。如果遭遇事緣阻礙，就不能稱為圓成戒歲。戒教太過急迫而根機遲緩，佛陀就不名為具一切智之人；若嚴格不可通融，則無法常行，也不能周遍攝化眾生，所以開許在前一個月內可陸續結夏以成就戒歲，難道不是這樣嗎？

【1866-0011】03_業疏/20a_卷四之三#39
【原文】次問答中，初約開後釋。「又下」次約留前釋。佛名一切智人，以能知機故；攝生不盡，不收中下故
【譯文】在其次的問答中，首先依據開許最後一個月來解釋。自「又」以下，次依據寬留前一個月來解釋。佛陀稱為「一切智人」，是因為能洞悉根機之故；如果攝受眾生不周盡，就無法包容中下根機之人。

【原文】三明夏閏延促者
【譯文】第三、說明夏季遇閏月時安居的延長與縮減。

【1866-0013】03_業疏/20a_卷四之三#41
【原文】有人言：佛制三月，但依教數，不勞多事通閏四月也。故《伽論》云：王作閏月，數安居日滿自恣已，受迦絺那衣。即此衣成受不成受，謂依閏不依閏。據此論文，明知不依自然得夏，并受衣也
【譯文】有人說：佛陀制定安居三個月，只要依循教法規定的天數即可，不需要多事把閏月也一併算入而變成四個月。所以《薩婆多毘尼摩得勒伽》說：國王設立閏月，數算安居的日數滿了並受自恣之後，領受迦絺那衣。這件功德衣究竟成受還是不成受，取決於依循閏月還是不依循閏月。依據這段論文明顯可知：即使不依隨閏月，自然也能圓滿夏歲，並且可以領受功德衣。

【1866-0014】03_業疏/20a_卷四之三#42
【原文】三、定閏中，初師初立義，「故」下引據。「王作閏」者，謂國家出年歷也。「數滿」，謂從前四月十六去取九十日，即六月十六自恣受衣。不依已滿，故成受；依閏未滿，故不成受。「據」下結斷。
【譯文】在第三判定閏月的科文中，第一位法師首先建立己義，自「故」以下引用依據。「王作閏」，是指國家朝廷頒布年曆。「數滿」，是指從前四月十六日開始算起滿九十天，即到六月十六日便自恣受衣。不依閏月者日數已滿，所以成就受衣；依循閏月者日數未滿，所以不成就受衣。自「據」以下作結斷。

【1866-0015】03_業疏/20a_卷四之三#43
【原文】有人言：本契三月，不出本界。今夏未滿，閏中出界，即非相續依處安居，故是破也。昔人不依閏者，但數九十日耳。今有不依閏者，正月便安，閏月不安
【譯文】有人說：原本相約三個月不出原結界。現在夏季未滿，在閏月中走出了結界，這就不是連續不斷地依止一處安居，所以算作破夏。過去的人不依循閏月，只是死板計算九十天而已；現在有些不依循閏月的人，在正月中便安居，到了閏月卻不安居。

【1866-0016】03_業疏/20a_卷四之三#44
【原文】次師中初科，初敘過。「未滿出界」，即下數滿者；「閏中出界」，即下「閏月不安」者。「昔」下指非。昔人可恕，今人愈乖。「正」字去呼，對餘謂之正，下同。謂前後三月則守安居，中間閏月則許出界
【譯文】在第二位法師的內容中，第一科首先敘述過咎。「夏未滿而出界」，就是指下文單純數滿九十天的人；「在閏月中出界」，就是指下文「閏月中不安居」的人。自「昔」以下指責其錯誤：古人尚有情可原，今人則更加違背法度。「正」字讀作去聲，相對於閏月而稱為「正」，下同。意思是前後三個月就恪守安居，中間的閏月卻任意外出界外。
