# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【311-0001】02_戒疏/16b_卷四上之一#40
【原文】【記】第二，制意中。初敘合宜。「人士」者，謂人中之士，即目有道之流。《律》云：「佛告諸比丘：『凡人欲有所說，當說善語，不應說惡語。善語者善，惡語者自熱惱。』」、「反」下，二、顯過相。初約廢業明過。「形呰」，謂相形比而作毀呰。「又」下，次約傷惱明過。「切」，謂逼切。「劒割」傷體，惡語傷心，故云「甚」也。
【譯文】【記文】第二在制戒意圖之中。首先敘述應有的合宜行持。「人士」，是指人群中的優秀之士，也就是指有道德修養的群體。《四分律》說：「佛陀告訴諸比丘：『凡是人有所言說，應當說善語，不應當說惡語。說善語的人身心安善，說惡語的人自己徒增熱惱。』」「反而」以下，第二顯現過失相貌。首先是就廢弛學道正業來說明過失。「形呰」，是指拿彼此的身分或短處相互對比而加以毀謗譏笑。「又」以下，接著就刺傷熱惱人心來說明過失。「切」，是指逼迫痛切。「刀劍劈割」傷害的是肉體，惡毒的言語傷害的是心靈，所以說是「痛苦更甚」。

【譯文】也就是〈衣犍度〉的經文，那裏說明佛在舍衛國時，告訴諸位比丘：我想三個月靜坐思惟，不要讓外人進來，唯獨留一位送飲食供養的人；各位比丘立下規約，如果有進去的人，就要作波逸提懺悔；當時長老和先跋闍陀之子，與波羅國的六十位頭陀行者，沒有理會比丘們的規約，一同前往佛的住處；佛稱讚說：太好了，太好了！和先，你們全都是住阿蘭若的行者等，可以隨意問訊；

【311-0003】資持記/15a_下三#11
【原文】諸比丘聞已，多習頭陀行，乃至捨長衣成大𧂐。則知少欲離染，隨順佛語，即為供養佛人。彰利中。論明十二頭陀，各具十利；且引練若一種，以彰多利；故至下文列相，不復引也。初標示。言略說者，明不盡故。言盡形者，明要期故。次列相。初謂身無所屬，二謂無物所繫，三即不為他阻；
【譯文】諸位比丘聽聞之後，大多修習頭陀行，甚至捨棄多餘的長衣堆成了大堆。由此可知，少欲知足、遠離染著、順從佛的教導，就是真正供養佛的人。在彰顯利益（彰利）中，論書說明十二頭陀行各具備十種利益；這裏暫且引用阿蘭若一種，用來彰顯多種利益；所以到了下文羅列行相時，就不再重複引用了。起初進行標示說明。所謂「略說」，是說明無法完全窮盡。「盡形」，是說明終身發願的期限。其次羅列行相：第一是指身體無所拘屬，第二是指沒有物品牽繫，第三就是不受他人阻礙；

【311-0006】資持記/15a_下三#14

【311-0007】01_行事鈔/11a_卷下之三#6
【原文】初衣服中者。衣是資道之緣，濟身最要，故先就外資，以明知足。若於此衣取不得方，廣生罪累，為惡業所纏，縛在三有，障礙出道，即非頭陀。是故教諸比丘，於彼外資，少欲知足，受取有方，趣得資身長道便罷，即是頭陀，離諸貪著故。衣中立二：一者納衣，二者三衣。雖得衣以障身，內有飢虛等惱，寧堪進業？故就食中立四頭陀，一者乞食，二不作餘食法，三一坐，四一揣也。然衣食乃具，修道義立，若處在憒鬧，心多蕩亂，必托靜緣，始成正節，是以於處立五頭陀：謂蘭若、塚間、樹下、露坐、隨坐。上來三種並是助緣，若繫念思量，斬纏出要者，無過坐法，故於威儀立一常坐。
【譯文】首先就衣服而言。衣服是資助進道的助緣，也是救濟色身最切要的物資，因此首先就外在的資生物質，來說明知足的道理。如果對於這衣服獲取不得其法，廣泛滋生罪業過患，被惡業所牽纏，束縛在三界生死之中，障礙出離之道，這就稱不上是頭陀行了。因此教導諸位比丘，對於那些外在的資具，應當少欲知足，受取合乎如法的方法，只要剛好能滋養色身、增長道業就滿足了，這就是頭陀行，因為遠離了一切貪戀執著。在衣服方面確立了兩項：一是納衣（糞掃衣），二是但持三衣。雖然得到了衣服來遮蔽形體，但內心若有飢渴虛耗等困擾，哪裡能夠精進修業呢？所以在飲食方面確立了四種頭陀行：一是乞食（常乞食），二是不作餘食法（不接受另外的殘食法或額外勸食），三是一坐食，四是一揣食（節量食、一摶食）。然而衣服和飲食既然具足，修道的基礎便已確立；但如果身處於紛亂喧鬧之中，心念多所動盪散亂，必須依託寂靜的環境外緣，方能成就正道操守，因此在居處方面確立了五種頭陀行：也就是阿蘭若處、塚間處、樹下坐、露天坐（露坐）、隨所得坐（隨坐）。以上三種（衣、食、處）都是修道的助緣，而若要專注繫念思量、斬斷煩惱纏縛的出離樞要，沒有比坐法更殊勝的了，所以在行住坐臥四威儀中確立了一項「常坐不臥」。

【311-0009】資持記/15a_下三#15
【原文】初敘過非。是下，示教立。少欲知足者，離貪求也。受取有方者，合制法也；制法如下所示。下之三科，一一竝有躡前生起，列相二段，尋文可分。三中。蕩即蕩逸，節謂節行。露坐隨坐，以儀目處，與下異也。四中。前三望坐，坐是正修，故名助緣；若望心觀，坐亦緣耳。
【譯文】首先敘述過失與非理。「是」字以下，指示教法的建立。「少欲知足」，是遠離貪求。「受取有方」，是符合制定的法則；制定的法則如下文所示。下面的三個科判，全都有承接前文生起次第、羅列行相這兩個段落，循著文字便可區分開來。在第三項中，「蕩」就是放蕩放逸，「節」就是節制德行。「露地坐」與「隨處坐」，是以儀表威儀來標示處所，與下文有所不同。在第四項中，前三種相對於端坐而言，端坐是正修，所以前三種稱為助緣；若是相對於心性觀照而言，端坐也只是一種助緣罷了。

【311-0013】02_戒疏/16b_卷四上之一#43
【原文】【註】佛在舍衛。六群於斷事人前種類罵，彼忘失前後，慚愧不語。比丘以過白佛。便引牯牛以譬，「畜生得毀，不堪進力」等，便制此戒。

【311-0014】02_戒疏/16b_卷四上之一#44
【原文】【疏】就戒緣中。初緣，後「引牯牛為譬」，下類上也。《論》云：「畜生古時皆能語者，以世劫初，先有人天，未有三惡，並從人天中來，宿習故語。今多從三惡趣來，所不語。」
【譯文】【疏文】在制戒的緣起之中。前半段是緣起事由，後半段「引用公牛作為譬喻」，是以畜生為例來比況人類。《薩婆多論》說：「上古時代的畜生全都能說人話，這是因為在世界劫初之際，最初只有人道與天道，還沒有三惡道眾生，後來的畜生都是從人道與天道墮落而來的，憑藉往昔的宿世習氣所以能說話。現今的畜生多半是從三惡道流轉而來，所以就不會說人話了。」

【311-0015】02_戒疏/16b_卷四上之一#45
【原文】【記】釋緣起中。初分文。注「斷事人」，即能斷諍者。「牡牛譬」者，《律》因剎尸國婆羅門有牛，與國中長者牛鬪力，共駕百車，賭金千兩。時婆羅門於眾人前作毀呰云：「一角可牽。」牛即不肯出力，長者牛勝，輸金千兩。婆羅門責問，牛即答云：「汝於眾人前毀我故爾。若改往言，當更與鬪，賭金二千兩。」時婆羅門於眾人前贊言「端正好角」，於是得勝。佛言：「畜生得毀，猶自慚愧，況復於人。」、「論」下，次引《多論》，決上畜生能語之意。
【譯文】【記文】解釋緣起之中。首先劃分經文段落。註文所說「斷事人」，就是指能夠調停斷絕爭端的人。「牡牛的譬喻」，《四分律》記載是因為剎尸國的一位婆羅門養了一頭牛，與城中長者的牛比賽力氣，共同拉動一百輛車，以黃金一千兩作為賭注。當時婆羅門在眾人面前辱罵貶低說：「這隻獨角牛可以拉了。」牛聽了便不肯用力，結果長者的牛勝出，婆羅門輸了一千兩黃金。事後婆羅門責問牛，牛回答說：「那是因為你在眾人面前羞辱毀謗我，所以我才這樣。如果你能改掉先前的話，應當再去跟他們比賽，賭注兩千兩黃金。」當時婆羅門便在眾人面前讚歎說這是一隻「端正美好的角牛」，結果贏得了勝利。佛陀說：「畜生受到毀辱謾罵，尚且懂得慚愧生怨，更何況是人呢？」從「論」字以下，接著引述《薩婆多論》，解決前面關於畜生為什麼能夠說話的疑問。

【311-0021】02_戒疏/16b_卷四上之一#51
【原文】【註】若說善法而面罵者，言「汝是阿蘭若」乃至「坐禪」；若喻罵者，言「汝似坐禪」也；若自比罵者，言「我非」也——說了、不了，並吉羅。尼墮，三眾吉羅。不犯者，相利故說，為法、為律、為教授故，為親厚故，或戲，或失口，或錯誤者是。
【譯文】【註文】如果用稱讚善法的方式來當面謾罵，說「你是個住阿蘭若的」乃至說「你是個坐禪的」；如果是用比喻的方式謾罵，說「你就像個坐禪的」；如果是拿自己相比來謾罵，說「我可不是那種人」——無論說得清楚與否，全都結突吉羅罪。比丘尼犯此戒結波逸提墮罪，辱罵下三眾則結突吉羅罪。不犯的情況是：為了對方的利益而說，為了闡揚佛法、維護戒律、為了教誡訓導的緣故，為了情誼親厚深重的緣故，或是開玩笑，或是無心失口，或是口誤說錯話的，都屬於不犯。
