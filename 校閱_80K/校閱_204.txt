# 校閱材料　第204檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【204-0001】03_業疏/11a_卷二之五#74
【原文】大乘戒學中初科，初標示三品，即是三聚，出瓔珞經：一、攝律儀戒，律儀禁惡，即斷惡也；二、攝善法戒，即修善也；三、攝眾生戒，亦名饒益有情戒，即度生也。小乘則隨緣別制，大教則依心總結，故以三戒通攝一切，故名為聚。是故斷惡則無惡不斷，修善則無善不修，攝生則無生不度。且舉大略，餘廣如後。「約下」二、對小乘以明同異。初、性戒明義同。且舉殺戒，餘並例作：如婬息諸染緣，常修梵行，不汙前生；如盜則離侵損緣，常行惠施，不惱前生；如妄則離虛妄緣，常行實語，不誑前生；下至眾學，條條類說，無非三聚。若準智論，聲聞戒但有斷惡一聚，既不度生，不習方便，無餘二聚。今用大意決於小宗，約義明同，莫不齊具。「非下」次明遮戒或異。地持云：「若菩薩有檀越以金銀等寶物奉施菩薩，以瞋恨心違逆不受，即名為犯，由捨眾生故。」小乘則制畜捉，故云開制異也。且略舉之，必欲通知，須將善戒、梵網對下六聚，則同異可見
【譯文】大乘戒學中的初科，首先標示三品，也就是三聚淨戒，出自《菩薩瓔珞本業經》：第一是攝律儀戒，律儀是用以禁止惡行，也就是斷除一切惡法；第二是攝善法戒，也就是修行一切善法；第三是攝眾生戒，也稱為饒益有情戒，也就是度化一切眾生。小乘是隨順犯事的因緣而個別制定戒條，大乘教法則是依據發心進行總相結戒，所以用這三種戒通攝一切戒行，因此稱之為「聚」。所以斷惡就是沒有任何惡法不斷除，修善就是沒有任何善法不修持，度生就是沒有任何眾生不救度。這裡暫且舉其大綱，其餘詳細內容見於後文。自「約下」以下，第二是比對小乘來闡明同異。首先，就性戒闡釋義理相同。疏中暫且舉殺戒為例，其餘戒條皆依此類推。（今例作如下：）例如不婬戒，止息一切染污因緣（攝律儀），常修清淨梵行（攝善法），不染污對方眾生（攝眾生）；例如不偷盜戒，遠離侵損他人財物的因緣（攝律儀），常行布施惠濟（攝善法），不惱害對方眾生（攝眾生）；例如不妄語戒，遠離虛妄欺詐的因緣（攝律儀），常行真實言語（攝善法），不誑騙對方眾生（攝眾生）；下至眾學法等戒，條條依此分類解說，無非三聚淨戒。如果依照《大智度論》，聲聞戒只有斷惡這一聚，既然不度化眾生，也不修習權巧方便，就沒有其餘兩聚。如今運用大乘的深意來融決小乘宗義，從義理上闡明其相同之處，便無不平等齊備。自「非下」以下，其次闡明遮戒在開遮上有所不同。《菩薩地持經》說：「如果菩薩遇到施主以金銀等珍寶布施菩薩，菩薩若以瞋恨心違逆拒不受納，即算犯戒，因為捨棄眾生的緣故。」小乘則制定禁止蓄積抓持金銀，所以說在開許與限制上有所不同。這裡暫且略舉一二，若想通達了知，必須將《菩薩善戒經》、《梵網經》對比下文所說的六聚戒法，那麼其間的同異之處就顯而易見了。

【204-0002】03_業疏/11a_卷二之五#75
【原文】然菩薩有二，謂在家、出家。出家菩薩，形位同諸聲聞。智論中文殊、彌勒在比丘中，依夏坐也。故涅槃中白四所受，息世譏嫌，性重無別。浮囊多少，即譬五篇，度生死海，雖乞不與。又如攝論：「菩薩得無分別智，一切塵不顯現，由勝智方便，具行殺生等事，有利益故，自無染過；縱有利益，有過不行。」此明大乘之人出家戒也。在家菩薩，如淨名說
【譯文】然而菩薩有兩類，即是在家菩薩與出家菩薩。出家菩薩的外形與僧位都與諸聲聞相同。《大智度論》中文殊師利菩薩、彌勒菩薩列在比丘僧眾之中，依照戒臘安居坐夏。所以在《大般涅槃經》中，由白四羯磨所受的戒法（受同），持息世譏嫌戒（遮戒）與持性罪重戒（性戒）無所差別、平等堅持（隨同）。經中以索乞浮囊分量的多少，來比喻五篇罪相的輕重，欲度越生死苦海，哪怕羅剎乞討微塵許的浮囊，也堅決不給。又如《攝大乘論》說：「菩薩證得無分別智，一切妄塵境界皆不顯現，由於具備殊勝智慧與善巧方便，即使行持殺生等事，若能帶來大利益，自身便無染污之過失；即使有利益，但若自身會生過失，也是不能去做的。」這是說明大乘行人的出家戒法。至於在家菩薩的戒行，則如《維摩詰經》（淨名經）中所說。

【204-0003】03_業疏/11a_卷二之五#76
【原文】次科，初通標。「出下」次別釋。前明出家菩薩有三：初、明形位同。他方諸佛多有聲聞、菩薩二種僧，不相參混；其菩薩僧不局形體。唯釋迦佛但有聲聞僧，不立菩薩僧，故諸大菩薩影響施化，皆須剃染稟戒，所以形位同聲聞也。此據一類機緣所見，然菩薩作用，不必常爾。故下二、明受隨同。「息世譏嫌」即諸遮戒，「性重無別」謂性遮等持也。浮囊多少者，彼明人欲渡海而須浮囊，有羅剎問乞，初全乞不與，次乞一半，三乞掌許，四乞指許，五乞微塵許，喻三毒欲犯五篇而皆不與，即喻堅持也。又下三、明急護同。無分別智，謂觀諸法如實平等故無分別，唯一真體，外塵本無故塵不顯現，亦名如理智，初地已上始得用之。方便即權巧。殺生等者，即十惡也。有利益者，謂利他也；自無染者，謂自利也；具此二利，雖行無犯；互有所缺，亦不行之，故云「縱有」等。今時愚人不量位地，不知權行，作惡無耻，妄引為例，自誤誤他，難可救也。後明在家菩薩，指淨名經。彼云：「雖為白衣，奉持沙門清淨戒行；雖處居家，不著三界；示有妻子，常修梵行；現有眷屬，常樂遠離；乃至入諸婬舍，示欲過等
【譯文】次科中，首先作總相標明。自「出下」以下，其次分別解釋。前段說明出家菩薩有三點：第一、說明形象與地位相同。他方世界諸佛大多有聲聞僧與菩薩僧兩種僧團，彼此不相混雜；菩薩僧團並不局限於出家形貌。唯獨釋迦牟尼佛的娑婆世界只有聲聞僧團，不另外設立菩薩僧團，所以各大菩薩作為影響眾施行教化時，都必須剃除鬚髮、身著染衣而稟受戒律，因此形象與地位和聲聞相同。這是依據一類眾生的機緣所見而論，然而菩薩的示現作用，未必恆常如此。自「故下」以下，第二說明受戒與隨行相同。「息世譏嫌」就是指各條遮戒，「性重無別」是指性戒與遮戒同等堅持。所謂「浮囊多少」，是彼經說明有人想要渡過大海必須依賴浮囊，途中有羅剎前來乞討浮囊，起初乞討整個浮囊，人不給；次而乞討一半，也不給；第三次乞討手掌大小的一塊，不給；第四次乞討手指大小的一點，不給；第五次乞討微塵般大小的一點，依然不給；這比喻三毒煩惱引誘去違犯五篇戒相，而修行者絲毫也不違犯，即是比喻堅決持戒。自「又下」以下，第三說明緊要急迫護持相同。所謂「無分別智」，是指觀察一切諸法如實平等，因而沒有凡夫分別，唯有一真法界本體，外在妄塵本來虛妄，所以塵境不顯現，也稱為「如理智」，初地以上的菩薩才開始能夠運用。方便就是指權巧智慧。「殺生等」，就是指十惡業。「有利益」，是指能利益他人；「自無染」，是指自己無有貪染過失；具備這兩種利益，雖然行作也無有犯戒過咎；如果互相缺少了一項，也是絕不施行的，所以說「縱有利益」等。如今世上的愚昧之人，不自量自己的修行果位，不懂得權巧方便的深意，作惡無恥，胡亂引證這段話作為自己的藉口，自誤誤他，實在難以救藥！最後說明在家菩薩，指引《維摩詰經》（淨名經）。該經說：「雖然是在家人身分，卻嚴謹奉持沙門的清淨戒行；雖然生活在居家環境，卻不貪著三界凡塵；示現娶妻生子，卻常修清淨梵行；示現擁有眷屬，內心卻常樂遠離；乃至走入各處淫舍妓院，只為示現愛欲的過患」等。

【譯文】律文中列出「生像（生色似色金銀）」，古人曾說世間具有人形或牲畜形狀的玩樂道具不可捉持，如同律中所制定的不可拿持樂器也是此類比況。然而《僧祇律》中所說的「生色」，是指黃金；「似色」，是指白銀。「似」就是「像」，是白銀的另一種名稱。疏文梵語與華語並舉，是為了讓大家都能明白通曉其深意；「金」、「色」都是漢土華夏之語，梵語本名中說銀，就如同此處「似」、「像」之稱呼而已。

【204-0107】03_業疏/11b_卷二之五#74
【原文】次科，初出古解，彼逐言相，謂是眾生形像，故如下示今釋。初縱古，善見云人施樂器不得捉得賣。「然下」顯今，初引據。生色謂生有瑩彩，似色謂似近於金。似即像者，會字義也。「梵下」釋今文生像，是翻梵金銀即唐言，意令通曉，所以雙標。「即下」會通二律名義無別
【譯文】在第二科中，起初列出古人的解釋，古人拘泥於字面言相，以為是指眾生的形體偶像，所以才如下文示明當今的正解。起初姑且順應古解，《善見律》說有人布施樂器，比丘不得捉持但可以變賣。自「然」字以下顯明今解，首先引述律文依據。「生色」是指天生具有晶瑩光彩，「似色」是指顏色近似於黃金。「似即像」，是融會貫通字義。自「梵」字以下解釋疏文（戒文）中的「生像」是譯自梵語，「金銀」則是唐土漢語，用意在於令人完全通達明曉，所以兩者雙雙標列。自「即」字以下融會貫通兩種律本，說明其名稱義理並無差別。
