# 校閱材料　第882檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【882-0001】03_業疏/17b_卷三之六#48
【原文】三辨行事，斥世中初文。初通斥，「故下」別列。年末受學，正朝進具，即以兩日以當二歲。應作四句：一、年缺行具；二、行缺年具；三、年行俱缺；四、年行俱具。忽不行者，謂慢教也
【譯文】第三、辨明如法行事，在斥責世俗弊病的初文中，首先總體斥責；自「故」字以下逐一列舉。所謂歲末受法、元旦就進受具足戒，就是把跨年的短短兩天當成了兩年。此處應當作成四句分別：第一、年限有缺而戒行具足；第二、戒行有缺而年限具足；第三、年限與戒行兩皆殘缺；第四、年限與戒行兩皆具足。所謂「忽而不行」，是指輕慢戒律教法而不切實奉行。

【882-0002】03_業疏/17b_卷三之六#49
【原文】亦有一師當白四法都盧成就謂沙彌尼六法本法及大戒也相共召之名㮯樸戒不知何出此復何論
【譯文】又有一位律師主張，應當只用一次白四羯磨就「都盧」（全部一併）成就，也就是將沙彌尼戒、六法、尼本法以及大僧具足戒合在一起受，大家共同稱呼這種戒為「㮯樸戒」（混然未分的質樸之戒）；不知這種做法出自何典，這又有什麼可論取的呢？

【882-0003】03_業疏/17b_卷三之六#50
【原文】次科，尼中四法：一、白四受，故云「都盧」，此即方俗之語，猶言一併也。「㮯」音混，「樸」音朴。彼謂但一法受，㮯成樸質，不須更分漸次多端也。「不下」正斥，上句斥無所據，下句明無可取
【譯文】下一科中，比丘尼應受的四種法：僅以一次白四羯磨而受，所以說「都盧」，這就是方言俗語，相當於說「一併、全都」。「㮯」字音讀如混，「樸」字音讀如朴。那位法師認為只要通過一種受法，混然合成質樸的全體，不需要再區分多種繁複的漸次階位。自「不知」以下正面斥責，上一句斥責其毫無經典依據，下一句說明其做法完全沒有可取之處。

【譯文】下一科在揀除非法以顯正理中，首先列舉種種非法，「受有缺者」即是指戒行有缺；自「諸」字以下總體判定，既然沒有沙彌尼直接受大戒的道理，所以依例判定受戒不能成就。

【882-0008】03_業疏/17b_卷三之六#55
【原文】若爾，沙彌不受，得受戒者？答：不同也。一、無文開尼受已得具；二、男氣剛正，有秉持故；三、為女弱不能持戒，故生一位以為行本。今無本行，何得後受？四者，男無可試身胎，故不限於時月；女則反前，故須具學
【譯文】如果這樣的話，男眾沙彌即便沒有受沙彌戒，受具足戒也能得戒，這又如何解釋呢？回答：這兩者是不同的。第一、律文中沒有任何明文開許比丘尼跳過式叉階位受戒後能得具足戒；第二、男子之氣質剛烈端正，具有持守戒律的秉受力；第三、因為女人性格怯弱無法直接持守大戒，所以特別創立式叉摩那這個位階作為持戒的行持根本，如今若是沒有這個根本行持，如何能進受後面的大戒？第四、男子沒有需要查驗的身孕胎患，所以不受年月時間的限制；女子則與此相反，所以必須圓滿兩年的修學。

【882-0009】03_業疏/17b_卷三之六#56
【原文】釋妨，問中：沙彌不受十戒，直得具足，但僧得小罪，那與式叉不同？答中：初合總合；「一下」別示，有四：初即反顯沙彌有文開故；二顯男位，開則有益；三明沙彌蹤闕五十，能以具戒即為行本，尼則不然，故加此位；四則易見，準知頓受唯許僧中，不開尼眾。問：不受五十，直受六法，得不？答：式叉以十戒為體，若容直受，則無所依，故不可也
【譯文】在釋難之中，問句的意思是：沙彌若是沒有受十戒而直接受具足戒，受戒依然有效，只是傳戒僧眾獲小罪，為什麼與式叉摩那的情形不同呢？回答中：開頭一句總體作答；自「一」字以下分別說明，共有四點：第一就是反顯僧律中有明文開許沙彌頓受的緣故；第二顯示男眾之位，即使開許頓受也有持戒利益；第三說明沙彌縱然缺少了五戒與十戒，也能直接以具足戒作為戒行根本，而尼眾則不能如此，所以必須增加式叉此位；第四點則很容易明白，由此可知頓受具足戒只開許在僧中，不開許在尼眾。問：如果不受五戒、十戒，直接受六法，可以嗎？答：式叉摩那是依十戒為戒體的，如果容許直接受六法，戒法就無所依傍，所以是不可以的。

【882-0010】03_業疏/17b_卷三之六#57
【原文】今約上文，十歲、十八二女受學，年滿受具者，義須推之。如十八式叉年初即受，明年十九，後年二十，正滿兩周，得戒定也。如是正月二日乃至臘月晦日，皆得受具，可獨在於正月元日也？不妨最小式叉臘月盡日受學法者，猶是十八年內，沙彌尼受法得一日也。至明日歲初，為年十九，一周學之後，年二十與受大戒，判言為得，不違教相，驗胎身淨，豈與前減同日而言哉
【譯文】如今依照上文所說，曾嫁之十歲女童與十八歲童女受六法學戒，年滿之後受具足戒，在義理上必須仔細推敲：如果十八歲的式叉摩那在年初就受法，第二年滿十九歲，第三年滿二十歲，剛好滿兩整年，得受戒體是毫無疑義的。照這樣推算，若在正月初二乃至十二月最後一天受學法，（年滿時）也都得受具足戒，難道（受學法）只能單單限定在正月初一嗎？這也不妨礙受學期限縮至最少的式叉摩那在十二月的最後一天受學戒法，雖然是在十八歲之內，沙彌尼受法只有一天；到了次日歲首，年齡便算作十九歲，經過滿一整年的修學之後，二十歲那年為她傳授大戒，判定為可以得戒，這並不違背律教之相，因為已經歷經了一年，足可查驗身無胎患而清淨，這哪裡能和前面所斥責的「兩天充當兩年」相提並論呢？

【882-0011】03_業疏/17b_卷三之六#58
【原文】今義中，初通標；「如下」別舉。初明：年月俱滿；「如是下」次明：年滿日月不滿。最小之者，實行一年一日，以臘月盡日即當一年，不違教者，年數滿故；可驗身胎，以經年故。「豈下」異古，「前減」即上所斥。然今雖減，與古全乖，不同日而言者，言與彼異也
【譯文】在闡述今時義理中，首先通體標明；自「如」字以下分別舉例說明。首先說明：歲數與月份日期皆圓滿；自「如是」以下接著說明：歲數雖滿而日月天數未全滿。受學期限最少者，實際上修學了一年零一天，把十二月最後一天算作了一年，之所以不違背教律，是因為名義上的年數已滿；而且可以查驗身孕胎相，是因為畢竟已經歷經了一整年。自「豈」字以下說明與古說不同，「前減」就是前面所斥責的弊端。然而現在這種減省日數的情況，與古德之妄減完全不同，所謂「豈同日而言」，是說兩者本質完全有別。

【882-0012】03_業疏/17b_卷三之六#59
【原文】彼不行者，及至受時，僧問：「滿不？」尼徒無媿，唱言：「滿淨。」自誑不了，用受何為？況面奉佛口，行虗詐，何遽此急，恐失聖耶？然彼聖果，非虗言之所得矣。誡之哉
