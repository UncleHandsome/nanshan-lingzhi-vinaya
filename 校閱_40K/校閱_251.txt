# 校閱材料　第251檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【251-0001】資持記/05d_上四#40
【原文】止下，勸依後法。問得否者，為破古解。疏云：有人定判依受夏破是也。答言無失者。疏云：增乞減乞，各有所憑；羯磨大途規模在故，依受不失。〔意詳不無非法之罪。〕第四師者。疏云：近世諸師不加乞詞，依本直誦。〔即同疏序云：即今一家依本直誦也。
【譯文】從「止」字以下，勸勉應依循後面的如法程序。問及作法是否成就，是為了破除古代的偏狹見解。疏中說：有人斷定依此受法會破夏，即指此而言。回答說並無過失。疏中說：增添乞詞或減少乞詞，各有所依憑；羯磨大體上的綱要規準依然具備，所以依此受法不致破夏失夏。〔深究其意，恐怕仍不免違犯非法的輕罪。〕第四位律師。疏中說：近代的諸位律師不添加乞求詞，直接依照律文原本誦讀。〔正如同疏文序言所說：現今我們一家便是依照律本直接誦持。

【251-0002】資持記/05d_上四#41
【原文】舊指願師本者，且願出北齊，則非近世。問：前四中不列曇諦本者？答：同光師故，不復出之。問：既除乞詞，羯磨緣中應無正陳本意？答：疏明古師立緣增減，謂受日無乞，闕第八緣；祖師難云：受日無乞，豈不須告！
【譯文】舊說指這是願律師的本子，然而願律師出身北齊，絕非近代人。問：前面四家中為何未列出曇諦的本子？答：因為與光律師的本子相同，所以不再重複列出。問：既然刪除了乞求詞，羯磨的陳因中豈不是沒有正式陳述其最初心願？答：疏中說明古德確立因緣的增減，認為受日法沒有乞詞，便是欠缺了第八種因緣；祖師難斥說：受日縱無乞詞，難道不需要預先告白嗎！

【251-0003】資持記/05d_上四#42
【原文】準此，合行事時，受者應具儀至僧中告云：比丘某甲欲受十五日〔若一月日〕出界，為某事故，還來此中安居。白已，方可加法。〔此為諸文多違，後進難曉，不免繁長。〕一月法中。不得雙誦者，以律本中不別出法。於十五日下，連書一月；翻譯省文，意令隨改；往往愚者依文謹誦，故此遮之；
【譯文】依照此理，在應當行事的時候，受法者應當具備威儀來到僧中告白說：「比丘某甲想要受十五日〔或一個月〕出界，為了某事情的緣故，還會回到此處安居。」告白完畢之後，才可以正式加法。〔這是因為諸多文獻相互違背，後輩學人難以通曉，故不免敘述繁冗冗長。〕一月法之中。不得重疊雙誦，是因為律本中沒有另列作法。只是在十五日之下，連續書寫一個月；這是翻譯時省略文字，本意是讓人隨情況更改；往往愚昧的人拘泥於文字而直接連誦，所以在此嚴加遮止；

【251-0004】資持記/05d_上四#43
【原文】疏云則四十五日故也。疏又問云：受一月不云過半月者？解云：七日別人，餘皆眾法；但云過七日，明知餘二俱白二也。又云：若受半月，數日滿足，以加法云十五日故；若受一月，則隨大小。私謂，若從初一受則可隨月，或中間受而遇小月，如何數之？準亦依小得二十九日，以受月故。
【譯文】疏中說那樣誦讀就會變成四十五天了。疏中又提問說：受一月法為何不說「過半月法」？解釋說：七日法屬於個別對首法，其餘都是僧團眾法；律文只說「過七日」，由此明知其餘兩種都是白二羯磨。又說：如果受半月，日數是固定的足數，因為加法中明說「十五日」；如果受一個月，則隨月份的大小天數而定。我私下認為，如果是從初一受法，則可以順隨當月天數，若是在月中受法而遇到小月，該如何計算？照理也是依照小月得到二十九天，因為是受一個「月」之故。

【251-0005】資持記/05d_上四#44
【原文】〔如十六日受，至月盡止，得十四日，後更數十五日耳。〕三料簡中。通明受日安居差別之義，故云雜也。初科。夏熱即餘緣，此且略舉，餘例開之。須同緣者，牒事便故，異緣不得。下指所出。然與《四分》受戒頗同，亦可例準。依處中，依界。可解。依藍中，初文。
【譯文】〔例如十六日受法，到月底只有十四天，之後再補數十五天即可。〕第三雜料簡中。全面闡明受日與安居之間的相異與相通之義，所以稱為雜明。第一科。「夏天酷熱」是指其餘因緣，這裡只是略舉一例，其餘情況依此開許。必須是相同的因緣，是為了複述事情時更為順暢，不同因緣則不可混用。下文指明法條的出處。然而這與《四分律》受具足戒的作法頗為相通，也可以依此比照。在依靠住處中，依靠界限的情況，文義容易理解。在依靠寺院（伽藍）中，第一段文字。

【251-0006】資持記/05d_上四#45
【原文】即前云：結夏在前，結界在後，故云先無也。二界，即大界戒場。言離衣者，此據作法攝衣為言，自然亦不失也。次科。云本結者，明先有界也。言佛制者，比丘住處，佛制必先結界，制令依界明矣；伽藍有緣未及結界，或依村舍等處，可依自然。若僧坊有界，定須依界；
【譯文】這就是前面所說的：結夏在先，結界在後，所以說先前未曾結界。所謂「二界」，即是指大界與戒場。說到「離衣」，這是依據作法攝持衣物而言，在自然界中本來也不會失衣。下一科。說到「本來所結」，顯明先前已經設有界限。說到「佛陀制令」，比丘的住處，佛陀規定必須先結界，制令必須依據界限，這是顯而易見的；若寺院有特殊因緣來不及結界，或者依附村落居舍等處，才可以依據自然界。如果僧團精舍已有大界，必定必須依據界限；

【251-0007】資持記/05d_上四#46
【原文】今人行法，有界之處，令依藍結；則餘場小，往返無妨；意謂依藍依界，隨人所欲，反謂此文是順古義〔從前至此三處出此義，並指為古，謬之太甚。〕；後學無知，皆隨盲導，何可救也。言却縮者，捨寬藍，從狹界，得教意故。下指廣者，疏明先本無界依藍結者；
【譯文】現今的人行法，在有大界之處，卻令人依據寺院自然界去結夏；這樣戒場範圍就狹小，往返不會有妨礙；自以為依據寺院或依據界限，可以隨人之意願，反而聲稱本鈔這段文字是順從古人的見解〔從前到此處共有三處提出此義，都指為古說，荒謬到了極點。〕；後學無知，都盲目隨從錯誤引導，如何能加以挽救呢！說到「卻縮」，是指捨棄寬廣的寺院自然界，順從狹小的大界，這才契合教誡的本意。下文指示詳論者，疏中說明先前本無結界而依寺院結夏的情形；

【251-0008】資持記/05d_上四#47
【原文】後云：立心行者行護從急；若後作法遠於自然，但依自然分齊；既無緣難，不可後開；若結狹本有說依新〔他解〕，意以安居隨本自然為定；由本作法意在羯磨，安居隨處，不要加結。〔古記見此，便謂先有界處，亦不須依界，誤矣。〕結指中。點上所判。
