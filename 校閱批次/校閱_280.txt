# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【280-0001】02_戒疏/15a_卷三下之三#5
【原文】【疏】何以制者？凡出家之人，理須息務靜坐修道，何得躬自販博，馳騁市肆，動越威儀，招世譏醜？又錢財既交，事容犯重，可懼之甚，義須早制。《多論》四義：「一、為佛法增上故；二、為止鬪諍故；三、為成四聖種故；四、為長信敬，不誹謗故。」
【譯文】【疏文】為什麼要制定這條戒呢？大凡出家之人，按理應當放下俗務，靜坐修習道業，怎麼可以親自從事販賣博易，奔走於街市店鋪之間，舉手投足都違背了出家威儀，招致世俗之人的譏嫌與醜態呢？而且既然涉及金錢財務的往來交接，事情就極有可能演變成觸犯偷盜等重罪，這是非常令人恐懼的，所以依照義理必須儘早制戒防範。《薩婆多論》提出了四種制戒意義：「第一、為了使佛法更加增上；第二、為了止息爭端與爭論；第三、為了成就依止知足的四聖種；第四、為了增長信眾的信敬，使其不生誹謗之心。」

【280-0002】02_戒疏/15a_卷三下之三#6
【原文】【記】制意中。初約義明，有二：初約乖道意，次約防盜意。「多」下，二、引文示。《論》中四義，初即住持，二即滅惡，三、生善，四、兩兼。
【譯文】【記文】在制戒意圖的部分。首先依循義理說明，分為兩點：第一是說明此舉違背修道的本意，第二是說明防範犯下偷盜的意圖。「薩婆多論」以下，第二部分是引用文獻予以說明。論典中所提的四種意義：第一項是為了住持佛法，第二項是為了止滅惡行，第三項是為了生起善法，第四項則是兩者兼具。

【280-0003】02_戒疏/15a_卷三下之三#7
【原文】【疏】六緣成犯：一、在俗二眾；二、相貿；三、決價；四、為己；五、自貿易；六、受，犯。
【譯文】【疏文】具備六種條件即構成犯罪：第一、交易對象是在家的男女二眾；第二、互相交換買賣；第三、議定價格；第四、是為了自己；第五、親自進行交易；第六、接受所得物品，即構成犯罪。

【280-0005】02_戒疏/15a_卷三下之三#9
【原文】【註】佛在舍衛國。時，跋難陀往無住處村，以生薑易食，食已持去。舍利弗後至乞食，檀越以跋難陀事徵之，慚愧無言。又共外道博衣，悔而不得。比丘舉過，佛因制戒。
【譯文】【註文】佛陀在舍衛國時。當時，跋難陀前往沒有僧寺的村落，用生薑換取食物，吃完後還把剩餘的帶走。舍利弗隨後抵達該處乞食，施主便拿跋難陀的事情來質問他，使他感到慚愧而無言以對。此外，跋難陀又與外道交換衣服，事後外道反悔想要回，他卻不肯歸還。比丘們向佛陀檢舉他的過錯，佛陀便因此制定了這條戒律。

【280-0006】02_戒疏/15a_卷三下之三#10
【原文】【疏】就戒緣起中，分二：初以衣食起過，後舉過訶制。前又分二：初至「慚愧無言」已來，明跋難陀生薑易食緣；二、「又共外道」，即明此人貿衣過起。前中，由跋難陀易食，致比丘法猥濫不行，謂非乞食之士，及舍利弗後乞，即以前事徵之，致使尊者無言也。
【譯文】【疏文】關於此戒的緣起部分，分為兩段：首先是因飲食和衣服而引起過失，其後是僧眾檢舉過失並由佛陀訶責制戒。前半部分又分為兩段：從開頭到「慚愧無言」為止，是說明跋難陀用生薑換取食物的緣起；第二段「又與外道」起，就是說明此人交換衣服而引發過失。在前半段中，由於跋難陀用物品換取食物，導致清淨的比丘法度變得雜亂而無法推行，令人以為出家人不是依止乞食，等到舍利弗後來去乞食時，施主就拿先前跋難陀的事來質問，以致尊者慚愧無言。

【280-0007】02_戒疏/15a_卷三下之三#11
【原文】【記】戒緣中。初分文，「前」下，牒釋。注中，初明貿食緣，「無住處村」，即無伽藍也。「食已持去」，謂持餘食去。「猥濫」，「猥」即是雜。時至乞食，清淨活命，是「比丘法」，彼以物易，令法雜濫。「以前事徵」者，索物易也。次明貿衣緣。《律》因外道將一好衣入祗桓求易，跋難陀以故衣修治如新，與彼博之，外道尋悔，陀遂不還，呵罵而去。
【譯文】【記文】在戒律緣起的部分。首先分析文句段落，「前半部分」以下，是提撕並解釋。註釋中，先說明換取食物的緣起，「沒有住處的村落」，就是指沒有寺院的村莊。「吃完後帶走」，是指把剩下的食物帶走。「雜亂」，「猥」就是雜亂的意思。到了乞食時間去乞食，過著清淨的活命生活，這才是「比丘法度」，跋難陀卻用物品去交換，讓這項法度變得混雜紊亂。「拿先前的事質問」，是指向尊者索取物品來交換。接著說明交換衣服的緣起。《四分律》中記載，起因是外道拿著一件好衣服進入祇園精舍尋求交換，跋難陀把舊衣服修整得如同新的一樣，拿去跟對方交換，外道隨即反悔，跋難陀卻不肯歸還，外道便呵斥謾罵後離去。

【280-0016】02_戒疏/15a_卷三下之三#20
【原文】【疏】二、「種種」者，文不顯也。此與前戒言詞不分，要須注解，方顯兩戒。此初譯人之過也。縱佛本言，必不如此，結集傳之，亦須從俗。故佛言令人易解為要，今多列「種種」，深叵知矣。
【譯文】【疏文】第二句「各種各樣」，正文的表述並不明顯。這句話與前一條戒律的詞句沒有分別，必須依賴註釋，才能凸顯這兩條戒律的差異。這是最初翻譯者的過失。縱使佛陀當初開示時，也絕不會如此含混，結集傳誦這部律典時，亦應當順應世俗通用的語言習慣。所以佛陀教導應以讓人容易理解為首要原則，現在這裡大多只列出「種種」二字，實在深奧而難以知曉。

【280-0017】02_戒疏/15a_卷三下之三#21
【原文】【記】戒本，第二，釋文中。初示翻文混漫。言「此初」者，謂當本翻譯不詳也。「縱」下，推本不然。一以佛語明顯，二則結集隨時，必無混濫。「故」下，引證。即如《母論》：「比丘說法，佛聽引要言妙詞直顯其義。」故知但欲「令人易解」。今反難解，故云「深叵知」等。
【譯文】【記文】在戒本第二句的解釋文句中。首先指出翻譯文本的含混不明。說「這是最初」等語，是指該底本翻譯時不夠詳盡。「縱使」以下，推論佛陀原本的說法並非如此。其一，因為佛陀的話語一向清晰明白；其二，結集經典時必然隨順當時語言，絕不會混亂不清。「所以」以下，引證說明。正如《毘尼母論》所言：「比丘說法時，佛陀准許採取精要的文詞與巧妙話語，直接彰顯其義理。」由此可知，本意只在於「讓人容易理解」。現在反而晦澀難解，所以說「深奧而難以知曉」等。

【280-0022】02_戒疏/15a_卷三下之三#26
【原文】【疏】注解之中，初總明相，故云「一錢」。「數上下」者，此是「販」之異耳。言「增賣」者，本賤索貴也。「買亦如是」者，本貴買賤也。本實直五錢，減買言直三錢。重減買者，本直五錢，言直一錢。
【譯文】【疏文】註釋當中，一開始是總體說明交易的行相，所以說「一錢」。「頻繁上下調整」這句話，是屬於「販」的另一種表現方式。所說的「抬高價格售賣」，是指原本低廉的物品卻索求高價。「壓低價格收購也是如此」，是指原本昂貴的物品卻壓低價格購買。原本確實價值五錢，減價購買時謊稱只值三錢；嚴重壓低價格收購的情況，是原本價值五錢，卻謊稱只值一錢。

【280-0023】02_戒疏/15a_卷三下之三#27
【原文】【記】釋注中。初釋一錢，云「總明相」者，該下三位故。「數」下，次釋三位。初釋「販」中，言「上下」者，或隨時貴賤加減價直，或對人交貿進退論量。正是販易，而言相不同，故云「異」也。次賣、後買，示相甚明。
【譯文】【記文】在解釋註釋的部分。首先解釋「一錢」，說「總體說明行相」，是因為這句話涵蓋了接下來的三種身分行為。「頻繁」以下，接著解釋這三種身分行為。在最初解釋「販」的內容中，說到「上下調整」，是指或者隨時局物價的貴賤而加減其價值，或者面對交易對手時進退討價還價。這正是販運貿易，只是表現的形式有所不同，所以說是「另一種表現」。接下來解釋「賣」，最後解釋「買」，所展示的相狀非常清楚明確。

【280-0024】02_戒疏/15a_卷三下之三#28
【原文】【疏】《多論》云：「此販賣物，若無同心淨人，應作四方僧臥具。若入佛者，外道謗言『瞿曇沙門多貪利故，令弟子捨物持用自入』。又除佛福田，無過四方僧，不問邪正、持戒破戒，一切無遮。」
【譯文】【疏文】《薩婆多論》說：「這些因販賣而得的物品，如果沒有心志相通的淨人可以託付，應當充作十方常住僧眾的臥具。如果收歸佛寶所有，外道就會誹謗說『沙門瞿曇因為非常貪圖利益，所以讓弟子捨棄物品拿來收歸自己受用』。此外，除了佛寶這塊福田之外，功德再也沒有超過十方常住僧眾的了，這裡不論正邪、持戒或破戒，一律平等接納而沒有遮阻。」

【280-0025】02_戒疏/15a_卷三下之三#29
【原文】【記】釋第三中，初文。《多論》「永捨入僧」，如上已示，復申不入佛寶之意。初明杜絕譏謗，故不入佛。「瞿曇」，即召如來，過去師瞿曇仙，因此為氏。「又」下，次顯僧福最勝，故捨入僧。
【譯文】【記文】在解釋第三段之中，此為第一部分經文。《薩婆多論》提到「永遠沒收歸於僧眾」，如前文已經說明，這裡再次陳述不收歸佛寶的原由。首先說明為了杜絕外道的譏嫌誹謗，所以不納入佛寶。「瞿曇」就是用來稱呼如來，因為過去世的師長是瞿曇仙人，便以此作為姓氏。「此外」以下，其次顯明僧眾的福田最為殊勝，所以要沒收充歸僧眾。

【280-0026】02_戒疏/15a_卷三下之三#30
【原文】【疏】據此文相，《四分》所明，但有衣藥。衣有同類，可如常捨。藥則穀米，治生收利，如是不淨，其相如《鈔》。準《論》穀米，俗人為主。若無同心，可依《論》斷。
【譯文】【疏文】依據此處的文句行相，《四分律》所指明犯戒的物品，只有衣服和藥物。衣服有同類物，可以按照常規作法捨交給僧眾。至於藥物則是穀米之類，若用來經營謀生以獲取利益，這類不淨物品的處理方式，其具體行相如同《事鈔》所說。依照論典的規定，穀米應當由俗人作主掌管。如果沒有同心互信的俗人，便可依循論典的判定來處理。

【280-0027】02_戒疏/15a_卷三下之三#31
【原文】【記】次科，為二。初明犯物。《四分》「衣藥」，即如注列。衣對僧捨，故云「同類」。「藥」有四種，且論時藥，「治生收利」，有犯販賣，須明捨相。指「如《鈔》」者，彼引《五百問》「治生道人得物犯捨」等。「準」下，二、正判。上約有淨主。《多論》「穀米」，捨同錢寶。「若」下，次約無淨主。「依《論》斷」者，入四方僧也。
【譯文】【記文】在第二個科判中，分為兩點。第一點說明所犯的物品。《四分律》所說的「衣服與藥物」，正如註釋所列。衣服應當對著僧眾捨出，所以說是「同類物品」。「藥」有四種，姑且討論時藥部分，若是「經營謀生以獲取利益」，就觸犯了販賣罪，必須說明捨棄物資的行相。指示「如同《事鈔》」的部分，是那裡引述了《五百問》中「經營謀生的出家人所得物品構成捨墮」等內容。「依照」以下，第二點是正式判定。上述是就著有淨信施主的情況而言。《薩婆多論》認為「穀米」的捨棄方式等同於金錢寶物。「如果」以下，接著針對沒有淨信施主的情況。「依循論典的判定」這句話，是指直接沒收入十方常住僧眾中。

【280-0028】02_戒疏/15a_卷三下之三#32
【原文】【疏】又如開緣，止餘同類「五眾」，餘人則約。如《衣法》中，及如他律，並聽比丘身自交貿，但不增減。《律》據有人可貿，理必不得自為，反上無人，可依他部。廣如《鈔》引。
【譯文】【疏文】又如開許的特例，僅限於同屬出家身分的「五眾」，對於其他人則加以限制約束。例如《衣法》之中，以及其他部派的律典，都允許比丘親自進行物品交換，但條件是不得討價還價增減價格。《四分律》是立足於有人可以代為交易的情況，在義理上比丘絕對不可以親自進行；反之，若遇上沒有人可以代辦的情形，則可以依循其他部派的開許規定。這在《事鈔》中有廣泛的引證。
