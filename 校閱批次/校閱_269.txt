# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【269-0001】02_戒疏/14b_卷三下之二#61
【原文】【疏】純語往索，齊六不犯；純默往索，十二反；語參默故，則九反。《律》文「四反」、「五反」者，承前語勢接次四五。若行事時，始心一二，故成六默。
【譯文】【疏文】如果純粹開口去索求，最多六次就不犯戒；如果純粹靜默前去索求，可以到十二次；如果開口與靜默混合交替，總共就是九次。《戒律》經文中說「四次」、「五次」，是順著前面開口講話的語句氣勢，順次接續著數四、數五。但實際行持時，靜默是從第一次、第二次開始算起，所以總共有六次靜默的額度。

【269-0002】02_戒疏/14b_卷三下之二#62
【原文】【記】三、分齊中。初示三位。但一番語當二番默。「律」下，點戒文。以《戒本》中正約三語六默相參明犯。前二三反，即為語索。後四五六反，即借前一二三數，接下四五六以為六默，故云「承前語」等。「若行事」等者，譯文雖省，至用默索，即從一至六。據義合云「若一反乃至若六反，在前默然立」，文相方顯耳。
【譯文】【記文】在第三項索求的限度中。首先標示出三種情況。只要一次口頭言語，就相當於兩次靜默的額度。「《戒律》」以下，分析戒律經文。因為《戒本》中正是以「三次言語、六次靜默」互相交雜的情況來說明犯相的。前面所說的「二反、三反」，就是指口頭言語索求。後面說的「四反、五反、六反」，則是借用前面的第一、第二、第三的基數，接續順數四、五、六來代表六次靜默，所以才說「順著前面的語氣」等等。「實際行持時」等語，是說翻譯的文字雖然精簡，但在實際進行靜默索求時，必須從第一遍算到第六遍。按照法理應當譯為「如果一次乃至如果六次，在面前默默站立」，這樣文義才會明確顯豁。

【269-0009】02_戒疏/14b_卷三下之二#69
【原文】【疏】制意者。綿是生緣，得在損命，不懷慈道，方廣乞求，外招譏醜，內喪善本，為過極深，故聖特制。餘雖緣財，捨懺物在；此則斬壞，永竭貪源。而世同塵，同惡相濟，身所服用，無非損生，口說行慈，何人能奉？故《多論》云：「有四義故，一、止誹謗；二、長信敬；三、為行道得安樂故；四、為不害眾生命故。」

【269-0013】02_戒疏/14b_卷三下之二#73
【原文】【疏】今人衣服皆犯通開，斯何故邪？迷名者也。文言「作臥具故」，謂如被也。今定其名，方知我犯。但以「三衣」總號，此土先無，但聞以綿作僧伽棃，此土本無，不知何物。而廣張有相，同此被敷，故即相翻，或云「臥具」，或云「敷具」。
【譯文】【疏文】現代人的衣服全都違犯了這條戒卻通通以為是開許不犯，這到底是什麼原因呢？這是因為對名詞產生了執著與迷惑。戒文中說「因為做臥具的緣故」，大家便誤以為是指被子之類的東西。現在把它的名稱徹底審定清楚，大家才會知道自己早已犯戒。只因為「三衣」是一個總稱，中土本來沒有這個名稱；大家只聽說過用綿做成的僧伽梨，但這在中土從前根本沒有，所以不知究竟是什麼物品。然而它鋪展開來的寬大形貌，恰好如同此地所用的被褥被單，所以翻譯時就順著外貌翻了過去，或者譯為「臥具」，或者譯為「敷具」。

【譯文】【疏文】所以《摩訶僧祇律》說：「所謂敷具，就是指三衣的名稱。」《薩婆多論》說：「所謂六年的臥具，指的就是正三衣。」如果不是指三衣，哪裡會有向僧眾乞請作法的規矩呢？《摩訶僧祇律》又說「老病比丘持有羊毛織成的僧伽梨」，此處翻作「臥具」，難道不也是同一個東西嗎？後面的黑毛臥具戒、白毛臥具戒，也全都是相同的道理。

【269-0019】資持記/14c_下二#38
【原文】後二聖人，學無學異。言盜用者，無德輒受，同劫掠故。言債負者，必償他故。言得罪者，違制教故。負信施者，醻業報故。親友用者，分屬己故。言主用者，得自在故。《母論》，前明受施，後辨能施，前文又二，初示結業。不如法者，或無厭治，或將非用。入下，次明感報，上句是生報。
