### 1. `mk_judge_materials.py`（6.8）的 `split_units()` 會毀掉 `疏文` 與 `資持記`
看第 6.8 節這幾行：
```python
def split_units(body):
    body = re.sub(r'^\s*【(?:疏文|記文|鈔文|律文|註文|序文)】\s*', '', (body or '').strip(' \t\r\n*'))
    parts = re.split(r'【(疏文|記文|鈔文|律文|註文|序文)】', body)
    out = {}
    if len(parts) >= 3:
        for i in range(1, len(parts) - 1, 2):
            out[parts[i]] = parts[i + 1].strip()
    if not out and body.strip():
        out['疏文'] = body.strip()
    return out
```
這是重構支援「律／註／序」時留下的嚴重 Bug，會造成兩個毀滅性後果：
- **所有配對「疏＋記」組的盲翻【疏文】都會被丟棄**：盲翻輸出 `【疏文】A\n【記文】B` → 第一行 `re.sub` 把開頭 `【疏文】` 剝掉變成 `A\n【記文】B` → `re.split` 切出 `['A\n', '記文', 'B']` → `out` 只存入 `{'記文': 'B'}`，**`A` 直接不見**！接著 `_pick(a_map, '疏文')` 找不到 `'疏文'`，就拿 **`non_ji_old`（舊白話）** 當成譯本甲，等於「舊白話跟舊白話對決」。
- **所有《資持記》與單邊【記文】的盲翻都會變空白**：盲翻輸出 `【記文】B` → 第一行把 `【記文】` 剝掉 → `out` 變成 `{'疏文': 'B'}` → `_pick(a_map, '記文')` 只查 `m.get('記文', '')`，**全部回傳空字串 `''`**！

**修法**：拿掉開頭那行 `re.sub`，且允許指定 `default_lab`（取該組第一個 unit 的標籤，如 `記文`、`鈔文`、`律文`）：
```python
def split_units(body, default_lab='疏文'):
    body = (body or '').strip(' \t\r\n*')
    parts = re.split(r'【(疏文|記文|鈔文|律文|註文|序文)】', body)
    out = {}
    if len(parts) >= 3:
        for i in range(1, len(parts) - 1, 2):
            lab, val = parts[i], parts[i + 1].strip()
            if val:
                out[lab] = (out[lab] + '\n\n' + val) if lab in out else val
    if not out and body:
        out[default_lab] = body
    return out
```

### 2. `pack_judge.py`（6.7）有 4 個會造成錯位與資料遺失的 Bug
1. **`chunk` 欄位沒寫進 JSON，會跨卷混併**：
   `pack_judge.py` 用 `ch = md.get('chunk') or ''` 防止跨卷打包，但 `mk_review_materials.py`（6.4）與 `mk_judge_materials.py`（6.8）的 `MI.write_json()` **都沒有寫入 `'chunk'`**！導致 `ch` 永遠是 `''`，上一卷最後幾段會跟下一卷開頭混包在一起。
   - **修法**：6.4 和 6.8 的 JSON 都補寫 `'chunk'` 與 `'s0'`, `'g1'`；`pack_judge.py` 同時加上 `key.rsplit('_', 1)[0]` 保底，並且檢查是否真的相鄰（或至少不可混入 `md.get('packed') == True` 的組，否則外層 `[1][2]` 會和內層既有的 `[1][2]` 打架）。
2. **`do_split` 遇到「疏＋記」成對組會互相覆蓋**：
   `JUDGE_PROMPT` 規定「同一欄標籤只在開頭寫一次」，若打包了 3 組「疏＋記」，模型極可能輸出：
   `【疏文】[1]…[2]…[3]… 【記文】[1]…[2]…[3]…`
   但 `do_split` 直接 `re.split(r'\[\s*(\d+)\s*\]', body3)`，會讓【記文】的 `[1]..[3]` **把【疏文】的 `[1]..[3]` 整個覆蓋掉**！
   - **修法**：打包裁決材料應強制改寫輸出要求為「每組編號前皆須帶標籤：`[1]\n【疏文】…\n【記文】…`」，或在 `do_split` 先依 `【疏文】/【記文】` 分區再拆 `[n]`；或是乾脆只對「單欄組」與「疏＋記分開處理」的規則寫死。
3. **單獨一組（`len(pack) < 2`）漏複製 `.json`**：
   `do_pack` 第 59 行只複製了 `.md`，沒把對應的 `.json` 複製過去，會讓下游 `mk_audit_materials` 遺失 `book`、`packed` 等資訊。
4. **`do_split` 後的檔案未整併**：
   `do_split` 只把拆回的 `*_回.txt` 寫到 `_拆回/回覆`，且未寫出對應單組的 `.md`/`.json`（要讓後續 `mk_audit_materials --src` 能直接讀，需將拆回後的回覆放回原未打包的裁決目錄 `回覆/`，或由 `pack_judge` 自動複製對應單組 `.md`/`.json`）。

### 3. `AUDIT_PROMPT`（2.5）疑似過度壓縮，必須做一次 A/B 抽驗
前面 20 組對照已經出現強烈警訊：

**建議立即做一次 5 分鐘低成本驗證**：拿 **2.5 節現行版 `AUDIT_PROMPT`** 重跑原本「舊流程那 20 組的裁決譯文」。

### 4. `PASS_A_KEEP_A` 標記的反引號與標點容錯
`JUDGE_PROMPT` 內寫作 `` `PASS_A_KEEP_A` ``（帶反引號），實跑時模型偶爾會跟著輸出 `` `PASS_A_KEEP_A` `` 或 `PASS_A_KEEP_A。`。
目前 `mk_audit_materials.py`、`mk_revise_materials.py`、`build_a2.py`、`pack_judge.py` 全都是用 `body == 'PASS_A_KEEP_A'` **嚴格相等比對**，一旦多兩個反引號，這 15 個字元就會被當成正式譯文送去終審甚至寫進定稿。
- **修法**：四處統一改用共用的 `MI.is_keep_a(body)`（先 `.strip(" \t\r\n`*。.") == 'PASS_A_KEEP_A'`）。

## 二、P1：影響 6,249 個單邊段、長段與檢索命中率的問題

### 5. `業疏`/`戒疏` 共 6,249 個「單邊／律註序」分段，標籤提示與正則沒對齊
依 4.10 節，`業疏` 3,309 組裡只有 1,238 組是成對「疏＋記」，`戒疏` 5,781 組裡只有 1,603 組是成對——也就是有 **6,249 組是單邊段**（只有 `記文`、`疏文`、`律文`、`註文` 或 `序文`）。目前這裡有兩處斷裂：
1. **提示詞輸出格式硬寫死**：`mk_blind_materials.py`（6.5）、`mk_judge_materials.py`（6.8）、`mk_revise_materials.py`（6.10）只依 `book` 給格式（`BC.cfg(book)`），沒有看 `md['units']`。結果遇到單獨一段 `■ 記文（原文）` 或 `■ 律文（原文）` 時，提示詞仍要求模型輸出 `【疏文】……\n【記文】……`；而 `mk_review_materials.py`（6.4）的 `get_prompt(True)` 在單邊 `疏文`/`律文` 時又會寫成 `【鈔文】……`。
   - **修法**：`book_config.py` 的 `cfg(book, units=None)` 依實際 `units` 的 `lab` 動態決定 `scope` 與 `out_format`（例如只有 `記文` 就只印 `【記文】……`，只有 `律文` 就印 `【律文】……`）。
2. **`col3`／`_strip_dup_labels` 漏掉 `律文|註文|序文`**：
   `qwen_local.py`（6.1）的 `_strip_dup_labels` 與 `_split_col3` fallback、`mk_judge_materials.py`（6.8）、`mk_audit_materials.py`（6.9）、`mk_revise_materials.py`（6.10）的標籤正則都只寫 `【(?:疏文|記文|鈔文)】`，漏了 `律文|註文|序文`（只有 `build_a2.py` 有寫全）。全部補齊即可。

### 6. `qwen_local.py` 與 `local_corpus.py` 檢索設定與書庫遺漏
