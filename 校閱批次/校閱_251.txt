# 校閱材料　第251檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【251-0001】03_業疏/07a_卷二之一#86
【原文】有人言：但盡自然亦得，以相外標內是無法地，未是法被，何勞遠集
【譯文】有人說：只要召集齊全自然界內的人即可，因為界相之外、界標之內屬於沒有作法之處，尚未被羯磨法力所加被，何必勞師動眾遠去召集？

【251-0002】03_業疏/07a_卷二之一#87
【原文】次科，古謂標寬相狹，未結在自然外，不妨作法；結已雖同法界，結法已成，故不須集
【譯文】下一科中，古德認為界標寬而界相狹時，未結界前處在自然界之外，不妨礙作羯磨法；結界之後雖然同屬作法界，但結界之法已經完成，所以不需要前去召集。

【251-0003】03_業疏/07a_卷二之一#88
【原文】今解云：雖在自然之外，非別所收，然作法文中通牒標內，擬成二同。唱時結時，別眾在內，律無所開，何得非別？界為法本，義必深防，既無正文，亦須比用。故《僧祇》避難界云：三由旬內，彼有比丘，若呼來，若出界去，然後結之。無問相之內外，有尼界者不妨，必有僧界內有比丘，但不出界，亦不須喚。此則明文召集，不可人語有依也
【譯文】如今解釋說：雖然此處處在自然界之外，不屬該處別眾所收攝，然而羯磨作法文中通盤申明界標之內，旨在成就「二同大界」。在宣唱界相之時與正式結界之時，若有未集會的僧眾處在界內，戒律並無開許之例，怎能不算作別眾？界是僧法的根本，在義理上必須嚴加防範；既然沒有直接的正文，也應當比照類似條文施行。因此《僧祇律》論及避難界時說：三由旬之內如果有比丘，或者將他叫來，或者讓他離開出界，然後方可結界。此時不問是界相的內還是外；若界內有比丘尼界則不妨礙，但若界內已有比丘僧界且其中有比丘，只要他不走出自己的界，也就不需要呼喚他。這就是律中要求召集僧眾的明文，不可盲目依憑個人的私說。

【251-0004】03_業疏/07a_卷二之一#89
【原文】三中，初以義通。唱相所圍，結法所牒，明非異處，故判成別界。「下」次引比例。眾法所依，故為法本。《僧祇》難界三由旬集，豈非據標？尼界兩不相礙，僧界義須隔出。「此下」準判，所謂依法不依人也
【譯文】在第三段中，首先從義理上加以通融。宣唱界相所包圍的範圍，就是羯磨結法中所申明的區域，顯明兩者並非不同處所，所以判定會構成別界。「故《僧祇》」以下，其次引用相類之例進行比照。由於是一切大眾僧法所依止的基石，所以稱為「法本」。《僧祇律》避難界要求在三由旬之內全體集僧，豈不正是依據標記範圍而定？比丘尼界與比丘僧界兩不互相妨礙，若是其他僧界則在義理上必須將其隔開或令其出界。「此則」以下依準律文予以判定，這正是所謂的「依法不依人」。

【251-0005】03_業疏/07a_卷二之一#90
【原文】六、不得受欲者，有三義
【譯文】第六門「不得受欲（不得接受轉達意見）」包含三種義理。

【251-0006】03_業疏/07a_卷二之一#91
【原文】一、結界眾同之本，理須通和，餘法眾同之末，竝依後起，故不開欲也
【譯文】第一，結界是僧眾和同共處的根本，理應要求全體通融和合；其餘各項僧法都是僧眾和同之事的末梢枝節，全都依止於結界之後而發起，所以不開許受欲。

【251-0007】03_業疏/07a_卷二之一#92
【原文】六、明欲法，初義明其制急
【譯文】在第六門說明受欲之法中，第一種義理說明了此項戒制的極其嚴格緊急。

【251-0008】03_業疏/07a_卷二之一#93
【原文】二者，自然本弱，僧事不行，不開一結，用通僧界，諸務不立。故此白二，乃是前開；欲是末緣，必憑僧起，界是作法強故攝之
【譯文】第二，自然界的法力本來微弱，常規僧事無法推行，若不開許結界一次以通達僧界，各項僧務就無法建立。因此這番白二羯磨乃是最初特許開立的；受欲是枝末因緣，必須依憑和合僧團而發起，而結界是作法界，其法力強大，因此能總攝僧眾而必須親自到場。

【251-0009】03_業疏/07a_卷二之一#94
【原文】二中，初敘僧法不許自然，唯一結界事須開耳。首冠諸務，故云「前開」。「欲」下次明欲法必須法地，僧本欲末，從本故勝
【譯文】在第二種義理中，首先敘述一般僧法不允許在自然界中推行，唯獨結界這件事必須破例開許。由於結界居於各項僧務之首，所以說是「最初特許開立」。「欲是」以下，其次說明受欲之法必須依賴作法之地，僧眾為根本而受欲為枝末，從根本出發所以僧法勝過受欲。

【251-0010】03_業疏/07a_卷二之一#95
【原文】三者，結界本興，為存限域，依、正兩報，附此而知。若開欲結，終非委練。故《十誦》云：作羯磨人死，餘不知相者，應捨更結。非欲之致，可見意矣
【譯文】第三，結界的興起本是為了確立界限區域，依報處所與正報僧人都要依憑這項界限才能了知其分齊。如果開許受欲結界，缺席者終究不能詳盡熟悉界相。所以《十誦律》說：主持結界羯磨的人去世後，其餘人若不知道界相的，應當捨界重新結界。若非因開許受欲所致，怎會如此？由此可見其深意。

【251-0011】03_業疏/07a_卷二之一#96
【原文】三中，初正明為知界相，此義最長。常途即以處為依報，人為正報；今云兩報，即攝三界：依報則攝食、攝衣，知其持犯；正報則攝僧作業，知其和別，故云「附此而知」。「故」下引證，文據明矣
【譯文】在第三種義理中，首先正明結界是為了讓全體通曉界相，這個義理最為切當殊勝。通常一般將處所視為依報，僧人視為正報；如今所說的依、正兩報，即涵蓋了三種界：依報即涵蓋攝食界與攝衣界，從而能了知持戒與犯戒；正報即涵蓋攝僧界以成辦僧事，從而能了知和合與別眾，所以說「依憑此界而了知」。「故」字以下引律文為證，文辭證據十分顯明。

【譯文】在「義設」的第一科中，首先提示文意。因為是一切僧法的根本，所以稱為「群宗」。「解」字以下，其次指明其餘僧法。所謂「解界後者」，即是其餘大界及戒場等，全都與此相同。

【原文】四、明成壞。綱則順成違壞，緣則違通成壞
【譯文】第四、說明成壞。綱要骨幹則是順應便成就、違背就壞敗，緣起則是若字句有異但事理通達便能成就，若違乖事理則會壞敗。

【251-0106】03_業疏/07b_卷二之一#91
【原文】如前文通，不可改動，事義相纏，增損俱敗，故文云「勿令違法」也
【譯文】如同前面文義貫通的部分，不可改動，事相與義理緊密相連，有所增添或減損都會導致作法失敗，所以律文說「不可使其違背正法」。

【251-0107】03_業疏/07b_卷二之一#92
【原文】綱中，纏猶續也。下引律文，即古所執。彼則通證綱、緣，今唯別證綱耳
【譯文】在解釋綱要中，「纏」如同相續連接。下面引用的律文，正是古德所執持的依據。他們是普遍用來證成綱要與緣起，如今則只專門用來證成綱要罷了。

【251-0108】03_業疏/07b_卷二之一#93
【原文】餘文局中，以事條是別，標舉應機。梵本唐辭，翻傳單複，隨其意義，尚寫經中，如翻三衣為臥具敷具，略得其相，失其本體等。故隨其事，得應法緣，雖少增減，不失事義，皆得成也
【譯文】其餘在文句受局限的部分中，由於具體事由條目各有差別，標舉出來是為了應對相應機宜。梵本與漢地語言，翻譯流傳有單字與複詞之別，隨順其意義，尚且抄寫在經本之中，例如將「三衣」翻譯為「臥具」、「敷具」，只是大致把握了它的表相，卻失去了它的本來實質等。因此只要順應那件事，能夠契合羯磨之緣，雖然略有增減，只要不失事理實質，都能夠成就。

【251-0109】03_業疏/07b_卷二之一#94
【原文】緣中初科，初標事別。「梵」下次示理通。且舉三衣以明差互，猶為正經，則驗緣中改作無過。經中即指戒本。若作離衣、六年羯磨，或梵或華，隨牒通得。又如說戒布薩，互牒皆成。故下結示通成，但取應事，不局文言
【譯文】在解釋緣起的第一條中，起初標示法事各有差別。自「梵」字以下接著開示義理貫通。暫且舉出三衣來說明翻譯的參差出入，這尚且被當作正經，便可檢驗出在緣起之中稍作改動並無過失。經中就是指戒本。如果作離衣羯磨、六年羯磨，或者用梵名、或者用華語，隨意牒入皆可通用。又如說戒與布薩，互相換牒都能成就。所以下面結尾開示普遍皆能成就，只在於相應於事由，而不拘泥於文言辭句。

【251-0110】03_業疏/07b_卷二之一#95
【原文】故諸部羯磨文義通者，竝無異辭；文局義通，部別乖各，意可見也。如此開張，舉例自委
【譯文】因此各部律典的羯磨中文字與義理相通的部分，全都沒有不同的文辭；至於文句局限而義理相通的部分，各部派之間互有出入差異，其深意便可見一斑了。如此開展說明，舉例自然就十分詳盡。

【251-0113】03_業疏/07b_卷二之一#98
【原文】問：羯磨文中前後竝云「僧聽」、「僧忍」，中間何以言「長老忍」者？答：事達在僧，成不在別。別須語默，僧唯六和。假用未彰，還從別舉，故曰也。或有文云「大德忍」者，終問別人，隨時稱謂也
【譯文】問：羯磨文中前後都說「僧聽」、「僧忍」，中間為何說「長老忍」呢？答：事情的通達在於僧團全體，而羯磨能否成就則取決於個別之人。但是個別之人必須透過出聲或默然來表態，僧團則唯在於六和敬。在借事顯用尚未彰顯之時，還是要從個別之人來舉問，所以這樣說。或者有的羯磨文說「大德忍」，終究也是詢問個別之人，只是隨著具體情況更換稱呼罷了。
