# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【譯文】第一、說明設立四條戒的原因：凡是譏嫌過失的產生，一種是託附內部眷屬而起，另一種是託附外部眷屬而起。就內部眷屬而言，不外乎私密隱蔽之處以及大眾之中。在私密處產生過失，比丘與比丘尼雖然同著黑染僧服，但男女有別，若身在聚落，親自從尼僧手中取食，極易生起染污深心，招致譏嫌而損害道業，為了遠離這種過失，所以制定了第一條戒。如果是在大眾之中，比丘尼偏心指點授食，行跡涉及私情曲媚，受食者若默默承受而不加呵止，在大眾面前無法避嫌，為了遠離這種過失，所以制定了第二條戒。託附外部產生的過失，不外乎聚落與阿蘭若處：在聚落中，學道家若過度布施供養，導致家庭資財耗盡，會招來外界的譏諷非議，所以制定了第三條戒，這是在聚落中所引發的；若比丘懈怠懶惰，身處險遠之處，安然端坐等待受食，致使送食的婦女遭到盜賊觸惱侵擾，同樣會招來外界譏嫌，為了遠離這種惡事，所以確立了第四條戒。這類戒本無性罪之實體，所以《薩婆多論》說：此戒的體性沒有定罪名稱，只要在一比丘面前發露悔過，如果惡念止息，便都能滅除罪過。

【661-0003】05_拾毗尼義鈔/04b_卷中之二#15
【原文】第三持犯相者第二第四具二持犯二持者若尼指授止而不食是止持若見過呵責後食無罪名為作持此二名體俱別二犯者若見指食默然不呵食便得罪由止而生故曰止犯雖指不呵身業不食無犯犯由身業食食而生名曰作犯望前名止望後為作此罪體一而名有異。
【譯文】第三、說明持犯的行相：第二條與第四條戒都具備兩種持戒與兩種犯戒的行相。兩種持戒者：如果比丘尼指點授食，自己止住而不食用，這屬於「止持」；如果見到過失而當場呵責，之後再食用便無罪，這稱為「作持」，這兩者的名稱與行體各自不同。兩種犯戒者：如果見到尼僧偏心指食，自己默然不予呵斥，吃下去便得罪，因為放任縱容而產生，所以稱為「止犯」；雖然尼僧指食而自己沒有呵止，但身體若不實際去吃就沒有犯罪，犯戒完全是由於身體造作吃食的動作而產生，所以稱為「作犯」——對照前因稱為止犯，對照後果稱為作犯，其罪體只有一個，只是觀察角度不同而名稱有異。

【原文】第一序名不同者所以此篇不序頭數但言眾者今篇威儀違失乃有塵沙不可以限數法局故稱名眾今且標人之喜犯百戒重者集在篇內餘在雜威儀中如善見云式叉迦羅尼翻學應當語倒故言應當學婆論問何故此篇獨名應當學答餘戒易持而罪重犯懺是難此戒難持而易犯常須念學不結罪名故言應當學首解若就所防彰名應言眾突吉羅今隱其所防就能治行受稱故名學問論其學也實通上四非局此篇何故偏得此名答此篇威儀微細自非專翫在心勤加護持其行難成故特加勸學之名又復能持此戒滿足無缺學行成就之終彰學功義顯故偏受學名。
【譯文】第一、說明戒序名稱相異的原因：本篇之所以不像前幾篇那樣依序標明罪條數量、只統稱為「眾」的原因，是因為本篇所規範的威儀失誤多如塵沙，無法用有限的條目法度來侷限，所以統稱為「眾」。現在暫且標列出世人最容易違犯的一百條較重威儀，結集在本篇之內，其餘則散見於雜威儀之中。如《善見律》說：「式叉迦羅尼」翻譯為「學應當」，因梵漢語序顛倒，所以譯為「應當學」。《薩婆多論》問：為何本篇獨自命名為「應當學」？答：其餘各篇的戒法容易受持但罪責深重，一旦違犯極難懺除；本篇戒法難以受持而容易違犯，行者心念必須時刻保持修學，不直接彰顯其罪名，所以稱為「應當學」。首師解釋說：如果依照所防範的罪過來定名，應該稱為「眾突吉羅」；現在隱去其所防之罪，順應行者能對治的修持來命名，所以稱為「學」。問：論及修學，實際上貫通前面的四篇戒法，並非局限於本篇，為何偏偏只有本篇得到這個名稱？答：本篇的威儀極其微細，若不是時時專注玩味於心、精勤守護，這種德行極難圓滿成就，所以特地加上勸勉修學的名稱；再者，能夠將這篇戒法持守得圓融無缺，正是修學行持圓滿成熟之極致，彰顯修學功德的意義最為顯著，所以偏偏享有「學」的名稱。

【原文】第三僧尼同異者趍行生艸有二戒不同餘者同犯無教人為己故無任運犯此中有四一從初至立大小便有五十一戒明敬僧威儀二從不恭敬人不得與說法至騎乘人有八戒辨敬法威儀三從不得止宿佛塔中至安佛在下房有二十六戒明敬佛威儀四從人坐己立訖末有十五戒出能敬之人若大乘一體三寶法先師故佛後資故若就別相佛初成道次轉法輪後當機悟聖今就住持由僧教化斷惡修善法由人通依法潔淨安置尊像故得住持初五十一戒中初二戒明教諸比丘著衣服式齊整應法二從不得反抄至不得戲笑坐二十三戒明入村落受請行來坐起方法三不用意受食至洗鉢水弃白衣舍有二十三戒明食上方法四大小便生艸下有三戒明大小便利進止方法大意如是。
【譯文】第三、說明比丘與比丘尼戒的同異：只有「趨走急行」與「生草上大小便」這兩條戒有所不同，其餘各戒雙方違犯相同。因為沒有教唆他人為自己做的情況，所以沒有任運自然得罪的犯相。本篇之中包含四個部分：一、從最初直到「立大小便」，共有五十一條戒，明示恭敬僧寶的威儀；二、從「不得為不恭敬法之人說法」直到「騎乘之人」，共有八條戒，辨明恭敬法寶的威儀；三、從「不得止宿在佛塔中」直到「安置佛像在下房」，共有二十六條戒，明示恭敬佛寶的威儀；四、從「他人坐自己站立」直到最後，共有十五條戒，列出能敬（主動恭敬）之人的威儀。如果就大乘一體三寶來說，法是先師所以居先，佛是後嗣所以居後；若就別相三寶而言，佛先成道，接著轉法輪，最後弟子感契聖道；如今就住持三寶來說，全賴僧寶弘化教導以斷惡修善，正法藉由僧人弘通，依照戒法潔淨身心、妥善安置佛陀尊像，佛教才能常住於世。在前五十一條戒中：最初兩條戒說明教導諸比丘穿著衣物的規範，應當齊整合乎戒法；二、從「不得反抄衣」直到「不得戲笑坐」等二十三條戒，明示進入村落受請、行走、往來、坐臥起立的規矩；三、從「不得不用意受食」直到「將洗鉢水棄於白衣舍內」等二十三條戒，明示進食時的方法規範；四、在「大小便生草上」以下共有三條戒，明示大小便溺時進退動靜的法則，大體意旨就是如此。

【661-0010】05_拾毗尼義鈔/04b_卷中之二#22
【原文】問五篇戒中何故制泥洹僧著三衣獨觀過去未來佛及淨居天答婆論云佛結五篇戒皆應觀三世諸佛及淨居天但年歲久遠文字漏落餘篇盡無此篇獨有又本結五篇此最在初後結集者詮次在後以初貫後故餘不論之又云三世諸佛結戒有同不同五篇戒中不必盡同著泥洹僧袈裟一切盡同是故此戒觀佛及天如十誦云佛觀過未諸佛齊整著內衣及聞淨居天空言齊著故制此戒此中婆論云極高著者如釋種千人同時出家羯磨受者非善來也乃至踝上一搩手上下過名高下若比丘沙彌遠行來時應踝上二搩手上至膝下比丘尼等一切時踝上一搩也母論云踝上三指應法過是不應長四肘廣一肘半是名量。
【譯文】問：在五篇戒法中，為何單單在制定穿著下裙（泥洹僧）與披著三衣時，特別要觀察過去佛、未來佛以及淨居天的行止？答：《薩婆多論》說：佛陀制定五篇戒時，每一戒本來都應當觀察三世諸佛與淨居天，只因年代久遠、文字抄寫脫漏，其餘各篇都遺失了，唯獨本篇保存下來。又有一說，原本結集五篇戒時，這一篇列在最前，後來的結集者將其次第編排在後，因為用最初的通例貫徹至後，所以其餘各篇不再重複贅述。論中又說：三世諸佛制戒有同有異，五篇戒中的規範未必完全相同，但穿著下裙與袈裟的威儀，一切諸佛完全相同，所以此戒必須觀瞻諸佛與天人。正如《十誦律》所說：佛陀觀察過去未來諸佛均齊整穿著內衣，又聽聞淨居天人空中言稱威儀齊整，所以制定此戒。本篇中《薩婆多論》說：穿得極高，如同釋迦族千人同時出家受羯磨者那樣，不是善來比丘那種穿法；乃至高過踝骨上一搩手、過高過低都算犯高下之失。如果比丘、沙彌遠行歸來時，可以提高至踝上二搩手、直到膝蓋以下；比丘尼等任何時候都只能提高到踝上一搩手。《毘尼母論》說：踝骨以上三指才合乎法度，超過這個限度便不應當。長四肘、寬一肘半，這是標準的尺寸。
