# 校閱材料　第1729檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1729-0001】03_業疏/11b_卷二之五#113
【原文】十中，初標。「彼」下出計。增修定者，初則緣色住心，即以定業以滅欲有亂業；此定既成，次又觀空，即用無色定業以滅色有定業；至此為極，謂為涅槃。「佛」下顯正，彼既緣色、緣空以為至極，此即用十一切處定以破之。此之十境，亦緣色、空，但是發定之處，非至極也：一、青一切處，二、黃一切處，三、赤一切處，四、白一切處，五、地一切處，六、水一切處，七、火一切處，八、風一切處，九、空一切處，十、識一切處。十皆言「一切處」者，即從所觀境徧滿為名。今名「入」者，謂從此以發定也。「尋本際」者，推於心也。「多少」，謂初觀少色，後使多偏，實唯一識，攝境歸心也。「但是」等者，彰外計之過，引證可知。
【譯文】第十段中，起初標示。自「彼」以下，指出外道妄計。所謂「增修定」，起初是攀緣色相安住心念，也就是用色界定業來滅除欲界諸有的散亂雜業；這種禪定修成之後，其次又觀修虛空，也就是用無色界定業來滅除色界諸有的定業；達到此處便以為是至極，稱之為涅槃。自「佛法」以下，顯明正理。彼外道既然攀緣色、攀緣空而當作至極，此處就用「十一切處定」來加以破斥。這十種定境雖然也是攀緣色與空，但只不過是引發禪定的處所，並非至極之道：一、青一切處，二、黃一切處，三、赤一切處，四、白一切處，五、地一切處，六、水一切處，七、火一切處，八、風一切處，九、空一切處，十、識一切處。十種都稱為「一切處」，是因為所觀照的境界周遍圓滿而得名。現在稱之為「入」，是指從此處發起禪定。所謂「尋本際」，是推求於自心。所謂「多少」，是指起初觀想少量的色相，後來使其廣大周遍，實質上唯有一識，將外境攝歸於自心。所謂「但是妄倒」等語，是彰顯外道執計的過失，所引用的經論文證顯而易知。

【譯文】第三、指明省略的文段中，起初說明「作持」的行持相同。所謂「持說、受淨」，是指沙彌依制規定擁有兩件縵衣與一個鉢，其餘多餘的衣物、藥品、鉢全都必須作淨施；因為作法受持所以必須執持，淨施的衣藥所以必須作法說淨。自「罪」字以下，指示「止持」的行持有所差別。所謂「悔以隨戒」，是指沙彌通於五篇罪相，全都一概作為突吉羅（惡作）來懺悔。後文指示參照《行事鈔》，全都見於〈沙彌篇〉。

【1729-0008】03_業疏/12a_卷三之一#3
【原文】言「比丘」者，中梵天音，此方無譯，可以陳相。如水火等，彼此同體，以名目之，得其實也。比丘不爾，元出中方，此土本無，不知何目，且用義例，得詮便止。因此四句：以義翻名、以名翻義，餘二俱句，可以例知。
【譯文】所謂「比丘」，是中印度梵天之音，此方漢地沒有相應的直接翻譯，但可以陳述其體相特徵。就像水、火等物，兩地本體相同，用名稱來稱呼它，就能切合其實質。比丘則不是這樣，他原本出自中印度，此方土地本來就沒有這種身分，不知該用何詞命名，姑且借用義理譬例，只要能夠顯明其意便止。由此形成四句分別：以義理翻譯名稱、以名稱翻譯義理，其餘兩句俱句（以名翻名、以義翻義），可以依此類推而知。

【1729-0009】03_業疏/12a_卷三之一#4
【原文】二、授具戒法標舉正釋中，初文初示無譯。「如」下，即舉有譯反顯無譯，故云「比丘不爾」等。「水火未詳梵語」。「詮」，顯也。因列四句：「以義翻名」，即下翻「比丘」是也，又如以「覺」翻「佛」、以「業」翻「羯磨」等，此類甚多，臨文自舉；「以名翻義」，如「火器」翻「憍陳如」、「鶖鷺」翻「舍利」，並以此土物名翻彼得名之義；餘二俱者，「以名翻名」，如水火等，彼此名同，又如「白楊」翻「尼俱律」、「線」翻「修多羅」、「律」翻「毗尼」、「戒」翻「尸羅」之類；「以義翻義」，如「彼岸到」翻「波羅蜜」、「無上正等正覺」翻「阿耨多羅」等是也。
【譯文】在第二、授具戒法標舉正釋的文句中，第一段初次指出不可直接翻譯。自「如水火」以下，就是列舉可以直譯者反襯顯明無可直譯之處，所以說「比丘不爾」等。（水、火二詞尚未詳考其梵語）。「詮」就是顯明的意思。由此列出四句：「以義翻名」，也就是後文翻譯「比丘」為乞士等即是，又如用「覺」翻譯「佛」、用「業」翻譯「羯磨」等，這一類非常多，隨順經文各自舉出；「以名翻義」，例如用「火器」翻譯「憍陳如」、用「鶖鷺」翻譯「舍利」，全都是用此方事物的名稱來翻譯彼方得名的義由；其餘兩個俱句，「以名翻名」，就像水、火等物兩地的名稱實質相同，又如用「白楊」翻譯「尼俱律」、用「線」翻譯「修多羅」、用「律」翻譯「毗尼」、用「戒」翻譯「尸羅」之類；「以義翻義」，例如用「彼岸到」翻譯「波羅蜜」、用「無上正等正覺」翻譯「阿耨多羅」等便是。

【1729-0010】03_業疏/12a_卷三之一#5
【原文】中梵本音，號曰「煏芻」，此傳訛失，轉「比丘」也。初翻「怖魔」，次云「乞士」，後云「破煩惱」。或從功能者，令魔怖也；明本志者，為怖於魔也。魔名如上。世魔有四：欲魔，即下界頂住者，以欲纏生令不出也；言陰魔者，即身所聚，念念壞也；言煩惱魔者，即心三毒，起必滅善也；言死魔者，劫略善財，終趣死也。此人為怖此四故出家也，取其志致，用以翻名
【譯文】中印度的原本讀音稱為「煏芻」，此方流傳傳抄訛誤，轉化成為「比丘」。最初翻譯為「怖魔」，其次稱為「乞士」，最後稱為「破煩惱」。若從其功用效能而言，是指能令魔王生起畏怖；若闡明其本來志願，則是指自身畏懼於魔障。魔的名稱如前文所述。世間的魔有四種：欲魔（天魔），就是居於欲界頂天者，以貪欲纏縛眾生令其無法出離；所謂陰魔（五陰魔），就是色身所聚集的五陰，念念遷變壞滅；所謂煩惱魔，就是內心的貪、瞋、癡三毒，一旦生起必然毀滅善法；所謂死魔，就是劫奪眾生的善法財寶，最終驅赴死亡。此人正是因為畏懼這四種魔的緣故而發心出家，取其本來立志旨趣，用以翻譯其名稱。
