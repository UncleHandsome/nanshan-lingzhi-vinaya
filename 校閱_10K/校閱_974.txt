# 校閱材料　第974檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【974-0001】資持記/03b_上二#15
【原文】疏引古云：及作受戒，相如熨斗柄，是中問遮是也。今破中，初科為二；初文示妨，明不可立。此下，示同，明不當異。次科引文，即三種結法中牒緣文也。初即〈受戒〉中文。一處者，疏云知無異外也。中云即說戒文。爾許集者，疏云知數人外無界也。後即自恣文。
【譯文】疏文中引用古師的話說：在進行受戒時，界標的形狀如同熨斗的長柄，在此處詢問有無遮難，指的就是這個意思。現在破斥古師之說，第一科分為兩部分：第一段指出窒礙之處，說明萬萬不可樹立界標；從「此」字以下，說明小界性質相同，斷定不應有所差異。下一科引用律文，指的就是三種結界法中重提緣起的文句。第一段即是〈受戒篇〉中的文字；所謂「一處」，疏文解釋為明瞭界外再無其他界相。中間一段即是說戒的文字；所謂「有如此多僧眾聚集」，疏文解釋為明瞭在這些人數之外並不存在界域。最後一段即是自恣的文字；

【974-0002】資持記/03b_上二#16
【原文】齊坐處者，疏云知坐處外非界也。文下，通示。止在此者，謂上三文，皆約坐處也。遮濫中。以《僧祇》文是彼所據，故須釋之；文出第八，彼明比丘犯長求懺；以大界難集，或恐勞僧，故出界作。至界外者，即指戒場。以隔自然，故云外也。無場方出界外別結。文云者，即彼結法。彼云：大德僧聽！
【譯文】所謂「齊坐處」，疏文解釋為明瞭坐處之外就不是結界範圍。從「文」字以下作通體說明；所謂「止在此」，是指上面三段文字，都是僅以坐處為界。在防止混淆的段落中，因為《摩訶僧祇律》的文字是古師所依據的憑據，所以必須加以解釋；該段文字出自第八卷，那裡說明比丘犯了長物罪而求懺悔，因為大界集合僧眾困難，或者擔心勞煩僧眾，所以走到界外去作法。所謂「走到界外」，指的就是戒場；因為中間隔著自然界，所以稱為「外」。只有在沒有戒場時，才走到界外另外結小界。文中所謂的結法，就是指該律所載的儀軌，經文說：「大德僧聽！

【974-0003】資持記/03b_上二#17
【原文】若僧時到僧忍聽，僧於此地，即接齊僧等三句。此下，決破，上句是縱。下二句即奪。上句指類戒場以名通故，下句顯非三小，由非難故。《四分》下，質彼迷名。行事中，初出正義。界外問難，受法明文。叢坐者，前後兩邊身相連及，非謂環繞使中空也。足開者，足可相容也；
【譯文】若僧時到僧忍聽，僧於此地……」隨即接續「齊僧坐處」等三句。從「此」字以下作決斷破斥，上一句是暫且順從對方的說法，下兩句則是予以駁奪。上一句指稱該處類似戒場，那是因為名稱相通；下一句則顯明它並非三種小界，因為那並不是在有災難的情況下結設。《四分律》以下，詰問對方在名稱上的執迷不悟。行事之中，首先提出正確認識；在界外詢問遮難，這是受戒法度中的明文規定。所謂「叢坐」，是指前後左右僧人的身體緊密相連，並不是指圍成環狀而中間留空。所謂「足開」，是指空隙剛好可以容納一人；

【974-0004】資持記/03b_上二#18
【原文】疏云：十人融通開間納取。必半身者，舉分況全也。《十誦》，一比丘一處坐足四處僧作法，證今半身即成同界。《善見》未詳何文。是定義者，疏云：如斯行事，內準佛教，外約凡訶；僧有授法之功，前無虛受之願可也。必下，二斥非法。鎮，壓也。下指《義鈔》文逸，今見《業疏》，破立頗詳。
【譯文】疏文說：十個人圓融變通，稍微騰出空隙接納問難者進入。若是「半身進入」，這是舉出部分來比況全體。《十誦律》說：一個比丘在同一處坐著，即可為四處作法的僧團湊足人數，由此證明如今只要半身進入就算屬於同一個界域。《善見律毘婆沙》的文字目前尚不清楚出自何處。所謂「定論之義」，疏文說：這樣的行事方式，內在合乎佛陀教法，外在符合凡情評斷的規矩；僧團既有傳授戒法的功德，前來受戒者也沒有空受一場的遺憾，如此便屬可行。從「必」字以下，第二步斥責非法行徑。「鎮」就是壓制的意思。下文指出《義鈔》的原文已經佚失，如今見於《業疏》中，破斥與建立的論辯相當詳盡。

【974-0005】資持記/03b_上二#19
【原文】說恣中，初明說戒。同師善友者，非不同意也。下道者，道路之下，即蘭若也。使相近者，必有空間，非一界也。自恣圓坐，示相可知。此下，雙結不可必固。指結法中。事希故略者，非鈔意也。今略引之，說戒文云：大德僧聽！今有爾許比丘集，若僧時到僧忍聽結小界，白如是；羯磨準知。
【譯文】說戒與自恣之中，首先說明說戒。「同師善友」，是指彼此並非意見不同、難以共處之人。所謂「下道」，是指道路下方，也就是阿蘭若處。所謂「使相近」，是指兩處必定要有空間相隔，並非屬於同一個界域。自恣時僧眾圍繞而坐，所呈現的界相自可明瞭。從「此」字以下，雙雙總結不可固執己見。在指出結界方法的段落中，所謂「因事情少見而予以省略」，並非《行事鈔》的本意；如今略微加以引述，說戒文說：「大德僧聽！今有如此多比丘聚集，若僧時到僧忍聽，結小界。白告如是。」羯磨文則準照此例可知。

【974-0006】資持記/03b_上二#20
【原文】〔餘二緣相，如前已引。〕示餘三中。初謂一處有食無法，一處有法無食；各解同結，自他相濟，名為法食二同界。二謂二俱有食，一處有法，名法同食別界。〔此二并上人法二同，即三種大界。〕三謂二俱有法，一處無食，名食同法別界。為下，別釋第三，初示開意。
【譯文】〔其餘兩種緣起的體相，如同前面已經引述過的。〕標示其餘三種大界中：第一種是指一處有飲食供應卻缺乏說法者，另一處有說法者卻缺乏飲食；兩處各自解除舊界、共同結成一界，彼此互通有無，稱為「法食二同界」。第二種是指兩處都有飲食供應，但只有一處有說法者，稱為「法同食別界」。〔這兩種加上前面的人法二同界，就合稱為三種大界。〕第三種是指兩處都有說法者，但其中一處缺乏飲食，稱為「食同法別界」。從「為」字以下分別解釋第三種，首先說明開許的用意。

【974-0007】資持記/03b_上二#21
【原文】言守護者，不令彼處僧散寺廢故。四方唱和者，顯非結界；而前標云三種界者，以利養相通，義同一界；下云開結，意亦同之。疏云：本非結界，因前同別，故有事來；末下，傷今不行。殆，將也。必下，勸令遵奉。解中，無場法。可解。結歸中，聽字或存或去，諍論紛紜；然非是綱，去之無在；
【譯文】所謂「守護」，是為了不讓該處的僧眾離散、寺院廢棄。所謂「四方唱和」，是顯示這並非真正透過羯磨來結界；而前面標名為「三種界」，是因為供養利養互相流通，在義理上等同於同一界域；下文所說的開許結界，用意也是相同。疏文說：本來就不是正式結界，只是因為承續前文的同別之義，才產生了這項處事之法；從「末」字以下，感嘆當今已經不再推行這項做法。「殆」就是將近的意思。從「必」字以下，勸勉大家應當尊崇奉行。在解界之中，沒有戒場的解法很容易理解。在羯磨結歸句中，羯磨文中「聽」字究竟該保留還是去除，歷來爭論不休；然而這並非關鍵綱領，去掉它也無妨；

【974-0008】資持記/03b_上二#22
【原文】比諸羯磨，並無此言，疑是律文傳寫之誤。次有場中，初示先後。反前結法。解大界中，初明問答。恐謂兩解，妄行通答故。又準《注羯磨》，結解二法，不得通答；以解在法地，結依自然；故必依次解，人衣食界，理得通答。若下，即指前解，無別法故。解場中，示解處者。絕濫行故。
【譯文】對比其他羯磨文，全都找不到這個字，懷疑是律文在傳抄過程中的錯誤。其次在有戒場的情況中，首先說明解界的先後次序，與前面結界的方法剛好相反。在解除大界之中，首先說明提問與回答，是擔心有人以為解除兩個界，便妄自作籠統一次回答的緣故。再者依據《注羯磨》，結界與解界這兩種法度，不可以籠統通答；因為解界是針對已成立的如法地界，結界則是依憑自然地界；所以必須依序解除，而人界、衣界、食界在法理上則可以通答。從「若」字以下，就是指前面的解法，並沒有其他的特別方法。在解除戒場之中，指明解界的地點，是為了斷絕胡亂行事流弊的緣故。
