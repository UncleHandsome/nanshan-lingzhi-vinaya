# 校閱材料　第242檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【242-0001】01_行事鈔/11a_卷下之三#28
【原文】二明對緣是非。《四分》中有四：一不應禮一切白衣及女人；二前受戒人不應禮後受戒者；三不禮犯邊罪等十三難人、被舉、滅擯、應滅擯等；四不禮一切說非法語者。《寶梁經》云：若破戒比丘，受他持戒者恭敬禮拜，得八輕法：一作愚癡；二口瘖瘂；三顏貌醜陋；四其面側戾，見者𧈪笑；五轉受女身，作貧窮婢使；六形體羸瘦，夭損壽命；七人所不敬，常有惡名；八不值佛世。此破戒者，乃至大地無涕唾處。餘如上篇。二應禮，分二：初無緣合敬。律中，小沙彌尼禮大沙彌尼，如是展轉，乃至如來及塔。餘如後說。《四分》：十種非威儀不應禮：大、小行、裸身、若剃髮、若說法、嚼楊枝、洗口、若飲、若食、若噉果。《增一》云：塔中不應禮。《五分》：相瞋屏處不得禮。《十誦》：睡、縫衣、大眾中、在路行、病時，不得禮。《僧祇》：泥作、浣衣、洗浴、及手足著一衣時、疾行等，不應禮。《十誦》：佛塔、聲聞塔前，自他不得互禮。《五百問》云：佛塔前禮比丘，犯墮。《僧祇》：禮塔、誦經、讀經、寫經、授經、闇中，並不得禮。皆謂別有所敬故也。
【譯文】第二、辨明面對各種境界是對是錯。《四分律》中列出四種不應禮敬的情況：第一、不應當禮拜一切在家白衣以及婦女；第二、先受戒的戒長比丘，不應當禮拜後受戒的戒幼比丘；第三、不禮拜犯了波羅夷邊罪等十三難之人、被僧團作羯磨舉罪處分之人、被滅擯驅逐之人，以及應當被滅擯之人等；第四、不禮拜一切宣說非法之言論者。《大寶積經·寶梁清淨品》說：如果破戒比丘接受其他持戒清淨者的恭敬禮拜，將獲得八種輕賤的果報：一是轉生為愚癡無知；二是口不能言、喑啞殘疾；三是容貌醜陋不堪；四是面部歪斜扭曲，見者𧈪笑〔註：𧈪，音義疑同「嗤」，嗤笑譏誚之意〕；五是轉受為女身，充當貧窮卑微的婢女僕使；六是身體羸弱消瘦，短命夭折；七是不為世人所敬重，常蒙受惡名聲；八是生生世世遇不到佛陀出世。這種破戒之人，甚至連大地之上都沒有他可以吐一口痰涕的立足之地。其餘規定如上篇所述。第二、應當禮拜的情況，分為兩部分：首先是正常無妨礙因緣時理合應行禮敬。律藏規定，新戒小沙彌尼禮拜戒長大沙彌尼，像這樣層層推展，乃至禮拜如來及佛塔。其餘規矩如後文所述。《四分律》指出有十種不合威儀的情形不應禮拜：大便、小便、赤身裸體、正在剃髮、正在說法、正在嚼楊枝（刷牙）、正在漱口洗口、正在喝水、正在吃飯、正在吃水果。《增一阿含經》說：在佛塔之中不應當互相禮拜。《五分律》說：彼此心懷瞋怒之時，或者在隱蔽暗處，不得禮拜。《十誦律》說：睡眠時、縫衣服時、在大眾齊聚之時、正在路上行走時、患病之時，均不得行禮禮拜。《摩訶僧祇律》說：正在從事泥水勞作、正在洗衣、正在沐浴及洗手洗腳、身上僅穿著一件單衣之時、匆促疾行之時等，均不應當禮拜。《十誦律》說：在佛塔、聲聞塔前面，彼此雙方均不得互相禮拜。《五百問》說：在佛塔前禮拜比丘，犯波逸提（墮）罪。《摩訶僧祇律》說：正在禮拜佛塔時、誦經時、讀經時、抄寫經典時、傳授經典時，以及處在黑暗之中，全都不准互相禮拜。這都是因為此時心中另外有所專注崇敬的對象的緣故。

【242-0002】01_行事鈔/11a_卷下之三#29
【原文】三立敬儀式。分三：初敬佛法，二敬僧法，三大小致禮法。
【譯文】第三、確立致敬的威儀法度。分為三個項目：第一是敬奉佛法（佛像塔寺）之法，第二是敬奉僧眾之法，第三是戒臘大小長幼致敬之法。
