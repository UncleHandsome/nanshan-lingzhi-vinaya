裁決改成直接輸出修正後的譯文

**可以，而且非常推薦這樣做。**

原因很實際：
1. **幾乎不加成本**：一段完整譯文才 300～600 tokens，跟思考量（幾千到上萬 tokens）相比只佔約 3%～5%；
2. **無縫相容你現有的程式**：只要把裁決的最後一欄標題一樣命名為 **`3. **修正後的譯文**`**，你的 `qwen_local.py`（`_split_col3`、`_strip_dup_labels`、`_looks_pasted`、`_quota`）和後面的 `改前改後.md` 提取腳本**幾乎不用改就能直接沿用**，不用另外寫腳本去回補 `PASS_A` 的譯文！

下面直接給你修改後的 **`JUDGE_PROMPT`（一律輸出完整定稿譯文版）**：

---

### 一、新版 `JUDGE_PROMPT`（與現有 3 欄相容）

```python
JUDGE_PROMPT = '''你是南山律典雙譯裁決編輯。下方附有同一段原文的兩份白話譯文：【譯本 A（既有定稿）】與【譯本 B（獨立盲翻）】。

請**只針對【本次待審原文】**，拿 A 與 B 逐句對照原文進行「差分審判」，並嚴格依序以「1. **結論**」「2. **分歧與裁決**」「3. **修正後的譯文**」為標題輸出：

### 裁決原則：
1. **以 A 為骨架、以 B 照盲點**：保留 A 原有的分段、標題結構與正確的消歧義／條件括注（不可因 B 沒補就誤刪）；同時**高度警覺 A 是否因讀起來順口而暗藏錯譯、主客顛倒、偷增原文無有之字、誤套比丘／尼制或遺漏限定條件**。
2. **重點審判分歧句**：凡 A 與 B 實質義理、主詞對象、限定條件、數理度量或專名解讀不同之處，必須回歸原文（{book_note}）與律制邏輯（必要時檢索查證），判別何者正確，或綜合兩者修正。
3. **防範共同盲點**：即使 A 與 B 譯法一致，仍須快速確認該處是否同犯「望文生義、古今異義誤讀、底本疑訛或體例錯誤」（獨立律典用《》、問答作「問：」「答：」、直引原字不混入白話、非引原字用標準正體字）。
4. **不為修辭重寫**：若 A、B 實質義理無分歧且無明顯錯誤，即使 B 用詞更口語，亦直接沿用 A，不作純修辭改動。

### 輸出格式（嚴禁在譯文重貼任何原文）：

1. **結論**：`PASS_A`（A 無實質錯誤，完全沿用）或 `REVISED`（A 有實質錯誤或須採 B 之優點修正）

2. **分歧與裁決**：
   - 若為 `PASS_A`，只寫一句：「A、B 實質義理一致且無明顯誤譯，沿用譯本 A。」
   - 若為 `REVISED`，條列有改動處：`[疏/記/鈔] 原文「……」｜A 作「……」vs B 作「……」｜裁決：……`

3. **修正後的譯文**（完整純白話譯文，同一欄標籤只在開頭寫一次）：
   - 若結論為 `PASS_A`，**請一字不改照原樣輸出譯本 A 的完整譯文**；若為 `REVISED`，則以 A 為底本修改並輸出完整定稿：
{out_format}
'''

def get_judge_prompt(is_nicao=False):
    note = (
        '《尼鈔》須依比丘尼律制與對舉「僧／尼」語境審斷'
        if is_nicao else
        '《業疏》文注指《隨機羯磨》，《戒疏》文注指《含注戒本》，「律」方指《四分律》，且【疏】【記】須雙向互洽'
    )
    fmt = '【鈔文】……' if is_nicao else '【疏文】……\n【記文】……'
    return JUDGE_PROMPT.format(book_note=note, out_format=fmt)
```

### 二、順手把「裁決材料區塊順序」也配好（免改 `qwen_local.py`）

組裝裁判用的 `.md` 時，建議把原本區塊排成這樣：

```text
【本次待審單元】

■ 疏文（原文）
...
■ 疏文（譯本 A：原現譯）
...
■ 疏文（譯本 B：盲翻）
...
■ 記文（原文）
...
■ 記文（譯本 A：原現譯）
...
■ 記文（譯本 B：盲翻）
...
```
（《尼鈔》則只有 `■ 鈔文（原文）` → `■ 鈔文（譯本 A：原現譯）` → `■ 鈔文（譯本 B：盲翻）`。）

**這樣排有兩個好處**：
1. 裁判模型在每一小節都能把「原文 ↔ A ↔ B」緊挨著對看，分歧一目了然；
2. 你的 `qwen_local.py` 裡 `_quota()`、`_src_unit()`、`_split_col3()`、`_strip_dup_labels()`、`_looks_pasted()` **一行都不用改就能直接相容**（只在跑**步驟 1 盲翻 B** 時才需要跳過 `_split_col3()` 直接存純譯文）。

*(跑完後想快速抽查哪幾段真的有改動，只要掃描回覆檔裡含 `REVISED` 的那幾組去看 `2. **分歧與裁決**` 即可！)*
