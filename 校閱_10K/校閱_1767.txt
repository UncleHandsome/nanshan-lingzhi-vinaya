# 校閱材料　第1767檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1767-0001】03_業疏/14b_卷三之三#16
【原文】七、問良賤，以位居尊勝，非卑劣所及，故律中盜度奴，令主譏訶。同是奴聚，必如法放，非復為奴，本不可尋也
【譯文】第七、詢問是良人還是奴賤：因為僧伽地位極為尊貴殊勝，絕非卑賤之流所能企及，所以律中記載偷度奴僕出家，招致主人譏嫌訶斥。同樣屬於奴僕之類，如果確實依法被主人放免，便不再是奴僕，原本的奴隸身分就不可再追究了。

【1767-0002】03_業疏/14b_卷三之三#17
【原文】奴僕中初科，初、示意。「故」下，引緣。「必」下，簡主放者。本不可尋，以後從良亡前賤跡故也
【譯文】奴僕第一科中，首先說明用意。從「故」字以下，引用制戒的因緣。從「必」字以下，簡別被主人放免之人。所謂「原本不可追究」，是因為此後既然已經成為良人，先前卑賤的痕跡便已消除了。

【1767-0003】03_業疏/14b_卷三之三#18
【原文】僧祇》云：有五，若家生、買得、抄得者，此人諸處不得度也；他與、自來，餘處聽度。據此而論，本言被放，何論彼此？不放輙度，則入盜收。將非賤為譏本，雖放猶被輕故？《善見》：若放奴時云「有道心者放，無者還為奴」，如是語者不得度。準此，主自送放，開度成受；逃奴不合出家。《經》云：若放奴婢、人民出家，得大福德。斯言是也
【譯文】《摩訶僧祇律》說：奴僕有五種，若是家中生養、花錢買得、或抄掠俘虜得到的，這種人在任何地方都不得度化；若是他人贈與、或自行投奔前來的，在其他地方則聽許度化。根據這點來論斷，原本若已經被放免，何必再論此處或他處？如果不經放免而擅自度化，就歸入盜竊罪所收攝。難道不是因為身分卑賤是招致譏訶的根本，即使已經放免仍然容易被人輕蔑的緣故嗎？《善見律》說：如果放免奴僕時說「有修道之心的就放免，沒有道心的仍回來當奴僕」，說這種話的就不得度化。準照此理，主人親自送來放免的，開許度化並能成就受戒；逃亡的奴僕則不應當出家。《佛說出家功德經》說：如果放免奴婢、人民出家，能獲得極大福德。這句話正是這個意思。

【1767-0004】03_業疏/14b_卷三之三#19
【原文】引示中初科，《僧祇》五奴：家生，謂在主家產者，并下買得、抄得，皆損財力，屬主義強，諸處不得，謂本國他邦，今時一統，須論州郡；他與、自來，無損財力，他處聽之。「據」下，準決。下二：初、以義通。若非主放，度即成盜；明是放者，理合通開，何局餘處？詳究律意，為避譏呵，故云「將非」等。《善見》下，次、引文證。道心即出家心，主言無決，故不得度。「準」下，三、約義決。下仍引經，證成自放
【譯文】引文開示的第一科中，《摩訶僧祇律》的五種奴僕：家生，指在主人家中出生的，加上後面的買得、抄掠俘虜而得，這些都耗損了財力，歸屬主人的屬性極強，所以在任何地方都不得度化，這是指本國與他邦，現今天下一統，則須就不同州縣來論；他人贈與、自行投奔前來的，沒有耗損主人的財力，所以在其他地方聽許度化。從「據」字以下，是準照義理予以斷決。以下分為兩點：第一、以義理融通。如果不是主人放免，度他便構成盜罪；明確已經被放免的，理應普遍開許，為何局限於他處？詳細探討律典的用意，是為了避免他人譏嫌訶責，所以說「難道不是」等語。從《善見律》以下，第二、引文為證。「道心」即是出家修道之心，主人的話語沒有徹底決定放免，所以不得度化。從「準」字以下，第三、就義理予以斷決。下面又引用經文，證實主人親自放免是合法的。

【1767-0005】03_業疏/14b_卷三之三#20
【原文】五百問》云：知是佛奴度者，犯重；若先不知，後知不遣，亦重。其人非大道人故，僧奴準之。餘如盜戒《僧祇》等制
【譯文】《五百問事經》說：明知是佛奴而度他出家的，犯重罪；如果起初不知道，後來知道了卻不遣送回去，也犯重罪。因為那個人不能算作大比丘（不能成就受具足戒）的緣故，僧奴也比照此例辦理。其餘規定如同盜戒及《摩訶僧祇律》等處的限制。

【1767-0007】03_業疏/14b_卷三之三#22
【原文】八、官人者，皆謂勳品已上，流內九等，文武員者。恐負天朝，可憂有責；餘之散任，義不在言
【譯文】第八、詢問是否為官人：都是指勳品以上、屬於流內九品的文官武職官員。因為唯恐有負於朝廷官守，令人憂慮會招致官府責罰；其餘沒有官品的雜散職務，依理不在限制之列。

【1767-0008】03_業疏/14b_卷三之三#23
【原文】官人中初科，凡官有九品，竝據勳爵以分差次，自下至於一品，故云「已上」。係勳品者，謂之「流內」；自餘散職，並名「流外」。恐負天朝，律因比丘輙度匿王勇將白佛故制。可憂有責，謂慮國家見罪於僧故
【譯文】官人第一科中，大凡官員分為九品，都是依據勳位爵秩來劃分等級等次，從下等品級一直到一品，所以說「已上」。列入勳品品級的，稱為「流內」；其餘散任雜職，全都稱為「流外」。所謂「恐負天朝」，是律中因比丘擅自度化波斯匿王的勇猛將領，國王向佛稟白，佛因而制定此戒。所謂「可憂有責」，是指憂慮國家會怪罪懲處僧團的緣故。

【1767-0009】03_業疏/14b_卷三之三#24
【原文】僧祇》云：官有四種：有名有祿、有名無祿，此彼俱制；有祿無名，餘處得度；無名祿者，一切俱開。據此度人，知何不得？但違王制，《多論》小罪
【譯文】《摩訶僧祇律》說：官員有四種：有名有祿、有名無祿，這兩種在本地與他處都禁止度化；有祿無名，在其他地方可以度化；無名無祿的，在任何地方全部開許度化。根據這點來度人，便知道哪些人不可度化。若是違反國家王法定制，《薩婆多論》判定結輕微的小罪（突吉羅）。

【1767-0010】03_業疏/14b_卷三之三#25
【原文】次科《僧祇》，名即聲名，祿謂爵祿，用此二者，歷為四句。有名無祿，如賢臣除謫者；有祿無名，謂世之庸吏；無名無祿，即散任常流也。此彼，亦約國土為言，然或國王聽許，即非此限。「據」下，準後一句以決。庶人有謂係於官籍，不得輙度；準無名祿，義合通開。《多論》几違王制，結吉羅罪
【譯文】次一科中，《摩訶僧祇律》所說的「名」即是名望官銜，「祿」是指爵位俸祿，運用這兩項，排列為四句。有名無祿，例如賢臣被免職流放的情況；有祿無名，指世俗的庸碌小吏；無名無祿，就是雜散職任的尋常百姓。所謂「本地與他處」，也是就國土邊界而言，然而如果國王特許出家，就不在此限。從「據」字以下，依照第四句來斷定。有人認為平民百姓既然附屬於官府戶籍，就不得擅自度化；但準照「無名無祿」這句來看，在義理上理應全面開許。《薩婆多論》凡是違反國家法制者，結突吉羅罪。

【1767-0011】03_業疏/14b_卷三之三#26
【原文】九、問丈夫。夫者男子通名，丈者極形之量也。孔子九尺餘，亦有一丈者，故為大分耳
【譯文】第九、詢問是否是大丈夫。「夫」是男子的通稱，「丈」是形體高大至極的度量（一丈）。孔子身長九尺多，古人也有長達一丈的，所以取其作為成年男子的大體標準。

【1767-0012】03_業疏/14b_卷三之三#27
【原文】丈夫中初科，《孔子家語》云：孔子長九尺六寸，河目隆顙，其頭似堯，其頸似皐繇，其肩似子產，然自腰下不及禹者三寸。且舉極形，未必皆爾，故云大分
【譯文】丈夫第一科中，《孔子家語》說：孔子長九尺六寸，黃河般深長之目、高隆之額，他的頭形像堯，脖子像皋陶，肩膀像子產，然而從腰部以下比禹短了三寸。此處只是列舉形體極為高大的例子，並非人人都是如此，所以說是成年人的大體標準。

【1767-0013】03_業疏/14b_卷三之三#28
【原文】文列堪耐十事者，皆近局形骸耳。惡言、持戒，在於心護；俗以難割為之沈溺，道則反之。近忍事惱，遠忍理觀，依因有由，故簡堪能應丈夫位也
【譯文】文中列出能堪耐的十種苦事，都只是切近於形體身軀的承受而已。但忍耐惡言、嚴持禁戒，則在於內心的護持；世俗之人以難以割捨為由而沉溺愛著，修道之人則正好相反。近處能忍耐事相上的苦惱，遠處能安住於理體上的止觀，這是有其憑藉與前因的，所以要揀選具有堪能的人，以相應於大丈夫之位。
