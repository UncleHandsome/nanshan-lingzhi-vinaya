# 校閱材料　第914檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【914-0001】03_業疏/21b_卷四之四#89
【原文】沙彌同位，僧因相假，但以位卑行缺，故有降也。言等與者，與大僧同一疋也；言與半者，大僧一疋，彼二丈也；言三分與一者，即四丈中與沙彌一丈也，故異部云「一大僧分與三沙彌」是也。所以等者，莫非福田，同應供也
【譯文】沙彌與大僧同屬出家之位，並且是成就僧眾的因位而互相藉助，只是因為地位低下、戒行尚不具足，所以分配才有所降低。所謂「均等分給」，是指與大僧同樣分得一匹；所謂「分給一半」，是指大僧分得一匹，沙彌分得二丈；所謂「三分給一」，是指在四丈布中分給沙彌一丈，所以其他部派律典說「一位大僧所得的份額分給三位沙彌」，就是這個意思。之所以有均等分給的情況，是因為莫不是世間福田，同樣堪受供養的緣故。

【914-0002】03_業疏/21b_卷四之四#90
【原文】四中初敘與意。「言同位」者，僧二尼三各有類故；「僧因相假」，必由小戒至具戒故。「言」下示分法，等、半、少分，竝由僧命，觀其長幼、勤惰、善惡、貧富等。異部即《僧祇》。「所」下辨等與
【譯文】第四段中，起初敘述分給的意旨。所謂「同位」，是因為大僧有二眾（比丘、沙彌）、尼僧有三眾（比丘尼、式叉摩那、沙彌尼），各自有其同類之故；所謂「僧因相假」，是指比丘必定由受小戒（沙彌戒）逐步進至受具足戒的緣故。自「言」字以下指示分配之法，均等、減半或給予少分，都由僧團差遣決定，觀察其年齡長幼、作務勤惰、行止善惡、資生貧富等情況而定。其他部派就是指《摩訶僧祇律》。自「所」字以下辨明均等分給的道理。

【914-0003】03_業疏/21b_卷四之四#91
【原文】守寺淨人應等與，乃至《五分》中與一分者，體非福田，以供僧勞，望僧故合。不與、不應分者，以制在僧，僧須周給，今但繼於上尊，不兼及下，失於僧和無礙，即非僧義，雖分不合，又是盜攝也
【譯文】守護寺院的淨人應當均等分給，乃至在《五分律》中分給一份的情況，是因為其本質雖然不是福田，但由於為僧團服勞供役，對待僧團的勞苦而言是合宜的。至於說「不給予」、「不應分配」的說法，是因為權限制定在於僧團，僧團必須周遍施給，如今如果只接濟上座尊者，而不兼顧下位之人，就喪失了僧團和合無礙的意義，便不符合僧伽的精神；這樣即使分配了也不合律制，而且屬於盜戒所攝之罪。

【914-0004】03_業疏/21b_卷四之四#92
【原文】五中初敘得分之意，非福田故少與，供僧勞故須與。「不」下次釋不與之過，恐謂俗眾不預施故。「不合」是吉，「盜收」犯重
【譯文】第五段中，起初敘述淨人得以分獲利養的意旨：因為不是福田，所以少分給予；因為服侍僧團有勞苦，所以必須給予。自「不」字以下接著解釋不給予的過失，這是恐怕有人認為俗人眾等不應當參與施與的緣故。「不合」是指犯突吉羅（輕垢罪），「盜收（盜取收執）」則違犯重罪。

【914-0014】03_業疏/21b_卷四之四#102
【原文】次科初指廣。亡物重輕即處判也；作法制約即攝僧、別賞勞、付分等也。鈔及儀文，開釋甚廣。「至」下勸引，仍誡曉達。今更略分：二亡物中，大分為二，初敘所屬，「又」下次示分法，十門明之，大同儀、鈔，文亦自顯，有疑尋對。第九門中有四，前二是僧，後二即別。初僧即五人已上，行事備故。付分羯磨中「諸長老」下，秖合單牒根本，多牒緣十五字，秉時削去
【譯文】下一科起初指示詳盡的廣文。亡僧遺物的輕重即是指處置判斷；作法制約即是指召集僧眾、特別賞賜勞苦、交付分派份額等。在《事鈔》與《輕重儀》文中，開示解釋得極為詳盡。自「至」字以下勉勵予以引證，並誡飭必須通曉明達。如今再略作劃分：在第二科亡物之中，大體分為兩部分，起初敘述遺物的歸屬，自「又」字以下接著指示分配之法，以十門來加以說明，大致與《輕重儀》及《事鈔》相同，文意也自然顯明，若有疑問可對照查尋。第九門中包含四種情形，前兩種屬於僧團公有，後兩種即屬於個人私屬。起初僧團的情形是指五人以上，因為羯磨行事具備的緣故。付分羯磨文中在「諸長老」之下，只應當單獨宣讀根本語句，若多讀了事緣的十五個字，在秉持作法時應當刪去。

【914-0017】03_業疏/22a_卷四之五#3
【原文】上諸門中，被於行淨專精之人。但以五濁澆風，鼓扇塵境，不能制割，遂與犯同。若不清蕩，未曰智人；覆藏瑕疵，終歸顯露。故當及時早懺，不可後世悔之。
【譯文】上面各門之中，是加被於行業清淨、專精修持的人。然而由於五濁惡世的澆薄之風，煽動塵勞境界，行者若不能克制斷割，於是就如同犯戒一般。如果不加以洗滌清蕩，就算不上是智慧之人；若隱瞞遮蓋自身的瑕疵罪咎，終究會顯露出來。所以應當及時早早懺悔，不可等到來世才後悔。

【914-0018】03_業疏/22a_卷四之五#4
【原文】敘意中初科，初二句結前七篇正宗行相；「但」下，生起當篇須立之意。初敘成犯之由，五濁：時數漸減為劫濁，邪執堅固為見濁，催年促壽為命濁，三毒猛盛為煩惱濁，分別妄計為眾生濁，皆非清淨，故並名濁，亦名五滓，即是有情、無情二種世間。劫減情浮，逐境造業，與犯同者入篇聚也。「若」下明須懺所以，注引律二種愚人、二種智人：一、堅持不犯，二、犯已能懺。「終歸顯露」，即現、當、後三報。
【譯文】敘述大意中的第一科，前兩句總結前面七篇正宗的行持相狀；自「但」字以下，生起本篇必須建立的意旨。起初敘述構成犯戒的緣由，所謂五濁：年月壽數漸減為「劫濁」，邪倒妄執堅固為「見濁」，摧折年歲促短壽命為「命濁」，貪瞋癡三毒熾盛為「煩惱濁」，分別妄加計度為「眾生濁」，全都不是清淨之法，所以一併稱為「濁」，也稱為「五滓」，這就涵蓋了有情世間與器（無情）世間二種世間。在減劫中凡情浮躁，隨逐塵境造作惡業，與犯戒相同者便墮入相應的篇聚之中。自「若」字以下說明必須懺悔的原因，注文引述律典中所說的二種愚人與二種智人：智人一是堅持不犯，二是犯了之後能夠悔改。「終歸顯露」，就是指現報、生報、後報這三報必定受報。

【譯文】第三段中，《大智度論》對四惡趣各自有一首偈頌，這裡引用的是地獄偈。前一偈開示地獄的苦報，「陰」就是五陰，猶如融鐵聚合，只是大略譬喻極少部分，所以說不可譬喻；後一偈是勸勉修行。餓鬼偈說：「餓鬼承受污穢的身形，其種類有百千之多，連水漿的名字都聽不到，動輒歷經千萬劫。」畜生偈說：「畜生互相殘害，日夜常受恐怖逼迫，因為愚癡蒙蔽障礙的緣故，根本無從思索求取解脫。」阿修羅偈說：「阿修羅被五道所攝，以威武之勢對抗諸天，因為多有懷疑而不信順的緣故，焚燒毀滅了一切善根。」自「斯」字以下是總結告誡。船舟譬喻聖法，可以用來救濟度脫。同法、同道、同行、同學等人，都是用來稱呼出家奉持戒律之士。

【原文】凡罪生也，託因從緣。因即妄心，非有謂有，隨有興我，便計彼此，即起集業。故經說言：「一切諸法自本來今，性相空寂；而眾生虗妄，橫計得失彼我，起不善念，造眾惡業，輪迴五道，億劫不出。」二者妄緣，境有色心，由之造業，不知心變，妄謂他有，還緣自心，故反纏裹。如說「三界上下法，我說皆是心」，向造諸業，但知唯心，則無分別是彼此也
【譯文】大凡罪業的生起，都是依託內因而順從外緣。所謂「因」，就是妄心，原本非有卻妄認為有，隨著妄執的有而生起我見，隨即計度彼我分別，由此便發起積集惡業。所以佛經中說：「一切諸法從無始以來至今，其本性與行相皆是空寂；然而眾生虛妄，橫加計度得失與彼我，生起不善之念，造作種種惡業，輪迴流轉於五道之中，億劫不得出離。」第二是「妄緣」，所緣境界包含色法與心法，依此造作罪業，卻不知道一切境界皆是唯心所變，妄自認為心外別有他境，反過來又以自心緣取妄境，所以反被自身纏縛包裹。就如佛所說「三界上下的一切法，我說全都是自心所現」，從前所造的種種罪業，只要通達唯是自心，那麼也就不會去妄自分別彼此了。

【914-0026】03_業疏/22a_卷四之五#12
【原文】義門第一立懺意中，初科初總標。「因」下，別釋，又二：初示罪因。妄，無也，無而謂有，即是妄義。由隨境有，謂之六塵緣影，亦名六境界心，幻化、陽𦦨、龜毛、兔角皆喻此心。興我起業，生死輪迴。由不了此，故下引證。「諸法本空」，證非有也；「眾生妄計」，證謂有也。「橫計」等是惑道，「起不善」等是業道，「輪迴不出」即苦道。二明罪緣。色、心二法攝境盡故。「不知心變」，迷唯心故；「妄謂他有」，計心為境故；以心緣心，造業自縛，如蠶繭故。已上敘迷，如下顯悟。三界中，色、無色天為上，欲界為下。或云「三界無別法，唯是一心作」，語少異耳。既了唯心，反觀前罪皆非他法，故云「向」也
【譯文】義門第一「立懺之意」中，第一科起初是總標。自「因」字以下作分別解釋，又分為兩部分：首先開示罪業的內因。「妄」，就是虛無，本無而妄認為有，這就是「妄」的意思。因為隨逐境相而執為實有，稱為六塵緣影，也稱為六境界心，幻化、陽焰、龜毛、兔角都是用來比喻這種心念。由執我而造起業行，導致生死輪迴。由於不明白這個道理，所以下文引經為證。「諸法本空」，證明本來非有；「眾生妄計」，證明妄自認為有。「橫計」等等屬於惑道，「起不善」等等屬於業道，「輪迴不出」即是苦道。其次說明罪業的外緣。色法與心法兩種法門已將一切境界攝盡。「不知心變」，是因為迷失了唯心的實相；「妄謂他有」，是因為執取自心妄現之相為心外實境；以心去攀緣自心，造業而自我繫縛，就如同春蠶作繭自縛一樣。以上是敘述迷亂之狀，以下則是顯發覺悟之態。在三界之中，色界與無色界天為上，欲界為下。有的經文說「三界無別法，唯是一心作」，只是用詞稍有差異而已。既然明了唯心，反觀先前所造的罪業全都不是心外之法，所以說「向（從前）」了。
