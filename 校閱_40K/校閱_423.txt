# 校閱材料　第423檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【423-0001】03_業疏/15a_卷三之四#84
【原文】答中初略指今宗，羯磨首標曇無德部自可知故。「此」下次對辨假實。小教入道不出四宗：一空、二有、三雙亦、四雙非。今取此方盛行，故唯有二。言假宗者，彼明諸法緣生故空，故名空宗；但有名字，故名假宗；又深取大乘空義，故名經部師。實法宗者，彼明我人等假名是空，陰界入等並是實有，亦名一切有宗，亦即毗曇部
【譯文】回答中，首先簡略指出本律所屬教宗，因為羯磨卷首已經標明曇無德部，自然可以知曉。「此」字以下，接著對比辨析假宗與實宗。小乘教法入道門徑不出四宗：第一是空宗、第二是有宗、第三是雙亦（亦空亦有）宗、第四是雙非（非空非有）宗。如今只選取此方中土盛行弘傳的，所以只有二宗。所說的「假宗」，該宗闡明一切諸法因緣和合而生所以體性本空，因此稱為空宗；諸法唯有假立的名字，所以稱為假宗；又深深汲取了大乘的空義，所以被稱為經部師。所說的「實法宗」，該宗闡明我、人等假名是空無自性的，但五陰、十八界、十二入等法體全都是真實存在的，也稱為「一切有部」，也就是阿毗曇宗。

【423-0002】03_業疏/15a_卷三之四#85
【原文】故律明色，眼識能見，異於毗曇根能見也。諸有結正，並問何心，故云「造善見三業，當審觀其意」，不同彼宗身口七業皆是色中，有損益故，餘不具出
【譯文】所以本律說明色法時，主張是眼識能夠見色，這不同於阿毗曇宗主張是眼根能夠見色。凡是律中判定根本重罪（結正罪），都會審問當時是出於什麼心念，所以說「造善雖顯現於三業，應當仔細審察他的本意」，這不同於有部宗認為身、口七支業全屬於色聚之中、由具有增減損益之義而立為色法，其餘的差異不再一一詳述。

【423-0003】03_業疏/15a_卷三之四#86
【原文】次科有二：初明根識異。《四分》且舉眼根，餘根皆爾，既推心識有所分別，則顯通深，但不談七八，與大異耳。毗曇不爾，既不推心，故唯根見。眼耳鼻等為浮塵根，見聞覺知即勝義根，二皆是色，唯意是心。「諸」下次明結犯異。結正即結篇聚正罪。律中凡比丘犯過，問佛求決，佛問汝以何心犯，有心則斷成犯，無心則云不犯，此明兩犯由心也。故下即律序偈，雖具三業，主在於意，故偏審之。彼云「備具三種業」，則通於持犯，今此易之，且據二持為言。彼宗不爾，七支並判色聚所收，故云皆是色中。即《雜心》云：色者一切身口業是色性，因四大故。有損益者，示彼所計，如善戒持則體肥，犯則戒羸；罪業造則更增，懺則除滅。由有此義，故立為色。如上《雜心》因四大者，亦彼所計，能造是色，所造亦然。彼宗立色不出斯二。下指餘者，如後五義顯示分通，全乖小道，此且略之
【譯文】下一段科文有兩部分：首先說明根見與識見的差異。《四分律》暫且舉出眼根為例，其餘諸根也是如此，既然推究到心識具有分別作用，就顯示出其義理通向深遠，只不過不談第七識、第八識，而與大乘有所差別而已。阿毗曇宗則不是這樣，既然不推究心識，所以主張純粹是根見。眼、耳、鼻等肉眼可見者是浮塵根，能發起見、聞、覺、知的精微物質便是勝義根，這兩者全都屬於色法，唯獨意根屬於心法。「諸」字以下，其次說明結定犯戒的差異。「結正」就是結定篇聚之中的正罪。律中凡是比丘犯了過失，請教佛陀尋求裁決，佛陀總是問：你當時是以什麼心犯的？如果是有心故意則斷定構成犯戒，若是無心則判定不犯，這說明了成犯與否兩者皆由心念所決定。引文「故」以下即是律序當中的偈頌，雖然具備身、口、意三業，但主導全在於意念，所以特別審究它。彼偈原文明明說「備具三種業」，實則通於持戒與犯戒，如今這裡稍作變通，暫且依據止持與作持二持的角度來說。有部宗則不是這樣，身三口四等七支業行全都判定屬於色聚所收攝，所以說「皆是色中」。也就是《雜心論》所說：所謂色法，一切身業、口業都是色法的自性，因為依四大所造的緣故。所謂「有損益」，是指明彼宗所計執的觀點，例如善戒守持則戒體肥充增長，若有毀犯則戒體羸弱虧損；惡罪業若去造作則進一步增長，如法懺悔則罪業消除磨滅。由於具有這種增減損益之義，所以立為色法。如上面《雜心論》所說「因四大者」，也是彼宗的計執，認為能造的四大是色法，所造的身口業自然也是色法。彼宗安立為色法不出這兩種原因。下文指出其餘各點，例如後文以五種義理顯示《四分律》分通大乘、完全不同於狹隘小乘小道，這裡暫且略過不提。

【423-0005】03_業疏/15a_卷三之四#88
【原文】體謂業體，正是戒法所依本也。經論所談善惡業者，名也；今述作、無作者，業之體也。混名從體，一也；離實談名，異也
【譯文】所謂體，就是業體，正是戒法所依止的根本。經論中所探討的善惡業，是名稱；現在所闡述的作戒與無作戒，是業的自體。融攝名稱順從自體而言，名稱與自體是一體的；若脫離實體單純談論名稱，二者則是有差別的。

【423-0006】03_業疏/15a_卷三之四#89
【原文】第二定名體中初示體相。思願要緣，攬法成業，故塵沙戒法為能依，業體無作為所依也。「經」下次會名體。諸論明善惡業，即作、無作之名；作、無作即善惡業之體。作與無作，二俱名業，業名是通，作無作別。混名從體一者，名體相即故；離實談名異者，名體兩分故。「混」猶攝也
【譯文】在第二項審定名稱與自體中，首先開示體相。發起思願要誓的緣境，攬取法界戒法成就戒業，所以如塵沙般的眾多戒法是能依，而無作戒體本身則是所依。「經」字以下，接著融會名與體。諸部論典所闡明的善惡業，就是作戒與無作戒的總名；作與無作，則是善惡業的具體實體。作與無作二者都稱為業，「業」這個名稱是通稱，作與無作則是個別的名稱。所謂「融攝名稱順從自體為一」，是因為名稱與實體彼此相即不二的緣故；所謂「脫離實體單談名稱為異」，是因為名稱與實體劃分為二的緣故。「混」的意思就是攝合。

【423-0007】03_業疏/15a_卷三之四#90
【原文】多論》陳體，教、無教也；《成實》、《雜心》，作、無作也。皆略名銓體，義說動靜，而難顯其相，如諸塵也。今且依俙，如論兩傳，寄之取狀
【譯文】《薩婆多論》陳述戒體，稱之為「教」與「無教」；《成實論》與《雜心論》則稱為「作」與「無作」。這些都是簡略其名而詮顯其體，從義理上分為運動與寂靜，然而其具體相貌極難顯了，就像各種微塵的積累一樣。現在姑且依稀彷彿地，依照各部論典所流傳的兩種說法，借用它們來描摹取顯戒體的形狀。

【423-0008】03_業疏/15a_卷三之四#91
【原文】次指體中初示諸文。《多論》「教、無教」義，篇首已釋。《俱舍》名為表、無表者，取表示義。《雜心》體同多宗，名濫《成實》。「略名」謂不論善惡業也，「詮體」謂唯明作無作也。「動」即是作，「靜」即無作。「如諸塵」者，取相類也。《心論》云：七極微成一阿耨，七阿耨為一銅上塵，七銅塵為一水上塵，七水塵為一兔毫上塵，七兔毫塵為一羊毛上塵，七羊毛塵成一牛毛上塵，七牛毛塵成一向遊塵，七向遊塵成一蟣，七蟣成一虱，七虱成一𪍿麥等。「今」下標今釋。「依俙」，隱約之貌。相既難顯，且寄兩宗之論出其相狀，即彰此門陳體，且依二宗所計，至後正義三宗分別，始是今師正出體相
【譯文】在其次指出戒體中，首先出示各家文獻。《多論》所說的「教」與「無教」的含義，在篇章開頭已經解釋過了。《俱舍論》稱之為「表」與「無表」，是取顯現表示之義。《雜心論》的體性同於有部宗，其名稱卻與《成實論》相同。「略名」是指不談善惡業的名稱，「詮體」是指唯獨闡明作與無作的自體。「動」就是作業，「靜」就是無作業。「如諸塵」是取相似的比喻。《雜心論》說：七個極微構成一個阿耨微塵，七個阿耨構成一個銅上塵，七個銅塵構成一個水上塵，七個水塵構成一個兔毫上塵，七個兔毫塵構成一個羊毛上塵，七個羊毛塵構成一個牛毛上塵，七個牛毛塵構成一個向游塵（日光中浮塵），七個向游塵構成一蟣（蝨卵），七蟣構成一蝨，七蝨構成一粒稞麥等。「今」字以下標明如今的大師解釋。「依俙」是隱約彷彿的樣子。相貌既然難以顯明，姑且寄託於兩宗論典標出其相狀，這正是顯明本門陳述戒體，暫且依循這兩宗的主張，等到後面「顯正義」以三宗加以辨別時，才真正是南山大師正式確立戒體體相之處。
