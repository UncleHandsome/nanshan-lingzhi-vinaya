# 校閱材料　第1100檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1100-0001】資持記/07b_中一下#31
【原文】世疑戒本防非，三乘果人，煩惑既傾，業非永喪，何用戒為？又經律中，如來成道，方始感戒，羅漢破結上法得戒。準此初句，頗決深疑；更有別通，文在《義鈔》。境不盡者，經云：眾生無盡，戒亦無盡；此舉正報必兼依報，故非情境亦無盡也。第二句。正通前難，餘三相因而來。
【譯文】世人常疑惑戒律本是用來防範過非的，三乘聖果之人既然已經拔除煩惱迷惑，惡業過非已經永遠滅盡，又何必還要戒法呢？再者經律中提到，如來成道之後才開始感得戒法，阿羅漢破除煩惱結使後依上品善法得戒。依據這第一句，很大程度能化解這層深微的疑惑；另外還有其他會通的說法，記錄在《拾毘尼義鈔》中。所謂「境界無有窮盡」，佛經說：「眾生無窮無盡，戒法也無窮無盡」；這裡舉出正報眾生，必定連帶包含依報環境，所以無情的境界也是無窮無盡的。第二句，正是正面會通先前的難問，其餘三句則是順著文理推演而來。

【1100-0002】資持記/07b_中一下#32
【原文】心過在者，以惑心未破，妄業隨興；害生斷草，心不息故。三二俱句。凡夫現境，二皆存故。四中。不同者，如初四重，名僧尼同戒；後四重，尼有僧無；漏觸麁歎，僧有尼無，名不同戒。如僧轉為尼，漏觸等境，非我所防，復無能防，故云俱謝。此句論謝，即不同前謝滅之謝，比之可知。
【譯文】「心念的過非依舊存在」，是因為凡夫內心的惑業尚未破除，虛妄的業力隨時生起；傷害眾生、砍折草木的心始終沒有止息。第三句「兩者俱存」，是說凡夫面對當前的境界，能造惡的心與所造的境兩者都依然存在。第四句當中，所謂「不相同」，例如最初的四波羅夷罪，稱為僧尼共戒；後面的四重罪，比丘尼有而比丘沒有；故出精、摩觸、說麤惡語、讚歎自身索供等戒，比丘有而比丘尼沒有，稱為僧尼不共戒。例如比丘變性為比丘尼時，摩觸等戒所緣的境界不再是自己所要防範的對象，自己也沒有了比丘那種能防範的身分，所以說能防所防「全都謝滅」。這一句所論述的謝滅，與前面所說動作停止的謝滅不同，互相比較便能清楚。

【1100-0003】資持記/07b_中一下#33
【原文】次明非情中，初文。論約大千者，據宗限也；下文多云法界，其語猶通；須約大小簡辨寬狹，此意常切知之。罪福，即善惡也。《善生》中。且舉無情，四義，如下配戒中。以下，結勸。可知。三情境中。阿鼻非想，別舉上下，統攝中間。可不可者，或約三世；可即現在，不可即過未；
【譯文】接著說明「無情境」，第一段文字中：論典以「大千世界」來作界定，是依據該宗派教理的局限；下文多次提到「法界」，語意就比較寬廣圓通；必須依據大乘或小乘的教義來簡別寬狹，這個要點應當隨時精準掌握。所謂「罪福」，就是惡業與善業。《善生經》中，姑且舉出無情境的四種涵義，下文會將它們配屬在戒法中。自此以下，是結尾的勸勉，道理十分明確。在第三「有情境」當中：阿鼻地獄與非想非非想處天，是分別舉出三界的極下與極上，以此統攝中間的所有世界。所謂「能加害與不能加害（可不可）」，也可以從三世來論：能夠加害的指現在世，不能加害的指過去與未來世；

【1100-0004】資持記/07b_中一下#34
【原文】又現在中，五道相隔；又人中，遠近不及；又近中，凡聖可否等。乃至者，略淫盜也。如來者，獨指釋迦；亦當分義，大取恒沙。三因緣者，即三善也。又下，結歎。通五眾者，境量同故。戒德瓶者，即喻受體；《智論》云：持戒之人，無事不得；破戒之人，一切皆失；譬如有人，常供養天，以求富貴；
【譯文】又在現在世當中，五道輪迴彼此隔絕；在人道當中，遠方與近處的力量所達不到；在身邊近處當中，凡夫與聖人的境界是否能夠觸及等等。「乃至」一詞，是簡略帶過了淫戒與盜戒。「如來」，在小乘單指釋迦牟尼佛；這也是就小乘本分的教義而言，若依大乘則通指恆河沙數諸佛。「三種因緣」，就是指無貪、無瞋、無癡三善根。「又」字以下，總結讚歎。說「通於五眾」，是因為五眾所面對的戒境廣度是完全相同的。「戒德瓶」，就是用來比喻戒體；《大智度論》說：持戒的人，沒有什麼善願不能達成；破戒的人，一切功德全都喪失；這就好比有人長期供養天神以祈求財富富貴；

【1100-0005】資持記/07b_中一下#35
【原文】天愍此人，乃與一器，名曰德瓶，所須之物從此瓶出；其人得已，應意所欲；以至憍佚，立瓶上舞，瓶即破壞，眾物皆滅。持戒之人，亦復如是；種種妙樂，無願不得；若憍佚自恣，亦如彼人，破瓶失物。端拱，謂縱不持也。福德，即無作。《了論》中，初科，分二，初引論；據下，二結歎。
【譯文】天神憐愍這個人，就給了他一個寶瓶，名字叫作「德瓶」，所需要的一切物資都會從這個瓶子中源源不絕現出；這人得到寶瓶後，事事稱心如意；以致驕慢放蕩起來，甚至站在寶瓶上跳舞，寶瓶隨即被踩碎損壞，瓶中變現的財物也全部化為烏有。持戒的人也是如此，能夠獲得種種微妙的安樂，沒有願望不能實現；如果驕慢放縱、自暴自棄，也就如同那個人踩碎寶瓶而失去所有財富一樣。「端拱」，是指即使放任雙手不作身口持守的動作。所謂「福德」，就是指無作戒體。《戒律二十二明了論》中，第一科分為兩部分：首先引用論典；「據」字以下，第二部分是總結讚歎。

【1100-0006】資持記/07b_中一下#36
【原文】初中，先引論文。次引論解，此又分二，初配數顯德，前釋名義。福即善業，河即譬喻。破戒煩惱，即業惑二道。言下，合數，三段，先示戒數。所引律戒，皆彼論自指，此土竝無；又指尼別戒，亦據彼部，不可以今宗挍之。問：《了論》宗正量，何以戒數不依彼部？
【譯文】第一部分當中，先引用論典的本文。接著引用論典的解釋，這又分為兩節：首先配屬數量以顯發戒德，在此之前先解釋名詞的涵義。「福」就是善業，「河」是借用江河奔流不息作譬喻。「破戒的煩惱」，就是指惡業道與煩惱道兩者。「言」字以下，將戒數作具體的配合，分為三段：首先標示出戒律的條數。所引用的律法戒相，都是該論典自己所指稱的，在漢地都沒有譯本；所指比丘尼特有的戒律條數，也是依據該部派的傳承，不能拿現在的四分律宗來硬相校對。有人問：《明了論》屬於正量部，為什麼戒律條數不依照正量部的規定呢？

【1100-0007】資持記/07b_中一下#37
【原文】答：或恐止量戒本，宗彼二律；又恐欲顯多相，故用別部也。一一戒下，次以十利配戒。一戒有十利，總成四千二百。一一功德下，後以十行配利。一利有十行，一戒成百行，總成四萬二千。信等者，等取二精進，三念，四定，五慧。身口二護，通一切戒，不可專配七支。又下，二舉名顯具。
【譯文】回答：或許是因為當時該論只考量戒本，而依據了那兩部律典；又或許是為了顯發更多持犯行相，所以借用了其他部派的數目。在「每一條戒」以下，接著以十種利益配屬各戒。一條戒具備十種利益，總共合為四千二百種利益。在「每一種功德」以下，最後以十種行持配屬各利益。一種利益具備十種行持，一條戒就成了一百種行持，總共合為四萬二千種行持。「信等」，是等同包含第二精進、第三念、第四定、第五慧。身業防護與口業防護通於一切戒律，不能專門配屬給身口七支。在「又」字以下，第二項舉出名稱以顯發圓滿具足。

【1100-0008】資持記/07b_中一下#38
【原文】謂以無願之名，顯滿足之義。言學處者，是修行者所依處故。問中。論取僧尼二戒，合成四百二十；今據一眾，不當具發四萬二千，故以為問。初解中。謂一眾邊，實不可具。準前二律，僧有三百二十一戒，則有三萬二千一百；尼戒，但出與僧別戒之數，未知彼部尼戒少多，不可妄配。
【譯文】這是用「無願」的名義，來顯明戒德滿足的深意。稱作「學處」，是因為戒律是修行者所依止處進修的根本。在提問中：論典將比丘與比丘尼兩部戒本加起來，總共構成四百二十條戒；如今若只就單獨一個部眾來說，理應不能全數引發四萬二千種行持，所以提出這個疑問。在第一種解答中：認為就單一僧眾自身而言，確實無法全數具足。依照前面兩部律典，比丘有三百二十一條戒，那就應當引發三萬二千一百種行持；比丘尼戒，論中只列出與比丘不同的戒條數，不知道該部派的比丘尼戒總數究竟有多少，不能胡亂配屬。
