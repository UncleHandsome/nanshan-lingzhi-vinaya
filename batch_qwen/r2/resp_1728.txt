整體看下來，這八則譯文的**義理掌握大致正確、行文也順**，沒有嚴重的顛倒解讀。問題集中在幾處：一句語法斷裂、一個無據的增補、幾個詞的訓解不一致或含糊。以下按「該改」與「可再斟酌」分列。

---

## 一、建議必改

### 1.【#110】「把」字句沒有著落，且「非想」的釋義與【#111】自相矛盾

譯文：「他們**把**非想天以及有頂天（非想非非想處天），因為心念沈寂微細、粗浮之心不再覺察，便自稱契會了大道至理……」

兩個問題：

- **語法斷裂**：「把 A 以及 B，因為……，便自稱……」——「把」字後面沒有處置動詞，句子接不下去。
- **術語不一致**：緊接著的【#111】元照記明說「『非想』，即**色界無想天**；『有頂』，即無色界非想非非想處天」。譯文卻只給「有頂」作註，讓「非想天」與「非想非非想處天」並列，讀者必然誤以為兩者同指或重複。

建議改：
> 他們認為「非想」（即色界無想天）與「有頂」（即無色界非想非非想處天）這兩處，心識都已沉沒隱微、粗顯的心念不再覺知活動，便自稱已契會大道至理……

另可加一譯註：道宣疏中「非想」特指無想天，與一般慣稱的「非想非非想」不同，元照記已作判釋。

### 2.【#105】「如有一室」是無據增補

原文只作「**如下**出計」，譯文逕填「自『如有一室』以下」。所引疏文若實作「如獼猴……」或其他起句，這個補字就錯了。建議保守處理為「自『如……』以下（指疏文舉喻之文）」，或查對前段疏文後再確定引號內的字。

同段「窻猴為喻」譯作「以窗戶與猴子作比喻」略嫌籠統，可作「以『六窗一猴』為喻（一猴居室，六窗皆應，看似六而實一）」，與下文「似多而一」才扣得上。

### 3.【#107】「進修」≠「進一步修持」

原文：「而此七覺，**通是運智擇法進修**」。
譯文：「全都是運用智慧簡擇正法並**進一步修持**」。

「進修」是**精進修習**，不是「進一步」。【#106】「方便增修」有「增」字，譯「進一步精勤修習」無妨；此處無「增」，應改「精進修習」。

### 4.【#107】「以為臻極」的主語錯位

原文是說：八萬劫外冥然不知之處，**外道便認定那就是究竟極處（涅槃）**。
譯文「便**自以為達到了**終極之境」，變成「自己已證到極處」，與下文「意謂凡人八萬劫盡，自至涅槃」（是理論推斷，非自謂已證）不合。

建議：「幽暗而不知其處，便認為那冥然之處就是究竟極處」。

### 5.【#108】「遠業將起」語意含糊

譯文「**長遠的善業即將生起**」，容易讀成「未來將造長遠的善業」。原意是**宿世久遠所造的天業即將成熟感果**。

建議：「宿世久遠所造的生天善業即將感果，因而轉生色界天；彼外道不推究這久遠的宿因，反以為就是眼前畜生果報（吃草等行）本身能生天」。

## 二、可再斟酌

| 出處 | 譯文 | 建議 |
|---|---|---|
| #105 | 「隨逐塵境生滅的**事象之識（事識）**」 | 「事象之識」生硬且與括註重複。事識即**六識**（對梨耶本識而言），可作「隨塵境生滅的六識（事識）」 |
| #105 | 「如果這樣的話，佛法也談到單一識」 | 這是設問，宜標出「（問：）既然如此，佛法也說『唯是一識』……」，語氣更清楚 |
| #106 | 「冥諦涅槃的處所」 | 「冥諦」是數論派所計萬法本源的冥性，首次出現宜加短註，否則白話讀者無從理解 |
| #106 | 「任運至窮」→「任其自然運轉到了極盡之時」 | 可補足為「任運流轉到（八萬劫）業盡之處」 |
| #106 | 「乃剋」→「才能成辦」 | 「成辦」偏泛，宜「才能剋證道果」，與上句「終歸果剋」呼應 |
| #108 | 「世間的八種禪定」 | 依【#109】可補註「即四禪、四空定」 |
| #109 | 「只是**中間被其他**強業牽引受生為畜生」 | 「中間／其他」是增字釋義，方向沒錯（順後次受業），但可簡化為「今為強業所牽而受畜生報」，減少無據成分 |
| #110 | 「破除**妄計生處涅槃為真正道果**的人」 | 疊床架屋、語意拗口。建議「為破除妄計此等生處即是涅槃之道的人」 |
| #111 | 原文「非有無想天」逕譯「非想非非想處天」 | 依義改讀正確，但原文字面有訛略，宜出一校註（疑當作「非有想非無想天」） |
| #112 | 「諸入」（**定境處所**） | 這個括註是猜測。「諸入」通常指十二入，或十一切入（十遍處定）；從下文「緣色住心」「以空滅色有」看，偏指定所緣入處。建議查證後再註，或暫不加註 |
| #112 | 「自心運轉運用的**範圍廣狹**多少」 | 「範圍廣狹」為增義。可作「都只是自心作用（業用）的差別而已」 |
| #112 | 《智論》引文原樣照錄 | 其餘全文皆已白話，此處獨留文言，體例不一。建議補譯：「外道能造禪定之船，渡過欲界、色界之海；但無色界海深廣，難以得度，因為未能破除我見之故。」（原文引文缺下引號，譯文補上可，但宜註明） |

另，#112「以色滅欲有」的「滅」，在外道是「自謂已滅」，實際只是伏離；若加一小註更不易誤導，非必改。

## 三、體例建議

1. **術語統一表**：事識／梨耶、非想（＝無想天）／有頂、四依、八禪、七覺支「除＝輕安」——前後各則的註解要一致，尤其「非想」這條目前#110與#111打架。
2. **引號內的疏文起句**（「如下」「佛下」「彼下」）一律以實際疏文核對後再填，避免#105那樣的推測性補字。
3. **增補義譯**（如「不知自身正是虛妄」「取捨」「凡夫」）方向都對，但建議統一用括號或譯註標示，讓讀者分得清哪些是原文、哪些是依記補釋。

總結：**#110 那一句（語法＋術語）優先修**，#105 引文、#107「進修」「臻極」、#108「遠業」次之，其餘屬潤飾與體例層面。
