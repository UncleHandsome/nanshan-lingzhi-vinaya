# 南山律典譯校流程修正指南

## 一、修正總綱（為什麼要改、改什麼）

本次修正同時處理三層問題：
1. **提示詞補漏與升維**：把《尼鈔》抽檢發現的複合條件拆解誤讀、列舉邊界失真、一般古詞直留／窄化、對象省略等問題，抽象為可跨六部書通用的原則（不寫死個案字詞）。
2. **消除內部與跨關矛盾**：解決「無工具的修訂能否駁回有工具的審核」「同義疊詞 vs. 純修辭」「標題短語 vs. 遮蔽反讀」「甲乙相同跳過裁決 vs. 防同誤」「`NO_TOOLS_SYSTEM` 與主線規則不同步」等衝突。
3. **建立〈體例規範〉與修補程式盲區**：把提示詞管不到的跨段格式統一抽成獨立體例表；並修補 `norm.py` 引號內跳過簡轉繁、`SIMP` 補丁表與 `merge_long.py` 目錄互蓋問題。

## 二、獨立〈全書體例與譯例表〉（解決跨段一致性）

單段送審彼此獨立，跨段一致性不要靠審核員臨場猜測，建議統一抽出成獨立常量 `STYLE_SPEC`（可置於 `book_config.py`，直接附掛於 `BLIND_PROMPT`、`JUDGE_PROMPT`、`AUDIT_PROMPT`、`DRAFT_PROMPT` 末尾）：

```text
【全書共通體例】
1. 儀式代稱與引號：羯磨、表白、發露文中的「某甲」一律保留原稱「某甲」，不改「某某」；凡直接宣讀、唱白或心念的定型儀式文句，一律以「……」全形引號包圍。
2. 平行條目一致：同屬一組排比綱目（如四依、諸聚名目）之標題詞性與重複關鍵詞（如「長利」譯「額外的利養」），前後維持同一結構與譯法。
3. 鈔主引導詞：「義云」「釋云」等鈔主釋義起語，依文脈統一譯為「按義而言」或「釋義如下」（記實見聞時可譯「按（個人）所知／見聞而言」），勿僵硬套用。
4. 標點與字形：一律使用現代繁體標準字形（如「蓄留」「裡」「污」），引文結尾與鈔主結語之間以句號明確切分，勿以分號混連。
```

```text

### 原則
1. **忠實**：不漏條件、實質夾注、音訓與實詞；不增原文所無的細目、背景、程度誇飾或考訂，亦勿將特例限縮戒名通義。省略之主賓、受益或受事對象及前提條件直接融入句中；背景截斷而未見所指時，寧用中性泛稱，不臆補。
2. **律義與文法**：{book_ctx}{shuji_rule}辨古今異義、部別稱謂、科判層級與「文」之所指；嚴核主客施受、持犯開遮與模態強弱、想疑心念、作法時序與複合條件邏輯（勿將連帶或並存要件拆為各自獨立的充分條件）、範圍否定作用域與列舉邊界（區分封閉定舉與開放舉例，勿擅增開放詞或漏譯限定詞）；句尾虛字須辨結上或領下，引文起迄與標點須分明，勿混同著者評論。{tail_rule}
3. **表達與專詞分界**：消除文言直抄與歐化倒裝，輸出語法自足、簡明自然的現代正體書面白話；涉及戒相、身體或行為要件之實詞須精準直譯，勿改為籠統委婉語。律宗專名、法數、古度量衡與儀軌稱謂原則保留原稱；一般古漢語物名、性狀與動作實詞及古今撞義詞，須轉譯為無歧義之現代書面確詞（並避開現代口語歧義詞）。
4. **衝突優先序與短語豁免**：凡忠於原文詞序／字面將導致現代讀者單讀時誤判主客、時序、詞義或條件邏輯者，必須改用現代確詞並展開完整句法成分；惟科判標題與條目綱要保持短語（免受單句完整展開之限），若屬古文縮略語或跨部沿用稱謂致單讀易誤解者，得以極簡同位語或定語界定實義，勿抹除原稱亦勿展開為長句。
5. **括號與顯訛**：除原文實質夾注與讀音釋義外，不用圓括號添加解說。原文無實質文義之空白括號一律刪除；凡依上下文或平行文已有確證之顯性形訛，逕依確義直譯，不留訛字；僅確屬校勘未定者始留 `〔補字〕`／`〔疑作X〕`，勿寫校勘按語。

{style_spec}
照下列完整標籤輸出，勿簡寫或自創標籤：
{out_format}
```

```text
1. **律義與部別**（{book_note}）：違背律宗常制、錯混部別、混淆本宗定論與他部異說、科判層級或「文」之所指有誤、引文與著者評論混同、【疏】【記】義理不能互核。
2. **文法與邏輯**：主客施受反轉、持犯開遮與模態強弱錯置、想疑心念與行為要件失真、時序與複合條件邏輯錯置（將連帶或並存要件誤拆為各自充分條件）、列舉邊界失真（封閉定舉誤加開放詞或漏譯限定詞）、範圍與否定作用域偏差、句尾虛字斷句致因果轉折反轉、引文起迄與標點錯亂。
3. **忠實與增刪**：漏譯條件、實質夾注、音訓、實詞或受益／受事對象；無據增補細目、背景、程度誇飾或考訂；無據窄化詞義或戒名通義；誤將背景或他欄專論混入正文；依文脈腦補譯文所無之詞。
4. **表達與體例**：一般古漢語實詞未轉為現代確詞、古今／口語歧義誤讀、文言直抄、歐化倒裝、動詞缺主賓、致語意歧義之雙譯殘留、違規添加解說性圓括號、同一核心術語前後或違反〈全書共通體例〉之譯法歧出，以及網址／按語／自創標籤殘留。
5. **遮蔽原文反讀**：假設完全不見原文，單讀【待審譯文】，是否仍能唯一讀出正確的施受、對象、時序、條件模態與前後邏輯自洽（科判標題短語除外）？凡須依賴讀者腦補古文脈絡才能讀通者，不得判 PASS。
6. **括號與顯訛**：原文無實質文義之空白括號一律列為硬傷；凡依上下文或平行文已有確證之顯性形訛，譯文逕依確義直譯者，不得僅因未留訛字或校注而判 FIX；僅確屬校勘未定者始得保留 `〔補字〕`／`〔疑作X〕`。
7. **衝突優先序**：為消除古今撞義、主客時序、對象或條件模態歧義而作的句法展開，以及對縮略語或跨部稱謂所作之極簡同位語或定語界定，均不屬「無據腦補」；惟不得增添原文所無的義理、背景或考訂。依規保留原稱之專名度量不得判為文言直抄。

{style_spec}
凡涉上述實質問題或致語意歧義者，一律列為硬傷判 `FIX`。

### 輸出（勿改寫整段，勿在建議中代寫完整替換句）
1. **【逐句簡核】**：逐句對照【原文】與【待審譯文】實際字面，核明核心實詞、動詞、主客與界限之實際譯法（禁止按段概括或僅複述原文大意帶過），註明查證結果。
2. **【結論】**：`PASS` 或 `FIX`（判 FIX 須列至少 1 項硬傷；判 PASS 則下欄只寫「無」）。
3. **【必改硬傷】**（無硬傷時**只寫「無」一字**，勿寫「經核對…」等說明）：
   - `[疏/記/鈔/律/註/序，打包段附[n]] 原文「……」→ 待審譯文「……」｜問題：……｜依據：……（引原文或查證書名卷次，**凡涉外部查證須直接於此欄摘錄關鍵原句 1–2 句，供修訂端核對**）｜修正方向：……（只寫須補齊或糾正之要素；所涉專詞須兼顧現代白話清晰而不生歧義）`
```
