以下逐段檢視，分成「**明顯誤譯**」「**增譯／漏譯**」「**用語與文氣建議**」三類，並附改譯建議。整體來說譯筆流暢，但有幾處把注文的方向、範圍讀反或讀窄了，需要修正。

## 【1629-0001】

**❌ 明顯誤譯**

1. **「不論相教」→「不論及相互教唆」**
 律疏中「相教」的「相」多指單向的「教他」（如「此明自犯，不論相教」），此處是說：注文只泛示下眾**自己犯戒**之相，不涉及**教他人犯**的問題。譯作「相互教唆」意思正好偏掉。
 → 建議：「不論教他（相教）之事」。

2. **「二開對治，覺知遭逼，亦此所攝」→「其次開許為了對治，**或者**覺察到遭受逼迫而極力抗拒，也為此條所收攝」**
 「或者」把從屬關係讀成並列了：「覺知遭逼」正是**被收攝在「對治」這一項之內**的例證，不是另一種開緣。且「極力抗拒」原文全無。
 → 建議：「其次開許對治；覺知遭到逼迫（而起對治），也攝屬此項。」

3. **「通收眾緣」→「通括收攝眾多的**犯緣**」**
 此處在「不犯」科中，「眾緣」指種種因緣情況（不犯之緣），補上「犯」字反而矛盾。
 → 建議：「通收各種因緣情況」。

**⚠️ 需斟酌**

4. **「樂在前人」→「快樂在於前人自身」**：全段既已把「能／所」譯為「能教唆／受教唆」，此處卻保留「前人」未譯，體例不一。宜作「快樂是由實際行事者（前人）自己領受」。
5. **「次示三眾」→「下三眾」**：補「下」字大抵可從（下文即言「下眾」），但屬推斷，建議加括號或確認鈔文所指。
6. **「戲笑非重」→「嬉笑而不具重罪」**：「非重」一般指「無重心（非殷重之心）」，譯成「不具重罪」是另一層意思，宜作「戲笑而無重心」。
7. 「罪唯一品」→「罪名只有一種品階」：重點在**罪只一等、不分輕重**，非「罪名」，可作「罪只有一品（不分等級）」。
8. 「名利**全**歸對方」的「全」為原文所無，可刪。

## 【1629-0002】

**❌ 明顯誤譯（本段最關鍵）**

1. **「非理損者為盜」→「不合事理而**暗中**損害他人者稱為盜」**
 加了「暗中」二字，正好與下文「盜名通攝（涵蓋劫與偷）」自相矛盾——「盜」是總名，**不限定暗中**；暗中而畏主覺知者才叫「偷」。
 → 建議：「不合正理而損他財物者名為『盜』，公然強取者名為『劫』，畏懼財主發覺（而暗取）者名為『偷』。」

**⚠️ 其他**

2. 「王臣呵責」譯作「國王大臣」語意含糊，宜明作「國王及大臣」或「國王的大臣」（依律本事，宜作前者）。
3. 「敘意中」宜點明是《戒本疏》**敘制戒之意**那一科，作「《疏》敘述制意中」較清楚。
4. 「初示相難護」的「**極**難」為增字，可刪。
5. 「夷殘蘭提」展開為波羅夷、僧殘、偷蘭遮、波逸提，正確，可保留。

## 【1629-0003】

**❌ 易生誤解**

1. **「《十誦》四卷，《善見》三卷」→「《十誦律》**有四卷**，《善見律毗婆沙》**有三卷**」**
 原文承上句「釋盜涉五卷」而來，是說**解釋盜戒所佔的卷數**；照現譯會被讀成該書總卷數（《十誦》實有六十一卷）。
 → 建議：「《十誦律》（釋盜）四卷，《善見律毗婆沙》三卷。」

**💡 用語建議**

2. 「如下自釋」→「正如後文自身所解釋的那樣」：「後文自身」生硬，宜作「如下文（鈔）自會解釋」。
3. 「二明闕緣，又二，初別示闕相」：第一層譯成「說明欠缺犯緣**的相狀**」，與下一句「分別展示缺緣之相」重複。第一層宜只作「第二說明闕緣（犯緣不具）」，再分「初、別示闕相」。
4. 「釋犯境」可略作提示：「解釋所犯之境（所盜的對象）」，讀者較易掌握。

## 【1629-0004】

**❌ 明顯誤譯**

1. **「互闕不定」→「**相互**欠缺並不固定」**
 「互」在此是「或此或彼、交互不定」，指諸緣**隨缺一種或多種、情況不定**，不是「彼此互相欠缺」。
 → 建議：「所謂『緣差』，是諸緣或有欠缺而情況不定：或盜心止息、或物已移位、或前事受阻等。」

**⚠️ 需斟酌**

2. **「非畜物替，故云奪也」→「非人或畜生的物品更換了原物」**
 語意含混，易讀成「非人畜生的物品被換掉」。原意是：本為人物之境，被非人、畜生之物**替代（奪去）**，故稱「境奪」。
 → 建議：「（人物之境）被非人、畜生之物取代，所以稱為『奪』。」
3. **「於人初上」→「在**人類**這最初之境上」**：「人類」用語不合律疏語境，宜作「就最初『人（物）』一境而言，有三種異想」。
4. **「通結非犯」→「總體結斷為不犯**重罪**」**：補「重罪」雖與下文「唯有本心方便」相合，但屬增譯，建議作「總結為不犯（根本罪）」並用括號標出。
5. 「若是正當作非人、畜生物品等懷疑或錯想時」讀來拗口（「正當作」易誤讀）。宜作「若就正起『非人、畜生之物』的疑想時而言」。
6. 「亦非盜境」不必再加「構成根本重罪」的長定語，可簡作「也就不成其為盜境了」。

## 【1629-0005】

**❌ 明顯誤譯／增譯**

1. **「此土屬官」→「但在這片土地**一切**歸官府所有」**
 「一切」為原文所無，把範圍無限擴大（原意是：這類山林川澤等物，在中國屬官府所有）。
 → 建議：「但在此土（中國）則屬官府所有，那就不是無主物。」
2. **「驗非偏判也」→「這證明並非**偏頗**的判斷」**
 「偏判」指**只就一邊（闕境）作判定**，不是「不公平、偏頗」。
 → 建議：「可見（前文）並非只就一邊作判定。」

**💡 用語建議**

3. 「別問」是「**另外**設問」，非「特別提問」；宜作「另設的問答中，示（無主物之）相有四種」。
4. 「第二須約國亂」宜作「第二種須就國家動亂的情況來說」，比「必須在國家混亂時」更貼原意。
5. 「唯有本心方便」可略補：「只結本心（欲盜人物）的方便罪」。

## 【1629-0006】

**⚠️ 需斟酌**

1. **「損財明盜」→「**損害財物**以顯明盜行」**
 「損財」是**令財主損失財物**（財物離處），不是「毀損財物」。這是盜戒成重的關鍵，宜改：「以令財主損失財物來界定盜，（財物離處）便成重罪。」
2. **答文邏輯宜串接**：原文「恐涉濫故」是**不列「方便」為緣的理由**，現譯三句並列，因果斷裂。
 → 建議：「因怕混濫，所以縱有方便也不列出；只須知道財物未離原處之前，一切都攝屬方便。」
3. 「今判」「無今第五」的「今」指**今鈔（鈔主）**，不是「如今／現在」。宜作「今（鈔）判定……」「沒有本鈔所列的第五緣」。
4. 「初文」→「第一篇文字」過於隆重，宜作「初文（第一節）」。
5. 「據俗令」宜作「依據世俗法令」，避免「律令」與佛教「律」混讀。
6. 「意亦可見」→「顯而易見」稍強，可作「其用意也就可以明白了」。

## 總評

* **必須改**：0002「非理損者為盜」加「暗中」；0001「不論相教」譯成「相互教唆」；0001「或者」割裂「亦此所攝」；0004「互闕不定」；0003《十誦》《善見》卷數；0005「一切歸官府」與「偏判」。
* **通病一：增字過度**——「極（難）」「全（歸）」「一切」「立即」「極力抗拒」「構成根本重罪」等多為原文所無，宜刪或加括號標示為補註。
* **通病二：術語體例不一**——「能所」已白話化，「前人」卻原樣保留；「今」時而譯成「如今」。建議統一：能教／所教、前人（實際行事者）、今鈔。
* **通病三：科判層級被壓平**——如「二明闕緣，又二，初別示闕相」、「別問，答中」，白話宜保留「第幾／又分二／初……」的層次，讀者才看得出記文在解鈔的哪一段。
