# 校閱材料　第1175檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1175-0001】資持記/09b_中三上#40
【原文】表裏即內外，謂摘開各處，非全物也。若下，四明別務。思惟，即禪定。不犯中。但明囑付二人。律文更列力勢所持命梵二難，不作次第而去不犯。十五。〔佛在舍衛，客比丘在邊房宿，不語便去，臥具壞爛，故制。〕僧物制意同前。緣中。第五犯相有二，如後釋中。
【譯文】「表裏」是指內部與外表，是指將用具拆散開來放在各處，不是一件完整的器物。「若」字以下，第四說明處理別的事務。思惟，就是指修習禪定。不犯戒的情況中。只提到了鄭重囑託給兩個人。律文中還另外列出了受到強大勢力脅迫牽制，以及面臨危及生命、危及梵行這兩大急難，此時若來不及按程序逐一收拾就離開，不算犯戒。第十五條戒律〔佛陀住在舍衛城時，有客比丘在僧房偏僻角落的房間借宿，未告知主人就逕自離開，導致臥具受潮腐爛，佛陀因而制戒〕。僧團公物的制戒用意與前面那一條相同。條件中。第五個犯戒相狀有兩種，正如後面的解釋所述。

【1175-0002】資持記/09b_中三上#41
【原文】疏云：所以分二戒者，一屏露異。二得罪異，露則出門，屏則出界；又決去出界，暫往三宿。三開緣異，露則兩相緩急〔緩則如上方便，急謂勢力命梵等緣，不作次第。〕，屏則開於二夜〔屏是房室，故有斯開。〕。釋中，初明出界犯，前示方便。若不下，結犯。若即下，次明三宿犯，初示方便。
【譯文】《戒疏》說：之所以把這件事分開制定為兩條戒，第一是室內遮蔽處與室外露天處環境不同。第二是結罪的判準界限不同，露天處只要一走出房門即成罪，室內遮蔽處則要走出寺院結界才成罪；而且抱定主意離開必須走出結界，若是暫時出外則以留宿達三夜為限。第三是開許的因緣條件不同，露天處有緩急兩種情況〔緩慢情況就如上述如法善後，緊急情況是指遇上勢力脅迫、生命危難、梵行危難等特殊緣由，可以不必走完收拾程序〕，室內遮蔽處則直接寬限開許可以外宿兩夜〔因為室內是遮風蔽雨的房室，所以才有這項放寬〕。解釋的文句中，首先說明走出結界即構成犯戒，前面先列出預備階段的方便罪。「若不」以下，做出正式結罪的結論。「若即」以下，其次說明外宿滿三夜構成犯戒，前面先列出方便罪。

【1175-0003】資持記/09b_中三上#42
【原文】不下，結犯。不犯者，如上方便，已在界外，水陸命梵等緣皆開。十六。〔佛在舍衛，六群十七群同道行，至無住處，十七群求得住處；六群知，強於中間敷臥具宿，故制。〕釋中，律文分三，初釋中間。約身四邊者，明其迫窄不相容也；以間寬不妨，開無犯故。次釋臥具。且列四種，餘物準知。若下，三約心明犯。
【譯文】「不」字以下，做出正式結罪的結論。不犯戒的情況，是指完全做到了上述善後的處置方法，或者人已經走出結界之外，遇到水災、陸路阻斷、生命危難、梵行危難等突發事故，全部都在開許之列。第十六條戒律〔佛陀住在舍衛城時，六群比丘與十七群比丘在路上同行，走到一處沒有客舍可住的荒野，十七群比丘好不容易求得一處落腳安宿的屋舍；六群比丘得知後，硬是在兩人的鋪位中間強行鋪設臥具擠著睡覺，佛陀因而制戒〕。解釋的文句中，律文分為三段，首先解釋何謂「中間」。從身體的四周邊界來界定，這是為了說明空間過於逼仄狹窄、彼此不能相容的窘態；因為如果中間間隔寬敞、互不妨礙，就開許不成立犯戒。其次解釋何謂「臥具」。此處暫且列舉四種，其餘用具可以依此推知。「若」字以下，第三是從動機心態來界定犯戒。

【1175-0004】資持記/09b_中三上#43
【原文】開不知故。《十誦》。於中敷已，又作多事惱他意令避去，故隨事結。且列八種，不出聲色。隨他之語，總收一切。不犯中。初句不知，次五並以若字分之；下明難緣，共成七也。語已住者，彼許容也。親舊教者，彼自召也。倒地、轉側，皆非意也。命梵等者，文略力勢所持，及繫閉也。
【譯文】這開許給不知情者。《十誦律》說：在兩人中間鋪設好之後，又蓄意製造許多雜事惱亂對方，企圖逼迫他人主動避開離開，所以伴隨著這些惱人的舉動一一結罪。此處姑且列出八種，都離不開出聲與作態色相。而鈔文中「隨他（不樂事作）」這句話，則總括收攬了一切惱害騷擾的行徑。不犯戒的情況中。第一句是指不知情無心之過，接下來五種都用「若」字相間分列；最下方說明遭遇急難的因緣，總共合成了七種免責情況。說話之後才留宿的，是指對方已經明確答應接納包容。受熟識的老朋友指引的，是指對方自己主動邀請召喚的。跌倒在地、翻轉側身，這些都完全不是出於故意。遇到生命與梵行等急難的，文中略過了受到強暴勢力牽制，以及遭到關押囚禁等情形。

【1175-0005】資持記/09b_中三上#44
【原文】十七。〔佛在舍衛，六群十七群在道行至小住處，十七群先入寺掃洒令淨；六群知故驅起牽出，因制。〕犯緣中。初簡三時，春冬分房，有上座來，下座應避，非定屬己，牽出數故；夏房不爾，稀故結輕。釋中，《四分》為二，初通示多少。隨所牽者，此約人也。隨出房者，即約處也。若牽下，別釋多少。
【譯文】第十七條戒律〔佛陀住在舍衛城時，六群比丘與十七群比丘在路上同行，走到一處小歇息處，十七群比丘先進入僧寺打掃灑水清理乾淨；六群比丘明知此情，故意驅趕他們起身並強行拉出門外，佛陀因而制戒〕。在犯戒條件中。首先要區分三個時節，在春季與冬季分配房舍，若是有德高望重的上座比丘到來，下座比丘理應主動讓出鋪位，因為這鋪位並非固定專屬於自己，拉人出去的次數頻繁；夏季安居的房舍則不是這樣，更動極為稀少，所以違犯時結罪較輕。解釋的文句中，《四分律》分為兩部分，首先通盤說明結罪的數量計算。隨著所強行牽拉的人數多寡，這是就受害人方面來算。隨著拉出多少間房間，這就是就處所地點方面來算。「若牽」以下，個別詳細解釋罪數的多寡。

【1175-0006】資持記/09b_中三上#45
【原文】並約出戶明犯分齊。文引兩句，互明多犯。準律初後出二俱句，文云：若牽多人出多房，多墮；一人出一房，一墮，則四句備矣。上約牽出犯重。若持下，明不牽犯輕。律云：若持他物出〔好將出也〕，若擲著戶外〔謂棄擲也，此是兩相，不可違讀。〕。閉戶外者，因彼出外，不令入故。《僧祇》，初明牽人。
【譯文】這都是以將人拉出門外作為界定犯戒的標準底線。文中引用了兩種句型，相互發明多次犯戒的意涵。依照律文的前後脈絡，這構成了牽人與牽出房間的「二者皆是」的綜合句型，律文說：如果牽拉多人走出多間房間，犯多次墮罪；牽拉一人走出一間房間，犯一次墮罪，這樣四種邏輯句型就完全齊備了。以上是針對拉人出去而結犯重罪的判定。「若持」以下，說明沒有牽拉其人、只動其物而結犯輕罪的判定。律文說：如果是拿著他人的物品搬出門外〔是指端整拿持出去〕，或者是扔擲丟棄在門戶之外〔是指惡意摔擲丟棄，這是兩種不同情態，萬萬不可混淆閱讀〕。把門反鎖將人關在門外，是因為對方正好走到外面，就故意不讓他再進門。《僧祇律》中，首先說明強拉他人。

【1175-0007】資持記/09b_中三上#46
【原文】牽出是身犯，呵叱即口犯。一一墮者，不同《四分》約出戶也。若瞋下，次明驅畜。《十誦》中。鼾〔音汗〕，鼻聲也。據非驅逐，惱他事同。文制不應，違須小過。《五分》，初開折辱弟子。以慈濟故。若下，次制惱他。不喜人，謂他所怨嫌者。出亦言者，非驅逐也。
【譯文】動手拉出是身業違犯，厲聲呵斥驅趕就是口業違犯。每動一次手就一一結犯墮罪，這與《四分律》以越過門戶為界的標準不同。「若瞋」以下，其次說明瞋怒驅趕牲畜。《十誦律》中。「鼾」的讀音為汗，是指打呼嚕的鼻息聲。按照道理這雖然不是直接動手驅逐，但惱亂干擾別人的實質效果完全一樣。律文規定不應當這麼做，有所違背就必須結算為輕微小過（吉羅）。《五分律》中，首先開許為了挫折訓誡劣徒而動粗。這是出於慈悲救度的大前提。「若」字以下，其次禁止惡意惱亂他人。所謂「不喜愛的人」，是指平時與他人有宿怨仇嫌的人。即使對方搬出去了也只判結吉羅，是因為這並非親自動手驅逐的緣故。
