== PROBLEM ==
文末「非專受戒故。內德者，不出慈悲解脫慚愧也。決判中。」未譯，直接抄錄原文。

== SUGGESTION ==
改譯為：「顯示當初制戒的意圖另有所在，並非專為受戒而設。所謂『內德』，不外乎慈悲、解脫、慚愧之心。在『決斷判定』中。」

== ORIG ==
答中三義，顯本制意別，非專受戒故。內德者，不出慈悲解脫慚愧也。決判中。

== CURRENT ==
（這必須限於永久賣斷才算成立，現今有人暫時租借，仍舊等同於借用。）下文引用《五分律》，輾轉證實借用衣鉢的情況。既然命令物主捨棄，成為自己名下的衣物，那就等同於《四分律》所說應當讓他乞求贈與。在《多論》中，首先標明判定，確定可以得戒。從「論」字以下，引用文句反過來詰難。意思是說既然沒有衣鉢依然能得戒，佛陀又何必為此制戒。回答中有三種深意，顯示當初制戒的意圖另有所在，非專受戒故。內德者，不出慈悲解脫慚愧也。決判中。
