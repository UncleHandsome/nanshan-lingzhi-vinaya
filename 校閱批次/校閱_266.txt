# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【266-0004】02_戒疏/14a_卷三下之二#144
【原文】【註】佛在舍衛國。多比丘遇賊失衣，來到祇桓。有信聞之，多送衣與，比丘言：「止，便為供養已。有三衣故，不須也。」六群令取，「持以與我」。遂更受之。比丘舉過，佛因制戒。
【譯文】【註文】佛陀在舍衛國。當時有許多比丘遭遇強盜失掉了衣服，來到祇樹給孤獨園。有善信居士聽聞此事，送了許多衣服來供養，比丘們說：「請留步，這就已經算作供養了。我們已有三衣，不需要再添了。」六群比丘卻指使他們收下，「拿了之後拿來給我」。於是他們又收受了衣服。其他比丘揭發此過，佛陀因此制定此戒。

【266-0005】02_戒疏/14a_卷三下之二#145
【原文】【疏】就戒緣中。「六群令取」者，自既已足，因奪得多，更行人事以乖施意也。
【譯文】【疏文】在制戒緣起中。「六群令取」，是指自己既然衣已具足，卻趁著他人失衣之機多索取，轉而用以做世俗人情交往，這嚴重違背了施主的本意。

【266-0006】02_戒疏/14a_卷三下之二#146
【原文】【記】釋戒緣中。注明比丘三衣自足，為六群受，故云「行人事」也。
【譯文】【記文】解釋制戒緣起中。注文指明比丘的三衣自身已經齊足，卻為六群比丘的唆使而受衣，所以稱為「行人事（做人情）」。

【譯文】【疏文】第二句、「失奪」等四種因緣。注文中「若失一衣不應取」，《善見論》說「如果三衣全都失去，只能索取上下兩件，剩餘的一件向外另籌」，這是因為失衣之處施主好心殷切，出家人不可全都拿滿。注文中也只吩咐拆解現有厚衣相互拼湊做衣，唯有完全行不通時，才聽許向外接受一件。

【譯文】【註文】如果三件衣全都失去，彼比丘應當知足受衣。所謂知足有兩種：在家人方面的知足，是隨居士所能給予的布料而受用；出家人方面的知足，是指以三衣為限，不可超額。

【譯文】【記文】戒本第五句中，第一科。如果依本戒原意，因失奪而施才犯，此處卻言「自恣請」。如今詳察文義，是想說明即使施主放任隨意供養，尚且應當知足，何況是專門為失奪之難而前來布施的呢？學者應當更為細詳。

【266-0022】02_戒疏/14a_卷三下之二#162
【原文】【疏】「是比丘當知足」者，謂失三受二也。注明道俗知足，釋成兩相：「在家知足」，不可自量，隨彼所施；「出家知足」，止約三衣，佛已正制失二受一是也。
【譯文】【疏文】「是比丘當知足」，是指若失去三衣只可接受兩件。注文列出道俗知足之別，解釋成兩種相貌：「在家的知足」，是居士不可自行限定微少，應隨自力竭誠布施；「出家的知足」，標準只限於三衣，佛陀已明確定下「失二只得受一」的規矩。

【266-0023】02_戒疏/14a_卷三下之二#163
【原文】【記】次科。初釋文，次釋注。在家行施，即是「知足」，不可自量，出於他故。此舉在家，對顯出家「知足」異耳。戒文「知足」，正約出家。
【譯文】【記文】第二小節。起初解釋經文，其次解釋注文。在家人行布施，就是居士自身的「知足」，出家人不能以此苛求對方，端隨對方布施之心。此處列舉在家人，是為了相對顯明出家人的「知足」意趣不同。戒文中的「知足」，正式是指對出家人的規範。

【266-0025】02_戒疏/14a_卷三下之二#165
