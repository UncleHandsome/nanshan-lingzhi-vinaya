### 二、 補上最後 3 個「前幾輪還沒點到的細節問題」

1. **`local_corpus.py` `_norm_book()` 前綴誤吃書名，且缺 `含注戒本` 映射**
   看 `local_corpus.py` 第 126–128 行：
   ```python
   for alias, target in sorted(ALIASES, key=lambda x: len(x[0]), reverse=True):
       if q == alias or q.startswith(alias):
           return target
   ```
   因為 `ALIASES` 裡有 `('四分', '四分律')` 和 `('四分律行事鈔', '行事鈔')`，只要模型在 `work` 填了庫外書名（如 **`四分律行事鈔批`**、**`四分僧戒本`**、**`四分比丘戒本`**），`startswith` 會直接把它**錯認成《行事鈔》或《四分律》**，連 `relaxed` 全庫放寬都救不回來（還害模型以為該書真的沒寫）。
   另外，提示詞天天提到**《含注戒本》**，但 `ALIASES` 裡沒有 `('含注戒本', '戒疏')`（它只收了 `四分律含注戒本`），模型若填 `work='含注戒本'` 一定先查無再觸發全庫放寬。

2. **`qwen_local.py`：一筆 `400` 會讓整本書的自動化管線永遠卡在 `.stage_partial`**
   看 `qwen_local.py` 第 472 行與第 769 行：遇到 `_400審查.txt` 跳過時回傳 `'skip-400'`，但第 769 行只放行 `st == 'skip' or st.startswith('ok')`，導致 `'skip-400'` 被算進 `fail += 1` 並寫出 `.stage_partial`。若後續用 `run_pipeline.py` 或 `run_all_books.py` 接力推下一關，只要整本書有哪怕 1 段撞 400（且設了預設 `QWEN_SKIP_400=1` 略過它），管線就會永遠中止在同一關不往前走（若這是刻意當安全煞車可保留，否則建議印出更明確區分）。

3. **`qwen_local.py`：一審（`QWEN_RAW_SAVE=0`）路徑漏了 `QWEN_NO_CITE` 網址攔截**
   `run_pipeline.py` 的 `review` 階段設了 `QWEN_RAW_SAVE='0'`、`QWEN_NO_CITE='1'`，但 `_save_result` 裡檢查並剝除 `https?://` 的程式只寫在 `if QWEN_RAW_SAVE == '1':` 分支裡，`else:` 分支沒有攔截。
