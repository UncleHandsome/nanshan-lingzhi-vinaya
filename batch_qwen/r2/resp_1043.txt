整體看，八段譯文的方向大致正確，科判（「此下」「律下」「廣下」等）的處理也一致；但有**一處人名錯誤**、**兩處術語誤譯**，以及若干「增譯過度／語意含糊」的地方。以下逐條列出。

---

## 【0001】

1. **「初牒律文」譯作「首先宣讀律文」——誤。**
 「牒」在科文中是「牒舉、引述（前文或律文）」，不是誦讀。建議：「先引述律文」。同樣的錯在 0007「文牒」又出現一次（見下）。
2. **「指首師《律疏》」譯作「法首大師的《律疏》」——人名恐誤。**
 《鈔》《記》中的「首師」一般指**智首律師**（道宣之師，撰《四分律疏》，即所謂「大疏」）；「法首」查無其人。建議：「智首律師的《四分律疏》」。
3. **「舊記云」譯作「過去的筆記說」——語域不合。**
 「舊記」指前人對《行事鈔》的舊註（古記），非個人筆記。建議：「舊有的《鈔》註（古記）說」。
4. 「為下，示意」→「說明立教的意圖」：原文只是「顯示其用意」（承上「解界本非為夏，別有所為」），「立教」是加出來的。建議「顯示其用意」。
5. 「致令錯會」→「導致大家產生誤解」：「大家」偏口語，可作「致使後人誤解」。

## 【0002】

1. **「乃顯別有所為」譯作「另有其他公務作為」——不當。**
 「所為」指另有目的因緣（如護衣、受日等），與「公務」無關。建議：「而是顯示另有其他用意（因緣）」。
2. 「古人云者，已為前代古德難破，今引用之」：譯文主語不明。建議：「疏中所說的『古人云』，是指那些說法早已被前代古德破斥，如今再引出（加以破斥）」。
3. 「十四十五未竟皆成」→「在十四、十五日自恣雖未全滿但也都算成辦」：**「未竟」的主語是「夏（安居九十日）」**，現譯易讀成「自恣未滿」。建議：「十四、十五日自恣，安居日數雖未滿，也都不成破夏」。
4. 「二文不異」→「兩處律文並無不同」：可補足重點——兩文同樣說「安居竟」，故引來相並類比。

## 【0003】

1. **「即日明離」譯作「當天看見明相便算離衣犯戒」——用語需調整。**
 「明」指**明相現時（天亮）**，不是「看見明相」。建議：「當日明相現時就應算離衣（成離衣罪）」。
2. 「然未經宿，不說離衣」→「律中**絕**不說」：「不說」只是「不稱為」，加「絕」語氣過重；「在外過夜」也是增譯，宜作「尚未經過一夜（明相未出）」。
3. 「上句示文同」→「律文**句式**相同」：「文同」指兩段律文用語相同，「句式」是多加的。
4. 夾注「前云」譯作「前面古德說……所以道宣律師才提出這項問難」：補出主語可以，但屬推定，宜用括號或「（即前引古說）」標示，避免與原文混同。

## 【0004】

1. **「從狹彌勝」譯作「範圍越狹小則持守越殊勝」——過度泛化。**
 原意是就問答作結論：**依從狹小的本界更為殊勝**，不是「越小越好」的通則。建議：「依從狹（本）界為勝」。
2. 「今解中」→「當前的正確解釋」：建議統一作「今師（道宣）的解釋」，與下文「今意」一致（見通則）。
3. 「初二句判定」宜補賓語：「前兩句先判定（解界結界不破夏）」。
4. 「依藍」→「依止僧園」：可作「依伽藍（寺院）界」，並註明屬自然界，讀者才接得上下文的「自然／作法」對比。

## 【0005】

1. 「必下，明制」→「闡述戒律嚴正制定的常軌」：**「開／制」是一對**，此處只是「說明制限（不許）的一面」，譯文過於鋪張。建議：「說明制限」。
2. 「妄下，顯過」→「揭示虛妄犯戒的過失」：宜點明所指——妄受日、妄計夏臘以取施物之過。
3. 「北地亦然」→「北地中原也是這樣」：「中原」是猜測性增譯，保守作「北方（此土）地區也是如此」。
4. 「故多此過」→「經常滋生這種**冒領**的過失」：屬合理推論，但原文無「冒領」字面，建議「所以多有這類過失」，或把「冒領」放在括號內。
5. 「以不離界故」→「自始至終都沒有離開」：「自始至終」為增譯，可省。

## 【0006】

1. **「開別合眾／合別離眾」只作字面直譯，讀者無法理解。**
 建議加註：前者＝別法開為二（心念、對首）＋眾法合為一，故成三種；後者＝七日法合為一＋眾法分為二（半月、一月），亦成三種。
2. 「總分（全面劃分）」的註解失準。重點是**三科通論三法，而非一科配一法**，故稱「總」。建議：「所以稱『總分』（總括三法而分科）」。
3. 「所對人」→「所面對的**受法**僧人」：易誤讀為「領受此法的人」。所對人是受法者對之陳說的對象，建議「所對告（對首）的比丘」。
4. 「比丘通僧別」→「通於對大僧集體或個別對首」：**「別」含心念與對首**，此處漏了心念，且與 0008 的處理不一致（見下）。
5. 「制行受日不離當界」譯得可以，但「當界」宜明示為「本人所在之本界」。

## 【0007】

1. **「故知文牒倍過之過」譯作「律文宣讀『過』」——同 0001 的「牒」誤。**
 建議：「所以知道律文所標舉的『過』字，就是『倍過』（加倍而超出）的『過』」。
2. 「三中」→「在第三項中」：宜作「第三科中」，與他處「初科／次科」體例一致。
3. 「古師執法」→「死執法條形式」：「法條」是現代法律語，建議「執著於法相（文相）」。
4. 「今師」→「當前大師」：建議「今師（道宣）」。
5. 「三法半倍」的說明可再精確：半月十五日是七日之倍**而有餘**（15＞14），一月是半月之倍，正因如此律文才用「過」字。現譯「加倍（兩倍）」會讓「過」字失去著落。
6. 「道謂口言，方俗之語」：譯文可保留，但宜標明這是在訓解疏文「道」字（＝說），否則讀者不知從何冒出。

## 【0008】

1. **「別法為弱」譯作「個人對首法勢力微弱」——與 0006 不一致。**
 別法應含心念、對首，建議「別法（心念、對首）勢弱」。
2. **「法容隱顯」譯作「法規允許隱微或顯露」——含糊且用語現代化。**
 意思是：作法本身容有隱顯（強法顯則弱法隱），故立「相攝」一門。建議：「作法容有隱顯（強顯弱隱）」。
3. **「先敘用竟」譯作「先敘述事務已經運用完畢」——語意不明。**
 「用竟」指所受之日（前法）已用畢。建議：「先敘述前所受之法已用畢的情形，表明那不是此處所論（相攝）」。「事務」一詞空泛。
4. 「不顯今意」→「當前宗師的真正意旨」：建議「今師（道宣）的意旨」。

---

## 通則（建議統一處理）

| 原文術語 | 現譯問題 | 建議 |
|---|---|---|
| 牒 | 宣讀（誤） | 引述／標舉 |
| 今解／今師／今意 | 「當前的正確解釋／當前大師／當前宗師」三種說法 | 一律「今師（道宣）…」 |
| 古師／古人 | 時作「古德」（帶敬意） | 破斥語境用「古師／古人」 |
| 疏 | 《業疏》✓ | 首次出現註明《四分律隨機羯磨疏》 |
| 舊記 | 過去的筆記 | 舊（古）註記 |
| 別法 | 有時只譯對首 | 心念＋對首 |
| 受日 | 0005 才加註 | 在 0004 首次出現即註「受法請假外出」 |

另外，全篇有較多**強調性增譯**（「絕對」「徹底」「絕不」「死執」「自始至終」「防護力」「公務」等）。《資持記》是簡峭的科判體，建議把解釋性內容收進括號，正文盡量貼著原字，避免把元照的判斷語氣放大成絕對斷言。

**最需要改的三處**：①「法首大師」→智首律師；②兩處「牒」誤作「宣讀」；③「別有所為」誤作「公務作為」。其餘多屬精準度與一致性的修潤。
