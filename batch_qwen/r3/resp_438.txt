整體讀來通順，科判意識也在，但有**幾處關鍵誤譯會直接誤導律義**（尤其「教死」），另有術語層次混淆與增譯過度的問題。以下按輕重分列。

---

## 一、必須修正的誤譯

### 1. 「教人死／教死」誤為「教唆他人去死」（#64、#65、#66）——最嚴重

- 原文：「口亦可造，**或教人死**，或以呪殺」；記：「云『教死』者，《論》云『教勅』，**即是遣使**，文無歎死，義亦同之。」
- 原譯：「或者教唆他人去死」／「教人去死」／「教唆他人致死」。
- 問題：元照已明示「教勅＝遣使」，即**教令、指使他人去殺人**，不是勸人去死（自殺）。而且記文特意把「教死」與「歎死」（讚歎死亡、勸人自殺）分開，說論文雖未列歎死而義亦同攝；譯文把「教死」譯成「教人去死」、「歎死」譯成「讚歎致死」，兩者幾乎同義，正好把元照的分別抹掉了。
- 建議：
 - #64：「或者**教令他人（去）殺害眾生**，或者用咒術殺人。」
 - #65：「『教死』，論中本作『教勅』，就是遣使（指使他人去殺）；文中雖未列『**歎死**』（讚歎死亡、勸人自殺），義理上也同樣攝在口造身業中。」
 - #66：「口業造作身業，如**教令他人殺生**、誦咒殺人。」

### 2. 「此云蔭山」誤為「此處譯為」（#65）

「此云」是譯語定式＝「此翻為／漢譯作」，不是「此處」。
建議：「《經音義》說：或稱單多羅迦山，**此翻為『蔭山』**。」

### 3. 「事不究竟」被降格為時間副句（#62）

記文明說：「出不互所以，**則有二意**：初約業異釋……『事』下，次約事不竟釋。**初句立義**，『言』下釋成。」
原譯「事情尚未究竟時，話語雖然說得清清楚楚……」把第二個理由變成第一句的時間條件，科判結構消失。
建議：「為什麼呢？**一是業的體性各異；二是事情不能究竟成辦**——話雖說得清楚明白，仍不能成就業道，必須由身業相助。」
另，「未得成業」譯「不能單獨構成重罪」，「重罪」是引申，宜作「不能成就業道（罪業未成）」。

### 4. 「前人」誤為「前面的造作者」（#75）

「前人」是律典術語，指**對方那個人**，與「前面／先後」無關。
建議：「若教唆他人行淫，**受樂染著的是對方（受教之人）**，與我自身無關，教者不得同犯重罪。」

### 5. 「《成論》所通」誤為「所通達的義理」（#64）

「通」在此是**通許、開通**（《成論》亦許此義），非「通達」。
建議：「若依本律（《四分律》），並《成實論》**所通許**之義，三業可以互造，且各自成業。」

### 6. 「今宗」不宜逕譯為「大乘分通教」（#65）

此處「今宗」是與前段有部對舉的**今所宗義（本律、《成實論》）**。逕標「大乘分通教」是把別處判教結論塞進來，屬過度引申。
建議：「**今所宗（本律、《成論》）的立場中**，第一科分三。」

## 二、術語與層次不精確

| 段 | 原譯 | 問題／建議 |
|---|---|---|
| #63 | 「若就**所發能造**的色法而言」 | 「能造色／所造過／所發／來報」是四個平行層次，下文另有「若約所發」，此處混入「所發」會撞層。刪去，作「若約**能造的色法**而言」。（可補注：身表是形色，故可見有對；語表是音聲，故不可見有對。） |
| #63 | 「口業作欺誑妄語」 | 「誑、妄」宜分列：「口業則造欺誑、妄語等語過」。 |
| #63 | 「若就業力發起而言」 | 「所發」宜作「若約**所發起的業體**而言，業性各不相混」。 |
| #66 | 「三業互相**交替**造作」 | 「交替」易誤讀為輪流；應作「三業**互相造作（互造他業）**」。 |
| #67 | 「四種**位次**」／「這些**句型**」 | 「四位」「諸句」是四句分別，非位次、非語法句型。作「文中四句」「都攝在這四句之中」。 |
| #72 | 「其義理**名相**已經在前文闡明」 | 「義句」＝義理與句式（四句分別），非「名相」。 |
| #72 | 「必然建立在對方**深信不疑**的基礎上」 | 「必約前信」重點在**前人領解信受**（故云「無疑」），不必誇大為「深信不疑」。 |
| #71 | 「為求取**名譽利益**」 | 宜作「名聞利養」。 |
| #64 | 「**隨意**以自身殺害眾生」 | 「隨」是「隨即／就用」，非「隨意」。作「就是以自己的身體去殺害眾生」。 |
| #74 | 「就教人與差遣兩方面作分別」 | 可，但宜與後文科判一致（先明教人，次應明遣使），用語統一為「教人／遣使」。 |

## 三、增譯與語氣

1. **#65「非要依所作的事相去硬定身業或口業不可」**——原文「不同《多》《雜》從所作事判定身口」是平敘，「非要……硬……不可」加了貶抑語氣，宜刪。
2. **#63「如施主言『若是聖人應當起立』而凡夫起立」**——方向可從，但「施主」「凡夫」皆原文所無，宜加括號或注標明是補充；且此句重點在 **「必假他語，即是口助」**（有部主張身造口業仍須口業為助），譯文宜把這一層點出，與上文「要由身助」對稱。
3. **#69「由此理即可明白根本不隨枝末轉之理」**——「理……理」重複，且後半是記文之意。簡化為：「由此便可明白（身口不能造意業）了。」
4. **#64「古代諸仙人以瞋恨心所化作造成的」**——「古代」為增字，「化作造成」冗贅；作「都是諸仙人瞋心所造成的」。
5. **#63「所感果報亦大不相同」**——「大」可刪。
6. **#65「論文分為兩截」「起初普遍明示三業」**——宜作「論文分為兩段」「先總明三業」。
7. **#67「在推演法理之中」**——「約義」是科名，作「就義理推演這一科中」較清楚。

## 四、建議補足的說明（不加則讀者難解）

- **#66「著脫三衣」**：與 #63「是聖者起」同例——依施主「若是聖者，著衣／脫衣」之語而著、脫三衣，以**身相**詐示證聖，故是「身造口業」。「無德者」宜改「未證聖果的比丘」。
- **#66「布薩默妄」**：宜補機制——說戒三問清淨時，有罪不發露而默然，**以默然表示清淨**，成「默妄語」；無言語而由覆藏心成口業之妄，故云「意造口業」。原譯「心懷罪卻默然妄語」略顯跳躍。
- **#62「必須人鬼相助」**：「人」即所遣使者，「鬼」即鬼神，分別對應「自在者語」與「仙人意嫌」。宜作「必須假手於人（使者）或鬼神相助，業方得成」，比「凡人或鬼神的身力」清楚。
- **#62「自在者」**：依記即國王、大臣，可加括號注明。

## 五、修訂示例（#62）

> 【疏文】若依《薩婆多論》、《雜心論》等有部論典，身、口、意三業不能互造。為什麼呢？一是業的體性各異；二是事情不能究竟成辦——話雖說得清楚明白，仍不能成就業道，必須由身業相助。論中又說：「如國王大臣（自在者）發令遣使，仙人內心瞋嫌呪詛，都必須假手於人（使者）或鬼神相助，罪業才能成辦。」

**結論**：#64、#65 的「教死／歎死」與 #65「此云」、#75「前人」、#62「事不究竟」、#64「所通」這幾處務必改；其餘多屬用語精度與增譯節制問題。
