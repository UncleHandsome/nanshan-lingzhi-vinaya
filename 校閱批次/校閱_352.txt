# 校閱材料　第352檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【352-0001】資持記/02d_上一下#27
【原文】尼等四人，未必約犯；十三難人，無體可破；然今但取境非淨僧，通云穢耳。穢本不足，淨相難知；所以注中但示淨者。清淨一色，且據不犯四重為言。色，猶類也。下指句法。準《業疏》云：一是別非足〔應來不來，及不與欲。〕；二是足非別〔即善比丘身參眾侶〕；
【譯文】比丘尼等四種人，未必是就犯戒來說；十三難人，則是根本無戒體可破壞；然而現在只是選取其人境不是清淨的比丘，統稱為垢穢罷了。垢穢本就不算足數，清淨的行相卻難以知曉；所以注釋中只指示清淨的人。所謂清淨同一個類別，姑且是就沒有違犯四重禁戒來說的。「色」，就如同類別的意思。下文指出四種句型邏輯。依照《業疏》說：一是屬於別眾而非足數〔應當來而沒來，以及不交給欲意的人。〕；二是屬於足數而非別眾〔也就是善良比丘身在僧眾行列中〕；

【352-0002】資持記/02d_上一下#28
【原文】三亦足亦別〔得訶人訶〕；四非足非別〔睡定瘂聾等〕。彼文甚廣，非學不知，故略引示。簡學悔中，初示不足。前未明故。問：究論學悔，四例何收？答：既毀根本，體非淨僧，故非初例。來否隨意，復開秉法，故非第二。生善滅惡，一切不足，復非第四。
【譯文】三是既屬足數又屬別眾〔能夠呵責的人當場提出呵責〕；四是既非足數又非別眾〔睡眠、入定、啞巴、聾子等〕。那裡的文字非常廣博，不深學的人無法知曉，所以簡略引述提示。在簡別修學悔過人之中，起初說明不算足數。前面尚未說明清楚的緣故。問：追究推論修學悔過的人，四個例項中屬於哪一類所收攝？答：既然毀犯了根本重戒，戒體已非清淨僧寶，所以不屬於第一個例項。來與不來聽憑其隨意，又開許他秉持僧法，所以不屬於第二個例項。無論是生長善法還是滅除惡業，一切羯磨都不能算入足數，所以又不屬於第四個例項。

【352-0003】資持記/02d_上一下#29
【原文】前既不收，此中方示；雖開秉法，須在數外。準此。乃知秉法之任，信非率爾；且羯磨之詞，不過數句；若唯謹誦，誰不能之，豈得眾中竟無解者。文標無解，此語可思；律制堪能，須知有以；觀今罔冐，實為悲哉。別下，正示所簡。開秉預眾，異彼穢流。足別俱非，寧同淨用。故云中間也。
【譯文】前面既然沒有收攝，在這裡才特別指示；雖然開許他秉持羯磨，但也必須列在法定人數之外。依照此理。才明白秉持僧法的責任，確實非同小可隨便；況且羯磨的言詞，不過只有短短幾句；如果只是謹慎誦念，誰會辦不到呢，難道僧眾之中竟然會沒有通曉的人嗎？經文中標註「沒有通曉者」，這句話深值得深思；戒律規定必須有堪能的僧人，必須知道是有深意的；看到今日的人胡亂冒充濫竽充數，實在令人感到悲哀啊。從「別」以下，正面指出所簡別的內容。開許他秉持僧法、參與大眾，這就不同於那些垢穢之流。足數與別眾兩者都不屬於，哪能同於清淨僧寶來任用呢？所以說處於「中間」地帶。

【352-0004】資持記/02d_上一下#30
【原文】次成否中，即明別眾成不成相。正簡中，初科，上二句明成。別犯下諸篇，不壞本故。別犯下，明不成。根本已壞，眾法絕故。文又為二，初約不知明成法。引律無作有想，以例穢作淨想，理無差故。羯磨成者，佛判法成；即彰非別。罪即吉羅。心不同者，出結罪意。審下，二約眾知明隨別。
【譯文】其次在「成否」一科中，就是說明別眾究竟構成與否的行相。在正式簡別中，第一個科判，上面兩句說明構成別眾。別眾之人若犯以下各篇輕罪，因為沒有毀壞根本戒體的緣故（仍成別眾）。從「別犯」以下，說明不構成別眾。根本重戒既然已經毀壞，參與大眾僧法的資格就斷絕了（故不成別眾）。內文又分為兩部分，起初是就不知情來說明構成別眾之相。引述戒律中「無比丘而作有比丘想」，以此來比照「將垢穢者當作清淨者想」，在道理上是沒有差錯的。羯磨成就，是指佛陀判定此法成立；這就彰顯出他們並不構成別眾。所犯的罪過就是突吉羅。內心不同意，是點出結罪的原由。從「審」以下，第二是就大眾知情來說明可隨意別開他（不障僧法）。

【原文】雜類中，初列人相。三狂，總亂心病壞也。須簡下品及中品未得法者。或下，明非別所以。上句對十三難。次句對三舉。形差對尼等。沙彌，法未滿；文略此句，疏則具之。病報對三狂瘂聾。緣下一句，通括上四。開謂許別也。凡下，總判。言未論者，未猶不也。足謂足數，別即別眾。

【原文】出與欲後悔戒。非正制者，不出欲法故。僧受行者，示可取故。《僧祇》彼更有蘭若衣鉢〔經營衣鉢〕，王賊禁閉並開。下句指略，有云《義鈔》，今見疏中。斥世中，初指非。多慢即心非。妄行是事非。斯法即欲。〔有準《尼鈔》是慢說戒羯磨法者，彼此別致，不可一例。〕謂下，釋相。
【譯文】出自「與欲之後反悔戒」。之所以不算正式制定，是因為並未出現在欲法的專屬篇章中。之所以僧團接受並奉行，是顯示可以採納的緣故。《僧祇律》那裡更有經營阿蘭若衣缽〔料理衣缽之事〕，以及被官府、賊人拘禁幽閉等也都開許。下一句是指引略過的內容，有人說是《義鈔》，現在見於《業疏》之中。在痛斥世人弊病中，起初指出其錯誤。「多慢」是指內心的錯誤。「妄行」是指行事的錯誤。「斯法」就是指交付欲意之法。〔有人依照《尼鈔》認為是指怠慢說戒羯磨法，彼此意旨不同，不可一例。〕從「謂」以下，解釋行相。
