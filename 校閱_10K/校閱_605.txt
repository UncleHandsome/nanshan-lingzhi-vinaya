# 校閱材料　第605檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【605-0001】02_戒疏/11a_卷三上之二#31
【原文】【疏】前明汙家，後明惡行。言「聚、城」者，所在汙家之處也。「汙佗家」下，正顯過相。《多論》云：「若作惡業，破他信心，名為『汙家』。作不清淨，穢汙垢濁，得惡果故，名『惡行』也。」《僧祇》云：「若依聚落，得四事利，或免諸難，皆名『依』義。作非梵行、飲酒、非時食，不名『汙家』。若先有信心，供養眾僧，造立寺舍，令彼退減，是名『汙家』。」當律相中，四汙文顯，廣如《鈔》說。
【譯文】【疏文】經文前半段說明汙損白衣家庭，後半段說明施行惡劣行徑。所謂「村聚與城鎮」，是指犯僧造作汙家罪行的處所。「汙損他家」以下，是正式顯發過失的相狀。《薩婆多毘尼毘婆沙》（簡稱《多論》）說：「如果造作惡劣行為，破壞在家人對佛法的信心，就稱為『汙家』。造作不清淨的罪業，穢惡垢濁，會招感惡果，所以稱為『惡行』。」《僧祇律》說：「如果依託聚落，獲得四事供養的利益，或者藉以免除各種危難，都屬於『依』的意涵。若是犯了非梵行、飲酒、非時食，並不稱作『汙家』。如果信眾先前本有清淨信心，樂意供養僧眾、修建寺舍，卻因比丘的惡行導致其信心退轉減損，這就稱為『汙家』。」在本律的相狀中，四種汙家的文義非常明顯，詳細內容如同《事鈔》中所記載。

【605-0002】02_戒疏/11a_卷三上之二#32
【原文】【記】第一雙，所諫事，牒釋中，初科。初二句分示。「言」下，別釋。初釋聚城。「汙」下，次釋二事。《多論》、《僧祇》，並以壞俗信名「汙家」，破戒為「惡行」，即失自他兩利。《僧祇》先明依聚，而以得利避難，顯示依義。「當律四汙」，廣在《鈔》文，顯注略引。四中，初是俗所惠物，二即受供所獲，三謂假他勢力，四即盜用僧物。皆謂隨情厚薄，令失信心故也。「惡行」注中。初總標。「自」下，列示，有三：初鄙賤行；「村有」下，二、染汙行；「或自」下，輕逸行。「鼓簧」謂吹笙笛等。《經》中「亦見亦聞」，謂為過公顯，道俗共知也。注引緣示：初明比丘入聚；「居士」下，明俗士見輕；「彼」下，明白佛設擯。
【譯文】【記文】在第一雙科判中，關於所勸諫之事的引文解釋，屬於初科。前面兩句是分別標示。「言」字以下，是分別解釋。先解釋聚落與城邑。「汙」字以下，接著解釋汙家與惡行這兩件事。《薩婆多論》與《僧祇律》，都是將敗壞俗人信心稱為「汙家」，破壞戒律稱為「惡行」，這便喪失了自利與利他兩種利益。《僧祇律》先說明依傍村落，並以獲得利養與躲避災難來顯示「依」的意義。「本律所說的四種汙家」，詳細收錄在《事鈔》文中，顯註裡僅是簡略引用。這四種情況中，第一種是轉贈俗人布施之物，第二種是轉送受供所獲之物，第三種是依仗他人權勢，第四種是盜取挪用僧團公物。全都是指隨順私人好惡厚薄，致使信眾喪失信心的緣故。「惡行」的隨文註解中，首先是總體標明。「自」字以下，列舉說明，共有三種：第一是下賤卑鄙的行徑；「村有」以下，第二是染汙身心的行徑；「或自」以下，第三是輕浮放逸的行徑。「鼓簧」是指吹奏笙、笛等簧片樂器。戒經中的「親眼所見亦親耳所聞」，是指造作過犯公開顯露，僧俗大眾人盡皆知。註文引述緣起加以說明：先說明如法比丘進入村落；「居士」以下，說明俗人輕視守戒者；「彼」以下，說明向佛陀陳稟並下令驅逐。

【605-0003】02_戒疏/11a_卷三上之二#33
【原文】【律】諸比丘當語是比丘言：「大德汙他家，行惡行；汙他家亦見亦聞，行惡行亦見亦聞。大德！汝汙他家，行惡行，今可遠此聚落去，不須住此。」
【譯文】【律文】眾比丘應當對這位比丘說：「大德！你敗壞他人良善家庭，做出種種惡劣行徑；你汙損人家是大家親眼所見也是親耳所聞，你施行惡行也是親眼所見親耳所聞。大德！你既然汙損他家、做出惡行，現在可以遠遠離開這個村落，不必再住在這裏了。」

【605-0004】02_戒疏/11a_卷三上之二#34
【原文】【註】時舍利弗為諸居士說法，令得信樂。食訖集僧，為彼比丘作舉，作憶念，便與罪，如上作羯磨已，驅出聚落。當作法時，便起謗言：「餘同犯者不驅，而獨驅我！」便作是言。
【譯文】【註文】當時舍利弗先為各位居士講說妙法，使他們重新生起清淨信樂。吃完齋飯後召集僧眾，為那兩位比丘舉行揭發舉處，令其憶念所犯罪過，隨即判定其罪，如上述規定作完羯磨後，便將他們驅逐出村落。就在僧團作法時，犯僧立刻出言毀謗道：「其餘一起犯過的人不驅逐，卻偏偏只驅逐我一人！」便說出這類話來。

【605-0005】02_戒疏/11a_卷三上之二#35
【原文】【疏】二、「諸比丘」下，過既彰顯，愚俗昏心，致令賢善無由投造。故須擯出，白四作法。注中具解，不勞云云。
【譯文】【疏文】第二段自「諸比丘」以下，說明過失既然已經公開顯露，愚癡俗人的心智被蒙蔽，導致賢德良善的比丘無從前來親近投託。因此必須將其驅逐，由僧團執行白四羯磨。註文中有詳細解釋，在此不再贅述。

【605-0006】02_戒疏/11a_卷三上之二#36
【原文】【記】次科，經文。初牒過，「大德」下，加擯。《疏》中。初釋牒過，意見上緣。「故」下，次釋加擯。注中，先令俗士知非得信，次乃驅擯，因之起謗。
【譯文】【記文】次科，戒經正文。首先是重提過失，「大德」以下，是依法驅逐。《義疏》中，先解釋揭發其過失，其用意已見於前述制戒因緣。「故」字以下，接著解釋施加驅逐處分。註文中，僧團先讓俗人明白是非而重獲正信，接著才予以驅逐，由此引發了犯僧的毀謗。

【605-0007】02_戒疏/11a_卷三上之二#37
【原文】【律】是比丘語彼比丘，作如是語：「大德！諸比丘有愛，有恚，有怖，有癡；有如是同罪比丘，有驅者，有不驅者。」
【譯文】【律文】這位比丘對那些比丘回答，說出這樣的話：「各位大德！眾比丘心有偏愛、心有忿恨、心有恐懼、心有愚癡；面對同樣犯這條罪的比丘，有的被驅逐，有的卻不被驅逐。」

【605-0008】02_戒疏/11a_卷三上之二#38

【譯文】【註文】當時舍利弗返回將事情稟告世尊，詳細陳述毀謗僧團的始末。佛陀隨即在遠方加以呵責，並命令對其進行正式的勸諫。

【605-0009】02_戒疏/11a_卷三上之二#39

【譯文】【疏文】第三段自「是比丘」以下，說明這位比丘不反省自己的過錯，竟然聲稱僧團的行跡看似有偏私與畏懼，無端非理毀謗僧團。

【605-0012】02_戒疏/11a_卷三上之二#42
【原文】【律】諸比丘諫言：「大德！莫作是語『有愛，有怖，有恚，有癡；有如是同罪比丘，有驅者，有不驅者』。而諸比丘不愛，不恚，不怖，不癡。大德汙他家，行惡行；汙他家亦見亦聞，行惡行亦見亦聞。」是比丘如是諫時，堅持不捨，彼比丘應三諫，捨此事故。乃至三諫，捨者，善；不捨者，僧伽婆尸沙。
【譯文】【律文】眾比丘便勸諫說：「大德！請不要說這種話：『眾比丘心有偏愛、心有恐懼、心有忿恨、心有愚癡；面對同樣犯這條罪的比丘，有的被驅逐，有的卻不被驅逐。』事實上眾比丘並無偏愛，並無忿恨，並無恐懼，並無愚癡。大德！確實是你汙損他人家門、做出惡劣行徑；你汙損他家是大家親眼所見也是親耳所聞，施行惡劣行徑也是大家親眼所見親耳所聞。」當眾比丘這樣勸諫他時，他若是頑固堅持而不肯捨棄這種言論，眾比丘應當三次勸諫他，令他放棄這件事。直到勸諫三次為止，如果願意放棄，那很好；如果不肯放棄，就犯了僧伽婆尸沙罪。
