# 校閱材料　第541檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】安居中牽他出房戒具五緣犯一是僧房分得入已二先聽在彼房住三瞋心牽出四無因緣五出戶便犯僧祇云牽他出時彼若抱柱捉戶倚壁隨離一一處皆提若口訶叱隨語離處亦提此律驅下二眾吉僧祗云若尼出行不付房舍牀褥與知事人閉戶而去者提十誦伽論云若鼾眠應起經行不能經行應起屏處不應惱他。
【譯文】（安居期間強將他人拉出房舍戒）具備五個條件即構成犯罪：一是僧團公有房舍，對方已分配依規入住，二是先前已經同意對方在該房中居住，三是心懷瞋恨動手將對方強行拉出，四是沒有如法的正當因緣，五是一拉出房門即犯波逸提罪。《摩訶僧祇律》說，強拉他人出房時，對方如果抱住柱子、抓住門框、倚靠牆壁，比丘尼每將對方拉離一個倚靠處，就各犯一個波逸提罪；如果是口出惡言驅逐喝斥，每罵一聲驅離一處也各犯一個波逸提罪。依照本律，若是驅逐沙彌尼、式叉摩那等下二眾，犯突吉羅罪。《摩訶僧祇律》說，比丘尼若是出遠門，沒有把房舍床褥移交給知事人，就鎖閉門窗擅自離去的，犯波逸提罪。《十誦律》與《摩得勒伽論》說，如果睡覺打鼾嚴重，應當主動起身經行；如果無法經行，應當起身移到隱僻無人之處睡覺，不應當在房內吵鬧惱亂他人。

【541-0028】04_比丘尼鈔/04b_卷中之下#66
【原文】不詣大僧自恣戒具四緣犯一是夏安居竟二五人已上成眾三無因緣四不差人往自恣便犯五分云若尼聚落無比丘自恣無請處蘭若有比丘道路險難彼比丘為尼入聚落自恣尼先自眾中自恣已後差人往比丘中教誡語同。
【譯文】（安居結束不詣大僧處求自恣戒）具備四個條件即構成犯罪：一是夏安居已經圓滿結束，二是尼眾在五人以上足堪形成大眾，三是沒有正當阻礙因緣，四是不派遣代表前往比丘僧團中請求自恣，即犯波逸提罪。《五分律》說，如果比丘尼居住的聚落中沒有比丘安居自恣、無處可請，而阿蘭若處雖然有比丘但道路凶險艱難，那些比丘可以為了比丘尼專門進入聚落舉行自恣；比丘尼應先在自己的僧眾中自恣完畢，之後差遣使者前往比丘僧中（請求自恣），其遣使請白之言辭與前述請教誡法相同。

【541-0029】04_比丘尼鈔/04b_卷中之下#67
【原文】不依大僧安居戒具三緣犯一在無比丘處二不作依止心三結安居竟便犯。
【譯文】（不安居在有大僧依止之處戒）具備三個條件即構成犯罪：一是安居的處所附近完全沒有比丘，二是內心沒有生起依止大僧求教之心，三是結夏安居羯磨宣告完畢即犯波逸提罪。

【541-0030】04_比丘尼鈔/04b_卷中之下#68
【原文】不白入大僧寺戒具四緣犯一是有比丘寺二不白比丘三無因緣四入門便犯僧祇云尼不白大僧入伽藍者最初入者提後入者無犯五分云若立不見比丘不得不白而入須見比丘應往前白比丘籌量可聽不可聽者若人不見及不聽而入提。
【譯文】（不先白告擅入大僧寺院戒）具備四個條件即構成犯罪：一是該寺院確實是有大比丘居住的寺院，二是未曾預先向比丘白告通報，三是沒有遭遇危急救難等特殊因緣，四是一步邁進山門即犯波逸提罪。《摩訶僧祇律》說，比丘尼若是沒有向大僧白告就擅自進入僧伽藍，走在最前面最先進入的人犯波逸提罪，跟隨在後進入的人則不犯戒。《五分律》說，如果站在寺門外看不見比丘，不得在未白告的情況下逕自闖入；必須見到比丘，應上前向比丘稟告，由比丘權衡考量是否准許入內；如果不見比丘，或是未獲准許就擅自進入的，犯波逸提罪。

【541-0031】04_比丘尼鈔/04b_卷中之下#69
【原文】訶罵比丘戒具三緣犯一是大比丘二以惡言罵彼三言詞了了便犯十誦云喑嗌向比丘者提。
【譯文】（惡言呵罵大比丘戒）具備三個條件即構成犯罪：一是對象是大比丘，二是口出粗暴惡毒之言辱罵對方，三是言語詞意清楚明白即犯波逸提罪。《十誦律》說，如果氣惱忿恨、發出怨聲對著比丘號哭叫囂的，犯波逸提罪。

【541-0032】04_比丘尼鈔/04b_卷中之下#70
【原文】罵尼眾戒具四緣犯一是尼眾二因諍事瞋怨三以惡言罵辱四言詞了了便犯。
【譯文】（瞋罵比丘尼眾戒）具備四個條件即構成犯罪：一是對象是比丘尼僧眾，二是起因於爭執糾紛而內心懷抱瞋恨怨懟，三是以惡毒粗暴之言侮辱謾罵，四是言語詞意清楚明白即犯波逸提罪。
