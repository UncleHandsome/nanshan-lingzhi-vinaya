# 校閱材料　第655檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【655-0001】資持記/16a_下四#48
【原文】《智論》，教差次。請命依臘，須從上起；差役取卑，故從下起。四中，《薩遮、俱舍》，制不得壞。上品治者，同逆罪故。《智論、僧祇》，開壞惡易好。五中。供人即法者，以人解法，法依人故。六中。律令選一能者，知掌眾務；初大僧，二沙彌，三淨人，尋文可見。帥，所類反，領也。七中，初科，《僧祇》明賞給。
【譯文】《大智度論》教導差遣僧差的先後次第。如果是請命供養，應依照戒臘的高低，必須從上座大德開始延請；如果是派遣執役勞務，應先選取戒臘居下的人，所以必須從下座僧人開始差遣。第四段中，《薩遮尼乾子經》與《俱舍論》嚴厲規定，寺院佛法設施絕對不得毀壞。律中判定以最高品階的罪相論處，是因為毀壞僧物等同於犯下五逆重罪的緣故。而《大智度論》與《僧祇律》中，則特別開許若是為了除壞破爛醜惡的設施以換取良好莊嚴的新物，則不在禁止之列。第五段中：供養有德之人便等同於供養正法，這是因為人能通達理解正法，正法也完全依賴人來弘揚住持的緣故。第六段中：戒律命令大眾應當推選出一名具備才幹能力的人，負責總領執掌僧團的大眾事務；第一在大僧中立維那，第二在沙彌中立沙彌首領，第三在淨人中立主帥，細尋下文便可明白。經文中的「帥」字，音讀為率領的「率」，意思便是總領率領。第七段的第一科中，《僧祇律》闡明對於辛勞執事者的賞賜給予。

【655-0002】資持記/16a_下四#49
【原文】言有功者，是彼經營故。一熟，謂一番採熟留生也。一剪，謂一番剪也。《五分》三段。初明知事嘗食，開舌舐吉；次明僧物暫借俗用，相依住故；三明五種僧物不分賣者，是常住故。《僧祇》同上，初制永定。次開轉易。《四分》。結蘭。暫礙僧用，必侵入己，如上犯重。次科。
【譯文】所謂「有功勞的人」，是指此處的果木等物產全由那人辛苦經營培植的緣故。所謂「成熟一輪」，是指第一批採摘已成熟的果實，而留下尚未成熟的。所謂「一剪」，是指收割一茬瓜菜。《五分律》包含三段內容：第一說明知事僧人在調味時若要品嘗食物，開許將食物放於掌中以舌舐嘗調味，開免舌舐手食之突吉羅罪（吉）；第二說明僧團的常住器具可以暫時借給俗人使用，這是因為彼此相互依存居住的緣故；第三說明有五種僧團常住物資是絕對不得私自瓜分販賣的，因為這是屬於十方大眾常住所有的緣故。《僧祇律》與上述意旨相同，首先規定常住物應永遠固定保有。其次開許在必要時得以物易物以求其合宜。《四分律》規定結偷蘭遮罪，是因為只是暫時妨礙僧團使用；若是侵占歸入己有，則正如前面所說應犯重罪。在下一科中：

【655-0003】資持記/16a_下四#50
【原文】《僧祇》，收舉補治，並制共作，不容辭設，違得小罪。徐行，謂緩步。三中，《母論》，初明賞給，量功多少。若下，次教施食，心無希望。非隨病食，病所忌者。得罪，準前殺戒，理應結蘭，或違教吉。已上諸文，並如〈隨相〉盜戒具委。第二門，初科。
【譯文】《僧祇律》規定，收拾保管與修補修治僧物，全都命令大眾必須共同協作，絕不容許藉詞推諉，違背這項規定便結得輕微的小罪。所謂「徐徐行走」，是指沉穩和緩的步伐。第三段中，《毘尼母論》首先闡明賞賜勞作的原則，應當審度功勞的多寡來給予相應的物資。從「若」字以下，接著教導為病患布施食物時，內心絕不可懷抱貪求回報的奢望。不得給予那些不合乎病情的飲食，也就是病患身體所忌諱的食物。若給予忌諱之物而結罪，比照前面殺戒的判定準則，在理義上應結偷蘭遮罪，或者是結犯違背教令的突吉羅罪。以上所引述的種種律文，全都如同在〈隨相篇〉的偷盜戒章節中所詳細剖析陳述的那樣。第二門的第一科中：

【655-0004】資持記/16a_下四#51
【原文】五法，慈心平等，離分別過。二謙下自卑，離貢高過。注中四句，行者反照，於己如何。上二句，即《梵網》云：惡事自向己，好事與他人；下二句，出《淨名經》；彼文續云：恒以一心，求諸功德。三坐起有序，離亂眾過。註中，應字去呼，合也；
【譯文】這「五種法度」分別是：第一、內懷平等無偏的慈悲心，遠離人我分別計較的過失。第二、謙遜低下安於卑位，遠離貢高我慢自負的過失。在注文中的四句話，是命令修行者必須時時反省自照，檢視自己平日的修持究竟如何。前兩句便是《梵網經》中所說的：「凡是罪過不好的事自己一肩承擔，凡是榮譽美好的事全部讓與他人；」後兩句則出自《維摩詰所說經》，該經文接著說道：「恆常以純一無雜的專注之心，勤勉求取一切出世功德。」第三、起坐進退安詳有序，遠離擾亂大眾威儀的過失。注文中的「應」字讀作去聲，是相合、合宜的意思；

【655-0005】資持記/16a_下四#52
【原文】俯下仰上，舉動合宜，故云得時。四不雜語，離戲論過。註中，初句明上說法，次句示上不雜語。五令示默，離惱眾過。次科，《善見》，明下座辭謝。裝字去呼，即用象牙為飾。《智論》，明陞座伸敬。師子座，謂說法之處；
【譯文】俯下與仰上，一切舉止動靜都合乎時宜法度，所以才說「行持得時」。第四、絕不隨意插話閒聊，遠離世俗戲論雜話的過失。注文中，首句闡明上文的「說法」，次句顯示上文的「不雜語」。第五、令自身保持沉默，遠離惱亂僧團大眾的過失。在下一科中，《善見律》闡明下法座、禮僧辭謝的威儀。文中的「裝」字讀作去聲，是指用象牙來裝飾（法扇）。《大智度論》闡明登上法座講法時應伸展恭敬之禮。所謂「師子座」，是指說法教化的處所；

【655-0006】資持記/16a_下四#53
【原文】《智論》云：佛為人中師子，佛所坐處，若床若地，皆名師子座。《僧祇》，莊嚴法座。拂華坐者，去奢美故。三中，初入堂威儀。傍門面者，隨左右頰而舉足也。右下，次示打法。擬砧，使椎砧相當也。重響，謂振聲。下數不辨，故須左手𭣋之。〔舊云表眾不一，謬矣；又見打者，以左手就椎，作旋轉勢，更可笑也。〕然下，三明啟白。
【譯文】《大智度論》說：佛陀是人中的獅子，佛陀所坐的地方，無論是床或是地面，都稱為「師子座」。《僧祇律》說明莊嚴法座的作法；所謂「拂華坐」，是為了去除奢華華美的緣故。第三科中，首先說明進入殿堂時的威儀。所謂「傍門面」，是指隨著左右門頰的方向舉足而入。從「右」字以下，其次指示打椎的方法。所謂「擬砧」，是使椎與砧互相對準；所謂「重響」，是指震動所發的餘聲。否則擊打的次數便難以辨別，因此必須用左手按住木椎（以止住餘振）。〔舊說認為這是表示僧眾心意不一，這是錯誤的；又曾見打椎的人，以左手就著椎作旋轉之勢，更是可笑。〕從「然」字以下，第三說明啟白之事。

【655-0007】資持記/16a_下四#54
【原文】等得，亦云等供，即大小食時，唱食平等。不下，制非法。準知打椎，上為白告靜眾，不同鍾磬打為事用也。第三門，此門事雜，約義分為一十六段，初中。五問，無非戲調打辱，不為求法，故不須答。次料。如〈標宗〉具釋。三中，《五分》。差次，謂知事差僧，及法食會集；
【譯文】所謂「等得」，也稱為「等供」，是指在早齋或午齋過堂的大小時分，唱令大眾受食平等無偏。從「不」字以下，嚴厲禁止非法的敲擊。比照規矩便可知道，擊打木椎主要是為了向大眾宣白告示、令僧堂維持肅靜之用，這與日常敲擊鐘磬用以操辦雜務勞役是完全不同的。在第三門中，因為本門所涵括的事相極為繁雜，依照義理大致劃分為十六個小段落：在第一小段中，（上述《十誦》所列的）五種問難，無一不是蓄意戲弄、嘲諷與羞辱僧眾，根本不是為了至誠求索正法，所以比丘完全無須予以作答。隨後的辨析分剖，如同在〈標宗篇〉中已經完整詳細解釋過的那樣。在第三小段中，《五分律》提到：差遣次第，是指知事僧差派僧人服役，以及召集僧眾進行法會講法或過堂受食等事相；

【655-0008】資持記/16a_下四#55
【原文】非唯此二，故云等也。《四分》。學誦，謂誦外書俗典。世論，謂方算語論。雜法，即〈雜犍度〉。《十誦》。文頌，即今歌詩。可怖畏者，法將滅故。以書算卜術，俗典文頌，俱是世法，非出家業；為因緣故，時復許之。今時釋子，名實俱喪；
【譯文】並非僅僅只有這兩項，所以才用「等」字來涵括其餘。《四分律》提到：所謂「學誦」，是指讀誦外道的書籍與世俗的經典。所謂「世論」，是指方術、曆算、談辯等言論技藝。所謂「雜法」，指的便是律藏中的〈雜犍度〉。《十誦律》提到：所謂「文頌」，就是指現今的詩詞歌賦。之所以說這件事「令人感到怖畏恐怖」，是因為這代表正法即將走向衰微湮滅的緣故。因為書法、曆算、占卜醫術，以及世俗經典與詩詞歌賦，全都是屬於世間有漏之法，根本不是出家解脫的正業；唯有在利益眾生的特殊因緣之下，佛陀有時才會隨緣暫時聽許。現今末法時期的佛門弟子，在出家的名義與實質上幾乎都已喪失殆盡；

【655-0009】資持記/16a_下四#56
【原文】能書寫則稱為草聖，通俗典則自號文章，擇地則名為山水，卜術則呼為三命；豈意捨家事佛，隨順俗流之名；本圖厭世超昇，翻習生死之業。故《智論》云：習外典，如以刀割泥；泥無所成，而刀自損；又如視日光，令人眼暗。然往古高僧，亦多異學；或精草隷，或善篇章，或醫術馳名，或陰陽顯譽；
【譯文】稍微擅長書法書寫的便自誇自封為「草聖」，稍微通曉世俗文史典籍的便自命為「文章巨擘」，懂得堪輿選地的便自居為「山水地理宗師」，通曉占卜算命之術的便自吹為「三命精微大師」；哪裡想得到自己當初辭親出家原本是為了求事於佛，如今卻反過來隨逐附和世俗凡流的虛名；原本圖謀的是厭離五濁世間以求超昇解脫，如今反倒全力修習流轉生死的有漏之業。所以《大智度論》說道：出家人修習外道世俗典籍，好比「拿鋒利的寶刀去切割爛泥」；爛泥固然絲毫無法塑造成功，而寶刀的鋒刃自己卻已經受損變鈍了；又好比「直視烈日強光，反倒使人的眼睛當場盲黑」。然而縱觀古代的諸位高僧大德，也往往兼通許多世間異學；他們有的精研草書隸書，有的擅長詩文篇章，有的以精湛醫術揚名當世，有的以精通陰陽曆數顯赫一時；

【原文】皆謂精窮本業，傍涉餘宗；無非志在護持，助通佛化。故《善戒經》云：若為論義，破於邪見；若二分經，一分外書，不犯；《四分》開誦，皆此意耳。今或沽名邀利，附勢矜能；形廁方袍，心染浮俗；畢身虛度，良可哀哉。《母論》。一句一偈，通指三藏教詮；

【655-0011】資持記/16a_下四#58
【原文】雖是聖教，令觀時用舍，不可專固，故云應行即行等。後世比丘，即佛滅後，傳法祖師；凡有言教，亦須隨宜，故云亦爾。四中，《五分》，示開制。無人，謂無剃髮者。難緣，謂遭世難。論家，即《多論》。彼明次第，即約多人，同時剃故。《母論》，簡剃處。餘毛，即身腋等處，律制偷蘭。
【譯文】這縱然是至高無上的聖者教法，但也要求修學者必須審察時機來決定取捨運用，絕不可固執一端僵化不變，所以才說「應該行持的時候便如實推行」等等。所謂「後世的比丘」，是指佛陀滅度之後，歷代承續弘揚正法的祖師大德；凡是所立下的言教法規，也必須隨順時機因緣而靈活運用，所以才說「也是如此」。在第四小段中，《五分律》明示了開許與禁制的界限。所謂「無人」，是指身邊沒有可以代為剃髮的人。所謂「遇上險難因緣」，是指遭遇世間戰亂流離等危急苦難。所謂「論家」，指的便是《薩婆多論》的論師。該論闡明剃髮的先後次第，是針對有多數人同時聚在一起剃髮的情況而言。《毘尼母論》則嚴格揀別可以剃除毛髮的部位。至於其餘各處的體毛，也就是腋下、隱私部位等處，戒律明文規定若任意剃除便結偷蘭遮罪。
