# 校閱材料　第870檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【870-0010】02_戒疏/21c_卷四下之三#16
【原文】【疏】第五段，明輕縱放逸行。然放逸之相極多，莫非迹散流俗，心隨苦樂，名「放逸」也。如《涅槃》說「最為善行之霜雹」。就偈分二：上半明因行，下半明果滿也。
【譯文】【疏文】第五段，說明輕率縱容的放逸行為。然而放逸的相貌極為繁多，無非是行為行跡散漫於世俗之中，心境隨著苦受與樂受起伏，這就稱為「放逸」。如同《涅槃經》中所說「放逸最是摧毀善行之冰雹」。就這首偈頌分為兩部分：上半首說明因地的修行，下半首說明果位的圓滿。

【870-0011】02_戒疏/21c_卷四下之三#17
【原文】【記】第五佛偈，標分中。初示放逸相。「迹散流俗」，謂行非潔白。「心隨苦樂」，謂志不堅正。「如」下，引示。放逸能喪「善行」，「霜雹」能摧生物，故以喻焉。彼經第十三云：「諸善男子，因不放逸能生世出世法，若有欲得阿耨菩提，應當勤修不放逸法。夫放逸者，有十三果報：一、樂為世間作業，二、樂說無益之語，三、常樂久寢睡眠，四、樂說世間之事，五、常樂親近惡友，六、懈怠懶惰，七、常為他人所輕，八、雖有所聞尋復忘失，九、樂處邊地，十、不能調伏諸根，十一、食不知足，十二、不樂定寂，十三、所見不正。夫放逸者，雖得近佛及佛弟子，猶名為遠。」
【譯文】【記文】第五尊佛的偈頌，在標出科判的段落中。最初指示放逸的相貌。「行為行跡散漫於世俗」，是指品行不夠潔白純淨。「心境隨苦樂起伏」，是指心志不夠堅定純正。「如」以下，引用經文予以指示。放逸能摧折喪失「善行」，「冰雹」能摧毀生長的萬物，所以以此為譬喻。那部經第十三卷說：「各位善男子，由於不放逸而能生起世間與出世間的善法，若有人想要證得無上正等菩提，就應當勤奮修習不放逸之法。夫放逸者，會有十三種果報：第一、喜好從事世間的事務工作；第二、喜好宣說沒有益處的言語；第三、時常貪圖長久的睡眠；第四、喜好談論世間的瑣事；第五、時常樂於親近惡友；第六、懈怠與懶惰；第七、時常被他人輕賤鄙視；第八、雖然有所聽聞隨後又遺忘喪失；第九、喜好居住於邊陲偏僻之地；第十、無法調伏眼耳等諸根；第十一、飲食不知節制滿足；第十二、不喜愛禪定與寂靜；第十三、所持的見解不正。凡是放逸的人，雖然得以親近佛陀以及佛的弟子，仍然被稱作是遠離正法。」

【870-0012】02_戒疏/21c_卷四下之三#18
【原文】【疏】縱心塵境，隨緣染著，方名「放逸」。若能攝心，與正觀相應，離諸緣過，故曰「心莫作放逸」。然逸通身口，心為本業，故指「心」也。此明離過，進修會正，有解脫因，名為「聖法當勤學」。
【譯文】【疏文】縱任心念奔逐於塵勞境界，隨著外緣而染汙執著，才稱為「放逸」。如果能夠收攝身心，與正觀智慧相應，遠離諸多攀緣的過失，所以說「內心不要放逸」。然而放逸通貫於身業與口業，心則是造業的根本，所以特別指出「心」。這是說明遠離過失，進一步修持而契會於正道，具足解脫的正因，稱為「聖法應當勤加學習」。

【原文】【記】上半偈中，初釋上句。初牒釋。「逸通身口」，言其末也；「心為本業」，窮其始也。「此」下，釋下句。躡前離過，生下學法。
【譯文】【記文】在上半首偈頌中，首先解釋第一句。最初重提文句並解釋。「放逸通貫身與口」，說的是枝末末梢；「心是造業根本」，是追究其最初源頭。「此」以下，解釋第二句。順應前面遠離過失之意，引申出下文學習佛法之理。

【870-0014】02_戒疏/21c_卷四下之三#20
【原文】【疏】「如是」者，牒上因成也。由行聖法，入增忍位，苦業永亡，故曰「無憂愁」也。心淨慧明，諸有永絕，故曰「心定入涅槃」也。
【譯文】【疏文】「如是」二字，是延續承接前文因地修行的成就。由於實踐聖法的緣故，進入增上忍位，墮入苦趣之惡業永遠滅除，所以說「沒有憂愁」。心念清淨而智慧朗照，三界諸有永遠斷絕，所以說「心專注安定就能證入涅槃」。

【870-0015】02_戒疏/21c_卷四下之三#21
【原文】【記】次半偈中。初釋上句。「增忍位」，即內凡第三位。「苦業永亡」者，且據三途因果為言，以忍位不退，不墮惡道故。「心」下，次釋下句。「諸有永絕」，即無學極聖。上舉深賢，永離三惡，下舉極聖，永出三界。
【譯文】【記文】在下半首偈頌中。首先解釋第三句。「增上忍位」，也就是內凡位中的第三位。「墮入苦趣之惡業永遠滅除」，姑且是根據三惡道的因果來論述，因為到了忍位就不會退轉，不會墮落惡道。「心」字以下，接著解釋第四句。「三界諸有永遠斷絕」，也就是無學位的至極聖人。上句舉出深位的賢人，永遠脫離三惡道，下句舉出至極的聖人，永遠超脫三界輪迴。
