# 校閱材料　第156檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【156-0001】01_行事鈔/07c_卷中之三#32
【原文】露地然火戒五十七。四緣：一是露地，二無緣，三然草木有焰者，四然便犯。《五分》：為炙身然火，焰高四指者墮。《多論》：若他已然，後隨作何事皆墮。《四分》：病者須火便身也，得自然，若教人。若無緣，燒草木糠糞，一切墮。若半焦、然炭、及不云知是看是，一切吉羅。《僧祇》：旋火作輪，或火中有草木撥聚，一切墮。若壞生二罪：一壞生，二然火；在生地，理又一墮。《僧祇》：若抖擻火炬，在灰上瓦上，不得在生地。律不犯者：語言知是看是。若病人自然、教人然。有緣看病人，為病者煮糜粥羹飯。若在厨屋中、浴室中，熏鉢煮染，然燈燒香，一切並開。
【譯文】露天無故生火戒第五十七。具備四個條件構成犯戒：一是身處露天無遮之處；二是沒有正當因緣；三是點燃草木發出火焰；四是火一點燃隨即犯波逸提。《五分律》說：為了烤身取暖而生火，火焰高達四指者犯波逸提。《薩婆多論》說：如果是別人已經點燃的火，比丘隨後借火去做任何事情，全都犯波逸提。《四分律》說：病患需要火來調順身體取暖，可以自己點火，或者教別人點火。如果沒有正當因緣，焚燒草木、米糠、乾糞，全都犯波逸提。如果燃燒半焦的木頭、點燃木炭、以及生火時沒有口說「知是（知曉此火）」、「看是（看顧此火）」，全都犯突吉羅。《摩訶僧祇律》說：揮舞火把旋轉成火輪玩耍，或者把火堆中的草木撥弄聚攏，全都犯波逸提。如果損害了有生命的植物則結兩種罪：一是破壞有生命物，二是擅自生火；若是在未經燒墾的生土地面（生地）上生火，按義理還要再結一個波逸提罪。《摩訶僧祇律》說：抖落火把上的火星，必須在熟灰或瓦礫石板上進行，不得在生土地面上抖落。戒律中開許不犯的情況：點火時口中稱說「知是」、「看是」。生病的人自己點火、或教他人點火。因故照看看護病患，為病患熬煮稀粥、菜羹、米飯。如果在廚房中、浴室中生火，或者是為了熏烤瓦鉢、煎煮染料，或者點油燈、焚名香，這些全部都開許不犯。

【156-0002】01_行事鈔/07c_卷中之三#33
【原文】藏他衣鉢戒五十八。三緣：一大比丘衣鉢，二驚動意，三取藏便犯。《多》云：若五大色衣、不淨衣，吉羅。未熏鉢、鍵𨩲、衣鉢作淨畜者，皆墮。律不犯者：若實知彼人物，相體悉而取舉。若在露地，風雨漂漬，舉之。若物主為性慢藏，衣物狼藉，為誡勅故藏之。若借他衣，而彼不收，故舉。若因此衣鉢，有命梵等緣故藏，一切不犯。
【譯文】藏匿其他比丘衣鉢戒第五十八。具備三個條件構成犯戒：一是所藏之物是具戒大比丘的衣物或鉢盂；二是心存開玩笑故意驚擾恐嚇對方的意圖；三是拿取並隱藏起來，隨即犯波逸提。《薩婆多論》說：如果是藏匿染有五大正色的違法衣、或未作淨法的不淨衣，犯突吉羅。如果是尚未熏焙的鉢、鍵𨩲（鑰匙或金屬用具）〔註：「鍵𨩲」，律藏名物，亦作鍵鎱、鍵鑷，指鑰匙或金屬匙鏟〕、以及已經作過淨法蓄持的衣鉢，藏匿起來全都犯波逸提。戒律中開許不犯的情況：如果確實知道那是某人的衣物，因彼此相知體諒而代為收檢保管。如果在露天之處，眼見即將被風吹雨淋浸泡損壞，因而將它收起。如果物主本性散漫懈怠、不會妥善收藏，衣物雜亂狼藉，為了告誡策勵他而暫時藏匿。如果是借用他人的衣服，而對方用後未及時收理，因而代為收檢。如果因為這件衣鉢，可能引發危害身命、毀犯梵行等重大凶險緣故而暫時收藏，這一切情況都開許不犯。

【156-0003】01_行事鈔/07c_卷中之三#34
【原文】真實淨不語取戒五十九。四緣：一是己物，二作真實淨，三不語主，四取便犯。戒本列五眾者，以明犯不犯義，辨相具解。展轉淨施，問不問俱得。
【譯文】作真實淨施後不告知受主而取用戒第五十九。具備四個條件構成犯戒：一是這件物品原本是自己的財物；二是已經對他人作了「真實淨施」（將所有權正式轉移給他人以合律蓄持）；三是未曾告知新的主人；四是擅自拿來取用，隨即犯波逸提。戒本中之所以列舉出出家五眾，是為了彰明犯戒與不犯戒的分野界限，明辨其行相細節以使人通達了知。若是作「展轉淨施」（寄名暫託作淨，所有權實質仍在自己），無論是否告知對方，直接拿取都可以，不犯戒。
