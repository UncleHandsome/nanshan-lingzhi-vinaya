# 校閱材料　第265檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【265-0001】03_業疏/12b_卷三之一#98
【原文】次未具中。五戒鹿野者，律中佛為耶輸伽父授五戒，云「是為最初優婆塞三自歸」，耶輸伽父為首是也。十戒羅睺為始，可以為定。八戒雖云未測，然十戒相但於八中加一，可驗在前
【譯文】在第二「未具足戒」之中。五戒在鹿野苑傳授，是指律中佛陀為耶輸伽的父親傳授五戒，說「這是世間最初以三自歸受戒的優婆塞」，正是以耶輸伽之父為第一人。沙彌十戒以羅睺羅為創始，這是可以斷定的。八關齋戒雖然說尚無法測知確切時間，然而十戒的戒相只不過是在八戒之中加上一條（不持金銀財寶戒），所以可以驗證八戒是在十戒之前就興立了。

【原文】具解受義，附文消判，更如後卷
【譯文】若要具體詳細地理解受戒的義理，必須附隨相關律文來消解評判，更詳盡的內容見於後卷。

【265-0003】03_業疏/12b_卷三之一#100
【原文】指廣中。前但分別五受而未明受義，故指如文。後卷即自此之後解釋標目、緣法等文，皆見受義；或可「卷」合作「說」，疑是字誤
【譯文】在指示詳盡內容之中。前面只是分別辨析了五種受戒法，而尚未闡明受戒的精要義理，所以指陳詳見後文。「後卷」就是從這裡之後解釋標題條目、緣法等各段文字，都可以見到受戒的義理；或者「卷」字應當作「說」字，懷疑是傳抄文字之誤。

【265-0004】03_業疏/13a_卷三之二#1
【原文】就法辨緣，言授戒者，標其目也；就事辨緣，言正授者，顯行務也。就初法中，注分為二：初顯戒德尊高，後依緣簡略
【譯文】就戒法來辨別因緣，說「授戒」的，是標示其綱目；就事相來辨別因緣，說「正授」的，是彰顯臨機修行的事務。在第一項就戒法辨緣之中，夾注分為兩部分：第一是彰顯戒德的尊嚴崇高，第二是依憑因緣而簡別選取。

【265-0005】03_業疏/13a_卷三之二#2
【原文】釋緣分示中：就法辨緣言標目者，謂標列條目，楷模可準，體此五緣，則曉知成敗；就事辨緣言行務者，謂臨機正受次第儀式，準此八緣，則事有倫序。又就法則總收終始，就事則唯局受前。昔人解《鈔》，科前為古五緣、後為今十緣者，幾許誤哉！今猶講之，誤未省耳
【譯文】在解釋因緣分類指示之中：就戒法辨別因緣而說「標目」，是指標列條目，作為可以依準的楷模標準，體察這五種緣，就能明了戒法得失成敗的關鍵；就事相辨別因緣而說「行務」，是指臨場正式授戒時的先後儀式程序，依循這八種緣，那麼法事就能井然有序。再者，就戒法而言是總括包含自始至終，就事相而言則唯獨局限在受戒之前。古時有人解釋《事鈔》，將前者判為「古代五緣」、將後者判為「現今十緣」，這是多麼嚴重的錯誤啊！現在的人依然這樣宣講，實在是尚未省察出其中的訛誤罷了。

【265-0006】03_業疏/13a_卷三之二#3
【原文】文列戒為舟航、違順約緣者，以如來出世，不欲增長諸有，要求滅欲，故立茲學。然戒是定慧初基、眾行元本，本既不立，餘何所憑？但以佛世利機，契動便感；末時澆薄，聖制從緣。緣集則作業功成，緣散則戒德無立。無作不可見也，託緣定其有無，大聖唱言，信非徒爾，故前控引生起緣非
【譯文】疏文中列出戒律是生死之舟航、違順取決於因緣，是因為如來出興於世間，並不想讓眾生增長三界輪迴的種種生存境界，而是要求斷滅貪欲，所以才創立了這門戒學。然而戒律是禪定與智慧的初步基礎，是一切行持的根本源頭；根本既然不能確立，其餘的修行又能憑藉什麼？只是因為佛陀在世時眾生根機敏利，心意契合動念便能感得戒體；末世世風澆薄浮泛，至聖佛陀才制定受戒必須依順因緣。各種因緣聚集完備則造作戒業之功成就，因緣散亂欠缺則戒德無法建立。無作戒體是不可見的，必須依託外在因緣來判定其有無，大聖佛陀所宣發的言教，確實不是隨意虛設的，所以前面引證指陳而生起關於受戒因緣是非的辨析。

【265-0007】03_業疏/13a_卷三之二#4
【原文】就法顯戒德中：初至「所憑」，釋歎戒。前釋生死舟航，「不欲增諸有」者，人天非意也；「要求滅欲」者，為令出離也，欲即是惑，生死本故。「然」下釋正法根本，定慧是別標二學，眾行乃統攝三乘。「但」下至「徒爾」，次釋立緣。初敘須緣所以，利機如善來度者，契動謂不假多緣也。「緣集」下明順違得失，集即齊具，散即乖缺。「無作非色」故不可見，「眾緣有相」故可定之。「大聖唱言」，謂是佛制。「故」下示注意，控猶據也
【譯文】在就法彰顯戒德之中：開頭至「所憑」一句，是解釋讚歎戒律。前半段解釋戒為生死舟航，「不欲增諸有」是指佛意不在於求得人天福報；「要求滅欲」是為了令眾生解脫出離，欲就是煩惱迷惑，因為它是生死輪迴的根本。「然」字以下解釋戒為正法根本，定慧是個別標示定慧二學，眾行則是總體統攝三乘的一切行門。「但」字以下至「徒爾」，接著解釋立緣的理由。開頭敘述必須依託因緣的原因，敏利的根機如同善來度化之人，「契動」是指不須假借繁多的因緣。「緣集」以下說明順違與得失，集就是齊備具足，散就是乖違欠缺。「無作非色」所以肉眼不可見，「眾緣有相」所以可以據以判定其有無。「大聖唱言」，是指這是佛陀所制定的教令。「故」字以下顯示疏文註解的用意，「控」的意思如同引證依據。

【265-0008】03_業疏/13a_卷三之二#5
【原文】今解已下，託緣顯障。文云「二種羯磨具五緣」者，或中邊分二，或僧尼分二，竝通收羯磨，用分諸受。然諸部中，敘緣不一：《母論》但就緣言，《多釋》唯列因相。今通會之，總五為約，謂能、所、心，及具、終也
【譯文】「今解」以下，是依託因緣來彰顯障礙。疏文中說「二種羯磨具足五緣」，或者是指依中國（中印度）與邊地而分為二種，或者是指依比丘僧與比丘尼僧而分為二種，都是普遍含攝羯磨法，用來分別各種受戒法。然而在各部派律典之中，敘述因緣各不一致：《毗尼母論》只就「緣」的角度來說，《薩婆多論》的解釋則只列出「因」的事相。現在普遍融會各說，總結以五種為準則，也就是：能受人、所受境、發心，以及作法資具、終成作法。

【265-0009】03_業疏/13a_卷三之二#6
【原文】次科釋總標中：初點文，「託緣」即下五緣，一一緣下各顯乖障，用成如法。「文」下牒釋，中邊約方，僧尼約位。「竝通收」等者，羯磨六受，若中邊分者，十人、二十、遣信、曾歸，竝中國也；五人并義立十人，竝邊方也。若僧尼分者，五人、十人是僧，餘二十人等竝屬尼也。「然」下列示，《母論》如所對中三、五兩緣所引，《多釋》即是《多論》，如能受中初、三兩緣所引。此據能、所以分因緣，或約發心為因，餘竝為緣，隨時不定，勿滯一端
【譯文】在第二科解釋總標之中：開頭點明文字，「託緣」就是指下文的五種緣，在每一種緣的下面各自顯發違背法度的障礙，以彰顯如法的狀態。「文」字以下引述原文並作解釋，中邊是就地域方所而分，僧尼是就僧眾階位而分。所謂「竝通收」等，羯磨六種受戒法，如果按中邊來分：十人受、二十眾受、遣信受、曾歸受，都屬於中國；五人受以及比照義理建立的十人受，都屬於邊地。如果按僧尼來分：五人受、十人受屬於比丘僧，其餘二十眾受等全屬於比丘尼。「然」字以下列出示範，《毗尼母論》就像在所對境之中第三、第五兩種緣中所引用的那樣，《多釋》就是《薩婆多論》，如同在能受人之中第一、第三兩種緣中所引用的那樣。這是依據能受與所受來區分因與緣，或者也可以將發心視為因，其餘全都視為緣，隨順各時的解說並不固定，不要執滯於單一說法。

【265-0010】03_業疏/13a_卷三之二#7
【原文】就初能受類分又五，以能名濫，非別不顯。在生正務，唯戒尊高，有缺諸緣，雖受不獲，故須指掌程露其相故也
【譯文】就第一項能受人之中分類又分為五種，因為「能受」的名稱容易含混籠統，不加以分別就無法顯發明確。在人的一生中最重要的正業事務，唯有戒律最為尊嚴崇高；如果有所欠缺這些因緣，即使受戒也無法獲得戒體，所以必須如同指看手掌般明確顯露其相狀的緣故。

【譯文】文中列明請師法式要在僧眾大眾之中進行，是為了令受戒者親睹僧伽威儀法相而生起恭敬心。若必定要在受戒前一年或一月預先延請，也無妨礙。有人主張「請師加法須局限在受戒同一法席中進行，不得提早延及久前，是恐受者時間一久心生懈怠」，這在義理上似乎有所欠缺。依序隨位禮拜，是因為凡夫大多具有傲慢習氣，受戒的要旨在於敬奉謹慎，所以必須折伏傲慢之形體身軀，一心希求清淨正法，受戒之後每逢想犯戒時便會反思：這不是師長隨便傳授給我的。

【265-0077】03_業疏/13a_卷三之二#74
【原文】修敬中：初釋僧中，初出今解，僧、私兩通。預須受者，謂先私請也。「人」下次斥非，彼局僧中，不通先請。畢世師資，豈容心怠？故云似失，其實失也。「次」下次釋徧禮，初令盡敬，意在後持
【譯文】在「修敬」之中：首先解釋在僧眾中請師，先提出當前的見解，認為大眾僧中與私下延請兩皆融通。「預先受師」是指在受戒前私下延請。自「人」字以下斥責錯誤見解，彼說局限於受戒時的僧中，不通融受戒前預先請師。然而終身依止的師徒關係，豈能隨便任由弟子起懈怠之心？所以文中說「似失」，其實就是錯失了正理。自「次」字以下解釋遍禮大眾僧，受戒之初令其竭盡敬意，用意在於受戒之後能謹慎奉持。
