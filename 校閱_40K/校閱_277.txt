# 校閱材料　第277檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【277-0001】資持記/09a_中三上#40
【原文】四病者〔疥廯顛狂等〕，五罪者〔夷至吉羅〕，六罵者〔作世間淫穢醜惡語，《四分》無此。〕，七結使者〔愚癡暗鈍等〕。某甲說汝是句絕，即指上七種，傳告彼人也。若前三種有下中上，一切皆墮；後四無有下中上，亦一切墮；今引後四結文，通收七種；無論品類，欲離皆犯，故云無有等。
【譯文】第四是疾病〔疥癬、癲癇發狂等〕，第五是罪過〔從波羅夷罪到突吉羅罪〕，第六是惡罵〔說世間淫穢下流醜惡的話，《四分律》沒有這條。〕，第七是煩惱結使〔愚痴、頑固暗鈍等〕。說「某甲說你是如何如何」這句話停頓處，就是指上述七種事情，輾轉傳話告知對方。如果前三種具有下中上三品，只要傳話意圖離間全都墮入犯戒；後四種雖然沒有下中上三品的分別，也同樣全都墮入犯戒；如今引用後四種的結罪文句，通盤收攝了這七種事；不論品類高低，只要心存挑撥離間都算犯戒，所以說「沒有」等語。

【277-0002】資持記/09a_中三上#41
【原文】離不離墮者，離取起心，不論前境。後引《多論》彰異，上句明重結。如一說未離，再三說故。下明緣闕。此戒所犯，必兼二處；今但自搆，故入輕中。準此，若但傳言，不欲離散，理亦非重。一切吉者，彼論但云突吉羅，而前列多相，並是輕罪；故加一切，統而收之。
【譯文】所謂離間或未達離間都墮罪，是著眼於動念造作的離間心，而不論外在境界是否真的被挑撥成功。隨後引用《薩婆多論》彰顯不同情況，上一句說明重複結罪。例如說了一次雙方尚未決裂，又再次、三次前去挑撥。下一句說明犯戒條件欠缺。這條戒所造的犯行，必定要牽涉到兩處人事；如今只是自己在中間憑空捏造，所以歸入輕罪之中。依照這個道理，如果只是傳話，心中並沒有挑撥離間使人分散的意圖，在法理上也不算重罪。所謂「一切吉羅」，該論只是說犯突吉羅，而前面列出了多種罪相，全都是輕微之罪；所以加上「一切」二字，統括收攝。

【277-0003】資持記/09a_中三上#42
【原文】彼云說汝是多食戲笑欺誑多詐等，傳向比丘者，聞則吉羅，不聞亦吉。不犯中，上之二種，破近習惡人。世有濫濁之僧，反為眾首，俗愚無識，妄相親厚；護法利他，故破無犯；惡伴同之。和尚等者，次破共謀惡事。無義利者，謂欲共議侵壞僧塔；律云：數數語，方便欲作是也。破下，總結。
【譯文】該論說如果傳話說「某人說你是個貪吃、好嬉笑、欺詐騙人、詭計多端的人」，把這些話傳給比丘，對方聽懂了固然犯吉羅，沒聽懂也是犯吉羅罪。在不犯戒的條款中，上面的兩種情況，是為了破除親近依附的惡人。世間有些行為污濁敗壞的僧人，反而盤踞大眾的首位，世俗愚夫毫無見識，盲目與他們親厚交往；為了護持正法與利益大眾，所以拆穿離間他們並不算犯戒；對於惡劣同伴也是同樣道理。「和尚」等語，是接著說明破除眾人共同謀劃惡事。所謂「無義利的事」，是指想要共同商議侵占損壞僧團的常住物或佛塔；戒律所說的：屢屢商談言語，透過種種方便手段企圖造作者就是指這件事。從「破」字以下，是總結歸納。

【277-0004】資持記/09a_中三上#43
【原文】律文更列壞僧、助壞僧、非法、非律羯磨等。第四。〔佛在舍衛，阿那律行寄婬女舍宿；彼裸身來嬈，故制。〕緣中。第一簡下畜女得吉；又須可淫，簡下黃形石小皆吉。釋中，初科有三，初示女相。有智謂解知好惡，以簡幼稚。命根未斷，即簡死壞。室下，次明室相。
【譯文】戒律經文更列出了破壞僧團、協助破僧、舉行非法非律的羯磨法事等情況。第四條戒。〔佛陀在舍衛國時，阿那律尊者外出寄宿在淫女家中；那女人赤裸身體前來騷擾挑逗，佛陀因此制定此戒。〕犯戒條件中。第一條簡別與母畜生同宿只結吉羅罪；再者女人必須是具有行淫能力者，簡別如果是黃門、二形、石女、幼女，同宿都只結吉羅罪。解釋之中，第一科包含三個部分，首先指出女人的相貌特徵。具有智慧是指能夠分辨是非好壞，藉此簡別毫無知覺的幼童。命根未斷，就是簡別已經死亡或毀壞的屍體。從「室」以下，接著說明房屋的形制相貌。

【277-0005】資持記/09a_中三上#44
【原文】初相可知。注中上句示相，下二句釋疑。準論，即下引多見，同一室中有諸小房亦犯是也。第二注云長行房謂相連接者，簷下兩頭，即三邊有障，顯前敞也。第三注中通覆者，即四圍有屋，中開庭心，異下少開纔漏光耳。此下三辨犯相又二，前明正犯，初二句通標。或下，列相。
【譯文】第一種形狀容易明白。注文中上一句指出建築相貌，下面兩句用以釋除疑惑。依照論典的說法，就是下面所引《多論》《善見》二論所說，同一棟大屋中即便隔出許多小房間也同樣算犯戒。第二個注文說「長行房」是指相互連接的連排房屋，屋簷下的兩頭，也就是三面都有牆壁遮障，這顯現出前面是敞開的。第三個注文中所說「通覆」，是指四周全都有屋頂遮蓋，中間開出天井庭院，不同於下面所說只開微小孔隙僅能漏進光線的情況。從「此」以下，第三部分是辨析犯戒的具體相狀，又分為兩節，前半部說明正犯，前兩句通泛標明。從「或」以下，逐一列舉相狀。

【277-0006】資持記/09a_中三上#45
【原文】上三句明至室俱互，若亞臥一句示業分齊。言亞臥者，謂身斜倚，但令著處，即同臥相，律作敧臥。〔去寄切，不正也。〕隨下，結犯。隨轉犯者，業深教急故。若與下，次明輕罪有三，初明異趣。注引好畜，染同人類。若人下，明異報。並由前境非勝，故罪輕降。比丘下，明異儀。
【譯文】上面三句說明到達房室時男女雙方的動靜配合，至於「亞臥」這一句則是指出構成犯業的具體界限。所謂「亞臥」，是指身體側臥斜靠，只要身體有倚靠著地之處，就等同於臥倒的姿態，戒律中寫作「敧臥」。〔音去寄切，不正斜臥的意思。〕從「隨」以下，判定犯戒結罪。之所以隨動念轉身就犯戒，是因為淫業深重而戒教急迫的緣故。從「若與」以下，接著說明輕微之罪，共有三種，首先說明非人與畜生等異趣。注文中引證說端正的母畜生，對其起染著的心等同於對待人類。從「若人」以下，說明變形異報的眾生。都是由於對方的境界並非完整的人體，所以罪過降等減輕。從「比丘」以下，說明威儀姿態不同。

【277-0007】資持記/09a_中三上#46
【原文】準疏同宿，一須僧女俱臥，二須局在夜分；若互坐臥，及晝日俱臥，並犯屏坐；今此僧臥女立，故但犯吉。坐則犯提，如注所顯，即指後戒。引誡中，《十誦》，初示制急。羅漢聖人，雖無故犯；欲顯過重，極誡凡夫，故同一制。如下，喻顯女情，意令遠離。此律即那律緣起。餘下，正責。
【譯文】依照律疏的判定同宿的定義，一是必須僧人與女人同時躺臥，二是必須局限在夜晚時分；如果一人坐著一人躺臥，或者在大白天兩人同時躺臥，都只犯屏處與女人同坐戒；如今是比丘躺臥而女人站立，所以只犯吉羅罪。若是兩人同坐就犯波逸提罪，正如注文所標示的，就是指後面的那條戒。在引用勸戒經文中，《十誦律》，首先指出制戒的緊迫嚴厲。阿羅漢等聖人，雖然絕不可能故意犯戒；但是恐顯過重，極誡凡夫，故同一制。從「如」字以下，以譬喻顯露女人的情執欲望，用意在於令人徹底遠離。這部律所說的就是阿那律尊者的犯罪緣起。從「餘」以下，是正面的嚴厲責備。

【277-0008】資持記/09a_中三上#47
【原文】拒抗謂特違聖制。引文中，多見二論，初明室相。有二，即都堂及共戶也。注釋共戶。部即是州。舊云：彼間作屋，上不起楝，平以土覆，中間開溝洩水；或十間五間不隔，同一門也。次釋覆壁。壁即是障。並舉極小，已上可知。若下，示室量。文出極廣，已下可準。所對下，次簡女境。
