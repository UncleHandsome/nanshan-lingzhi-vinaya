# 校閱材料　第468檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【468-0001】資持記/03b_上二#36
【原文】初二同鈔，三異見互結，四邪正互結，五是中邊，六即合今四五兩種。別證中。然與論文小異，今具引之，彼前問云：二眾結界，得互相叉結否？答：得叉〔謂不共行法故。〕，得共結〔謂受戒出罪，僧尼同法，鈔變其語，故云不得相叉。〕，後問云大僧得與尼通結界否？答得。
【譯文】前兩種與《行事鈔》相同，第三種是不同見解者互相結界，第四種是邪正見解者互相結界，第五種是中國與邊地互結，第六種則是將此處的第四、第五兩種情況合併為一。個別引證中：然而此處與論典文字有些許不同，如今完整引述：論典前面提問說：僧、尼二眾結界，可以交錯互相結界嗎？回答說：可以交錯〔是指二眾不共行法事〕，也可以一同結界〔是指受戒與出罪等法事，僧尼依照同一法度作法，行事鈔稍改其語句，所以說不可互相交錯〕。後面又提問說：大僧可以與比丘尼一同結界嗎？回答說可以。

【468-0002】資持記/03b_上二#37
【原文】今鈔所引，上二句即後問答，下一句即是前答。疏云不相叉者，恐出僧外，非成同法故。7 釋僧網篇(上二)釋僧網篇僧宗事多如網，此篇五門如綱；用此五者，如提其綱，則餘網目無有不正；從喻為題，以彰正要。住持攝眾，舍此何為？仰夫聖教昭彰，遵之甚易；但以人非清正，舉之或難；
【譯文】如今《行事鈔》所引用的，上兩句就是後面的提問與回答，下一句就是前面的回答。疏文所說的「不相交錯」，是擔心如果超出僧團之外，就不能成立同法界的緣故。7 釋僧網篇（上之二）解釋〈僧網篇〉：僧團教宗的事務繁多就如同漁網，本篇所設立的五門就如同網的總繩大綱；運用這五門，就如同提起了漁網的大綱，那麼其餘的網目就沒有不端正妥善的；從譬喻中立出篇名，用以彰顯端正的重要綱領。住持佛法並攝受僧眾，捨棄了這個還能靠什麼呢？我們景仰佛陀的聖教昭彰分明，若能奉行其實非常容易；只是因為主事者多非清正之人，若要真正推行或許會遭遇困難；

【468-0003】資持記/03b_上二#38
【原文】有教無施，可用長歎。敘意中，初文四段；前四句明凡為眾主，必遵於教。一方者，通語遠近傳弘之處。立法通者，舉事依教，餘方共遵；曲任私情，不流於外故也。上二句明立制軌物，下二句明臨事處斷。令下四句，二明近益。遠域異邦，語重事一；
【譯文】聖教空存卻無處施展，真令人不禁發出長嘆！序述大意之中，第一段文字分為四個小節；前四句說明凡是作為僧團的首領首座，必定要尊崇依循佛教。所謂「一方」，是通指無論遠近弘傳佛法的地方。所謂「立法通達」，是指推行事務全依聖教，其他各方都能共同遵行；如果任意屈順個人私情，法度就無法流傳於外。上兩句說明訂立規制以作為大眾的模範軌則，下兩句說明臨事時能夠做出公正決斷。從「令」字以下四句，第二小節說明近處的利益。遠方邊鄙之域與異國邦域，話雖重複但事實是一致的；

【468-0004】資持記/03b_上二#39
【原文】或可遠域近指郡縣，異邦遠指他國，如祖師聲飛五竺之例。上二句明外化景慕，下二句明內化日益。翹謂舉踵而望。神即是心，業即是行；無相觸撓，心神故安；境勝緣靜，行業乃進。若下，三明眾必從化。上二句明事皆可舉，下二句明人無敢違。豈下，四示遠益。上二句躡前近益，發起下文，故云豈止也。
【譯文】或者可以說「遠域」近指同國的郡縣，「異邦」遠指外邦他國，就像東土祖師的名聲遠播五印度的例子。上兩句說明外部受到教化而產生崇敬仰慕，下兩句說明內部受化後修行日益增進。「翹」是指抬起腳後跟眺望的意思。「神」指的就是內心，「業」指的就是修持身行；內心沒有受到觸惱動搖，心神自然安定；外境殊勝、外緣清靜，所修行的道業才能精進。從「若」字以下，第三小節說明大眾必然會順從化導；上兩句說明各項法事都能順利舉行，下兩句說明僧眾無人膽敢違逆。從「豈」字以下，第四小節揭示深遠的利益；上兩句承接前面的近利，發起下文的論述，所以說「豈止」。

【468-0005】資持記/03b_上二#40
【原文】肅，靜也。下二句正示遠益。道與慧並佛正法；道能生長，故喻如樹；慧能破暗，故喻如日。扶疎，豐茂之貌。方，猶將也。彰損中，反前四義；初四句反前初義。出恒情者，明自任也。言無據者，明非教也。科罰下，明行事俗惡，如下第二門中所列。能下二句，反上餘三。
【譯文】「肅」就是肅靜安定的意思。下兩句正式揭示深遠的利益。「道」與「慧」都是佛陀的正法；道能夠生長善法，所以比喻為大樹；慧能夠破除黑暗，所以比喻為日光。「扶疎」是茂盛豐美的樣子。「方」如同將要的意思。在揭示損害的段落中，正與前面的四種義理相反：前四句與前文的第一種義理相反。「超出常情」說明全憑個人私意專斷；說「毫無依據」，說明這並非出自聖教。「科處罰責」以下，說明僧團行事充滿世俗惡習，如同下文第二門中所羅列的種種亂象。從「能」字以下兩句，正與前面的其餘三項義理相反；

【468-0006】資持記/03b_上二#41
【原文】能施非者，必兼人法，人即眾主，法即非制。諠亂之言，總含三過：一人不從化，二無近益，三無遠益。故下引證。滅法過重，荷法功深；學者知此，當如之何！不值佛世，是當來餘報。生地獄即是生報；如箭射者，言其疾也。引《三千經》，明僧必依法；既闕良導，是為愚聚。故下，準文示意。
【譯文】能施加錯誤法度者，必定同時牽涉到「人」與「法」，「人」是指僧團首領，「法」是指非法的私立規制。所謂「喧囂紛亂」，總體包含了三種過失：一是眾人不服從教化，二是沒有眼前的利益，三是沒有深遠的利益。因此下文引經為證。破滅正法的罪過極其沉重，荷負正法的功德至為深厚；求學者明白這一點，心中應當作何感想！不能值遇佛陀出世，這是來世的餘報；直接墮入地獄則是命終後的生報（來世受報）；說「如同利箭射出」，形容墮落之迅疾無比。引用《三千威儀經》，說明僧團必須依循法度；既然缺乏良好的引導者，便只是一群愚癡聚集的烏合之眾。因此下文依據經文顯示其深意。

【468-0007】資持記/03b_上二#42
【原文】篇意中，初明去非；此中刪補，不同章疏廣解之繁；但是世人妄行非制，名為繁惡；隱其正制，名為遺漏。使下，顯是。言制者，即下五門所立之法；並稽於教，故曰相應。義謂事之用與，皆適於時，故云並合；此用律中如來制戒知時義合之語。故下，引證。言漸漸者，翻非為是，不可頓革。
【譯文】本篇意旨中，首先說明去除錯誤；此處的刪除與增補，不同於各家章疏長篇大論的繁雜；而是針對世間人妄自施行非法的私自規制，稱之為「繁惡」；同時隱沒了佛陀的正統規制，稱之為「遺漏」。從「使」字以下顯發正確之法。所謂「規制」，就是下文五門所確立的法則；全都考證依據於聖教，所以稱為「相應」。「義」是指事務的施行與廢止都能切合時宜，所以說「並合」；這引用了律典中如來制立戒律時「通曉時宜、契合義理」的原話。因此下文引經為證。所謂「漸漸」，是指翻轉錯誤回歸正確，並非一朝一夕能頓然變革。

【468-0008】資持記/03b_上二#43
【原文】若下，指略。病患即非法之過；能使法滅，故言損減。即下五門皆出非相是也。化教，標中。通道俗者，略示化義；顯下制教唯局道也。下引三經；初引《大集》，通道俗治；次《十輪》中，唯聽道治，不許俗治；後引《涅槃》，且明道治。下更引文亦通二眾，決通同異，並在下明。
【譯文】從「若」字以下指示略而不述之處。「病患」指的就是非法的過患；因為會導致正法滅亡，所以稱為「損減」，下文五門全部揭露非法的體相就是這個意思。化教法門的標題中，通指道俗二眾，略微展示化導之義；藉以突顯下文的制教純粹侷限於出家僧道。下文引用三部經典：首先引用《大集經》，通貫出家與在俗二眾共同懲治；其次在《十輪經》中，純粹只聽任僧道自治，不允許在俗世俗插手懲治；最後引用《涅槃經》，暫且說明僧道自律懲治。下文還將引用其他經文，同樣兼通二眾，如何通達融會其間的同異之處，都將在下文清楚說明。

【原文】《大集》中，初明國王縱彼造惡。則下，顯過。斷三寶者，翳障正法也。奪眾生眼者，損他正見也。戒施滅失者，損自功德也。言無量世者，舉遠多以況近少，則滅失可知；修戒施惠，略舉六度初二也。廣下，指文。見二十八，分卷之異。彼云：寧護如法比丘一人，不護無量諸惡比丘；
