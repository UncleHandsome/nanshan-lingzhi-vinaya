# 校閱材料　第383檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【383-0001】資持記/01d_上一上#26
【原文】一不明了，如十五種略說戒，及東方有山稱山之類。二不了足，如四人法不除懺捨等。下文一一別標，用此二意尋之可見。二廢前者。如歌聲說戒，鈔云此是《五分》廢教。〔如試外道、魚肉正食，雖同廢教，至下六師方可言之。此中且據諸律，古記一混，學者須知。
【譯文】第一種是指文義記載得不夠明晰詳盡，例如十五種簡略說戒的方式，以及東方有大山就隨山勢稱名結界的這類文句。第二種是指條文內容交代得不夠圓滿具足，例如四人僧團羯磨中不包含出罪懺悔捨物等作法。下文中逐一分別列出標示，運用這兩種思路去探尋就能明瞭見到。第二種屬於「廢止前法」的情況。例如以吟詠歌唱之聲誦說戒本，《行事鈔》指出這是《五分律》中已被廢除的教法。〔例如考核試驗外道、准許以魚肉為日常正食，雖然同樣屬於廢除的教法，但要到下文論述六位律師見解時才能辨析討論。這裡暫且僅依據各部廣律來談，古來的筆記將兩者混為一談，修學者必須清楚明辨。〕

【383-0002】資持記/01d_上一上#27
【原文】三有義無文者。如顛狂人前捨戒不成，是有不足之義，故引《十誦》等證之。〔如定由旬，準律十四說戒，十三先往，準強百里，遂用《智論》下品為定。又十三難不問壞比丘，準尼受反問，引《善生》明文。此皆屬後六師中。〕四無文有事。
【譯文】第三種屬於「法理具足而缺乏條文」的情況。例如在瘋癲狂亂之人面前宣告捨戒不能成就，本宗雖無明文，但具有此人不具備受捨資格（不足數）的義理，所以引用《十誦律》等文獻來作證明。〔例如判定由旬的距離，依據律典十四日說戒，十三日就應當先行前往，依據腳力估計約有一百里，於是採用《大智度論》下品由旬的標準來判定。又如十三種障難中不盤問毀壞比丘僧團的人，比照比丘尼受戒時反向盤問的準則，引用《優婆塞戒經》的明文。這些都屬於後面六位律師的範疇。〕第四種屬於「缺乏明文而實有其事」的情況。

【383-0003】資持記/01d_上一上#28
【原文】如云三衣應受持，及非時殘宿不受皆明三藥加法，而無受文。或云結界集僧，無自然六相文等。如下，結示。取用法，相關中，初文為二，初正明取舍。緩急重輕，四義條別。初如受衣文《僧祇》通夜，《多論》無衣鉢得戒等，並緩別也。二如《僧祇》轉欲即失，捨財入僧永棄等，名急別也。
【譯文】例如律中說三衣應當受持，以及非時、殘宿、不受等文句中都指明了三種藥的加法受持儀軌，卻缺乏具體的受持文句。或者說結界時應當聚集僧眾，卻缺少自然界六種標相的文句等。如同下文所述，在此作出總結開示。關於取用教法、互相牽涉的文句中，起初的文段分為兩部分，第一是正式說明取捨之法。寬鬆、緊嚴、加重、減輕，這四種義理各自列有分明的條規。第一種如受持衣物的文句，《僧祇律》通融整夜，《多論》認為沒有衣缽也能得戒等，都屬於寬鬆放寬的差別。第二種如《僧祇律》受託之欲法若再轉託他人則該欲法立即失效、捨棄財物歸入僧團就永遠捨除等，稱為緊嚴嚴苛的差別。

【383-0004】資持記/01d_上一上#29
【原文】三如前所引境想不同，即重別也。四初篇無重犯等，謂輕別也。是非一句，通收上四互望為言。又引事釋者，〈足數〉中古師以破戒和尚在十人外；今斥云不得輒用他部；又受日中云：不得秉《四分》羯磨，用《僧祇》事訖等。餘尋諸部篇。準論不取者，即同意用也。故下，二引證。
【譯文】第三種如前面所引述的境想判斷不同，就是屬於加重刑責的差別。第四種如初篇重罪不重複犯戒等，是指減輕處分的差別。「是非」這一句話，普遍涵蓋了上述四種情況互為對照來立論。又引用事相來作解釋，在〈足數篇〉中古代律師認為破戒的和尚應算在十位傳戒師之外；現在斥責說不得隨意套用其他部派；又在受日法的文句中說：不得在主持《四分律》的羯磨時，卻採用《僧祇律》的規定來了結僧事等。其餘內容請查尋〈諸部篇〉。依照論典決定不予取用，就是等同於「自意」的度量運用。從「所以」往下，第二部分是引述經文來作證明。

【383-0005】資持記/01d_上一上#30
【原文】言四說者，本律增四中云：佛告諸比丘，有四種廣說，一若比丘作是語：長老！我於某村某城親從佛聞，受持不忘，此是法、是毘尼、是佛所教。若聞彼說，不應嫌疑，亦不應呵。應審定文句已，尋究法律；
【譯文】所謂「四種廣說」，在《四分律》的增四篇法中說：佛陀告訴各位比丘，有四種廣泛的解說法則，第一種如果有比丘這樣說：各位長老！我在某個村莊、某座城中親自聽佛陀宣說，受持而不忘失，這是正法、是毘尼律法、是佛陀親自的教導。如果聽到那樣的說法，不應當心生懷疑嫌棄，也不應當立即予以呵責。應當在詳細審定文句之後，深入探究法律本意；

【383-0006】資持記/01d_上一上#31
【原文】若相違者，應語彼言：汝所說者非佛所說、或是長老不審佛語、不須復誦、亦莫教餘人，今應棄捨。若與法相應者，應語彼言：是佛所說、應善誦習、教諸比丘等。〔此名一廣說也。〕第二從僧中上座前聞。第三從知法眾多比丘所聞。第四從知法一比丘所聞。
【譯文】如果相互違背，就應當對他說：你所說的不是佛陀所說的教法、或者長老未能審查明辨佛語、不需要再繼續誦讀、也不要拿去教導別人，現在應當徹底捨棄。如果與正法完全相應，就應當對他說：這確實是佛陀所說的真理、應當妥善誦讀研習、並用來教導各位比丘等。〔這稱為第一種廣泛解說。〕第二種是從僧團中的長老上座面前親耳聽聞。第三種是從通達正法的眾多比丘那裡聽聞。第四種是從通達正法的一位比丘那裡聽聞。

【383-0007】資持記/01d_上一上#32
【原文】〔並如上檢校，文同不引。〕《十誦》墨印者，即是《四分》四說，故云亦同，但名異耳。《四分》約能說人，《十誦》據能證教。彼云：若言我從佛聞，乃至一比丘聞，未應歎毀；應向三藏聖教印定是也。引此二文者，由先世諸師隨情引用；今約部類檢勘可否，即同意用。若作此釋，方見所引四說墨印，頗符論意。
【譯文】〔全都要如同上面那樣考核查驗，經文大致相同就不再贅引。〕《十誦律》中所說的「墨印」，其實就是《四分律》所說的「四說」，所以說實質相同，只是名稱不同罷了。《四分律》偏重於以能說法的人來論定，《十誦律》偏重於以能印證的教法來論定。該律說：如果有人說我是從佛陀那裡聽聞，甚至說從一位比丘那裡聽聞，先不要給予讚美或毀謗；應當拿去對照三藏聖教加以印可印定就是這個意思。引述這兩段經文的原因，是由於前代各位律師隨順各自的心意任意引用；現在依據部派類別來查勘核對是否合宜，這也就是等同於運用心意來度量。如果作出這樣的解釋，才能看出所引用的「四說」與「墨印」，相當契合論典的深意。

【383-0008】資持記/01d_上一上#33
【原文】次科，初句躡前。次二句明合教。心謂行心，境即前事。心不昧教，事非暗託，故云相照。規猷謂法則，即前四法四說四印也。下二句明合理。相關方引，既無橫評之繁；條別不取，仍無闕事之略。前文所謂圖度取中，至此方彰，故非晦沒。晦，暗也；沒，隱也。
【譯文】下一個科判，第一句承接前文。隨後兩句說明與教法完全契合。「心」是指行持的心念，「境」就是指當前的事相。行心不違背昧失聖教，事相非盲目暗中依憑，所以說「彼此相互照應」。「規猷」是指法規準繩，就是指前面所說的四種法則、四種廣說、四種印證。下面兩句說明契合正理。唯有彼此相互牽涉時才加以引用，既不會有橫加妄加評論的繁雜；在界限條規分明處絕不妄取，依然不會產生遺漏僧事的缺略。前面文句所說的「籌劃度量而取中道」，到了這裡才完全彰顯出來，所以說並非晦澀隱沒。「晦」是晦暗；「沒」是沉隱。

【原文】所謂如來說法，常依二諦是也。斯文之言，通含一化，所以下文別指律藏。問：律文詮事，應非顯理；經論詮理，應非隨事？答：統明佛教，託緣而興，無非對事，皆為顯理；但藥病相對，不無親疎，故分三學對治有異耳。別明中，初科，初二句敘教本具周。斯律藏者，且據所弘《四分》一部。
【譯文】這就是所謂「如來宣說正法，時常依循二諦並行」的深意。這段文字的義理，普遍涵蓋了一代佛陀的聖化，所以下文中才特別單獨指出律藏。問：律藏的條文只詮述具體事相，理應不是用來顯發真理；經藏與論藏專門詮顯至理，理應不是隨順具體事相而設？答：統攬明辨整個佛教體系，都是依託因緣而興起，無一不是面對具體事相，無一不是為了顯發究竟真理；只不過對治眾生煩惱時如同對症下藥，其間不免有親疏切合之分，所以劃分出戒定慧三學，在對治修持上才互有差異罷了。在分別說明的文段中，第一小節，前兩句敘述教法原本具備圓滿周全。這裡所說的「這部律藏」，暫且是依據本方所弘揚的《四分律》一部而言。
