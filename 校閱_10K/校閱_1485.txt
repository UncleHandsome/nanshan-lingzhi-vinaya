# 校閱材料　第1485檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1485-0001】04_比丘尼鈔/06a_卷下之下#34
【原文】第五忘捨衣財者謂捨衣已或還衣竟而未說淨忽見本捨之財即生己想還成相染一切不成更將總捨若衣已說淨後見本忘物前捨並成淨法不失後忘元物或別捨若衣已捨未還主者見本忘物即須別捨共本捨衣總還其主令同說淨既知捨財不易未捨物前應總作念云現集之財今並將捨已外忘財不集者決定捨與三寶同學知識之意如是念已後見本忘物無問早脫前捨並成若捨已還未得說淨見本忘物方生捨念者不成由染意前生捨心後起故此謂長財捨竟還見長財等故有相染若見本忘物是販賣財者無相染義若捨墮還竟見本長財過十日者此入相染之例便作長犯捨之以販賣財罪已捨懺竟同是長財也。
【譯文】第五項是遺忘所捨之衣物財物：是指捨衣之後，或者衣物已交還而尚未作說淨，忽然看見原本遺忘的捨物，立刻生起這是自己所有的念頭，便會再度產生執取與牽纏，導致之前的捨法全部失效，必須重新拿來一同全部捨棄。如果衣物已經說淨，事後看見原本遺忘的物品，之前的捨法依然成立，淨法不失，之後發現遺忘的原物再另行捨棄即可。如果衣服已經捨出但尚未還給物主，見到原本遺忘的物品，就必須單獨捨棄，並與原本捨出的衣服一併還給原主，讓它們一同作說淨法。既然知道捨財不容易，在尚未捨棄物品之前，應當整體發起意念說：「現在聚集在此的財物，如今全數準備捨棄；除此以外遺忘未聚集的財物，我也決意捨給三寶、同學道友或相識同修。」發起這種心念之後，後來再看見原本遺忘之物，無論發現得早或晚，先前的捨財法都算成功。如果捨棄後還給物主、尚未說淨之時，見到原本遺忘之物才生起捨念者，不能算成就；因為貪染之心先動，捨心後起的緣故。這是指長財捨除之後又看見長財等物品，所以會互相影響牽纏。如果看見原本遺忘之物屬於販賣所得之財，則沒有牽纏失效的疑慮。如果是犯捨墮的物品交還之後，看見原本的長財超過十天的，這屬於相牽纏的範疇，應依照犯長物之例捨棄；因為販賣所得之財罪過已捨懺完畢，同樣都歸為長物了。

【1485-0002】04_比丘尼鈔/06a_卷下之下#35
【原文】第六捨寶者當取所畜錢寶金銀等捨與知法白衣淨人云此是我所不應畜汝當知之捨已其罪對尼懺懺主未捨罪前應問所畜錢寶並捨與白衣淨人未答已捨若未捨者教如法捨已然後罪同前懺自餘穀米等並同前說淨篇述。
【譯文】第六項是捨棄金銀珍寶：應當拿取所蓄積的金銀錢寶等，捨給懂戒法的在家淨人，並對他說：「這是依法我不應當蓄積的物品，你應當知曉並收下。」捨棄之後，其違戒的罪過則對比丘尼懺悔。懺悔主在受懺之前，應當詢問她蓄積的錢寶是否已經全數捨給在家淨人？回答說「已經捨棄」；如果尚未捨棄，則教導她如法捨棄之後，再依前述方法懺悔其罪。至於其餘米糧等物，全如前面〈說淨篇〉中所敘述。

【1485-0003】04_比丘尼鈔/06a_卷下之下#36
【原文】第七雜法者此別對首法若能所滿四人已下但使無僧不問作法自然界中並成對首若能所滿五人已上作法界內及戒場上不合對首應作眾法捨之縱自然界及白衣舍亦不合對首捨以正懺悔時尼唯是所懺不落僧攝餘尼展轉懺竟還墮僧數又餘懺尼雖未捨懺以體是大尼豈非僧攝既成僧故何得對首捨懺若知不易眾法復難欲得受多尼捨懺之時令諸懺悔尼總向大界內坐懺主尼一一喚來入自然界內如是展轉作法乃受無量皆成如法不爾之時徒自費功財還不淨虗為獨善數見僧尼共行此法別疏記之。
【譯文】第七項是雜項規定：此處特別說明對首懺法。如果能懺與受懺者加起來在四人以下，只要沒有比丘僧在場，無論是在結界作法之處或自然界中，都能成就對首懺法；如果人數達到五人以上，在作法界內以及戒場上，就不合乎對首懺的規定，應當作僧眾法來捨罪。縱然是在自然界以及在家人房屋中，也不合乎對首捨法；因為正懺悔的時候，受懺比丘尼只是受懺對象而不落入羯磨僧數，其餘比丘尼輾轉懺悔完畢又算入僧數之中。再者，其餘求懺比丘尼雖然尚未捨罪懺悔，但本質上是具足戒尼，豈能不算在僧數之內？既然已經構成僧團，如何能進行對首捨懺呢？如果深知這不容易，而僧眾大眾法又很繁複難行，想要接受多位比丘尼捨懺的時候，可讓各位要懺悔的比丘尼全都坐在大界內，懺悔主比丘尼將她們一一叫出進入自然界內，如此輾轉作法，即便接受無量之人也全都合乎戒法；不這樣做的話，徒然白費工夫，財物依舊不合淨法，成了虛妄的自求清淨。我屢次見到僧尼共同誤行此法，因此特別記錄在此予以辨正。

【1485-0004】04_比丘尼鈔/06a_卷下之下#37
【原文】第二單懺百七十八單提法此中分二一若有覆藏突吉羅亦有輕重兩位謂輕者責心重者對人此二法下懺突吉羅中具說二若犯提吉不覆藏者則不須此今且懺根本捨罪法具修威儀請清淨比丘尼懺悔已傍尼答云好受尼語懺悔尼云某甲身器豈得清淨非行者良緣大姉既犯佛戒還須向佛懺悔譬如因地而倒還須託地而起如是生殷重心請十方諸佛同時加被為我證明兼說利養難消出家難得種種方便隨時誨責大同捨墮中說廣誡勑已告言罪相如是何得隱藏若欲懺悔具須陳說除疑不識後當決了見論云若生時惡罵彼人彼已入涅槃能罵者求懺悔當於涅槃處作懺悔懺悔已天道門不閉如是語已次教捨罪云。
【譯文】第二項是單獨懺悔一百七十八條波逸提罪（單提法），這裡分為兩節：一是如果有隱瞞覆藏的突吉羅罪，也分為輕重兩種等級，輕的責心自懺，重的對人陳懺，這兩種方法在下文懺突吉羅中會詳細說明；二是如果犯了單提與突吉羅而沒有隱瞞覆藏，就不需要那些手續。現在且說明懺除根本捨除罪名的方法：整肅威儀，迎請清淨比丘尼為受懺主完畢，身旁比丘尼答應說「好」，受懺比丘尼對發懺比丘尼說：「某甲的器量豈能永遠清淨無染，這不是修行者的善妙因緣。大姊既然毀犯了佛陀的戒律，終究必須向佛陀悔過。就如同因為踩著大地而跌倒，依舊必須依靠大地才能站起來。應當像這樣發起極其殷重的心，祈請十方諸佛同時庇佑加持，為我作證，同時說明信施供養極難消受、出家因緣極難遭遇，以種種善巧方便隨機教誡責備，大多如同捨墮篇中所說。」廣泛告誡完畢後，告訴她說：「罪相就是這樣，怎能隱瞞覆藏？如果要懺悔，必須具體完整陳述，除去疑惑不解的部分，日後應當徹底明白決斷。」又見到論典記載：如果在世時惡口咒罵他人，那人後來入了涅槃，惡罵者若想求懺悔，應當到那人入涅槃之處進行懺悔；懺悔之後，通往善趣天道的大門就不會被關閉。如此開導之後，接著教導捨罪說：
