# 校閱材料　第245檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【245-0004】03_業疏/04b_卷一之四#64

【245-0006】03_業疏/04b_卷一之四#66
【原文】有人云：四羯磨者，眾法皆通；僧殘諸治，局二篇悔
【譯文】有人說：受四種羯磨罰治的人，所有的僧眾羯磨法都可以通融充數；而受僧殘諸項懲治的人，只是局限於第二篇罪的懺悔羯磨中不足數。

【245-0007】03_業疏/04b_卷一之四#67
【原文】引古中初科。四羯磨人，但不訶法，生善滅惡一切眾法竝謂足數，故云皆通；僧殘四人，但不足懺殘羯磨，餘法皆通，故云局二篇悔。此師所判，乃據律文，《事鈔》科為少分不足，猶循古解，不了義也
【譯文】在引述古解的第一科中。受四羯磨治罰的人，只是不能訶止法事，而在生善與滅惡的一切眾法中都認為可以足數，所以說「皆通」；受僧殘懲治的四種人，只是不能充任懺悔僧殘羯磨的足數，其餘僧法則都可以通融充數，所以說「局限於二篇之悔」。這位法師所作的判定，是依據律文表面，《事鈔》將其科判為少分不足，仍然是因循古德的解釋，並非了義之說。

【245-0008】03_業疏/04b_卷一之四#68
【原文】若作此解，焉有被訶責者得更治人？犯二篇者開餘懺主？審約情事，律文不了，以義糺定，應分二途：若同犯同治，理無預加，律言足數，謂差、結等；若自有犯，必無清過，故有罪人不合解罪，乍可應餘非罪羯磨。若作斯通，始終無妨。故此四人通前數等，三十二也
【譯文】如果作這樣的解釋，哪有自身正被訶責治罰的人反而得以去懲治他人？犯了第二篇罪的人又怎能開許去擔任他人罪愆的懺主？仔細審究情理與事相，律文屬於未了之義；以法理推尋判定，應當分為兩種途徑：如果是同犯同治（自己有同樣罪過又去治罰他人），理應不能參與加罪；律文所說的足數，是指差遣職事、結界等生善法事。如果是自己本身有犯，必定沒有能力去澄清他人的過失，所以有罪之人不合為人解除罪名，至多只能充任其餘非治罪的羯磨。如果作這樣的圓通解釋，前後始終都無妨礙。所以這四種人連通前面的人數，共有三十二人。

【245-0009】03_業疏/04b_卷一之四#69
【原文】次科初躡破。生善可爾，治罰懺罪竝滅惡事，身既有過，如何加彼？「審下」義決。初總標。糺，猶正也。「若下」別列。同犯同治，如犯殘者不足懺殘，被訶責者不足訶責，餘準說之。差、結生善，可通律意；若自有犯，即別犯別治，如犯殘不足捨墮，訶責不足擯出等。犯者不得為人解罪，是律所制；非罪羯磨，亦即生善。若作下結示，用此二途決文不了，於義盡善，故無所妨
【譯文】在下一科中，首先承接上文加以破斥。生善法事尚可如此，而治罰與懺罪都是滅惡之事，自身既然有過，如何能加罰於他人？自「審約」以下，以義理決斷。首先總括標示。「糺」相當於正的意思。自「若同犯」以下分別列舉。同犯同治，例如犯僧殘的人不能充當懺悔僧殘的僧數，被訶責的人不能充當訶責他人的僧數，其餘依此類推。差遣、結界等生善之法，可以貫通律文的深意；若是自己有犯，即指犯相不同而治罰不同，例如犯僧殘者不能充當捨墮懺罪的僧數，受訶責者不能充當擯出羯磨的僧數等。有犯罪過之人不得為他人解除罪過，這是律典所規定的；非罪羯磨，也就是指生善法事。自「若作斯通」以下總結指示，採用這兩種途徑來決斷律文中未盡之義，在義理上最為完善，所以毫無妨礙。

【245-0016】03_業疏/04b_卷一之四#76
【原文】又《伽論》云：行別住人作擯成就，除受戒法，餘盡得作。引約《四分》，明言不足者，但據僧殘四位；若同上通，非滅罪法，可竝作耳
【譯文】又《摩得勒伽論》（《伽論》）說：行別住的人參與作擯出羯磨能夠成就，除了受具足戒法之外，其餘一切法事都可以參與作法。對照引述《四分律》，明確說不足數者，只是依據僧殘四種受治罰之位；如果依同於上面的融通之義，只要不是滅罪之法，都可以共同參與作法。

【245-0017】03_業疏/04b_卷一之四#77
【原文】三中初引論文。彼除受戒，準前義判，反得成足。「引下」次對本律。如上所明，若下準前義決，但足生善，自餘治懺一切不通
【譯文】在第三段中，首先引述論文。該論雖除去了受戒法，但按照前面的義理判定，受戒反而得以充當足數。自「引約」以下，接著對照本律。如同上面所闡明的那樣；自「若同上通」以下按照前面的義理決斷，只是可以充當生善法事的足數，至於其餘懲治、懺悔等法事則一概不通。

【245-0018】03_業疏/04b_卷一之四#78
【原文】四睡眠人、五亂語、六憒閙、七入定。故彼律云：若前比丘睡眠、入定等，或眾僧睡眠、入定等，聞白已方睡定者成，不聞者不成也。八瘂、九聾、十具二患人
【譯文】第四、睡眠之人，第五、語無倫次之人，第六、心神憒亂喧鬧之人，第七、入定之人。所以《十誦律》說：如果上首比丘睡眠、入定等，或者大眾僧睡眠、入定等，在聽聞白讀之後才睡眠、入定者羯磨得成，未曾聽聞者羯磨不成。第八、啞巴，第九、聾子，第十、兼具聾啞二患之人。

【原文】初中「佛法事」下，辯緣開也。大途橫絕，有犯戒事，無如法緣而與欲者，以事非故，不成是別。僧事清淨，理不容濫；無心至尚，豈是欣欲？故有說者，更招妄語。當律開緣，如文有五。下文衣緣者，乃非佛制，比丘受行，理亦通準。《僧祇》云：「說戒不來者，蘭若、為衣鉢、王賊禁閉、守房等緣，是開欲也
【譯文】在第一部分「佛法事」以下，是辨明因緣開許的道理。大體而言橫生阻隔、存有違犯戒律之事，如果沒有合法的因緣而給與其欲，因為事情本身不如法，所以與欲不能成立，而構成別眾。僧團法事清淨純潔，道理上不容許濫充；如果心中毫無崇敬尚仰之念，哪裡談得上是欣樂與欲呢？所以如果有代言者宣說，更會招致妄語之罪。本律所開許的因緣，如文中所述共有五種。下文所提到的因縫衣之緣，雖然不是佛陀最初的通制，但比丘依此受持奉行，在義理上也可以比照準用。《摩訶僧祇律》說：「說戒時不前來者，因住阿蘭若、縫製衣鉢、被官王盜賊監禁拘閉、留守僧房等因緣，都是開許給與其欲的。」

【245-0094】03_業疏/05a_卷一之五#16
【原文】緣如非中，初敘立所以。大途，謂欲法大意；絕，即是斷。「不成是別」者，己欲非法，僧事別眾。「無心至尚」謂於僧法無崇尚之心，而濫委他緣，輙爾送欲，豈是欣慕希須耶？「說招妄語」者，以不欲言欲，違心故犯。《鈔》云：「令他傳此，對眾而說，一一人邊皆波逸提；所傳之人知而為告，結犯亦然。」「當」下引示緣相。《四分》六緣，下文即六群作衣，僧喚與欲，僧作法已，六群後悔，佛制犯提；僧既受行，故知如法。欲法出〈布薩犍度〉，作衣出戒本，計非下文，未詳何意。《僧祇》三緣，今通準用
【譯文】在因緣是否如法之中，首先敘述立論的原由。「大途」是指與欲之法的大綱要旨；「絕」就是斷阻。「不成是別」是指自己給予的欲不合法，使得僧團事務構成破壞和合的別眾。「無心至尚」是指對於僧團羯磨大法沒有崇敬尊尚之心，卻濫用其他藉口，動輒差人送欲，這哪裡是欣慕渴求之意呢？「說招妄語」是指本不想與欲卻口稱給欲，違背本心所以犯過。《事鈔》說：「指使他人傳達此語，面對大眾宣說，每對一人宣說都犯一波逸提罪；受託傳話的人明知故犯而代為宣告，結罪也是一樣。」「當」字以下引用律文顯示合法因緣的相貌。《四分律》列有六種因緣，下文即提到六群比丘正在縫衣，僧團召喚他們給與其欲，僧眾作完羯磨後，六群比丘又心生反悔，佛陀於是制定反悔者犯波逸提；僧眾既然可以接受並執行此法，由此可知作衣也是如法的開緣。與欲之法出自〈布薩犍度〉，作衣之事出自戒本，照理說並不屬於疏文此處的「下文」，疏主為何稱「下文」，其用意尚未詳明。《摩訶僧祇律》的三種因緣，現在也全面通融比照準用。

【245-0095】03_業疏/05a_卷一之五#17
【原文】二定開制中，以欲之所在，必緣僧務，自然薄弱，力所不勝。「唯除結界」者，自然開眾務，其唯結界。一解如上；又云：界須制限，自結開欲，終不識委，故須通集也
【譯文】在第二判定開許與制止之中，因為與欲這件事，必定是因為有其他僧務因緣在身，自然界地力薄弱，不能勝任僧事羯磨（故不開許傳欲）。「唯除結界」的意思是，在自然界中開許兼顧各項僧務，唯獨結界這件事不許與欲。一種解釋如上面所述；另一種解釋又說：結界必須劃定區域界限，如果結界時開許送欲而不親自到場，終究不能清楚知曉界相的詳細範圍，所以必須全體親自聚集。

【245-0096】03_業疏/05a_卷一之五#18
【原文】次定開制：注云「竝聽與欲」是開，「唯除結界」是制，文但敘制，餘開可知。初敘制意，由不勝僧事，故不許傳欲。「唯除」下次牒文釋，即顯律中不開所以。此有二釋：一解如上，即前所敘自然薄弱等；次解可會。準結界中有三解：初云結界眾同之本，理須通和，餘法眾同之末，竝依後起；下二同此
【譯文】其次判定開許與制止：注文說「皆聽許與欲」是開許，「唯除結界」是制止，律文只陳述了制止的部分，其餘開許的情況即可想而知。首先敘述制止的意旨，由於無法完全勝任僧事，所以不允許傳達其欲。「唯除」以下接著引述律文予以解釋，即顯示律中不准開許的原由。這裡有兩種解釋：第一種解釋如前所述，即前面所敘述的自然界地力薄弱等；第二種解釋可以相互會通。依照結界法中的說明，共有三種解釋：第一種說，結界是大眾同體和合的根本，理應全體親身和集，其餘的羯磨法則是大眾同體的枝末，都依據結界而後成立；其餘兩種解釋與此處相同。
