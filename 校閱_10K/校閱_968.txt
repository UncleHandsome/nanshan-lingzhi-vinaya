# 校閱材料　第968檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【968-0001】資持記/03a_上二#29
【原文】僧集於中，循繩唱相；兩處繩圍，故名二繩；中間一繩，左右兩邊，即為兩相。準下，正決。大牆準山，可分準繩。上云一肘，雖不顯破；然準論文，頗彰彼局；疏云相去一肘，無有正文；約同二繩，得分便罷是也。四問中。物有多別，須定內外。答中，初明圓物通內外，先明內者。
【譯文】僧眾聚集在其中間，沿著繩子唱告界相；兩處都有繩子圍繞，所以稱為「二繩」；中間牽引的一條繩子，其左邊與右邊就作為兩種界相。「準」字以下，進行正式裁決。高大的圍牆推準如山，可以劃分界線的推準如繩。上文說相隔一肘，雖然沒有明文駁斥；然而依據論典之文，頗能彰顯那種說法太過局促；《業疏》中說相隔一肘沒有正法明文，只要依照二繩之法，能夠區分內外就可以了，說的就是這個意思。在第四問中，物件有許多差別，必須敲定內界與外界。回答中，首先說明圓形物件通於內外，先說明算在界內的情況。

【968-0002】資持記/03a_上二#30
【原文】如傍地閬直穿諸柱，不勞循外。舊云生樹穿中，容生長故；見穿柱者，反乃嗤笑；且問中通問石木，木可云生，石寧有長？必有圓石，穿中得否；文中但云令界相正耳，請細詳之，勿事粗魯。或下，明循外。若下，次明尖斜。取外方者易解，文中不言。
【譯文】例如沿著長廊地面直接穿過柱子中央劃界，不需要繞到柱子外面。古人說活生生的樹木可以穿過中間，因為樹木還能生長的緣故；但看到穿過柱子的，反而出言譏笑；且問句中普遍詢問了石頭與木頭，木頭可以說是活的，石頭難道也會生長嗎？如果真有大塊圓石，穿過中間算不算得界呢？律文中只不過是要求讓界相平直端正罷了，請仔細詳察，切莫行事粗魯草率。在「或」字以下，說明繞行到物件外側。「若」字以下，其次說明尖斜之處。選取外側平直方正的很容易理解，所以文中沒有多說。

【968-0003】資持記/03a_上二#31
【原文】一分者，若角若楞，須分內外東西，的指分齊。餘下，指例。應下，誡審悉。非唯唱者，理須合界通知。不下，遮濫。今時行事，潛錄界相，遣他令誦，曾不案行。同住之僧，莫知其處。徒相勞擾，法定不成。下云結界如法者少，斯言不虛。五問中。標等三相，結界宗要；
【譯文】所謂「取一分」，是指遇到轉角或稜邊，必須分清內外與東西走向，確切指出邊界齊限。在「餘」字以下，指明依此類推。在「應」字以下，告誡審查務必詳實。不僅僅是唱界相的人，按理必須全界同住的僧眾全都知曉。「不」字以下，遮止雜亂虛妄。現今行事之人，私下抄錄界相，差遣他人去背誦，自己從未實地巡查。同住的僧眾完全不知道界相在何處，平白相互勞煩紛擾，所結之法必定不能成就。下文說結界合乎戒法的人極為稀少，這句話真是一點都不假。在第五問中，「標」等三種概念，是結界的根本要領；

【968-0004】資持記/03a_上二#32
【原文】一事有迷，眾緣徒設，故須明委。答中，先示三種。標即物者，即次科所引《四分》、《善見》等。相即標畔者，內外兩相，皆依其畔。體之表者，謂方圓曲直，即下界形也。疏云：標即唱者之所據，相即羯磨之所牒，體即作法之依地。斯文益顯。或下，示離合，初二句簡標體。標即體者，據外唱也。
【譯文】只要對其中一事有所迷惑，眾多因緣就全屬徒設，因此必須辨別清楚。回答中，首先明示這三種名相。「標」就是指實體物件，即下一科所引用的《四分律》、《善見律》等中的名物。「相」是指標記的邊緣邊界，內相與外相，都是依據其邊緣而立。「體之表」是指方形、圓形、曲折、筆直等幾何外觀，也就是下文所說的界線形狀。《業疏》說：標是唱告者所依據的實物，相是羯磨文中所列舉的界線，體則是作法所依托的整片土地。這段文字說得更加顯明。在「或」字以下，說明離與合，前兩句揀別標與體。標即是體，是依據唱告在外圍而言；

【968-0005】資持記/03a_上二#33
【原文】標異體者，約內唱也。次一句簡體相。一向不異。臨下，誡早辨。第六問。律無明斷，世有濫行，故此釋之。答中，初以義決。文出說戒，既制相接，驗不開重。彼云時諸比丘二界相接，佛言不應爾，當作標式；彼二界共相錯涉，佛言不應爾，應留中間。今鈔合之耳。若下，引例決。
【譯文】標異於體，是依據唱告在內側而言。下一句揀別體與相，兩者向來沒有差異。在「臨」字以下，告誡應當及早辨別清楚。第六問：律文中沒有明確斷定，世間多有浮濫行事的現象，因此在此加以解釋。回答中，首先以法理加以裁決。律文出自說戒部分，既然禁止兩個大界彼此相銜接，由此驗知絕不開許界線重疊。彼處說當時諸比丘兩界相接，佛說不應當這樣，應當樹立標記標式；又彼處兩界彼此交錯混雜，佛說不應當這樣，應當在中間留出空隙。如今《行事鈔》將這兩段文融會在一起罷了。「若」字以下，引用先例來裁決。

【968-0006】資持記/03a_上二#34
【原文】即〈藥法〉中開淨地文。彼云：諸比丘不知何處是淨地，白佛，佛言若疑先有淨地，解已然後結，如篇末備引。故下，通結二文。昔人有作《行事策》者，云凡欲結界，恐往世曾結，必須先解；後世相承，名解妨疑；不問空有水陸曾結不結，例皆先解；弊風罔世，三百餘年；
【譯文】即〈藥犍度〉中開許尋找淨地之文。彼處說：諸比丘不知何處是合法的淨地，稟白佛陀，佛說如果懷疑原先已有淨地，應先解界然後再結界，如本篇末尾詳細引述。在「故」字以下，總結上述兩段引文。從前有人撰寫《行事策》，說凡是想要結界，唯恐過去世曾經結過，必須先做解界；後世人相承襲，稱之為「解妨礙疑界」；不問此處是空處、聚落、水上、陸地，曾結界還是未曾結界，一律全都先做解界；這種弊風欺騙世人長達三百多年；

【968-0007】資持記/03a_上二#35
【原文】雖英敏間生，曾無一悟，況執迷鼓論于今尚然；有據此文，故須略釋；直引明據，餘廣如別。今言疑者，略有二種：一疑先結如非，二疑標相分齊。初中，如〈受戒篇〉云：羯磨所託，必依法界；若作不成，後法不就；故須深明界相，善達是非；訪問元結是誰，審知無濫，方可依準；
【譯文】雖然其間偶有英明敏銳之人降生，卻從未有人省悟這一點，何況那些頑固執迷、高談闊論的人至今依然如此；有人執持這段文字為依據，所以必須略加解釋；直接引出確鑿的依據，其餘詳細考證見於別卷。如今所說的「懷疑」，大略有兩種：一是懷疑原先所結之界是否如法，二是懷疑標相的四至界限。在第一種情況中，如〈受戒篇〉說：羯磨法所依托之處，必須是合法的界地；如果結界不能成就，後續的一切僧法便無法成立；因此必須深刻通達界相，明察是非得失；訪查探問最初結界的人是誰，審查確認毫無浮濫錯謬，才可以依循遵循；

【968-0008】資持記/03a_上二#36
【原文】不然，解已更結，《戒壇經》云：至於結界，持護要須，是非相顯；若疑若誤，捨已重加，豈非敬慎之至也。又下云：先結大界，後結戒場，不成後法，故須解之。又《五百問》：云：於中受戒，恐無所獲。又〈受戒〉中，引僧伽跋摩恐界不如法，駕船江中等。
【譯文】若非如此，就必須解界之後重新結界，《戒壇經》說：至於結界之事，護持戒法極為緊要，是非對錯必須分明；如果有所疑慮或有所錯謬，應當捨棄舊界重新加持結界，這難道不是恭敬慎重到了極點嗎！又下文說：若先結了大界，其後才結戒場，戒場便不能成就後續僧法，所以必須解開重結。又《五百問》說：在不如法的界中受戒，恐怕一無所獲。又〈受戒篇〉中，引用僧伽跋摩因唯恐界地不如法，駕船到江中等事蹟。

【968-0009】資持記/03a_上二#37
【原文】二疑標相者，下云結已即須牓示，令後主客俱委，無有濫疑；又云：作羯磨比丘死，餘人不知界處，佛令捨已更結；又下引治故伽藍，不失淨地，若疑應捨已更結，故知界在等。請考諸文，足為明據；豈是先不結處，強自生疑！且羯磨所加，緣如則法就；事須考實，豈得妄施；
【譯文】第二種懷疑標相者，下文說結界完成後就必須榜示公告，使後來的住寺僧與客僧都能詳細明瞭，沒有浮濫疑慮；又說：主持羯磨的比丘過世，其他人不知道界限處所，佛便命令捨解舊界之後重新結界；又下文引用修葺舊有伽藍，並不會失去淨地，如果心生疑慮應當捨解後重新結界，故知界在等。請考查各部引文，足以作為明證；哪裡是在原本不曾結界之處，勉強自己無端生疑！何況羯磨加持，因緣如法僧事才能成就；凡事必須核求真實，怎能盲目施設；
