# 校閱材料　第375檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【375-0001】02_戒疏/03a_卷一下之一#121
【原文】【疏】二、諸比丘集者，表法無乖，明人不別也。
【譯文】【疏文】第二段提到「諸位比丘聚集」，是表顯戒法毫無乖違，明示與會的大眾無所差別。

【375-0002】02_戒疏/03a_卷一下之一#122
【原文】【記】第二段，釋文中。「法」即指戒。謂法非偏被，人無獨說，即明同界須集之意。
【譯文】【記文】在第二段的釋文中。「法」就是指戒法。意思是戒法並非偏向某人，大眾無人能置身法外獨自去說，這就是說明同一個僧界之內必須全體集會的用意。

【375-0003】02_戒疏/03a_卷一下之一#123
【原文】【註】佛言：「同羯磨者集在一處，乃至應訶者不訶，是名如法。」
【譯文】【註文】佛說：「共同作羯磨的人聚集在一處，乃至於應當提出反對的人沒有反對，這就叫做合乎佛法。」

【375-0004】02_戒疏/03a_卷一下之一#124
【原文】【疏】注云「同羯磨者來」，名身集也；形礙法通，須陳欲法，名心集也；身雖赴座，容有「訶止」，默忍法圓，名口集也。以斯三業，共成一僧，故云「集一處」也。
【譯文】【疏文】注釋中所說「共同作羯磨的人前來」，稱為身業的聚集；身體受阻但法制仍須相通、必須陳述傳達與欲之法，稱為意業心念的聚集；身體雖然親自赴座，但仍保有依法提出「諫阻反對」的權力，大家靜默默許令法事圓滿成就，稱為口業的聚集。以這身口意三業的如法，共同成就一個僧團，所以稱為「聚集在一處」。

【375-0005】02_戒疏/03a_卷一下之一#125
【原文】【記】釋注，初科。注文「乃至」字，略其心集。《疏》中備約三業解之。「形礙」，身有緣故。「法通」，可傳欲故。「法圓」，羯磨成辨故。「一僧」，「僧」即眾故。
【譯文】【記文】在解釋注釋的第一小節中。注釋中「乃至於」這幾個字，簡略帶過了心念傳欲的內容。《疏》中則周全地依據身口意三業來作解釋。「身體受阻」，是指身體遇到急難因緣。「法制相通」，是指可以合法傳欲。「法事圓滿」，是指羯磨法得以如法成就。「一個僧團」，「僧」就是大眾合和之意。

【375-0006】02_戒疏/03a_卷一下之一#126
【原文】【疏】又解云：「『同羯磨』者，明說正戒，行淨者同。自餘過犯不足數者，不同羯磨，不須集也。言『應與欲』者，謂此行教，不可自輕。大急要緣，事不獲已，方開與欲；自餘輕小，則不須也。且如病緣，重者輿來，少者僧就，可以知也。言『應訶』者，謂四羯磨、諸雜治人，行法在身，無容秉法，身雖足數，口不陳非故也。若斯陶練，方得實人，可不然也！」
【譯文】【疏文】另一種解釋說：「所謂『共同作羯磨的人』，是說明宣說清淨正戒，唯有行持清淨的人才能共同參與。其餘有違犯過失、不夠資格計入法定人數的人，不能參與共同的羯磨，也不需要集會。所謂『應當傳達與欲』，是說明這項行持與教法絕不可輕慢隨意。必須遇到極重大的緊急事故，萬不得已之時，才開許傳達與欲；其餘輕微小事，則一概不許缺席請託。況且如疾病因緣，病重能移者用擔架抬來僧中，不能移動且人數少者則由僧眾親往其處作法，依此即可明白。所謂『應當反對提出訶止』，是指正受四種處罰羯磨、以及各類正在受治罪處分的人，因為身上帶有處分罰則，沒有資格秉持僧事法制，雖然在場能補足法定出席人數，口中卻不得陳述異議。必須經過這樣的審查甄別，才能得到真正合乎法度的與會僧人，難道不是這樣嗎！」

【375-0007】02_戒疏/03a_卷一下之一#127
【原文】【記】佗解中三節，並約揀眾。一、簡足數。「過犯」謂三舉二滅人，更兼尼等四眾，瘂、聾、睡、狂等人。二、簡欲緣。「大急」即三寶、疾病等。三、簡合訶。「四羯磨」：一、訶責，二、擯出，三、依止，四、遮不至白衣家。此四，《律》名「得滿不得訶」。「諸雜治」者，即收行覆藏等人。竝由奪其智能，不得訶法；必非此等，方名「應訶」。「若」下，總結。「陶練」，即是揀擇。「實人」，謂合教者。
【譯文】【記文】在另一種解釋的三個層次中，全部都是針對甄選篩除會眾而論。第一、簡別合格的法定人數。「違犯過失」是指被判處三種擯舉、二種滅擯的人，還包括比丘尼等其餘四眾，以及啞巴、聾子、熟睡、狂亂失心等人。第二、簡別准許請假傳欲的因緣。「極重大因緣」是指守護三寶物資、突發重病等。第三、簡別有資格提出反對發言的人。「四種羯磨處分」是指：一、訶責羯磨，二、擯出羯磨，三、依止羯磨，四、遮不至白衣家羯磨。這四種在《律》中被稱為「得滿法定人數，但無權發言反對」。「各類受處分者」是指包括正在行履隱覆藏罪懺悔等處分的人。這些人全都被剝奪了正常的僧權智能，不能依法反對法事；必定要排除這些人，才稱得上是合格的「應訶止反對之人」。「必須經過」以下是總結。「甄查甄別」就是嚴格簡別挑選。「合格合法人員」是指完全合乎教法律儀的僧眾。

【375-0008】02_戒疏/03a_卷一下之一#128
【原文】【註】「若眾大聲小，敷妙高座，立上而說。」
【譯文】【註文】「如果大眾人數眾多而聲音微弱，應當鋪設微妙的高座，站在上面宣說。」

【375-0009】02_戒疏/03a_卷一下之一#129
【原文】【疏】言「敷妙座」者，重正法也。開「立說」者，惠及人也。意在說聽有功，道根無失，豈可無聞，徒勞彼此，何所益也！
【譯文】【疏文】提到「鋪設妙高座」，是為了尊崇無上的清淨正法。開許「站立宣說」，是為了慈悲利益底下的聽眾。用意在於讓宣說與聽受都能產生真實功德，讓心中的道法戒根不致失落，怎能讓大眾聽不清楚，徒然耗費彼此的心力，那又有何助益呢！

【375-0010】02_戒疏/03a_卷一下之一#130
【原文】【記】次科。初釋制意，次釋開意。言「立說」者，《律》因眾大聲小，不得盡聞，佛開「立說」；猶故不聞，聽作轉輪高座，立上說之。「道根」即戒體。
【譯文】【記文】第二小節中。首先解釋制定規範的用意，其次解釋開許通融的用意。所謂「站立宣說」，《律》中記載因為大眾人數極多而宣說者聲音太小，無法讓全體聽聞，佛陀開許「站著宣說」；如果還是聽不清楚，允許搭設底座可轉向各方的轉輪高座，站在上面高聲宣說。「道根」就是指戒體。

【375-0011】02_戒疏/03a_卷一下之一#131
【原文】【註】「八難、餘緣，隨時略說。」
【譯文】【註文】「若遇到八種災難或其他事故，可隨當時情況簡略宣說。」

【375-0012】02_戒疏/03a_卷一下之一#132
【原文】【疏】言「八難」者，謂王、賊、水、火、重病、惡蟲等是也。言「餘緣」者，寒、熱、雨、濕、人多坐迮等是也。廣文如《鈔》。
【譯文】【疏文】所謂「八種災難」，是指王難、賊難、水災、火災、重病、惡毒蟲獸危害等狀況。所謂「其他事故」，是指嚴寒、酷暑、暴雨、潮濕、或者人多而場地過於擁擠狹窄等。詳細的記載如同《事鈔》所說明。

【375-0013】02_戒疏/03a_卷一下之一#133
【原文】【記】略說中，初文。「八難」文略人與非人。「餘緣」略眾中多病，布薩多，夜已久，或鬪諍事，論毗曇、毗尼，說法夜久等。義加「寒、熱」，不出《律》文。
【譯文】【記文】在簡略宣說的第一段中。「八種災難」在疏文中簡略未提人與非人的危害。「其他事故」簡略未提僧眾中病人過多、布薩次數繁多、夜色已深、或是大眾發生紛爭諍事、或者研討阿毗曇與毗尼、講經說法耽誤已久至深夜等情況。義理上額外補入「寒冷、酷熱」，這並非出自《律》典本文。

【375-0014】02_戒疏/03a_卷一下之一#134
【原文】【疏】「隨時略說」者，聖教被機，時來不一。眾首智人，商略事務，戒有十段，略說有九，斟酌用捨，故曰「隨時」也。
【譯文】【疏文】「隨當時情況簡略宣說」，是說明聖人的教法是因應眾生根機與時局而施設，突發的事端情況各不相同。僧團的首座與明智之人，應當衡量當前的事務緩急，整部戒本共有十個段落，其中可略說（省略）的段落有九段，仔細斟酌當前局勢來取捨決定，所以稱作「隨當時情況」。

【375-0015】02_戒疏/03a_卷一下之一#135
【原文】【記】次科。「時」謂時緣，如上多種，故言「不一」。十段戒文，初段必廣，故但「略九」。然作白已，卒難排門，不可說序，但云「各正身口意」，則十皆可略。但白在序中，義同廣誦，故云「九」耳。
【譯文】【記文】第二小節中。「時」是指時節因緣事故，如上面所列舉的多種情況，所以說「情況各不相同」。十段戒相經文中，第一段戒序通常必須宣讀，所以只能「略說九段」。然而一旦完成表白之後，急難突然逼臨門戶，哪怕連戒序都無法說完，只要說一句「請大眾各自端正身口意三業」，那麼整部十段都可以省略。只不過因為這項表白本就包含在序文之中，在義理上等同於廣誦的開端，所以律典才說「可以省略九段」。
