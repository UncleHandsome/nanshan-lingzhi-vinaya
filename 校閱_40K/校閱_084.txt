# 校閱材料　第084檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【084-0001】02_戒疏/02d_卷一上之二#101
【原文】【記】四、明說欲。釋文中，初躡前起後。「異結」即各結別部，令僧破故。「或」下，明開意。「諸緣」，如下注釋。「自」下，釋欲法。初制欲、淨各傳，「欲」應羯磨，「淨」應說戒。後廢前教，例須合傳，故從此釋。
【譯文】【記文】在第四、說明「說欲」的段落中。在疏文解釋中，首先承接前文引發下文。「異結」是指各自在不同住處分立結成別部，從而導致僧團破裂破僧。「或」字以下，說明開許代傳心意的用意。「諸緣」正如後文註解中所解釋的。「自」字以下，解釋欲法的名義。起初佛制中「與欲」和「清淨」是分開傳達的，「與欲」是用來相應羯磨，「清淨」是用來相應說戒。後來廢除了先前的教令，通例必須合在一起傳達，所以依照這個原則來解釋。

【084-0002】02_戒疏/02d_卷一上之二#102
【原文】【註】時說戒日，有病比丘，若看病者，及三寶事，不來聽戒。佛言：「應與欲及清淨，隨其廣略。若不現身相、不口說者，不成。若病重者，舁至僧中；恐病增動，若出界作。以無方便可得別眾羯磨說戒故也。」
【譯文】【註文】當時在說戒之日，有罹患疾病的比丘，或是看護病人的人，以及正在承辦三寶事務的人，無法前來聽戒。佛陀宣示：「應當向僧眾呈交與欲以及證明清淨之詞，隨事情緩急可廣可略。如果不親自展現身相、不親口宣說，則作法不能成立。如果是重病之人，應當用擔架將他抬到僧眾之中；如果唯恐病情因搬動而加重，或者可出界外去作法。因為絕對沒有任何通融的方便，可以允許在同一個結界內劃分別眾去作羯磨說戒的緣故。」

【084-0003】02_戒疏/02d_卷一上之二#103
【原文】【疏】注中引「病」等者，成欲緣也。言「廣、略」者，緣奢、促也。「重者舁來」，以法濟也；「恐增出界」，以事攝也。欲明眾別兩行互相資成，不可逼也。言「無方便別眾」者，以大聖布教，意在清心。心濁之元，我倒為本。故無同界別我乖宗，但使一和，通成僧法，則我倒漸亡。定慧之力，功由於戒。故以事約之，可不然也？
【譯文】【疏文】註解中引用的「疾病」等因緣，是成就傳達與欲的正當助緣。所謂「廣或略」，是指因緣寬裕或緊急的不同。「病情嚴重的要抬來」，是用佛法來救濟；「唯恐病情加重而由僧眾出界外作法」，是用事相的善巧來攝護。這是要表明大眾法與個別行事兩者應當互相扶持成就，絕不可強行逼迫。所謂「沒有方便可以允許別眾」，是因為大聖佛陀施設教化，真正的本懷在於清淨自心。自心污濁的根源，以「我執倒錯」為第一根本。所以在同一個結界之內絕不允許劃分出『我的小團體』而違背僧伽的大宗，只要保持全體如一的和合，就能普遍成就如法的僧事，如此一來我執倒錯便會漸漸消亡。禪定與智慧的力量，其功效全在於戒律的基石。所以用嚴厲的事相來約束制約，難道可以不這樣做嗎？

【084-0004】02_戒疏/02d_卷一上之二#104
【原文】【記】注中。初釋欲緣。注列五種，《鈔》中更加作衣緣，竝名如法。「言」下，釋欲法。「奢、促」者，「奢」謂緣緩，故須廣說，對首陳詞。「促」即緣急，乃聽四略：一、云「我說欲」，二、「我與欲」，三、「為我說欲」，四、現相。準《鈔》，約健、病以分，四略唯病，廣通健、病。「重」下，釋重病。云「事攝」者，且令身安，不聞法故。「欲」下，總釋開意。「眾」法多方，使私緣各遂。「別」人情順，得眾行功成，故云「相資」也。「不可逼」者，謂須開也。「言無」下，釋制意。初敘教意。「故」下，明立制。「故無同界」者，「無」，猶不得也。所別望能別，故云「別我」；反增我倒，故曰「乖宗」。此明制意之急，以顯注中「無方便」義。「則」下，顯益。「事約」者，即別眾之制。
【譯文】【記文】在註解的解釋中。首先解釋與欲的正當緣由。註解列出了五種情況，《事鈔》中又加上了趕製衣服等因緣，全都被判定為如法。「言」字以下，解釋與欲的方法。「奢促」的意思，「奢」指因緣寬裕，所以必須詳細宣說，相對親自陳述言詞。「促」指因緣緊急，於是聽許四種簡略方式：第一、說「我說欲」，第二、「我與欲」，第三、「為我說欲」，第四、做出身業表態動作。依照《事鈔》的規範，是依照健康與生病來劃分，四種簡略法只適用於病人，詳細的陳述則通於健康人與病人。「重」字以下，解釋重病的情況。所謂「事攝」，是暫且先讓病人色身安穩，顧不上聽聞戒法。「欲」字以下，總括解釋開許的深意。大眾僧法有著多種善巧，讓個人的私緣各得其所。個別人的心意順遂，大眾行持的功德便能成辦，所以說「互相資助成就」。「不可逼」是說必須有所開通通融。「言無」以下，解釋嚴格制戒的深意。先敘述立教的宗旨。「故」字以下，說明立法的緣由。「故無同界」的「無」，就是不得的意思。被分裂的僧眾相對於能分裂的人，所以稱為「別我」；這反而增長了我執倒錯，所以稱為「違背僧宗」。這是說明制戒意旨的嚴格急切，以此彰顯註解中「無方便」的深意。「則」字以下，彰顯所得利益。「事約」指的就是禁止別眾說戒的嚴格制度。

【084-0006】02_戒疏/02d_卷一上之二#106
【原文】【疏】五、明尼來請法者。已上四緣，止是一徒自行。今兩眾相攝，非法不可弘之。故因說戒，便有斯告，成外化也。
【譯文】【疏文】第五個問答，是詢問比丘尼是否前來請受教誡之法。以上四個助緣，還只是單單一眾僧侶內部的自行法事。現在僧尼兩眾要互相提攜攝受，若不依託佛法就無法弘揚正道。所以在說戒的因緣中，便有了這項通告，用來成就教化外部大眾的功德。

【084-0007】02_戒疏/02d_卷一上之二#107
【原文】【記】五、尼請法，初科，敘意中，初總結前緣。「徒」亦是眾。「今」下，正示今意。「非法不弘」者，謂必假說戒緣也。
【譯文】【記文】在第五、比丘尼請受教法的科判中，敘述大意的段落裡，首先總結前面的四個助緣。「徒」也是指大眾部類。「今」字以下，正式開示當前經文的深意。「非法不弘」是說必定要假借說戒的大好因緣。

【084-0008】02_戒疏/02d_卷一上之二#108
【原文】【疏】文云「尼眾遣何人來」者，此問尼也。或云「尼遣何人傳信從僧乞教授」者，即謂所告比丘也。以言中不了，故光師製戒序云：「誰遣尼來請邪？」此謂比丘受信者。得意忘言，任通無在。但知行德兼備，不可妄傳，故須待請，方往教授也。
【譯文】【疏文】經文中說「尼眾遣何人來」，這是詢問前來的使者尼僧是誰。或者是說「比丘尼派遣了什麼人傳遞信函前來向大僧祈請教授教誡」，那就是指接受請託告白的大僧比丘。因為經文言辭不夠明確，所以光律師在編製戒本序時寫道：「是誰派遣尼僧前來求請教誡呢？」這是指受尼僧委託的比丘。只要領會其精神意旨而忘卻文字表相，不論採用哪種解釋都各通其理、全無妨礙。但必須知道擔任教誡之人必須道行與功德兼備，絕不可隨意委託傳授，所以必須等待比丘尼前來懇請，然後才前往教授。

【084-0009】02_戒疏/02d_卷一上之二#109
【原文】【記】次科，文列三出。初云「此問尼」者，點「何人」字，指使尼也。次釋「何人是所告」者，即尼遣僧，事儀不便。後約「受信」，釋上「誰」字，即僧遣尼，語意無失。謂受囑者令尼來問可否，即為「遣」也，《刪定戒》中亦同此示。「得」下，遣執。「但」下，示意。「行德」即所請人，須具十德，如《鈔》具引。
【譯文】【記文】在下一小節中，文理列出了三種不同的見解。疏文開頭說的「這是問尼僧」，是扣緊「何人」二字，指代所差遣的使者尼僧。第二種解釋認為「何人是指接受告白的比丘」，但這便成了尼僧指使大僧，事相軌儀上極不合宜。最後一種依據「接受囑託」，來解釋上面的「誰」字，這就是指大僧派遣尼僧前來，在文言語意上就毫無缺失了。也就是接受尼僧囑託的比丘，吩咐尼僧前來探問是否可派人教誡，這就算是「遣」，在《刪定戒本》中也是如此指示的。「得」字以下，排遣名相偏執。「但」字以下，闡明立意要旨。「行德」指受請去教誡的人，必須具備十種德行，正如《事鈔》中所詳細引證的那樣。

【084-0010】02_戒疏/02d_卷一上之二#110
【原文】【註】佛言：「若有者，即應起白言：『比丘尼僧和合，禮比丘僧足。』」廣如《刪補羯磨》中。若無來者，答云：「無尼請教誡也。」

【譯文】【記文】在發問的文句中。「白」是指公開表白宣告。在回答中，首先指出照本宣讀乖違法理。「俟」就是等待依靠。「故」字以下，列舉事相作為質詢的明證。自古以來的高僧大德，多半崇尚弘法論道，都是隨順問難應答如流，手握經卷照讀絕不算是有能力。「登」就如同面對。「自」字以下，遮止排除心中的疑惑。只是因為眾生的根機千差萬別，引發悟道的因緣從無定相；無論是見到、聽聞、觸及、覺知，全都可以藉機趣入佛道。然而此方東土震旦的眾生耳根最為明利，偏偏最崇尚音聲聽聞之教；若是能由口背誦修持以施行訓導告誡，尤其能收穫極大的行持利益。聖教的嚴格制定，始終絕不是徒勞虛設的；其餘極少數的特殊特例，萬萬不可拿來作為普遍通用的法規。《事鈔》中舉出此處的規矩，用來比照衡量羯磨法，由此可知這兩種法門，在作白宣告上的深意是完全相同的。

【084-0047】02_戒疏/03a_卷一下之一#4
【原文】【記】初敘意中。初徵問。「僧」下，釋。有二義，初約僧情不同。「諧」，和也。「又」下，二約說戒差別。「五階」者，《律》有三五十五種。初、說至「序」，餘者，應言「僧常聞」；二、誦至「四事」；三、誦至「十三」；四、至「二不定」；五、廣說。復有五事：一、說「序」至「四事」已，略；二、至「十三」已，略；三、至「二不定」；四、至「三十」；五、廣說。復有五事：一、說「序」至「十三」；二、至「二不定」；三、至「三十」；四、至「九十」；五、廣說。今且據一段，故云「五階」。或可「五」合作「三」。「聖制通」者，但使有緣，並開諸略。「凡心須顯」者，隨緣緩急，令眾同知。「故須」等者，情和緣合，法事可行也。
【譯文】【記文】最初敘述主旨的文句中。起初提出審問。「僧團」以下是解釋。包含兩層意涵，首先是就僧眾的心態各有不同而言。「諧」就是和睦的意思。「再者」以下，第二是就誦戒的繁簡差別而言。所謂「五個層次」，《律》中記載了三組共十五種情況。第一種是：誦到「戒序」為止，其餘部分應當說「大眾平常都已聽聞」；第二種是誦到「四波羅夷」；第三種是誦到「十三僧殘」；第四種是誦到「二不定法」；第五種是完整廣誦。又有另外五種情況：第一是誦完「序」到「四事」之後就省略；第二是誦到「十三」之後就省略；第三是誦到「二不定法」；第四是誦到「三十捨墮」；第五是廣說。還有另外五種情況：第一是誦完「序」到「十三」；第二是誦到「二不定法」；第三是誦到「三十」；第四是誦到「九十單墮」；第五是廣說。如今暫且依據其中一段來說，所以稱為「五個層次」。或者「五」字也可能是「三」字的傳抄之誤。所謂「聖人法則本可通融」，是指只要遇到特殊事故，全都允許採用各類簡略誦法。所謂「凡夫心意必須明確」，是指應當隨著因緣的緩急程度，讓大眾全體明了知曉。所謂「因此必須」等語，是指心意和諧且因緣具足，這項如法的事務才能順利推行。
