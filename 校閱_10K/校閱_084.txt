# 校閱材料　第084檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【084-0001】01_行事鈔/05a_卷中之一#40
【原文】三略解名義。依彼梵本，具立三名：初言毘尼，此翻為律。即《四分》十八法中，毘尼及律，二名不並；又《增一》中七種律也，謂七毘尼。或以滅翻，從功能為號，終非正譯。故以律翻之，乃當正義。二言尸羅，此翻為戒，即六度所說，良證可知。三言波羅提木叉，此云處處解脫。顯三次第，即是一化始終。律則據教，教不孤起，必詮行相，戒則因之而立；戒不虛因，必有果克，故解脫絕縛，最在其終。次明其義。初云律者，法也。謂犯不犯，輕重等法；並律所明，即教詮也。問：餘之兩藏，亦明行法，何不標名？答：《智論》云：餘藏所詮，意存定慧；此中顯宣，戒行為萬善之因基；故先取法名，引生後二也。所以前標律者，由出家五眾，形服異世，顯內法亦異；而外道俗流，濫同聖迹，無由取別，妙以法除；故創弘律名，用顯知法。餘如常解。二者戒義，如《雜心》說，謂類通法界也。廣如後明。《智論》云：戒者，秦言性善也。又《善生經》云：戒者，制也，制不善法；或云迮隘，性不容惡；或云清凉，遮煩惱熱；或名為上，能上天堂，至無上道。此但從功能彰名。或從心辯，如經云，學也，學調伏心等。或就體解，即作無作戒，如《雜心》云：別解脫調伏，以體是善，非惡無記。因明正義，戒者，性也；性通善惡，故惡律儀，類亦通周，故云不律儀也。若此立名，戒當禁也。惡法禁善，名之為律；樂殺前生，行順此法，名之為儀。若就善律儀，反解即是。此則以戒從教立名。又律云：木叉者，戒也，此因從果為號也。三解脫義者。近而彰名，隨分果也。謂身口七非，犯緣非一；各各防護，隨相解脫。遠取戒德，因戒克聖；望彼絕累，由遵戒本。故律云：除結無罣礙，縛著由此解。餘如後說。
【譯文】三、略為解釋名義。依照梵本，共建立三個名稱：第一個稱為「毘尼」，這裡譯作「律」。也就是《四分律》十八法之中，毘尼與律這二名並不並列；又《增一阿含》中說七種律，就是七毘尼。有人譯作「滅」，這是從功能上建立名號，終究不是正確的譯法；所以用「律」來翻譯，才契合正義。第二個稱為「尸羅」，這裡譯作「戒」，也就是六度當中所說的戒，可以作為明證。第三個稱為「波羅提木叉」，這裡譯作「處處解脫」。這三名顯示出三重次第，也就是如來一代教化的始終：律是依教法而建立，而教法不會孤然生起，必定要詮釋行持的相狀，戒便依此而建立；戒不會徒然虛設，必定有果德的剋證，所以解脫斷除結縛，列在最後。接著說明其義理：第一項所說的「律」，就是「法」的意思，也就是犯與不犯、輕重等法規，都是律所闡明的，這即是教法的詮釋。問：其餘兩藏也闡明行持之法，為什麼不標立這個名稱？答：《大智度論》說：其餘兩藏所詮釋的，用意在於定與慧；此處明顯宣說戒行是萬善的因地基礎，所以先取「法」的名稱，引生後面的定、慧二者。之所以首先標舉「律」，是因為出家五眾的形貌服飾不同於世俗，顯示內在之法也有別；外道與世俗之流混濫地仿同聖者的行迹，無從加以區別，唯有以法來簡除，所以開創弘揚「律」的名稱，用以顯示必須知法。其餘如同通常的解說。第二項「戒」的義理，如《雜心論》所說，是指戒的品類通於法界，廣泛的解說如後文所明。《大智度論》說：戒，秦地之語稱為「性善」。又《善生經》說：戒，就是「制」，能制伏不善之法；或稱為「迮隘」，因為體性容納不下惡法；或稱為「清涼」，能遮止煩惱的熱惱；或名為「上」，能上生天堂，乃至到達無上道。這些都只是從功能上彰顯名稱。有的是從心念上辨明，如經中所說「學」，即是學習調伏心念等。有的是就戒體來解釋，就是指作戒與無作戒，如《雜心論》說：別解脫與調伏，因為戒體是善性，不是惡性，也不是無記性。因而申明正義：戒，就是「性」；而性通於善與惡，所以惡律儀這一類也同樣通遍周及，因此稱為「不律儀」。若依此建立名稱，戒就當作「禁」來理解：惡法能禁止善法，稱之為「律」；喜好殺害眼前的生靈，行為隨順這種惡法，稱之為「儀」。若是就善律儀而言，反過來理解便是。這就是以戒隨從教法而建立名稱。又律中說：木叉，就是戒，這是因位隨從果位而建立名號。第三項「解脫」的義理：就近期而言彰顯名稱，是指隨分所得的果；也就是身口七支的過非，犯戒的緣由不止一種，能各各加以防護，隨其所對之相而得解脫；就遠處而言，是取戒的功德，因持戒而剋證聖果，期望達到斷絕塵累，這是由於遵行戒本。所以律中說：斷除結縛而無罣礙，一切纏縛執著都由此而得解脫。其餘如後文所說。
