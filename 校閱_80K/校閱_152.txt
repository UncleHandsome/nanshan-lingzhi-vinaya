# 校閱材料　第152檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【152-0001】資持記/13c_下一#9
【原文】麁者尚破，餘三叵言，故云常沒其中。聽門中。前之六物，通被三根。此門四科，初對中下。次局上根，若據四依，名為本制；望非定約，用舍由人，故歸聽攝。受施分物，通三可知。初門，總分中。百一供身，謂時須要用者，加受憶識二俱通許。異前必受，故云令也。
【譯文】粗顯的戒相尚且會違犯，其餘三種更不堪設想，所以說常常沉淪在其中。在「開聽門」中，前面所說的六種物品，通貫被及上中下三根。本門的四個科判，最初針對中根與下根；接著局限於上根，如果依據「四依法」，名為本原的制度；考量到這並非定然的約制，採用與捨棄全由個人決定，所以歸入開聽的範疇。接受布施分取物品，通於三根是可以想見的。在最初一門的「總分」中，「百一供身」，是指平時必須要用的物品，透過「加法受持」與「心念憶識」兩種方式都通許。不同於前面一定要加法受持，所以說是「令」。

【152-0002】資持記/13c_下一#10
【原文】長物局衣，更收錢穀等物，故云及餘也。百一中，初科，初通示名體。若下，別簡。似寶不得自畜。除行須之具，即得畜用；如水精偽珠銅鐵等物，如〈隨相〉三十中具明。開許中，《僧祇》。通示所開，不唯百一，義通餘長。《五分》。三衣，即是本制；同受持故，相從列之。髀，左右股也。踝，足跟旁骨。
【譯文】「長物」局限於衣物，進而收納金錢穀物等物資，所以說「以及其餘」。在「百一」項下，最初科判，先普遍說明名稱與體質。「若……」以下，分別簡擇。類似寶物的東西不得私自蓄存，除了行路所必需的器具，便得以蓄持使用；例如水晶、偽造珠寶、銅鐵等物品，如同在〈隨相〉三十條中所詳細說明的那樣。在「開許」中，《僧祇律》普遍說明所開許的項目，不單限於百一，義理上通達於其餘長物。《五分律》的三衣，就是根本制度；因為同樣屬於受持的物品，所以順從著一併列出。「髀」，是指左右大腿。「踝」，是腳後跟旁的骨頭。

【152-0003】資持記/13c_下一#11
【原文】󰈷，市兗反，亦作腨，脚腨腸也。如下，結示。諸衣即前多種，似衣即後巾囊等。受法中，初科，前示通名。云下，次出受法。某色即牒衣目。亦合先云：大德一心念！我某甲，是僧祇支；方接餘文。後注中。上六字是彼文。下五字，即鈔家點示，恐謂五眾互相對故。次科，初明受持。
【譯文】「󰈷」（音義同腨），也就是小腿肚子。「如……」以下，結語指示。「諸衣」就是前面列舉的許多種，「似衣」就是後面的手巾、囊袋等。在「受法」中，最初科判，先指明通用的名稱；「云……」以下，接著寫出受法的辭句。「某色」就是提出該衣物的名稱。也理應先說：「大德一心念！我某甲，這件是僧祇支」；然後才接續其餘文句。後面的注文中，上面六個字是該律的原文；下面五個字，是行事鈔作者的點拔指示，唯恐誤認為五眾之間可以互相對著作法。下一科判，最初說明受持之法。

【152-0004】資持記/13c_下一#12
【原文】雖穿不失者，三衣有失不失；雨衣已下，一向不失。道名字者，法中別牒也。手下，次簡多少。手巾二者，擬更換故。雜衣似針線囊幞之類。餘衣即雨衣坐具等。《十誦》。七衣，三衣為三，上六不係百一，故以六字結之。《婆論》中。衣鉢制受，違則有過。〔坐具亦爾，論中不言。
【譯文】「雖穿不失」，三衣有破洞破損會喪失或不喪失的分別；從雨衣以下，一概不喪失受持。「道名字」，是在作法中個別提出其名稱。「手……」以下，接著簡別數量的多寡。手巾備有兩條，是準備用來更換。「雜衣」如同針線囊、包裹布之類。「餘衣」就是雨衣、坐具等。《十誦律》的「七衣」，三衣佔了三種，前述六種不隸屬於百一，所以用「六」字來作小結。在《婆論》中，衣和缽是硬性規定要受持，違背了就會有過失。（坐具也是如此，論中沒有明言。）

【152-0005】資持記/13c_下一#13
【原文】百一聽受，亦須加法，故云則可；若但憶識，不加亦許，故云無過。〔古云不受成上根者，非。〕沙彌中，初示制衣。并下，即百一。自下，即餘長。除錢󰝿者，施俗眾故。次明長衣，服飾中，初科。彼云：大衣五日成，七條四日成，五條二日成，長衣一日成。
【譯文】百一屬於開聽受持的物品，也必須透過加法，所以說「則可以」；如果只是心中憶念辨識，不加作法也是允許的，所以說「無過」。（古人說不受持便成為上根之人，是不對的。）在「沙彌」項下，最初指示制度中的衣物；「并……」以下，就是百一物；「自……」以下，就是其餘長物。「除錢󰝿者」，是為了布施給世俗信眾。接著說明長衣。在「服飾」的初科中，該律說：大衣五天縫成，七條衣四天縫成，五條衣兩天縫成，長衣一天縫成。

【152-0006】資持記/13c_下一#14
【原文】若據通論，但使受持之外，俱名為長。今此且對受持，欲明長衣是餘小物，故約一日可成，非謂不通大小。祇支中。注文翻名，即據下律文，從相為名。前翻掩腋，頗得其實。《四分》下，引示，初引三律明制法。後引《僧祇》示制量。注中，上明本相。下示後改。
【譯文】如果就通則而論，只要在受持的定額之外，都稱作長物。如今這裡暫且對照受持的衣物，想要表明長衣屬於其餘小件物品，所以約定一天可以縫成，並非說它不通於大衣或小衣。在「祇支」中，注文翻譯名稱，就是依據後面的律文，依照形相來命名。前面翻譯為「掩腋」，相當切合它的實況。「《四分》……」以下，引用顯明：最初引述三部律典闡明制度作法，其後引用《僧祇律》說明制定的尺寸。注釋之中，上方說明原始的形式，下方說明後來的演變。

【152-0007】資持記/13c_下一#15
【原文】後魏即元魏，今時褊衫，又復變也，疏解其文已亡。涅槃僧中，初文。注翻內衣。西國本無裩袴，即以此衣襯體著故。《僧祇》中制戒即眾學初戒。《十誦》。作時，即作務時。《三十》中。三繞即約帶，準被當上有帶字。
【譯文】「後魏」即元魏時代，現今的褊衫，又再次改變了形式，相關註疏文獻已經亡佚。在「涅槃僧」中，最初的文字，注釋翻譯為內衣。西印度原本沒有褲裩，就是用這種衣服貼身穿著。《僧祇律》中所制定的戒律，就是眾學戒的第一條。《十誦律》所說「作時」，就是操作勞務的時候。《三千威儀》之中，「三繞」是指圍繞腰帶；對照彼書原文，鈔文「當」字之上應當有「帶」字（應為「五、帶當三繞」）。

【152-0008】資持記/13c_下一#16
【原文】餘法後明，露著泥洹僧，上無僧祇支，不得著袈裟，不得上塔至佛像講堂三師上座僧前等。《五百問》。得繫脚者，謂繫裙裾，以閉風故。《四分》。反襵著，謂不用帶繞，反襵抄之。二三四條，以小無力，重加助之。條之謂不使亂。玦如環少缺，即同鉤類；由恐數繫易損，故以玦㺲束勒之。吳即南方，蜀即川界。
【譯文】其餘作法在後面說明，若單獨露出泥洹僧而穿著，上方沒有僧祇支，就不得披著袈裟，不得登上佛塔、前往佛像處、講堂，或是去到三師、上座及大眾僧面前等處。《五百問》說「得繫腳」，是指繫住裙擺的邊緣，用以遮擋風吹。《四分律》所說「反襵著」，是指不用帶子纏繞，而是反向摺疊掖塞住。有兩條、三條、四條，是因為力量微小不夠固定，所以重複添加作為輔助。「條之」是指使其不致紊亂。「玦」如同環狀而帶有缺口，就如同鉤子之類；由於擔心頻繁繫綁容易損壞，所以用玦㺲來束緊固定。「吳」就是指南方，「蜀」就是指四川地區。

【152-0009】資持記/13c_下一#17
【原文】今時作裙，上施腰帶，即同此土俗女方裙，雖乖本制；而便於著用，少有不齊之過。十、五二律。岐間即兩服之中。左掩上者，謂先以左邊在內，掩向其右；後以右邊於上，掩從其左故也。前云襞頭近左，《章服儀》云：如俗所傳左袵是也；今多右掩，頗乖此法。當後，當即前也。
【譯文】現今製作裙子，上方安設腰帶，就如同這片土地上俗家女子的方裙，雖然乖違原本的制式；但方便於穿著使用，很少有長短不齊的過失。十誦、五分兩部律。「岐間」就是指兩件衣服的中間。「左掩上」，是指先將左側置於內側，向右側掩覆；之後再將右側置於上方，從左側掩覆上去的緣故。前面說「襞頭近左」，《章服儀》說：如同俗人所說的左衽；如今大多向右掩覆，相當違背這個法則。「當後」，「當」就是指身前的意思。
