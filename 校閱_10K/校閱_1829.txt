# 校閱材料　第1829檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1829-0001】03_業疏/17b_卷三之六#89
【原文】次釋異中，初出古解為二緣者。彼謂「除自手取」，即開自不受而食也；「授食與他」，開為他作能授人也。今下，次示今解。初約一緣釋通文相。「不受授尼」對簡大尼受已可授，準鈔亦據無人方開。若下次斥古謬說。不受食戒下列四眾，可驗同制，義無輙捉
【譯文】在隨後解釋差異中，首先列出古德解釋為兩種因緣的說法。古師認為「除自手取」就是開許自己不用經過授受程序而直接進食；「授食與他」是開許可以作為能授之人而布施食物給他人。自「今」字以下，接著提出當前的正解：首先依據一種因緣來貫通文句相貌。「不受授尼」，是相對於比丘尼而言——大尼必須先領受然後才能轉授他人，依照《事鈔》也是依據沒有淨人等無人之時才作開許。自「若」字以下接著斥責古代的謬誤之說。「不受食戒」之下列舉了出家下四眾，足以證明同樣受到該戒的規制，在義理上絕不可隨意自行抓取食物。

【1829-0006】03_業疏/17b_卷三之六#94
【原文】近人行事，是沙彌者，例著五條；至於六法，還同本服。是則律崩法壞，漸訛替也。為師為匠，俱行諂附，密誘沙彌，不覺滅法。以多論文，沙彌二衣：一當安陀會，擬常務也；二當鬱多羅僧，擬入眾也。若是正衣，不應云「當」，故以位分上下，衣服標異也。律無明斷，故有斯漸
【譯文】近代主持教事的人，凡是沙彌便照例穿著五條衣；至於到了六法學戒女，反而依舊穿著原來的服飾。這真是規律崩毀、法度壞失，日漸訛誤衰替啊！為人師範的大德，全都一味諂媚迎合，暗中放任誘導沙彌僭越，卻不知這是在無形中滅絕佛法。因為依照《薩婆多論》的記載，沙彌只有二衣：第一種相當於（當）安陀會（五條衣），用以應對日常事務；第二種相當於鬱多羅僧（七條衣），用以預備進入大眾集會。如果是正式的條衣，文中就不應當使用「當」（相當於、充當）字，所以應當以僧位區分上下尊卑，在衣服上標示出差異。正因為律文中沒有明確判斷禁止，所以才演變出這樣的漸次訛誤。

【1829-0007】03_業疏/17b_卷三之六#95
【原文】斥濫中初科，初敘訛。沙彌著五條，則僭於上；式叉同本服，則屈於下。是下正斥。諂附謂私於己徒，密誘謂容其僭濫。下引多論證知非法。「當」字去呼，代也。故下結上相傳。律下究訛所以。故有斯漸，謂漸訛也
【譯文】在斥責混濫的第一科中，首先敘述其訛謬之處：沙彌若穿著五條衣，就是僭越了上座；式叉摩那若仍穿原本的沙彌尼服，就是屈抑了其位階。自「是」字以下正面斥責：「諂附」是指對自己的徒弟徇私溺愛；「密誘」是指縱容其僭越混濫。後文引用《薩婆多論》證明這種做法是非法的。「當」字讀去聲（讀如「檔」），是充當、替代的意思。自「故」字以下總結上面古代相傳之規矩。自「律」字以下探究訛誤產生的緣由。「故有斯漸」，是指逐漸演變成的訛失。

【譯文】又有一位法師主張，沙彌所穿著的衣服應當完全同於具足戒僧人，因為佛陀制定三衣本來只是為了禦寒而已；既然大僧蒙受施主布施衣物，豈能簡別除外下眾？所以應當一律給予三衣。

【原文】次科初敘非大小同服本制為寒義無簡小
【譯文】下一科首先敘述錯誤見解：認為大僧與小眾應當穿著相同衣服，本意制定三衣是為了抵禦寒冷，在義理上不應當把小眾揀除在外。

【1829-0010】03_業疏/17b_卷三之六#98
【原文】今解不然。緣起制僧，下眾非制，必隨時服，教所不禁。若是未具，已受三衣，不應大戒更示三號，鉢亦如此。體是下位，供奉為務，僧器受用，自足形有。縱有依持，法終未具，理必衣鉢大受時須，如文所列。至於出家十戒非制，故不問也，即三衣鉢也
【譯文】如今解釋認為並非如此。佛陀因緣起而制衣是針對大僧比丘，下眾並非制衣的對象，若是隨順氣候寒熱而添減常服，戒教原本就不加禁止。倘若尚未受具足戒就已經受持了三衣，那麼受大戒時就不應該還要另外開示三衣的名號，缽的事宜也是如此。沙彌本質上處於下位，以承事侍奉大僧為本務，所受用的僧物器具，自然只要滿足色身生存所需即可。縱使持有這些法器，但作法畢竟尚未具足，在理法上衣缽必然是要到受大戒時才必須具備，正如羯磨文中所列的那樣。至於在出家受十戒時並非佛制必須具足，所以不加審問，這就是指三衣與缽。

【1829-0011】03_業疏/17b_卷三之六#99
【原文】次今解中，初敘僧具。緣起制僧，即衣犍度為比丘制。「隨時」，謂隨寒熱單重換易。若下次明小眾不許。初以理難破，以受具問難先示衣鉢，必先加受，豈得後示？可驗前無。鉢亦例同，但可依持，未可即用，準用僧器。縱下示乖法。理下示正儀。大受時須，謂受大戒方制具故。如文列者，即羯磨詞中牒衣鉢故。至下取反例。十戒不問，顯非合具。「即三衣鉢」者，轉釋十戒所不問事
【譯文】在接下來的今時解釋中，首先敘述比丘僧所應具足的衣服因緣。所謂「緣起制僧」，是指〈衣犍度〉是專門為比丘所制定的。「隨時」，是指隨順氣候寒暖而更換單衣或夾衣。自「若」字以下，接著說明小眾不被允許穿著三衣：首先以理詰難破斥，因為受具足戒審問難事時必須先出示衣缽，如果沙彌事先已經受了三衣，受大戒時哪裡還用得著事後再次出示呢？由此可驗證此前沙彌並無三衣。缽的規定也是同理，平日只能依傍保管，不能直接當作正式法缽使用，只能準用一般的僧中器具。自「縱」字以下顯示其乖違法度。自「理」字以下開示正統儀軌。所謂「大受時須」，是指受大戒時才規定必須具足衣缽。所謂「如文列者」，就是指羯磨文詞中具體提及衣缽之事。自「至」字以下引用反例，受十戒時不問衣缽，顯明沙彌本不合具足三衣與缽。「即三衣鉢者」，是轉過來解釋受十戒時所不審問的事項。

【1829-0013】03_業疏/17b_卷三之六#101
【原文】初、標緣中，列諸受相，略為四種，廣列為七：八敬、善來、破結、羯磨也。前三如上已釋，後一離分為四相，如上顯然。此羯磨後代所行，須知緣法
【譯文】第一、在「標示因緣」中，列舉各種受戒相貌，約略分為四種，廣泛則列為七種：即八敬受戒、善來受戒、破結受戒、羯磨受戒。前三種受戒相正如上面已經解釋過的；後一種羯磨受戒又可分出四種相貌，如上文所述極為顯然。這種羯磨受戒是後代所遵行的法則，必須通曉其所依的因緣與法軌。

【1829-0014】03_業疏/17b_卷三之六#102
【原文】三、大尼標緣中，初科：諸受前三局一羯磨，開合故，略四廣七。前三後四，並指前者，即總義中上即指略。然下敘起羯磨之言，通含四受
【譯文】在第三項「比丘尼受戒標示因緣」的第一科中：各種受戒相中的前三種各局限為一種，由於最後一種羯磨受戒有開展與合併的緣故，所以全體受戒相概略為四種、廣分則為七種。所謂「前三後四」，都是指前面總義中所述的內容，「上」即是指概略之說。自「然」字以下敘說生起，羯磨受戒之語通體涵蓋了後面的四種受戒形式。
