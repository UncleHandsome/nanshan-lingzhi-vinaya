# 校閱材料　第214檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【214-0001】02_戒疏/05c_卷二上之一#57
【原文】【疏】行雖成顯，須有緣依，故次「欲說戒者，當如是說」，辨說教相，以成教益。
【譯文】【疏文】戒行雖然已經確立顯明，但僧團日常必須有依循宣講的儀軌，所以緊接著「欲說戒者，當如是說」這句，是辨明宣說戒教的儀軌相貌，用以成就教法化導的利益。

【214-0002】02_戒疏/05c_卷二上之一#58
【原文】【記】戒緣，初文，敘前段中。託緣制立，故云「結戒」。呵過立治，名為「行法」。對後說戒，即是眾法。「行」下，明次段。「緣依」，即目說由，說戒警行故為緣，以行憑教故為依。前制治過，名「行益」；後說弘傳，名「教益」。
【譯文】【記文】在因緣的第一部分、敘述前半段之中。藉由事緣而制定戒規，所以稱為「結戒」。呵責過失而確立對治法則，稱為「行法」；相對地，後文所說的說戒，則是全體僧團的羯磨共法（眾法）。「行雖成顯」以下說明第二部分。「緣依」是指宣說戒相的由來，透過定期說戒來警惕戒行，所以說是「緣」；修行必須憑藉教條規範，所以說是「依」。前半段制戒以對治過失，稱為「行門利益」；後半段定期宣說傳布，稱為「教化利益」。

【214-0008】02_戒疏/05c_卷二上之一#64
【原文】【記】初段，分文中。初云「不勝名利」者，「律序」：「身子請佛制戒。佛言：『未得利養，過漏未起』。」以初出世，法化未通。後漸弘廣，信施充積，因茲生過。故知四事眾惡之源。有智深思，特須遠離。毛繩截骨，世喻昭然；肉駱駝山，昔緣顯矣。請詳緣本，宜用書紳。敘下二段，一一皆有躡前生起，以文對注，總意可見。上下指略。觀下諸戒，並委出本緣，略明呵制，至於十利，例皆不述。今此所指，但前兩科，生起同耳。
【譯文】【記文】在第一大段的分段之中。開頭說「經不起名聞利養」，正如《律序》中所記載：「舍利弗請佛制定戒律。佛回答說：『比丘們還沒有得到豐厚利養，過失與煩惱尚未生起。』」因為僧團剛建立時，佛法尚未普遍廣傳；後來佛法逐漸弘揚光大，信徒的布施日漸豐厚，因此便滋生了罪過。由此可知，衣服、飲食、臥具、醫藥這四事供養，是許多罪惡產生的源頭。有智慧的人應當深切思維，特別需要遠離貪著。毛繩鋸截骨頭的世俗比喻歷歷在目；貪求利養命終化為肉駱駝山的往昔因緣昭然若揭。請大家詳察戒緣的根本，應當銘記於心、時時惕勵。戒疏敘述下文的兩段，每一段都承接前一段的起因而發起，將戒疏文字對照戒本註文，整體的意旨便一目了然。疏文自『上來科約』以下，是指示後文略而不釋。縱觀後面的各條戒，都是詳細列出犯戒本緣，簡略說明佛的呵斥制約，至於十種利益，通常都不再重複敘述。現在此處所指的，只是前面這兩科在起因結構上完全相同罷了。

【214-0013】02_戒疏/05c_卷二上之一#69
【原文】【疏】如《律．結集》中，犯有戒相，恐涉妄列，必須三處審同所由。若乖其本，雖佛所說，亦不依用。故彼文云：「何處制？因誰制？何因故制？」如是諸戒，例此三徵。末代持律，亦準三責，如四廣說，可以求之。
【譯文】【疏文】如同《律典．五百結集》中，凡是要認定犯戒的戒相，唯恐涉入虛妄不實的陳述，必須從三項要點（制戒處所、因誰而制、因何事而制）審核查驗其原委。如果違背了原本的事實，即使傳說是佛陀所說的，也不能依信採用。所以該文中記載：「是在何處制定的？是因為誰而制定的？是因為什麼緣故而制定的？」所有的戒條，都依照這三種方式來盤問。後世持律的人，也應當準照這三種要點來責問審定，就如同「四大廣說」中所指示的原則，可以從中尋求審判的依據。

【214-0014】02_戒疏/05c_卷二上之一#70
【原文】【記】緣起中，初科。初分文。「如」下，引示。初敘本集意。言「三處」者，初即住處，二、三即目人、犯為處。「故」下，次引彼文，即《五百結集》中，始自初戒，終至眾學。迦葉一一舉此三事為問，波離隨問答之，集成《律藏》。「末」下，明今準用。「四廣說」，如別所引。《律》明四說，正為末世辦定是非。舉彼例此，令依處判。
【譯文】【記文】因緣科判中的第一科。首先劃分經文。「如律」以下引用律文予以說明。首先敘述當初結集律藏的本意。所謂「三處」，第一是指住處，第二、第三是指將涉案的人與犯戒的事當作關鍵之處。「故彼文云」以下接著引用五百結集的律文，也就是《五百結集》中從第一條波羅夷戒開始，一直到眾學法為止，大迦葉尊者一一提出這三件事作為提問，優波離尊者隨著提問一一回答，最後結集成這部《律藏》。「末代」以下說明現在也應準照使用。「四大廣說」如其他律典文獻所引用的那樣。律中說明四廣說，正是為了讓末世僧團判定是非真偽。引用那個例子來對照此處，是為了讓人在判斷犯戒時必須依據這三處（住處、犯人、犯事）來判定。

【214-0015】02_戒疏/05c_卷二上之一#71
【原文】【疏】就初住處，「毗舍離」者，《多論》云「廣嚴城」也。
【譯文】【疏文】首先就最初的駐留處所而言，「毗舍離」，《薩婆多論》翻譯為「廣嚴城」。

【214-0016】02_戒疏/05c_卷二上之一#72
【原文】【記】住處中。云「廣嚴城」者，「廣」謂土境之大，「嚴」即風物之美。昔波羅奈國王夫人，生一肉團，羞媿不已，封之金函，棄於江內。有一道人，見而取之。後生一兒一女，有大人相，乃立為王。子孫漸多，三展其國，故曰「廣嚴」。

【214-0025】02_戒疏/05c_卷二上之一#81
【原文】【疏】初中，「於如來清淨法」者，略教法也。略教法意，總舉行體，莫非喪苦集，求滅道也。言「於欲無欲」者，思前貪境，名之為「欲」，察知妄起，名「無欲」也。言「斷渴愛」者，思後重貪，追境不捨如「渴」也。觀如此渴，非由境生，但是自心，如犬咬骨，故能斷也。此二集諦，世結之因。「破壞巢窟」者，世結果也。集因既傾，苦果自滅，故曰也。「除眾結縛」者，修道法也。「愛盡涅槃」者，證滅諦也。「乃作惡事」者，總結前辭以用訶也。
【譯文】【疏文】在第一部分中，「在如來的清淨教法中」，指的是佛陀最初所宣說的簡略戒教法門。略示戒教的意旨，是總括標舉修行的體系，無非是滅除苦諦與集諦，以求證滅諦與修持道諦。所謂「於愛欲中心無愛欲」，回思先前引發貪愛的境界，就稱作「欲」；覺察觀照到妄念生起而能自拔，就稱作「無欲」。所謂「斷除渴愛」，回思後續滋生的強烈貪戀，追逐外境不肯捨離，就像飢渴一樣，稱為「渴」。觀照到這種飢渴之感並非是由外境所產生，純粹是自己的妄心在作祟，就像狗啃乾骨頭自以為有肉味一樣，明白了這個道理就能夠斷除了。這兩句屬於苦集二諦中的「集諦」，是繫縛世間生死的根源。所謂「破除輪迴的巢穴」，指的是世間的苦果。招感苦難的集因既然已經被摧毀，痛苦的果報自然跟著熄滅，所以這樣說。所謂「消除一切煩惱纏縛」，是指修習出世聖道之法（道諦）。所謂「貪愛永盡的涅槃」，是指證悟清淨寂滅之理（滅諦）。所謂「竟然做出這種惡事」，是總結前面的言詞來予以深切責備。
