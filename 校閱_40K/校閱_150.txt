# 校閱材料　第150檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【150-0001】02_戒疏/12a_卷三上之三#9
【原文】【疏】三者，雖制畜三，首足猶露，力薄心羸，寒苦所逼，神情亂涉，無心存道。是以如來又量機性，故開百一，記識受持。《多論》云：「百一物中，三衣鉢具必應受持，餘外若受則可，不受無過。」
【譯文】【疏文】第三種根機，雖然規定蓄存三衣，但頭頂與雙足依然裸露在外，因體力薄弱、心智羸弱，受到寒苦逼迫，心神便混亂不定，無心存留於修道。因此如來再度衡量其根機心性，特地開許蓄存「百一供身具」，只要心中記住標識而受持即可。《薩婆多論》記載：「在百一供身物當中，三衣與缽具等必須加法作法受持；其餘各物如果作法受持也可以，不作法受持也沒有過失。」

【150-0002】02_戒疏/12a_卷三上之三#10
【原文】【記】三中。初敘機劣，二、明佛開。下三分文並同。初中，「力薄」故「寒苦所逼」，「心羸」故「神情亂涉」。次明開中，「記識」，謂不加法，記憶而已。「受持」即加法者，以對三衣，不必加故。如《論》可見。
【譯文】【記文】在第三種情況中，首先敘述機根劣弱，其次說明佛陀開許。下文其餘三種情況的分段架構也都相同。在第一部分中，因為「體力薄弱」所以「受到寒苦逼迫」；因為「心智羸弱」所以「心神混亂不定」。在其次說明開許的部分中，「記識」是指不作加法羯磨，只是在心中記憶罷了。「受持」是指以羯磨法作法受持，這是針對三衣而言，其餘物品不必然需要作法加持。這點如同論典所載，顯而易見。

【150-0003】02_戒疏/12a_卷三上之三#11
【原文】【疏】第四人者，形報微弱，心用非利，待時待處，須暖須好。若得供給，便能進業，若制同上，退道為惡。故開畜長，隨施而受，令彼獲福，此得資道。
【譯文】【疏文】第四種人，身軀果報微弱，心思運用並不敏銳，必須等待適當的時節與環境，需要保暖且品質完好的衣物。如果能獲得充足的資具供給，便能進修道業；如果禁制要求如同前述幾種人，反而會退失道心而造作惡業。所以佛陀開許蓄存多餘的衣物，隨順施主的供養而接受，既能讓施主獲得福報，也能使修行者得到資身以助修道。

【150-0004】02_戒疏/12a_卷三上之三#12
【原文】【記】第四機中。初二句，色心俱劣。「須暖」對「待時」，謂不耐寒苦；「須好」對「待處」，謂不堪卑陋。「若得供給能進業」者，明開有益也；「若制同上」便「退道」者，示制有損也。「故」下，明開，即成二利。
【譯文】【記文】在第四種機根中，前面兩句說明其身心均屬劣弱。「需要保暖」對應「等待時節」，指其無法耐受寒冷苦楚；「需要良好」對應「等待環境」，指其無法忍受卑微粗陋。「若能獲得供給便能進修道業」，說明了開許的好處；「若禁制如同前人」便會「退失道心」，指出了禁制的損害。「故開」以下，說明開許能同時成就自他二利。

【150-0005】02_戒疏/12a_卷三上之三#13
【原文】【疏】第五人者，根力最弱，要假重物，方能濟苦，寧身進道，可有階漸。故開被褥、車轝重物依教而畜，以事重故，不令淨施。
【譯文】【疏文】第五種人，根骨氣力最為軟弱，必須依憑厚重的物資，才能救濟身上的苦痛，使身體安寧而精進修道，從而能有階梯式的循序漸進。因此開許棉被、褥墊、車輿等厚重物品依據教法蓄存；由於物品厚重而貴重的緣故，不要求必須透過對人作法說淨的方式來布施。

【150-0006】02_戒疏/12a_卷三上之三#14
【原文】【記】第五機中。「苦」謂有身。「寧」即安也。「故」下，顯制，可解。
【譯文】【記文】在第五種機根中，「苦」是指身為受苦之身。「寧」就是安適的意思。「故開」以下，顯明了制戒內容，文意容易理解。

【150-0007】02_戒疏/12a_卷三上之三#15
【原文】【疏】第六人者，須得眾寶莊嚴房宇，方得安心。如《分別功德論》，天須菩提聞說麤衣，不肯入道，索諸寶舍。佛令借王一切供具，比丘受用，一宿得道。佛言：「當知悟道在心，不拘形服，自今已去，須者開之。」
【譯文】【疏文】第六種人，必須獲得用各種珍寶裝嚴修飾的房舍，才能使心神安定。如同《分別功德論》所記載，天須菩提聽聞佛陀說起粗劣衣服的苦行，不肯出家入道，要求索取種種寶飾房舍。佛陀便令人向國王借來一切宮廷供具，讓這位比丘受用，結果他僅僅住了一宿就證得道果。佛陀說道：「應當知道悟道是在於自心，並不受制於外在的形相衣服；自今以後，有此需要的比丘皆予開許。」

【150-0008】02_戒疏/12a_卷三上之三#16
【原文】【記】六中，初科。初敘機宜。「如」下，引示佛制。彼云，佛弟子中有兩須菩提，一王者種，一長者種。今此王種，故加「天」簡之。以五百世中常生化應聲天，下生王家。佛還本國時，真淨王勸五百釋種出家，此比丘在數。出家時，佛勅諸比丘：「夫為道者，皆當約身守節，麤衣惡食，草耨為床，便利為藥。」此比丘聞已，心自思惟：「吾生豪貴，衣食自然，宮殿服飾極妙莊嚴，猶不盡意，況當著五納衣耶？且當還家，適我本意。」即往佛所辭退，阿難語曰：「若且止一宿。」乃往王所，借種種坐具幡蓋、花香燈油，事事嚴飾，令此比丘於中止宿。至於後夜，得羅漢果。阿難白佛，佛答如《疏》。
【譯文】【記文】在第六種情況中，是第一小節。首先敘述其機根適宜的情狀。「如」字以下，引證以展示佛陀的制戒由來。該論說，佛弟子中有兩位須菩提，一位出身王族，一位出身長者家族。眼前這位屬於王族，所以加上「天」字以示簡別。因為他在過去五百世中經常投生在化應聲天，最後才降生於王室之家。佛陀返回祖國時，淨飯王勸導五百名釋迦族人出家，這位比丘也在名額之中。出家之際，佛陀訓誡諸位比丘：「凡是修道之人，都應當約束自身、謹守節操，身著粗衣、口食粗食，以草藉為床鋪，以陳腐棄藥為醫療。」這位比丘聽聞之後，心中自忖：「我生於富貴之家，衣食自然豐足，宮殿服飾極為美妙莊嚴，我尚且覺得不合心意，何況要我穿著粗弊的五納衣呢？我不如先返回家中，順從我的本意。」他隨即前往佛陀處請求退道，阿難對他說：「你且暫住一晚。」阿難於是前往國王處，借來各種坐具、幡蓋、花香、燈油，每樣器物都裝飾得極其華麗，讓這位比丘在其中留宿。到了後半夜，他便證得阿羅漢果。阿難將此事稟告佛陀，佛陀的回答就如疏文所引述。

【150-0010】02_戒疏/12a_卷三上之三#18
【原文】【疏】如來出世，為除我本。如《持世佛藏經》云：「若不為除我故，在我法中，不得受用一杯之水，一納之衣。」為解脫煩惱者，如《涅槃》云：「雖復十萬，不以為多。」行者自量，據位何在？如《母論》云：「若無戒行而受衣食，不向地獄者，衣即離身，食便破腹。」斯言甚矣，何得自欺？如《多論》云：「有三意故，便制此戒：一、因畜長故，貪於俗利，壞道功德財故；二、失於俗人信敬之心，比丘貯積，與俗無別；三、違佛四依，非節儉行故。」
【譯文】【疏文】如來出興於世間，是為了斷除我執的根本。如同《持世佛藏經》所說：「如果不以斷除我執為目的，在我的正法之中，連一杯水、一縷衣物都不得受用。」若是真正為了從煩惱中解脫者，如同《涅槃經》所言：「即使受用價值十萬兩黃金的物品，也不算多。」修道人應當自我衡量，自己所處的境界究竟在哪裡？如《毘尼母論》所說：「如果沒有戒律德行而受用衣服飲食，若能幸運不墮入地獄，衣物便會脫離身體，食物便會剖裂肚腹。」這些話語極其沉痛嚴肅，豈能自欺欺人？又如《薩婆多論》說：「由於三種本意，所以制定此條戒律：第一、因為蓄存多餘衣物，便會貪戀世俗利益，從而敗壞道業功德法財；第二、會喪失世俗百姓的信敬之心，比丘積聚財物，便與俗人毫無差別；第三、違背佛陀所定的四依行，不合於節儉的道風。」

【150-0011】02_戒疏/12a_卷三上之三#19
