# 校閱材料　第1043檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1043-0001】資持記/05c_上四#51
【原文】此下，難破有四，初斥妄。律下，二顯正；初牒律文。為下，示意。但文非明顯，致令錯會；故準《十誦》德衣之文，方決疑壅。廣下，指彼三十五云：夏竟，眾多僧坊共結一界受功德衣已，捨是大界，諸比丘皆名受功德衣否？答：一切皆得受之。又下，三引證。舊記云，指首師《律疏》。
【譯文】「此」字以下，進行難問破斥，共有四點：首先斥責其妄說。「律」字以下，第二點顯發正理：首先宣讀律文。「為」字以下，說明立教的意圖。只是因為文字不夠直白明顯，才導致大家產生誤解；所以必須準照《十誦律》受功德衣的文字，才能徹底破除疑惑阻滯。「廣」字以下，指出該律第三十五卷說道：夏安居結束後，許多僧坊共同結為一個大界以受納功德衣，受納完畢後，又廢除了這個大界，請問諸比丘還算不算受納了功德衣？回答說：所有比丘全都算獲得了功德衣。「又」字以下，第三點引述典籍作證。過去的筆記說，這是指法首大師的《律疏》。

【1043-0002】資持記/05c_上四#52
【原文】本非為夏，乃顯別有所為；文雖不示，義應同上。古下，四引難。古人云者，已為前代古德難破，今引用之，疏中標云有人言是也。前引律云安居竟應解界應自恣，二文不異，故引相並。然律通三日自恣，十四十五未竟皆成；及中後人隨前自恣，住待日滿；
【譯文】當時解除結界原本就不是為了夏安居的事，而是彰顯另有其他公務作為；文字雖然沒有明示，義理應當與上述相通。「古」字以下，第四點引述問難。所謂「古人云」，是指這在早先就已經被前代古德難破，現在予以引用，《業疏》中所標出的「有人言」指的就是這件事。前面引述律文說安居結束應當解界、應當自恣，這兩處律文並無不同，所以引來互相對比。然而律中通融自恣可在十四日、十五日、十六日三天舉行，在十四、十五日自恣雖未全滿但也都算成辦；以及中安居、後安居之人跟隨前安居之人自恣後，留住等待日數算滿；

【1043-0003】資持記/05c_上四#53
【原文】用此相並，明知解結非破夏矣。文兼等者，不竟解結若云破，不竟自恣亦應破；自恣既不破，解結云何破！上句示文同，下句明義合；破則齊破，成則俱成，不可偏故。疏又難云：如在攝衣界中，護衣緣故須解，亦應失本所依，即日明離；然未經宿，不說離衣；夏亦同此，何得即破。〔前云：解界即日破夏，不待經宿，故有此難。
【譯文】拿這點相互比對，就能明確知道解界與結界絕對不是導致破夏的原因。所謂「文兼」等語，如果說夏未全滿就解界結界算破夏，那麼夏未全滿就先行自恣也應該算破夏；自恣既然不算破夏，解界又何以會算破夏呢！上一句說明律文句式相同，下一句說明箇中義理相合；若算破壞則應當一同算破壞，若算成辦則應當一同算成辦，絕不可偏執一端。《業疏》又責問說：如同在「攝衣界」之中，為了守護僧衣的因緣所以必須解除該界，照你們的說法這也應該喪失了原本所依憑的界，當天看見明相便算離衣犯戒了；然而只要還沒有在外過夜，律中絕不說是離衣犯戒；夏安居也是如此，怎能說解界當天就立刻破夏呢！（前面古德說：解界當天即刻破夏，不須等待過夜，所以道宣律師才提出這項問難）。

【1043-0004】資持記/05c_上四#54
【原文】今解中，初二句判定。但下，明前後寬狹，初生起。若下，示相為二；初明依界前狹後寬。《僧祇》：避難界，縱廣三由旬。問：先廣後狹，為依何處？答：準下自然，亦應依本。從狹彌勝。若下，二明依藍。疏中，又有師云：自然中安居已，結界受日，失本自然，亦破夏也。
【譯文】在當前的正確解釋中，前兩句作出定論。「但」字以下，說明前後結界範圍的寬與狹，首先是發起端緒。「若」字以下，列示兩種相狀：首先說明依止結界時「先狹後寬」的情況。《僧祇律》記載：為了避難而結的界，縱橫廣大可達三由旬。有人問：如果一開始寬廣而後來變得狹小，這時僧人應當依止何處？回答說：準照下文自然界的道理，也應當依止本有的範圍。範圍越狹小則持守越殊勝。「若」字以下，第二點說明依止僧園的情況。《業疏》之中，又有律師主張：在自然界中安居之後，又在其中作法結界以便受日外出，這就失去了原有的自然界，所以也算破夏。

【1043-0005】資持記/05c_上四#55
【原文】難云：本依自然，結夏尚成；今結作法，牢強於本，何得云破！以不離界故。此不標古，直伸今意。初明後狹。若下，明後寬。二緣即有難無難也。〔昔云前注文順古者，準此知非。〕受日，敘意中；初敘開。必下，明制。妄下，顯過。西土施物，多依夏數；北地亦然，故多此過。可下，生起。
【譯文】駁難者說：原本依止自然界，結夏尚且都能成立；現在作法結界，其防護力比原本更為堅固牢強，哪有反而算作破夏的道理！因為行者自始至終都沒有離開這個界域。此處不再標列古代觀點，而是直接申述當前的主張。首先說明「後狹（後來範圍變狹）」。若字以下，說明「後寬（後來範圍變寬）」。所謂「二緣」，就是指有災難與沒有災難這兩種因緣。（過去有人認為前文的夾注是順從古說，準照此處就能明白那種見解是錯誤的）。在「受日（受法請假外出）」的敘述原由中：首先敘述通權開許之事。「必」字以下，闡述戒律嚴正制定的常軌。「妄」字以下，揭示虛妄犯戒的過失。西域施主布施財物，多半依據受戒的夏臘多寡來分配；北地中原也是這樣，所以經常滋生這種冒領的過失。「可」字以下，引起下文。

【1043-0006】資持記/05c_上四#56
【原文】標分中，初列三法。下分三科，通論上三，故云總分也。初科。標云三種者，即上三法開別合眾；或是七日半月一月三位，則合別離眾也。對人中。引《十誦》二問，明所依處及所對人，制行受日不離當界。須從五眾，各局為言；比丘通僧別，餘眾唯局別，不行月法故。次科，易見。
【譯文】在標列劃分之中，首先列出三種作法。下文分為三科，全面通論上述三者，所以說是「總分（全面劃分）」。第一科，標題稱為「三種」者，就是指上述三種法（心念、對首、眾法）分開別法而合攏眾法；又或者是七天、半個月、一個月這三個級距，則是合攏別法而分開眾法。在「對人（所面對之僧人）」之中，引述《十誦律》的兩個提問，明示受法所依止的處所以及所面對的受法僧人，規定受日作法不得脫離當下的結界。必須依從五眾弟子各自的界限局限而論；比丘則通於對大僧集體或個別對首，其餘四眾則僅局限於個別對首作法，不能行使半月或一月的受日僧法。下一個科判，義理容易理解。

【1043-0007】資持記/05c_上四#57
【原文】三中。古執三種次受，不得前後；今此反之。須知古師執法，故不許差；今師義緣隨緣即得，故不同也。釋疑中。即古所計，疏云：昔人云：先受七日，後便十五；以文云受過七日法故。答中。道謂口言，方俗之語，使人易解。三法半倍，半月倍七日，一月倍半月，故知文牒倍過之過。
【譯文】在第三項中，古人執著這三種期限必須依序受取，不得顛倒先後；現在此處則推翻這種說法。必須知道古德死執法條形式，所以不容許前後參差；而當前大師則是從義理因緣出發，主張隨所遇到的具體因緣即可隨機受取，所以看法有所不同。在「釋疑」之中，所解釋的正是古人的妄計，《業疏》說：過去有人主張：必須先受七天的法，之後才能受十五天的法；因為律文中有「受過七日之法」的詞句。在回答中指出：「道」是指口中宣說，這是世俗方言，為了使人容易聽懂。這三種法後後都是前前的倍數，半個月是七天的加倍（兩倍），一個月又是半個月的倍數，由此可知律文宣讀「過」，指的是倍數超過之意。

【1043-0008】資持記/05c_上四#58
【原文】相攝中。以眾法是強，別法為弱；強必攝弱，法容隱顯，故有此門。初科，先敘用竟，顯非所論。若七日下，正示相攝；初立義。由下，釋所以。律下，引文據。次科，初正示。比下斥非。上且從古，不顯今意。
【譯文】在「相攝（作法相互含攝）」之中，因為大眾僧法勢力強大，個人對首法勢力微弱；強大的必定能涵攝微弱的，法規允許隱微或顯露，所以設立了這一門。第一科中，先敘述事務已經運用完畢，以此顯示這不在討論的範圍之內。「若七日」以下，正式宣示相互涵攝之相：首先確立宗義。「由」字以下，解釋其所以然的因由。「律」字以下，引述律文作為依據。下一個科判中，首先正式宣明。「比」字以下斥責錯誤見解。上面暫且是順從古說，並未顯發當前宗師的真正意旨。
