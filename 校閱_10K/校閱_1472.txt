# 校閱材料　第1472檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1472-0001】04_比丘尼鈔/05a_卷下之上#41
【原文】第一簡請此律請有二種一僧次二別請雖開別請然諸經律禁約者多故梵網仁王並廣訶不為十誦善生雖別請五百羅漢猶故不得名請僧福田若能僧中請一似像惡比丘猶得無量果報增一經成論云如飲海水即飲眾流僧次亦爾比丘應供經云若我弟子有受別請定失四果不名比丘道人不名受檀越供養人是人不得國王地上行不得飲國王水有五百大鬼常遮其前是比丘七劫不見佛不為授手不得檀越之物五百大神常隨其後言佛法中大賊佛言莫如外道親近知識國王大臣前自唱言我得真道欲受別請若我弟子受別請者非佛弟子非求道人是空作是計名為畜生地獄中人不見千佛五分但為解脫出家者得為僧次請唯除犯惡戒人正法念經云心常念他請喚與食此是放逸因緣十誦云別請有二處一寺上二施主門外又別請人有四種一別請有德二別請耆年三別請親屬四別請主人又僧次對別請四句一初僧次後成別請謂寺上僧次差來是僧次至施主家語言今有德師來稱某甲請意即答言實爾便成別請二初別請後成僧次謂寺上別請至施主家毀訾別請讚歎僧次後無別請心故成僧次三前後俱別四俱不別初及第三犯別眾提二四不犯別請對別眾亦有四句一別請非別眾謂寺上別請來是別請施主門外無人可別非別眾食二非別請是別眾謂施主門外有人可別是別眾食謂寺上僧次請來非別請三二俱別四二俱不別二三犯提初四不犯門外別者謂施主家內先有三人後別請門外一人門外更有人可別故是別請亦是別眾食若施主家先無比丘尼要門外別請四人更有人可請別眾食婆論云若聚落界內無眾僧有施主請四人已上聽打犍稚若不打者設知此中乃至一比丘尼不來者得別眾食罪若疑有比丘尼者不集亦犯若打犍稚不問有無一切無罪又僧祇云食應作四種相一打犍稚二吹貝三打鼓四唱令若不作四相而食僧祇食名不清淨名盜食僧祇食不問界內有比丘尼無比丘尼不作四相皆犯盜僧祇也。
【譯文】第一「揀擇請僧的性質」（簡請）：本律所說的受請有兩種：一是僧次（依大眾僧次序輪派），二是別請（個別指定邀請）。雖然開許別請，但許多經律對此多有嚴格約束禁制；所以《梵網經》與《仁王經》皆廣加呵責而不允許。《十誦律》與《善生經》都指出，即使個別邀請五百位羅漢，仍然算不上是迎請僧寶福田；如果能在僧團中依僧次邀請一位如同常人般的劣格比丘，所獲福報依然無量無邊。《增一阿含經》與《成實論》說：就像喝了海水一口，就等於喝到了千江萬流的水；依僧次受請也是如此。《比丘應供經》說：如果我的弟子接受個別邀請，必定喪失證得四沙門果的機會，不能稱之為比丘修道之人，不能稱之為受施主供養之人；這個人不能在國王的土地上行走，不能飲用國王的水，常有五百大鬼擋在面前；這個比丘七劫見不到佛陀，佛陀不為他伸手接引，無法得到施主供養之實益；常有五百大神跟在身後，呵罵他是佛法中的大盜賊。佛陀告誡：千萬不要像外道那樣，親近世俗權貴、在國王大臣面前自吹自擂說「我得真道」，以此招徠受納別請；如果我的弟子接受個別邀請，那就不是佛的弟子，不是求道之人，這種徒具虛名的妄想，稱之為畜生或地獄中的眾生，累劫遇不到千佛出世。《五分律》說：凡是為了尋求生死解脫而出家的人，都可列入僧次的輪派受請，唯獨除了觸犯重惡戒律之人。《正法念處經》說：心裡常常掛念著他人邀請呼喚提供美食，這是放逸的因緣。《十誦律》說：別請發生在兩個處所，一是寺院之中，二是施主門外。又個別邀請的人有四種：一指名邀請有德之人，二指名邀請年高長老，三指名邀請俗家親屬，四指名邀請原舊宿主。又「僧次」對待「別請」有四種句型：第一是「起初依僧次，後來成別請」，是指寺院按僧次差派前來，原本是僧次，到了施主家中，施主說：「今日有大德法師前來，正合我當初邀請的心意」，法師便答道：「確實如此」，這就轉變成了別請；第二是「起初為別請，後來成僧次」，是指原本在寺院接受指名別請，到了施主家後，斥責別請的流弊、讚歎僧次供僧的功德，施主隨後打消了指名心念，因此轉成僧次；第三是「前後皆是別請」；第四是「前後皆非別請」（皆依僧次）。其中第一種與第三種情況觸犯了「別眾食」的波逸提罪，第二種與第四種則不犯。「別請」對待「別眾食」也有四種句型：第一是「屬於別請，但不成別眾」，是指在寺院受個別指名邀請，是別請，但施主門外並無其他僧人可供甄別揀退，所以不構成別眾食；第二是「不屬別請，卻成別眾」，是指施主門外尚有其他僧人可供揀別，卻成了別眾食，這是指在寺院原本是依僧次差派前來，所以不是別請；第三是「二者皆屬別請別眾」；第四是「二者皆非別請別眾」。其中第二與第三種情況犯波逸提罪，第一與第四種情況不犯。所謂在「門外分別揀別」，是指施主家中原先已有三位僧人，之後又個別邀請門外的一人，門外既然還有其他僧人被排擠挑剔，所以既是別請，也是別眾食。如果施主家中原本沒有比丘尼，硬要只在門外個別指名邀請四人，門外顯然還有其他比丘尼可供迎請，這就構成別眾食。《薩婆多論》說：如果在聚落劃定界內沒有大眾僧，施主前來邀請四人以上，聽許敲擊犍稚；若不敲犍稚，哪怕明知在此區域內只有一位比丘尼不來，都會結下別眾食罪；若懷疑可能有比丘尼在而不去集結大眾，同樣犯戒；如果敲擊了犍稚，不管到底有沒有其他僧人，大家全都沒有過失。又《僧祇律》說：受食應當顯發四種信號儀相：一是敲擊犍稚，二是吹大法螺，三是擊大法鼓，四是高聲唱令。如果不作這四種信號而擅自受食僧團常住之食，稱為「不清淨」，稱之為「盜食僧常住食」；無論界內究竟有沒有其他比丘尼，只要未作四種信號召集，一律犯盜食僧伽物資之罪。
