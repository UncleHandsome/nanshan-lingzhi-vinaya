# 校閱材料　第1727檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1727-0001】03_業疏/11b_卷二之五#97
【原文】二中初標示。「彼下」出外計，且列數端，例餘皆爾。「佛下」正破。彼計無因，故以十二因緣破之，亦名十二支：無明、行，過去因也；識、名色、六入、觸、受，現在果也；愛、取、有，未來因也；生與老死，未來果也。內外即是依正。初通示。「心下」委釋。識支投染，遂為名色支；染，即男女赤白不淨。哥羅邏時，謂初受胎時，亦名羯邏藍，此云雜穢。七日一轉，三十八箇七日，成二百六十六日，五大四小，故成九月；已前與母同氣，已後四日與母別氣，故至十月然後趣生
【譯文】在第二項中，起初標明開示。自「彼」字以下指出外道的邪執妄計，暫且列舉數項事例，其餘各項亦皆以此類推。自「佛」字以下正式破斥。外道妄計諸法無因，所以用十二因緣法來破斥其執著，十二因緣亦稱為十二支：無明與行，是過去世之二因；識、名色、六入、觸、受，是現在世之五果；愛、取、有，是未來世之三因；生與老死，是未來世之二果。內報與外報，就是正報與依報。起初通體說明。自「心」字以下詳細解釋。識支投入於男女交合的染質之中，便轉成名色支；「染」，就是男女交合的赤白不淨物。「哥羅邏時」，指最初受胎之時，也稱羯邏藍，此處翻譯為「雜穢」。七天為一轉變，三十八個七天，共成二百六十六天，依五個大月（三十天）四個小月（二十九天）計算，所以滿九個月；此前與母親同體呼吸氣息，此後四天與母親氣息分別，所以到了第十個月然後趣向出生。

【1727-0002】03_業疏/11b_卷二之五#98
【原文】三、痛痒想，即受異名。古人翻經未通字義，假事為目：痛者苦受，痒者樂受，想者捨受。此破為計梵天因者。以劫初成，梵天創下，因有人物；諸眾生等，便計彼天以為父母，此生瞋喜，還因彼天。佛法不爾，生憎愛者，實由本陰，何于天也？以初一念緣色心名之為識，了達染淨名之為想，領納違順名之為受。由三想故，便生三受；由三受故，便有三行；故長淪歷，無有解脫也
【譯文】第三、「痛痒想」，即是「受」的異名。古人翻譯經典時尚未通曉字義，便藉用具體事相來命名：痛是指苦受，痒是指樂受，想是指捨受。這是為了破除執著大梵天為萬物之因的外道。因為劫初生成之時，大梵天最初下降，隨後便有了人類與萬物；各類眾生便執計彼梵天為自己的父母，以為自身所生起的瞋怒與歡喜，也全都是由於彼梵天所致。佛法並非如此，眾生生起憎惡與喜愛，實在是由於自身的本陰（受陰），何嘗與梵天有關？因為最初一念攀緣色身與心相名為「識」，明了通達染污與清淨相名為「想」，領受接納違逆與隨順之境名為「受」。由於三種想的緣故，便生起三種受；由於三種受的緣故，便產生三種行（善、惡、無記之業行）；因此長期沉淪流轉於生死之中，無有解脫。

【1727-0003】03_業疏/11b_卷二之五#99
【原文】三中初標示。古譯名為痛痒想，今翻謂之苦、樂、捨。「此下」出計。彼土多事梵天，葢尊其始以為父母。「佛下」正破。本陰，即五陰中受陰。受有三別，故名三受。前由識、想，後起三行，即善、惡、無記業因，感苦、樂、憕懵果報，因果相續，故云長淪等
【譯文】第三段中，起初標明指示。古時翻譯名稱為「痛痒想」，如今翻譯則稱為「苦受、樂受、捨受」。自「此破」以下，指出外道的妄計。彼印度之地多數事奉梵天，大概是尊崇其為最初之始而奉為父母。自「佛法不爾」以下，正式破斥。所謂「本陰」，即是五陰中的受陰。受有三種差別，所以稱為三受。前面是由識與想引發，後面則生起三行，也就是善、惡、無記的業因，感召苦、樂以及憕懵（愚昧懵懂）的果報，因果相續不斷，所以說「長期沉淪」等。

【1727-0004】03_業疏/11b_卷二之五#100
【原文】四者、約諦，為破無因外道也。如外艸木自生死耳，人亦同之。佛法不爾，苦集二法世俗因果，滅道二諦出世因果。諸眾生等知苦無諦，不思惟故，終不厭離；諸出聖人，解苦有諦，廣如涅槃盛開釋也
【譯文】第四、從「諦」（四聖諦）來論述，是為了破除主張無因的外道。就像外界的草木自然生長與枯死罷了，人也是同樣如此。佛法則不是這樣，苦、集二法是世間的因果，滅、道二諦是出世間的因果。各類眾生雖然知曉苦，卻不知苦的聖諦，因為不作如實思惟的緣故，始終無法產生厭離；各類出世的聖人，明了知解苦中有聖諦，這正如《大般涅槃經》中廣泛詳盡開示解釋的那樣。

【1727-0005】03_業疏/11b_卷二之五#101
【原文】四中初標示。「如下」出計。外艸木者，即用無情類顯有情。「佛下」對破。世出世間，皆由因果。諦是審諦，如實觀察。凡愚無諦，故受輪轉；聖人有諦，故能出離。指涅槃者，彼云「善男子！所言苦者，不名聖諦。何以故？若言苦是聖諦者，一切牛、羊、驢、馬及地獄眾生，應有聖諦」，此明眾生無諦之義，廣如第七卷中。問：無因與前自然何異？答：前計現法皆無因由，此即撥無三世因果，故不同也
【譯文】第四段中，起初標明指示。自「如外」以下，指出外道妄計。所謂「外界草木」，就是用無情之物來比況顯明有情眾生。自「佛法」以下，針對破斥。世間與出世間，全都是由因果所構成。所謂「諦」是指審諦，即如實觀察。凡夫愚人沒有審諦觀察苦諦，所以遭受生死輪轉；聖人具足審諦觀察，所以能夠出離生死。指稱《大般涅槃經》之處，該經說：「善男子！所言苦者，不名聖諦。何以故？若言苦是聖諦者，一切牛、羊、驢、馬及地獄眾生，應有聖諦」，這是闡明眾生不知苦諦的義理，詳如該經第七卷中所說。問：無因論與前面所說的自然論有何差別？答：前面是執計現前的諸法全都沒有任何因由，此處則是徹底撥無過去、現在、未來三世的因果，所以兩者不同。

【1727-0006】03_業疏/11b_卷二之五#102
【原文】五、約陰論，為破執神我外道。如彼計身中有神我諦，身中宰主如麻米等，統御心識。佛法廣破：我在何處？為在色中？為在識中？計此身中，但有五陰。隨陰計我，則有五種；如是離合次第求之，覓我無從，便悟妄執，得無我理，分成無漏相似聖人
【譯文】第五、從「陰」（五陰）來論述，是為了破除執著神我的外道。正如他們執計身體之中有真實不虛的神我，是身中的主宰，大小如胡麻或米粒等，統御著心識。佛法則廣泛破斥：我究竟在何處？是在色身之中嗎？還是在心識之中？審察這個身體之中，唯有五陰。隨順每一陰而執計有我，便有五種；像這樣分別（離）與總合（合）依序推求尋找，根本尋覓不到「我」的蹤跡，便能覺悟此乃妄想執著，從而證得無我之理，部分成就無漏的相似聖人。

【1727-0007】03_業疏/11b_卷二之五#103
【原文】五中初標示。「如下」出計。或有計云我大色小、色在我中，或計色大我小、我在色中，受、想、行、識竝有二計，歷之可見。「佛下」對破。「為在」等者，且舉二陰，略受想行，此即離求；應云「為總在五陰中」，此名合求。得無我理，即是我空，亦名人空、生空真如也。分成相似，即是內凡世第一人
【譯文】第五段中，起初標明指示。自「如彼」以下，指出外道妄計。或者有人執計說「我大色小，色在我之中」，或者執計「色大我小，我在色之中」，對於受、想、行、識也同樣各有這兩種執計，依序歷算便可明了。自「佛法」以下，針對破斥。所謂「為在色中」等語，是暫且舉出色、識二陰，省略了受、想、行三陰，這就是分別推求（離求）；還應當說「或者總在五陰之中」，這稱為總合推求（合求）。證得無我之理，也就是我空，亦稱為人空、生空真如。所謂「部分成就相似」，就是指內凡位中的世第一法之人。

【1727-0008】03_業疏/11b_卷二之五#104
【原文】六、約識論，為破一識之道。如有一室而具六窻，獼猴徧出，無識之人謂有六猴，其實一也。人亦如是，根門乃六，一識通行。佛法不爾，識隨根起，若是一識，豈眠根中而聞聲耶？故知非也
【譯文】第六、從「識」來論述，是為了破除「單一神識」的外道理論。就像有一間屋子而設有六扇窗戶，一隻獼猴在各個窗戶處隨處顯現，無知之人便以為有六隻猴子，其實只有一隻。人也是這樣，根門雖然有六個，卻只有一個神識在其中周流貫通。佛法並非如此，識是隨順各自的根門與境相應而生起，如果真是一個神識，難道會在閉目睡眠（眠根）之時還能聽聞聲音嗎？由此可知彼論是錯誤的。
