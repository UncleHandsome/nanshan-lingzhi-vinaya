## 一、明顯錯譯（一定要改）

### ★【1385-0008】「故制不合」

> 原文：恐謂懺竟得著，**故制不合**；隨著，吉羅。
> 譯文：所以制定**不合理**；隨其穿著，得突吉羅罪。

「不合」是唐宋口語的「**不許、不得**」，接的是上句的「著」——怕人以為波逸提懺完就可以穿那件紡績而成的衣，所以**制令不得穿著**；每穿一次犯突吉羅。譯成「制定不合理」語意全非，且與下句「隨著，吉羅」邏輯斷裂。

建議：「恐怕有人以為懺悔之後就可以穿著（所紡績的衣），所以制定不得穿著；每穿一次，犯突吉羅。」

### ★【1385-0002】「有凡褰衣渡水」→「有凡夫尼」

「凡」應是「**尼**」的形訛（同段「**尺**有尼」的「尺」即「又」之訛，譯文已暗改卻未注）。《四分》緣起只作「有比丘尼褰衣渡水，為賊觸嬈」，並無「凡夫尼／聖者尼」的揀別。「凡夫尼」是依訛字造詞，屬硬譯。

建議：「有比丘尼撩起衣服渡水……」，並出校注「凡，疑為尼之訛；尺，疑為又之訛」。

### ★【1385-0001】「下疏口說」的「下」被吃掉

> 原文：次簡言相。**下疏口說**，狀詞揩定，言說通泛，故罪兩分。

「下」是資持記慣用的科文語，指「（鈔／律）下文」；「疏」是疏別、另列。全句是「下文另外疏別『口說』的情形」。譯文把它併成「下手寫成狀詞與口頭陳說兩種情況」，「下」字變没了，科文層次也丢了。

建議：「其次簡別言說之相。下文另列『口說』：書狀楷（原文作揩）定明確，口說通泛不定，所以罪分兩等。」

### ★【1385-0003】「犯初法應捨僧伽婆尸沙」整句未譯

前後文都翻成白話，唯獨這句戒本結罪文原樣照搬，體例不一致。至少要處理成：「……即犯僧伽婆尸沙（僧殘）罪，須依僧法捨除（『初法應捨』為戒本結罪用語）」，並加注說明「初法」依《行宗記》等之解釋，不宜留白。

## 二、判讀／待核問題

### ？【1385-0007】「單提一百二十」

《四分》比丘尼單提是**一百七十八**條（尼戒348：8夷＋17殘＋30捨墮＋178單提＋8提舍尼＋100眾學＋7滅諍）。此處作「一百二十」，疑為「一百七十八」之脫訛。譯文逕寫「共有一百二十條」，等於把可疑數字坐實成律制事實。建議核對底本，並加校注。

### ？「緣」字作科文段次解，不宜一律譯「因緣」

這是**貫穿四段的系統性問題**：

* 0003「初**緣**又二」
* 0004「第二**緣**，初示犯相」「三四可知」
* 0005「獨宿中。初**緣**」
* 0006「獨行中，同上三**緣**；……即第一**緣**／第二**緣**／第三**緣**」

從「初至處行，即第一緣。根本，即發足時。又下，即第二緣。《四分》下，第三緣」可知，這裡的「緣」＝**段／節**（記文在把鈔文切段編號），與「開緣」「命梵二緣」的「緣」不同。譯文全用「因緣」，讀者會誤以為在講犯戒條件。

尤其 0004「**三四可知**」譯成「第三、第四個**因緣**可以由此類推而知」——那是渡水科下的第三、四**段文**，不是因緣。

建議：段次的「緣」一律譯「第○段」；「開緣／無緣」才譯「因緣」。

### ？【1385-0001】「初二並局俗人，道則非重」

「前兩者」所指不明（前二戒？前二種所詣？），且「若**訴訟**出家人」把「道」一律理解為「被告對象」。但下文既說「初示**所詣**」「餘人，謂非官及斷事人」，「道」也有可能指**所往陳訴的對象是出家眾**。二者結罪方向不同，建議回查前段鈔文確定，並把主語補出來（「所告的對象是俗人／所詣是俗官」）。

### ？【1385-0001】「犯罪者隨」

譯文「因為隨**所罰之物**構成了盜取與損害」——「所罰之物」是增譯。原文與下句「應償者，是俗物故」對舉，只是「（文中說）犯罪者隨（之結罪），因已成盜損故」。建議貼著原文譯，不要補入罰贓情節。

### ？【1385-0004】「文據兩尼，以示輕重」

譯文加「**同行**」二字。四獨戒正是以「無伴」成犯，說「兩位比丘尼同行」易生矛盾；原文只說律文就「兩尼」（兩種情況）顯示方便／究竟的輕重。建議刪「同行」。

### ？【1385-0004】「通界外內」

譯作「通於**結界**之外與結界之內」，「結」是增字。此處承「道行戒（邊方疑怖處人間遊行）」而來，「界」所指宜存疑，建議作「通於界內、界外」並加注。

### ？【1385-0007】「初約守戒明不犯」

「首先依據謹守戒律說明不犯」語意空泛。此處「守戒」疑指**與持戒清淨的同伴共宿**（故不犯），建議對照鈔所引律文再定譯。

### ？【1385-0001】括注「（結僧殘）」「（結偷蘭）」

判得合理，但原文只說「罪兩分」，未出罪名。這是譯者補注，宜標明為推補並核《四分》律文，以免與原文混淆。

## 三、用語／文氣潤飾

| 出處 | 現譯 | 建議 |
|---|---|---|
| 0001 | 「不論自己是否有理」 | 「得理」偏指**勝訴得直**，可作「不論訟事是否得直」 |
| 0001 | 「從方便分齊直到究竟結果，便構成犯戒的分寸」 | 「由方便（未遂）趨向究竟（成事），即是成犯的分際」（「分齊」重複） |
| 0003 | 「這四條戒合併制定」 | 「四事合制為一戒，隨犯一事即成」 |
| 0004 | 「教導端正的儀軌」 | 「教示如法的作法」（正儀＝正確作法，非儀式） |
| 0006 | 「互相檢校探尋的方法」 | 「互相檢核（有無同伴）的方法」，「探尋」可刪 |
| 0006 | 「沒有涉水涉足」 | 「不涉水」即可，「涉足」贅 |
| 0006 | 「第三種缺乏正常因緣」 | 與0005「無特殊因緣」不一致；應作「即前文第三段所說的『無緣』（無命難、梵行難）」 |
| 0008 | 「『織』則自然明白」 | 「『織』的意思可自行領會（故不釋）」 |
| 0008 | 「究竟是為了圖謀何事」 | 「本來所求為何」（「圖謀」今義偏負） |
| 0008 | 「又跟身處世俗有何差別」 | 「何如在俗」是**反詰不如**：「還不如在家！」語氣更重 |

| 0001 | 《善見律》 | 實為《善見律毘婆沙》，屬律釋（論），非律本，可統一作《善見論》或加注 |
| 0007/0008 | 「紡線織布」 | 「紡績」本義為紡紗績麻；四事中另有「織」，可作「親手紡紗績麻」 |

**總結**：整體理解方向大致正確，最致命的是 0008「故制不合」譯成「制定不合理」；其次是 0002「凡夫尼」依訛字立義、0003 戒本結罪文漏譯，以及「緣」字科文段次一律誤作「因緣」（連帶 0004「三四可知」判讀錯誤）。這四類改掉，譯文品質就穩了。
