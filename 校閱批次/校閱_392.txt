# 校閱材料　第392檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【392-0001】資持記/02b_上一下#19
【原文】自非負識高達之士，不肖下流，豈能奉律耶！文中其中此事，皆指毘尼。《婆論》。三藏對論以彰律勝。二中，一切佛弟子者，通該七眾。一切眾生，且指三善道。第四纓絡，即喻住持。《善見》五法，言相交涉。初遵稟教法，二淨僧成眾，三傳受不絕，四行業清淨，五住持久永。
【譯文】若不是具有高超通達見識之士，那些平庸無能的下流之輩，哪裡能夠恭敬奉行戒律呢！經文中的「其中」、「此事」，都是指毘尼（戒律）。《薩婆多論》（《婆論》）。將三藏相互對照討論，以此彰顯律藏的殊勝。第二點中，所謂「一切佛弟子」，泛指比丘、比丘尼等七眾弟子。所謂「一切眾生」，暫且是指天、人、阿修羅三善道。第四點所比喻的瓔珞，就是用來比喻住持正法。《善見律毘婆沙》提到五種法，彼此之間息息相關。第一是遵從稟受教法，第二是僧眾清淨組合成團體，第三是傳承受戒不曾斷絕，第四是日常行業清淨無染，第五是正法住世長久永遠。

【392-0002】資持記/02b_上一下#20
【原文】所以唯據五人者，能辦受戒等眾法故。所以約五千年者，論問千年已，佛法為都滅耶？答：不都滅。於千年中得三達智〔通達三世〕；復千年中，得愛盡羅漢，無三達智；復千年中，得阿那含；復千年中，得斯陀含；復千年中，得須陀洹，學法五千歲得道；後五千年，學而不得道。
【譯文】之所以唯獨以五人僧團為標準，是因為五位清淨比丘便能成辦受戒等僧團共同羯磨大法的緣故。之所以界定為五千年，是因為論中發問：一千年過後，佛法難道就全都滅絕了嗎？回答：並沒有全都滅絕。在最初的一千年中，有人能證得通達過去、現在、未來的宿命、天眼、漏盡三達智；第二個一千年中，能證得斷盡貪愛的阿羅漢，但沒有三達智；第三個一千年中，能證得阿那含果（三果）；第四個一千年中，能證得斯陀含果（二果）；第五個一千年中，能證得須陀洹果（初果），修學戒定慧五千年內皆有人能夠證道；後面的五千年間，修行者雖修學卻無法證道。

【392-0003】資持記/02b_上一下#21
【原文】萬歲後經書文字滅盡，但現剃頭有袈裟而已。《五百問》，初敘阿難懷憂。乃至者，略阿難答云世間無師。佛言下，答有三段，竝指戒即是佛。所以然者，佛有生法二身。法身復二，一理法身，即所證理顯；二事法身，即五分德圓。生身有生滅，此二法身，即是常住。
【譯文】一萬年過後，經卷文字完全消滅殆盡，世間只剩下剃除鬚髮、身穿袈裟的僧相而已。《五百問經》，首先敘述阿難尊者滿懷憂慮的情形。文中的「乃至」，省略了阿難回答說「世間將失去導師」等語。從「佛言」以下，回答共分為三段，皆明確指出戒律就是佛陀。之所以如此，是因為佛陀具有生身與法身兩種身。法身又可分為兩種：一是理法身，即所證得的真理顯現；二是事法身，即戒、定、慧、解脫、解脫知見五分法身功德圓滿。生身有生滅無常，而這兩種法身則是常住不滅的。

【392-0004】資持記/02b_上一下#22
【原文】故馬鳴釋於我滅後珍敬木叉云：示現不盡滅，法身常住世間，作究竟度故。是知佛本無身，全是積劫修成功德之聚；還以己德開示群生，故名為戒；當知此戒即是如來，故云若我在世無異此也。苟迷此旨，佛語何通？後學至此，宜切注意。初示親臨。
【譯文】所以馬鳴菩薩在解釋「於我滅度後，應當尊重珍敬波羅提木叉」時說：這是佛陀示現並非徹底滅盡，而是法身常住於世間，作為救度眾生的究竟依託。由此可知佛陀本來就沒有實質肉身，完全是歷經無量劫修持成功的功德聚合；如來又將自身的功德開示顯發給眾生，所以稱之為戒律；應當知道這清淨戒律就是如來，所以說「若我住世，與此無異」。如果迷失了這個深旨，佛陀的言教如何能通達理解呢？後世學者研讀到這裡，應當切實特別留意。第一段開示戒律如同佛陀親臨。

【392-0005】資持記/02b_上一下#23
【原文】法實不來，高座演說，有同來故。又言下，二顯同體，初正示。文中敬念持護，竝同於佛。如下，喻顯。飲水殺蟲者，合上任運兩得之意。智者勿責喻。又如下，三明面對。良以一聞淨戒，體用高深，即是如來不漏果德，故云見也。次釋祕勝，《多論》中。又云者，對前文故。初句引問。
【譯文】戒法實質上雖然沒有肉身前來，但陞坐高座宣說法義，就如同佛陀親臨說法一樣。又從「言」字以下，第二段顯揚戒律與佛陀同體，首先正面開示。經文中所說的恭敬、念想、持守、護持，全都與對待佛陀無異。「如」字以下，舉出比喻來闡明。飲水卻傷害水中蟲子的比喻，是為了符合前面「自然兩者兼得」的意旨。有智慧的人不要在比喻的細節上過度苛求。又從「如」字以下，第三段說明如同親自面對佛陀。實在是因為只要一聽聞清淨戒律，其本體與作用極為高廣深遠，這本就是如來無漏的果德，所以說如同見到了佛陀。接著解釋戒律之祕密殊勝，《薩婆多論》之中。又說「又云」的原因，是為了對應前文。第一句引出提問。

【392-0006】資持記/02b_上一下#24
【原文】與彼頗異，彼云契經阿毘曇不以佛在初，獨律誦以佛在初。〔謂廣律戒本，竝初標世尊在某處等，經中先云如是我聞，故有是問。〕今云初集，未詳聖意。以下是答，初句略答。勝謂高超餘藏，祕謂不使他聞。如下，比釋，上三句明餘藏非勝祕。
【譯文】這裡的記載與該論稍有差異，該論是說經藏阿含與論藏阿毘達磨開頭都不把「佛在某處」放在最前面，唯獨律藏誦出時把佛放在最前面。〔這是指廣律與戒本，開頭皆標示世尊在某個處所等等，而經藏開頭則先說「如是我聞」，所以才有這個疑問。〕現在鈔文說是「初次結集」，尚不清楚聖者的本意何在。「以」字以下是解答，第一句是簡略回答。「勝」是指高高超越其餘經論兩藏，「祕」是指不讓未受戒的外人聽聞。「如」字以下，透過比較來解釋，上面三句說明經論二藏並不具備「殊勝」與「祕密」的特質。

【392-0007】資持記/02b_上一下#25
【原文】不擇時處人者，彼云契經中諸弟子說法，有時釋提桓因說，佛言如是，有時化佛說。律下，彰律祕勝。唯佛說者，反上擇人也。彼云一切佛說故。在僧中者，反上擇時處也。彼云若屋中有事不得即結，必當出外。〔即擇處也。〕若白衣邊有事，必在眾結。〔此明不對二眾，即擇時也。〕故勝下合有祕字。〔舊記妄解，不免委曲。
【譯文】所謂不挑選時間、地點、人物，該論是說經藏中各位佛弟子也能說法，有時是天帝釋提桓因說法，佛陀印可說「正是如此」，有時則是化佛說法。「律」字以下，彰顯律藏的祕密殊勝。唯獨由佛陀親口宣說，正是反對上述經論的不揀選說法之人（律藏專門揀擇說法人）。該論說是因為全由諸佛宣說的緣故。在僧團之中宣說，正是反對上述經論的不揀選時間與地點（律藏專門揀擇時處）。該論說如果屋內有犯戒事故不能立即結戒，必須走到屋外大眾中。〔這就是挑選地點。〕如果在俗人身旁有違犯之事，必定要回到僧團大眾中結戒。〔這說明不能面對在家二眾結戒，也就是挑選時機。〕因此在「勝」字下方應當補上一個「祕」字。〔過去的注解胡亂解釋，不免顯得牽強附會。〕

【原文】雖下，二明形濫體乖。若下，三因中示果。又下，四自懼惡報。上二句懼現報，下句畏來報。此據智人。往往盲愚，死而無悔。如是下，五結勸。問中，彼論前云：若於罪不罪不可得故，是時名為尸羅波羅蜜。後即問曰：若人捨惡行善，是為持戒，云何言罪不罪不可得？
【譯文】「雖」字以下，第二段說明外形冒充濫竽充數，但本質與僧相徹底相違。「若」字以下，第三段從因地行為揭示未來的苦果。「又」字以下，第四段說明破戒之人自己畏懼惡報。上面兩句是畏懼現世的惡報，下一句是畏懼來世的報應。這是指具有智慧的修行人。世上往往有盲目愚昧之輩，直到臨死都毫無悔改之心。「如是」以下，第五段結語勸勉。在提問之中，該論在前文說：如果在罪性與非罪性中皆了不可得，這時才被稱為持戒波羅蜜。隨後緊接著發問說：如果有人斷除惡行修持善法，這就是持戒，為什麼說罪與不罪皆不可得呢？
