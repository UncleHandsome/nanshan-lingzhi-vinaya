# 校閱材料　第1897檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1897-0001】03_業疏/22a_卷四之五#62
【原文】四中，初示宗要。「故」下，次誡還墮。由本不牢，故有反覆
【譯文】在第四項中，起初指示宗旨要義。自「故」字以下接著告誡不可再次退墮。這是因為當初發心立誓不夠堅固，所以才會產生反覆退轉。

【1897-0002】03_業疏/22a_卷四之五#63
【原文】五、如教明證。當緣塵境，或夢或覺，非是妄心之所變耶？又非魔鬼之所惑耶？若是魔者，我之所行未出魔境，魔何由來？將非我業之妄現耶？令我心著，重起倒耶？若知唯心，境不滅者，將是我心之所妄耶？如是覆疎，本即非本，何由靜妄？知妄非真，即此非真，還傳妄耳。如斯反識，分了妄因；又識此了，還知從妄。不爾，欣慶隨妄不返，深須早練，不容自誑。俗中識者，年至五十知四十九非，何況學道而懷習著？則不可也
【譯文】第五、依循聖教勘驗明證。當攀緣六塵境界時，無論是在夢中還是在醒時，難道這不是妄心所變現出來的嗎？難道不是魔鬼的惑亂嗎？如果是魔障，我目前的修行尚且未曾超出魔王的境界，魔王又何必無端前來干擾？莫非是我自身的業障虛妄顯現出來的嗎？以便使我的心念執著，再次生起顛倒嗎？如果已知境象唯心所現，而外境卻依然不消滅，難道這是由於我內心的妄想未除嗎？如此反覆推究疏理，自心本源既已迷失而不再清淨，又憑藉什麼來平息妄念呢？雖然知道妄境不是真理，但這能知妄境的覺知若未契入實相，也依然只是在傳續妄念罷了。像這樣反向審視識心，便能部分明了虛妄生起的因由；進而又能省識這份明了之智，依然知道它也是隨順妄心而起。如果不是這樣，一旦心生欣慶得意，便會隨逐妄執而一去不返，因此深切需要及早純熟磨鍊，萬萬不容自欺欺人。世俗中明智通達的人，到了五十歲尚且知道前四十九年的過錯，更何況是修學至道之人，又怎能心懷惡習染著而不捨呢？這是絕對不可行的。

【1897-0003】03_業疏/22a_卷四之五#64
【原文】五中，初明緣境，謂夢覺中善惡相現。「非」下，次明撿察。初疑心變，「又」下，次疑魔現。「若是」下，三責業現。魔居欲界天頂，若修世禪及無漏業，將出彼境，方感魔故。「若知」下，四責心妄。「如是」下，結示。本即真心，展轉推妄，故皆非本。知妄遣知，了妄遣了，識了從妄，應須遣識，遣遣無窮，則無所住。不爾，忻慶謂作勝解。下文引俗況道：《莊子》云「蘧瑗年五十知四十九年非」；孔子年六十知五十九年非；又《論語》云「加我數年，五十以學《易》，可以無大過」，則知爾前未達天命，動成非也。問：修理懺人須禮誦否？答：愚智兩分，事理無二。上智達理，不礙修行；中下昧空，故存漸誘。應為四句總攝群機：一、得理失事，一心禪觀，外闕莊嚴，如有目無足，不能前進；二、逐事迷理，計功分課，不了緣生，如有足無目，不知所從；三、事理雙運，目足相資，萬行圓修，必至彼岸；四、理事俱昧，盲而無足，愚癡惰慢，終無出期。是知理事各立，未免偏邪；空有一如，是真修習。故曰「實際理地，不受一塵；佛事門中，不捨一法」。諸佛菩薩歷劫熏修，華竺祖師終身苦行，此理深密，何可盡言？略示大途，粗分緇素耳
【譯文】在第五項中，起初說明所緣之境，是指在夢中或醒時所呈現的善惡相狀。自「非」字以下接著說明檢察驗證：起初懷疑是妄心變現，自「又」字以下接著懷疑是魔鬼現形。自「若是」以下第三是審責為自身惡業所現；魔王居於欲界天頂（他化自在天），只有在修持世間禪定以及出世無漏聖業、將要脫離其境界管轄之時，才會感召魔擾。自「若知」以下第四是反省為自心妄想。自「如是」以下總結開示。所謂「本」就是指本具的真心，輾轉推求虛妄，所以知曉一切現境全都不是真心本體。知妄則當遣除這「知」，了妄則當遣除這「了」，既然省識到能了之智也是從妄而生，就應當遣除這分別之識，如此遣了又遣以致於無窮，則心無所住。若不如此，便會心生欣慶自喜，妄自認為得到了殊勝解悟。下文引用世俗名賢的例子來比況修道：《莊子》說「蘧瑗到了五十歲，方知前四十九年之非」；孔子到了六十歲，方知前五十九年之非；又《論語》說「加我數年，五十以學《易》，可以無大過矣」，由此便知在此之前未能通達天命，起心動念皆成非過。問：修持理懺的人，還必須禮拜誦經嗎？答：愚鈍與智慧根機雖有兩分，但事相與理體本無二致。上等智慧之人通達真理，不妨礙起修事相；中下根機之人昧於真空之理，所以保留事修以作循序引導。應當立為四句來總括攝受一切根機：第一、得理失事，一心唯修禪觀，外在缺乏事相功德莊嚴，就像有雙眼卻沒有雙腳，無法向前邁進；第二、逐事迷理，斤斤計較於功勞定額，不明了緣生無自性之理，就像有雙腳卻沒有眼睛，盲目亂走不知何去何從；第三、事理雙運，眼目與雙足互相資助配合，萬德萬行圓滿修持，必定能抵達解脫彼岸；第四、理事俱昧，雙目既盲又無雙足，愚癡懈怠傲慢放逸，終究沒有出離苦海的期限。由此可知，事與理若各自割裂孤立，都免不了落於偏頗偏邪；唯有理事圓融、空有一如，才是真正的修行修習。所以古德說：「實際理地，不受一塵；佛事門中，不捨一法。」十方諸佛菩薩歷劫熏陶修持，震旦西竺歷代祖師終身奉行苦行，這其中的妙理深邃幽密，哪裡是一兩句話能說得盡的呢？此處只是略示大體方向，大略辨明是非緇素罷了。

【1897-0004】03_業疏/22a_卷四之五#65
【原文】二、就小乘律中，懺者亦有五緣：一能、二所、三心、四相應、五究竟也
【譯文】第二、在小乘律典之中，懺悔罪過同樣必須具備五種因緣：一是能懺悔之人，二是所對受懺之人，三是懺悔之心，四是彼此言語境界相應，五是懺悔法事究竟圓滿。

【1897-0005】03_業疏/22a_卷四之五#66
【原文】初就能中：一是五眾犯過之人，二備儀相對，下加四，對上加禮，如前明也
【譯文】首先就第一項「能懺悔之人」而言：第一是出家五眾之中犯了過失的人；第二是具備如法威儀面對所對之人，若對下座比丘則加具偏袒右肩等四種威儀，若對上座比丘則在此之上再加頂禮，正如前面所闡明的那樣。

【1897-0006】03_業疏/22a_卷四之五#67
【原文】二小乘別釋中，初能懺有二。「對下加四」，即偏袒右肩等五儀中除禮足也
【譯文】在第二節小乘各門分別解釋中，首先能懺悔者包含兩點。所謂「對下加四」，就是指在偏袒右肩、脫革屣、胡跪、合掌、頂禮這五種威儀中，扣除禮足（頂禮雙足）這一項。

【1897-0007】03_業疏/22a_卷四之五#68
【原文】二、所對有七：初是同眾、同戒見者，二清淨戒（具如《五分》中蘭若所說；同犯開懺，謂命難也，餘如下文），三作請辭，四依教說，五者可懺（即輕四篇），六說名種非有疑濫，七勢分相及非別眾者
【譯文】第二、所面對的受懺之人必須具備七個條件：第一是同屬出家眾、戒律與見解共同一致的人；第二是具備清淨戒行之人（詳細內容正如《五分律》中阿蘭若處所說；至於同犯之人開許接受懺悔，那是專指面臨命難等特殊情形，其餘詳如下文）；第三是作法時要陳辭祈請；第四是依照如來教法如律宣說；第五是所犯之罪屬於可懺之罪（即僧殘以下的輕四篇之罪）；第六是明確陳說所犯罪名的種類，不得有疑惑含混或浮濫；第七是彼此處於界域勢分所及之處，且不構成別眾。

【1897-0008】03_業疏/22a_卷四之五#69
【原文】二所對中，指《五分》者，彼云若有命難因緣，佛開同犯、不同犯並得受懺，無緣不得，準知揀淨。五中四篇可懺者，夷雖開懺，終不復本故
【譯文】在第二項受懺者中，之所以引用《五分律》，是因為該律說如果有危及生命的命難因緣，佛陀才開許同犯戒之人與未犯之人都可以接受懺悔；若無特殊因緣則不被允許，由此準此即可知道應當揀選清淨持戒之人為受懺者。第五點中說四篇之罪可以懺悔，是因為波羅夷罪雖然在某些情形下開許懺悔以除障，但終究不能恢復原本清淨比丘的資格之故。

【1897-0009】03_業疏/22a_卷四之五#70
【原文】三、明懺心又有三也：內心慚愧，最是治本；二立誓永斷，此即懺悔也；三露罪示他，耻更後犯
【譯文】第三、說明懺悔的心態又包含三種：第一是內心生起深重慚愧，這最是對治罪過的根本；第二是立下誓願永遠斷絕惡業，這就是悔過自新的精神實質；第三是發露罪咎以示他人，深以為恥而誓不再犯。

【1897-0010】03_業疏/22a_卷四之五#71
【原文】三懺心中，具慚、斷、露，罪無不脫
【譯文】在第三項懺悔心中，只要具備內心慚愧、立誓永斷、發露罪名這三點，罪業就沒有得不到解脫免除的。
