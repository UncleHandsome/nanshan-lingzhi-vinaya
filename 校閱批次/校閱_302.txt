# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】【疏文】第三、「物品已經答應給僧眾」的情況分為三種：（一）確定不屬於自己，定是要為僧眾所用，施主對給多數常住僧或給少數現前僧心意尚未決定，比丘若迴轉入己，犯捨墮罪；（二）「為了僧眾而作、尚未答應給僧眾」，雖然不屬於自己，但在常住與現前僧之間尚未劃分，如果迴轉，犯輕垢罪；（三）「已經正式交付僧眾」，這東西已經確定屬於有主之物，如果私自迴轉，則犯更重的盜戒。

【302-0012】02_戒疏/15d_卷三下之三#154
【原文】【記】戒本，第三中。初句「決非屬己」，捨心決也。「眾多別少」，謂欲與眾則恐人多，欲與別則復慮人少，即猶預未決之意。次句，由未決許，迴則但輕。上二句並屬當戒，重輕異耳。第三，落前盜戒。
【譯文】【記文】戒本第三句中。第一句「確定不屬於自己」，是說施主的捨心已經堅定。「眾多別少」，是指施主想給大眾僧又擔心人太多，想給少數人又顧慮人不夠分，這屬於猶豫未定的意思。第二句，因為還沒正式許諾，迴轉就只結輕罪。上面兩句都屬於本戒的範疇，只是罪名有重輕的差別。第三種情況，則落入了前面的根本不與取盜戒之中。

【302-0027】02_戒疏/16a_卷四上之一#10
【原文】【疏】有二十一戒，口業犯而非身。故偈記言：「故毀兩同說，道女異嫌尼，譏法恐怖疑，發起欲拒毗，同欲無根謗，二十一語持。」

【302-0029】02_戒疏/16a_卷四上之一#12
【原文】【疏】昔云：小年與受，是口業犯。今解不爾。《律》結和尚，不是戒師。當時和尚默坐眾中，未曾有語。故知解非。《律》結僧吉、師提者，此在自身作業假他語也，如後為道。
【譯文】【疏文】過去有人說：為未滿二十歲者授具足戒，是口業違犯。現在的解釋並非如此。《律》中是結和尚犯單提，而非戒師。當時和尚靜默坐在僧眾中，未曾發過言語。因此可知過去的解釋不正確。《律》中結僧眾犯吉羅、和尚犯單提，這是屬於自己在身業上造作，卻借用他人的言語來完成犯罪，正如後文所說。

【302-0030】資持記/15a_下三#5
【原文】言因緣者，即中下機，生衣食房藥四種開教，皆有緣故。不得已者，非聖意故。餘事者，通指一切聽教也。分章中。上二唯局本部，三顯他部，四出餘行。釋名中，《善見》，初二句翻名。抖擻，舉棄於物，令盡無餘，從喻為名。謂下，釋義。煩惱是惑，滯著即業。《聖善經》中。
【譯文】說到「因緣」，是指中下根機者，產生了衣、食、住、藥四種開許的教法，都是有其緣由的。「不得已」，說明這並不是佛陀的本意。「餘事」，總指一切聽許開緣的教法。在劃分章節（分章）中，前兩門僅局限於本宗部派，第三門顯示其他部派，第四門列出其餘的行持。在解釋名稱（釋名）中，《善見律》前面兩句翻譯名稱。「抖擻」，是舉起物品拋棄、使它乾淨無餘的意思，這是依據比喻來立名。「謂」字以下，解釋含義。煩惱屬於惑，滯留執著屬於業。《聖善經》中。

【302-0031】01_行事鈔/11a_卷下之三#4
【原文】初釋總名顯德。《善見》云：頭陀者，漢言抖擻。謂抖擻煩惱，離諸滯著。《聖善住意天子經》云：頭陀者，抖擻貪欲、瞋恚、愚癡、三界、六入，一一別論。又云：我說此人能善抖擻。如是抖擻，不取不捨，不修不著，我說此人能說頭陀。《增一阿含》云：其有毀讚十二頭陀一一行者，則為毀讚於我；我常讚行此法，由此住世故，我法久住於世也。《十輪》云：毀破禁戒失頭陀，以造逆故非我滅，如過去佛之所說，破淨戒者不入眾數。《華手經》云：以迦葉行頭陀苦行故，來至佛所，如來移身分座與，迦葉辭讓不受。《雜含》中：佛親命以半座，手授僧伽梨，易迦葉所著大衣，於大眾中稱讚頭陀大行。《四分》：佛三月靜坐，唯除一供養人；時有六十頭陀，往至佛所，為佛讚歎，名供養佛人。《十住婆沙》：阿練若比丘，略說十利，盡形不應捨：一自在來去，二無我我所，三隨意無障，四心樂習空處，五住處少欲少事，六不惜身命為具功德，七遠離鬧語，八雖行功德不求報恩，九隨順禪定易得一心，十處於空處易生無礙想。若有因緣，聽入塔寺，有通有局，不同外道盡形空處。廣說如〈頭陀品〉中。頭陀名通聚落、空野。蘭若、塚間，定出城邑；餘之十行，喧靜通行。
【譯文】第一、解釋總名並彰顯其功德。《善見律毘婆沙》說：「頭陀」，漢語譯為「抖擻（抖落、振作）」。意思是抖落滌除煩惱，脫離一切執滯貪著。《大乘聖善住意天子所問經》說：所謂頭陀，就是抖擻滌除貪欲、瞋恚、愚癡、三界、六入（六根六境），每一種都分別論述。經中又說：我說這樣的人能夠善於抖擻。能如此抖擻，不取不捨、不落於修證之相也不執著，我說這樣的人才能宣說頭陀之法。《增一阿含經》說：若有人毀謗或讚歎十二頭陀中的任何一行，便是毀謗或讚歎我；我常常讚歎並修行此法，正因為此法住持於世，我的正法才能長久住世。《大乘大集地藏十輪經》說：若毀破禁戒，便失去了頭陀行的實質；因為造下逆罪的緣故，不能證得我所說的涅槃寂滅。正如過去諸佛所宣說的，破壞清淨戒律的人，不能列入僧眾之數。《華手經》說：因為大迦葉尊者修持頭陀苦行的緣故，當他來到佛陀處所時，如來特地移身分出半座讓給他，迦葉謙辭而不敢接受。《雜阿含經》中記載：佛陀親自命令分半座與大迦葉，親手以自己的僧伽梨（大衣），交換迦葉所穿的粗弊大衣，並在大眾中稱揚讚歎頭陀的大行。《四分律》記載：佛陀在結夏三月中入靜坐安居，只許一人入內送食供養；當時有六十位修持頭陀行的比丘來到佛所，受到佛陀的極力讚歎，稱他們是真正能供養佛的人。《十住毘婆沙論》說：阿練若（阿蘭若，寂靜處）比丘，簡略來說有十種利益，應當盡形壽（終身）都不捨棄：一是來去自在，二是無我執與我所執，三是隨意順心而無障礙，四是心念樂於安住修習空寂之處，五是居處少欲且少世俗事務，六是不惜身命以圓滿功德，七是遠離喧鬧的言論，八是雖行功德而不求回報，九是隨順禪定容易證得一心不亂，十是安處於空寂處容易生起無礙的智慧觀想。若有特別因緣，也開許進入塔寺之中，這是有通融有拘限的，不同於外道一味終身死守空處。詳細說明如該論〈頭陀品〉中所載。頭陀的名稱貫通於聚落（城鎮村莊）與空曠原野。其中「阿蘭若」與「塚間（墓地）」兩行，必定要走出城邑之外；其餘十種頭陀行，則在喧鬧與寂靜之處都可行持。
