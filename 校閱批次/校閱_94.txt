# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【94-0001】01_行事鈔/09a_卷下之一#32
【原文】八作衣方法。《四分》：大衣、七條要割截，五條得襵葉。《僧祇》：若作衣，餘人相助，一日恐不成，應麁行急竟，受持後，更細刺。《中含》云：世尊親為阿那律裁三衣，八百比丘，同時為連合，即成。《四分》：尼五日不成僧伽梨，得墮；比丘犯吉羅。《薩婆多》：有緣得一端㲲，指作三衣，則不犯長。若少一衣五肘外，若少二衣十肘外，有長者須說淨。《四分》：得縵衣廣長足，若裁割作衣，便少，令揲葉作。若作五納衣，得上色碎段衣，亦得裁作五納衣。《五分》：若染縵衣作條，又縫葉著衣，或襵作衣葉，或半向上半向下作葉，一切吉羅。若以雜色線縫著衣上，作條幅處，此是外道法，偷蘭。阿難奉教，為諸比丘作衣法，左條左靡，右條右靡，中條葉兩向靡。若得衣不足，乃至一長一短作；若猶少者，聽揲葉作；乃至不足，聽作縵安多會。準此，本是大衣，少故下例成之；受法正從二品，理須類用；《十誦》中，有縵僧伽梨等。《僧祇》：不得畫作葉，對頭縫之，應割截作葉。極廣應四指，極狹如䵃麥。不得橫葉相當。縫衣葉後，衣宣脫，應作馬齒縫；衣上下破，應安緣，要須却刺。急時如前分別。借俗人被，作三衣中；先作淨，安紐受持。《十誦》，佛自教比丘施䩙紐法：前去緣四指，施䩙；後去緣八指，施紐；應如是作。準此，以左肩上，常以衣右角覆故；出《毘柰耶律》。《十誦》又云：却刺者是佛所許，如法畜用；直縫不得，是世人衣；為異俗故，又防外道故。又云：以一尺二尺物補衣，皆應却刺；若直縫者，衣主命過，應摘此物與僧，及與看病人。《四分》但云縫僧伽梨，準用《十誦》。《三千威儀》云：三衣揲四角。《十誦》亦爾。《四分》挽角令正，安揲等。又云：應安鉤紐，肩上揲障垢膩處。《十誦》：若糞掃衣比丘，以佛制不著割截衣入聚落，便補揲作鉤蘭施緣。佛言：即當割截，上安揲，得成受持。《十誦》明文開著入。準此貧少衣服，定開入俗。
【譯文】第八、製作衣服的具體工法。《四分律》規定：大衣、七條衣必須嚴格剪截碎布縫合，五條衣則可以折疊出葉條。《摩訶僧祇律》說：如果製作法衣，有其他人從旁相助，唯恐一天之內無法完成，應當先用粗針粗線趕快縫完，經過加法受持之後，再重新細密挑縫。《中阿含經》說：世尊親自為阿那律尊者裁製三衣，八百位比丘同時動手協助拼接縫合，當下就完成了。《四分律》規定：比丘尼若在五天之內沒縫成僧伽梨，犯波逸提（單墮罪）；比丘則犯突吉羅（惡作罪）。《薩婆多論》說：如果有特殊因緣得到一整匹細棉布（㲲），心裡明確指定用來製作三衣，就不會犯蓄持長物之罪。如果少做了一件衣服（只做兩件），多餘布料超過五肘以外的部分；如果少做了兩件衣服（只做一件），多餘布料超過十肘以外的部分，有多餘的布料就必須作說淨。《四分律》說：如果得到的整幅布長寬足夠，但若裁割拼接作法衣布料就會不夠，則准許折疊縫出葉條（揲葉）來製作。如果要製作五納衣（百納衣），得到了高品質純色的破碎布片，也可以裁截拼作成五納衣。《五分律》說：如果在整幅布上畫染出條幅，又把葉縫在衣服上，或者折疊縫作衣葉，或者將葉條半邊朝上半年朝下縫製，這一切都結犯突吉羅罪。如果用雜色線縫在衣服上以標示出條幅界線，這是外道之法，結犯偷蘭遮（重罪）。阿難尊者奉佛陀教敕，為諸比丘制定縫製衣服的法度：左側的條葉向左順倒，右側的條葉向右順倒，中央一條的葉條則向兩邊分別順倒。如果所得的布料不足，乃至可以做成一長一短的樣式；如果還是不夠，聽許折疊布葉（揲葉）來做；乃至依然不足，聽許直接製作不割截的整幅布（縵）安陀會。依照這個道理，原本是要製作大衣，因布料不足而降格仿效下位衣的做法來完成；受持的法式有正品與從品（附屬品）兩種差別，理當比照類推使用；《十誦律》中也有「縵僧伽梨」（不割截的大衣）等規定。《摩訶僧祇律》說：不得在布上畫出衣葉、直接兩端相對平縫，應當割截拼接作出衣葉。葉條的最寬處應為四指寬，最窄處應如青稞麥粒般大小。橫向的葉條不能正相對齊。縫好衣葉之後，如果衣服布料容易鬆脫，應當採用馬齒縫（犬牙交錯狀密縫）；衣服上下邊緣磨損破裂時，應當加縫包邊（安緣），並且一定要使用回針倒縫（却刺）。時間緊迫時依前面所說的緊急方法處理。如果向俗人借用被褥改作為三衣；應先進行「說淨」，安上鉤紐然後加法受持。《十誦律》中，佛陀親自教導比丘安設鉤環（䩙）與繫紐（紐）的方法：前面距離邊緣四指處安設䩙（鉤環），後面距離邊緣八指處安設紐（帶扣），應當這樣製作。照此規定，是因為在左肩上，常常要以衣服的右角覆蓋過來的緣故；這出自《鼻奈耶律》。《十誦律》又說：回針倒縫是佛陀所聽許的，可以如法蓄持使用；直線順平縫合是不可以的，那是世俗之人的衣服樣式；這樣做是為了有別於世俗，也是為了防備外道。又說：用一尺、二尺見方的布料補衣服，都應當使用回針倒縫；如果是平直順縫的，衣服的主人去世後，應當將這塊補布拆除還給僧眾，以及分給看病之人。《四分律》中只提到縫製僧伽梨，應準用《十誦律》的規定。《三千威儀經》說：三衣的四個角都要加縫襯布補強（揲四角）。《十誦律》也是這樣說的。《四分律》說拉直衣角使其方正、安加補貼等。又說：應當安裝鉤紐，在肩頭部位加縫襯布以防護污垢油膩。《十誦律》說：穿著糞掃衣的比丘，因為佛陀規定不得穿著未割截拼接之衣進入聚落，便補綴作出條葉之相並加施緣邊。佛說：應當立刻剪裁割截，在上面加縫補片，便能成就合法的受持。《十誦律》中有明文開許穿著這樣的衣服進入聚落。依照這條規定，貧困缺少衣服的比丘，必定開許穿著這類衣進入俗舍。

【94-0002】資持記/13a_下一#52
【原文】今準《感通傳》，天人示法，逐相填之。彼敘天人問云：大衣重作，師比行之。然於葉下乃有三重，豈得然耶？即問其所作。便執余衣以示之。此葉相者，表於稻田之塍壃也。以割截衣段，就裏刺之，去葉󰎣麥已後。此則條內表田，葉上表渠相，豈不然耶！今則通以布縵，一非割截，二又多重。
【譯文】如今依準《感通傳》中天神所示之法則，應當順著條相一塊塊加以填襯。該傳敘述天神發問說：大衣重疊製作，律師近來正是如此遵行。然而在葉相之下竟然疊有三重布料，這怎麼合乎道理呢？律師隨即請教該如何製作。天神便拿起律師的衣服指點說明：這個葉相，是象徵水稻田的田埂界畦。應當用割截下來的衣料碎塊，從內側針刺縫綴，距離葉相如小麥粒大小的距離縫刺即可。這樣一來，布條之內象徵稻田，葉相之上象徵水渠田溝之相，豈不是理所當然嗎！現今若用整幅布在底下一通鋪襯，一來不屬於割截碎料，二來又疊得太厚重。

【94-0003】資持記/13a_下一#53
【原文】既非本制，非無著著之失。問：下引《多論》，摘分持行，豈非多衣重沓邪？答：祖師爾前並依論作，垂終感聖，方復改之。故此傳文，決了三藏不明之事；如坐具四增安左臂等，世並行之，何獨疑此。縱欲通縵，準論應得，但非截多重之難，無以通之。問：大衣單作，加受成否？
【譯文】這既然不符合最初的制度，在穿著時便難免有違犯威儀之過失。有人問：下文引用《薩婆多論》，允許將重疊的衣拆分開來隨身攜帶，這難道不就是多層衣服重疊累積嗎？回答：祖師道宣在此之前都是依照論典製作，晚年將終感得聖天降臨，這才加以修改糾正。所以這部《感通傳》的文字，解決斷定了三藏經律中未曾明朗之事；如同坐具四邊各增長一層、將袈裟安放在左臂等行儀，世間全都遵行，為何唯獨對這項做法心生疑惑呢？縱然想要通體襯布，依照論典雖說應該可行，但面對「非經割截」與「多層重疊」這兩項難題，便無法圓融解釋了。有人問：大衣若單層製作，行受持法能成就嗎？

【94-0004】02_戒疏/04b_卷一下之二#7
【原文】【疏】如欲行殺，前境及強，倒欲害我，差此進趣，壅住在因，故曰「方便」。然境強非偷蘭，偷蘭由強而生。餘之上下，類此可釋。
【譯文】【疏文】比如想要行殺，對象的境界及其力量過於強大，反而企圖加害於我，阻礙了殺害行動的推進，使得行為停滯在起因階段，所以稱作「方便」。然而境界強大本身並不是偷蘭遮罪，偷蘭遮罪是因為境界強大而引生的。其餘前後各條，皆可依此類推解釋。

【94-0005】02_戒疏/04b_卷一下之二#8
【原文】【記】次緣分二。初敘緣。「然」下，定罪。強非罪緣，故曰「非蘭」。因強壅住，故云「由生」也。「餘」下，指例，如云「闕緣非偷蘭，偷蘭由闕緣而生」等。
【譯文】【記文】這第二個緣分為兩部分。最初敘述其緣起。「然」字以下，判定罪名。境界強大並非罪業之緣，所以說「不是偷蘭遮」。因為境界強大而使行為停滯，所以說「由此而生」。「餘」字以下，指示例證，例如說「缺緣並非偷蘭遮，偷蘭遮是由缺緣而生」等。

【94-0009】02_戒疏/04b_卷一下之二#12
【原文】【疏】如欲殺盜，往逢異人，或恐有事，或刀杖毀壞，或要期未遂，總號「緣差」。就義通名，七緣皆是；隨相取別，唯此第三。
【譯文】【疏文】比如想要行殺或行盜，前往時遇到別的人，或者害怕事情敗露，或者刀杖毀壞，或者約定之期未能如願，總括稱為「緣差」。若就寬泛的義理而言，七種緣皆可統稱緣差；若隨具體行相來區分，則唯獨指這第三種。

【94-0010】02_戒疏/04b_卷一下之二#13

【94-0014】02_戒疏/04b_卷一下之二#17
【原文】【疏】如欲殺人，剋心在張，王人異境，而代張處。緣王張解，望人不殊，究竟成重。由異境來，張人不死，殺意又息，壅住方便，故曰「境差」。
【譯文】【疏文】比如想要殺人，特定心思鎖定在張三身上，李四這個不同的人，卻代替了張三的位置。面對李四卻誤認為張三，但就屬於人類這點而言並無不同，最終殺害仍構成最重罪。由於不同的對象前來，張三未死，且行殺的心意隨之平息，行為停滯在起因階段，所以稱作「境差」。

【94-0015】02_戒疏/04b_卷一下之二#18
【原文】【記】人異境中，初科分二。初明差相。且舉張王兩姓，以分本異二境。「緣」下，結犯。初結異境，「由」下，結本境。罪是偷蘭，號「闕緣方便」也。
【譯文】【記文】在「人類異境」之中，最初科段分為兩部分。首先說明差錯的行相。暫且舉出張、李二姓，藉此區分原本的對象（本境）與替代的對象（異境）。「緣」字以下，判定犯戒結果。首先判定異境的罪，「由」字以下，判定本境的罪。罪名屬於偷蘭遮，稱作「闕緣方便」。

【94-0016】02_戒疏/04b_卷一下之二#19
【原文】【疏】問：「本殺王時，但作張解，無殺王心，何因得重？」
【譯文】【疏文】問：「原本殺害李四時，只是將他當作張三，並沒有殺李四的心，為何會結成重罪？」

【94-0017】02_戒疏/04b_卷一下之二#20
【原文】【疏】答：「張王非罪緣，人是殺境，雖無王心，然有人想，殺緣既具，何得非重？是故《律》云『男想殺女，佛言：波羅夷罪』，可以類之。」
【譯文】【疏文】答：「張、李的個別身分並非定罪關鍵，只要身為人類就是殺害的對象，縱然沒有殺李四的心，然而確實存有殺人的想法，殺戒所具備的條件既然圓滿，怎麼能不定為重罪？因此《律》中說『誤將女子當作男子而殺，佛陀判定：犯波羅夷罪』，正可以此為例來推知。」

【94-0018】02_戒疏/04b_卷一下之二#21
【原文】【記】初問。以心境既差，理非結重。答中，初正答。望張境差，望王心差，故云「非罪」。張、王是別，人趣是通，今就通結，故成「殺重」。「是故」下，例證。
【譯文】【記文】最初提問。認為心念與境界既然發生差錯，按理不應結為重罪。回答中，首先正式回答。對張三而言是境界差錯，對李四而言是心念差錯，所以說個別身分「非定罪關鍵」。張與李是個別差異，但人類趣類是共通的，如今就共通的人類來定罪，所以構成「殺害重罪」。「是故」以下，引用律文作為例證。

【94-0019】02_戒疏/04b_卷一下之二#22
【原文】【疏】問：「殺王重罪，乃取張因而成極果，為望張邊，別有方便？」
【譯文】【疏文】問：「殺死李四所犯的重罪，是截取當初針對張三的起因而促成終極的重罪結果？還是針對張三那邊，另外保有方便罪？」

【94-0020】02_戒疏/04b_卷一下之二#23
【原文】【記】次問。意謂果成因沒，應無方便。古有異解，故問以決之。
【譯文】【記文】第二個提問。意思是說如果結果已經促成，起因便已消失，應當沒有方便罪。古代論師對此有不同解釋，因此藉由提問來決斷。

【94-0021】02_戒疏/04b_卷一下之二#24
【原文】【疏】解云：「張王姓別，人境不殊，重果位同，輕因相等。故攬張因，用成王重。如《律本》中，列『過五』因，用成『五』重。」
【譯文】【疏文】有解釋說：「張與李雖然姓名不同，但同屬人類境界而無差異，兩者的重罪果位相同，輕微的方便因亦相等。因此可以擷取針對張三的因，用來促成針對李四的重罪結果。正如《律本》中，列舉『意圖盜取超過五錢』的因，用來促成『盜滿五錢』的重罪結果。」
