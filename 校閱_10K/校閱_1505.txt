# 校閱材料　第1505檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1505-0001】05_拾毗尼義鈔/01a_卷上之一#14
【原文】第三二覺得戒者若依僧祇如來果中得戒故彼律云佛在菩提樹下最後心中廓然大悟自覺好證是名具足若依婆論亦果得戒以自言不起此座而得漏盡漏盡之時果戒俱得若依五分因中得戒故彼律云二月八日夜半逾城乃至在一須摩那樹下剃髮著袈裟即言我今已獲具足不言受也善見亦因中得戒以寶衣易得麤布僧伽棃已被衣剃髮竟即言已獲具足四分無文若以義推缾沙王見菩薩著袈裟乞食爾時未成道故知因中得然此太子王宮非實生雙樹非實滅不可定言又解爾時未有佛法云何得袈裟剃髮者是首陀會天化作獵師令厭離也問戒本防非佛既惡盡何以戒為答戒是功德法若當無戒乃可惡盡功德不滿是故須耳若爾果頭得有戒者果頭亦應有三護何故果頭有三不護答本是惡法護其三業防過未起故果頭不須三護戒是善法是故有戒問獨覺為有戒耶解云亦得雖出無佛世緣於別事得脫亦得解脫戒問若爾別解脫佛出世有既出無佛世云何得有之者如婆論言非僧攝耶答別解脫有二一在家三歸五八等二出家別解脫二百五十是多論就初而說故言無戒今更解得具別解脫何以故五戒形俱過去時有不至今身亦佛未出世故無自受法婆論如此依善見云有以五戒十善戒一切時有乃至無佛出世辟支輪王等亦教受故若不爾者如來獨覺得自然戒佛亦在家耶真諦明了疏云於過去多劫中以修戒行於最後生身即五戒性成在家已至苦法忍時而出家具戒鬚髮自落衣鉢在身爾時具得別脫定生無漏戒也問如來所以得自然名弟子而得上法者答因中不假師說教故會自然理得盡智故弟子不爾問佛與獨覺不假他身教假自身教不婆論云假自身教得佛在樹下坐即身教成就口自發言我要不解此坐而得漏盡即口教成就後得漏盡戒亦俱得廣如大疏。
【譯文】第三門、如來與獨覺證得戒體（二覺得戒）。如果依據《僧祇律》，如來是在證得極果之中得到戒體的，所以該律說：「佛在菩提樹下，於最後一念心之中廓然徹悟，自覺證得勝妙之法，這就稱為具足戒。」如果依據《毗婆沙論》，也是在果位中得到戒體，因為佛陀自誓說「不起此座，誓盡諸漏」，當諸漏斷盡的時候，佛果與具足戒體同時證得。如果依據《五分律》，如來是在因地修持中得到戒體，所以該律說：二月八日半夜越過城門，乃至在一棵須摩那樹下剃除鬚髮、身著袈裟，隨即宣稱「我現在已經獲得具足」，並未說「受」戒。《善見律》也主張是在因地得戒，以寶衣換得粗布僧伽梨衣，已經披上袈裟、剃髮完畢，隨即宣稱「已獲得具足戒」。《四分律》雖然沒有明文記載，但如果依照義理推敲，瓶沙王（頻婆娑羅王）見到菩薩身穿袈裟托缽乞食，那時佛陀尚未成道，由此可知是在因地得戒。然而，悉達多太子在王宮中並非真正出生，在雙樹間也非真正滅度，這是不可以定論的。另一種解釋認為，當時既然還沒有佛法，如何能得到袈裟並剃除鬚髮呢？那是淨居天人（首陀會天）化作獵師的模樣，為了引發太子的厭離心。有人問：戒律本是用來防非止惡的，佛陀既然已經斷盡了一切惡法，為什麼還需要戒律呢？回答是：戒律是成就功德的善法，如果沒有戒律，即便惡法斷盡，功德也不圓滿，所以是必須具備的。追問：如果是這樣，成佛的果位既然可以擁有戒律，那麼果位上也應當具備「三業護持」的修行，為什麼佛陀在果位上反而宣稱「三不護」呢？回答是：防護本是針對惡法，是用來護持身口意三業、防範過失於未然的，所以果位上自然不需要防護三業；然而戒律本身是圓滿的善法，因此佛果依然具足戒體。有人問：獨覺辟支佛也有戒體嗎？解釋說：辟支佛也能得戒。雖然出生在沒有佛出世的時代，但透過觀察其他緣起而證得解脫，自然也證得了別解脫戒。追問：若是如此，別解脫戒只有在佛出世時才存在，既然生在無佛之世，怎麼可能會有呢？正如《毗婆沙論》所言，辟支佛不屬於佛陀僧團所攝受呀？回答是：別解脫戒有兩種：一是在家的三歸、五戒、八關齋戒等，二是出家的別解脫戒，即二百五十條具足戒。《毗婆沙論》是針對第一種在家戒而言的，所以才說無戒。現在進一步解釋，獨覺辟支佛能夠圓滿證得別解脫戒。為什麼呢？因為五戒與身心相隨，在過去世雖有修行，但功德尚未延續至今生，也因為無佛出世，沒有自行受戒的方法（無自受法），《毗婆沙論》是就此而言。依照《善見律》的說法：五戒與十善戒是一切時期都普遍存在的，乃至在沒有佛出世的時候，辟支佛與轉輪聖王等人也會教導他人去領受。如果不是這樣的話，如來與獨覺證得的是「自然戒」，難道佛陀也是在家身分嗎？真諦大師在《明了論疏》中說：辟支佛在過去生多劫之中修持戒行，到了最後一生之身，五戒的德性自然成就，在家時就已達到了苦法忍的階位，進而捨俗出家，具足戒法使鬚髮自然脫落、袈裟衣缽自然在身，那時便具足證得了別解脫戒、定共戒與無漏戒。有人問：為什麼如來能獲得「自然」之名，而弟子卻只能稱為「上法」呢？回答是：因為如來在因地修行時不需要憑藉師長教導，能直接契合自然之至理而獲證盡智，弟子則做不到這點。追問：佛陀與獨覺受戒時不需要憑藉他人的身行教化，那是否需要憑藉自身的身教呢？《毗婆沙論》說：是憑藉自身的身教而得戒。佛陀坐在菩提樹下，身教便已成就；口中親自發願「我誓不起此座，直到證得漏盡」，口教隨即成就；其後證得漏盡，戒體也同時圓滿證得，詳細內容如同《大疏》所載。
