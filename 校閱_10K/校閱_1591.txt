# 校閱材料　第1591檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1591-0001】03_業疏/03a_卷一之三#4
【原文】初科判中，初敘意總標。準此羯磨，本唯一卷，今分為二，乃後開耳。「法下」就文別判：初敘序分。「由下次」敘正宗。「八篇下」三敘流通。略，即要也。二、三兩篇多是眾法，第四唯是別法，後五竝通眾別，故云「僧私兩成」。末篇首明六念入聚、師資住持等法，故云「靜念」等。毗，即訓助。未葉，即目後世。若據經宗三分判文：序及流通，結集所敘；中間正宗，是佛所說。今此十篇無非佛語，但取作法眾緣為羯磨之序，加法被事是羯磨正宗，修奉弘持為羯磨流通，故與經宗名同義異。又復序中須分證信、發起之別。今以集法廣列聖教，發生物信，故為證信序；次以緣成委示緣相，為法由致，故為發起序
【譯文】在最初科判之中，起初敘述意圖並總括標示。依照這部羯磨，本來只有一卷，現在分為兩卷，是後人展開劃分的。自「法」字以下就課文分別科判：首先敘述序分；自「由」字以下第二敘述正宗分；自「八篇」以下第三敘述流通分。「略」就是綱要的意思。第二篇、第三篇大多是眾法，第四篇唯獨是別法，後五篇都通於眾法與別法，所以說「僧私兩成」。最後一篇開頭闡明六念法、入聚落、師資住持等法，所以說「靜念」等。「毗」就是訓解為輔助。「末葉」就是指後世。若依據經典傳統的三分法科判文句：序分與流通分是結集者所敘述；中間正宗分則是佛所親說。如今這十篇全都是佛陀所言，只是取作法的各項助緣作為羯磨的序分，加持教法被及事相作為羯磨的正宗分，修行奉持弘布住持作為羯磨的流通分，所以與經典的三分名同而義異。再者，序分中必須分出「證信」與「發起」的差別。如今以〈集法〉廣泛列出聖教，啟發眾生敬信，所以是證信序；其次以〈緣成〉詳細開示緣起之相，作為教法的由來因致，所以是發起序。

【譯文】就最初一部分又分為二：前段標列並解釋篇目，後段科判律文隨文解釋。

【1591-0003】03_業疏/03a_卷一之三#6
【原文】言集法緣成者，諸出教本，文散難尋，及到臨機，僧別混亂，至於加被成不，渺然。故前示綱模，後依加用，庶無遲慮也
【譯文】所謂「集法緣成」，各種羯磨出自根本律教，文句分散而難以尋檢，等臨到具體行事之機，僧法與別法容易混亂，至於加法被事到底成就還是不成就，更是渺茫難知。所以在前面先開示綱領模範，在後篇依循加以運用，庶幾不再有所遲疑顧慮。

【1591-0004】03_業疏/03a_卷一之三#7
【原文】釋篇目中，初科前敘所患，又二：初敘法亂。眾法全出本宗，別法多取外部，所出非一，故云「文散」。「至下」次敘緣暗。「故下」後明立意。法亂須集，緣暗須明，此則前示綱模，後依加用，即下諸篇行事。遲慮，即疑惑也
【譯文】在解釋篇目之中，最初一科前面敘述所憂患的問題，又分為二：首先敘述法相混亂。眾法完全出自本宗律部，別法大多取材於其他部派律典，出處不是一處，所以說「文句分散」；自「至」字以下次敘述對法緣的暗昧；自「故」字以下後說明立篇的用意。法相混亂就必須集錄，法緣暗昧就必須明示，這就是先在前面開示綱領模範，隨後依此加法運用，也就是下述各篇的行事做法。「遲慮」就是疑惑的意思。

【1591-0005】03_業疏/03a_卷一之三#8
【原文】注云「事法兼通大小齊降」者，欲明教下所被，無非成業為功，謂羯磨通也。雖隨緣優劣，皆有濟務，謂齊降也。依位數舉，謂綱領也。隨數顯相，各有通塞，若綱目之在綱，如裘毛之依領，故云「末振毛目」也。此明總集三法區分之意
【譯文】注中說「事與法兼通，大與小齊降」的意思，是想說明教法之下所被及的境界，無非是以成就羯磨業性為功效，這就是指羯磨通達；雖然隨著法緣而有優劣之分，但都能成濟事務，這就是所謂齊降；依照僧位與法的數量列舉，這就是所謂綱領；隨著數量顯現名相，各自具有通達與閉塞，如同漁網的目網繫於總綱，如同皮裘的毛依附於衣領，所以說「隨後振舉毛目」。這是說明總括集錄三種羯磨法並加以區分的用意。

【1591-0006】03_業疏/03a_卷一之三#9
【原文】釋注中，初科為二：初釋文，「此下」示意。初中，事法即所被中自分三別：房衣等是事，說恣等為法，受懺等即人。今以句局，義必兼人，羯磨聖法通被此三，故曰兼通。大小，即三法下三品之事故，云優劣。文舉大小，亦合收中。降字訓等，謂成濟無殊；或可訓被，謂聖法不揀也。依位舉數，即三法總目，如綱領；隨數顯相，即八品別類，如毛目，對文可解
【譯文】在解釋注釋之中，最初一科分為二：起初解釋文句；自「此」字以下提示用意。在起初之中，「事法」即所被及的境界中自當分為三種：房舍衣服等是非情之「事」，說戒自恣等是教「法」，受戒懺罪等就是有情之「人」。現在因為文句字數受限，義理上必然兼含人，羯磨聖法普遍被及這三種，所以說「兼通」。「大小」就是指三法之下上品、下品等事，所以說有優劣之分。文中列舉大與小，自然也包含中品。「降」字訓解為齊等，是指成濟僧事並無差別；或者可以訓解為加被，是指聖法不加挑揀。依照僧位列舉數量，就是指三種羯磨的總名目，如同綱領；隨著數量顯明事相，就是指八種品類的個別分類，如同裘毛與網目，對照注文即可理解。

【1591-0007】03_業疏/03a_卷一之三#10

【譯文】在列舉大數之中，第一科所指「如上面所說」，就是前面總論義理分判廣略時所說的「隨事而論有無量法，何止前面的數量」，即是此意。

【1591-0013】03_業疏/03a_卷一之三#16
【原文】有三羯磨攝一切者，隨相顯法，互周事境，不可收盡；以法從緣，不過三法，皆成業行，故以三教攝之，不隨事境定其數也。不同《十誦》恰列百一，終非通被，故此不論。若準此收，但據眾法；若人通於僧別，云三種、五種一切攝盡也
【譯文】所謂「有三種羯磨統攝一切」，是因為隨著事相顯發教法，交錯周遍於一切事境，無法全部收錄窮盡；若以法依從緣起來論，不過就是這三種羯磨法，都能成就律儀業行，所以用三種教法來統攝它，而不隨著外在事境去固定其數量。這不同於《十誦律》恰恰只列出一百零一種，終究不能周遍被及，所以這裡不採用其說。如果依照這種方式來收攝，只是依據眾僧之法；如果按僧人而通論眾法與別法，那麼說三種、五種羯磨法，就能將一切羯磨收攝窮盡了。
