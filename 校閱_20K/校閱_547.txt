# 校閱材料　第547檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【547-0001】資持記/08a_中二#56
【原文】今詳《了論》，或不約量，或取外地通歸樹巖。解下，引疏釋，初明制乞。所下，顯意，初列示兩過。故下，準過以決。諸律多約僧地，據斯二過，何簡僧私。〔此二句準《戒疏》是鈔家語。〕指授中，《僧祇》有二法；初至亦得，引第一僧法。即比丘來三乞已，僧與處分法。
【譯文】現在深入詳究《明了論》的意思，或許該論不拘泥於房屋的具體尺寸，又或者將樹木和岩石周圍的外圍土地也一併算入樹洞和岩穴之中。「解」字以下，引用《戒疏》的解釋，首先說明佛陀制定必須乞請處分的規定。「所」字以下，顯露制戒的用意，首先列出並說明兩種過失。「故」字以下，依據這兩種過失來作裁斷。各大律典多半是針對屬於僧團共有的土地來立論，但基於這兩種過失的本質，哪裡還需要去區分是僧團共有地還是私人私有地呢。〔這兩句話依據《戒疏》的脈絡，是《行事鈔》作者道宣律師本人的評語。〕在指示指定用地的羯磨中，《摩訶僧祇律》有兩種方法：開頭一直到「亦得」，是引述第一種由全體僧團親自到場的作法。也就是比丘前來向僧團乞請三次之後，僧團正式批准處分的方法。

【547-0002】資持記/08a_中二#57
【原文】必無能秉，方開三說。〔上二皆是僧作。〕若處下，引第二僧差使法。由前僧法，合眾往彼；今為病等七緣，不得同往，故開遣使。彼比丘亦於僧中三乞已，僧作羯磨差使觀察，至彼審無妨難者；一比丘云：僧已示作房處，三說。〔今鈔不引。
【譯文】僧團中如果確實沒有通達律法能主持白二羯磨的人，才開許只用口頭宣告三次的方式。〔以上兩種都必須由大眾僧團共同造作。〕「若處」以下，是引用第二種由僧團派遣代表使者前往勘察的方法。按照前一種僧法，理應全體僧眾一同前往該處；現在如果因為生病等七種合法因緣，僧眾無法全部同去，所以開許派遣僧差使者。那位起造房舍的比丘也必須在僧團中乞請三次，僧團作白二羯磨派遣使者前去實地考察，到達現場審視確實沒有任何危難與妨礙後；其中一位使者比丘便宣告說：「僧團已經指示認定了建房的地點」，如此宣告三次。〔當前的《行事鈔》沒有引錄這段具體文句。

【547-0003】資持記/08a_中二#58
【原文】不得羯磨四人者，謂白二差人，不得加四；彼云不得眾羯磨眾，故極至三人。往彼下，簡指授成不。四種人即能指授比丘也。第一彼云：先年預指授。〔以乞造必在年內，不當先與指授故。〕二中，彼云：他界不名指授。〔以不知此處妨難故。〕第三彼云：若僧中一人二三人不作房，不應指授。
【譯文】所謂「不可四人作羯磨」，是指白二羯磨派遣使者時，使者人數最多不得達到四人；該律說不能以一個僧團去對另一個僧團作羯磨，所以派遣的人數最多只能到三人。「往彼」以下，是甄別指示指授的程序是否如法成立。所謂「四種人」，是指四種妄行指授而使其指授不成立的比丘。第一種情況，該律說：不能在前一年預先指授。〔因為乞法建房必須在一年之內完成，不應當提早預先批准指授的緣故。〕在第二種情況中，該律說：跨越到他方僧界所作的指授無效。〔因為不了解該地具體有無妨害難處的緣故。〕第三種情況，該律說：如果僧團中只有一人、兩人或三人不打算建房，這時不應當批准指授。

【547-0004】資持記/08a_中二#59
【原文】〔不作者少，顯作者多，恐相覆隱故。〕若不作房者多，聽作。第四彼云：若水中非砂地非碎石地非石上非火燒地。〔反明非上水中，是下四地，方成指授；以非生地故。〕據此約處，亦由不善知法，妄行指授，還屬簡人。即下轉證。律中：乞法比丘若不可信，眾僧往看；若僧不去，應遣僧中可信者看。
【譯文】〔不建房的人少，意味著打算建房的人多，恐怕他們會結黨互相談護隱瞞過失的緣故。〕如果僧團中多數人都不打算蓋房，這時才准許指授建造。第四種情況，該律說：如果在水中、或者不是沙土地、不是碎石地、不是堅固石面、不是經過火燒的地面，都不得指授。〔從反面來說，必須不是在水中，並且是上述四種地質之一，指授才能合法成立；因為這些都不是能滋生蟲蟻的有生之地。〕依照這些針對地質處所的限制，也是由於指授者如果不善於通曉律法，就會盲目妄作指授，所以歸根結底還是屬於考核甄選人選的問題。「即」字以下進一步引證。律中說：前來乞法的比丘如果品行不可信任，全體僧眾應當一同親自去查看；如果大眾僧不能一同前去，應當派遣僧團中老成持重、值得信賴的人前往勘查。

【547-0005】資持記/08a_中二#60
【原文】三中，《多論》，初明房處，必須相應。餘下，示有不乞得作之義。重屋，即樓閣也過量中，初科。《善見》應有四句，文出二互；二俱易解，不在言故。文中且舉一磔為度；至論過減，不必限此。若下，明多人共成；此有兩別，初明無犯。客為主成，主不至果；故言無罪，準有方便。
【譯文】在第三部分中，《薩婆多論》首先說明蓋房的處所，必須與身分法度相稱相應。「餘」字以下，說明也有不需要經過乞法就能直接興建房舍的例外情況。所謂「重屋」，就是指多層的樓閣建築。在建造過量的科判中，第一段科判。《善見律》本應有四句排列，文中只列出了「互有超減」的兩句；至於雙方都超量或都不超量的情況很容易理解，所以沒有多費文字說明。律文中暫且拿「超過一磔手」來作為舉例的尺度；至於實質論斷超量或減縮的幅度，並不一定受限於這一個數值。「若」字以下，是說明由多人共同合力建成的情況；這裡包含兩種不同的情況，首先說明不犯重罪的情況。客人替主人建造完成，但原房主自始至終並未參與促成最後的結果；所以判定房主沒有犯根本重罪，但依理推斷仍有前行方便罪。

【547-0006】資持記/08a_中二#61
【原文】以下，釋無犯意。主客共成，非別屬故。若下，次明有犯。上約一房前後而成，此據大房同時而造。若通擬多人，不別計者，文在開通。問答中。房衣過量犯相不同，故須決釋以申教意。二教作中，初引律文。但云犯者，由通能所，兼合重輕，故不別指。若下，義判。房主即能教，巧師即所教。
【譯文】「以」字以下，解釋為什麼不犯重罪的用意。因為這是主人與客人共同完成，房屋所有權並不單獨歸屬於原房主一人。「若」字以下，接著說明構成犯罪的情況。上面是就同一座僧房由前後不同人接續建造而言，這裡則是針對一座大僧房由眾人同時合力建造而談。如果這座房屋一開始就是通盤打算供全體大眾共同居住，沒有特別算作是哪一個人的私產，這種情況在律文的開許範圍之內。在問答之中，房屋建造超量與衣服裁剪超量的犯相本質各不相同，所以必須加以辨析解釋，以發明宣揚佛教的制戒意趣。在第二段討論「教唆他人建造」中，首先引用律文。律中只籠統說「犯戒」，是因為既通於發起教唆的主人也通於受教動手的匠人，同時兼括了重罪與輕罪的可能，所以沒有作個別指向性的裁決。「若」字以下，是從法理上作出的判定。房主就是能教唆之人，工匠就是被教唆之人。

【547-0007】資持記/08a_中二#62
【原文】文據過量，且云得蘭；不乞妨難，應具四罪；即《注戒》云：為他成者，二蘭二吉是也。五中。且據具有為言，《注戒》云：互相有無，隨其所犯。不犯中。八相三類。前二種翻犯明不犯〔《注戒》更有如量，僧處分，如法絣地，共上成五。〕；佛圖等四，非專己故；
【譯文】律文針對超量這一點，暫且說是結偷蘭遮罪；如果加上沒有乞法以及處所存在妨礙危難，照理就應當具足四種罪過；這就是《注戒》所說的：替他人建造過量房舍者，犯兩個偷蘭遮罪與兩個突吉羅罪。在第五部分中，暫且是就過失與違規條件全都具備的情況來論罪，《注戒》說：各個條件彼此或有或無，應當隨其具體觸犯的情況來判定罪名。在不犯的情況中，共有八種相狀，歸納為三種類型。前兩種是從反面翻顯犯相來闡明不犯〔《注戒》中另外還列出「符合法定尺寸」、「得到僧團處分」、「如法拉線規劃土地」，連同上述合為五種〕；建造佛塔等四種建築，是因為並非為了專供自己個人享用；

【547-0008】資持記/08a_中二#63
【原文】草庵等二，非過量故。第七。〔佛在俱睒彌國，王為闡陀造房，斫路中神樹，人訶，田制。〕此由有主，大小從他，故無過量；但恐妨難，特制自專，故分二戒。釋中，初科。制意同者，此既有主，無擾二趣；然據緣起，事異義同。釋第二中，初句示所屬。前房自作，屬己無疑。

【原文】此既有主，恐謂未有所屬，故特標簡。若下，明有緣隨用有二，初明自判。若死，謂將死也。不許賣地，緣是僧物；必是私有，理亦應通。僧不許賣，常住常住物故；房僧得罪，若賣成盜故。〔前房賣用應同，此房受用亦制。但文互現耳。〕若房下，明不自判。可解。六中。列罪，須知有無不定。
【譯文】這座房舍既然已有主人，唯恐大家誤以為是無主之物，所以特別標明以作甄別。「若」字以下，說明遇到特殊緣故而隨機處理，分為兩部分：首先說明自己生前預先處置。「若死」是指臨終將死的時候。不允許變賣土地，是因為這屬於僧團常住物；如果確實是私人物品，按理也是可以通融處置的。僧團之所以不允許變賣，是因為它是永久常住之物；房主僧人結罪，是因為若將土地變賣便會構成盜戒之罪。〔前面提到房舍變賣使用應當相同，這座房舍的受用也受到限制，只是文句在不同處互相照應罷了。〕「若房」以下，說明生前未作處置的情況，文義容易理解。在第六項中列出罪名，必須明白罪名並非固定，而是依情況有無而定。

【原文】準疏古解有二。初約體淨，彼據戒本非波羅夷為證。次師約想淨，即如鈔引；文中，初出彼所立；故下，準疏是今師引破；彼云：無餘是重，作是曾犯。是則明知有犯，亦成謗罪，豈須想淨耶！今師但據自無三根，不論彼境淨穢；循古引示，而非所取，故別立第二。
【譯文】依照律疏，古德的解釋有兩種：第一種是從對象本體清淨來論，依據是戒本中明言「非波羅夷罪」作為證明。第二位律師則從主觀認定其清淨來論，就如《行事鈔》所引用的；文中首先列出該師的主張；「故」字以下，依照律疏是今師引述來予以駁斥；《戒本疏》中說：無餘罪是重罪，這樣做就是曾有犯戒行為。由此可知明知對方有犯，說出來也構成誣謗罪，哪裡需要主觀認定其清淨呢！今師只依據自己並無見、聞、疑三根作為依據，不論對象境緣是否清淨；引述古說只是順帶展示，並非所採納的觀點，所以另外確立了第二個犯緣。

【原文】八前人知者，但取所對，不必所謗。釋中。論明謗者強戾，僧折伏法。初教僧詳緩。若下，出彼請判。論具云：若言眾僧為我判此罪莫停；若是者，我當受持；若不是，我不受。〔受即執也，此是兩向求斷之語。〕僧下，示折伏法有三，初教遷延。暝即暗也。猶下，次令出界。如是覓寺下，後明為斷。懦，柔弱也。
【譯文】第八項「對方知曉」，只針對說話的對象而言，不一定是被誣謗的人。解釋文中，論部說明誣謗者態度強橫暴戾時，僧團用以折伏的方法。首先教導僧眾要審慎寬緩。「若」字以下，說明對方請求裁斷的話語。論中完整說道：如果對方說「請大眾僧為我判斷這項罪名，不要拖延；如果是真的，我應當承受；如果不是，我就不接受。」〔接受就是堅持認同，這是兩頭逼迫求斷的話語。〕「僧」字以下，指示折伏的方法有三種：首先教導拖延時間。「暝」就是天色昏暗。「猶」字以下，其次是命令他移出結界。「如是覓寺」以下，最後說明為他裁斷。「懦」是指性格柔弱。

【547-0015】資持記/08b_中二#7
【原文】不犯中，初通示。實有下，別簡五實。具五成開，闕一成犯。第二約心，餘皆約境。真實者，字誤；準疏作真境實，謂所對不謬也。想實者，想心謂不淨也。若下，總結。論開須具五實，反犯止在一虛。後引二律。別證第五，縱知實犯，互亦成謗。第九。〔慈地因見羊行淫，便言羝羊如沓婆，母羊如慈地尼；向諸比丘，我今親見，非前無根，因此而制也。〕
【譯文】不犯條款中，首先作普遍說明。「實有」以下，分別挑選出五種真實情況。具備這五種便構成開緣，缺少一種便構成犯戒。第二項是依據內心，其餘各項都是依據境緣。「真實」二字有傳抄錯誤，依據律疏應作「真境實」，意思是所面對的對象並無錯誤。「想實」是指心裡認定對方並不清淨。「若」字以下作總結。依論而言開緣必須具備五種真實，反過來說犯戒只要在一項上虛妄即可。後面引述兩部律典，特別證明第五項，即使明知對方確實犯戒，彼此互換情節舉發也同樣構成誣謗。第九條戒。〔慈地比丘因為看見公羊與母羊行淫，便說這隻公羊好比沓婆，母羊好比慈地比丘尼；他向諸位比丘說，我現在親眼看見，絕非先前那樣無憑無據，佛陀因此而制定此戒。〕
