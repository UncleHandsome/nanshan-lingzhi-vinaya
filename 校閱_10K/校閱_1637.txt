# 校閱材料　第1637檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】初僧法中，文義為二。恐人懷疑非相徒設，故依律本具解七非；非相眾多，隨文叵盡，故又從義用收諸非
【譯文】在最初的僧法之中，分為經文與義理兩個部分。恐怕人們懷疑非法之相只是徒然虛設，所以依照律典原本（律藏正文）具體解釋「七非」；非法的行相非常繁多，隨著律文無法說盡，所以又從義理的角度來收攝各種非法。

【譯文】在僧法分文之中，只有僧法中同時具備文與義，其餘兩種別法只有義理上的非法。自「恐」字以下，敘述同時列出文與義的原由。

【1637-0005】03_業疏/06a_卷一之六#19
【原文】就前七非，疏有大義。彼從文故，科約稍煩；今但舉名，審其體相，行事委識，得離便止。四門張之：一、列數釋名體，二、分總別，三、體有無，四、攝非相。此即是上羯磨義中末下門也
【譯文】就前面的七非而言，《律疏》有宏大的義理。因為彼疏順著經文解釋，所以科判條目稍微繁瑣；如今只舉出其名稱，審察其體性行相，使臨事行持時能詳細熟知，能夠遠離非法也就達到目的了。將它開展為四門：一是列出數目並解釋名稱與實體，二是區分總與別，三是辨析體性的有無，四是收攝非法的行相。這也就是上面羯磨義章中最後一門。

【1637-0006】03_業疏/06a_卷一之六#20
【原文】僧法文非敘意中，「疏」即首律師疏，彼解廣律，故曰從文。名及體相，義門自顯。「此下」對指，即前總義能辨教中第四廣顯非相也
【譯文】在「僧法文非敘意」之中，「疏」是指智首律師的《四分律疏》，他解釋廣律，所以說順從律文。名稱以及體相，在義理門中自然會彰顯。自「此」字以下對應指陳，就是前面總義「能辨教」中第四門「廣顯非相」。

【1637-0008】03_業疏/06a_卷一之六#22
【原文】言列數者，非出昏情，事通凡聖。述緣約於眾法，語失墜於四心。隨相而言，則不可盡；且從法約，以為七種，其數如文
【譯文】所謂列出數目，非法乃出自於昏昧的情識，其事相則通於凡夫與聖人。陳述因緣則局限於眾僧之法，言語過失則墮入（受、想、行、識）四心之中。若是隨順具體行相來說，則是說不盡的；姑且順從法義加以歸約，列為七種，其數目正如經文所示。

【1637-0009】03_業疏/06a_卷一之六#23
【原文】義說初門列數中，初二句敘非所起。昏情有二：一者愚教，二則迷忘。凡夫具二，望有事述，故云通也。「述」下次明事廣緣約。眾法局三羯磨故，失墜四心通三性故，識、受、想並無記，行兼善惡。隨相之言，通指百三十四眾法。「且」下三明束約，統歸七耳
【譯文】在義理說明的第一門「列數」之中，前兩句敘述非法所由生。昏情有兩種：一是愚昧於教法，二是迷惑遺忘。凡夫二者兼具，相對於有所造作陳述，所以說通於凡聖。自「述」字以下，接著說明事相廣大而因緣有所歸約。眾僧之法局限於三種羯磨，而有過失之語墮於四心，則通於善、惡、無記三性，識、受、想三陰皆是無記，行陰則兼有善與惡。「隨相」這句話，通指一百三十四種眾僧羯磨法。自「且」字以下，第三說明約束歸結，總體歸為七種罷了。

【1637-0010】03_業疏/06a_卷一之六#24
【原文】二釋名者，據律以相取名，今以義求。作無軌要，號曰非法；體非教制，名非毗尼。言羯磨者，若是入非，不名羯磨；今得名者，以非法非律被他作業，故曰也。或可作業通於善惡，是名非法羯磨。餘六非名，大途略爾。若解隨名，如下文中；若竪義者，引從此述
【譯文】第二「解釋名稱」，依據律典是按行相來取名，如今則依義理來探討。造作之時無有軌則綱要，稱為「非法」；本體不符合戒律制定，名為「非毗尼（非律）」。所謂「羯磨（辦事作業）」，如果陷入非法之中，按理不名為羯磨；如今之所以得名，是因為以非法、非律加之於他人而進行作業，所以如此稱呼。或者可以說，作業通於善與惡，所以名為非法羯磨。其餘六種非法的名稱，大體概況也是如此。如果要隨名稱作解釋，如隨後的下文所述；若要豎立義理框架，則應當引入遵從此處的論述。

【1637-0011】03_業疏/06a_卷一之六#25
【原文】釋名中，前釋初名。「非法」約事乖，「非毗尼」據違教。「羯磨」兩釋：初取被事釋，後約惡法釋。「餘」下次指後六，羯磨通號，下六並同。然「非法別眾」、「法相似」等六種別名，無非乖事違教，故云「大途略爾」。仍指釋文，令先引說
【譯文】在「釋名」中，前面解釋第一個名稱。「非法」是就事情乖違而言，「非毗尼」是依據違背教制而論。對於「羯磨」有兩種解釋：先就所被之事解釋，後就惡法解釋。自「餘」字以下，接著指示後面的六種非，羯磨是通稱，下面六種均同。然而「非法別眾」、「法相似」等六種個別名稱，無非都是乖違事情、違背教制，所以說「大體概況略微如此」。並指引後續的解釋文句，讓人先引述說明。

【原文】三定體中為三：初約文，二約事，三約業
【譯文】第三「判定體性」中分為三部分：一是依據律文，二是依據具體事情，三是依據業性。

【1637-0013】03_業疏/06a_卷一之六#27
【原文】初約文者，即律所出，單就白二、白四以明七非。單白非者，但具於五，以無羯磨闕二似故。所以如大疏辨，此非體所起在三羯磨，餘約相出，具如文解
【譯文】第一「依據律文」，就是依律典所出，單純就白二羯磨、白四羯磨來說明七非。單白羯磨的非法，只具備其中的五種，因為它沒有羯磨正文，欠缺「法相似別眾」與「法相似和合」這兩種似法的緣故。其原因正如《大疏》所辨明，這七非體性的生起是在三種羯磨之中，其餘則是依據具體行相顯現，詳具如文中解釋。

【1637-0014】03_業疏/06a_卷一之六#28
【原文】定體中，初約文者，即三羯磨以明非體。初敘文，初非略舉單白，後非通含，中間五非並二羯磨，故云「單就」等。單白具五，例準明之。以白與羯磨互倒名法相似，單白獨作，義無二似，廣在律疏，故指如彼。「此下」次義決，須該三法，但具闕耳。「餘約相」者，即指文中不從義也
【譯文】在「定體」中，第一「依據律文」，就是依據三種羯磨來說明非法的體性。首先敘述經文，第一非略舉單白，最後一非通相包含，中間五非都具備兩種羯磨，所以說「單就」等。單白具足五非，依此比例可以明瞭。因為白文與羯磨文互相顛倒才稱為「法相似」，單白法是單獨秉作，義理上沒有兩種似法，詳細論述在《律疏》中，所以指引如彼。自「此下」字以下接著從義理上決斷，必須涵蓋三種羯磨法，只是具足與欠缺不同而已。「餘約相」，就是指經文之中不順從義門推演之處。

【1637-0017】03_業疏/06a_卷一之六#31
【原文】如初非中三種俱非：僧舉僧等，人也；羯磨增減，法也；無病有藥，事也。次五人法相對明非，末下單就如法明非。就中五內，位又分三：非、似二別，人法俱非；非、似二和，法非人是；法別眾者，是人非
【譯文】例如在第一非中，三種全都落於非法：僧人舉發僧人等，是人不如法；羯磨文辭增減，是法不如法；無病而妄用藥，是事不如法。接下去的五種是非，是就人與法相對來說明非法，最後一種非則是單就如法羯磨而言非法。在中間五種非之中，位次又分為三類：「非法別眾」與「法相似別眾」這兩種別眾，是人與法全都非法；「非法和合」與「法相似和合」這兩種和合，是法非法而人是如法的；「法別眾」這一種，則是法如法而人非法（法是、人非）。
