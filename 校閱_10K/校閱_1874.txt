# 校閱材料　第1874檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1874-0001】03_業疏/20b_卷四之三#20
【原文】四中，初牒釋注中人解忘成及界不開中安居。「有」下次引義決，制開四法竝通三位，指前義門對之可解
【譯文】在第四項中，首先提引解釋注文中他人對於「遺忘而成立」以及「結界不開許」中安居的理解。自「有人言」以下，接著引述義理予以決斷，指出制與開的四種法則都通於前、中、後三種安居位次，對照前面的義門便可理解。

【1874-0002】03_業疏/20b_卷四之三#21
【原文】二明出界行法。律中有五：初受日出法，二命梵移法，三和護餘緣，四受出逢難，五無緣經難不來成敗。就總分二：前一有法開出，後四無法為緣
【譯文】第二、說明出界行法。律典中共有五種：第一是受日出界法，第二是為救護命難與梵行難的移界法，第三是為和合僧眾與護法的其餘因緣，第四是受日出界遭遇災難，第五是無正當因緣而經歷災難不回來的安居成敗。就整體而言分為兩大類：前一種是具備白法羯磨而開許出界，後四種則是不作羯磨白法而純以事難為因緣。

【1874-0003】03_業疏/20b_卷四之三#22
【原文】二受日分門中，初列章，一、二及四即牒本文，餘二義章對之自見。「就」下總分。若據第四初亦有法，望後逢難是無法耳
【譯文】在第二「受日分門」中，首先列出章目，第一、第二及第四項即是提引律文原本的文句，其餘兩項是依義理立出的章目，對照之下自然明瞭。自「就總分二」以下做總體的分門。如果依據第四項，最初出界時也是有受日法的，但相對於後面遭遇災難而言，則算是因難無法罷了。

【1874-0004】03_業疏/20b_卷四之三#23
【原文】初又分二：對首、眾法也
【譯文】第一項又分為兩種：對首法與僧眾法。

【1874-0005】03_業疏/20b_卷四之三#24
【原文】且總簡約四種不同：一對人，二約界，三前後，四相攝
【譯文】且先總體甄別歸納為四種不同：一是針對受法之人，二是約定所依之界，三是受法的前後次第，四是諸法相互含攝。

【1874-0006】03_業疏/20b_卷四之三#25
【原文】初中七日法者，別人所持；羯磨眾法，唯僧所作。互秉不成
【譯文】在第一項中，七日法是個人對首所持受的；羯磨眾法，則唯有僧眾才能作。彼此互換秉持就不能成就。

【1874-0007】03_業疏/20b_卷四之三#26
【原文】受日總簡對人中初文，眾、別三位，對緣長短，不可濫用
【譯文】受日總體甄別中針對「對人」的首段文字，指明眾法與別法三種位次，是針對事緣時間的長短而設，不可混淆濫用。

【1874-0008】03_業疏/20b_卷四之三#27
【原文】今亦有人對首受一月者，愚教人也。知何不為，猶知受法，此癡而作
【譯文】如今也有人以對首法受一個月的，這是愚昧不知教理的人。真不知他們有什麼事做不出來（肆意妄為而無所不為），只略知要受法，這是愚癡盲目而作。

【1874-0009】03_業疏/20b_卷四之三#28
【原文】次文，愚教自任，故無不為也。知受昧法，故是癡也
【譯文】下一段文字指出：由於愚昧於教法卻自以為是，所以無所不敢為。雖知應當受法卻昧於律法軌則，所以是愚癡。

【1874-0010】03_業疏/20b_卷四之三#29
【原文】十誦》應界內從五眾受七日也。計互非所足，何得從受？此立法通文，如五眾安居，例此各從所位也
【譯文】《十誦律》說：應當在界內從五眾受七日法。考量五眾彼此並非皆具足所對之位，怎能互相從彼受法？這是立法時通貫的文辭，就如五眾各自安居一樣，比照此例，應當各自從所屬的階位受法。

【1874-0011】03_業疏/20b_卷四之三#30
【原文】三中，初引文云「從五眾」，在言頗混。「計」下決通。「立法通文」，謂通開五眾皆得受日也
【譯文】在第三點中，首先引述律文說「從五眾」，文句上頗易引起混淆。自「計互非所足」以下予以決斷通達。「立法通文」，是指通泛開許五眾皆得受日。

【1874-0012】03_業疏/20b_卷四之三#31
【原文】二對界者：七日既是別人，兩界通成；羯磨須作法界也
【譯文】第二、就所依之界而言：七日法既然是個人對首所持，在自然界與作法界兩者中皆能成就；而羯磨眾法則必須在作法界中舉行。

【1874-0013】03_業疏/20b_卷四之三#32
【原文】二界可解
【譯文】第二項關於界限之理，容易理解。

【1874-0014】03_業疏/20b_卷四之三#33
【原文】三先後者：昔人云先受七日，後便十五日，以文云「受過七日法」等
【譯文】第三、受法的前後次第：古人說應當先受七日法，之後才受十五日法，因為律文中有「受過七日法」等文句。

【1874-0015】03_業疏/20b_卷四之三#34
【原文】三中初科，古謂三法次受，不通差互，仍執牒緣，究文不細
【譯文】第三項的第一科中，古德認為三種法必須依序受持，不能錯亂參差，仍然執著於作法所陳的事緣，這是審究律文不夠細緻所致。

【1874-0016】03_業疏/20b_卷四之三#35
【原文】今解不然：本未有緣，何得妄受？隨事有無，前後皆得。文列「過七日」者，立法限約，豈有事也？此羯磨法是過七日緣耳，非謂曾用今受月也
【譯文】現在的解釋並非如此：本來尚無事緣，怎能虛妄受法？應當隨事緣的實際有無，受法在先在後都可以。律文中列出「過七日」的字句，是立法時所定的期限標準，哪裡是指具體的事實？這項羯磨法只是針對「超過七日的事緣」而設，並非是指以前曾經受用七日、現在才來受一個月。

【1874-0017】03_業疏/20b_卷四之三#36
【原文】次科初斥古非。「隨」下顯今義。「文」下釋妄執，謂文中「過」字乃是過法之過，非過前也
【譯文】下一科首先駁斥古解的錯誤。自「隨事有無」以下顯明今家的正義。自「文列」以下解釋古人的妄執，說明律文中的「過」字乃是指超過法限之「過」，而非指經歷過前面的「過」。

【1874-0018】03_業疏/20b_卷四之三#37
【原文】四相攝者：謂先受七日，更受一月，攝而通用
【譯文】第四、所謂相攝：是指先受了七日法，接著又受一個月，彼此含攝而通用。

【1874-0019】03_業疏/20b_卷四之三#38
【原文】四中初標，通含古今兩意
【譯文】第四項中首先標出名目，普遍涵蓋了古解與今義兩種觀點。

【1874-0020】03_業疏/20b_卷四之三#39
【原文】有人言：前受七日用竟不論，若受未用即羯磨受，攝前對首入在眾法，以法強故。若前羯磨受日用盡，方得更受七日法也，以一身中無二法現故。文云「不及即日還受七日」也，又「不及七日還用羯磨法」，然今七日未盡，何得以羯磨受？明知相攝
【譯文】有人說：先前所受的七日法如果已用完則不須論究；若是受了尚未使用就以羯磨法受日，則會將先前的對首法攝入眾法之中，因為眾法的力量較強。如果先前羯磨受日的天數已經用盡，才可以再受七日法，因為一身之中不能有兩種法同時顯現。律文說「來不及當日返回者，聽許受七日法」，又說「來不及七日返回者，改用羯磨法」，然而如今七日尚未滿，怎能又以羯磨受法？由此顯知是二法互相含攝。

【1874-0021】03_業疏/20b_卷四之三#40
【原文】次科他解中初立義。別法是弱，眾法為強，先別後眾則攝弱歸強，前眾後別則強能禁弱。「以」下示意，仍據律文，不善其意
【譯文】下一科在引述他人見解中，首先確立其義理：別法微弱，眾法強大，若先別後眾便是攝弱歸強，若先眾後別則是強法能禁制弱法。自「以一身中」以下說明其意圖，雖然依據律文，卻未能善體其深意。

【1874-0022】03_業疏/20b_卷四之三#41
【原文】今解云：不無此理也。但本是一緣，不得有長短二法，可如前判；今前後別緣，各依受日，前法被事，事未是息，何得失法？如為患事須服酥油，兩緣未差，口法隨在。律列三品受法不同，竝約眾緣不可受用，故不及即日例用七收。明知以法收緣，依緣法則隨有也
【譯文】現在的解釋是：並非沒有這種道理。如果原本只是一件事緣，確實不能同時存在長短兩種法，那就可如前面那樣判定；如今若是前後各自有別的事緣，各自依事緣受日，前法所針對之事尚未止息，怎會失卻其法？如同為了治病必須服用酥油，兩種病緣都尚未痊癒，隨服的受藥法則便各自並存。律中列出三種受法品類的不同，都是約定諸種非法因緣不得受用，所以「來不及當日返回」等情況，依例皆以七日法來收納。由此顯知是以法收緣，法乃隨順著事緣而各自存在。
