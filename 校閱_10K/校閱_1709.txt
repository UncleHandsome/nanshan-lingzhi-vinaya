# 校閱材料　第1709檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1709-0001】03_業疏/10b_卷二之四#86
【原文】前相中如俱舍論分別者，即義門末也。故彼文云：戒分三位：前四名戒分，離性惡故；次一名為無放逸分，若善受戒，由飲酒故，擾動諸學處故；後三名修分。若不受下二分，有何過？由飲酒故，即便忘失是事非事念也。離莊嚴者，謂非舊莊嚴也，若常所用莊嚴，不生極醉亂心也。若用高勝臥處及歌舞音樂，隨行一事，破戒不遠也。若依時食，離先所習非時食也。憶持八戒，即起厭離隨助之心；若無第八，此二不生也
【譯文】前面的戒相中如同《俱舍論》所分別的，就是義門的最後一部分。所以該論之文說：八戒分為三類：前四條稱為「戒分」，因為遠離性罪之惡的緣故；接下來的一條稱為「無放逸分」，如果妥善受戒，若因飲酒的緣故，就會擾亂動搖各項學處的緣故；後三條稱為「修分」。如果後面的這兩分（無放逸分與修分）不加受持，會有什麼過患呢？因為飲酒的緣故，就會忘失對正當事與非當事（是事與非事）的憶念。遠離妝飾裝嚴，是指並非日常舊有的莊嚴飾物，如果是平常所用的裝束莊嚴，不會生起極度沉醉迷亂之心。如果使用高大殊勝的臥處以及觀聽歌舞音樂，隨便實行其中一件事，離破戒就不遠了。如果依時飲食，就能遠離先前所習染的非時進食。憶念受持八戒，就能生起厭離世間與隨順助成道業的心；如果沒有第八條過午不食，這兩種心就無法生起。

【1709-0002】03_業疏/10b_卷二之四#87
【原文】列相總示中初科，初標指。由八戒相諸出不同，文依《俱舍》，故須標定，即前義門第五顯戒相也。「故」下引論判釋，初、通分三分。「諸學處」，即前後諸戒；「修分」，謂約事䇿修，助成性重故。「若」下次別顯後二，初反徵，「由」下顯過，又二：初、明第二分，酒能亂性，不辨是非，容犯諸戒故；「離」下次明第三分，次第三戒各顯過失。「非舊莊嚴」，謂華瓔等俗中常習是舊莊嚴，今竝離之，但存常所服用，故云「非」也；高牀長慢，樂音動情，皆近破戒；依時食者，即不過中；憶八戒者無他念故，即滅惡也；起猒離者不樂世緣，即生善也；若不節食，飽腹嗜味，故二心不生也。
【譯文】在列出戒相予以總括指示的第一科中，首先標示指明。由於八戒的戒相在各經論中所載不同，疏文是依據《俱舍論》，所以必須標示確定，這就是前面義門第五門顯明戒相的內容。「故」字以下引用論典予以判別解釋，首先普遍劃分為三分。「諸學處」，就是前後的各條戒律；「修分」，是指就具體事相策勵修持，用以助成防範根本性罪之重的戒法。「若」字以下接著分別顯明後兩分，先反向徵問，「由」字以下顯明過患，又分為兩部分：第一、說明第二分（不飲酒），因為酒能擾亂心性，無法分辨是非，容易毀犯諸戒的緣故；「離」字以下接著說明第三分，依序就後面的三條戒各別顯明其過失。「非舊莊嚴」，是指花鬘瓔珞等世俗中常習以為常的是原本的盛妝莊嚴，如今全部遠離，只保留平日所穿著佩戴的衣物，所以說「非」；高大的床榻助長驕慢，音樂之聲觸動情欲，都接近於破戒；依時進食，就是不超過正午進食；憶念八戒則沒有其他妄念，這就是滅除惡業；生起厭離之心就不樂著於世俗塵緣，這就是生起善法；如果不知節制飲食，飽食腹脹貪嗜美味，那麼這兩種善心便無法生起。

【1709-0003】03_業疏/10b_卷二之四#88
【原文】有離非時食，餘為八戒，以開觀歌舞及莊嚴為二，此本論不同。增一中不過時食為第六，合前嚴身及觀樂也。若依多論，齋以過中不食為體，八事照明，故成齋體，共相支持，名八支齋，故言八齋，不言九也。若已受齋，鞭打眾生，雖即日不行，待明當作，皆齋不淨。以要言之，若身口作非威儀事，即名不淨；若心起貪、瞋、害覺，雖不破齋，齋不清淨；若不修六念等，亦名不淨
【譯文】有的論典將遠離非時食除外，其餘列為八條戒，這是將觀聽歌舞與身著莊嚴分開為兩條，這與本論（《俱舍論》）不同。《增一阿含經》中將不過中食列為第六條，合併了前面的嚴飾身體與觀聽娛樂。如果依據《薩婆多論》，齋戒是以過午不食為實體，其餘八事輔助照明，因而成就齋戒之體，共同相互支持，稱為八支齋，所以稱作「八齋」，不稱「九齋」。如果已經受了齋戒，卻想要鞭打眾生，即使當天不行鞭打，等待明天再做，都屬於齋戒不清淨。概括而言，如果身業和口業做出違背威儀之事，就稱為不淨；如果內心生起貪欲、瞋恚、惱害等妄覺，雖然沒有破壞齋戒，但齋戒已不清淨；如果不修持念佛、念法、念僧等「六念」，也稱為不淨。

【1709-0004】03_業疏/10b_卷二之四#89
【原文】次科，初云「有離等」即是《多論》，謂非時之外，展七為八，則有九支。開歌舞莊嚴者，對下《增一》合為一故。「此本論」者，即文中所列，是依《俱舍》，以合高牀、觀樂為一，故云不同。《增一》中列數則同，離合、列次與今全異。《多論》列數如前文中，但出離開之意，謂一日節食，以八事檢束，方顯清心奉齋之行，故云照明等。支持，猶佐助也。上示名體。「若已下次」明持奉，有三：初身口犯，「待明當作」，即要期業；「若心下」二明意犯，違情故嗔，惱他為害，上二皆作犯；「若不下」三明止犯，以受戒者當須逐日念佛、法、僧及天、戒、施故
【譯文】第二科，開頭說「有離等」指的就是《薩婆多論》，也就是在非時食之外，將其餘七條展開為八條，就共有九支。展開歌舞與莊嚴為兩條，是相對於下文《增一阿含經》合二為一而言。「此本論」，就是疏文中所列的，是依據《俱舍論》，因為將高床與觀樂合為一條，所以說不同。《增一阿含經》中排列的數目雖然相同，但分合與次序則與現在所依完全不同。《多論》排列的數目如同前面文中所述，只是說明分開列出的用意，是指在一日之中節制飲食，以八件事來檢點約束，才能顯現清淨其心奉持齋戒的戒行，所以說照明等。「支持」，就如同輔助的意思。以上說明了名稱與實體。「若已下」接著說明受持奉行，共有三點：第一是身業與口業的毀犯，「待明當作」，屬於立下誓約日後造作的業；「若心下」第二說明意業的毀犯，違背己意便起瞋恨，擾惱他人便是惱害，上面兩種都屬於「作犯」（有所造作而犯戒）；「若不下」第三說明「止犯」（應當做而不做而犯戒），因為受戒之人應當每天憶念佛、法、僧以及天、戒、布施的緣故。

【1709-0005】03_業疏/10b_卷二之四#90
【原文】就相文中，隨戒文二：初「如諸佛至不殺生」，舉勝境所行也；二「某甲已下」，引已上同，問答之相，顯成持誓。有本云「我某甲一日夜不殺生亦爾」者，直述己契，上同於佛，不假問答，亦成說相。餘竝準此
【譯文】在戒相之文中，每條戒的文句分為兩部分：第一是「如諸佛乃至不殺生」，舉出殊勝對境（諸佛）所持的行持；第二是「某甲已下」，引導自己向上等同於佛，藉由問答之相，顯發成就持戒的誓願。有的版本說「我某甲一日一夜不殺生亦爾」，是直接敘述自己的誓約，在向上等同於佛，不藉助問答，也成就了宣說戒相的作法。其餘各條戒都依此類推。

【1709-0006】03_業疏/10b_卷二之四#91
【原文】別釋中初科為三：初分文。云「諸佛」者，已經開顯，得通指故。「有下次」點別本。已契謂要誓也。「餘下」三指例
【譯文】個別解釋中的第一科分為三部分：第一是劃分文句。說「諸佛」的，是因為已經過法華開顯，得以普遍通指的緣故。「有下」次點明其他版本。「己契」是指立下的誓願。「餘下」第三是指示依此類推。

【1709-0007】03_業疏/10b_卷二之四#92
【原文】第三、婬戒者，以自他俱遠故。有人云「邪婬」者，此五戒相，由制他開自故；八戒云「邪」者，誤也
【譯文】第三、淫戒，是因為對自己的配偶與他人的配偶都一概遠離的緣故。有人說成是「邪淫」，這本是五戒的戒相，因為五戒是制止侵犯他人而開許自己的夫妻正淫；八戒若說成「邪淫」，那是錯誤的。

【1709-0008】03_業疏/10b_卷二之四#93
【原文】第三中，初正釋。五戒斷他妻，八戒二俱斷。「有下次」指誤。今世有授五戒反除邪字，愚教人也
【譯文】第三戒中，首先正式解釋。五戒是斷除侵犯他人妻子，八戒則是兩者全都斷除。「有下」接著指出錯誤。現今世上有人傳授五戒時反而去掉「邪」字，這真是愚昧地教導他人。

【1709-0009】03_業疏/10b_卷二之四#94
【原文】第五戒相，有人加辛肴者，正文無此。既受淨身，焉噉羶臭？理不可也
【譯文】第五條戒的戒相，有人加上五辛與葷肉（辛肴），佛經正文中並無此說。既然已經受持清淨之身，怎會去食用羶腥臭穢之物呢？在理情上絕不可如此添加。
