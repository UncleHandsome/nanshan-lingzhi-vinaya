# 校閱材料　第957檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【957-0001】資持記/02f_上一下#1
【原文】一非法非毘尼羯磨，二非法別眾羯磨，三非法和合羯磨，四如法別眾羯磨，五法相似別眾羯磨，六法相似和合羯磨，七訶不止羯磨。略示中二，初正示是非。謂下三句，明是。別相，即法所攝事。若下四句，明非。如但心念，止齊三事；若加餘事，即是非攝。
【譯文】第一、非法非毘尼羯磨；第二、非法別眾羯磨；第三、非法和合羯磨；第四、如法別眾羯磨；第五、法相似別眾羯磨；第六、法相似和合羯磨；第七、訶不止羯磨。在略要說明的文字中分為兩部分，首先是正面指出正確與錯誤。鈔文「謂」字以下的三句，是說明正確的情況；其中的「個別名目（別相）」，就是該僧事儀軌所包含的特定事項。鈔文「若」字以下的四句，則是說明錯誤的情況；比如單純的心念羯磨，範圍只限於三件事，如果加入其他事項，就屬於錯誤的範圍。

【957-0002】資持記/02f_上一下#2
【原文】乃至白四唯被三十八事，若加說恣差結等事，即名非法。如是八位，例之可知。此謂約法加事，交互彰非，欲使初學略識其相。若欲下，指義七非。言通知者，上文但明法非；未顯下三皆有非故。此門者，總指相攝一科。上下，即前後四位。各有非相，隨位總收，故云橫括；
【譯文】乃至於白四羯磨只能用於三十八種僧事，如果擅自加入說戒、自恣、差派人員或結界等事，就稱為非法。像這八個範疇，以此類推便能明白。這是指根據僧事儀軌擅自添加事項，彼此交錯而顯出過失，目的是要讓初學者大致認識其形式。下文說到「若欲」之處，是指七種非法的義理。之所以說「通通必須了解（通知者）」，是因為上文只說明了儀軌本身的過失，尚未顯明儀軌之外的其餘三種條件也各自存在過失。這裡所說的「這個門類（此門者）」，是總括指稱互相關聯相涉的這一科判。上下兩方，也就是指前後的四個範疇。它們各自具有非法的表現，隨著各個範疇全部收攝，所以說是「全面涵括（橫括）」；

【957-0003】資持記/02f_上一下#3
【原文】即如下科單複為句，其相可見。庶，望也。貳，異也。釋別號中。古執羯磨名局眾法，故須決之。答中，本宗二文。初出受法。已興白四，即斷三語。舍利弗問云：三語受戒，是善作羯磨否？佛言是善作羯磨；自制已後，不名受具足。及下，即〈說戒〉中。彼因六群說戒日與諸白衣言語問訊作羯磨〔即五戒三歸。
【譯文】也就是如同下一個科判所列，以單一或複合形式組合成句子，其中的表現型態十分清楚。所謂「庶」，是期盼的意思；所謂「貳」，則是相異、生疑的意思。在解釋個別名稱（釋別號）的段落中。古代學者執著地認為羯磨這個名詞只限定於大眾僧事，所以必須予以辨正決斷。在解答的內容中，引用了本宗的兩處文獻。首先引出受戒之法。既然已經興起了白四羯磨，就隨之廢止了三皈依受戒。舍利弗尊者曾發問說：以三皈依來受具足戒，算不算是妥善成就的羯磨呢？佛陀回答說：確實是妥善成就的羯磨；但自從制定白四羯磨以後，就不能再以此稱為受具足戒了。接著下文引用〈說戒犍度〉的內容。那是因為六群比丘在說戒之日，向許多在家白衣說話、問訊並舉行羯磨〔也就是傳授五戒與三皈依〕、

【原文】說戒〔即五戒相。〕，說法；佛言此是上座應作。以三語五戒兩竝對人，且證對首。下引《十誦》雙證二法。彼明疑問，佛為決之。羯磨下，續云後來比丘不與分。第二明事有三：一情事，二非情事，三二合事。百八十四，此三攝盡。標指中，由前八法各出別相，故云不重。
【譯文】說戒〔也就是宣說五戒的具體行相〕、說法；佛陀說這些事情應當由上座來做。因為三皈依受戒與傳授五戒這兩者，都是單獨面對一個人進行的，以此暫且證明有對首羯磨的存在。下文又引用《十誦律》同時證明這兩種法。那裡記載了生起疑問的情況，佛陀親自為大眾決斷。在羯磨的文句下方，接著記載說後來的比丘不再分給僧物。第二部分說明羯磨所針對的事由，共有三種：第一是涉及有情眾生的事（情事），第二是不涉及有情的事（非情事），第三是兩者混合的事（二合事）。一百八十四種僧事，全部被這三種涵蓋窮盡。在提綱標示的文字中，由於前面八種法已經各自列出個別形態，所以說「不再重複」。

【957-0005】資持記/02f_上一下#5
【原文】正辨中，初科為二，初示體相。文標二事，二合在中。竝下，明是非。以人法及界，各局自分；事涉多種，非相不一，故云一緣等。且如受戒，遮難衣資發心陳乞；又如治舉，窮勘三根，作舉憶念；如是求之。別示，徵中。也合作耶。情事中，初科引文有二，初引人法者。彼因比丘犯二僧殘，二俱覆藏；
【譯文】在正式辨析（正辨）的段落中，第一個科判分為兩部分，首先提示體性與外相。經文中標示了兩種事，而兩者混合之事已包含在其中。下文「一同（竝）」等字，是在說明正確與錯誤。因為參與的人、儀軌以及結界，各自局限在自身的本分；然而所涉及的僧事類別繁多，非法的樣態也不盡相同，所以才說是「同一個因緣等」。暫且以受戒為例，包含了遮難、衣物資具、發起道心以及親自陳情祈請等項目；又比如舉治罪過，必須澈底勘查見、聞、疑三根，然後進行檢舉羯磨並令其憶念；應當像這樣去推求考察。在個別指示的徵問中，文句中的「也」字應當作「耶」字。在涉及有情之事的段落中，第一個科判引用的文獻有兩處，首先引用的是〈人法犍度〉的記載。那是因為某個比丘犯了兩種僧殘罪，兩者都加以隱瞞掩蓋；

【原文】如下，二舉事正明，先出非相。若下，明如法。而下，於如中復簡。臣謂伏首。以罪有種相不同，種中造作各異；如摩觸犯殘，首言實犯，然非本時之事；與舉相違，不合加法。〔世傳結界須解妨疑，立義云：縱非曾結，且徒施一法；請觀此文，聖法被事，可虛謬耶。〕非情中。且舉處分。
