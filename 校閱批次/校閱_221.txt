# 校閱材料　第221檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【221-0001】04_比丘尼鈔/04b_卷中之下#18
【原文】毀毗尼戒具五緣犯一是毗尼二前比丘尼誦戒時三作滅法意不令久住四發言毀呰五言了便犯僧祇云僧未說戒時訶越說時訶提說已訶越心悔五分云發心作念令人遠離毗尼不誦而毀呰提若作念木叉令不久住蘭此律若毀阿毗曇契經等犯吉不攝耳聽戒具四緣犯一是廣誦戒時二在眾中坐三作不聽意四說過五篇犯一提僧祇云從序至篇吉隨中間戒一一吉一切不聽止一提此提不得向人悔當於眾中持戒威德敬難者前悔前人應訶治同羯磨賞知事後悔謗僧戒此希故不述具緣婆論云凡僧和合若執苦人大德及貧匱人和合賞已訶者提若外來訶者吉。
【譯文】（毀謗毘尼戒）具備五個條件即構成犯罪：一是對象確實是毘尼戒律，二是正當其他比丘尼誦戒之時，三是懷有滅除戒法、不願讓戒法長久住世的念頭，四是開口譏刺毀謗，五是說完話即犯波逸提罪。《摩訶僧祇律》說，僧團尚未開始誦戒時出言呵責，犯越毘尼罪；正在誦戒時出言呵責，犯波逸提罪；誦戒完畢之後出言呵責，犯越毘尼罪並應在心裡悔過。《五分律》說，若是發心作念想讓人遠離毘尼而不願誦讀，進而誹謗毀蔑的，犯波逸提罪；如果存心想讓波羅提木叉戒法無法長久傳世，犯偷蘭遮罪。依照本律，如果毀謗阿毘達磨論典或契經等，犯突吉羅罪。（誦戒時不專心凝聽戒）具備四個條件即構成犯罪：一是僧團廣泛誦讀戒本之時，二是身在僧眾之中坐著，三是存心不想聽聞戒法，四是誦完五篇罪名後即犯一個波逸提罪。《摩訶僧祇律》說，從戒序開始到各篇章不聽，犯突吉羅罪；在各條戒誦讀過程中若不聽，一條戒各犯一個突吉羅罪；如果從頭到尾完全不聽，只犯一個波逸提罪。這個波逸提罪不得隨便向個別一人懺悔，應當在僧眾中具有持戒威德、令人敬畏的尊長面前懺悔，前人應當給予呵責管教。（參與羯磨賞賜知事僧事後反悔謗僧戒）這種情況非常罕見，因此不詳細列述犯緣。《薩婆多毘尼毘婆沙》說，凡是僧眾和合達成共識，對於操勞僧事的執苦人、德高望重的大德，以及貧窮匱乏之人，僧眾和合給予賞賜之後，事後又出言反悔斥責的，犯波逸提罪；如果是外來比丘反悔呵責的，犯突吉羅罪。

【譯文】（拾取遺落珍寶戒）具備五個條件即構成犯罪：一是貴重的金銀珠寶（無論是自己所有還是他人所有），二是包含各類莊嚴飾物，三是不在自己常住之處或投宿之處，四是雖然沒有偷盜之心、原本打算歸還原主，五是只要動手捉持觸碰即犯波逸提罪。《薩婆多毘尼毘婆沙》說，雖然以撿拾遺失寶物為緣起，但正式犯戒在於觸摸拾取，只要動手拿取珍寶即構成犯戒。本律規定，若是為了供養佛塔寺院的莊嚴器具而牢固收存保管，則不犯戒。《摩訶僧祇律》說，如果看到遺失物品，應當高聲宣告招領；若無人認領，應當懸掛在高處明顯的位置讓人能看見。如果有人前來認領說是他的物品，應當詢問他：「你的東西是在哪裡遺失的？」若回答相符，便如數歸還；如果始終無人相認，應當存放保留滿三個月。如果是在佛塔園區內撿到的，就歸佛塔使用；如果在僧團園區內撿到的，就歸十方常住僧物使用。如果是貴重物品如瓔珞金銀，不能公開顯露出來招領；撿到寶物的比丘應當仔細查驗點算、審慎觀察有何特徵記號，然後妥善收藏起來。有人前來認領且特徵相符時，應當在大眾面前公開歸還，不得在私密處私相授受，並應教授他受持三皈依，對他說：「若不是佛陀制定戒律，你這件東西眼看著是找不回來的。」如果一直無人前來認領，應保存到滿三年，然後依照前面所說的地點，在相應界內充作公用。如果修繕古塔時挖掘土地發現寶藏，如果身邊的淨人不可靠，應當稟報國王知曉；如果淨人可靠，存放保管滿兩年之後，應當充作佛塔修繕使用。如果國王察覺後質問比丘：「你們這裡挖出寶藏了嗎？」比丘回答：「得到了，已經用於這座佛塔的建造修繕。」國王若說：「已經用掉的就罷了，這份功德歸我，剩下的全部還給我。」或者國王質問：「難道你不知道地底下的寶藏都是屬於我的嗎？為什麼全用完了？趕快還給我！」比丘應當拿佛塔的物品變賣償還；如果佛塔無物可抵，應當為佛塔向外化緣償還。如果國王問：「佛陀戒律中是怎麼規定的？」比丘回答：「在佛塔土地上得到的物品就用於佛塔，在僧團土地上得到的物品就用於僧團。」國王若認可遵從佛僧規約而免除追究，則無罪過。《摩訶僧祇律》說，進入聚落中若看到遺失物品，不得自行撿取；如果有人撿到了交給比丘，可以接受，這時對方就算是施主。在聚落中看見風吹飄落的衣服，不得擅自當作無主的糞掃衣去撿取；如果是在空曠無人的道路上則可以拾取。如果衣服上綴有寶物，應當用腳踩住弄斷丟棄，拿著衣服時應顯露拿著讓眾人看見；如果到了住處才發現上面有寶物，應當交給淨人保管，用來抵作縫製衣服或醫藥的費用。《五分律》說，如果比丘寄放衣物滿十二年不來取回，僧團若想處置，應召集僧眾評定價格，歸十方僧眾使用；如果原主後來返回，僧團應以僧物償還給他，如果對方願意放棄不受償，那是最好的。

【譯文】（非時無故進入聚落戒）具備五個條件即構成犯罪：一是時間不合規矩（過了正午的非進食時段），二是沒有事先受請或召喚的因緣，三是沒有向同住同修託付告知，四是走向俗家人的住舍，五是一腳跨進家門即犯波逸提罪。《十誦律》說，如果阿蘭若處的比丘向同修告白後進城入聚落，返回阿蘭若處之後，又憑著剛才的告白再次進入聚落，犯波逸提罪；如果告白進入聚落，從聚落出來到了原來的僧坊，又再次折返進入聚落，也以此前的告白為由擅自進入，犯波逸提罪；在同一結界內若有同修善比丘在，不先向其告白就擅入聚落，犯波逸提罪。不向同修告白的比丘，每經過一條大街或小巷，就各犯一個突吉羅罪；每進入一家白衣舍宅，就各犯一個波逸提罪。如果進入阿蘭若處，或者進入靠近聚落的僧坊，就算不告白也沒有罪過。《薩婆多毘尼毘婆沙》說，如果總體向同修告白要進聚落，之後在聚落中隨意走動前往各處，都不算犯戒。《摩訶僧祇律》說，如果多人結伴在路上行走想要進入聚落，應當輾轉互相告白，然後才可以進入；如果已經抵達住宿之處，又想外出砍取柴草木料，若是沿著原本走的路出去則不犯戒，若是改從其他道路出去卻沒有告白，犯波逸提罪。《大智度論》說，一切在家人居住的房舍都總稱為聚落。《善見律毘婆沙》說，有集市買賣的稱為聚落，沒有集市買賣的稱為村界。依照本律，如果有事先告白，或者受人請託召喚，或者只是趕路途中穿過聚落，都不算犯戒。

【221-0009】04_比丘尼鈔/04b_卷中之下#26
【原文】剃三處毛戒具緣可解母論云剃髮者但除頭毛及鬚餘毛一切不聽却所以剃髮者為除憍慢自恃心不聽利木刀刮汗却毛若斷一一毛一一吉羅除頭上毛不犯若斷餘毛一一偷蘭剃髮有四種次第一上座二髮長三先洗頭四有緣欲行五分云尼過半月不剃髮提涅槃云髮爪長利破戒之相此律不得為白衣剃髮驅使提除欲出家者不犯頭髮極長若兩月若廣二指一剃爪極長如一麥即剪髮不得用剪刀剪半月應剃髮一剪爪違者吉羅聽畜盛髮器十誦云髮當埋坑中若髮長者開畜剃刀及鞘若刀卷者手上波石上磨其石內刀囊中。
【譯文】（剃除三處體毛戒）犯此戒的構成要件容易理解。《毘尼母論》說，出家人剃除毛髮，只能剃除頭髮和鬍鬚，其餘部位的體毛一律不准刮除。剃除頭髮的本意，是為了斷除傲慢與自命不凡之心；戒律不許使用銳利的木刀在刮汗時順便剔除體毛，若是剃斷一根毛就各犯一個突吉羅罪（剃除頭上的毛髮不犯戒）；若是刮斷其餘部位的體毛，每刮斷一根各犯一個偷蘭遮罪。剃髮有四種先後順序：一是按照戒臘從上座先剃，二是頭髮長的人先剃，三是洗好頭的人先剃，四是有要事即將遠行的人先剃。《五分律》說，比丘尼超過半個月不剃髮，犯波逸提罪。《涅槃經》說，指甲和頭髮留得又長又尖銳，是破戒的徵相。依照本律，不得為在家人剃髮供其驅使役使，違者犯波逸提罪；但如果是為發心準備出家的人剃髮，則不犯戒。頭髮長到極限，若是過了兩個月，或者長度達二指長，就必須剃除一次；指甲最長若達到一粒麥子的長度，就必須修剪；頭髮不得用剪刀剪截，每半個月應剃頭一次、修剪指甲一次，違背規矩者犯突吉羅罪。允許蓄備裝盛剃落頭髮的器具。《十誦律》說，頭髮應當深埋在坑穴中；如果頭髮長了，開許蓄備剃刀及刀鞘；如果刀刃捲口，可以在手掌上或砥石上打磨，打磨用的砥石應收納在刀囊之中。
