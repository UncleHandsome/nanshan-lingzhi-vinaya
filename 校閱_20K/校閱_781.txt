# 校閱材料　第781檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【781-0001】03_業疏/04b_卷一之四#94
【原文】觀此五迷，深明四法，微為弘㢡，僅涉僧倫；齊五所收，義歸不足。至於隨法明非，非如霧結，自非博觀，餘復何論？約指通情，如前亦可。且就鈍人，餘如後說
【譯文】審觀這五種愚迷，若能深刻明瞭這四種羯磨法，稍能弘揚勸勉，才勉強算得上踏入僧倫之列；若是落入這五迷所收攝的範圍，在義理上都應歸為不足之數。至於隨著具體法事辨明非法，那些錯謬如同濃霧般凝結叢生，若不是博通博覽之人，其餘的還有什麼可談的呢？簡要指陳、通達情理，如前面所列也就可以了。暫且針對愚鈍之人而言，其餘的留待後文再詳述。

【781-0002】03_業疏/04b_卷一之四#95
【原文】三中初示足不足。觀迷明法，粗可秉宣，未為通博，故云「微」、「僅」。至下次指非相。如霧結者，喻其多也。約指通情，即上五迷。指餘如後，即辨壞中
【譯文】在第三段中，首先指示足數與不足數。能審觀愚迷而明了教法，粗略可以秉承宣揚，但還談不上博通，所以說「微」、「僅」。自「至於」以下，接著指明非法的行相。所謂「如霧結」，是比喻其過失繁多。「約指通情」，就是指上面的五迷。指出其餘如後文所說，就是指在辨析破壞羯磨的篇章之中。

【781-0003】03_業疏/04b_卷一之四#96
【原文】如《僧祇》中有九：一者與欲人堂中作法，通收欲者以入現數；二若隔障，即同在覆，別有遮斷，不見身也；三半覆露，中間隔障；四半覆露，申手不相及；五同在露地，申手不相及。此上五種，是善比丘當時乖相，故非數限
【譯文】如《摩訶僧祇律》中有九種人：第一是給予欲法的人，在堂中作法時，卻將這出具欲法者算入現前人數之內；第二是如果有屏障隔開，即雖然同在屋覆之下，但另有遮斷障礙，看不見其身形；第三是半覆半露（部分在屋簷下、部分在露地），中間又有屏障阻隔；第四是半覆半露，彼此伸手搆不著；第五是同在露地之中，彼此伸手搆不著。以上這五種情況，都是如法的善比丘在當時行相有所乖違，所以不合列在足數的界限內。

【781-0004】03_業疏/04b_卷一之四#97
【原文】僧祇》初科。半覆露者，謂半僧簷下，半僧露地也
【譯文】在疏文引《摩訶僧祇律》的第一科中。所謂「半覆露」，是指半數僧人在屋簷之下，半數僧人在露天地上。

【781-0005】03_業疏/04b_卷一之四#98
【原文】又有行、住、坐、臥更互作句，以義細分，則一行有三，歷作十二，且從四儀，即合前九。然此行等必有餘緣，亦應開許，如立說戒、教授白召、病者輿來，豈同坐也？然須相順，面必向僧，則成開制故
【譯文】又有行、住、坐、臥四種威儀交替互為句式，若依義理細分，則每一「行」對應其餘三者，展轉可作十二句；暫且依隨四種威儀，即與前面合為九種。然而這行等威儀如果有特殊的因緣，也應當開許，例如站立說戒、教授師白告召喚受戒人、患病之人用輿床抬來，難道能與大家一同坐著嗎？然而必須彼此順應，面孔必須朝向僧眾，這就成就了開許與制止的規矩。

【781-0006】03_業疏/04b_卷一之四#99
【原文】次科初列人相。四儀更互者，如行作法，住不足數，坐、臥亦爾，舉一為首，以歷餘三，故成十二。然下次明開緣。若據白召，本是制立；且望相乖，成法為開。病人雖臥，不得背僧，故成開制
【譯文】在下一科中，首先列舉人的威儀行相。所謂四種威儀交替互對，例如以行走作法，站立便不能充數，坐著與躺臥也是如此；舉出一種為首，依次經歷其餘三種，所以構成十二種句型。自「然此」以下，接著說明開許的因緣。如果依據白告召喚，本來就是制定義務必須站立；暫且對照威儀相貌相乖違之處，為了成就僧法則給予開許。病者雖然躺臥，但不得背對僧眾，所以構成了開許與制止之規。

【781-0007】03_業疏/04b_卷一之四#100
【原文】五分》中，病人背說戒者，正判別眾。《四分》我往不坐，為作別眾等，竝是正量
【譯文】《五分律》中，患病之人背對著說戒處（背對說戒僧眾）的情形，律文正式判定為別眾。《四分律》中「我前往而不坐下，為其構成別眾」等，也都是正確的法則標準。

【譯文】《五分律》中背對大眾構成別眾是一人，仍舊引述《四分律》威儀乖違之文來顯明。又綜觀文句脈絡，《五分律》是用來證明上文「患病之人必須面朝僧眾」，《四分律》則用來證明上文「四種威儀互相乖違」。

【781-0009】03_業疏/04b_卷一之四#102
【原文】上來六十，俱是簡緣，豈唯如舊但二十八？必過今數，義理有歸，亦須收取。如極醉人、共語不解人等，亦是不相領會，何有忍默之理？故須通照也
【譯文】以上所列的六十人，全都是需要揀別排除的因緣，怎能像舊說那樣僅僅只有二十八人？若人數必定超過現在這個數目，只要義理上有所歸宿，也必須收納進來。例如大醉之人、與之言語不能理解通達之人等，也是無法互相領會法事的，哪裡有認可忍默的道理？所以必須全面通達觀照。

【781-0010】03_業疏/04b_卷一之四#103
【原文】義加中初科。初結數反古。「必下」正示義加。義有歸者，謂歸不足。注引捨戒睡狂如上，出在他部；醉及不解，此之二人諸部無文，是今義判。問：既出捨戒，那云義加？答：由非正列不足數中，然對捨不成，義是不足故也
【譯文】在義理增加一門的第一科中。首先總結人數以反駁古說。自「必過」以下，正式指示依義增補。所謂義理有所歸宿，是指歸於不足數之中。夾注中引述捨戒時睡眠、發狂如同前文所說，是出自其他部派；大醉與言語不解這兩個人，諸部律文中並無直接明文，是依據現今義理所作的判定。問：既然出自捨戒條文，為何說是「義加」呢？回答：由於並非正式列在不足數的專門條目中，然而對著他們捨戒不能成立，在義理上便屬於不足數之列。

【781-0013】03_業疏/04b_卷一之四#106
【原文】文云須知別眾足數四句者，上雖通列，名含是非，但為緣差，濫通淨行，故以法簡，不宜混雜，就分兩對
【譯文】文中說「須知別眾與足數的四句分別」者，上面雖然總體列出，但名稱中包含著合法與非法的不同情況，只是因為因緣差失，以致混濫貫通了清淨行持之人；所以必須用法式加以揀別，不應當混淆雜亂，因此分為兩對四句。

【781-0014】03_業疏/04b_卷一之四#107
【原文】次足別句中初文敘前列相。或體非而相是，或體淨而緣差，同歸非數，故云名含等。所以淨行之人濫通數內，事雖非足，不妨成別，故以足、別作句簡辨
【譯文】在下一段「足數與別眾句法」中，第一段文敘述前文所列的行相。或者體性是非法而外相是合法，或者體性清淨而因緣差失，兩者同樣歸入不足之數，所以說「名含」等。清淨行持之人之所以會混濫通入僧數之內，是因為事相上雖然不能充任足數，卻不妨礙其構成別眾，所以用「足數」與「別眾」列成四句來揀除辨析。

【781-0022】03_業疏/04b_卷一之四#115
【原文】四中，初《四分》二十二人。報別即尼等三人，法乖即沙彌及十三難，行違即二滅，治重即三舉。《十誦》十二人，次第牒解，一一各顯二非所以。入定中，雖是善行，而非證法，故云別有等。如色、無色定，各有所緣，澄心凝住，故云靜慮。瘂等人中，以羯磨法誡聽勸說，故云乖也。狂中兩能，亦即說、聽。白衣中，如律戒本釋比丘中，有相似比丘，謂剃染形同，本無戒者。非別非足，易知不解。同住樹上，即界內樹也。枝委外地，即涉兩界；若不委地，但從根判。重病下，即《伽論》三人、義加二人，非二可知
【譯文】在第四句中，首先是《四分律》中的二十二人。所謂「果報形別」，就是指比丘尼等三人；所謂「戒法乖違」，就是指沙彌及十三難人；所謂「行持違犯」，就是指兩種滅擯；所謂「治罰深重」，就是指三種舉罪。《十誦律》中的十二人，依次逐一標牒解釋，各自顯明兩者皆非的原因。在入定的人當中，雖然是修持善行，但並非當前作證僧法的心態，所以說「另有」等。如同色界定與無色界定，各有所緣之境，澄清心念凝寂安住，所以稱為靜慮。在啞巴等人當中，因為羯磨法誡飭專心聽受、勸勉如法宣說，所以說「相乖」。發狂等人當中的「兩種功用」，也就是指宣說與聽受。在白衣當中，如同律典戒本解釋比丘時，提到有「相似比丘」，是指剃除鬚髮、身著染衣與比丘外形相同，而本質上沒有具足戒的人。既非別眾亦非足數，道理顯而易見所以不再詳解。一同共住於樹上，是指生長在界內的樹。樹枝若垂覆落在界外地面，就牽涉到兩個結界；如果樹枝不垂落到地面，就只依樹根所在之處來判定。自「重病」以下，即是指《摩德勒伽論》中的三人以及義理增加的二人，兩者皆非的道理是可以得知的。
