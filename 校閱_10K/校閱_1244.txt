# 校閱材料　第1244檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1244-0001】資持記/11d_中四上#50
【原文】四句輕重者，以初一句，業雖不均；望犯究竟，一向是重，計不須論；然必依律五階，次第具釋，故云亦須等。一具。可解。二疑中，初雙標二句。〔此標頗符律文句法。〕前下，辨釋重輕。釋前疑云半緣者，疑心猶豫，通涉兩境故。後疑中云非本期者，異境來替，本無害故。
【譯文】分析這四句的輕重：因為第一句的業道雖不完全均等，但就成犯究竟根本罪而言，一概都屬於重罪，照理不需要拿來比較；然而必定要依照律典規定的五個位階次第完整解釋，所以說「亦須」等。其一為「具足」，道理容易理解。其二在「懷疑」之中，首先同時標明兩句。〔這種標示相當符合根本律文的句法。〕從「前」字以下，辨析解釋罪過的輕與重。解釋前一種懷疑說「半緣」者，是因為懷疑之心猶豫不定，同時通涉於真假兩種境界的緣故。在後一種懷疑中說「非本期」者，是因為相異的境界前來替代，本來並無加害此境的意圖。

【1244-0002】資持記/11d_中四上#51
【原文】此之二句，疑心不別，境分本異；故說重輕，後想亦爾。二想中，初雙標。前下，辨釋。前云本方便者，取前心也，望後正對心不當境。後云單有心者，作人想故；無本境者，非人替故。次本異中，初句標示。本下，列釋；初示本境二句，初雙示。以下，配釋。後下，釋異境二句，分三，初標示。
【譯文】這兩句之中，懷疑的心態並無差別，只是境界劃分為原本的境界與相異的境界；所以論述罪過的輕與重，後面的心想句也是如此。在兩想之中，首先同時標明兩句。從「前」字以下進行辨析解釋。前面說「本方便」者，是著眼於原本發動的心念，相較於後面正對境界時心與境並不相符。後面說「單有心」者，是因為心中單純存有人想；說「無本境」者，是因為已有非人之境前來替代。接著在「本境與異境」（本異）之中，第一句標明指示。從「本」字以下，列舉解釋；首先指出面對原本境界的兩句，開頭先同時列示。從「以」字以下，配合解釋。從「後」字以下，解釋面對相異境界的兩句，分為三部分，首先標明指示。


【1244-0003】資持記/11e_中四上#1
【原文】以下，列釋。故下，總結。兩位，即想疑，想唯闕境，疑兼兩闕故。罪屬本心者，不從異境故。結略中。示不盡義。廣在疏中，故云且也。第五，生起中，為三，初敘所詮廣遍。以持犯大體，即是制教所明善惡二業；業相隨緣無量，故曰該通。教義不可盡收，故非一法包舉。
【譯文】從「以」字以下，是分項解釋。從「故」字以下，是總結前文。「兩位」是指想心與疑心，因為想心只是單純對境界缺少確認（闕境），而疑心則兼具缺少境界與缺少決斷兩種情況。「罪責歸於根本心念」這句話，是指罪相不能順著差錯的外境來判定。在總結省略的文句中，指出了法義並未完全道盡；由於詳細內容都寫在《戒疏》之中，所以這裡才說「暫且」。第五部分「生起」（次序生起門）中，共分為三段，首先敘述所詮釋的教法極為廣博普遍。因為持戒與犯戒的整體本質，就是制教所闡明的善、惡兩種業相；業的相狀隨著因緣變化而無窮無盡，所以稱為涵蓋通徹。教法的義理不可能全部收攬，所以無法用單一的法門概括列舉。

【1244-0004】資持記/11e_中四上#2
【原文】故下，示能詮廣略。初示前有歸。諸門，即指已前總別科義。此下，顯今從略。羅，亦列也。陶鑄，喻研究也；範土曰陶，鎔金曰鑄。列名有五。《戒疏》文廣，不可具錄；恐未見疏，且就四重，略撮名義，以示新學。初明剋漫，先釋名；剋，謂情專一境；漫，謂心涉多緣。
【譯文】從「故」字以下，說明能詮釋的文字有詳有略。起初先指出前文各有歸宿。「諸門」就是指前面已經列出的總括與個別的科判義理。從「此」字以下，顯明當前從簡略處理。「羅」也是羅列的意思。「陶鑄」用來比喻深入研究研習；用模子燒製泥土叫做「陶」，鎔化金屬鑄造器具叫做「鑄」。這裡列出的名稱有五種。《戒疏》的文章篇幅極廣，無法完整抄錄；擔心初學者還沒讀過《戒疏》，姑且針對四根本重罪，簡略撮取名相與義理，用來啟發新進學者。首先說明「特定與廣泛」（剋漫），先解釋名稱：「剋」是指心念專注鎖定在某一特定對象；「漫」是指心念牽涉眾多廣泛的因緣。

【1244-0005】資持記/11e_中四上#3
【原文】漫復有二：一者大漫，如本標心，遍通三趣；俱是所期，隨作成犯。二者小漫，但該人道，不兼非畜。次配四戒，唯婬一戒，不問乖差；但使境交，無非大重；盜殺二戒，大漫則隨境成犯，小漫則異趣非犯；剋定一人，三趣非犯；妄語一戒，三境俱現，內知歷然；
【譯文】廣泛的心念又分為兩種：第一是大漫，比如起初立定心意，普遍通於人、非人、畜生三道；全部都在預期之中，隨著任何一個對象造業便構成犯戒。第二是小漫，僅僅涵蓋人道，並不包括非人與畜生。接著將這項概念配對到四種根本戒：唯獨淫戒，不論對象是否有差錯違背；只要身體交接，全都構成大重罪。至於偷盜與殺生這兩條戒，若是出於大漫之心，就隨著相應的境界構成重罪；若是小漫之心，遇到人道以外的對象就不犯重罪；如果已經特定鎖定某一人，誤對三道其他對象下手都不犯重罪。妄語戒的部分，如果三道的對象同時在場，自己心裡清楚明白；

【1244-0006】資持記/11e_中四上#4
【原文】犯無剋心，通境隨犯；三趣不現，隨剋隨犯。二明錯誤，先示名；錯就現緣境差為義，誤就不現緣境差心謬忘為義。二對戒者，婬戒隨犯，不論錯誤；盜戒分三，大漫三趣齊犯，小漫非畜物不犯。剋心又二：若對異人以論，盜張得王不犯；若就一主，盜金得銀，即還不犯；殺戒，漫心同上；
【譯文】犯罪時若是沒有特定對象的心念，對著通泛的對象便隨之犯重罪；如果三道對象並非同時在場，則是依據當初特定鎖定的對象來判定是否犯戒。第二說明「錯與誤」（錯誤），先指出名稱的意涵：「錯」是指針對當前現前的因緣，因對象產生差錯為其定義；「誤」則是指針對不是當前現前的因緣，對象出現差錯且心中迷謬遺忘為其定義。第二項將它對應到各條戒律：淫戒只要發生就犯重罪，不論是錯還是誤；盜戒分為三種情況，大漫之心在三道對象上同樣犯重罪，小漫之心對非人與畜生的財物則不犯重罪。鎖定特定對象的心又分兩種：如果是針對不同的人來討論，想偷張三卻偷了李四的財物，便不犯重罪；若是針對同一物主，想偷金子卻誤拿了銀子，若當即歸還本處則不犯盜罪；殺戒的部分，漫心的情況如同前面所說；

【1244-0007】資持記/11e_中四上#5
【原文】剋心以論，錯開不犯；現境歷然，心緣別故；誤則成重，緣王張解，人想不差故。妄語一戒，大漫同上；小漫錯犯，對現境故；誤不犯，不竝現故。剋心有二，對人誑他義一，錯誤俱重；對法為言，說聖稱凡，迷凡謂聖，錯誤皆開；若就聖法，如錯說三四禪皆重。
【譯文】如果以鎖定特定對象的心來討論，發生「錯」的情況則開許不犯重罪；因為眼前的境界清清楚楚，是自己的心念攀緣到了別的對象；如果是「誤」則構成重罪，因為本來心緣王某，卻將張某錯解為王某，把對方當作人的認知並沒有差錯。妄語這條戒，大漫的心態如同前面所述；小漫的情況下若是「錯」則犯重罪，因為是面對當前現前的對象；若是「誤」則不犯重罪，因為不同對象並沒有同時並列在眼前。鎖定特定對象的情況有兩種：針對人來說，欺騙他人的本質是相同的，所以錯或誤都犯重罪；如果針對所宣說的法而言，宣說聖法卻誤稱為凡夫法，或是誤把凡夫法當作聖法，錯與誤都開許不犯重罪；但若是針對聖法內部來說，比如錯把三禪說成四禪，這兩種情況都犯重罪。
