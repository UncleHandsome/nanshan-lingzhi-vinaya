# 校閱材料　第590檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【590-0001】02_戒疏/10c_卷三上之一#68
【原文】【記】釋輕重中，初科。初斥古。《義鈔》引云「一解，今此四戒，皆倚傍行教，言說相濫，朋黨相助，事成破僧。前二壞法輪，後二壞羯磨」等，「說欲不障，於理教有違，僧法無濫。又復口說未犯根本。所以事微，故結提罪」。此所謂「云云」也。「披」，分也。今解中。初立義，「如」下，引例。隨事重輕，義通一切，故總舉諸戒也。
【譯文】【記文】在解釋罪名輕重的第一小段。首先駁斥古說。《義鈔》引述說：「有一種解釋認為，如今這四條戒，都是依傍偽造教法而行，言論互相混淆，朋黨相互勾結，事情已演變成實質破僧。前兩條破壞法輪，後兩條破壞羯磨」等等，「至於說欲受染不障道，只是在教理上有所違背，對僧團法制作業並沒有造成混淆。再者口頭言說也還沒觸犯到根本性罪。因此事情性質較為輕微，所以只結波逸提罪（單墮罪）」。這就是所謂的「紛紜龐雜」。「披」是剖析分明的意思。在如今的新解之中。首先確立論點，「如」字以下，引用事例作證。隨事態輕重而定罪，這個法則通於一切戒律，所以概括列舉各項戒品。

【590-0002】02_戒疏/10c_卷三上之一#69
【原文】【疏】問：「若隨事大小故，違諫罪有階降者；我未諫前，亦應隨事，不應同吉？」
【譯文】【疏文】問：「如果說是因為事情大小的不同，違抗勸諫的罪名才有了輕重等差；那麼在僧團尚未正式勸諫之前，犯罪也應當隨著事情大小而有差別，不應該同樣都只結突吉羅罪吧？」

【590-0003】02_戒疏/10c_卷三上之一#70
【原文】【疏】答：「諫諫元事不諫罪，何妨說事有輕重。」
【譯文】【疏文】回答：「勸諫是針對原本所作的事情去勸阻，而不是針對抗諫產生的罪名去勸阻，這何妨礙所作事情本身確實有輕重的區別呢。」

【590-0004】02_戒疏/10c_卷三上之一#71
【原文】【記】釋疑中，初難。由此五戒未作白前，堅持不捨，並犯吉羅。若云「隨事」，合分階降。答中，但分所諫有別，而未盡來難，留在下科。
【譯文】【記文】釋除疑惑之中，首先是難問。由於這五條戒在正式行白羯磨之前，堅持錯誤不肯捨棄，同樣都只是結突吉羅輕罪。如果硬說是「隨事情大小」，那在諫前就應當分出罪名等差。回答之中，只是劃分出所勸諫的事情各有不同，但尚未徹底解答對方的難問，這個問題保留在下一段中交代。

【590-0006】02_戒疏/10c_卷三上之一#73
【原文】【疏】答：「大有道理。稀數不同，事大作稀，事小作數，是故俱吉。諫本依事，隨事大小，如前解也。」
【譯文】【疏文】回答：「這大有深層道理。因為行為發生的頻率高低不同，重大的惡事難得發生一次，微小的事情卻會頻繁出現，所以事前一律同結突吉羅罪。僧團勸諫本來是依據具體事由，因此最終罪名仍需隨著事情的大小來判定，如同前文所作的解釋。」

【590-0008】02_戒疏/10c_卷三上之一#75
【原文】【疏】問：「對舉以論，何故彼有此無者？」
【譯文】【疏文】問：「若是對比『宣舉』處分來討論，為什麼彼處的單墮戒有舉法，此處的四條僧殘戒卻沒有舉法？」

【590-0009】02_戒疏/10c_卷三上之一#76
【原文】【疏】答：「『九十』諫竟，便即出舉者，為明能隨舉人有同犯故。若不出舉，無由得結能隨之過。此四諫竟，若有不見，亦合作舉。以隨不見，但得吉故。既不同犯，不勞須出。」
【譯文】【疏文】回答：「九十單提中的規勸完畢後，隨即宣告舉法處分，是為了表明隨順受舉之人也有同犯之罪的緣故。若不宣告舉法，就無從判定隨順者之罪過。而此處這四條戒在勸諫完畢之後，如果犯僧仍不承認自身有罪（不見罪），理應也要對其作不見舉處分。但因為盲從隨順此不見罪者，僅僅只得突吉羅罪。既然隨順者與受舉者並非同犯一罪，律文中就不必多此一舉列出舉法（另制隨舉戒）了。」

【590-0010】02_戒疏/10c_卷三上之一#77
【原文】【記】次舉不舉。問意，可解。答中。初明後戒有舉，以隨舉戒相連次故。次明四諫無舉。論舉有三：一、不見舉，二、不懺舉，隨順此二犯吉；三、惡邪不捨舉，即說欲不障也，隨順犯提。今此四諫，舉唯上二，隨但輕吉。能所各篇，故不同上。
【譯文】【記文】其次是關於有無「舉法」處分的辨析。提問的用意很清楚。回答之中。首先說明後面的單墮戒之所以要有舉法處分，是因為與盲從隨順受舉者的戒條是前後緊密相連的。接著說明四條僧殘戒之後律文之所以未列出舉法（另制隨舉戒）。論及舉法處分共有三種：第一是不見罪舉，第二是不懺悔舉，盲從隨順這兩者的人都犯突吉羅輕罪；第三是堅持惡見不捨舉，即宣稱淫欲不障道這一類，盲從隨順這種舉法的人會犯波逸提罪。如今這四條違諫戒，所能構成的舉法只有前兩種，盲從者只得輕微的突吉羅罪。能隨順者與所隨受舉者的罪名屬於不同篇聚，所以不同於上述單墮戒的情況。

【590-0015】02_戒疏/10c_卷三上之一#82
【原文】【疏】所以不聽破僧者。僧眾和合，義無乖異，理應詳遵，如水乳合。今反倚傍理教，說相似語，惑亂羣心，壞僧斷法，墜陷無辜，為惡滋甚。故須聖制，意在於斯。
【譯文】【疏文】之所以不准許破壞僧團。是因為僧眾理應清淨和睦、和合共處，義理上不容有絲毫乖謬殊異，大眾理當審慎遵奉戒法，就如同水與乳般水乳交融。如今破僧之人反而假借依傍佛法教理，口吐似是而非的言辭，惑亂群眾心志，摧毀僧團制度並斷絕正法傳承，使無辜之人深陷罪網，所造的罪惡極其深重。因此必須由聖人制定戒律，其用意就在於此。

【590-0016】02_戒疏/10c_卷三上之一#83
【原文】【記】第十，制意中，初科。初敘僧義。「詳」謂審其邪正。「遵」謂稟其法制。「今」下，明破義。文敘四過：一、倚教，二、惑眾，三、滅法，四、損他。具上諸惡，故云「滋甚」。「滋」，益也。
【譯文】【記文】在第十項制戒旨趣的第一小段。首先敘述僧團原本的和合義理。「詳」是指詳審辨別法與非法的邪正。「遵」是指恭敬稟承佛陀的制度法規。「今」字以下，指明破僧行為的嚴重性質。文中陳述了四種罪過：第一、依傍偽托教法，第二、惑亂大眾視聽，第三、滅絕正統法脈，第四、陷害牽連他人。具備了上述種種罪惡，所以說是「滋甚」。「滋」是更加、增長的意思。

【590-0017】02_戒疏/10c_卷三上之一#84
【原文】【疏】二、須諫意。然彼邪人，倚傍佛教。乞食等四，生聖之緣，趣道遠因，說緣為種。正語等八，生聖之因，趣道近法，正為聖體。稱法而談，名為正見。邪人反說，顛倒教理，是非兩濫，言同意異，真偽難分。迷情墜惡，實可憐愍。須僧設諫，開示是非。冀彼改迷從正，棄惡就善。是以須諫，意在於此。
【譯文】【疏文】第二、必須設立勸諫的用意。提婆達多那樣的邪人，往往依託附會佛教教義。乞食等四依法，本來只是生起聖道的輔助資緣、是趨向佛道的遠程助緣，他卻將助緣誇大為根本種子。正語等八正道，才是生起聖道的真正內因、是趨向聖道的核心正法，也是聖者人格的實體所在。完全契合正法來談論，才稱為正見。邪見之人卻反其道而說，完全顛倒了佛教的義理，使是非正邪兩相混淆，言詞表面雷同而實質意涵完全相違，真偽極難分辨。無知的僧眾被蒙蔽情志而墮入惡道，實在令人哀憐悲痛。所以必須由僧團出面設立嚴正的勸諫，向其剖析開示是非對錯。無非是希望他能改迷成悟、歸向正道，改惡向善。這就是必須設立三諫程序的深意所在。
