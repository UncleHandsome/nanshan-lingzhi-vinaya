# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】下明坐跪名二。禪觀加趺，飲食踞坐。尼令長跪，非不通僧；僧制互跪，則不通尼，故注云：各有所立也。別示中，初科，《三千》中，明踞坐。交足，左右交過；雙竪，謂脚頭向上；却踞，謂反向後；掉捎，謂搖動；搘拄，謂一足著地，搘起一足直申向前；上足，即翹起一足。

【652-0006】01_行事鈔/12a_卷下之四#4
【原文】制意者。夫有待之形，多諸嬰累；四大互反，六府成病；若不假相提接，薄命則無所托。然則，世情流變，始終難一；健壯則親昵，病弱則損捨；鄙俗恒情，未能忘此故。如來深鑒人物，知善未崇，惡必相遵，故親看病。故律中佛言：汝曹不相看視，誰當應為？乃至世尊為病人洗除大小便已，掃治臥處，極令清淨，敷衣臥之。便立制云：自今已去，應看病比丘，應作瞻病人；若有欲供養我者，應供養病人。佛為極地之人，猶勵諸比丘，親自下接；況同法義重，如何相棄？乃至送終，意同斯述。問：供養病者，等佛何耶？答：謂悲心看病，拔苦與樂，慈行同佛故也！又論云：隨順我語，名供養佛。《僧祇》：二人為伴往看佛，一伴遇病，便捨，來詣佛所，具述因緣；佛種種呵責已，還令看病等。又云：有病人，得隨病藥食，看守則差，不者則死；是故應好看，務令如法安隱，即為施命，得大功德，諸佛讚歎。
【譯文】制定義意：凡是有所依待而生的血肉之軀，往往充滿了各種疾病與纏縛；地水火風四大相互乖違，六腑便會生起疾病；此時若不憑藉同道相互提攜照料，微薄的生命就無處依託。然而，世俗的情態隨境流變，始終難以始終如一；他人強健時便親近交好，病弱時便損抑捨棄；凡俗鄙陋的常情，往往不能免除這種心態。如來深刻照見眾生的根性，知道眾生對於善行尚未崇尚，惡習卻必然盲目相循，因此親自探視照看病僧。所以律典中佛陀說道：「你們同門之間若不互相照看，還有誰應當照看呢？」乃至世尊親自為病僧清洗大小便溺後，打掃清理臥具處所，使其極為清淨，鋪設好衣物讓病僧躺下。隨即制定戒律說：「從今以後，應當照看生病的比丘，應當充當瞻看照料之人；若有人想要供養我，就應當供養病人。」佛陀身為證得無上極位之人，尚且勉勵諸位比丘，親自屈尊降貴照拂病患；何況同參法友之間法義深重，怎麼可以互相拋棄？乃至於臨終送別之事，其旨意也與此處所述相同。有人問：供養病人，為何能等同於供養佛陀呢？回答說：這是因為以悲憫之心照看病人，能拔除其痛苦、給予其安樂，慈悲的行持與佛陀相同的緣故！又論書中說：「隨順依從我的教誨，就稱為供養佛陀。」《摩訶僧祇律》記載：有兩人結伴前往探望佛陀，其中一人路上生病，另一人便捨下他，獨自來到佛陀處所，具體陳述了事情的原委；佛陀對其作了種種呵斥之後，依然命令他回去照看病僧等。《僧祇律》又說：有了病人，若能得到適合病情的醫藥和飲食，又有專人看守照料就會痊癒，否則就會死亡；因此應當好好照看，務必使其依循如法的生活而安適平穩，這便是行施予生命（施命），能獲得極大的功德，受到諸佛的讚歎。

【652-0007】資持記/16a_下四#1
【原文】四分律行事鈔資持記下四26 釋瞻病篇(下四)釋瞻病篇題中四字，即下兩門；瞻送是能施，病終即所為。制意中，初科，初敘病患。多嬰累者，通目眾苦也。四大等者，別示病惱也；地水火風，內外該遍，故通名大；六府者，大腸、小腸、胃、膀胱、三焦、膽也。〔從頂至心為上焦，從心至腰為中焦，從腰至足為下焦，此三共為一府。
【譯文】本篇標題中的四個字，便概括了下文的兩大門徑；「瞻送」是能主動施予的行持，「病終」則是所關照的對象。在制戒緣由中，第一科首先敘述病患。所謂「多受累贅牽纏」，是總括指稱世間的眾苦。至於「四大等」語，則是個別指出病痛的惱亂；地、水、火、風四大遍佈於體內體外，所以通稱為「大」；六腑則是大腸、小腸、胃、膀胱、三焦以及膽。（自頭頂至胸口為上焦，胸口至腰部為中焦，腰部至足部為下焦，這三處合稱為一腑。）

【652-0008】05_拾毗尼義鈔/03b_卷中之一#16
【原文】問初得衣鉢過於五日若被擯等若狂亂人上入天宮至北單越後解擯若得本心若還本處以何日為限而作說淨答一解更得一日又解取前五日律師云後義定也此中首解真實施主若命終者勿問先作及以未淨皆須說淨以守人亡故有說若得長財作成被及得先成不合說淨是重物故問若爾如尼十六枚器七日藥等豈是輕物聖開說淨法耶更問離三衣重離餘衣輕有何意耶答夫三衣者道標服式資身要用無時不須生善最勝以受時要心不許離宿今既離宿達本要心失於受持故得罪重餘衣鉢等非是道服又用有時非常所須是以受時不言不離今雖離宿不失受法所以罪輕又解三衣制畜是上中下違制故提餘衣為此中下對開有違故犯吉問若爾鉢亦對制有違何故犯吉而不失受答衣障形醜無時不須犯提失受鉢用時限故不相竝善見云受持三衣已轉根即捨。
【譯文】問：初得衣缽過於五日，若被擯黜、若發狂亂、若上入天宮至北拘盧洲，後解擯、若得本心、若還本處，以何日為期限而作說淨？答：一解更得一日；又解取先前五日，律師云後義定也。此中首解：真實施主若命終，勿問先前已作說淨及未淨，皆須說淨，以守護之人已亡故。有說：若得長財作成被褥，及得先成者，不合說淨，以是厚重之物故。問：若如此，如尼十六枚缽器、七日藥等，豈是輕物，聖何以開說淨法？更問：離三衣宿重，離其餘衣輕，有何意？答：夫三衣者，是道法標幟服式，資身要用，無時不須，生善最為殊勝；以受持之時立下要心，不許離宿，今既離宿，違達本來要心，失於受持，故得罪重。其餘衣缽等非是道服，又使用有特定之時，非常時所須，是以受時不誓言不離；今雖離宿，不失受法，所以罪輕。又解：三衣佛制必備上中下，違制故結波逸提；其餘衣為對應此中下開許之物，有所違背故犯吉羅。問：若如此，缽亦對制有違，何故犯吉而不失受？答：衣障形體醜陋，無時不須，犯波逸提（或尼薩耆波逸提）即失受；缽使用限於特定之時，故不相並。《善見律》云：受持三衣已，轉根即自然捨除。

【652-0009】05_拾毗尼義鈔/03b_卷中之一#17
【原文】問十日衣一月衣分為二戒者離衣有病得僧羯磨病差離衣何以不分二戒而合一也答凡論分離一財體不同故二日月長短不同故此中合者一同是三衣二若病未差無離衣宿若差離宿與本無病不異是故合也問羯磨離衣於三衣中得離何衣幾時得離答四分云唯離伽棃十誦云下二亦得明知三衣隨意離一五分云得留中衣上下不得若有賤者好者隨留十誦云從七月至九月夏分不開五分云今聽前安九月後安八月祇律云白四羯磨限一月夏中亦得今律白二善見云病僧為羯磨離衣往餘方若差欲還路嶮不得還恒作還意雖差不失婆論云羯磨病重不行病差不行更得病即先羯磨同一月內得。
【譯文】問：十日衣、一月衣分為二戒，離衣宿因病得僧羯磨開許、病差離衣何以不分二戒而合為一？答：凡論分戒：一由財體不同，二由日月長短不同。此中合為一者：一同是三衣之範疇；二若病未差無離衣宿罪，若差而離宿與本來無病不異，是故合為一也。問：羯磨開許離衣，於三衣中得離何衣？幾時得離？答：《四分律》云唯離僧伽梨；《十誦律》云下二衣亦得，明知三衣隨意離一。《五分律》云得留中衣，上下二衣不得離；若有粗賤精好者隨意留。《十誦律》云從五月十六日至八月十五日（即夏安居期間）不開許。《五分律》云今聽前安居留九月、後安居留八月。《僧祇律》云白四羯磨限一月，夏中亦得；今律用白二。《善見律》云：病僧為作羯磨離衣往餘方，若差欲還而路險不得還，恒存歸還之意，雖差不失開許。《薩婆多論》云：羯磨後病重不行、病差不行更得他病，即先前羯磨在同一月內仍得。

【652-0010】05_拾毗尼義鈔/03b_卷中之一#18
【原文】問有時衣有非時衣就何立月望衣耶答就非時衣此中祇律云前十日得故衣若細衣得已不自作不教他作過前十日犯捨中後二十亦如是說四分分之若前十日五日已過得望衣用後五日中十日前五日此十日應作中十亦爾後十日前五日過得望衣乃至九日過一日中作十日得衣即日作多論云勤求不斷待滿一月若想念斷不至一月若初得衣日自知必無望處過十日犯捨若初日得衣停衣待望不得所望非望而得是二種十日內不淨施與人作衣至十一日犯捨墮乃至十日不得所望非望而得應合成十一日犯捨墮善見云若有望處一月得畜若二十九日得望衣細先麤者說淨細者復得一月為望得故若後得衣麤復停一月如是乃至勿過一月義云若三衣俱故竝少勿問皆開一月若十日中大衣上同衣足者當日不割綿[打-丁+迸]十一日明相出犯下二衣財少不足者亦染犯長若無根本者得開一月。
【譯文】問：有時衣、非時衣，就何者立「一月望衣」？答：就非時衣。此中《僧祇律》云：前十日得舊衣、細衣，得已不自作、不教他作，過前十日犯捨墮；中、後二十日亦如是說。《四分律》區分之：若前十日中前五日已過，得望衣布料，用後五日作；中十日前五日、後五日亦爾；後十日前五日過得望衣，乃至九日過一日中作，十日得衣即日作。《薩婆多論》云：勤求不斷以待滿一月；若想念已斷則不至一月；若初得衣之日自知必無望處，過十日犯捨；若初日得衣停衣待望，不得所望而得非所望者，此二種十日內不淨施與人作衣，至第十一日犯捨墮；乃至十日不得所望而得非所望，應合成十一日犯捨墮。《善見律》云：若有望處，一月得蓄；若第二十九日得望衣為細布，先得粗者說淨，細者復得一月，為望得之故；若後得衣又是粗者，復停一月，如是乃至勿過一月。義理云：若三衣俱舊破而布料少，勿問皆開一月；若十日中大衣上同衣足者，當日不割截縫疊，第十一日明相出，犯長衣罪；下二衣財少不足者，亦染犯長衣；若無根本三衣者，得開一月。

【652-0011】05_拾毗尼義鈔/03b_卷中之一#19
【原文】問既為作三衣體自無長何以染也答少財若無故壞受持三衣自實無染今言染者以有故壞三衣故不如昔解問先有長衣三衣望未斷為被染不答此是法衣彼是長衣何得相染問若爾三衣望斷得少餘財為被染不答既同犯長何得不染乃至二十九日亦如是足即不開不足便開故。
【譯文】問：既為作三衣，體自無長物，何以相染？答：少財若無故壞受持三衣，自實無染；今言染者，以有破壞之三衣故，不如昔解。問：先有長衣，三衣之望未斷，為其所染否？答：此是法衣，彼是長衣，何得相染？問：若如此，三衣望斷，得少餘財，為其所染否？答：既同犯長衣，何得不染？乃至第二十九日亦如是，足即不開，不足便開故。

【652-0012】05_拾毗尼義鈔/03b_卷中之一#20
【原文】問何故取尼衣重不制取鉢答衣有五故喜能捨與致受義數故須制鉢唯有一尼捨稀故設令受者但得小罪又解無犯祇云尼與比丘鉢及餘小物取而無犯故廣說乃至出界二十五肘離見聞處一切犯提問尼取僧衣何故小罪答大僧上尊與尼義稀故問若爾能與之人亦應犯輕何僧得提答大僧與尼就譏過中制生染義深故得罪重尼取僧衣就稀數而制故得輕罪。
【譯文】問：何故取尼衣重，不制取缽？答：衣有五條，易能捨與，致受取之義數多，故須制戒；缽唯有一，尼捨極稀，設令受者但得小罪。又解無犯。《僧祇律》云：尼與比丘缽及餘小物，取而無犯。廣說乃至出界二十五肘離見聞處，一切犯尼薩耆波逸提（捨墮）。問：尼取僧衣何故小罪？答：大僧上尊，與尼衣義稀故。問：若如此，能與之人亦應犯輕，何以僧得捨墮？答：大僧與尼，就譏嫌過失中制，生染污義深，故得罪重；尼取僧衣就稀數而制，故得輕罪。
