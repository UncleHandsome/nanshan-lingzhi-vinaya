# 校閱材料　第550檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【550-0001】02_戒疏/09b_卷二下之二#152
【原文】【疏】「我修梵行」下，舉善法以動也。
【譯文】【疏文】「我修梵行」以下，是舉出善法來打動對方。

【550-0002】02_戒疏/09b_卷二下之二#153
【原文】【疏】問：「既修梵行，義無行非，何用索欲供者？」
【譯文】【疏文】問：「既然已經修習梵行，按理就不會有行淫之事，何必索求以淫欲來供養呢？」

【550-0003】02_戒疏/09b_卷二下之二#154
【原文】【疏】答：「必實行欲，索者偷蘭，大婬方便也。今本不行，口言其相，妄開婬門，擬通適故耳。」
【譯文】【疏文】答：「如果真正去實行淫欲，那麼索求的人便犯偷蘭遮，這是大淫（波羅夷）的方便罪。如今根本沒有實行，只是口中說出那些事相，虛妄地開啟淫欲之門，用意只在求取暢快適悅罷了。」

【550-0004】02_戒疏/09b_卷二下之二#155
【原文】【記】第五，梵行中。問答甚要，能破二疑：一、自稱梵行，不當索欲；二、索欲婬因，理應蘭罪。一披後答，頓釋深疑。雖不期婬，發言求索，故云「婬門」。「通」即是暢，「適」即訓悅。
【譯文】【記文】第五科，是解釋「梵行」這一部分。這一問一答非常重要，能破除兩種疑惑：第一，既然自稱修梵行，就不應當索求淫欲；第二，索求淫欲是淫行的因，按理應結偷蘭遮罪。一旦讀到後面的答文，深重的疑惑便頓時消解。雖然並不期望行淫，但開口求索，所以稱為「婬門」。「通」就是暢快，「適」就是喜悅。

【550-0005】02_戒疏/09b_卷二下之二#156
【原文】【註】勤修離穢濁也。
【譯文】【註文】精勤修持，以遠離污穢濁惡。

【550-0006】02_戒疏/09b_卷二下之二#157
【原文】【疏】注言「勤修離濁」者，「濁」謂欲染。所以汙染離，由勤修也。釋上「梵」字，當唐言「淨行」也。
【譯文】【疏文】註文說「勤修離濁」，「濁」指的是欲染。能夠遠離染污，正是由於精勤修行的緣故。這是在解釋前面「梵」字，相當於唐代漢語所說的「淨行」。

【550-0007】02_戒疏/09b_卷二下之二#158
【原文】【記】釋注。「欲染」即五欲。「所以污染離」。
【譯文】【記文】釋註。「欲染」就是指五欲。「所以污染離」這句，是解釋正是由於精勤修習，染污才能夠得以遠離。

【550-0008】02_戒疏/09b_卷二下之二#159
【原文】【律】「持戒精進。」
【譯文】【律文】「持守戒律，勇猛精進。」

【550-0009】02_戒疏/09b_卷二下之二#160
【原文】【疏】言「持戒精進」者，明止作兩持，無有缺也。
【譯文】【疏文】所說的「持戒精進」，是說明止持、作持這兩種持守都能完整無缺。

【550-0010】02_戒疏/09b_卷二下之二#161
【原文】【註】不缺，不穿漏，無染汙。
【譯文】【註文】不破缺，不穿穴，沒有染污。

【550-0011】02_戒疏/09b_卷二下之二#162
【原文】【疏】注解「不缺」，不犯第二篇；「不穿」，不犯三、四聚；「無染汙」者，謂餘篇聚皆明淨也。又解：「初持方便，言『不缺』也；中持正本，言『不穿』也；後奉持戒，隨助之心，故云『無染汙』也。」或以戒、見、威儀具持故，以三配之，可解。
【譯文】【疏文】註解說「不殘缺」，是指不觸犯第二篇僧殘罪；「不穿漏」，是指不觸犯第三聚偷蘭遮與第四聚波逸提等罪；「沒有染污」，是指其餘所有篇聚戒法都皎潔明淨。又有一種解釋：「最初持戒時的防護方便，稱為『不殘缺』；中途如實持守根本戒律，稱為『不穿漏』；事後護持戒行、相隨助道的善心，所以稱為『無染污』。」或者以戒律、正見、威儀均圓滿持守，將這三者配對解釋，也可以理解。

【550-0012】02_戒疏/09b_卷二下之二#163
【原文】【記】持戒中，釋注三義。初約篇聚釋。文收下聚，不配初篇，是行本故。持則堅完，犯則喪失，故不論「穿」、「缺」也。「餘篇聚」者，謂下篇惡作、惡說。「又」下，次約三時釋。初中後心，配「缺」、「穿」、「汙」。「或」下，三、對四事釋。「不缺」即「戒」，「不穿」是「見」，「無汙」對「威儀」，「正命」即攝「戒」中。
【譯文】【記文】「持戒」一科，是解釋註文的三層義理。第一是就篇聚來解釋：註文所收攝的是下面諸聚，並不配對初篇，因為初篇是修行的根本。持守時堅固完整，毀犯時便全部喪失，所以不再論「穿」「缺」的分別。「餘篇聚」，是指下面諸篇的惡作、惡說。「又」字以下，第二是就三時來解釋：以初、中、後三種心，配對「缺」「穿」「汙」。「或」字以下，第三是就四事來解釋：「不缺」就是「戒」，「不穿」是「見」，「無汙」對應「威儀」，「正命」則含攝在「戒」之中。

【550-0013】02_戒疏/09b_卷二下之二#164
【原文】【律】「修善法。」
【譯文】【律文】「修習各種善法。」

【550-0014】02_戒疏/09b_卷二下之二#165
【原文】【疏】「修善法」者，謂頭陀等相，並生善道之法也。
【譯文】【疏文】「修善法」，是指頭陀行等事相，都是能使人投生善道的方法。

【550-0015】02_戒疏/09b_卷二下之二#166
【原文】【註】樂閑靜處，時到乞食，著糞掃衣，作餘食法不食，一坐食，一揣食，塚間坐，樹下坐，常坐，隨坐，持三衣，唄匿，多聞，能說法，持毗尼，坐禪是也。
【譯文】【註文】喜愛空閑寂靜的地方，時間到了才出去乞食，穿著糞掃衣，縱使作了餘食法也不再進食，一坐食（坐下進食便不再起身），一揣食（只取一摶，不再添受），在墳塚間坐，在樹下坐，常坐不臥，隨所至處而坐，受持三衣，唄匿（讚誦經法），多聞，能宣說佛法，受持毗尼，坐禪——這些就是。

【550-0016】02_戒疏/09b_卷二下之二#167
【原文】【疏】注解中，分六位：初舉頭陀，明節儉法；二舉「唄匿」，明稱讚法；三舉「多聞」，明廣見法；四舉「說法」，明開智法；五舉「持律」，明奉行法；六舉「坐禪」，明剋道法。
【譯文】【疏文】註解之中，分為六類：第一舉出頭陀行，說明節儉的方法；第二舉出「唄匿」，說明稱揚讚歎的方法；第三舉出「多聞」，說明廣博見聞的方法；第四舉出「說法」，說明開啟智慧的方法；第五舉出「持律」，說明奉行戒法；第六舉出「坐禪」，說明剋期證道的方法。

【550-0017】02_戒疏/09b_卷二下之二#168
【原文】【記】修善，注中，初科。「六位」，統收善法。束六為二，不出解、行，或復為三，即是三學。
【譯文】【記文】「修善」一科，在註文之中是第一部分。「六位」統攝收束一切善法。把六位歸束為兩類，不外乎「解」與「行」；或者再分為三類，就是三學（戒、定、慧）。


【550-0018】02_戒疏/09c_卷二下之二#1
【原文】【疏】就前頭陀，約相十二，以事束之，止唯四位，謂衣、食、處、儀也。於衣知足立二，謂「糞掃衣、一衣」也。於食知足立四，謂「乞食、不餘、一坐、一摶」也。於處知足立五，謂「靜處、塚間、樹下、露地、隨坐」也。四儀唯一，即是「當坐」，繫念現前，發智觀察也。餘如《鈔》中。
【譯文】【疏文】關於前面所說的頭陀行，如果依據行相共有十二種；若以事情來歸納，僅有四類，也就是衣、食、住處與威儀。在衣服知足方面立了兩種，即「糞掃衣、但持一衣」。在飲食知足方面立了四種，即「托鉢乞食、不收殘食、一坐食、節量一摶食」。在住處知足方面立了五種，即「阿蘭若寂靜處、塚間、樹下、露地、隨處坐」。四威儀中只有一種，也就是「常坐不臥」，繫念在前，發起智慧來觀察。其餘的詳細內容如《行事鈔》中所說。

【550-0019】02_戒疏/09c_卷二下之二#2
【原文】【記】次科。「四位」總收，可解。「食」中，「不餘食」者，但能節後。「一坐食」者，前後俱節。「一摶食」者，不復受益。「處」中五種，注中缺「露坐」，後世寫脫，《律本》具之。《事鈔．頭陀篇》中，一一具出制意、名體、行相、功益，此不繁引，故略指之。
【譯文】【記文】接著下一科。以「四類」來總括收攝，很容易理解。在「飲食」當中，「不收殘食」只能節制吃飽之後不再受食。「一坐食」則是起坐前後都能自我節制。「節量一摶食」則是決定不再增加食物。在「住處」的五種當中，注文中缺少了「露地坐」，這是後代抄寫時脫漏，《律本》中是完全具備的。《行事鈔．頭陀篇》中，逐一詳細列出了制戒本意、名稱體質、修行事相以及功德利益，這裡不再繁瑣引述，所以只作簡略指引。

【550-0020】02_戒疏/09c_卷二下之二#3
【原文】【律】「可持是婬欲法供養我。如是供養第一最」，僧伽婆尸沙。
【譯文】【律文】「妳可以用這淫欲之事來供養我。這樣的供養是第一等、最殊勝的」，犯僧伽婆尸沙罪（僧殘罪）。
