  == 420-0013 02_戒疏/04b_卷一下之二
     原: 【記】作犯中。初牒名，「出」下，釋義有四。初釋作。初句標能犯之人，次二句敘起業之本。「不」下，正明造業，釋成「作」義。「作與」下，次釋犯。「犯由」下，三、合名。「此」下，四、顯宗。兩犯並不指事者，翻持可知故。
  == 420-0010 02_戒疏/04b_卷一下之二
     原: 【記】次所以中。初徵意者。以修捨義順，今相反故；又止作體同，今分異故。《論》下，次引釋。《論》即《百論》，文有二段。初釋不同。彼明佛說法有二種：一止相，二行相。謂息一切惡名止，修一切善名行。外道難曰：「已說善行，不應復說惡止，以惡止即善行故。」內曰：「止相息，行相作，性相違故。」今變其語，取其義耳。「又」下，次釋前後。彼云：「外人又難曰：『善行應在初，以善法有妙果故。』內曰：『次第法故，先除麤垢，後染善法。』」
  == 420-0009 02_戒疏/04b_卷一下之二
     原: 【疏】所以前後不同者。《論》云「戒相止，行相作」也。又云「惡止善行，義之次第」。
  == 420-0001 02_戒疏/04b_卷一下之二
     原: 【記】四、明持犯。《鈔》具七門，此但明四，故云「略分」。名必召體，體成有處，心容明昧，四段辨相，大途已顯。餘如對篇，逐位別配。
  == 420-0012 02_戒疏/04b_卷一下之二
     原: 【疏】言「作犯」者，出家五眾，內具三毒，我倒自纏，不思對治，鼓動三業，違教造境，名之為「作」。作與持違，汙本所受，名之為「犯」。犯由作成，故曰「作犯」。此對造作惡法為宗。
  == 420-0008 02_戒疏/04b_卷一下之二
     原: 【記】作持中，躡前生起。「必」下，釋義，亦五。初釋作。「有」下，明持。「持由」下，合名。「如」下，指事。衣、食、藥三，皆通受淨，房有制量、乞法。或可糞衣、乞食、樹下、腐藥，《羯磨疏》中科為「根本作持」。修道假此，故名「四緣」。「雜行」，總收眾共，皆作持攝。「此」下，示宗，可知。
  == 420-0003 02_戒疏/04b_卷一下之二
     原: 【記】名字中。「名」即是「字」，無別所以，不必強分。然須先了二名，並依受體而立。由本受時，不出二心，一者斷惡，二者修善。所發業性，即本願體。隨中守護，對分兩持，違反本受，即戒兩犯。
  == 420-0007 02_戒疏/04b_卷一下之二
     原: 【疏】惡既已離，事須修善。必當勤䇿三業，修習戒行。有善斯護，名之為「持」。持由作成，故號「作持」。如衣食四緣，威儀雜行，作意防擬，方成戒淨。此對修習善法為宗。
  == 420-0005 02_戒疏/04b_卷一下之二
     原: 【疏】所言「止」者，方便正念，護本所受，禁防身口，不造諸惡，目之為「止」。止而無違，戒體光潔，順本所受，稱之曰「持」。持由止成，號「止持戒」。如初篇等，可以自明。此對不作惡法為宗。
