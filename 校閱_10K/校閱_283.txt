# 校閱材料　第283檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【283-0001】01_行事鈔/12c_卷下之四#16
【原文】律云：僧十四日自恣，比丘尼僧十五日自恣。若大僧病、別眾、眾不和眾、不滿等，尼應遣問訊。尼眾病，乃至不滿，亦須問訊大僧。《十誦》云：差二勦了知法尼，往大僧中。
【譯文】律藏說：比丘僧於十四日自恣，比丘尼僧於十五日自恣。如果大僧（比丘僧）全體有病、別眾分黨、僧眾不和合、人數不足法定僧數等情況，尼眾應當派遣信使前往問訊。尼眾全體患病，乃至人數不滿，也必須問訊大僧。《十誦律》說：應當差遣兩位精明敏捷且通曉戒法（勦了知法）的比丘尼，前往大僧之中。

【283-0002】01_行事鈔/12c_卷下之四#17
【原文】問：何故制尼依大僧？答：《愛道經》云：女人但欲惑色、益壽、畜弟子，亦不欲學問，但知須臾之事。故依大僧。
【譯文】問：為何制定比丘尼必須依止大僧？答：《大愛道經》說：女人往往只貪著容顏美色、增益壽命、蓄養弟子，也不想求學問道，只知眼前的短淺瑣事。所以必須依止大僧。

【283-0003】01_行事鈔/12c_卷下之四#18
【原文】六明隨戒相。尼八重中，前四戒大同僧中，故不出。
【譯文】六明隨戒相。在比丘尼的八波羅夷（八重罪）中，前四條戒大致與比丘僧中相同，所以此處不再列出。

【283-0004】01_行事鈔/12c_卷下之四#19
【原文】摩觸戒。六緣成犯：一是人男子。二作人男子想。三彼此有染心。律云：謂意相染著也。四腋以下，膝以上，腕以後身分。甄去輕境，染心既微，必無陵逼之過，故犯輕罪。若尼以輕觸男重境，男以輕境觸尼重境，此二皆重；不要取二重境相觸也。五身相觸。除一有衣，一無衣；二俱有衣，不犯重。六隨觸多少，一一結重。尼摩觸戒，與大僧四種不同：一大僧就壞行中制，莫問死活，但觸著便犯，據有淫心；尼就陵逼中制，死者不犯。律云：染污心男子也。二僧則不簡女人大小；尼觸男子，取能行淫事。《十誦》：人男者，謂能作淫事。三僧隨觸境便犯；尼簡境有上下。四僧不問境染淨；尼觸必俱染心。《僧祇》：若尼輕處有瘡癰，得使男子治之，先令二女急捉，令不覺男子手；若重處者，使女人師治。《善見》：若比丘觸尼，尼身不動，受樂，隨處得罪。《四分》，同僧中。《十誦》：不犯者，父兄弟兒想，若水火刀杖惡緣等，一切無著心故；非無吉羅。
【譯文】摩觸戒。具足六種因緣構成犯戒：第一、對方是人類男子。第二、作人類男子想。第三、彼此雙方都有染著之心。律藏說：指心意互相染污貪著。第四、腋下以下，膝蓋以上，手腕以後的身分部位。甄別除去輕微部位，染著心既微弱，必定沒有受陵逼侵害的過失，所以只犯輕罪。如果比丘尼以自己的輕罪部位觸碰男子的重罪部位，或者男子以其輕微部位觸碰比丘尼的重罪部位，這兩種情況都結重罪；並不一定要雙方的重罪部位互相觸碰。第五、身體相觸。若排除「一方有衣、一方無衣」以及「雙方皆有衣」這兩種不犯重罪的情形（唯有雙方皆無衣而肌膚直接相觸，才犯波羅夷重罪）。第六、隨著碰觸的次數多少，每一次都結重罪。比丘尼的摩觸戒，與大僧有四種不同之處：第一、大僧是從敗壞梵行的角度制定，不論死人活人，只要觸及便犯，以具有淫心為準；比丘尼是從遭受陵辱逼迫的角度制定，碰觸死者不犯。律藏說：必須是有染污心的活男子。第二、比丘犯戒不挑選女人年齡大小；尼僧碰觸男子，以男子已具備行淫能力為限。《十誦律》說：人類男子，是指能夠行淫事的人。第三、比丘隨意碰觸任何身體部位便構成犯戒；尼僧則有區分身體部位的上下輕重。第四、比丘犯戒不論對方是否有染著心或清淨；尼僧犯戒必須雙方都具備染著之心。《摩訶僧祇律》記載：如果比丘尼在身體輕微部位長了瘡癰，可以讓男子為其醫治，但必須先讓兩位女子緊緊按住她，使她感覺不到男子的手；如果長在重罪部位，則必須讓女醫治病。《善見律毘婆沙》說：如果比丘碰觸比丘尼，尼僧身體不動，但領納快感，隨碰觸部位各得其罪。在不犯的開緣方面，《四分律》與比丘僧中相同；《十誦律》則記載不犯的情況是，作父親、兄弟、兒子想，或者遭遇水溺、火燒、刀杖等險惡因緣（為救難而觸碰），全都是因為沒有貪著之心的緣故；但並非完全沒有突吉羅輕過。

【283-0005】01_行事鈔/12c_卷下之四#20
【原文】八事成重。五緣：一人男，二人男想，三有染心，四犯前七事未懺，五八事作，犯。八事：一捉手者，乃至腕。二捉衣者，身上衣。三入屏處者，謂離伴見聞處。四屏處立、語、行等；三事，亦爾。七身相倚者，二身相及。八共期者，共行淫處。若尼男俱染，犯上七事，七偷蘭；若不懺，犯八事，波羅夷。準此，犯八捉手，不成重；若一男犯八、一時犯八、八年犯八、八男成八，但成八，重；亦無次第。《僧祇》如此。不犯者，若有所施與、若禮拜、若悔過、若受法入屏處，不作惡事，不犯，由俱無染心故。下入闇室犯墮者，由無所為，事涉譏醜故犯。
【譯文】八事成重。具備五種因緣構成犯戒：第一、對方是人類男子；第二、作人類男子想；第三、懷有染著心；第四、犯了前七件事而未曾懺悔；第五、做了第八件事，便犯戒。八事分別是：第一、捉手，指握手乃至手腕；第二、捉衣，指拉扯身上的衣服；第三、進入隱蔽處，指離開同伴眼見耳聞之處；第四、在隱蔽處站立；第五、在隱蔽處交談；第六、在隱蔽處同行（這三事也是如此）；第七、身體相倚，指兩人身體互相接觸倚靠；第八、共同約定，指約定一同前往行淫之處。如果尼僧與男子都有染著心，犯了上面前七件事，結七個偷蘭遮罪；如果沒有懺悔，又犯了第八事，便結波羅夷重罪。依照此理，僅僅犯了八次握手，不能構成重罪；如果同一名男子犯齊八事、同一時間犯齊八事、歷經八年犯齊八事、或者與八個男子各犯一事累計成八事，只要八事具足，就結重罪；而且不論發生的前後順序。《摩訶僧祇律》也是這樣規定的。不犯的情況是：如果有財物布施、或是禮拜、或是悔過、或是為聽受教法而進入隱蔽處，不做惡事，都不算犯戒，因為雙方都沒有染著之心的緣故。至於下文提到進入暗室犯波逸提（單墮罪），是因為沒有正當事由，牽涉到譏嫌醜惡，所以犯戒。
