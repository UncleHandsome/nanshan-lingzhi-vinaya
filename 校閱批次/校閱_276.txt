# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 校閱材料　第276檔

【276-0001】01_行事鈔/10c_卷下之二#30
【原文】四明觀法。然衣、食、房、藥四事供養，能施捨慳，受施除貪；此則能所俱淨，生福廣利。若彼此隨情，縱逸任性者；則俱墮負，聖賢同非。故《涅槃》云：或令施主果報減少，或復無報等。雖利養等同，發有希數。食為大患，時須進口；過興既數，整法亦難；若不策其心府，改其節操者，多陷迷醉矣。夫沙門之異俗，由立行有堅貞；同鄙世之昏悶，餘行亦可知矣。故《成論》云：現見在臭屎中生，不在磐石中者，由貪味香故也。今故約食時立觀，以開心道。略作五門，《明了論》如此分之：初計功多少，量他來處。《智論》云：思惟此食，墾植、耘除、收穫、蹂治、舂磨、洮沙、炊煮乃成，用功甚多；計一鉢之食，作夫流汗，集合量之，食少汗多。須臾變惡。我若貪心，當墮地獄噉燒鐵丸，從地獄出作諸畜生償其宿債，或作猪狗常噉糞除。故於食中應生厭想。《僧祇》云：告諸比丘，計此一粒米，用百功乃成，奪其妻子之分，求福故施，云何棄之。二自忖己身德行。《毘尼母》云：若不坐禪、誦經，不營佛法僧事，受人信施，為施所墮。若無三業，知故而施，俱為施墮。比丘強飽食施主食，憍慢意或自食己食，強飽過分，為施所墮；以其食亦從施主得故。何以故？佛長夜中，常嘆最後限食。施持戒者，能受能消；施持戒果報大，破戒果報少。足食已，更強食者，不加色力，但增其患，故不應無度食。三防心離過。《明了論疏》云：律中說，出家人受食，先須觀食，後方得噉。凡食有三種：上食起貪，應離四事：一喜樂過，貪著香味，身心安樂，縱情取適故；二離食醉過，食竟身心力強，不計於他故；三離求好顏色過，食畢樂於光悅勝常，不須此心；四離求莊嚴身過，食者樂得充滿肥圓故。二者下食，便生嫌瞋；多墮餓鬼，永不見食。三者中膳，不分心眼，多起癡捨；死墮畜生中，作諸噉糞樂糞等蟲。初貪重故，並入地獄。且略如此。反此三毒，成三善根，生三善道；謂無貪故生諸天，中、下二可知。四正事良藥觀，分二：為除故病，飢渴不治，交廢道業；不生新病，食飲減約，宿食消滅。又以二事為譬：初如油膏車，但得轉載，焉問油之美惡。二欲度險道，有子既死，飢窮餓急，便食子肉，必無貪味。五為成道業觀，三種：一為令身久住故，欲界之身，必假摶食，若無不得久住，道緣無託故。二為相續壽命，假此報身假命，成法身慧命故。三為修戒定慧，伏滅煩惱故。《持世》云：若不除我倒，此是外道，不聽受人一杯之水。《佛藏》亦爾。必厭我倒，於納衣麁食，不應生著。
【譯文】四明觀法。衣服、飲食、臥具房舍、醫藥這四事供養，布施者能藉此捨離慳貪，受施者能藉此消除貪愛；如此則能施與受施雙方皆得清淨，方能生廣大福德與殊勝利益。如果雙方都隨順世俗凡情，縱逸放任心性；則彼此都會墮入虧欠辜負之中，同為一切聖賢所呵斥斥責。所以《大般涅槃經》說：這樣做有時會令施主的福報減少，有時甚至完全沒有果報等。雖然這四種利養本質相同，但其引發過失的頻率卻有稀有與頻繁之別。其中以飲食為最大的禍患，因為時刻都需要送進口中；過患生起既然如此頻繁，要整肅修行法度也就更加困難；此時若不策勵自己的心神內府，痛改自己的品行節操，多半會沉陷於貪食迷醉之中。沙門之所以有別於世俗凡夫，全在於立身行持具有堅定貞純的操守；如果與鄙陋世人一樣昏昧沉淪，其餘的修行德行如何也就可想而知了。所以《成實論》說：眼見蛆蟲在臭糞便中滋生，卻不在堅硬的磐石中化生，這就是因為貪愛氣味香味所致啊！因此如今專就進食之時確立觀想之法，以開啟通達修道之心。此觀法大略分為五門，《明了論》便是如此劃分的：初門、「計功多少，量他來處」（審計勞動工夫之多寡，思量食物從何而來）。《大智度論》說：應當思惟這份食物，必須經過墾荒耕種、耘鋤除草、收割成熟、踐踏脫粒、舂搗磨粉、淘洗沉沙、生火炊煮等諸多程序方能製成，所耗費的工夫極其繁多；估算這一鉢的食物，農夫勞作者所流下的汗水，若聚合起來計量，食物微少而汗水巨多。而且一經吃下，片刻之間便化為污穢惡濁之物。我若對此生起貪婪之心，命終當墮入地獄吞食燒紅鐵丸，從地獄出來後當投生為各類畜生償還宿債，或者化作豬狗常年吞食糞便污穢。因此面對食物應當生起厭離想。《僧祇律》說：佛告諸比丘，計算這一粒米，需要耗費上百道人工勞力方能長成，這是施主省下剝奪自己妻兒的份額，專為求取福報而來布施的，你們怎能輕率糟蹋拋棄呢？二門、「自忖己身德行」（自省自度己身的修持德行是否全缺）。《毘尼母經》說：若不能精進坐禪、讀誦經典，又不為佛法僧三寶營辦弘化修護事業，白白接受他人的信施，必將為信施所累而墮落。若比丘毫無上述三種德業，施主明知卻依然故施，二人皆會因這場布施而墮落。比丘勉強自己強行吃飽施主的食物，心懷傲慢之意；或者自己吃自己的食物，勉強吃得過飽超量，都會為飲食所累而墮落；因為自己所有的食物歸根結底也是從施主那裡獲得的。為什麼呢？因為佛陀在長劫說法中，經常讚歎「留有餘地、適可而止的最後限量飲食」。布施給持戒清淨的人，受施者能安心承受亦能消化其福報；布施持戒者所獲果報廣大，布施破戒者所獲果報微少。進食已足之後，若再勉強強食，不僅不能增長體力色澤，只會增加肉身的病患，故不應無度食。第三門、「防心離過」（防護自心、遠離過咎）。《明了論疏》說：律中說，出家人受用食物，必須先如法觀想食物，然後才能進食。大凡食物可分為三種：面對上等美食容易生起貪心，應當遠離四種過患：一是喜樂過，貪著食物的香美味道，貪求身心安適快樂，放縱情欲以取適性；二是離食醉過，吃完後身心力氣充實強壯，便傲慢不顧及他人；三是離求好顏色過，吃完後貪樂容光煥發光潤悅目勝於平常，不應當存有這種妄心；四是離求莊嚴身過，進食者貪求體魄充實肥滿圓潤。第二種是面對粗劣下等食物，容易隨之生起嫌棄瞋恨之心；這種人死後大多墮入餓鬼道中，永世見不到食物。第三種是面對中等平常飲食，心念與眼界往往不加辨析分別，多半生起愚癡、隨便任性的捨受心；死後將墮入畜生道中，成為各類以吞食糞便、樂居糞穢為生的蟲類。第一種上等飲食因為貪心深重之故，皆墮入地獄之中。大略情況如此。若能反轉此三毒惡心，便成就三善根，生於三善道中；也就是說因不起貪心而得生天界，中品無癡與下品無瞋的生處由此亦可類推得知。四門、「正事良藥觀」（將飲食真正當作療養身病的良藥之觀想），此分為兩點：一是為除舊病，飢渴若不及時醫治，勢必會耽誤荒廢修道事業；二是為不生新病，飲食簡約節制，使腹中宿食能夠消化，新病便無由而生。又以兩件事物作為比喻：首先如同油脂潤滑車軸，只是為了讓車輪能夠運轉載物，哪裡會去過問油脂是香美還是惡臭呢？其次如同想要橫渡險惡艱難之道，行人的兒子不幸死去，由於飢困窮蹙逼迫到了極點，迫不得已只能食用親生兒子的肉，這時心中必定全無貪求美味之念。五門、「為成道業觀」（為了成就出世道業之觀想），包含三點：第一、為了讓色身能長久住世，欲界的血肉之軀，必須依憑「段食（摶食）」的滋養，若無飲食則色身無法久存，修道的憑藉便無所寄託。第二、為了使生命得以延續，假借這個業報假身的短暫壽命，以成就法身與慧命。第三、為了精修戒、定、慧三學，降伏斷滅內在一切煩惱。《持世經》說：若不破除我見顛倒，便與外道無異，根本不聽許接受他人哪怕是一杯水的供養。《佛藏經》也有同樣的教誡。因此必須深切厭離我見顛倒，對於粗糙的補衲衣物與粗淡的劣質食物，絕不應生起絲毫的貪執沾著。

【276-0003】02_戒疏/14c_卷三下之二#63
【原文】【註】比丘尼吉羅。不犯者：若持至三由旬；若減三由旬；有人，語持，中間不助；使尼四眾，齊三由旬；若擔毳𮖢、毳繩；若擔頭上毛；作帽、巾者，得。
【譯文】【註文】比丘尼犯此戒結突吉羅罪。不構成犯戒的情況包括：如果攜帶剛好到三由旬；或者少於三由旬；或者有人答應代挑，自己在中間絕不插手相助；役使比丘尼等四眾攜帶，正好達到三由旬而止；如果挑擔的是細絨線、細絨繩；或者挑擔的是羊頭頂上的雜毛；用來準備做帽子、頭巾等物的少量毛料，這些均可開許。

【276-0004】02_戒疏/14c_卷三下之二#64
【原文】【疏】戒本五句：一、犯人；二、「道路行」下，立法，注解，文相可知；三、「若無人」下，明戒業也；下二，可知。
【譯文】【疏文】戒本條文共有五句：第一句、犯戒的人身；第二句、「道路行」以下，屬於開立的法度，戒本注文已有解釋，文理相狀容易理解；第三句、「若無人」以下，說明具體構成戒罪的造作行為；最末兩句，文意容易理解。

【276-0005】02_戒疏/14c_卷三下之二#65
【原文】【記】戒本中，初科。第二句指「注解」者。注中，初明得取自持限滿。「若有人」下，次明倩他續持。「若令」下，三、明使餘眾持。「除」下，四、明諸輕物。
【譯文】【記文】戒本之中，第一科。第二句之所以指稱看「注解」，是因為在注文中，起初說明了得以收取並由自己攜帶的最大路程限度。「如果有人」以下，接著說明聘請請求他人接續攜帶的規範。「若是役使」以下，第三說明指使其他四眾弟子代攜的罪責。「除羊毛外」以下，第四說明挑攜各種輕賤非制物品的罰則。

【276-0010】02_戒疏/14c_卷三下之二#70
【原文】【疏】制戒意，成犯緣，同上浣衣戒。彼制故者，新是輕犯，此既勞功，新故同犯。

【276-0013】02_戒疏/14c_卷三下之二#73
【原文】【註】佛在迦維羅衛。六群比丘取羊毛使尼浣、染、擗之。時，姨母尼為染毛故，汙色在手，往佛所，禮足而立。佛知故問，訶而制戒。
【譯文】【註文】佛在迦維羅衛國時。六群比丘拿了羊毛役使比丘尼代為清洗、染色、分撕梳理。當時，身為佛陀姨母的大愛道比丘尼因為染羊毛的緣故，手上沾染了顏料汙漬，便前往佛陀處所，頂禮佛足後肅立在一旁。佛陀明明知曉卻故意發問，隨後加以訶責並制定了戒律。

【276-0014】02_戒疏/14c_卷三下之二#74
【原文】【疏】就戒緣中，「姨母為染」至「佛所禮足而立」者。《多論》云：「所以制者。與諸比丘增上法故，若諸尼眾執作浣染，廢修正業，則無威儀，破增上法。又止惡法次第因緣，各令清淨故。」所以不坐者，女人敬難情多，又佛不廣為女眾說法，又尼至佛所，一切皆立，為止外道誹謗故，又女人鄙陋，多致譏疑，所以不坐。
【譯文】【疏文】在戒律制定的因緣中，「姨母為其染毛」以至「前往佛所禮足肅立」的記載。《多論》說：「之所以要制定此戒，是為了給予諸比丘長養增上善法的緣故，如果眾比丘尼全去操持粗重的洗滌染織雜務，荒廢了自己修道的正業，就會喪失出家人的威儀，從而破壞了比丘引導眾生證得增上法的使命。此外也是為了在最初便止息惡行相續蔓延的因緣，讓僧尼各自保持清淨。」而比丘尼禮佛後之所以站著而不坐下的原因，其一是女人對佛的敬畏與難為之情較多；其二是佛陀通常不為女眾作長篇繁複的說法；其三是尼眾到了佛陀面前，一律保持站立，是為了止息外道誣衊譏諷的誹謗；其四是世俗看待女人較為低賤鄙陋，坐著容易引發世人譏評猜疑，所以站著不坐。

【276-0015】02_戒疏/14c_卷三下之二#75
【原文】【記】戒緣中。初牒文徵意。《多論》下，引釋，有二。初釋制戒，有二意：初意「與比丘增上法」者，由尼執作廢業乖儀，則是比丘破增上法；次意「止惡法次第」者，禁輕防重故。「所以」下，次明不坐，四意釋之。第二說聽非久，故不須坐，餘三可解。注中「姨母」，即大愛道尼。「汙手見佛」，發請制戒也。
【譯文】【記文】在戒緣之中。起初引提經文並推究深意。《多論》以下引導解釋，分為兩個部分。首先解釋制定戒律的原因，有兩層意圖：第一層「給予比丘增上法」，是因為尼眾若忙於勞務而荒廢道業、威儀失序，這等同是比丘在破壞增上法；第二層「止息惡法次第蔓延」，是為了從小事禁防以防止嚴重大過。「所以」以下，接著說明尼眾不就坐的原由，共用四個觀點加以解釋。第二點提到因為說法與聽法時間不會很久，所以不必坐著，其餘三點容易明白。注文中所說的「姨母」，就是大愛道瞿曇彌比丘尼。「雙手染汙面見佛陀」，這正是觸發並請求佛陀制定戒律的機緣。
