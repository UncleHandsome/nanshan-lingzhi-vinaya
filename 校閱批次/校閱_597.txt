# 校閱材料　第597檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第四安置者僧祇若大德應在露處上好房中擬道俗問訊生善瞻病人每須燒香然燈香水塗地供待人客見論看病人讚病者言長老持戒具足莫戀著住處及衣物知識明友但存念三寶及念身不淨於三界中慎莫懈怠隨命長短而作如西國祗桓圖云寺西北角日光沒處為無常院若有病者安置在中堂號無常多生厭背去者極多還唯一二其堂內安一立形像金色塗之面向西方其像右手舉左手中繫一五色綵幡令病人手執幡脚作往生淨土之意雖有便利世尊不以為惡原其此土本是雜惡之處猶降靈俯接下類羣生令度苦海況今信心將命投佛而棄捨之隨病者所緣何境或作彌勒阿閦等形如前安置燒香散華種種莊嚴生病者善心。
【譯文】第四項安置處所：《僧祇律》說：若是大德高僧患病，應安置在開闊通風的優質房舍中，便於俗人與僧眾前來慰問問訊、生起善心；看病之人必須時常燒香點燈，以香水塗抹地面，妥善接待來客。《善見論》說：看病之人應讚歎病患說：「長老平日持戒具足，切莫依戀顧惜住處、衣物及同修善知識，只要一心專念三寶、專念色身不淨，在三界生死中切莫鬆懈放逸，隨壽命長短安心受報。」如同西域祇洹精舍圖示所繪：寺院西北角夕陽落下的方位，設立無常院，若有患病者便安置在其中。這座殿堂定名為無常院，能讓走進去的人多生起厭離世間之心，去的人極多，能病癒返回的原只是一二人。堂內安置一尊立姿佛像，通體塗敷金色，面朝西方；佛像右手高舉，左手中繫著一條五色綵幡，讓病患手握著幡角，生起往生西方淨土的意願。病房中雖然常有便溺穢氣，世尊並不以為厭惡。探究原因，我們這個娑婆世界本來就是雜染險惡的地方，世尊尚且降下神靈垂念救接下等凡愚眾生，令其度脫苦海；何況如今病人生起堅定信心、以命歸投佛陀，佛陀豈有遺棄捨下之理？隨病患心中平素歸向何等淨境，也可以塑造彌勒菩薩、阿閦佛等聖像，依照前面的方法安置，燒香散花，種種莊嚴，引發病人的善念信心。

【597-0012】04_比丘尼鈔/06b_卷下之下#6
【原文】第二銅鐵瓦木者此律云銅缾盆器繩牀水缾澡罐錫杖扇斧鑿燈臺机案車轝及鐵皮竹木陶作器等此下五種作器並是能造判重剃刀入輕錢寶等入重十誦云一切染色若煑未煑不應分準諸作具類從入重僧祗錢七寶珠木槃木盆竹笤等入重見論云鍼線入輕楞伽經云為割截袈裟故畜四寸刀頭如月刃義判入輕過量白鐵瓷瓦鉢等入重若生時造諸擬送終調度等並判入重若生存之日為師僧父母所造隨入輕亡人所屬鏡及屏風障子鎻等以妨長故義判重收此律俱夜羅器者相傳云銅盌是入輕十誦云鍵𨩲者謂小盌也出要律儀云鍵𨩲者為助食器秦言淺鐵鉢也義準供養具經架佛牀机案拂等及襯香鑪衣香鑪經櫃等若無心作作時唯擬入佛法供養者隨亡人意入佛法用不得追奪以別屬故若生時是己物造作或他人布施無別的標者香爐經架準十誦入輕母論隨能供養者與若有寶物莊嚴不可脫者入輕寶物入重其餘雜香案隨香鑪斷自外佛牀曲机夾膝如意杖案拂經櫃等亡人生存不定屬佛法者死後入重若定入佛法者隨亡者意唾壺入重木槵木蘭竹節數珠澡豆麪瓠𤬛以隨身長道要故入輕義判鐘錢殘物等施主定屬鐘者還入鐘用若施主通者殘物入常住僧。
【譯文】第二項是銅、鐵、瓦、木所製成之物，本律說：銅瓶、盆器、繩床、水瓶、澡罐、錫杖、扇、斧、鑿、燈台、几案、車轎，以及鐵、皮、竹、木、陶製器具等，這後五種製造工具皆能造物，故判入重物，剃刀入輕物，錢財珍寶等入重物；《十誦律》說，一切染料不論煮過或未煮過皆不可分配，比照各類作具依例判入重物；《僧祇律》說錢、七寶、珍珠、木盤、木盆、竹掃帚等入重物；《善見論》說針線入輕物；《楞伽經》說為裁剪袈裟故蓄持四寸如月牙形之刀，義理上判入輕物；超量之白鐵、陶瓷、瓦缽等入重物；若生前製造各類打算送終的器具等，皆判入重物；若在生之時為師長、僧眾、父母所造，隨之判入輕物；亡人所屬之鏡子、屏風、障子、鎖匙等，因容易助長貪愛，義理上判歸重物；本律中的俱夜羅器，相傳是銅碗，入輕物；《十誦律》說鍵𨩲是指小碗；《出要律儀》說鍵𨩲是助食器，秦言稱為淺鐵缽；義理上比照供養器具、經架、佛床、几案、拂塵等，以及襯香爐、衣香爐、經櫃等，若無特定心意製作，製作時純粹打算供養佛法者，隨亡人本意歸入佛法受用，不得追索奪回，因已有特別歸屬之故；若是生前用自己財物造作，或他人布施而無特別標明用途者，香爐、經架依照《十誦律》入輕物，《毘尼母論》說給予能夠供養之人；若有寶物裝飾而不可拆卸者入輕物，寶物部分入重物；其餘雜香案比照香爐裁斷；此外佛床、曲几、夾膝、如意杖、几案、拂塵、經櫃等，亡人活著時未特定歸屬於佛法者，死後入重物，若特定歸入佛法者，隨亡者本意處置；唾壺入重物；木槵子、木蘭、竹節念珠、澡豆、麵粉、匏瓜杓等，因隨身修道所必需，故入輕物；義理上判定鑄鐘的餘錢與殘物，施主若明確指定歸鐘用者，仍歸鐘用，施主若泛指無定者，殘物歸常住僧。

【597-0013】04_比丘尼鈔/06b_卷下之下#7
【原文】第三田宅園林者入重十誦赭土入重義判雌黃白墡入重。
【譯文】第三項是田地、宅舍、園林，皆判入重物；《十誦律》說赭土入重物，義理上判定雌黃、白堊土亦入重物。
