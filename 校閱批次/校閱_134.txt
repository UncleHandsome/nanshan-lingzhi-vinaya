# 校閱材料　第134檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【134-0001】資持記/01a_上一上#34
【原文】及乎取彼要當，還屬鈔取；自餘不引，始號刪繁；故鈔興意中但云情見，不言疏鈔也。二明補闕者。自古持律，或隨己執見、或暗於教部，至於行事，未適時宜。如尺量短長、由旬大小、羯磨例皆白讀、問難不取解知、臥具謂非三衣、畜長不科減量、淨地不立唱相、七證全無請詞；
【譯文】等到摘取那些精確適當的部分，依然屬於《事鈔》的採納；其餘不予引用的，才稱為「刪繁」；所以《事鈔》發起旨趣中只說「情見」，並未單指注疏鈔記。第二說明「補闕」：自古以來持律的人，有的隨順自己的偏執見解，有的對教法部派昏昧不明，以至於在實際行事時，未能切合時宜規範。例如尺規長短的標準、由旬大小的折算、羯磨表白一概照本宣科盲目宣讀、審問遮難不審查其是否真正理解知曉、以為臥具不屬於三衣範圍、蓄長衣戒中不對減量衣科判定罪、劃定淨地不宣告立定界相、七位證戒師完全沒有迎請之詞；

【134-0002】資持記/01a_上一上#35
【原文】斯類極多，例皆遺闕。今鈔約義準文，補令詳備。故下房戒，定尺量已，云余曾遊晉魏及以關輔，諸方律肆，每必預筵；至論尺斗廢興，曾未霑述；故即補闕，反光九代。〔印本作故即刪補，然既未霑述，豈得有刪？今準古本為正。〕今以往古未論之事，即為所補；
【譯文】這種類型非常之多，向來全都遺漏殘缺。如今本《事鈔》依據義理、比照經律正文，予以補足使其周全詳備。所以下文在〈房舍戒〉確定尺規尺度之後，說道：「我曾遊歷晉魏及關中、輔畿之地，諸方的律學講肆，每次必定參與法席；但講論到尺與斗等度量衡的廢弛興立，卻從未有人談及；所以隨即予以補闕，光照反哺九代以來的盲點。」（印本寫作「故即刪補」，但既然前人從未論及，哪裡談得上「刪」？如今應當以古本為準才是正確的。）如今把往古不曾論及的事項，作為「所補」；

【134-0003】資持記/01a_上一上#36
【原文】鈔中所引文義理例，是為能補。問：補闕與下文義決通，為同為異？答：決通通先有，補闕局元無。餘如序中第五門說。問：《隨機羯磨》云：律藏殘缺，義有遺補，豈非補律？答：正由律缺，行事不周；故引文約例，補彼羯磨。至如律文，仍前自缺，何嘗補之。
【譯文】鈔中所引用的文義、理路與條例，就是「能補」的主體。問：補闕與下文所說的「義理決通」，是一樣還是不同？答：「決通」是通達原本就已經存在的文義，「補闕」則局限於補足原先根本沒有的內容。其餘詳情正如序文第五門中所說。問：《隨機羯磨》說：「律藏殘缺，義理上有所遺留補充」，這難道不是「補律」嗎？答：正是由於律藏有所缺失，行事才不夠周全；所以引用教文比照通例，來彌補那部《羯磨》行事。至於律藏本文，依然維持它原本的缺失，何曾去改動填補律文呢！

【134-0004】資持記/01a_上一上#37
【原文】問：《輕重儀》云：刪補舊章，撰述事鈔；準此刪補不在於律，如何不許刪補章疏？答：所刪所補，多出舊章；能刪能補，並見今鈔。但章疏語局。情見言通，口授文傳，理無不攝。請詳鈔意，勿事遲疑。行事者，行以運造為義，事即對理彰名。然事相多途，義須精簡。
【譯文】問：《輕重儀》說：「刪補舊章，撰述事鈔」；照此看來刪補不在於律藏，為何不承認是刪補舊章疏？答：所刪除和所彌補的內容，大多出自舊章疏；能刪除和能彌補的評述，全都見於現在這部《事鈔》。只是「章疏」的用詞太狹隘，而「情見」的說法更通達，舉凡口傳與文字記述，在理路上一概都能涵蓋。請詳加體察鈔記的深意，切莫遲疑不決。「行事」者：「行」以運轉造作為義，「事」則是對應「理」而彰顯的名稱。然而事相有許多途徑，在義理上必須精確揀別。

【134-0005】資持記/01a_上一上#38
【原文】初以事通善惡，此唯善事。二就善中簡餘泛善，局明戒善。三約上下兩卷眾共二行名作善；中卷自行名止善。四約諸篇細分諸事。上卷十二篇：標宗一篇，總勸行事。集僧已下有五事：初眾法緣成事〔集僧、足數、受欲、羯磨、結界，五篇。
【譯文】首先，「事」通於善事與惡事，此處專指善事。第二，就善事之中淘汰其餘泛泛的世間善行，局限專明戒律之善。第三，就上下兩卷的眾行與共行這二行稱為「作善」；中卷個人自行修持的稱為「止善」。第四，依據各篇細緻劃分各項事相。上卷十二篇：〈標宗顯德篇〉一篇，總括勸導奉行戒事。自〈集僧篇〉以下有五件事：第一是大眾僧法因緣和合成就之事（包括集僧、足數、受欲、羯磨、結界五篇）。

【134-0006】資持記/01a_上一上#39
【原文】二匡眾住持事〔僧網〕，三接物提誘事〔受戒、師資〕，四檢察清心事〔說戒、自恣〕，五靜緣策修事〔安居〕中卷四篇，有二事：初專精不犯事〔篇聚、釋相、持犯〕，二犯已能悔事〔懺篇〕下卷十四篇分八事：初內外資緣事〔二衣、四藥、鉢器〕，二節身離染事〔對施、頭陀〕，三卑己謙恭事〔僧像〕，四外化生善事〔訃請、導俗〕，五待遇同法事〔主客、瞻病〕，六日用要業事〔雜行〕，七訓導下眾事〔沙彌及尼〕，八旁通異宗事〔諸部〕。
【譯文】第二是匡正僧眾、住持正法之事（僧網篇），第三是接引物情、提攜誘導之事（受戒、師資二篇），第四是檢討察驗、清淨身心之事（說戒、自恣二篇），第五是寂靜塵緣、策勵修持之事（安居篇）。中卷四篇，包含二件事：第一是專精持守、不犯戒規之事（篇聚、釋相、持犯三篇），第二是犯戒之後能如法悔過之事（懺篇）。下卷十四篇，劃分為八件事：第一是內外資助生活之緣之事（二衣、四藥、缽器三篇），第二是節制身心、遠離染著之事（對施、頭陀二篇），第三是謙遜低下、恭敬行禮之事（僧像篇），第四是對外化導、生發善心之事（訃請、導俗二篇），第五是接待照顧同修道友之事（主客、瞻病二篇），第六是日常所需必要道業之事（雜行篇），第七是訓育引導下位僧眾之事（沙彌及尼篇），第八是旁通不同部派宗風之事（諸部篇）。

【134-0007】資持記/01a_上一上#40
【原文】是則一部始終所詮行相，無非三業鼓動方便緣搆而成，故云行事。首題標此，特異群宗；本設化根源，正教詮宗骨。反光九代，斯言不虛。故序云顯行世事，方軌來蒙者，百無一本。此乃一家大要，遍見諸文。凡預學宗，彌須詳練；苟迷斯旨，餘復何言！問：準下持犯，事法兩分；
【譯文】這便是整部書自始至終所詮釋的行持相貌，無非是由身口意三業的發動、借方便因緣構造而成就的，所以稱為「行事」。在書本首題標出「行事」，特別不同於其他各宗；這正是如來施設教化的根本源頭，更是整部律教詮顯的核心骨幹。能夠反照光耀九代以來的迷夢，這句話絕非虛妄。所以序文說「顯揚推行世間事相，規範教導後進蒙童者，百本之中無有一本」，這正是我們一家律學的大要，普遍見於各部著述。凡是發心學習律宗的人，更必須詳加熟練體會；如果迷失了這個宗旨，其餘的還有什麼好談的呢！問：依照後文持犯篇，事相與法相是分開的；

【134-0008】資持記/01a_上一上#41
【原文】今唯題事，則非攝法？答：彼明止作，各攝分齊，故須兩分。今望運造，無問事法，通歸事耳。問：題云行事，下云三行；語音別召，同異云何？答：行據造修，行取成德。由行成行，語別義同。莫非流入行心，緣構成業也。鈔者，有二義：一採摘義，二包攝義。
【譯文】如今書題只標「事」，難道就不涵蓋「法」嗎？答：那裡是在明析止持與作持各自含攝的分際，所以必須分成兩半。現在若從身心發動造作的角度來看，不論是事還是法，通通歸結於「事」而已。問：書題稱為「行事」（動詞行），下文說「三行」（名詞行）；語音稱呼不同，兩者的同異是什麼？答：「行（動）」著重在造作修持，「行（名）」著重在成就德行。由於行持造作而成就了德行，字音雖別而義理相通。無非都是流入實踐的心念，藉由因緣構造成為業行。「鈔」字有兩種含義：一是採摘義，二是包攝義。

【譯文】前人既然迷失了教旨，所執的法義便毫無依憑；同一黨派的人便盲從苟同，互相憎惡嫉妒的人便故意立異；世間的這種情狀親眼可見，古往今來都是如此，所以說「同異紛呈」等。「區」也是劃分的意思。在第三小節中。因為前述種種相異的見解，固執諍論紛紛揚揚，是非對錯難以判定，使人遲疑不決；所以必須推崇博學深識之士，才能加以裁奪決斷。在經文中，前兩句是簡擇其是否具有這等能力。上一句說明精通窮究律藏，教法有廢止與興起之分，偏執狹隘的人固執己見便會造成爭論。

【134-0051】資持記/01b_上一上#19
【原文】下句明評量諸師，釋說多異，後進未達，取捨莫從。必具二能，方堪此任，故云自非等。孰能下，顯餘人不能。闢即開也。重疑者，謂展轉生疑。如執夏中不得解界，人已生疑；因又疑曰：必若解之，為成夏否？又如執一夏三度受日疑云：必欲重受，為失夏耶？又如小界立相疑云：必行受戒，為得戒否？
【譯文】下一句說明評量考究諸位律師的見解，諸師解釋學說大多不同，後進晚輩未能通達，往往不知道該如何取捨。必須同時具備這兩種能力，才能勝任這項重任，所以說「自非」等語。「孰能」以下，顯示其他人無法辦到。「闢」就是開通消解。「重疑」是指輾轉接連產生疑惑。例如執泥於夏安居當中不得解散界相，眾人本已心生懷疑；接著又懷疑說：如果一定要解散它，安居到底算不算成立？又如執泥於一夏之中只能三次受日外出，便疑慮說：如果必須再次受日，是否會喪失安居資格？又如在小界建立相界，眾人便疑慮說：若真在此受戒，到底能不能得戒？

【134-0052】資持記/01b_上一上#20
【原文】略舉數端，以遣文相；凡此之類，隨時引之。大論疑者，事既不明，任運滋廣，故云重疑。遣猶除也。累字去呼，謂滯礙也；心既有疑，事即成礙。人無不爾，故云通也。或作罪累釋者，如執夏末受日，十五限滿不還成夏。又七日藥開無內宿，盜常住物令奪取等；足使人疑，依行有罪。
【譯文】大略列舉幾項端倪，來說明經文的含義；大凡這一類的疑惑，隨時都可舉出。總括論述疑惑這件事，事理既然不明確，疑惑自然就會滋長擴大，所以說是「重疑」。「遣」猶如消除。「累」字讀去聲，是指滯礙不通；心裡既然有了疑惑，做事就會窒礙難行。人人都無可避免，所以說是「普遍通病」。或者將它解釋為「罪累」，例如執泥於夏末受日外出，滿了十五天的期限不歸來仍算成就安居。又如將七日藥開許為不犯宿藏，甚至偷盜常住僧物卻令其奪回等；這足以使人生疑，若依之實行便會獲罪。

【134-0053】資持記/01b_上一上#21
【原文】必決其疑，則令離過，故云遣也。此二句對上考諸說虛實。括下二句，對上統教意廢興。部執且指五部；五師情見，岳立不同；若偏守一宗，則必成諍論；故須統括考校異同，斟量取捨，方明行事，故云爾也。與字平呼，即語詞也。〔此四句二事，古作四義釋者，非。〕次明撰集，別斥中，初科，上二字傷歎。
【譯文】若是徹底決斷這些疑惑，便能使大眾遠離過失，所以說是「遣除」。這兩句是相對於上面的「考究諸家學說之虛實」而言。「括」字以下的兩句，是相對於上面的「統攝教理大意之廢興」而言。「部執」暫且指小乘五部律；五部律師的見解，如高山峙立互不相同；如果偏執守著某一宗，則必然造成爭論；所以必須總括考究校驗其異同，權衡斟酌如何取捨，才能明曉法事的實踐，所以才這樣說。「與」字讀平聲，在此是語助詞。〔這四句兩件事，古人作四種義理來解釋，那是錯誤的。〕接著是說明著述撰集、分別斥責前人缺失的段落，在第一小科中，前兩個字是傷痛感歎。

【134-0054】資持記/01b_上一上#22
【原文】前下，敘其虛費；上二句總示所出。遺記者，通目疏鈔，如第十門具列者是。下二句別列非相。言止論者，貫下兩句。謂撰疏者但相廢立，作鈔者唯逞難問，更無他意故也。如義鈔兩疏時或引之是也。問：此中既斥，彼那引之？答：此明行事，故須奪破；彼演義章，不妨引用。
【譯文】「前」字以下，敘述前人的徒勞虛耗；前兩句總括指出其著作來源。「遺記」是通稱各家的疏與鈔，如同第十門中所具體列舉的那些便是。後兩句分別列出其缺失的形相。「止論」這兩個字，貫通貫穿下面的兩句話。意思是說撰寫章疏的人只懂得互相廢立爭辯，編寫鈔書的人只顧著賣弄問答詰難，再也沒有其他利益與深意了。就像《義鈔》以及二疏（《戒疏》、《業疏》）有時所引用的那些情況便是。有人問：這裡既然予以斥責，為何那邊又加以引用呢？回答說：這裡是著眼於實踐行事，所以必須破除奪取；那邊是在敷演義理章句，不妨加以引用。

【134-0055】資持記/01b_上一上#23
【原文】又古文極繁，彼唯摘要取其少分以辨是非，所以義鈔題云拾毘尼義是也。至下，斥其失宗。行事訓蒙，毘尼宗體；於茲既失，餘不足言。今鈔首題，即彰此意。高超遠古，深契佛心；紐絕扶顛，誠在於此。是以諸篇演布，唯存行事為宗；隨處提撕，專以訓蒙為意；
【譯文】何況古人的文獻極其繁複，彼處只是摘錄其要點取其少部分來辨明是非，所以《義鈔》的題目才叫做《拾毘尼義》便是這個道理。「至」字以下，是斥責其喪失了宗門根本。付諸實踐行事、訓導啟發蒙昧，是毘尼戒律的宗要本體；在這一點上既然已經失落，其餘的也就不足掛齒了。如今本鈔卷首的題目，就彰顯了這個宗旨。高高超越遠古諸師，深深契合佛陀本心；接續斷絕的法脈、扶持傾頹的律風，確實都在於這部著作。因此各篇的敷陳鋪排，唯獨以實踐行事為宗要；隨處提點警策，專心以訓導啟發晚學為宗旨；
