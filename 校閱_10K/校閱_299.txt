# 校閱材料　第299檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【299-0001】02_戒疏/01a_卷一上之一#27
【原文】【記】顯益中，上二句明攝生益，下二句明住持益。「乘」能運載，「津」是水濟。載出家眾，度生死津，故曰「乘津」。「燾」亦訓「覆」，今取「載」義，《禮》云「如天地，無不覆燾」是也。「萌」謂草木始芽，今取蒙昧，或復眾多，以喻萬類也。上句局出家，下句通道俗。或可「群萌」語通，義該六道。以眾聖弘揚，無往不利，豈唯七眾獨受其賜？「開務」即各布行教，「攝持」謂匡正佛法。「允符玄旨」，二義釋之：初約開教雖殊，皆契佛意，所被之眾，無不悟道；又解，出世弘持，並合懸記。「允」，順。「符」，合也。
【譯文】【記文】彰顯教化利益這部分，上面兩句說明攝受度化眾生的利益，下面兩句說明住持正法的功德。「乘」能夠運載，「津」是渡口水津。運載出家僧眾，度過生死的渡口，因此說「乘津」。「燾」字亦訓詁為「覆」，此處取其「乘載覆育」之義，《禮記》說「如同天地一般，無所不覆載包容」即是此意。「萌」原指草木最初破土的嫩芽，此處取其蒙昧無知、或是數量極為繁多的意思，以此比喻世間萬類眾生。上句局限於出家大眾，下句通貫於道俗眾人。或者可以說，「群萌」語意甚廣，義理涵蓋六道眾生。因為歷代聖賢弘揚流通此道，所到之處無不利澤廣施，難道只有出家在家七眾弟子獨得其利益嗎？「開務」即是各自宣布鋪展行持的教規，「攝持」是指整飭匡正佛教法脈。「允符玄旨」，可用兩種義理來解釋：第一，就各宗開演教門雖然互有殊異而言，其實全都契合佛陀本意，凡所蒙受教化的眾生，無一不因此悟道；另一種解釋，歷代祖師出世弘揚住持，完全符合佛陀當年的懸記預言。「允」是順隨，「符」是契合的意思。

【299-0002】02_戒疏/01a_卷一上之一#28
【原文】【疏】至如《四分》肇興，祖習緜遠；正法初百，便列其宗。斯人博考三機，殷鑒兩典；包括權實，統收名理；集結茲藏，通被時賓。故使韋編成規，欽承無絕。自諸部遠流，咸開衢術；獨斯一宗，未懷支派。良由師稟有蹤，知時不墜故也。
【譯文】【疏文】至於《四分律》的肇建興盛，祖述沿襲的歷史悠遠綿長；在佛法正法千年的最初百年間，便已赫然標立其宗派。其結集者博考深察上、中、下三種根機，殷重借鑑了大乘與小乘兩部寶典；融會包括方便權教與究竟實教，統攝收取了一切名義與理性；結集成就這部律藏，全面利澤當時的一切參學來客。因此使得歷代學者如同韋編三絕般翻檢研讀奉為規臬，欽仰承受始終未嘗斷絕。自從各部派遠傳流布以來，皆紛紛分支另闢道路門徑；唯獨這一宗派，未曾分化衍生旁支派系。這確實是由於傳承受學有明確的軌轍，深知時宜機緣因而永不墜失的緣故。

【299-0003】02_戒疏/01a_卷一上之一#29
【原文】【記】別歎中，初至「其宗」，敘其時遠。「肇」，始。「祖」，承。「綿」，長也。正法千年，一百年時分出，故云「初百」。佛滅千年，法流此土，至于唐朝，幾六百載，大約而論，則一千五百許年矣。
【譯文】【記文】個別讚歎（別歎）這部分，從開頭到「其宗」，敘述此律源遠流長。「肇」是創始，「祖」是承接，「綿」是延綿長久。正法一千年之中，於一百年之際分出此部，因此說「初百」。佛陀滅度千年之後，佛法流傳至東土漢地，到了唐朝，將近六百年之久，概略估算，距今約有一千五百年左右了。

【299-0004】02_戒疏/01a_卷一上之一#30
【原文】【記】「斯人」下，釋久傳之意，有二：初約人法以明；二、「自」下，約分部以顯。初中，「三機」者，上機即四依、頭陀等；中機謂百一供身、二房、二請等；下機如諸長、淨地、鉢器、皮革、諸重物等。自有通三機者，如三衣、鉢具、篇聚等制。良以教本對機而設，約機考教，得其源矣。「殷」謂殷重，「鑒」即訓視，「兩典」謂大小二乘。此二句，美其深達也。「權實」者，一往且約大小而分，此明《四分》通大之意。心為業主，識對諸塵，沓婆迴心，施生成佛。逈異有宗，深通實道。但教局小乘，未容直顯故也。「名」謂能詮名句，「理」謂所詮義趣。「統收」之言，該乎一化。「時賓」謂當時學眾。此四句，明所集教體。「韋」，熟皮也，古者用編簡牘。如孔子讀《易》，韋編三絕，今借彼意，以明古今披覽無厭。此二句，釋成久傳之意。
【譯文】【記文】「斯人」以下，解釋此律得以長久傳承的原因，共有兩層意涵：第一先就結集者與其教法來闡述；第二自「自」字以下，從部派分化的層面來顯明。在第一層中，所謂的「三機」，上根之機是指嚴持「四依」、修持「頭陀」等苦行者；中根之機是指獲准蓄持「百一供身物」、開造「有主無主二類僧房」、接受「僧請別請二種受請」等律儀；下根之機如同開許蓄積諸多長物、劃設淨地、蓄持各類鉢具皮革及各類貴重物品等。也有通於三種根機的通規，如同受持三衣、鉢具、五篇七聚等戒律制定。確實是因為教法原為對應根機而設立，依照根機深考教理，才掌握到了它的源頭。「殷」指殷實深重，「鑒」即訓詁為觀照審視，「兩典」指大乘與小乘二藏經典。這兩句話，讚美結集律師理解通達極其深遠。「權實」二字，暫且從大小乘的分野來劃分，此處用以說明《四分律》通貫大乘的深意。例如主張以心識作為造業的主導，六識對應種種塵境，沓婆尊者迴小向大、生起發心，以及將功德回施眾生普共成佛等內容。這與阿毗達磨有部等宗派迥然有別，極深地相通於大乘實教之理。只是教法形式上仍局限於小乘律部，未能直接顯露宣說罷了。「名」指能詮顯教理的名言章句，「理」指所詮顯的教化意趣。「統收」這句話，意思是總括涵蓋了佛陀一代教化。「時賓」是指當時依止參學的僧眾。這四句話，說明了所結集律藏的教體特色。「韋」是熟皮，古時用以編綴竹簡。如同孔子讀《周易》，多次翻閱致使穿簡的牛皮繩斷裂三次，此處借用那個典故，以表明古往今來的學人反覆翻閱研讀、永無厭足。這兩句話，解釋說明了歷經久遠仍得傳承的因由。

【299-0005】02_戒疏/01a_卷一上之一#31
【原文】【記】次分部中，下引三藏所傳。「薩婆多」出四，「迦葉遺」中分二，「彌沙塞」分一，「僧祇」中分六，故云「咸開」等。「衢」、「術」，皆路之別名。「獨斯」下，彼云「唯曇無德部始終不分」，此且約一途以歎，餘如後辨。「良由」下，正歎，由集律者達教適機，故不分耳。上句明傳受得旨，故曰「有蹤」；下一句明立法悠永，故云「無墜」，此亦顯上「緜遠」義也。
【譯文】【記文】接下來講部派分化部分，下文引述三藏法師所傳授之說。薩婆多部分化出四派，迦葉遺部分化出兩派，彌沙塞部分化出一派，僧祇部分化出六派，因此說「咸開」等語。「衢」與「術」，都是指道路的別名。「獨斯」以下，彼處經典記載「唯有曇無德部始終不曾分化」，此處暫且就這個角度來讚美，其餘論點如後文辨析。「良由」以下，正式讚歎，由於結集這部律典的祖師通達教理、契合時機，所以不再分流。前一句說明其傳承依止得其真意宗旨，所以說「有蹤」；後一句說明其立法的精神悠遠長久，所以說「無墜」，這也是為了進一步顯發上面所說的「緜遠」之義。

【299-0007】02_戒疏/01a_卷一上之一#33
【原文】【記】敘古本中。已上通明一宗，此下正敘《戒本》。列示中，初覺明本者，文雖不指，義見次科。「蘊結」，即目結集。教流此土二百餘歲，至於姚秦，覺明始傳，故曰「千餘」。梵云「佛陀耶舍」，此云「覺明」。自秦至唐，未滿四百，故云「將」也。「諸有」下，正指此本，而意生下文，故語通上下。
【譯文】【記文】敘述古本這部分。以上內容總體闡明了一宗的概況，此處以下正式敘述《戒本》本體。在列舉明示中，首先是覺明譯師的版本，文字雖然未曾指明，其義理在下一科判便會顯露。「蘊結」就是指結集之意。教法流傳到此方土地二百多年，直到姚秦時期，佛陀耶舍才初次翻譯傳授，因此說「千餘年」。梵語稱為「佛陀耶舍」，漢譯為「覺明」。從後秦至唐朝，時間未滿四百年，所以說「將近」。「諸有」以下，正式指稱這個譯本，而文意啟發了下文的開展，所以這句話語氣貫通上下兩端。
