# 校閱材料　第438檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【438-0001】02_戒疏/05b_卷二上之一#45
【原文】【記】第八，正示中三。初示制意。「惡」通業惑，「止」分近遠。今明教本，須對惑論。「業所興」者，推示業本。「三毒」之言，大小兩乘，並通惑業。業謂意地三業，即瞥爾、重緣以分相；惑謂性中三妄，即見、思、無明以為體。良以無始結情，熏積日深，觸境發情，徧造諸業。業雖無量，不出三毒，以為業本。然佛制戒，現止業非。究其遠圖，為清心惑。是則深窮制意，曲盡教源。四重既然，餘篇皆爾。「故」下，次引文證。《十住婆沙．除業品》文，「三三九種」：身、口、意為一三；自作、教他、見作隨喜，為二三；現報、生報、後報，為三三。「三煩惱」：欲、色、無色三界繫。然則界繫，即毒為體，由毒起業，由業感苦，故云從三「生」也。次引《成論．業道品》。彼問曰：「何故名為業道？」答：「意即是業，於此中行，故名業道。先行後三中，後行前七中。」此明意思先起三毒，後至七業，則顯七業發自三心。「故」下三，分戒配毒，以彰教意。
【譯文】【記文】第八門，正式開示的段落分為三部分。首先指出制戒的本意。「惡」通於造作的業與內在的惑，「止」則分為眼前的防護與長遠的斷除。現在要闡明教法的根本，必須針對煩惱惑障來論述。「惡業之所以會生起」，是推原並指出造業的根源。「三毒」這個名詞，在大小兩乘中都通含於惑與業。業指的是意地的三種業，也就是以微細生起與再三思量來劃分其相狀；惑指的是自性中的三種妄執，也就是以見惑、思惑、無明作為其本體。實在是因為無始劫以來的結縛情染，日積月累地熏習漸深，一接觸到外境便引發妄情，普遍造作出種種罪業。業雖然有不可勝數之多，但其造業的根本都不出於三毒。然而佛陀制定戒律，表面上是為了在當下制止惡業的過非，但窮究其長遠的圖謀，則是為了滌清內心的迷惑妄想。如果這樣去深入窮究制戒的本意，才能徹底通達教法的源頭。四條重戒既然是如此，其餘各篇戒律也全都是這樣。「所以」以下，接著引用經論來作證明。《十住婆沙論·除業品》中的文句，所謂「三三九種」：身、口、意是第一組三；自己作、教唆他人作、看見他人作而心生隨喜，是第二組三；現世受報、來生受報、後生受報，是第三組三。「三種煩惱」是指被欲界、色界、無色界三界所繫縛的煩惱。然而所謂的三界繫縛，就是以三毒為本質體性，因為三毒而造作惡業，因為惡業而感召苦報，所以說惡業是從三毒「生」出來的。接著引用《成實論·業道品》。該論問道：「為什麼稱為業道？」回答說：「心意本身就是業，在這種心意中造作運行，所以稱為業道。心念先運行於後面的意地三業之中，然後才運行落實於前面的身口七業之中。」這說明了心念動向是先發起三毒，其後才演變成身口的七種罪業，這就顯明了七種罪業完全是從貪瞋癡三種心所引發出來的。「因此」以下第三點，將四戒分別配屬三毒，以此顯彰教法興起的意圖。

【438-0004】02_戒疏/05b_卷二上之一#48
【原文】【疏】答：「貪心雖一，境殊內外；通須歷止，故因立二。瞋境亦二，罪則有差。癡慢誑境，局唯在情。故有殊也。」
【譯文】【疏文】答：「貪愛之心雖然只有一種，但所面對的對象卻有內在有情與外在非情物品的差別；這兩類對象都通統需要歷經境緣來加以制止，所以因應此理而確立了兩條戒。瞋恨心所對應的境界雖然也有這兩類，但引發的罪名輕重卻有很大落差。愚癡與驕慢所欺騙的對象，範圍僅僅侷限在有情眾生身上。所以制戒的單雙配對才會有所不同。」

【438-0005】02_戒疏/05b_卷二上之一#49
【原文】【記】答中。初示前雙對。「內外」，即情非情。然盜亦通人，且就多分為言耳。「瞋」下，明後隻對。初二句明瞋毒。「境亦二」者，內境易解，外即草土，掘壞犯提，罪不同篇，故無雙對。據論掘壞，未必由瞋，但俗計有命，譏責無慈，故望損傷，義同瞋殺故也。次二句明癡毒。非情無誑，唯隻可知。下一句結異。
【譯文】【記文】回答的段落中。首先說明前面雙重對應的情況。「內在與外在」，就是指有情眾生與無情財物。不過偷盜其實也涉及活人，這裡只是就多數情況而言罷了。「瞋恨心」以下，說明後面單一對應的情況。前兩句說明瞋毒。「境界也有兩類」，內在境界（殺人）容易理解；外在境界則是指掘鑿損壞草木泥土，這只犯波逸提罪，罪名不屬於同一個篇章，所以沒有雙雙列為重戒。若依理而論，掘壞土地未必是出於瞋恨，但因為世俗之人認為草木泥土中有生命，會譏嫌責備修行人毫無慈悲心，所以就造成損傷這一點而言，其義理等同於瞋恨殺害。後兩句說明癡毒。對無情之物無法進行欺騙，所以只能單獨對應有情，這是不言而喻的。最後一句總結其產生差異的緣由。
