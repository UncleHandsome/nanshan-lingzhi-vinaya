# 校閱材料　第409檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【409-0001】02_戒疏/04b_卷一下之二#68
【原文】【記】料簡中三。初殺畜盜畜，方便但吉；轉作人想，殺盜皆蘭。二殺人盜人，轉為非畜，後心並吉，故云「反上」。三互轉俱重，如淫前作非道想，後作正道想，或前正後非，無非果本。私釋：更立互轉俱輕，如非人畜生，心想互差，可以明之。
【譯文】【記文】分別探討（料簡）分為三點。第一，殺畜生、盜畜生，方便罪只是突吉羅；若轉念當作是人，殺、盜方便皆升為偷蘭遮。第二，殺人、盜人，轉念當作是非人或畜生，轉念之後的心念皆只是突吉羅，所以說「反上」。第三，互相轉變皆是重罪，例如行淫前作非道想，隨後作正道想，或者先正道後非道，無一不是根本大果。私下解釋：還可以另立一種「互相轉變皆是輕罪」，例如在非人與畜生之間，心念想差互相轉變，便可以此說明。

【409-0006】02_戒疏/04b_卷一下之二#73
【原文】【疏】上四句單疑也，今此雙舉，何者是邪？自他俱疑成方便，如身口互造也；即成究竟者，妄語言了也；自他俱不疑成方便，如出血在佛也；即成究竟者，一切戒是也。
【譯文】【疏文】以上四句是單方面的懷疑，如今將自他雙方同時並舉，又有哪些呢？自他雙方皆懷疑而構成方便罪，例如身業與口業互相造作之時；自他雙方皆懷疑而構成究竟罪，例如妄語之言詞已經了了分明之時；自他雙方皆不懷疑而構成方便罪，例如對佛加害而出佛身血；自他雙方皆不懷疑而構成究竟罪，一切戒律正常違犯皆是如此。

【409-0011】02_戒疏/04b_卷一下之二#78
【原文】【疏】第七，善心息方便者。如欲造罪，身口雖發，未鄰究竟，忽起善心，便止前業，壅礙不暢，但居方便。

【409-0012】02_戒疏/04b_卷一下之二#79

【譯文】【記文】第七，在善心止息的初段中。「鄰」就是接近的意思。說「忽然生起」，可能是因為旁人勸勉，或是遇到殊勝因緣，或是思維佛陀戒教，或是怖畏因果報應。若不是這一類因緣，善心怎會發起？「居方便」，是指先前的起意行動結為偷蘭遮罪。

【原文】【疏】問：「此乃善心生，今何言『息』？」

【409-0014】02_戒疏/04b_卷一下之二#81
【原文】【疏】答：「實如來問。向若不生，惡必趣果，由此善心，能息惡想，即所息處，號為『方便』。又如《律》文『捨者，偷蘭』，捨時非罪，由能捨故，前惡不至後果，故號前因為『方便』也。」
【譯文】【疏文】答：「確實正如你所問。剛才若不是善心生起，惡行必然奔向究竟結果；由於這念善心，能夠止息惡想，就在那止息之處，稱之為『方便』。又正如《律》文中所說『放棄的人，犯偷蘭遮』，放棄的當下並不是罪，由於能夠放棄，先前的惡業才沒有演變成最後的結果，所以將先前的因稱作『方便』。」

【409-0015】02_戒疏/04b_卷一下之二#82
【原文】【記】釋難中。此即善生惡息，於義易知，欲生下答，故此為問。答文為二，初正答，「又」下引例。能捨則同善生，所捨可類惡息。
【譯文】【記文】化解詰難部分。這屬於善心生起而惡念止息，在義理上很容易理解，是為了引出下文的回答，所以在此發問。答文分為兩部分，首先正式回答，「又」字以下引用例證。能捨棄就如同善心生起，所捨棄的惡事即可比喻為惡業止息。

【409-0021】02_戒疏/04b_卷一下之二#88
【原文】【疏】剋心辨差，其境則寬。以元在張，王、非、畜、杌後來差故。漫心辨差，其境則狹。以通三趣，有境齊害，唯有杌境，用分輕相。乃至想、疑，剋漫可解。
【譯文】【疏文】以專注特定對象的心（剋心）來辨明差錯，其可能面臨的境界就比較寬廣。因為原本的心思在張三身上，李四、非人、畜生、枯木後來前來差錯替換的緣故。若以泛泛普徧的心（漫心）來辨明差錯，其境界就比較狹隘。因為泛指三種趣類，只要是有情境界一律都要加害，唯有面對枯木境界，才能分出罪相較輕的情形。乃至於想差與疑心，其剋心與漫心的道理也可以依此理解。
