# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【279-0001】02_戒疏/14c_卷三下之二#131
【原文】【疏】昔人不立，以「財無兩捨，罪不雙結」。誦得此語，不敢漏失。今不同之，見今以錢買金而畜，初貿後畜，緣相是異，何不雙結？
【譯文】【疏文】過去的律師不贊成建立第三句的雙重結罪，理由是「同一筆財物不應重複兩次沒收行捨法，一種罪行也不應雙重結罪」。他們死記背誦了這句話，便不敢有絲毫逾越遺漏。現在我不同意這種看法，眼見現在有人拿錢買了黃金而後蓄存起來，先是買賣交易、後是長久蓄存，觸犯這兩條戒的事實緣起截然不同，為什麼不能雙重結罪？

【279-0002】02_戒疏/14c_卷三下之二#132
【原文】【記】斥古中。初敘古意。彼謂第三句但犯貿寶，不犯前畜。「誦」下，正斥。「財無兩捨」等語，乃謂犯過衣財，無再犯長。彼但承言妄舉，而不知用處自別，故云「誦得語」等。「今」下，顯正。理如上判，但將一捨牒悔兩罪。「緣相異」者，謂二戒犯緣前後各異，故須別犯。
【譯文】【記文】斥責古代律師的段落。起初陳述古代律師的想法。他們認為第三句只能判犯買賣金寶戒，不應再判前面那一條蓄寶戒。「死記」以下，正面予以斥責。「財無兩捨」等話語，原本是指觸犯過一次捨墮的衣物資財，日後不再重複結犯蓄長罪。古人只是盲目附和套用別處的話頭，卻不知道這句話各自應用的時機本有差別，所以說他們「死記背誦這句話」。「現在」以下，顯明正確的主張。義理應當如上面所判定的那樣，只不過是將同一份被沒收的財物，在羯磨中同時提引來懺除這兩種罪名罷了。「犯緣相狀不同」，是指這兩條戒違犯的事實因緣在時間前後各不相同，所以必須分別結罪。

【279-0003】02_戒疏/14c_卷三下之二#133

【譯文】【疏文】「如果按照你的說法，那販賣經商所獲取的衣料資財，豈不是也應該一併作說淨法？」

【279-0004】02_戒疏/14c_卷三下之二#134
【原文】【疏】答：「全不同也。淨法簡境，罪不約境故也。」
【譯文】【疏文】回答：「這完全不可相提並論。說淨的法則只是針對合法物品所作的資具除罪手續，而結罪則是針對違犯行為本身，兩者不能混為一談。」

【279-0005】02_戒疏/14c_卷三下之二#135
【原文】【記】釋難中。既立雙結，則犯過之財容有犯長，義須說淨。如上義門，古義還立。答文，顯別以破來難。
【譯文】【記文】在解答質難之中。質難者認為既然主張可以雙重結罪，那麼違犯過失所賺來的財物就有可能再次結犯蓄長罪，照理就必須做說淨。如果是按照前面這種義理邏輯，古人的舊論點反倒能成立。回答的文句，彰顯兩者的本質區別以破除對方的質難。

【279-0006】02_戒疏/14c_卷三下之二#136
【原文】【疏】《論》云：「此戒一往即犯，不同販賣。捨與白衣，不得與沙彌，以彼畜寶亦須捨故。」
【譯文】【疏文】《多論》說：「這條戒只要一有買賣交易的行為當下就犯重罪，不同於一般的販賣戒。沒收捨出的金寶必須交給在家人，絕對不得交給沙彌，因為沙彌自己蓄存金寶也是必須交出捨離的。」

【279-0007】02_戒疏/14c_卷三下之二#137
【原文】【記】三、引證中。「論」即《多論》，對後貿衣，略示二別。初約犯相別。此戒即犯；後販賣戒收時但輕，出賣方犯故。次明捨財別。貿衣不通俗；貿寶不通道，所以下眾亦不與也。
【譯文】【記文】第三、引用論典證明之中。「論」就是指《薩婆多論》，拿本戒與後面的販賣衣物戒相比，簡要指出了兩點差異。首先依違犯相狀的快慢作分別。本條戒一經交易立刻結犯重罪；後面的販賣戒，在進貨收取時只結輕罪，唯有真正轉手售出時才結犯捨墮重罪。其次說明捨出財物歸宿的分別。買賣衣物戒沒收的衣服絕不給予在家人；買賣金寶戒沒收的珍寶絕不留給僧道中人，所以即便地位較低的沙彌也絕不能交給他。

【279-0022】02_戒疏/14c_卷三下之二#152
【原文】【疏】如昔云「未成金」者，謂雜石礦也。安有塊石，而明金相？如《僧祇》、《善見》釋相，彼轉「成」文以為「作」也。言「成」者，已成器也，華釵莊嚴具是也。「未成」者，即金鋌也。「已成未成」者，鎔潟作器而未鋌治者。「銀」例此三。「錢唯一種」，據理亦三，但未成就，文像不具，世所不行，則非貴物，故唯一也。
【譯文】【疏文】比如過去有人說「未成金」是指夾雜在石頭裡的原始金礦。但怎麼能拿一塊頑石，來作為戒律中所界定的黃金相狀呢？如果參照《僧祇律》與《善見論》對此相狀的解釋，那些論典把「成」這個字改換成了「作」字。所謂「已成」或「已作」，是指已經打造成實用器具的黃金，例如金花、金釵等各種莊嚴飾品便是。「未成」或「未作」，是指未經精雕細琢的生金條、金錠。「已成未成」，是指已經熔化澆鑄出了器具形貌、卻尚未經搥打磨光的半成品。「白銀」的分類也比照這三種。「錢幣唯有一種形式」，按照常理錢幣本來也該有這三種進程，但若未經鑄造完成，錢幣的文字圖像全不具備，在世間根本無法流通，就失去作為貴重貨幣的本質，故判定錢幣只有「已鑄成」這一種形式。

【原文】【記】別釋中二。初釋三相，又三。初釋金中，先斥古非。彼迷「成」字，謂是金礦未經烹鍊者。故引《僧祇》、《善見》質之。彼名「已作金、未作金」，不同今文，故云「轉成為作」也。既言「未作」，顯是未成器者，非石礦也。「言」下，次示正解。「鋌冶」，「鋌」謂搥打，「冶」即揩磨。第二，釋銀。三種同上。第三，釋錢。唯是已成，故但有一，如文可知。
【譯文】【記文】個別解釋之中分為兩段。起初解釋三種型態，又分為三小節。首先在解釋黃金的部分，先斥責古代律師的錯誤見解。他們誤解了「成」字的涵義，以為是指未經冶煉的金礦石。所以引用《僧祇律》和《善見論》來勘驗對質。那些書中稱為「已作金、未作金」，用字與本經不同，所以說「轉成為作」。既然論典說是「未作」，就顯然是指未打造成器具的黃金金塊，而不是指含金的礦石。「言」字以下，接著提出正確的解釋。「鋌冶」這兩個字，「鋌」是指敲打整型，「冶」是指磨光修飾。第二小節解釋白銀，三種型態與黃金相同。第三小節解釋錢幣，錢幣唯有已鑄造成型者才算數，所以只有一種型態，文義正如上述這般清楚明了。

【279-0030】02_戒疏/15a_卷三下之三#2
【原文】【疏】第二十，販賣戒。
【譯文】【疏文】第二十條，是關於販賣的戒律。

【279-0031】02_戒疏/15a_卷三下之三#3
【原文】【疏】據此戒中，須分三位，即販、賣、買也。為利故收，為利故出，諍價而高，為「販」也。為利而取，故減前價，名「買」。為利故出，強增其價，曰「賣」也。《戒本》中但明增減市易，《論》及餘律廣出販賣之相，如《鈔》廣分也。
【譯文】【疏文】依照這條戒律的內容，必須劃分為三種身分行為，也就是「販」、「賣」和「買」。為了圖利而收購，又為了圖利而售出，在論價爭執中抬高價格，這叫做「販」。為了圖利而獲取物品，因而壓低原有的價格，這叫做「買」。為了圖利而售出物品，強行抬高其價格，這叫做「賣」。《戒本》中只說明了透過增減價格來進行市場交易，而各部論典以及其他律典則廣泛列出了販賣的具體行相，這在《事鈔》中有詳細的分析。

【279-0032】02_戒疏/15a_卷三下之三#4
【原文】【記】二十，分位初中。初總示。「為」下，列釋。「販」、「賣」並是出物，但約先收、不收以分兩異。「戒」下，指廣。「但明增減」等者，如注止列賣、買之相，不言收販。「論律出」者，即《多論》云「此販賣墮，一切墮中最重，寧作屠兒止害一生，販賣一切俱害」等，又《僧祇》云「儲藥草時作念『此後當貴』，乃至後賣，犯捨」。《鈔》文甚廣，不可具錄。
【譯文】【記文】在第二十條戒中，解釋第一段劃分身分行為的文句。一開始是總體提示。「為了圖利」以下，是逐一列出並解釋。「販」與「賣」都是將物品售出，只是以事先有無收購來區分兩者的差異。「戒本中」以下，是指出詳盡的內容。「只說明增減價格」等語，是指注文中只列出了賣與買的具體樣貌，沒有提到事先收購的「販」。「論典與律典所列出」的內容，就是《薩婆多論》所說的「這種販賣所犯的墮罪，在一切墮罪中最為嚴重，寧可去做屠夫，也只是殘害一期生命，若是販賣，則對一切眾生都有所損害」等；又如《僧祇律》所說「儲存藥草時心想『這東西以後會變貴』，乃至日後售出，便構成捨墮罪」。《事鈔》中的文句極為廣博，無法在此全部收錄。
