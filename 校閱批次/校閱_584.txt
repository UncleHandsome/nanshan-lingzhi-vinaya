# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第一念知日月大小法者若是白月應云今朝白月大一日乃至十五日以白月一向大故不須云小若是黑月便通大小黑月大者應云今朝黑月大一日乃至十五日黑月小者今朝黑月小一日乃至十四日此謂識去布薩日遠近又防俗問故解云若入聚落先知日月數等。
【譯文】第一條「念知白月黑月與日數大小之法」：如果是白月（前半月），應當念想自語說：「今天是白月大，初一日……乃至十五日。」因為白月一概都是十五天（大盡），所以不必說小盡。如果是黑月（後半月），就通於大盡（十五天）和小盡（十四天）；若是黑月大盡，應當說：「今天是黑月大，初一日……乃至十五日。」若是黑月小盡，應當說：「今天是黑月小，初一日……乃至十四日。」這是為了清楚知曉距離布薩誦戒之日還有多遠，也是為了防備世俗之人詢問；所以解釋說：如果要進入村落聚落，必須先清楚知道當天的月分日數等。

【584-0011】04_比丘尼鈔/02a_卷上之下#63
【原文】第二念知食處法者全不受請者應云我今不受請自食己食或云食僧常食不受請或云乞食不受請若受請無供養者應云我今自食無請處或云我今食僧常食無請處或云乞食無請處若受請不背者應云今有請處念當自往若受請有背緣者應云今有某緣得背請若受多請者應對人捨云今日有多請處自受一請餘者施與大姉在某處若無人對依十誦依親里住尼心念捨云我某甲今朝檀越施我五正食迴施比丘尼某甲檀越於我不計我得自恣食。
【譯文】第二條「念知受食之處法」：完全不受信眾請齋的人，應當念想說：「我今天不接受迎請，自食自己的食物。」或者說：「我食用僧團的常態供應食物，不接受迎請。」或者說：「我以乞食自活，不接受迎請。」如果接受了迎請卻無人供齋，應當念想說：「我今天自己用食，沒有受請之處。」或者說：「我今天吃僧常食，沒有受請之處。」或者說：「我今天乞食，沒有受請之處。」如果接受了迎請而按時赴約不違背的，應當念想說：「今天有受請的去處，念及應當親自前往。」如果接受了迎請卻因故違背赴約的，應當念想說：「今天因為某種特殊因緣，得以違背赴請。」如果接受了多家邀請，應當對著同修作捨請法說：「今天有多處迎請，我自己接受其中一處迎請，其餘的轉施給大姊在某某處受用。」如果沒有同修可以面對作法，依照《十誦律》，依止親族居處居住的尼僧，可以在心中默念作捨食法說：「我某甲，今天早上檀越布施我五種正食，我轉迴施給比丘尼某甲；檀越於我已不再牽掛計較，我可以隨意自恣食用。」

【584-0012】04_比丘尼鈔/02a_卷上之下#64
【原文】第三念知夏大小法者若初受戒者應云我於某年歲次在某日月在一尺木若干影時受具足戒我今無夏後若有夏隨夏多少稱之。
【譯文】第三條「念知戒臘大小法」：如果是初受戒的比丘尼，應當念想說：「我於某某年、歲次某某、在某月某日、在日影一尺木有若干長度的時辰受具足戒，我現在還沒有戒臘。」日後如果有戒臘，隨其戒臘的多少據實稱念。

【584-0013】04_比丘尼鈔/02a_卷上之下#65
【原文】第四念知衣盋法者若衣盋具受者應云我五衣盋具足受持若長衣盋藥等求說者應云念當說淨犯長者應云今有長財念當說淨。
【譯文】第四條「念知衣缽法」：如果三衣一缽都已合法受持具足，應當念想說：「我五衣及缽具足受持。」如果有多餘的長衣、長缽、醫藥等需要求人作「說淨」（借名共管以去私蓄之貪），應當念想說：「憶念應當依法說淨。」如果犯了非法蓄積長物的罪，應當念想說：「如今身邊存有長財，憶念應當儘速依法說淨。」

【584-0014】04_比丘尼鈔/02a_卷上之下#66
【原文】第五念知別眾食法者若有別眾者云今有某緣得別眾食或病迦提月等若無緣者應云念不別眾食。
【譯文】第五條「念知別眾食法」：如果有單獨別立僧眾受食的因緣，應當念想說：「今天有某種特殊因緣（如生病、迦提月等），得以別眾受食。」如果沒有特殊開緣，應當念想說：「憶念不可違犯別眾受食。」

【584-0018】04_比丘尼鈔/02a_卷上之下#70
【原文】第一制聽者所以名制者謂五衣六物佛制令畜違便得罪所以言聽者謂一切長衣及百一供身具等隨報開聽違順無過。
【譯文】第一項「制立與聽許」，為什麼稱作「制」？是指五衣、六物等，是佛陀硬性制定必須蓄受備辦的，違犯了便得罪過。為什麼稱作「聽」？是指一切多餘的長衣以及百零一種隨身資生供具等，是隨順個人身受需要而開許聽任蓄用的，違背或順行都不算結罪犯戒。
