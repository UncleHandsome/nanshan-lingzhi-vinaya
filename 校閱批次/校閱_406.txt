# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【疏】起予鞭吾，恰急於魏帝之貴幼弟也。如予斗筲之器，雖不以足貴，而揚桴擊皷，雖欲不鳴，其豈可得遂乃謾諾矣。退而倩想，自小學薙染志學入律以來，長被佛祖曠恩，夙浴三學法水，實知罔極矣，焉敢不謝之乎，是亦非宿因所令然耶。況復戒則定慧之本原，十方如來一門超出妙莊嚴路，戒足不全，若為發趣？欲全戒足，則豈捨之。
【譯文】【疏文】他對我的啟發策勵與鞭策，比當年魏文帝嚴厲逼責其幼弟（七步成詩）還要急迫。像我這般斗筲般薄陋的才具器識，雖然本不足以自貴，然而懸桴擊鼓之勢已成，想要讓它不出聲鳴響，又怎麼可能呢？於是只能勉強答應下來。退席之後反覆深思冥想，自幼落髮出家、立志向學趣入律藏以來，長久蒙受佛陀與祖師的浩瀚洪恩，夙昔沐浴在戒定慧三學的法水之中，深知此恩廣大罔極，又怎敢不以身圖報呢，這難道不也是宿世深因所致使的嗎？更何況戒律乃是定力與智慧的根本根源，是十方如來唯一徑直超脫妙莊嚴路的通途，若戒足殘缺不全，又如何能啟程趣向聖道？若是想要圓滿戒行法足，又豈能棄捨此書而不顧。

【406-0013】02_戒疏/21c_卷四下之三#106
【原文】【疏】大哉戒德，方行資始。《百論》盲跛之譬，《牟子》之說行之解如之何乎？苟守一隅而固辭，則早晚使挑，慧矩蒼生，照正行之路。因而利其器，從事於斯矣。而戒本注疏文段鉤鏁，不唯一重。殆病符合，而賴繹文逐節排布。《疏》、《記》循科分會綸次，今將法彼曲成從，天地易簡，五部俱會，一覽使普矣。茲稔功成，更以異本校讐，猶恐爽靈鑒多矣。恭候后喆之琢磨，非敢功於比先輩，纔酬佛恩，少答祖德矣。冀稱性微勳，彌編法界，佛日增輝，法壽無窮矣，云爾。
【譯文】【疏文】巍峨廣大啊戒律的功德，正是修持品行資糧的最初始端。《百論》中盲人與跛子相助的譬喻，《牟子理惑論》中關於行道與明理不可偏廢的精闢議論，難道可以等閒視之嗎？如果固守一隅而堅決推辭，那麼究竟何時才能挑亮智慧的明炬，照亮芸芸蒼生修持正行的道路？因此必須先磨利其器物工具，我也就欣然從事於這項編纂事業了。然而這部《戒本注疏》的文字段落如鎖鏈般相勾，往往不止一層重疊。最讓人苦惱的是五部文段要像符節般逐一相合對齊，全憑抽繹文本、依照段落逐一排比鋪展。使《疏》與《記》依循科判分條縷析、絲絲入扣地編纂成序，如今將取法宇宙天地曲成萬物的至理，順從天地化繁為簡的要妙，將經本、注文、科判、注疏、記文五部徹底合編，使人一展卷便能全盤洞悉。如今整年辛勤大功告成，進一步採用不同的版本互為校勘比對，內心依然深恐錯漏疏失之處甚多。恭謹等候後世賢哲仁人的琢磨修正，我絕不敢妄將此功績與古代前輩相提並論，只求藉此稍稍酬謝佛陀的大恩、些許報答祖師的厚德罷了。唯願這依順真如自性所生起的微末微勳，周遍充盈於十方法界，令佛法慧日增長光輝，令法脈壽命歷久無窮，如此而已。
