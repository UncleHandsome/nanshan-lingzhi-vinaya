# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【172-0001】03_業疏/18b_卷四之一#39
【原文】有人不加言教，但奉持無離，即是受也。若爾，何以文中云有疑捨受？明知有法，故須捨之。不受持者自犯罪耳，由失法故，無宜不受
【譯文】有人主張不需要言詞教法作法，只要恭敬執持而不離身，這就是受持。如果真是這樣，為什麼律文中說「如果有疑慮，應捨去後重新受持」？顯然知道一定有作法之法，所以才需要先捨後受。若有衣而不依法加持受持，自身便犯突吉羅罪；既然會因離身而失法，就絕不應當不受持。

【172-0002】03_業疏/18b_卷四之一#40
【原文】釋中初文，初出古所執。「若下」，據文難破
【譯文】在解釋的初文中，首先提出古代法師的執見。自「若爾」以下，依據律文進行詰難破斥。

【172-0003】03_業疏/18b_卷四之一#41
【原文】有人用僧祇受者，此迷教也。彼律開夜會，此部制明相，有緩急也，何得妄行？今用十誦，持犯相類也
【譯文】有人採用《摩訶僧祇律》的受持法，這是迷失了教旨。《摩訶僧祇律》開許夜間去與衣服相會，而本部《四分律》則制定以明相（黎明出光）為界限，有寬緩與嚴格的差別，怎能妄加套用？現在採用《十誦律》的受持法，因為它的持戒與犯戒規定與本部最相類同。

【172-0004】03_業疏/18b_卷四之一#42
【原文】次科初指昔迷，後示今用。《僧祇》夜分暫到衣所，即不失法；《四分》、《十誦》並護明相
【譯文】在次一科中，首先指出前人的迷誤，隨後指示今日所應當採用的方法。《摩訶僧祇律》規定在夜分中暫時走到放衣之處，就不算失法；而《四分律》與《十誦律》都同樣以守護明相為準。

【172-0005】03_業疏/18b_卷四之一#43
【原文】文中若疑者，謂曾受持後忘，謂未欲重加受，疑情不遣，故須先捨後受明白也。或可先受後難，事訖疑生，失不未了，故須捨受
【譯文】文中所謂「若疑」，是指曾經受持而後來忘記，以為尚未受持而想要重新加持受法，心中的疑惑難以釋懷，所以必須先捨去舊法然後重新受持以求明確。或者可能是先已受持，隨後遭遇災難逼迫等因緣，事端結束後心生懷疑，未能了知是否已經失法，所以必須先捨後受。

【172-0006】03_業疏/18b_卷四之一#44
【原文】次釋有疑初科有二：初約迷忘明疑；「或下」，次約難緣明疑，謂奪失、道斷、染隔等緣
【譯文】在其次解釋「有疑」的第一科中分為兩點：首先就迷惘遺忘來說明懷疑；自「或可」以下，接著就難緣來說明懷疑，也就是被掠奪、失落、道路斷絕、染礙阻隔等因緣。

【172-0007】03_業疏/18b_卷四之一#45
【原文】問：疑是無知，何不結罪？答：此中疑從事生，非本不學也。以心境迷忘，至佛方除。如夜暫出，作心防護，不謂失衣，忽然地了，人衣兩別，此失無疑。疑謂未明，雲霧闇塞，非問自知，忽然日出。此之迷事，非學得知，故須捨之，無罪可負
【譯文】問：懷疑屬於無知，為什麼不結罪？答：此處的懷疑是因具體事相而生起的，並非原本不肯學習。因為心境迷惘遺忘，到了成佛才能徹底斷除。如同夜間暫時出外，心裡本有防護之意，不認為會失落衣物，忽然大地大明，人與衣服分處兩地，這叫作失衣無疑。所謂「疑」，是指天色尚未明朗，雲霧遮蔽昏暗，不能自己知道，忽然太陽升起。這種事相上的迷惘，並不是靠學習律法就能得知的，所以必須捨衣後重受，並不會違犯罪名。

【172-0008】03_業疏/18b_卷四之一#46
【原文】問答中，初示疑心。若生來不學，臨境瞢然，此可結犯；今是事迷，縱前不學，非學之功，故無有罪。忘是無明，至佛方盡。如下出迷相。「非問自知」，「自」合作「能」，「負」，違也
【譯文】在問答之中，首先闡明疑心。如果生來不學戒法，面臨境緣時茫然無知，這應當結犯無知之罪；如今是事相上的迷昧，縱使以前沒有學過，這也不是靠學習律法就能明白的事，所以不結罪。遺忘是無明惑，到了成佛才斷盡。如隨後指出迷昧之相。「非問自知」中的「自」字應當作「能」字。「負」，是違犯的意思。

【172-0009】03_業疏/18b_卷四之一#47

【172-0011】03_業疏/18b_卷四之一#49
【原文】問如今大衣竝非復作又是正色成受用不答必有外緣聽用無罪無緣有財故單者犯如善見中若見著五大色衣者有智慧人知是失衣比丘唯暫得著後求如法不可妄行非複暫受如上已說可通覽也。

【172-0014】03_業疏/18b_卷四之一#52
【原文】前正衣中，初明作法正儀。「下衣有四種」下，解其所以，謂割等四，如文列也。襵葉一種，局在下衣，餘通上二。先明正三品者，謂割、褋、襵作五條也。從有二十一，謂取十八品大衣、二品中衣、一通縵者，同加安陀會也
【譯文】在前面正衣之中，首先說明作法的正式儀式。自「下衣有四種」以下，解釋其中的緣由，即割截等四種作法，如律文中所列。襵葉這一種，局限於下衣，其餘三種則通於上二衣。先說明正衣三品，是指以割截、褋葉、襵葉縫製的五條衣。從衣有二十一品，是指取十八品大衣、二品中衣、一品通用的縵衣，一同加持作為安陀會。

【172-0016】03_業疏/18b_卷四之一#54

【譯文】在加持從衣的第一科中，首先點明正文。自「何以通之」以下，解釋開許之意。依準借用他人之衣來比況自身已有之衣，在理法上必定應當開許准聽。

【172-0018】03_業疏/18b_卷四之一#56
【原文】有懼行事縫諸條葉，唯留五條，一長一短，即衣加受。今不同之。縵衣類極下也，猶尚通下及上，况正三衣不得加作？但依相題加三法故

【172-0028】03_業疏/18b_卷四之一#66
【原文】後明捨法中，《四分》有疑如上開也，非謂開捨而得離宿。故《僧祇》云：夜往會衣不能得遂，佛令遙捨，以輕易重，寧無衣故犯吉羅也。若捨無罪，須用白二，以輕換重，隨義亦然，餘則不開也。又如《五分》換易故捨，《善見》、《多論》壞相失捨，如是不定，同皆捨故。或對衣作，或緣隔作，並同成也
【譯文】在隨後說明捨法中，《四分律》有疑惑如上文所開許，但並不是說開許捨衣就可以離衣過宿。所以《摩訶僧祇律》說：夜間前往衣處相會而未能及時趕到，佛陀令其在遠處遙捨其衣，用輕罪替換重罪，寧可因身邊無衣而犯突吉羅罪。如果捨衣而要完全無罪，必須使用白二羯磨；若以輕罪換重罪，依義理來說也是如此，其餘情況則不開許。又如《五分律》中為了換易衣服而捨衣，《善見論》、《薩婆多論》中因衣服損壞失去法相而失法捨衣，像這類不定的因緣，同樣都屬於捨衣。或者面對衣服作法，或者因緣隔絕在遠處作法，都同樣成就。
