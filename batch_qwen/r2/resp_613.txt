整體看下來，譯文流暢、科判層次掌握得不錯，但有幾處**實詞誤解**（會誤導義理）與**增譯／術語不一致**的問題，建議修訂。以下按輕重分列。

---

## 一、語意誤解（建議必改）

**1.「容」誤作「容許」──#36、#37（最關鍵）**
- 原文：「此未來中事，**容有無實犯**故」／「**容無實犯**，顯示不定故」
- 現譯：「**容許**有並未實際犯戒的情況」／「**容許**沒有實犯」
- 問題：此處「容」是「或許、可能」，非「容許、允許」。原文是說「（雖已同坐）可能並未真正犯到三罪」，所以立為不定；譯成「容許」會變成佛陀允許不犯，語意大偏，且下文 #38「既無實犯，何須制者」的問難也接不上。
- 建議：「這是未來之事，**可能並沒有實際犯戒**的緣故」／「『**或許沒有實犯**』，是顯示其不定」。

**2.「染分」誤作「情分」──#39**
- 原文：「三戒**染分**，外涉必多」
- 現譯：「涉及男女貪染的**情分**」
- 問題：「分」是類分（染分／淨分相對），指這三戒屬於染污（淫欲）這一類，不是「情分」。
- 建議：「這三戒**屬於染污（淫欲）之類**，對外與俗人交涉的機會必然很多。」（「三戒」宜加註：即三罪所對應的淫戒、麤語戒、與女同坐戒。）

**3.「能治行」譯成「能治罰的善行戒體」──#27**
- 問題：(a)「治」是**對治**，非「治罰」；(b) 原文只作「能治行」，譯文擅加「戒體」二字。此段古師正是「能治行／所防罪」對舉，加上「戒體」會混淆誰是能治、誰是所防體。
- 建議：「佛制令比丘『如法自言』，這就是『**能對治之行**』。」

**4.「何假此中方言最初」──#34**
- 現譯：「何須**假借**在此處才說」
- 問題：「假」＝須、藉，「何假」即「何必」，不必再譯出「假借」。
- 建議：「**何必**在此處才說『最初（犯）』呢？」

**5.「同處麤語」的斷句──#30（建議覆核）**
- 原文：「獨一女人**同處麤語**」
- 現譯：「獨自與一名婦女**在同一處所說**麤惡淫穢的言語」
- 問題：把「同處」與「麤語」併成一事。此處應是並舉兩不定戒的情境：**屏露同處（坐）**與**說麤惡語**，故下文才有「於三罪中令他疑怪」。
- 建議：「獨與一女人**同處（而坐）、說麤惡語**」。

**6.「所疑事／能疑人」的能所對舉譯失──#35**
- 現譯：「『三種罪』是**引人懷疑**之事，可信賴的女人就是生起疑心的人」
- 問題：「所疑事」是被懷疑的對象（所），與「能疑人」（能）成對；譯成「引人懷疑」把所疑變成能生疑之因，能所關係散了。
- 建議：「『三罪』是**所疑之事**，俗女是**能疑之人**。」

**7.「疑定」過度渲染──#36**
- 現譯：「生起懷疑這一點是**千真萬確、固定不移**的」
- 問題：原文「疑定」是與「所疑不定」對照的判語，重點在「**生疑是決定的，故以疑為體**」，不宜加語氣渲染。
- 建議：「由此可知，**『生疑』是確定的**（故以疑為戒體）。」

**8.「戒家所防體」譯作「實體」──#37**
- 「體」是戒體之體，非哲學義的「實體」。建議作「這就是**此戒所防之體**」。

## 二、增譯／語意偏移（原文無而譯文有）

| 段 | 現譯 | 問題與建議 |
|---|---|---|
| #38 | 「既然沒有真正犯下**重罪**」 | 原文只作「無實犯」，三罪中含波逸提（輕罪），加「重」縮小了範圍 → 「既然沒有實際犯戒」 |
| #33 | 「本篇所犯的戒境**多是**在俗人的房舍」 | 原文「犯在俗舍」是断定，無「多是」的保留語氣 → 刪 |
| #29 | 「**古人**先詰難第一位律師」 | 原文「先難初師云」未標主語（依《義鈔》行文，可能是作者或次師），不宜擅定 → 「先詰難初師說」 |
| #22、#35 | 「**可信賴的**女人」 | 「俗女」只是在家女子；「住信優婆夷」是戒文語，若要保留宜作「俗女（即住信優婆夷）」並加註，勿直接把註解混入本文 |
| #32 | 「**極易**招致彼此的污損」 | 原文「汙辱彼此」直述，無「極易」 |
| #40 | 「制戒的**深意**」「制戒的**最終**目的」 | 「制意」即制戒之意，「深」「最終」可省 |
| #25 | 「**眾多**律師的不同主張」 | 「多師」＝數位律師，「眾多」稍誇 |
| #34 | 「這種**引起懷疑的**心思」 | 「此之疑心」即俗女的疑心本身 → 「這種（俗女的）疑心」 |
| #34 | 「將它立為**本戒的戒條**」 | 「以為戒本」此處指以「疑」為**此戒之體**，非「戒條」 → 「即以『疑』為此戒之本（體）」 |
| #30 | 「引發他人的懷疑**怪罪**」 | 「疑怪」是疑惑訝異，非怪罪責備 → 「懷疑訝異」 |

## 三、術語與前後一致性（影響讀者對照原疏）

**1.《義鈔》書名疑誤（#22、#29、#31）**
譯文一律作「《戒疏義鈔》」。《行宗記》中所引《義鈔》，一般指道宣 **《四分律拾毗尼義鈔》**；註解《戒疏》的即是《行宗記》本身，並無「戒疏義鈔」一書。建議查核後統一為《拾毗尼義鈔》（或逕存「《義鈔》」不加全名）。

**2.「不定體」宜作「不定戒之體」（#29、#30）**
現譯「不定的戒體」易被讀成「不確定的戒體」，而原意是「不定（戒）的體」。

**3.「非法自言」系列譯法請統一（#26、#27、#29）**
現有「違法的自我陳白／違法的陳白／非法的陳白／如法地坦白陳說／如法地自我坦白發露」等多種。且「違法」帶世俗法律語感，律家語宜作「**不如法**」。建議固定為「如法自言（如法自說所犯）／不如法自言」。

**4. 記文所引疏文關鍵字，須與疏文譯語對得上**
《記》的科判是直接標舉《疏》的字（「但」下、「今云」下、「若」下、「故」下、「令」下），譯文若不一致，讀者無法對應：
- 「今云」：#30「現在應當解釋為」／#31「如今應當說明」 → 請統一
- 「故」：#39「因此」／#40「所以」 → 統一
- 「令」：#39「好讓」／#40「使令」 → 統一
- 「不信心」：#36「不信任的心思」／#37「不**信敬**心」（且多一「敬」字） → 統一作「不信心（不信、懷疑）」

**5. 科判量詞**：#31「第一科」、#32「下一科」，但 #35、#37、#40 作「第三點／第四點／第五點」。建議一律用「科」。

## 四、語句潤飾

- **#31**「第一位律師的觀點已經**如第二位律師所破除的那樣**」→ 語意含混。原意：初師之說已被次師所破（如上引），故今略而不引。建議：「初師之說**已被次師所破**，此處略而不引，只破次師。」
- **#35**「再次**重點點破**古德見解的謬誤」→「重點」與「點破」疊用。原文「重點古非」＝重（再）點（指出）古解之非 → 「**再次點出**古解的過失」。
- **#30**「怎麼能**勉強包裹**在一起當成同一條戒」→ 口語且失律家語感 → 「怎能**強行束合**為一戒？」
- **#24**「在事實審核清楚之前真相未明」→ 稍繞 → 「此則是**事情尚未審查明實**，故稱不定」。另「二三、單並不定」的「單並」指單犯或併犯，譯「數量不確定」略偏，可作「所犯是二罪三罪、單犯或併犯，皆不確定」。
- **#22**「其餘**詳盡辨析如同**《義鈔》所述」→ 直作「其餘**詳見**《義鈔》」即可。
- **#32**「所以極有必要**立法禁制**」→ 律家語作「**制戒**禁斷」較貼切（#34「未曾立法禁止」同理）。

## 五、無問題、可保留者

#23、#28（「屏錄三罪，露收兩罪」判讀正確）、#31 末「即首解也」判為智首律師、#33「如戒緣說」譯為制戒緣起、#40 科判分句（初二句／故下／令下）等，理解都準確。

**優先處理順序建議：** 一之 1（容）、2（染分）、3（能治行）、5（同處麤語）→ 二之 #38「重罪」、#33「多是」→ 三之《義鈔》書名與引文對應字統一 → 其餘潤飾。
