# 校閱材料　第003檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【003-0002】01_行事鈔/00_卷首#79
【原文】後明鈔興本意。夫鈔者，固令撮略正文，包括諸意也！余智同螢曜，量實疎庸；何敢輕侮猷言，動成戲論。雖然，學有所承，承必知本；每所引用，先加覆撿。於一事之下，廢立意多；諸師所存，情見繁廣。今並刪略，止存文證。及教通餘論，理相難知；自非通解，焉能究盡？具如集《義鈔》所顯。而抄略證文，多不具委，但取文義堪來入宗者。自外不盡之文，必欲尋討，知其始末，則非鈔者之意。故文云：諸比丘欲不具說文句，佛言聽之。《毘尼母論》云：佛令引要言妙辭，直顯其義。庶令臨機有用，無待訪於他人；即事即行，豈復疑於罪福？猶恐後代加諸不急之務，增益其中，使真宗蕪穢，行者致迷；鳥鼠之喻，復存於茲日矣！
【譯文】最後說明這部鈔興起的本意。所謂「鈔」，本來就是要撮取正文的精要、包括諸家的意旨！我的智慧如同螢火之光，才量實在疏淺平庸；怎麼敢輕慢聖人的言教，動輒成為戲論。雖然如此，所學有所傳承，傳承就必須知道根本；每次有所引用，都先加以覆核檢查。在每一件事之下，取捨建立的用意很多；諸位律師所保存的，情見繁雜廣博。現在一概刪略，只保存文證。至於教法通於其餘論典，義理相狀難以了知；若非通達理解，怎能究盡？詳細如所集的《義鈔》中所顯示。而抄錄節略的證文，大多不夠完備詳委，只取其中文義足以收入本宗的部分。除此之外未盡的文字，若一定要尋求探討、知其始末，那就不是作鈔者的本意了。所以文說：諸比丘想要不具說文句，佛說可以。《毘尼母論》說：佛令引用要言妙辭，直接顯示其義。希望能使面對機境時有所用，不必等待去問他人；即事即行，哪裡還會對罪福有所疑惑？但仍恐怕後代加上一些不急要的事務，在其中增益，使真正的宗旨荒蕪污穢，行道的人因此迷惑；那麼「鳥鼠」的比喻，又要出現在今日了！

【003-0020】01_行事鈔/01a_卷上之一#15
【原文】夫律海冲深，津通萬象，雖包含無外，而不宿死屍；騰岳波雲，而潮不過限。故凡廁豫玄門者，克須清禁，無容於非；沐心道水者，慕存出要，無染於世。故能德益於時，迹超塵網。良由非法無以光其儀，非道無以顯其德。而澆末淺識庸見之流，雖名參緇服，學非經遠；行不依律，何善之有？情既疎野，寧究真要！封懷守株，志絕通望。局之心首，而言無詣；意雖論道，不異於俗；與世同流，事乖真趣。研習積年，猶迷闇託；況談世論，孰能體之？是以容致濫委，以亂法司。肆意縱奪，專行暴剋，尚非俗節所許，何有道儀得存？致令新學困於磐石，律要絕於羈䩛；於時正法玄綱，寧不覆墜耶？故知興替在人也！深崇護法者，復何患佛日不再曜，法輪不再轉乎！今略指宗體行相，令後進者，興建有託。
【譯文】律法的大海浩瀚深邃，津梁通達萬象，雖然廣大包含、無所不容，卻不容留死屍；其波浪翻騰如高山浮雲，但潮水決不越過堤防分限。因此，凡是參與佛門玄宗的人，必須嚴持清淨禁戒，絕不容納絲毫過非；凡是以聖道之水沐浴自心的人，當心懷出離的要旨，不受世俗塵勞所染污。如此才能使功德利益於當世，行跡超脫於塵俗羅網之中。這實在是因為若沒有如法的戒律，便無法光大威儀；若沒有修道的實踐，便無法顯揚道德。然而末世那些識見淺薄、見解庸俗之輩，雖然名義上身著僧衣，學問卻不深遠久長；行為不依循戒律，能有什麼善德可言？心性既然粗疏狂野，又怎能探究佛法的真實要旨！自我封閉、守株待兔，心志斷絕了圓通遠大的指望。心胸狹隘局促，言論毫無著落；本意雖然是在談論佛道，卻與世俗庸論毫無差別；隨順世俗同流合污，行事背離了真實的妙義。縱使研習戒律多年，仍然茫然不知依託與歸宿；更何況談論世俗之言論，又有誰能真正體悟法理？因此導致偽濫委積，擾亂了主持教法的僧綱體統。甚至肆意放縱、橫加剝奪，專行暴虐苛刻之事，這連世俗的節操品行尚且不容許，哪裡還有修道的威儀能夠留存？致使初學者困滯不前，如被巨石壓身；戒律的綱要如同斷絕了韁繩車軔（失去規範約束）；到了這種地步，正法的玄奧綱領怎能不傾覆墜落呢？所以可知，佛法的興盛與衰替全在於人！若是真正深切尊崇且護持正法的人，又何須憂慮佛日不再照耀、法輪不再轉動呢！如今在此簡略指陳戒律的宗體與行相，使後來的學人，在建樹正法時有所依憑寄託。

【003-0021】01_行事鈔/01a_卷上之一#16
【原文】夫戒者以隨器為功，行者以領納為趣。而能善淨身心，稱緣而受者，方克相應之道；若情無遠趣，差之毫微者，則徒染法流，將何以為道之淨器？為世良田，義復安在？是以凡欲清身行徒，遠希圓果者，無宜妄造；必須專志攝慮，令契入無滯。故經云：雖無形色，而可護持，斯文明矣！何者？但戒相多途，非唯一軼；心有分限，取之不同；若任境彰名，乃有無量；且據樞要，略標四種：一者戒法，二者戒體，三者戒行，四者戒相。
【譯文】戒法的作用在於隨順受者的根器而發揮其功用；修持者的要旨則在於能領納戒法於心。只有能善加清淨身心、契合如法之機緣而受戒的人，才能成就感通相應的聖道；如果心中沒有遠大的求道旨趣，稍有絲毫差池，就只是徒然沾染法流的名相，又憑什麼作為承載大道的清淨器具？作為世間眾生的良田福田，其意義又在何處？因此，凡是想要使身心清淨的修行者、遠期證得圓滿聖果之人，切不可魯莽妄動；必須專注心志、收攝雜念，使自心契入戒法而無所凝滯。所以經典中說：「戒法雖然沒有形體色相，卻可以持守護持」，這段經文說得極為明瞭！為什麼呢？因為戒的行相途徑繁多，並非只有一種軌轍；行者的發心各有限量，領納也有所不同；如果隨順外境來立名，更有無量差別；暫且依據樞要，大略標示四種：一是戒法，二是戒體，三是戒行，四是戒相。

【003-0022】01_行事鈔/01a_卷上之一#17
【原文】言戒法者，語法而談，不局凡聖。直明此法，必能軌成出離之道，要令受者信知有此。雖復凡聖通有此法，今所受者，就已成而言，名為聖法。但令反彼生死，仰廁僧徒，建志要期，高栖累外者；必豫長養此心，使隨人成就，乃可秉聖法在懷，習聖行居體，故得名為隨法之行也。
【譯文】所謂「戒法」，若純粹就其法門自體而言，並不局限於凡夫或聖人。直接說明此法，必然能夠範軌並成就出離生死之道，關鍵是要讓受戒者深信確知有這項解脫之法。雖然凡夫與聖人共同具備此戒法之理，但現在受戒者所納受的，就其圓成之功德而言，稱為「聖法」。只要能夠背離生死流轉，仰慕加入僧伽行列，立下誓願要期，高蹈於塵勞繫縛之外；受戒者必須預先長養這種出離向道之心，使戒法隨著受戒者自身的願力而成就，如此方能將聖法秉持於懷抱之中，將聖行修習於自體之內，所以稱之為順應戒法的修行。

【003-0023】01_行事鈔/01a_卷上之一#18
【原文】二明戒體者。若依通論，明其所發之業體；今就正顯，直陳能領之心相。謂法界塵沙，二諦等法，以己要期，施造方便；善淨心器，必不為惡；測思明慧，冥會前法。以此要期之心，與彼妙法相應，於彼法上，有緣起之義；領納在心，名為戒體。
【譯文】第二說明「戒體」。若是依照一般的通論，是說明受戒時所發起之無表業體；現在直接依正義顯明，直接陳述能領納戒法的心識行相。這是在受戒時，緣取法界如塵沙般的萬法、真俗二諦等法，依據自己立下的誓願要期，施設各種前行方便；妥善清淨自己的心器，立誓絕不再造作一切惡行；運用深思明達的智慧，使自心冥然密合於眼前所緣的境法。以此立誓要期之心，與那不可思議的微妙戒法相應，在此妙法之上，產生了緣起相生的義理；將此法領納銘刻於心，就稱為「戒體」。

【003-0024】01_行事鈔/01a_卷上之一#19
【原文】三言戒行者。既受得此戒，秉之在心，必須廣修方便，撿察身口威儀之行；克志專崇，高慕前聖，持心後起，義順於前，名為戒行。故經云：雖非觸對，善修方便，可得清淨，文成驗矣。
【譯文】第三說明「戒行」。既然已經受得此戒體，秉持在心中，之後就必須廣泛修習種種隨順護戒的方便，檢點省察自己身、口二業與行住坐臥的威儀；克制心志、專一尊奉，高蹈仰慕前代聖者，受戒後隨順而發起持守之心，行持的義理順合於先前所發的誓願，這就稱為「戒行」。所以經典中說：「戒體雖然不是有形質可以觸對之物，但只要善加修習持戒方便，身口就能得到清淨」，這段經文正可作為明證。

【003-0025】01_行事鈔/01a_卷上之一#20
【原文】四明戒相者。威儀行成，隨所施造，動則稱法，美德光顯，故名戒相。
【譯文】第四說明「戒相」。當威儀操行修習圓滿，隨順日常一切施設作為，一舉一動都能合乎戒法軌度，美好德行外彰光顯，所以稱為「戒相」。

【003-0026】01_行事鈔/01a_卷上之一#21
【原文】此之四條，並出道者之本依，成果者之宗極，故標於鈔表，令寄心有在；知自身心，懷佩聖法，下為六道福田，上則三乘因種；自餘紹隆佛種，興建法幢，功德不可思議，豈唯言論能盡！直引聖說成證，令持法高士，詳而鏡諸。就中分二：初明順戒，則三寶住持，辨比丘事。二明違戒，便覆滅正法，翻種苦業。但諸經論歎戒文多，隨部具舒，相亦難盡。今通括一化，所說正文，且引數條，餘便存略。
【譯文】這四條綱要，都是修道出離者根本的依憑，證得聖果者至極的歸宿，因此標列於本鈔卷首，使學人寄託發心有所方向；讓人明白自己的身心，已經佩帶奉持著出世聖法，向下可以作為六道眾生的福田，向上則是成就三乘聖道的因種；其餘延續光大佛法僧種、建立正法寶幢的不可思議功德，哪裡只是言語論述所能說得盡的！現在直接引證佛聖言教作為憑證，使秉持佛法的高尚之士，能夠詳審審察明鑑。其中分為兩部分：首先說明順從戒律，則三寶得以久住維持，辨析比丘應行之事。其次說明違背戒律，便會覆滅正法，反倒播下受苦的業因。然而諸部經論讚歎持戒的文句極多，若隨各部完全鋪陳，義相難以窮盡。現在綜括佛陀一代教化所說的正文，暫且引錄數條，其餘則予省略。

【003-0028】01_行事鈔/01a_卷上之一#23
【原文】初又分四。一就小乘經者。如《般泥洹經》明：佛垂滅度，世間無師，阿難啟請。佛言：比丘若能奉戒者，是汝大師，若我在世，無異此也。《遺教》等經並同斯示。然發趣萬行，戒為宗主，故經云：若欲生天等，必須護戒足。又如大地能生成萬物，故經云：若無淨戒，諸善功德不生。又云：依因此戒得有定慧。又經云：戒者，行根住持。即喻如地能生成住持也。
【譯文】化教中又分為四項。第一依小乘經典：如《般泥洹經》中所載：佛陀臨近滅度時，世間將失去導師，阿難尊者向佛啟請。佛陀說：「比丘若能奉持戒律，戒律就是你們的大師，這與我親自在世教導沒有任何差別。」《佛遺教經》等經也同樣作此昭示。而且發起趨向萬種善行，戒律是其宗主，所以經典說：「如果想要投生天界等善趣，必須保護好自己的戒足。」戒律又如大地能化育生成萬物，所以經典說：「若是沒有清淨戒律，一切善法功德皆不得生起。」又說：「依憑於此戒，方能發起禪定與智慧。」又經中說：「戒律，是一切行門善根的住持依託。」這就是以大地能化育生成與安住執持萬物作為譬喻。
