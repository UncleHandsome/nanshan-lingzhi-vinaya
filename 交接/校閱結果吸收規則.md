# 校閱結果吸收規則

每次拿到 `校閱批次/new/reN.txt`，一律用：

```
python _src/absorb_review.py 校閱批次/new/reN.txt reN
```

它會：

1. 從報告抓 `NN-NNNN` 與「檔案編號：NN-xxxx ～ NN-yyyy」兩種線索。
2. 把對應的 `校閱_NN.txt` 移到 `校閱批次/new/已完成/reN/`。
3. 重建 `index.tsv`（檔數、段數、bytes）。

## 為什麼要這樣

- 只靠 `NN-NNNN` 會漏掉「零問題」的檔案——它們沒有任何意見，也就沒有編號。
- 所以提示詞已要求每檔結尾固定輸出「檔案編號」與「已檢查 N／M 段」。
- 兩者合起來，才能保證每個跑過的檔都被收起來，不會重跑。

## 例外

- 報告若完全沒有「檔案編號」行（例如舊格式），只能靠 `NN-NNNN`；零問題的檔會留在待跑區，需人工確認。
