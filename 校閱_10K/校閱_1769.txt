# 校閱材料　第1769檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1769-0001】03_業疏/14b_卷三之三#42
【原文】善見》云：癩、癬二病，不問赤、白、黑，下至如爪。若在露處，增長、不增，俱不得度；屏處，增長不得，不增得度。《育王經》：疥癩初果，瘡痍四果也，由惑盡此生，業終報故，總集受也。《多論》云：出家後癩者，諸有僧事，皆共作之；若二食時，莫在眾也
【譯文】《善見律》說：癩病與癬病這兩種病，不問是赤色、白色或黑色，小至如同指甲蓋大小。如果長在顯露之處，無論是繼續擴大或不再擴大，都不得度化；若是長在隱蔽處，擴大的不得度，不再擴大的則可以度化。《阿育王經》說：患疥癩的人證得了初果，身生瘡痍的人證得了四果，這是因為煩惱在這一世斷盡，業報至此終結，所以重報總集於一身受償。《薩婆多論》說：出家之後才患上癩病的，一切僧眾事務都可以共同參與；但到了晨粥與中食這兩餐進食之時，不可處於僧眾之中。

【1769-0002】03_業疏/14b_卷三之三#43
【原文】別釋中初科，《善見》屏、露兩別，意恐招譏，不生物善故。次、《育王經》，即明聖人未免業報，則凡夫可知也。業終報者，謂所作業終此一報。三、引《多論》受後患生處眾之法。僧事，即羯磨
【譯文】在分別解釋的第一科中，《善見律》將隱蔽處與顯露處分為兩種差別，用意在於唯恐招致他人譏嫌、無法令眾生生起善心的緣故。其次引用《阿育王經》，就是說明聖人尚且免不了業報，那麼凡夫的情形就可想而知了。所謂「業終報」，是指所造之業在這一身報應中徹底終結。第三、引用《薩婆多論》說明受戒之後罹患疾病時處於僧眾中的規矩。僧事，就是指僧團羯磨法事。

【譯文】《五分律》中說：狂亂、心智敗壞、或者沒有和尚，都不能稱作受戒。

【譯文】在次一科的引文開示中，「或無和尚」這一句，是連帶順便引用的。

【1769-0005】03_業疏/14b_卷三之三#46
【原文】今時受者，至時昏梗，瞪瞢如醉，此竝亂心，全無心領，何發無作？和上諸師，俱不清卓，故臨作法，多增掉慢，輕略眾網，鬧憒識神，或至睡眠，低頭合眼，意謂耳聞，而實昏惱，前後文字，何能具領？故賊住成難，要在具辭；今聽錯亂，豈成弘攝？俱不成受，如非數說
【譯文】現今的受戒者，臨到受戒時神智昏昧阻滯，目瞪眼花如同醉酒，這些全屬心智錯亂，完全沒有用心領納，如何能發起無作戒體？和尚與諸位戒師，全都不清高卓越，所以在臨場作法時，多半增長掉舉傲慢，輕忽草率地對待大眾綱紀，神識散亂紛擾，甚至昏沉睡眠，低頭閉眼，心想耳朵還聽得見，而實質上神智昏沉惱亂，戒相前後的文辭，又豈能完全領納？所以賊住之所以構成重難，關鍵在於能具足聽懂文辭；如今聽聞時顛倒錯亂，又豈能成就戒法的弘通與攝受？這些全都不能成就受戒，如同算不上出家之數那樣所說的。

【1769-0006】03_業疏/14b_卷三之三#47
【原文】斥非中，初、敘機鈍。梗，塞也；瞪，文證反，目直視貌；瞢，武互反，心不明也。「和尚」下，次、斥師乖。不清卓者，解行鈌也。臨席作法，有三過：一、輕慢，二、閙憒，謂馳散也，三、昏睡。仍引賊住反例。如法要具辭者，初、中、後語，始終無謬。弘，謂弘法；攝，即攝機
【譯文】在斥責非法的文字中，首先敘述受戒者根機愚鈍。「梗」是阻塞的意思；「瞪」，音為「文證切」，是兩眼直視的樣子；「瞢」，音為「武互切」，是心智昏昧不明的意思。從「和尚」以下，其次斥責戒師的乖違。「不清卓」，是指見解與行持都有所欠缺。戒師臨席作羯磨時，有三種過失：第一是輕率傲慢；第二是散亂紛擾，即心念奔馳散亂；第三是昏沉睡眠。接著引用賊住的例子從反面作例證。所謂合法的羯磨必須具足文辭，是指初、中、後的詞句始終毫無差謬。「弘」，是指弘揚戒法；「攝」，是指攝受受戒根機。

【譯文】第五、作白召喚進入僧眾之中，就此分為三個部分：因緣、白法、威儀。

【1769-0010】03_業疏/14b_卷三之三#51
【原文】初緣中，相去舒手相及處立者，中國戒壇多在露地，故須在於兩手相接，即一尋內。地有成僧，相遠不相攝，則別眾收。豈唯教師，餘僧亦爾。中間非數，兩頭須及；恐有見譏，但望叢坐，展轉周帀，會有相連。在於覆處，不用此制
【譯文】在最初的因緣中，相距在伸手可及之處站立的規定，是因為印度的戒壇大多設在露天開闊之地，所以必須在雙手可以相接的範圍內，即一尋（八尺）之內。在露地上若要成就合法的僧團，如果彼此距離過遠而不能互相攝受，就會被判定為別眾。豈止是教授師，其餘僧眾也是如此。若列行對坐導致中間隔得太遠，就會被算入非數；若不然，就必須讓兩端的僧眾伸手相及；唯恐有人見了譏嫌，只要大家聚集坐在一起，展轉環繞一圈，終究會有相連的可能。如果是在屋簷覆蓋之處，就不適用這條限制。

【1769-0011】03_業疏/14b_卷三之三#52
【原文】第五緣中初科，初、正釋教師立處。「豈」下，次、明眾僧坐相。由列行對坐，則中間相遠，故非數收；不然，須令兩頭伸手相及。借令如此，猶恐見者譏為非數，故令叢坐，則免他疑。言叢坐者，謂叢身參坐，不使相遠也
【譯文】第五項因緣的第一科中，首先正解教授師站立之處。從「豈」字以下，其次說明僧眾就坐的相狀。由於列行相對而坐，中間距離便會相隔過遠，因此會被算入非數別眾；不然，就必須讓兩端的僧眾伸手相及。假使做到這樣，還唯恐見到的人譏笑不算法定僧數，所以令大眾叢聚而坐，就可以免除他人的疑慮。所謂「叢坐」，是指大家聚身交錯而坐，不讓彼此相隔太遠。

【1769-0012】03_業疏/14b_卷三之三#53
【原文】文令立者，諸羯磨法，威儀必同；此既坐立，極成乖別。由本是僧差，往外為問，事須酬對，坐和失相。如立說戒，俱是為僧，意可見也。餘通如眾，有乖成別
【譯文】文中命令站立的原因：各項羯磨法事中，僧眾的威儀姿態必須相同；這裡既然有人坐有人立，極其容易造成乖違隔閡。這是由於教授師本是由僧團派遣，前往壇外詢問，事理上必須當面應對答覆，若是坐著與僧和合，就會失去奉差應對的儀相。這如同站立說戒一樣，全都是為了僧事，其中的用意顯而易見。其餘一般的羯磨法都要與大眾姿態相同，若有違背便構成別眾。

【1769-0013】03_業疏/14b_卷三之三#54
【原文】次科，初、敘異。「由」下，釋通。坐和失相，謂非為使酬對之儀。如「下」，引例。「餘」下，示餘法不開
【譯文】次一科中，首先敘述威儀不同之處。從「由」字以下，解釋會通。所謂「坐和失相」，是指坐著就失去了作為特使奉命應對的威儀姿態。從「如」字以下，引用站立說戒為例。從「餘」字以下，指出其餘羯磨法皆不開許坐立不同。

【1769-0014】03_業疏/14b_卷三之三#55
【原文】二、正加法。邊地五人僧者，據斯一白用僧處也；中方僧多，十人加法，通始終作
【譯文】第二、正式加施白法。所謂邊地五人僧團，是依據此一單白羯磨所需要的僧眾人數而言；中方僧人眾多，則以十人僧團加施作法，貫穿首尾始終而作。

【1769-0015】03_業疏/14b_卷三之三#56
【原文】法中初科，邊地五人，前後三法皆四人僧，獨此一白五人僧用，故云「用僧處也」。中國始終，通是十人
【譯文】在正法的第一科中，邊地規定五人，其前前後後的三個法事都只需四位僧人，唯獨這一單白羯磨需要五位僧人，所以說「所用僧眾之處」。中國自始至終，通通都是十人僧團。
