# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】【記】三、明自然，敘意中。初二句標示。「下」下，明僧衣二界相參所以。「如鳥知雌雄」者，《詩》云：「具曰予聖，誰知烏之雌雄。」彼刺周幽王昏亂，君臣上下不辨尊卑，今借彼意反而用之。「略」下，列章。科名難曉，如下隨解。

【252-0007】02_戒疏/13a_卷三下之一#42
【原文】【疏】聚落有二：可分別者，如《十誦》盡聚落集之；不可分者，如《僧祇》七弓之量，七樹中間則六十三步。廣如《羯磨疏》中。
【譯文】【疏文】聚落有兩種：能夠劃分邊界的，依照《十誦律》，應當召集整個聚落的僧眾；不能劃分邊界的，依照《僧祇律》，以七張弓的長度為準，七棵樹之間就是六十三步的距離。詳細內容如同《羯磨疏》所述。

【252-0008】02_戒疏/13a_卷三下之一#43
【原文】【記】聚落中。「可分別」者，處有分齊，人有限量。反此二種，名「不可分別」。由無限齊，故依「樹量」合數。並如《鈔記》。
【譯文】【記文】聚落之中，「可分別」的，是處所有明顯界限，人數也有限量。反於這兩種情況的，稱為「不可分別」。由於沒有界限，所以依照「樹木的間距」來折算步數。這些都詳見於《戒本疏鈔記》。

【252-0009】02_戒疏/13a_卷三下之一#44
【原文】【疏】二者，蘭若，亦有兩種：無難空地，可用《十誦》面俱廬舍五里集之；有難蘭若，則如《善見》七槃陀量五十八步四尺八寸。所以有難、無難者。僧法同遵，義無乖競，必有見異，多恐破僧，故須局狹。必若情通，自然廣攝。
【譯文】【疏文】第二種是阿蘭若，也有兩種：沒有危難的荒野空地，可以採用《十誦律》所說以一個俱盧舍（方圓五里）的範圍來召集僧眾；有危難的阿蘭若，則依照《善見律》以七個槃陀的距離，即五十八步四尺八寸為準。之所以區分有危難與無危難，是因為僧法應當共同遵守，在義理上不容許有違逆爭端，一旦意見不同，很可能導致破僧，所以界域必須收緊局限；如果僧情通達無礙，自然就可以廣泛包容攝受。

【252-0010】02_戒疏/13a_卷三下之一#45
【原文】【記】蘭若中。初列示兩相。《十誦》「俱盧」止是二里，今言「五里」，依《雜寶藏經》也。「七槃陀」，「槃陀」梵語，即彼量名。「所」下，推釋分意。言「有難」者，即三小界。不同意人作難故開，故云「必有見異」等。「情通廣攝」，即無難五里集也。
【譯文】【記文】阿蘭若之中，首先列出並指示兩種相狀。《十誦律》的「俱盧舍」只是二里，此處說「五里」，是依據《雜寶藏經》。「七槃陀」，「槃陀」是梵語，就是該處的度量名稱。「所以」以下，推究並解釋區分的用意。所謂「有危難」，是指三種小界。因為持不同見解的人引發留難諍礙，所以開許設立小界，因此說「必有見異」等。「僧情通達自然廣泛攝受」，就是指沒有危難時以五里範圍召集僧眾。

【252-0015】02_戒疏/13a_卷三下之一#50
【原文】【疏】上列二門，各有教相，僧、衣不同。今次第四，單就村落合辨人衣寬狹不同。所以同處人寬衣狹者。人為同法，事須通和，少一不成，前須濟益，必約詳御，用寬為善。三衣若離，多諸過咎，更無別辨，義在隨身，故制須狹。
【譯文】【疏文】上面列出兩門，各自具有教法的規範，在僧界與衣界互不相同。現在接著是第四門，單就村落來綜合辨別攝人與攝衣範圍寬狹的不同。之所以同處一地而攝人範圍寬、攝衣範圍狹，是因為人是共同行持佛法者，事情必須通融和合，缺少一人羯磨就無法成就，首要的是給予濟拔利益，若要審慎御眾，範圍寬廣比較妥當；至於三衣若脫離身邊，會產生許多過失，沒有其他特別的通融，其義理全在於常隨己身，所以制定的範圍必須狹小。

【252-0016】02_戒疏/13a_卷三下之一#51
【原文】【記】四中。初結前。二、三兩門，並約僧衣二界空聚對論。「今」下，生後。「所以」下，徵釋。初徵。「人寬」，即可不可分二種聚落。「衣狹」，即下「村界」，必有三礙，制隨身故。「人為」下，次釋。初釋人寬。「三」下，釋衣狹。

【252-0017】02_戒疏/13a_卷三下之一#52
【原文】【疏】五、明蘭若人衣不同。空逈少礙，僧遊者希，事須作法，遠攝方得。處非諠雜，過濫又希。若欲攝衣，同前空難，通其勢分，七十步餘。
【譯文】【疏文】第五、說明阿蘭若中攝人與攝衣的不同。空曠遼闊之處障礙較少，僧人遊歷來此的極為稀少，遇到僧事必須作法時，必須擴大攝受範圍才能召集大眾。此處不是喧鬧雜亂之地，違法濫權的情形也極為少見。如果想要攝持衣服，則比照前面空處有危難的尺度，通計其所延伸的勢力範圍，約有七十多步。

【252-0018】02_戒疏/13a_卷三下之一#53

【252-0019】02_戒疏/13a_卷三下之一#54
【原文】【疏】六、明自然攝衣強弱不同。
【譯文】【疏文】第六、說明自然攝衣界力量強弱的不同。

【252-0020】02_戒疏/13a_卷三下之一#55
【原文】【疏】就於自然，又分三等。且依《四分》十一自然。八界，望僧住、人住，八界是弱，藍、村是強。八界自相望，如樹、車等，不論強弱。蘭若空界，不守自性，全是其弱。
【譯文】【疏文】就自然界而言，又分為三個等級。暫且依照《四分律》的十一種自然界：樹木、車輛等八種界，相對於僧人所住、俗人所住之處，這八界屬於弱，僧伽藍與村落屬於強；八界彼此相互對照，例如樹木與車輛等，則不分強弱；至於阿蘭若這種空曠之界，無法守持自身的獨立性，完全屬於弱。

【252-0021】02_戒疏/13a_卷三下之一#56
【原文】【記】第六，總論中。初標示。「八界」下，別釋。初八望「藍、村」為一等，「八界」即樹、場、車、船、舍、堂、倉、庫也。八自相望為一等。蘭若自為一等。
【譯文】【記文】在第六門總論中，首先標示章目。「八界」以下，分別解釋。前八界相對於「僧伽藍、村落」為一個等級，所謂「八界」就是指樹木、打穀場、車輛、船隻、房舍、堂閣、糧倉、庫房。八界彼此互相比對為一個等級。阿蘭若自己單獨為一個等級。

【252-0022】02_戒疏/13a_卷三下之一#57
【原文】【疏】僧村二界，互兩相形，則俗強僧弱。何以知之？俗人入寺，別生村界，比丘入村，無別藍界。
【譯文】【疏文】僧伽藍界與村落界，兩者互相對照時，則是世俗村界強而僧界弱。如何得知呢？世俗之人進入寺院，會另外產生村落界；比丘進入村落，卻不會另外產生僧伽藍界。

【252-0023】02_戒疏/13a_卷三下之一#58
【原文】【記】次僧村，強弱中，初科。「俗人入寺」既「別生村」，故知「俗強」。「比丘入村」既「無別藍」，故知「僧弱」。
【譯文】【記文】接著在討論僧伽藍與村落的強弱中，這是第一段。「俗人入寺」既然「另外產生村界」，所以知道「世俗強」；「比丘入村」既然「沒有另外形成僧伽藍界」，所以知道「僧界弱」。

【252-0024】02_戒疏/13a_卷三下之一#59
【原文】【疏】若準此說，恐理不然。若彼俗人將家男女入寺別院，有界亡言。若在露地却施障幕，是村以不？若言是村，村則有相，四種之中，何相所攝？若是有村，約何分齊，非時入相？結攝衣界，除斯村不？若不除此，文云「村所及處」，如其不除，應不失衣。若即失衣，成村義立。
【譯文】【疏文】如果依照這種說法，恐怕義理上並非如此。如果那些俗人帶著家眷男女進入寺院的獨立院落，已有清楚邊界，自不待言。但若在露天處只是搭設遮障帷幕，這樣算不算村落呢？如果說是村落，村落就必須有特定界相，在四種村落界相之中，屬於哪一種所攝？如果這算是有村落，要依據什麼分界來判定比丘「非時入村」的犯相？在結界攝持衣服時，是否要扣除這個帷幕村落呢？如果不扣除，經文說「在村落勢力所及之處」，假使不扣除它，比丘在寺內過夜就應該不算失去衣服的管領。但如果立刻就算失衣，那麼將帷幕判定為村落的義理才能成立。

【252-0025】02_戒疏/13a_卷三下之一#60
【原文】【記】次難破者。以上文但云「俗人入寺」，而不明成村相故。初二句通斥。「若彼」下，牒難，又二。初舉別院，縱彼所立。「將家男女」者，以單俗人則非村故。「亡言」，「亡」，無也，謂不在致詰。「若在」下，次約施障，正難非村。初通問。「若言」下，別難，又三：初以四相不成難；「若是」下，次約非時入犯難；「結攝衣」下，三、約結法牒除難。
【譯文】【記文】接著是駁斥難破的內容。因為前文只說「俗人入寺」，卻沒有說明構成村落的界相。前兩句是通盤駁斥。「若彼」以下，提出詰難，又分為兩層。先舉獨立院落為例，暫且放過對方的立論；「將家男女」，是因為單一俗人不能構成村落；「亡言」，「亡」即是無，意思是不需要在此詰問。「若在露地」以下，接著以搭設帷幕為例，正式詰難這不能稱為村落。先作通泛提問。「若言是村」以下，分別詰難，又包含三個層次：首先以無法符合四種村相來難破；「若是」以下，接著以非時入村的犯戒定義來難破；「結攝衣界」以下，第三以結界時是否宣讀排斥該處來難破。

【252-0026】02_戒疏/13a_卷三下之一#61
【原文】【疏】若如此徵，但是障礙二通，不名村界。以彼俗家未來之時，人衣往返，二通無壅。由其來故，是為情隔，不許往還，故是失衣。
【譯文】【疏文】如果這樣詰問，那其實只是造成進出兩相隔閡的障礙，不能稱為村落界。因為那些俗人家庭還沒有來的時候，比丘與法衣往返其間，出入兩無阻礙。由於他們的到來，形成了情感或世俗上的隔閡，不再允許比丘自由來回，所以才會失去對衣服的管領。

【252-0028】02_戒疏/13a_卷三下之一#63
【原文】【疏】今通論之。無問道俗，互入僧、村有四相者，僧、村界起。此即相望，何論強弱？
【譯文】【疏文】現在通泛地討論：無論是出家人還是世俗人，互相進入僧伽藍或村落，只要具備四種界相，僧界或村界就會生起。這本是平等的相互對照，哪裡有什麼強弱之分呢？

【252-0029】02_戒疏/13a_卷三下之一#64
【原文】【記】次無強弱中。俗入僧中，則有村界，比丘入俗，則成僧界，二種竝約「別有院相」為言。兩相各立，故無強弱。
【譯文】【記文】接著在論述無強弱之分中，世俗人進入僧寺，若有界相就會形成村界；比丘進入俗地，若有界相也會形成僧界，這兩種情況都是以「另外具備獨立院落界相」而言。兩邊界相各自成立，所以沒有強弱之分。
