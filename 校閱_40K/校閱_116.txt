# 校閱材料　第116檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【記】十一，初總示。「舟」下，別釋。初明盜物。「若」下，明盜船。「《僧祇》中」，明因果、分齊、次第之相。「《善生》離栓」亦同。「栓」，巨月反，樁也。
【譯文】【記文】第十一項，首先總括說明。從「舟」字以下，分別解釋。首先說明盜取船上的物品。從「若」字以下，說明盜取船隻本身。「《僧祇律》中」，指明了犯罪前因後果、界線、階段先後的相貌。《善生經》說「離開木樁」也是同樣的道理。「栓」字音「決」，就是指繫船的木樁。

【116-0002】02_戒疏/07a_卷二上之三#63
【原文】【疏】十二、「盜水」者，律中但明所損，不出分齊。如《僧祇》中，溉灌流水，或一宿直一文，乃至四五，比丘為於佛僧，復自為，盜壞彼渠，得越；水入田，蘭；滿五者，夷。《摩得伽》云：「計彼塘工，過分而用，水滿者結重。」
【譯文】【疏文】第十二、「盜水」，本律中只說明造成他人的損失，沒有明確劃分界線。如同《僧祇律》所記載，用來灌溉的流水，灌溉一整夜價值一文錢，乃至四文五文，比丘為了佛陀或僧團，又或者為了自己，暗中毀壞他人的水渠，犯突吉羅；水流進田地，犯偷蘭遮；流入之水價值滿五錢者，犯波羅夷。《摩得伽論》說：「計算修築該水塘的工程費用，若超額享用水流，所盜用的水價值滿五錢者結重罪。」

【116-0003】02_戒疏/07a_卷二上之三#64
【原文】【記】十二，初示本宗通漫。《律》中但云「盜水中金銀、衣被、魚鼈，及壞他水處」等。「如」下，引他部顯相。《僧祇》，前明主者計價，下明比丘盜損。「為佛」者，他緣亦犯也。「渠」即水溝。《伽論》二義判犯：一、計塘工；二、用過分。
【譯文】【記文】第十二項，首先說明本宗《四分律》的文義較為籠統含糊。《律》中只說「盜取水中的金銀、衣服被褥、魚鱉，以及毀壞他人的蓄水處」等等。從「如」字以下，引用其他部派的律典來彰顯明確行相。《僧祇律》中，前半段說明管理水利者如何計算價值，後半段說明比丘盜水的損害罪責。「為了佛陀」等語，是說明為他人的緣故盜水同樣犯戒。「渠」就是水溝。《摩得伽論》依據兩個準則來判罪：第一、計算水塘工程費用；第二、使用超額。

【116-0005】02_戒疏/07a_卷二上之三#66
【原文】【疏】如《律》，比丘無稅，白衣應稅，為彼過物，故制重。如《十誦》中：「比丘應稅，不稅亦重。雖不為過，而示餘道，以不被稅，為他過物，故犯罪也。」如《多論》中，持國禁物出界，入死罪，故言重者，但違王教，故得吉羅。《薩遮經》云：「不輸王課，非盜也。」又《僧祇》云：「一切出家人不稅。若賣買人，應稅。」
【譯文】【疏文】如同《律》所規定，比丘依法免稅，在家人應當繳稅，比丘若替在家人夾帶走私貨物過關，所以制定為重罪。如同《十誦律》中所說：「如果比丘也應當繳稅的國家，比丘逃漏關稅也犯重罪。雖然沒有替人夾帶，卻指出其他逃稅小道，使其免於被課稅，這等同替他人逃漏貨物，所以也構成犯罪。」又如《薩婆多論》中所說，攜帶國家禁運的物品出國境，在國法上被判處死罪，所以才說是重罪；但若只是違背國王的法令，在戒律上只結突吉羅罪。《薩遮經》說：「不繳納國王的稅捐，並不構成偷盜。」此外《僧祇律》也說：「一切出家人都不用繳稅。但如果是經商做買賣的人（世俗商人），就應當繳稅。」

【116-0006】02_戒疏/07a_卷二上之三#67
【原文】【記】十三中，初科。本律「比丘無稅」者，謂官不稅比丘物，而為他過物也。《十誦》，初明自稅，謂有國土，稅比丘物。「雖」下，明為他免稅。《多論》兩斷，《論》云：「若國禁物出王界者，入死罪。若比丘持出，律師初言得重。後云不入重，但有違王教，吉」。據此，縱令官稅比丘物，而故不稅者，止得吉耳。此則決前《十誦》結重之文。下引經律，文據益顯。《薩遮尼犍子經》云：「何等不應稅？世尊弟子、比丘、比丘尼、一切外道出家人物，是名不應稅；若賣買者應輸，是名稅分齊。」、「課」，即稅也。《僧祇》同上。
【譯文】【記文】第十三項中，第一小科。本律說「比丘無稅」的意思，是指官府不對比丘的隨身物課稅，而比丘卻替在家人夾帶偷運貨物。《十誦律》中，首先說明比丘自身應課稅的情況，是指有些國家連比丘的物品都要課稅。從「雖」字以下，說明替他人免除關稅的情況。《薩婆多論》有兩種斷定，《論》中說：「若是攜帶國家禁運物私出國界，依國法是死罪。若是比丘帶出，律師起初說犯重罪。後來修正說不算重罪，只算違背國王政令，結吉羅罪。」依照這個觀點，縱使官府要課比丘的稅，而比丘故意不繳，也只結吉羅罪而已。這就解決評定了前面《十誦律》結重罪的文句。下面引用經律，文獻依據更加明顯。《薩遮尼犍子經》說：「哪些人不應被課稅？世尊的弟子、比丘、比丘尼以及一切外道出家人的隨身物，這些都屬於不應課稅的範圍；但如果是從事經商買賣的，就應當繳納，這就是課稅的界限劃分。」「課」就是賦稅。《僧祇律》的說法也與此相同。

【116-0007】02_戒疏/07a_卷二上之三#68
【原文】【疏】若官稅比丘，方便自免者，非犯：一、本不共要，二、非理稅我。故上文云「比丘無稅法」也。若成犯者，賊來劫我，方便隱物，亦應犯重？然有白衣，官稅其物，比丘為隱，如《律》科重。
【譯文】【疏文】如果官府強行要課比丘的稅，比丘用巧妙方法讓自己免除繳納，這不算犯戒：一來彼此本來就沒有約定要納稅，二來官府是不合理地強徵我的稅。所以上文才說「比丘在法理上是沒有賦稅的」。如果這也算犯戒，那麼當強盜來搶劫我時，我用機智隱藏財物，難道也算犯重罪嗎？然而如果有在家人，官府依法要對其財物課稅，比丘替他藏匿走私，這就要如同《律》所說判處重罪。

【116-0008】02_戒疏/07a_卷二上之三#69
【原文】【記】次中。初明不稅無犯，又三。初約義定。「故」下，指文據，即《四分》、《多論》等文。「若」下，引事反質。「然」下，次明為俗故犯。「如《律》」，即上《四分》。

【116-0010】02_戒疏/07a_卷二上之三#71
【原文】【疏】初云「取信物」者。《律》中，持人物在右手，隨離結重。若本左手持物，盜心不還，須捨盜心，方移右手，不捨而移，是名重盜。如是類之。又《十誦》云：「若貸他物，抵言『不貸』，故妄，得提。」如《善見》中：「偷方便故吉羅。」《十》云：「若先用盡，後斷當已，得重。先斷當，後離處，方得夷。受他寄物亦爾。」《善見》云：「若負他債，比丘持去，無盜故無罪也。」
【譯文】【疏文】首先說到「奪取寄託信任之物」。《律》中記載，手中拿著別人的物品放在右手，隨後物一離開右手（本處）就結重罪。如果原本用左手拿著別人物品，心中生起偷盜念頭不想歸還，必須先捨棄盜心，才可以換移到右手；如果不捨棄盜心而直接換手，這就構成了嚴重的盜罪。其餘身體部位以此類推。另外《十誦律》說：「如果向他人借貸財物，事後耍賴不認帳說『沒借』，這是故意打妄語，得波逸提罪。」又如《善見論》中所說：「這屬於偷盜的預備行為，所以結吉羅罪。」《十誦律》又說：「如果先把借來的東西消耗用盡，事後才耍賴斷然拒絕歸還，得重罪。如果先耍賴拒還，之後才把東西移離原處，這才得波羅夷重罪。接受他人寄放的物品也是如此。」《善見論》說：「如果有人欠他人債務，比丘擅自替欠債人拿東西去還，因為沒有自肥的盜心，所以不構成盜罪。」

【116-0011】02_戒疏/07a_卷二上之三#72

【116-0028】02_戒疏/07a_卷二上之三#89
【原文】【疏】義言：「若他兒子賊奪去將，便損父母依報力用，屬賊是強。不得教走，若自走來，則不負賊。」故《十誦》中：「賊捉弟子將去，師還奪取，犯重。賊未決想，無犯。弟子自偷身來者，不犯。」如昔解云：「師不得奪，身自得走者：父母感子力強，賊奪得重，已屬賊是強，師弱奪賊，故重；兒報正體是強，賊得力用則弱，走是強報相逐，弱用隨來，不犯。」
【譯文】【疏文】法理上說：「如果別人的兒子被盜賊搶走擄去，這就損害了父母賴以生活的勞動力，此時兒子歸屬於盜賊的權力之下是強勢的。比丘不得教唆他逃跑，如果他自己逃跑回來，就不算辜負盜賊。」所以《十誦律》中說：「盜賊抓了弟子帶走，師父跑去奪取回來，犯重罪。若是盜賊心中還沒有徹底佔有的念頭，奪回就不犯戒。若是弟子自己偷跑脫身回來，就不犯戒。」如同過去的解釋說：「師父不得強奪、弟子卻可以自己逃跑的原因在於：父母感得兒子的勞力回報強烈，盜賊奪得即結重罪，但此時人身已落入盜賊掌控而成為強勢，師父權力薄弱卻向強勢的盜賊強奪，所以犯重罪；兒子自體的身報才是本體最強的，盜賊所得的只是支配勞力，相對而言是弱勢，兒子逃跑是依憑自己強大的身報自主離去，賊方微弱的勞役支配權也只是隨同其身體而歸來，所以不犯戒。」

【116-0029】02_戒疏/07a_卷二上之三#90
【原文】【記】奪賊中三。初以義判，前明賊奪成重。子是父母所依，假其力用，所損處重，故「屬賊強」。「不」下，教比丘護盜。教走成重，以損賊故；自來無過，以非意故。「故」下，引證，可見。「如」下，引昔解。初牒前兩判。「父」下，釋出所以。初明師犯重意。「兒」下，次明自來無犯。「兒報強」者，自所有身，非他屬故。「賊得弱」者，非所生親，復非雇主故。「強報相逐」者，身隨己意故。「弱用隨來」者，賊無分故。
【譯文】【記文】在從盜賊手中奪回的論述中分為三層。首先依法理判定，前半段說明盜賊奪取（弟子）即構成重罪。兒子是父母的生活依靠，仰賴其勞動付出，被搶走所造成的損害極重，故「屬賊強」。從「不」字以下，教導比丘如何防範偷盜罪。教唆其逃跑構成重罪，因為損害了盜賊既得的利益；若是自己逃回就沒有罪過，因為不是被比丘教唆指使的。從「故」字以下，引用文獻為證，顯而易見。從「如」字以下，引用古德的解釋。首先重提上述兩項判定。從「父」字以下，解釋其中的根本原因。首先說明師父搶奪犯重罪的原因。從「兒」字以下，接著說明自己逃回不犯戒的道理。「兒子的身報強」，是因為自己的身體屬於自己，並非天生屬於他人。「盜賊所得弱」，是因為盜賊並非生身父母，又不是出資雇主。「強報相逐」，是身體聽從自己的意志行動。「弱用隨來」，是因為盜賊對他的支配權本就薄弱，自然隨著人走而消失。
