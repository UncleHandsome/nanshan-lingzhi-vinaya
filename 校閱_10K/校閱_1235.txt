# 校閱材料　第1235檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1235-0001】資持記/11c_中四上#47
【原文】此緣所立，正取期心；但始終相當，於義易曉，所以唯明後心無記耳。引證中，初明先期後犯。文據無疑。逆重，即業制二俱犯也。阿下，引聖例凡。然羅漢夢犯，本非方便；但取無記有犯，例成上義，故云凡夫須準也。《智論》轉釋疑情，以無學結使已盡，無睡眠故；
【譯文】這一條緣所建立的目的，正是為了鎖定原初預期的心念；只要前念與後念始終相符，在義理上就容易理解，因此這裡只說明後續心念轉為無記狀態罷了。在引用證文之中，首先說明先有預謀期約而後犯戒的事實。文證的依據是毫無可疑的。「逆重」是指性罪的業道與教法的制戒兩者同時觸犯。從「阿下」開始，引用聖者為例來比況凡夫。然而阿羅漢在睡眠中犯戒，本來就沒有事先的方便罪；這裡只是借用在無記心態下仍可能犯戒的道理，來類推成立上述的論點，所以說「凡夫應當以此為準則」。《大智度論》則轉進一步解釋世人的疑惑，因為無學果位的聖者煩惱結使已經斷盡，本來不應當有睡眠的迷亂；

【1235-0002】資持記/11c_中四上#48
【原文】準《遺教論》，有三種睡眠：一從食起，二從時節起，三從心起；羅漢有上二，凡夫通三種。四五兩緣，不通者戒，先須料簡。初對上二篇，唯婬怨逼時開命難，餘竝無開，梵難一切不開。次就下三篇，一切性戒俱不開。三就遮戒，非下三句所收者，亦復不開。〔女三十開二戒，九十十入成，眾學二十六戒，如下引配。〕四中，初文。
【譯文】依照《遺教經論》，睡眠可分為三種：一是因飲食過量而生起，二是因時令氣候而生起，三是因內心煩惱昏昧而生起；阿羅漢只會出現前兩種睡眠，凡夫則是三種睡眠都全盤具足。在第四與第五兩條因緣中，有些戒條是不能通融開許的，這必須預先加以審查剖析。首先是相對於上兩篇（波羅夷與僧殘），只有在遭遇淫亂怨賊逼迫時才對「命難」有所開許，其餘情況全都不予開許，而「梵行難」更是一概不開許。其次是就下三篇而言，一切本質為惡的「性戒」全都不予開許。第三是就防微杜漸的「遮戒」而言，如果不屬於後述三句所涵蓋的範圍，同樣也是不予開許的。（如三十捨墮戒中開許了兩條，九十單墮戒中開許了十八條，眾學法中開許了二十六條，如後文所引證配合。）在第四緣中，是第一段文字。

【1235-0003】資持記/11c_中四上#49
【原文】標釋，可解。次科，性戒中，初正明，又二，初總示性重。且舉殺妄，顯無開理。唯下，別簡婬戒。三時無染者，雖開還制，異遮戒故。不損境者，出開所以；簡異餘重，一向無開。文下，引證。即初戒，釋同戒文。我為者，闢大慈門也；結戒者，授祕方也；寧死不犯，勸令守護，甚於命也。
【譯文】標釋容易明白。在下一科「性戒」之中，首先正式說明，又分為兩部分，第一是總體展示性戒罪責的深重。姑且舉出殺生與妄語為例，來顯明絕無開許免罪的道理。從「唯下」開始，個別揀擇淫戒。所謂「在受逼的三個時段中毫無染著之樂」，說明縱使暫且開許免除重罪、但隨後若起染心依然要制止結罰，這與一般的遮戒不同。所謂「沒有實質損害到對境的生命利益」，這是說明能夠開許的理由；以此揀別於其餘不可開許的重戒，那些是一概不能通融的。從「文下」開始引用證文。這就是初篇戒，用以解釋符合戒本之文。所謂「我為了……」，是開啟佛陀大慈大悲的法門；所謂「制定戒律」，是授予對治煩惱的祕方；寧可身死也絕不犯戒，這是勸勉大眾守護戒律的心應當看得比性命還要貴重。

【1235-0004】資持記/11c_中四上#50
【原文】此證性惡不開命難，據本文意，則通一切。遮中，初總示。道下，別釋，初釋上根不開。非教不開，但上根之士，重法輕生，護遮同性故也。草繫者，彼論第二云：昔有諸比丘，曠野中行，為賊剝衣；賊懼比丘往告聚落，即以草繫之；諸比丘護戒，不敢挽絕。中有老比丘，語諸年少云：汝等善聽。
【譯文】這是證明本質為惡的性戒不能因生命危難而開許，根據原文的意趣，是通達於一切性戒的。在「遮戒」之中，首先作總體的展示。從「道下」開始分別解釋，首先解釋上等根機的人絕不開許破戒。這並非教法本身不可通融，而是上根利智之士，重視佛法而輕視自身性命，愛護遮戒就像愛護性戒一樣嚴謹。所謂「草繫比丘」的故事，那部論的第二卷說：古時有一群比丘在曠野中行走，被強盜剝光了衣服；盜賊害怕比丘會跑到村落報官，就用雜草把他們綑綁在地上；這群比丘為了愛護草木戒，不敢用力扯斷青草。其中有一位老比丘對年輕僧人說：你們好好聽著。

【1235-0005】資持記/11c_中四上#51
【原文】人命短促，如河駛流。設處天堂，不久磨滅；況人間命而可保乎！既云不久，云何為命而毀禁戒？〔此言切要，故為具引。〕海板者，論云：昔有諸比丘，與估客人海採寶，船壞時，一年少捉一板，上座不得板，將沒水中。上座語年少言：汝不憶佛制，當敬上座。年少思惟，如來實有斯語；
【譯文】人的壽命短暫倉促，就像奔流的河水一樣迅速。縱使投生在天堂，不久之後也是要磨滅消失的；何況人間這點短暫的性命，哪裡是能夠常保的呢！既然明知生命不能久住，又何必為了這點微命而毀犯佛陀的禁戒呢？（這段話切中要害，所以特地為之完整引用。）所謂「海板」的故事，論典記載：古時有一群比丘，與商人入海採集寶物，船隻破裂損壞時，一位年輕比丘搶抓到了一塊木板，老上座沒有拿到木板，即將沉沒在海水中。老上座對年輕比丘說：難道你忘記佛陀的教誡，應當恭敬尊重上座長老嗎？年輕比丘心想：如來確實說過這樣的話；

【1235-0006】資持記/11c_中四上#52
【原文】乃說偈云：為順佛語故，奉板遺身命；若不為難事，終不獲難果，便即捨板；時海神感其精誠，接置岸上。論文緣廣，此略提名，不復具引，故云等也。〔有云：等鵝珠者，彼乃護性，非此中意。〕餘下，明中下根通開。兼梵難者，探示後開，竝下根故。
【譯文】於是他說了一首偈頌：為了順從佛陀的教誨，我交出木板捨棄自己的身命；如果不能經歷艱難困苦的行持，終究無法獲得難得的無上菩提佛果；隨即把木板讓了出去；當時海神被他至誠專精的心所感動，立刻將他接引安置到海岸上。論典中的因緣極為廣泛，此處只是略微提及名稱，不再完整引用，所以說「等等」。（有人說：這就像「鵝吞寶珠」的故事，但那是護持不殺生的性戒，並非此處討論護持遮戒的意思。）從「餘下」開始，說明中等與下等根機的人可以通融開許。其中兼含梵行難，是預先展示後面的開許，全都屬於針對下根之人而設的。

【1235-0007】資持記/11c_中四上#53
【原文】又復應知，此明開不開者，即約機大判；後就下根，自有開不開者，乃約教細分。五中，初科，標名顯相。婦女是婬緣，伏藏是盜緣，蟲即殺緣，惡伴是破眾戒緣。文下，引證。即〈安居〉中文，彼開破夏，直去無罪故。次科，總判中，初簡上二篇。不下，次簡性戒。就下，三簡遮戒。
【譯文】此外還應當明了，這裡說明開許與不開許，是針對眾生的機感所作的粗略判斷；後續針對下根之人，本身又有開許與不開許的細微分別，那則是依據教法的具體規定所作的細緻劃分。在第五緣中，第一科標示名稱並顯現行相。婦女是引發淫戒的助緣，地下的伏藏是引發偷盜戒的助緣，蟲蟻是引發殺戒的助緣，惡劣的同伴則是破壞僧團諸多戒規的助緣。從「文下」開始引用證文。也就是〈安居〉篇中的文字，該處開許比丘破除夏安居，直接離去而判定無罪。在下一科「總判」之中，首先揀除上兩篇（波羅夷與僧殘）。從「不下」開始，其次揀除性戒。從「就下」開始，第三是揀除遮戒。
