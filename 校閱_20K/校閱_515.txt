# 校閱材料　第515檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【515-0001】資持記/06b_中一上#36
【原文】以下，鈔家結示。無慚無悔，即是不善，始終二心。該前四種，一一相兼。初無者，古記云：初，猶都也；雖不出字書，借訓顯義，從古無妨。引示中，初引《成論》證業隨心重。約制則蟻輕人重，篇聚定故；就業則蟻重人輕，心行別故。由下，推論所以。如下，次引《十誦》轉證懺業不亡。
【譯文】從「以」字往下的文段，是鈔記作者所作的總結指示。無慚無悔，這就是不善之心的體性，貫穿了造罪始終的兩重心態。這通通涵括了前面四種心相，每一種都是互相交涉關聯的。所謂「初無」，古籍記載說：「初」當作「都（完全）」字來講；雖然字書中沒有這種訓詁，但借用古訓來顯發義理，自古以來並無妨礙。在引經指示的文段中，首先引用《成論》來證明業報是隨著心念的加重而變重。若依據佛陀制教來論，殺蟻罪輕而殺人罪重，因為篇聚的科條是固定裁決的；但若就世間業道來論，如果心懷極重惡意，殺蟻的業報反而重，殺人若動機輕微業報反而輕，這是由於起心動念的用心各有不同。從「由」字往下的文段，推論探究其中的原由。從「如」字往下的文段，接著引用《十誦律》輾轉證明懺除了戒罪而業報依然不亡。

【515-0002】資持記/06b_中一上#37
【原文】調達，具云提婆達多，此翻天熱；是佛堂弟，阿難兄也。破僧犯蘭，制教罪也；逆業最重，故墮阿鼻一劫。故下，三引經轉證悔已墮獄。亦名《地獄報應經》。業定不定，但約三時具闕分異；三時具者，則為定業。定有二義，如文列之；不定亦二，反明可解。
【譯文】「調達」具足的梵音稱為提婆達多，這裡翻譯為「天熱」；他是佛陀的堂弟，阿難的親哥哥。分裂僧團違犯了偷蘭遮罪，這是制教上的戒罪；但他所造下的逆罪最為深重，所以直接墮入阿鼻地獄長達一大劫。從「故」字往下的第三部分，引經輾轉證明即便懺悔了戒罪仍須墮入地獄。這部經也稱為《地獄報應經》。業力究竟是定業還是不定業，純粹是依據在造業初、中、後三時心態的具足或欠缺來作劃分；三時惡心全部具足者，就構成定業。定業有兩種涵義，如同經文所列出的那樣；不定業也有兩種涵義，反過來理解即可明白。

【515-0003】資持記/06b_中一上#38
【原文】諸佛不能轉者，眾生業力，勝佛力故。下指卷末，即〈懺篇〉中。三無記多別。一無情局無記，有情通三性；二就情中，報色是無記，心則通三性；三就心中，三心局無記，行心通三性。下明二種，初縱放者，謂泛爾無記；次約睡狂，即昏迷無記。示心中，初文又二，前示心相。如下，次列犯事。
【譯文】所謂「諸佛也不能扭轉」，是因為眾生自身的業力，有時甚至強大過諸佛威神之力的緣故。下文指引讀者查閱卷末，也就是〈懺篇〉之中的內容。在第三「無記心」中包含許多差別。第一，無情物純粹屬於無記，有情眾生則通貫善、惡、無記三性；第二，就有情眾生而言，受生所得的色身果報是無記，心念則通貫三性；第三，就心念內部而言，受、想、識三心局限於無記，後續造作的行心則通貫三性。下文說明無記的兩種相狀：首先是「縱放無記」，是指泛爾漫不經心的無記；其次是「睡狂無記」，也就是昏迷神智不清的無記。在指示心相的段落中，第一部分又分為二，前半段指示心念相狀。從「如」字往下的文段，接著列舉違犯的事相。

【515-0004】資持記/06b_中一上#39
【原文】別舉諸戒，臨文自對。高談費時者，律制。行來俯仰，常爾一心，違皆犯吉故。方，大也。上明不學制犯。唯下，簡勤學開迷。次科。初句指前，列相未盡；即，猶止也。前方便者，或自作犯，如初睡時作漏失意；或教他犯，如殺盜等；或自業相成犯，如自安殺具等。若據果成，雖在無記；
【譯文】這裡個別列舉了諸多戒條，研讀本文時自可一一對照。所謂「高談闊論浪費時光」，是因為律宗規定。無論行進、往來、低頭、仰首，都必須隨時保持專注的一心，違背這項原則都會結成突吉羅罪。所謂「方」，就是重大的意思。上面說明由於不肯學習佛制而導致違犯。從「唯」字往下的文段，甄別唯有精勤學習者在陷入昏迷忘失時可以開緣免罪。進入下一科。第一句承指前文，指出列舉的心相尚未窮盡；「即」當作「僅僅（止）」講。所謂「前方便罪」，有的是自己造作而犯，例如在最初剛要入睡時動了漏失精液的意念；有的是教唆他人去犯，例如指使他人行殺行盜等；或者是由自身過去的造作相續成就其犯行，例如自己預先安置殺害生命的器具等。如果依據最終惡果成就的當下而言，行為人雖然正處於無記昏昧的狀態；

【515-0005】資持記/06b_中一上#40
【原文】由假方便，故云通前等。如論，即下《成實》。初問中。徵上指論。答中，初句通示。初下，別釋，先約方便釋。即上睡狂無記也。初明因前故感報。而下，明正成則非報。二約總別兩報釋。此義通前兩種無記。總報，謂地獄總受；別報，謂餘趣別受。如下，引證有三；前二證上縱放，後一證上睡狂。
【譯文】但由於藉助了先前的方便惡心，所以說「通貫前面所說的心態」等等。所謂「如論所說」，就是指下文的《成實論》。在第一個提問中，針對上文所指引的論文提出質問。在回答中，第一句先作通泛指示。從「初」字往下的文段分別解釋，首先依據方便罪來解釋。這就是指上面提到的在睡夢癲狂等無記狀態中造罪。前半段說明由於先前有方便惡意，所以依然會感召果報。從「而」字往下的文段，說明如果罪業成就的當下全無惡心，則不感召業道果報。第二是依據總報與別報這兩種果報來解釋。這種義理通貫於前面所說的兩種無記心。所謂「總報」，是指在地獄中整體承受苦難的報應；所謂「別報」，是指在其他惡趣中個別承受的苦報。從「如」字往下的文段，引證包含三項；前兩項證明上面的縱放無記，後一項證明上面的睡狂無記。

【515-0006】資持記/06b_中一上#41
【原文】如經者，未詳何經。〔有指《十二頭陀經》，彼文不出。〕不覺是無記心。《五百問》。彼說昔有一執事比丘，手挃物器，墮餓鬼中；有羅漢，於廁聞呻吟聲，問之，答云：曾於此寺，為僧執事；手挃淨器，使不淨食與僧；墮餓鬼中，為蟲噉身，不得糞食，故此呻吟；羅漢為悔，方得噉糞等。誤觸，即無記心。《成論》。
【譯文】所謂「如經所說」，目前尚未查清是哪一部經。〔有人指出是《十二頭陀經》，但該經中並沒有這段文句。〕不知不覺就是指處於無記心。引用《五百問》說：彼處記載過去有一位執事比丘，用手亂撞僧團的器物，後來墮落到餓鬼道之中；有一位羅漢，在廁所聽到了痛苦呻吟的聲音，上前詢問，餓鬼回答說：我曾在此寺院中擔任僧團的執事；因為用手猛撞淨器，使得不乾淨的飲食供給了僧眾；因此墮入餓鬼道中，身體被無數蟲子啃食，連糞便都吃不到，所以在此痛苦呻吟；羅漢為他代作悔過，他才得以吃到糞便等等。所謂「誤觸」，就是無記心的一種表現。接著引用《成論》。

【515-0007】資持記/06b_中一上#42
【原文】睡眠業者，如夢漏失，五吉之類。教人自業，如上所明。次問中。徵前開忘。答中，初二句指前標後。謂下，正答，初敘學人。偶下，示迷忘。如下，略列戒相。反上，謂非學人，翻對可解。結歎中，初二句，示生死長久。業苦，通舉因果；綿，謂出沒久遠；積，謂造受眾多。生報，別示苦果；
【譯文】在睡眠中所造的業，例如夢中遺精而違犯五種突吉羅這類的過失。教唆他人或由自身造作相續成罪的情形，正如上面所闡明的那樣。在下一個問題中，針對前面「精勤學習者忘失可獲開緣」的說法提出疑問。在回答中，前兩句承指前文並標示後文。從「謂」字往下的文段是正式回答，首先敘述精勤向學之人的心態。從「偶」字往下的文段，說明偶然迷亂忘失的情形。從「如」字往下的文段，簡略列舉所涉及的戒相。所謂「反之」，是指非勤學之人，將其行徑反過來對照即可理解。在結語感歎的文段中，前兩句指示生死輪迴的漫長久遠。所謂「業苦」，通泛列舉了造因與受果；「綿」是指在六道中流浪沉浮歷時極其久遠；「積」是指造業受苦的數量極為眾多。所謂「生報」，是特別指示來生所受的苦果；

【原文】窮，盡也。虛下，嗟毀犯陷墜。隨妄興業，故云虛縱。無三善者，多惡因也。加三惡者，無善果也。附，憑也。加，增也。以下，正歎。經生，猶度世也。息即是氣。第二引證，正明中，初《目連問經》〔亦名《犯戒報應輕重經》〕。初標犯人。
