# 校閱材料　第1247檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1247-0001】資持記/12a_中四下#14
【原文】又凡造罪，具足三時，俱起猛心為重；或二時一時為輕。定不定者，復簡重業；定業極重，縱懺不亡；不定猶輕，或容轉易。下二句彰益。轉報謂易奪不受，對上輕及不定業也。輕受謂轉重為輕，即上重中定業也。並下，指廣。《佛名經》文，見第十；
【譯文】再者凡是造罪，具足事前、正作、事後三時，而且全都生起猛烈惡心的屬於重罪；或者僅有一時、二時的則屬於輕罪。說「定與不定」，是再度簡別重業；極重的定業，縱然懺悔也無法完全消除；不定業仍屬較輕，還有可能轉變改易。後兩句彰顯其利益。「轉報」是指扭轉拔除而不用受報，對應上述的輕業與不定業。「輕受」是指將原本的重報轉為輕微領受，即對應上述重業中的定業。「並下」指引廣泛典籍。《佛名經》的經文，見於第十卷；

【1247-0002】資持記/12a_中四下#15
【原文】《方等陀羅尼經．三卷》，《虛空藏經》、《占察經》等，並明悔法。若準《業疏》，須具五緣：一請佛菩薩為證〔即奉請眾聖也〕，二誦經呪〔即誦經諷呪〕，三說己罪名〔即說懺悔〕，四立誓言〔即今發願〕，五如教明證〔即今求相簡擇邪正〕。重廣中，初示所修觀相。無性即空理。以下，明罪滅所以。
【譯文】《方等陀羅尼經》三卷、《虛空藏經》、《占察經》等，全都闡明了悔罪之法。若依據《業疏》所說，必須具備五種因緣：一是恭請佛菩薩作為證明（即奉請諸位聖者），二是誦念經典與神咒（即誦經諷咒），三是自說己罪之名稱（即如實陳白懺悔），四是立下誓願（即如今之發願），五是如教法明示獲致瑞相驗證（即如今求取瑞相以簡別邪正）。在重新廣泛發揮中，首先開示所修觀行的境相。無性，就是諸法本空的實理。「以」字以下，闡明罪業得以消除的原由。

【1247-0003】資持記/12a_中四下#16
【原文】諸世間業，皆從我生，我為業主；我既無託，故所造善惡，不從我倒而生；妄業無依，故得除滅。見謂達理，思謂起修，除謂能觀智，滅即所觀業。破妄顯真，而非頓證，故皆云分。若約位判，分見分思，即內凡人；分除分滅，即初果已去。如下，喻顯。眠醉喻迷，醒覺喻悟；
【譯文】世間一切善惡業，都是從自我執著而生起，「我執」即是造業的主宰；既然「我」已無處寄託寄附，那麼所造的善惡之業，便不會從我見的顛倒中滋長；虛妄罪業失去了依託，所以能夠得以斷除消滅。「見」是指通達實理，「思」是指發起修持，「除」是指能觀的智慧，「滅」就是所觀的罪業。破除虛妄而顯發真實，並非一蹴即成，所以都稱為「分」（部分逐步）。若依修行果位來判定，分見、分思，即是內凡位的修行人；分除、分滅，則是證得初果以上的聖者。如同下文，以比喻來顯明。昏睡與沉醉比喻沉淪迷妄，睡醒與酒醒比喻開悟覺知；

【1247-0004】資持記/12a_中四下#17
【原文】眠覺醉醒，相似法故。次列三觀，標中。理本是一，何有三者？若權實往分，前二是權，後一是實；若大小相對，前一是小，後二屬大。若約開權會小，終歸一理；若對三宗，性空局小，唯識局大，相空通小大，如是分之。性空中分三，初示所觀境，即諸法二字。諸法之言，總包一切；
【譯文】睡眠與沉醉、睡醒與酒醒，在情狀上都是各自相似的法相。接著列出三種觀法，在標題中。實相之理本來唯一，為何會有三種觀法？若從權教與實教來區分，前二種是權教，最後一種是實教；若從小乘與大乘相對而言，第一種屬於小乘，後兩種屬於大乘。若就開權顯實、會通小乘歸於一實而言，終究回歸於同一實相之理；若對應於三宗，性空觀局限於小乘宗，唯識觀局限於大乘宗，相空觀則通於小乘與大乘，應當如此區分。在性空觀中分為三部分，首先開示所觀之境，即「諸法」這兩個字。諸法這個詞，總括包羅一切事物；

【1247-0005】資持記/12a_中四下#18
【原文】諸經論中，或約依正因果，或世出世間，或有漏無漏，或色心非色心，或善惡無記，或陰界入等。若據通論，總觀諸法；今就懺悔，且指罪業而為觀境。性空無我一句，即能觀智。罪從緣有，本無自性；緣即心境，虛妄心境和合成業，業性自空，非使之空。由存妄計，故受輪轉；
【譯文】在諸多經論之中，或者就依報正報與善惡因果而言，或者就世間出世間、有漏無漏、色法心法非色心法、善惡無記，或者五陰十八界十二入等來論述。若是通泛論述，則是總觀一切諸法；如今就懺悔法而言，且專指罪業來作為所觀之境。「性空無我」這一句，就是能觀的智慧。罪業是依憑因緣而生起，本來就沒有自性；所謂因緣就是內心與外境，虛妄的心與境和合而形成罪業，罪業的本性自身本空，並非修行者刻意使它變成空。由於存有虛妄的計執，所以才遭受生死輪迴；

【1247-0006】資持記/12a_中四下#19
【原文】但破妄計，覓罪叵得；叵得之處，強名空理。言性空者，小機智劣，不能即法見空；必待推析窮法體性，然後方空；其中須分利鈍，利者體法即空；鈍者析法見空；或云：有宗唯證人空，假宗人法二空。此下判位。小乘通收聲聞緣覺；據所乘法，諦緣雖殊；若論斷證，同見空理。
【譯文】只要破除了虛妄執著，尋求罪業的自性了不可得；這了不可得的實相，勉強稱它為空理。稱為「性空」的緣由，是小乘根機智慧低劣，不能當下就萬法徹見其體性本空；必須等待推求析破以窮究諸法的實體，然後才能見到空性；在小乘根機中又必須區分利根與鈍根，利根者體達當下萬法即是空；鈍根者必須逐步分析萬法才見到空；又或者說：阿毗達磨有宗只證悟人我空，成實假宗則兼證人我、法我二空。「此下」判定果位。小乘法總括收攝聲聞與緣覺；若據其所依乘的法門而言，四諦與十二因緣雖有不同；但若論及斷惑證真，則同樣親見此一空理。

【1247-0007】資持記/12a_中四下#20
【原文】相空中亦三，示境同前。能觀中。言相空者，了法無相，猶如幻化，昧者謂真；亦如空華，眼病謂實；故云唯情妄見。判位中。小菩薩者，雖發大心，未窮心本；故設此觀，空諸塵境；如諸般若所被初心。言照用者，二乘住寂，故但照心；菩薩涉事，故云照用。若對三宗，即當四分；
【譯文】在相空觀中也分為三部分，所開示的境界與前述相同。在能觀智中。稱為「相空」的意思，是了達諸法了無實相，宛如幻術化現，迷昧之人誤以為真；又如同空中亂花，眼睛有病之人誤以為實有；所以說是「唯有情執妄見」。在判定果位中。所謂「小菩薩」，是指雖然發起了大菩提心，但尚未窮究心識的根本；所以施設這種觀法，來空掉一切塵世外境；如同各大部《般若經》所教化接引的初發心者。說「照用」的意思，是二乘行者安住於沉寂，所以只觀照自心；菩薩必須涉入世事歷練，所以稱為照用。若對應於三宗，即相當於《四分律》的宗義；

【1247-0008】資持記/12a_中四下#21
【原文】同觀空理，故云小也；志慕佛乘，故云菩薩；相召佛子，即為明例。唯識中三科同上，觀境可解。能觀中。外塵謂一切境界也。言本無者有二義：一者境即心故，《占察經》云：一切境界，從本已來體性自滅，未曾有故；因如此義，是故但說一切諸法依心為本；當知一切諸法，悉名為心；
【譯文】因為同樣觀空理，所以稱為「小」；因為志願仰慕佛乘，所以稱為「菩薩」；彼此以「佛子」相稱，就是明顯的例子。唯識觀中的三科與上面相同，所觀之境可以理解。在「能觀」這一段中：外塵指的是一切境界。說「本無」有兩層意義：一是因為境界就是心，所以《占察經》說：一切境界從無始以來，體性本來就自體空滅，從來不曾真實存在；由於這個道理，所以只說一切諸法以心為根本；應當知道一切諸法，都名為心；

【1247-0009】資持記/12a_中四下#22
【原文】以體不異，為心所攝故。二者虛妄見故，經云：但以眾生無明癡暗熏習因緣，現妄境界，令生念著；又云：若無覺知能分別者，則無十方三世一切境界差別之相；《唯識論》云：唯識無境界，以無塵妄見；如人目有翳，見毛如月等事。
【譯文】因為體性沒有差異，都為心所攝屬。二是因為只是虛妄的見解，經上說：只由於眾生無明愚癡黑暗熏習的因緣，才現出虛妄的境界，使人產生念著；又說：如果沒有覺知能分別的作用，就沒有十方三世一切境界的差別相。《唯識論》說：唯識無境界，因為沒有外塵，只是虛妄的見解；就像人眼睛有翳病，會看見毛髮、第二月等事物。
