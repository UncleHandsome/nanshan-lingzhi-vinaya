# 校閱材料　第967檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【967-0001】資持記/03a_上二#21
【原文】眾起即羯磨僧事。四位僧中，略舉初後，中二大同。善下，示量。以二十人僧通行一切眾法，更兼所為，故容二十一人。減則不周，故所不許。此據一眾為言，必兼二眾，須容四十一人。問：二界立量同異云何？答：大界制廣，狹則不拘。場界制狹，廣則無在。所以然者？
【譯文】「眾起」是指進行羯磨等僧團集會之事。在四種位階的僧團中，此處略舉最初與最後的位階，中間二者大致相同。「善」字以下，指示戒場尺度。因為二十位比丘的僧團便能全面推行一切僧事羯磨，再加上所要處置或受戒的一人，所以必須能夠容納二十一人。若是縮減便無法周全容納，因此戒律不予允許。這是就單一比丘僧眾而言；如果必須比丘、比丘尼二部僧共同集會，就必須能夠容納四十一人。有人問：大界與戒場界在訂立尺度上的同異如何？回答：大界限制其最大範圍，至於狹小則不加拘束；戒場界限制其最小範圍，至於寬廣則無妨礙。為什麼會這樣呢？

【967-0002】資持記/03a_上二#22
【原文】大界更廣，不免奔馳之勞。場界更狹，行法有所不足。故《壇經》中烏仗那壇縱廣二百餘步，疏云：律中壇上相覓不見，故可知矣。三小界，初科，先敘本緣。難事者，心不同也。恐廢者，示權意也。並下，定量。列示中三，初受戒中，前出古解。結戒場法，亦名小界，故得準之。
【譯文】大界如果再擴大，眾人免不了奔波勞頓的辛苦；戒場界如果再狹小，施行羯磨法則在空間上有所不足。所以《戒壇圖經》記載烏仗那國的戒壇縱橫廣達二百多步，《業疏》說：律中提到在壇場上互相尋找卻看不見人，由此即可明白其廣大。三種小界中，第一科先敘述最初的因緣。所謂「難事」，是指眾人心意不合或遭遇災難。所謂「唯恐廢止」，是展示權巧開許的用意。「並」字以下，敲定尺度限量。在列出示範的三種小界中，首先在受戒小界中，前面先列出古代的解釋。結戒場的方法也稱為小界，所以可以依此推準。

【967-0003】資持記/03a_上二#23
【原文】彼計問難安立，並須界內；獨此一種，須立外相。今下，直示正義，指斥如後。文義並見次科。下列說、恣。直坐圓坐，此亦循古一往分之，義必無在。釋無外中，初句牒前。由下，正釋，初示義。故下，引文。即說戒小界羯磨緣也。若下，復約制解，以彰不立。疏云：不應不解而去。顯無外相，起必迷方。
【譯文】古人認為訊問遮難與安立受戒者，都必須在界限之內；唯獨這一種小界，必須設立外在標相。「今」字以下，直接宣示正義，並在後文指責糾正其錯誤，文字與義理都見於下一科。接著列出誦戒與自恣小界。眾人直排而坐或圍繞圓坐，這也是依循古法暫且劃分而已，在義理上並無絕對必然之處。在解釋「沒有外相」中，第一句承接前文。「由」字以下進行正面解釋，首先闡明義理。「故」字以下引用律文，指的就是說戒小界羯磨的發起因緣。「若」字以下，又依據制約與解除的法理來解釋，以彰顯小界不需設立外相。《業疏》說：比丘不應當不經解界就擅自離去；這顯示小界若無外在界相，人一起身離席必定會迷失方向界限。

【967-0004】資持記/03a_上二#24
【原文】不下，顯前須立。依位解者，即三法界。大界，標中。先結場者，此言合在有場法中；當時有執昔見，故預點之。出緣成中。料簡一科，義是稱量。第二即陳本意；若約唱相，合須在後；今望竪標，故當次列。第三即攝能秉五緣，義兼託界。是則三科總含八緣。問答二種，見正加中。初問。
【譯文】「不」字以下，彰顯前面大界等確實必須設立標相。所謂依不同位次分別解說的，就是指三種作法界。在「大界」的標題中，提到先結戒場的話，這句話本該放在「有戒場的大界」法門中；但因為當時有人固執過去的成見，所以預先點明糾正。在列出「成界緣由」中，評鑑揀選這一科，在義理上是衡量考察。第二科即陳述本來意圖；若是就唱告界相而言，本來應該列在後面；如今為了對應樹立標相的順序，所以當作次一項排列。第三科即涵蓋能主持羯磨的五種因緣，義理兼及所依托的界地。因此這三科總共包含八種因緣。問答有兩種，見於正式加持作法之中。第一問：

【967-0005】資持記/03a_上二#25
【原文】村者，即是俗舍，西竺僧坊多有俗住；此土或容暫止，或復界寬恐疑故問。答中，初引《五分》。既請布薩，必先結界；此文乃是全在俗舍，類顯僧界有村不妨。次引《婆論》。明文通結。聚落即村，名通大小；今取男女所居，下至一家，即名聚落。後引《四分》。即攝衣文。
【譯文】「村」是指世俗人家的房舍，西印度僧房寺院周邊多有俗人居住；此地中國有時也容許俗人暫時居住，或者因為大界劃得太寬而令人心生疑慮，所以才提出疑問。回答中，首先引用《五分律》。居士既然迎請僧眾布薩誦戒，就必定要先結界；這段律文是全在俗人家中結界，以此類推顯示僧界中包含村落並無妨礙。其次引用《薩婆多論》，經文明文開許通融結界。「聚落」就是村落，名稱通於大小聚居地；如今只要取有男女居住之處，少至一戶人家，就可以稱為聚落。最後引用《四分律》，即攝衣界的文句。

【967-0006】資持記/03a_上二#26
【原文】疏云：《四分》明文，除村村外，明知攝僧不簡村也。〔有引法食二同文者，非。彼明界相耳。〕村取者，昇本作取村；或云寫誤，合作聚字。次問中。律雖明約，理非全閉，故此決之。答中，引律者。彼因比丘隔河結界，十五日欲往說戒，而不能度，故佛制之。除船橋者，此明開也。
【譯文】《業疏》中說：《四分律》的明文唯獨除外村落及村落之外，由此明知攝僧界並未排除村落。〔有人引用「法食二同」的文字，是不對的，那裡只是在說明界相罷了。〕「村取」二字，在昇公本中作「取村」；也有人說是抄寫錯誤，應當是「聚」字。在第二個疑問中，律文雖然明令限制，但在法理上並非全盤禁絕，所以在此予以裁決。回答中引用律文：那是因為當時有比丘隔著河流結界，十五日想要前往說戒卻無法渡河，所以佛陀才加以制止。言『除非有船隻與橋梁（則得結）』者，這是說明開許的規定。

【967-0007】資持記/03a_上二#27
【原文】橋梁事一，物有大小。若駛流者，此明制也。駛，疾也。必下，準理決通。語略船字。雖是疾流，但令可度，不障來集，故判理得。下引尼律，轉證無橋得結不疑。即僧殘中獨度河戒。彼云但使褰衣度水，乃至界內亦犯，故云通也。三問。恐二界相接，又欲顯示標量故也。
【譯文】橋梁的性質一致，物件則有大小之分。如果是湍急的水流，這是說明禁止的條件。「駛」就是迅疾。在「必」字以下，依照法理來裁斷通融。文中文字簡略省略了「船」字。縱然是湍急奔流，只要能夠順利渡過，不阻礙僧眾前來集會，所以在法理上判定可以結界。下面引用比丘尼律，進一步佐證沒有橋梁也能結界而無可懷疑。這出自僧殘罪中比丘尼獨自渡河的戒條。彼處說只要提起衣角渡水，乃至在界內渡過也算犯戒，所以說是通用的。第三問：是唯恐兩個大界彼此相銜接，又想要明確顯示標相的尺度緣故。

【967-0008】資持記/03a_上二#28
【原文】答中，初從古定量。次準論示通，初明大者。山即一標，東西共用，即為兩相。又下，明小。二繩者，如兩寺相隣；一欲結界，而隣僧作難，故開此法；先於本處隨地安相，以繩圍繞，引繩遠去，但使彼僧在自然外〔不必蘭若，非同三小。〕；至彼先安相已，復以繩圍；
【譯文】回答中，起初順從古人的說法敲定尺度。其次依照論典來指示通融之道，首先說明範圍寬廣的情況。一座山作為一個標記，東邊與西邊共同使用，就成為兩重界相。在「又」字以下，說明使用小標的情況。「二繩」的意思是，好比兩座寺院相鄰；其中一座想要結界，而鄰寺的僧眾故意留難，所以開許這種方法：先在自己本地隨處安立標相，用繩子圍繞，再拉長繩子引向遠處，只要能使鄰寺的僧眾處在自然界之外即可〔不必非要在蘭若處，不同於三種小界。〕；到達遠處先安好標相之後，再次用繩子圍繞；
