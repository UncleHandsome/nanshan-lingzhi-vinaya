# 校閱材料　第256檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【256-0001】02_戒疏/08d_卷二下之一#132
【原文】【疏】問：「此律重犯，隨作不輕，何故《僧祇》『學悔人犯，止但吉羅，亦應驅出』者？」
【譯文】【疏文】提問：「本律對於重複犯戒，隨每次造作都判重罪而不減輕，為什麼《僧祇律》說『正在行學悔法的人如果犯戒，只判突吉羅罪，但也應當驅逐出僧團』呢？」

【256-0002】02_戒疏/08d_卷二下之一#133
【原文】【疏】答：「義同文異也。《律》中犯重，有行悔者，猶在僧中，說戒、自恣異於沙彌，故同夷罪。如打犯重，還結波逸提。《僧祇》輕者，就不足為言。故《十誦》云：『與學悔沙彌尼安居中犯僧殘，聽比丘受日與摩那埵。若學悔沙彌，行婬、盜、殺、妄，還得波羅夷。』」
【譯文】【疏文】回答：「義理相同而文句不同。《四分律》中觸犯重罪的人，如果有在進行悔過修行的，依然留在僧團之中，其說戒、自恣都與沙彌不同，所以等同判波羅夷罪。如同毆打犯重罪而行悔的比丘，仍然要結波逸提罪。《僧祇律》判為輕罪，是就其不能算作合格僧數而言。所以《十誦律》說：『曾犯重罪而領受學悔法的沙彌尼，若在夏安居中又犯了僧殘罪，聽許大僧比丘受日出界前往為其授予摩那埵悔罪法。如果行學悔法的沙彌，造作行淫、偷盜、殺人、大妄語，依然得波羅夷罪。』」

【256-0003】02_戒疏/08d_卷二下之一#134
【原文】【記】問異部中。《四分》、《僧祇》，重不重別，計非相比。欲顯二宗之意，故此問之。答中。初句通示。學悔預眾，而不足數，彼此皆爾，故曰「義同」。重犯結罪，夷吉重輕，故云「文異」。「律」下，別釋。初明本部重結，別下眾故，引例可知。次釋《僧祇》犯輕，簡堪足故。下引《十誦》示之。先明「不重」唯約初篇，僧殘已下，例有重犯。「若」下，次顯初篇亦有重義。謂同名之罪有重犯，如前婬後殺等；同種之罪不重犯，如前盜後復盜等。
【譯文】【記文】詢問不同部派的文段中。《四分律》與《僧祇律》對於是否重判的差別，本來就不能一概而論。為了顯示這兩個部派的深意，所以在此提出詢問。回答之中。第一句通盤說明。行學悔法的人參與大眾，卻不能計入僧數，兩部律都是如此，所以說「義理相同」。重複犯戒的結罪，有波羅夷重罪與突吉羅輕罪的差別，所以說「文句不同」。從「律」字以下分別解釋。首先說明本部律重複結重罪，是為了與下眾（沙彌等未受具者）有所區別，引用事例可以明瞭。接著解釋《僧祇律》判罪較輕，是因為簡別其不具備僧數資格。下面引用《十誦律》來顯示。先說明「不重複結罪」只局限於初篇，僧殘罪以下，照例都有重複結罪。從「若」字以下，接著顯示初篇也有重複結罪的含義。也就是指同名但不同事的罪會重複結罪，如前面行淫、後面殺人等；若是同一種類的罪則不重複結罪，如前面偷盜、後面又偷盜等。

【256-0009】02_戒疏/08d_卷二下之一#140

【256-0020】02_戒疏/09a_卷二下之二#11
【原文】【記】釋僧殘篇，初總列。八段束之為四：初即是惑，二、三約業，四、五、六據教，七、八就人。從「二」已下，一一皆有結前生起。「遮、性」二位，或約情非情，或就事輕重，並從境分，故云「由境」也。八篇戒相，遮性統收，故云「相攝」也。「為存道本」者，下篇諸戒，為防四重，四重即是入道之基故。「持犯」總收四行，四行統一切行，故指持犯以為「行基」。
【譯文】【記文】解釋僧殘篇，起初是總體列出。八個段落可歸納為四個層次：第一項探討的是煩惱惑業；第二、三項是就造作的身口業來談；第四、五、六項是依據戒法教導來立論；第七、八項則是針對受戒的人身來分析。從第二項開始，每一項都承接前項而引發後項。遮戒與性戒兩類，或針對有情眾生與無情器物，或就事情的輕重程度，都是從所對境界來劃分，所以說是「由境而興」。八篇中的一切戒相，都被遮戒與性戒完全總攬，所以說是「互相統攝」。「為了保全修道的根本」，是指後續各篇的眾多戒條，都是用來防範根本四重戒的違犯，因為四重戒就是入道的基石。持戒與犯戒總括了止持、作持、止犯、作犯四種行持，這四行統轄了一切戒行，所以指稱持犯為「行持的基石」。

【256-0022】02_戒疏/09a_卷二下之二#13
【原文】【疏】就此十三：初有七戒，因雖三毒，成必貪心；次二謗戒，因亦三毒，成在瞋嫉；二破兩戒，亦因三事，癡慢心成；後有二戒，因瞋癡起，成亦同之。
【譯文】【疏文】就本篇十三條戒而言：前七條戒，引發的起因雖通於三毒，但成就罪相時必定在於貪欲心；接著的兩條毀謗戒，起因也通於三毒，但成就罪相在於瞋恨與嫉妒；兩條破僧戒，同樣起因於三毒，是由愚癡與驕慢心所促成；最後兩條戒，因瞋恚與愚癡而生起，成就罪相時的心態也同樣是瞋癡。

【256-0023】02_戒疏/09a_卷二下之二#14
【原文】【記】配毒中。「因」即始起，「成」謂究竟，始終二心，同異不等，故須兩列。然起不可定，今但取成。「初七貪成」者，漏失等五從內色起，二房由外事生。「二謗瞋嫉成」者，如《律》緣起，瞋恨沓婆，嫉他好請，嫉對違境，亦屬瞋中。「二破癡慢」者，「癡」謂立邪破正，「慢」則稱佛自尊，慢攝於癡。「後二瞋癡起成同」者，「瞋」謂遭擯被諫，「癡」謂謗僧抵拒。
【譯文】【記文】配對三毒的討論中。「因」是指最初發起的心念，「成」是指造業究竟的心態。前後兩種心念，其性狀往往不一致，所以必須分別列出。然而發起的心念難以固定，如今只截取成就罪相的那一刻來判定。「前七條戒由貪欲所成」，是因為漏失等前五戒是從貪愛自身內色而生，兩條造房戒則是從貪著外在事物而起。「兩條毀謗戒是由瞋嫉所成」，如同《律藏》中的緣起，是因為瞋恨沓婆尊者、嫉妒他受到信眾優厚供養，嫉妒所面對的是違逆己意之境，所以也歸屬於瞋毒之中。「兩條破僧戒由癡慢所成」，「癡」是指建立邪見破壞正法，「慢」是指自封為佛、自尊自大，傲慢本來就為愚癡所含攝。「後兩條戒由瞋癡生起且成就相同」，「瞋」是指遭受擯斥與被僧團規諫時心生惱怒，「癡」是指毀謗僧團並強硬抵拒。

【256-0026】02_戒疏/09a_卷二下之二#17

【256-0027】02_戒疏/09a_卷二下之二#18

【256-0028】02_戒疏/09a_卷二下之二#19
【原文】【疏】第二，明身口相者。
【譯文】【疏文】第二，說明身業與口業的造作面貌。

【256-0029】02_戒疏/09a_卷二下之二#20
【原文】【疏】漏失、摩觸，唯身心犯。二房據本，由身成犯，亦有教人口業犯義。自餘九戒，口業成犯，亦有身業助成之義。如後四諫，縱設不言，隨滿便結，何待口也？意通前業，不可別配。
【譯文】【疏文】漏失精液、摩觸女身這兩戒，純粹是身業伴隨動心而造犯。兩條造房戒依據其根本性質，是由身體實際營造而構成違犯，但也有教唆他人去作而以口業構成犯戒的義理。其餘九條戒，主要是以口業構成違犯，但也有依託身業協助促成的義理。例如最後四條規諫戒，縱使違犯者不發一言，只要僧團白四羯磨完畢便結成重罪，何需等待口頭言語？動心意業貫通於前述的兩種業行，不能單獨拿來單一配對。

【256-0030】02_戒疏/09a_卷二下之二#21
【原文】【記】三業中，初配。漏、觸但是身業，而云「心」者，以通從別，相帶而言。次二房，「亦有口業犯」者，如下「教遣」是也。後「九」下，明互造。且舉諫戒不必假言，而二麤、媒嫁、二謗，如後《戒本》，並通作相故。「意」下，若單意業，未必有身口，若身口業，其必兼意業，故云「通前」也。
【譯文】【記文】在三業的分門中，首先進行配對。漏失、摩觸本來只是身業，卻提到「動心」者，是以通貫全局的意業順帶附隨於別特的身業，相攜連帶來敘述。接著談到兩條造房戒，「也有口業犯戒」的情形，如同下文所說「教唆派遣他人」便是。在「其餘九條」之下，說明身口互相協助造作。姑且以四條規諫戒為例，其違犯未必需要假藉言語，而二種粗語、媒嫁、二種毀謗，如同後文《戒本》所說，都通於身口協同作相。「動心意業」以下說明：如果只是單純的意業，未必會引發出身業與口業；但如果是身業或口業，其背後必定兼帶有意業，所以說「貫通於前述的身口業」。

【256-0031】02_戒疏/09a_卷二下之二#22
【原文】【疏】故《僧祇》云：「有罪非身口，從心生。即應問言：『何心取物、殺人、觸女、斷草、掘地？』是名取心不取事也。有罪取事不取心者，不應問他：『汝以何心婬、飲酒、與未受人宿過限？』隨有犯者，當如法治。」
【譯文】【疏文】所以《僧祇律》說：「有的罪過並非單看身口表面動作，而是從內心動念而生。這時就應當審問他：『你是抱持何種心思拿取物品、殺害人命、摩觸女人、斬斷草木、挖掘土地？』這稱為查驗內心而不單取外在事實。有的罪過則是取決於外在事實而不論內心動念，不應當去問對方：『你是以何種心思去行淫、飲酒、與未受大戒者共宿超過時限？』只要實際出現違犯行為，就應當依法裁處懲治。」

【256-0036】02_戒疏/09a_卷二下之二#27
【原文】【疏】若二麤，能所互有染，隨染而結重。
【譯文】【疏文】若是二種粗語戒，教唆者與受教者之間若互有一方具染污心，便隨具染污心者結成重罪。

【256-0037】02_戒疏/09a_卷二下之二#28
【原文】【記】別釋中，二麤。能所互染者重，不染者蘭。《義鈔》云：「能所互有染心，能所互輕重；能所俱有染心，能所同犯。」明有教人成重之義。
【譯文】【記文】個別解釋中，探討二種粗語。教唆者與受教者之間只要有人具足染污心，有染心的人即結犯重罪；不具染污心則犯偷蘭遮罪。《義鈔》說：「教唆者與受教者若僅一方具染污心，則兩人結罪互有輕重（有染者重、無染者輕）；教唆者與受教者若皆具足染污心，兩者同犯重罪。」這說明了教唆他人也有構成重罪的義理。
