# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【146-0001】02_戒疏/07a_卷二上之三#5
【原文】【疏】二、十方常住物。如飯餅等，見熟之食。本擬十方聞聲同飯。有盜此食，望護結重，望僧結輕，以僧分業，無滿五故。
【譯文】【疏文】第二種是「十方常住物」。例如米飯、麵餅等已經煮熟的食物。本來就是準備給十方僧人聽聞打鐘聲就一同前來食用的。如果有人盜取這些食物，對保管看守者結重罪，對僧團全體則結輕罪，因為若分算到每一位僧人的應得份額上，是達不到五錢之數的。

【146-0002】02_戒疏/07a_卷二上之三#6
【原文】【記】二中。初列物體。「本」下，示別名。通名同上，故不重出。「有」下，明犯相有二。「望主重」者，謂餘人盜。「望僧輕」者，即犯偷蘭，或主客同盜，或主自盜。
【譯文】【記文】這第二部分中。首先列出物品本體。從「本」字以下，說明其特定的名稱。其通名與前面相同，所以不再重複說明。從「有」字以下，說明犯相有兩種。「對管物主結重罪」，是指外人來盜竊的情況。「對全體僧結輕罪」，就是結偷蘭遮罪，這包括主客共同盜取，或是管物者自己盜取的情況。

【譯文】【記文】有人問：「這兩種常住物都通於十方僧，為什麼前一種不對全體僧結罪，後一種卻要對全體僧結罪呢？」

【譯文】【記文】只要仔細推敲上下文意，自然就能通達明白。

【146-0005】02_戒疏/07a_卷二上之三#9
【原文】【疏】問：「聲鐘告集，是僧皆飯。未知他寺奴、畜得否？」
【譯文】【疏文】有人問：「寺院敲鐘集合，只要是僧人都得享用食物。不知其他寺院的奴僕和牲畜，是否也能一同食用？」

【146-0006】02_戒疏/07a_卷二上之三#10
【原文】【疏】答：「不合也。僧具六和，隨處皆是。人、畜別屬，義非通使，使既是局，食亦如之。」
【譯文】【疏文】回答說：「這是不合戒規的。僧人具備六和敬，無論到了哪裡都是僧團的一員。奴僕與牲畜各自有所屬，在道理上不能通融使喚；既然他們的使役僅限於本處，享用飲食自然也應當如此限定。」

【146-0007】02_戒疏/07a_卷二上之三#11
【原文】【記】問中，意謂他寺奴畜，彼此通僧，應得食故。答中。初句判定。「僧」下，釋所以。初示僧通之義。「人」下，明「奴畜」不通。《鈔》云：「行至外寺，私有人畜，用僧物犯重。以施主擬供當處僧，不供別類，非福田故。僧家人畜，犯吉。」
【譯文】【記文】提問的意思，是認為其他寺院的奴僕牲畜，在彼此的僧團中都是共通的，理應可以食用。回答中，第一句先作判定。從「僧」字以下，解釋其中的緣由。首先說明僧人通融享用的道理。從「人」字以下，說明奴僕與牲畜不能通融享用。《行事鈔》說：「行走到外面的寺院，私自帶有奴僕牲畜，若使用該寺僧物則犯重罪。因為施主本是打算供養當地的僧眾，並不供養其他類別的人畜，因為他們不是福田。若是該寺僧團常住所有的奴僕牲畜食用，則犯突吉羅罪。」

【146-0008】02_戒疏/07a_卷二上之三#12
【原文】【疏】三、現前現前物。如今諸俗，以供養僧，無問衣、藥、房、具，並同現前僧也。如《中含》，施招提僧房，所謂「別房施」是也。又如《經》中「僧鬘物」者，此梵本音。據唐言之，「對面物」也，即是現前對面之施耳。《鈔》引昔解謂「花果」者，隨字顯相，乖其事義也。
【譯文】【疏文】第三種是「現前現前物」。例如現在各位俗人前來供養僧團，不論是衣服、醫藥、房舍還是器具，全都是供養當下現前的僧眾。如同《中阿含經》中，將招提僧房布施，也就是所謂的「別房施」。又如經典中所說的「僧鬘物」，這是梵語的發音。依照唐朝漢語來說，就是「對面物」，也就是當面現前所作的布施。《行事鈔》引用過去的解釋說是「花果」，那是只隨字面望文生義，違背了該詞原本的事理與意義。

【146-0009】02_戒疏/07a_卷二上之三#13
【原文】【記】三中。初示名體。「如」下，引證，《中阿含經》：「阿難受別房，用施招提僧。」、「所謂別房施」即翻名也，謂以「別房」施「現前僧」。「又如經」者即《涅槃》文。初翻名顯相。「《鈔》」下，點示昔非。謂《事鈔》中誤用昔解。彼云「房宇是招提物，華果是僧鬘物」，即取「華果結鬘」之義，故云「隨字顯相」。華梵不辨，即是「乖事義」也。
【譯文】【記文】這第三部分中。首先說明名稱與本體。從「如」字以下引用經典作證，《中阿含經》說：「阿難接受特別的房舍，用來布施給招提僧。」「所謂別房施」就是翻譯其名稱，指將特定的房舍布施給現前僧眾。「又如經中」指的是《大般涅槃經》的經文。首先翻譯名稱以顯示名相。從「《鈔》」字以下，指出過去解釋的錯誤。是說《行事鈔》中誤用了過去的舊解。舊解說「房舍屋宇是招提物，花朵果實是僧鬘物」，那是採取了「採花果編結成花鬘」的字面意思，所以說是「隨字顯相」。梵文與漢義無法辨明，這就是「違背了事理與意義」。

【146-0010】02_戒疏/07a_卷二上之三#14
【原文】【疏】四、十方現前物。如僧得施，及五眾亡物。以此物施，通擬十方，有僧皆得，故此福分，廣大無邊。及論立法，不可盡集。制作通法，用約十方，隨現集者，皆有其分，故曰也。若未羯磨，盜者偷蘭，以十方僧不滿五故。若羯磨已而行盜者，隨其輕重，據現結正。既定罪相，隨務則多。講至於此，引《鈔》解也。
【譯文】【疏文】第四種是「十方現前物」。例如僧團獲得大批布施，以及五眾弟子亡故後留下的遺物。因為這類物品在布施時，普遍打算利益十方，凡是有僧人在場都應得一份，所以這份福報廣大無邊。但若論及實際立法執行，不可能召集十方所有僧人。因此制定了共通的法則，用以約束代表十方僧眾，只要當下參與集會的人，都能分得一份，所以才這樣稱呼。如果尚未進行羯磨作法就被盜取，盜者結偷蘭遮罪，因為分攤給十方僧眾每人不足五錢。如果已經羯磨作法完畢才進行盜取，則隨盜取金額的輕重，依照當場分得人數來判定其罪（或輕或重）。既然罪相已經確定，隨事處理的細節就很多。講到這裡，應當引證《行事鈔》來詳細解釋。

【146-0011】02_戒疏/07a_卷二上之三#15
【原文】【記】四中。初簡物相。「以」下，示名義。「制通法」者，即白二羯磨。「若」下，定犯相。輕重兩判，準《善生經》。初犯「蘭」者，由未作法，人無限數，望「十方」結；後「隨輕重」者，既作法已，人有數限，故隨所盜，輕重兩結。
【譯文】【記文】這第四部分中。首先揀選物品名相。從「以」字以下，說明名稱由來。「制定通法」，指的就是白二羯磨。從「若」字以下，判定犯戒的罪相。輕與重的兩種判定，是依據《優婆塞戒經》（善生經）。最初犯偷蘭遮罪，是因為尚未作法，應得之人數沒有限制，是針對十方無量僧眾來結罪；後面說「隨輕重」，是因為作法之後，分得的人數已有明確限制，所以隨所盜取的價值，分別結重罪或輕罪。

【146-0013】02_戒疏/07a_卷二上之三#17
【原文】【疏】就緣分三：初明掌護損失，後明被賊、盜相。
【譯文】【疏文】就犯緣分為三部分：先說明保管看守者的損失責任，後說明被盜賊掠奪後的盜罪行相。

【146-0014】02_戒疏/07a_卷二上之三#18
【原文】【疏】初中，妙同《鈔》引。《善見論》中，若守護財物，謹慎不懈，而有盜者，私竊而取，或強逼取，皆望本主結者，以非護主能禁之限故也。若反此者，守物須償，以本盜人欺守護故，是須還他。若不還，犯。
【譯文】【疏文】在第一部分中，精妙之處與《行事鈔》所引相同。《善見論》中說，如果守護財物的人謹慎不懈怠，卻有盜賊暗中竊取，或是強力逼迫奪走，這些都針對原物主來結罪，因為這已經超出看守者能力所能防範的限度。如果與此相反，是看守者懈怠，那麼守物的人就必須賠償，因為原盜賊是欺負看守者的疏忽，所以看守者必須償還主人。若是不肯償還，就構成犯罪。

【146-0015】02_戒疏/07a_卷二上之三#19
【原文】【記】次、別人物，釋中，初科。上句指廣。彼約二主，分為七種：一、掌護損失主；二、寄附損失主；三、被盜物主；四、賊施比丘物主；五、枚囚縛賊主；六、狂人施物主；七、守視人作主。並廣如彼，須者尋之。下引《善見》，即彼初位。《論》中。初明守護謹慎。「望本主」者，有二義故：一、非能禁，二、無填償。本主索償，反成盜故。「若」下，次明慢藏。反上二義，故從守護。
【譯文】【記文】其次、關於個人財物的解釋，第一小科。上面那句指引去參閱廣泛的內容。那裡依照兩種主體，分為七種類型：第一、掌管看守造成損失的主人；第二、接受寄託造成損失的主人；第三、財物被盜的原主人；第四、盜賊將物布施給比丘的原主人；第五、被收押為囚或被綑縛之盜賊的主人；第六、瘋狂之人布施財物的主人；第七、看守視察之人作主的情況。全都詳見彼處，有需要的人可以去查閱。下面引用《善見論》，就是彼處的第一種情況。《論》中首先說明守護得很謹慎。「針對原主人結罪」有兩個道理：一是超出防禁能力，二是守者無需填補賠償。此時原物主若強索賠償，反而構成盜竊。從「若」字以下，說明疏忽收藏的情況。這與上述兩種道理相反，因此罪過要從守護者這一邊來結算。

【譯文】【疏文】第二、被盜賊搶奪的情況，如同《行事鈔》所引用的，在法理上開展為兩種情形，即「當面搶奪」與「不當面暗取」。結罪的時候，應當看這兩位主人（原物主與盜賊）放棄財物的心念是否已經斷絕來判定。
