# 校閱材料　第702檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【702-0001】03_業疏/21b_卷四之四#66
【原文】次科初敘難，即第五段下注文。佛制相待及出囑者分，恐不及羯磨故耳。答下，彼謂相待留分，乃是舊住暫出，故具三義；外客止有夏勞，闕前二義。下仍引據，明非外人
【譯文】下一科起初敘述問難，也就是第五段底下的注文。佛陀制定應當等待以及外出者可囑託代分，唯恐趕不上作羯磨法的緣故。在「答」以下，他們認為等待留分的人，是舊住僧暫時外出，所以具備三種意義；外來客僧只具備安居辛勞，欠缺了前兩種意義。底下仍舊引用依據，說明並非給予外人。

【702-0002】03_業疏/21b_卷四之四#67
【原文】今解須法。若不作者，何名為僧？何名限約？界外來至，何得不給？若許不與，此即現前，非僧得矣。故文云「彼得夏衣應心念口言」等，即是加法也。又《十》、《五》二律云：「安居時僧得施者，應受持，若淨施人；不爾者，後來比丘應共分。」故知須也
【譯文】如今的解釋是必須作羯磨法。如果不作法，憑什麼稱為僧得？憑什麼加以限制約束？界外的比丘來到，又怎能不分給他？如果允許不分給他，這就成了現前施，而不是僧得施了。所以律文說「彼得夏衣應當心念口言」等，這就是加持作法。而且《十誦律》、《五分律》都說：「安居時僧眾獲得布施者，應當受持，或者淨施與他人；若不這樣做，後來到達的比丘應當共同分得。」由此可知必須作法。

【702-0003】03_業疏/21b_卷四之四#68
【原文】今解中初句判定。「若」下顯過，有二：一不作法過，二不給外客過。「故」下引證。初引本律，具如注中。「又」下次引他部，分物入手未曾持說，後來有分，驗知通收，義須法約
【譯文】在現今的解釋中，第一句作出判定。自「若」以下顯發過失，有兩種：一是不作羯磨法的過失，二是不分給外來客僧的過失。自「故」以下引用經證明。起初引用本宗《四分律》，具體正如注文中所說。自「又」以下接著引用其他部派律典，分得財物到了手中未曾作受持或淨施之說，後來的比丘就有權分享，以此驗知僧得是普遍納受的，在義理上必須作法予以限制約束。

【702-0008】03_業疏/21b_卷四之四#73
【原文】就前又二：現前及僧得。現前又二：時及非時，各一部、二部。僧得亦二：時及非時。非時有三：一常住處，二約界得，三隨僧得。此下二門各分一部、二部，於中有一人法、二人、三人、四人、五人已上，作法各別，至時口引。就二部中：一對面施二部，二互施二部。如《五分》中，非安居時比丘住處施，比丘尼無者，僧應分；尼坊施僧，無者尼分。時中亦列二部互施
【譯文】就前一項（檀越施）又分為二：現前施與僧得施。現前施又分為二：時施與非時施，各有一部僧與二部僧之別。僧得施也分為二：時施與非時施。非時施有三種：一是常住處物，二是約界得物，三是隨僧得物。這底下的後兩門（約界得、隨僧得）各分一部僧與二部僧，其中有一人法、二人法、三人法、四人法、五人以上法，作法各自不同，到時再口頭引申說明。在二部僧施之中：一是當面布施給二部，二是互通施給二部。如《五分律》中，在非安居時於比丘住處布施，若沒有比丘尼，比丘僧應當平分；在尼庵中布施給僧，若沒有比丘僧，比丘尼分。在時施之中也列有二部互施的情形。

【702-0009】03_業疏/21b_卷四之四#74
【原文】檀越施中，僧得非時施中，初打入常住，僧不分也；二約界集者，羯磨分也；三隨僧得，謂檀越隨來者與也。就一部中，作法五位。就二部中，對、互兩別。下引《五分》別證互施，前時僧得止就一部，彼通二部，如文所明
【譯文】在施主布施中，僧得非時施之中：第一種歸入常住，僧眾不予分發；第二種依界內聚集者，作羯磨法分發；第三種隨僧而得，是指施主隨來到的僧人而給予。就一部僧而言，作法有五種位次。就二部僧而言，有當面施與互施這兩種差別。底下引用《五分律》特別印證互施的情形，前面的時僧得施只就一部僧而言，那裡則通於二部僧，正如文中所闡明的。
