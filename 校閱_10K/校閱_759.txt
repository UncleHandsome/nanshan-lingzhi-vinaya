# 校閱材料　第759檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【759-0001】02_戒疏/17b_卷四上之二#57
【原文】【疏】戒本四句：一、人；二、僧差；三、教；四、「乃至日暮」下，結罪。
【譯文】【疏文】戒本文字共有四句：第一是能犯之人；第二是受僧團差派；第三是進行教授；第四從「乃至日落昏暗」以下，為結定罪名。

【759-0002】02_戒疏/17b_卷四上之二#58
【原文】【記】戒本。第二句，注云「一教授」等者，《律》云「眾僧中差，白二羯磨」。然與前戒異者，前是不差，通指二法，此既已差，別據一法。
【譯文】【記文】在戒本之中。第二句，註文說「一者受差教授」等語，《四分律》說「在僧眾中正式差派，作白二羯磨」。然而本戒與前一條戒不同之處在於，前戒是未受差派，通泛涵蓋了說法與八敬二法，此戒既然已經受差，則是專門依據說法這一件事來論罪。

【759-0003】02_戒疏/17b_卷四上之二#59
【原文】【疏】廣釋中，「除教授」已，「餘誦、受經至暮」同譏，如何輕者？以教授僧集尼眾易，故重。自餘別請，尼之來去無攝法，故輕也。
【譯文】【疏文】在詳細解釋中，除了「正式教授」之外，「其餘如誦經、受經持續至日暮」同樣招致譏嫌，為什麼處罰較輕？因為僧團差派教導是大眾集會，尼眾易於大批群聚，所以罪責較輕。其餘個別私自請益，尼眾的來去沒有僧法作為常規約束，所以罪責較輕。

【759-0004】02_戒疏/17b_卷四上之二#60
【原文】【記】第四中。初徵問。「以」下，釋通。初明教授重，是眾法故。「自」下，次明餘輕，別人請故。注不犯中，「未日暮」者，無犯明不犯。「除婦女」者，即餘男子，無譏疑也。「若船濟」下，四種，三並因聽，非專為尼。第三，「尼寺中」者，處無非故。「因人請」者，寫倒，合作「因請人」，《律》云「說戒日來請教授人，值說便聽」是也。
【譯文】【記文】在第四句中。首先提出詰問。從「因為」以下，進行解釋釋疑。首先說明教授罪重，因為這是僧團僧法大眾集會的緣故。從「其餘」以下，接著說明其餘情況罪輕，因為純屬私人請法之故。註文中不犯的條目，「太陽尚未下山」一句，本來就沒有犯戒行相，明白指出是不犯。「除了婦女之外」，就是指其餘男子，不會引發世俗譏嫌與猜疑。從「若在渡船」以下共有四種情況，其中三種都是順帶聽聞，並不是比丘專程為尼眾講說。第三種「在尼寺之中」，因為身在尼寺處所，沒有日暮閉城不及回歸的非法過失。「因他人祈請」，原稿文字倒置，應當改作「因請人」，《四分律》說是「說戒日尼眾前來迎請教授師，適巧遇上比丘說法便在旁隨聽」的情況。

【譯文】【律文】第二十三、譏訶受差教授者戒。

【759-0007】02_戒疏/17b_卷四上之二#63
【原文】【疏】然備德被差，慈心教授，情存為法，不希厚味。今見他獲利，內生嫉妬，發言譏訶，惱亂賢善。脫由斯敗，事絕兼濟，損處非輕，故制。
【譯文】【疏文】具備完滿德行而受到僧團差派，懷著慈悲之心前去教導，心念全在於弘揚正法，絕不貪圖豐厚的供養飲食。如今看見別人獲得利養敬奉，內心便生起嫉妒，出言譏諷指責，無端擾亂賢善的法師。若是因此導致教授之法廢弛，將永遠斷絕兼濟教化尼眾之事，所造成的損害極其深重，因此佛陀制定此戒。

【759-0008】02_戒疏/17b_卷四上之二#64
【原文】【記】二十三，制意中。初敘所差如法。「厚味」，即美食也。「今」下，次敘能謗起過。初明惱人。「嫉妬」心業，「譏呵」口業。「脫」下，次明壞事。「敗」，猶廢也。「絕兼濟」者，失利他也。「損」下，雙結。
【譯文】【記文】第二十三條，在制戒旨意中。首先敘述受差派者完全合乎戒法。「厚味」，就是指美味的飲食。從「如今」以下，接著敘述造謠誹謗者所生起的過失。首先說明惱亂他人。「嫉妒」屬於意業，「譏諷指責」屬於口業。從「若是」以下，接著說明敗壞僧事。「敗」，就像是廢棄。「斷絕兼濟」，是指喪失了利益他人的弘法大業。「所造成」以下，作雙重結定。

【759-0009】02_戒疏/17b_卷四上之二#65

【759-0011】02_戒疏/17b_卷四上之二#67
【原文】【註】佛在舍衛。尼聞教授師來，出迎供給，六群生嫉，云：「彼無實，但為食故教授尼也。」比丘以過白佛，因而制戒。
【譯文】【註文】佛陀在舍衛國時。尼眾聽聞教授師前來，出門迎接並供養所需物品，六群比丘看見後生起嫉妒，說：「那些人根本沒有實德，只是為了貪圖飲食供養才去教授比丘尼的。」比丘將此過失稟告佛陀，佛陀因而制定此戒。

【759-0012】02_戒疏/17b_卷四上之二#68
【原文】【記】戒緣中，六群比丘因過被制，既不具德，差法絕分，內懷怨忿，故致譏呵。
【譯文】【記文】在戒律緣起中，六群比丘因為犯過而受戒律約束，既然自己不具備十德，差派的僧法自然與他們無關，內心懷著怨恨憤怒，所以發出譏諷指責。

【759-0013】02_戒疏/17b_卷四上之二#69
【原文】【律】若比丘，語諸比丘作如是語——「諸比丘為飲食故，教授比丘尼」者，波逸提。
【譯文】【律文】如果有比丘，對其他比丘說出這樣的話——「那些比丘完全是為了飲食的緣故，才去教授比丘尼的」，犯波逸提。

【759-0014】02_戒疏/17b_卷四上之二#70
【原文】【註】若說不了了，吉羅。比丘尼等吉羅。不犯者：其事實爾，為飲食供養故教授，為飲食故教誦經、受經，若問；若戲，若錯說者——一切不犯。
【譯文】【註文】若說得不夠清楚明了，犯突吉羅。比丘尼等犯突吉羅。不犯的情況：事情的真相確實如此，教授者純粹是為了飲食供養才去教授，或純為飲食才教導誦經、傳授經典，或是提出探詢；若只是開玩笑，若是口誤說錯——一切都不構成犯戒。

【759-0019】02_戒疏/17b_卷四上之二#75
【原文】【疏】凡僧尼位殊，理無交涉。無緣取與，尚涉譏疑，況交致染，容壞梵行，誠為大損，故制。

【759-0020】02_戒疏/17b_卷四上之二#76
【原文】【記】二十四，制意中。初明類別。「無」下，次顯招譏。「無緣取與」者，謂無取與之緣，徒與往還，猶不免譏，況持衣與而相交染耶？往往犯於大重，此顯須制之意。
【譯文】【記文】第二十四條，在制戒旨意中。首先說明僧尼類別有異。從「無緣」以下，接著顯露招致譏嫌的危險。「無緣無故取與」，是指沒有合理的戒律因緣，空自與尼眾互通有無，尚且免不了受人譏嫌，何況親手持衣贈與而相互交染結情呢？這往往會進一步觸犯極重的根本大戒，此處正顯現出必須制戒的深意。
