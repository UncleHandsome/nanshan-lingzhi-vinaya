# 校閱材料　第403檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【403-0001】03_業疏/10a_卷二之四#38
【原文】初解中三：初正定體「教、無教性」。彼論續云：「受三歸時，胡跪合掌，口說三歸，是身口教。若淳重心，有身口無教。」「此就」等者，疏家斷也。教為能發，由教發得無教，故云「所發教之業」，即以無教為性也。「無教者」下，二釋名。一發謂初念，續現即第二念。教猶使也，謂非教使之然，任運自然酬因感報故也。「今下」會異，即《善生》、《成論》、《雜心》等也，餘如〈戒業章〉中
【譯文】在第一種解釋中有三個部分：第一、正確判定體性為「教、無教性」。該論接著說：「受三歸時，胡跪合掌，口說三歸，這是身教與口教。如果有純熟深重之心，便有身無教與口無教。」自「此就」以下，是疏主的判斷；教為能引發者，由教引發而得到無教，所以說是「教所引發之業」，也就是以無教為體性。自「無教者」以下，第二、解釋名稱；「一發」指最初一念，「續現」即是第二念；「教」如同差使，是指並非由外在教令指使它如此，而是任運自然酬答前因、招感後報之故。自「今」字以下，會通各論的異名，也就是《善生經》、《成實論》、《雜心論》等，其餘內容如〈戒業章〉中所述。

【403-0002】03_業疏/10a_卷二之四#39
【原文】又云：三業為性，謂從初發業者為名。故云互跪合掌，口說三歸，是身口教，因具而發，能存於有，故名為性
【譯文】論中又說：以身口意三業為體性，這是依最初生起的造作之業來立名。所以說互跪（胡跪）合掌、口說三歸，這是身教與口教，因身口之具而發起，能夠存續於後有果報之中，所以稱為體性。

【403-0003】03_業疏/10a_卷二之四#40
【原文】次師中，初示體。三業即是前教。「謂下」今判。「故下」引證，但云身口，意在二中。「因下」示立所以。具即身口，有即來報
【譯文】在第二位論師的觀點中，首先顯示體性，三業也就是前面的教（表業）。自「謂」字以下，是如今的判定。自「故」字以下引用作為證明，文中雖然只說身、口，意業已含攝在身口二者之中。自「因」字以下，顯示立論的原由；「具」就是指身、口，「有」就是指來世果報。

【403-0004】03_業疏/10a_卷二之四#41
【原文】又云：善五陰為性者，色身恭敬，識、想、受中緣法翹注，竝由善本，便生善行，無貪等三攝御斯法，能生後有，故因得名也。由諸眾生依法受歸，隨其心力，有善業起，扶助形命。若輕浮心，體是無記，不發無作
【譯文】論中又說：以善五陰為體性者，色身表現恭敬，在識、想、受三陰中專注攀緣歸依之法，全都是由於善根根本，便生起行陰之善行，由無貪、無瞋、無癡三善根攝持統御此法，能夠感生後有果報，所以依因而得名。由於一切眾生依教法領受三歸，隨其心力深淺，有善業生起，扶助色身生命。如果是輕浮之心，體性屬於無記，就不能發起無作戒體。

【403-0005】03_業疏/10a_卷二之四#42
【原文】三師中，初示體。色身恭敬，即兼口說；三心緣法，此明初受，故為善本；行心攝御，隨起奉持，五陰備矣，因以名焉。斯法即三歸功德。「由下」釋所以。依法受歸，即初受也；隨心力者，即隨持也。此師亦據能發明體，雖兼色陰，發必由心，故下準論證成心起
【譯文】在第三位論師的觀點中，首先顯示體性。色身恭敬，即同時兼具口中說辭；識、想、受三心攀緣歸依之法，這是說明初受之時，所以稱為善本；以行陰之心攝持統御，隨後發起奉持，五陰就具備了，因而以此立名。「斯法」就是三歸的功德。自「由」字以下，解釋其所以然。「依法受歸」，就是最初領受；「隨心力者」，就是隨後持守。這位論師也是依據能引發之法來闡明體性，雖然兼帶色陰，但發起必定由心而來，所以下文依照論典證成它是由心念生起的。

【403-0006】03_業疏/10a_卷二之四#43
【原文】二解歸意者
【譯文】第二、解釋歸依的本意。

【403-0007】03_業疏/10a_卷二之四#44
【原文】論云：以三寶為所歸。所歸以救護為義。如人獲罪於王，投向他國，以求救護。彼王勑言：「汝求無畏以投我者，莫出我境，莫違我教，必當救護。」眾生亦爾，繫屬於魔，有生死過，歸向三寶，魔無如之何
【譯文】論中說：以三寶為所歸依之處。所歸依以救護為意義。如同有人觸犯了國王的律法獲罪，逃奔投向他國以尋求救護。那個國家的國王敕令說：「你為了尋求免除畏懼而投奔我，就不要離開我的國境，不要違背我的教令，我必定會救護你。」眾生也是如此，繫縛隸屬於魔王，有流轉生死的過咎，歸向三寶之後，魔王就對他無可奈何了。

【403-0008】03_業疏/10a_卷二之四#45
【原文】第二、歸意中初文，初句示境；「所歸」下顯義；「如人」下舉喻；「眾生」下合法，上三句合上「獲罪於王」，下二句合上「投向地國」。魔有四種：天、陰、惱、死，未歸三寶，皆繫屬焉。
【譯文】在第二門「歸意」的第一段文中，第一句指示所歸之境；自「所歸」以下顯發其義理；自「如人」以下列舉譬喻；自「眾生」以下合喻於法，上三句合於上面的「獲罪於王」，下二句合於上面的「投向他國」。魔有四種：天魔、五陰魔、煩惱魔、死魔，眾生在未歸依三寶之前，都繫屬在魔的管轄之下。

【403-0009】03_業疏/10a_卷二之四#46
【原文】論云：我境即四念處，他境即五欲也。我教謂心師也，他教謂師心也。魔者，梵本具彰云魔阿羅，此方略之，但置上字。後人加鬼，不入字書。依唐譯之，則云殺者，能損眾生法身慧命也
【譯文】論中說：我的境界就是四念處，他的境界就是五欲。我的教化是以法為師（心師於法），他的教化是放任自心（師心自用）。所謂的「魔」，梵語原本具足稱為「魔阿羅（Māra）」，此方漢地予以省略，只保留上面的字。後人在下面加上「鬼」字，並未收錄於古字書中。依照唐代的翻譯，則稱為「殺者」，因為它能戕害損壞眾生的法身與慧命。

【403-0010】03_業疏/10a_卷二之四#47
【原文】次科，四念為我境者，是佛所教，可依住故，即身不淨、受是苦、心無常、法無我，四皆如實而觀，故云「念處」。五欲為他境者，是魔所住故。佛則以心師法，魔則捨法任心。魔是略梵，據字本體，從手從石，世謂鬼趣，相傳加鬼，篇韻有之，知非古也。翻名釋義，在文易解
【譯文】就下一科而言，以四念處為佛的境界，是因為這是佛陀所教導、可以依止安住的緣故，即身念處觀身不淨、受念處觀受是苦、心念處觀心無常、法念處觀法無我，這四種都如實修觀，所以稱為「念處」。五欲為魔的境界，是因為這是魔王所安住之處。佛是讓心師承於正法，魔則是捨棄正法而放任自心。「魔」是梵語的略譯，依據該字本來的形體，原本從手（摩）或從石（磨），世人認為屬於鬼道之類，相傳才加上「鬼」字偏旁，《玉篇》、《廣韻》等字書雖然收錄了，由此可知並非古代原貌。翻譯名稱與解釋意義，在文中淺顯易解。

【403-0011】03_業疏/10a_卷二之四#48
【原文】彼論又云：如昔有鴿為鷹所逐，移入佛影，泰然安樂；在身子影，戰怖如初。乃至如來習氣盡故，久修慈悲，能為物護
【譯文】該論又說：如同過去有一隻鴿子被老鷹追捕，移入佛陀的身影中，便泰然安樂；若在身子（舍利弗）的身影中，依然戰慄恐懼如初。乃至因為如來的習氣已斷盡，長久修習慈悲，能夠為一切眾生提供救護。

【403-0012】03_業疏/10a_卷二之四#49
【原文】次科引緣，意彰唯佛是可歸故。準論，初在舍利弗影，後入佛影，故云「移」也。今文互倒，取其意耳。「乃至」者，彼云「所以爾者，佛有大慈悲，舍利弗無故；佛習氣盡，舍利弗未盡故；佛阿僧祇劫修菩薩行，舍利弗六十劫修苦行故」。文但舉佛三勝，對之可見
【譯文】下一科引用因緣，用意在於彰顯唯有佛陀才是真正可歸依之處。依照論典，鴿子起初是在舍利弗的身影下，後來進入佛陀的身影，所以說「移」。現在疏文次序互倒，只是取其大意而已。所謂「乃至」，論中說「之所以如此，是因為佛陀具有大慈悲，舍利弗沒有；佛陀的習氣已斷盡，舍利弗尚未斷盡；佛陀歷經無量阿僧祇劫修菩薩行，舍利弗僅六十劫修苦行」。文中只列舉佛陀的三種殊勝，對照之下便可明了。

【403-0013】03_業疏/10a_卷二之四#50
【原文】問：如上所列，審能護者，提婆出家，本歸三寶，何造三逆，入阿鼻中？答：夫言救者，救於可救；惡深罪定，是以叵救
【譯文】提問：如果像上面所列舉的，三寶確實能夠救護眾生，那麼提婆達多出家，本來就歸依了三寶，為什麼還造作三種逆罪，墮入阿鼻地獄之中？回答：所謂救護，是救護那可以救拔的人；若是罪惡深重、定業難移，因此便不可救拔。

【403-0049】03_業疏/10a_卷二之四#86
【原文】問：佛亦是法，法亦是佛，僧亦是法，正是一法，有何差別？答：雖有一義，相有差別。以三寶而言：無師大智、一切功德是佛寶；盡諦涅槃無為是法寶；聲聞學、無學功德智慧是僧寶
【譯文】提問：佛也是法，法也是佛，僧也是法，本來同是一體之法，有何差別？回答：雖然有同具一性的一面，但在顯現之相上有所差別。就三寶而言：無師自悟的大智慧與一切功德是佛寶；盡諦涅槃寂靜無為之理是法寶；聲聞乘有學、無學的功德與智慧是僧寶。

【403-0050】03_業疏/10a_卷二之四#87
【原文】次問中，準《戒疏》，三寶有四：一體、理體、化相、住持。然一體局大乘，理體通大小，且就教限，理體無別，以為問端。三寶互望，佛、僧無體，同歸一法，則無三別，欲明互倒何意不得？答中，初標示，一即據體，別乃約相。「以下」別釋，佛、僧能證，法即所證，能中師資位分，故三恒別。佛云「無師大智」，對下僧寶從佛所聞專自利故；法云「無為」，簡異佛、僧皆修證故。所以二寶皆稱功德。彼論又云：「以法而言，無師無學法為佛寶，非學非無學法為法寶，聲聞學無學法為僧寶
【譯文】在下一段提問中，依準《戒疏》，三寶有四種：一體三寶、理體三寶、化相三寶、住持三寶。然而「一體」局限於大乘，「理體」則通於大乘與小乘，暫且就教理界限而言，理體三寶本無差別，以此作為提問的發端。三寶相互對照，佛寶與僧寶並無另外的自體，同歸於一法，既然沒有三種差別，便想辨明為什麼念誦互換倒置就不成就？回答中，首先標示說明：同「一」是依據體性而言，「別」則是就外相而論。自「以」字以下分別解釋：佛與僧是能證者，法則是所證之理，在能證之中又有師資果位的分野，所以三寶恆常有所差別。佛寶稱為「無師大智」，是相對於下文僧寶從佛陀聽聞正法且偏向自利的緣故；法寶稱為「無為」，是簡別排除佛與僧皆屬於修證造作的緣故，所以佛、僧二寶都稱為「功德」。該論又說：「以法體而論，無師自悟的無學法為佛寶，非學非無學法（無為法）為法寶，聲聞乘的有學無學法為僧寶。」
