# 校閱材料　第379檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【379-0001】02_戒疏/18b_卷四上之三#88
【原文】【記】答：「但使無病，並是非時。」
【譯文】【記文】答：「只要沒有病，就都算非時。」

【379-0002】02_戒疏/18b_卷四上之三#89
【原文】【記】「若非」下，簡辨。「餘」下，指例。由下二戒，三藥罪同，各如注解。是則加法「盡形」，無病輙服，咽咽三吉，更兼惡觸。廣如前篇。注不犯中，三節。初《律》云：「乞食比丘見作石蜜，中有罽尼，畏慎不敢非時噉。佛言：『聽噉，無犯。作法應爾。』」、「吐下藥」，即取食之藥。「哯」，胡典反，不嘔而吐也。若準《鈔》中，不得復咽。此中開者，猶在喉中。
【譯文】【記文】「若非口法」以下，是揀別辨析。「餘殘宿、不受」以下，是指示類例。由於下面兩條戒，三種藥的罪相同，各如註解所說。這樣說來，加法受持的「盡形壽藥」，沒有病而隨便服用，每一咽都結三種突吉羅，另外還兼有惡觸之罪，詳細如前篇所說。註文「不犯」之中，分為三節。第一，《律》中說：「乞食的比丘看見人家製作石蜜，裡面有罽尼，心生畏慎，不敢在非時吃。佛說：『允許吃，不犯。製作的方法本來就應該這樣。』」「吐下藥」，就是取來服食的藥。「哯」，音胡典反，是不嘔而吐的意思。若依準《鈔》中所說，吐出來就不得再咽回去；這裡開許的，是指食物還在喉中。

【379-0003】02_戒疏/18b_卷四上之三#90
【原文】【律】三十八、食殘宿食戒。
【譯文】【律文】第三十八、食殘宿食戒。

【379-0004】02_戒疏/18b_卷四上之三#91
【原文】【疏】食殘宿食戒三十八。
【譯文】【疏文】食殘宿食戒第三十八。

【379-0005】02_戒疏/18b_卷四上之三#92
【原文】【疏】凡飲食繁穢，近則長貪，令人不節。又體現交盡，義無貯畜，故置異處，不得輒噉。然今行人，但存省事，隨宜受納，不思遠大，致使教法日就崩離，稱心之過，知何不犯？是以大聖，隨事節約，若衣若食，並有軌儀。緣而不曉，即結無知；可學不涉，又結怠惰。意令割略我倒，專心思道，不令貯畜，用遺愚著，故制斯戒。
【譯文】【疏文】凡是飲食繁雜穢污，靠近它就會增長貪欲，使人不知節制；又食物之體現前受用即盡，義理上不應貯藏積畜，所以要放置在別處，不可隨便就吃。然而現今修行的人，只求省事，隨意受納，不思考長遠的大事，致使教法一天天走向崩壞離散；一味順遂心意的過失，哪有什麼戒是不犯的呢？因此大聖隨事加以節制約束，無論是衣是食，都有軌範儀則。遇到境界而不明白，就結「無知」之罪；可以學而不去學，又結「怠惰」之罪。用意是教人割捨、簡略我執顛倒，專心一意思惟道法，不許貯藏積畜，以此遣除愚癡的執著，所以制定這條戒。

【379-0006】02_戒疏/18b_卷四上之三#93
【原文】【記】三十八，制意為三。初敘食過，文列二過：一、貪染不可近，二、現物不宜畜。「置異處」者，即淨地中。「然」下，次敘違犯。此據緣起坐禪比丘，故言「省事」，今時貪恣，則非所敘。「不思」等者，已雖少欲，凡愚相倣，疾滅法故。「稱心過」者，充其所欲，欲即妄情，必須制故。「是」下，三、彰聖制，又三。初明根本制，文通諸罪，意在今戒。「緣」下，次明重增制。即無知犯提，不學得吉，此二該通止、作兩犯，如前所明。「意」下，顯教益，即生善滅惡也。
【譯文】【記文】三十八戒的制意分為三節。開頭敘述飲食的過失，文中列出兩種過失：一、貪染之心不可親近；二、現前的食物不宜貯畜。「置異處」，就是指放在淨地之中。「然今行人」以下，其次敘述違犯的情況。這裡是根據緣起中坐禪的比丘而說，所以說「省事」；當今之人貪婪放縱，就不是這裡所敘述的了。「不思遠大」等句，是說自己雖然少欲，但凡夫愚人互相仿效，會使教法迅速滅亡的緣故。「稱心之過」，是說充遂其所欲，欲望就是虛妄的情識，所以必須加以制止。「是以大聖」以下，第三是彰明聖人的制教，又分三層：先說明根本的制教，文中通於諸多罪相，用意在於今此一戒；「緣而不曉」以下，其次說明因重增而制的教，就是無知犯波逸提、不學得突吉羅，這兩種通於止犯、作犯兩類，如前所說明；「意令割略」以下，顯示教法的利益，就是生善滅惡。

【379-0007】02_戒疏/18b_卷四上之三#94
【原文】【疏】論犯三緣：一、是殘宿食；二、知是；三、咽，便犯。殘、宿相對，四句分之。殘宿、內宿，亦有四句。可如《鈔》引。
【譯文】【疏文】論犯此戒有三種緣：一、是殘宿食；二、知道是殘宿食；三、一咽便犯。「殘」與「宿」相對，分為四句。殘宿與內宿的對照，也分為四句。可以照《鈔》中所引。

【379-0008】02_戒疏/18b_卷四上之三#95
【原文】【記】犯緣中。初列示。「殘」下，指句。兩重料簡，俱指如《鈔》，今為引之。彼云：「一、殘而非宿，吉；二、宿而非殘，亦吉；三、亦殘亦宿，提；四、非殘非宿，無罪。」次四句者：「一、是殘宿，非內宿，得墮；二、是內非殘，吉；三、四俱句，與前無別。」
【譯文】【記文】這是「犯緣」部分。首先列出顯示。「殘、宿相對」以下，是指示句數。兩重料簡，都指向如《鈔》所說，現在為之引出。那裡說：「一、是殘而非宿，得突吉羅；二、是宿而非殘，也得突吉羅；三、既是殘又是宿，得波逸提；四、非殘非宿，無罪。」第二重四句是：「一、是殘宿而非內宿，得墮；二、是內宿而非殘，得突吉羅；三、四兩句，與前面沒有差別。」

【379-0009】02_戒疏/18b_卷四上之三#96
【原文】【註】佛在羅閱祇。迦羅坐禪，乞食疲苦，食先得者。比丘於小、大食上不見，覓之，具說所由。比丘白佛，佛便訶言：「汝雖少欲，後來眾生相法而行。」因即制戒。
【譯文】【註文】佛在羅閱祇。迦羅坐禪，覺得乞食疲累辛苦，就吃先前所得的食物。比丘們在小食、大食的時候不見他，去尋找他，他詳細說明了原由。比丘們稟白佛陀，佛便訶責說：「你雖然少欲，但後來的眾生會互相仿效（你的做法）而行。」因此就制定了這條戒。

【379-0010】02_戒疏/18b_卷四上之三#97
【原文】【疏】就緣起中，此戒不受，以「坐禪」人為緣起者。約情為論，輕戒而重觀門，故佛言：「後來眾生相法而行。」非法而行，何可妄也？
【譯文】【疏文】在緣起中，這條戒所說的「不受（而食）」，是以「坐禪」的人作為緣起。就人情而論，是輕視戒律而看重觀門，所以佛說：「後來的眾生會互相仿效而行。」不依正法而行，怎麼可以隨便妄為呢？

【379-0011】02_戒疏/18b_卷四上之三#98
【原文】【記】戒緣中。初牒文。「約」下，出意。「非」下，結勸。今時禪、講各尚己宗，頓忘戒律。況加輕弄惑誑後生，謂持戒則徒自拘囚，學道則不勞把捉。豈念壇場立誓，盡壽堅持？非戒無以為僧，非戒將何受施？阿鼻苦楚，本為忘恩；瘖瘂盲冥，良由謗法。金言呵制，明為將來，後學聰明，幸遵慈訓。
【譯文】【記文】在戒緣這一段中，首先牒引疏文；「約」字以下，是顯示用意；「非」字以下，是總結勸誡。當今參禪的人與講經的人，各自崇尚自己的宗派，頓時忘失了戒律。更何況又加以輕慢戲弄，迷惑欺誑後學，說持戒只是白白地自我拘束，學道則不必勞煩把捉。哪裡想到在戒壇上立下的誓願，要盡形壽堅持？沒有戒就不能成為僧伽的一員，沒有戒又憑什麼接受信施？阿鼻地獄的劇烈苦報，本來就是為忘恩而設；成為瘖啞、盲冥的人，實在是由於謗法。佛陀金口呵責制戒，明明是為了將來的人；後學之人若有聰明，但願遵奉這慈悲的教誨。

【379-0022】02_戒疏/18b_卷四上之三#109
【原文】【疏】就第二句，注解中。《十誦》云：「此方殘宿食，餘二方不得食。北方宿食，開三方食，以無我所故。」制不受食，意拔我根，著色味故。餘辨相中可解。《鈔》中大分別也。
【譯文】【疏文】就第二句而言，是在注解中解說的。《十誦》說：「此方（南洲）的殘宿食，其餘二方不得食用；北方的宿食，開許三方食用，因為北方沒有『我所』的緣故。」制立不受食（戒），用意是拔除「我」的根本，因為眾生貪著色味的緣故。其餘辨別行相的部分可以理解，《鈔》中有詳細的分別。

【379-0023】02_戒疏/18b_卷四上之三#110
【原文】【記】釋第二中。引《十誦》明四州者，顯示注中「一切」義故。「制」下，明通禁之意。「餘」下，指廣，檢《鈔》對之。
【譯文】【記文】在解釋第二句的段落中。引用《十誦》說明四洲，是為了顯示注解中「一切」的含義。「制」字以下，說明普遍禁制的用意。「餘」字以下，指示廣說之處，查檢《鈔》來對照。

【379-0030】02_戒疏/18b_卷四上之三#117
【原文】【疏】《多論》五義：「一、為斷盜竊因緣；二、為作證明；三、為止誹謗故；四、為成少欲知足故；五、為生敬心，令外道得益故。」
【譯文】【疏文】《多論》提出五種意義：「一是為了斷除盜竊的因緣；二是為了作證明；三是為了止息誹謗；四是為了成就少欲知足；五是為了生起敬心，使外道得到利益。」

【379-0031】02_戒疏/18b_卷四上之三#118
【原文】【記】三十九，《多論》五意。初、若令自捉，慣習成盜。二、若非他證，或容抂濫。三、如緣起，《五分》中白衣呵云「我不喜見著割截衣人不受食食」。四、成上行。五中，因外道搖果墜地令比丘捉，比丘言「佛不許自捉」，外道因發心出家，得漏盡。前三滅惡，後二生善。一、四自行，餘三化他。
【譯文】【記文】第三十九條，《多論》的五種用意。第一，如果讓比丘自己拿取，習慣成自然就會變成盜竊。第二，如果沒有旁人作證明，或許就會蒙受冤枉誣賴。第三，如緣起中所說，《五分》裡白衣呵責道：「我不喜歡看見穿著割截衣的人不受食而食。」第四，成就殊勝之行。第五中，因為外道搖動果樹讓果子掉落地上，叫比丘去撿，比丘說「佛不允許自己拿取」，外道因此發心出家，得到漏盡。前三種是滅惡，後兩種是生善。第一和第四是自行，其餘三種是化他。

【原文】【律】若比丘，不受。
【譯文】【律文】若比丘，不受（食）。

【379-0049】02_戒疏/18b_卷四上之三#136
【原文】【註】不與食者，未受者是。受有五種：手與，手受；手與，持物受；持物與，手受；若持物授，持物受；若遙過物，與者、受者俱知，中間無所觸閡，得墮手中是也。復有五種：身、衣、曲肘、器與，還以上四受，若有因緣置地與，是為五種也。
【譯文】【註文】不給與食物的情況，就是「未受」。領受有五種：手給與，用手接受；手給與，持物接受；持物給與，用手接受；或持物給與，持物接受；或從遠處傳遞物品，給與的人和接受的人都知道，中間沒有任何觸隔障礙，而落入手中，就是這一種。另有五種：以身、以衣、以曲肘、以器皿給與，受者亦各還用上述四種（身、衣、曲肘、器）來接受；如果有特殊因緣，放在地上給與，這合為五種方式。
