# 校閱材料　第533檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【533-0001】02_戒疏/08d_卷二下之一#127
【原文】【記】次科，今解中，初文又二。初標示；「時」下，敘疑；「故今」下，正釋。「二種法」者：一、說戒，二、羯磨。
【譯文】【記文】第二科判，現在的解釋中，第一段文字又分為兩層。首先標明提示；從「時」字以下，敘述疑惑；從「故今」以下，正面解釋。「兩種法」，就是指：第一、誦戒；第二、僧團羯磨。

【533-0002】02_戒疏/08d_卷二下之一#128
【原文】【疏】二、「後亦如是」者，釋重疑也。時人意謂：初犯斬首，有戒可破，後雖犯過，謂非有罪。故今釋言「後犯亦爾」。不預前共住之例，故曰「不應共住」也。
【譯文】【疏文】第二、「後亦如是」，是為了解除重複犯戒的疑惑。當時人們心中以為：第一次犯重罪如斷頭，是有戒體可以破壞，後來雖然再次犯過，以為就不再算有罪了。所以現在解釋說「後來再犯也是如此」。不能參與先前共住的例行法事，所以說「不應當共住」。

【533-0003】02_戒疏/08d_卷二下之一#129
【原文】【記】次疑中。初標示；「時」下，出疑意；「故」下，釋通。「不預前」者，謂未犯時。
【譯文】【記文】第二種疑難中。首先標明提示；從「時」字以下，指出疑難的意思；從「故」字以下，解釋通達。「不預前」，是指還沒犯戒的時候。

【533-0004】02_戒疏/08d_卷二下之一#130
【原文】【疏】有人言：「白衣沙彌，不足僧數，一犯已後，如前無異，故言『不得共住如前』。疑無重犯，故云『後亦如是』。」
【譯文】【疏文】有人說：「在家人和沙彌，不算入僧團的人數之中，比丘一旦犯重戒之後，就和從前未受具足戒時沒有差別，所以說『不得共住如前』。唯恐有人懷疑不會重複犯戒，所以說『後亦如是』。」

【533-0005】02_戒疏/08d_卷二下之一#131
【原文】【記】他解中。大同上解，唯「如前」義別。謂犯重非數，與本未具無異，故云「如前」。
【譯文】【記文】其他論師的解釋中。大體上與前面的解釋相同，唯有對「如前」的含義解釋不同。認為犯了重罪就失去僧數資格，與原本未受具足戒時沒有兩樣，所以說「如同從前」。

【533-0006】02_戒疏/08d_卷二下之一#132
【原文】【疏】問：「此律重犯，隨作不輕，何故《僧祇》『學悔人犯，止但吉羅，亦應驅出』者？」
【譯文】【疏文】提問：「本律對於重複犯戒，隨每次造作都判重罪而不減輕，為什麼《僧祇律》說『正在行學悔法的人如果犯戒，只判突吉羅罪，但也應當驅逐出僧團』呢？」

【533-0007】02_戒疏/08d_卷二下之一#133
【原文】【疏】答：「義同文異也。《律》中犯重，有行悔者，猶在僧中，說戒、自恣異於沙彌，故同夷罪。如打犯重，還結波逸提。《僧祇》輕者，就不足為言。故《十誦》云：『與學悔沙彌尼安居中犯僧殘，聽比丘受日與摩那埵。若學悔沙彌，行婬、盜、殺、妄，還得波羅夷。』」
【譯文】【疏文】回答：「義理相同而文句不同。《四分律》中觸犯重罪的人，如果有在進行悔過修行的，依然留在僧團之中，其說戒、自恣都與沙彌不同，所以等同判波羅夷罪。如同毆打犯重罪而行悔的比丘，仍然要結波逸提罪。《僧祇律》判為輕罪，是就其不能算作合格僧數而言。所以《十誦律》說：『曾犯重罪而領受學悔法的沙彌尼，若在夏安居中又犯了僧殘罪，聽許大僧比丘受日出界前往為其授予摩那埵悔罪法。如果行學悔法的沙彌，造作行淫、偷盜、殺人、大妄語，依然得波羅夷罪。』」

【533-0008】02_戒疏/08d_卷二下之一#134
【原文】【記】問異部中。《四分》、《僧祇》，重不重別，計非相比。欲顯二宗之意，故此問之。答中。初句通示。學悔預眾，而不足數，彼此皆爾，故曰「義同」。重犯結罪，夷吉重輕，故云「文異」。「律」下，別釋。初明本部重結，別下眾故，引例可知。次釋《僧祇》犯輕，簡堪足故。下引《十誦》示之。先明「不重」唯約初篇，僧殘已下，例有重犯。「若」下，次顯初篇亦有重義。謂同名之罪有重犯，如前婬後殺等；同種之罪不重犯，如前盜後復盜等。
【譯文】【記文】詢問不同部派的文段中。《四分律》與《僧祇律》對於是否重判的差別，本來就不能一概而論。為了顯示這兩個部派的深意，所以在此提出詢問。回答之中。第一句通盤說明。行學悔法的人參與大眾，卻不能計入僧數，兩部律都是如此，所以說「義理相同」。重複犯戒的結罪，有波羅夷重罪與突吉羅輕罪的差別，所以說「文句不同」。從「律」字以下分別解釋。首先說明本部律重複結重罪，是為了與下眾（沙彌等未受具者）有所區別，引用事例可以明瞭。接著解釋《僧祇律》判罪較輕，是因為簡別其不具備僧數資格。下面引用《十誦律》來顯示。先說明「不重複結罪」只局限於初篇，僧殘罪以下，照例都有重複結罪。從「若」字以下，接著顯示初篇也有重複結罪的含義。也就是指同名但不同事的罪會重複結罪，如前面行淫、後面殺人等；若是同一種類的罪則不重複結罪，如前面偷盜、後面又偷盜等。

【533-0009】02_戒疏/08d_卷二下之一#135

【533-0010】02_戒疏/08d_卷二下之一#136
【原文】【疏】答：「初篇斷頭之罪，疑謂一犯後不重科，須安『後亦』。殘是有餘，無疑不著。」
