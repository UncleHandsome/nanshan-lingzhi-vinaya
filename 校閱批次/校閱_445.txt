# 校閱材料　第445檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【445-0001】資持記/06b_中一上#22
【原文】文下，示略。《義鈔》、《戒疏》，其文甚廣。而下，示尼。統論八篇，一夷殘單墮提舍，多少異也；二不定，有無異也；三捨墮眾學滅諍，彼此竝同，故云通戒。問答中，初問有二，前問五七離合；今下，問六七離合。前云約義差分，故今問顯。答中，初文，前示五篇。
【譯文】從「文」字往下的文段，標明在此從略。《義鈔》與《戒疏》中，相關文獻記載得極為詳盡。從「而」字往下的文段，說明比丘尼戒的情形。統籌論述八篇戒法：第一，波羅夷、僧殘、單墮、提舍尼這四篇，男女二眾在條數多寡上有所差異；第二，不定戒，男女二眾在有無上有所差異；第三，捨墮、眾學、滅諍這三篇，雙方則是完全相同的，所以稱為「通戒」。在問答環節中，第一個問題包含兩層意思：前半段詢問五篇與七聚之間的分合關係；從「今」字往下的文段，則是詢問六聚與七聚之間的分合關係。前面提到是依照義理的不同來加以劃分，所以現在透過問答來闡明顯現。在回答中，第一段文字首先標明五篇。

【445-0002】資持記/06b_中一上#23
【原文】問：篇名本出《僧祇》，題中標云篇者；乃目他宗，非關本部。答：五法本同，立名乍異；今借彼名，以標本部；況篇聚義通，隨用無在故也。其下，明聚。下文即諸犍度中，或六或七，間列不定。別釋中，初科可解。入五中者，《僧祇》、《四分》，篇聚異名，昔多偏計；
【譯文】問：篇的名稱原本出自《摩訶僧祇律》，題目標題稱作「篇」；那是標示其他宗派的名詞，與本部律典沒有關聯。答：五篇所包含的法體本來相同，只是安立的名稱暫時有異；現在借用彼宗的名相，來標示本部律典；何況篇與聚的義理本來相通，隨宜使用並沒有任何妨礙。從「其」字往下的文段，說明「聚」的涵義。下文即指各個犍度之中，有時列為六聚，有時列為七聚，其間並穿插列出不定戒。在個別解釋的段落中，第一科很容易理解。所謂「歸入五篇之中」，《僧祇律》與《四分律》中篇與聚的名稱雖然相異，過去的人多有偏頗的計著；

【445-0003】資持記/06b_中一上#24
【原文】今但云五，無所局也。下亦合云，通入七攝；而云聚者，順今宗也。次科。六據體同者，前云：正結罪科，止有六法故。七約過多者，吉羅罪眾，量等塵沙；隨具兩分，簡易可識故。次問中。猶恐新學昧彼名數，委曲提示，慈念之深矣。下指《戒疏》，文見第一；
【譯文】現在只籠統稱為「五」，就不受限於任何特定的宗派局限了。下文原本也應當說「通通歸入七聚所收攝」；此處卻說歸入「聚」，是為了順應本宗的習慣說法。下一科。所謂「六聚是依據法體相同而立」，如前文所說：真正結定罪名的科別，實際上只有六種法體而已。所謂「七聚是依據過失繁多而立」，是因為突吉羅罪極為繁多，數量等同於微塵細沙；隨順身口兩具將它分為惡作與惡說兩部分，這樣簡單容易讓人認識的緣故。在下一個問題中，唯恐初學者對那些名相條數感到昏昧，所以委曲詳盡地提點指示，這體現了祖師慈悲念慮的深厚。下文指出《戒疏》的說法，文句見於第一卷；

【445-0004】資持記/06b_中一上#25
【原文】彼問：吉羅既通方便，如何在篇？答：簡究竟者，以入篇中；餘方便者，入聚所攝。問：即應偷蘭，竝簡從生；取究竟者，用以入篇？答：不同也；偷蘭究竟，或均或雜，或前或後，難定其罪，大約分三，懺同墮位，故入聚收云云。後問中。五百之言，他文所出，與律不同；
【譯文】那裡發問：突吉羅既然通貫作為前幾篇的方便罪，為什麼能獨立列在一篇之中？答：挑選出那些屬於根本究竟的罪過，讓它歸入篇中；其餘所有的方便罪，則收攝歸入聚中。問：那麼偷蘭遮罪，也應該通通簡別剔除其從屬伴生的微罪；只選取根本究竟的罪過，用來歸入篇中嗎？答：情況並不相同；偷蘭遮的根本罪，有時均等，有時雜駁，有時居前，有時居後，極難判定其罪位，大約區分為三品，其懺悔法位階等同於波逸提，所以一概收歸於聚中等等。在最後一個問題中，「五百戒」的說法出自其他文獻，與律典所載不同；

【445-0005】資持記/06b_中一上#26
【原文】故問以審之。答中，初文為二，初示數不定。約，即略也。通言，即僧尼兩數。論下，次顯略所以，初通明體量。且下，別示兩數，初明僧戒。蹊徑即小路。律下，示尼戒。戒是能防，過是所防，戒通過別；從別為言，故云所防。
【譯文】所以特別提出質問來加以審核辨明。在回答中，第一段文字分為兩個部分，首先標示條數並非固定。「約」就是簡略的意思。「通言」是指男女二眾合併計算的條數。從「論」字往下的文段，其次顯發簡略說明的緣由，首先通泛說明戒法的總體份量。從「且」字往下的文段，分別標示男女二眾的條數，首先說明比丘戒。「蹊徑」就是狹窄的小路。從「律」字往下的文段，標明比丘尼戒。戒法是能防範的主體，過失是所防範的對象，戒法通於各條而過失則各自不同；從各別過失的角度來說，所以稱之為「所防」。

【445-0006】資持記/06b_中一上#27
【原文】次釋通中，彼云：略則八萬四千，廣則無量無邊，今對上五百，且以八萬為廣；望下無量，還成略耳；既無數量，則知五百，言非虛矣。二犯報中。先明起業者，欲明苦果，須考業因。況造業萬差，何由一揆；如下引經，墮獄年劫；且據制罪，一往以分；自有犯輕而報深，不妨犯重而報淺；
【譯文】接著在解釋通說的段落中，彼論說：簡略而言有八萬四千，廣泛而言則無量無邊，現在對比上面的五百條，暫且以八萬四千作為廣說；但若對望於下文的無量無邊，這八萬四千反而又成為略說了；既然戒法本就沒有固定的數量，就可知說「五百戒」這句話，絕非毫無根據的虛言。在第二「犯報」的段落中。首先說明起造業力的根源，是因為若想明瞭痛苦的果報，必須先考察造業的因由。何況眾生造業有萬般差別，哪裡能用同一標準來衡量；如同下文引用的經文，墮入地獄的年限與劫數；暫且只是依據佛陀制定的罪名，大致劃分其期距；往往有人違犯了輕罪卻承受極深的果報，也不妨礙有人違犯了重罪卻受較淺的果報；

【445-0007】資持記/06b_中一上#28
【原文】須推能造所起不同，善惡報應，絲毫不昧。是知化制兩教，辨業天乖；制則從教重輕，化則論心濃薄；教唯揩定，緣具則例入刑科；心既不常，動發則須分體性；因果既異，化制斯分。必昧宗途，未窮業本；故先料簡，委示來蒙。初文，前示業本。業無自性，必假緣生；
【譯文】這必須推究能造業的心念與所引發的事相各不相同，善惡的因果報應，絲毫都不會產生差錯。由此可知化教與制教這兩大教門，在辨析業力時有著天壤之別；制教完全依照佛陀教法來判定罪行輕重，化教則是論究造業心念的深厚與微薄；教規只依據客觀標準來裁定，條件具足就一律判入刑責科別之中；但人的心念既然生滅無常，發動造業時就必須區分其自性與體質；既然因果各有不同，化教與制教的界線便由此劃分開來。如果對宗門途徑產生昏昧，就無法窮究業力的根本；因此必須先進行剖析簡擇，詳盡指示給後來的學者。第一段文字中，首先標示業力的根本。業力沒有固定的自性，必定要藉由因緣才能生起；

【445-0008】資持記/06b_中一上#29
【原文】緣雖眾多，不出心境；由境發毒，構造成業；境是外緣，毒從內發；故明起業，惟推三毒。毒從我生，我即妄計；即斯妄計，是業之本，故名妄業；經云：一切業障海，皆從妄想生。諦求妄本，畢竟無依；但是一心，隨緣不覺；以不覺故，硜然計我；由我起毒，因毒生業；
