# 校閱材料　第767檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【767-0001】02_戒疏/17c_卷四上之二#70
【原文】【註】尼同犯。不犯者：一宿受；病，過受食；若居士請住，「我為沙門釋子故設此食」；若檀越次第請食；若兒、女、妹、婦次第請；或今日受此人食，明日受彼人食；若道斷等難者。
【譯文】【註文】比丘尼犯同樣的罪。不犯戒的情況有：只住宿一晚接受供食；因生病而過度受食；居士主動挽留說「我是專為了釋迦沙門佛子才設辦這份飲食的」；施主依序逐日迎請用餐；或者是居士的兒子、女兒、妹妹、妻子分別依序迎請；或者今天受這位施主的飲食、明天受另一位施主的飲食；以及遇到道路中斷等危難阻礙的情況，均不犯戒。

【767-0002】02_戒疏/17c_卷四上之二#71
【原文】【疏】戒本三句：初施一食處，有比丘者，是人也；二、無病緣應受，此是犯人；三、過受，結犯。
【譯文】【疏文】戒本條文可分為三句：第一句是「只布施一餐的住處，有比丘在那裡」，這是說明主體人物；第二句是「沒有生病等因緣應當受一餐」，這是指犯戒的人；第三句是「過度接受」，結定犯罪。

【767-0003】02_戒疏/17c_卷四上之二#72
【原文】【記】戒本，分文。初句合「人、處」者，欲明是受施人，非犯人故。然前後分句開緣、結犯，或分不分，隨時不定。述作之體，義非專固，抑恐封文，學者須曉。次句，注中，「劇」字訓甚。
【譯文】【記文】戒本條文的分段劃分。第一句將「人物、處所」合併而言，是為了說明那是接受布施的人，並非一定是犯戒的人。然而前後分句中將開許因緣、結定犯罪，有時分開、有時不分，是因應當時行文體裁而定，並不固定。撰述著述的體例，義理本來就不是死板固執的，因為擔心後人拘泥於文字，所以修學的人必須明瞭。第二句在戒本註中，「劇」字解釋為病重、嚴重。

【767-0004】02_戒疏/17c_卷四上之二#73
【原文】【疏】此中明正食與非正俱結。故文中明「除食已」，得「衣、油」犯輕者。食資身急，人並喜受，又受用交盡，損惱施主故重。餘之衣、油，得用，不得將去。縱有燈油，身外受用微少故輕。
【譯文】【疏文】此處說明正食與非正食，過度食用都同樣結定犯罪。因此文中明確指出「除了日常飲食之外」，若獲得「衣服、燈油」則判罪較輕。飲食是維持身體生命最急迫的，每個人都樂於接受，而且一經受用就完全消耗殆盡，極易損耗惱害施主，所以處罰較重。至於其餘的衣服、燈油，比丘可以使用，不能整件帶走。即使耗用了燈油，也屬於身外極微小的受用，所以處罰較輕。

【767-0005】02_戒疏/17c_卷四上之二#74
【原文】【記】牒釋中。初二句標判。下「背」、「別」局正食犯，恐濫同故。「故」下，次準注以決。既通除食，不簡正與不正，明知並犯。初牒注。「食」下釋通。初敘二食重，兩意通之。「餘」下，次釋衣油輕。初二句通明二物，下三句別示燈油。由有喜受、用盡之義，故約外資通之。注不犯中，「居士請住」等者，施意通故。「檀越次第」請者，日別一食，非過受故。「兒女」已下，竝異主故，亦非過也。
【譯文】【記文】在引述並解釋的段落中。前兩句標示定性判斷，因為底下的「背請戒」、「別眾食戒」局限於正食才算犯戒，唯恐後人混為一談。從「故」以下，接著依據注文來做決斷：既然註文通用「除飲食」，並不區分正食與不正食，顯然可知兩者吃了都算犯戒。一開始引述註文；從「食」以下解釋通達其理：先敘述正食與非正食這兩種飲食處罰較重，用兩種意理加以貫通；從「餘」以下，接著解釋衣服與燈油處罰較輕的原因：前兩句通論這兩樣物品，下三句特別指出燈油：由於燈油也有令人樂於受用、隨即消耗殆盡的特性，所以疏文以屬於身外資具（受用微少）來會通解釋。戒本註中關於不犯戒的情況，「居士請住」等語，是因為施主布施的心意是全面敞開的；「檀越次第」迎請，是指每天各受一餐，並不是在同一餐中過度受食；從「兒女」以下，因為都是不同的施主，所以也都不算過度。

【譯文】【律文】第三十二條、背棄前請戒。

【767-0008】02_戒疏/17c_卷四上之二#77
【原文】【疏】然信心俗士，供給美味，延請僧田，希存受用。今先許後違，是無信也，令他飲食徒設而已，無受用也。損惱之重，無過於此，故制。
【譯文】【疏文】深具信心的在家人，備辦美味飲食，迎請僧寶福田，無非是希望僧眾能前來受用。如今比丘先答應了卻又違背約定，這是失去信用；這會讓施主白白備辦了一桌飲食，無人享用。對施主造成的損耗惱害之深重，沒有比這更嚴重的了，所以佛陀制定此戒。

【767-0009】02_戒疏/17c_卷四上之二#78
【原文】【記】三十二，制意中。初敘施意。「今」下，明過制。「無信」即是自失，「無用」即損供施。若據戒緣，應兼長貪、招譏之過。文從別相，又易知，略不明耳。
【譯文】【記文】第三十二戒，在說明制戒用意中。首先敘述施主的發心；從「今」以下，指明過失而立制：「無信」就是比丘自己失德，「無用」就是損害了施主的供養布施。如果依照制戒緣起，還應當兼具助長貪心、招致譏嫌的過失；此處是順著個別的行相來說，而且顯而易見，所以略過不明說罷了。

【767-0010】02_戒疏/17c_卷四上之二#79
【原文】【疏】釋此戒名，諸部各異。《四分》，展前家食，轉就後家，故名也。《僧祇》云「數數食」，亦言「處處食」。《十誦》、《五分》、《多》、《伽》，並同「數數食」。《注戒本》名「背請」者，隨俗取解，亦無過也。
【譯文】【疏文】解釋這條戒的名稱，各大部派各不相同。《四分律》稱為「展轉食」，意思是指移轉了前一家的飲食，轉而奔赴後一家的飲食，因此得名。《摩訶僧祇律》稱為「數數食」（頻繁受食），也稱為「處處食」。《十誦律》、《五分律》、《薩婆多論》、《毘尼摩得勒伽》（《伽論》），都同樣稱為「數數食」。《戒本註》稱之為「背請」，這是順應世俗容易理解的話來命名，也沒有過失。

【767-0011】02_戒疏/17c_卷四上之二#80
【原文】【記】釋名中。初總引諸部。本宗獨異。《祇律》兩名並約緣起重食為言，《十誦》等律同上《僧祇》初名，語意大同，譯者隨立。「注」下，正示今文。「背請」之名，非出諸部，《僧祇》六念，乃有是言。自昔相傳，於義易顯，故云「隨俗」等。
【譯文】【記文】在解釋戒名的段落中。首先總結列出各部派的用詞，本宗的稱呼獨樹一幟。《摩訶僧祇律》的兩個名稱，都是依據緣起中連續重複受食的情節來立名，《十誦律》等律典則與上述《摩訶僧祇律》的第一個名稱相同，語意大體一致，端看翻譯者隨緣訂定。從「注」以下，正式指出《戒本注》的用語：「背請」這個名稱並非出自各部派律典，《摩訶僧祇律》在六念法中才有這種說法；由於歷代相傳已久，在義理上更容易顯豁，所以說「隨俗取解」等。

【767-0012】02_戒疏/17c_卷四上之二#81
【原文】【記】問：「何不依《律》而從俗者？」
【譯文】【記文】有人問：「為什麼不直接依照《四分律》本文，反而要順應世俗稱呼呢？」

【767-0013】02_戒疏/17c_卷四上之二#82
【原文】【記】答：「若依《律》名，攝相不盡。如背前向後，更往前家，可如諸律。若直背前，亦成正犯，則非『展轉』、『處處』等義。但云『背請』，理無不收。」
【譯文】【記文】回答：「如果依照《四分律》的原名，涵蓋的違犯行相不夠完全。如果是背棄了前一家奔向後一家，吃完後又前往前一家，那確實可以如同各部律典所稱。但如果比丘只是直接背棄前一家的邀請，就已經構成正犯，這就不是『展轉』、『處處』等詞所能涵蓋的意義了。只要稱作『背請』，在義理上就沒有不被收攬包容的。」

【767-0014】02_戒疏/17c_卷四上之二#83
【原文】【疏】論犯五緣：一、受犯五正食請，不問道俗、親非親；二、食體堪飽足；三、無因緣，謂病、施衣、功德月等；四、更受後請；五、隨咽即犯，不待飽也。
【譯文】【疏文】論述構成犯戒的五個條件：第一、接受了五種正食的迎請，不論施主是出家人還是俗人、是親屬還是非親屬；第二、食物的份量足以讓人吃飽；第三、沒有生病、布施衣物、做功德月等特定開許因緣；第四、又答應接受了後來的迎請；第五、每一口吞下隨即構成犯戒，不需要等到完全吃飽。

【767-0015】02_戒疏/17c_卷四上之二#84
【原文】【記】犯緣。第一，食局人通；二、食體堪飽，非喰飽故；三中，列示三開，並見下文。
【譯文】【記文】犯戒條件中。第一點，限定是五正食，但施主身分不拘；第二點，食物份量足以吃飽，不是指真的要吃飽；第三點中，列出三種開許條件，都見於下文。
