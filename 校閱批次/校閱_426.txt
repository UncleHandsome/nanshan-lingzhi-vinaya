# 校閱材料　第426檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【426-0001】資持記/08c_中二#35
【原文】無過有重者，準疏三十中四戒得重犯，浣衣、擔、擗、雨衣是也；文云語使浣染打，三尼薩耆故。《僧祇》。明湔洗。半洗曰湔。不下，示捨法。五中。《四分》明輕，皆謂非犯緣故。《善見》明重使，結二罪者，尼薩耆是前犯，吉羅即後罪，即犯捨衣無重義也。不犯三相。病是難緣，佛僧借他，皆非己物也。
【譯文】沒有過失卻有重犯的情況，依照疏文在三十條捨墮戒中有四條戒能重疊犯戒，洗衣、擔毛、打毛、雨衣戒即是；文中說只要開口命令洗、染、拍打，就結下三個尼薩耆罪。《摩訶僧祇律》說明「湔洗」。「湔」是指只洗滌局部的污處。「不……」以下，指示捨衣的方法。在第五點中。《四分律》中說明判輕罪的，都是指不構成正犯條件的情況。《善見論》說明重複指使、結下兩項罪愆者，尼薩耆是先前的重罪，突吉羅是後續的輕罪，這就意味著所犯捨墮的衣物不會再重複結罪。不犯戒的三種情況：患病屬於難緣，佛陀、僧團與借用他人，全都不屬於自己的私物。

【426-0002】資持記/08c_中二#36
【原文】第六。〔佛在舍衛，跋難陀為人說法，索所著衣，俛仰與之；單衣入城，俗譏因制。〕名中。簡親及道，皆非犯故。制意中，初文。一以多求則壞佛法；二由俗有上下，不必同心；三以求索過度，為人輕慢；四因覩少欲，信法尊勝。初是住持，中二滅惡，下即生善。
【譯文】「第六戒（向非親里居士乞衣戒）」。〔佛陀在舍衛國時，跋難陀比丘為人說法，隨後索取人家身上穿的衣服，施主勉為其難給了他；施主只穿著單衣走入城中，招致世俗譏諷，佛陀因而制定此戒。〕戒名。揀別親族以及出家同道，向這些人索取都不算犯戒。在制戒深意中，第一小節：第一，貪婪多求便會敗壞佛法；第二，世俗之人有貧富尊卑，心意不可能完全相同；第三，索求過度會招致世俗輕賤鄙視；第四，世人看見出家人少欲知足，才會深信佛法尊貴殊勝。第一點是為了護持正法住世，中間兩點是為了滅除惡名譏嫌，最後一點則是為了生發善心。

【426-0003】資持記/08c_中二#37
【原文】次科，論引昔緣，初敘現業。命下，生報。駱駝山者，形大背高，有如山焉。佛告下，明聖誡。比丘之法，少欲為本。貪求不厭，未殊鄙俗。況講法談禪，身當眾首；非唯自陷，抑誤後生；請詳上緣，仍思佛誡。自非木石，寧不動心哉。又下，約施明制。乞字去呼，與也。好非好者，謂持毀也；此句即彼問辭。
【譯文】下一小節，論典引述往昔的宿世因緣，先敘述現世造作的惡業。「命……」以下，敘述死後的果報。所謂「駱駝山」，是指身體龐大、脊背高聳，宛如一座大山。佛告以下，明示聖者的訓誡。比丘的修行法則，以少欲知足為根本。貪求無厭，便與粗鄙的俗人毫無二致。何況是講經說法、談玄論禪之人，身為大眾表率；這樣做非但陷自己於沈淪，更耽誤誤導了後學晚輩；請詳察上述因緣，切實深思佛陀的告誡。只要不是木石無情之物，難道能不動心警惕嗎？「又……」以下，依據布施者的角度來闡明制戒用意。「乞」字讀去聲，是給予的意思。所謂「好與不好」，是指持戒者與毀戒者；這句話正是施主的問話。

【426-0004】資持記/08c_中二#38
【原文】實犯墮者，自述德故〔同下勸增〕。不實犯棄者，即盜取故。若貪下，約開明急，曲濟貧乏；復制中後不自手捉，知意急矣。注中謂形同無戒，猶類淨人；有戒法同，制同上眾。犯緣第一。注中上明直乞，下明為衣乞穀，情容諂故。五穀者，黍稷菽麥稻也。二中，初示緣相。非下，遮簡。
【譯文】實有修行而自稱說自己功德者犯捨墮罪（如同下文的勸請增資）。若並無實德卻妄稱，則犯波羅夷（棄）重罪，因為這屬於盜取供養。「若貪……」以下，從開緣的角度顯現戒律的嚴切，雖然曲意周濟貧乏；但又規定午後不得親手觸摸拿取，足見其防範之心的嚴急。注文中說形相如同尚未受戒，猶類似淨人；若已有戒法相同，制約條例便等同於具戒大僧（上眾）。犯戒條件第一點。注文中前半說明直接向人乞討，後半說明假借衣物之名乞討糧穀，心態容易夾雜諂媚。所謂「五穀」，是指黍、稷、豆、麥、稻。在第二點中，首先展示犯緣的相狀。「非……」以下，加以阻斷揀別。

【426-0005】資持記/08c_中二#39
【原文】恐謂迦提開乞無犯，故特示之。必下，通許。此謂實無，微通濟急，非教所開。交，俱也。限約所須，故云隨量。第三。律論三相，據親無過，約惱故吉。論云：親里多財，從乞無犯；今以貧匱惱他，索多無足，雖親亦罪。匱乏也。四中，兩緣合示。十祇文中，初明應量。謂此戒犯量非定三衣。
【譯文】唯恐有人認為迦提月期間開許乞討便無罪，所以特別指出這一點。「必……」以下，予以通融允許。這是指確實一無所有，稍微通融以解燃眉之急，並非教法原本的開緣。「交」就是「全都」的意思。限度局限於維持生存所需，所以說是「隨量索取」。第三點。律典與論典提出三種相狀，依據親屬而言本無過失，但若因索取造成惱害，便結突吉羅罪。論典說：親戚資財豐厚，向其索取無罪；如今因索求過甚而使貧乏者生惱，要得太多不知滿足，即便是親戚也構成罪過。「匱」就是匱乏貧困。在第四點中，兩條因緣合併說明。《十誦律》與《摩訶僧祇律》文中，首先說明「應量」標準。這是說本戒構成犯罪的份量，並不限定於完整的三衣。

【426-0006】資持記/08c_中二#40
【原文】四肘計七尺二寸。若下，釋為己。文列四相，皆為邪求。除下，明開乞。繫頭物，舊云帽帶巾帊之類。緣中一條，謂三衣揲緣。若下，明乞小得大。開遮可見。緣開中，初緣起。佛下，示法。次第四開，初取己長，二借他物，後二並僧物。可分衣即十方現前物；僧衣者，常住常住物。
【譯文】四肘折合為七尺二寸。「若……」以下，解釋「為自己」求取。文中列出四種情況，全都是出於邪心求索。「除……」以下，說明開許乞討的特殊情形。「裹頭物」，古稱帽子、綁帶、頭巾手帕之類。邊緣的一條布，是指三衣縫邊加固用的布料。「若……」以下，說明乞求少量卻獲得大量的情形。其中開許與禁止的分界極為分明。在開許的因緣中，首先敘述因緣生起。「佛……」以下，宣示作法法度。依次有四種開許：第一是取用自己的長衣，第二是借用他人的物品，後兩種都是借用僧團公物。所謂「可分衣」，就是指十方現前僧眾的物品；「常住僧衣」，則是指寺院固定常住的共有物。

【426-0007】資持記/08c_中二#41
【原文】若得下，明還法。如法治者，不復本處，違制吉羅；若取入己應重。〈雜篇〉廣示遇賊法，故此指之。不犯中，初正示開緣，前五緣中。本宗四種，文闕燒漂。此五反上第二緣。律下，次五取中。上三反第四，下二反第三。次《五分》下，明能所俱犯。
【譯文】「若是獲得……」以下，說明歸還的方法。所謂「如法治罪」，是指事後不歸還原處，便違背戒制結突吉羅罪；若是擅自佔為己有，罪過便應加重。〈雜篇〉中詳細指明了遭遇盜賊後的補救辦法，所以此處僅作指引。在不犯戒條款中，首先正面指出開許的因緣，在前五種因緣中。本宗列舉了四種，文字中缺漏了火燒與水漂。這五種因緣正好反顯前面的第二種犯戒因緣。「律中……」以下，在隨後的五種取法中。上三種反顯第四犯緣，下二種反顯第三犯緣。其次「《五分律》……」以下，說明接受者與施予者雙雙犯戒。

【426-0008】資持記/08c_中二#42
【原文】上句明受施者，謂行邪諂乞求他施，正犯此戒。下句即能施人，謂不擇前境而故與之，為施所墮。上局比丘；下通道俗，道應輕罪，俗必成業。即〈興治〉中二俱為施所墮是也。第七。〔佛在舍衛，比丘失衣；有信居士多送衣與比丘，言不須；六群令取持與我更受，因制。〕戒名。
【譯文】上一句說明接受施捨者，是指以邪心諂媚向他人索求施捨，正是本戒的正犯。下一句即是能布施的人，是指不加揀擇受者的品行而執意給予，因而一同墮入盲目布施的罪咎。上一句局限於比丘；下一句則通達道俗兩眾，出家人應結輕罪，俗人則必定造下罪業。這就是〈興治篇〉中所說的「受與施雙方一同墮落」的情形。「第七戒（過量索衣戒）」。〔佛陀在舍衛國時，有比丘失落了衣物；有正信的居士送來許多衣服給比丘，比丘推辭說不需要；六群比丘卻唆使他拿下來轉交給自己，佛陀因而制定此戒。〕戒名。

【426-0009】資持記/08c_中二#43
