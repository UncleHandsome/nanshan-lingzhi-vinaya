# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【602-0001】04_比丘尼鈔/04a_卷中之下#10
【原文】離衣宿戒具六緣一是己五衣二受法三人衣異處四不捨會五無因緣六明相出犯人衣異有四種不同一者染礙謂同界有男子者名為染礙故律云諸比丘脫衣服人家形露佛言除村村外界故知村不攝衣名為染礙二者隔礙此律若水陸道斷等離衣不犯三者情礙此律若失奪想惡獸命梵難緣等失衣無犯婆論云王來入界住宿大小行在近處並非衣界以情隔故四者界礙此律自然衣界有十一種一伽藍二村界三樹界四場界五車界六船界七舍界八堂界九庫界十倉界十一蘭若界前中伽藍及村二界各有四相成者不名多界為僧村二界義強襵前九界便成一界若此四相不圓者諸界並生便有十一界起故律云若干界四相一周帀垣墻二籬柵不周三籬牆不周四四周有屋此律云十一界各加勢分更有十三步故律云以中人擲石所及處是見論云中人者取不徤不羸人盡力擲至落處不取轉處若置衣在十一種界內身在界外宿若不捨會不至擲石所及處明相出一一犯捨墮若界內有男子持衣須近身不爾明相出犯捨以無勢分故又餘部衣界有四一道行者十誦云與師持衣道中行前後四十九尋內不失衣婆論云縱橫四十九尋內不失衣二洲上界者見論云水洲上十四肘內不失衣若有人來往衣須近身不爾失衣三水界者見論云比丘在阿蘭若處夜入池中浴未竟明相出犯捨母論云一脚在岸一脚入水雖經明相不失衣四井界者僧祇云道行露地井闌旁宿諸衣在二十五肘內身在外宿者失衣或置衣井內身在上宿不以繩連或不垂手脚經明相出皆犯明了云道行夜宿錯持衣去他衣不失己衣失也。
【譯文】離衣宿戒具備六個條件即構成犯罪：一是自己的五衣；二是已作受持法；三是人與衣服處在不同界內；四是未作捨棄或會同羯磨；五是無特殊緣故；六是黎明天明破曉時即構成犯罪。人與衣服分離的情況有四種不同：第一是染礙，指同一界內有男子存在稱為染礙，所以律中說諸比丘在人家中脫去衣服露出形體，佛陀說除村落外、村外另立界，由此可知村落無法攝持護衣，故稱為染礙。第二是隔礙，依本律規定，若是水路陸路阻斷等原因而與衣服分離，不犯戒。第三是情礙，依本律規定，若是誤以為遺失被搶、遭遇惡獸威脅、危及生命或梵行等危難因緣而失去衣服，無犯；《薩婆多論》說，國王前來界內留宿，其大小便溺之處附近，都不能算作護衣之界，因為心存敬畏隔閡之故。第四是界礙，本律規定自然衣界有十一種：一僧伽藍界、二村界、三樹界、四場界、五車界、六船界、七舍界、八堂界、九庫界、十倉界、十一阿蘭若界。前述之中的僧伽藍界與村界，各有四種外相成就者，就不算作多個零散小界，因為僧界與村界的範圍效力強大，包攬整合了前面的九種界，便歸併成一個大界；如果這四種外相不圓滿，各小界就會各自成立，便會出現十一種界同時並存。因此律中說：若干種界的四相包括：一周圍有完整圍牆；二籬笆柵欄不周全；三籬笆圍牆不周全；四四周皆有房屋。本律說：這十一種界各加上周圍延伸的勢分界，另有十三步的距離；因此律中說：以中等人扔擲石頭所能達到的距離為準。《善見論》說：所謂中等人，是指體力既不強壯也不贏弱之人，用盡全力擲石，以石頭落地之處為界，不計滾動到的地方。若將衣服放在這十一種界內，自己卻在界外留宿，若既不捨衣也不作會同，且未到達擲石所及的勢分之內，只要黎明天明破曉，一一都犯捨墮罪。如果界內有男子，持衣者必須讓衣服靠近身邊，若不如此，天明破曉時即犯捨墮，因為此時已失去了勢分範圍。此外，其餘部派的衣界還有四種：一是道行界，《十誦律》說與師父持衣在道路中行走，前後四十九尋之內不算失衣，《薩婆多論》說縱橫四十九尋之內不失衣；二是沙洲之界，《善見論》說水中小洲十四肘之內不失衣，若有人來往走動，衣服必須貼近身體，否則即算失衣；三是水界，《善見論》說比丘在阿蘭若處夜間入池中沐浴，未洗完天明破曉即犯捨墮，《母論》說一腳在岸上一腳入水，即使經過破曉也不算失衣；四是井界，《僧祇律》說在路上露天水井的井欄旁過夜，若眾衣在二十五肘之內而自身在界外留宿者算失衣，或者把衣服放在井內而自身在井上留宿，不用繩子牽連、或不垂下手腳相接，經過天明破曉者都犯戒。《明了論》說：行路夜宿時誤拿他人衣服離去，他人的衣服不算失去受持，自己的衣服則算失去。

【602-0002】04_比丘尼鈔/04a_卷中之下#11
【原文】畜寶戒具四緣犯一是錢寶二知是三為己四受取犯寶是八不淨財中一數盛辨八不淨物名通經論一是田宅二種植園林三畜積鹽粟四畜奴婢五養羣畜六貯金銀錢七為金銀鏤牀錦褥氍毹八銅鐵釜鑊若畜此八皆長貪壞道汙染梵行又得穢果故名不淨次明開畜得否者第一田宅一向無開唯小房一口資身長道別人開不犯五分云有人施僧田宅店肆佛言聽受使淨人知第二園池者別人不許受見論云居士以池施僧供給浣灌及眾生飲用得受第三畜積鹽粟者僧祇云若比丘糴時作是念此後時恐貴今糴此粟當依是得誦經坐禪行道者得婆論云若比丘得穀米等即日應作淨若無白衣時四眾邊作淨若不作淨至地了時作吉懺第四畜奴婢者僧祇云若人施僧供給女淨人聽受若施別人一切不得若施淨人為料理僧故別人得受第五養羣畜者僧祇云一切眾生不應受自餘野鳥獸等若不受者我當殺之語言汝自求水草守護勿令傷害不得剪翅羽籠繫若能飛行自活者放去莫拘縶之日藏分經云佛言大王於我法中有諸比丘假令如法始從一人乃至四人我不聽受田宅園林象馬奴婢等常住僧物若滿五人乃可得受遺教法律云騎乘車馬一日除五百日齋福一歲三百六十日乘除十八萬日齋福舍利弗問經何故比丘乘騎除五百日齋福者佛言比丘知禁律人他見生謗令他得罪除老弱暫乘得第六畜金銀錢者僧祇云若居士施金銀為衣直得受不得自手取使淨人知無淨人者指脚邊地語言是中知著地己自用草葉甎瓦等遙擲覆上將人令知持去若知佛有金銀欲舉者若是生地應教淨人知己作坑內錢置中若散落者得自提甎瓦擲錢使入得自填上僧祇十誦善見云若病兒得金銀錢令淨人畜為貿藥故若多人與藥直得置氈褥底眼暗求時手觸無犯第七金銀鏤牀錦褥氍毹者母論云別人聽受刻鏤大牀唯除金銀不犯此律氍毹廣三肘長五肘毛長三指聽受應淨施畜第八銅鐵釜鑊者母論云瓦缾銅盆銅盔種種等器佛聽別人得受是論云若施器使僧應打壞不得賣若樂器不得捉得賣僧祇云若四月八日大會供養時金銀塔及菩薩像幢供養具等有金銀塗者使淨人捉若倒地者助捉無金銀處若塗徧者以物裹手捉不得先提後放僧祇云受寶物者若身分乃至手脚繫僧伽梨鉢中皆犯此律若受金銀者決定非我沙門釋子法五分云當知是人必定不信我之法律。
【譯文】蓄積寶物金錢戒具備四個條件即構成犯罪：一是金銀錢寶；二是明知是寶物；三是為了自己；四是接受收取便犯戒。金錢寶物屬於八種不淨財之一，其廣泛論述於經論之中，名為八種不淨物：一是田產房屋；二是種植果園林木；三是囤積鹽與穀粟；四是蓄養奴婢；五是豢養各種牲畜；六是儲藏金銀錢財；七是製造雕花金銀床、錦繡褥子與毛毯毛席；八是銅鐵釜鑊鍋具。如果蓄積這八種東西，都會滋長貪心、敗壞道業、染污清淨梵行，又會招感污穢的惡果，所以稱為不淨物。其次說明是否開許蓄積：第一種田宅，一概不開許個人蓄積，只有一間小僧房以維持生命、增長道業者，由個別僧人開許居住不犯；《五分律》說：有人布施僧團田宅店鋪，佛陀說准許接受，並交由淨人掌管照料。第二種園林池塘，不准許個人接受；《善見論》說：居士以池塘布施僧團，供浣洗、灌溉及眾生飲水之用，准許接受。第三種蓄積鹽與穀粟，《僧祇律》說：若比丘買糧食時心想：『之後恐怕會漲價，現在買下這穀物，可藉此安心誦經、坐禪、修道』，這樣可以開許；《薩婆多論》說：若比丘得到穀米等糧食，當天就應當作淨法，如果沒有白衣，就在出家四眾前作淨法，如果不作淨法，到了天明破曉時，須作突吉羅罪的懺悔。第四種蓄養奴婢，《僧祇律》說：若有人布施女僕、淨人給僧團以侍奉僧眾，准許接受；若布施給個別比丘，一律不得接受；若布施淨人是為了照料僧眾事務，個別比丘得以接受。第五種豢養牲畜，《僧祇律》說：一切眾生都不應接受，其餘野生鳥獸等，如果施主說：『若不接受，我就殺了牠』，應告訴他說：『你自己去尋求水草照看守護牠，切莫傷害牠。』不得剪除鳥獸羽翼或關進籠子拴住，如果牠能飛行自主生存，就應放生，切莫拘禁羈絆。《日藏分經》說：佛陀說：『大王！在我的戒法中，有些比丘即便合乎戒規，只要人數從一人到四人，我都嚴禁其接受田宅、園林、象、馬、奴婢等作為常住僧物；必須滿五人以上，才准許接受。』《遺教法律》說：騎乘車馬一天，折損五百天的持齋福德；一年三百六十天連續騎乘，折除十八萬天的持齋福德。《舍利弗問經》說：為什麼比丘騎乘要扣除五百天的持齋福德？佛陀說：比丘是知戒受律之人，他人看見容易心生毀謗，致使他人獲罪；除年老體弱短暫騎乘可免咎。第六種蓄積金銀錢財，《僧祇律》說：若居士布施金銀作為購買衣服的價款，准許接受，但不得親手拿取，應讓淨人知曉掌管；若無淨人，可用手指著腳旁的地面告訴居士說：『放在這裡便知』，居士放在地上後，自己可用草葉、磚瓦等從遠處丟擲覆蓋在上面，然後帶淨人前來指認拿走；若知道佛前有金銀需要收起，若是未經加工的金銀原礦，應指示淨人知曉後挖掘土坑埋入其中，若散落滿地，可以親自拿磚瓦丟覆在錢上，並親自填平土石；《僧祇律》、《十誦律》、《善見論》說：生病的小沙彌若得到金銀錢財，應讓淨人代為保管，以便換取藥品；若有多人提供醫藥費，可放在毛氈被褥底下，眼花摸索尋找時手觸碰到，不算犯戒。第七種雕鏤金銀床及錦褥毛毯，《母論》說：個別僧人准許接受雕刻精美的大床，但唯獨排除金銀質地者，方不犯戒；本律規定，毛毯寬三肘、長五肘、毛長三指者准許接受，但應透過展轉淨施法來蓄存。第八種銅鐵釜鑊，《母論》說：陶罐、銅盆、銅盔等種種器物，佛陀准許個別僧人接受；該論又說：若布施器物作為僧團公用，應將其敲損毀形使用，不得販賣換利；若是樂器，則不得拿持，但可賣掉變現。《僧祇律》說：若在四月八日佛誕法會供養時，金銀塗抹的塔、菩薩像、寶幢及供具等，應讓淨人搬持；若傾倒在地，可協助搬持沒有塗抹金銀的地方；若是通體塗滿金銀，須用布包住手來搬持，不可先抓取後隨意放置。《僧祇律》說：接受寶物者，無論綁在身上乃至手腳、僧伽梨大衣或缽中，全皆犯戒；本律說：若接受金銀者，斷然不屬於我釋迦沙門弟子的戒法。《五分律》說：當知這種人必定不深信受持我的戒律體系。

【602-0003】04_比丘尼鈔/04a_卷中之下#12
【原文】貿寶戒具五緣犯一是錢寶二相易三決價四為己五領受便犯此律以財物易錢寶故犯不論衣食也此戒貿易便犯不同販賣為利故買以還賣故得與白衣淨人不得與沙彌以同犯故。
【譯文】以物易寶戒具備五個條件即構成犯罪：一是錢財寶物；二是相互交換；三是議定價格；四是為了自己；五是接收領取即犯本戒。本律認為，用一般財物換取金銀錢寶即構成犯戒，不論換取的是衣物還是食物。此戒只要進行貿易互換即算犯戒，不同於為求利潤而先買後賣的販賣罪；因此可以將換得之物交給在家白衣或淨人，但不得交給沙彌，因為沙彌同屬出家眾，同犯此過。
