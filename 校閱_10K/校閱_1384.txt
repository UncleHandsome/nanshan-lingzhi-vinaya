# 校閱材料　第1384檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1384-0001】資持記/16d_下四#17
【原文】引律證者，即前《戒本》；既標污心，明須活境。二大小異。三身分異。四心境異。下引《僧祇、善見》，別證第三。隨處得罪，此約尼犯，分境重輕；若論比丘，一向成重。不犯中，初指本宗。律云：若有取與，及解救等觸，一切無欲心，不犯。次引他部。初是想差；若下，即急難。一切無著，顯上開意。
【譯文】引用律文作證，就是前面的《戒本》；既然標明是染污心，顯然必須是活的境界。二是年齡大小的差異。三是身體部位的差異。四是心境配合的差異。下文引用《僧祇律》、《善見律》，分別證實第三點。隨觸碰何處而得罪，這是依據比丘尼違犯而言，區分境界的輕重；如果論及比丘，一向直接結成重罪。不犯情形中，首先指出本宗之說。律中說：若有拿取給與、以及解救危難等觸碰，一切沒有欲心者，皆不犯。接著引述他部之說。起初是想念差錯；若以下，就是遇到緊急危難。一切毫無染著，正彰顯了上述開許之意。

【1384-0002】資持記/16d_下四#18
【原文】非無吉者，制非儀故。六八事成重戒。〔佛在舍衛，長者與偷羅難陀尼繫心，受長者捉手等，尼白佛因制。〕若比丘尼染污心知，男子染污心受，捉手〔一手尼腕〕，捉衣〔二身上衣〕，入屏處〔三〕，共立〔四〕，共語〔五〕，共行〔六上四並取難伴見聞處〕，身相倚〔七身得相及處〕，共期〔八得共行淫處〕，是比丘尼波羅夷，不共住。
【譯文】「並非沒有吉羅罪」，是因其不合威儀而結罰。第六條八事成重戒。〔佛在舍衛國，長者與偷羅難陀尼互生情執，比丘尼接受長者牽手等事，尼眾向佛稟白因而制戒。〕若比丘尼懷有染污心，明知男子懷有染污心，而接受其捉手〔第一，牽比丘尼手腕〕，牽衣〔第二，牽身上衣服〕，進入隱蔽處〔第三〕，共同站立〔第四〕，共同言語〔第五〕，共同行走〔第六，以上四事皆指缺乏同伴見聞之處〕，身體互相依偎〔第七，身軀能夠相及之處〕，共同期約〔第八，約定在能夠行淫之處〕，這位比丘尼犯波羅夷，不得共住。

【1384-0003】資持記/16d_下四#19
【原文】列緣第四，此戒必須八事滿足方犯，懺則不成。釋八事中，初文。對前《戒本》，可解。料簡有三。一男八男，謂人同異；一時八年，明時遠近；無次第者，犯通前後。不犯中，初開屏處。下下，簡後戒。即單提中，第八十六戒；律因六群尼，與男子入闇室，故制。
【譯文】列舉成犯因緣第四點，此戒必須八事完全具足方始構成違犯，若中途懺悔了前事，則不構成重罪。解釋八事之中，第一段文句。對照前面的《戒本》，即可明白。析辨考量有三種情況。一男子或八男子，是指作案對象為同一人或相異之人；一時或八年，說明時間的長短遠近；不分先後次第者，成犯通於前後順序。不犯之中，首先開許進入隱蔽處的情形。從「下」字以下，是簡別後一條戒。也就是單墮（波逸提）中的第八十六戒；律因六群尼與男子進入暗室，所以制戒。

【1384-0004】資持記/16d_下四#20
【原文】若比丘尼與男子共入闇室中者，波逸提。彼從譏過，不約染心故也。七覆藏他重罪戒。〔佛在舍衛，偷羅難陀尼妹，名坻舍偷羅，知彼犯夷，恐得惡名，道默然不言，後坻合休道方言，白佛因制。坻，音遲。〕若比丘尼，知比丘尼〔決了彼犯。〕，犯波羅夷；
【譯文】若比丘尼與男子一同進入暗室中，犯波逸提。那條戒是從招致外界譏嫌立論，不論是否有染污心之故。第七條覆藏他重罪戒。〔佛在舍衛國，偷羅難陀尼的妹妹名叫提舍偷羅，偷羅難陀明知妹妹犯了波羅夷，害怕獲致惡名，不向人說而默然不言，後來提舍休道還俗，偷羅難陀才說出，諸尼白佛因而制戒。坻，音同遲。〕若比丘尼，明知比丘尼〔確切明了對方違犯。〕，犯了波羅夷重罪；

【1384-0005】資持記/16d_下四#21
【原文】不自發露，不語眾人〔一二三人〕，不白大眾〔四人若過。〕；若於異時，彼比丘尼，或命過，或眾中舉〔為僧擯舉。〕，或休道，或入外道眾；後作是言：我先知有如是非〔於八夷中，隨有所犯。〕，是比丘尼波羅夷，不共住。犯緣中。覆重方犯，覆餘罪蘭。覆比丘提，覆下眾吉。犯中，初科，前引文示。
【譯文】自己不向外發露，不告訴眾人〔一、二、三人〕，不稟白大眾僧團〔四人或四人以上。〕；如果於其他時間，那位比丘尼或者命終，或者在僧眾中被揭發舉罪〔被僧伽擯除舉發。〕，或者休道還俗，或者墮入外道眾中；其後才說出這樣的話：我先前就知道有這樣的過非〔在八波羅夷中，隨其所犯的一種。〕，這位比丘尼犯波羅夷，不得共住。成犯因緣中。覆藏重罪方才成犯，覆藏其餘輕罪得偷蘭遮。覆藏比丘犯波逸提，覆藏下眾犯突吉羅。成犯之中，第一科，前面引述律文昭示。

【1384-0006】資持記/16d_下四#22
【原文】指懺罪中，即中卷〈懺篇〉；明十種緣，皆不成覆。《十誦》。被舉是法隔。狂亂即非心。《僧祇》。難緣開不成覆。捨心相應，謂捨棄不說之心。準下，次以義詳，初示合開。無記，謂睡眠遺忘等。後明成犯，須不善心。次科，簡所對人，有四別。非清淨者，初簡有犯不懺也。先知不肯者，次簡覆藏不說也。
【譯文】指引懺罪法中，就是中卷的〈懺篇〉；說明有十種因緣，皆不能構成覆藏罪。《十誦律》中：被僧舉發屬於羯磨法阻隔。狂亂失心則非本心。《僧祇律》說：危難之緣開許不算覆藏。捨心相應，是指存心捨棄而不說的心念。準照以下，接著以義理詳述，首先標示應當開許之處。無記心，是指睡眠、遺忘等狀態。其後說明構成犯罪，必須具備不善之惡心。次一科，簡別所面對的人，有四種差別。非清淨者，首先揀除有違犯卻不懺悔之人。先前知曉而不肯發露者，其次揀除覆藏不說之人。

【1384-0007】資持記/16d_下四#23
【原文】二俱有過，彼此皆成覆故。向犯者懺，有誠例故。識人名等者，三簡如實不妄。此通能所也。若前下，明一說。若彼下，明非覆。《十誦》，不得比丘者，四簡異眾。僧尼位別，不得對首；唯聽不識，咨請犯相耳。三中。乃至，略食後知，初夜說；初夜知，中後說等。委如〈釋相〉解。
【譯文】兩方都有過失，彼此都會構成覆藏的罪愆。向違犯之人懺悔，已有明確的教規案例。認識他人名字等語，第三是揀除必須如實而不虛妄。這通於能說與所說之人。如果前人以下，說明只說一遍的情況。如果彼人以下，說明不算覆藏。《十誦律》說不得對比丘說，第四是揀除不同眾別。比丘與比丘尼位階有別，不得對首發露；只聽許不知罪相者，向比丘諮詢求請犯相罷了。第三科中。「乃至」一詞，略指食後知情而在初夜宣說；初夜知情而在中夜、後夜宣說等。詳細內容如〈釋相篇〉中所解釋。

【1384-0008】資持記/16d_下四#24
【原文】不犯中有四。初是無心，下三並非意。八隨順被舉比丘戒。大略同僧中，故此不出。僧直犯提，尼須三諫不捨，方結重夷。已上八重，前四根本。後四枝條，女情偏重，故須特制，即限分不同戒也。僧殘篇十七戒。媒謗及諫，大約同僧。略示二條，餘希不出。第四言人戒。
【譯文】不犯情形之中有四條。第一條是無心之失，以下三條全都是非出於本意。第八條隨順被舉比丘戒。大致與比丘僧中相同，所以此處不另列出。比丘直接犯波逸提，比丘尼則必須經三度諫勸仍不捨棄，方才結成重波羅夷罪。以上八條重罪，前四條為根本大戒。後四條為枝條末節，女子情欲染念偏重，所以必須特別制定，這就是男女界限分齊不同的戒條。僧殘篇共有十七條戒。媒嫁、毀謗以及諫勸等戒，大致與比丘相同。此處略微標示兩條，其餘稀見者不另列出。第四條訴訟（言人）戒。

【1384-0009】資持記/16d_下四#25
【原文】〔佛在舍衛，有尼在蘭若處，有居士為於此作精舍，後尼捨去，居士兒即犁此處，諸尼往官所言訟，令官觸彼，因。〕若比丘尼，詣官言居士、若居士兒、若奴、容若作人〔上並所言之人〕，若晝若夜，若一念頃，若彈指頃，若須臾頃，是比丘尼犯初法應捨僧伽婆尸沙。〔初作便結，不同諫戒三法竟犯。〕緣中。
【譯文】〔佛在舍衛國，有比丘尼在阿蘭若處修行，有居士為了她在此建構精舍，後來比丘尼捨棄離開，居士的兒子便來耕犁這塊土地，諸尼便前往官府控告打官司，致使官府逮捕觸惱對方，因此制戒。〕若比丘尼，前往官府控訴居士、或是居士之子、或是奴婢、或是被容留者、或是雇工傭人〔以上皆是被控告之人〕，或者白天或者黑夜，或者一念之間，或者彈指之頃，或者片刻須臾，這位比丘尼犯初法應捨僧伽婆尸沙。〔初次作成便結罪，不同於諫戒要經三法白羯磨完畢才犯。〕成犯因緣中。
