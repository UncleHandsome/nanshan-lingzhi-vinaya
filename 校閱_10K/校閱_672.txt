# 校閱材料　第672檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【672-0001】02_戒疏/14b_卷三下之二#120
【原文】【疏】此毛體貴，無宜服用。虗損施物，增長貪結，又自營造，招譏障道，深妨本業。故所以制。
【譯文】【疏文】這種黑羊毛材質非常昂貴，實在不適合出家人穿戴服用。這會平白浪費施主的供養布施，助長內心的貪婪結縛，而且還要自己耗費心思經營製作，招致世俗的譏嫌、遮障聖道，嚴重妨害了出家人的修道本業。這就是佛陀制戒的原因。

【672-0002】02_戒疏/14b_卷三下之二#121
【原文】【記】制意。總括有六：一、虗費，二、長貪，三、經營，四、招譏，五、障道，六、妨業。對文可見。言「體貴」者，如下《僧祇》明之。
【譯文】【記文】制戒意旨。總括起來有六點：第一、平白浪費；第二、助長貪念；第三、經營造作；第四、招致譏嫌；第五、遮障聖道；第六、妨礙本業。對照原文便一目了然。所謂「材質昂貴」，在下文引述的《摩訶僧祇律》中有詳細說明。

【672-0003】02_戒疏/14b_卷三下之二#122
【原文】【疏】四緣成：一、純黑羊毛；二、作三衣，除作氈被、臥具，罪非此戒；三、為己；四、自作成犯。《僧祇》云：「諸比丘並作氈三衣、坐具，唯除漉水囊。乞毛眾多，為人所厭。又毛大貴，一兩須二三金錢。毛細輭，觸人眼睛不淚出。為人求故，或還或死，破人家業。故捨入僧。」
【譯文】【疏文】具備四種因緣構成犯戒：一、使用純黑色的羊毛；二、用來製作三衣袈裟，若是拿來做毛氈被子、寢具鋪墊，罪過則不屬於本戒所管；三、是為了自己使用；四、自己製作完成便構成犯戒。《摩訶僧祇律》說：「當時諸位比丘全都用羊毛氈來製作三衣法衣和坐具，唯獨過濾水囊除外。他們向俗人乞求大量的羊毛，令大眾感到非常厭煩。而且這種黑羊毛極其昂貴，一兩重就要兩三個金錢。毛質細緻柔軟，即使不小心觸碰到人的眼珠子，眼睛也不會痛得流淚。為了替比丘尋求這種珍貴毛料，俗人有時出遠門輾轉才能返家，有的甚至客死他鄉，導致許多家庭傾家蕩產。因此佛陀下令必須將所造之衣捨棄交給僧團。」

【672-0004】02_戒疏/14b_卷三下之二#123
【原文】【記】犯緣。第二點古迷名，故簡「氈被」。「非此戒」者，體是重物，理應得吉。《僧祇》下，引示制意，有二。初是自求，令俗生厭。「又」下，次倩他求，令彼破業。初明體貴，顯其難得。「為人求」等者，彼律估客婦告舍利弗言「我夫主及諸親屬，為求是毛故，或時還家，或死不還」等。此彰過重，故佛制之。
【譯文】【記文】在犯戒因緣中。第二點是針對古人混淆名詞而作的辨正，所以特別排除了「毛氈被褥」。「不屬於本戒」是指這類物品本質上也是重物，按理應當屬於突吉羅罪。《僧祇律》以下，引證以展示佛陀制戒的深意，共有兩層原因。首先是比丘親自乞求，引起俗人強烈的厭棄反感。「而且」以下，第二是央求他人尋覓，導致他人家庭破敗破產。前一段先說明材質極度珍貴，以凸顯其取得之艱難。「為了替比丘尋求」等語，是該部律中記載一位商人的妻子向舍利弗訴苦說「我的丈夫和各位親屬，為了解決比丘對這種黑毛的需求，有時歷盡艱辛才能回到家，有時甚至死在外地再也回不來了」等等。這充分彰顯了過失的嚴重性，所以佛陀才制定了嚴規。

【672-0005】02_戒疏/14b_卷三下之二#124
【原文】【註】佛在毗舍離。諸棃車子多行邪行，作黑毛氈，披體夜行，使人不見。六群比丘見，便故作之，棃車譏嫌。比丘舉過，佛因制戒。
【譯文】【註文】佛陀住在毗舍離國時。諸位離車子弟經常在外進行不正當的放蕩邪行，他們製作純黑色的羊毛氈衣，夜間披在身上外出潛行，好讓別人看不見自己。六群比丘看見之後，便故意仿效製作，遭到離車子弟們的譏刺嘲嫌。比丘們舉發他們的過失，佛陀因此制定了這條戒。

【672-0006】02_戒疏/14b_卷三下之二#125
【原文】【記】緣起中。「棃車」，即外道名。「邪行」，即彼外道法。「棃車嫌」者，濫同己故。
【譯文】【記文】在緣起之中。「離車」，就是印度的一支部族外道之名。「邪行」，就是指那群外道的浪蕩非法行徑。「離車子弟嘲嫌」，是因為比丘的穿著混淆得和他們自己一模一樣。

【672-0007】02_戒疏/14b_卷三下之二#126
【原文】【律】若比丘，以新純黑羺羊毛作新臥具者，尼薩耆波逸提。
【譯文】【律文】如果比丘，使用未經混雜的全新純黑小羔羊毛製作新的大衣臥具，犯尼薩耆波逸提（捨墮罪）。

【672-0008】02_戒疏/14b_卷三下之二#127
【原文】【註】自作、教他、為他，犯相並如前戒。尼突吉羅。不犯者：若得已成者；若割裁壞；若細薄疊作兩重；若小坐具；若作褥；若作帽；作𧙕；作攝熱巾；或作裹革屣巾——一切不犯。
【譯文】【註文】自己製作、教唆他人製作、為他人製作，犯戒的情況都與前一戒相同。比丘尼犯突吉羅。不犯的情形：若是得到已經做成的；或是把它割裁破壞；若是毛質細薄，疊作兩重；或是作小坐具；或是作褥；或是作帽；作襪；作遮擋熱氣的巾；或作包裹皮鞋的巾——這些一切都不犯。

【672-0009】02_戒疏/14b_卷三下之二#128
【原文】【疏】戒本五句。
【譯文】【疏文】戒本經文共有五個文句。

【672-0010】02_戒疏/14b_卷三下之二#129
【原文】【疏】一、人。
【譯文】【疏文】第一、能犯戒的人。

【672-0011】02_戒疏/14b_卷三下之二#130
【原文】【疏】二、「以新純黑羺羊毛」者，所制境也。「純」則不雜，雜作非犯。「羺」，謂小羊羔也。
【譯文】【疏文】第二、「以新純黑羺羊毛」，這是本戒所要約束規範的對象境緣。「純」就是純一不雜，如果摻雜別的毛料製作就不算犯戒。「羺」，是指細嫩的小羔羊。

【672-0012】02_戒疏/14b_卷三下之二#131
【原文】【記】戒本中，第二句。「羺」字奴鈎反，胡羊也。文云「小」者，毛又細故。
【譯文】【記文】戒本經文中的第二個文句。「羺」字讀作「奴鉤反」，是指胡羊。疏文中說是「小羊」，是因為小羊的毛質更加細緻的緣故。

【672-0013】02_戒疏/14b_卷三下之二#132
【原文】【疏】三、「作臥具」，正犯境也。即是法衣，若作餘衣，如上不犯。如戒緣中，衣用上披，擬夜行故，比丘効之。知非下裳，何況作褥，是犯戒也？故下開通，褥非是犯。
【譯文】【疏文】第三、「作臥具」，是正犯之境（或：是正要構成犯戒的對象境緣）。指的就是如法僧衣袈裟，如果拿去做其餘世俗衣服，就如同上面所說是不犯本戒的。正如戒律緣起所載，這種毛氈是用來披在身上、打算在夜晚潛行行動的，比丘正是仿效這種做法。由此可知它絕不是下身穿的裙裳，何況是拿來做地下的褥子，又怎麼會犯戒呢？所以下文的開許條例中，做成褥子明白判定為不犯戒。

【672-0014】02_戒疏/14b_卷三下之二#133
【原文】【記】第三句，牒釋中。初定名體。「如上」，即列緣中。「如」下，引緣證。既在外披，顯是袈裟。俗中釋名，上者曰「衣」，下者曰「裳」。今是上者，故非下裳。裳猶非犯，褥非著用，故云「何況」。
【譯文】【記文】在解釋第三句的文義中。首先考定名稱與物質形體。「如同上面」，就是指前面所列舉的因緣之中。「正如」以下，引用緣起故事作為鐵證。既然是用來披覆在身體外面，顯然就是指袈裟。世俗在解釋名稱時，穿在上面的叫做「衣」，穿在下面的叫做「裳」。現在既然是穿在上面的，自然就不是下身的裙裳。連裙裳尚且都不構成犯本戒，褥子根本不是穿在人身上的，所以才說「何況」。

【672-0015】02_戒疏/14b_卷三下之二#134
【原文】【疏】昔以此等為「五敷具」，故制戒云：「此毛貴物，無宜下用，作無用之費，此言是也。」今所不同。竝上義中時為敷具者，欲改恐迷，且存古耳。讀者知非，則無大過。
【譯文】【疏文】過去的學者把這些戒條全都看作是「五種鋪設在地的敷具」，所以古人解釋制戒意旨時說：「這種羊毛極為珍貴，不適合拿來作為下等鋪地的用途，是徒作無益的浪費。」這話固然是對的，但我現在的看法有所不同（認為臥具指法衣而非敷具）。至於前面義理門中偶爾還會寫到「敷具」等詞，是因為如果要大幅修改恐怕會讓讀者產生迷惘混亂，所以暫且保留了古人的習慣稱呼。讀者只要心裡明辨是非，就不會有太大的過失了。
