# 校閱材料　第156檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【156-0001】02_戒疏/02a_卷一上之二#111
【原文】【記】能敬中，初科。上四句示名義。「稽」訓「下」者，下至地故。「如」下，引二教以釋。「三品」，出《智論》：一、口禮，二、屈膝，三、頭至地。「九品」，出《周禮》：一、稽首，頓首二，三、空首，四、振動，五、吉拜，六、凶拜，七、奇拜，八、褒拜，九、肅拜。「稽」但著地，「頓」乃叩頓；「首」即是頭，「顙」謂面額。名雖多別，事亦無殊，故云「一」也。
【譯文】【記文】在能禮敬的科判中，這是第一段。上面四句開示其名稱與字義。「稽」字訓解為「下」，是因為頭部低下至於地面的緣故。「如」字以下，引述出世間與世間兩種教理來作解釋。「三品禮節」出自《大智度論》：第一是口頭致敬，第二是屈膝跪拜，第三是五體投地、頭部著地。「九品禮節」出自《周禮》：第一是稽首，第二是頓首，第三是空首，第四是振動，第五是吉拜，第六是凶拜，第七是奇拜，第八是褒拜，第九是肅拜。「稽」只是頭部著地停留，「頓」則是叩頭頓擊；「首」就是指頭部，「顙」是指前額面額。名稱雖然有繁複的差別，但在表達最極致恭敬的事行上並無兩樣，所以說「是一（本質相同）」。

【156-0002】02_戒疏/02a_卷一上之二#112
【原文】【疏】「禮」者，敬而已矣。由屈敬故，表情盡儀，故云「禮」也。禮者，理也，事行合於正理也。餘如鄭玄注《周禮》說。古德相傳，禮謂拜手；據俗中解，禮則通諸。不可廣說，但知略也。
【譯文】【疏文】所謂「禮」，無非就是內心極致的恭敬而已。由於身心屈折敬奉的緣故，從而表露內心情感、窮盡一切法度威儀，所以稱為「禮」。禮，在深意上就是「理」，代表言行舉止完全契合於中正的真理。其餘詳情正如鄭玄注解《周禮》時所說的那樣。古來大德世代相傳，認為禮專指兩手作揖跪拜；若依據世俗通達的解釋，禮則通括所有的行誼節度。此處不可繁瑣地廣為敷演，只要明白其大綱概略即可。

【156-0003】02_戒疏/02a_卷一上之二#113
【原文】【記】次文中。初示禮本。敬在於心，禮見於身。心敬不已，身乃致禮。是則禮者，唯主於敬，更無他意，故云「而已」。「禮者」下，次釋禮義。《禮記》云：「禮也者，理也；樂也者，節也。君子無理不動，無樂不節。」又云：「禮者，體也。體不備，君子謂之不成人。設之不當，猶不備也。」、「餘」下，如上所引，皆彼文也。「古」下，三、斥局。言「通諸」者：一、禮訓於理，不唯在拜；又，如上九禮，豈止拜手，知非局矣。「不」下，示略。廣在《歸敬儀》中。
【譯文】【記文】在第二段文中。首先開示禮敬的本源。恭敬存於內心，禮儀顯發於外在身形。心中極致恭敬無法自抑，身軀這才施展禮敬。由此可知所謂禮節，完全是以內心恭敬為主體，再也沒有其他的用意，所以說「而已」。「禮者」以下，接著解釋禮的本義。《禮記》說：「禮也者，理也；樂也者，節也。君子無理不動，無樂不節。」又說：「禮者，體也。體不備，君子謂之不成人。設之不當，猶不備也。」「餘」字以下，說明正如上面所引述的文句，全都是彼鄭玄注中的文字。「古」字以下，第三、斥責古代見解過於狹隘局限。說禮「通貫各方面」的理由是：第一、禮在字義上訓釋為合乎天理，絕不僅僅是指作揖跪拜；再者，如同上面所列的九種世俗禮法，哪裡僅限於拱手作揖，由此可知古德的定義過於偏狹。「不」字以下，表示行文有所簡略。更詳細的說明全都載於《歸敬儀》之中。

【156-0004】02_戒疏/02a_卷一上之二#114
【原文】【疏】眾聖非一，謂「諸佛」也。致敬教主，所以通者，顯道無二，齊須同敬，故兼諸佛也。又下列七佛，即通奉敬。若準流通，三世齊禮。
【譯文】【疏文】一切出世聖人並非只有單獨一位，所以經文稱為「諸佛」。在致敬教主的威儀中，之所以普遍向一切佛陀致敬的原因，是為了顯明十方諸佛所證悟的實相之道毫無差別，全體都應當受到同等的敬奉禮拜，所以通貫含括了一切諸佛。又因為下文列出了過去七佛，這也是通貫敬奉的證明。若是依照全卷結尾的流通分來看，對於過去、現在、未來三世諸佛，全都應當平等頂禮。

【156-0005】02_戒疏/02a_卷一上之二#115
【原文】【記】次釋所敬，佛寶中，初文。上二句牒釋。「致」下，釋通敬意。餘宗戒本，但歸釋迦，獨今《四分》，徧敬諸佛。「道無二」者，通而為語，自行修證，化他權實；別論今意，釋尊制戒開遮重輕，並觀三世無異轍故。「又」下，據前後序，釋上諸義。
【譯文】【記文】接著解釋所禮敬的對象，在佛寶科判中，這是第一段。上面兩句是提舉經文並解釋字義。「致」字以下，解釋普遍敬奉十方諸佛的深意。其餘部派的戒本，開篇往往只單獨歸敬釋迦牟尼佛一人，唯獨現在這部《四分律》，周遍普遍地禮敬一切諸佛。「道無二」這句話，若廣義而論，是指十方佛自行的修證實相、以及化導他人的權巧與真實完全一體；若就本律撰述的特殊立意而論，釋迦牟尼佛制定戒律的開許、遮止、重罪、輕罪等尺度，全都徹照審察過三世諸佛一貫的軌範而毫無二致。「又」字以下，依據戒本前後的序文與偈頌，來證成上面所說「諸」字的普遍意涵。

【156-0007】02_戒疏/02a_卷一上之二#117
【原文】【疏】答：「此宗大乘，如《羯磨疏》。光律師判非是小乘。故《戒》下云『現在諸世尊』，斯文良證也。」

【156-0008】02_戒疏/02a_卷一上之二#118
【原文】【記】釋疑中。初問意者。以今小教，但明大千世界，釋迦一佛，以為化主，無餘佛土；文通諸佛，義實乖宗。故須會釋，即指前引。答中，初正答。「此宗大乘」者，即「分通」義。指「如《疏》」者，彼約五義，以顯分通：一、沓婆迴心，二、施生成佛，三、相召佛子，四、捨財用輕，五、識了塵境。如彼廣之。「光師」下，據他判。「故」下，還引流通為據。
【譯文】【記文】在除疑釋惑的科判中。最初提問者的意圖在於：因為在一般小乘的教理中，僅僅認定三千大千世界唯有釋迦牟尼佛一尊佛作為教化之主，絕對不可能同時存在其他佛陀的淨土世界；現在經文卻通稱禮敬十方諸佛，在教理義理上確實與尋常小乘宗義有所違背。所以必須加以會通解釋；問文所說「文所列者」，即是指前文疏中所引用的經文。回答之中，首先作正面裁斷。「此宗大乘」者，即指分通大乘之義。所指「如《疏》」，是指該疏從五種義理層面，充分顯彰了本律暗通大乘的深意：第一是沓婆摩羅子發心迴向大乘，第二是迴施眾生共成佛道（戒本迴向偈云『施一切眾生，皆共成佛道』），第三是互稱佛子，第四是對捨棄財物與懺悔的從輕認定，第五是明確承認心識能了達塵境。詳細義理如同該疏所廣泛敷演。「光師」以下，是借重其他法師的判教權威。「故」字以下，則是回過頭來引述戒本流通分中的經文作為鐵證。

【156-0014】02_戒疏/02a_卷一上之二#124
【原文】【記】僧寶，初科。先示僧體。人無自體，五陰合集，號假名人。陰本無用，假人有用，總四人假，以為僧體，故云「攬假」。四人和聚，能辦前事，故曰「成用」。比丘是別，攬別成僧，故兩列之。「比丘」下，標名。《業疏》云：「或云煏芻。」
【譯文】【記文】在僧寶科判的第一段中。先指示僧伽的體質。單一的人身並沒有獨立實體，只不過是五蘊假合凝聚，名義上稱為「假名之人」。五蘊本身沒有功用，五蘊和合的假名之人卻有用，總括四個假名之人以為僧體，所以稱為「攬假」。四人和睦共聚，能成辦當前的羯磨法事，所以稱為「成用」。比丘是個別的分子，總聚個別的分子才能成就僧伽的總體，所以經文中將二者並列。「比丘」字以下，標明名稱的來源。《業疏》說：「也有音譯為『煏芻』的。」

【156-0015】02_戒疏/02a_卷一上之二#125
【原文】【疏】此方無人，以三義譯。一曰「怖魔」，或令魔怖。遵修三行，出三有也，由此義故，名之為「僧」。故《五分》云「為解脫出家，名為僧也」。二曰「乞士」，有二義故。上則乞法以練心，下則乞食以資身。得法奉持，驗以四教；受食觀厭，須離五邪。廣如常解。三曰「破煩惱者」，欲使依名思義，顧瞻有本，不至流俗，唯欣出要。故云「於我法中，快修梵行，盡苦源」也。
【譯文】【疏文】此方中土原本沒有這等清淨修道之人，因此依據其三種功德義理來翻譯。第一種稱為「怖魔」，或者稱為「令魔畏怖」。因為行者精進修持戒、定、慧三種清淨行持，誓願跳出欲界、色界、無色界這三界輪迴，正因為具備了這個殊勝意義，所以稱之為「僧」。因此《五分律》說「是為了追求究竟解脫而剃落出家，所以才稱名為僧伽」。第二種稱為「乞士」，這是因為具足了兩種義理：對上向諸佛如來乞討無上法藥來鍛鍊自心，對下向世間檀越乞求飲食資具來維持肉身。求得佛法之後信受奉持，必須以四依法來加以審察檢驗；接受世俗飲食供養之時必須作不淨之想以深生厭離，必須徹底遠離五種邪命的謀生手段。詳細行持正如平常律典所廣泛宣說的那樣。第三種稱為「破煩惱者」，這是為了使行者顧名思義，時時自我省察煩惱的根本深源，使身心不至於隨波逐流落入世俗名利，唯獨欣慕追求出離生死的究竟要道。所以佛說：『在我的正法之中，善修清淨梵行，斷盡痛苦的根本。』

【156-0016】02_戒疏/02a_卷一上之二#126
【原文】【記】義譯中，初科。上二句標示。「一」下，別釋，初義兩別。「怖魔」者，明其本志；「魔怖」者，約其功行。「魔」有四種：天、陰、惱、死。「遵」下，通釋二名。「三行」即戒、定、慧。「由」下，結名。「故」下，引證。此釋「比丘」，皆云「僧」者，以眾假別成，故別從眾號。次義中。「乞」即求義。「法」是道因，「食」乃道緣，因正緣傍，故分「上下」。「得」下，明二皆從正，方成此目。「四教」，即《涅槃》四依：一、依法不依人，二、依義不依語，三、依智不依識，四、依了義不依不了義。此四辨決邪正，行者依憑故。「五邪」者：一、為求利養，改常威儀，詐現異相；二、說己功德；三、高聲現威；四、說己所得，激動令施；五、為求利養，強占吉凶。後義中，初句示名。「欲」下，顯意。「依名」是聞，「思」義即思，「顧瞻」下是修：由此一名，克全三慧。「顧瞻」即觀察，「有本」即煩惱。「不至流俗」者，棄捨世樂故。「欣出要」者，高慕聖道故。「故」下，引證，即佛以「善來」度人之詞。初句生正信，次句修因，下句證果。「苦」是生死，「源」即煩惱。
【譯文】【記文】在義理翻譯的科判中，這是第一段。上面兩句是總體標示提示。「一」字以下，分別逐一解釋，第一種義理包含了兩種不同層面的表述。「怖魔」，是指行者初發心時誓斷生死的根本志向；「令魔怖」，是著眼於行者日後戒德圓滿、功行深厚時令魔宮震動的外在威德。「魔」分為四種：天魔、五陰魔、煩惱魔、死魔。「遵」字以下，通盤解釋這兩種名號的由來。「三行」就是指戒、定、慧三無漏學。「由」字以下，總結立名。「故」字以下，引用經論作為佐證。此處明明在解釋「比丘」，後文卻都結語稱為「僧」的原因，是因為僧團整體是借由個別比丘所組成的，所以個別成員隨順著整體的名號而共同受稱。在第二種義理中。「乞」就是乞求、追求的意涵。「佛法」是成就佛道的正因，「飲食」只是維持肉身修道的助緣，正因為法為正因而飲食為旁緣，所以在文意上劃分出「對上」與「對下」的高低層次。「得」字以下，說明求法與乞食這二者都必須歸於正道，才得以圓滿成就「乞士」的名號。「四教」，就是指《大般涅槃經》所載的「四依」：第一是依法不依人，第二是依義不依語，第三是依智不依識，第四是依了義經不依不了義經。這四種準則是行者用來辨別決斷邪法與正法的最高依憑。「五邪命」是指：第一是為了求取利養，故意改變尋常威儀，詐現奇特異相；第二是逢人宣說自己的修行功德；第三是大聲說話以顯現威嚴氣勢；第四是宣說自己有所證得，以此激動信眾令其布施；第五是為了求取利養，強行替人占卜吉凶。在第三種義理中，第一句標示出名稱。「欲」字以下，顯明立名的深遠用意。「依名」就是聞慧，「思義」就是思慧，「顧瞻」以下就是修慧：單憑「破煩惱」這一名號，就能完全具足聞、思、修這三慧。「顧瞻」就是指觀照審視，「有本」是指心中所依附積累的煩惱。「不至流俗」，是因為徹底捨棄了世間俗樂的緣故。「欣出要」，是因為一心高瞻仰慕出世聖道的緣故。「故」字以下，引述佛典作為明證，這就是佛陀當年在世以「善來比丘」度化善根之人出家的原話。第一句令其生起正信，第二句勸勉修持因地梵行，最後一句直指證悟究竟佛果。「苦」是指無邊生死輪迴之苦，「源」就是指無始以來的根本煩惱。
