# 校閱材料　第596檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【596-0001】02_戒疏/10d_卷三上之一#33
【原文】【記】前三，並由僧諫秉法，屏不作法，故分二別。
【譯文】【記文】前三門，都是由於僧團公眾規勸必須正式秉法作羯磨，而私下規勸不作法，所以區分出這兩種差別。

【596-0002】02_戒疏/10d_卷三上之一#34
【原文】【記】四中。初總標。「違」下，次別釋，又二。初明僧諫制多事少。僧有五戒，尼八夷中第六戒，僧殘中八戒，共有九戒。「五義」，即前「性惡」等五。次明違別制少事多。「九十」中不受、拒勸二戒，並諫通篇聚故也。
【譯文】【記文】第四門中。先總體標明。「違」字以下，接著分別解釋，又分為兩部分：首先說明僧諫制定的戒相多但所管之事少。比丘僧有五條戒；比丘尼在八重戒中有第六戒，僧殘中有八條戒，比丘尼共有九條戒。「五義」，就是指前面所說的「性惡」等五種條件。其次說明違背個人私勸的戒相少但所涉之事多。「九十單墮」中不接受規勸與抗拒勸學這兩條戒，都是其規勸通於一切篇聚罪相的緣故。

【596-0003】02_戒疏/10d_卷三上之一#35
【原文】【記】五中。「別人」即屏諫，所諫通七聚，拒諫兼提、吉。「僧諫」中，大則犯夷，如尼第八，中如諸殘，下即犯提。隨事各定，故不同前。
【譯文】【記文】第五門中。「別人」就是指私下規勸，所規勸的內容通於七聚罪，抗拒規勸兼具波逸提與突吉羅罪。「僧諫」之中，重的就犯波羅夷，如比丘尼第八戒；中等的如各條僧殘戒；輕的就犯波逸提罪。隨每件事各自決定，所以與前一種不同。

【596-0004】02_戒疏/10d_卷三上之一#36
【原文】【記】六中。僧諫不定，如後注中；屏二品定。「言了」，即拒諫也。
【譯文】【記文】第六門中。僧團公眾規勸罪相不固定，如後面注文所示；私下規勸則固定分為兩品罪。「言了」，就是指開口回絕抗拒規勸。

【596-0005】02_戒疏/10d_卷三上之一#37
【原文】【記】七中，僧諫但令不捨，默亦成違。
【譯文】【記文】第七門中，僧團公眾規勸只要對方心不捨棄邪執，即使默不作聲也構成違抗。

【596-0006】02_戒疏/10d_卷三上之一#38
【原文】【記】八中，「別通止作」，不受諫作犯，拒勸諫止犯。
【譯文】【記文】第八門中，「別通止作」，不接受規勸屬於作惡犯，抗拒勸導屬於止善犯。

【596-0007】02_戒疏/10d_卷三上之一#39
【原文】【記】九中。僧諫「已未」，各收二戒。「既往不咎」，文出《論語》。「既」，已也。「咎」，猶責也。
【譯文】【記文】第九門中。僧團公眾規勸的「已作與未作」，各自收攝了兩條戒。「既往不咎」，語出《論語》。「既」是已經的意思。「咎」就是追究責備的意思。

【596-0008】02_戒疏/10d_卷三上之一#40
【原文】【記】十中。言「相成」者，謂屏能成僧，僧不成屏，故云「不同」。初引《僧祇》。「越」，即吉羅異名。合因成果，故「無別小罪」。《四分》但分僧、別兩諫，不論一與眾多。《五分》「三吉」，應是屏處三諫。《僧祇》、《五分》，僧諫止有偷蘭，唯《四分》白未竟吉，故云「不同」也。
【譯文】【記文】第十門中。說到「相成」，是指私下規勸能助成僧團公眾規勸之罪，但僧團公眾規勸不能反過來助成私下規勸，所以說「不同」。首先引用《僧祇律》。「越」就是越毘尼，即突吉羅的異名。把前面所有的因位罪合併成最後的果位罪，所以「不再另結小罪」。《四分律》只區分僧諫與私諫兩種，不論一人勸還是眾多人勸。《五分律》說的「三吉羅」，應當是指私下處的三次規勸。《僧祇律》與《五分律》中，僧諫過程只有偷蘭遮，唯獨《四分律》在單白未完時有突吉羅罪，所以說是「不同」的。

【596-0009】02_戒疏/10d_卷三上之一#41
【原文】【記】已上十門，前三并十，據能諫不同；四與五、六，約制法差別；七及八、九，就所諫分殊。則僧、屏兩諫，條然可見。
【譯文】【記文】以上十門，前三門加上第十門，是依據能發起規勸方面的不同；第四與第五、第六門，是依據制戒法則的差別；第七以及第八、第九門，是針對被規勸的事情來劃分。如此一來，僧團公眾規勸與私下規勸兩者，其條理脈絡便清晰可見了。

【596-0010】02_戒疏/10d_卷三上之一#42
【原文】【律】彼比丘應諫是比丘言：「大德！莫壞和合僧，莫方便壞和合僧，莫受壞僧法堅持不捨。大德！應與僧和合，歡喜不諍，同一師學，如水乳合，於佛法中有增益安樂住。」
【譯文】【律文】那位比丘應當規勸這位比丘說：「大德！請不要破壞和合僧團，不要採取手段破壞和合僧團，不要接受破壞僧團的非法而且執迷不捨。大德！應當與僧團和合一心，歡喜無諍，跟隨同一個導師修學，就像水與乳完美相融那樣，在佛法之中獲得道業增益與安樂安住。」

【596-0011】02_戒疏/10d_卷三上之一#43
【原文】【疏】就解屏諫，分二。從初至「堅持不捨」來，一往牒過，示知非法，莫壞莫受。二、「大德應與和合」下，勸同和相。
【譯文】【疏文】關於解釋私下規勸這一段，分為兩部分。從開頭直到「堅持不捨」為止，是總括提起他的過錯，明確指示那是違法之事，告誡他不要破壞、不要接受。第二部分從「大德應當與僧和合」以下，是勸導他共同回歸和合之相。

【596-0012】02_戒疏/10d_卷三上之一#44
【原文】【疏】初中，「彼比丘」者，如法比丘見行非法，故自陳諫。「諫是比丘」者，是行邪法人也。初「莫壞」者，牒始心於佛不忍，思欲破輪時也。中「莫方便」者，牒共四伴計校時也。後「莫受」下，牒其行化於時，不須破僧，不須受法也。
【譯文】【疏文】第一部分中，「彼比丘」，是指如法的清淨比丘見到對方行持非法，所以主動陳詞規勸。「諫是比丘」，是指那個推行邪法的人。開頭的「莫壞」，是總括他最初在佛陀面前懷有不能忍受之心，心裡盤算著想要破壞法輪的那個時期。中間的「莫方便」，是總括他與四個同黨密謀策劃的那個時期。最後的「莫受」以下，是總括他在世間推行教化的那個時期，告誡他不必去破壞僧團，也不要去接受那種非法。

【596-0013】02_戒疏/10d_卷三上之一#45
【原文】【記】次正釋，牒過中。初釋比丘，明簡邪正。「初」下，次釋壞僧，次第三時。
【譯文】【記文】接著作正面解釋，在總括提撕過錯的段落中。首先解釋比丘，用以揀別邪正的不同。「初」字以下，接著解釋破壞僧團在時間上的三個前後階段。

【596-0014】02_戒疏/10d_卷三上之一#46
【原文】【疏】二、「大德」下，上有所勸不為故，下必有所為也。
【譯文】【疏文】第二部分從「大德」以下，因為上面有所勸導告誡不要去做的惡事，下面就必然有所勸導應當去從事的善行。

【596-0015】02_戒疏/10d_卷三上之一#47
【原文】【記】次釋勸同，總分中。「上勸不為」，即前壞僧也。「下有所為」，即後令和合也。
【譯文】【記文】接著解釋勸導回歸同和，在總體劃分當中。「上勸不為」，就是指前面不要破壞僧團。「下有所為」，就是指後面勸令彼此和合。

【596-0016】02_戒疏/10d_卷三上之一#48
【原文】【疏】就勸同中，初舉喻示諫，二、舉有益示諫。就初法中，初「與僧和合」者，成僧義也。俗以和為貴，僧以和為義。必同六相，方成僧體，如何同戒而欲別見？此勸體同也。
【譯文】【疏文】在勸導同和的內容中，首先是舉出比喻來開示規勸，第二是舉出得大助益來開示規勸。在第一種正法內涵中，開頭的「與僧和合」，是成就僧伽的意義。世俗尚且以和為貴，僧團更應當以和為其核心本質。必須具備六和敬之相，才能構成僧團的主體，怎麼可以受持同樣的戒律，內心卻想要存有相左的偏見呢？這是勸導在僧團體性上要同和。

【596-0017】02_戒疏/10d_卷三上之一#49
【原文】【記】次科，勸體同中。「俗以和為貴」，《論語》云：「禮之用，和為貴。先王之道，斯為美。」、「六相」即六和，內外各三也。
【譯文】【記文】下一科段，在勸導僧體同和當中。「俗以和為貴」，《論語》說：「禮的運用，以和為最尊貴。古代先王治理之道，最美妙的地方就在這裡。」「六相」就是指六和敬，內在與外在各具三種。

【596-0018】02_戒疏/10d_卷三上之一#50
【原文】【疏】二、明「不諍同師學」者，世有諍者，由異學故。今同釋姓，師本無殊，有何意見而欲乖異？此勸行同也。
【譯文】【疏文】第二、說明「不諍、同一師學」，世間之所以會產生紛諍，都是因為各從其師、修學各異的緣故。如今大家共同以釋迦為姓，導師本來就沒有兩樣，能有什麼個人私見而偏要背離乖異呢？這是勸導在修行實踐上要同和。
