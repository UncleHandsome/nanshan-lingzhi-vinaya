# 校閱材料　第256檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【256-0001】01_行事鈔/11c_卷下之三#10
【原文】《地持》云：若見眾生，當即慰問；舒顏先語，平視和色，正念在前，問言：道路清泰，四大調適，臥覺安樂？歎言善來。又隨世間巧便語言，呪願妻子眷屬，錢財穀米，增長具足；見功德者，歎施戒等。《四分》：若白衣病，來寺中，應方便喻遣。若稱譽佛法僧者，隨能作為之。若死，為淨伽藍故，自擔棄之。若白衣嚏者，呪願長壽。
【譯文】《菩薩地持經》說：如果見到眾生，應當立即加以慰勞問候；展顏微笑主動招呼，目光平視、面色溫和，提起正念在心，問候說：「沿途路途平安通泰嗎？四大身心是否調和適意？睡眠醒來是否安樂？」並讚歎說「歡迎善來」。又隨順世間善巧方便的語言，為對方的妻子眷屬祝願，祈願其錢財糧食增長具足；若見到對方修持功德，就讚歎其布施、持戒等善行。《四分律》說：如果有在家的白衣生病來到寺院中，應當用善巧方便曉諭勸導遣回家中。如果對方是極為稱揚讚歎佛法僧三寶的信眾，則可隨自己的能力為其看顧照料。如果在寺中亡故，為了保持僧伽藍（寺院）的清淨，比丘當自行將屍體抬出安厝。如果在家人打噴嚏，應祝願他長命百歲。

【256-0002】01_行事鈔/11c_卷下之三#11
【原文】《僧祇》：若入王眾，不得譽毀軍陣射術。應云，剎利種是上姓，如來應供正遍知，常在二家生；諸出家人，於法力二輪中，賴力輪護故，得以自安。又不得形相他身，云多我慢；當生下趣，乃至雞䐗地獄中等。欲有所論，當說已而去。俗人若言，為我禮塔，答言若憶當禮；如是禮長老比丘亦爾。若受請應言：無障礙當來。若入諸居士富家，不得語云：汝坐店肆，輕秤小斗，欺誑於人。應云：如世尊說，二輪之中，得食輪已，乃轉法輪；諸居士等，供給衣食，是為難事；我依汝等，於如來法中修梵行，度生死流，皆是汝等信心之恩。若入外道眾，不得形訾，云邪見無慚愧，說其過惡。應譽實事，云：汝等能出家解繫縛，捨於俗服，冥心空閑，甚是難事。
【譯文】《摩訶僧祇律》說：如果進入國王或王族大眾之中，不得妄加稱揚或毀謗軍陣作戰、弓射兵術。應當說：剎帝利種姓是尊貴的上等姓氏，如來、應供、正遍知，常常降生在剎帝利與婆羅門這兩大家族中；一切出家人在正法與國力這「法、力二輪」之中，正是依賴國王權力之輪的庇護，才得以安穩修道。又不得品評審視王臣的相貌，說對方多生我慢、將來當墮下賤惡道、乃至墮入雞䐗地獄等。若有法義需要論說，宣說完畢就應當離開。俗人如果請求說「請替我向佛塔禮拜」，應當回答說「如果想起當為你禮拜」；若託付禮拜長老比丘也是如此回答。如果接受俗人的請帖，應當回答說：「若無障礙當會前去。」如果進入富貴的居士家中，不得開口指責說：「你們坐在店鋪作買賣，使用大斗進、小斗出（或輕秤短尺）來欺瞞眾人。」而應當說：「正如世尊所說，在正法與食物這二輪之中，先得到食物之輪資養色身，才能運轉正法之輪；諸位居士能夠供給我們衣食，這是非常難能可貴之事；我們依靠你們的布施，才能在如來正法中修持梵行、度越生死苦海，這全賴你們至誠信心的恩德。」如果進入外道群眾之中，不得當面譏諷指責，斥罵其為邪見、無慚無愧，宣揚其過錯惡行。而應當稱讚其實在的長處，說道：「你們能夠出家解脫世俗繫縛，捨棄世俗服飾，靜心安住於空閑之處，這真是非常難得的事。」〔註：「雞䐗」，音雞都，八大地獄之一阿鼻地獄之別名或其附屬眷屬地獄。〕

【256-0003】01_行事鈔/11c_卷下之三#12
【原文】二明受戒法。就中分三。
【譯文】第二、說明受戒之法。這當中分為三個部分。

【256-0004】01_行事鈔/11c_卷下之三#13
【原文】初翻邪三歸。又分為四：一制意，二懺悔法，三立歸法，四總料簡。初中，《涅槃》云：一切眾生，怖畏生死四魔，故受三歸。名一義異，或時說三為一，說一為三；諸佛境界，非二乘所知。又金翅鳥，不噉受三歸龍。餘如《義鈔》。二懺悔法。以信邪來久，妄造非法；今創歸投，必翻邪業。《阿含》等經，並令先悔。《涅槃》云：發露諸惡，從生死際，所作諸惡，悉皆發露，至無至處；如第十卷說。必論設懺，隨時誦習，亦得通用。三作法者。《知論》云：互跪合掌，在比丘前，當教言：「我某甲盡形壽，歸依佛，歸依法，歸依僧。」即發善法。次結云：「我某甲盡形壽，歸依佛竟，歸依法竟，歸依僧竟。」《薩婆多》：若淳重心，具教、無教。四雜料簡，《大集》云：妊娠女人，恐胎不安，先受三歸已，兒無加害；乃至生已，身心具足，善神擁護。《薩婆多》：五道皆得受三歸；無受戒法。亦得一年半年，五三日間受之；不得戒也。
【譯文】第一、翻破邪見而受三歸依。又分為四項：一是制定歸依的意旨，二是懺悔的方法，三是確立歸依的作法，四是綜合辨析料簡。第一項制定意旨中，《大般涅槃經》說：一切眾生因為恐懼畏怖生死與四魔（煩惱魔、陰魔、死魔、天魔），所以受持三歸依。名相雖一但義理有異，有時說三寶為一體，有時說一體為三寶；這乃是諸佛的甚深境界，並非聲聞、緣覺二乘所能徹底測知。此外，金翅鳥絕不吞食受過三歸依的龍族。其餘義理如《受戒義鈔》中所詳述。第二項懺悔方法：因為長久以來盲信邪道，妄造了諸多非法惡業；如今初次歸投三寶，必須徹底翻轉原有的邪業。《阿含經》等經典，都指示受歸前必須先求懺悔。《大般涅槃經》說：應當發露陳白一切罪惡，從最初生死的無始劫來，所造作的種種惡業，都發露無遺，徹底清淨乃至達到無餘涅槃；如同經中第十卷所說。若是施設專門的懺悔法，隨時誦念修習，亦可通用。第三項儀式作法：《大智度論》說：胡跪（互跪，右膝著地）合掌，在比丘面前，比丘應當教其宣稱：「我某甲盡形壽（終其一生），歸依佛，歸依法，歸依僧。」至此三說即生起善法（尚未發戒體）。接著結語宣說：「我某甲盡形壽，歸依佛竟，歸依法竟，歸依僧竟。」《薩婆多論》說：如果是至誠淳厚莊重之心，就能具足教（作戒、表業）與無教（無作戒、無表業）。第四項雜項料簡：《大集經》說：懷孕的婦女，若擔心胎兒不安穩，先受三歸依後，胎兒便不會遭遇災害傷害；乃至出生之後，身心六根具足，蒙善神護佑。《薩婆多論》說：五道眾生皆可受三歸依；但人道之外其餘各道並無受戒之法。受三歸也可以限定受一年、半年、乃至三五天（此簡別時限）；但單純受三歸依並不會發起戒體（此簡別法體）。
