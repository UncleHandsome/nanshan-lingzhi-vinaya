# 校閱材料　第457檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【457-0001】資持記/11b_中四上#57
【原文】問：此不可學，既是迷忘，何得有識？答：三心交絡，作句須爾；其實識心，非不可學。問：前云隨戒境想，唯開學人；今不學人何以開耶？答：前文敘結，且據大判，不妨不學，準例同開。若以義求，則迷事不別；若取文證，則《業疏》顯然；臨文自舉，此不繁引。
【譯文】有人問：這不可學既然屬於迷誤遺忘，怎會有「識」心存在？回答：三種心交錯配列，構成句式必須如此；實際上其中的識心，並不屬於不可學的範圍。有人問：前文說過依照戒條的境想，唯有學戒之人能得開許；如今不學戒的人為何也能開許免罪呢？回答：前文敘述結罪，暫且是依據大原則來判斷，並不妨礙不學戒的人依此準例同樣獲得開許。若依義理來探討，在迷誤外境這一點上並無差別；若取律文為證，則《業疏》中寫得極為顯然；臨到相關律文時自會舉出，此處不再繁瑣引述。

【457-0002】資持記/11b_中四上#58
【原文】問：前後句法，竝約三心，如何分異？答：識心是同，疑及不識則別。前是迷教，後是迷心。問：舊云：明白心中成可學，迷忘心中故不可學，其義云何？答：如前可學，識事識犯，可是明白；疑及不識，則非明白，故知不爾。又迷忘之心，是不可學；
【譯文】有人問：前後兩套句法全都是依據三種心，到底該如何區分其不同？回答：「識心」是相同的，但「疑」與「不識」則完全不同。前者是迷誤教法，後者是迷誤自心。有人問：舊說主張「在明白的心中構成可學，在迷誤遺忘的心中所以構成不可學」，這個義理如何？回答：如同前述可學句法中，「識事識犯」固然可以說是明白；但「疑」與「不識」就不是明白了，所以知道舊說不對。再者，迷誤遺忘的心本身就是不可學；

【457-0003】資持記/11b_中四上#59
【原文】豈得迷忘成不可學，義亦不然。疏鈔兩文，竝無此語。今但準下，分二種迷；前九名可學迷，後九名不可學迷。問：二迷何別？答：前迷是愚教，後迷即昏倒。問：後九迷者，必須先識，後容起迷；學人可爾，不學應無？答：前明不學，自有解者。從先不解，亦容有迷；
【譯文】哪裡可以說是迷誤遺忘「成就」了不可學呢，義理上也是說不通的。律疏與行事鈔兩處文獻中，都沒有這種說法。現在只要依照下文，區分為二種迷：前九句稱為「可學之迷」，後九句稱為「不可學之迷」。有人問：這二種迷有何差別？回答：前一種迷是愚昧於教理，後一種迷則是神智昏亂顛倒。有人問：後九句的迷誤者，必須是先前明白認識，之後才可能生起迷誤；學戒之人固然可以如此，不學戒之人應該不會有這種情況吧？回答：前面已說明不學戒之人中，自然也有原本理解戒法者。縱使從前不理解，當下也容許產生迷誤顛倒；

【457-0004】資持記/11c_中四上#1
【原文】如主無主想，人非人想，臨事即生，豈待先學。如是思之。示罪中，初正示。尋前圖相，對文可曉；三箇初句，竝無罪故。指下二句疑不識別者，示犯上二心，對事是總，故犯云別。亦下，結宗。義同前示。事開中，初科。但明事開，準疏，續去：罪是可學，若有迷者，皆結其罪；
【譯文】像是有主物卻誤以為無主物，或者對人誤以為非人，這種念頭都是臨事當下就生起的，哪裡需要事先學習？應當如此深入思惟。在開示罪相的文句中，首先是正式開示。只要檢索前面的圖表相狀，對照文句就能明了；因為前三組的打頭第一句，全都判為無罪。至於下文指出後兩句之生疑與不識，是為了標明緣犯這一邊的兩種心態；相對而言，在每一品中事相是總括唯一的，而違犯的心態則是各別分列的。在「亦下」這段，是結歸宗義，意旨與前面開示的相同。在開許事件的科判中，是第一科。這裡只說明開許事件，依照戒疏的文意，接著說：罪責是屬於應當學習的範圍，如果有昏昧迷惘的情況，都必須結算其罪責；

【457-0005】資持記/11c_中四上#2
【原文】披則具明犯結。又云：由不識事，境非可學〔事開〕；不妨於犯，是可學故〔犯結〕；有斯明據，復何所疑。問：一等是迷，何以開結不同？答：事是現對造修，心想容生遺忘。犯是冥緣教相，有迷猶是無知；縱令先已學通，還制後心怠墮。細詳聖意，諒不徒然。
【譯文】查閱文典就完全載明了結罪的規定。戒疏又說：由於不認識事件的本質，這類境界並不是可以事先學習的範疇（此即開許事件）；但這並不妨礙對違犯教法之處結罪，因為教法是可以且應當學習的緣故（此即結算犯戒）；有如此明確的依據，還有什麼好懷疑的呢？有人問：同樣是迷惘，為什麼開許與結罪會有不同？回答說：事件是當前直接對境造作修習的，心思與意想容許產生遺忘。犯戒則是冥冥中相涉於佛陀教法名相，只要有昏昧，就依然屬於無知的過失；縱使先前已經學得通曉，戒律還是要制罰後續心念上的怠惰鬆懈。仔細推敲聖人的立意，確實不是徒勞無益的。

【457-0006】資持記/11c_中四上#3
【原文】有人言：前九句結不學人，後九開學人；以不學人，先既不學，無迷忘故，更開犯上十二罪；今謂，且學人生可學迷，尚不結罪，那得迷忘，方欲開罪！又若開十二罪者，則句法俱無有罪，用立何為？又有人云：今是迷心不迷教，學人須於事上，放十二枝條；此中順古，且說事開犯結；
【譯文】有人主張說：前九句是針對不學習的人結罪，後九句是為有學習的人開許；因為不學習的人，先前既然沒有學習，就不會有迷失遺忘的問題，更進一步開許免除在違犯上的十二種罪；現在我認為，有學習的人如果對可學習之事產生迷惘，尚且都不結罪，哪有反而在迷失遺忘時，才想要開許免除罪責的道理！況且如果真的開許了十二種罪，那麼句式法則就全都沒有罪責了，又何必建立這個法規呢？又有人說：現在是心思迷妄而不是對教法迷妄，有學習的人必須在事件上，免除十二種枝條罪；這裡只是順從古師的說法，姑且說是開許事件而結算犯戒；

【457-0007】資持記/11c_中四上#4
【原文】若今師以迷心望之，則事犯根條俱放，豈有事開犯結乎！且罪是佛制，那得由汝輒自放耶！又疏鈔皆明事開犯結，汝反攻破，豈不公違祖訓。又若以此為順古，則作犯門中，辨十二罪，文極詳委，皆應是古；則此一門，都無今義；下文囑云：不知鏡不，豈令鏡古耶？嗟乎！世之講學，多習舊迷；
【譯文】如果依現在祖師的觀點從迷心來看，那麼事件與犯戒的根本及枝條都應當免除，哪裡會有開許事件卻結算犯戒的事呢！況且罪責是佛陀所制定的，哪裡容許你擅自任意免除呢！再者，戒疏與行事鈔都明文指陳「事開犯結」，你反而去攻破它，豈不是公然違背祖師的訓示。又如果把這當成是順從古說，那麼在作犯門中辨析十二種罪的文字極其詳細委曲，豈不全都是古代的主張了；如此一來這一整門便毫無今師的正義可言；下文叮囑說：「不知是否能成為明鏡？」難道是讓人去對照古舊的說法嗎？唉！世間講學的人，大多承襲舊有的迷思；

【457-0008】資持記/11c_中四上#5
【原文】但務守文，寧思開悟；自緣宿善，濫染祖乘；粗能考校古今，剖決可否；甞形筆墨，曲盡是非；雖或相從，鮮能詳究；故茲略示，猶愧繁詞；信乎！持犯之相實深，不學無知微隱；指唯標月，書不盡言；必欲通明，終須面扣。初問中。準律境想，難上事開。初作本迷後心釋。
【譯文】他們只一味死守文句，哪裡會去思考發明開悟；只憑藉著自己宿世的善根，勉強沾染了祖師的法門；粗略能夠考訂古今的異同，剖析判定其可行或不可行；過去曾經形諸筆墨，曲折詳盡地論說是非；雖然或許有人跟從學習，但鮮少能有人詳細探究到底；所以在此只是略微提示，依然對文辭過於繁瑣感到慚愧；確實啊！持戒犯戒的行相實在是深奧莫測，不學無知的過失又極其幽微隱晦；文字的指涉只是標示月亮的方向，書本文字無法窮盡所有的言意；如果必定想要徹底通達明白，終究還是必須親自當面請益。在最初的提問中，是依照律文中的境想，來質難前述開許事件的道理。首先是以「根本起迷、後續之心」來作解釋。

【457-0009】資持記/11c_中四上#6
【原文】言律結無罪者，異境後心，律不結故。亦制犯者，準殺非人，相傳犯吉故。答中，初示有無所以。言心犯者，以有殺非人心，故結吉罪。然下，正答通來問；初約根本，通前事開。正罪，即根本。莫下，次約罪境，答上有無。次準《戒疏》，約轉想前心釋。問云：律結無罪者，如盜戒無第三句也；

【457-0022】資持記/11c_中四上#19
【原文】上云一向無罪，恐謂後識都無犯故。辨句法中。上中二品，罪相自定；下品不定，故須料簡。初問作犯立句，必約有罪；下品無犯，不應此門。答中。初縱後奪。謂若望事開，則可除之；由兼犯結，還須具九。初難。二犯行別，各攝所宗；如上所通，豈非相濫。答中，初正答。
【譯文】上面說一概無罪，是唯恐有人以為後來認識之後就完全不犯的緣故。在辨析句法中，上中兩品的罪相自然固定；下品則是不固定的，所以必須加以料簡。起初問難說作犯之門立句，必定是要依據有罪為前提；下品既然沒有犯戒，就不應歸入此門。在解答中，首先縱容退讓而後奪回立論。意思是如果單看事件的開許，確實可以將它除開；但由於兼含了對違犯教法的結罪，所以還是必須具備九句。第一道問難說：兩類犯戒的行相各不相同，各自統攝所屬的宗要；如果依照上面那樣貫通，豈不是互相混淆了。解答中，首先是正式回答。
