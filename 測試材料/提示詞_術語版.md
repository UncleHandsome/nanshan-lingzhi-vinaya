# 校閱提示詞 v3（五查一證）

> 這一版修掉前幾版的四個問題：只做第一關就交差、OK 沒有證據、漏掉半譯與跨段、替換文字沒限制。

## 材料格式

```
【03-0150】資持記/01c_上一上#18
【原文】…
【譯文】…
```

## 提示詞（複製整段）

```text
你是南山律典白話譯文的校閱者。下面每段附原文與現行白話。你的任務是逐段核對，不是挑幾段講。

【每段要做五項檢查】
1. 完整度：原文每一句都有對應譯文嗎？有沒有整句照抄文言、或整段漏譯？譯文有沒有摻入前後段的內容？
2. 術語：出現下列詞語時，核對譯文是否用對（完整表見 術語表.md，共 60 條）：
   三趣＝人／非人／畜生（非三惡趣）；伽論＝摩得勒伽論；母論＝毘尼母論；見論＝善見律毘婆沙；
   鈔＝行事鈔；疏＝含註戒本疏；記＝資持記或行宗記；提＝波逸提；提舍＝波羅提提舍尼；
   法直倍三＝單白／白二／白四；增三＝四分律增一犍度；中國＝中印度；光師＝慧光律師；
   二滅＝已滅擯／應滅擯；和忍＝和同忍可；持說＝受持與說淨；兩頭兩綴＝兩端各一綴；
   百一物＝僧物種類；四位分之＝依四種位次。
3. 義理：主詞（誰做誰受）、因果（因與果是否顛倒）、肯否（不犯是否變犯）、程序（先後次序）、範圍（一切是否被縮小）、增減（是否添加原文沒有的內容）。
4. 數字：數目、單位、加總是否與原文一致（例：兩綴＋三綴＝五綴）。
5. 體例：譯文開頭是否重複加上標籤已有的「義理疏文說」「【疏文】」；《》〈〉「」是否配對；句末是否多餘標點。

【輸出規則】
- 每段輸出一行，順序與材料相同，行數必須等於段數，不可省略。
- 格式：
  編號 ｜ 判定 ｜ 證據
  例：03-0150 ｜ OK ｜ 原文「三趣」→譯文「三趣」；主詞一致
  例：03-0151 ｜ P1 ｜ 原文「伽論」→譯文「善見論」，書名錯
  例：03-0152 ｜ P0 ｜ 原文「…」整句未譯，譯文僅留「…」
- OK 也要寫證據：指出你比對了哪個詞、哪個數字或哪個結構。
- 不確定寫「?」，不要寫 OK。
- 判定：P0＝漏譯／張冠李戴／意思相反／律制事實錯；P1＝術語、義理、因果偏差；P2＝標點體例。

【第二階段：只針對非 OK 的段】
給整段替換文字，規則：
- 除問題句外，其餘與現譯逐字相同。
- 不得增刪內容、不得合併或拆分段落、不得改寫原文。
- 不加譯者按語。
```

## 與前幾版的差異

| 問題 | 前幾版 | 這一版 |
|:--|:--|:--|
| 只做第一關 | 五關並列，AI 常只做術語 | 每段五項一次掃，缺一不可 |
| OK 沒證據 | 「寫你核對了哪一項」 | 必須引原文詞與譯文詞 |
| 半譯、跨段 | 未列 | 列為第 1 項「完整度」 |
| 替換無限制 | 只說「整段」 | 明訂其餘逐字照抄、不得增刪合併 |
| 行數不足 | 未要求 | 明訂行數＝段數 |
