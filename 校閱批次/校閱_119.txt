# 校閱材料　第119檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【119-0001】02_戒疏/18b_卷四上之三#59
【原文】【記】三十七，制中。初敘食緣利害。「故」下，次示制法順違。初明順益。「事順」，謂世俗常儀，皆多朝食。「應法」，謂三世諸佛，並不過中。「過則」下，次明違損，通及自他。言「招譏」者，如《律》緣起：「女人恚言：『沙門釋子，寧自破腹，不應夜食。』」
【譯文】【記文】三十七戒的制意部分。開頭敘述飲食因緣的利害。「故限之令定」以下，其次顯示制戒之法中的順與違。先說明順的好處：「事順」，是說世俗通常的儀節，大多在早晨進食；「應法」，是說三世諸佛都不過中而食。「過則非儀」以下，其次說明違逆的損害，通涉自身與他人。所說「招譏」，就像《律》中緣起所說：「女人忿怒地說：『沙門釋子，寧可自己剖開肚子，也不應該在夜間進食。』」

【119-0002】02_戒疏/18b_卷四上之三#60
【原文】【疏】據《阿含》中《時非時經》明，一年二十四半月，月十五日。準此俗中二十四氣。故彼冬分四月，以八月十六日為始，終於臘月十五日。春分十六日為始，至四月十五日。夏分不言自曉。
【譯文】【疏文】依據《阿含》中的《時非時經》所說，一年有二十四個半月，每個半月十五日。這相當於此方世俗所說的二十四節氣。所以那經中冬分四個月，從八月十六日開始，到臘月十五日結束；春季四個月從臘月十六日開始，到四月十五日；夏分則不必說明也能明白。

【119-0003】02_戒疏/18b_卷四上之三#61
【原文】【記】引示中。《時非時經》出阿含部，今亦別行，在「竟」字函，文近兩紙，廣分三時步影之數，須者尋之。初引經以示。「月十五日」，白、黑分也。「準」下，次會同此方。「俗中二十四氣」，一年十二月中，每一月有兩節氣，大約亦以十五日為一氣。「故」下，三、引三時以證。既以黑月為三時之始，則知西竺月分黑、白，不同此方白、黑共為一月也。
【譯文】【記文】這是「引經顯示」的部分。《時非時經》出自阿含部，現今也有單行本，收在「竟」字函中，文字將近兩紙，詳細分判三時測影的度數，需要的人可以自己尋檢。開頭是引用經文來顯示。「月十五日」，是指白分、黑分各十五日。「準此俗中二十四氣」以下，其次會通此方的曆法。所謂「俗中二十四氣」，一年十二個月之中，每個月有兩個節氣，大約也是以十五日為一個節氣。「故彼冬分」以下，第三是引用三時來證明。既然以黑月作為三時的開端，就可知道印度的月份分為黑分、白分，不同於此方把白分、黑分合為一個月。

【119-0004】02_戒疏/18b_卷四上之三#62
【原文】【疏】然今此國三種日月：一、天上日月；二、人中日月；三、陰陽日月。上二不定，陰陽剋時，楷定無爽。至如佛法，春分以臘月十六日為始者：須準陰陽曆家，大寒是十二月中氣，如是類例，十六日便為立春，剋定步數，可知時分。故《僧祇》中「令作脚影」，此即是也。《多論》晝夜各分九時，《僧祇》日夕三十須臾，唐國晷漏，箭為百刻。
【譯文】【疏文】然而現今此國有三種日月：一、天上日月；二、人中日月；三、陰陽日月。前二種不固定，陰陽曆法所刻定的時刻，則準確固定而沒有差錯。至於佛法中說春分以臘月十六日為開始，這就必須依準陰陽曆家：大寒是十二月的「中氣」，照此類推，十六日便成為立春；刻定測影的步數，就可以知道時分。所以《僧祇律》中說「令作脚影」，就是指這件事。《多論》說晝夜各分為九時，《僧祇》說一日一夜有三十須臾，唐國的晷漏則以箭刻分為一百刻。

【119-0005】02_戒疏/18b_卷四上之三#63
【原文】【記】會通中。初示日月不同。「天上」者，《增輝》云「今所見者」。「人中」者，即今幾時為日，幾日為月。「陰陽」者，即曆數之家剋定分抄以為算數，故云「無爽」。「爽」，差也。「至如」下，次明前經準俗之相。二氣之間，名為「中氣」。然其相準未必全同，但取一月兩分之數耳。「故」下，引證。初證「脚影」同。「多」下，次證時刻同。《多論》「晝夜各分九時」，此據春、秋兩分，晝夜相等，冬、夏兩至，例有增減。《僧祇》「須臾」者，日極長十八，極短十二，晝夜等各十五。「唐國晷漏」者，「晷」即時刻，夏至日六十刻、夜四十，冬至日反上，春、秋分各五十刻。謂以竹箭竪於壺中，水漏箭浮，以分刻數。
【譯文】【記文】這是「會通」的部分。首先顯示三種日月的不同。「天上日月」，是指《增輝》所說的「現今所見的日月」。「人中日月」，就是現在以幾個時辰為一日、幾日為一月。「陰陽日月」，就是曆算之家刻定分秒作為推算的數值，所以說「無爽」；「爽」就是差錯的意思。「至如佛法」以下，其次說明前面所引經文依準世俗的情況。兩個節氣之間，叫作「中氣」。然而兩者相準未必完全相同，只是取一個月分為兩半的數目罷了。「故《僧祇》」以下，是引用證據：先證明「脚影」一法相同；「《多論》」以下，其次證明時刻相同。《多論》說「晝夜各分九時」，這是根據春分、秋分晝夜相等時而說，冬至、夏至則照例各有增減。《僧祇》所說的「須臾」，是白日最長時十八須臾、最短時十二須臾，晝夜相等時各十五須臾。「唐國晷漏」，晷就是時刻，夏至白天六十刻、夜間四十刻，冬至則相反，春分、秋分各五十刻。這是把竹箭豎立在壺中，水漏出而箭浮起，用來分辨刻數。

【119-0006】02_戒疏/18b_卷四上之三#64
【原文】【疏】出家時節，知何不須？然於一食，日別常法。但用步晷一法，足定方隅，縱在山澤，有迷依步，無不立曉。必時陰暗，以鏡映之。寧早不晚，是持護法。

【119-0007】02_戒疏/18b_卷四上之三#65
【原文】【記】結告中。初示須知。「但」下，令準前經。「陰時以鏡映」者，未詳其事。「寧」下，次勸急護。古之高德，奉敬律儀，一食卯齋，用為常務。今時濁惡，噉食無時，設有營齋，遲留至暮，禪師講匠，坐受安然。唯知取適於穢軀，豈念公違於聖教！糞蟲餓鬼，即此心成；銅汁鐵丸，豈從他得？有識高達，宜乎勉之。
【譯文】【記文】這是「結告」的部分。首先顯示必須知道時節。「但用步晷一法」以下，是教人依準前面所引的經文。「陰暗時以鏡映照」，此事未能詳知。「寧早不晚」以下，其次勸人急切護持。古時的高僧大德，奉持敬重律儀，一食卯時用齋，把它當作日常要務。現今時代濁惡，吃東西不按時節，即使有人營辦齋會，也拖延到傍晚；禪師、講經的法匠，安然坐著接受。只知道求取適合這穢惡的身軀，哪裡想到公然違背聖人的教法！糞蟲、餓鬼的果報，就是由這種心念造成的；銅汁、鐵丸的苦報，難道是從別人那裡得來的嗎？有見識的高明之士，應該要勉力而行！

【119-0106】02_戒疏/18c_卷四上之三#23
【原文】【記】釋第一中，《多論》二段。初示名，以下三句，三義釋之。「美食」下，二、簡辨，有四句。初句，「乳、酪」是時食，蘇本是七日藥，今望可充食邊，亦名美食。次句，以「生酥、油」不可直服，故但名藥。「俱是」句中，「魚、肉」是食，復加酥煑，故兼二名。「俱非」中，據「訶棃勒」是盡形藥，然望「七日」，非美物故。若據「藥」、「食」名通，《論》中且約可常作食者名「食」，不可者號「藥」。
【譯文】【記文】在解釋第一部分的文句中，《多論》分為兩段。前段說明名稱由來，藉由後面的三句話從三種意義來闡釋。「屬於美食」以下是第二段，進行詳細的簡別與辨析，共有四種句型。第一種句型中，「乳」與「酪」屬於平常合時的食物，熟酥本質上雖然是七日藥，但從它足以充飢飽腹的層面來看，也算是美食。第二種句型中，因為「生酥」與「香油」不能直接當作日常食物大口吞服，所以只算作藥品。在「兩者皆是」的句型中，「魚」與「肉」本身是食物，又加上酥油烹煮，因此同時兼具兩者的名稱。在「兩者皆非」中，純粹以「訶梨勒」屬於終身服用的藥物而言，相對於「七日藥」的濃郁滋養來說，並不能算作甘美的珍品。若是就「藥」與「食」這兩個名稱在廣義上的互通性來說，《論》中暫且將能夠常態性充當正餐的定名為「食」，無法常態性當作正餐的則稱之為「藥」。

【譯文】【記文】第四十一條說明制戒用意，分為三個方面。第一是招致外道反過來毀謗，這與制戒緣起的事實相符。第二是外道並非合格的福田，這又包含兩層意涵：第一是令人煩惱退失布施的誠心；「同時」以下，第二層是損耗了施主的功德果報。第三是愚弄迷惑了世俗凡夫。「因為」以下，是全文的總結歸納。

【119-0116】02_戒疏/18c_卷四上之三#33
【原文】【疏】論犯六緣。一、是出家外道，以在家者但犯小罪。由出家名同，真偽難別，生人惑倒故重。二、知是。三、非親里，開與父母。《僧祇》中：「父母、兄弟外道出家者，使淨人與。無者，語令自取。若嫌者，答云：『汝出家不得處，佛制戒如是，不食者隨意。』」四、是食，除與衣犯小罪。五、自手與。以食味是通，理無獨食，置地使人，不生感倒故開。六、領受犯。
【譯文】【疏文】若論定構成犯戒，必須具備六項條件：第一、對方必須是已經出家的外道人士，如果只是給予在家外道，僅結犯輕微的小罪。這是因為出家之名相同，世俗人極難辨別真偽，容易令人產生迷惑顛倒，所以從嚴治罪。第二、自己明知對方是出家外道。第三、對方不是自己的至親眷屬；若對方是親生父母，則在開許容許給予的例外之中。《僧祇律》記載：「如果父母或兄弟成為了出家外道，比丘應當派遣佛門淨人代為轉送食物。如果沒有淨人，就開口吩咐他們自己動手拿取。如果他們心生抱怨怨恨，比丘就應當回答說：『你們出家投在非處（誤入邪門）；佛陀制定的戒律本來就是如此，如果不想吃的話就隨你們的便。』」第四、所給予的必須是食物；如果贈與的是衣服，只結犯突吉羅小罪。第五、必須是比丘用自己的雙手親自遞交給對方。因為食物美味是通於大眾滋養之物，法理上本不應完全自私獨吞，若是把食物放在地上或吩咐他人代送，並不會引起世人崇仰外道的顛倒錯覺，因此特許開緣。第六、外道親手受領完畢，此時正式構成犯戒。

【119-0117】02_戒疏/18c_卷四上之三#34
【原文】【記】列緣中。初緣，「在家小罪」者，即汙家犯吉。三、引《僧祇》，彼不開親，還須遣置，今何引者？一、彰部別，二、令兼用，欲使暫加折辱，冀彼迴邪。五中，「食味通」者，容兼濟故。
【譯文】【記文】在列舉犯戒條件中。第一項條件提到「給予在家外道犯小罪」，指的是這種行為類似於阿諛世俗的「汙家」之失，結犯突吉羅罪。第三項引用《僧祇律》，那部律典並未開許親屬例外，依然必須吩咐他人代送或放在地上，那麼此處為何要引用呢？第一是為了彰顯各個部派律典的細部差別，第二是為了讓本宗修行者能兼融運用，藉此暫時給予外道親屬一些折服與羞辱，希望能引導他們悔改回頭、摒棄邪道。在第五項條件中提到「食物美味通於大眾」，是因為食物容許有分甘濟貧、照顧弱小的餘地。

【119-0118】02_戒疏/18c_卷四上之三#35
【原文】【註】佛將弟子從拘薩羅遊至舍衛。佛及眾僧大得餅食，令阿難分與餘乞人。遂以黏餅與女人。又以外道得食，號「禿頭居士得」。佛集僧以所聞告，因制此戒。
【譯文】【註文】佛陀帶領弟子們從拘薩羅國遊化行腳到了舍衛國。佛陀和僧團大眾獲得了信眾供養的大量餅食，佛陀吩咐阿難尊者將多餘的餅分發給其他乞討的人。阿難隨後將黏在一起的餅拿給了一位外道婦女。後來外道乞食得到這份食物後，便四處張揚宣稱：「這是光頭居士給予的。」佛陀召集僧眾並將聽到的譏評告知大家，便順應此事制定了這條戒律。

【119-0119】02_戒疏/18c_卷四上之三#36
【原文】【疏】就戒緣起中，初與女人起過，後與男食反為譏弄，是以便制。
【譯文】【疏文】在探討戒律的緣起過程時，一開始是因給予外道婦女而引發了譏嫌過失，其後又因給予外道男子食物而反遭他們的調侃戲弄，佛陀因此隨即制定了這條戒律。

【119-0120】02_戒疏/18c_卷四上之三#37
【原文】【記】戒緣，有二。初緣「女」者，《律》云是「裸形外道家女，顏貌端正」。注云「黏餅」者，阿難分餅，人各與一，二餅相黏謂是一餅，與此女人。餘乞人云：「彼與女私通，何得不與二也！」
【譯文】【記文】制戒緣起包含兩件事。第一件涉及「女子」的緣起，《四分律》記載她是「裸形外道家中的女兒，容貌極為美麗端正」。隨文註解中提到「黏在一起的餅」，是指阿難在分發餅食時，原本每人都只發給一個，但有兩張餅黏結在一起，阿難誤以為只是一個，就順手給了這位女子。其餘乞討的人見狀便起鬨造謠說：「阿難肯定與那女子有私情，不然怎會平白無故給妳兩個餅呢！」
