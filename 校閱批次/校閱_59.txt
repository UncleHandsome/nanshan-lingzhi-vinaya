# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【59-0001】03_業疏/17b_卷三之六#59
【原文】彼不行者，及至受時，僧問：「滿不？」尼徒無媿，唱言：「滿淨。」自誑不了，用受何為？況面奉佛口，行虗詐，何遽此急，恐失聖耶？然彼聖果，非虗言之所得矣。誡之哉
【譯文】那些不行六法的人，到了受大戒的時候，大僧詢問：「六法年限圓滿清淨了嗎？」尼眾徒眾毫無愧恥，高聲唱答：「已圓滿清淨。」這完全是自己欺誑自己、懵懂無知，這樣受戒又有何用？何況面對佛陀的金口聖教，竟然行使虛假詐術，何必如此匆忙急迫，難道是唯恐失去聖果嗎？然而那殊勝的聖果，絕不是憑藉虛妄誆語所能證得的。千萬應當深切引以為戒啊！

【59-0002】03_業疏/17b_卷三之六#60
【原文】三中初敘謬。以僧中正受，先須問尼六法滿淨。滿謂年具，淨即行具。自下正斥。初斥誑自，不了謂不曉了。況下次斥欺佛。何下斥忽遽。以不行六法，欲速受具故。妄語障道，判非得聖。今時皆爾，五十六法一併而受，便受具戒，必無得理。無戒滿洲，正當今矣
【譯文】在第三段中，首先敘述其錯謬行徑。因為在大僧中正式受戒時，僧中必須先審問比丘尼六法是否「滿、淨」。「滿」是指修學年限具足，「淨」是指六法戒行具足。自「自」字以下正面斥責：首先斥責欺騙自己，「不了」是指不明事理；自「況」字以下接著斥責欺誑佛陀；自「何」字以下斥責匆忙急躁，這是因為不行兩年六法而急於受具足戒的緣故。妄語將障蔽聖道，判定其絕不可能證得聖果。現今時代往往都是這樣，五戒、十戒、六法一併而受，隨即進受大戒，這必定沒有得戒的道理。「無戒之僧充滿天下神州」，正切中了當下的時弊啊！

【59-0003】03_業疏/17b_卷三之六#61
【原文】就乞法緣，五儀具也。兩膝著地，此長跪也，謂足指及膝拄地。律中為身愞弱，互跪倒地，佛令立儀，與僧異也。今時骽地，猶勝大坐佛前也
【譯文】關於乞受六法的因緣，五種威儀必須具足。「兩膝著地」，這就是長跪，是指腳趾與雙膝同時支撐觸地。律中記載，因為女眾身體孱弱，互跪（單膝著地之長跪）容易疲憊傾倒於地，所以佛陀為其制定長跪的威儀，這與比丘僧是不同的。如今女眾即便以臀部著地而坐，也總好過在佛前隨意箕踞大坐。

【59-0004】03_業疏/17b_卷三之六#62

【譯文】在乞受戒法的第一科中，首先總體點出五種威儀；自「兩」字以下分別解釋長跪，並引用制戒的原起因緣，說明女眾與僧眾儀規的不同。「骽」字音吐猥反（音tuǐ），是指用大腿臀部貼地著坐；按照規矩這雖不是正統的跪拜威儀，但比起漫不經心地盤腿大坐還是要好得多。

【59-0030】03_業疏/17b_卷三之六#88
【原文】除自手取食、授食與他」者，有人解為二緣，今則不然。餘行竝同大尼，唯開不受授尼，不同尼從人受，方與尼有此異耳。若論不受惡觸，何得不無？戒下四眾，罪不虗列，理自從人，方可進耳
【譯文】經文所說的「除自手取食、授食與他」，有人解釋為兩種開許的因緣，如今判定並非如此。其餘隨行全都與大尼相同，唯獨開許她們可以不必親自領受食物即可轉授給大尼，不同於大尼必須先從他人處接受受食法，正是在這一點上與比丘尼有所不同而已。若是論及自手取食而觸犯「不受食惡觸」之戒，哪裡能說沒有過失呢？在「不受食而捉持」的戒條下列出了下四眾，其結罪絕非虛設之文，按理自然應當由他人授與，方可進食。

【59-0031】03_業疏/17b_卷三之六#89
【原文】次釋異中，初出古解為二緣者。彼謂「除自手取」，即開自不受而食也；「授食與他」，開為他作能授人也。今下，次示今解。初約一緣釋通文相。「不受授尼」對簡大尼受已可授，準鈔亦據無人方開。若下次斥古謬說。不受食戒下列四眾，可驗同制，義無輙捉
【譯文】在隨後解釋差異中，首先列出古德解釋為兩種因緣的說法。古師認為「除自手取」就是開許自己不用經過授受程序而直接進食；「授食與他」是開許可以作為能授之人而布施食物給他人。自「今」字以下，接著提出當前的正解：首先依據一種因緣來貫通文句相貌。「不受授尼」，是相對於比丘尼而言——大尼必須先領受然後才能轉授他人，依照《事鈔》也是依據沒有淨人等無人之時才作開許。自「若」字以下接著斥責古代的謬誤之說。「不受食戒」之下列舉了出家下四眾，足以證明同樣受到該戒的規制，在義理上絕不可隨意自行抓取食物。
