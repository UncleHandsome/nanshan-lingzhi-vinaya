# 校閱材料　第1848檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1848-0001】03_業疏/18b_卷四之一#92
【原文】三情礙中，《僧祇》兄弟分居同家別室，在中護衣；眾處非界。《五分》、《多論》外道幻惑，樂人蕩逸，王臣威勢，若與同處，皆不自在。遊行門等皆都眾處，既非衣界，制必隨身。下指四分，即離衣中
【譯文】在第三情礙中，《摩訶僧祇律》講親兄弟分家後住在同屋的不同房間，只能在自己房中守護衣物；而公共處所則不是衣界。《五分律》、《薩婆多論》講外道妖幻惑眾，樂人放蕩縱逸，王臣威勢逼人，如果與他們同處，心中皆不能自由自在。大門通道等都是大眾聚集之處，既然不是衣界，便制定衣物必須隨身攜帶。下文指引《四分律》，即在離衣戒的釋文中。

【1848-0002】03_業疏/18b_卷四之一#93
【原文】四者、隔礙，如《僧祇》中天祠門外，須梯須鑰，無者失衣；《四分》水陸道斷，同界難會，豈非失也？故《五分》云：僧作羯磨結不失衣界，而於中不得自在往返者，是離衣也
【譯文】第四種是隔礙（空間物體阻隔障礙），如《摩訶僧祇律》中天祠門外，進門必須用梯子或鑰匙，若沒有這些工具進不去便算失衣；《四分律》中水路陸路阻斷，雖在同一結界卻難以相會，這豈不就是失衣嗎？所以《五分律》說：僧團作羯磨結成了不失衣界，但比丘在其中不能自由自在地來往取衣，這就算離衣。

【1848-0003】03_業疏/18b_卷四之一#94
【原文】四隔礙，《僧祇》衣在祠中，梯鑰可入，方便開之；《四分》可解；《五分》不得自在，義通三礙，為物阻絕，即屬此收
【譯文】在第四隔礙中，《摩訶僧祇律》說衣服在天祠之中，若有梯子鑰匙可以進去，便用方便法開許；《四分律》文義容易理解；《五分律》說不得自在往返，其義理通於前三種障礙，凡是被外物阻隔隔絕的，就歸於隔礙所攝。

【1848-0004】03_業疏/18b_卷四之一#95
【原文】此之四失，廣如別疏。就文明義，羯磨解竟，須附文釋。前已廣解作法攝衣，此明自然，皆歸戒本也
【譯文】這四種失受持相，詳細內容見於別部疏鈔（《戒本疏》）。就本篇文詞闡明義理而言，羯磨作法既然已解釋完畢，就必須隨順經文予以註釋。前面已經詳細解釋了作法攝衣界，此處說明自然衣界，其詳細義理都歸入戒本疏中。

【1848-0005】03_業疏/18b_卷四之一#96
【原文】結中初指廣，即《戒本疏》。「就下」，示今略，謂就今文當廣其義，而結攝衣中已明，今此附文，不宜廣義。「須下」，示前廣此略，各有宗故
【譯文】在結語中，首先指示廣博解釋之處，即《戒本疏》。自「就文明義」以下，指示此處從略之由，即按本篇文字應當鋪展其義理，但在結攝衣界一科中已經講明，如今此處隨文附釋，不適宜再廣博鋪展義理。自「須附文釋」以下，指示前面詳解而此處略述，是因為各有其主旨的緣故。

【1848-0006】03_業疏/18b_卷四之一#97
【原文】受尼師壇法，本梵音也，律翻坐具，故有明相，就文為二
【譯文】受持尼師壇之法。「尼師壇」本是梵語音譯，律中翻譯為坐具，所以有明確顯著的形象，就文義而言分為兩部分。

【1848-0007】03_業疏/18b_卷四之一#98
【原文】受坐具中初科翻名。「有明相」者，似此氈褥，對翻可見故
【譯文】在受坐具的第一科中翻譯名稱。「有明相」，是指如同世間的氈毯褥墊，對照翻譯即可了知其相貌。

【1848-0008】03_業疏/18b_卷四之一#99
【原文】初制緣起中：為身者，以形骸所資，假斯故立也；為衣者，若無坐具，以衣為敷，事不可也；臥具者，恐損僧物，擬用藉之。自非無學，何免穢溢
【譯文】在最初制定的緣起中：為護自身，因為身體形骸所需依憑資助，藉助坐具才得以安立；為護衣服，如果沒有坐具，便用身上的袈裟法衣來鋪墊，這在法事上是不可行的；為護臥具，唯恐損壞僧團常住的被褥器物，打算用坐具來墊藉。若非證得無學果的阿羅漢，誰能免除身體分泌穢物的沾染流溢？

【1848-0009】03_業疏/18b_卷四之一#100
【原文】釋緣中初科三意：一資己身，二敬法衣，三護僧物。無學苦依未亡，尚有穢漏；入無餘已，然始免之
【譯文】在解釋因緣的第一科中有三重含義：一是資益自身，二是恭敬法衣，三是保護僧物。即使是阿羅漢無學聖人，只要苦報之身尚未滅亡，尚且會有體液穢物之流漏；只有證入無餘涅槃之後，才真正免除這一切。

【1848-0010】03_業疏/18b_卷四之一#101
【原文】長周尺量者，律云長佛二搩手，廣一搩手。佛在人倍，人長八尺，佛則丈六，並依周尺以定律呂也。更增半搩者，謂截竟加半搩耳，非謂相連說增也。故佛滅度後一百年之時，毗舍離國擅行十事，「不割縷淨」是其一擅。今世盛有，即䟦闍風，妄情難信，但準聖言，自無咎也
【譯文】以周朝長尺來度量坐具，律中說長度為佛的二搩手，寬度為一搩手。佛的身量是常人的兩倍，常人身長八尺，佛的身長則是一丈六尺，這都是依周尺來配合律呂（法定準則）而制定的。「更增半搩」是指裁剪完成後另外加上半搩手的緣邊，並不是指連同布料主體直接說加大。所以佛滅度一百年時，毗舍離國跋闍子比丘擅自推行十事非法，其中妄執「坐具不裁截邊緣亦屬合律之淨法（不割縷淨）」便是其擅自行事之一。如今世間盛行這種作法，正是跋闍之遺風，凡夫妄情難以憑信，只要遵照聖人的教言，自然就沒有過咎。

【1848-0011】03_業疏/18b_卷四之一#102
【原文】二中初明初量。佛一搩手長二尺，人止一尺。律呂猶準則也，六律六呂，氣候不差故。「更下」，次明增量。初示增法。「故下」，引斥妄行。䟦闍十事，《資持》具引。「擅」謂專輙。「不割縷淨」，謂統同增量，如法無過
【譯文】在第二部分中，首先說明最初的應量。佛的一搩手長二尺，常人只有一尺。「律呂」猶如準則，因為六律、六呂與天地節氣時候絲毫不差。自「更增」以下，其次說明增量的規定。先指示增量之法。自「故佛滅度」以下，引古例斥責妄行。跋闍十事，《資持記》中有詳細引述。「擅」是指專擅妄為。「不割縷淨」，是指彼等妄執將坐具統同一體加大尺寸，是合於戒律而無過錯的淨法。

【1848-0012】03_業疏/18b_卷四之一#103
【原文】必須重者，以單薄用藉：一、損身增患，二、漏汙僧物故也
【譯文】坐具必須作成重層（雙層），是因為若單薄地用來鋪墊坐臥：第一、容易損傷身體而增加疾病患苦；第二、容易使汗垢滲漏而污染僧團的臥具什物。

【1848-0013】03_業疏/18b_卷四之一#104
【原文】三中初示不量二過，兼復損衣
【譯文】在第三項中，首先指出不依法度（作單層坐具）的兩種過失，而且還會兼及損傷衣物。

【1848-0014】03_業疏/18b_卷四之一#105
【原文】如《僧祇》可教誡者，情多樂廣，喜受偽法，故遮惡緣，預設防禁。今不披律，至廣長作，正法滅身也；除依教行，正法生身也。執此兩途，增漏障道也
【譯文】如《摩訶僧祇律》所說應受教誡之人，凡情往往喜好寬大，樂於接受偽妄之法，所以佛陀遮止惡緣，預先施設防範禁制。如今若不展閱律典，乃至將坐具作得極其寬長，這是正法在自身滅沒；若能依教奉行，正法便在自身生起。若偏執於這兩種途徑，便會增長煩惱漏疾而障蔽道果。

【1848-0015】03_業疏/18b_卷四之一#106
【原文】四中初示律意。「今」下斥非，法之興廢在於一身，可不慎乎！違教則如病須藥，依教則病差藥有，二俱障道，情不可留也。注中諸相，並見《鈔》、《記》。
【譯文】在第四項中，首先開示律文的本意。「今」字以下斥責非理，佛法的興盛與廢墜全在於個人一身，怎能不謹慎呢！違背教法就像生了病必須用藥，依從教法則病已痊癒卻仍執著藥物不捨，這兩者都障礙道業，凡情執著絕不可存留。註文中的各種行相，都見於《事鈔》與《資持記》。

【1848-0016】03_業疏/18b_卷四之一#107
【原文】言不得淨施者，以宅所履，本制須之，必受持也。自餘聽畜，方開淨施。今多說淨，無有受者，不可怪也。說淨猶次，但無準的
【譯文】所說坐具「不得作淨施」，是因為它是安居鋪墊、坐臥所履踐之物，本律規定必須具備，所以必須加法受持。其餘聽許蓄留之衣物，才開許作說淨施。如今大多只是行說淨法，卻沒有依法受持者，不足為怪（因其不知教法）。說淨法尚屬次等，只是沒有切實的依準。

【1848-0017】03_業疏/18b_卷四之一#108
【原文】五中初明制受，非長故不聽淨。「宅」，居也。「今下」，斥非。「不可怪」者，不知教故。「說淨次」者，次於受持，勝不受故
【譯文】在第五項中，首先說明制定應當受持，因為它不是長物，所以不聽許作說淨。「宅」即安居之意。「今」字以下，斥責非理。「不可怪」這句話，是因為彼等不知教法之故。「說淨次」是指，說淨之法次於受持法，但還是勝過全不受持。
