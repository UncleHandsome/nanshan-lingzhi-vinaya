# 校閱材料　第411檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【411-0001】02_戒疏/04b_卷一下之二#107
【原文】【疏】惡既已離，事須修善。必當勤䇿三業，修習戒行。有善斯護，名之為「持」。持由作成，故號「作持」。如衣食四緣，威儀雜行，作意防擬，方成戒淨。此對修習善法為宗。
【譯文】【疏文】惡行既然已經遠離，理應當修持善法。必須精進策勵身口意三業，修習戒律的行持。凡有善法皆能精勤守護實踐，稱之為「持」。持戒是由積極作為而促成的，所以號稱「作持」。例如衣、食等四種資生之緣（四緣），威儀以及各項僧中雜行，用心防護與准擬規劃，才能成就戒行的清淨。這是以「修習善法」為其宗旨。

【411-0002】02_戒疏/04b_卷一下之二#108
【原文】【記】作持中，躡前生起。「必」下，釋義，亦五。初釋作。「有」下，明持。「持由」下，合名。「如」下，指事。衣、食、藥三，皆通受淨，房有制量、乞法。或可糞衣、乞食、樹下、腐藥，《羯磨疏》中科為「根本作持」。修道假此，故名「四緣」。「雜行」，總收眾共，皆作持攝。「此」下，示宗，可知。
【譯文】【記文】在作持之中，是接續前文止惡而生起的。「必」字以下解釋其意義，也是分為五節。首先解釋「作」。「有」字以下說明「持」。「持由」以下合稱其名。「如」以下指示具體事相。衣、食、藥這三項，皆通於受持與淨施之法，建造房舍則有規定的尺碼容量、以及向僧眾乞請的合法程序。或者糞掃衣、常乞食、樹下坐、腐爛藥（四依），在《羯磨疏》中科判為「根本作持」。修道仰賴這些條件，所以稱作「四緣」。「雜行」，總括收羅僧團大眾共住共行的規範，全都被作持所包攝。「此」以下指示宗旨，道理顯而易見。

【411-0003】02_戒疏/04b_卷一下之二#109
【原文】【疏】所以前後不同者。《論》云「戒相止，行相作」也。又云「惡止善行，義之次第」。
【譯文】【疏文】前後次序之所以不同的原因：《論》中說「戒的行相是止息，行的行相是作為」。又說「止息惡行、力行善法，是義理上的必然次第」。

【411-0004】02_戒疏/04b_卷一下之二#110
【原文】【記】次所以中。初徵意者。以修捨義順，今相反故；又止作體同，今分異故。《論》下，次引釋。《論》即《百論》，文有二段。初釋不同。彼明佛說法有二種：一止相，二行相。謂息一切惡名止，修一切善名行。外道難曰：「已說善行，不應復說惡止，以惡止即善行故。」內曰：「止相息，行相作，性相違故。」今變其語，取其義耳。「又」下，次釋前後。彼云：「外人又難曰：『善行應在初，以善法有妙果故。』內曰：『次第法故，先除麤垢，後染善法。』」
【譯文】【記文】接著說明次序緣由。最初探問用意。因為就修持與捨棄而言，修似乎應在前，如今卻將止惡放在前面；又因為止與作的體性相同，如今卻區分前後，所以提問。《論》以下，接著引文解釋。「論」就是指《百論》，文中有兩段。首先解釋兩者的相異。彼論說明佛陀說法有兩種：一是止相，二是行相。也就是止息一切惡稱作止，修習一切善稱作行。外道詰難說：「既然已經說了行善，就不應再說止惡，因為止惡本身就是行善。」佛法內宗回答：「止的行相是休止，行的行相是起作（造作），兩者的性質是相反的。」如今疏文變更了論中的語句，擷取其義理罷了。「又」字以下，接著解釋前後順序。彼論說：「外道又詰難說：『善行應當排在最初，因為善法具有殊勝的果報。』內宗回答：『這是由於修持的先後次第，必須先除掉粗重的垢穢，之後才能染習善法。』」

【411-0006】02_戒疏/04b_卷一下之二#112
【原文】【疏】言「作犯」者，出家五眾，內具三毒，我倒自纏，不思對治，鼓動三業，違教造境，名之為「作」。作與持違，汙本所受，名之為「犯」。犯由作成，故曰「作犯」。此對造作惡法為宗。
【譯文】【疏文】所說的「作犯」，是指身為出家五眾，內心具足貪瞋癡三毒，被我執倒錯所纏繞，不想方設法對治，反而發動身口意三業，違背教法去造作惡境，這就稱之為「作」。這樣的造作違背了持戒，玷污了原本所受的戒體，這就稱之為「犯」。犯戒是由積極造惡而形成的，所以稱作「作犯」。這是以「造作惡法」為其違犯的主旨。

【411-0007】02_戒疏/04b_卷一下之二#113
【原文】【記】作犯中。初牒名，「出」下，釋義有四。初釋作。初句標能犯之人，次二句敘起業之本。「不」下，正明造業，釋成「作」義。「作與」下，次釋犯。「犯由」下，三、合名。「此」下，四、顯宗。兩犯並不指事者，翻持可知故。
【譯文】【記文】在作犯之中。最初列出名稱，「出」字以下，解釋其意義有四段。首先解釋「作」。第一句標示出能違犯的人，接著兩句敘述造業的根源。「不」字以下，正式說明造作惡業，藉此釋成「作」的意義。「作與」以下，接著解釋「犯」。「犯由」以下，第三、合稱其名。「此」字以下，第四、彰顯宗旨。這兩犯之所以沒有具體列出所犯的事相，是因為反轉持戒之相即可明白的緣故。

【411-0008】02_戒疏/04b_卷一下之二#114
【原文】【疏】惡既作矣，必不修善，是以第二即明「止犯」。良由癡心怠惰，不奉教法，行違本受，厭而不學，故名為「止」。止而有違，反彼願本，故名為「犯」。犯由止成，故名「止犯」。此對不修善法為宗。
【譯文】【疏文】惡事既然已經去造作了，必然無法修持善法，因此第二項隨即說明「止犯」。這確實是由於愚癡的心態導致懶惰懈怠，不奉行遵從教法，行徑違背了當初受戒的誓願，心生厭倦而不肯學習，所以稱之為「止」。在該行善處止步而有所違背，反背了最初的願心根本，所以稱之為「犯」。犯戒是由消極怠止而構成的，所以稱作「止犯」。這是以「不修善法」為其違犯的主旨。

【411-0012】02_戒疏/04b_卷一下之二#118
【原文】【記】二、明體狀，「昔解」中。初明止持，通指十惡。「屈」下，明作持。初二句即身業；「讚」下，是口業；「意」下即意業。上明事行，「各」下，次列心觀。初句即指五停心、總別相念等。「離染行」者，即十二頭陀。「四弘」，即四無量心，文舉「慈悲」，而略「喜捨」，如後對破。二犯，相反，可解。此師大要，不明化制兩教業行不同。故下並約制教難破。
【譯文】【記文】第二、說明體狀中，引錄「往昔解釋」。最初說明止持，普遍指向斷除十惡。「屈」字以下，說明作持。最初兩句就是身業；「讚」以下是口業；「意」以下則是意業。以上是說明具體的事相行持，「各」字以下，接著列出內心的觀想。初句即指五停心觀、總相念住與別相念住等。「離染行」，就是十二頭陀行。「四弘」，就是四無量心，文中列出「慈悲」而略去了「喜捨」，後面會針對這點駁難反破。兩種犯戒，正好相反，理應明瞭。這位論師的大意，在於沒有弄清楚教化眾生的「化教」與制定僧規的「制教」在業行上的差異。所以下文全部依據制教來提出詰難破除。
