# 校閱材料　第180檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【180-0001】02_戒疏/17b_卷四上之二#110
【原文】【疏】論犯四緣：一、是尼三眾，《五分》、《多論》「尼眾俱犯提罪」，道、船行戒亦爾，除去俗女不犯此戒；二、是隱、露處；三、無第三人，人相如《鈔》中；四、共坐便犯，《多論》：「比丘坐住，隨尼起坐，一一結提。尼坐亦爾。兩人同一坐，通日但一墮。」
【譯文】【疏文】論述構成犯戒的四個條件：第一、對方是尼眾三眾，《五分律》與《薩婆多論》都主張「尼三眾在此戒中同樣結犯波逸提」，後面的「同道行戒」與「同船行戒」也是如此，除了世俗女子不在此戒結犯（另有俗女戒）；第二、處所屬於隱蔽處或露天處；第三、現場沒有具備見證資格的第三人在場，合適的見證人行相如《行事鈔》中所載；第四、雙方一同坐下即構成犯戒，《多論》指出：「比丘坐著不動，尼眾隨之起立又坐下，每一次坐下都各自結犯一次波逸提。比丘尼坐著不動比丘起坐也是如此。若兩人同坐在一張長座上，整日相續不起只結犯一次墮罪。」

【180-0002】02_戒疏/17b_卷四上之二#111
【原文】【記】犯緣。第一，《四分戒本》唯據大尼，故引他部。既云「尼眾」，通三不疑，及後「道、船」例同此判。「除俗女」者，下有別制，故云「不犯此」也。第三，指《鈔》，彼「與女坐戒」引《僧祇》云「若母、姉妹，若大小淨人、睡眠、癡狂、嬰兒，並非證人」。
【譯文】【記文】在犯戒條件中。第一項，《四分戒本》雖然表面只依大比丘尼立名，所以引用其他部派律典作證。既然通稱「尼眾」，毫無疑問通指三眾，後文的「道行戒」、「船行戒」也都依此類推判定。「除世俗女子」，因為下文另有單獨制定的戒律，所以說「不犯此戒」。第三項，指向《行事鈔》，該書在「與女人共坐戒」中引用《僧祇律》說「如果是母親、姊妹，如果是年長或幼小的淨人、正在熟睡者、癡狂者、嬰兒，都不具備第三見證人的資格」。

【180-0011】02_戒疏/17b_卷四上之二#120
【原文】【疏】二、與尼。「作衣」、「與衣」，親無染譏故開。「屏坐」、「同行」，不問親疎，外人不練，招譏義一。
【譯文】【疏文】第二句、與比丘尼。「作衣戒」與「贈衣戒」中，親屬尼眾沒有情染與譏嫌，所以開許。「屏處共坐」與「同道而行」，不論是否為親屬，外界不知底細，招致的譏嫌是一樣的。

【180-0013】02_戒疏/17b_卷四上之二#122
【原文】【疏】三、屏處。如《律》中「見、聞兩屏」，其相可解。「盲、聾」互有，不成全證，故吉。由是坐戒，「立」故是輕。
【譯文】【疏文】第三句、屏處。如《四分律》中所說「眼見隱蔽」與「耳聞隱蔽」兩種屏處，行相很容易理解。「盲、聾」互有缺陷，不能構成完全的見證，所以犯突吉羅。因為本戒是針對「坐」而制，比丘與尼若僅是站立（非坐），威儀緣相不合，故僅犯突吉羅輕罪。

【180-0014】02_戒疏/17b_卷四上之二#123
【原文】【記】第三。初指二屏，注釋頗詳，委如「二不定」中。「盲」下，次釋第三人。「由」下，三、釋立住。上是根缺，下即緣乖，故並犯輕。
【譯文】【記文】第三句。首先指出兩種隱蔽處，註解解釋得相當詳盡，具體情況就如「二不定法」中所闡述。從「盲聾」以下，接著解釋第三人的資格。從「因為」以下，第三是解釋比丘與尼站立（未坐）的行相。前面屬於根官殘缺，後面屬於威儀行相不合，所以都結犯輕罪。

【180-0015】02_戒疏/17b_卷四上之二#124
【原文】【疏】所以尼輕者，上尊共坐，志不自由，過微故也。
【譯文】【疏文】之所以比丘尼處罰較輕的原因，是因為與上位尊宿一同坐著，心意不由自主，過失較微細的緣故。

【180-0016】02_戒疏/17b_卷四上之二#125
【原文】【記】第四，初科。徵示尼輕，由非意故。或可上尊狎下則易，下位牒上則難，故雖同坐，情過自別。
【譯文】【記文】第四句，此為第一科。探問說明尼眾罪輕的原由，是因為並非由尼眾主導之故。或者可以說上位尊長親近下位較為容易放肆，下位要主動攀附上位則較為拘謹困難，所以雖然同坐，心中的過失情節自然有別。

【譯文】【疏文】開許條文中的「不盲不聾」，是為了開解免除前面「盲而不聾」那一類有缺陷的文句，下文所列也是如此。其餘情況皆容易理解。

【180-0018】02_戒疏/17b_卷四上之二#127
【原文】【記】次科。釋注「不盲」等，二句語同，互倒而列。對翻互缺二句，以開吉羅。「餘可解」者，行倒、病、勢，皆非意故。

【180-0022】02_戒疏/17b_卷四上之二#131
【原文】【記】二十七。「制同前」者，事別意通，故不重舉。宿、坐、船、行，離染無別，隨境造作，事相不同。文多略指，其意若此。
【譯文】【記文】第二十七條。「制意同前」，是因為事情雖然不同但防患之意完全相通，所以不再重複舉述。同宿、共坐、共船、同行，遠離情染的本意毫無二致，只是隨著境界造作的不同，事相才有所區分。文中大多簡略指出，用意就在於此。

【180-0023】02_戒疏/17b_卷四上之二#132
【原文】【疏】六緣犯。《多論》云：一、尼家三眾；二、共期，除偶相值，或期不許，不離聞處；三、同一道；四、不離見聞處；五、無緣；六、隨度界犯。
【譯文】【疏文】具備六個條件即構成犯戒。《多論》說：第一、對方是尼家三眾；第二、事先共同約定同行，除非是偶然相遇，或者是約定而對方未答應，彼此未脫離能聽聞的範圍；第三、走在同一條道路上；第四、彼此未脫離眼見與耳聞的距離；第五、沒有正當開許的因緣；第六、隨跨越界限即構成犯戒。

【180-0060】02_戒疏/17c_卷四上之二#19
【原文】【疏】何故不開「別眾」七緣？聖人制戒，開遮防過。此戒由歎無德，於法深損，通無所開。是以《多論》云「但偏歎德，不問凡聖，食者皆墮」。
【譯文】【疏文】為什麼不開許「別眾食戒」中的七種因緣呢？聖人制定戒律，開許與禁止都是為了防範過失。這條戒律是因為讚歎無德之人獲食，對佛法有極深的損害，所以全面禁止而不開許。因此《薩婆多論》說「只要是偏私讚歎其德行而獲食，不論是凡夫還是聖人，吃下去的人都會墮入罪苦」。

【180-0061】02_戒疏/17c_卷四上之二#20
【原文】【記】簡別眾中。初徵。二、釋，又二。初通示開遮。「別眾」須開，遮則失利，此戒宜遮，開則有過，開遮隨時，不可一槩。「此」下，正明當戒不開之意。供施有德，植福良田，是佛所教，今則反之，故云「探損」。「是」下，引示。若知彼贊，雖聖尚犯，況無德耶？聖必無犯，為約下凡極誡耳。
【譯文】【記文】在甄別別眾食的段落中。首先提出質問。第二部分進行解釋，又分為兩節。首先通論開許與禁止的原則：別眾食必須開許，若一味禁止會讓比丘失去利益；而本戒則應當禁止，若給予開許就會產生過失，開許與禁止必須順應時節因緣，不能一概而論。從「此戒」以下，正式說明本戒不予開許的用意：供養布施有道德的人以在良田中修福，是佛陀的教導，如今本戒的作法卻與之相反，所以說是「深損」。從「是以」以下，引述經論作證明。如果明知對方讚歎，即使是聖人去吃尚且都犯戒，更何況是沒有德行的凡夫呢？其實聖人必定不會犯戒，這樣說只是就教誡一般凡夫而作出的極重告誡罷了。

【180-0074】02_戒疏/17c_卷四上之二#33
【原文】【記】次《成論》中。初句立義。「乃」下，釋成。初約佛與弟子對校。彼論問云：「為智福勝，為斷福勝？」答：「智能達法相，謂畢竟空，此則勝斷。何者？如佛以智故，於弟子中勝，不以斷故。」、「供」下，次唯就弟子比校，文為三段。初示勝劣。「前言」下，《論》自釋難。彼論前引《雜藏經》「供百初果，不如一二果」，與此相違故。「從」下，釋通，有二。初云「從多說」者，謂前經且據多少相望，初果多故劣，二果少故勝，今此約智，與彼不同。「亦」下，次約不了釋，謂彼經赴機一往權說，非究竟故。「還」下，還據彼經會同前義。初引畜生勝人道。「又」下，次引因人勝果人。彼云「彌勒菩薩雖未得佛，為羅漢所禮，由智大故」，又云「乃至沙彌發無上心，羅漢自取衣鉢，擔隨後行，故知智慧福田為勝」。
【譯文】【記文】接下來是引述《成實論》的段落。第一句立下義理主張。從「乃至」以下，解釋論證。首先以佛陀與弟子的關係作比校：該論提問道「究竟是智慧的福報殊勝，還是斷惑的福報殊勝？」回答說「智慧能通達法相，也就是了達畢竟空，這便勝過單純的斷惑。為什麼呢？因為佛陀是以智慧的緣故，在諸弟子中尊貴超勝，而不是單憑斷盡煩惱的功德。」從「供利根」以下，接著單就弟子之間進行比較，內文分為三段。第一段指出勝劣差別。從「前言」以下，是該論自行解釋疑難：因為該論前面曾引《雜藏經》說「供養一百位初果不如供養一位二果」，與這裡的主張相違背。從「從多說」以下，進行會通解釋，共有兩種：第一種說「從多說」，是指前面的經典暫且從人數多寡來對比，初果人多故算劣，二果人少故算勝，而現在此處則是就智慧利鈍來論，與那裡不同；從「亦不了」以下，第二種依非了義來解釋，是指那部經是為了適應某些眾生的根機而暫作權巧說法，並非最究竟之談。從「還即」以下，依舊引用那部經文來會合相同的義理：首先引用畜生勝過人道的例子；從「又如」以下，接著引用因地菩薩勝過果位羅漢的例子：論中說「彌勒菩薩雖然尚未成佛，卻受到阿羅漢的頂禮，這是因為他智慧廣大的緣故」；論中又說「乃至於沙彌發了無上菩提心，阿羅漢便親自為他拿取衣缽、背在後面跟隨，由此可知以智慧為福田是最為殊勝的」。

【譯文】【記文】戒本條文。在第三句中，注文列出了讚歎的言辭，也就是修持十二頭陀等德行，這在前面「讚歎己身」戒中已經詳細具備了。
