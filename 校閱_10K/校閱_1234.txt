# 校閱材料　第1234檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1234-0001】資持記/11c_中四上#39
【原文】學者請試詳之。次近方便，在文易見。指例中。上且約婬示相，三戒準同；餘篇不明，故須略指。僧殘一吉二蘭；提下三篇，例皆二吉；輕重多少，不同可見。然殘中三罪，一同初篇；提下二吉，止分遠近，遠則同前；復合次近，總為一吉；大相可準，其義如是。
【譯文】請研學者試著仔細推詳其中的奧妙。次方便與近方便兩科，在鈔文中容易明白。在指示通例之中，上面姑且就淫戒來展示行相，其餘三條重戒也是比照相同；其餘篇聚中沒有詳細闡明，所以必須稍微加以指明。僧殘罪具備一個吉羅與兩個偷蘭遮；波逸提以下的後三篇，依例全都是兩個吉羅；其中的輕重與多寡，彼此不同是一目了然的。然而僧殘中的三種罪責，完全同於初篇的規定；波逸提以下的兩個吉羅，只區分遠方便與近方便，遠方便就同於前面的吉羅；接著把次方便與近方便合併，總結為一個吉羅；大致上的行相可以比照推演，其義理就是如此。

【1234-0002】資持記/11c_中四上#40
【原文】釋名中，即用《了論》，成就隨順二義釋之，初即成就義。注指七緣，文見次科。若下，即隨順義。根本中，前明根本之相，初句通問。謂下，別釋，初列示四重。如下，總指諸篇。若下，明攬因成果。簡異他宗，使無濫用。後方便中。不論篇聚重輕，竝制一吉，故云通也；
【譯文】在解釋名稱之中，直接採用《了論》所說的「成就」與「隨順」兩種義理來作解釋，首先就是「成就」的義理。注文中所指的七種條件，文句見於下一科。從「若下」開始，就是「隨順」的義理。在「根本罪」中，前面先說明根本罪的相狀，第一句是統貫發問。從「謂下」開始分別解釋，首先列出並開示四條重戒。從「如下」開始，總括指涉其餘各篇。從「若下」開始，說明牽引因地而結成果報。這也是為了揀擇異於其他宗派的主張，使兩者不致混淆濫用。在「後方便」中，不論篇聚是重還是輕，全都制定為一個吉羅罪，所以說是「通同」；

【1234-0003】資持記/11c_中四上#41
【原文】翻前方便，二三不同，蘭吉有異故也。三明具緣，標中。語含通別二種；通則遍該諸聚，名數齊均；別則隨局戒條，體相各異。凡於一犯，考以兩緣；則成不歷然，判斷有據矣。敘由中，初標示。業下，正敘為二，初明作業成不。上明緣具成業；必下，明緣缺不成。罪即惡業，福即善業；
【譯文】這是因為翻轉了前方便那種二個或三個層次的不同、以及偷蘭遮與吉羅在名相上的差異。第三部分闡明「具足因緣」，在標題中。文字涵蓋了「通緣」與「別緣」兩種：通緣是普遍涵蓋所有的戒聚，名目與數量都是齊平劃一的；別緣則是隨著侷限在各個個別戒條，本體與行相各自不同。凡是對於一樁犯戒事實，只要用這兩種因緣來考量核對；那麼到底成不成立犯罪就會清清楚楚，判決斷定也就有了依據。在敘述緣由中，首先標示說明。從「業下」開始正式敘述，分為兩部分，首先說明造業到底成立不成立。上面是說明條件具足就結成罪業；從「必下」開始，說明條件缺漏就不能結成罪業。罪指的就是惡業，福指的就是善業；

【1234-0004】資持記/11c_中四上#42
【原文】此論成犯，正明罪業；但緣搆義同，故茲通示。故下，次明化制不同，初敘制教；上二句，指律制。因緣，則總通別，或可二緣不出心境，因即是心，緣即是境。為下二句，顯所以。即為二別，上句明制科楷定，下句顯六懺不互。不下，次簡化教。彼明造業，亦是緣成；
【譯文】這裡論及成立犯戒，主要是在闡明罪惡之業；但因緣組織構建的義理是相同的，所以在此普遍加以開示。從「故下」開始，其次說明教化教法與制戒教法（化制二教）的差異，首先敘述制戒之教；前兩句是指律法的制定。所謂因緣，則是統括了通緣與別緣，或者也可以說這兩種緣不超出心念與境界，因就是指內心，緣就是指外境。從「為下」的兩句，彰顯其中的緣由。這構成了兩種差別：上一句說明制刑科條極其權威規範且確立不變，下一句顯明六種懺悔法門各自獨立不能互相通用。從「不下」開始，其次揀擇化教的範疇。化教闡明造作惡業，雖然也是由因緣和合而成；

【1234-0005】資持記/11c_中四上#43
【原文】但不局名數，故為異耳。對上二別，反為二通；一者罪通十業，二者懺通三世。次科，通敘中，初總標。依諸戒者，二緣竝出律文戒本故。別下，二別示，初指別緣。有下，立通緣，先示古立。〔舊云：願師立五緣：一是大比丘，二有所對境，三有心，四心境相當，五事戒究竟。
【譯文】但並不局限於固定的名目與數量，差別就在這裡。在對照上述的兩種差別時，化教反過來呈現為兩種普遍通融：一是罪業通攝身口意十業，二是懺悔通於過去、現在、未來三世。在下一科「通敘」之中，首先是總體標示。所謂「依照諸戒」，是因為這兩種緣都出自律文與戒本的緣故。從「別下」開始分別開示，首先指明個別緣（別緣）。從「有下」開始建立共同緣（通緣），先展示古代大德的說法。（舊說認為：願律師建立了五種緣：一必須是大比丘，二有對象境界，三有犯心，四心念與境界相符，五事件情節究竟圓滿。

【1234-0006】資持記/11c_中四上#44
【原文】非無此義者，示有可取，不盡非故。後進未知者，彰其所失，未盡善故；謂人多承用，曾未思審；用今對校，方顯是非。今下，次標今立。考下七緣，自有通局；如命梵二難，不開夷殘；又下三篇，不開性戒；何須此緣，然今對別，大約為言，故云遍六聚也。
【譯文】所謂「並非沒有這個道理」，是顯示該說法尚有可取之處，並非全盤皆錯。所謂「後進之輩尚不知曉」，是彰顯古說的缺失與不夠圓融純善；意思是許多人盲目承襲引用，從來不曾審慎思索；唯有用現在的體系去對照校勘，才能顯露出其中的是非優劣。從「今下」開始，其次標示今日所確立的規範。考查下面的七種緣，本身自有通達與局限的區別；例如生命與梵行的兩種危難，並不開許給波羅夷與僧殘罪免責；再者後三篇中，也不對性戒給予開許；那麼又何須建立這個通緣呢？然而現在是相對於別緣而言，只是作個大體上的概括，所以才說「普遍涵蓋六聚」。

【1234-0007】資持記/11c_中四上#45
【原文】第一緣中，初句標緣。以大小雖殊，塵沙遍發，故通五眾，異上古師。餘文簡濫，初簡非眾。或是下，簡是眾。文列五相，即是四捨。竝下，總結。業思暢者，除命終他殺，餘三種也。二中。重病即通標；顛下二句，別顯兩相。若下，正示緣相。顯上重病，皆不了知。第三，初科，初標緣。
【譯文】在「第一緣」中，第一句標示該因緣。因為大眾與小眾戒品雖然有別，但戒體是遍及如塵沙般無量境界面前所發起的，所以通攝於出家五眾，這與上述古師的見解不同。其餘的文字是用來揀除混濫，首先揀除不屬於僧團之眾。從「或是下」開始，揀除雖曾是僧眾但已失戒的情形。文中列出了五種相狀，其實就是指四種捨戒的因緣。從「竝下」開始做總結。所謂「業念思緒通暢」，是指除了命終與被他人殺害之外的其餘三種情形。在第二緣中，嚴重的重病是總體標示；從「顛下」開始的兩句，分別顯示兩種狂亂顛倒的病相。從「若下」開始，正式展示該緣的行相。這顯示上述重病中的人，全都是處於無知無覺的狀態。在第三緣中，第一科首先標示因緣。

【1234-0008】資持記/11c_中四上#46
【原文】非下，示相又二，初遮簡。文列對境，四種無心；律文所開，據無方便；恐人妄謂一向無犯，故云非謂等。若下，顯正。謂後對境，雖人餘心；由先方便，即心當境，故皆結犯。如〈隨相〉中，漏觸飲酒等；及前通塞，教人自業；《戒疏》，沙彌任運等，類然。
【譯文】從「非下」開始展示行相又分為兩部分，首先是遮除揀擇。文中列出了面對境界時四種無心的狀態；律文中所開許免罪的，是依據沒有事先造作方便罪的情況；唯恐有人妄自以為一概都不犯戒，所以才說「並非指」等語。從「若下」開始顯示正確的義理。意思是說後來在面對境界時，雖然墮入了其餘無犯的心境；但由於先前已經造作了方便罪，當初的心念已經鎖定在對境上，所以全都必須結算犯戒。正如〈隨相〉篇中，遺精、撫觸、飲酒等情況；以及前面關於通開與閉塞中，唆使他人造業而視為自身之業的道理；又如《戒疏》所說，沙彌在不自覺中造業等，全屬此類。
