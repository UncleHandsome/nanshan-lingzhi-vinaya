# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【600-0002】04_比丘尼鈔/03b_卷中之上#32
【原文】八事成重戒具五緣成一是男子二男子想三有染心四七事未懺悔五作八事便犯此律捉手者輕腕已後重捉衣者身上衣入屏處者謂離伴見聞處共立共語共行者亦離見聞處也身相倚者二身相及處共期者共行婬處若尼及男子二俱染心犯前七事者偷蘭若不懺悔犯第八事竟波羅夷若準此犯八捉手不成重以事是一文若一男犯八或一時犯八八年犯八八男成八俱犯重罪亦無次第僧祇亦然不犯者此律云若有所與禮拜悔過受法屏處不作惡事不犯俱無染心故下文暗室者提以招機故覆藏他重罪戒具六緣成一是大比丘尼二犯重罪三知他犯重四作覆藏心五不發露六明相出便犯十誦云若尼被舉狂亂心覆者不犯若狂止覆者便犯僧祇云知尼犯應向人說若犯罪人兇惡有勢力者恐有命梵等難應作念言彼業行罪報自當知喻如失火燒舍但自救身焉知他事得心相應便罷義云若欲發露故不成者為非清淨者若對先知不肯發露人二俱有過以各須發露故如向有犯者不成懺悔若欲發露稱犯重人名各各說罪名種方成發露若不得人名罪名無覆藏過若前人受他發露竟不須更說若說則有無窮之過若彼犯人自發露竟餘人作覆藏心皆不成以根本已發露竟十誦云尼不得比丘前發露麤過還向尼前懺悔若不識罪相至比丘所汎問取解還至尼邊懺悔此律若知尼犯重前食時知後食時說蘭乃至初中後夜時時並蘭明相出重不犯者若無人可向說意欲說而未說明相出或命梵等難不說皆不犯。
【譯文】八事成重戒（共男八事）：具備五種條件構成犯戒：一是真正男子；二明知是男子並作此想；三心懷染污淫意；四前面所犯的七件事尚未向僧眾懺悔；五進而造作第八件事，即成犯重罪。本律所列八事：抓手是輕觸手腕之後是重，拉扯衣服是指男子身上所穿的衣服，進入隱蔽處是指離開同伴視線與聽覺範圍的僻靜處，一同站立、一同說話、一同行走也都指離開他人能見能聞的隱秘之處，身體互相倚靠是指兩具肉身互相貼靠之處，共同期約是指暗中約定共同行淫之處。如果比丘尼與男子雙方都心存染污，犯了前面七件事，皆犯偷蘭遮罪；如果一直不加懺悔，最後又去赴約完成了第八件事，便徹底構成波羅夷罪。如果依據此項標準，只犯了前面抓手等八件事中的零星項目，尚不構成波羅夷重罪，因為八事合為一條戒文；但如果跟同一個男子接連犯全了八件事，或者在同一個時間段犯全八事，乃至歷經八年犯全八事，或者分別與八個男子各犯一事累計成八事，全都結犯重罪，而且各事的發生也沒有先後次序的限制。《僧祇律》也是同樣的規範。不構成犯戒的情況，本律說：如果有正當因緣給予物品、行禮拜、求悔過、領受法教，在僻靜隱蔽之處絕不造作惡事，不犯戒，因為雙方完全沒有染污之心的緣故。至於下文提到的「暗室」，那是犯波逸提罪，因為暗室私處容易招致世人譏嫌猜忌。覆藏他重罪戒：具備六種條件構成犯戒：一是已經受戒的大比丘尼；二確實犯了波羅夷重罪；三清楚知曉他人犯了重罪；四心中萌生隱瞞包庇的念頭；五不肯向僧眾發露檢舉；六等到次日清晨天色黎明、天光初現（明相出），便構成犯戒。《十誦律》說：如果比丘尼被舉劾時正處於癲狂混亂的心智失常中而未舉發，不犯戒；若是瘋狂停止、神智清醒後仍予隱瞞，即刻犯戒。《僧祇律》說：知曉某尼犯了重罪，應當向其他人說出檢舉；如果犯罪之人兇狠殘暴且富有權勢，檢舉她恐會招來殺身之禍或梵行毀滅等危難，此時應當在心中作意觀想：「她所造下的罪業行徑與罪業果報，未來她自己自會承擔受報；好比失火焚燒房屋，眼下只能先顧全己身，哪裡還顧得上他人的事？」只要內心這般作意相應，便可暫時罷手。依義理來說：如果存心想要發露檢舉，卻因故無法完成舉證，那是因為被告知的人並非清淨有威望的僧人；如果面對早就知情卻不肯發露檢舉的人，這兩個人都有過失，因為雙方各自都有舉證的責任。如果知情者自己也有罪在身，就不能構成合法的受懺人。如果想要發露舉證，必須逐一稱呼犯重罪人的法名，分別說清楚她所犯罪行的名稱與種類，這才算完成了發露；如果說不出犯人的名字與罪名，就不算完成了檢舉，但也不構成隱瞞包庇之過。如果受懺者已經接受了對方的發露，便不需要再向旁人宣說；如果再去宣說，就會有宣揚罪過的無窮過失。如果那個犯罪的人自己已經發露完畢，其餘不知情而未及時檢舉的人，心中即便動過隱瞞的念頭，也全都不能結成覆藏重罪，因為根本的罪行已經有人發露清楚了。《十誦律》說：比丘尼不得在比丘面前發露粗鄙重罪，必須回到比丘尼僧眾面前求懺悔；如果自己搞不清楚具體的罪名行相，可以前往大僧長老處泛泛諮詢以求明瞭義理，弄懂之後仍要回到比丘尼僧前正式懺悔。本律說：如果知道比丘尼犯了重罪，在上午飯前知情、延宕到下午飯後才說，犯偷蘭遮罪；乃至拖延到初夜、中夜、後夜才說，時時刻刻都結犯偷蘭遮罪；一旦黎明天光大亮仍舊不說，便正式結成波羅夷重罪。不構成犯戒的情況是：如果周圍沒有清淨僧人可以向之報告，心中本來想要檢舉但尚未及時說出天就亮了，或者面臨性命不保、梵行難以維繫等重大危難因而未能說出，全都不算犯戒。

【600-0004】04_比丘尼鈔/04a_卷中之下#2
【原文】媒嫁戒具六緣犯一人男女二人男想三為媒嫁事四媒嫁想五言章了六受語往還報便犯此律若一念頃乃至須臾暫時和合媒嫁竝犯僧殘受男家語時吉羅報女家時蘭許還報殘若作券書言非我婦猶未唱出和者蘭若婦禮已斷不復往還和合者殘僧祗云若主人畜多婦妾不均鬬諍一婦私成比丘即為和平或夫婦不和勸和合者蘭若婦人及女還家比丘到舍便勸早還者蘭五分云若為男倩女為女倩男長使者蘭此律云知事白僧媒嫁淨人供給婚具問僧和可者一切殘若非理用物犯重伽論云若指腹作媒嫁及自媒身者蘭僧祇云乃至為他求好馬種和合者蘭餘畜生吉毗柰耶得僧殘。
【譯文】做媒戒具備六個條件即構成犯罪：一是男女二人；二是認定對方為男女；三是為媒合婚姻之事；四是存有做媒的意圖；五是言詞表達明白；六是接受一方請託並往返通報，即犯本戒。依本律規定，只要一念之間乃至片刻短暫撮合婚姻，都犯僧殘罪。接受男方委託時得突吉羅罪，回報女方時得偷蘭遮罪，應允女方並回報男方時即成僧殘罪。若立下休書字據寫著「她不再是我的妻子」，在尚未當眾宣讀唱出前便從中撮合和好者，得偷蘭遮罪；若休書已宣讀、名分禮數已斷絕不再往來，而又從中撮合復合者，犯僧殘罪。《僧祇律》說：若男主人蓄養多名妻妾，待遇不均引發爭執，比丘私下為某一婦人說情求和，或夫妻不和而居中勸和者，得偷蘭遮罪；若婦人及女兒回娘家，比丘到其家中便勸其早點回去者，得偷蘭遮罪。《五分律》說：若為男子僱請女子，或為女子僱請男子作長期使女奴僕，得偷蘭遮罪。本律說：執事比丘向僧眾稟白為淨人做媒，並供給婚聘器具，詢問僧眾是否贊同，贊同者皆犯僧殘罪；若不合理動用僧物，則犯重罪。《摩得伽論》說：若指腹為婚，或為自己作媒者，得偷蘭遮罪。《僧祇律》說：乃至為他人尋求優良馬種進行交配者，得偷蘭遮罪；其他畜生則得突吉羅罪；依《毗奈耶》則得僧殘罪。

【600-0005】04_比丘尼鈔/04a_卷中之下#3
【原文】言人戒具四緣一往俗官所言二言白衣居士三詞列其事四下手疏便犯此律相言謂詣官共諍曲直若斷官下手疏者僧殘說不道名目者偷蘭見論云至官言人令官罰物隨多少犯罪物應償之若被奪物得就官乞護身不得道名字官目訪得治罰無犯若人入寺斫伐樹木不得奪刀斧應還直五分云若為人輕陵得語父母親里有力者援護十誦云尼在斷事人前瞋恨訶罵本所打人僧殘若向餘人訶罵本所打人蘭。
【譯文】告官告狀戒具備四個條件即構成犯罪：一是前往俗家官府陳告；二是所控告的是在家白衣居士；三是具體陳列其事狀；四是官府立案下筆成文即犯本戒。本律所說告狀，是指前往官府爭論是非曲直。若承辦官吏立案下筆，即犯僧殘罪；陳述案情卻未指明姓名身份者，得偷蘭遮罪。《善見論》說：到官府告人，致使官府罰沒財物，隨其罰款多寡定罪，所罰之物應當予以賠償。如果財物被搶奪，可以向官府請求保護自身安全，但不得說出搶奪者的姓名，官府自行查訪抓獲並處罰者，不犯本戒。若有人進入寺院砍伐樹木，不得奪取對方的刀斧，應折算價值償還。《五分律》說：若遭人欺凌侮辱，可以告訴其有權勢的父母親族前來救助防護。《十誦律》說：比丘尼在審理案件的官員面前，心懷瞋恨訶斥咒罵先前打自己的人，犯僧殘罪；若向其他無關的人訶罵先前打自己的人，得偷蘭遮罪。

【600-0006】04_比丘尼鈔/04a_卷中之下#4
【原文】度賊女戒具五緣一是賊人罪應死者二知是賊女三不問王大臣四輒便受具五羯磨竟便犯十誦云賊有二種一偷財物犯王法王欲殺之二偷身犯夫欲殺之是中犯者和尚知殘闍梨知蘭尼僧知吉都不知無犯五分若發心度賊女方便乃至集僧三羯磨未竟皆吉三羯磨竟和尚殘餘師皆蘭僧祇云與出家越與學戒蘭受具戒殘。
【譯文】度賊女出家戒具備五個條件即構成犯罪：一是對方為犯死罪的女賊；二是明知她是女賊；三是未向國王或大臣請示；四是擅自為其授具足戒；五是羯磨儀式完成即構成犯罪。《十誦律》說：賊有兩種，一是偷盜財物觸犯國法，國王欲處死者；二是私通犯姦，丈夫欲處死者。此中結罪情況：戒和尚明知者犯僧殘罪，阿闍梨明知者得偷蘭遮罪，大眾尼僧明知者得突吉羅罪；如果大家全都不知情，則不犯。《五分律》說：若發心度女賊出家，從用手段乃至召集僧眾、三次羯磨未完成前，全都得突吉羅罪；三次羯磨完成後，戒和尚犯僧殘罪，其餘諸師都得偷蘭遮罪。《僧祇律》說：為其剃度出家得越毗尼罪，授式叉摩那學戒得偷蘭遮罪，授具足戒得僧殘罪。

【600-0007】資持記/15e_下三#27
【原文】〔童女是長者名，非女人也。〕鸚鵡，彼云：過去雪山，有一鸚鵡，父母都盲；時有田主，初種󰝿時，願言：與眾生共食，鸚鵡子，即常於田採取，以供父母；田主按行苗稼，見諸虫鳥，剪󰝿穗處；嗔恚，便設網捕，鸚鵡子言：田主先有好心，何見網捕？且田者如母〔常生長故〕，種子如父〔相繼續故〕，實語如子〔可寶惜故〕；
【譯文】（童女是這位長者之子的名字，並不是指女子。）鸚鵡的公案，彼經說：過去雪山中有一隻鸚鵡，父母雙目失明；當時有一位田地主人，最初播種穀物時發願說：願將這田產與一切眾生共享。這隻小鸚鵡就常常飛到田裡採擷穀物，用來供養父母；田主巡視巡查莊稼，看見許多鳥雀啄食剪斷穀穗的地方；心中惱怒，便設下網羅捕捉，小鸚鵡說：田主你先前發過廣大的好心，為什麼現在反而設網捕捉？況且田地如同母親（能常生長五穀），種子如同父親（世代相承延續），真實的言語如同兒子（誠信可寶貴珍惜）；

【600-0008】資持記/15e_下三#28
【原文】田主如王，擁護由己〔得白在故〕。作是語已，田主歡喜；問言：汝取此󰝿何為？答言：有盲父母，願以奉之。佛言：鸚鵡者，我身是；田主者，舍利弗是；盲父母者，淨飯摩耶是。《增一》兩節，初校量功德。一生補處，即等覺菩薩。準知孝養，德唯降佛。《菩薩戒》云：孝順至道之法；儒書亦謂至德要道。
【譯文】而田主如同國王，保衛護持全由自己做主（因其能得自由自在的緣故）。說了這番話後，田主非常歡喜；問牠說：你摘取這些穀物做什麼用？小鸚鵡回答：家中有眼盲的父母，希望能拿回去奉養他們。佛說：那隻小鸚鵡，就是我的前身；那個田主，就是舍利弗；那對雙盲的父母，就是淨飯王和摩耶夫人。《增一阿含經》的兩段文，第一段校量功德。所謂一生補處，是指等覺菩薩。由此準照可知，孝養父母的功德，唯有佛陀果位能超越它。《菩薩戒》說：孝順是通達至道的根本大法；儒家經典也稱孝道為至德要道。

【600-0009】資持記/15e_下三#29
【原文】則萬善之總，百行之源。儒釋皆然，釋門尤切；常當思報，勿得背恩。文下，次明恩大。文合作又，並《增一》故。謂雖以善導，罔極難酬，故云不可報；或可教導餘人，可使報恩；父母有恩，故不望報。是下，結勸。五中。論舉盲病，餘病例然；又但闕所須，不必在病。
【譯文】由此可見孝道是萬種善法的總匯，是百種品行的根源。儒家與佛家都是如此，而佛門的要求尤為切要深切；身為佛子應當常念圖報親恩，萬萬不可背離辜負大恩。下文第二段，接著說明親恩無量廣大。經文中的「文」字應當作「又」字，因為兩處都是引用《增一阿含經》的緣故。意思是說雖然可以用善法引導父母，但父母昊天罔極的深恩依然難以徹底報盡，所以說「不可報」；或者也可以解釋為，教導外人尚且能指望對方知恩報答；但父母對兒女只有純粹的慈恩，從來不指望回報。自「是」字以下，結語勸誡。第五段中。論中雖然只舉出盲目與疾病為例，其餘的病苦都可準此類推；而且只要是缺乏生活所需，並不一定非要生病才可給予。
