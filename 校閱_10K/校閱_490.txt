# 校閱材料　第490檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【490-0001】02_戒疏/07a_卷二上之三#73
【原文】【疏】二、「取水」者。《律》中，離地水器盛而盜，隨滿結重。《僧祇》：「若以筒就孔中飲，滿者重；若稍飲數止，咽咽偷蘭。若器先塞，盜拔塞時，越；注入器中，蘭；注滿者，重；若注未滿即悔，畏重，以倒本器中，偷蘭。」雖繩斷未離處，離處未斷繩，俱蘭。蘇、油、蜜等，例同。
【譯文】【疏文】第二、「取水」的情況。《律》中說明，離開地面盛在水器中的水若加以盜取，隨著盜水價值滿五錢就結重罪。《僧祇律》說：「如果用竹筒靠近水器的孔中偷喝，偷喝總量價值滿額就犯重罪；如果喝幾口就停下來，每吞下一口結一個偷蘭遮罪。如果容器原本塞住，暗中拔掉木塞時，犯突吉羅；水注入自己的容器時，犯偷蘭遮；注入的水量價值滿五錢時，犯重罪；如果注入尚未滿五錢就後悔，害怕犯重罪，而將水倒回原來的容器中，犯偷蘭遮罪。」雖然繫容器的繩子斷了但器皿未離開原處，或是器皿離開了原處但繩子還沒斷，都結偷蘭遮罪。酥油、香油、蜂蜜等物品，全比照此例辦理。

【490-0002】02_戒疏/07a_卷二上之三#74
【原文】【記】二中。《律》約「器盛」者，文云：「大小瓮及餘種種水器，若香水，若藥水，若取者，夷。」《僧祇》，前明以筒盜飲。「稍」，即少也。「若」下，明持器盜取。「雖」下，約連器持去。下例蘇、油，同上三判。
【譯文】【記文】第二項中。《律》是依據「容器盛裝」來論述，經文說：「大大小小的水甕以及其他各種盛水容器，不管是香水還是藥水，如果盜取，犯波羅夷。」《僧祇律》前半段說明用竹筒偷喝。「稍」就是少許的意思。從「若」字以下，說明拿容器來盜取。從「雖」字以下，是就連同容器一起拿走的情況來論。下面將酥油、芝麻油列為同類，適用上面三種判定。

【490-0003】02_戒疏/07a_卷二上之三#75
【原文】【疏】三、「楊枝」者，義同上相。《律》隨有者，便隨言之。
【譯文】【疏文】第三、「楊枝」（潔牙木），法理與上述的情相相同。《律》中隨當時所有的物品，就順著提出來說明。

【490-0004】02_戒疏/07a_卷二上之三#76
【原文】【記】三中。「同上」者，亦為隨盜滿五成重，《律》云「若一、若兩，若眾多，若一把、一擔」等。「律」下，通示律文列相之意，謂前後所出，隨據有者為言，非止此數。
【譯文】【記文】第三項中。「同上」的意思，也是指隨偷盜的價值滿五錢就構成重罪，《律》中說「或是一根、或是兩根，或是很多，或是一把、一捆」等等。從「律」字以下，通盤說明律文列出這些名相的用意，是指前後所列的物品，只是隨當時存在的東西作為例子來說，絕不僅止於這幾種數額。

【490-0005】02_戒疏/07a_卷二上之三#77
【原文】【疏】四、「園果草木」者，如上「僧物」中。《鈔》中廣引。
【譯文】【疏文】第四、「果園果實與草木」，如同前面「僧物」中所說。《行事鈔》中對此有極廣泛的引證。

【490-0006】02_戒疏/07a_卷二上之三#78
【原文】【記】四中，初科。指上，即「常住常住物」。下又指《鈔》，即「盜戒」中。彼引《大集》云「盜僧物者，罪同五逆」，隨損一毫，則望十方凡聖一一結罪。又引《方等》云「五逆四重我亦能救，盜僧物者我所不救」等。彼又廣引諸律，明用得否，撿彼看之。
【譯文】【記文】第四項中，第一小科。指涉前面，就是指「常住常住物」。下面又指引參閱《行事鈔》，也就是在「盜戒」之中。彼處引用《大集經》說「偷盜僧團財物的人，罪過等同五逆罪」，只要損害一絲一毫，就針對十方所有凡聖僧人一一結罪。又引用《方等經》說「犯下五逆罪和四重罪的人，我還能夠救度；偷盜僧團財物的人，是我所不能救度的」等等。彼處又廣泛引用各部派律典，說明到底能否取用，應當去翻檢彼處查閱。

【490-0007】02_戒疏/07a_卷二上之三#79
【原文】【疏】僧園果木，比丘多犯，以我寺中，不謂有犯。然立寺者，以盛無我之僧，隨有施為，無非為解脫故。今不思此，取他眾人所有之物，以為自保，此罪大也。如《僧護》、《日藏分》中，特可畏也，故須深思。
【譯文】【疏文】僧團果園中的果實草木，比丘往往極容易違犯，因為總以為是在自己的寺院裡，不認為這算犯罪。然而建立寺院的初衷，是為了安頓清淨無私的僧眾，在這裡所有的施捨與作為，無一不是為了趣向解脫。如今不思索這一點，反而擅取全體僧眾共有的物品，拿來作為自己享用保養之需，這罪過是極其巨大的。如同《僧護經》、《日藏分》中所載的果報，特別令人恐懼畏懼，所以必須深刻反思。

【490-0008】02_戒疏/07a_卷二上之三#80
【原文】【記】次科。初敘喜犯。「然」下，次彰業重。初明立寺之本。「今」下，次明盜取之情。「如」下，指教勸思。《僧護經》，彼因耶舍遊海邊，見五十餘處地獄，多是侵盜僧物，現受苦報。《日藏》，具云《大乘方等日藏經》，佛對日藏菩薩說諸破戒受苦等事。《鈔》云：「別人得用僧薪草者，此要具戒清淨應僧法者。若行少缺，得罪無量。」
【譯文】【記文】第二小科。首先敘述容易犯戒的心理。從「然」字以下，接著彰顯罪業的深重。首先說明建立寺院的根本目的。從「今」字以下，接著揭露盜取僧物的私心。從「如」字以下，指出佛經教誡勉勵大家深思。《僧護經》中，是因為耶舍尊者遊歷海邊，看見五十多處地獄，受刑者大多是因侵佔偷盜僧物，而當下承受慘烈的苦報。《日藏分》，全名是《大乘大方等日藏經》，佛陀對日藏菩薩宣說了各種破戒受苦的事相。《行事鈔》說：「個別僧人能夠享用僧團的柴薪與草料，必須是具備清淨戒律且行持符合僧法的人。如果行持稍微有所缺漏，將招致無量的罪過。」

【490-0009】02_戒疏/07a_卷二上之三#81
【原文】【疏】如《僧祇》中：「僧地種果有功，聽與一熟，乃至菜瓜，例與一翦。」、「若於園中搖樹，果落地，持去方重。若就園內食，滿者結重。」《十誦》：「僧園樹華，聽供養佛。大木供僧，皮葉隨比丘用。」《僧祇》：「院內樹薪，供僧食用。若無定限。應取乾者。」
【譯文】【疏文】如同《僧祇律》所說：「在僧團土地上種植果樹有功勞的人，聽許分給他一季收成的果實，乃至菜瓜，比照給予一次採收的份量。」「如果在果園中搖晃樹木，果實落到地上，拿著走開時才算重罪。如果就在果園內直接吃，吃下的價值滿五錢就結重罪。」《十誦律》說：「僧園樹上的花朵，聽許採來供養佛陀。大樹木供僧團使用，樹皮與葉則聽許隨比丘個人取用。」《僧祇律》說：「寺院內的樹枝柴薪，用來供大眾僧煮食享用。如果沒有限定分配，個人應當只拾取乾枯的樹枝。」

【490-0010】02_戒疏/07a_卷二上之三#82
【原文】【記】三中。《僧祇》，初明賞功。「一熟」，謂一番熟者與之。「一翦」，亦約一番採摘。「若」下，次明盜果。《十誦》，樹華僧用、供佛，不成互用。「皮葉」及《僧祇》「樹薪」，並開別人取用。準前明判，要須戒淨。
【譯文】【記文】第三小科。《僧祇律》首先說明獎賞辛勞。「一熟」，是指果實成熟的一季就分給他。「一翦」，也是指一次採摘的收成。從「若」字以下，接著說明盜取果實的罪相。《十誦律》中，僧團樹上的花拿去供佛，不成互用。「樹皮落葉」以及《僧祇律》所說的「樹枝柴薪」，都開許個人取用。但準照前面的判準，取用者自己必須戒行清淨。

【490-0011】02_戒疏/07a_卷二上之三#83
【原文】【疏】五、「無足」者。《律》中，蛇、魚為初，有主盜取故。《僧祇》云：「若以龍蛇等，盜取犯重。若瞋罵言『何以籠繫』，即開放者，越。」《五分》：「若壞殺具，無犯；不應爾。」《十誦》、《摩得伽》中：「壞網，慈心吉羅。」
【譯文】【疏文】第五、「無足動物」。《律》中以蛇、魚作為開端，因為這是有主人飼養而遭到盜取的情況。《僧祇律》說：「如果是龍、蛇等，盜取價值滿額犯重罪。如果憤怒斥罵說『何以籠繫』，隨即將牠放生的，犯突吉羅。」《五分律》說：「如果毀壞殺生的捕具，不算犯戒；但平時不應當這樣做。」《十誦律》與《摩得伽論》說：「出於慈悲心毀壞捕魚網，結突吉羅罪。」
