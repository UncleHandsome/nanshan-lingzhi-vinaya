# 校閱材料　第223檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】次科初引難。「今」下釋通。初約初制釋，謂始制時未有他緣故。「或」下次約同緣釋，初立義，謂一緣上不開再受，異緣雖重不名重故。如「下」引例，律中佛初出世，凡受歸戒竝云某人最初受歸等，法同人別，不名為重
【譯文】下一科首先引述詰難。自「今解」以下通達解釋：首先就最初制定來解釋，是說剛制戒時尚未有其他事緣的緣故。自「或一事上」以下接著就同一因緣解釋，先確立義理，指同一事緣上不開許再受，不同事緣即便多次受法亦不名重複。自「如受三歸」以下引例，律中佛初出世時凡受皈戒皆稱某人最初受皈等，法式相同而人各相異，不名為重複。

【譯文】在接下來敘述宗意的內容中，前兩句敘述安居，「開」是明曉的意思。次兩句彰顯自恣，制模造陶、鎔鑄金屬稱為陶冶，這裡取調伏鍛練的意思；精靈就是神識，正量就是教法。自「故」以下轉而解釋自恣：前兩句敘述「自」的含義，「累」就是罪愆，「前緣」就是五德比丘。次兩句說明「恣」的含義，也就是前面所說的陶冶。後兩句彰顯利益，也就是前面所說的契合正量。

【223-0128】03_業疏/21a_卷四之四#97
【原文】就文為二：標緣、作法
【譯文】就文意而言分為兩部分：一是標示緣起，二是正行作法。

【223-0129】03_業疏/21a_卷四之四#98
【原文】初標目者，如十誦云：云何自恣？攝眾僧故，善惡相化故，以出過罪如法清淨故。伽論云：欲令諸比丘不孤獨故，各各憶罪發露悔過故，又以苦言調伏故，又得無病安穩故，自意喜悅故，清淨無罪故
【譯文】起初標示篇目，正如《十誦律》所說：什麼是自恣？是為了統攝僧眾的緣故，為了善惡相互教化（令其去惡向善）的緣故，為了發露過失與罪愆而如法清淨的緣故。《伽論》說：是為了令諸比丘不感到孤獨的緣故，各個憶念罪過、發露悔過的緣故，又為了用切直逆耳之言予以調伏的緣故，又為了獲得無病安穩的緣故，為了自心歡喜愉悅的緣故，為了身心清淨無罪的緣故。

【223-0130】03_業疏/21a_卷四之四#99
【原文】釋標篇目中，十誦三意：攝眾是住持益，善惡相化即利他益，出過清淨是自利益。伽論六意：一、有法為侶，二、無覆藏，三、摧我慢，四、身安，五、心樂，六、業淨。已上律論但出制意。準鈔釋名云：自宣己罪，恣僧舉過，內彰無私隱，外顯有瑕疵，身口託於他人，故曰自恣
【譯文】在解釋標示篇目的內容中，《十誦律》有三種意旨：統攝大眾是住持正法的利益，善惡相化就是利他的利益，發露過失以得清淨是自利的利益。《伽論》有六種意旨：一是得以佛法為伴侶，二是沒有覆藏，三是摧伏我慢，四是身體安穩，五是內心快樂，六是業行清淨。以上律典與論典只是說明制定自恣的用意。依照《事鈔》解釋名稱說：自己宣說罪過，放任（請求）僧眾舉發過失，對內表明沒有自私隱瞞，對外顯露自身尚有瑕疵，將自己的身口行為託付給他人檢點，所以稱為自恣。

【223-0131】03_業疏/21a_卷四之四#100
【原文】緣列共住受瘂法者，由妄設法，因言致諍，俱行默然，何事乖越？佛法不爾，義須識非。生知者少，必假良友，豈伊不語，何得離愆？言滿天下無口過者，豈聖人乎？故訶言同白羊也，至死無聲。此但強戾，須作何善？故佛制之，相撿挍也
【譯文】緣起中列出共住而受持「啞法」的情形：由於妄自設立條法，認為因言語會引發爭執，於是大家都保持沉默不語，怎麼會有違犯逾越的事情呢？但佛法不是這樣的，在法理上必須認清是非過咎。生來就明白事理的人很少，必定要借助良師益友；難道只要不說話，怎能離開罪愆？能做到「言語傳遍天下而沒有口過」的人，難道只有聖人嗎？所以佛陀呵斥這種做法如同白羊一般，到死都不出聲。這只不過是性情剛強暴戾，能修成什麼善行呢？因此佛陀制定自恣之法，讓大家互相檢點考較。

【223-0132】03_業疏/21a_卷四之四#101
【原文】次制緣中，初文初敘愚見。妄設法者，非制而制故。因言致諍，意謂各默則無乖違。佛下敘制意。豈伊不語，豈猶苟也。孝經云：言滿天下無口過，行滿天下無怨惡。豈聖人者，凡人皆可行也。強謂剛強，戾即狠戾。我人相競，故非善也
【譯文】在接下來的制戒緣起中，前段文字起初敘述愚癡的見解。所謂「妄設法」，是因為並非佛制卻擅自制定。所謂「因言致諍」，是認為各自保持沉默就不會有違背。自「佛」以下敘述佛陀制戒的意旨。所謂「豈伊不語」，「豈」相當於「苟且、若僅僅」。《孝經》說：「言滿天下無口過，行滿天下無怨惡。」所謂「豈聖人者」，是說凡夫也是可以做得到的。強是指剛強，戾是指狠戾。執著於我相人相而互相抗衡，所以不是善法。

【223-0133】03_業疏/21a_卷四之四#102
【原文】又表一歲之勤，情本據道，中含非法，正缺道標，義須清蕩，無瑕受歲。今若相默，豈抱過生年？故須相撿，應僧淨法也
