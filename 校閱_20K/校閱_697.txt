# 校閱材料　第697檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】掘地戒具五緣犯一是生地二作生地想三自掘四使人掘時不作知淨語五傷如蚊脚便犯此律但使教人不作知淨不問現前不現前掘掘皆提若自方便掘一提若中間止住一一提若使前人多掘一提若重語疾疾掘語語提僧祗云走來走去欲令地壞乃至擲物令傷如蚊脚者一切提釘房內壁損傷人功者得越毗尼罪先有孔者不犯地有沙石者不犯見論云若野火來近寺為護住處得剗草掘地以斷火若把火燒手擲地不犯僧祇云覆處地不犯。
【譯文】掘地戒具備五個條件即構成犯罪：一是未經開墾翻動的天然生土；二是認定為天然生土；三是親自挖掘；四是吩咐他人挖掘時不說合律的知淨語；五是損傷土地如蚊子腳般微細便犯本戒。本律規定：只要教導他人挖地而不說知淨語，不論本人是否在場，挖了就犯波逸提罪。若是自己動手挖掘，每挖一下得一個波逸提罪；若是中間停頓之後再挖，每一動作各得一個波逸提罪；若是差遣對方大肆挖掘，得一個波逸提罪；若是反覆催促說『快點挖、快點挖』，每說一句各得一個波逸提罪。《僧祇律》說：在地上來回跑動企圖使泥土損壞，乃至丟擲物品使地面受到哪怕如蚊子腳般的損傷，全都犯波逸提罪；在僧房內壁釘釘子損傷人工修繕者，得越毗尼罪；若是原先已有土孔者，不犯；地面多為沙石者，不犯。《善見論》說：若野火蔓延逼近寺院，為了保護住所，可以鏟草掘地以阻斷火勢；若手持火把燒傷手而丟擲在地上，不犯。《僧祇律》說：在有遮蓋屋簷下的地面，不犯掘地戒。

【譯文】破壞生長種子戒具備五個條件即構成犯罪：一是屬於五種具有生機的種子；二是認定為生長種子；三是親自破壞；四是未作合律的知淨語；五是傷損物品便犯本戒。本律說：生長種子有五種：一根、二枝、三節、四覆羅（如蔓藤倒插接枝）、五子。生種的知淨作法也有五種：一用火、二用刀、三以爪刻創傷、四鳥啄破、五天生不能發芽（不中種）。《僧祇律》說：根莖類的種子，用刀從中間切破作淨；節種，用刀切破或摘除芽眼作淨；心種如蘿蔔、芹菜、蓼草等，應當揉搓搓損作淨；子種如穀物、麥子等，應脫去外皮作淨；若統一使用火烤作淨，便可通盤適用於上述五種種子。五種果實中，包核類的果實如紅棗、杏子等，應當用指甲掐破作淨，然後去掉果核食用；經火烤作淨者，可以連核一同食用；肉質果皮類的果實如嗶茇、梨子、蘋果等，都必須用火作淨。若一切成熟果實自然脫落，碰撞樹木石頭造成的傷痕哪怕只有蚊子腳般細小，也算作淨成立，應當除去種子食用；硬殼類的果實如椰子、核桃、石榴等，都必須用火作淨；細軟多囊果實如香薷、紫蘇、荏草等，若無種子應當揉搓作淨，若有種子應當用火作淨；豆莢類果實如大豆小豆等，若是種子尚未成熟，應揉搓作淨，種子已成熟者應當用火作淨。掌管糧倉的執事者處有穀倉尚未作淨，若擔心年輕比丘尼不懂戒法，應派人先行用火作淨，乃至日後經常囑咐他人『拿去舂米』，這樣便不犯戒。如果把五種生長種子扔進池塘中、水井中、大小便溺中、垃圾堆中，得越毗尼罪；使種子腐爛喪失生機者，犯波逸提罪。在草木叢中行走，若存心想踩死草木者，得越毗尼罪；使草木傷損如蚊子腳般細微者，犯波逸提罪。石頭上長青苔、糕餅上長菌毛，都必須讓淨人知曉處理，否則犯戒；若是經烈日曬乾，准許剝除丟棄。水中的浮萍，不得用手隨意撥動；若是有牛馬走過踩開的地方，准許取水使用；若是沒有走過之處，可抓取土塊或石頭向上拋擲並口稱『飛到梵天上去吧』，落下時砸開水面浮萍之處，隨即可以用該處的水。在水中翻動撥弄浮萍，得越毗尼罪；若是將浮萍撈起放在岸上，犯波逸提罪。若入水洗浴時，水草沾附在身上，應當用水再沖洗讓它回到水中；若是採摘折斷朝生暮死的菌菇，得越毗尼罪。《善見論》說：若需要花朵果實，可以自己把樹枝拉低，讓淨人採摘，也可以抱起淨人去採摘。《五分律》說：凡是對草木有所需求時，應告訴淨人說：『你知曉這事嗎？』對方若不明白，再對他說：『你看看這個。』對方若還不明白，再對他說：『我需要這個。』本律規定：若不說『你看看這個』，得突吉羅罪；破壞地面也是同樣的規矩。雜草生長覆蓋道路，為了通行而全面綁紮開闢道路，因非故意而導致枝折葉落者，不犯戒，因為並非蓄意破壞。

【697-0007】04_比丘尼鈔/04a_卷中之下#34
【原文】別眾食戒具七緣犯一是有施主二僧次請及別請別乞三五正食在時中四食處成眾五知界內有比丘尼不集六無因緣七咽咽犯提此律無問道俗皆成施主見論云要別請四人俱受成眾即座上一人覆鉢不食待餘三人食竟一人後食不犯故知俱受成眾此律云若二三人隨意食四人已上應分作二部更互入食婆論云若大界內有二處僧祇一日中俱有檀越食布薩處無過不布薩處不請布薩處一人不送一分食者此僧犯提此律病者不犯下至脚跟躄故不犯見論云謂沙土入中不能行也。
【譯文】別眾食戒具備七個條件即構成犯罪：一是設有施主；二是屬於僧團依序輪請、個別邀請或個別托缽求乞；三是接受五種正食且正值合法的非時之前；四是就餐處集結成眾；五是明知同一界內有比丘尼未被召集；六是無特殊開緣因緣；七是每咽下一口食物便犯波逸提罪。本律規定：不論對方是出家人還是俗家人，都算作施主。《善見論》說：必須是施主個別邀請四人，且四人同時接受邀請才算集結成眾；若就座時其中一人覆缽不食，等待其餘三人吃完後，該人再單獨進食，這樣便不犯戒，由此可知四人同時受食方能成眾。本律說：若是兩三個人聚餐，可隨意食用；若是四人以上，應分成兩組，輪流進入就餐。《薩婆多論》說：若在大界之內有兩處僧眾聚落，同一天內兩處都有施主供齋，在舉行布薩之處就餐者無過失；但在未舉行布薩之處，若不邀請布薩處的僧眾一人前來，也不送一份飯食給他們，該處僧眾便犯波逸提罪。本律規定：生病者不犯戒，乃至腳後跟裂傷不能行走者也不犯。《善見論》說：這是指沙土滲入裂口疼痛而無法行走的情況。

【697-0008】04_比丘尼鈔/04a_卷中之下#35
【原文】非時食戒具四緣犯一是非時二非時想三時食四咽咽便犯此律云時者明相出乃至日中按此時為法四天下亦爾毗羅三昧經云佛為法慧菩薩說食四種旦起天食時午時法食時暮時畜生食時夜鬼神食時後二種食多生病疾其出家人應作天食法食故曰時食過午已後非上二時故曰非時見論云吐食未出咽喉還咽無犯若出咽者提十誦云阿那律弟子病服吐下藥中後心悶佛言稻稗竹笋汁囊盛米粥絞汁與猶不差佛聽屏處食米粥食殘宿食戒具三緣犯一是殘宿食二知是三咽便犯此律今日受食自貯界內留至明日自煑食者咽咽得七罪謂三提四吉一不受二非時三殘宿四內煑五內宿六自煑七惡觸。
【譯文】非時食用食物戒具備四個條件即構成犯罪：一是處於非規定的時間；二是認定為非規定時間；三是食用正規食物；四是每咽下一口食物便犯本戒。本律說：合法的時間，是從黎明天明破曉開始一直到正午為止，按照這個時段作為規定的正時，四天下皆是如此。《毗羅三昧經》說：佛陀為法慧菩薩解說四種進食時間：早晨是諸天進食之時，正午是三世諸佛法食之時，黃昏是畜生進食之時，夜晚是鬼神進食之時。後兩種時間進食容易滋生各類病痛疾患，因此出家人應當遵循天食與法食的時間，所以稱為『時食』；過了正午之後，就不屬於上述兩種時間，所以稱為『非時』。《善見論》說：食物嘔吐反胃但未吐出喉嚨，隨後又吞嚥下去的，不犯戒；若是已經吐出咽喉之外又吞下的，犯波逸提罪。《十誦律》說：阿那律的弟子生病服下催吐或瀉下的藥劑，到了中午過後心胸煩悶，佛陀說：可以用布袋裝著稻稗或竹筍汁及米粥，絞出汁液給他喝；若依然不見好轉，佛陀開許可以在隱蔽之處喝稀米粥。【食殘宿食戒】具備三個條件即構成犯罪：一是屬於隔夜殘宿之食；二是明知是隔夜食物；三是咽下便犯本戒。本律規定：今天接受的食物，自己儲存在界內留到明天，又親自烹煮來食用者，每咽下一口得七種罪過，也就是三個波逸提罪和四個突吉羅罪：一是不受食戒、二是非時戒、三是殘宿戒、四是內煮戒、五是內宿戒、六是自煮戒、七是惡觸戒。


【697-0009】04_比丘尼鈔/04b_卷中之下#1
【原文】不受食戒具緣可解見論云天人鬼神畜生飛鳥皆成受食婆論云為作證明故非人畜生及無知小兒悉不成受此律除水及楊枝不須受僧祇云若風吹塵午駝振身塵來乃至眾鳥女人行衣曳地塵來如是一切塵坌鉢下草不坌食者成若及食者一切更須受唯畜生振身作意受者得自餘一切不作意受者應更從他受若行麨時抖擻麨器迸落鉢中作意者得名為受不作意者不名為受餘食亦爾五分云眼暗比丘得按萆受食見論云額汗流入鉢更須受臂中汗流入手不須受得食無罪十誦云行食時淨人觸比丘手若特輕故觸比丘手不應受婆論云手不淨受食犯吉僧祇云淨人行果菜時應語云懸空放果墮草上即去不名為受小停者得為受見論云遙擲從地轉來落比丘上成受僧祇云大會時淨人難得比丘受取行之若鎗鑊。
【譯文】（未受而食戒）犯此戒的構成要件容易理解。《善見律毘婆沙》說，天人、鬼神、畜生、飛鳥來授食，都算受食成功；《薩婆多毘尼毘婆沙》則認為，受食必須有人作證明，所以非人、畜生以及不懂事的小孩授食，都不能算受食成功。本律除了水和楊枝之外，一切食物都必須經過受食程序。《摩訶僧祇律》說，如果風吹塵土、牛或駱駝抖身揚塵，乃至群鳥飛過、婦女走動衣袍拖地揚起塵土，這一切塵土飛落，若只落在缽底的草墊上而沒有沾到食物，受食仍然有效；如果塵土沾落到食物上，所有食物就必須重新受食。只有畜生抖身時，比丘若起心作意接受，才算合法受食；其餘各種塵土飛來時若沒有作意受食，都應該重新向他人接受受食。分發炒麥粉時，如果抖動盛粉器具，麥粉濺落缽中，比丘起意接受就名為受食，若沒有起意就不算受食，其他食物也是如此。《五分律》說，視力昏暗的比丘可以撫摸著草蓆來接受食物。《善見律毘婆沙》說，額頭的汗水流進缽中，食物必須重新受食；如果是手臂上的汗水流到手上，就不需要重新受食，吃下去也沒有罪過。《十誦律》說，分發食物時淨人若是觸碰到比丘的手，如果是故意輕慢而觸碰，比丘就不應該接受。《薩婆多毘尼毘婆沙》說，比丘（尼）手不乾淨去接受食物，犯突吉羅罪。《摩訶僧祇律》說，淨人分發瓜果蔬菜時，比丘應當吩咐他：「懸空放手讓果物落在草墊上即可離去。」這樣不算受食；如果淨人稍微停留片刻才放手，就算受食成功。《善見律毘婆沙》說，從遠處扔擲過來，食物從地上滾過來落在比丘身上，就算受食成功。《摩訶僧祇律》說，舉行盛大法會時淨人難得，比丘可以親自接受並端拿搬運。至於像鐵鼎、鐵鑊這類器具，可能沉重得無法直接捧受。

【697-0010】04_比丘尼鈔/04b_卷中之下#2
【原文】不得受者當下以兩木橫置地比丘脚躡上言受受得成此律下文欲受油錯受蘇等不成受必令心境相當得成受此律受食已有三失一任運失謂受得已食時既過故云任運失也二遇緣失謂淨人觸失受也三自變生為熟失也見論云受生薑後生芽不失受火淨已生芽處更淨非生芽處得食鹽變成水得食。
【譯文】遇到這類情形，應當在器具下方橫放兩根木頭在地上，比丘用腳踩踏在木頭上說「受」，受食就算成立。本律後文提到，心裡想接受香油卻誤受了酥油等情況，受食不能成立；必須做到心念與所受物品完全相合，受食才算成功。依照本律規定，受食之後有三種情況會失去受食效力：第一是自然失效，即受食之後已經過了合法的進食時間；第二是遇緣失效，即淨人觸碰到了已經受食的物品；第三是自體轉變失效，即生食變為熟食。《善見律毘婆沙》說，接受生薑之後生薑發芽，受食效力並不喪失；經過火作淨法之後發芽的部位，只要對新發芽處重新作淨即可，未發芽的部位依然可以食用；鹽巴化解成水，依然可以食用。
