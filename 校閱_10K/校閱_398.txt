# 校閱材料　第398檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【398-0001】02_戒疏/04a_卷一下之二#35
【原文】【記】次科又二。前明別分。「具」即身口。以吉羅無限，分之令易，故為七聚。「作義」下，次顯通含。「作」通「說」局，故云「作義長」也。此就罪體，鼓動不異，故或為六聚。「《律》下文」者，即諸犍度。
【譯文】【記文】第二小科又分作兩部分。前半段說明分別剖析。「具」就是指身體與言語的工具；因為突吉羅罪相無窮無盡，將其分別剖析才容易辨識，所以安立為七聚。「作義是長」以下，接著顯明通融含攝的意趣。「作」字義通身口，「說」字則偏局於口，所以說「作字的含義較廣」。這是就造罪的體性而言，兩者在造作發動上並沒有差異，所以有時也統合成六聚。「律下文」指的就是律典中的各個犍度篇章。

【原文】【疏】言得名義者。
【譯文】【疏文】義理疏文說：接著解說名號得立的深義。

【398-0003】02_戒疏/04a_卷一下之二#37
【原文】【疏】有人言：「聚雖有七，得名有五。初之二聚，從法立名，謂『無餘』、『有餘』也；第三偷蘭，從過立名，言『障道』也；第四就惡果；第五從對治；六七從具也。」
【譯文】【疏文】義理疏文說：有人主張：「罪聚雖然有七種，但得名的緣由只有五類：前二聚（波羅夷、僧殘）是從滅除罪垢的教法來立名，也就是『不可救療的無餘』與『尚可救治的有餘』；第三聚偷蘭遮是從過失功能立名，稱為『阻礙聖道』；第四聚波逸提是就墮落惡道的果報立名；第五聚提舍尼是從對治悔過的行法立名；第六與第七聚則是從造罪的器官工具立名。」

【398-0004】02_戒疏/04a_卷一下之二#38
【原文】【記】得名中，初釋。可解。
【譯文】【記文】在「得名義」的段落中，這是第一種解釋，文義淺顯易明。

【398-0005】02_戒疏/04a_卷一下之二#39
【原文】【疏】有人言：「聚雖有七，得名有六。波羅夷者，名為『極惡』，當體受名；僧殘，體境合目，有殘之罪，假僧除滅故也；偷蘭，『障道』為稱。」餘則還同前解。
【譯文】【疏文】義理疏文說：有人主張：「罪聚雖然有七種，但得名的緣由有六類：波羅夷稱為『極惡』，是就罪體本身來受名；僧殘是自體與懺悔境地合稱，指殘存未死的罪身，必須假借僧伽大眾之力予以除滅；偷蘭遮則以『阻礙聖道』為稱。」其餘各聚的解釋，則都與前一種說法相同。

【398-0006】02_戒疏/04a_卷一下之二#40
【原文】【記】次釋中。「夷從體」者，即《僧祇》云「義當極惡」是也。「僧殘從體境」者，「僧」是懺境，「殘」即罪體。「偷蘭」，前約能障，此據所障。
【譯文】【記文】在第二種解釋中。「夷從體」，就是《僧祇律》所說「義當極惡」的意思。「僧殘從體境」，「僧」是指懺悔所對的境界（懺境），「殘」是指所懺的罪體。「偷蘭遮」，前一解是約能障礙而言，此解則是依被障礙的聖道而言。

【398-0007】02_戒疏/04a_卷一下之二#41
【原文】【疏】如律大疏，更有諍名癈立。終非濟人，神爽不常，何得及之。但如上解，足為道分蹊徑也。
【譯文】【疏文】義理疏文說：如《四分律大疏》中，記載了更多關於名相廢立的爭論。這些爭論終究無法救度利益眾生，歷代論師的心思見解又變動不拘，哪裡能全部加以論述。只要依照上面所解釋的義理，就足以作為修道辨析途徑的指引了。

【398-0008】02_戒疏/04a_卷一下之二#42
【原文】【記】結告中。初示廣。「終」下，顯略。初句明無益。次二句明難曉。「神爽」，即指諸師心見。此謂他師情見各異，故云「不常」。無暇盡述，故云「何得及之」。「但」下，指前已備。「蹊」，小徑也。
【譯文】【記文】在「結語告誡」中。首先指出義理之繁博。「終非」以下，顯明文句精簡的原因。第一句說明無益於修行。接著兩句說明紛雜難以全然明了。「神爽」指的就是諸位論師的心意知見；這是說各家論師的情識執見互不相同，所以說「不常」。無暇逐一評述，所以說「何得及之」。「但如」以下，指明前文所述已足夠明備。「蹊」是指行路的小徑。

【譯文】【疏文】第四、解說篇與部在戒本中文義隱沒與顯現的形相。

【398-0012】02_戒疏/04a_卷一下之二#46
【原文】【疏】答：「斯出聖心，非凡能決。律中所列，多云『二百五十戒』，為行正宗，故此戒本，成斯大數。至於餘罪，不入戒本，非余所解，不可情求。」
【譯文】【疏文】義理疏文說：回答道：「這種編排出自佛陀聖心的大智慧，不是凡夫所能隨意妄決的。律典中所列舉的，多數都說是『二百五十條戒』，這是作為戒行規範的正宗綱領，所以這部戒本，才湊成如此龐大的數目。至於其餘各類罪相之所以未能列入戒本，並非我所能窺測解答的，萬不可憑凡夫私情妄加測度。」

【398-0013】02_戒疏/04a_卷一下之二#47
【原文】【記】答中。初明聖意難裁。「律」下，依文示數。「多云」者，諸律並同故。「至於」下，謙己讓他。
【譯文】【記文】在回答之中。首先說明佛陀聖意難以蠡測。「律中所列」以下，依循文句標示戒條數目；「多云」是因為諸部律典記載皆一致。「至於」以下，表示謙卑退讓。

【398-0014】02_戒疏/04a_卷一下之二#48
【原文】【疏】有人解云：「二百五十，且以數求。比丘感戒，量周法界，可不然也。偷蘭一罪，不在戒本者，豈不以體相不倫，因果難定，故單抽出，用在聚收。所以前後通塞不定。」
【譯文】【疏文】義理疏文說：有人解釋道：「二百五十戒這項說法，暫且只是就具體數量來推求而已。比丘所感得的戒體戒法，其廣大原本是周遍於一切法界的，豈止於這個數字！偷蘭遮這一種罪，不在戒本之中，難道不正是因為它的體性與相狀各不對等，因罪與果罪的層次難以固定，所以才特別單獨抽離出來，安置在七聚的體系中收攝？正因如此，它在聚位中列前列後、以及稱戒或稱威儀的通融與局限，向來都沒有定論。」

【398-0015】02_戒疏/04a_卷一下之二#49
【原文】【記】古解中，初科。前示數量，「偷」下，明不入所以。「體相」約品位重輕，「因果」即從生、根本。「所」下，指證。《律》中或列第三，或在第五。「通」，謂三品皆名為「戒」，並號「威儀」；「塞」，即上品是戒，中下名威儀。
【譯文】【記文】在「古德的解釋」中，這是第一小科。前面指出數量的意義；「偷蘭一罪」以下，說明未編入戒本的原因。「體相」是就品位輕重而言，「因果」是指從生方便罪與根本罪。「所以」以下，指引出教證：律本中有的把它列在第三位，有的列在第五位。「通」是指偷蘭遮的上、中、下三品都可稱作「戒」，也並稱作「威儀」；「塞」則指上品是戒，中品與下品僅稱為威儀。

【398-0016】02_戒疏/04a_卷一下之二#50
【原文】【疏】今就通論，俱名為「戒」，是故《律》云「最初犯戒」。若就相說，齊號「威儀」，故云「非威儀」也。又據輕重分之。前之三聚，過相麤著，能治名「戒」，偷蘭則在第三。下四過輕，能治之行，名曰「威儀」。
【譯文】【疏文】義理疏文說：現在如果就通泛的義理來論述，它們全都可名為「戒」，因此《四分律》中說「這是最初犯戒」。如果就具體行相來說，又齊整地名為「威儀」，所以說「這是非威儀的行徑」。又可以根據過失的輕重來劃分：前三聚的過失行相粗顯顯著，能對治的善行稱為「戒」，此時偷蘭遮便列在第三位；後四聚的過失較輕微，能對治的戒行則稱為「威儀」。

【398-0017】02_戒疏/04a_卷一下之二#51
【原文】【記】釋成中，初科。前約通論，「又」下，次就別辨。
【譯文】【記文】在「闡釋成立」的第一小科中。前半段就通論而說；「又據」以下，接著就個別角度辨析。

【398-0018】02_戒疏/04a_卷一下之二#52
【原文】【記】問：「偷蘭第三，但攝上品，餘二何收？」
【譯文】【記文】問：「偷蘭遮若列在第三位，僅能收攝上品偷蘭，其餘中、下兩品又由何處收攝？」
