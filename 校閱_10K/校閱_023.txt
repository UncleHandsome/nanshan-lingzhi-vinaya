# 校閱材料　第023檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【023-0001】01_行事鈔/02a_卷上之二#64
【原文】《十輪經》云：若有鈍根眾生，為欲發起善根因緣，懈怠少智忘失正念，貪著住處衣服飲食四事供養，遠離一切諸善知識；如此眾生教令勸化，料理僧事及以佛法和尚闍梨，是為安置營事福處。若聲聞弟子心不恭敬、不堅持戒；為法久住而調伏之，若起心念教令心悔。又須言語而謫罰者，驅令下意，終不與語；亦於僧中謫令禮拜，訶詰嫌責，不同僧利；或在僧前四體布地，自歸伏罪；或時驅出，不得共住。我知眾生心所趣向，為利彼故廣說諸經地獄等苦，為欲調伏破戒眾生。若諸比丘護持戒者，天人供養，不應謫罰。除其多聞及持戒者。若有破戒而出家者，能示天龍八部珍寶伏藏，應作十種勝想、佛想、施心。若有破戒，作惡威儀，當共耎語，乃至禮足；後生豪貴，得入涅槃。是以依我出家，持戒、破戒，不聽輪王宰相謫罰，況餘輕犯。破戒比丘，雖是死人；是戒餘力，猶如牛黃麝香眼藥燒香等喻。破戒比丘，為不信所燒，自墮惡道；能令眾生，增長善根。以是因緣，一切白衣皆應守護，不聽謫罰。四方僧眾布薩自恣，三世僧物飲食敷具，皆不預分。優波離白佛：若非法器，云何驅遣？佛言：我不聽俗人譏訶，比丘得作。復有十種非法，即得大罪：若僧不和，於國王前、王眷屬前、大臣前訶，白衣、婦女小兒中、僧淨人前、比丘尼中、本怨嫌人前。如是等，假使舉得少罪，亦不應受。下具出舉法，如律法中。
【譯文】《十輪經》說：若有鈍根眾生，為了發起善根因緣，卻懈怠少智、忘失正念，貪著住處、衣服、飲食等四事供養，遠離一切善知識；對這樣的眾生，應當教導勸化他們，去料理僧團事務，以及為佛法、和尚、阿闍梨奔走營辦，這便是將他們安置在營辦福業之處。若聲聞弟子內心不恭敬、不堅持戒律，為了正法久住而調伏他們：若剛起心動念，便教令內心悔過；若須藉言語責罰，則貶抑其傲慢令其謙順，且始終不與他說話；也可在大眾僧中責令其禮拜認錯、呵斥責問，不准共享僧團利養；或在僧前四體著地、歸順伏罪；或者暫時驅逐出寺，不得共住。我深知眾生心之所向，為了利益他們而在諸經中廣說地獄等痛苦，就是為了調伏破戒眾生。若諸比丘能護持戒律，受天人供養，則不應橫加責罰。（持戒者自不待言），即使除去了多聞與持戒之德（純屬破戒者），若有破戒而出家者，能為天龍八部開示珍貴的法寶伏藏，信眾應當對其生起十種殊勝想、作佛想、生起布施供養之心。若有人雖然破戒、威儀粗惡，在家人也應當對其和言軟語，乃至向其頂禮雙足；以此恭敬福田因緣，來世能生於豪門富貴之家，終得趣入涅槃。所以凡是依從我的教法出家之人，無論持戒還是破戒，佛都不允許轉輪聖王或宰相大臣對其進行責罰，何況是其餘輕微犯戒者。破戒比丘雖然在佛法中如同死人，但依憑戒體的殘餘威力，依然如同牛黃、麝香、眼藥、燒香等比喻那樣具有妙用。破戒比丘雖然因缺乏正信焚燒自身而將自墮惡道，卻仍能令見聞眾生增長善根。因為這個緣故，一切在俗白衣皆應當守護僧人，不准許擅加責罰。（但破戒比丘）對於四方僧眾的布薩說戒、自恣，以及十方三世僧眾的飲食、坐臥鋪具等常住物，都不得參與受分。優波離尊者向佛稟白：『如果破戒者已非佛法法器，應當如何驅遣他？』佛說：『我不聽許在家人譏嫌呵斥，但比丘僧眾可以如法處理。』又有十種非法的舉罪情況，舉者即得大罪：一、在僧團不和睦時舉罪；二、在國王面前；三、在國王眷屬面前；四、在大臣面前訶責比丘；五、在在家人、婦女小兒之中；六、在寺院僕役淨人面前；七、在比丘尼之中；八、在原先就有怨懟嫌隙之人面前舉罪訶責。如是等，假使舉得少罪，僧團亦不應受理該檢舉。後文詳細列出如法舉罪之法，如同律典中所說。

【023-0002】01_行事鈔/02a_卷上之二#65
【原文】《涅槃》中，種種示相已，云：於毀法者，與七羯磨；為欲示諸行惡行者有果報故。當知如來，即是施惡眾生無恐畏者。以現在治罰，息將來大怖故。若善比丘置不訶責，當知是人佛法中怨；若能驅遣舉處治罰，是我弟子真聲聞也。
【譯文】《涅槃經》中，在種種指示相狀之後說：對於毀犯正法的人，僧團應當對其作「七種羯磨」予以懲戒；這是為了向所有造作惡行的人昭示必定會有業力果報的緣故。應當知道如來正是施予造惡眾生無所怖畏的大慈悲者。因為藉由現世在僧團中的懲戒處治，能夠止息他們未來墮入惡道的巨大恐怖之故。如果持戒修善的善比丘放任不管而不加訶責，應當知道這個人是佛法中的怨敵；如果能夠驅遣、舉處並加以治罰，這才是我佛的弟子、真正的聲聞。

【023-0003】01_行事鈔/02a_卷上之二#66
【原文】二就制教以明者。僧令懺悔，改迹便止。上品之徒，見影依道；下流之類，拒逆僧命，不肯從順，無慚無愧，破戒犯失，續作不止。自非治罰，何由可息？如似遲驢，必加楚罰；則有七種調伏，及惡馬治、默擯、不與語等。
【譯文】第二是就「制教」（戒律制度之教）來加以說明。僧團飭令犯過者發露懺悔，若其改過遷善便立即停止追究。上根上品的僧人，猶如良馬見鞭影便能依循正道收斂；下劣頑鈍之輩，則抗拒違逆僧團號令，不肯聽從順服，無慚無愧，破戒犯過接連不斷、造作不止。若非施以治罰，如何能夠止息惡行？就如同愚鈍遲緩的劣驢，必須施加楚罰鞭責；因此律中便有七種調伏之法，以及惡馬治、默擯、不與語等治罰。

【023-0004】01_行事鈔/02a_卷上之二#67
【原文】比佛法東流，多不行此；若聞正說，反生輕笑；薄濫佛法，自穢淨心。有過之徒，實當此罰；反用俗法，非理折伏；相雖調順，心未悛革。致使聖網，日就衰弱。文云：非制而制，速滅正法。斯言允矣。今舉彼微言，重光像運；有力住持眾主，準而行之。
【譯文】自從佛法東傳漢地以來，多數寺院不推行這些律制；有些人若聽到如律的正說，反而生起輕浮蔑笑；輕慢濫用佛法，自染污了清淨自心。有罪過之輩，確實應當受此治罰；然而近世反而採用世俗之法，不依佛理加以折伏；外相雖然看似調順，內心卻未曾悔改革新。以致使僧團的戒律聖網日益衰頹削弱。經文說：『非佛所制卻擅自制定，將會迅速毀滅正法。』這話確實切當。如今標舉經律中幽微深奧的教言，以重振像法時期的教運；有能力的住持與大眾執事，應當以此為準則遵照實行。

【023-0005】01_行事鈔/02a_卷上之二#68
【原文】《四分》中：凡欲治罰舉人者，自具兩種五德，如〈自恣〉法。又須三根具了，徒眾上下同心共秉，犯者聽可，然後舉之。具如律本遮法中說。若違上法，舉不知時，反生鬪諍。故文云：汝等莫數數舉他罪，以恐壞正法故。必具上法，縱而不治，亦滅正法。
【譯文】《四分律》中說：凡是想要檢舉並懲處犯過之人者，自身必須先具備兩種「五德」（五種清淨德行），詳見〈自恣篇〉。又必須對「見、聞、疑」三根罪相具體審察明了，大眾僧徒上下齊心共同秉公行事，並徵得被檢舉者的同意聽許，然後才能正式檢舉發落他。這一切都詳細記載在《四分律》本「遮犍度」中。如果違背上述法軌，舉發不知合於時宜，反而會引發鬥諍；所以經文說：『你們不要頻頻舉發他人的罪過，因為唯恐敗壞正法。』但如果已經具備上述如法的舉罪條件，卻放縱惡人而不加治罰，同樣也會毀滅正法。

【023-0006】01_行事鈔/02a_卷上之二#69
【原文】今明治法七種九種。言七法者：一謂訶責，二謂擯出，三者依止，四者遮不至白衣家，五者不見罪，六者不懺罪，七者說欲不障道。加惡馬、默擯二法，則為九也。
【譯文】現在說明處治之法有七種與九種。所謂「七法」是指：第一是訶責羯磨，第二是擯出羯磨，第三是依止羯磨，第四是遮不至白衣家羯磨，第五是不見罪羯磨，第六是不懺罪羯磨，第七是說欲不障道羯磨。若再加上「惡馬治」與「默擯」兩種治法，便總合為九種治法。
