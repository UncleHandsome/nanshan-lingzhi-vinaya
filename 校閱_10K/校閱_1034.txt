# 校閱材料　第1034檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1034-0001】資持記/05b_上四#44
【原文】初明輕罪可懺，是本位故。重不可懺，故致異說。次科，初示無文；今下，義定；云今日下，出法。言通解者，取上初義；按自恣中，即準座上發露為例；即對次義為局，故云通也。問：此發露已，為須更陳三說布薩否？答：文云不應說戒，似不再陳。準《注羯磨》引《五百問》，令如上三說。
【譯文】首先說明輕微之罪可以懺除，這是常途本位之法；重罪不可懺除，所以引發了不同的說法。次一科中，首先指出律典並無明文；從「今」字以下，是由義理來判定；從「云今日」以下，是列出作法的詞句。所謂「通解（通達之解釋）」，是取用上面的第一種義理；按照〈自恣篇〉中的規定，就是比照在座上發露為例；這相對於第二種義理的局限，所以稱為「通」。問：此處發露之後，還需要另外陳述三番說布薩嗎？答：律文說「不應說戒」，看似不再陳述。但依照《注羯磨》引述《五百問》的說法，則命令如同上文那樣作三番宣說。

【1034-0002】資持記/05b_上四#45
【原文】又約疏中，引《僧祇》，若無客者，作念：若得清淨比丘，罪如法除；念已，當心念口言，三說布薩。此即向四方僧發露，大如僧中。〔疏文〕今詳《羯磨》及疏，並作念發露，無別詞句，故依三說；此既立法，即當布薩，不勞更陳。然今臨事依疏為佳。三中。向僧懺悔，即作念陳露也；或可輕罪責心即滅。
【譯文】另外依照戒疏之中引述《僧祇律》，如果沒有客僧到來，就應當在心中作念：「如果我得以遇到清淨的比丘，我的罪業必定依照戒法除滅」；作了這個念頭之後，應當口中宣說、心中默念，三番宣說布薩法。這就是向四方僧眾發露，其法度大略如同在大眾僧中作法。〔此處為戒疏原文〕如今詳細玩味《羯磨》與戒疏，都是作念發露而沒有別的繁雜詞句，所以應當依據三說之法；這裡既然已經立下作法，當下就等同於布薩，用不著再徒勞重陳。然而如今臨場行事，還是依照戒疏的規矩為好。在第三段中。「向僧懺悔」，就是心中起念陳述發露；或者輕微的戒罪只要深自責心就能滅除。

【1034-0003】資持記/05b_上四#46
【原文】三說者，謂作法布薩也。廣誦戒者，識知持犯也。然非教制，本不須誦；以前作法，即成說戒；不同僧法白告和僧，非陳淨故。心念既爾；前對首中，殘及重蘭，例開發露，如〈自恣〉中。
【譯文】所謂「三說」，是指如法進行布薩儀式。所謂「廣誦戒本」，是為了能清楚辨識並通曉持戒與犯戒的界限。然而這非教制，原本不必強求背誦；因為前面的作法，當下就已經達成了說戒的實質功德；這不同於大眾僧法中那種正式宣告並求得僧眾和合的儀軌，並非單純陳述個人清淨而已。心念作法既然如此；前面的對面作法中，僧殘罪以及重偷蘭遮罪，也都照例開許發露，正如在〈自恣篇〉中所說的那樣。

【1034-0004】資持記/05b_上四#47
【原文】11 釋安居篇(上四)釋安居篇形心攝靜曰安，要期在住曰居〔此依疏解〕，隨時警勵曰策，三業󰍍善曰修。上通人處，下局行業。就此一門，總有四別：初約法有四，對首、心念、忘成、及界；又及界中，園界兩所，足有雙隻，則為七矣。時有三種，前中後也。
【譯文】第十一章：解釋安居篇（上四部分） 解釋安居篇：身形與內心收攝歸於止靜稱為「安」，立下必定履行的期限而安住一處稱為「居」〔這是依照戒疏的解釋〕，隨著時節策勵警醒稱為「策」，身口意三業成辦充備諸善稱為「修」。「安居」二字普遍通於人與處所，「策修」二字則偏重局限在行持與事業。單就這一個門類而言，總括起來共有四種差別：首先就作法而言有四種，即對面作法（對首）、心中默念（心念）、忘記結界而自然成就（忘成）、以及依界結夏（及界）；又在及界法中，有僧園與攝僧界兩個處所，踏入界內時又有雙腳（雙足）與單腳（隻足）之別，共成四種，加上前三種就成了七種。時節則有三種，即前安居、中安居、與後安居。

【1034-0005】資持記/05b_上四#48
【原文】處通兩界，自然、作法。人該五眾，並通一制。問：安居別法，那為眾行？答有三意。一受說安恣，次第相由故。二夏安居竟，其必自恣，以後攝故。三本篇雖是別法，分房受日，皆眾法故。制意中，初科為二；初釋安義，兼示策修。隨下，明居義。此敘教意，仍見篇題。處字上呼，訓止訓息。
【譯文】處所則通貫兩種界限，即自然界與如法作法所結之界（作法界）。所規範的人涵蓋五眾弟子，全都普遍遵從同一套佛制。問：安居本是各別修持的法門，為什麼被列為大眾僧共修的行持？答：這裡面有三層用意。第一，受戒、說戒、安居、自恣這四法，是依循次第環環相扣而生起的。第二，結夏安居圓滿結束之後，必然要舉行自恣儀式，這是由後續的大眾法來攝持前法的緣故。第三，本篇雖然表面是各別修持的法門，但劃分僧房、受取七日行法等，全都是必須依憑大眾僧來運作的法事。在「制定安居的本意（制意）」中，第一科分為兩部分；首先解釋「安」的意義，順帶指明策進修持的道理。從「隨」字以下，是闡明「居」的意義。這是敘述佛陀立教的本意，同時扣合本篇的題目。「處」字要讀作上聲（止息），訓解為止住、訓解為休息。

【1034-0006】資持記/05b_上四#49
【原文】攝慮專注，為靜處也；觀緣勝法，為思微也。微之一字，兼含事理；事則憶本所受，即戒學也；理則達妄冥真，即定慧也。即〈沙彌篇〉，性空相空唯識三觀；性相二空，即空為理；唯識一觀，即識是理。此三種行，名為聖道；非靜不思，非思不證。三乘雖異，入道皆同，故云正軌。
【譯文】收攝散亂的思慮而專注於一境，這就叫作安靜之處；觀察緣起微妙深遠的殊勝正法，這就叫作深思微妙。這個「微」字，同時兼含了事相與理性兩個層面；就事相而言，是憶念最初受戒時所發的誓願，這就是戒學；就理性而言，是通達妄相本空而契入真如，這就是定學與慧學。正如〈沙彌篇〉中所說的性空觀、相空觀、唯識觀這三種觀照；性空與相空這兩種觀門，都是以空性為最高理性；唯識這一種觀門，則是以識心為究竟理性。這三種行持，統稱為聖道；心不寧靜就無法深思，不深思就無法證悟。聲聞、緣覺、菩薩三乘雖然根機不同，但趣入聖道的正軌都是一致的，所以說是通往解脫的正軌。

【1034-0007】資持記/05b_上四#50
【原文】剋期夏限，不捨寸陰，故云假日追功。勉慎懈怠，無遺正念，故云策進心行。次釋居義，初句明所須。即下《了論》，處無五過。次句明標志。即下起三種安居心。不許下，明守制。即下三過，對之可見。次科，初敘通意。律因諸比丘一切時遊行，蹋生草木，斷眾生命；世人譏訶：蟲鳥猶有巢窟；
【譯文】嚴格限定在結夏的三個月期限之內，分秒必爭而不肯荒廢一寸光陰，所以說是趁著假期來追趕道業功勛。勉勵戒懼懈怠放逸，不讓正念有一絲一毫的遺失，所以說策勵推進身心的修持。其次解釋「居」的意涵，第一句是說明安居所必須具備的前提。也就是下文《四分律了論》所說的，所住處所必須沒有五種過失。第二句是說明立定志向目標。也就是下文要生起三種安居的發心。從「不許」以下，是說明必須堅守佛制戒規。也就是下文所列的三種過失，兩相對照即可明了。在次一科中，首先敘述普遍通行的意旨。律藏記載因為諸位比丘一年四季都在外遊行托缽，踩踏傷害了新生的草木，斷送了眾生的性命；世俗之人便譏諷責難說：就連飛禽走獸蟲鳥都還知道構築巢穴窟洞；

【1034-0008】資持記/05b_上四#51
【原文】佛因制曰：不應一切時遊行。文下，明偏意。三過中，初是自損，二即損他，三損自他。招世譏者，如上緣起。問：三時情過多少，在文可明；制有重輕，如何以辨？答：春冬有緣則聽，夏月有無俱制。又夏有結法，春冬則無。又春冬不結，但犯一吉；夏中不結，至後安居，日日吉羅。
【譯文】佛陀因此制定戒條說：不應當在一年四季無休止地遊行在外。從「文」字以下，是說明特別偏重的用意。在三種過失之中，第一是傷害自己，第二是傷害他人，第三是自他俱損。所謂「招致世人的譏嫌責難」，就如同上面的緣起所說。問：春、夏、冬三時中，比丘們在情理上的過失多寡，在文獻中可以清楚明白；但佛制的戒律處分有重有輕，又該如何加以辨析？答：在春天和冬天如果有正當事緣，佛陀就聽許外出遊行，唯獨在夏季三月，無論有沒有事緣都一律嚴格禁止。再者，夏季必須如法作法結夏，春冬二時則完全沒有結界安居之法。再者，春冬二時不結夏，只不過違犯一個輕微的吉羅罪；在夏季如果不作法結夏，到後安居之時，天天都在結犯吉羅罪。
