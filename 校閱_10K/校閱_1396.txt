# 校閱材料　第1396檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】此篇大門有七一波羅夷二僧伽婆尸沙三偷蘭遮四波逸提五波羅提提舍尼六突吉羅七惡說。

【1396-0004】04_比丘尼鈔/01a_卷上之上#9
【原文】第一波羅夷者十誦云謂墮不如意處婆論釋云猶與魔鬬以犯此戒便墮負處阿毗䟦律云夷者秦言劫功德也釋云波羅夷者譬如斷人頭不可復起也若犯此戒不復成比丘尼此但從行法非用為名又無餘者此從眾法絕分為名故偈云諸作惡行者猶如彼死屍眾所不容受以是當持戒。
【譯文】第一類、「波羅夷」：《十誦律》解釋為：墮落到極其不如意、極痛苦的處所。《薩婆多論》解釋說：如同與魔王作戰，一旦毀犯了此戒，便立刻墮入慘敗的境地。《阿毗䟦律》說：夷，在秦地語言意為劫奪功德。律文解釋說：波羅夷，好比砍斷了人的頭顱，再也不可能復活；如果毀犯了這條戒，就再也不成其為比丘尼了。這純粹是從失去行持戒法的資格而命名的。又被稱為「無餘」，這是從徹底斷絕於僧團大眾共住法之外而命名的。所以偈頌說：凡是造作極重惡行的人，就像那沒有生命的死屍一樣，僧團大眾絕不予以包容接納，因此應當謹慎持守淨戒。

【1396-0005】04_比丘尼鈔/01a_卷上之上#10
【原文】第二名僧伽婆尸沙者婆論云僧伽者名僧婆尸沙者名殘若犯此罪垢纏行者非全淨用有殘之罪由僧除滅故名僧殘母論云如人為他所斫殘有咽喉故名為殘。
【譯文】第二類、名為「僧伽婆尸沙」：
《薩婆多論》說：僧伽，意思是僧團；婆尸沙，意思是殘餘。如果犯了這種罪過，罪垢纏繞在修行者身上，已經不再是完全清淨無瑕的行者，但還留有殘餘挽救的希望，這殘餘的罪過必須完全依賴僧團才能除滅，所以稱為僧殘。《毗尼母論》說：就像人被他人砍傷，殘存著喉嚨一息尚存，所以稱之為殘。

【1396-0006】04_比丘尼鈔/01a_卷上之上#11
【原文】第三偷蘭遮者見論云偷蘭名為大遮言障善道體是鄙穢此從不善以立名。
【譯文】第三類、「偷蘭遮」：
《善見律》說：偷蘭，意思是重大；遮，意思是阻礙障蔽善道。其本質極為鄙陋汙穢，這是從不善的惡劣體質來命名的。

【1396-0007】04_比丘尼鈔/01a_卷上之上#12
【原文】第四波逸提者十誦云墮在燒煑覆障地獄故名墮尼薩耆者出要律儀云尼薩耆者舊翻為捨墮聲論云尼翻為盡薩耆為捨此云盡捨捨財捨罪捨心具此三捨故云盡捨。
【譯文】第四類、「波逸提」：
《十誦律》說：會墮落在遭受燒烤、煮沸、幽暗覆蓋的地獄之中，所以意譯為「墮」。關於「尼薩耆」，《出要律儀》說：尼薩耆過去翻譯為「捨墮」。《聲明論》說：尼翻譯為「盡」，薩耆翻譯為「捨」，在漢語中意思就是「盡捨」；必須捨棄非法所得之財物、發露捨除所犯之罪過、徹底捨棄貪求執著之心，具備了這三種捨，所以稱為盡捨。

【1396-0008】04_比丘尼鈔/01a_卷上之上#13
【原文】第五波羅提提舍尼者義翻云向彼悔從對治境以立其名明了論云翻為各對應說謂對人說所作罪也。
【譯文】第五類、「波羅提提舍尼」：
義譯為「向彼悔」，是依據對治化解罪過時所面對的對象來命名的。《明了論》中翻譯為「各對應說」，意思是必須面對個別清淨的人陳述並揭露自己所犯的罪過。

【1396-0009】04_比丘尼鈔/01a_卷上之上#14
【原文】第六突吉羅者見論云突者惡也吉羅者作也此律云式叉迦羅尼者翻為應當學見論云式叉者學迦羅尼應當作名為學應當作也義云西域語例故云學應當作若依此方應云應當學婆論問曰何故此篇獨名應當學答餘戒易持而罪重犯懺是難此戒難持罪輕而易犯當順心學不結罪名故云應當學又西僧云翻為守戒此罪微細持之極難故隨順當守以立其名十誦云以天眼見犯戒比丘如駛雨下豈非精翫在心名為守戒也。
【譯文】第六類、「突吉羅」：
《善見律》說：突，意思是惡；吉羅，意思是作。本部《四分律》稱之為「式叉迦羅尼」，翻譯為「應當學」。《善見律》說：式叉是修學，迦羅尼是應當作，全名就是「學應當作」。義理上說：這是印度西域的語言行文慣例，所以說學應當作；如果依照漢地的語法，應當稱為「應當學」。《薩婆多論》提出疑問說：為什麼這一篇單獨稱作應當學呢？回答說：其餘篇章的戒條比較容易防持，但罪過沉重，犯了之後難以懺悔清淨；這一條戒極難防持，罪過雖然輕微卻非常容易違犯，因此應當順應本心隨時修學，而不直接冠上罪名，所以稱為應當學。另外，西域的高僧說：這也可以翻譯為「守戒」，因為這種罪過極其微細，持守起來無比困難，所以必須隨順謹慎防守，以此確立名稱。《十誦律》說：佛陀以天眼看見犯戒的比丘，多得像暴雨傾瀉而下，若不是在內心極其精細地研磨觀照，怎能稱得上是守戒呢？

【1396-0010】04_比丘尼鈔/01a_卷上之上#15
【原文】第七惡說者初以身名惡作口名惡說故突吉羅復加一惡說合有七也。
【譯文】第七類、「惡說」：
起初以身體所犯的稱為「惡作」，口業所犯的稱為「惡說」，因此在突吉羅之外又加上了「惡說」，合起來就有了七聚罪名。
