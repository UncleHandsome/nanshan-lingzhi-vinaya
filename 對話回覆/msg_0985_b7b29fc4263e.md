### 二、 相關程式碼調整（確保審核拿對資料、檢索找對母文、下游不撞牆）

#### 1. `mk_audit_materials.py`（及 `pack_audit.py`）
* **修正舊批次《資持記》誤標 `鈔文` 帶入審核的問題**：
  第 3 組中《資持記》在裁決階段就已經錯標成 `■ 鈔文（原文）` 與 `【鈔文】`。在 `mk_audit_materials.py` 寫出 `srcs` 與 `body` 前，若確認 `book == '資持記'`，應把舊材料殘留的 `鈔文` 標籤轉正為 `記文`，別讓審核模型頂著錯誤的 `【鈔文】` 標籤判讀：
  ```python
  if book == '資持記':
      srcs = [('記文' if lab == '鈔文' else lab, s) for lab, s in srcs]
      body = re.sub(r'(?m)^【鈔文】', '【記文】', body)
  ```
* **放寬裁決線索篇名截取長度**：
  `mk_audit_materials.py` 的 `_srcs = re.findall(r'《[^》]{2,20}》[^，。；\n]{0,8}', _why)` 只有 8 字，像 `《行事鈔》卷下之四〈諸部別行篇〉` 會被截成 `〈諸部`。改為 `{0,16}` 即可保留完整卷次或篇名。
* **移除已失效的冗餘 `note` 判斷**：
  `mk_audit_materials.py`、`pack_audit.py`、`mk_judge_materials.py`、`mk_revise_materials.py` 裡那段 `if book in ('業疏', '戒疏') and not _has_dual: note = ... else: note = ...` 都會在兩行後被 `note = BC.note_for(book, _labs)` 覆蓋，建議刪掉冗餘舊段，統一由 `BC.note_for()` 控制。
