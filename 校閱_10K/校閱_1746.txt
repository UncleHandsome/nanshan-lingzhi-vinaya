# 校閱材料　第1746檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1746-0001】03_業疏/13a_卷三之二#3
【原文】文列戒為舟航、違順約緣者，以如來出世，不欲增長諸有，要求滅欲，故立茲學。然戒是定慧初基、眾行元本，本既不立，餘何所憑？但以佛世利機，契動便感；末時澆薄，聖制從緣。緣集則作業功成，緣散則戒德無立。無作不可見也，託緣定其有無，大聖唱言，信非徒爾，故前控引生起緣非
【譯文】疏文中列出戒律是生死之舟航、違順取決於因緣，是因為如來出興於世間，並不想讓眾生增長三界輪迴的種種生存境界，而是要求斷滅貪欲，所以才創立了這門戒學。然而戒律是禪定與智慧的初步基礎，是一切行持的根本源頭；根本既然不能確立，其餘的修行又能憑藉什麼？只是因為佛陀在世時眾生根機敏利，心意契合動念便能感得戒體；末世世風澆薄浮泛，至聖佛陀才制定受戒必須依順因緣。各種因緣聚集完備則造作戒業之功成就，因緣散亂欠缺則戒德無法建立。無作戒體是不可見的，必須依託外在因緣來判定其有無，大聖佛陀所宣發的言教，確實不是隨意虛設的，所以前面引證指陳而生起關於受戒因緣是非的辨析。

【1746-0002】03_業疏/13a_卷三之二#4
【原文】就法顯戒德中：初至「所憑」，釋歎戒。前釋生死舟航，「不欲增諸有」者，人天非意也；「要求滅欲」者，為令出離也，欲即是惑，生死本故。「然」下釋正法根本，定慧是別標二學，眾行乃統攝三乘。「但」下至「徒爾」，次釋立緣。初敘須緣所以，利機如善來度者，契動謂不假多緣也。「緣集」下明順違得失，集即齊具，散即乖缺。「無作非色」故不可見，「眾緣有相」故可定之。「大聖唱言」，謂是佛制。「故」下示注意，控猶據也
【譯文】在就法彰顯戒德之中：開頭至「所憑」一句，是解釋讚歎戒律。前半段解釋戒為生死舟航，「不欲增諸有」是指佛意不在於求得人天福報；「要求滅欲」是為了令眾生解脫出離，欲就是煩惱迷惑，因為它是生死輪迴的根本。「然」字以下解釋戒為正法根本，定慧是個別標示定慧二學，眾行則是總體統攝三乘的一切行門。「但」字以下至「徒爾」，接著解釋立緣的理由。開頭敘述必須依託因緣的原因，敏利的根機如同善來度化之人，「契動」是指不須假借繁多的因緣。「緣集」以下說明順違與得失，集就是齊備具足，散就是乖違欠缺。「無作非色」所以肉眼不可見，「眾緣有相」所以可以據以判定其有無。「大聖唱言」，是指這是佛陀所制定的教令。「故」字以下顯示疏文註解的用意，「控」的意思如同引證依據。

【1746-0003】03_業疏/13a_卷三之二#5
【原文】今解已下，託緣顯障。文云「二種羯磨具五緣」者，或中邊分二，或僧尼分二，竝通收羯磨，用分諸受。然諸部中，敘緣不一：《母論》但就緣言，《多釋》唯列因相。今通會之，總五為約，謂能、所、心，及具、終也
【譯文】「今解」以下，是依託因緣來彰顯障礙。疏文中說「二種羯磨具足五緣」，或者是指依中國（中印度）與邊地而分為二種，或者是指依比丘僧與比丘尼僧而分為二種，都是普遍含攝羯磨法，用來分別各種受戒法。然而在各部派律典之中，敘述因緣各不一致：《毗尼母論》只就「緣」的角度來說，《薩婆多論》的解釋則只列出「因」的事相。現在普遍融會各說，總結以五種為準則，也就是：能受人、所受境、發心，以及作法資具、終成作法。

【1746-0004】03_業疏/13a_卷三之二#6
【原文】次科釋總標中：初點文，「託緣」即下五緣，一一緣下各顯乖障，用成如法。「文」下牒釋，中邊約方，僧尼約位。「竝通收」等者，羯磨六受，若中邊分者，十人、二十、遣信、曾歸，竝中國也；五人并義立十人，竝邊方也。若僧尼分者，五人、十人是僧，餘二十人等竝屬尼也。「然」下列示，《母論》如所對中三、五兩緣所引，《多釋》即是《多論》，如能受中初、三兩緣所引。此據能、所以分因緣，或約發心為因，餘竝為緣，隨時不定，勿滯一端
【譯文】在第二科解釋總標之中：開頭點明文字，「託緣」就是指下文的五種緣，在每一種緣的下面各自顯發違背法度的障礙，以彰顯如法的狀態。「文」字以下引述原文並作解釋，中邊是就地域方所而分，僧尼是就僧眾階位而分。所謂「竝通收」等，羯磨六種受戒法，如果按中邊來分：十人受、二十眾受、遣信受、曾歸受，都屬於中國；五人受以及比照義理建立的十人受，都屬於邊地。如果按僧尼來分：五人受、十人受屬於比丘僧，其餘二十眾受等全屬於比丘尼。「然」字以下列出示範，《毗尼母論》就像在所對境之中第三、第五兩種緣中所引用的那樣，《多釋》就是《薩婆多論》，如同在能受人之中第一、第三兩種緣中所引用的那樣。這是依據能受與所受來區分因與緣，或者也可以將發心視為因，其餘全都視為緣，隨順各時的解說並不固定，不要執滯於單一說法。

【1746-0005】03_業疏/13a_卷三之二#7
【原文】就初能受類分又五，以能名濫，非別不顯。在生正務，唯戒尊高，有缺諸緣，雖受不獲，故須指掌程露其相故也
【譯文】就第一項能受人之中分類又分為五種，因為「能受」的名稱容易含混籠統，不加以分別就無法顯發明確。在人的一生中最重要的正業事務，唯有戒律最為尊嚴崇高；如果有所欠缺這些因緣，即使受戒也無法獲得戒體，所以必須如同指看手掌般明確顯露其相狀的緣故。

【1746-0006】03_業疏/13a_卷三之二#8
【原文】初能受人標舉中：初示通別，能受名通，五種相別，濫謂通濫。「在」下明須列之意，指掌喻其易見，程露猶顯示也
【譯文】在第一項「標舉能受戒之人」中：首先說明通名與別相，「能受人」是通稱，五種條件是別相，「濫」是指通稱容易造成混淆混濫。自「在」字以下說明必須列舉這些條件的用意，以「了如指掌」比喻其容易明白見到，「程露」就是顯露、示現的意思。

【1746-0007】03_業疏/13a_卷三之二#9
【原文】初唯是人簡四趣者：天實報勝，但著樂多，無求修道故也；修羅懷疑，道在會正；非人鬼神，諂誑不實；畜生報局，愚騃所收，道在質直、慧心遐舉，戒受為道，非道故障；地獄常苦，亂惱衝心，故論說言「如鎔鐵聚，何能懷道而受戒也？」唯斯人者，苦輕下趣，樂劣上天，強識念力，能崇道業，如《多論》引歸戒所投，誠有致也
【譯文】第一項「唯獨人道能受戒」而簡別淘汰其餘四道者：天道果報確實殊勝，但貪著享樂太多，沒有修求道業之心；阿修羅心懷猜疑，而道法貴在契會正理；非人、鬼神諂媚誑詐而不真實；畜生果報侷限，為愚蠢癡呆所拘縛，而道法貴在質樸正直、智慧高遠超拔，受戒是為了成道，非道之障礙便阻礙了發心；地獄長受劇苦，擾亂煩惱衝擊其心，所以論中說「如同融化的鐵汁聚結，哪裡能懷抱道心而受戒呢？」只有人道眾生，痛苦比下三道輕微，享樂不及諸天，具有強大的辨識力與意志力（念力），能夠尊崇建立道業，正如《薩婆多論》所引三皈依與戒法所寄託付予之處，確實深具道理。
