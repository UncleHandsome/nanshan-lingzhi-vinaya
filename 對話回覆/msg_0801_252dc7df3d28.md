### 一、要先修的 4 個新 Bug／不同步（不修會影響輸出）

#### 1. `mk_split_blind.py` 字串跳脫寫錯，會印出字面 `\n`
看第 6.16 節這三行：
```python
_pn = "\\n\\n（本單元為長文第 %d/%d 部分，只譯這一部分，勿補前後文。）" % (pi, len(parts))
_j = prompt.find("照下列完整標籤輸出")
prompt = (prompt[:_j] + _pn + "\\n" + prompt[_j:]) if _j >= 0 else (prompt + _pn)
```
這裡寫成了雙反斜線 `"\\n\\n"` 與 `"\\n"`，產出的 `.md` 檔會直接出現字面 `\n\n（本單元……）\n照下列完整標籤輸出`，沒有真的換行。改回 `"\n\n..."` 和 `"\n"` 即可。

#### 2. `pack_audit.py` 把所有單欄書的 `book_note` 都清空了
看第 6.20 節這兩行：
```python
_dual = ('**【疏】【記】須義理互核**：...' if (_book in ('業疏', '戒疏') and {'疏文', '記文'} <= _labs) else '')
_note = _cfg.get('note', '') if _dual else ''
```
只要是《尼鈔》《行事鈔》《義鈔》《資持記》，或單欄的《業疏》《戒疏》，`_dual` 都是空字串，這行會讓 **`_note` 直接變 `''`**！
結果材料會印出 `### 檢核（；只抓實質錯誤，不挑純修辭）`，而且《尼鈔》的比丘尼律制、《資持記》的「鈔／疏／文／律」指涉規則**全部不見**。應該只對「非雙欄《業疏／戒疏》」換單欄版 `note`，單欄四部書（尼鈔／行事鈔／義鈔／資持記）仍須保留 `_cfg.get('note', '')`（順便把結尾 `【後文背景（僅供參考）】` 也補上 `嚴禁譯入正文`）。

#### 3. `book_config.py` 的 `CHOU_NOTE` 漏了右括號 `）`
```python
CHOU_NOTE = ('《行事鈔》《義鈔》以比丘律制為主，稱謂依原文實指翻譯'
             '（惟本段兼論僧尼或專引尼事者，依該段文脈而定，勿強轉為單一性別。')
```

`《行事鈔》《義鈔》以比丘律制為主，稱謂依原文實指翻譯；兼論僧尼或專引尼事者，勿強轉為單一性別。` 更乾淨。

### 二、剩下 3 處「改了一半、前後微打架」的小地方

#### 1. `SYSTEM_PROMPT` 放寬了檢索例外，但 `AUDIT_PROMPT` 還沒同步
* 你在 `SYSTEM_PROMPT` 第 2 點已經把「法數總括與展開書名引文」拿掉，改成 `（惟略牒詞與古今撞義詞不在此列）`——改得很好，能壓低無謂檢索。
* 但 **`AUDIT_PROMPT` 第 2 段還沒改**，依然寫著：`但遇疏中略牒（如「某字下」「此下」）、古今撞義詞、法數總括或書名引文，仍須檢索確認，不得以字面通順放行。` 終審一樣會被這句逼著狂搜，建議同步拿掉「法數總括或書名引文」。

#### 2. `STYLE_SPEC` 第 1 點連寫兩遍、第 5 點語氣小矛盾
* **第 1 點**：剛講完 `除被訓釋原詞、人地書名、戒名、儀軌稱謂、法數、古度量及「第X篇：……」……外，勿留生澀文言原詞`，後面又緊接 `（保留例外總表：被訓釋原詞、人地書名、戒名、儀軌稱謂、法數、古度量、篇題、……）`，前 7 項在同段背靠背寫了兩次。直接合併成：`除下表例外外，勿留生澀文言原詞（保留例外：被訓釋原詞、人地書名、戒名、儀軌稱謂、法數、古度量、「第X篇：……」〔末不加句號〕、無確據之「某某反」、未定〔補字〕／〔疑作X〕、儀軌「某甲」）。`
* **第 5 點**：寫 `正文一律保留原稱，不強制展開全稱`。「一律保留」＝禁止展開，「不強制展開」＝可展開也可不展開，兩截語氣相反。如果目標是不展開（免得和系統簡稱表互改），寫成 **`正文保留原稱，勿擅自展開全稱`** 會明確許多。（另外「薩婆多」的屬律＝《十誦律》／《薩婆多律》、屬論＝《薩婆多毘尼毘婆沙》仍未寫明對應，模型還是要靠猜。）
* （小註：第 2 點仍無「科判短語除外」，對量產主線沒影響，只會影響 legacy 的一審 `BASE_PROMPT`。）
