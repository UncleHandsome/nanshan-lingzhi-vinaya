# 校閱材料　第367檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【367-0001】02_戒疏/17b_卷四上之二#79
【原文】【註】佛在舍衛。乞食比丘威儀具足，尼見生善而數請，比丘不受。後僧分衣，便以衣與尼，尼輙受之。彼嫌責尼，數數向人說。比丘以過白佛。訶制此戒。
【譯文】【註文】佛陀在舍衛國時。有一位乞食比丘威儀具足，比丘尼看見後生起善敬之心，多次邀請供養，比丘都不接受。後來僧團分發衣料，比丘便將衣物送給該尼，該尼隨即大方接受。那比丘內心嫌惡責怪比丘尼，屢次向別人訴說此事。比丘將這樁過失稟白佛陀。佛陀訶責後制定了這條戒。

【367-0002】02_戒疏/17b_卷四上之二#80
【原文】【疏】就戒緣中。初明尼與僧衣，推而不受。後僧試與，望同僧心，尼輙受之，大乖本望，故科為罪。多事多患，其相若此！
【譯文】【疏文】在戒律緣起中。首先說明尼眾欲供僧衣，比丘謙遜推辭而不肯接受。後來比丘故意試探著給予，期望尼眾也能像自己當初一樣推辭，尼眾卻當場毫不客氣地收下，完全大違比丘原先的期望，所以佛陀判定為有罪。多管閒事必多招患難，事情的行相就是如此！

【367-0003】02_戒疏/17b_卷四上之二#81
【原文】【記】戒緣中。「推」謂辭讓。言「試與」者，《律》云：「比丘念言：『尼數請我而我不受，我今與衣，彼必不取。』」、「多」下，指過誡勑，令無多事。
【譯文】【記文】在戒律緣起中。「推」是指辭讓推卻。說到「試探著給予」，《四分律》說：「比丘心裡想：『這尼眾屢次請我而我不收，我現在拿衣服給她，她必然也不會拿。』」從「多管」以下，指出過失並加以警惕敕勉，令人莫要多事生非。

【367-0004】02_戒疏/17b_卷四上之二#82
【原文】【律】若比丘，與非親里比丘尼衣，除貿易，波逸提。
【譯文】【律文】如果有比丘，贈送衣物給沒有親屬關係的比丘尼，除了互相折算交易之外，犯波逸提。

【367-0005】02_戒疏/17b_卷四上之二#83
【原文】【註】比丘尼等吉羅。不犯者，與親里尼衣，共相貿易，若與塔、與佛、與僧，無犯。
【譯文】【註文】比丘尼等犯突吉羅。不犯的情況：贈送給具有親屬關係的尼眾衣物，雙方互相平價交易交換，若是供養佛塔、供養佛陀、供養僧團，都不犯戒。

【367-0006】02_戒疏/17b_卷四上之二#84
【原文】【疏】戒本六句：一、人；二、非親；三、尼；四、衣物等，文中不明尺寸，而於過咎，大小俱提；五、除貿易；六、結罪。
【譯文】【疏文】戒本文字共有六句：第一是能犯之人；第二是非親屬；第三是比丘尼；第四是衣物等，經文中雖然沒有明確規範尺寸大小，但就招引過患而言，衣物大小都犯波逸提；第五是除互相交易之外；第六是結定罪名。

【367-0007】02_戒疏/17b_卷四上之二#85
【原文】【記】戒本，第四句但指衣體，故知不局大小。
【譯文】【記文】在戒本中，第四句只通泛指出衣物實體，由此可知並不局限於尺寸長短大小。

【367-0008】02_戒疏/17b_卷四上之二#86
【原文】【疏】所以尼與大僧二眾衣犯輕者。今不就希數而制戒也，就譏過故。僧是上尊，躬奉下眾，招譏處深，故重；尼下奉上，譏疑是輕，可知。
【譯文】【疏文】至於比丘尼贈送衣物給大僧與沙彌二眾處罰較輕的原因。現在並非依照事情發生的頻率多寡來制戒，而是完全著眼於世俗譏嫌的過患。比丘僧是高位尊宿，若親手奉送物品給下位女眾，招惹譏嫌極深，所以罪重；比丘尼以下位奉敬上位僧寶，外界的譏嫌猜疑相對輕微，這是理所當然的道理。

【367-0009】02_戒疏/17b_卷四上之二#87
【原文】【記】釋尼犯中。初徵異。大僧、沙彌，故云「二眾」。「今」下，釋通。上奉於下，情理不當，下奉於上，事成順便，故不同也。
【譯文】【記文】在解釋比丘尼犯戒的段落中。首先提出差異何在。包括大僧與沙彌，所以稱為「二眾」。從「現在」以下，進行解釋釋疑。上位尊宿奉承下位女眾，在常情戒理上都不妥當，下位奉事上位，事情顯得順理成章，所以處罰有所不同。

【367-0016】02_戒疏/17b_卷四上之二#94
【原文】【註】佛在舍衛。迦留陀夷為作大衣，便裁作婬像，成已付尼，令在眾後著之，生俗譏笑。諸尼以過白佛，因制此戒。
【譯文】【註文】佛陀在舍衛國時。迦留陀夷為比丘尼縫製大衣，便在上面裁繡男女情愛交會的圖像，縫好後交付給尼眾，並交代她穿著走在僧眾隊伍最後面，引發世俗之人的譏嫌嘲笑。眾比丘尼將此過失稟白佛陀，佛陀因而制定此戒。

【367-0017】02_戒疏/17b_卷四上之二#95
【原文】【疏】就戒緣中，「作婬像」者，良由染患情重，寄物彰過，約境須斷也。《五分》云：「愛道卷衣舒以示佛，視此所作也。」
【譯文】【疏文】在戒律緣起中，所謂「裁製情欲圖像」，確實是因為愛染煩惱極重，藉由物品彰顯內心的淫欲過失，針對境界必須徹底斷除這種因緣。《五分律》說：「大愛道把衣服卷好帶去展開展示給佛陀看，說請看比丘所做的衣物。」

【367-0018】02_戒疏/17b_卷四上之二#96
【原文】【記】戒緣中。初牒釋。由為作衣，致有情染，故云「寄物彰過」。故知此戒雖制作衣，實為斷欲。《五分》下，引示。「卷衣示佛」，顯過宜制。
【譯文】【記文】在緣起中。首先引述解釋。由於替尼眾做衣服，引發了染愛之情，所以說「藉由物品彰顯過失」。由此可知本戒表面上是禁止作衣，實質上完全是為了斷除淫欲。《五分律》以下，引用經律作證。「卷衣展給佛看」，更加顯明此種過失極應制戒防範。

【367-0020】02_戒疏/17b_卷四上之二#98
【原文】【註】彼比丘隨刀截多少，隨一縫一針，皆墮。若復披看、牽挽、熨治，以手摩捫，若捉角頭挽方正、安揲，若安緣，若索線，若續線，一切吉羅。尼等吉羅。不犯者：與親里尼作；與僧作；若為塔；若借著，浣、染、治還主者——一切開。
【譯文】【註文】那名比丘每下一刀裁截布料，乃至每縫一針、下一針，全都結犯波逸提墮罪。如果是代為展開翻看、牽引拉扯、熨燙整理、用手撫摸弄平，或是拉扯衣角使其方正、縫綴補強布片（安揲），或是裝安邊緣，或是尋覓線縷，或是接續縫線，這一切行為都犯突吉羅。比丘尼等犯突吉羅。不犯的情況：為具有親屬關係的尼眾縫製；為比丘僧團製作；若是為了供養佛塔；若是借穿別人的衣服，代為清洗、染色、整修好後歸還原主的——一切都開許不犯。

【367-0032】02_戒疏/17b_卷四上之二#110
【原文】【疏】論犯四緣：一、是尼三眾，《五分》、《多論》「尼眾俱犯提罪」，道、船行戒亦爾，除去俗女不犯此戒；二、是隱、露處；三、無第三人，人相如《鈔》中；四、共坐便犯，《多論》：「比丘坐住，隨尼起坐，一一結提。尼坐亦爾。兩人同一坐，通日但一墮。」
【譯文】【疏文】論述構成犯戒的四個條件：第一、對方是尼眾三眾，《五分律》與《薩婆多論》都主張「尼三眾在此戒中同樣結犯波逸提」，後面的「同道行戒」與「同船行戒」也是如此，除了世俗女子不在此戒結犯（另有俗女戒）；第二、處所屬於隱蔽處或露天處；第三、現場沒有具備見證資格的第三人在場，合適的見證人行相如《行事鈔》中所載；第四、雙方一同坐下即構成犯戒，《多論》指出：「比丘坐著不動，尼眾隨之起立又坐下，每一次坐下都各自結犯一次波逸提。比丘尼坐著不動比丘起坐也是如此。若兩人同坐在一張長座上，整日相續不起只結犯一次墮罪。」
