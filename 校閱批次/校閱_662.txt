# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【662-0001】05_拾毗尼義鈔/04b_卷中之二#25
【原文】第一釋字得名者夫按經論毗尼名滅以無為體但無理一揆更無殊狀何有七滅今隨緣而表且序七而已此中體非過未名曰現前能滅於諍故曰毗尼所以目云現前毗尼毗尼不須更論義無異故世局受稱若在過未不能滅諍故憶念者由僧作法念彼清淨情即息故就能治得名不癡者詳心作法證彼前人黠來不犯諍情即息故從境受目不癡對癡癡在僧故自言者引過懺悔定罪輕重而滅於諍故約能立名多人語者詳心捉籌表多人語定理邪正以滅於諍故亦約能治立名罪處所者前引後違或前言犯後言不犯輕重亦爾言致相違徵其犯處故於前後中以前為實後便是虗何者初言伏罪義可好心僧未許治故言多是實後見僧欲治便復更言此是懼罰之言義可不實故不信也約境為名艸覆地者眾僧共犯因評致諍言既翻覆若尋撿者恐成深重難可從滅故聖大慈開不說名種直爾二眾和合迭相懺謝以息其諍如艸覆地掩塵使不用故引喻得名問既憶念不癡二俱清淨得更互彰名不答望同清淨應得俱成增諍不得互彰然憶念本來清淨若與不癡者所舉不息以他諍謂己曾作故若不癡與憶念名者能舉之人諍復難息以他謂我妄舉清人故問憶念不癡律皆言不作舉憶念何故罪處所中律獨云作舉作憶念答彼實不犯但執三根大眾知情故言此罪更不作舉憶念此人實犯須作舉憶念是知不例。
【譯文】第一、解釋字義以明定得名：依照經論所述，毘尼名為「滅」，是以無為法為體性。真理本是一致的，並沒有特殊異相，哪裡會有七種滅法？現在只不過是隨順各種事緣來表彰，姑且序述七種罷了。在此法中，其體性不屬於過去與未來，稱為「現前」；能夠平息爭諍，所以稱為「毘尼」，因此命名為「現前毘尼」。毘尼的涵義不必再行繁述，其理無別，只因順應具體事緣而領受其名；如果滯留在過去或未來，就不能滅除諍事。所謂「憶念」：是由僧團依法作羯磨，追憶證知該人身心清淨，爭端的情執隨即止息，這是從「能對治」的功能而得名。「不癡」：是詳細審察而依法作羯磨，證明當事人神智清醒之時從未犯過，爭吵隨之止息，這是從所對的境緣受名——以「不癡」對治「癡」，而癡態已在僧前判明。「自言」：是指引咎懺悔，確認罪業的輕重以平息諍端，所以依「能懺」之力立名。「多人語」：是經過仔細審查後以抽籌表決多數人的意見，依法裁定是非邪正以滅除爭端，所以也是約「能治」之法立名。「罪處所」：是指前發言與後發言互相矛盾，或先前承認有犯、後來改口說沒犯，罪情輕重亦是如此前後不一；言辭既然自相矛盾，便必須盤問其犯戒的實處；在前後兩種說辭中，以前說為實，後說則為虛妄。為什麼呢？因為起初認罪伏罪，理應是出於善意真心，當時僧團尚未決定治罰，所以說的往往屬實；後來見僧團即將處罰，便改口狡辯，這顯然是畏懼處罰的話，理應不實，所以不可採信；這是約所犯的境緣立名。「草覆地」：是指大眾僧人共同犯過，因互相評駁引發爭端，言語反覆狡辯；如果逐一盤查檢核，恐怕罪名越來越深重，難以平息；所以聖者大發慈悲，開許不必逐條說明罪名與種類，直接由雙方僧眾和合，互相禮拜懺謝，以此止息諍論；就像用青草覆蓋地面、遮蔽塵土不再揚起一樣，這是引用比喻得名。問：既然憶念與不癡兩者都屬於本體清淨，這兩種名稱可以互相通用嗎？答：從同屬清淨的層面看，理應可以互通；但為了避免引發更激烈的諍端，絕對不可混用。因為憶念戒本來就意味著當事人向來清淨，如果賜與不癡羯磨，舉發者仍不會服氣，會以為他過去真做過錯事；如果對不癡之人給予憶念羯磨，舉發之人同樣難以平息怒氣，以為僧團在胡亂包庇清白之人。問：對於憶念與不癡，律典都規定「不再對此人作舉罪與憶念」，為何在罪處所羯磨中，律文偏偏說「要對此人作舉罪、作憶念」？答：前面那兩種人確實沒有犯罪，只是因為牽扯上見、聞、疑三根，大眾已知內情，所以明言此罪不再作舉罪與憶念；而罪處所這類人是確實犯罪的，必須作舉罪與憶念，由此可知兩者不可相提並論。

【原文】第二定體異者且論現前必有五法五法者何起諍名人秉法名僧僧住處名界軌用名法能滅名毗尼此有四解一解五名四體人僧界別有名體法與毗尼更無別體軌用邊名作法滅諍名為毗尼第二解五名四體少異言毗尼無別體用上四法為體故第三解五名五體既言五法故以調逆進不名法正殄於諍名毗尼問有法起時名作毗尼毗尼起時有法已息如何乃言五法現前答雖不竝頭而有相續在現故言現前第四解能所相對在現前故言五法僧界法毗尼是其能起諍者是其所要以能對所方有滅諍義得名現前毗尼故問為當四人已上作法一向具五法為當亦有不具者答義即不定如伽論云十種羯磨不現前但具四法何者覆鉢捨學家捨作房擯沙彌顛狂不禮不共語不供養等是也唯有僧界法毗尼毗尼者遠有諍義又說戒自恣等唯有僧界法如結大小界唯有僧法若三人已下作能滅者但須三種現除僧界設四人已上但使不秉羯磨者亦有三問五法中能斷通僧人但與一僧名所為通僧人隱僧彰人何答秉法故存僧名所中就數分實有僧別之位皆不秉法故從別名人問五中能所別故使僧人立二名者如三中亦有能所別何故不從能所立僧人答若就數分實應僧人立二但以別人及僧不秉羯磨處齊故同作人名若與僧名恐濫於作法故問瞻波中一人舉一人乃至僧舉僧皆不如法何故上云一人乃至為僧僧為僧皆如法者答瞻波中對羯磨治人是故皆非此中直是定理是非非治人故所以如法問既知五法未知五法中法毗尼人與三法中法毗尼人有何差別答五中法指羯磨法三中法者或是言語定是非為法或自言懺法名法三中人者起諍人及判諍人通名人現五中人者但取起諍人不取於僧其毗尼者勿不皆是諍無之處此是正體故五三同也若就詮相三五皆異何者五法中無指羯磨判滅為無名毗尼三法中無者言語判滅為無名毗尼或以自言懺滅名為毗尼汎論五三異者五法是寬三法是狹何者五法獨滅於言諍若配餘六通滅四諍三法不通故廣如別章。
【譯文】第二、判定滅諍法體的差異：若論「現前」，必定具備五法。何謂五法？一、引發諍端之人稱為「人」；二、秉持如法羯磨者稱為「僧」；三、僧團所居之處稱為「界」；四、運作的軌範法則稱為「法」；五、能止息爭端者稱為「毘尼」。對此有四種解釋：第一種解釋認為是五名四體，「人、僧、界」三者有名稱且有各自的體性，「法」與「毘尼」則沒有個別獨立的體性，在軌範運作方面稱為「作法」，在滅除爭諍方面稱為「毘尼」。第二種解釋同樣是五名四體但微有不同，認為毘尼沒有單獨的法體，是以前面四法的整體運作作為其法體。第三種解釋認為是五名五體，既然名為五法，便以「能調順、折伏、進退等儀軌」稱為法，以「正能斷絕消滅爭諍」稱為毘尼。問：作法生起之時稱為運作毘尼，當毘尼完全顯發時法事已經止息，如何能說五法同時現前？答：雖然不是在同一剎那並列，但有因果相續呈現在當前，所以稱為現前。第四種解釋是以「能治」與「所治」相對呈現在當前，所以稱為五法；僧、界、法、毘尼是能治，引發爭諍的人是所治；必定要以能治對應所治，才具有滅除爭端的作用，所以得名為「現前毘尼」。問：凡是四人以上的作法，是一概都具備這五法，還是也有不具備的情況？答：義理並不固定。如《伽論》說：有十種羯磨不屬於現前，只具備四法：例如覆鉢、捨學家、捨造房、擯沙彌、顛狂者不予作禮、不與交談、不與供養等羯磨即是。這些羯磨只有僧、界、法、毘尼，所謂毘尼只是遠遠具有防諍止諍的意思。又如說戒、自恣等法，只有僧、界、法；如同結大界、結小界，只有僧與法。如果是三人以下進行滅諍，只需三種現前，去除「僧」與「界」；假使有四人以上，但只要不秉作羯磨，也只有三法。問：五法之中，「能斷諍」貫通僧團與個別之人，卻只給予「僧」的名稱；「所處理」的對象也貫通僧與人，為何隱去僧名而只標示為「人」？答：因為實際秉持戒法的是僧團，所以保留僧的名義；在被處理的對象中，就人數來分固然有僧眾與別人之位，但都不處於秉法之位，所以順從個別之稱而稱為人。問：五法中由於能治與所治有別，所以分立「僧」與「人」二名；而在三法之中同樣有能治與所治的分別，為何不依據能所立出僧、人二名？答：若就人數來分，確實應該分立僧與人二名；但因為此處個人與僧團皆不秉作羯磨，其地位平等，所以一律稱為人；若給予僧的名義，恐會與如法作羯磨的僧團相混淆。問：《瞻波羯磨》中說一人舉發一人乃至僧舉發僧，皆是不如法的；為何上文卻說一人乃至僧舉發僧都是如法的？答：《瞻波羯磨》所對治的是以羯磨來治罰人，所以那種做法都是不如法的；此處純粹是論定是非曲直，並非治罰當事人，所以是如法的。問：既然已知五法，不知道五法中的「法、毘尼、人」與三法中的「法、毘尼、人」有何差別？答：五法中的「法」專指羯磨法；三法中的「法」或是指以言教斷定是非之法，或是指自言懺悔之法。三法中的「人」包括引起爭端之人與裁斷爭端之人，通稱為人現前；五法中的「人」只取引起爭端之人，不包含作法的僧眾。至於「毘尼」，無一不是指爭諍止息的無諍境界，這是兩者共通的正體，所以五法與三法在這一點上相同；但如果就表現出來的儀相而言，三與五皆不相同：五法中的無諍，是指藉由羯磨裁決斷滅為無，稱為毘尼；三法中的無諍，是以言論判斷滅除為無稱為毘尼，或是以自言懺悔滅罪稱為毘尼。泛論五法與三法的差異：五法範疇較寬，三法範疇較狹。為什麼呢？因為五法能單獨滅除言諍，若配搭其餘六滅，通滅四種諍端；三法在此則無法通達，詳細如別章所明。

【662-0003】05_拾毗尼義鈔/04b_卷中之二#27
【原文】第三總別通塞者總以收攝為義別以區分立稱通以體徧諸處塞乃唯局自分此中名有總別體殊通塞毗尼之名是總以有收攝義故若論現前名等是則以名各不相收然現前是體通用通故名為總餘六不獨行要假現前方得滅諍即是明用通餘六六自相望六六常別憶念現前非是不癡現前故知是別若以餘六望現前現前常是總若以現前望下六即是其別如似羯磨望受日結界受日結界是別若以結界受日望羯磨羯磨即是總問現前該六名為通者自言亦通何故落在塞中答汎爾自言應說為通但今自言唯取攬短歸己名自言毗尼故不在通餘無攬短之義如憶念之人本亦不犯木癡之人病差不為多人語者各言我是罪處之人後便解違艸布地者不說名種是故不說自言為通指文辨相廣如別章如此七滅論義皆有三法現前若如文辨者唯現前自言二毗尼有三五現前餘五各五其中界現前五中皆同法滅位通隨相各別人亦通五毗尼唯多人語中人可在斷諍數中餘皆不爾僧亦位通隨相不同何者現前毗尼中僧具十德者集餘不在例多人語中僧不問愚智悉集并起諍人自判艸覆中僧不揀愚智要是兩朋眾皆集即此彼互作僧人憶念不癡罪處所中僧應簡取具不愛等四諸門如律。
【譯文】第三、說明總名、別名、共通與局限：總，以收攝統括為義；別，以區分各相而立名；通，指其體性能遍及諸處；塞，指其法局限於自分之內。在此七法中，有名稱上的總別，也有體性上的通塞。「毘尼」之名是總名，因為具有收攝一切滅法之義；若論「現前」等名，則屬於別名，因為各自的名相互不相涉。然而「現前」本身是體性，其功能共通於後六種滅法，所以稱為總；其餘六種滅法不能單獨運作，必須憑藉現前法才能滅諍，這便說明現前的體用通於其餘六滅。後六滅法彼此相對，六法之間常是各自差別的，「憶念現前」絕非「不癡現前」，所以知道是各自獨立之別法。若將其餘六滅對照現前，現前永遠是總；若將現前對照後六滅，現前相對於個別滅法就是其別相。這如同「羯磨」對照「受日」與「結界」，受日與結界是別法；若將結界與受日對照羯磨，羯磨便是總法。問：現前涵蓋了後六法所以稱為通法，「自言」也貫通於諸處，為何卻落在局塞之中？答：一般廣泛意義的自言懺悔，本可說為共通之法；但此處的自言毘尼，專門取「攬取短處歸於自己、發露認罪」為義，所以不列入共通之列。其餘諸法都沒有攬短認錯的意思，如憶念者本來就沒有犯戒，不癡者是狂病已癒不認病中之事，多人語者是各自堅持己見，罪處所者是事後翻供矛盾，草覆地者是不說具體罪名與種類；所以不將自言稱為通法。依據經文辨別各自行相，詳細載於別章。這七種滅諍法在義理推論上，都含有「三法現前」；如果按照律文辨析，唯獨「現前毘尼」與「自言毘尼」兼具三法與五法現前，其餘五滅都各自具足五法現前。其中「界現前」在五法中全體相同；「法滅」的果位通達於一切，但隨其事相各自不同；「人現前」也通於五種毘尼，唯獨在多人語羯磨中，引發爭端之人可以列入裁斷爭端的僧數之中，其餘皆非如此。「僧現前」的果位也是相通的，隨其事相而有不同：在現前毘尼中，僧眾必須具足十德，不符合者不在此列；在多人語中，不論愚昧或聰慧之僧全體齊集，連引發爭諍之人也親自參與判決；在草覆地中，僧團不挑選愚智，必須是爭執的兩派陣營全體到齊，雙方互為秉法之僧與受懺之人；在憶念、不癡、罪處所中，僧眾應當揀選具備不愛、不恚、不怖、不癡等四德的清淨僧，各種門徑皆如律中所述。
