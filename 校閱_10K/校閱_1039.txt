# 校閱材料　第1039檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1039-0001】資持記/05c_上四#20
【原文】行法中，初文。具五法者名為五德。上四約心，名為通德，通一切故；第五約事，名為別德，隨事各局故。順己無黨故不愛，違心無憎故不恚，達教無疑故不怖，知機適變故不癡。知可分等者，或約人論，大僧為可，惡比丘及沙彌為不可；或約處者，房舍為可，眾處不可；
【譯文】在實行的方法中，第一段文字。具備五種法條件的人，稱為「具備五德」。前四種是就內心修養而言，稱為「通德（普遍的德行）」，因為它通貫於一切事務；第五種則是就外在事務而言，稱為「別德（個別的德行）」，因為它是隨特定職務而各有局限。順應自己的私意也不結黨偏袒，所以稱為「不愛」；違逆自己心意也不心懷怨恨，所以稱為「不恚」；通達戒律教法而毫無疑慮，所以稱為「不怖」；能看清時機機變應對，所以稱為「不癡」。所謂知道哪些可以分配等等，如果就人而言，大僧比丘為可，惡性比丘及沙彌為不可；如果就處所而言，一般僧房為可，眾人共同的大堂則不可；

【1039-0002】資持記/05c_上四#21
【原文】更總為言，必須通解分法始終，方堪差舉。羯磨下，引法。可解。次科，初五德唱告。下明眾僧集物。隨己所有，並持入眾；唯除床榻臥具等。三中，初數知房舍。經營主者，或彼剏造，或復修治，任意選取，以賞勞績；〈鉢器篇〉云：營事比丘房成，與房住九十日一移等，餘廣如彼。
【譯文】若再總體而言，必須通盤理解分房法自始至終的程序，才能勝任並受推選擔任這項差事。「羯磨」以下，引述具體的作法，義理容易理解。下一個科判，首先由具備五德的僧人宣告大眾。下文說明僧眾集中物品的情形。隨自己名下所擁有的一應財物，都要帶出來交給大眾；唯獨除去了床榻與被褥等臥具。「三」字一段中，首先要清點查明房舍數量。所謂「經營主者」，是指或者由他最初開闢建造，或者由他出資整修維護的，可以隨其意願優先挑選，以犒賞其辛勞功績；〈鉢器篇〉記載：負責營造事務的比丘在僧房落成後，給予該房居住九十天然後輪換一次等，其餘詳情正如該處所載。

【1039-0003】資持記/05c_上四#22
【原文】後下，二依次分與。若有下，明人少房多，再三分之。故下，明更分無用，故令留置。問：既隨所樂，可取先所住處否？答：必取先住，還因分得，理應無過。然本教意，恐著住處；苟能遷徙，節己稱法，在人為之。若惡下，三明簡人。時下，四示嚴制。問答中，初難者。律制行食不得偏饒上座；
【譯文】「後」字以下，第二步是依長幼僧次分配給予僧人。「若有」以下，說明如果人少而房舍較多，便應當再次乃至三次予以分配。「故」字以下，說明如果再分下去也沒有實際用處，因此應當保留放置。有人問：既然可以隨其心願喜好，那麼可以挑選自己原先所住的舊房間嗎？回答說：如果執意要選原先住處，最後依然是透過合法分房而取得，在道理上應當沒有罪過。然而佛陀立教的根本初衷，就是唯恐人貪著住處；如果能夠主動遷徙換房，克制自己以合乎法度，這全在於修行者自身的修為。「若惡」以下，第三項說明簡別不合適的人選。「時」字以下，第四項顯示出嚴格的制約規範。在問答之中，第一個質疑者提出：戒律規定分配食物時不得偏袒厚待上座；

【1039-0004】資持記/05c_上四#23
【原文】不同分房，故用相並。答中，上二句明食味均通。下明房舍局定，二義反之，初明好惡已定。反上平融也。好惡可會。美好不同者，好中復簡，謂好相多別也。限下，二明時長，反上短促也。次問中。以現前僧物，好惡亦定；復是別屬，理應任選；而制參取，故躡為難。
【譯文】這與分房的規定不同，所以拿來相互比照問難。回答中，上兩句說明食物的滋味普遍均等；下文說明房舍的分配有其局限與固定，以兩種意義反駁前難：首先說明房舍的好壞優劣原本就已固定，反駁上文飲食的平等通融；好壞優劣容易理會。所謂美好程度不同，是在好房中再度細分，指其優良的特點各有許多差別。從「限」字以下，第二點說明分配居住的時間長久，反駁飲食時間的短促。在下一個問題中：發問者認為現前僧物的好壞優劣也是固定的，而且分配後也是歸個人個別所有，理應任憑個人挑選；然而戒律卻規定要以摸彩（抽籤）方式參取，所以順著前文提出質難。

【1039-0005】資持記/05c_上四#24
【原文】舊云：先以施物好惡相雜，然後書現前人名於籌上，使不見物者投之於上也。答中。現前者須通二種，如盜戒中。等分謂平等而分，此句反房不等也。通有一分者，以望未分，未成別屬，此句即反房非通有也。投策即擲籌，言之變耳。餘相中，《僧祇》三節，初明小眾可否。若房下，明重分。
【譯文】古時解釋說：先將布施的物品好壞混雜擺放，然後將現前僧人的名字寫在竹籌上，讓看不見物品的人將竹籌投擲在物品上面。在回答中指出：「現前僧物」必須通達兩種意義，如同盜戒當中所說。「等分」是指平等地分配，這句話是反對房舍的不可等分。「通有一分」，是因為在未分之前，尚未成為特定人的專屬物品，這句話也就是反對房舍並非人人普遍共同擁有的性質。「投策」就是擲籌抓鬮，只是用詞不同罷了。在其他事相中，《僧祇律》包含三節：第一節說明沙彌等小眾是否可以分受。若房舍過多以下，說明再次分配。

【1039-0006】資持記/05c_上四#25
【原文】若春下，明三時緩急。夏房專為治事故與。春冬更兼受用而與，故云具通二與。《四分》亦三，初明客來不移。同上可見。若分下，簡非處。若有下，明預定。律因諸比丘見阿練若好窟，念言當於此安居；後餘比丘見已，亦如是作念；至十六日共至，住處迮狹，佛聽先作相者住；
【譯文】「若春」以下，說明三時在分房上的寬緩與緊迫。夏季分配房舍專門是為了防護雨水與修治事務，所以才給予；春冬兩季則更兼具了實質受用而給予，所以稱為具足兼通兩種給予的意義。《四分律》也包含三點：第一點說明若有客僧前來則不予移換，這點與上文相同，容易明白。「若分」以下，簡別哪些不是合適的處所。「若有」以下，說明預先劃定。律中因為諸比丘看見阿練若處有極好的山窟，心中念著說：我應當在這裡安居；後來其餘比丘見到了，心中也是這樣想；到了四月十六日大家一同前來，發現住處過於窄小，佛陀便聽許先留下標記者居住；

【1039-0007】資持記/05c_上四#26
【原文】即書云某甲欲於此安居。詳此，似非分房；應是山間嵓窟庵舍孤立之處，可自標定；必是僧坊，自行分法，理無預占。滅名去者，恐妨後人故。滅即除也。三明作法，設教中。標云四種，對首本制，常途所行；餘三緣開，心念開無人，忘成開非心，及界開奔赴。對首中，前安居。
【譯文】也就是寫字註明「某甲想要在此安居」。詳細推究此事，似乎並非一般的僧坊分房；應當是指山野深谷巖窟孤立的庵舍之處，才可以自行標定；如果是僧眾的常住僧坊，自然有其分房的常規作法，在道理上是不容許預先霸占的。所謂「消除姓名而離去」，是唯恐妨礙了後面來到的人。滅就是抹除的意思。第三科說明具體作法。在設立教法之中，標題列出四種：面對面作法是根本制定，是一般常規所通行的；其餘三種是隨因緣開許的：心念作法是開許在沒有他人的時候，忘記成夏是開許在無心遺忘之時，跨入界內則是開許給急迫奔赴的人。在「面對面（對首）」法中，首先是前安居。

【1039-0008】資持記/05c_上四#27
【原文】標云通諸界者，謂作法自然；或聚落蘭若，或僧坊俗舍，並通安居故。今下，標今立法。出法中，初具儀。二示法。準疏分八。初句告所依，證無餘想也；我某甲者，簡非他也；依某處者，定所標也；前者簡中後也；三月者，通餘一月為開制也；夏者，除春冬也；安居，簡遊行也；
【譯文】標題所說的「通於各類結界」，是指自然界或作法界；無論是村落聚落、阿蘭若荒野，或是寺院僧坊、俗人家舍，全都可以通達安居的緣故。「今」字以下，標明現在確立的作法。在出示作法之中，第一步要具足威儀。第二步宣示詞句。依照《業疏》可劃分為八個要點：第一句是告知所依對象，以證明自己沒有其他異想雜念；「我某甲」，是明確自己而簡除他人；「依某處」，是確定所標立的處所；「前」，是簡除中安居與後安居；「三月」，是通融其餘一個月作為開許或限制的依據；「夏」，是排除春季與冬季；「安居」，是排除外出遊行；
