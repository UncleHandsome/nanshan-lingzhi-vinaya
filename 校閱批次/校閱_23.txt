# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【23-0001】02_戒疏/01a_卷一上之一#17
【原文】【記】序文大略，歎教敘宗。傳弘著撰，意令觀序識其來緣。歎教體中，初句，標所釋本文。「斯乃」下二句，正歎。言「萬行」等者，謂此戒文通收善惡事法，對惡事惡法以明止行，對善事善法而成作行。止行斷惡，作行修善，行雖多途，無出斯二。又解，約境而言，戒則無量，且列二百五十為持犯綱領，則知戒文攝一切相。又復通及化教諸行，若非此戒，行檀不淨，進忍徒苦，禪智不生。萬行不出六度，六度必戒為本。此文詮戒，故知總攝，下云「世出世行，並依承之」，《鈔》云「發趣萬行，戒為宗主」，並同此意。「關」即是門，「鍵」謂鏁鑰，城邑宅舍，用此為要，可喻止作「統」收「萬行」。言「三乘」者，一切聖人無不由戒以為初門，故喻「階轍」。「階」謂階梯，「轍」謂車跡。
【譯文】【記文】序文的大意，在於讚歎教法並敘述宗旨。傳承弘揚與撰述發揮，意在讓觀閱序文之人明白其源流因由。在讚歎教體這部分，第一句標示出所解釋的本文。「斯乃」往下的兩句話，則是正式讚歎。所說的「萬行」等詞，是指這部戒本經文普遍涵蓋善法與惡法等事，面對惡事惡法以闡明止持之行，面對善事善法以成就作持之行。止行在於斷除惡業，作行在於修持善業，修行途徑雖然繁多，終究不出這兩大類。另一種解釋，若就所對境界而言，戒律雖然無量，姑且列出二百五十條作為持犯的大綱，由此可知戒律經文涵蓋了一切境界相狀。而且進一步通貫到一切化教的修行，倘若缺乏這部戒律，行持布施則不純淨，精進與忍辱將徒勞受苦，禪定與智慧亦無從生起。萬行終究不出六度，而六度必定以持戒為根本。本文專門詮釋戒法，因此可知總攝了一切，下文說「世間與出世間的一切行法，皆以此為依憑乘載」，《行事鈔》亦說「發起奔赴一切行門，以戒律為宗綱主宰」，都是相同的意趣。「關」就是門閂，「鍵」就是鎖鑰，城池聚落與宅院房舍，都以此為關鍵樞紐，正好用以比喻止持與作持兩門「統括」包攬了「萬行」。所說的「三乘」，指的是一切聖人無不以戒律作為入門第一道門檻，因此比喻為「階轍」。「階」是指階梯，「轍」是指車輪行經的軌跡。

【23-0003】02_戒疏/01a_卷一上之一#19
【原文】【記】答：「若據菩薩，別有頓戒。今以二意通之：一者，出家菩薩，必須次第，先小後大；二者，《勝鬘》、《智論》謂毗尼藏即大乘學。由斯二途，故指今戒為佛階梯，於義無失。又解，《梵網》大戒不兼於小，有部小乘不通於大，唯此四分兼前通後，故言『三乘』也。」
【譯文】【記文】答：「若單就大乘菩薩而言，另有頓入的菩薩戒。如今以兩層意理來融通它：第一，出家菩薩修行必須依循次第，先受持小乘戒而後進修大乘戒；第二，《勝鬘經》、《大智度論》皆認為律藏本來即是大乘修學的內容。基於這兩種道理，所以指出眼前的這部戒律是成佛的階梯，在法義上完全沒有差失。另一種解釋，《梵網經》的大乘戒不兼攝小乘戒，說一切有部的小乘戒亦不通融於大乘，唯有這部《四分律》能兼攝先前的小乘、貫通後續的大乘，所以稱作通於『三乘』。」

【23-0007】02_戒疏/01a_卷一上之一#23
【原文】【記】初段「夢氎」者，下引《大集》，有一長者夢氎一段，後分為五，佛告長者「我滅度後有諸弟子，分五部」等。「告」，示。「徵」，驗也。「喻金」者，《律》因拘睒彌比丘𩰖諍，來至舍衛，諸優婆塞問佛：「當云何布施？」佛言：「應分作二分，此亦是僧，彼亦是僧。如彼金杖，分為二分，二俱是金。」又《因緣經》云：「頻毗娑羅王，夢一金杖斬十八段，怖而問佛，佛言：『我滅度後一百餘年，有阿輸迦王威加瞻部。時苾芻眾散分十八，趣解脫門，其致一也。』」上喻本同後別，下喻雖異還同。以金、㲲體同，裂析則異。故此二句，「機」、「教」互顯。
【譯文】【記文】第一段所說的「夢氎」，下文引述《大集經》，記載有一位長者夢見一塊細白布，後來被撕裂成了五段，佛陀告訴長者說「我滅度後將有諸多弟子，分裂成為五個部派」等內容。「告」是開示，「徵」是徵兆驗證。所說的「喻金」，是指《律》中記載因拘睒彌國的比丘發生爭端，眾人來到舍衛城，諸優婆塞居士向佛請問：「我們應當如何布施？」佛陀說：「應當分成兩份布施，這一邊也是僧眾，那一邊也是僧眾。猶如那根金杖，雖然折斷分成兩截，兩段依然皆是真金。」又《因緣經》說：「頻毗娑羅王夢見一根金杖斷成十八截，驚駭恐懼而向佛請問，佛陀說：『我滅度後一百多年，會有阿育王威德名震閻浮提洲。那時比丘僧眾將離散分化為十八個部派，但眾人奔赴解脫之門，其最終的歸宿是一致的。』」前面的譬喻是本體相同而其後顯現差異，後面的譬喻是相狀雖異而本質依舊相同。因為黃金與細布的本質完全相同，撕開折斷後的形體則各有相異。因此這兩句話，分別從「根機」與「教法」兩方面交互彰顯其理。

【23-0009】02_戒疏/01a_卷一上之一#25
【原文】【記】初段，四位分部，廣如下疏。「隨務」者，約所詮之事，聞見不同；「任緣」者，據派別之由，時緣不一。然此二途，皆通四位，文中各對，義必相收。宗部既殊，可明事異。言「任緣」者，二部因簡眾純雜，五部由師無所判。其十八部，《異執論》中，育王集會，論法成乖。五百部者，有言無相，教雖不敘，起必從緣。
【譯文】【記文】第一段，四種位階的部派分立，詳細內容如後文疏解所載。「隨務」是就律典所詮釋的作持事務而言，由於傳承聽聞與見解互有差異；「任緣」是依據部派分裂的原由，各時代的緣起條件並不一致。然而這兩種情況，都通貫於四個位階的部派劃分，經文中雖然各自對應，其法義必定相互涵蓋。部派宗旨既然不同，自然顯明各部行事作法相異。所說的「任緣」，兩部派之分是因為甄別僧團純淨與駁雜，五部派是由於各部論師對戒法未有一致判準。那十八個部派，在《異執論》中提到，是因阿育王召集大會，論究佛法產生歧見而致。至於五百個部派，歷來有此傳說但未見具體部派名稱，教典雖然未曾詳載，但其興起必定順隨因緣而生。

【23-0010】02_戒疏/01a_卷一上之一#26
【原文】【記】歎人中。「孚」，信也。教由聲說，故云「聲教」。「真空」者，即滅諦涅槃，非偽故「真」，離相故「空」。以諸部師多是無學，此二句明信教證空，歎其果德。「導」猶深也。「化源」者，即如來設化之本。「明理性」者，空有雖殊，無非化物，見理悟道。理性祇是真空，但上取自證，下明化物，餘如後辨。此二句明達化顯理，歎其明解。
【譯文】【記文】讚歎傳法人這部分。「孚」是信奉的意思。教化本由音聲宣說而立，因此稱作「聲教」。「真空」即是滅諦涅槃之理，不是虛妄矯飾所以稱作「真」，遠離一切妄相執著所以稱作「空」。因為各部派的祖師大多是阿羅漢無學果位，這兩句話說明他們深信言教、證悟空性，旨在讚歎他們的果地功德。「導」猶如深入之意。「化源」就是如來施設教化的根本基底。「明理性」是指空宗與有宗的觀點雖然有別，無非都是為了化導眾生、使之見理悟道。理體之性本就是真空，只是上句偏指自身的內證，下句偏指對外的化導眾生，其餘細節在後文辨明。這兩句話說明通達教化源頭、顯揚真如理性，旨在讚歎他們對法義的明徹通達。

【23-0011】02_戒疏/01a_卷一上之一#27
【原文】【記】顯益中，上二句明攝生益，下二句明住持益。「乘」能運載，「津」是水濟。載出家眾，度生死津，故曰「乘津」。「燾」亦訓「覆」，今取「載」義，《禮》云「如天地，無不覆燾」是也。「萌」謂草木始芽，今取蒙昧，或復眾多，以喻萬類也。上句局出家，下句通道俗。或可「群萌」語通，義該六道。以眾聖弘揚，無往不利，豈唯七眾獨受其賜？「開務」即各布行教，「攝持」謂匡正佛法。「允符玄旨」，二義釋之：初約開教雖殊，皆契佛意，所被之眾，無不悟道；又解，出世弘持，並合懸記。「允」，順。「符」，合也。
【譯文】【記文】彰顯教化利益這部分，上面兩句說明攝受度化眾生的利益，下面兩句說明住持正法的功德。「乘」能夠運載，「津」是渡口水津。運載出家僧眾，度過生死的渡口，因此說「乘津」。「燾」字亦訓詁為「覆」，此處取其「乘載覆育」之義，《禮記》說「如同天地一般，無所不覆載包容」即是此意。「萌」原指草木最初破土的嫩芽，此處取其蒙昧無知、或是數量極為繁多的意思，以此比喻世間萬類眾生。上句局限於出家大眾，下句通貫於道俗眾人。或者可以說，「群萌」語意甚廣，義理涵蓋六道眾生。因為歷代聖賢弘揚流通此道，所到之處無不利澤廣施，難道只有出家在家七眾弟子獨得其利益嗎？「開務」即是各自宣布鋪展行持的教規，「攝持」是指整飭匡正佛教法脈。「允符玄旨」，可用兩種義理來解釋：第一，就各宗開演教門雖然互有殊異而言，其實全都契合佛陀本意，凡所蒙受教化的眾生，無一不因此悟道；另一種解釋，歷代祖師出世弘揚住持，完全符合佛陀當年的懸記預言。「允」是順隨，「符」是契合的意思。

【23-0014】02_戒疏/01a_卷一上之一#30
【原文】【記】「斯人」下，釋久傳之意，有二：初約人法以明；二、「自」下，約分部以顯。初中，「三機」者，上機即四依、頭陀等；中機謂百一供身、二房、二請等；下機如諸長、淨地、鉢器、皮革、諸重物等。自有通三機者，如三衣、鉢具、篇聚等制。良以教本對機而設，約機考教，得其源矣。「殷」謂殷重，「鑒」即訓視，「兩典」謂大小二乘。此二句，美其深達也。「權實」者，一往且約大小而分，此明《四分》通大之意。心為業主，識對諸塵，沓婆迴心，施生成佛。逈異有宗，深通實道。但教局小乘，未容直顯故也。「名」謂能詮名句，「理」謂所詮義趣。「統收」之言，該乎一化。「時賓」謂當時學眾。此四句，明所集教體。「韋」，熟皮也，古者用編簡牘。如孔子讀《易》，韋編三絕，今借彼意，以明古今披覽無厭。此二句，釋成久傳之意。
【譯文】【記文】「斯人」以下，解釋此律得以長久傳承的原因，共有兩層意涵：第一先就結集者與其教法來闡述；第二自「自」字以下，從部派分化的層面來顯明。在第一層中，所謂的「三機」，上根之機是指嚴持「四依」、修持「頭陀」等苦行者；中根之機是指獲准蓄持「百一供身物」、開造「有主無主二類僧房」、接受「僧請別請二種受請」等律儀；下根之機如同開許蓄積諸多長物、劃設淨地、蓄持各類鉢具皮革及各類貴重物品等。也有通於三種根機的通規，如同受持三衣、鉢具、五篇七聚等戒律制定。確實是因為教法原為對應根機而設立，依照根機深考教理，才掌握到了它的源頭。「殷」指殷實深重，「鑒」即訓詁為觀照審視，「兩典」指大乘與小乘二藏經典。這兩句話，讚美結集律師理解通達極其深遠。「權實」二字，暫且從大小乘的分野來劃分，此處用以說明《四分律》通貫大乘的深意。例如主張以心識作為造業的主導，六識對應種種塵境，沓婆尊者迴小向大、生起發心，以及為眾生布施終成佛道等內容。這與阿毗達磨有部等宗派迥然有別，極深地相通於大乘實教之理。只是教法形式上仍局限於小乘律部，未能直接顯露宣說罷了。「名」指能詮顯教理的名言章句，「理」指所詮顯的教化意趣。「統收」這句話，意思是總括涵蓋了佛陀一代教化。「時賓」是指當時依止參學的僧眾。這四句話，說明了所結集律藏的教體特色。「韋」是熟皮，古時用以編綴竹簡。如同孔子讀《周易》，多次翻閱致使穿簡的牛皮繩斷裂三次，此處借用那個典故，以表明古往今來的學人反覆翻閱研讀、永無厭足。這兩句話，解釋說明了歷經久遠仍得傳承的因由。
