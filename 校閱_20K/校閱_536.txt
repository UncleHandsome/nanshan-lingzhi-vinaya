# 校閱材料　第536檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【536-0001】資持記/07c_中一下#38
【原文】僧物雖多，四種攝盡。初屬處永定，不可分判，故雙疊之；二雖局處，隨人分食，故云十方；第三人局現數，物據即分，故雙云也；四物雖即分，人無定限；羯磨遮約，故名十方。約名定體，物分四別，如下自明。別釋，常住中，初簡物體。疏加米麵，準五穀醬菜饌食眾物，皆此所攝。以下，斷犯。
【譯文】僧物雖然種類繁多，四種類別就可以全部收攝窮盡。第一種歸屬之處永遠固定，不可分割分配，所以用重複疊加的名稱；第二種雖然局限在特定處所，但隨每個人分發受用，所以稱為「十方」；第三種人數局限在現前人數，物資依據當下立即分發，所以也是疊加命名；第四種物資雖然立即分發，但享受的人數沒有界限；透過羯磨僧事予以遮止約束，所以稱為十方僧物。依據名稱來確定體質，物資分為四種差別，正如後文自己所明示。在個別解釋常住常住物中，首先簡別物體。戒疏中增加了米麵，依此類推五穀、醬菜、飲食等各種物品，都屬於此類所收攝。從「以下」開始，判定犯戒。

【536-0002】資持記/07c_中一下#39
【原文】如論，即《善見》。引《僧祇》證。言縱一切集者，恐謂當界不可分，遍十方，集則可分故。二十方中，初簡體。疏云：如飯餅等現熟之物，本擬十方，作相同食，是也。有疑醫豉為熟物，判在十方者。今以意分，不問生熟；但使未入當日供僧限者，並歸前攝；如貯畜鹽醬，是常住常住；
【譯文】正如論典所說，即是《善見律毗婆沙》。引用《摩訶僧祇律》作證明。所謂縱使十方大眾全部聚集，是唯恐有人以為當界不能分發，若是全十方僧眾聚集就可以分發的緣故。第二種十方常住物中，首先簡別其體質。戒疏說：例如米飯、餅類等現前已煮熟之物，本來就是準備給十方僧眾，作為共同飲食之用，指的就是這個。有人懷疑藥用的豆豉屬於熟物，判定在十方常住之中。如今以意理來劃分，不過問是生是熟；只要是尚未列入當天供養僧眾配額之物，全都歸入前一類常住常住物所收攝；例如儲存積蓄的鹽與醬，屬於常住常住物；

【536-0003】資持記/07c_中一下#40
【原文】取入日用，即十方常住。體下，二斷犯。同共者，主客同心，無掌執故。得輕者，即偷蘭罪；疏云：以僧分業無滿五故。問：常住常住，亦無滿五，何以重耶？答：分不分異，重輕致別。引示中，初科，《僧祇》。長食，非己分者。《善見》。五賊，並謂竊法求利故；
【譯文】若提取出來列入每日飲食所用，就是十方常住物。從「體下」開始，第二是判定犯戒。所謂「同共」，是指主人與客人同心，沒有專門的值掌看守之人。獲得輕罪，就是偷蘭遮罪；戒疏說：因為僧眾分配的份額中沒有滿五錢的緣故。提問說：常住常住物也沒有滿五錢，為何會結成重罪呢？回答說：物資是否可以分發的情況不同，所以導致了罪責輕重的差別。在引導指示之中，第一科引用《摩訶僧祇律》。所謂「長食」，是指非屬自己分額之物。引用《善見律毗婆沙》。五種賊人，都是指藉由竊取佛法來謀求名利的人；

【536-0005】資持記/07c_中一下#42
【原文】後段犯重，注有主者，文標盜心故。《母論》，同故不引。不作相中。上下兩段，不顯罪名，注文並斷蘭者。以不打鐘，或結主掌，或通主客。次空寺中，顯是無主，亦由不作相犯；準必作相，理得啖之。三中。不出物相，疏云：如今諸俗，以供養僧，無問衣藥房具，並同現前僧也。文通二主。本主者，即本施主。
【譯文】後段判定犯重罪，注文標明「有主」者，是因為經文標示了存有盜心的緣故。《毘尼母論》內容相同所以不予引用。在不作羯磨表白的情形中。上下兩段都沒有明示具體罪名，注文全都判定為偷蘭遮罪。因為沒有鳴鐘告知大眾，或者依主管者結罪，或者通貫於主管與客僧共同結罪。其次在空寺之中，顯然是沒有主人，也是由於沒有作表白而構成犯戒；照理來說若是作了表白，道理上是可以食用的。第三種現前現前物中。經文沒有列出具體物相，戒疏說：如同現今的諸位俗人，用來供養僧眾，無論是衣物、藥品、房舍用具，全都等同於現前僧物。文字通貫於本主與護主二位主人。所謂本主，就是原本的施主。

【536-0007】資持記/07c_中一下#44
【原文】注斷犯夷，有人云：總望現僧，盜五成重；同前常住常住之倒。又云：現前百僧，須盜五百，方成滿五；減則得輕。問：秉羯磨已，即付五德；此同主掌，何不望結？答：此據出物正作法時，爾前必有知事看守，應從守護結重；後付五德，令為僧分；現物屬僧，即非掌護。若下，三明囑授。
【譯文】注文判定犯波羅夷重罪，有人說：總體對著現前的僧眾，盜取達到五錢便構成重罪；這犯了同前面常住常住物一樣的顛倒錯誤。又有人說：若是現前有一百位僧人，必須盜取五百錢，才能構成滿五錢之數；少於此數則得輕罪。提問：秉宣羯磨之後，隨即交付給五德僧人；這等同於有主掌守護之人，為何不對著他們結罪？回答：這是依據拿出物品正式作法的時候而言，在此之前必定有知事僧人看守，應當依據守護人來結重罪；後來交付給五德，是為了讓它分配給僧眾；現前的物品已經歸僧眾所有，那就已經不是個人掌管護持的狀態了。從「若下」開始，第三是說明囑託交付的情形。

【536-0008】資持記/07c_中一下#45
