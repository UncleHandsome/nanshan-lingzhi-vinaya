# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【407-0001】03_業疏/00_卷首#1
【原文】原夫平等法界，體性常遍，出之無方，入之無所，何來為始，何去為終？同一實際，非有非空。非空即真空，無惡不止焉；非有即妙有，無善不作焉。此之止作，名曰本性之尸羅，乃無為戒也。萬德悉備，豈易得而言哉！盖上自極聖，下逮至憃，孰有不具此萬德者耶？雖然，諸佛悟解之而開寂滅之樂土，眾生迷執之以制生死之苦域。於是我大牟尼，哀彼封執而令開解，亦與二戒，斷惡修善。此之止作，名曰受持之木叉，乃有為戒也。萬行悉備，曷可得而罄哉！倘剋論之，則有為之與無為，本自無別；本性之與受持，安得有二耶？然又律剖大小，戒判顯密，何也？謂以心殊麤妙，智異淺深故耳。所言大小、顯密，毗尼結集西竺，翻傳東夏。論師提要，明辨開制之分齊；釋家釣玄，沈研持犯之狀相。戒學之為急也，厥用心可見矣。良以雖曰萬行，攝盡二戒，可謂止作二持，則無量乘之宗轄也。顯其止持者，戒本也；明其作持者，羯磨也。暨唐南山徵照大師，佩《法華》開顯之戒印，持《涅槃》扶談之德瓶，弘通律教，以自為任，力撰《羯磨》、《戒本》二疏。先此，為學戒者述《行事鈔》，綜該二持，包括三行，三部大成，而立一家義矣。後宋靈芝大智律師，繼其家業，研究鑽極，虔䖍著記，以解大部。諒若遺書之於末學也，豈翅滿籝之兼金耶！譬如水火之於人用也，不可一日欠之；一家三部亦爾，奉戒之倫不可斯須去也。本朝傳律，討厥初基，則天平勝寶中，大師法孫龍興鑒真大律師，應請來遊，敕舘于東大寺。聖武上皇大悅，於盧遮那殿前建壇，上皇、天皇、太子等相次受菩薩戒。乃移戒壇于大殿西，而構戒壇院，諸傳戒等職一任真師，而賜號大和尚。自時創行羯磨受法，所以天下之僧徒奔波都會于茲，猶如百川之注巨海也。大和尚住持戒壇之僧坊，六更座菅，退隱於招提寺矣。中興乎泉涌正法國師、西大興正菩薩，秉戒盛行於海內矣。後起乎槙峰明忍律師。槙峰律法分出兩派：曰神鳳在泉南，曰青龍在河陽。本支併之，今三僧坊研講毗尼也，無忝前達矣。神鳳門中有禪龍大德者，專精不怠，珠圓月滿，世稱明戒，競所依止。日者來謂余曰：「宗門所學，三部本書，各記科文，三通別行。始涉之者，多病對閱。嚮有人就《事鈔》會入記于本文之下，系排科于其上，此寔足以救彼病矣。吾雖不敏，從事於斯，《業疏》一部亦方遂功，期欵梓之廣布遐邇，冀師助以序引。」余對之云：「稟賦斷無文思，豈敢得然諾耶？」竣拒彌責。竊式惟忖：近掛錫于戒壇，本誓在乎興律，詎諱詞拙，不揚斯善？聿敘於卷首，聊以讚厥功云。
【譯文】探究本原，平等的法界體性恆常遍在，它顯現出來沒有一定的方向，隱沒進去也沒有固定的處所，從何處來作為開始？到何處去作為終結？同歸於一個真如實際，非有非空。非空即是真空，沒有惡法不予止息；非有即是妙有，沒有善法不予奉行。這種「止」與「作」，稱為「本性之尸羅（戒）」，也就是無為戒。它具備了一切萬德，哪裡是容易用言語說盡的呢！大抵上自極位的聖人，下至極愚蠢的凡夫，誰不具備這萬德呢？話雖如此，諸佛徹悟明了它，從而開闢了寂滅的淨土；眾生卻迷惘執著它，從而造成了生死的苦海領域。於是我們偉大的釋迦牟尼佛，哀憐眾生的偏執不悟而令其開解，也給予了止與作這二戒，用以斷惡修善。這種「止」與「作」，稱為「受持之木叉（別解脫）」，是有為戒。具備一切萬行，哪裡能夠說得窮盡呢！如果嚴格論究，那麼有為與無為本來就沒有差別，本性戒與受持戒又哪裡會有兩種呢？然而律藏中又區分大乘與小乘，戒法又判明顯教與密教，這是為什麼呢？是因為眾生之心有粗糙與微妙的差異，智慧有淺顯與深奧的不同罷了。 所說的大乘與小乘、顯教與密教之戒，毗尼（律藏）在西印度結集，翻譯流傳到東土中華。論師提綱挈領，明辨開緣與制約的界限分寸；解釋之師探尋玄微，深研持戒與犯戒的相狀與情態。戒學是如此緊要迫切，先賢們的用心由此可見。確實是因為雖然說有萬種行持，卻全部收攝於止持與作持這二戒之中，可以說止持與作持兩門，乃是一切無量乘教的根本樞紐。彰顯止持的，是〈戒本〉；闡明作持的，是〈羯磨〉。 到了唐代，南山徵照大師（道宣律師）佩帶《法華經》開顯之戒印，手持《涅槃經》扶談之德瓶，以弘揚通達律教為己任，竭力撰寫了《羯磨疏》與《戒本疏》二部註疏。在此之前，他為學戒之人撰述了《行事鈔》，總括包攬二持，涵蓋攝受了三行，三部大作圓滿成就，從而樹立了南山一家之宗義。後來宋代的靈芝大智律師（元照），繼承南山家業，深入鑽研窮極幽奧，虔敬嚴謹地著述記文，用以解釋南山大部著作。這遺留給後學的著述，哪裡只是滿筐的黃金所能比擬的呢！就像水與火對於人類的生活一樣，一天也不能缺少；南山一家的三部大作也是如此，奉持戒律的人一刻也不能離開它們。 我國（日本）流傳律宗，追究其最初的根基，是在天平勝寶年間，南山大師的法孫龍興寺鑒真大律師應請前來東瀛，朝廷下敕安置在東大寺住宿。聖武上皇大為歡喜，在盧遮那大佛殿前築起戒壇，上皇、天皇、太子等相繼受菩薩戒。隨後將戒壇移至大殿之西，修建了戒壇院，凡是傳戒等職任全部委託鑒真大師，並賜予「大和尚」的封號。自此開始推行羯磨受戒之法，所以全日本的僧徒奔波匯聚於此，就如同百川注入大海一般。大和尚住持戒壇之僧坊，歷經六年更替席位，之後退隱於唐招提寺。 後來有泉涌寺的俊芿正法國師、西大寺的叡尊興正菩薩振興中興，持戒之風在海內盛行。其後又有槙峰的明忍律師崛起。槙峰一派的律法分出兩派：一是泉南的神鳳派，一是河陽的青龍派。本支與分支合在一起，如今共有三處僧坊研習講授毗尼，無愧於前輩先達。 神鳳門下有位禪龍大德，專精修學毫不懈怠，德行如珠圓月滿，世人稱讚其戒行精明，眾人競相前去依止。日前他來對我說：「本宗所學的，有南山三部原書，每一部皆有本書、記文、科文三種文本各自獨立單行。剛開始涉獵的人，多半苦於相互對照翻閱。以往有人將《行事鈔》的記文會編編入本文之下，並把科判排系在上面，這確實足以補救那種弊病。我雖然資質魯鈍，也從事於這項工作，整部《業疏》剛好完成了會編，期望刻版印刷以廣泛流布遠近，希望法師您能賜予序文引言相助。」我回答他說：「我生來毫無文章才思，哪裡敢承諾答應呢？」但我越是堅決推辭，他越是督促懇請。我私下思量：近期駐錫於戒壇，本來的誓願就在於振興律學，豈能因顧忌文筆拙劣，而不去表彰這樣的善行呢？於是提筆在卷首作序，姑且藉此讚揚他的功德。

【407-0004】03_業疏/00_卷首#4
【原文】甞聞毗尼藏也者，佛法壽命也。毗尼藏住，則佛法方住。故生善滅惡，羯磨以為宗；斷惑證理，木叉以為本。是以生善之大，莫過乎受體焉；滅惡之大，莫高乎懺重焉。羯磨為德，其盛矣哉！必過、未及現在人行之而證覺位，可謂渡海之舟航、登樓之梯隥者矣。且夫自佛日西隱，毗尼東漸而後，機成時至，逮乎我祖曾成如來使，出興于赤縣，撰戒業行事之疏鈔，著教誡輕重之儀文，反光前代。是以法雲重布於震旦，玉毫再暉於東域。故三果梵僧讚嘆曰：「自佛滅後，像法住世，興發毗尼，唯師一人而已。」然則普天之下，不可以無此師焉；率土之濵，不可以無此書焉。爾後足以行止作之事，從事於斯者，豈可不勉勵耶？高弟大慈律師親從以受密誨，鄭重傳持，引祖之所甞示者，乃為鈔記，以標指外之月。雖取名當世，而辭質義玄，尚未易通曉。故曇勝、融濟等諸大律師相競撰之記者，凡六十家焉。竝漫引費詞，間亦混魚魯，無曾說得宗要者。取其辭極理盡者，則會正為最；及大智一出，則棄之而弗取。但痛行事之尚隱，悲迷方之失指，不欲空搆游辭，妄盈緗帙，但宣持犯之正義，玅布八品之方軌，釋得緊要，決通凝滯。玉麈一揮，先斥會正，其餘者望風而伏從，實為羣記之魁首也。然至戒業二疏，鮮為之記者。唯有允師雖撰次之記，而曲證勉引，妄逞胸臆，行事反隱也。唯有今記，言寡旨深，無片言隻字未甞有所本，其止以美其作。斯著所益良多，足以為龜鏡也。斯乃芝祖之所以有功于止作之二持，而揭毗尼於不墜也，其功豈易言哉！所貴惟疏，所寶惟記，未有舍此而能達止作之奧者也。如何閱之者之不之察也？餘竊謂三本異卷者，右索左搜而難輙窺焉。故今慨然發志，以欲合刻疏記，使學者隨需而得之。是亦欲起張正法綱紀，使若僧若尼有志于毗尼之學者有增益之微意也。遂繡于梓，以廣乎世，因敘其始末，以弁諸篇端云
【譯文】曾聽聞律藏乃是佛法的壽命。律藏住世，佛法才能住世。因此，生長善法、息滅惡法，以羯磨為宗趣；斷除惑業、證悟真理，以木叉（別解脫戒）為根本。因此，生善的盛大，莫過於領納戒體；滅惡的重大，莫過於懺除重罪。羯磨的功德，真是盛大啊！過去、未來以及現在的人，必定是遵行它才能證得覺悟果位，真可謂是渡過苦海的舟船、登上高樓的梯蹬啊。 況且自從佛陀慧日隱落西方，律法漸漸東傳之後，根機成熟、時節到來，直到我南山初祖（道宣律師）曾親受如來囑託擔當使者，降生興起於中華赤縣，撰寫了《戒疏》、《業疏》、《行事鈔》，編著了教誡弟子、分別輕重犯相的儀軌文字，光芒遠遠掩映前代。因此，佛法的慈雲重新密布於震旦，佛陀的玉毫金光再次照耀於東方。所以證得三果的印度梵僧曾讚歎說：「自從佛陀滅度之後，像法住世以來，振興闡發律學的，唯有道宣律師一人而已。」既然如此，普天之下不可以沒有這位祖師；四海之內，不可以沒有這些著作。從此以後，凡是足以推行止持與作持之事、致力於律學修持的人，豈可不奮勉自勵呢？ 高足弟子大慈律師親自隨侍而受深密教誨，鄭重傳持，引述初祖昔日的開示，撰寫了《鈔記》，用來指示指頭之外的明月。雖然在當時名重一時，但因文辭質樸、義理玄深，仍不容易徹底通達明了。因此曇勝、融濟等各位大律師競相撰寫記文，共有六十家之多。這些著作全都漫泛引證、詞句冗繁，其間也難免魚魯混淆（文字訛誤），從未有人能真正切中宗趣要旨。若取其中文辭窮極、義理詳盡的，則以《會正記》為最上；但到了大智律師（元照）出世，就屏棄它而不再採用。《資持記》只是痛惜修行行持之法依然晦暗隱晦，悲憫迷失方向的人失去指南，不願憑空構設浮詞贅語，徒然塞滿書卷緗帙，而是一心宣暢持犯的正義，巧妙鋪陳〈八品〉的軌則，解釋得切中緊要，疏決融通了種種凝滯。玉麈塵尾一揮，首先斥駁《會正記》，其餘諸家望風歸附順從，實在是群記之中的冠冕魁首。 然而對於《戒疏》與《業疏》二部註疏，卻極少有人為它們作記。唯有允堪律師雖然編撰了記文，卻曲解引證、牽強附會，妄自抒發胸中所思，反而使律行事業更為晦暗隱蔽。唯有大智律師這部《業疏記》（濟緣記），文字簡省而義理深遠，沒有隻言片字不具備出處依據，其止持之解恰恰用以成全其作持之法。這部著述利益極大，足以作為楷模借鑑（龜鏡）。這正是靈芝元照祖師對止持與作持這二持具有豐功偉績，將毗尼高高舉起使其不致墜沒的原因，他的功德哪裡是能輕易說盡的呢！所尊貴的唯有《疏》，所珍寶的唯有《記》，絕沒有捨棄它們而能通達止持與作持奧祕的人。為何閱讀的人卻不細加察覺呢？ 我私下以為，如果疏與記分屬三部不同的卷軸，左右翻檢搜尋，難以隨時窺見全貌。所以如今慷慨立下宏願，想要將《疏》與《記》合版刻印，使研學者隨其需要便能一目了然地獲取。這也是為了整頓弘揚正法綱紀，使有志於研習律學的比丘、比丘尼能夠獲得增益的微薄心意。於是將其雕刻付梓，以廣泛流傳世間，因而敘述這段始末，作為全書篇首的序言。

【原文】僧以眾為名，眾以和為義。良以情生性昧，行別事乖，由此隨流，莫知究本。所以歸一師之氏族，等三聖之容儀；其為德也，戒見利以齊均；其為用也，身口意而一致。爭紛既息，我倒斯平，可使性顯情忘、返流復本者矣。且夫陰陽育物，非斯而萬物不成；禮樂治民，舍此而四民不立。所謂天時地利，不如人和；先王之道，用斯為美。矧乃發揮佛化，綱紀僧宗，建滅惡生善之緣，闢超凡趣聖之路，唯茲勝法，備此大功。爰自玉毫收彩於西乾，貝葉流津於東夏。微言殆絕，異集繁興。賴我聖師，慨茲凡庶，知時舉要，纂八法以成文；索隱鉤深，闡四緣而作疏。忝霑微善，獲迨遣音，竭慮研幾，何啻於韋編三絕；隨聞著錄，敢遵於墨印四求。庶令垂裕後昆，豈謂反光前代。使僧海還同於一味，祖燈分照於無竆，劫石可消，願言曷既。勉夫來學，無怠流通
【譯文】僧伽以「眾」為名，眾以「和合」為義。確實是因為眾生隨情妄動而使真性昏昧，行為有別、事理相乖，由此隨順生死流轉，不知探究本源。所以應當同歸於釋尊同一導師的氏族，齊等於佛及辟支佛、阿羅漢三聖的威儀容貌；其內在德行，在戒、見、利上完全平齊均等；其外在作用，在身、口、意上完全和合一致。紛爭既然平息，我慢與顛倒也就隨之平復，由此可使本性顯發、妄情消泯、逆生死流而復歸心性本源。 再者，陰陽化育萬物，若無此和順則萬物不能生成；禮樂治理萬民，若捨棄和合則士農工商四民無法立足。所謂「天時不如地利，地利不如人和」；「先王之道，斯為美（和為貴）」。更何況是弘揚發揮佛陀的教化，整飭作為僧團的綱紀，建立滅惡生善的因緣，開闢超凡入聖的坦途，唯有這項殊勝的羯磨妙法，才具備這般弘大的功德。 自從佛陀的白毫金光隱沒於西印度，貝葉經卷的法乳流注到東土華夏。深奧微妙的言教幾乎斷絕，異端紛紜的撰集雜然並起。幸賴我們南山聖師（道宣律師），憐憫痛惜世間凡俗，洞察時宜而提挈綱要，纂集八種羯磨之法而成正文；探尋幽隱、鉤索精深，闡發四種成辦之緣而著述註疏。後學忝借宿世的微少善根，得以遭逢祖師遺留的德音，竭盡思慮研幾探微，其勤苦何止於讀《易》的韋編三絕；隨聞錄下師傳，不敢自專，謹遵四大教法之規矩。但願能為後世子孫垂留福澤，豈敢說是輝映超越前代。期使僧伽大海重歸一味和合，祖師慧燈展轉映照於無窮，劫石縱然磨滅消盡，弘誓宏願何嘗有窮竭之期！勉勵後來的學人，切莫懈怠，務必流通此法。
