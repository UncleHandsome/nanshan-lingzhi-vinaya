整體看，這批譯文方向大致正確、術語（篇、聚、方便、突吉羅等）也守得住，但有幾處**義理反轉**、**無據增字**與**體例不一致**的問題，建議修正。按輕重排列如下。

---

## 一、義理必須修正的

### 1. #120「非不別因」譯反了，且與 #121 記文自相矛盾（最嚴重）

原文：「及論成果，**非不別因**，即以此罪，名為方便。」
今譯：「…並非沒有**這別異的起因**，**因此**便將這前緣的罪過，也稱之為方便。」

問題：元照在 #121 明說「『非不別因』者，即下『近』中自有方便也」——意思是**果罪另有更切近的因（近方便）**，遠罪並不是它的直接因；只是就此遠罪仍得名「方便」。今譯把「別因」指回「這前緣之罪」，又用「因此」連成因果，恰好把疏意倒過來，也與下一則記文打架。

建議改譯：
> 至於論到果罪的成辦，並非沒有另外（更切近）的因——即下文「近方便」所說——只是仍就此前罪，稱之為「方便」。

### 2. #128「緣成果剋」譯成循環句

今譯：「前緣成就了後續的犯罪，就成了後面的違犯。」——前後兩句同義反覆，且「果剋」（果罪剋遂、成辦）沒有落實。
建議：**「助緣一旦成就，果罪便隨之剋遂成辦，於是構成後面的違犯。」**

### 3. #130「自覆露」的「露」字沒有交代

今譯只作「自己覆藏罪垢」，把「露」吞掉了。記文只牒「自覆」犯吉，可見是一個詞組，但「露」或指「覆藏而不發露」，或另指「露地（敷具、然火等）」輕罪，**建議回查《戒疏》原文／校本再定**，不宜逕行略去。
另：「引生後續的**大**罪」——「大」是增譯，後犯未必屬重篇，宜作「後面的犯罪」。

---

## 二、無據增字（#117）

* 原文只举單字「**必**」下、「**有**」下、「**今**」下，譯文卻擴成「**必觀**」「**有人**」「**今且**」。這三個詞在所引原文中並無根據，除非已核對前面疏文，否則應保留單字（「『必』字以下」），或注明所據疏文。
* 「故**持遮**之」譯成「所以持此回答**遮蔽化解**」語感偏了。「遮」是遮止、駁斥對方嫌略之議，不是「遮蔽」；「持」＝特地。建議：**「對方嫌所說太簡略，所以特地予以遮止。」**
* 「智度大海」的「智度」即般若波羅蜜，可略點一句，勝於泛譯「智慧的大海」。

## 三、術語與措辭

| 處 | 問題 | 建議 |
|---|---|---|
| 全部【疏】 | 一律譯「**義理疏文**說」，「義理」二字無來由 | 作「疏文說」或「《戒本疏》說」 |
| #118「四位」、#120「位分有五」 | 譯「品位」易與篇聚品第混淆 | 「四種位分（階段）」；#120 宜點明「五」即五篇（夷、殘、提、提舍、吉） |
| #118「通於篇聚」 | 「各篇與各聚」生硬 | 「通於五篇七聚一切罪類」 |
| #122「與盜作緣」 | 譯「為**盜戒**…作緣」 | 應是「盜**罪**」；戒≠罪 |
| #120「遠資前境」 | 「前面的事境」易讀成「時間在前之境」，與下句「後面的犯罪」扞格 | 「遙遠地資助於（後犯的）現前之境」 |
| #120「名體全隔」 | 「自體」用語怪 | 「罪名與罪體完全相隔（不同篇）」 |
| #125「初望根本」 | 「望向根本罪」太直譯 | 「先是就（觸、語）相對於根本淫罪（波羅夷）而言」 |
| #125「後得相觸」 | 「**相互**撫摸接觸」 | 「後進而與對方身體相觸」 |
| #125「支，流也」 | 「流派分流」重複 | 「『支』是支流、分支的意思」 |
| #126「初、二」 | 只譯「前兩篇的重大犯罪」 | 依記文明說「初篇波羅夷、第二篇僧殘（淫、觸）」 |
| #126「（與尼）坐」 | 括注只加在「坐」，但取衣、染、浣同樣對尼而制 | 統一加注或統一不加 |
| #129「受尼受女食」 | 「接受比丘尼或受女子之食」句法不順 | 「受（非親里）比丘尼之食、受女人之食」；「受女食」所指宜再核 |
| #129「眾學」 | 未標篇次 | 「第五篇眾學（突吉羅）」 |
| #129「後通上篇」 | 「通達擴大」語意浮泛 | 「後來牽連而通至上位重篇」 |
| #131「隨篇重輕」 | 「隨各篇輕重結罪」稍含混 | 「隨所教唆之罪所屬篇聚而定輕重」 |

另建議：「方便」首次出現（#118）時加一句短注——**成犯之前的加行、預備階段**——讀者較易進入。

## 四、標點體例

* #127：「作衣、坐」等是指「九十單墮 **。」** → 句號應在引號外：「九十單墮」**。**（與前句「三十捨墮」；不一致）

## 五、可直接採用的改譯示例

**#120**
> 所謂「遠」，是指雖相隔遙遠，卻能資助於後犯的現前之境，藉其勢而成就犯罪；兩事隔絕、心念各別，罪名與罪體完全相隔，所以稱為「遠」。至於論到果罪的成辦，並非沒有另外更切近的因（即下文「近方便」），只是仍就此前罪稱之為「方便」。今就這類過失，位分分為五種（即五篇）。

**#129**
> 第四篇提舍尼中的受（非親里）比丘尼食、受女人食，第五篇眾學中的入白衣舍等，都是先犯這些輕過，之後牽連而通至上位重篇。依種類收攝諸戒，尋檢即可了知。

**#128**
> 乃至第四篇、第五篇，也都按種類相互收攝；助緣成就、果罪剋遂，便構成後面的違犯。

---

**小結**：最需要改的是 #120「非不別因」（義理顛倒，且與 #121 衝突）、#128 循環譯、#130「露」字漏譯；其次是 #117 三個無據擴詞與「遮」的語感；其餘屬術語統一與標點問題。
