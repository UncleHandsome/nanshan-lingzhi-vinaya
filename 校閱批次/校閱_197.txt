# 校閱材料　第197檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【197-0001】資持記/13d_下一#64
【原文】須歷帳者，無論大小現不現物，皆須錄示；至僧集時，先令維那打槌披讀。加法中。五人已上，行法整足，故別明之。處判中，次科。注中。據律合牒六物。上文但云若衣非衣，蓋準《多論》，容不集故。彼云：三衣在餘處者，索來此賞；若此德不具，則隨彼分等。《母論》亦爾。
【譯文】必須登載帳冊，是因為無論大小、在場或不在場的物品，都必須詳細登錄揭示；等到僧眾集會時，先令維那敲擊槌木，宣讀帳目清冊。在「加行作法」中。有五人以上參與，羯磨行法整肅完足，所以特別加以闡明。在「處斷判定」中，下一科。註解中，根據律典原本應當逐一列舉六種隨身物。上文僅僅提及「若是衣服或非衣服」，大概是依照《薩婆多論》，容許物品不全數集中之故。該論說：如果三衣散落在其餘處所，索取到此處再來賞賜；如果這裏看病者的德行不具足，就隨順彼處的規定去分配等等。《毘尼母論》也有相同的規定。

【197-0002】資持記/13e_下一#1
【原文】判物中有三，先問有三，一問負債，二問囑授，三問同活。應令一人答其有無。次判輕重。如上分者，即應對僧逐物提示重輕之意，然後各著一處。三索送喪物。三唱還者，應先告僧若千件數津送亡者，此是看病者物，將替入法，應須還波；唱云：大德僧聽！
【譯文】辨別物品（判物）這部分包含三項程序。首先是詢問三件事：一是詢問是否有積欠債務，二是詢問是否曾有交代託付，三是詢問是否有同甘共苦共同生活的同修。僧團應指定一人來回答這些狀況的有或無。接著是辨別物品的輕重。按照先前分類的標準，應當面對僧眾逐一出示物品並說明輕重之意，然後分別放置在不同的地方。第三是索還用於辦理喪事的物品。三次唱告索還時，應先向僧眾稟告：「拿出若干件數的物品是用來料理亡者後事，這是屬於照料病人者的私物，先前暫時代替亡者之物納入僧物規範，如今理應歸還給他。」唱告詞為：「大德僧聽！」

【197-0003】資持記/13e_下一#2
【原文】僧今持此衣還某甲比丘。〔三說。〕若無，謂不將亡物送喪也。賞勞中，初科，前標合賞。今下，次辨須否，初斥時對問。以答具不具，二皆不便。俗所恥者，《論語．顏子》云：願無伐善。〔謂自稱己德。〕與下，顯今不須。律云：即引結說戒堂文，故云結不結也。
【譯文】僧眾現在拿這件衣物歸還給某甲比丘。」（此句重複宣說三次。）如果沒有這項手續，是指當初並未動用亡者遺物來料理喪事。在犒勞看護者（賞勞）的章節中，第一個小段落是先前標明理當給予犒賞。接著在「今下」的部分，則是辨析是否需要詢問對方。首先斥責當面訊問當時看護者的作法。因為無論回答具足看護之德或不具足，兩種回答都令人尷尬難堪。世俗之人所引以為恥的，就如《論語》中顏子所說：「希望自己不誇耀功勞。」（意思是不主動自稱有德行。）從「與下」開始，顯明現今不需要當面詢問。律典所說的內容，即是引用結定說戒堂的文句，因此才用是否要「結」來作比喻。

【197-0004】資持記/13e_下一#3
【原文】此明賞給由僧，不必須問。次科。上座告者，即獎飾之意。看病謙者，不自伐也。僧抑伏者，上座應云：此佛嚴制，不在辭遜；當受羯磨，便即互跪。羯磨中。四處牒緣皆不同者，由物不定，意令隨故，如前注中。後注從物，名相多少，尋文可知。次差人中，初科，前標示律文。今下，準用時事。
【譯文】這說明給予犒賞是由僧團自主決斷，並不一定要當面詢問對方。第二個小段落中，由上座長老宣告，這代表獎勵與讚許的意思。看護病人者表示謙讓，是不自我誇耀功德。僧眾予以勸解堅持，上座此時應當說：「這是佛陀制定的嚴格規範，不可一味推辭謙遜；應當接受羯磨法式。」看護者隨即互跪接受。在羯磨法之中，四處宣讀事由文句之所以各不相同，是因為所涉及的物品情況並不固定，用意是讓文句隨具體情況調整，就如同前面注文所述。後續的注文則是依據具體物品，其名稱相貌與數量多寡，查閱經文便可了知。接著在推派人選（差人）的內容中，第一個小段落先標明並出示律藏原文。在「今下」部分，則是依據實際情況彈性運用。

【197-0005】資持記/13e_下一#4
【原文】《注羯磨》云：有人存三番作法，此思文未了〔一差人，二付衣，三分次；律云持衣與一比丘，令白二分，然律即指付分一法，彼謂有二，故是未了。〕；亦有存二番法者〔一差人，二付分，古記謂是口差，今家即者，非也。〕：今鈔所用，即一番法者；以口差人，但作付分，故不作差法；
【譯文】《注羯磨》中提到：有人主張要經過三道作法程序，這是對律文思考得不夠透徹（第一是推派人選，第二是交付衣物，第三是分配順序；律典說將衣物交給一位比丘，令其作一白一羯磨（白二羯磨）來分配，然而律典所指的其實只是交付分配這一種作法，他們誤以為有兩套獨立程序，所以是不透徹）；也有人主張保留兩道程序（第一是推派人選，第二是交付分配，古代的註記認為推派是用口頭指定，並稱這就是今家行事鈔的做法，這種說法是不對的，因為今家實為一番法）。如今行事鈔所採用的，乃是單一一道程序的作法；這是因為由僧團口頭推派人選，只須施行交付分配的羯磨，因此不再另外舉行推派的羯磨法；

【197-0006】資持記/13e_下一#5
【原文】反上律文，故云違法。知事則本由公選，口差則亦顯眾和，故云通得。間既云違法，何不白二差之？答：律雖明制，不出法故。諸家所立，竝是意裁。今家不行，恐成專擅。〔作《行事策》者，亦妄出法；古記相㳂，雷同引用，都迷聖旨。
【譯文】這與前述的律文有所不同，所以才稱作與法相違。知事人員本來就是經由大眾公開推選，口頭指派人選也能彰顯大眾的和合，因此說兩者皆可行得通。有人詰問既然說與法相違，為何不用一白一羯磨（白二羯磨）來推派差請？回答是：律典雖然明確規定要推派，卻沒有給出具體的作法文詞。各家所創立的文句，全憑各自的心思裁量。我們本派之所以不推行，是擔心變成擅自專斷。（寫作《行事策》的人，也是妄自制定程序文句；古代註記相沿承襲，隨波逐流地引用，完全迷失了佛陀的聖意。

【197-0007】資持記/13e_下一#6
【原文】即《注羯磨》云：今準律文，具含付分二法，餘無故不出是也。若爾，違法即應有過。答：律既不出，非故不行。況知事口差，通和義顯，理應無過。次科，初總示。持律者即指五德。以瞻病德缺，及沙彌分法，不行賞勞；作分衣羯磨已，直爾處分；故令先知，方可作法。
【譯文】）這就是《注羯磨》所說的：如今依照律典文字，其內容已完整涵蓋交付與分配這兩重意涵，此外沒有別的法式，所以才不另外列出。如果真是這樣，與法相違豈不應當有過失？回答是：律典既然沒有明確寫出儀軌，便不是故意不去遵行。更何況知事人員經由口頭指派，體現了大眾通融和合的精神，在義理上自然應當判定為沒有過失。下一個小段落中，首先是總體開示。所謂精通戒律者，就是指具備五種德行的人。如果照料病人者的德行有所欠缺，以及在沙彌參與分配的情況下，都不實行犒賞看護的程序；在完成分衣羯磨之後，直接給予處置發落；因此必須讓這些執事者預先知曉，隨後方可如法操作。

【197-0008】資持記/13e_下一#7
【原文】多下，別釋，初釋具德。注中，上句明彼得分，普該十方故；下句顯此分賞，隨與少物故。三五肘外應白僧者，由是長物，不合持賞；復連法衣，不可截去；白僧和與，彼此通成。十下，次釋沙彌。前引《僧祇》，望入和尚；故是直分，沙彌自物。羯磨同僧，乃據《十誦》；意令準用，故此引之；

【197-0051】資持記/14a_下二#29
【原文】《涅槃》云：有六種味：一苦，二酢，三甘，四辛，五鹹，六淡時量中，初對味別簡。六味中，缺鹹淡二味。甘味中，甘草是盡形，蜜等即七日。酸中，果汁是非時。辛味中，薑椒等皆盡形。苦味不入時食，故唯在終身。次對七日總簡。以七日體別，同是可食，故除已外，一切名時。從下，顯示時義。
【譯文】《涅槃經》說：有六種滋味：一是苦，二是醋（酸），三是甘（甜），四是辛（辣），五是鹹，六是淡。在「時量」之中，首先對照不同滋味分別進行簡別。六味之中，缺少鹹味與淡味。在甘味之中，甘草是盡形壽藥，蜜等則是七日藥。酸味之中，果汁是非時漿。辛味之中，生薑花椒等都是盡形壽藥。苦味不列入日常正餐，所以唯獨屬於終身服用的藥。接著對照七日藥作總體簡別。因為七日藥體性不同，但同樣可以食用，所以除去七日藥之外，其餘一切皆稱為時藥。自「從」字以下，顯示時的定義。

【197-0052】資持記/14a_下二#30
【原文】若論時及盡形，皆通六味。但時藥微通辛苦，盡形少於甘肥，非時多是甘酸，七日唯局甘味，如是求之。更量者，日中受藥，以五更為限故。日夜各五時者，無論長短，但將一日分為五時，對夜五更。〔不可定約寅卯等時；以夜五更，亦不限此時故。
【譯文】若論時藥與盡形壽藥，兩者都通於六味。但時藥稍微通於辛辣與苦味，盡形壽藥則缺少甘甜與肥美，非時漿多是甘甜與酸味，七日藥則唯局限於甘甜之味，應當依此準則去探求。所謂「更量」，是指在白天受藥，以五更為時限的緣故。所謂「晝夜各分五時」，不論時間長短，只是將一天分為五個時段，對應夜晚的五更。（不可死板限定在寅時卯時等時辰，因為夜晚的五更也不局限於固定的鐘點。）

【197-0053】資持記/14a_下二#31
【原文】若準《僧祇》，晝夜三十須臾，即三須臾為一時，且據相等為言。〕至二更者，謂盡一更，交至二更，受法即謝。如是輪轉者，謂第二時受，即盡二更，至三更謝等。若約《四分》，但盡非時。今須依律。此下，簡濫。漬飯漿，即今之漿水也。大開者，望不制受，故得此名。《四分》下，會異。轉變中，初科。
【譯文】（若是依循《僧祇律》，一晝夜有三十個須臾，也就是三個須臾算為一個時段，這姑且是依相等的長度來說的。）所謂「至二更」，是指一更結束、交接到第二更時，所受之法的效力即告謝退。所謂「如是輪轉」，是指在第二個時辰受法，就一直延續到第二更結束、至第三更時效力謝退等。若依照《四分律》，則只延續到非時結束。如今必須依循本律。從「此」字以下，簡除混濫之物。漬飯漿，就是現今所說的漿水。所謂「大開」，是相對於沒有制定加受之法而言，所以得到這個名稱。從《四分律》以下，融會各律的差異。在「轉變」之中，這是第一科。

【197-0054】資持記/14a_下二#32
【原文】苦酒得飲者，準上無酒氣味。二中，且約四物，餘可類準。胡麻同肉者，亦通兩轉故。是知一物，或通四藥，或三或二，轉變不定，隨舉說之。相和中，不等有三，前明七日，初立義。由下，釋所以。如下，舉事。次若以下，明終身，即盡形異名。初立義。如下，示相。酥是七日，乳是時藥。
【譯文】苦酒可以飲用，是依照上述沒有酒的氣味來判定。在第二段中，暫且依四種物品為例，其餘可以類推。胡麻之所以等同於肉，也是因為通於兩種轉變的緣故。由此可知同一種物品，有時通於四種藥，有時通於三種或兩種，其轉變並不固定，隨所舉的事物而說明。在「相和」之中，藥力不等的有三種情形，前面說明七日藥，首先確立定義。從「由」字以下，解釋其原因。從「如」字以下，舉出事例。接著「若以」以下，說明終身藥，也就是盡形壽藥的別名。首先確立定義。從「如」字以下，顯示相貌。酥是七日藥，乳是時藥。

【197-0055】資持記/14a_下二#33
【原文】浸豆麥者，即用豆麥浸去其毒。後若以下，明時藥。可解。次科，唯據盡形為言，初立義。餘藥分者，即通四藥。如下，顯相。次明淨地，制意中，初總示，根器不同。若下，別明立教有異。初敘上根從制。分衛即乞食，《經音義》云：正言儐茶波多，此云團墮；言行乞食，團墮在鉢中也。
【譯文】所謂浸泡豆麥，就是用豆麥浸泡以拔除其毒性。最後「若以」以下，說明時藥，這很容易理解。下一科，唯獨依據盡形壽藥來說明，首先確立定義。所謂「餘藥分」，就是通於四種藥。從「如」字以下，顯露相貌。接著說明「淨地」，在制戒意旨中，首先總體提示眾生的根器各不相同。從「若」字以下，分別說明立教有所差異。首先敘述上根之人依循制戒。「分衛」就是乞食，《經音義》說：梵語正音為儐茶波多，此地譯為團墮；是說行乞食時，食物摶成一團團墮入缽中。
