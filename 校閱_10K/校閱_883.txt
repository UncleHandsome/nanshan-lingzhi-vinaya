# 校閱材料　第883檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【883-0001】資持記/01a_上一上#58
【原文】化相一種，局據佛世；住持一位，通被三時。功由戒力運載不絕，故如舟焉。何以然耶？由佛法二寶，並假僧弘；僧寶所存，非戒不立，如〈標宗〉中，順則三寶住持，違則覆滅正法。又如《華嚴》云：具足受持威儀教法，能令三寶不斷等。餘如後引。或可越度凡流，入三寶位，必須受戒，以合舟喻。
【譯文】化相三寶一種，只局限於佛世當時；住持三寶這一類位，則通被正法、像法、末法三個時期。三寶能延續流傳，全憑戒律的力量運載不絕，所以用「舟船」來作比喻。為什麼是這樣呢？因為佛寶與法寶二者，都必須仰賴僧寶來弘揚；而僧寶之所以能夠存續，如果沒有戒律就無從建立，正如〈標宗篇〉所說：「僧眾順從戒律則三寶長久住持，違背戒律則正法覆滅敗亡。」又如《華嚴經》說：「具足受持威儀教法，能使三寶種性不斷絕」等。其餘的教證在後文還會引述。或者也可以說：想要超越度脫凡俗之流，證入三寶之位，必須經過受戒，以此來符合舟航渡人的比喻。

【883-0002】資持記/01a_上一上#59
【原文】文通此釋，前解為正。寔字音植，訓實訓是。次顯勝中有二，初對二學，明所詮行勝；下對兩藏，顯能詮教勝。定慧莫等者，須約兩意互明勝劣。若望斷惑證真，則慧為勝；戒但止業，定唯攝散故。若約修行次第，必戒為始；禪定智慧，因之而生故。
【譯文】文意通於這兩種解釋，但以第一種解釋為正宗。「寔」字音同植，訓解為「實在」、訓解為「正是」。其次顯揚殊勝之中分為兩段：先對比定、慧二學，說明戒律所詮顯的「戒行」殊勝；後對比經、論二藏，顯揚戒律這部能詮顯的「教典」殊勝。「定慧莫等」這句話，必須從兩種意義互相發明其殊勝與劣後。如果從斷除迷惑、證得真理的究竟角度來看，那麼智慧最為殊勝；因為戒律只是制止造惡業，禪定只是收攝散亂的心念罷了。若依照修行的次第來說，必定要以戒律作為開始；因為禪定與智慧，都是依託戒律而後得以生起的緣故。

【883-0003】資持記/01a_上一上#60
【原文】今云建修，正從後義，故云莫等。《遺教》依因，《成論》捉縛，並同此意。次顯教中。群藉即目經論二藏，於茲乃指住持之事。經論不談，故云息唱。謂剃染稟戒入道次第，以至僧中受懺安恣結說治諫師資上下行住坐臥飲食衣服眾法別行；此諸事相，佛法紀綱；住持萬代，功由於此；唯斯律藏，委示規模；
【譯文】如今說「建修」（建立修行），正是順著後面這個次第的含義而言，所以說定慧無法與戒律相比。《遺教經》以戒為「依因」，《成實論》以戒為「捉縛」煩惱盜賊，都是同一個意旨。次顯教典殊勝之中：「群藉」就是指經藏與論藏二藏，而「於茲」乃是指僧團中住持正法的事相。經藏與論藏對此皆不談論，所以稱為「息唱」（停止宣講、噤口不提）。是指剃度染衣、承受戒法、入道的先後次第，以至僧團內部受戒、懺罪、安居、自恣、結界、說戒、治罪、諫阻、師徒、尊卑上下、行住坐臥、飲食用餐、衣著物資、大眾共法、個人別行等；這些事相，正是佛法的紀綱維繫所在；佛法能住持萬代，功勳全繫於此；唯獨這部毗尼律藏，詳細示範其法則規模；

【883-0004】資持記/01a_上一上#61
【原文】餘藏非宗，故所不辨。故《善見》云：毘尼藏者，佛法壽命；毘尼藏住，佛法方住；曲論來致，備如中卷。準上所詮，亦須兩釋。若詮理發智，破妄顯真，則經論為勝。若軌事攝修、滅惡生善，則毘尼獨尊。故知三藏各具勝能；今望住持，故有優劣。
【譯文】其餘經論二藏並非以律為宗旨，所以不曾加以明辨。因此《善見律毗婆沙》說：「毗尼藏是佛法的壽命；毗尼藏住世，佛法才能住世」；委曲詳論其源流理致，詳細記載在中卷。依照上面所詮釋的道理，也必須作兩種層面的解釋：如果論詮顯勝義、啟發智慧、破除妄執、顯露真性，那麼經藏與論藏最為殊勝。若是論規範事相、約束修持、滅除罪惡、生起善根，那麼唯獨毗尼律藏最為尊貴。由此可知三藏各具殊勝的功能；如今若單從住持佛法的角度來看，所以才有優劣的差別。

【883-0005】資持記/01a_上一上#62
【原文】問：標宗所引大小經論，亦明戒律，那云息唱？答：雖復兼明，號隨經律，止是略歎戒功；至如上列住持等事，非彼所論，故得云耳。敘弘傳中，初文。正法像法，各一千年，末法萬年。如來定在正法，四依通於正像。文為二段，上明教主親弘，下明弟子傳化。
【譯文】問：〈標宗篇〉中所引用的大小乘經論，也闡明了戒律，為何說經論「息唱」？答：雖然也附帶說明戒律，但那被稱為「隨經律」，只不過是大略讚嘆持戒的功德罷了；至於像上面所列舉的住持僧團等具體事相，非彼等經論所探討的內容，所以完全可以說是「息唱」。在敘述弘揚傳承的文段中，這是第一段。正法時期一千年，像法時期一千年，末法時期有一萬年。如來必定降生在正法時期，四依大士則通貫於正法與像法二期。課文分為兩段：上段說明教主親自弘揚，下段說明弟子傳承化導。

【883-0006】資持記/01a_上一上#63
【原文】《住法圖贊》，列二十五祖，即以如來為開法大師；迦葉已下，為傳法聖僧。今此戒律，佛出方制；本其元始，故云自也。大師者，所謂天人之師，即十號之一；以道訓人，故彰斯目。然以師通凡小，加大簡之。是則三界獨尊，九道依學；唯佛大聖，得此嘉號；自餘凡鄙，安可僣稱！
【譯文】《法界住法圖贊》羅列了二十五位祖師，就是以如來為開立法門的大師；自摩訶迦葉以下，稱為傳承正法的聖僧。如今這戒律法門，是佛陀降世才親自制定的；追究它的最初起源，所以用了「自」這個字。「大師」者，即所謂的天人之師，是佛陀十種名號之一；因為以正道訓育眾生，所以彰顯這個名號。然而因為世俗中「師」通於凡夫和小乘，所以加上「大」字以示揀別。這便是三界中獨一無二的尊者，九道眾生皆當依止學習；唯有佛陀這位大聖人，配得上這個美好的尊號；其餘凡夫鄙陋之輩，豈可僭妄妄稱！

【883-0007】資持記/01a_上一上#64
【原文】故《十誦》云：若比丘言我是大師，說大師事法，得蘭夷罪，同大妄故。〔言我是，犯蘭；說事法，得夷。〕言在世者，娑婆五濁，所取之土也；大千世界，所化之境也。賢劫中第九減劫，人壽百歲，出世之時也。三十成道，說三乘法；度人無量，八十唱滅。
【譯文】所以《十誦律》說：「如果有比丘揚言『我是大師』，宣說自己證得了大師（佛）所證的過人之法，得偷蘭遮罪或波羅夷罪，因為這等同於大妄語罪的緣故。」（自稱「我是大師」犯偷蘭遮罪；若具體說自己證得了大師之法，則犯波羅夷根本罪。）所謂「在世」：娑婆五濁惡世，是佛陀所選取受生的國土；大千世界，是他所教化開導的境域。在賢劫第九減劫、人壽百歲之時，是他降生出世的時代。三十歲成道，宣說三乘教法；度化無量無邊之人，八十歲示現涅槃滅度。

【883-0008】資持記/01a_上一上#65
【原文】今指五十年中行化之時，故云在世。言偏弘者。謂雖談眾典，然於毘尼最所留意。故〈篇聚〉云：世尊處世，深達物機；凡所施為，必以威儀為主是也。又經通餘人所說，律唯金口親宣；大權影響，但知祇奉；況餘小聖，安敢措詞！又復諸經說有時限，律則通於始終。
【譯文】如今是指他五十年講經說法行化人間的時期，所以稱為「在世」。所謂「偏弘」：是指雖然普遍宣講諸多經論典籍，然而對於毗尼戒律最為深切留意。所以〈篇聚篇〉說：「世尊居於世間，深切通達萬物的機理；舉凡一切所施設的教化，必定以威儀戒相為主要核心」就是這個道理。又者，經藏通於允許佛弟子其餘人宣說，而律藏唯獨由佛陀金口親自宣制；大權示現的影響眾大菩薩，也唯有恭敬遵奉；何況其餘小乘聖者，怎敢擅自插手措辭！再者，各部經典的宣講皆有特定的時期與時限，而戒律的施行則自始至終貫穿於佛陀一生說法的全過程。
