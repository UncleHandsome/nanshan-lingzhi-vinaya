# 校閱材料　第801檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【801-0001】02_戒疏/19a_卷四下之一#93
【原文】【疏】凡出家離惡，本是學宗，要由善友，迭相諫喻。然以情迷，將欲作罪，他以理諫，復不從順，苟且為非，違損不輕，故制。
【譯文】【疏文】大凡出家求道是為了遠離罪惡，這原本是學修佛法的宗極根本，這必定要依賴善知識同參好友，彼此互相規勸開導戒勉。然而眾生往往由於情執迷惘，將要造作罪業之際，旁人以正理前來勸諫，卻仍不肯順從遵行，苟且遷就去盲目作惡，這種違背戒法、損害自他的過失極為重大，所以必須制定此戒。

【801-0002】02_戒疏/19a_卷四下之一#94
【原文】【記】五十四，制意中。初敘為道假友琢磨。「迭」，互也。「然」下，次明執愚故違造過。知非故為，故云「苟且」。
【譯文】【記文】第五十四條，在制戒用意中。起初敘述修道必須假借善友相互砥礪切磋。「迭」，是彼此交替互相的意思。從「然而」以下，接著說明眾生執迷愚癡而故意違背戒律造作罪過。明知不對卻偏要去做，所以稱為「苟且」。

【801-0003】02_戒疏/19a_卷四下之一#95
【原文】【疏】五緣成：一、將欲作罪；二、他如法諫；三、知己所作非，前人諫者是；四、拒諫不受；五、隨作犯根本，違諫故結提。
【譯文】【疏文】由五種條件構成犯戒：第一，即將造作某項罪業；第二，旁人合乎法度戒規地前來規勸；第三，心知自己所作是錯誤的，而勸諫者是正確的；第四，剛愎抗拒諫言拒絕接受；第五，隨後依舊去做，便犯了該事的根本罪，又因違抗勸諫而另加結犯波逸提。

【801-0004】02_戒疏/19a_卷四下之一#96
【原文】【記】犯緣。第五，初違但吉，待作方提。
【譯文】【記文】犯戒條件中。第五點，初次違抗諫言時僅犯突吉羅，必須等到真正把惡事做成了，才正式結犯墮罪。

【801-0005】02_戒疏/19a_卷四下之一#97
【原文】【註】佛在拘睒毗。闡陀欲犯戒，比丘諫言：「莫作此意，不應爾。」不從他諫，即犯諸罪。比丘以過白佛，因訶制戒。
【譯文】【註文】佛陀住在拘睒毗國時。闡陀比丘正準備違犯戒律，有比丘勸諫他說：「請不要動這種念頭，出家人不應當如此行事。」闡陀不肯聽從對方的勸諫，隨即違犯了種種罪業。比丘們將這件過失稟告佛陀，佛陀因而呵斥並制定了此戒。

【801-0006】02_戒疏/19a_卷四下之一#98

【譯文】【記文】制戒因緣。與先前僧殘法中的抗諫戒性質相同，只是先前那條是在僧團大眾集會中抗拒僧團諫議，而這條戒則是在私下場合拒絕個人的勸諫。

【譯文】【律文】如果有比丘，不接受正當勸諫的，犯波逸提。

【801-0008】02_戒疏/19a_卷四下之一#100
【原文】【註】若他遮言「莫作是，不應爾」，然故作，犯根本；以不從語故，突吉羅。若自知「我所作非」，然故作，犯根本；不從語者，波逸提。不犯者，若無智人來諫，報言：「可問汝師和尚，更學問誦經知諫法，若諫，當用。」若戲笑、獨語、夢中語，欲說此，乃說彼者，不犯。
【譯文】【註文】若旁人阻攔制止說「請不要做這事，這是不合宜的」，然而比丘仍舊故意去做，便犯了該事項的根本罪；因為不順從善意言語勸告的緣故，另犯突吉羅（輕垢罪）。若自己明知「我所做的是錯的」，然而仍舊執意去做，便犯了該事的根本罪；同時拒不聽從勸言的行為，結犯波逸提（單墮罪）。不犯的情況：若是沒有智慧的盲昧之人前來妄加勸諫，比丘回答說：「你應當先去請教你的親教師和尚，多學戒律、讀誦經典，懂得正確的勸諫法度，若勸得有理，我自會採納。」若是以玩笑戲謔口吻、自言自語、夢囈說夢話，或是口誤本想說此事、卻說成了彼事，均不犯戒。

【801-0011】02_戒疏/19a_卷四下之一#103
【原文】【疏】就辨相中二句。初犯輕者，迷心為己是，前諫己為非，情微故犯吉。不妨隨有作事，隨犯輕重。後犯重者，謂知已犯非，前諫者是，違情過重，所以非輕。
【譯文】【疏文】在辨析犯罪相狀的條文中有兩層意涵。起初結犯較輕的情況，是因為心神迷惑，自以為所做正確，反而認為前來勸諫的人是錯誤的，抵觸的情緒較為輕微，所以只結犯突吉羅。這並不妨礙他隨後所造作的事項，依據該事性質各自結犯輕重不同的根本罪。後段結犯重罪的情況，是指明知自己所犯是錯誤的，深知前來勸諫者是正確的，故意違背正理的情節太過惡劣，所以懲處絕不可從輕。

【801-0012】02_戒疏/19a_卷四下之一#104
【原文】【記】辨相中，初科。「二句」，即注犯中輕重二段。初釋犯輕。「不妨隨作輕重」者，謂彼所作通七聚故。「後」下，次釋犯重。
【譯文】【記文】辨析行相中，第一科判。「兩層意涵」，是指隨律註解中犯戒條款裡輕、重兩段。起初解釋結犯輕罪。「不妨礙隨其所作結犯輕重」，是指彼人所做的違戒行為通貫七篇聚罪。「從後段」以下，接著解釋結犯重罪的情形。

【801-0013】02_戒疏/19a_卷四下之一#105
【原文】【疏】問：「文中列所作，明知諫作犯，若有止犯者，於何而設諫？」
【譯文】【疏文】提問：「經文中列出所要造作的事，由此明確知道是針對『作犯（起心去做惡事）』而實施勸諫；倘若有人是消極放棄該修的善法而構成『止犯（不依教修持）』，又應當在哪條戒律中設立勸諫法呢？」

【801-0014】02_戒疏/19a_卷四下之一#106
【原文】【疏】答：「若拒勸學戒諫，違名止犯。諸戒制非，皆己作者，此之一戒，制欲犯者。但以業非不一，不可集僧一一而諫，故令一人處處行諫，知將欲犯，必須止約，有違結墮。故知要急，勿過此制。」
【譯文】【疏文】回答：「若是抗拒他人勸勉學習戒律的勸諫，違抗這種規勸就屬於『止犯』。各條戒律所禁制的過非，全都是針對自己已經造作的罪業，唯獨這一條戒，是特別用來禁制『正準備動手犯罪』之人。只是因為造作罪業的過非千差萬別，不可能每次都召集全體僧眾一個個加以如法勸諫，所以令個人（任一比丘）隨時隨處進行規勸，一旦得知他人將要犯戒，就必須及時制止約束，若有違抗便結犯墮罪。由此可知此事的緊要迫切，沒有超過這條戒制的了。」

【801-0015】02_戒疏/19a_卷四下之一#107
【原文】【記】問答中。初問五言為句。欲示後戒，故發此問。答中，初舉後戒正答。「拒勸學」，即下第七十一戒。「諸」下，對餘戒顯要，又三。初明制別。「但」下，示立意，僧諫難成，別諫易遂。「故」下，結歎。
【譯文】【記文】問答環節中。前段提問以五言格式成句。為了引出後面的戒文，所以發起這項提問。回答中，起初舉出後續戒法作正面答覆。「抗拒勸勉學戒」，即指後文第七十一條戒律。從「各條戒」以下，將本戒與其他戒條對比以彰顯其核心重要性，又分三點。起初闡明戒規的不同。從「只是因為」以下，開示立法的深意，僧團全體勸諫在手續上難以次次達成，個人單獨勸諫則容易及時付諸實行。從「由此可知」以下，總結讚歎。

【801-0016】02_戒疏/19a_卷四下之一#108
【原文】【疏】問：「違僧諫中，諫竟即犯，不待事成。此諫未犯，要待事成違諫犯者？」
【譯文】【疏文】提問：「在違抗全體僧團如法勸諫的戒條中，白四羯磨勸諫完畢立刻結犯重罪，無須等待把惡事做成。為何面對這單獨一人的勸諫卻尚未結罪，一定要等到事情真正做成了，才以違抗勸諫而結犯墮罪？」

【801-0017】02_戒疏/19a_卷四下之一#109
【原文】【疏】答：「僧中諫者，眾命是重，違情過深，隨諫結犯。此一人諫，反上可知。要待成結，若不作事，便成受勸。故不同彼。」
【譯文】【疏文】回答：「在僧眾大會中所作的勸諫，僧團的公意法命最為隆重，違抗公眾意願的過失極其嚴重，所以勸諫儀式一結束就結犯重罪。而這只是一介個人的私下勸諫，情勢與前者相反，這很清楚。所以必須等待惡事辦成才結定墮罪，如果在勸阻後最終沒有去做這件事，便算是接受了勸導。所以處理方式與僧團羯磨不同。」

【譯文】【記文】第二個提問中。針對違抗僧團大眾諫言與個人諫言在結罪時機上的兩相差異，因而發問求通。回答中，起初指出僧團勸諫告竣便立即結罪；從「而這只是」以下，第二步說明個人勸諫必須等待惡事成就方能結定。
