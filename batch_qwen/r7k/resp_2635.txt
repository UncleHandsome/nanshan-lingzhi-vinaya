整體看，這份譯文相當忠實、流暢，沒有漏譯，專有名詞（陰入、始來末去、依正、種子）大致掌握得住。問題集中在**一處所指誤認**、幾處**增字解經**與**語意含混**。分項說明如下。

---

## 一、必須修正：「四、出立意」的「二宗」不是上文的唯識／攝論

> 原文：問：**二宗**談體自足，何須別立圓教？答：**兩宗**出體，教限各殊……故準二經，別立一教。
> 譯文：問：**前面兩宗**談論體性已經很充足……

這是全段最要緊的問題。此處「二宗」應指《業疏》三宗判教中的**實法宗（薩婆多／有部，以色為體）與假名宗（成實，以非色非心為體）**，不是「三、顯體」中剛講的唯識師、攝論師。理由：

1. 「教限各殊」是判教語，指小乘二宗各有教域局限；唯識、攝論同屬大乘，無「教限各殊」之判。
2. 上文已說「一切大乘莫不皆以常住佛性妙理為體」，若二宗指唯識／攝論，則「若唯依彼，則辨體不明」自相矛盾。
3. 「若復不依，則宗途紊亂」正說律宗不能全棄本宗（四分／成實）傳承；「準二經（法華、涅槃）別立一教」即開權顯實、會小歸大之意。

**建議改譯**：「問：實法、假名二宗談戒體已經足夠，何須別立圓教？答：前二宗（實法宗、假名宗）所出之體，教門局限各有不同……」並加注說明與上文「唯識、攝論二宗」不同指。否則讀者一定會誤接上文。

（附帶：「二經」補作《法華》《涅槃》，依《濟緣記》是對的，可保留。）

## 二、增字解經／語意偏移

**1.「而與無明七識共俱」→「與具足無明的前七識共同俱在」**
「具足」是譯者加的，且把「無明七識」定讀為「無明之七識」。《楞伽》本文作「生無明住地，與七識俱」，一般可讀為「與無明及七識共俱」。建議採中性譯法：「而與無明、前七識共同俱起」，或保留原語再加注兩說。

**2.「不與妄合」→「不與妄念和合」**
「妄」指妄染、生滅妄法（與真如相對者），不限於「念」。縮成「妄念」會把真妄和合的義理窄化為念頭問題。建議：「不與妄染（生滅妄法）和合」。

**3.「流於心意，為第六」→「奔流於心意志念之中」**
「心意志念」語意含混，讀者不知所指。建議：「流注於心、意之間（起分別思慮），便是第六識」，或貼原文作「流於心意，即成第六識」。

**4.「成熟來果」→「成熟為未來的果報」**
原意是業種在第八識中**能成熟當來之果**（主動），譯成「成熟為未來的果報」語法上變成業種自己變成當果。建議：「含藏於第八識中，成熟當來的果報」。

**5.「須信投心無地」→「必須相信將投心無處」**
「須信」＝須知、必然；「投心無地」＝無處用心、無所依託。現在譯法生硬且意思不明。建議：「須知如此則無處用心（修行無所依託），一生虛度，豈不是自誤！」

**6.「紹眾聖因種」→「紹繼諸聖賢的因位種子」**
「眾聖」不宜加「賢」；「因位種子」也偏離。意為紹隆眾聖之因種、令聖種不斷。建議：「紹隆眾聖的因種（使成佛聖種相續不絕）」。

## 三、增補宜標明為譯者所加

* **《唯識》→《成唯識論》**：原文只作《唯識》，此處與《起信》《攝論》並列，逕定為《成唯識論》可，但穩妥作「《唯識論》」並注。
* **第九清淨真識（菴摩羅識）**：原文無「菴摩羅識」，屬增補，宜標「（即菴摩羅識，譯者補）」或移到註腳。
* **（末那識）（意識）（諸有＝三界）（法華、涅槃）**：這類補注有助理解，可留，但全篇宜統一用括號或註腳標識，避免與原文混同。
* 「我祖所立的圓教**乘門**」：「乘門」是生造詞，建议「我所宗祖的圓教一乘」。

## 四、可再潤飾的小處

| 譯文 | 建議 |
|---|---|
| 無不都以……為體性 | 「無不以……為體」（「無不都」冗贅） |
| 在日用之間毫無知覺 | 「日用之間卻不自覺」（避免讀成失去知覺） |
| 唯識宗師／攝論宗師 | 「唯識師（唯識家）／攝論師（攝論家）」，「宗師」易誤為一代宗師 |
| 通而為言，法法皆是→一切事法無一不是 | 補賓語：「無一不是識（所現）」 |
| 最初投胎時先來 | 「受生時最先來、命終時最後去」（「最初…先」重複） |
| 維持承載果報生命 | 「執持一期果報身命」 |
| 因業與果報 | 「因果」即可 |
| 皆可知也→全都可以藉此了知 | 補所知的對象：「皆可由此了知第八識的行相」 |
| 究竟決斷了達 | 「究竟徹底、決然明了」 |
| 隨順外緣而妄動 | 「隨緣而妄動」（「外」是添加） |

## 五、建議加的兩條註（幫助讀者）

1. **「八識之相」＝第八識之相**，非「八個識」。譯文判讀正確（與「造雖在六，起必因八」一致），但字面極易誤讀，值得加注；答中「始來末去、任持報命、六識依止、憶持往事」都是第八識的功能，可一併說明。
2. **偈「無有若干相」**：直譯「沒有種種各別的相狀」讀者難解，宜補一句義理提示——波浪雖多，同是一水，故無差異之相；諸識與心亦然，差別即無差別。這正呼應上文「已成差別法中，了無差別，故云唯識」。

## 六、小結

* 必改：**「四、出立意」的二宗指實法／假名**（其餘皆屬可改進而非錯譯）。
* 宜改：「無明七識」的斷句增字、「不與妄合」縮為妄念、「流於心意」「成熟來果」「須信投心無地」「紹眾聖因種」。
* 宜標：菴摩羅識、成唯識論、法華涅槃等增補。

改好這幾處，這份譯文的準確度就相當高了。
