# 校閱材料　第199檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【199-0001】02_戒疏/20a_卷四下之二#99
【原文】【疏】古師相傳，以緣起為所犯。今約戒本，諸部明解，但捉即犯，何論拾遺。故初列戒本，捉寶則犯。但除兩緣，下開収拾塔具，都無別開之相。如何乃云「捉寶犯吉，遺者提」乎？廣如《鈔》中《隨相》所列，明白如鏡，不蒙昧也。
【譯文】【疏文】古代律師代代相傳，都把緣起故事中的「拾取遺落之物」當作犯戒的具體行相。現在依據戒本文句以及諸部律典的明確解釋，只要動手拿取珍寶就構成犯戒，哪裡還需要論及是否為拾取遺失之物。所以戒本一開頭便列出，抓取寶物就犯戒。戒文中僅僅除去了兩種特殊情境，下文又開許收拾佛塔的供具，除此以外完全沒有另外開許的情形。怎麼可以說「平時捉寶犯吉，遺落者犯提」呢？詳情如同《事鈔》中《隨戒釋相》所列，清清楚楚如同明鏡，絲毫不容混淆蒙蔽。

【199-0002】02_戒疏/20a_卷四下之二#100
【原文】【記】斥非中。初引非。彼據「緣起」，捉但犯吉，拾遺方提。「今」下，正斥。初判犯。「故」下，引示。初示戒本。「除兩緣」，即伽藍、宿處。「下開塔具」，即不犯中。除此三緣，餘無別文開捉，那云捉但吉耶？「廣」下，指《事鈔》。彼據諸部，文相明顯，故云「明白」等。彼引《多論》「若捉金薄、金像，若捉他寶，自說淨寶，皆墮」，又引《僧祇》「知佛僧事人，有寶不得自取，乃至金銀塔像，使淨人捉」等，並非拾遺犯也。
【譯文】【記文】斥責錯誤見解之中。首先引述錯誤的看法。他們依據「緣起故事」，認為平時拿寶物只犯突吉羅罪，拾取遺落的寶物才結波逸提罪。「現在」以下，予以嚴正斥責。首先判定犯相。「所以」以下，引證說明。先指出戒本文句。「除去兩種情境」，就是指寺院伽藍之內與出外寄宿之處。「下文開許塔具」，是指不犯條文中的規定。除了這三種特殊情境之外，其餘並沒有任何文字開許可以拿取寶物，怎麼能說平時捉寶只犯突吉羅呢？「廣如」以下，指示參閱《行事鈔》。該書依據各部律典，文句行相極為明顯，所以說「明白」等等。書中引用《薩婆多論》說「如果執捉金箔、金像，或者執捉他人寶物，或者執捉經由自己作法說淨的寶物，全都犯墮罪」，又引用《僧祇律》說「管理佛僧事務的人，見到寶物不得自己動手拿取，乃至於金銀佛塔佛像，也必須讓淨人代為執持」等，這些全都不是因為拾取遺落之物才結犯的。

【199-0003】02_戒疏/20a_卷四下之二#101
【原文】【疏】論犯四緣：一、是寶物；二、非塔寺莊具；三、非餘緣；四、捉便犯。
【譯文】【疏文】論及其犯戒的四個條件（四緣）：第一、是真正的寶物；第二、不是塔寺的供養莊嚴具；第三、不是其他開許的事緣；第四、動手捉持便構成犯戒。

【199-0004】02_戒疏/20a_卷四下之二#102
【原文】【記】犯緣。第二，準本宗開通「莊具」不犯，《僧祇》、《多論》亦不許捉，《鈔》約淨人有無以通兩文。三、「非緣」者，即伽藍、宿處。
【譯文】【記文】犯戒條件（犯緣）。第二點，依照本宗規定，開許為保護「莊嚴具」而收持是不犯戒的；《僧祇律》、《薩婆多論》則完全不允許手捉，《事鈔》以現場是否有淨人來會通這兩處律文的差異。第三點「非開許之事緣」，就是指伽藍之內與寄宿之處這兩種情況。

【譯文】【註文】《律二十二明了論疏》說：「『我因為某種緣由，必須前往某處，特此稟白大德讓您知曉。』對方回答說『聽許』，這就叫做稟白之法。這具有兩種意涵：第一、為了不障礙僧團事務，唯恐僧團要作羯磨或其他法事，需要大家共同參與，若不知他的去向，就會擾惱全體僧眾；第二、使人不能隨心所欲、毫無拘束地出入俗人家中。如果是三五人相逐入村，到了村落旁邊還必須再次稟白（由長夏向幼夏稟白）。受戒十夏的要向受戒九夏的稟白，如果年資小的向年資大的稟白反而犯突吉羅罪，這是為了顯示不得隨意自在的深意。戒臘長者尚且要囑託戒臘幼者，戒臘幼者哪裡還能隨意自在？在同一個結界之內，尊卑大小可以互相稟白。」

【199-0034】02_戒疏/20a_卷四下之二#132
【原文】【記】《了論》。初示白法。「有」下，示須白意。一、障僧事。常途作法，但不同界，或有法事，須彼同作，容有稽留，白知所在，可令往喚故。二、「令不自在」者，檢自行故。下出白相，初明村中制大白小。言「復白」者，本寺白已，至村重白。「若小白大」，違制故吉。從上白下，極下無對，應開白上。「本」下，次明在界則聽互白。彼部如此。今宗但令須白，不分村中、本界之異，亦無至村復白之制。今若行事，但依本宗。
【譯文】【記文】《律二十二明了論》。首先展示稟白的方法。「具有」以下，展示必須稟白的深層意涵。第一、避免阻礙僧事。常規的法事運作，只要仍在同一個結界內，一旦有法事需要，就必須所有人一同行作，期間可能會有耽擱延誤，若預先稟告了去向，僧眾就可以差人前去尋找呼喚。第二、「使人不得自在」，是為了檢點自己的心行。下文列出稟白的儀式行相，先說明在村落之中規定由大戒臘向小戒臘稟白。所謂「再次稟白」，是指在寺院中已經稟白過了，到達村口時還要重新稟白一次。「如果小的向大的稟白」，因為違反了該部的特殊規定所以結突吉羅罪。從上位向下位稟白，到了最底層的僧人已經沒有對象可稟白時，應當開許他向居上位者稟白。「在結界」以下，接著說明若在寺院結界之內，則准許尊卑大小互相稟白。那是該部派的規定。本宗（四分律）只要規定必須稟白即可，並不區分村落之中與本寺結界的差異，也沒有到了村口必須重複稟白的要求。如今若要行持行事，只需依循本宗的規範即可。

【199-0053】02_戒疏/20a_卷四下之二#151
【原文】【記】定量中。「俗人八戒」，亦同僧制。「周尺」一尺六寸，「當今一尺三寸」，即唐尺也。以一尺二寸為唐一尺，以三寸六分為三寸，更餘四分，故云「許」也。下指《僧祇》，雖是「僧床」，亦兼己分，造者犯提，餘人應吉。
【譯文】【記文】訂定尺度規格之中。「在家人八戒」，也是等同於僧人的規矩。「周尺」的一尺六寸，「折合現在的一尺三寸」，指的就是唐尺。因為以周尺一尺二寸折為唐尺一尺，周尺三寸六分折為三寸，還剩下四分，所以說是「一尺三寸許」。下文指出《僧祇律》的說法，雖然是「僧團公有床」，但也包含了自己受用的份額，親手製造者犯波逸提罪，僧中其餘大眾應當結突吉羅罪。
