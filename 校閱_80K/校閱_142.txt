# 校閱材料　第142檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【142-0001】資持記/10b_中三下#13
【原文】〔佛將弟子從拘薩羅遊至舍衛，大得餅食，令阿難分與乞人，遂以粘餅與女人，餘皆得一，女獨得二，彼因譏謗；又外道得食，人問，便云禿居士處得，以此二緣故制。〕明開中。《五分》不明外道；乞兒語通，故此引之。下二乞字，並去呼。《十誦》、《多論》二文並開，但非自手，則同今宗。
【譯文】〔佛陀帶領弟子從拘薩羅國遊化至舍衛國，獲得了極多的餅食，便命令阿難將餅分發給乞丐，阿難於是把黏在一起的重疊餅發給一名婦人，其餘乞兒都只得一張，唯獨這名婦人得到兩張，眾人因此譏嫌毀謗；又有外道得到了這份食物，別人詢問，外道便說是在光頭居士那裡得到的，因為這兩起因緣而制定此戒。〕在說明開許的文句中。《五分律》並沒有明確提及外道；「乞兒」這一稱呼通於各類乞食之人，所以此處予以引用。下文的兩個「乞」字，都應讀為去聲。《十誦律》與《多論》兩處文句都開許施予，只要不是親手遞給對方，便與本宗的意旨相同。

【142-0002】資持記/10b_中三下#14
【原文】無見即邪空外道，或住邪見無正見者。文略不犯，準律有五。一若捨著地與；二若使人與；三若與父母〔謂住外道者，《僧祇》不開。〕；四與塔別房作人，計作食價與；五若力勢強奪去。四十二。〔佛在舍衛，長者為跋難陀飯僧，彼時欲過方來，比丘食竟不足；
【譯文】「無見」是指執持斷滅邪空的外道，或者是安住在邪見、毫無正見的人。經文簡略未備不犯的情形，依照律典共有五種。一是如果捨棄放置在地上讓對方拿取；二是如果差遣俗人轉交；三是如果施予父母〔這是指父母已淪為外道者，若依《僧祇律》則不開許〕；四是給予塔寺或別房的雜役僱工，折算作工資勞務的食物費用而給予；五是如果對方憑藉暴力強行奪去。第四十二條戒。〔佛陀在舍衛國時，長者為跋難陀比丘設齋供僧，跋難陀直到用餐時間將過才姍姍前來，導致僧眾用餐完畢卻食物不足；

【142-0003】資持記/10b_中三下#15
【原文】又羅閱城大臣得果令僧中分，後食已詣餘家，僧不得食，二緣故制。〕名云同利，即同受請者。凡受他請，有緣入聚，須白同請，令知所在。不白故犯。釋初緣中。《僧祇》二墮，前戒委引。義決中。以文制同利，則據多人，不明獨請。故準《僧祇》令白請家等。
【譯文】又有一次，羅閱城的大臣得到美味果品送給僧團平均分配，跋難陀用餐完畢後又前往別人家，導致僧眾無法如期分得食物，因這兩起因緣而制定此戒。〕戒名稱為「同利」，就是指共同接受請齋的人。凡是接受他人迎請，若有緣由需要進入村落聚落，必須告知同受請的人，使大家知道自己的去向。如果不作宣白便會犯戒。在解釋第一條犯緣中。《僧祇律》判定結兩次波逸提罪，前一戒已詳細引述。在義理決斷中。因為經文規定是「同利」，乃是依據有多人同受請而言，並未言明獨自一人受請的情況。因此依照《僧祇律》的規範，應當告知齋主施主家等人。

【142-0004】資持記/10b_中三下#16
【原文】一合作以，或可來上脫二字，即配上兩白也。彼下，引證。常請謂長供不絕。交往謂我往彼家，他來此家。釋後四中，初釋食前後。食時者，相傳以為辰時；用此為中，以分前後。注同《時經》，即《時非時經》。次釋餘家。可解。白下，明囑授，初明所囑人。注文簡異。
【譯文】「一」字應當改作「以」字，或者可能是「來」字上面脫漏了兩個字，也就是用來配屬前述向請主與同行僧的兩次宣白。彼處文句以下，引述作為證明。「常請」是指長期供養不曾斷絕。「交往」是指我前往彼人家中，他人來到我這處僧舍。在解釋後四條犯緣中，首先解釋食前與食後。「食時」，歷代相傳認為是辰時（上午七至九點）；以此時作為分界，來區分食前與食後。附註與《時經》相同，即是《時非時經》。其次解釋「別人家（餘家）」。文意容易理解。「白」字以下，說明囑託告知的方法，首先說明被囑託告知的對象。注文簡別辨明不同之處。

【142-0005】資持記/10b_中三下#17
【原文】以非時白，通界內外。若下，明失囑法。有六緣。中道還者，準約息意，不往故失。或餘家者，非向所囑家。不下，結犯。不犯中，初文六節。上四可解。第五律作若無比丘，不囑授，而至餘處等，以無法可違故。六家家請，如欲往彼請家，中途他家相命，因而暫止。律文更開難緣，今此略耳。
【譯文】因為非時入村的宣白，通於同結界之內與界外。隨後說明喪失囑託效力的法規。共有六種因緣。中途折返的人，按常理是依據打消了前往的念頭，既然不去村落，先前的囑託效力自然喪失。或者前往別人家者，並非先前所囑託預告的那一家。「不」字以下，判定結罪。在不犯的開緣中，起初的文段有六個關節。前面四項容易理解。第五項律文寫作：如果現場沒有其他比丘，未作囑託而前往別處等，因為當時沒有可循的囑託對象與法則，所以不犯。第六項是「家家請」，例如原本打算前往那家受請，中途有另一家施主臨時盛情相邀，因而暫時停留。律文中進一步開許了災難等特殊危急因緣，此處只是簡略敘述罷了。

【142-0006】資持記/10b_中三下#18
【原文】他部中。《十誦》約正足，此開背請，亦聽不囑。《多論》明犯，非關此戒；或緣輒往令眾不知，少有同故，寄此明之。下卷即〈赴請篇〉。四十三。〔佛在舍衛，迦留陀夷與本俗友婦繫意，後住其家，其婦嚴身，其夫極愛，比丘食已坐住，夫瞋故制。〕釋名。四食者：一段食〔麁細為二，麁則可知，細謂中有食香；
【譯文】其餘部派的律典中。《十誦律》是依據進食正已滿足而言，此處開許了背離原請，同時也聽任不必預先囑託。《多論》所說明的犯戒相狀，並非直接關乎這條戒；或者是因為有事輒自私往而讓大眾茫然不知，稍微有雷同之處，所以寄託於此戒中順帶說明。下卷則是指〈赴請篇〉。第四十三條戒。〔佛陀在舍衛國時，迦留陀夷比丘與出家前的世俗友人之妻彼此眷戀，後來常住其家，其婦盛裝打扮，其夫極其寵愛她，比丘用完齋後依然留坐不去，丈夫生起瞋怒，因而制定此戒。〕解釋名稱。四種食包括：第一是段食〔分為粗與細兩種，粗段食顯而易見，細段食則是指中陰身以聞香為食；

【142-0007】資持記/10b_中三下#19
【原文】天及劫初，食無變穢；如油沃沙，散人支體，故名為細。〕，二觸食〔根境識三和合生諸觸，如見色生喜樂等，今戒當此。〕，三思食〔謂意業也，思心希望，能延命故。〕，四識食〔中陰地獄無色眾生入滅盡定，雖無現識，識得在故；小乘則識蘊，大教即梨耶，勢力所資，能任持諸根故。〕。
【譯文】天人以及劫初之時，進食後體內沒有排泄穢物；如同香油澆灌細沙，營養自然散布滋養人體四肢百骸，所以稱為細食〕，第二是觸食〔眼耳鼻舌身意六根、色聲香味觸法六境與六識，三者和合生起種種觸受，例如看見妙色便生起歡喜安樂等感受，如今此戒正相當於這一類〕，第三是思食〔是指意業，心存希望思慕，能夠延續生命之故〕，第四是識食〔中陰身、地獄以及無色界的眾生入於滅盡定時，雖然沒有當下顯現的情識，但微細識體依然常在；在小乘即是識蘊，在大乘即是阿賴耶識，憑藉其勢力的資持，能夠任持守護諸根不壞〕。

【142-0008】資持記/10b_中三下#20
【原文】段食局欲界，餘三通三界。略知如此，他宗法相不可廣故。五下，引證。《五分》情者但就識論。《僧祇》具列根境識三。緣中。第二，《十誦》斷淫謂夫婦修梵行，受齊即八戒斷正淫故。三中，《五分》妨事者，令彼夫婦不得隨意故。《十誦》多人，即同第四人故。四中，三人外更有一人不犯，故云第四。

【譯文】《僧祇律》中有五點，首先說明過濾後檢視蟲子的方法。「厭課」是指事情迫不得已，如同趕工催促一般。大象步行遲緩，何況背上有負載，折返必定延宕很久，所以取此作為時間限制。「若施」以下，說明受居士迎請到家中濾水的方法。「不得向人說有蟲」，是擔心居士知道後倒掉而造成殺生之犯。「蟲水」以下，說明將蟲水送還原處的方法。「不消」，是指經過很長時間水都不會乾涸。「若知」以下，說明知道有蟲之後保存守護的方法。在顯明制戒意圖中，指出本戒與前戒相同。《戒疏》說：如果依含有蟲的水這點來看，理應合為一條戒；

【原文】為重物命，故內外兩結。律不犯中。先不知，若無虫想；若虫，麁觸水使去；若漉水飲用，並無犯。六十三。〔佛在舍衛，十七群語五群言：云何入初禪？云何得羅漢果？彼報言汝說者犯波羅夷，佛呵因制。〕初緣者。《多論》：十三難，顛狂比丘，吉羅；學悔，六夜別住，四羯磨，僧尼互疑悔，皆提。釋第三。

【原文】六事。初生時者，即云汝非爾許時生。二年歲者，云汝非爾許歲，如餘受者。三受戒者，云汝受戒年不滿，又界有別眾。四羯磨者，汝受時羯磨不成。五六聚者，云汝犯夷乃至惡說。六聖法者，云汝所問法則，自稱上人法，犯重，非比丘也。隨下，通結。上引《僧祇》。但開正受。
【譯文】共有六種事。第一是「出生時節」，就是說你並不是在那個時候出生的。第二是「年歲」，說你並不是那個歲數，如同其他受戒者所知那樣。第三是「受戒情節」，說你受戒時年齡不滿，或者戒場結界中有僧眾別異分開的情況。第四是「羯磨法」，說你受戒時的羯磨沒有如法作成。第五是「六聚罪」，說你犯了波羅夷重罪甚至惡說輕罪。第六是「聖法」，說你所問的法，就是自稱證得上人法，犯了重罪，已經不再是比丘了。「隨」以下，作總結。上面所引用的《僧祇律》，只開許在正受戒時可以勘問。

【原文】但為表己心無私曲，復恐相惱，故不須多。次科，《僧祇》初簡對露。若下，次明難開。護根謂意根也。三中。《多論》開疑，由未審決，不成覆故。四十，引律明犯，初約晝夜各分時限，遞明知說。故知露罪制在半日之內。問：小食時知，食後不說，復有罪不？
【譯文】只是為了表明自己心中毫無自私偏曲，又擔心造成對方的苦惱，所以不必向太多人說。下一科，《僧祇律》首先簡別相對發露的情形。「若」字以下，其次說明遇到困難時的開許。「護根」是指防護意根。第三項中，《薩婆多論》開許心懷疑慮的情況，因為尚未審慎判定，所以構不成覆藏罪。第四科，引用律文說明結犯，首先以白晝與黑夜各自劃分時限，遞次說明知道之後發露的規定期限。由此可知發露罪過規定在半天之內。有人問：在吃早粥時知道，吃完午齋（正食）後仍不說，這樣到底有罪沒有？

【原文】答：約義以求，初夜中夜不說皆吉，並是方便；若論犯墮，須約明相；文中結墮，因前次第，且據中後夜耳。除下，次明所覆輕重。餘罪即下三篇。自下，三簡自他不同。疏云：覆他名重而治輕〔但悔本罪〕，自覆名輕而治重〔覆殘行別住，餘篇並先悔。〕。
【譯文】回答：從法義來探求，初夜、中夜不說都結突吉羅罪，這都屬於方便未成之罪；如果論及結犯墮罪（波逸提），必須以天亮顯現明相為準；律文中結墮罪，是順著前面的先後順序，暫且依據中夜與後夜來說罷了。「除」以下，接著說明所隱瞞罪過的輕重。其餘的罪過就是指下三篇輕罪。「自」以下，第三項簡別自覆與覆他的不同。《戒疏》說：隱瞞他人的罪名義上較重，但處罰較輕〔只須懺悔當下的覆藏本罪〕；隱瞞自己的罪名義上較輕，但處罰較重〔隱瞞僧殘罪必須行別住，其餘各篇也都必須先懺悔覆藏罪〕。
