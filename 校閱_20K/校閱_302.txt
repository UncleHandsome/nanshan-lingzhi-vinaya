# 校閱材料　第302檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【302-0002】02_戒疏/11c_卷三上之二#122
【原文】【疏】又僧不制伴，開日覓淨，尼則反前故也。
【譯文】【疏文】再者，僧眾不限制一定要有同伴同行，開許寬限日子尋找淨人說淨；比丘尼則恰恰相反的緣故。

【302-0003】02_戒疏/11c_卷三上之二#123
【原文】【記】次釋，立義中。「覔淨」謂擇淨境以作對首，或可覓人說淨，故云「覓淨」。尼制須伴，故云「反前」。
【譯文】【記文】次一種解釋立論中。「覓淨」是指選擇清淨之人作為對首，或者說是找人說淨，所以稱為「覓淨」。比丘尼被制令必須有人作伴，所以說「反前」。

【302-0004】02_戒疏/11c_卷三上之二#124
【原文】【疏】「若爾，尼畜長衣，有伴可說，不應同僧？」
【譯文】【疏文】提問：「如果是這樣，比丘尼蓄積長衣既然有同伴可以說淨，就不應該與比丘僧同樣開許十天？」

【302-0005】02_戒疏/11c_卷三上之二#125
【原文】【疏】答：「鉢不同衣。未成非鉢，無長可犯。若鉢已成，須對說淨。衣營未成，皆有長過。一日簪縫，不得成辨，故開十日。」
【譯文】【疏文】回答：「缽與衣服不同。未經製成就不算作缽，沒有長缽之罪可犯；如果缽已經製成，就必須對人說淨。衣服只要開始裁作而尚未縫成，都有蓄長的過失；一天的時間穿針引線，是不能裁縫完畢的，所以開許十天。」

【302-0006】02_戒疏/11c_卷三上之二#126
【原文】【記】釋難中。以尼長衣同開十日，若約有伴，義則不成。答中。鉢取如法熏治都竟，乃有犯長。衣取財體過日成長，所以不同。
【譯文】【記文】在解釋問難中。因為比丘尼長衣戒同樣開許十天，如果以有同伴為由，義理便不能成立。回答中，缽必須等到如法熏洗燒烤完全完備，才會構成犯長；衣服則是布料本身超過限期（十日）即構成蓄長，所以情況不同。

【302-0007】02_戒疏/11c_卷三上之二#127
【原文】【疏】「若爾，長衣未成，有伴對說，與鉢相似，何為不得？」
【譯文】【疏文】提問：「如果是這樣，長衣尚未缝成，既然有同伴可以對面說淨，這與長缽的情況相似，為何不能只限制一日呢？」

【302-0008】02_戒疏/11c_卷三上之二#128
【原文】【疏】又解：「衣開十日，據但三衣者為言，以十日內開成，不須淨施故。若說淨者，亦制一日。」
【譯文】【疏文】另一種解釋是：「衣服開許十天，是針對僅有三衣的比丘尼來說的，因為在十天之內開許縫製完畢，不需要作淨施；如果是可以說淨的情況，也同樣限制為一日。」

【302-0009】02_戒疏/11c_卷三上之二#129
【原文】【記】後釋中。初躡破前解。上雖兩分，未通伴義。「又」下，正立。「但三衣人」由不說淨，故開十日。餘則不開。
【譯文】【記文】後一種解釋中。起初順著前文破斥先前的見解，上面雖然分了兩面，卻尚未圓滿通達同伴的義理。從「另一種」以下，正式建立主張。「但三衣人」因為不作說淨，所以開許十天；其餘情況則不開許。

【302-0010】02_戒疏/11c_卷三上之二#130
【原文】【疏】「若爾，何以同開十日？」
【譯文】【疏文】提問：「如果是這樣，為何全體一同開許十天？」

【302-0011】02_戒疏/11c_卷三上之二#131
【原文】【疏】答：「一開已後，同至十日。如病開粥，不病亦開，類知。」
【譯文】【疏文】回答：「一旦開許了一個人之後，大眾就全都一律開許至十天。好比因生病而開許食粥，沒病的人也能一同吃粥，依此類推便可明白。」

【302-0012】02_戒疏/11c_卷三上之二#132
【原文】【記】釋妨中。今畜長者則不應開。答中，如上所通，據本開耳，開已同開。舉例可解。
【譯文】【記文】解釋難點中。若照此理，蓄積長衣的人就不應該得到開許。回答中，正如前面所融通的，是根據最初開許的緣由，一旦開許則大眾同享開許。舉出的例子顯而易見。

【302-0013】02_戒疏/11c_卷三上之二#133
【原文】【疏】三、輕重不同，謂五敷、取尼衣、浣故、擔、擗，尼吉僧提故也。所以不同，至文更敘。
【譯文】【疏文】第三、罪名輕重不同。也就是五種敷具、取非親尼衣、請尼浣洗衣物、擔羊毛、擘羊毛，比丘尼犯突吉羅，而比丘僧犯捨墮。之所以不同的原因，留到後文再作敘述。

【302-0014】02_戒疏/11c_卷三上之二#134
【原文】【記】三、輕重中。初列名，總有九戒。「所以」下，指意。「至文敘」者，準下亦多不釋。今詳五敷，尼得施薄，希故俱輕。取尼衣者，下云僧是上尊，與希故輕。浣、擗則下無使上之義，擔毛則女弱多耻為之，故與僧異也。
【譯文】【記文】第三、罪名輕重當中。起初列舉戒名，總共有九條戒。從「之所以」以下，指明原由。「留到後文敘述」，對照下文其實大多也沒有再作解釋。如今詳加推敲：五種敷具，比丘尼所得布施菲薄，得敷具因緣稀少所以五條戒全都屬輕罪（俱犯突吉羅）；取尼衣戒，下文說僧眾是上位尊長，僧眾給予衣服的情況稀少所以尼犯輕罪；浣衣、擘毛，則因為下位者本來就沒有驅使上位者的道理；擔羊毛則因為女子柔弱且多知羞恥而不肯去做，所以與比丘僧有所不同。

【302-0015】02_戒疏/11c_卷三上之二#135
【原文】【疏】八、沙彌任運者。
【譯文】【疏文】第八門，沙彌自然任運犯戒的情況。

【302-0016】02_戒疏/11c_卷三上之二#136
【原文】【記】第八門。「沙彌」有二：一、形同沙彌，縱受五戒，體猶同俗，非此所明；二者，法同沙彌，即受十戒者，前後所論，並據此耳。
【譯文】【記文】第八門。「沙彌」有兩種：第一是形同沙彌，即使受了五戒，本質依然等同俗人，這不是此處所要說明的；第二是法同沙彌，也就是受了十戒的人，前後文所討論的，都是根據這一類沙彌而言。

【302-0017】02_戒疏/11c_卷三上之二#137
【原文】【疏】未受具前，先教人作十五戒。
【譯文】【疏文】在尚未受具足戒之前，預先教唆他人製作，牽涉到十五條戒。

【302-0018】02_戒疏/11c_卷三上之二#138
【原文】【疏】謂長衣、鉢、月望、急過後。此四戒者，沙彌時受財屬已，受具後數過十日，謂通受前，三性之中任運犯提。藥法不爾，沙彌時作手、口二受竟，進具後即失受法，故無任運也。
【譯文】【疏文】也就是長衣、長缽、月望衣、急施衣過期之後這四條戒。沙彌時期接受了財物歸為己有，受具足戒之後計算天數超過十天，也就是通計受戒前受戒後的日子，在善、惡、無記三性之中自然任運構成捨墮。七日藥法则不是這樣，沙彌時期親手受取並口中受法完畢，進受具足戒之後便立即喪失了先前的受藥法，所以不會任運構成犯戒。

【302-0019】02_戒疏/11c_卷三上之二#139
【原文】【記】初科，四長中。準《義鈔》，此有二義。「受後數過」，即初義也。「謂通受前」，即是次義，《義鈔》云「亦可通前日數，前後滿十」，「謂」合作「或」。又詳，彼存二義，此取後義，釋上「數過十日」，故云「謂通受前」也。然須更簡，犯有二別，一、正受日過，二、受竟限滿，並三性犯。下簡長藥。雖是長數，由有受法，故異上四。「受法失」者，以位別故。
【譯文】【記文】第一科，在四種長物戒中。依照《義鈔》，這裡包含兩種義理。「受戒後計算天數超過」，這是第一種義理；「通計受戒前受戒後的日子」，這是第二種義理，《義鈔》說「也可以通算受戒前的天數，前後合滿十天」，「謂」字應當作「或」字。再詳加審核，彼處存留了兩種義理，此處採用後一種義理，用以解釋上面的「數過十日」，所以說「謂通受前」。然而必須再加簡別，犯戒有兩種不同：第一是在正受具戒之日超期，第二是受戒完畢後期限屆滿，兩者都通於三性犯戒。下文簡別長藥。雖然同是計算長期的日數，但由於長藥包含特殊的受持法，所以不同於上面四條。「受法失效」，是因為果位品階不同的緣故。

【302-0020】02_戒疏/11c_卷三上之二#140
【原文】【記】「若爾，沙彌時畜長，進具已後，亦是位別，何故通前數耶？請為通之。」
【譯文】【記文】「如果是這樣，沙彌時期蓄存長物，進受具足戒之後也同樣是地位不同，為什麼要通算先前的天數呢？請為我解答融通。」

【302-0027】02_戒疏/12a_卷三上之三#3
【原文】【疏】初制意者。良由眾生根報不同，強弱不等，致令大聖方便開遮，始終將補，有六種之別。
【譯文】【疏文】首先說明制戒的本意。這實在是因為眾生的根器與果報各自不同，強健與羸弱並不均等，因而促使大聖如來運用權巧方便進行開許與禁止，從始至終予以輔助調補，共有六種根器的差別。

【302-0028】02_戒疏/12a_卷三上之三#4
【原文】【記】第一，制意，總敘中，初科。「方便開遮」，「遮」即是制。初是本制，望次名聽，第二是制，制必須開，下四並開，開皆有制。「始終」總下六種。隨機開制，故云「將補」。「將」，猶助也。
【譯文】【記文】此處是第一部分「制戒本意」的總體敘述，也是第一小節。「權巧開許與禁止（方便開遮）」中，「禁止（遮）」就是制定戒條。第一種是根本禁制，對比後者則稱為開許；第二種是禁制，既然禁止就必須有所開許；其餘四種全屬開許，而在開許之中又皆附帶禁制。「始終」兩字總括以下六種情況。隨著眾生的機根而進行開許與禁制，所以稱為「輔助調補（將補）」。「將」字就是扶助、護持的意思。

【302-0029】02_戒疏/12a_卷三上之三#5

【302-0030】02_戒疏/12a_卷三上之三#6
【原文】【記】次科，糞衣中。「面王」者，《賢愚經》云「面有王字」，若準《分別功德論》云：「此人生下，頂有天冠，請梵士為作字，名為『面王』。出家時披一白㲲，至世尊所，欲求為道，佛曰『善來』，即成沙門。直以所披白㲲染為袈裟，不用餘衣，白佛：『弟子正欲終身披此一衣，願佛聽之。』佛即默可。」據此似非「胎衣」。然準《章服儀》云「面王釋子，報服隨身」，即知「胎衣」明矣。若《付法藏傳》，商那和須，亦是「胎衣」，此乃佛滅後事，引證制意，殊不相合。「資」謂外資，「持」即支持。「及」下二句，即上出家白佛也。「如來」下二句，即默可也。「便」下二句，出聽意也。「自靜」，無他求也。「緣濟」，一衣已足也。
【譯文】【記文】接下來的一節是關於糞掃衣的內容。「面王」的名稱，《賢愚經》記載「面容上有『王』字之相」；若依照《分別功德論》所說：「此人出生時，頭頂自有天冠，父親請來梵志為他命名，取名為『面王』。出家時他身披一匹白㲲布，來到世尊面前請求修道，佛陀說了聲『善來』，他當下便成為沙門。他直接將所披的白㲲布染成袈裟，不肯使用其餘任何衣物，並向佛稟白：『弟子只希望終身披著這一件衣服，祈願佛陀應許。』佛陀隨即默然許可。」依照這段記載，似乎並非「胎衣」。然而按照《章服儀》所說「面王釋子，果報之服自然隨身」，就能明瞭確實是「胎衣」。至於《付法藏傳》中所載的商那和須比丘，也是帶著「胎衣」出生，但那是佛陀滅度後的事蹟，若用來引證佛陀當時制戒的本意，便十分不相吻合。「資」是指外在資財，「持」是指維持護持。「及將入法」以下兩句，就是指上文出家時向佛陀稟白之事。「如來順機」以下兩句，就是指佛陀默然應允。「便能自靜」以下兩句，指出了開許的本意。「自靜」是指心中無求於外物；「緣濟」是指僅憑這一件衣服就已經完全足夠。

【302-0033】02_戒疏/12a_卷三上之三#9
【原文】【疏】三者，雖制畜三，首足猶露，力薄心羸，寒苦所逼，神情亂涉，無心存道。是以如來又量機性，故開百一，記識受持。《多論》云：「百一物中，三衣鉢具必應受持，餘外若受則可，不受無過。」
