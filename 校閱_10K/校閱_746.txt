# 校閱材料　第746檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【746-0001】02_戒疏/16c_卷四上之一#142
【原文】【疏】口業綺者，名作「異語」。身業綺者，名作「觸惱」。兩緣未白，隨作犯吉。白制後犯，違制故提。同違制故，兩戒合制。《成實》云：「雖是實語，以非時故，無利益故，言義無本，煩惱心說，皆名『綺語』。」
【譯文】【疏文】口業的輕浮綺語，在經文中稱為「作其餘異語」。身業的輕浮綺語，在經文中稱為「觸惱」。在僧團尚未正式舉行單白羯磨宣告制止之前，只要有所造作都只結突吉羅罪。在單白羯磨宣告制約之後若再違犯，因為屬於違抗僧團命令，所以犯波逸提墮罪。正因為同樣屬於違抗僧團制約的緣故，所以兩條戒合併在一處制定。《成實論》說：「縱使所說的話完全是實話，但若是說得不合時機、對聽者毫無利益、言談義理毫無根據、完全出於自我的煩惱妄心而說，這些全部都名為『綺語』。」

【746-0002】02_戒疏/16c_卷四上之一#143
【原文】【記】釋名中，初科。初釋二名。「兩」下，示犯相。「同」下，明合制。「成論」下，示同類。口綺言「非時」者，不宜說也。言「無利」者，不稱機也，「無本」者，不稽實也。「煩惱心」者，非利他也。
【譯文】【記文】科判解釋名稱中，第一科。最初解釋兩種名稱。「兩」字以下，指出犯戒的面相。「同」字以下，說明合併制戒的理由。「成論」以下，指出其餘同類的法相。口業綺語所謂「非時」，是指在不合宜的場合時間說話。所謂「無利」，是指不契合聽者的根機；「無本」是指未經查考驗證無真實本末；「煩惱心」是指完全不是出於利益他人的慈悲心。

【746-0003】02_戒疏/16c_卷四上之一#144
【原文】【疏】問：「餘三口業直作即犯，不待僧制者？」
【譯文】【疏文】有人提問：「其餘三種口業（妄語、惡口、兩舌）只要一開口做出來就立即犯戒，不需要等待僧團作羯磨制裁；為什麼唯獨這條綺語戒需要如此呢？」

【746-0004】02_戒疏/16c_卷四上之一#145
【原文】【疏】答：「彼之三過，一、正相違，二、損處重，所以隨犯。綺語反前，要違僧制，方始制墮。」
【譯文】【疏文】回答說：「那三種口業過失，第一是直接與佛法戒相相違背，第二是所造成的損害極其嚴重，所以隨做隨犯。綺語的性質恰好與前三者相反，性質較輕微，必須等到明確違抗了僧團的正式制止命令之後，才開始結定波逸提墮罪。」

【746-0005】02_戒疏/16c_卷四上之一#146
【原文】【記】問答中，初問。口四犯相不同。答中，初示餘三直犯，次明綺語須制。若論綺語，亦具違損兩義，但不如餘三過狀麤著，故云「反前」也。
【譯文】【記文】科判問答中，第一問。因為四種口業的犯戒相貌有所不同。回答中，先說明其餘三種口業是直接犯戒，接着說明綺語必須等待僧團法制。若深究綺語，其實也具備相違與損害兩種性質，只是其過失行相不如前三種那樣粗重顯著，所以說「與前相反」。

【746-0006】02_戒疏/16c_卷四上之一#147
【原文】【疏】問：「此戒白竟未犯，更作便犯。一切諫戒，諫竟即犯者何？」
【譯文】【疏文】有人提問：「這條戒在羯磨唱白結束時尚未犯墮罪，必須日後再次違犯才算犯墮罪；為什麼一切諫勸性的戒律，卻都是三次羯磨諫勸一結束就立即犯重罪呢？」

【746-0007】02_戒疏/16c_卷四上之一#148
【原文】【疏】答：「此謂惱僧，故作制約；白竟未違，要作違制，方結其犯。就結犯相，與諫不同。」
【譯文】【疏文】回答說：「這是因為當事人惱亂了僧團，所以僧團作法予以約束警戒；唱白剛結束時他還沒有進一步違抗，必須日後真正做出違背制約的行為，才正式結他的犯戒之罪。就結定罪相的機制而言，這與一般諫勸性戒律本就不同。」

【746-0008】02_戒疏/16c_卷四上之一#149
【原文】【記】次問中。此與諫戒，違法是同，結犯兩異故。答中，初明綺語。若不更作，即是順制，故「白竟未違」。「就」下，次明諫戒。為諫作法，法竟不捨，即是相違，故不待更作。
【譯文】【記文】科判第二問答中。因為本戒與諫戒同樣是違抗教法，但在結定罪名的方式上卻有前後差異。回答中，先說明綺語戒。如果在唱白後不再重犯，就等於是順從了制約，所以說「唱白完畢尚未違犯」。「就」字以下，接着說明諫戒。僧團作法是為了命令他立刻捨棄惡見惡行，羯磨法一旦完結而他仍不肯捨棄，當下就已經構成了違抗相違，所以不需要等待日後再造作新的行為便直接結罪。

【746-0009】02_戒疏/16c_卷四上之一#150
【原文】【註】佛在拘睒毗國。闡陀比丘犯罪，餘比丘問，以餘事答。以過白佛，便訶已，作餘語白。後便惱僧，喚來不來，乃至不應語而語。以過白佛，訶已，作觸惱白，因此故制也。
【譯文】【註文】佛陀住在拘睒彌國。闡陀比丘犯了過失，其餘比丘訊問他，他卻故意顧左右而言他，拿別的事情搪塞回答。比丘們把這項過失稟白佛陀，佛陀呵斥之後，僧團便為他作了禁止作其餘異語的單白羯磨。後來他索性藉此擾亂僧團，僧團召喚他來他偏不來，乃至說出許多不該說的話。大眾再度將過失稟白佛陀，佛呵斥之後，僧團又作了禁止觸惱僧團的單白羯磨，正因為這個緣故才制定了此戒。

【746-0010】02_戒疏/16c_卷四上之一#151
【原文】【疏】就戒緣中，初語違僧，後「來不來」，是觸惱相也。文中列「語」，為表身乖也。
【譯文】【疏文】在戒律的緣起當中，最初是用言語違抗僧團，後來的「叫他來卻故意不來」，就是屬於身業觸惱的相貌。戒律經文中雖然列出「言語」，是為了用言辭來彰顯其身體行為的不順從與相違背。

【746-0011】02_戒疏/16c_卷四上之一#152
【原文】【記】釋緣中。初牒釋。「文」下，簡濫。以身綺中云「不應語而語」等故。
【譯文】【記文】科判解釋緣起中。最初引述經文解釋。「文」以下，防範混淆濫用。因為在身業綺語的範疇中，也包含「不應語而語」等口業表現的緣故。

【746-0017】02_戒疏/16c_卷四上之一#158
【原文】【註】若上座喚，不來，吉羅。不犯者：重聽不解，前語有參錯，「汝向誰說」，乃至「我不見此罪」；若作非法、無利益羯磨，不與和合，喚來不來；若為作非法羯磨，若不欲知，教言「莫來」便來；若一坐食，若不作餘食法食，若病，喚起不起；命、梵等難，教「莫起」便起；若惡心問，不與說；若作非法事，便訶語者；若小語；若錯說——一切不犯。
【譯文】【註文】如果上座尊者召喚，故意不前來者，結突吉羅罪。不犯戒的情況：因為耳背聽不清楚而未能理解，或者先前的語句有所錯亂混淆，因而詢問「你剛才對誰說話」，乃至說「我實在不知自己有此罪過」；如果是僧團正在進行非法的、無利益羯磨，比丘不予認同和合，僧團召喚他來而故意不來；如果僧團正準備對他（或他人）進行非法羯磨，僧團若不想讓他知道（或他想要前去知曉）而有人交代囑咐說「不要過來」，他偏偏前來；如果正在奉行一坐食的頭陀行，或者正在依律奉行不作殘食法的飲食，或者身體有病，旁人叫他起身而不起身；如果面臨性命危險、梵行難保等危難，旁人吩咐「不要起身」他隨即起身躲避；如果是他人心懷惡意故意盤問，因而拒絕回答；若是見到他人正在做非法之事，隨即嚴詞呵責者；若是輕聲細語低語；若是無心說錯話——這一切全都不算犯戒。
