# 校閱材料　第1172檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1172-0001】資持記/09b_中三上#15
【原文】以律不犯中，除屋內土不犯；但云除土，不言得掘，是文不了。〔下不犯，中不引。〕疏引古解云：屋內死浮土也。今師云：準如《僧祇》，露處死土，屋中自掘藏物者得。〔是知露處約死，覆處不論死活。〕不犯中，初開作法。若下，明作務九相。疏云：《四分》反甎曳材不犯；
【譯文】因為律文在不犯戒的項目中，除去屋內的泥土不算犯戒；但只說除去泥土，沒有明言可以挖掘，這是文意不夠明瞭之處〔下文列舉不犯戒時，中間漏引了這點〕。《戒疏》引用古德解釋說：這是指屋內的死土與浮土。現在法師主張：應當準照《僧祇律》，露天處指死土，屋內為了埋藏器物而自己挖掘是可以的〔由此可知露天處要看是否為死土，有遮蔽的屋內則不論生地死土〕。不犯戒的情況中，首先開許如法說清淨語（作淨法）而不犯。「若」字以下，說明日常勞作的九種情形。《戒疏》說：《四分律》規定翻轉磚塊、拖拉木材不算犯戒；

【1172-0002】資持記/09b_中三上#16
【原文】《僧祇》犯者，俱有心也。〔前云曳木驅牛馬等。〕然律開文緩而義急，故一切通開不故掘也。〔疏文〕是則《僧祇》無心亦開，《四分》故意亦犯。〔凡與上文相違，並宜此斷。〕十一。〔佛在曠野城，因前造房斫伐神樹非沙門法，呵責而制。〕壞音怪，損也。壞即是業，生種即境，禁斷此過名戒。
【譯文】《僧祇律》卻判定為犯戒，這兩者都是在有心掘地的前提下討論〔前面提到拖曳木材、驅趕牛馬等〕。然而律典放寬規定的文字看似寬鬆，其內在精神卻極為嚴謹，因此一切都是通盤開許給無心掘地的情況〔《戒疏》原文〕。由此看來，《僧祇律》若是無心之失亦可開許，而《四分律》若是故意掘地也算違犯〔凡是與上文相違背之處，都應當依照這個標準來裁決〕。第十一條戒律〔佛陀住在曠野城時，因為先前造房砍伐了神樹，被非難說這不是沙門之法，佛陀呵責後制定此戒〕。「壞」讀作怪，是毀損的意思。破壞即是造作的惡業，生長的植物即是所犯的對象環境，禁絕斷除這種過失就稱為戒。

【1172-0003】資持記/09b_中三上#17
【原文】指緣同前，但改一二為生種耳。正名中，初標戒本。鬼者下，引律牒釋。注中，初示村義。故下，遮濫。恐有迷名，謂毀神廟，諸部即下所引。《十誦》中蟁音盲，合作虻；蛺蝶上古協切，飛蛾也。《僧祇》兩分，即名草木為鬼神村。釋初緣中，《四分》，初示生種。
【譯文】指示的犯戒緣由與前一條相同，只是把其中的一兩項抽換為生長的植物而已。正式定名中，首先標出戒本的名稱。「鬼者」以下，引用律文逐句解釋。注文中，首先指出神鬼聚集村落的含義。「故」字以下，防止名義混淆。唯恐有人被字面迷惑，誤以為是毀壞鬼神廟宇；各部派的說法即是下面所引述的。《十誦律》中的「蟁」字讀音同盲，應當寫作「虻」；「蛺蝶」的蛺讀古協切，是指飛蛾。《僧祇律》將其分為兩類，也就是直接把草木稱為鬼神棲息的村落。解釋第一個條件中，《四分律》首先指出有生命生長的植物種類。

【1172-0004】資持記/09b_中三上#18
【原文】五種者，古記引《首疏》云：合五為三，一根種分二〔不假節生者名根種，如薑芋蘿萄；若假節生者名覆羅種，如蘆葦芹蓼等。〕；二枝種亦二〔不假節生名枝種，如柳榴之類；假節生名節種，如藕蕪等。〕；三種子，子復生子，故名子子〔如五穀等〕。注雜種者，離四種外，總收一切。
【譯文】所謂五種植物，古代記錄引用《首疏》說：將五種合併為三類：第一是根種，分為兩種〔不藉由節點生長的稱為根種，如生薑、芋頭、蘿蔔；若是藉由節點生長的稱為覆羅種，如蘆葦、芹菜、水蓼等〕；第二是枝種，也分為兩種〔不藉由節點生長者稱為枝種，如柳樹、石榴之類；藉由節點生長者稱為節種，如蓮藕、荸薺等〕；第三是種子，種子種下又能生出種子，所以稱為子子〔如五穀雜糧等〕。注文所說的「雜種」，是指除了上述四種之外，總括收納其餘一切植物。

【1172-0005】資持記/09b_中三上#19
【原文】《戒疏》則指芹竹〔芹菜與竹〕，《僧祇》以為勒蓼，具如上注。若下，次明損壞。斫截墮，注戒作墮落。上明全生者。若斷下，明萎乾者。多分生，謂生分過半也。《僧祇》，初科，先配五種。莖即枝也。心即覆羅。蘿勒蓼即蘭香也。揉𫝽，兩手相錯。
【譯文】《戒疏》則具體指稱芹菜與竹子，《僧祇律》認為是羅勒與水蓼，詳細內容正如上面注文所載。「若」字以下，其次說明毀損破壞。砍斷或截落，戒本的注文寫作「墮落」。以上是指完全鮮活的植物。在「若斷」以下，說明枯萎乾燥的植物。多數鮮活，是指具有生機的部分超過了一半。《僧祇律》的第一科，先對應列出五種植物。「莖」就是指樹枝。「心」就是指覆羅。「蘿勒蓼」就是蘭香草。揉搓，是用兩手相互搓揉。

【1172-0007】資持記/09b_中三上#21
【原文】注二棗者，熟謂在樹熟者；生如青棗，以火觸故，表裏皆淨，故得合核。膚謂皮膚無核有子。注蓽茇，味辛而香。奈似林檎而小。創字平呼。𥢶者，《指歸》云：麁糠皮故，謂之𥢶，此果最小，皮如麁糠；《輕重儀》中，謂松柏子也。角即菱豆也。注中蒿者，此屬子種；
【譯文】注文中的「二棗」，熟棗是指在樹上完全熟透的；生棗就像青棗，因為經過火熱觸碰處理，表皮與內核都算清淨，所以可以連同果核一起保存。「膚」是指外皮與果肉，指無堅硬外核而有細小種子的果實。注文中的蓽茇，氣味辛辣而且芳香。柰果類似蘋果但體積較小。「創」字念平聲。「𥢶」這個字，《指歸》說：因為有粗糙的外糠皮，所以叫作𥢶，這種果實極小，外皮如同粗糠；在《輕重儀》中，認為是指松柏的果仁。角就是菱角或豆莢。注文中的「蒿」，這屬於種子類；

【1172-0008】資持記/09b_中三上#22
【原文】恐謂葉隔不成火淨，故準𥢶角以決之耳。但下，示作淨法。已前五果，火淨亦通；餘淨各局，在文可尋。行護中有十一節，隨次點示，初明總淨。畏年少者，恐彼不作淨語故。言春去者，由先已淨，不須淨語。已前種果，皆可準之，故云餘事類知。若以下，明壞種。
【譯文】唯恐有人認為葉片阻隔就不算用火淨化成功，所以比照𥢶果與豆角來加以裁決。在「但」字以下，說明施行清淨法的具體作法。前面所說的五種果實，用火淨化的方法全都可以通用；其餘的淨化方法則各有局限，在律文脈絡中可以查考。日常防護的規定共有十一個節段，依序指點說明：第一說明總體清淨。畏懼年輕人，是擔心他們不會依照如法言語作清淨口令。所謂交代「拿去舂米（舂去）」，是因為先前已經清淨處理過，不需要再作清淨口令。前面列舉的種子與果實，都可以依此類推，所以說其餘事情可以比照得知。「若以」以下，說明毀壞種子。

【1172-0009】資持記/09b_中三上#23
【原文】越是方便，死提即果罪。若草下，明踐草。言欲令者，即是故心。石下，明護衣毛。石衣即苔蘚；毛，謂蒸潤生者，皆有生性故。雨下，明舉物。與下不犯相違，故注和會。夏下，明暫繫。夏有時限，故遍言之。泥下，明緣開。水下，明護浮萍。擲石至天者，何有此理？開必須法，令無自任。
【譯文】產生方便罪是輕微過失（越濟），徹底毀壞致死（墮罪）則是根本結果的重罪。「若草」以下，說明踩踏青草。說「存心想要」，就代表是有故意的主觀意圖。「石」以下，說明保護石衣與菌毛。石衣就是苔蘚；菌毛，是指潮濕受熱所滋生的菌絲黴斑，它們都具有生長繁衍的自性。「雨」以下，說明拿起物品。此處與下文不犯戒的規定相矛盾，所以注文做了調和融通。「夏」以下，說明暫時繫綁。夏季有固定的時間限制，所以通盤作了要求。「泥」以下，說明開許的特殊因緣。「水」以下，說明保護浮萍。投擲石頭飛到半空中，世上哪有這種道理？既然開許就必須遵守如法程序，不可任由自己隨意行事。
