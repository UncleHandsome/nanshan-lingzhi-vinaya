# 校閱材料　第1102檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1102-0001】資持記/07b_中一下#47
【原文】準此經文，則以根本隔出業戒；可證七支不攝餘戒，故云故知等。此二句，若取偶對，合云：七支根本所收；或不改上句，則下句合云：種類業戒所攝，在文順便。今戒本中，初篇四重，及九十中，兩舌、毀呰、口綺，則七支戒；除此已外，皆業戒也。〔舊記以殺妄大小，謂七支攝九戒，非也。此亦輕重不同，何得相攝。
【譯文】依照這段經文，就是用根本罪把其餘業戒隔開排除在外；由此可以證明身口七支不能包攬其餘各戒，所以才說「故知」等等。這兩句文詞如果要講求對仗工整，理應說：「七支由根本所收攝」；或者若不更改上一句，則下一句理應說：「種類由業戒所收攝」，這樣在文意上才順暢通達。如今戒本中，第一篇的四波羅夷（身三及大妄語），以及九十單墮罪當中的兩舌、惡口（毀呰）、綺語（口綺），合計即身口七支戒；除此以外的所有條目，全都是業戒。〔過去的記疏把殺生戒與妄語戒依輕重大小拆開，認為七支涵蓋了九條戒，這是錯誤的。這也是屬於輕重不同，怎麼可以這樣牽強相攝。〕

【1102-0002】資持記/07b_中一下#48
【原文】問：據此所解，即應不立種類耶？答：前後兩解，大途不異；但前以七支，總攝種類；後以七支，自為根本；別立業戒，統收種類。多見妄解，故此細釋。作句中。前約根本種類，統收眾戒；然與業道，容有相濫，故須料簡。初句。後三者，即貪瞋邪見；化教所禁，故名善；律所不制，故非戒。
【譯文】有人問：按照這裡的解釋，豈不是就不成立「種類」的說法了嗎？回答：前後兩種解釋，大體上並沒有多大差異；只是前一種解說是用七支來總括統攝各種流類；後一種解說則是把七支自己當作根本，另外安立業戒來統攬各種流類。因為經常看見有人胡亂解釋，所以在此作詳細剖析。在「辨析四句」當中：前面是就根本與種類來統攝一切戒律；然而這些名相與化教的業道，容易產生混淆濫用，所以必須加以辨析揀別。第一句中：所謂「後三種」，就是指貪心、瞋心、邪見；這是化教所禁止的，所以稱為「善」；但律宗並沒有制定相關的制教罰則，所以「不是戒」。

【1102-0003】資持記/07b_中一下#49
【原文】《四分》重緣，相同十業，可入戒收；若約菩薩，十善俱戒，如是知之。第三句中，初示相。以下，雙釋。不要期者，顯示世善無願體也。反此者，謂有要期受體，然後如體而修。問戒儀中。上明戒體周遍，頗濫律儀，故當分折。答中，初以義略分。衍，猶遍也。以律訓法，法即遍制，恒令不起，不待對事；
【譯文】《四分律》中對於屢次起念的重緣，在行相上等同於後三種意業，可以納入戒律所收攝；如果就菩薩戒而言，十善法全都是戒，這點必須明白。在第三句中，起初標示行相。在「以」字以下，對這兩者作雙重解釋。所謂「沒有立誓期限」，是顯示世間善行並沒有立誓獲取的戒體。所謂「與此相反」，是指事先立下期限而領受了戒體，然後再順應著戒體去落實修持。在詢問「戒儀」當中：上面闡明戒體周遍法界，語意上頗容易與律儀混淆，所以應當加以區分剖析。回答當中，起初從義理上作簡略區分。「衍」，意思是普遍。用「律」來解釋法度，法就是普遍的制度，恆常使過失不起，不必等待面對具體事境才發生；

【1102-0004】資持記/07b_中一下#50
【原文】戒者訓禁，禁即對過，防遏為功，必約對境；二皆有相，故竝名儀。如下，舉善惡委示，又二；初善，二惡。尋文可解。三戒行中，初科。言二戒者，示現隨戒義故。方便言通，且約遠離對治之智。正釋中，初文，前約法明。要期，即盡形斷惡，決絕之誓；思，即緣境周遍，慈愍之心；
【譯文】「戒」則是訓釋為禁止，禁就是面對具體過咎，以防範阻遏為功用，必定要在面對境界時才談得上；兩者都具有外在表相，所以都稱為「儀」。在「如下」的文句中，列舉善法與惡法作詳細說明，又分為兩部分：一是善法，二是惡法。順著文句尋求便能理解。在第三項「戒行」當中，第一科。說到「二戒」，是為了顯現隨順戒體的隨戒意義。方便的說法雖然寬通，暫且是就遠離惡緣與對治煩惱的正智來談。在正面解釋中，第一段文字，先就法理來闡明。立誓期願，就是誓願盡形壽斷除一切惡業的堅決誓詞；思慮心，就是緣念一切境界周遍無餘的慈愍心；

【1102-0005】資持記/07b_中一下#51
【原文】合此二心，混為一願，即受體也。稱願者，合上要思，即隨順義。譬下，次約喻顯。初營宮宅，喻求聖道；下喻受隨，可知。營搆，謂造立屋宇。相須中，初敘互缺，先明缺隨。寒露者，喻無善蓋覆。弊，謂困死，喻沈惡道。若下，次明缺受。隨生死者，但是世善，非道基故。
【譯文】將這兩種心合而為一、融合成一個大願，這就是受戒的體性。所謂「稱合本願」，就是順應符合上述的誓願與深思，也就是隨順教戒的意思。「譬如」以下，接著藉由譬喻來顯發。起初建造宮室宅第，比喻追求出世聖道；下文比喻受體與隨行，道理顯而易見。「營構」，就是建造房屋殿宇的意思。在「相輔相成」當中，起初敘述兩者互有欠缺的情況，先說明缺少隨行的弊病。所謂「受寒露風吹」，是比喻沒有善法功德作為覆蓋庇蔭。「斃」，就是困頓致死，比喻沉淪墮落於惡道之中。「若」字以下，接著說明缺少受體的弊病。說「隨順生死輪迴」，是因為這只屬於世間善法，不能作為出世解脫之道的根基。

【1102-0006】資持記/07b_中一下#52
【原文】又局狹者，緣境不遍，惡心存故。穿窬，謂穿壁；窬，牆也。由無外院，其間房室，容彼穿窬。此明無受防約，雖修善行，還為塵擾，喪失善根；如賊穿窬，盜竊財寶也。必下，示相須。問中。上明相須，其功一等；招生感果，必有親疎，故須顯示。答中，初對顯親疎。上二句，明受疎也。必下，明隨親也。
【譯文】又說這種善行「局限狹隘」，是因為緣念境界未能普及一切，內心殘存著惡念的緣故。「穿窬」，穿是指鑿穿牆壁，窬是指跨越矮牆。由於沒有外圍院落的防護，內部的房間就很容易任由盜賊鑿牆穿壁。這是說明如果沒有受體的防範約束，縱然修持種種善行，依然會被外在塵境所干擾侵損，徹底喪失善根；如同盜賊鑿穿牆壁矮牆，將家產財寶盜竊一空。在「必」字以下，揭示兩者必定要互相憑藉。在提問中：上面闡明受戒與隨行必須相輔相成，其功用等齊並重；但引發後續受生感得果報時，兩者必定有親疏親近的分別，所以必須加以澄清顯示。回答中，起初相對顯發兩者的親疏關係。上面兩句，說明受體較為疏遠。「必」字以下，說明隨行更為直接親切。

【1102-0007】資持記/07b_中一下#53
【原文】以壇場初受，頓起虛願；對境防約，漸修實行；行即成因，因能感果。故《業疏》云：故偏就行，能起後習；不約虛願，來招樂果。然受隨二法，義必相須；但望牽生，功有強弱。隨雖感果，全自受生；受雖虛願，終為隨本。是則懸防發行，則受勝隨微；起習招生，則隨強受弱。
【譯文】因為在戒壇上當初領受時，頓時發起的是尚未落實的誓願（虛願）；唯有在面對境界防範約束時，才能逐步修證踏實的行持；行持當下就構成真切之因，真因才能真正感召出世果報。所以《業疏》說：因此偏就實質行持來說，它能引發後續的熏習善性；絕非光憑虛泛的願心，就能招感未來的安樂果報。然而受戒與隨行這兩種法，在義理上必定相輔相成；只是單就牽引受生感果而言，力量的強弱各有不同。隨行雖然直接感召善果，但它的力量完全是從最初的受體所生發；受戒雖然屬於初期的誓願，卻終究是隨行的根本基石。這樣看來，若論預先防範、發起行持，則是受體殊勝而隨行微細；若論熏起習氣、感召果報，則是隨行力強而受體顯弱。
