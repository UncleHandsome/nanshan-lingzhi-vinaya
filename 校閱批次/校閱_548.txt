# 校閱材料　第548檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】第三段說明懺除偷蘭遮罪的方法，另外分為兩部分：一是說明罪過的輕重，二是說明懺悔的儀式。

【548-0019】04_比丘尼鈔/06a_卷下之下#2
【原文】第一出罪輕重復有二節一初篇下從生方便偷蘭遮二不從篇下生者名為獨頭偷蘭遮第一從生方便復有三品一上二中三下故十誦云從初篇下生重此近方便蘭應一切僧中懺若初篇下生輕二篇下生重者應界外四比丘眾懺若二篇下生輕者應界內一比丘前懺上來雖分輕重然未識罪名自下具顯出之後時興懺令識易行。
【譯文】第一部分說明罪過的輕重，又分為兩節：第一節是由根本重戒前方便所衍生出的偷蘭遮罪，第二節是不從根本戒衍生出的獨立偷蘭遮罪。第一節由根本戒衍生出的方便罪又分為上、中、下三品。因此《十誦律》說：由第一篇根本重罪衍生出的重方便，屬於接近成罪的偷蘭遮，應當在全體大眾僧中懺悔；若是第一篇衍生出的輕罪，或第二篇衍生出的重罪，應當在界外由四位比丘所組成的僧眾前懺悔；若是第二篇衍生出的輕罪，應當在界內對一位比丘懺悔。前面雖然區分了輕重，但尚未列出具體罪名，以下完整列舉出來，讓後人想要懺悔時容易明白且便於遵行。

【548-0020】04_比丘尼鈔/06a_卷下之下#3
【原文】初篇生重者就尼八重中且逐數犯者述其三五如欲犯婬共男子身口交觸未得暢遂得初篇方便重偷蘭遮或欲盜五錢已捉物著因緣不遂得重偷蘭遮或受男子摩觸腕已前膝已下隣近重境得重偷蘭遮或欲犯八事已犯前七垂犯第八遇緣不遂時重偷蘭遮或知他犯重故作心覆未經明相臨曉悔露得重偷蘭遮如是等罪並依十誦一切僧中悔若從初篇生輕者如欲犯婬犯盜等已隣近人物者因緣不遂得初篇方便輕偷蘭遮二篇生重者如欲媒嫁受男家語將報女家受女家語還男家臨報還悔得重偷蘭遮或言人口說至官欲道名字方便還悔得重偷蘭遮或獨入水待後伴欲雙脚上岸方便還悔得重偷蘭遮或獨行至村臨越村界方便還悔得重偷蘭遮或獨宿離伴伸手外意臨至明相方便悔露得重偷蘭遮或獨在後行欲俱離見聞垂離還悔得重偷蘭遮上來兩篇輕重二位依十誦界外四比丘前懺。
【譯文】從第一篇衍生出重罪的情形，就比丘尼的八重戒中，暫且針對常犯的幾條列舉三五項：例如想要行淫，與男子身口相互接觸，但尚未得逞，便犯了第一篇方便重偷蘭遮；或者想要偷盜滿五錢的財物，已經動手捉住財物，但因緣不湊巧未能得手，得重偷蘭遮；或者接受男子撫摩接觸，位置在手腕以下至手掌或膝蓋以下，因為接近重罪的部位，得重偷蘭遮；或者想要犯下八事重罪，已經犯了前七事，將要犯第八事時遇到阻礙而未能得逞，得重偷蘭遮；或者明知他人犯了重罪，故意存心包庇隱瞞，未經過拂曉時分，在清晨天亮前發露悔過，得重偷蘭遮。像這類的罪，都要依照《十誦律》在全體大眾僧中懺悔。如果從第一篇衍生出輕罪的情形，例如想要行淫或偷盜，已經接近對方的身體或財物，因緣不湊巧而未能成事，得第一篇方便輕偷蘭遮。第二篇衍生出重罪的情形，例如想要為人撮合婚姻，接受了男方的傳話將去回報女方，又接受女方的傳話回報男方，臨到回報時中途反悔，得重偷蘭遮；或者犯言人戒，前往官府口頭陳訴，將要說出對方姓名的當下及時反悔中止，得重偷蘭遮；或者獨自入水過河，在水裡等待後來的同伴，雙腳將要踏上對岸時中途反悔，得重偷蘭遮；或者獨自走到村落，臨要跨越村界時中途反悔，得重偷蘭遮；或者獨自露宿，離開同伴超過手臂伸長的距離，本想挨到天亮，在拂曉前反悔發露，得重偷蘭遮；或者獨自走在隊伍最後，想要完全脫離前人的視聽範圍，將要離開時中途反悔，得重偷蘭遮。以上這兩篇的輕重兩類罪位，都依照《十誦律》在界外四位比丘面前懺悔。

【548-0028】04_比丘尼鈔/06a_卷下之下#11
【原文】僧今和合。何所作為。答。單白懺。重偷蘭遮羯磨。
【譯文】「僧眾如今和合聚集，要做什麼事呢？」大眾回答：「進行單白和僧、懺悔重偷蘭遮罪的羯磨。」

【548-0029】04_比丘尼鈔/06a_卷下之下#12
【原文】大姉僧聽。比丘尼某甲。故犯不淨行。己共男子。身口交觸。未得暢遂。犯初篇方便。重偷蘭遮罪。不憶數。或犯盜用四錢。得獨頭重偷蘭遮罪。不憶數。今從眾僧。乞懺悔。若僧時到僧忍聽。我受比丘尼某甲懺悔。白如是。
【譯文】「請各位大姊僧眾聽弟子陳白。比丘尼某甲，故意犯了不淨行，已經與男子身體和言語互相接觸，但尚未完全成事，犯了第一篇方便重偷蘭遮罪，次數記不清。或者犯了盜用四錢，得獨立重偷蘭遮罪，次數記不清。如今向大眾僧乞求懺悔。若僧眾時機合適且僧眾聽許，我便接受比丘尼某甲的懺悔。事情陳述完畢。」
