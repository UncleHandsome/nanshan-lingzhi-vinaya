# 校閱材料　第101檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【101-0001】01_行事鈔/05c_卷中之一#17
【原文】《明了論》中，盜義極多。且約眼耳鼻舌身心，於六塵起不如法行；或犯重，或犯輕；若人食毒，或為蛇螫，犯如此罪。若人偷地水火風空等界，亦犯波羅夷，悉從盜戒判。解云：有諸仙人，是胸行蛇毒藥師，作仙人書字，見者皆愈，欲見者須價直；比丘被害，偷看之，計直犯重。乃至他人學得，偷看亦爾。若誦呪治病，欲學須直；比丘密聽，計直得重。偷嗅甞觸亦如是。知若祕方要術，病者心緣即差，得直方示，得直聽寫；比丘受法就師，心緣得差，不與價直，故犯重也。次約六界，前三可知。有呪扇藥塗，比丘偷搖不與價直。若起閣，臨他空界，妨他起造，即名盜空。論云：等者，等於識界，智慧屬識。人有伎兩，不空度他，須與價直；比丘方便，就彼學得，不與價直，即是盜識。自外諸緣，不可錄盡。但知非理損財解盜，無義不收。廣如《戒本䟽》說。
【譯文】《律二十二明了論》中，關於偷盜的定義極其廣泛。大略是就眼、耳、鼻、舌、身、意六根，面對六塵境界生起不如法的造作，有的犯重罪，有的犯輕罪。例如有人服毒或被蛇咬傷，為了求生而犯下這類盜罪。若是有人偷盜地、水、火、風、空、識等六界，也同樣結犯波羅夷，全都要依盜戒來判定。論中解釋說：有些仙人是精通對治蛇毒的藥師，他們繪製仙人咒字圖文，凡是看見的人都能痊癒，但想看的人必須付出報酬價金。比丘遭毒蛇咬傷，暗中偷看其咒字，折算其價值滿五錢便犯重罪；乃至他人花錢學得之後，比丘去偷看也是如此。若是誦念咒語治病，想學必須付錢，比丘暗中偷聽學會，折算價值滿五錢得重罪。暗中偷嗅香氣、偷嘗滋味、偷摸觸碰，也都是如此。明知那是祕方要術，病患只要專心觀想此方即可痊癒，醫者收了錢才肯示人、才准抄寫；比丘前往從師受法，藉此觀想而病癒，事後卻不給付代價，這便犯下盜戒重罪。其次就六界來說：前三界（地、水、火）依常理可知；風界如有人以持咒藥膏塗抹扇子，比丘暗中偷搖扇子取風而不給錢，便算盜風；若建造樓閣，凌空伸入他人的領空範圍，妨礙他人施工營造，這就名為「盜空界」。論中說的「等」字，是指等於「識界」，智慧屬於識界所攝；他人身懷技藝，不肯無償傳授，必須支付酬金；比丘施展巧詐方便，從彼處暗中學得技藝卻不付酬勞，這便是「盜識界」。除此以外的種種因緣，無法一一詳錄。只要懂得「非理損害他人財物即構成偷盜」的原則，一切盜相無不含攝在內。詳細內容如《戒本疏》中所說。

【101-0002】01_行事鈔/05c_卷中之一#18
【原文】大門第三盜非畜物。初明非人物。若有護者，望護主結。《五分》：取他覆塚旛蓋，神廟中衣；他所護物，他心未捨，直五錢犯重。《僧祇》：盜外道塔物，神祀舍物，得重；若無護主，隨境結之。故《十誦》：盜天神像衣及華鬘等，得偷蘭。《善見》：取諸鬼神物，及人繫樹物，無守護者，無罪。《薩婆多》云：取非人物，五錢已上，重偷蘭；四錢已下，輕蘭。今或多人，取諸神衣物者，據理，得不如上；必無人守，恐神護者，可擲卜而知捨吝。盜畜生物，《四分》無文，有人斷同大重者。故律云：鼠偷胡桃，積成大聚，比丘盜之，佛言波羅夷故。有解，非望畜生，還望本主；以鼠盜疑豫未決，望人猶是本主，故還就人結重。餘如他部。《十誦》：取虎殘犯吉羅，由不斷望故；師子殘不犯。《薩婆多》：一切鳥獸食殘，取者吉羅。
【譯文】大門第三盜非畜物。初明非人物。若是有人看管守護的物品，對著守護主結罪。《五分律》說：取走他人覆蓋墳塚的幡蓋，以及神廟中的衣服；凡他人所守護之物，他人心中尚未放棄捨棄，價值滿五錢者即犯重罪。《僧祇律》說：盜取外道塔中的物品、神祠廟舍中的物品，得重罪；若是沒有看管守護的主人，則隨對象境界結罪。所以《十誦律》說：盜取天神像上的衣服以及花鬘等物，得偷蘭遮。《善見論》說：取用諸鬼神的物品，以及世人繫掛在樹上的物品，若無人守護看管者，無罪。《薩婆多毘尼毘婆沙》說：取用非人之物，價值滿五錢以上，結重偷蘭遮；四錢以下，結輕偷蘭遮。現今或有許多人，拿取諸神像的衣物，按理而論，究竟可否取用，正如上文律論所分別判定；若必定無人守護看管，又恐怕神明自身慳吝愛護者，可以透過擲筊占卜，以得知神明是捨棄還是慳吝。盜取畜生所屬的物品，《四分律》中沒有明文，有人判定等同於犯大重罪（波羅夷）。如同律中所說：老鼠偷盜胡桃，堆積聚成一大堆，比丘將其偷走，佛說是犯波羅夷重罪之故。但有法師解釋：這並非對著畜生結罪，而是轉回對著原本的人類主人結罪；因為老鼠偷取物資，其主權歸屬尚猶豫未定，對人而言依然是原主，所以轉回對著人結重罪。其餘規定如同其他部派律典。《十誦律》說：取用老虎吃剩的殘肉，犯突吉羅（輕罪），因為老虎尚未徹底斷除回顧吃肉指望的緣故；若是獅子吃剩的殘食，取用則不犯戒（因獅子不食殘肉）。《薩婆多毘尼毘婆沙》說：一切鳥獸吃剩的殘食，取用者皆犯突吉羅。

【101-0003】01_行事鈔/05c_卷中之一#19
【原文】二明有主想。若作無主想，始終不轉，無罪；前後互轉，互得輕重。廣如〈持犯〉中。
【譯文】二明有主想。若是心中作無主之物想，從始至終不轉變其念頭者，無罪；若是前後心念互相轉變（例如起初作無主想，後轉為有主想而取），則交錯招致輕罪或重罪。詳細情況如同〈持犯〉篇中所載。
