# 校閱材料　第391檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【391-0001】02_戒疏/03c_卷一下之一#65
【原文】【疏】二、名「僧伽婆尸沙」者，《善見論》云「『僧伽』為眾，『婆』者為初，『尸沙』云殘」。謂犯此罪，眾僧前與覆藏，末後出罪。故本律云「僧殘」是也。由罪纏行人，非全淨用，僧作法除故也。《律》名此罪又云「有餘」，以行法不絕為稱。《母論》云：「如人為他所斫，殘有咽喉，故名殘罪。」《明了論》解云：所言「殘」者，僧中受房舍利養最在其外故也。
【譯文】【疏文】第二種名為「僧伽婆尸沙」，《善見律毗婆沙》說：「『僧伽』翻譯為大眾僧，『婆』翻譯為最初，『尸沙』翻譯為殘餘。」意思是說犯了這種罪的人，大眾僧最初給予其覆藏行法，到了最後由僧團作法解除其罪過。所以本律稱之為「僧殘」就是這個意思。這是由於罪垢纏繞著修行人，使其不再具備完全清淨的功用，必須由僧團集體作法來消除罪垢的緣故。《廣律》稱這種罪又叫做「有餘」，是因為修行戒法尚未被徹底斷絕而得名的。《毗尼母論》說：「就好比一個人被他人揮刀砍劈，唯獨殘留著咽喉一絲氣息尚未斷絕，所以稱為殘罪。」《明了論》解釋說：之所以稱為「殘」，是因為他在僧團中接受房舍分配與利養供應時，被排擠在最邊緣殘存的外圍之故。

【391-0002】02_戒疏/03c_卷一下之一#66
【原文】【記】次篇，四節教文，「殘」義皆異。《善見》，初翻梵名，云「眾初殘」。「謂」下，釋義。云「眾僧」者，即上「眾」義；「前與覆」者，即「初」義；「後出罪」者，即「殘」義。「眾」義是通，「初」、「殘」為別，以覆、出二法，皆眾作故。「故」下，引《律》，初示名同。「由」下，釋義，則與前別。「非全用」者，是「殘」義；「僧作法」者，即「僧」義。「《律》」下，示異名。根本不壞，對前為目。
【譯文】【記文】在第二篇之中，四處教理文獻對於「殘」的涵義解釋各自不同。《善見律》最先翻譯梵文名稱，稱作「大眾僧、最初、殘餘」。「意思是說」往後解釋其內涵。說「大眾僧」，就是對應上面的「僧伽（眾）」之義；說「最初給予覆藏」，就是對應「婆（初）」之義；說「最後為其出罪」，就是對應「尸沙（殘）」之義。「眾」的涵義是貫通始終的，而「初」與「殘」則是各別的階段，因為覆藏與出罪這兩種法事，都是由僧團大眾集體執行的。從「所以」往後引用本律，首先指出名稱相同。從「這是由於」往後解釋義理，就與前面有所不同。「不再具備完全功用」，是「殘」的意思；「由僧團作法」，就是「僧」的意思。從「《廣律》稱」往後顯示其異名。由於修道根本戒體並未徹底壞滅，所以相對前一篇而冠以這個名稱。

【391-0003】02_戒疏/03c_卷一下之一#67
【原文】【記】問：「前云眾法絕分，行法絕不？」
【譯文】【記文】有人問：「前面說犯第一篇者在僧團大眾法事中絕分，在修道行法中是否也絕分呢？」

【391-0004】02_戒疏/03c_卷一下之一#68
【原文】【記】答：「由行絕故，不堪預眾；今行不絕，懺復本淨，即堪同法。是則夷罪行法亦絕，僧殘眾亦不絕。」
【譯文】【記文】回答：「犯波羅夷罪的人，由於修道之行已經斷絕，所以不堪再參預僧團大眾的行列；如今僧殘罪則修道之行並未斷絕，懺悔之後即回復本來的清淨，因此依然堪可共同參與僧團法事。這樣說來，波羅夷罪是連修道之行也一併斷絕，而僧殘罪則是連僧團法事也並未斷絕。」

【391-0005】02_戒疏/03c_卷一下之一#69
【原文】【記】《母論》喻釋還對斷頭。《了論》約行別住治罰以釋。「僧中」即「僧」義，「在外」即「殘」義。
【譯文】【記文】《母論》用比喻來解釋，也是相對「斷頭」而作的對比。《明了論》則是依據行苦修「別住」等懲罰處境來解釋。「在僧團之中」就是「僧」的意思，「排在最外圍」就是「殘」的意思。

【391-0006】02_戒疏/03c_卷一下之一#70
【原文】【疏】三、名「波逸提」者，《十誦》云：「此罪墮在燒煑覆障地獄，故云『墮』也。」《明了論》解本音為「波羅逸尼柯部」，此云「應功用」也。有三義故：一、罪名輕細，難識好毀；二、性遮兩罪，其相交雜；三、人多輕陵，數犯其過。大須功用對治，勿令滋廣。上座部云「波質胝柯」，翻「能燒熱」。此罪報得大叫喚地獄，因時能燋熱心，果時能燒然眾生。
【譯文】【疏文】第三種名為「波逸提」，《十誦律》說：「犯這種罪的人，將會墮落在受燒煮、覆蓋障蔽的地獄之中，所以稱之為『墮』。」《明了論》解釋其梵文原本的讀音為「波羅逸尼柯部」，漢語翻譯為「應當精勤對治（應功用）」。這包含三種涵義：第一、罪名所涵蓋的行相極其輕微細小，不容易察覺其持守與毀犯；第二、本質惡與違制惡兩種罪性，其相貌交錯混雜；第三、人們多半輕慢忽視，從而頻繁違犯這些過錯。因此極為需要付出精勤功用來加以對治，切莫讓它滋生蔓延。上座部律典稱之為「波質胝柯」，翻譯為「能燒起熱惱」。犯這種罪的果報是墮入大叫喚地獄，在造因時能燒焦熱惱自心，在受果時能焚燒煎熬眾生。

【391-0007】02_戒疏/03c_卷一下之一#71
【原文】【記】第三篇名。初《十誦》中，「燒煑覆障」，乃地獄通名。準《雜心論》中，墮眾合地獄一晝夜，則夜摩天二千歲，人間十四億四十千歲。《了論》中，初翻名，「有」下，釋義。初、「輕細」者，入威儀分故；二、「性遮雜」者，三十並遮，九十中三十條屬性，六十戒是遮，廣如下釋；三、「輕犯」者，謂非重故。「大」下，結名。「上座部」者，彼論自引。上約對治，此就因果。文中獄名，與上《雜心》所出不同。
【譯文】【記文】這是第三篇的名稱。首先在《十誦律》中，「燒煮覆蓋障蔽」是各處地獄的通用名稱。若依照《雜心論》的說法，墮入眾合地獄受苦一日一夜，就相當於夜摩天二千歲，折合人間長達十四億四萬歲之久。在《明了論》中，首先翻譯名稱；從「這包含」往後解釋其義理。第一點「輕微細小」，是因為它已進入威儀節制的範疇；第二點「本質惡與違制惡混雜」，是因為捨墮三十條全部屬於遮戒（違制惡），單墮九十條之中有三十條屬於性戒（本質惡）、六十條屬於遮戒，詳細內容如下文所解釋；第三點「輕慢毀犯」，是說它並非重罪的緣故。從「極為需要」往後總結罪名。「上座部」的說法，是該論自己引述的。上面是從對治修行的角度立論，此處則是就因果業報立論。文中所舉出的地獄名稱，與前面《雜心論》所引出的名稱有所不同。

【391-0010】02_戒疏/03c_卷一下之一#74
【原文】【疏】五、名「突吉羅」者，如《律本》云「惡作、惡說」也。分身口業，故有斯目。《明了論》中，二業一名，俱為「惡作」；身口為非，無非鼓動故也。
【譯文】【疏文】第五種名為「突吉羅」，正如根本律典中所說，就是指「惡作、惡說」。因為區分了身業與口業的過犯，所以才有了這兩個名目。《明了論》中，身口二業統用一個名稱，全都稱之為「惡作」；因為身業與口業造作非理之事，無一不是內心造作鼓動所顯現的緣故。

【譯文】【疏文】正如過去古德解釋說：「對治罪過的藥法共有五種，為了對應這五種良藥，所以建立了五篇罪名。」
