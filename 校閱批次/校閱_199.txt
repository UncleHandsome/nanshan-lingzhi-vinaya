# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【199-0001】02_戒疏/09d_卷二下之二#34
【原文】【記】顯今中。初明理當。教無明判，義例決通，故云「意言」。「如有」等者，示須廣之意。晉左太沖作《三都賦》，豪貴傳寫，洛陽為之紙貴。「所」下，次引據。「常光」、「常身」，竝簡現起則有不定。「一丈」，或云一尋。佛身倍半，則磔必倍尺，故云「即如」等。音「率」為「律」，有本細注，疑是後加。「率」，猶數也。「長」下，示量。上明縱廣量，後引《僧祇》，出高下量。彼用魏朝一文，即是宋朝文二。今取姬周，應除二尺，故云「若通」等。
【譯文】【記文】在闡明今家正確見解中。首先說明義理應當如何。戒律教理雖然沒有明文硬性規定折算，但依據義例可以決斷貫通，所以謙稱「意言（個人淺見）」。說「如果有所省察」等等，是表示必須廣泛論述的用意。西晉左思（左太沖）撰寫《三都賦》，豪門貴族爭相傳抄，使得洛陽為之紙價高漲。從「所以」以下，接著引證文獻依據。「常光」與「常身」，都是排除佛陀特別顯大神變時的身量不定。「一丈」，有的說法叫作「一尋」。佛陀的身量是常人的加倍（常人八尺，佛身一丈六尺），那麼佛的磔手也必定是常人尺規的一倍，所以說「即如」等語。把「率」讀作「律」，某些版本有細字註解，懷疑是後人添加的。「率」，就是數額準則的意思。從「長度」以下，明確列出尺寸。上方說明了長寬的量度，後面引用《僧祇律》，指出了高度的標準。該律採用魏朝的一丈，換算成劉宋的尺規就是一丈二尺。現在如果採用周朝古制，就應當減去二尺，所以說「若通其本」等語。

【199-0004】02_戒疏/09d_卷二下之二#37
【原文】【註】彼比丘看無難、無妨處己，到僧中，脫革屣，偏露右肩，禮上座足，右膝著地，合掌白言：「大德僧聽！某甲比丘自乞作屋，無主，自為己。我今從眾僧乞知無難處、無妨處。」如是再三也。
【譯文】【註文】那位比丘先觀察確定此地沒有危難、沒有妨礙之後，來到僧團當中，脫去皮鞋，偏袒露出右肩，禮拜上座僧足，右膝著地，合掌稟白說：「大德僧伽請聽！某甲比丘自己乞討物料想要建造房屋，沒有施主，純粹為了自己。我現在向大眾僧乞請指劃裁定沒有危難、沒有妨礙的處所。」像這樣稟告三次。

【199-0005】02_戒疏/09d_卷二下之二#38
【原文】【疏】注中，廣列作之方法。初「看無妨難」者，以羯磨所因，在于妨難，必有作法，得罪不成，故先定基址，後方從乞。六門分之：一、能處分人是非；二、僧私二地須處分不；三、有妨難作法成不；四、處分法，約作於人處；五、不處分，罪分有無；六、沙彌已乞，受竟須不。
【譯文】【疏文】在注文當中，詳細列出了建造房屋的軌則方法。起初所說「觀察沒有妨礙與危難」，是因為僧團羯磨所依據的核心，就在於是否存在妨礙與危難；如果盲目作法，將結成非法得罪且羯磨不成，所以必須先選定地基，然後才向僧團乞請。這分為六門來分析：第一、能主持裁決指劃處所的人是否合法；第二、僧團共有地或私有地是否都需要指劃裁決；第三、若存在妨難，所作的羯磨能否成立；第四、指劃裁決的法式，是依據人還是依據處所而成立；第五、如果不經指劃處分，其罪名究竟是有還是無；第六、沙彌時已經乞法，受具足戒之後還需不需要再乞請。

【原文】【記】指授，釋注中，初科。前點注意。「六」下，列義章：初人；二、處；三、法；四、人法處三種合論；五、罪；六、下眾。
【譯文】【記文】在指授處所這段解釋注文中，這是第一科。前面先點出注文大意。從「分為六門」以下，列出法義的各章節：第一是論人；第二是論處所；第三是論羯磨之法；第四是將人、法、處所三者綜合論述；第五是論罪名；第六是論未具戒的下眾。

【199-0007】02_戒疏/09d_卷二下之二#40
【原文】【疏】初依律量觀，信與不信，信即依作，不信往觀。如《僧祇》中，「都無解羯磨者，一切往就作房處，一比丘唱云『僧為某比丘指授作房處』，三說亦得。若處遠、隔水等緣，但差二三人亦得。」若越年、異界、作私房多、妨難處，皆不成也。
【譯文】【疏文】第一門，依照律文的量度來觀察，分為此人可信與不可信兩種情況，如果此人誠實可信，就依據他的話准許動工；如果不可信，僧團就要親自前往察看。正如《僧祇律》記載：「如果僧團中完全沒有懂得主持羯磨的人，全體僧眾就一起前往造房的地點，由一位比丘唱言『僧伽為某比丘指點劃定造房處所』，宣說三遍也算合法。如果該處太過偏遠、有河水阻隔等特殊因緣，只差派二、三位比丘前往察看也可以。」如果是跨越年度、在不同結界之內、建造私房過多、或在有妨害危難之處，羯磨全都無法成立。

【譯文】【記文】在第三門的古師解釋中。第一句直接下判定。「如果是這樣」以下，提出疑難並解答。前面引用《律》文提出問難，顯然認為羯磨不能成立。回答則根據所防範的著眼點不同，認為依然有成立的道理，所以說「又」。從「正如」以下，引用律文為證。

【199-0016】02_戒疏/09d_卷二下之二#49
【原文】【疏】今解不成。毗尼因緣，三求無過，則成持也。此戒緣者，正妨難也。《戒本》所列，還分妨難，及後廣解，妨難愈彰。故《律》文中「互有不成」，何況俱者？必有作法，與法正違。眼看妨難，卓然而云「無有妨難」者，大可笑也。
【譯文】【疏文】現今的正確解釋是羯磨不能成立。戒律的因緣軌則中，乞人、乞地、乞如法這三種祈求都沒有過失，持戒方能圓滿成立。這條戒律制定的核心緣起，正是妨礙與危難。《戒本》中所列舉的罪相，依然是辨別妨礙與危難，到了後文詳細解釋時，妨害與危難的過患更加明顯。所以《律》文中明確指出「只要其中一者有妨難，羯磨就不能成立」，更何況是兩者都存在呢？如果在此情況下強行作法，就與戒法徹底相違。眼睜睜看著妨害危難歷歷在目，卻大言不慚地唱念「此處沒有危難、沒有妨礙」，這實在是太荒唐可笑了。

【199-0017】02_戒疏/09d_卷二下之二#50
【原文】【記】今解中。初句義斷。「毗」下，斥非。初約義斥。《戒本》廣解，文現可知。若據戒緣，不明妨難，或指二戒斫伐神樹，神欲加害，即為妨難。「故」下，次引文斥。《律》列四句：一、有妨有難，二、無難有妨，三、有難無妨，四、無難無妨。「必」下，三、約作法斥。
【譯文】【記文】在現今的正解中。第一句以義理直接判定。「戒律」以下，駁斥古師的錯誤見解。首先從義理上加以駁斥。《戒本》中的詳細解釋，經文極為明顯易懂。如果單從這條戒的最初緣起看，雖然沒有直接明言妨難，或者是指另一戒中砍伐神樹、樹神想要加害之事，這本身就是嚴重的危難。從「所以」以下，接著引用律本文駁斥。《律》中列出四種情況：一是既有妨又有難，二是有妨無難，三是有難無妨，四是無妨亦無難。從「如果強行」以下，第三、從羯磨作法本身的不實來駁斥。

【199-0018】02_戒疏/09d_卷二下之二#51
【原文】【疏】「若爾，前言二吉，此豈凡心？」
【譯文】【疏文】有人問：「如果不能成立，前面引律文說的『犯二個突吉羅』，難道是凡夫隨意說的嗎？」

【199-0019】02_戒疏/09d_卷二下之二#52
【原文】【疏】答：「此是處分先成，妨難後起。法成不壞，無殘可結，妨生不合，強作故吉。此是緣外相違故生，不壞前法，如受戒後難生，不失前戒相似也。」
【譯文】【疏文】答：「這是指處分羯磨在先已經合法成立，妨害或危難是後來才產生的。既然先前作法已經圓滿成立而不致毀壞，就沒有僧殘重罪可結；但後來妨害生起時本不應繼續動工，比丘卻勉強建造，所以才結犯突吉羅。這是因為作法因緣之外的境況產生了相違，並不會破壞先前成立的合法羯磨，就如同受具足戒之後才出現障難，並不會失去先前已得的戒體是相似的。」

【199-0020】02_戒疏/09d_卷二下之二#53
【原文】【記】釋古執中。初難，由前古師引此為據，故問通之。答中，初二句立理。「法」下，明開制。「此」下，釋開成之意。羯磨後生，故云「緣外」，如乞法時本無妨難，得法已後惡獸始來等。下引「受戒難生」為例，具戒者，汙尼、賊住，必無後生；二形、破內，永變非、畜，戒亦有失；邊、黃、五逆，暫變二趣，則無有失。今云「不失」，蓋據此耳。
【譯文】【記文】在化解古師執著的段落中。第一段提出詰難，由於前面古師引用這段律文作為依據，所以在此設問以通達其義理。回答中，前兩句樹立根本法理。「既然作法」以下，闡明開許與制罪的差別。「這是因為」以下，解釋羯磨得以成立的深層意趣。因為難處是在羯磨完成之後才發生，所以稱為「緣外」，就像乞法時本來沒有妨難，得法之後惡獸才搬遷過來等等。下文引用「受戒後生難」作為比喻，具足戒者若是玷污尼僧、賊住入僧，絕不會是事後生起的問題；若是變為雙性（二形）、損破男根（破內），永遠退墮非人、畜生道，戒體確實會喪失；但如果是邊罪、黃門、五逆罪，或暫時轉化為異類，戒體則不致失去。現在所說的「不失去」，大概就是根據這類情況而言。

【199-0021】02_戒疏/09d_卷二下之二#54
【原文】【疏】「若爾，人病衣重，病差法在不？」
【譯文】【疏文】有人問：「如果是這樣，病患比丘作法加持蓄長衣，等病痊癒之後，這長衣的免責法效還在嗎？」

【199-0022】02_戒疏/09d_卷二下之二#55
【原文】【疏】答：「不同也。以此要心有期，病差必違前法。如受戒後捨者，以遂要期便失。」
【譯文】【疏文】答：「這兩者不同。因為長衣免責的立心是有具體期限的，疾病痊癒就必定與先前的法式前提相違背。如同受戒之後自願捨戒一樣，只要滿足了當初設定的期限或願心，法效便隨之消失。」

【199-0023】02_戒疏/09d_卷二下之二#56
【原文】【記】次難中。以羯磨離衣，病差法失，故引為並。意言，既許難生不壞，亦應病差法存。答中，初句直破前難，「以」下，釋法失之義。「如」下，引例。「受戒後捨」，通指四捨。
【譯文】【記文】在第二個問難中。因為因病羯磨開許離衣，病好之後這項特權法效便自然喪失，所以古師引此作為對比質難。意思是說，既然允許事後妨難生起不破壞先前的羯磨，那麼生病加持的法效在病好後也應當繼續存在。回答中，第一句直接擊破前面的問難，從「因為」以下，解釋法效消失的內在法理。從「如同」以下，引用同類例子。「受戒後捨戒」，通指四種捨戒的情況。

【199-0024】02_戒疏/09d_卷二下之二#57
