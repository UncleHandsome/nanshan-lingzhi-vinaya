整體看下來，這批譯文水準不錯，专名（迦提月、功德衣、尼薩耆波逸提、阿蘭若）與疏／記／律／註的分辨都掌握得住。以下按「該改」與「可斟酌」分列。

---

## 一、比較要緊的問題

### 1. #98「後迦提一月滿」的時節讀法（最關鍵）

原譯：「三個月夏安居結束，**其後迦提月滿一個月**，居住在阿蘭若處。」

這句語意含混，容易被讀成「在迦提月這一個月**當中**」。但本疏 #105 明判「二、時。**列非時分**」，#112 又說「非受於五利」——可見道宣是把此句讀為「安居竟、其後迦提月也已**期滿**」，即已出功德衣時（非時），才有這條「蘭若開六夜」的適用。譯文若讀成「迦提月中」，就與疏判「非時」直接相違。

建議：「若比丘，夏安居三個月已結束，其後的迦提月一個月也已期滿（即已過功德衣時），住在阿蘭若處。」

### 2. #106「點文注也」譯錯

原譯：「『列非時』是**點明經文與注文的內容**。」

「點文注」是說：疏文「二、時」是總標，底下那句夾注「列非時分」是點示之注；不是「經文＋注文」兩者。而且此處是律／戒本，不宜稱「經文」。

建議：「疏中先說『時』，是總標第二句；『列非時（分）』則是點出文中的夾注。」

### 3. #106 科判断句：「戒本，第二，初科」

原譯「戒本第二句，這是第一科」把「第二」讀成「第二句」。依疏文結構（先「就戒緣中」，次「就戒本中」），應是「（釋）戒本＝第二大段，此是其中初科」；#109「次科」正好接問答。建議改譯為「戒本（第二大段），這是初科」。

### 4. #113「迦提一月夏竟常開」

原譯：「**迦提月滿一個月**是夏安居結束後**通行**的開許」。

- 「滿」是譯者加的，原文只作「迦提一月」，且與 #98 的「滿」混同，會攪亂時節判定。
- 「常」是恆常（夏竟即常開，不待作法），不是「通行」。

建議：「迦提這一個月，是夏安居結束後恆常開許的（不論有沒有受功德衣），上士也同樣霑此開許，所以文中列出。」

### 5. #101「若捨」

原譯「如果**捨棄**衣服」易被讀成丟掉。律中此處是「捨衣」（對人作法捨／捨與他人），與「捉衣」「至擲石所及處」同為解離衣之方。建議作「（對人）捨衣」。

### 6. 「經文」一詞（#106、#113 共三處）

前後 #96、#100 都用「律文」，此處忽稱「經文」，術語不一致且不合律藏文體，宜一律改「律文／戒本文」。

## 二、可再斟酌（語意偏移或讀來生硬）

| 段 | 原譯 | 建議 |
|---|---|---|
| #96 | 「被打搶奪雜物」 | 「打奪」是毆打＋搶奪，主語是賊；改被動且漏譯「打」。作「（賊來）毆打、搶奪（比丘的）雜物」 |
| #96 | 「律文顯示**該比丘**物品眾多」 | 「人物」泛指「人的物品」，不必坐實為某比丘。作「律文彰顯：人的物品眾多、積聚一處，就都稱為『什』」 |
| #97 | 「物品**本質**通於一切」 | 「體」指所詮之物體／體類，非「本質」。作「所指之物通於一切種類」 |
| #97 | 「難道只**剛好**是十件嗎」 | 「豈唯在十」＝哪裡只限於十。去掉「剛好」 |
| #97 | 「到底要加上什麼物品才能湊滿十件呢」 | 「未詳」的責難語氣可補：「不知（古師）在六物之外還加了哪些物，才湊成十件？」 |
| #100 | 「有疑慮恐怖的地方」 | 可點出所疑者為賊難：「有疑慮（疑有盜賊）、有怖畏危險的地方」 |
| #100 | 「留下其中一件衣服」 | 「一一衣」＝三衣中**隨任何一件**，可補「任何」 |
| #103 | 「依據**文義**分為十句」 | 「約文」＝依文、就文，不必加「義」 |
| #104/#105 | 「第一句、明指…」 | 「明指」略生硬；「一、人」即能犯之比丘。格式建議「第一句：人（能犯的比丘）」 |
| #105 | 「列出了非時的時段」 | 讀者難解，宜補注「非時＝非功德衣時，即迦提月滿後」，與 #98 呼應 |
| #109 | 「提問的意圖很清楚」 | 「可解」＝一看即懂、不須解釋。作「問意不難理解（故不別釋）」 |
| #110 | 「不斷奮勉向上推進功行」 | 「翹企望上」有仰慕企求上進之意，可作「仰慕企求上進而努力用功」 |
| #110 | 「一心務求少欲**知足**」 | 原文只「少欲」，「知足」為增譯 |
| #112 | 「功德衣是透過僧團作法而**擁有**」 | 重點在「五利須作法方有」。作「功德衣（的五利）須經僧中作法受得才有；迦提月的開許則不待作法，任運自然獲得」 |
| #107/#110/#114 | 「寬鬆的利益」 | 「寬利」指放寬戒限的五利，作「放寬（戒限）的利益」較清楚 |

---

## 三、體例建議

1. **增譯標記要統一**：#96「（誤把『什』當『十』）」、#113「（同列於此時開之中）」等括號補注很有幫助，但 #114「修持頭陀行的高士」是把記文的解釋直接塞進疏文而未標記。建議凡譯者所加一律用括號（或全用〔〕），標準一致。
2. **「今解」宜作「今師（道宣）的解釋」**，與「古解／古師」對舉，比「現在的正確見解」更貼切且少評價色彩。
3. 「六物」首次出現可補注（三衣、鉢、坐具、漉水囊），讀者才懂 #97 的破斥理路。

---

**小结**：真正需要動的是 #98 的時節讀法、#106 的「點文注」與科判、#113 的「常開」與衍「滿」、#101 的「捨」，以及「經文」一詞；其餘多屬用語精度問題。其中 #98 一改，#105「非時分」、#112「非受於五利」、#113 的問答邏輯才會連成一貫。
