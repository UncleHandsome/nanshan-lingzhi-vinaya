# 校閱材料　第449檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【449-0001】02_戒疏/05c_卷二上之一#74
【原文】【記】犯人中。初示父名。注云「須提那子」，即子從父名，西竺多爾。翻為「求得」，未詳何義。「其」下，出子名。初翻名。「如」下，釋義。初引《僧祇》釋。彼云「毗舍離城，有長者子，名曰『耶舍』。信家非家，捨家出家」等。「又」下，引《見論》釋。以其持信厭財，捨家入道，故云「明」也。
【譯文】【記文】在犯戒者身分的解釋中。首先說明父親的名字。註文說「須提那子」，也就是兒子依隨父親的名字來稱呼，西域大多有這樣的習俗。翻譯為「求得」，還不清楚其具體含義。「其子」以下指出兒子的名字。首先翻譯名字。「如僧祇」以下解釋其字義。首先引用《僧祇律》的解釋，該律說「在毗舍離城中，有一位長者的兒子，名叫『耶舍』。信家非家，捨家出家」等語。「又見論」以下引用《善見論》的解釋。因為他具足信心、厭棄財富，捨家修道，所以稱為「明」。

【449-0005】02_戒疏/05c_卷二上之一#78
【原文】【疏】就訶責中，初明比丘，後明佛者？欲顯比丘同徒同住，過犯先知，故前列也。如來三達，知見常圓，示同化儀，位尊殊隔，義無先知，故在後列。又解，理越常情，絕於鑽仰。今為同徒所訶，分當己位，容可勵己，剋意不為。後明佛訶者，玄軌之教，出於高軌，切磋之益，義存我友。亦彰比丘言無虗設，互相敦崇，用成同濟之道。餘語略之，下更不解。
【譯文】【疏文】在呵斥譴責之中，為何先敘述比丘同修的呵責，其後才敘述佛陀的呵責呢？這是為了顯明比丘們同屬同一個道場、同住在一起，過失必定是同儕先察覺知道，所以列在前面。至於如來的智慧通達三世，知見永遠圓滿無礙，只是為了示現符合教化的儀軌，且佛的尊位殊勝超絕，在世俗情理上不應表現為私下搶先察知，所以列在後面。另一種解釋是，佛陀的境界超越凡常之情，高深到無法揣摩仰望。如今先受到同修同伴的呵責，身分地位彼此相當，反而容易激勵自己，下定決心不再違犯。隨後才寫佛陀的呵斥，是因為根本大法的戒律教導，必須由至高無上的聖者確立規範，但同儕間切磋砥礪的助益，則寄託在道友身上。這也彰顯了比丘們的規勸並非虛設，彼此互相敦勉尊重，以成就共同修行解脫的道業。其餘的文句從略，以下各戒不再重複解釋。

【449-0006】02_戒疏/05c_卷二上之一#79
【原文】【記】犯相，呵意中。初牒問。「欲」下，釋通，又二。初約察知前後釋。「三達」等者，明佛非不先知。化物之相，示同後知。「三達」，《智論》云：「過去、未來、現在，此三種智，通達無礙故。」、「又」下，次約勸誡前後釋。初示聖意難測。謂其堅不可鑽研，其高不可仰視，故云「絕」也。「今」下，約義以求。初敘比丘呵。「後」下，明佛呵。「玄軌」，即所制戒法。「高範」，即佛之所行。「切磋」，喻規諫短失。此謂朋儔職在諫諭，師長主乎教誨。若不先呵，直爾白佛，顯同友無相成之義。律緣世相，法爾須然。上約立教須後。「亦」下，次明彰前故後。「餘」下，略指。上句略去餘說，下句指後例同。以下諸戒，多有二呵，大同此釋。
【譯文】【記文】在辨明犯相中呵責用意的段落。首先提出問題。「欲顯」以下進行解答會通，又分兩層意思。第一是依據察知時間的先後來解釋。「三達」等句，說明佛陀並非不能先知，但在化導眾生的外相上，示現如同常人般在同儕反映後才處理。「三達」，《大智度論》說：「對過去、未來、現在，具備這三種圓滿智慧，能夠通達無礙。」「又解」以下，接著從勸諫教誡的角度來解釋。前半段說明聖者的心意深不可測。如同堅硬之物無法鑽研，高山無法一眼望盡，所以說是「絕於鑽仰」。「今為」以下從事理的意義來探究。先說明同修比丘的呵責。「後明」以下說明佛陀的呵斥。「玄軌」就是佛陀所制定的戒律法則。「高範」就是佛陀本身的聖者行儀。「切磋」比喻互相規勸提醒缺失。這是說明同儕道友的職責在於勸導告誡，師長與佛陀則主持根本教誨。如果不先由同修呵責，直接跑去向佛稟告，就顯得道友之間缺乏互相成就勉勵的道義。戒律的緣起必須合乎世間人情事理，法爾如是自然應當如此。以上是從確立戒教必須置於最後來論述。「亦彰」以下進一步說明佛的呵斥是為了彰顯前面同修呵責的正確性。「餘語」以下為略示與指例之科。上一句是略去其餘紛紜的說法，下一句是指明後文各戒皆依此類推。以下各條戒多有兩次呵責，大體都符合這種解釋。

【449-0008】02_戒疏/05c_卷二上之一#81
【原文】【疏】初中，「於如來清淨法」者，略教法也。略教法意，總舉行體，莫非喪苦集，求滅道也。言「於欲無欲」者，思前貪境，名之為「欲」，察知妄起，名「無欲」也。言「斷渴愛」者，思後重貪，追境不捨如「渴」也。觀如此渴，非由境生，但是自心，如犬咬骨，故能斷也。此二集諦，世結之因。「破壞巢窟」者，世結果也。集因既傾，苦果自滅，故曰也。「除眾結縛」者，修道法也。「愛盡涅槃」者，證滅諦也。「乃作惡事」者，總結前辭以用訶也。
【譯文】【疏文】在第一部分中，「在如來的清淨教法中」，指的是佛陀最初所宣說的簡略戒教法門。略示戒教的意旨，是總括標舉修行的體系，無非是滅除苦諦與集諦，以求證滅諦與修持道諦。所謂「於愛欲中心無愛欲」，回思先前引發貪愛的境界，就稱作「欲」；覺察觀照到妄念生起而能自拔，就稱作「無欲」。所謂「斷除渴愛」，回思後續滋生的強烈貪戀，追逐外境不肯捨離，就像飢渴一樣，稱為「渴」。觀照到這種飢渴之感並非是由外境所產生，純粹是自己的妄心在作祟，就像狗啃乾骨頭自以為有肉味一樣，明白了這個道理就能夠斷除了。這兩句屬於苦集二諦中的「集諦」，是繫縛世間生死的根源。所謂「破除輪迴的巢穴」，指的是世間的苦果。招感苦難的集因既然已經被摧毀，痛苦的果報自然跟著熄滅，所以這樣說。所謂「消除一切煩惱纏縛」，是指修習出世聖道之法（道諦）。所謂「貪愛永盡的涅槃」，是指證悟清淨寂滅之理（滅諦）。所謂「竟然做出這種惡事」，是總結前面的言詞來予以深切責備。
