# 校閱材料　第168檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【168-0001】02_戒疏/02c_卷一上之二#69
【原文】【疏】又解：「假以世喻，略收皆盡；一往統舉，空、有所收。有中極貴，勿過王也；包納水陸，勿過海也；光涼明暗，勿過月也；出有大聖，勿過佛也。縱有餘類，竊比難矣。」
【譯文】【疏文】另一種解釋說：「如果借用世間的事物為喻，這四種比喻已經大致將一切意義收攬無遺了；總體統括來說，真諦的『空』與俗諦的『有』皆已含括在內。在『有』的世間中最為至尊極貴的，莫過於國王；包容接納水陸一切萬物的，莫過於大海；光芒清涼、破除幽暗的，莫過於明月；超脫於世俗之『有』的無上大聖，莫過於佛陀。即便世間還有其他物類，想要私下攀比也是極難為比的了。」

【168-0002】02_戒疏/02c_卷一上之二#70
【原文】【記】次答中，初總舉。「空有」即真俗二諦，攝盡世出世法。今此四喻，不出二諦。前三並俗有，後一真空。故知喻戒，義無不盡。「有」下，別示。「明」猶照也。「出有唯佛」，此據理諦，化相、住持，則通世諦。「縱」下，結顯。以超群獨勝，無及於王；深廣徧周，豈過於海；照迷濟世，唯月難倫；凡聖尊崇，獨佛無等。此外餘物不堪為喻，故云「竊比難」也。
【譯文】【記文】在第二種回答的段落中，首先作總體的列舉。「空與有」就是指真諦與俗諦二諦，收攝了所有的世間法與出世間法。如今這四個比喻，完全不超出這二諦的範疇。前面三個比喻全都屬於俗諦世間之「有」，最後一個比喻則屬於真諦出世之「空」。由此可知用它們來比喻戒律，在義理上是無不圓滿完備的。「在『有』」以下，是分別開示。「明」在此處如同「照耀」的意思。「超脫世俗之有唯獨佛陀」，這是依據真諦之理而言；若從佛陀的化身相貌與住持佛法的角度來看，則同樣通於俗諦。「即便」以下，是總結彰顯。因為超絕群倫、獨一無二的尊勝，沒有能比得上國王的；深廣普遍包羅萬象，哪裡能超過大海；照亮迷途、濟度世間，唯獨明月難以比擬；凡夫與聖人共同尊崇仰慕，唯獨佛陀無可等同。除此以外的其他事物都不足以拿來作為比喻，所以說「想要私下攀比也是極其困難的」。

【168-0003】02_戒疏/02c_卷一上之二#71
【原文】【疏】就後偈中，文分為三：初有半偈，總合上喻；次有一句，舉法屬人，明無虗制；後有一句，說教之時，非合上喻。
【譯文】【疏文】在後一首偈頌文之中，文字分為三部分：最初有半首偈頌，總結落實前文的四個比喻；其次有一句經文，指出戒法乃是由尊貴的聖人所親立，以顯明並非無端虛妄設立；最後一句經文，是明示宣說教法應當遵守的時限，並非屬於對應比喻的部分。

【168-0004】02_戒疏/02c_卷一上之二#72
【原文】【疏】就初文中。「一切眾律中」者，合明三藏所明群行，並有調伏業非之功，義稱為「律」，律即法也。「戒經為上最」者，指今所演如上四尊，既同傾仰，聞何不奉？並謂三乘之夷途也。
【譯文】【疏文】在最前一部分的文字中。「在一切各種律法之中」這句話，是總結說明三藏聖典中所開示的各種行持，全都具有調伏身口惡業的功德，在義理上都可以稱之為「律」，「律」也就是法度的意思。「《戒經》最為至高無上」這句話，是指如今所宣演的戒法，如同前面所說的四種至尊之物一樣，既然為大眾所共同傾慕瞻仰，聽聞之後又怎能不恭敬奉行呢？這都是三乘行者所必經的平坦康莊大道。

【168-0005】02_戒疏/02c_卷一上之二#73
【原文】【記】法合中，總合有三，初釋。以經、論二藏，通有「法」義，故云「義稱」，明非本翻也。下句中，即約行根住持，二藏不及，正宗行要，毗尼不如，故稱「上最」。「四尊」即前四喻所顯四義。「既同」等者，顯示序中推勝之意。「夷途」，平路也。
【譯文】【記文】在落實法理的段落中，總結法理分為三個層次，這是最初的解釋。因為經藏與論藏同樣具有「法度標準」的涵義，所以說是「義理上的稱呼」，藉此說明這並非律藏最初翻譯時的狹義本名。在下一句經文中，是著眼於戒律作為修行根基與住持佛法的功能，經藏與論藏實有不及之處；就佛法修行的正統要領而言，其他的毘尼律條也比不上《戒經》，因此稱之為「至高無上」。「四尊」指的就是前面四個比喻所顯明的四種殊勝義理。「既然共同」等語，顯露出序文推崇戒法殊勝的核心用意。「夷途」指的就是平坦寬廣的大路。

【168-0006】02_戒疏/02c_卷一上之二#74
【原文】【疏】又解：但餘二藏明律相處，皆名「眾律」，故論云「隨經律」是也。
【譯文】【疏文】另一種解釋：只要其餘經、論二藏中解說戒相律法之處，都可以稱作「眾律」，所以論典中所說的「隨順經教之律」指的就是此類。

【168-0007】02_戒疏/02c_卷一上之二#75
【原文】【記】次釋。雖兼二藏，不取定慧。「論」者，未詳何文。
【譯文】【記文】這是第二種解釋。雖然兼攝了經、論二藏，但並不採納其中的定學與慧學內容。「論」是指哪一部論典，文字上尚且未能詳究。

【168-0008】02_戒疏/02c_卷一上之二#76
【原文】【疏】又解：「一部律宗，雖明緣起、辨相、開遮、法聚等文，俱調身口，各有正儀，應同名『律』。但為非結正宗，不名為『最』；戒本一段，親起行基，言約義周，攝僧斯要，故文所云『戒經最』也。」
【譯文】【疏文】還有一種解釋：「整部律宗典籍，雖然廣泛闡明了制戒緣起、辨析犯相、開緣與遮止、法聚分類等經文，這一切都在調伏身口惡業，各自具備其端正的威儀，應當都統稱為『律』。只不過因為那些內容不是結集戒條的核心正統，所以不被稱作『最上』；唯獨戒本這一部分，直接作為生起一切戒行的根基，文字簡要而義理周全，是統攝僧團的最關鍵要務，所以經文中才說『以戒經最為至高無上』。」

【168-0009】02_戒疏/02c_卷一上之二#77
【原文】【記】後釋中。「緣起」等者，即二部戒本，初明國土、犯人、起過、白佛，即「緣起」也；後有廣解，即「辨相、開遮」也；戒本後有二十犍度等，即「法聚」也。「俱」下，釋眾律。「但」下，釋戒經為最。
【譯文】【記文】在最後一種解釋中。「制戒緣起」等語，是指兩部比丘與比丘尼戒本中，最初都會說明制戒的國土、犯戒的人員、生起何種過失、如何向佛陀稟白，這就是「緣起」；後面有更廣泛的分析解釋，這就是「辨相與開遮」；戒本之後附帶有二十犍度等規範，這就是「法聚」。「這一切」以下，解釋何謂「眾律」。「只不過」以下，解釋為何唯獨「戒經最為至高無上」。

【168-0010】02_戒疏/02c_卷一上之二#78
【原文】【疏】然末世鈍機，雖聞法勝，若非至聖所立，恐生疑慢，故重舉人，釋成法勝，是以文云「如來立」也。乘如實道，來成正覺，故曰「如來」也。過犯既興，隨便制約，故曰「立」也。法教所詮，為存止善，曰「禁戒」也。
【譯文】【疏文】然而末法世間的鈍根之人，雖然聽聞戒法無比殊勝，但如果不是最至高的聖人所親手立下的法度，恐怕會生起懷疑與怠慢之心，所以經文再度特別列出制教之人，以此證明並成立這項戒法的無比殊勝，因此經文中說「這是如來所制定的」。順應乘履如實之道而來成辦正等正覺，所以稱作「如來」。過失與犯戒的行為既然已經產生，隨即依此制定條規予以約束防範，所以稱作「制定」。佛法名教所要詮釋的目的，純粹是為了存持止惡防非之善（止持之善），這就稱作「禁戒」。

【168-0011】02_戒疏/02c_卷一上之二#79
【原文】【記】次句中，初示意。前列七佛，故云「重舉」。「乘」下，牒釋如來之名，文出《成論》。真理平等，體絕虗妄，故云「如實」；乘履此法，出現利生，故得斯號，即真、應二身也。「過」下，釋制戒。「止善」即「禁戒」義。
【譯文】【記文】在第二句經文中，首先說明經文的用意。前面已經列舉了七尊佛陀，所以說「再度列出」。自「乘」字以下，是引述並解釋如來的稱號，其文字出於《成實論》。真諦之理平等不二，其體性斷絕了一切虛妄之相，所以稱作「如實」；乘御踐履此法而顯現於世間利益眾生，所以獲得此一名號，這含括了真身（法身）與應身兩種身。自「過」字以下，解釋何謂制立戒律。「止善」（止惡即是善）就是指「禁戒」的實質義理。

【168-0012】02_戒疏/02c_卷一上之二#80
【原文】【疏】但以三乘既攝，必藉教成。故約晦望，折中之宜，時便為說。故曰也。

【168-0023】02_戒疏/02c_卷一上之二#91
【原文】【疏】何名「略教」？以佛初成道，將開化法。創起希仰，寄心無地。故先示行法，令依奉行。不待犯戒，未有罪故，不得懷疑起謗。略陳教法，故曰「略教」。
【譯文】【疏文】什麼叫做「略教」？因為佛陀最初成就聖道時，即將開展教化眾生的法度。弟子們初初生起仰慕向道之心，心念尚且沒有依託歸向之處。所以佛陀先開示修行的通則法度，讓大家依循奉持推行。這不需要等待有人犯戒，因為當時還沒有任何罪愆產生，也就不會對教法生起懷疑毀謗。只是簡略地陳述法度大綱，所以稱作「略教」。

【168-0024】02_戒疏/02c_卷一上之二#92
【原文】【記】初章，略名中。初標徵。「以」下，正釋。初二句示教興之時。「創」下，明機緣已發。「故」下，明立教。「不」下，示名相。「不待犯」者，異廣教故。「不得懷疑」者，謂若即制廣，容生疑謗，知機制略，不得生故。
【譯文】【記文】在第一章說明「略教」名稱的段落中。首先標出問題提出徵問。「因為」以下，是正式解答。前兩句指出教法興起的歷史時機。「初初」以下，說明眾生的求道機緣已經引發成熟。「所以」以下，說明建立教法的緣由。「不需要」以下，顯示其名詞的法相。「不需要等待有人違犯」是為了有別於後來的廣教。「不容許懷疑」是說如果在一開始就制定極其繁瑣的廣教條文，容易讓人起疑謗法；佛陀深知根機而制定簡略條文，正是為了杜絕疑謗的產生。

【168-0025】02_戒疏/02c_卷一上之二#93
【原文】【疏】言「廣教」者。由略名含，未曉前相，雖造諸非，不謂有犯。故須廣張網目，收攝罪聚。鈍根之流，聞便得解。因廣說故，名為「廣教」。
【譯文】【疏文】所謂的「廣教」。是由於簡略的名稱含意較為籠統，鈍根之人無法明瞭具體的造惡行相，縱使造作了各種非理的行為，也往往不認為自己是在犯戒。所以佛陀必須廣泛鋪展如同網目般細密的條文，用篇聚條目來收攝罪相。那些根機愚鈍的人，聽聞了詳細條文之後便能徹底明白。因為是廣泛詳盡宣說的緣故，所以稱作「廣教」。

【168-0026】02_戒疏/02c_卷一上之二#94
【原文】【記】廣名中。初標，「由」下，釋。準前釋略，亦應四節，但闕初時，廣在略後，自可知故。初明違略，即廣教機生。通禁三業，未列過相，故曰「名含」等。「故」下，明立教。「張網目」者，隨事別制也。「收罪聚」者，科約篇聚也。「因」下，結名。
【譯文】【記文】在說明「廣教」名稱的段落中。首先標出名稱，「是由於」以下，進行解釋。比照前面解釋略教的體例，此處本來也應包含四個環節，只不過省略了最初興起的時節，因為大家都知道廣教必然是在略教之後才出現的。首先說明違犯略教的情形，這正是廣教根機生起的緣由。略教只通盤禁戒身口意三業，並未詳列具體的犯過罪相，所以說「含意籠統」等等。「所以」以下，說明建立教法。「鋪展網目」是指隨著個別犯戒事件分別制訂條例。「收攝罪愆聚集」是指將罪過分門別類歸納於各篇聚之中。「因為」以下，是總結定名。
