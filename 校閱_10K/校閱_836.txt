# 校閱材料　第836檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【836-0001】02_戒疏/20a_卷四下之二#177
【原文】【律】若比丘，作骨、牙、角針筒，刳刮成者，波逸提。
【譯文】【律文】若有比丘，製作骨、牙、角的針筒，刳挖刮削完成者，犯波逸提罪。

【836-0002】02_戒疏/20a_卷四下之二#178
【原文】【註】若自作、教他作，成犯如上。比丘尼吉羅。不犯者，若鐵、銅、鉛、鍚、白鑞，若竹，若木，若葦，若舍羅草，用作針筒，不犯。若作鍚杖頭、鏢灒，若作傘蓋子及斗頭鏢，若纏蓋斗，若作鈎，若刮汙刀，若如意，若玦紐，若匕，若杓，若鈎衣鍸，若眼藥鎞，若刮舌刀、摘齒物、挑耳鎞、禪鎮、熏鼻筒，如是者並不犯。
【譯文】【註文】如果自己做、指使他人做，做成了便如同上述般犯波逸提罪。比丘尼則犯突吉羅罪。不犯戒的情況：若是用鐵、銅、鉛、錫、白鑞，或是用竹子、木頭、蘆葦、舍羅草等材質來製作針筒，不犯戒。如果是用骨牙角來製作錫杖頭、護杖鏢頭，或製作雨傘傘柄零件與骨架頂端斗頭，或用以纏繫傘斗，或製作懸物掛鈎、刮除污垢的刮刀、如意柄、衣紐帶扣、匙子、勺子、鈎衣環扣、塗抹眼藥的小撥棒、刮舌刀、剔牙籤物、挑耳杓、坐禪防睡的禪鎮、吸嗅藥氣的熏鼻筒等物，像這一類的物件全都不犯戒。

【836-0003】02_戒疏/20a_卷四下之二#179
【原文】【疏】尼多住寺，不喜遊行，作希故輕。
【譯文】【疏文】比丘尼大多長住寺院之內，不喜好四處遊方行腳，製作針筒的機率極少，所以罪責從輕。

【836-0004】02_戒疏/20a_卷四下之二#180
【原文】【記】戒本三句：一、犯人；二、「作」下，犯境；三、「成」下，結業。牒釋中，注文「尼」但犯「吉」，故示輕意。「住」猶在也。注不犯中，初開體別。「若作」下，次開作餘物，次列十八物，名相如《鈔記》委解。
【譯文】【記文】戒本文句共有三句：第一、犯罪的人；第二、「製作」以下，說明所犯的對象物境；第三、「完成」以下，確立結罪業報。提引解釋之中，注文提到「比丘尼」只犯「突吉羅罪」，所以特地指出罪責較輕的緣由。「住」就是常在的意思。注文不犯戒的條文中，首先開許材質種類不同。「若作」以下，接著開許可以用骨角製作其他合用物品，隨後列舉了十八種生活物品，其具體名稱與行相如同《事鈔記》中所詳細解說。

【原文】【律】八十七、過量尼師壇戒。
【譯文】【律文】第八十七條、製作過量尼師壇戒。

【836-0006】02_戒疏/20a_卷四下之二#182
【原文】【疏】過量坐具戒八十七。
【譯文】【疏文】製作過量坐具戒，為第八十七條。

【836-0007】02_戒疏/20a_卷四下之二#183
【原文】【疏】自下四戒，不聽過量者，並是信施，受用應法，則增本福，功德無限，比丘之法，趣得支身。今過量而作，長貪損施，無用之費，喪道增業，過患之甚，故制。
【譯文】【疏文】自此往下的四條戒律，之所以不准許尺寸過量，全都是因為這些物品來自於信徒的布施，如法合理地受用，就能增長施主原本的福報，獲得無量功德；而比丘的生活法則，只不過是求得能維持身軀生存即可。現在若是超越規格過量製作，不但增長自己的貪心，又損耗了施主的信施，徒造無用的浪費，既喪失修道本心又增添生死惡業，過失災患極為嚴重，因此制定此戒。

【836-0008】02_戒疏/20a_卷四下之二#184
【原文】【記】八十七，制意中。四戒並由過量，故總示之。初敘合宜，有二：一、受施須如法；二、為道合隨緣。「今」下，顯過患，違上兩意。準《鈔》具五緣：一、作坐具；二、過量；三、為己；四、自作使人；五、作成便犯。下四並同，但改初緣為異。
【譯文】【記文】第八十七條，制戒意圖之中。以下四條戒律全都是因為尺寸過量而制定，所以在開頭總體說明。首先敘述合理的行持，包含兩點：第一、接受信施必須合乎戒法；第二、為了修道應當隨緣知足。「現在」以下，揭示過患之處，正好違背了上述兩項原則。依據《事鈔》的規範，具備五個犯戒條件：第一、製作坐具；第二、尺寸過量；第三、為自己製作；第四、自己做或差遣他人做；第五、製作完成即構成犯戒。以下四條戒全體相同，只需置換第一個條件的物品名稱即可。

【836-0009】02_戒疏/20a_卷四下之二#185
【原文】【註】佛在舍衛。諸佛常法，若不受請，徧行房舍，見僧臥具敷在露地，不淨汙之，告諸比丘：「外道仙人離欲者尚無此事。聽為障衣、障臥具故，作尼師壇。」六群大作，比丘舉過，佛因制戒。
【譯文】【註文】佛陀住在舍衛國。諸位佛陀的一貫常法，如果在受請名單之外未赴請，便會巡視僧眾的房舍，見到僧團的臥具被鋪在露天泥地上，被不淨之物所污染，佛陀便告訴各位比丘說：「連遠離欲染的外道仙人尚且沒有這樣粗率邋遢的事。聽許你們為了遮擋護衛衣服、遮護臥具的緣故，製作尼師壇坐具。」六群比丘便將坐具做得極大，比丘們舉發其過失，佛陀因而制定了此戒。

【譯文】【疏文】在戒律緣起之中，起初是因為防止遺精排泄污染而聽許製作坐具以遮擋護衛，後來因為有人做得太過寬大，所以才藉此制訂了尺寸限制。

【譯文】【記文】解釋緣起故事之中。注文裡面，首先敘述巡行房舍時見到了過失。「告訴」以下，引出佛陀喝責的言詞。「聽許」以下，確立制度。「六群」以下，引發了過失，疏文解釋了後面這兩段。「為了污染漏泄」，就是指遮護衣物與遮護臥具的意思。

【原文】【疏】三、「更增」者，開緣也。還從本制，限外別增。若通取量，即䟦闍子非法之教，廣流於世。
