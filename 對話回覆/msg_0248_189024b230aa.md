這份是**路線 ③「無錨定盲翻 B ＋ 雙譯差分裁決」**的完整實戰測試指南。

這套做法的核心精神是：**不丟掉現譯 A 原本做對的 8 成排版與括注，而是用「完全沒看過 A 的盲翻 B」當作照妖鏡，把 A 藏在流暢文字底下的誤譯逼出來。**

---

### 一、流程總覽（兩步驟＋分流省流）

```text
步驟 1（盲翻 B）：只給【前後背景原文】＋【本次原文】→ 輸出純白話譯文 B（不寫檢查表）
                                ↓
步驟 2（差分裁決）：把【原文】＋【現譯 A】＋【盲翻 B】並排送審
  ├─ A、B 無實質分歧且無明顯錯 → 僅輸出 `PASS_A`（沿用 A，不重吐整段，極省 token）
  └─ A、B 有實質分歧或共同誤譯 → 輸出 `REVISED`（簡列分歧裁決 ＋ 以 A 為骨架融合修正後定稿）
```

---

### 二、步驟 1：盲翻 B（無錨定重翻）

因為完全不給現譯 A，所有「保留原譯／勿僅換詞」的包袱全部消失，提示詞可以變得極短、純粹專注在翻譯準確度上。

#### 1. `BLIND_PROMPT`（放入材料生成腳本）
```python
BLIND_PROMPT = '''你是精通南山律宗的白話譯者，負責將《四分律》與南山三大部／三大記（{scope}）原文忠實譯為現代白話。

請**只翻譯【本次待譯單元】**，前後背景僅供確認主詞、承前啟後指代與律制脈絡，不需翻譯。

### 翻譯原則：
1. **忠實完整**：不漏譯任何限定條件、小注或原文詞義；不無據增譯原文所無之實詞、修飾詞或未見之他書字眼。
2. **律義與邏輯**：{book_ctx}{shuji_rule}準確辨析古今異義、數理度量換算、部別律制與稱謂（依比丘／尼眾所屬部別區分對稱稱謂與專制名數）、持犯開遮與想疑心念、能所施受與對仗結構；無標點或錯標點古籍須依律脈重新斷句並確認引文起迄。
3. **現代漢語與體例**：只輸出流暢、語法自足的正體中文白話，消除文言直抄與歐化倒裝。簡短或須考證之引文於引號內保留原字並於外附白話，其餘譯成完整白話；獨立律典用《》不用〈〉，問答作「問：」「答：」。僅在「不補必嚴重誤讀」時加極簡圓括號（虛字旁不附括號，無把握不臆補定義）；原典明顯脫訛須補字者以 `〔補字〕` 或段末極簡括注標明。

### 請直接依下列格式輸出純白話譯文（嚴禁重貼原文，勿輸出逐句檢查表或說明文字）：
{out_format}
'''

def get_blind_prompt(is_nicao=False):
    if is_nicao:
        return BLIND_PROMPT.format(
            scope='鈔文',
            book_ctx='',
            shuji_rule='',
            out_format='【鈔文】……',
        )
    return BLIND_PROMPT.format(
        scope='疏文與記文',
        book_ctx='《業疏》所釋「文／注」指《隨機羯磨》文注，《戒疏》所釋指《含注戒本》文注，「律／本律」方指《四分律》；',
        shuji_rule='【疏】【記】須義理相契（勿把記文解釋搬入疏文正文，亦須使疏文保留銜接記文所釋實詞之字眼，並以疏文前提理解記文科判動詞）；',
        out_format='【疏文】……\n【記文】……',
    )
```

#### 2. 步驟 1 的模型與檢索設定（控制成本關鍵）
* **檢索設定**：保留按需檢索（`max_search=2`、`max_fetch=1`、`budget=2`），沿用你原有的 `SYSTEM_PROMPT` 即可（把第 5 條「寫進第 2 欄」略去，或直接禁附網址在譯文裡）。

### 三、步驟 2：雙譯差分裁決（Diff Judge）

材料結構把原本的 `■ 疏文（現譯）` 換成並排的兩份譯本：
* `■ 譯本 A（原現譯）`
* `■ 譯本 B（盲翻對照）`

#### 1. `JUDGE_PROMPT`
```python
JUDGE_PROMPT = '''你是南山律典雙譯裁決編輯。下方附有同一段原文的兩份白話譯文：【譯本 A（既有定稿）】與【譯本 B（獨立盲翻）】。

請**只針對【本次待審原文】**，拿 A 與 B 逐句對照原文進行「差分審判」：

### 裁決原則：
1. **以 A 為骨架、以 B 照盲點**：保留 A 原有的分段、標題結構與正確的消歧義／條件括注（不可因 B 沒補就誤刪）；同時**高度警覺 A 是否因讀起來順口而暗藏錯譯、主客顛倒、偷增原文無有之字、誤套比丘／尼制或遺漏限定條件**。
2. **重點審判分歧句**：凡 A 與 B 實質義理、主詞對象、限定條件、數理度量或專名解讀不同之處，必須回歸原文（{book_note}）與律制邏輯（必要時檢索查證），判別何者正確，或綜合兩者修正。
3. **防範共同盲點**：即使 A 與 B 譯法一致，仍須快速確認該處是否同犯「望文生義、古今異義誤讀、底本疑訛或體例錯誤」（獨立律典用《》、問答作「問：」「答：」、直引原字不混入白話、非引原字用標準正體字）。
4. **不為修辭重寫**：若 A、B 實質義理無分歧且無明顯錯誤，即使 B 用詞更口語，亦直接沿用 A，不作純修辭改動。

### 請依狀況二選一輸出（嚴禁重貼原文）：
- **狀況一（A 無實質錯誤，可完全沿用）**：只輸出兩行，**不要重寫譯文**：
  【結論】PASS_A
  【說明】A、B 實質義理一致，無須更動。

- **狀況二（發現 A 有錯或須採 B 之優點修正）**：依序輸出：
  【結論】REVISED
  【分歧與裁決】
  - 簡列有改動處：`[疏/記/鈔] 原文「……」｜A 作「……」vs B 作「……」｜裁決：……`
  【定稿譯文】（以 A 為底本修改後的完整純白話譯文，同一欄標籤只在開頭寫一次）：
  {out_format}
'''

def get_judge_prompt(is_nicao=False):
    note = (
        '《尼鈔》須依比丘尼律制與對舉「僧／尼」語境審斷'
        if is_nicao else
        '《業疏》文注指《隨機羯磨》，《戒疏》文注指《含注戒本》，「律」方指《四分律》，且【疏】【記】須雙向互洽'
    )
    fmt = '【鈔文】……' if is_nicao else '【疏文】……\n【記文】……'
    return JUDGE_PROMPT.format(book_note=note, out_format=fmt)
```

#### 2. 步驟 2 的執行設定
* **模型與思考**：這一步最適合用**最高階模型**（`xhigh` 或 Claude／Gemini 等強推理模型），因為它不須從頭翻譯每句，只做「裁判」；
* **檢索設定**：這一步**只在 A 與 B 打架且靠內文無法裁決時才搜**（`max_search=2`, `MAX_TOOL_ROUNDS=3`），若前面盲翻 B 已經幫你解掉大多數疑問，裁判很多時候 1 輪就判完了。

### 四、程式端接入必須注意的 2 個小調整

若你要直接複用現在的 `qwen_local.py` 與 `mk_review_materials.py` 跑路線 ③，務必避開這兩個地方：

1. **停用 `_split_col3()` 與 `_looks_pasted()`（重要！）**：
   * 你現在的 `_save_result()` 預設假設輸出裡有 `3. 修正後的譯文`，並會呼叫 `_split_col3()` 去截出第 3 欄來執行 `_strip_dup_labels()`。
   * 盲翻 B（沒有第 3 欄標題）與差分裁決（使用 `【定稿譯文】` 或 `PASS_A`）格式不同，直接共用原版 `_save_result()` 可能會切錯段落或錯判重貼！
   * 建議在 `qwen_local.py` 加一個環境變數（例如 `QWEN_RAW_SAVE=1`），在「盲翻／二審／裁判」模式下跳過 `_split_col3()`，只單純寫出完整 `content` 與 `_usage.json`。
2. **清理材料時剝除雙份譯文的段首標籤**：
   * 生成裁決材料時，無論是 `AI語譯/out/` 的 A 還是步驟 1 產出的 B，讀入時都要像你現在 `mk_review_materials.py` 一樣用 `re.sub(r'^【(?:疏文|記文|鈔文)】\s*', '', ...)` 剝乾淨再放進 `■ 譯本 A` 與 `■ 譯本 B`，避免多餘標籤干擾裁判。

### 五、10 分鐘實驗驗收法（用《回歸 11 組》實測）

直接拿同樣這 **11 題**（`業疏 01, 02, 03, 04, 07, 10, 17, 18 ＋ 尼鈔 35, 38, 39`）跑一輪路線 ③，重點看 **4 個指標**：

1. **錨定破除率（看 B 有沒有立功）**：
   原本單輪一直放過的 **`#01`（受體止持）**、**`#05`（唯三小界局在蘭若）**、**`#09`（屈曲／前學未達）**、**`#10`（僧界＝比丘界）**、**`#11`（急制／五衣）**，盲翻 B 有沒有靠自己翻對，並成功在步驟 2 讓裁判糾正 A？
2. **優點保留率（看 A 有沒有守住防線）**：
   原本單輪曾改壞的 **`#03`（成眾之緣／水合水）** 與 **`#06`（若不抬來或僧眾前往）**，有沒有因為「以 A 為骨架」而在步驟 2 完整保留下來？
3. **共同盲點率**：
   有沒有 A 跟 B 同時翻錯、結果步驟 2 卻誤放成 `PASS_A` 的句子？如果有，代表盲翻 B 跟產出 A 的模型太同質，換另一家模型做 B 就能大幅改善。
4. **總成本對比**：
   統計 `盲翻 B + 差分裁決` 兩步加總的 token 與耗時，對比單輪校對（或一審＋二審純找碴）哪一條 CP 值最高。
