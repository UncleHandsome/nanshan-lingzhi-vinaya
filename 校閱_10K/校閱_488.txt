# 校閱材料　第488檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【488-0001】02_戒疏/07a_卷二上之三#53
【原文】【疏】七、言「村」者，謂託村為處。《律》中，初約盜物，後盜村體，或以機關攻擊，強力水澆，言辭辨說，誑惑而取，皆重。
【譯文】【疏文】第七、說到「村」，是指依託村落作為處所。《律》中首先是說明在村中盜取物品，其次是說明盜取整個村落的本體，或者使用機關武力攻擊，或是依仗權勢強奪、用水沖灌，或是運用花言巧語辯說，以欺詐迷惑的手段強佔，這些都構成重罪。

【488-0002】02_戒疏/07a_卷二上之三#54
【原文】【記】七中。初「盜物」者，《律》云「若村中有金銀等，若牽、挽取，初離得夷」是也。「盜村體」者，即如所引。「攻擊、水澆」，損壞也。「強力」者，《律》云「依親厚強力而盜取」也。「言詞辨說」者，誑誘取也。「說」，音稅。
【譯文】【記文】第七項中。第一種「盜物」，《律》中說「若在村中有金銀等物，如果拖拉牽引奪取，剛離開原地就犯波羅夷」，就是指這個。「盜取村落本體」，就是如文中所引用的。「攻擊、水澆」，是指損壞摧毀的手法。「強力」，《律》中說是「依仗親信有權勢者的強大力量而強佔」。「言詞辯說」，是指用欺瞞誘騙的話術佔為己有。「說」，音同「稅」，指勸誘說服。

【488-0003】02_戒疏/07a_卷二上之三#55
【原文】【疏】八、「阿練若」者，村外空地。二位同村，可知。
【譯文】【疏文】第八、「阿練若」，是指村莊外面的空曠荒野之地。關於盜物與盜取土地這兩種情形都與「村落」相同，這是容易明白的。

【488-0004】02_戒疏/07a_卷二上之三#56
【原文】【記】「蘭若」，梵言，即翻「空處」。「二位同村」，即盜物及體，《律》云「空處有金銀」等，又云「若以方便，壞他空」等，是也。
【譯文】【記文】「阿練若」是梵語，翻譯過來就是「空處」。「兩種情形與村落相同」，就是指盜取其中的物品以及霸佔空地本體，《律》中說「在空處有金銀等物」，又說「如果使用各種手段，破壞強佔他人的空地」等等，就是指這兩種。

【488-0005】02_戒疏/07a_卷二上之三#57
【原文】【疏】九、「田處」者，田有多種，百穀所生之處總名為「田」。《律》中兩相，如上村解。《十誦》云：「若為田故相言，得勝者重，不勝者輕。若作異相，過分勝者重。僧房舍者亦爾。」不言理之曲直。如尼言犯殘中，但得述理，官占無犯，不許橫言。今以義約，若後主想決，則應屬己。若不定者，應非重科。
【譯文】【疏文】第九、「田處」，田地有許多種，生長各類穀物的地方總稱為「田」。《律》中所說的兩種行相，如同上述村落的解釋。《十誦律》說：「如果是為了爭奪田地而告官打官司，勝訴霸佔者結重罪，敗訴者結輕罪。如果是私自更改地界標記，越界侵佔獲勝者犯重罪。爭奪僧團房舍的情況也是如此。」這裡並沒有論及爭訟道理的曲直。就像比丘尼因訴訟犯僧殘罪的戒律中，只准許陳述事實公理，官府依法判給就沒有罪過，不准橫加無理爭奪。現在依法理來規範：如果前田主心意已決絕放棄索討，則判定田地已為侵奪者所據有（屬己）而結成不可悔重罪；如果前田主或官府裁決猶豫未定，則侵奪者尚未達到重罪科處（應非重科）。

【488-0006】02_戒疏/07a_卷二上之三#58
【原文】【記】田中。初示名相。「《律》」下，引釋。初本律言「兩相」，亦即物、體。《十誦》「相言」，謂詣官詞訟。「得勝重」者，謂非理而得。「不如」字誤，彼作「不勝」。「若作異相」者，彼云：「若不勝已，更作相，若所得地，乃至滿五，得彼羅夷。」「房舍」準田以判，故云「亦爾」。「不言」下，決文不了，又二。初準例決。即約理之曲直，明犯、不犯。「尼」下，脫「相」字，即尼「相言戒」，開述理故。「今」下，次約義決。即就主心，定與不定，判犯輕重。縱是僧地，前主心決，奪亦成重。
【譯文】【記文】在「田」這一項中。首先指出名稱與實相。從「《律》」字以下，引用解釋。首先本律所說的「兩相」，也就是指田中的物品與田地本體。《十誦律》所說的「相言」，是指到官府打官司訴訟。「得勝者重」，是指以非理手段霸佔成功。（若本子作）「不如」二字是傳抄有誤，彼律原作「不勝」。「若作異相」，彼律說：「如果官司不勝，私自變更邊界標記，如果侵佔所得的土地價值乃至達到五錢，就犯波羅夷罪。」「房舍」比照田地來判定，所以說「也是如此」。從「不言」以下，解決律文未說透徹之處，又分為兩層。第一、準照同類戒律判定。也就是依據道理的曲直，來明辨犯與不犯。從「尼」字以下，脫漏了一個「相」字，是指比丘尼的「相言戒」（訴訟戒），其中開許據實陳述公理。從「今」字以下，其次依據法理來判定。也就是就主人的心理，是確定放棄還是未定，來判定犯罪的輕重。縱使原本是僧團土地，前任佔有者心意已絕，奪取也同樣會構成重罪。

【488-0007】02_戒疏/07a_卷二上之三#59
【原文】【疏】十、「處所」者，或店肆作處，如是非一。亦有二位，如上列之。
【譯文】【疏文】第十、「處所」，或者是店鋪市集作為處所，像這類的處所不止一種。同樣有只盜物品與霸佔處所本體這兩種情形，如同前面所列出的一樣。

【488-0008】02_戒疏/07a_卷二上之三#60
【原文】【記】十中。初示相。「處所」語通，故云「非一」。《律》云「若家、若市肆、果園、菜園、庭前舍後，若復有餘處」等。「亦」下，判犯。盜物、盜體，「二位」同前，故略指之。
【譯文】【記文】第十項中。首先指出相貌。「處所」這個名詞涵蓋很廣，所以說「不止一種」。《律》中說「或者家中，或者市集店鋪，果園、菜園、庭院前後，或者還有其他處所」等等。從「亦」字以下，判定罪責。盜取物品、霸佔處所本體，「這兩種情形」與前面相同，所以略加指點而已。

【488-0009】02_戒疏/07a_卷二上之三#61
【原文】【疏】十一、「船處」者，亦有二科。船中盜物，即船為處。若盜船體，如《僧祇》中「解船筏時，越；動時，偷蘭；雖斷繩未離者，蘭；要斷繩離處，方重」。《善生》：「流水中，解船離栓，即重。」
【譯文】【疏文】第十一、「船處」，同樣分為兩條。在船上盜取物品，就以船作為處所。如果是偷盜船隻本身，如同《僧祇律》中所說：「解開船筏的繩纜時，犯突吉羅；船隻晃動時，犯偷蘭遮；雖然割斷了纜繩但船未離開原處，結偷蘭遮；一定要纜繩割斷且船已移離原處，才構成重罪。」《善生經》說：「在流動的水中，解開繫船的繩索使船漂離木樁，當下就犯重罪。」

【488-0010】02_戒疏/07a_卷二上之三#62
【原文】【記】十一，初總示。「舟」下，別釋。初明盜物。「若」下，明盜船。「《僧祇》中」，明因果、分齊、次第之相。「《善生》離栓」亦同。「栓」，巨月反，樁也。
【譯文】【記文】第十一項，首先總括說明。從「舟」字以下，分別解釋。首先說明盜取船上的物品。從「若」字以下，說明盜取船隻本身。「《僧祇律》中」，指明了犯罪前因後果、界線、階段先後的相貌。《善生經》說「離開木樁」也是同樣的道理。「栓」字音「決」，就是指繫船的木樁。

【488-0011】02_戒疏/07a_卷二上之三#63
【原文】【疏】十二、「盜水」者，律中但明所損，不出分齊。如《僧祇》中，溉灌流水，或一宿直一文，乃至四五，比丘為於佛僧，復自為，盜壞彼渠，得越；水入田，蘭；滿五者，夷。《摩得伽》云：「計彼塘工，過分而用，水滿者結重。」
【譯文】【疏文】第十二、「盜水」，本律中只說明造成他人的損失，沒有明確劃分界線。如同《僧祇律》所記載，用來灌溉的流水，灌溉一整夜價值一文錢，乃至四文五文，比丘為了佛陀或僧團，又或者為了自己，暗中毀壞他人的水渠，犯突吉羅；水流進田地，犯偷蘭遮；流入之水價值滿五錢者，犯波羅夷。《摩得伽論》說：「計算修築該水塘的工程費用，若超額享用水流，所盜用的水價值滿五錢者結重罪。」
