# 校閱材料　第1263檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1263-0001】資持記/13a_下一#1
【原文】四分律行事鈔資持記下一大宋餘杭沙門釋元照撰下卷題號，並同前釋。注撰，注宜作著。列篇生起，如釋題及序中備釋。17 釋二衣篇(下一)釋二衣篇衣資雖眾，制聽收盡；以教名物，故云二衣。言總別者，即下二門；物相繁細，恐難辨析；故先總條貫，然後別解，即以科目用入題中。
【譯文】《四分律行事鈔資持記》下卷之一，由大宋餘杭沙門釋元照撰寫。本卷題號的體例，與前面的解釋完全相同。題下的「注撰」，按文意應當作「著」字。本卷所列各篇的次第生起關係，已在釋題與總序中詳細說明。第十七篇：解釋二衣篇（下卷之一）。在「解釋二衣篇」中，修道所用的衣資雖然繁多，但佛陀所規定的「制衣」與允許蓄持的「聽衣」已將其全數收盡；以教法來為器物安名，所以稱為「二衣」。所謂「總別」，就是指下文所分的兩門；由於物品的法相繁雜細碎，恐怕難以辨別析理，因此先作總綱貫通，隨後再行個別解說，並直接把科判綱目納入題目之中。

【1263-0002】資持記/13a_下一#2
【原文】然考篇題所立各異，四藥從法，鉢器從教，對施頭陀等即約行，僧像赴請等乃就事，如是求之。敘意中三，初敘資用以顯功。言功有二：一能成儀，即上二句；二能障染，即下二句。識心具縛，色質有待，故云世累。塵染謂身之垢穢，或可形色生人愛著。若下，二明順違以生起。
【譯文】然而考究各篇篇題的安立方式各有不同：「四藥」依據戒法立名，「鉢器」依據教令立名，「對施」、「頭陀」等是依據修行立名，「僧像」、「赴請」等則是就著具體事相立名，應當如此依例推求。在敘述本篇意趣（敘意）的文段中分為三部分：第一部分是敘述衣資的作用以彰顯其功德。所謂功德有兩種：一是能成就威儀，即原文前面的兩句；二是能遮障塵染，即原文後面的兩句。凡夫的心識具足煩惱繫縛，肉身質礙有所依侍，所以稱為「世累」。塵染是指身體的垢穢，或者是指形體美色容易引發旁人的愛著心。自「若」字以下，第二部分是說明順法與違教的後果以引導生起戒慎。

【1263-0003】資持記/13a_下一#3
【原文】上明順法成持，下明違教成犯。方式並訓法。咎戾即目罪也。故下，三約二教以分章。總分中，初示名義。制聽名義，約罪有無。就下，正分，初分制物。即六物中，五種屬衣，如文所出，鉢在本篇。〔亡物賞看病法，乃以針筒為六，與此不同。〕後列聽物。百一諸長為一，糞掃為二，俗施為三，亡物為四。
【譯文】上一句說明順依戒法便能成就持戒，下一句說明違背教旨便會構成犯戒。「方」與「式」都是「法」的訓釋。「咎戾」就是指罪名。自「故」字以下，第三部分是依循制與聽這二種教法來分列章門。在總分章節中，首先標示名相與義理。制衣與聽衣的名義，是依據是否隨意受持而結罪有無來界定的。從「就」字以下為正文分列，首先劃分「制物」（規定必須受持之物）。在六種隨身資具物中，有五種屬於衣類，正如文中所列，鉢器則收錄在本篇之中。〔至於亡僧遺物賞賜看病僧人的法規中，是以針筒作為六物之一，與此處的定義不同。〕後文則列出「聽物」（允許額外蓄持之物）：百一等諸長物為第一類，糞掃衣為第二類，信眾施予之物為第三類，亡僧遺物為第四類。

【1263-0004】資持記/13a_下一#4
【原文】制門三衣制意中，文列十段，義節為五；初意，《多論》示希有義。三名即僧伽梨等。尚無北名，況有實乎！《功德論》中，有二意：一對三時；亦下，二為障蟲。言三時者，乃是興制之緣，非謂三時不通互著。人多錯會，學者須知。《智論》。聖弟子者，通目凡聖修聖道者。外道裸身，表著空也；
【譯文】在「制門」（制物門）說明三衣的制裁本意中，經文列有十段，義理上可節略為五個要點：第一個本意，引用《十誦律》或《薩婆多論》（《多論》）顯示其希有之義。三種名稱即指僧伽梨等。連其名稱尚且未曾聽聞，何況能具備其實質呢！《功德論》中則包含兩種用意：一是為應對寒、熱、雨三時的氣候；「亦」字以下，二是為遮蔽蟲蟻叮咬。所謂三時，是佛陀當初制定三衣的因緣，並不是說這三種衣在三時中彼此不能互通穿著。許多人都誤解了此點，求學之人必須明白。《大智度論》（《智論》）中所說的「聖弟子」，通指修習聖道的凡夫與聖人。外道赤身裸體，象徵偏執於「空」；

【1263-0005】資持記/13a_下一#5
【原文】白衣重著，表著有也；比丘三事不多不少，表住中道，不著空有二邊也。《十誦》中。以外道有著全段白㲲，故截以異之。次意中，《雜含》四無量者，即慈悲喜捨；心遍生境，故稱無量。準下，示名。三中。《華嚴》三毒，《四分》結使，皆目煩惱。《戒壇圖經》云：五條下衣，斷貪身也；
【譯文】世俗白衣凡夫重疊多穿，象徵偏執於「有」；比丘受持三衣不多不少，象徵安住於「中道」，不執著於空、有兩邊。《十誦律》中記載，因為外道穿著整匹未經剪裁的白㲲布，所以將布料剪截縫製，以此區別於外道。第二個本意中，引用《雜阿含經》所說的「四無量心」，就是慈、悲、喜、捨；由於此心周遍緣取一切眾生之境，所以稱為無量。依準下文，進一步開示其名稱。第三個本意中，《華嚴經》所說的三毒，與《四分律》所說的結使，都是指煩惱。《戒壇圖經》說：五條衣作為下衣，是為了斷除身業的貪愛；

【1263-0006】資持記/13a_下一#6
【原文】七條中衣，斷瞋口也；大衣上衣，斷癡心也。〔即配三毒及三業也。〕四中，《多論》。初意可解。第二應云：一衣不能有慚愧，三衣能有等。餘三亦然。《疏》解云：由常一衣，染淨通著，慚愧不生；以隨三用各有法式，屏露行護，發生善心故。
【譯文】七條衣作為中衣，是為了斷除口業的瞋恚；大衣作為上衣，是為了斷除意業的愚癡。〔這正是配合三毒與身口意三業來作說明的。〕第四個本意中，《薩婆多論》的第一層意思容易理解。第二層應當作這樣的表述：僅有一件衣不能生起慚愧心，具備三衣則能生起慚愧心等等。其餘三點也是如此。《律疏》解釋說：由於平時只穿一件衣，染穢與潔淨通融穿著，便無法生起慚愧心；若能依照三衣各自的用途各有其法度儀軌，在幽僻隱密、顯露大眾之處都能守護威儀，便能引發善心。

【1263-0007】資持記/13a_下一#7
【原文】第三反明三衣則中入聚，疏云：由僧伽梨隨聚方服，生物信故。第四具三衣，則道行生善；疏云：若在道行，反披高揲〔準下村外得反披，或揲肩上。〕；敬護如塔，幽顯懷德故。第五明三衣威儀淨者，疏云：四儀受用，各有所在故。五中。《僧祇》賢聖，通目大小三乘。
【譯文】第三點反過來顯明具備三衣才合適進入村聚聚落，《律疏》說：這是因為僧伽梨必須隨順進入村聚時方能穿著，以此引生眾生信敬的緣故。第四點說明具足三衣，則在道路行走時能生長善念；《律疏》說：如果在道路上行走，應反披高疊於肩上〔依下文村外可以反披，或疊放在肩上〕；恭敬守護如同佛塔，使幽冥與顯現之眾生皆能懷抱聖德的緣故。第五點說明三衣能使行住坐臥威儀清淨，《律疏》說：這是因為四種威儀的受用，各自有其適宜的衣著處所的緣故。第五個本意中，《僧祇律》所說的「賢聖」，通指大乘與小乘等三乘聖賢。

【1263-0008】資持記/13a_下一#8
【原文】𢡠音志，旗之異名〔又通熾試二音〕，字合作識，即訓記也。鉢是出家人器者，亦謂表異外道俗流；據在後明，相因引耳。當宗為寒者，〈衣犍度〉中，佛因夜寒，初中後夜，次第取三衣重著，因制三衣；佛言：當來善男子不忍寒苦，畜三衣足，不得過。外部即上二論。
【譯文】「𢡠」字音為「志」，是旗幟的異名〔又通熾、試二音〕，字體應當作「識」，訓詁為記認的意思。「鉢是出家人器皿」這句話，也是說要以此表顯有別於外道與世俗凡流；此項規定本在後文說明，因相關聯而順帶引出。本宗《四分律》以禦寒為緣起，在〈衣犍度〉中，佛陀因為夜晚天寒，在初夜、中夜、後夜，依序取三衣重疊加穿，隨後便制定了三衣之法；佛陀說：未來世的善男子不能忍受寒冷之苦，蓄持三衣即已足夠，不得過量。其餘外部（他部）論典，即指上述的兩部論典。
