# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【88-0001】資持記/13a_下一#50
【原文】文中通舉，須知兩異。次科，初明如法。所以長增至四，短唯局一者，疏云：法服敬田，為利諸有；表聖增而凡減，喻長多而短少。若下，簡非法。所以成受著用犯者，疏云：著取儀相，用生物善；長短差違，乖慈梵行；隨步越儀，一一結罪。〔今時禪眾多作九條，長短不定；或紗或綾，或絣或碧，自號法衣；體色量相，俱乖正制，何法之有。
【譯文】鈔文中通通列舉，必須明瞭這二者文獻出處的不同。下一科，首先說明如法之制。為什麼長條塊可以增加至四塊、短條塊卻唯獨局限在一塊？《律疏》說：袈裟法服是恭敬福田，旨在利益一切有情；象徵聖人功德增長而凡夫習氣減少，以此比喻長塊較多而短塊較少。自「若」字以下，甄別非法的形相。之所以能成就受持、但穿著使用時卻會結罪，是因為《律疏》說：穿著法衣是為了端正儀相，用以引發世人的善心；長短比例若產生差池乖違，便違背了慈悲修行的梵行清規；舉步動止之間便有越軌失儀之過，每一步都要逐一結罪。〔現今禪門大眾多製作九條衣，長短完全毫無定制；或者用生紗，或者用細綾，或者織花，或者染成青碧，自己宣稱為法衣；其實材質、顏色、尺寸與條相，全都乖違佛陀正制，哪裡算得上是什麼法衣！

【88-0007】02_戒疏/04a_卷一下之二#4
【原文】【疏】有人講論作七聚義，素不讀律，以意出之：「總取諸篇方便，以之為聚；成究竟者，以之為篇。」亦是一家《唯識普決》，不可依也。云何名聚？眾罪非一，號之為「聚」。若如此釋，五罪可爾；偷蘭、惡說，聚在何處？
【譯文】【疏文】義理疏文說：有人升座講論、剖析七聚的含義，平日不曾研讀戒律，憑自己的心意妄加推論說：「總括各篇的方便前方便罪，把它當作『聚』；已成就究竟果罪的，把它當作『篇』。」這就像某家所造的偽書《唯識普決》一樣，絕對不可依從。為什麼稱作「聚」？各種罪過並非單一，聚集在一起才稱為「聚」。如果按照他的解釋，戒本中的五篇罪還可以勉強說得通；那麼偷蘭遮與惡說這兩種罪，又該歸聚在哪裡呢？

【88-0008】02_戒疏/04a_卷一下之二#5
【原文】【記】解義中，初科為二。初斥無稽。「講論」，「論」即是說，謂諸傳律者。或指他宗論師，故言「素不讀律」等。此有二失：一者名局；二者罪局。《律》中七聚，通攝本、因，不唯方便故。「亦」下，斥非。「《唯識普決》」者，即人造偽論，如《鈔．序》所列。謂古所出，同彼偽妄耳。「云何」下，次斥妄釋。五罪在文，容可指處，偷蘭、惡說，不入戒本，則非聚處。故舉以攻之，足彰虗謬。
【譯文】【記文】在「解釋義理」的段落中，第一科分為兩部分。首先斥責無稽之談。「講論」的「論」就是說解，指那些傳授戒律的人，或者指其他宗派的論師，所以疏文說「平日不曾研讀戒律」等語。這種說法有兩大過失：一是名稱被侷限，二是罪相被侷限。因為律本中的七聚，普遍涵蓋根本果罪與前方便因罪，並非只單指方便罪。「亦是一家」以下，斥責其錯謬。「《唯識普決》」是一部偽造的論典，正如《事鈔．序》中所列舉的那樣。這是說古代某些論師的見解，如同那部偽論一般虛妄。「云何名聚」以下，接著斥責其妄加解釋。五篇罪在戒本文中有文句可尋，還勉強有指涉的處所；偷蘭遮與惡說並未編入戒本，就沒有所謂的聚處了。所以舉出這兩罪來質難攻擊，足以顯露其虛妄謬誤。

【88-0009】02_戒疏/04a_卷一下之二#6
【原文】【疏】今解云：「古人以《戒本》罪相，文籍所收，云聚一處。今不存此，以名義收。但有罪相輕重不同，或七或五，統以收之，隨名束罪，用通『篇』、『聚』。若以名聚，則止如文。夏不依人犯墮罪者，非《戒本》收，應不篇攝。乃至眾學如法治處，其相無限。故不同昔。今但名收，無罪不盡，義可解。」
【譯文】【疏文】義理疏文說：現在我們解釋為：古人認為《戒本》所收錄記載的罪相，集中列在一處，便稱之為「聚一處」。如今我們不採納這種說法，而是以名稱與含義來統攝。只要罪相有輕重差別，無論分為七聚或五篇，都用名稱來總括統攝，隨著罪名約束各類罪相，藉此貫通「篇」與「聚」二詞。如果只以戒本文句聚集為聚，那就僅侷限於戒本文相了。例如安居夏安居時不依止大德而犯墮罪，這並非《戒本》所收錄，難道就不屬於各篇所統攝了嗎？乃至眾學法中依如法處置的情形，其罪相無窮無盡。因此我們的看法不同於前人。現在只要依據罪名來統攝，便沒有任何罪相不能網羅殆盡，義理自然通達好解。

【88-0010】02_戒疏/04a_卷一下之二#7
【原文】【記】今解為二。初出古意。「今」下，次申正解。又三。初，立義。「名義收」者，如舉吉名，則總攝塵沙無邊輕罪，餘皆例之。「或七或五」者，言「七」通本因，言「五」唯果罪，「篇」、「聚」二名，任稱無在。若作此解，通達無疑，與彼昔義，條然天別。「若」下，質非。上二句牒非，「夏」下，引難。特引《戒本》不攝之戒，難彼局文，理不可立。「故」下，結示。
【譯文】【記文】「現在的解釋」分為兩部分。首先指出古人的意思。「今不存此」以下，接著陳述正確的解釋。其中又分三點：第一、樹立正義。「以名義統攝」，就像舉出「突吉羅」這一名稱，便能總括如塵沙般無邊無際的輕罪，其餘罪名也以此類推。「或七或五」，稱「七聚」是通指根本果罪與方便因罪，稱「五篇」則專指究竟果罪；「篇」與「聚」這兩個名稱，隨意稱呼都無妨礙。如果這樣理解，通達無礙，與往昔古人的義理相比，截然有天壤之別。「若以名聚」以下，詰難古人的錯誤。上面兩句提出古說之非，「夏不依人」以下引出問難，特地舉出《戒本》未收錄的戒相，詰難對方拘泥於文字文相，其道理根本無法成立。「故不同昔」以下，做結語開示。

【88-0011】02_戒疏/04a_卷一下之二#8
【原文】【疏】二、明離分品位之意，即辨離分置七意者。
【譯文】【疏文】第二、說明將罪相析分離判為各種品位的用意，也就是辨明分立為七聚的意趣。

【88-0012】02_戒疏/04a_卷一下之二#9
【原文】【記】二、明離分，標。云「即辨」者，點上科語。
【譯文】【記文】第二科「說明析分離判」，標立科名。疏文說「即辨」等語，是為了點明並承接上一科的語意。

【88-0013】02_戒疏/04a_卷一下之二#10
【原文】【疏】如昔解云：「語罪為言，體唯不善，理須就本，置不善聚。但以體含輕重，業相莫分，故不就體立一聚也。」
【譯文】【疏文】義理疏文說：如同往昔古德解釋道：「若就罪過本身而言，其體性純是不善，按理應當直接就其根源本體，設立一個『不善聚』即可。但因為不善的體性中包含著重罪與輕罪，造作的業相難以細分，所以不能只依體性而安立單一罪聚。」

【88-0014】02_戒疏/04a_卷一下之二#11
【原文】【記】古解中，初文有二。初敘須立。一切業相，不過善與不善。制戒禁惡，故云「理須」等。「但」下，明不立。
【譯文】【記文】在「古德的解釋」中，前半段文字有兩層意思。首先敘述照理應當安立單一聚。一切造業的形相，不外乎善與不善；如來制定戒律是為了禁遏惡行，所以說「按理應當」等語。「但以」以下，說明為何不能只安立一聚。

【88-0015】02_戒疏/04a_卷一下之二#12
【原文】【疏】「若爾，身口造業用收眾罪，惡作、惡說應有二聚，何以無者？今解以此二業，體含輕重，相亦難分，故不置也。」
【譯文】【疏文】義理疏文說：「如果這樣，身業與口業造作時統攝了諸多罪過，理應設立『惡作』與『惡說』這兩個罪聚，為什麼沒有呢？現在古師自己解釋：因為身、口這兩類業，本體同樣包含輕重，行相也很難分判，所以不單立這二聚。」

【88-0016】02_戒疏/04a_卷一下之二#13
【原文】【記】次科。初敘難。身口業別，應須立二。「今」下，明不立，即古師自釋。
【譯文】【記文】第二小科。首先敘述問難：既然身業與口業性質有別，就應該安立身、口兩聚。「今解」以下，說明不立的原因，這是古師自設問答來解釋。

【88-0017】02_戒疏/04a_卷一下之二#14
【原文】【疏】「是以隨義離分，出於五聚。五所不攝，還復二位。以二配五，故有七聚生焉。」
【譯文】【疏文】義理疏文說：「因此，古師隨順罪義加以析分離判，分出了五聚。凡是五聚所無法統攝的其餘罪相，又回歸到身、口這兩個品位。把這兩個品位配屬到前五聚之中，因此便衍生出了七聚。」

【88-0018】02_戒疏/04a_卷一下之二#15
【原文】【記】三中。彼謂一切惡業，不出二聚；由相難分，故離五聚，謂夷、殘、蘭、提、提捨為五。自餘罪相，歸本二位，足上成七。上約從通派別，故從一分二，就二分七。是知七祇是二，二還歸一。
【譯文】【記文】第三小科。古師認為一切惡業都不出這兩個罪聚；由於行相繁複難以細分，才分出五聚，也就是波羅夷、僧殘、偷蘭遮、波逸提、提舍尼五種。其餘未盡的罪相，再歸回身、口這兩處原本的品位，加上去便湊成了七聚。這是依循由總體分化為局部的路徑，所以先從一個不善本體分出二業，再就二業分出七聚。由此可知，所謂七聚不過就是身口二聚，二聚最終又回歸為一個不善之體。

【88-0019】02_戒疏/04a_卷一下之二#16
【原文】【疏】有人言：「如斯意言，出何聖量？若言造罪不出身口，惡作、惡說違略方有，何得輒言離出於五？若未制戒前，身口通中便有惡作，俗人所犯亦應入聚。若制後別中有惡作者，五年制婬，未有吉羅，無廣教故，何得云離？故知是難。」
【譯文】【疏文】義理疏文說：有人提出質難說：「這樣的立論意圖與言論，到底出自哪一部聖典的權威教證？如果說造罪離不開身業與口業，那麼惡作與惡說這兩種罪，必須在違犯略教戒律之後才會產生，怎麼能隨意宣稱五聚是從身口二聚中分化出來的呢？若是在佛陀制定戒律之前，身口通泛的業中就已經有惡作罪，那麼在家人所犯的罪也應該納入僧團的罪聚了。若是在制定戒律之後的個別條文中才有惡作罪，佛陀成道後第五年才制定斷淫戒，當時根本還沒有突吉羅罪名，因為尚未宣講廣教戒相，又怎麼能說是析分離判出來的呢？所以可知這種說法極難成立。」

【88-0020】02_戒疏/04a_卷一下之二#17
【原文】【記】他難中，初難為二。初通斥，「若」下，二牒難。初難後分五聚。七聚並因違略而制，是則七聚俱從略出，那云五聚從二出耶？「若未」下，次難先有二聚。五從二出，二必在先，故約二教，兩以徵之。初約略教難。略是通制，二聚別制，豈得通中先容有別？「身口通」者，即目略教。次約廣教難。淫是制廣之始，此時無吉，明非先有。「制後別中」者，即是廣教。
【譯文】【記文】在「他人的質難」中，第一段質難分為兩部分。首先通盤斥責；「若言」以下，第二步列舉難點。首先質難「後來分出五聚」之說：七聚都是因為違犯略教戒律才隨緣制定的，既然如此，七聚都是出自略教，怎麼能說五聚是從身口二聚中衍生出來的呢？「若未制戒前」以下，接著質難「預先存在身口二聚」之說：五聚既然出自二聚，二聚就必定先存在，所以古德約略教與廣教兩方面加以追問盤詰。首先約略教難詰：略教是共通的總制，二聚是個別的特制，哪有共通的教法中能預先容納個別戒相的道理？「身口通」指的就是略教。其次約廣教難詰：斷淫戒是制定廣教戒條的開端，此時尚未有突吉羅罪，足證二聚並非原先就存在。「制後別中」指的就是廣教。

【88-0021】02_戒疏/04a_卷一下之二#18

【譯文】【疏文】義理疏文說：有人迂迴曲折地辯解說：「在未曾制定廣教戒條之前，確實還沒有惡作罪名；這是預先借用後世制定的罪名，用來擬比指稱前期的罪相。」

【88-0022】02_戒疏/04a_卷一下之二#19
【原文】【疏】此亦不然。七聚並在未來，俱借齊妙。何止身口二吉，用以離分？
【譯文】【疏文】義理疏文說：這種說法也不正確。七聚全都屬於未來尚未制定的名稱，要借用就應當一齊平等借用，為什麼偏偏只借出身、口兩種突吉羅，用來分拆成各個品位呢？

【88-0023】02_戒疏/04a_卷一下之二#20
【原文】【記】斥曲救中。初出他義。謂作、說雖後，用後擬前，不妨前有，則成上義。「此」下，正斥。後既有七，何獨借二？於理亦乖。
【譯文】【記文】在「斥責曲意救解」的段落中。首先引述對方的觀點：認為惡作、惡說名稱雖在後制定，但用後面的名稱擬比前面的罪相，不妨礙前面就已有其實質，這樣便能成立前面的說法。「此亦不然」以下，進行正面駁斥：後世既然有七聚名稱，為什麼唯獨偏借這二種？在義理上顯然相互違背。
