# 校閱材料　第160檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【160-0001】02_戒疏/02b_卷一上之二#105
【原文】【記】次科，總分中。「修」謂履善，「捨」即離惡。「結說」者，「結」謂總括七佛，「說」即剏制廣教。佛不說廣，偈云「說」者，即是「制」耳。
【譯文】【記文】接著進入下一科，在整體分段中。「修」是指實踐善法，「捨」是指遠離惡行。「結說」的含義，「結」是指總括過去七佛，「說」是指最初制定廣博的教法。過去諸佛原本未廣宣戒條，偈頌中說「說」，指的其實就是「制定」。

【160-0002】02_戒疏/02b_卷一上之二#106
【原文】【疏】就初文二：前之三句，廣教戒相滅惡之功；下有一句，舉功勸聽。
【譯文】【疏文】在第一個部分中分為兩段：前面的三句，闡述廣教戒相滅除罪惡的功德；下面的一句，列舉其功德以勸導大眾諦聽。

【160-0003】02_戒疏/02b_卷一上之二#107
【原文】【疏】「欲除四棄」者，舉此教本，能防未非，應起不起，名之為「除」。非謂已犯，而說除擯。假名比丘，方便禁警，使初篇業，冥伏不起，名為「欲除」。所除是何？即「四棄」也。而言「法」者，法義極多，今取能成犯緣，故云「法」也。
【譯文】【疏文】「欲除四棄」的意思，是指舉出這部戒教的根本，能夠防範尚未發生的過失，使本應生起的惡業不再生起，這就叫做「除」。並不是指僧人已經犯了重罪，才說要予以除名擯出。對於凡夫位階的假名比丘，藉由戒法方便加以禁戒警示，使得根本重罪的初篇惡業，在暗中潛伏而無法萌發，這就叫做「欲除」。所除滅的究竟是什麼？就是「四波羅夷（四棄）」罪。而之所以稱為「法」，是因為法的含義極其繁多，如今此處是選取其能構成犯戒條件的軌範，所以稱為「法」。

【160-0004】02_戒疏/02b_卷一上之二#108
【原文】【記】釋四棄中，初正釋。「非」下，遮濫。「假」下，重釋。內凡已還，未見真理，無實德故，通號「假名」。初果已去，名「真實僧」。「冥」猶潛也。「法義多」者，如「自體」、「軌持」之異。「今取」等者，謂諸戒相各列「犯緣」，具則成犯，揩式軌定，犯由緣辨，故曰「能成」。即二義中軌持解也。
【譯文】【記文】在解釋四棄罪的文句中，首先正面解釋。「非」字以下，阻斷混淆的偏解。「假」字以下，重新加以解釋。內凡位以下的修行人，因為尚未照見真理、沒有真實無漏的功德，所以普遍稱為「假名比丘」。初果以上，才被稱為「真實僧」。「冥」，如同潛藏的意思。「法義多」的意思，例如有「維持自體」與「軌範持守」的不同解釋。「今取」等句，是指各條戒相中各自列出的「犯罪緣起條款」，若完全具備便構成犯戒，這些章法式樣都有規律軌範，犯罪是藉由各種緣起條件來認定的，所以說「能成」。這就是取兩種定義中「軌持」的解釋。

【160-0005】02_戒疏/02b_卷一上之二#109
【原文】【疏】若據義收，「滅」、「障」、「除」、「遣」，隨言皆得，莫非離過而為本也。
【譯文】【疏文】如果依照義理來融通統攝，「滅」、「障」、「除」、「遣」這幾個名詞，隨文選用都可以，無非都是以遠離過失作為最根本的宗要。

【160-0006】02_戒疏/02b_卷一上之二#110
【原文】【記】總示中。以文列三篇，三名別對，恐生局計，故總示之。文無「遣」字，義類無異，故通舉之。
【譯文】【記文】在總體開示的文句中。因為律文分別列出了戒律的三篇，並各自對應了三種名詞，唯恐學者產生僵化局限的見解，所以作此通體開示。偈文中雖然沒有出現「遣」字，但義理類別上並無差異，所以一併提出。

【160-0007】02_戒疏/02b_卷一上之二#111
【原文】【疏】初篇既離，行本得成，若不淨撿二篇，眾法難立，故名「滅」也。
【譯文】【疏文】最重罪的初篇既然已經遠離，清淨修行的根本才得以成就；此時如果不徹底清淨檢點第二篇的僧殘罪，眾人的法事羯磨便難以建立，所以用「滅」來稱呼。

【160-0008】02_戒疏/02b_卷一上之二#112
【原文】【疏】上具戒行，不顯威儀，則形心不淨，眾法無託，故當靜緣，令非不起，是曰「障」也。
【譯文】【疏文】具足了上面的重大戒行，如果不顯發整肅細微威儀，則身心難得清淨，大眾的集體法事就沒有依憑寄託之處，所以應當平息擾動之緣，令微小的非分惡念不起現行，這就稱為「障」。

【160-0009】02_戒疏/02b_卷一上之二#113
【原文】【記】次釋殘、墮，皆躡前義勢，發起後文。並云「眾法」者，對今說戒，當機要故。
【譯文】【記文】接著解釋僧殘與捨墮兩篇，都是承接前面的義理脈絡，以引發後文。此處都提及「眾法」，是因為相較於當前進行的說戒羯磨，威儀清淨是正當機要的先決條件。

【160-0010】02_戒疏/02b_卷一上之二#114
【原文】【疏】既已識相，依說須行，故又勸聽也。計初一勸，義則兼通。但以末世鈍機，情多浮濫，聖所制禁，凡所常行，恐未志奉，妄有輕忽，故又重勸。
【譯文】【疏文】既然已經明了了戒相，依據宣說就必須起而力行，所以再次勸勉大眾諦聽。按理說最初的那一次勸勉，義理上就已經通貫全局了。但因為末法時代眾生根機愚鈍，性情多浮躁散亂，聖人所嚴加禁制之事，卻是凡夫平日習以為常的行徑，唯恐眾人未能立志奉行，反而妄自輕蔑忽視，所以再次鄭重勸告。

【160-0011】02_戒疏/02b_卷一上之二#115
【原文】【記】釋勸聽中。初牒釋，「計」下，明重意。初二句指前偈，「但」下，申所以。專念曰「志」，遵行曰「奉」。說本為行，非聞不曉，惑重信輕，故頻加勸。
【譯文】【記文】在解釋勸導諦聽的文句中。首先牒出經文進行解釋，「計」字以下，說明重複勸勉的意圖。前兩句指向前一首偈頌，「但」字以下，申述其緣由。專心致志稱為「志」，依教遵行稱為「奉」。宣說原本是為了付諸實踐，但如果不聽聞就無法通達明了，末法眾生往往惑障深重而信心輕薄，所以需要頻頻加以勸勉。

【160-0014】02_戒疏/02b_卷一上之二#118
【原文】【疏】答：「滅惡之戒，通攝五篇，且列上三，餘蓋存略。又解：『初三「戒」攝，下是「威儀」，且舉綱領，故不隨事。』又云：『今列篇相，正存聽說。序中所為凡有二人：專精不犯，非治所科；犯已從滅，法唯三別，初篇非數所攝，雖懺終不成僧，二篇唯是眾除，三篇同對別捨。廣教具含二淨，義須列相示之。』」
【譯文】【疏文】回答：「滅除罪惡的戒律，實際上通貫攝受了全部五篇，這裡暫且只列出前三篇，其餘兩篇大概是省略了。另一種解釋說：『前三聚歸屬於「戒律」所攝，後續諸聚則屬於「威儀」範疇，此處暫且提綱挈領，所以不隨各別細事逐一列出。』又有一種說法：『如今列出篇聚相狀，本意正是為了宣說聽戒。序文中所針對的對象總共有兩種人：一種是專精持戒不曾毀犯者，並不是戒律治罰所涉及的對象；另一種是犯戒之後依法悔滅者，懺罪的方法只區分為三種差別：初篇罪不被僧數所接納，即使懺悔了終究也不能恢復僧籍；第二篇罪唯獨必須透過大眾僧作法才能消除；第三類懺法（下三篇罪）則同樣面對個別僧人發露捨罪即可。廣博教法完整包含了這兩類清淨之人，所以在義理上必須列出相狀加以開示。』」

【160-0015】02_戒疏/02b_卷一上之二#119
【原文】【記】答中三釋。初文略釋，可解。次、約提綱釋。戒分列二，不明偷蘭；威儀標一，不顯餘三。故云「且舉」等。三、對懺法釋。初示列相；「序」下，約人釋義。「序為二人」者，文云「犯者應懺，無犯默然」故。初專精人，因而先出；次犯懺人，正釋今文。犯雖有五，懺但分三。提舍、吉羅，並對首悔，故同一位。若論初、二，同是眾法，但初不復本，次局二十，故分二位。又據下三，約說，三、一有異；望人，對別是同。「二淨」即前「二人」，初人持淨，次人懺淨。
【譯文】【記文】在回答的文句中共有三種解釋。第一種是簡略的解釋，容易理解。第二種是依提綱挈領的角度來解釋。根本戒條中分列了前二篇，未明列偷蘭遮罪；威儀細行中標出了捨墮這一篇，未顯列其餘三篇。所以說「暫且舉出」等語。第三種是對照懺罪之法來解釋。首先標明列出篇相；「序」字以下，依據不同的人來解釋義理。「序文中針對二人」，是因為文句說「有犯戒者應當懺悔，無犯戒者默然安住」的緣故。第一種專精持戒的人，順帶先作說明；第二種犯戒懺悔的人，正是用來解釋當下的文意。罪名雖然分為五篇，懺悔的儀軌卻只分為三類。波逸提與提舍尼、突吉羅，全部都是對首單獨懺悔，所以屬於同一個層次。如果要論及初篇與二篇，雖然同樣都是僧團大眾法事，但初篇不能恢復本來比丘身分，二篇則局限於二十位清淨僧方得懺除，所以分為兩個位階。再依據下三篇來說，若就陳辭宣說而言，有三遍與一遍的差異（三說與一說的差別），但望向受懺對象，都是面對個別僧人而無不同。「二淨」就是指前面的「二人」，第一人是持戒清淨，第二人是懺悔清淨。

【160-0023】02_戒疏/02b_卷一上之二#127
【原文】【記】答中，先敘難測。「無方」，猶言不定。「盛衰」謂律明住滅。「謀」謂圖度。「《律》」下，顯經律之意，各據一端，機見有異，未可和會。「五過」出《成論》，謂迷名生法癡，隨文增五失：一、不正信；二、退勇猛；三、誑人；四、謗法；五、輕於聖法。
【譯文】【記文】在回答中，首先敘述聖意難以揣測。「無方」，就是說不定規律。「盛衰」，是指戒律中所說的正法延續與衰滅。「謀」，是指揣測度量。「《律》」字以下，顯明經與律各自的立論意趣，各自依據一個面向，針對的機鋒見解不同，不可強行融會。「五過」出自《成實論》，是指因為執迷於名相而產生法癡，隨逐字句而滋生五種過失：第一、失去正信；第二、退失勇猛精進；第三、欺誑他人；第四、毀謗正法；第五、輕蔑聖賢教法。

【160-0026】02_戒疏/02b_卷一上之二#130
【原文】【記】次問中。佛在六為過去，滅後七皆過去。答中，初答唯引過去，後答不明現、未。現佛化他方，教法不被此；未來同此土，教法復未設。望今現無，故云「無教」。
【譯文】【記文】在第二個提問中。佛陀住世時前六尊佛為過去佛，佛滅度後七佛皆為過去佛。回答中，首先回答為何唯獨引述過去佛，後面回答為何不談現在與未來佛。現在佛正在教化其餘他方世界，教法不普及於此處；未來佛雖然將誕生於此界，但其教法尚未設立。相對於當前的我們而言都是不存在現成教法的，所以說「無教」。

【160-0027】02_戒疏/02b_卷一上之二#131

【譯文】【疏文】提問：「序文中缺少了現在佛與未來佛，為何到了流通分卻又完整列明了過去、現在、未來三世諸佛？」

【160-0028】02_戒疏/02b_卷一上之二#132
【原文】【疏】答：「各有其致。『戒序』將弘聖教，恐時不奉，故引已起之教，成勸信之由。流通泛引戒益，必行會聖。聖不虗會，三佛皆行。因教圓德，無不果滿也。」

【160-0032】02_戒疏/02b_卷一上之二#136
【原文】【疏】就結人成法中。七佛非一曰「諸」，宇宙無上曰「世尊」，行滿位高曰「大德」也。「為我說是事」者，引上廣教，被下世機，定非私傳，聞必至聖。此則顯己承習有由，何得不奉！
【譯文】【疏文】在藉由教主以圓滿成立法統的文句中。七佛並非單單一位所以稱「諸」，遍大千宇宙至高無上所以稱「世尊」，福慧行持圓滿位階尊貴所以稱「大德」。「為我宣說了這件事」的意思，是引導上述的廣大教法，用以加被後世的根機，這決定不是說戒者個人的私自傳承，所聽聞的必定來自極致聖者。這就彰顯了自己承受修學是有真實源頭的，大眾又怎能不恭敬奉行！
