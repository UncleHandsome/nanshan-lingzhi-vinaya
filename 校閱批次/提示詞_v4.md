# 校閱提示詞 v4（精簡版）

> 依這幾輪實測調整：拿掉術語表（實測對召回無幫助），保留真正有效的三件事——
> 每段必答、完整度優先、證據具體。

## 材料格式

```
【03-0150】資持記/01c_上一上#18
【原文】…
【譯文】…
```

## 提示詞（複製整段）

```text
你是南山律典白話譯文的校閱者。下面每段附原文與現行白話。請逐段核對，不要只挑幾段講。

【每段檢查五項】
1. 完整度（最重要）：原文每一句都有對應譯文嗎？有沒有整句照抄文言、整段漏譯、或把前後段的內容摻進來？
2. 名相：佛教名相、罪名、書名簡稱，是否與原文一致（例如原文說「伽論」，譯文不能變成「善見論」）。
3. 義理：主詞（誰做誰受）、因果（因與果是否顛倒）、肯否（「不犯」有沒有變「犯」）、程序（先後次序）、範圍（「一切」有沒有被縮小）、增減（有沒有添加原文沒有的內容）。
4. 數字：數目、單位、加總是否與原文一致。
5. 體例：譯文開頭是否重複加上標籤已有的「義理疏文說」「【疏文】」；《》〈〉「」是否配對；句末是否多餘標點。

【輸出】
每段輸出一行，順序與材料相同，行數必須等於段數：
編號 ｜ 判定 ｜ 證據
- 03-0150 ｜ OK ｜ 原文「三趣」→譯文「三趣」；主詞一致
- 03-0151 ｜ P1 ｜ 原文「伽論」→譯文「善見論」，書名錯
- 03-0152 ｜ P0 ｜ 原文整句未譯，譯文只留「…」

判定：P0＝漏譯／張冠李戴／意思相反；P1＝名相、義理、因果偏差；P2＝標點體例。
OK 也要寫證據；不確定寫「?」，不要寫 OK。

【第二階段：非 OK 的段】
給整段替換文字：
- 除問題句外，其餘與現譯逐字相同。
- 不得增刪內容、不得合併或拆分段落、不得改寫原文。
- 不加譯者按語。
```

## 這版跟前幾版的差別

| 項目 | 前幾版 | v4 |
|:--|:--|:--|
| 術語表 | 60 條表格 | **拿掉**（實測召回 27%→27%） |
| 完整度 | 部分版本沒有 | 列第一項 |
| 證據 | 可寫可不寫 | 必寫，且要引原文詞 |
| 行數 | 未要求 | 必須等於段數 |

## 實測基準（同一份 T2，100 段）

| 版本 | 召回 | 誤報 |
|:--|--:|--:|
| 只回報問題 | 27% | 3 |
| 每段判定 | 27% | 3 |
| 術語表版 | 27% | 5（含 2 個真錯） |

三版召回相同，所以改用更小的檔＋更嚴的證據要求，而不是再加規則。
