# 校閱材料　第409檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【409-0001】03_業疏/11a_卷二之五#9
【原文】然世濁惑深，厭苦求樂，初雖欣出，終墜欲海，不修行業，故徒行也
【譯文】然而世道混濁、眾生惑障深重，往往只是為了厭惡痛苦、希求安樂，最初雖然欣求出家，最終卻墮落於欲海之中，不修持戒行道業，所以只是徒然出家罷了。

【409-0002】03_業疏/11a_卷二之五#10
【原文】三、引誡中初科，初示時機。謂厭在家營趁之苦，求出家供給之樂，即涅槃云「為衣食而出家」者。「初下」次明退墮。詩云「靡不有初，鮮克有終」，即斯類矣。徒行，謂出家無益也
【譯文】第三、引用戒勉中的第一科，首先指示當下的時勢根機。是指厭惡在居家業謀生求利的勞苦，希求出家後受人供養的安樂，這就是《涅槃經》所說的「為了衣食而出家的人」。「初下」接著說明退失墮落。《詩經》說「靡不有初，鮮克有終」（萬事無不有個開頭，但很少能善始善終），指的就是這類人。「徒行」，就是指如此出家毫無益處。

【409-0003】03_業疏/11a_卷二之五#11
【原文】如智論云：「六情根完具，智鑒亦明利，而不求道法，唐受身智慧。禽獸皆亦知，欲樂以自恣，而不知方便，為道修善事。既已得人身，宜勉自利益，不知修道行，與彼亦何異？」龍樹引誡為極言也。聞而不行，猶是不聞；今重引告，何得不用
【譯文】正如《大智度論》說：「六種根識皆完好具備，智慧鑑照也明晰敏銳，卻不求取正道佛法，白白承受了這人身與智慧。禽獸也都知道追求欲樂來放縱自己，卻不懂得藉由善巧方便，為了修道而造作善事。既然已經獲得寶貴人身，應當勉勵自己追求真實利益，如果不知道修持道行，與那些禽獸又有何差異？」龍樹菩薩引用此戒勉可以說是言辭痛切至極。聽聞了而不去奉行，就如同沒有聽聞一樣；現在重新引述告誡，怎能不認真遵奉力行呢？

【409-0004】03_業疏/11a_卷二之五#12
【原文】次科論文三偈：初偈上二句明報勝，下二句嗟不學。六情根者，情即是識，謂根識無缺也；智能鑒物，故云智鑒；唐，虗也；身對初句，智慧對次句。次一偈舉況，畜是癡報，但知欲樂，即經所謂「但念水草，餘無所知」也。後一偈中，上半合初偈，下半合次偈。「龍下」結告勸依。必應此偈出在他經，故云引誡；以畜況人，為誡深切，故云極言
【譯文】第二科論典文字有三首偈頌：第一偈上半兩句說明果報殊勝，下半兩句嗟嘆其不修學佛法。六情根，「情」就是識，是指六根與六識毫無殘缺；智慧能鑑別事物，所以稱為「智鑒」；「唐」，就是虛妄、白白的意思；「身」對應第一句，「智慧」對應第二句。第二首偈頌列舉比況，畜生是愚癡果報，只知道享受欲樂，也就是經中所說的「只知念著水草，其餘一無所知」。最後一偈之中，前半首合於第一偈，後半首合於第二偈。「龍下」總結告誡勸勉依循教奉行。想必這首偈頌出自其他經論，所以說是引用誡勉；用畜生來比況人類，是極為深切痛切的戒誨，所以說是極言。

【409-0005】03_業疏/11a_卷二之五#13
【原文】道行何耶？一切無染者是也。良由眾生無始封著是此是彼、是得是失，因之起染，纏縛有獄。故世鈍者多著財色，少有利者多貪名見，四科束之，尠不收盡。終歸死去，何事迷乎
【譯文】什麼是修道的戒行呢？對於一切事物不起染著就是了。這實在是因為眾生從無始以來，執著於這是此、那是彼，這是得、那是失，因此生起染污貪著，被繫縛於三有生死牢獄之中。因此世間愚鈍之人大多執著於財富與美色，少數稍有利根聰明之人則大多貪愛名聲與知見見解，以財、色、名、見這四項加以歸納概括，幾乎無不網羅收盡。然而人生終究歸於死亡，為何還要如此執迷不悟呢？

【409-0006】03_業疏/11a_卷二之五#14
【原文】三中，初示道行。以偈文未顯，故特徵示用開心路。一切之言，通收善惡塵境；染惡則增業，染善則成障；能於日用所行所學，觸境無染，無染之智即是般若，背塵合覺、絕縛入道必始於此，深可體究，慎勿誦文。「良下」反釋所以，又三：初、示染本。封著是貪愛，此彼得失即分別；由斯二種，輪迴不息；能離此者，即名道行，非別有道，故下云「道在虗通，達累為本」是也。「故下」次舉世情。財收八穢，色乃荒婬，名謂虗聲，見即妄執；上二常流所著，故為鈍；下二學者所求，故為利；此且一往分之，然有具四或復互輕，不必一定；尠，猶無也。「終下」重誡。凡在同徒，用斯自照，有一于是，未脫輪迴。且聽教參玄，為人軌範，反乃積財荒色、諍見沽名，跡混世塵，不思出要，形出心沒，何所利乎
【譯文】第三科中，首先開示修道之行。由於偈頌文義尚未完全顯露，所以特別徵問開示用以啟發修心之路。「一切」這個詞，通攝善與惡的各種塵境；若染著惡法就會增長罪業，若染著善法就會成為證道障礙；若能在日常所行所學之中，接觸境界而無所染著，這無所染著的智慧就是般若，背離塵勞契合覺性、斷絕束縛趣入道果必定從這裡開始，極為值得深切體認探究，切不可只是口頭念誦文句。「良下」反過來解釋其中的原因，又分為三點：第一、指出染著的根本。封固執著就是貪愛，此彼得失就是妄想分別；由於這兩種執著，使人在輪迴中流轉不息；能夠遠離這些，就稱為修道之行，並不是離開這些另有玄妙之道，所以下文說「道在於虛明通達，通達並解脫牽累才是根本」，就是這個意思。「故下」接著列舉世俗常情。財物收納了八種不淨之物（八穢），色情則是荒淫無度，名是指虛浮的名聲，見就是妄加執取的知見；前面兩者（財、色）是凡夫常流所執著的，所以屬於鈍根；後面兩者（名、見）是修學之士所追求的，所以屬於利根；這姑且是依大致情況來劃分，但有的人四者俱備，或者互相有輕重不同，並不一定局限；「尠」，就如同「無」的意思。「終下」重新加以痛切勸誡。凡是身在同參道友之列的人，應當以此反照自身，若有其中一項存在，就尚未能脫離生死輪迴。況且聽聞教理、參究玄義，身為他人的模範榜樣，反而積聚錢財、荒淫著色、爭執見解、沽名釣譽，行跡混雜於世俗塵勞之中，不思求出離的要道，身雖出家而心沉世網，這樣究竟有何益處呢？

【譯文】第二、說明出家超越世間的功德。

【409-0008】03_業疏/11a_卷二之五#16
【原文】橫約諸有，無思離染，故樹出家樂處閑靜；若有貪著，終成金鎖；引出方便，唯斯一道
【譯文】就三界二十五有的一切眾生而言，無人思求遠離染著，所以建立出家之法，令人樂於處在幽閒清靜之中；如果對此閒靜仍有貪戀執著，最終這閒靜也會成為黃金的枷鎖；引導眾生出離世間的善巧方便，唯有出家這一條坦途大道。

【409-0009】03_業疏/11a_卷二之五#17
【原文】第二門釋中初科，初示立意。約，謂約絕。「若下」次遣滯著，謂不知方便，住於閑靜，故以金鎖以喻法縛。「引下」三點權道
【譯文】第二門解釋中的第一科，首先指明立意。「約」，是指約束隔絕。「若下」接著破除沉滯貪著，是指不知道這是過渡的方便，反而執著停留在閒靜之中，所以用金鎖來比喻被法執所繫縛。「引下」第三點明方便權宜之道。

【409-0010】03_業疏/11a_卷二之五#18
【原文】如華手經：有四法轉身，即在善來比丘蓮華化生，現增壽命。一者、自樂出家，亦勸助人令欣出家；二、求法無倦，亦勸他人；三、自行和忍，亦勸他行；四、習行方便，深發大願，隨有功利，至時付引
【譯文】正如《華手經》說：有四種法門能夠轉變來世的身報，也就是能轉生為善來比丘、於蓮花中化生，並且在現世增長壽命。第一、自己樂於出家，也勸勉助成他人令其欣求出家；第二、勤求佛法不知疲倦，也以此勸勉他人；第三、自己奉行和睦忍辱，也勸勉他人奉行；第四、修習推行善巧方便，深切發起廣大誓願，隨其所具有的功德利益，到機緣成熟時引導並付囑於他人。
