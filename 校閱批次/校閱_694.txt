# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

# 校閱材料　第694檔

【694-0001】01_行事鈔/12c_卷下之四#26
【原文】獨宿三緣：一離申手外宿，不問俗僧兩處。兩處置床，在申手內，互相檢校，方能離過。若本在申手內，後因睡相離者，不犯；本作離意，隨轉側，犯。故文云：若舒手不相及，隨轉，一一僧殘。《僧祇》：當在申手內，一夜中，三度以手相尋，不得一時頓三；當初中後夜，各一度相尋。《五分》：若在不相及處，初中後夜，偷蘭；明相出，僧殘。二無緣，除命、梵、樂靜等。三隨臥，一一結。
【譯文】獨宿三緣：第一、離開伸手可及的範圍之外住宿，不問是在俗人家還是僧寺這兩處。在兩處安設床鋪，必須在伸手可及的距離之內，彼此互相照應巡檢，才能免除過失。如果原本安在伸手可及的距離內，後來因為睡眠中翻身而分開的，不犯；如果原本就抱持遠離之意，隨著每次翻身輾轉，便構成犯戒。所以律文說：如果伸手不能相及，隨著翻身輾轉，每一次翻身都各犯一次僧殘罪。《摩訶僧祇律》記載：應當在伸手可及的距離內，在一夜之中，三次用手相互探尋，不能在同一時間一次摸三次；應當在初夜、中夜、後夜，各探尋一次。《五分律》記載：如果在伸手不及之處，初夜、中夜、後夜，各犯偷蘭遮；到了天明黎明出時，結僧殘罪。第二、是沒有特殊緣由，除遭遇生命威脅、梵行危難、或樂住清靜等緣由。第三、隨著每一次躺臥入睡，一一結罪。

【694-0002】資持記/16d_下四#30
【原文】三無緣，亦謂命梵。次科。據本成犯，須約村門。古解越界，乃約村中橫道成殘；不唯太過，抑亦昧文。下引律證。明約村門，足知非解。出村亦犯，即知入出，皆名越界。獨宿中。初緣。初句明犯分齊。次句示犯處，不問僧俗，通一切故。兩處下，明持。若下，示開。故下，證犯。
【譯文】第三是無特殊因緣，也稱作危及生命或梵行。次一科。依據根本成犯而言，必須以跨越村門為準。古代的解說認為越過分界，竟是指在村落中的橫道穿行即成僧殘；不僅太過嚴苛，而且也昧於律文原本的真意。下文引述律文作證。明定是以村門為界，足以明白古解是不正確的。走出村落也算違犯，即可知進入與走出，都稱為跨越界限。獨自留宿之中。第一個因緣。第一句明示犯戒的分寸界線。第二句指示犯戒的處所，不問是出家或世俗之地，通攝一切處所。兩處以下，說明持守之法。若以下，指示開許因緣。故以下，證實結罪情況。

【694-0003】01_行事鈔/12c_卷下之四#27
【原文】獨在後行。或根本獨去，或中間作意，離伴見聞處行；又伴無諸難緣，故犯。《四分》云：見聞俱離，殘；見聞互離，蘭。不犯中，開度水者，若共伴漸度，不失威儀；乘船、橋上、躡梁、躡石；伴尼死、休道、遠行、及諸雜難不得作伴，並開。《五分》：水淺，無畏男子處，不犯。開入村緣，如前具緣中。開獨宿者，律云：共二尼宿，舒手相及處；若一尼出大小便，或出受經誦經，若樂靜獨處誦經，或為病尼煮羹粥作飯，乃至餘難緣，並開。《僧祇》：若病，賊亂圍城，獨宿不犯。開獨行中，應在不離見聞處；若一尼大小便、諸難，皆開。《僧祇》：不得出聚落界，除道行便利，邂逅失伴，未及中間，不犯；病亦如是。《五分》：若恐怖走時，老病不及伴者，不犯。
【譯文】獨在後行。或者從一開始就單獨離去，或者中途生心作意，脫離同伴眼見耳聞之處行走；而且同伴並未遭遇任何危難事故，所以構成犯戒。《四分律》說：離開同伴直到眼見、耳聞皆不可及之處，犯僧殘；眼見與耳聞只要有一者相離，犯偷蘭遮。在不犯的情況中，開許涉水渡河者：如果是與同伴依序漸漸渡過，不失威儀；或者乘船、在橋樑上走、踩著獨木橋、踏著水中跳石渡過；或者同伴尼僧身亡、還俗（休道）、遠行、以及遭遇各種危難而無法作伴，全都開許。《五分律》說：水流平淺、且沒有可畏男子的處所，不犯。開許入村的因緣，如前文具緣中所述。開許單獨住宿者，律藏說：與另外兩位尼僧同宿，處於伸手可相及的範圍內；如果其中一位尼僧出去大小便，或出去聽受經典、誦經，或者喜好清靜而獨處誦經，或者為患病的尼僧熬煮羹粥做飯，乃至遭遇其餘危難因緣，都予開許。《摩訶僧祇律》說：如果患病、或有盜賊叛亂圍困城池，單獨住宿不犯。在開許單獨行走中，原則上應在不脫離眼見耳聞的範圍；如果因一位尼僧大小便、或遭遇各種危難，都予開許。《摩訶僧祇律》說：不得走出村落邊界，除非行路時需要大小便，或者偶爾走散失伴、在尚未追趕上的這段時間內，不犯；患病時也是如此。《五分律》說：若在驚恐逃跑時，因年老患病追趕不上同伴者，不犯。

【694-0004】資持記/16d_下四#31
【原文】《僧祇》明相檢法。《五分》示犯相。獨行中，同上三緣；初至處行，即第一緣。根本，即發足時。又下，即第二緣。《四分》下，第三緣。不犯四節，初獨度中。言共伴者，非犯緣也。乘船等者，不涉水也。伴死等者，非本意也。《五分》水淺，無觸嬈也。次入村中。指如前者，即第三無緣也。三獨宿中。
【譯文】《僧祇律》說明檢察罪相的方法。《五分律》指示犯戒相貌。獨自落後行走之中，同於上述三種因緣；首先抵達處所而行，就是第一因緣。根本成犯，就是舉足出發之時。又以下，就是第二因緣。《四分律》以下，是第三因緣。不犯戒的四節文句中，首先獨自渡水之內。所說的「伴侶同行」，並非犯戒的因緣。乘船等等情況，是因為沒有涉水涉足。同伴死亡等狀況，並非出於本意。《五分律》說水淺之處，沒有遭到觸碰騷擾的危險。其次獨自入村之中。「指如前」的意思，就是第三種缺乏正常因緣。第三獨自留宿之中。

【694-0006】資持記/16d_下四#32
【原文】初約守戒明不犯。若下，伴有緣也。乃下，已有難也。獨行中。伴緣己難，並同上開。《僧祇、五分》，並據緣開，可解。邂逅，不期也。單提一百二十。與僧同者，如前〈釋相〉。異但出一，現行數犯；餘尋《尼鈔》，自可委明。第一百十四紡績戒。〔佛在舍衛，六群尼自手紡績，居士笑言，如我婦無異，白佛因制。
【譯文】首先依據謹守戒律說明不犯。若以下，是同伴遇到了因緣事故。乃至以下，是自己遇到了危難。獨自落後行走之中。同伴的因緣與自己的危難，都同於前文的開許。《僧祇律》、《五分律》，都是依據因緣而開許，理可想知。邂逅，是指未曾預期而偶遇。波逸提（單提）共有一百二十條。與比丘僧相同的戒條，如前面〈釋相篇〉中所述。相異的戒條此處僅提出一條，是因現今經常有所違犯；其餘若查尋《尼鈔》，自然可以詳盡明了。第一百一十四條紡績戒。〔佛在舍衛國，六群尼親手紡線織布，居士笑著說，跟我家婦人沒有兩樣，白佛因而制戒。

【694-0007】01_行事鈔/12c_卷下之四#29
【原文】七相攝諸行。尼以無伴，多度非法之人；但希利己，不準道教；故律中二十餘戒，偏結和尚之罪。故律云：度弟子已，應以衣食及法攝取。《五分》：師僧應六年自攝、若教他攝弟子，違犯墮。《僧祇》：和尚尼欲授弟子具戒，應先求善比丘，不得臨時選眾；若不可得者，當求半許、若過半而作法。《四分》云：受戒已，不得輒離和尚。《五分》：當六年依承和尚。餘有師徒教授、報恩供養、呵責治罰，並如上卷〈師資相攝〉中。
【譯文】七相攝諸行。比丘尼由於身旁無伴，往往隨意剃度不合戒法之人；只圖利益自己，不遵照聖道教誨；所以律藏中有二十多條戒，專門結歸剃度和尚尼的罪過。因此律藏說：剃度弟子之後，應當以衣食資糧及佛法善法攝受訓育她們。《五分律》記載：戒師僧應當在六年之內親自攝受、或者囑託他人代為攝受弟子，若有違反而不攝受者，犯波逸提。《摩訶僧祇律》記載：和尚尼若想為弟子傳授具足戒，應當預先尋求賢善的比丘，不得臨時隨便湊集僧眾；如果賢善者難得，應當尋求半數左右、或過半數是賢善僧人來作法。《四分律》說：受戒之後，不得擅自脫離和尚尼。《五分律》說：應當依止奉事和尚尼滿六年。其餘師徒間的教授規矩、報恩供養、呵責懲處，都如本鈔上卷〈師資相攝篇〉中所詳述。

【譯文】若比丘尼親手紡線織布者，犯波逸提。「擗」，是指分剖撕扯；「引」就是牽引拉線；「縈」，是指卷繞絲絡；「織」則自然明白；這四種事隨便作哪一種，都犯墮罪。唯恐有人以為懺悔完畢後衣服就可以穿著，所以制定不合理；隨其穿著，得突吉羅罪。現今的比丘尼女子，以織布刺繡作為生活事業。捨棄父母親人出家入道，究竟是為了圖謀何事？如果像這樣出家，又跟身處世俗有何差別！所謂想要躲避溺水卻反而投身烈火，正是說的這類人。結語之中。「上下」就是指戒本的前前後後。

【694-0010】01_行事鈔/12c_卷下之四#30
【原文】次明諸要行，勿過八敬。《善見》：佛初不度女人出家，為滅正法五百年；後為說八敬，聽出家，依教行故，還得千年；今時不行，隨處法滅；故須勵意。今列其名：一者百歲比丘尼，見初受戒比丘，當起迎逆、禮拜、問訊、請令坐。二比丘尼不得罵謗比丘。三不得舉比丘罪，說其過失；比丘得說尼過。四式叉摩那，已學於戒，應從眾僧求受大戒。五尼犯僧殘，應半月在二部僧中行摩那埵。六尼半月內，當於僧中求教授人。七不應在無比丘處夏安居。八夏訖，當詣僧中求自恣人。如此八法，應尊重恭敬讚歎，盡形不應違。
【譯文】次明諸要行，勿過八敬。《善見律毘婆沙》說：佛陀起初不度女人出家，是為了避免正法提早五百年滅亡；後來為她們宣說八敬法，才准許出家，因依教奉行的緣故，正法住世依然可得千年；現今之人若不遵行，隨所到之處佛法便隨之衰滅；所以必須勉勵留心。現今列出其名稱：第一、即使是百歲戒臘的比丘尼，見到剛受戒的比丘，也應當起立迎迓、頂禮拜伏、問訊起居、恭請其就坐。第二、比丘尼不得辱罵毀謗比丘。第三、比丘尼不得舉發比丘罪過、宣說其過失；比丘則得宣說尼眾之過失。第四、式叉摩那（正學女）完成學戒之後，應當向二部僧眾乞求傳受具足戒。第五、比丘尼犯僧殘罪，應當在半個月內於二部僧中行摩那埵（悅眾意悔過法）。第六、比丘尼每半月之內，應當向比丘僧中求請教誡教授之人。第七、比丘尼不應在沒有比丘居住的處所進行夏安居。第八、夏安居結束後，應當前往比丘僧中求請自恣之人。這八種法則，應當尊重、恭敬、讚歎，終身（盡形壽）不得違背。

【694-0012】資持記/16d_下四#36
【原文】凡攝弟子，不出有二：一者事攝，即衣食；二者義攝，即法訓；衣食可闕，法不可無。《五分》：六年自攝，和尚親教也；比丘五夏，分差降也。若教他攝者，付餘人也。《僧祇》，次明受具。當求半許者，據本僧尼，各須十人，準邊方開，但五人耳。過半者，極至十也。
【譯文】大抵攝受教導弟子，不出兩種方式：一是物質供養攝受（事攝），就是衣食醫藥；二是法義精神攝受（義攝），就是佛法教訓；衣食可以匱乏，佛法教導絕不可無。《五分律》說：六年親自攝導，是由和尚尼親自教導；比丘滿五夏即可，這顯示出二眾之間的差別降等。如果交由他人攝導，則是交付給其餘的人。《僧祇律》接著說明受具足戒的事相。應當求取半數左右，是依據原本僧尼二眾，各需要十人，準照邊地開許的特例，只需要五人罷了。超過半數，最多則達到十人。

【694-0013】資持記/16d_下四#37
【原文】注中。以犯殘已下，並足生善門事，故唯簡犯重；恐其求備，法事難成；但選秉法之人，餘人但不犯重，不必具美，故云可可。此據無人，有則須擇。《四分》下，三制依師。本律不限年數，故引《五分》決之。餘下，指略。要行中，初科，《善見》本緣。
【譯文】注解之中。因為犯僧殘以下的罪，都還足以生長善法而能參與羯磨僧事，所以只嚴格簡擇犯重戒之人；唯恐一味強求圓滿無瑕，導致法事難以成就；只要選拔主持行法之人，其餘之人只要不犯重罪，不一定非要十全十美，所以說是「大致尚可」。這是依據缺乏如法人選時而言，若有人選則必須詳細挑選。《四分律》以下，第三說明必須依止師長。本律沒有限定具體年數，所以引用《五分律》來作決斷。其餘以下，指出省略之文。重要行儀中，第一科是《善見律》所載的根本因緣。
