# 校閱材料　第293檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【293-0001】資持記/11b_中四上#32
【原文】心念不常，前後具缺，不出八句，括之斯盡。初句歷示三心重相。尤即訓甚，但非極甚，即是輕心。然極甚難明，略須示相。但約起心，念念不間，色心躁悶，不愧旁人；神思昏迷，都忘善事；奔趨前境，暢悅己情。三邪見居懷，撥無因果；向親姻作穢，對塔殿行非。
【譯文】心念並不恆常，前後三時的善惡具足或欠缺，不出八種句型，總括於此便已窮盡。第一句依序顯示三種時段都是重心的行相。「尤」就是「甚」的意思，只要不是極度嚴重，就屬於輕心。然而極度嚴重的行相難以明瞭，必須略微提示其面貌。只要看起心動念時，念念相續不間斷，身心躁動煩悶，在旁人面前不知慚愧；神思昏沉迷亂，全然忘卻善事；奔向所緣之境，一心只求滿足自己的快意。又或者懷抱邪見，撥無因果；對親族姻親行污穢淫行，在佛塔殿堂前胡作非為。

【293-0002】資持記/11b_中四上#33
【原文】凡此用心，皆名定業；能牽來報，縱懺不亡。以此自量，何容輕動。識心之士，豈不畏乎！文中，句數交絡；欲令新學易曉，為圖示之。初一句三┐┌方便┐├┤根本├重時俱重─┘└成已┘┌方便┐│　　├重┌初句┤根本┘│　　└成已─輕第二三句┐│　　┌方便─輕├┤中句┤根本┐二重一輕┘│　　│　　├重│　　└成已┘│　　┌方便┐└後句┤　　├重│成已┘└根本─輕┌根本─重│方便┐┌初句┤　　├輕│　　└成已┘第三三句┐│　　┌方便─重├┤中句┤根本┐一重二輕┘│　　│　　├輕│　　└成已┘│　　┌成已─重└後句┤方便─┐│　　　├輕
【譯文】凡是這類用心，全都被稱為「定業」；必定能牽引未來的惡報，縱然懺悔也無法滅除。以此自我衡量，怎能輕舉妄動！識得自心之士，難道能不畏懼嗎！文中各句交錯繁複，為了讓初學之人容易理解，故製圖以彰顯之。第一句的三時皆重：包含方便時、根本時、成已時，三時皆為重心。第二類的「二重一輕」包含三句：初句為方便與根本俱重、成已轉輕；中句為方便輕、根本與成已俱重；後句為方便與成已俱重、根本反輕。第三類的「一重二輕」亦含三句：初句為根本重、方便與成已俱輕；中句為方便重、根本與成已俱輕；後句為成已重、方便與根本俱輕。

【293-0003】資持記/11b_中四上#34
【原文】└根┘第四一句┐┌方便┐├┤根本├輕三時俱輕┘└成已┘若以四位分之，上句最優，下句至劣，中二通優劣。若約八句論之，則句句相降；中間二位，各有三句；竝依重輕次列，比之自見。第四中。引諸經律，舉事顯相；雖懷憐愍，非無殺意，俱輕可知。會通中，初正明。
【譯文】與根本俱輕。第四句的三時皆輕：包含方便時、根本時、成已時，三時皆為輕心。若以四個位階來區分，第一句最重（為優），最末句最輕（為劣），中間二位則互通優劣。若就八句逐一而論，則是句句遞降減輕；中間兩個位階各有三句，全都是依照由重至輕的次序列出，一加比對自然明瞭。在第四項中。引用諸經論與律典，列舉實際事相以顯明行相；雖然懷抱憐憫之心，但並非全無殺意，所以三時皆輕是可以理解的。在會通義理中，最初正面說明。

【293-0004】資持記/11b_中四上#35
【原文】謂若依律制，則無輕重；今取心業，故分八句。故下，引證。律據制罪，人重於畜；論就心業，畜重於人。第十門，標中。有心通含輕重，無心與前為異。歷句竝同。初一句三┐┌方便┐├┤根本├有時俱有心┘└成已┘┌方便┐│　　├有┐┌初句┤根本┘　├四戒俱重│　　└成已─無┘第二三句┐│　　┌方便─無┐├┤二句┤根本┐　├四戒俱重二有　無┘│　　│　　├有┘│　　└成已┘│　　┌方便┐└三句┤　　├有┐│成已┘　├初戒重餘三方便蘭成已吉└根本─無┘┌根本─有┐│方便┐　├四戒俱重┌初句┤　　├無┘│　　└成已┘第三三句┐│　　┌方便─有┐
【譯文】這就是說，如果單依律典佛制，並沒有輕重之別；如今是取內心的業道來論，所以區分為八句。在「故」字以下引文作證。律典依據制罪，殺人罪重於殺畜生；經論依據心業，殺畜生有時反而重於殺人。第十門，標題中。所謂「有心」，通括輕心與重心；「無心」則與前門有異。各句的推演排列完全相同。第一句三時皆有心：即方便、根本、成已三時全都有心。第二類「二有一無」含三句：初句為方便與根本有心、成已無心，四戒皆結重罪；中句為方便無心、根本與成已俱有，四戒亦皆重；第三句為方便與成已有心、根本無心，初戒（淫戒）結重罪，其餘三戒方便時結偷蘭遮、成已時結突吉羅。第三類「一有二無」亦含三句：初句為根本有心、方便與成已無心，四戒皆結重罪；

【293-0005】資持記/11b_中四上#36
【原文】├┤二句┤根本┐　├初戒重三戒方便蘭吉一有二無┘│　　│　　├無┘│　　└成已┘│　　┌方便┐└三句┤　　├無┐│根本┘　├初戒重三戒成已吉└成已─有┘第四一句┐┌方便┐　　婬戒怨逼├┤根本├無　禁心三戒三時俱無┘└成已┘　　始終迷忘優劣之義，亦如上明。
【譯文】第二句為方便有心、根本與成已無心，初戒結重罪，其餘三戒方便時結偷蘭遮或突吉羅。第三句為方便與根本無心、成已有心，初戒結重罪，其餘三戒成已時結突吉羅。第四句三時皆無心：方便、根本、成已三時皆無心。此時淫戒若遇怨家強逼，以及禁心防護的他戒在始終迷失遺忘的情況下，皆不結罪。優劣的意涵，也如同前文所說明。

【293-0006】資持記/11b_中四上#37
【原文】若八句相望者，但以第二位中，後句在下；第三位中，初句在上，則次第義便。問：下句無罪，豈名犯劣？答：但望教開，故無有罪；非不造事，故入犯中。引例中。欲示此門有所據故。本作念者，即方便時；正妄時知，即根本時；說已，即成已時，如小妄中具引。料簡中，初科。可解。
【譯文】如果將這八句互相比對，只要將第二位階之中的後一句排在下方，第三位階之中的第一句排在上方，其先後次第的義理就順暢了。有人問：最末一句既然無罪，怎能列入「犯戒」的劣品之中？回答：這只是從教法開許的角度來看，所以判定為沒有罪過；但並非沒有造作這件事，所以仍然歸入犯戒門中。在引證通例中，是想顯示此門是有根據的。所謂「原本起意作念」，就是指方便時；「正說妄語時明知」，就是根本時；「說完之後」，就是成已時，如〈小妄語戒〉中詳細引用。在辨析考核（料簡）中，第一科容易理解。

【293-0007】資持記/11b_中四上#38
【原文】應知前約化業，此據制教。次文，初牒前。對上輕重，故云後明。〔或可別點第四俱無。〕或下，示相，初句別簡婬戒。此門明婬，竝據怨逼，三時有無；若約自造，境合即犯，不約三時，境想不開，無心亦重，故非所論。及下，合示三戒。通約迷心，不了前境。
【譯文】應當知道前面是就化教業道而論，此處是依據制教戒律而言。下一段文中，最初重提（牒）前文。為了對照上方的輕重，所以說「後明」〔或者也可以特別指點第四種三時俱無心〕。在「或」字以下指示行相，第一句特別簡別淫戒。本門說明淫戒，完全是依據怨家強行逼迫時，三時之中到底是有心還是無心；如果是自己主動造作，只要身境交會即刻成犯，不論三時如何，境想也不開許，即便無心也是重罪，所以不在此例。在「及」字以下，合併說明其餘三條戒，普遍就迷亂之心、無法辨明眼前對象而言。

【293-0008】資持記/11b_中四上#39
【原文】又復婬戒，於三時中，隨有一時，無非皆重；俱無方開。餘之三戒，重輕不定；初有餘無，或吉或蘭，竝方便故；中有餘無皆重，竝根本故；後有餘無皆吉，竝隨喜故。統約十門，二三四五十，竝就制教；初六七八，俱通化制；第九唯局化教。如是尋之。第七門。五章教義，共聚一門，故云雜也。
【譯文】再者，淫戒在三時之中，只要有任何一時受樂，無一例外全都是重罪；唯有三時全無受樂才得以開許免罪。其餘的三條戒，其輕重則不一定：最初有心而其餘時段無心，或結突吉羅或結偷蘭遮，都屬於方便階段；中間有心而其餘無心則全結重罪，因為屬於根本階段；後段有心而其餘無心全結突吉羅，因為屬於隨喜階段。總括上述十個門類：第二、三、四、五、十門，完全是就佛制戒律而論；第一、六、七、八門，皆通於化教與制教；第九門則唯局限於化教。應當依照這個原則去探尋研讀。第七門。共有五章的教說義理匯聚在同一個門類，所以稱為「雜」。

【293-0009】資持記/11b_中四上#40
