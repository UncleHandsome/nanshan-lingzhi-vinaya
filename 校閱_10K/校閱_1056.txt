# 校閱材料　第1056檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1056-0002】資持記/05e_上四#36
【原文】若少，若等〔客主數同〕，若多〔客多於主〕；竝隨上下座，依次自恣〔今文不引，以易知故。〕；若自恣竟，舉眾未起，若已起，客來少者，應與清淨；不與，如法治；若等，若多，應更自恣；不者，如法治。若下，別示別人。僧法即五人，對首同四人，故竝指如前。第五問。答中。破夏可解。
【譯文】如果來的客人少，或者與主人數目相等〔客主數同〕，或者多於主人〔客多於主〕；都要隨著上下座次，依次自恣〔今文沒有引述，因為容易了解的緣故〕。如果自恣已經結束，大眾還沒有起身，或者已經起身，客人來得少的，應當給與清淨；不給與的，依律法治罪。如果人數相等，或者來得多，應當重新自恣；不這樣做的，依律法治罪。「若」字以下，是另外指示對首、心念等個別人的作法。僧法就是五人，對首法同於四人的情形，所以都指向前面所說。第五問。回答之中，破夏的道理可以理解。

【1056-0003】資持記/05e_上四#37
【原文】言離衣者，以未入迦提故。受日中。此謂七月九日受者。下引文證。疏云：如律所制，及七日還；今限明相，乃在界外；絕此分齊，故說破夏；又云：七月十日受七日，至第七日是夏滿，不來無犯。〔準知從十已去受者，前緣未竟，不來奔夏。〕六問。答中。
【譯文】所說的「離衣」，是因為還沒有進入迦提月的緣故。在「受日」一段中。這是指七月九日受七日法的人。下面引文作證明。《戒疏》說：依律所制，滿七日就要回來；現在期限到明相時，人卻還在界外，斷絕了這個分齊，所以說破夏。又說：七月十日受七日法，到第七日就是夏滿，不回來也沒有過失。〔由此可知，從七月十日以後受日的人，前面的因緣還沒結束，不回來趕赴夏安居的圓滿。〕第六問。回答之中。

【1056-0004】資持記/05e_上四#38
【原文】《四分》：受日往餘處自恣，及客來多少，有難出界，竝非當處。而《僧祇》結罪者，乃制無緣輒往耳。第七問中。謂時僧得，時現前；此二種施，竝賞夏勞故；非時二施，非所論矣。若二衣中，時現前施，局前安居人者；中後非分，如後明之。答中，初引文明許。雖是中後，夏功齊故。破夏不結，定不預分。
【譯文】《四分律》說：受日到別處去自恣，以及客僧來的或多或少，或遇災難而出界，這些都不算在「當處」。而《僧祇律》判結罪過，只是制止沒有因緣就隨便前往罷了。第七問中。所說的「時僧得」、「時現前」，這兩種布施都是酬賞夏安居的辛勞；非時的兩種布施，就不在討論之內了。如果在〈二衣篇〉中，時現前施只限於前安居的人，那麼中安居、後安居的人就沒有分，如後面所說明。回答之中，最初引經文說明允許。雖然是中安居、後安居，夏安居的功勞相同，所以也得。至於中途破夏者與一向未結夏者，必定不得參與分配。

【1056-0005】資持記/05e_上四#39
【原文】若下，引房為例。律中，分房已；猶故多者，開客住處；乃知中後安居，得受房舍；夏竟分物，可以例證。八問中。有緣開略，無難如何？恐致濫行，故須問決。答中。律明六群恐餘比丘為作羯磨，遮自恣故，乃起諸過。文列七種，五是非法，二是別眾。
【譯文】「若」字以下，引用分配房舍之事作為例證。律中說：分房已畢，還有剩餘的，就開許作為客僧的住處；由此可知，中安居、後安居的人也可以接受房舍；夏安居結束後分物，可以比照證明。第八問中。有因緣時開許用略法，沒有災難時又該如何？恐怕導致濫用，所以必須提出問答來決斷。回答之中。律中說明六群比丘恐怕其他比丘為他們作羯磨，所以阻礙自恣，因而生起種種過失。文中列出七種，其中五種是非法，兩種是別眾。

【1056-0006】資持記/05e_上四#40
【原文】因一說二說，佛即制斷自今已去，三說自恣。竊語，謂低聲。佛言：應了了自恣，足使他聞。疾疾，即急語；佛言：應徐徐自恣。明教詔中，初教年少，有三，初二師預教。猶下，五德臨事教。句句，謂隨教者語，逐句說之。二教年老，初躡前問。答中，初答同。故下，引例。九問。答中。
【譯文】因為只說一遍、兩遍，佛就制斷：從今以後，要說三遍自恣。「竊語」，是指低聲說話。佛說：應當清清楚楚地自恣，足以讓別人聽見。「疾疾」，就是說得太急；佛說：應當慢慢地自恣。說明教導訓示的部分中，第一是教導年少比丘，分為三節，第一節是二師（和尚、阿闍梨）預先教導。「猶」字以下，是五德在臨事時教導。「句句」，是指隨著教導者的話，逐句跟著說。第二是教導年老的比丘，開頭承接前面的問。回答之中，先回答相同的部分。「故」字以下，引用例證。第九問。回答之中。

【1056-0007】資持記/05e_上四#41
【原文】律因前後安居人雜住，不知隨何自恣；白佛。初令隨上座，上座中又有前後。〔主客各有上座。〕次令隨舊住，復有前後。令隨多者，如文所引。第十問。答中，初引制教定犯，《四分》文通。下引《母論》。既云出界，即是僧住；無緣結犯，應得輕吉。文言緣者，或是三寶，或約難事；隨有阻礙，不可去者。
【譯文】律中因為前安居與後安居的人混雜住在一起，不知道該隨哪一邊自恣，於是向佛稟白。佛最初說隨上座，但上座之中又有前安居、後安居的分別。〔主人與客人各自都有上座。〕其次說隨舊住的人，但舊住的人中也有前安居、後安居。最後才說隨人數多的一方，如文中所引。第十問。回答之中，先引制教判定犯戒，《四分律》的文義較為通泛。下面引《母論》。既然說「出界」，就是指離開僧眾安住的地方；沒有因緣而結罪，應當得到輕的突吉羅。文中所說的「緣」，或者是指三寶的事，或者是指災難之事；只要是有阻礙、不能前往的，就不算犯。

【1056-0008】資持記/05e_上四#42
【原文】《五分》。受請，正據俗舍；有惱請主，故結重提。非請處者，即是僧舍；反上得住，準前應吉。次約化教顯過。五中，一二可見；或下，三句為三種。二三相濫，以義分之；上是慳悋，下即貪求，或可上約田宅園林，下是錢寶󰝿帛。此五，無非慳貪多事，非出家業；遠離此者，成德可知矣。
【譯文】《五分律》。受請，正是就著俗人的房舍而說；因為會惱亂施主，所以結成重的波逸提。不是受請的地方，就是僧舍；與上面相反，可以停留；比照前面，應當得突吉羅。其次就化教顯示過失。五種之中，第一、第二可以明白；「或」字以下三句，分為三種。第二與第三容易混淆，要按義理區分：上面是慳吝，下面就是貪求；或者可以說上面是就田宅園林而說，下面是就錢財珍寶、穀米布帛而說。這五種，無非都是慳貪和好事多務，不是出家人的本業；能遠離這些，成就德行就可想而知了。

【1056-0009】資持記/05e_上四#43
【原文】迦絺那衣。律中，佛在舍衛拘薩羅國；諸比丘夏安居竟，往見世尊；道路值雨，衣濕僧伽梨重，疲極；又寒雪國，糞掃衣比丘，來見世尊；亦值天雨，疲極；因聽受功德衣，開五種利。注中翻名，《了論》四名。第二從施主，餘三就功能。上二名下，自釋。無敗壞者，補舊易新也。
【譯文】迦絺那衣。律典記載，佛陀住在舍衛國拘薩羅國時；諸比丘結束夏安居後，前往探視拜見世尊；在半路上遭遇大雨，衣服濕透使得大衣僧伽梨極為沉重，身體困頓疲極；又有寒雪國的糞掃衣比丘前來拜見世尊；同樣遭遇天下大雨，困頓疲極；佛陀因此聽許接受功德衣，開許五種便利權益。注文中翻譯名義，《了論》列出四種名稱。第二個名稱是順從施主而立，其餘三種是依據功能來立名。「上二名」以下，自作解釋。所謂「無敗壞」，是指修補舊衣換成新衣。
