# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【165-0001】02_戒疏/08b_卷二下之一#32
【原文】【記】三中，初正明。「俗人」無濫，下眾未具，無破僧理，故但有四。亦通伴助，如後所明。「俱」下，引《論》。初引《論》偈。「餘界」，即色、無色天。次引《論》解，前簡人道，別除黃門，文列三義。初「無戒因」者，以具戒者，方能具造，「黃門」當體，即戒障故。次「父母」下，明上恩疎。「增上」，謂身不具，形報非勝故。「又」下，顯下敬薄。故有殺者，不成逆業，然文中但明父母二逆，餘不能作，於義可知。「畜」下，簡餘趣。文約愚智，以明有無。據《論》「有」者，可對三逆。豈有非、畜而能破僧、出血耶？《論》無「五」字，必是傳訛。
【譯文】【記文】第三小科中，首先正面闡明。「在俗之人」界限分明，未受具足戒的下四眾弟子尚未圓具大戒，依律絕無單獨破僧的道理，所以他們只有四種逆罪。但他們也可以作為破僧的同伴或隨助者，如後面所明示。從「《俱舍》」往下，引用論典。首先引用《俱舍論》的偈頌。「其餘界」，就是指色界與無色界諸天。接著引用論中的解釋，前面先簡別在人道當中，特別排除黃門（性殘缺者），文中列出三種理由。第一是「無戒因」，因為唯有具足完備戒體之人，才能完全造作逆罪，黃門其身當下就是戒法的障礙。第二從「父母於其恩少」往下，說明父母所施的恩德相對疏淡。「不具身分為增長」，是說身體有殘疾，所得的果報並非殊勝。第三從「又其於父母」往下，顯明為子者孝敬之心淡薄。所以黃門若有殺害父母之事，並不構成真正的無間逆罪，然而文中只針對殺父母兩種逆罪來說明，其餘逆罪他們無法造作，在道理上顯而易見。從「畜生」往下，簡別排除人道以外的其餘各趣。論文依據愚笨與智慧的差別，來說明能否造業。依照《俱舍論》所說「有智者能造」，頂多只能對應三種殺逆罪。怎麼可能非人、畜生能去破僧、使佛身出血呢？原本論典中沒有「五」這個字，必定是傳抄過程中的錯誤。

【165-0008】02_戒疏/08b_卷二下之一#39
【原文】【疏】一、種子不淨，攬父母形以為己有。故偈云：「是身種不淨，非餘妙寶物，不由白淨生，但從穢道出。」
【譯文】【疏文】第一、種子不淨，攬取父母的精血形相作為自己的身體。所以偈頌說：「這個身體的種子本來就不乾淨，並不是世間其他美妙的珍寶，它不是由清白潔淨之物所產生，純粹是從污穢的孔道中流出。」

【165-0009】02_戒疏/08b_卷二下之一#40
【原文】【記】引示中，初「不淨」中。《論》云：「父母以妄想邪憶念風，婬欲火故，血髓膏流，熱變成精。宿行因緣，識種子在赤白精中住，是名身種。」偈中，初句標示，下三句釋成。上句明當體不淨，下二句生出不淨。「穢道」，即父母便利處也。
【譯文】【記文】在引論開示中，第一種「不淨觀」中。《大智度論》說：「父母因為妄想顛倒的邪念欲風，引動淫欲之火，以致血髓脂膏流動，受熱轉變成為精液。眾生往昔所作的宿業因緣，使神識種子安住在赤白精血當中，這就稱為身軀的種子。」偈頌中，第一句標明提示，後三句解釋成立。前一句說明種子本身當體不淨，後兩句說明產生的管道不淨。「穢道」，就是指父母排泄大小便的污穢部位。

【165-0010】02_戒疏/08b_卷二下之一#41
【原文】【疏】二、依處不淨，謂在生熟兩藏中間。故偈云：「是身為臭穢。不從華間生，亦不從薝蔔，又不出寶山。」
【譯文】【疏文】第二、住處（依處）不淨，也就是胎兒處在母體的生藏與熟藏兩者之間。所以偈頌說：「這個身體本來就是發臭污穢的。它不是在花叢花朵之間誕生，也不是從清香的瞻蔔花中生出，更不是產自珍貴的寶山之中。」

【165-0011】02_戒疏/08b_卷二下之一#42
【原文】【記】第二。「依處」，亦名生處。人有生熟二藏，食在生藏，猶未變動，流入熟藏，即成糞穢，胎處于中，故云「不淨」。偈中，初句標，下三句簡非淨處，以顯不淨。「薝蔔」，亦花，而別舉者，以花極好，彼國所貴，經論多引，蓋此意也。此翻「黃花」。
【譯文】【記文】第二種。「依處」也叫做生處。人體內有生臟與熟臟，食物剛進入生臟時，尚未消化腐壞，流進熟臟之後，就轉變成了糞便污穢，胎兒就夾處在二者正中間，所以說是「不淨」。偈頌中，第一句標示體質，後三句排除了各種清淨高雅的處所，以此顯發其污穢本質。「薝蔔」也是一種花，之所以特別提出，是因為此花芬芳美好，在印度極受尊崇，經論經常引作比喻，正是這個用意。中文翻譯為「黃花」。

【165-0012】02_戒疏/08b_卷二下之一#43
【原文】【疏】三、當體不淨，謂三十六物，成身十二，內外兩相，各十二也。故偈云：「地水火風質，能變餘不淨，傾海洗此身，不能令香潔！」
【譯文】【疏文】第三、本體（當體）不淨，是指由三十六種不淨物質構成，塑造身體結構的有十二種，內在與外在的體相各有十二種。所以偈頌說：「地、水、火、風四大構成的肉體，能把其餘攝入之物轉化成不淨，即使傾倒整個大海的水來清洗這個身體，也絕對無法讓它變得芳香純潔！」

【165-0013】02_戒疏/08b_卷二下之一#44
【原文】【記】三。「當體」者，亦云自性。「三十六物」，《論》中備列，總判為三，而少不次。今以義分：髮、毛、爪、齒、薄皮、厚皮、筋、肉、骨、髓、血、心；脾、腎、膽、肝、肺、小膓、大腸、胃、胞、肪、𦚻、腦膜；屎、尿、垢、汙、淚、涕、涎、唾、膿、黃、白痰、癊。偈中上句示體，次句明流變，餘不淨者總上諸物。下二句顯示不淨。
【譯文】【記文】第三種。「當體不淨」，也稱為自性不淨。「三十六種物質」，《大智度論》中詳細列出，總共判定為三類，只是順序稍有交錯。現在依文義重新劃分：第一類有頭髮、體毛、指甲、牙齒、薄皮、厚皮、筋脈、肌肉、骨頭、骨髓、血液、心臟；第二類有脾臟、腎臟、膽囊、肝臟、肺臟、小腸、大腸、胃囊、膀胱、脂肪、肌肉膏油、腦髓腦膜；第三類有糞便、尿液、皮垢、汗污、眼淚、鼻涕、唾液、口水、濃汁、膽汁、白痰、胸痰胸水。偈頌中第一句指出四大之體，第二句說明體內的轉化排泄，其餘不淨之物總括了上述各項。後兩句則極力顯明身體的不淨本色。

【165-0014】02_戒疏/08b_卷二下之一#45
【原文】【疏】四、外相不淨者，九孔常流，俱不可用。故偈言：「種種不淨物，充滿於身中；常流溢不止，如漏囊盛物。」
【譯文】【疏文】第四、外貌（外相）不淨，身體的九個孔竅常年排泄污穢，全都不能碰觸食用。所以偈頌說：「種種污穢骯髒的東西，充斥充滿在人的身軀當中；不停地向外滲漏流溢，就像破漏的皮囊盛裝著穢物一樣。」

【165-0015】02_戒疏/08b_卷二下之一#46
【原文】【記】四中。「九孔」，眼、耳、鼻、口，及大、小道。偈中，上二句明內穢，下二句示外相。
【譯文】【記文】第四種當中。「九孔」，指眼睛兩只、耳朵兩只、鼻孔兩個、嘴巴一張，以及大小便的排泄通道。偈頌中，前兩句說明內在的污濁，後兩句顯露外在排泄孔竅的骯髒相貌。

【165-0016】02_戒疏/08b_卷二下之一#47
【原文】【疏】五、究竟不淨，終歸死膖，不可忍見。故偈言：「審諦觀此身，終歸必死處。難御無反覆，背恩如小兒。」
【譯文】【疏文】第五、最終（究竟）不淨，壽終之後必定歸於死亡腫脹腐爛，令人無法忍心直視。所以偈頌說：「應當審慎諦實地觀照這個身體，它最終必定走向死亡腐爛的下場。大限一旦到來便無法抵禦留住，毫無轉圜復生，捨棄時背叛昔日恩寵就像任性無情的小孩。」

【165-0017】02_戒疏/08b_卷二下之一#48
【原文】【記】第五。《論》云：「身若投火則為灰，若虫食則為屎，在地則腐爛，在水則膖脹。」偈中，上半標示，下半釋成。時至莫留，故云「難御」。奄然長往，故「無反覆」。生存資養，一旦捨棄，故云「背恩」。「小兒」，相似法故。
【譯文】【記文】第五種。《大智度論》說：「這個身體如果投進烈火就會化為灰燼，如果被蛆蟲吞食就變成糞便，棄置在土地上就會腐爛變臭，浸泡在水中就會腫脹破裂。」偈頌中，上半部標明提示，下半部解釋成立。死期一到誰也無法阻擋，所以說「難御」。氣絕長逝不再回轉，所以說「無反覆」。活著的時候百般供養資助，一旦命終便被徹底捨棄，所以說是「背恩」。用「小兒」來比喻，是因為任情翻臉的性質相似。

【165-0018】02_戒疏/08b_卷二下之一#49
【原文】【註】彼習定已，厭患身命，歎死，勸死。
【譯文】【註文】那些比丘修習不淨定之後，極度厭棄嫌患自己的身軀生命，於是讚歎死亡的解脫，甚至勸誘彼此尋死。

【165-0019】02_戒疏/08b_卷二下之一#50
【原文】【疏】注云「彼習定已，厭患身故，歎死，勸死」者，以修乖方，少於遣滯，故習此觀，封著不捨，便滅其身，此非有智。
【譯文】【疏文】注文說「他們修習定法之後，由於極度厭棄身體的緣故，讚歎死亡、勸人尋死」，這是因為修習的方法有偏差，缺少了破除執滯的智慧，所以在修習這個觀法時，牢固執著不捨，以致於滅絕自己的肉身，這絕不是有智慧的行徑。

【165-0020】02_戒疏/08b_卷二下之一#51
【原文】【記】三中，初科。智能遣滯，有修無智，即是「乖方」。
【譯文】【記文】第三科中，這是第一小段。智慧能夠排除執著滯礙，空有修行而沒有智慧，這就是「乖違法度」。

【165-0021】02_戒疏/08b_卷二下之一#52
【原文】【疏】《善見》云：「『佛是一切智人，何因說觀乃令其死？』答：『深見往機曾作獵師，多殺群鹿，已墮地獄，餘報出家。若不說觀，人殺生惱，惡心無已；由作此觀，人殺生喜，得生天上，故無咎也。乃至說已，入靜室中，五百人死，同世不知，知必制戒，息世機故。』」
【譯文】【疏文】《善見律》說：「『佛陀是一切智人，為什麼宣說不淨觀卻反而導致比丘們自殺殞命？』回答：『因為佛陀深切徹見這些人過去世的業緣，他們曾當過獵人，大肆殺戮鹿群，本已墮入地獄受苦，以殘餘的惡報今生得以出家。如果不為他們宣說不淨觀，他們在被人殺害時會心生瞋恨惱怒，惡心難以休止；由於修作了這種不淨觀，他們在面對被殺時反而心生歡喜，死後得以生天享福，所以佛陀說此法並無過失。乃至於佛陀宣說完之後，進入靜室安住入定，期間有五百人自殺，佛陀示同世俗凡夫一樣不知情，因為知道的話就必須當場制定戒律，這樣做是為了平息世俗的譏嫌誹謗。』」

【165-0022】02_戒疏/08b_卷二下之一#53
【原文】【記】引示中。如來大智，鑒機授法，藥病不差，今此殺緣，全乖上義。《論》申佛意，以決群疑，相似差機，實唯應病。答中，初敘知機獲益，「乃」下，明示現不知。佛自明鑒，示同凡人，故云「同世」。若不如此，必生外謗，故云「息譏」。
【譯文】【記文】在引用論典的解釋中。如來具備圓滿大智，洞察根機而傳授佛法，開出的藥方與病症絕無差錯，現在這種殺生引發的因緣，表面上完全違背了上述常理。《善見律》代為闡明佛陀的心意，用來破除大眾的疑難，表面看似藥不對症，實質上完全是為了因應宿世業病。回答中，首先敘述佛陀明察因緣而使比丘獲得解脫之益，從「乃至說已」往下，說明佛陀暫時示現為不知情。佛陀自心徹照分明，外表卻示現得如同凡人一般，所以說「同世不知」。如果不這樣示現，必定引發外界嚴重的毀謗，所以說「息滅譏嫌」。

【165-0023】02_戒疏/08b_卷二下之一#54
【原文】【註】難提比丘受雇殺人，居士警怖。
【譯文】【註文】難提比丘接受僱用幫人殺人，使在家的居士們深感驚恐驚怖。

【165-0024】02_戒疏/08b_卷二下之一#55
【原文】【疏】言「難提受雇」者，《善見》云：「是外道沙門也，頭留少髮，依比丘住，拾殘食活。」
【譯文】【疏文】注文所說的「難提接受僱用」，《善見律》指出：「他其實是個外道沙門，頭頂上留有一點點頭髮，依傍著比丘僧團居住，靠著拾取僧團吃剩的殘羹剩飯維持生計。」

【165-0025】02_戒疏/08b_卷二下之一#56
【原文】【記】雇殺中。注稱「比丘」，《疏》號「沙門」，由此二名，通邪正故。「留少髮」者，表異內眾，亦著壞色衣，一以覆身，一置肩上。
【譯文】【記文】在受雇行殺的一段中。注文稱他為「比丘」，《疏文》稱為「沙門」，這是因為這兩個名稱，本來就通稱於正法與外道邪說。「留有一點頭髮」，是用來表示不同於佛門僧眾，他也穿著壞色法衣，一件遮蔽身體，一件搭在肩膀上。
