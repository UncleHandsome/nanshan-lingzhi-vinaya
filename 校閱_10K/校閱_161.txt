# 校閱材料　第161檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【161-0001】01_行事鈔/07d_卷中之三#17
【原文】瞋打比丘戒七十八。四緣：一大比丘，二生瞋心，三作打意，四著便犯。律中，打犯重者，亦墮。若以手石杖等墮，若餘戶鑰拂柄挃者吉羅。《十誦》：如一把沙豆，散眾多比丘，隨著一一墮。《伽論》：欲心打女人，僧殘。《僧祇》：若惡象馬牛羊，來入塔寺，觸突形像，壤華果樹，得以杖打木石，恐怖令去；不得杖擬畜生，一一吉羅。律不犯者：有病須人椎打；食噎，椎脊；共語不聞，觸之；乃至誤觸，不犯。撿諸經律，無為訓治，故開比丘行笞杖者。釋迦一化並無，末代往往見有；前卷已明，故是法滅之相。《大集經》云：若道俗等，打破戒無戒比丘，罪重出萬億佛身血。何以故？以能示人出要道，乃至涅槃故。《智論》：律中結戒，為世間事，為攝僧故，為護佛法故；有人有眾生，隨逐假名而結戒，不觀後世罪多少。如道人鞭打、殺牛羊，罪重而戒輕；歎女人戒罪重，後世罪輕等。
【譯文】瞋打比丘戒七十八。構成犯戒有四種因緣：一、對方是具足戒大比丘；二、心中生起瞋恨忿怒；三、具有毆打對方的企圖；四、擊中對方身體便構成犯戒。律典中說，毆打犯了重罪（如波羅夷）的人，也同樣結犯墮罪。若是用手、石頭、木杖等擊打，結犯墮罪；若是用門鑰匙、拂塵柄等物品輕微戳刺觸碰，結犯突吉羅罪。《十誦律》說：如果抓起一把沙子或豆子撒向眾多比丘，沙豆擊中幾人，便一一結犯幾個墮罪。《毘尼摩得勒伽》（伽論）說：若以貪欲淫心拍打女人，犯僧殘罪。《摩訶僧祇律》說：如果有兇暴的象、馬、牛、羊闖入佛塔寺院，衝撞碰撞佛像、毀壞花果樹木，可以用杖擊打木頭或石頭發出聲響，以此恐嚇讓牠們離開；不得直接用杖擊打或比劃威嚇牲畜，否則一一結犯突吉羅罪。律典中規定不犯的情況：對方有病需要他人捶按敲打；吃東西噎住而捶打其背部；與對方說話他聽不見而用手觸碰提醒；乃至無意中失誤碰到，都不算犯戒。檢閱各部經藏與律藏，佛陀絕無為了訓誡懲罰而開許比丘動用笞杖打人之事。釋迦牟尼佛一生化導教法中完全沒有這種事，末法時代卻往往能見到比丘鞭杖懲人；前卷中已經辨明，這實在是正法衰滅的徵兆。《大集經》說：若有出家人或在家人毆打破戒乃至無戒的比丘，其罪過深重於出萬億佛身之血。為什麼呢？因為出家人哪怕破戒，其形象依然能向世人開示出離生死之要道，乃至引導眾生證得涅槃的緣故。《大智度論》說：律藏中制定戒律，是為了隨順世間防譏嫌之事、為了統攝清淨僧團、為了護持正法久住；是依於世間有人、有眾生的假名施設而結定罪名，並非完全依照後世業報之罪業輕重來定罪。例如出家人鞭打乃至殺害牛羊，在因果業報上罪極重，但在戒律上結罪卻較輕；又如讚歎女人行淫等粗惡語（即麁惡語戒中的歎女）在戒律中結犯僧殘重罪，但其後世業報罪過反而相對較輕等等。

【161-0002】01_行事鈔/07d_卷中之三#18
【原文】搏比丘戒七十九。前是限分，此戒深防，擬便是犯。《伽論》：舉手向眾多比丘，一一提。
【譯文】搏比丘戒七十九。前一戒是以實際打中對方為界限，此戒則是更加嚴密的防護，只要舉手作出比擬擊打之勢，便構成犯戒。《毘尼摩得勒伽》說：若舉手威嚇比擬擊打眾多比丘，對著幾個人，便一一結犯幾個波逸提（提）。

【161-0003】01_行事鈔/07d_卷中之三#19
【原文】無根僧殘謗戒八十。略同第二篇，罪墮為別。
【譯文】無根僧殘謗戒八十。此戒的犯緣與行相，大體同於第二篇僧殘法中的無根謗戒，區別只在於此處是無根誣謗他人犯僧殘罪，其罪名結為波逸提墮罪。

【161-0004】01_行事鈔/07d_卷中之三#20
【原文】突入王宮戒八十一。四緣：一是剎利王，二王共夫人同處，三王未出寶未藏，四入王宮門限便犯。律中，若入粟散小王豪貴長者門限內，吉羅。
【譯文】突入王宮戒八十一。構成犯戒有四種因緣：一、對方是剎帝利灌頂國王；二、國王正與夫人在後宮同處；三、國王尚未走出寢殿、夫人等珍寶未曾隱蔽退避；四、比丘未經通報擅自邁入王宮門檻便結犯墮罪。律典中說，如果擅自邁入粟散小王（地方小諸侯）或豪門富貴長者的內寢門檻，結犯突吉羅罪。
