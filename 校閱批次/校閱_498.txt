# 校閱材料　第498檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【498-0001】資持記/15c_下三#50
【原文】《四分》在後，恐謂因法得食，濫彼邪緣。世傳在前，意令時眾先知情旨，然後受食，故云無失。然雖兩通，依教彌善；若據隨機，不可一定。二中。讀誦必待他請。今時俗舍，或有喪靈；僧徒共往，強為諷誦。無意利他，止圖齋請；重食壞法，招俗譏嫌，識者宜誡。三中，初科，《增一》。即持香迎僧之緣。
【譯文】《四分律》規定說法呪願在受食之後，是恐怕被人誤認為因說法而得到食物，濫同求食的邪命因緣。世間流傳在受食之前說法呪願，用意是讓大眾先明白施主的意願情旨，然後才受食，所以說在義理上沒有過失。然而雖然兩種作法都說得通，依照佛陀教敕（在食後）更加妥善；如果根據隨順根機而言，則不可拘泥一定。第二科中，讀誦經典必須等待他人延請。現今世俗人家若有喪事靈堂，僧徒往往一同前往，勉強為其諷誦經文，心中並無利他之意，只圖施主的齋飯供養；這樣重視飲食而敗壞佛法，招致世俗的譏嫌，有識之士應當引以為戒。第三科中，第一小科引《增一阿含經》，就是手持香爐迎請僧眾的緣起。

【498-0002】資持記/15c_下三#51
【原文】以能通信，故云佛使。《賢愚》。即行香緣，彼第七云：佛告阿難，過去無量阿僧祇劫，閻浮提有一大國，名波羅捺；時有一人，好修家業，意偏愛金，勤力積聚；因得一瓶，於其舍內，掘地藏之；如是勤身，乃得七瓶，悉取埋之；後遇疾終，作一毒蛇，守此金瓶；如是展轉受形，經一萬歲；
【譯文】因為它能夠傳達訊息，所以稱為「佛使」。《賢愚經》，就是行香的緣起，該經第七卷說：佛告訴阿難，過去無量阿僧祇劫時，閻浮提有一個大國，名叫波羅捺；當時有一人，喜好經營家業，心裡特別貪愛黃金，勤勞努力地積聚；因此得到一瓶金，就在自己屋內掘地埋藏；這樣辛勤經營，一共得到七瓶，全部取來埋藏；後來生病命終，變成一條毒蛇，守著這些金瓶；這樣輾轉受生，經過一萬年；

【498-0003】資持記/15c_下三#52
【原文】最後受身，厭心忽生；見有一人，順道而過；蛇呼之云：吾今此處，有一瓶金；欲用相託，供僧作福；設食之時，持一阿先提〔此云草籠。〕來取我；彼至日，擔蛇至寺，著眾僧前；食時已到，僧住行立；蛇令彼人，次第賦香〔賦給〕；眾僧食訖，為蛇說法，歡喜轉增；將僧維那，到本金所；
【譯文】最後一次受身，厭離的心忽然生起；看見有一人順著道路走過；毒蛇呼喚他說：我現在這個地方有一瓶金，想託付給你，用來供僧修福；設食的那天，拿一個阿先提〔此譯為草籠〕來裝我；那人到了約定的日子，擔著蛇到寺裏，放在眾僧面前；用食的時間到了，僧眾列隊站立；蛇讓那人依次分香〔賦就是給與〕；眾僧吃完飯後，為蛇說法，蛇的歡喜更加增長；於是帶著僧維那，來到藏金的地方；

【498-0004】資持記/15c_下三#53
【原文】餘六瓶金，盡用施僧；命終，生忉利天。佛告阿難，爾時持蛇人者，則我身是；是毒蛇者，今舍利弗是。富那奇，亦即彼經第六云：佛在舍衛，放鉢國長者有子，名富那奇；後出家，證阿羅漢；化兄羨那，造旃檀堂請佛；各持香爐，共登高樓；遙望祇桓，燒香歸命，念佛及聖僧；
【譯文】其餘六瓶金，全部用來布施僧眾；命終之後，生到忉利天。佛告訴阿難：當時那個拿蛇的人，就是我的前身；那條毒蛇，就是現在的舍利弗。富那奇，也是該經第六卷所說：佛在舍衛國時，放鉢國有一位長者生了兒子，名叫富那奇；後來出家，證得阿羅漢；度化他的哥哥羨那，建造旃檀堂請佛；兄弟各自手持香爐，一同登上高樓；遙望祇桓精舍，燒香歸命，稱念佛及聖僧；

【498-0005】資持記/15c_下三#54
【原文】香烟乘空，至佛頂上，作一烟蓋；佛知，即語神足比丘同往。〔前是行香緣，後即迎僧緣。〕次科，初簡施主是非。僧護殘罪，尼防重夷。五下，次明比丘儀式。律論並據香片，故有斯過。今時多以香烟熏手，則男女坐立，準理俱通。三中。唄即梵音。
【譯文】香煙乘空而上，飄到佛的頂上，結成一個煙蓋；佛知道後，就告訴有神足的比丘一同前往。〔前者是行香的緣起，後者是迎請僧眾的緣起。〕下一科，首先簡別行香施主的對與不對：僧眾要守護的是僧殘罪，尼眾要防止的是波羅夷重罪。「五」字以下，其次說明比丘的儀式。律和論都是根據手接香片而說，所以有這樣的過失。現在的人多用香煙熏手，那麼男女或坐或立，按道理都可以通融。第三科中，唄就是梵音。

【498-0006】資持記/15c_下三#55
【原文】未見經文者，上引諸緣，但直行香，不云作唄故。下指諸文，止明開唄，意是存之，今亦罕用。呪願中，初科，《四分》。令隨彼欲，欲即是機。應機說法，實難其任；在乎有智，隨事觀量。《僧祇》選能，不必上座，其在茲矣。乃至者，隨有不能，次第選下也。
【譯文】所謂「未見經文」，是因為上面所引的各種緣起，只是直接說行香，並沒有說要唱唄。下面所指的各種文獻，只說明開許唱唄，意思是把它保留著，現在也很少用了。呪願的部分，第一科是《四分律》：隨順對方的心意，心意就是根機。應機說法，實在很難勝任；這在於有智慧的人，隨著事情觀察衡量。《僧祇律》選任有能力的人，不一定是上座，道理就在這裡。「乃至」的意思是，隨著有人不能勝任，就依次往下選。

【498-0007】資持記/15c_下三#56
【原文】並得罪者，合眾吉羅，制須學故。正示中，初文，初斥世訛。豎，謂未冠之童稚；今但通目泛常小人，以為凡竪。貴族，謂豪富長者之人。鼎食，鼎即盛食之器；卿大夫已上，皆列鼎而食。令他傳誤謂之訛，強言妄悅謂之諂；今時讀疏，現事昭然。故下，引況。經法。猶爾，餘何足言。次科。
【譯文】所謂「並得罪」，是說全體僧眾都犯突吉羅，因為佛制規定必須學習。正式指示的部分，第一段先斥責世俗的錯誤。「豎」是指還沒有行冠禮的兒童；現在只是通稱一般平庸的小人，叫作「凡豎」。「貴族」是指豪富長者之類的人。「鼎食」，鼎就是盛食物的器具；卿大夫以上，都列鼎而食。「令他傳誤」叫作「訛」，勉強說好話來討人歡喜叫作「諂」；現今齋會宣讀意疏（祈願疏文）之時，眼前的事實就是這樣清清楚楚。「故」字以下，引用經典作比況：經法尚且如此，其餘的還有什麼可說。下一科。

【498-0008】資持記/15c_下三#57
【原文】亡人偈中，上二句歎無常，餘並示來報；天獄世報，泥洹出世報；以今修善，必獲善報故也。次生子偈，上二句代歸依；七世，即七佛；次四句舉喻，謂歸佛得護，如親愛子；後二句旁資親屬。新舍者，彼云：若入新舍設供者云：屋舍覆廕施〔謂造屋行施也。〕，所欲隨意得；吉祥賢善眾，處中而受用；
【譯文】在為亡人所作的偈中，前兩句是讚歎無常，其餘都是顯示未來的果報；生天、墮地獄是世間的果報，證涅槃是出世間的果報；因為現在修善，必定獲得善報的緣故。其次為生子所作的偈，前兩句是代為歸依；「七世」就是七佛；接著四句是舉譬喻，說明歸依佛能得到護念，就像慈愛自己的孩子一樣；最後兩句是旁及親屬。新舍的呪願，該經說：如果進入新屋設供，就念：「以屋舍覆廕而施〔這是說造屋行施〕，所想要的都能隨意得到；吉祥賢善的大眾，在其中受用；」

【498-0009】資持記/15c_下三#58
【原文】世有黠慧人，乃知於此處；清持戒梵行，修福設飯食；僧口呪願故，宅神常歡喜；善心生守護，長夜於中住；若入聚落中，及以曠野處；若晝若於夜，天神常隨護。估客者，彼云：諸方皆安隱，諸天吉祥應；聞已心歡喜，所欲皆悉得。兩足者安隱，四足者安隱；

【原文】彼因目連見已問佛，佛答如鈔。顯知施福，冥拔幽靈；但可修崇，不勞祭祀。三中。以鬼有通力，變少為多。此明施生不必多也。雜法中，初科；《僧祇》，初令顧比座。若下，次預擬受食。第三人，即已上兩座。《四分》。令上座觀食均等，不許偏饒。
【譯文】那部經是因為目犍連尊者見到餓鬼受苦的情景後向佛陀請教，佛陀所作的回答正如鈔文所載。這清楚說明修布施之福，能在冥冥中拔濟幽冥靈魂；人們只要虔誠修善崇奉即可，不必徒勞進行世俗的祭祀。第三個要點，因為鬼神具有神通力量，能把微少的食物變幻得極為豐盛。這說明了布施鬼神時食物並不需要很多。在「雜法」中，第一科引用《摩訶僧祇律》，首先要求必須顧及旁邊的同座僧人。「若下」接著說明預先準備領受食物。所謂「第三人」，是指位在自己前面的兩位僧座。《四分律》規定，上座僧人應當觀察食物分配是否均勻平等，絕不允許有所偏私厚待。
