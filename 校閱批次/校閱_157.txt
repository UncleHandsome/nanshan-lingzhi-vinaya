# 校閱材料　第157檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【157-0001】資持記/05b_上四#18
【原文】污淨識者，輕法之源，實由染世；不聞正法，已是盲冥；況舉輕心，更招殃禍；欲令反本，其可得乎！於法無味者，積惡漸深，去道轉遠故。大法者，通目佛教。出家無益者，乖本意故。口下，斥言行相違。師徒義絕，揀從外道，不亦宜乎。《高僧傳》中。隋東川僧雲法師住寶明寺。
【譯文】染污清淨心識，這是輕蔑佛法的根源，實質上是由於貪戀染著世俗；不能聽聞正法，就已經如同身處盲目幽暗；更何況懷抱著輕慢之心，那更是平白招攬無邊殃禍；要想讓他們返本還原，又怎麼可能做到呢！對於佛法感到索然無味，那是因為惡業逐漸累積深厚，距離解脫之道越發遙遠的緣故。「大法」是通稱一切佛教教法。所謂「出家毫無利益」，是因為違背了最初出離生死的本意。從「口」字以下，是斥責其言行互相違背。師徒之間的名義情分早已斷絕，將這些人甄別排斥到外道隊伍中去，難道不是理所應當的嗎！《高僧傳》中記載：隋代東川僧雲法師住在寶明寺。

【157-0002】資持記/05b_上四#19
【原文】以四月十五臨說戒時，乃白眾曰：戒本防非，人人誦得，何勞徒眾數數聞之。可令一僧竪義，令後生開悟。當時無敢抗者。訖於夏末，廢說戒事。至七月十五日早，將昇草座，失雲所在。大眾崩騰，四出追覓，乃於寺側三里許古塚間得之。遍體血流，如刀屠割。借問其故。
【譯文】在四月十五日將要說戒之時，竟然當眾宣稱：戒本是用來防非止惡的，每個人都背得滾瓜爛熟，何必勞煩大眾反覆不斷地聽聞。不如讓一位僧人登座立論辯義，還能讓後生晚輩得到開悟。當時在大眾之中沒有人敢抗議反對。一直到結夏安居結束，都徹底廢除了說戒這件事。到了七月十五日早晨，僧眾正準備登上草座自恣，卻發現僧雲法師失蹤了。大眾驚慌奔走，四出搜尋，才在寺院旁邊約三里遠的一處荒塚廢墟中找到了他。只見他全身流血，皮開肉綻就像被利刃屠戮切割過一樣。眾人詢問他緣由。

【157-0003】資持記/05b_上四#20
【原文】云有一大丈夫執三尺大刀，厲色瞋雲改變布薩；刀膾身形，痛毒難忍。因接還寺，端情懺悔。乃經十載，說戒布薩。臨終之日，異香迎之，神色無亂，欣然而卒。此乃上智，故動幽呵；今時下愚，竟無顯驗；縱令永廢，反自安然；法滅於時，可用長歎！七中，初別簡初篇。僧下，總示諸聚。
【譯文】他說有一位神異的大丈夫手持三尺長刀，面容威嚴厲色怒斥僧雲擅自改動布薩法事；隨即用刀猛切割裂他的身體，痛苦毒害到了難以忍受的地步。眾人於是將他接回寺院，他以無比端正誠懇的心情深切懺悔。此後歷經整整十年，都堅持每月如法說戒布薩。到了臨終那一天，有奇異的妙香前來迎接他，他神色安詳毫不紊亂，滿懷歡喜地安然圓寂。這乃是具有上等智慧的人，所以才能驚動幽冥神靈降下呵責；如今世上的下等愚夫，竟然絲毫沒有任何明顯的感應警示；哪怕讓正法永遠廢弛，反而自覺安然無恙；佛法在此時走向淪亡，真讓人禁不住長聲哀嘆！第七段中，首先特別甄別初篇的重罪。從「僧」字以下，總括顯示六聚戒罪。

【157-0004】資持記/05b_上四#21
【原文】若約聞戒通塞，則六聚並同；若論別眾成不，則根條兩異。如律顯者，即如戒本，有犯懺悔，無犯默然。八中二，初明對首。露言對眾者，謂於眾前對人作法。律云：當至一清淨比丘所，具威儀，說所犯名種，白云：大德憶念我比丘某甲犯某罪，今向大德發露，後如法懺悔。〔三說。
【譯文】如果就聽聞戒律的准許或隔絕而言，那麼六聚罪相完全相同；如果就私自分割僧眾是否合法而言，那麼根本重罪與枝條輕罪便截然不同。如同律藏中所顯明的，就如戒本所定，有犯罪的人應當懺悔，沒有犯罪的人則保持默然。第八段分為兩部分，首先說明當面相對發露（對首）。「發露說面對眾人」，是指在僧眾面前對著特定一人如法作法。律藏說：應當走到一位清淨比丘身邊，端正具足僧人威儀，說出自己所犯的罪名和種類，稟白說：「大德請為我作證，我比丘某甲犯了某條罪，現在向大德發露陳述，過後當依照戒法如法懺悔。」〔說三遍。

【157-0005】資持記/05b_上四#22
【原文】說戒時憶者，須用此法，餘時依法懺悔。〕又律中，比丘於犯有疑，復逼說戒，佛言：應發露已，得聞戒，亦對人云：大德憶念我比丘某甲，於某犯生疑，今向大德發露；後無疑時，如法懺悔。〔三說。已上準《注羯磨》出之。〕恐下，二明心念復二，初明識罪法。
【譯文】在說戒的時候忽然回憶起來的人，必須使用這種方法，在平時則依照平常的法規懺悔。〕又律藏記載，比丘對於自己是否犯戒心懷疑慮，偏偏又逼近了說戒之時，佛陀說：應當發露之後，方可聽聞戒本，也是對著同參說道：「大德請為我作證，我比丘某甲，對於某條犯戒之事生起疑心，現在向大德發露；日後疑心決了時，當如法懺悔。」〔說三遍。以上都是依照《注羯磨》所摘錄出來的。〕從「恐」字以下，是第二部分說明心中默念法（心念），這又分為兩點：首先說明自知有罪的方法。

【157-0006】資持記/05b_上四#23
【原文】律中，為在座上忽憶本罪，向比座說，舉眾鬧亂，佛令發露心念，而不出文，鈔家義立。準《羯磨》說戒字下，更加一句，云恐鬧亂眾故。亦須三說。若下，明疑罪法。應云我某甲於某犯生疑，餘詞準同。第四略法中。標云雜者，據略則純；但緣與法各有多別，故云雜耳。
【譯文】在律藏中，是為了照顧在座席上忽然想起自己原本犯了某罪，如果轉身向鄰座宣說，會引得整座大眾喧嘩擾亂，所以佛陀才開許在心中默念發露，然而律文並未提供具體詞句，是撰鈔的律師依據法理所創立的。依照《羯磨》在「說戒」二字之下，再增加一句，說「因為唯恐擾亂大眾的緣故」。這也必須在心中默念三遍。從「若」字以下，是說明對罪生疑時的心念法。應當說：「我某甲對於某條犯戒之事心生疑惑」，其餘詞句與前面相同。第四部分「簡略方法（略法）」中。標題稱作「雜」，如果單就簡略而言本是純一的；只因緣起與作法各自有許多差別，所以才稱為「雜」罷了。

【157-0007】資持記/05b_上四#24
【原文】緣中，本宗。八難餘緣者，若據緣難，二名不局；今須標簡，重者名難，輕者為緣。王難者，疏云：或將士眾擁寺列兵。病人與下緣中相濫，應以重輕分之。非人即鬼神為惱。惡蟲，通目畜獸能為命難者。人難引論釋之；此據常人，不同賊也。餘緣者，通收無限，故但言餘；
【譯文】在特殊事緣中，就本宗四分律而言。所謂「八種災難及其餘事緣」，如果就事緣與災難來說，這兩種名稱並沒有嚴格界限；現在必須標示區別，情節重大的稱為「難」，情節輕微的稱為「緣」。「國王難」，戒疏解釋說：或者有將官士卒圍繞寺院列陣陳兵。「病人」則容易與下文緣起中的病人相混淆，應當以病情的輕重來作區分。「非人」就是鬼神前來惱亂。「惡蟲」是通指那些能夠危及生命的凶禽猛獸。「人難」則引用律論來解釋它；這是指平常人帶來的危難，與盜賊強盜並不相同。「其餘事緣」通攝無窮無盡的瑣事，所以只籠統稱為「餘」；

【譯文】借用字義來訓釋，「聽」字就等同於「令（飭令）」的意思。意思是命令派遣僧眾必須去作，是絕對不可違背的。如果能夠作這樣的理解，那麼其餘經律文獻就再也沒有滯礙不通的地方了。在提問之中。一個季節各包含四個月，單就遊行可能產生的過失而言三季本是相同的，佛陀卻沒有在所有的時間都全部嚴禁遊行，所以必須透過問答解釋來彰顯立教設制的深奧意趣。回答有兩種意理，首先是針對「安居之後開許受衣」來回答。這唯獨普及到那些嚴格實行前安居的人。因為色身乃是承載痛苦的器皿，飢渴寒熱之苦隨時都需要資生之物來撫慰，所以稱為「待形（滋養色身）」。比照普遍通達的五種利養，這裡暫且舉出外在的物資，這是佛陀正宗開許的本意，所以才單單提及「衣服」。其次是針對「安居之初開許寬限續結」來回答。
