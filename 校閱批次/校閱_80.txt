# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【80-0001】資持記/11c_中四上#40
【原文】釋名中，即用《了論》，成就隨順二義釋之，初即成就義。注指七緣，文見次科。若下，即隨順義。根本中，前明根本之相，初句通問。謂下，別釋，初列示四重。如下，總指諸篇。若下，明攬因成果。簡異他宗，使無濫用。後方便中。不論篇聚重輕，竝制一吉，故云通也；
【譯文】在解釋名稱之中，直接採用《了論》所說的「成就」與「隨順」兩種義理來作解釋，首先就是「成就」的義理。注文中所指的七種條件，文句見於下一科。從「若下」開始，就是「隨順」的義理。在「根本罪」中，前面先說明根本罪的相狀，第一句是統貫發問。從「謂下」開始分別解釋，首先列出並開示四條重戒。從「如下」開始，總括指涉其餘各篇。從「若下」開始，說明牽引因地而結成果報。這也是為了揀擇異於其他宗派的主張，使兩者不致混淆濫用。在「後方便」中，不論篇聚是重還是輕，全都制定為一個吉羅罪，所以說是「通同」；

【80-0002】01_行事鈔/08a_卷中之四#67
【原文】三具緣成犯者。先明成犯意。業不自成，成假修造；諸緣和具，方結罪福；必片乖阻，擁結方便。故律中犯相，並託因緣；為罪居六聚，懺法又別。不同化教，但論成業；結犯已外，無論違制。
【譯文】第三、「具足諸緣成犯」。先說明成犯之意。業行不會自然生成，生成必定假藉造作修持；各種條件因緣和合具備，才能結定罪業或福德；如果稍有一片乖違阻礙，便壅滯停留在方便罪上。所以律中的犯戒行相，都是依託因緣而成立；為此罪名分居在六聚之中，懺悔之法也各有不同。這不同於化教（經論法門），化教只論業道的成辦；於結犯之外，並不另論違制。

【80-0003】資持記/11c_中四上#41
【原文】翻前方便，二三不同，蘭吉有異故也。三明具緣，標中。語含通別二種；通則遍該諸聚，名數齊均；別則隨局戒條，體相各異。凡於一犯，考以兩緣；則成不歷然，判斷有據矣。敘由中，初標示。業下，正敘為二，初明作業成不。上明緣具成業；必下，明緣缺不成。罪即惡業，福即善業；
【譯文】這是因為翻轉了前方便那種二個或三個層次的不同、以及偷蘭遮與吉羅在名相上的差異。第三部分闡明「具足因緣」，在標題中。文字涵蓋了「通緣」與「別緣」兩種：通緣是普遍涵蓋所有的戒聚，名目與數量都是齊平劃一的；別緣則是隨著侷限在各個個別戒條，本體與行相各自不同。凡是對於一樁犯戒事實，只要用這兩種因緣來考量核對；那麼到底成不成立犯罪就會清清楚楚，判決斷定也就有了依據。在敘述緣由中，首先標示說明。從「業下」開始正式敘述，分為兩部分，首先說明造業到底成立不成立。上面是說明條件具足就結成罪業；從「必下」開始，說明條件缺漏就不能結成罪業。罪指的就是惡業，福指的就是善業；

【80-0004】01_行事鈔/09a_卷下之一#31
【原文】七重數多少。《四分》等律云：不得細薄，大衣二重，餘二衣並一重，此謂新者。若用故者，《十誦》云：四重作大衣，二重作七條五條等。《薩婆多》云：若新大衣三重，一重新二重故。餘如《十誦》。故彼律云：若三重作大衣坐具，若以新衣重縫，作時吉，過限墮；中間悔摘却者吉。律中，糞掃衣隨意多作。《薩婆多》云：重縫三衣，設有因緣，摘分持行，到於異處，名不離衣宿。若死者，前言本界內，後言應與看病人；以本是一衣，同受持故；律師云：後是定義。
【譯文】第七、層疊重數的多少。《四分律》等各部律典說：衣服不得過於纖細薄弱，若是新布，大衣要做成雙層（二重），其餘七條、五條二衣都做成單層（一重）。如果使用的是舊布，《十誦律》說：四層舊布拼縫作大衣，兩層舊布作七條衣與五條衣等。《薩婆多論》說：如果是新大衣可以作三重，也就是一層新布加兩層舊布。其餘規定如同《十誦律》。所以該律說：如果是三重製作大衣或坐具，若是完全用新布重疊縫製，製作時犯突吉羅（輕垢罪），超過限制受持就犯波逸提（單墮罪）；中途若生悔意將多餘層數拆除者，只結突吉羅罪。律藏中對於糞掃衣（拾取遺棄之碎布所作之衣），則聽許隨各人意願縫合多層。《薩婆多論》說：將多層布縫合成的三衣，假設有特殊因緣，將其中一層拆開分開攜帶旅行，到了其他地方，仍不算作「離衣宿」（離開法衣過夜之罪）。如果該比丘身亡，論中前面說此衣歸屬原本舊住處之本界僧，後面又說應當分給看病照顧的比丘；因為原本屬於同一件法衣，共同經過加法受持的緣故；古德律師說：後面的說法是確定的定論。

【80-0013】02_戒疏/03b_卷一下之一#147
【原文】【記】三釋撿問，標分中。云「正問眾中」者，《戒本》「是中」兩字，世人不曉，謂指戒文，所以或謂問前，或云問後。準今科判，乃問「僧中」，則由來疑諍，渙然冰釋。傳迷斯久，學者須知。
【譯文】【記文】在第三段解釋檢驗詢問的標列分段中。所謂「正問眾中」，《戒本》中「是中（在其中）」這兩個字，世人多未能徹解，誤以為是指戒文條文之中，所以才會有人爭論是問前篇、還是問後篇。依照今疏的科判，此語乃是直接詢問「大眾僧團之中」，如此一來，歷來所有的疑慮爭端皆如冰雪消融。此一誤傳盲信已歷時甚久，修學律法之人必須審慎明辨。

【80-0016】02_戒疏/03b_卷一下之一#150
【原文】【疏】答：「解有多途。說戒為於行淨，有犯不應說儀。羯磨別為前緣，緣成則合事辨，故隨白問，終為成法，不別舉也。」
【譯文】【疏文】回答：「對此問題歷來有多種解釋。說戒的核心完全是為了使僧眾戒行清淨，若身有違犯者原本就不合乎參與說戒的威儀軌範。一般羯磨則是專門為了承辦當前的特定事緣，只要因緣具備便應當把事情合力辦妥，所以只要隨著單白發問認可，終究以成就該項法事為旨歸，無須另外再提出清淨與否的專門檢驗。」

【80-0017】02_戒疏/03b_卷一下之一#151
【原文】【記】答中。初句總示。下引五解，前四明異，後一顯同。初約所為自他不同。「前緣」即法所被事。「緣成」即通十種方便。「隨白問」者，謂單白羯磨並問忍可。意專被事，故云「終為成法」。無勞撿淨，故云「不別舉」也。
【譯文】【記文】回答章節中。首句作總括開示。下文引出五種解釋，前四種在說明兩者的相異之處，最後一種在顯發共通點。第一種是依據「所成辦目的屬於自利或利他」的不同來劃分。「前緣」是指羯磨法事所要利益處理的特定對象與事件。「緣成」是通貫十種受戒或處分的方便要件。「隨白問」是指在單白羯磨中詢問眾僧是否默然忍可。其意旨全在於成辦事件本身，所以說「終為成法」。既然無須勞師動眾逐一檢驗清淨，所以說「不另外提出檢問」。

【80-0018】02_戒疏/03c_卷一下之一#1
【原文】【疏】又解：「說戒僧別兩舉，說聽必約清修。羯磨多為別緣，僧成即堪御法。」
【譯文】【疏文】另一種解釋說：「說戒時，大眾僧法與個人私行必須同時舉揚檢點，說戒與聽戒都必須限定在清淨修持者之間進行。而僧團法事（羯磨）多半是為了解決特定的個別因緣，只要僧團合法成立，就足以執行法事。」

【80-0019】02_戒疏/03c_卷一下之一#2
【原文】【記】次解。約眾法、別行，單具往分。「別」即自行。說戒為僧，兼別須問；羯磨為別，單眾不須。
【譯文】【記文】這段文字是第二種解釋。這是就全體僧團的集體法事（眾法）與個人的單獨行持（別行）是兼具還是單一來加以區分。「別行」就是指個人的行持。說戒是為了整個僧團，但也兼顧個人的行持，所以必須審問清淨與否；僧團法事只是為了解決特定事件，只要僧團人數合乎法定要求即可，不需要審問個人。

【80-0020】02_戒疏/03c_卷一下之一#3
【原文】【疏】又解：「兩法在僧，俱須行淨。說戒制問，為清行染之人；羯磨不制，法通純雜之士。如僧殘行法，開停為他，明知罪未出也。聞戒知犯，必開默露，明知說被淨也。」
【譯文】【疏文】又有一種解釋說：「這兩種法事都在僧團中進行，按理都應當行持清淨。但說戒時規定必須審問，是為了查出並清滌行為染污的人；僧團法事不規定審問，是因為該法事通於純淨者與染污者共同參與。例如僧殘罪的行法，允許為他人暫停進行，由此清楚知道他的罪過尚未徹底解除。而聽聞戒律時若察覺自己犯戒，就必須開口坦白發露、不得隱瞞默然，由此清楚知道說戒只涵蓋身心清淨之人。」

【80-0021】02_戒疏/03c_卷一下之一#4
【原文】【記】三約淨穢，通局不同。初二句通示，「說」下，別分。「如」下，引證。初證羯磨通雜，「聞」下，證說戒局淨。
【譯文】【記文】這是第三種解釋，從「清淨」與「染污」是普遍適用還是有所局限的差異來說明。前兩句是總體提示；從「說戒」往後，是分別剖析；從「例如」往後，是引文以為證。前半段證明僧團法事可通於混雜染污之人，後半段「聞戒」往後，則證明說戒局限於完全清淨之人。

【80-0022】02_戒疏/03c_卷一下之一#5
【原文】【疏】又解：「羯磨所為在事也，說戒所為在犯也。『有犯不得聞戒』，斯明證也。故說戒之作，為兩種人：持者為能清，犯者為所清。若知有犯，即須遮舉懺洗令淨，方聞後戒。乃至《律》文見犯不說，經二十年。羯磨不爾，標舉時事。三根五法，相圓無染，即成僧用，故不制問。」
【譯文】【疏文】還有一種解釋說：「僧團法事所著重的是特定事務，說戒所著重的是防範與止息犯戒。『若有犯戒者，不得聽聞戒律』，這就是明確的證明。因此舉行說戒，是為了兩種人：持戒清淨的人屬於能引導清淨者，犯戒的人屬於被清滌的對象。如果知道自己犯戒，就必須立即制止其聽戒、檢舉並令其懺悔洗滌罪垢而恢復清淨，然後才能聽聞後續的戒條。甚至《律藏》記載，看見有人犯戒卻不指出的僧團，竟然長達二十年不舉行說戒。僧團法事則不同，它只是標明並處理當下的特定事務。只要具備『三根清淨』與『五法現前』，法事的儀相圓滿無缺、不被染污，就能成就僧團的法定功用，所以不需要規定審問。」

【80-0023】02_戒疏/03c_卷一下之一#6
【原文】【記】四明立教所為，罪事差別。初雙標，「有」下，別釋。初釋為犯有四：初據聖制證；「故」下，約所為證；「若」下，引遮舉證；「乃」下，引廢說證，即《僧祇》比丘鬪諍緣也。「羯磨」下，次釋為事。「相圓」對「五法」，「無染」對「三根」。「五法」即五現前。此謂說戒必取體淨，有犯不開，故須責問；羯磨但取相淨，便成僧法，故不勞問。
【譯文】【記文】這是第四種解釋，說明設立教法的根本目的，在於「治罪」與「辦事」的差別。前兩句同時標出兩者，從「若有犯戒」往後分別解釋。先解釋著重於「犯戒」方面有四點：首先依據佛陀的聖制為證；「因此」往後，就其教化對象為證；「如果知道」往後，引用制止與檢舉為證；「甚至」往後，引用廢止說戒的典故為證，也就是《僧祇律》中比丘紛爭鬥亂的因緣。從「僧團法事」往後，接著解釋著重於「辦事」方面。「法相圓滿」對應「五法」，「無染污」對應「三根」。「五法」就是指五種現前。這段話的意思是說，說戒必須要求實體本質徹底清淨，有犯戒者絕不通融，所以必須責問；僧團法事只要儀軌相貌清淨，就能成就僧團的法定效力，所以無須費事審問。

【80-0026】02_戒疏/03c_卷一下之一#9
【原文】【疏】問：「須知淨行，一告便足，有何義故，殷勤三反？」
【譯文】【疏文】有人問：「既然必須明瞭眾人是否具備清淨行持，詢問通告一次就足夠了，究竟有什麼深意，必須懇切鄭重地詢問三次？」

【80-0027】02_戒疏/03c_卷一下之一#10
【原文】【疏】答：「說聽相應，可名傳法，雖聞不識，容犯妄聽，故須三問，鄭重窮檢。一則未呈昏忘，多則在眾致繁，故限以三，法儀所致也。」
【譯文】【疏文】回答：「說戒者與聽戒者的心念相互契合，才可以稱作是傳持正法。有的人雖然聽到了卻沒有聽清楚，便容易帶著犯戒的身心妄自聽受；所以必須三度詢問，極其慎重地徹底檢驗。詢問一次，唯恐有人一時昏沉忘失；詢問過多，又會使大眾感到繁瑣，所以將次數限制在三次，這是法事儀規必然的要求。」
