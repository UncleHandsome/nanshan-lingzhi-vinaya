# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【420-0001】03_業疏/21a_卷四之四#53
【原文】有人言：諸師解繁，以意分二。若僧差、難起，不專私意，但依律作用，乞何為？如沓婆被差、五德知事等例。必為衣藥、看病、問苦，既是私緣，非乞不委，加乞不妨，故前三家集意在此，不由此乞號加羯磨。故律中「增應作一白，眾多白，是名增也；文句非應，妄有所加」，即律文云「不如白法而作白」也。今時加乞準諸乞辭，及入法作亦準諸法，何得專制獨斷不成？義不可也
【譯文】有人說：各位律師的解釋過於繁瑣，依義理應當分為兩種：如果是僧團差派、或者災難突起，這並非專屬個人的私事，只要依照律文行事作法即可，何必陳乞？如同沓婆摩羅子被差派分房、差派五德知事等事例一樣。但如果是為了衣服、醫藥、看視病人、慰問疾苦，這既然屬於個人私事，若不陳述乞請便無法詳審其情由，因此補加乞辭並無妨礙，所以前面三家編集羯磨的本意就在於此，不能因為增加了乞辭就稱之為非法增法羯磨。律文中所說的增，是指「本應作一白，卻作了多次白告，這叫做增；或者言詞文句不合理，妄自有所增添」，也就是律文所說的「不如白法而作白」。如今所加的乞辭是比照其餘律典的乞請辭句，正式入羯磨作法時也比照其餘正法，怎能擅自獨斷判定羯磨不能成就呢？這種武斷判定在義理上是行不通的。

【420-0002】03_業疏/21a_卷四之四#54
【原文】三兩通中，初總標。「若」下別釋。初明僧事不乞。僧差如營幹三寶等緣，難起如救寺、和僧之類，律中差知事、五德竝無乞請，故舉為例。「必」下次明私緣須乞。初示緣相，問苦謂濟他急難。「故」下救前諸師雖各加乞，不違律制。律明增加有二非法：一、多增白法，二、妄增詞句。今皆有準，故是可用
【譯文】在第三段兩相融通的辨釋中，起初總括標示。從「若」字以下分別解釋：首先說明公家僧事不需乞請。僧團差派如同營辦照料三寶等事緣，災難突起如同救護寺院、和合僧眾之類，律中差派知事僧與五德僧都沒有陳乞之辭，所以舉此為例。從「必」字以下接著說明個人私事必須乞請：首先開示事緣的相貌，「問苦」是指救濟他人的急難危困。從「故」字以下為前面各位律師辯護，說明他們雖然各自增加了乞辭，卻不違背律制。律中明示增法有兩種非法：第一是多增加了白告法式，第二是妄自增加了言詞語句。如今所加的乞辭皆有所依準，所以是可以採用的。

【420-0009】03_業疏/02a_卷一之二#6
【原文】三中，初二句通標。以上三事攝一切事，一一事下各有是非，故云「互也」；竝由加被，其相方彰，故云「附法生也」。「總」下別示，初顯是。實事言通，須知其相。《鈔》云「竝令前境是實，片無錯涉，皆成法事；若一緣有差，悉竝不成」，如不覆藏與覆藏羯磨，即無事有法；又應與作訶責，乃作擯出，此即有藥有病，施不相當，佛竝判不成。故知事者必須稱實，方稱聖教。「設」下示非，破戒自惱是損自，如受具緣乖、懺治非法、戒場太界標相不明、淨地攝衣事容虗謬，隨有違教，無非結罪；招機妨業即損他，如無病離衣、妨難造房等，一一犯戒，又復招機。或可破戒招譏通前諸事，既容毀戒，豈不招譏？是則二損通該一切。「隨」下示意，隨文事多，無由委示，止可如上約義通明。
【譯文】在第三科中，開頭兩句為總標。以上述三類事相統攝一切事相，每一件事相之下都各有其「是」與「非」，所以說「互也」；都是由於羯磨法的加被，其行相才得以彰顯，所以說「附法生也」。「總」以下分別說明，首先顯明「是」（合法）。實事一詞涵蓋面很廣，必須明白其具體行相。《行事鈔》說「都必須使現前對境真實無訛，絲毫沒有錯謬混淆，才都能成就法事；只要有一項因緣有差錯，便全都不能成就」，例如沒有覆藏之罪卻作覆藏羯磨，這就是無事而妄作法；又如應當給予訶責處罰，卻作成擯出羯磨，這就是雖有藥也有病，但施藥與病情不相匹配，佛陀全都判定為不成就。由此可知，事相必須與實情完全符合，才符合聖者的教誡。「設」以下指出「非」（非法），破戒自惱是損害自身，例如受具足戒時因緣乖違、懺悔治罰非法、戒場大界的標相不分明、淨地攝持衣物之事容有虛假錯謬，隨順任何違背教誡之舉，無不結罪招過；招譏妨業則是損害他人，例如無病而離衣宿夜、在有妨害留難之處建造房舍等，每一項都違犯戒律，又招致外界譏嫌。或者說破戒與招譏通於前面所有事相，既然容許毀犯戒律，豈能不招致譏嫌？因此這兩種損害普遍涵蓋一切事相。「隨」以下說明用意，隨順律文之事極為繁多，無從在此詳盡開示，只能如同上面這樣就義理普遍說明。

【420-0011】03_業疏/02a_卷一之二#8
【原文】初制意者，僧寶流世，元為生善；然生善在事，假法成立；法不自建，弘斯在人。故制羯磨，必由僧秉。良以五眾為出世之田，凡所造修，無非拔濟，故以僧和之法，能成勝業之緣。何以知然？如果向俗人，雖參聖限，以形乖法別，未許傳授，所以五戒等受授必出家，其意可見
【譯文】第一、制戒的用意：僧寶流傳於世間，本來是為了令眾生生起善法；然而生起善法在於具體的事修，事修又必須藉助如法之規矩才能成立；法規不能自行建立，弘揚它全在於人。所以制定羯磨，必定要由僧伽來秉持操作。這確實是因為出家五眾是超脫世間的福田，凡所造作修持，無不是為了拔苦濟度，所以用僧眾和合之法，能夠成就殊勝善業的勝緣。如何得知是這樣呢？例如證得四果四向的在家俗人，雖然已列入聖者的等位，但因為形貌相違、法軌有別，並不聽許他們傳授戒法，所以受授五戒等必須由出家人傳授，其中的用意便清晰可見。

【420-0012】03_業疏/02a_卷一之二#9
【原文】三能秉制意中，初敘立意，二「良」下推所以。初中「生善」之言，通於自他、世及出世。事即眾別行相，僧非事則不能生善，事非法不立，法非人不弘，則知事法竝依人矣。次所以中，初敘勝能，五眾皆為解脫出家，能生他福，故喻如田；「勝業」即羯磨。「何」下次舉事顯，「果向」即四果四向，「未許傳授」者，此明雖聖而非師也；五八二戒通五眾授，此明雖居下眾，即堪軌物也
【譯文】在第三「能秉御僧」的制戒用意中，起初敘述立意的宗旨，第二自「良」以下推究其所以然。第一部分中，「生善」這句話通於自己與他人、世間法以及出世間法。「事」就是大眾與個人的行持相貌，僧伽若沒有具體法事就不能生善，法事若沒有法軌就不能成立，法軌若無人就不能弘揚，由此可知事相與法軌都依賴於人。在第二部分推究所以然中，起初敘述殊勝的功用，五眾都是為了求得解脫而出家，能夠為他人出生福德，所以比喻為良田；「勝業」就是指羯磨。自「何」以下接著舉出事例顯發，「果向」就是四果四向，「未許傳授」是說明雖然位列聖者卻不可作為傳戒師；五戒與八戒通通聽許由出家五眾傳授，這是說明雖然位居下眾，卻堪能做他人的軌範規範。

【420-0013】03_業疏/02a_卷一之二#10
【原文】言僧伽者，中梵本音，此土無名，比眾以譯，有加和合，乃是義用。故文云：「僧者四人若過，和者羯磨說戒。」即如經律佛法眾也

【420-0016】03_業疏/02a_卷一之二#13
【原文】次科：雖翻為眾，律但稱僧，故須示意。以通名則濫於小眾，據別德則唯局四人，簡通標別，故存梵號。「餘」下釋妨，以餘經中有從華語，故此通之。若爾，上指經律云「佛法眾」，是則律中亦有從華，如《十誦》、《伽論》五眾、十眾受戒，即五十、二僧也；又如當部戒場緣云「有四眾、五眾事起」等。今作二釋：一者從多為言，雖諸律中華梵互舉，多云僧故；二者諸律餘處或標為眾，正明能秉，竝云僧故，如下引律「四種僧」等是也
【譯文】第二科：雖然翻譯為「眾」，但律典中只稱「僧」，所以必須說明用意。因為若用通稱就會混淆於少數人（小眾），依據別德則唯獨限定在四人以上，為了簡別通稱而標顯別德，所以保留梵語稱號。自「餘」以下解釋難阻，因為其他經典中有順從華語的，所以在此加以通釋。如果這樣的話，上面指出經律中說「佛法眾」，那麼律典中也有順從漢語的，例如《十誦律》、《僧伽論》中說五眾、十眾受戒，也就是五人僧、十人僧以及二部僧；又如本部律典在戒場因緣中說「有四眾、五眾事起」等等。現在作出兩種解釋：第一是就多數而言，雖然各部律典中漢梵夾雜互用，但多數稱「僧」的緣故；第二是各部律典在其他地方或許標示為「眾」，但在正式說明能秉持法事時，一律都稱「僧」，正如後文所引律文「四種僧」等便是如此。
