# 校閱材料　第1474檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1474-0001】04_比丘尼鈔/05b_卷下之上#4
【原文】第五就座者此律云菩提王子請佛從於階下布衣令佛蹈上過世尊不受令却之為未來比丘故又往食處不應雜亂叢聚而住應隨次坐上座入座已應看中座下座勿令不如法不善覆身若有者彈指令覺若遣人語知好如法坐中下座以去互看亦爾僧祇云不好覆身坐者謂著細生疎衣形體露現摩訶羅坐尼坐不正不待語恐其慚恥應作方便遣令取物若婬女故作者當自避去此律至請家彼此相問年歲大小訖坐若恐日時欲過聽上座八人尼次第坐餘者隨坐五百問事云若共師並坐更無別處者得不得同槃食沙彌威儀經云若共師連坐飯當離師六尺此律云不應故在後往食上令諸比丘起見來亦不須起若未來者比坐開處僧祇云若有可笑事上座應語言云何聖毗尼中出齗現齒呵呵而笑當忍之起無常苦空無我死想若不可止當以衣角遮口徐徐制止身不定者當動手足乃至折草漸漸自制義云若至死亡之家禁慎諠笑不得妄談世論致俗譏訶五分云若至請處外有客比丘不得入語主人聽入不許者語云與我食分自共等食又不許者應自語委知僧坊有食可往彼去然後乃食婆論云通集門外比丘一處喚一大者入更餘不集者亦喚入之雖打楗稚終須不遮方得清淨長阿含經云世尊計會常在眾中坐左面比丘右面清淨士也。
【譯文】第五、就座入席（就座）。本律說：菩提王子迎請佛陀，從階梯下方一路鋪設布料，希望佛陀踩在上面走過；世尊不肯接受，命其收起，這是為了顧及後世比丘的緣故。此外，前往用餐處時，不應雜亂擁擠地聚集成堆，應當依照戒臘次序就座。上座入座之後，應當照看中座與下座的僧眾，切勿讓大家舉止不如法、未能妥善遮蔽身體；如果發現有失儀之處，應當彈指令其警覺，或派人私下告知，使其如法端坐；中座與下座以下的僧眾互相照看，也是如此。《僧祇律》說：所謂未能妥善遮身而坐，是指穿著輕薄粗疏的衣物，致使身體曲線輪廓外露；年老遲鈍的僧尼若坐姿不端，不必當面指責，免得其羞慚難堪，應當設法差遣她起身取物，藉此自我調整；若是淫蕩婦女故意如此作態，則應當自行避開。本律說：到達請家之後，彼此互問戒臘年資完畢，方可入座；若是擔心過午的時間將至，准許上座八位比丘尼依序就座，其餘大眾則隨即跟著入座。《五百問事》說：如果與剃度師同席並坐，且再無其他座處，尚屬許可；但絕不可共用同一個餐盤進食。《沙彌威儀經》說：若與師父連席而坐用餐，應當距離師父六尺。本律說：不得故意拖延在後才前往用餐，致使先到的比丘們紛紛起立相迎；見到晚來者，大家也不必起立；若尚有人未到，相鄰坐著的人應當為其預留空位。《僧祇律》說：現場若有引人發笑之事，上座應當勸告說：為何在神聖的毗奈耶戒律中，竟敢露齒咧嘴而哈哈大笑？應當極力忍耐，內心生起無常、苦、空、無我以及死滅的觀照；如果笑意實在止不住，應當以衣角掩口，慢慢加以克制；若身軀躁動不寧，應當藉由擺動手足，乃至彎折草葉等微小動作，逐漸自我收攝克制。義理解釋說：若前往發生喪事的家庭，務必謹慎禁絕喧譁嬉笑，不得隨意談論世俗閒話，以免招致俗人的譏嫌斥責。《五分律》說：若抵達受請之處，門外有外來的客比丘，不得擅入；應先告知主人准許其進入；主人若不答應，則告知主人說「請將我的飯食分量分給他，我們一同平均食用」；主人若仍不答應，則應當親自告知客僧，使其詳細明瞭僧坊中備有食物，可以前往該處用餐，隨後自己方能進食。《薩婆多論》說：應當將聚集於門外的客比丘集合在一處，呼喚其中一位戒長者進入；其餘未聚集者，也應一併喚入；縱使擊打楗稚召集，始終不可拒絕他人，如此用餐方能合乎清淨。《長阿含經》說：世尊參加聚會時，往往在僧眾當中端坐，左邊是出家比丘，右邊是清淨的在家居士。

【1474-0002】04_比丘尼鈔/05b_卷下之上#5
【原文】第六淨食者此律云上座應問云果菜淨未若言未淨令淨僧祇云上座當知誰看房看病等應語與食若檀越惜者應語長壽法應與不得不與若日晚者應先發遣令去也。
【譯文】第六、檢驗食物是否清淨（淨食）。本律說：上座應當詢問說：果品蔬菜是否已經作過「淨法」？若回答尚未作淨，應當令其如法作淨。《僧祇律》說：上座應當明瞭有誰在寺中看管房舍或照料病患等，應當吩咐為他們留取飲食；若檀越捨不得給予，應當告誡說：這是讓人獲得長壽之法，理應給予，不得不給；如果天色將晚，應當先將食物送去，令其先行用餐。

【1474-0003】04_比丘尼鈔/05b_卷下之上#6
【原文】第七行香呪願增一云有設供者手執香鑪而白時至佛言香為佛使故須之也五百問事三千威儀經云不得立受香因比丘受香女觸其手欲心發退道佛言若立受吉羅十誦云為諸天聞唄喜故開唄此律佛受賈客麨已然後呪願辯意長者子經云食前呪願僧祇云上座應知前人所施當為應時呪願若不能者次座應說又不能者乃至下座都無者並得罪雜寶藏經云諸比丘若說法呪願當解時宜憂悲喜樂知得不得妄說。
【譯文】第七、行香與行咒願（行香呪願）。《增一阿含經》說：有設齋供養者，手執香爐向僧眾稟白用餐時間已到；佛陀說：香是用來通達佛事的使者，因此必須使用香。《五百問事》與《三千威儀經》說：不得站立受香；曾有比丘站立受香，婦女接觸到他的手，致使其退失道心；佛陀因此規定，若站立受香犯突吉羅罪。《十誦律》說：為了讓諸天聽聞梵唄而心生歡喜，因此開許唱誦梵唄。本律說：佛陀接受商人供養的炒麥麵之後，方才為其祝願。《辯意長者子經》說：應於用餐前進行咒願。《僧祇律》說：上座應當清楚施主所布施之事物，應當為其作契合時節因緣的咒願；如果上座不能說，應由次座宣說；若次座也不能說，乃至輪至下座；如果全體都不會說，則全體均得罪。《雜寶藏經》說：諸比丘若要說法咒願，應當通曉當下的適當時宜，洞察人家的憂戚、悲哀、喜悅與歡樂，明白何時當說、何時不當妄說。
