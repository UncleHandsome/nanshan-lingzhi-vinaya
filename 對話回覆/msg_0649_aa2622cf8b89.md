## 2. `pack_judge.py` (`do_split`)：拆包時會「靜默丟失未改欄位」＋ 閉包錯位

### 問題
1. **靜默丟欄（最危險）**：在雙欄書（《業疏》《戒疏》）併批裁決時，假設第 `[1]` 組的 `【疏文】` 沒問題、`【記文】` 有改動，模型依規則只會在 `【記文】` 下輸出 `[1]`。目前 `do_split` 看到 `per_group[1]` 非空（有 `記文`），就不會進入 `if not segs:` 補甲譯本，結果寫回檔案時**整個 `[1]` 的 `【疏文】` 直接憑空消失**！
2. **閉包變數脆弱**：`_jia_group(n)` 定義在 `for i, ok_key in enumerate(originals, 1):` 之外，內部卻直接參照外層自由變數 `ok_key`。
3. **PASS_A 容錯**：若模型判了 `PASS_A` 卻漏寫 `PASS_A_KEEP_A`，會誤進 `REVISED` 拆回分支。

### 改法（`_src/pack_judge.py` 的 `do_split` 內）
把 `_jia_group` 改為顯式傳 `ok_key`，並在組裝 `segs` 時**逐一檢查譯本甲原有的每個標籤，缺哪個就補哪個**：

```python
        _jia_cache = {}
        def _jia_group(n, target_key):
            if target_key in _jia_cache:
                return _jia_cache[target_key]
            out_segs = []
            if mat:
                _mp = os.path.join(mat, target_key + '.md')
                if os.path.exists(_mp):
                    _mt = io.open(_mp, encoding='utf-8').read()
                    _jia = MI.from_jia(_mt)
                    for _lab, _body in re.findall(
                            r'【(疏文|記文|鈔文|律文|註文|序文)】\n(.+?)(?=\n【|\Z)', _jia, re.S):
                        out_segs.append((_lab, _body.strip()))
                    if not out_segs:
                        for _lab, _idx, _body in re.findall(
                                r'■ (疏文|記文|鈔文|律文|註文|序文)（譯本甲）\[(\d+)\]\s*\n+(.+?)(?=\n+■ |\n+【|\Z)',
                                _mt, re.S):
                            if int(_idx) == n:
                                out_segs.append((_lab, _body.strip()))
            _jia_cache[target_key] = out_segs
            return out_segs
```

並且在處理每一個 `ok_key` 時，改為**按標籤合併**（有改的用 `per_group`，沒輸出到的標籤自動補回譯本甲）：

```python
        # 若模型結論明寫 PASS_A（即使忘記寫 PASS_A_KEEP_A）且完全沒列分歧，直接走 PASS_A

                if mat:
                    _emit_single(mat, dst, ok_key)
            ok += 1
            continue
```

以及迴圈內補齊缺失標籤：
```python
        for i, ok_key in enumerate(originals, 1):
```

## 3. `make_hybrid.py` ＋ `qwen_local.py`：時間戳與 `src_hash` 導致預填的 6,551 份舊回覆全部重跑

```python
        import hashlib
```
