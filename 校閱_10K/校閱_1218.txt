# 校閱材料　第1218檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1218-0001】資持記/11a_中四上#34
【原文】房有妨難，衣曾犯過，不合加法，故名聽止。言下，別釋，初釋可學。〔準疏有法，即處分說淨等。〕不可學中，初指同。但下，略示。謂房量過減，長財大小，迷忘互生；但不違教，故名止持；迷非可學，故不制犯。〔法，謂作法是非，昏迷雜起也。〕上二句始終迷。
【譯文】若是房舍營造有妨礙與災難，衣服曾經涉入犯戒過失，依律不合適再行附加羯磨加法，這就稱為「聽止」。「言」字以下，個別進行解釋，首先解釋可學。（依照《戒疏》，此處應當有行法，也就是處分、說淨等羯磨法則。）在「不可學」之中，首先指出與前文相同。「但」字以下，略作提示。這是指房舍的尺度超過或不足、長物資財的大小規格，在心中迷亂遺忘相互交替產生；但只要沒有故意違背戒教，就仍舊稱為止持；由於這種迷亂並非人力可刻意學習防範的，所以並不制定為犯戒。（法，是指羯磨作法的正確與否，心中昏昧迷亂雜亂生起。）上面兩句是指自始至終都處於迷亂。

【1218-0002】資持記/11a_中四上#35
【原文】如作房衣過量，一向謂為如量等。下二句明轉想。如前心欲作過量，後轉謂如量；前心蘭，後心無犯；故云不定；今望後心，為不可學。作持中，可學，制門，初總標。法下，別釋；前釋法中，初句總示。下二句轉釋。言律藏者，復分二類：一者，總收制作三種羯磨。
【譯文】例如建造房舍或裁剪衣服超過了標準尺度，自始至終一味誤以為是符合標準尺度的情形。下面兩句說明中途產生轉想。例如先前的心本來打算要做超量的事，後續念頭一轉誤以為是合乎標準的；前念僅構成偷蘭遮罪，後念則不構成犯戒；所以說結果並不固定；如今著眼於轉想之後的後念，將它歸為不可學。在「作持」之中，可學的「制門」，首先作總括標舉。「法」字以下，分別進行解釋；在前面解釋法的部分中，第一句作總括提示。下面兩句輾轉解釋。所謂「律藏」，又細分為兩類：第一類，總括統攝制作方面的三種羯磨。

【1218-0003】資持記/11a_中四上#36
【原文】眾法，如受結說恣治諫懺擯等。〔處分杖囊，等在聽門。〕對首，即安居依止持衣加藥之類。〔衣藥說淨等屬聽門。〕心念，如六念責心等。二者，總收眾共兩行，除羯磨外，律諸犍度所制行法，如〈師資〉、〈僧網〉、〈衣鉢〉、〈行護〉之類，通有制聽，具如上下兩卷。
【譯文】眾法羯磨，例如受戒、結界、說戒、自恣、治罰、諫斥、懺罪、擯出等等。（處分杖、囊等羯磨，歸在聽門。）對首羯磨，也就是安居、依止、持衣、加持常藥這一類。（衣服、醫藥的說淨等屬於聽門。）心念羯磨，例如六念法、責心懺罪等等。第二類，總括統攝眾行與共行這兩種行持（大眾共處之眾行與共修履踐之共行），除了羯磨法之外，律藏各個犍度所制定的行持之法，例如〈師資〉、〈僧網〉、〈衣缽〉、〈行護〉這一類，全都通貫於制教與聽教，具體內容詳載於上卷與下卷之中。

【1218-0004】資持記/11a_中四上#37
【原文】行謂對治者，如衣食房藥，隨時起觀；行住坐臥，常爾一心之類。次明事中。與前止持制作無異；但取造修，是今本位。〔準此亦有制作制止，但止在前門，故此不分耳。〕聽門法事可見。次難通中。已前一向依古，唯明可學，彼以惡事為不可學；作門事法俱善，故不可立，今約迷心為不可學；
【譯文】所謂「行謂對治」（行持指的是對治煩惱），例如在飲食、衣服、房舍、醫藥等方面，隨時生起正念觀察；在行住坐臥四威儀中，恆常保持一心不亂這一類。其次在說明「事相」之中。這與前面止持制作門完全沒有差別；只是純粹著眼於積極造作修持，才是此處作持門原本的位階。（依照這個道理，作持其實也兼具制作與制止，只是制止已在前面的門徑說明過，所以這裡不再細分罷了。）聽門中的法與事，依照文義即可明白。其次在難題通達之中。前面一向依照古說，僅僅闡明了可學，那是因為古人把惡事判定為不可學；而作持門中的事與法全都是善法，所以古人認為不可在此立不可學，如今依據迷亂之心來判定不可學；

【1218-0005】資持記/11a_中四上#38
【原文】無問善惡，一切皆通。欲顯古今不同，故於文後徵破；即如疏云：若依此明，與昔持犯，通塞全異，是也。〔舌塞今通。〕初牒前徵起。由下，直以今義難破。謂長衣開忘，房開想疑；既同迷忘，亦合齊立，何得不通耶？廣如後者，指雜料簡句法中。
【譯文】不論善法還是惡法，一切全都普遍通達。為了顯現古今見解的不同，所以在文末特別提出徵問並加以破斥；這正如《戒疏》所說：如果依照現在這種觀點來闡明，那麼與往昔所論持犯的通達或隔阻將全然不同，正是這個意思。（昔日不通而今通達。）首先引述前文提起徵問。「由」字以下，直接依憑當前的義理發難破斥。這是說長衣開許遺忘，造房開許轉想與生疑；既然同樣屬於迷亂遺忘，理當同樣齊整設立不可學，怎麼能說不通呢？詳細內容如同後文所述，是指在雜料簡的句法之中。

【1218-0006】資持記/11a_中四上#39
【原文】若準《戒疏》，徵文之下，先出古解云：非此所明，以非進修，聖不制學〔此示不可學義〕；不同止持，通不可學；事唯離過，故得明也。今此略其古解，直示今義耳。〔或有改字為亦通者，或云：與疏影略者，皆非，安有影略文在別部耶！〕此下，點示行宗。恐謂迷忘非作持故。後明兩犯，竝翻二持；
【譯文】若是依照《戒疏》，在發難徵問的文句之下，先列出古人的解釋說：這不是此處所要說明的，因為它並非進取修持的善行，聖者並不制定在此處修學（這是指明古人不可學的涵義）；這不同於止持，止持普遍通於不可學；因為止持的事相純粹在於遠離過失，所以才得以說明。如今本鈔省略了古人的解釋，直接展示了當前的義理罷了。（有人將字改為「亦通」，或者說：與《戒疏》是互有影略，這些都是錯誤的，哪有影略的文字反而留在另一部著作裡的道理！）此處以下，點明提示行持的宗歸要旨。這是擔心有人誤以為迷亂遺忘就不是作持的緣故。後面說明兩種犯戒，全都是將兩種持戒翻轉過來；

【1218-0007】資持記/11a_中四上#40
【原文】以無別體狀，但望順違，兩分持犯。前作犯云，但不依戒，後止犯云，所對法事，即略指其體；至於制、聽、止、作，可、不可學，竝同前耳。昔人有立制聽二教為體。今謂二教，乃是攝法總科；所攝事法，乃是其體，故知非也。又有章門，以四行無作為體，謂與受體不別。
【譯文】因為這並沒有另外獨立的體狀，純粹是著眼於順從戒律或違背戒律，從而劃分出持戒與犯戒。前面作犯說「只要不依照戒律」，後面止犯說「所對應的法則與事相」，就是粗略地指明其本體；至於制教、聽教、止持、作持，以及可學、不可學，全都與前面所說的一樣。過去有人主張以「制、聽二教」為持犯之體。如今我們認為，二教只是統攝行法的總綱領；二教所統攝的具體事相與法則，才是真正的本體，由此可知古人的說法是不正確的。又有其他論章，主張以四行中的「無作戒體」為體，認為它與當初受戒所得的受體並無區別。

【1218-0008】資持記/11a_中四上#41
【原文】今謂受隨前後，發業不同；云何持犯，與受不別；況兩犯無作體是不善，豈同受體，是亦不然。又有人立萬境為體。今謂境乃持犯之緣，非是其體；又諸戒列緣，境專一種；若唯立境，不攝諸緣，則成局故；又婬、觸、麁、媒，說法同宿，行坐、乘船，止一女境；若唯立境，則迷諸相；
【譯文】如今我們認為，受戒與隨行有時間前後之別，兩者所引發的業力性質完全不同；持犯的體怎麼能說與受體沒有差別呢？更何況作犯與止犯這兩種犯戒的無作體是不善業，哪裡能等同於受戒所得的純善受體，因此這種說法也是不對的。又有人主張以「萬千外境」為戒體。如今我們認為，外境只是引發持犯的外緣，並不是持犯的本體；再者，各條戒律在列舉犯罪要件時，境界只是其中的一種要件而已；如果僅僅以境為體，就無法統攝其餘各項犯罪因緣，這樣定義就顯得過於局限；而且，淫欲、摩觸、粗語、媒嫁、說法同宿、共同行走坐立、同船共渡等戒，所對的僅僅都是同一個女性之境；若僅僅以境為體，就會混淆諸多戒條的不同行相；
