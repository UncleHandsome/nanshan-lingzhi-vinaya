# 校閱材料　第926檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【926-0001】資持記/02b_上一下#2
【原文】我亦下，遮其受經。所以然者。經明眾生佛性，如雜血乳；停搆煎煖，乃出醍醐。佛性亦爾，為煩惱雜；三學修治，漸至佛果。欲斷煩惱，先須止業。止業之要，豈過戒律。今時濫染大乘，便言不拘不檢，無持無犯，何善何罪。師徒傳妄，作惡無窮。又云：持戒人天果報。請詳佛語，宜息邪情。
【譯文】「我亦」以下，遮止他們領受經法。為什麼會這樣呢？經中說明眾生的佛性，就像混雜著鮮血的牛奶；必須經過靜置澄清、搆取精華並加熱熬煮，才能提煉出純淨的醍醐。佛性也是如此，被種種煩惱所雜染；唯有透過戒、定、慧三學的修持調伏，才能漸次達到成佛的果位。想要斷除煩惱，必須先制止惡業。而制止惡業的關鍵，哪裡能超過戒律呢？現在有些人浮濫沾染大乘教法，便妄言不用拘束檢點，沒有持戒也沒有犯戒，哪裡有什麼善行與罪業。師父與徒弟相互傳遞虛妄見解，造作無窮無盡的惡行。又有人說：持戒只能得到人天福報。請仔細研讀佛陀的教誡，應當熄滅這種邪妄的心念。

【926-0002】資持記/02b_上一下#3
【原文】況《華嚴》圓頓上乘，《涅槃》終窮極唱；金言猛勵，可不信乎！《華嚴》偈，上句示功。無上菩提者，以果彰因也。次句勸修。下半偈明聖所歎。以順教故。故下，祖師示意。望前已引，故言重也。大乘論，《智論》釋《般若經》，具云《大智度論》。今引第十四。文為五段，初二句舉果總勸。
【譯文】更何況《華嚴經》是圓滿頓悟的無上乘法，《涅槃經》是究竟窮極的終極開示；佛陀金口宣說的嚴厲策勵，難道可以不相信嗎！《華嚴經》的偈頌中，上一句開示持戒的功德。所謂無上菩提，是藉由佛果來彰顯持戒之因。次一句勸勉大眾修持。下半偈說明這是聖者所讚歎的。因為這是隨順教法的緣故。「故」字以下，是祖師開示經義。相對於前面已經引述過的內容，所以說是重複引述。大乘論典中，《大智度論》是解釋《般若經》的，全稱為《大智度論》。現在引用第十四卷的內容。這段文字分為五段，最初兩句舉出佛果來作總體勸勉。

【926-0003】資持記/02b_上一下#4
【原文】大利如上二經。一切下，二敘功勸。諸德根及下善法處，同前大地喻也。出家要者，同前《華嚴》文也。如下，舉世二物，喻令護惜。又下，三約無戒損失勸，上舉三喻。若下，法合。好果語通五乘，對前大利，須指佛果。若棄下，四舉無益苦行勸。文列諸外道法。
【譯文】所謂大利益，如同上述兩部經典所言。「一切」以下，第二段敘述持戒功德來勸勉。「諸德之根」以及下面的「善法居處」，與前面將戒比喻為大地的意義相同。「出家的要道」，與前面《華嚴經》的經文義理相同。「如」字以下，舉出世間的兩種事物，作為比喻讓人好好愛護珍惜。「又」字以下，第三段從缺乏戒律所招致的損失來勸勉，上面先舉出三種比喻。「若」字以下，將比喻與法理相結合。結出美好果報這句話通於五乘，但對應前文所說的大利益，這裡必須特指成佛之果。「若棄」以下，第四段舉出無益的苦行來勸勉。經文中列舉了各種外道的修法。

【926-0004】資持記/02b_上一下#5
【原文】袈裟語通，或即外道服，或可外道僣著袈裟；如販賣戒，外道與跋難陀袈裟相易，為戒緣起。或可通名不受佛戒之人，不專外道。人雖下，五約現報勸，初明生前報。上二句標持人。香聞下三句，即戒本中名譽樂；香喻美德外揚，為他所聞。所願一句，即利養樂。此謂戒德所感，非求而得之。
【譯文】袈裟這個詞通指法衣，這裡或者是指外道的服飾，或者可能是外道僭越穿著佛教的袈裟；就像販賣戒的緣起，是外道與跋難陀比丘交換袈裟，而成為制定戒律的由來。或者也可以通稱不領受佛戒的人，並不專指外道。「人雖」以下，第五段依現世果報來勸勉，首先說明生前的果報。上面兩句標示出持戒之人。「香聞」以下的三句，就是戒本中所說的名譽之樂；香氣比喻美好的德行名揚於外，為其他人所聽聞。「所願」這一句，就是利養之樂。這是指由戒德自然感應而來，並不是刻意祈求得來的。

【926-0005】資持記/02b_上一下#6
【原文】持戒下，次明臨終報。準《俱舍》中，人命終時，三大次解；火大解時，令心躁悶，翻睛吐沫；水大解時，形體洪腫，筋脈爛壞。〔此相必受惡報。〕風大解時，瞥爾命終，不知不覺；地大堅重，不能解也。〔生時由此三大，支節連持。此三既散，支節即死。故云解也。〕今取最後，故舉風大；能解支節，故喻如刀。
【譯文】「持戒」以下，接著說明臨終時的果報。依照《俱舍論》的說法，人命終時，地、水、火、風中的三大會依序分解；火大分解時，會使人心煩躁悶熱，翻白眼、吐白沫；水大分解時，身體會嚴重浮腫，筋脈潰爛敗壞。〔出現這種相貌必定遭受惡道果報。〕風大分解時，瞬間命終，在不知不覺中死去；地大質地堅硬厚重，不會消散分解。〔活著時依賴這三大，肢體關節才能相連維持。這三大既然散去，肢體關節便隨之死亡。所以稱為分解。〕現在取最後死亡的階段，所以舉出風大；因為風大能吹散解體肢體關節，所以比喻為利刀。
