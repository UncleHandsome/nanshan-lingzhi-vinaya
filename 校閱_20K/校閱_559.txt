# 校閱材料　第559檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【559-0001】資持記/08d_中二#60
【原文】言轉易者，示戒名也。此下，簡販賣。五異指如疏者，彼云：初對人不同，貿寶七眾俱犯，貿衣唯二俗犯〔在家二眾〕；二貿寶自作教他，為己同犯，除為三寶，貿衣使人不犯；三貿寶一制不開，貿衣則開酥油相易；四衣寶捨則道俗不同〔衣對道捨，寶對俗捨。〕；五還財本非本別〔衣捨還元物故云本，寶捨易淨，物故非本。〕。
【譯文】文中所說的「轉易」，是指標明這條戒律的核心名稱。從這裡以下，詳細簡別本戒與後面的經商販賣戒。所說的五種相異之處全如《戒疏》所說，疏中指出：第一是對待的對象不同，寶物貿易戒無論面對出家還是受戒七眾都會構成犯戒，而衣物販賣戒則唯有面對在家男女二眾才會構成違犯；第二是寶物貿易戒無論是自己親手做還是教唆別人做，只要是為了謀取私利就一律同罪，除非是為了常住三寶的利益才不犯，而衣物販賣戒只要差遣在家人去辦理，比丘自身就不犯重罪；第三是寶物貿易戒一經制定便毫無開許，而衣物販賣戒則開許以酥、油互相交換；第四是依法捨棄時面對的對象道俗有別【違犯販賣衣物是面對出家修道人捨棄，違犯貿易寶物則是必須面對世俗在家人當面捨棄】；第五是捨棄之後返還的財物本體不同【衣物捨棄還元物故云本，寶物捨棄換成清淨物故非本】。

【559-0002】資持記/08d_中二#61
【原文】律下，準律顯異。律有七物交互並犯；金有三品：一已成金〔華敘莊嚴具是〕，二未成金〔即金鋌也〕，三已成未成金〔鎔瀉成器未鋋治者〕；銀亦三種，錢唯一品，總為七也。但下，簡異；則知此戒唯約寶論。犯緣中。是錢寶者，局所貿也。能貿則通衣寶餘物。明懺中。
【譯文】從「律」字以下，依循律典本文彰顯其中的差異。律典列出了七種財寶，彼此交互交易買賣全都構成犯戒；黃金分為三種等級：第一是「已經成型的熟金」【例如雕花首飾等各類莊嚴器物】；第二是「尚未成型的生金」【也就是未經鍛造的金條金錠】；第三是「處於成型與未成型之間的半熟金」【例如剛熔鑄成器具粗胚但尚未經細緻錘鍊打磨的金屬】；白銀也同樣具備這三種等級，加上流通的錢幣只有一種品類，總共合稱為七種財寶。從「但」字以下，作簡別歸納；由此便可知曉這條戒律純粹是針對珍寶而論。在犯戒條件中，『是錢寶』一句，局限於所換得的標的物；而用來換取的物品，則通於衣服、珍寶及其餘雜物。在說明懺悔的段落中。

【559-0003】資持記/08d_中二#62
【原文】此戒不對僧捨，恐隨別悔，故特遮之。以過重故。不犯中。唯開三寶，餘無所通。二十。〔佛在舍衛，跋難陀往無住處村，以生薑易食；又共外道博衣，悔而不還，譏訶因制。〕戒名。準疏分三：為利故收，為利故出，諍語而高，為販也。為利而取，故減前價，名買也。
【譯文】這條戒所涉及的錢寶不可在僧眾面前捨棄（因僧人不捉寶，須對在家人捨），但悔罪則必須對僧團發露，唯恐比丘私下隨便對個別比丘懺悔，所以特地加以遮止禁止。這是因為違犯這條戒律的過失實在太過沉痛深重的緣故。在不犯戒的特例中。唯獨開許為了常住三寶的弘法與修繕利益而進行調換，其餘一切個人私用皆絕對不在開許之列。第二十條戒【佛在舍衛，跋難陀往無住處村，以生薑易食；又共外道博衣，悔而不還，譏訶因制】。戒律的具體名稱。依照《戒疏》的剖析分為三種型態：為了謀取暴利而大肆收購，為了謀取暴利而高價賣出，在交易過程中討價還價爭吵喧鬧，這就叫做「販」。為了謀取暴利而買進，所以拼命壓低對方的原始價格，這就叫做「買」。

【559-0004】資持記/08d_中二#63
【原文】為利故出，強增價而高，曰賣也。〔販但先收犯還同賣。〕制意中。四聖種即四依行；制斷賣買，令修四法。犯緣中。初緣簡五眾不犯。略示中，初示開貿。上句指律，文見不犯。次句準餘部，如下《僧祇》、《十誦》。若據下，引《四分》衣法，亦開比丘，不獨他部。
【譯文】為了謀取暴利而將物品出手，故意強行抬高價格索取暴利，這就叫做「賣」。【「販」只是指先前低價收購囤積，日後出手獲利的犯相本質上依然等同於「賣」。】在制戒的深遠用意中。所謂「四聖種」，就是指出家人安住於「糞掃衣、乞食、樹下坐、陳棄藥」這四種神聖的依止行法；佛陀制戒徹底斬斷世俗的一切買賣交易，就是為了令出家人專心致志地修習這四種解脫正法。在犯戒條件的判定中。第一個條件是簡別若對出家五眾進行交易則不構成犯此重罪。在簡略說明的段落中，首先說明開許以物易物的合法範疇。上一句是指向律典本文，其具體條文可見於不犯的章節中。下一句則是參照其餘部派律典的規定，正如後文所引用的《僧祇律》與《十誦律》。從「若據」以下，引證《四分律》中關於僧衣處置的法規，同樣也是開許比丘之間互相調換的，並非只有其他部派才這樣規定。

【559-0005】資持記/08d_中二#64
【原文】《四分》下，示犯相。律云：以時藥易時非時七日盡形波利迦羅衣，如是互易。〔隨一一物為頭，以歷諸物。〕疏云：此指緣起說，若以錢買衣，屬此戒攝；反則前戒。〔准知販買兩戒，但據所買以分。〕次廣明中，初科，前明業重。甚於屠者，以心普故。
【譯文】從「《四分》」以下，詳細展示具體的犯戒相貌。律中說：以當令的時藥去換取非時藥、七日藥、盡形壽藥，或者是用來調換各類受持的資身僧衣，像這樣將各類物資相互進行交易兌換。【隨意拿其中任何一種物品作為本錢開頭，以此歷遍其餘各類物品相互換取。】《戒疏》解釋說：這段律文是順應制戒的最初因緣來說明的，如果是拿世俗的金錢去購買衣服，就屬於本條販賣戒所管轄；相反地，如果是拿僧衣去換取金銀錢財，就歸屬於前面那條貿寶戒所攝受。【由此準則即可明瞭：販買衣物戒與貿易珍寶戒這兩條戒律，純粹只是依照比丘最終所買得、換得的物品性質來作出區分。】在接著廣泛說明的內容中，第一個科判，前半段深入揭示這種經商造業的罪過極其深重。經中指出出家人經商的罪業甚至比屠夫屠宰生靈還要嚴重，這是因為商人盤剝盤算的心念是普遍針對世間一切眾生的緣故。

【559-0006】資持記/08e_中二#1
【原文】此販賣下，次明施物營福不開用者，物體穢故。初示制約。所以下，徵制意。若販下，三結犯相。罪重結者，物唯一捨，罪則合懺。次科，初明受施。經營活業，名為治生。言犯捨者，謂受施人。若下，示儉開。須彼告白僧，作白衣物受。即是開法。若施下，明轉施得受。
【譯文】這段「販賣」以下，接著說明布施的物品若用來經營福業，也是不允許使用的，因為物品本質已經染污。首先標出制戒約束。從「所以」以下，追究制戒用意。從「若販」以下，第三部分判定犯戒之相。罪名重結的意思，是指物品只須捨棄一次，罪名則必須合在一起懺悔。下一個條目，先說明接受布施。經營維生事業，稱為「治生」。說到犯了應捨棄的罪，是指接受布施的人。從「若」以下，說明饑荒歉收時的開許。必須由那人向僧眾表白宣告，當作俗人的物品來接受。這就是開許的法則。從「若施」以下，說明轉手施捨後便可以接受。

【559-0007】資持記/08e_中二#2
【原文】彼既決捨，即是淨物。三中，初明結罪。即犯販也。若下，明開自食興福。因出所餘，非本意故。衣鉢義同，故注示之。四中，初明對易。相似謂以九物相易；不相似者，即互易；二種俱犯。若下，可捨物即已犯金寶，用此糴粟。以粟易物，雖復轉易，亦不合用。食但犯吉，異上《多論》。
【譯文】既然對方已經下決心捨棄，那便算作乾淨的物品。在第三部分中，先說明定罪。這就犯了販賣罪。從「若」以下，說明開許自己食用與興辦福德。因為這是處置剩下的部分，並不是最初的本意。衣與鉢的道理相同，因此在注文中提示。在第四部分中，先說明互相交易。性質相同是指用九種物品互相調換；性質不同則是指互換不同類別；這兩種情況都會犯戒。從「若」以下，可以捨棄的物品既然已經涉及犯戒的金寶，用這些來買小米。再用小米換取物品，雖然經過反覆轉手交易，依然不合乎使用規定。食用只犯輕罪（吉羅），這一點不同於上面提到的《多論》。

【559-0008】資持記/08e_中二#3
