# 校閱材料　第001檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【001-0052】01_行事鈔/00_卷首#52
【原文】今序斯大略，所謂有七：一興厭漸頓。二結正業科。三報果不同。四攝趣優劣。五起情虛實。六開制互立。七約行彰異，如誼靜二儀也！凡此諸例，並制教之本懷，據斷之宗體。
【譯文】現在敘述其大略，共有七項：一是興起厭離心的漸與頓。二是結成正罪的類科。三是果報的不同。四是所攝道趣（如人、非人、畜生等道趣境界）的優劣。五是生起煩惱之情的虛與實。六是開與制互相建立。七是約行持而彰顯差異，如喧鬧與寂靜兩種情況下的儀則。凡是這些類例，都是制教的本意，是據以判斷的宗旨與體要。

【001-0053】01_行事鈔/00_卷首#53
【原文】第三對事約教判處意。自佛法東流，幾六百載，諸師穿鑿，判割是非；競封同異，不可稱說。良由尋討者不識宗旨，行事者昏於本趣。故須學師必約經遠，執教必佩真文。何事被於毀譏，豈復淪乎蚩責？今判其持犯，還約其受體；體既《四分》而受，豈得異部明隨？猶恐不曉大綱，更示其分齊。謂輒將己所學者，判他持犯；脫罹愆失，其唯不學愚癡！今通立定格，共成較準，一披條領，釋然大觀。
【譯文】第三，對事約教判處的用意。自從佛法東流，將近六百年來，諸位律師穿鑿附會，判割是非；競相封守同異之見，多得無法稱說。這實在是由於探討的人不認識宗旨，行事的人對本來的旨趣昏昧不明。所以受學律藏的人，立約求學一定要期望經久長遠，執持教法一定要佩帶真實的文本。這樣還有什麼事情會遭到毀謗譏嫌，又怎會淪落於無知的責備呢？現在判定持與犯，還是要依據他所受的戒體；戒體既然是依《四分律》而受，怎麼可以用其他部派來判明隨行呢？仍恐怕不能知曉大綱，再為他指示分齊界限。就是說：動輒將自己所學的，去判定他人的持犯；倘若遭受過失，那只能怪自己不學而愚癡了！現在通盤建立固定的格範，共同作為比較的標準，一旦翻開條目綱領，就能豁然開朗地宏觀全局。

【001-0054】01_行事鈔/00_卷首#54
【原文】第四用諸部文意。統明律藏，本實一文，但為機悟不同，致令諸計岳立。所以隨其樂欲，成立己宗，競采大眾之文，用集一家之典。故有輕重異勢，持犯分塗；有無遞出，廢興互顯。
【譯文】第四，運用諸部文義的用意。總體說明律藏，本來實際上是一味的教法，只因為眾生根機悟入不同，致使各種見解如高山並立。所以隨順各自的愛樂欲求，成立自己的宗派，競相採集大會結集的大眾文句，用來結集成一家的典籍。因此有輕重的不同情勢，持犯的分途；有與無交替出現，廢與興互相顯現。

【001-0055】01_行事鈔/00_卷首#55
【原文】今立《四分》為本；若行事之時，必須用諸部者，不可不用。故《善見》云：毘尼有四法，諸大德有神通者，抄出令人知。一本者，謂一切律藏。二隨本。三法師語者，謂佛先說本，五百羅漢廣分別流通，即論主也。四意用，謂以意方便度用及三藏等廣說也。先觀根本，次及句義，後觀法師語；與文句等者用，不等者莫取。正文如此。
【譯文】現在以《四分律》為根本；如果在實際行事時，必須用到諸部（其他部派）的，就不可不用。所以《善見論》說：毘尼有四種法，諸位有大神通的大德把它抄錄出來讓人知道。第一是「本」，就是一切律藏。第二是「隨本」。第三是「法師語」，就是佛先說了根本，五百羅漢廣泛分別而流通，也就是論主。第四是「意用」，就是以心意方便度量運用，以及三藏等廣為宣說。先觀根本，其次及於句義，最後再觀法師語；與文句相等的就用，不相等的就不要取。正文就是這樣說的。

【001-0057】01_行事鈔/00_卷首#57
【原文】謂此宗中，文義俱圓，約事無缺者，當部自足，何假外求？餘有律文不了，事在廢前；有義無文，無文有事；如斯眾例，並取外宗，成此一部。
【譯文】就是說：在本宗之中，文與義都圓滿、就事相而言沒有欠缺的，本部自身就已足夠，何必假借向外求取？其餘有律文未能究竟明了的，有事相是當部未制、前代他部已制（事在廢前）的；有義理而無文字、無文字卻有事相的；像這樣的眾多例子，都要取用外宗的說法，來成就這一部鈔。

【001-0058】01_行事鈔/00_卷首#58
【原文】又所引部類，必取義勢相關者，可用證成；必緩急重輕，是非條別者，準論不取。故文列四說，令勘得失。《十誦》墨印，義亦同之。若此以明，則心境相照，動合規猷；繁略取中，理何晦沒。若不鏡覽諸部，偏執一隅，涉事事則不周，挍文文無可據；遂師心臆見，各競是非，互指為迷，誠由無教。
【譯文】又，所引用的部類，一定要取義勢相關的，才可以用來證明成立；若是緩急重輕、是非條理有所差別的，依照論的做法就不取。所以文中列出四種說法，讓人勘驗得失。《十誦律》的墨印（原則），義理也與此相同。若能如此明白，則心與境互相映照，一舉一動都契合規矩；繁略取其中道，道理怎會隱晦埋沒。如果不以鏡子般的眼光遍覽諸部，而偏執於一個角落，那麼涉獵事情時事相就不周全，校對文字時文字也沒有可依據的；於是就師心自用、憑臆測之見，各自競爭是非，互相指責對方迷惑，這實在是由於沒有教法依據。

【001-0059】01_行事鈔/00_卷首#59

【譯文】如果《四分律》判定事相的文句有限，事情不能普遍通行，就回過頭來用其他部派的文句，以成辦其他部派所說的事。或者兩部律之中，文與義都明白，那就無從取捨，便一併列出正法，隨自己的意思採用。然而在實行運用正教時，要親自披閱原典，這是恐怕傳聞會混濫真理的緣故！

【001-0062】01_行事鈔/00_卷首#62
【原文】第五文義決通意。夫理本絕名，故立名標其宗極；名隨事顯，故對事而備斯文。然考斯律藏，言事並周，但為年代渺邈，聲彩靡追；法為時移，事多殘缺；加以五師捃拾，情見不同；重由翻譯失旨，妄生構立；又為抄寫錯漏，相承傳濫。所以至於尋究，紛慮良多。今總會之，以通其大見。

【001-0063】01_行事鈔/00_卷首#63
【原文】若文義俱闕，則可舉一以例諸；或就理有，而成前事；或在文雖具，而於義有闕，便以義定之。故論言以理為正故也！或義雖必立，當部無文，則統關諸部，以息餘謗。
【譯文】如果文與義都欠缺，就可以舉一例來類推其餘；或者就義理上應有的，來成立前面所說的事；或者文字雖然具足，但在義理上有欠缺，便以義理來判定。所以論中說「以理為正」的緣故！或者義理雖然一定應成立，而本部沒有文字，就統攝關涉諸部，以止息其餘的謗議。
