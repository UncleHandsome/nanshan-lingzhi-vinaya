# 校閱材料　第962檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【962-0001】資持記/02f_上一下#36
【原文】上二句明得中，下二句示制意。結文中。亦分綱本。僧已忍竟，僧忍默然故；是事如是持，此為綱也。兩句在上，下竟字當中間。與某受戒，某甲為和尚，還結前本也。此下，點文。可解。三法料簡，增減中。據律，單白及白二中白；或止有四句，闕第二句者，則名為減；然本無增，望彼五句相待為言。
【譯文】最上面的兩句說明合乎適中之道，最下面的兩句顯示出佛陀立制的用意。在結語的文句中，同樣拆分為綱領與根本。僧團既然已經默許完畢，正因為僧團忍可而保持沉默；這件事就應當這樣堅持遵守，這就屬於骨架綱領。這兩句話排在上面，下方的「竟」字應當居於中間。傳授某人具足戒，由某甲擔任和尚，這又是回過頭來結示前面的根本事項。從此以下，提示文句。理應可以理解。對於三種儀軌的分析考量（三法料簡），在文句增減的段落中。依據律藏的記載，單白羯磨以及白二羯磨中的宣白，有時只有四句話，欠缺了第二句話，這種情況就稱為「減」；然而原本並不存在增加的情況，只是相對於那五句的完整結構互相對比而言。

【962-0002】資持記/02f_上一下#37
【原文】若是羯磨及白四中白，定無增減，故非所論。文中先出所以，不出三意。若是事重，如諸說恣還衣亡物之類；若有緣起，如諸結界，須比丘唱相緣起〔謂羯磨前緣，非謂本制緣。〕；若有乞詞，如諸受懺〔謂捨墮單白，非受戒及餘懺也。〕。
【譯文】如果是羯磨本體以及白四羯磨中的宣白，必然固定沒有任何增減，所以不在這裡討論的範圍內。文句中首先探討其中的緣由，歸納起來不外乎三種意圖。第一是如果僧事非常重大，例如各項說戒、自恣、退還袈裟、處理亡僧遺物之類；第二是如果有特定的發起緣由，例如各類結界之法，必須有比丘親自宣唱界相邊界的發起緣由〔這是指正式羯磨前的鋪陳前緣，不是指佛陀最初制戒的緣起〕；第三是如果包含懇求的陳詞，例如各種受領懺悔（捨墮受懺）〔這是指捨墮罪的單白羯磨，不是指受具足戒以及其他各篇的懺悔法〕。

【962-0003】資持記/02f_上一下#38
【原文】不牒事者，如上結界受懺，竝以前緣牒入羯磨。若上三種，必具五句。若但四句成者，反此三意，兼不牒入，如文所列；即說戒堂及滅諍結集中諸白，竝諸差人白二等是也。然又須知唯略第二；至第四句，緣本雙牒，必無有缺，尋之可知。餘下，明增。例皆五句。然律文亦有翻傳脫漏之者；
【譯文】解釋鈔文「不牒事」之語：如同前面所說的結界與受懺，全都是把先前的事緣寫入羯磨文之中。如果是上面這三種情況，就必定要具備完整的五句話。如果僅僅具備四句話就能成辦羯磨，那是與這三種意圖相反，並且也不用將前緣寫入羯磨之中，就如同文中所列舉的那樣；這就是指在說戒堂以及熄滅諍論、結集三藏時的各種單白，以及各種差派人員的白二羯磨等等便是。然而大眾又必須明白，所省略的唯獨只有第二句；到了第四句時，細部事由與根本事項必定是雙雙陳述，絕對不會有所欠缺，只要仔細尋思就能明白。下文「其餘（餘）」字以下，說明增加的情況，照例全部都是五句話。然而律藏的傳抄譯本之中，也難免有翻譯流傳時脫落遺漏的情況；

【962-0004】資持記/02f_上一下#39

【962-0005】資持記/02f_上一下#40
【原文】功成由解，不必泥文，故云不了等。是非，中初。綱中增減，一向屬非；白中三句，總一十四字，羯磨正體一十七字，結文一十四字，此竝楷定。縱無增減，而音聲淆混，言相不明，亦歸非攝。緣中，初明理順。以言雖通許，理不可乖；往往世愚，輒便加減。增下，明開許，初句開增減。
【譯文】羯磨的功德成辦全在於心領神會，用不著死板拘泥於文字，所以才說「如果不能通曉（不了）」等等。在正確與錯誤（是非）的段落中，首先看第一點。在核心綱領之中擅自增減字句，一律屬於非法的過失；宣白中的三句話，總共只有十四個字，羯磨的正身本體只有十七個字，結尾的宣告詞只有十四個字，這些全部都是固定不可動搖的格式標準。縱使字數沒有任何增減，但若是發音混亂不清、語義含糊不明，同樣也歸入非法的範圍。在細部事由的段落中，首先說明義理應當通暢順達。因為言詞雖然開許可以變通，但其中的戒律法理絕對不可違背；然而世間愚昧之徒，往往動不動就擅自任意增加或刪減。下文「增加（增）」字以下，說明開許融通的界限，第一句開許了合理的增減。

【962-0006】資持記/02f_上一下#41
【原文】疏云：如結大界，即列二同；戒場小界，攝僧義一，豈得二別？何不列也！準此增著亦得；如《五分》結場，增文同一布薩等〔此明戒場三小得增〕；減却二同亦得，如諸界等〔此明大界得減〕。次句開易語。詁訓謂言異義同；如云某甲作和尚，從僧求戒，眾誦戒之類。
【譯文】《羯磨疏》說：例如結大界時，儀軌中列出了「身同住」與「法同食」這二同；戒場與小界，收攝僧眾的意義本是相同的，難道可以分裂為二嗎？為什麼不一併列入呢！依照這個道理，額外增加文字也是可以的；例如《五分律》結戒場時，就額外增加了「同一布薩」等文句〔這是說明戒場與三種小界允許增加文字〕；刪減掉二同的文句也是可以的，例如各類結界法等〔這是說明大界允許刪減文字〕。下一句開許了替換字詞的作法。所謂「詁訓」，是指字面文字不同而內在義理完全一致；比如改說「某甲作和尚，懇求僧團賜與戒法，大眾齊心誦戒」之類。

【962-0007】資持記/02f_上一下#42
【原文】而下二句，結上二開。類下，引例有三，初引部別證。《五分》白及羯磨一概四句，竝無第四；《十誦》受戒法云：年歲已滿，衣鉢具足等。又外部羯磨綱中，尚有增減；《五分》長老忍下無者字，結詞僧已下無忍字；《十誦》第四句牒本已云：忍者是長老默然，又說字上有便字，共加五字。
【譯文】下方的兩句話，總結了上述兩種開許的原則。下文「比照（類）」字以下，引用了三類例子作為明證，首先引用不同部派的律典作為證明。《五分律》的宣白與羯磨一概都只有四句，完全沒有第四句；《十誦律》受戒法中則說：「年齡歲數已滿，衣鉢資具齊備」等。此外，其他部派羯磨的核心綱領中，尚且存在著字數的增減；例如《五分律》在「長老忍」下方沒有「者」字，結尾辭「僧已」下方沒有「忍」字；《十誦律》在第四句引述根本事項時說：「忍者是長老默然」，而且在「說」字上方多了一個「便」字，一共增加了五個字。
