# 校閱材料　第140檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【140-0001】01_行事鈔/07b_卷中之三#2
【原文】覆屋過三節戒二十。四緣：一自為己，二自作使人覆，三至第三節未竟不去見聞處，四至三節竟犯。
【譯文】覆屋過三節戒二十。具備四種緣成犯：一、是親自為了自己；二、自己親手作或差使他人覆蓋；三、工程進行到第三節未完成期間，如果不離開能見聞工程的處所（一直留在現場監工）；四、到了第三節覆蓋完畢，便結犯。

【140-0002】01_行事鈔/07b_卷中之三#3
【原文】輒教尼戒二十一。四緣：一不為僧差，二集於尼眾，三說法教誡，四言了使犯。律中僧不差說法八敬，俱墮；日非，吉羅。《僧祇》：前三後二，此日去者，名為日非。但德須具十，人行又布；今但為略法，如刪補羯磨。
【譯文】輒教尼戒二十一。具備四種緣成犯：一、未經僧團差派（不為僧差）；二、召集比丘尼眾；三、為其說法教誡；四、言語說畢便結犯。《四分律》中說：未經僧團差派而為尼眾說法或教誡八敬法，皆結波逸提（單墮罪）；若非在指定時日前往（日非），結突吉羅（吉羅）。《僧祇律》說：以半月布薩日為準，前三天與後兩天，若於這些日子前往教誡，稱為「日非」（非時）。但能教誡尼眾的比丘必須具備十種德行，且其人格操行又當廣布著稱；如今只作簡略的教誡法，如同《刪繁補闕隨機羯磨》（刪補羯磨）中所述。

【140-0003】01_行事鈔/07b_卷中之三#4
【原文】與尼說法至日暮戒二十二。六緣：一是僧差，二尼眾來集，三教誡說法，四日暮，五知想，六說法不止，犯。律中：除教授，若受經、誦經、若問、若以餘事，乃至日暮。除尼，若為餘女受經至暮，一切吉羅。不犯者：教授尼至日未暮便休；除婦女已，為餘人；若船濟處說法，尼聽；若與賈客共行，夜說法；至尼寺中；若因人請，值說便聽者，一切不犯。
【譯文】與尼說法至日暮戒二十二。具備六種緣成犯：一、是受僧團差派；二、比丘尼眾前來集會；三、為其教誡說法；四、時值日暮；五、明知且認定已到日暮（知想）；六、依然說法不休止，便結犯。《四分律》中說：除了受差教授之外，如果是為尼眾傳授經文、領誦經文、解答疑問，或者因為其他事情而延續到日暮，以及除了比丘尼之外為其他婦女傳授經典至日暮，這一切皆結突吉羅（吉羅）。不犯的情況包括：教誡尼眾在日落之前便及時停歇；排除婦女之後，只為其餘男子說法；在渡口渡船處說法而比丘尼從旁聽聞；與商旅結伴同行而在夜間說法；比丘親至比丘尼寺中；或是因他人迎請，比丘尼正好遇上說法而隨眾聽聞者，一切皆不犯。

【140-0004】01_行事鈔/07b_卷中之三#5
【原文】譏教尼人戒二十三。六緣：一是僧差，二情存為法，三內心嫉忌，四說為飲食，五言了，六前人聞知。不犯者：其事實爾；為供養故，教授、誦經、受經、若問；若戲、若錯，一切不犯。
【譯文】譏教尼人戒二十三。具備六種緣成犯：一、對方是受僧團合法差派的教誡比丘；二、對方本心完全是為了弘法（情存為法）；三、自己內心懷有嫉妒嫌恨；四、譏嫌毀謗他是為了貪圖飲食供養才去教誡；五、譏諷之言說畢；六、對方聽聞並明白其意。不犯的情況包括：該比丘確實就是為了飲食才去教化，實情本來如此；或者對方本來就是為了獲取供養而進行教授、領誦經文、傳授經典或解答疑問；或者是開玩笑（戲笑）、口誤說錯，一切皆不犯。

【140-0005】01_行事鈔/07b_卷中之三#6
【原文】與非親尼衣戒二十四。四緣：一是尼，二非親，三與衣，四領受便犯。律中，除貿易，若與塔佛僧者，一切不犯。
【譯文】與非親尼衣戒二十四。具備四種緣成犯：一、對方是比丘尼；二、彼此非親里（無親屬關係）；三、將衣物贈與對方；四、對方領受完畢即結犯。《四分律》中說：除了公平的物資互換（貿易），或者將衣物布施供養給佛塔、佛像、僧團（塔佛僧）者，一切皆不犯。

【140-0006】01_行事鈔/07b_卷中之三#7
【原文】與非親尼作衣戒二十五。具三緣成犯：一是尼，二非親，三隨作，犯。律中：隨刀截多少，隨一縫一針，皆墮。若復披著牽挽熨治，以手摩捫，若捉角頭挽方正安揲，若緣索線，一切吉羅。不犯者：與親里尼作，若佛塔僧作，若借著者浣染治還主等。
【譯文】與非親尼作衣戒二十五。具備三種緣成犯：一、對方是比丘尼；二、非親屬關係；三、隨作，犯。《四分律》中說：隨剪刀每裁剪一刀、隨縫線每穿縫一針，皆結波逸提（單墮罪）。如果替其披掛試穿、拉扯牽引、熨燙整理、用手撫平摩撫，或者執持衣角拉正疊齊（安揲），或是穿引繫帶索線，這一切附帶動作皆結突吉羅（吉羅）。不犯的情況包括：替具有親里關係的比丘尼縫製；替佛塔、佛像及僧團裁作衣物；若是借穿比丘尼的衣物，將其洗滌、染色、縫補修治完畢後歸還原主等，皆不犯。

【140-0007】01_行事鈔/07b_卷中之三#8
【原文】獨與尼屏露坐戒二十六。四緣：一是比丘尼，二無第三人，三在屏露二處，四共坐便犯。《十誦》：屏處相去一丈墮，丈五吉羅；二丈若過不犯。《僧祇》：共一尼屏坐；或尼請一比丘食，一尼共比丘坐，一尼往來益食。益食去時，隨一一墮。比丘爾時應起，語言：「我欲起。」莫令彼疑作非法。若尼去者不犯。《多論》：比丘坐住屏覆處者，無慚愧處，可作淫處。律中見聞二屏，如二不定中說。若盲而不聾，聾而不盲，若立住，一切吉羅。不犯者：比丘有伴；若有知人，非盲聾；若行過倒地；若勢力持，命梵難者。
【譯文】獨與尼屏露坐戒二十六。具備四種緣成犯：一、對方是比丘尼；二、身旁無第三人；三、處於屏處（隱蔽處）或露處（露天處）這兩種場所；四、一同坐下即結犯。《十誦律》說：在屏障隱蔽處，兩人相距在一丈之內結波逸提（單墮罪），相距一丈五尺結突吉羅（吉羅）；若相距達二丈或超過二丈，則不犯。《僧祇律》說：與一位比丘尼單獨在屏處共坐；或者比丘尼迎請一位比丘應供，一位比丘尼陪同比丘坐著，另一位比丘尼來回添飯加菜。當添飯的比丘尼離開時，單獨相對，隨著每一次獨坐即結一個波逸提（單墮罪）。比丘在那個時候應當立刻起立，並對她說：「我想要站起身來。」切莫讓旁人懷疑比丘在行非法之事。如果是比丘尼主動離開，比丘則不犯。《薩婆多論》（多論）說：比丘坐著或停留在隱蔽屏障處，是指沒有慚愧心之人可以施行淫亂的地方。《四分律》中所指的見屏（眼不見處）與聞屏（耳不聞處），如「二不定法」中所說明。如果第三人眼盲而不耳聾，或耳聾而不眼盲，又或者兩人只是站立停留，這一切皆結突吉羅（吉羅）。不犯的情況包括：比丘身邊有同伴；有通曉事理的第三人在場，且非盲非聾；行路經過時失足跌倒在地；被強有力的勢力強行扣留阻攔；或者遭遇危及性命與梵行之危難（命梵難者），皆不犯。

【140-0008】01_行事鈔/07b_卷中之三#9
【原文】與尼期行戒二十七。五緣：一是尼，二言許共行，三無緣，四同一道，五度界，犯。律不犯者：不共期，若大伴行疑恐怖處，若往彼得安隱，命梵等不犯。《十誦》：開為尼負衣過險徑。
【譯文】與尼期行戒二十七。具備五種緣成犯：一、對方是比丘尼；二、言許共行，承諾同行；三、無合法的因緣；四、走在同一條道路上；五、跨越一個聚落之界限（度界），便結犯。《四分律》中不犯的情況包括：事前未曾相約同行；如果是跟隨龐大的商旅旅伴同行於令人疑懼怖畏的險難之處；或者前往該處能獲致平安安隱；或者為了避免性命或梵行遭遇危難等，皆不犯。《十誦律》開許：為比丘尼背負衣物涉過危險狹隘的險徑，不犯。

【140-0009】01_行事鈔/07b_卷中之三#10
【原文】與尼同船戒二十八。四緣：一是尼，二共期，三同乘上下，四入船，犯。律中，除直度，船師失濟上下水者，不犯。
【譯文】與尼同船戒二十八。具備四種緣成犯：一、對方是比丘尼；二、彼此約定同行；三、同乘一船逆流而上或順流而下；四、登入船中，便結犯。《四分律》中說：若是橫渡水流（直度），或是船夫操作失控偏離擺渡航道而隨順或逆向漂流者，皆不犯。
