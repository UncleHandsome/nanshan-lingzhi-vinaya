# 校閱材料　第1832檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1832-0001】03_業疏/17b_卷三之六#140
【原文】有人不立由法在僧
【譯文】有人不設立結界，認為是因為羯磨之法全在比丘僧中進行。

【1832-0002】03_業疏/17b_卷三之六#141
【原文】第三釋中初科彼謂尼不秉法故不須界
【譯文】在第三項解釋中，第一科是指彼人認為比丘尼不主持秉持羯磨，所以不需要結界。

【1832-0003】03_業疏/17b_卷三之六#142
【原文】今解：須界以法，是兩眾所持，既行僧事，義無自然。雖是僧作，尼開重結，諸律所聽，明有事故。如五百問：重結之不相叉者，恐出僧外，非成同法
【譯文】我們如今的解釋是：必須結界，因為戒法是由僧尼兩眾共同主持受持的，既然要舉行僧中法事，在理上絕無使用自然界的道理。雖是由大僧主持作法，但開許比丘尼重疊結界，各部律典之所以聽許，正明白顯示此處有特定法事之故。正如《五百問》所說：重疊結界而不使界相交叉者，是擔心走出僧界之外，並非意味著兩眾合為同一個羯磨法事。

【1832-0004】03_業疏/17b_卷三之六#143
【原文】次科初立理雖下引證諸律聽者即是善見及下五百問彼云僧尼重結得不得相叉謂界相須等準非同法雖叉無害
【譯文】下一科首先確立義理。自「雖是僧作」以下引用證據，「諸律所聽」即是指《善見論》以及下文的《五百問》。彼處說僧尼重疊結界是可以的，但不可相互交叉，是指界相必須相等；但依理而論兩者並非同一個法事，縱使交叉也並無妨害。

【1832-0006】03_業疏/17b_卷三之六#145
【原文】然行事者紛紜意言謹依五分彼十比丘尼將本法者至大僧中在前相對與受戒也
【譯文】然而如今辦事者議論紛紜、憑空揣測。我們應當謹依《五分律》：那十位比丘尼帶著受過本法的戒子來到大僧之中，在前方相對而立，為其授戒。

【原文】第四詣僧法中初通斥謹下示儀五分明文反前臆度
【譯文】在第四項前往大僧受戒之法中：起初普遍斥責混亂做法；自「謹依」以下指示如法儀軌，《五分律》有明確經文，正可破斥前面的主觀臆測。

【1832-0008】03_業疏/17b_卷三之六#147
【原文】今時行者，僧尼單列，各面相對，本法在中。然據外相，不無議涉，縱容取中，義亦通成。當僧在上位，前後叢坐；尼眾在下，還聚一處，使尼教師引本法者，從僧次禮，然後在僧戒師前，如文乞等
【譯文】現今的行事者，讓比丘僧與比丘尼單排排列，各自面對面相對而立，受本法戒子置於中間。然而依外在儀態來看，不免招致非議譏嫌；若稍作變通折衷取其妥當，在義理上也是可以通達辦成的。應當讓僧眾坐在上位，前後聚集而坐；尼眾位居下座，同樣聚在一處。讓尼教師引導受本法戒子，依序向僧眾頂禮，然後來到僧中戒師座前，依照儀文乞求受戒等。

【1832-0009】03_業疏/17b_卷三之六#148
【原文】次科：初出異，然下立法。僧尼相對，尊卑抗敵，故生譏毀。然於禮乞對受，事有不便，縱容取中，是今裁度，中猶當也。二眾同行，上下叢坐，一位有倫序，二行事順便
【譯文】第二科：起初指出不當的異樣做法；自「然據」以下確立如法制度。僧尼面對面相對，尊卑分寸如同對等抗衡，因此會引發譏嫌毀謗。而且對於禮拜、乞戒與面對面受戒而言，事理上也極為不便。寬容折衷以取其中道，是如今的斟酌裁定，「中」也就是妥當之意。二眾一同行事，上下分坐而聚集安坐，第一具有倫理尊卑次序，第二辦理事法順暢便利。

【1832-0011】03_業疏/17b_卷三之六#150
【原文】問：本法尼已聞白四，得聞餘法不？答：已聞應開，但是未具，至於僧中所有加結，不預僧例。若得在者，用僧何為？要由僧作，方成尼具，故知異也。正作結界，須自然外，後加白法，一一召入
【譯文】問：受過本法的比丘尼已經聽聞了白四羯磨，可以聽聞其他羯磨法嗎？ 答：既然已經聽聞白四，原則上應當開許，只是她尚未具足大戒；至於僧中所進行的一切附加羯磨結界等法，不得列入僧眾同法之列（不可計入僧數）。如果容許她在場同等參與，那還要大僧作什麼？必須經由僧眾作法，方能成就比丘尼的具足戒，所以可知是不同的。在正式作法結界時，必須讓她退到自然界外；其後附加白四羯磨時，再一一召集入內。

【1832-0012】03_業疏/17b_卷三之六#151
【原文】第五，初問中：餘法謂尼結界，本法尼得同聞否？答中：初明不合，已聞應開是縱，未具不預，即奪僧中加結，謂往僧寺尼結界時。若下二簡異，謂若許在眾同法，則即是大尼，何勞僧受耶？正下三示制度，謂結界時，令本法尼出六十三步外等
【譯文】第五項，在起初的提問中：「餘法」是指尼眾結界，受本法尼能否一同聽聞？ 解答中：起初說明不合體制；「已聞應開」是寬容縱許之說，「未具不預」是實質奪其資格，所謂僧中附加結界，是指前往大僧寺院尼眾自行結界之時。 自「若得在者」以下，第二辨明差異，意思是如果允許她在大眾中同預法事，那她就是大尼了，又何勞前往僧中受戒呢？ 自「正作結界」以下，第三指示具體制度，是指結界之時，令受本法尼退出六十三步之外等。

【1832-0013】03_業疏/17b_卷三之六#152
【原文】若爾，未預僧法，全是無戒，在內何妨？今解：此尼不同下眾，全未得法，故須消息，中間人也。故律中明名本法者，為比丘尼相濫具戒，然未預僧法，何名具也
【譯文】若按這樣說，她既然未曾參與僧法，完全等於沒有戒體，留在界內又有何妨？ 我們如今的解釋是：這位尼眾不同於下位小眾（沙彌尼等）之完全未得戒法，所以必須審量詳斷，她是處於兩者之間的「中間人」。因此律中明確將受本法者稱為「比丘尼」，外相上彷彿已具大戒；然而尚未參與僧中之法，又豈能稱為具足呢？

【1832-0014】03_業疏/17b_卷三之六#153
【原文】次難中，既無具戒，義同小眾，體不足數，何妨在界？今下釋通，初定名：消息猶言詳度也，中間人者，非大小所攝故。故下示義，初明非小，名字去呼；然下次顯非大
【譯文】在第二次問難中：既然未得具足戒，在義理上等同於小眾，其身分不足以計入僧數，留在界內又有何妨？ 自「今解」以下解釋通達，起初確定名位：「消息」猶如說詳審度量，「中間人」是因為既不為大眾所攝、也不為小眾所攝。 自「故律中」以下闡明義理：起初說明並非小眾，因已用比丘尼之名相去稱呼；自「然未預」以下，其次顯明尚未成大尼。

【1832-0015】03_業疏/17b_卷三之六#154
【原文】如僧史說求那䟦摩傳中，尼戒大僧中生。假令不作本法，直從僧受，亦成，但犯罪耳。律無正斷，而是所通，以事證知，故知僧中大須立法，方發彼戒。若不能結界，二眾不滿，中容非別，眾用界分；若不約之，雖來無用，受定難剋。寧可本法不成，事通得不必；若僧法有缺，定判虗行一世，又須誡哉
【譯文】如同佛教僧史所記載的求那跋摩傳中所說，比丘尼戒乃是在大僧之中產生的。假使未曾在尼部作本法，直接向僧中受戒，戒體亦得成就，只是有犯戒之罪而已。律藏中雖無明確判定，但在義理上是通得過的，以史實可以證知；由此可知在大僧之中極需確立如法軌則，才能引發彼人的具足戒體。若不能如法結界，二部僧眾人數不滿額，或者二眾之中容有非數不足、僧尼別眾之相，僧眾的法事功用完全取決於界域劃分；如果不在此加以約束規範，即使前來也是徒勞無益，受戒必定難以成辦。寧可尼中本法未成——在事理上尚且通得過，但到底得不得戒呢？倘若大僧之法存在缺陷，則定然判定其虛度修行一輩子，這又必須深加戒惕啊！
