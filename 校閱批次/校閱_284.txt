# 校閱材料　第284檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【284-0001】03_業疏/20a_卷四之三#103
【原文】「有三安居」者，《增三》具明前、中、後也。據時定分，初、後一日，中間安居二十九日。就犍度中，但明前後各住三月，則無中也。故舍利弗欲於佛所安居，十七日至，制後安居。據相以言，但前一日，餘三十日為後安居，莫不望初俱名後故，則缺中也。
【譯文】所謂「有三種安居」，《四分律·增一法》（增三）中詳細說明了前安居、中安居、後安居。按照時間劃分，前安居與後安居各占一天，中安居則有二十九天。就律部〈安居犍度〉而言，僅僅說明了前安居與後安居各自安居三個月，就沒有中安居了。所以舍利弗想要在佛陀處所安居，十七日才到達，佛陀便制定他結後安居。就相狀而言，只有第一天為前安居，其餘三十天都屬於後安居，無非都是相對於初日而統稱為「後」，所以就沒有列出中安居了。

【284-0002】03_業疏/20a_卷四之三#104

【譯文】在第二科解釋緣起的文句中，第一段又分為二：第一、根據《四分律·增一法》（增三）闡明三種安居；「就」字以下，其次依準〈安居犍度〉提出兩種安居之法，引用律文開許緣由，把中安居稱為後安居，只是名稱不同而已。

【284-0003】03_業疏/20a_卷四之三#105
【原文】文引《十誦》制五眾者，如彼文云「誰應安居？謂五眾也」。《四分》尼三時遊行戒中，尼提僧及三眾俱吉羅也。緣發在尼，體是女弱，無宜遊散，故重；餘分有缺，故輕也。《五分》持律有五種，安居時依廣誦者乃至沙彌，不依者吉。
【譯文】疏文引用《十誦律》說制定五眾皆須安居，正如該律文說「誰應當安居？就是五眾」。《四分律》比丘尼三時遊行戒中，比丘尼違犯得波逸提罪，比丘僧以及其餘三眾違犯都得突吉羅罪。因為制定緣由發起於比丘尼，比丘尼體質柔弱，不適宜在外遊蕩散漫，所以制罪較重；其餘各眾在違緣方面有所欠缺，所以制罪較輕。《五分律》中說持律者有五種，安居時必須依止能廣誦律典者，乃至沙彌也是如此，若不依止則得突吉羅罪。

【284-0004】03_業疏/20a_卷四之三#106
【原文】次科，初引《十誦》，次會本宗。制通五眾，戒制三時，則知春冬無緣遊涉亦制。「緣發」等者，示重輕意。「餘分缺」者，即指四眾情非重故。後引《五分》持律五種，即五律師，下文自引。「廣誦」者，即第五律師。沙彌須依，驗知五眾竝須坐夏
【譯文】在第二科中，首先引用《十誦律》，其次會通本宗《四分律》。既然制令通於五眾，戒條制止三時遊行，便可知春冬兩季若無特殊因緣而隨意遊歷跋涉也是被制止的。「緣發」等句，是開示制罪輕重的用意。「餘分缺」，是指比丘等其餘四眾的情狀不如比丘尼嚴重。「後引」以下，引用《五分律》的五種持律者，就是指五種律師，下文自會引用。「廣誦者」，就是第五種律師。連沙彌都必須依止，由此驗知五眾都必須安居坐夏。

【284-0005】03_業疏/20a_卷四之三#107

【譯文】《律二十二明了論》中記載有五種因緣能使夏安居成就：第一、處所有遮蓋覆蔽；第二、在夏初十六日，該論疏說「前安居與後安居各自到了十六日這一天」；第三、若是東方現出紅霞（明相出），該論疏說「十五日夜分已盡，東方泛紅，便進入十六日；若東方尚未泛紅，則仍屬於十五日，還不是結夏的時候。如果十五日就結夏，這還是春季的最後一天，不能稱為結夏」，這就破斥了《十誦律》的講習者主張必須在十五日趕入界內的說法，該論律文至為明朗決斷；第四、在別住處所中生起安居之心，論疏說「別住是指布薩界」，安居之心有三種：一是為了自修自利，二是為了利益他人，三是為了料理三寶之事、修繕整治僧房舍宅，一隻腳踩入界內生起前述之心，即告成就安居；第五、沒有五種過失，正如論疏正文所載。

【284-0007】03_業疏/20a_卷四之三#109
【原文】初過者，待形須濟，事籍資緣，遠覔妨業也。二者，城市猥雜，出道清修，性相違反也。三者，蚊蟻物命，惱害者多，或唼形骸，不能思擇也。四者，人須良友，全梵行基，雖竝號善，未必相副，故須簡練。又須具五：隨問無滯，一也；隨說生信，二也；隨疑決之，三也；問答無疑，四也；辯同見正，離諸邪執，五也。又以身非匏瓜，繫而不食，前須藥食交濟，旦夕無此，則不可結也

【284-0008】03_業疏/20a_卷四之三#110

【譯文】第三是父母與大臣緣：《四分律》中，父母與大臣二人無論具信或不信，都聽許前往。其餘普通俗人，能生福、具信樂者聽許前往；若是不信者，比丘若有能力使其回心轉意，亦應前往。《十誦律》中關於父母之事，無論有無派遣使者信差皆可前往。或者有外道召請比丘前去說：「我要祭祀摩醯首羅天神等。」比丘不敢前往，佛陀聽許前往彼處，是為了使彼生起清淨善心的緣故；乃至途中聽聞已故則須折返。

【284-0101】03_業疏/20b_卷四之三#56
【原文】三中，《四分》二人父母、大臣各有信與不信。尊親不可違，官力能損益，故不信亦聽。「力能返心」，謂有道德能迴邪見。《十誦》父母通開，可決不簡不信；外道召往，可決不信亦開。摩醯首羅即大自在天，中梵所事。「為清淨」者，即發彼善心
【譯文】第三緣中，《四分律》所指父母與大臣二人各有具信與不信的分別。尊親不可違逆，官府權勢能產生損益，所以不信者亦聽許前往。「力能返心」，是指具有道德修為而能迴轉其邪見。《十誦律》中對父母普遍開許，可決斷為不論信與不信；外道召請亦聽許前往，可決斷為不信者亦予開許。摩醯首羅即是大自在天，為中天竺所敬奉之神。「為清淨」，就是啟發彼等的善心。

【284-0102】03_業疏/20b_卷四之三#57
【原文】四者為求衣鉢病藥者：若自病重，不堪受日，即是命難，直去亦得，如不得隨意食等。若知他病無人瞻視，不問召喚，聽受日往；及為覔藥食，隨方遠近，皆得行也
【譯文】第四是為尋求衣鉢及醫藥病人：若是自己病情嚴重，不堪忍受作受日法，這便屬於命難，直接出界亦可，如同不得隨意食等情況。若是得知他人患病無人照料看護，不論有無召喚，皆聽許受日前往；以及為彼尋覓醫藥飲食，隨其所在之遠近，都可以前往。

【284-0103】03_業疏/20b_卷四之三#58
【原文】四中，初明已病，雖容直去，要須受日。不任眾食，許其別索，名隨意食，不得開去。「若」下次明看病，不召聽往，急於濟苦
【譯文】第四緣中，首先說明自身患病，雖然容許直接出界，但若尚能為之仍須受日。若不耐僧團常食，准許其另外求取，稱為「隨意食」；若求之不得，則開許離界。自「若知他病」以下，接著說明看護病患，未受召請亦聽許前往，這是由於救濟疾苦事甚緊迫之故。

【284-0104】03_業疏/20b_卷四之三#59
【原文】五為和僧護法事者：律中顯緣，未明受日。必有和限，依受聽去；無限隨事，可準《僧祇》；或重破僧，即以事去
【譯文】第五是為了和合僧眾與護持正法之事：律中顯明此項因緣，卻未言明受日之法。若有一定能和合的期限，應依限受日而聽許前往；若無確定期限而隨事情發展，則可比照《僧祇律》；或者若是事關重大的破僧事件，便直接因急事而前往。

【284-0105】03_業疏/20b_卷四之三#60
【原文】五中，初示律文，但令破去。「必」下義決。初約無限釋，有須依受，無準《僧祇》事訖羯磨。「或」下次約事重釋
【譯文】第五緣中，首先指明律文只令破夏前往。自「必有和限」以下依義理決斷：首先就無限期來解釋，有期限須依限受日，無期限則準照《僧祇律》待事畢再作羯磨。自「或重破僧」以下，接著就情事重大者來解釋。

【284-0106】03_業疏/20b_卷四之三#61
【原文】四分》緣中十八不同：十四是檀越，餘者佛法僧事也
【譯文】《四分律》因緣中有十八種不同：十四種是施主檀越請召，其餘則是佛法僧三寶之事。
