# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【378-0001】02_戒疏/20a_卷四下之二#96
【原文】【疏】捉寶戒八十二。
【譯文】【疏文】捉持珍寶戒，為第八十二條。

【378-0002】02_戒疏/20a_卷四下之二#97
【原文】【疏】寶物利重，人多貪附，沙門高世，事絕貪貯。「三十」戒中，直畜已結，況復身觸，誠非道儀，故但執捉，便結墮罪。今此比丘不思聖制，輒捉遺寶，反被誣謗，清濁莫分，故約此緣而制斯戒。
【譯文】【疏文】寶物具有極重利益，人們大多生起貪心攀附，沙門的志向超塵絕俗，理應斷絕貪念儲蓄之事。「三十捨墮」戒之中，光是蓄積儲存金銀就已結罪，何況是以身體親手觸碰，這實在非修道者應有的威儀，因此只要親手執捉，便結犯墮罪。現在這比丘沒有深思聖者的戒規，擅自撿拾他人遺落的珍寶，反而遭受誣陷誹謗，清白與污名無從分辯，所以依循這個緣由而制定了這條戒律。

【378-0003】02_戒疏/20a_卷四下之二#98
【原文】【記】八十二，制意中。初敘財寶過，直畜尚結，況更手捉。「今」下，次明執捉過。「捉遺被誣」者，據本緣起。
【譯文】【記文】第八十二條，制戒意圖之中。首先敘述錢財珍寶的過患，光是蓄存就已結罪，何況親手執捉。「現在」以下，接著說明執持抓取的過失。「拾遺反被誣陷」，是依據原始的制戒緣起。

【378-0004】02_戒疏/20a_卷四下之二#99
【原文】【疏】古師相傳，以緣起為所犯。今約戒本，諸部明解，但捉即犯，何論拾遺。故初列戒本，捉寶則犯。但除兩緣，下開収拾塔具，都無別開之相。如何乃云「捉寶犯吉，遺者提」乎？廣如《鈔》中《隨相》所列，明白如鏡，不蒙昧也。
【譯文】【疏文】古代律師代代相傳，都把緣起故事中的「拾取遺落之物」當作犯戒的具體行相。現在依據戒本文句以及諸部律典的明確解釋，只要動手拿取珍寶就構成犯戒，哪裡還需要論及是否為拾取遺失之物。所以戒本一開頭便列出，抓取寶物就犯戒。戒文中僅僅除去了兩種特殊情境，下文又開許收拾佛塔的供具，除此以外完全沒有另外開許的情形。怎麼可以說「平時捉寶犯吉，遺落者犯提」呢？詳情如同《事鈔》中《隨戒釋相》所列，清清楚楚如同明鏡，絲毫不容混淆蒙蔽。

【378-0005】02_戒疏/20a_卷四下之二#100
【原文】【記】斥非中。初引非。彼據「緣起」，捉但犯吉，拾遺方提。「今」下，正斥。初判犯。「故」下，引示。初示戒本。「除兩緣」，即伽藍、宿處。「下開塔具」，即不犯中。除此三緣，餘無別文開捉，那云捉但吉耶？「廣」下，指《事鈔》。彼據諸部，文相明顯，故云「明白」等。彼引《多論》「若捉金薄、金像，若捉他寶，自說淨寶，皆墮」，又引《僧祇》「知佛僧事人，有寶不得自取，乃至金銀塔像，使淨人捉」等，並非拾遺犯也。
【譯文】【記文】斥責錯誤見解之中。首先引述錯誤的看法。他們依據「緣起故事」，認為平時拿寶物只犯突吉羅罪，拾取遺落的寶物才結波逸提罪。「現在」以下，予以嚴正斥責。首先判定犯相。「所以」以下，引證說明。先指出戒本文句。「除去兩種情境」，就是指寺院伽藍之內與出外寄宿之處。「下文開許塔具」，是指不犯條文中的規定。除了這三種特殊情境之外，其餘並沒有任何文字開許可以拿取寶物，怎麼能說平時捉寶只犯突吉羅呢？「廣如」以下，指示參閱《行事鈔》。該書依據各部律典，文句行相極為明顯，所以說「明白」等等。書中引用《薩婆多論》說「如果執捉金箔、金像，或者執捉他人寶物，縱然自己表明只是保管淨化寶物，全都犯墮罪」，又引用《僧祇律》說「管理佛僧事務的人，見到寶物不得自己動手拿取，乃至於金銀佛塔佛像，也必須讓淨人代為執持」等，這些全都不是因為拾取遺落之物才結犯的。

【原文】鄙謂庸惡，末謂卑下；輒為領袖，故參眾首。眉謂尤眉，壽即高臘；反相欺壓，故在下行。武力，謂恃勢陵物之者。文華，謂世俗文筆之流。上四句，敘坐次乖道；下二句，明推舉同俗。彼時尚爾，況今衰末，不足怪矣。如下，結歎生起。提引者，即指當篇明誡者，乃彰垂訓。次科，分章中。
【譯文】「鄙」是指庸碌惡劣，「末」是指地位卑下；這類人往往擅自充當領袖，因而擠入大眾首位。「眉」是指尨眉（花白長眉的老人），「壽」是指戒臘深厚的前輩；反而遭到這輩人的欺凌壓迫，所以只能位居下座。所謂「武力」，是指依仗權勢欺凌外物的人；所謂「文華」，則是指鑽研世俗浮華筆墨的文士。上面四句，是敘述座位次序背離了道法；下面兩句，則是說明舉薦推崇的風氣全同世俗。當時的情形尚且如此，何況到了如今這衰頹末世，就更不足為奇了。「如」字以下，是結尾感嘆並引起後文。所謂「提引」，就是指在本篇中加以提點引導；所謂「明誡」，則是彰顯佛陀所垂示的訓誡。在下一個科判「分章」之中。

【378-0019】資持記/15b_下三#3

【譯文】標明「如題」的意思，就是指本篇的主題乃隨法附錄。在「制立意旨（制意）」中，第一段引用《大智度論》，首先開示真實的境地。這是因為佛的應化肉身，正是法身所依憑的器物。如同後文所說，引用事緣來作為證明：佛陀升到忉利天為母親說法，即將從天宮降回人間時，大眾都爭相前去迎接；此時須菩提正在石室中安住於空三昧，心裡思惟著：佛陀常說「如果有人能用智慧之眼觀察佛的法身，才算最先見到佛」；思惟完畢後，他就安坐在石室裡不動；這時蓮華色比丘尼想要搶先見佛；

【378-0020】01_行事鈔/11a_卷下之三#27
【原文】初中，《智論》云：諸佛不以生身為禮敬也；若見法身，是名供養。如佛從忉利天下，須菩提在石窟中觀無常空故，為先見佛；蓮華色尼寶階先禮，佛不受之。所以相敬者，為除慢法故。《四分》中：由諸比丘不知大小故，佛訶責已，告言：汝謂誰應受第一座，第一水，第一食，乃至起迎逆禮拜，恭敬問訊耶？諸比丘言各不定，或云十二頭陀者，大姓、多聞、法師、持律、禪師等。佛言：汝等各各長慢，故作是語。廣說三鳥獸相恭敬法。便說偈言：「其敬長老者，是人能護法，現世有名譽，將來生善道。」教化人民，皆隨法訓。汝等於我法律中出家，更相恭敬，佛法可得流布。自今已去，聽隨長幼，恭敬禮拜上座，迎逆問訊。《大悲》云：佛過去時，若見三寶、舍利、塔像、師僧、父母、兄弟、姊妹、耆年、善友、外道、諸仙、沙門、婆羅門等，無不傾側，謙下禮敬；以是報故，成佛已來，山林人畜見佛行時，無不傾側，低頭禮拜。《增一》云：無恭敬心於佛者，當生龍蛇中；以過去從中來，今猶無敬、多睡等。《雜含》云：告諸比丘，若見四眾，攝持諸根，長夜安樂等。《智論》云：外道是他法，故輕佛，來至佛所自坐；白衣如客，故命坐；一切出家五眾，身心屬佛，故立；若得道羅漢，如舍利弗等，皆坐；三道以下，並不聽坐，以所作未辦，結賊未破故。又云：釋迦牟尼佛，無別菩薩僧故，文殊師利、彌勒等，入聲聞僧中，次第而坐云云。
【譯文】在第一項中，《大智度論》說：諸佛並不以血肉之生身為禮敬的對象；唯有徹見法身，才稱得上是真正的供養。就像當年佛陀從忉利天降下人間，須菩提在石窟中觀照無常空性，因此成了最先見到佛陀法身的人；而蓮華色比丘尼搶先在寶階旁禮拜佛陀生身，佛陀卻未加肯定。之所以制定相互禮敬，是為了破除我慢煩惱的緣故。《四分律》中記載：因為諸位比丘不懂得戒臘大小尊卑的次序，佛陀斥責之後，問道：「你們認為誰應當受用第一席座、第一盞洗手漱口水、第一份飲食，乃至誰應受起身迎接、頂禮拜伏、恭敬問訊呢？」諸比丘各說各話，有的說是行十二頭陀行者，有的說是名門望族大姓出身者、多聞者、法師、持律師或禪師等。佛陀說：「你們每個人都滋長傲慢心，才會說出這些話。」佛陀隨後廣說鷓鴣、猴子與大象三隻動物互相推讓恭敬的因緣故事，並說偈言道：「其敬長老者，是人能護法，現世有名譽，將來生善道。」佛陀訓勉化導世人，皆應依循正法戒規。你們在我的正法與戒律之中出家，更應互相恭敬，正法才能廣泛流通傳播。從今以後，准許依照出家戒臘長幼之序，恭敬禮拜上座，起立迎接、致意問訊。《大悲經》說：佛陀在過去生修行時，若是遇見三寶、舍利、塔廟形像、師僧、父母、兄弟、姊妹、耆宿尊長、良朋善友，乃至外道、諸仙、沙門、婆羅門等，無不俯身側立、謙遜卑下地予以禮敬；以此善業果報，自從成佛以來，山林草木乃至世人牲畜見到佛陀走過時，無不俯身傾側、低頭恭敬禮拜。《增一阿含經》說：對佛陀毫無恭敬心的人，來世將轉生於龍蛇之類畜生中；這是因為他過去生原本就是從龍蛇投生而來，習氣未除，今日依舊毫無敬意且貪愛多睡等。《雜阿含經》中：佛陀告誡諸位比丘，如果見到出家在家四眾弟子，應當攝受收斂六根根門，如此能在漫漫長夜（生死輪迴）中獲致安隱快樂等。《大智度論》說：外道修習的是異端之法，所以輕視佛陀，來到佛陀處所就自顧自坐下；在家白衣如同訪客，所以佛陀招呼其就坐；所有出家五眾，身心皆歸屬於佛陀，所以應當侍立；若是證道的大阿羅漢，如舍利弗尊者等人，都可以就坐；三果（阿那含）以下的聖賢及凡夫僧，一概不准就坐，因為所作尚未成辦、煩惱盜賊尚未除盡的緣故。該論又說：釋迦牟尼佛的教法中沒有另外獨立劃分的菩薩僧團，因此文殊師利菩薩、彌勒菩薩等，都編入聲聞僧團之中，依照戒臘次序而坐，等等。
