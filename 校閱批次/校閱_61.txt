# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【61-0013】02_戒疏/02c_卷一上之二#91
【原文】【疏】何名「略教」？以佛初成道，將開化法。創起希仰，寄心無地。故先示行法，令依奉行。不待犯戒，未有罪故，不得懷疑起謗。略陳教法，故曰「略教」。
【譯文】【疏文】什麼叫做「略教」？因為佛陀最初成就聖道時，即將開展教化眾生的法度。弟子們初初生起仰慕向道之心，心念尚且沒有依託歸向之處。所以佛陀先開示修行的通則法度，讓大家依循奉持推行。這不需要等待有人犯戒，因為當時還沒有任何罪愆產生，也就不會對教法生起懷疑毀謗。只是簡略地陳述法度大綱，所以稱作「略教」。

【61-0017】01_行事鈔/07d_卷中之三#24
【原文】兜羅貯床褥戒八十五。五緣：一是兜羅綿，二貯床褥，三為己，四自作使人，五成便犯。《五分》：隨坐結墮，要先棄後悔。
【譯文】兜羅貯床褥戒八十五。構成犯戒有五種因緣：一、填塞物是兜羅綿（細軟的柳絮木棉等珍貴軟茸）；二、填塞填充成床墊或坐褥；三、是為了自己受用；四、親自製作或指使他人製作；五、製作完成便結犯墮罪。《五分律》說：每次坐臥都結犯墮罪，必須先把其中的兜羅綿拆除棄置之後，才能依法懺悔。

【原文】枝必隨本，從本為言。又下，轉釋。恐謂開迷何有根本；然雖迷忘，不結正罪，何妨造境得名作犯。次難中。若兼止犯，可如前言；下品初句，既無枝條，理須除去。答中。指如前者，即上相從根本之義；下云相從造事，亦得說九是也。次解中。前文二局，一單約本迷，二定須九句；
【譯文】枝條罪必定跟隨根本罪，這是順從根本罪的角度來說的。在「又下」這段，是轉進一步的解釋。唯恐有人以為開許了迷惘哪裡還會有根本罪；然而雖然因為迷失遺忘而不結算正罪，但這不妨礙造作境界本身仍可稱之為「作犯」。在第二道問難中說：如果兼顧了止犯，或許可以如同前面所說那樣；但是下品的第一句既然沒有枝條罪，理應必須除掉。解答中，指出「如同前面所說」，就是指前面所論隨從根本罪的道理；下文所說「隨從造作事件，也能說是九句」，也就是這個意思。在第二種解釋中，前面的文意有兩處局限：一是單純就原初即迷立論，二是限定必須是九句；

【61-0020】資持記/11c_中四上#21
【原文】此解反上，一兼通轉想，二作句不定。文分為二，初敘可學者。此中正意，料簡後九；欲彰兩位定不定別，故先示之。不可學中，三位分別；初約本迷轉想，對明六九。若下，次單就本迷後心，明六九。若據律文，後心無罪；今取心緣罪境，義結吉羅。若兼下，三就後心無罪，明八九。結告中。
【譯文】這種解釋正好與上面相反：一是兼能通達轉移想念，二是造句並不固定。文句分為兩部分，首先敘述可學的範疇。這裡的核心意趣，是要料簡後面的九句；想要彰顯這兩個位階在固定與不固定之間的差別，所以先作開示。在不可學的範疇中，分三個層次來辨別：首先是就原初即迷與轉移想念，對照闡明「六句與九句」。從「若下」這段，其次單就原初即迷的後念之心，來闡明「六句或九句」。如果根據律文，後念之心是沒有罪的；現在取心念攀緣犯罪境界的意思，在義理上結為吉羅罪。從「若兼下」這段，第三是就後念之心無罪的立場，闡明「八句或九句」。在總結與告誡中。

【61-0024】02_戒疏/02c_卷一上之二#93
【原文】【疏】言「廣教」者。由略名含，未曉前相，雖造諸非，不謂有犯。故須廣張網目，收攝罪聚。鈍根之流，聞便得解。因廣說故，名為「廣教」。
【譯文】【疏文】所謂的「廣教」。是由於簡略的名稱含意較為籠統，鈍根之人無法明瞭具體的造惡行相，縱使造作了各種非理的行為，也往往不認為自己是在犯戒。所以佛陀必須廣泛鋪展如同網目般細密的條文，用篇聚條目來收攝罪相。那些根機愚鈍的人，聽聞了詳細條文之後便能徹底明白。因為是廣泛詳盡宣說的緣故，所以稱作「廣教」。
