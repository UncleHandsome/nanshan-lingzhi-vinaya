# 校閱材料　第1245檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1245-0001】資持記/11e_中四上#6
【原文】三自他中，初通示三例：一自造他境，二他造自境，三自造自境。二別配四戒：婬戒，三句皆重；盜戒，初例重，餘二無罪；殺戒，初二例有無可解；自殺自犯俞蘭；造語，上二，易會；自誑，義準犯吉，非言說軌儀故。《四分》身口，通約四戒，前三身犯，後一口犯；別約互造，婬局身造，後三竝通互造。
【譯文】第三說明「自身與他人」（自他）的範疇中，起初普遍指示三種常規：第一是自己向他人的境緣造業，第二是他人向自己的境緣造業，第三是自己向自己的境緣造業。第二項個別配對四條重戒：淫戒在這三種情況下都犯重罪；盜戒只有在第一種情況犯重罪，其餘兩種都沒有罪；殺戒的前兩種情況有無罪責容易理解，自殺則是自己犯偷蘭遮罪；造妄語戒，前兩種情況容易體會理解，若是自己欺騙自己，依義理推準應當犯吉羅罪，因為這不合乎言語對外說明的常軌原則。《四分律》中談及身業與口業，整體而言是就四條戒來論，前三條戒由身業造犯，最後一條由口業造犯；若個別就互為造作而言，淫戒局限於身業造作，後面三條戒則都通於身口互為造作。

【1245-0002】資持記/11e_中四上#7
【原文】五教人自成，即是兩業；隨戒不同，故云各分。初明教人：婬戒，自作成重；教他，樂在前人，不得同犯。〔教人作者犯蘭，不作犯吉。〕盜殺，自作教人，損境暢思，彼我俱重。妄戒，教人，名利壅彼，故不同犯。次明遣人：教則利己義疎，遣則向己義親；
【譯文】第五說明「教唆他人與親自完成」（教人自成），這本是兩種不同的業行；隨著各條戒律性質不同，所以說各自有所劃分。首先說明教唆他人：淫戒如果親自造作就構成重罪；若是教唆他人，淫樂是在對方身上，教唆者不能同犯重罪。〔教唆他人去行淫，若對方做了，教者犯偷蘭遮罪；若對方沒做，教者犯吉羅罪。〕盜戒與殺戒，無論是親自造作或教唆他人，都損害了受害境緣並滿足了犯戒意圖，被教者與教唆者同樣犯重罪。妄語戒如果教唆他人，名聲與利益都壅塞歸於對方，因此教唆者不同犯重罪。接著說明派遣他人：教唆他人則為自己謀利的關係較疏遠，派遣他人則利益歸向自己的關係較親近；

【1245-0003】資持記/11e_中四上#8
【原文】如遣人婬己，遣人說聖，皆重；盜殺無遣，故非所論。多人通使，亦即教人，婬無此義。言多人者，謂重使及展轉使；重使者，謂隨續使人，乃至百千；展轉使者，謂所遣人不得自去，復轉使人乃至眾多也。文出殺戒，義必通三；成遣彼作，故云緣別；彼我齊犯，是業同。〔有將口讚坑陷等釋之，非也。
【譯文】例如派遣他人來與自己行淫，或是派遣他人去宣說自己證得聖果，派遣者都犯重罪；盜戒與殺戒並沒有這種反向指向自己的派遣，所以不在這裡討論。多人輾轉派遣使者，本質也是屬於教唆他人，淫戒則沒有這種形式。所謂「多人」，是指接連派遣以及輾轉派遣；「接連派遣」是指連續不斷指派使者，乃至多達成百上千人；「輾轉派遣」是指受派遣的人無法親自前去，又再輾轉指派他人，乃至牽涉許多人。這段文字雖然出自殺戒，義理必定通於三戒（盜、殺、妄）；因為構成了派遣他人去造作，所以說因緣各別；受遣者與派遣者同樣獲罪，這是因為業性相同。〔有人用口頭稱讚、挖掘坑洞陷害等例子來解釋這段，是不正確的。〕

【1245-0004】資持記/11e_中四上#9
【原文】上且略舉數名，非謂已盡。若彼疏文，義章極廣；如上引釋，略通名相；必欲窮盡，積學猶迷；故不繁引，順鈔意也。結顯中，初二句示上眾名。鈔下，顯今略意。易識為令解教，即行為令成行。難知希用，對翻可知。四分律行事鈔資持記卷中四上
【譯文】上面只是大略列舉幾項名相，並非指已經窮盡無遺。若是參照那部《戒疏》的文句，義理篇章極為廣博深遠；如上面所引用的解釋，只是粗略通達基本名相；若一定要徹底窮究完畢，即便長年累積學問的人也依然會感到困惑；所以此處不再繁複引證，以順應《行事鈔》簡明扼要的原意。在「總結顯明」（結顯）中，前兩句指示上述的各種名相。從「鈔」字以下，顯明現今採取簡略的用意。讓人容易理解是為了使人通達教理，讓人能付諸實踐是為了促使修行圓滿。難以理解與罕見少用的部分，反過來對照推知便能明白。《四分律行事鈔資持記》卷中第四之上結束。

【1245-0005】資持記/12a_中四下#1
【原文】四分律行事鈔資持記中四下16 釋懺六聚法篇(中四下)釋懺六聚法篇懺是能懺之心，六聚即所懺之罪，法謂懺之軌度。梵云懺摩，此翻悔往；有言懺悔，梵華雙舉。準《業疏》云：取其義意謂不造新；懺謂止斷未來非，悔謂恥心於往犯；有將懺字訓首訓鑒，義雖通得，華梵須分。
【譯文】四分律行事鈔資持記中卷四之下第十六、解釋懺六聚法篇(中卷四之下)解釋懺六聚法篇。「懺」是指能夠發起懺悔的自心，「六聚」就是所要懺悔的罪過類別，「法」則是指進行懺悔的軌則與制度。梵語稱為「懺摩」，中文翻譯為「悔往」（追悔過往所犯）；有人稱作「懺悔」，這是梵文與華語並舉的稱呼。依據《業疏》所說：取其義理內涵是指不再造作新過；「懺」是指止息並斷除未來的過非，「悔」是指對過去所犯懷抱羞恥慚愧之心；雖有人將「懺」字訓詁為陳首（自首陳白）或鑒察，義理上雖然說得通，但梵華語源仍必須加以區分。

【1245-0006】資持記/12a_中四下#2
【原文】然懺通化制及以理事，今此且據制教事行以為篇目。敘來意中，初科為二，初敘懺意，上句明造業。且約篇聚所制二犯之罪；結業成因，必招來果，故如種焉。次句明須懺。以犯從妄起，罪假緣生；妄體本空，緣生無性；了知妄本，則犯相何依！識達緣生，則罪根叵得。是以忽追所犯，深恨前非；
【譯文】然而懺悔通於化教與制教，也兼具理懺與事懺，如今本篇姑且依據制教的事相行持來立為篇目。在敘述開展此篇的意圖中，第一科分為兩部分：首先敘述懺悔的意旨，上一句說明造業。此處姑且就篇聚戒相所制定的「由作而犯」與「由止而犯」這二種罪行而言；造業凝聚成因，必定會招感未來的苦果，所以如同播下種子一般。下一句說明必須懺悔。因為犯戒是從妄念生起，罪過是憑藉因緣而生；妄念的本體本來是空寂的，因緣所生之法也沒有固定不變的自性；既然徹底明瞭妄念的根本為空，那麼所犯之罪相又要依託何處！如實照見因緣生法無有自性，罪業的根源便不可尋得。因此忽然追悔所犯之過，深深痛恨先前的非行；

【1245-0007】資持記/12a_中四下#3
【原文】仰對勝緣，盡披肝膽。罪從心起，還逐心亡；既伏現因，不牽後果。犯而不悔，業苦何窮。有智識非，義無隱覆故也。則下二句彰益。上句自行無瑕，下句眾法有用。故下，引勸；前引論文勸速改，初引論；不下，申勸。彼論問曰：何法重於地？何法高於空？何法多於草？何法疾於風？
【譯文】恭敬仰對殊勝的境界與對象，毫無保留地剖露肺腑、徹底發露。罪業是從心念生起，自當還隨著自心止息而消亡；既然伏斷了現前的惡因，便不再牽引未來的苦果。如果犯了戒卻不求懺悔，所感召的業苦何時才能窮盡。有智慧的人認清了過非，在義理上本就毫無隱蔽覆藏的道理。接續下來的兩句彰顯懺悔的利益。上一句說明自身行持清淨無瑕，下一句說明在僧團各項羯磨作法中皆具備合格資格。因此在下文引據加以勸導；前半段引用論典之文勸勉應當迅速改過，先引論典；自「不」字以下，申述勸誡。那部論典問道：什麼法比大地更重？什麼法比虛空更高？什麼法比草木更多？什麼法比疾風更快？

【1245-0008】資持記/12a_中四下#4
【原文】答曰：戒德重於地，我慢高於空，煩惱多於草，心念疾於風。今略引後句以明昔心造惡，今忽追悔，剎那翻善，不待終日。意令有犯速須求懺。次引經文彰佛勸。經明如來訶責示惡之意，欲令行者有過尋悔。上訶毀禁，令成止行；下說惡道，令成作行。斥古中，初示非。
【譯文】回答說：戒德比大地更重，我慢比虛空更高，煩惱比草木更多，心念比疾風更快。如今大略引用最後一句，用以說明往昔之心造作了惡業，現今一旦追悔，剎那間便能翻轉為善念，用不著等待整日。用意在於令有犯戒者必須儘速求懺悔。接著引用經典之文彰顯佛陀的勸勉。經文中說明如來呵責並開示惡行之意圖，是想令修行人有了過失隨即悔改。前半段呵斥毀犯戒禁，是為了促成止持之行；後半段宣說墮入惡道之苦，是為了促成作持之行。在斥責古師說法中，首先指出其謬誤。
