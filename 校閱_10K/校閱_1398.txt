# 校閱材料　第1398檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第二立相者若依此律界相不定若東方有山稱山有壍艸𧂐汪水糞聚釘杙空地等竝得作相然空相一種結竟即須題記令後來尼識知界相行法者無疑見論云界形有五一方二圓三鼓形四半月五三角義云若先無相隨前所列者立之亦得今時結者多是空地四方城邑隨相唱之然須識過後便得唱結謂前學未達後學未明若唱方相須容舛錯如從牆外唱云從東南角至西南角乃至一周訖寺南門外便成別眾以唱界從牆基直過門限外便成界內儻寺中閉戶作羯磨門限外有人不喚盡集豈非別眾若從牆內唱復有破夏離衣之過以界隨牆內起今既傍牆直唱門限內地便成界外寺中作法有人說欲至門限內須有所作又來入界豈非別眾若破夏離衣者有人在界安居明相未出至限邊未還之頃明相已出便是界外豈非破夏離衣既知不易不得籠通直唱儻有斯謬令他一生虗過。
【譯文】第二步驟、確立標界物標記：依照本部律的規定，界的標記並沒有固定模式。如果在東方有山，就指稱以山為標記；若有壕溝、草叢、水窪、糞堆、木樁、空地等，全都可以作為標記物。然而如果使用空地作為標記，結界完畢之後，就必須立刻樹立文字題記牌，好讓後來的比丘尼清楚辨認僧界範圍，讓如法行事的人心中沒有疑惑。《善見律》說：僧界的形狀有五種：第一是方形，第二是圓形，第三是腰鼓形，第四是半月形，第五是三角形。義理上分析：如果先前本來沒有現成的地標，依照前面所列舉的標記去隨宜樹立，也是可以的。現今時代結界，大多是在空地、四方形的市鎮城邑中，隨順其地形標相來唱名宣示結界。然而，必須事先明瞭可能產生的過失，然後才能唱相結界；這是因為以前的修學者尚未透徹通達，後來的修學者又未曾明瞭。如果唱誦方形的界相，往往極易產生差錯：比如從圍牆外唱誦說「從東南角到西南角，乃至圍繞一周完畢」，那麼寺院南門之外就會形成孤立的別眾。因為如果唱界是從牆基直接筆直穿過，門檻外就會被劃在界內，萬一寺院內部關起門來舉行羯磨作法，而門檻外面有人卻沒有招呼集合過來，豈不就造成了非法別眾的過失嗎？如果改從圍牆內側唱界，又會產生破壞夏安居和離衣宿夜的過失；因為界限順著牆內升起，現在既然順著圍牆筆直唱誦，門檻之內的地面反而變成了界外。寺院內部作羯磨時，有人陳說委託欲意後，走到門檻以內因有事需要處理，又再次跨入界內，豈不也成了別眾嗎？若談到破夏和離衣：有人在僧界內安居，天剛破曉黎明尚未破曉時，走到門檻邊界而尚未返回之際，天光已然大亮黎明破曉，人既然身處界外，豈不是犯了破壞安居和脫離僧衣的過失嗎？既然知道結界如此不容易，就絕不能含混籠統地直接唱誦；萬一產生了這種差錯，將會使別人一生之中的修法都虛度而無效。

【1398-0010】04_比丘尼鈔/01a_卷上之上#31
【原文】大姉僧聽。此住處比丘尼。唱四方大界相。僧今於此四方相內結大界。同一住處。同一說戒。誰諸大姉忍。僧今於此四方相內結大界。同一住處。同一說者默然。誰不忍者說。僧已忍。於此四方相內。同一住處。同一說戒。結大界竟。僧忍默然故。是事如是持。
【譯文】「各位大姊僧眾請聽清！這處住處的比丘尼，已經宣唱了四方大界的標相。僧眾現在就在這四方標相範圍之內結立大界，成為同一個住處，共同舉行半月說戒。有哪些大姊同意？僧眾現在要在這四方標相之內結立大界，同一個住處，共同說戒。同意的人請保持沉默；誰若不同意，請立刻提出！僧眾大眾都已同意，在這四方標相之內，同一個住處，共同說戒，結大界完畢。正因為僧眾默然贊同，這件事就這樣堅定受持。」
