# 校閱材料　第206檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【206-0001】02_戒疏/09c_卷二下之二#55
【原文】【記】次科，為三。初標示。由是時之別相，故云「異名」。「僧祇」下，次引釋。「瞬」，謂目一開合也。「羅預」，亦是西梵時名，未詳所釋。「日極長」者，且舉夏至。「夜長日短」，即謂冬至，晝則十二，夜則十八，故云「反上」。春秋二分，則晝夜半分焉。「此」下，三、明二土不同。《漏刻經》，梁朝出之，明置漏刻之法。「不問」下，冬至日四十刻夜六十刻，夏至反之，春秋二分亦各等半。「箭在水」者，刻漏制云：「箭長四尺五寸，分四面，每面三時二十五刻，四面共成百刻。其箭在水壺中，壺上安木蓮華。作木人，高七寸，跪坐花心，兩手捧盤。壺中浮箭，自盤心涌出，以驗時刻之數。水漏下一刻，箭上涌一刻。每箭上壺二十五刻，一度放水，故四度而成晝夜。」、「未」下，顯略。「遑」，及也。「時節學」者，謂知時刻，別是一家之學，非可於此具論。
【譯文】【記文】下一科分為三段。首先標出名相。因為這是時間的不同劃分相狀，所以稱為「異名」。從「僧祇」以下，接著引文解釋。「瞬」是指眼睛一張一合的時間。「羅預」也是天竺的時間名詞，詳細意義尚不清楚。「日極長」是暫且舉出夏至。「夜長日短」就是指冬至，白天十二須臾，夜晚十八須臾，所以說「反之即可知」。春秋分則是晝夜各半。從「此」字以下，第三、說明中印兩國的不同。《漏刻經》是梁代翻譯出來的，說明設置滴漏計時的方法。從「不問」以下，冬至白天四十刻夜晚六十刻，夏至則相反，春秋分也是各佔一半。「箭在水」的意思，滴漏儀軌規定：「浮箭長四尺五寸，分為四面，每面分屬三個時辰、刻有二十五刻，四面合起來共是一百刻。那支浮箭放在水壺中，壺上安置木雕蓮花。做一個木人高七寸，跪坐在花心，雙手捧著盤子。壺中的浮箭從木人手中盤心湧出，以此檢驗時刻的數值。水漏下一刻，浮箭就上升一刻。每當浮箭上升二十五刻，就放水一次，所以四次放水就剛好構成一個晝夜。」從「未」字以下，說明省略的原因。「遑」是顧及。「時節學」是指推算時刻的專門學問，本是獨立的一家學問，無法在這裡全面討論。

【206-0002】02_戒疏/09c_卷二下之二#56

【206-0011】02_戒疏/09c_卷二下之二#65
【原文】【記】問意，躡上二罪，可解。答中。初釋不往犯輕。文明二吉，由此篇犯相，故心雙結：一者應懺，二則非儀。今「傳情欲」，即是應懺也。「所以」下，次明往即結重。指「如上」者，謂作意欲往即吉，受語即下品蘭，還報未及又中品蘭，同上次第三方便矣。文中承前一吉，故云「兩蘭」。
【譯文】【記文】問話的意圖，是緊扣上面兩種罪名而來，很容易理解。答覆當中，首先解釋不前往為何結罪較輕。經文闡明犯了兩個吉羅罪，是由於本篇戒律的罪相，因此起心時雙重結罪：第一是應當懺悔的性罪，第二是違背僧儀的遮罪。現在「傳達情欲」，就是指應當懺悔的過失。從「所以」以下，接著說明前往說合就結犯重罪。指稱「如上」的意思，是指動念想要前往就結犯吉羅，剛接受委託就結犯下品偷蘭遮，前往說合而尚未回報時又結犯中品偷蘭遮，這與前面依序排列的三種方便罪完全相同。文中承接前面的一個吉羅，所以說「兩個偷蘭遮」。

【206-0013】02_戒疏/09c_卷二下之二#67
【原文】【疏】語既三時重輕，下四例此可悉。若「使」及「書」，言中自了，「指印、現相」，必假言通。故《僧祇》云：「作相者，當知『見我著垢衣、持空鉢、坐卑牀、說賤語』者，不得也。反上吉相。得與不得，還報者殘。」
【譯文】【疏文】言語做媒既然在三個時期各有輕重，下面其餘四種方式依此類推便可以完全通達。如果是「遣使」與「寄信」，文辭言語中本來就能表達清楚；而「手印信物」與「做出形相暗示」，則必定要借助言語來溝通。所以《僧祇律》說：「做出暗示信物的，應當說『見到我穿著髒衣服、拿著空鉢、坐在低矮的床上、說卑賤粗俗的話』，就是事情沒辦成。反過來則是吉利的吉相。無論成與不成，只要回去回報情況的比丘，都犯僧殘罪。」

【206-0030】02_戒疏/09c_卷二下之二#84
【原文】【記】次意中三。初雙徵事法。「然」下，二、正明制意。初敘少欲順教。「今」下，明違法多過。上二句，總標，「一」下，別列。五中，前三過量過，後二不乞過。前中，初過，多事長業，則反正行。第二，多貪增惑，則反少欲。第三，多乞惱他，則反自滅法。「二趣」者，如戒緣中人、非人也。四中，不乞處分，眾法不行，故礙僧事。第五，若在難處，則有命、梵二難。「自損」即命難，「違慈」即梵難。「以」下，通結。
【譯文】【記文】在第二個制戒用意中分為三段。首先雙重質詢建造的事相與法則。從「然」字以下，第二、正式說明制戒用意。首先敘述少欲知足順應聖教。從「今」字以下，說明違背戒律將產生諸多過患。上面兩句是總括標出，從「一」字以下逐一列出。五種過失中，前三種是建造過量所致，後二種是未經僧團審查處分所致。在前三種中，第一種過失是雜事太多滋長世俗業累，違背了正行。第二種是貪念太多增長煩惱惑業，違背了少欲。第三種是過度乞求惱亂他人，反而自我毀滅正法。「二趣」是指戒律緣起當中所說的世人與非人鬼神。在第四種過失中，不向僧團請求審查處分，僧團法事無法如法推行，所以妨礙了僧務。第五種，如果在險難之處造房，就會帶來生命與梵行二種危難。「自損」就是威脅生命，「違慈」就是障礙梵行。從「以」字以下，全面總結。

【206-0031】02_戒疏/09c_卷二下之二#85
【原文】【疏】問：「四依須行，不行不制，四開有違，制輕重者？」
【譯文】【疏文】問：「出家四依的苦行本該奉行，若不實行佛陀卻未制定罪過；四種開許的法規有所違犯，為何反而制定輕重的罪名呢？」
