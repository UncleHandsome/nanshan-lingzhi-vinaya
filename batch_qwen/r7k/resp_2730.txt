整體看，這批譯文方向正確、語句通順，對「略說戒—別法—指忘」的科判层次也掌握得住。問題主要集中在三類：**律學專名被意譯淡化**、**少量增譯超出原文**、**一處義理（露過便滅）需謹慎**。以下逐則列出，並標示輕重。

## 一、逐則檢討

### 【2730-0001】#32

| 等級 | 問題 | 建議 |
|---|---|---|
| ★需修正 | 「餘唱常聞」譯成『此法大眾常聞』 | 律中略說戒有定格唱詞：**「餘者僧常聞」**。建議照錄原句再加註（未誦部分以此語代替），不宜自造意譯句。 |
| ★需修正 | 「三語」譯成「互道三語清淨布薩」 | 「三語布薩」是三人對首布薩的作法名稱，非「互相說三句話」。建議保留「**三語布薩**」＋註（三人對首、各說清淨）。 |
| ○可斟酌 | 「出到結界之外」 | 「界外」指說戒界（大界）之外，「結界之外」易誤讀。建議「出（說戒）界外」，並可補一句說明：**上座出界，界內恰成三人得作對首，界外一人自成心念**。 |
| ★需修正 | 「當授一聰者既利」譯為「傳授給其中一位聰穎者使他熟練」 | 原意是**各人把自己會的那一篇，教給同一位聰利者，使他通利整部戒本**（如此即堪能說戒）。現譯未點出「各授一篇、合成全本」。另「既」疑為「令」之異文／訛字，宜出校。 |
| △小瑕 | 「如果全都不能流利背誦、不能完整說完戒本的人，應當……」 | 句式拗口。改：「若四人都不能流利背誦、無法誦完整部戒本，就應當……」 |
| △小瑕 | 「越毘尼罪」 | 可加註：即突吉羅（違越律制之輕罪）。 |

**譯對而值得保留者**：「四、三、二、一篇」譯為戒本分篇（由多至少），非四條戒，理解正確；「重誦／逆誦／合誦／有忘得補」與下一則疏釋完全對得上。

### 【2730-0002】#33

- **★需修正：「別法」**。這是律學專名，與「眾法」相對：四人以上僧法稱眾法，三人以下的**對首、心念**稱別法。此處正指上座心念、三人三語。譯成「別種作法」等於沒有譯。
 → 建議：「『舉』字以下第二是開許**別法（即心念、對首布薩）**」。
- ○「重誦，再說一篇」建議補為「（從頭）再誦整篇」，才能與「忘得補＝只覆誦所遺」形成對照。
- △校勘回報：底本「若下三開指忘重誦，再說一篇也」應斷為「**若下三、開指忘。重誦，再說一篇也**」。譯文理解正確，是底本標點可議。

### 【2730-0003】#34

- ★「當分人遣至餘寺誦之」→ 現譯「分派人員派遣到其他寺院」**動詞重複**。建議：「應當**分別派人到別的寺院（各學一段）** 去學誦」。
- ★「至時人謂一篇盡」的「**謂**」字未落實，疑為「誦」之訛，或作「（某人）所誦的一篇完了」解。建議校勘並加註，不要含混帶過。
- △「又接著隨後背誦接續」冗贅 → 「另一人接著往下誦」。

### 【2730-0004】#35

- ○此則是**釋文歸納**，不是律文原句。譯作「《四分律》是讓……」略有把釋文當律文之嫌。
 → 建議：「（釋曰）《四分律》的意思是：各人分學一段，遞相接續，共成一部戒本。」

### 【2730-0005】#36

- ★「俱是聖教」譯「**神聖的教令**」偏西式且語意浮泛；「聖制必依」譯「**聖人的定制**」在中文語境易聯想儒家聖人。此處「聖」皆指**佛**。
 → 「說戒與羯磨都是**佛陀所制的聖教**」「**佛制**必須遵依」。
- ★「餘法猶可」譯「尚且罷了」語氣偏離。「猶可」＝還勉強過得去。
 → 「其餘法事（讀文而作）還勉強可以；縱使法不成就，過失也較輕。」
- ○「故於聽說」有歧義：可讀為「說戒與聽戒」，亦可讀為律典慣語「（佛所）聽許之說戒」。現譯採前說可通，但建議加註存異，或譯「所以在（佛所）聽許的說戒法中，豈可執文而讀」。
- ○「如世言令」建議作「世間**君父的敕令**」，與下一則記文「君父垂誡」對應。

### 【2730-0006】#37

- ★「本通說戒，因兼羯磨」譯「本來是通於說戒」語意不明。
 → 「（不許執讀的）制意**本是就說戒而說，因而兼帶羯磨**」。
- △**牒文引號不一致**：記文作「深不可者」，譯文引號內寫成「深不可也」（那是疏文全句）。引號應與所牒底本字面一致。
- △「足為明例」→「足以作為**明確的例證**」比「顯著的例子」貼切。
- ○「文明羯磨說戒例然」建議：「疏文明就**羯磨**而言，**說戒比照亦同**」，層次更清楚（也才不會與前句「本通說戒」看似矛盾——前者說制意本起，後者說文面所指）。

### 【2730-0008】#39（本則問題最多）

1. **★「露過便滅」——義理須謹慎**。
 白懺是「**作白發露、待遇清淨眾再如法懺**」的權巧開緣；本段所舉正是受錢寶的**尼薩耆（捨墮）**，須捨財＋對首懺，並非一經發露罪即消滅。現譯「罪過一經發露便得消滅」容易誤導。
 → 建議：「按理應總作白發露，**發露之後（覆藏、障礙說戒之）過即除**」，並加註：此為時逼無清淨眾的開緣，事後仍須向清淨比丘如法懺。若判定疏主確指「滅罪」，也應出註說明其為開緣之說。
2. ★「無任應說」譯「**全界**已無合格之人可以登座說戒」——「全界」為增譯。
 → 「（眾中）已無**堪任說戒**之人」。
3. ○「如何識罪同時犯耶？」是**詰問何以可能**，非純定義性提問。
 → 「怎麼會有明知是罪、卻全眾同時犯的情況呢？」
4. ○「雖罪不責」→「雖是罪，卻（彼此）不加責舉／不以為非」；「往往」可刪。
5. △「所獲贓賄」→「所得的**不如法財物**」（「贓物」今義偏刑事，稍隔）。
6. △「合眾安坐」可略註：全眾安然共坐、默然納受。

### 【2730-0009】#40

- **★需修正：「釋通」譯成「通達解釋」**。「釋通」＝疏通解釋／通釋，非「通達」。
 → 「『世』字以下是**通釋**，又分兩層」。
- ★科判斷句：「二釋懺露識罪懺中，初文」宜作「**二、釋懺露。識罪懺中，初文……**」。

- △「過午非時」宜點明是**非時食**：「當今齋會中過午非時食、受取金錢捉持珍寶之類」。
- △「引證可知」→「（疏）引律為證，一看即知」。

- **★術語不一致**：「次第對懺」譯「**對面**懺悔」，#42 卻用「對首」。同一詞應統一作「**對首懺**」。

- ○「今開白者，義不同也」建議補出對照對象：「如今開許作白發露，是就時逼無法外懺而言，與律中（餘時作法）之義不同」。

### 【2730-0011】#42

- ★**因果未顯**。「合眾皆犯，一人懺淨，堪為對首」是說明「**餘時不許**」的理由：平時可令一人先懺淨，即堪作餘人對首之境，所以不必開白懺。現譯三句平列，讀者看不出論證。
 → 「『故』字以下簡別其餘時候不許：因為全眾雖皆犯，只要**先令一人懺淨，便堪作其餘人對首懺悔之境**（故不開白）。」
- △「須派一人**出外**」屬語境增譯，可保留，但以括號或註標示較穩。
- △「牒釋」建議作「**牒（律）文而解釋**」。

## 二、通則建議

1. **專名保留＋簡註，勿意譯淡化**：別法／眾法、三語布薩、心念布薩、對首、作白、白懺、僧常聞、尼薩耆（捨墮）、越毘尼（突吉羅）。目前失分最多的就是「別法」「三語」「常聞」三處。
2. **術語統一**：對首（勿作「對面」）、界／界外（勿作「結界之外」）、聖教／佛制（勿作「神聖教令」「聖人定制」）。
3. **增譯節制**：全界、出外、往往、登座、神聖……屬語境補足，建議以括號或註腳處理，不要混入正文。
4. **牒文引號須與底本字面一致**（深不可 ≠ 深不可也）。
5. **可回報的校勘／標點疑點**：#32「既利」（疑「令利」）、#33「若下三開指忘重誦」斷句、#34「人謂一篇盡」的「謂」字。
6. **義理把關**：#39「露過便滅」務必加註，避免讀者誤以為作白發露即可滅捨墮罪——這是整批譯文中唯一可能造成實質誤解的地方。

其餘如 #36 的問答語氣、#37 的科文对应、#41 的律制程序，譯得都相當到位，只需依上述微調即可。
