# 校閱材料　第604檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【604-0001】02_戒疏/11a_卷三上之二#17
【原文】【記】闕緣中。闕初緣，如以衣食與父母、病人，採華供三寶等，兩不成故；闕第二，如逆路求悔，不須諫故；闕第三，舉擯非法；闕第四，或不反謗；第五，諫不如法；六、中間捨悔，竝非正犯。
【譯文】【記文】欠缺條件中。欠缺第一項條件，例如將衣食供給父母、病人，或是採花供養三寶等，汙家與惡行兩者皆不成立；欠缺第二項條件，例如半途迎向僧團求哀悔過，便不需要勸諫；欠缺第三項條件，指舉發驅逐的程序不合法度；欠缺第四項條件，指對方並未反過來毀謗；欠缺第五項條件，指勸諫的作法不如法；第六項，若在勸諫過程中放棄執著並悔改，這些全都不屬於僧殘的正犯。

【604-0003】02_戒疏/11a_卷三上之二#19
【原文】【疏】就戒緣中，分四：初明汙家相；二、「比丘舉過」下，明擯出相；三、「當作法時」下，明起謗緣，此正戒之過非也；四、「以過白佛」下，明制戒也。科約此四，入於戒本，須明識之。不爾，誦持一亂也。
【譯文】【疏文】關於制戒的緣起，可分為四個部分：首先說明汙損良善家庭的具體情狀；其次，自「比丘舉過」以下，說明驅逐外出的處分情狀；第三，自「當作法時」以下，說明發起毀謗的緣由，這正是此戒所要規範的過非所在；第四，自「以過白佛」以下，說明制戒的始末。依照這四個科判段落納入戒本對照，必須清楚認識。否則，誦持戒相時便會混亂無章。

【604-0009】02_戒疏/11a_卷三上之二#25
【原文】【註】家者，有男有女。汙家者，有四種。一，依家汙家。一家得物，又與一家。所得物處聞之不喜，所與物處思當報恩，即作是言：「有與我者，我當報之；若不與我，我何故與？」二者，依利養汙家。如法得利，及鉢中餘，或與一居士，得者生念：「當報其恩。若不與我，我何故與？」三者，依親友汙家。若比丘依王、大臣，或為一居士，或不為一居士。便生念言：「其為我者，我當供養；不為我者，我不供養。」四者，依僧伽藍汙家。若比丘取僧華果與一居士，不與一居士。彼有得者思「當供養；若不與者，我不供養」也。
【譯文】【註文】所謂良善家庭（家），包括男子與女子。汙損家庭的情形共有四種：第一，依憑世俗人情而汙家。從某一戶人家獲得財物，轉手又送給另一戶人家。原本送出財物的施主聽聞此事心生不悅，而接受轉贈的家庭則心想應當報恩，於是便說：「只要有出家人給我好處，我就報答供養他；如果不出資給我，我又為何要供養他？」第二，依憑信施供養而汙家。依法托缽獲得利養，以及缽中所剩的飲食，有時送給某個居士，得到的人便動念：「我應當報答其恩德。若是不給我，我又為何供養他？」第三，依仗親屬朋友勢力而汙家。如果比丘依附國王、大臣的權勢，私下袒護某個居士，而不偏向另一個居士。受其關照者便動念說：「為我出力的人，我應當供養；不為我出力的人，我不供養。」第四，依仗僧團寺院財物而汙家。如果比丘私自拿僧眾的花果贈送給某位居士，而不給另一位居士。那位獲得好處的人便想「我應當供養他；如果拿不到，我就不供養」。

【604-0013】02_戒疏/11a_卷三上之二#29
【原文】【註】時有比丘，於彼止宿，著衣持鉢，入村乞食，法服齊整，行步庠序，低目直前，不左右顧視，以次行乞。居士見已，自相謂言：「此是何人？低目而行，既不顧視，亦不言笑，不相周接、善言問訊。我等不應與其飲食。不如阿濕婆等，與人周接——及上所言——應與供養。」時彼乞食，困乃得之。往至佛所，問言：「住止樂不？僧和合不？不以飲食為苦耶？」彼具白佛。便遙訶責，令往設擯。
【譯文】【註文】當時有如法守戒的比丘，在該地投宿留止，整齊穿戴袈裟並持缽，走入村落乞食，戒衣整肅齊整，步伐安詳莊重，垂眼正視前方，不隨意左顧右盼，依照門戶次序行乞。居士們見到後，私下彼此議論說：「此是何人？低垂著眼睛走路，既不左右看人，也不言談微笑，更不與大家酬酢應對、以好話問候慰勉。我們不該拿飲食供養他。還不如阿濕婆等人，與人熱情往來——就像上面說的種種討好舉止——我們才該給予供養。」當時那位如法乞食的比丘，受盡冷落艱難才勉強乞得食物。回去見到佛陀，佛陀問他：「住在那裡安樂嗎？僧團和睦團結嗎？不致於為了飲食而受苦吧？」該比丘便詳細向佛陀稟告。佛陀隨即在遠方嚴厲斥責，並派人前往執行驅逐羯磨。

【604-0014】02_戒疏/11a_卷三上之二#30
【原文】【疏】二、「依聚落」下，諫所諫事也，就中分三：初明依聚落造過；二、「諸比丘語言」下，至「不須住此」，正明牒過治擯；三、「是比丘」下至「不驅者」，明非理謗僧，此正所為事也。
【譯文】【疏文】第二部分，從「依聚落」以下，是勸諫所針對的具體事項，此中分為三段：首先說明依傍村落製造過失；第二段自「諸比丘語言」以下到「不須住此」為止，是正式說明揭發過犯並施以驅逐處分；第三段自「是比丘」以下到「不驅者」為止，說明犯僧無端毀謗僧團，這正是引發此戒所要處罰的核心事件。
