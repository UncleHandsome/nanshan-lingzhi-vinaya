# 校閱材料　第659檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【659-0001】03_業疏/15a_卷三之四#14
【原文】總結中初科初點文。「依」下釋注。「依文」即《善見》與本律。一年中春夏冬三時，一時有四白四黑月，一月有十五日。一日量影分中前後，謂於日中立竿，中前受者，以影長為先，影短為後；中後反之。或以尺量，或論脚步。「食時」即中時也。「有前後發」謂發戒也。「如是例」者，且舉量影，自餘取時可例此也。指「念法」者，即〈雜法篇
【譯文】在總結之中，第一科首先點出文句。「依」字以下解釋注文。「依文」是指《善見論》與本部《四分律》。一年之中分為春、夏、冬三季，每一季有四個白月、四個黑月，每個月有十五天。一天之內測量日影以分出日中之前與日中之後，也就是在正午立竿，正午前受戒的，以影子較長的為先、較短的為後；正午後受戒的則恰恰相反。有的用尺來量，有的用腳步來計量。「食時」就是指日正當中的時候。「有前後發」是指發起戒體的先後。「如是例」的意思，是暫且以量日影為例，其餘記錄時間的方法都可比照此例。文中所指的「念法」，就是指〈雜法篇〉。

【659-0002】03_業疏/15a_卷三之四#15
【原文】問：具戒發時在何言下
【譯文】問：具足戒體發起的時候，究竟是在哪一句話之下？

【659-0003】03_業疏/15a_卷三之四#16
【原文】答：如《智論》云「羯磨竟得」，又云「與汝受戒竟得」。有人解云「是事如是持」者是竟也。如《心論》中「第三羯磨剎那頃，作及無作是根本業」。律師以為「第三說字是得戒也
【譯文】答：如同《大智度論》所說「羯磨究竟之時得戒」，又說「說到『與汝受戒竟』時得戒」。有人解釋說，說到「是事如是持」時才算究竟圓滿。如同《阿毘曇心論》中所說「第三度羯磨念完的那一剎那間，作戒與無作戒就是根本業」。有律師則認為「說完第三度羯磨的最後一個字時就是得戒之時」。

【659-0004】03_業疏/15a_卷三之四#17
【原文】初問答中初科，前引《智論》，論出兩解，人取後義，如下。後引《雜心》，根本業即受體也。「律師」者，論家自指
【譯文】在第一番問答的第一科中，前面引述《大智度論》，論中提出了兩種解釋，古人多採取後一種義理，如下文所述。後面引述《雜阿毘曇心論》，所謂「根本業」就是指所受的戒體。「律師」一詞，是論主自己的稱呼。

【659-0005】03_業疏/15a_卷三之四#18
【原文】今以此解比前二度，似是竟處；引後通收，則未竟也。故第三中「不忍者說」，尋有人訶，便不成就。既命令說，依命而說，可成前也。故眾既默，明有所許，故通收云「僧已忍與受戒竟」，故至此前名為戒法，理同《智論》受戒竟也，如上卷中
【譯文】如今若拿這個解釋來對比前兩次羯磨，似乎這裡就是終結處；但若引出後面總結之語來通徹收攏，則此處尚未完結。因為在第三次羯磨說到「不忍者說」時，隨即若有人出言反對斥責，羯磨便不能成就。羯磨師既然命令有異議者說出來，若有人依照命令說出反對意見，豈能成就前面的法事呢？。所以僧眾既然保持沉默，就表明已經認可准許，所以總結收束說「僧已忍與受戒竟」，因此直到說完這句話之前都稱為戒法作法，其義理正同於《大智度論》所說的「受戒竟」，如同上卷中所闡明的。

【659-0006】03_業疏/15a_卷三之四#19

【譯文】在次一科中，首先列舉前後文句作總括提示。「前二度」是指第一度、第二度羯磨，「後通收」是指最後的總結文。「故」字以下作分別解釋。首先解釋三說之時法事尚未究竟完結，「命」就是宣召呼命。「故眾」以下其次解釋到了總結收束之時才算究竟圓滿，這正是《大智度論》的第一種義理，在結界篇中已經指示過，所以在此再次指明。

【659-0007】03_業疏/15a_卷三之四#20
【原文】問：羯磨竟得，通三性不
【譯文】問：羯磨作法圓滿之際得戒，在受戒者的心態上通於善、惡、無記三性嗎？

【659-0008】03_業疏/15a_卷三之四#21
【原文】答：《多論》云一切皆得。故《十誦》、《伽論》云：「知時犯，不知時清淨」者，如犯殘懺，聞出罪白後，睡不覺羯磨竟者是也。準此以通，前聞白已，後睡得戒
【譯文】答：《薩婆多論》說善、惡、無記一切心都能得戒。因此《十誦律》、《摩得勒伽論》說：「知時犯，不知時清淨」，這好比犯了僧殘罪進行懺悔，聽聞出罪的白文之後，便睡著而沒有察覺羯磨何時念完，這種情況依然算清淨出罪。依照這個道理來融通，受戒者先前聽聞了白文之後，隨後即使睡著也能得戒。

【659-0009】03_業疏/15a_卷三之四#22
【原文】次問答立義中初科，初引答。「一切得」者，通三性也。「故」下次舉例。「知時」即不善有記，「不知時」即無記。下舉悔殘顯示上義。「準」下三準決。既聞白已，知僧為秉，領納心決，故判得戒
【譯文】在次一番問答立義的第一科中，首先引文回答。「一切得」的意思，就是通於三性。「故」字以下其次舉出事例。「知時」就是指不善的有記心，「不知時」就是指無記心。下文舉出懺悔僧殘罪的例子來顯示上述義理。「準」字以下第三為準則判定。受戒者既然已經聽聞白文，知道僧團正為自己秉法，納受戒體的心念已然決定，所以判定能夠得戒。

【659-0010】03_業疏/15a_卷三之四#23
【原文】若爾，既睡雖作不聞，今俱不作，何妨感戒？答：前雖無記，白是和本；後作教圓，緣非乖相，故不作不成
【譯文】如果這樣的話，既然睡著了即使僧眾作法他也聽不見，那麼現在僧眾都不作法，又有何妨礙於感發戒體？答：受戒者後面雖然處於無記睡眠狀態，但前面的單白是僧眾和合的根本；後面宣讀羯磨教法圓滿，因緣並沒有相違違悖，所以僧眾如果不作法是絕不能成就的。

【659-0012】03_業疏/15a_卷三之四#25
【原文】有人言：戒是善本，善心相續，思心暢滿；若初善後惡，皆不發戒，以種類不續故。律云：與瞋恚、睡眠人不名受具。此豈始終惡、無記耶？中間暫起，即乖心思，何有成耶？如人起殺，臨到境所，心亂等生，前事不犯，戒亦同爾
【譯文】有人說：戒法是善法的根本，必須善心相續不斷，造作的心思通暢圓滿；如果起初是善心而後轉為惡心，都不能發起戒體，因為心念的種類不能相續的緣故。律中說：給處於瞋恚、睡眠中的人受戒，不能稱為得受具足戒。這難道是指他自始至終都處於惡或無記心嗎？中途暫時生起惡心或睡著，就違背了受戒的心念，怎麼能夠成就呢？好比有人生起殺心，將要走到所殺對象的處所時，忽然生起心亂等障礙，前面的殺業便不能構成犯罪，受戒也是同樣的道理。

【659-0013】03_業疏/15a_卷三之四#26
【原文】斥異中初科初立義。種類不續，三性相間故。「律」下引證，即受戒犍度文。彼約暫起，今取始終，如「下舉例」。「心亂生」者，或疑想心差，或癡狂失念。「戒同爾」者，比之可知
【譯文】在斥責異說的第一科中，首先建立其論點。所謂「種類不續」，是指善、惡、無記三性互相間隔之故。「律」字以下引律作證，即〈受戒犍度〉的律文。那段律文是就中途暫時生起而言，如今此處取的是通貫始終，如同「下文舉例」。「心亂生」，或者由於生起疑念想念偏差，或者由於癡狂喪失正念。「戒同爾」，拿它作比喻即可明了。

【659-0014】03_業疏/15a_卷三之四#27
【原文】解云：不同。受是緣成法，殺盜自造境。自造須作成，作成感無作，故前心異，作無有業也。受則不爾，自作在前，及論無作，假緣方感，已聞白竟，故是業起
【譯文】解釋說：這兩者並不相同。受戒是依憑外緣而成就的法，殺生與偷盜則是自己造作境業。自己造作必須作意行為成就，作相成就才能感得無作業體，所以前念心意如果發生變異，作相就無法構成業果。受戒則不是這樣，自己的作戒表業在聽白時已於前成就，至於論及無作戒體，則是假借僧眾等外緣才得以感發，既然先前已經聽聞白文完畢，所以戒業自然能夠生起。
