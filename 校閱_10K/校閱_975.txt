# 校閱材料　第975檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【975-0001】資持記/03b_上二#23
【原文】廢古中。言律無者，傳譯脫漏故。舊下，引古疏。指光師，曇諦本亦然。今下，點非。由前大界牃二同解，立場本非說恣，復非住處；所以前結不牃，後解何得稱之。疏中又出他師用三小解，破云三小無相，一席作法，如何類之。今準下，顯正。準難事者，即小界也。若爾，與他師何異；
【譯文】廢除古說的段落中，所謂「律文沒有記載」，是因為翻譯傳承時脫落遺漏的緣故。從「舊」字以下引用古疏，指的是光律師，曇諦法師的傳本也是如此。從「今」字以下指出其謬誤；因為前面大界解界文稱牒了二同（同一住處、同一說戒）來作解，而當初設立戒場本來就不是為了說戒與自恣，更不是為了長久居住；所以當初結戒場時並未稱牒二同，後來解界時又怎能稱牒呢。疏文中又提到其他法師引用「三種小界」的解法，破斥說：三種小界原本就沒有固定的界標界相，只是在一席坐處作法，如何能夠拿來相比附呢？從「今準」以下顯發正理；所謂「依據有難之事」，指的就是小界；若如此說，這與其他法師又有何不同呢？

【975-0002】資持記/03b_上二#24
【原文】彼用解法之文，今準相翻之義，故不同也。雜相中，初引《善見》，前明非僧住處。剔，他歷反，解也。壞，音怪，毀也。外下，明立場處。如祭壇者，亦如宮觀醮壇。五下，證在露處。解三小中。言同前者，亦事希也。今略出之，文云：今有爾許比丘集，解此處小界。三法起中。
【譯文】其他法師是直接引用解小界的經文，如今是依據「相反而對翻」的法理，所以兩者並不相同。雜項體相中，先引用《善見律毘婆沙》，前面說明戒場並非僧人常住之處。「剔」音為「他歷反」，是解除的意思；「壞」音為「怪」，是毀壞的意思。從「外」字以下說明設立戒場的地點。所謂「如同祭壇」，也就是如同道家宮觀所設的醮壇。從「五」字以下，證明戒場應當設在露天之處。在解三種小界中，所謂「如同前述」，也是因為這種情況非常罕見；如今略微列出，經文說：「如今有如此多比丘聚集，解除此處的小界。」在第三門法起所由中：

【975-0003】資持記/03b_上二#25
【原文】古有異說，準教詳定，故取前解。初師立理中，前明法起所以。作及無作，二法相待，安得有作而無無作耶！善行陰者，五陰攝法；此既造作，故屬行陰；行通三性，此屬善性；行即是心，心動成業，故疏云：然初結處，非心不起；地是依報，何得不從；隨心業力，有法依地等。此下，明遍處。非下，示法體。
【譯文】古德有不同的說法，如今依照教理詳細審定，因此採取前面的見解。第一位法師確立義理的內容中，先說明戒法生起的原因：有表作相與無表作相兩種法是相待而成的，哪有只有作法而沒有無作之法生起的道理呢！所謂「善行陰」，五陰含攝一切法；結界既然屬於造作，因此歸屬於行陰；行陰通於善、惡、無記三性，此處則屬於善性；行陰指的就是心念，心念一動便造作成業，所以疏文說：在當初結界之處，如果沒有心念則法不會生起；土地是眾生的依報，戒法豈能不隨心力而依附；隨著心念造作的業力，便有戒法依附於土地之上。從「此」字以下說明遍及的處所。從「非」字以下開示戒法的體性。

【975-0004】資持記/03b_上二#26
【原文】不與地連者，色及非色，記與無記，性不合故。非不相及者，界是色法，業依色起故。引證中，此引前後二段。前段又二，初至一界來，證上不與地連。以掘去本土，亦不失故；於上起屋，別加外物，亦同界故。言水際者，土輪下是金輪，金下水輪，水下風輪，風外即是虛空；
【譯文】戒法「不與土地相連」，是因為色法與非色法、有記與無記，體性無法真正相合；「並非互不相及」，是因為結界屬於色法，而業力必須依附於色法而生起。引證之中，共引用了前後兩段文字。前一段又分為兩部分，開頭直到「同一界」為止，是證明上面所說「不與土地相連」的道理；因為即便挖除原本的土壤，戒法也不會喪失；在上方建造房屋、額外加入其他外物，也屬於同一界之內。所謂水際，土輪之下是金輪，金輪之下是水輪，水輪之下是風輪，風輪之外即是廣大虛空；

【975-0005】資持記/03b_上二#27
【原文】法極金輪，故言水際，以界依堅處；水相浮蕩，非本期故。三重屋者且舉一相，多層亦然，彼文正作起三層樓，變其語耳。若下，證上非不相及，初是論文。以下，即鈔家釋意。上句示界體；標相限域，為眼所對故；互不相通，是障礙故；界具二義，故云色法。〔有將法字在下讀，反成破句。〕故下，次引後段。
【譯文】戒法極限達金輪底部（與水輪交際處），所以說水際，這是因為戒法必須依止在堅固之處；水性浮動蕩漾，原本就不是結界時所期望的範圍。所謂「三重房屋」，只是舉出一種具體形態，蓋很多層也是同樣的道理；律文原文正作「起三層樓」，此處只是換了一種說法而已。從「若」字以下，證明上面所說「並非互不相及」，前半段是論典的原文；從「以」字以下，則是《行事鈔》作者的解釋用意。上一句指出界的本體；設立標相以劃定界線範圍，是眼睛所能面對看見的；彼此互不相通，是具有隔閡障礙特性的；界域同時具備這兩種意義，所以稱為色法。〔有人將「法」字連到下一句讀，反而成了斷句錯誤。〕從「故」字以下，接續引用後一段文字；

【975-0006】資持記/03b_上二#28
【原文】亦明處毀法存，證成有法。水流字下，略知其處所一句；論本具之，則顯不知不可作法。準下，結證前義。次貶無法中分三，初出彼計。《業疏》引云：謂能作是情，所為非情，何有法起，誰領繫者，故知但是約界集處。
【譯文】這也是說明處所縱然毀壞而戒法依然存在，以此證成確實有界法存在。「水流」等字下方，省略了「知道該處所」這一句話；論典原文完整具備這句話，就顯明如果不清楚界處，便不能進行作法。從「準」字以下，結語證成前面的義理。其次貶斥「無有界法生起」之說，共分為三部分；首先列出對方的見解。《業疏》引用該說法道：能夠作法的是有情眾生，被結界的土地屬於無情物，哪裡會有戒法生起呢？又有誰來領受維繫呢？因此知道那只不過是劃定界限以便集合僧眾的處所而已。

【975-0007】資持記/03b_上二#29
【原文】仍引文據，如鈔所示，此即滅諍中五現前文，彼云：云何法現前，所持法滅諍者是；云何毘尼現前，所持毘尼滅諍者是；云何人現前，言議往返者是；云何僧現前，應來者來等是，界如鈔引。此下，點彼誤解。薩下，引文質非，《婆論》、《五分》。並明界功非人不惱，豈非有法。
【譯文】古師隨後引用律文依據，如同《行事鈔》所標示的，這即是滅除諍事章節中「五種現前」的經文；經文說：什麼是法現前？依照所受持的佛法來滅除諍事即是；什麼是毘尼現前？依照所受持的戒律來滅除諍事即是；什麼是人現前？雙方言論爭辯來往之人即是；什麼是僧現前？應當前來的僧人依律出席等即是；關於界現前則如《行事鈔》所引用的。從「此」字以下，指斥對方誤解了經文含意。從「薩」字以下，引用經論文字詰問對方的錯誤觀點，《薩婆多論》與《五分律》都說明結界的功效能使非人鬼神不敢擾害，若非有法存在又怎能如此？

【975-0008】資持記/03b_上二#30
【原文】前料簡中備引，故略指之。下引經證。文義益顯。如土臺者，謂無作業相，天眼所見；《壇經》云：結界之地，隨其限域，至金剛輪；雖經劫壞，終焉莫毀等。第四明非法中，初三句示重意。指前述者，下文隨示。謂下，列非相。初至結之，有三非，如前料簡問答已明。
【譯文】前面在分析辨別中已經詳細引用，所以此處僅略微指出。下文引用經典作證明，文句的義理更加鮮明。所謂「如同土臺」，是指天眼所能看見的無作業之相；《壇經》說：結界的地方，隨著它所劃定的界限，向下深達金剛輪；縱然歷經劫火壞滅，始終都不會被毀壞等等。第四項說明非法界中，前三句說明再次重提的用意。所謂「指陳前文所述」，下文隨即有所揭示。從「謂」字以下列出非法之相。開頭直到「結之」為止，包含三種非法，如同前面分析辨別的問答中已經說明。
