# 校閱材料　第1112檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1112-0001】資持記/07d_中一下#2
【原文】如人物中，無我所心，無守護，望主成犯。誡誥中，初牒前文。即《十誦》隨比丘用，《僧祇》供別房也。此下，明可否，初簡合用。言具戒者，成就自行也。應僧法者，堪入眾法也。若下，次明不合，反上二行。指前經證者，即《方等》、《大集》等經。又引傳者，即《高僧傳》；
【譯文】如同下文「盜人物」門中所說，地主心中雖無「我所有」之念，現場也無人守護，但盜取者對著地主仍構成犯罪。在誡誥文句中，起初提引前文。這也就是《十誦律》所說隨比丘所需使用，《僧祇律》所說供養特定僧房之意。接著「這」以下，辨明是否合乎原則，起初揀選適合使用的人。所謂「具足戒者」，是指能成就自身的戒行。所謂「能應對僧法者」，是指有資格參與大眾的羯磨作法。接著「如果」以下，其次說明不合資格之人，其情況與前述兩條修行標準相反。文中所指引的前面經文作證，就是《方等經》、《大集經》等。另外引用的傳記，就是《高僧傳》；

【1112-0002】資持記/07d_中一下#3
【原文】彼云：齊州靈巖寺，有僧暴死，見觀音舉一石函出，記眾僧罪藉；並為取僧樹葉柴薪等；此僧還活，具陳於眾。斯下，出所以。有下，伸誡。信法向道名有心，勵己攝修名行者。自隱者，令審己也；參取者，令詳教也。前引經律，緩急互見；量德全缺，隨依用之。當分互，釋中，初列三寶。
【譯文】傳記中記載：齊州靈巖寺有位僧人猝死，看見觀世音菩薩拿出一只石匣，裡面記錄著眾僧的罪過名冊；全都是私自取用僧團的樹葉、柴薪等物造成的；這位僧人甦醒還陽後，將所見詳細陳述給大眾。接著「這」以下，點出其中的原因。接著「有」以下，展開誡勉。信仰佛法、心向正道稱為「有心」，勉勵自我、攝心修持稱為「行者」。所謂「自我審察」，是為了讓大家審度自己的德行；所謂「參究取決」，是為了讓大家詳研戒律的教示。前面引用的經律，要求有寬有嚴、互有顯現；應當衡量自己的道德是圓滿還是欠缺，再隨之依循採用。「同分內部互用」（當分互）的解釋中，首先列出佛、法、僧三寶。

【1112-0003】資持記/07d_中一下#4
【原文】《大品》，即《般若經》。皆下，斷犯。理可通者，釋迦彌陀，並是果人；《般若》、《涅槃》，皆出正錄；房舍車乘，並常住常住故；違施心者，乖本願也。文中不出罪名；準下《善見》，迴供彼像；《十誦》，盜與餘寺，皆犯吉羅。律下，引證，初引迴僧物戒。
【譯文】《大品》，就是《大品般若經》。自「皆」字以下，判定罪名。在義理上可以通用的原因在於：釋迦牟尼佛與阿彌陀佛同為究竟果位的聖人；《般若經》與《涅槃經》都出自正統藏錄；僧房舍宅與車乘，同屬於常住常住物；而違背施主的心意，是因為違背了他最初的本願。鈔文中沒有明說罪名；但依準下文《善見論》移轉供養其他佛像，以及《十誦律》私自將僧物轉送其他寺院，都判定犯突吉羅罪。接著「律」字以下，引用證據，首先引出轉移僧物的戒條。

【1112-0004】資持記/07d_中一下#5
【原文】準律，犯吉。及下，引尼律。尼在露地說戒，居士施錢造堂；彼云：說戒隨處並得，今可迴作五衣；施主知已，譏嫌；佛制尼提，僧吉。二文並證違施心犯。佛法物中，初科，前明經像本末互。言俱違者，違情，即乖本施心；違理，即本末全別；顯其過重，須同下判。
【譯文】依照戒律，犯突吉羅罪。接著「以及」以下，引證比丘尼律。曾有比丘尼在露天處說戒，有居士布施錢財為其建造講堂；比丘尼卻說：說戒在任何地方都可以，現在可以把錢改作五衣；施主得知後便生起譏諷嫌棄；佛陀因此制定比丘尼犯波逸提，比丘則犯突吉羅。這兩段文句一同證明違背施主的心意即構成犯罪。在佛物與法物的篇章中，第一科先說明佛經佛像的本末互用。所謂「全都違背」，違背情理是指違背了最初的布施心意；違背法理是指根本與枝末全不相同；這顯現出其過失極為嚴重，必須等同下文來判罪。

【1112-0005】資持記/07d_中一下#6
【原文】本造下，次明經卷真偽互。文中二錄，通指藏錄；謂入此錄中經，皆真經也。因下，判犯。福下，示犯所以。次科。龕即是塔。有主，謂各有掌護；無主，謂無別主管。三中。言元通者，如人施財，擬造下殿，不定在佛；師即是佛，徒即菩薩弟子之類。牛馬等物，並非佛家所宜，故不通也。
【譯文】接著「原本建造」以下，其次說明經典真偽的互用。文中所指的兩種目錄，通指大藏經目錄；也就是錄入此目錄中的經典，都屬於真正的佛經。自「因」字以下，判定罪名。接著自「福」字以下，顯示構成犯罪的原因。下一科中，龕室也就是佛塔。所謂「有主」，是指各有專人掌管守護；所謂「無主」，是指沒有專職主管之人。第三點中，所謂「本來就相通」，例如有人布施財物，打算用來建造下殿，並不限定只用於佛陀；導師就是佛，門徒就是菩薩弟子之流。牛馬等牲畜都不是佛家所適宜擁有的，所以不能互通。

【1112-0006】資持記/07d_中一下#7
【原文】非義人者，除神王部從，餘不合者，皆名非義。五下，引證。初制罪者，謂別用也。除供養者，開元通也；引此，決上所宜用者，亦得作之。彼又問：佛物得作天人世人畜生像否？答：佛邊得作。僧物中，初科二段，初明互僧物；欲供下，次明互佛物；初中又二，前明迴互。
【譯文】所謂「不合理的人像」，是指除了神王眷屬部從之外，其餘不合規定的，都稱為不合理。接著「五」以下，引證律文。最初制定罪名，是指移作他用。所謂「供養除外」，是開許本來就相通的情況；引用這段文句，是為了決斷前面所說適宜使用之物，同樣可以製作。那部論又問：佛陀的財物可以用來製作天人、世人、畜生的像嗎？回答說：在佛陀身邊供奉的像就可以製作。在僧物之中，第一科包含兩段，起初說明僧物之間的互轉；接著「打算供養」以下，其次說明僧物轉作佛物；在起初一段中又分兩節，前面說明互轉之事。

【1112-0007】資持記/07d_中一下#8
【原文】擬施園果等者，謂施主施園果，所出財利，供僧四事；主者分食，此迴常住常住，為現前現前；而有盜心，故犯重罪也。次擬作僧房重物，即錢寶等；迴作僧食者，此迴常住常住，為十方常住；而不云盜心，或是僧食有闕，但不和僧輒用，故犯蘭也。若住下，次明開互。為護住處，和僧故開。初迴園果作食；
【譯文】所謂「打算布施園林果實等物」，是指施主布施園林果木，將出產的財利供養僧團四事需求；主管者私自分食，這是將「常住常住物」轉改為「現前現前物」；如果存有盜心，就會犯下極重的罪業。其次，打算作為建造僧房的重物，也就是金錢寶物等；若將其轉改為僧眾飲食，這是將「常住常住物」轉改為「十方常住物」；此處不說存有盜心，或許是因為僧眾伙食有所匱乏，只是未經僧眾集體羯磨和合就擅自挪用，所以犯偷蘭遮罪。接著「如果住處」以下，其次說明開許互換的情形。為了維護寺院住處，經僧團和合決議所以開許。最初是轉用園林果產作為伙食；

【1112-0008】資持記/07d_中一下#9
【原文】乃下，開貿現房作食；若下，明貿房治房；治賊下，明暫移糧食。互佛物中。結吉者，迴互彼此，違施心故。第下，指廣；卷軸既繁，不可撮錄，須者看之。次科，初引十伽。結吉，不作法故。次引祇律。通結，免出界故。雜用中，初科，引論三問，初明供給未度。彼云：白僧得，不白犯墮。
【譯文】接著「乃」以下，開許變賣現有房屋充作食物；接著「如果」以下，說明變賣房屋以修繕房屋；接著「防備盜賊」以下，說明暫時轉移糧食。在挪用作佛物的情況中，判定犯突吉羅，是因為彼此互調、違背了施主本心的緣故。接著「第」以下，指示詳情見於廣論；經卷典籍繁多，無法全數摘錄，有需要的人應當親自查閱。下一科中，起初引用《十誦伽論》。判定犯突吉羅，是因為未曾依法進行羯磨僧事。接著引證《僧祇律》。通融結為一界，是為了避免僧物出界之過。在雜物使用之中，第一科引用論典的三個問答，起初說明供給尚未受戒者。該論說：向僧眾報告宣告後可以給予，不報告宣告就給予則犯波逸提。
