# 校閱材料　第680檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【680-0001】02_戒疏/14c_卷三下之二#62
【原文】【律】若無人持，自持過三由旬，尼薩耆波逸提。
【譯文】【律文】如果無人代挑，自己攜帶超過三由旬的路程，犯尼薩耆波逸提。

【680-0002】02_戒疏/14c_卷三下之二#63
【原文】【註】比丘尼吉羅。不犯者：若持至三由旬；若減三由旬；有人，語持，中間不助；使尼四眾，齊三由旬；若擔毳𮖢、毳繩；若擔頭上毛；作帽、巾者，得。
【譯文】【註文】比丘尼犯此戒結突吉羅罪。不構成犯戒的情況包括：如果攜帶剛好到三由旬；或者少於三由旬；或者有人答應代挑，自己在中間絕不插手相助；役使比丘尼等四眾攜帶，正好達到三由旬而止；如果挑擔的是細羊毛裘、細絨繩；或者挑擔的是羊頭頂上的雜毛；用來準備做帽子、頭巾等物的少量毛料，這些均可開許。

【680-0003】02_戒疏/14c_卷三下之二#64
【原文】【疏】戒本五句：一、犯人；二、「道路行」下，立法，注解，文相可知；三、「若無人」下，明戒業也；下二，可知。
【譯文】【疏文】戒本條文共有五句：第一句、犯戒的人身；第二句、「道路行」以下，屬於開立的法度，戒本注文已有解釋，文理相狀容易理解；第三句、「若無人」以下，說明具體構成戒罪的造作行為；最末兩句，文意容易理解。

【680-0004】02_戒疏/14c_卷三下之二#65
【原文】【記】戒本中，初科。第二句指「注解」者。注中，初明得取自持限滿。「若有人」下，次明倩他續持。「若令」下，三、明使餘眾持。「除」下，四、明諸輕物。
【譯文】【記文】戒本之中，第一科。第二句之所以指稱看「注解」，是因為在注文中，起初說明了得以收取並由自己攜帶的最大路程限度。「如果有人」以下，接著說明聘請請求他人接續攜帶的規範。「若是役使」以下，第三說明指使其他四眾弟子代攜的罪責。「除羊毛外」以下，第四說明挑攜各種輕賤非制物品的罰則。

【680-0005】02_戒疏/14c_卷三下之二#66
【原文】【疏】開中「帽、巾」者，本未擔前立意者耳。
【譯文】【疏文】開緣中所謂的「帽子、頭巾」，是指在原本擔負之前，心裡就已經立定用途意向的情況而已。

【680-0006】02_戒疏/14c_卷三下之二#67
【原文】【記】次不犯中。已成帽巾，本無有犯。今此開者，謂擔少毛意欲作耳。
【譯文】【記文】接下來不犯的科別中。如果是已經做好的現成帽子或頭巾，本來就沒有犯戒的問題。現在這裡之所以開許，是指挑擔少量的羊毛，打算用來製作這些小物品的情形。

【680-0007】02_戒疏/14c_卷三下之二#68
【原文】【律】十七、使非親尼浣羊毛戒。
【譯文】【律文】第十七條：役使非親屬比丘尼洗滌羊毛戒。

【680-0008】02_戒疏/14c_卷三下之二#69
【原文】【疏】第十七，使尼浣擗毛戒。
【譯文】【疏文】第十七條，役使比丘尼洗滌、分理羊毛戒。

【680-0009】02_戒疏/14c_卷三下之二#70
【原文】【疏】制戒意，成犯緣，同上浣衣戒。彼制故者，新是輕犯，此既勞功，新故同犯。
【譯文】【疏文】制定戒律的意旨，以及構成犯戒的緣起條件，與前面的洗滌舊衣戒相同。那一條戒律針對舊衣才判重罪，新衣只是輕犯；而在這一條戒中，因為洗染分理羊毛極其勞累耗費功力，所以不論是洗新毛或舊毛，同樣都結犯重罪。

【680-0010】02_戒疏/14c_卷三下之二#71
【原文】【記】十七，名中。「擗」，合作「擘」，分也。「擗」本音「闢」，字之誤也。
【譯文】【記文】第十七條，戒名之中。「擗」字理應寫作「擘」，意思是將羊毛撕開分理。「擗」字原本的讀音是「闢」，在此是傳抄的錯字。

【680-0011】02_戒疏/14c_卷三下之二#72
【原文】【記】通釋中。初指同。此亦三緣同制，犯相離合，並同上說。犯緣唯改第三，是「羊毛」耳。「彼」下，簡異，可知。
【譯文】【記文】通論解釋之中。首先指出相同之處。此戒也是由三種犯罪緣起共同制約，罪相的分合界限，全都和上面洗衣戒的說明一樣。犯戒條件中唯獨把第三項更改為「是羊毛」而已。「彼」字以下，辨析二者的相異之處，文理容易明白。

【680-0012】02_戒疏/14c_卷三下之二#73
【原文】【註】佛在迦維羅衛。六群比丘取羊毛使尼浣、染、擗之。時，姨母尼為染毛故，汙色在手，往佛所，禮足而立。佛知故問，訶而制戒。
【譯文】【註文】佛在迦維羅衛國時。六群比丘拿了羊毛役使比丘尼代為清洗、染色、分撕梳理。當時，身為佛陀姨母的大愛道比丘尼因為染羊毛的緣故，手上沾染了顏料汙漬，便前往佛陀處所，頂禮佛足後肅立在一旁。佛陀明明知曉卻故意發問，隨後加以訶責並制定了戒律。

【680-0013】02_戒疏/14c_卷三下之二#74
【原文】【疏】就戒緣中，「姨母為染」至「佛所禮足而立」者。《多論》云：「所以制者。與諸比丘增上法故，若諸尼眾執作浣染，廢修正業，則無威儀，破增上法。又止惡法次第因緣，各令清淨故。」所以不坐者，女人敬難情多，又佛不廣為女眾說法，又尼至佛所，一切皆立，為止外道誹謗故，又女人鄙陋，多致譏疑，所以不坐。
【譯文】【疏文】在戒律制定的因緣中，「姨母為其染毛」以至「前往佛所禮足肅立」的記載。《多論》說：「之所以要制定此戒，是為了給予諸比丘長養增上善法的緣故，如果眾比丘尼全去操持粗重的洗滌染織雜務，荒廢了自己修道的正業，就會喪失出家人的威儀，從而破壞了增上善法（或：這等同是比丘在破壞增上法）。此外也是為了在最初便止息惡行相續蔓延的因緣，讓僧尼各自保持清淨。」而比丘尼禮佛後之所以站著而不坐下的原因，其一是女人對佛的敬畏與難為之情較多；其二是佛陀通常不為女眾作長篇繁複的說法；其三是尼眾到了佛陀面前，一律保持站立，是為了止息外道誣衊譏諷的誹謗；其四是世俗看待女人較為低賤鄙陋，坐著容易引發世人譏評猜疑，所以站著不坐。

【680-0014】02_戒疏/14c_卷三下之二#75
【原文】【記】戒緣中。初牒文徵意。《多論》下，引釋，有二。初釋制戒，有二意：初意「與比丘增上法」者，由尼執作廢業乖儀，則是比丘破增上法；次意「止惡法次第」者，禁輕防重故。「所以」下，次明不坐，四意釋之。第二說聽非久，故不須坐，餘三可解。注中「姨母」，即大愛道尼。「汙手見佛」，發請制戒也。
【譯文】【記文】在戒緣之中。起初引提經文並推究深意。《多論》以下引導解釋，分為兩個部分。首先解釋制定戒律的原因，有兩層意圖：第一層「給予比丘增上法」，是因為尼眾若忙於勞務而荒廢道業、威儀失序，這等同是比丘在破壞增上法；第二層「止息惡法次第蔓延」，是為了從小事禁防以防止嚴重大過。「所以」以下，接著說明尼眾不就坐的原由，共用四個觀點加以解釋。第二點提到因為說法與聽法時間不會很久，所以不必坐著，其餘三點容易明白。注文中所說的「姨母」，就是大愛道瞿曇彌比丘尼。「雙手染汙面見佛陀」，這正是觸發並請求佛陀制定戒律的機緣。

【譯文】【律文】如果比丘役使沒有親屬關係的比丘尼清洗、染色、分理羊毛的，犯尼薩耆波逸提。

【680-0021】02_戒疏/14c_卷三下之二#82
【原文】【疏】寶是八穢之一，因明料簡：一、列數顯非；二、開制不同；三、輕重結罪；四、互貿得罪。
【譯文】【疏文】金寶是佛門所說「八種穢物」中的一種，在此順帶加以辨析探討：第一、列出名數以彰顯其非；第二、說明開許與禁止的不同；第三、辨別輕罪與重罪的結犯；第四、說明彼此互相貿易所犯的罪過。
