# 校閱材料　第635檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【635-0001】02_戒疏/12b_卷三上之三#7
【原文】【記】答中。初二句，令通諸部。「長」下，正定先後，「如《律》證」者，六群初犯，制云「若比丘畜長衣，尼薩耆」等，未列迦絺，故知長在初矣。又如後注引阿難緣，次開十日，而迦絺緣開，《律》文不顯。「但」下，示缺所以。「促近」即十日，謂結集家但欲示其促限，故致略耳。
【譯文】【記文】回答的內容中。前兩句話，是要求貫通各部律典。從「長衣」以下，正式判定前後次序；所謂「如同《律》文證實」，是指當初六群比丘初犯時，佛陀制定戒律說「若有比丘畜存長衣，犯捨墮」等語，當時條文中並未列入迦絺那衣的開許，所以知道長衣戒在最前面。又如後文註解引阿難的因緣，接著才開許十天的期限，而迦絺那衣的開許因緣，《四分律》正文沒有明顯交代。從「但是」以下，指明文辭缺略的原由。「短促」就是指十天，意思是結集律藏的人只是想表達這項短暫的期限，所以才將文辭省略了。

【635-0002】02_戒疏/12b_卷三上之三#8
【原文】【疏】如《五分》云：「因六群犯，制畜一宿，過則犯罪。後因那律得衣恐犯，一日不成，又因夏末持衣疲頓，乃開五事。更開第二『若衣已竟，捨迦絺那，畜過一宿者犯』。又因阿難非時得衣，復開十日，制第三戒。」今此戒中，三中少一，是以迷也。
【譯文】【疏文】如同《五分律》記載：「因為六群比丘犯戒，先制定長衣只能畜存一夜，超過就算犯罪。後來因為阿那律獲得布料恐怕犯戒，一天之內做不成僧衣，又因為夏末比丘攜帶厚重僧衣行路極度疲勞，佛陀才開許五件事。進而又開許了第二階段的戒條：『如果做衣之事已結束，捨棄了迦絺那衣，畜存超過一夜者犯戒。』後來又因為阿難在非規定時間獲得布料，佛陀又開許可以保存十天，這才制定了第三階段的戒文。」現在我們這部《四分律》的戒文中，三個階段的因緣缺少了中間那一個，所以才會令人迷惑。

【635-0003】02_戒疏/12b_卷三上之三#9
【原文】【記】次科。《五分》三緣。第一，「因六群犯制畜一宿」，同上《四分》。「後」下，第二緣，復有二緣。初「因那律」者，彼云：「諸比丘若須一一衣，眾僧羯磨所應分物與之。時阿那律衣弊，諸比丘語曰：『何不從僧取，使一日成？』那律言：『我不敢取，恐一日不成，犯捨。』其次又因波利邑諸比丘，於鞞陀邑安居訖，十六日便進佛所，道經泥水，三衣麤重，極大疲極，到禮佛足，具陳向事。諸比丘以上二緣白佛，佛言：『從今聽受迦絺那衣，聽畜長衣五事。』」、「又因」下，第三緣。「開十日」，亦同《四分》。「制第三戒」者，謂此一戒，凡三番制耳。「今」下，點缺。「今此戒」即《四分》，缺中間緣，故惑先後。
【譯文】【記文】第二科。《五分律》記載了三個因緣。第一個，「因為六群比丘犯戒而制定只能畜存一夜」，這點和上述《四分律》相同。從「後來」以下，是第二個因緣，其中又包含兩件事。第一是「因為阿那律」，那部律說：「各位比丘如果需要單件的衣物，僧團應當透過會議羯磨把應分配的物品分給他。當時阿那律的僧衣破爛，比丘們對他說：『何不向僧團領取布料，讓它在一天之內縫好？』阿那律說：『我不敢領取，恐怕一天做不完，會犯捨墮罪。』其次又因為波利邑的許多比丘，在鞞陀邑結束安居後，十六日當天就前往佛陀住處，路上經過泥水，三衣粗大笨重，身體極為困頓疲累，抵達後禮拜佛足，把剛才的情況完整稟告。比丘們把這兩個因緣稟白佛陀，佛陀說：『從今天起准許受持迦絺那衣，准許享受畜存長衣等五項開許。』」從「後來又因為」以下，是第三個因緣。「開許十天」，這也與《四分律》相同。「制定第三階段戒文」，是說這一條戒前後共經歷了三次修訂。「現在」以下，點出文脈缺漏。「現在這條戒」就是指《四分律》，因為缺少了中間那段因緣，所以大家才會對前後次序感到疑惑。

【635-0005】02_戒疏/12b_卷三上之三#11
【原文】【疏】「何故三戒獨列迦開，餘則不列？」
【譯文】【疏文】有人問：「為什麼唯獨這三條衣戒列出了迦絺那衣的開許，其他戒條卻不列出？」

【635-0006】02_戒疏/12b_卷三上之三#12
【原文】【疏】答：「有兩義故：此三皆是屬己，開益無罪；二、不惱施主。自他無惱，餘則反前。」
【譯文】【疏文】回答：「因為有兩個道理：這三條戒所涉及的物品都屬於自己所有，給予開許有助於行道而沒有罪過；第二、不會對施主造成困擾。既能讓自己不受損害也不惱亂他人，其他戒條則與此相反。」

【635-0007】02_戒疏/12b_卷三上之三#13
【原文】【記】二中，初科。問中，謂餘衣戒何意不開。答中二義，則顯餘戒或非屬己，或復惱他，故所不開。
【譯文】【記文】在第二部分中，這是第一科。提問中，是問其餘的衣戒為什麼不給予開許。回答中的兩個道理，則表明其餘戒條若非屬於自己所有，就是會惱亂他人，所以不予開許。

【635-0008】02_戒疏/12b_卷三上之三#14
【原文】【疏】「若爾，自作五敷，過旬，用雨，豈非屬己？非惱施主，何不同開？」
【譯文】【疏文】有人又問：「如果這樣，自己製作五種坐臥具、挑運羊毛超過三由旬、在非規定時間使用雨衣，難道不也屬於自己所有？而且也不會惱亂施主，為什麼不同樣給予開許？」

【635-0009】02_戒疏/12b_卷三上之三#15
【原文】【疏】答：「彼由作用，自損妨道，故訶制之。此雖長、離，譏訶是少，開則有益。」
【譯文】【疏文】回答說：「那些行為都出於刻意的造作，損害自身精力並妨礙修道，所以佛陀才呵斥並加以制止。這裡雖然蓄積長衣、離衣而宿，招致的譏嫌呵責畢竟較少，給予開許則對修道有實質利益。」

【635-0010】02_戒疏/12b_卷三上之三#16
【原文】【記】次釋難中。「過旬」即擔羊毛。「旬」或是前字，連下雨衣。答中，言「作用」者，反前三故，由是作用，故有「損妨」。「故訶制」者，謂俗譏也。「此」下，遮妨。以畜長、離衣，亦招譏呵，故以多少通之。
【譯文】【記文】接下來是釋除疑難。「超過由旬」就是指挑運羊毛。「旬」字或許是「前」字之誤，應與下文的雨衣連讀。回答中提到「刻意造作」，是相對於前面三條戒而言的，正因為那是刻意的貪圖造作，所以會有「損害與妨礙」。「佛陀才呵斥制止」，是指會引來世俗的譏評譏諷。從「這裡」以下，是防免對方的質難。因為蓄積長衣和離衣而宿同樣也會招致微嫌呵責，所以用譏嫌程度的多少來解答通達。

【原文】【疏】三、開緣入不者。
【譯文】【疏文】第三、開許的因緣究竟列入正戒條文還是不列入。

【635-0012】02_戒疏/12b_卷三上之三#18
【原文】【疏】問：「此三戒得時利，著『迦衣竟』，餘三食戒亦得利開，何為不著『迦衣已出』？」
【譯文】【疏文】問道：「這三條衣戒得到時限上的開許利益，都寫上了『迦絺那衣期限已結束』，其餘三條飲食戒同樣能得到利益開許，為什麼正戒條文不寫『迦絺那衣期限已出』？」

【635-0013】02_戒疏/12b_卷三上之三#19
【原文】【疏】答：「此三專得迦衣利故，不假餘緣，故戒本前著。餘食反前，更有餘開，故在戒末，所以文言『作衣時』是也。但為親疎不同，故有前後。」
【譯文】【疏文】回答：「這三條衣戒是專門依憑迦絺那衣而得到利益，不需要假借其他因緣，所以直接寫在戒本條文的前面。其餘飲食戒則與此相反，除了迦絺那衣之外還有其他的開許條件，所以放在戒條末尾，因此律文所說的『在做衣的時候』就是指這件事。只因為因緣關係有親有疏的差別，所以安放的先後位置不同。」
