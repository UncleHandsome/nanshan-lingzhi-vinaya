# 校閱材料　第1143檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1143-0001】資持記/08c_中二#22
【原文】準上情隔三斷，故云比二；界礙可知，故不在言。文下，斥古。不通諸部者，緣出《多論》等，如前所引。問中，律不犯文，不明忘故。答中。還約勤怠二心以判。事下準例可解。疏又問云：如戒緣開，何分勤惰？答：諸戒相開，並為奉者；必有惰學，隨犯根本，非是通開。結指中。
【譯文】依照上面「情念」與「物理阻隔」的三種斷別，所以說「比照這兩者」；至於「界限上的障礙」顯而易見，所以不再贅言。經文以下，斥責古人的見解。所謂「不通融諸部派」者，是因為這些因緣出自《薩婆多論》等書，正如前面所引述的一樣。在提問中，律文的不犯條款中，並未明文記載「遺忘」這種情況。在回答中。依然是依據「勤勉」與「懈怠」這兩種心態來進行判定。「事……」以下，比照前例便可以理解。疏文中又提出疑問說：如果戒律的因緣已經開許，又何必區分勤勉與懈怠？回答：各種戒相開許的條款，都是為了切實奉行戒律的人而設；如果有懈怠怠惰而隨意求寬者，便隨其心念犯下根本罪，絕不是普遍毫無限制地開許。在最後「結語與指引」中。

【1143-0002】資持記/08c_中二#23
【原文】《戒本疏》廣明自然，《羯磨疏》廣明作法，故兩指之。第三。〔佛在舍衛但三衣比丘僧伽梨故壞，十日不辨，聽畜長，為滿足故；六群取同衣不足者寄人間遊行，因制。〕名中。月即開之時限，望謂希其滿足。釋中，初科，前敘本制。畜下，示教限。犯緣中。第二且約後位以論；中位少財，但有染犯。
【譯文】《戒本疏》詳細闡明了「自然界」，《羯磨疏》詳細闡明了「作法界」，所以文中雙雙指引這兩部疏文。「第三戒（月望衣戒）」。〔佛陀在舍衛國時，有一位只持三衣的比丘，其僧伽梨大衣陳舊破壞，十天之內無法籌備齊全，佛陀聽許蓄留多餘的長衣，是為了使三衣籌足滿足；六群比丘便藉口衣服不足，拿著多餘衣物寄存在俗世人間四處遊行，佛陀因而制定此戒。〕在戒名中。「月」是開許的時限寬限，「望」是指期盼衣料能夠籌足滿足。在解釋中，第一科，先敘述原始的制度。「蓄……」以下，開示教導的時限。在犯戒條件中。第二點暫且依照後位以論；中位如果缺乏衣料，則只構成貪染的犯相。

【1143-0003】資持記/08c_中二#24
【原文】五即迦提一月五月。釋中，初科。初位十日內，雖滿不犯。若至十日得足，當日須成；不爾，十一日明出便犯。中位十九日同足即犯，後泣一日不足亦犯。得不得者，不同中位得足犯故。同不同，如後解。次科，《僧祇》，且據初位滿足示相。作衣下，明即作。所以爾者，以但三衣人，不說淨故。
【譯文】「五」就是指迦提月的一或五個月期間。在解釋中，第一小節。第一階段的十天之內，即使籌滿衣料也不犯戒。如果到了第十天籌足了，當天就必須縫製完成；若不如此，第十一天天明露出時便構成犯戒。中位階段的十九天內同類布料籌足便構成犯戒，後一位若過限一日仍未籌足亦犯。所謂「得與不得」，與中位階段籌足即犯的情況不同。所謂「相同與不相同」，如後文所作的解釋。下一小節，《摩訶僧祇律》暫且依據第一階段滿足條件來顯示相狀。「作衣……」以下，說明必須立刻裁製。之所以如此，是因為只持三衣的人，是不允許作說淨手續的。

【1143-0004】資持記/08c_中二#25
【原文】初明可竟。若下，開急竟。此律下，合上急竟。絣謂疎綴令定。三中，先明同不同者。如營一衣，得多零段，體色相類，名為同衣；餘不類者，不堪共作，即不同衣。皆開一月者，或求三衣同時一月，或復前後各取一月；但得少財，即為初日。若下，明染犯。同足即中位，限滿是後位。
【譯文】首先說明可以縫製完畢的情況。「若……」以下，開許在緊急情況下暫時粗縫完畢。「此律……」以下，契合上述緊急粗縫的意義。「絣」是指粗略綴縫使其定型。第三點中，先說明「布料相同與不相同」的情況：例如經營裁製一件衣物，得到許多零碎布料，材質與顏色互相吻合，就稱為「同衣」；其餘材質色彩不相符、不堪放在一起縫製的，就是「不同衣」。這類情況都「開許一個月寬限」，或者為了求取三衣而在同一個月內求齊，或者前後分別各取一個月的時間；只要獲得些微衣料財物，那一天就算是第一天。「若……」以下，說明連帶沾染犯長的情形。同類布料籌足就是中位階段，時限屆滿就是後位階段。

【1143-0005】資持記/08c_中二#26
【原文】由下，釋所以。所下，引證。不犯指前，同是長故。第四。〔佛在羅閱祇，蓮華色尼脫所著貴衣，換比丘弊故納往佛所，因問而制。〕戒名。取即是業，非親簡親，尼別下眾。犯緣，第二中，初句標緣。律下，釋相為三，前明親非親相；本律通示親里，以顯非親。《善見》別簡，初示二親。
【譯文】「由……」以下，解釋箇中原因。「所……」以下，引用經文作證。不犯戒的規定指引前文，因為這些同樣都屬於長衣的範疇。「第四戒（從非親里比丘尼取衣戒）」。〔佛陀在羅閱祇城時，蓮華色比丘尼脫下身上所穿的昂貴衣物，換取比丘破舊的粗劣糞掃衣穿著前往佛所，佛陀因應大眾的疑問而制定此戒。〕戒名。「取」是指行為動作，「非親」是用來揀別親族，「比丘尼」是用來揀別其餘沙彌尼等下眾。犯戒條件，在第二點中，第一句標明因緣。「律……」以下，分三段解釋戒相：首先說明親眷與非親眷的外相；本律是籠統指出內外親戚，藉此彰顯非親眷的範圍。《善見論》作了特別揀別，首先指出父系與母系兩類親族。

【1143-0006】資持記/08c_中二#27
【原文】乃至者，略兄弟；兒孫即舅姨家者。皆下，釋親義。唯約父母二姓所屬。又下，簡非親。出家婦者，由姓異故。伯叔之婦，亦是異姓。論中不出，故例同之。《十誦》下，二明開親之意。少尚與者，謂尼貧乏，僧猶愍濟。何況等者，言無此理。律云：若非親里，亦不籌量可否；
【譯文】「乃至」這個詞，省略了堂表兄弟；兒孫是指舅父與阿姨家族的後代。「皆……」以下，解釋「親族」的定義。這僅僅局限於父親與母親兩個姓氏所屬的血脈。「又……」以下，揀別非親眷的情形。出家前曾為妻室的婦女，因為娘家姓氏不同的緣故而屬非親。伯父與叔父的妻子，也屬於異姓姻親。論典中雖未列出，但也比照同例判定。《十誦律》以下，第二段說明開許向親眷索取衣物的用意。連微薄之物尚且願意相贈，這是說比丘尼貧乏時，僧人尚且予以憐憫賑濟；「何況」等語，是說絕沒有在她不足時反而去索取的道理。律文說：如果不是親戚，就不會審慎考量對方的承受能力；

【1143-0007】資持記/08c_中二#28
【原文】若是親里，則便籌量，知有無可取不可取等。《五分》下，三簡親尼淨穢。制吉罪者，遮世譏故。第三中，初約緣定境。《僧祇》簡餘輕物。無犯者，望墮為言，非無輕吉。疏云：衣多喜與故重，鉢唯有一故輕。四中。虛心謂專勤一意，無他想故。〔有云揀實心非也。〕
【譯文】如果是親戚，就會反覆考量，清楚其有無能力、可以取或不可取等。《五分律》以下，第三段揀別親族比丘尼本身持戒是清淨還是毀犯。制定突吉羅輕罪，是為了阻絕世俗的譏嫌誹謗。在第三點中，首先依據因緣確定對境。《摩訶僧祇律》揀別其餘輕微物品。所謂「無犯」，是針對免除「捨墮」重罪而言，並不是說完全沒有突吉羅輕罪。《戒本疏》說：衣服大多令人心生歡喜而貪求贈與，所以罪責重；缽只有一個，所以罪責輕。在第四點中。「純淨的心（虛心）」是指專注勤謹於單一意志，毫無其他非分企圖。（有人說是揀擇實質的心，這種說法是錯誤的。）

【1143-0008】資持記/08c_中二#29
【原文】乞無犯者，非虛心與故。《僧祇》，初明暫借無犯。非決取故。若下，明轉施無犯。從餘人取故。據下二眾，亦應得吉，非全無犯，如上通之。五中，初文。受寄無犯，非正與故。次科。使人同犯，能使教他，所使情諂故。三中。僧尼互論，人分多少，罪無差降。四中，《十誦》。
【譯文】乞求而判「不犯」，是因為對方並非以純淨無求之心主動相贈的緣故。《摩訶僧祇律》中，首先說明「暫時借用」不構成犯戒。因為這不是存心佔為己有。「若……」以下，說明「轉手施捨他人」不構成犯戒。因為衣服是從第三者處獲得的緣故。若依據下二眾（式叉摩那與沙彌尼）而言，也應當被結判突吉羅罪，並非全然無犯（仍結輕罪），如同上面所作的融通解釋。在第五點中，第一段經文。接受「寄放」不犯戒，因為這不是正式的贈予。下一小節。「役使他人」同樣犯戒，指使者教唆他人，受指使者產生諂媚迎合之心的緣故。在第三點中。僧人與比丘尼互換論罪，不論涉入人數的多寡，罪過本質毫無等級差異。在第四點中，《十誦律》說。
