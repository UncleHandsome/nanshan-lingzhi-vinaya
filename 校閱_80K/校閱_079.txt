# 校閱材料　第079檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【079-0001】02_戒疏/14a_卷三下之二#198
【原文】【記】後段中，初科為三。初牒釋。「有求義」者，文云「與我為好」，即是求也。「文」下，初釋增價。注云「一錢」，即古大銅錢，一當十六。「十六之一」，即一小錢，亦為增價。「如」下，次釋增衣。「今」下，決持事。「同此戒」者，即增價也。「十」下，示同異。本宗但無增色，文中二增，即是價、量。
【譯文】【記文】後半段中，第一科分為三層。起初依文解釋。「有求義」，經文中說「送我為了好的緣故」，這本身就是求討。「文」字以下，首先解釋增添價款。注文說「一錢」，是指古代的大銅錢，一枚值十六枚小錢。「十六分之一」，就是指一枚小錢的價值，微少如此也算增價。「如」字以下，接著解釋增加衣料面積。「今」字以下，衡量現實中的行持事項。「同此戒」，就是指增加價款之類。「十」字以下，辨明各部派律文異同。本律宗派只是沒有列出「增加顏色」一項，文中的兩類增加，正是價款與尺度的增加。

【079-0002】02_戒疏/14a_卷三下之二#199
【原文】【疏】此戒犯相，要在本絹於上勸增。若令買布，屬前乞戒。
【譯文】【疏文】這條戒的犯相關鍵，在於居士原本就預定要買該匹絹布，比丘在原基礎上勸請增添。若是叫居士改買完全不同的麻布，那就屬於前面那一條無端乞衣戒的範疇了。

【079-0003】02_戒疏/14a_卷三下之二#200
【原文】【記】次科。以「勸增」論犯，局在本物。若易物體，即非增故。
【譯文】【記文】第二小節。因為是以「勸增」來論定犯罪，所以犯相局限於居士原本發心布施的那項物品上。如果改變了物品的原形實體，就不屬於勸增的範疇了。

【079-0004】02_戒疏/14a_卷三下之二#201
【原文】【疏】問：「勸增戒中，一縷即犯。乞衣戒中，一條方犯，與此不同？」
【譯文】【疏文】提問：「在勸增衣價戒中，增求一根織線就犯捨墮。在乞衣戒中，乞得滿一條（袈裟一相之量）才犯罪，為何這兩條戒規定不同？」

【079-0005】02_戒疏/14a_卷三下之二#202
【原文】【疏】答：「乞本施主無心，乞時任其多少，惱義是微，故約一條方犯。勸增之中，虗心限約已定，不荷嫌少索多，貪惱之情最重，故使不問多少，同犯罪也。」
【譯文】【疏文】回答：「乞衣戒原本施主並未動念要施，乞求時任由對方隨意給予多寡，造成的逼惱微弱，所以限定滿一條（袈裟一相之量）才犯重罪。勸增戒之中，施主竭誠發心且限額已經確定，比丘不感念其恩德，反而嫌少索多，貪婪逼惱施主的情節最為嚴重，所以無論增求多少，哪怕極微，皆一律結犯重罪。」

【079-0006】02_戒疏/14a_卷三下之二#203
【原文】【記】問中。與前乞衣少多異故。言「一條」者，謂袈娑一相許也。答中，分示二戒情過不同，故制限兩別。
【譯文】【記文】提問中，指出本戒與前面乞衣戒數量多寡不同的疑點。所謂「一條」，是指足夠做成袈裟一個隔段的布料。回答中，分別說明兩條戒中比丘的心態與過失深淺不同，所以規定的限度有嚴寬之別。

【079-0007】02_戒疏/14a_卷三下之二#204
【原文】【疏】諸餘可解耳。
【譯文】【疏文】其餘經文皆容易理解。

【079-0008】02_戒疏/14a_卷三下之二#205

【譯文】【記文】總結略述中，就是指「若得衣者」以下的三句經文。

【譯文】【律文】九、勸請二家居士增添衣價戒。

【譯文】【疏文】第九條，勸二居士增衣價戒。


【079-0011】02_戒疏/14b_卷三下之二#1
【原文】【疏】制意、犯緣同前，但合二家共作一衣為異耳。
【譯文】【疏文】制戒意旨與構成犯戒的因緣，都和前一條戒相同，唯一的差別只在於：將兩家人的布施合併起來共做一件僧衣。

【079-0012】02_戒疏/14b_卷三下之二#2
【原文】【記】第九，通釋中，初科。「犯緣同」者，唯加第一云「二非親居士」耳。
【譯文】【記文】在第九條戒的統括解釋中，屬於第一科。「犯戒因緣相同」這點，僅僅在第一項因緣中增加「兩位沒有親戚關係的居士」而已。

【079-0013】02_戒疏/14b_卷三下之二#3
【原文】【疏】問：「勸二居士共作一衣，價本不增，為有犯不？」
【譯文】【疏文】提問：「如果勸請兩位居士合力做一件僧衣，但原本的布施價值完全沒有增加，這樣算不算犯戒？」

【079-0014】02_戒疏/14b_卷三下之二#4
【原文】【疏】答：「如文云『增』，不增非犯。」
【譯文】【疏文】回答：「如同戒律原文所說的『增加』，如果價值沒有增加，就不構成犯戒。」

【079-0015】02_戒疏/14b_卷三下之二#5
【原文】【記】二中，初問。但勸二家合而不增，亦應犯勸。答中。犯必約增，不增非犯。文云「為好」，即是增故。
【譯文】【記文】第二部分中，首先是提問。如果只是勸兩家人合力，而總價沒有增加，按理也應該犯了擅自勸求的過失。回答中說明：犯戒必定要以『價值增加』為判定標準，價值沒有增加就不算犯戒。因為原文說的『為了做得更好』，指的就是增加價值。

【079-0016】02_戒疏/14b_卷三下之二#6
【原文】【疏】問：「勸二作一，有增不增，在何戒攝？」
【譯文】【疏文】提問：「勸請兩家合做一件僧衣，如果出現一家增加價值、另一家沒有增加的情況，這該歸屬於哪一條戒所管轄？」

【079-0017】02_戒疏/14b_卷三下之二#7
【原文】【疏】答：「後戒所攝，雖不增非犯，增者合作故。」
【譯文】【疏文】回答：「這屬於後一條戒所管轄。雖然沒增加的那部分不構成犯戒，但增加了的那部分是與另一家合併製作的緣故。」

【079-0018】02_戒疏/14b_卷三下之二#8
【原文】【記】次問。或一家不增，兩戒何收？答中，既涉二家，故非前戒。
【譯文】【記文】接下來提問：如果其中一家沒有增加價值，這在兩條戒中該如何歸屬？回答中指出：既然已經牽涉到兩家，就不是前一條戒所能涵蓋的了。

【079-0019】02_戒疏/14b_卷三下之二#9
【原文】【疏】問：「但制合二，不云三者？」答：「舉例可知。」
【譯文】【疏文】提問：「戒文只限制合併兩家，為什麼不提三家呢？」回答：「舉出這個例子，其餘情況就可以類推而知。」

【079-0020】02_戒疏/14b_卷三下之二#10
【原文】【記】三問答中。但舉二家，三四皆爾，但無緣起，故所不明。
【譯文】【記文】第三個問答中：雖然只列舉兩家，但三家、四家也是相同道理；只是當時沒有這樣的具體事緣發生，所以戒文中沒有特別說明。

【079-0021】02_戒疏/14b_卷三下之二#11
【原文】【疏】問：「三家各欲作布，今令合細，可非損邪？何戒所攝？」
【譯文】【疏文】提問：「如果三家原本各自想做粗布衣，現在比丘讓他們合起來做細布衣，難道不算是損耗施主嗎？這該歸屬於哪一條戒？」

【079-0022】02_戒疏/14b_卷三下之二#12
【原文】【疏】答：「合三作細，異於本體，前戒所攝。」
【譯文】【疏文】回答：「把三家的粗布合做成細布，已經改變了物品原本的質地，這應當屬於前面那條乞衣戒所管轄。」

【079-0023】02_戒疏/14b_卷三下之二#13
【原文】【記】四問。合布為細，亦是增價，須定所屬。答中，易體非增，義同前釋。
【譯文】【記文】第四個提問。把粗布合做成細布，實質上也算增加了價值，必須判定它屬於哪一條戒。回答中說明：改變材質並不同於單純的增加價值，其義理如同前面所解釋的那樣。

【079-0024】02_戒疏/14b_卷三下之二#14
【原文】【疏】《僧祇》中，「為僧、眾多、若一人，合作，同犯墮罪」。如上僧犯。
【譯文】【疏文】《摩訶僧祇律》中說：「無論是為了整個僧團、眾多僧人、或是個別一人，只要勸請合併製作，同樣犯捨墮罪。」這就如同上面所說的僧團犯戒情況。

【079-0025】02_戒疏/14b_卷三下之二#15
【原文】【記】三中。僧別三位，勸增齊犯，以長貪惱主，義無異故。下指「如上」，即前義門。
【譯文】【記文】第三部分中指出：無論是對全體僧團、多數人、或個人這三種對象，只要勸誘增加價值，所犯的罪責都完全相同；因為滋長貪心、惱害施主的本質是沒有差別的。文末所指的「如同上面」，就是指前面義理門中所討論的內容。

【譯文】【疏文】珍寶玉璧等貴重精華之物，是世俗人情所看重的，蓄存它們會滋長貪念、妨礙修道，引生過患極深，特別不是出世修道之人所適宜蓄存的。然而施主誠心布施，作為購買僧衣的價款，比丘唯恐犯下蓄寶之戒，不宜親自接受，因此託付給俗人掌管，令其代辦清淨衣物。比丘若索求過於急迫切促，毫無從容寬緩的餘地，接連不斷催促，逼迫擾惱了辦事的淨人。因此佛陀制定限制，只許開口三次、靜默六次，若超過限度索取而得到衣服，便是輕蔑戒律禁網，過患深重、障礙道業，怎能不加以制止約束呢？

【079-0032】02_戒疏/14b_卷三下之二#22
【原文】【記】第十，制意中四。初敘世寶生患。「然」下，次明淨施俗人。由是實淨，物過主邊，故與此戒。「尋」下，三、明因索惱他。「忽」謂急速。「豫」猶緩也。「故」下，四、明過限制犯。「三語六默」，如下自明。
【譯文】【記文】第十條，在制戒意旨中分為四層。首先敘述世間珍寶容易引生過患。「然而施主」以下，次說明應當將物資淨施委託給俗人。由於實質上已經託付俗人作淨，物權已轉移給主管人，所以才會制定這條戒。「索求得過於急迫」以下，第三說明因為索求無度而擾惱他人。「急切」是指過於急速。「容豫」如同從容寬緩。「因此佛陀」以下，第四說明超過限制便判定為犯戒。「語三次、默六次」的具體規定，在後文自會說明。

【079-0037】02_戒疏/14b_卷三下之二#27

【079-0153】02_戒疏/14b_卷三下之二#143
【原文】【記】十三，制意中。初句指同。體雖非貴，長貪營造，妨業不殊，故須制約。「五」下，示異。本宗緣於純白，乃制相參，二律因彼微參，故制分齊。「小小白尨」，謂不多也。「尨」，莫江反，若依字書，則犬多毛。有云合作「牻」，訓雜者，此乃雜色牛名，非訓雜也。今準注中，頭脚等處即是「麤毛」，倉黃色者謂之「尨毛」。
【譯文】【記文】第十三條，在制戒意旨中。第一句是指涉意旨相同。白毛材質雖然沒有純黑毛那麼昂貴，但貪心滋長、營造營求、妨害修道本業的情形是完全相同的，所以必須加以約束限制。「《五分》」以下，展示各部律典的差別。本宗《四分律》是針對比丘使用「純白毛」而引發譏嫌，才制定相雜配比的限制；《五分》、《十誦》二部律典則是因為比丘稍微摻入一點點雜毛來規避前戒，所以才制定嚴格的比例分寸。「微量的一點點白毛與雜毛」，是指數量極少。「尨」字讀作「莫江反」，如果依照字書字典的解釋，是指長著很多長毛的狗。有人說這個字應當寫成「牻」，解釋為雜色，但那其實是雜色牛的名稱，並不是解釋為顏色龐雜。現在依照律注中的定義，羊頭部、腳部等處的粗糙毛髮就是「粗毛」，顏色呈灰黃蒼黃色的就稱為「尨毛（雜色毛）」。
