# 校閱材料　第042檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【042-0001】01_行事鈔/06a_卷中之二#5
【原文】媒人戒第五。六緣成犯：一是人男女，二人想，三為媒嫁事，四媒嫁想，五言辭了了，六受語往還報，便犯。律文要三時具者，方結僧殘：一謂受語，二往彼陳說，三還報知。若具二者結偷蘭遮；具一時者結突吉羅。若受語往彼說，而言已嫁、若死、若賊將去者，偷蘭；若言癩病等，還報者，僧殘。除二道已，媒餘身分者偷蘭；若媒人男畜生等，並吉羅。《五分》：不許而報，偷蘭。《十誦》：不能男女，若道合一道女，石女等，一切偷蘭。此律中，諸比丘白二羯磨，差人媒嫁，一切僧殘。今知事白僧，媒娶淨人，供給婚具，問僧同和，一切僧殘。若用僧物，同俱犯重。《僧祇》：為他求好馬種和合故，偷蘭；餘畜吉羅。《五分》若為男長倩女使，偷蘭；為女倩男亦爾。《十誦》、《伽論》云：若指腹為媒，及自媒者，偷蘭。《四分》：媒法以語書、指印、遣使，但情相領，參互作句，皆犯。若比丘持他書往不看者，及為白衣作餘使，並吉羅。《僧祇》：勸歸婦早還者偷蘭。律不犯中，若男女先已通，後離別，還和合者，開不犯。《十誦》云：作券書言非我婦，猶故未唱出者，偷蘭；若婦禮已斷，不復來往，而和合者，僧殘。律中開持書者，若為父母，及信心精進優婆塞病，若在獄繫，及為佛法僧事，病比丘事等，看書持往不犯。
【譯文】媒人戒第五。具備六個條件構成違犯：一是人道的男女，二是作人道想，三是為了媒合婚嫁之事，四是作媒合婚嫁想，五是言辭清晰分明，六是接受囑託往返傳話通報，便結犯。律文中必須三種時節皆具備，方才結犯僧殘：第一是接受委託之語，第二是前往對方處陳述遊說，第三是返回向委託人回報知會。如果只具備前兩項者結偷蘭遮；只具備第一項者結突吉羅。如果接受委託前往對方處陳說，而對方回覆說已經出嫁、或者已經死亡、或者被盜賊擄走，回報者結偷蘭遮；如果對方回覆患有癩病等殘疾而回報者，結僧殘。除了以行房交合（前道、後道）為目的媒合而犯僧殘之外，若是牽線媒合親撫身體其餘部位，結偷蘭遮；若是媒合人道男子（男男媒合）或畜生等，皆結突吉羅。《五分律》說：對方不應允而回報者，結偷蘭遮。《十誦律》說：為不能男、不能女，或者道合一道女（產道直腸相通者）、石女等作媒，一律結偷蘭遮。本律中規定，若諸比丘透過白二羯磨（一白一羯磨的僧團表決），差遣人員為人作媒婚嫁，所有人皆犯僧殘。如今知事比丘向僧團表白，為淨人（寺院侍者）作媒娶親，提供籌辦婚嫁器具，並徵詢僧團一致和合通過，全體皆犯僧殘。若是挪用僧團常住物資，則同樣犯重罪。《摩訶僧祇律》說：如果為他人尋求良種公馬與母馬交配和合，結偷蘭遮；為其餘畜生作媒合，結突吉羅。《五分律》說：如果為男主人僱用女婢使女，結偷蘭遮；為女主人僱用男僕亦同。《十誦律》、《鼻奈耶得伽論》說：如果指著孕婦之腹預作媒約，以及為自己作媒者，結偷蘭遮。《四分律》說：做媒的方法包括以言語、書信、指印印信、差遣使者，只要彼此心意相通領會，互為參佐成句，全都構成違犯。如果比丘替俗人送信前往而不看信件內容，以及為在家人充當其餘差使，皆結突吉羅。《摩訶僧祇律》說：勸勉回娘家的婦女早日返回夫家者，結偷蘭遮。律中不犯的情況包括：如果男女雙方先前已經私通，後來分離，比丘令其重修舊好者，開許不犯。《十誦律》說：丈夫立下字據契約聲稱「這不再是我妻子」，但尚未在公眾場合唱名宣告休棄者，為之和合結偷蘭遮；如果夫妻禮儀恩義已絕，不再往來，而再去為之撮合者，結犯僧殘。律中開許替人送信的情形：如果是為了父母，以及具備正信精進的優婆塞（男居士）患病，或者身陷囹圄囚禁，以及為了佛、法、僧三寶之事，或為患病比丘之事等，查看信件後替其攜帶前往者，皆不犯。

【042-0002】01_行事鈔/06a_卷中之二#6
【原文】無主僧不處分過量房戒第六。具有五過：一須人經營，妨修道業。二《多論》云：長己貪結，壞少欲知足故。三處處乞覓，惱亂人非人二趣，不生信敬，壞滅正法令不久住故。四專任自由，不乞處分，容障僧事，多惱亂故。五或自損行，違其慈道，壞梵行故。六緣成犯：一無主，二為己，三自乞求，四過量不處分，五過量不處分想，六房成，結犯。《薩婆多》云：末後二摶泥未竟，輕蘭；餘一摶在，重蘭。《善見》云：若留一摶泥，在後當成，蘭；決罷心者，僧殘。《僧祇》：瓦木板石灰泥草覆，乃至最後一把草，覆竟即殘。若自受用，皆吉羅；房主若死、休道、施僧，乃可受用。律中，若作此房，先知無妨難已，然後來僧中乞法；若不可信，一切僧共往看之；若可信者，即當聽作。《善見》云：無妨難地處，平治如鼓面，後至僧中乞；長六搩手，廣四搩手已下，不須乞處分。《四分》云：長佛十二搩手內，廣七搩手。
【譯文】無主僧不處分過量房戒第六。造作此房具備五種過失：第一，需要耗費人力經營建造，妨礙修習道業。第二，《薩婆多毘尼毘婆沙》說：會滋長自己的貪愛結縛，敗壞少欲知足的美德。第三，四處乞討索求材料，惱亂人類與非人兩趣眾生，使人不生信敬之心，損毀正法令其不能久住。第四，專斷放任自憑心意，不向僧團乞求處分指授，容易阻礙僧團事務，引發諸多惱亂。第五，有時損害自己的德行，違背慈悲之道，敗壞梵行清淨。具備六個條件構成犯罪：一是指無檀越（施主）出資之房，二是為自己建造，三是親自四處乞求建材，四是建造超過限量且未經僧團羯磨處分，五是作超量且未經處分想，六是房屋建成，便結犯僧殘。《薩婆多部》說：建造塗泥時，最後兩摶（團）泥尚未塗完，結輕偷蘭遮；僅剩最後一摶泥未塗，結重偷蘭遮。《善見律毘婆沙》說：如果留下一摶泥，打算以後再完成，結偷蘭遮；如果內心決意到此停工罷造，便結犯僧殘。《摩訶僧祇律》說：無論是用瓦、木、板、石、灰泥或覆草建造，乃至最後一把草覆蓋完畢，房屋告成，當下即結僧殘。建造完成後如果自己入住受用，每宿皆結突吉羅；除非此房的主人死亡、還俗（休道），或者將房舍捨施給僧團，方才可以受用。律中規定，如果要建造這種房屋，應當先查明預定地沒有各種禍患妨害，然後來到僧團中乞求作法處分；如果造房比丘不可信，全體僧眾應當共同前往實地勘察；如果比丘為人可信，僧團便應當聽許其建造。《善見律毘婆沙》說：在沒有妨害災難的地點，把土地整平如鼓面一般，然後到僧團中乞請處分；若長度在六搩手、寬度在四搩手以下，則不須向僧團乞求處分。《四分律》規定：長度在佛的十二搩手之內，寬度為七搩手。

【譯文】有主僧不處分房戒第七。制戒意旨與前一戒相同。構成犯罪具備六個條件：一是有施主出資建造；二是為自己建造；三是建造長度在佛的六搩手、寬度在四搩手以上的房舍；四是未經僧團羯磨處分；五是作未經處分想；六是房屋建造完畢便結犯。這座房舍產權屬於比丘個人，若比丘去世，或遠走不再返回，隨其意願處分分配；若贈與三寶、親朋好友或在家人，或是自己賣掉換取錢財，皆可隨心自在處理；唯獨不得將地基土地變賣，因為土地是僧團常住物，僧團不允許變賣，房僧得罪。如果房主離去時自己未作處分吩咐者，房舍歸屬十方常住僧，由僧眾依戒臘次第居住。律中規定，若有妨礙處、危難處而造，得兩個突吉羅罪；就未向僧團乞求處分這一面而言，得一個僧殘罪。開許通融的情況：如果已向僧團乞求處分；或是建造草庵、樹葉庵，以及僅容己身的小屋，因為建築狹小所以無須乞求處分；若是建造供大眾居住的多人處所等，都屬合法律制。

【原文】無根重罪謗他戒第八。《多論》：為護自行，令法久住故；二為止謗毀，令梵行者，安樂修道故。問：謗他是妄語，得幾罪？答：《善見》云：無別提罪，以謗假虛成。今以義通，若元意專謗，無妄語墮；若兼誑僧，望前人得僧殘，望僧虛解得墮；如殺父羅漢，妄語兩舌，相對互說。餘如《戒本疏》。具八緣：一是大比丘及尼，除下三眾。二想心謂淨，不妨實不淨；如打破戒，犯墮。故文云：若遮無根無餘作，不成遮，治其謗罪。二謂作大比丘想。三內有瞋心。四無三根。五下至對一比丘說；《僧祇》：對所謗比丘前罵謗，語語僧殘。六者重事如誣。七言辭了了。八前人知，犯。《善見》云：若有謗他，在僧中請判者，僧未應判。若彼語僧，若不是者，我便不受；僧應語言：汝且禮佛，為其說法，後當為判此事。若遷延至暝者，當語明朝來。如是三反，猶剛強者，語云：此處少律師，不得斷，可往餘寺；彼餘寺僧知如是者，亦云：此無律師。如是覓寺不得，來還本寺，心懦折伏，隨僧教行者，方問被謗之僧，依法斷之。律不犯中，見、聞、疑三根說實。實有五種：一真實；二想實；三事實，如殺王還道殺王；四三根不互實；五四戒不互實。若反此五，謗他犯殘。《十誦》：四重互說成謗。《四分》亦同。
【譯文】無根重罪謗他戒第八。《薩婆多毘尼毘婆沙》說：第一是為了護持自身的德行，令正法長久住世；第二是為了止息誹謗毀辱，令修習梵行清淨之人得以安樂修習道業。問：毀謗他人本身就是妄語，這樣會得到幾種罪？答：《善見律毘婆沙》說：沒有另外結波逸提（單墮罪），因為這條誹謗罪本身就是假借虛妄誣陷而成立的。如今以義理融通來說，如果最初的本意專門在於毀謗，那就只有僧殘而無妄語的單墮罪；如果是兼帶有存心欺誑僧團的意圖，對被謗之人結犯僧殘罪，對僧團虛妄欺解則結單墮罪；這就像殺死既是父親又是阿羅漢的人，同時構成弒父與弒阿羅漢兩種逆罪；又如說出一句挑撥的假話，同時構成妄語與兩舌兩種口業——都是依相對境界、面對不同對象而分別結罪。其餘細節廣如《戒本疏》中所述。具備八個條件構成犯罪：一是受謗者為大比丘及比丘尼，排除下三眾（沙彌、沙彌尼、式叉摩那）。二是作大比丘想：毀謗者主觀意想中認為對方是清淨無犯的，即使對方事實上不清淨亦不影響本罪成立；正如故意擊破他人戒行，自身犯單墮罪。所以律文說：如果以無根由、無餘殘的重罪去遮止他人布薩，其遮止不能成立，僧團反而要治其無根誹謗之罪。三是內心懷有瞋恨憤怒之心。四是毫無見、聞、疑三種實質根由。五是至少面對一位比丘宣說；《摩訶僧祇律》說：若直接在被謗比丘面前當面咒罵毀謗，說一句便結一個僧殘罪。六是誣告的重罪事實毫無根據純屬誣陷。七是言辭表達清晰明瞭。八是對方聽聞理解，即結犯僧殘。《善見律毘婆沙》說：如果有僧人毀謗他人，來到僧團中請求裁判斷定，僧團切不可立即判決。如果那人對僧團說：「若判決不合我意，我便不接受！」僧團應當對他說：「你暫且去禮拜佛陀，僧團為你講說佛法，過後自當為你裁決這件事。」如果故意延宕到天黑，應當告訴他明天早晨再來。像這樣反覆三次，如果他性格依然剛強頑劣，僧團就對他說：「我們這裡缺乏精通戒律的律師，無法裁斷，你可以前往其餘寺院；」其餘寺院的僧人知道內情後，也同樣對他說：「我們這裡沒有律師。」像這樣四處尋覓寺院皆不可得，他無奈返回原寺，內心變得謙遜軟化、心悅誠服，願意聽從僧團教導奉行之時，僧團才去訊問被毀謗的僧人，依法公平裁斷。律中不犯的情況包括：基於見根、聞根、疑根而據實陳說。所謂「實」有五種情形：一是真正的事實；二是主觀意想為真實；三是客觀情節屬實，例如殺害了國王，據實說他殺害了國王；四是見、聞、疑三根之間互不混淆錯亂而屬實；五是四重波羅夷戒的罪名互不混淆錯亂而屬實。如果違背這五種真實，捏造誹謗他人便犯僧殘。《十誦律》說：將四重罪名彼此互換牽連誣指，即構成毀謗。《四分律》的規定也是如此。
