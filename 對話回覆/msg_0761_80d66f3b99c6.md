### 1. `mk_revise_materials.py` 第 62–63 行有兩個字串轉義 Bug ⚠️
看您新改的 `fixes_block(rt)`：
```python
_core = re.search(r'【逐句簡核】(.+?)(?=【必改硬傷】|\\Z)', rt, re.S)
_pre = ('【終審查證依據】\\n' + _core.group(1).strip()[:1500] + '\\n\\n') if _core else ''
```
* **Bug A**：`r'...'` 是 raw string，裡面寫 `\\Z` 會變成匹配字面上的「反斜線＋Z」，**不是結尾 `\Z`**（雖然正常都有 `【必改硬傷】`，但萬一終審漏寫 `【】` 就會匹配失敗而丟掉 `_pre`）。
* **Bug B**：`'【終審查證依據】\\n'` 是一般字串，寫 `\\n` 會在提示詞裡印出**字面的 `\n` 兩個字**，而不是換行！
* **建議改為**：
  ```python
  _core = re.search(r'【逐句簡核】(.+?)(?=【必改硬傷】|\Z)', rt, re.S)
  _pre = ('【終審查證依據】\n' + _core.group(1).strip()[:1500] + '\n\n') if _core else ''
  ```
