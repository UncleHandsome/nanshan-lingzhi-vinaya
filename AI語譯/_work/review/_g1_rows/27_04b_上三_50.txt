== PROBLEM ==
把律中「因為連續逢大月布薩而誤計滿歲（實則年仍不滿）」的非法受戒事由，徹底顛倒扭曲為「頻繁的大布薩會使不滿年歲的情形增多」。律中是指若連續逢三十日的大月布薩，不可擅自借此多出的日數虛增年歲；若強行以此算作滿二十歲受戒，佛判仍屬「年不滿受戒（不得戒）」。

== SUGGESTION ==
改為：「年齡不足二十歲的，必須核算在母胎中的月數與閏月；至於因連續逢大月布薩而藉機虛增歲數者，佛判定依然屬於年歲不滿（不得戒）。」

== ORIG ==
年不滿者，須論胎閏；頻大布薩，增不滿者。

== CURRENT ==
然而這並非明文規定，容許有多種不同的解釋；現在律師依義理判定，所以列在後面。問：依據確定不發戒，為什麼不稱作「難」呢？答：名字可以改稱，年齡可以等到滿。不同於永久的障礙，所以不歸入「難」所收。年齡不足的，必須討論胎中的時間與閏月；頻繁的大布薩，會使不滿年歲的情形增多。《五分律》中，先列出的是「遮」，制戒：僧眾不可隨便剃度。「或」字以下，其次說明不是「遮」的情況，制戒令僧眾提出詰難。《僧祇律》有多種，大致與《四分律》相同，略舉七種相狀。雀目也就是夜盲，即屬於「盲」一類之中。
