# 校閱材料　第339檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【339-0001】02_戒疏/02a_卷一上之二#122
【原文】【記】法寶中。指「如上」者，見釋名中。
【譯文】【記文】在法寶科判中。指稱「如上所解」，見於前文解釋三寶名稱的科判之中。

【339-0002】02_戒疏/02a_卷一上之二#123
【原文】【疏】「比丘僧」者，攬假成用也。「比丘」者，梵天本音名為「苾芻」，傳之訛偽，故致斯耳。
【譯文】【疏文】所謂「比丘僧」，是總合聚集眾多假名個體而成就其僧團總體功用的意思。「比丘」是西方印度的梵天正音，原本發音稱為「苾芻」，後世因為傳播翻譯的音韻訛誤，才演變成了「比丘」這樣的譯詞。

【339-0003】02_戒疏/02a_卷一上之二#124
【原文】【記】僧寶，初科。先示僧體。人無自體，五陰合集，號假名人。陰本無用，假人有用，總四人假，以為僧體，故云「攬假」。四人和聚，能辦前事，故曰「成用」。比丘是別，攬別成僧，故兩列之。「比丘」下，標名。《業疏》云：「或云煏芻。」
【譯文】【記文】在僧寶科判的第一段中。先指示僧伽的體質。單一的人身並沒有獨立實體，只不過是五蘊假合凝聚，名義上稱為「假名之人」。五蘊本身沒有功用，五蘊和合的假名之人卻有用，總括四個假名之人以為僧體，所以稱為「攬假」。四人和睦共聚，能成辦當前的羯磨法事，所以稱為「成用」。比丘是個別的分子，總聚個別的分子才能成就僧伽的總體，所以經文中將二者並列。「比丘」字以下，標明名稱的來源。《業疏》說：「也有音譯為『煏芻』的。」

【339-0004】02_戒疏/02a_卷一上之二#125
【原文】【疏】此方無人，以三義譯。一曰「怖魔」，或令魔怖。遵修三行，出三有也，由此義故，名之為「僧」。故《五分》云「為解脫出家，名為僧也」。二曰「乞士」，有二義故。上則乞法以練心，下則乞食以資身。得法奉持，驗以四教；受食觀厭，須離五邪。廣如常解。三曰「破煩惱者」，欲使依名思義，顧瞻有本，不至流俗，唯欣出要。故云「於我法中，快修梵行，盡苦源」也。
【譯文】【疏文】此方中土原本沒有這等清淨修道之人，因此依據其三種功德義理來翻譯。第一種稱為「怖魔」，或者稱為「令魔畏怖」。因為行者精進修持戒、定、慧三種清淨行持，誓願跳出欲界、色界、無色界這三界輪迴，正因為具備了這個殊勝意義，所以稱之為「僧」。因此《五分律》說「是為了追求究竟解脫而剃落出家，所以才稱名為僧伽」。第二種稱為「乞士」，這是因為具足了兩種義理：對上向諸佛如來乞討無上法藥來鍛鍊自心，對下向世間檀越乞求飲食資具來維持肉身。求得佛法之後信受奉持，必須以四依法來加以審察檢驗；接受世俗飲食供養之時必須作不淨之想以深生厭離，必須徹底遠離五種邪命的謀生手段。詳細行持正如平常律典所廣泛宣說的那樣。第三種稱為「破煩惱者」，這是為了使行者顧名思義，時時自我省察煩惱的根本深源，使身心不至於隨波逐流落入世俗名利，唯獨欣慕追求出離生死的究竟要道。所以佛說：『在我的正法之中，善修清淨梵行，斷盡痛苦的根本。』

【339-0005】02_戒疏/02a_卷一上之二#126
【原文】【記】義譯中，初科。上二句標示。「一」下，別釋，初義兩別。「怖魔」者，明其本志；「魔怖」者，約其功行。「魔」有四種：天、陰、惱、死。「遵」下，通釋二名。「三行」即戒、定、慧。「由」下，結名。「故」下，引證。此釋「比丘」，皆云「僧」者，以眾假別成，故別從眾號。次義中。「乞」即求義。「法」是道因，「食」乃道緣，因正緣傍，故分「上下」。「得」下，明二皆從正，方成此目。「四教」，即《涅槃》四依：一、依法不依人，二、依義不依語，三、依智不依識，四、依了義不依不了義。此四辨決邪正，行者依憑故。「五邪」者：一、為求利養，改常威儀，詐現異相；二、說己功德；三、高聲現威；四、說己所得，激動令施；五、為求利養，強占吉凶。後義中，初句示名。「欲」下，顯意。「依名」是聞，「思」義即思，「顧瞻」下是修：由此一名，克全三慧。「顧瞻」即觀察，「有本」即煩惱。「不至流俗」者，棄捨世樂故。「欣出要」者，高慕聖道故。「故」下，引證，即佛以「善來」度人之詞。初句生正信，次句修因，下句證果。「苦」是生死，「源」即煩惱。
【譯文】【記文】在義理翻譯的科判中，這是第一段。上面兩句是總體標示提示。「一」字以下，分別逐一解釋，第一種義理包含了兩種不同層面的表述。「怖魔」，是指行者初發心時誓斷生死的根本志向；「令魔怖」，是著眼於行者日後戒德圓滿、功行深厚時令魔宮震動的外在威德。「魔」分為四種：天魔、五陰魔、煩惱魔、死魔。「遵」字以下，通盤解釋這兩種名號的由來。「三行」就是指戒、定、慧三無漏學。「由」字以下，總結立名。「故」字以下，引用經論作為佐證。此處明明在解釋「比丘」，後文卻都結語稱為「僧」的原因，是因為僧團整體是借由個別比丘所組成的，所以個別成員隨順著整體的名號而共同受稱。在第二種義理中。「乞」就是乞求、追求的意涵。「佛法」是成就佛道的正因，「飲食」只是維持肉身修道的助緣，正因為法為正因而飲食為旁緣，所以在文意上劃分出「對上」與「對下」的高低層次。「得」字以下，說明求法與乞食這二者都必須歸於正道，才得以圓滿成就「乞士」的名號。「四教」，就是指《大般涅槃經》所載的「四依」：第一是依法不依人，第二是依義不依語，第三是依智不依識，第四是依了義經不依不了義經。這四種準則是行者用來辨別決斷邪法與正法的最高依憑。「五邪命」是指：第一是為了求取利養，故意改變尋常威儀，詐現奇特異相；第二是逢人宣說自己的修行功德；第三是大聲說話以顯現威嚴氣勢；第四是宣說自己有所證得，以此激動信眾令其布施；第五是為了求取利養，強行替人占卜吉凶。在第三種義理中，第一句標示出名稱。「欲」字以下，顯明立名的深遠用意。「依名」就是聞慧，「思義」就是思慧，「顧瞻」以下就是修慧：單憑「破煩惱」這一名號，就能完全具足聞、思、修這三慧。「顧瞻」就是指觀照審視，「有本」是指心中所依附積累的煩惱。「不至流俗」，是因為徹底捨棄了世間俗樂的緣故。「欣出要」，是因為一心高瞻仰慕出世聖道的緣故。「故」字以下，引述佛典作為明證，這就是佛陀當年在世以「善來比丘」度化善根之人出家的原話。第一句令其生起正信，第二句勸勉修持因地梵行，最後一句直指證悟究竟佛果。「苦」是指無邊生死輪迴之苦，「源」就是指無始以來的根本煩惱。

【339-0006】02_戒疏/02a_卷一上之二#127
【原文】【疏】又解：在因，名「怖魔」、「乞士」、「破煩惱」也；在果，名「殺賊」、「應供」及「無生」也。相對轉勝，故殊絕也。
【譯文】【疏文】又有一種解釋：在修行因地之時，分別稱為「怖魔」、「乞士」、「破煩惱」；到了果位證得阿羅漢之時，則對應稱為「殺賊」、「應供」以及「無生」。因地與果位兩相呼應，果德層層輾轉超勝，其境界是至極殊妙高絕的。

【339-0007】02_戒疏/02b_卷一上之二#1
【原文】【記】對果中，初文。果號阿羅漢，亦具三義，翻前三因。「殺賊」者，二惑盡故。「應供」者，是真福田，德堪物供故。「應」字平呼，謂相應也。「無生」者，苦報永亡故。因名己勝，果號復勝，故云「轉」也。
【譯文】【記文】在相對於果位的解釋中，這是第一段文。果位的名稱為阿羅漢，也同樣具備三種含義，對照翻譯前面的三種因位名義。『殺賊』，是因為見思二惑已斷盡的緣故。『應供』，是真實的福田，德行堪受一切眾生物資供養的緣故。『應』字讀平聲，意思是相應。『無生』，是因為苦果果報永遠滅除的緣故。因位的名稱已經十分殊勝，果位的名號更加殊勝，所以說是『轉』。

【339-0008】02_戒疏/02b_卷一上之二#2
【原文】【疏】問：「乞法練神，何不至果？」
【譯文】【疏文】提問：「乞求佛法以修鍊心神，為什麼這種行持不能延續到果位？」

【339-0009】02_戒疏/02b_卷一上之二#3
【原文】【疏】答：「如筏喻者，渡已不乘；藥為治病，病亡藥遣，若不除藥，又成深病。止得就因。形有資待，若從果德，應為物供。乃至因有惑可破，果無惑可生，例而知也。」
【譯文】【疏文】回答：「正如船筏的譬喻，渡過彼岸之後便不再乘坐；良藥是為了醫治疾病，疾病消除了藥物就應當捨棄，如果不及時除掉藥物，反而會積成重病。乞法修持僅止於因位。肉身仍有賴於物質的資助供養，如果順應果位的功德，就應當作為接受眾生供養的福田。乃至因位有煩惱惑障可破除，果位則不再有惑障生起，依此類推便能明了。」
