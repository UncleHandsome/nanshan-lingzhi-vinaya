# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

# 材料開始

# 校閱材料　第298檔
# 本檔編號一律為 298-NNNN，回報時整串照抄。

【298-0001】02_戒疏/15d_卷三下之三#7
【原文】【疏】問：「藥受過期限，不食是亦失；受日不出界，過限亦應失？」
【譯文】【疏文】問：「受藥如果過了期限，不吃便會失去受持法；受日出界若未出界，過了期限也應該失去受日法嗎？」

【298-0002】02_戒疏/15d_卷三下之三#8
【原文】【疏】答：「藥服為於病，病轉有期限。受日本為事，事在故法在。所以上明隨病一二日，乃至七日轉故也。」
【譯文】【疏文】答：「服藥是為了解決病苦，病況轉變本來就有期限。受日外出本是為了解決事情，只要事情還在，受日法就依然存在。這就是前文說明隨順病情一兩天，甚至隨病在七天內轉移的原因。」

【298-0003】02_戒疏/15d_卷三下之三#9
【原文】【記】三問。謂夏中受日未用，但使緣在，縱經多日，受法不失，藥法不同，故引比難。答中，因病加藥，病限即時，為事受日，事容延緩。「所」下，指前為證，即重受中《多論》、《僧祇》文也。
【譯文】【記文】這是第三問。意思是夏天受日外出如果還沒成行，只要因緣還在，縱然過了許多天，受日法也不會喪失；受藥之法與此不同，因此引來作比照問難。回答中指出，因病用藥，病情受限於當下；為了解決事務而受日，事情則容許延緩。「所以」以下，指出前文作為依據，也就是再次受持中引用《薩婆多論》和《摩訶僧祇律》的經文。

【298-0004】02_戒疏/15d_卷三下之三#10
【原文】【疏】問：「藥既說淨，過限失受，淨法在不？」
【譯文】【疏文】問：「藥既然已經作了說淨，過了期限而失去口受法，那麼說淨法還存在嗎？」

【298-0005】02_戒疏/15d_卷三下之三#11
【原文】【記】四問。謂至七日說淨，八日失受，疑謂淨法亦應隨失。
【譯文】【記文】這是第四問。意思是到了第七天作說淨，第八天失去口受法，於是懷疑說淨法是否也應該隨之失去。

【298-0006】02_戒疏/15d_卷三下之三#12
【原文】【疏】答：「有人言『受法雖失，淨法在故』。」
【譯文】【疏文】答：「有人認為『受持法雖然失去，說淨法卻依然存在』。」

【298-0007】02_戒疏/15d_卷三下之三#13
【原文】【記】初師中，初文，可解。
【譯文】【記文】在第一位論師的觀點中，開頭這段文意淺顯易懂。

【298-0008】02_戒疏/15d_卷三下之三#14
【原文】【疏】「若爾，淨依手、口受，本失末猶存；亦可約界結攝衣，解却大界衣界在？」
【譯文】【疏文】「若是如此，說淨法依附於手受與口受，根本的法既然喪失，枝末的法卻還留存；難道也可以類比於依照大界來結攝衣界，解除了大界之後，衣界還能繼續存在嗎？」

【298-0009】02_戒疏/15d_卷三下之三#15
【原文】【記】次科。淨法是能依，故為「末」；受法是所依，故為「本」。本既已失，末不應存。故比結界，義則相反。
【譯文】【記文】這是第二科。說淨法是能依，所以是「末」；口受法是所依，所以是「本」。所依之本既然已經喪失，能依之末就不應當留存。所以用結界來相比，道理剛好相反。

【298-0010】02_戒疏/15d_卷三下之三#16
【原文】【疏】有人解云：「不同解界：一、僧約有心解，二、衣必假大界。淨法不爾：受法任運失，故非作意捨；二、淨法不假於受法，是故受失而淨在。」
【譯文】【疏文】有人解釋說：「這和解除結界不同：第一、僧團解除結界必須作意；第二、衣界必須依賴大界才能成立。說淨法並非如此：口受法是自然隨時限喪失，並非作意捨棄；第二、說淨法不依附於口受法，因此口受法雖失，而說淨法依然存在。」

【298-0011】02_戒疏/15d_卷三下之三#17
【原文】【記】三中。初明解界，二義故失。次明淨法，反界二義，不可比同。衣界非大界不成，淨法無受法自立，故云「不假」等。
【譯文】【記文】在第三個段落中。首先說明解除結界，由於這兩種意義所以法隨之喪失。接著說明說淨法與解除結界有兩點相反，不可相提並論。衣界若沒有大界便不能成立，而說淨法沒有口受法也能自立，所以說「不依附」等語。

【298-0012】02_戒疏/15d_卷三下之三#18
【原文】【疏】有人云：「若第八日，相與俱失。既不任用，加淨免過。」
【譯文】【疏文】有人說：「如果到了第八天，口受與說淨應當一同喪失。這藥既然已不得再服用，當初加上說淨只是為了免除過失而已。」

【298-0013】02_戒疏/15d_卷三下之三#19
【原文】【記】次師，立理中。謂第七日說淨，至第八日淨法與受同失。「既」下，釋所以。上句明後失淨，下句顯前說淨，止免長過，非為久畜。
【譯文】【記文】這是第二位論師立論的段落。認為第七天作了說淨，到了第八天，說淨法與口受法便一同喪失。「既不」以下，解釋原因。上一句說明後來失去說淨法，下一句闡明先前說淨只是為了免除蓄長的過失，並非為了長久蓄積。

【298-0014】02_戒疏/15d_卷三下之三#20
【原文】【疏】「若爾，如犯捨戒猶須懺，比此口亡淨法在？」
【譯文】【疏文】「如果是這樣，就像犯了僧殘以下的諸罪，即使捨戒還俗，重受時依然需要懺悔；這難道不能拿來比照：口受法雖消滅，而說淨法依然留存嗎？」

【298-0015】02_戒疏/15d_卷三下之三#21
【原文】【疏】答：「受過俱無二法謝。此障猶存故須悔。又不同衣淨法存，所防在故法不失也。」
【譯文】【疏文】答：「受持與蓄長之過都已沒有，所以兩種法同時謝滅。但犯戒的業障依然留存，所以必須懺悔。這又不同於蓄衣時說淨法留存的情況，因為防範蓄長的因緣還在，所以說淨法不失。」

【298-0016】02_戒疏/15d_卷三下之三#22
【原文】【記】釋難中。謂如犯殘下諸罪，捨戒還家，後復重受，須懺先罪，彼既戒失而罪尚在，今口法失，淨法合存，如何隨失耶？「比」，謂相並。答中，初二句釋通，上句釋淨隨受失。「受過」文誤，古本作「彼過」，對下「此障」。由加淨法，俱無長過，所以受、淨二法俱謝。下句釋捨戒罪在。罪是業障，障不可亡，不隨戒失，故須後悔。「又」下，次遮妨。以前長衣淨法不失，恐引為難，先此通之。「所防」即長過。
【譯文】【記文】在化解問難的段落中。意思是如同犯了僧殘以下的諸多罪過，捨戒還俗之後又再次受戒，必須懺悔先前的罪過；那種情況既然戒法已失而罪過尚在，如今口受法雖失，說淨法理應留存，怎麼會隨之一同喪失呢？「比」字，是相提並論的意思。回答中，前兩句予以通釋，上一句解釋說淨法隨口受法一同喪失。「受過」在文中有誤，古本寫作「彼過」，用來對應下文的「此障」。由於作了說淨法，兩邊都已沒有蓄長之過，所以口受與說淨二法同時謝滅。下一句解釋捨戒後罪過仍在的原因。罪過屬於業障，業障是不會消失的，不會隨著戒體失去而消滅，所以必須在重受戒後懺悔。「又不同」以下，接著防範後續的詰難。因為前面說過蓄留長衣時說淨法不會喪失，恐怕會有人引用來作問難，所以先在這裡說通。「所防」就是指蓄長的過失。

【298-0017】02_戒疏/15d_卷三下之三#23
【原文】【疏】問：「淨財加受淨法謝，藥加淨法不失受者？」
【譯文】【疏文】問：「作了說淨的財物如果再加入受持法，說淨法就會謝滅；為何藥物作了說淨法，卻不會失去受持法呢？」

【298-0018】02_戒疏/15d_卷三下之三#24
【原文】【疏】答：「衣患無故淨法亡，藥患服故二法在。」
【譯文】【疏文】答：「衣服沒有疾病的患難，所以說淨法會消滅；藥物是為了患病服用，所以二法可以並存。」

【298-0019】02_戒疏/15d_卷三下之三#25
【原文】【記】五問。謂說淨財將作三衣，加受持法，即失本淨，反例藥說淨已，受亦合失。答中，「患」謂病患，衣無藥有，此則可知。
【譯文】【記文】這是第五問。意思是已經作說淨的布料若要製成三衣，只要加入受持之法，就會失去原先說淨的效力；反推過來，藥物既然說淨，受持法理應也要失去。回答中，「患」是指疾病患難，衣服沒有這層顧慮而藥物有，這道理顯而易見。

【298-0020】02_戒疏/15d_卷三下之三#26
【原文】【疏】亦不欲廣於問答，以費紙墨。欲開神慧，知持犯相。讀者思之，慎莫誦語，大悞人也。
【譯文】【疏文】我本來也不想把問答展開得太廣，以免浪費紙墨。只是希望能啟發修學者的心智，使其明了持犯的行相。讀者應當細心深思，切莫死記話柄，否則會大大地誤導他人。

【298-0030】02_戒疏/15d_卷三下之三#36
【原文】【疏】過前用四緣成：一、是己雨衣；二、時中得；三、過前持；四、過前用。
【譯文】【疏文】提前使用具備四種條件構成犯戒：一、是屬於自己的雨浴衣；二、在規定的時節內獲得；三、在規定期限之前受持；四、在規定期限之前使用。

【298-0031】02_戒疏/15d_卷三下之三#37
【原文】【記】過用緣中。二、「時中得」者，準此不犯前求，方犯後用。準《多論》犯過求者，過用但吉。前總義云「雨衣重犯」者，謂過用中隨用隨犯。
【譯文】【記文】在提前使用的條件中。第二點「在時節內獲得」，照此標準，必須是在沒有犯提前索求的前提下，才會單犯後面的提前使用罪。若依照《薩婆多論》，如果已經犯了提前索求，提前使用就只犯輕垢罪。前面總論中提到「雨浴衣重複犯戒」，是指在提前使用當中，每用一次就結犯一次罪。

【298-0040】02_戒疏/15d_卷三下之三#46
【原文】【疏】立法中四句。一、人。二、「春殘月」，求衣分齊。三、「浴衣」，制名相也。諸師解者多途，皆不可用。今西土來者，親自對之，還同三衣可披著也。故《僧祇》云「雨時披浴」，餘如《鈔》中。四、「半月」下，制用時節。《多論》云：「雨、熱時障身浴，無雨時裹三衣。若閏三月者，後三月十六日求。閏四月者，前四月十六日用，同安居也。」此土僧用全希，故略言也。
【譯文】【疏文】制定法度中有四句話。第一、明指所制之人。第二、「春殘月」，指索求雨衣的時間限度。第三、「浴衣」，是制定衣服的名稱與形相。歷代法師的解釋說法眾多，都不可採用。如今從西域前來的僧人，親自向他們求證，得知它依然如同三衣一樣是可以披在身上的。所以《僧祇律》說「下雨時披著洗浴」，其餘細節如《行事鈔》所載。第四、「半月」以下，是制定使用的時節。《薩婆多論》說：「下雨炎熱時用來遮體洗浴，不下雨時用來包裹三衣。如果遇到閏三月，就在後三月的十六日索求。如果遇到閏四月，就在前四月的十六日使用，原則與安居相同。」此地中國僧人極少使用此衣，所以略作說明。
