# 校閱材料　第309檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【309-0001】02_戒疏/01b_卷一上之一#48
【原文】【記】次示今義，明通中，初科。即顯本律通前二輪。下引律者，復見二輪非唯經論，用此兩通，攻前二局，則知未盡矣。指「如律」者，「五十一」中，佛於臘月十五日，從初一日至十五日，日日現通說法，令得歡喜。座上無數百千人遠塵離苦，得法眼淨。又《受戒》中，化三迦葉二十餘番現神變，後得見道。如提婆破僧，將五百人去，目連往現神通，舍利弗說法，諸比丘得法眼淨，同歸佛所。又如阿那律現通，化婬女得初果等。且略引示，律文更廣，故云「不少」。「見聖迹」者，獲果證也。
【譯文】【記文】其次開示本疏的正義，在闡明其圓通的段落中，此為第一科。此段旨在顯明《四分律》本體同樣涵蓋前兩種輪。後文引述律藏，也是為了證明前二輪並非經論所獨有，藉由這兩種皆具共通性的論點，來破除前面（三輪師）兩方面的偏局，便可知曉他們的立論尚不窮盡。所謂「指如律」，在《四分律》第五十一卷中，佛陀在臘月十五日時，從初一到十五日，每天都示現神通並宣說正法，令大眾心生歡喜。法座之上無數百千人由此遠離塵垢、出離痛苦，證得清淨法眼。又在《受戒犍度》中，度化三迦葉時示現了二十多次神足變化，三迦葉隨後得以見道。又如同提婆達多分裂僧團、帶走五百位比丘時，目犍連尊者前往示現神通，舍利弗尊者宣說正法，使這批比丘證得清淨法眼，共同回歸佛陀身邊。又如阿那律尊者示現神通，化度婬女證得初果等等。這些只是稍微引述舉例，律藏中的記載還要更為廣泛，所以說「其量不少」。「見聖迹」的意思，就是證獲聖果。

【309-0002】02_戒疏/01b_卷一上之一#49
【原文】【疏】夫解生由說，見理在心，故隨說悟，不待加勸。且機通利鈍，道假時來，泛說未明，故懷記憶，若不別示，情則浮疎。託境流言，乃存加念。念通事理，約行淺深，同遣縛緣，無非為道。
【譯文】【疏文】大抵說來，理解的生起是由於言語宣導，契會至理則在於內心觀照，因此利根之人往往隨著說法就能當下開悟，無須再額外施加勤苦的勸勉。況且眾生的根機通於利根與鈍根，得道必須假借時節因緣成熟，單憑泛泛宣說法義尚無法明了之人，所以必須在心中時常憶念修持；如果不個別加以開示警醒，其情識便容易流於浮躁粗疏。唯有依託於外在境界而宣示規誡之言，才能使人存心加以憶念用功。這份憶念通達於事相與理體，依照行持的淺深層次不同，共同目的都是要遣除繫縛身心的罪緣，無非都是為了成就無上道業。

【309-0003】02_戒疏/01b_卷一上之一#50
【原文】【記】正敘中。初敘利機聞說獲證。「且」下，正明鈍根必用懷念，初敘須意。「託」下，正立。「境」即事、理，事即戒緣，理即諦理。「流言」者，如前云「思惟」是等。「念」下，釋妨。前化行師即以二證別對三藏，故斥憶念言通於理。今明二證，專約律宗，行雖淺深，會歸一致故。云「同遣」等，即前所謂「制戒為道」，意可見也。
【譯文】【記文】在正式敘述的段落中。起初敘述利根之人聽聞說法即能獲證聖果。從「且」以下，正式闡明鈍根之人必須憑藉心懷憶念，起初敘述這份憶念的必要意趣。從「託」以下，正式確立正見。「境」指的就是事相與理體，事相指的是持戒的緣境，理體指的是四聖諦之理。「流言」，如同前面所說的「應當思惟這件事」等等。從「念」以下，化解疑惑妨難。前面的化行論師正是把事理二證分別配對到三藏之中，所以斥責憶念輪概念通向了定慧之理。如今闡明的事理二證，是專門就律宗來立論的，行持雖然有淺深之別，最終的歸趨卻是一致的。所以說「同遣」等等，即指前文所說的「制定戒律全都是為了修道」，其意趣於此顯而易見。

【309-0004】02_戒疏/01b_卷一上之一#51
【原文】【疏】問：「為道設教，乃是佛宗，斯通三輪，豈唯憶念？」
【譯文】【疏文】有人提問：「為了證道而施設教化，本是佛陀立教的通規，這種旨趣通貫於所有三輪之中，哪裡只是憶念輪專有的呢？」

【309-0005】02_戒疏/01b_卷一上之一#52
【原文】【記】兼正中，問。意謂既順初宗專用憶念，今言律藏通說三輪，義無所歸，故須問決。
【譯文】【記文】在兼顧通局正理的文段中，此為提問。其意趣是認為：既然順應第一家主張專門使用「憶念輪」，如今又說律藏普遍兼通「三輪」，在義理上顯得沒有定歸，因此必須發問以求決疑。

【309-0006】02_戒疏/01b_卷一上之一#53
【原文】【疏】答：「教門不壅，故是所通。然憶念輪，偏懷內眾。以俗居事亂，繁慮情多，何能靜處，思擇非業？但為說法，利者先開；於彼未悟，自為來習。不說憶念，以非學故。道則反俗，常有時功，近遣塵欲，遠清諸惑，若不念持，何能通會？」
【譯文】【疏文】回答道：「教門本身圓通無礙，所以律藏自然也通於前二輪。然而『憶念輪』的特質，是格外偏重關照出家內眾的。因為在俗之人居住於塵世、事務紛擾，思緒繁瑣、情執深厚，哪裡能夠身處寂靜之處，深細思擇非理之業呢？因此佛陀只對他們宣說正法，利根的人先開悟證道；對於那些尚未開悟的人，自然成為未來世的修行習氣。佛陀不對他們宣說憶念輪，是因為在俗並非以此為常軌學修的緣故。出家之道則與世俗相反，恆常具備專注用功的時節因緣，就近處言能遣除塵勞欲望，就深遠處言能洗滌清淨種種迷惑，若不用心憶念堅持，又如何能通達契會於道呢？」

【309-0007】02_戒疏/01b_卷一上之一#54
【原文】【記】答中。初二句明通者。如經論中，豈無憶念？善思正觀，徧見諸經。又上引律，具兼二輪，是則三輪徧該三藏，故云「不壅」。「然」下，顯局，初二句立定。「以」下，釋成。初敘經論局於二輪。「為來習」者，結因種也。「道」下，次明律藏唯在憶念。「塵欲」即業非，在因故「近」。「諸惑」即總五住，望果故遠。
【譯文】【記文】在回答的段落中。最前兩句說明其通貫的道理。如同經藏與論藏之中，難道就沒有憶念修持嗎？善加思惟、正念觀照，普遍見於各部經典。又如上文引述的律文，本來就兼具神足、說法二輪，由此可知三輪普遍涵蓋了經律論三藏，所以說「教門不壅」。從「然」以下，顯明律藏的特殊局限性，最前兩句立定論點。從「以」以下，解釋促成這個論點的理由。起初敘述經論在對機上局限於神足與說法二輪。「為來習」的意思，是結下未來的善因種子。從「道」以下，其次闡明律藏唯獨偏重在憶念輪。「塵欲」指的就是造作惡業的過非，由於屬於因位所以說是「近」。「諸惑」是總括了五住地煩惱，相望於果位而言所以說是「遠」。

【309-0008】02_戒疏/01b_卷一上之一#55
【原文】【疏】近復有人立三種教：一、唯制道教，即篇聚所列十、具戒等；二、唯制俗教，即五、八戒在家行宗；三、通道俗教，即四含、雜藏。
【譯文】【疏文】近代又有人立出了三種教法：第一、「唯制道教」，也就是律篇律聚中所排列的沙彌十戒、比丘具足戒等；第二、「唯制俗教」，也就是作為在家修行宗要的五戒與八關齋戒；第三、「通道俗教」，指的就是四部《阿含經》與《雜藏》。

【309-0009】02_戒疏/01b_卷一上之一#56
【原文】【記】次引餘義，正明中。初列三種，前二皆制。「制」名雖通，機教兩別，所以分之。後一是化，名及機教，一切俱通。「四含」為四，「雜藏」是一，名為五藏。據前化制，五、八二戒，攝局化中。今此所立，不異於前，但離「五」、「八」別為一教耳。
【譯文】【記文】在其次引述其餘見解、正式說明的段落中。首先列出這三種教法，前兩種全屬於「制教」。「制」的名稱雖然相通，但領受的根機與教法各有不同，所以將它們拆分開來。最後一種則是「化教」，無論名稱還是根機與教法，全部兼通道俗二眾。「四阿含」算四種，《雜藏》算一種，合稱為「五藏」。依照前面化制論師的看法，五戒與八戒是局限收攝在化教之中的。如今這家所立之論，實質上與前面沒有不同，只不過是把五戒與八戒抽離出來獨立成為一門教法罷了。

【309-0010】02_戒疏/01b_卷一上之一#57
【原文】【疏】問：「如律所明，具通俗行，如何橫判以為道教？」
【譯文】【疏文】有人提問：「如同律藏中所闡明的那樣，完全兼通了在俗之人的修行，怎麼能武斷橫加判定說律藏僅僅是『制道教』呢？」

【309-0011】02_戒疏/01b_卷一上之一#58
【原文】【記】釋妨中。意以《律本》亦明觀行及五八戒，是則律文兼通二教，不唯制道，則乖前判。
【譯文】【記文】在解除疑惑妨難的段落中。提問者的意思是：《四分律》本體中也闡明了觀行修法以及五戒、八戒，如此一來律文便兼通了後兩種教法，並非唯獨制約出家人，這就與前面的判定相違背了。
