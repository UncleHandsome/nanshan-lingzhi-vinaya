# 校閱材料　第223檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【223-0001】資持記/02b_上一下#50
【原文】文出〈說戒揵度〉。必先設座，後方鳴鐘；疏云：由聲告即集，床座未施，佇待悽惶，非成㢡務；制先定座，良在茲也。制法中，初緣起。佛言下，立制，初列示四相。使下，明能打人。不下，明打法。三通如後說。吹螺倣上打人，故云亦爾；彼云沙彌守園人吹。除下，簡物。
【譯文】這段文字出自〈說戒揵度〉。必須先陳設布置座位，然後才能鳴擊鐘磬；《羯磨疏》說：因為聲音一宣告大眾便立即集合，如果床座尚未鋪設完畢，讓大眾久立等待心生倉皇，就不能成就恭敬威儀的法務；制定必須先鋪設好座位，深意確實就在這裡。在制定鳴鐘法則中，最初先說明緣起。佛說「佛言」以下，確立律制，首先列舉開示了四種相狀。「使」字以下，說明可以負責敲擊的人選。「不」字以下，說明敲擊的節奏方法。敲擊三通的打法如同後文所說。吹海螺的規定依循上述負責敲擊的人選，所以說「亦爾」（也是如此）；該律說由沙彌或看守園林的人負責吹螺。「除」字以下，淘汰不可使用的木料。

【223-0002】資持記/02b_上一下#51
【原文】漆毒樹，相傳云恐傷手故。上明布薩時。若下，明大小食時。住處多者，別房散遠故。若下，明開許。疏云：此召僧法制，非具道者所為；必無二人，方聽兼助也。明俗打中，初引背請戒文。彼明居士作食持入祇桓打犍槌；諸比丘問，答云請比丘食耳。乃至下，出提舍中，初句出第二戒。
【譯文】漆樹和有毒的樹木，相傳是因為擔心其汁液或毒性會損傷人手的緣故。以上是說明舉行布薩（說戒）時的召集方式。「若」字以下，說明早齋與午齋小食、大食時的敲擊法。所謂住處眾多，是因為個別僧房分散偏遠的緣故。「若」字以下，說明開許的特殊情況。《羯磨疏》說：這是召集僧眾的威儀法則，本來就不是具足戒品的高僧所應親自操作的雜務；必須在僧團完全沒有沙彌或在家人這二類人的情況下，才開許由比丘親自兼任協助敲擊。在說明在家人敲擊的內容中，首先引用「背請戒」的經文。那裏說明居士做好了飲食，帶進祇園精舍敲擊犍槌；諸位比丘前來詢問，居士回答說只是要請比丘用餐而已。「乃至」以下，出自波羅提提舍尼法中，第一句出自第二條戒。

【223-0003】資持記/02b_上一下#52
【原文】彼因居士請佛及二部僧；明日食至，晨朝敷座，遣使白佛時到。〔此證唱令。〕及下，出第四戒。彼云諸女持食入僧坊，打犍槌與僧分食等。中食下，未詳何文。道打中，初文。出彼十六。佛在舍衛鹿母園中，夏竟受歲，令阿難打之。此是下，即阿難語。信鼓者，於事則告眾有期，在法則歸心無二。
【譯文】那是因為居士迎請佛陀以及比丘、比丘尼二部僧團；第二天用餐時間到了，早晨鋪設好床座，派使者前去向佛陀稟告用餐時辰已到。〔這是用來證明口頭宣告唱令的方式。〕「及」字以下，出自第四條戒。該律說有一群婦女帶著飲食進入僧舍，敲擊犍槌召集僧眾來分派飲食等等。至於「中食」以下，尚不清楚是出自哪一部經文。在出家人敲擊的段落中，第一段經文出自該律第十六卷。佛陀在舍衛國的鹿母講堂中，夏季結夏安居結束舉行自恣受歲時，命令阿難尊者敲擊犍槌。阿難所說「此是」以下，就是他的唱告辭。所謂信號之鼓，在事相上能讓宣告大眾集合有固定的期約，在法理上則能讓大眾歸向道心純一無二。

【223-0004】資持記/02b_上一下#53
【原文】鼓謂擊動發聲，名通鐘磬。《十誦》，緣起闕事有八，四段明之。無人下，即闕作相；正是今用，下並因引。又下，即闕作務。及下，是闕指授；彼作苦酒中蟲，今言食者，改局從通。飲下，即闕理眾。佛下，明立法。顯上作相，比丘為之。〔又準行水亦通比丘。〕下引他文釋名可了。通意中。
【譯文】「鼓」的意思是指擊打震動發出聲響，這個名稱通於鐘與磬。《十誦律》中，記載因為缺乏作法而產生延誤緣起的事由共有八項，分四個段落予以說明。「無人」以下，就是指缺乏發出信號的相狀；這正是我們現在所要引用的核心，下方內容都是順帶引述。「又」字以下，是指缺乏出坡作務的宣告。「及」字以下，是指缺乏指導講授的時機；原律寫的是苦酒（醋）中長了小蟲，現在鈔文改寫為「食」，是變更狹隘的字眼而順應通俗的說法。「飲」字以下，是指缺乏調理大眾作息的信號。從「佛」字以下，說明制定法規。由此顯明上述發出信號的動作，在必要時比丘也可以親自執行。〔又依照律制，行水供僧之事也通於開許比丘親自為之。〕下方引用其他文獻解釋名稱，便能清楚明瞭。在通攝意義的段落中。

【223-0005】資持記/02b_上一下#54
【原文】律列八種，第三打地作聲；今略為七，未詳何意。量影者，謂剋時令集。八中，烟影是色，餘六是聲。又唱告是情，餘並非情。亦下，示通。此明律不局道，意彰通俗。上引諸文，證定能打，乃是暗破當時妄執。《尼鈔》云：今時諸寺僧尼立制，不許沙彌白衣打鐘，此迷教甚矣。梵號中。
【譯文】該律列出了八種作信號的方法，第三種是敲打地面發出聲響；現在鈔文簡略歸納為七種，尚不清楚是基於什麼用意。所謂「量影」，是指以日晷測量日影來克定時間使大眾集合。八種方法中，煙霧與日影屬於色法顯相，其餘六種則屬於聲音。此外，以言語唱名宣告屬於有情眾生之法，其餘各項則都屬於無情之物。「亦」字以下，顯示通融兼用的原則。這是說明律制並不局限於出家人操作，用意在彰顯亦可通於在家人。上面引述的各種文獻，證明確認了凡此各類人（包括沙彌、淨人、居士、婦女等）皆能負責敲打，這其實是在暗中破除當時世人虛妄執著的偏見。《尼鈔》說：現在許多寺院的僧尼擅自立下規矩，不准許沙彌與在家人敲鐘，這真是對佛陀教法太過深沉的迷昧啊。在梵語名稱中。

【223-0006】資持記/02b_上一下#55
【原文】若諸律論，並作犍槌，或作犍稚，如字而呼，乃是梵言訛轉，唯獨《聲論》正其音耳。今須音槌為地。又《羯磨疏》中直云揵地；未見稚字呼為地也；後世無知，因茲一誤，至於鈔文前後，以及一宗祖教，凡犍槌字並改為稚，直呼為地；請尋古本寫鈔，及大藏經律考之，方知其謬。
【譯文】如果查閱各部律論，大多寫作「犍槌」，或者寫作「犍稚」，如果照著字面直接發音，那只是梵語在流傳中的音譯訛誤，唯獨印度《聲論》才匡正了它的準確讀音。現在讀這個字必須把「槌」讀作「地」的音。又《羯磨疏》中直接寫作「揵地」；從未見過把「稚」字讀成「地」音的；後世的人無知，因為這一個文字上的誤傳，以致於鈔文前後各處，乃至整個律宗祖師的遺教之中，凡是出現「犍槌」兩個字的全都被擅自改為「稚」，並直接讀成「地」；請去查閱古本抄寫的鈔本，以及大藏經中的律典原文互相比對考證，才會明白這種改動的荒謬。

【223-0007】資持記/02b_上一下#56
【原文】但以稚椎相濫，容致妄改；今須依律論並作犍槌；至呼召時，自從《聲論》。〔或作椎亦爾。世有不識梵語，云是打鐘之槌及砧槌等，此又不足議也。〕若準《尼鈔》云：西傳云：時至應臂吒犍槌；臂吒此云打，犍槌此云所打之木，或用檀桐木等；彼無鐘磬，故多打木集人。
【譯文】只不過因為「稚」與「椎」字形容易混淆，所以才容許引發了這種妄自修改；現在必須依照各大律論統一寫作「犍槌」；等到開口呼喚召集時，讀音自然隨從《聲論》讀為揵地。〔或者寫作「椎」也是同樣的道理。世間有人不懂梵語，誤以為是指敲鐘用的木槌或者砧槌等器物，這種淺見就更不值得拿來討論了。〕如果依照《尼鈔》的說法：西域傳來說法道：時辰一到應當「臂吒犍槌」；「臂吒」翻譯為擊打，「犍槌」翻譯為所擊打的木頭，或者使用檀木、桐木等；印度當地沒有金屬鐘磬，所以多半擊打木板來召集僧眾。
