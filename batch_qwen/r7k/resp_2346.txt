整體看，這批譯文對疏文與注文的理解方向是正確的，「前」字在不同段落所指（#50 指訶責、#56 指前四羯磨、#58 指不見舉）都補對了，「眾表＝眾外」也與 #48「中表即內外」的訓解一致，這些都值得保持。以下按條列出需要修正或可斟酌之處，並標示輕重。

## #48

1. **【需補】「十七已下八種，即四羯磨治罰法」**
 譯文「共八種法，就是四種羯磨治罰法」，讀者會困惑「八為何等於四」。宜補括註：
 → 「第十七項以下共八種，就是四種治罰羯磨（每種各連同『解法』，故成八種）。」

2. **【需改】「彼皆破言不破」**
 關鍵在「皆**破**」——事實上已破，口裡卻說不破。現譯「犯者都反過來稱自己沒有破犯」把「實破」略掉了。
 → 「他們其實都已破犯，卻口稱沒有破犯，所以叫『倒說』。」

3. **【可斟酌】** 「道眾僧倫」語意重疊（道眾＝僧眾），作「對內染污僧眾」即可。
4. **【一致性】** 「倒說」此處譯「顛倒其說」，#49、#50、#56 譯「顛倒妄說」。建議統一（如「顛倒而說」），並固定加引號。

## #49

1. **【需改】「宜須長信」的對象**
 是「比丘住在聚落，應令**俗人**信心增長」。現譯「理當增長信眾的正信」易被讀成增長自己的信；「正信」也是添字。
 → 「既然住在俗人聚落之中，理應使俗人的信心增長。」
2. **【可斟酌】** 「聚落」譯「城鄉村落」，「城」屬添字，作「村落／聚落」即可。
3. **【可斟酌】** 「壞亂俗心」→「敗壞擾亂俗人的信心」；「信向之心」稍生硬。
4. **【可斟酌】** 「流習難革」→「流弊積習難以革除」（「惡濁」為添譯）。
5. **【可斟酌】** 「準前為解」可補「準照前面（訶責）的解法」，與 #50 呼應。

## #50

理解無誤。可更貼近：「只是就（污家）面對俗人這一點，與前面（訶責）不同罷了。」

## #51

1. **【需改·文字】** 「與依止羯磨**與**解除法」贅一「與」→「與依止羯磨及其解法」。
2. **【需改】「既無志度」**
 「志度」是志向、器度（無立志向上之量），現譯「無力自我約束修持」偏於解釋，且與上句「纔懺還犯」意思重複。
 → 「既然沒有志向器度（不能自立向上），僧團便制令他依止明達有德之師。」
3. **【需改】「令識沈浮」**
 下一條注文已明說「沈浮即善惡」，此處譯「辨識善惡沉浮」把譬喻與實義疊在一起。
 → 「使他認識善惡（沉浮）」，或直譯「沉浮」並留待 #52 解釋。
4. **【可斟酌】** 「盡形修學」→「盡形壽（終身）依止修學」，把「依止」補回更完整。

## #52

無誤。

## #53

1. 理解正確（「既忿再面，耻更謝愆」指比丘不願再見面、以再度謝罪為恥）。
2. **【可斟酌】** 「不許不至」保留雙否定很好，可再加一句白話說明：「即強制他必須到白衣家懺謝。」
3. **【可斟酌】** 「遮其煩憤」的「其」指比丘，譯文可從；若要嚴謹，可註明「藉強制謝罪以止息其瞋惱（兼可平息白衣之憤）」。
4. **【可斟酌】** 「失出世法」→「有失出家人出世之道的體統」。

## #54

無誤。

## #55

1. **【需改·邏輯】「且信為道源，又為德母，必懷邪信」**
 原文是推理：信既是道源德母，而他反說不見罪，可見必懷邪信。現譯兩句平列，因果斷裂。
 → 「況且信是修道之源、功德之母；（他竟反說不見己罪，）可見他必定心懷邪信，因此須作舉法治罰，棄置於大眾之外……」
2. **【需改】「德行之慈母」**
 《華嚴》原句為「信為道元功德母」，「慈」是添字 → 「功德之母」。
3. **【可斟酌】** 「亦絕僧務」→「並且斷絕他參與僧事（不得預僧數、僧利）」；「之權」屬現代化增語，可省。

## #56

1. **【需補】** 同 #48，六種＝三舉＋三解，宜加括註。
2. **【需改】「而言不見有罪」**
 「而」在此是對比（前四說「不破」，此則說「不見有罪」），現譯「而且堅稱」讀成並列，「堅稱」也是添譯。
 → 「這也是顛倒四事而說，只是說成『不見有罪』。」
3. **【可斟酌】** 「此壞正信」的「徹底」可刪；「但加責罰」作「只加以責罰」即可（「訶責等」略窄化）。
4. **【可斟酌】** 《華嚴》補「經」字可，若求嚴謹可註出「信為道元功德母，長養一切諸善法」。

## #57（問題最集中）

1. **【需改】「今冐染大度」漏了「染」**
 依 #58 元照自釋「雖學大教，言行相違，故云冒染」：「冒」＝假冒（冒充學大乘），「染」＝內懷染污。現譯只作「妄自冒充豁達大度」，「染」義落空，且與 #58 保留「冒染」不譯的處理不一致。
 → 「如今卻以染污之心冒充大乘的豁達大度，妄說罪福本空，內心實與世俗染著無異，全不想洗滌蕩除。」
2. **【需改·術語】「義同不足」**
 「不足」即律中「不足數」，宜加短註：「義同『不足數』（不列入僧數，不得預僧事、僧利）」。
3. **【可斟酌】** 「偏非道務」譯「全非修道之正業」，「正業」易與八正道之「正業」混 → 「全不是修道者應為之事」。
4. **【可斟酌】** 「更作法收」譯「另作羯磨法收納回來」，「另作」易誤解為別一種羯磨 → 「再依作法解除、收攝歸眾」。

## #58

1. **【需改·添義】「但知心空，不知心有」**
 現譯「只知心性本空，不知心用（因果）是有」加入了體用架構，原文無此。
 → 「只知心空（之理），不知心有（因果業報之事）。」
2. **【需改·用詞】** 「多墮此見」譯「頑空偏見」，「頑空」偏指斷滅無知，此處元照批的是偏執於空 → 「偏空之見」較貼切。
3. **【需加註】「玅有則一毫不立，真空乃因果歷然」**
 譯文照字面沒錯，但這是空有互奪互成的表述，讀者極易誤以為前後錯置。建議保留對句並加註：
 → 「由此可知：真正的『妙有』一毫不立，真正的『真空』卻因果歷然。」
 註：妙有即真空之有，故不立一毫；真空即妙有之空，故因果分明——非謂「有」中無因果、「空」中有因果。
4. **【可斟酌】** 「有犯不解」→「有犯而不肯懺悔除罪」，比「懺解」白話。
5. **【可斟酌】** 「還成偏計」的「妄想」為添譯（遍計所執本即妄計），可精簡為「仍舊成了遍計所執」。
6. **【建議查核】** 「智者云」可註「智者大師（智顗）」；引句「業性雖空，果報不失」若能查得出處（天台止觀類文獻）宜補註。另《梵網》引文用字可與今本核對（一般作「口便說空，行在有中」），保留疏文原引即可，必要時註明異文。

**A. 必改清單**
- #57「冒染」的「染」義補足，並與 #58 統一處理方式。
- #48「皆破而言不破」的「實破」要譯出。
- #55「信為道源德母 → 必懷邪信」的推理連接詞補上；「慈母」改「功德之母」。
- #51「既無志度」回歸「志向器度」；「令識沈浮」與 #52 分工。
- #56「而言不見有罪」的「而」作轉折。
- #48、#56 補「四羯磨＋四解＝八」「三舉＋三解＝六」的括註。
- #58「不知心有」去掉體用添義；空有對句加註。
