# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第四量如者此律大盋受三斗小者斗半中器可知母論云若不滿斗半及過三斗者不成受持義云此之升斗諸方用各不定未可準定將古類今上盋受一斗下者五升中者可知然佛初出世人形姝大所食亦多故限五升以為楷定今經像季人形漸小若定行斯良恐非用故五分云隨方國土雖是我語不為清淨者不行無過雖非我語於餘方清淨者不得不行又盋名應器須應其身大小準食之故下律云量腹而食度身而衣趣足而已不得見有此判遂畜小小之者若不滿四升已上定不得受僧盋不滿五升已上定不成持數見尼等受持四升已下故別標記。
【譯文】第四、容量合乎規定（量如）：本律規定，大缽可容納三斗，小缽容納一斗半，中缽容量介於兩者之間即可知曉。《毗尼母論》說：如果容量不滿一斗半，或超過三斗，都不能算受持成功。律義分析：這裡所說的「斗升」，各個時代地方度量標準不同，不能硬套古制；若以古度量折合今日，大缽約受一斗，小缽約五升，中缽亦可比照。然而佛陀初出世時，人身體格高大，食量也大，因此以五升作為下限標準；如今進入像法末世，人的身形漸趨矮小，如果硬要推行古代的大標準，恐怕無法實際使用。所以《五分律》說：在隨方國土中，雖然是佛陀親口說的規定，若在當地不能達成清淨實用，不實行也無過失；即使不是佛陀親口說的規定，在其他地方如果有利於保持清淨，則不得不遵行。再者，缽既然叫作「應器」，就必須應合個人的身量大小以盛裝適量的飲食；所以下文律文說：「衡量自己的食量而進食，度量自己的身材而穿衣，能滿足所需即可。」不能因為看到這條開許，就一味蓄存極小的缽；若容量不滿四升以上，絕對不可作為僧缽受持；若不滿五升，絕對無法成立僧用應量缽的受持數額；因為常見有比丘尼受持四升以下的極小缽，所以特別在此註記糾正。

【587-0009】04_比丘尼鈔/02b_卷上之下#46
【原文】第一施主者有二一展轉二真實真實希故不論今且明展轉法於中簡別對施有五一衣二藥三盋四寶五穀米前三施主依僧祇善見於五眾中隨得一人作展轉施主後二竝以俗人為淨主涅槃經云雖聽受畜錢寶等物要須淨施篤信檀越婆論云先求一知法白衣為淨主五分云有四種人不為展轉淨施主一不讚歎人二不與人好名稱三應淨施五眾四不得與白衣婆論云應相前人持戒多聞有德而作施主後得物時於一比丘尼邊稱施主名說淨僧祇十誦五分等竝不得對施主而說亦不應令前人知直別處對一人說。
【譯文】第一、物主的資格（施主）：施主有兩種：一是轉手替換的「展轉施主」，二是實質將物給予的「真實施主」。真實施主較為罕見，在此暫且不論，現先說明展轉施主法。在這之中，針對不同物品的施主有五類分別：一衣、二藥、三缽、四財寶、五穀米。前三種（衣、藥、缽）的施主，依《僧祇律》與《善見論》的規定，在出家五眾之中隨便請一人即可作為展轉施主；後兩種（金銀寶物、穀米食糧）則都必須以俗人作為淨主。《涅槃經》說：雖然開許出家人蓄存錢寶等物，但必須經由虔敬篤信的在家檀越為其作淨施。《薩婆多論》說：應先尋找一位懂得戒律法則的在家人作為淨施主。《五分律》提到：有四種人不可作為展轉淨施主：一是不懂得隨喜讚歎他人者，二是不給他人留好名聲者，三、應當對出家五眾作展轉淨施；四、不可給予白衣作展轉施主。《薩婆多論》說：應當審慎觀察對方是位持戒、多聞且有德行的人，方可請其擔任施主；日後獲得長物時，對著身邊另一位比丘尼稱呼該施主的名字來作說淨。《僧祇律》、《十誦律》、《五分律》等都規定：不得當著施主本人的面直接對他作說淨，也不應讓施主知悉此事，只需在別處對著另外一人依法宣說即可。

【587-0025】04_比丘尼鈔/02b_卷上之下#62
【原文】第五失法者婆論云若死更求施主除錢寶糓米等自外一切長財盡五眾邊作淨義準錢寶等俗人淨主存亡同前此律若忘不說淨或賊奪失想等難多日不犯長若失五日後時憶得更經五日說淨亦得若得衣十日至第十日冥忘不說後時憶得即須當日說淨不爾犯捨墮十誦云忘後五日得所忘衣更得十日說淨婆論云若說淨財寶及以衣財若人貸之後時寶還寶錢還錢乃至衣財相當還者不須說淨不相當者更須說之若補衣物不滿尺六狹八寸者亦犯長故婆論云若先不應量衣此衣盡捨作突吉羅懺母論云惡比丘尼不說淨者入手即犯不須至十日婆論云若得新鞾應令白衣著行五七步即是淨五分得新履令淨人著行七步。
【譯文】第五、失效的界線（失法）：《薩婆多論》說：如果展轉施主過世，必須重新尋找施主更換；除了錢寶、穀米等物之外，其餘一切多餘長財，都必須在出家五眾處作說淨；依此推論，作為錢寶淨主的在家人，其生死問題亦比照上述辦理。本律規定：若因遺忘而未及時說淨，或者因遭遇盜匪劫奪、生起丟失想等危難，多日未說淨並不犯長物罪；若遺失了五天後重新尋獲，還可以再有五天的寬限期來作說淨。如果獲得長衣剛好十天，到了第十天夜晚忘記說淨，日後回想起來時，必須在當天立即補作說淨，否則便會犯捨墮罪。《十誦律》說：遺忘之後經過五天重新找回失衣，從尋得當日起算，還可以再有十天的說淨期限。《薩婆多論》說：如果原本已說淨的財寶或布料被他人借走，日後歸還時，只要是金寶還金寶、錢還錢，乃至布料品質尺寸相當對等歸還，就不需要重新說淨；若歸還的物品與原物不相當，就必須重新作說淨手續。若是拿來補衣服的布料，長不足一尺六寸、寬不足八寸，若私存超過十日也犯長物罪；所以《薩婆多論》說：如果原本持有不合規定尺寸的衣物，應將這些衣物完全捨除，並作突吉羅懺悔。《毗尼母論》說：存心不良的比丘尼故意不作說淨，物品一經入手便立即結罪，不需要等到十天期限屆滿。《薩婆多論》說：如果獲得了新皮靴，應當先讓在家人穿著走上五至七步，這樣就算是如法作淨了。《五分律》說：獲得新鞋履，應當讓淨人穿著走上七步。
