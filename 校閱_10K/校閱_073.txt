# 校閱材料　第073檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【073-0001】01_行事鈔/04c_卷上之四#25
【原文】二明衣體。《四分》云：若得新衣，若檀越施衣，若糞掃衣，新物揲作淨。若已浣，浣已納作淨。即日來不經宿。不以邪命得，不以諂曲得，不以相得，不以激發得，不捨墮。作淨者，應法四周有緣，五條作十隔；若過是條數，應自浣染、舒張、碾治，裁作十隔縫治。又云：不得大色染衣，聽用袈裟色。《十誦》：若不割截、減量作、不揲四角，若故爛壞、覆死人衣、到塚取來者，及曾已受作迦絺那衣，並不成；若揲葉衣，得成。《摩得勒伽》云：死比丘受用三衣及故衣，不成；若急施衣、時衣，成受。《僧祇》：未曾受用三衣得作。《五分》：若浣染打縫不如法，若小，若大，若錦綺衣，若未自恣竟受，若貪利養故捨五事，皆不成；反上成受。《善見》：若七眾衣，得受；若三衣中隨受一二，得。《四分》：必須編邊、安紐、作鉤，成受。
【譯文】第二說明衣體（作迦絺那衣的布料或衣物本質）。《四分律》說：如果得到新衣料，或是施主布施的衣，或是糞掃衣，若是新布料則需貼補襯邊（揲）來作淨法；如果已經洗過，洗後需縫綴密刺作淨法。必須是當天送來而未曾過宿的。不得以邪命方式獲取，不得以諂曲諂媚獲取，不得以現相暗示獲取，不得以激發言詞獲取，也不得是犯捨墮之衣。製作如法淨衣者，合法的規格應當四周縫有緣邊，五條裁剪為十隔（五條衣相）；如果超過這個條數，應當自己洗滌、染色、展平舒張、碾平熨治，裁剪縫製成十隔。又說：不得用純濃的正色（大色）染色，聽許使用袈裟色（如法壞色）。《十誦律》說：如果不加割截、減少尺寸規格製作、沒有補綴四角，如果是破舊爛壞、覆蓋死人的布、從墳塚中取來的，以及曾經已經受作過迦絺那衣的，都不能成就；如果是重疊碎布葉縫綴的衣（揲葉衣），則可以成就。《摩得勒伽》說：已故比丘生前受持使用的三衣以及舊衣，不得用來成就受衣；如果是急施衣、時衣（應時施衣），則能成就受衣。《僧祇律》說：未曾受用過的三衣可以用來製作。《五分律》說：如果洗滌、染色、捶打、縫綴不如法，或者太小、太大，或者是錦緞華綺之衣，或者尚未自恣完畢就受衣，或者為了貪圖利養而故意捨棄五事利益，都不能成就；反之上述情況則能成就受衣。《善見》（《善見律毘婆沙》）說：若是佛門七眾所施之衣，都可以受用；若是三衣中隨意受其中一種或兩種，也可以。《四分律》說：必須編織邊緣、安設紐結、製作衣鉤，才能成就受衣。

【073-0002】01_行事鈔/04c_卷上之四#26
【原文】三簡人差別者。先明受人，後明持人。《四分》云：不在僧前受。若有難，若無僧伽梨；若僧如法受衣，而彼在界外住，並不成。《善見》：前安居人得受；若後安居、破安居、異界僧等，不得受利。若此處僧少，不滿五人，得預請界外僧，足數成受；其異界僧，不得受利。若住處有四比丘，一沙彌，安居欲竟，為沙彌受大戒，得足數，成受。新受戒者，亦得五利。一比丘，四沙彌，又爾。若住處雖有五人，不解受衣，得請異界知法僧來作羯磨受衣；異界人自不得受。《十誦》云：諸異界僧，欲受衣，不可得者，各解本界，同結，受已，然後別結。捨者成捨，不捨者依利。犯僧殘人、別住人、學悔沙彌、擯人等，不成受。二明持衣人。《十誦》云：守衣人具不愛等五德，謂知得受不得受，了了分明。《善見》云：若多人送功德衣，應受一衣，餘同輕物，應分；重物屬四方僧。若施主言，持三衣作盡與，持衣人隨施主意。若羯磨迦絺那衣與衣壞者，若衣壞者多，與衣壞中老者；若老者多，與老中夏多者；不得與慳貪人。《明了論疏》云：於初結安居時，欲受迦絺那衣，悉須白僧：我欲受衣。僧觀此人，不多緣事不？不好失衣不？此人從來不貪聚財物，有慈悲心好行惠施者，僧即許可；若不爾者，不須許之。
【譯文】第三說明揀選人員的差別。先說明同受利益之人（受人），後說明主持持衣之人（持人）。《四分律》說：不在僧團現前面前受衣；如果有災難障礙；如果沒有僧伽梨（大衣）；如果僧眾如法受衣，而該比丘留在結界之外住，這些都不能成就受衣。《善見》說：前安居的人可以受衣；如果是後安居、破壞安居、其他結界的僧人等，都不得享受功德衣的利益。如果此處僧人稀少不足五人，可以預先延請界外的僧人前來補足人數以成就受衣；但那位異界的僧人本身不得享受利益。如果住處有四位比丘、一位沙彌，在安居即將結束時，為沙彌受具足大戒，得以補足人數而成就受衣；新受戒者也能獲得五種利益。若是一位比丘、四位沙彌，也是如此。如果住處雖然有五人，但都不懂受衣之法，可以延請界外懂法的僧人前來主持作羯磨受衣；但界外之人自己不得享受利益。《十誦律》說：諸異界僧想要受衣而依法不可得時，可以各自解除原本的結界，共同結為一界，受衣完畢後，然後再分別結界；捨棄利益者即成捨，不捨者則依舊享有利益。犯僧殘罪之人、行別住罰之人、學悔沙彌、被擯除之人等，皆不能成就受衣。其次說明持衣之人。《十誦律》說：守護功德衣的人應具備不愛、不恚、不怖、不癡以及知曉得受與不得受等五德，能夠了了分明。《善見》說：如果有多人送來功德衣，應當只接受其中一件作功德衣，其餘的視同輕物（日常資具）應當分配給現前僧；重物則歸屬於四方僧。如果施主表明說將所施三衣全部給予持衣人，則隨順施主的心意。如果作羯磨將迦絺那衣給予衣服破損的人，若衣服破損的人多，給予破衣者中年長的人；若年長的人多，給予年長中戒臘高的人；不得給予慳吝貪心之人。《明了論疏》說：在最初結夏安居之時，若想要受迦絺那衣，都必須向僧眾陳白：「我想要受衣。」僧眾觀察這個人：是否事務緣端不多？是否不常遺失衣物？這個人若向來不貪圖積聚財物、富有慈悲心且樂善好施，僧眾便許可他；如果不符合這些條件，就不應當許可他。
