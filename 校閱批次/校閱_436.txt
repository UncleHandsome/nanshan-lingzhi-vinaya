# 校閱材料　第436檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【436-0001】資持記/05d_上四#23
【原文】下文指廣，如上略引，餘更如彼。長短中。三位極限為長，一日八日十六日為短，中間長短可知。文中唯明七日短緣，長易知故。半月一月，例準同之。律下，引文示。立下，申所以。若下，釋疑。但約緣長，不必路遠。僧尼中，初文。僧法可知，尼中不同，故須簡別。《四分》、《僧祇》明文可了。
【譯文】鈔文下文是指引參見廣本文疏（詳細說明），如上面略微引述，其餘內容正如彼處所記。長短期限之中。三個位階的極限屬於長，一天、八天、十六天屬於短，中間的長短由此可知。文中僅說明七日的短期因緣，因為長期的容易理解。半月與一月的情況，可依此類推。從「律」字以下，引用律文加以說明。從「立」字以下，申述設立的原因。從「若」字以下，解釋疑難。只要依據因緣時間的長短，並不一定是指路途遙遠。僧眾與尼眾的科判中，第一段文字。大僧的法則容易明瞭，尼眾之中有所不同，所以必須加以甄別揀選。《四分律》與《僧祇律》的明文非常清楚。

【436-0002】資持記/05d_上四#24
【原文】不云多者，不明餘二也。次科，初出濫行。《四分》下，判非法。三中。文敘二義。別緣者，簡非眾故。必有長緣，事須前往，或容返界重受七日；或比難緣，義通直去。事訖中。疏引古計云：事訖不來，夏亦不失，以法在故。今師不同，如文所示。初示所以。施猶用也。
【譯文】不說多數法度，是因為未曾說明其餘兩種。下一科，首先揭示虛濫的行持。從「《四分》」以下，判定為非法。第三科中，文字敘述兩種義理。所謂「個別因緣」，是甄別非屬僧團眾法。如果必定有長期的因緣，事情必須前往處理，或者可以中途返回界內重新接受七日法；或者比照危難因緣，義理上通許直接離去。事情完結的科判中。疏引古人的計度說：事情辦完不回來，夏安居也不會失去，因為受日法仍然存在。現在祖師見解不同，正如文中所明確指示。首先說明其原因。「施」如同使用的意思。

【436-0003】資持記/05d_上四#25
【原文】問：事訖即謝，返界路遙，中途經宿；無法隨身，應須失夏？答：法託緣生，緣謝法失；本期還來，未及本處，事猶未息，故非失夏。問：事訖法亡，或緣未竟，期限已滿，約何明失？答：《四分》、《十誦》日夜兩別，如後自明。《明了》下，引證。
【譯文】問：事情辦完法力隨即消謝，返回本界的道路遙遠，中途停宿；沒有受日法隨身護持，豈不是應當失去夏安居？答：法是依託因緣而生，因緣消謝法力便隨之失去；但原本預期是要返回，尚未抵達本處之前，事情仍不算完全停息，所以不算失去夏安居。問：事情辦完則法力消滅，或者因緣尚未結束，而受日預定的期限已滿，應當依據何者判定破夏？答：《四分律》與《十誦律》在以日數或夜數計算上各有不同，如後文自然會說明。從「《明了》」以下，引述經文明證。

【436-0004】資持記/05d_上四#26
【原文】《十誦》不許者，前云：中路聞死反戒八難起不應去等。《僧祇》同者，前云中前和了，中後即還等是也。正加中，心念中，初文。本是對首，以無所對，故開心念。初明開緣。獨住等者，等取蘭若、遠行〔謂寄道中安居〕、長病、飢時依親里，五緣。並約無侶，有即不開。故下猶須相待。
【譯文】《十誦律》不聽許的情況，前面說：半路上聽聞受請者死亡、反叛還俗、或八難生起，就不應前往等。《僧祇律》相同之處，前面說午前調和完畢，午後便須返回等即是。正式作法中，心念受法的第一段文字。受法原本應是對首行之，因為沒有相對受法的對象，所以開許用心念法。首先說明開許的因緣。所謂「單獨居住等」，「等」字涵蓋了阿蘭若處、遠行〔指寄居於道中安居〕、長期患病、饑荒時依附親友，共五種因緣。這些都是在沒有同伴的情況下，若有同伴就不開許。所以下文提到仍須互相等待。

【436-0005】資持記/05d_上四#27
【原文】若界下，示非法。即成別眾，人非所收。若待下，明如法。次科，初指上開。若下，正示告法。十下，遮濫。有執此文，謂通互對等故。然此且據七日為言；羯磨月法，不通餘四；前文但簡尼眾，準理沙彌亦然。指沙彌中。下亦不出，還指同僧。對首中。
【譯文】從「若界」以下，顯示屬於非法。那樣就形成了個別聚眾，人眾也不合法度所收攝。從「若待」以下，說明合乎戒律的情形。下一科，首先指明上面的開許。從「若」字以下，正式說明宣告的作法。從「十」字以下，防範虛濫。有人執著此段文字，認為可以互相對首受法等。然而這姑且是針對七日法而言；羯磨的月法，不能通融於其餘四眾；前文僅是甄別除開尼眾，依照道理對沙彌也是如此。在指示沙彌的文段中，下文也未另出作法，依然指示與大僧相同。對首作法之中。

【436-0006】資持記/05d_上四#28
【原文】受法分五，初求他審諦，二述己情懷，三標期無濫〔簡眾法故。〕，四牒事非虛，五期還奉制。簡辨中，初科。云準羯磨白者，即第三句緣本詞也；不無加減，對之可見。次科，正明中，初立理。不下，簡異。世凡論病，七日則轉；藥不加病，故限七日。次科。疑者云：病轉可爾；不轉過日，法應隨在。
【譯文】受法分為五個階段，一是祈求對方審實諦聽，二是陳述自己的情懷，三是標明期限無所虛濫〔為了簡別眾法之故〕，四是如實陳述事情並非虛假，五是預定歸期以奉持戒制。簡別辨析中，第一科。說到依準羯磨的宣白，即是第三句因緣本來的詞句；不免會有些許加減，對照之下便可看出。下一科，正式說明之中，首先確立道理。從「不」字以下，簡別相異之處。世間大體談論病情，到了第七天病情便會轉變；藥力不再多加於已轉之病，所以將七日藥限定在七天。下一科。懷疑的人說：病情好轉（藥法隨失）固然說得通；如果不轉變而超過期限，藥法應當隨著病情仍在而繼續存在。

【436-0007】資持記/05d_上四#29
【原文】住猶存也。答如論者，即多成《了論》，如四藥引。問答中。並由昔世妄行，故特辨示。答中，初句義定。此唯約第七夜為言，非謂不兼前六夜也。以下，釋所以。文明七日，餘二準同。又下，止非又二；初正斥妄改。亦下，因斥濫用。曇諦羯磨後隨出事訖法，有昧教者輒用故。
【譯文】「住」就是存續的意思。依據論典作答，即是指《薩婆多論》、《成實論》、《明了論》，如四種醫藥段落中所引述。問答之中。都是由於往昔世人妄加行持，所以特地辨析指示。回答中，第一句確立義理界定。這僅僅是針對第七夜來說，並非說不涵蓋前面的前六夜。從「以」字以下，解釋其原因。律文明確規定為七天，其餘兩種法依此類推。從「又」字以下，制止非法，又分兩點；首先正式斥責妄加修改。從「亦」字以下，順帶斥責濫用。曇諦所出羯磨後隨附了事情辦畢的作法，有不明教理的人動輒濫用。

【436-0008】資持記/05d_上四#30
【原文】問：兩宗失受，同異云何？答：失法則異，破夏乃同。《四分》受日，日沒即失；《十誦》受夜，夜盡方謝；及論破夏，並約八日明相為言。疏云：第七夜分明相未出，自屬前夜；明相若出，即屬八日，制七日夜須及界中，又云：《十誦》亦及七夜返，還同《四分》，有何異耶？問：諸律立法，差別何相？
【譯文】問：兩部律宗失去受日資格，相同與相異之處為何？答：失去法力之點有所不同，至於破夏的判定則是相同的。《四分律》受日，日落之後法力即失去；《十誦律》受夜，夜晚過去法力才消謝；若論及破夏，都是以第八天的黎明破曉（明相）為準。疏中說：第七夜後半夜如果天亮明相未出，自然屬於前一夜；明相若已現出，即屬於第八天，戒制要求七日七夜必須趕回界內。又說：《十誦律》也是趕在七夜前返回，與《四分律》完全相同，又有何差異呢？問：各部律典確立作法，差別形態如何？

【譯文】後來又說：立志修行的行人，持戒守護當從嚴急；如果後來作法的界限比自然界更寬廣，則只依據自然界的範圍；既然沒有因緣危難，不可在事後予以寬開；若後結之界比本處狹小，有主張依新界者〔此為其他見解〕，本意認為安居隨從本來的自然界為定限；由於當初作法的意圖是在於行羯磨，安居在任何地方，不需要額外結界。〔古代的撰記者看到此段，便認為先前已有界限的地方，也不需要依界結夏，這真是大錯特錯。〕結尾指明中，點評上面所做出的判定。
