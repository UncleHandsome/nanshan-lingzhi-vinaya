# 校閱材料　第551檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【551-0001】02_戒疏/09c_卷二下之二#5
【原文】【註】若作如上譽已，「供養我來」，不說「婬欲」者，偷蘭。餘境雜犯，如前戒說。不犯者：若比丘語女人言「此處妙尊最上，此比丘精進持戒、修善法，汝等應以身、口、意業等供養於彼」，若女意謂「為我歎身」；若說毗尼，言次及此，彼謂歎身；若錯說者——並不犯。
【譯文】【註文】如果像上面那樣讚美自己之後，只說「妳來供養我」，而沒有說出「淫欲」字眼的，結犯偷蘭遮罪。其餘境界的雜犯情況，如同前一條戒所說。不犯的情況：如果有比丘對女子說「這個處所極為尊妙殊勝，這位比丘精進持戒、修習善法，妳們應當以身、口、意業等來供養他」，女子心裡卻誤以為「他是在稱歎自身，想向她索求供養」；或者是在宣講戒律時，話語順序剛好說到這裡，對方誤以為是在讚身索欲；或者是一時說錯話——這些情況都不犯。

【551-0002】02_戒疏/09c_卷二下之二#6
【原文】【疏】就辨相中，若但說欲，如前戒；若但歎身，結偷蘭；歎身索欲，方犯此戒罪。餘相狀可解。
【譯文】【疏文】在辨析行相方面，如果只是談論淫欲，就如同前一條戒；如果只是稱讚自身，則結犯偷蘭遮罪；必須是稱讚自身同時索求淫欲，才結犯本戒的僧殘罪。其餘的事相很容易理解。

【551-0003】02_戒疏/09c_卷二下之二#7
【原文】【記】第六中，釋注辨相。云「餘可解」者，注指「前戒」，謂遣、書、現相報、別趣異等，並同故也。就不犯中，初如實歎他及說法等，彼謂「歎身」，非我心故。
【譯文】【記文】在第六科中，解釋註文以辨析行相。疏文說「其餘事相可解」，是註文指涉「前一條戒」，也就是差遣人、寫信、以手勢示現等回報，以及分別對待不同對象等，情況都相同。在不犯的情況中，首先是如實稱讚他人以及說法等，對方卻誤以為是「讚身索欲」，這並非我本來的意圖，所以不犯。

【551-0012】02_戒疏/09c_卷二下之二#16
【原文】【註】佛在羅閱祇。迦羅比丘，本是大臣，善知俗法，城中嫁娶盡往𧫎問。時婚娶者，逢對好、惡，便願迦羅受於苦、樂。居士譏訶，比丘舉過，佛因制戒。
【譯文】【註文】佛陀住在羅閱祇城。迦羅比丘原本是朝中大臣，精通世俗禮法，城中凡有嫁娶之事，都前往向他請教詢問。當時結婚的人，如果遇上合適或糟糕的配偶，便詛咒或祝願迦羅承受痛苦或快樂。居士們對此譏諷責罵，比丘們便舉發其過失，佛陀因此制定了這條戒。

【551-0013】02_戒疏/09c_卷二下之二#17
【原文】【疏】就戒緣中，迦羅本知姻媾、相祿、休咎，故雖出家，還尋本業，斯積習生常，不言有過。如今屠販之士，迷利故所以行，可不然哉？故《律》中「先客書者，不得畜筆；先客縫者，不得畜針；先客木者，不得畜斤斧」等，並制惡習也。又言「婚對好惡，願受苦樂」者，俗人無識，不謂往緣，既得違順，便言「媒人與我苦樂」。斯為過兆，故制在茲。由諸比丘與迦羅類，故彼言有涉也。
【譯文】【疏文】在制戒的緣起中，迦羅本來就精通姻親嫁娶、命相祿位、吉凶休咎等術數，所以雖然出家了，還是回頭去搞舊業，這是經年累月的積習成了自然，自以為沒有過錯。就如同現今屠宰販賣之輩，因為被利益迷惑而去做那些事，能不如此嗎？所以《律》中規定「出家前曾靠寫字為業的，出家後不得私蓄筆墨；曾靠縫紉為業的，不得私蓄針線；曾做木匠的，不得私蓄斧斤」等，都是為了禁制過去的惡習。又說「婚姻配偶的好壞，願使受苦受樂」這點，世俗之人缺乏智識，不認為這是前世的因緣，既然遇到了違逆或順心之事，就說是「媒人帶給我痛苦或快樂」。這就是過失的徵兆，所以制戒的關鍵就在這裡。由於眾比丘與迦羅同屬僧類，所以世人的話語也連帶牽涉到了大家。

【551-0014】02_戒疏/09c_卷二下之二#18
【原文】【記】戒緣中。初明迦羅本緣。「姻、媾」，皆婚娶之名。「相祿」謂命分。「休咎」即吉凶。「如」下，舉事為況。「故」下，引教以證，令知出家，必除俗習。「又」下，次釋毀讚，《律》云「彼婚娶得適意者，便歡喜供養讚歎，言『令迦羅常得歡樂，及餘比丘亦得供養』。若彼不得適意者，便言『當令迦羅常受苦惱，及餘比丘亦受苦惱，不得供養』」等。然彼毀讚言及餘人，須出其致，故云「由諸比丘」等。由是同類，例遭譏毀。據此，《戒本》注中「願迦羅」下，合有「及餘比丘」一句，恐是寫脫。
【譯文】【記文】在戒律緣起中。首先說明迦羅本來的因緣。「姻、媾」都是婚娶的名稱。「相祿」是指命相與福祿分量。「休咎」就是吉凶。從「如」字以下，舉出世事作為比喻。從「故」字以下，引用經教來證明，讓人知道出家必定要革除俗習。從「又」字以下，接著解釋世人的毀謗與稱讚，《律》中說「那些婚娶後稱心如意的，就歡喜地供養讚歎，說『願迦羅常得歡樂，其餘比丘也能得到供養』。如果婚後不如意者，就詛咒說『應當讓迦羅常受苦惱，其餘比丘也受苦惱、得不到供養』」等。然而世人的毀謗與稱讚牽扯到了其他人，必須說明其中的原因，所以說「由於諸比丘」等。因為是同一個僧團群體，便照例遭受譏嫌毀謗。據此看來，《戒本》註文中的「願迦羅」之下，理應有「及餘比丘」這一句，恐怕是傳抄時脫漏了。
