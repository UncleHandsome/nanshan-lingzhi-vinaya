整體看下來，這幾則譯文的義理掌握大致無誤（六聚歲數的數字換算、「修捨＝止觀」的對應、四略門的歸屬等都對），問題主要集中在**文獻指稱錯誤、引號標點、幾處增譯與用語**。以下逐則列出。

## 一、需要修正的實質問題

### 【365-0001】#100

1. **「文中」誤作「經文」**
 原文「文中且據『初篇』示相」是元照《行宗記》在解道宣《戒疏》，「文中」指的是**疏文**，不是經文。
 → 建議：「**疏文中**暫且只依『初篇』（四波羅夷）來顯示行相。」

2. **「眾、別悔法」譯得含糊且次序顛倒**
 「眾」＝對僧眾（作法）懺，「別」＝對別人（一人）懺，是懺法的兩類，不是「個人或大眾的懺悔方法」這麼籠統。
 → 建議：「僧殘以下，**對僧眾懺與對個人（別人）懺**的種種懺法，詳如《行事鈔・懺六聚法篇》。」

3. **「對略結顯」語意不明**
 譯作「相對於略教來作結尾顯明」，讀者會誤以為是要顯「廣」。此處下記正是解釋「何以名略」。
 → 建議：「『略』字以下，是**對照廣教（三相）而總結顯示略教的名義**。」

4. **標點錯誤**：結尾「所以統統稱之為『略。』」→ 句號應在引號外：「……稱之為『略』。」

5. （建議）篇名補全：《鈔・僧網》＝《行事鈔・**僧網大綱篇**》；《懺篇》＝《行事鈔・**懺六聚法篇**》。地獄名「大叫獄」可作「大叫**喚**地獄」。

*（附帶：歲數換算全部正確——四十千＝四萬、六十千＝六萬、九百千＝九十萬，與《犯戒罪報輕重經》相合。）*

### 【365-0004】#103

1. **「若滿未起」的處理宜再斟酌**
 「滿」字在此費解，一般律典引《善見論》此語多作「**舋（釁）未起**」，即「過釁、犯緣尚未生起」。譯文增譯為「時機尚未成熟、尚未有人犯過」，前半句是自行補義。
 → 建議：查核底本用字後，譯為「**若過釁（違犯）尚未生起，就貿然預先制戒……**」，避免無據的增譯。

2. **引號多一個**：結尾「……才會動手下針。』」」——多出一個下引號，應為「』」」。

3. 「恭敬**重戴**之心」用詞生硬 → 「恭敬**尊重**之心」。

4. （建議）「豈謂善識世人心器」可補主語：「（如來）難道稱得上善於辨識世人的心量根器嗎？」語氣更清楚。

### 【365-0005】#104

1. **「無機」譯成「沒有機緣」失準**
 此處「機」是**根機**：因當時皆利根、奉略教即無違犯，故無「須制廣教之機」。
 → 建議：「當時受教的根機多屬利根，奉持略教便無所違犯，所以說『無機』（**沒有須施設廣教的根機**）。」

2. **「時機多利」** 譯成「最初的求道機緣多為利根之人」，把「機緣」與「人」混在一起 → 「當時的根機多屬利根」。

3. **錯字**：「**升**起敬重」→「**生**起敬重」。

4. **詞序**：「顯淺易懂」→「**淺顯**易懂」。

5. **「舉」字宜保留**：記文是在釋疏文「待熟方舉」的「舉」字，譯成「『下針』就是指……」雖與前文一致，但建議作「『**舉**』（下針）就是用針刺破膿瘡」，讓訓釋對象清楚。

### 【365-0012】#111（同 #107 一併）

**「文」＝律文，非經文（兩處）**
「『呵欲』，文見『婬戒』」「『勸修』亦初戒緣」，所指皆是《四分律》婬戒的制戒緣起文。
→ 「斥責婬欲之文，見於（《四分律》）婬戒」「也是初戒（婬戒）的制戒因緣，**律文**說……」。
同理，「後二引略順釋」的「略」指略教偈頌（出律），稱「略教經文」也宜改為「略教偈文」。

### 【365-0013】#113

1. **「過體則通」宜點明「道俗共通」**：譯文只說「共通的」，讀者不知所通為何。
 → 「正如初篇戒，**就所犯過失之體（性罪）而言，道俗共通**」。

2. **「取其聲教，兩分其位」譯得生硬含混**：「言聲名教制度」不宜；「兩分其位」是說道、俗二位各別（戒法唯局出家）。
 → 「若就佛陀制戒的**言教**來說，則**道俗二位分別**（此戒唯局出家眾）」。

## 二、可保留但建議潤飾

* **#101**「通被時機」→「普遍**適用於一切時機與根機**」，比「普遍對應適應各個時期的根機」乾淨。
* **#105**「二、定相中」譯「判定相貌」易被讀成外貌 → 「第二科、**判定（略教的）行相**」。
* **#107**「訶欲」譯「斥責情欲」偏寬 → 依下記「文見婬戒」，作「**呵責婬欲（欲染）之過**」較貼切。
* **#109**「止唯三業」的「僅僅歸納約束」→「**只是就身口意三業加以約束**」。
* **#100**「盡形即學悔」可略加註：「即**盡形壽與學悔法**（終身行學悔）」；「七九治法」若加註「七種羯磨治法與九種治法」，讀者更不易誤解。
* **#110–111**可考慮加一小註，把《阿含》四句與「三學」的對應點出（諸惡莫作＝戒、眾善奉行＝心意清淨〔定〕、自淨其意＝除邪顛倒〔慧〕），疏文「止在三學」才看得出落處。

## 三、體例統一建議

1. **文獻稱名要分層**：疏＝《戒疏》、記＝《行宗記》、律＝《四分律》、鈔＝《行事鈔》。目前多處把疏文／律文一律稱「經文」，是最需要系統性修正的一點。
2. **引號與句號位置**：#100「略。」、#103 多一個」，建議全部檢查巢狀引號（「…」『…』「…」）的配對。
3. **常見錯字**：生起（非升起）、淺顯（非顯淺）。
4. 記文釋字時（如「所」下、「又」下、「舉」謂），建議保留原字＋括號說明譯語，例如「『所』（所以）字以下」、「『舉』（下針）是……」，便於對照原文。
