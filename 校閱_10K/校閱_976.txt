# 校閱材料　第976檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【976-0001】資持記/03b_上二#31
【原文】及下三非，不集羯磨，如前結戒場中，方相如前唱法。故云前具述也。並下，通結。五下，別證。總束諸非，不出四種。錯涉隔水方相，三並事非；重結即處非，不集謂人非，羯磨是法非。棄捨失中。必約作意捨去，後更不還，無一人住，方名失界。疏云：雖非作法，僧義絕故；
【譯文】從「及」字以下說明其餘三種非法：「不集僧」與「羯磨錯誤」，如同前面結戒場所述；「界相方正與否」，如同前面唱告界相之法，所以說前文都已具備詳細論述。從「並」字以下做全體總結。從「五」字以下個別引證。將各種非法統攝起來，不出四種類型：互相錯雜牽涉、隔水結界、以及界相不方整，這三者都屬於「事項錯誤」；重疊結界屬於「處所錯誤」；僧眾不集合稱為「人員錯誤」；羯磨作法顛倒則是「法度錯誤」。在因放棄捨離而失界的內容中：必須是打定主意要捨棄離開、日後不再返回、且沒有留下任何一人居住，才稱為喪失界法。疏文說：雖然沒有進行解界作法，但僧團共住的義理已經斷絕；

【976-0002】資持記/03b_上二#32
【原文】又引《文殊問經》云：下至有一優婆塞宿，是名不失。文中，前引《十誦》。明須作念，故知不作則不失也。《智論》。限定一宿，故知未宿還來，亦不失也。釋難中，初問。前引《善見》，掘地水蕩，亦無僧住，皆言不失，顯是相違。疏云：《善見》水蕩，計僧並散，豈人水下宿守界耶！
【譯文】疏文又引用《文殊師利問經》說：哪怕只要留下一個在家優婆塞過夜住宿，這就稱為界法不失。文字之中，前面引用《十誦律》，說明必須存有捨棄之念，因此知道如果沒有生起這個念頭，界法便不會喪失。《大智度論》則限定以住滿一夜為準，因此知道如果尚未過夜就又返回，界法也不會喪失。在解釋疑難中，首先提問：前面引用《善見律毘婆沙》，土地被挖掘、被大水沖蕩，同樣也沒有僧人居住，但都說界法不失，這顯然前後互相違背。疏文說：《善見律毘婆沙》提到大水沖蕩，料想僧眾都已經離散，難道會有人潛在水底過夜來守護地界嗎！

【976-0003】資持記/03b_上二#33
【原文】答中，初約捨心有無，和會無違。文中皆言者，即上《十誦》、《智論》。《四分》下，證前不失，無捨心故。文出〈藥揵度〉。故伽藍者，顯是荒廢之處。不失淨地者，明知大界猶存。又下，彼云比丘不知何處是淨地，佛答如鈔。故下一句，結顯二文。〔解疑之文，本出藥法，有智細詳，方知昔謬。
【譯文】回答之中，首先根據「是否有捨棄之心」來進行會通融洽，使之不相違背。文中所說的，指的就是上述的《十誦律》與《智論》。從《四分律》以下，證明前面不失地界的說法，是因為當時僧人並無捨棄之心。這段文字出自〈藥揵度〉。所謂「荒廢的伽藍」，表明那是一處破舊荒蕪的地方。既然說「不失去淨地」，顯然就知道大界仍然完好留存。又在下文中，律說比丘不知道哪裡才是淨地，佛陀的回答就如《行事鈔》所引述的一樣。從「故」字以下的一句，結語顯明這兩段律文的意旨。〔這段破除疑惑的文字，原本出自藥法，有智慧的人仔細推求，才會明白過去說法的荒謬。

【976-0004】資持記/03b_上二#34
【原文】作法捨中。若約法儀，必須次捨；先食，次衣，後捨人界。若論失法，但捨人界，三種頓失。疏云：雖本失末亡，而非正則，亂倫獲罪。今云俱捨，語通漸頓。若準行事，須依漸法。不失中，五種。初惡心者，律因比丘欲令餘人得不淨食，故解淨地，佛判不成；大界無文，故云例準。
【譯文】在「作法捨除」的內容中：如果依照如法的儀軌，必須循序漸進地捨除：先捨食界、次捨衣界、最後捨除人界。若單就失卻界法來論，只要捨除了人界，此三種界法便頓時全部喪失。疏文說：雖然根本的人界一旦失去則枝末的界法隨之消亡，但這畢竟不是正統的法則，紊亂了律法的倫常體系必定會獲罪招愆。如今所說的「俱捨」，語意上兼通於漸捨與頓失。若依實際行事而論，必須依照漸次捨除之法。在「不失界」的內容中，共列出五種情況。第一種「出於惡心者」，律典因有比丘想要讓其他人吃到不乾淨的飲食，所以故意解除淨地，佛陀判定這種解法不能成立；大界雖無明文，因此說是依例比照。

【976-0005】資持記/03b_上二#35
【原文】二云互結者，文出《善見》，彼但明結，今準結類解；結既兩成，解亦不失，故疏標云：僧尼互解。〔古記云結必先解者，謬矣。〕三準捨戒，兩不相足，故通互結，解亦不成。第四可知。五如《四分》治故伽藍。若準《業疏》，則列六種；
【譯文】第二種說「互結者」，文字出自《善見律毘婆沙》，那裡只說明互結，如今依照結界的道理來比類解界；結界既然兩處都能成立，解界時自然也不會失去界體，所以疏文標名為「僧尼互相解界」。〔古記說結界時必須先解除，這是錯誤的說法。〕第三種依據捨戒的先例，雙方語言不通而不能互為湊足僧數，所以通許互相結界，解界同樣不能成立。第四種情況其理顯自明。第五種就像《四分律》中所說的修治荒廢的舊伽藍。如果依照《業疏》所定，則一共列出六種情況：

【976-0006】資持記/03b_上二#36
【原文】初二同鈔，三異見互結，四邪正互結，五是中邊，六即合今四五兩種。別證中。然與論文小異，今具引之，彼前問云：二眾結界，得互相叉結否？答：得叉〔謂不共行法故。〕，得共結〔謂受戒出罪，僧尼同法，鈔變其語，故云不得相叉。〕，後問云大僧得與尼通結界否？答得。
【譯文】前兩種與《行事鈔》相同，第三種是不同見解者互相結界，第四種是邪正見解者互相結界，第五種是中國與邊地互結，第六種則是將此處的第四、第五兩種情況合併為一。個別引證中：然而此處與論典文字有些許不同，如今完整引述：論典前面提問說：僧、尼二眾結界，可以交錯互相結界嗎？回答說：可以交錯〔是指二眾不共行法事〕，也可以一同結界〔是指受戒與出罪等法事，僧尼依照同一法度作法，行事鈔稍改其語句，所以說不可互相交錯〕。後面又提問說：大僧可以與比丘尼一同結界嗎？回答說可以。

【976-0007】資持記/03b_上二#37
【原文】今鈔所引，上二句即後問答，下一句即是前答。疏云不相叉者，恐出僧外，非成同法故。7 釋僧網篇(上二)釋僧網篇僧宗事多如網，此篇五門如綱；用此五者，如提其綱，則餘網目無有不正；從喻為題，以彰正要。住持攝眾，舍此何為？仰夫聖教昭彰，遵之甚易；但以人非清正，舉之或難；
【譯文】如今《行事鈔》所引用的，上兩句就是後面的提問與回答，下一句就是前面的回答。疏文所說的「不相交錯」，是擔心如果超出僧團之外，就不能成立同法界的緣故。7 釋僧網篇（上之二）解釋〈僧網篇〉：僧團教宗的事務繁多就如同漁網，本篇所設立的五門就如同網的總繩大綱；運用這五門，就如同提起了漁網的大綱，那麼其餘的網目就沒有不端正妥善的；從譬喻中立出篇名，用以彰顯端正的重要綱領。住持佛法並攝受僧眾，捨棄了這個還能靠什麼呢？我們景仰佛陀的聖教昭彰分明，若能奉行其實非常容易；只是因為主事者多非清正之人，若要真正推行或許會遭遇困難；

【976-0008】資持記/03b_上二#38
【原文】有教無施，可用長歎。敘意中，初文四段；前四句明凡為眾主，必遵於教。一方者，通語遠近傳弘之處。立法通者，舉事依教，餘方共遵；曲任私情，不流於外故也。上二句明立制軌物，下二句明臨事處斷。令下四句，二明近益。遠域異邦，語重事一；
【譯文】聖教空存卻無處施展，真令人不禁發出長嘆！序述大意之中，第一段文字分為四個小節；前四句說明凡是作為僧團的首領首座，必定要尊崇依循佛教。所謂「一方」，是通指無論遠近弘傳佛法的地方。所謂「立法通達」，是指推行事務全依聖教，其他各方都能共同遵行；如果任意屈順個人私情，法度就無法流傳於外。上兩句說明訂立規制以作為大眾的模範軌則，下兩句說明臨事時能夠做出公正決斷。從「令」字以下四句，第二小節說明近處的利益。遠方邊鄙之域與異國邦域，話雖重複但事實是一致的；
