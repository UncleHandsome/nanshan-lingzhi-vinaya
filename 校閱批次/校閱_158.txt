# 校閱材料　第158檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【158-0001】資持記/05c_上四#5
【原文】是名下，謂結夏日異，受歲日同。前一月中，隨日可結，故云三十日安居也。問：難事不息都不結者，為得夏否？答：疏云：或五日三日乃至一月，雖不結之，不失前坐；以難不結，非是故心。若下，明後。以後安居人本是八月十五日夏滿，聽隨前安居人探前自恣。
【譯文】「是名」以下，是指結夏的日期雖然不同，但受歲自恣的日期卻是相同的。在夏初的一個月內，隨哪一天都可以結夏，所以稱為「三十日安居」。有人問：如果災難阻礙一直沒有平息，完全不曾作法結夏，究竟算不算是獲得了一夏？回答說：《業疏》指出：即使耽誤了五天、三天，乃至一個月，雖然不曾作法結夏，卻不會失去先前安居的資格；因為這是由於災難而未能結夏，並不是出於故意放逸之心。「若」字以下，說明後安居的情形。因為後安居的人原本應當在八月十五日夏滿，律中開許他們跟隨前安居的人提前進行自恣。

【158-0002】資持記/05c_上四#6
【原文】令由難阻隨息開作，故通一月；此即結夏日同，受歲日異。問：前中二種，有難開否？答：準理應通。若爾，律中有難開增自恣者？答：彼是外界鬪諍，此即王賊等阻障；俱號難緣，名同事別。上三前後，初賞罰，以前安一日為前，後三十日為後。次得罪中，以前三十日為前，後安一日為後。
【譯文】為了因應災難阻礙、隨其平息而開許作法，所以時間通達整整一個月；這便是結夏的日子相同，而受歲自恣的日子互異。有人問：在前安居與中安居兩種情況下，遭遇災難時也有此類開許嗎？回答說：依照義理推敲應當也是通用的。如果真是這樣，律中為何又有遭遇災難而開許增加自恣日期的規定呢？回答說：那是因為界外發生了鬥爭，而此處則是指遭遇官府、盜賊等阻礙；雖然都稱為難緣，卻是同名而事相各異。以上三種前後：第一種賞罰，是以前安居的一天為「前」，其後的三十天為「後」。第二種結罪，是以開始的三十天為「前」，最後安居的一天為「後」。

【158-0003】資持記/05c_上四#7
【原文】三難事中，即約安恣互明前後。疏有六種。三種同前。第四位約前後，初後兩夏各十六日，中間二十九日。五明行住〔住謂舊住，行即外客。〕，對念二法，行住通用；忘成及界，以是行人，先有要故。〔又云：必舊有要，例亦開之。〕六據法不同，對念作法，以容預故。
【譯文】第三種難事之中，則是綜合安居與自恣的關係互論前後。《業疏》中列出六種情形。其中前三種與前面所說相同。第四種位次是就前後兩夏而言，初夏與後夏各有十六天，中間則有二十九天。第五種是說明行路人與定居者（「住」是指原住僧眾，「行」則是指外來客僧），面對面作法與心念作法這二種法，行路人與定居者皆可通用；至於忘記而自然成夏以及跨入界內，乃是因為此人身為行路者，先前心中已有確定的期約（疏中又說：如果原住僧人本來就有明確期約，依例也可獲得開許）。第六種是依據作法性質的不同：面對面與心念作法，因為時間較為寬裕從容；

【158-0004】資持記/05c_上四#8
【原文】忘成及界，恐乖前後，直爾便得。〔準疏後亦加法。〕夏閏中。標云延促者，依閏為延，不依名促；又閏中三例，住日多少，延促可尋。依閏中三，初示文闕。比下，二取例。比即是例。前引論文。彼云：若閏四月者，則取前四月受雨衣，滿百二十日，故知含閏在其間矣。
【譯文】若是忘記而成夏以及剛跨入界內，唯恐違背了前後的時限，所以當下直接便算成辦（依照《業疏》，事後仍然需要補作加法）。在論述「夏閏（閏月）」之中，標題所說的「延促（延長或緊縮）」，依照閏月而坐夏便算延長，不依閏月便算緊縮；再者，在閏月之中有三種條例，安住日數的多少，其延長或緊縮皆可從中推尋。在「依閏」的段落中有三小節：第一節說明律文的缺漏。「比」字以下是第二小節，取為類例。「比」就是依例之意。前面曾引述論部之文，該處記載：如果是閏四月，就取前四月來受納雨衣，滿一百二十天，由此可知閏月是包含在其中的。

【158-0005】資持記/05c_上四#9
【原文】彼下，以開況制。開緩尚依，制急宜準。又下，三釋疑。疑云：閏是虛坐，既非正月，閏中出界，應不破夏，何須坐閏。故此通之。今明依閏雖經四月，閏不在數，但恐間絕三月實夏，故依之耳。次不依中，初標示。摩下，引據。安居已作閏者，顯是初結未知有閏，故通數滿。
【譯文】「彼」字以下，是以開許之法來比況制定之法。寬緩的開許尚且要依從閏月，緊迫的制定更應當準照辦理。「又」字以下是第三小節，用來釋疑。有人懷疑說：閏月是虛設的月份，既然不是正月份，那麼在閏月期間走出界外，應該不算破夏，又何必一定要坐閏月呢？因此此處為之融通說明。現在闡明：依從閏月雖然歷經了四個月，閏月本身不算在實數內，只是唯恐中斷隔絕了三個月真正的夏安居，所以才依從它罷了。接著在「不依閏」的段落中，首先列標提示。「摩」字以下，引述典據。「安居已作閏」這句話，顯示出一開始結夏時並不知道有閏月，所以通融算滿九十天即可。

【158-0006】資持記/05c_上四#10
【原文】下明受衣，言成受者，以不依閏數日滿故。言不成者，或有依閏日未滿故。謂下，對釋可解。兩判中，初句指前文。《多論》唯明依閏，《伽論》文通兩位，故云兼具。次句明雙用。夏下，正判；初明須依。謂先知有閏，宜從《多論》，不得不依。故不取《伽論》。若下，次明通依不依。
【譯文】下文說明受功德衣，所謂「成受（成辦受衣）」，是因為不依閏月而天數已經算滿了；所謂「不成受」，則是因為有人依閏月而天數尚未算滿。「謂」字以下，加以對比解釋，義理容易理解。在雙重判斷中，第一句是指向前面的律論文字。《薩婆多毘尼毘婆沙》（多論）只說明依閏，《伽論》的文字則通於依與不依兩個層面，所以說兩者兼具。次句說明兩論皆被採用。「夏」字以下進行正判：首先說明必須依從閏月的情形。如果預先知道有閏月，應當依循《多論》，不得不依從它，所以不採用《伽論》之說。「若」字以下，接著說明通於依與不依的情形。

【158-0007】資持記/05c_上四#11
【原文】言反前者，謂夏初不知有閏，結已方立。或依不依，隨人取捨，故云通二論也。西土作閏不定；此方不爾，預出年曆，並是先知，皆須依閏。〔舊謂：先知有閏，要依不依，隨人所欲者。非。〕疏云：即彼《伽論》，前安居已，王作閏月；本知有故，則依閏不合受衣；本不知有，數日成夏。問答中。
【譯文】所謂「反前」，是指在夏初時並不知道有閏月，結夏之後國家才宣布設置閏月。此時或者依從、或者不依從，全憑個人自行取捨，所以說通於兩種論典。西域設置閏月並不固定；東土則不然，會預先頒布整年曆法，大家都是預先知道的，因此全都需要依從閏月。（過去有人認為：縱使預先知道有閏月，要不要依從，全憑個人意願。這種說法是錯誤的。）《業疏》中說：就是那部《伽論》記載，在結前安居之後，國王才設置閏月；如果原本就知道有閏月，那麼依照閏月就不得受衣；若是原本不知道有閏月，算滿日數即可成夏。在問答之中：

【158-0008】資持記/05c_上四#12
【原文】此兩重問，並謂以開難制；兩答不同，在文可見。言二六者，一月五月中間兼閏，則二月六月也。一月中局閏七月，五月中通含七八九十十一五箇月也。開犯獲利，故云奢法。問：雨衣亦開，何攝閏者？答：熱時須用，有益無損，故不同也。差別中。標云進否，謂日多少也。
【譯文】這兩層提問，都是用寬開的法規來質疑緊閉的制條；兩段回答各有不同，在文字上可以看得明白。所說的「二、六」，是指若在一月或五月的中間夾雜著閏月，那就變成了兩個月或六個月。在一個月之中局限於閏七月，五個月之中則普遍包含七、八、九、十、十一這五個月。開許免除犯戒並獲得利益，所以稱為寬縱寬大之法（奢法）。有人問：雨衣也是開許之法，為什麼能攝受閏月呢？回答說：炎熱季節必須使用，這樣做只有好處而沒有損害，所以性質不同。在「差別」一科中，標題所說的「進否」，是指日數的增多或減少。

【譯文】當時解除結界原本就不是為了夏安居的事，而是彰顯另有其他公務作為；文字雖然沒有明示，義理應當與上述相通。「古」字以下，第四點引述問難。所謂「古人云」，是指這在早先就已經被前代古德難破，現在予以引用，《業疏》中所標出的「有人言」指的就是這件事。前面引述律文說安居結束應當解界、應當自恣，這兩處律文並無不同，所以引來互相對比。然而律中通融自恣可在十四日、十五日、十六日三天舉行，在十四、十五日自恣雖未全滿但也都算成辦；以及中安居、後安居之人跟隨前安居之人自恣後，留住等待日數算滿；

【158-0049】資持記/05c_上四#53
【原文】用此相並，明知解結非破夏矣。文兼等者，不竟解結若云破，不竟自恣亦應破；自恣既不破，解結云何破！上句示文同，下句明義合；破則齊破，成則俱成，不可偏故。疏又難云：如在攝衣界中，護衣緣故須解，亦應失本所依，即日明離；然未經宿，不說離衣；夏亦同此，何得即破。〔前云：解界即日破夏，不待經宿，故有此難。
【譯文】拿這點相互比對，就能明確知道解界與結界絕對不是導致破夏的原因。所謂「文兼」等語，如果說夏未全滿就解界結界算破夏，那麼夏未全滿就先行自恣也應該算破夏；自恣既然不算破夏，解界又何以會算破夏呢！上一句說明律文句式相同，下一句說明箇中義理相合；若算破壞則應當一同算破壞，若算成辦則應當一同算成辦，絕不可偏執一端。《業疏》又責問說：如同在「攝衣界」之中，為了守護僧衣的因緣所以必須解除該界，照你們的說法這也應該喪失了原本所依憑的界，當天看見明相便算離衣犯戒了；然而只要還沒有在外過夜，律中絕不說是離衣犯戒；夏安居也是如此，怎能說解界當天就立刻破夏呢！（前面古德說：解界當天即刻破夏，不須等待過夜，所以道宣律師才提出這項問難）。

【158-0050】資持記/05c_上四#54
【原文】今解中，初二句判定。但下，明前後寬狹，初生起。若下，示相為二；初明依界前狹後寬。《僧祇》：避難界，縱廣三由旬。問：先廣後狹，為依何處？答：準下自然，亦應依本。從狹彌勝。若下，二明依藍。疏中，又有師云：自然中安居已，結界受日，失本自然，亦破夏也。
【譯文】在當前的正確解釋中，前兩句作出定論。「但」字以下，說明前後結界範圍的寬與狹，首先是發起端緒。「若」字以下，列示兩種相狀：首先說明依止結界時「先狹後寬」的情況。《僧祇律》記載：為了避難而結的界，縱橫廣大可達三由旬。有人問：如果一開始寬廣而後來變得狹小，這時僧人應當依止何處？回答說：準照下文自然界的道理，也應當依止本有的範圍。範圍越狹小則持守越殊勝。「若」字以下，第二點說明依止僧園的情況。《業疏》之中，又有律師主張：在自然界中安居之後，又在其中作法結界以便受日外出，這就失去了原有的自然界，所以也算破夏。

【158-0051】資持記/05c_上四#55
【原文】難云：本依自然，結夏尚成；今結作法，牢強於本，何得云破！以不離界故。此不標古，直伸今意。初明後狹。若下，明後寬。二緣即有難無難也。〔昔云前注文順古者，準此知非。〕受日，敘意中；初敘開。必下，明制。妄下，顯過。西土施物，多依夏數；北地亦然，故多此過。可下，生起。
【譯文】駁難者說：原本依止自然界，結夏尚且都能成立；現在作法結界，其防護力比原本更為堅固牢強，哪有反而算作破夏的道理！因為行者自始至終都沒有離開這個界域。此處不再標列古代觀點，而是直接申述當前的主張。首先說明「後狹（後來範圍變狹）」。若字以下，說明「後寬（後來範圍變寬）」。所謂「二緣」，就是指有災難與沒有災難這兩種因緣。（過去有人認為前文的夾注是順從古說，準照此處就能明白那種見解是錯誤的）。在「受日（受法請假外出）」的敘述原由中：首先敘述通權開許之事。「必」字以下，闡述戒律嚴正制定的常軌。「妄」字以下，揭示虛妄犯戒的過失。西域施主布施財物，多半依據受戒的夏臘多寡來分配；北地中原也是這樣，所以經常滋生這種冒領的過失。「可」字以下，引起下文。
