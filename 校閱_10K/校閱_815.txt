# 校閱材料　第815檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【815-0001】02_戒疏/19c_卷四下之一#37
【原文】【記】次科。初敘意。「前月未至」，即前沙彌，七月始滿，未入八月故。月既未至，故云「本非所開」。義當足滿，故云「何得輒略」。「今」下，明填補。以五月一日，實從四月十八日抽出十三日，今即以十三日填之，還成實數。初填「布薩」，以四月有二大二小，得六日，十八日中得一日，共還七日。次還「閏餘」，四月十八日，共餘六十五分，得二日一分，內有兩箇小盡，得二日。共四日一分，未成五日，故「弱得」。今云「弱得」者，將四日一分，開為一百二十九分，五分破之，成二十六分為一日，但少一分耳。三、還「頻大」，以頻大法一年半許，止得一日，七八月許，始得半日，今四月十八日，未成半日，故弱得也。「總計十三日」，即頻大弱半日，亦當一日，據實止得十一日零十餘分耳。所以《鈔》中但還十一日，至八月十日得受。今約弱得，多還所退，則令所增出得二日，筭數滿足，是以依《鈔》起筭猶少二日，如彼廣之。「就實四月十八」者，既填還已，筭數已成，即須退減。舉要為言，即是於前古師十八年二日中，約實退去四月十八日，約虗即是退五月一日耳。
【譯文】【記文】第二科。首先敘述原由。「前月未至」，即指前述的沙彌，到了七月實算才滿，尚未真正跨入八月。月份既然還沒到，所以說「本非所開」。在法理上應當補足，所以說「何得輒略」。「今還」以下，說明填補退還之法。因為五個月又一天，實質上是從四個月十八天中抽取十三天湊成的，現在就用十三天填補回去，恢復實際的天數。首先填補「布薩」，因為四個月中有二大二小，得六天，十八天中得一天，共歸還七天。其次歸還「閏餘」，四個月又十八天之中，共計多餘六十五分，可得兩天又一分，其中包含兩個小月，算得兩天。共計四天又一分，未滿五天，所以說「略少於」。這裡說「略少於」，是將四天一分化為一百二十九分，以五分去除，得二十六分為一天，僅僅少了一分。第三歸還「頻大」，因為依頻大法大約一年半才得一天，七八個月才得半天，現在四個月十八天還湊不成半天，所以也是略少。「總計十三天」，即頻大略少於半天也算作一天，依實際情況而言只有十一天多十幾分而已。所以《事鈔》中只退還十一天，到了八月十日即可受戒。現在依照略少之數，多退還了一些抽取的日數，從而使增長推算出來的時間多了兩天，計算數目更為完滿，因此依照《事鈔》推算還差兩天，詳細情形如彼處所述。「實際只有四個月十八天」，既然已經填補完畢，推算數目已定，就必須退減。總括來說，就是在先前古師所定的十八年又兩天中，依實數退去四個月十八天，依虛數來說就是退去五個月又一天。

【815-0003】02_戒疏/19c_卷四下之一#39
【原文】【記】三中。初示今定限。「年暮日生」，即一日當一年。十九歲上八月受戒，中間實得十七年，前後合成七箇月零十三日。約此實數，即用胎、閏等四位起算，正滿二十年。然生日受月，不必一定，但約此為法，隨人計滿，即堪與受，不復疑矣。「若」下，次示頻大。前云「不存應法」，以非正教所開，恐生疑慮，故兩出之。若却不用，則於實年上更增十四日，故至二十六方得受耳。
【譯文】【記文】在第三段中。首先標示出如今所定的受戒期限。「歲末之日出生」，即當天的一日便算作虛歲一年。十九歲那年的八月受戒，中間實質度過了十七整年，前後合起來共七個月又十三天。依照這個實質數目，採用胎月、閏月等四種層位推算，剛好圓滿二十年。然而出生的日子與受戒的月份未必人人固定，只要依循這個法則為基準，隨各人的實際情況推算滿足，就足以為其授戒，不必再存懷疑。「若卻」以下，次說明扣除頻大月的情況。前文說「不存應法」，是因為頻大月並非正統聖教所開許，恐怕引起疑慮，所以兩套算法並列。如果捨棄不用，就必須在實際年歲上再追加十四天，因此要推遲到八月二十六日才可受戒。

【815-0006】02_戒疏/19c_卷四下之一#42
【原文】【疏】有人依《多論》，數實月為十九年者。今準《四分》，與俗計同。如尼六法云：「十八童女二歲學戒，年滿二十，與受具足。」據此十八，未必年盡為歲，滿十八年朝即是十八，依教便受六法，明年十九方二歲學，後年正朝，豈非二十？如此例之，縱極小者，年暮受法，即此一日便當一年，明年具行，後年正月一日受戒，豈非二十也？若不爾者，要滿十八，至十九年初，方受六法，明年二十，始學一年，年滿學終，後年二十一方與受者。又無律文如此延引。故知剋定以俗年為定。餘文云云，何由可盡！
【譯文】【疏文】有人依照《薩婆多論》，主張必須計算實足的月份達到十九整年。現在依照《四分律》，其年歲的算法與世俗相同。正如比丘尼六法中所說：「滿十八歲的童女應當給予兩年時間學戒，年滿二十歲，再為其授具足戒。」依據這裡所謂的十八歲，未必是指十八個整年全都過盡才算一年，只要進入滿十八歲的那一年正月初一就算十八歲，依教法便能領受六法；到了明年十九歲正好修行兩年，後年的正月初一，豈非就是二十歲？照此推例，縱使是年齡極小的極端例子，在歲末最後一天領受六法，光是這一天便充當了一年，第二年整年修行，第三年正月一日受戒，豈非也是二十歲嗎？若不如此解釋，非要實足滿十八年，等到第十九年之初才准許受六法，到了第二十年才開始學習了一年，學期圓滿結束，要等到第二十一年才為其授戒。但各大律藏中根本沒有如此拖延拉長年限的明文。由此可知，律中規定完全是以世俗通行的跨年算法為準定。其餘律文的議論繁多，哪裡能說得盡！

【815-0007】02_戒疏/19c_卷四下之一#43
【原文】【記】五中。初引彼妄執。《多論》云：「真實不滿，乃至無十九故，所以不開也。」彼謂十九，乃約實月，則俗年二十也。「今」下，舉例難破。成上俗年十九，八月得受之義。初二句，通示。「準《四分》」者，即如下引。「與俗同」者，謂俗中論年齒，亦取跨涉，不數實月。「如」下，引例，又二。初舉文。「據」下，示年數。初約跨涉，合教以證今義。「若不爾」下，次約實月乖文，以顯昔非。「故」下，準決。「餘」下，指廣。
【譯文】【記文】在第五段中。首先引述那些人的妄加固執。《薩婆多論》說：「若真實年歲不滿，甚至連十九歲都不到，所以不予開許。」古人認為所謂十九歲，是指實足計算月份，換算起來世俗虛歲就是二十歲。「今準」以下，舉出先例加以難破。藉此確立上述世俗虛歲十九、在八月即可受戒的主張。開頭兩句為通體開示。「準《四分律》」，即如同下文所引。「與世俗相同」，是說世俗計算年歲，也是採用跨越年份的算法，並不逐月累計實足月份。「如尼」以下，引律例證明，又分為兩層。初舉出律文。「據此」以下，說明年數計算。首先依跨年算法，契合教理以印證今義。「若不爾者」以下，次就實月算法會違背律文，以顯明古說之謬。「故知」以下，依準決斷。「餘文」以下，指示其餘廣泛文證。

【815-0009】02_戒疏/19c_卷四下之一#45
【原文】【疏】發諍戒六十六。
【譯文】【疏文】重新挑起諍事戒第六十六。
