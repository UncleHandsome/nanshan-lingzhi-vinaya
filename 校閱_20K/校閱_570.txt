# 校閱材料　第570檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【570-0001】資持記/09c_中三上#5
【原文】謂使尼去時，比丘恐犯；故先自起，欲令尼去。釋三中，初引《多論》別示屏過。以人不見，放逸無慚，思行婬欲，故以二過以命其處。次引律文通釋三緣，初釋第三。指如前者，煙塵闇黑名見屏，常語不聞名聞屏。據此以論，未必覆障。若下，次釋二四。疏云：盲聾互有，不成全證，故吉；
【譯文】這是指當作為第三人的使女（使尼）離開之際，比丘唯恐自己犯戒，所以自己先起身離開，目的是讓同坐的比丘尼也跟著離去。在解釋第三項時，首先引用《薩婆多論》分別揭示隱蔽處的過失。因為旁人看不見，人便容易放縱懈怠、不知慚愧，進而思量做出淫欲之事，所以才以這兩種過患來判定該場所的過失。接著引用律文融通解釋三種條件，首先解釋第三項。文中所指與前文相同，如果煙霧灰塵昏暗漆黑導致看不清，稱為「視覺上的隱蔽」；若是尋常說話聲音聽不見，稱為「聽覺上的隱蔽」。依據這個道理來推論，隱蔽場所未必一定要有實體的牆壁遮障。在「若」字以下，接著解釋第二與第四項。義疏指出：如果第三人是盲人或聾人，由於不能構成完全的見證，所以結突吉羅輕罪；

【570-0002】資持記/09c_中三上#6
【原文】又是坐戒，立故是輕。不犯有四。初是同侶，二即俗人，此二皆謂有第三人；三謂非意；四即遭難，文闕病緣。二十七。〔佛在舍衛，六群與六群尼共行，人譏故制。〕緣中。準疏有六，加第四不離見聞處〔離則非犯。〕第二言共到某村城國等。第三謂非伴行疑怖緣。
【譯文】再者，本戒原本是針對坐著而制定，若是站立著則罪責較輕。不犯的情況共有四種：第一種是有同行的僧伴，第二種是有世俗人在場，這兩種情況都是指現場有第三人在場；第三種是無意中巧遇並非存心；第四種是遭遇危難，此處文句遺漏了生病的開緣。第二十七條波逸提法。〔佛陀在舍衛國時，六群比丘與六群比丘尼相約結伴同行，受到世人譏嫌，佛陀因而制戒。〕在成犯條件中，依照義疏共有六項，並加入了第四項「彼此不離開視覺與聽覺的範圍」〔若是離開了視聽範圍便不犯戒。〕第二項是指相約共同前往某個村落、城鎮或國家等地。第三項是指並非出於恐懼疑慮而結伴同行之緣由。

【570-0003】資持記/09c_中三上#7
【原文】第五村聚，隨村分齊眾多界一一墮；空處，至十里墮；若減一村，減十里，皆吉。不犯有四。一不共期者，疏云：除偶相值，或期不許；而不離見聞，皆不犯。二大伴者，律緣眾多比丘與眾多尼皆欲從舍衛至毘舍離；以佛制戒，不與同行；尼眾在後，為賊所劫，白佛故開；兩眾多人，故云大伴；
【譯文】第五項關於村落聚落，隨著村落的分界，每越過一個界限就各結一個波逸提罪；若是在無人的曠野空處，每走滿十里便結一個波逸提罪；如果不足一個村落的分界，或是不足十里路程，都結突吉羅輕罪。不犯的情況有四種：第一種是未曾相約同行，義疏說：開許偶然相遇、或者是對方相約而自己不答應的情況，即使沒有離開相互的視聽範圍，也都不犯。第二種是有龐大的同伴隊伍，律典的緣起是許多比丘與許多比丘尼都打算從舍衛國前往毘舍離國；由於佛陀制定戒律，比丘不得與尼僧同行；尼僧落後走在後方，半路遭到盜賊劫掠，向佛陀稟告後佛陀才開許同行；因為兩眾人數都很多，所以稱為大伴同行；

【570-0004】資持記/09c_中三上#8
【原文】今一比丘多尼亦開；又疏云：行途逈遠，招譏過大；縱多比丘，一尼亦犯，要得多尼方開；坐處譏輕，有兩比丘，即不犯位。〔前戒開通僧多尼少不犯。〕三若往安隱者，如病等別緣，必須前詣。四命梵難緣，文略力勢被繫，故云等也。下，引《十誦》過險，開意同前，但加負衣耳。
【譯文】如今一位比丘若與多位比丘尼同行也得以開許；此外義疏也說：路途遙遠漫長，容易招致嚴重的譏嫌誹謗；即使有眾多比丘在場，若只有一位比丘尼同行仍然犯戒，必須有多位比丘尼才能開許同行；至於同坐一處的譏嫌較輕，只要有兩位比丘在場，就屬於不犯戒的範圍。〔前一條戒開許比丘多而比丘尼少的情況下不犯戒。〕第三種是前往安全穩妥之處，例如患病等特殊事故，必須親自前往求醫。第四項是為了避開危害生命及梵行的災難，條文中省略了遭到強權勢力囚禁禁錮等情事，所以用「等」字概括。在後文引用《十誦律》中度過危險險境的記載，其開許的意趣與前文相同，只是額外增加了替對方背負衣物這項內容罷了。

【570-0005】資持記/09c_中三上#9
【原文】二十八。〔佛在舍衛，六群與六群尼共乘船，人譏故制。〕緣中。準疏有六，但於三中分出四五。三同一船。四順流上下，文開直渡，必約上下往來方結；又但取作意，纔入即犯，不待船行。第五謂非直渡失濟之緣。第六雙脚入犯，律中一脚在船，一脚在地，吉羅。準疏俗女亦犯。不犯中。律云直渡彼岸也。
【譯文】第二十八條波逸提法。〔佛陀在舍衛國時，六群比丘與六群比丘尼共同乘船，引來世人譏嫌，佛陀因此制戒。〕在成罪條件中，依照義疏共有六項，只是在第三項中分立出了第四與第五項。第三項是共乘同一條船。第四項是順著水流向上游或下游航行，經文開許橫截直渡到對岸，但必須是有向上游或向下遊航行往返的意圖才會結罪；而且只要心生此意，剛踏入船身就已犯戒，不必等到船隻開動。第五項是指不具備橫直渡河時船夫操作失控的免責事由。第六項是雙腳同時踏入船中即算犯戒，律典中若是一隻腳踏在船上、一隻腳踩在岸地，結突吉羅輕罪。依照義疏的看法，與世俗婦女同乘也同樣犯戒。在不犯的情況中，律典記載只要是單純橫直橫渡到彼岸就不犯。

【570-0006】資持記/09c_中三上#10
【原文】〔但開過岸，非謂遠途。〕失濟者，本為直渡，上下非意。又云：往彼岸不安隱〔却返上下〕，勢力繫閉命梵等，皆開。二十九。〔佛在舍衛，居士請舍利弗、目連食；偷蘭難陀尼言是皆下賤人，勸請調達是龍中龍，因制。〕緣中。第二知者，疏云知是非法。
【譯文】〔此處僅僅開許橫渡過對岸，並非指長途水路旅行。〕所謂迷失航向，是指原本為了橫直渡河，轉往上下游並非本意。律中又說：前往對岸並不安全〔因而被迫折返或上下漂流〕，或是遭到惡勢力拘禁捆綁，以及面臨生命危險、損害梵行等急難時，都得以開許。第二十九條波逸提法。〔佛陀在舍衛國時，居士邀請舍利弗與目犍連應供用餐；偷蘭難陀比丘尼卻向居士詆毀說這兩位都是下賤之人，勸居士應當迎請提婆達多，稱讚他是人中之龍，佛陀因此制戒。〕在成犯條件中，第二項提到「明知」，義疏解釋為明知這是不合戒律的非法讚歎。

【570-0007】資持記/09c_中三上#11
【原文】釋中，本律，初明贊歎。上二句即十二頭陀，略舉初後三種，故云乃至。讚下，四種名相可知。次釋食中，初明時食。疏云大小二食俱犯。除下，明餘物。疏云：衣輕者，財重難捨，燈油物微故也。《僧祇》為七，初句。彼因長者見長老比丘，辨食供養；尼為料理，往請白時至行食等；
【譯文】在文義解釋中，本律首先說明了比丘尼讚歎的情狀。前兩句是指十二頭陀苦行，此處只概略舉出最初與最後的三種苦行，所以用了「乃至」一詞。在稱讚的下文，列出了四種名相，內容顯而易見。接著在解釋食物時，首先說明了正餐時段的食物。義疏指出，早晨與中午兩餐正食受請都算犯戒。「除」字以下，說明其餘的物品。義疏解釋：衣物判罪較輕，是因為大眾對財物執著難捨，而燈油等物品價值微薄的緣故。《僧祇律》將此分為七種情況，第一句是緣起。那是因為長者看見年長德高的比丘，便準備食物前來供養；有位比丘尼在旁張羅協助，前往請示並稟報時間已到、可以行食等等；

【原文】比丘疑不敢食，乃至白佛，佛聽除舊檀越。此明元是舊識，非因彼歎而致請故。二乃至下，彼云：有唱供時歎，始下食時歎，初作食時歎，作食辨已歎，有請時歎，此五並以更有至墮等文該之。今舉二種，故云乃至。前云更有比丘非歎不犯；復言此是頭陀，正歎故墮。
