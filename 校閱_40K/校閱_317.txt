# 校閱材料　第317檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【317-0001】資持記/15b_下三#9
【原文】攝諸根者，謂恭謹也。長夜通目現未，安樂通世出世。三中，《智論》，初明對佛不同，有四；前二，俗眾俱坐，命不命別。後明道眾，或坐不坐，學無學分。三道，即三果；凡夫，可知。未辨，謂所證道；未破，謂所斷惑。又下，次明大小坐次。餘佛僧徒，三乘位別；
【譯文】所謂「攝諸根」，是指舉止恭敬謹慎。「長夜」通指現世與未來世，「安樂」則通貫世間與出世間的善果。在第三段中引用《大智度論》，首先說明面對佛陀時的不同禮儀，共有四種情形：前兩種是世俗在家眾都坐著，以有無受命來區分；後面則是說明出家修道眾，有的坐、有的不坐，以有學位與無學位來區分。「三道」就是指聲聞前三果；「凡夫」之況自然可以想見。所謂「未辨」，是指尚未證得極致聖道；「未破」，是指尚未斷盡相應惑障。「又」字以下，接著說明大乘與小乘的座位次序。其他諸佛的僧團徒眾中，三乘階位各有不同；

【317-0002】資持記/15b_下三#10
【原文】釋迦之眾，純一聲聞，故云無別菩薩僧也。文殊師利，此云妙吉祥；彌勒，此云慈氏。次第，謂依夏臘。準此以明，諸大菩薩，必應示受聲聞律儀；即經所謂即現聲聞而為說法，是也。次科，不應中，初文。四種，前是俗人，餘皆道眾；入復二是下座，三即非僧，四即無德；
【譯文】釋迦牟尼佛的僧團大眾，純粹是聲聞僧相，所以才說沒有另外分立的菩薩僧。文殊師利在此翻譯為「妙吉祥」；彌勒在此翻譯為「慈氏」。所謂「次第」，是指依照受戒的夏臘長幼來排定。按照這一點來說明，諸大菩薩必定都示現受持聲聞律儀；這也就是經中所說的「即時示現聲聞身而為說法」的道理。在下一個科判「不應敬禮（不應）」中，第一段鈔文。四種人中，前一種是世俗凡人，其餘皆是出家道眾；進入道眾中，其二是下座，第三是不成僧數之人，第四則是無德之人；

【317-0003】資持記/15b_下三#11
【原文】三中，十三難人無戒三舉行缺，二滅體壞。古來國朝，多有令僧反拜君父。蓋不知三寶福田，四生依怙；道超塵網，德跨樊籠；君不得臣，父不得子；不墮四民之數，是為三界之賓；形雖免於屈申，心敢忘於奉敬。但以志求解脫，仰答劬勞；不怠重修，上資治化；豈唯拜伏，方為報德乎！
【譯文】在第三種之中，十三難人根本未曾得戒，受三舉（不見罪、不懺罪、惡邪不捨）處分者戒行有缺，犯二滅（已滅擯、應滅擯）者戒體全壞。自古以來世俗朝廷，多有下令僧人反過來跪拜君王與父親的。這大概是因為不知三寶是無上福田，是四生六道的依仗與歸宿；出家之道超越塵俗羅網，出家之德凌駕世間樊籠；君主不得將其視為臣下，父親也不得將其視為私子；僧人不再列入四民戶籍之數，乃是超越三界的尊貴之賓；身體形貌雖然免除了世俗的屈膝俯首，內心又何曾敢忘卻敬奉追慕之誠！僧人只是志在求取解脫，以此仰答父母撫育的辛勞；勤勉修行不敢懈怠，以此在冥冥中資助國家教化；難道只有匍匐跪拜，才算得上是報答恩德嗎！

【317-0004】資持記/15b_下三#12
【原文】《寶梁》中。八輕者，由無慚恥，慢易有德，即因心也；下列八法，並來報也，或可六七通於現未。乃至下，明德薄；毀戒之人，片地無分；即《梵網經》云：不得國王地上行，不得飲國王水；五千大鬼，常遮其前，掃其脚跡，罵言大賊等；又如《佛藏》，不消一杯之水，一納之衣，何況四事。
【譯文】《寶梁經》中，所謂「八輕」，是由於毫無羞恥之心，輕慢侮慢有德之人，這就是因地的心念；後文所列出的八種惡法，全都是招感而來的果報，或者第六、第七兩種果報也可以通貫現世與後世。乃至於下文說明德行淺薄之處；毀犯禁戒的人，連在寸土之上立足的資格都沒有；這正如《梵網經》所說：不得在國王的土地上行走，不得飲用國王土地的水；五千名大鬼常擋在其身前，掃去其走過的腳印，斥罵其為大賊等等；又如同《佛藏經》所言，連一杯水、一件補衲之衣都消受不起，更何況是四事供養。

【317-0005】資持記/15b_下三#13
【原文】指上篇者，即〈對施〉中。應禮中，初文。無緣者，緣見次科；下禮於上，故云合敬。下大小相敬中自說，故此指之。二中，初廣引諸文。《四分》十種，大小行為二。《增一》塔中，謂非處也。《五分》相瞋，謂心惡也。《十誦》有五，并下二塔前為七。《僧祇》有七，分之可見。《五百問》示犯，準應得吉。
【譯文】此處指出「見於上一篇」，就是指在〈對施興治篇〉之中。在「應受禮敬（應禮）」的第一段文中（初文），所謂「無緣」，其特定緣由見於下一科判；下座頂禮上座，所以說是合乎敬法。在後文「大小相敬」章節中自然會說明，因此在這裡先作提示。第二部分中，起初廣泛引用各部經律。《四分律》列出十種情況，大行與小行分為兩類。《增一阿含經》提到的「塔中」，是指行禮的處所不合宜。《五分律》說的「相瞋」，是指內心懷有惡念。《十誦律》列出五種，連同後面塔前的兩種合為七種。《僧祇律》列出七種，依文剖析即可明瞭。《五百問》指明犯過情況，依準律制應當結吉羅罪。

【317-0006】資持記/15b_下三#14
【原文】《僧祇》六種。皆下，別示經塔等不得之意。三中，標分。有三，初是佛寶，義須兼法；下正明云，佛像經教住持儀等是也，即題中像字；下之二科，僧別分之，即題中僧字。敬儀中，初科，初正明。準前盜戒，佛受用物，乃至為佛，亦不得賣易。支提，亦翻為廟。故下，引證。王，即瓶沙王。
【譯文】《僧祇律》列出六種情形。「皆」字以下，分別說明在佛經、佛塔等處不得受禮的緣由。第三部分是標示分章。共分為三科：第一是佛寶，依義理必須涵蓋法寶；下文正文明確說道，佛像、經教、住持儀軌等即屬此類，也就是篇題中的「像」字；後面兩個科判，僧團與個人分別說明，也就是篇題中的「僧」字。在「敬重儀軌（敬儀）」中，第一科首先正式說明。依照前文盜戒的標準，佛陀受用的物品，乃至是為了佛陀而設之物，都不可以轉賣變換。「支提」也可以翻譯為「廟」。「故」字以下，是引用經文作證。「王」就是指頻婆娑羅王。

【317-0007】資持記/15b_下三#15
【原文】注文語勢連上，合是大書，疑其傳誤。施佛，則永不通僧；施僧，則兼通於佛。次科。五功德，前四別報，並列因果；後一總報，通前為因，故但示果。南無，《經音義》中，翻為歸禮，或云歸敬，或云度我。如來者，《成論》云：乘如實道，來成正覺；無所著者，離塵染故；至真者，離虛偽故；
【譯文】註文的語氣與上文連貫，原本應當作正文大字書寫，懷疑是傳抄過程中的錯誤。布施給佛的財物，就永遠不能通給僧眾使用；布施給僧眾的財物，則可以連帶通及於佛。下一個科判中，五種功德裡，前四種屬於別報，都是因果並列列出；最後一種屬於總報，總括前面的善因為因，所以只明示果報。「南無」在《一切經音義》中，翻譯為歸禮，或者說是歸敬，或者說是度脫我。「如來」一詞，《成實論》解釋為：乘著如實之道而來成就正覺；「無所著」是指遠離塵世染著；「至真」是指遠離虛妄造作；

【317-0008】資持記/15b_下三#16
【原文】等正覺者，謂三世道同，正即簡異邪妄。此即下，勸修。諸佛所行，下凡宜學。三中，初引三禮。口即言相審問，名下禮；屈膝即跪，為中禮；頭至地，即稽首也。地下，示五輪。《地持》語通，故引《阿含》續釋。五處皆圓，故名五輪；四支及首，名為五體；輪則別指五處，體則通目一身。先下，正示禮儀。
【譯文】「等正覺」是指三世諸佛所證之道平等無別，用「正」字來揀別排斥邪知妄見。「此即」以下，是勸勉大家修持。這是諸佛所實踐的行止，凡夫末流理應虛心學習。第三段中，首先引用三種禮拜儀軌。口頭以言語互相關懷問候，稱為「下禮」；屈膝而跪，稱為「中禮」；頭頂叩觸地面，就是「稽首」。在「地」字以下，開示「五輪」之意。《地持論》用詞較為籠統，所以引《阿含經》繼續解釋。這五個部位形狀皆圓，所以稱作五輪；四肢與頭部，合稱為五體；「輪」是個別指稱這五個部位，「體」則是通盤指稱整個身軀。「先」字以下，正式開示頂禮的儀態。
