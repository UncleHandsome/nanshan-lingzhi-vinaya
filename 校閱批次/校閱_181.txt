# 校閱材料　第181檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【181-0001】資持記/10a_中三下#20
【原文】彼明天竺說時有二：一名迦羅〔此云實時，謂年月日時四時部氣等，世俗背計為實故。〕，二名三摩耶〔此云假時。謂隨事緣，長短不定，無有實故。〕。佛隨世諦，說三摩耶不說迦羅，為除外道俗人邪見故〔俗人著有，外道計常；若說實時，更增彼計。此亦大分為言，非俱不說。〕。
【譯文】該論說明印度對於「時」的說法有兩種：第一種叫做迦羅〔這裡翻譯為實時，指的是年月日時、四季氣候等，世俗凡夫執著妄計為真實的緣故〕；第二種叫做三摩耶〔這裡翻譯為假時，指的是隨著事緣而定，時間長短不固定，沒有實體本質的緣故〕。佛陀順應世俗的道理，說假時而不說實時，是為了破除外道和俗人的邪見〔俗人執著實有，外道執著恆常；如果說實時，會更加增長他們的執著妄計。這也是大致而言，並非完全不說〕。

【181-0002】資持記/10a_中三下#21
【原文】論中，先破彼計實時皆無有實。然毘尼制法，多依實時；則顯如來亦說實時，豈是無時；故以為問，如鈔所引。答中為二，初約義釋通；二佛下，遮其來難。初中三義，初從假釋。論中難破時已，乃云見陰界入生滅假名為時無別時。〔謂時經及餘經等亦說實時，乃是隨世名字，故云假名，此與俗說假名言同義別。
【譯文】論中，首先破除他們妄計實時都是沒有真實體性的。然而戒律所制定的法則，大多依據實時；這就顯示如來也說實時，哪裡是沒有時間呢？所以拿這點作為疑問，如同《行事鈔》所引用的那樣。回答中分為兩部分：第一是依據義理來解釋通達；第二是從「佛」字以下，阻擋對方的詰難。第一部分有三種義理，首先從假名來解釋。論中詰難破除了實時之後，才說看見五陰、十八界、十二入的生滅而假名為時間，並沒有另外的時間實體。〔這是說《時經》以及其餘經典等也說到實時，只是隨順世間的名相，所以稱為假名，這與世俗所說的假名是詞同而意異。

【181-0003】資持記/10a_中三下#22
【原文】又準佛說則彼二皆是假名，隨彼而言，故云實耳。〕文云我已說者，即指上文。世界法有故，不妨說時非時；非實故，不妨無時；立論已明，不審重問，故反責之云不應難。〔有下闕時字，實下脫法字，論本有之。〕亦是下，次隨世釋。世界實者，俗所計也。〔論文實下有非第一實一句，又無有字。〕眾人呵者，即指緣起。
【譯文】又依照佛陀所說，那麼這兩種說法都是假名，只是隨順世俗而言，所以稱為實體罷了。〕文中說「我已經說過」，就是指上文。因為世間法存在的緣故，不妨礙說適當時限與非適當時限；因為不是真實體性的緣故，也不妨礙時間本無實體；論點已經立得很清楚，不再審查卻重複發問，所以反過來責備他說不應當這樣問難。〔「有」字下面缺少「時」字，「實」字下面脫漏「法」字，論典原本中是有的。〕從「亦是」以下，其次是隨順世間來解釋。世間的真實性，是俗人所執著的。〔論典文字在「實」字下面有「非第一實」一句，又沒有「有」字。〕眾人訶責，就是指制戒的緣起。

【181-0004】資持記/10a_中三下#23
【原文】〔律中女人呵迦留陀夷云：寧自破腹，不應夜食。〕由彼計實而致譏訶，律附世相遮譏故制。亦欲下，三護法釋。謂受戒時分定上中下，互相敬事，令法不滅，故云使久存等。〔初義約假從道以釋，後二約實從俗而釋。〕遮來難中。以毘尼制教，隨順世諦，從權建立，不可橫以真理而難俗事；
【譯文】〔律文中婦女呵責迦留陀夷說：寧願自己剖破肚子，也不應當在夜間進食。〕由於世人執著實時而招致譏諷呵責，戒律依循世間相狀以制止譏嫌，所以才制定此戒。從「亦欲」以下，第三是為了護持正法來解釋。這是說受戒的時間先後決定了上座、中座、下座的次序，彼此恭敬事奉，使得正法不致滅亡，所以說能讓佛法長久存在等。〔第一種義理是就假名而言、順從修道來解釋，後兩種則是就實時而言、順從世俗來解釋。〕在阻擋詰難中。因為戒律的制止教化，隨順世俗的諦理，是依權巧而建立的，不可強行用勝義真理來詰難世俗事相；

【181-0005】資持記/10a_中三下#24
【原文】以化就蕩相，制是建立，故云不應求等。論具云：諸佛世尊結諸戒，是中不應求有何實〔體之虛實〕，有何名字〔名之有無。〕，何者相應，何者不相應〔義之違順〕；何者是法，如是相；何者是法，不如是相〔相之是非〕，以是故是事不應難。〔化教詮理，必須四義求之。〕次難中。
【譯文】因為化教側重於破除執相，制教側重於建立事相，所以說不應當追求等等。論中完整說：諸佛世尊制定各項戒律，在這當中不應當追求有何等真實體性〔本體的虛妄或真實〕，有何等名字〔名稱的存在或沒有〕，什麼是相應的，什麼是不相應的〔義理的順從或違逆〕；什麼是法，符合這樣的相狀；什麼是法，不符合這樣的相狀〔法相的是與非〕，正因如此，這件事是不應當詰難的。〔化教詮釋真理，必須依據這四種義理去探求。〕在第二個詰難中。

【181-0006】資持記/10a_中三下#25
【原文】論文前云如來為除邪見，不言迦羅，說三摩耶。謂餘經中多說假時；如上引律，乃說實時；義有相違，故以為難。答中為二，初明毘尼說實意，上句正示。〔不字誤，論文正作中字。〕以下，顯意。謂毘尼不許白衣外道聞故，可說實時；以道眾自知非實，不生邪執故。〔文中下聞字，論作而字。〕說下，次明餘經說假意。
【譯文】論典文字先前說如來為了破除邪見，不言迦羅，而說三摩耶。意思是其餘經典中多數說假時；但像上面引用的戒律，卻說的是實時；義理上存在矛盾，所以拿來詰難。回答中分為兩部分：首先說明戒律中說實時的意圖，上一句正式指出。〔「不」字是傳抄錯誤，論文原本正是「中」字。〕從「以」以下，顯明其用意。這是說戒律不允許在家人和外道聽聞，所以可以說實時；因為出家修道的大眾自己明白並非真實體性，不會生起邪妄執著的緣故。〔文中下面的「聞」字，論文原本寫作「而」字。〕從「說」以下，其次說明其餘經典說假時的意圖。

【181-0007】資持記/10a_中三下#26
【原文】通多分者，道俗俱可聞故。〔古多錯解，妄改文字；學者難曉，不免繁文。〕顯意中。以學語者恥已貪嗜，濫謂大乘無時非時；故今還引《大論》以誡邪執；近世學大學小，噉食無時，不畏佛戒。銅漿鐵丸，焦爛喉腹，病徹心髓，誰當代之？悲夫！次科。經即《毘羅三昧經》。
【譯文】通於大多數人，是因為修道者與世俗大眾都可以聽聞的緣故。〔古人大多錯誤理解，胡亂更改文字；導致後學難以通曉，免不了徒增繁複的文字。〕在彰顯教意中。因為學人口頭空談，羞於承認自己的貪吃嗜欲，胡亂說大乘佛法沒有適當時限與非適當時限；所以現在依然引用《大論》以告誡這種邪執；近代無論學大乘還是學小乘的人，吃東西沒有固定時限，毫不畏懼佛陀的戒律。將來吞飲熱銅漿、咽下鐵丸，燒焦腐爛喉嚨腸胃，痛苦徹入心肺骨髓，那時誰能代你受苦呢？真是悲哀啊！下一個段落。這部經就是《毘羅三昧經》。

【181-0008】資持記/10a_中三下#27
【原文】通列四時。前後三種，大約不定。日中一種，佛佛常法；以住中道，假事表理故；凡所化儀，無不皆中。佛制下，正顯教意。上有三趣，地獄同鬼類。欲超三界，必斷六因。故制比丘不同彼食，令依極聖，出離可期。嗟彼愚人，多食晚食；肯斆諸佛，而甘同鬼畜，不知何意乎！

【原文】《戒疏》具五緣，加第二隨非親乞，準此開親。釋初緣中。前引《僧祇》以明譏過。八種是總舉，乳酪即別相，彼律酥油乳酪蜜石蜜魚肉為八種。言招譏者，彼律俗人譏言瞿曇沙門，不能乞麁食，而乞酥油等；此敗壞人，何道之有。次《五百問》，以云別犯。
