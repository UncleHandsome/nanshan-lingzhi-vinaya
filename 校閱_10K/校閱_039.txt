# 校閱材料　第039檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【039-0001】01_行事鈔/03a_卷上之三#24
【原文】二犯比丘尼。《四分》等律並云汙尼，不明淨穢。故世行事者云：「汝不犯清淨尼不？」此依《僧祇》而問。彼律云：若須、斯二果及凡夫持戒尼，被人污者，初人受樂，是壞尼淨行；中後人犯，不名壞尼難。若那含、羅漢，初後人俱名難也。故知唯是淨境，方成難攝。《十誦》云：若摩觸八尼，污尼八事；若一人以八事犯尼，令犯重者，俗人不成難也。《善見》云：若壞尼下二眾，不障出家；若壞大尼，三處行淫，皆名難也。若以白衣俗服強與尼著而行淫者，成難；若尼自樂著白衣服就上淫者，不障出家。必以義求，若知受具戒緣事，著於俗服亦應成難。但壞淨境，不論知淨不淨。廣有廢立，如《疏》、《義鈔》。問：何不言壞比丘耶？答：亦成難也。尼受戒中反問便是，由事希。故《善生經》：受五戒者，問遮難云：「汝不犯比丘、比丘尼不？」故知同是難攝。皆謂俗人時犯；若受戒已，犯者，止名邊罪所收。
【譯文】第二、犯比丘尼難（污尼）。《四分律》等律典皆只稱「污尼」，並未明言被污者是清淨尼還是已非清淨尼。所以世間主持法事者往往問：「你沒有犯過清淨尼嗎？」這是依照《僧祇律》的問法。該律說：如果是初果須陀洹、二果斯陀含以及持戒凡夫比丘尼，遭人染污時，最初那人侵犯時比丘尼若感受染樂，這便是破壞了比丘尼的淨行；中間及後續行淫之人再犯，就不名為破壞淨尼之難。若是三果阿那含、四果阿羅漢比丘尼，則最初與後續行淫之人皆算構成重難。由此可知，唯有侵犯清淨之境，才構成此難所攝。《十誦律》說：如果與比丘尼身相摩觸，或對比丘尼行八事（共八人各行一事，或一人具行八事），使比丘尼犯下重罪，在家人本身並不構成重難。《善見論》說：如果破壞了尼眾中的下二眾（式叉摩那、沙彌尼），不障礙其出家受具；如果是破壞具足戒大尼，在口、大便道、小便道三處行淫，都稱為重難。如果以在俗白衣俗服強行給比丘尼穿上而行淫者，構成重難；如果是比丘尼自己歡喜穿上白衣俗服前往行淫者，不障礙出家。若必定以法理推求，如果明知她是受過具足戒的比丘尼因緣，縱然她穿著俗服，行淫者也應構成重難。只要破壞了清淨戒境即可，不論行淫時知不知其為清淨尼。此中廣泛的取捨廢立，正如《四分律疏》與《義鈔》中所說。有人問：為何不說破壞比丘（污比丘）呢？回答：侵犯比丘同樣構成重難。在比丘尼受戒法中反過來詢問便是，只因俗男侵犯比丘之事極其稀罕。所以《善生經》中，為在家受五戒者審問遮難時便問：「你沒有侵犯過比丘、比丘尼嗎？」由此可知同樣屬於重難所攝。這全都是指作在家人時所犯；如果已經受了具足戒之後才犯此事的，則只歸於邊罪難所收攝。

【039-0002】01_行事鈔/03a_卷上之三#25
【原文】三賊心受戒者。律中為利養故，輒自出家。若未出家者，未受，不應受；已受，得戒。曾經說戒羯磨，已受者滅擯。《四分》云：若至一人二人三人眾僧所，共羯磨說戒，皆滅擯。義詳，共一人作對首眾法，皆成障戒。如說戒自恣等法，必聽眾法心念，亦成難攝。若對他三人已下對首法，四人已上餘和合法，不秉羯磨，皆不成難。《善見》云：三種偷形：一者無師自出家。不依大僧臘次，不受他禮，不入僧法事，一切利養不受。二偷和合者。有師出家，受十戒，往他方；或言十夏，次第受禮，入僧布薩一切羯磨，受信施物。三二俱偷者，可知。若偷形者，不經法事，不受禮施，為飢餓故，若欲出家，受戒者得。《五百問》云：沙彌詐稱大道人，受比丘一禮拜，是名賊住難。《四分》中但言賊住難者，謂共羯磨說戒，不說聽聞不聞及愚癡因緣等。依如《僧祇》。若沙彌作是念：說戒時論說何等，即盜聽之。若聰明記得初中後語者，不得與受戒；若闇鈍或緣餘念，不記初中後者，得受具。若凡人，自出家著袈裟，未經布薩等者，得受；反之不得。《摩得伽》云：不自知滿二十而受具，後知不滿者，若經僧布薩羯磨，是名賊住。《四分》疑惱戒云：若年不滿，作法不成受者，有知者語令識之，後更受戒。《十誦》云：比丘尼如法捨戒，若更受者，不得。即名賊住難。
【譯文】第三、賊心受戒難（賊住難）。律典中說，有人為了利養的緣故，擅自冒充出家。如果是尚未正式出家者，若未受戒，本不應為他受戒；若是已經受了戒，則得戒。但若是曾經參與僧團的說戒布薩或羯磨法事，已經受戒者必須予以滅擯（驅逐趕出僧團）。《四分律》說：若是到一人、二人、三人或大眾僧處，共同參與羯磨、說戒，事後皆應滅擯。依義理詳察，哪怕只是與一人作對首法，或是參與眾法，都會構成障戒之難。例如說戒、自恣等法，若是偷聽了獨住僧人所作的眾法心念羯磨，也屬於此難所攝。若是面對三人以下的對首法，或四人以上的其他和合法，只要沒有秉持正式羯磨，都不構成此難。《善見論》說有三種偷盜形相：一是無師自通私自剃髮出家。但他不依大僧戒臘次序排位，不接受他人禮拜，不參與僧團法事，一切利養也都不受。二是偷盜僧團和合僧相者。這是有師父為其剃度出家、受了十戒，但前往他方時，妄稱自己戒臘已有十夏，依序接受僧人禮拜，參與僧團布薩及一切羯磨，接受信眾施捨財物。三是形相與僧事兩者皆偷盜者，其相狀可想而知。如果是單純偷盜出家形貌者，未曾參與僧團法事，未曾接受禮拜與布施，只因飢餓糊口而穿僧服，日後若真想發心出家，是可以為他授戒的。《五百問經》說：沙彌詐稱自己是大比丘，接受了具足戒比丘的一拜，這就名為賊住難。《四分律》中只說賊住難是指共同參與羯磨說戒，並未詳述盜聽時究竟聽懂與否、以及愚癡不知等因緣。若依照《僧祇律》所說：沙彌若心想「僧團說戒時究竟講些什麼」，因而前去偷聽。如果天資聰明，能記得說戒從頭到尾（初中後）文句的人，日後不得為他受戒；如果資質愚鈍、或受其他念頭分心，記不得全部語句者，仍得受具足戒。若是普通凡人，自己冒充出家身披袈裟，但未曾經過布薩等僧事者，可以受戒；反之，若已經歷僧事則不得受戒。《薩婆多部摩得伽論》說：自己不知年齡未滿二十歲而受了具足戒，事後知道不滿者，如果曾經參與僧團的布薩羯磨，即名為賊住。《四分律》在疑惱戒中說：如果年齡不滿，作法不能成就受戒者，若有知情者應當告知讓他明白，日後年滿應重新受戒。《十誦律》說：比丘尼若是如法捨了戒，日後如果想再受具足戒，是絕不允許的，再受即名為賊住難。

【039-0003】01_行事鈔/03a_卷上之三#26
【原文】四破內外道者。謂本是外道，來投佛法，受具已竟，反還本道，今復重來；彼此通壞，志性無定。律中，令度出家，對僧與沙彌戒，四月試之；使志性和柔，深信明著，方為受具。問：信邪來久，何故先與沙彌戒耶？答：信此投歸，若不以十戒調柔，違相不顯；又彰佛法深妙漸次授法，不同外道一往不簡。此事既希，多述無益，必有，律自廣明。
【譯文】第四、破內外道難（越濟人難）。是指原本是外道徒眾，前來投歸佛法，受完具足戒之後，又反悔返回原來的外道，如今再度前來求入佛門；這種人將佛教與外道兩邊的規矩皆予以毀壞，志向品性毫無定準。（為防與此難混淆，須辨明外道初來之法）律典中規定，外道初來投歸求度出家時，應在僧前給予沙彌十戒，並進行四個月的考驗觀察；務使其志向品性調和柔順，深切信心顯著明確，然後才為他受具足戒（若如前述反覆背叛破內外道者，則永不得受具）。有人問：他信奉邪見已久，為何要先給他受沙彌戒呢？回答說：既然他發心投靠歸依，如果不先以十戒調柔其身心，其違背佛法戒律的行相就顯露不出來；同時這也彰顯了佛法的甚深微妙，是循序漸進傳授戒法，不同於外道一下子全不加甄別簡選。這種事情既然極為稀少，多加贅述也無益處，如果真碰上了，律典中自會廣泛說明。
