== PROBLEM ==
把「不說得罪」（若不回答，就結得罪）誤解為「律中沒說會有什麼罪」，肯定獲罪被譯成否定（沒說會有罪），意思相反。 段040前半段記文被錯置於段039譯文末尾，造成段039增譯、段040漏譯。

== SUGGESTION ==
改為：「『若不回答便結得罪』，這句話是局限於受問者不作回答而言。」 將段039譯文末尾「『肅』就是肅靜安定的意思...如同將要的意思」移回段040譯文開頭。

== ORIG ==
應分下，四制昧暗。不說得罪，此局不答為言。

== CURRENT ==
在羯磨的正式作法中，審問能否成辦分為兩部分：第一是總體展示問答的規矩。引《十誦律》以下，是引述當初佛陀制定此戒的緣起，首先說明緣起的由來，也就是六群比丘隨意作法的過失。下文「佛陀……」，是裁定這種行為是非法的。下文「應當……」，是指出佛陀所制定的四條嚴格規矩：第一是制止心緣妄境，其餘雜念就是異心，動念稱為「覺」，反覆籌度思量稱為「思惟」。下文「應當……」，第二是制止怠慢輕忽戒法。下文「應當……」，第三是制止音聲節奏間隔中斷。下文「應當分別……」，第四是制止神志昏聵暗昧。律中沒說會有什麼罪，這裡是指局限於不作回答的過失。
