以下按則檢視。整體讀來通順，但有**幾處關鍵性誤譯**（漏「閏」字、「結去各十六日」、「保著生常」、「頗符水乳」），另有名相、科判與文句訛字的處理問題。

---

## 一、先確認本段的計算原則（可用來檢核譯文）

這一大段「閏月安居」的算法是：**閏月是「虛月」，不計入九十日**（故疏云「須跨過虛月」）；「住日」指**實際安住的天數**（含閏月），「去」指夏滿次日出界（即自恣後離去）。

驗算：閏四月二日結→（閏4/2～7/30）＝29＋90＝**119日住**，8/1去；閏4/30結＝1＋90＝**91日住**，8/1去。與原文全同。
又如閏七月：5/2結，至前七月盡日只89日，須取8/1一日足滿，故8/2去。

**由此可知「結去各十六日」絕不是「各住十六天」，而是「結夏的日期通十六日、離去的日期也通十六日」**（例：結4/16～閏4/1共十六日，去7/16～8/1共十六日）。此處 #3、#4、#6 三則全部譯錯，是本段最嚴重的系統性錯誤。

## 二、逐則問題

### 【1038-0001】
1. **「故云通二論也」譯「通於兩種論典」——存疑。** 上句既說「或依不依，隨人取捨」，「二論」很可能指「依閏／不依閏」兩種**說法**（兩可之論）。宜核對鈔文所引究竟是哪兩部論；若無確證，不宜逕譯為「兩種論典」。
2. **「不合受衣」譯「不得受衣」太含混。** 「受衣」是**受功德衣（迦提衣）**；因本知有閏須依閏，夏滿延後，故於常軌自恣日不合受功德衣。建議：「那麼就須依閏（夏未滿），不合受功德衣。」
3. 「即彼《伽論》」是說 **《業疏》所引即前文《摩得勒伽論》之文**，不是「那部《伽論》記載」；《伽論》宜補全名。
4. **「問答中。」是科判標語**，應作「（以下是）『問答』一科」，不宜譯成「在問答之中：」（#2「差別中」你已正確處理為「一科」，宜前後統一）。

### 【1038-0002】
1. **「以開難制」譯「緊閉的制條」——錯。** 「制」是**禁制、遮制**，與「開（開許）」相對。應作「用『開許』之文來詰難『禁制』之規」。
2. **「開犯獲利」譯「開許免除犯戒」——語意反了。** 是「開許（原本）違犯之事（如離衣宿、別眾食等），而獲得（五種）利益」，不是「免除犯戒」。
3. 「奢法」＝**寬緩（寬奢）之法**；「寬縱寬大之法」贅詞，可簡。
4. **「二六」宜補背景**：「一月」指迦提月（7/16～8/15），「五月」指受功德衣的五利期（七～十一月）。「一月中局閏七月」是說 **「一月」只限閏七月才會成二月**；「五月」則七、八、九、十、十一月中任一月有閏皆攝，故成六月。現在譯文「在一個月之中局限於閏七月」語意不明。
5. 「攝閏」＝**把閏月計入（開期）**，不是「攝受閏月」。「故不同也」宜補出比較對象：「所以（與五利『開犯獲利』的理由）不同」。

### 【1038-0003】
1. **「初位，五六二月」漏「閏」——關鍵錯誤。** 應是**閏五月、閏六月**。理由也須改：因閏月落在安居三個月的**中間**，結夏（4/16～5/16）與解夏（7/16～8/16）的**日期都不受影響**，故只立一位。譯文「這兩個月處於中間，不牽涉到結夏與解夏」意思含糊且失準。
2. **「結去各十六日」** 如前說，應作「結夏與離去的日期各通十六日」。
3. 「初四月住中」是第一位 **「四月住」（在四月結夏者）**，非「在四月安住之中」。

### 【1038-0004】
1. **「前通二十九日結」譯「前面總計二十九天內結夏」不清楚。** 應作「前面（閏四月）二日至三十日這二十九天中結夏的人，都同樣到八月一日才離去」。
2. 「結去各十六日」同誤（此處結5/1～5/16、去8/1～8/16）。
3. 「百十九日住」宜標明是**實際安住日數（含閏月）**，以免與「九十日成夏」混淆。「故唯三月」可補「只住三個月（九十日）」。

### 【1038-0005】
1. 「三句」「句型」——「句型」是語法學術語，此處是**三種對比句式／三種情形**，宜改。#7「疏立二句」同。
2. 「自恣降一日」＝自恣（離去）日只**差一日**；「相距降為僅差一日」可簡為「即只差一日」。
3. **原文兩注日期不一致**：第一注作「五月二日」，第二注作「五月一日」。依算，4/30結→7/30去、5/1結→8/1去，正好差一日，故第一注「五月二日」疑當作「五月一日」，宜出注存疑，不要照抄了事。

### 【1038-0006】
1. 「結去各十六日」同誤（結4/16～5/1，去7/16～閏7/1）。
2. **「未至閏」應指「（九十日夏滿時）還未到閏月」**，不是泛指「還沒碰到閏月」（因其離去日恰在閏月一日，易生誤解）。
3. 「三閏七月」＝第三段「閏七月」；與前「次閏四月」宜統一譯為「第二位／第三位」或「第二種／第三種情形」。

### 【1038-0007】
1. **「結通十月五日」文有訛字**，依算應作 **「結通十五日」**（結5/2～5/16共十五日，去8/2～8/16共十五日）。譯文默默把「十月」丟掉，應加校注說明。
2. 「結夏時間可通達十五天」→「結夏日期通於十五日，離去日期也有十五日」。
3. 其餘（89日、跨虛月、取8/1足滿、初二去）譯得準確。

### 【1038-0008】
1. **「前退後增」譯「前面的天數往後退、後面的天數往前增」語意不通（且自相矛盾）。** 依算應是：五月三日以後結夏者，**前（七月）所數的日數遞減、後（八月）所數的日數遞增**（5/3結→8/3去、5/4結→8/4去……），故與5/1結（閏7/1去）皆相隔一月。建議改譯並加注。
2. **「三時」譯「春、夏、冬」缺乏依據**：西土三時一般指**熱時、雨時、寒時**，宜作「三時（印度一年所分三季）」或加注。「常儀」是**常規、慣例**，不是「儀式」。
3. **「保著生常」譯「對常住處所生起耽著眷戀」——疑誤。** 「生常」是**生起「常住不變」之想（常想、常執）**，與下句「不思厭世」、對治語「薄情遣滯」正相呼應。建議：「大概是怕（比丘）貪保執著（房舍），生起常住不變之想，不再思惟厭離世間。」
4. 「《義鈔》文逸」宜作「《（拾毘尼）義鈔》之文已散佚（今不可見）」，比「原卷佚失」貼切。

### 【1038-0009】
1. **「頗符水乳」是肯定語，譯文加「表面看似」「混雜」是不當增義。** 應作「有的共住一堂，頗能契合水乳交融（和合）之義」——與下句「不異俗流」的貶語形成對比。
2. 「君子安遷」是**君子安於遷徙、不戀居處**（對「小人懷土」），「隨遇而安」偏義，宜正。
3. 「守株」重在**固守不知變通**；「固步自封、守株待兔」疊用略贅，可留其一。
4. 「行儀永墜」→「行持的軌儀從此永久廢失」，「永遠墜落」生硬。
5. **「舊住自知」不是「心知肚明」**（有知情不言之意），而是「舊住僧自己已知（房舍好壞），所以只叫客僧去看」。
6. 「故所絕聞」＝「所以此法（在東土）絕無所聞」；「銷聲匿跡」暗示曾有後失，稍偏。
7. 「簡於客舊」＝在客僧與舊住之間**有所簡別偏袒**，譯文可，但「主」宜點明是舊住（主）僧。

## 三、建議統一的譯法

| 詞 | 建議 |
|---|---|
| 結 | 結夏（安居開始之日） |
| 去 | （夏滿自恣後）出界離去之日 |
| 住 | 實際安住日數（含閏月） |
| 虛月 | 閏月（不計入九十日） |
| 攝閏 | 把閏月計入（開期） |
| 開／制 | 開許／禁制 |
| 奢法 | 寬緩（寬奢）之法 |
| 「…中」「…下」 | 科判：「…一科中」「『…』字以下」 |
| 「…句」 | 句（對比情形），非「句型」 |
| 結去各十六日 | 結夏、離去的日期各通十六日 |

**最需修訂的三處**：#3「閏五月、閏六月」漏「閏」、#3/#4/#6「結去各十六日」、#8「保著生常」；其次 #9「頗符水乳」的增義與 #2「以開難制／開犯獲利」。
