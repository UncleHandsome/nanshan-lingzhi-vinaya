# 校閱材料　第1139檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1139-0001】資持記/08b_中二#53
【原文】大小行者，論作行來處，即是行路。〔或云便利處。〕王臣恃勢，幻術惑眾，樂音蕩情；凡此等人，皆可畏避，故即成礙。以下，結名。界礙中，初科，前示兩界。上下，明異礙，初明界通三礙。若下，正顯界礙。文明各界通護，則顯互望不通。五下，引證。不自在者，謂有三礙。
【譯文】大小行處，論中作「行來處」，也就是行走的道路。〔或者說是指大小便處。〕王公大臣依仗權勢，幻術師迷惑大眾，倡伎音樂蕩滌心志；凡是這類人，都是應當畏懼迴避的，所以就構成了阻礙。以下結示其名稱。界礙之中，第一科，前面指示了兩重結界。「上」字以下，說明不同的阻礙，首先說明結界通於前三種阻礙。「若」字以下，正明何為界礙。文中說明各個結界只守護本界，便顯明彼此相互望去是不通的。「五」字以下，引述證明。所謂「不得自在」，是指存在上述三種阻礙。

【1139-0002】資持記/08b_中二#54
【原文】反上者，謂得自在。別釋中，初文。作法語通，此謂結攝衣界。若單攝僧，止屬自然伽藍界耳。下卷即〈二衣篇〉。次科，僧村界中，初科。體別相同，故合明之。初列名。各下，示相。垣牆是一，柵籬為二，此二並約周匝。籬牆不周為三，謂四圍有缺；若但三面有障，亦成村相。
【譯文】「反上者」是指能夠獲得自在。分別解釋中，第一段文字。所謂「作法」其語意寬泛，此處是指結攝衣界。如果是單純攝僧的結界，只屬於自然的大僧寺界罷了。下卷就是指〈二衣篇〉。下一科判，在僧伽藍界與村界中，第一科。體質雖別但相貌相同，所以合併說明。首先列出名目。「各」字以下展示相狀。垣牆算作第一種，竹柵木籬算作第二種，這兩種都是針對周圍環繞而言。竹籬垣牆不完整算作第三種，是指四圍有缺口；如果只有三面有障礙遮蔽，也構成村落的相狀。

【1139-0003】資持記/08b_中二#55
【原文】四周屋為四，謂上有覆，必兼簾壁等障。次科，引古中，先出彼意。此下，奪破。既云相壞，則非藍村；樹車自立，故云別界。疏云：若缺非藍，事同空野是也。今解中，初立義。僧下，引證。文如前釋。乃下，指例。舍屋，總倉庫等。尼寺即伽藍。餘相可見。三礙同別，並同藍村，故言亦爾。樹界中，初文。
【譯文】四周皆有房屋算作第四種，是指上方有屋頂覆蓋，必然同時兼具竹簾牆壁等遮障。下一科判，引述古說中，先列出彼方觀點。「此」字以下，予以駁斥破除。既然說標誌已經損壞，那就不再是僧寺村落；樹木車輛各自獨立成界，所以稱為別界。律疏說：「如果缺損便不再成其為僧寺，情況如同空曠野外」，就是這個意思。在現今的解釋中，首先確立義理。「僧」字以下引證證明。文義如前所釋。「乃」字以下，指出同類之例。舍屋是統稱倉庫等建築。尼寺也就是比丘尼僧寺。其餘相貌顯而易見。三種阻礙的相同與相異，都如同僧寺與村落，所以說「亦爾」。在樹界中，第一段文字：

【1139-0004】資持記/08b_中二#56
【原文】與人等者，示高量也。蔭跏趺者，即廣量也。此相極小，已下非用，故注示之。次科，《十誦》中。獨株名樹，相接為林；各顯分齊，如文可見。拘盧舍即二里。《善見》中，初引論文。樹取影覆，隨時大小；林無限齊，故約肘量。十四肘計二丈五尺二寸，得四步餘尺二。人來往者，謂有礙也。
【譯文】「與人等高」是標明高度標準。「能蔭蔽跏趺坐」則是標明寬度範圍。這種相狀極為窄小，以下不再適用，所以用注文予以顯明。下一科判，在《十誦律》中：獨株稱為「樹」，枝條相接稱為「林」；各自顯現其範圍界限，如同律文顯而易見。「拘盧舍」就是指二里之地。在《善見律》中，首先引述論部文字。單株樹木以樹蔭覆蓋處為界，隨時光推移而大小不一；樹林則沒有固定的邊界，所以依照肘量來界定。十四肘折合為二丈五尺二寸，相當於四步多一尺二寸。所謂「有人來往」，是指存在阻礙。

【1139-0005】資持記/08b_中二#57
【原文】上下，會通律論林相不同。難即是礙。《僧祇》中。蔓即藤蘿。二十五肘，計四丈五尺，得七步半；四面取之，則相去十五步；此據極廣以量約之，狹則隨架大小。上下中。引《了論》正取樹相，樓是相因。上落下者，言有此義，不必須落。場界隨處，故不明量。車船中，初列名。
【譯文】「上」字以下，融會貫通律與論對於樹林相貌的不同說法。「難」也就是阻礙的意思。在《僧祇律》中，「蔓」就是指藤蘿。二十五肘折合為四丈五尺，相當於七步半；從四面度量，那麼彼此相距十五步；這是依據極為寬廣的情況來加以規範限制，若樹架狹小則隨樹架的大小而定。「上下」之中，引述《了論》正取樹木的相貌，樓閣只是依附相連之物。所謂「從上落下」，是說有這種可能情況，並非必定要有東西落下。場地之界隨處設立，所以沒有明確規定尺寸。車船界中，首先列出名目。

【1139-0006】資持記/08b_中二#58
【原文】並在陸地者，車無入水，何須簡陸！據義合云俱在地住，言相方顯。律下，引示。初明住量。迴轉取周圓內地。十下，明行量，初明行車。約多車相接為言。杖所及者，杖即駕車人所持。《僧祇》下，明行船。多住處者，即一船中前後各據也。舍界，初科，先示體。律但列名，故云無相。
【譯文】全都位於陸地上，車子既然不會開進水中，何須簡別陸地！依照義理應當說全都停駐在地上，語句意相才顯得清楚。律文以下，引述並予以指示。首先說明停駐時的標準範圍。旋轉的範圍取其圓周之內的地面。「十」字以下，說明行走時的標準範圍，首先說明行駛中的車輛。這是就多輛車互相銜接的情況而言的。所謂「長杖所能觸及的距離」，「杖」就是指駕車人所持的韁繩策杖。《僧祇律》以下，說明行駛中的船隻。所謂「多處住所」，是指同一條船中前後各自佔據的空間。舍界，第一科，先展示其本體。律中僅列出名稱，所以說「沒有具體相貌」。

【1139-0007】資持記/08b_中二#59
【原文】村外舍者，即今田野間草舍之類。村聚如後，即指下科。僧下，明量，先準《僧祇》。樓閣取梯橙外。次約本宗。倉庫據四周內。二律不出舍界正量，故云兩無。今準用別界，隨人取舍，故云任得。〔有云：無四障，依《僧祇》，有則取《四分》。〕次科，標中。若據村聚，合在初明。
【譯文】「村外舍」是指如今田野間的草屋之類。村落聚落的情況如後文所說，就是指下一科判。「僧」字以下說明度量，首先依照《僧祇律》。樓閣以梯蹬的外沿為界。其次依照本宗律典。倉庫以四面周壁之內為界。兩部律典都未明確指出舍界的正式尺寸標準，所以說「兩者皆無」。如今準照引用別的結界，聽憑個人取捨，所以說「任得」。〔有人說：如果沒有四面屏障，就依據《僧祇律》；如果有屏障，就取法於《四分律》。〕下一科判，在標題中：如果按照道理村落聚落，本應放在最初說明。

【1139-0008】資持記/08b_中二#60
【原文】但舍在聚外，故須對顯。復由舍聚二界相濫，寄此辨之；故云對上因解也。聚落中，初文，《四分》村聚，名相不別。《善見》約市且分名異。至論護衣，相亦無異。《多論》四句。聚止一家，則依聚界；多家即從家界。須此簡異，方無相濫。次科，定名中。共住即聚義，落猶居也。
【譯文】只因為舍界位於聚落之外，所以必須互相比對顯現。又因為舍界與聚落界兩種結界容易混淆，所以寄託在此處加以辨別；因此說是「對照前文順帶解釋」。在聚落之中，第一段文字：《四分律》中村與聚，名稱相貌並無分別。《善見律》依照有無集市暫且劃分名稱的差異。若論及守護衣物，兩者的相狀並沒有差別。《薩婆多論》推演出四種句型：聚落中若只有一家，就依循聚落界；若有多家，就依照各家之界。必須作這種簡別區分，才不致於互相混淆。下一科判，在確定名稱中：眾人同住就是「聚」的意思，「落」也就是居住的地方。
