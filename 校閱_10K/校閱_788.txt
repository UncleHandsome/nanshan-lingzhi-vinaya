# 校閱材料　第788檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【788-0001】02_戒疏/18c_卷四上之三#21
【原文】【記】戒本，分文中。初句明食而標「比丘」，即得食人，下云「比丘」，即犯過人，故云「互現」也。
【譯文】【記文】在戒本文句的分段說明中。第一句在說明美食的同時標上了「比丘」，是指獲得食物的人；下文再次提到「比丘」，則是指違犯過失的人，因此說兩處是「互為映襯」。

【788-0002】02_戒疏/18c_卷四上之三#22
【原文】【疏】《多》云：「所以名美食者，以價貴故，卒難得故，愈病疾故。美食非美藥，乳、酪、蘇是；美藥非美食，生蘇、油是；俱是者，蘇魚、肉脯是；俱非者，訶棃勒是。」
【譯文】【疏文】《薩婆多論》中解釋：「之所以稱為『美食』，是因為它的價格昂貴、平時難以輕易獲得，並且具有治療沉痾痼疾的功效。屬於『美食但非美藥』的，如乳、酪與熟酥就是；屬於『美藥但非美食』的，如生酥與香油就是；兩者『都是』的，如用酥油烹調的魚和肉乾就是；兩者『皆非』的，像訶梨勒果實就是。」

【788-0003】02_戒疏/18c_卷四上之三#23
【原文】【記】釋第一中，《多論》二段。初示名，以下三句，三義釋之。「美食」下，二、簡辨，有四句。初句，「乳、酪」是時食，蘇本是七日藥，今望可充食邊，亦名美食。次句，以「生酥、油」不可直服，故但名藥。「俱是」句中，「魚、肉」是食，復加酥煑，故兼二名。「俱非」中，據「訶棃勒」是盡形藥，然望「七日」，非美物故。若據「藥」、「食」名通，《論》中且約可常作食者名「食」，不可者號「藥」。
【譯文】【記文】在解釋第一部分的文句中，《多論》分為兩段。前段說明名稱由來，藉由後面的三句話從三種意義來闡釋。「屬於美食」以下是第二段，進行詳細的簡別與辨析，共有四種句型。第一種句型中，「乳」與「酪」屬於平常合時的食物，熟酥本質上雖然是七日藥，但從它足以充飢飽腹的層面來看，也算是美食。第二種句型中，因為「生酥」與「香油」不能直接當作日常食物大口吞服，所以只算作藥品。在「兩者皆是」的句型中，「魚」與「肉」本身是食物，又加上酥油烹煮，因此同時兼具兩者的名稱。在「兩者皆非」中，純粹以「訶梨勒」屬於終身服用的藥物而言，相對於「七日藥」的濃郁滋養來說，並不能算作甘美的珍品。若是就「藥」與「食」這兩個名稱在廣義上的互通性來說，《論》中暫且將能夠常態性充當正餐的定名為「食」，無法常態性當作正餐的則稱之為「藥」。

【788-0004】02_戒疏/18c_卷四上之三#24
【原文】【疏】尼結輕者，大僧丈夫身，報力強，喜乞美食，取資身故，所以重制。尼乞美食，女人所諱，為希故輕。此吉罪者，結不同罪，實犯提舍。
【譯文】【疏文】比丘尼犯此戒判定為較輕的罪，是因為大僧比丘身為偉岸丈夫之體，果報體力本來就強壯，卻往往偏好索求美食來滋養肉軀，所以律制處罰極重。而比丘尼開口乞求美味，在世俗眼光中是女人家極為羞愧忌諱之事，發生這種過失的情況極少，因此定罪較輕。此處比丘尼結犯的突吉羅罪，是屬於體系「不同」的隨轉罪名，她若實際觸犯，真正成立的應是提舍尼罪。

【788-0005】02_戒疏/18c_卷四上之三#25
【原文】【記】釋尼犯中。初出重輕之意。「此」下，次示結犯不同。尼八提舍，即無病乞八種美食，謂酥、油、蜜、石蜜、乳、酪、魚、肉也。僧尼各聚，故云「不同」。
【譯文】【記文】在解釋比丘尼犯戒的段落中。首先說明判罰輕重有所懸殊的用意。「此處」以下，進一步指出兩部律制在結罪分類上的差異。比丘尼戒律中的八條提舍尼法，正是規定無病不得向人乞求八種美食，也就是酥、油、蜂蜜、石蜜、乳、酪、魚、肉這八樣。由於僧部與尼部的戒篇分聚各自獨立，因此稱作「不同」。

【788-0006】02_戒疏/18c_卷四上之三#26
【原文】【疏】問：「不同何罪而結於尼？」
【譯文】【疏文】問：「既然是體系不同，那麼究竟是以什麼具體罪名結罰比丘尼呢？」

【788-0007】02_戒疏/18c_卷四上之三#27
【原文】【疏】答：「不同非罪，示不同戒。隨結方便，使異二部。餘可解。」
【譯文】【疏文】答：「這裡所說的「不同」並非比丘尼的正犯罪名，而是用以標示兩部僧團所屬戒條之不同。只是隨著大僧戒條而附帶結犯方便罪（突吉羅），藉此區分二部律儀。其餘內容容易理解。」

【788-0008】02_戒疏/18c_卷四上之三#28
【原文】【記】問中。今此吉羅，既非實犯，應成虗結，故問何罪。答中，初明「非罪」，非正犯故。「隨」下，次示罪體。「餘」下一句，語勢兩向，或似指例前後諸戒，或似指注不犯等文。
【譯文】【記文】針對提問的部分。此處判定比丘尼犯突吉羅，既然不是她本條的正條重罪，豈不成了空架子的假結罪，因此發問這究竟算什麼罪名。回答之中，開頭先說明「非罪」，是指這並非比丘尼本門的正犯罪名。「隨著」以下，指明該罪的實質體性在於方便過失。「其餘」這一句話，在語意上有兩重指涉：一方面看似通指比照前後各戒的判例，另一方面也看似直接指示讀者參照註解中關於不犯等條款。

【原文】【律】四十一、與外道食戒。
【譯文】【律文】第四十一條、與外道食戒。

【788-0010】02_戒疏/18c_卷四上之三#30
【原文】【疏】與外道食戒四十一。
【譯文】【疏文】與外道食戒四十一。

【788-0011】02_戒疏/18c_卷四上之三#31
【原文】【疏】有三過故。一、異學情反，恒多疎外，難與理親。雖復惠施，不荷其恩，反生譏謗。二、邪見乖宗，非真福田，以信心之食，授與外道，施主聞之，特生不忍。又損施福，不得功德，田中不獲反報故。三、躬自奉食授與外道，容生外人愚倒己見，謂外道勝，比丘不如。以斯諸過，故制。
【譯文】【疏文】制定這條戒律是為了防止三種過患。第一、信奉外道異學的人心思與佛門相悖，平時多抱持疏遠排斥的態度，很難以佛法正理與其真心結交。縱使慈悲布施給他們，他們非但不感念這分恩德，反而常常轉向生起毀謗與譏嫌。第二、外道懷抱顛倒邪見，違背清淨正宗，根本不是能夠生長功德的真正福田；若將信徒帶著誠敬心供養的食物轉送給外道，施主聽聞之後，內心必定深感不忍與不快。同時這也損害了施主的布施功德，無法獲得殊勝善報，因為在不良的田地裡播種無法得到應有的豐收回報。第三、如果比丘親自動手捧著食物遞奉給外道，很容易讓世俗愚昧大眾產生倒錯的偏見，誤以為外道的德行勝過三寶、比丘反而不如外道。因為存在這許多的深重過患，所以佛陀制定了這項禁止。

【788-0012】02_戒疏/18c_卷四上之三#32
【原文】【記】四十一，制意三。初招反謗，即如緣起。二、非福田，復有二意：一、惱施心；「又」下，二、損施福。三、罔時俗。「以」下，總結。
【譯文】【記文】第四十一條說明制戒用意，分為三個方面。第一是招致外道反過來毀謗，這與制戒緣起的事實相符。第二是外道並非合格的福田，這又包含兩層意涵：第一是令人煩惱退失布施的誠心；「同時」以下，第二層是損耗了施主的功德果報。第三是愚弄迷惑了世俗凡夫。「因為」以下，是全文的總結歸納。

【788-0013】02_戒疏/18c_卷四上之三#33
【原文】【疏】論犯六緣。一、是出家外道，以在家者但犯小罪。由出家名同，真偽難別，生人惑倒故重。二、知是。三、非親里，開與父母。《僧祇》中：「父母、兄弟外道出家者，使淨人與。無者，語令自取。若嫌者，答云：『汝出家不得處，佛制戒如是，不食者隨意。』」四、是食，除與衣犯小罪。五、自手與。以食味是通，理無獨食，置地使人，不生感倒故開。六、領受犯。
【譯文】【疏文】若論定構成犯戒，必須具備六項條件：第一、對方必須是已經出家的外道人士，如果只是給予在家外道，僅結犯輕微的小罪。這是因為出家之名相同，世俗人極難辨別真偽，容易令人產生迷惑顛倒，所以從嚴治罪。第二、自己明知對方是出家外道。第三、對方不是自己的至親眷屬；若對方是親生父母，則在開許容許給予的例外之中。《僧祇律》記載：「如果父母或兄弟成為了出家外道，比丘應當派遣佛門淨人代為轉送食物。如果沒有淨人，就開口吩咐他們自己動手拿取。如果他們心生抱怨怨恨，比丘就應當回答說：『你們出家投在非處（誤入邪門）；佛陀制定的戒律本來就是如此，如果不想吃的話就隨你們的便。』」第四、所給予的必須是食物；如果贈與的是衣服，只結犯突吉羅小罪。第五、必須是比丘用自己的雙手親自遞交給對方。因為食物美味是通於大眾滋養之物，法理上本不應完全自私獨吞，若是把食物放在地上或吩咐他人代送，並不會引起世人崇仰外道的顛倒錯覺，因此特許開緣。第六、外道親手受領完畢，此時正式構成犯戒。
