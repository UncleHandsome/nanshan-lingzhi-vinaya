# 校閱材料　第911檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【911-0001】資持記/01e_上一上#22
【原文】又經中多破外計，委辨魔事，指示正道，恐墮邪逕，故云識達。又行業是因，通收善惡；心因冥邈，故曰難知。來報是果，亦通苦樂；果相麁著，故云易述。次行教中，初標名體。定下，示教相。初二句明眾行，上句正示。若取能秉，即簡人是非。
【譯文】另外經中多半破除外道邪見，詳細辨明魔事，指示正確之道，擔心眾生墮入邪途，所以說「認識通達」。再者造業是因，普遍收攝善與惡；內心的起因微細深邃，所以說「難以了知」。未來的報應是果，也通於痛苦與快樂；果報之相粗淺顯著，所以說「容易宣說」。第二在「行教」之中，起初標明名稱與實體。「定」字以下，顯示教法的行相。起初兩句說明大眾共同的行持，上句正是正面開示。如果就主持能秉者來說，就是揀別人員的是非合律與否。

【911-0002】資持記/01e_上一上#23
【原文】若論所被，並須合教，如受戒遮難、說恣有犯、七九治罰、六聚悔露，一一事中，皆有取捨。次句釋成取捨之意。謂顯佛法尊高，超于世表；僧門清白，不容非濫；住持萬載，功由於此。顯下二句明別行。上句正示，下句釋成，亦同上。如條部中波離對聖重條咨問，意可見矣。
【譯文】若就所被對象來說，都必須符合教法，例如受戒時的遮難審查、說戒自恣時是否犯戒、七種與九種的治罰法、六聚戒罪的懺悔發露，在每一件事之中，都有所取捨。下一句解釋成就取捨的用意。這是為了顯發佛法之尊貴高尚，超絕於世俗之外；僧團門風清白純潔，不容許絲毫非分濫雜；正法住持萬年之久，其功德全在於此。「顯」字以下兩句說明個別的行持。上句正面開示，下句解釋說明，也和上面一樣。如同調部中優波離尊者對佛陀重提戒條並一一請示，其意旨便可以明了了。

【911-0003】資持記/01e_上一上#24
【原文】上明教有限齊，反前汎明。指下，示其顯了，反上沈密。上二句示文顯，下二句明事備。初文，如諸戒相，國土犯人舉過呵責制戒牒釋方便境想下眾同別犯及不犯輕重等相，一一皆然。聖智通明，故言不勞重覽。凡愚淺識，不可輒爾僣同。且祖師聽二十遍，猶言未是心證；
【譯文】上面說明了教法具有限定範圍，正好反襯前文的廣泛明了。「指」字以下，顯示其條目顯著明了，正好反襯上面的沉晦隱密。上面兩句顯示文義顯豁，下面兩句說明事理具備。第一文段，如同各條戒相，從國土、犯人、舉過、呵責、制戒、牒釋、方便、境想、下眾同別、犯與不犯、罪之輕重等相，無不一一如此。聖人的智慧徹悟明了，所以說不需要再次翻閱。凡愚淺識之人，不可以貿然自視相等。況且祖師聽講二十遍，尚且說還未達到心地印證；

【911-0004】資持記/01e_上一上#25
【原文】僧休聽三十遍，尚恨逾增逾暗；是知昏鄙安可自務。結罪等者，如婬兩結〔不捨戒共畜生〕，別眾七開〔施衣作衣等七緣開〕，一一通前重入戒本，故云再科。所判，初科，上二句示相濫。以七支十業，無別體故。如環連續，以喻相涉，不易分故。下二句標判。
【譯文】僧休法師聽講三十遍，還遺憾越聽越增茫然昏暗；由此可知昏昧鄙陋之人，哪裡可以隨便自信自滿。「結罪」等語，例如行婬有兩重結罪（不捨戒與對畜生行婬），別眾食有七種開許緣由（施衣、作衣等七種因緣開許），一一都貫通前面而重新編入戒本，所以說「再次列科判斷」。（在所判定的段落中），第一科上面兩句顯示行相容易混淆。因為身口七支與十業道，並沒有另外獨立的體性。猶如環環相扣連續不斷，以此比喻互相涉入、不易區分。下面兩句標示判定。

【911-0005】資持記/01e_上一上#26
【原文】正判中，初文即約三業相對以分，上三句判化教。經論明心顯理，是故心業以理為宗。下三句判行教。施為即事也。律藏約事辨行，故身口業以事為宗。如〈篇聚〉中，起業輕重，受報淺深；篇聚即約行，起業即依化。又〈持犯〉中，單心三時辨犯；八句重輕，此依化也；八殺俱重，即約行也。
【譯文】在正式判定的文段中，最初的文段就是依據三業相對而劃分，上面三句判定化教。經論在於闡明心性、顯發真理，所以心業是以理為宗。下面三句判定行教。「施為」就是事相。律藏依據事相辨明行持，所以身口業是以事為宗。例如〈篇聚篇〉中，造業的輕重、受報的深淺；篇聚就是依據行教，起業就是依據化教。又如〈持犯篇〉中，單純以心念歷經三時來判定犯戒；八句的輕重，這是依據化教；八種殺人行為全都判定為重罪，這就是依據行教。

【911-0006】資持記/01e_上一上#27
【原文】又如〈懺篇〉，三品理觀，即是化教；六位悔法，即準行教。又〈沙彌篇〉，凡福聖道，即依化教；剃落與戒，即是行教。餘更尋之。若爾，化教應不禁身口，行教應不制內心？答：此據道眾雙稟二教為言，世多不曉，故為委示。初約違明四句。一違化不違制〔瞥爾貪嗔，律宗不制；及在家人作十不善是也。〕；二違制不違化〔即犯諸遮戒也〕；
【譯文】又例如〈懺罪篇〉，三品理觀就屬於化教；六個層位的懺悔法，就遵循行教。又如〈沙彌篇〉，世俗福報與聖道，就依循化教；剃度與授戒，就屬於行教。其餘的可以自行尋查。如果是這樣的話，化教難道就不禁止身口，行教難道就不制約內心嗎？回答：這是針對出家道眾同時領受二教而言，世人多半不明白，所以為之詳細開示。首先就違背而言，說明四句：第一違背化教而不違背制教（短暫生起貪瞋，律宗並不制罪；以及在家人造十不善業即是）；第二違背制教而不違背化教（就是觸犯了各類遮戒）；

【911-0007】資持記/01e_上一上#28
【原文】三俱違〔犯諸性戒〕；四俱不違〔理觀內照，戒律外撿。〕。次約順四句。一順化不順制〔性相唯識三觀破迷〕；二順制不順化〔心無慧觀，專守事戒。〕；三俱順〔如上第四〕；四俱不順〔造業凡愚〕。三約受戒四句。一稟化不稟制〔《淨名》云：汝但發心，即名具足是。〕；
【譯文】第三化制俱違（觸犯了各種性戒）；第四化制俱不違（以理觀內在觀照，以戒律外在檢點）。其次就隨順而言，也有四句：第一隨順化教而不隨順制教（用性相、唯識、三觀來破除迷妄）；第二隨順制教而不隨順化教（內心沒有智慧觀照，專門死守事相戒律）；第三化制俱順（如同上面的第四句）；第四化制俱不順（造作惡業的凡夫愚人）。第三就受戒而言，也有四句：第一領受化教而不領受制教（《維摩詰經》說：「你只要發菩提心，就叫做具足戒」即是）；

【911-0008】資持記/01e_上一上#29
【原文】二稟制不稟化〔自智不明，循律軌度。〕；三俱稟〔心希出離，受律禁戒，趣向聖道。佛世利根，善來三語，即得道果。又《涅槃》出家菩薩是也。〕；四俱不稟〔可知〕。四約懺罪四句。一化淨制不淨〔如犯篇聚，理觀明照，達罪性空；而不依律懺，縱得好相，不入淨僧。〕；
【譯文】第二領受制教而不領受化教（自身智慧未明，只是循著戒律軌則度數行持）；第三化制俱稟（內心希求出離，領受戒律之禁戒，趣向聖道。佛陀在世時利根之人，一聲「善來比丘」或受三皈語，當下就證得道果。另外《涅槃經》的出家菩薩也屬於此類）；第四化制俱不稟（道理可知）。第四就懺罪而言，也有四句：第一化教清淨而制教不清淨（例如犯了篇聚罪，理觀分明觀照，了達罪性本空；然而不依照戒律懺悔，縱使感得祥瑞好相，也不能列入清淨僧數）；

【911-0009】資持記/01e_上一上#30
【原文】二制淨化不淨〔犯依律悔，而無觀慧，但滅違制，業性確然。〕；三俱淨〔篇聚依教滅，業道任靜思。〕；四俱不淨〔愚者犯不肯懺〕。問：化行二教，為大為小？答：化收大小，制唯局小。若爾，《梵網》善戒，大乘行教，那判為化？答：大乘三藏制不制別，得名為行。
【譯文】第二制教清淨而化教不清淨（犯戒依戒律懺悔，但沒有觀慧，只是滅除了違背制約之罪，其業道罪性依然堅固）；第三化制俱淨（篇聚罪依教法滅除，業道罪則任由靜坐思惟理觀予以消弭）；第四化制俱不淨（愚癡之人犯了戒又不肯懺悔）。請問：化行二教，到底是大乘還是小乘？回答：化教通攝大乘與小乘，制教則局限於小乘。如果是這樣，《梵網經》與《善戒經》是大乘的行教，為何判定為化教？回答：大乘三藏中制戒與不制戒各有差別，可以稱為行教。
