整體讀來通順、科判層次也抓得住，大方向沒有偏離。問題主要集中在幾處**律學術語的處理**、**推測性的增譯**，以及一兩個**邏輯用語與漢語措辭**上。以下逐則列出，並標示輕重。

## 一、比較要緊的問題

### 【465-0003】「根條」譯錯
> 譯文：「如果從戒律的**根本與條目**來看」

「根條」是**根本罪與枝條（枝末）罪**：初篇波羅夷為根本，餘四篇為枝條。「條目」（項目的意思）與此無關，屬誤譯。
建議：「若就**根本與枝末（枝條）** 而言」。

同則「若約**戒儀**」譯為「行持規矩」過於籠統。此詞宜再核（可能指戒相篇聚的儀則，或懺治儀式），建議暫譯「就戒法儀則而言」並加註待考，不要用白話含糊帶過。

另：「通別兩緣」「通別二持」宜保留為「**通緣／別緣**」「**通持／別持**」。譯文統一寫成「通相與別相」，會與 0001 的「總相／別相」混為一談，術語層次亂掉。

### 【465-0007】「同時存在」與後文自相矛盾
> 譯文：「單舉犯戒之法來說，就**同時存在**著犯戒之行與不犯之行。」

原文是「犯法（教相）中**具**有犯行、不犯行兩義」，不是說同一行為中善惡並存。0011 明說「善惡不俱」、0012 說「犯不兼持」，加了「同時」会让读者觉得前后打架。
建議：「就舉『犯法』來顯明，其中便**具**有犯行與不犯行（兩義）。」

### 【465-0011】「正正相反」用語錯誤
漢語沒有「正正相反」的說法；「正欲」是「正是要」。
建議：「並不是要人隨順過失去造作，**而正是要**大家觀見犯相生起厭離……」

同則兩處小增譯：「順著過失的**軌跡**」是贅飾；「同一**剎那**」是依「善惡不俱」所作的推補（可保留，但最好註明或改為「不能同時並起」）。「犯**罪**因緣」帶現代刑事語感，宜作「成犯的因緣」。

### 【465-0015】此則問題最多

1. **「以輕奪重」譯失準**
> 譯文：「以較輕的**情節取代了**重罪」

「奪」是**奪除**，輕重指**罪之輕重**而非情節。意思是：因開緣故只結輕罪、奪去重罪，就重罪說「不犯」。
建議：「而是**以輕罪奪除重罪**（只結輕罪、不犯重罪）」。

2. **「開許」宜改「開緣」**
全則（及 0014）用「開許戲笑言論」「開許純淨無染的受逼迫」，容易讓讀者誤以為佛陀准許戲笑妄語、行淫等。此處「開」是**開緣不犯重**，仍有小犯——正是疏文「非是純淨名為不犯」的意思。建議統一作「開緣」「就……開緣而說不犯」。

3. **「婬、摩開淨、授」對應被合併，且有推測成分**
原文是**淫戒開「淨」、摩觸戒開「授」**的分別對應。譯文寫成「『淫戒』與『摩觸戒』開許純淨無染的受逼迫與交接物品」，兩戒開緣混在一起；而「受逼迫」是對「淨」字的推測（「淨」所指須核戒本開緣與《行宗記》釋文）。
建議：「淫戒開『淨（無染心）』、摩觸戒開『授（取與物品）』」，並對「淨」加註待考。

4. **「念捨」語意含糊**
「在心中捨置三衣」不明所以。「念捨」是**心念捨衣**（預先捨去衣的受持，以免離宿之重罪）。
建議：「離三衣宿戒開『心念捨衣』」。

5. 「非是純淨」譯「**自體**完全純淨無染」——「自體」是多出來的；「**當**自攝持」譯成「**若能時時**自我攝持」，把應然改成條件，且「時時」為添加。建議：「並不是完全清淨無犯才叫不犯……**應當**自我攝心持守，名為『不犯行』。」

## 二、次要的增譯與偏窄

| 出處 | 譯文 | 問題／建議 |
|---|---|---|
| 0001 | 「與前面說的**四個字**不同」 | 原文只作「與上不同」，四字是依下文推補。大致可從，但宜作「與上文所說不同（即四字）」 |
| 0001 | 「總綱通泛含攝**一切**」 | 「一切」為添加，「通含」是通泛含攝別相 |
| 0001 | 「必約」→「必定要**藉由**」 | 「約」是「就……而論」，非「藉由」。宜「必定要就（別相）而論」 |
| 0002 | 「對治**惡念**的修持」 | 對治通身口，不限於念。宜「生起對治過非的持行」 |
| 0002 | 「造罪的**動機**與招感的果報」 | 「因」窄化為動機。宜「造業之因與所感之果都輕微」 |
| 0005 | 「**作惡**的因緣具備」 | 宜「造作過非的因緣具足」 |
| 0005 | 「**直接**違背了聖者的教法」 | 「現」是顯現／現行，宜「明顯違背聖教」 |
| 0005 | 「若有**比丘**毀壞自己的行持」 | 「比丘」為添加，原文只作「有」；可作「有人自壞戒行」 |
| 0006 | 「犯與持通於**兩套分類**」 | 「兩位」即犯位、持位。宜「即已通含犯、持兩位」 |
| 0006 | 「法都是從**教理**而言」 | 「教」指佛所制之教（制教），非義理。宜「就聖所制教而言」；「從人」宜作「就能持能犯的人而言」 |
| 0006 | 「四個名稱」／「犯、不犯、輕、重這四門」 | 「四名」很可能是犯法、犯行、持法、持行；「四門」才是犯、不犯、輕、重。譯文一處含糊、一處填實，讀者易混，建議分別加註 |
| 0008 | 「前面的**名詞解釋**」 | 宜照科判作「前面『列名解（釋名）』一科」 |
| 0009 | 「正如上面廣泛引述的」 | 可作「如上文廣泛引證」 |

## 三、可保留、譯得好的地方

* 「汙本所受」→「玷污當初所納受的**戒體**」：準確。
* 「如此**重**解」讀為「重複解釋」：正確（未誤讀為輕重之重）。
* 「因果微」「反上句」的句式、「五篇迭論」譯「層層互相比對」、「中間三篇並通重輕」：都到位（「反上句」若補一句「即因強果重」更好懂）。
* 0004、0010、0012、0013、0014 大致無誤。

## 四、建議統一的幾個詞

* 科判單位：「次科」時而「第二小節」時而「下一節」，建議統一為「次一科／下一科」。
* 「開」一律作**開緣**，不用「開許」。
* 「通別」保留**通緣／別緣、通持／別持**；「總別」才用總相／別相。
* 「奪」統一作**奪除**。
* 「法／行」在記文中固定為「**約教／從人**」，白話可作「就制教而言／就人的造作而言」。

如果要我挑一則最需要重寫的，就是 **0015**；其次是 0003 的「根條」與 0007 的「同時」。
