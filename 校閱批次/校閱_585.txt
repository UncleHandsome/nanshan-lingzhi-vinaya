# 校閱材料　第585檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【585-0001】03_業疏/02a_卷一之二#37
【原文】次科初躡破。眾別兩法當分自通，相望互塞，別人不得行僧事，大眾不許作對念，若約互望，則俱非盡辨，皆不名僧，何獨別人？若從當分，則各自能辨，齊得名僧，何獨四人？「古人」下正名，初出古見，彼謂僧名標顯勝德，非是從數，即迷名也。「今」下示今釋，既翻為眾，眾即是數，數通多少，是以三緣皆彰僧號。下舉僧次請人、眾法心念，例顯別人名體不別。鈔云：「別請五百羅漢，不如僧次一人，得福無量，如飲大海則飲眾流」，故云功用大也；下云心念說恣，籌華、香水、鳴鐘集僧，一同大眾，故云「與百千等」也。引彼例此，名義不殊，故云齊量。雖是別人，辨法功大，約此假用，即為僧體
【譯文】下一科首先承接上文而予以破斥。大眾法與個別法在各自的分位上本自通達，但若彼此相望則互相受阻，個別之人不得私自行辦大眾僧事，大眾也不被允許作對首與心念法，如果依彼此相望來說，那麼雙方都不能完全辦盡一切法，就都不該名之為僧，為何單獨否定個別之人？若是順從各自的本分，那麼彼此各自都能成辦其事，同樣都能稱為僧，為何唯獨限於四人？ 「古人」以下是端正名稱，起初指出古人的見解，他們認為「僧」這個名稱是用來標顯殊勝德能，而不是依據人數而定，這就是迷惑於名稱。「今」以下展示現今的合理解釋，既然翻譯為「眾」，眾就是人數，人數通於多與少，因此三種因緣（一人、眾多、四人以上）都能彰顯僧的稱號。 下文舉出依僧次請人、行眾法心念的例子，以此類比顯明個別之人的名與體並沒有差別。《事鈔》說：「個別迎請五百位羅漢，不如依僧次迎請一位凡夫僧，所獲福報無量無邊，就像喝了大海水就等於喝了一切河流一樣」，所以說功用極大；下文又說在無人處心念說戒、自恣，行籌散花、灑香水、鳴鐘集僧等儀軌，完全等同於大眾僧，所以說「與百千人宣教等同」。引述彼例來說明此理，名與義並無殊異，所以說是等齊的量度。雖然只是個別一人，成辦教法的功用卻極大，依照這份假名功用，即構成了僧體。

【585-0004】03_業疏/02a_卷一之二#40
【原文】故正戒、見為法慧之宗。由戒法為眾德之基，同受故須同行，有缺緣成，不名僧也；雖復同戒，心同見慧為入道之本，有異見者，同界別法兩各得成，故見異法同，不名僧也；雖同戒見，淨行須同，邪命利乖，財法不共，又非僧也
【譯文】所以端正戒律與知見，是戒法與正慧的根本宗旨。由於戒法是一切功德的基石，既然共同受持，就必須共同奉行，如果有所缺漏或因緣不具而成立，便不能稱為僧；即使同樣受戒，內心同具正見與正慧才是進入聖道的根本，若有不同知見者，在同一個結界之內各自做不同的法羯磨也能各自成立，所以即便所作之法相同但知見相異，也不能稱為僧；縱然戒與見都相同，清淨的行持也必須一致，若以邪命求利而產生利養乖離、在財物與佛法上互不共有，這同樣不能算作僧。

【585-0005】03_業疏/02a_卷一之二#41
【原文】次科三體中分二：初明戒見。初二句雙標，戒是法宗，能生眾德；見是慧宗，能入聖道。宗即本也。「由」下各釋，初釋正戒，受隨兩同乃入僧位，受中缺緣謂本受不得，隨中缺緣謂受已毀破。「雖復」下次釋正見，異見有二：一邪見異，如調達部黨；二執見異，如俱睒彌鬪諍。雖同正戒，由見不同，同界別法佛竝判成。「雖同」下二明同利，淨行即是正命乞食，僧次別請僧常竝不別眾，反此利乖，戒見亦異，故云財法不共
【譯文】下一科在三種自體當中分為兩部分：首先說明「戒同」與「見同」。起初兩句雙重標明，戒是佛法的宗本，能生長眾多功德；見是智慧的宗本，能引導趣入聖道。宗就是根本的意思。「由」字以下分別解釋：首先解釋端正戒律，必須受戒與隨順持戒兩者都相同，才得以進入僧伽之位，受戒中若有缺緣是指當初根本沒有得戒，隨戒中若有缺緣是指受戒之後毀犯破失。「雖復」以下，其次解釋端正知見，不同的知見有兩種：一是邪見相異，如同提婆達多的黨羽；二是執著之見相異，如同俱睒彌國比丘的爭鬥。雖然同持正戒，但由於知見不同，在同一結界內各自舉行羯磨僧事，佛陀全都判定可以成立。「雖同」以下，第二說明利養相同，清淨行持就是指如法的正命乞食，無論是隨僧團順次、個別迎請、或僧團常住利養，全都不能脫離大眾獨享，反之若是利養乖違，戒與見也會隨之相異，所以說在財利與教法上不能共住。
