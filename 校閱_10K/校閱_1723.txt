# 校閱材料　第1723檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1723-0001】03_業疏/11b_卷二之五#44
【原文】緣中因巧師兒，比丘輒度，有不知者，後覓即得，因生譏謗。為成問對無虧，故令通告。如五分：先不相識者，七日試之。餘有出家儀式，具如事鈔，不可兩繁，至時量引。文中列通、別二知者，具兼二緣，不和別語，為成問答；若通和白，為表僧義
【譯文】在事緣中，起因是有工巧匠的兒子，比丘擅自度他出家，僧中有不知情者；其後家屬前來尋找便找到了，因而產生譏嫌毀謗。為了做到面對詢問應答無有差錯，所以命其通告大眾。如同《五分律》所載：若先前不相識之人，應當試驗考察七天。其餘出家儀軌，詳見《事鈔》，不可兩處重複繁瑣，屆時酌量引用。律文中列出通告大眾與個別告知兩種，具備兩種因緣：未合眾前個別告知，是為了應答盤問時有所依據；若是集眾唱白通告，則是為了表彰僧團和合決斷之義。

【1723-0002】03_業疏/11b_卷二之五#45
【原文】形同釋緣中，初示本緣。巧師即工巧之匠，入寺求覔，有不知者，問答有差，生譏故制。令通告者，總下通、別二知。五分制試，意在遮譏。下指事鈔，亦沙彌篇。「文下」次釋白告通知，謂作白法；別知，即房房語。「具兼二緣」即僧和、不和，此句總標；「不下」別釋各顯教意
【譯文】在形同法解釋事緣的第一科中，起初說明制戒的本來緣起。工巧匠就是做工巧技藝的匠人，巧師進寺院尋找（出家的兒子），寺中有比丘不知此事，問答之間出現差錯，招致譏嫌，所以律典制立此戒。命令通告，總攝下文的集眾通告與個別告知兩種知曉。《五分律》制定試驗七天，用意在於防範譏嫌。下文指示參照《事鈔》，也是指〈沙彌篇〉。自「文」字以下接著解釋作白宣告。「通知」，是指作單白法；「別知」，就是逐房個別告知。「具兼二緣」即僧團和合羯磨與個別不同席之時，此句是總括標明；自「不」字以下分別解釋，各自顯明教法的深意。

【1723-0003】03_業疏/11b_卷二之五#46
【原文】此中欲求者，即和尚為剃頂髮也。律中剃髮闍梨者，為剃四邊，不在羯磨中
【譯文】此處作白中所說的「欲求」，就是請和尚為他剃除頭頂之髮。律中所說的剃髮阿闍梨，是負責替他剃除四周圍的頭髮，並不列在羯磨受法程序之中。

【1723-0004】03_業疏/11b_卷二之五#47
【原文】次釋法白文中初科。白云「彼某甲」者，即所度之人；「欲求某甲」，謂能度和尚。恐人濫用，疏特簡之。竊原剃髮本須和尚，但恐煩累，故令闍梨先落四邊，唯留頂髻，和尚自落，以彰親度。後世妄傳：四邊斷下八地煩惱，頂上斷有頂一地煩惱，以具難斷，故令和尚除之；仍先剃為九髻以應其數。訛風一扇，愚蔽相習，微具智眼，豈不省非
【譯文】在第二解釋作白律文的第一科中。白文中說「彼某甲」，指的就是被度之人；「欲求某甲」，指的是能度的和尚。唯恐有人混淆濫用，疏文特地予以辨明。私下探究剃髮本應全由和尚親為，只是唯恐太過繁重勞累，所以讓闍梨先剃除四邊頭髮，唯獨留下頭頂髮髻，由和尚親自剃落，以彰顯親自度化之意。後世妄傳荒謬之說：四邊頭髮代表斷除下八地的煩惱，頭頂之髮代表斷除有頂天那一地的煩惱，因為具備極難斷除之義，所以才讓和尚親自剃除；甚至還先剃成九個髮髻以呼應九地煩惱之數。這種錯誤風氣一經煽動，愚蒙蔽塞之人相互沿襲，略微具備正法慧眼的人，難道看不出這是非法的嗎？

【1723-0005】03_業疏/11b_卷二之五#48
【原文】有人言所以須白，為量和尚，以文中「從某甲剃髮」故。今解不然，和尚在初已乞畜眾，故無重請，但為沙彌
【譯文】有人說之所以必須作白，是為了審核評量和尚，因為文中說「從某甲剃髮」的緣故。現今解釋並非如此，和尚在最初就已經乞求過蓄眾之法，所以不必重複請求，作白只是為了沙彌一人而已。

【1723-0006】03_業疏/11b_卷二之五#49
【原文】二中，以文牒二名，所為難定。昔指和尚，今定沙彌，是非可見也
【譯文】在第二部分中，因為作白條文牒列了和尚與弟子兩個名字，作白究竟為誰而作便難以判定。以往的說法指稱是為了審量和尚，如今判定是為了沙彌，二者孰是孰非一目了然。

【1723-0007】03_業疏/11b_卷二之五#50
【原文】有人言尼須乞畜眾，僧無制者。此未讀文，下結僧罪，事行同也
【譯文】有人說比丘尼必須乞求蓄眾之法，比丘僧則沒有這項規定。這是沒有讀通律文，下文明明結犯比丘僧罪，可見兩者的作法實行是完全相同的。

【1723-0008】03_業疏/11b_卷二之五#51
【原文】三中，以畜眾法出尼犍度故生異執，既結僧罪，可驗通行
【譯文】在第三點中，因為蓄眾之法出自《尼犍度》，所以產生了不同的執見；既然律文明確結犯比丘僧罪，即可證驗蓄眾之法通於僧尼兩眾。

【1723-0009】03_業疏/11b_卷二之五#52
【原文】五分先與五戒者，佛法大海漸漸深故。如多論云：先以五戒調伏身心，信樂漸增，方受十戒也
【譯文】《五分律》規定先授予五戒，是因為佛法大海是循序漸進、逐漸深邃的緣故。正如《薩婆多論》所說：先用五戒來調伏身心，使受者的信樂之心逐漸增長，然後才受十戒。

【1723-0010】03_業疏/11b_卷二之五#53
【原文】釋注中初科。五分以喻顯意，律鈔續云「不同外道一往頓受」；下引多論釋漸深義
【譯文】在解釋注文的第一科中。《五分律》以大海為喻來顯明深意，《事鈔》接著說「不同外道一往頓受」；下文引用《多論》解釋逐漸深邃的義理。

【1723-0011】03_業疏/11b_卷二之五#54
【原文】四分文中「彼剃髮與出家人同」者，且據形同耳。計在家法不應道務，然律上下非以剃髮為出家，以法分俗，方絕彼此，故沙彌戒歸方云出家也
【譯文】《四分律》文中說「彼剃髮與出家人同」，只是暫且依據外形相同而言罷了。按常理在家法不應承擔修道事務，然而律文前後自始至終並不是以剃髮為真正的出家，必須以正法來劃分道俗界線，才能徹底斷絕世俗與出家的彼此分野，所以沙彌受戒的三歸文中才說出家。
