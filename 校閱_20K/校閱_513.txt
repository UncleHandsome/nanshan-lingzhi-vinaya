# 校閱材料　第513檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【513-0001】資持記/05f_上四#14
【原文】餘下，指相攝。時前十日開受急施，即非時攝時也；自恣竟不為安居施者，時攝非時也。誡等心中，恐於利養，得失動懷；故引經示，令心平等。初列四法。即是八風，四違四順。文先舉違，故云有四；後方合辨，則云八法。無恐是心，以安住故。不轉即身口，以守常故。
【譯文】「其餘」以下，是指兩者相互涵蓋包容的情況。在正當時限之前的十天內，開許接受緊急施捨的衣物，這就是非時期間包攝了時衣（非時攝時）；自恣結束後卻不為了安居而施捨衣物的，這就是正當時限包攝了非時衣（時攝非時）。在「告誡保持平等心」之中，是恐怕大家對於供養利養的得到與失去而心生動搖；因此引用經典開示，讓內心保持平等。首先列出四種情況。這其實就是世間「八風」，也就是四種違逆、四種順境。文中先列出違逆的一面，所以說是四種；後面合併起來辨析，就稱作八種境界。心中毫無畏懼，是因為內心安住的緣故。身口沒有改變，是因為堅守常規的緣故。

【513-0002】資持記/05f_上四#15
【原文】得下，示得失平等。初別釋第一，是今正意；餘三因引，故所不明。八法者，一利，二衰〔即上得失。〕，三毀，四譽，五稱，六譏，七苦，八樂。四違對上四順，相反可知。上即修己。為下，示他。得失榮辱，皆本業緣；違順風來，故無忻慼也。〔即本以前段作注字，又無經文傳之訛脫。
【譯文】「得」字以下，展示了得與失應當看作平等。首先特別解釋第一種情況，這是現在主要要表達的意思；其餘三種只是順便引出，所以不作詳細說明。所謂的八種境界，第一是利，第二是衰〔也就是上面說的得到與失去。〕第三是毀謗，第四是讚譽，第五是稱揚，第六是譏刺，第七是痛苦，第八是快樂。四種違逆與上面的四種順境相對，正好相反，這是很容易明白的。上面所說的是修持自身。從「為了」以下，是教導開示他人。得到、失去、榮耀、恥辱，全都是由於自己過去的業力因緣所致；無論是違逆還是順應的八風吹拂而來，因此心中都不會生起欣喜或悲傷。〔此處原文在舊版本中本來被當作小字注文，又因為缺乏經文對照，所以流傳過程中出現了訛誤缺漏。〕

【513-0004】資持記/06a_中一上#1
【原文】四分律行事鈔資持記中一上大宋餘杭沙門釋元照撰中卷題號，竝同前釋。文列四篇，總明自行；無非離惡，護本所受。約行次第，德成有用，合為上卷；今望住持，功有勝劣，故居次焉。列篇中。上下諸篇，皆宗羯磨；此卷四篇，竝依戒本。前三精持，後一犯悔。

【513-0005】資持記/06a_中一上#2
【原文】又上三中，前二隨文，第三總義。又上二中，初解通名，二釋別相。有斯諸異，所以分之。13 釋篇聚篇(中一上)釋篇聚篇篇聚者，攝犯之大科，據斷之綱格；辨業輕重，定報淺深。篇即章品之名，謂罪分局段；聚是攢集之號，謂犯有條流。篇出《僧祇》，聚出本律；
【譯文】又在上面三篇之中，前兩篇隨順戒本正文，第三篇則通論義理。又在前兩篇之中，首先解釋通名，其次解釋別相。正因有這些差異，所以加以劃分。第十三篇「解釋篇聚篇（中卷一之上）」。解釋篇聚篇：篇聚，是總攝罪犯的綱領，是審斷是非的準則；能辨明罪業的輕重，判定果報的深淺。「篇」是章節品目的名稱，意指罪犯有一定的段落範圍；「聚」是積聚會合的名稱，意指罪犯有條理派別。「篇」出自《摩訶僧祇律》，「聚」則出自本部的《四分律》；

【513-0006】資持記/06a_中一上#3
【原文】名殊義一，故此雙標。疏引古解，具三均者名篇，一名均〔五篇當局，同一名故，均即等也。〕，二體均〔犯懺同故〕，三究竟均〔不為諸，篇方便。〕；不具號聚，如蘭吉之類；但有名均，體則不均〔蘭分三懺，吉分兩悔。〕，究竟不均〔蘭局初二從生，吉通諸篇方便。〕。
【譯文】兩者名稱雖然不同但義理如一，所以在此同時標舉。戒疏中引用古代法師的解釋：具足三種平等的稱為「篇」，第一是名稱平等（五篇各自局限本位，同一位次名稱一致，均就是平等），第二是罪體平等（所犯與懺悔的方法相同），第三是究竟平等（不是其他篇次的前方便罪）；不具備三種平等的稱為「聚」，例如偷蘭遮與突吉羅之類；它們只有名稱平等，但罪體並不平等（偷蘭遮分為三種懺法，突吉羅分為兩種悔過），究竟也不平等（偷蘭遮局限於前兩篇根本罪所從生，突吉羅則通於各篇的前方便罪）。

【513-0007】資持記/06a_中一上#4
【原文】今師不爾，篇聚名通，不必偏對，唯約五七，以分均雜；故疏云：縱使聚從五位，義具三均；篇名在七，本因雜攝是也。問：若約戒本，自有八篇；今分五七，如何相對？答：今言篇聚，不局戒本；但是立名，統收眾罪。若以五數，以對戒本；三十九十，合之為一；不定滅諍，總歸吉羅。
【譯文】本宗祖師則不作這種看法，認為篇與聚的名稱本來相通，不必偏執相對，唯獨依據「五」與「七」的分別來劃分純一與參雜；所以戒疏說：縱使「聚」依從五個位次，義理上也能具備三種平等；「篇」的名稱若安在七種之中，根本罪與從生枝條也會互相參雜，就是這個道理。問：如果依據戒本，本來就有八篇；如今分成五篇與七聚，該如何相互對應？答：如今所說的篇聚，並不局限於戒本；只是一種立名，用來總括收攝一切罪犯。如果用五個名數來對照戒本：就把三十捨墮與九十單墮合為一類；不定法與滅諍法，全都歸入突吉羅之中。

【513-0008】資持記/06a_中一上#5
【原文】然本立名，不逐文相；但使律儀所制，境遍塵沙，因果重輕，統歸五七；但五收根本，七雜本因，以為異耳。問：吉羅一聚，三均義闕，那入五中？答：誠如來難，故下文中，均雜往分，但據前四；今準《戒疏》，且約戒本百戒為言。題中，篇聚言通，貫下名報；名報語別，即後二門。
【譯文】然而當初立名，並不逐一拘泥於文字表面形式；只要是戒律所制定的威儀，所防範的境界遍及微塵沙粒那麼多，因果的輕重統統歸入五篇或七聚之中；只是五篇收攝根本重罪，七聚則摻雜根本罪與枝條因緣，以此作為差別罷了。問：突吉羅這一聚，缺失了三種平等的義理，怎麼能列入五篇之中？答：確實如同提問所詰難的那樣，所以下文中劃分純一與參雜時，僅僅依據前四篇來論；如今依照《戒疏》，只是暫且依據戒本中的百戒來立論。題號之中，「篇聚」二字意義通貫，統貫下方的名目與果報；「名」與「報」在語意上各有不同，即是後面的兩門科判。

【513-0009】資持記/06a_中一上#6
【原文】名謂教所制刑，報謂因所感果；尋名則識教，觀果則知因；此章之來，於是見矣。〔有本作來報，傳之誤矣。〕敘意，初科，上二句徵。實下，釋所以。戒體者，是善法之聚，聖道之基；超越人天，堪為物供；生福益世，實由此焉。是下，引證。受謂受體，持謂隨行。
【譯文】「名」是指佛陀教法所制定的刑責，「報」是指罪因所招感的苦果；尋究罪名就能通達教規，觀察苦果就能知曉罪因；這一篇章的由來，在此就能看明白了。（有版本寫作「來報」，那是流傳抄寫的錯誤。）敘述撰寫意旨的初門中，前兩句是徵問。從「實下」開始，解釋其中的原因。所謂戒體，是純善功德的聚會，是成就聖道的基石；能超越人天界，堪受一切眾生的供養；出生福德饒益世間，實在全是由此而生。從「是下」開始，是引經作證。「受」是指領受戒體，「持」是指隨順修持。

【513-0010】資持記/06a_中一上#7
