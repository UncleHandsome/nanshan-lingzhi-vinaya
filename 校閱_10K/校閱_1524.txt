# 校閱材料　第1524檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1524-0001】05_拾毗尼義鈔/03a_卷中之一#7
【原文】第四配初篇種類之別者如婆沙論云十三中初五戒三十中取衣浣衣染羊毛三九十中女人說法同宿女坐強坐露坐教尼下十合有十五悔過中後戒眾學中高瞻視等此是婬類二房畜寶貿寶販賣乞縷奪衣迴僧物藏衣鉢不問主賊期行四悔中第三戒眾學中飯覆羮艸淨水此是盜類十三中汙家三十中憍奢耶九十中用飲蟲水搏打他殺生等四悔中初戒眾學中大摶飯淨艸水此是殺類十三中二謗二破戾語三十中有一二居士王臣遣使九十中初戒悔過中第二戒眾學中一切說法戒等是妄語戒種類。
【譯文】第四門、依配第一篇波羅夷同類罪相之差別：正如《薩婆多論》所說：十三僧殘中的前五戒，三十捨墮中的取非親里尼衣、洗衣、染羊毛三戒，九十波逸提中的為女人說法、與女人同宿、與女人同坐、強坐、露天坐以及自教尼戒以下十戒（九十中合有十五戒），四悔過法中的最後一戒，眾學戒中的高視遠盼等，這些全部屬於淫欲類。僧殘中的二房戒，三十捨墮中的蓄積過量寶物、貿易珍寶、販賣、求乞織縷、奪衣、回轉僧物，九十戒中藏匿衣缽、不問主人自取、與盜賊同行，四悔過法中的第三戒，眾學戒中以飯覆羹、草覆淨水等，這些都屬於「盜竊」的同類罪。僧殘中的汙家戒，三十捨墮中的憍奢耶衣戒，九十戒中飲用含蟲水、毆打他人、殺害生類等，四悔過法中的第一戒，眾學戒中大團食、以淨草淨水等，這些都屬於「殺生」的同類罪。僧殘中的二謗戒、二破僧戒、惡性戾語戒，三十捨墮中的一兩條戒，如居士、王臣遣使送衣物，九十戒中的第一戒妄語戒、悔過法中的第二戒、眾學戒中一切說法等戒，這些全都屬於「妄語」戒的同類罪。

【1524-0002】05_拾毗尼義鈔/03a_卷中之一#8
【原文】第五持犯方軌者唯有二房具二持犯餘戒止便成持作即是犯二房二持者止不作房名止持從僧乞法名作持言二犯者止不乞法名止犯作造房邊名作犯此罪體一而名有異止持作持名體各別此中但解作持九句上品唯一識法識犯隨僧乞造故名作持識犯無愚不犯二罪名為上品中品四句得法無罪名為作持各帶愚癡不及上品故制為中品四句者一識法疑犯二識法不識犯三疑法識犯四不識法識犯下品亦四句唯癡多為別制以為下品四句者一疑法疑犯二疑法不識犯三不識法疑犯四不識法不識犯廣如大疏。
【譯文】第五門、持戒與犯戒的規則（持犯方軌）：唯獨二房戒同時具備「止持、作持、止犯、作犯」這四種軌範，其餘各戒只要停止不做就是「持」，一有所造作就是「犯」。二房戒的「二持」是指：停止建造不合規定的房舍稱為「止持」；向僧團乞求劃定地基的作法稱為「作持」。所謂「二犯」是指：停止而不向僧團乞求作法稱為「止犯」；在造作建造房舍的行為上違規稱為「作犯」。此處罪的本體雖是一件事，但名稱有別；止持與作持的名目和實體也是各不相同的。這裡只解釋作持的九句分別：上品只有一句，即明識戒法、明識犯相，隨順僧團如法乞求建造，所以稱為作持，因為明識法與犯而沒有愚癡，不犯二種罪，稱為上品。中品有四句，雖然獲得了如法的作法而沒有罪過，名為作持，但因為各自帶有愚癡之心，比不上上品，所以制定為中品；四句分別是：一、明識戒法而對犯相有懷疑，二、明識戒法而不識犯相，三、對戒法有懷疑而明識犯相，四、不識戒法而明識犯相。下品也有四句，純粹是因為愚癡極多而特別制定為下品；四句分別是：一、對戒法有疑且對犯相有疑，二、對戒法有疑且不識犯相，三、不識戒法且對犯相有疑，四、不識戒法且不識犯相。詳細情況如同《大疏》所說。

【1524-0003】05_拾毗尼義鈔/03a_卷中之一#9
【原文】第六僧尼犯異者有六戒輕重不同漏失一戒大僧重尼犯輕何者如婆論云女人要在屏處多緣多力苦乃盈流故輕男子隨事能出故重摩捉一戒尼重僧輕何者尼惑厚重更受摩捉必為前境所陵成大過故方便之內制與重名男子必無陵壞不須深防限分中制故輕二麤語大僧重尼輕僧為之義數故重女人志劣麤語稀故輕二房僧重尼輕何者僧得孤遊獨宿二房得殘尼即不爾媒嫁二謗已下七戒僧尼同犯義即可思。
【譯文】第六門、僧尼二眾犯相的差異：共有六條戒在罪過輕重上有所不同。漏失戒這一條，大僧犯則重，比丘尼犯則輕。為什麼呢？正如《薩婆多論》所說，女人必須在隱蔽處、憑藉多種助緣和大力氣，苦惱折磨才會流洩，所以判輕；男子則隨順因緣就能排洩，所以判重。摩觸戒這一條，比丘尼犯則重，比丘犯則輕。為什麼呢？因為女人煩惱惑障深重，如果再接受摩觸，必定會被對方境緣所凌辱侵害而釀成大過，所以在方便位中就給予重罪之名；男子絕對沒有被人凌虐毀壞的危險，不需要過度深防，只在界限範圍內制約，所以判輕。兩條粗語戒，大僧犯則重，比丘尼犯則輕；因為比丘常常容易這樣做，所以判重，女人志氣怯弱，粗語情況較稀少，所以判輕。二房戒，比丘犯則重，比丘尼犯則輕；因為比丘可以孤身雲遊、獨宿一處，造二房違規得僧殘，比丘尼則不允許如此。從媒嫁、二謗以下的七條戒，僧尼二眾同犯同罰，其義理可以仔細思索明白。
