整體看，這篇譯文讀來通順，專名（和尚／阿闍梨、式叉摩那、牸牛、草馬、闍維、檀越）處理得不錯，「不得不往」這種雙重否定也沒有譯反，方向是對的。以下按輕重列出可修之處。

---

## 一、建議必改（實質問題）

**1.「餘三眾」的對象譯錯了**

> 譯文：其餘**式叉摩那、沙彌尼、優婆夷**三眾也比照此法處理。

這裡是承上文「病**比丘**」「病**比丘尼**」而來，「餘三眾」應是**出家五眾**扣除比丘、比丘尼後的**式叉摩那、沙彌、沙彌尼**（律典「三眾」多即指此下三眾）。譯文顯然是取前面《四分》「比丘尼、式叉摩那、沙彌尼、優婆夷」這組女性名單去掉比丘尼而得，但：

- 漏了**沙彌**（男眾），與前文「道逢病比丘」的男性脈絡不合；
- 本段的處理內容是「**死用彼衣鉢，雇人闍維**」——亡者遺物歸僧、以衣缽充葬資，這是**出家眾**的作法；優婆夷（在家女）有眷屬財產，不適用此法。

建議改：「其餘式叉摩那、沙彌、沙彌尼三眾，準此辦理。」（可再核《資持記》該段釋文確認。）

**2.「無所分別，不問牸牛草馬」的理由譯偏了**

> 譯文：如果病情嚴重，**已無暇挑揀分別**……皆可借用騎乘載運。

律制平時不許比丘乘騎**牝畜**（防觸染、譏嫌），所以特別點出「牸牛、草馬」；「無所分別」是說**病篤開緣、不再拘此禁令**，不是「來不及挑好壞」。譯成「無暇挑揀」把開緣的律意換成了時間緊迫。

建議改：「若病情沉重，則不必顧忌（平時不得乘牝畜之限），無論母牛或母馬，皆可乘載。」
另「借用」原文無，可刪。

**3.「若俗人嫌者」憑空加了原因**

> 譯文：如果世俗之人嫌棄**惡臭不便**……

原文只有「嫌」（嫌惡棄屍於此、譏嫌），「惡臭不便」是譯者補的具體理由。建議：「若世俗人嫌惡（在此棄置遺體），應擔送至遠處。」

## 二、可再精確（增譯／收窄原意）

| 原文 | 現譯問題 | 建議 |
|---|---|---|
| 若不看者，一切僧得罪 | 「如果**大家都**不照看」把條件收窄成全體不看；律意是病者無人看護，則（同界內）一切僧皆得罪 | 「若不看護，一切僧眾皆得罪」 |
| 取薪火 | 「取來柴火」漏了「火」的用途 | 「取柴薪、生火（供取暖）」 |
| 供養屍骸 | 「供養**安葬**」偏指土葬，與後文「闍維（火葬）」不一致 | 「如法殯送、處理其遺骸」 |
| 死用彼衣鉢 | 「**變賣資財**」是推衍（律文只說以其衣缽雇人） | 「以其衣缽充作酬資，雇人火化」（或保留但加括號說明） |
| 無者，捨去 | 「唯有捨棄放置」未點出「離去」，也未點出「無者」指無衣缽可用 | 「若無衣缽可用，只好置屍離去」 |
| 應倩女人 | 「倩」＝請託／僱請；「**世俗**」為添加 | 「應另請（僱）女人代為按摩身體」 |
| 唯除手觸 | 未明主語 | 「唯獨（男眾）不得親手碰觸」 |
| 馱載令歸 | 「車乘**馬匹**」「返回**僧坊**」皆屬補字 | 「求車乘或牲口馱載，載他回去」 |
| 我走向聚落 | 「**前方的**村落」為添加 | 「我趕到村落去」 |
| 若弟子 | 未標明是誰的弟子 | 「或（病人的）弟子」 |
| 眾僧應與瞻病人 | 「與」＝供给、為其安排；「指派專人擔任」略偏行政化 | 「僧團應為他提供瞻病人」 |
| 若不肯者 | 主語本可兩解（僧眾不肯給看病人／被差者不肯），「不肯**主動承擔**」是解讀 | 中性化：「若不肯，應依次第差派」 |
| 並是佛自號令 | 「**戒**令」稍窄，此處道宣強調是**佛親制之教令**（非祖師私意），故不可違 | 「這些都是佛陀親自下的號令（教令），依理應順從奉行」 |
| 二簡人中 | 「在揀選照料者之中」生硬 | 「第二、簡選瞻病人這一科中」 |

## 三、修訂示例（後半段）

> ……若病情沉重，則不必拘於平時的限制，無論母牛或母馬，皆可乘載。若無車乘，應留人照料；無人可留，則為他搭草庵、取柴生火、留下醫藥飲食，並告訴他：「你安心靜養，我趕到村落，求車乘來接你。」然後離去。到村落時，不得先去繞塔、問訊和尚等，應直接說：「曠野中有病比丘，大家一同去迎接回來！」諸比丘若說：「那裡多虎狼，恐怕人已被吃光了。」即使聽了這話，也不得不去，必須趕到。若已死，就如法殯送遺骸；若還活著，帶回來，交村中比丘照護；無比丘，則告知施主令其照看。共迎病人的作法亦如前。若路上見到病比丘尼，不得捨棄離去，乃至前往迎接等，都與比丘相同；唯獨不得親手碰觸，應另請女人為她按摩身體。若死亡，以其衣缽充資雇人火化；無衣缽者，置屍離去；若俗人嫌惡，則應擔送至遠處。其餘式叉摩那、沙彌、沙彌尼三眾，準此辦理。這些都是佛陀親自下的號令，理當順從奉行；更詳盡的內容，如律中所述。

---

**小結**：唯一稱得上「錯」的是 **「餘三眾」**；其次是 **「無所分別」的律意**與 **「惡臭不便」的添譯**。其餘多屬補字與用語可再貼合原文的問題，改後即可用。
