# 二、第一篇：標宗顯德篇第一

### 【總標宗旨與痛陳末法弊病】
戒律的大海深邃廣博，貫通世間萬象；它雖然無所不包、外無遺漏，卻容不得半點死屍（譬喻破戒之僧）；其波濤如高山雲湧，而潮水絕不漫過界限。因此，凡躋身玄門僧眾之列者，務必嚴持清淨戒禁，不容有毫無軌度的非理之行；沐浴心靈於正道法水者，當欣慕出離苦海之要道，在世間一塵不染。如此才能立德於當世，蹤跡超脫於塵俗羅網。這實是因為：沒有正法，無以光顯其威儀；沒有道德，無以彰顯其德行。

然而末世那些見識淺薄庸俗之輩，雖身列緇衣僧服之名，學問卻不曾深遠；行為不依循戒律，有何善法可言？性情既已疏懶粗野，豈能探究真如要旨！只知固步自封、守株待兔，出離之志早已斷絕。心智局促於方寸之間，而言論毫無著落；口中雖妄談玄道，所作所為與世俗無異；隨波逐流，行事完全乖違解脫真趣。即便研習多年，依然昏昧無知所依；更何況談論世俗學問，又有誰能真正體悟？

因此導致濫竽充數、混亂戒法綱紀。隨心所欲地放縱爭奪，專行蠻橫刻薄之事，這尚且為世俗道德禮節所不齒，又何來修道者的儀範可存？以致新進後學困頓如被巨石壓身，戒律要領完全斷絕於軌範之外；在此之時，正法的玄妙綱領怎能不傾覆墜地呢？

所以當知，佛法的興盛與衰替全在於人！若是真正尊崇護持正法之人，又何必擔憂佛日不再重輝、法輪不再轉動呢！如今我扼要指出戒律的宗要、戒體、戒行與戒相，使後進學人修行建功有所依託。

### 【立戒之目的與戒之四科】
戒律是以隨順眾生根器為其功用，修道者則以領納於心為其宗趣。唯有能善加清淨身心、如法應機而受戒之人，方能成就與大道相應之境界；如果心中毫無超凡遠大的志向，稍有絲毫微細偏差，就只不過是在法流之中徒染虛名，將憑何作為修道的清淨器皿？又憑何作為世間的大良福田？其意義何在！

因此，凡是志在使身心行持清白、遠期證得圓滿聖果之人，切不可草率妄動；必須凝神定志、攝持思慮，使心神契入戒體而無窒礙。故經云：「戒雖無具體形色，卻可以真實護持。」其義理再明白不過了！為什麼呢？因為戒相萬端，非僅一種途徑；人之發心有限量，領納各不相同；若隨境相立名，則有無量數之多；今提綱挈領，簡略標出四種：**一者戒法，二者戒體，三者戒行，四者戒相。**

#### 1. 戒法
所謂戒法，純就法體而言，通於凡夫與聖人。直接指出此法必定能夠規範成就出離生死之道，要使受戒者深信確實有此法存在。雖然凡聖皆通有此法，但今日所受者，就其成就聖道之功而言，名為「聖法」。凡是要跳脫生死輪迴、敬仰並廁身於僧寶行列、立下誓願歸期、高蹈於世俗繫縛之外的人，必須預先長養這顆道心，使之隨各人身心而成辦；如此方能心懷聖法、身居聖行，所以稱之為「隨順戒法之行」。

#### 2. 戒體
第二說明戒體。若依照一般通論，是指受戒時所發起的身口「無作（無表）業體」；如今若依本宗正見，則直接顯明其「能領納之心相」。這意思是說：面對遍法界如塵沙般的事相、以及真俗二諦等法，受戒者以自己懇切誓受的期願，施設受戒的種種方便；徹底清淨自心器皿，立誓絕不再造惡；以審慎思維的明澈智慧，與眼前的法界妙法默然相契。以此誓願之心，與彼微妙戒法感應道交，在此法上便具有了法界緣起的深義；將此法領納銘刻於心，就稱之為「戒體」。

#### 3. 戒行
第三說明戒行。既然受得了此戒體，秉持銘記於心，便必須廣修各種對治方便，嚴格檢察身口二業的威儀舉止；立志專一崇尚戒德，高步景仰歷代前聖；持戒之心隨後綿延生起，行為順從於先前所受的戒體，這就稱之為「戒行」。所以經云：「雖尚未直接面對境緣，但若能善修對治方便，亦能保持清淨。」經文即是明證。

#### 4. 戒相
第四說明戒相。由內在戒行所顯發的身口威儀圓滿成就，隨其舉手投足所作所為，一舉一動皆完全契合佛法軌範，戒德之美光明顯發於外，故稱之為「戒相」。

這四條，是修道者的根本依憑、成道者的終極歸宿。因此標示在本書篇首，使學人寄心有所歸屬；深知自身心懷佩持著如來聖法，在下可作為六道眾生的福田，在上可作為圓成三乘聖道的因種；其餘紹隆佛陀血脈、建立正法幢相的不可思議功德，豈是區區言語所能道盡！以下直接引述佛陀聖言作為明證，令持戒之清高士子深研照察。

### 【順戒法住與違戒法滅之經論明證】
內容分為兩部分：一是明「順戒」，則三寶住世，成辦比丘清淨聖業；二是明「違戒」，則覆滅正法，轉而播種地獄苦業。

#### 【甲、順戒讚戒】
**一、化教小乘經論**
* **小乘經**：《般泥洹經》說，佛陀即將滅度，世間將失去導師，阿難啟請問佛。佛言：「比丘若能奉持戒律，戒就是你們的大師，如同我常住世間毫無差別！」《佛遺教經》等亦作同樣示導。要發起萬種菩提行持，戒是根本宗主，故經云：「若想轉生天界，必須具備戒律之足。」又如大地能生成萬物，經云：「若無淨戒，一切善法功德皆不得生。」又云：「依憑此戒，方能引發定與慧。」又云：「戒是行持的根本住持。」即譬喻如大地之生成住持一切。
* **小乘論**：《成實論》說：「三十七道品的樓閣以戒為巨柱，禪定心城以戒為城郭；若欲列身善人群體，務必佩持戒法之印。」因此特須尊重戒律。《解脫道論·戒品》中極多讚歎，文字繁多不備出；需要者自當查閱，受持則戒體不致羸弱。《大毘婆沙論》說：具足戒足者，戒稱為「尸羅」，亦即行持、守信、器具之義。尸羅譯為「清涼」，因為沒有破戒之熱惱及三惡道火熱之苦；又名「善夢」，持戒者常做吉善之夢；又名「習」，因常修習戒法；又名「定」，安住於戒中心易得定；又名「池」，是群聖沐浴之處；又名「瓔珞」，老少中年佩戴皆美妙；又名「明鏡」，因戒清淨故無我真像得以顯現；又名「威勢」，如來在世之大威力，皆由尸羅之力而來。其餘如降伏惡龍之事：五百位大阿羅漢皆不能驅逐，唯有一位羅漢僅以平素連極微小戒都等同重大戒般護持的戒力，便能當場將惡龍驅離！戒又名為「首」，能明見苦諦等諸色法；能善加防護，故名「守信」；能抵達涅槃城，故名「行」；功德所依憑，故名「器」。尊者瞿沙說：「不破損就是尸羅之義。如同人之雙足未破，便能行走遠方；行者不破壞尸羅，便能通達涅槃。」

**二、化教大乘經論**
* **大乘經**：《華嚴經》說：具足受持威儀教法，奉行六和敬，妥善統領大眾，內心毫無憂惱悔恨，不違背過去、未來、現在三世諸佛所說正法；能令三寶血脈不斷，使正法久住。《大集經》云：十方世界的菩薩懇請佛陀為五濁惡世眾生制定戒律，如同其餘佛土一樣，以求正法久住。佛陀答允之後，便開始制戒。《薩遮尼犍子經》說：若不持戒，未來世連疥癬癩皮的野干（野狐）之身都得不到，何況能得莊嚴功德法身！《月燈三昧經》說：即便生於尊貴種族且多聞博洽，若無持戒智慧，依然猶如禽獸；雖處卑下微賤且少見寡聞，若能清淨持戒，便是殊勝大士！《大般涅槃經》說：若想明見佛性、證得大涅槃，必須深心修持淨戒；若一面受持此經卻一面毀犯淨戒，此人乃魔王眷屬，非我弟子，我亦不聽許他受持此經。《華嚴經》偈頌說：「戒為無上菩提本，應當具足持淨戒；若能堅持於禁戒，則是如來所讚歎！」故特別重引此偈，令大眾銘記於心頭首位。
* **大乘論**：《大智度論》說：若求大利益，當堅持淨戒；戒是一切功德的根基、出家修行的要領。應如同珍惜稀世重寶、如同守護身家性命般護戒，因為戒是一切善法的住處。又好比沒有雙足卻想行走、沒有翅膀卻想飛翔、沒有船隻卻想渡江，絕不可得；若無戒法而想得到解脫善果，亦絕不可能。若放棄此戒，即便居於深山行苦行、服氣飲水、身穿草衣、披著破衲袈裟，受盡種種苦行，最終也是空無所得。人縱使身世貧賤，若能持戒，德香便遍聞十方，美名廣布，天人恭敬愛戴，所願皆成。持戒之人到了壽終之時，即便四大解體、風刀解體如斷筋脈，內心亦毫無恐懼。《菩薩地持經》說：佛陀的三十二相好，其無差別的通因皆是持戒所得；若不持戒，連下賤人身都得不到，何況感得大人相好的福報！《十住毘婆沙論》中有〈讚戒〉、〈戒報〉兩品，廣泛陳述持戒的深遠利益，詳如彼論所說。

**三、制教律部與律論**
* **律本**：《僧祇律》說：欲得五種利益，應當受持此律——一能建立佛法，二令正法久住，三不致心生疑悔而需請問他人，四能為犯罪的僧尼作皈依依靠，五欲遊歷化導四方而無窒礙，這是給篤信善男子的五種利益。《四分律》云：持律之人可獲五種功德——一戒品牢固，二善勝一切怨仇，三於大眾中決斷是非而無所畏懼，四遇他人有疑悔能為之開解，五善持毘尼令正法久住。又得如攝取於僧等十種利益。《十誦律》說：阿難問佛法幾時能住世？佛答：只要有清淨比丘說戒之法不毀壞，就叫正法住世；三世諸佛亦復如是。
* **律論**：《毘尼明了論》解說：「毘那耶」簡稱毘尼，具五種意義：一能生起種種殊勝利益（引生世間與出世間善法）；二能教導身口二業清淨正直；三能消除滅除罪障；四能引向勝妙之義（引導在家人出家，乃至證得梵住、聖住、無餘涅槃）；五是殊勝之人所行之事業（最勝人是佛，其次是獨覺與聲聞，皆行於戒律之中；凡夫能持戒者，亦是殊勝之人方能為之）。《薩婆多論》說：毘尼有四種深義，為其餘經典所未載——一、戒是佛法的平地，萬善皆從中生長；二、一切佛弟子皆依戒而住，一切戒定慧功德由戒而有；三、是趨入涅槃的最初法門；四、是佛法的瓔珞莊嚴，能嚴飾法身佛法。具備這四義，其功德遠勝他典。《善見律》記載：佛陀對阿難說，我滅度後，有五種法能令佛法久住——一是毘尼戒法，即是大眾導師；二在世間至少有五位持律比丘住世；三在中國（佛法中心地）有十人、在邊地有五人能如法受戒；四乃至有二十位清淨僧能如法為犯僧殘者出罪懺悔；五因有律師傳持戒律之故，正法得以住世五千年。《五百問》云：佛陀即將入滅（垂泥曰）時，阿難悲痛泣淚。佛問何故悲泣，佛說：「我並未真正滅度，半月一次誦戒時我都將重來！」又說：「佛有二身，肉身雖逝，法身常存。若有恭敬法、憶念法之人，就是恭敬佛、憶念佛；若能堅持五戒，便是得見法身；若能護持戒法，便是護持諸佛。」如同兩位比丘在荒漠中寧死不飲蟲水、以命護戒的比喻。又如半月誦戒，見戒即是見佛。《薩婆多論》又問：何以律藏結集在最先？因其最殊勝、最隱秘之故。諸經不論時間、處所、對象皆可宣說而得名為經；律則不然，唯佛親自金口宣說，且必須在僧團內部宣說，故最為殊勝尊貴。《分別功德論》亦云：因戒律極其勝妙隱密，非世俗凡夫所能行持，故不許俗人觀閱。《大莊嚴經論》亦慨嘆：卑劣愚癡之人，絕不堪護持此無上清淨戒！

#### 【乙、違戒法滅】
綜合二教雜明違戒之相：
《十誦律》說，像法之時有「五種滅法」：一、比丘稍得內心微小定境，便自妄稱證得聖果；二、在家人行善生天，出家人破戒反墮地獄；三、有人捨棄世俗家業出家，卻隨即毀犯禁戒；四、破戒惡人反而有眾多同黨予以協助；五、乃至阿羅漢聖僧亦被無知之徒毆打辱罵。

又有「五種怖畏」之事：一、自己不修身、戒、心、慧，卻收徒度人，教人也不修身戒等法；二、私蓄沙彌而不加如法管教；三、未具德行便收納他人依止；四、與淨人、沙彌同住，自己卻不懂「三相」（即不知耕掘泥土、斬斷青草、灌溉有蟲之水等犯戒威儀）；五、雖背誦律藏，前後次序雜亂無章。

《四分律》指出「五種正法迅速滅亡之因」：
1. 有比丘未能審諦受持誦念律藏，動輒忘失文句，又去教導他人；文句既不完備，義理便產生闕漏。
2. 身為僧團中的尊宿長老、一國所宗奉的高僧，卻大多不持守戒律，只修不良之行；後輩爭相倣效學習，放逸拋棄戒行。
3. 有比丘通達經法、律藏、論藏（阿毘曇摩夷），卻不肯教導出家與在家道俗，一旦命終，致使法脈斷絕。
4. 有比丘性情剛愎極難教導，拒不受善言相勸，其餘善信比丘只能棄之不理。
5. 僧團內部互相謾罵詆毀，互挑長短，加速正法滅亡。

《十誦律》載：諸比丘廢棄毘尼不學，專門讀誦修多羅（經）與阿毘曇（論），世尊為此種種嚴厲訶責；明確指出正因有毘尼戒律在，佛法才能長久住世。因此有許多上座長老比丘精研學律。《雜阿含經》說：若長老、上座、中年、少年僧眾，起初便不喜愛戒律、不尊重戒律，見到精勤持戒者亦不及時讚美，佛說：「我絕不稱讚這種人！為什麼？因為深恐他人也認同其邪見，在漫長黑夜中受極大痛苦！」

《中阿含經》說，犯戒者有「五種衰敗」：一者求財不得；二者設使有財亦迅速衰損耗盡；三者不為大眾敬愛；四者惡名傳播遠近；五者死後墮入地獄。《大般涅槃經》中佛說：由於眾多比丘不持禁戒，畜積八種不淨財物，反而妄稱是佛陀開許，這等人怎不驚懼舌頭捲縮腐爛！《摩耶經》預言末世法滅之相：僧人喜好華服、縱逸嬉戲；奴婢買賣成為比丘、比丘尼；不樂意修不淨觀；肆意毀謗毘尼；袈裟褪色變白，不肯受如法染色；貪心私用三寶公物等，皆是正法滅亡徵兆。

《大智度論》嚴厲指出：破戒之人，眾人不敬，其住處猶如墓塚廢墟；喪失一切功德，宛如枯乾死樹；其惡心令人畏懼，好比羅剎夜叉；人皆遠離不敢靠近，如同對待致命大病人；難以共同相處，如同身側盤踞毒蛇。這種人雖剃髮染衣、按順序領受籌夾，本質上絕非比丘！若披著法衣、執持缽盂，那法衣便等同烙身的灼熱鐵片，缽盂等同滾燙的洋銅器；所吃飲食，如同吞服熱鐵丸、飲滾沸銅汁，本質上早已是地獄中人。心中更應時常恐懼：「我是佛門大賊，常畏死期橫至！」如是種種破戒惡相，難以言盡。修行之人應當一心一意堅持清淨戒！

### 【辨破惡取空：釋「罪與不罪不可得」】
* **問**：有人說：「深入法性，見到罪業與非罪業皆空不可得，這才叫作真正的持戒。」這種說法對嗎？
* **答**：經中所言，絕不是指以世俗凡夫的邪見粗心，狂妄地說世間根本沒有罪福！若能真正深入諸法實相，安住於空三昧中，以般若智慧之眼徹照萬法，方能說「罪不可得」。若是依凡夫肉眼之所見、心懷貪瞋妄加套用，其行徑見解與牛羊牲畜又有何異！如今世上許多誇口大乘口頭禪的人，自身戒力本就薄弱，不堪受持嚴謹戒律；又以自身的污穢惡行深感羞恥，大多不肯傳承修學律法。甚至有人引導空論作為擋箭牌，根本不解經文真諦；對此曲解謬誤，我在《四分律含注戒本疏》（大疏）第十五卷中已廣為剖析辨正。

《四分律》指出破戒有五種過失：一者自害身心；二者為智慧者所訶責；三者惡名遠播四方；四者臨命終時悔恨莫及；五者死後直墮三惡道。《十誦律》指出加速正法滅亡的十種惡法：有比丘毫無清修之志且根性遲鈍，雖能諷誦文句義理，卻不能如法受持，也絲毫不理解其意；不能使受教者生起恭敬威儀；乃至不喜愛阿蘭若（幽靜修處）法門；不隨順佛法教導；不敬上座；自身又無威儀；使後進晚輩不肯受學毘尼，致使放逸懈怠，喪失一切善法；沉溺於撰作華麗文章詩頌、莊嚴辭藻，樂於世俗文字之道——凡此種種貪愛世俗之行，皆會令正法迅速消亡，實令人極其畏懼！
