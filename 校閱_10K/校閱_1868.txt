# 校閱材料　第1868檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】有人言：本依界故成安居，若解本界便失夏也。以失所依，即日雖結，亦不成就。故文云「安居竟應解界」，未竟而解，知非也
【譯文】有人說：本來是依憑界地才成就安居的，如果解除了本界，便失掉了夏安居。因為失去了所依憑的界地，當天雖然重新結界，安居也不成就。所以律文說「安居結束後應當解界」，如果在安居尚未結束時就解界，便知是不合法的。

【譯文】問：在所處之地成就安居，走出界外必須過夜（經宿）才算破夏，為什麼解界當天就會立即破夏？答：走出界外的人，他所依憑的界地依然存在，所以一定要過夜才破夏；如今解除了本界，便失去了原來的所依憑之處，因此不用等到過夜就已經破夏了。

【譯文】在第二科中，首先決斷破斥前一位論師所執持的觀點。「同法合界」的含義見於後面的科段。「由」字以下，顯明僧事與安居的意義不同。所謂安居隨處皆可：第一是不專限於作法界地，第二是不局限於僧伽藍寺院之內。

【1868-0018】03_業疏/20a_卷四之三#79
【原文】今解云：本依自然結夏尚成，今結作法牢強於本，何得云破？以不離界故。然立心行者，行護從急。若後作法遠於自然，但依自然分齊，既無緣難，不可後開；若結狹本，有說依新，意以依處安居隨本自然為定。由本作法意在羯磨，安居隨處，不要加結
【譯文】如今解釋道：當初依憑自然界結夏尚且能夠成就，如今結成作法界，比原來的自然界更為堅固牢實，怎能說是破夏呢？因為並未脫離界地的緣故。然而立心持戒的行者，其操行持護應當從嚴從急。如果後來結成的作法界範圍大於（遠於）原先的自然界，則只應依循原自然界的界限，既然沒有特殊緣由與難事，就不可在事後予以放寬擴大；如果結成的作法界狹於原本的自然界，有人說應依新的作法界，但律疏之意認為，依處安居應當以原本的自然界為準定。因為當初作法結界的用意是在於如法舉行羯磨，而安居則是隨處皆可，並不需要額外加結作法界。

【1868-0019】03_業疏/20a_卷四之三#80
【原文】次科初斥非理。「然」下次決寬狹。初明先狹後寬，古今不異。「立心行者」，謂秉志持奉之人。「若」下次決先寬後狹，兩釋不同。「有說依新」，即示古解，彼謂從急捨寬就狹。「意以」等者，即明今義。安居要依本期，義須仍舊；結界為行羯磨，事不相干
【譯文】在第二科中，首先斥責前面的說法不合義理。「然」字以下，接著決斷範圍寬狹的問題。先說明先狹後寬的情況，古今說法沒有差異。「立心行者」，是指立定心志奉持戒法的人。「若」字以下，接著決斷先寬後狹的情況，兩種解釋有所不同。「有說依新」，即指出古代的解釋，他們認為應當從嚴從急，捨棄寬界而依從狹界。「意以」等句，即闡明如今的正義：安居必須依據最初約定的處所，在義理上必須依照舊界；結界是為了推行僧事羯磨，兩者在事相上互不相干。

【1868-0020】03_業疏/20a_卷四之三#81
【原文】有人言：隨後作法是聖教本，如依自然護衣，後結作法，既不失前，亦隨廣護也
【譯文】有人說：隨順後來結成的作法界才是聖教的本意，就像原本依憑自然界來守護衣物，後來結了作法界，既不會失掉先前的護衣功德，也能隨之擴大守護的範圍。

【1868-0021】03_業疏/20a_卷四之三#82
【原文】次解初中，「是聖教本」者，本制依界故。下舉衣界例，須依後
【譯文】在第二種解釋的第一部分中，「是聖教本」的意思是佛陀本來就制定要依界而住的緣故。下文援引衣界為例，主張必須依從後來的作法界。
