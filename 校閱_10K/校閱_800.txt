# 校閱材料　第800檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【800-0001】02_戒疏/19a_卷四下之一#69
【原文】【記】戒緣中。「三律」，即《五》、《十》、《祇》也。注中，初明起過。年少新學十七人共為群黨，事同六群，比上可解。「匿王」已下，次明制戒之由。王見譏嫌，夫人對王恐生輕易，又令奉蜜請佛立制。大權護法發起斯教，非凡所擬也。
【譯文】【記文】制戒因緣中。「三部律」，即指《五分律》、《十誦律》、《僧祇律》。隨律註解中，起初說明生起過失的原由。年少新受戒的十七人結為同夥群黨，行徑與六群比丘類似，對照上文即可明白。從「波斯匿王」以下，接著說明制定戒律的緣由。國王看見後產生譏嫌輕視，夫人在國王面前唯恐他因此輕視三寶，又命人敬奉石蜜請佛立法。大權菩薩護持佛法以促成這條教規的建立，絕非凡夫常情所能揣度。

【800-0005】02_戒疏/19a_卷四下之一#73
【原文】【註】除水已，若酪漿、苦酒、麥汁，器中弄，一切吉羅。不犯者：若道行渡水；或從此岸至彼岸；或水牽竹木𥱼，順流上下。若取石沙，若失物沈入水底，此沒彼出；或學知浮法，而擢臂畫水、灒水者，無犯。
【譯文】【註文】除了水以外，若是乳酪漿、酸醋、大麥汁，在容器中攪動玩弄，一律犯突吉羅（輕垢罪）。不犯的情況：若是在路途行進時涉水渡河；或者從此岸橫渡到彼岸；或者在水中牽引竹筏木排，順著水流上下往來。若是為了拾取石塊沙土，或是為了打撈掉落沉入水底的物品，而在水中沉潛浮現；或者是為了學習掌握游泳之法，因而揮動手臂劃水、潑起水花者，均不犯戒。

【800-0006】02_戒疏/19a_卷四下之一#74
【原文】【疏】戒本三句，文相易耳。入中為洗，不戲難哉。
【譯文】【疏文】戒本條文共有三句，文字意義十分淺顯易懂。跳入水中原本是為了洗澡沐浴，若要不生嬉鬧玩樂之心實在太難了。

【800-0007】02_戒疏/19a_卷四下之一#75
【原文】【記】戒本。「三句」，大同前戒。「入」下，誡慎。此土南方入水者稀，然水性清冷，人多喜弄，準上鉢中，弄者皆犯。注不犯中，「𥱼」音牌；「擢」合作；「掉」音調，振也。
【譯文】【記文】戒本條文。「三句」，與前一條戒律大致相同。從「跳入」以下，告誡修道者應審慎提防。此地南方入水游泳的人很少，然而水性澄澈清涼，人們多半喜歡戲水玩弄，依照上文連在缽中撥水都屬違犯，嬉戲者皆會觸犯戒律。隨律註解不犯條文中，「𥱼」字音同牌（意為竹筏）；「擢」字應當作「掉」字，音調，是搖動振臂的意思。

【800-0010】02_戒疏/19a_卷四下之一#78
【原文】【疏】事雖是輕，過容至重。小人無志，多喜為之。極是鄙薄，大虧形望，損道傷風，勿過此失，故制。
【譯文】【疏文】舉動雖然看似輕微微不足道，招致的過咎卻極可能深重異常。低劣之人缺乏堅定修道之志，往往特別喜歡做這種事。這極其卑陋薄俗，大大損害了出家僧人的莊嚴威德與崇高聲望，毀辱道法敗壞教化風氣，沒有比這種過失更嚴重的了，所以必須立法嚴制。

【800-0011】02_戒疏/19a_卷四下之一#79
【原文】【記】五十三。「擊攊」，謂以手捵弄腋下，令懼痒也。制意中，初二句標過重，次二句明喜為。「極」下，出過相。「鄙」即鄙惡，「薄」謂薄賤。「大虧形望」者，乖出家之勝儀，損尊高之令望。「損道」謂辱於佛法，「傷風」即壞於化導。事輕過重，故可見矣。
【譯文】【記文】第五十三條。「搔抓撫弄（擊攊）」，是指用手指戳動逗弄他人的腋下，使人發癢而恐懼躲避。在制戒用意中，起初兩句標明罪過深重，接著兩句說明無志之人常樂於此舉。從「極其」以下，指出過患的具體形相。「鄙」即是卑鄙齷齪，「薄」即是薄賤浮躁。「大虧形望」者，是指乖違背離了出家人超凡拔俗的威儀，毀損了受人尊奉的高尚風範。「毀辱道法」是指污辱玷污了清淨佛法，「敗壞風氣」就是破壞了化導世間的純良教化。看似事小而過失深重，由此完全可以看清。
