# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【475-0001】03_業疏/07b_卷二之一#43
【原文】次釋羯磨初解為三段：初、陳情告眾，二、審眾可否，三、顯眾已和。言「情事」者，情謂能秉之心，事即所被之事。所被自分情、非情別；今望能秉，一切羯磨竝須心和，通為情事。「語默表情」者，語則表別，默則表和，即文云「忍者默然，不忍者說」，說即語也。「眾情」下二句釋「僧已忍」至「竟」字，前審說、默，眾既無說，即顯情和，故為成相；「故」下一句釋「僧忍默然故」，「持」下一句釋「是事如是持」，持謂同心秉行，非輕爾也。
【譯文】接著解釋羯磨的第一種見解，分為三段：一、陳情告眾，二、審查大眾可否，三、顯現大眾已經和合。所謂「情事」，「情」指能秉持作法的心，「事」就是所針對的事由。所針對的事由自身又區分為有情與非情之別；如今對望於能秉持者而言，一切羯磨都必須心意和合，所以統稱為情事。「言語或默然以表情」這句話，言語就表示有異議，默然就表示贊同和合，也就是經文所說的「同意的人默然，不同意的人說出來」，說出來就是言語。「眾情」以下兩句是解釋從「僧已忍」至「竟」字，前面審查說或默，大眾既然沒有人發言，就顯出眾情和合，所以是成就之相；「故」字下一句解釋「因為僧眾同意而默然」，「持」字下一句解釋「這件事應當這樣受持」，「持」是指同心秉持奉行，並非草率隨便。

【475-0011】03_業疏/07b_卷二之一#53
【原文】白中文五，第二句者，牒時有顯晦：有則牒緣、牒本，無則略之，連唱第三「若僧時到」，至第四句方牒其二，總告結白，故律文中竝牒緣、本。故若有緣起，如前結界，須比丘唱；若有乞辭，諸受、懺等，第二句中並牒緣、本，故具五句；若諸差人無因緣者，但有四句，如前述也。

【475-0019】03_業疏/07b_卷二之一#61
【原文】第二、第四，此之二句，文局一事，義通諸務，試為舉之
【譯文】第二句與第四句這兩句，文句局限於某一件事，義理卻通貫於各項事務，試著列舉說明如下。

【475-0020】03_業疏/07b_卷二之一#62
【原文】次科標舉中。文局一事，謂結、說、受各不相同；義通諸務，謂緣本雙單，諸白無異
【譯文】在下一條標示列舉之中。「文局一事」，是指結界、說戒、受戒各自文詞不同；「義通諸務」，是指緣起與事本的雙牒或單牒，在各種白文中並無差別。

【475-0021】03_業疏/07b_卷二之一#63
【原文】如結界云「舊住比丘」，謂初緣也；「牒方相」者，謂事本也。說戒白云「今僧十五日」，亦是緣也；「布薩說戒」，亦事本也。受戒白云「某甲從和尚乃至清淨衣鉢具足」等，竝緣也；「今從僧乞戒」，即事本也。如是例通，緣本是一，自可知也。
【譯文】例如結界白文說「舊住比丘」，這是指最初的緣起；「牒出四方界相」，是指事物的根本。說戒的白文說「今僧十五日」，也是緣起；「布薩說戒」，也是事本。受戒的白文說「某甲從和尚乃至清淨衣鉢具足」等，都是緣起；「如今向僧眾乞戒」，就是事本。像這樣推例相通，緣起與事本的體例是一致的，自然可以明白。

【475-0022】03_業疏/07b_卷二之一#64
【原文】第二句中，略舉三法，餘自例知。然據單白，緣本可分；若羯磨前白，則緣本不同。如結界白，比丘為緣，牒相為本；及至羯磨，人、相竝緣，結界是本。受白亦爾，從和尚等為緣，乞戒為本；若論羯磨，從乞皆緣，僧受為本。隨義栽取，不可一例。
【譯文】在第二句中，略微列舉了三種法事，其餘自可依此類推得知。然而依據單白，緣起與事本可以分明；若是羯磨之前的白文，則緣起與事本有所不同。例如結界白文，比丘是緣起，牒出界相是事本；到了羯磨時，人與界相都成了緣起，結界才是事本。受戒白文也是如此，依從和尚等是緣起，乞受戒是事本；若論及羯磨，依從乞請都成了緣起，僧眾為其授戒才是事本。應當隨順義理來裁奪選取，不可一概而論。

【475-0023】03_業疏/07b_卷二之一#65
【原文】至第四句中，單牒根本，略去前緣，縱有雙者，結翻非淨，何以括耶？故結界白云「於此相內結大界」，豈非本所為事也？說戒第四云「和合說戒」，亦是本也。受戒第四云「僧與某甲受具」，亦是本也。本義是通，受、說文異
【譯文】到了第四句中，只單牒根本，省略了先前的緣起，縱使有雙牒的文句，也是結集與翻譯時潤色不精審，怎能以此為準則來概括呢？所以結界白文說「於此相內結大界」，這難道不是原本所要辦理的法事嗎？說戒白文第四句說「和合說戒」，也是事本。受戒白文第四句說「僧與某甲受具」，也是事本。事本的義理是共通的，而受戒、說戒的文詞則各自不同。

【475-0024】03_業疏/07b_卷二之一#66
【原文】第四句中初總示。據義唯單，或有雙者，結集翻傳治文不淨。「何」下次別列，後二句結示通局
【譯文】在第四句中，起初作總體指示。依據義理原本只有單牒，若有雙牒的情況，那是結集與翻譯流傳時文字整理不夠精當。自「何」字以下接著逐一列舉，最後兩句總結顯示通與局。

【475-0027】03_業疏/07b_卷二之一#69
【原文】羯磨之辭，亦同斯舉：「大德僧聽」、「誰諸長老忍僧」、「忍者默然，不忍者便說」、「僧已忍作某竟」，此字已前，文義皆通。中牒緣本，義通文局。「僧忍默」下，文義亦通。通據白二、白四兩羯磨也
