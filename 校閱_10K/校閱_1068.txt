# 校閱材料　第1068檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1068-0001】資持記/06a_中一上#59
【原文】故但出二法，即六夜出罪也。引正量中。指同釋別，尋文可見。三偷蘭聚，《善見》中，初翻名。障善道者，即罪之力用也；下翻罪，惡過者，就罪之當體也。後下，釋義。惡能障善，從業為名。〔古云調達破僧，令法輪不轉，名障善者，一暗文相，二成局狹。〕從下，出所以。又下，出異名。《聲論》。
【譯文】所以論中只提出兩項法軌，也就是六夜摩那埵與出罪羯磨。引用正量部的文獻中，指明相同之處、解釋相異之處，循著文字便可看出。第三「偷蘭遮聚」，在《善見律毘婆沙》中，首先翻譯名稱。「障礙善道」，是指這項罪過所產生的破壞力用；下文翻譯為罪、「粗重的過患」，是依據罪過的當下體質而言。從「後下」開始，解釋其義理。惡業能夠障礙善法，這是依循業用來立名。（古人說調達破壞僧團，使得法輪無法轉動，名為障善，這是一者昧於文字相貌，二者使得義理變得偏頗狹隘。）從「從下」開始，說明立名的因由。從「又下」開始，指出異名。引《聲論》。

【1068-0002】資持記/06a_中一上#60
【原文】但出梵名而不翻者，與上同故。《波離問經》云：吐羅遮者，邊國語也。〔舊記云：彼論具云薩偷蘭祇僧，此翻麁罪，未見本論，不知何出。〕《了論》中，初總翻名。次別釋，初釋麁義。重方便者，同上《善見》；斷善根者，謂成逆也。次釋過義，先約法釋。如下，以喻顯。援謂援護，即籬圍也。
【譯文】論中只列出梵名而不翻譯，是因為與上面的解釋相同。《優波離問經》說：吐羅遮，是邊緣國家的方言。（舊注說：那部論完整說為「薩偷蘭祇僧」，這裡翻譯為粗罪，但我未曾見過本論，不知道出自何處。）在《戒了論》中，首先總體翻譯名稱。其次分別解釋，首先解釋「粗」的含義。「重的方便罪」，與前述《善見論》相同；「斷除善根」，是指造作了五逆重罪。其次解釋「過失」的含義，先依照法義解釋。從「如下」開始，用譬喻顯發。所謂「援」，就是援護周全，也就是籬笆圍牆。

【1068-0003】資持記/06a_中一上#61
【原文】然下，簡通別，上句示通。以餘諸罪，竝是不依佛戒，故云通也。此下，明局。問：初二篇罪，吉羅最初，那推蘭耶？答：若三方便次第相成，吉但成蘭，蘭方成重，故蘭為初；又復吉通諸聚，蘭局二篇，去通就局，故言初矣。前後中，初標。云罪通等者，示雜相也。律列上下，明不定也。
【譯文】從「然下」開始，揀擇通相與局限，上一句指出通相。因為其餘一切罪過，全都屬於不依循佛陀戒律所致，所以說是「通」。從「此下」開始，闡明局限的專相。問：第一篇與第二篇的罪，突吉羅是最初生起的，為什麼反而把偷蘭遮推為最初？答：若是三種方便罪依次第互相促成，突吉羅只促成了偷蘭遮，偷蘭遮才能促成根本重罪，所以偷蘭遮是直接的前階；再者突吉羅通貫所有罪聚，偷蘭遮則局限於前兩篇根本罪，捨棄通相而著眼局限的專相，所以說偷蘭遮為前方便之首。在前後順序之中，起初先標明。所謂「罪過通於」等語，是展示交雜的相貌。律典中將其列在上位或下列，說明其位次本不定。

【1068-0004】資持記/06a_中一上#62
【原文】抑是語助。別釋中，初科，正明中。通約篇聚，大分為二；初二兩篇，過相麁重，多是止離，故名戒分；提罪已下，多制衣藥，身口乖違，號威儀分；約此二分，以釋列次。初明前列。遠近方便者，且順《十誦》二罪為言；約前所立，遠應云次，初篇具二；次篇唯近，遠在下收。
【譯文】「抑」字只是一個語助詞。在各別解釋中，第一科判，在正式闡明中。通體對照篇聚，大體劃分為兩部分：第一篇與第二篇，過失相貌粗暴深重，多數屬於必須停止遠離的性戒，所以稱為「戒分」；波逸提罪以下，多數是規範衣物、醫藥等事，屬於身口行為的違逆，稱為「威儀分」；依照這兩部分，來解釋排列的次序。首先說明排列在前的情況。所謂「遠方便與近方便」，是暫且順隨《十誦律》的兩種罪來說；若依據前文所立的三方便，遠方便應當稱為「次方便」，第一篇兼具這兩種；第二篇則只有近方便，其遠方便則歸於下方收攝。

【1068-0005】資持記/06a_中一上#63
【原文】獨頭即果罪，名簡從生。或下明在後。裸身用髮，皆同外道，竝制犯蘭。釋戒儀中，初二句總示。通下，別釋，先釋通者。即律戒緣，佛竝訶云：汝所為非，非威儀；又云：如此癡人，多種有漏，最初犯戒。戒戒皆爾，故知一切竝兼二名；以上篇重戒，亦是乖儀；下聚威儀，無非禁惡故也。若下，釋別。
【譯文】所謂「獨頭」，就是直接構成的果罪，名目是揀別於從根本罪所衍生出來的。從「或下」開始，說明排列在後面的情況。裸露身體、使用頭髮編織，都與外道同流，所以律中皆制定犯偷蘭遮罪。在解釋「戒」與「威儀」時，前兩句是總體提示。從「通下」開始，分別解釋，先解釋通義。也就是律中每條戒的起緣，佛陀都會訶責說：你所做的是非法的，不合威儀；又說：這樣的愚癡之人，種下多種有漏惡因，是最初犯戒的人。每一條戒都是如此，因此可知一切戒罪都兼具這兩種名稱；因為上篇的重戒，本質也是違背了威儀；下聚的威儀過失，無非也是屬於禁斷惡行。從「若下」開始，解釋局部的專稱。

【1068-0006】資持記/06a_中一上#64
【原文】如上所分，正從別也。均雜分中。止明在下之意。初分前後。然下，示次第。問：雖通上下，止出一名；即應前不收輕，後不攝重？答：隨列前後，竝收三品；但在前從重，輕者同歸；在後從輕，上下齊攝。問：下云五篇，義具三均；今言四是均者？
【譯文】正如上面所劃分的，正是依從其局部的專門特質。在純一與參雜的劃分中，只是說明置於下位的用意。首先區分前面與後面。從「然下」開始，揭示先後次第。問：雖然貫通於上篇與下篇，但經文只標出一個名稱；豈不是前文就不能收攝輕罪，後文就不能統攝重罪嗎？答：無論是排列在前面還是後面，全都通攝三品罪過；只是排列在前面時依從重罪立名，輕罪便一同歸納進來；排列在後面時依從輕罪立名，重罪與輕罪統統都能包含。問：後文說五篇在義理上具足三種平等；如今卻說只有前四篇是平等的，這該如何解釋？


【1068-0007】資持記/06b_中一上#1
【原文】答：準《戒疏》說，且取吉羅果罪，以應五篇五犯之數；究理而論，吉須在雜，故唯四耳。問：獨頭蘭有方便不？答：文雖不明，義同下聚，立二方便。四波逸提，翻名中。燒煮，是酷罰之事；覆障，即處所之相，乃地獄通號。或可燒煮收八熱，覆障總八寒。準下《了疏》，墮大叫喚獄；
【譯文】回答：依照《戒疏》的說法，暫且取突吉羅的究竟果罪，來湊足五篇對應五種犯戒的數目；但若深入究理而論，突吉羅必須收在雜罪（即聚）中，因此嚴格來說只有四篇而已。問：單獨發生的偷蘭遮罪有沒有方便罪？答：經文雖然沒有明確說明，但義理與下層的罪聚相同，應當立兩種方便罪。在第四「波逸提」翻譯名稱的段落中。所謂「燒煮」，是指嚴酷刑罰的具體情形；「覆障」，則是受刑處所的狀態，這兩者都是地獄的通稱。或者也可以說，燒煮總括了八熱地獄，覆障總括了八寒地獄。依照下文《了疏》所說，犯此罪者墮入大叫喚地獄；

【1068-0008】資持記/06b_中一上#2
【原文】《心論》，墮眾合獄一晝夜，所出不同耳。次科，初示總數。分下，明離合，前約事明離。因財故貪，違教故慢。若下，據罪明合。僧尼中，初示數。三十者，明捨墮全同。餘下，示單提同別。尼總有百七十八，九十對之，共有七十四戒；
【譯文】《心論》則說墮入眾合地獄一晝夜，各典籍所載的處所不同罷了。下一科，首先標示總數。從「分」字往下的文段，旨在說明戒條數目的分合，前面是依據所涉的事相來說明分開的緣由。因為財物而生起貪心，因為違背教誡而生起傲慢。從「若」字往下的文段，則是依據罪名體性來說明合併為一。在比丘與比丘尼戒的比較中，首先標示總數。「三十」這項，說明捨墮罪的數目在男女二眾完全相同。從「餘」字往下的文段，標示單墮罪在男女二眾中的相同與相異之處。尼戒總共有百七十八條單墮，比丘的九十條單墮與之相對照，共有七十四條是雙方相同的；
