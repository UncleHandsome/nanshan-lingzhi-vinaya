# 存疑裁判材料：02_戒疏（r3 批）

## 裁判提示詞（全文）

```text
你是南山律典譯文的資深校勘者。下面每條有一個「疑點」，是前一位校閱者不確定、暫時擱下的問題。

請對每一條給出明確結論，不要含糊：
1. 讀原文與譯文，判斷疑點成立不成立。
2. 結論只有三種：
   - 是錯：指出錯在哪，並給整段替換文字。
   - 不是錯：說明為什麼原文支持現行譯法。
   - 材料不足：指出缺什麼，不要猜。

輸出格式（每條一段）：
### <段號>｜是錯
判斷：…
建議：（整段替換文字，其餘與現譯逐字相同）

### <段號>｜不是錯
判斷：…

### <段號>｜材料不足
判斷：需查…，現有材料無法判定。

規則：
- 「是錯」才給建議，且必須是完整段落。
- 不要硬判；材料不足就寫材料不足。
- 不要改原文、不要合併段落、不要加譯者按語。
```

## 材料開始

# r3 存疑：02_戒疏（resp 299–323）

> 逐條判定為「存疑」者，現行譯文均未改動，待覆核古注後定。

- **302**：僧殘釋義、急施衣、奪衣
- **314**：後輪/二輪、文同廣引
- **324**：0002「即如經律傳梵訛僻是也」兩讀（所傳梵文有訛／相傳為梵者實多胡語訛僻），現譯「轉輾傳譯梵文所產生」可通，未改
- **326**：0008 古五刑「墨、劓、宮、割、刖」之「割」所指未詳（或謂截耳），現譯「截耳」屬推測，未改
- **327**：0001 記文同釋此五刑，「割」亦作「削去耳朵」，與 326 同一存疑；「奏法→秦法」校注體例未統一
- **337**：0004「縱是佛說…豈妄承奉」與 0005 記文「雖非究竟，義須承奉」正反兩讀（承奉與否），現譯一從記文，未改

## r3 401-437（本次）

- **406-0009**：【記】「故知是難」現譯「所以可知這種說法極難成立」。此科記文判為「他難」，下接「有人解云」曲救，故四字亦可能是疏主結語「故知（此）是他家之責難」；兩讀皆通，暫不改。
- **435-0007**：科判「六錯誤／七剋漫」與後文釋文先後互置，待核疏後文再定；現譯僅存按語，未改門次。
