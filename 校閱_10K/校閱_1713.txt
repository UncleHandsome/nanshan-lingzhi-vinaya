# 校閱材料　第1713檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1713-0001】03_業疏/11a_卷二之五#14
【原文】三中，初示道行。以偈文未顯，故特徵示用開心路。一切之言，通收善惡塵境；染惡則增業，染善則成障；能於日用所行所學，觸境無染，無染之智即是般若，背塵合覺、絕縛入道必始於此，深可體究，慎勿誦文。「良下」反釋所以，又三：初、示染本。封著是貪愛，此彼得失即分別；由斯二種，輪迴不息；能離此者，即名道行，非別有道，故下云「道在虗通，達累為本」是也。「故下」次舉世情。財收八穢，色乃荒婬，名謂虗聲，見即妄執；上二常流所著，故為鈍；下二學者所求，故為利；此且一往分之，然有具四或復互輕，不必一定；尠，猶無也。「終下」重誡。凡在同徒，用斯自照，有一于是，未脫輪迴。且聽教參玄，為人軌範，反乃積財荒色、諍見沽名，跡混世塵，不思出要，形出心沒，何所利乎
【譯文】第三科中，首先開示修道之行。由於偈頌文義尚未完全顯露，所以特別徵問開示用以啟發修心之路。「一切」這個詞，通攝善與惡的各種塵境；若染著惡法就會增長罪業，若染著善法就會成為證道障礙；若能在日常所行所學之中，接觸境界而無所染著，這無所染著的智慧就是般若，背離塵勞契合覺性、斷絕束縛趣入道果必定從這裡開始，極為值得深切體認探究，切不可只是口頭念誦文句。「良下」反過來解釋其中的原因，又分為三點：第一、指出染著的根本。封固執著就是貪愛，此彼得失就是妄想分別；由於這兩種執著，使人在輪迴中流轉不息；能夠遠離這些，就稱為修道之行，並不是離開這些另有玄妙之道，所以下文說「道在於虛明通達，通達並解脫牽累才是根本」，就是這個意思。「故下」接著列舉世俗常情。財物收納了八種不淨之物（八穢），色情則是荒淫無度，名是指虛浮的名聲，見就是妄加執取的知見；前面兩者（財、色）是凡夫常流所執著的，所以屬於鈍根；後面兩者（名、見）是修學之士所追求的，所以屬於利根；這姑且是依大致情況來劃分，但有的人四者俱備，或者互相有輕重不同，並不一定局限；「尠」，就如同「無」的意思。「終下」重新加以痛切勸誡。凡是身在同參道友之列的人，應當以此反照自身，若有其中一項存在，就尚未能脫離生死輪迴。況且聽聞教理、參究玄義，身為他人的模範榜樣，反而積聚錢財、荒淫著色、爭執見解、沽名釣譽，行跡混雜於世俗塵勞之中，不思求出離的要道，身雖出家而心沉世網，這樣究竟有何益處呢？

【原文】橫約諸有，無思離染，故樹出家樂處閑靜；若有貪著，終成金鎖；引出方便，唯斯一道
【譯文】就三界二十五有的一切眾生而言，無人思求遠離染著，所以建立出家之法，令人樂於處在幽閒清靜之中；如果對此閒靜仍有貪戀執著，最終這閒靜也會成為黃金的枷鎖；引導眾生出離世間的善巧方便，唯有出家這一條坦途大道。

【1713-0004】03_業疏/11a_卷二之五#17
【原文】第二門釋中初科，初示立意。約，謂約絕。「若下」次遣滯著，謂不知方便，住於閑靜，故以金鎖以喻法縛。「引下」三點權道
【譯文】第二門解釋中的第一科，首先指明立意。「約」，是指約束隔絕。「若下」接著破除沉滯貪著，是指不知道這是過渡的方便，反而執著停留在閒靜之中，所以用金鎖來比喻被法執所繫縛。「引下」第三點明方便權宜之道。

【1713-0005】03_業疏/11a_卷二之五#18
【原文】如華手經：有四法轉身，即在善來比丘蓮華化生，現增壽命。一者、自樂出家，亦勸助人令欣出家；二、求法無倦，亦勸他人；三、自行和忍，亦勸他行；四、習行方便，深發大願，隨有功利，至時付引
【譯文】正如《華手經》說：有四種法門能夠轉變來世的身報，也就是能轉生為善來比丘、於蓮花中化生，並且在現世增長壽命。第一、自己樂於出家，也勸勉助成他人令其欣求出家；第二、勤求佛法不知疲倦，也以此勸勉他人；第三、自己奉行和睦忍辱，也勸勉他人奉行；第四、修習推行善巧方便，深切發起廣大誓願，隨其所具有的功德利益，到機緣成熟時引導並付囑於他人。

【1713-0006】03_業疏/11a_卷二之五#19
【原文】次科華手經，轉身即生報也。善來比丘，謂值佛得戒者。蓮華化生，即生佛淨土者。現增壽命，即現報也。下列四法：前三並自行勸他，後一即化他行願；正取初法，餘三連引。「隨下」囑令廣述。引付，謂引以付他
【譯文】第二科《華手經》，「轉身」就是指來世的生報。「善來比丘」，是指值遇佛陀而得受戒之人。「蓮華化生」，就是往生佛陀淨土之人。「現增壽命」，就是指現世的果報。下面列出四種法門：前三項都是既自己奉行又勸導他人，最後一項則是化導他人的願行；這裡正要取用的是第一法，其餘三法是連帶引用的。「隨下」是囑咐應當廣為宣述。「引付」，是指引導並付囑傳給他人。

【1713-0007】03_業疏/11a_卷二之五#20
【原文】又如出家功德經：若能放人出家受戒，功德無邊。譬如四天下滿中羅漢，百年供養，不如有人為涅槃故，於一日夜出家受戒。謂猶前施雖多有竭，是欲界繫；為法出家，非三界業，故說過前。又云：縱起寶塔至忉利天，亦劣出家功德者。一時欣出，雖未可數，然其積微，是高勝本。前供無學，功德未多；後以供佛，情謂大勝；然終事供，淪歷下地，判非靜業，何有相勝
【譯文】又如《出家功德經》說：若能放任許可他人出家受戒，所獲功德無量無邊。好比四大天下之中遍滿了阿羅漢，以飲食供養他們百年之久，還不如有人為了證得涅槃的緣故，在一日一夜之中出家受戒。這是因為前者的布施功德雖然極多但終有窮竭之時，仍屬於欲界所繫縛；而為了求法而出家，則不屬於三界的有漏業，所以說超過前者。經中又說：縱使建造寶塔高達忉利天，其功德也比不上出家的功德。一時間欣求出家，其時間雖然微不足道，然而積聚微小之因，正是成就崇高殊勝果報的根本。前面供養阿羅漢無學聖人，功德尚且算不上最多；後面建造寶塔以供養佛陀，常情往往自認為極其殊勝；然而這終究只是事相上的供養，仍流轉沉淪於欲界下地，判定並非出離的清淨之業，又哪裡談得上勝過出家呢？

【1713-0008】03_業疏/11a_卷二之五#21
【原文】次功德經，初歎德。「譬下」次引喻，有二：初、供聖喻。前引經；「謂下」出意。有漏有竭，無漏無窮，優劣可見。「又下」二、寶塔喻。前引經。忉利天在須彌頂。「一下」示意，初明勝劣。「前下」顯重喻。佛僧雖異，事供不殊，二皆非勝；下地即欲界，靜業即禪定，尚非上二界之定業，況無漏聖業乎
【譯文】第二科《出家功德經》，首先讚歎功德。「譬下」接著引用比喻，分為兩項：第一、供養聖人的比喻。前半段引用經文；「謂下」說明其用意。有漏的功德終有窮盡，無漏的功德無窮無盡，優劣高下顯而易見。「又下」第二、建造寶塔的比喻。前半段引用經文。忉利天位居須彌山頂。「一下」說明其用意，先說明勝劣。「前下」彰顯更進一步的比喻。佛陀與僧眾雖然有別，但事相上的供養並無不同，兩者都算不上最殊勝；下地就是指欲界，靜業是指禪定，事相供養尚且不是色界、無色界的禪定業，又何況能比得上無漏解脫的聖業呢？

【1713-0010】03_業疏/11a_卷二之五#23
【原文】智論彼引蓮華色比丘尼本生經云：佛在世時，此尼得羅漢果。後化諸婦人出家，女云：「我等持戒為難，恐破戒墮獄。」尼云：「墮者從墮，久有出期。我昔曾為戲女，因著袈裟，至迦葉佛時乃得出家；由破戒故墮獄，今值釋迦佛，却得出家解脫。」以此證知，若都不出家，寧獲聖果？下指如鈔，即沙彌篇
【譯文】《大智度論》在那裡引用《蓮華色比丘尼本生經》說：佛在世時，這位比丘尼證得了阿羅漢果。後來她教化許多婦女出家，女人們說：「我們持守戒律太難了，恐怕會破戒墮入地獄。」比丘尼說：「就算墮入地獄就由它墮入，長久之後終究有出離之期。我過去曾做過歌舞戲女，因為戲穿袈裟的緣故，到了迦葉佛時才得以出家；後來由於破戒的緣故墮入地獄，如今遇到釋迦牟尼佛，反而得以出家獲得解脫。」由此可以證知，如果根本不出家，又怎能獲得聖果？下文所指的「如鈔」，也就是指《行事鈔》的〈沙彌別行篇〉。

【1713-0011】03_業疏/11a_卷二之五#24
【原文】三、障出有損者
【譯文】第三門、說明障礙他人出家會招致損害。
