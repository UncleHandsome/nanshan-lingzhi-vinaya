# 校閱材料　第241檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【241-0002】01_行事鈔/11a_卷下之三#23
【原文】僧像致敬篇第二十二
【譯文】僧像致敬篇第二十二

【241-0003】01_行事鈔/11a_卷下之三#24
【原文】法軌被時，景仰斯立。謙恭斂敬，俗禮命章；遜恪攝儀，道宗爰始。豈以形服標異，而得倨慢無知；良由致敬有方，故能清革耳！故《增一》云：有慚愧二法住世，則相恭敬。是故比丘，當勤共學。比時移情淡，禮義云亡。鄙末之小僧，妄參眾首；眉壽之大德，奄就下行；以武力為智能，指文華為英彥。如斯冐罔，孰可言哉？故輒略提引，永成明誡。
【譯文】正法的軌範加被於世間，景仰崇奉的道風由此樹立。謙遜恭敬、收斂肅敬，是世俗禮法開篇之大綱；謙抑嚴謹、檢點威儀，則是出家釋道之宗本發端。豈能因為出家形貌服飾與俗人有異，便可傲慢無禮、愚昧無知；這實在是由於表達敬意有其正則規矩，才能澄清流弊、革除陋習啊！所以《增一阿含經》說：世間只要有「慚」與「愧」這二種善法住世，人與人之間就會互相恭敬。因此諸位比丘，應當勤勉共同學習此道。近來時風遷移、道情淡薄，禮義綱常蕩然無存。鄙陋末學之年幼小僧，狂妄地列席僧團上首；白眉高壽之尊宿大德，反倒屈居於下行末座；有人把武斷強梁視為才智能力，將浮華虛文指為俊秀英才。像這般淆亂顛倒、冒昧非禮的怪相，哪裡說得盡呢？因此特地略加提點引導，永遠作為僧界的明訓警戒。

【241-0004】01_行事鈔/11a_卷下之三#25
【原文】就中分二，如題所明。
【譯文】本篇分為兩部分，正如篇題所標明。

【241-0005】01_行事鈔/11a_卷下之三#26
【原文】初中，分三：一制相敬意。二對敬立緣，合不兩相。三立敬儀式。
【譯文】第一部分中分為三項：一是制定相互致敬的本意；二是面對所敬之境建立因緣，辨析應當與不應當致敬的兩方面相貌；三是確立致敬的威儀法度。

【241-0006】01_行事鈔/11a_卷下之三#27
【原文】初中，《智論》云：諸佛不以生身為禮敬也；若見法身，是名供養。如佛從忉利天下，須菩提在石窟中觀無常空故，為先見佛；蓮華色尼寶階先禮，佛不受之。所以相敬者，為除慢法故。《四分》中：由諸比丘不知大小故，佛訶責已，告言：汝謂誰應受第一座，第一水，第一食，乃至起迎逆禮拜，恭敬問訊耶？諸比丘言各不定，或云十二頭陀者，大姓、多聞、法師、持律、禪師等。佛言：汝等各各長慢，故作是語。廣說三鳥獸相恭敬法。便說偈言：「其敬長老者，是人能護法，現世有名譽，將來生善道。」教化人民，皆隨法訓。汝等於我法律中出家，更相恭敬，佛法可得流布。自今已去，聽隨長幼，恭敬禮拜上座，迎逆問訊。《大悲》云：佛過去時，若見三寶、舍利、塔像、師僧、父母、兄弟、姊妹、耆年、善友、外道、諸仙、沙門、婆羅門等，無不傾側，謙下禮敬；以是報故，成佛已來，山林人畜見佛行時，無不傾側，低頭禮拜。《增一》云：無恭敬心於佛者，當生龍蛇中；以過去從中來，今猶無敬、多睡等。《雜含》云：告諸比丘，若見四眾，攝持諸根，長夜安樂等。《智論》云：外道是他法，故輕佛，來至佛所自坐；白衣如客，故命坐；一切出家五眾，身心屬佛，故立；若得道羅漢，如舍利弗等，皆坐；三道以下，並不聽坐，以所作未辦，結賊未破故。又云：釋迦牟尼佛，無別菩薩僧故，文殊師利、彌勒等，入聲聞僧中，次第而坐云云。
【譯文】在第一項中，《大智度論》說：諸佛並不以血肉之生身為禮敬的對象；唯有徹見法身，才稱得上是真正的供養。就像當年佛陀從忉利天降下人間，須菩提在石窟中觀照無常空性，因此成了最先見到佛陀法身的人；而蓮華色比丘尼搶先在寶階旁禮拜佛陀生身，佛陀卻未加肯定。之所以制定相互禮敬，是為了破除我慢煩惱的緣故。《四分律》中記載：因為諸位比丘不懂得戒臘大小尊卑的次序，佛陀斥責之後，問道：「你們認為誰應當受用第一席座、第一盞洗手漱口水、第一份飲食，乃至誰應受起身迎接、頂禮拜伏、恭敬問訊呢？」諸比丘各說各話，有的說是行十二頭陀行者，有的說是名門望族大姓出身者、多聞者、法師、持律師或禪師等。佛陀說：「你們每個人都滋長傲慢心，才會說出這些話。」佛陀隨後廣說鷓鴣、猴子與大象三隻動物互相推讓恭敬的因緣故事，並說偈言道：「其敬長老者，是人能護法，現世有名譽，將來生善道。」佛陀訓勉化導世人，皆應依循正法戒規。你們在我的正法與戒律之中出家，更應互相恭敬，正法才能廣泛流通傳播。從今以後，准許依照出家戒臘長幼之序，恭敬禮拜上座，起立迎接、致意問訊。《大悲經》說：佛陀在過去生修行時，若是遇見三寶、舍利、塔廟形像、師僧、父母、兄弟、姊妹、耆宿尊長、良朋善友，乃至外道、諸仙、沙門、婆羅門等，無不俯身側立、謙遜卑下地予以禮敬；以此善業果報，自從成佛以來，山林草木乃至世人牲畜見到佛陀走過時，無不俯身傾側、低頭恭敬禮拜。《增一阿含經》說：對佛陀毫無恭敬心的人，來世將轉生於龍蛇之類畜生中；這是因為他過去生原本就是從龍蛇投生而來，習氣未除，今日依舊毫無敬意且貪愛多睡等。《雜阿含經》中：佛陀告誡諸位比丘，如果見到出家在家四眾弟子，應當攝受收斂六根根門，如此能在漫漫長夜（生死輪迴）中獲致安隱快樂等。《大智度論》說：外道修習的是異端之法，所以輕視佛陀，來到佛陀處所就自顧自坐下；在家白衣如同訪客，所以佛陀招呼其就坐；所有出家五眾，身心皆歸屬於佛陀，所以應當侍立；若是證道的大阿羅漢，如舍利弗尊者等人，都可以就坐；三道（即須陀洹、斯陀含、阿那含三果）聖賢及凡夫僧，一概不准就坐，因為所作尚未成辦、煩惱盜賊尚未除盡的緣故。該論又說：釋迦牟尼佛的教法中沒有另外獨立劃分的菩薩僧團，因此文殊師利菩薩、彌勒菩薩等，都編入聲聞僧團之中，依照戒臘次序而坐，等等。
