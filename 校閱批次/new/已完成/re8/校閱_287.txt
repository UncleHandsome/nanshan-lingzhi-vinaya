# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【287-0004】02_戒疏/15a_卷三下之三#140
【原文】【記】次難中。以浣衣戒偏制尼故。答中。尼浣有二：一、僧喜為，二、妨尼道業。「俗反此」者，反上二義。「不」下，遮難。難云：「使浣無過，遣織何制耶？」以文通之。
【譯文】【記文】在第二個詰難之中。因為洗衣戒偏偏是針對比丘尼而制定的緣故。回答中說明：令比丘尼洗衣有兩重弊病：第一是大僧動輒喜歡支使，第二是妨礙了比丘尼的道業。「俗人相反」的意思，是指反過來沒有上述兩項弊病。「不同於」以下，是化解詰難。詰難的意思是：「如果使喚俗人洗衣沒有罪過，差遣俗人織布為什麼要制戒呢？」以此文理來予以融會貫通。

【287-0019】02_戒疏/15b_卷三下之三#3
【原文】【疏】犯緣有六：一、非親辦縷遣織，緣起戒本雖無，下開「親非犯」故；二、本期有限；三、知有限；四、勸好增價；五、為增縷；六、領受，犯。
【譯文】【疏文】構成違犯的因緣共有六項：第一、由非親屬的施主準備絲線並差遣織師，雖然最初制戒的緣起戒本中未明寫此條，但因下文開許「若是親屬則不犯」，故知此為條件；第二、施主原本預定的工料數量有限；第三、比丘明知施主所定有限；第四、勸請織師織得更好並許諾增加工資；第五、織師確實為此增加了絲線；第六、比丘領納受取，即結成正罪。

【287-0020】02_戒疏/15b_卷三下之三#4
【原文】【記】犯緣。第一，準下開通，以決戒本。一與二即屬施主，五屬織師，餘並比丘。
【譯文】【記文】犯戒因緣。第一項是準照後文的開許條文，用來判定戒本的定義。第一與第二項屬於施主的條件，第五項屬於織師的行為，其餘各項皆屬於比丘本身的犯相。

【287-0021】02_戒疏/15b_卷三下之三#5
【原文】【疏】《多論》，前戒憑勢遣織，作成即犯；此戒自求，領受便結。
【譯文】【疏文】《薩婆多論》提到：前一戒是仗憑權勢差遣織師，織好之時就結犯；本戒則是比丘私自向織師索求，直到親自領受衣物時才結罪。

【287-0022】02_戒疏/15b_卷三下之三#6
【原文】【記】次對簡中。前是己物，故約「作成」；此由他施，故須「領受」。
【譯文】【記文】接著在兩戒的對比簡別中。前一戒是由於用了自己的絲線物料，所以依「織成」來定罪；本戒是由於他人布施，所以必須等到「領受」才結罪。

【287-0023】02_戒疏/15b_卷三下之三#7
【原文】【疏】問：「此戒損縷，與前一、二居士何異？」
【譯文】【疏文】有人問：「這條戒損耗了施主的絲線，與前面第一、第二位居士那兩條戒有什麼不同？」

【287-0024】02_戒疏/15b_卷三下之三#8
【原文】【疏】答：「前面對縷主，此屏勸織師，故兩制也。」
【譯文】【疏文】回答說：「前面是當面向絲線的主人索求，本戒則是背著施主私下勸請織師，所以分為兩處制定制約。」

【287-0025】02_戒疏/15b_卷三下之三#9
【原文】【記】初問。以一、二居士，亦是勸增，故須顯異。答中，可解。
【譯文】【記文】首先提問。因為向一、二位居士索求也是勸其增多，所以必須闡明兩者的差異。答語的內容淺顯易懂。

【287-0026】02_戒疏/15b_卷三下之三#10
【原文】【疏】問：「前後兩戒，皆由織師，何以取分？」
【譯文】【疏文】又問：「前後這兩條戒，都是經由織師織造，憑什麼標準來作區分？」

【287-0027】02_戒疏/15b_卷三下之三#11
【原文】【疏】答：「不同有四：一、前損織師，自得縷故，此損縷主；二、前損織師，不與價犯，此損縷主，與價便犯；三、前戒開親，後戒俱犯，損義通也；四、前是己物，織成即犯，此本屬他，要受方犯。」
【譯文】【疏文】回答說：「不同之處有四點：第一、前戒損害的是織師，因為比丘自己提供了絲線；本戒損害的是絲線的主人。第二、前戒損害織師，不給工錢才犯戒；本戒損害絲線主人，給了織師工資反而犯戒。第三、前戒開許由親屬織造不犯，後戒無論親疏全都犯戒，因為損害他人利益的實質是一樣的。第四、前戒本是自己的物料，織成之時便結犯；本戒物料原屬於他人，必須等到正式接受衣物時才結犯。」

【287-0028】02_戒疏/15b_卷三下之三#12
【原文】【記】次問。二戒不同，緣相可見，欲生料簡，故發此問。答中。第三「後戒」親、非親「俱犯」者，謂織師也。上列緣中，明簡親者，據縷主也。
【譯文】【記文】第二個提問。兩條戒律的情形不同，事緣行相顯而易見，為了進一步辨析簡別，所以提出這個問題。答語中提到第三點「後戒」無論是親是疏「全都犯戒」，指的是對織師而言；上文所列的犯緣中，明確簡別親疏的，則是就絲線主人來說的。

【287-0029】02_戒疏/15b_卷三下之三#13

【287-0038】02_戒疏/15b_卷三下之三#22
【原文】【疏】注解「自恣請」者，謂許好取惡耳，非長貪壞信而索好也。《僧祇》云「若俗家兄弟令自往營，疾成，得好」，是自恣相。
【譯文】【疏文】註文中所解釋的「自恣請」，意思是施主原本許諾給好的，自己卻選取粗劣的，並不是放縱貪心、破壞施主信心反而索取更好的。《僧祇律》說「如果俗家的兄弟讓比丘自己去督造操辦，以便早日織成、織得更好」，這便是屬於任意請託的情況。

【287-0039】02_戒疏/15b_卷三下之三#23
【原文】【記】釋注中。初牒釋。言「自恣」者，任比丘意也。「僧祇」下，引示。彼文約親，本無所犯，且欲顯示「自恣相」耳。
【譯文】【記文】解釋注文的內容。首先摘錄註文加以解釋。所謂「自恣」，就是完全聽憑比丘的心意。「僧祇」以下，引用律文來指示說明。該條文是針對親屬而言，本來就沒有犯戒的嫌疑，此處引用只是為了顯示「自恣請的行相」罷了。
