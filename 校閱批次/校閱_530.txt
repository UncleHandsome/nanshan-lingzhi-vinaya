# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】破結中。初須聞教，非自然故；二須立誓，期心在後，若非此緣，破結無戒；五見空者，空即真理
【譯文】在破結受之中。第一必須聽聞佛陀教導，因為這不是無師自悟的自然受的緣故；第二必須立下誓願，將期許受戒的心置於證果之後，若不是因為這種因緣，單純破除結惑並不會得戒；第五見空，空就是指真諦之理。

【530-0002】03_業疏/12b_卷三之一#68

【譯文】三語受的五種因緣是：第一是外形與僧相相同，律文說「剃除鬚髮、穿著袈裟」的緣故；第二是受者面對阿羅漢無學僧以及教授之法；第三是受者具有希求之心，律文說「想要前往佛陀住處」；第四是心與境相合；第五是發起戒業作法完畢。

【530-0007】03_業疏/12b_卷三之一#73

【譯文】在問答之中。善來受是面對佛陀，必定會自然轉變身形與衣服，所以必須以得道作為得戒的因緣。其餘的不這樣，是因為並非面對佛陀。破結受是證得聖果，身形衣服自然隨之轉變；其餘兩種（三語、八敬）是面對弟子（資），弟子的威德力不能讓受者轉變形服。所謂「如上說」，就是指前面師資差別那一科所說的內容。

【530-0011】03_業疏/12b_卷三之一#77
【原文】初說結不同者，善來、八敬一徧便得，以唱教人大，不假叮嚀，渴法心重，又不須結；三語之法，初受法弱，故須三說，前受心奢，又假三結；羯磨在僧，通和非易，故須四徧，眾心齊忍，與奪已決，故結一也
【譯文】第一是宣說與結告次數的不同：善來受與八敬受宣說一遍便能得戒，因為宣唱教令的人德行尊大，不須多加叮嚀囑咐，而且受者求法之心懇切渴仰，因此也不需要作結告；三語之法，起初傳授的法力較弱，所以必須宣說三次，受戒者先前的求戒之心較為寬散放逸，所以又須假藉三次結告；羯磨受是在僧團中進行，要達到全體和合通融並不容易，所以必須宣說四遍（一白三羯磨），僧眾的心意既然齊一默忍，贊同或反對已經決定，所以只結告一次。

【530-0012】03_業疏/12b_卷三之一#78
【原文】二對同異初中。善來、八敬，機教俱勝，不假叮嚀，謂不須多徧。三語初受法弱，謂能授教劣，一說難感，故至於三；前受心奢，謂所受機劣，恐有陵犯，加結囑之。羯磨四徧，一白三羯磨，以和難故，說須多也。眾既和忍，不假多結。與奪即可否。不同三語別人獨授，故須三徧。破結無法，故非所論
【譯文】在第二「相對辨別異同」的第一點中。善來受與八敬受，根機與教法都極為殊勝，不假借叮嚀囑咐，是指不需要宣說多遍。三語受起初傳授的法力較弱，是指能傳授教法的弟子威德較劣，只說一遍難以感發戒體，所以必須重複到三次；受戒者先前的發心寬散，是指受戒者的根機較劣，恐怕日後有所凌逼毀犯，所以增加結告來囑咐他。羯磨受要宣說四遍，也就是一白三羯磨，因為僧團和合困難的緣故，所以宣說必須多次。僧眾既然已經和合默忍，就不需要多次結告。所謂「與奪」，就是指同意或否決。這不同於三語受是由一位比丘單獨傳授，所以三語受必須結告三遍。破結受沒有特定的作法儀軌，所以不在此討論之列。

【530-0013】03_業疏/12b_卷三之一#79
【原文】二乞有無者，通論四受，理須前告，如今「我欲」即是其相；但羯磨者，通情稍難，若不遜請，無由牒法，故制乞也
【譯文】第二是乞求戒法的有無：普遍來說這四種受戒法，在理則上都必須在事前向師長稟白，如同經文所說的「我想要……」就是乞戒的表現；然而唯獨羯磨受，要讓全體僧眾的心意通達和諧稍有困難，如果受戒者不謙遜地請求，僧團就無從引據法度來為他作羯磨，所以制定了乞戒的儀式。

【530-0014】03_業疏/12b_卷三之一#80
【原文】二中。初通明四受，亦除破結，既不對人，故無從乞。如今「我欲」，「今」合作「文」，即前善來文云「我欲於如來法中」等，即是求乞。三語、八敬並如上引。「但」下別顯羯磨。稍，猶漸也
【譯文】在第二點之中。開頭先普遍說明四種受戒法，這也是除去了破結受，破結受既然不對著人受戒，所以沒有地方可以乞求。如經文說「我欲」，原文中的「今」字應當作「文」字，也就是前面善來受的律文說「我想要在如來正法之中」等語，這就是乞求。三語受與八敬受也都如同上面所引用的律文。「但」字以下個別彰顯羯磨受的特殊性。「稍」，意思如同漸漸、稍顯。

【530-0015】03_業疏/12b_卷三之一#81
【原文】三立名相者，初皆無相，羯磨約緣。由前三受內凡已上，羯磨具縛，有犯性重，故制相也。五、八、十戒，或對俗化儀，或是羯磨犯後，故十戒中列和上名，明知非制前也
【譯文】第三是安立戒相名稱：起初各種受戒法都沒有宣說具體的戒相，只有羯磨受是依事緣而宣說戒相。因為前面的三種受戒法（善來、三語、八敬）都是內凡位以上的人受持，羯磨受則是具足煩惱繫縛的凡夫所受，可能毀犯自性重罪，所以才制定宣說戒相。至於五戒、八戒、十戒，有些是針對在俗信眾的教化儀軌，有些則是在羯磨受戒有人犯戒之後才制定的，所以在傳授十戒時列出和尚的名字，由此明顯可知並不是在羯磨受之前制定的。

【530-0016】03_業疏/12b_卷三之一#82
【原文】三立名相。名謂受名，相即戒相。初二句略示，上句通舉四受，羯磨受法初亦無相；下句別點羯磨後因犯重方制說相，緣即緣起。「由」下委釋所以。初明三受無相，內凡初果少犯性重，破結無犯，故不在言；「羯」下次明羯磨有相，雖通上聖，正為凡下，故云「具縛」等。「五」下因決餘戒立相之意。對俗化儀謂五、八也；羯磨犯後謂十戒也。由羯磨法制依和尚，故準十戒作法詞中牒和尚名，可驗在後，義見次科
【譯文】在第三「安立名相」中。名是指受戒的名稱，相就是戒相。開頭兩句簡略標示，上一句普遍舉出四種受戒法，羯磨受法在最初也是沒有宣說戒相的；下一句特別指出羯磨受後來是因為有人犯了重戒才制定宣說戒相，所謂「緣」就是指犯戒的緣起。「由」字以下詳細解釋其緣由。首先說明三種受戒法沒有宣說戒相，是因為內凡與初果聖人很少會犯自性重罪，破結受的阿羅漢根本不會犯戒，所以更不用說了；「羯」字以下接著說明羯磨受有宣說戒相，雖然也通於上乘聖人，但主要是為了凡夫下劣之人，所以說「具縛」等。「五」字以下順帶斷定其餘戒法安立戒相的用意。針對在俗的教化儀軌是指五戒、八戒；羯磨受犯戒之後才制定是指十戒。因為羯磨法制定了必須依止和尚，所以比照十戒作法詞中必須稱提和尚名字這一點，可以驗知十戒是在羯磨受之後才制定的，其義理見於下一科。

【原文】三校量約緣中。初明勝劣，四義分之：初約自他，次約師資，三約兼獨，四約聖凡，從寬至狹，對之可見。「癈」下二明無勝劣。以上四位並據能授人分，若論所授，無非具戒

【530-0024】03_業疏/12b_卷三之一#90
【原文】二對過有無者：善來機勝，以無四過，不無遮犯，以在制前；破結無著，但有悞犯；八敬、三語如上所被已明，如《毗曇》中煖心退作五逆斷善，故此二受應是內凡已去也；羯磨受者，如《多論》中內實凡夫，福薄感戒，欣下有羸，一過也；容退道法，二過也；容變二形，三過也；邪見斷善，四過也。餘四反此，故無災患
【譯文】第二是依有無過失來對照：善來受的根機極為殊勝，因為受者沒有四種過失，但不能說完全沒有毀犯遮戒之事，因為當時是在戒律制定之前；破結受是阿羅漢無著境界，只可能會有無心的誤犯；八敬受與三語受，如上面所說教法所覆被的人已經辨明，如《俱舍論》（阿毗曇）中所說，煖位的心可能退轉而造作五逆罪、斷絕善根，所以這兩種受戒法的人應當是內凡的忍位以上；羯磨受的人，如《薩婆多論》中所說，受戒者內心實質上是凡夫，福報微薄而感得戒體，貪著欣慕下劣世俗而使戒力羸弱，這是第一種過失；容許退失道法（捨戒），這是第二種過失；身根可能轉變為男女二形，這是第三種過失；可能生起邪見而斷絕善根，這是第四種過失。其餘四種受戒法與此相反，所以沒有這些災難患害。

【530-0025】03_業疏/12b_卷三之一#91
【原文】對過中。善來無四過，謂無「下有羸」等過。雖有犯遮，爾時未制，不論所犯。破結毒盡，無故心故。八敬、三語前引《多論》判為內凡，然內凡有四位：一煖、二頂、三忍、四世第一。《毗曇》煖心有退，則顯《多論》據忍與世第一人，故云「內凡已去」。《俱舍》亦云「忍終不斷善」，則知爾前尚有退也。凡羯磨被凡，具過可知：初謂毀犯，二即捨戒，三即根變，四即墮邪。餘四反者，即前四受。災患即四過也
【譯文】在對照過失之中。善來受沒有四種過失，是指沒有「戒力羸弱」等過失。雖然有毀犯遮戒的情況，但當時尚未制定戒條，所以不論罪犯。破結受是三毒斷盡，沒有故意造惡的心念。八敬受與三語受在前面引用《薩婆多論》判定為內凡位，然而內凡位有四種階位：第一是煖位、第二是頂位、第三是忍位、第四是世第一位。《阿毗曇》說煖位之心仍有退轉，這就顯示《薩婆多論》是依據忍位與世第一位的人而說，所以說「內凡以上」。《俱舍論》也說「證得忍位者終究不會斷絕善根」，由此可知在忍位之前的心念仍有退轉。大凡羯磨受所覆被的是凡夫，具足這些過失是顯而易知的：第一種是指毀犯戒律，第二種是指捨棄戒律，第三種是指性根轉變，第四種是指墮入邪見。其餘四種相反，就是指前面所列的四種受戒法。所謂「災患」也就是這四種過失。
