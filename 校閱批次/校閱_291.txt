# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【291-0001】02_戒疏/15b_卷三下之三#93
【原文】【記】三中。《僧祇》「豆等頭不破」者，明須清澄，破即時漿，不得飲也。下「酥、油」等，例皆如之。《善見》諸物並須清澄。「菜」、「瓜」二物，必不能清，以所除之。
【譯文】【記文】第三段。《僧祇律》說「豆類等表皮不破」，說明汁液必須清澈透明，如果破了就會煮出澱粉變成時漿，過午就不能喝了。下文的「酥、油」等，全都可以此類推。《善見律》記載各種物品都必須徹底澄淨。「蔬菜」與「瓜類」這兩種東西，汁液絕對無法做到完全澄澈，所以被排除在外。

【291-0002】02_戒疏/15b_卷三下之三#94
【原文】【疏】次明蕪濫者，如棗汁、梨漿，稠濁未分，此與時漿不別，何得非時而飲？且諸果之中，自有清汁，此是淨漿，斤有滓濁，即兼時藥。故《十誦》云：「清漿無滓，病者得飲。」既無渴病，輙飲清漿尚犯非時，何況濁者？病亦成犯。
【譯文】【疏文】接著說明混濫雜亂的情況，例如棗子汁、梨子漿，質地濃稠混濁分不清的，這與正常的時藥稠漿沒有區別，怎麼可以在過午非時飲用呢？況且各種水果當中，自然含有清澈的汁液，這才是合乎戒規的淨漿，只要稍微帶有渣滓混濁，就夾雜了時藥的成分。所以《十誦律》說：「清澈無渣的果漿，生病的人才可以喝。」既然沒有口渴之病，貿然飲用澄清果漿尚且犯了非時飲用罪，何況是濃濁的汁液呢？即使有病飲用也構成了犯戒。

【291-0003】02_戒疏/15b_卷三下之三#95
【原文】【記】次簡濫中。初示濫。「稠」，濃也。「且」下，顯相。「故」下，引證。
【譯文】【記文】第二、簡明混濫中。首先指出混濫。「稠」，是濃稠的意思。「且」字往下，顯發其相狀。「故」字往下，引用律文為證。

【291-0004】02_戒疏/15b_卷三下之三#96
【原文】【疏】京邑非時行杏人湯、茯苓末、諸美煎等，謂是開者。此無正文。《四分律》中，杏人生用，非是熟噉。故《律》正制不任食者，聽為盡形。今生用非食，熟則是食，何得因本仍為盡形，同生薑也？
【譯文】【疏文】京城裡在非時的時段通行飲用杏仁湯、茯苓粉、各種甜美煎膏等，認為這是戒律所開許的。這在律典中根本沒有正文依據。《四分律》當中，杏仁是作為生藥使用，並不是煮熟來吃的。所以《四分律》正式規定不能拿來當食物充飢的物品，才聽許作為盡形壽藥。如今生用不是正食，煮熟之後卻成了食物，哪能因為它原本的樣子就依然當作盡形壽藥，而硬要同生薑相提並論呢？

【291-0005】02_戒疏/15b_卷三下之三#97
【原文】【記】斥濫中，初科。初指非。「京邑」，即京兆。「煎」字去呼。「此」下，決破。「四分」下，釋疑。彼執《律》文，通以杏人為盡形故，今約生熟兩別以彰彼過。「《律》正制」者，《四分》云：「一切鹹、苦、辛、甘不任為食，名盡形藥體。」不同生薑，生熟皆盡形耳。
【譯文】【記文】斥責謬誤中，第一段。首先指出其錯誤。「京邑」，就是京兆長安。「煎」字讀去聲。「此」字往下，徹底駁斥破除。「四分」往下，解釋疑慮。那些人執著於《四分律》的字面，一概把杏仁當作盡形壽藥，所以如今從生吃與煮熟兩種不同情況來揭示他們的過咎。「律正制」這句話，是指《四分律》說：「一切鹹、苦、辛、甘之物，如果不適合作為正餐充飢的，稱為盡形壽藥的體質。」這與生薑不同，生薑無論生熟都純粹屬於盡形壽藥。

【291-0006】02_戒疏/15b_卷三下之三#98
【原文】【疏】故《善見》中：「諸樹木草不任為食，根、莖、華、果，得盡形藥。或俱是時藥；或果心時藥，餘者盡形。」
【譯文】【疏文】所以《善見律》中說：「各種樹木草類中不適合作為食物充飢的，其根、莖、花、果，可以作為盡形壽藥。或者全株都屬於時藥；或者果肉果心屬於時藥，其餘部位屬於盡形壽藥。」

【291-0007】02_戒疏/15b_卷三下之三#99
【原文】【記】次科，《善見》中。初通示。彼云「得盡形壽服」，文作「藥」字，寫錯。「或」下，別簡。彼具云：「有樹草木舉體時藥；有樹果心時藥，餘者盡形；有樹舉體盡形。」此證盡形不可一判也。
【譯文】【記文】第二段，《善見律》的內容。起初通論開示。該律原文說「可以終身服用」，此處疏文誤寫成了「藥」字。「或」字往下，分別簡別。該律完整說道：「有的樹木全株都是時藥；有的樹木果肉是時藥，其餘部位是盡形壽藥；有的樹木全株都是盡形壽藥。」這證明盡形壽藥不能一概而論。

【291-0008】02_戒疏/15b_卷三下之三#100
【原文】【疏】準此為例，生熟不定。或生熟俱是，如米、麥、薑、椒等；或生是時藥，熟為盡形；或生是盡形，熟為時藥，如杏人、署預、芋子、葛根。故轉變隨時，不可一定。如甘蔗一色轉通四藥，豈成石蜜，唯許時中？斯濫極多，略舉一二。
【譯文】【疏文】依此作為通例，物品的生與熟判定是不一定的。有的生熟全都是同一類，例如稻米、大麥、生薑、胡椒等；有的生時是時藥，熟了之後卻變成盡形壽藥；有的生時是盡形壽藥，煮熟之後卻變成了時藥，例如杏仁、山藥（署預）、芋頭、葛根。所以藥物的性狀轉變隨著時機而定，不可執著於固定一端。好比甘蔗這一種原料，轉變後可以通貫四種藥，難道加工製成了冰糖石蜜，就只能限定在應食的時段中吃嗎？這類的混濫情況非常多，這裡僅僅略微列舉一二罷了。

【291-0009】02_戒疏/15b_卷三下之三#101
【原文】【記】三中。初準上論，以例生熟。初句，「米、麥」俱時藥，「薑、椒」俱盡形。第二句，如米、麥、甘蔗燒灰之類。第三，列相可見，文無俱非，不可立故。「故轉變」下，顯示不定。「甘蔗通四」，如下自引，以本是時藥，若取清汁得非時服，若作石蜜得七日服，若燒作灰得終身服，故云「豈成」等。「斯」下，示略。
【譯文】【記文】第三段中。首先依照上文論述，用來類推生熟的變化。第一種情況，「稻米、大麥」生熟全都是時藥，「生薑、胡椒」生熟全都是盡形壽藥。第二種情況，例如把稻米、大麥、甘蔗燒成炭灰之類。第三種情況，列舉的行相顯而易見；文中沒有列出「生熟全非」的情況，因為根本無法成立。「故轉變」以下，顯示性狀並不固定。「甘蔗通四」，如下文自會引用，因為它本質是時藥，若榨取澄清果汁就可以在非時飲用，若熬製成石蜜就可以作為七日藥服用，若燒製成灰就可以作為終身盡形壽藥服用，所以說「難道製成石蜜」等語。「斯」字往下，表示此處僅作簡略說明。

【291-0010】02_戒疏/15b_卷三下之三#102
【原文】【疏】然口腹之累，道俗同弊。知教慎行，世中稀耳。故晉慧遠至死不飲蜜漿。非律不開，以律文親須目見，遂討尋將及，奄從物故。斯人可敘。餘固亡言。乍可非時噉飯，知非其罪可滌；不可無病飲漿，迷教終難懺蕩。故《涅槃》明罪，非有非無。良由慚愧之倚仗也。

【譯文】【疏文】第三、七日藥的體質。《四分律》中列出的五種藥，都是世間人所熟知的生活物資，所以佛陀開許比丘受持七天。《僧祇律》說：「五種藥以及動物油脂，只要清淨不帶有正餐主食的氣味，可以一次性全部受持，在七天之內服用。」《明了論》中說，是因為疾病的緣故佛陀才開許，以病情痊癒為期限，最多不超過七天。如果本來就沒有病，或者在七天期限內病已經好了，且身上又沒有飢渴之苦，那麼在過午非時服用就構成了犯罪。動物膏脂也是同樣的道理。
