# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】無德不依者依在欽重誠由行解累負人情義無歸向故雖專獨非罪緣也
【譯文】所謂「師長無德則不予依止」，依止的本意在於欽佩敬重，確實是由於師長行持與見解有虧，辜負了弟子的依賴之情，在義理上便沒有歸向投靠之處，因此此時即便獨自一人生活，也不構成結罪的因緣。

【37-0002】03_業疏/17b_卷三之六#25
【原文】無德中，初敘可依；「累」下，示不可依。若作「」上聲，則數為非義；若作去呼，則自不清白。並負弟子依賴之情。專獨非罪，謂無師時許不依止故
【譯文】在「無德」一段中，先敘述何種情形可以依止；自「累」字以下，指示何種情形不可依止。如果「累」字讀上聲（讀如「壘」），就是多次違背正理法度的意思；如果讀去聲（讀如「類」），就是指自身不清白有牽累。這些都辜負了弟子依託仰賴之情。所謂「專獨非罪」，是指在沒有具德明師之時，律中開許可以不依止的緣故。

【37-0016】03_業疏/17b_卷三之六#39
【原文】就標緣中，具列兩相。初淨心者，以女人志弱，愚教者多，隨緣造過，特由學淺，故特聖制增位勸學。男子不爾，多堪苦緣，雖為難阻，不即陵壞，故僧位中不曲制也。二淨身者，由曾出適，言歸事人，後喪從道，懷胎受戒，誕育懷挾，譏過由生，故限二年。可知染淨，是知學法為淨心，本文列盡形者是也；約制有期為淨胎，本文列二歲者是也。兩設其致，各有源矣
【譯文】在標示因緣中，具體列出了兩種相狀：第一是「淨心」，因為女人意志軟弱，昧於教理的人居多，隨逐境緣而造作過非，特別是由於學修淺薄的緣故，所以佛陀特別制定增加這一位階來勸勉修學。男子則不是如此，多數能忍受艱難苦行之緣，縱使遇到障難阻礙，也不會立即頹廢毀敗，所以在比丘僧位中沒有委曲增設此一階位。第二是「淨身」，是由於曾出嫁他人、委身事人為婦，後來丈夫亡故而修道出家，唯恐她受戒時已懷有身孕，受戒之後生產哺乳撫抱幼兒，世間的譏嫌罪過便由此產生，所以限定兩年的時間。由此可知身心是染是淨。因此可知，學習戒法是為了清淨自心，這正是本文中所列「盡形壽受持」的規定；限定特定的期限是為了查驗胎息清淨，這正是本文中所列「學法兩年」的規定。這兩種規制的設立，各自都有其根源由來。

【37-0017】03_業疏/17b_卷三之六#40
【原文】釋標中三：初標舉，「初下」次別釋。初釋淨心，前敘尼有增位，謂別立一眾勸學，即重加六法。男下，次明僧無，反尼可見。二釋淨身，適即訓往，歸猶嫁也；後喪從道，謂夫亡而出家者；誕育，謂生子；懷挾，即抱持。是下三結顯：初結淨心，引後說相，既通盡形，證知修學；約下，次結淨身，引後結法，既局二歲，顯是驗胎。各有源者，即上二本
【譯文】在解釋標題中分為三個部分：第一、標舉大綱；自「初」字以下，第二、分別解釋。首先解釋「淨心」，前面敘述比丘尼體系增設位階，是指單獨設立一眾來勸勉修學，也就是重新加受六法。自「男」字以下，接著說明僧中沒有此位階，反觀尼眾之制便可明了。其次解釋「淨身」，「適」訓解為前往，「歸」猶如出嫁；「後喪從道」，是指丈夫亡故後出家修道的人；「誕育」，是指生育孩子；「懷挾」，就是懷抱持撫。自「是」字以下，第三、結語顯明：首先總結淨心，引用後文宣說戒相，既然通貫於盡形壽，便可證知是為了修心學戒；自「約」字以下，接著總結淨身，引用後文結成教法，既然局限在兩年之內，便顯明是為了查驗身孕。所謂「各有其源」，就是指上述的這兩個根本意旨。

【37-0022】03_業疏/17b_卷三之六#45
【原文】此學法女無戒體也，但受別教，位過沙彌，如上已解，恐忘故重言之。以人不解，謂分三眾有三戒體，實同而異，但增學也。何以明耶？依六法行，無過聽受；分有所犯，更從始學。或不學法，或學不滿，或缺不行，竝名非法，為佛所訶，義無輙受
【譯文】這位學法女並沒有另外發起獨立的戒體，只是領受了個別的增上教法，其位階高於沙彌尼，正如上面已經解釋過的，唯恐後人遺忘所以再次重申。因為一般人不理解，以為既然分有三眾，就必定有三種不同的戒體；其實本體相同而形相有所差異，只是增加了修學的內容而已。憑什麼來明證這一點呢？若是依照六法行持，沒有毀犯過失，才聽許受具足戒；哪怕只有部分犯戒，就必須重新從頭開始修學。有的人根本不學六法，有的人修學期限不滿兩年，有的人戒行殘缺而不從頭學起，這些全都稱為非法，皆為佛陀所呵斥，在義理上絕不可輕率傳授具足戒。

【37-0023】03_業疏/17b_卷三之六#46
【原文】次科，初以義判，體同沙彌，無別戒體，指上解者，文見二下之首。以下斥非，實同謂體一而異，即增學。「何下」推所以，即明六法增法檢行，為受方便，義非發體。初敘如法，「或不」下明非法。或不學者，謂都不受學；不滿者，此雖曾受，年限未充；缺不行者，受已有犯，不復從始。如尼律中，並因起非，佛訶制戒，故云「為佛訶」也
【譯文】下一科中，首先依義理判定，其戒體與沙彌尼相同，並無另外單獨的戒體；指出上面已解釋之處，其文見於第二卷下半部的開頭。自「以」字以下斥責錯誤見解，「實同」是說戒體同一，而之所以「異」，即在於增廣修學。自「何以」以下推究其所以然，即是說明六法只是增加法門以檢點戒行，作為受大戒的方便前導，在義理上並非另發新戒體。首先敘述合乎教法的情形；自「或不」以下說明非法的情形。所謂「不學」，是指根本沒有受持修學；「不滿」，是指雖然曾經受法，但年限尚未圓滿；「缺不行」，是指受法之後有了毀犯，卻不再從頭開始行持。正如比丘尼律中所載，都是因為生起種種過非，佛陀才呵責並制定戒律，所以說「為佛所訶」。

【37-0025】03_業疏/17b_卷三之六#48
【原文】三辨行事，斥世中初文。初通斥，「故下」別列。年末受學，正朝進具，即以兩日以當二歲。應作四句：一、年缺行具；二、行缺年具；三、年行俱缺；四、年行俱具。忽不行者，謂慢教也
【譯文】第三、辨明如法行事，在斥責世俗弊病的初文中，首先總體斥責；自「故」字以下逐一列舉。所謂歲末受法、元旦就進受具足戒，就是把跨年的短短兩天當成了兩年。此處應當作成四句分別：第一、年限有缺而戒行具足；第二、戒行有缺而年限具足；第三、年限與戒行兩皆殘缺；第四、年限與戒行兩皆具足。所謂「忽而不行」，是指輕慢戒律教法而不切實奉行。

【37-0026】03_業疏/17b_卷三之六#49
【原文】亦有一師當白四法都盧成就謂沙彌尼六法本法及大戒也相共召之名㮯樸戒不知何出此復何論
【譯文】又有一位律師主張，應當只用一次白四羯磨就「都盧」（全部一併）成就，也就是將沙彌尼戒、六法、尼本法以及大僧具足戒合在一起受，大家共同稱呼這種戒為「㮯樸戒」（混然未分的質樸之戒）；不知這種做法出自何典，這又有什麼可論取的呢？

【37-0027】03_業疏/17b_卷三之六#50
【原文】次科，尼中四法：一、白四受，故云「都盧」，此即方俗之語，猶言一併也。「㮯」音混，「樸」音朴。彼謂但一法受，㮯成樸質，不須更分漸次多端也。「不下」正斥，上句斥無所據，下句明無可取
【譯文】下一科中，比丘尼應受的四種法：僅以一次白四羯磨而受，所以說「都盧」，這就是方言俗語，相當於說「一併、全都」。「㮯」字音讀如混，「樸」字音讀如朴。那位法師認為只要通過一種受法，混然合成質樸的全體，不需要再區分多種繁複的漸次階位。自「不知」以下正面斥責，上一句斥責其毫無經典依據，下一句說明其做法完全沒有可取之處。

【37-0029】02_戒疏/01c_卷一上之一#66
【原文】【疏】意以適緣授法，悟入為先，何有乖各輕重異見？故《論》云「牟尼大聖主，悉斷一切見」等。
【譯文】【疏文】佛陀的意旨在於順應眾生根機而傳授相應的佛法，以引導眾生證悟契入為首要目標，何曾存在相互乖違、將罪責判為輕或重的各自分歧的見解呢？所以《論》中說「牟尼世尊是大聖主，徹底斷盡了一切妄見」等。

【37-0030】02_戒疏/01c_卷一上之一#67
【原文】【記】立教中，初正明。約義祥教，故云「意以」。「緣」即是機。此明教門輕重，全自機差；佛意常融，寧存「異見」；月臨眾水，可以喻焉。「故」下，引證，未詳何論。「牟尼」此翻寂默，即釋尊名。見惑通三界，故云「一切見」。如來無明究盡，豈有妄見乎？
【譯文】【記文】在立教本旨的文段中，首先正式闡述。依據教理詳審體察教化，所以說「意以」。「緣」就是眾生的根機。這是說明教法條目判定的輕與重，完全是源於眾生根機的千差萬別；佛陀隨順施教的心意始終是圓融一貫的，哪裡會存有私己的「歧見」呢？好比一輪明月映照在眾多水面之中，即可以用此作為譬喻。「故」字以下，引用論典作為證成，尚未詳考出於哪一部論。「牟尼」此處翻譯為寂默，是釋迦牟尼佛的德號。見惑通屬於欲界、色界、無色界三界，所以稱作「一切見」。如來已將根本無明徹底斷除窮盡，怎可能還會有凡夫的妄見呢？
