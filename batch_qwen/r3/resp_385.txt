整體看下來，這批譯文水準相當穩定，術語（告淨、發露、對首、作白、八篇、三問）掌握大致到位。以下按「義理必須修正」→「用語可斟酌」→「體例一致性」分層列出。

## 一、義理有誤，建議必改

### 1. 【385-0007】「即」猶「卒」也 —— 釋義錯誤
> 譯文：「即」就像「突然間說完」的意思。

「卒」在此是**倉卒、匆促**之義（同段【385-0001】「卒難排門」的「卒」用法可參）。元照是在注解疏文「不可**即**言」的「即」字，不是解「說完」。
**建議**：「『即』，就是『卒（倉促、匆促）』的意思。」
並與【385-0006】對齊：「斯事眾矣，不可即言」→「這類事務極為繁多，**無法倉促之間說完**」（現譯「無法在當下逐一說盡」意思不遠，但與此處的訓釋要能呼應）。

### 2. 【385-0015】「唯在除犯」→「消除罪犯」 —— 用詞嚴重失真
「罪犯」在現代漢語指**犯罪的人**，與「除犯（滅除違犯之罪）」完全不同。
**建議**：「說戒的本意，只在於**除滅所犯的罪過**」。

### 3. 【385-0003】「以聞三問也」→「三度發露審問」 —— 混淆兩件事
「三問」是戒序中三度唱問「是中清淨不」，屬**審問清淨與否**；「發露」是犯者自行陳罪，兩者不同。譯作「三度發露審問」會誤導。
**建議**：「因為已經聽聞了戒序中**三次『是中清淨不』的審問**」。

### 4. 【385-0019】漏掉「指略」的語氣 —— 與下一則記文相違
> 原文：懺悔義應此處道之，可妙同於《事鈔》也。
> 譯文：懺悔的精深義理理應在這個地方詳細發揮，其奧妙處與《事鈔》所說完全相同。

緊接的【385-0020】記文標題就是「**指略**」（指出處而從略）。現譯讀起來像「此處要詳細發揮」，正好相反。
**建議**：「懺悔的義理本應在此處說明，但其精妙之說與《事鈔》所明相同（**故此處從略，逕指《事鈔》**）。」
另，「可妙」一詞諸本文字略有出入，直譯成「奧妙處」證據不足，建議保守處理或加譯註存疑。

### 5. 【385-0001】兩處
- **「哪怕連戒序都無法說完」**：原文「卒難排門，不可說序」是**假設語句**（難緣突至→來不及誦序），不是讓步句；且「不可說序」是「無法誦說戒序」，非「說不完」。
 建議：「然而在作白之後，若難緣突然破門而入，**連戒序也來不及誦說**，此時只要說一句『各正身口意』，十段便都可省略。」
- **「義同廣誦的開端」**：「的開端」是無據增譯。原意是「作白既在序分之中，**作了白就義同已廣誦（序分）**」，所以才說只略九段。
 建議：「只因作白本就攝在序分之中，義理上**等同於已經廣誦**，所以才說『略九』。」

## 二、用語／增譯可再斟酌

| 編號 | 問題 | 建議 |
|---|---|---|
| 0001 | 「時節因緣**事故**」；「所以**律典**才說」 | 「事故」為贅字；「故云九耳」是解釋**前文（疏／註）** 的用語，未必出自律典，宜作「所以文中只說『略九』」 |
| 0002 | 「**剛好**念過這篇序文」 | 「剛好」為增譯，宜作「（來到時）已誦過此序」 |
| 0003 | 「在**會外**聚集前來」 | 「外集」是**從外來集（遲到入眾）**，不是「在會外聚集」，易生誤解 |
| 0009 | 「三藏教**網**」→「義理綱領」 | 網是譬喻（教法如網，撈漉眾生），譯成「綱領」譬喻盡失，宜保留「三藏教法之網」 |
| 0010 | 「鎖」即對治門→「**戒律的**對治法門」 | 「戒律」為增譯，此處泛指對治散亂之法，宜刪 |
| 0010 | 「心多別慮」→「**許多人**心生別的妄念」 | 「多」是「多半、往往」，非「許多人」 |
| 0010 | 「警策**策勵**自己的蒙昧昏沉」 | 疊詞冗贅，作「用以警策自己的昏昧」即可 |
| 0012 | 「端正心意並詳細思辨抉擇，稱為『端意』」 | 以「端正心意」釋「端意」略嫌循環；可作「註中所謂『端意』，是指端正其心、如理思擇」 |
| 0014 | 「**就**應當自行懺悔」 | 「即」的「立即」義是全段重點（疏、記反覆強調「不容延久」），律文宜譯出「就應**立即**自行懺悔」 |
| 0017 | 「西方梵語」 | 可補「印度（此土稱西方）」；又《倉》本指《倉頡篇》，記文方言《三倉》，可加註說明 |
| 0021 | 「說犯**名字**」→「所犯戒條的名稱」 | 「名字」指**罪名**（波羅夷、僧殘等），非戒條條名 |
| 0021 | 「才有**資格**聽聞戒律」 | 「資格」偏現代法律語；「方得聞戒」宜作「才能聽聞說戒」 |
| 0007 | 「多人別牒總告」 | 可補足：「多人時則**逐一牒列姓名，再總合告白**（如『某甲等若干人清淨』）」 |

## 三、體例一致性（跨則）

1. **「上起」譯法不一**：0015 保留「『上起』（即懺悔）」，0016 卻直譯為「向上生起」。既然記文說「從喻為名」，宜**一律保留原詞**並加一次譯註（喻罪令人沉墜、懺令善法上生／如人倒地還從地起），不要一處保留、一處意譯。
2. **「客舊外集」三則譯法不一**（0002「前來集合」／0003「在會外聚集前來」），建議統一為「客比丘與舊住比丘從外前來集會」。
3. **科判層級稱法混亂**：0001「次科」→「第二小節」、0004「四中」→「第四項說明」、0009「三」→「第三段」、0016「初科」→「第一小節」。其中 0004／0007 的「四中」「五中」指的是**疏文大段**，與 0001「次科」的**記文小節**層級不同，現譯用「小節／項」交互使用，讀者易誤判層次。建議定為：疏文大段＝「第X段（科）」，段下細分＝「第X小節」。
4. **引號與句號位置**：如「所以說『情況各不相同。』」「所以只能『略說九段。』」——句號宜置於引號外，全批統一。

## 四、可維持原樣（確認無誤）

- 0004「望制眾／望制別」譯為「就約束全體大眾／個別僧人而言」，判讀正確。
- 0007「客少不勞重說，等、多更說」譯義正確（可補「與舊住比丘相比」使比較對象明確）。
- 0013「上簡邪思，下簡亂想」、0017「懺摩／倉雅」、0020「懺六聚篇」、0021「不問識、疑，白懺後說」等，皆無問題。

**優先處理順序**：0007（即＝卒）→ 0015（罪犯）→ 0019（指略）→ 0003（三問）→ 0001（義同廣誦／假設句），這五處屬會誤導讀者的義理問題；其餘多為潤飾與體例。
