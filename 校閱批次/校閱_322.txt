# 校閱材料　第322檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【322-0001】02_戒疏/21b_卷四下之三#7
【原文】【記】第三，為二。初正釋。「癡」，即顛狂心亂。「癡解」，謂狂病已止，得法解竟。「不無前犯」者，示有他疑，不與同法故。「與癡狂」下，簡濫。顛狂羯磨，及與解法，並用「白二」。此有二意：一、為簡二法，二、為彰別意。注中，初緣；「以事白佛」下，是相。文出三狂：初是下品，二即上品，此二不與法；三即中品，故須與法。
【譯文】【記文】第三段，分為兩部分。起初是正面解釋。「癡」，就是顛狂且心神錯亂。「癡解」，是指狂病已經止息，已經依法作羯磨解除顛狂身分。「不無前犯」，是指顯示別人對他尚有懷疑，不肯與他同共行法。「與癡狂」以下，是簡別浮濫。給予顛狂身分的羯磨，以及病癒解除的作法，都使用「白二羯磨」。這裡有兩個含意：第一是為了簡別兩種法規的不同，第二是為了彰顯事情輕重的特別用意。註文中，起初是緣起；「以事白佛」以下，是作法相狀。經文明示了三種癲狂：第一種是下品輕狂，第二種是上品重狂，這兩種都不給予不癡羯磨；第三種就是中品，所以必須給予不癡羯磨。

【322-0003】02_戒疏/21b_卷四下之三#9
【原文】【註】佛在瞻波國。白月十五日僧說戒時，佛在眾坐，默不說戒。初夜已過，阿難請說，佛言：「欲令如來於不淨眾中說戒者，無此理也。」中夜、後夜請，答亦爾。時大目連即以天眼觀犯戒者去佛不遠，內懷腐爛，外現完淨，即手牽出，來白佛言：「眾已清淨，應得說戒。」佛言：「自今已後不應為。取自言治。」因制此戒。
【譯文】【註文】佛陀住在瞻波國。在白月（前半月）十五日僧團說戒的時候，佛陀坐在大眾之中，沉默不說戒。初夜過去了，阿難尊者請佛說戒，佛說：「想讓如來在不潔淨的大眾中說戒，沒有這樣的道理。」中夜、後夜阿難再次啟請，佛陀的回答也是一樣。這時大目犍連尊者立即以天眼觀察，發現犯戒的人距離佛陀不遠，內心敗壞墮落，外表卻裝作完好清淨，目犍連尊者便親手將他拉出門外，來稟白佛陀說：「大眾已經清淨，應當可以說戒了。」佛陀說：「從今以後不應當這麼做。必須取得犯者自己承認才進行治處。」因而制定了這條戒規。

【322-0004】02_戒疏/21b_卷四下之三#10
【原文】【疏】四、「自言治」者。罪是自生，還須自露。對於人眾，面陳其失，故曰「自言」，因言其罪，情無隱伏，則曰「治」也。緣中，由不取自言，恐後清人，濫被驅逐，因制斯藥。亦有三法自言，五法自言，如上現前，可以知也。
【譯文】【疏文】第四科、「自言治毗尼」。罪過既然是自己生起的，還必須由自己親自發露。面對大眾，當面陳述自己的過失，所以稱為「自言」；藉由親口陳說罪過，內情不再隱瞞遮掩，就稱為「治」。制戒緣起中，由於先前沒有取得當事人自己承認，恐防以後清白的人會遭到浮濫驅逐，因而制定了這帖法藥。另外也有「三法自言」與「五法自言」，如同前面「現前毗尼」中所說，可以參照得知。

【322-0007】02_戒疏/21b_卷四下之三#13
【原文】【註】佛在舍衛國。時，諸比丘於十八事諍不息，遂至僧中斷，不了。以事白佛，佛言：「應與多覓罪相。法、非法語同一處，應差比丘令行舍羅。行有三種：一者，顯露；二者，覆藏；三者，耳語。若上座標首智人、和尚、闍棃住如法地，應顯露行舍羅；若住非法地者，作下二法行之；若非法語人多，彼應作亂起去故。」此律本云「求覓罪相」，意亦同之。
【譯文】【註文】佛陀住在舍衛國。那時，比丘們對於十八種事端諍論不休，最終告到僧團中決斷，卻無法結案。比丘將此事稟白佛陀，佛陀說：「應當給予作多覓罪相（多人語）羯磨。說法與說非法的人集中在同一處，應當差派比丘前去分發籌籤（舍羅）。發籌有三種方式：第一是公開發籌表決；第二是秘密投票；第三是耳邊私語投票。如果上座長老、首領智者、和尚、阿闍梨站在合法的立場，應當公開發籌表決；如果他們站在非法的立場，則依照後兩種方法行籌；如果堅持非法言論的人佔多數，他們可能會鬧事離去，因此需要審慎。」此處《四分律》戒本稱為「求覓罪相」，意思也是一樣。

【322-0008】02_戒疏/21b_卷四下之三#14
【原文】【疏】五、「多人語」者。由評法相，取解不同。故召兩朋，同處面決。行籌五德具八法者，三種量度，詳審眾情，又知義理，邪正明決，依法行之。非法者多，且令散去，後當更斷，待法語人。事希法隱，故略不述。
【譯文】【疏文】第五科、「多人語毗尼」。這是由於評議教法義相時，個人的理解不同。所以召集雙方朋黨，在同一處當面裁決。負責發籌的人必須具備五德、通達八法，以三種發籌方式衡量推度，詳盡審察大眾的情緒，又要通曉教理，明辨邪正，依照如法的方式推行。如果持非法觀點的人佔多數，暫且讓大眾散去，日後等待持如法言論的人聚齊時，再作裁斷。因為這種事極少發生且法規幽微，所以此處簡略不再多述。

【322-0009】02_戒疏/21b_卷四下之三#15
【原文】【記】第五，初科。先敘緣，即注從初至「不了」也。「故」下，次示制法，即注「以事白佛」已下文也。「八法」者，《律》云：「不愛、不恚、不怖、不癡、知已行不行，有如是五法，應差行舍羅。」并解三種行籌法，共為「八」也。「三種」，如注所列。「舍羅」，即籌。籌有二別，一完，二破。從正者捉完籌，隨邪者捉破籌，多者為是。細尋可解。注中，「此律」下，示別名。「事希」下，三、顯略。
【譯文】【記文】第五段，第一科。先敘述緣起，也就是註文中從開頭到「不了」的文句。「故」以下，接著指明制定作法，也就是註文中「以事白佛」以下的文句。「八法」，《律典》說：「不偏愛、不瞋恨、不怖畏、不愚癡、能知行籌與否，具備這五種德行，方能差派去發放舍羅。」再加上通曉三種發籌方法，共合為「八法」。「三種」，如同註文所列。「舍羅」，就是算籌。算籌有兩種差別，一種完整，一種破損。順從正法的人拿完整的籌，順從邪說的人拿破損的籌，以多數的一方為判定準則。仔細推尋即可明白。註文中，「此律」以下，指明不同的名稱。「事希」以下，第三部分，說明簡略的緣由。

【322-0010】02_戒疏/21b_卷四下之三#16
【原文】【疏】今亦有師共諍佛性，或道理有，或執行成，俱有俱無，不能自決。十住羅縠，凡下絕思。義須三藏，據理取斷。是名事露法隱，誰有行之？
【譯文】【疏文】如今也有法師共同爭論佛性，有的主張道理上本具，不假修證；有的堅持由修行功力方能成就；有的主張兩者皆有，有的主張兩者皆無，自己無法裁決。連十地菩薩看佛性都如隔著輕紗薄紈，凡夫更斷絕了妄加思度的可能。按義理必須依憑三藏聖典，根據正理來加以裁斷。這就叫做「事情顯著而行法晦沒」，現在又有誰能施行呢？

【322-0011】02_戒疏/21b_卷四下之三#17
【原文】【記】次科。「或理有」，謂理性本具，不假修證，此執有也。「或行成」者，謂行功所成，非性本有，此計無也。「俱有」，謂亦理具亦修成，此計兩亦。「俱無」，如定性聲聞、闡提無等，此執雙非也。然彼佛性，不墮四句，凡計一竭，俱為戲論。「十住」字誤，合云「十地」，或通指十聖，或但第十地及等覺人。彼見佛性，如隔羅縠觀月，喻其末明。《涅槃經》云：「菩薩位階十地，尚不了了知見佛性，何況聲聞緣覺之人能得見耶？」文況下凡，非彼所測，則可知矣。「義」下，明合用此法。由是言諍，須教殄滅。「是」下，傷時不用。「露」，顯也。法何所隱，由人不行耳。
【譯文】【記文】第二科。「或理有」，是指理性本來具足，不假借後天修證，這是執著於「有」。「或行成」，是指靠修持功力所成就，並非自性本來具有，這是執著於「無」。「俱有」，是指既在理體上具足也在修持上成就，這是執著於「兩者皆是」。「俱無」，如同認為定性聲聞、闡提沒有佛性等，這是執著於「兩者皆非」。然而那佛性，根本不墮入這「四句」的分別中，凡是執計一端，全都是戲論。疏文中的「十住」字有誤，應當作「十地」，或者通指十聖位，或者單指第十地與等覺菩薩。他們見佛性，如同隔著輕紗觀月，比喻尚未徹見圓明。《涅槃經》說：「菩薩果位高達十地，尚且不能清清楚楚地見到佛性，何況聲聞、緣覺之人哪裡能得見呢？」經文以此況顯下位凡夫，更非凡夫所能測度，理當可知。「義」以下，說明理當採用這種羯磨法。正因為這是言語的諍論，必須以聖教來平息消滅。「是」以下，感傷當前時代已無人施行。「露」，就是顯露。羯磨法哪裡會自我隱蔽，全是因為沒有人去推行罷了。

【譯文】【記文】第二大段「略教」，也分為三分。在序分中有三種解釋，第一種解釋，在正面解釋中分為兩點。首先解釋「餘」的意義。「據上釋迦說」，就是指廣教。「六佛在釋迦前」，都是過去佛。從「明」以下，接著解釋「序」的意義。

【322-0040】02_戒疏/21b_卷四下之三#46
【原文】【疏】又解：「上章八篇廣相，二機同感，『序』引七佛咸共說之。略教既被化初，多被攝心之士。恐於末法，無機不須。故列七法，同成一禁也。」
【譯文】【疏文】另一種解釋：「上一章八篇戒法的廣相，利根、鈍根兩種根機同受感化，『序文』引出過去七佛都共同宣說這部戒。略教既然是施設於教化之初，多半是用來攝受能夠調心持戒的利根之士。唯恐在末法時期，眾人以為沒有相應根機而不再需要。所以列舉出七佛略法，共同構成一體遵行的禁戒。」

【322-0041】02_戒疏/21b_卷四下之三#47
【原文】【記】次列意中。對廣明略。廣教通被三時利鈍二機，略教反上，一被化初，二唯利士。「恐」下，出疑情。「故」下，正列意。
【譯文】【記文】接著在排列意旨之中。比對廣教以闡明略教。廣教通於攝受三時之中的利、鈍二種根機；略教則與之相反，一是施設在教化初期，二是唯獨攝受利根之士。「恐」以下，提出疑難情由。「故」以下，正式列明意旨。
