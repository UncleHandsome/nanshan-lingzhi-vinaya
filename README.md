## 三、體例說明

1. **文字一仍 CBETA 底本**，未改字、未增刪。
2. **校勘注（腳注異文）未收**，只存正文，以免版面蕪雜。
3. 戒疏、業疏採用**會本**：疏文大字（原書以「【疏】」標起），元照的記文以**小字灰色**排印，略如古本夾註之例。
4. 標點情況：
   - 行事鈔、戒疏：底本已有完整新式標點。
   - 業疏、比丘尼鈔、拾毗尼義鈔：底本標點從簡（多僅句末），一仍其舊，未代為句讀。
5. 標題中「No. 7xx-A」等，是卍續藏原書的序跋編號；書末的「新羅國寄還書」等亦原書附錄。
6. CBETA 造字（Unicode 未收之罕用字）無法顯示者，以「□」代之，為數極少。
