# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【162-0001】01_行事鈔/10a_卷下之二#12
【原文】四相和者。《薩婆多》：四藥相和，從彊而服。若以時藥、終身藥，助成七日藥，作七日服；由七日藥勢力多故，又助成故；如以穌煮肉，此穌肉汁，得作七日服。若以時藥、七日藥，助成終身藥，作終身服；如以穌、乳，和葶藶子作丸者是；又如附子、烏頭等諸毒藥，浸豆、麥等，名盡形藥。若以終身、七日，助成時藥者，時中服之；如麪食，用穌、油，薑、椒等。若分數俱等，勢力相似者，隨以藥首一名標目，餘者藥分稱之；如石英、鍾乳，黃耆、白木，丸、散、湯、膏、煎等，並例知用之。
【譯文】第四、闡明藥物的混合相和：《薩婆多論》說：四種藥物相互調和時，順從藥力強大的一方來規定服用期限。如果以時藥、終身藥來輔助成就七日藥，就當作七日藥來服用；因為七日藥的藥力成分占多數，且其他藥物是輔助成就它；比如用酥來煮肉，這酥肉汁便可以當作七日藥來服用。如果以時藥、七日藥來輔助成就終身藥，就當作終身藥來服用；比如用酥、乳汁調和葶藶子製成藥丸便是如此；又如用附子、烏頭等各類毒藥來浸泡豆、麥等，這也稱為盡形藥。如果以終身藥、七日藥來輔助成就時藥，則必須在正午之前的「時中」服用；比如製作麵食，添加了酥、油、薑、椒等。如果各類成分比例相等、藥力勢均力敵，便隨意選取主要藥材中的一種名稱來立名，其餘藥物則按成分稱呼；比如石英、鐘乳，黃耆、白術（白木），製成丸劑、散劑、湯劑、膏劑、煎劑等，都依此類推而通達知曉其用法。

【162-0003】01_行事鈔/10b_卷下之二#34
【原文】三所受比丘，有二。初自無五過：一相續畜。若畜至七日，即日受藥，不成。《僧祇》：比丘有第七日石蜜，即日更得石蜜，是名相污。問：此既未過，云何相染？答：非犯長相污，由前七日服訖，病猶不差，更服無益，作法不成；若得異藥，得加七日。二相續畜。已曾畜藥至八日犯長，即日得藥入手作法，被染，更不堪服。三曾食他第七日藥，即日自得，作法不成，以藥味通故；《僧祇律》如此。四相續受。《僧祇》：比丘七日中，日日受藥，受而不食；至八日，不得更受，須一日不受間之。謂貪多過受，又不服療。五相續犯。《僧祇》：比丘七日恒服，至八日正可，不得更服，不妨受於異藥。上明相續，對一蜜藥為言；若得油者，亦即加法。《僧祇》：生穌、熟穌、醍醐，展轉易味，七日更受。二自作四法：一仰手受。二分別。言作七日油想；若本心作然燈、塗足受者，不成，如《僧祇》說。三記識。言此中淨物生，我當受。四展轉。受生穌作熟穌。《毘婆沙》云：七日藥手受口受已，置一處，勿令淨人觸之。
【譯文】三所受比丘，有二。初自無五過：第一、相續蓄積。如果蓄積藥物已滿七日，當天又接受同種藥，作法不成立。《僧祇律》說：比丘持有第七日的石蜜，當天又得到石蜜，這稱為相互污染。問：既然尚未超過期限，為何會相互染污？答：這不是犯畜長物（過限）的相污，而是因為前七日服完之後病仍未痊癒，再服此藥也無益處，所以作法不成立；如果得到不同的藥，則可以加持七日法。第二、相續蓄積。曾經蓄藥到了第八天已犯畜長罪，當天得到新藥入手作法，受到前罪染污，也不得再服用。第三、曾經吃過他人第七日的藥，當天自己得到同種藥，作法不成立，因為藥味相同相通的緣故；《僧祇律》是這樣說的。第四、相續受持。《僧祇律》說：比丘在七天當中，天天接受新藥，受了卻不吃；到了第八天，不得再受，必須空隔一天不受來間隔之。這是指貪多過度受取，又不用來服藥治病。第五、相續犯戒。《僧祇律》說：比丘七天內經常服用，到了第八天藥剛好用完，不得繼續加受同種藥，但不妨礙接受不同種類的藥。上述說明相續，是針對單一蜜藥而言；如果得到油類，也可以立即加法。《僧祇律》說：生酥、熟酥、醍醐，輾轉改變滋味形態，可以重新受持七日。第二方面，比丘自身應作四法：第一、仰手承接。第二、作分別想。口中宣說作「七日油」之想；如果本心是為了點燈、塗足而受持，作法不成立，如《僧祇律》所說。第三、記識。口中宣說「此中淨物生，我應當領受」。第四、輾轉。接受生酥而熬煉作熟酥。《毘婆沙論》說：七日藥經過手受與口受之後，安置在一個地方，切勿讓淨人碰觸。

【162-0005】資持記/14b_下二#34
【原文】問答中，由未犯長，制受不成，故須問決；答中，前釋不成，後簡異藥。第二。長染不成，可會。三中。藥味通者，義同共畜故。《僧祇》如此者，若據本宗，理應自成。四中，初引制法。一日即第八日。謂下，顯意。上句示間日，下句明非犯。據本不服，理應成受；制須間日，為抑貪情。
【譯文】問答之中，因為還沒有構成「犯長」的過失，戒律規定受持不能成功，所以必須提出問答來決斷；回答之中，前半段解釋受法不成立的原因，後半段簡別其他種類的藥物。第二種過失，因為染著犯長而不成立，這個道理可以融會貫通。在第三種過失中，藥物的味道如果相通，在義理上就等同於共同儲蓄。《僧祇律》雖然是這樣說，但如果依照本宗的義理，在法理上應該能自然成立。在第四種過失中，首先引用戒律規定的作法。「一日」就是指第八天。「謂」字以下，顯露其深意。上一句指出必須間隔一天，下一句說明這並不算犯戒。按照原本沒有服用的情況，理應能夠受持成功；但戒律規定必須間隔一天，是為了壓制貪婪的心情。

【譯文】【疏文】回答：「那部經是依照所面對境緣的尊卑來衡量內心殺意的大小，所以劃分出三個等級，並不是在說明律法中逆罪與波羅夷罪的輕重相狀。如果不這樣理解的話，同一段經文接著說『一闡提不墮入這三種殺業中』，難道殺一闡提就毫無罪過了嗎？若依照律典，是依循眾生形體境緣來判定，殺一闡提依然構成殺人的波羅夷重罪；若依照經論的深義，一闡提只是暫時不具足引發成佛的清淨善性罷了。」

【162-0011】02_戒疏/08a_卷二下之一#92
【原文】【記】三難中。即據《涅槃》，轉難初答。《經》明佛及菩薩，皆了知殺法，故云「知殺」。「羅漢」上，準《經》有「父母」二字，今此正問辟支，故略之耳。《經》文既以三乘同為上品，則知緣覺罪無差降。答中。初出《經》意。《經》分心業，不揀夷逆。準此，若殺辟支，雖非逆重，由境尊勝，業異常流。「若不」下，就經反質。初引示《經》文。梵云「一闡提」，此云「信不具」。「不墮三殺」者，由殺無罪，不入三品，故《經》云「譬如刈草、掘地等，無有罪報」。「約」下，比對律制。言「無性」者，準《經》，前明闡提無佛性。據後決前，此名「隨他語」。一切有性，名「隨自語」。
【譯文】【記文】第三個詰難中。是直接根據《涅槃經》的說法，轉過來駁難前面的第一個回答。經中說明佛陀與菩薩都能如實了知殺生的法相，所以稱為「知殺」。「阿羅漢」之上，依照經文本來有「父母」二字，此處因為正是在質問辟支佛的問題，所以省略了這兩個字。經文既然將三乘聖者同列為上品殺業，就表示殺害緣覺的罪責並不亞於羅漢。回答中，首先點出《涅槃經》的本旨。經文純粹是劃分起心動念的業行，並非在甄別律制中的波羅夷與逆罪。照此看來，如果殺害辟支佛，雖然不構成律制中的五逆重罪，但由於對象尊貴殊勝，所招感的惡業絕非尋常之流。「如果不」以下，引導經文反詰質疑。首先引述經文的記載。梵語稱為「一闡提」，中文翻譯為「信根不具」。「不墮三種殺業」的意思，是由於經中方便宣說殺之無罪，不列入三品之中，所以經文說「好比割草、掘地一樣，沒有罪業果報」。「依照」以下，比對律宗的制度。所謂「無性」，依照經文前段，是指一闡提斷盡善根無佛性。但根據後文的判決，這只是佛陀隨順眾生根機的「隨他意語」；一切眾生皆有佛性，才是佛陀徹底的「隨自意語」。

【162-0015】02_戒疏/08a_卷二下之一#96
【原文】【疏】第四，惡心出佛身血者。
【譯文】【疏文】第四句、心懷惡意讓佛陀身體出血。

【162-0016】02_戒疏/08a_卷二下之一#97
【原文】【疏】垂降生善，為世福田；慈濟含識，亦是恩養。佛為法王，四弘開化，惠益群品，其恩無外，宜應敬養，植福清心。反加瞋忿，興於逆害，命不可斷，但出身血。損法身器，其過尤深！故制方便，業當逆罪。
【譯文】【疏文】佛陀垂跡降生化導眾生生起善法，是世間無上的至極福田；以大慈悲普度一切有情，這也是至高無上的恩養之德。佛陀身為法王，以四無量心（四等）開啟教化，利益一切品類的眾生，這份恩德浩瀚無外，信眾理應當虔誠敬養，培植福報並澄澈身心。如今反而橫加瞋恚忿怒，興起大逆不道的加害行徑；佛陀的性命是不可能被斷絕的，頂多只能使其身體微損出血。然而損壞了法身所依託的色身器量，其過失極為深重！所以律法雖然只能制定未遂手段的偷蘭遮罪，但其招感的業報直接相當於大逆重罪。

【162-0017】02_戒疏/08a_卷二下之一#98
【原文】【記】第四句，制意中。初科為二。初示句。「佛」下，正敘。初明恩深合敬。「四弘」，即上「四等」，「弘」即訓大，亦由普徧，故得名耳。「恩無外」者，所被無遺故。「反」下，次顯過明制。「損法身器」者，《多論》云「色身是法身所依」。「故制方便」者，即偷蘭也。佛不可殺，義無究竟，制輕業重，相別可知。
【譯文】【記文】第四句的制戒用意中。第一科分為兩部分。首先標示句義。「佛陀」以下，正式鋪陳敘述。起初說明佛恩深厚理當崇敬。「四弘」就是前文所說的「四無量心」，「弘」字解釋為廣大，也是由於慈光普遍涵蓋，所以得到這個名稱。「恩德無外」的意思，是佛陀慈光被及之處毫無遺漏。「如今反而」以下，接著顯明過失並確立制戒原則。「損毀法身器量」的意思，《薩婆多論》說「色身是法身所依託的基石」。「所以制定方便罪」的意思，是指只能判處偷蘭遮罪。佛陀是不可能被真正殺死的，在理則上根本沒有殺害既遂這回事；因此律法制裁雖輕，但因果罪業極重，兩者的差別由此可知。

【162-0018】02_戒疏/08a_卷二下之一#99
【原文】【疏】然出身血，其相是一，心懷善惡，同一業報。耆域出血，善心治病，一劫色有而受樂報。調達反此，故入地獄。恐濫善者，故標惡心。
【譯文】【疏文】然而致使佛身出血這件事，外在的行為表相是一樣的，但內心懷抱善意或惡意，卻招感同等時限的業報。名醫耆婆使佛身出血，是出於治病的善心，因而獲得一整個大劫在色界梵天受大樂報；提婆達多則與此相反，惡意害佛出血而墮入阿鼻地獄。唯恐行者將善意之舉與惡行相混淆，所以戒律特別標明必須是「惡心」。

【162-0019】02_戒疏/08a_卷二下之一#100
【原文】【記】次科。初明相濫。「同業報」者，此約時論，並一劫故。「耆」下，次引緣釋。「耆域」，亦云耆婆，善醫，世尊足疾，因針出血。「色有」，即梵天，此明善心也。調達以推山壓佛，碎石傷佛指足，生陷阿鼻，此明惡心也。「恐」下，後示簡意。
【譯文】【記文】第二科。首先說明外相容易混淆。「同一業報」的意思，是就時間的長度來論斷，兩者同樣長達一個大劫。「耆婆」以下，接著引述歷史公案來解釋。「耆域」又稱耆婆，是當世神醫，佛陀腳部患疾，耆婆以金針為佛刺破出血治療。「色有」是指色界梵天，這是說明善心醫治的果報。提婆達多推落山石企圖壓死佛陀，碎石崩裂擊傷了佛陀的腳趾，因而活生生陷入阿鼻地獄，這是說明惡心的罪報。「唯恐」以下，最後說明特別簡別惡意的用意。
