# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【368-0008】02_戒疏/19c_卷四下之一#91
【原文】【記】戒本中。「七句」，指「如殘」中，即三雙一隻。「若比丘」，所諫人。「作如是語」下，所諫事。即第一雙也。「彼比丘諫言」下，別人屏諫。違反佛語，即「謗世尊」。業重障深，故是「不善」。「彼比丘諫時堅持不捨」，拒屏諫。第二雙也。「彼比丘乃至」下，眾僧作法諫。「不捨」者，拒僧諫。第三雙也。結罪，為一隻。注文，指前僧殘。「優降」，即重輕也。
【譯文】【記文】戒本文句中。「七句」，指「如同僧殘法」中的科分，即由三對雙句配上一單隻句構成。「若比丘」，指被勸諫的人。「作如是語」以下，指被勸諫的事端。這構成了第一對。「彼比丘諫言」以下，指個別人員進行私下勸諫。違背佛陀的言教，就是「毀謗世尊」。惡業重大、障道深厚，所以是「不善」。「彼比丘諫時堅持不捨」，指抗拒私下勸諫。這構成了第二對。「彼比丘乃至」以下，指僧團大眾依法舉行羯磨勸諫。「不捨」，指抗拒僧團的大眾勸諫。這構成了第三對。最後的判定罪名，作為單獨的一隻句。經文注解指向前面的僧殘法。所謂「優降」，就是指罪刑的重與輕。

【譯文】【疏文】問：「同是被僧團舉罰，惡見與前二事的義理相同，為何前二者是輕罪，而隨順惡見則是重罪？」

【368-0017】02_戒疏/19d_卷四下之一#5
【原文】【疏】答：「說欲非障，言說相似，濫於理教以滅正法。又自壞行，障學路。亦順人情，多喜隨順故。餘二條然是非，無滅法過。雖有自壞，隨順者希，無壞人義，故結輕也。」
【譯文】【疏文】答：「主張行欲不障蔽聖道，其言論聽起來似是而非，容易混淆正理與教義從而毀滅正法。再者，這也會敗壞自己的梵行，障礙修學之路。而且這種說法順應世俗人情，眾人多半喜歡隨順迎合。至於另外兩種舉罰（不見罪、不懺罪），是非分明、條理清楚，沒有毀滅正法的過失。隨順者雖然自壞梵行，但願意附和跟從的人極為稀少，不具有敗壞他人的性質，所以只結判為輕罪。」

【368-0018】02_戒疏/19d_卷四下之一#6
【原文】【記】後輕重中。初標徵。不見、不懺，隨順並吉，惡見犯提，故云「二輕一重」。答中，初明惡見重意，有三義：初濫教；「又」下，二、壞己；「亦」下，三、損他。「餘」下，次明餘二輕意。上三義中，但具次義。
【譯文】【記文】後面辨析輕重之中：一開始先提出徵問。不見罪、不懺罪這兩條，隨順者都結判為突吉羅輕罪，唯獨隨順惡見者犯波逸提，因此說是「二輕一重」。在回答中，首先說明隨順惡見罪責重的原因，共有三層涵義：一是混淆教法；「又」字以下，二是敗壞自心；「亦」字以下，三是損害他人。「餘」字以下，接著說明其餘兩種舉罰結罪較輕的原因。前述的三層涵義中，其餘兩條僅僅具備敗壞自身的第二義而已。

【368-0019】02_戒疏/19d_卷四下之一#7
【原文】【疏】論犯四緣：一、是惡見舉人；二、知是；三、隨順；四、隨同一一事，結。
【譯文】【疏文】論述構成犯戒的四個條件：一、對方是因惡見而被僧團舉罰之人；二、明知對方是這樣的人；三、有心隨順迎合；四、只要與對方共同從事隨順之中的任何一項事務，即結罪。

【368-0020】02_戒疏/19d_卷四下之一#8
【原文】【記】犯緣中。初是所隨，下並能隨。四中，「隨同一事」，謂供給、羯磨等事，如文所列，隨一成犯，不待具也。
【譯文】【記文】犯戒條件之中：第一項是所隨順的對象，以下各項則是能隨順的行為。第四項中所說的「共同從事隨順之中的任何一項事務」，是指供給生活所需、共同參與羯磨法事等，如同戒文所列舉的，只要隨同做了其中一件事便構成犯罪，不須各項全部具備。

【368-0021】02_戒疏/19d_卷四下之一#9
【原文】【註】佛在舍衛。梨吒惡見生，僧諫不捨，佛令白四舉之。六群供給所須，共同羯磨。比丘舉過，佛因訶責，故制此戒。
【譯文】【註文】佛陀在舍衛城時。梨吒生起了惡邪見，僧團勸諫他卻不肯捨棄，佛陀便令大眾以「白四羯磨」依法舉罰他。六群比丘卻供給他生活所需，並和他一同進行羯磨。其他比丘揭發此項過失，佛陀藉此呵責，因而制定了這條戒。

【368-0022】02_戒疏/19d_卷四下之一#10
【原文】【律】若比丘，知如是語人，未作法，如是邪見而不捨，供給所須。
【譯文】【律文】如果比丘明知此人發表過這類言論，僧團尚未為其作法解罰，依然堅持這種邪見而不肯捨棄，卻仍供給他生活所需。

【368-0023】02_戒疏/19d_卷四下之一#11
【原文】【註】有二種，若法，若財。法者，教修習增上戒、意、智，學問誦經；財者，供給衣服、飲食、牀褥、醫藥。
【譯文】【註文】供給分為兩種，一是法供養，二是財供養。法供養是指教導他修習增上戒學、心學、慧學，以及教導學問與誦經；財供養則是指供給他衣服、飲食、臥具、醫藥這四事供養。

【368-0024】02_戒疏/19d_卷四下之一#12
【原文】【律】共同羯磨、止宿。
【譯文】【律文】或是與他共同進行羯磨、一同止宿。

【368-0025】02_戒疏/19d_卷四下之一#13
【原文】【註】屋有四壁，一切覆障；或一切覆，不一切障；或一切障，不一切覆；或不盡覆、不盡障。
【譯文】【註文】房屋有四面牆壁，四周完全遮障且上方完全覆蓋；或者上方完全覆蓋，四面未完全遮障；或者四面完全遮障，上方未完全覆蓋；或者上方未完全覆蓋、四面也未完全遮障。

【368-0026】02_戒疏/19d_卷四下之一#14
【原文】【律】言語者。
【譯文】【律文】或者與他交談共語。

【368-0027】02_戒疏/19d_卷四下之一#15
【原文】【註】若比丘先入屋，彼人後入，若彼人先來，若俱入，隨脇著地，一一墮。
【譯文】【註文】如果比丘先走進屋內，對方隨後進來；或者對方先來；或者兩人一同進入，只要身體一側著地躺下，每犯一次便結一個墮罪（波逸提）。

【368-0028】02_戒疏/19d_卷四下之一#16
【原文】【律】波逸提。
【譯文】【律文】判犯波逸提罪。

【368-0029】02_戒疏/19d_卷四下之一#17
【原文】【註】尼同犯。不犯者：若不知；若屋一切覆，無四障，或半障，或少障；或一切障，無覆、半覆、少覆；或半覆障、少覆障、露地。若病，被繫者，命、梵難，無犯。
【譯文】【註文】比丘尼同犯此罪。不犯的情況包括：若是不知情；如果房屋上方雖有完整覆蓋，但四面全無遮蔽，或只有半邊遮蔽，或只有極少遮蔽；或者四面完全遮蔽，上方卻無遮蓋、只有半遮蓋或極少遮蓋；或者只有半遮蔽半覆蓋、少許遮蔽少許覆蓋，乃至身在露天平地。如果因病或被拘禁繫閉，面臨喪命難或失梵行難時，均不犯戒。

【368-0030】02_戒疏/19d_卷四下之一#18
【原文】【疏】戒本十句：一、人；二、知；三、如法語人；四、未作法；五、如是邪見；六、不捨；七、供給；八、同法；九、止宿；十、結罪。
【譯文】【疏文】戒本正文可分為十個分句：一、對方是誰（人）；二、明知其情（知）；三、如實發表邪見者（如法語人）；四、僧團尚未解罰（未作法）；五、堅持此類邪見（如是邪見）；六、不肯悔改（不捨）；七、給予物資（供給）；八、共同羯磨（同法）；九、同宿同居（止宿）；十、裁定罪名（結罪）。
