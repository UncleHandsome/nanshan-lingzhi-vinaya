# 校閱材料　第149檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【149-0003】02_戒疏/04a_卷一下之二#139
【原文】【記】次科。古謂未至止隔，但是違理，故「增不善」。若論違制，自歸果罪，及以「闕緣」。故約制教，則無「進趣」。

【149-0010】02_戒疏/04a_卷一下之二#146
【原文】【疏】有人言：「進趣方便，或有或無。若藉一世因成，中無隔絕，既因不定，如何結罪？或藉異世因成，如諸諫戒，中有法隔，乃至殺盜微涉遲疑，皆有其罪，如《律》文中，捨者三蘭。」
【譯文】【疏文】義理疏文說：有人解釋道：「進趣方便，有時存在，有時不存在。若是藉由同一個時段因緣一氣呵成，中間毫無間斷阻隔，既然前因尚未固定，如何能結罪？這時便沒有此罪。或者若是藉由前後相異的時段因緣而成就，例如各類勸諫戒，中間被羯磨儀軌相隔開來，乃至進行殺生、偷盜時稍微產生了遲疑猶豫，這些過程都各有其罪；正如《四分律》文中所說，捨棄惡見者會犯下三個偷蘭遮罪。」

【149-0011】02_戒疏/04a_卷一下之二#147
【原文】【記】次解中。初通標不定。「若」下，別釋。初釋或無。「一世」，謂同時無閒，對下「異世」可解。「或藉」下，釋或有。「諸諫」羯磨，「殺盜遲疑」，皆謂心事相閒，不一時故。
【譯文】【記文】在第二種解釋中：首先通泛標明或有或無。「若藉」以下，分別解釋。首先解釋「或無」：「一世」是指同一時間毫無間隙，對比下文「異世」便可明白。「或藉」以下，解釋「或有」：勸諫羯磨以及行殺行盜時的遲疑，都是指心意與事相在時間上產生間斷隔閡，並非在一瞬之間完成。

【149-0012】02_戒疏/04a_卷一下之二#148
【原文】【疏】有人解言：「一切造業，其必有因。業成當果，則篇聚所攝，如何此因乃名違理？若以違理惡因，而成違制罪者，則違制罪時，更無違理惡業。然違理違制，各有二業。故知其因，雙分兩緣，其義極矣。是以《十誦》、《多論》步步偷蘭，文誠驗也。」
【譯文】【疏文】義理疏文說：有人解釋道：「凡是一切造業，必定有其前因。業道若成辦了當前的究竟果罪，自然被篇聚所收攝；怎麼可以把這個前因單純判定為『違背正理』呢？如果認為因地中違理的惡因，能轉化為究竟時違背佛制的罪過，那麼當違背佛制的罪過成就時，豈不是就不再具有違背正理的惡業了嗎？然而事實上，違背正理與違背佛制，始終各有這兩種惡業。由此可知造業的前因，必定同時分屬於理與制兩種因緣，這個道理已至極透徹。因此《十誦律》與《薩婆多論》明確指出趣向惡境時『步步皆結偷蘭遮』，這是極為真實誠懇的明證。」

【149-0013】02_戒疏/04a_卷一下之二#149
【原文】【記】第三，立義中，初科。初難破。彼謂因中違理，果方違制，因果不等，故云「如何」等。「若」下，正難。因既違理不違制，果應違制不違理。「然」下，立義。初明理制相兼。以違制其必違理，故云「各二業」也。「故」下，正立。前明因但違理，今須違制，故云「雙分」等。「是」下，引證。
【譯文】【記文】在第三種「樹立正義」的第一小科中：首先質難破斥。古德認為因中只是違背正理，到了果位才違背佛制，因果地位既然不對等，所以質疑「如何此因」等。「若以」以下，正式質難：因地既然只違理不違制，那麼果位也應當只違制而不違理。「然違理」以下，樹立正見：首先說明違理與違制兩者兼備；因為違犯佛制時必然也違背正理，所以說「各有二業」。「故知」以下，正式建立理論：前人認為因位只違背正理，現在主張必定也違背佛制，所以說「雙分兩緣」。「是以」以下，引文為證。
