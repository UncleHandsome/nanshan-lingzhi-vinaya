整體看，這份白話譯文骨架清楚、科判層次交代得不錯，但有幾處**術語被「口語化」之後意思走樣**，還有一兩處**漏掉關鍵結論、語意近乎相反**。以下先列重點，再逐則細說。

---

## 一、影響義理的重點問題（建議必改）

| 出處 | 原文 | 譯文 | 問題 |
|---|---|---|---|
| 0008 | 言縱一切集者 | 「所謂縱使十方大眾全部聚集」 | 漏掉「**亦不可分**」，讀來變成「聚集就可分」，與常住常住物「永不可分」的本義相反 |
| 0004 | 何得焚除，失事在福也 | 「反倒將招致罪過之事當作求福」 | 「失事在福」應是**喪失事相（經像）所生之福德**，非「把罪當福」 |
| 0002 | 戒律不用流落 | 「戒律破損不用漂流遺落」 | 「流落」＝散落零落，不是「漂流」 |
| 0007/0008 | 約名定體／初簡體 | 「確定體質」／「簡別其體質」 | 「體」是體性、體類，不是現代語的「體質」 |
| 0006 | 並具通塞 | 「通行與防堵」 | 通塞＝**通（普遍）與塞（局限）**，非「防堵」 |
| 0002 | 舊云損色 | 「損傷了色相」 | 損色指吹氣損壞經上**墨色字跡**，「色相」是另一個術語 |
| 0008 | 有疑醫豉為熟物 | 「有人懷疑……屬於熟物」 | 中文「懷疑X屬於Y」是**否定**傾向；原文是「誤以為是熟物而判歸十方」 |

## 二、逐則細部

### 【1108-0001】
1. **「佛是有情，可同非人」**：「非人」是盜戒三類境（人／非人／畜生）之一，指天、鬼神等。譯文照抄而未說明，讀者會誤以為「不是人」。
 建議：「佛屬於有情眾生，可比照『非人』（天、鬼神等）一類來論；法則是非情之物，本身不能為主，只能就掌管守護的人論犯。」
2. **「明指護主」→「明確指涉當前的防護主人」**：「當前」為原文所無，「防護主人」生硬。宜作「明確指出是就**守護主（保管經卷者）** 結罪」。
3. **「言通兩主」**：譯作「本主與護主」是合理推斷，但原文未明說，建議加註標明是推釋之詞。
4. **「還歸佛用」→「利益依舊歸佛陀所用」**：「利益」是添加語，宜作「（變賣所得）仍歸供佛之用」。
5. 「第二盜法」宜作「第二科、盜法（法寶）物」；「此有兩節」的「節」是段落，不宜譯成「章節」。

### 【1108-0002】
1. **「戒律不用流落」**（重點）：宜作「戒本（律典）已破損不堪使用、散落零落了，可以燒掉嗎？」
2. **「須以淨物拂拭」→「乾淨的布帛」**：原文只說「淨物」，未限定布帛，屬過度具體化。改「潔淨之物拂拭」。
3. **「舊云損色」**：宜作「舊說（口吹會）損壞經卷的顏色字跡，未必如此」。
4. **「恐成觸污輕慢經法」**：譯文「形成觸染玷污輕慢了經法」句法不通。建議「恐怕口氣觸污經卷，構成對經法的輕慢」。
5. **「今云犯輕」「今云重者」**：這個「今」指 **《鈔》文現在說的**，不是「如今（現代）」。兩處「如今所說」易誤導，建議統一改「《鈔》中說的『犯輕』即指此」。

### 【1108-0003】
1. **「方便破僧」**未加解釋，一般讀者不懂。宜「與**破僧的方便罪**（破和合僧未遂，結偷蘭遮）相同」。
2. **「同二逆故」→「等同於造下二種逆罪」**：語氣過重。原文是**比況**（與二逆相類），用以判定上文所犯為偷蘭，並非說真的犯了逆罪。建議「舉此比況，判定上文犯偷蘭遮，因為與二種逆罪相類」。
3. 「準此，且望無主為言」可補足：「這是就**沒有守護主**的經卷而言；若是有主，理應依前文（計紙墨價值、望主結重）判定。」
4. 「知出何文」原文疑脫「不」或為反詰語，譯作「不知出自何部典籍」意思可通，但宜加校注。
5. 「是法因緣生偈」宜註明即緣起偈（諸法因緣生……）。

### 【1108-0004】
1. **「失事在福」**（重點）：這句是承上「何得焚除」而來——經像是生福之具，焚毀即**失去世相上的福德**。譯成「把招罪之事當作求福」既與前文「謂言得福，此妄思度」重複，也丟了「失」字。
 建議：「怎能焚燒毀除，而喪失了（禮拜供養經像所生的）事相福德呢！」（可加註：一說「失事相之福」。）
2. **「我今火淨」**：「火淨」是律中以火作淨的術語，此處是愚人自以為「燒掉就清淨」。譯文「火化清淨」略含糊，可作「我現在用火燒掉使之清淨」。
3. **「借拒犯蘭」→「借用拒絕歸還」**：宜「借他人經卷，抵拒不還，犯偷蘭遮」。
4. **「盜寫祕方」→「盜竊抄寫獨門祕方」**：重點在**未經允許私自抄錄**，宜明說。
5. 「肆意焚燒」「堂堂並列」「徹底霸占」等修飾語原文所無，建議收斂。
6. 「半偈捨身」「兩字除惑」是典故，宜加注（雪山童子為半偈捨身等），否則白話讀者仍不知所以。

### 【1108-0005】
1. **「須約前人悋護，計直定犯」**：譯成「依據對方吝嗇守護的**程度**，折算價值」，會讓人以為按吝嗇程度計價。應是「須就物主慳吝守護（之心），計算其價值來判定犯相」。
2. **「遙心敬者」**：指對**已滅度的佛（佛像）** 遙以心恭敬。譯文「心馳遙遠起恭敬心的人」對象不明，建議補出。
3. **「眼可對故」→「肉眼可以直接對視」**：「對視」是互看，應作「眼根可直接對境（面對面看到）」。
4. **「暗誦」→「暗中背誦」**：易誤讀為「在黑暗中背」，應作「不看經本而背誦」。
5. 「相例為問」宜作「以類比的方式提出疑问」。

### 【1108-0006】
1. **「並具通塞」**（重點）：改「佛、法二寶都兼具『通』與『塞（局）』兩面」。
2. 「得最大大功德」→「無上至大功德」，與前文「大功德／更大功德」的三階不對應，建議保留層級：「大功德／大大（更大）功德／最大大（最更大）功德」。
3. **「望守護者，餘人盜也」**：譯文「對待守護管理人來說，是其他人前來盜竊」語意不清。宜「所謂『望守護主結罪』，是就其餘的人來盜僧物而說」。
4. **「或無主掌，餘人亦同」**：「也是相同」未說同於誰，應補「也與『主自盜』的情形相同」。
5. 「互用」宜註明是**四種僧物彼此挪用**（互用罪）。
6. 「下局初位」→「第一種地位」：「位」是類位，宜「第一類（常住常住物）」。
7. 「據義則通」譯「**完全**可以相通」，「完全」是添加。

### 【1108-0007】
1. **「約名定體」→「確定體質」**（重點）：改「依名稱來確定它的體性」；0008「簡別其體質」同改「簡別其體類」。
2. **「故雙疊之」「故雙云也」**：譯文只說「重複疊加的名稱」，讀者不知疊的是什麼。建議明寫：第一「**常住常住**」、第三「**現前現前**」。
3. **「隨人分食」→「隨每個人分發受用」**：應是「隨**十方來僧**皆可分食」，這才是稱「十方」的理由。
4. 「人無定限」→「享受的人數沒有界限」：宜「受用者不限於現前僧（通於十方）」；「享受」用詞偏俗。
5. 「如下自明」→「正如後文自己所明示」不順，改「如下文自會說明」。
6. 「疏加米麵」的「疏」即《戒本疏》，與 0004 保持一致即可。

### 【1108-0008】
1. **「言縱一切集者……」**（重點）：建議全句改寫——
 「《僧祇》說『縱使一切（十方）僧全部集合，也不得分此物』，是怕有人以為：只在本界內的僧不可分，若十方僧統統集合起來就可以分，所以特別這樣說。」
2. **「有疑醫豉為熟物，判在十方者」**：改「有人誤認藥用豆豉是熟食，而把它判歸十方常住」。
3. **「作相同食」**：此處「作相」在律中多指**鳴犍稚（打板集僧）之相**，全句疑是「本擬供十方僧，作相集眾而同食」。譯文只作「共同飲食之用」，恐漏「作相」義，建議再核《戒本疏》《行宗記》相關文。
4. 「今以意分」譯「以意理來劃分」可，或作「今依義理來區分」，與 0006「鈔主義決」用語統一。

## 三、通用建議

1. **科文標記的譯法要統一**：「若下」「故下」「以下」是「『若』字以下」的省稱，譯成「從『若下』開始」等於把標記當引文，建議一律作「『若』字以下的文」。
2. **術語保留＋首次加注**：非人、護主／本主、捨墮（尼薩耆波逸提）、偷蘭遮（決斷）、方便／果本、火淨、互用、羯磨遮約、通塞——這些直接照抄或硬譯都會失真，建議首次出現時括注。
3. **節制添加語**：「完全、堂堂、肆意、徹底霸占、無上至大、當前」等原文無有，會悄悄改變判斷的輕重語氣，律學文字尤宜避免。
4. **注意「體」「色」「位」這樣單字術語**：不要順手組成現代複詞（體質、色相、地位），這是本份譯文最系統性的毛病。
