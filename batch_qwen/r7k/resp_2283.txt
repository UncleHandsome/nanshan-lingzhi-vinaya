整體看下來，這份白話譯文水準不錯，紀年（享保十六＝1731辛亥、十五＝1730庚戌）、干支別名（重光＝辛、大淵獻＝亥、相月＝七月）、地名（平城＝奈良、赤縣／震旦＝中國）都處理正確，文意大方向也通。以下按「該改」「宜存疑加注」「潤飾」三類列出問題。

## 一、意思有出入、建議修改的地方

### 1.「著教誡輕重之儀文」——很可能是兩部書名（最重要）
原文對仗極工整：

* 撰 **戒、業、行事** 之 **疏鈔** → 《戒疏》《業疏》《行事鈔》（譯文已正確譯出）
* 著 **教誡、輕重** 之 **儀文** → 應指道宣《**教誡（新學比丘行護）律儀**》與《**量處輕重儀**》

譯文作「教誡弟子、分別輕重犯相的儀軌文字」，把它泛化了；尤其《量處輕重儀》是講**亡僧遺物輕重分配**，不是「輕重犯相」，屬實質誤解。
建議：「撰著《教誡律儀》《量處輕重儀》等儀範文字」。

### 2.「反光前代」——譯文自相矛盾
譯文正文作「反照前代」，括號又說「使前代律學重光」，兩者意思不同。依下文「法雲**重**布」「玉毫**再**暉」，此處當是「使前代（律學）重放光明／光復前代之盛」。建議刪去「反照前代」，直取括號義。

### 3.「必過、未及現在人行之而證覺位」——「必」字漏譯
原文有肯定語氣「必」，譯文只作「都是」。
建議：「過去、未來、現在的人，**必定**都是依此而行，才證得覺位」。

### 4.「曾成如來使」——增譯過多
「曾親受如來囑託擔當使者」中的「親受囑託」是原文所無。宜作「曾是如來（所派遣）的使者」。

### 5.「玉毫再暉於東域」——「東方」易生歧義
「東域」與上句「震旦」對文，同指中國；作者是日本人，譯成「東方」讀者可能誤會為日本。建議「東土（中國）」。

### 6.「高弟大慈律師」——師承未點明
「高弟」承上文指**道宣門下**，譯文只作「高足弟子」，讀者不知是誰的弟子。另「乃為鈔記」宜作「於是為《行事鈔》撰作記文」，比逕稱《鈔記》清楚。

### 7.「及大智一出，則棄之而弗取」——主語與所指可再斟酌
上句「則**會正**為最」舉書名，此句「大智一出」也可解為「 **《大智記》（即《資持記》）一問世**」；且「棄之弗取」的主語應是**當時學者**，不是元照自己。
建議：「等到大智律師的《資持記》一出，學者便捨《會正記》而不取。」（或至少加注另一解）

### 8.「餘竊謂三本異卷者」——語氣不宜改成假設
原文是陳述事實，譯文加「若……」變成假設句。建議：「我私下認為，三本文本各自別卷流通，左右翻檢搜尋，難以即時查見。」

### 9.【0004】地名重複且過度具體
「和泉國泉州」語意重複（泉州即和泉國）；「今大阪府堺一帶」把泉州縮到堺，範圍過窄，萬代莊確址也未見交代。
建議：「泉州（和泉國，今大阪府西南部）萬代莊」。

## 二、宜存疑、加注，不宜逕下定解的地方

### 1.「玅布八品之方軌」
譯文照抄「八品」而未說明所指，讀者無從索解。《行事鈔》通行科判為三十篇，「八品」所指需查（是否指〈持犯方軌篇〉的品目科分，或底本用字有異）。**建議核對底本並加注，或標「待考」**。

### 2.「行事反隱也」
此句承「**戒業二疏**」而來，「行事」很可能指**行事作法**（羯磨實務），未必是《行事鈔》。譯文逕作「反而使《行事鈔》更為晦暗」，與上下文略有扞格。建議譯「反而使行事作法更加隱晦」，或並存加注。

### 3.「其止以美其作」
此句極晦，譯文「其止持之解恰恰用以成全其作持之法」是一種讀法（「恰恰」為添字），但另有讀法：「止＝有所不言／不為」「作＝著作」，即「他有所不說，正是為了成就其著作之美」——這與上句「無片言隻字未嘗有所本」也能連貫。建議**保留原句並加注兩解**，或標「疑」。

### 4.「三本異卷」
譯文定為「疏、記、科」，屬推測。合刻本常見的另一組合是「**羯磨本文＋疏＋記**」。既然序題只說「合刻疏記」，此處宜加注說明所據，不宜坐實。

### 5.「星紀」
十二次之「星紀」本對應丑，與「大淵獻（亥）」不合；此處顯然是泛指「歲次」。譯文處理正確，可加一注免得讀者起疑。（【0004】的「龍舍」同理，即歲星所舍＝歲次，可注。）

### 6.「渡海之舟航」
原文只作「渡海」，譯文加「苦海」是引申，可保留但屬增譯，宜自覺。

## 三、文字潤飾（不影響意思）

| 譯文 | 建議 |
|---|---|
| 生善的盛大／滅惡的重大 | 「就生善而言，最重大的莫過於受戒納體；就滅惡而言，最殊勝的莫過於懺除重罪」 |
| 法雲重新**密布** | 「密布」多用於烏雲，改「重新遍布／覆布」 |
| 文辭**窮極**、義理詳盡 | 「文辭最精、義理最盡」 |
| 所**珍寶**的唯有《記》 | 「所珍視的」 |
| 徒然塞滿**書卷緗帙** | 語意重複，「徒然充塞卷帙」即可 |
| 沒有隻言片字不具備出處依據 | 「字字句句皆有所本」更順 |
| 登上高樓的**梯蹬** | 「階梯」 |
| 用来指示指頭之外的明月 | 「如以指標月，令人因指見月（藉文字悟入言外之旨）」 |

| 屏棄 | 一般作「摒棄」 |

## 四、改寫示例（可直接採用）

**【0001】**
> 時值享保十六年（1731，歲次辛亥）七月十五日佛歡喜日（僧自恣日），平城（奈良）東大寺戒壇院長老住持比丘慧光恭敬題寫。

**【0003】關鍵兩句**
> ……直到我南山初祖道宣律師，曾是如來的使者，出興於中華赤縣，撰《戒疏》《業疏》《行事鈔》，著《教誡律儀》《量處輕重儀》等儀文，使前代律學重放光明。因此法雲重新遍布震旦，佛陀玉毫之光再度照耀東土。

> 唯有允堪律師曾撰集疏記，卻曲解引證、牽強附會，妄逞己意，反而使行事作法更加隱晦。

> 時值享保十五年（1730）歲次庚戌秋季僧自恣日（七月十五），通受（三聚淨戒）比丘禪龍敬書於泉州（和泉國，今大阪府西南部）萬代莊佛頂山金輪寺方丈室。
