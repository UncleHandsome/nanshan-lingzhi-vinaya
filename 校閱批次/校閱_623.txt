# 校閱材料　第623檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【623-0001】05_拾毗尼義鈔/04b_卷中之二#36
【原文】第四三性之義者言覔犯事皆通三性義準可知問不善犯中凡聖何異答凡夫遮性俱犯三果唯犯遮戒亦可凡夫犯廣略學人唯犯略十誦云凡夫通三性犯戒阿羅漢唯無記作四分亦似通善問四諍為善為不善答不善問若爾何故文云或善等耶答若據始心評理是非說作善後心乖惱即是諍今滅時滅諍不滅善言覔二諍中無記是善無記犯諍中無記是不善無記事諍中無記不定若言覔二諍中無記名善無記犯諍中事諍無記是不善無記問既言無記如何乃說王不善耶答論解不定此說微品善惡不能引於總報說為無記望感別報邊說善不善非謂泛爾無記心起故言無記問從三諍生事諍如何昔解若諍制言諍羯磨以七藥滅名言諍中事作若諍制覔諍中羯磨亦以七藥滅名覔中事作若諍制犯諍中羯磨亦同七藥滅名犯中事作若爾諍受日等羯磨何諍所收今解但使諍其一切已作百一羯磨道理是非事同見異者是言諍中事作若諍治人舉罪能舉證犯所舉諱犯不肯引過者覔中事作若前人羯磨惡心懈怠心者是犯中事作指事顯相品之差別廣如別章。
【譯文】第四、辨析三性的義理：言諍、覓諍、犯諍、事諍都貫通善、不善、無記三性，其義理準照常規可知。問：在不善的犯戒中，凡夫與聖人有何差別？答：凡夫遮戒與性戒都會違犯，三果聖人只會違犯遮戒；也可以說凡夫會違犯廣戒與略戒，有學聖人只會違犯略戒。《十誦律》說：凡夫貫通善、惡、無記三性犯戒，阿羅漢唯有在無記心時有所誤作。《四分律》中似乎也通於善心犯戒。問：四種爭諍本身究竟是善還是不善？答：是不善。問：如果是這樣，為何律文說「或善等」呢？答：如果依據最初評議道理是非的發心，可以說作善心；後續演變成乖違惱怒，就成了爭諍。現在滅諍之時，是滅除爭諍之惡，而不是滅除善心。言諍與覓諍中的無記心屬於善無記；犯諍中的無記心屬於不善無記；事諍中的無記心則不定。如果說言諍與覓諍中的無記稱為善無記，那麼犯諍與事諍中的無記就是不善無記。問：既然說是無記，為何又說通於不善呢？答：論典的解釋並不固定。此處是指微細品級的善惡，其力量微弱，無法引生總報的大業，所以方便稱為無記；但對照感召個別別報的層面來說，仍屬於善或不善，並非指一般泛泛生起的純粹無記心，所以稱為無記。問：從三諍中如何衍生出事諍？過去的解釋是：如果爭論那滅除言諍的羯磨，以七滅藥來滅除，稱為「言諍中之事」；如果爭論那滅除覓諍的羯磨，也以七滅藥來滅除，稱為「覓諍中之事」；如果爭論那滅除犯諍的羯磨，同樣以七滅藥來滅除，稱為「犯諍中之事」。若是這樣，爭論「受日」等一般羯磨，應收攝在哪一種爭諍？現在的合理解釋是：只要是爭論一切已作過的百一羯磨法事，其道理是非、所爭之事相同而見解判定相異者，屬於「言諍中之事」；如果是爭論治罰人、舉發罪過，能舉發者指證犯罪，而被舉發者隱諱罪行、不肯引咎認錯，屬於「覓諍中之事」；如果在前人主持羯磨時心懷惡念、懈怠放逸，屬於「犯諍中之事」。各別指陳具體事由以顯明行相與品級差別，詳細內容如別章所明。

【623-0002】05_拾毗尼義鈔/04b_卷中之二#37
【原文】第五定諍多少者如律中云或有言即是言諍或有言非言諍或有言諍即是言或有言即是諍或有言非諍或有諍即是言或有諍非言廣如彼說此中首解諍有二種初言單諍者因其論義兩情乖背無伴勢者是名單諍以是義故或有言者舉單言即言諍者是單諍或有言者舉單言非言諍者非單諍是往復單言恐此單言諍濫餘三諍故須簡言或有言諍即言者謂是言諍非三諍後言重諍者兩人論義執情致鬬復有餘人即伴勢力自重諍故或有言即是諍是初總顯也或有言非諍者或有諍即是言者正是重諍恐此重生諍謂是餘三諍故須簡之或有諍非言諍謂是餘三諍犯覔等諍準此類解故律不論廣如首解。
【譯文】第五、判定諍端相狀的多寡：正如律中所說：或有言語即是言諍，或有言語並非言諍；或有言諍即是言語；或有言語即是諍，或有言語並非諍；或有諍即是言語，或有諍並非言語，詳細內容如該律所載。對此，首師解釋爭諍有兩種：最初所說的「單諍」，是指因為討論法義，雙方心意相左，各自沒有同黨聲援者，這稱為單諍。基於此義，所謂「或有言語」，舉出單純言辭即是言諍者，是指這種單諍；所謂「或有言語」，舉出單純言辭而非言諍者，是指不構成諍事的言辭，只是往復問答的單純言語；因為擔心這種單純言語的諍執會與其餘三諍相混淆，所以必須加以揀別。所謂「或有言諍即是言語者」，是指純屬言諍、而非其餘三諍。後面所說的「重諍」，是指兩個人論議法理，各執己見而引發爭鬥，又有其他人加入作為同黨聲援，使諍事轉為嚴重；所以「或有言即是諍」，是最初總括開示；「或有言非諍者」，以及「或有諍即是言者」，正是指這種重諍。因為擔心這種嚴重的諍執會被誤認為是其餘三諍，所以必須加以揀別。所謂「或有諍非言諍」，是指其餘三諍——犯諍、覓諍、事諍等，準照此類推理解，所以律文不再贅述，詳細如首師所釋。

【623-0008】05_拾毗尼義鈔/04b_卷中之二#43
【原文】此之三軸名拾毗尼即集義鈔也國初南山祖師述助釋行事鈔矣于時艸藁纔成新羅僧之所竊歷今二百餘載不覩其文去會昌五年春幸因大檀越李侍御字元佐附海東金舍人於本國求之蒙彼國王城慧明寺。
【譯文】這三卷著作名為《拾毘尼》，也就是《集義鈔》。唐朝初年南山律祖撰述此書，用以輔助解釋《行事鈔》。當時草稿剛剛完成，就被新羅僧人竊取帶走。歷經兩百餘年，在中土未曾得見其文。直到往昔會昌五年春季，幸逢大護法檀越李侍御（字元佐），託付海東金舍人前往新羅尋求此書，承蒙該國王城慧明寺寄還。
