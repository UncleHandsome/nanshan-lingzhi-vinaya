# 一、《四分律刪繁補闕行事鈔序》（作者自序）

### 【戒德之超勝與末世風氣之慨嘆】
戒律的功德不可思議，超越一切世間森羅萬象；它是人、天、聲聞、緣覺、菩薩等「五乘」修行的軌道與指引，更是佛法僧三寶住世渡人的舟航！依照戒律立基修行，定與慧的功用便無與倫比；佛法的住持與弘傳，使一切經論在此都退讓高唱，唯推戒律為最勝根本。

自佛陀在世時，便特別弘揚這部律典；及至後世傳法的「四依大士」，這份遺風始終未曾改變。到了像法末季，時代風氣轉為澆薄虛偽；人們多在脣舌之間爭勝競鋒，熱衷於議論玄虛無形的事理。因此，震嶺（震旦）傳下的教法雖歷經九代，能超群拔萃的，也不過是憑藉文辭才智而已。若要彰明行儀軌範、匡正攝持像法；垂立準則以訓導末學；接續已斷絕的玄妙綱領、扶起已傾頹的法幢標幟，這實在值得詳細評議。難道不是因為空談虛理容易憑藉口舌文字發揮，而落實於日常行事卻難以成辦、能持守如露水般潔淨無瑕的人實在太稀少了嗎！

### 【前代律記之流弊與本作宗旨】
然而，前代大德依託律藏，指陳行事、引證律文來運用；文句固然多屬如實的聖教記錄，但所依託引用的因緣卻頗有繁瑣氾濫之弊。加之學者學問不夠精深博通，主觀臆測之說特別多；歸納類比少有深究討論，平素種種異見遂雜然並存。以致在分析行事過咎時產生矛盾，判罪輕重顛倒；僧團綱紀的維持、同異的分判，也都亂了準則。若非能貫通整個如來教法之廢立興替、詳考諸家學說虛實之人，誰能為後人破除重重疑惑、遣除整體滯礙、綜括各派部執，並清晰闡明戒行的行相呢？

我常遺憾前代諸師所留下的著述，大都僅停留在文疏義理的取捨廢立、問答式的綱要節錄；至於能彰明世間實務操作、為後學立下行為軌範的著作，百部之中沒有一部。偶爾有人立志著眼於實務行事，其材料卻散見於各家文集義海中；或者文章多浮辭冗句，不足以契合實用之機；或者僅僅標列羯磨條目，而具體的儀軌成相卻未加說明。後人照著文字去操作，往往辨不清這羯磨到底該用在什麼事上；而且篇章碎亂無序，根本無從查考檢索。因此，求學之人若非長年積累學識便無從知曉；領會之人若非精研深練亦無法透徹通達。

我趁著聽法講授的餘暇，瀏覽歷代諸家論篇；對於那些未能切合宗旨的著述，心中已衡鑑出其優劣長短。於是奮發執筆，暢然直抒己見。本書廣泛包羅了其他部派的真實文獻，統括各部經典的隨宜說法，以及西天聖賢所遺留的典籍、此方先德的碑誌文記；全面搜求考訂其同異，窮究辨核到底。凡有卓越見解必定收錄，以輔助讀者廣博見聞；凡屬虛浮氾濫之說必定刪削，以成就圓融通達的義理。

在行文上，有的詳細敘述以彰明實務應用，有的簡要提點以便歸納同類；有的引文看似中斷而義理相連，有的則假設問答以辨析義理。如此始終相映照，隱現互為表裡。同時，將現行的羯磨作法、各項僧務的是非、引導俗人的法儀、僧團內部的雜法細則，全部總攬為南山一宗的定見，藉此省去後學摸索的枉費工夫！

### 【繁簡折衷與三卷架構】
贊同我的人，欣賞我抓住了大綱要領；持異議的人，則嫌我這部鈔文辭太繁。然而文辭繁複，難道是我喜歡的嗎？實在是臨事所需，不得已啊！為什麼呢？若過於簡略而只取大綱，臨事操作往往不足；若橫生枝節評議無關緊要的話，對一部「鈔」書而言便成了大忌。

如今我權衡折衷、力求適中，務使內容兼顧精簡與完備；既能救急於臨時，又備詳於倉促之間，因而勒編成上、中、下三卷。如果思慮未能周全於一切當代行事，在實務行持的闡發上固然有所缺漏，我也先略標旨趣綱要，以待後人繼續增廣。

整部書的義理展開為三個層次：

* **上卷**：總攝僧團大眾的事務，使一切作法成辦皆有軌度儀範；
* **中卷**：遵循受戒之戒體，辨析持戒犯戒的界限並確立懺悔法門；
* **下卷**：隨順個別機緣的重要行持，托附於各項具體事物而生起。

全書如文中所詳，想來不致紊亂；但行事境界實在繁多，確實難以分類擬定。如今將性質相近者歸為一類，冠於篇首；更唯恐綱目條流尚未詳盡，特以「十門」來總括全書大綱，使人能如明鏡映照般徹底通曉全書的幽遠宗旨。

### 【十門大綱詳釋】

#### 第一、序教興意（說明制教興起之意旨）
至聖佛陀出世，利益眾生自有善巧法度；隨順眾生根機施設教化，在法理上絕無虛設。論典說：「依大慈悲門，宣說毘尼（戒律）。」律典也說：「世尊因慈念一切眾生，故為之說法。」第二，是為對治外道自誇無拘束而自居勝境，彰顯佛法之尊貴崇高，因此制定禁戒。縱觀律中所制各條，都蘊含有破除外道邪術之意，故律文說：「若不結集戒律，將招致外道的毀謗閒言。」第三，是為了與其他宗派部派區別而來。部派各有不同：如薩婆多部（說一切有部），其戒本繁簡不一，所指的戒體不夠圓融；引導俗人過於拘泥於時限刻數，律法的運用通融卻往往失去標準。如今我們所依的曇無德部（四分律），人與法皆井然有序，軌範用法周全兼備；教化引導唯以啟發善心為宗，立教宗旨顯豁而約要。

上面是通論教法之興起，現在依本宗進一步辨明：
教法絕非孤立而起，必因人而施設；人的根性既各不同，教法也就非止一種。因此攝受教導、弘濟眾生的法則實在很多。最寶貴的是掌握其根本宗旨，因為要窮究其細微枝末實屬不易。所以從「開緣」與「制止」來檢驗，可知其宗旨全在於利益人；從辨明「持戒」與「犯戒」來看，其深意在於令人不再造過。今將整部律藏濃縮為五個面向來分析，教法興起的深意便清晰可見：

1. **以遮戒與性戒來分**：性惡（殺盜淫妄等自性罪）通於教化的一般世間道德與律制；遮戒（佛陀因特定過失而遮止的行為）則是因事制宜。然而性戒在文字上看似有開緣，但實質上極其嚴格，因為即使在開緣情況下仍易結犯，縱使持守也很難做到清淨無染（如淫戒要求三時無樂受，毀謗戒要求始終懷慈悲救護心；凡夫既有根本貪瞋，如何能禁制心念毫不放逸？可知性戒重在急迫守護心意）；而遮戒通常是一概制止，若有利益時便開許，開許後若滋生流弊，又重新制約。這難道不是為了隨順教化世俗、深怕眾生失足墜入陷阱嗎？大慈悲佛陀施設教法，意在檢點眾生的過失，所以《毘尼母論》具體確立了「緩」與「急」兩套準則，令人循此貫通融會。
2. **從開遮制止來推求**：教法貫通於如來在世與未來二世。故律文說：因世尊是一切智人，故制戒後又因緣開許，開許後又隨機再行制止，這是通於未來世的教法。《五分律》亦云：「雖是我所制定的戒，在其他地區若不被視為清淨合禮的，就不應施行；雖非我所制定的規矩，但在其他地區若是非實行不可的，就不得不行。」這是佛陀在世時的靈活教導。兩種原則相互融通，彼此涵蓋。
3. **因眾生依報與根性有強弱**：教法也隨之有嚴格與寬許之分。就制定戒律而言，有深防重禁與界限劃分；就具體實行而言，住山林與處塵世亦各不相同。
4. **以根機領悟為優先**：教門的輕重因而產生隔閡，小乘五部各執所見，難道不正是這個原因嗎？
5. **以「事」與「法」相對待**：法只是軌範儀式，違背了宗旨則作法不成立；事則通於人情性格，所以必須隨境緣來裁定其得失。戒條的生起，或依託於善、惡、無記三性之緣，或隨世間人的譏嫌而制定。

以上略舉數條，使讀者稍知端倪。總括而言，無非是為了拯拔救度凡庸眾生、心懷涅槃解脫而興起教法！所以律文說：「世尊為何制定增上戒學？為了調伏三毒！為何而學戒？為了證得四沙門果！」以下各門中所述之制戒之意，僅隨具體事項解說，使後學能由條文探究其根本。
