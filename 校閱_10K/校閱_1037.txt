# 校閱材料　第1037檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1037-0001】資持記/05c_上四#3
【原文】故舍利弗欲於佛所安居，十七日至，制後安居；據相以言，但前一日為前安居，餘三十日為後安居；莫不望初俱名後故，則缺中也。下指結文，三法別故。次科。標云泛明者，此中正明安居前後；而下三門名同事別，以類相從，故云泛也。初中。是前下，合云得受五利名賞。
【譯文】因此舍利弗想在佛陀處所安居，到了四月十七日才趕到，佛陀便為他制定後安居；若就事相而言，僅僅前一天算是前安居，其餘三十天都算作後安居；這無非是因為相對於一開始的初日而言，後面全部都稱為「後」，因此便缺落了中安居之名。下文指出作法的結文，乃是因為三種法各不相同的緣故。下一個科判，標題稱為「泛明（廣泛說明）」者，是因為此處原本主要在說明安居的前後時段；然而下面三門只是借用相同的名稱而事相各異，將其依同類歸納在一起，所以稱為「泛」。在第一項中，「是前」等語，文意應當接續為：能夠獲得五種利養，稱為賞賜。

【1037-0002】資持記/05c_上四#4
【原文】結者下，合云是後；上下相映，在文省約。二中，初明前不結有犯不犯。十六日下，明後不結皆犯。除難事者，示開緣也。尼同別者，簡通濫也。同謂同前，別即別後；以尼外化義少，不許遊涉，故重於僧。三中，初明前者。乃至後夏不結者，雖未暇加法，而身已在界，故並成前坐。
【譯文】「結者」等語，文意應當接續為：這屬於後安居；上下文字相互呼應，在文筆上力求簡省約要。在第二項中，首先說明前安居若不結夏，何時有犯、何時無犯。「十六日」以下，說明後安居若不結夏則統統犯戒。「除難事者」，是在明示開許的特殊因緣。「比丘尼同別」一句，是為了簡別並防止相濫。所謂「同」，是指同於前安居；所謂「別」，是指後安居另有不同；這是因為比丘尼向外教化的意義較少，不被允許隨意外出遊行，所以戒律對她們的限制比僧眾更為嚴格。在第三項中，首先說明前安居的情形。乃至於到了後夏仍未結夏的人，雖然還沒來得及加行作法，但身體已經在結界之內，因此都算作成辦了前安居。

【1037-0003】資持記/05c_上四#5
【原文】是名下，謂結夏日異，受歲日同。前一月中，隨日可結，故云三十日安居也。問：難事不息都不結者，為得夏否？答：疏云：或五日三日乃至一月，雖不結之，不失前坐；以難不結，非是故心。若下，明後。以後安居人本是八月十五日夏滿，聽隨前安居人探前自恣。
【譯文】「是名」以下，是指結夏的日期雖然不同，但受歲自恣的日期卻是相同的。在夏初的一個月內，隨哪一天都可以結夏，所以稱為「三十日安居」。有人問：如果災難阻礙一直沒有平息，完全不曾作法結夏，究竟算不算是獲得了一夏？回答說：《業疏》指出：即使耽誤了五天、三天，乃至一個月，雖然不曾作法結夏，卻不會失去先前安居的資格；因為這是由於災難而未能結夏，並不是出於故意放逸之心。「若」字以下，說明後安居的情形。因為後安居的人原本應當在八月十五日夏滿，律中開許他們跟隨前安居的人提前進行自恣。

【1037-0004】資持記/05c_上四#6
【原文】令由難阻隨息開作，故通一月；此即結夏日同，受歲日異。問：前中二種，有難開否？答：準理應通。若爾，律中有難開增自恣者？答：彼是外界鬪諍，此即王賊等阻障；俱號難緣，名同事別。上三前後，初賞罰，以前安一日為前，後三十日為後。次得罪中，以前三十日為前，後安一日為後。
【譯文】為了因應災難阻礙、隨其平息而開許作法，所以時間通達整整一個月；這便是結夏的日子相同，而受歲自恣的日子互異。有人問：在前安居與中安居兩種情況下，遭遇災難時也有此類開許嗎？回答說：依照義理推敲應當也是通用的。如果真是這樣，律中為何又有遭遇災難而開許增加自恣日期的規定呢？回答說：那是因為界外發生了鬥爭，而此處則是指遭遇官府、盜賊等阻礙；雖然都稱為難緣，卻是同名而事相各異。以上三種前後：第一種賞罰，是以前安居的一天為「前」，其後的三十天為「後」。第二種結罪，是以開始的三十天為「前」，最後安居的一天為「後」。

【1037-0005】資持記/05c_上四#7
【原文】三難事中，即約安恣互明前後。疏有六種。三種同前。第四位約前後，初後兩夏各十六日，中間二十九日。五明行住〔住謂舊住，行即外客。〕，對念二法，行住通用；忘成及界，以是行人，先有要故。〔又云：必舊有要，例亦開之。〕六據法不同，對念作法，以容預故。
【譯文】第三種難事之中，則是綜合安居與自恣的關係互論前後。《業疏》中列出六種情形。其中前三種與前面所說相同。第四種位次是就前後兩夏而言，初夏與後夏各有十六天，中間則有二十九天。第五種是說明行路人與定居者（「住」是指原住僧眾，「行」則是指外來客僧），面對面作法與心念作法這二種法，行路人與定居者皆可通用；至於忘記而自然成夏以及跨入界內，乃是因為此人身為行路者，先前心中已有確定的期約（疏中又說：如果原住僧人本來就有明確期約，依例也可獲得開許）。第六種是依據作法性質的不同：面對面與心念作法，因為時間較為寬裕從容；

【1037-0006】資持記/05c_上四#8
【原文】忘成及界，恐乖前後，直爾便得。〔準疏後亦加法。〕夏閏中。標云延促者，依閏為延，不依名促；又閏中三例，住日多少，延促可尋。依閏中三，初示文闕。比下，二取例。比即是例。前引論文。彼云：若閏四月者，則取前四月受雨衣，滿百二十日，故知含閏在其間矣。
【譯文】若是忘記而成夏以及剛跨入界內，唯恐違背了前後的時限，所以當下直接便算成辦（依照《業疏》，事後仍然需要補作加法）。在論述「夏閏（閏月）」之中，標題所說的「延促（延長或緊縮）」，依照閏月而坐夏便算延長，不依閏月便算緊縮；再者，在閏月之中有三種條例，安住日數的多少，其延長或緊縮皆可從中推尋。在「依閏」的段落中有三小節：第一節說明律文的缺漏。「比」字以下是第二小節，取為類例。「比」就是依例之意。前面曾引述論部之文，該處記載：如果是閏四月，就取前四月來受納雨衣，滿一百二十天，由此可知閏月是包含在其中的。

【1037-0007】資持記/05c_上四#9
【原文】彼下，以開況制。開緩尚依，制急宜準。又下，三釋疑。疑云：閏是虛坐，既非正月，閏中出界，應不破夏，何須坐閏。故此通之。今明依閏雖經四月，閏不在數，但恐間絕三月實夏，故依之耳。次不依中，初標示。摩下，引據。安居已作閏者，顯是初結未知有閏，故通數滿。
【譯文】「彼」字以下，是以開許之法來比況制定之法。寬緩的開許尚且要依從閏月，緊迫的制定更應當準照辦理。「又」字以下是第三小節，用來釋疑。有人懷疑說：閏月是虛設的月份，既然不是正月份，那麼在閏月期間走出界外，應該不算破夏，又何必一定要坐閏月呢？因此此處為之融通說明。現在闡明：依從閏月雖然歷經了四個月，閏月本身不算在實數內，只是唯恐中斷隔絕了三個月真正的夏安居，所以才依從它罷了。接著在「不依閏」的段落中，首先列標提示。「摩」字以下，引述典據。「安居已作閏」這句話，顯示出一開始結夏時並不知道有閏月，所以通融算滿九十天即可。

【1037-0008】資持記/05c_上四#10
【原文】下明受衣，言成受者，以不依閏數日滿故。言不成者，或有依閏日未滿故。謂下，對釋可解。兩判中，初句指前文。《多論》唯明依閏，《伽論》文通兩位，故云兼具。次句明雙用。夏下，正判；初明須依。謂先知有閏，宜從《多論》，不得不依。故不取《伽論》。若下，次明通依不依。
【譯文】下文說明受功德衣，所謂「成受（成辦受衣）」，是因為不依閏月而天數已經算滿了；所謂「不成受」，則是因為有人依閏月而天數尚未算滿。「謂」字以下，加以對比解釋，義理容易理解。在雙重判斷中，第一句是指向前面的律論文字。《薩婆多毘尼毘婆沙》（多論）只說明依閏，《伽論》的文字則通於依與不依兩個層面，所以說兩者兼具。次句說明兩論皆被採用。「夏」字以下進行正判：首先說明必須依從閏月的情形。如果預先知道有閏月，應當依循《多論》，不得不依從它，所以不採用《伽論》之說。「若」字以下，接著說明通於依與不依的情形。
