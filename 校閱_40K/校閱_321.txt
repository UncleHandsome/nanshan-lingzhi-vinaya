# 校閱材料　第321檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【321-0001】資持記/15d_下三#15
【原文】開鉢水棄白衣舍，以無飯故。第八《僧祇》，初制相待。唯據上座。狼䟺，彼獸性暴，取喻急速；䟺字，補蓋反，或作狽。又下，次明餘食。恐謂僧餘，不應與俗。準此明開，寺中應閉。次科。經中行水，謂別器盛貯，以備食時滌手，食訖澡漱。不同今時洒手而已。仍引《雜含》，證用澡漱。九中，初科。
【譯文】開許將洗缽水潑灑在俗人家中，因為水中沒有米飯殘渣的緣故。第八段中，《摩訶僧祇律》首先規定應當互相等待進食完畢。這項限制唯獨針對上座。「狼䟺」中，那種野獸性情暴躁，在此是用來比喻進食急促忙亂；「䟺」字的發音是「補蓋反」，有時也寫作「狽」。自「又」字以下，接著說明剩餘食物的處理。有人恐怕誤以為僧人剩餘的飲食不能給予俗人。依照此處律文說明是可以開許的，但寺院內的常住食物則應嚴加閉守。下一科，經文所說的「行水」，是指用另外的器皿盛裝淨水，以備進食時洗手、吃完後漱口清潔之用。這與現在隨便灑幾滴水在手上的做法完全不同。文中接著引用《雜阿含經》，證實確實是用來洗手和漱口的。在第九段中，第一科說明：

【321-0002】資持記/15d_下三#16
【原文】達嚫大嚫，梵言少異，亦云檀嚫。此翻財施，謂報施之法，名曰達嚫。文約施衣，準應不局。〔世謂以財𭣋食，故名嚫者，不識華梵。又召說法為施財者，並非。〕問：為召施物，為目說法？答：據名召物。今謂行施之時，必為說法，因名說法，以為達嚫。準理具云達嚫說法，事義方全。
【譯文】「達嚫」或「大嚫」，梵語音譯略有差異，也稱為「檀嚫」。此詞翻譯為「財施」，指酬報施恩的法式稱為達嚫。律文雖然是就布施衣物而言，但準照法理，其適用範圍並不局限於衣物。（世俗以為是用財物來貼補襯附飲食，所以稱作「嚫」，這是分不清華語與梵語的謬誤。又有把出家人的說法稱為布施財物，這同樣是不對的。）有人問：這個詞究竟是稱呼布施的物品，還是指稱說法？回答：單就名詞本身而言是指布施的物品。但我們現在認為行施的時刻，必定伴隨著說法，因而順帶將說法稱作達嚫。準照法理而言，應當完整稱為「達嚫說法」，這樣事相與理義才算齊備。

【321-0003】資持記/15d_下三#17
【原文】問：此與呪願何別？答：約事似同，究義須別。呪願則別陳所為，達嚫則通為說法；今或營齋，事須雙用。次科，初引緣起。一令生疑，二令起謗。檀越，亦云檀那，並訛略也；義淨三藏云：具云陀那鉢底，此翻施主。佛下，次引佛制。注文指上，即若為利故施等偈。
【譯文】有人問：這與「祝願」有何差別？回答：就外在事相來看似乎相同，但窮究其內在涵義則必須加以區分。祝願是個別陳述所祈求的功德方向，達嚫則是通貫普遍地為眾人說法；現在若是營辦齋會，兩者必須兼併運用。下一科首先引用制戒的緣起。一是為了避免信眾心生懷疑，二是避免招惹世人毀謗。「檀越」也稱為「檀那」，都是梵文的音訛或省稱；義淨三藏說：完整的梵文是「陀那缽底」，中文翻譯為「施主」。「佛下」接著引用佛陀的制約。注文指涉上文，就是指「若為利故施」等偈頌。

【321-0004】資持記/15d_下三#18
【原文】說時餘聽去者，有緣須往，無緣應住。三中。四益，前二利己，後二利他。四中。契經修多羅，華梵各出。種種義者，令隨機而舉。開撮文者，不必盡誦也。五中，《五分》簡德，初引緣。破戒無行，邪見無慧，根不具無威儀。惡人得勢，謂假此興謗。佛下，立制。
【譯文】說法的時候開許其餘僧眾先行離去，是指有要事者必須前往，若無要事則應留下來聽法。第三段內容中提到四種益處，前兩種利益自己，後兩種利益他人。第四段中，「契經」與「修多羅」，是中文與梵文的並列對稱。「種種義」是指讓說法者能夠隨應聽眾根機而靈活開示。開許「撮要而講」，是指不必將經文從頭到尾完全背誦完畢。第五段中，《五分律》甄別說法者的德行，首先引用緣起。破戒者缺乏德行，邪見者缺乏智慧，諸根殘缺者缺乏威儀。所謂「惡人得勢」，是指惡人會藉此挑起譏嫌與毀謗。「佛下」確立制度規範。

【321-0005】資持記/15d_下三#19
【原文】《伽論》選能。文明誦唄，例準說法，必取堪能。六中，初標律偈。《增一》下，引解。初句即身口二業，次句心業，三是正慧，四即正信。七中，初斥世。若下，次勸說。準《五分》者，即呪願中引云四足汝安隱等。華侈，謂綺飾之詞；侈，尺紙反，奢也。十中。八人即留兩眾，餘開前去，同上有緣。
【譯文】《薩婆多部毘尼摩得勒伽》要求選拔有才能的人。律文表面上雖指誦經唱唄，依此類推到登座說法，也必定要選取具有相應能力的人才。第六段中，首先標出律藏中的偈頌。「《增一》下」引用經義進行解釋。第一句對應身、口二業，第二句對應意業，第三句是指正智慧，第四句就是指堅固的正信。第七段中，首先斥責世俗的弊病。「若下」接著勸勉應當如法說法。準照《五分律》的意旨，就是在祝願中引用「四足汝安隱」等語句。「華侈」是指浮華綺靡的修飾言詞；「侈」的讀音是「尺紙反」，意思是奢侈誇大。第十段中，「八人」是指留下僧、尼兩眾各四人，其餘僧眾則開許先行離去，這與前面有要事離去的情況相同。

【321-0006】資持記/15d_下三#20
【原文】貧道，亦云乏道，皆謙收之稱。今僧受齋，但知飽食接嚫而已。律儀法度，無一可觀。將何發彼善心，消他信施，悲失！次科。引經佛在說法，令後倣之。晡即申時。24 釋導俗篇(下三)釋導俗篇導，謂能化之法；俗，即所化之機。以法接機，必遵正教；備舒軌度，故曰化方。
【譯文】「貧道」也稱為「乏道」，都是出家人自謙退讓的謙稱。現在的僧人應邀受齋，只知道飽餐一頓和收取利養而已。舉手投足間的律儀法則，沒有一樣拿得出手。這將憑藉什麼來啟發信眾的善心、消受他人的信施供養呢？實在太令人悲嘆慚愧了！下一科引用經典說明佛陀在世時的說法儀軌，令後世弟子依循仿效。「晡」就是申時（下午三點至五點）。第二十四篇「釋導俗篇」。「導」是指教化引導的法門；「俗」是指被教化的世俗機根。用法門去接引根機，必須完全遵從佛陀正教；其中詳盡展現了各種軌範度數，所以稱為「化導之方」。

【321-0007】資持記/15d_下三#21
【原文】來意中，初科，前四句通標。影逐形生，響由聲發；形影聲響，不可相離，故取喻焉。形別可解；言法別者，或約戒釋，或約福智二分釋；或可世出世教，制法不同。所趣同者，謂道修解脫因，俗結解脫緣；行分遲速，求脫不殊；或可同歸三寶，共弘正化，而為所趣，頗合下文。
【譯文】在說明「來意」的內容中，第一科的前四句是通盤標明大旨。影子隨著形體而產生，回響由聲音震動而發出；形體與影子、聲音與回響，是絕對無法分離的，所以以此作為比喻。出家與在家在外形上的差別容易理解；至於說「法制差別」，可以從戒律層面來解釋，或是從福德與智慧兩方面來解釋；也可以說是世間法教與出世間法教的制定規則互不相同。所謂「所歸趨的方向相同」，是指僧道修持出離解脫之因，俗人結下解脫之緣；兩者修行步調有快慢之別，但追求解脫的目標沒有不同；又或者可以說雙方同歸三寶、共同弘揚正法，這正是彼此一致的歸宿，相當契合下文的意涵。

【321-0034】資持記/15d_下三#48
【原文】阿難問佛，何緣微笑？佛言：是老女人，施佛食故；十五劫中，天上人間，受福快樂；後得男子，出家學道，成辟支佛。受億耳羹句絕，彼云：沙彌二十億耳，以好羹上佛；佛以殘與頻婆裟羅王，是知佛受已，與則得食，不與則不能消；復次為佛設食，佛未食，人不能消；已食殘者，佛與能消。
【譯文】阿難尊者請教佛陀：「世尊今日以何因緣而現微笑？」佛陀說：「是因為這位老婦人以至誠心供養佛陀食物的緣故；她在未來的十五劫之中，將輾轉流轉於天上與人間，常享富貴福報與安樂；最後一世將轉生為男子，出家精勤修學聖道，最終證得辟支佛果。」引文在「受億耳羹」一句劃分斷句，該論記載說：二十億耳沙彌，曾以極美味的羹湯奉獻供養佛陀；佛陀將吃剩的殘羹賜給頻婆娑羅王，由此可知只要佛陀先納受了，再賜給他人便能消化吸收，若佛不賜予則不能消受；換句話說，專為佛陀備辦的精緻飲食，若佛陀尚未動用，凡人吃了無法消受；若是佛陀已經吃剩的殘食，經佛陀賜予則他人便能消受。
