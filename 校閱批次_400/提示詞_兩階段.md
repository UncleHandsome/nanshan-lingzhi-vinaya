# 校閱提示詞．兩階段版

## 材料格式

```
【03-0150】資持記/01c_上一上#18
【原文】…
【譯文】…
```

- `03-0150` 是全域編號（檔號-序號），全書唯一。
- `資持記/01c_上一上#18` 是真實位置。
- **兩者都要原樣照抄**，不可只寫「段150」，不可自行重編。

---

## 第一階段：掃描（每段都要給判定）

把整檔逐段看過，對**每一段**輸出一行，不要只挑有問題的：

```
03-0150 OK
03-0151 P1 術語
03-0152 P0 漏譯
03-0153 OK
```

判定代碼：

| 代碼 | 意思 |
|:--|:--|
| `OK` | 這一段沒問題 |
| `P0` | 嚴重：意思相反、漏譯、張冠李戴、律制事實錯 |
| `P1` | 術語、名相、因果理解偏差 |
| `P2` | 標點、體例、錯字 |

類型可省略，但 P0/P1 要寫一行類型（例：`P0 漏譯`）。

**要求**：輸出行數必須等於材料段數。少一行就代表有一段沒看。

---

## 第二階段：深究（只針對第一階段標記的段）

對每個非 OK 的段，輸出完整替換文字：

```
### 03-0151｜資持記/01c_上一上#19｜P1｜術語
原文：（照抄材料原文）
現譯：（照抄材料譯文）
問題：一句話說明錯在哪
建議：整段白話（可直接取代現譯，其餘文字與現譯相同）
```

規則：

1. 「建議」必須是**完整段落**，不是「A 改 B」的片段。
2. 除問題句外，其餘文字與現譯逐字相同。
3. 不加譯者按語、不寫「本段大意」、不改段數。
4. 原文、現譯必須從材料**複製**，不可重打。

---

## 為什麼這樣做

- 第一階段輸出小，但能證明整檔都被看過，不會只回報最顯眼的幾條。
- 第二階段直接給整段替換，程式可 100% 套用，不會因為引錯一個字而失敗。
- 兩階段分開，AI 不必同時做「找錯」與「改寫」，品質較穩。

## 一次跑多少

- 每檔 400 段，單一書。
- 第一階段與第二階段可以同一個對話跑（先掃描、再深究），也可以分開送。
