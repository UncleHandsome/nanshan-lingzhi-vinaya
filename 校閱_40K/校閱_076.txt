# 校閱材料　第076檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【076-0001】02_戒疏/02a_卷一上之二#27
【原文】【記】釋佛為二，初翻名。梵名有七，或云「沒陀」，或下加「耶」字。「具」下，次釋義。「覺察」義中，「煩惱障」不出十支，總為見思。三界見惑，麤故易斷，合為一住；三界思惑，微細難破，離之為三：故為「四住」。此障凡夫不覺，二乘同斷。「覺悟」義中，「無明」一住，通號無明，別分事理。初、「迷事」者，障俗諦故。世出世法，唯佛通達，名「如量智」，故能開覺一切眾生。故云「三趣」，謂人、非人、畜，總收六道，竝是所覺，此謂「覺他」也。二、「迷理」者，障真諦故。法性真理，唯佛盡證，境智相冥，名「如理智」，此即「自覺」也。然此二覺，二乘不覺，菩薩分覺。後二句總結。「通而獨悟」，唯局果人，此即覺行滿足也。《佛地論》云：「具一切智、一切種智，離煩惱障及所知障。於一切法，一切種相，能自開覺，亦能開覺一切有情，如夢睡覺，如蓮花開。故名為『佛』。」更欲委辨，非宗且略。
【譯文】【記文】解釋佛陀分為兩部分，首先是翻譯名稱。梵文名稱有七種發音，有的稱為「沒陀」，或者在字尾加上「耶」字。「具」字以下，接著解釋其字義。在「覺察」的義理中，所謂「煩惱障」不出十種根本煩惱，總括為見惑與思惑。三界之內的見惑，相狀粗顯所以容易斷除，合併稱為一住地；三界之內的思惑，幽微細密難以破除，分別劃分為三種住地：所以合稱為「四住地」。這種障礙凡夫毫無自覺，二乘聖者則與佛同樣加以斷除。在「覺悟」的義理中，所謂「無明住地」通通稱為無明，又各別區分為事障與理障。第一、所謂「迷事無明」，是因為障礙了俗諦的緣故。對於一切世間法與出世間法，唯有佛陀能夠徹底通達明了，稱為「如量智」，因此能夠開導覺悟一切眾生。疏文說「三趣」，是指人道、非人（天、修羅、地獄、鬼）、畜生道，總體收攝了六道輪迴，這些全都是佛所開悟的對象，這就是所謂的「覺他」。第二、所謂「迷理無明」，是因為障礙了真諦的緣故。諸法本性的真空真理，唯有佛陀能夠究竟證得，所照之境與能照之智冥合為一，稱為「如理智」，這就是所謂的「自覺」。然而這兩種覺悟，二乘聖者皆未能覺悟，菩薩則隨分有所覺悟。後兩句則是總結。「統貫一切而能獨自徹悟」，唯有局限於究竟佛果之人，這就是覺行圓滿具足。《佛地經論》說：「具備一切智與一切種智，徹底遠離煩惱障與所知障。對於一切諸法及其所有差別行相，自己能夠徹底開覺，同時也能開導覺悟一切有情，就像從夢境長睡中醒來，又如蓮花盛開無垢一般。因此稱為『佛陀』。」若還想更詳細地辨析，因為不屬於律宗本門所以暫且略過。

【076-0002】02_戒疏/02a_卷一上之二#28
【原文】【疏】所言「法」者，此土方言，大夏梵音即云「達磨」，或云「曇無」、「曇摩」之異傳耳，未解「聲明」，故言多僻。
【譯文】【疏文】所說的「法」，是此方中土的用語，在大夏傳來的印度梵音中稱為「達磨」，或者有「曇無」、「曇摩」等不同的音譯傳承，這都是因為譯者未能通曉印度「聲明」（語言音韻學）之學，所以用字大多僻漏差訛。

【076-0003】02_戒疏/02a_卷一上之二#29
【原文】【疏】「法」有二義：一、自體解「法」，如三聚等；二、軌模解「法」。今據後義。至聖演教，意在成行。如車從轍，如器從模，法非目覩，以喻成也。又如行必從道，道不從人。道即行之所依法式，無越此也。
【譯文】【疏文】「法」具有兩種義理：第一是從自存體性來解釋「法」，例如色法、心法、非色非心法這三聚等；第二是從規範法則（軌模）來解釋「法」。現在是依據後一種義理。至高無上的聖者演說教法，本意在於成就實踐修行。就像車輛必須順著車軌而行，器皿必須順應模型鑄造，法體並非眼睛所能直接看見，因此用比喻來加以彰顯。又如同行路必定要沿著道路前進，道路不會隨順人的私意而改。道就是行路之人所依循的法則軌範，絕不能超越逾越於此。

【076-0004】02_戒疏/02a_卷一上之二#30
【原文】【記】釋法中。初示華梵。西國有「聲明論」，辨定語音訛正。今指翻傳之人，未善彼論，故所出不同。「法」下，釋義。初、言「三聚」者，一、色，二、心，三、非色非心。此三體性差別，不相混濫，故云「自體」。次義如文自顯。初標示，「至」下，喻釋。又二：初、約車器喻，二、取道路喻，釋成「軌模」義也。並上二句立喻，下二句對合。
【譯文】【記文】解釋法的科判中。首先開示華語與梵語的對應。西方印度有專門的《聲明論》，用以審定語言讀音的差訛與純正。這裡是指早期翻譯傳播的人，未能精通該論，因此翻譯出來的名稱互有不同。「法」字以下，解釋其義理。第一、所謂「三聚」，第一是色法，第二是心法，第三是非色非心法。這三種法的體性各有差別，彼此不相混亂混淆，所以稱為「自體」。第二種義理就如疏文自身所顯露的那樣明白。最初是標明提示，「至」字以下，則用比喻來解釋。其中又分為兩重：首先是拿車軌與器具模型作比喻，其次是拿道路作比喻，以解釋成就「規範軌模」的意涵。都是上面兩句確立譬喻，下面兩句加以對照相合。

【076-0005】02_戒疏/02a_卷一上之二#31
【原文】【疏】「僧」者天音，具云「僧伽」。此無其人，以相翻之，號為「眾」也。或有舊解，言「和合眾」，即體相為名。言斯等人同具六和，四人非一，崇成眾法故也。然諸經中，但單「眾」翻，不兼體說。廣如《羯磨疏》解。
【譯文】【疏文】「僧」是印度的梵天之音，完整稱呼為「僧伽」。此方中土沒有這類人物與體制，因此依據其聚眾大眾之相來翻譯，稱之為「眾」。也有古代的解釋，稱為「和合眾」，這是兼取其體質與外相共同立名。意思是說這類修行人共同具足六和敬，而且必須四人以上而非單獨一人，共同尊奉成就僧團的一切羯磨法事。然而在各部經文之中，大多只是單純翻譯為「眾」，並不兼帶其和合之體來界定。詳細內容如同《羯磨疏》中的解釋。

【076-0006】02_戒疏/02a_卷一上之二#32
【原文】【記】釋僧中。初翻名。單就「相」翻，是今正譯。「或」下，出古解。初翻名，和合是「體」，眾即是「相」。「言」下，釋義。「具六和」者，釋上「體」也；「四人」者，釋上「相」也；「成眾法」者，辨一切羯磨也。「然」下，指歸正義。「《羯磨疏》」中但取「眾」翻，廣有廢立，不復繁引。
【譯文】【記文】解釋僧伽的科判中。首先說明翻譯名稱。單純就「外相」來翻譯為「眾」，是現在通行的正確譯法。「或」字以下，提出古代的解釋。最初翻譯名稱時，認為和合是「本體」，眾多就是「外相」。「言」字以下，解釋義理。所謂「具足六和」，是解釋前面的「體」；所謂「四人」，是解釋前面的「相」；所謂「成就眾法」，是辨明僧團能共同成就一切羯磨事務。「然」字以下，指歸正確的界定義理。《羯磨疏》之中只選取單譯為「眾」，其中廣泛辨析了廢止與確立的理由，這裡不再繁複引述。

【076-0034】02_戒疏/02a_卷一上之二#60
【原文】【記】初明理寶，文出《多論》。「五分」者，戒、定、慧，從因受名，解脫、解脫知見，從果彰號。由慧斷惑，惑無之處，名解脫。出纏破障，反照觀心，名解脫知見。「滅理」，四諦、滅諦、涅槃。「學、無學」者，初果已去，同見真諦，名理和僧。然此理寶，亦即同體，但望佛、僧證理邊為別。故《多論》云：「佛亦是法，法亦是佛，僧亦是法。止是一法，相有差別，故分三寶。」
【譯文】【記文】首先說明理體三寶，經文出自《薩婆多論》。「五分」法身，戒、定、慧是從修行的因位而獲得名稱，解脫與解脫知見則是從證悟的果位而彰顯名號。由於智慧能斷除煩惱惑業，煩惱不復存在之處，就稱為解脫。跳脫纏縛、破除障礙，迴光反照審觀自心體性，就稱為解脫知見。「滅理」，是指苦、集、滅、道四聖諦中的滅諦涅槃。「學、無學」，是指從初果須陀洹以上，同修共見真空真諦之理，稱為理和同體僧。然而這種理體三寶，本質上也即是同體三寶，只是對照佛陀與僧伽證悟真理的角度而有所區別。所以《薩婆多論》說：「佛也就是法，法也就是佛，僧也就是法。其實只是一個法體（同一法性），由於顯現的相狀有所差別，因此劃分為三寶。」
