# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【289-0001】02_戒疏/15b_卷三下之三#58
【原文】【疏】《律》中三名：一、蒱闍尼，謂時藥也；二、佉闍尼，謂非時藥也；三、奢夜尼，謂七日藥等。皆號為藥者，無非療患故也。
【譯文】【疏文】《律》中記載了三種梵名：第一、蒱闍尼，指的是時藥；第二、佉闍尼，指的是非時藥；第三、奢夜尼，指的是七日藥等。這些全都被稱為藥，是因為無非都是用來治療疾病患難的緣故。

【289-0002】02_戒疏/15b_卷三下之三#59
【原文】【記】釋名中，通釋。但有三名。三中，云「等」，應攝盡形。上出別名。「皆」下，示通名。人有二患：飢渴為故患，初二藥療之；四大違反為新患，後二藥療之。
【譯文】【記文】在解釋名稱中，首先是共通解釋。律中只有三個名稱。第三個名稱中提到「等」字，應當也涵蓋了盡形壽藥。上面指出了個別名稱。「皆」字以下，指出共通的名稱。人有兩種病患：飢餓乾渴是舊有的病患，由前兩種藥來治療；四大不調是新生的病患，由後兩種藥來治療。

【289-0003】02_戒疏/15b_卷三下之三#60
【原文】【疏】就別解中。名雖有四，約時往判，正有二藥。如豆穀、乳酪、餅果、飯菜，從旦至中，聖教開服，事順法應，名為「時藥」。過中已去，明未出來，聖不聽服，服則生過，名為「非時」。餘三種藥，並犯在時，非時分中，聽服無罪，應名為「時」。由對前故，名「非時藥」，藥體非非時。若從此解，正有二藥，時及非時。所以四者，時藥當分唯一不分，非時離三，故有四也。
【譯文】【疏文】在個別解釋當中。名稱雖然有四種，但如果依據時間來判定，實際上只有兩類藥。例如豆類穀物、乳酪、糕餅水果、飯菜，從清晨到正午，佛陀聖教開許服用，事理相順、合乎教法，稱為「時藥」。過了正午以後，直到次日天明之前，佛陀不聽許服用，服用了便會產生過失，稱為「非時」。其餘三種藥，違犯的情況都在白天應食的時限之內，在過午非時的時段中，開許服用而沒有罪過，照理應當稱為「時」。由於是相對於前面所說的正食，所以被稱為「非時藥」，但藥物本體並非就是非時。如果依照這種解釋，實質上只有兩種藥，即時藥與非時藥。之所以分為四種，是因為時藥在其本分上只有一種不再細分，而非時藥中分出了三種，所以共有四種。

【289-0004】02_戒疏/15b_卷三下之三#61
【原文】【記】次別解中。初科古解，又三。初總標。「約時有二」者，謂時與非時二種藥也。「如」下，二、別釋。初釋時藥，過時不得，故獨名「時」。「餘」下，次釋三藥。「並犯在時」，彼謂時內不得服故。然此三藥，非時中服，正是其時，故應名時，望前時藥，故名「非時」。「若從」下，三、結示開合。
【譯文】【記文】在第二個別解釋中。第一段是古人的見解，又分為三層。首先總體標示。「約時有二」，是指時藥與非時藥這兩類。「如」字以下，第二、分別解釋。起初解釋時藥，因為過時就不能吃，所以單獨稱為「時」。「餘」字以下，接著解釋其他三種藥。「並犯在時」，是古人認為在應食的時間內不能隨便服用的緣故。然而這三種藥，在非時的時段服用，正合乎其適當的時機，所以本應稱為時，只是對照前面的時藥，所以稱作「非時」。「若從」字以下，第三、總結說明法義的開合。

【289-0005】02_戒疏/15b_卷三下之三#62
【原文】【疏】若作此解，恐非聖言。何以然者？時藥、非時，名體是局，可如上論。餘之二藥，一受已後，時及非時俱得噉服，豈約非時離分三也？
【譯文】【疏文】如果作出這樣的解釋，恐怕不符合聖人的教言。為什麼這樣說呢？時藥與非時藥，它們的名稱與體質是有明確局限的，確實可以像上面那樣討論。但其餘的兩種藥，一旦依法作法受持之後，在應食的時間與非時的時段全都可以食用服用，哪裡能夠說是依據非時而分出三種呢？

【289-0007】02_戒疏/15b_卷三下之三#64
【原文】【疏】今重釋名，時藥如上。欲明諸清果漿，明勢功能，正通時飲，但以非時分中病起要須，若不曲開，道器不立，故約過午，即以為名。更無勝功，故守「非時」之目。蘇、油、脂等，加法藥勢，唯在七日，故從日限為名。薑、椒辛苦，非人恒噉，療患力微，要在久延，方能治病，故聽作法，隨形而受。形有三種：一、盡藥形；二、盡病形；三、盡報形。所以可知。
【譯文】【疏文】現在重新解釋名稱，時藥的定義如同上面所說。為了說明各種澄清的水果漿汁，其性質與功用，本來完全適合在應食的時段飲用，只因為在過午非時的時段中比丘生起渴病急需緩解，如果不及時通融開許，修道的色身便無法維持，所以依據過午的時間，就以此命名為非時藥。它並沒有更超勝的療病功效，所以始終保持著「非時」的名目。酥、油、動物脂肪等，藉由作法加持的藥性效力，只能維持在七天之內，所以依據天數的期限來命名。生薑、胡椒等辛辣苦味的草藥，不是平常人恆常食用的食物，治療病患的力量微弱，必須依賴長久服用才能治病，所以聽許依律作法，伴隨身體壽命而受持。這類盡形壽的「形」有三種意義：第一、到這劑藥物耗盡為止；第二、到這種疾病痊癒為止；第三、到這一期生命報體終盡為止。其中的緣由顯而易見。

【289-0008】02_戒疏/15b_卷三下之三#65
【原文】【記】今解中。時藥指「上」，古今同故。「欲」下，次明非時。「道器」即目色心。「無勝功」者，限外無用，劣後二故。「蘇」下，三、明七日。取「藥勢」者，凡藥治病，七日見功，過則不療。「薑」下，四、明盡形。「辛」、「苦」，即六味之二，餘四即甘、酸、鹹、淡也。下列「三種」，正歸盡報，所以《了論》名為「一期」，或曰「終身」，或名「盡壽」等也。
【譯文】【記文】現在的新解釋中。時藥指稱「如上」，因為古今的理解相同。「欲」字以下，接著說明非時藥。「道器」就是指色身與心識。「無勝功」，是指在限定時間外沒有別的特殊功用，性質遜色於後兩種藥的緣故。「蘇」字以下，第三、說明七日藥。取「藥勢」，是因為一般藥物治療疾病，七天內就能見效，過期就失去醫療價值。「薑」字以下，第四、說明盡形壽藥。「辛」、「苦」，就是六種味道中的兩種，其餘四種是甘、酸、鹹、淡。下面列出的「三種」，主要歸結在終盡此生報體，所以《明了論》稱之為「一期」，或者稱為「終身」，或者名為「盡壽」等。

【289-0011】02_戒疏/15b_卷三下之三#68
【原文】【疏】三、立四所以。病有二種：一者，常病，易治數發；二、稀發，難治常差。對前常病，故立二藥：飢病既動，一食飽足，通日兼夜，病得消殄，故立時藥；渴病數發，隨發隨服，未局時節，故立非時。對後希病，故立二藥。七日功強，盡形力劣，故約功用長短不同。時與非時，位定各一，七日、盡形，通時非時。二定兩通，故立四藥。
【譯文】【疏文】第三、建立四種藥物的原因。疾病有兩種：第一種是經常性發作的病，容易醫治但頻繁發作；第二種是罕見發作的病，難以醫治且痊癒後不易復發。針對前一種常發的疾病，所以建立了兩種藥：飢餓之病既然發作，只要吃一餐飽足，整天乃至整夜，病態就能消滅除盡，所以建立了時藥；口渴之病頻繁發作，隨時發作就隨時飲用，沒有局限於特定時節，所以建立了非時藥。針對後一種罕見的疾病，所以建立了後兩種藥。七日藥的藥力強勁，盡形壽藥的藥力較為緩和微弱，所以依據功用時限的長短而有所不同。時藥與非時藥，其適用的時間固定各佔一處；七日藥與盡形壽藥，則通貫於時與非時皆可服用。由於有兩種時間固定、兩種時間通貫，所以總共確立了四種藥物。

【原文】【記】三、立四中，初科為三。初示二病。「常病」即是飢渴，「稀病」即四百四病。亦名新故，亦曰主客。常病非患故「易治」，日別常生故「數發」；稀病違反故「難治」，治已永無故「常差」。「對前」下，二、明四藥。初明立前二藥。「殄」即滅也。「對後」下，次明立後二藥。「七日功強」，故限短；「盡形力劣」，故限長。「時與」下，三、結示通局。

【289-0013】02_戒疏/15b_卷三下之三#70
【原文】【疏】若依《明了》，藥則有五。一、依時量。二、依更量，即非時之異名。然彼論中，日夜分五時，隨時受藥，約至七時，如平旦至二更等輪轉為時，故曰「更」也。三、依七日量。四、依一期量，即盡形也。五、依大開量，謂灰、土、水、屎、尿也。此五世人所棄，不須受取，故曰「大開」。準《四分律》，有通塞也。
【譯文】【疏文】如果依照《明了論》，藥物則分為五種。第一、依時量。第二、依更量，這就是非時藥的另一種名稱。但在該論當中，將一晝夜分為五個時段，隨著當時受持藥物，大約以七個時段為輪轉期限，如平旦受藥可至二更，依序輪轉交替作為時段，所以稱為「更」。第三、依七日量。第四、依一期量，也就是盡形壽藥。第五、依大開量，指的就是灰、土、水、屎、尿這五種。這五種東西是世間人所遺棄的，不需要特別作法受取，所以稱為「大開」。若按照《四分律》，則有開許與禁制的不同規定。

【289-0014】02_戒疏/15b_卷三下之三#71
【原文】【記】次科。《了論》，五並名「量」，謂限齊也。「時量」，可知。「更量」者，即以五更為分齊更改也。「日分五時」者，寅、卯等時，乃是此方曆數，不可對之，但約一日分為五分，以對五更。「約至七時，如平旦至二更」，日夜共七時，日高時受，至三更；日中時受，至四更；日斜時受，至五更；日落時受，至夜分盡。若準本宗，無論早晚，皆盡夜分。五、「大開」者，無所制也。《四分》灰、土，有人須受，無人別開，故云「有通塞」也。《論》結云：「此五攝一切皆盡。」
【譯文】【記文】第二段。《明了論》中，五種都稱為「量」，是指期限標準。「時量」容易明白。「更量」，就是以五更的交替作為更換的分界。「日分五時」，寅、卯等時辰是此地的曆法算法，不能直接生硬對應，只是把一整天分為五個部分，用來對應五更。「約至七時，如平旦至二更」，晝夜共七個時段，太陽升高時受藥，可持續到三更；正午受藥，可持續到四更；夕陽西斜時受藥，可持續到五更；太陽落山時受藥，可持續到黑夜結束。如果依準本律宗的規矩，無論早晚受藥，都只能持續到當夜結束為止。第五、「大開」，是指毫無限制規定的意思。《四分律》中灰、土若有人看守則必須受取，無人看守才另外開許，所以說「有通塞」不同。《論》總結說：「這五類涵蓋了一切藥物。」
