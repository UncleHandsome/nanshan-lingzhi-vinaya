# 校閱材料　第408檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【408-0001】03_業疏/10b_卷二之四#77
【原文】三中，初引論文，有四：清旦是定時，從他即假境，下坐是具儀，隨說即作法。布薩翻「淨住」，即是戒義。《明了論》云：「在身口名戒，在心名護」是也。「故下次」引論解，次第四節，各顯教意，當自分之
【譯文】第三科中，首先引用論典之文，共有四點：清晨是定時，從他人處領受即是藉助對境，坐在低位是具備威儀，隨後念說是進行作法。「布薩」翻譯為「淨住」，也就是持戒的意思。《律二十二明了論》說：「表現在身口上的稱為戒，存於內心的稱為護」，即是此意。「故下」次引用論典的解釋，依照次序分為四節，各自彰顯聖教的用意，應當自行分別清楚。

【408-0002】03_業疏/10b_卷二之四#78
【原文】又云一日夜者，以五種三歸文相叢雜，故須簡定，義無混亂。故準多宗，必一日夜，不通過減。縱引十誦皮革所見本居諸人，晝夜互受，苦樂兩果，竝云「不能全受八戒、五戒，或於半日夜」者，以俱舍論解：但得善行可愛果，不得戒也。依文成實，隨力多少者，接俗之教，不可約之，如上說也
【譯文】文又說「一日一夜」的，是因為五種三歸依的文相交錯雜亂，所以必須揀擇確定，使義理不致混亂。因此依照薩婆多宗的規矩，必定是一日一夜，不能超過也不能減少。縱使有人引用《十誦律》〈皮革犍度〉中所見同鄉舊識之人，日夜交替感受苦樂兩種果報，並且都說「不能完全受持八戒、五戒，或者只在半日半夜受持」等語，依據《俱舍論》的解釋：這只是得到善行的可愛樂果報，並未得到戒體。依據《成實論》文句所說「隨人的能力多少受持」者，是接引世俗之人的教法，不可用定限來拘束限制它，正如上面所說的那樣。

【408-0003】03_業疏/10b_卷二之四#79
【原文】四中「又云」，即牒注也。注標「論云」，即是《多論》。初出彼宗之局，初示意，「故」下引據，彼論云「以佛本聽一日一夜齋法，以有定限不可違也」。「縱」下通妨，初引難，彼論自難云「若爾如皮革中說等」，即《十誦》〈皮革犍度〉說億耳沙彌在曠野行，見諸餓鬼，皆是鄉黨本居之人，或日受樂夜受苦，或日受苦夜受樂，「竝云」等者，億耳問故，諸鬼答也。「半日夜」者，謂曾受五、八，或受日不受夜，或受夜不受日，豈非五、八不局時耶？「以」下次引釋，《多論》自通曰「本生因緣不可定」，又曰「迦旋延欲度億耳，故作變現，感悟其心，非是實事」，此釋理迂，故引《俱舍》通之，謂彼受樂止是泛善，既不全受，故不得戒，善行是因，可愛即樂果。「依」下次準成宗，二戒竝通時日多少，前文已示，故此指之。
【譯文】第四節中「又云」，就是引述注文。注文標示「論云」，指的就是《薩婆多論》。首先指出該宗派的局限，先表明大意，「故」字以下引用依據，該論說「因為佛陀本來只聽許一日一夜的齋法，因為有固定期限不可違背」。「縱」字以下通達釋疑，首先提出問難，該論自己設難說「如果這樣，如同皮革犍度中所說等」，也就是《十誦律》〈皮革犍度〉說億耳沙彌在荒野中行走，看見許多餓鬼，都是同鄉舊識之人，有的白天受樂夜晚受苦，有的白天受苦夜晚受樂，「竝云」等句，是因億耳詢問，眾鬼回答。「半日夜」的意思，是指曾受五戒或八戒，或者受白天不受夜晚，或者受夜晚不受白天，這難道不是說明五戒、八戒並不局限於固定時間嗎？「以」字以下接著引述解釋，《多論》自己解釋說「本生的因緣不可一概而論」，又說「迦旃延想要度化億耳，所以作神通變現以感發啟悟他的心，並不是實有的事」，這種解釋在義理上顯得迂迴牽強，所以引用《俱舍論》來解答會通，認為那些鬼受樂只是一般的世間善行，既然沒有完全受持，所以並未得戒，善行是因，可愛樂即是樂果。「依」字以下接著依準成實宗，五戒與八戒都通融於持戒時日的多少，前面文中已經開示過，所以在此指出。

【408-0004】03_業疏/10b_卷二之四#80
【原文】正受法中，受、結為二
【譯文】在正受戒法之中，分為「受」與「結」兩個部分。

【408-0005】03_業疏/10b_卷二之四#81
【原文】正受中初科。受、結二者，前三歸是受，正納體故；後三歸是結，重囑累故
【譯文】正受戒中的第一科。受與結這兩者：前面的三歸依是「受」，因為是正式納受戒體的緣故；後面的三歸依是「結」，因為是重新鄭重囑咐的緣故。

【408-0006】03_業疏/10b_卷二之四#82
【原文】初文可解。言淨行者，以所期時，奉持九支，同諸佛戒，故云淨也。何以不言如來正覺者？五戒初離邪緣，故以正隔之；今於五上重增勝行，復何須也
【譯文】最初的文句容易理解。所說的「淨行」，是因為在所約定的期限內，奉持九條戒支，與諸佛的戒行相同，所以稱為「淨」。為什麼不稱「如來正覺」呢？因為五戒是剛開始脫離邪緣，所以用「正」字來阻隔邪法；現在是在五戒之上重新增添殊勝之行，又何須再加稱呢？

【408-0007】03_業疏/10b_卷二之四#83
【原文】次科，初句指略，即上三歸，前已釋故。「言下」牒釋，以同佛戒，故名淨行。私釋：對前五戒未斷正婬，故加簡之。「何下」示異。由五戒後具列三號，今文既闕，故此通之。若爾，不受五戒，直受八戒，非是重增，理須加唱；若謂五戒初離邪緣，故須簡正，何以十戒又復著耶？私釋：作法加簡，非正受詞，前除後加，義應通得。文中且據一往釋耳
【譯文】第二科，第一句是指示省略之處，也就是上面的三歸依，因為前面已經解釋過的緣故。「言下」引述並解釋，因為等同於佛陀的戒行，所以稱為「淨行」。私下的解釋是：對比前面的五戒尚未斷除正淫，所以特別加以揀別。「何下」顯示其差異。由於五戒後面完整列出了如來三種德號，現在八戒文中既然缺漏，所以在此加以通釋。如果這樣的話，若有人不受五戒，直接受八戒，這就不是在五戒上重新增勝，按理就必須加上宣唱；如果說五戒是剛脫離邪緣所以必須揀別為「正」，那為什麼十戒又再次加上呢？私下的解釋是：作法時加以揀別，並非正受戒時的誓詞，前文免除而後文加上，在義理上應當都能通融成立。疏文中姑且只是依據普遍情況作了一種解釋罷了。

【408-0008】03_業疏/10b_卷二之四#84
【原文】三、明相中文分為二：初列相示，二「阿含」下明願引也。所以須二者，行足願目，事緣相假。雖奉勝行，無願引心，則令此業隨緣墜地。故經論中盛弘此意，至時長引，證非徒
【譯文】第三、說明戒相的文中分為兩部分：第一是列出戒相予以開示，第二自「阿含」以下說明發願引導。之所以需要這兩部分的原因，是因為行持如同雙足，願力如同雙目，事相與因緣必須相互依憑。雖然奉持殊勝的戒行，若沒有願力來引導其心，就會讓這種善業隨順世俗因緣而墜落於世間福報。所以在經論中極力弘揚這個用意，到受戒時應當長遠引發大願，以證明戒行絕非徒勞無功。

【408-0009】03_業疏/10b_卷二之四#85
【原文】三明相中初科為二：初正分文。「所下次」出所以。行足願目，舉事喻法，以顯相須。行願二法，經論廣明，不可具述。囑令長引，徒，虗也
【譯文】第三說明戒相中的第一科分為兩部分：首先正式劃分文句。「所下」次說明其中的緣由。「行足願目」，是用具體事例比喻法義，以顯示兩者必須相輔相成。行持與發願這二法，經論中有廣泛的闡明，無法詳細列述。囑咐應當長遠引導發願；「徒」，就是空虛、徒勞的意思。

【408-0010】03_業疏/10b_卷二之四#86
【原文】前相中如俱舍論分別者，即義門末也。故彼文云：戒分三位：前四名戒分，離性惡故；次一名為無放逸分，若善受戒，由飲酒故，擾動諸學處故；後三名修分。若不受下二分，有何過？由飲酒故，即便忘失是事非事念也。離莊嚴者，謂非舊莊嚴也，若常所用莊嚴，不生極醉亂心也。若用高勝臥處及歌舞音樂，隨行一事，破戒不遠也。若依時食，離先所習非時食也。憶持八戒，即起厭離隨助之心；若無第八，此二不生也

【408-0045】03_業疏/11a_卷二之五#8
【原文】次文，初後二俱句，中間二互句。初句「從道」是形出，「求脫」即心出。若以兩根對四句者，初句兼收利鈍，鈍者因形而發心，利者起心而從事；第三句唯利；二、四兩句則非所論
【譯文】第二段文字中，第一句與第四句是身心一致之句（二俱句），中間第二與第三句是身心互違之句（二互句）。第一句「從道」是指形體出家，「求脫」是指內心出家。如果將利根與鈍根兩類人對應這四句：第一句兼收了利根與鈍根，鈍根者藉由外在形體出家而啟發道心，利根者則是先發起道心進而在事相上奉行；第三句（心出形沒）純粹是利根之人；至於第二句（形出心沒）與第四句（俱不出），則不在合宜之列，無足深論。
