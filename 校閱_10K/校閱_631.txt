# 校閱材料　第631檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【631-0001】02_戒疏/12a_卷三上之三#28
【原文】【記】次科。問者，發下證文。答中，彼謂犯捨衣貿易新衣，後衣即染犯。「一提」是長罪，「一吉」即著用罪。
【譯文】【記文】接下來的一節。提問者是為了引出下文的經證。回答中，古師認為將已犯捨墮的衣服拿去交易換得新衣，後來的衣服就會沾染犯相。「一提」是指長衣的罪過，「一吉」則是指著用時的罪過。

【631-0002】02_戒疏/12a_卷三上之三#29
【原文】【疏】若存此釋，尼衣、販賣，入手須說，不說過限，又犯長罪。今解不然，販財體穢，不合說淨作三衣故。《律》云「犯捨墮衣，不合淨受」，據此非淨何由有染？又財無兩捨，罪不重結。淨法簡境，何得妄施？
【譯文】【疏文】如果保留這種解釋，那麼向比丘尼取衣、販賣所獲之財，剛入手時就必須作法說淨，如果不作法而超過期限，又會結犯長衣之罪。現在的見解並非如此，販賣得來的財物其本體極為污穢，本就不合律法拿來說淨或作持為三衣。《律本》說「犯捨墮之衣，不合如法說淨受持」，據此既然根本不能成淨，又從何而來沾染？再者，同一筆財物沒有二次捨離的道理，罪過也不能重複結判。說淨的儀軌對對象是有所揀擇的，豈能胡亂施行？

【631-0003】02_戒疏/12a_卷三上之三#30
【原文】【記】今解中。初科為二。初指古非。「尼衣」、「販賣」，且舉二戒，餘戒例然。《義鈔》云：「販賣入手，要說淨，作三衣。」又云：「既為長染，明知理合說淨，作三衣開。」又難云：「若爾，何故《衣法》云『尼薩耆衣，不應說淨作三衣？』」答：「得小罪故云『不應』，非謂不成等。」準知古師許有說淨受持之義。「今」下，次立理破，又三。初約淨法破，財體既穢，何由入淨？文證可知。言「淨受」者，「淨」即說淨，「受」即作三衣。「又」下，二、約捨財破，無兩捨故。三、據結罪破，無重結故。「淨」下，重舉初義，以責非理。
【譯文】【記文】在當今正解之中。第一節分為兩部分。首先指出古師的謬誤。「尼衣」、「販賣」只是暫且列舉此二戒，其餘各戒亦可依此類推。《義鈔》中說：「販賣所得之物一經入手，就必須說淨、作三衣。」又說：「既然已被長衣所染，明知在道理上理合說淨，准許作三衣使用。」又提出質疑：「如果是這樣，為何《衣法》說『犯尼薩耆的衣物，不應當說淨作三衣？』」回答：「因為會得小罪所以說『不應當』，並不是說作法不成等。」由此可知古師准許有說淨受持之理。「今解」以下，接著立理駁斥，又分為三層。第一是依據說淨法來駁斥，財物本體既然污穢，如何能入於說淨之法？律文證據極為明確。所謂「淨受」，「淨」是指說淨，「受」是指受持作三衣。「又」字以下，第二是依據捨財來駁斥，因為同一物不能有兩次捨財。第三是根據結罪來駁斥，因為戒罪不可重複結判。「淨法」以下，重新舉出第一點義理，用以斥責古師說法不合義理。

【631-0006】02_戒疏/12a_卷三上之三#33
【原文】【疏】如昔解云：「自於五眾邊貿，及遣人二眾邊貿，不犯販博，故有染犯。若自俗交，則犯販博，體染非淨及著二罪。」
【譯文】【疏文】正如過去的解釋所說：「自己向出家五眾身邊換取，以及差遣他人向兩眾身邊換取，不構成販賣之罪，所以會有沾染犯過的情況。如果是親自與在俗之人交易，就犯了販賣罪，財物本體沾染不能說淨，則結犯體染不能說淨（體染罪）與著用這兩種罪過。」

【631-0007】02_戒疏/12a_卷三上之三#34
【原文】【記】昔解中。初明體淨染犯，止有二罪。「若」下，次明體穢染犯。此有三罪：「販博」一提，「體染」一提，及「著」一吉。但由販博，自是別犯，所以文中止明「染、著二罪」，合上《律》文。
【譯文】【記文】在過去的解釋中。首先說明財物本體清淨而沾染結犯的情況，僅有兩種罪。「若自俗交」以下，其次說明財物本體污穢而沾染結犯的情況。這裡本應有三種罪：「販賣」的一個波逸提罪，「本體沾染」的一個波逸提罪，以及「著用」的一個突吉羅罪。但由於販賣本身屬於另外單獨結犯，所以文中僅僅說明「染與著二罪」，以符合上述律文。

【631-0008】02_戒疏/12a_卷三上之三#35
【原文】【疏】今解不然。豈有財去，後來新物而得有染？引《多論》中，無如此義。縱在俗交，亦無有染。
【譯文】【疏文】現在的解釋並非如此。哪裡有原先的財物已經離去，後來換得的新物品卻還能沾染罪過的道理？查考引述《薩婆多論》的內容，並沒有這樣的義理。即使是與俗人交易，也不會有沾染成罪之事。

【631-0009】02_戒疏/12a_卷三上之三#36
【原文】【記】今解中，初科。初釋淨者無染。「《多論》無此義」者，彼云「若先應量捨墮物，更貿得衣財，即作二衣。此衣不懺，懺先提罪」，則知後衣無染明矣。餘廣如《鈔》。「縱」下，次釋穢亦非染。由自有過，故無所染。
【譯文】【記文】在當今正解中，這是第一小節。首先解釋清淨之物絕無沾染。「《薩婆多論》無此義理」，因為該論說「如果先將合量的捨墮物，再拿去更換貿易得到衣料，當下便能製成二衣。這件新衣服無須懺悔，只需懺悔前面所犯的波逸提（捨墮）罪」，由此便能清楚知道後來的衣服並無沾染。其餘詳細論述見於《事鈔》。「縱在俗交」以下，接著解釋本體污穢之物同樣不存在沾染。因為自身本來就別有罪過，所以不再受他者沾染。

【譯文】【記文】在第二小節立論質疑中。律文既然明明白白結判了兩種罪過，就代表通染成犯，該如何解釋它呢？

【631-0012】02_戒疏/12a_卷三上之三#39
【原文】【疏】答：「昔解非也。今言『不捨更貿』者，以體不淨，須捨須悔，如何不捨違制？故一墮之罪，財去罪也；一吉之罪，違佛教也。」
【譯文】【疏文】回答：「過去的解釋是錯誤的。現在所說的『不捨出而更換貿易』，是因為衣物本體不淨，必須先捨出並進行懺悔，怎能不經捨懺而違背佛制呢？所以結犯的一個墮罪，是前財離去時原本未懺的罪過；結犯的一個吉羅罪，則是違背佛教規定的過失。」

【631-0013】02_戒疏/12a_卷三上之三#40
【原文】【記】答中，初科。初句指破前解。「今」下，次伸正釋。初敘違制。以犯捨衣，制須懺淨，可將餘用，縱直施人，亦制與罪。「故」下，示罪相。「一墮」即前衣本犯未悔之罪，「一吉」即違制。則顯新衣都無過矣。
【譯文】【記文】回答之中是第一小節。第一句直接斥破前人的解釋。「今言」以下，接著陳述正確的解釋。首先敘述違背教制。因為凡是犯了捨墮的衣服，依制必須經過懺悔清淨之後，才可以拿去作其他用途，縱使直接拿去布施給他人，依制也是要結罪的。「故一墮之罪」以下，明示其罪相相貌。「一墮」就是指前一件衣服本身違犯而尚未懺悔之罪，「一吉」是指違背佛教制作之罪。這正顯明了新換得的衣服完全沒有過失。

【631-0014】02_戒疏/12a_卷三上之三#41
【原文】【疏】如此解時，全無「傍」義？今解得有。如先犯長，後博新衣，止犯減價之罪，不為長染。及捨還衣，為長所染，故義通也。
【譯文】【疏文】按照這樣的解釋，豈不是完全沒有了「旁向通染」的意義了嗎？現在的見解認為依然可以成立。例如先犯了蓄長衣罪，後來拿去折價換得新衣服，此時僅犯減價之罪，不會被先前的長衣罪所沾染。直到後來依律捨出又還給本人之後，新衣才被長衣之罪所沾染，所以在義理上依然是相通的。

【631-0015】02_戒疏/12a_卷三上之三#42
【原文】【記】次科。初指上文，既翻古解，旁染不成。「今」下，示今別立。文中且明販博，除前九戒，自餘皆有染犯之義。舉一例諸，自可解也。
【譯文】【記文】接下來的一節。首先指出上面的內容，既然推翻了古人的解釋，橫向沾染的說法便無法成立。「今解得有」以下，指示當前獨立建立的正義。文中暫且針對販賣貿易來說明，除了前述九條戒之外，其餘各戒自然都有沾染成犯的義理。以此舉一反三，自然可以理解。
