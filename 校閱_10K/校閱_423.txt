# 校閱材料　第423檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【423-0001】02_戒疏/04c_卷一下之二#150
【原文】【疏】就此根本不識事中。始終無心，如悞殺人等，不結其罪。前則有心，中後無心，但轉想疑，除婬、酒戒，餘結方便。若不差者，還結根本。若心了境，不造前事，則無罪也。
【譯文】【疏文】就這個根本的「完全不識事相」的類別中。如果自始至終完全沒有造惡的意圖，例如誤殺他人等情況，戒律完全不判定結罪。如果是起初有造惡的心思，進行中或到最後卻失去了造惡的心思，只是中途轉變了想法或生起疑惑，那麼除了淫戒與酒戒之外，其餘戒條都只判定預備行為的方便罪。如果想法沒有產生偏差，依然會判定觸犯根本大罪。如果心念已經清楚明了眼前境界，毅然停止不再造作先前預謀的惡事，那就完全沒有任何罪過了。

【423-0002】02_戒疏/04c_卷一下之二#151
【原文】【記】料簡中，初科為二。初標品位。三識三疑，俱有罪故，不須辨之。唯三不識，有無不定，故此委示。「始」下，正簡有四。初明本迷。「前」下，明轉想。「除淫、酒」者，該上本迷。「若不」下，於不可學，轉為可學。「若心」下，如善心息也。
【譯文】【記文】在辨析簡別中，第一科分為兩部分。首先標明品位層次。因為前六句的三個明識與三個疑惑全都必然獲罪，所以不需額外辨析。唯獨最後三個全然不識，罪業的有無無法一概而論，所以在此詳細說明。「自始」以下，正式辨析出四種情況。第一、說明始終完全迷惘。「起初」以下，說明中途轉變想法。「除了淫戒與酒戒」，這項例外規定涵蓋了前面所說的始終迷惘。「如果想法」以下，是指從不可學的迷惘，又轉回成了可學的清醒狀態。「如果心念」以下，是指善心生起而使惡行止息的情況。

【譯文】【疏文】回答：「是為了讓持戒與犯戒的各種相貌，能夠容易互相比對看清。」

【423-0005】02_戒疏/04c_卷一下之二#154
【原文】【記】次科，問答。云「相易」者，謂階品差降，則結罪有無多少可見，如次所顯。
【譯文】【記文】第二科，進行問答。所謂「容易看清」，是指品位階梯的高低順序井然排列，那麼所結罪名之有無與多寡便能一目了然，正如接下來所展示的。

【423-0006】02_戒疏/04c_卷一下之二#155
【原文】【疏】故前九中，上品一句，中下各四者，由緣一事，帶疑不識，交絡互明，出其犯相。九句就事，皆結究竟。緣而不了，愚教之罪，自結不學無知也。其愚教罪，亦是究竟，無果可趣。有識無疑，則非罪攝。
【譯文】【疏文】所以在前一組九句中，上品只有一句，而中品與下品各自有四句，這是由於面對同一件事相，夾帶著疑惑與全然不識，相互交織錯綜說明，從而顯露出犯戒的各種相貌。這前九句就事相本身的發展而言，最後全都結成了圓滿犯戒的究竟根本罪。而在面對境界時卻懵懂不明，這份愚昧於教法的罪過，自然要另外判定結下不學無知罪。這份愚教之罪本身也是獨立的究竟罪責，並非還要引申趨向於其他罪果。若能清清楚楚認識教法而毫無疑惑，自然就不屬於罪過所收攝的範疇了。

【423-0007】02_戒疏/04c_卷一下之二#156
【原文】【記】明前九中。初明立句。以識等三心歷於事犯，上下不定，故云「交絡」。「九句」下，明根本罪。「緣」下，示枝條罪。古師謂是方便，故特點之。
【譯文】【記文】在闡明前一組九句中。首先說明立句的結構。因為是以明識等三種心態歷經事相與罪相，層次高低排列不定，所以稱為「相互交織」。「這前九句」以下，說明根本罪的成立。「在面對」以下，指出枝末連帶的罪名。古德誤以為這只是預備階段的方便罪，所以在此特別嚴正點出。

【423-0008】02_戒疏/04c_卷一下之二#157
【原文】【疏】論後九句，三品各三。由不識事，境非可學。不妨於犯，是可學故。致列其相，事總而罪別也。
【譯文】【疏文】論及後一組九句，上、中、下三品各有三句。這是由於全然不識事相，當前的情境並非事前修學所能避免的。但這並不妨礙對於罪名法規而言，依然屬於應當修學的範疇。因此羅列出這些相貌，呈現出事相心態統括為一、而罪相心態各自有別的局面。

【423-0009】02_戒疏/04c_卷一下之二#158
【原文】【記】次明後九，初中。略舉「不識」，必該疑心。是則三識非不可學，句法相因，故可知矣。此中立句，事但一心，且如上品上半，皆云「識事」，故云「事總」。下半犯中，識、疑、不識，三心不同，故云「罪別」。
【譯文】【記文】其次闡明後一組九句，首先是第一部分。此處文字簡略只列出「全然不識」，但必定也同時涵蓋了疑惑的心態。這樣看來，前面三句的明識事相就不屬於不可學的範疇，句型的推演互為因果，由此就可以明白了。在此處的立句架構中，事相在各品中都只固定維持一種心態，姑且以上品的前半段為例，全都稱為「明識事相」，所以稱為「事相統括為一」。後半段的罪相中，明識、疑惑、不識這三種心態各不相同，所以稱為「罪相有別」。

【423-0010】02_戒疏/04c_卷一下之二#159
【原文】【疏】問：「若據此論，識、疑二事，分句為六，可是犯攝。不識等三，便是無犯。云何說言『作犯九句』？」
【譯文】【疏文】有人問：「如果按照這種說法來推論，對事相具有明識與疑惑的心態，分開立句共有六句，確實可以被犯戒的範疇所收攝。但對於全然不識事相的三句，根本就沒有犯罪。怎麼可以籠統地宣稱這是『作犯的九句』呢？」

【423-0011】02_戒疏/04c_卷一下之二#160
【原文】【疏】答：「若就本迷，實唯六句。然緣犯法，有疑不識，即是其犯。故說九句。」
【譯文】【疏文】回答：「如果單純就根本事境的迷心來說，確實只有六句犯戒。然而在面對犯罪法規時，內心若存在疑惑或全然不識，這本身就是一項罪犯。所以依然統括說成是九句。」

【423-0012】02_戒疏/04c_卷一下之二#161
【原文】【記】次科。上中二品，有罪可知。此下唯明下品三句。初問中，以作犯門，必須有罪，下三非犯，故設此問。答中，初縱來問。「然」下，奪歸須立。
【譯文】【記文】第二科。上中兩品必然獲罪是顯而易見的。從此處開始專門針對下品的三句來論述。在第一段提問中，發難者認為作犯門必須要有實際犯罪才成立，既然下品三句根本不犯大罪，所以提出這項質疑。回答時，首先順應對方的質疑退讓一步。「然而」以下，隨即扭轉結論，強調立為九句的必要性。
