# 校閱材料　第276檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【276-0001】資持記/08d_中二#46
【原文】似色銀者，可用塗染，像於金故。次明錢中。隨國用者，體通八種。不得捉者，捉犯後戒；然畜必由捉，故多標之。《多論》四節，初明重寶。摩尼，此翻離垢，言不為垢染故。真珠，即蜯珠。珊瑚，《智論》云：海中石樹。車渠，《尚書》大傳云：大貝如大車之渠〔渠即車輞〕。
【譯文】所謂「似色銀」，是指可以用來塗抹染色、外觀極為相似於黃金的白銀。接著在說明錢幣的段落中。所謂隨各國通用的貨幣，其物質實體普遍涵蓋前面所說的八種品類。律中說「不得捉持」，是因為捉持就會觸犯後面一條戒律；然而私藏蓄存必然是經由親手捉持而來，所以戒條上大多會同時標示捉持之名。《薩婆多論》將內容分為四個層次，首先說明貴重的珍寶。摩尼寶，這裡翻譯為「離垢」，是指這種寶物本性明淨、絕不沾染塵垢染濁的緣故。真珠，就是產自蚌貝中的珍珠。珊瑚，《大智度論》說：是生長在深海之中的石質樹木。硨磲，《尚書大傳》說：是一種如同大車車輪外輞般巨大的貝殼【「渠」就是指車輪外圈的車輞】。

【276-0002】資持記/08d_中二#47
【原文】馬碯，石類；應法師云：此寶色如馬之腦。當取等者，示開遮法。若下，次明似寶。琥珀者，《博物志》云：松脂入地千年化為茯苓，茯苓千年化為琥珀。水精，千年寒谷中氷凌所變。偽珠，世中以藥石燒者。鍮石等者，準論更列銅錢白鑞鈆錫。〔論約錢體，故入似寶，捉但犯吉；今所不取，《僧祇》、《四分》，八種錢並入正寶。
【譯文】瑪瑙，屬於名貴石類；玄應法師說：這種寶物的色澤紋理就像馬的腦髓一樣。從「當取」等文，指明開許與禁止的界線原則。從「若」字以下，接著說明各類「似寶」的物品。琥珀，《博物志》說：松樹的樹脂滲入地下歷經千年化為茯苓，茯苓在地下再經千年便化為晶瑩的琥珀。水晶，是在千年酷寒的深谷之中由堅冰凌霜凝結質變而成。偽珠，是指世俗間用藥草與礦石人工燒製而成的假珍珠。鍮石等各類雜金屬，依照該論典的詳細分類，還額外列入了銅錢、白鑞、鉛塊與生錫塊。【該論典是單純就錢幣的金屬質地來判定，所以將它們歸入似寶的輕物之中，捉持了只犯突吉羅輕罪；但本書現在不採納這種分法，因為依照《僧祇律》與《四分律》，世間通用的八種錢幣應當全部歸入真正的重寶之中。】

【276-0003】資持記/08d_中二#48
【原文】五取如後引。為畜吉者，則知不畜捉亦無過。若捉下，三明捉寶。文舉金寶，理通前七。金薄謂裹貼之物，金像如鑄成聖像〔《四分》不犯。〕自寶者，論作自說淨寶。若似下，四簡似寶。百一受持，故不假淨。釋第四中，初科三段，前定名體。彼以金銀錢為重寶，名不淨物；餘寶名淨不淨物。
【譯文】五種如法取用的方式正如後文所詳細引用的。經中說「為了私蓄而拿取才犯突吉羅罪」，由此即可反推明瞭：只要不是出於私自蓄存的心態，臨時捉持也是沒有過失的。從「若捉」以下，第三層次說明捉持珍寶的戒相。經文中雖然只舉出了金屬珍寶，在義理上普遍貫通前面的七種寶物。「金薄」是指用來包裹或貼金裝飾的金箔物品，「金像」是指用純金鑄造完成的佛菩薩聖像【依照《四分律》手觸金像是屬於不犯的】。所謂「自己的寶物」，論典中解釋是指自己已經依法完成說淨程序的寶物。從「若似」以下，第四層次簡別各類似寶。若是身邊屬於「百一」以內受持的日常用具，本來就無須特別辦理說淨手續。在解釋第四項中，第一科分作三段，前段先判定名目與體性：彼以金、銀、錢為重寶，名為不淨物；其餘諸寶名為淨不淨物。

【276-0004】資持記/08d_中二#49
【原文】初明重寶。止列三種，《多論》七寶俱制，與此不同；不得觸者，示不淨義。次釋餘寶。除上三物，通收一切。言得觸者，不制捉故。不得著者，同制畜故。著即貪畜，畜犯吉罪。若下，次明犯相，初通明重寶。若相等者，別顯錢體。言相成者，如胡膠皮木等錢，及此間鑞錫之類；
【譯文】首先說明最貴重的珍寶。文中只嚴格列舉了三種，而《薩婆多論》則是將世間七寶全部納入嚴厲禁止之列，這與此處的規範有所不同；經中規定「連用手碰觸都不可以」，正是為了彰顯其本質就是徹底的不淨物。接著解釋其餘各類珍寶。除了上述三種絕對禁止的物品之外，其餘珍寶通通包含在內。經中說「可以觸摸」，是因為並沒有制戒禁止用手捉持。經中說「不得著身」，是因為同樣制戒嚴禁私自蓄藏。所謂「著」，就是生起貪愛並私自蓄存，蓄存了就會觸犯突吉羅輕罪。從「若」字以下，接著說明具體的犯相，首先通途說明貴重珍寶的規範。從「若相」等文，分別闡明錢幣實體的特殊狀態。所謂「以其他材質相替代而成」，是指像用胡膠、皮革、木頭等材料製成的古代錢幣，以及此地世俗所使用的鉛錫硬幣之類；

【276-0005】資持記/08d_中二#50
【原文】必國土尚用，亦應提罪。若凡下，三示受法。使淨人知者，或且令受，或即作法。無者，謂無淨人。暫安地處，言是中知，即淨語也。令知持去者，若不可信，令持付他，但云知是；若可信人，即令掌舉；須作淨法，詞見次科。次作淨中，《四分》。即已犯財對俗捨文。準疏分四節，初句牒前制過。
【譯文】只要是該國度官方至今仍在公開流通使用的，比丘蓄存了也應當被科處墮罪（波逸提）。從「若凡」以下，第三部分指示如法接受供養的操作軌範。所謂「讓淨人知曉」，或者暫且讓淨人代為收下，或者當場依法作說淨法事。所謂「無淨人」，是指身邊當時沒有在家的淨人可以差遣。比丘可以暫時將錢財放置在地面上，並明確宣說「這是大家所知道的物品」，這句話本身就是合法的「淨語」。所謂「讓信得過的人知道並拿走」，如果該在家人不可信任，就只能請他拿去交付給其他人，口中只要宣說「你知曉此事即可」；如果是完全可以信賴的淨人，就可以直接委託他代為掌管儲存；但比丘必須同時依律作說淨儀軌，其具體的文詞詳見下一個科判。在接著說明作說淨法的內容中，引用《四分律》。這段文字正是比丘對於已經違犯蓄存的非法錢財，必須面對在家人當面捨棄的規定文句。依照《戒疏》的剖析分為四個步驟，第一句是重複標示前面所犯下的制教過失。

【276-0006】資持記/08d_中二#51
【原文】告下，二明捨錢方便。覓淨主付也。若彼下，三謂不達施意。佛為淨故，令彼受之；彼不解故，不敢即受，乖淨施法。當為彼物受者，既捨與彼，即屬彼故。若為貿衣須易受者，以先淨法不成故。若彼下，四此約解意。即取迴淨，不須轉易。若下，別明淨語。
【譯文】從「告」字以下，第二個步驟是說明捨棄非法金錢的善巧方便，也就是尋找一位如法的淨人主人將錢財全數交付出去。從「若彼」以下，第三個步驟是指在家人往往無法明白比丘布施錢財的真實用意。佛陀是為了讓出家人身心清淨的緣故，才命那位在家人接受這筆金錢；但那位在家人不明就裡，所以嚇得不敢當場接受，這就違背了清淨施捨的法度。比丘應當為那人將財物收下，因為既然已經徹底捨棄給了對方，在名義上這筆錢財就已經屬於該淨人所有了。如果比丘需要拿這筆錢去買布做僧衣，就必須換一個人來代為接受，這是因為先前建立的淨法尚未徹底圓滿的緣故。從「若彼」以下，第四個步驟是指如果該淨人完全理解比丘的用意。比丘就可以直接將這筆錢財轉化為清淨的購衣物資，不需要再大費周章地輾轉調換淨人。從「若」字以下，特別詳細說明比丘應當宣說的「淨語」內容。

【276-0007】資持記/08d_中二#52
【原文】疏云：看是謂看於錢寶；知是，謂非我所作，為淨與爾，何得不道，失法故吉。《僧秖》，初明知事藏取法。裹眼三旋，意令迷處，防盜損故。若施主下，次明受用寶器法。應言等者，謂有緣開口受。不得字，貫下三相。不讚歎者，表非所好，抑彼貪故。此下，總點。
