# 校閱材料　第203檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【203-0001】01_行事鈔/09b_卷下之一#15
【原文】二簡施主法。就中，衣、藥、鉢、寶、穀米等，並須施主。前明上三施主。《僧祇》云：五眾得作。《善見》云：展轉者，五眾中隨得一人作施主；真實者，至一比丘所，不言對沙彌也。《五分》云：五人不應作：一不相識，二未相諳悉，三未相狎習，四非親友同師，五非時類。復有四人：一不能讚歎人，二不與人好名稱，三應淨施五眾，四不得與白衣。義準前五真實淨主；後四展轉淨主。《十誦》：不得稱二三人作淨，應與一人。若將他淨施物不還，應索取；不得者，彊奪取，語言：「佛有教，為清淨故與汝；汝今將去，已犯吉羅。」自今已去，說淨者應籌量，與一好人。《薩婆多》：求持戒多聞有德者而作，除惡邪、四重、得戒沙彌，聾盲瘂瞎、顛狂心，行別住、六夜、五法人等。為令清淨作證明，不生鬪諍，如上等人，則不如法；非此人者，用為施主，後得物已，於一比丘邊，稱施主名而說淨。錢寶穀米等，並以俗人為淨主。《涅槃》云：雖聽受畜，要須淨施篤信檀越。《薩婆多》云：先求知法白衣等，如後所說。
【譯文】二簡施主法。在當中，衣服、藥品、鉢、珍寶、穀米等，都必須有施主。先說明前三種（衣、藥、鉢）的施主。《僧祇律》說：出家五眾都可以擔任施主。《善見律》說：所謂展轉淨施，五眾之中任尋一人皆可作為施主；若是真實淨施，則必須到一位比丘處作法，不說對沙彌作。《五分律》說：有五種人不應作為施主：一是不相識的人，二是彼此不熟悉的人，三是未曾親近交往的人，四不是親友同門師兄弟，五不是同一輩類。又有四種人（的原則）：一是不會讚歎人，二是不給人好名聲，三應當淨施給五眾，四不得給俗人白衣。按義理推準，前五條是指真實淨施的淨主；後四條是指展轉淨施的淨主。《十誦律》說：作淨施時，不得稱說兩、三個人的名字，應當只給一人。如果有人把別人的淨施物拿走不還，應當索討取回；若索討不給，可以強行奪回，並對他說：「佛陀有教誡，為了使物清淨才施與你；你現在據為己有拿走，已經犯了突吉羅。」從今以後，作說淨的人應當仔細考量，託付給一個好人。《薩婆多論》說：應當尋求持戒、多聞、有德行的人來做淨主，排除被處舉治之惡邪者、犯四波羅夷罪者、受學悔之得戒沙彌、聾盲瘖啞瞎眼者、精神顛狂者，以及正在行別住、六夜、五法等受罰之人。因為為了令物清淨、作證明、不生諍鬥，上述這類人則不如法；若是除這類人之外的清淨者，選用他為施主，之後獲得物品時，在另一位比丘面前，稱呼這位施主的名字而作說淨。錢財、珍寶、穀米等，全都以世俗之人作為淨主。《涅槃經》說：雖然聽許接受蓄存，但必須淨施給深具篤信的檀越。《薩婆多論》說：應先尋求通曉佛法的白衣俗人等，如同後文所說明的那樣。

【203-0002】01_行事鈔/09b_卷下之一#16
【原文】三請法聽不。先明須請。《薩婆多》云：應求多聞人等。若死、往他國者，更求清淨者作。欲令作證明，則名如法，故知對面請也。乃至錢寶，亦言：語令知比丘法，今以檀越為淨主。此明文開請。次明似不須請。《五分》云：於五眾中，隨意與之。請法，應具儀至大德所前，告本意，許可已，然後說言：「大德一心念！我比丘某甲，今請大德為衣藥鉢展轉淨施主，願大德為我作衣藥鉢展轉淨施主。慈憫故！」三請。若至尼所，告云：「我今請比丘尼，為展轉淨施主，幸願為之。」真實淨者。文云：「大德一心念！今請大德為衣藥鉢真實淨施主，願大德為我作真實淨施主。慈憫故！」寶施主者，《多論》云：先求知法白衣語之；若不知者，告令解之。至彼所云：「比丘之法，不得畜錢寶金銀穀米等。今以檀越為淨施主；後得錢寶，盡施檀越。」次明合說進不。《薩婆多》云：錢寶穀米，並同長衣，十日說淨。《涅槃經》云云。
【譯文】三、延請淨主之法是否聽許。首先說明「必須延請」之說。《薩婆多論》說：應當尋求多聞之人等擔任淨主。如果該施主過世，或者前往其他國家，就應當重新尋求清淨的人來做。想要讓他充當證明，才稱得上合如教法，由此可知必須當面延請。乃至於錢寶，也說：應當告知俗人使其明白比丘之法，說明現在以檀越為淨主。這是律論明文開示必須延請的依據。其次說明「看似不須延請」之說。《五分律》說：在出家五眾之中，隨意指定施與即可。延請之法：應當具備威儀來到大德尊前，陳述自己的本意，對方應允許可之後，然後陳白說：「大德一心念！我比丘某甲，現在祈請大德作為我衣服、藥物、鉢的展轉淨施主，願大德為我作衣服、藥物、鉢的展轉淨施主。慈愍故！」如是請三遍。如果前往比丘尼處，則稟告說：「我現在祈請比丘尼，作為展轉淨施主，希望能為我擔任。」若是延請真實淨主，律文說應言：「大德一心念！現在祈請大德作為我衣服、藥物、鉢的真實淨施主，願大德為我作真實淨施主。慈愍故！」若是延請珍寶淨施主，《薩婆多論》說：先尋找通曉佛法的白衣告訴他；如果他不懂，就教導告知令他明白。前往他的處所說：「比丘的戒法，不得蓄存錢財、珍寶、金銀、穀米等物。現在以檀越作為淨施主；以後我若得到錢寶，全都布施給檀越。」其次說明錢寶是否應當作說淨。《薩婆多論》說：錢寶、穀米，全都等同於長衣，應在十天之內作說淨。《涅槃經》云云（已如上引）。
