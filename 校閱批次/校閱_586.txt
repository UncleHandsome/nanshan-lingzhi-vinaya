# 校閱材料　第586檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】（非時無故進入聚落戒）具備五個條件即構成犯罪：一是時間不合規矩（過了正午的非進食時段），二是沒有事先受請或召喚的因緣，三是沒有向同住同修託付告知，四是走向俗家人的住舍，五是一腳跨進家門即犯波逸提罪。《十誦律》說，如果阿蘭若處的比丘向同修告白後進城入聚落，返回阿蘭若處之後，又憑著剛才的告白再次進入聚落，犯波逸提罪；如果告白進入聚落，從聚落出來到了原來的僧坊，又再次折返進入聚落，也以此前的告白為由擅自進入，犯波逸提罪；在同一結界內若有同修善比丘在，不先向其告白就擅入聚落，犯波逸提罪。不向同修告白的比丘，每經過一條大街或小巷，就各犯一個突吉羅罪；每進入一家白衣舍宅，就各犯一個波逸提罪。如果進入阿蘭若處，或者進入靠近聚落的僧坊，就算不告白也沒有罪過。《薩婆多毘尼毘婆沙》說，如果總體向同修告白要進聚落，之後在聚落中隨意走動前往各處，都不算犯戒。《摩訶僧祇律》說，如果多人結伴在路上行走想要進入聚落，應當輾轉互相告白，然後才可以進入；如果已經抵達住宿之處，又想外出砍取柴草木料，若是沿著原本走的路出去則不犯戒，若是改從其他道路出去卻沒有告白，犯波逸提罪。《大智度論》說，一切在家人居住的房舍都總稱為聚落。《善見律毘婆沙》說，有集市買賣的稱為聚落，沒有集市買賣的稱為村界。依照本律，如果有事先告白，或者受人請託召喚，或者只是趕路途中穿過聚落，都不算犯戒。

【譯文】（剃除三處體毛戒）犯此戒的構成要件容易理解。《毘尼母論》說，出家人剃除毛髮，只能剃除頭髮和鬍鬚，其餘部位的體毛一律不准刮除。剃除頭髮的本意，是為了斷除傲慢與自命不凡之心；戒律不許使用銳利的木刀在刮汗時順便剔除體毛，若是剃斷一根毛就各犯一個突吉羅罪（剃除頭上的毛髮不犯戒）；若是刮斷其餘部位的體毛，每刮斷一根各犯一個偷蘭遮罪。剃髮有四種先後順序：一是按照戒臘從上座先剃，二是頭髮長的人先剃，三是洗好頭的人先剃，四是有要事即將遠行的人先剃。《五分律》說，比丘尼超過半個月不剃髮，犯波逸提罪。《涅槃經》說，指甲和頭髮留得又長又尖銳，是破戒的徵相。依照本律，不得為在家人剃髮供其驅使役使，違者犯波逸提罪；但如果是為發心準備出家的人剃髮，則不犯戒。頭髮長到極限，若是過了兩個月，或者長度達二指長，就必須剃除一次；指甲最長若達到一粒麥子的長度，就必須修剪；頭髮不得用剪刀剪截，每半個月應剃頭一次、修剪指甲一次，違背規矩者犯突吉羅罪。允許蓄備裝盛剃落頭髮的器具。《十誦律》說，頭髮應當深埋在坑穴中；如果頭髮長了，開許蓄備剃刀及刀鞘；如果刀刃捲口，可以在手掌上或砥石上打磨，打磨用的砥石應收納在刀囊之中。

【586-0016】04_比丘尼鈔/04b_卷中之下#34
【原文】共男子入暗室戒前是覆障屏有窻牖光明無第三人犯今以其暗室故生患處重雖有多人猶犯以此為異故別制也五分云共男子入暗室語語提若恐怖處若卒燈滅不犯義云不問親與非親須有燈明惡心呪詛戒具三緣犯一有瞋心二作惡呪詛三言詞了了便犯此律云立誓者令稱南無佛提謂經云南者歸無者命佛者覺又南者禮無者大佛者壽。
【譯文】（與男子共入暗室戒）前面一條戒律是指有屏障遮擋但有門窗光線透入、因身邊沒有第三人而犯戒；本戒則是因為置身在昏暗無光的房間內，滋生過患之處更為嚴重，所以即便身邊有多人在場，仍然構成犯戒，正是因為這一點差異而另外制戒。《五分律》說，與男子同入暗室內交談，只要一說話就犯波逸提罪；如果是在令人恐懼的處所，或者燈火突然熄滅，則不犯戒。法義上說，無論對方是親戚還是非親戚，都必須點亮燈燭照明方得同處。（以惡毒心咒詛戒）具備三個條件即構成犯罪：一是內心懷有瞋恨，二是口中發出惡毒咒詛之詞，三是言語詞意清楚明白即犯波逸提罪。依照本律，若要發誓，應當令其稱念「南無佛」，《提謂經》說：「南」是歸依，「無」是歸命，「佛」是覺悟；又解釋說，「南」是敬禮，「無」是廣大，「佛」是無量壽。

【586-0017】04_比丘尼鈔/04b_卷中之下#35
【原文】因瞋心推𦙄哭戒具四緣犯一同於諍事不善憶持二內瞋恨三推𦙄哭已四隨便淚墮一一提僧祇云若尼自打不啼啼而不打亦打亦啼俱提。
【譯文】（因瞋恨心搥胸啼哭戒）具備四個條件即構成犯罪：一是參與諍論之事卻不能妥善如法憶持處理，二是內心懷抱瞋恨，三是搥打胸膛痛哭，四是眼淚隨即落下，每落一次淚各犯一個波逸提罪。《摩訶僧祇律》說，比丘尼若是自己捶打身體而不哭泣，或者只哭泣而不捶打，或者既捶打又啼哭，全都犯波逸提罪。

【586-0018】04_比丘尼鈔/04b_卷中之下#36
【原文】覆身同牀戒具四緣犯一同牀臥二覆身三無病緣四隨臥便犯同被褥臥同牀不同被褥同牀同被褥不同牀在地上臥亦犯。
【譯文】（與人同床蓋同一被褥戒）具備四個條件即構成犯罪：一是同在同一張床上躺臥，二是覆蓋同一條被褥，三是沒有患病的特殊因緣，四是隨即躺臥即犯波逸提罪。兩人同蓋一條被褥躺在同一張床上、同床不同被褥、同被褥不同床、甚至在地上合蓋同一條被褥躺臥，也都算犯戒。

【586-0019】04_比丘尼鈔/04b_卷中之下#37
【原文】故惱客舊戒具四緣犯一知他比丘尼先住後至二作故惱心三在前誦經問義四言詞了便犯。
【譯文】（故意惱亂客宿或舊住比丘尼戒）具備四個條件即構成犯罪：一是明知其他比丘尼是先來常住或是後到的客人，二是存心故意去惱亂對方，三是在對方跟前高聲誦經或研討詰問經義，四是言語音聲清晰即犯波逸提罪。

【586-0020】04_比丘尼鈔/04b_卷中之下#38
【原文】同活病不看戒具四緣犯一是比丘尼病二是同活三無因緣四不看便犯五分云同學病不看提同學者謂同和尚阿闍棃及常共伴若止住不同無犯。
【譯文】（同住弟子患病不予照看戒）具備四個條件即構成犯罪：一是對方是生病的比丘尼，二是彼此屬於同師共住照料的關係，三是自己沒有特殊正當因緣，四是不去探視照看即犯波逸提罪。《五分律》說，同門同學生病不去照看，犯波逸提罪。所謂同學，是指依止同一位和尚、阿闍梨，或者是經常結伴同修的人；如果平時居住不同處，則不犯戒。
