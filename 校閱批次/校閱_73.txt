# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【73-0001】02_戒疏/03a_卷一下之一#111
【原文】【記】三分解中。初釋「當結」，即默妄罪。「當」，猶將也。次釋「當說」，即下序文召令懺露。「交」，猶對也。三釋「當發起」。「八段」即序八章。
【譯文】【記文】在三分科解中。首先解釋「應當制立」，就是指默然妄語的罪責。「當」就像將要的意思。其次解釋「應當宣說」，就是指下文序文中召喚眾人出面發露懺悔。「交」如同當面、眼前的意思。第三是解釋「應當發起」。「八段」就是指戒序中的八個章節。

【73-0002】02_戒疏/03a_卷一下之一#112
【原文】【記】問：「此釋初段，正說發起，云何都以八段為『當』？」
【譯文】【記文】有人問：「此處正在解釋第一段，正是在說發起序，為什麼把整個八段通通稱為『應當』？」

【73-0003】02_戒疏/03a_卷一下之一#113
【原文】【記】答：「初略標宗，望後多分，猶未陳說，故通指之。」
【譯文】【記文】回答說：「最初只是簡略揭示宗本，放眼後面絕大部分的內容，都尚未陳述宣說，所以作通盤的統稱指涉。」

【73-0004】02_戒疏/03a_卷一下之一#114
【原文】【疏】上有三當，總是緣漸。八篇正戒，輕重條然顯示，故云「演布開現」也。
【譯文】【疏文】上面有三個「應當」，全部都是逐步漸進的發起因緣。八篇清淨正戒，輕重層次條分縷析地昭示顯露，所以稱為「廣泛演說陳布顯現」。

【73-0005】02_戒疏/03a_卷一下之一#115
【原文】【記】正宗中。上二句躡前。「緣漸」即發起義。「八」下，正釋。「現」即示也。
【譯文】【記文】在正宗分中。上面兩句承接前文。「漸進因緣」就是發起的意思。「八篇」以下是正式解釋。「現」就是彰顯昭示。

【73-0006】02_戒疏/03a_卷一下之一#116
【原文】【疏】廣教流通，篇別重舉。恐有理墜，罔冐將來，故云「反覆分別」也。
【譯文】【疏文】廣博的教法為了流布傳承，每一篇各自分門別類重複提問宣告。唯恐義理沉沒遺失，蒙蔽誤導了未來的行者，所以說「反覆周詳地區別辨明」。

【73-0007】02_戒疏/03a_卷一下之一#117
【原文】【記】流通中。初二句指文。「篇別重舉」，謂牒前已說，即是反覆也。「恐」下，示意。誦有遺漏，則是「沉墜」。誤於後傳，故言「罔冐」。
【譯文】【記文】在流通分中。前面兩句指示經文。「每一篇重複提問宣告」，是指再次提說前面已說過的戒相，這就是反覆叮嚀。「唯恐」以下顯露其用意。誦持若有遺漏，就是戒法「沉沒廢墜」。若是誤導了後世的傳承，所以稱作「蒙蔽誤導」。

【73-0008】02_戒疏/03a_卷一下之一#118
【原文】【疏】有人云：「八篇正宗，各有三致，何得通收廣教？如初篇中『諸大德四棄』即『當發起』；中開四相，列坐齊聞，即『布現』；後結三問，重條前章，即『反覆分別』。並是聖言引用，何得不依！」
【譯文】【疏文】有人說：「八篇正宗分各自具有這三種起承轉合，怎能通用來總括整部廣博教法呢？好比初篇中『諸大德四棄法』就是『應當發起』；中間開展四條罪相、列坐齊聽，就是『陳布顯現』；最後結尾三度審問、重新覆述前章，就是『反覆區別』。這些全都是聖人言教所明文引用的，怎能不予遵循！」

【73-0009】02_戒疏/03a_卷一下之一#119
【原文】【記】他解中。初立義指斥。「如」下，舉初篇別配。此則唯就正宗明之。然前列三當，此師但舉發起一義，餘二文略，義必通含。「並」下二句，似是他師結責之詞，又如疏家取用之語。上文配釋，全據本經，故云「並是聖言」也。
【譯文】【記文】在轉述其他法師的解說中。起初立論並提出斥責。「好比」以下列舉初篇做個別對配。這就純粹是就正宗分來進行闡釋。然而前面列出三個「應當」，這位法師只引用了「發起」這一條義理，其餘兩項雖然文略，但義理必定相通包含。「這些」以下兩句，看似是那位法師總結責問的語句，也像是疏主道宣律師採信吸收的言語。上面對配的解釋，完全是依據律藏原本，所以說「全都是聖人言教」。

【73-0013】02_戒疏/03a_卷一下之一#123
【原文】【註】佛言：「同羯磨者集在一處，乃至應訶者不訶，是名如法。」
【譯文】【註文】佛說：「共同作羯磨的人聚集在一處，乃至於應當提出反對的人沒有反對，這就叫做合乎佛法。」

【73-0014】02_戒疏/03a_卷一下之一#124
【原文】【疏】注云「同羯磨者來」，名身集也；形礙法通，須陳欲法，名心集也；身雖赴座，容有「訶止」，默忍法圓，名口集也。以斯三業，共成一僧，故云「集一處」也。
【譯文】【疏文】注釋中所說「共同作羯磨的人前來」，稱為身業的聚集；身體受阻但法制仍須相通、必須陳述傳達與欲之法，稱為意業心念的聚集；身體雖然親自赴座，但仍保有依法提出「諫阻反對」的權力，大家靜默默許令法事圓滿成就，稱為口業的聚集。以這身口意三業的如法，共同成就一個僧團，所以稱為「聚集在一處」。

【73-0015】02_戒疏/03a_卷一下之一#125
【原文】【記】釋注，初科。注文「乃至」字，略其心集。《疏》中備約三業解之。「形礙」，身有緣故。「法通」，可傳欲故。「法圓」，羯磨成辨故。「一僧」，「僧」即眾故。
【譯文】【記文】在解釋注釋的第一小節中。注釋中「乃至於」這幾個字，簡略帶過了心念傳欲的內容。《疏》中則周全地依據身口意三業來作解釋。「身體受阻」，是指身體遇到急難因緣。「法制相通」，是指可以合法傳欲。「法事圓滿」，是指羯磨法得以如法成就。「一個僧團」，「僧」就是大眾合和之意。

【73-0016】02_戒疏/03a_卷一下之一#126
【原文】【疏】又解云：「『同羯磨』者，明說正戒，行淨者同。自餘過犯不足數者，不同羯磨，不須集也。言『應與欲』者，謂此行教，不可自輕。大急要緣，事不獲已，方開與欲；自餘輕小，則不須也。且如病緣，重者輿來，少者僧就，可以知也。言『應訶』者，謂四羯磨、諸雜治人，行法在身，無容秉法，身雖足數，口不陳非故也。若斯陶練，方得實人，可不然也！」
【譯文】【疏文】另一種解釋說：「所謂『共同作羯磨的人』，是說明宣說清淨正戒，唯有行持清淨的人才能共同參與。其餘有違犯過失、不夠資格計入法定人數的人，不能參與共同的羯磨，也不需要集會。所謂『應當傳達與欲』，是說明這項行持與教法絕不可輕慢隨意。必須遇到極重大的緊急事故，萬不得已之時，才開許傳達與欲；其餘輕微小事，則一概不許缺席請託。況且如疾病因緣，病重能移者用擔架抬來僧中，不能移動且人數少者則由僧眾親往其處作法，依此即可明白。所謂『應當反對提出訶止』，是指正受四種處罰羯磨、以及各類正在受治罪處分的人，因為身上帶有處分罰則，沒有資格秉持僧事法制，雖然在場能補足法定出席人數，口中卻不得陳述異議。必須經過這樣的審查甄別，才能得到真正合乎法度的與會僧人，難道不是這樣嗎！」

【73-0017】02_戒疏/03a_卷一下之一#127
【原文】【記】佗解中三節，並約揀眾。一、簡足數。「過犯」謂三舉二滅人，更兼尼等四眾，瘂、聾、睡、狂等人。二、簡欲緣。「大急」即三寶、疾病等。三、簡合訶。「四羯磨」：一、訶責，二、擯出，三、依止，四、遮不至白衣家。此四，《律》名「得滿不得訶」。「諸雜治」者，即收行覆藏等人。竝由奪其智能，不得訶法；必非此等，方名「應訶」。「若」下，總結。「陶練」，即是揀擇。「實人」，謂合教者。
【譯文】【記文】在另一種解釋的三個層次中，全部都是針對甄選篩除會眾而論。第一、簡別合格的法定人數。「違犯過失」是指被判處三種擯舉、二種滅擯的人，還包括比丘尼等其餘四眾，以及啞巴、聾子、熟睡、狂亂失心等人。第二、簡別准許請假傳欲的因緣。「極重大因緣」是指守護三寶物資、突發重病等。第三、簡別有資格提出反對發言的人。「四種羯磨處分」是指：一、訶責羯磨，二、擯出羯磨，三、依止羯磨，四、遮不至白衣家羯磨。這四種在《律》中被稱為「得滿法定人數，但無權發言反對」。「各類受處分者」是指包括正在行履隱覆藏罪懺悔等處分的人。這些人全都被剝奪了正常的僧權智能，不能依法反對法事；必定要排除這些人，才稱得上是合格的「應訶止反對之人」。「必須經過」以下是總結。「甄查甄別」就是嚴格簡別挑選。「合格合法人員」是指完全合乎教法律儀的僧眾。

【73-0021】資持記/11c_中四上#32
【原文】今言迷倒，隨位皆有，是也。指通中，初句指前勸學。隨下，舉一類通。問：今家句法，總有幾句？答：若對四行，止持作犯，對事各有一九；作持止犯，竝對事法，各有二九，共四箇二九。若依《戒疏》，四行竝通事法，則八箇二九。若以二九通對諸戒，則二百五十戒，戒皆具二九；
【譯文】現在我們認為迷惘顛倒在每一個品位中都可能存在，說的就是這個意思。在指示通融之中，第一句是指示前面的內容並勸勉修學。從「隨下」開始，舉出一種類別來貫通全體。有人問：我們這一家所立的句法，總共有多少句呢？回答說：如果對應於「四行」（止持、作持、止犯、作犯），止持與作犯在對待事件上各自有一個九句；作持與止犯則同時對待事與法，各自有兩個九句，總共是四個「兩個九句」。如果依照《戒疏》，四行都完全通達於事與法，那麼就會有八個「兩個九句」。如果把這兩個九句普及對應到一切戒條，那麼二百五十條戒中，每一條戒都各自具備這兩個九句；

【73-0022】資持記/11c_中四上#33
【原文】乃至塵沙戒法，塵沙二九；又一一戒下，事法多別；隨事隨法，無非二九。類通法界，義在於此。第二方便，敘意中，初示三時。即方便、根本、成已也。是下，顯制意。剋，猶約也。略如上者，前優劣中，引律小妄三時之文。前方便，標問中。通三方便，望後根本，俱名為前。
【譯文】乃至面對塵沙般無量的戒法，就有塵沙般無量的兩個九句；又在每一條戒之下，事與法又各有許多區別；隨其事或隨其法，無不具備這兩個九句。能這般類推貫通於一切法界，深刻的義理就在於此啊。第二部分關於方便罪，在敘述大意之中，首先展示造業的三個時段。也就是方便、根本、成已三時。從「是下」開始，顯示制戒的深意。「剋」的意思就是約束或依據。所謂「略如上述」，是指前面在評斷輕重優劣時，所引用律文論及小妄語三時的那段文字。在前方便這部分，標題提問中。這個詞通攝三種方便，相對於後面的根本罪，都總稱為「前」。

【73-0023】01_行事鈔/08a_卷中之四#65
【原文】今通會輕重。約初篇中淫戒以明。如內心淫意，身口未現，名遠方便，此犯吉羅。故文云：或發心作，心念作也。若爾，與單心何別？答：律制，動身口思心，名為期業；若單心者，制限大乘。故《善見》云：凡人恒緣欲境，聖人若制心戒者，無有得脫之期。故律中起心，不動身口，但自剋責，還復好心，是名不犯。二動身口，未到前境，名次方便，犯偷蘭。三者臨至境所，身分相交，未至犯處已來，名近方便，是重偷蘭。已下諸聚，雖輕重多少不同，大相可準。
【譯文】如今融通匯合其輕重。依初篇之中的淫戒來闡明。如果內心起了淫念，身口尚未表現出來，稱為「遠方便」，這犯了突吉羅。所以文中說：「或者發心作，指心念造作。」若是如此，這與「單純起心」有何區別？答：律藏所制的，是鼓動了身、口意圖的「思心所」，稱為「期業」（預定成辦之業）；如果是單純起心動念，那是大乘戒法所制伏的界限。所以《善見論》說：「凡夫總是恆常攀緣欲境，聖人若是制立起心即犯的心戒，凡夫便沒有得以解脫的時期了。」因此律中起心動念而未牽動身口的，只要自我責厲，回復善心，這就名為不犯。第二、牽動了身口，但尚未到達對境之處，稱為「次方便」，犯輕偷蘭遮。第三、臨近到達境緣之所，彼此身分已經交觸，但在未到達正犯部位（入如毛頭）之前，稱為「近方便」，這是重偷蘭遮。以下各篇聚，雖然輕重與階段多少有所不同，但大體行相皆可依此準則推知。
