# 校閱材料　第579檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【579-0001】02_戒疏/10b_卷三上之一#47
【原文】【疏】二、明自謗、覆、說。初自謗無罪者，謗他擯惱，枉治犯殘，自過尚覆，豈輒言犯？自覆吉者，覆他過多，有本故重，自覆過輕，無本故微。自說義稀故輕，說他事數故重。
【譯文】【疏文】第二、說明對自己進行毀謗、覆藏、宣說的情況。首先，自己毀謗自己並無罪名，因為毀謗他人是為了驅逐惱亂對方，使他人蒙冤受治才結犯僧殘，自己的過錯尚且想隱瞞覆藏，哪裡會隨便說自己犯罪？自己覆藏自己的過錯結犯突吉羅，是因為覆藏他人的過失太多，有明文戒律根本依據所以罪重，自己覆藏自己過失的情節較輕，沒有特設根本重條所以罪責微小。自己宣說自己的罪過在常理上很少見所以結罪輕，宣說他人罪過的事情很頻繁所以結罪重。

【579-0002】02_戒疏/10b_卷三上之一#48
【原文】【記】二、明自中，初科。三位自別。覆中「有本」者，「本」即指戒。以覆他自淨，重制令露。自覆己穢，故不須制。
【譯文】【記文】第二、在說明自己之中，第一科。三種地位各有不同。覆藏中所謂「有本」，「本」就是指戒條。因為覆藏他人之過而圖自己清淨，所以從重制戒要求揭露。自己覆藏自己的污穢，所以不需要特別制重罪。

【579-0003】02_戒疏/10b_卷三上之一#49
【原文】【疏】問：「前言自謗無罪，今何自說得吉者？」
【譯文】【疏文】提問：「前面說自己毀謗自己沒有罪，現在為什麼自己宣說自己的罪過卻得突吉羅罪呢？」

【579-0004】02_戒疏/10b_卷三上之一#50
【原文】【疏】答：「論謗在僧，自故非犯。說罪在俗、未具，招譏同故得吉。」
【譯文】【疏文】回答：「討論毀謗罪著眼在僧團之中，毀謗自己所以不構成犯罪。宣說罪過則是著眼於向俗人、未受具足戒者宣揚，同樣會招致世人的譏嫌，所以結犯突吉羅罪。」

【579-0005】02_戒疏/10b_卷三上之一#51
【原文】【記】次引難中。謗、說有無，理非所隱，欲明教意，故復徵之。答文，可解。
【譯文】【記文】其次在引發難問中。毀謗與宣說罪名的有無，其法理本不隱蔽，但為了彰顯制定教法的深意，所以再次追問。回答的文義，容易理解。

【579-0006】02_戒疏/10b_卷三上之一#52
【原文】【疏】三、明僧尼互謗、覆、說者。
【譯文】【疏文】第三、說明僧尼相互毀謗、覆藏、宣說的情況。

【579-0007】02_戒疏/10b_卷三上之一#53
【原文】【疏】初明其謗。僧尼雖殊，枉治莫別，俱廢正修，同犯僧殘。
【譯文】【疏文】首先說明毀謗。比丘與比丘尼雖然身分有別，但使其遭受枉屈懲治並無二致，都荒廢了正法修持，所以同樣犯僧殘罪。

【579-0008】02_戒疏/10b_卷三上之一#54
【原文】【記】三、明僧尼互，初互謗中。尼是下流，謗同僧犯，故須辨之。文中所敘，同有二種：一、治擯同，二、廢業同。
【譯文】【記文】第三、說明僧尼相互，在首先的相互毀謗中。比丘尼身分在比丘之下，但毀謗她所犯之罪與毀謗大僧相同，所以必須加以辨析。文中敘述，相同處有兩種：一是懲處驅逐相同，二是荒廢修業相同。

【579-0009】02_戒疏/10b_卷三上之一#55
【原文】【疏】說、覆以論。
【譯文】【疏文】從宣說與覆藏來討論。

【579-0010】02_戒疏/10b_卷三上之一#56
【原文】【疏】僧尼互覆，罪無階降。尼同類中，自分三品。
【譯文】【疏文】僧尼相互覆藏罪過，結罪沒有層級升降的差別。而比丘尼在同階層之中相互覆藏，則自身分為三個等級。

【579-0011】02_戒疏/10b_卷三上之一#57
【原文】【記】次明覆說，互覆中，初科。罪同提、吉，故「無階降」。「同類三品」者，覆夷犯重，覆殘犯提，覆提已下皆吉。
【譯文】【記文】其次說明覆藏與宣說，在相互覆藏中，這是第一科。結罪同樣是波逸提或突吉羅，所以「沒有等級升降」。「同階層分三等」，是指比丘尼覆藏波羅夷犯重罪，覆藏僧殘犯波逸提，覆藏波逸提以下皆犯突吉羅。

【579-0012】02_戒疏/10b_卷三上之一#58
【原文】【疏】問：「尼說大僧，則違敬法，何故覆罪乃制提者？」
【譯文】【疏文】提問：「比丘尼向他人宣說大僧的罪過，就違背了八敬法，為什麼覆藏大僧之罪反而要判為波逸提呢？」

【579-0013】02_戒疏/10b_卷三上之一#59
【原文】【疏】答：「制尼說過不對犯者。但明所隱，同類便得；故不露罪，情過得提。」
【譯文】【疏文】回答：「制止比丘尼宣說大僧過錯，是不允許她當面指責比丘的過犯。但就隱瞞遮蔽罪行而言，只要對同類眾中有所隱瞞便成立覆藏；所以不揭露大僧之罪，就其包庇私情之過，結犯波逸提。」

【579-0014】02_戒疏/10b_卷三上之一#60
【原文】【記】釋疑中。說既違敬，覆不當制。答中。初明敬法不許對僧。「但」下，次明覆犯自論同類。
【譯文】【記文】解釋疑問中。宣說過失既然違背八敬法，覆藏罪理應不該制為重罰。回答中。首先說明八敬法不允許比丘尼當面指責大僧。從「但」往下，其次說明覆藏的結犯是從同類眾中隱瞞過失來論定的。

【579-0015】02_戒疏/10b_卷三上之一#61
【原文】【疏】互說之相，準前可領。
【譯文】【疏文】相互宣說過錯的情相，準照前面的法理就可以領會。

【579-0016】02_戒疏/10b_卷三上之一#62
【原文】【記】互說中。僧尼互說，同類自說，同是提、吉，竝無階降，故云「準前」。
【譯文】【記文】在相互宣說中。僧尼相互宣說，同類之間相互宣說，同樣都是波逸提或突吉羅，並無階位降等，所以說「準照前面」。

【579-0017】02_戒疏/10b_卷三上之一#63
【原文】【疏】注中「隨前所犯」者，舉四篇謗，隨謗分罪也。
【譯文】【疏文】注文中所謂「隨前所犯」，是列舉四篇罪名進行毀謗時，隨著所毀謗的篇聚來分別結罪。

【579-0018】02_戒疏/10b_卷三上之一#64
【原文】【記】牒釋中，初科。「舉四篇」者，除四重也。「隨謗分罪」，諸提、吉也。
【譯文】【記文】引文解釋中，第一科。「舉四篇」，是指除去初篇四重罪（四波羅夷）之外的其餘四篇。「隨謗分罪」，是指各類波逸提、突吉羅。

【579-0019】02_戒疏/10b_卷三上之一#65
【原文】【疏】問：「謗人惡說，還犯惡說者，及上初篇，還應大重？」
【譯文】【疏文】提問：「毀謗他人犯惡說罪，毀謗者回過頭來也犯惡說罪；那麼若毀謗前面最初的初篇重罪，毀謗者是否也應該結犯最大的重罪（波羅夷）呢？」

【579-0020】02_戒疏/10b_卷三上之一#66
【原文】【疏】答：「結罪分齊，各有指歸。輕重有由，階降論罪。小下無名，止同篇聚。若還有者，無窮之咎。」
【譯文】【疏文】回答：「結罪的界限與分寸，各自有其宗要依歸。罪業輕重皆有特定的根由，是依據階梯等級來判定罪罰的。最下等之罪（惡說）其下已無更低階的罪名，所以只能止於同一篇聚。如果其下還要再有罪名（來降階結罪），就會陷入罪位無窮無盡的過咎。」

【579-0021】02_戒疏/10b_卷三上之一#67
【原文】【記】問惡說中。以能所犯同，例上應爾。答文，初通示判犯不可一定。「輕」下，次明前判三位不同。「小」下，正答惡說同篇之意。
【譯文】【記文】在詢問惡說罪中。提問者認為能謗與所謗之罪相同，依例推照上面也應當如此。回答的文字，首先普遍說明定罪判刑不可一概而論。從「輕」往下，其次說明前面所判定三種地位的差異。從「小」往下，正面回答惡說罪歸入同一篇聚的用意。

【579-0022】02_戒疏/10b_卷三上之一#68
【原文】【疏】就「不犯」中。言「說實」者，有五：一、想心實；二、瞋境實；三、前事實，如張王、青黃等；四、三根非互實；五、四戒不互實，如《十誦》四重互說成謗。
【譯文】【疏文】在「不犯」的條款中。所謂「說實話」，包含了五項實情：第一、心中的認定確實如實；第二、所瞋恨的對象確實無誤；第三、眼前的事件確實發生，例如確實是張某或王某、青色或黃色等；第四、見、聞、疑三根沒有張冠李戴，確實如實；第五、四種重戒沒有相互混淆，確實如實，例如《十誦律》中將四重罪相互混淆宣說，依然構成毀謗。

【579-0023】02_戒疏/10b_卷三上之一#69
【原文】【記】不犯中。「想心實」者，意謂不淨也。「瞋境實」，所對不謬也。「前事實」，所見何等事也。餘二可解。具五則開，闕一成謗。
【譯文】【記文】在不犯條款中。「想心實」，是指心中確實認定對方不清淨。「瞋境實」，是指所針對的人沒有認錯。「前事實」，是指親眼所見的具體事件。其餘兩項容易理解。五項條件全部具備才能免除罪責（開緣），缺少任何一項就構成毀謗罪。
