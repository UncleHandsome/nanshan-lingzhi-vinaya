# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】第六項殯葬後事：《五百問事》說：師長過世，不得放聲大聲號哭，只應暗自低聲流淚而已。本律中規定比丘尼搥胸痛哭啼泣流淚，每一聲都結波逸提墮罪。義理上解釋說：這是因為愛染之情未除，世俗習氣未能捨棄的緣故；但如果是高尚節操、清修幽居之人，原本不貪著世俗情感，為了引導眾生生起善念而哭泣，又有何罪過？因此世尊在雙沙羅樹間入滅後，諸大比丘悲痛得在地上翻滾，如同圓木輾轉，搥胸大叫，淚下如雨；他們雖然尚未完全離欲，卻不會招致世人的譏嫌。如果外地前來弔唁的人戒臘小於亡者，到了遺體停放處，應當依照常規行禮，先握住亡者首徒弟子的手，默默以言詞慰問哀悼；然後走到長老大德住處，充分陳述哀思，行禮拜見問候。《五百問事》及《四分律》等都記載：如果看見塚塔所葬之亡者戒臘長於自己的，都應當行禮致敬。《五百問事》說：應當先向僧團稟白，用亡者生前穿的泥洹僧裙和僧祇支覆蓋遺體而送去殯葬，陪葬物品的價值不得超過五錢，超過便犯重罪。亡者的師長、弟子或同學道友，應當籌募資財辦理殯葬；如果沒有物資可以送殯，全體僧眾或個別僧人應當各自出少許資財，供養遺體舍利；如果全無財物，應當先暫借亡者生前遺物充當費用以辦理喪葬，事後加倍償還；或者行完羯磨法後，向現前全體僧眾乞討資助，也是可行的。《五分律》說：亡者遺體應當用衣服蓋住下身私處。《毘尼母論》說：不得隨意跟隨送葬隊伍，除非是為了觀修無常之理才不犯戒；如果是親手扶持母親遺體入殮殯葬，並無罪過。《增一阿含經》說：如來與阿難、羅睺羅親自抬起姨母（養母）摩訶波闍波提的靈床，不讓其他人代勞，這是為了報答親恩的緣故。從義理上說：和尚阿闍梨長養我們的法身慧命，生身父母兄弟長養我們的肉身，恩德既然深重，親自肩擔送葬，想來也是沒有過失的。只是絕不可以改換喪服。近來見到邊遠鄉野地區的僧尼，披著袈裟服喪，使用粗布死白之色，全同於世俗喪制；佛法滅亡的徵兆，沒有比這更嚴重的了！因此《摩耶經》說：佛陀滅度一千三百年後，各位比丘的衣服將漸漸變成純白，不再接受染色，應當知道佛法衰微毀滅的時期就不遠了。西域印度的葬法有四種：一是水葬，二是火葬，三是土葬，四是林葬（棄置樹林餵禽獸）。《五分律》說：屍體應當埋入土中；如果火化，應在平整石頭上焚燒，不得放置在青草地上。本律記載，只有如來與轉輪聖王二種人合乎全身火葬。《五百問事》說：可以為亡故的師長塑造聖容畫像。《僧祇律》說：持律法師、經手寺務的比丘、具備高尚德望的比丘，逝世後應當建造寶塔，掛上相輪，懸掛擺設幡蓋莊嚴，但必須安置在清靜偏僻處，不得設置在經行繞塔處或多人行走的通道上；若違背規定便結罪。如果僧團大眾不允許建塔，應當從中調解，使大眾和合共識後再行動工。

【625-0004】04_比丘尼鈔/06a_卷下之下#66
【原文】第一制意者問所以五眾身亡物皆入僧又依三寶出家何為不兼入佛法耶答以生存之日因僧受施身行所為僧寶所攝縱施佛法僧亦無分是以身亡之後追物入僧佛法無分親俗亦不合得故十誦云難陀死後諸親白衣競來諍物佛判不與欲使三寶位別無招互用之咎道俗形殊又無債索之諍。
【譯文】第一項制定本戒的用意：有人問：為什麼五眾出家人亡故後，遺物都要收歸僧團所有？既然是依止三寶出家，為何不分一部分歸入佛寶和法寶呢？回答說：因為出家人在世之時，是仰仗僧團的名義接受十方信施，身心的一切行持，都屬於僧寶所統攝；即便信徒供養的是佛寶和法寶，僧眾也不能從中分潤。因此出家人身亡之後，追溯財物應當全部入歸僧寶，佛寶與法寶無權分受，俗家的親族更不應當繼承。因此《十誦律》說：難陀比丘去世後，各位在家的親屬爭相前來爭奪遺物，佛陀判定全數不給；這是為了讓三寶的財位分明，不招致互相挪用混淆的過咎，同時也顯出道俗身分的懸殊，避免了索討遺產債務的紛爭。

【625-0005】04_比丘尼鈔/06b_卷下之下#1
【原文】第二簡物者此門有四一糞掃想取五分云界中水漂死人挂樹枝上隨前見者得衣四分無人得取若二人已上便須作法分二入二部僧想取五分獨住死婆論云二界中間死此律無住處白衣家死隨五眾先來見者得取三入俗人親想取婆論云滅擯死將衣鉢付生緣以生時不同僧法故四入同和尚僧想取十誦云沙彌死所有內外衣白二羯磨與看病人輕物入僧重物不應分五分亦同此律無文依彼部斷。
【譯文】第二門辨別物品（簡物）包含四種情況：第一是作糞掃物想而取用，《五分律》說，在結界內被水漂流的死人掛在樹枝上，隨先看見的人獲得其衣服，而《四分律》則說無人可以隨意取走，若有兩人以上就必須依法羯磨分發；第二是作歸屬二部僧物想而取用，《五分律》說獨自居住而死，《毘尼母論》說在兩界中間死去，本律則說在無常住處的居士家死去，都隨五眾出家人中最先來見到的人可以獲得；第三是作歸屬俗家親屬想而取用，《毘尼母論》說被滅擯而死的人，將其衣缽交付給世俗親眷，因為他活著時就已不同於僧團法制的緣故；第四是作同師和尚之僧物想而取用，《十誦律》說沙彌死去，其所有內外衣服應作白二羯磨分給看護病人，輕物歸現前僧，重物不可分，《五分律》也有相同規定，本律雖無明文，應依彼部律典來裁決。

【625-0006】04_比丘尼鈔/06b_卷下之下#2
【原文】第三共財者義云若師本意唯與弟子衣食自外餘財不共同者已給者得未與者師亡以師物悉皆屬僧實非同生假冐同生取僧物者犯重若師本言所有財物決心同共看如兒想終無分別者若當別活還俗及死者悉共分半自著衣服現用器物各屬其身未用之財衣或取半是名共活不同活妄言而取能與之僧所受之人皆犯二罪謂重物入常住準僧祇犯重輕物入現前準善生犯蘭。
【譯文】第三門共有財物（共財），依教理說：如果師父本意只供給弟子衣食，此外的其餘財物不與弟子共有，那麼已經給予的歸弟子所有，尚未給予的，師父過世後全部歸屬於僧團，若不是真正財物共生，卻假冒共生之名擅取僧物，即犯重罪；如果師父當初曾發話，所有財物決心共同所有，看待弟子如同己子，始終毫無分別，那麼若是弟子另立生活、還俗或死亡，所有財物都平分一半，各自所穿衣服、現用器具歸各自所有，未用的財物衣服則取一半，這稱為共活；若非共同生活，卻妄稱共有而取用，能給予的僧眾與接受的人都犯兩種罪，即重物歸常住僧物，比照《僧祇律》犯重罪，輕物歸現前僧物，比照《善生經》犯偷蘭遮罪。

【625-0007】資持記/10a_中三下#20
【原文】彼明天竺說時有二：一名迦羅〔此云實時，謂年月日時四時部氣等，世俗背計為實故。〕，二名三摩耶〔此云假時。謂隨事緣，長短不定，無有實故。〕。佛隨世諦，說三摩耶不說迦羅，為除外道俗人邪見故〔俗人著有，外道計常；若說實時，更增彼計。此亦大分為言，非俱不說。〕。
【譯文】該論說明印度對於「時」的說法有兩種：第一種叫做迦羅〔這裡翻譯為實時，指的是年月日時、四季氣候等，世俗凡夫執著妄計為真實的緣故〕；第二種叫做三摩耶〔這裡翻譯為假時，指的是隨著事緣而定，時間長短不固定，沒有實體本質的緣故〕。佛陀順應世俗的道理，說假時而不說實時，是為了破除外道和俗人的邪見〔俗人執著實有，外道執著恆常；如果說實時，會更加增長他們的執著妄計。這也是大致而言，並非完全不說〕。

【625-0008】01_行事鈔/07b_卷中之三#35
【原文】食殘宿戒三十八。三緣：一是殘宿，二知是，三食咽咽犯。律中殘宿食者，今日受已至明日；於一切沙門釋子受大戒者，皆不清淨。四藥以論，過限結罪如前戒。《善見》、《十誦》、《五分》：大比丘受食已，或食未食，經夜名殘宿。問：殘之與宿，為一為異？四句答之：一殘而非宿，吉羅。二宿而非殘亦吉。三亦殘亦宿，提。四非殘非宿可知。殘宿、內宿，亦作四句：一是殘宿非內宿，得墮。二是內非殘。三四俱句，類知。有云，淨地無內宿。文云除去比丘，故知有也。律中，殘宿、不受食戒，以坐禪比丘為緣起者，為防未來惡比丘故。內無道觀，煩惱未伏；妄倚道業，便輕聖戒。此乃心涉愛憎，大我未伐；故諸三乘道人，並不輕戒。以深伐我根，傾慢使幢；敬戒而增道業，可不欽尚之哉。
【譯文】食殘宿戒三十八。具備三種緣成犯：一、食物確實是屬於吃剩或經夜的殘宿食；二、明知是殘宿食；三、下咽食用，每吞咽一口便結犯。《四分律》中說明：所謂殘宿食，是指今天正式接受了施主的受授之後，留存放置到了隔天黎明；這對於所有受了具足大戒的釋迦門下沙門弟子而言，通通都屬於不清淨的食物。若是就「四種藥物」的期限來論斷，凡是超過受持期限者，其結罪正如前一條戒中所明定。《善見律》、《十誦律》、《五分律》均指出：大比丘正式接受了食物之後，不論是已經吃過剩餘下來的，還是完全未吃過而留存下來的，只要經過了一夜，便統稱為殘宿。設問道：「殘」與「宿」，兩者是一樣的概念還是有所不同？以四種關係（四句）來解答：第一、是殘食而非宿食（如上午吃剩的飯未經作法，在中午前自己再吃），結突吉羅（吉羅）。第二、是宿食而非殘食（如昨天接受了未曾動口吃過的乾糧，隔天未經重新受授而吃），亦結突吉羅（吉）。第三、既是殘食又是宿食（昨天吃剩且又留置過夜），食用每咽一口結波逸提（提）。第四、既非殘食又非宿食，其合於律制之清淨自是不言而喻。關於殘宿與內宿（在僧房宿處內貯存過夜），同樣可以列為四句來辨析：第一、是殘宿而非內宿（在屋外經夜，或在界外放置），結波逸提（單墮罪）。第二、是內宿而非殘食。第三與第四種俱全或俱非之句，依此類推可知。有人聲稱：「如法作法的淨地之中不存在內宿之罪過。」然而律文中明白記載說，作法之淨地必須排除比丘在內起居住宿（方得宿食），由此可知（若不除去比丘）淨地之中確實也存在內宿之罪。在律典中，佛陀制定「殘宿食戒」與「不受食戒」，追溯其最初結戒的起因，皆是以山林中坐禪比丘貪圖打坐不出行乞食而儲存食物為緣起；這是佛陀為了防範未來世中借修行為名之惡比丘而特別制定的。這類人內心缺乏深細的聖道觀照，貪嗔煩惱根本未曾降伏；卻虛妄依託自己有些許坐禪道業，便輕慢蔑視佛陀制定的清淨聖戒。這完全是心緒牽涉於貪愛與憎惡，心頭巨大的我執慢毒尚未鏟除討伐之表徵；因此真正修證三乘道果的得道聖人，絕對不會輕賤戒律。因為他們已經深深斬斷了自我的執念根源，推倒了驕慢傲慢的煩惱魔幢；他們以敬重奉持戒律來增上自己的聖道道業，吾輩修行者又怎能不欽奉崇尚呢！

【625-0009】資持記/10a_中三下#21
【原文】論中，先破彼計實時皆無有實。然毘尼制法，多依實時；則顯如來亦說實時，豈是無時；故以為問，如鈔所引。答中為二，初約義釋通；二佛下，遮其來難。初中三義，初從假釋。論中難破時已，乃云見陰界入生滅假名為時無別時。〔謂時經及餘經等亦說實時，乃是隨世名字，故云假名，此與俗說假名言同義別。
【譯文】論中，首先破除他們妄計實時都是沒有真實體性的。然而戒律所制定的法則，大多依據實時；這就顯示如來也說實時，哪裡是沒有時間呢？所以拿這點作為疑問，如同《行事鈔》所引用的那樣。回答中分為兩部分：第一是依據義理來解釋通達；第二是從「佛」字以下，阻擋對方的詰難。第一部分有三種義理，首先從假名來解釋。論中詰難破除了實時之後，才說看見五陰、十八界、十二入的生滅而假名為時間，並沒有另外的時間實體。〔這是說《時經》以及其餘經典等也說到實時，只是隨順世間的名相，所以稱為假名，這與世俗所說的假名是詞同而意異。

【625-0010】資持記/10a_中三下#22
【原文】又準佛說則彼二皆是假名，隨彼而言，故云實耳。〕文云我已說者，即指上文。世界法有故，不妨說時非時；非實故，不妨無時；立論已明，不審重問，故反責之云不應難。〔有下闕時字，實下脫法字，論本有之。〕亦是下，次隨世釋。世界實者，俗所計也。〔論文實下有非第一實一句，又無有字。〕眾人呵者，即指緣起。
【譯文】又依照佛陀所說，那麼這兩種說法都是假名，只是隨順世俗而言，所以稱為實體罷了。〕文中說「我已經說過」，就是指上文。因為世間法存在的緣故，不妨礙說適當時限與非適當時限；因為不是真實體性的緣故，也不妨礙時間本無實體；論點已經立得很清楚，不再審查卻重複發問，所以反過來責備他說不應當這樣問難。〔「有」字下面缺少「時」字，「實」字下面脫漏「法」字，論典原本中是有的。〕從「亦是」以下，其次是隨順世間來解釋。世間的真實性，是俗人所執著的。〔論典文字在「實」字下面有「非第一實」一句，又沒有「有」字。〕眾人訶責，就是指制戒的緣起。

【625-0011】資持記/10a_中三下#23
【原文】〔律中女人呵迦留陀夷云：寧自破腹，不應夜食。〕由彼計實而致譏訶，律附世相遮譏故制。亦欲下，三護法釋。謂受戒時分定上中下，互相敬事，令法不滅，故云使久存等。〔初義約假從道以釋，後二約實從俗而釋。〕遮來難中。以毘尼制教，隨順世諦，從權建立，不可橫以真理而難俗事；
【譯文】〔律文中婦女呵責迦留陀夷說：寧願自己剖破肚子，也不應當在夜間進食。〕由於世人執著實時而招致譏諷呵責，戒律依循世間相狀以制止譏嫌，所以才制定此戒。從「亦欲」以下，第三是為了護持正法來解釋。這是說受戒的時間先後決定了上座、中座、下座的次序，彼此恭敬事奉，使得正法不致滅亡，所以說能讓佛法長久存在等。〔第一種義理是約定假名、順從修道來解釋，後兩種則是約定實時、順從世俗來解釋。〕在阻擋詰難中。因為戒律的制止教化，隨順世俗的諦理，是依權巧而建立的，不可強行用勝義真理來詰難世俗事相；
