# 校閱材料　第449檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【449-0001】03_業疏/21a_卷四之四#4
【原文】問曰：今有七月九日受七日法，出界不還，夏成以不？答：破也。何以知然？夏有後開，無前開也。以七月十五日須及夜分還返本界，如律所制「及七日還」，令限明相乃在界外，絕此分齊，故說破也
【譯文】問：如果有人在七月九日受了七日法，出界後沒有及時返回，夏安居算成就還是不算？ 答：破夏了。憑什麼知道是這樣？安居有在期限之後開許，沒有在期限之前開許的。因為七月十五日必須在夜分之內返回本界，如同律文所規定的「及七日還」；如果讓期限延展到黎明天明（明相出）時人還在界外，超出了這個分界界限，所以說是破夏。

【449-0002】03_業疏/21a_卷四之四#5
【原文】問答中，初問亦由諸說不同，故立問轉難，以盡疑情。答中，初直判。「夏有後開」，謂迦提月；「無前開」，即夏限內。「以」下，悉釋。三位受法，竝須最後一日身在界中，不爾破夏
【譯文】在問答之中，起初的提問也是因為各家說法不同，所以設立問難層層詰問，以徹底消除疑惑。回答之中，首先直接判定。「夏有後開」是指解夏後的迦提月；「無前開」是指在安居期限之內不能提前開許。從「以」字以下詳盡解釋。三種位階的受法，都必須在最後一天的夜分結束前身體回到界內，否則就是破夏。

【449-0003】03_業疏/21a_卷四之四#6

【譯文】如果這樣的話，為什麼律文中說「最後自恣七日在，受七日不還，不犯」呢？ 答：這是指七月十六日是最後的自恣日，如同在急施衣中所說的那樣。現在這個人是在七月十日受七日法，因此他的第七天正是安居圓滿之時，所以不回來也不犯破夏。

【449-0004】03_業疏/21a_卷四之四#7
【原文】次難中，自恣三日，十六為最後，退前七日，即初十也。釋中指急施衣，彼次第增中「自恣十日在」，即七月初六受衣，迦提後不增；乃至云「自恣一日在」，謂從初七去至十五日受衣，後須次第增，則知以十六為自恣日。餘如《資持》中
【譯文】在第二個問難中，自恣有三天期限，十六日是最後一日，往前回推七天，就是七月初十。解釋中指出急施衣的法式，在那裡依序遞增的規定中，所謂「自恣十日在」，即在七月初六受衣，迦提月之後不需遞增；乃至說「自恣一日在」，是指從初七起至十五日受衣，其後必須依序遞增，由此可知是以十六日為最後自恣日。其餘詳細內容見於《資持記》中。

【449-0007】03_業疏/21a_卷四之四#10
【原文】又問：制及七日是有法緣，至明夏滿，法隨事失，有何犯故，令我破夏？答：日夜分齊，約明相分。第七夜分明相未出，自屬前夜；明相若出，即屬八日。制七日夜須及界中，今不在界，故翻破夏。至十六日自是後開，由違前制，故說破也。若約此解，《十誦》亦及七夜返還，同《四分》，何有異耶？明相若出，不及夜也，如是思之
【譯文】又問：規定趕在七天內返回是因為受法事緣所繫，到了天明天亮安居已滿，受日之法隨著事緣結束而消逝，究竟有什麼犯戒之處，會令我破夏呢？ 答：白天與黑夜的分界，是以黎明的明相來劃分的。第七夜在明相未出之前，自然屬於前一夜；明相一旦顯出，就屬於第八日了。戒律規定七天七夜必須及時回到界內，如今明相出時人尚不在界中，因此反成了破夏。到了十六日自然是期限之後的開許，但由於違背了先前的規定，所以判定破夏。如果依此解釋，《十誦律》同樣也是要求趕在七夜之內返回，與《四分律》完全相同，哪裡有什麼不同呢？明相一旦顯出，就等於趕不上夜分了，應當這樣去深入思考。

【449-0014】03_業疏/21a_卷四之四#17
【原文】今解不同，不可依也。事訖法謝，《十誦》明文。不同欲法，羯磨不牒；今受日法，牒事加之，故謝法失；亦如藥法，病止無用；又不同狂，解須乞故。何因浪引，令此煩釋
【譯文】我們現在的解釋不同，前面的說法不可依從。事情辦妥之後受法便告謝滅，這是《十誦律》的明文規定。這不同於與欲法，與欲的羯磨中不提具體事緣；如今的受日法，在羯磨中必須宣讀事由而加法，因此事由謝滅則受法隨之喪失；這也如同服藥之法，疾病停止了藥法便無所用；又不同於狂癡羯磨，因為狂癡羯磨需要另行乞請解除。為何要隨意妄引不相干的例子，招致如此繁瑣的辨釋呢？

【449-0015】03_業疏/21a_卷四之四#18
【原文】今義中，初斥前非。「事」下，指所據，《十誦》文見注中。「不」下，責妄引。欲不牒緣，受日牒故；藥法病止無用，受日容有他營；狂須乞解，受日自失。三皆非例，前義不成
【譯文】在本文義理中，首先斥責前面的錯誤。從「事」字以下，指出所依據的文獻，《十誦律》的文句見於注釋之中。從「不」字以下，斥責其妄加援引：與欲法不宣讀事緣，受日法卻要宣讀；藥法在病癒後便無用，受日法在事畢後可能還有其他營求；狂癡羯磨必須另乞解除，受日法則是隨事畢自然消失。這三者都不能作為同類例子，所以前面的主張不能成立。
