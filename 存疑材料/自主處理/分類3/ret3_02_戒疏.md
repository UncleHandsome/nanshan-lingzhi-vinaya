## 02_戒疏 卷一下之一（及併列條目）

- **558-0009／03a#90｜「如法聚、條部，有問為解」｜改**
  - **原譯 → 新譯**：`如法聚、條部中` → `如〈法聚〉（即《二十犍度》）、〈條部〉（即《四分律·調部》）中所載`
  - **依據**：《行宗記》釋「眾律」明言「戒本後有二十犍度等，即法聚也」；《濟緣記》亦云「犍度梵言，即翻法聚」。又道宣諸著每稱《四分律·調部毘尼》為「條部」（如《資持記》卷一：「如條部中波離對聖重條咨問」；《行事鈔》：「故條部律云」；《行宗記》卷二亦呼為「調部」）。二者皆指《四分律》篇品，且皆有問答解疑，非泛指「集法毗尼」。

- **561-0011／03b#126｜「重者輿來，少者僧就」｜仍存疑**
  - **依據**：已查《戒疏》上下文（「且如病緣，重者輿來，少者僧就，可以知也」）及《行宗記》（卷三僅科「大急即三寶疾病等」，未釋此八字）。「少」讀為「病輕（微少）」則與常情「病重反輿來、病輕反煩僧眾前往」似相悖；讀為「健康比丘人少／或病人少」亦無《行宗記》或《四分律》平行明文可證，故不能定。

- **562-0007／03a#133｜「布薩多」｜改**
  - **原譯 → 新譯**：`次數繁多` → `（布薩時）懺罪人多而耗時甚久`
  - **依據**：道宣《行事鈔·說戒正儀篇》（T40n1804）平行原文自注云：「布薩多，夜已久（謂懺罪人多經久也）」。可見「布薩多」是指布薩時懺悔發露之人多（或事多）導致夜深，故開略說，而非指布薩次數頻繁。

- **562-0004／03a#130｜「轉輪高座」｜仍存疑**
  - **依據**：已查《四分律》卷三十六（「應作轉輪高座，平手立及在座上說戒」）、《資持記》（引尼鈔「開作轉輪高座說戒」）及《簡正記》（「第一古師云：是座下有輪腳，令人推輪其座，即轉來者……」）。古說除「座下安輪可推移／轉動」外，尚有「轉輪王式高座」之說，《行宗記》此處未明定形制，「可轉動」與「可推移」兩義在古疏中皆存。

- **561-0011／03b#126（原列第7條）｜「言『應訶』者，謂四羯磨、諸雜治人」｜改**
  - **原譯 → 新譯**：`所謂「應當反對提出訶止」，是指正受四種治罰羯磨……的人` → `所謂「應訶（應受訶止不得發言陳非之人）」，是指正受四種治罰羯磨……的人`
  - **依據**：《戒疏》引「又解云」將注中「應訶者不訶」解作：「言『應訶』者，謂四羯磨、諸雜治人，行法在身，無容秉法，身雖足數，口不陳非故也」。該他解顯然將「應訶」讀為**被動義**（應被訶止、不聽陳非之人），故下接「口不陳非」。《行宗記》則依《律》「此四，《律》名得滿不得訶……必非此等，方名『應訶』」，乃元照依本律定格辨明「應（有資格發）訶」與他解讀法之別。原譯作主動去「反對提出訶止」，與疏文「無容秉法，口不陳非」正面衝突，必須改正並可加譯註說明記文辨義。

- **（未編號）｜「彼云：『非道想不疑，殘。』」｜改**
  - **原譯 → 新譯**：`律文中說：「非道想不疑，殘」` → `律文中說：「（於非道起）非道想而不懷疑，犯僧殘」`
  - **依據**：核《資持記》卷中四（T40n1805）釋《行事鈔》引《條部》同句：「後引條部明文為證。謂**非道作非道想，不疑**，即是漏失。心境相當，故知必有想疑等句。」 明確斷定是一句（非道作非道想，且不生疑），非「非道想、不疑」兩句並舉。

- **712-0012／06c#28｜「世相無幾」｜改**
  - **原譯 → 新譯**：`世間世事無多` → `人世時日無多（世壽不久）`
  - **依據**：《行宗記》本段訓釋極明：「『無幾』，謂非久也；『時可惜』者，恐虗度也。」「世相無幾」與「時節可惜」對文，謂人生在世為時不久，不當虛度光陰去複述講者通誦的闕緣句法。「世間世事無多」失其時間「非久」之義。

- **706-0013／06b#92 與 707-0001／06b#94｜「通緣／別緣」分判相反｜改（僅明晰706#92指代，707#94不改）**
  - **原譯 → 新譯（706#92）**：`先解釋後面的兩種，這是屬於各條戒律共通適用的免責緣由` → `（註文列出五種不犯相，疏文依五意從後倒釋：）先解釋註文後面的兩種（最初、癡狂），這是諸戒共通的免責緣由；後解釋註文前面的三種（睡眠、不受樂、無婬意），這是本戒各別的免責緣由`
  - **依據**：核《戒本含注》與《行宗記》原文：註文五項之順序為「①睡眠無覺、②不受樂、③一切無婬意、④最初未制戒、⑤癡狂等」；疏文「從後倒釋」，先釋「癡狂、最初」（＝註文**後二**，正屬諸篇通開之**通緣**），後釋「無婬意、不受樂、睡眠」（＝註文**前三**，皆婬戒**別緣**）。707#94 再依大位細分「難開（不樂、無意）、別開（睡眠）、通開（最初、癡狂）」。記文並無「通／別」字訛，系誤以「後二／前三」指疏文次序所致。

- **652-0001／651-0007｜「闇中誤偷白衣」／「誤得己衣」｜不改**
  - **依據**：原譯正確。核《摩訶僧祇律》卷三（T22n1425）原文正作「誤偷**自己**衣鉢」，《戒疏》作「誤得己衣」，允堪《發揮記》作「悞得己衣」，《毗尼關要》（X40n0720）作「誤偷自己衣鉢」，且現代校訂本《行宗記》已校作「誤偷**自**衣」。「白衣」顯為「自衣」刻本形訛。

- **660-0002／05b#117｜「初篇分二」與三科不合｜仍存疑**
  - **依據**：已查《戒本疏》《行宗記》此處原文（疏：「初篇分二：初有一行……；中列四戒……；後已說者……」；記：「共為一章，文分三故」）。記文未明言「分二」為「三」字之訛，亦無「標釋為一、結為二」之解釋；且 `未涵蓋_01.md` 未引現行 `out` 譯文，無法檢核現行譯文處理方式，故判仍存疑（義理上「二」極可能為「三」之傳抄訛誤，翻譯宜據實附註）。

- **（未編號）｜「『重病』言通，必須簡別。『負』，背也。」｜不改**
  - **依據**：原譯「『負』是違背的意思」正確。核緊接前段之《戒疏》原文為：「三、無重病，以不自知，無**負**心故。」 「負心」指違背戒制之心，故《行宗記》訓「負，背（違背）也」。

- **651-0007／05b#32｜「半衣邊滿」夾註義未明｜改**
  - **原譯 → 新譯（651-0007）**：保留夾註`（半衣邊滿）` → 若核對原底本疏文確無此夾註（CBETA X39n0714 該段作「不分與他，半滿犯重」，並無「（半衣邊滿）」夾註），則應刪除該殘留夾註；若須譯出該義，應統一比照 652-0001 譯為「應分給同夥的那一半衣物價值滿五錢」
  - **依據**：核《摩訶僧祇律》卷三原文作「出外不分故，是中半衣邊滿者，波羅夷」，《毗尼關要》釋云：「既誤盜己衣，亦准分半；既不與，分滿五錢，波羅夷。」 義極明確，652-0001 譯法正確，兩處應統一。

- **（未編號）｜「具緣行四重，三時無悔心」｜改**
  - **原譯 → 新譯**：`在起心、正作、作畢三時之中毫無悔改之意` → `在作前（方便）、正作（根本）、作後（隨喜）三時之中毫無悔改之意`
  - **依據**：核緊接之後句《戒疏》原文：「或**本無方便**，**後無隨喜**，**事不得已**，此重法生輕行。」 正以「本（方便）」、「事（正作）」、「後（隨喜）」對舉「三時」。律家「三時」以「方便」為初時，非單純「起心」。

- **（未編號）｜「唯九戒不汙，謂二離、二毛、二寶、二鉢及殘藥也。」｜不改**
  - **依據**：現行已改譯法（保留泛稱，不增動詞）正確。《行宗記》本段僅分「上四法持（二離、二毛），下五體異（二寶、二鉢、殘藥）」，未列具名；保持泛稱最忠於原典，不致強指「二毛」而涉爭端。

- **941-0004／12b#9｜「諸比丘若須一一衣」｜改**
  - **原譯 → 新譯**：`各位比丘如果需要單件的衣物` → `各位比丘如果需要（三衣中的）任何一件衣物（或：各自所需之某一衣物）`
  - **依據**：核《五分律》卷四（T22n1421_p0023a27、c10）下文即有「三衣中若離**一一衣**」，又接「時阿那律衣麁弊壞，諸比丘語言：『……何不從僧取作……』」。律典譯語「一一衣」常指「（三衣等之）某一件／各各所需之一衣」（對應巴利律 *aññataraṁ cīvaraṁ*），非「單件（只有一件）的衣物」。

- **942-0002／12b#16｜「反前三故」｜改**
  - **原譯 → 新譯**：`是與前面的情形相反` → `是指與前面三條衣戒（長衣、離衣、望衣三戒單純畜持而無造作營求）相反`
  - **依據**：核《行宗記》（X40n0714_p0021b01-12）上下文，前科正問「何故**三戒**（長衣、離衣、望衣）獨列迦開」，次科設難舉「自作五敷、過旬、用雨」三事詰問，答中對比「彼由作用，自損妨道……此雖長、離，譏訶是少」。記云「反前三故」，確指「與前三條開功德衣之衣戒相反」，無須模糊作「前面的情形」。

- **946-0009／12b#68｜「非衣者，不許餘用」｜改**
  - **原譯 → 新譯**：`如同《律》文中記載「屬於非衣的布料，不准挪作其他用途」` → `如同《律》文中所說「（作非衣者，）不許拿去製作革屣囊、鉢囊等其他器物」`
  - **依據**：核《行宗記》（X40n0714_p0023b13-15）正引《律》原文疏解此句：「《律》云『時有將非衣作鉢囊、革屣囊，佛言「不應作」』，此即『不許餘用』也。」 道宣正據律文「禁止將非衣改作鉢囊等囊器」，反破古師「非衣即革屣鉢囊」之說。

- **949-0006／12b#92｜「作與、作被」｜不改**
  - **依據**：現行已改譯法保留「作與、作被」並準確譯出「重物不合加淨、不入長犯」之義，是妥當的。核《四分律》卷六（T22n1428）不犯文作「若他與著、若作被，不犯」，《含注戒本》及《行事鈔》作「若他與作被」，《戒疏》略舉作「作與作被」，《行宗記》歸為第四項並釋「四、是重物，本不開畜，故不入淨」。

## 02_戒疏 卷四上之一

- **1066-0012（16a#24）｜「四期」｜不改**
  - **依據**：原譯「即四種約期同行」可通。核《拾毗尼義鈔輔要記》（X43n0748）：「四期：一與尼期行（27），二與尼期同乘一船（28），三與賊期行（66），四與女期行（67）。」「期同乘船」亦是約期同行（共乘舟行），括稱「四種約期同行」無誤。

- **1068-0012（16a#48）｜「此中入聚」｜仍存疑（但可確定「此中入聚」義指單提42）**
  - **依據**：核《行宗記》（X40n0714_p0076b03-09）上下問答：「問：德衣開五利，何獨背、別得為作持？答：前篇長、離，自有淨施、羯磨；此中入聚，別有白法。」功德衣五利為「畜長、離衣、背請、別食、食前食後至他家不白餘比丘」，對應疏文「七階」第三階「有囑法，故得非時前後入他家」（即單提第42「食前後入聚戒／至他家戒」），**非**單提第83「非時入聚落戒」。因 `未涵蓋_01.md` 未載此段現譯用詞，故判「仍存疑」（若現譯已明指第42戒則不改，若兼含83戒或含糊則當改）。

- **1069-0001（16a#50）｜「就本從長，故所不列」｜不改**
  - **依據**：原譯「在功德衣項下不予列入」正確。核《戒疏》（X40n0714_p0076a23）於七階第二項唯列「二、受功德衣，故得背請、別食」；《行宗記》（p0076b07-09）問「若爾，前三（長、離、入聚）得用德衣為作持否？」答「若用德衣，則廢本法，故知三戒並兼兩法，就本從長，故所不列」，明確解釋疏文在功德衣項下不列長、離、入聚三戒之故。

- **1071-0002（16a#76）｜「人別三受」｜不改**
  - **依據**：原譯「每個人各自三遍受法」合乎《行宗記》（X40n0714_p0077b07）「言加受者，謂作羯磨、人別三受」及《四分律》受功德衣法（僧作羯磨差人持衣後，界內比丘人各對持衣者三唱受功德衣）。

- **1073-0011（16a#104）｜「三期」｜仍存疑（若對應偈文「三期賊行」則須改）**
  - **依據**：已查《行宗記》卷四上之一（X40n0714_p0075b06）括戒偈文作：「尼同船，三期賊行，四期女行」，此處「三期」是序數「第三種期戒（與賊期行）」，非「三種約期」。然 `p0075b06` 屬 `16a` 前段（`1066` 附近），而 `1073-0011` 標為 `16a#104`（應在 `p0078` 附近），因無法調閱本機原文 `TXT_分卷` 確認 `16a#104` 處之實際原文是否重引此偈或另有「三期」，暫判「仍存疑」。

- **1074-0002（16a#108）｜《尼律》引文「出門」主語｜仍存疑**
  - **依據**：已於 CBETA 檢索《行宗記》卷四（X40n0714）與《五分律》《四分律》之「尼律」「出門」用例（如《五分》尼戒「不付囑……出門」、《四分》尼「牽他出房」、露處敷具「出門」等），因無本機原文 `TXT_分卷` 可核 `16a#108`（約在 `p0078` 簡僧尼科）確切所引之《尼律》句子，無法判斷主語，判仍存疑。

- **1077-0007（16b#1）｜「過非乖越」｜仍存疑**
  - **依據**：已查《戒疏》《行宗記》（X40n0714_p0080a18-21）及《資持記》卷中二（T40n1805_p0305b26），疏文作「綺語一業，掉戲壞心，過非乖越，未得僧制，通皆小罪」，兩部記文皆未訓釋「過非乖越」四字。可讀作「過失並非重違大法（或乖越僧制）」或「過失與乖越行儀（未得僧白法制止前皆屬小罪）」，無法唯一斷定。

  - **依據**：核《行宗記》（X40n0714_p0081a19-20）：「善眾可說，不說成妄；惡人成難，默亦無過。如《僧祇》作念『失火燒舍』等。」 又核《行事鈔·尼眾別行篇》引《僧祇》原文作：「若犯罪人兇惡有勢力，恐有命、梵難者，作念云：『彼行業罪，報自當知；喻如失火燒舍，但自救身，焉知他事？』得捨心相應。」 補出其方便開緣之義旨，文意始明。

  - **依據**：已核《四分律》卷46「破僧揵度」（T22n1428）與《戒疏》《行宗記》（X39n0714_p0897a19-20）：律本原記載阿難與六十長老以「鬱多羅僧著一面」作為表決反對調達五事之舉；《戒疏》承「六十長老及阿難云……」亦連舉此句；然《行宗記》解為「以乞懺治擯，並著下衣，今為僧諫，事同擯罰故」，轉作受諫罰者脫衣。既存在律本與記文之異解，現行譯文刪去自補主語而作「於是脫下鬱多羅僧，置於一旁」最為審慎（宜於註解說明兩解）。

## 02_戒疏 卷二下之一

- **748-0002（08a#26）｜「尚且找不到實有的生起相狀」（「尚無生相」）｜改**
  - **依據**：已核《行宗記》（戒疏記卷七‧二‧一八）上下文：「**第一義中，實無眾生，逐陰求之，尚無生相，何況有殺？**」「生相」與前句「眾生」及下句「有殺」相呼應，意謂推求五陰尚且無「眾生之相（生命實體之相）」，何況有「殺（眾生）」可言，非「生滅之生起相」。
  - **原譯 → 新譯**：`尚且找不到實有的生起相狀` → `尚且找不到實有的眾生相狀（生命實體之相）`。

- **750-0003（08a#46）｜「羺羊」｜改**
  - **依據**：同書《戒本疏》「三十捨墮法」（持羊毛過限戒，戒疏記卷一一‧六五‧二○）明訓：「**羺，謂小羊羔也。**」《行宗記》亦釋：「**羺字，奴鉤反，胡羊也。文云小者，毛又細故。**」同書已有明確自訓，不當泛譯為「公羊」。
  - **原譯 → 新譯**：`公羊` → `小羊羔（胡羊）`。

- **750-0003（08a#46）｜「則狂發戒捨，但結偷蘭」｜不改**
  - **依據**：已核《戒本疏》（X39n0714_p0837a02-03）及《行宗記》，此處直引《十誦律》語，指加害未死（先結偷蘭），在對方未斷命前加害者若發狂或捨戒，即不再結究竟夷罪，唯存前偷蘭。照字面譯出不強添推斷，十分穩妥（可略加括注輔助理解）。

- **761-0011（08b#44）｜「肪、𦚻」｜改**
  - **依據**：本段《行宗記》（X39n0714_p0841c12-13，戒疏記卷七‧二四‧四）自文已明注：「**肪（音方，腸脂也）、𦚻（音珊，胃脂也）**」，無須姑依字面推作「脂肪、肌肉膏油」。
  - **原譯 → 新譯**：`脂肪、肌肉膏油` → `腸脂（肪）、胃脂（𦚻）`。

- **764-0010（08b#79）｜「倚撥」｜不改**
  - **依據**：已核《戒本疏》下文（X39n0714_p0843c08-09）自釋「審知彼人倚撥其處，便施刀杖，彼依而死者」及《行宗記》（戒疏記卷七‧三二‧七）「謂潛安殺具，令彼觸動也」（又《資持記》同）。今譯「倚撥（藉倚靠、撥動物件或機關致死）」與疏記完全相符。

- **767-0001（08b#92）｜「非留死蘭」｜改**
  - **依據**：《戒本疏》（X39n0714_p0843c07）引《十誦》作「為人作坑，人從死重，非留死蘭」。核《十誦律》卷2原文作「為人作坑，人死者波羅夷；**非人死者偷蘭遮，畜生死者亦偷蘭遮**」，且《行宗記》云「約三趣互論輕重」。可見「非留」實為「**非畜**」（非人與畜生，見《南山律學辭典》所錄亦作「非畜死蘭」）之形訛；僅譯「非人」漏了「畜生」。
  - **原譯 → 新譯**：`非人` → `非人或畜生（死，犯偷蘭遮）`（並出校注：原文「非留」當為「非畜」之訛）。

- **770-0004（08c#7）｜「快勸死」之「快」｜仍存疑**
  - **依據**：已查《四分律》卷2、《四分律比丘戒本》（T22n1429_p1015c15 有異讀斷為「歎譽死快、勸死」）及《戒疏》《行宗記》（X39n0714_p0845a01-02，未訓「快」字）。「快」兼具「急切促死（快點死）」與「以死為快意而極力勸說」二義，記文無釋，今譯「竭力勸誘」可暫存參。

## 02_戒疏 卷首

- **439-0001（00_卷首#54）｜第四十三「食家強坐戒」｜改**
  - **依據**：同書《戒本疏》卷四上之三「食家強坐戒四十三」（X40n0714_p0119c）及《行宗記》（戒疏記卷一四‧七六‧四）明文訓釋：「一是食家。如《鈔》所解，**是觸食家，以眼對色故**。」《行宗記》：「**觸食者，根塵相遇，暢思資神，故云觸食**。」且《四分律》卷15原文定義「**食者，男以女為食，女以男為食，是名為食**」。本書絕無「供食檀越家」義，原譯係誤讀。

- **443-0001（00_卷首#63）｜「纔羅七五之名，妄居一字之首」｜改**
  - **依據**：同書《戒本疏》卷二（戒疏記卷五‧六二‧二）引《涅槃經》云：「**善解一字，名為律師。有人解云，即『律』字也**。」《資持記》下三之四亦同此釋；宋·道言《釋四分戒本序》（X40n0715）更專釋此句：「**七、五名者，即五篇、七聚之名，纔能識達；一字首者，即律師也。**」原譯略「纔羅七五之名」且未顯「一字之首」即「律師／律字之宗首」的典源。
