### 一、新改程式碼中的 3 個實質 Bug（建議必修）

#### 1. 【會直接閃退】`mk_split_blind.py` 第 136 行漏了 `_ban` 賦值
看 `mk_split_blind.py` 第 133–147 行：
```python
_bctx = _cfg.get('ctx', ('', ''))[0] if _lab_full in ('疏文', '記文') else ''
if _lab_full == '疏文':
    _sr = ''                 # ← 原本的 _ban = '' 拿掉後，這裡沒給 _ban 預設值！
elif _lab_full == '記文' and args.book in ('業疏', '戒疏'):
    _sr = '...'
    _ban = ''
else:
    _sr = ...
    _ban = _cfg.get('shuji_ban', '') if _lab_full == '疏文' else ''
...
prompt = BLIND_PROMPT.format(..., shuji_ban=_ban, ...)
```
**後果**：只要碰到《業疏》或《戒疏》超過 500 字的**疏文**長段，程式走進 `if _lab_full == '疏文':` 並跳過 `elif` 和 `else`，執行到第 147 行時會因為 `_ban` 從未被宣告而**直接報 `UnboundLocalError: cannot access local variable '_ban'` 閃退**。
**修法**：在 `if _lab_full == '疏文'` 之前先設好 `_ban = _cfg.get('shuji_ban', '')`（或直接寫 `_sr, _ban = '', _cfg.get('shuji_ban', '')`）。

#### 2. 【標籤會貼錯】`make_hybrid.py` 的 `trim_group()` 會把《尼鈔》《行事鈔》《義鈔》寫成 `疏文`
看 `make_hybrid.py` 第 53 行：
```python
gg['unit'] = g.get('unit') or '疏文'
```
在 `mk_review_materials.py` 的 `BOOKS` 字典裡，只有 `資持記` 有寫 `unit='記文'`，而 **`尼鈔`、`行事鈔`、`義鈔` 的 `g['unit']` 都是 `None`**（原本是靠 `emit()` 的 `'鈔文' if g.get('no_ji') else '疏文'` 才轉成 `鈔文`）。

#### 3. 【雙欄打包仍會串位】`pack_judge.py` 的 `_cur_n` 遇到 2 段以上雙欄無號記文會全塞進最後一段
看 `pack_judge.py` 第 168–207 行：
你新增的 `_cur_n` 本意很好（補救 `[2]【疏文】…【記文】…` 裡記文沒寫 `[2]` 的情況），但因為第 168–172 行的 `lab_map` **已經先把整包所有段的【疏文】黏成一大塊、所有【記文】黏成另一大塊了**。
假如一個包有 2 段且模型輸出：
```text
[1]
【疏文】疏1
【記文】記1

[2]
【疏文】疏2
【記文】記2
```
經過重排與 `lab_map` 合併後：
- `lab_map['疏文']` 是 `[1] 疏1 \n [2] 疏2` → 跑完後 `_cur_n` 停在 **`2`**；
- `lab_map['記文']` 是 `記1 \n 記2`（裡面沒有 `[1][2]`）→ 跑進 `len(parts) == 1` 後，**`記1` 和 `記2` 會被整塊一起塞進 `_cur_n = 2`（第 2 段），第 1 段的 `記1` 直接遺失並沿用舊譯甲**！
**修法**：只要發現 `body3` 原本存在 `[n]` 領起雙欄區塊（即多組交替出現 `【疏文】…【記文】` 且 `【記文】` 內不帶 `[n]`），不要先用 `lab_map` 把同標籤黏在一起，改為**先切開每個 `[n]` 區塊，再在區塊內部分開抓 `【疏文】`/`【記文】`**（最簡單是第 148 行先不重排，而是偵測 `re.search(r'(?m)^\s*\[\d+\]\s*$', ...)` 或直接在原始 `body3` 按 `[n]` 切塊）。

### 二、提示詞與銜接的 2 個小細節

#### 4. `STYLE_SPEC` 第 4 條把「注疏所釋原詞」放進了「一律放白話譯文」裡
看現在修完的第 4 條：
> 忠實對譯之典籍原句、儀軌（保留「某甲」）**與注疏所釋原詞**，以「……」包圍；**引號內一律放白話譯文**，不得夾雜未譯文言或半文半白。惟注疏體例若先引原文原句、再以白話解釋，則引號內只放原文原句，白話解釋置於引號外；**同一段不得兩種混用**。

這兩處字面有一點小打架：
1. **「注疏所釋原詞」**：注疏點名所釋的字詞（例如「所謂『作法』者，是指……」），照第 1 條例外清單就是保留原詞不譯；把它放在第一句，等於要求「注疏所釋原詞」也要翻成白話放入引號內，反而跟第二句打架。建議把「注疏所釋原詞」從第一句移到第二句的「原文原詞／原句」那邊。
2. **「同一段不得兩種混用」**：有時同一段疏文裡，前面先點釋原詞（先引原詞再白話解釋），後面接著直接引一段《四分律》整句翻成白話，兩種體例確實可能在同一段內前後出現。若你們真正想禁止的是「**同一個引句內**一半文言一半白話」，把「同一段不得兩種混用」改為「**同條引文不得半文半白；先引再解者引號內只留原詞／原句**」會更穩妥，不易被審核誤判 FIX。
