整體看，五段譯文的**大意都對**，沒有顛倒原意的重大誤譯；問題集中在幾處**律學術語的處理**、**交叉引用被誤讀成時間敘述**、**引號內增字**，以及**體例不一致**。以下按「必修」與「建議」分列。

## 一、跨段的共同問題

1. **「律云」宜譯「《四分律》說」**（0001「不依犯墮」、0003「僧十四日自恣」）。
 《行事鈔》單稱「律」，慣例指本律《四分律》，其餘諸律才冠律名（僧祇、十誦、善見）。譯作「律藏說」会让读者以为泛指一切律典。
2. **標題譯法不一致**：0001「四、說明安居法」、0002「五、說明自恣法」都譯了，0005 卻原樣留「六明隨戒相」。應統一為「六、說明隨戒相」。
3. **稱名混用**：「大僧／比丘僧／比丘僧團」、「尼／尼僧／比丘尼」在各段來回切換。建議首次出現注「大僧（比丘僧）」，其後統一；並區分**個人＝比丘尼**、**團體＝尼僧（尼眾）**。0001「邀請尼僧前去安居」原文只作「請尼」，若指個人，用「尼僧」反而失真。
4. **引號內不宜增字**（見 0002）。
5. **由旬換算不一致**：0001「半由旬（約二十里）」有注，「三由旬」卻無。且「里」是古里（一由旬古傳四十里／三十里／十六里諸說），與今公里易混。建議要嘛全不換算，要嘛統一注「古傳一由旬約四十里；今測約七至十一公里諸說」。

## 二、逐段問題

### 【424-0001】

| 原文 | 原譯 | 問題與建議 |
|---|---|---|
| 夏竟**說證** | 夏安居結束時**說自恣** | 意思對，但直接把僻詞換掉、讀者無法回查原文。建議保留並注：「說證（即自恣）」。 |
| 先**教**請比丘 | 先**教導施主**邀請比丘 | 「教」在此是「使／令／告知」，不是「教導」；且上文稱「親族親戚（親里）」，此處忽改「施主」，指稱斷裂。建議：「應先要親里也迎請比丘」。 |
| 路有難事，**得安居** | 准許**就地安居** | 尼已結安居，此處是「得**繼續**安居、不必遷離」，「就地安居」易讀成重新結安居。 |
| **卒**無者 | 如果連一人也沒有 | 漏譯「卒（猝）」＝一時、倉卒之間。建議：「若一時（倉卒間）沒有比丘」。 |
| 三由旬內有**僧**處 | 有**僧人**的處所 | 「僧」指**比丘僧團**（四人以上），不是泛指任何僧人（否則含尼眾，義全失）。建議：「有比丘僧的處所」。 |
| **通結取** | 都可以**通連結取安居界** | **本段最需修的一處**。「安居界」是譯者臆增。此語大意是「（結界時）可通連該比丘僧處一併結取，以彼僧為依止（行布薩、受教誡）」。建議保留原詞＋注釋，並查《資持記》確認，不要逕譯為「安居界」。 |
| 雖在一比丘處 | 即使只在有一位比丘的處所 | 可補足語意：「即使當地只有一位比丘（不足僧數、不能作僧法）」。 |
| 半月應請問布薩 | 每半個月應前往請問布薩**日期** | 「日期」是合理加注，但「請問布薩」實含**問布薩日＋求教授教誡**，只講日期偏窄，建議加括注。 |
| 乃至後夏初…比丘有緣事不來 | 乃至到了後夏初…**始終**未能前來 | 「始終」為添字（可保留，但屬譯者補語，宜一致處理）。 |

**另可加一則譯註**：善見「半由旬」是**安居處與比丘住處的距離上限**，僧祇「三由旬」是**依僧請問布薩的範圍**，兩者標準不同、用途不同，並列易被誤讀為「三由旬內都可安居」。

### 【424-0002】

1. **「鳴椎」譯「敲擊木槌」——需改。**
 「椎」即**犍稚**（集僧用的木梆／響板），是被敲的法器；「木槌」是敲擊工具，正好錯位。建議：「敲擊犍稚（集僧的木製響器）」。
2. **「如前教誡中」被誤讀成時間——需改。**
 原譯「如同先前請教誡時一樣」像是回想某次事件；實為**篇內交叉引用**，指前文所述「教誡法」的作法。建議：「依照前面〈教誡〉一節所說的方式」。同理，末句「依上大僧自恣法」宜作「依照前文所明大僧（比丘僧）自恣之法（尼僧照作）」。
3. **引文內增字**：「比丘尼僧依見、聞、疑三事**向大僧**說自恣」——「向大僧」原文所無。建議移入括注或放到引號外。
4. 「彼尼受教已」→「那位比丘尼**接受教導**之後」語意含糊，宜作「領受大僧的教示（答覆）之後」。
5. 「自恣（任由他人檢舉己過並懺悔）」可再精準些：「自恣（放捨自身，任僧眾隨意舉發己之見、聞、疑罪）」——重點在「恣他舉己」，非僅「他人檢舉」。
6. 「頂戴受持完畢」可，或作「恭敬領受（頂戴）完畢」。

### 【424-0003】

1. **「別眾」譯「別眾分黨」——需改。**
 律中「別眾」是**同一界內有人不集、又不與欲，致作法不成**，與「分黨（破僧、鬥諍）」不同；後文「眾不和」才是鬥諍不和，两者并列，混譯会重复且失義。建議：「別眾（有人未集合、未與欲，作法不成）」。
2. 「不滿」譯「人數不足法定僧數」偏籠統，可注「不足自恣所需的五人數」。
3. 「問訊」宜略注「派人前往致意、探問（並了解能否如法自恣）」。
4. 「勦了知法」處理得好（保留原詞＋括注）；可再加音注「勦，音ㄔㄠ，敏捷幹練」。
5. 可補一注說明**為何僧十四、尼十五**：因尼須先赴僧中說自恣，隔日才回尼眾自恣，故僧提前一日。否則讀者會以為與一般十五日自恣相違。

### 【424-0004】

1. **經名**：《愛道經》全稱 **《大愛道比丘尼經》**，譯作《大愛道經》不夠準確。
2. **「惑色」有歧義，是本段唯一實質風險**：可解為「貪著（自身）容顏美色」，亦可解為「以色相迷惑（媚）人」，或「迷戀色欲」。原譯選了第一說而未注。建議采一說並加註「一說指以色媚人」。
3. **「但欲」＝只想**；原譯「女人**往往**只貪著…」的「往往」是原文無有的限定詞。若是為了缓和語氣而加，屬譯者介入，宜移到譯註處理，不要混入經文。
4. 「但知須臾之事」→「只知眼前的短淺瑣事」可，或「只知短暫眼前之事」。
5. 建議加一則譯註，說明此為經文本身的時代性表述（引述古律典立場），避免讀者誤認為鈔主或譯者的評價。

### 【424-0005】

1. **標題漏譯**（見上）：應作「六、說明隨戒相」。
2. **「隨戒相」宜加註**：即「隨行戒相」——受戒後隨行護持的戒條相狀（對「受戒」而言的「隨行」）。這是全篇篇目用語，不加注讀者無從理解。
3. 「八波羅夷（八重罪）」正確；可補注「後四條為尼眾特有（摩觸、八事成重、覆他重罪、隨舉大僧供給衣食）」，讓「前四同僧、故不出」的省略更有交代。
