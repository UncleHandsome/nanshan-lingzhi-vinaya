# 校閱材料　第327檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】曾聽聞律藏乃是佛法的壽命。律藏住世，佛法才能住世。因此，生長善法、息滅惡法，以羯磨為宗趣；斷除惑業、證悟真理，以木叉（別解脫戒）為根本。因此，生善的盛大，莫過於領納戒體；滅惡的重大，莫過於懺除重罪。羯磨的功德，真是盛大啊！過去、未來以及現在的人，必定是遵行它才能證得覺悟果位，真可謂是渡過苦海的舟船、登上高樓的梯蹬啊。 況且自從佛陀慧日隱落西方，律法漸漸東傳之後，根機成熟、時節到來，直到我南山初祖（道宣律師）曾親受如來囑託擔當使者，降生興起於中華赤縣，撰寫了《戒疏》、《業疏》、《行事鈔》，編著了教誡弟子、分別輕重犯相的儀軌文字，光芒遠遠掩映前代。因此，佛法的慈雲重新密布於震旦，佛陀的玉毫金光再次照耀於東方。所以證得三果的印度梵僧曾讚歎說：「自從佛陀滅度之後，像法住世以來，振興闡發律學的，唯有道宣律師一人而已。」既然如此，普天之下不可以沒有這位祖師；四海之內，不可以沒有這些著作。從此以後，凡是足以推行止持與作持之事、致力於律學修持的人，豈可不奮勉自勵呢？ 高足弟子大慈律師親自隨侍而受深密教誨，鄭重傳持，引述初祖昔日的開示，撰寫了《鈔記》，用來指示指頭之外的明月。雖然在當時名重一時，但因文辭質樸、義理玄深，仍不容易徹底通達明了。因此曇勝、融濟等各位大律師競相撰寫記文，共有六十家之多。這些著作全都漫泛引證、詞句冗繁，其間也難免魚魯混淆（文字訛誤），從未有人能真正切中宗趣要旨。若取其中文辭窮極、義理詳盡的，則以《會正記》為最上；但到了大智律師（元照）出世，就屏棄它而不再採用。大智律師深痛《行事鈔》之旨依然隱晦，悲憫迷失方向的人失去指南，不願憑空構設浮詞贅語，徒然塞滿書卷緗帙，而是一心宣暢持犯的正義，巧妙鋪陳〈八品〉的軌則，解釋得切中緊要，疏決融通了種種凝滯。玉麈塵尾一揮，首先斥駁《會正記》，其餘諸家望風歸附順從，實在是群記之中的冠冕魁首。 然而對於《戒疏》與《業疏》二部註疏，卻極少有人為它們作記。唯有允堪律師雖然編撰了記文，卻曲解引證、牽強附會，妄自抒發胸中所思，反而使律行事業更為晦暗隱蔽。唯有大智律師這部《業疏記》（濟緣記），文字簡省而義理深遠，沒有隻言片字不具備出處依據，其止持之解恰恰用以成全其作持之法。這部著述利益極大，足以作為楷模借鑑（龜鏡）。這正是靈芝元照祖師對止持與作持這二持具有豐功偉績，將毗尼高高舉起使其不致墜沒的原因，他的功德哪裡是能輕易說盡的呢！所尊貴的唯有《疏》，所珍寶的唯有《記》，絕沒有捨棄它們而能通達止持與作持奧祕的人。為何閱讀的人卻不細加察覺呢？ 我私下以為，若疏文、記文、科文三種文本各自分卷流通，左右翻檢搜尋，難以隨時窺見全貌。所以如今慷慨立下宏願，想要將《疏》與《記》合版刻印，使研學者隨其需要便能一目了然地獲取。這也是為了整頓弘揚正法綱紀，使有志於研習律學的比丘、比丘尼能夠獲得增益的微薄心意。於是將其雕刻付梓，以廣泛流傳世間，因而敘述這段始末，作為全書篇首的序言。

【327-0004】03_業疏/01a_卷一之一#1
【原文】四分律刪補隨機羯磨疏濟緣記卷一之一
【譯文】僧伽以「眾」為名，眾以「和合」為義。確實是因為眾生隨情妄動而使真性昏昧，行為有別、事理相乖，由此隨順生死流轉，不知探究本源。所以應當同歸於釋尊同一導師的氏族，齊等於佛及辟支佛、阿羅漢三聖的威儀容貌；其內在德行，在戒、見、利上完全平齊均等；其外在作用，在身、口、意上完全和合一致。紛爭既然平息，我慢與顛倒也就隨之平復，由此可使本性顯發、妄情消泯、逆生死流而復歸心性本源。 再者，陰陽化育萬物，若無此和順則萬物不能生成；禮樂治理萬民，若捨棄和合則士農工商四民無法立足。所謂「天時不如地利，地利不如人和」；「先王之道，斯為美（和為貴）」。更何況是弘揚發揮佛陀的教化，整飭作為僧團的綱紀，建立滅惡生善的因緣，開闢超凡入聖的坦途，唯有這項殊勝的羯磨妙法，才具備這般弘大的功德。 自從佛陀的白毫金光隱沒於西印度，貝葉經卷的法乳流注到東土華夏。深奧微妙的言教幾乎斷絕，異端紛紜的撰集雜然並起。幸賴我們南山聖師（道宣律師），憐憫痛惜世間凡俗，洞察時宜而提挈綱要，纂集八種羯磨之法而成正文；探尋幽隱、鉤索精深，闡發四種成辦之緣而著述註疏。後學忝借宿世的微少善根，得以遭逢祖師遺留的德音，竭盡思慮研幾探微，其勤苦何止於讀《易》的韋編三絕；隨聞錄下師傳，不敢自專，謹遵四大教法之規矩。但願能為後世子孫垂留福澤，豈敢說是輝映超越前代。期使僧伽大海重歸一味和合，祖師慧燈展轉映照於無窮，劫石縱然磨滅消盡，弘誓宏願何嘗有窮竭之期！勉勵後來的學人，切莫懈怠，務必流通此法。
