# 校閱材料　第281檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【281-0001】01_行事鈔/12b_卷下之四#57
【原文】初明來往是非者。《四分》云：若作本法已，即日往大僧中，不者犯罪。有人就尼寺與受戒者，不成。《薩婆多師資傳》云：非法，不成。如端正難緣，尚自遣信；此無難緣，縱有不合。有人就尼寺外，結界而受者，律無定決；然情為尼故來，非法有罪；若判得戒，亦可通之。問：尼得僧寺作本法不？答：如《明了論》：僧界中為尼立界，令尼作法；依式結界而受，理得無過。問：本法人名作何等？有戒以不？答：但是戒緣，未發具足，而律中名為比丘尼也。
【譯文】第一、說明受戒來往儀軌的合法與非法。《四分律》說：比丘尼若在尼寺作完本法（尼僧團初白四羯磨）之後，應當在當天立即前往大僧（比丘僧團）中受具足戒，否則便犯戒結罪。如果有人由比丘親自移駕前往尼寺為尼授戒的，不能成就受戒。《薩婆多部師資傳》說：此舉屬於非法，不能成就受戒。正如女子長相過於端正而有遭遇非禮之險難因緣時，尚且要派遣使者傳達（遣信受戒）；如今並無險難因緣，比丘親赴尼寺授戒縱有藉口也絕不相合。有人由大僧來到尼寺門外，在尼寺外另行結界而為尼授戒的，律典中對此並無明文裁決；然而就情理而言比丘是特意為了尼眾而前來，實屬不如法且有罪過；但若單就羯磨效力評判是否得戒，在通融義理上亦可算作成立。提問：比丘尼可以在比丘僧寺中作本法受戒嗎？回答：正如《律二十二明了論》所說：在比丘僧的大界之內，特別為尼眾建立一個專屬的小界，讓尼眾在其中作法；如果依照法定儀軌結界而受戒，在法理上是可以成立而沒有過失的。提問：剛受完本法的人，應當稱作什麼身分？她到底得戒了沒有？回答：這僅僅是受戒的前奏因緣，尚未真正引發具足戒體，但在律典隨機名相中，已經先假稱為「比丘尼」了。

【281-0002】01_行事鈔/12b_卷下之四#58
【原文】二明僧尼數量者。有人作本法已，將二三尼，將本法尼往僧中而受者。若依律本，比丘尼僧，應將受戒者至大僧中；乃至文云，二部僧具足滿；故知僧尼二十人也。《僧祇律》：尼受戒法，名二十眾；既有定數，前行非法。《五分》明文，彼云：彼和尚、闍梨，復集十尼僧，往比丘僧中，在羯磨師前小遠，兩膝著地，乞戒。
【譯文】第二、說明參與受戒的僧尼法定人數。有的人在作完尼部本法之後，只帶著兩三位比丘尼，便將受本法尼帶往比丘僧團中去受戒。如果依據根本律文，比丘尼僧團的大眾應當親自帶領受戒者前往大僧之中；乃至律文說「二部僧團皆必須具足圓滿」；由此可知僧尼二部必須各自滿十人，總共應為二十人。《摩訶僧祇律》記載：比丘尼受具足戒之法，明確稱為「二十眾法」；既然有法定的法定人數，前面只帶兩三位尼前去的做法實屬非法。《五分律》更有明確正文，文說：那位和尚尼、阿闍梨，應當另外召集十名清淨比丘尼，一同前往比丘僧中，在比丘羯磨師前方稍遠處，雙膝著地，恭敬乞求傳授具足戒。


【281-0003】01_行事鈔/12c_卷下之四#1
【原文】三明尼須結界。有人不立比法。然此一法，二眾同秉，各有別眾；非界無以攝人，非界無以羯磨。若不信須結，但僧獨作，應成；事則不爾，故知須結，審委無疑。應自然界，尼僧盡集，唱相結之；本法尼者，且置自然界外；下二眾，同住無妨。又如尼懺僧殘，二眾各結，受隨俱同也。此結界法，佛法東流，行事者用之，有不立者少；然中國僧來傳法，通有賢聖，不共非奪。
【譯文】三明尼須結界。有人不主張立此（比丘尼結界之）法。然而這一法門，是比丘與比丘尼二眾共同秉持的，且僧尼二部各自都會產生別眾（非法離群作法）之過失；如果沒有界域，就無法攝集眾人；沒有界域，就無法如法作羯磨（僧團辦事儀式）。如果不相信尼眾必須結界，認為只要比丘僧單獨作羯磨就能成就（尼受戒等事），但事實上並非如此，所以知道尼眾必須結界，審核詳審確實無疑。應當在自然界中，尼僧全體集會，宣唱界相以正式結界；受本法的尼眾，暫且安置在自然界之外；至於沙彌尼與式叉摩那等下二眾，在界內同住則無妨。又如同比丘尼懺悔僧殘罪時，二眾各結，受戒與隨行持戒的情況都相同。這個結界之法，自從佛法東傳以來，負責僧事運作者都採用它，不主張結界的人極少；而且印度（中國/天竺）僧人前來傳法時，其中通有賢聖之士，也都未曾共同予以非難或廢除。

【281-0004】01_行事鈔/12c_卷下之四#2
【原文】四安置儀式。應在二眾各結界內，長鋪兩席，使中央空二三尺許，令申手相及。諸本法尼，多者兩處安置；一眾多聚處，二單身在僧前。一一召來，入眾教乞；得戒已，令在大尼下坐；待竟，總為說相。
【譯文】四安置儀式。應當在二眾各自結成的界內，長長鋪設兩排坐席，使中央空出大約二至三尺的距離，讓彼此伸手可以互相觸及。各位本法尼（求受具戒之尼），如果人數眾多，應安置於兩處：一是大眾聚集處，二是單身一人在比丘僧前。將她們一一召喚過來，進入僧眾中教導她們乞求受戒；受得大戒之後，讓她們在大尼（已受具足戒的比丘尼）的下座就坐；等全體受戒完畢，總體為她們宣說戒相。

【281-0005】01_行事鈔/12c_卷下之四#3
【原文】五入戒法中。先須請戒師。律無正文，準前須請。以外受法、問難、戒體、隨相，一一準僧中行之。
【譯文】五入戒法中。首先必須迎請戒師。雖然律藏中沒有明文規定，但依照先前的通例必須迎請。此外的傳受戒法、詢問遮難、領納戒體、宣說隨行戒相，全都一一比照比丘僧中的儀軌來實行。

【281-0006】01_行事鈔/12c_卷下之四#4
【原文】二明懺罪法。初篇有犯，無覆、有悔，亦開懺悔；同僧懺法。二篇一法，覆藏全無；六夜，改僧制限半月。以尼女弱，情垢既多，要假大僧，受隨皆爾。若欲懺者，二部中行，各滿四人，半月悔過；及至出罪，各具二十。但道風漸替，知犯，不知有悔；縱有懺心，集眾難得；故闕而不載。偷蘭已下，乃至吉羅，各有懺儀，如中卷列；唯當部自結，稱名大姊為異；餘辭並同。
【譯文】二明懺罪法。初篇（波羅夷，斷頭重罪）若有違犯，如果沒有覆藏、且有悔改之心，也開許懺悔（學悔）；與比丘僧的懺法相同。二篇（僧殘罪）只有一種治罰之法，完全不立因覆藏而設的別住法（不論有無覆藏，一律行摩那埵）；比丘行六夜摩那埵，尼眾則改制限定為半個月。因為比丘尼身為女性較為柔弱，情執結縛與煩惱塵垢既多，必須憑藉大僧（比丘僧）之力，受戒與隨行懺罪都是如此。如果想要懺悔，必須在比丘、比丘尼二部僧中進行，每部僧各滿四人，歷經半個月悔過；等到出罪之時，二部僧必須各自具備二十人。但由於道風日漸式微，人們往往知犯戒卻不知有懺悔法；縱然有懺悔之心，要召集足夠的僧眾極為困難；所以此處略過不載。從偷蘭遮以下，乃至突吉羅（輕垢罪），各自有其懺悔儀軌，如本鈔中卷所列；只有在尼僧當部自行懺悔了結、稱呼對方為「大姊」這點不同；其餘懺詞都與比丘僧相同。

【281-0007】01_行事鈔/12c_卷下之四#5
【原文】三說戒請法儀。《善見》云：初為女人鈍根故，盡聽尼往僧寺受教；後為人譏故，開五人來；猶致譏，聽僧往尼寺。《四分》無文，意同。
【譯文】三說戒請法儀。《善見律毘婆沙》說：起初因為女人根性較為鈍拙，完全開許尼眾前往比丘寺院接受教誡；後來因為遭到世人譏嫌，便開許五位尼僧代表前來；但仍然招致譏嫌，於是聽許比丘前往比丘尼寺。《四分律》中沒有明文，但意旨相同。

【281-0008】01_行事鈔/12c_卷下之四#6
【原文】二差人請法。於說戒日，白二差之，文如常說。《四分》：白二，差一人已，差二三人為伴，往僧寺中。至所囑人所，曲身低頭，合掌云：「某寺尼眾和合，禮比丘僧足，求請教授尼人。」當囑主人，無病、有智者，明日應問可不。
【譯文】二差人請法。在說戒日，以白二羯磨（一白一羯磨之僧團作法）差遣，羯磨文如常規所述。《四分律》記載：以白二羯磨差遣一人後，再差遣二、三人作為同伴，前往比丘寺中。到達所付囑的比丘處所，彎曲身子低著頭，合掌說道：「某寺比丘尼僧和合，頂禮比丘僧足，請求差遣教授尼眾之人。」應當付囑常住的主人（非客僧）、沒有疾病且有智慧的比丘，次日應當去詢問答應與否。
