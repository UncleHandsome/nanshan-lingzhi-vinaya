# 校閱材料　第992檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【992-0001】資持記/04a_上三#9
【原文】文有兩節，上簡堪能，年減亦制；下簡年歲，縱能亦遮。下文指廣，彼云八十九十太老，過七十臥起須人，不聽度；若能修習諸業，聽出家〔謂作沙彌〕。二諸根具者，以儀相有虧，污辱僧眾，故須簡之。文為三段，初釋緣相。身具等者，略示三根。百遮者，舉其大數。律下，指廣。如後具引。
【譯文】鈔文分為兩節，前半節簡別其堪能性，年齡在七十歲以下（未滿七十歲若無堪能）也加以制止；後半節簡別其年齡歲數，縱然能力可以也被遮止。下文指引了詳盡的律文，彼處說八十歲、九十歲太老，超過七十歲如果起臥都需要人攙扶，就不聽許度化出家；如果還能修習各項道業，則聽許出家（指作沙彌）。第二條「諸根具足」，是因為儀容表相若有殘缺，會侮慢羞辱僧眾，所以必須簡選排除。文段分為三部分，首先解釋緣的相狀。「身具」等詞，是略微舉出身、耳、眼三根作為代表。「百遮」則是舉出其大略的數目。從「律」字以下，指引詳盡的文句，如同後文具體引用。

【992-0002】資持記/04a_上三#10
【原文】準下，決律文，初簡永定。《疏》云：耳舌意三，助道勝也；由耳聽法，意緣邪正；有疑通決，非舌不明。此三有缺，則不成受。餘下，明不定。如上所列，相有重輕，如正問中。下指《義鈔》，文見上卷。三身器中。若全未受，容有污尼、賊住、五逆，受五八十，則有邊、賊，故云俗已來等。
【譯文】從「準」字以下，判定律文，首先簡別出永久定局之障。《業疏》說：耳、舌、意這三根，對於助修道業最為殊勝；因為要藉由耳朵聽受法義，意識緣取邪正；心中有疑慮要通達決斷，若無舌根就無法明言表達。這三根若有殘缺，就無法成就受戒。從「餘」字以下，說明非永久定局者。如同上面所列舉的，殘缺情況有輕有重，如同正受戒時所問難的內容。下面指引《義鈔》，文句見於上卷。在第三條「身器清淨」中，如果完全不曾受過戒，有可能犯下污尼、賊住、五逆等罪；如果受過五戒、八戒、十戒，則可能犯下邊罪、賊住，所以說「自從作俗人以來」等等。

【992-0003】資持記/04a_上三#11
【原文】十三難者，且通舉之。此簡身器，唯論造業，但收邊尼賊破五逆九種，故云雜過等。非畜初緣收，黃形第二攝。四相具者。律中裸形著俗服外道衣等，並不得受故。五中，初示緣相。有願未具，故言少分。下引律制。言得戒者，白四頓發也。得罪者，失漸次制也。
【譯文】所謂「十三難」，是暫且通泛舉出其名目。此處簡選受戒法器，純粹就所造作的惡業來論斷，只收攝了犯邊罪、污尼、賊住、破僧、五逆這九種罪障，所以說「種種過患」等等。非人與畜生被第一條緣所收攝，黃門與二形則被第二條緣所統攝。第四條「出家形相具足」，律中規定赤身裸體、穿著世俗衣服、著外道服裝等，通通不得受戒。在第五條中，首先顯示緣的相狀。雖然有發願但尚未具備全體，所以說是「少分」。下面引用律藏的規定。說「得戒」，是指白四羯磨當下頓然發起戒體。說「得罪」，是指違失了循序漸進的制戒程序。

【992-0004】資持記/04a_上三#12
【原文】上五次簡從寬至狹，初約諸趣簡人，二就人中簡報，三就勝報簡業，四就業淨簡儀，五就具儀簡法。又總為三：前二並報，中業同前；後二體相，形法二同。又約遮難收者，一三重難，無者方成。餘三輕遮，有亦通許。更自辨之。
【譯文】以上五條次第簡選，由寬廣漸至狹隘：首先就各趣之中簡別出人道，第二就人道之中簡別出身報完具，第三就殊勝的身報中簡別出惡業清淨，第四就業行清淨中簡別出威儀具足，第五就具足威儀中簡別出法式完備。又總體歸納為三類：前兩條皆屬於依報與正報，中間一條屬於業行同前所簡；後兩條屬於體貌威儀，外形與法式兩者相同。又若依遮難來收攝：第一條與第三條屬於重難，必須完全無難才能受戒成就。其餘三條屬於輕微的遮障，若有開許情況也通融准許。對此應當自己詳加辨明。

【992-0005】資持記/04a_上三#13
【原文】第二所對，結界中，初科為二，初明須界所以。故下，誡令審悉。
【譯文】第二項「所對的境界」（第二所對），在結界文段中，第一科分為兩部分，首先說明必須結界的原因。從「故」字以下，誡勉大家必須審慎詳明。

【992-0006】資持記/04a_上三#14
【原文】則有二種：一明界相，知集限分。二達是非者，究本行事。不然者，即反上二，或標相無準，或先結不如；微涉疑濫，並須再結。疏云：捨結極易，何得自輕。斥古中，初二句明違本制。輒下，斥妄行。前篇已破，故指如上。必下，指教。此緣者，或僧難集；或疑舊界，須出界外故。
【譯文】審詳包含兩種情況：第一要明了界的標相，知道大眾集會的邊界界限。第二要通達是非對錯，徹底探究原本的行事規範。如果不這樣，就會反於上述兩點，要麼標界界相毫無準則，要麼原先結界就不合法；只要稍微牽涉疑惑混亂，都必須重新結界。《業疏》說：捨除舊界再重新結界極為容易，為何要妄自輕忽呢？在斥責古德的文段中，前兩句說明其違背本來的戒制。從「輒」字以下，斥責盲目妄行。前面篇章已經破斥過了，所以指引「如同前述」。從「必」字以下，指明教法的規定。此種因緣，可能是因為僧眾難以聚集，或者懷疑舊界不合法，所以必須走到界外受戒。

【992-0007】資持記/04a_上三#15
【原文】然大界本制，不為難緣，兼須立相；小界反此，故判非法；若加大界，緣相並如，故云無爽。次科引傳，即其事矣。上決小界。若依下，次示戒場。恐後濫用，故此引示。引勸中，初三句通示。言諸師者，以《傳》中所述僧伽跋摩，既是西僧；例知皆爾，故總指之。故下，正引。即《梁高僧傳》。
【譯文】然而大界的本意制定，並非為了應付危難事緣，而且必須確立自然界相；小界則反於此道，所以判定為非法；如果附加結立大界，因緣與標相都如法符合，所以說「沒有差錯違逆」。接下來的科文引用高僧傳記，就是這件事情。以上是決斷小界的問題。從「若依」以下，接著說明戒場。唯恐後人混亂濫用，所以在此引用指明。在引用教證勸勉的文段中，前三句是通泛指明。之所以說「諸位律師」，是因為《高僧傳》中所記述的僧伽跋摩既然是西域梵僧；按例推知其他人也是如此，所以總體指稱。從「故」字以下，正式引用，即是《梁高僧傳》的記載。

【992-0008】資持記/04a_上三#16
【原文】宋元嘉十一年，祇桓寺慧照於跋摩重受大戒，駕船江中。人問者，即慧義法師。難曰：布薩僧事，常在寺內；及論受戒，何出邑外？答下，並跋摩語，初示所疑。別眾非法者，或本結時，僧有乖別；或今受時，界無分齊，致有別眾。餘下，答寺內布薩。夫下，答出外受戒。前云尊重，蓋指此也。脫，猶略也。
【譯文】南朝宋文帝元嘉十一年，祇洹寺的慧照法師在僧伽跋摩座下重新受具足戒，在江中的船上舉行。詢問的人，就是慧義法師。他質問說：布薩等僧眾法事，向來都在寺院內舉行；到了談論受戒時，為何要走出城邑之外？從「答」字以下，全部是僧伽跋摩的回答，首先指出心中的疑惑。所謂「僧眾分散不和合而非法」，可能是原本結界時僧眾內部有所違背隔閡；或者如今受戒時，結界沒有明確界限，導致出現別眾的情況。從「餘」字以下，回答平日在寺內布薩的理由。從「夫」字以下，回答為何要前往郊外受戒。前面所說的「莊嚴尊重」，大概就是指這個意思。「脫」也就是略微的意思。

【992-0009】資持記/04a_上三#17
【原文】第二能秉，與下數滿何異？答：能秉據僧體，數滿約事用。
【譯文】第二項「能主持羯磨的僧眾」（第二能秉），與下文的「人數滿足」有何差異？回答：能秉是依據僧伽體質而言，數滿則是就受戒事相功用（或事相行用）而言。

【992-0010】資持記/04a_上三#18
【原文】三中分二，初釋緣相。作無軌度名非法，事違教制曰非毘尼。今下，遮濫。必取應法，昧教寡德，多亦非滿。
【譯文】第三項之中分為兩部分，首先解釋緣的相狀。作法沒有軌度法式稱為「非法」，事相違背教誡制定稱為「非毘尼」。從「今」字以下，遮止混濫情況。必定要選取應當如法的僧人，若昏昧於教理、缺少道德，人數再多也不算滿足僧數。

【992-0011】資持記/04a_上三#19
【原文】文下，二引本制，初明兩位。中邊分齊，如〈二衣〉中。
【譯文】從「文」字以下，第二部分引用原本的戒制，首先說明中邊兩種地位。中國與邊地的界限劃分，如同〈二衣篇〉中所說。
