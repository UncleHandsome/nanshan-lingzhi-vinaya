### 2. `norm.py`：行首限定前綴 ＋ 保護篇名 `〈〉` ＋ 補常見簡字
* **修法 A（根治第 01 組 `先敘述提問：` 變 `先敘述問：`）**：
  不要用無差別 `.replace('提問：', '問：')`，改限定行首：
  ```python
  s = re.sub(r'(?m)^(?:提问|提問)：', '問：', s)
  s = re.sub(r'(?m)^(?:回答|答曰)：', '答：', s)
  ```
* **修法 B（根治第 16 組 `〈隨戒釋相篇〉` 被洗成 `《》`）**：
  轉換 `〈〉→《》` 時排除常見篇名／章節後綴：
  ```python
  s = re.sub(r'〈([^〈〉《》]{1,20}(?<!篇)(?<!品)(?<!章)(?<!節)(?<!門)(?<!科)(?<!犍度))〉', r'《\1》', s)
  ```
  *(註：Python `re` 負向後行須定長，用 `(?!篇〉|品〉|章〉|節〉|門〉|科〉|犍度〉)` 接負向前瞻寫在結尾更簡潔：`re.sub(r'〈([^〈〉《》]{1,20}?)(?<!篇|品|章|節|門|科)〉', ...)`；或直接用回呼 `lambda m: m.group(0) if m.group(1).endswith(('篇','品','章','節','門','科','犍度')) else '《'+m.group(1)+'》'` 最穩！)*
* **修法 C（順手清除偶發簡字詞組）**：
  加入高安全性的多字詞轉換（避免單字誤傷如「不准」）：
  `s = s.replace('精准', '精準').replace('通达', '通達').replace('没有', '沒有').replace('时候', '時候')`
