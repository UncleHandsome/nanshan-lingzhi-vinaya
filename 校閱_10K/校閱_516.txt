# 校閱材料　第516檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【516-0001】02_戒疏/08b_卷二下之一#90
【原文】【疏】言「遣書」者，身現其相，表於紙墨，令用死者。如《多論》中：「若優婆塞，及以比丘，知吉凶相，令破異國，隨得財命，皆同殺盜重罪。」若作死書，教使送彼，使向親說，使自得重，遣者犯輕；使自依死，犯輕亦爾。若作死經，有人偷讀、遺失拾得，依經取死，造者犯重。言「教遣書」者，自不親對，遣人作書，令彼受死，無問自他，若死俱重。《五分》：「作書時，字字蘭。」
【譯文】【疏文】所說的「寄送書信」，是指身體動作表現在紙墨文字之上，企圖讓讀到的人據此尋死。就像《薩婆多論》中所說：「如果優婆塞（在家男居士）以及出家比丘，通曉吉凶之相，教唆去攻破別的國家，隨後奪得財物或殺傷人命，全都等同犯下殺生與偷盜的根本重罪。」如果寫下催命的絕命書，教唆使者送給對方，使者若改為當面向本人親口陳說，使者自己犯重罪，寄信人則犯較輕的罪；如果使者自己看了信而自殺，寄信人犯輕罪也是同樣道理。如果是寫下一本教唆自殺的書籍，有人暗中偷看、或是拾獲遺失的書卷，依照書中指引尋死，寫書的造作者即結犯根本重罪。所說的「教唆寄送書信」，是指自己不出面面對，而是指使別人去寫信寄送，促使對方喪命，不論是指使者自己還是受指使的他人，只要對方死亡，兩者全都結犯根本重罪。《五分律》說：「在書寫奪命文字的時候，每寫成一個字就結犯一個偷蘭遮罪。」

【516-0002】02_戒疏/08b_卷二下之一#91
【原文】【記】遣書中，前明死書。初示相。言「身現」者，謂書中所述也。「如」下，次引明。若據《論》中，未定「遣書」，然吉凶之相，容可書報，故引釋之。「若」下，辨犯。「使向親說」，不以書示也，及「使自害」，並由能教心克，乖本所期，但得蘭罪，故云「犯輕」。「若作」下，次明死經。「偷讀、拾得」，「死皆重」者，由本造時，漫心無簡故。教遣書中。初明犯相。「《五分》」下，引示方便。彼立進趣，故約「字」論。
【譯文】【記文】在寄送書信的一段中，前半部說明催命書信。首先展示其相狀。所說的「身現其相」，是指透過筆墨文字在書中所表達的意念。從「如《多論》」往下，接著引用論典來闡明。如果依據論中的原意，雖然沒有直接指定為「寄送書信」，但占卜吉凶禍福之相，完全可以透過文字書信來通報，所以引來解釋。從「若作死書」往下，辨別罪犯的輕重。「使者改為當面向本人親口陳說」，也就是沒有把書信直接給當事人看，以及「使者自己看信尋死」，這都是由於能教唆者原本限定了受害對象，結果違背了原先設定的預期，所以教唆者只結犯偷蘭遮罪，故說「犯輕」。「若作死經」往下，接著說明偽造催死經書的情況。「偷讀、拾得」而「死亡皆結重罪」的原因，是因為當初著作這本死經時，內心廣泛散漫沒有限定特定的對象，任何人都可能受害。在教唆寄送書信中。首先說明犯戒的相狀。從「《五分》」往下，引證其方便罪。該律設立了步步推進入罪的層級，所以是依據「一字一句」來論罪。

【516-0003】02_戒疏/08b_卷二下之一#92
【原文】【疏】言「坑陷」者，知人遊行必從此道，故設坑穽，令墮死也。《十誦》云：「為人作坑，人從死重，非留死蘭。為畜造坑，畜死提，人死吉。若不定者，隨人畜死，重輕如律。」言「倚撥」者，審知彼人倚撥其處，便施刀杖，彼依而死者。言「與藥」者，文事可解。言「安殺具」者，即如世中行刑之所，比丘往看，施其繩索，令彼死者，同重。《多》云：「若為殺故，造刀杖者，吉羅；往趣彼人，步步輕蘭；或著彼身，命未斷，重蘭。」
【譯文】【疏文】所說的「設置陷阱」，是指知道某人出外遊走必定經過這條道路，所以預先挖設土坑陷阱，企圖讓他失足跌死。《十誦律》說：「如果為了謀害人而挖坑，人落入坑中跌死則結重罪，如果非人精怪落入摔死則結偷蘭遮罪。如果為了捕捉野獸造坑，野獸摔死結波逸提罪，如果誤使人摔死則結突吉羅罪。如果挖坑時心意未定，隨其摔死的是人還是野獸，依照律法判定其罪之輕重。」所說的「倚暗器傷人」，是指詳實得知某人必定會倚靠觸碰那個地方，便在該處暗中佈置刀劍棍杖，使對方依附觸碰而死。所說的「給予毒藥」，文字與事情很清楚容易理解。所說的「安置殺生器具」，就像世俗執行死刑的刑場，比丘跑去看熱鬧，在那裡替劊子手擺設繩索刑具，使死囚因而致死，同樣結犯根本重罪。《薩婆多論》說：「如果是為了殺生，打造刀棒兵器，結突吉羅罪；拿著武器走向受害者，每走一步結一個輕偷蘭遮罪；如果兵器已經砍刺到受害者身上，而對方氣息未斷，結重偷蘭遮罪。」

【516-0004】02_戒疏/08b_卷二下之一#93
【原文】【記】殺具中。坑陷又二。初示相。「穽」音靜，亦坑也。「《十誦》」下，引釋。初約三趣，互論輕重，即是小漫。合有為非人作坑，人畜死吉，稀故不明。下云「不定」，乃約大漫，隨犯可會。「倚撥」者，謂潛安殺具，令彼觸動也。「安殺具」者，置辦器杖，令彼自用。「即」下，決其世事。「《多論》」下，示其方便。
【譯文】【記文】在殺生器具的一段中。設陷阱又分兩層。首先展示相狀。「穽」的讀音為靜，也就是地坑、陷阱。從「《十誦》」往下，引用律文來解釋。首先依據人、非人、畜生三趣眾生，交叉推論罪名輕重，這屬於動機範圍較狹小的「小漫心」。照理應當還有為非人挖坑，結果人或畜生摔死結突吉羅的情況，因為極為罕見所以沒有詳細列出。下文說「動機不定」，則是屬於涵蓋所有對象的「大漫心」，隨著實際所犯的對象來決定罪名。「倚暗器」的意思，是指暗中安裝致命兇器，使對方碰觸而引發。「安置殺具」，是指備辦準備兇器刀杖，讓對方自己拿去使用。「即如世中」往下，判定世俗中發生的這類實事。「《多論》」往下，開示殺罪逐步形成的方便罪相。

【516-0005】02_戒疏/08b_卷二下之一#94
【原文】【疏】文言「及餘方便」者，非謂如上所列而言相盡，更餘方便，律雖不載，但依而死，皆是重攝。
【譯文】【疏文】經文中說「以及其餘一切方便手段」，並不是說上面所羅列的殺害相狀已經窮盡無遺，還有其他害命的手段，戒律中雖然未能一一記載，但只要依循這些手段而導致他人死亡，全部都屬於根本重罪所攝受的範疇。

【516-0006】02_戒疏/08b_卷二下之一#95
【原文】【記】顯略中，初文。「律不載」者，謂不盡也。
【譯文】【記文】在顯明省略的說明中，這是第一段。「律不載」，是指文字無法完全窮盡。

【516-0007】02_戒疏/08b_卷二下之一#96
【原文】【疏】又欲遮惡比丘，避於佛制，如上網目所不攝者，欲加殺害。故又張網，總而收之，欲獲罪人，實唯一目。故俗云「天網恢恢，疎而不漏」是也。
【譯文】【疏文】這也是為了防範惡劣奸黠的比丘，刻意逃避佛陀明確制定的戒條，企圖利用上述條文網目沒有涵蓋到的漏洞，去對他人施加殺害。所以佛陀又張開這一道整體統攝的法網，企圖把罪犯一併網羅收伏，實際上只要有一條戒目適用就足夠了。就像世俗古話所說「天網恢恢，疏而不漏」就是這個道理。

【516-0008】02_戒疏/08b_卷二下之一#97
【原文】【記】次科。「又張網」者，謂此一句，統收多相，猶如張網。後必有犯，止在一事，猶如得魚，故云「一目」。下引俗證，出老子《道德經》。「恢」，大也。謂天道雖大，不容於惡，如網雖疎，不漏於物。
【譯文】【記文】這是第二小段。「又張網」，是說這一句經文，涵括了無量無邊的犯相，就像在虛空中張開一張廣大的天網。日後若有人犯戒，哪怕只是做出其中一件微細的殺事，就像自投羅網的魚一樣無所遁逃，所以說「一目」。下文引用世俗名言作為印證，出自老子《道德經》。「恢」是廣大的意思。是說天道法網雖然極為廣大，但絕不包容惡行，就像網眼雖然稀疏，卻絕不會漏掉任何事物。

【516-0009】02_戒疏/08b_卷二下之一#98
【原文】【疏】問：「如汝所釋，浪作分疎，至如佛意，何必如此？」
【譯文】【疏文】提問：「正如你上面所作的解釋，隨意牽強地作了分析梳理，至於佛陀當初制戒的真正心意，難道真的一定會是這樣嗎？」
