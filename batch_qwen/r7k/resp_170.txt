整體來說兩段譯文方向正確、可讀性好，但有幾處**實質性誤譯**與**無據增譯**，另有一些名相與行文問題。分別列出：

## 一、【170-0001】盜戒「不犯」段

### （1）必須修正

**①「已有想」應是「己有想」——關鍵誤讀**
《四分律》盜戒五種不犯作：與想、**己有想**、糞掃想、暫取想、親厚意。「己有想」是「誤以為那是**自己所有**之物而取」。譯文照抄成「作已有物想」，語意不明（讀者會以為是「已經有的東西」），完全沒有譯出這一條的意義。
→ 建議：**「以為是自己所有之物而取」**，並可加註說明原文「已」為「己」之形訛。

**②「三明不犯中」未翻譯**
這是科判句（第三、明不犯的情形），白話譯文中直接照抄文言，體例不一致。
→ 「第三、說明不犯的情形中（承上盜戒）。」

### （2）增譯與用詞

| 譯文 | 問題 | 建議 |
|---|---|---|
| 難忍之「屈辱」自己能忍受 | 原文只作「難忍能忍」，加「屈辱」把範圍窄化 | 「（為朋友）難以忍受之事能忍（如對方的惡言、侵損）」 |
| 「有過失」能彼此掩飾覆藏 | 「有過失」是增譯；且易與「覆藏他重罪戒」混淆 | 「彼此的隱私、過失互相覆護不宣」，並註明此非指覆藏他比丘重罪（另戒所制） |
| 機密之事能相互「告白」 | 「告白」是现代日語式用法，且「機密」偏公務 | 「**私密之事能彼此坦誠相告**」 |
| 「他人難行之事自己能代為行之」 | 「代為」是增譯 | 「（為朋友）難做之事能做」 |
| 「世人」若能身體力行 | 原文只作「人」，不必限定世人 | 刪「世人」 |
| 依準此標準來「權衡衡量」 | 疊義贅詞 | 「依此標準來衡量」 |

### （3）語意未落實

「準此量之」——**衡量什麼**沒有譯出。道宣引七法，是要人據此判斷「對方是否算得上律中所許的『親厚』」，從而決定「親厚意取（不問而取）」能否不犯。
→ 建議：「應依這七法來衡量（誰才是真正的親厚，可否適用『親厚意』而不犯）。」

## 二、【170-0002】殺人戒段

### （1）明顯錯誤，务必改

**①《伽論》書名錯**
《伽論》＝《**薩婆多毘尼摩得勒伽**》（即《毘尼摩得勒伽》，T1441）。譯文作「《薩婆多毘尼勒伽》」，漏「摩得」，且與下文《薩婆多》（＝《薩婆多毘尼毘婆沙》）易混。

**②「自殺者偷蘭」譯成「自殺未遂者結偷蘭遮」——實質誤譯**
律文只說「自殺者偷蘭」，重點是：**自害己身不結波羅夷（殺戒以他人為境），只就其「方便（加行）」結偷蘭遮**，並非以「未遂」為條件。譯文「未遂」是無據的限縮；「依其行凶手段而結罪」也把「方便」誤解為「手段」。
→ 建議：「自己殺害自身（自殺）者結偷蘭遮，這是就其加行方便而結罪（非根本波羅夷）。」

**③前后「自殺」同名異義，未加區分**
前文《四分》「一者自殺」＝**親自下手殺他**（譯文括號「自己親手殺害」正確）；此處「自殺」＝**自害己身**。同一篇中兩義並存而不註，讀者必混。
→ 前文建議改作「一是親自下手殺人（律云『自殺』）」並加註。

**④「犯罪」擅自定為「突吉羅」**
《十誦》原文僅作「乃至斷指，**犯罪**」，未標罪品。譯文逕填「皆犯突吉羅罪」，屬於代律定罪。
→ 保留「犯罪」，或加註「原文未標罪品，諸律判法不一，待考」。（下文「人死吉羅」譯為突吉羅則是正確的略稱還原。）

**⑤「籠頭」譯為「套頭面具」可疑**
「手巾絹帛，以作籠頭絞繩」是絞殺用具，「籠頭」當指**蒙覆頭面的布套／套頸頭套**，「面具」無據。
→ 「用作蒙頭布套、絞勒繩索等」，或存疑加註。

**⑥「並如律本結重」主語不明**
譯文「這都應當依循律典原本規定結波羅夷重罪」——「這都」指誰？結罪者是**讚美的七眾**，不是自焚者。
→ 「這些讚美稱揚的人，都依律本結波羅夷重罪。」

### （2）無據增譯（建議刪或降為註解）

- 「讚歎死亡**解脫之樂**」：原文只作「讚死」（稱死勝生、勸其速死），「解脫」是添加的教理色彩 → 「讚歎死亡（勸其死）」。
- 「讚美其人**道行**」：原文只作「讚美其人」 → 刪「道行」。
- 「乞其**痛快的**一刀」：原文「乞其一刀」（求速死免苦），「痛快的」宜移入註解。
- 「或**出於善心**給予藥物飲食」：原文「或以藥食」，善心之意已由末句「一切無害心」承擔 → 刪。
- 「使**國家出兵**征伐破壞別的國家」：原文「征破異國」主語應是國王／軍隊 → 「（國王）依比丘之言征伐攻破他國」。
- 「人跌入**摔死**」：坑陷致死不限摔死 → 「墮坑而死」。
- 「誤中他人身體」等處「碰撞」「趁機」「竟」屬語氣性增譯，可酌留，但「竟」帶評判語氣，與原文「亦有無知五眾與者」的平敘略異。

### （3）漏譯／語意不足

- **「或以藥食」漏了「而死」**：原文四事皆以「而死」為結句，譯文此句無致死語，與「不犯」的成立條件脫節 → 「或因給予藥物、飲食而致死者」。
- **「身現相」太籠統**：「自己現出身體動作」不知何意 → 「以身體動作示意（如點頭、招手，令彼致死）」。
- **「從初識至後識」**：「臨終最後一口氣息的滅亡之識」把「識」與「氣息」混說 → 「直到臨終最後一念心識為止」。
- **「無犯」宜限定**（薩婆多讚死條）：此處是說**對旁人之死不犯**（本非所期對象、無殺彼心），逕譯「說法比丘無犯」易被讀成一切無罪 → 「就旁人之死而言無犯（因非本所期，無殺彼之心）」。
- **「隨其前使」語意含混**：「隨順所派遣前去使役之人」讀來不知所指。此語一般解為「隨其前面所列（所派）使者的種種差別」，宜依《資持記》核定後改譯並加註。

### （4）行文問題

- 「犯戒的具備因緣有五項」→ **「構成犯戒的因緣（條件）有五項」**（原句語序不通）。
- 「第二心中明知是人想」贅 → 「二是作人想（認知對方是人）」。
- 「扶抱攙扶病人」疊義 → 「扶抱病人」。
- 「這就名為直接提供殺人物具」：原文「即名殺具」是說**所給之物即名殺具** → 「所給之物即名為殺具」。

### （5）建議加註的三處名相

1. **「三性之中，能教犯重」**：譯文雖已展開為善、惡、無記，但未說明為何三性皆犯。通行理解是：教唆者事後縱使心轉為善或無記，只要所教之殺事果遂、稱本期，仍犯波羅夷。宜加註（並核《資持記》）。
2. **「優婆塞例同」**：在家五戒之殺盜為「不可悔」重罪，此處借波羅夷之名，宜註明，免得誤以為在家人有波羅夷之名相。
3. **「以贖論」**：可註《唐律疏議》「過失殺傷人者，各依其狀以贖論」，即收贖贖罪，非處死。

## 三、優先處理順序

1. 「已有想」→「己有想」（意思整條漏失）
2. 「自殺未遂」刪「未遂」＋前后「自殺」二義加註
3. 《伽論》書名訂正
4. 「犯罪」不得逕填「突吉羅」
5. 「籠頭」非「面具」
6. 「並如律本結重」補主語
7. 「或以藥食」補「而死」
8. 其餘增譯（道行、解脫之樂、善心、痛快的、國家出兵…）酌刪或移註

其余如「漫心／剋心」「吉羅＝突吉羅」「五眾＝出家五眾」「本期＝本所期對象」的處理都正確，可保留。
