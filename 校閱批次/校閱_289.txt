# 校閱材料　第289檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【289-0001】02_戒疏/18a_卷四上之三#67
【原文】【疏】初「無緣」者，謂無上九中前六緣也。有緣之人，但能自益，不能益他；無緣之人，故須白出。
【譯文】【疏文】第一項「沒有特殊因緣」，是指沒有具備前面九種開緣中的前六種因緣。具備因緣的人，其開許只能利益自身，不能連帶利益他人；沒有因緣的人，所以必須稟白大眾後退出。

【289-0002】02_戒疏/18a_卷四上之三#68
【原文】【記】釋中，初科。九中，前六私緣，不必該眾，有無出入，須白除疑。後三通眾，故非所論。
【譯文】【記文】在解釋之中，這是第一個子目。九種因緣中，前六種屬於比丘個人的私事因緣，不一定涵蓋整個僧眾，出入有無，必須稟白說明以消除眾人的疑慮。後三種因緣通於全體僧眾，所以不是此處所要討論的。

【289-0003】02_戒疏/18a_卷四上之三#69
【原文】【疏】「若二、三人隨意食」者，反上九中第六「大眾」也。
【譯文】【疏文】「若是兩個人、三個人隨自己的意願受食」這句話，是反照上面九種因緣中的第六項「大批僧眾」。

【289-0004】02_戒疏/18a_卷四上之三#70
【原文】【記】次科，二、三非眾，故「反大眾」。
【譯文】【記文】第二個子目，兩個人或三個人並不構成四人以上的僧團規模，所以是「反照大眾」。

【289-0005】02_戒疏/18a_卷四上之三#71
【原文】【疏】「四人若過」者，舉前大眾，分破入食。
【譯文】【疏文】「四個人或四人以上」這句話，是舉出前面的大眾規模，將其分組拆散後再進入受食。

【289-0006】02_戒疏/18a_卷四上之三#72
【原文】【記】三中。言「分破」者，四人至六人可分二部，七人已上須分三部，如是知之。
【譯文】【記文】第三個子目。所謂「分組拆散」，四人至六人可以分成兩組，七人以上必須分成三組，依此類推便可明瞭。

【289-0007】02_戒疏/18a_卷四上之三#73
【原文】【疏】言「有緣」者，有六緣故。無緣直出，所以須白者，護施主故。有緣直入而須白者，護內比丘故。身是有緣，入須儀式，故「依次入」。又《律》釋疑也。若不白入，謂我僧次，無緣之徒，隨我濫入，故白簡之。無緣白出，釋疑亦爾。
【譯文】【疏文】所謂「具有因緣」，是指具備了上述六種因緣的緣故。沒有因緣的人逕自離席，所以必須稟白說明，是為了顧全施主的感受。具有因緣的人逕自進入而必須稟白說明，是為了護衛在座其他比丘的清白。自身雖然具有因緣，但進入時必須具備威儀法則，所以要「依照戒臘次序進入」。這也是《律藏》為了消除眾人疑惑的規定。如果不稟白說明就進入，大家會誤以為這是僧團普請的次序，那些沒有因緣的人就會跟著我魚貫濫入，所以必須透過稟白來加以簡別篩選。沒有因緣的人稟白後離去，其消除疑惑的作用也是如此。

【289-0008】02_戒疏/18a_卷四上之三#74
【原文】【記】四中。初示有緣。「無」下，對上「無緣」，雙出制白之意。初明無緣白出。「護施主」者，恐謂嫌弃故。次明有緣白入，又二。初「護比丘」者，恐疑成別故。「身有緣」等，釋「注」中「依次入」也。「又」下，二、約「釋疑」者，恐他疑己是無緣故。下云「無緣亦爾」者，若不白出，疑謂有緣，妄隨他出故。
【譯文】【記文】在第四個子目中。首先指出有因緣的內涵。從「沒有因緣（無）」字以下，對照前面的「無因緣」，同時說明制定稟白之法的兩層意趣。先說明沒有因緣者稟白而出的原因。「顧全施主」是指唯恐施主誤以為比丘嫌棄供養而捨棄離去。接著說明具有因緣者稟白而入的原因，這裡又有兩層：第一是「護衛在座比丘」，唯恐他人懷疑彼此結夥脫離大眾。「自身具有因緣」等語，是解釋注文中的「依照戒臘次序進入」。從「這也是（又）」字以下，第二是從「消除疑惑」的角度來說，唯恐他人懷疑自己也是沒有因緣的人。下文說「無因緣亦爾」，是指如果不稟白就逕自離開，旁人會懷疑他是有因緣受食而妄自跟著離去。

【289-0009】02_戒疏/18a_卷四上之三#75
【原文】【疏】問：「此中有緣，不白但犯吉者；我三寶緣，不白入聚，亦應犯輕？」
【譯文】【疏文】有人問：「此處具有因緣的人，不作稟白只犯突吉羅輕罪；那麼為了三寶的事緣，不稟白就進入聚落村莊，是否也應當只犯輕罪？」

【289-0010】02_戒疏/18a_卷四上之三#76
【原文】【疏】答：「此白除疑，別有所防。白入聚者，正是防也。」
【譯文】【疏文】回答說：「此處的稟白是為了消除眾人的疑惑，另外有所防範的目標。進入聚落時的稟白，所防範的正是擅自出入不作稟白這件事本身。」

【289-0011】02_戒疏/18a_卷四上之三#77
【原文】【記】結罪中，初問。以不白是齊，結犯別故。答中，有緣白法，自防他疑，故云「別有所防」。入聚白法，為防不白，故云「正是防」也。
【譯文】【記文】在結罪的辨析之中，這是第一個問難。因為同樣都是沒有稟白，但結罪的判定卻有所不同。在回答中，具備因緣者的稟白法則，是為了防止別人的疑心，所以說「另外有所防範」。進入聚落時的稟白法則，純粹是為了防範不稟白而產生的放逸，所以說「正是防範其事本身」。

【289-0012】02_戒疏/18a_卷四上之三#78
【原文】【疏】「若爾，覆藏治法，有緣出界，不白應輕，不應失宿？」
【譯文】【疏文】「如果是這樣的話，那麼依照隱匿罪過（覆藏）的治罰之法，在受罰期間有特殊因緣要跨越戒界，如果不作稟白應該也只是輕罪，而不應當導致喪失已懺除罪業的折算日數（失宿）吧？」

【289-0013】02_戒疏/18a_卷四上之三#79
【原文】【疏】答：「不同。病等六緣，正治別眾，不防於白。六夜出界，正防失宿，不防於白。何得將對治難不對治也？」
【譯文】【疏文】回答說：「兩者並不相同。生病等六種因緣，正是用來對治脫離大眾私食之過，而不是專為防範稟白這道程序本身。而在六夜出界的情況下，其重點正是為了防止喪失折算日數，而不是單純防範未作稟白。怎能拿具有對治目標的法則，去質難不具備相同對治目標的法則呢？」

【289-0014】02_戒疏/18a_卷四上之三#80
【原文】【記】次難中。行覆出界，制須白捨，不白犯吉，與此有緣不白罪同，彼更失宿，重於此者。答中，初明此白對治別眾。「六」下，次明六夜防於失宿。治防兩別，義非例難，故云「何得」等，以責非難也。
【譯文】【記文】在第二個問難中。修行覆藏治罰期間若要跨越戒界出外，戒律規定必須稟白暫時捨棄行法（白捨），不作稟白犯突吉羅罪，這與此處有因緣而不稟白的罪相相同，但彼處還會額外喪失宿夜的苦行成果，懲罰比這裡嚴重得多。在回答中，先說明此處的稟白是用來對治私組小團體的別眾食。從「六夜出界（六）」字以下，接著說明六夜的規定純粹是為了防範喪失宿夜。對治與防範的目標完全不同，義理上不能相提並論來進行難問，所以說「怎能」等語，用以責備這種不當的問難。

【289-0015】02_戒疏/18a_卷四上之三#81
【原文】【疏】問：「別眾食，何不計所別境犯，而結咽罪者？」
【譯文】【疏文】有人問：「脫離大眾受食，為什麼不依照被脫離的大眾人數來結罪，而是依照自己吞咽食物的次數來結吞咽罪？」

【289-0016】02_戒疏/18a_卷四上之三#82
【原文】【疏】答：「釋疑之體，終須識本。制意有二，不惱所別，故不就別人以結於犯。但隨業結，罪重自止也。」
【譯文】【疏文】回答說：「消除疑惑的根本體證，終究必須認識到制戒的本懷。制戒的意趣有兩點，為了不惱亂被脫離的僧眾，所以不在被脫離的人數上來結算犯行。只是隨著自身的動作造業來結罪，罪責深重自然能令比丘及時止步而不犯。」

【289-0017】02_戒疏/18a_卷四上之三#83
【原文】【記】次問。不從所別而隨咽犯，須明教意。答中，初汎敘答意。「制」下，正釋來問。初明不從境意。「制意二」者，即如上明損於道俗，「不惱所別」故。「但」下，次明隨業意。咽屬身業，隨動即結，故云「罪重」。原聖制意，令懼不犯，故云「自止」。
