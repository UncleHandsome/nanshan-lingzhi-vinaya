# 校閱材料　第1889檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1889-0001】03_業疏/21b_卷四之四#37
【原文】對首中，初明五人不得受欲，本是僧位，集行僧法。「若」下次明四人能秉不足，正是別位，止行對首。三人、二人隨改初句
【譯文】在對首自恣的內容中，起初說明五個人不能受欲，這本來是僧眾的位次，應當聚集推行僧法。自「若」以下接著說明四個人能秉法的人數不足，正屬於別眾位次，只能推行對首自恣。三人或二人時，隨之改動起首的文句。

【1889-0002】03_業疏/21b_卷四之四#38
【原文】心念法中，大同說戒。前修眾具，如文可知。說己心行，應於僧故，以即法不二，十方同遵，故曰「今日眾僧自恣」也
【譯文】在心念自恣法中，大體同於說戒法。事前所備辦的各種資具，正如律文所記可知。陳說自己的心念行持，必須相應於僧眾的緣故，因為當下之法本無二致，十方僧眾共同遵行，所以說「今日眾僧自恣」。

【1889-0003】03_業疏/21b_卷四之四#39
【原文】心念中，初指緣說。「下」次釋法。即法不二，以事表理，事既同遵，理必無外
【譯文】在心念自恣的內容中，起初指明因緣而說。自「下」以下接著解釋作法。當下之法本無二致，是以事相顯彰理體，事相既然共同遵行，理體必定無所遺外。

【1889-0004】03_業疏/21b_卷四之四#40
【原文】就尼法中，要取兩眾滿五已上，方得治舉行事具也。不同教誡，約夏量德，四人已下，縱有所陳，治舉非數
【譯文】在比丘尼法中，必須僧尼二眾各自滿五人以上，才能具備治罰舉罪與辦理法事的條件。這不同於半月教誡法那樣依照戒臘衡量德行；比丘若在四人以下，縱然有所陳白，也非治舉所需的法定人數。

【1889-0005】03_業疏/21b_卷四之四#41
【原文】尼中初科又二：初明滿眾。彼此僧法，互缺不成。說戒請人須二十夏，自恣但取具二五德。「四」下次釋不滿，治舉非數，且就僧論。若尼不滿，不行差法，但用口差。應作四句：一、尼滿僧不滿，二、僧滿尼不滿，三、俱滿，四、俱不滿。二句廣法，二句略法
【譯文】在比丘尼法的第一科中又分為兩部分：起初說明僧數圓滿。彼此僧團的羯磨法，互相缺少一人便不能成就。說戒時延請教誡人必須滿二十夏，自恣則只選取具足兩種五德之人。自「四」以下接著解釋人數不滿，治舉人數不足，這是暫且就比丘僧而言。如果比丘尼人數不滿五人，則不行羯磨差派法，只用口頭差遣。應當分為四種句型：一是尼眾滿五而僧眾不滿，二是僧眾滿五而尼眾不滿，三是僧尼俱滿，四是僧尼俱不滿。其中兩句屬廣法，兩句屬略法。

【1889-0006】03_業疏/21b_卷四之四#42
【原文】此相依法，制在八數。今時殆盡，彼此缺矣，何名正法返千載乎
【譯文】這種二眾相依之法，制定在八敬法之數中。現今這個時代幾乎廢絕殆盡，僧尼彼此都欠缺了，怎麼能說是讓正法延續回歸千年呢？

【1889-0007】03_業疏/21b_卷四之四#43
【原文】二中初示制法在八數者，即八敬中「夏末依僧自恣」為一敬也。次「今」下傷歎彼此缺者。僧既缺德，尼則缺敬。最初如來不許度尼，乃曰正法千年，若度女人減五百歲，能行八敬還復千年，故舉此言以傷法滅
【譯文】在第二部分中，起初指出所制之法在八敬法之數，也就是八敬法中「夏末依止大僧自恣」為其中一敬。接著自「今」以下感傷嘆息僧尼彼此欠缺：僧眾既然欠缺德行，尼眾就欠缺恭敬。最初如來不允許度化婦女出家為尼，曾說正法本可住世千年，如果度化女人出家則減損五百年，若能奉行八敬法便能重獲千年；所以舉出這段話，以此傷悼正法的衰滅。

【1889-0008】03_業疏/21b_卷四之四#44
【原文】近有行事，或別房中，或在戒場，將五人僧受尼請恣，且得酬於下眾，非是佛制本規。嗚呼！見此良悲，法滅餘亦須述，知復何言
【譯文】近來有人行事，或者在個別僧房中，或者在戒場裡，帶領五位比丘僧去接受比丘尼請自恣，暫且用以應付下眾（尼眾），這絕非佛陀制定的本來規矩。嗚呼！見到這種情形實在令人悲痛，然而正法雖滅，其餘法規儀軌也必須記述，真不知還能說什麼呢！

【1889-0009】03_業疏/21b_卷四之四#45
【原文】三中，本須大界通眾求舉，別房、戒場深非本制。下復悲嗟法無興衰，隨人故減。縱述無用，故云「知復何言」。文廣疏略，今更分之：初注是緣；「若眾滿」下即法，又三：初尼差人法，二「佛言」下尼往僧中請法，三「良久」下僧中上座誡勑法，又二：初示法，上座告勑使尼傳教，「此」下二結告。教誡詞句，祖師義設，非律有之，且標一句言其少也，未必依文令轉變也
【譯文】在第三部分中，本來必須在大界內向全體僧眾請求舉過，在個別僧房或戒場中深不合於原本制度。底下再度悲嘆法本無興衰，純粹是隨著人的敗壞而減損衰落。縱然陳述也無濟於事，所以說「知復何言」。律文繁廣而疏文簡略，現在再作劃分：起初的注文是緣起；自「若眾滿」以下就是作法，又分為三：一是尼眾差派使人法，二是自「佛言」以下尼眾前往僧中請法，三是自「良久」以下僧中上座誡敕之法；這又分兩節：一是示明其法，由上座告敕令使尼傳達教誡；自「此」以下第二是結語告誡。教誡的文詞語句，是祖師在法義上所施設的，並非律典本有，姑且標示一句說明其文句簡省，未必非要完全依照文字逐句轉變。

【譯文】夏末接受利養施捨，本將作為救濟之因緣，但若是受納違背軌儀，福報便會流注到不相應之處（流於非福田）。所以必須周詳觀瞻各種布施，確立戒法的通融與局限，如此則能施與所受都無瑕疵，不至於因受施而墮落，這難道不是極好之事嗎？

【1889-0014】03_業疏/21b_卷四之四#50

【譯文】在敘述宗意的內容中，起初敘述違背戒法的損害。「非地」，地就是指處所。「故」以下接著說明確立戒法的利益。「具瞻」，如同普遍觀覽。「可不好者」，是說具有莫大益處。

【1889-0017】03_業疏/21b_卷四之四#53

【譯文】起初義理分為四門：一是判定時衣與非時衣的體性，二是現前施與僧得施中各有時與非時，三是需要作法與不需要作法，四是位次條例的差別。

【1889-0018】03_業疏/21b_卷四之四#54
【原文】初明體者，時有二種：初一月、五月，是饒益夏勞供五利時，如律毗蘭若請為安居故，施名為時也；除此已外，名為非時。律中時有檀越為施塔故及亡人會，現前僧大得可分衣物留過安居，佛言不應留過，此是非時衣，現前僧應分。準此為言，但一年中不為夏勞，即名非時，何獨迦提五月之外
【譯文】第一說明體性，「時」有兩種：最初的一個月或五個月，是為了犒勞安居之辛勞而提供五種利益的時期，正如律中於毗蘭若受請安居，為此而布施的稱為「時」；除此以外，都稱為「非時」。律典中當時有施主為了施塔以及為亡人設齋會，現前僧眾獲得許多可分的衣物，僧人將其留存以待安居之後分發，佛陀說不應當留過安居，這是非時衣，現前僧眾應當立即分發。依照此例而言，只要一年之中不是為了犒賞安居辛勞而布施的，就稱為非時衣，何止是迦提月或受功德衣的五個月之外才算非時呢？
