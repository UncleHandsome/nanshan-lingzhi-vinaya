# 校閱材料　第947檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【947-0001】資持記/02d_上一下#45
【原文】我不須者，非己事也，非謂無心同須法事。問：三體何異？答：初是能欲，後即所欲，中即說詞。鈔出後解，餘義存略。開遮中，初明遮。遮即是制。律文唯結三種大界羯磨之前，並云不得受欲，故曰唯除。〔義準三小戒場亦遮。〕餘下，明開，初句判定。下二句義決。
【譯文】我個人不需要，是因為並非與自己直接相關的事，但並不是說內心沒有共同需要這場法事的心意。問：這三種體性有何差別？答：第一種是能欲的心，最後一種是所欲的事，中間一種就是宣說的言詞。行事鈔採用後一種解釋，其餘的義理暫時省略。在開許與遮止中，起初說明遮止。遮止就是制止不許。律文唯獨在作三種大結界的羯磨之前，都明載「不得接受欲意」，所以說「唯除」。〔依義理推斷，三種小戒場的結界也同樣遮止。〕從「餘」以下，說明開許，第一句直接判定。下兩句以義理裁決。

【947-0002】資持記/02d_上一下#46
【原文】欲法制緣，出說恣二犍度；戒本單白，捨德衣白，前列問欲；自餘並無，故云非明文也。除結界法，制不取欲；餘並不制，意即是開，故云以非制也。所以唯遮結界者，答如本篇明之。緣中為二，初簡非緣。犯戒非法，語略事含；通於一切治生邪命放逸縱怠，不應所列，並入非緣。
【譯文】欲法制定的因緣，出自說戒與自恣兩個犍度；戒本的前方便單白羯磨，以及捨去功德衣的單白羯磨，前面都列有詢問欲意的話；其餘羯磨並無此文，所以說是「非明文規定」。除了結界之法，明文規定不得收取欲意；其餘的法都沒有禁止，意旨就是開許，所以說是「因為非禁止之故」。至於為什麼唯獨遮止結界法，回答就如同本篇後文所說明的。在因緣中分為兩部分，起初簡別非合法的因緣。犯戒與不合法的行為，語詞簡略而包含的事務極多；通括一切經營生計、邪命生活、放逸懈怠等，凡是不符合所列條款的，全都列入非合法因緣。

【947-0003】資持記/02d_上一下#47
【原文】要知欲法，事不得已，故曲開之。微涉濫委，無非背叛。重病舁至，教意可知。寄言學者，彌須競慎。不合者，遮未說也。不成者，斥已說也。若下，次明如緣，有六。律文欲法中本無塔事，《注羯磨》亦列五種；今準不與欲戒加之，彼云僧事塔寺事瞻視病人，並開與欲。上引正緣。而下示旁緣。
【譯文】必須明白欲法是在不得已的情況下，才委曲予以開許的。稍微涉入浮濫廢弛，無非都是對僧團的背離背叛。重病之人甚至要抬到僧中，教法的用意由此可知。在此寄語學者，更應當極力警惕謹慎。所謂「不合」，是遮止尚未宣說之前。所謂「不成」，是斥責已經宣說之後。從「若」以下，其次說明如法的因緣，共有六種。律文中欲法本來沒有修塔的事，《注羯磨》也只列了五種；現在依照「不與欲戒」加以補充，那裡說僧團的事、塔寺的事、看護病人的事，都開許交付欲意。上面引述的是正當因緣。從「而」以下顯示旁附因緣。

【947-0004】資持記/02d_上一下#48
【原文】出與欲後悔戒。非正制者，不出欲法故。僧受行者，示可取故。《僧祇》彼更有蘭若衣鉢〔經營衣鉢〕，王賊禁閉並開。下句指略，有云《義鈔》，今見疏中。斥世中，初指非。多慢即心非。妄行是事非。斯法即欲。〔有準《尼鈔》是慢說戒羯磨法者，彼此別致，不可一例。〕謂下，釋相。
【譯文】出自「與欲之後反悔戒」。之所以不算正式制定，是因為並未出現在欲法的專屬篇章中。之所以僧團接受並奉行，是顯示可以採納的緣故。《僧祇律》那裡更有經營阿蘭若衣缽〔料理衣缽之事〕，以及被官府、賊人拘禁幽閉等也都開許。下一句是指引略過的內容，有人說是《義鈔》，現在見於《業疏》之中。在痛斥世人弊病中，起初指出其錯誤。「多慢」是指內心的錯誤。「妄行」是指行事的錯誤。「斯法」就是指交付欲意之法。〔有人依照《尼鈔》認為是指怠慢說戒羯磨法，彼此意旨不同，不可一例。〕從「謂」以下，解釋行相。

【947-0005】資持記/02d_上一下#49
【原文】言無病者，此約牒緣者為言。令下，顯過，初明與欲人過。令傳至僧，成教人業。據理，初與時，前對不知亦得三罪。所下，出受欲人過。由知不實，自他同犯。言三罪者，即上三妄。今不牒緣，則無初妄。必若體淨，亦無第二。不欲言欲，定有可知。後二句訶誡。
【譯文】說「無病」，這是就宣讀陳述因緣的人來說的。從「令」以下，顯明罪過，起初說明交付欲意之人的罪過。指使他人傳達到僧中，構成了教唆他人造業。按照道理，最初交付的時候，面對的受欲人如果並不知情，自己也構成三種妄語罪。從「所」以下，點出受欲人的罪過。由於明知事情不實，自己與他人都一同犯戒。所謂「三罪」，就是指上述三種妄語。現在如果不陳述因緣，就沒有第一種妄語。如果自身戒體本來清淨，也沒有第二種妄語。但不想交付欲意卻聲稱要交付，這必定存在是顯而易見的。最後兩句是呵責與戒勉。

【947-0006】資持記/02d_上一下#50
【原文】《尼鈔》問云：無病既不合說，得成法事否？答：成。前人自有妄語之罪。二欲法自與中，初科。以律但云佛言不應稱事與欲清淨，聽如法僧事與欲清淨。無上二句，故云不具。《業疏》云：律云廣說，不正出文；今比轉欲裁出，故云義設。
【譯文】《尼鈔》設問說：無病既然不合適宣說欲意，那麼僧團法事究竟能不能成辦？答：可以成辦。前面那個人自己承擔妄語的罪過。第二、欲法中親自交付的項目中，第一個科判。因為律文只說佛言不應當指稱具體事務交付欲意清淨，聽憑在如法僧事中交付欲意清淨。缺少了前面兩句，所以說是「不具備」。《業疏》說：律中說有廣說之詞，但沒有正式列出完整文字；現在比照轉傳欲意的文句裁度制定出來，所以說是「按義理施設」。

【947-0007】資持記/02d_上一下#51
【原文】詞中，初句告前憶持，次句自言名號，第三句牒所欲事，第四句正陳本心。次定多少中，初示他部。今下，明不取。即序所謂是非條別故也。初示本宗立法分齊。無結略者，如捨戒悔吉等，不云三說；單白白二，不云第二第三等是也。文中且指白四為言，若三歸乞詞，對念說恣，並直云三說。
【譯文】言詞之中，第一句是告知對方要用心記住，第二句是自稱法名法號，第三句是列出所欲求的事務，第四句是正式陳述自己的本心。其次在判定多寡之中，起初指出其他部派的說法。從「今」以下，說明不予採納。這就是序文中所說「是非標準條理分別」的緣故。起初顯示本宗立法的界限準則。沒有結尾概括省略詞的，例如捨戒、悔吉等，不說「三番宣說」；單白與白二羯磨，也不說「第二遍、第三遍」等就是如此。文中暫且是指白四羯磨而言，若受三歸的祈求詞，對首與心念的說戒、自恣，都直接明說「三番宣說」。

【947-0008】資持記/02d_上一下#52
【原文】準下，舉法例成。以轉欲中無結略故。不下，斥非。疏云：有人依《五分》、《僧祇》，云不三說不成欲，故此斥之。所以一說即成者，疏云：莫非呈心至僧，眾多忘隱，明判開之；豈限三說，方成一法。不牒緣中。古本羯磨欲並稱緣；恐後疑執，故此問破。此欲詞者，指上義設。
【譯文】從「準」以下，舉出僧法比照成立。因為在轉傳欲意中並沒有結尾省略詞的緣故。從「不」以下，斥責錯誤。疏文說：有人依據《五分律》、《僧祇律》，認為不說三次就不能成辦欲意，所以在此予以斥責。之所以說一次就能成辦，疏文說：這無非是為了將心意呈報到僧眾之中，眾人多有遺忘或隱晦，律文明確判定予以開許；哪裡需要受限於非得說三次，才能成辦一項法事呢。在不陳述因緣的項目中。古代版本的羯磨法中，欲意詞全都宣讀因緣；唯恐後人產生疑惑執著，所以在此提出質問予以破除。這裡說的「欲詞」，是指上面依照義理施設的句子。
