# 校閱材料　第027檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【027-0001】01_行事鈔/04b_卷上之四#29
【原文】五重受者。昔解，一夏之中，開於三法，差此不成。今云，得重。廣有徵難，如《疏》述也。但事緣如法，無問多少，一切通開；必是犯戒緣者，一受不合。故律列二十餘緣，但云佛未聽我如是事去，不言不得重去。且約為事信樂父母，則有四重；況餘雜請，頓便限局。《五分》：若有請無請，須出界外，一切聽受七日。《十誦》中，列多七夜緣已，文云：若自為身、若為他身，若不遣使、若遣使，應去；聽一七夜，不聽二七夜。謂一時雙牒二七日，前後重用。若準和僧，似一事上，不許重受；然彼有不請之文，寬於《四分》；重受不開，文非明了，理須通明。《五百問》云：受七日行，不滿七日還本界，後更行，不須更受；滿七日已，乃復重受。《明了論》中，得受。《疏》解云：前請七日，事了，還至界內；第八日，更請七日出界宿。此論真諦三藏翻，中國親承此事。寧得自執一隅小見，通壅三千佛化乎。余親聞見中國翻經三藏，及中國來者，云佛滅度來，無有立一夏三度受日法；隨事如法並開。餘廣如《疏》、《鈔》。
【譯文】五重受者。往昔的解釋認為：一個夏安居之中，只開許七日、半月、一月三種法各一次（一夏三度），若有差池便不能成就。如今我認為可以重複受法。其中廣泛的論辯問難，如《疏》中所述。只要事緣合乎戒律，不論次數多少，一切皆通融開許；假若是犯戒的因緣，即使受一次也不合戒法。所以律中列出二十多種因緣，只說「佛陀尚未准許我為了這樣的事前去」，並沒有說不得重複前往。單就為了事奉具有信樂的父母而言，就有四重因緣；何況其餘雜項邀請，怎能驟然加以局限。《五分律》說：若有邀請或無邀請，只要必須出界外，一切皆准許受七日法。《十誦律》中列出多種受七夜法的因緣之後，文中說：若是為自己身、若是為他人身，若對方未派使者、若對方派遣使者，皆應當去；准許請受一個七夜，不准許請受兩個七夜。這是指不准在一次作法中同時宣讀兩個七天，而非指不許前後分別重複受用。如果照調和僧眾爭端之事來看，似乎在一件事上不許重複受日；然而該律中有未受邀請亦可前往的明文，這比《四分律》更為寬鬆；對於重受不予開許，經文並非明白了徹，於理應當融通明晰。《五百問事》說：請受七日法出行，未滿七日即返回本界，之後若還要出行，不需要重新受法；滿了七日之後，才再重複請受。《明了論》中也認為可以重複受法。《疏》解釋說：先前請受七天，事情辦妥，返回到界內；第八天，再次請受七天出界留宿。此論由真諦三藏翻譯，是印度（中國）親承相傳的行持。怎能執著於自己一孔之見，而窒礙阻隔三千大千世界的佛陀教化呢？我親自聽聞並見到印度來的譯經三藏，以及從印度前來的人說：自佛陀滅度以來，從未有立下「一夏只能三次受日」這種法則的；只要隨事且合乎戒法，全都予以開許。其餘詳細如《疏》與《鈔》所述。

【027-0002】01_行事鈔/04b_卷上之四#30
【原文】六約事長短。縱令前事唯止一日二日，皆須七日法。律云：不及即日還，聽受七日去；夏末一日在，亦作七日法。立法楷定，作法應爾。若路近得還，由緣經宿，亦須受日。
【譯文】六約事長短。縱使所要辦理的事僅需一天或兩天，都必須請受七日法。律中說：來不及在當天返回者，准許受七日法而去；夏末只剩下一天在，亦同樣作七日法。戒律立法的規範標準如此，作法時就應當這樣。如果路途很近本可當天返回，但因為事緣而在外過夜者，亦必須受日法。

【027-0003】01_行事鈔/04b_卷上之四#31
【原文】七僧尼不同。《四分》尼律中：開受七日，不云多。《僧祇》：尼無羯磨受日法；若塔事、僧事遊行者，受七日去。比有濫同僧法者，但令緣至，三法受日；《四分》無文，《僧祇》明斷，足是指歸，不勞別解。所以不同者，尼是女弱，不假多遊；入俗外化，生善義少；但開七日，亦濟別緣。
【譯文】七僧尼不同。《四分律》比丘尼律中：只開許受七日法，沒有說更多天數。《僧祇律》說：比丘尼沒有羯磨受日法；若是為了佛塔之事、僧伽之事出外遊行，受七日法而去。近來有人混濫等同於比丘僧法，只要事緣一到，就以三種法（七日、半月、一月）受日；《四分律》並無明文開許，而《僧祇律》有明確裁斷，這足以作為行持的準則依歸，無須另作強解。之所以有所不同，是因為比丘尼身為女性較為柔弱，不應當過多出外遊歷；進入俗世教化，能生起善法的意義較少；所以只開許七日法，這也能周濟解決特別的因緣。

【027-0004】01_行事鈔/04b_卷上之四#32
【原文】八事訖不來成不者。由所牒緣謝，法亦無施，便失法也。即須反界，不反破夏。《明了論》云：請七日出界訖，事竟不還，破安居，得小罪。《十誦》明文不許往。《僧祇》意亦同之。
【譯文】八事訖不來成不者。由於所列明的事由因緣已經了結，受日之法也沒有施行的依據，便喪失了法力。這時就必須返回界內，若不返回就算破夏。《明了論》說：請受七日法出界完畢，事情辦完卻不返回，破壞安居，得輕垢小罪。《十誦律》有明文不准許繼續在外。《僧祇律》的意旨亦同於此。

【027-0006】01_行事鈔/04b_卷上之四#34
【原文】前明心念法。《十誦》：五種人，謂獨住等，心念受日。若界中有人堪來，不待，心念不成。若待不得，界又無人，具儀，心生口言：「我某甲比丘，今受七日法出界外，為某事故，還來此中安居。」此謂無比丘開心念。若有沙彌者，作念已，告以事緣：「今請七日出界，若了即還，汝知之！」《十誦》令五眾受日，五眾邊受。準此，當眾相共作之；無者，準前言告。其沙彌受日，如下〈別法〉。
【譯文】前明心念法。《十誦律》說：有五種人（如獨自一人安住等情況），可行心念法受日。如果界內有其他比丘能夠前來，卻不等候他，則心念受日不成。如果等候不來，界內又確實沒有其他人，則具足威儀，心生想念口中說道：「我某甲比丘，今受七日法出界外，為某事故，還來此中安居。」這是指沒有其他比丘時開許作心念法。如果身邊有沙彌，作心念完畢後，應告知他事由因緣：「我如今請受七日法出界，事情若辦完立即返回，你要知曉此事！」《十誦律》命令出家五眾受日，要從五眾之處求受。準照此理，應當在各自所屬的同眾中共同作法（對首受日）；如果沒有同眾，則依前面所說口頭告知（如比丘告知沙彌）。至於沙彌受日之法，如下文〈別法〉中所述。

【027-0007】01_行事鈔/04b_卷上之四#35
【原文】二對首受法。應具儀對比丘言：「大德一心念！我某甲比丘，今受七日法出界外，為某事故，還來此中安居。」然心念、對首二法，諸部無文，但開受法。相傳準羯磨白文，雖非佛說，義準無失。若受七日未用，過七日用亦得，以本緣在故；若無，法謝。不同七日藥，彼已限滿，病轉故失。若爾，病住法應在？答：由佛制定。如論云：服之七日，堅病得消。問：此請七日，得兼夜不？答：不得。以文云：至第七日當還。不同《十誦》，彼以文中受七夜故。又不得改云七夜，以部別不同。亦不得秉《四分》羯磨，用《僧祇》事訖，具如諸部別行法中。
【譯文】二對首受法。應當具足威儀對一位比丘說：「大德一心念！我某甲比丘，今受七日法出界外，為某事故，還來此中安居。」然而心念、對首這兩種方法，各部律中並沒有明文白文，僅僅開許了受日的法則。相傳是依照羯磨白文推準擬定，雖然不是佛陀親口宣說之文，但在義理上推準並無過失。如果受了七日法尚未動用，過了七天之後才使用也可以，因為原本的事緣依然存在的緣故；若事緣已不存在，法力便告消退。這不同於「七日藥」，那是因為期限已滿，病情轉變故失去開許。若照此反問：病情若仍在，藥法是否應當還在？答：這是由於佛陀明文制定的緣故。如論中說：服用七天，固著的重病便能消除。問：這裡請受七日，能兼含第七夜嗎？答：不能。因為律文中說：「至第七日應當返回。」不同於《十誦律》，那是因為該律文中明說受「七夜」的緣故。此處又不得改口說「七夜」，因為部派傳承不同。亦不得秉持《四分律》羯磨，卻借用《僧祇律》的事訖法（以事畢為期），詳情具如各部律別行法中所述。

【原文】然九旬修道，精練身心；人多迷己，不自見過。理宜仰憑清眾，垂慈誨示，縱宜己罪，恣僧舉過；內彰無私隱，外顯有瑕疵；身口託於他人，故曰自恣。故《摩得伽》云：何故令自恣？使諸比丘不孤獨故，各各憶罪發露悔過故，以苦言調伏得清淨故，自意喜悅無罪故也！所以制在夏末者，若論夏初創集，將同期欵九旬，立要齊修出離；若逆相舉發，恐成怨諍，遞相訟及，廢道亂業。故制在夏末者，以三月策修，同住進業；時竟云別，各隨方詣。必有惡業，自不獨宣，障道過深，義無覆隱；故須請誨，良有茲焉。故律聽安居竟自恣。《毘尼母》云：九十日中，堅持戒律及修諸善，皆不毀失，行成皎潔，故安居竟自恣。此是自言恣他舉罪，非謂自恣為惡；此雖相顯，有無知者濫行。
【譯文】在九十天的安居修道中，精純磨練身心；然而人往往迷惑於自己，看不見自己的過失。在理上應當仰賴憑藉清淨僧眾，垂賜慈悲教誨示導，放任說出自己的罪過，任由僧眾檢舉自己的過失；對內彰顯無所私自隱匿，對外顯露自己存有瑕疵；將身口交託於他人，所以稱為「自恣」。因此《摩得伽》（《薩婆多部毘尼摩得勒伽》）說：為何要讓比丘自恣？是為了使諸位比丘不陷於孤立無依之故，使各自回憶罪過並發露悔過之故，以苦切的言辭調伏身心而得清淨之故，內心自我喜悅無有罪垢之故！所以制定在安居期末的原因：若是談到夏初剛剛聚集之時，大家將要一同約定九十天之期，立誓共同修行出離之道；如果在一開始就互相檢舉揭發，恐怕會形成怨恨諍論，彼此互相興訟牽連，荒廢道業、攪亂學修。所以制定在夏末的原因，是因為經過三個月的策勵修持，同住增進道業；此時期限已滿即將告別，各自隨方向行去。必定若有造作惡業，自己不會單獨宣說，其障道之過患深重，在義理上絕不可覆藏隱瞞；因此必須請求教誨，確實是由於這個緣故。所以律中聽許安居結束時進行自恣。《毘尼母》（《毘尼母經》）說：在九十日之中，堅定持守戒律以及修習諸多善法，都沒有毀犯缺失，戒行成就皎潔無瑕，所以在安居結束後進行自恣。這是自己陳說並任由他人檢舉罪過，並非說任憑自己隨意造作惡行；這雖然事相顯著，但仍有無知之人妄肆濫行。

【027-0023】01_行事鈔/04c_卷上之四#12
【原文】初中，《四分律》取具二五法者，謂不愛、恚、怖、癡、知自恣不自恣，此名自恣五德。律文又差知時不以非時、如實不以虛妄、利益不以損減、柔耎不以麁獷、慈心不以瞋恚，此謂舉罪五德。意令和合無諍，有罪非謬；欲使前人懺悔清淨，美德外彰；故能勸喻，離於懷惱；愍物與樂，不欲非法故。所以差二人者，《四分》文不了；《十誦》、《僧祇》中，並差二人為法；《五分》中，二人已上，乃至多人；《三千威儀》云：要差二人，為僧自恣竟，自相向出罪，不得求餘人自恣，以餘人僧不差故。今行事者，多有人人別差，此未通諸部。又差年少輕揵者，多不生善，《十誦》、《僧祇》多差上座有德者，令下座來向上座自恣也！
【譯文】第一項中，《四分律》選取具備兩組五德（二五法）的人，即不因貪愛、瞋恚、恐怖、愚癡而行事，以及知曉自恣與不自恣之法，這稱為「自恣五德」。律文中又差遣知時而不以非時、如實而不以虛妄、為了利益而不損減、柔和而不粗獷、心懷慈悲而不懷瞋恚之人，這稱為「舉罪五德」。其用意在於使僧團和合而無諍論，所舉之罪真實無誤；期望使對方發露懺悔而得清淨，美好的德行向外彰顯；因此能夠循循勸導，使其遠離懷恨煩惱；憫念眾生而給予安樂，不欲行非法之故。之所以差遣兩人的原因，《四分律》的行文不夠明確；在《十誦律》、《僧祇律》（《摩訶僧祇律》）中，都是差遣兩人為法定標準；《五分律》中，則是兩人以上，乃至多人；《三千威儀》（《大比丘三千威儀》）說：必須差遣兩人，為僧眾受自恣完畢後，兩人互相向對方發露除罪，不得找其餘的人自恣，因為其餘的人僧伽並未差遣。如今執行僧事者，多有每個人各自差遣受自恣人的情況，這並未通達諸部律典。又有人差遣年輕輕浮捷疾之人，往往不能生起善法，《十誦律》、《僧祇律》多差遣上座有德之人，使下座比丘前來向上座自恣！
