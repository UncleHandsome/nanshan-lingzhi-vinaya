# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【103-0011】02_戒疏/04c_卷一下之二#105
【原文】【疏】然受戒後，勤學教行，於諸事法，明若指掌，忽於境想，迷忘而造，律制非犯。此不可學迷也。
【譯文】【疏文】然而受戒之後，若能勤奮學習教理與行持，對於各項事相與法規，都明了得如同看手掌心一樣清楚，如果突然對於境界的認知產生混亂遺忘而做了違律的事，戒律特別規定這不算犯戒。這就是屬於不可修學的突發迷惘。

【103-0012】02_戒疏/04c_卷一下之二#106
【原文】【疏】若由來不學，不思過犯，隨所造作，不問事法，但作有違，皆犯根本。緣而不了，結無知。若於二持，雖不違負，望非明決，不名為福。若緣不解，但是無知。是以佛言「隨作犯根本，更增無知罪」。
【譯文】【疏文】如果從一開始就不肯修學，從不思考什麼是過失違犯，隨著自己的作為，不管面對的是具體事相還是僧事法規，只要造作時有所違背，全都觸犯了根本戒。若面臨境界卻懵懂不解，就要加結不學無知罪。如果在止持或作持這兩方面，雖然沒有違背戒條，但因為心中並非明確堅定而行，所以不能算作真正的福德功德。如果在面對境界時茫然不解，這單純就是犯了無知罪。因此佛陀說：「凡是違犯就結根本罪，更要額外增結一條不學無知的罪名。」

【103-0013】02_戒疏/04c_卷一下之二#107
【原文】【記】敘結分三。初明立教之旨，「然」下敘結之所以。初明學人開迷。文中明學，須具二義。言「學教」者，謂精窮三藏。「學行」者，謂專修對治。若此為學，方開迷忘，自餘泛爾，皆不學收。舉世相傳，纔過學肆，便稱「學人」，自謂無罪。觀其所業，曾未勤勞；求其所行，略無奉慎。豈能全免不學無知！請詳此文，足為龜鏡。「律制」者，即諸戒後境想中開。「若由」下，次明不學須結。又三，先明迷犯。「若」下，次明昧持。故知不學，由不曉教，持亦成犯。「是」下，引證。即「不攝耳聽戒」文。
【譯文】【記文】在敘述與判定中分為三部分。首先說明佛陀立戒的主旨，「然而」以下敘述判罪的原由。第一、說明有學之人在遇到迷惘時獲得開許。文中說明「修學」，必須具備兩層意義。所謂「修學教理」，是指精研窮究經律論三藏；所謂「修學行持」，是指專心修習對治煩惱惡法。只有達到這種程度的修學，才開許突發的遺忘迷惘，其餘那些泛泛度日的人，全都收歸於不學之流。現在世俗相傳，才稍微進過幾天講堂學肆，就自稱為「學戒之人」，自以為沒有罪過了。檢視他所修的學業，未曾真正下過苦功勤勞；考察他平素的行持，絲毫談不上謹慎奉行。這樣的人怎麼可能完全免除「不學無知罪」呢！請深細審視這段文字，足可以作為修行的大明鏡。「戒律規定」這句話，是指各條戒後面關於境界想念中所給予的開許。「如果從」以下，第二、說明不肯修學的人必須判定結罪。又細分為三點：首先說明因迷惘而犯戒；「如果」以下，接著說明對於持戒的盲目，由此可知不肯修學的人，由於不懂戒律，即便守戒也可能轉成獲罪；「因此」以下，引用佛經為證，也就是引自〈不攝耳聽戒〉的經文。

【原文】【疏】今略標舉，須配位法。此立兩箇九句，交絡有無，為持犯方軌。
【譯文】【疏文】現在略微標舉列出，必須將其配對在具體的階位與法規上。此處設立了兩組九句，相互交織錯綜出有罪與無罪的狀況，作為判定持戒與犯戒的準則規範。

【103-0015】02_戒疏/04c_卷一下之二#109
【原文】【記】總標中。初句指前，「須」下生後。言「交絡」者，即於事犯，各有識、疑、不識三心，互織作句，如圖所顯。言「方軌」者，若解二九，隨一事法，無不該通，故《事鈔》云「類通法界」是也。
【譯文】【記文】在總標題中。第一句承指前面，「必須」以下引發後文。所謂「相互交織」，是指對於事相與罪犯這兩方面，各自具備「明識」、「疑惑」、「不識」這三種心態，互相交錯交織編組成九句，如同圖表中所顯示的那樣。所謂「準則規範」，是指如果參透了這兩組九句，隨便面對任何一項事相或法規，都能無不貫通周延，所以《行事鈔》說「能夠類推貫通法界一切事」，指的就是這個道理。

【103-0017】02_戒疏/04c_卷一下之二#111
【原文】【記】止持，可學，標中。「有無」等者，「有」即疑及不識，「無」即是識，「輕」謂不學及疑，「重」即不識。立句之意，如作犯門，具明所以。
【譯文】【記文】在止持、可學的標示中。所謂「有無」等詞，「有罪」就是指心存疑惑與全然不識，「無罪」就是指明確明識；「輕罪」是指不學與疑惑所造成的突吉羅罪，「重罪」就是全然不識教法所造成的波逸提罪。建立這九句的意圖，正如作犯門中所詳細說明的原由一樣。

【103-0018】02_戒疏/04c_卷一下之二#112

【103-0019】02_戒疏/04c_卷一下之二#113

【103-0027】02_戒疏/04c_卷一下之二#121
【原文】【疏】中品事犯，句雖兼識，然於罪事，生疑不識。隨有迷處，皆結兩罪：一是不學，二是無知。四句單雙，罪則有八。猶自名為「中品持律」，以句帶識，非是全迷。
【譯文】【疏文】中品的事相與罪相，文句雖然都還帶有一部分明識，然而對於罪相或事相，卻產生了疑惑或全然不識。只要有迷惑之處，隨處都要判定結下兩種罪名：第一是不肯學習戒律的「不學罪」，第二是不懂戒相的「無知罪」。中品四句中，事相與罪相僅有一方迷誤（單），但每一迷處皆結不學與無知二罪（雙），所以合起來共有八個罪名。但仍舊勉強稱他們為「中品持律之人」，因為文句中還帶有一半的明識，並不是徹底的全盤迷惑。

【103-0028】02_戒疏/04c_卷一下之二#122

【103-0029】02_戒疏/04c_卷一下之二#123
【原文】【疏】下品四句，罪事俱迷，隨句有四，則十六罪。此則名為「下品持律」。然於末句最第九也：由涉疑故，是解家津；不識罪事，非智之甚，可不然也？
【譯文】【疏文】下品的四句，對於罪相與事相全盤陷入迷惑，隨著每一句都包含四重迷誤，總共構成十六個罪名。這就被稱為「下品持律之人」。然而在這最後一句、也就是全部的第九句中：由於前面各句還夾帶有疑惑的心態，疑惑往往是邁向明解開悟的渡口樞紐；但若對於罪相與事相徹底不識，這是極度缺乏智慧的表現，難道不是這樣嗎？

【103-0032】03_業疏/17b_卷三之六#164
【原文】四正明問難遮中，如前顯父母夫主，先問有無，有問聽不，無不須問。奴婢罪名，士女同諱；僧是知法，義須轉勢也。二根下病非女五也，世俗所諱，僧尼同恥，不問亦得，故僧祇中僧問遮法，除女隱處也，以彼此懷慚，失弘誘相耳
【譯文】第四、在正式詢問十三重難與諸遮法中：如同前面所說明關於父母與夫主，先問有無；若有，則問准許與否；若無，則不需發問。「奴隸婢女」乃是犯罪僕役之名，士紳女流皆同所忌諱；僧人既然深通戒法，在義理上必須變換措辭發問。雙根以下諸病，乃是非女五相，為世俗所忌諱，僧尼皆引以為羞恥，不予詢問也是可以的；所以《僧祇律》中僧人詢問遮法，排除了女子的隱處私密疾病，這是因為彼此心懷慚羞，便會失卻宏大化導誘進的莊嚴風貌。
