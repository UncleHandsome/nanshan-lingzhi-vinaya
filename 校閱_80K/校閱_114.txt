# 校閱材料　第114檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【114-0001】資持記/02f_上一下#5
【原文】正辨中，初科為二，初示體相。文標二事，二合在中。竝下，明是非。以人法及界，各局自分；事涉多種，非相不一，故云一緣等。且如受戒，遮難衣資發心陳乞；又如治舉，窮勘三根，作舉憶念；如是求之。別示，徵中。也合作耶。情事中，初科引文有二，初引人法者。彼因比丘犯二僧殘，二俱覆藏；
【譯文】在正式辨析（正辨）的段落中，第一個科判分為兩部分，首先提示體性與外相。經文中標示了兩種事，而兩者混合之事已包含在其中。下文「一同（竝）」等字，是在說明正確與錯誤。因為參與的人、儀軌以及結界，各自局限在自身的本分；然而所涉及的僧事類別繁多，非法的樣態也不盡相同，所以才說是「同一個因緣等」。暫且以受戒為例，包含了遮難、衣物資具、發起道心以及親自陳情祈請等項目；又比如舉治罪過，必須澈底勘查見、聞、疑三根，然後進行檢舉羯磨並令其憶念；應當像這樣去推求考察。在個別指示的徵問中，文句中的「也」字應當作「耶」字。在涉及有情之事的段落中，第一個科判引用的文獻有兩處，首先引用的是〈人法犍度〉的記載。那是因為某個比丘犯了兩種僧殘罪，兩者都加以隱瞞掩蓋；

【譯文】他只記起其中一種罪，記不起另一種罪；僧團卻為他做覆藏兩種罪的羯磨；對於記起的那項罪固然極好，但對於沒記起的那項就屬於非法；這件事遭到了深知戒法的客比丘呵斥，相關文句就如《行事鈔》所引用的那樣；經文又說：僧團應當為此做突吉羅罪的懺悔。從此以下，便顯露出非法的過失。接著引用〈瞻波犍度〉的文字。那裡記載優波離尊者向佛陀發問，此處引用其發問的言詞；佛陀回答說這是不合乎戒法的，所以下文說是「佛陀所判定」。從此以下，便正式判定其為非法。在總結旨趣（結意）的段落中分為兩部分，首先是總結前文並作標示。所謂「一件事」，就是指治罰之法。至於其餘受戒、懺悔等各類僧事，都可以比照這個準則。

【譯文】〈說戒犍度〉中記載：那時諸比丘聽聞佛陀允許諸比丘前往王舍城羅閱祇誦戒，各方的比丘聽聞後，奔波前來集會感到極度疲憊；比丘們便稟白佛陀，佛陀因而允許從今以後，可以隨各自所在之處結界等等。在確立教法中，最初兩句說明開許原由。「極度疲乏」總括了上述的兩種因緣。透過作法予以劃分間隔，這是展示結界的方法。在同界中共同尊奉遵行，這是說明戒律的制約。眾人共同遵從同一羯磨，就不會形成破壞和合的別眾。「功成」是指自己的修業不會廢止，「事遂」是指僧團的大眾僧事容易成就，這是彰顯結界的利益。最後一句做總結。

【114-0057】資持記/03a_上二#8
【原文】又翻上釋者。局結反上通集，作法反上自然，同界反上十方；功成事遂，反上二損。標列四章。前二明結時緣法，後二辨結已是非。標簡中。攝衣攝食所以列者，同界攝故。指本篇者，各從其類故。《注羯磨》云：衣界者，攝衣以屬人，令無離宿罪。食界者，攝食以障僧，令無宿煮罪。
【譯文】若從反面推求文句來解釋：局限結界，是反轉原先通行遠集的困頓；透過羯磨作法，是反轉原先隨處的自然界；處於同一界內，是反轉原先遍及十方的漫無界限；修功圓成、僧事順遂，則是反轉原先個人與大眾的兩種損害。此處標明並列出四章。前兩章說明結界時的因緣法則，後兩章辨析結界之後的是非得失。在「標名揀別」中，攝衣界與攝食界之所以並列提出，是因為它們都被大界所涵攝。文中指出應看本篇，是因為各法應歸入其所屬的門類。《注隨機羯磨》說：衣界，是將衣物攝屬在比丘身邊，使其不犯離衣宿罪；食界，是將食物儲存隔絕於僧團生活之外，使其不犯宿煮等罪。

【114-0058】資持記/03a_上二#9
【原文】僧界者，攝人以同處，令無別眾罪。此三分相，宗旨甚明。自然中，初明統通自然。即上剡浮一集，空即蘭若，有即聚落，水即水界，陸即道行；四種攝處，相無不盡。未分已前，通為一集。後下，明六相自然。即初開也。初三句敘緣開。隨境即上四處，分限即界量。人下，釋名。
【譯文】僧界，是將僧眾聚集在同一處所，使其不犯分黨別眾之罪。這三種界域的相貌，宗旨非常明確。在自然界中，首先說明統攝通達的自然界。也就是前面所說閻浮提內的大聚會，無人之處就是聚落外空處（阿蘭若），有人之處就是聚落，水域就是水界，陸地就是道路行進之處；這四種處所含攝所有空間，境界相狀無不周盡。尚未劃分之前，整體通為一個聚會處。「後」字以下，說明六種相貌的自然界，這就是第一次的開許。起初三句敘述隨因緣而開許。隨順境界就是指上述四種處所，劃定界限就是指界域的範圍。「人」字以下，解釋名稱。

【114-0059】資持記/03a_上二#10
【原文】不假造作，故曰任運。言界起者，但是隨身到處，即有界限，非謂有法生起也。約下，指量。可知。作法中二，初敘自然，上二句通標。設下，別釋有二，初四句明展縮有妨。教文定者，六相分齊也。用不可者，界限與處，不相稱故。捨非制者，不依六相，無教開故。下二句明不勝。
【譯文】不需要假借人工作法，所以稱為「任運」。所謂「界起」，只不過是隨著比丘身體所到之處，便自然具備界限，並不是說有實體的法生起。「約」字以下，指出其尺寸限度，意思很容易理解。在作法界中分為兩部分，首先敘述自然界，上文兩句是總括標示。「設」字以下，分別解釋有兩點，最初四句說明擴展或縮減自然界所產生的妨礙。教文有所限定，是指六相自然界的界限範圍。如果運用不可行，是因為所劃界限與處所不相稱。若捨棄教文則非佛制，是因為不依照六相，佛陀沒有教文開許的緣故。下文兩句說明自然界微弱而無法承擔大事。

【114-0060】資持記/03a_上二#11
【原文】羯磨法既尊特，常地莫行。如持祕呪，必結壇場。羯磨呪術，其類頗同。故下，次明作法界，初敘開結。此即第二開也。開已復開，故云曲順。楷式定者，開中制也。任下，顯益。上一句反上初患，下四句反上次患。問：至此凡幾開耶？答：初明統通，即本制也。〔律中令結說戒堂，猶是統通一界，即同本制。
【譯文】羯磨僧法既然極為尊貴殊勝，尋常土地不可直接施行。就像持誦祕密神咒，必定要築結壇場一樣。羯磨與神咒，其道理相當類似。因此在「故」字以下，接著說明作法界，起初敘述開許結界。這就是第二次的開許。已經開許之後又再次開許，所以稱為曲順人情。楷模法式固定下來，是指在開許中又制定了準則。「任」字以下，彰顯其效益。上一句反轉上述的第一個過患，下四句反轉上述的第二個過患。有人問：到這裡為止總共有幾次開許？回答：最初說明統攝通達的自然界，這就是根本的規制。〔律中命令結說戒堂，仍然屬於統攝通達的自然界，等同於根本規制。〕

【114-0061】資持記/03a_上二#12
【原文】次分六相，即初開也。復令局結，第二開也。又作法中，復有二開；數集結場，難事結小。若望法食二同，法同食別；二種大界，亦是第開。然莫非大界，故所不論。已上凡經四開，文中宛爾。古多妄解，故須辨示。問：六相自然，開秉羯磨否？答：此無明說，以義定之。
【譯文】其次劃分為六相自然界，這是第一次開許。接著又命令局部結界，這是第二次開許。又在作法界中，還有兩次開許：為了頻繁集會而開許結戒場，為了有危難之事而開許結小界。若就法同食同、法同食別這兩種大界而言，也是次一級的開許。然而它們無一不是屬於大界，所以在此不贅述討論。以上總共歷經了四次開許，在經文脈絡中歷歷分明。古代學者多有妄自曲解的，因此必須辨別指明。有人問：在六相自然界中，是否開許秉宣羯磨？回答：律文中沒有明確說明，但可以從法理推斷。
