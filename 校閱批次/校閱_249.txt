# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【249-0001】02_戒疏/12b_卷三上之三#65
【原文】【記】《四分》。「邊方」開五事，長衣「入手」方犯，謂少僧處，但未手捉，容待人故。「若見比丘」者，以開未捉本為待人，今既有人，即須說淨，不說即犯，故云「未須手捉」。
【譯文】【記文】《四分律》在提到「邊遠地區」開許五事時規定，長衣必須「到了手中」才開始算犯戒天數，這是因為僧人稀少的地方，只要還沒親手拿取，就還可以寬容等待同修前來。至於「如果看見有比丘在場」，那是因為先前開許未親手拿取不算犯，本來是為了等待其他比丘來作證說淨；現在既然眼前已經有比丘在，就應當立即作說淨，不說淨就立刻犯戒，所以說「不必非要親手拿取」。

【249-0002】02_戒疏/12b_卷三上之三#66
【原文】【疏】《了論》云：「有物眼至得、非身至得者，如人施衣、蘇至比丘前，目見不觸，作己意，不說淨，隨日算而取罪。二、有身至非眼，如暗中施者。三、二俱至得，可解。四、有非二至得入算者，如暗中施者。有即二至得不入算數：若不許受，雖見觸而擬施三寶者。」
【譯文】【疏文】《毗尼入道了論》說：「有些物品是眼睛看見就算得到，而非身體接觸才算得到，例如有人把衣料、酥油送到比丘面前，比丘眼睛看見而沒有用手觸摸，只要心中認定這是自己的東西，若不作說淨，就必須依照天數計算而判定有罪。第二種情形是身體接觸到而非眼睛看見，例如在黑暗中接受布施。第三種是眼睛看見與身體接觸二者同時俱備，文義很清楚。第四種是二者都沒有接觸到，卻依然計入天數而得罪的，如同在黑暗中意念受納。另外也有雖然兩者都接觸到了，卻不計入犯戒天數的情況：例如比丘原本就不答應接受，雖然眼睛看見了、身體也碰到了，但打算轉布施給三寶。」

【249-0003】資持記/14c_下二#25
【原文】次科五節，初明佛自執作。佛在阿羅毘國，見寺門楣損，乃自修之。僧下，明作具。僧坊下，迴易修治。次僧坊下，制上座自作以勵餘人。猶恐目恃，仍引迦葉為況。《多論》云：舍利弗經營祇桓精舍目連經營五百精舍，彼論問曰：諸弟子所作已辦，何故方復棲悽有所經營，作諸福業，答：一為報恩故，二為長養佛法故，三為滅凡劣眾生作小福業自貢高故，四為將來弟子折伏憍豪心故，五為發起將來眾生福業故。

【249-0004】01_行事鈔/10c_卷下之二#23
【原文】《僧祇》：比丘作房，欲自泥壁，五彩畫之，並得。唯除男女和合像，餘山林人馬，並得。《四分》：亦不得用。不應文繡裝挍，聽用餘雜色禽獸文者。阿難得別房，開受。若僧地中作私房，有客來應起；不起，還僧地。若營屋者，不得卒成，以不堅牢；若作大重閣堂，聽十二年經營；餘者隨大小量宜。若營事比丘作房成，莊嚴香熏，所須具足者，與房住，九十日一移，不得更受餘房。若有俗人能治破房者，白二與之。《五分》：諸房上，皆題某甲檀越房。《十誦》：若以房施僧，轉施尼者，是非法施、非法受、非法用；若施尼轉與僧，亦爾。若房舍臥具有檀越者，但得看視，不得奪一與一。治壞房者，六年與住；作新房者，十二年住。《僧祇》：先是僧房破壞，更易戶嚮，二三年隨功夫多少，羯磨與住。若空房不任住，治事者，應與一時住。若床几枕褥垢膩破，更染浣補治者，亦一時住。
【譯文】《僧祇律》說：比丘建造房舍，想自己塗抹牆壁並以五彩顏料彩繪，都是准許的。唯獨禁止繪製男女交合的圖樣，其餘山林、人物、車馬等畫像都可以畫。《四分律》則說：山林人馬等圖案也不得使用。房舍不應以刺繡雕琢繁複裝飾，只聽許使用其餘雜色的禽獸紋理。阿難尊者獲施主布施獨立專屬的僧房，佛陀開許接受。若在僧團公有土地中建造私人僧房，當有客比丘前來時應當起身讓房；若不肯讓出，該房屋收歸為僧團公產。如果營造房屋，不可急遽草率完工，以免不夠堅固牢實；若是建造多層的大重閣堂，聽許花費十二年的時間營建；其餘房舍則隨其規模大小酌情裁量修建工期。如果是負責營建的營事比丘將房屋建好，內外莊嚴、香氣熏染、生活所需器具一應俱全者，僧團應分給此房讓他居住，但每九十天（一夏）須輪換移居一次，不得再額外佔受其他僧房。如果有在家人能修繕破舊僧房，僧團應當作白二羯磨將該房給予其居住。《五分律》說：所有僧房的門額上，都應題寫「某某檀越所施之房」。《十誦律》說：如果有人將僧房布施給比丘僧，卻轉而改施給比丘尼僧，這便屬於非法布施、非法接受、非法使用；若布施給比丘尼僧又轉給比丘僧，也是如此。如果房舍及臥具有專屬施主認領供養者，僧團只能代為看照護持，不得強行奪此人之物而給予另一人。親自修繕破損舊房的人，僧團配給其居住六年；建造全新房屋的人，配給其居住十二年。《僧祇律》說：原先是損壞的僧房，重新修葺改換門窗朝向，依照花費工夫心力多少，以羯磨僧事法分給其居住二至三年。如果是荒廢無法居住的空房，動手修治好的人，應當分給其居住一季（一夏）。如果床几枕褥等沾染油垢或破爛，經過重新染色、洗滌、修補整理的人，也應分給其居住一季（一夏）。

【譯文】20 對施興治篇(下二)

【249-0007】資持記/14c_下二#27
【原文】九十日者，取一安居期故。若有下，明治故房。律中比丘自力不搆，俗人相兼；由同俗治，必須和眾，故制羯磨與之。《五分》：題名者，別標為記故。《十誦》，初明僧尼互施。非法施是比丘過，不合與尼故。非法受者，僧尼共有是過。非法用是尼過。或可非法受用並屬尼。若房下，誡主者自任。
【譯文】所說的九十日，是取一個安居期作為期限。「若有」以下，是說明修治舊房。律中比丘靠自己的力量不能成辦，須由俗人相助；由於要與俗人共同修治，必須僧眾和合，所以制定羯磨法來授予他。《五分律》所說的「題名」，是另外標示作為記號。《十誦律》首先說明僧尼互相布施：非法布施是比丘的過失，因為不應該把房舍給比丘尼；非法接受，是僧尼共有的過失；非法使用，是比丘尼的過失。或者可以說，非法接受與非法使用都屬於比丘尼的過失。「若房」以下，是告誡主事的人要自己擔負責任。

【249-0008】資持記/14c_下二#28
【原文】奪一與一，約人為言；此謂檀越既存，止可隨人看守；不可偏情將同己物，輒生與奪，護施心故。治下，明賞功。作新同前，修舊減半，功多少故。《僧祇》，初明治破房。隨工多少者，謂二年修治，得二年住，三年得三年住。若下，次治空房。謂非破壞，但闕受用者。若下，三明治受用。
【譯文】「奪一與一」是就人而說的；這是說施主既然還在，只可以隨著人來看管，不可偏私任情把它當作自己的東西，隨便加以奪取或給予，這是為了保護施主的布施之心。「治」以下，說明獎賞功勞。新建房屋與前面所說相同，修治舊房則減半，因為功勞有多少的緣故。《僧祇律》首先說明修治破房。所謂隨工多少，是說修治兩年，就可以住兩年；修三年，就可以住三年。「若」以下，其次說明修治空房，是說房屋並沒有破壞，只是缺少受用的人。「若」以下，第三說明修治受用之物。

【249-0009】02_戒疏/12b_卷三上之三#67
【原文】【記】《了論》，四句。初及第四竝心受，二即身受，三即兩兼。初句中，「蘇」字合作「酥」，即長藥也。「隨日算」者，「算」猶數也。第四云「暗中施」，暗中非眼見，又不手觸，但作意受也。「即二至不入筭」者，此即第四句相翻顯異也。「不許受」者，如暫寄等，或施三寶，竝非屬己故。
【譯文】【記文】《了論》提出了四種句型。第一句與第四句都純粹屬於心念認領，第二句是身體接觸受納，第三句則是兩者兼具。第一句裡的「蘇」字應當作「酥」，指的是可以儲存較久的藥用酥油。「按日算取罪」的「算」，就是計算天數的意思。第四句說「在黑暗中受施」，黑暗中眼睛既沒看見，手上也沒有碰到，純粹是心念認定領受。又有一種是眼與身二者俱到，卻不計入算數的情況，這是與第四句相反以顯明差別。「不答應接受」，比如只是暫時借放寄放，或者是打算直接布施給三寶，這些都不屬於個人私有物資的緣故。

【249-0010】02_戒疏/12b_卷三上之三#68
【原文】【疏】言「作非衣」者，昔云「如幡蓋等」。此是佛物，有何長過？有云「革屣鉢囊等」，此亦非也。如《律》文中「非衣者，不許餘用」。相傳云「帽袜之類」。又云「聽與尼非衣」，豈唯㡌袜邪？
【譯文】【疏文】註文所說的「製作成非衣」，古人解釋說「例如做成幡蓋等物」。可是幡蓋是屬於佛前的供奉之物，比丘私下能有什麼蓄存長衣的過失呢？又有人解釋說「做成鞋子、缽袋等物」，這也是不對的。如同《律》文中記載「屬於非衣的布料，不准挪作其他用途」。民間相傳說指的是「帽子、襪子之類」。律中又說「准許把非衣轉送給比丘尼」，如果真是這樣，難道非衣就只有帽子和襪子嗎？

【249-0011】02_戒疏/12b_卷三上之三#69
【原文】【記】二、非衣中。初出古解。「如」下，引文示。《律》云「時有將非衣作鉢囊、革屣囊，佛言『不應作』」，此即「不許餘用」也。文既不許將作囊器，應是首飾，故以「帽𧙕」釋之。「𧙕」音末。「又」下，《律》中「諸比丘畏慎，不敢與尼非衣，鉢囊等。佛言『聽與』」。據此文通，不專帽𧙕，則顯上解亦非所取。然文但斥非，而不顯正。《鈔》云：「今但通而述之，何妨彼此俱攝。」古記解云：「但非所著用，皆名非衣，則通彼此兩眾矣。」
【譯文】【記文】第二、在說明非衣之中。首先列出古人的解釋。從「如同」以下，引用律文加以糾正。《律》文記載「當時有人拿非衣布料做成缽袋、鞋袋，佛陀斥責說『不應該這樣做』」，這就是「不許挪作其他用途」的明證。經文既然不准做成袋囊類的器物，推測應該是用在頭上的穿戴飾品，所以古人才用「帽子、襪子」來作解釋。「袜」音同末。從「又」以下，《律》文中記載「比丘們謹小慎微，不敢把非衣以及缽袋等物送給比丘尼，佛陀說『准許送給她們』」。依照這段經文廣義來看，非衣的範圍很廣，絕不僅限於帽子和襪子，這就顯示出上面的狹隘解釋是不適當的。不過律文雖然駁斥了錯誤，卻沒有明確給出標準定義。《事鈔》說：「現在我們只作通貫的陳述，何妨把兩邊的解釋都涵蓋進去。」古來的註疏解釋說：「只要不是比丘法衣所穿戴受持的布料，通通都叫做非衣，這樣就能廣泛通達男女兩眾的日用品了。」

【249-0012】02_戒疏/12b_卷三上之三#70
【原文】【疏】言「親友意」者，謂非己物，故不犯也。
【譯文】【疏文】註文所說的「親友意」，是指心裡認為這並不是自己的東西，所以不算犯戒。

【249-0013】02_戒疏/12b_卷三上之三#71
【原文】【記】三、親友意，謂作與彼想也。
【譯文】【記文】第三、親友意，是指心中認定這是為對方代為保管的想法。

【249-0014】02_戒疏/12b_卷三上之三#72
【原文】【疏】言「忘去」者，謂忘財體及忘不加法，俱開十日。唯當律開忘。《僧祇》、《善見》都所不開。
【譯文】【疏文】註文所說的「遺忘了此事」，是指遺忘了有這筆財物本身，或者是遺忘了還沒有對它作說淨儀軌，這兩種情況都可以給予十天的寬限。只有我們本宗《四分律》對遺忘給予開許。《摩訶僧祇律》和《善見律論》全都不予開許。

【249-0015】02_戒疏/12b_卷三上之三#73
【原文】【記】四、忘去。初明二忘。「唯」下，簡部別。《十誦》同開，如後所列。
【譯文】【記文】第四、遺忘。首先說明兩種遺忘的情況。從「只有」以下，簡別部派之間的差別。《十誦律》同樣也給予開許，如同後面所列舉的一樣。
