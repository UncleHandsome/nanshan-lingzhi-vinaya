# 校閱材料　第663檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【663-0001】資持記/16c_下四#52
【原文】兩通者，犯相同僧，故犯通；上得治下，故舉通。別法中。一切同僧，故不出之。第五略指中。雖是下位，俱發塵沙，與僧無別，故竝指之。廣引中，初科。知慚愧，謂不作諸過。善住，謂住於善處。師法中，初總誡。當下，次別示。文示善惡，不出三業。無定亂言者，由亂言故，則無定也。
【譯文】之所以稱「兩者皆通」，是因為違犯戒律的相貌沙彌與大僧完全相同，所以違犯之法共通；大僧在上位有權舉發並懲治在下位的沙彌，所以舉罪懲處之法也共通。在個別特法之中，一切規範全與大僧無異，所以在此不再一一列舉。第五項簡略指引之中。沙彌雖然身處下位，但受戒時心性同樣能引發遍滿如塵沙法界的清淨戒體，在這點上與大僧毫無差別，所以在此一併予以指明。在廣泛引證之中，第一個小段落。「知慚知愧」，是指內心自律不再造作種種惡業過失。「善住」，是指身心安住在善美的正法境界之中。在對待師長侍奉的法則中，首先提出總體的告誡訓導。「當」字以下，接著逐條分別指示。經文中所昭示的善惡規範，總括來說不離身、口、意三業。所謂「沒有定力而胡亂言語」，就是因為平日言語散亂放蕩，所以內心無法生起深厚的定力。

【663-0002】資持記/16c_下四#53
【原文】淨不淨，或約為僧作淨，或據自知持犯。二中，《多論》唯明掘地開制。《五分》通示一切法制。《四分》略列犯相。餘可準知，故云例之。三中，初明語師。若治下，次示治相。若不下，三制奉給。不應下，四明同利。《四分》給房，當量可否。斥謬中。古謂下眾，犯同五八，不係篇聚。故有此通。剩，即多也。
【譯文】清淨與不淨，或是指替僧團準備符合戒規的清淨飲食物品，或是指自己內心明了持戒與犯戒的差別相貌。在第二項中，《薩婆多論》唯獨指出了掘地一事的開許與禁止規範。《五分律》則是通盤開示了一切戒法的禁止規定。《四分律》只是略微列出了違犯的相貌。其餘各條皆可依此類推而知，所以說「依照此例推衍」。在第三項中，首先說明應當如何向師長稟白報告。在「若治」字以下，接著說明如法懲戒治罰的具體相貌。在「若不」字以下，第三項規定沙彌應當如法承奉供給師僧服勞作使。在「不應」字以下，第四項說明如何公平共享僧團利益。《四分律》中分配僧房，應當詳細裁量其資格是否合適。在斥責荒謬觀點的段落中。古代學者誤以為下位三眾，其所違犯的過失只等同於在家的五戒、八戒，並不隸屬於出家法規的五篇七聚之中，因此才產生了這種似是而非的通融說法。「剩」就是多餘繁瑣的意思。

【663-0003】資持記/16c_下四#54
【原文】此下，正斥。人語，出於凡情；正教，出於聖意。故須準教，不可依人。29 釋尼眾篇(下四)釋尼眾篇題中，上二字，通收三位。別行，如前釋。注中。翻名，總云阿摩尼，此云母女。即佛呼姨母之稱，故云重尼也。敘意，初科；上三句，標廣。女流情著，行相倍增故。同下，示同別；
【譯文】在「此」字以下，正式予以嚴正斥責。世俗之人的言語，完全出自於凡夫的虛妄情執；如來的純正教法，才是徹底流露自聖者的圓滿聖意。因此行事必須嚴格遵循聖教規範，萬萬不可盲目聽信個人的私意妄談。第二十九篇，解釋〈尼眾篇〉（屬卷下之四）。在解釋〈尼眾篇〉的標題中，前面「尼眾」這兩個字，廣泛涵蓋了比丘尼、式叉摩那以及沙彌尼這三個法位。個別行持的法式，如同前文已經解釋過的一樣。在註解之中。翻譯名義時，梵語總體稱為「阿摩尼」，漢語翻譯為「母女」。這原本是佛陀呼喚親生姨母大愛道時的尊稱，所以將比丘尼的尊稱視為極其隆重的稱謂。在敘述本篇意旨的部分，第一個小段落；前面三句，標示出其戒相繁多廣大。因為女性的情執與貪著較重，所以防範過失的戒律行相相較於大僧倍增繁多。在「同」字以下，指出相同與相異之處；

【663-0004】資持記/16c_下四#55
【原文】初指同，即上諸篇；今下，正敘此篇；即披，是教有所準故；不浮漫，是行無所昧故。次科，初徵；以約類雖然，據位則亂故。次引論釋，言不便者，男女相配，涉譏疑故。大尼受戒中，初文；十二歲者，是師位故；僧則十歲，《業疏》云：所以加二歲者，顯其志弱，累年為德也；
【譯文】首先指出共通之處，指的就是前面已敘述過的各篇章；「今」字以下，正式展開陳述本篇的正旨；立即翻閱披讀，是因為言行舉止完全有聖教作為依準規範；不至於散漫浮泛，是為了讓修道行持時內心明朗不致迷茫昏昧。下一個小段落，首先提出詰問反思；因為若單純依照男女類別來劃分似乎可行，但若按照出家受戒的法位相較，隨意配列則會導致僧團體制尊卑混亂。接著引用論典來做解釋，文中所說的「不便」，是指若將男女法位直接互相配對，容易招致世人的譏嫌與猜疑。在比丘尼受具足戒的章節中，最初的文段；規定受戒必須滿「十二臘（十二年）」，是因為這已經是為人師表的長老資格；大僧比丘則只需要受戒滿十年即可，《業疏》中解釋說：之所以為比丘尼額外增加兩年的年限，是為了彰顯女性在道心上容易怯弱，必須累積更多的年資修持才能成就厚重德行；

【663-0005】資持記/16c_下四#56
【原文】又女人多樂畜眾，由本習也；年年度人，不能教授，多有違犯，故制乞法，令眾量之；不乞，受具犯墮；受人依止，度餘二眾，並制乞法，不乞皆吉；比丘通吉者，制乞同尼，但除式又；違犯一等，而無差降。其下，指乞法，文見《隨機羯磨》、及《尼鈔》。若下，示制限。受戒標中，非法濫相，如下正受斥古，是也。
【譯文】再者，女性多半習慣好樂蓄養大批徒眾，這是源於過去世養育照顧的宿習；如果每年都隨意度人出家，自己又沒有足夠能力訓誨教導，往往會導致弟子多有違犯，因此佛陀制定必須向尼僧團求乞聽許度人的法度，由全體僧眾審核裁量；若不求乞就擅自為人授具足戒，傳戒師要犯波逸提單墮罪；若收受他人作為依止弟子，或是剃度沙彌尼、式叉摩那其餘二眾，也全都制定必須向尼僧團求乞聽許，未事先求乞者一律結突吉羅輕罪；比丘違犯一律結突吉羅罪，是因為制度上乞法與尼眾相同，只是除去了式叉摩那；違犯的罪責一律相同，並無差別等降。在「其」字以下，指明如何舉行求乞法會，相關文辭詳見於《隨機羯磨》以及《比丘尼鈔》。在「若」字以下，指出受戒次數與名額的嚴格限制。在受戒的標題之中，提及種種不如法且混淆濫用的現象，正如後文正式受戒章節中斥責古德錯誤見解所說的那樣。

【663-0006】資持記/16c_下四#57
【原文】本法中，初示前緣；八法者，一請師，二安置立處，三差威儀師，四出眾問難，五單白召入，六對眾乞戒，七戒師白和，八對眾問難。文中，但示一四兩種，律文，請詞云：願阿姨為我作和尚等，故此釋之；十三難中，若據尼女，號佛無信，本無破僧，然有伴助，亦須問之；
【譯文】在比丘尼根本法受戒儀式中，首先指明先前的預備緣由；所謂的「八種法規」，第一是延請親教師，第二是安置受戒者站立的適當位置，第三是派遣端正威儀師，第四是領其步出大眾詢問遮難，第五是宣唱單白將其召入法堂，第六是令其面對尼僧大眾如法乞求戒法，第七是戒師宣唱和合白文，第八是正式面對尼僧大眾再次詳審詢問遮難。在正文中，只列舉了第一項請師與第四項出眾問難這兩種程序，律藏原文中，迎請的詞句說：「懇願阿姨慈悲為我擔任傳戒和尚」等，所以在此特別對此做出解釋；在十三種重難之中，若依照比丘尼身為女性的特質，即便自號為佛也無人信從，本來沒有能力作為首領破法輪僧，然而考慮到有可能在旁參與協助策劃，因此受戒時也必須嚴格詢問；

【663-0007】資持記/16c_下四#58
【原文】十六遮，於父母聽下，更問夫主；先問有無，無則不須。乃下，次明正受。餘下，指略；《隨機羯磨》甚備，須者尋對。正受中，初緣明是中，正教明制；必往僧中，《尼戒本》云：若比丘尼，與人授具足戒已〔即本法也。〕；經宿方往僧中，與受具足戒者，波逸提。《業疏》，問云：經宿失本法不？
【譯文】在十六種遮難之中，在「父母是否聽許出家」這項提問之下，還要更進一步詢問是否有「夫婿丈夫的允許」；程序上應當先詢問是否嫁人有丈夫，若未婚沒有丈夫則不須再問。在「乃」字以下，接著說明正式納受具足大戒的程序。在「餘」字以下，指明此處省略了其餘細節；因為《隨機羯磨》中記載得極為詳盡齊備，需要遵行實踐的人應當自行翻閱對照修持。在正式受戒的段落中，第一科說明來往是非之中，以聖教正文明示制令；受本法後必定要前往大僧僧團中，《比丘尼戒本》中明文說：如果比丘尼為弟子授完具足本法之後；竟然放置隔夜才帶往比丘僧團之中為其傳受具足戒者，傳戒尼師要犯波逸提單墮罪。《業疏》中提問道：如果放置隔了一夜，先前在尼僧中所受的本法戒體是否會失效退失呢？

【663-0008】資持記/16c_下四#59
【原文】答：不失法，由捨故，不由隔日；若當日不去，明日須捨故受新，方得。斥非中，二，初斥僧來尼寺。《師資傳》，明判；遣信明例，是非可見矣。次斥寺外結界，律無定決，不云成不，故以義通之；僧須得罪，尼應得戒。釋難中，初問；由制作本法已，方往僧中；恐違此教，故問決之。
【譯文】回答說：先前的本法並不會失效，戒法的退失是因為當事人主動捨戒，並不是單純因為時間隔了一天；但是如果受了本法當天不及時前往僧中，第二天就必須重新捨去前法、重新傳受新的本法，然後才能前往大僧處求戒。在斥責非法的段落中，分為兩個部分，首先是嚴厲斥責比丘僧親自前往尼寺傳戒的荒謬行徑。《師資傳》中有極為明斷的判定；律中開許派遣可信賴的代理人受戒已經有明確的範例，比丘親往尼寺是非對錯自然顯而易見。其次是斥責在寺院外任意結界傳戒的弊病，律典中對此沒有下死定論，並沒有直接言明這樣做到底算不算結界成功，所以我們在此純粹從法理上予以融通剖析；比丘這樣做必定要獲結違制之罪，但比丘尼在法理上應該還是能如願得到具足戒體。在解釋各方難題中，首先提出疑問；因為律制規定必須先在尼僧中圓滿本法之後，然後才能前往比丘僧團中求戒；大家擔心違背這項聖教訓示，所以特別提出問題請求裁決明斷。

【原文】由加本法，名同上位；以於三眾，無所收故。第二斥非中，初引古。若下，今斥，初引當宗。律本，即〈尼犍度〉。乃至文云者，即說相中文。次引他部。《僧祇》，八種受具，僧受名十眾，尼受名二十眾；名數既顯，可驗昔非。次科，《五分》人數，事儀委悉，宜應準行；小遠者，若在露處，亦須尋內。

【663-0011】資持記/16c_下四#62
【原文】第三斥非中，初標古。然下，正斥，初以理直破。一法，謂尼受白四，本制同秉，一眾不成；結界，本為攝人秉法，尼既同秉；無界則集人無準，法起無依，故云非界等。若下，次約法皮質。次科。自然集者，僧作法界，尼望為自然故；唱相結者，一依僧界。《五百問》中，不得相又，以法故。
【譯文】在第三個斥責非法的段落中，首先標示出古德的錯誤觀點。在「然」字以下，正式展開嚴正駁斥，首先從純粹的法理上給予直接破斥。所謂「同秉一法」，是指比丘尼求受具足戒的白四羯磨，根本律制規定必須由大僧與尼僧共同合力主持秉宣，單憑其中任何一個僧眾大眾都是無法單獨成就法事的；結界的根本目的，原本就是為了收攝同一區域內的清淨僧眾共同如法主持僧事，比丘尼既然要與大僧共同宣秉大戒；如果沒有合法嚴謹的結界，那麼召集僧眾的人數便無從依循標準，神聖的戒法生起也將欠缺堅實的依憑，所以說「若非如法結界則法事不立」等等。在「若」字以下，接著從法事的實質內涵層面展開深層的剖析與質疑。下一個小科判。所謂「在自然界中集會」，是指大僧所正式作法結成的大界，在比丘尼看來就等同於順應天然的自然界一般；而「宣唱界相以正式結界」，則必須完全依循比丘大僧所劃定的結界界線。《五百問》中說，二眾結界的界相不得相互交叉錯雜，因為僧尼是為成就同一受戒之法的緣故。
