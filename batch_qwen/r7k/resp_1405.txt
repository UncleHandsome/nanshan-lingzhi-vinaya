整體看，這五則譯文的骨架都對，科判語（「上出答相」「謂下遮濫」「結指」「初示位」）處理得也中規中矩。問題主要出在**術語判讀**與**前后一致性**上，其中有一處是硬傷。以下按輕重分列。

---

## 一、必須改的（硬傷）

### 1. 【1405-0002】「心中默念的心念法」——與 #48 自相矛盾

【1405-0005】原文明說：

> 「恐有迷名，**不加口說**；引證明委，成否可知……據論作業，非三不成。」

元照正是怕人望文生義，以為「心念」就是不出聲。譯文卻在 #45 直接把心念法釋為「心中默念」，等於替元照所破的誤解背書。

**建議**：「對首法（面對他人作法）與心念法（獨自秉法，仍須口說）」，或乾脆保留「心念法」不加註解。

### 2. 【1405-0003】「彼文（《隨機羯磨》）」——書名疑誤

這一段自「疏云：今解竝須具之」以下，一路是引《羯磨疏》，「又云對首心念……又如眾法心念……」都還在引文內，收尾「**此且略引，廣在彼文**」是就所引之疏而言（略引 ↔ 廣在彼文），故「彼文」應指 **《羯磨疏》（《四分律刪補隨機羯磨疏》）**。

下一則「下指別法，應是《隨機羯磨》」是另起，講鈔文下文的「別法」，兩者不宜混為一談。建議改為《羯磨疏》，或暫去掉書名括注。

### 3. 【1405-0001】引文用字：「授戒羯磨」應作「受戒羯磨」

「總云受戒羯磨」是**答辭原文**，屬引用羯磨語句，不宜改字。前文既譯「傳授具足戒」，此處引號內更應保持「受戒羯磨」。

### 4. 【1405-0003】「五、前對相可」譯「對面的同伴行相合格」——疑誤讀

十緣中第五位相當於眾法的「告眾情和」，「相可」是**彼此許可、情和無違**，不是「行相／合格」（那是第六「癡鈍非數」簡眾是非的事）。

**建議**：「五、現前所對之人彼此情和相可（無異議）」。

### 5. 【1405-0003】「六、自量是非」譯「自我衡量作法是非」——疑誤

說戒前的「自量是非」，是**自審己身有無過犯、清淨與否**（是＝淨，非＝犯），不是衡量「作法」對錯。譯文加了「作法」二字，方向偏了。

**建議**：「六、自己省量有無過犯（清淨與否）」。

### 6. 【1405-0004】「且如法中」的「法」——不是一般的「法度」

此處承上「法、事、人、處」四位而言，「法中」＝**四位中的「法」這一位**，故下云「餘三亦爾」（事、人、處）。譯成「就像在法度之中」，讀者會誤以為泛指律法。

**建議**：「就以『法』這一位來說，三種、八種若錯互混用，作法便不成就；其餘事、人、處三位也是一樣。」

## 二、語意含糊、宜斟酌的

| 出處 | 譯文 | 問題與建議 |
|---|---|---|
| #45 | 「結界無欲，立緣顯之」→「但需設立事緣來彰顯它」 | 「它」指代不明。原意是：**雖無欲可受，仍須立此第七緣，以顯示「結界不受欲」之義**（這才扣得住「今解竝須具之」）。 |
| #45 | 「不宣告四至界相」 | 結淨地的「唱相」是**唱房名**（下文律文即證），「四至」是結大界唱四方相，此處添「四至」反生誤導。逕作「不唱（宣告）相」即可。 |
| #45 | 「故云等也」→「所以說是『等』」 | 宜作「所以鈔文用『等』字含攝（此類情形）」。 |
| #45 | 「五大上色，義加不成」→「這是律疏依義理追加的規定，若違犯則法不成就」 | 「義加」是**依義理判立**（相對於律文正制），非「追加規定」；且非法衣是「作法不成」，不是「違犯」。建議：「五大正色與上色之衣不如法，依義理判為受持不成。」 |
| #46 | 「二、事通兩界」 | 「兩界」宜注：**自然界與作法界**。 |
| #46 | 「七、取欲非法」→「受取欲法不合律規」 | 讀來像「受欲的方法不如法」。原意是**此法不得受欲，取欲即成非法**（與說戒心念「獨集非欲」同位）。 |
| #46 | 「八、執衣言議」→「陳述商議」 | 「言議」是陳說、告白，非「商議（討論）」。建議「手執其衣，口陳受持之辭」。 |
| #46 | 「十、答問可者」→「回答詢問如法合宜」 | 「可」很可能是答辭「**可爾**」，非泛言「合宜」。此條建議對照《羯磨疏》原文再定。 |
| #46 | 「九、激動說緣」→「激發策動宣說事緣」 | 幾乎等於未譯。此位相當於眾法的「勅眾審聽／前方便」，宜作「發起（策動）說戒的因緣」，並待查疏文。 |
| #46 | 「又如眾法心念」→「大眾法的心念法」 | 「眾法心念」是專名：**本屬僧眾之法，因界內無人而開許獨自秉作**。建議補一句說明，否則與 #47「眾法對首，兼開法也」對不上。 |
| #47 | 「三種八種」 | 未注。一般解：三種＝單白、白二、白四；八種＝眾法三＋對首二＋心念三。宜補括注。 |
| #47 | 「事微小者，即本位也」 | 「本位」宜點明即「**但心念**」；下文「眾法對首」＝眾法心念、對首心念（譯文理解正確，但可直接用專名，更清楚）。 |
| #47 | 「隨一一中」→「在隨順每一項當中」 | 「隨順」是贅字，「隨一一中」即「每一項之中」。 |
| #47 / #45 | 「階位」 | 「位」指法事人處四類位、心念三位，非高低階級，用「位（類別）」較穩。 |
| #44 | 「羯磨是法」→「『羯磨』是指法度」 | 此處「法」是**作法的通名**（答辭「某羯磨」中，某＝別事，羯磨＝作法通稱），「法度」偏儒家式用語，易生歧義。 |
| #44 | 「作特殊的揀別」 | 「揀別」即簡別區分，建議「加以簡別（分出特殊情形）」。 |
| #48 | 「常爾一心」→「常使自心保持在一種正念之中」 | 這是律中成句（「常爾一心，念除諸蓋」），宜保留原語再略釋為「恆常攝心一處」，並點出此處是在分辨「心念」一詞所攝的多種情形（作法性心念 vs. 策勵性攝心）。 |

## 三、跨則一致性

1. **「疏」的指稱要統一**：#45 兩處譯「律疏」，#46 卻注《隨機羯磨》。全段應統一為《羯磨疏》；《隨機羯磨》是羯磨本，與疏有別，#47 元照自己也在推測「別法」所指，兩者不可混。
2. **「心念」的定義**：#45 的「默念」必須與 #48 的口說要求對齊（見上）。
3. **「法」的譯法**：#44「法度」、#46「羯磨」、#47「法度」混用。建議統一：專名保留「羯磨／作法」，四位之「法」則明標為「『法』位」。

## 四、小結

- 真正需要動刀的是 **#45「心中默念」、#46「彼文」書名、#46「前對相可」「自量是非」、#47「且如法中」** 五處；
- #44「授戒」改「受戒」是校字問題；
- 其餘多屬術語未注或語意含糊，補括注即可。

另：十緣的名目（尤其「答問可者」「激動說緣」「義加不成」）建議直接核對《羯磨疏》暨《濟緣記》原文再定譯，這幾條單憑資持記的略引，容易各說各話。
