# 校閱材料　第1343檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】「迴食」是指食物在口腔內翻轉咀嚼。《增壹阿含經》勸勉世俗信徒為僧眾行食派飯。君王或大臣親自操辦供養事務，是古印度的通例儀節。在中土此地，梁武帝也曾親自為僧眾分發食物。像這樣放下尊貴地位、崇奉正法的舉止，古往今來極為罕見。至於其餘凡夫平民，實在不值得以此自高自大。第四段中，《四分律》說明受供之人的平等（人等）。所謂「二部」，就是指僧、尼二眾，也就是五眾弟子都能蒙受供養。先行僧眾後行尼眾，是依據時間尚早（離日中尚早）而言。接著引用經文勸勉飲食平等（食等）。該經全名為《梵摩難國王經》，譯者姓名已經亡佚。

【1343-0005】資持記/15d_下三#16
【原文】達嚫大嚫，梵言少異，亦云檀嚫。此翻財施，謂報施之法，名曰達嚫。文約施衣，準應不局。〔世謂以財𭣋食，故名嚫者，不識華梵。又召說法為施財者，並非。〕問：為召施物，為目說法？答：據名召物。今謂行施之時，必為說法，因名說法，以為達嚫。準理具云達嚫說法，事義方全。
【譯文】「達嚫」或「大嚫」，梵語音譯略有差異，也稱為「檀嚫」。此詞翻譯為「財施」，指酬報施恩的法式稱為達嚫。律文雖然是就布施衣物而言，但準照法理，其適用範圍並不局限於衣物。（世俗以為是用財物來貼補襯附飲食，所以稱作「嚫」，這是分不清華語與梵語的謬誤。又有把出家人的說法稱為布施財物，這同樣是不對的。）有人問：這個詞究竟是稱呼布施的物品，還是指稱說法？回答：單就名詞本身而言是指布施的物品。但我們現在認為行施的時刻，必定伴隨著說法，因而順帶將說法稱作達嚫。準照法理而言，應當完整稱為「達嚫說法」，這樣事相與理義才算齊備。

【1343-0006】資持記/15d_下三#17
【原文】問：此與呪願何別？答：約事似同，究義須別。呪願則別陳所為，達嚫則通為說法；今或營齋，事須雙用。次科，初引緣起。一令生疑，二令起謗。檀越，亦云檀那，並訛略也；義淨三藏云：具云陀那鉢底，此翻施主。佛下，次引佛制。注文指上，即若為利故施等偈。
【譯文】有人問：這與「祝願」有何差別？回答：就外在事相來看似乎相同，但窮究其內在涵義則必須加以區分。祝願是個別陳述所祈求的功德方向，達嚫則是通貫普遍地為眾人說法；現在若是營辦齋會，兩者必須兼併運用。下一科首先引用制戒的緣起。一是為了避免信眾心生懷疑，二是避免招惹世人毀謗。「檀越」也稱為「檀那」，都是梵文的音訛或省稱；義淨三藏說：完整的梵文是「陀那缽底」，中文翻譯為「施主」。「佛下」接著引用佛陀的制約。注文指涉上文，就是指「若為利故施」等偈頌。

【1343-0007】資持記/15d_下三#18
【原文】說時餘聽去者，有緣須往，無緣應住。三中。四益，前二利己，後二利他。四中。契經修多羅，華梵各出。種種義者，令隨機而舉。開撮文者，不必盡誦也。五中，《五分》簡德，初引緣。破戒無行，邪見無慧，根不具無威儀。惡人得勢，謂假此興謗。佛下，立制。
【譯文】說法的時候開許其餘僧眾先行離去，是指有要事者必須前往，若無要事則應留下來聽法。第三段內容中提到四種益處，前兩種利益自己，後兩種利益他人。第四段中，「契經」與「修多羅」，是中文與梵文的並列對稱。「種種義」是指讓說法者能夠隨應聽眾根機而靈活開示。開許「撮要而講」，是指不必將經文從頭到尾完全背誦完畢。第五段中，《五分律》甄別說法者的德行，首先引用緣起。破戒者缺乏德行，邪見者缺乏智慧，諸根殘缺者缺乏威儀。所謂「惡人得勢」，是指惡人會藉此挑起譏嫌與毀謗。「佛下」確立制度規範。

【1343-0008】資持記/15d_下三#19
【原文】《伽論》選能。文明誦唄，例準說法，必取堪能。六中，初標律偈。《增一》下，引解。初句即身口二業，次句心業，三是正慧，四即正信。七中，初斥世。若下，次勸說。準《五分》者，即呪願中引云四足汝安隱等。華侈，謂綺飾之詞；侈，尺紙反，奢也。十中。八人即留兩眾，餘開前去，同上有緣。
【譯文】《薩婆多部毘尼摩得勒伽》要求選拔有才能的人。律文表面上雖指誦經唱唄，依此類推到登座說法，也必定要選取具有相應能力的人才。第六段中，首先標出律藏中的偈頌。「《增一》下」引用經義進行解釋。第一句對應身、口二業，第二句對應意業，第三句是指正智慧，第四句就是指堅固的正信。第七段中，首先斥責世俗的弊病。「若下」接著勸勉應當如法說法。準照《五分律》的意旨，就是在祝願中引用「四足汝安隱」等語句。「華侈」是指浮華綺靡的修飾言詞；「侈」的讀音是「尺紙反」，意思是奢侈誇大。第十段中，「八人」是指留下僧、尼兩眾各四人，其餘僧眾則開許先行離去，這與前面有要事離去的情況相同。
