# 校閱材料　第1192檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1192-0001】資持記/10a_中三下#52
【原文】蠅停鳥啄，不名失受，故得食之。三中，《善見》。總列四趣，鬼收修獄，則為六趣。《五分》下三律。別舉三趣，合上論文。《僧祇》即佛受獼猴蜜。《十誦》目連尊者億耳沙彌皆受彼食，則餘重獄，義無從受。準下，總決。即前《了論》意也。四中，《十誦》。五塵不受，在文少漫，如注通之。《善見》，初明塵落。
【譯文】蒼蠅停落、鳥雀啄食，不稱為失去受食的資格，所以可以食用。第三部分中，《善見律》。總括列出四趣，餓鬼收錄阿修羅與地獄，那就是六趣。《五分律》等以下三部律。分別舉出三趣，契合上面的論文。《僧祇律》就是佛陀接受獼猴獻蜜。《十誦律》中目犍連尊者、億耳沙彌都接受過他們的食物，至於其餘嚴重的地獄眾生，在義理上是無從接受食物的。從「準」以下，作總結決斷。就是前面《了論》的意思。第四部分中，《十誦律》。五種塵埃不需要重新受食，在文字上稍顯含糊，如同注文中所疏通的那樣。《善見律》首先說明塵埃飄落。

【1192-0002】資持記/10a_中三下#53
【原文】可決《十誦》。注中兩意，和會律論。嚮明，謂窓隙飛塵，細中復細者，則不須受。行下，次明食墮。亦約作意故成。《僧祇》，初簡諸塵。言作意者，塵飛入時，須起受意。乃下，明諸食，初明逆落成不。僧下，明不淨成受。僧尼宿觸，互望為淨。二中，《善見》。四物不受，非可愛故。《了論》。
【譯文】可以用來決斷《十誦律》。注文中的兩種含意，調和會通了律和論。所謂迎向明光，是指門窗縫隙中的飛塵，是細微中更細微的，那就不需要重新受食。從「行」以下，其次說明食物掉落。也是依據有所作意所以成立。《僧祇律》首先甄別各類塵埃。所說「作意」，是飛塵進入時，必須生起接受的心意。從「乃」以下，說明各類食物，首先說明反向掉落是否成立受食。從「僧」以下，說明不潔淨是否成立受食。僧尼兩眾的隔夜宿觸，彼此相較視為清淨。第二部分中，《善見律》。四種物品不需要受取，因為不是可喜愛的東西。《了論》。

【1192-0003】資持記/10a_中三下#54
【原文】五量攝一切物，如〈四藥〉備引。便利水土，並名大開量；謂得自取，無所遮故。律文令受，與論不同，故約有人通之。據上二論，有人亦開。三中，《十誦》，初開不受。擔行不使人見，食須下道，皆謂避譏嫌故。搦，寧尼反，謂手一握也。又下，次制易淨。二文相違，故注以會之。《僧祇》、《多論》。
【譯文】五種量度涵蓋一切物品，如同〈四藥〉中詳細引用。大小便、水、泥土，都稱為極大開許之量；也就是可以自己拿取，毫無遮止障礙。律文要求接受，與論典不同，所以依據有人在場來疏通會通。依據上述兩部論典，即使有人在場也是開許的。第三部分中，《十誦律》首先開許不必受取。挑擔走而不讓人看見，吃的時候必須走下道路，都是為了避免譏評嫌疑的緣故。「搦」字音為寧尼反，指手握一把。從「又」以下，其次是制定轉手使之潔淨。兩段文字相違背，所以作注來調和會通。《僧祇律》、《多論》。

【1192-0004】資持記/10a_中三下#55
【原文】文如前引。亦下，決通開意。《四分》，儉時開八事，內宿、內煮、自煮、惡觸、僧俗二食、水陸兩果、不作餘食法。《五百問》中。七日一受，自作不失。先淨米取，文脫；彼具云先淨米受取〔謂火淨已受也〕。四中。水本大開，且約清者；今論鹹濁，亦須受之。
【譯文】文字如同前面所引用的。從「亦」以下，決斷會通開許的深意。《四分律》在饑荒時開許八件事：內宿、內煮、自煮、惡觸、僧食俗食互換、水生陸生兩種果、不作餘食法。《五百問》中。七天受取一次，自己作法不算失去受持。先對米作淨（火淨）再拿取（受取），文字脫落；該書完整文字為「先淨米受取」〔是指用火淨過後接受〕。第四部分中。水原本是極大開許之物，暫且是就清澈的水而言；現在論及鹹水、濁水，也必須受取。

【1192-0005】資持記/10a_中三下#56
【原文】《僧祇》、《伽論》約色，《五分》據味。五中。流汗有同鹹水，故亦須受。注中，上句決上臂汗，下句例成額汗。六中，《僧祇》。楊枝分咽不咽，氷雪約人有無。《四分》。楊枝不分兩用，故令準上。明轉變中。下列諸物，雖有變動，不易本質，故皆不失受。
【譯文】《僧祇律》、《薩婆多論》是就顏色而論，《五分律》是依據味道而論。第五部分中。流下的汗水等同於鹹水，所以也必須受取。注文中，上一句決斷了上面所說手臂上的汗，下一句依此類推額頭上的汗。第六部分中，《僧祇律》。楊枝分為吞嚥與不吞嚥兩種情況，冰雪依據身邊有沒有人來決定。《四分律》中。楊枝不分這兩種用途，所以令其依照上面處理。在說明性質轉變中。下列各類物品，雖然形態發生變動，但沒有改變原本的質地，所以都沒有失去受持。

【1192-0006】資持記/10a_中三下#57
【原文】《善見》生薑生牙，但須重淨。《僧祇》。注文，即指律中阿難為佛溫飯之緣。酪酥等者，謂中前受酪蔗麻，欲中後作酥蜜油，須加記識法云：此中淨物生，我當作七日藥受。〔非時亦同。〕過中變造，俱不失受。五十。空中不成，謂能受在空；若論所對在空，亦應不成；故知能所俱須在地。
【譯文】《善見律》中生薑發芽，只需要重新作火淨。《僧祇律》。注文就是指律文中阿難為佛熱飯的緣起。酪和酥等，是指在正午前接受了酪、甘蔗、胡麻，想在正午後做成酥、蜜、油，必須加上標記作法說：「這些乾淨物品產生時，我要當作七日藥來受取。」〔非時藥也是如此。〕過午之後轉變製造，都不會失去受持。第五受處中。在空中不能成立受食，是指能接受的人在空中；如果要論所面對的人在空中，也應當不能成立；由此可知接受者和給予者都必須在地上。

【1192-0007】資持記/10a_中三下#58
【原文】如前即指第二門。六受法中，初科。《了論》三位可解。今時就盤取食，準至物邊，理應成受。二身心中四句，初句。非心成受者，雖非專緣食境，必須心境分明。一向無心，則不成受。第二句，初示相。毘尼下，引緣。彼因毘舍離穀貴，神足比丘往外國乞；彼嫌比丘等，如鈔所引。若下，顯異。
【譯文】如同前面就是指第二門。在六種受食法則中，第一個段落。《了論》的三個位置容易理解。現在來到盤子前取用食物，依照到達物品邊上的說法，在義理上應當成立受食。第二是身體與心靈的四句分別，第一句。不是用心而成立受食，是指雖然不是專心注視食物之境，但必須心靈與外境分明。如果一味無心，就不能成立受食。第二句，首先指出相狀。從「毘尼」以下，引用緣起。那是因為毘舍離城糧食昂貴，有神通的比丘到外國去乞食；外國人嫌棄比丘等等，如同《行事鈔》所引用的。從「若」以下，顯明不同。

【1192-0008】資持記/10a_中三下#59
【原文】口加如後。第三。平等，謂正意仰手而受。上明如法。若下，簡非法。身心雖等，違法不成。第四。先有方便，故開後成。關即涉也。三單心者。即前第二句。前對身心歷句，此中獨約心論。《僧祇》中，初引邪見緣。彼因登瞿國是邊地邪見；嫌比丘故，不親授食。當下應有作字。
【譯文】口中附加作法如同後文所說。第三句。平等，是指心存正念、仰手接受。上面說明合乎戒法。從「若」以下，甄別不合戒法。身體與心靈雖然齊等，但違背戒法則不能成立。第四句。因為先前有了方便作法，所以開許後來成立。「關」就是牽涉。第三種是純粹用心。就是前面的第二句。前面是把身體與心靈結合起來逐句列出，這裡唯獨就心靈來論斷。《僧祇律》中，首先引用邪見的因緣。那是由於登瞿國是邊地邪見之處；嫌棄比丘的緣故，不肯親手遞送食物。「當」字下面應當有一個「作」字。

【1192-0009】資持記/10a_中三下#60
【原文】滿茶邏，此云壇規圓也。口云三受，以替手法。前下，指實器緣。畜寶所引，亦《僧祇》文。彼因施主作金椀盛食；比丘以手示器，口加三受等。明下，指略。即彼二部，皆開口受。又中邊不相解語，亦同開之。《五分》。施主送食，未及授與，急緣置地，應加口法。《僧祇》。禪眠，彼云覺者成受；
【譯文】滿茶邏，這裡翻譯為壇場，取其規律圓整。口中說三次「接受」，用來替代手的動作。從「前」以下，指向以實體器皿受取的因緣。在蓄積寶物處所引用的，也是《僧祇律》的文字。那是因為施主造了金碗盛裝食物；比丘用手指給他看器具，口中附加三次「接受」等等。從「明」以下，指出簡略作法。就是指那兩部律，都開許口頭受食。另外中原與邊地言語不通，也同樣開許口受。《五分律》。施主送來食物，還沒來得及授予，因為緊急因緣放在地上，應當附加口頭法事。《僧祇律》。坐禪昏睡，該律說醒著的人算受食成功；
