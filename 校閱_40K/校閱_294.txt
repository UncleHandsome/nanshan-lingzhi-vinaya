# 校閱材料　第294檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【294-0001】資持記/11c_中四上#7
【原文】亦制犯者，即殺戒第三句結偷蘭也。答中云結心犯者，前心方便也；非罪境者，始終迷心也。故《戒疏》云：然彼迷心，竝不結犯；皆約前心方便為言。〔疏文〕且存兩釋，學者思而擇之。對簡中。以前九句，疑及不識，本是愚教，皆可學迷。言同義別，故持簡之，使無相濫。法事者，法即是犯。
【譯文】而又制定為犯戒的，就是殺生戒中第三句結算為偷蘭遮罪。解答中所說結算心犯，是指前念之心的方便罪；所謂不是犯罪的境界，是指始終處於迷惘的心境。因此《戒疏》說：然而那種迷妄的心念，全都不結算犯戒；這全都是就前念之心的方便罪而言的。（以上為疏文）姑且保留這兩種解釋，學習的人應當審慎思考並加以抉擇。在比對揀擇中，因為前九句所說的疑惑與不認識，本質上是對教法的愚昧，都屬於可以學習而致迷惘的範圍。說法雖然相同而義理有別，所以特地持以揀擇，使它們不會互相混淆。所謂法事，「法」指的就是違犯。

【294-0002】資持記/11c_中四上#8
【原文】次引難。有二意：一為古師，於作持門中，不通不可學；今欲準事例法，竝通二九故。二為至後作持，不復重出；欲明句法，開結理齊故。文云若爾者，牒前緣罪有無義也。二房處分，望初篇殺盜，故云後也。殺盜制止事，處分聽作法，故云緣法也。
【譯文】其次引用問難。這裡有兩層用意：一是因為古師在作持門中，不能通達「不可學」的概念；現在想要依照事件來比照法則，讓兩者都能貫通兩種九句。二是因為到了後面的作持門，就不再重複列出；想要說明句式法則中，開許與結罪的道理是齊平一致的。文中說「如果是這樣的話」，是承接前面緣罪之有無的義理。第二篇房舍與處分的戒條，相對於初篇的殺生與偷盜，所以稱為「後」。殺生偷盜是制止作惡的事，處分則是聽許修作的如法僧事，所以稱為「緣法」。

【294-0003】資持記/11c_中四上#9
【原文】處分五句境想，文引二三兩句。不犯重者，即開想轉，不至殘也。言亦是者，比前不結正也。制罪者，二句皆結蘭也。何為二字，正是立難。意謂，若云殺緣罪境，故有；犯盜非罪境，故無犯者；處分緣法，亦非罪境，理應無過，何為結蘭？是則緣法不開迷耶。答中，有二，初示此門。言且據者，未暇兼明也。
【譯文】處分的五句境想中，經文引用了第二和第三兩句。所謂不犯重罪，是指開許了想念轉移的情況，罪責不至於達到僧殘。所謂「亦是」，是比照前面不結算根本正罪的情況。所謂制定罪責，是指這兩句全都結算為偷蘭遮罪。「何為」這兩個字，正是立論問難的核心。意思是說，如果認為殺生是攀緣犯罪境界，所以有罪；犯偷盜時由於並非犯罪境界，所以判定無罪；那麼處分是攀緣教法，也並非犯罪境界，理應沒有過失，為何要結算為偷蘭遮罪呢？這難道是說緣法的情況下就不開許迷妄了嗎？解答中有兩點，首先顯示此門。所謂「姑且根據」，是指還無暇兼顧闡明他處。

【294-0004】資持記/11c_中四上#10
【原文】必下，指後門。如所引者，承前難意也。對法有二九者，此顯作持通不可學，與古不同；既立迷忘，比今止門，開結無異。是則律制偷蘭，亦為前心方便；至於迷想，俱無有過。〔以人妄解，故特委釋；或引《戒疏》問答相比者，而不知彼此難勢自別；致使尋求，無由可曉。〕作犯，標中。
【譯文】在「必下」這段，是指向後面的門類。所謂「如所引用的」，是承接前面的問難之意。相對於法而有兩種九句，這是顯示作持門也能通達「不可學」，與古師的主張不同；既然確立了迷惘遺忘的界線，比照現在的止持門，其開許與結罪並沒有不同。如此則律文所制定的偷蘭遮罪，也是針對前念之心的方便罪；至於後續的迷妄想念，全都算作沒有過失。（因為有人胡亂解釋，所以特地詳細剖析；有人引用《戒疏》的問答來相比擬，卻不知彼此問難的形勢各自不同；導致後人探尋時，根本無從通達明了。）在「作犯」的標題中。

【294-0005】資持記/11c_中四上#11
【原文】準前名體，持犯各明；此論句法，持犯間列者；欲顯句法同流，相翻易曉。同異中，初指同；但下，示異。初中。標云法事者，文多法字。今以二意，定其傳誤；一檢鈔前後，止持作犯，竝不言法；《戒疏》方立，未可預標。二比前止持，亦單標事；兩門體一，豈得相違！用此以求，故須制去。〔或可準前目於犯法，舊作惡法解者，非。
【譯文】依照前面名稱與本體的規定，持戒與犯戒本該各自闡明；這裡討論句法時，持戒與犯戒卻穿插排列；是想要顯示句法的流類相通，互相對照翻轉就容易明了。在同異之中，首先指出相同之處；從「但下」開始，顯示相異之處。首先在第一部分，標題寫「法事」的，文字上多了一個「法」字。現在從兩點用意，判定它是傳抄的錯誤：一是查檢行事鈔的前後文，止持與作犯全都不稱「法」；直到《戒疏》才建立這個說法，不應在此預先標出。二是比照前面的止持門，也是單單標示為「事」；這兩門的本體既然一致，豈能彼此相違！用這個標準來推求，所以必須刪除該字。（或者也可以比照前面用來指稱違犯之法，舊解解釋為惡法的，是錯誤的。

【294-0008】資持記/11c_中四上#14
【原文】不可學九，上品可見；疑及不識，罪相難明，故須特簡。罪相中，初科為二，初明本迷。除淫酒者，此二不開迷故。若下，次明轉想。如前作人想，後作非人想之類；前心犯蘭，故云方便；後心無犯，即是開迷。若不差者，或約轉迷，還復為識；或約先期，後迷亦犯。〔如前〈隨相〉摩觸夢失之類。〕或不造者，即是息心；

【原文】欲使是非兩異，今古雙明，立破俱存，取舍無惑故也。〔下止犯中，亦同比意。〕釋中，初科為二；初敘略，上三句明事法句別。但下，明略出法句。明用別者，此明事法異也；且如房戒，尺量是事，白二是法；長衣，過日是事，說淨是法等。階降不異者，此示作句同也。唯對可學者，彰古局也。
