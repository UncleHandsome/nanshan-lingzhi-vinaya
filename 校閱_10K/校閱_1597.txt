# 校閱材料　第1597檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1597-0001】03_業疏/03a_卷一之三#112
【原文】二十五、六，律因一眾布薩日，於曠野中行，眾不和合，隨同師善友下道，各集一處，結小界說戒。尋言起行，以行踐言，故曰相因；然言行所立，必由淨僧弘闡聖法，故云「要在人法」，此明半月說戒之意。下道，即蘭若處；若在城邑則非開限，恐彼來訶故須疾結；結已無外，則容緩說
【譯文】第二十五、二十六項，律中起因是一群僧眾在布薩日，行走在荒郊曠野之中，大眾意見不和合，便跟隨同一師承的善友離開大路，各自聚集在一個地方，結小界說戒。依照聖言生起修行，以實際行持實踐聖言，所以說「互為因果（相因）」；然而言行之所以確立，必定有賴清淨僧眾弘揚闡發聖法，所以說「關鍵在於人與法（要在人法）」，這是說明每半月說戒的用意。「下道」就是阿蘭若僻靜之處；如果是在城鎮村落之中則不在開許的限度內；唯恐諍鬧之僧前來呵責作難，所以必須迅速結界；結界完成之後界外無人干預，便可從容緩慢說戒。

【1597-0002】03_業疏/03a_卷一之三#113
【原文】二十七、結二同者，兩住互缺，理須通和，彼此法食咸有濟務也
【譯文】第二十七、結法食二同界：兩個住處各有欠缺，理當互相通融和合，使彼此在佛法修行與飲食供養上都能獲得濟助。

【1597-0003】03_業疏/03a_卷一之三#114
【原文】二十七下三法，律有四種大界，初如前列，此即餘三，後一非界，所以總義但列三種。兩住互缺者，律明有二住處：一處行說戒無利養，一處有利養不說戒。佛開各解共結，此名法食二同界
【譯文】自第二十七項以下的這三種法，律中有四種大界，第一種正如前面所列出的大界，這裡就是其餘三種；最後一種並不是結界，所以在總體義理上只列出三種。「兩住各有欠缺」者，律中說明有兩個住處：一個處所修行說戒卻沒有利養供養，另一個處所有利養供養卻不行說戒。佛陀開許各自解除舊界而共同結為一界，這就稱為「法食二同界」。

【1597-0004】03_業疏/03a_卷一之三#115
【原文】二十八、單法同者，亦是各住合界之事。一則法食俱豐，一則有食無法，僧由法住，故別解通結，使二住成濟也
【譯文】第二十八、單法同界：這也是各別住處合併結界的情形。一處是佛法與飲食都很豐足，另一處是有飲食卻沒有佛法，僧眾依正法而安住，所以各自解除原界而通同合結新界，使兩個住處都得到成全濟助。

【1597-0005】03_業疏/03a_卷一之三#116
【原文】二十八，兩處各受利養，同一布薩，此謂法同食別界
【譯文】第二十八項，兩處各自受用飲食利養，卻共同舉行同一布薩說戒，這就稱為「法同食別界」。

【1597-0006】03_業疏/03a_卷一之三#117
【原文】二十九、單食同者，兩俱豐法，一所無食，若不兼濟，全乖僧體，故須和送，非是結界。上之三法，應有解文，律出其緣，至時皆顯
【譯文】第二十九、單食同法：兩處的佛法都很豐足，但有一處缺乏飲食，如果不兼顧濟助，就完全違背了僧團和合互助的本體，所以必須和合通融派人送食濟助，這並非真正結界。以上三種法，理應當有解除的羯磨文，律本列出其因緣，到了適當時機都會顯明。

【1597-0007】03_業疏/03a_卷一之三#118
【原文】二十九，兩各說戒，一有利養，一無利養，此名食同法別界。相因名界，實非標結。「上下」點缺。下云「後若法食俱豐，律令解為二別」，故知此三竝須有解。「律下」指廣，後結界中具明來致
【譯文】第二十九項，兩處各自說戒，一處有利養，一處無利養，這稱為「食同法別界」。只是順應前文而借稱為界，實際上並非標相結界。「上之三法」句是點出缺少解界之文。下文說「日後若是法與食都豐足了，律文命其解除而分為兩處」，所以知道這三種法都應當有解除法。「律出其緣」句是指其詳廣，在後面的結界篇中會詳細說明其由來緣致。

【1597-0008】03_業疏/03a_卷一之三#119
【原文】三十及三十一、與狂癡法及解者，心亂壞神，不守本性，來往違犯，多乖法度。據內非犯，約外招疑，故以法除，雖在不妨；後若病愈，得乞為解
【譯文】第三十及第三十一、給予狂癡法與解除法：心神錯亂敗壞靈性，無法持守本來心性，日常來往多有違犯，極為乖離戒律法度。依其內心而言並非故意違犯，但就外相來看會招致世人疑謗，所以藉由羯磨法免除其責任，即便人在僧中也不妨礙僧事；日後病痛若是痊癒，可以向僧眾乞請作法解除。

【1597-0009】03_業疏/03a_卷一之三#120
【原文】三十、三十一，即難提比丘得癲狂病多犯眾罪，故制此法。內非犯者，以無心故；外招疑者，人不悉故。雖在界中，不妨僧事。狂有三品：下品常來，上品不來，中品來否不定，故須與法。愈，即病差
【譯文】第三十、三十一項，就是難提比丘得了癲狂病而多次違犯諸戒罪，所以佛陀制定此法。所謂「內非犯」，是因為狂亂無心；所謂「外招疑」，是因為外人不明底細。雖然身在界內，並不妨礙僧眾作羯磨法事。發狂有三種層級：下品的常來參與僧事，上品的完全不來，中品的來與不來不一定，所以必須作羯磨給與其狂癡法。「愈」就是疾病痊癒。

【1597-0021】03_業疏/03a_卷一之三#132
【原文】四十三、差人守功德衣者，既名難活，亦號堅固，為功非少，非德不持，故須通和，守不出界，故曰也
【譯文】第四十三、差人受持迦提功德衣法：此衣既然名為「難活」，也稱為「堅固」，所產生的功德非同小可，非具道德之人不能秉持受持，所以必須通同和合僧眾作法差遣，守護而不使其失落出界，所以立此法。

【1597-0022】03_業疏/03a_卷一之三#133
【原文】四十三、名「難活」者，《鈔》云「貧人取活為難，能捨少財入此衣，獲功極大」。又翻「堅實」，謂能感多衣，衣無敗壞；或云「堅固」，或云「廕覆」等。差己須付，故有後法。
【譯文】第四十三項，名為「難活」者，《事鈔》說：「貧窮之人謀求生計極為艱難，若能割捨微薄資財加入縫製此衣，所獲功德極為廣大。」又翻譯為「堅實」，是指能感召獲得眾多衣服，且衣服不易損壞；或者稱作「堅固」，或者稱作「蔭覆」等。差定其人之後必須授予其衣，所以有後續的付衣之法。
