# 校閱材料　第288檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【288-0001】02_戒疏/11a_卷三上之二#58
【原文】【疏】然則法由人興，人能通法。德人懷道，明達取捨，理宜憑仗，請決進不。所以聖教勸依三藏，開導愚迷，以成資訓。然今闡陀內實無德，聞諫不受，反傍勝人，恃己陵物。便言：「佛是我家佛，因釋種故。法是我家法，因佛說故。汝今依我釋種佛法出家，我是佛法根本，正應教諸大德，何用大德教我？」言說相似，愚叢謂是。須諫開示，是非路分。有德相誨，為除迷結，是以須諫。
【譯文】【疏文】話說回來，正法是依靠人才能興盛，人能夠弘傳貫通正法。有德行之人胸懷道業，明瞭通達取捨的分寸，在戒理上應當依憑投靠他們，請求裁決修行上的進退取捨。所以佛陀聖教一再勸勉大家應當依止精通三藏的師長，啟發引導愚昧昏迷之心，藉以成就受教訓導的資糧。然而現在闡陀內在實質上毫無道德修養，聽到勸告也不接受，反而攀附非凡殊勝之人，依仗私交而傲視欺凌眾人。竟然聲明說：「佛陀是我家的佛陀，因為世尊出自釋迦族的緣故。佛法是我家的佛法，因為是由佛陀宣說的緣故。你們如今依附我釋迦族的佛陀與正法出家，我是佛法的根本根基，本來就應該由我教導各位大德，哪裡用得著大德來教訓我？」這番言詞聽起來似乎煞有介事，愚昧的僧眾還真以為有理。因此必須進行勸諫給予開示，將是非對錯的界線劃分清楚。由具足德行者出面勸勉訓誨，以破除大眾與其自身的迷惑結縛，這就是必須進行勸諫的緣由。

【288-0002】02_戒疏/11a_卷三上之二#59
【原文】【記】二中。初通敘諫人。謂此四種多不從諫：初即恃老，二即恃長，三恃少能，四恃他勢。用此自檢，孰可逃乎？似此等人，並須設諫。今此闡陀即同第四，故云「正當」也。
【譯文】【記文】在第二點中。首先全面敘述接受勸諫之人。意指這四種人大多不服從勸諫：第一種是仗恃年邁，第二種是仗恃身居僧首，第三種是仗恃微薄才智，第四種是仗恃他人權勢威德。拿這四點來自作檢點，誰又能倖免於傲慢呢？像這幾類人，都必須給予勸諫。如今這位闡陀正等同於第四種，所以義疏說「正當此人」。

【288-0003】02_戒疏/11a_卷三上之二#60
【原文】【記】「然」下，正敘今意。初通明依師學法。「聖教」即律文，如《受戒》中選師須通達三藏、勤教授者，當須依之。「資訓」，謂資稟教訓。「然今」下，正示須諫所以。初敘諫緣後。「闡陀」即車匿，本王宮侍人，為佛控馬踰城入山，最先親侍，故常以此自負，故云「我家」也。「言說」下，正明立諫。「迷結」，即上「愚叢謂是」。
【譯文】【記文】「然」字以下，正式敘述現今制戒的本意。首先全面說明應當依止師長學習佛法。「聖教」指的就是律文，例如在《受戒篇》中規定選擇依止師，必須通達三藏、勤於教授弟子者，方應當依止。「資訓」，是指稟受教誨訓誡。「然今」以下，正式指出必須勸諫的原由。先敘述勸諫因緣的背景。「闡陀」即是車匿，本是釋迦王宮的侍僕，曾為佛陀牽馬踰越城牆進入深山修行，是最早親自侍奉佛陀的人，所以經常以此自負，故而口口聲聲說是「我家」。「言說」以下，正式說明建立勸諫的理由。「迷結」，就是指前文所說的「愚昧僧眾誤以為其說得有理」。

【288-0004】02_戒疏/11a_卷三上之二#61
【原文】【疏】三、結罪意。僧既詳心，設諫救攝。三藏明告，義非沈伏。迷理開悟，故違僧命，情過尤重，所以殘收。
【譯文】【疏文】第三點，結罪懲罰的用意。僧團既然是用詳審慈悲的心，設立勸諫來救度攝受他。以經律論三藏之理明白告知，法義彰顯而非幽晦隱曲。在明白道理的開示下，他卻故意抗拒違背僧團指令，其過失情節特別嚴重，所以最終以僧殘罪予以收懲。

【288-0005】02_戒疏/11a_卷三上之二#62
【原文】【記】三中。初明能諫。上二句示能諫人如，下二句明所持教顯。「詳心」，非麤暴故。「救攝」，非瞋怒故。「三藏」者，《律》云「如法、如律、如佛所教諫」故。「沉伏」，即隱覆也。「迷」下，明所諫故違。「迷理」，謂彼所執非理也。「開悟」，謂自知非也。
【譯文】【記文】在第三點中。首先說明實施勸諫者的如法。前兩句指出能勸諫者心態安詳平靜，後兩句說明所秉持的教理清晰顯明。「詳心」，是指並非粗暴對待。「救攝」，是指並非心懷嗔怒。「三藏」，是指《律藏》所言「如法、如律、如佛陀教導而行勸諫」。「沉伏」，即是指隱蔽覆蔽。「迷」字以下，說明被勸諫者故意違抗。「迷理」，是指他所執著的論調全非正理。「開悟」，是指僧團開示後其理應自知非理。

【288-0010】02_戒疏/11a_卷三上之二#67
【原文】【註】佛在拘睒彌國。尊者闡陀惡性拒諫，反言：「我應教諸大德，何以故？我聖主得正覺故。」比丘舉過白佛。便訶責已，而制此戒。
【譯文】【註文】佛陀住在拘睒彌國時。尊者闡陀生性凶劣抗拒勸諫，反而說：「應當由我來教訓各位大德，為什麼呢？因為我的聖主證得正等正覺的緣故。」比丘們檢舉其過失稟告佛陀。佛陀嚴厲呵責之後，制定了這條戒律。

【288-0011】02_戒疏/11a_卷三上之二#68
【原文】【疏】就戒緣中：從初至「我聖主得正覺」來，過起所由；二、「比丘舉過」，明訶制戒。初中所以云「我聖主」者，本是佛家使人也。故《見》云：「佛是我家佛，我將佛入山學道，不見諸長老一人侍佛者，乃至得轉法輪故，法是我家法。」與僧競故，不云僧也。《僧祇》云：「我常隨佛，佛唯教我，我當受持。」如是陵慢。
【譯文】【疏文】在此戒的因緣中：從最初至「我聖主得正覺」為止，是過失發起的原由；第二段「比丘舉過」，是說明呵責並制定戒律。第一段中之所以會說「我的聖主」，是因為他原本是佛陀家族的僕役。《善見律毘婆沙》說：「佛陀是我家的佛陀，是我護送佛陀入山修道，當時沒見到各位長老有任何一人侍奉佛陀，甚至一直到佛陀轉法輪為止；所以佛法也是我家的佛法。」因為他正在與僧團抗爭賭氣，所以絕口不提僧寶。《僧祇律》記載他說：「我常年跟隨佛陀，佛陀唯教導我一人，唯有我應當領受奉持。」就是如此傲慢自大、輕視他人。

【288-0012】02_戒疏/11a_卷三上之二#69
【原文】【記】釋戒緣中。初科分。「初」下，牒釋。《善見》三寶中，獨「不云僧」者，由「與僧競」，顯非「我家」故。《僧祇》「我常隨佛」，恃其最久也。
【譯文】【記文】解釋制戒因緣中。首先劃分科段。「初」字以下，引文解釋。《善見律》在三寶之中，唯獨「不提僧寶」，是因為他「正在與僧團爭執抗衡」，藉以表明僧眾不是「我家的人」。《僧祇律》記載其自稱「我長年跟隨佛陀」，正是仗恃自己跟隨佛陀的時間最長久。

【288-0040】02_戒疏/11a_卷三上之二#97
【原文】【疏】我教彼悔，彼教我懺，彼我迭為，故曰「展轉懺悔」。對前為言，此除已起之惡也；對前修善，即是作持止行兩善。所以成者，功由善友相導。故云「大德當諫比丘，比丘亦諫大德」也。
【譯文】【疏文】我教導對方發露罪衍，對方教導我悔悟前愆，彼此交互為之，所以稱為「展轉懺悔」。相對於前面而言，這是為了除滅已經發生的罪惡；相對於前文的修善而言，這正屬於作持與止行這兩種善法。這一切之所以能夠成就，功德全在於善知識良友的相互引導教化。因此經文說「大德應當勸諫比丘，比丘也應當勸諫大德」。
