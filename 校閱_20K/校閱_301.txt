# 校閱材料　第301檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【301-0001】02_戒疏/11c_卷三上之二#88
【原文】【疏】就五長戒，本由貪貯，故犯令捨，反彼貪心。不得即日還主，必有他緣，如文所開。如《多論》中「即日得受異財，不染長過，以心斷故」。所以本財不得者，曾經畜過，須以宿隔其心。必若不斷，多宿亦犯。不同過藥，當日得還，制不服用。
【譯文】【疏文】就五種長物戒來說，本來是由於貪求貯存，所以犯戒時令其捨棄，以反制原來的貪心。物不能當天歸還給原主，除非遇到特殊的緣由，正如經文所開許的那樣。好比《薩婆多論》中所說：「當天得以接受其他財物，不受長物過失的沾染，因為蓄積之心已經斷除的緣故。」至於原本的財物之所以不得接受，是因為曾經蓄存有過，必須用過夜的時間來阻隔這份貪心。如果貪心必定不曾斷除，即使過了許多夜也依然算犯戒。這不同於過期的藥物，當天就可以歸還，只是制令不得自行服用。

【301-0002】02_戒疏/11c_卷三上之二#89
【原文】【記】正明中。初敘五長捨意。「他緣」即難集遠行，開展轉還。「如」下，引示捨心。初明得受異財，即下第三句。「所以」下，示不開本財。「不」下，簡長藥。以同貪貯，不隔宿故。
【譯文】【記文】在正式論述中。起初敘述五長戒捨財的意圖。「特殊的緣由」就是遇到集眾困難或長途遠行，開許可以展轉託人歸還。從「好比」以下，引證說明捨心。首先說明可以接受其他財物，這對應於下文的第三句。從「至於原本」以下，說明為何不開許收回原物。從「這不同」以下，簡別長藥；因為雖然同是貪求貯藏，藥物卻不需要隔夜。

【原文】【疏】故《多論》中六句分別。
【譯文】【疏文】所以《薩婆多論》中採用六種句型來加以分別。

【301-0004】02_戒疏/11c_卷三上之二#91
【原文】【疏】初、衣已捨，罪已悔，畜心未斷，更受異衣，為前衣所染。二、衣捨罪悔，求心不斷，乃至一月得所求衣及意外衣，皆染犯捨，心不斷故。
【譯文】【疏文】第一、衣服已經捨棄，罪業已經懺悔，但蓄積之心尚未斷除，如果又接受別的衣服，就會被先前的衣服所沾染。第二、衣服已捨、罪已懺悔，索求之心卻未斷除，乃至在一個月內獲得所求的衣服以及意料之外的衣服，都受沾染而犯捨墮，這是因為貪心未斷的緣故。

【301-0005】02_戒疏/11c_卷三上之二#92

【譯文】【記文】其次在引述句數中。前兩句有兩種分別：第一是蓄存心與索求心的不同；第二是時間久與暫時的不同。

【301-0006】02_戒疏/11c_卷三上之二#93
【原文】【疏】下有四句，由心斷故不染者，前緣無罪，後心吉羅。三、衣已捨，罪已悔，畜心斷，即日得衣無犯，以心斷故。四、衣已捨，罪已悔，畜心斷，後日更求得衣不犯，中間心捨故。五、地了時，衣捨、罪悔、畜心斷，向暮更求得衣，犯吉羅。六、衣已捨，罪未悔，畜心斷，正使多日得衣，犯吉。
【譯文】【疏文】以下有四句，由於心念已斷所以不受沾染的情況：前一段因緣沒有罪業，後起之心只犯突吉羅。第三、衣服已捨，罪已懺悔，蓄積之心已斷，當天得到衣服不犯戒，因為貪心已斷的緣故。第四、衣服已捨，罪已懺悔，蓄積之心已斷，日後再去求得衣服不犯戒，因為中間的心念已經捨棄的緣故。第五、在天色破曉時，衣服已捨、罪已懺悔、蓄積之心已斷，接近傍晚時又去求得衣服，犯突吉羅罪。第六、衣服已捨，罪業尚未懺悔，蓄積之心已斷，即使隔了許多天得到衣服，也犯突吉羅。

【301-0007】02_戒疏/11c_卷三上之二#94
【原文】【記】後四句中。初總示。「三」下，別列。二與六，並約得衣而悔罪已未別。「四」與「五」並約再求，而後日即日別。引此句數，則知捨心為悔本矣。
【譯文】【記文】在後四句當中。起初總體提示；從「第三」以下，分別陳列。第二句與第六句，都是針對得衣時罪業已懺或未懺的分別；第四句與第五句，都是針對再度求取，而在後日或當日求得的分別。引用這幾種句型，就能明白捨棄罪心乃是懺悔的根本。

【301-0009】02_戒疏/11c_卷三上之二#96
【原文】【疏】有師立義，三十捨罪，並皆集僧，以對眾心重故，不集不成。
【譯文】【疏文】有的法師立論主張：三十捨墮的懺罪，全部都必須集結僧眾，因為面對大眾的心意至為鄭重，如果不集結僧眾懺法就不能成就。

【301-0010】02_戒疏/11c_卷三上之二#97
【原文】【記】三、捨罪中，古解，初師。「三十」並須對僧，異單提故。蠶綿、二寶，捨雖非僧，單悔本罪，亦須盡集。
【譯文】【記文】第三、捨罪法中，古代的解釋，這是第一位法師。三十條戒全都必須對著僧眾懺除，這不同於單提罪；蠶綿衣與二寶雖然捨財不是對著僧團，但單純懺悔本罪時，也必須全體集僧。

【301-0011】02_戒疏/11c_卷三上之二#98
【原文】【疏】有師云：「捨財不得別眾，故文云『不得別眾捨，若捨，不成』。罪則別人所除，同墮，別眾亦得。」
【譯文】【疏文】有的法師說：「捨棄財物不得在個別僧眾處進行，所以經文說『不得在別眾中捨財，如果捨了，作法不能成就』。罪障則可以在單獨一人處消除，因為性質同於墮罪，在別眾（未集全的眾多人）面前懺悔也是可以的。」

【301-0012】02_戒疏/11c_卷三上之二#99
【原文】【記】次師。「捨財」局僧，文證甚顯。捨罪「同墮」，非別篇故。
【譯文】【記文】第二位法師觀點。「捨財」局限在僧團，文證極其明顯；懺罪「同於墮罪」，並不是另一篇獨立的罪位。

【301-0013】02_戒疏/11c_卷三上之二#100
【原文】【疏】有師云：「依《律》文好。如《律》綿衣、二寶捨不對僧，故文中不明僧悔。自餘並制在僧，或眾多或一人也。」
【譯文】【疏文】有的法師說：「依循《律》文最為穩妥。好比《律》文記載蠶綿衣、二寶捨財不對僧團，所以經文中沒有說明僧中懺悔之法；其餘各條都制令在僧團，或者在眾多人、或在單獨一人面前進行。」

【301-0014】02_戒疏/11c_卷三上之二#101
【原文】【記】後師。依《律》，餘並對僧，「綿、寶」對別。以三十中，獨蠶綿、二寶，不出悔法故。
【譯文】【記文】最後一位法師的觀點。依照《律》文，其餘都對著僧團，唯獨「蠶綿、二寶」對著個別人士，因為三十捨墮當中，唯獨蠶綿與二寶沒有列出懺悔法。

【301-0015】02_戒疏/11c_卷三上之二#102
【原文】【疏】今解：「三十之戒，緣財故犯，故抽前者，捨悔難故。豈可財難對僧，除罪則別？隨有所犯，捨財如《律》。捨罪必僧，縱是一人，界非別眾，一人僧也。如《律本》中，三戒不列者，但由財是別捨，乘不明悔，非謂別除。《四分》無文。《十誦》、諸部云，此罪必僧中悔故。至文更出，餘如《鈔》、《疏》。」
【譯文】【疏文】如今的解釋是：「三十條捨墮戒，都是因為財物而生起犯戒，所以將它抽調在前面，這是因為捨財悔罪難以辦到的緣故。哪有財物難於面對僧團、消除罪業卻可以從簡對別人的道理？隨其有所違犯，捨棄財物都依《律》文辦理；捨除罪業則必定要對著僧團，縱使只有一人，只要該結界內沒有分派成別眾，這一人也就是僧團的代表了。好比《律本》當中，有三條戒沒有列出懺法，這只是由於財物屬於各別捨棄，順著文勢便不再重申懺法，並非意味著可以找個人私下懺除。《四分律》雖然沒有明文，但《十誦律》等諸部律典都說，這種罪必定要在僧團中懺悔。到了後文還會再行列出，其餘的正如《事鈔》與《疏》中所說。」

【301-0016】02_戒疏/11c_卷三上之二#103
【原文】【記】今解中。初敘悔法。「故抽前者」，別「九十」故。「豈可」等者，財罪兩難，不可偏故。「隨」下，出今判。初正示。「縱一人」者，悔通三位，以無僧處，故開別人，雖對一人，界須盡集，無非僧法。「如律」下，釋妨。綿衣、二寶，《律》不明悔，後師執此以立依文，故須通決。初示《律》意。「財是別捨」者，綿則斬壞，二寶與俗，不對僧故。「乘」，猶因也。「四分」下，引據。《僧祇》云：「金銀錢，一切不得捉，捉得提，應僧中悔。」《多論》云：「一切重寶，捨與同意淨人，罪僧中悔。」、「至」下，指後。「餘」下，示略。
【譯文】【記文】如今的解釋中。起初敘述懺悔法。「抽調在前面」，是為了區別於「九十單提」。「哪有」等語，是說明財物與罪障兩者都困難，不可偏廢一邊。從「隨其」以下，提出如今的判定。起初正式闡明。「縱使一人」，說明懺悔通於三種位階，因為在沒有具足僧團的地方，所以開許對個人；雖然只對一人，只要界內僧眾全部到齊，無非都是合法的僧法。從「好比律本」以下，解釋疑難。蠶綿衣與二寶在《律》中沒有明載懺法，後面的法師執著此點而主張依文解讀，所以必須融通決斷。首先指明《律》本的立意。「財物個別捨」，是指蠶綿剪壞、二寶給予俗人，不對著僧團的緣故。「乘」就是順應、依循的意思。從「四分律」以下，引用依據。《僧祇律》說：「金銀錢財，一切不得拿取，若拿取了犯提罪，應在僧團中懺悔。」《薩婆多論》說：「一切珍重寶物，捨給志同道合的淨人，罪過要在僧中懺悔。」從「到了」以下，指引後文；從「其餘」以下，說明此處略去。

【301-0019】02_戒疏/11c_卷三上之二#106
【原文】【疏】如長衣、月望、長鉢、長藥、急施過後。此五長戒，佛令淨施如法受之。依教奉說名作持，不越佛制名止持。「作」謂䇿修奉行，「止」謂如教非越，此則名體各別。故違不說名止犯，越於期限名作犯，此亦名體各別，翻對自顯。並如上卷「持犯」中說。
【譯文】【疏文】好比長衣、月望衣、長缽、長藥、急施衣過期之後，這五種長物戒，佛陀制令必須透過如法的說淨法來受持它。依照教令實行奉持稱為「作持」，不逾越佛陀的規制稱為「止持」。「作」是指警策修行、如法奉持，「止」是指順從教導、不加逾越，這兩者的名稱與本質各別不同。故意違背戒法而不作說淨表白稱為「止犯」，超越了期限稱為「作犯」，這兩者的名稱與本質也各別不同，相互反照自然顯明。這些正如上卷「持犯」篇章當中所說。

【301-0020】02_戒疏/11c_卷三上之二#107
【原文】【記】第六門，五長中。初別列諸戒。「此」下，總示雙持。由有淨施，故行分兩別。「作謂」下，示名體。初示二持。「止作」是「名別」，「修奉非越」即「體別」。「故」下，明兩犯。「止作名別」，「不說越期」即「體別」。翻持成犯，故云「自顯」。以古師相傳云：二持名體各異，兩犯名異體一。上篇委斥，此復點示。「並」下，指廣。或指初卷「總義」，或指第二僧殘。
【譯文】【記文】第六門，在五長戒中。起初分別陳列諸戒。從「這五種」以下，總括說明作持與止持並存。由於有說淨法的存在，所以修行行相分為兩條不同軌轍。從「作是指」以下，說明名稱與實體。首先說明二種持戒。「止作」是「名稱相異」，「策修與非越」就是「實體相異」。從「故意違背」以下，說明兩部犯戒行相。「止作名稱相異」，「不說與逾期」就是「實體相異」。由翻轉持戒即成犯戒，所以說「自然顯明」。因為古代法師代代相傳說：二種持戒的名稱與實體各別不同，而兩部犯戒則是名稱相異但實體相同；上篇中已詳細斥責，此處再度點明提示。從「這些正如」以下，指引詳細內容，或指第一卷的「總義」，或指第二卷的僧殘篇。

【301-0024】02_戒疏/11c_卷三上之二#111
【原文】【疏】餘諸戒。如取尼衣，將衣來施，自量量他，見無法利，止心不受，恐犯戒故名止持。不但無心緣念便名止也。此止無記，非隨戒也。翻止受納，名作犯也。犯必依記，成於業也。
【譯文】【疏文】其餘各條戒。好比取比丘尼衣戒，比丘尼把衣服拿來布施，自己衡量自身與他人，見到沒有正法的利益，便收攝自心不加接受，因為恐懼犯戒的緣故所以稱為「止持」。這絕不僅僅是內心無念無想就叫做止；這種無所用心的停止屬於無記性，並不是隨順戒法而生起的持戒。翻轉過來不止住而領納受用，就稱為「作犯」；犯戒必定依附於善或惡的心念，從而構成業力。

【301-0025】02_戒疏/11c_卷三上之二#112
【原文】【記】次單持中。初句總示二十一戒。「如」下，別舉示相，又二。初明止持。「自量」等者，謂先觀察，即是智也。然後「不受」，即是行也。「不但」下，反古。彼謂任運不作即是止持，如前已破。「此」下，決破。因臨此語，不覺喟然，嗟往者之不聞，喜來蒙之獲遇。可謂毗尼教旨，皎在目前；萬行修持，坦然有據。寄言學者，熟而思之。「翻」下，明作犯。
【譯文】【記文】次論單純止持當中。第一句總括說明其餘二十一條戒。從「好比」以下，分別列舉行相，又分為兩層。首先說明止持。「自量」等語，是說事先省察，這就是智慧；然後「不受」，這就是修行實踐。從「絕不僅僅」以下，駁斥古說；古說認為任運無為不做就是止持，如前面已經破斥。從「這種」以下，作決斷破斥。在讀到這段話時，不由得令人慨然長嘆：既哀傷於往昔前人未曾得聞此理，又慶幸於後世蒙昧者得以遭遇此法。這可以說是讓毘尼戒律的深意，清清楚楚顯露於眼前；萬種修持之行，坦蕩穩實而有所依憑。寄語後世參學者，應當深思熟慮。從「翻轉」以下，說明作犯。
