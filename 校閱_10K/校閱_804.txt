# 校閱材料　第804檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【804-0001】02_戒疏/19a_卷四下之一#147
【原文】【記】次科。指廣「如《鈔》」，即開緣等。文中六緣。「熱時」，注云「春後四十五日」，即三月一日至四月十五。「夏初一月」，即四月十六至五月十五。共七十五日，餘五并犯。不犯文，如注，易解。
【譯文】【記文】下一科判。指示更廣泛的內容「如《事鈔》」，即指諸項開許因緣的辨別。條文中列出的六種因緣。「炎熱之時」，隨律註解說「春季最後的四十五天」，即指三月一日起至四月十五日止。「夏季最初的一個月」，即指四月十六日起至五月十五日止。總計七十五天允許洗浴，除此熱時之外，其餘五種開緣若不具足而頻繁洗浴者亦皆違犯。不犯的條文，如同隨律註解所述，文字容易明白。

【804-0004】02_戒疏/19a_卷四下之一#150
【原文】【疏】凡火性焚熾，事變無恒，容有延燒，不可不禁。又然火相聚，多著世話，廢業自輕，何得不制？
【譯文】【疏文】大凡火的本性是焚燒猛烈熾熱，事態演變往往沒有定規，極容易引發蔓延延燒的危險，絕不可以不加禁阻。而且生火容易聚眾圍坐，大家多半會沉迷閒聊世俗雜話，荒廢修道正業而自招輕浮放逸之譏，怎能不立法禁制？

【804-0005】02_戒疏/19a_卷四下之一#151
【原文】【記】五十七，制意有二。初為防失。「延燒」謂旁延他處。「又」下，次恐廢業。
【譯文】【記文】第五十七條，制戒用意有兩點。起初是為了防範火災過失。「蔓延延燒」是指火勢橫向蔓延延燒到其他區域。從「而且生火」以下，次要是擔心荒廢道業。

【804-0006】02_戒疏/19a_卷四下之一#152
【原文】【疏】論犯四緣：一、無緣；二、露地；三、草木有𦦨；四、然即犯。
【譯文】【疏文】論述構成犯戒的四種條件：第一，沒有正當開許因緣；第二，處在露天曠野的無遮之處；第三，引燃的草木生起明顯烈焰；第四，火燃燒起來便構成犯戒。

【804-0007】02_戒疏/19a_卷四下之一#153
【原文】【記】犯緣。第二，局在「露地」，屋中非犯。三、須「有焰」，無焰則輕。若在生地，或生草木，則有掘、壞二罪生焉。
【譯文】【記文】犯戒條件中。第二點，嚴格限定必須是在「露天之地」，若在密閉屋舍之內生火取暖則不犯此戒。第三點，必須「引發明火烈焰」，如果只有煙霧熱氣而無火焰，則結罪較輕。假使是在活生生的土地上生火，或是燃燒活生生的青翠草木，那麼挖動生地與損毀生草木的兩項墮罪又會隨之衍生。

【804-0008】02_戒疏/19a_卷四下之一#154
【原文】【註】佛在曠野城。六群相謂：「我等在上座前，不得隨意語言。」即出露地，拾諸柴草，然火向之。株內毒蛇，火氣逼出，遂驚擲火，燒佛講堂。比丘舉過，佛因訶制。
【譯文】【註文】佛陀住在曠野城時。六群比丘彼此商量說：「我們在德高望重的上座比丘面前，無法隨心所欲地暢所欲言。」於是便結伴走到露天的曠野空地，撿拾許多枯柴乾草，生火圍坐烤火取暖。樹樁樹洞內藏匿的毒蛇，被燥熱的火氣逼迫竄出，比丘們驚駭萬狀之下隨手將著火的柴枝胡亂拋擲，竟然延燒焚燬了佛陀的講堂。比丘們向佛陀檢舉這項重大過失，佛陀因而呵斥並制定了此戒。

【804-0009】02_戒疏/19b_卷四下之一#1
【原文】【疏】緣起中，由不得隨意語故，出外聚向，遂燒講堂，輕致重害，不可不慎。故世中所壞，多為火損，不爾久存。世界亦爾。火為凡貪，不可觸也。此是觀行，如何著之？
【譯文】【疏文】在緣起這一段中，由於不能隨意發言的緣故，便走到外頭聚集烤火，因而燒毀了講堂；輕忽而招致重大的損害，不可不謹慎。所以世間被毀壞的，大多是火造成的損失，否則就能長久保存。世界也是這樣。火為凡情所貪愛，不可去觸碰。這是觀行的內容，怎麼可以反而去執著它呢？

【804-0010】02_戒疏/19b_卷四下之一#2
【原文】【記】戒緣中。初牒文誡慎。「故」下，示過勸離。初指現事，故云「世中」等。次舉灾劫，故云「世界亦爾」，如大三灾起時，火灾壞至初禪天。三、明性烈，寒月雖貪，觸則爛體。「是觀行」者，謂觀火能變壞，了世無常而生猒捨。或可經論多舉為喻，或以三界喻火宅，或以世間喻無常，或令遠惡如避火坑，或云瞋心甚於猛火。斯等甚眾，略舉一二耳。
【譯文】【記文】在戒緣這一段中：最初是牒出文句、告誡要謹慎。「故」字以下，是指示過失、勸人遠離。首先指眼前的事實，所以說「世中」等語；其次舉出災劫，所以說「世界亦爾」，就像大三災生起時，火災一直壞到初禪天。第三、說明火的性質猛烈，寒月裡雖然貪求暖和，一碰觸就會燒爛身體。「是觀行」的意思是：觀火能變壞一切，從而了解世間無常，生起厭離、捨棄之心。或者經論中多舉火作譬喻：有的以三界譬喻火宅，有的以世間譬喻無常，有的教人遠離惡事如同躲避火坑，有的說瞋心比猛火更猛烈。這類說法非常多，這裡只是略舉一二而已。

【804-0012】02_戒疏/19b_卷四下之一#4
【原文】【註】彼於露地，若草木、枝葉、紵麻、芻摩，若牛屎、糠、糞、䴬中，一切然者，波逸提。若火置草木乃至䴬中，亦墮。若被燒半焦，擲著火中，及然炭者，突吉羅。若不語前人「知是，看是」，亦吉羅。不犯者：語言「知是，看是」；若病人自然，教人然；有時因緣，看病人煑糜粥羮飯；若在厨屋中、浴室中；熏鉢，煑染，然燈，燒香——一切無犯。
【譯文】【註文】他在露地，不論是在草木、枝葉、苧麻、芻摩之中，或在牛屎、糠、糞、麥皮之中，只要燃火，就犯波逸提。如果把火放進草木乃至麥皮之中，也同樣犯墮。如果把燒得半焦的東西丟進火裡，以及燃燒木炭，犯突吉羅。如果不告訴在場的人說「注意啊，看著啊」，也犯突吉羅。不犯的情形：先對人說「注意啊，看著啊」；或者病人自己燃火、教人燃火；或者有當時的因緣，為看護病人而煮稀粥、羹湯、米飯；或者在廚房裡、浴室裡；或者熏缽、煮染、點燈、燒香——這些全都無犯。

【804-0014】02_戒疏/19b_卷四下之一#6
【原文】【記】戒本中。略指而已。辨相，注中分二，犯與不犯也。犯中又二，重與輕也。重中，初以物然火，二、以火投物。初中「芻摩」是梵語，亦即草名，未知所譯。米糠、糞掃。麥䴰，音弋，麥皮也。次明輕中，「被半燒焦」，即上草木等曾經火者。「然炭」輕者，以無焰故。「不犯」中，「糜」，亦粥也。
【譯文】【記文】在戒本這一段中，只是大略指出而已。辨明相狀的部分，注解中分為二類：犯與不犯。犯中又分二種：重與輕。重的情形中，第一是以物品燃火，第二是把火投進物品中。第一類中，「芻摩」是梵語，也就是草的名稱，不知道當時譯作什麼。「糠」是米糠，「糞」是糞掃。「麥䴰」讀音為「弋」，就是麥皮。其次說明輕的情形：「被半燒焦」，就是指上面所說草木等曾經被火燒過的東西。「燃炭」之所以判輕，是因為沒有火焰的緣故。「不犯」中，「糜」也就是粥。

【804-0017】02_戒疏/19b_卷四下之一#9
【原文】【疏】出家達士，德類老成，隨事運為，永絕童戲。今調笑喧煩，觸途惱患，藏他衣鉢，覓不時得，令彼慞惶，惱深可厭。又既藏他物，容生盜心，臨危事重，可懼至甚。又雖無盜，致被言謗，清白難分，如何自拔。具斯多過，故須一制。
【譯文】【疏文】出家的達士，德行應像老成穩重的人，隨事應對運作，永遠斷絕孩童般的嬉戲。如今卻調笑喧鬧，所到之處都成為煩惱過患：藏起別人的衣鉢，使他不能及時找到，令他驚慌恐懼，這種煩惱深重而可厭。又，既然藏了別人的東西，就可能生起盜心，到了危急關頭事情就嚴重了，非常可怕。又，即使沒有盜心，也會招來口舌誹謗，清白難以分辨，自己如何能洗刷得清？具備這麼多過失，所以必須制定這一條戒。
