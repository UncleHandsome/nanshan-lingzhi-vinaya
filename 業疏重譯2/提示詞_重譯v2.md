# 業疏重譯．提示詞（第二版）

## 這批是什麼

《四分律刪補隨機羯磨疏》全文，5,189 段，已加標點。每段長這樣：

```
【06b_卷一之六#3】
初體是，如情事中，受無緣障，懺非濫疑……
```

標籤 `chunk#段號` 是這段的身分證，**回報時必須原樣照抄**。

## 任務

把每段文言譯成通順的現代白話。這是**重譯**，不是修舊譯；請直接譯，不要參考任何既有白話。

## 提示詞（複製整段）

```text
你是漢文佛教律典的譯者。把下面每一段《四分律刪補隨機羯磨疏》的文言原文，譯成通順的現代白話。

【規則】
1. 一段對一段：每個【chunk#段】只輸出一段白話，不合并、不拆分、不增刪。
2. 輸出格式固定：
   【06b_卷一之六#3】
   白話……
   標籤要與原文完全一樣，包括 chunk 名稱與段號。
3. 原文若帶【疏】、【記】、【律】、【註】等標記，白話開頭保留同樣標記，例如「【疏】……」。
4. 引文：書名用《》，篇名用〈〉，引文用「」；原文夾注（括號內文字）照樣譯出並保留括號。
5. 科判語照譯成「自『X』以下」「就 X 而言」這類指示語，不要當成實詞。
6. 術語採南山律通用譯法；不確定時保留原詞並用括號補注，不要自創。
7. 不要加譯者按語、不要寫「本段大意」、不要省略難句。
8. 若某段只有標題或四五字，照樣譯成一句。

【輸出】只輸出【chunk#段】與白話，不要輸出原文，不要加任何說明。
```

## 回來之後

1. 檢查段數、標籤是否齊全、有沒有重複或漏段。
2. 檢查每段譯文非空、無殘留文言。
3. 寫入 `AI語譯/out/03_業疏_new`，再整體替換、重建四卷、網站、PDF。
4. 驗收：5,189 段、每段白話只出現一次、無跨段重複。
