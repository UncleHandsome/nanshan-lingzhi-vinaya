# 校閱材料　第160檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【160-0001】資持記/05d_上四#50
【原文】不自反照，故多迷己。縱下，示名；上二句，標。內下，釋。初二句，釋上縱宣己罪，即明自義。誠心露過，故曰內彰；屈身坐草，發語求誨，故云外顯；即三業也。玉病曰瑕，人病曰疵，並喻於罪。身下一句，釋上恣僧舉過，即彰恣義。故下，結名。引證中，初問起。使下，列釋。四義，並以故字結之。
【譯文】不能自我反省觀照，所以多數都會迷失自心。從「縱」字以下，顯示篇名；上面兩句屬於標題。從「內」字以下進行解釋。前面兩句解釋上面的「放縱宣說己罪」，即是闡明「自」的含義。以至誠懇切之心發露過錯，所以稱為「內彰」；身屈於地坐於草蓆，發言乞求指正訓誨，所以稱為「外顯」；這即是身口意三業。玉的斑病稱為「瑕」，人的毛病稱為「疵」，都是用來比喻過罪。「身」以下一句，解釋上面的「任憑僧眾舉出過失」，即是彰顯「恣」的含義。從「故」字以下，結定篇名。引用經文作證中，首先發問引起後文。從「使」字以下，羅列解釋。這四種意義，都是用「故」字作為結尾。

【160-0002】資持記/05d_上四#51
【原文】不孤獨者，三業憑他，不自有故。苦言，即所陳詞句；以自述己過，使眾聞故。初即明制相依，餘並清過；二句有已，四即無犯，三通有無。又初後生善，中二滅惡。制夏末中，初科，初句徵。若下釋，又二；初敘不前意，上明來集之心欵，誠也。要，制也。若逆下，彰前舉之過。逆，謂未竟而先舉也。
【譯文】所謂「不孤立單獨」，是指身口意三業都憑藉他人的監督，不全依仗自己的緣故。「苦言」，即是所陳述的發露詞句；用來親自敘述自己的過錯，讓大眾得以聽聞之故。第一項是說明依法依附受戒而住，其餘幾項都是令罪過清淨；第二句是指已經有犯，第四句是指全無毀犯，第三句則通於有犯與無犯。又第一與最後一項是生起善行，中間兩項是消滅惡業。在制定於「夏末」的科判中，第一科，第一句提出追問。從「若」字以下進行解釋，又分兩點；首先敘述不在夏初舉罪的原因，上面說明大眾前來聚集的心情至為誠懇。所謂「要」，即是制約約定。從「若逆」以下，彰顯提前舉發過失的弊病。「逆」，是指事情尚未結束而提前舉發。

【160-0003】資持記/05d_上四#52
【原文】故下，二明須後意，初句重牒前徵。以下釋，初敘將散。方詣，謂所往之處。必下，明立法。不獨宣者，多迷己故。障道等者，顯須悔故。故下，結意。次科。律論皆云竟，證上彌顯。論中持戒律者，是遵制教；及諸善者，即依化教；化制無違，故云皆不毀等。遮濫中，初二句，正名。
【譯文】從「故」字以下，第二部分說明必須推至夏末的意圖，第一句重新列出前面的追問。從「以」字以下進行解釋，首先敘述大眾即將離散。「方詣」，是指離去後所前往的地方。從「必」字以下，說明立法用意。自己不會單獨宣說，是因為自己多會蔽昧過失。所謂「障道」等語，顯明必須發露懺悔之意。從「故」字以下，結定本意。下一科。律典與論典都明確寫著「安居畢竟」，證實上述論點更為顯明。論中所說的「持戒律者」，是指遵從戒制之教；「以及諸善法」，即是依循化導之教；化導與戒制互不違背，所以說都不可毀犯等。防範虛濫中，前面兩句正式確定正名。

【160-0004】資持記/05d_上四#53
【原文】非下，黜謬。昔人應以賞勞五利，開破五戒；是任意毀犯，而立其名。此下，示意。開章，標列中。言緣集者，謂定時簡人，竝須合教，方成法故。雜明者，料簡釋疑，非一相故。時節，含閏中，初明閏四五六月。七月十五日，且約前安居人；中後結者，多隨前坐，故不別標。
【譯文】從「非」字以下，斥退謬誤。過去的人應當是以勞苦犒賞的五種利益，任意開許破除五條禁戒；這純屬隨心所欲地毀犯戒律，而妄立虛名。從「此」字以下，顯明正意。在開顯章節與標示條列中。說到「因緣具集」，是指限定時間、甄別人員，都必須符合教法規定，法事方可成就。說到「雜明」，是指辨析料簡以釋除疑惑，因為情況非僅一種。在時間節氣涵蓋閏月的文段中，首先說明閏四月、閏五月、閏六月。七月十五日，姑且是針對前安居的人而言；中安居與後安居結夏者，多隨同前安居者一同安居（坐夏），所以不另外標列。

【160-0005】資持記/05d_上四#54
【原文】不依者，謂先結後閏，具如前篇；此即隨竟自恣，不局時節。若下，明閏七月。非前夏，數滿者，此據中後者多；必前多後少，亦隨前作，住待日滿耳。增減中。減前二日，增後二半；猶不去者，開強和合，一同說戒，故指如前。延日中。律因諸比丘安居，精勤行道，得增上果；恐往餘處，不得是樂，白佛；
【譯文】所謂「不依循」，是指先結夏、後發現有閏月的情況，詳細正如前篇所述；這即是隨順各自期限結束而行自恣，不拘泥於特定時節。從「若」字以下，說明閏七月的情況。所謂「非屬前夏、日數已滿」，這是依據中安居、後安居的人居多而言；如果前安居的人多而後安居的人少，也跟隨前安居作法，隨後繼續安住直到日數圓滿為止。日數增減之中。可以提前減少兩天，或者向後推延兩天半；若諍者仍不肯離去，便開許強行和合，一同行布薩說戒，所以指示如同前篇。延後日數之中。律中因眾比丘精進修行佛道，證得增上勝果；擔心前往其他住處無法獲得如此法樂，因而稟白佛陀；

【160-0006】資持記/05d_上四#55
【原文】因令作白，增益自恣。白云：大德僧聽！若僧時到僧忍聽，僧今不自恣，四月滿，當自恣，白如是。詳定中，初定無難；若下，明有難。初中又二，初引文以定。初云律中者，即〈自恣犍度〉云：諸比丘欲十四十五自恣，佛言聽。次引急施者，初句通指一戒；
【譯文】佛陀便指令作單白羯磨，增加延展自恣的日期。作白說：「大德僧聽！若僧時到僧忍聽，僧今不自恣，四月滿，當自恣，白如是。」詳細審定中，首先審定沒有危難的正常情況；從「若」字以下，說明遭遇危難的情況。第一部分又分兩點，首先引用律文加以確定。最先提到「律中」者，即是〈自恣犍度〉所說：諸比丘想在十四日、十五日自恣，佛陀說聽許。其次引述「急施衣戒」者，第一句泛指該戒；

【160-0007】資持記/05d_上四#56
【原文】次句別指戒中釋衣時應畜文，彼云：若自恣十日在〔七月六日〕得急施衣，受已，至一月〔無衣〕五月畜〔有衣也，此即時前開十日，後無所增。〕；乃至明日自恣應受〔十五受衣，十六自恣，故言明日。〕，一月五月外，更增九日〔謂初七得衣，前減一日，後增一日；
【譯文】下一句特指戒條中解釋「於衣時應蓄長衣」的文字，彼處說：如果在自恣前十天內〔即七月六日〕獲得急施衣，接受之後，在一個月〔無衣時〕或五個月內蓄持〔有衣時；這就是指在正常衣時前開許十天，其後並無所增加〕；乃至明天就要自恣而今日應當接受〔十五日受衣，十六日自恣，所以說明天〕，一個月或五個月之外，還要再增加九天〔意思是初七得到衣物，前面減少一天，後面增加一天；

【160-0008】資持記/05d_上四#57
【原文】乃至十五，前減九日，後增九日，故云次第增也。〕；此明十六自恣，合上犍度三日明矣。引〈增三〉中，律云：有三種自恣，十四十五月初日〔十六是黑月初〕。律云下，正定。此亦犍度中文。雖通三日，前二非竟，不符文意，故取十六也。律又下，二釋妨，初引文。
【譯文】乃至十五日得衣，前面減少九天，後面增加九天，所以說是依序遞增〕；這明確顯示了在十六日自恣，完全符合上述犍度的三天之說。引用增三法中，律文說：有三種自恣日，即十四日、十五日與月初第一天〔十六日即是下半月黑月之初〕。從「律云」以下，正式判定。這也是犍度中的文字。雖然通許這三天，但前兩天安居尚未竟期，不符合律文意旨，所以取定十六日。從「律又」以下，第二部分化解妨難，首先引用律文。

【原文】此出〈尼犍度〉中，恐人固執，故須釋通。此文且約處遠為言；準理，須云僧十五日，尼十六日。又尼近處，不勞隔日；如下文中，雙出二法是也。此下，正釋，初二句釋通。言相依者，疏云：僧須在前自恣，白眾治舉；既犯清淨，方合受尼故。及下，示通局。文既通三，今取十六；亦非專必，故云一期。
