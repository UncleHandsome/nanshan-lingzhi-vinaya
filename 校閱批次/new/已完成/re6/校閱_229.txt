# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【229-0001】01_行事鈔/10c_卷下之二#12
【原文】《四分》：木師出家，一切作器不應畜。制髮人出家，不得畜剃刀；眾僧得畜剃刀。木作器、角器，聽用盛油。若得衣順浣，開畜浣器及板、剪刀。若不解事數，聽用算子，以帒盛，懸杙上。為治病故，畜㓟刀、若煮藥銚，若銅釜、鐵釜、土釜，及三種瓶、煎餅𨫼、銅杓、銅鐏；眾僧亦得。若鉢不正，作鉢支；塵坌者，作蓋。若須薪、染草、牛屎等，無人處得持之，見白衣下著地；寺內得自移墼石材木等。擣藥須杵、臼、簸箕、篵、掃帚，並開。為治眼故，得畜瑠璃篦，若灌鼻筩。烟筩、吹火筩、若鉗、若椎、火把、煖水瓶、注水筩。并洗脚者供染槃洗脚器，所須應與。若得大小豆、麥、胡麻、粳米，應以鉢器為量，不得畜升斗秤；若穌油等須秤量者，聽刻木作鉢兩，齊四五兩作，準為斤數。《五分》，初如《四分》。後與他物，雖多猶瞋少，佛令僧私畜十解升合及秤。
【譯文】《四分律》說：木匠出家，一切木工器具都不應當私人蓄留。剃頭匠出家，個人不得蓄持剃刀；但僧團大眾（眾僧）得准蓄持剃刀。木製器具、牛角器具，聽許用來盛油。如果得到衣物需要順應清洗，開許蓄留洗衣器具、洗衣板及剪刀。如果不通曉算數法事，聽許使用籌算之子，裝在袋子裡，掛在木橛上。為治病之故，可蓄留割肉放膿的手術刀（㓟刀）、煎煮湯藥的藥銚，以及銅鍋、鐵鍋、陶土鍋，還有三種瓶（瓦瓶、鐵瓶、銅瓶等）、煎餅用的鐵鐺（𨫼）、銅杓、帶尖底的銅鐏；僧團大眾也可蓄持。如果鉢放不端正，可製作鉢座（鉢支）；若怕塵土沾染，可製作鉢蓋。如果需要柴薪、染色草、牛糞等物，在無人處可以自己手持，看見在家人時應當放下置於地上；在寺院之內，可以自己搬移磚坯（墼）、石頭、木材等。搗藥時所需的木杵、石臼、簸箕、盛物竹器（篵）、掃帚，全都開許蓄持。為了治療眼疾，得蓄持琉璃篦子；為了灌藥入鼻，得蓄持灌鼻筒。引煙出屋的煙筒、吹火筒、火鉗、鐵椎、火把、暖水瓶、注水筒。以及洗腳所用的染盤、洗腳器等，凡是必需之物都應當供給。如果獲得大豆、小豆、麥子、胡麻、粳米，應當以鉢具作為計量標準，不得私人蓄留升、斗、秤等衡器；如果是酥油等需要稱重量之物，聽許刻木製作如鉢般大小的木量具，以四五兩為一份，依此折準算作斤數。《五分律》起初規定如同《四分律》。後來因為分發給別人財物時，對方雖然分得多卻仍嫌少而起瞋心，佛陀便准許僧眾個人或寺院蓄置能容納十解（古量名）的升斗量器以及秤具。

【229-0006】02_戒疏/11a_卷三上之二#76

【譯文】【記文】戒本經文中，第一雙所勸諫事項中。首先解釋惡劣性情。「頑」是指頑劣愚昧，「戾」是指乖謬偏執。「無始」一詞，是形容其積習由來已久。「強我」一詞，是形容其我執極度兇猛熾盛。正以此為罪緣，才導致現今兇劣之態。「聞諫如怨」，指不喜歡聽聞良言勸告。

【229-0014】02_戒疏/11a_卷三上之二#84
【原文】【疏】「大德且止」者，出其理也。由倚傍故：一、傍略教「但自觀身行，不須見他過」，故言「且止」；二者，傍人，如上四種，故言「且止」也；三、種姓，謂同釋種故。
【譯文】【疏文】「大德暫且住口」這句話，點出了他為自己辯解的荒謬道理。由於有所依仗攀附：第一、攀附佛陀簡略教誡中說的「只要自己觀察檢點自心行為，不必去看別人的過失」，所以說「暫且住口」；第二、依仗自己是前述四種身分崇高之人，所以說「暫且住口」；第三、依仗種姓，自認與佛陀同屬釋迦種姓之故。

【譯文】【疏文】在第二對科判、私下勸諫（屏諫）的段落中。

【229-0018】02_戒疏/11a_卷三上之二#88
【原文】【疏】「莫不受諫」者，牒前拒詞；「當受諫」下，順理重誨。
【譯文】【疏文】「不要不接受勸諫」這句話，是引述前面抗拒勸導之詞；「應當接受勸諫」以下，則是順應正理重新給予教誨訓誡。

【229-0019】02_戒疏/11a_卷三上之二#89
【原文】【記】第二對，釋中，初科。言「順理」者，釋「當」義也。《經》中「如法諫」下，前拒僧云「莫向我說，我亦不向汝說」。故此諫令彼此相勸，硺磨成益。
【譯文】【記文】第二對解釋中，初科。所謂「順應正理」，是解釋經文「當（應當）」字的意涵。戒經中「如法諫」以下，是針對先前犯僧抗拒僧團所說「不要對我說，我也不對你們說」之語，所以在此勸導應當彼此相互規勸，切磋琢磨才能成就道業利益。

【229-0020】02_戒疏/11a_卷三上之二#90
【原文】【律】「如是佛弟子眾得增益，展轉相諫，展轉相教，展轉懺悔。」是比丘如是諫時，堅持不捨，彼比丘應三諫，捨是事故。乃至三諫，捨者，善；不捨者，僧伽婆尸沙。
【譯文】【律文】「這樣佛陀的弟子大眾才能得到道業增益，彼此輾轉相互勸諫，彼此輾轉相互教導，彼此輾轉發露懺悔。」當這位比丘受到這樣勸諫時，若是頑固堅持而不肯捨棄，那些比丘應當對其進行三次羯磨勸諫，令其捨棄這種抗拒行徑。直到三次勸諫為止，如果願意放棄，那很好；如果不肯放棄，就犯了僧伽婆尸沙罪。

【229-0021】02_戒疏/11a_卷三上之二#91
【原文】【疏】云「如是佛弟子眾得增益」者，道根日進也。
【譯文】【疏文】經文說「這樣佛弟子的僧眾便能獲得增長益處」，是指修道的善根日益增長精進。

【229-0022】02_戒疏/11a_卷三上之二#92

【譯文】【記文】勸勉增益中，初科。「道根」，即是指戒律行持。

【229-0023】02_戒疏/11a_卷三上之二#93
【原文】【疏】彼見我過，諫令不起。我見彼過，勸令不作。彼我迭為，故曰「展轉相諫」也。此謂未起之非。
【譯文】【疏文】對方看見我的過失，勸諫我令惡念惡行不再生起；我看見對方的過失，規勸他令過失不再造作。彼此相互督促，所以稱為「展轉相諫」。這是針對尚未發生的過失而言。

【229-0024】02_戒疏/11a_卷三上之二#94
【原文】【記】次文。「迭」，互也。「未起非」，對下已起令悔也。
【譯文】【記文】下一段文字。「迭」，即是輪流交互之意。「未起之過非」，是相對於下文所說對於已經造作的罪業令其悔過。

【229-0025】02_戒疏/11a_卷三上之二#95
【原文】【疏】我教彼修已、未之善，彼教我修曾、當兩福。彼我互為，故曰「相教」也。
【譯文】【疏文】我教導對方修習已經生起或尚未生起的善行，對方也教導我修持過去或將來的福德。彼此互相引導，所以稱為「相互教導」。

【229-0026】02_戒疏/11a_卷三上之二#96
【原文】【記】三中，「已未」、「曾當」，辭之互耳。
【譯文】【記文】第三段中，「已與未」、「曾與當」，只是詞彙交互使用罷了。

【229-0027】02_戒疏/11a_卷三上之二#97
【原文】【疏】我教彼悔，彼教我懺，彼我迭為，故曰「展轉懺悔」。對前為言，此除已起之惡也；對前修善，即是作持止行兩善。所以成者，功由善友相導。故云「大德當諫比丘，比丘亦諫大德」也。
【譯文】【疏文】我教導對方發露罪衍，對方教導我悔悟前愆，彼此交互為之，所以稱為「展轉懺悔」。相對於前面而言，這是為了除滅已經發生的罪惡；相對於前文的修善而言，這正屬於作持與止行這兩種善法。這一切之所以能夠成就，功德全在於善知識良友的相互引導教化。因此經文說「大德應當勸諫比丘，比丘也應當勸諫大德」。

【229-0028】02_戒疏/11a_卷三上之二#98
【原文】【記】四中，初正明。「對」下，對簡。初對相諫是未起，次對相教是福業。「所以」下，推所由。「故」下，引前通結。
【譯文】【記文】第四段中，首先正式解釋。「對」字以下，是相對簡別。最初相對相諫是針對尚未生起的過失，其次相對相教是針對福德善業。「所以」以下，推究成功的緣由。「故」字以下，引用前文做全面總結。

【229-0031】02_戒疏/11a_卷三上之二#101
【原文】【註】若未白前，惡性不受人語，一切吉羅。尼同僧犯。不犯者：若初諫便捨；非法訶諫，非法、非律、非佛所說者。若為無知人訶諫時，應語彼言「汝和尚、阿闍梨所行亦爾。汝當更學問誦經」，若其事如是，若錯說者，皆不犯。
【譯文】【註文】如果在僧團白四羯磨之前，性情頑劣不肯接受別人的規勸，一切都結犯突吉羅（輕垢）罪。比丘尼與比丘所犯相同。不犯的情況：若在最初口頭規勸時就立即放棄執著；僧團不依法度進行呵責勸諫，即不符合佛法、不符合戒律、不符合佛陀教導的非法勸諫。如果被無知且不守戒的人指責勸諫時，應當對那人說：「你自己的剃度和尚、阿闍梨的行徑也是如此。你應當再多去學習讀誦經典戒律。」如果事實果真如此，或者勸諫者說錯事實，被勸諫者抗拒皆不算犯戒。

【229-0032】02_戒疏/11a_卷三上之二#102
【原文】【疏】就辨相中，開「不犯」云「若其事如是」者，謂同《戒本》。道德勝緣，非可妄諫。
【譯文】【疏文】在辨明行相的註文中，開許「不犯」的條款中說「如果事實果真如此」，是指被勸諫者的行為符合《戒本》法度。其戒德與勝妙道業並無虧損，旁人絕不可胡亂對其勸諫。

【229-0033】02_戒疏/11a_卷三上之二#103
【原文】【記】釋注中。「同戒本」者，謂無所犯。或有妄諫，拒之無過。
【譯文】【記文】解釋隨文註記中。所謂「符合戒本」，是指自身毫無違犯。若有人妄加規勸，出言抗拒並無過錯。

【229-0034】02_戒疏/11a_卷三上之二#104
【原文】【律】諸大德！我已說十三僧伽婆尸沙法。九戒初犯，四至三諫。若比丘犯一一法，知而覆藏，應強與波利婆沙。行波利婆沙竟，增上與六夜摩那埵。行摩那埵已，應與出罪。應二十僧中出是比丘罪。若少一人，不滿二十眾出，是比丘罪不得除，諸比丘亦可訶。此是時。
【譯文】【律文】各位大德！我已經宣說了十三條僧伽婆尸沙之法。其中前九條戒律是一犯即刻成罪，後四條戒律則是經過三次勸諫仍不悔改才成罪。如果有比丘違犯了其中的任何一條法，明知犯戒卻故意隱藏掩飾，僧團應當強制給予其行別住（波利婆沙）的處分。履行別住期滿之後，僧團應當進一步加給予其六夜的行摩那埵處分。行完六夜摩那埵之後，僧團應當為其舉行出罪羯磨。必須在二十位清淨比丘僧眾之中，為這位比丘解除罪名。如果少了一人，不滿二十人的僧團為其出罪，這位比丘的罪名將不得消除，與會的各位比丘也應當受到呵責。現在正是適當時機。
