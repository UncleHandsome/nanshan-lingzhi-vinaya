# 校閱材料　第721檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【721-0001】02_戒疏/16a_卷四上之一#24
【原文】【記】次七戒中。初示業相，後以偈束。「屏露二敷」，亦約先語教人，前人為敷，我身捨去。「四期」。「索美食」，先以語索，前人施與，我食方犯。
【譯文】【記文】次一段七條戒中。先標示其造業行相，後以偈頌總括。「屏處與露地二處敷」，也是指先以言語教人鋪設，他人為其鋪設好後，自身卻捨棄離去。「四期」即四種約期同行。「索取美食」，指先以言語索求，他人布施給予後，自己吃了才成犯。

【721-0002】02_戒疏/16a_卷四上之一#25
【原文】【疏】後有五戒，自身作業假他口成。如「噉歎食」，假尼口歎，身業咽犯，餘者例同。偈言：「讚諫及二聽，與年不滿五。」且如違諫亦有言拒，今就一相，知別有義。
【譯文】【疏文】後面有五條戒，是自身造作行為，假借他人的口業而成立。例如「食用讚歎而得之食」，假借比丘尼口中讚歎，自身咽下食物時即構成犯罪，其餘各戒也是如此。偈頌說：「讚食、諫戒以及二聽，加上年齡不滿五條戒。」姑且以違諫戒為例，也有用言語抗拒的情形，現在只就其中一種顯著行相而論，應知尚有別的義理。

【721-0003】02_戒疏/16a_卷四上之一#26
【原文】【記】後五戒中。初示相。次偈括。贊諫二聽，與年不滿。「且」下，別簡諫戒。若取「言拒」，應在語業，今明不受，多就身論，故云「一相」。
【譯文】【記文】後面五條戒中。先標示行相。次以偈頌總括：讚歎得食、不受諫、屏處覆聽他人諍語戒、說戒時不攝耳聽法戒、與年不滿者受具。「姑且」以下，特為甄別違諫戒。若取「發言抗拒」，應歸在口業，現在說明不受規勸，多就身體舉止而言，所以說「就一種行相」。

【721-0004】02_戒疏/16a_卷四上之一#27
【原文】【疏】大分第二，次有七戒，語家止業，共身心犯。偈言：「覆背足非時，家真不與欲。」
【譯文】【疏文】大分類中的第二類，接著有七條戒，是口語的止業與身業、心意共同構成犯罪。偈頌說：「覆、背、足、非時，家、真、不與欲。」

【721-0005】02_戒疏/16a_卷四上之一#28
【原文】【記】第二，語止七戒。並有教法，由口不作，身違成犯故也。偈中：覆背足非時，家真不與欲。
【譯文】【記文】第二類，語止七條戒。都有相應的教法軌範，由於口頭上不去行持，身體違背便構成犯罪。偈頌為：覆藏、背請、足食、非時入村、入他家、真實施（淨施問主著戒）、不與欲。

【721-0006】02_戒疏/16a_卷四上之一#29
【原文】【疏】覆藏一戒，諸解不定。《伽》、《母》云「意業成犯」，此就本為言也。《善見》云「身心犯」者，由見聞他犯，懷覆不說，此通口業，未可取分。今云：聞過言陳，本自無罪，止口不露，意懷覆故，身為過本，故兩取之。
【譯文】【疏文】覆藏這一條戒，各家的解釋並不一致。《摩得勒伽》與《薩婆多毘尼母》說「在意業構成犯罪」，這是就其根本發心而言。《善見論》說「身心二業成犯」，是由於見聞到他人犯戒，心中懷著掩蓋之意而不說，這其實通於口業，但文中未明確劃分。現在的判定是：聽到過錯而發言陳述，本來就沒有罪，若是閉口不揭露，心中懷有覆藏之意，身體即是過患的根本，所以身口兩者都取。

【721-0007】02_戒疏/16a_卷四上之一#30
【原文】【記】別釋中。先引諸解。《伽》、《母》就「意」，意即是通，犯相難顯，不可全用。《見論》「身心」通別齊舉，「見聞」是身，「懷覆」即心。據云「不說」即是口止，故「通口業」，但文不標顯，故「未可分」。「今」下，判定，即通三業。捨通就別，指歸身、語，結屬當科，故云「兩取」。意在其中，不言可鑒。
【譯文】【記文】個別解釋之中。先引用各家見解。《伽論》、《母論》歸於「意業」，意業具有共通性，罪相難以彰顯，不可全盤採用。《善見論》將「身心」通別一併舉出，「見聞」屬於身業，「懷覆」即是心業。依據其所說「不說」即是口業之止，所以「通於口業」，只是文中未明確標出，所以說「未可劃分」。「現在」以下做出判定，即通於三業。捨去共通的意業而就具體業相，歸指於身、語二業，結罪歸屬當科，所以說「兩者都取」。意業已融攝其中，不用明說便可明瞭。

【721-0009】02_戒疏/16a_卷四上之一#32
【原文】【疏】有十二戒，教人同犯，餘即是輕。偈云：「掘壞牽用勸，恐然藏殺飲，無根捉落寶，自作教他同。」此十二戒，但使教人，縱不為己，作即同犯。
【譯文】【疏文】有十二條戒，教導他人同得重罪，其餘情況則較輕。偈頌說：「掘、壞、牽、用、勸，恐、燃、藏、殺、飲，無根謗、捉落寶，自作與教人同等犯。」這十二條戒，只要教唆他人，縱使不是為了自己，對方去作了即與自作同犯重罪。

【721-0010】02_戒疏/16a_卷四上之一#33
【原文】【記】二、自作教人，初十二戒。「餘即輕」者，無教人同犯故。偈詞對前，尋之可解。
【譯文】【記文】第二門自作教人，最初的十二條戒。「其餘則較輕」，是因為沒有教他人同犯重罪的情況。偈頌文辭與前文相對照，推尋便可明白。

【721-0011】02_戒疏/16a_卷四上之一#34
【原文】【疏】更有十戒，教人不為己，無問心之輕重，但得小罪。其相如何？偈云：「屏露與尼衣，高牀下七戒。」此之十戒，教比丘作，若為己者，能教犯提，受使犯吉。若不為己，受使犯提，能教犯吉。
【譯文】【疏文】更有十條戒，教他人若不是為了自己，不論其起心是輕是重，都只得小罪。其行相如何？偈頌說：「屏露與尼衣，高床下有七戒。」這十條戒，若是教導比丘去做，如果為的是自己，能教者犯波逸提，受使者犯突吉羅。如果不是為了自己，受使者犯波逸提，能教者犯突吉羅。

【721-0012】02_戒疏/16a_卷四上之一#35
【原文】【記】次十戒中。互通輕重。所以前標「不為己」者，且欲對上示不同故。「其相」下，列示。「屏、露」即二敷也。「此」下，正明能所互犯輕重。
【譯文】【記文】次一科十條戒中。教人與受教者互通輕重。之所以在前面標出「不為自己」，暫且是為了對照上一段以顯示不同。「其行相」以下列出示範。「屏露」即是二處敷設。「這十條」以下，正式說明教者與受教者互相違犯的輕重。

【721-0013】02_戒疏/16a_卷四上之一#36

【721-0016】02_戒疏/16a_卷四上之一#39
【原文】【疏】有三十戒，性與理違，悔犯事淨，集業未遣，要傾我倒，苦根方止。餘六十戒，但有事違，不無譏醜，故違教網。
【譯文】【疏文】有三十條戒，其本性即與正理相違，即便透過悔過使事相清淨，但積聚的業道尚未除滅，必須徹底破除我執顛倒，痛苦的根源方能止息。其餘六十條戒，只屬於事相上的違犯，不免招致世人的譏嫌醜陋，所以故意違背了佛陀的教誡羅網。
