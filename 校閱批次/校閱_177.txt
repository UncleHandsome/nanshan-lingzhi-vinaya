# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】【記】次釋入中。六根、六塵相入，名「十二入」，故亦名為「處」。然「色」名通，莫辨體相，故離根塵，以開迷者。
【譯文】【記文】接著解釋「入」的文段中。六根與六塵互相涉入，稱為「十二入」，所以也稱為「十二處」。然而「色」的名稱很寬泛，難以分辨其具體體相，所以拆開六根與六塵，以此啟發迷惑的人。

【177-0002】02_戒疏/08d_卷二下之一#31
【原文】【疏】通迷色心，為說界分。色為十一分，心為七分。至於藥治，可例上也。
【譯文】【疏文】如果色法和心法兩者皆迷惑，就為他說十八界。色法分為十一種，心法分為七種。至於用藥對治的方法，可以比照上面所說。

【177-0003】02_戒疏/08d_卷二下之一#32
【原文】【記】後釋界者。就上意根，更開六識，為十八界。「界」是別義，體相各異故，亦是因義，相假成用故。然法塵二界，兼通色心，故使經論開合不定：或攝在心，則色十心八；或分為二，則十色七心，各兼少分。今收於「色」，故云「十一」。「至於」下，示上入界通須勸治。良由根、境和合起用，造諸妄業，遂受輪轉。今既了達，隨境制根。然此諸根，心為其主，亦當「常爾一心」等。界中加「識」，對治亦爾，故云「例上」也。
【譯文】【記文】最後解釋「界」的文段。在上面的意根之外，再開展出六識，合為十八界。「界」是界限分別的意思，因為體相各自不同；也是因的意思，因為互為條件而生起作用。然而法塵與法界，同時涵蓋色法與心法，所以使得經論中的歸納開合並不固定：有的歸納在心法，則色法有十種、心法有八種；有的分為兩種，則色法十種、心法七種，各自兼帶少部分。現在將它收攝在「色法」之中，所以說「十一種」。從「至於」以下，指出上面「入」和「界」都必須勸令對治。實在是因為根與境和合生起作用，造作種種妄業，於是遭受生死輪迴。現在既然通達明了，就要隨順外境克制根門。然而這些根門，心是它們的主宰，也應當「經常一心專注」等。十八界中增加了「識」，對治方法也是如此，所以說「比照上面」。

【177-0022】02_戒疏/08d_卷二下之一#51
【原文】【疏】若「正受」者，四種：一、想正受，初禪覺觀俱也；二、無想正受，二禪無覺觀也；三、隨法正受，三禪樂由隨也；四、心想正受，四禪有無想，外人計為滅心，為除此計，故言「心想」也。
【譯文】【疏文】說「正受」，有四種：第一、想正受，即初禪具有尋、伺（覺、觀）；第二、無想正受，即二禪沒有尋、伺；第三、隨法正受，即三禪的安樂隨順而生；第四、心想正受，即四禪中具有無想定，外道執著此為心念滅盡，為了破除這種執著，所以稱為「心想」。

【177-0025】02_戒疏/08d_卷二下之一#54
【原文】【疏】剋證在己為「得」，遂因為「果」，酬因為「報」。無漏是「果」，而非「報」攝。

【177-0026】02_戒疏/08d_卷二下之一#55
【原文】【記】略釋中。初言「身念」。下引《律》釋。初句標觀功用。繫念修學，故云「狎習」。「乃至」者，彼續云「修習增廣，如調伏乘，守護觀察，善得平等，已得決定」，方接下文。遠離諸有，故「無艱難」。斷貪絕縛，故「得自在」。「受心法」者。「八正」。「四如意足」。「五根、力」。「四正勤」。「三空」。「四正受」即四禪天定：初禪具五支；二禪具四支；三禪五支；四禪四支。「十一支道」者：一支道，二支道，三支道，四支道，五支道，六支道，七支道，八支道，九支道，十支道，十一支道。「三慧」。「修」，「慧」，「見」。
【譯文】【記文】簡要解釋的文段中。首先說明「身念」。下面引用《律》文解釋。第一句標示觀法的功用。繫念於此精勤修學，所以稱為「狎習（親近依賴）」。所謂「乃至」，是因為彼處經文接著說「修習增廣，如調伏乘，守護觀察，善得平等，已得決定」，然後才接續下文。遠離一切三有，所以「沒有艱難」。斷除貪愛阻絕繫縛，所以「獲得自在」。「受心法」等文句。「八正」。「四如意足」。「五根、力」。「四正勤」。「三空」。「四正受」就是指四禪天的禪定：初禪具備五支；二禪具備四支；三禪具備五支；四禪具備四支。「十一支道」是指：一支道、二支道、三支道、四支道、五支道、六支道、七支道、八支道、九支道、十支道、十一支道。「三慧」，即修、慧、見三者（配屬修、思、聞三慧）。

【177-0027】02_戒疏/08d_卷二下之一#56
【原文】【律】「我知是，我見是。」
【譯文】【律文】「我知此法，我見此法。」

【177-0028】02_戒疏/08d_卷二下之一#57
【原文】【疏】文言「我知是」者，釋上「境虗」，知諦不妄也。「我見是」者，亦同也。
【譯文】【疏文】經文中說「我知是」，是解釋上面「境界虛假」，自稱了知真諦而非妄語。「我見是」，也是同樣的意思。

【177-0029】02_戒疏/08d_卷二下之一#58
【原文】【記】釋我知中。前引《僧祇》，「知」對「四諦」，故云「知諦」。「見亦同」者，應云「見通不妄」。
【譯文】【記文】解釋「我知」的文段中。前面引用《僧祇律》，「知」對應「四聖諦」，所以說「了知真諦」。「見亦同」，應當說是「得見神通而非妄說」。

【177-0036】02_戒疏/08d_卷二下之一#65
【原文】【疏】下列不淨觀、四禪、四空，例是凡法，有誑俱重者。《多論》答云：「是甘露初門，一切聖人由之而入，故言過人法也。」
【譯文】【疏文】下面列出不淨觀、四禪、四無色定，比照凡夫之法，只要有欺誑都屬於重罪。《薩婆多論》回答說：「這是甘露法門的初階，一切聖人都由此而入道，所以稱為過人法。」

【177-0037】02_戒疏/08d_卷二下之一#66
【原文】【記】次禪觀中。初牒問，以疑凡法而得重故。下引《論》答，以決所疑。「甘露」者，味中最勝，以喻出世無漏聖道。入道之始，必由五停，「不淨」居首，故云「初門」。
【譯文】【記文】接著說明禪觀的文段。首先引述問題，因為懷疑凡夫法何以會判為重罪。下面引用《論》文回答，以解決這層疑惑。「甘露」，是滋味中最殊勝的，用以比喻出世間的無漏聖道。入道的起始，必定要經過五停心觀，「不淨觀」位居首位，所以稱為「初門」。
