整體譯文流暢、術語（波逸提／突吉羅／五緣等）處理得當，方向是對的。以下按「須改」與「宜調」兩層列出問題，並附建議改法。

---

## 一、明顯誤譯（建議修正）

**1. 【835-0004】「俗情又異」譯錯**
譯文作「世俗民眾的**身材長短**也有差異」——這是把「俗情」誤解為體型。下一則【記】已明說：「『俗情異』者，**各執一端，容生諍也**」，指的是世俗人情各執己見、易起諍論，與身高手指長短無關。
建議：「…各國的度量制度不同，世俗人的見解又各執一端（易生諍論）。」
另：「則之永無乖異」的「乖異」是**不一致、有出入**，譯成「歧異與爭端」中的「爭端」是添譯。

**2. 【835-0014】+【835-0015】「含（合）坐」語意含糊，易誤解**
譯文「若是**連同衣服一起坐下**」，讀者會理解成「坐在衣服上」。原文「含坐」＝【記】「和衣坐」，是指**衣上黏著的兜羅綿未拂去，就這樣（帶著棉絮）坐下**。
建議 0014：「若在路上行走，風把綿絮吹黏到衣上，未拂去就帶著它坐下，犯突吉羅（越毘尼）罪，故應先拂去。」
建議 0015：「『合（含）』是說棉絮仍附在衣上，就和衣而坐。」

**3. 【835-0014】「隨坐」不是「隨意坐臥」**
「乃至隨坐，一一提」＝**每坐一次，各結一波逸提**。「隨」是「每、隨著」，非「隨意」；律文只說「坐」，「臥」為添字（0015「後坐復犯」同樣加了「臥」）。
建議：「乃至後來每坐一次，就各犯一個波逸提罪。」

**4. 【835-0015】「狀如臺故」不宜加「蓮」**
蒲臺是蒲草的花穗，元照只說「狀如臺」，譯文「因為形狀像**蓮臺**而得名」是無據的增譯。
建議：「就是蒲草的花（穗），因形狀像臺（座）而得名。」

**5. 【835-0022】「望其得福，而反得殃」主體錯置**
譯文「原本指望**供養他**能得到福報」，把指望得福的人變成了世人；原意是**這位工匠（為比丘作針筒）本望得福，結果反而招殃**，故世人譏嫌。
建議：「（他）本指望作福，結果反而招來禍殃。」
另「導致**全家**缺乏衣食」——「全家」原文所無，可刪或作「衣食無著」。

**6. 【835-0005】「佛唯有一，身量常定」語意錯位**
譯文「佛陀的**身量常住標準、獨一無二**」把「唯有一」併到「身量」上，且「常住」易與教理「常住」混淆。原文是兩個理由：**佛只有一尊（不像世人眾多、各國各異）＋身量恆定**，故可為準的。
建議：「『唯以佛為準』，是因為佛只有一尊，身量恆常固定，可作準確標準。」
另標題「釋佛指中」譯作「依**佛手**為標準」不妥，此處是**佛指（指量）**，下文才「搩、指」並舉。

**7. 【835-0001】「若脫脚者」宜再斟酌**
譯為「床腳已經**脫落**者」偏於偶然損壞；律中「脫腳床」多指腳可拆卸／活腳之床，此處不犯文與「截而用之」並列，語意應是**把床腳脫去（卸除、不用高腳）**。
建議：「或是脫去（卸除）床腳者。」（此點建議查前後疏記用語再定）

## 二、用詞與精確度（宜微調）

| 條號 | 問題 | 建議 |
|---|---|---|
| 0002 | 「教諸比丘作尺量法」未點出說法者 | 補「佛陀教導諸比丘製作（床腳）的尺量之法」 |
| 0003 | 「五種如上」只譯「所說的內容」，過於空泛 | 補明所指（前五種床／臥具之類別），或加註「詳前露敷戒注文」 |
| 0004 | 「約人用尺」逕譯為「常人的**手指**」 | 可作「以世人的尺度為量準」，較貼原文（記文才落到「佛指」） |
| 0006 | 「坐褥」縮小了範圍 | 戒兼大小臥褥、坐褥，作「褥墊」較妥 |
| 0008 | 「**容**損物命」＝可能；「**多**生諸蟲」＝常生 | 「很可能」語氣過重，改「可能」；「極容易」改「往往／容易」 |
| 0009 | 「四意」譯為「四種**意涵**」 | 應是「四點制戒理由」；「且舉一意」可註明即「生蟲損命、違慈壞行」這一點 |
| 0015 | 「**文**舉牀者」譯成「**經文**」 | 此處是戒本／律文，非經文，宜統一作「戒本文句」 |
| 0015 | 「這個字**字**偏旁」贅字；「合從衣」未點明結論 | 「『蓐』字應從『衣』旁，即應作『褥』」 |
| 0015 | 「明深防」 | 可作「更細密的防護（防微杜漸）」，比「深層防護之法」自然 |
| 0017 | 疏題原作「**牙角**鍼筒戒」，譯文加「骨」 | 若要忠於疏題可保留「牙角針筒戒」，或加註說明與律題一致 |
| 0018 | 「用功極多」譯為「工藝極為繁複」 | 原意是**耗費工夫（人力）極多**，非工藝繁複 |
| 0019 | 「『加』下」譯為「『加上』以下」 | 疏文作「加以」，宜作「『加以（損他家業）』以下」 |
| 0020 | 「是骨牙」漏「角」 | 此戒實制骨、牙、角三材（見律題與緣起），宜補「角」或註明「疏文舉略」 |
| 0014 | 引文起首「乃至」譯為「甚至」 | 此處「乃至」多為引文省略語，可作「（應拆褥）…乃至抽出綿料、抖擻令盡」 |

## 三、譯得好的地方
- 【835-0003】「除入梐孔上」＝入孔榫頭不計入八指，理解正確，這是本段最容易譯錯處。
- 【835-0014】「先除後悔」的懺悔次第（先除去兜羅綿再悔過）掌握準確，【835-0015】並有對應說明。
- 【835-0009】《多論》四意中「臥軟煖則後不堪麤硬」譯得貼切。
- 「越」判為突吉羅、「提」判為波逸提，罪名對譯一致，沒有混亂。

**最需優先處理的是第 1、2、3、5 項**（俗情、和衣坐、隨坐、望其得福），因為這四處會實質誤導讀者對文義與犯相的理解。
