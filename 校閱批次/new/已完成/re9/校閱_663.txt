# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【663-0001】05_拾毗尼義鈔/04b_卷中之二#28
【原文】第四滅罪諍及以治人者自言艸覆罪諍俱滅罪處一種不滅罪俱滅諍自餘四種唯滅諍而無罪可滅其七中六種但滅諍不治人以人無過故諍是𩰖亂故須滅之罪處所亦滅諍亦治人諍須滅如上以人諱罪觸僧故須治人與處所竟應奪三十五事又五分云本言治有二種一可悔二不可悔不可悔者與作盡形壽不可悔白四羯磨餘無此過故不論解此中問法之與藥有何別答如現前毗尼法者簡集智慧羯磨是也藥者正用三藏教法判者是也不如憶念等三法藥同體今疏家作法藥通解所以不出法藥體者一解滅不究竟故若作此解不出法者且得如是藥是究竟何以不出此責難自言毗尼諍應得滅從多論同言未滅第二作不定解者覔中三品上中下定言犯二諍執情流轉不定用藥無準故不出義可爾又解餘四所以不出法藥者現前通滅四諍智出何體若欲具論謂皆竝用正欲隨分少序恐謂常定謂皆滅諍是故隱之如現前中五法三法人有增減等是名不定雖簡眾白竟諍復未滅故言不究竟如自言或對一二三四或自引犯不犯輕重等故知無準雖假和白諍罪未滅故知亦不究竟多人語中三種行舍羅五四不同故知無準雖作差白羯磨等諍情未息滅亦不究竟艸覆中用法應定但以滅不究竟是故不出法體。
【譯文】第四、說明滅除罪事、諍事以及懲處當事人：在自言與草覆地中，罪與諍全部滅除；罪處所這一種不滅除罪，但滅除諍；其餘四種滅法只滅除諍事，而無罪可滅。在七滅諍中，有六種只滅諍而不懲處人，因為當事人並沒有過失，爭諍只是大眾心生擾亂，所以應當平息；罪處所既要滅諍，也要治處當事人——諍端必須平息如前所述，而當事人隱瞞罪行、觸惱僧團，所以必須予以懲戒。給予罪處所羯磨之後，應剝奪其三十五項僧事權利。又《五分律》說：原本所說的懲治有兩種，一是可悔，二是不可悔；不可悔者，應當對他作盡形壽不可悔的白四羯磨，其餘各法沒有這種過咎，所以不論。在此問：「法」與「藥」有何差別？答：如在現前毘尼中，「法」是指揀選聚集具備智慧的僧眾所作的羯磨；「藥」是指真正運用經律論三藏教法來裁定是非者。這與憶念等三滅法不同，那三法的「法」與「藥」體性相同。現在律疏家將法與藥作共通解釋，之所以沒有明確列出法藥體性，一種解釋是因為平息得不夠究竟徹底：如果作此解釋，而不標出羯磨法體，暫且說得通，但三藏教藥本身是徹底究竟的，何以也不標出？這正是要責難反詰自言毘尼：諍端應當已得滅除，但依《薩婆多論》等則認為並未徹底消滅。第二種解釋是作「不定解」：覓諍之中上、中、下三品是固定的，言諍與犯諍這兩種諍的情執輾轉流動不定，用藥沒有固定標準，所以不予標出，這在義理上是行得通的。另一種解釋說，其餘四種滅法之所以不標出法藥體性，是因為現前通滅四種爭諍，智慧究竟以何為法體？若想完全論述，就是全部並用；若只想隨分稍作介紹，又恐學者誤以為是固定常軌、以為已經完全滅諍，所以隱而不發。如同現前法中有五法、三法，人數有增有減等，這都稱為不定；雖然已經揀選大眾作白羯磨完畢，諍事卻尚未平息，所以說不究竟。如自言中，或者對一人、二人、三人、四人，或者自己招供有犯、無犯、罪重、罪輕等，由此可知沒有固定準則；雖然藉助和合宣白，諍事與罪業並未完全滅盡，所以知道也是不究竟。在多人語中，三種發籌表決方式，五德或四德之僧各有不同，所以知道無定準；雖然作了差派行籌的白羯磨等，爭諍之情未息，滅諍亦不究竟。草覆地中，所用的法應當是固定的，只因為滅得不徹底，所以不標明法體。

【663-0002】05_拾毗尼義鈔/04b_卷中之二#29
【原文】第五滅人多少者二通五局如律中解依阿含經要羅漢被舉得作憶念凡夫不得何故凡夫有故犯戒羅漢無故犯止誤犯耳善見云憶念毗尼者為愛盡比丘至那含不為凡夫婆論云比丘比丘尼現前三眾不現前與憶念羯磨不癡罪處亦爾婆多云若比丘犯戒內爛舉眾共知不須自言直爾遣出伽論云若不語彼而擯比丘得成擯僧犯吉羅不作憶念亦如是不作白羯磨亦得成擯眾僧犯吉不現前如是祇律云覔罪相羯磨人盡形行八事一不得與度人二不得與受具戒三不得與人作依止四不得受比丘按摩供給五不得作比丘使六不得受次第差會義云都盡時得七不得為僧作說法人八不得與僧作說毗尼及羯磨人。
【譯文】第五、說明滅諍人數的多寡：二種滅法通於大眾，五種局限於特定人數，皆如律文所解。依據《阿含經》，必須是阿羅漢遭到舉發，才可以作憶念羯磨，凡夫不得作。為什麼呢？因為凡夫會有故意犯戒的可能，阿羅漢沒有故意犯戒，只有無心誤犯罷了。《善見律》說：憶念毘尼是為斷盡貪愛的比丘乃至阿那含所設，不為凡夫而設。《薩婆多論》說：比丘、比丘尼須在現前，式叉摩那、沙彌、沙彌尼這下三眾不須現前，即可給予憶念羯磨；不癡、罪處所羯磨也是如此。《薩婆多論》又說：如果比丘犯戒、內部德行潰爛，全體僧眾皆已知曉，不須等待他自言供認，直接將他逐出即可。《伽論》說：如果不告知當事人就直接擯黜比丘，擯黜依然有效，但僧眾犯突吉羅罪；不作憶念羯磨也是如此；不作白羯磨就逕行擯黜，擯黜同樣有效，但大眾僧犯突吉羅；不現前作法也是如此。《僧祇律》說：被作覓罪相羯磨的人，終生必須遵行八事：一、不得度人出家；二、不得為人受具足戒；三、不得為他人作依止師；四、不得接受其他比丘的按摩侍奉供養；五、不得充當比丘的差使；六、不得接受依僧次輪流的齋會請供——論義說等到全體僧眾都輪遍時方可獲得；七、不得為僧團作說法人；八、不得為僧團作宣說毘尼及主持羯磨之人。

【663-0003】01_行事鈔/12a_卷下之四#6
【原文】次明供給法。《五分》：無淨人處，聽比丘自洗燒器，著水，令人洮米著中，比丘然火使熟；更從淨人受，持與病人。《五百問云》：病比丘，山澤無人處，日中不得往還者，比丘得為作食七日；先淨米、受取，作之。《寶梁經》、《蘭若習禪經》廣明獨住患比丘法。《僧祇》：病人有九法成就，必橫死：一知非饒益食貪食，二不知籌量，三內食未消而食，四食未消而摘吐，五已消應出而強持，六食不隨病，七隨病食而不籌量，八懈怠，九無慧。又云：若病人，衣鉢外，有醫藥直者，取之供給；無者，眾僧應與；若僧無者，彼有貴價衣鉢，當貿賤者，供給病者。若病人惜衣鉢者，應白僧言：「此病人不知無常，慳惜衣鉢，不肯貿易。」白僧已，軟語說法，使得開解，然後為貿；若復無者，應外乞與之。若僧中，取好食與看病人。又不得愛惜自業，而不瞻視。《四分》：看病人五德，乃至為病人說法，令得歡喜；己身於善法不減，如〈衣法〉中。《善見》：若病無湯藥，得以華果飲食餉人，求易湯藥，不犯。餘如《僧祇》三十八卷中，廣明看病法及死法。《十誦》：當隨病人所須，問病因緣，覓師求藥；日到僧厨問，有病人食不？若無，取僧所供給庫中物；無者，當為外求，應從善好名聞福德比丘索。《五分》：每到行粥時，應問別有病人粥不？若無，應先與病人，然後行與僧也。《十誦》：病人得藥差者，但是佛僧中不淨、殘宿、惡捉、不受、內宿，並得服之。《善生經》：瞻病人不應生厭。若自無物，出求之；不得者，貸三寶物；差已，依法十倍償之。《五百問》云：看病人，將病人物，為病人供給所須；不問病者，或問，起嫌，並不得用；若已取者，應償；不還，犯重。比丘病困，不得闕三衣鉢而作福德，若不即有故弊衣鉢受持者，犯墮。《摩得伽》云：不淨膏肉，雜鹽煮，病者開，《四分》：若病人不能至大小行處，當近處鑿坑，安大小便；若不能者，屋中安便器；不離床者，聽穿床作孔，便器著下。不得唾吐污地等。
【譯文】其次說明供給物資的方法。《五分律》記載：在沒有淨人（寺院服勞役之俗人）的地方，聽許比丘自己清洗炊具器皿、加入清水，讓他人淘米放入鍋中，比丘點火煮熟；然後再從淨人手中接受此食（受法），拿去給病人。《五百問》說：生病的比丘若身處山林水澤無人之處，正午前無法往返乞食者，比丘可以為其做飯七天；但應當先將米弄淨、接受之後，再去烹煮。《寶梁經》、《蘭若習禪經》中廣泛說明了獨居患病比丘的作法。《僧祇律》說：病人若具足九種情況，必然導致非時橫死：一是明知無益於病情的食物卻貪吃；二是飲食不知節制適量；三是肚裡的食物尚未消化又接著吃；四是食物未消化卻去摳喉催吐；五是已經消化該排泄卻強行憋忍；六是飲食不契合病情；七是雖吃對應病情的飲食卻不知節量；八是懈怠不調養；九是缺乏智慧。又說：如果病人除了三衣一缽之外，還有可換作醫藥費用的財物，就取來供給其醫療；如果沒有，僧團大眾應當提供；如果僧團也沒有，而病人有昂貴的高價衣缽，應當將其賣掉換成廉價的，餘款供給病者。如果病人吝惜衣缽，瞻病者應當稟白僧眾說：「這位病人不識無常，慳吝顧惜衣缽，不肯變賣交易。」向僧眾稟白之後，以柔和的話語為他說法，使其心地開解領悟，然後再為他變賣；如果依然沒有資財，應當向外界化緣乞求來給予他。若在僧團中，應當選取上好的食物給予照看病人的人。照看者也不得只顧愛惜自己的個人道業，而不去瞻視照料。《四分律》記載：看病的人應具足五種德行，乃至包括為病人說法、令其心生歡喜；照看者自身的善法亦不虧減，如〈衣法〉中所載。《善見律》說：如果生病而缺乏湯藥，可以用花果飲食饋贈他人，以求換取湯藥，這樣做不犯戒。其餘如《僧祇律》第三十八卷中，廣泛說明了看病之法與處理死亡之法。《十誦律》說：應當隨順病人所需，詢問其生病的緣由，尋找醫師、乞求藥物；每天到僧團廚房詢問，是否有病人專用的飲食？如果沒有，就取僧團平時庫存供給的物品；如果還是沒有，應當為其向外化緣求取，應向善良、有名望、有福德的比丘索求。《五分律》說：每次分發晨粥時，應當詢問另外是否有病人的粥？如果沒有特別備辦，應當先舀給病人，然後再分發給其餘大眾僧。《十誦律》說：病人若得到此藥病能痊癒的話，凡是佛僧之中被視為不淨、隔宿殘留、不如法拿取、未經正式受與、藏於屋內過宿的食物，都可以開緣服用。《善生經》說：照看病人者不應生起嫌厭心。如果自己沒有物品，應當外出求取；求不到的，可以暫時借貸三寶之物；病癒之後，依法當十倍償還。《五百問》說：看病的人，若拿取病人的物品來供給病人的所需，如果不先詢問病人，或者詢問了病人卻引起病人的嫌怪，都不得擅自使用；如果已經取用了，應當賠償；若不歸還，則犯重罪。比丘在病困之中，不得缺免三衣一缽而隨便拿去作福德變賣，如果沒有立即拿陳舊破損的衣缽來如法受持替代，便犯墮罪（波逸提）。《摩得伽》說：不清淨的膏肉，若摻鹽同煮，對病僧開許食用。《四分律》說：如果病人無法走到排泄大小便的場所，應當在近處挖坑，供其安便大小溺；如果連這也做不到，就在屋內放置便器；如果病人無法離床，聽許在床上鑿出孔穴，將便器置於床下。不得隨地吐痰口沫而染污地面等。

【663-0004】資持記/16a_下四#5
【原文】若無下，次明無乘往求。不繞塔等，恐遲滯故。及共迎者，謂召檀越往迎，同上比丘也。若路下，次明尼眾。同異可見。闍維，此云焚燒。俗嫌遠送，不令見故。餘下，後明下眾。文略不出，故令準之。三中。初句指前聖制，次句勸依，下二句指廣，即《僧祇》文。供給中，初科。《五分》唯開自煮。
【譯文】從「若是沒有」以下，接著說明沒有車乘而必須徒步前往求助的狀況。不繞行佛塔等處，是唯恐耽誤時間導致行程延宕的緣故。至於「共同迎接」，是指延請護法檀越一同前往迎接，其道理與前述接引比丘相同。從「假若在路上」以下，接著說明尼僧大眾的情形，彼此相同與差異之處清晰可見。「闍維」在漢語中翻譯為焚燒。這是因為俗人嫌惡屍穢，所以應挑往遠處，不令俗人看見的緣故。從「其餘」以下，最後說明位階在下的沙彌等眾，律文中略過沒有詳載，所以應當比照辦理。在第三段中，首句指陳前面聖者所立的戒制，次句勸勉大眾切實遵循，後兩句則指引詳備的文獻，指的便是《僧祇律》的經文。在「供給物品」這部分的第一科，《五分律》中僅僅開許自行煮食。
