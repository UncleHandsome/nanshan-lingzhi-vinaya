# 校閱材料　第768檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【768-0001】03_業疏/03a_卷一之三#13
【原文】初釋集法，法有三位。初眾法中，科分云「初集法」者，總標前段；「自分二」者，別分僧法也
【譯文】起初解釋集法，羯磨法共有三個位次。在最初的眾法之中，科判中說「初集法」是總括標示前一段；說「自身分為二」則是分別劃分眾僧之法。

【768-0002】03_業疏/03a_卷一之三#14
【原文】言僧法羯磨略有一百三十四者，總舉也，非謂攝盡。數是泛張，故稱略也，餘如上解
【譯文】所謂僧法羯磨大略有一百三十四種，這是總體列舉，並不是說已經統攝窮盡。數量只是廣泛鋪陳，所以稱為「略」，其餘如上面所解釋。

【768-0003】03_業疏/03a_卷一之三#15
【原文】舉大數中，初科指如上者，即前總義分廣中云「隨事無量，何止前數」是也
【譯文】在列舉大數之中，第一科所指「如上面所說」，就是前面總論義理分判廣略時所說的「隨事而論有無量法，何止前面的數量」，即是此意。

【768-0004】03_業疏/03a_卷一之三#16
【原文】有三羯磨攝一切者，隨相顯法，互周事境，不可收盡；以法從緣，不過三法，皆成業行，故以三教攝之，不隨事境定其數也。不同《十誦》恰列百一，終非通被，故此不論。若準此收，但據眾法；若人通於僧別，云三種、五種一切攝盡也
【譯文】所謂「有三種羯磨統攝一切」，是因為隨著事相顯發教法，交錯周遍於一切事境，無法全部收錄窮盡；若以法依從緣起來論，不過就是這三種羯磨法，都能成就律儀業行，所以用三種教法來統攝它，而不隨著外在事境去固定其數量。這不同於《十誦律》恰恰只列出一百零一種，終究不能周遍被及，所以這裡不採用其說。如果依照這種方式來收攝，只是依據眾僧之法；如果按僧人而通論眾法與別法，那麼說三種、五種羯磨法，就能將一切羯磨收攝窮盡了。

【768-0005】03_業疏/03a_卷一之三#17
【原文】釋注中三：初牒釋。隨相顯法，則數不可限，如上大數略舉而已；以法從緣，則總歸三法，故三羯磨攝盡一切。隨相從緣，竝目事境。互，即是徧。「不下」二、點異部，如前已示。「若下」三、顯通數。通僧別者，兼後對念，合僧為一，故總有三；開僧為五，僧別齊開，則為八、九
【譯文】在解釋注釋之中分為三點：首先標牒並解釋。隨著事相顯發教法，則數量不可限量，如上面大數只是略微列舉而已；以法依從緣起，則總體歸於三種羯磨法，所以三種羯磨能統攝窮盡一切。「隨相」與「從緣」，都是指稱事境。「互」就是周遍的意思。自「不」字以下第二點明其他部派之說，如前面已經指示。自「若」字以下第三顯明通攝之數。通論僧法與別法的，兼含後面的對首與心念，將僧法合為一種，所以總共有三種；若將僧法開展為五種，眾法與別法一同展開，就是八種或九種。

【768-0006】03_業疏/03a_卷一之三#18
【原文】就文又三：依人弘法，人分三位，故隨立也。初又為三，謂三羯磨
【譯文】就課文而言又分為三：依託僧人弘揚教法，僧人分為三個位次，所以隨之安立。第一部分又分為三種，也就是指三種羯磨。

【768-0007】03_業疏/03a_卷一之三#19
【原文】次顯相分文中，初總分三位，「初下」正分眾法
【譯文】在其次顯發名相的部分文中，起初總體分為三個位次；自「初」字以下正式劃分眾法。

【768-0008】03_業疏/03a_卷一之三#20
【原文】單白三十九法者，計理隨事，何止此數？且依律文次第而列，無有義類，但應白相有無而已
【譯文】單白三十九法，照理而言隨著事相何止這個數目？暫且依據根本律文的先後次第予以列出，並沒有義理上的分類，只是應對唱白之相的有無罷了。

【768-0009】03_業疏/03a_卷一之三#21
【原文】單白標中，初科依律次列，知無義類；隨相有無，則非加減，如三十懺白闕三之類
【譯文】在單白標示之中，第一科說明依照律文次第排列，可知沒有義理分類；隨著相狀的有無而列，就不是人為隨意增減，比如三十捨墮的懺悔單白中缺少三種白之類。

【768-0010】03_業疏/03a_卷一之三#22
【原文】至下篇中，亦不具出。何者？有則現用，當世盛行，且標名相，事體如後；無則事缺，或復行稀，或人通犯難為洗懺，如非時二和、因諍四增、觸惱、論法、餘語等是也。今集法者，且列名相，依而解之，用在將來，故不顯事法也
【譯文】到了後面的各篇之中，也沒有具體全列出來。為什麼呢？有的法屬於當前實用、當世盛行，暫且標出其名相，其事體行相如後文所述；有的法則事緣闕如，或者是施行稀少，或者大家普遍違犯而難以清淨洗懺，例如非時的二種和合、因諍事的四種增長日、觸惱僧、結集論法、言說餘語等即是。如今集錄教法，暫且列舉出名相，依照律教加以解釋，其功用在於未來，所以這裡不顯露具體行事的作法。

【768-0011】03_業疏/03a_卷一之三#23
【原文】次科初總示，下諸篇中眾法止有六十餘法，故云「不具出」也。「何下」徵意。初明出意，現用盛行，所謂隨機也，下文自廣，此但標名。「無下」示不出意，事缺所謂潛務也。稀行難舉，略提數法；餘不出者，類此可知。下篇無文，此須具解，開明法眼，資補心靈，或委質淨邦，或親逢三會，或為因行而化物，或作果用而利生，用在將來，所期遠矣
【譯文】次一科起初總括指示，後面的各篇中眾法只有六十多種法，所以說「不具體全出」。「何」字以下探問其用意。首先說明列出的用意，當前運用而盛行，這就是所謂隨應時機，下文中自然會詳述，這裡只是標出名目。「無」字以下指示不列出的用意，事緣闕如就是指沉潛不顯的事務。施行稀少而難以舉行的，略微提及數種法；其餘沒有列出的，依此類推即可得知。後篇雖然沒有具體作法文句，這裡必須詳細解釋，以便開明法眼，資助補益心靈，或者往生安質於淨土，或者親身欣逢龍華三會，或者作為因地修行以化導眾生，或者作為果地妙用以利益群生，其功用在於將來，所期望的意義是非常深遠的。

【768-0012】03_業疏/03a_卷一之三#24
【原文】初言三十中二十七受懺法者，計餘三十，但以二寶、綿衣，捨既非僧，因不明懺，故闕此三。餘有白者，捨既在僧，因即懺罪，須白告量。諸白例通，故不更舉也
【譯文】最初所說三十捨墮中具有二十七種受懺之法，推究其餘闕法者，在三十條戒中，只是因為捉持二種寶物以及乞作綿衣，其捨財既然不是捨給僧眾，因此沒有在僧中明示懺法，所以缺少這三種單白。其餘具有唱白的戒，捨物既然是在僧眾中進行，便隨之懺悔罪過，必須作單白告知僧眾考量決斷。各種唱白之例皆相通，所以不再逐一列舉。

【768-0013】03_業疏/03a_卷一之三#25
【原文】解注中，初科三十中，一一戒後竝出懺法。二寶、捨對俗人、乞綿制令斬壞，不對僧捨，因略懺法，故缺三白。有者反之，尋文可解。「諸下」二句示不加之意
【譯文】在解釋注釋之中，第一科說明三十捨墮中，每一條戒後面都列出懺悔之法。捉持二種寶物是向俗人捨離，過量乞綿則制令剪斬毀壞，都不對僧眾捨物，因而省略了僧中懺法，所以缺少三種單白。有單白的戒則反之，尋閱律文便可理解。自「諸」以下兩句是開示不再增加列舉的意圖。

【768-0014】03_業疏/03a_卷一之三#26
【原文】二、行鉢法者，一鉢支身，足堪助道，乃廣乞求，妨業招譏。好者奪留，惡者轉換，若不白告，無由得知，故曰也
【譯文】第二種，行鉢之法：一個鉢用以支撐色身，已經足夠用來助修道業，若廣為乞求過多的鉢，就會妨礙道業並招致譏嫌。對於好的鉢僧眾予以沒收留存，對於劣質的鉢則換給他，如果不作單白宣告，大家便無從得知，所以制立此法。

【768-0015】03_業疏/03a_卷一之三#27
【原文】二中，乞鉢懺捨具有四法：懺主白和單白如前，眾僧還鉢白二如後。此行鉢白，即取所乞下鉢，從上座行，易取惡者與之，令持五德行時，須白告眾。得惡鉢已，復作白二制令愛護，如後自說
【譯文】在第二法中，多乞鉢的懺悔與捨鉢共具備四種法：懺罪之主請求和合的單白如同前面，僧眾還鉢的白二羯磨如同後文。此處的行鉢單白，就是取其所乞得的鉢，於僧中行鉢、從上座開始巡行，換取下劣的鉢給他、令其受持，具五德之人巡行鉢時，必須作單白告知大眾。得到下劣鉢之後，又再作白二羯磨制令其愛惜守護，如後文自會說明。

【768-0028】03_業疏/03a_卷一之三#40
【原文】十七中，「將尅忍位」，即內凡四善根中第三位也。忍有二義：一、忍可義，忍可諦理皆如實故；二、決定義，善根決定無退動故。若至此位，必入初果，是以行人急欲修證，故延自恣。「待時解脫」者，羅漢有二種：若鈍根者，須待好時方得解脫，名時解脫。準《婆沙論》，待時有六：一須好衣服，二須好飲食，三須好臥具，四須好處所，五須好說法人，六須好同學；若利根者，不待如上六種好時自得解脫，名不時解脫。今謂末代利根者稀，故云「待時多也」。「會正方作」，謂待證聖果然後自恣也
【譯文】在第十七法中，「將尅忍位」，就是內凡位四善根中的第三位。忍有兩種意義：一是認可忍從之義，因為忍可四諦之理全都如實不謬；二是決定之義，因為善根已經決定不會退轉動搖。如果修到這個位次，必定能證入初果，因此修行人急於求得證悟，所以推延自恣。「待時解脫」，阿羅漢有兩種：若是鈍根之人，必須等待合適的時節機緣才能證得解脫，稱為時解脫。依照《大毘婆沙論》，待時有六種條件：一必須有合適的衣服，二必須有合適的飲食，三必須有合適的臥具，四必須有合適的處所，五必須有善巧說法的人，六必須有同心同德的同學；如果是利根之人，不需要等待上述六種良好時機自能解脫，稱為不時解脫。現在說末世利根之人罕見，所以說「待時多也」。「會正方作」，是指等待證得聖果然後再行自恣。
