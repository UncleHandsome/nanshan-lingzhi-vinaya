整體看下來，這批譯文水準不錯，專名（鄔波陀耶／依學／和上／力生／郁波弟耶）與人物（真諦＝陳朝三藏、彥琮＝隋法師、餘＝道宣自稱）都掌握正確。以下按「必須修正」與「建議斟酌」分列，並附改譯供參。

---

## 一、必須修正（義理或科文層級出錯）

### 【0006】#58 「初文」的層級錯置 ⚠️最要緊
上一則（#57）已把「請師法」分為兩段：①文敘師資教興所由 ②「作是請」下立法加被。
此處「**初文又二**」是就**第①段**再細分（前明緣致／後修虔敬），不是把整個「請師法」分成兩部分。

- 原譯「第一項文中又分為兩部分」→ 會讓讀者以為請師法只有「緣致＋虔敬」，把「立法加被」丟了。
- 建議：**「前段（敘教興所由）之文又分二：先明請師的緣由，後明弟子修虔敬之儀。」**

### 【0010】#62 「不知音本」誤譯
「音本」＝**音譯之本（本是梵音）**，不是「梵音本義」。元照此處正是說古人把音譯詞「和上」當漢語望文生義（和中最上），故云「迷於華梵」。

- 原譯「所以說不知梵音本義」✗
- 建議：**「所以說他不知『和上』本是梵音音譯」**。
- 附帶：#61 同一句你譯作「不知其乃梵音音譯之本」是對的，兩則自相矛盾，宜統一。

### 【0005】#57 「師資教興所由」被拆成兩事
原文是一個短語：**師資（師徒相攝）之教所以興起的緣由**。
原譯「敘述師徒相待之義，**以及**制定請師之教的緣由」＝無端增出一項。

- 建議：**「文中先敘師資之教（依師學道、師徒相攝）興起的緣由。」**

### 【0005】#57 「立法加被」
「加被」是**和尚對弟子的慈悲攝受**（請詞末云「慈愍故」），譯作「予以威德加被」既增「威德」，又未交代施受關係。

- 建議：**「自『作是請』以下，建立請師之法，以祈和尚慈悲加被（攝受）。」**

### 【0004】#56 「前緣列八」
「前緣」＝**前文所列之緣**（承上「八相」而來），不是「受戒前行之緣」。

- 建議：**「就行事而言，前文所列之緣共有八項，如（羯磨）文中所顯，歷然分明，各自有別。」**

## 二、建議斟酌（用語偏差、增譯、含糊）

### 【0001】#53
1. 「辨**俱互**四句」宜點明：**俱**＝心境俱如／俱非，**互**＝一如一非。只譯「心境俱互的四句差別」讀者無從理解。
2. 「**翻上可明**」＝把上一句**反過來**看即明（境如心非 ↔ 心如境非）。「反照上句」語意含混，建議改「反前第二句對照即可明白」。
3. 「亦不**相當**」＝**與境不相應（不能感發戒體）**，「亦不相符合」太空泛。
4. 「**不能兩離**」：元照自釋「心境俱非也」，故是「心與境**二者都不能離於過非**」。原譯「兩者皆全非正軌」意思不差，但字面關係沒譯出來，建議：**「『不能兩離』，謂心、境二者皆不免過非，即心境俱非。」**
5. 括注「第二緣（境界）／第三緣（受心）」宜與前列緣目原名一致（如「所對境界」「發心乞受」），請核對前文緣目。

### 【0002】#54
1. 「前後**無濫**」是**敘述**（八法次第井然、互不混濫），譯成「不得混亂顛倒」變成規範語氣，且「顛倒」為添字。建議「前後次第井然，不相混濫」。
2. 「**五行**」建議加譯註：一般解作金木水火土（釜、薪、水、火、灶等眾緣和合方成一食），否則現代讀者易誤解為「五種行為」。#55「五行調和」同此。
3. 「事成同一」可補一句釋名：**眾緣和合，同成一受戒之事**。

### 【0003】#55
「首先正文解釋」文句不順 → **「先是正釋（正式解釋）」**。

### 【0007】#59
1. 引號內「弟子**若**無**師僧**教授**訓導**」自行增字。引文宜照錄「弟子無師教授」，補充放引號外。
2. 「便隨之墮落、敗壞行持」緊接「必須憑藉師長的引導」，讀來像「有師導反而墮落」。宜補條件：**「（若無師導）便隨之墮落、壞其行持，實因沒有善友（善知識）之故。」**
3. 「中人已上」照譯無誤，但與#60「唯中人可教」表面有张力，可加註：上智不待教、下愚不可教，正取中人須師，故云「中人已上」。

### 【0008】#60
1. **「（『可尚』二字疑有訛，待考）」這個存疑註建議刪除或改寫。**「可尚制意」可通讀為「（和尚）可尊尚，故制請師法之意」，文義無滯，不必遽斷為訛字；若真要保留，宜作「『可尚』諸家未詳，今依文義讀為……」而非「疑有訛」。
2. 「緣由**因由**」疊床架屋 → 「請師的緣由」。
3. 「上智不待教」譯「不需**等待**教導便能自悟」稍滯 → **「上智之人不須教化（自然明達）」**。
4. 全句可改：**「其次，就行事中『請師緣致』之文，顯示和尚可尊尚、故制請師法的用意。」**

### 【0009】#61
1. 「**不得聲實**」：上下文全在辨**音訛**（元照亦云「故語多不正」），「聲實」＝音聲之真實，即**正確讀音**。譯「字音與**實義**」多了「義」。建議「未能得到梵語正確的音讀」。
2. 「猶乖**聲論**」：聲論＝**聲明之學（śabda-vidyā，梵語音韻文法）**。譯「梵文聲論**音律**」易誤為音樂律呂，建議「仍不合梵語聲明（音韻）之學」。#62 你已譯作「聲明之學」，兩則宜統一。
3. 「多雜蕃胡」重在**輾轉間接傳譯**（非直接來自梵本），可譯「多經由邊地蕃胡諸國輾轉傳譯，夾雜胡語」。
4. 「聲相近也」宜補所比對象：**「與梵本原音相近」**。
5. 《明了論疏》括注可再精確：真諦譯《律二十二明了論》並撰疏，疏文「所譯」乃泛稱，可註明「論為真諦譯，疏相傳亦真諦撰」。

### 【0010】#62
1. 「初出**正翻**」＝**正確的譯名（依學）**，「正宗的譯名」語感偏宗派義，建議改「正確譯名」。
2. 「乖聲論者，前出正翻……」是**對比說明**，建議把轉折挑明：**「說真諦『乖聲論』，是相對前文所出正翻而言——那是依聲明之學、於譯場親自請問而得，故名與義皆得其實。」**
3. 「琮即隋時法師」譯「隋代的**著名**法師」為添字，刪「著名」即可。

## 三、通用建議

| 原詞 | 建議統一譯法 |
|---|---|
| 聲論 | 聲明之學（梵語音韻文法），勿作「音律」 |
| 正翻 | 正確譯名 |
| 音本 | 音譯之本（本是梵音） |
| 近語 | 切近的梵語原音（本名） |
| 加被 | （和尚）慈悲攝受 |
| 俱互 | 俱（俱如／俱非）、互（一如一非） |
| 緣致 | 緣由（勿「緣由因由」） |

另：譯文中「威德」「著名」「出家人」「顛倒」「相待之義」等屬補義增譯，雖多半無害，但學術體例上建議**補語一律入括號**，與疏記本文區隔，避免讀者誤認原文有該義。
