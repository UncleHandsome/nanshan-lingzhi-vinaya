# 校閱材料　第750檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【750-0001】02_戒疏/17a_卷四上之二#52
【原文】【註】佛在舍衛。六群、十七群同道行，至無住處，十七群自求住處，彼六群知求得宿處，強在中間敷臥具宿。比丘以過白佛，因制此戒。
【譯文】【註文】佛陀住在舍衛國。六群比丘與十七群比丘同路行走，來到一處沒有僧寺之處，十七群比丘自己去尋找住處。那六群比丘明知人家已覓得住宿之地，卻強行在人家的鋪位中間鋪設臥具同宿。比丘們將其過失向佛稟白，佛因而制定此戒。

【750-0002】02_戒疏/17a_卷四上之二#53
【原文】【記】戒緣。云「無住處」者，明無僧寺，寄止俗舍。
【譯文】【記文】戒律起緣。所謂「沒有住處」，是指當地沒有僧團寺院，只能借宿在世俗民宅。

【750-0003】02_戒疏/17a_卷四上之二#54
【原文】【律】若比丘，知先比丘住處，後來強於中間敷臥具止宿，念言「彼若嫌迮者，自當避我去」，作如是因緣，非餘，非威儀，波逸提。
【譯文】【律文】若有比丘，明知先有比丘借得住處，後來的比丘強行在其中間鋪設臥具借宿，心裡想著「他若是嫌擠，自己應當避開我離去」，以此不良企圖為唯一緣由，並無其他合理原因，且非合乎出家威儀，犯波逸提罪。

【750-0004】02_戒疏/17a_卷四上之二#55
【原文】【註】謂隨轉側，脇著牀，結墮。不犯者：先不知；若語已住，先與開間；若間寬廣，不相妨閡；若親舊人教言「但敷，我自語主」；若倒地；若病，轉側墮上；若力勢所持；若被繫閉；命、梵二難——並不犯。
【譯文】【註文】只要身體隨之轉側、脅肋著床，即結犯波逸提墮罪。不犯的情況：事先並不知情；或是告知對方後經同意同住，先為其挪出空位；或是房間寬敞廣闊，彼此互不防礙妨塞；或是熟識親友教導說「你儘管鋪，我自己去向屋主交涉」；或是失足跌倒在床；或是生病轉側不慎倒在他人床上；或是被外力強行推置其上；或是被他人囚禁幽閉；面臨生命或梵行受危害這兩種難緣——全都不犯。

【750-0005】02_戒疏/17a_卷四上之二#56
【原文】【疏】戒本五句：一、犯人；二、知；三、後來強敷；四、「念言」下，作惱意；五、結罪。
【譯文】【疏文】戒本分為五句：第一、能犯之人；第二、明知情由；第三、後到而強行鋪設；第四、「心裡想著」以下，懷有惱害排擠之意；第五、結定罪名。

【750-0006】02_戒疏/17a_卷四上之二#57
【原文】【記】戒本，分文，可解。
【譯文】【記文】戒本經文，劃分句讀，容易明瞭。

【750-0007】02_戒疏/17a_卷四上之二#58
【原文】【疏】「作是因緣非餘」者，非餘不犯。將不犯以望犯，不犯是犯義「餘」。但以不依不犯，故相逼惱，非是威儀，何得不犯？
【譯文】【疏文】「以此不良因緣為由，並非其他原因」的意思，是指排除了其他不犯的特殊情況。把不犯的情形與犯戒的情形相對照，不犯的情況便屬於犯戒定義之外的「其餘」。如今只因不依循那些不犯的正當特例，存心互相逼迫惱害，這絕非出家威儀，怎麼可能不犯？

【750-0008】02_戒疏/17a_卷四上之二#59
【原文】【記】釋非餘中。「餘」即是外。不犯在於犯外，即「非不犯」，顯是正犯。初牒示。「將」下，明「餘」義。「但」下，合文釋。
【譯文】【記文】解釋「非餘」的經文。「餘」就是在此之外。不犯的情形處於犯戒條件之外，所謂「並非不犯之餘由」，正顯明這屬於純正的違犯。首先提起標明。「把不犯」以下，闡明「餘」的意義。「只因」以下，結合文義進行解釋。

【譯文】【律文】第十七條、牽拉他僧攆出房舍戒。

【譯文】【疏文】牽拉比丘攆出房舍戒，為第十七條。

【750-0011】02_戒疏/17a_卷四上之二#62
【原文】【疏】然四方僧房，眾人共有，理無偏局，義須通贍。雖先料理，安止已定，後來同徒，宜共受用。今乃內懷瞋恚，強牽他出，自壞惱他，諍競之本，損處非輕，故制。
【譯文】【疏文】十方常住的僧舍，是所有大眾共同擁有的，在法理上絕不能偏袒私占，義理上必須普遍利益供給眾人。即使先到者已經打掃整理、安頓安置妥當，後來的同道法侶，理當共同受用。如今竟然內心懷著瞋怒憤恨，強行將他人牽拉驅逐出房，既敗壞自身德行又惱害他人，這是引發爭鬥傾軋的根源，所造成的損害極不輕微，因此佛陀制定此戒。

【750-0012】02_戒疏/17a_卷四上之二#63
【原文】【記】十七，制意中。初明眾物理通，合與同住。「贍」，猶給也。「今」下，次敘過顯制。文闕犯緣，或同前戒，或是寫脫。今準《鈔》云：「一、是僧春、冬房；二、先安止定；三、作惱亂意；四、牽出犯。」
【譯文】【記文】第十七條制戒本意中。首先說明大眾公物在法理上人人有份，應當接納同住。「贍」，如同供給濟助之意。「如今」以下，接著敘述過失以彰顯制戒必要。疏文中缺少列出犯戒的條件，可能是與前戒相同，或者是抄寫時脫落遺漏。現在依據《事鈔》補充：「第一、是僧團供春冬居住的常住房舍；第二、先住者已安頓完畢；第三、生起惱害擾亂之心；第四、強行牽拉出房即成犯。」

【750-0013】02_戒疏/17a_卷四上之二#64
【原文】【註】佛在舍衛。六群、十七群同道行，至小住處。十七群於先入寺，掃灑令淨。六群知得好處，驅起牽出。比丘以過白佛，便制此戒。
【譯文】【註文】佛陀住在舍衛國。六群比丘與十七群比丘同路行走，來到一處小寺院住處。十七群比丘先進入寺內，灑掃收拾乾淨。六群比丘知道這是一處好房間，便強行驅趕逼迫並將他們牽拉拖出。比丘們將其過失向佛稟白，佛便制定此戒。

【750-0014】02_戒疏/17a_卷四上之二#65
【原文】【疏】就戒緣中，因先強敷，佛制與罪，由是俗家。此僧寺中，理依位夏，所以牽出。
【譯文】【疏文】在戒律因緣中，之前因為強行鋪床，佛陀制定為有罪，那是因為借宿在俗人家中。如今在僧團寺院裡，本應依戒臘座次來分配，六群比丘恃仗戒臘，所以動手牽拉攆出。

【750-0015】02_戒疏/17a_卷四上之二#66
【原文】【記】釋緣起。云「僧寺」等者，即明六群恃己之意。「位夏」語倒。
【譯文】【記文】解釋緣起起因。所謂「僧寺」等語，正是說明六群比丘依仗自身戒臘的傲慢心理。「位夏」在字面上略有倒置。

【750-0016】02_戒疏/17a_卷四上之二#67
【原文】【律】若比丘，瞋他比丘不喜，僧房舍中，若自牽出，教他牽出。
【譯文】【律文】若有比丘，瞋恨其他比丘而不喜愛他，在僧團的房舍中，自己動手牽拉驅逐，或叫別人牽拉驅逐。

【750-0017】02_戒疏/17a_卷四上之二#68
【原文】【註】若自作、教人牽，隨所牽多少，隨出房，隨犯。若牽多人出一戶，若牽一人出多戶，皆犯多墮。若一人出一戶，一墮。若持多物出，若擲著戶外，閉他戶外，皆突吉羅。
【譯文】【註文】如果自己牽拉、叫人牽拉，隨所牽拉人數的多少，只要被拖出房門，便隨之結罪。如果牽拉多人拖出同一扇門，或者牽拉一人拖穿多扇門，都犯多個墮罪。如果牽拉一人拖出一扇門，犯一個墮罪。如果拿起對方的諸多物品搬出門外，或者扔擲到門外，把別人反鎖在門外，全都犯突吉羅罪。

【750-0019】02_戒疏/17a_卷四上之二#70
【原文】【註】不犯者：無恚心，隨次出；若遣未受具出；若破戒、見、威儀，及為舉、𢷤；因此故命、梵難，驅出者——並開。
【譯文】【註文】不犯的情況：心無瞋恨之意，只是依戒臘次第重新排遷出房；或是驅逐未受具足戒的沙彌等出房；或是對方破了戒律、破了正見、破了威儀，以及依律對其進行舉罪、擯黜處分；或是因同住恐招致生命危難、梵行危難而將其驅離者——這些情形均予開許不犯。

【750-0022】02_戒疏/17a_卷四上之二#73
【原文】【疏】就解成犯相中，相從就「多」結者，欲止惡法令斷也。今封著者，多守房鎖戶，本不許入，牽出希耳。
【譯文】【疏文】在解釋構成犯戒的行相中，（人數與門戶數）互相比照而依多數結罪，是為了制止惡法而使其斷絕。如今執著私有的人，大多私自霸占房間並鎖上門戶，根本不准他人進入，直接動手把人牽拖出來的現象已經很少了。
