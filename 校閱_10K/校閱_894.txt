# 校閱材料　第894檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【894-0001】資持記/01c_上一上#21
【原文】次當宗中，初文，上句指前，下句標後。言通明者，以前三意統毘尼藏，義該群部，不局一宗。然上三意，能所互彰。初就能施，必兼所被；以慈不虛發，專為劣機。後之二種，文約所為，用顯能施。次則彰正法之尊高，後乃明教門之差別。正明中，初科，上二句明教起由機。人既下四句，明機別教廣。
【譯文】其次在「正明本宗」的科判中，第一段經文，上一句總指前文，下一句標示後文。所謂「通明」，是因為前面所說的三重意趣統攝了整部毘尼藏，其義理通貫諸多部派，並不拘限於單一宗派。然而上面這三重深意，能化之佛與所化之機互為顯揚。最初就如來「能施之化」而言，必定兼及所利益的根機；因為大悲之意絕不虛發，正是專為根基下劣者而設。後面的兩種意趣，文句雖然偏向說明所化的機緣，實際上卻是用來彰顯能施教法的佛心。次一意趣旨在彰顯正法的尊貴崇高，最後的意趣則是為了闡明各教門之間的權實差別。在正式說明的科判中，第一段的前兩句指明教法的生起完全是由於眾生的根機。「人既」以下的四句話，說明眾生根機千差萬別，教法也因此廣大浩瀚。

【894-0002】資持記/01c_上一上#22
【原文】攝誘謂曲施方便，弘濟謂普令獲益。軌用即一切事法，止作兩行。上句明能說之意，下句顯所說之教。貴下六句，敘今從要。本詮謂教之大旨；對下條緒，即事之別相。所以等者，探後二例，示本詮相。〔開制，即第二；持犯即第一。或可此二通該五例，以一一例中竝具兼故。
【譯文】「攝誘」是指委曲施展種種善巧方便，「弘濟」是指普遍令一切眾生獲得解脫利益。「軌用」就是指行事中的一切規矩法則，涵蓋了「止持」與「作持」兩種行門。上一句顯發佛陀能演說的本懷，下一句闡明如來所宣說的教軌。「貴」字以下的六句，敘述本處的宗旨是提綱挈領、直取核心要道。「本詮」是指教法中最根本的宗旨綱要；用來對照下文的「條緒」，也就是各種具體事相的個別行相。「所以」等句，是預先探索後面的兩種範例，以顯示本體教法的綱相。〔「開制」就是指第二例；「持犯」就是指第一例。又或者這兩者統括貫穿了全部五種範例，因為每一種範例中都兼具此二者的緣故。〕

【894-0003】資持記/01c_上一上#23
【原文】驗諒二字，謂以智窮考。旨意二字，即立教本懷。諒，信也。今下，總標。一部之文，不過五例；以少明多，故云束也。初遮性者。毘尼所制，無出遮性；用此二門，求一律藏；總歸二意，故曰往分。初通局中。十不善道違理之業，體本是惡，三藏齊禁。然毘尼中但制七支，更增篇聚，故通二教。
【譯文】「驗諒」這兩個字，是指運用智慧去窮究考查。「旨意」這兩個字，就是指立教時的根本意趣。「諒」就是信實的意思。「今」字以下，是總體標明綱領。整部律典的文句，歸納起來不過五種範例；用少數綱要來闡明廣大文義，所以說「約束統攝」。第一項範例是「遮戒與性戒」。毘尼戒律所制定的一切規範，不出遮戒與性戒這兩大範圍；運用這兩個門徑去探求整部律藏的旨歸，總體上皆可歸納入這兩種意旨，所以說「預先加以分別」。在「通局」的討論中：十不善業道等違背天然事理的罪業，其自體本來就是惡法，經律論三藏一同予以禁絕。然而毘尼律中只制伏了屬於身三、口四這七支惡業，並進一步依過失增設了篇聚罪名的區分，所以這類戒法通於化教與制教這兩大教門。

【894-0004】資持記/01c_上一上#24
【原文】壞生掘地等，本非不善；息世譏疑，制方成過，故局制教。據文，合云：遮戒則局於制教。文中為示遮性之義，故云因過等。然性戒元有，無論大聖制與不制，無非結業感報三途。遮戒不爾，佛出方制。故經論中或名主客、或號新舊、或約違理違事分之。餘如《戒疏》。
【譯文】傷害草木生命、掘地等事，本質上並非不善之惡；但為了止息世俗之人的譏嫌猜疑，佛陀制定之後才構成過犯，所以局限於律宗的制教。依照文意，理應表述為：「遮戒則僅局限於制教之中。」經文中為了開示遮戒與性戒的根本定義，所以特別表述為「因過失而制定」等語。然而性戒在法爾道理上本來就存在，無論大聖佛陀制不制定戒律，只要造作無非都會結下惡業，感召墮入三惡道的苦果。遮戒則不然，必須等佛陀降世立制之後才構成罪犯。因此經論之中，或將它們稱為主與客、或稱為新與舊、或者依據違背天理或違背事相來作劃分。其餘詳細意理如《戒疏》所說。

【894-0005】資持記/01c_上一上#25
【原文】次科，性戒中，初句正標教意。謂下，釋成，初二句示文緩。此收一切性戒，故云並有。文雖下，釋義急。初明教急行難；如下，略舉兩戒，顯上教急。既下二句，釋上行難。故知下，結歸。三時者，謂初入入已出時；於三時中，微動樂念，還即成重。毀呰即九十中罵戒。慈心誨勗，雖罵無犯；
【譯文】下一個科判，在論及「性戒」時，第一句正式標明立教的宗旨。所謂「謂」字以下，是具體釋明其所以然，前兩句指示文字上的寬緩。這涵蓋了一切性戒，所以說「皆有開許之文」。在「文雖」以下，是闡釋法義上的嚴急。首先說明教令嚴厲、持守極難；在「如下」這句，略舉兩條重戒，藉以顯發前述教法的嚴急。在「既」字以下的兩句，進一步解釋前述實踐上的艱難。因此在「故知」以下，作了總結歸納。所謂「三時」，是指行婬時「初進入」、「進入已」與「拔出時」這三個時段；在這三個時段之中，內心只要稍微生起絲毫的微細受樂念頭，隨即便結成不可悔的根本重罪。「毀呰」就是指九十單墮罪中的「罵詈戒」。若是以慈悲心予以誨勉督責，雖然口出嚴詞也沒有犯戒；

【894-0006】資持記/01c_上一上#26
【原文】微生瞋怒，亦結正科，故曰開實結犯等。〔二戒開文竝見戒本。〕遮戒中，初明緩急。制即是急，開即是緩。對前性戒，義立四句。一文緩義急，性中開也。二文急義緩，遮中制也。〔以非性業隨緣開故。〕三俱急者，性中制也。四俱緩者，遮中開也。豈非下，正示興意。上明護俗；
【譯文】但內心只要稍微生起一絲瞋怒之意，也立刻依照正法結罪，所以說「雖有開許，實則結犯」等等。〔這兩條戒的開緣條文，都詳細記載於戒本之中。〕在「遮戒」的論述中，首先說明條文的緩急。「制約」就代表法度嚴急，「開許」就代表法度寬緩。對比於前面的性戒，在法義上可建立四種句型：第一是「文句看似寬緩而義理實極嚴急」，這指性戒中的開緣；第二是「文句看似嚴急而義理實屬寬緩」，這指遮戒中的制約；〔因為遮戒本非性惡之罪，可隨特殊因緣予以開許的緣故。〕第三是「文義兩者皆嚴急」，這指性戒中的根本制約；第四是「文義兩者皆寬緩」，這指遮戒中的特殊開緣。在「豈非」以下，正面揭示戒法興立的本懷。上文說明這是為了護持世俗人心；

【894-0007】資持記/01c_上一上#27
【原文】大慈下，明制道。道既無失，俗則生善；一制兩得，權巧在茲。《涅槃》所謂息世譏嫌，即其義也。枉坑者，枉謂邪曲，以於僧起謗，必墮邪道，永無有出，喻之若坑；或可約報，即喻苦趣。引證中。彼論第七明犯罪有三種：一初犯緣，二因犯故制，三重制。
【譯文】在「大慈」以下，說明制約道人的意義。出家道人的行持既然沒有失誤，世俗之人自然就能生起敬信善心；制定一條戒律能同時達成這兩重利益，聖人的權巧方便正體現在此處。《涅槃經》所說的「止息世間的譏嫌」，表達的正是這個道理。所謂「枉坑」，「枉」是指邪曲無道，因為眾生若對僧團生起誹謗，必定會墮入邪道惡見之中，長劫難以出離，所以用深坑來作比喻；或者可以從果報的角度來談，那就是比喻極為劇烈的三惡道苦趣。在「引證」的段落中。該論第七卷指明犯罪的因緣有三種：一是最初犯戒的起緣，二是因有犯事而正式制定，三是重新再次制定戒條。
