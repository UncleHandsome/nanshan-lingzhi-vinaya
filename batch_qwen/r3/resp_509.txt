整體看下來，這批譯文對科判（初科、次科、分句、方便、究竟）的掌握大致到位，語氣也通順。但有**幾處實質誤譯**，加上一些用語與前後一致性的問題，建議修正。以下按嚴重程度分層說明。

---

## 一、必須修正的實質錯誤

### 1. 【509-0012】「但舉重者」譯錯（最關鍵）
> 譯文：「所以只列舉了**結重罪的情況**」

「輕重二位」指的是 **「滿五錢」與「減五錢」兩組境想句**，不是「重罪／輕罪」。從下一則記文即可自證：註文所引的滿五四句中，本身就含「疑→偷蘭」「無主有主想→偷蘭」等**輕罪**。所以「但舉重者」是「只舉出**重位（滿五錢）那一組**」，而非「只列重罪」。目前譯法與 #120 記文自相矛盾。

建議：「……《四分律》原文把（滿五錢的）重位與（減五錢的）輕位兩組境想句都完整列出，現在戒本註文從略，只舉出重位（滿五錢）那一組。」

### 2. 【509-0010】「賊復奪賊」譯成「強盜搶劫強盜」
本戒是**竊盜**戒，「賊」指竊賊，「奪」在此是「侵奪／再偷」之意，不是強盜搶劫。
建議：「這就等於**賊又偷賊（盜賊反過來盜竊盜賊）**，其中的義理顯而易見。」

### 3. 【509-0010】「盜緣成犯」譯成「行盜的緣起條件」
「盜緣」是**具緣成犯的構成要件**（有主、有主想、盜心、重物、離處），與「緣起」（pratītyasamutpāda）無關，這樣譯會讓讀者誤以為在講十二因緣。
建議：「**偷盜的諸緣（構成要件）已經具足而成立犯相**」。

### 4. 【509-0001】「教者無犯」那段用「教唆」自相矛盾
> 譯文：「如果**教唆**別人去拿東西，被差遣者誤以為是叫他去行竊……教唆者不犯戒。」

「教唆」在中文已預設惡意，既然結論是「教者無犯」，前提就是他**沒有盜心**（如律中典型例：叫人去拿我自己的衣）。
建議：「若**只是（無盜心地）叫人去取物**，受教者卻誤以為是要他去行竊而下手盜取，受教者犯重，教者無犯。」
同理，「若為取物，使無盜心」一句，建議補出對比：「**教者暗懷盜心**指使人取物，而受指使者並無盜心」。

## 二、語意偏差、易生誤解處

| 編號 | 問題 | 建議 |
|---|---|---|
| 0001 等多則 | 「**奪得／奪取**」反覆出現（諸處得物、有主想而奪取、取物是同） | 盜戒是竊取而非強奪，一律改「取得／拿取／盜取」 |
| 0012 | 「境想」譯為「心念與外境**相應**」 | 境想句正含「疑」「異想」等**不相應**的情況，改「外境與心想的相對配對（境想）」 |
| 0010 | 「雖然那件東西原本就是**我**自己的衣服」 | 白話保留第一人稱易誤解為敘述者，宜點明「雖然那是**教者自己**的衣服」 |
| 0010 | 「第二句……**也必須將物品分一半給他**」 | 主語不明，補「（教者）也必須分一半給（受教者）」；並可補「此句教者本無盜心」以呼應註文「教者無犯」 |
| 0001 | 「比丘尼等**出家四眾**」 | 讀者易與「四眾弟子（含在家）」混淆，建議列名：比丘尼、式叉摩那、沙彌、沙彌尼 |
| 0001 | 「如果未能得手，犯輕微罪」 | 宜補「（著手行竊而）未取得」，明示是未遂的突吉羅 |
| 0008 | 「當物品被**完全**拿離地面移位時」 | 「取離地」即「舉離本處」的成犯時點，「完全」是多餘的限定；「專是所教」可譯「純屬受教者自己所為（已超出所教範圍）」 |
| 0008 | 「與實際**境界**不符」 | 「乖境」的境是所取之物／處，「境界」易被讀成修證境界，改「與實際所取之境不符」 |
| 0009 | 「示犯重輕」→「指出結重罪與輕罪的**依據**」 | 「依據」為增譯，原文只是「顯示犯重、犯輕的差別」 |
| 0006 | 「心境相當**同犯**相」→「雙方共同結犯」 | 宜明說「教者與受教者**同犯波羅夷**」；「內心預謀」可改「心之所期」 |
| 0011 | 「同上《僧祇》」 | 較精確是「與**上文所引**《僧祇律》的說法相同」 |

## 三、前後一致性與用語風格

1. **「境想」譯法三種併用**：#110「外境與心念意想的相對判斷」、#119「心念與外境相應」、#120「境界心想／心境句型」。建議全書統一為「境想（客觀之境與主觀之想的相對句）」，首次出現加括號說明即可。
2. **「教人」的譯詞分層**：真正的教唆盜取用「教唆／指使」；「教者無犯」那類單純差遣用「叫人／託人」。目前一律「教唆」會製造邏輯矛盾（見上）。
3. **刑事語感偏重**：「作案」「分贓」「發號施令」「預謀」等，雖利於白話理解，但與律疏語境略有落差。可酌改「行竊」「分財物」「囑咐」「心期」，保留少數即可。
4. **罪名中譯一致**（波羅夷＝不可悔重罪、偷蘭遮＝粗惡罪、突吉羅＝輕微罪）：✅ 這部分處理得很好，建議維持。「五錢」可考慮首次出現時加註（古印度貨幣單位，摩沙迦）。

## 四、處理正確、值得保留的地方

- 【509-0011】「**必**能教者本無期心」的「必」作「若」解，譯為「如果……」，正確（此處極易誤譯為「必定」）。
- 「須分半」＝**能教者分給所教者**，依記文「即與所教」判讀無誤。
- 「雖誤得己物」的「己」判為**能教者自己之物**，與疏文「雖是我衣」相合，正確。
- 【509-0013】滿五／減五各四句、減五初句結蘭、餘三並吉，理解完全正確。
- 【509-0003】【509-0007】科判層層對照的還原清楚，「如是對之」「分示中」等處也無誤。
- 【509-0011】指出註文「教」下脫「者」字，忠實譯出；可加小註說明所指為「教者波羅夷」句（今本多已補「者」）。
