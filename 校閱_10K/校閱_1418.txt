# 校閱材料　第1418檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1418-0001】04_比丘尼鈔/02a_卷上之下#71
【原文】第二功能者婆論云欲現未曾有法故一切九十六種外道無此衣名為異外道故智論云佛聖弟子住於中道故制著三衣不同外道裸身無恥白衣多貪故重著也分別功德論云為三時故制有三衣冬則著重夏則著輕春則著中亦障諸蟲故此律寒故制著三衣又為三世如來竝著如是衣義云為調三毒因緣故制三衣華嚴經云著袈裟者捨離三毒也大悲經云但使性是沙門汙沙門行形是沙門被袈裟者於彌勒佛乃至樓至佛所得入涅槃無有遺餘悲華經云如來於寶藏佛所發願成佛時我袈裟有五功德一者入我法中或犯重邪見等四眾於一念中敬心尊重必於三乘受記二者天龍人鬼若能恭敬此人袈裟少分即得三乘不退三者有鬼神諸人得袈裟乃至四寸飲食充足四者若眾生共相違反念袈裟力尋生悲心五者若在兵陣持少分恭敬尊重常得勝他若我袈裟無此五力則欺十方佛僧祇云僧尼有戒德俗人索破袈裟段欲禳災者得與小者伽論僧尼等破壞三衣盋犯自性偷蘭遮但是衣盋不問受持不受皆不得壞滅亦不應破滅補衣賣之雜用皆犯前罪。
【譯文】第二項「功德效用」，《薩婆多論》說：為了彰顯佛門未曾有之法，因為所有九十六種外道都沒有這些衣的名號，是為了與外道有所區別。《大智度論》說：佛陀的聖弟子行持安住於中道，所以制定穿著三衣，不同於外道的赤身裸體毫無羞恥，也不同於世俗白衣過度貪著而重重疊疊地穿戴。《分別功德論》說：為了適應春、夏、冬三時氣候，所以制定有三種袈裟：冬天就穿重厚的，夏天就穿輕薄的，春天就穿不厚不薄適中的，同時也能阻擋各類蚊蟲侵擾。本律說：因為禦寒的緣故，所以制定穿著三衣；同時也是為了效法三世諸佛如來，都同樣穿著這樣的法衣。義理上說：是為了調伏貪、瞋、癡三毒的因緣，所以制定三衣。《華嚴經》說：身穿袈裟的人，能捨離三毒。《大悲經》說：只要種性曾為沙門，即便玷污了沙門梵行，只要形相是沙門、身披如來袈裟的人，在彌勒佛出世乃至最後的樓至佛出世期間，都能證入大般涅槃，無一人遺漏。《悲華經》說：如來當年在寶藏佛面前發願：當我成佛之時，我的袈裟將具備五種功德：一是進入我佛法之中的四眾弟子，縱使犯了重戒或生起邪見，只要於一念之中生起恭敬尊重袈裟的心，必定能在三乘道中蒙受授記；二是諸天、龍族、人類、鬼神若能恭敬這僧人袈裟哪怕只有少許碎片，即能在三乘道中得不退轉；三是若有鬼神及各類人等得到袈裟哪怕只有四寸大小，飲食便能豐足無缺；四是眾生之間若互相衝突敵對，只要憶念袈裟的神力，隨即能生起慈悲心；五是若在刀兵戰陣之中，只要攜帶少許袈裟碎片並恭敬尊重，便常能戰勝他人。如果我的袈裟沒有這五種功德力量，我便是在欺誑十方諸佛。《僧祇律》說：僧尼若具有戒德，世俗之人前來乞求破舊袈裟的布片想要消災辟邪的，可以把較小的碎片送給他們。《摩得勒伽論》說：僧尼若是故意破壞裁毀三衣及缽，犯自性偷蘭遮罪；只要是衣和缽，不論受持過與否，都不得故意毀滅；也不應當剪破毀壞拿去補衣服、變賣或挪作雜用，全都犯前述的重罪。

【1418-0002】04_比丘尼鈔/02a_卷上之下#72
【原文】第三釋衣名者此律云聽刀割壞成沙門衣不為怨賊所劫作安陀會襯身著鬱多羅僧僧伽梨入眾時著然此衣名諸部竝無正翻今以義推略知指歸慧上經云五條者名中著衣七條者名上著衣大衣者名眾集衣義云大衣者名雜衣以條數多故若從用立名入王宮聚落衣七條者名中價衣從用為名入眾衣五條者下著衣從用為名道行作務衣。
【譯文】第三項「解釋衣的名稱」，本律說：聽許以刀剪裁切破壞布料，縫製成沙門法衣，以避免被怨家盜賊搶劫；做成「安陀會」（五條衣），作為貼身內著；「鬱多羅僧」（七條衣）與「僧伽梨」（大衣），在進入僧眾大會時穿著。然而這些衣的梵語名稱，諸部律典都沒有完全對等的漢譯；現在依照其義理推敲，大致可以明白其旨趣。《慧上菩薩經》說：五條衣名叫「中著衣」，七條衣名叫「上著衣」，大衣名叫「眾集衣」。義理上說：大衣之所以又叫「雜衣」，是因為條數繁多的緣故；若是依據其功用來立名，則稱作「入王宮聚落衣」；七條衣稱為「中價衣」，若依功用立名，則稱為「入大眾衣」；五條衣是「下著衣」，若依功用立名，則稱為「路上行走及作勞務時所穿之衣」。

【1418-0003】04_比丘尼鈔/02a_卷上之下#73
【原文】第四財如者謂非四邪及自手興生出舉販博得財竝不如法受亦不成故律云不以邪命激發得現相得犯捨墮衣等竝不得作三衣。
【譯文】第四項「如法的財物」，是指布料來源不能出自四種邪命（占相吉凶、仰觀星宿、諂媚巧語、幻術迎合等），也不能以自己親手經商營利、放貸取息、販賣貿易等手段獲得的錢財來購置；否則全屬不如法，即便對它作加法受持也不能成就。所以律中說：不得以邪命乞求、故意激發施主、現奇特相索取、或者明知是犯了捨墮罪而應當沒收的衣物等，全都不得用來縫製三衣。

【1418-0004】04_比丘尼鈔/02a_卷上之下#74
【原文】第五體如者義云要須厚重者得若細薄生疎露體乃至綾羅綿繡文綺衣等竝不成受僧祇云一切生疎毛髮樹皮艸衣等不成受五百問云生絹不作三衣若不現身者得。
【譯文】第五項「如法的體質」，義理上說：質地必須要粗厚凝重的才可以；如果是細緻輕薄、編織生疏而會隱隱透出肌體的，乃至綾、羅、錦、繡、彩繪文綺等世俗華麗布料，全都不能用作受持法衣。《僧祇律》說：一切生疏粗惡的獸毛、頭髮、樹皮、雜草編成的衣服，都不能作受持的法衣。《五百問事》說：生絹不能拿來作三衣；但如果厚密不顯露身體的，則可以開許使用。


【1418-0005】04_比丘尼鈔/02b_卷上之下#1
【原文】第六色如者此律云上色染衣不得畜當壞作袈裟色十誦云一切青黃赤白黑五種純大色衣不得著除其納衣婆論云五大色衣不成作三衣又紫艸柰皮地黃紅緋染色黃櫨木等皆不如法色若五大色衣三點淨得作餘衣著謂紺黑青得早木蘭一切得受純青淺青碧等點淨得作衣裏用若赤白黃不純大色者亦得若不如法色染訖更以如法色覆成受持文殊問經云色衣不太赤不太黃不太黑不太白清淨如法色三法服及與餘衣皆如是色義云作淨法者用前紺黑青於四角頭隨意作一點僧祇云極大如四指極小如豌豆見論如麻子大僧祇云不得竝作或一三五七九等不得如華形作若浣褻泥汙即名淨若新僧伽梨趣一角頭作乃至一切衣新時亦爾若眾多破段衣一處合補者一處作淨青者謂銅青黑者謂雜泥等染木蘭者謂果汁等義云蜀地有木蘭樹皮其色赤黑然復鮮明可以為染微有香氣關東并州亦有木蘭樹子堪為數珠兼得為染其色稍黑京內諸山亦有求之者希。
【譯文】第六、顏色合乎規定（色如）：本律記載，上等純正鮮豔色彩染成的衣服不可畜存，應當破壞其色澤，染成合乎法度的袈裟色。《十誦律》說：青、黃、赤、白、黑五種純粹的大色衣都不可穿著，補衲衣除外。《薩婆多論》提到：五大色的衣服不能用作三衣；此外，紫草、柰樹皮、地黃、紅緋、黃櫨木等染料染出的顏色，都不合乎法度。若對五大色衣作三點淨，則可以當作其他衣服穿著；所謂紺黑、青、黑色（皁色）、木蘭等色，都可受持為如法衣；純青、淺青、碧綠等色點淨後，只可作衣裡使用；若是赤、白、黃而不屬於純粹的大色，也可以使用。若衣服已經染成不如法的顏色，必須再用如法的顏色覆染，才能受持。《文殊師利問經》說：染色的衣服不能太紅、太黃、太黑、太白，應當是清淨如法的壞色，三件法衣以及其他常服都應如此。律義解釋：作點淨法時，可用前面所提的紺、黑、青三色，在衣服四角任選一角點上一點。《僧祇律》說：點的大小最大如四指，最小如豌豆；《善見論》則說如麻子大。《僧祇律》又說：不可將點連成一片；點的數量可以是一、三、五、七、九點等（取奇數），但不可排列成花朵的形狀；若衣服經過洗滌、穿舊或被泥汙沾染，就自然算作已作淨。若是新縫製的僧伽梨，只需在任一角點淨即可，乃至所有新衣也是如此；若是用許多碎布拼接補綴成的衣，只需在其中一處點淨。「青色」是指銅青色；「黑色」是指用雜泥等染出的黑褐色；「木蘭色」是指用果汁等染出的顏色。律義補充：蜀地有一種木蘭樹皮，其色赤黑而帶有光澤，可用來染色，微有香氣；關東并州也有木蘭樹的果實，既能串成念珠，也可提煉染料，色澤偏黑；京城附近的各山也有這種植物，但採尋者極少。
