# 校閱材料　第022檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【022-0001】01_行事鈔/02a_卷上之二#57
【原文】二明不失略述五種。一非法惡心，解者不失。律云：惡心解淨地不成，例準。二僧尼互結，《善見》云：比丘於尼界上結界不失，尼同得成。三中邊不相解語，亦互重結。四失界相，如《善見》中。五空本處。《五百問》云：大僧與尼通結得，不得相叉。
【譯文】第二是說明不失界的情形，簡略敘述有五種：第一，出於非法或惡意而行解界者，界體不失。律中說：以惡心解除淨地不能成就，比照此例準知。第二，大僧與比丘尼互相結界，《善見律毘婆沙》說：比丘在比丘尼的界域上結界，原尼界不失，而比丘尼同樣能夠成就彼界。第三，中原僧人與邊地僧人語言不通，因而彼此重疊結界，原界不失。第四，界標等外在界相損毀遺失，如《善見律毘婆沙》中所說，界體不失。第五，僧眾暫時離開使得本處空無一人，原界亦不失。《五百問》說：大僧與比丘尼通括在一處結界是可以的，但彼此的界線絕不得互相交錯穿插。

【022-0004】01_行事鈔/02a_卷上之二#60
【原文】一方行化，立法須通；處眾斷量，必憑律教。令遠域異邦，翹心有所；界中行者，安神進業。若斯御眾，何事不行；既行正法，何人不奉？豈止僧徒清肅，息俗歸真；方能扶疏道樹，光揚慧日。若法出恒情，言無所據；科罰同於鄙俗，教網唯事重麁。能施已是於非，所被固多諠亂。故律云：非制而制，是制便斷，如是能令正法速滅；不值佛世，生地獄如箭射。《三千威儀》云：眾中無知法人者，百人千人不得同住；故知同住必遵聖法。今欲刪其繁惡，補其遺漏，使制與教而相應，義共時而並合。故律云：非制不制，是制便行，如是漸漸令法久住。若出其病患，明其損減，如下廣明。
【譯文】在一個地方推行教化，所立的法規條約必須圓融通達；統理大眾、裁斷是非衡量輕重，必定要依憑戒律教法。使遠方異域之人，心有所宗仰嚮往；使結界之內的修行者，能安心精進道業。若能像這樣統理僧眾，還有什麼法務推行不通？既然推行的是如來正法，又有誰會不願信受奉行？豈止能令僧眾清淨肅穆、止息塵俗回歸真道；更能使菩提道樹枝繁葉茂，光大顯揚智慧之日。倘若律制條規純出於常人私情臆測，立言全無教理依據；考核懲處混同於世俗鄙陋之法，統僧綱領只知施用粗暴沉重的刑罰。能施罰的主事者早已陷於非理過咎，被施罰的僧眾自然多生喧騰混亂。所以律中說：「非佛所制卻擅自制定，是佛所制卻擅自斷除廢棄，這樣做會使正法迅速滅亡；來世不得值遇佛世，命終墮入地獄如箭射般迅速。」《三千威儀經》說：「大眾之中若沒有通曉如來戒法的人，即使有百人千人也不得聚居同住」；由此可知大眾同住，必須共同尊崇聖法。如今我想要刪除那些繁雜惡劣的陋規，補足以往被遺漏的法制，使僧團的制度與佛陀的聖教完全相應，義理能與當前的時代相契合。所以律中說：「非佛所制就不擅自制定，是佛所制就切實奉行，這樣就能使正法漸漸長久住世。」至於指出其中的弊病過患、闡明其損減之相，正如後文所詳細說明。

【022-0007】01_行事鈔/02a_卷上之二#63
【原文】《大集》云：若末世中有我弟子多財多力，王等不治，則為斷三寶種，奪眾生眼；雖無量世修戒施惠，則為滅失。廣如第二十九卷〈護法品〉說。又云：若犯過比丘應須治者，一月兩月苦使，或不與語，不與共坐，不與共住，或擯令出；或出一國，乃至四國有佛法處。治如是等惡比丘已，諸善比丘安樂受法，故使佛法久住不滅。
【譯文】《大集經》說：如果末世之中有我的弟子雖然多有財富與勢力，國王等人若不予以懲治，那就是斷絕三寶種姓，奪去眾生的法眼慧眼；國王等人縱使在無量世中修習持戒、布施恩惠，其功德福報也會全部滅失。詳細如第二十九卷〈護法品〉中所說。經中又說：如果犯有過咎的比丘應當予以懲治的，可罰其一、兩個月服苦役勞役，或者大家不與他說話，不與他同坐，不與他共住，或者將其擯逐驅出；甚至將其驅逐出一個國家，乃至驅逐出四國之遠，安置在有佛法流傳的處所。整治了這些惡比丘之後，諸多善良比丘才能安穩快樂地納受正法，因此能使佛法長久住世而不滅亡。
