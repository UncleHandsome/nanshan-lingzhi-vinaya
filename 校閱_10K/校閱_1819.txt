# 校閱材料　第1819檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1819-0001】03_業疏/17a_卷三之六#96
【原文】上雖外形支立，然有饑虗，無由進業，故約內資明乞食法。若身康健，前三足充；必病在身，懷苦妨道，故次第四明服陳藥。
【譯文】上面雖然使外在形體得以支撐維持，但若腹中飢餓空虛，便無從精進道業，所以依據身內資助來說明常乞食法。如果身體康健，前三種法便已足夠充裕；但若疾病纏身，懷抱痛苦妨礙修道，所以接著在第四項說明服用腐爛陳藥。

【1819-0002】03_業疏/17a_卷三之六#97
【原文】內資中，初敘乞食。「若下」，次明腐藥。陳謂陳舊。
【譯文】在內在資助的段落中，起初敘述乞食。自「若下」句起，接著說明腐爛藥。「陳」是指陳舊。

【1819-0003】03_業疏/17a_卷三之六#98
【原文】是以《涅槃》具顯治本，故彼文云：出家之人有四種病，由是不得四所門果，為有衣欲，乃至為有欲。有四良藥能療是病，謂糞掃衣、乞食、樹下坐、身心寂靜治有惡欲，故名四聖行也。
【譯文】因此《大般涅槃經》具體顯明瞭對治的根本，該經文說：出家之人有四種病，由此導致不能證得四沙門果，即是因為有衣服之貪欲，乃至因為有其他貪欲。有四種良藥能治療這些病症，也就是糞掃衣、常乞食、樹下坐，以及用身心寂靜來對治存在的惡欲，所以稱為四聖行。

【1819-0004】03_業疏/17a_卷三之六#99
【原文】引證《涅槃》中，引文前出四病。四沙門即四聖道。文舉衣有二欲，乃至中略食欲、住處欲；欲即貪欲，滯著為病。「有下」，次示四藥，即是四依。第四與《律》不同。有惡欲，謂執世相為實，貪利追求等，故云惡欲；即以身心寂靜治之。一切聖人由茲得道，故云聖種。
【譯文】在引證《大般涅槃經》的段落中，所引經文前段先列出四種病。「四沙門」即是指四沙門果（四種聖道）。經文舉出了衣服之欲與有欲（二欲），「乃至」中間省略了飲食之欲與住處之欲；「欲」就是貪欲，停滯耽著即成過患之病。自「有下」句起，接著指明四種良藥，這也就是四依法。第四項與《律藏》不同。所謂「有惡欲」，是指執著世間相為真實，貪圖名利、四處追求等，所以稱為惡欲；便以身心寂靜來對治它。一切聖人皆由此而證得道果，所以稱為聖種。

【1819-0005】03_業疏/17a_卷三之六#100
【原文】《雜心》大同，依前四欲，轉云愛取，謂因衣生愛、乞食臥具生愛、因有無生愛者（愛斷滅故，除上及此，餘名有愛）。隨次對治，立四聖種。
【譯文】《雜阿毗曇心論》大致相同，依循前面的四種欲，改換稱為「愛取」，即指因衣服而生起貪愛、因乞食與臥具而生起貪愛、因有與無而生起貪愛（這是貪愛斷滅見的緣故；除去上面三種以及這種斷滅愛，其餘的一切法稱為有愛）。隨著次序加以對治，確立了四種聖種。

【1819-0006】03_業疏/17a_卷三之六#101
【原文】《雜心》初句示同。「依下」，正引。初示病。轉即改轉；愛取即欲，語少異耳。乞食是藥，那列病中？必應乞好而制乞麤，或可「乞」合作「已」，論文寫誤。第四論云「因有無有生愛」，即斷、常兩見；愛斷滅者，著邪空也。除上即衣、食、處，及此即斷滅，此四之外，諸所有法，皆名有愛。「隨下」，示藥，亦以寂靜治第四病。
【譯文】《雜阿毗曇心論》引文的第一句表示義理相同。自「依下」句起，正式引用。起初指明病症。「轉」就是改換轉變；「愛取」就是貪欲，只是用詞稍有不同罷了。乞食本是良藥，為何列在病症之中？想必是指貪求精美飲食而戒律規定乞討粗糲之食，或者「乞」字應當作「已」字，是論典傳抄之誤。第四種論典說「因有與無有而生起貪愛」，也就是指斷見與常見這兩種偏見；貪愛斷滅的人，是耽著於邪僻的空見。除去上面的衣服、飲食、住所，以及此處的斷滅見，這四種之外的所有一切法，都稱為「有愛」。自「隨下」句起，指出藥方，也是以身心寂靜來對治第四種病。

【1819-0007】03_業疏/17a_卷三之六#102
【原文】問：《涅槃》、《雜心》何不立藥？答：乞食攝故，又不常須，故不別立。
【譯文】問：《大般涅槃經》和《雜阿毗曇心論》為什麼不確立腐爛藥為四依之一？答：因為它已被乞食所攝納，而且又不是平時經常需要，所以不另行單獨設立。

【1819-0008】03_業疏/17a_卷三之六#103
【原文】初問中，上引經論不立腐藥，與《律》全異，故問決之。答有二釋，並《雜心》文。初釋，彼云依乞食攝藥故；「又下」，次釋，彼云又不一切時故，藥不別立。
【譯文】在第一個問答中，上面引用的經論沒有設立腐爛藥，與《律藏》完全不同，所以提出疑問來決斷。回答有兩種解釋，都出自《雜阿毗曇心論》的文句。第一種解釋，該論說是因為依循乞食就能統攝醫藥之故；自「又下」句起是第二種解釋，該論說又因為不是在一切時候都需要，所以藥品不單獨確立為一條。

【1819-0009】03_業疏/17a_卷三之六#104
【原文】問：為知足立種？為少欲耶？答：《雜心》云：知足現在境起，故立聖種；少欲未來處起。故知現在不取一錢難，未來捨輪王易也。即《涅槃》云「於未得財不生貪」，故云知足也。
【譯文】問：是為了「知足」而確立聖種，還是為了「少欲」呢？答：《雜阿毗曇心論》說：知足是針對現在當前的境界而生起，所以確立為聖種；少欲則是針對未來之處而生起。由此可知，在當下連一文錢都不妄取是困難的，在未來捨棄轉輪聖王之位反而是容易的。這也就是《大般涅槃經》所說的「對於未得之財不生貪著」，所以稱作知足。

【1819-0010】03_業疏/17a_卷三之六#105
【原文】次問少欲、知足二法差別，今此四依為何而立。答中，初正答。知足現境起，對有不貪故；少欲未來起，對無不求故。論云知足立聖種，非少欲故。「故下」，比校二行難易。今依難立，則知行勝。引《涅槃》證，未得財即現在境，但未入手，故云未得。
【譯文】第二個問答是探討少欲與知足兩種法的區別，現今這四依究竟是依哪一種而確立。回答中，首先正面作答。知足是針對現前境界而生起，因為對已有的不生貪著；少欲是針對未來境界而生起，因為對沒有的不去追求。論典說是依知足確立聖種，而不是依少欲之故。自「故下」句起，比較校量兩種修行的難與易。如今依難能之行而確立，就知道其戒行殊勝。引用《大般涅槃經》作證，「未得財」是指眼前的境界，只不過尚未到手，所以稱為未得。

【1819-0011】03_業疏/17a_卷三之六#106
【原文】所言體者，就前境論，四塵也；依《毗曇》，八微也。就內心論，無貪善根性；約眷屬論，善五陰性也。
【譯文】所謂其體性：若就所對的境界來論，是色、香、味、觸四塵；依據《阿毗曇》而言，是八微。若就內心而論，屬於無貪善根之體性；若就伴隨而生的眷屬心所來論，屬於善五陰之體性。

【1819-0012】03_業疏/17a_卷三之六#107
【原文】出體中，初標。「就下」，釋有二：初約境。色塵該四境，香、味收食、藥，觸塵有通別，通竝觸對，別但收衣、樹。《毗曇》、《有部》、《雜心》、《俱舍》，並明八微，謂四塵各起於極微故有四微，四塵之麤假四微所成，故通名八微。「就下」，次約心者，心即是行。《雜心》云：聖種何等性？答：無貪善根性，約眷屬論善五陰性。
【譯文】在顯明體性的段落中，起初標明。自「就下」句起，解釋分為兩部分：首先依境界而論。色塵涵蓋四種依怙的境界，香塵與味塵收攝飲食和藥品，觸塵則有通與別之分，共通而言皆能觸對，差別而言則僅收攝衣服與樹木。《阿毗曇》、《有部》、《雜心論》、《俱舍論》，都闡明八微之說，也就是色香味觸四塵各自生起於極微所以有四大極微，四塵粗顯之相假借四種微細極微所構成，所以通稱為八微。自「就下」句起，其次依自心而論，自心也就是內在修行。《雜心論》說：聖種是什麼體性？答：是無貪善根的體性，若就隨行眷屬而言，則是善五陰的體性。

【1819-0013】03_業疏/17a_卷三之六#108
【原文】四、明次第。
【譯文】第四、說明四依的次第。

【1819-0014】03_業疏/17a_卷三之六#109
【原文】衣則無時不須，資身最要，理先明之。既得覆形，內惱須濟，故次乞食。身雖得立，威儀須託，故第三明樹下坐。無病三足，病起不救，則無治能，故立腐藥為第四也。
【譯文】衣服是沒有任何時刻不需要的，對於資助色身最為切要，理應首先加以說明。既然已經得以遮蔽形體，體內的飢餓熱惱必須救濟，所以接著說明常乞食。身體雖然得以存立，修行威儀必須有所依託，所以第三說明樹下坐。沒有疾病時這前三種已然充足，但若疾病生起而不救治，就沒有修道的精力能耐，所以確立腐爛陳藥為第四項。

【1819-0015】03_業疏/17a_卷三之六#110
【原文】第四正釋中，躡前起後，次第相由，尋文易見。
【譯文】在第四項正式解釋中，承接前文引發後文，各項次第相互承接由來，循著文意很容易看出。
