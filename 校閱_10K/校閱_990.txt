# 校閱材料　第990檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【990-0001】資持記/03d_上二#13
【原文】對反僧中。次科中，初示不結之過。庫藏，即倉廩也。文中兩言淨者，即是淨地。道俗濫者，無所別也；淨穢混者，不辨宿煮，犯不犯也。立下，次責無知。言忽聞者，或知法者諭令行故。惑耳者，聞不解故；驚心者，謂為始立故。豈下，推過。淨住，即伽藍之異名也。三中，初顯過。
【譯文】在「比對相反的僧寺」這一科中。次一小科中，開頭揭示不作「結界」的過失。「庫藏」，就是指存放物資的糧倉庫房。經文中兩次提到「淨」字，就是指「淨地」。所謂「出家與世俗混淆」，是指二者毫無區別；所謂「清淨與污穢雜混」，是指無法辨別是否有過夜存放與在內煮食的差別，從而無法判定是否犯戒。從「立」字以下，接著責備其無知。說「忽聞」，是指或許有通達戒法的人勸喻要他們奉行。說「惑耳」，是因為聽了也不理解；說「驚心」，是因為以為這是新創立的制度。從「豈」字以下，推究這種過失。所謂「淨住」，就是僧伽藍（寺院）的另一種名稱。在第三項中，開頭顯露其過失。

【990-0002】資持記/03d_上二#14
【原文】䩛即乘馬具〔謂鞍轡等〕。韁即馬繩。絆即󰊋束。菤音卷，牛鼻鐶也。橛，具月反，繫牛馬杙也。雜下，引示。流注者，惡業遍也。相續者，念念增也。所以然者，由彼害心非止一境，復無時限故。《善生》、《成論》，失善戒者，惡勢強也。今下，準斥。舉猶合也。言同畜者，或眾主自為，眾心不欲，義無該眾。
【譯文】「䩛」就是騎馬的器具〔指馬鞍、繮轡之類〕。「韁」就是牽馬的繩子。「絆」就是用來捆綁拘束馬腳的繩索。「菤」字音讀為「卷」，是穿在牛鼻子上的環。「橛」字音讀為「具月反」，是用來拴繫牛馬的木樁。從「雜」字以下，引述經文開示。所謂「流注」，是指惡業無所不在。所謂「相續」，是指念念之間不斷增長。之所以會如此，是由於那種殘害眾生的心念不只是針對單一對象，而且也沒有時間期限。《善生經》、《成實論》中說會喪失善戒，是因為惡業勢力極為強大的緣故。從「今」字以下，依照準則予以斥責。「舉」相當於「全」的意思。說「全體一同蓄養」，倘若是住持私自作為，而僧眾內心並不同意，按義理就不該連累全體僧眾。

【990-0003】資持記/03d_上二#15
【原文】言無戒者，惡業順惑，勢力猛盛；一切善戒，並絕相續故；有云：且望一類鼠上，善戒不續非謂餘戒俱無；又云：此乃誡勒之切耳。四中，初列非法。倨，傲也。言依時者，謂法食等時。自下，示所損。並下，推過源。說戒撿校中，初明指授。鳴下，教勸導。五雜教授，能諫中，初引論五法。
【譯文】說「失去了戒體」，是因為惡業順應惑業，勢力兇猛炽盛；一切善戒體，全都會斷絕延續；有人說：這暫且是針對同一類老鼠來說，善戒不再相續，並不是說其餘戒體全部消失；又有人說：這乃是教誡約束之辭極為嚴厲懇切罷了。在第四項中，開頭列出非法行為。「倨」就是傲慢之意。說「依時」，是指順應講法、進食等時節。從「自」字以下，指示其所招致的損害。從「並」字以下，推究過失的根源。在「說戒檢校」這一科中，開頭說明指點傳授。從「鳴」字以下，教導如何勸勉引導。在「雜教授」的第五項中，關於「能諫」，開頭引用論典說明五種法度。

【990-0004】資持記/03d_上二#16
【原文】自有過失，不堪諫他。必下，取彼聽許，則無違諍。此下，正示能諫。諫眾過中二，初示屏諫，諫詞又三，初且泛誘。今下，正陳。欲下，示意。必下，次明對眾諫。得罪者，違教犯吉。諫違制中，初泛勸。引《地持》者，明雖是人制，佛令護之，故不可違。今下，二正陳。觀他自省，故云鑑戒。
【譯文】自己若有過失，便不配勸諫他人。從「必」字以下，必須取得對方的聽許，這樣就不會發生違逆與爭端。從「此」字以下，正式開示能諫之法。在「勸諫大眾之過」（諫眾過）這一項分為二部分，開頭說明暗中勸諫，諫勸的言詞又分為三段，開頭暫且廣泛誘導。從「今」字以下，正式陳述。從「欲」字以下，開示心意。從「必」字以下，接著說明當著大眾的面勸諫。說「得罪」，是指違背教制而犯了突吉羅罪。在「勸諫違背戒制」（諫違制）中，開頭先作廣泛勸勉。引用《菩薩地持經》，是為了說明雖然是人所制立的清規，但佛陀令大眾守護，所以不可違背。從「今」字以下，第二部分是正式陳述。觀看別人的得失以自我反省，所以說是「鑑戒」。

【990-0005】資持記/03d_上二#17
【原文】略陳方軌，餘任臨時，故示云云。諫六聚中。此與初諫何異？答：前在眾中，泛爾麁暴，心性未調，但云有過；不言何聚。文中初泛諭。見下，二審犯勸悔。反上語者，一者見犯，二犯已能懺。注令引經者，彼云：勿謂小罪，以為無殃；水滴雖微，漸盈大器。餘經未詳何文。
【譯文】此處只是簡略陳述方針軌範，其餘如何處置全憑臨機應變，所以用「云云」來表示。在「勸諫犯六聚罪」（諫六聚）中。這與最初的勸諫有何不同？回答：前面是在大眾之中，泛指一般粗暴、心性未調伏的情況，只說是有過失；並未具體說明是犯了哪一聚罪。經文中開頭廣泛曉諭。從「見」字以下，第二是審查犯行並勸令悔過。說「反上語」，一是指能認識到自己犯了罪，二是指犯罪之後能勇於懺悔。夾注中令其引用佛經，是指那部經說：「不要輕視小罪，以為不會有災禍；水滴雖然微小，漸漸也會裝滿大器皿。」鈔文所說的「餘經」則尚不詳明是何經文。

【990-0006】資持記/03d_上二#18
【原文】五不善中：一是斷已生善，二即起未生惡，三違教，四障道，五來報。諫將罰中，初以僧德勸。又云下，以治舉勸。又不下，以奪行勸。餘文可知。明攝眾中，初明益。牽字去呼，猶引也；課牽也，引而率之者，言導誘無倦，令眾獲益也。必下，彰損；初正示。年雖老邁，於法無知，同年小也。故下，引證。
【譯文】「五種不善」之中：第一是斷絕已經生起的善法，第二是生起尚未生起的惡業，第三是違背佛陀的教誡，第四是障礙修證道果，第五是招感未來的苦報。在「勸諫將受處罰者」（諫將罰）中，開頭以僧眾的德相來勸導。從「又云」以下，以依法治辦舉發來勸導。從「又不」以下，以剝奪修行權益來勸導。其餘文句意思容易明白。在「說明統領攝受僧眾」（明攝眾）這一科中，開頭說明其利益。「牽」字讀作去聲，相當於「引導」的意思；「課」即是督課程限，「牽」即是引領率導，引導誘導而率領大眾，是指教導誘導不知疲倦，讓大眾獲得利益。從「必」字以下，彰顯其損害；開頭正式開示。年紀雖然老邁，但對佛法卻一無所知，這與年輕後輩沒有差別。從「故」字以下，引述經文作證。

【990-0007】資持記/03d_上二#19
【原文】律中，阿難徒眾非法，為迦葉所訶。眾欲失者，失猶壞也。汝年少者，命阿難也。俱下二句，斥放逸。初下二句，斥懈怠。遍下二句，斥虛食信施，故言破穀。又解，穀即訓善，言壞他淨信。〔《論語》云：三年學，不至於穀，注云穀善也。〕以下，準文誡約。
【譯文】律藏記載，阿難的徒眾行事不合法度，因而遭到大迦葉的呵斥。說「僧眾將會毀滅」，「失」就是壞的意思。說「你這年輕人」，是在呼喚阿難。從「俱」字以下的兩句，是斥責其放逸。從「初」字以下的兩句，是斥責其懈怠。從「遍」字以下的兩句，是斥責其虛耗吞食信徒的布施，所以說是「破壞糧穀」。另一種解釋，是將「穀」訓讀為「善」，意思是毀壞了他人清淨的信仰。〔《論語》說：「學習了三年，心思還不在求取善道上」，註解說穀就是善的意思。〕從「以」字以下，依照經文進行告誡與約束。

【990-0008】資持記/03d_上二#20
【原文】善知法相者，以多聞故。若據佛在，阿難猶是學人；今云無學者，從後為言。自輕，謂不以攝眾為重故。簡人中，初標示。須下六句，列示五德。初行潔，二志堅，三學廣〔中間二句〕，四識高，五智深。可下二句，示堪能。今時昏鄙，無有一德，輒居僧首；
【譯文】所謂「善於了知法相」，是因為聽聞佛法極為廣博的緣故。若依佛陀在世時的情形來看，阿難當時還只是個「有學」之人；現在說他是「無學」，是順從後來的果位而說的。所謂「自輕」，是指不把統領大眾當作一件重大的事。在「甄選人才」（簡人）這一科中，開頭標明指示。從「須」字以下的六句，列出並開示五種德行：第一是德行純潔，第二是志向堅定，第三是學識廣博〔即中間的兩句〕，第四是見識高超，第五是智慧深邃。從「可」字以下的兩句，指出其所具備的堪能。現今時代的人昏聵鄙陋，毫無一德，卻動輒佔據僧團首領之位；
