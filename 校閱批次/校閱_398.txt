# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【398-0001】02_戒疏/21a_卷四下之三#140
【原文】【疏】言「毗尼」者，此云「律」也。「律」者，分也，筆也。謂須商度，據量有在，若律呂之分氣故也。又如世法據刑約制，道法亦爾，依根附教，各有差降，不可乖越，故曰「法」也。「律」字安「聿」，「聿」者筆也。必審教驗情，在筆投斷，如斯面對，故曰「毗尼」。如初解也。
【譯文】【疏文】所謂「毗尼（Vinaya）」，在漢地翻譯為「律」。「律」有劃分（分）以及筆錄定斷（筆）的意涵。意思是必須經過審度商量，掌握客觀的分寸尺度，就如同音樂律呂劃分陰陽二十四節氣一樣不差。又如同世俗法律必須依據刑名條文來規範約束，出世間的佛法也是如此，依據當事人的見聞疑三根、附順於律藏聖教，各有其等級輕重差異，不可乖違踰越，所以稱為「法」。「律」字旁邊安立了「聿」字，「聿」本來就是筆的意思。必定要詳審聖教法意、查核內心深淺，掌握在執筆下筆的定斷之中，像這樣當面相對來判定是非，所以稱為「毗尼」。就如同最初所作的解釋。

【398-0002】02_戒疏/21a_卷四下之三#141
【原文】【記】次科。翻名示義。「謂」下，別釋。初釋分義。一年十二月，奇月為「律」，偶月為「呂」。「律」為陽，「呂」為陰。一律一呂，各有二氣，六律六呂，共二十四節氣。故今喻「據量」，判斷無濫。「又」下，次釋筆義。初約俗律釋，上卷云「筆即法家之象」是也。「據刑」，謂刑名；「約制」，即條制。「依根」，即三根；「附教」，即律文。「律」下，正合筆義。從人從聿，象人執筆，《說文》曰「聿，所以書也。楚謂之『聿』，吳謂之『不律』，燕謂之『弗』，秦謂之『筆』」。「審教」，謂詳法制重輕；「驗情」，謂察用意深淺。俗中判斷，落筆定刑，況今律乘，準判即決。舉彼類此，故曰「如斯」。言「面對」者，即「現前」義。「如初解」者，指上三、五現前。
【譯文】【記文】次一科。翻出名目以顯示義理。「謂」字以下，是分別解釋。首先解釋「分」的意義。一年有十二個月，單數月為「律」，雙數月為「呂」。「律」屬陽，「呂」屬陰。一「律」一「呂」各有二氣，六律六呂合起來共二十四節氣。所以現在用它來比喻「據量」（依準度量），判斷而沒有氾濫差錯。「又」字以下，其次解釋「筆」的意義。首先就世俗的律法來解釋，上卷說「筆即法家之象」（筆是法家的象徵），就是這個意思。「據刑」，是說刑名；「約制」，就是條制。「依根」，就是三根；「附教」，就是律文。「律」字以下，正式會合「筆」的意義。字形從「人」從「聿」，象徵人執筆，《說文》說：「聿，所以書也（聿，是書寫的工具）。楚地稱它為『聿』，吳地稱為『不律』，燕地稱為『弗』，秦地稱為『筆』。」「審教」，是說詳細審定法制的輕重；「驗情」，是說考察（犯者）用意的深淺。世俗中判斷案件，落筆就定下刑罰，何況現在所講的律乘，依準判斷就立即裁決。舉世俗的事來類比此事，所以說「如斯」（如此）。所說的「面對」，就是「現前」的意思。說「如初解」，是指上面所說的三種現前與五種現前。

【398-0005】02_戒疏/21a_卷四下之三#144
【原文】【註】佛在舍衛國。時，迦留陀夷與六群在河浴，迦留陀夷誤著彼衣而去。六群比丘後謂彼盜，便不現前與滅擯羯磨。迦留陀夷以緣白佛。便訶責已，因制此法。有三種現前，法、毗尼、人也。有五種現前，法、毗尼、人、僧、界也。云何法現前？所持法滅諍者是。云何毗尼現前？所持毗尼滅諍者是。云何人現前？言議往反者是。云何僧現前？應來者來，應與欲者與欲，得訶人不訶者是。云何界現前？唱羯磨作制限者是。此現前法，通一切羯磨。若別人對首、心念，三種現前即得。若四人、五人已上僧法，若作羯磨，必須五法現前。以羯磨所起，必在作法界故，唯除結界自然界中也。
【譯文】【註文】佛陀駐錫於舍衛國。當時迦留陀夷尊者與六群比丘在河中沐浴，迦留陀夷誤穿了對方的衣服離開。六群比丘事後指控他偷盜，隨即便在迦留陀夷不在現場的情況下，私自作羯磨將他驅逐出僧團（滅擯羯磨）。迦留陀夷將事情始末稟告佛陀。佛陀呵責了六群比丘之後，因而制定了這項法則。有所謂的三種現前，即法現前、戒律現前（毗尼現前）、當事人現前。有所謂的五種現前，即法、戒律（毗尼）、當事人、僧團、結界全體現前。什麼叫做「法現前」？是指依法所持誦用以平息諍論的教理羯磨文句。什麼叫做「毗尼現前」？是指依戒律精神推選如法有德的裁決方式來平息爭端。什麼叫做「人現前」？是指當事雙方當面進行問答辯駁。什麼叫做「僧現前」？是指該出席的僧眾都已出席，應當委託同意權（與欲）的皆已委託，有權提出異議者沒有提出異議。什麼叫做「界現前」？是指依規定宣告唱誦界限圍繞的作法空間。這種現前法則，通融貫穿於一切僧團羯磨法事。如果是兩個人個別面對面（對首）或是獨自心中的作法（心念），只要具備三種現前就可以成就。若是四人、五人以上共同舉行的僧團法事，如果要作羯磨，就必須五種法則全部現前。因為羯磨所發起推展的範圍，必然是在法定的結界之內，唯獨在結界當下所依託的自然界中可以例外。

【398-0008】01_行事鈔/11a_卷下之三#30
【原文】初中敬佛塔法。若塔廟支提用受之物，乃至擬造堂殿床座材石等，已經佛像受用者；縱使風吹雨破，當奉敬之，如形像無異。故《四分》中，王以園施佛，佛不受，當令奉僧。何以故？若佛園及園物、房舍、房舍物、衣鉢、坐具、針筩，便是塔廟；一切諸天、世人、沙門、魔、梵不能受用，應恭敬如塔。《增一》云：告諸比丘，禮佛承事，有五功德：一者端正，以見佛像，發歡喜心。二者好聲，由見形像，口自稱號南無如來、無所著、至真、等正覺。三多財報，由以華香供施故。四生長者家，由見形已，心無染著，志心禮故。五命終生天。此即諸佛常法，當如是學。《智論》禮法有三：一者口禮。二屈膝頭不至地。三頭至地，是為上禮。《地持》：當五輪至地作禮。《阿含》云：二肘、二膝、頂，名輪也，亦云五體投地。先正立已，合掌，右手褰衣，屈二膝已，次屈兩肘，以手承足，然後頂禮；後起頂頭，次肘，次膝，以為次第。《智論》云：若聞諸佛功德，心敬尊重，恭敬讚歎。知一切眾生中，德無過上，故言尊也；敬畏之心過於父母、師長、君王，利益重故，故云重也；謙遜畏難，故云恭；推其智德故云敬；美其功德為讚；讚之不足，又稱揚之為歎。又云：植佛福田者，植謂專心堅著也。隨以一善，禮誦香華等，至佛無盡，由智勝故。《毘尼母》：不得著革屣入塔、繞塔。富羅不得入塔者，彼土諸人著者，皆起慢心，故不聽著。寒雪多處，聽著靴富羅。《三千》云繞塔法：一低頭視佛，二不得蹈蟲，三不左右視，四不唾地，五不與人語。又當念佛，恩大難報；念佛智慧，念佛經戒，念佛功德，念佛精進，乃至泥洹。又念僧恩，師恩，父母恩，同學恩。又念一切人，皆使解脫離苦。又念學慧，除其三毒，求出要道。見塔上草，念手去之，不得捉拔。有不淨，即分除之。若天雨，當脫履塔下，乃上禮佛。《五百問》云：比丘繞塔，女眾隨者，不得；有優婆塞，不犯。《大論》如法供養法，必應右繞。《賢愚》：舍利弗辭佛，膝行繞百匝也。《善見》云：辭佛法，繞佛三匝，四方作禮而去；合十指爪掌，叉手於頂上，却行；絕不見如來，更復作禮，迴前而去。《雜含》云：憍陳如久不見佛，後來；便以面掩佛足上，致禮。
【譯文】首先是禮敬佛塔佛像之法。凡是塔廟、支提（靈廟塔塚）所受用的物品，乃至預備用來建造堂宇殿堂、床座的木材、石料等，只要已經為供養佛像所受用過的；縱然被風吹雨打毀損殘破，仍應當像對待佛陀形像一樣毫無二致地恭敬奉持。所以《四分律》中記載，國王將園林布施給佛陀，佛陀不接受，而是指示應當施奉給僧眾。為什麼呢？因為若是專歸佛陀所有的園林與園中之物、房舍與舍內物品、衣鉢、坐具、針筒等，便都等同於塔廟聖物；一切天人、世人、沙門、魔王、梵天都消受承受不起，必須像尊敬佛塔一樣加以恭敬。《增一阿含經》說：告誡諸位比丘，禮敬佛陀、承事奉事，能獲得五種功德：一是相貌端正莊嚴，這是由於見到佛像而生起歡喜心的緣故。二是聲音美妙動聽，這是由於瞻仰聖相，親口稱揚名號「南無如來、應供（無所著）、正遍知（至真、等正覺）」的緣故。三是獲大財富果報，這是由於用鮮花名香供養布施的緣故。四是投生於富貴長者之家，這是由於見了聖相後內心毫無染著、至誠專心禮拜的緣故。五是壽命終結後往生天界。這就是諸佛一貫的常軌法則，應當如是修學。《大智度論》說禮敬之法有三種：一是口頭致敬（口禮）。二是屈曲雙膝但頭不著地。三是頭面著地，這是最上等的禮法。《菩薩地持經》說：應當以五輪著地行禮。《阿含經》說：雙肘、雙膝和頭頂，稱為「五輪」，也就是俗稱的「五體投地」。動作次序是：先肅穆直立，雙手合掌，右手提撩衣服，先彎曲雙膝跪下，接著彎曲雙肘著地，雙手手掌向上托承佛足，然後以頭額觸地頂禮；起身時先抬起頭部，接著抬起雙肘，最後直起雙膝，以此作為恭敬拜伏的先後順序。《大智度論》說：如果聽聞了諸佛的功德，內心應當由衷敬畏尊重、恭敬讚歎。深知在一切眾生之中，沒有任何人的德行能超越於佛，所以稱為「尊」；敬畏愛戴的心情超過了對待自己的父母、師長、君王，所蒙受的法益無比深重，所以稱為「重」；謙卑遜讓、戒慎恐懼，所以稱為「恭」；推崇歸仰其智慧功德，所以稱為「敬」；由衷稱美其巍巍功德稱為「讚」；僅是稱美猶嫌不足，進而宣揚歌頌就稱為「歎」。該論又說：在佛這塊大福田中播種善根（植佛福田），「植」的意思是專心一意、堅定不移。只要隨順修持哪怕一件微小的善法，如頂禮、誦經、供奉香花等，其功德迴向佛道便廣大無窮無盡，這都是由於佛陀智慧超勝所致的緣故。《毘尼母論》記載：不得穿著皮鞋進入佛塔，也不得穿皮鞋繞塔巡禮。「富羅（印度一種裝飾性厚皮靴履）」也不得穿進塔中，因為在印度穿著這種鞋履的人往往會生起驕慢炫耀之心，所以不許穿著。但在嚴寒多雪的極冷地區，則開許穿著靴子和富羅。《大比丘三千威儀》說繞塔之法：一是低頭瞻仰佛容，二是留心不得踩踏蟲蟻，三是目光專注而不左右顧盼，四是不隨地吐痰唾液，五是不與旁人交頭接耳交談。同時應當憶念佛陀浩瀚的大恩難以報答；憶念佛陀的深廣智慧，憶念佛陀的經典戒律，憶念佛陀的種種功德，憶念佛陀的勇猛精進，乃至證得大般涅槃。又憶念僧寶之恩、師長之恩、父母之恩、同修同學之恩。又發願憶念一切眾生，令他們皆得解脫離苦。又憶念修學智慧，除滅貪瞋癡三毒，尋求出離生死的大要之道。看見佛塔上長了雜草，應當以手除掉它，不得隨便抓拔；若有不淨污物，應當立即隨分隨力清除乾淨。如果逢上下雨天，應當在塔階下方脫下鞋子，然後才能登塔禮佛。《五百問》說：比丘在繞塔時，若有女性信眾緊隨其後，是不許可的；但如果有優婆塞（男居士）同行陪同，則不犯過。《大智度論》指出如法的供養法則，必定要向右順時針圍繞（右繞）。《賢愚經》記載：舍利弗尊者向佛陀辭別時，長跪膝行繞佛達一百圈。《善見律毘婆沙》說：辭別佛陀的法則，應當順時針繞佛三圈，向四方恭敬作禮後離去；雙手十指合掌，雙手交叉置於頭頂上方，倒退著向後走；一直退到完全看不見如來的聖容時，再恭敬頂禮一次，然後才轉身向前離去。《雜阿含經》記載：憍陳如尊者很久沒有見到佛陀，後來相見時，便俯身以面頰緊緊貼在佛陀雙足之上，行最深沉的敬禮。

【原文】【註】佛在王舍城。時，沓婆摩羅子為僧知事。六群中得惡房臥具、惡請處，起瞋謗言「有愛、恚、怖、癡」，遂以婬事誣謗。親於眾中，佛問虗實，彼言：「我從生來，乃至夢中不婬，況於覺寤？」比丘以事詰問六群，便言：「沓婆清淨，無如是事。」佛言：「沓婆無著人，不故犯戒，應白四羯磨與憶念法也。」
【譯文】【註文】佛陀住在王舍城時。那時，沓婆摩羅子比丘擔任僧團的知事。六群比丘分到了較差的房舍臥具和較差的受請齋處，便生起瞋恨心譭謗他說「有偏愛、瞋恚、怖畏、愚癡」，隨後更以淫行誣衊譭謗。佛陀親自在大眾中查問虛實，沓婆回答：「我從出生以來，乃至在夢中都不曾行淫，何況是清醒的時候？」比丘們便拿這件事質問六群比丘，六群比丘才說：「沓婆是清淨的，並沒有這樣的事。」佛陀說：「沓婆是斷除執著的阿羅漢，不會故意犯戒，應當作『白四羯磨』為他施行『憶念法』。」
