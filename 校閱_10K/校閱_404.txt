# 校閱材料　第404檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【404-0001】02_戒疏/04a_卷一下之二#150
【原文】【疏】「據如此理，亦無同異兩世。念念趣境，皆有違教之心。是以《律》云『發心作，心念作』，即其證也。」
【譯文】【疏文】義理疏文說：「根據這樣的正理，也就不存在所謂同一世或異世的差別了。只要心念念念趣向惡境，念念之中都懷有違背佛教之意。因此《四分律》中說『起心動念想作、心意謀度去作』即結罪，這就是明晰的鐵證。」

【404-0002】02_戒疏/04a_卷一下之二#151
【原文】【記】次科中，初點破。上句承前義，下句顯古非。「兩世」，即上一世異世。「念念」下，立義。初正立。「是以」下，引證。《律》中「發心、心念」犯吉，明知違制。
【譯文】【記文】第二小科中：首先點破舊說。上一句承接前面的正義，下一句顯發古德之謬。「兩世」指的就是上面所談的一世與異世。「念念」以下，樹立正義：首先正面立論；「是以」以下，引律文為證：律中「發心、心念」即犯突吉羅，由此證明因位確實已違背了佛制。

【404-0003】02_戒疏/04a_卷一下之二#152
【原文】【疏】問：「此之進趣，與近方便，復何殊邪？」
【譯文】【疏文】義理疏文說：提出問難：「這種進趣方便，與前面的近方便，又有什麼差別呢？」

【404-0004】02_戒疏/04a_卷一下之二#153
【原文】【疏】答：「言『進趣』者，心事不絕為名；言『近方便』者，從因至果，時分延促為義。何以分之？如前《了論》立三方便，此義合之，總名為『近』。」
【譯文】【疏文】義理疏文說：回答道：「所謂『進趣』，是以起心造事連續不絕來立名；所謂『近方便』，是以從起因走向結果之間，時間跨度的長短遲速為其內涵。如何區分呢？正如前面《明了論》所安立的三種方便，若把這個義理統整起來，總括都可稱之為『近』。」

【404-0005】02_戒疏/04a_卷一下之二#154
【原文】【記】初問，可解。答中。初示名義不同。遠者名「延」，近則名「促」，次通「延」、「促」。「何」下，正分兩別。但近方便，定約三時；進趣，念念隨結。如起淫心，即遠方便；後心思度，未動身口，念念吉羅，則是進趣。纔動身口，即次方便；身未交前，步步偷蘭，則是進趣。身分纔交，即近方便；未至究竟，並是進趣。欲令易曉，不覺詞繁。
【譯文】【記文】最初的問難，文義易明。回答之中：首先開示名號與義理的不同。時間長遠稱為「延」，時間短促稱為「促」，次方便則兼通「延」與「促」。「何以」以下，正式分判兩者的差異：近方便必定是就三個時位而言；進趣方便則是念念隨行隨結。例如剛動淫念，屬於遠方便；隨後心中盤算謀度，身體言語尚未發動，這期間念念結突吉羅罪，這便是進趣方便。色身言語稍一動作，即進入次方便；然而在身體未交合之前，前進的每一步驟步步結偷蘭遮，這又是進趣方便。身體局部剛一交接，即屬於近方便；但在尚未達到極限究竟之前，這一過程全都是進趣方便。為了使後學容易通達明了，故而不自覺言詞繁複。

【404-0011】02_戒疏/04a_卷一下之二#160
【原文】【記】第三難。以息不息各有所歸，則「近方便」義成無用，故云「何須」等。答中，先約二喻，顯二方便。「不妨」下，正通前難。謂近方便雖復暫息，而遠期根本；闕緣不爾，事止不成故。
【譯文】【記文】第三個質難。問難者認為停息與不停息既然各有其歸宿，那麼「近方便」這一名稱就成了多餘無用之說，所以質詢「何須」等。回答中：首先借用兩個譬喻，顯發這兩種方便的不同相貌。「不妨」以下，正面化解前面的質難：說明近方便雖然暫時停息，但心志依然遙指根本果罪；闕緣方便則不然，它是事情徹底終止而無法成辦故。

【404-0016】02_戒疏/04a_卷一下之二#165
【原文】【疏】有人製疏，改曰「不成」，以《律》文云「不成，偷蘭」。今解亦得，何須較執，即《律》文云「方便求盜不得，偷蘭」，斯則明證。
【譯文】【疏文】義理疏文說：有人撰寫律疏，將此改稱為「不成」，因為《四分律》文常說「若事情不成，結偷蘭遮」。如今我們解釋：稱作「不成」也可以，何必固執於特定文字呢？正如《四分律》文也明確記載「以方便企圖偷盜而未得財物者，結偷蘭遮」，這就是有力的證明。

【譯文】【記文】在「斥責古說」中：首先引述古德之論。古德認為「方便」既然是「趣向果罪」的名稱，如今既然未能到達果位，怎能稱作方便？充其量只能稱作「不成」罪而已。「今解」以下，斥責其偏狹自限。「較」讀作覺，是裁決固定的意思。既然兩種稱呼在律文中都有確切依據，義理上並無不可，哪能偏執於單一文句呢？
