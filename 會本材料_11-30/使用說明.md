# 會本材料 11–30　使用說明

## 一、資料夾

```
會本材料_11-30/
├─ bounds/            ← 鈔界（每條鈔從哪個記段開始）
│   ├─ 篇11_bounds.md … 篇30_bounds.md
│   └─ 篇14_分塊/第1–6塊_…_bounds.md
├─ splits/            ← 切點（跨鈔記段的切點）
│   ├─ 篇11_splits.md … 篇30_splits.md
│   └─ 篇14_分塊/第1–6塊_…_splits.md
└─ 使用說明.md
```

每一份 md 都是**提示詞＋該篇全文資料**，整份複製貼上即可。

## 二、流程

1. `bounds/篇NN_bounds.md` → 貼給 AI → 收 `{"bounds":[...]}`  
   存成 `AI語譯/_work/pian_bounds/bounds_篇NN.json`
2. `splits/篇NN_splits.md` → 貼給 AI → 收 `{"splits":[...]}`  
   存成 `AI語譯/_work/pian_splits/split_篇NN.json`
3. 告訴我「篇NN 好了」，我跑：
   ```
   mk_pian_split.py NN     # 出會本 docx
   chk_pian_docs.py        # 檢查逆序／無記鈔
   ```
   再轉 PDF 給你驗。

## 四、JSON 格式

**bounds**
```json
{"bounds": [{"c": 2, "n": 5}, {"c": 3, "n": 13}]}
```

**splits**
```json
{"splits": [{"n": 16, "base": 4, "markers": ["大界中"], "targets": [4, 5]}]}
```

規則：
- `markers` 必須在該記段原文中逐字出現
- `targets` 必須是 `base, base+1, …`
- 不確定不要列

1. 練手：篇25（9 鈔/16 記）→ 篇20（6/35）→ 篇19（29/42）
2. 中小篇：11、12、13、16、18、21–24、26、27、29

## 六、我會先驗

收到 JSON 後先檢查：c 連續、n 遞增、marker 逐字存在、targets 連續；有問題直接指出哪一條，不硬套。
