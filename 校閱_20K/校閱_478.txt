# 校閱材料　第478檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【478-0001】資持記/03d_上二#6
【原文】此那那由比丘心亂狂癡，或憶說戒，或不憶說戒，或來或不來；若僧時到僧忍聽，與此比丘作心亂狂癡羯磨，若憶若不憶，若來若不來，僧作羯磨說戒，白如是。〔羯磨準作。〕四對處明用；威儀中，初敘損益。《十誦》下，引文證。《伽論》中，並明上座軌眾之法；
【譯文】這位那那由比丘心智錯亂狂癡，或者記得要說戒，或者不記得要說戒，或者會來，或者不會來；如果僧團適時方便，請僧團大眾聽許，為這位比丘舉行心亂狂癡羯磨，無論他記不記得，無論他來不來，僧團都舉行羯磨來說戒。白告文詞就是如此。」〔正式羯磨文依此準則作。〕第四項是「針對處所說明儀軌作法」（對處明用）；在「威儀」這一項中，開頭先敘述其利益與損害。從《十誦律》以下，引證經文。在《摩得伽論》中，一併說明了上座軌範統領大眾的方法；

【478-0002】資持記/03d_上二#7
【原文】初看威儀，是今正用；下行食等，因而引之。僧跋，梵言，即上平等行食之唱法耳；〈赴請篇〉中亦同此引，即等供也。《十誦》下，指同。處眾法中，初引論示法。賢聖即弟子眾。準下，準論誡過。不得下，反上說法。又下，反上默然。修飾中，初科分二；上二句通標。薩下，別釋；
【譯文】一開始審查僧眾威儀，是當前正要採用的內容；後面分發食物等事項，是順帶引述的。「僧跋」是梵語，就是指前面所說的平等分發食物時的唱誦法式；在〈赴請篇〉中也作了相同的引述，意思就是平等供養。從《十誦律》以下，指出其規範相同。在「處眾法」這一科中，開頭引用論典以開示法度。「賢聖」就是指弟子大眾。從「準」字以下，依照論典來告誡過失。從「不得」以下，從反面說明上面應當說法的規定。從「又」字以下，從反面說明上面應當保持默然的規定。在「修飾」這一科中，第一小科分為兩部分；前面兩句通盤標示綱要。從「薩」字以下，作個別解釋；

【478-0003】資持記/03d_上二#8
【原文】前明剃剪，初《多論》明制，違則有罪。次引《四分》限時，不得更過。三引《涅槃》顯過。頭鬚爪髮，有云語倒，合作頭髮鬚爪，或可簡異餘毛，故曰頭鬚，即《說文》云面毛是也。〈雜篇〉，明指爪極長一麥應剪。長字平呼。經云：是破戒之相，故云佛訶。
【譯文】前面說明剃頭剪甲，首先引《薩婆多論》說明戒制，若是違犯便有罪過。其次引用《四分律》規定限期，不得超過期限。第三引用《涅槃經》以顯露其過失。經文中的「頭鬚爪髮」，有人說是語序顛倒，應作「頭髮鬚爪」，或者也可以說是用來區別於其他體毛，所以稱為「頭鬚」，也就是《說文解字》所說的臉部的毛。在〈雜篇〉中，說明指甲極限長到一顆大麥長時就應當剪去。這裡的「長」字讀作平聲。經中說：這是破戒的徵象，所以說佛陀深加呵責。

【478-0004】資持記/03d_上二#9
【原文】所下，次明著用。示如非相，在文可曉。下指履屐，如鉢器，亦見〈二衣篇〉中。次科。初明入眾五法者，一修慈愍物，二謙下自卑，三如鈔引，四說於法語，五見過修默。《十誦》下，初明起坐。次明入堂，初運想法。次下，出入法。文明東西舉足，且據堂門面南為言；
【譯文】從「所」字以下，接著說明衣物的穿著與使用。指明如法與不如法的相貌，在經文中可以明了。下面指出鞋履之類，如同缽具一樣，也見於〈二衣篇〉之中。下一個小科。開頭說明進入大眾的五種法度：一是修持慈悲憐憫眾生，二是謙遜降伏自己的傲慢，三如鈔文所引，四是只說佛法法語，五是見人有過則修持沉默。從《十誦律》以下，開頭說明起立與坐下的禮儀。其次說明進入殿堂之法，首先是運心作意之法。從「次」字以下，說明出入殿堂的規矩。律文明白寫著向東或向西邁出腳步，這暫且是依據堂門面朝南方來說的；

【478-0005】資持記/03d_上二#10
【原文】以要示之，但使出入先舉門頰邊脚，則通餘處，不必東西也。若欲下，示坐法。著用離俗中，初明俗服。褶亦袴類。袍亦襖類；裘謂皮衣。䩺即是靿。銅下，明俗器。瓦鉢體如，列在非者，或色量不如故。〔寫本或無瓦字。〕璭古困反，油字去呼。並下，明違教。善下，引證。當，猶應也。
【譯文】總括要點予以說明：只要出入時先跨出靠近門框那一側的腳，就能通達應用於其他方位的門，不必拘泥於非要東邊或西邊。從「若欲」以下，開示就坐的規範。在「著用離俗」這一科中，開頭說明在俗的服飾。「褶」也是褲子的一類。「袍」也是夾襖之類；「裘」是指皮衣。「䩺」就是靴筒。從「銅」字以下，說明世俗的器具。瓦缽的質地雖然合乎法度，卻列在不法之器具中，可能是因為顏色或容量不合乎規定。〔有的寫本中沒有「瓦」字。〕「璭」字音讀為「古困反」，「油」字在此讀作去聲。從「並」字以下，說明違背佛陀的教誡。從「善」字以下，引用文獻作證。「當」，相當於「應」的意思。

【478-0006】資持記/03d_上二#11
【原文】無罪者，據壞他物，本是盜收；心在護法，故開無犯。就處明用，初科引寺誥；前示過誡約。經即《涅槃．三十一》云：雖不與彼女人相合嘲調戲笑，於壁外遙聞女人瓔珞環釧種種諸聲，心生愛著；如是菩薩毀破淨戒，污辱梵行。僧下，引證。比下，斥時；初示僧寺。
【譯文】所謂「沒有罪過」，是依據毀壞他人器物本來會構成盜竊罪來判定；但此時存心是為了護持正法，所以開許為不犯戒。在「就處明用」這一科中，第一小科引述寺院的誡誥；前面揭示其過失並予以告誡約束。所引經典即是《涅槃經》卷三十一所說：即使不與那女人相聚調笑戲謔，只是在牆壁外遠遠聽聞女人身上瓔珞手鐲等種種聲音，心中生起貪戀執著；像這樣的菩薩便是毀壞了清淨戒法，玷污侮辱了清淨梵行。從「僧」字以下，引述經文為證。從「比」字以下，斥責當前的時局；首先指明僧寺的情況。

【478-0007】資持記/03d_上二#12
【原文】留穢謂畜女，去淨即除淨人。央，盡也。今時下愚，多因針縷，履涉婬舍，招俗譏訶；或在僧坊，牽延累日。取與不護於摩觸，語笑豈慎於麁言；染意窺看，念念重吉；深寮坐起，一一單提；現身遭世俗之刑，袈裟永離；生報有泥犁之苦，燒煮難堪。宜奉聖言，可保終吉。拘繫同者，謂如囚禁也。下明尼寺。
【譯文】所謂「留穢」，是指蓄養留住婦女；所謂「去淨」，是指趕走給予役使的淨人。「央」是竭盡的意思。現今時代低劣愚昧的人，多半因為做針線縫紉的事，而涉足出入煙花婬舍，招致世俗之人的譏嫌呵斥；或者讓婦女逗留在僧房中，拖延羈留好幾天。遞交拿取東西時不防備身體相觸，言談說笑中哪裡顧忌粗鄙浮薄的話語；以染著之心窺視觀看，念念之間都結成嚴重的突吉羅罪；在幽深的寮房中共坐同行，每逢一次便犯一次單墮罪；現世之身遭受世俗王法的刑罰，永遠脫去僧伽藍之袈裟；來世之報將受地獄的酷刑，油煎火燒之苦難以忍受。應當奉持佛陀聖言，才能確保最終的吉祥。所謂「如同拘繫」，是指像犯人被囚禁一樣。下面說明尼寺的情況。

【478-0008】資持記/03d_上二#13
【原文】對反僧中。次科中，初示不結之過。庫藏，即倉廩也。文中兩言淨者，即是淨地。道俗濫者，無所別也；淨穢混者，不辨宿煮，犯不犯也。立下，次責無知。言忽聞者，或知法者諭令行故。惑耳者，聞不解故；驚心者，謂為始立故。豈下，推過。淨住，即伽藍之異名也。三中，初顯過。
