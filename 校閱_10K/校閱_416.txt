# 校閱材料　第416檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【416-0001】02_戒疏/04c_卷一下之二#19
【原文】【疏】若據心用，以明持犯，一切諸戒，並二持犯。何者是邪？且如婬戒，順教禁防，即止持義；觀厭現前，無思染穢，縱有境逼，三時不樂，名為作持。違作止犯，違止作犯。
【譯文】【疏文】如果依據內心的心念運作，來說明持戒與犯戒，那麼所有的戒條，都同時通向雙重持戒與雙重犯戒。情況究竟如何呢？姑且以淫戒為例，順從佛法教導而自我禁防，這就是止持的意義；若能在對境時生起厭離觀想，心不起貪染污穢，即使面臨外境強逼，在行事的前中後三時都毫無樂受，這就是作持。違背了作持便是止犯，違背了止持便是作犯。

【416-0002】02_戒疏/04c_卷一下之二#20
【原文】【記】心用中。通「諸戒」者，凡持一戒，必起護心，望離惡邊，即成止持；望起護邊，復是作持。兩犯亦爾，違教作惡，必無對治。文約淫戒，示相可解。此謂二持兩犯，各自相通。非謂持中有犯，以善惡行別，違順心乖故也。
【譯文】【記文】在心念運作的說明中。通向「所有戒條」的意思是，凡是受持任何一條戒，內心必定生起防護的意念；從遠離惡行的角度看，就成就了止持；從生起防護行動的角度看，又成就了作持。兩種犯戒也是同樣的道理，違背教導去造惡，內心必定缺乏對治的防護。文中藉由淫戒為例，所呈現的行相很容易理解。這是說明二持與兩犯各自在自類中是相通的。並不是指在持戒當中有犯戒，因為善行與惡行本質不同、違逆佛意與順應佛意的心態完全相反。

【416-0003】02_戒疏/04c_卷一下之二#21
【原文】【疏】若據教行，必託境生，依教奉行，作而無犯。何者是邪？且如三衣，教遣備具，不敢違侮，名為「止持」；如教䇿修，順行不犯，名為「作持」。違此二持，便成兩犯。可同殺、盜，有教開作，名作持邪？
【譯文】【疏文】如果依據教法的實踐，就必須依托具體的外境而生起，依照教規去奉行實踐，有所作為而沒有違犯。這又是怎樣的情況呢？姑且以三衣為例，戒教指令僧人必須備齊，不敢違抗怠慢，這就稱為「止持」；按照戒律教導策勵修持，順行教規而不違犯，這就稱為「作持」。違背了這兩種持戒，就構成了兩種犯戒。這難道能和殺生、偷盜等戒相比，有哪條教規會開許你去作為，而能稱為作持嗎？

【416-0004】02_戒疏/04c_卷一下之二#22
【原文】【記】次教行者。此門須約有教令行，方具二持。如僧殘二戒，「三十」中九戒，「九十」中十二戒，提舍二戒，眾學中一戒。此約《戒本》具雙持者，餘皆單持。
【譯文】【記文】其次依據教法實踐來說。這個門類必須針對佛陀有制定教令要求去實踐的事，才算具備雙持。例如僧殘戒中的兩條、三十捨墮中的九條、九十單墮中的十二條、提舍尼中的兩條、眾學戒中的一條。這是就《戒本》中具備雙持的戒條而言，其餘的戒都屬於單純的止持。

【416-0005】02_戒疏/04c_卷一下之二#23
【原文】【記】是則一切作持，其必兼止；若但止持，未必有作。自餘羯磨衣鉢等事，則見廣律。文舉「三衣」，其相甚顯。「侮」，音武，慢也。「可同」下，對單持辨異。以殺盜等無教開作，則無雙義。
【譯文】【記文】由此可見，一切的作持必定兼具止持；如果單純只是止持，則不一定兼具作持。至於其餘各項羯磨法、衣鉢等具體規矩，詳見廣律中的記載。文中以「三衣」為例，其行相十分明顯。「侮」，音讀同武，輕慢的意思。「難道能和」以下，是對比單純止持以辨析差異。因為殺戒、盜戒等，絕對沒有任何教規會開許你去造作，所以沒有雙重持戒的意義。

【416-0006】02_戒疏/04c_卷一下之二#24
【原文】【疏】問：「依教造境名作持者，如婬怨逼，禁心境合，豈非順教，應具二持？」
【譯文】【疏文】有人問：「如果依照教導造作外境就稱為作持，那麼就像遭受淫賊怨家逼迫時，克制內心而身體被迫接合，這豈不是順應佛陀的教導，應當也算具備二持嗎？」

【416-0007】02_戒疏/04c_卷一下之二#25
【原文】【疏】答：「此以難緣，禁心名止，非謂恒爾。若無怨逼，對境有犯，況復合邪？」
【譯文】【疏文】回答：「這是因為遭遇危難因緣，克制內心不起染樂而稱為止，並不是說平時就可以經常這樣。如果沒有怨家逼迫，單單面對外境就已經犯戒了，何況身體還實質接合呢？」

【416-0008】02_戒疏/04c_卷一下之二#26
【原文】【疏】若作此釋，莫問事法，無聖教聽，並是單持。廣更如後。
【譯文】【疏文】如果採取這種解釋，那麼無論是事相或法規，只要沒有聖教明白開許去作的，全都是單純的止持。詳細內容如後文所述。

【416-0009】02_戒疏/04c_卷一下之二#27
【原文】【記】引難中。初篇四戒，淫開怨逼，《律》令作蛇口、火中等想，教既開作，合成雙持。答中，怨逼作想，豈與三衣等作同耶？「若作」下，總判。「廣」下，指後諸篇。
【譯文】【記文】在引用難題中。第一篇四條根本重戒中，淫戒開許了遭受怨家逼迫的狀況，律中命令此時應當作「毒蛇入口、投身火中」等想，既然教令開許作此想，理應合為雙持。回答中指出，遭受逼迫時所作的觀想，豈能與主動如法縫製蓄備三衣等造作相提並論呢？「如果採取」以下，是總結的評判。「詳細」以下，指引參照後面的各篇章。

【416-0010】02_戒疏/04c_卷一下之二#28
【原文】【疏】二、明止持對聽門中事法者，亦有可學及不可學。
【譯文】【疏文】第二、說明止持對應於開許（聽門）中的事相與法規，也有可以修學與不可修學的分別。

【416-0011】02_戒疏/04c_卷一下之二#29
【原文】【疏】言「可學事法」者，謂房舍尺量、長衣廣狹、指授白二、加說淨法是也。於此事法，亦聽作聽止。必有房財，理須加法，故「聽作」也。若有妨難犯過衣財，不合加法，故「聽止」也。
【譯文】【疏文】所謂「可以修學的事相與法規」，是指僧房建造的尺寸規格、蓄留長物的長寬標準、向僧團祈請指授的白二羯磨、以及依法宣告說淨等作法。在這些事相與法規中，既開許進行（聽作），也開許停止不作（聽止）。如果確實有僧房和財物，理當舉行加持作法，所以「開許進行」；如果存在障礙災難，或者是犯戒過失所獲的衣物財產，依法不能進行加持，所以「開許停止」。

【416-0012】02_戒疏/04c_卷一下之二#30
【原文】【記】聽門，釋可學中。初標示。「謂」下，出體。「於」下，明止作。聽中有違，還復令制，故得有止。
【譯文】【記文】在開許門（聽門）中，解釋可修學的部分。最初標明揭示。「是指」以下，指出具體內涵。「在這些」以下，說明停止與進行的道理。在開許的規範中若有所違背，還是會轉為禁止命令，因此可以有「停止」的規定。

【416-0013】02_戒疏/04c_卷一下之二#31
【原文】【疏】言「不可學事法」者，謂房財大小，迷忘互生，作法是非，昏昧雜起。望不違教，名為「止持」。迷非可學，故不制犯。
【譯文】【疏文】所謂「不可修學的事相與法規」，是指對於房舍或財物的大小規格，忽然產生混亂遺忘，對於僧事作法的對錯是非，昏昧惑亂同時生起。從沒有違背教誡本心的角度來看，仍稱為「止持」。但這種迷亂不是事前修學就能免除的，所以戒律不判定為犯戒。

【416-0014】02_戒疏/04c_卷一下之二#32
【原文】【疏】次對作持。亦就制聽，以明持相。
【譯文】【疏文】接下來對應作持門。同樣是就強制制定（制門）與開許（聽門）兩方面，來說明持戒的相狀。

【416-0015】02_戒疏/04c_卷一下之二#33
【原文】【記】次、作持中。標云「亦」者，亦前止持故。
【譯文】【記文】在接下來的作持門中。標題說「也」，是因為比照前面止持的分類方式。

【416-0016】02_戒疏/04c_卷一下之二#34
【原文】【疏】先將作持，對制教中，明制作者，位通事法。
【譯文】【疏文】首先將作持對應於強制制定的教法中，說明強制要求作為的規範，其範圍普遍涵蓋了具體事相與僧事法規。

【416-0017】02_戒疏/04c_卷一下之二#35
【原文】【記】釋中，依古者。昔謂作持無不可學。今且一向依彼出體。下文難破，方顯今疏還通二位。
【譯文】【記文】解釋的內容中，先依循古德的說法。古時認為作持門中沒有所謂的「不可學」。現在暫且完全依照古德的說法列出體系，下文加以問難破斥後，才會顯出本疏的主張——作持同樣通達「可學」與「不可學」兩個範疇。
