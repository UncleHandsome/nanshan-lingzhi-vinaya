# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】今解中：初躡破，尼中具問十三難，可驗非理。「今」下正解為三：初立理，尼中後四望違重教，故得邊名，二眾未稟，故不通耳；破僧據境，不望違教。「破」下次釋難，前科初解邊、破二難竝從法故，今此隨境，故復通之。律中著外道服、學外道事業，竝得偷蘭，可驗破二但約業重，非違重教。「故」下三結示
【譯文】在「今解」之中：首先承接並破斥前說，比丘尼受戒中具足詢問十三難，便可驗證前說是不合道理的。「今」字以下正式解釋分為三點：第一立正理，比丘尼戒中的後四重罪就違背重大教制而言，所以得邊罪之名，下位二眾尚未稟受，所以不通於她們罷了；破僧是依據所破之境，並非就違背教法來立名。「破」字以下其次解釋問難，因為前一科初解中將邊罪與破二道兩難都歸為從法立名，如今此處改為隨境立名，所以重新加以通釋。律典中穿著外道衣服、修學外道事業，全都結偷蘭遮罪，可以驗證破二道只是就造業深重而言，並非專就違背教制重罪來立。「故」字以下第三結尾指示。

【541-0002】03_業疏/14a_卷三之三#1
【原文】第四、收難。前明不盡，引《多論》中：初、敘本因。「諸」下，次、簡障難。初、約趣簡。天與鬼、獄竝非人攝，即簡非、畜也。「四」下，次、就人趣約四洲簡。北洲人壽千歲，珍寶、飲食自然，故是福報；著樂無厭，故是愚癡。「人」下，三、就三洲約四報簡。二具，謂根具者；黃、根，即黃門、二形。「就」下，四、就男女約諸業簡。越濟，即破內異名，邪正不攝，故名越濟。上之四位，總攝十四。前引《多論》犯五、八、十重者，受戒不得，即為邊罪，通為十五。婬母與斷善，在十三外。「大」下，三、總斷。葢不足言，謂必須淨器，諸餘雜類，不足言也
【譯文】第四、收攝難障。前面說明尚未詳盡，引述《薩婆多論》之中：第一、敘述根本由來。「諸」字以下，第二、簡別障難。首先依據趣道簡別：天與鬼、地獄都歸入非人所攝，這就是簡別非人與畜生。「四」字以下，其次就人趣之中依據四大洲來簡別：北俱盧洲之人壽命千歲，珍寶、飲食自然具足，所以是福報；但貪著享樂而不知厭離，所以是愚癡。「人」字以下，第三就東南西三洲依據四種身報來簡別：「二具」，是指諸根完具者；「黃、根」，就是黃門與二形根。「就」字以下，第四就男女依據諸般造業來簡別：「越濟」，就是破內道的別名，邪正兩邊皆不收攝，所以稱為越濟。以上四個層位，總共收攝十四種。前面引述《薩婆多論》犯五戒、八戒、十戒重罪者，受戒不得發戒，這就作為邊罪，通計為十五種。婬母與斷善根，都在十三難之外。「大」字以下，第三、總體判定。大概不足掛齒，是說必須是清淨法器，其餘各種雜類，就不值得一提了。

【541-0013】03_業疏/14a_卷三之三#12

【譯文】又有人解釋說：在受戒法中所說的十三難，已經把各難收攝殆盡了。如何說明呢？這裡主要是選取具有心識前來乞戒、雖然對其如法作羯磨加持、但因障礙而不得發戒的情況稱為「難」；其餘根本不會前來的，歸入別的難障收攝，不是此處重難所要包攝的。例如畜生，能夠變化為人形前來乞戒，所以稱之為難；至於其餘一般的畜生，本來就沒有這份心思，在義理上何須說是戒難呢！

【譯文】在次科最初的提問中，認為年齡未滿者乞求受戒障礙得戒，在理路上應當構成戒難，怎麼會歸在遮障之中呢？答文義理顯而易見。

【541-0017】03_業疏/14a_卷三之三#16
【原文】若爾，九歲和上應待其滿，如何感戒也？答：小年俱同，竝是遮位，緣疎因正，故得不異也。類彼式叉不滿非法，正制難違
【譯文】如果是這樣的話，九歲的小沙彌作和尚，理應也等他年齡圓滿，（但他度人時，被度者）又怎麼能感發得戒呢？答：年齡不足情況都相同，全都是屬於遮障的位階，由於外緣疏遠而受戒的正因端正，所以得戒並無不同。比照那式叉摩那學法不滿兩年即受具足戒為非法的例子，正面的制度規定難以違背。

【譯文】在轉釋詰難之中，律中記載九歲的和尚度人，被度者得戒而和尚得罪，依此詰難推比，小年（年齡未滿二十歲者）在法理上也應當得戒。答文之中，首先標示相同與相異之處。自「類」字以下，其次舉出例證。式叉摩那未滿二年的學戒期，不能成就受具足戒；小年受具戒也是如此。這兩者都是律藏的正式規制，所以不可違背。

【541-0019】03_業疏/14a_卷三之三#18
【原文】二、以八難攝者
【譯文】第二、以八難來收攝。

【541-0020】03_業疏/14a_卷三之三#19
【原文】有人言：十三障戒，八障聞思，故不攝也
【譯文】有人說：十三難障礙受戒，八難障礙聞慧與思慧，所以不能相互收攝。

【541-0021】03_業疏/14a_卷三之三#20
【原文】八難收中，初釋即攝不盡師義。八障聞思，即是障道，以聞、思、修是入道之慧，十三不攝，故知有餘
【譯文】在以八難收攝之中，第一種解釋即是主張不能攝盡的法師之義。八難障礙聞慧與思慧，也就是障礙修道，因為聞慧、思慧、修慧是趣入聖道的智慧，十三難不能收攝這些，所以知道八難之外尚有餘剩。

【541-0022】03_業疏/14a_卷三之三#21
【原文】又云：不異前說，眾難所收。如《華嚴》云四輪摧八難者，故《成實》云：一、住善處，二、依善人，三、發正願，四、植善根。初輪摧五難，三途、長壽天及北有洲也；二、摧佛前後；三、摧世智辯；四、摧聾盲瘂。此本無心受，不可通說難也
【譯文】又有一說認為：這與前面的說法並無不同，都為眾多障難所收攝。如同《華嚴經》說以四輪摧毀八難，因此《成實論》說：一是住於善處，二是依止善人，三是發起正願，四是培植善根。第一輪摧破五種難，即三途、長壽天以及北俱盧洲（北有洲）；第二輪摧破生在佛前佛後；第三輪摧破世智辯聰；第四輪摧破聾盲瘖啞。後面這幾種人本來就沒有求受戒之心，不可普遍稱為受戒之難。

【541-0023】03_業疏/14a_卷三之三#22
【原文】次釋，即前攝盡師義，故云「不異」等。如「下」，引示。《華嚴》文通，故引《成論》別配。先列四輪，輪以摧碾為義。「初」下，後配八難。初輪中，三途為三，天報壽長故云長壽天，北有洲者謂欲有處也。三途惡處，下二難處，故以住善處摧之。二中，佛出未時為佛前，佛法滅已名佛後，生不值佛，故以依善人摧之。三中，世間聰辯，多知愽聞，並歸邪見，故以正願摧之。四中，三根不具，由不親善，故以種善摧之。初輪摧五，下三各一。初處、二時、三心、四報，對之可見。「此」下，結示
【譯文】第二種解釋，即是前面主張能夠攝盡的法師之義，所以說「不異前說」等。自「如」字以下，引文指明。《華嚴經》文義較通泛，所以引用《成實論》分別配對。先列出四輪，「輪」以摧折碾碎為義。自「初」字以下，隨後將其配對八難。第一輪中，三途算作三難；天界果報壽命長久，所以稱為長壽天；北有洲，是指欲界所具有的處所（北俱盧洲）。三途屬於惡處，後面兩者屬於難以修道之處，所以用「住善處」來摧破它們。第二輪中，佛陀尚未出世之時稱為佛前，佛法滅盡之後稱為佛後，生於此時遇不到佛陀，所以用「依善人」來摧破。第三輪中，世間的聰明辯才、博學多聞，全都歸向邪見，所以用「發正願」來摧破。第四輪中，盲、聾、啞三根不具足，是由於過去不親近善法所致，所以用「植善根」來摧破。第一輪摧破五難，以下三輪各摧破一難。第一輪對應處所，第二輪對應時間，第三輪對應心念，第四輪對應果報，相互對照便可明了。自「此」字以下，作結語指示。

【541-0024】03_業疏/14a_卷三之三#23
【原文】三、以三障收者
【譯文】第三、以三障來收攝。

【541-0025】03_業疏/14a_卷三之三#24
【原文】黃門欲愛多，煩惱障收，又不能男，亦報障攝；邊罪、壞尼、賊心、破道及五逆九，並業障收。若障具戒，十三俱是；若障聞思，唯五逆也。據俗戒言，不妨受得，如《成論》中所簡別也。非、畜、二根，三是報障
【譯文】黃門由於貪愛欲念偏多，屬於煩惱障所收攝；又因其缺乏男性生理機能，也屬於報障所收攝；邊罪、汙尼、賊心入道、破內外道以及五逆等九種，全都屬於業障所收攝。如果就障礙具足戒而言，十三難全都會障礙；如果就障礙聞慧與思慧而言，則只有五逆才會障礙。依在家俗戒來說，並不妨礙可以受持，如同《成實論》當中所甄別的那樣。非人、畜生、二根這三種，則是報障。

【541-0026】03_業疏/14a_卷三之三#25
【原文】三障總收中，初、約煩惱收黃門者，取其心也；亦報障者，據其形也。「邊」下，次、約業障收。初、別示，以邊等九並由造作故是業收。「若」下，次、料簡，有三：初、通示戒障；次、別對聞思，若據非、畜亦障聞思，此且就業為言耳；三、明通受俗戒，前引《成論》「五逆、賊住、壞尼等，若為白衣，不遮絕慈等善，有世間戒何咎」是也。「非」下，三、約報障收，三皆不善報故
【譯文】在以三障總攝之中，首先依煩惱障收攝黃門，是取其心念貪愛而言；又說屬於報障，是依據其形體殘缺而言。自「邊」字以下，其次依業障收攝。首先分別指明，因為邊罪等九種都是由造作罪業所致，所以屬於業障收攝。自「若」字以下，其次進行料簡，共有三點：第一、普遍說明對受戒的障礙；第二、個別對應聞慧與思慧，如果依非人、畜生來說也能障礙聞思，這裡暫且只是就業障而言罷了；第三、說明可以受持在家俗戒，前面引用《成實論》所說「五逆、賊住、汙尼等，如果身為在家人，並不隔絕慈心等善法，受持世間戒有何過咎呢？」即是此意。自「非」字以下，第三、依報障收攝，因為這三種都是不良果報的緣故。
