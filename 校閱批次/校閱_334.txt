# 校閱材料　第334檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【334-0001】資持記/01c_上一上#35
【原文】彼此兩字，即指二宗。謂《四分》制已更開，即兼在世；《五分》雖制不用，亦兼未來。既而彼此相兼，即知本宗自具二世；但文不顯，故用彼文。問：遮性中亦明開制，與此何別？答：前通遮性，此唯在遮。若是性戒，不論時處。故《了論》中一切時處毘尼，謂婬盜等是也。第三例中。酬因曰報。
【譯文】「彼」與「此」這兩個字，就是指這兩個宗派。意思是《四分律》制定之後隨即再次開許，就已經兼顧了佛陀在世時的實際情況；《五分律》雖有嚴格規定但於特殊情況下准許不用，也同樣兼顧了未來的長遠情境。既然彼此所含攝的義理互通無礙，便可知道本宗自體本就具足貫通二世的深義；只不過文字未曾顯著標明，所以才借用彼律的經文來闡明這層道理。問：前面的性戒與遮戒中也講述了開許與制約，與這裡所說的開制又有什麼差別呢？答：前面是貫通於性戒與遮戒來論述的，此處則唯獨針對遮戒而言。如果是根本的性戒，無論在什麼時間、什麼處所都絕不允許開緣。所以《明了論》中所稱的「一切時處毘尼」，所指的就是根本的行婬、偷盜等重戒。在第三個範例中。酬償宿世因業所感的果報稱為「報」。

【334-0002】資持記/01c_上一上#36
【原文】言強弱者，或約男女二位，對下就制也。又男女中各分三根，對下約行也。所以不言重輕而言聽者，以重輕之言，不該約行，故以重聽通收二種。就制即止持，約行即作持。初中，準《戒疏》深防限分，各有通別。制四重，防三毒，即根本防。制種類，防四重，名深防。〔此即通也。〕又云：過犯未窮，預加重約；
【譯文】所謂「強弱」，有時是就男女兩種身位的差異來立論，這正對照著下文依據戒律「制約」的差別；有時則是從男女各自細分為上、中、下三種根器來立論，這正對照著下文依據「行持」的差別。之所以不說是「輕重」而說「聽許」，是因為單純講「輕重」兩個字，無法涵蓋修行者在行持上的寬緩，所以用「加重」與「聽許」這兩個詞來同時總攝制約與實踐這二者。「就制作而言」就是指消極防非的止持門，「就實踐而言」就是指積極修善的作持門。在第一部分中，依照《戒疏》所說，深入防範與局限分際，各自都具有共通與個別的不同含義。制定四重戒是為了防範貪、瞋、癡三毒，這叫做「根本的防範」。制定各類細微的罪相以全面預防重蹈四重戒的覆轍，這叫做「深層防範」。〔這指的就是共通的道理。〕又說：在過失尚未發展到不可挽回的地步之前，預先施加最嚴厲的約束；

【334-0003】資持記/01c_上一上#37
【原文】禁微防著，故曰深防。如尼觸犯夷等類。〔等餘三重。約戒以論，即名別也。若飲虫水防殺畜；手搏防打，亦號深防；非此中意，以不對報故。〕言限分者。指重緣心，以為下凡限分之制。〔此即名通，通諸戒故。〕又云：若就相論，可有修學，竝是限分；如漏失僧殘尼墮。
【譯文】禁遏微細萌芽以防範執著深陷，所以稱為深層防範。例如比丘尼只要與男子身相接觸便結成不可悔的根本大罪之類。〔等同於其餘三重戒的防微杜漸。若從個別戒條來論述，就稱為「個別之相」。若是飲用有蟲之水是為了防範殺害畜生；禁止以手擊打是為了防範傷害生命，這也可以稱為深層防範；但這並非此處的本意，因為它並不是針對果報身相的強弱而立論的緣故。〕所謂「局限分際」，是指眾生那種「屢屢生起重疊造業的心念」，以這個作為底線凡夫受戒時應當堅守的限度規範。〔這就叫做「通」，因為它共通貫徹於各條戒相之中。〕又說道：如果就個別事相來論述，凡是行者可以勉力修學、依教奉行的，全都是戒律的限度分際；例如漏失精液成僧殘罪、比丘尼墮罪等皆是如此。

【334-0004】資持記/01c_上一上#38
【原文】〔此為別也。又如僧中輒教尼等，及尼中四獨紡績一切不同之戒是也。〕今此約報強弱，須從別論。〔古記反破此解，請以《戒疏》為準。〕約行者，山謂蘭若，即上根也；世謂聚落，即中下根也。然上士不獨居山，中下豈唯在聚！取其大約以處分機。
【譯文】〔這就屬於「別」的範圍。又例如僧團中嚴禁比丘擅自單獨教誡比丘尼等，以及比丘尼戒中規定不可一人獨處、不可從事紡織等一切彼此不同的戒條，全都是這個道理。〕如今此處依據報體的強與弱來論述，必須依照「個別戒條」的脈絡來論究。〔古時的註記反而反駁推翻這種解釋，學者應當以《戒疏》的定論為最標準的依據。〕所謂「依據行持」，「山」是指阿蘭若寂靜空處，代表上等根機的修行者；「世」是指市集聚落，代表中等與下等根機的修行者。然而上等行者並非絕對只能隱居深山，中下等根器的人難道就絕對只能混跡市井？這不過是抓取其大體概況，藉以安頓處置不同品類的根機罷了。

【334-0005】資持記/01c_上一上#39
【原文】初明山者，僧尼二眾，通行四依：一糞衣，二乞食，三樹下坐，四腐爛藥。〔此上根也。尼樹下坐，但非蘭若。〕二明世者。衣中，根報次者制三衣，又次者畜百一，又次者畜長，又次者被褥等重物，又次者聽眾寶莊嚴〔此非常教，唯天須菩提耳。〕；
【譯文】首先說明適合居山的行法，僧尼二眾普遍遵行「四依住」：一是穿著糞掃衣，二是常行乞食，三是長坐於樹下，四是生病時服用腐爛陳舊之藥。〔這全是上根利器的修行典範。比丘尼雖也坐樹下，但只限於非深山空曠的阿蘭若處。〕第二是說明適應聚落世俗的行法。在衣服方面：根器報體次一等的行者佛准許蓄持三衣，再次一等的准許儲蓄百一供身等細物，再次一等的准許蓄留多餘長物，又次一等的開許使用被褥等厚重物資，最低等的甚至開許其身受種種珍寶嚴飾〔這絕非常規的教法，世尊僅僅特別允許天須菩提一人罷了〕；

【334-0006】資持記/01c_上一上#40
【原文】上準《戒疏》明五開，彼云：良由眾生根報不同，強弱不等，致令大聖方便開遮。〔此五前強後弱，中間互通。〕食中，開受僧別二請，僧常檀越送等。處開二房，藥開三種。〔此四開中下機。〕問：制行二位，強弱何分？答：制則強輕而弱重〔強依限分，弱假深防。
【譯文】以上是依照《戒疏》所開示的「衣服五層開緣」，那部疏說道：確實是由於眾生的根器果報千差萬別，堅忍與孱弱的程度各不相同，才致使大聖佛陀運用無盡善巧去施設各種開許與遮止。〔這五層開緣，前者根性較強、後者根性較弱，其間的應用互有通融。〕在飲食方面，開許接受全體僧眾或個別居士的設齋邀請，以及接受常住僧食和檀越專門送供等等。在住處方面開許修築兩種房舍，在醫藥方面開許服用三種良藥。〔這四類方便正是專為開化中根與下根的修行人而設。〕問：在「制戒」與「修行」這兩個層面，其強與弱究竟該如何劃分呢？答：就制約而言，報強者教法較輕而報弱者教法加重〔報強者依循通規的限度分際，報弱者則須借助特殊的深層防範〕。

【334-0007】資持記/01c_上一上#41
【原文】行則強制而弱聽〔強者堪耐，弱必隨開。〕。四中，初句明機差。此謂佛世起教之機，非五部師也。次句示教別。即對諸部以明輕重。輕重言通，不出罪事。如初篇重犯，婬制毛頭，盜限滿五，羯磨楷定，受法簡人之類，即此重餘輕。又開結淨地，捨財還主，接俗生善之類；
【譯文】修行方面，則報強者制約嚴格而報弱者准予聽許〔強者堪能忍耐，弱者必須隨緣開許〕。在第四種範例中，第一句指明根機的差異。這是指佛陀在世時促發如來立教的諸多受化根機，並不是指後世開展出五部律的諸位宗師。次句顯示教法的不同。這正是比對諸部派的規定，用以彰顯戒規的輕與重。所謂「輕重」是個總括之詞，不外乎犯罪的輕重與行事的繁簡。例如在根本第一篇的重犯中，針對婬戒《四分律》規定微細如毛頭觸入便結重罪，盜戒則限定必須滿五錢才結根本重犯，作法羯磨具有決定性格式，受戒法中嚴格揀擇受戒者資格等事，這就屬於「本律處罰嚴重而他部處罰較輕」。相反的，本律開許結集淨地以存糧、捨棄非時財物歸還元主、接引世俗凡愚廣修善根之類的通融；

【譯文】又說道：我們今日學戒，正純粹是為了求得這四果，因為本宗正屬於聲聞乘，所以講到此處就已經算是登峰造極了。我昔日聽聞參學之時，每每讀到這種話語，內心莫不感到無比痛心哽咽。這真可以說是極力壓抑屈折了祖師的宗旨法乘，徹底弄瞎蒙蔽了後世來學之人的眼目！〈受戒篇〉開宗明義闡述發起上品發心；〈沙彌篇〉宣說割愛辭親出家乃是修學佛道的根本源頭；〈篇聚篇〉廣引《勝鬘經》、《大智度論》，全都指明毘尼戒律當體就是大乘摩訶衍；《羯磨疏》中以「圓教」確立戒體的體性，更是等同於三聚淨戒；
