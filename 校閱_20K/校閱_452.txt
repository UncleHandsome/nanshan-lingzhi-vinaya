# 校閱材料　第452檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【452-0001】資持記/02c_上一下#9
【原文】作法有三，自然分六，則為局也。人中，別人及僧二位為通；別有三階，僧分四種，故為局也。語冠首題，一篇綱要；略知條目，始可尋文。標示中。制意開緣，下篇既顯，不可兩繁；故指如後。以類相從，此之謂矣。作法三者，場及大小。然有場四集，雖兼大界，正意明場。
【譯文】作法界有三種，自然界分為六種，這就屬於局相。在人員中，個別之人與僧伽兩個位階屬於通相；個別之人有三個等階，僧伽分為四種，所以屬於局相。這些話冠於篇首題目之中，是一整篇的綱要；大略通曉了條目，才可以進而披尋內文。「標明指示」這部分。制戒的本意與開許的因緣，在下一篇既然已有顯明闡述，就不可以重複繁複；所以指示如後文所載。按照同類性質相互歸納，指的就是這個意思。作法界的三種，是指戒場以及大小界。然而有戒場時可在四處集僧，雖然兼明了大界，但其主要用意是在說明戒場。

【452-0002】資持記/02c_上一下#10
【原文】又集僧約事有通有別：通謂說恣，內外俱集；別即餘法隨界各行。今文兩界，並從別論。問：如通集中，場上不來，犯別眾否？答：法成得罪。不妨異界，無別眾過。問：小界說恣有通集否？答：本由說恣，開結遮訶。是則三小唯有別集。次明自然，初科分二，初示相。四中，聚蘭各二，則為六相。皆下，釋名。
【譯文】此外僧眾集會依照僧事區分，有通集與別集：通集是指說戒與自恣，界內界外都要一同聚集；別集即其餘僧事隨著各自的界限分別舉行。現在文中所指的兩個界限，都是從別集來論述。提問：如果是在通集中，在戒場上的人不來，是否犯了個別結眾的罪？回答：羯磨法事雖然成就，但不來者仍結違法不赴集之罪；然而戒場與大界終究屬於不同界限，因此並不構成別眾的罪過。提問：小界中的說戒自恣有通集嗎？回答：本來就是由於說戒自恣，才開許結小界來隔絕難事。如此則三種小界只有別集。其次說明自然界，第一科分為兩部分，起初開示其相貌。在四種之中，村落與阿蘭若各有兩種，就成了六種相貌。「皆」字以下，解釋名稱。

【452-0003】資持記/02c_上一下#11
【原文】對彼作法，緣搆成故。當下，標所出。問：所以當律都不立者？答：止是闕略，義必具之。準三小界，明指集處；疏云雖當部中無自然界，異處下道，即是誠文；道是一界，下是蘭若。今言無者，或非明文，或無分齊故也。初明聚落，可分別中。準疏分二：謂僧則在無易委〔人可分別〕，聚亦周院可悉〔處可分別〕。
【譯文】這是相對於作法界是由羯磨因緣造作建構而成，（自然界則不為物造）。當下，標明其出處。提問：為何本律完全不建立自然界？回答：只是律文闕略而已，在義理上必定完備具足。準照三種小界，明確指出了集僧的處所；義疏說雖然本部律中沒有明文提及自然界，但在不同處所離開道路（步下道路），這就是確切的經文依據；道路本身為一界，走下道路處即是阿蘭若。現在說本部沒有，或許是因為沒有明確經文，或者是沒有劃定界限範圍的緣故。起初說明村落「界限可明確分別（可分別）」的情形。依照義疏分為兩點：即僧人住或不住容易明瞭〔人員可分別〕，村落也是四周圍院界線清楚可辨〔處所可分別〕。

【452-0004】資持記/02c_上一下#12
【原文】《尼鈔》云：城外村坊，邊夷城邑，人民稀尠，可得分別故。應作四句。初人處俱可分，則依此相。二人處俱不可分，如後步量。三人可、處不可，四處可、人不可，並依後集。故知此相必須具二。文引《十誦》二十二卷。彼因比丘問佛，初至結界，即引問詞。彼接云：爾時界應幾許？
【譯文】《比丘尼鈔》說：城外的村莊舍宅、邊遠蠻夷的城邑，人口稀少，可以明確分別的緣故。應當作四種情況分析。第一，人員與處所都可分別，就依循這個相貌。第二，人員與處所都不可分別，就如同後面步數測量的方法。第三，人員可分、處所不可分，第四，處所可分、人員不可分，都依循後面的集僧方法。由此可知這種相貌必須兩者兼備。文中引用《十誦律》第二十二卷。那是由於比丘請示佛陀，初到一處如何結界，隨即引出其請示之詞。彼律接著說：在那個時候界限應當劃定多大？

【452-0005】資持記/02c_上一下#13
【原文】言無僧坊者，人可分也。聚落即處可分。隨下，是佛答。謂隨處廣狹，即是界限。注。行來處見四十七，故云下文。此下，先以義決。分齊即同勢分，顯非聚落界體；意不取之。故《業疏》云：縱彼文中齊行來處，此制通攝，恐妨界內；必作法時身在門外，亦得兩成等。《四分》下，次引文決。
【譯文】說沒有僧坊的地方，這是人員可以分別。村落就是處所可以分別。「隨」字以下，是佛陀的回答。意思是隨著處所的寬窄，這就是界限。注釋。「平時往來之處」見於第四十七卷，所以說是下文。「此」字以下，先以法理來決斷。範圍界限就如同氣勢所及之處，顯明並非村落的界體；本意並不採納這種說法。所以《業疏》說：縱然在那段經文中以平時往來之處為界，這項規定是通泛含攝，唯恐妨礙了界內；如果作法之時自身在門外，也能使兩處法事都成就等。《四分律》以下，其次引用律文來決斷。

【452-0008】資持記/02c_上一下#16
【原文】及後離衣釋伽藍界，更不別列，略指如上，故知是同。必下，簡濫。準不周淨，三邊有相，須準聚集；兩面一面，還依蘭若。有人迷此，謂城邑中院相周匝處，並可分別；請觀〈結界篇〉中圖相，藍院四周，自然四出，即知謬妄，不勞攻之。今謂上明伽藍，同可分聚；
【譯文】以及後文在「離衣戒」中解釋寺院僧坊之界，不再另外列出，只是略微指示如同上述，所以知道兩者是相同的。「必」字以下，簡別浮濫。依照「不周全清淨地」的規則，如果有三邊具有相貌標誌，就必須準照聚集處而定；若只有兩面或一面，還是依循阿蘭若的規則。有人對此迷惑，認為城邑中院落格局周整完備之處，全都可以明確分別；請看〈結界篇〉中的圖相，寺院四周自然向外伸展，便知那是謬誤虛妄，不勞再去批駁。我現在認為上面所說的寺院僧坊，等同於可分別的村落；
