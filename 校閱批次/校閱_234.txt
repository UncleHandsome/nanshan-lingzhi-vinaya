# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【234-0003】02_戒疏/11b_卷三上之二#96
【原文】【疏】五、「屏處」，注分為二：初云「見屏」，中無隔障，但為緣來，兩不相見也；二、言「聞屏」，目兩見在，但不聞聲故。如《見論》中，約對第三人，「若無眼，或聾，或眠，或女人多」者，隨犯多墮。「覆障二處」，約緣相為言，屏處一種，約見聞根辨。
【譯文】【疏文】第五、「屏處」，小註將其分為兩種：第一種稱為「視覺屏障」，中間雖無遮蔽障礙，但因外在因緣干擾（如沙塵、迷霧），導致彼此互看不見；第二種稱為「聽覺屏障」，眼睛雖然能看見兩人同處，但完全聽不到彼此交談的聲音。正如《善見論》中相對於第三者而言：「如果身旁第三人眼瞎，或是耳聾，或是熟睡，或者旁邊只是一群普通女子」，這都隨順犯下多種墮罪。「遮蔽與障隔這兩處」，是就物體外在的形態障礙而言；而「屏處」這一種，則是專就眼睛與耳朵這兩處感官根門的隔絕來辨析。

【234-0009】02_戒疏/11b_卷三上之二#102
【原文】【記】戒本。次句，指「九十」者，即屏坐戒，彼云「申手不及戶坐，便犯」。三中，注文止簡小、騃、已死，而不明親非親等，故引《僧祇》決之。文中「大」字誤，古本作「女」。四中，《僧祇》所列，雖有此等，亦名為「獨」。五中。初別釋屏處。注云「三種」，寫誤。初釋見屏，「緣來」，即塵霧等。次釋聞屏，「目見不聞」，明其遠也。《見論》所列，並非第三人，「無眼」即見屏，「聾」即聞屏，「睡」即兼二。雖有「多女」，還同屏處。準知，第三必約有智男子矣。「覆」下，通簡三相。八中。初點文。二、釋注。初牒釋；次「優婆私」下，翻名。「私、尼、夷」者，並謂下一字，有三不同。「多」下，引示「有信」。凡作妄語，多因四緣：一、身，二、財，三、命，四、親友等。九、十，二句，即二種毗尼。用此二法，即兼現前也。
【譯文】【記文】戒經本文中。第二句指引至「九十單提」之處，就是指那條屏處同坐戒，彼處規定「只要距離近到伸手觸碰不到門扉處而坐，便構成犯戒」。在第三點中，小註原本只排除了年幼痴呆、或已死之人，卻沒有闡明親屬或非親眷的差別，所以引用《僧祇律》來作決斷。文中的「大」字是筆誤，古代刻本寫作「女」字。在第四點中，《僧祇律》所列出的這些人，縱然在場，律法上也依然判定為「獨自一人」。在第五點中，首先分別解釋隱蔽之處。注文中說「三種」，也是抄寫的錯誤。先解釋視覺屏障，「因緣而至」指的就是塵沙濃霧遮蔽。接著解釋聽覺屏障，「眼見卻聽不見」，指距離相隔甚遠。《善見論》所列舉的這些人，都不能算作有效的第三者：「眼盲」就是視覺屏障，「耳聾」就是聽覺屏障，「熟睡」則兩者兼具。身邊即便圍繞著「多名女子」，在律法上也依然等同於在隱蔽之處。由此可知，有效的第三人，必然必須是具有辨析判斷能力的成年男子。「遮覆」以下，通達簡要地總結三種情境。在第八點中，首先點出經文。二是解釋小註。先標註解釋；接著從「優婆私」以下，考證其梵音譯名。「私、尼、夷」三種稱呼，都是指最後一個字在音譯上的三種歧異。「薩婆多論」以下，引用說明何謂「具信」。世人蓄意說妄語，大多不出四種原因：一是為自身私利，二是為爭奪財富，三是為保全性命，四是為親友庇護。第九、第十這兩句，就代表了兩種滅諍法。運用這兩種方法，同時也就兼顧了現前毘尼的成立。

【234-0011】02_戒疏/11b_卷三上之二#104
【原文】【疏】就注解中。言「所趣向處」者，謂向彼女家道行也；「所到處」者，至女家也；「若坐若臥」，犯殘、提也；「若作」者，犯夷罪也。交互明罪，有無不定。罪犯隨篇，疑須舉處。故言「並如可信語治」。
【譯文】【疏文】就小註的文義而言。所謂「去往的處所」，是指走向那名女子家宅的道路之中；「抵達的處所」，是指已經到了女子的房舍之內；「若是坐下或是躺臥」，這便構成犯下僧殘或波逸提罪；「若有實施作為」，這就是觸犯了根本的波羅夷罪。這些行為交錯互見以顯明所涉罪嫌，是否存在尚未確定。所觸犯的罪名隨其對應的篇聚去懲治，但引人起疑這件事則必須在當處立案舉發。所以說「一概依照可信賴之人的言詞予以懲治」。

【原文】【律】若比丘，共女人在露現處不可作婬處坐，作麤惡語，有住信憂婆私於二法中以一一法說，若僧婆尸沙，若波逸提；是坐比丘自言「我犯是事」，於二法中應一一治，若僧伽婆尸沙，若波逸提，如住信憂婆私所說，應如法治是比丘，是名不定法。

【234-0016】02_戒疏/11b_卷三上之二#109
【原文】【註】是中若自言所趣向處、所到處，若坐若臥。或不自言，並如憂婆私所說治。是中無定法，故言「不定」也。
【譯文】【註文】在此程序中，若是自己承認去往的處所、抵達的處所，若有坐下或躺臥。或是他不承認，一概依照優婆夷所言予以處罰。因為在此之中沒有固定的罪相，所以稱為「不定」。

【234-0023】01_行事鈔/10c_卷下之二#13
【原文】《四分》：供給和上，聽用銅槃、若案、若几；所食之物，盡持置上，一時授與；得果多，壓取汁飲，開畜壓具。若夜集闇，須燈器，燈炷、鐵著、鐵炷、轉輪燈樹、火爐、燈籠、掃帚、扇；並得別人受。若為護衣故，寺內聽以樹皮、若葉、若竹作蓋；供給蓋具，一切得畜。為補革屣故，開畜錐；得熟皮作革屣，須刀裁、板剗、磨石等，並開。若刀錐、筋毛、縷皮剗迸散，聽作囊盛；若織竹作籠，若樹皮籠，聽以毛囊裹外，亦得趣用十種衣作囊；不得以皮作。若刀生壞，聽以毳劫具、大皮等裹刀。若髮長者，開剃刀及鞘，應以劫貝等，障勿令壞；若刃卷，手上波，石上磨，其石內刀囊中；刀鈍者，開畜刮刀；髮散，畜盛髮器。又開鑷子、剪爪刀、刮舌刀、揥齒物、排耳篦。

【234-0024】資持記/14c_下二#16
【原文】染草謂可染衣者。見白衣放下，護譏嫌故。擣下，明藥具。簸比磨反。簁，所宜反，或作篩。酢灌鼻治頭痛，四邊流出，須筩灌之。烟下，明食具。烟筩引烟出舍。火把，蒲巴反。并下，明澡洗物。澡槃謂灌手者。若得下，明斗秤。二十四銖為一兩。下引《五分》決上本宗。

【234-0025】資持記/14c_下二#17
【原文】初如《四分》者，謂前制兩同，後開出彼。次科五段，初明食飲具。一時授與，謂先從人受，然後奉師。若夜下，明燈具。燈器總標，下諸物別列。燈炷即然燈器。鐵炷持燈燼者。轉輪燈樹，謂作層輪，周匝安燈，機關運轉，形如樹焉。若為下，明衣蓋。為下，明補革屣物。剗，初雁反，或作鏟。籠字上呼。
【譯文】開頭「如《四分》」，是說前面制二同，後面開出彼宗之說。次科五段，先說明食飲之具。一時授與，是先從人受，然後奉師。「若夜」以下，說明燈具。燈器是總標，下面諸物別列。燈炷就是燃燈之器。鐵炷是持燈燼的。轉輪燈樹，是作層輪，四周安燈，機關運轉，形如樹。「若為」以下，說明衣蓋。「為」以下，說明補革屣之物。剗，初雁反，或作鏟。「籠」字讀上聲。
