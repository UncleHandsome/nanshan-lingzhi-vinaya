# 校閱材料　第012檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【012-0001】01_行事鈔/01b_卷上之一#59
【原文】二就事明者。謂羯磨所被之事，更不重明，即辨非者。所被事中，通情非情，並令前境是實，片無錯涉，皆成法事；若一緣有差，悉並不成。何者是也？如人法中，不覆藏者，與覆藏羯磨，不善、非法、不成，此謂無事有法；如〈瞻波〉中，應與作訶責，乃作擯出，此謂有樂有病，施不相當，佛判不成。故知事者，必須據實，方稱聖教；且約一事，餘者例之，如實犯罪自言不犯，實不犯自言犯等，並名非法；若實言實，方為相稱。而彼自言，還陳所為之事；若汎陳餘罪，不為自言。非情事中，二房羯磨，妨難不成；離衣杖等，必須兩具。此並律之誠文，臨事無忘失矣。
【譯文】第二、就「事」（所辦理之具體事項）來說明。這是指羯磨所針對處理的事由，此處不再重新重複列舉，而是直接辨析何者為非法。在所處理的事由中，通於有情眾生（如人）與非情事物（如界地、衣鉢），都必須要求所面對的境況是完全真實的，絲毫沒有差錯交涉，法事才能成就；如果其中有一個因緣發生差錯，便全都不能成就。
什麼是具體情況呢？例如在針對有情的法事中，本來沒有覆藏罪過的人，卻給予他適用於覆藏罪的治罪羯磨，這是不善的、非法的、不成就的，這叫做「無其事而空有其法」；又如〈瞻波犍度〉中，應當對他處以「訶責羯磨」，僧團卻對他處以「擯出羯磨」（逐出僧團），這叫做有藥有病卻對應不當、施治不符，佛陀判定這種羯磨不能成就。由此可知，事情必須完全切合實情，才契合聖人的教法；暫且就這一件事來說，其餘事項皆可比照例推，例如確實犯了罪卻自己宣稱沒犯，確實沒犯卻自稱有犯等，全都名為非法；只有實話實說，才算與實情相稱。而且他自己的陳白發露，必須切實陳述所要處理的那項事由；如果只是泛泛陳述其他無關的罪過，不能算作有效的自白。
在針對非情事物的事由中，營建兩房（小房、大房）的羯磨，如果處所有妨礙或有危難，羯磨就不能成就；給予病比丘離衣羯磨、持杖羯磨等，也必須符合雙重具備的條件。這些全都是律藏確鑿的明文規定，面臨行事時切勿遺忘遺失。

【012-0002】01_行事鈔/01b_卷上之一#60
【原文】三對人明者，亦有三人。初辨僧者。僧中有四，如前所說。唯秉羯磨，界中有人，並須盡集，若不來者，便成別眾，如〈足數〉中。但得御於眾法。已外對首心念，法之與事，決定不得。二三人中，具立二法。若作眾法對首，兩界無僧，盡集作之。若數滿四，則不成就，更須改法。若作對首之法，兩人各作，不相妨礙。必有邊人，有須問者，若三十捨懺，須問邊人；九十單墮，但對即得；亦有通須問者，謂同覆處，露地尋內，故須問之；必在外有障，亦不在通問。若持衣說淨，不論通別。若是心念，一向非分。必有其事，隨緣作之。一人心念，獨在界中。若作眾法心念、對首心念，並界無人，方成此法；若有一人，名非法別眾。若據所秉，如前法中。若作但心念法，不論同別。
【譯文】第三、對「人」來說明，也有三種情況。首先辨析「僧眾」（四人以上）。僧眾之數有四種僧，如前文所說。唯獨主持羯磨之時，結界之內若有同法僧人，全部都必須齊集到場；如果有不來的，就構成別眾，如同〈足數篇〉中所說。四人以上的僧眾只能主持「眾法」；除眾法之外的對首法與心念法，無論法軌與事項，絕對不得由僧眾羯磨來作。在二、三人當中，具足成立兩種法：如果進行「眾法轉對首法」，兩界（自然界或作法界）之內都沒有其餘僧人，便由現有的二、三人全部到齊集會進行。如果人數湊滿了四人，這項對首法就不能成就，必須改用僧眾法。如果是進行純粹的「對首之法」，兩人各自對首作法，互不妨礙。如果身邊另有旁人，有的情況需要徵詢詢問：例如三十尼薩耆波逸提（捨墮罪）的懺悔，必須詢問身邊之人；九十單墮罪的懺悔，只要面對一人即可成辦；但也有普遍都需要詢問的情況，也就是如果同在一個屋頂覆蓋之下，或在露天地一尋（約八尺）範圍之內，就必須詢問徵求同意；如果那人在外圍且有牆障阻隔，就不在普遍徵問之限。如果是受持衣物、作衣說淨，則不論普遍詢問或特定詢問，一概不須詢問身邊的人。如果是心念法，在二三人處一律不得開許作心念法。必定要遇到特殊事故（如難緣僧散獨留一人），才隨順因緣行作。一個人的「心念法」，是指獨自一人在結界之內。如果進行「眾法轉心念法」或「對首轉心念法」，都必須是界內完全沒有別的僧人，這項心念法才能成就；如果界內還有一位比丘，就稱為「非法別眾」。若論其所主持的法軌，如前面「法」中所述。如果是進行「純粹心念法」，則不論界內比丘是同住或別住，都能成就。

【012-0003】01_行事鈔/01b_卷上之一#61
【原文】四約界者。四種自然，羯磨法中，唯作結界一法，是僧執御；已外對首心念二法，及一二三人，眾中雜法，四人自恣，並得秉之。俱須盡集。二者作法攝僧界者，亦通二人，法通三種。就法界中，分為五位：一難事受戒小界，二因難事自恣，三數人說戒。此三小界，因難曲開；但作一法，後必閑豫，不開作之；故文中結已即解，非久住法也。四者戒場，本為數集惱僧，故開結之；唯除說戒、自恣、乞鉢、捨懺、亡人衣法、受日、解界、結衣界并解、結淨地、受功德衣等。五者大界，就中並有通塞，隨相可知。
【譯文】第四、依據「結界」來說明。在四種「自然界」（聚落界、蘭若界、道行界、水界）當中，僧眾羯磨法中，唯獨只有「結大界」這一項法事，是由四人以上的大僧來執持統御；除此之外的對首法與心念法這兩種，以及一人、二人、三人在大眾中的各項雜法、四人對首自恣，都可以在自然界中秉持進行，但界內同法之人全部都必須到齊集會。第二種是「作法攝僧界」（作法大界），也通於僧人與別人這兩類人，法式則通於眾法、對首、心念三種。在作法界之中，又細分為五個位階：第一、因危難事故而臨時結以受戒的「小界」；第二、因危難事故而結以自恣的小界；第三、供少數幾個人臨時說戒的小界。這三種小界，都是因為遭遇難事才委曲開許建立的；它們只能用來做當下那一項特定的法事，事後若處境安閒無難，就不許在那裡作法；所以律文中規定這些小界用完之後立即解除，並非持久長住之法。第四種是「戒場」，原本是因為頻繁召集大眾往來奔波會惱亂僧眾，所以開許專門結立戒場；在戒場中唯獨除開說戒、自恣、乞求授鉢、捨墮懺悔、分配亡人衣服之法、請假受日、解除大界、結不失衣界及其解除、結淨廚地、納受迦絺那功德衣等法事不許在戒場進行。第五種是「作法大界」，這當中隨其界相各有開通與遮止的限制，隨其具體名相即可通曉。

【012-0004】01_行事鈔/01b_卷上之一#62
【原文】二別舉羯磨，明其成壞。法不孤起，終須四緣；隨義明非，不過七種。先就但心念法，以解七非；乃至白四，類七可解。
【譯文】第二、分別列舉各類羯磨，闡明它們的成就與壞破。法軌不會憑空生起，終究必須具備法、事、人、界這四種因緣；隨其義理所辨明的不合法的相狀（非法），總結起來不超過七種非相（七非）。首先就「純粹心念法」來解析這七非；進而乃至白四羯磨，都可以比照這七非的模式來理解。

【012-0005】01_行事鈔/01b_卷上之一#63
【原文】初明七非者：一者人非，謂以此法，對人而作。二者法非，口不言了，法不稱教。三者事非，謂重吉羅，用責心悔，六念等事，一一非法；妄牒而誦，不成有罪。四者人法非，不妨事如。五者人事非，不妨法如。六者事法非，不妨人是。七具三非，並同上。餘則例之。
【譯文】首先說明純粹心念法的「七非」：
第一是「人非」，也就是把這純粹心念法，硬是對著他人去作。
第二是「法非」，口中言語含混不明了，法軌不符合聖教的規定。
第三是「事非」，也就是本屬於重突吉羅罪，卻試圖用心念責心懺悔；或者修持六念等事，事項本身根本非法；胡亂宣告文辭而讀誦，法事不能成就且自身獲罪。
第四是「人法非」，雖然所針對的事情是如法的，但人和法這兩項都錯了。
第五是「人事非」，雖然作法軌則合乎規範，但人和事這兩項都錯了。
第六是「事法非」，雖然作法者符合無人對坐的規範（人是），但事情和法式這兩項都錯了。
第七是「具三非」（人法事俱非），人、法、事三者全都不對，並如同上述各條的情況。其餘各類羯磨都可以此類推。
