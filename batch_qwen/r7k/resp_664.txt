整體讀來通順、科判層次也掌握得不錯，但有幾處**術語誤讀**與**釋義偏移**，另外體例（引號標點、用字統一、補充語未標示）可以再整一遍。以下逐則列出。

## 664-0001

| 問題 | 說明 / 建議 |
|---|---|
| ❗「『即此』以下**引申出**其他異名」 | 「引異名」的「引」是**引用**，不是「引申」。此處是說疏文接著引用「婬」的別稱——即《書》中的「荒」。建議：「『即』字以下，引用（婬的）別名『荒』。」 |
| ⚠「它與『淫』的**沉溺義理**相同」 | 「與淫義同」是說**字義相同**，「沉溺」是添義，「義理」也偏離（這裡只論訓詁）。建議：「因為『荒』與『婬』的字義相同。」另「引證荒字」宜作「引《書》文來印證『荒』字」。 |
| ⚠書名與引文 | 《尚書》篇名通行作〈五子之歌〉；「第二章」可作「第二歌（第二段）」。又今本《尚書》作「**甘**酒嗜音」，記引作「酣」，保留原字可，但宜出校或加註。 |
| 💡可補 | 「上六事」即六句所含六事（色荒、禽荒、酣酒、嗜音、峻宇、雕牆），列出可讓「六事」與「六句」的對應清楚。 |

## 664-0002

| 問題 | 說明 / 建議 |
|---|---|
| ❗「順著**塵世**境界」 | 「隨塵」的「塵」是**六塵／塵境**（此處正指女色等所緣境），不是「塵世（世間）」。記文也明說「『隨塵』是業」。建議：「隨著（六）塵境界而封執黏附。」「封附」＝封閉執取、黏附不捨，「妄加執著」略失「附」義。 |
| ⚠「**聖者**知道」 | 記文下一則明言「『聖』下，初句示教主」，故應譯「佛陀（聖者教主）」。 |
| ⚠「**性**無正慧」 | 「性」字被吞掉，可補「心性上沒有正慧」。 |
| 體例 | 「稱之為『淫。』」「稱之為『戒。』」——單引一名詞，**句號應在引號外**：「稱之為『淫』。」 |

## 664-0003

大致無誤（惑／業／習三重對應譯得很清楚）。小處：

- 「『聖知』以下」：記原文只標「『聖』下」，宜照標「『聖』字以下」，避免與疏文起句混淆。
- 「翻業」譯「翻轉惡業」可，或作「轉除（惡）業」。
- 「貼釋」可加註「（緊貼疏文逐句解釋）」，與其他科判詞（會通、通緣）體例一致。

## 664-0004

| 問題 | 說明 / 建議 |
|---|---|
| ❗「從本」＝「依循印度**本國語法**」 | 記文釋得很明白：「一以教從彼出，二以天音得正，故云從本。」故「本」是**本源、根本**（教法出自西竺、梵音為正），不是「本國語法」。建議：「隨順根本（教從彼出、梵音為正）」。 |
| ❗「從末」＝「本土**末流**語法」 | 「末」是相對「本」的**枝末**（此方），無貶義；「末流」中文帶貶義，會誤導。建議：「隨順枝末（此方對本源而言為末）」。 |
| ⚠「若作此解，不律儀也」譯成反問句 | 原文是**判斷句**（「就是不律儀了」），下接「何以知之」。改成「豈不成了惡律儀？」使論證次序變味。建議直述，並把「此解」點明：「若把『婬戒』理解成『行婬之戒』，那就成了不律儀（惡律儀）了。」 |
| ⚠「明知非善法」→「顯然**不合**善法」 | 「非善法」＝不是善法（即是惡法），語氣比「不合善法」重。建議：「明知不是善法（而是惡法）」。 |
| ⚠「後以心緣」→「能緣的心識**動態**」 | 「動態」是贅詞，作「再以能緣之心（動作）承接」即可。 |

## 664-0005

| 問題 | 說明 / 建議 |
|---|---|
| ❗三個梵例未點出「倒裝」 | 這段的重點就是**梵語語序顛倒**，譯文只說「直譯為『彼岸到』『分四』『仁能』」，讀者會以為誤譯。建議補括注：波羅蜜→「彼岸到」（即「到彼岸」）、折埵理→「分四」（即「四分」）、釋迦→「仁能」（即「能仁」），並收一句「都是所對在前、能作在後」。 |
| ⚠「屠獵受殺戒」 | 宜註明此「殺戒」是**惡律儀**（誓終身行殺），非佛制不殺之戒，否則與上文「不律儀」的論點接不上。 |
| ⚠「上二句通標」 | 宜點出所指即疏文「然隨俗相，語法不同」兩句。 |
| ⚠「梵音**最**得正軌」 | 「天音得正」是「梵音為正」，「最」是多添的比較級；建議「梵音才是正音」。 |
| 💡 | 「因過制教，故云從義」可補「（『義』即所防之過失）」，與上一則疏文對讀更順。 |

## 664-0006

- 可保留术语原詞再白話：「分『通緣』（共通條件）與『別緣』（各戒專屬條件）來分析」，因下一則疏文即接「言通緣者」。
- 「藉由事緣而構成犯戒的行相」略含糊，建議「由諸緣具足而構成犯戒的相狀」。

## 664-0007

| 問題 | 說明 / 建議 |
|---|---|
| ❗「制廣」譯「制定**具足戒條**」 | 「制廣」指**廣教（廣制戒相）**，與「略教（略教誡）」相對；譯作「具足戒條」易與「受具足戒」混。建議：「必須在佛廣制戒（廣教）之後」。 |
| ❗「但違業行」譯「違背**道德**業行」 | 「業行」是**業道之行（性罪）**，不是「道德」。建議：「只違於業道之行（性罪），尚無制教之犯」——你補的「不犯戒罪」是對的，可保留。 |
| ⚠三眾括注 | 括注「沙彌、式叉摩那、沙彌尼」合理（比丘尼同犯波羅夷，故不在「但吉羅」之列），但屬**註解性補充**，宜加「按」或說明理由；否則讀者會疑問五眾何以只簡三眾。 |
| ⚠「雖同犯婬」 | 他們並不犯波羅夷，作「雖同樣**行**婬」更精確，免得與罪名混淆。 |
| ⚠「無重病」 | 「重大病亂」用語生硬。建議：「沒有重病（病重壞心、失念）」；「以不自知，無負心」＝「因病不能自覺，沒有能違犯之心（無犯意）」。 |

## 通則建議

1. **用字統一**：0001 特別在辨「女」旁的「婬」，其後各則卻一律作「淫」。要嘛全用「婬」，要嘛在 0001 加註「以下白話從俗作『淫』」，否則該段辨字的意義被稀釋。
2. **補充語一律加（）或「按」**：如「望文生義」「惡習氣」「釋迦牟尼佛」「不犯戒罪」「三眾名單」等，皆非原文所有，宜與正文區隔。
3. **標點**：引單詞時句號置引號外（0002 兩處）。
4. **科判詞保留原稱再白話**：貼釋、會通、通緣／別緣、從本／從義／從末／從時，建議一律「原詞＋白話」，方便與疏記對讀。

### 最需要改的三處（若只改重點）
1. 0001「引異名」≠引申異名。
2. 0002「隨塵」≠塵世；「聖」＝佛。
3. 0004「從本／從末」的本末是**教法本源與此方枝末**，不是「本國語法／末流語法」。
