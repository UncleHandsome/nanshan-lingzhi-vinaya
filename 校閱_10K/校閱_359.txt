# 校閱材料　第359檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【359-0001】02_戒疏/02d_卷一上之二#1
【原文】【疏】何以知然？略教通含，利鈍俱攝，未張輕重，又總機緣。廣教不爾，反前不說。故《善見》云：「一切諸佛，但說教授木叉，不說威德木义。」豈非直陳三業，通被群機？若具篇彰，便同廣戒。故《律》文云「此是如來最後說戒」，是良證也。由佛自說，不容非濫。《十誦》、《五分》云：「若為犯說，頭破七分。」弟子不爾，肉眼所見，天眼舉罪違佛制故。
【譯文】【疏文】憑什麼知道是這樣呢？因為「略教」義理含攝廣博，能同時攝受利根與鈍根之人，既未鋪張列出罪相的輕重，又能總括一切根機因緣。「廣教」則不是如此，情況正好相反，所以佛不親自宣說。因此《善見律》說：「一切諸佛，只宣說用來教授勸導的波羅提木叉，不宣說顯現威嚴刑德的波羅提木叉。」這難道不是因為略教直接開示身口意三業，普被各種根機嗎？如果具體列出各篇條文，就等同於廣戒了。所以《四分律》原文說「這是我如來最後一次說戒」，便是最有力的證明。正因為由佛親自宣說，才不容許有任何毀犯混雜。《十誦律》與《五分律》都記載：「如果佛為犯戒者說戒，犯戒者將會頭破七分。」弟子則不能這樣，只能憑肉眼所見來判斷，若用天眼來檢舉他人罪過，是違背佛陀制定的戒律的。

【359-0002】02_戒疏/02d_卷一上之二#2
【原文】【記】次所以中三，初約二教對明。上句推問。「略」下，正明。初明說略意。上二句通標，下二句配釋。「廣」下，次明不說廣意。既張輕重，則非「通含」；但被鈍機，故非「俱攝」。《義鈔》云「若為五說，利益不普」是也。
【譯文】【記文】接下來在解釋原因（「次所以」）的段落中分為三部分，首先從廣略二教的對比來闡明。最前一句是推究發問。「略教」以下，是正式闡明。先說明佛宣說「略教」的用意。上兩句總括標示，下兩句配合解釋。「廣教」以下，接著說明佛不宣說「廣教」的用意。既然詳細鋪陳了犯戒的輕重，就不再是「義理通含」；而且廣教只為鈍根之人制定，所以也不是「利鈍俱攝」。《四分律拾毗尼義鈔》所說的「如果針對五篇罪相來宣說，利益就無法普遍」，就是這個道理。

【359-0003】02_戒疏/02d_卷一上之二#3
【原文】【記】「故」下，次引示。又二，初引《善見》。略教但指三業而直示，故云「教授」；廣教追事有怖，故云「威德」。「豈」下，結顯。後引本律《說戒犍度》云：「佛在瞻波國十五日說戒時，佛在眾默不說戒。初夜已過，阿難請說。佛言：『欲令如來於不淨眾中說戒者，無此理也。』中夜後夜請答亦爾。時大目連即以天眼觀犯戒者去佛不遠，即以手牽出。佛言：『聽作自言治。自今已去，汝等自作羯磨說戒。此是如來最後說戒。』」據此可驗，佛不說廣，明矣。
【譯文】【記文】「故」字以下，是第二部分，引用教證加以指示。這又分為兩層，首先引用《善見律》。略教只是直接指示三業的善惡，所以稱為「教授」；廣教則是追究犯事細節而帶有刑責怖畏，所以稱為「威德」。「豈非」以下，是總結彰顯。接著引用本律《說戒犍度》的記載：「佛在瞻波國十五日舉行說戒時，佛坐在僧眾中默然不說。初夜過去了，阿難尊者請求佛說戒。佛回答說：『想要如來在不清淨的僧眾中說戒，絕無此理。』到了中夜、後夜，阿難再次請求，佛的回答也是如此。當時大目犍連尊者隨即以天眼觀察，發現犯戒的人離佛不遠，就立刻用手將他拉出僧眾。佛說：『聽許你們對他依照自白認罪來治罰。從今以後，你們自己作羯磨說戒，這是我如來最後一次說戒。』」根據這段記載可以驗證，佛不親自宣說廣戒，是極為明確的。

【359-0004】02_戒疏/02d_卷一上之二#4
【原文】【記】「由」下，三、正示所以。此明如來因前重犯不說之意，則知略教唯被淨機，廣制通及淨穢。《五分》云：「諸佛常法，有五百金剛侍衛左右。若問三反不以實答，頭破七分。」、「天眼違制」者，即上目連因緣。又《婆論》云：「不得用天眼知他惡法。」
【譯文】【記文】「由佛自說」以下，是第三部分，正式開示其中的緣由。這是說明如來因為前面有人重犯戒律而不再親自說戒的深意，由此可知略教只攝受清淨的根機，而廣制則通被清淨與染污兩類大眾。《五分律》說：「諸佛常法，身邊常有五百位金剛力士侍衛在左右。如果被問了三次還不用實情回答，頭就會裂成七分。」所謂「天眼舉罪違背佛制」，就是指前面目犍連尊者的這段因緣。此外《薩婆多論》（《薩婆多毘尼毘婆沙》）也說：「不得使用天眼去窺探知曉他人的惡事。」

【359-0005】02_戒疏/02d_卷一上之二#5
【原文】【疏】問：「十二年前，已制廣教；今言說略，其義何乖？」
【譯文】【疏文】有人發問：「在成道十二年之前，就已經制定了廣教；現在卻說佛當時只說略教，這在道理上豈不是互相違背嗎？」

【359-0006】02_戒疏/02d_卷一上之二#6
【原文】【記】問中。《僧祇》五年制婬，自後隨制，顯有不淨之機。而十二年前佛猶說略，即對犯說，故曰「義乖」也。
【譯文】【記文】在發問的文句中。《僧祇律》記載成道五年時開始制定婬戒，從此以後隨事隨犯而制定，這顯示當時就已經有了身心不淨的犯過根機。然而在十二年之前佛依然宣說略教，那就等於是面對犯戒之人說戒了，所以發問說這在「道理上互相違背」。

【359-0007】02_戒疏/02d_卷一上之二#7
【原文】【疏】答：「《律》中所列重犯故耳。自此已前，先作無罪，猶同無事。至於說戒儀軌，前說略已，及至廣制，說不難知。故《增一》云：『因重犯戒，佛止不說，命上座持律能通利者說之。』故毗婆尸佛一百年前說『忍辱偈』，後付僧說；乃至尸棄、釋迦，八十、十二，可以情求。」
【譯文】【疏文】回答：「那是因為《四分律》中所記載的是再次重犯的緣故。在此之前，起初所作的犯戒行為在未制戒前算作無罪，情況還等同於無事的清淨僧。至於說戒的儀軌，先前既然宣說過略戒，等到後來有了廣制，廣說的儀軌也就不難理解了。所以《增一阿含經》說：『因為有僧人再次重犯戒律，佛便停止不再親自說戒，命令通達利落的持律上座去宣說。』因此，毘婆尸佛在成道最初的一百年間宣說『忍辱偈』（略戒），此後才付囑僧眾宣說廣戒；乃至尸棄佛的八十年間、釋迦牟尼佛的十二年間，皆可依此情理推求。」

【359-0008】02_戒疏/02d_卷一上之二#8
【原文】【記】答中，初釋相違。「《律》所列」者，指前證文。以目連牽出犯者，因盜金蓮花葉，望檀尼是第二犯，故云「重」也。「此前無罪」，以須提那等皆最初故，則顯如來已前說略，皆非犯者。「同無事」者，略教云「為無事僧」，即清淨僧也。「至」下，詳究說廣。初敘難定。前引諸文，但云十二年後付弟子說，不明爾前說不說故。若據如來，定不說廣；此疑弟子，故須決之。「故」下，引示。《經》明如來因犯不說，始命弟子。可驗爾前，定不說廣。以文非顯，故曰「可以情求」。七佛年次，如前委引。
【譯文】【記文】在回答的文段中，首先解釋表面看似相違之處。所謂「《律》所列」，是指前面引用的經律證文。因為目犍連尊者拉出去的犯戒者，是因為盜取了金蓮花葉，比起最初犯盜戒的檀尼迦是屬於再次重犯，所以稱為「重」。所謂「此前無罪」，是因為須提那等人都是最初首犯，在制戒前不算獲罪，這就顯明如來在十二年之前說略戒時，大眾中並沒有知情故犯的犯戒者。所謂「等同於無事」，略教中說「為無事僧說戒」，「無事」指的就是清淨僧。「至」字以下，是詳細探討宣說廣教的情況。先敘述難以確定的疑點。前面所引用的各文獻，只提到十二年之後付囑弟子宣說，並沒有明確說明在那之前到底有沒有宣說廣戒。如果依如來而言，必定是不親自說廣戒的；但這裡令人懷疑的是弟子們是否宣說，因此必須加以決斷。「故」字以下，引用教典予以指示。《經》中明確記載如來因為僧眾再次重犯而不說戒，才開始命令弟子代宣。由此可以驗證，在那之前弟子必定也不說廣戒。因為文獻記載不夠顯著，所以說「可以依情理推求」。七尊佛各自說戒的年限次第，正如前文已詳細引用過的。

【359-0009】02_戒疏/02d_卷一上之二#9
【原文】【註】已前偈文，法護尊者所作，為廣、略二教通序，前開持、毀之言，以成說、聽之本也。
【譯文】【註文】以上前面的偈頌文辭，是法護尊者所造，作為廣教與略教兩部教法的共通序分；在前面先行揭示持戒與毀戒的言論，用以建立宣說與聽受戒法的根本依據。

【359-0010】02_戒疏/02d_卷一上之二#10
【原文】【疏】注中「已前偈文」下，結前生後意也。
【譯文】【疏文】註解中從「已前偈文」以下，是總結前面文義並引出後續內容的意思。
