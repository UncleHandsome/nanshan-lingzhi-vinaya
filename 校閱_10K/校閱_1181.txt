# 校閱材料　第1181檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1181-0001】資持記/09c_中三上#18
【原文】大臣瞋恨，為佛呵責。後佛還羅閱城，諸比丘先受樂師請，後居士施五正食；食已後赴先請，不能多食，遭瞋故制。〕會異中。四律三名，無非重食。今云背請，乃是相傳；於義易顯，故云明判。疏云：隨俗取解，亦無過也。初緣，疏有四句，初前後俱正提，二前正後非正吉，三前不正後正，四俱不正，並不犯。
【譯文】大臣心生怨恨，佛陀因而呵責比丘。後來佛陀返回王舍城，比丘們先接受了樂師的宴請，隨後居士又布施了五種正食；比丘們吃飽之後再去赴先前的宴請，無法多進飲食，再次遭到施主怨恨，佛陀因此制戒。〕在會通各部派差異時，四部律典雖然有三種不同的戒名，但本質上無非都是指重疊重複飲食。現在稱作「違背先前的受請」，是歷代傳承下來的習慣說法；由於在意義上更容易顯明，所以說這是明確透徹的判別。義疏指出：順應世俗習慣來理解文義，也沒有什麼過失。第一項成犯條件中，義疏列出四種情況：第一，前後兩次吃的都是正食，結波逸提罪；第二，前一次是正食、後一次非正食，結突吉羅輕罪；第三，前一次非正食、後一次是正食，以及第四，兩次都不是正食，這兩種情況都不犯戒。

【1181-0002】資持記/09c_中三上#19
【原文】三云病等者，具如不犯中。五隨咽者，疏云不待飽也。釋初緣，正請中，初引二請，通皆有背。次明食體。五正列三，不存廢教。稠即濃厚，合上成四。下引《僧祇》，簡上稠粥。物雖一體，濃薄分異；取初出釜，不約凝漲。釋背中，《僧祇》有二，初明前請。若作下，次明結犯。
【譯文】第三項提到「患病等情況」，詳細內容如同不犯欄位中所列。第五項「隨吞嚥成罪」，義疏說是指每吞嚥一次即結一罪，不必等到完全吃飽。在解釋第一項成犯條件中「正式的受請」時，首先引出兩種受請方式（僧次請與別請），說明違背這兩種迎請皆算背請。接著說明食物的本質。五種正食中列舉了三種，並未廢止其餘教法。稠就是指濃稠厚實，合乎上述便構成四種情況。下文引用《僧祇律》，用來甄別判斷上述何者屬於濃稠的粥。物質雖然是同一種東西，但依濃稠與稀薄而有所分別；應當以剛剛起鍋時的狀態為準，而不是看冷卻凝固膨脹之後的樣貌。在解釋「違背約定」時，《僧祇律》分成兩部分，首先說明前一次的受請。在「若作」以下，接著說明如何結罪。

【1181-0003】資持記/09c_中三上#20
【原文】不白請家者，犯後四十二戒。釋第三，初科有三，初釋病緣。律因病比丘不得隨病食故。次釋施衣緣。律中一家單食請，一家衣食請，佛開背前；又律云：自恣竟，無衣一月，有衣五月〔此通開背，不約兼衣。〕；又云：若復有餘施食及衣等，此明兼施，不限時與非時，故云十二月也。若一日下，明捨請，初示捨法。
【譯文】如果事先不稟告前一位請客的施主，便會觸犯後文的第四十二條戒。在解釋第三項時，第一科包含三個層面，首先解釋患病的緣由。律中是因為生病的比丘無法隨意挑選適合病情的食物之故。接著解釋布施衣物的緣由。律典中記載，如果一家單純請吃素齋，另一家同時布施衣服與飲食，佛陀開許可以捨棄前一家；律中又說：解夏自恣結束之後，沒有得到僧衣者有一個月開緣，得到衣物者有五個月開緣〔這是通盤開許違背前請，並不限於兼施衣物的情況。〕；律中又說：如果還有其他施主供養食物與衣服等，這指兩者兼施，不論是應時或非應時的時段，所以說是整整「十二個月」。在「若一日」以下，說明捨棄先前受請的方法，首先指示捨請的儀軌。

【1181-0004】資持記/09c_中三上#21
【原文】若不下，明犯相。引《五百問》決上可否，主嫌不捨，亦應成背；準前六念，開心念捨。次科，彼宗開病，限至三家，但開背二；若容更背，恃開無節，教緩機慢，故不得四也。不犯中，七；前三如上，第四注中，粥謂出釜稀者，餘則枝葉細末等。五中，注云少者，犯取境足故。
【譯文】如果「不」字以下，說明成犯的情狀。引用《五百問》來裁決上述做法是否得當，如果施主心生怨嫌而不肯答應捨去，按理也應當構成違背受請；比照前文的「六念法」，此處開許可以在心中作意默許捨去。在下一科中，該部派開許生病時的受請，上限為三家施主，但只開許違背前兩家；如果允許繼續違背受請，比丘便會仗著開緣毫無節制，導致教規鬆弛、行者懈怠，所以絕不能通融到第四家。在不犯的項目中共有七種；前三種如上所述，第四種注文中提到，粥是指剛起鍋時質地稀薄的粥，其餘食物則是樹枝、綠葉、細碎粉末等雜食。第五項中注文提到「微少」，是因為要滿足犯戒條件必須達到標準的份量。

【1181-0005】資持記/09c_中三上#22
【原文】第六無請，豈得有犯；七謂前後重食，乃可犯足，而不犯背；必不壞儀，足亦非犯。律又云：一處前後食，謂同主異食，非背可知；文中不出，故云等也。三十三。〔佛在羅閱祇，提婆教人害佛，教闍王殺父；惡名流布，利養斷絕；乃與五人別乞，因制。〕釋戒名者，謂能別之人，食處成眾；
【譯文】第六項是根本沒有接受先前的邀請，哪裡會構成犯戒；第七項是指前後兩餐都吃得極飽，雖然可能觸犯「足食戒」，但並不觸犯「背請戒」；只要不損壞威儀體統，吃飽本身也不算犯戒。律典又說：在同一個處所先後進食，是指由同一位施主提供不同的食物，這顯然不屬於背請的範疇；條文中未一一列出，所以用「等」字概括。第三十三條波逸提法。〔佛陀在王舍城時，提婆達多教唆旁人謀害佛陀，教唆阿闍世王弒父篡位；惡名遠播之後，供養利養全斷絕了；他於是帶著五位徒眾另行單獨化緣乞食，佛陀因此制戒。〕解釋戒名時，是指能夠發起別立行為的人，在用餐處所聚合成了僧眾；

【1181-0006】資持記/09c_中三上#23
【原文】以眾別他，不共同味；若取語便，應云眾別；然據所別，非不通眾；但犯由能別，故獨彰名。又能唯約眾，所通眾別。委如《本疏》。約相中，初科，本律有二，初約廣解明別請。即開緣文。佛初未開，比丘凡有他請，皆用此言對之，如鈔所引。至後白佛，故有七開。若依下，次約緣起明別乞。
【譯文】他們以自己的小眾脫離了其他大眾，不肯與大眾共同享用同一樣食物；若是順應語法便利，理應稱作「別離大眾」；然而就其所脫離的對象而言，也未嘗不能通稱大眾；只是犯戒責任在於這群自行別立的人，所以單獨以此立名。又或者「能別」單指這群小眾，「所別」則通指全體大眾或個別僧眾。詳細內容正如《行事鈔本疏》所載。在分析犯戒相狀中，第一科提到，本律有兩種面向：首先是透過廣泛解釋來闡明個別受請。這正是屬於開緣的經文。佛陀最初尚未開許時，比丘只要遇到其他外來迎請，都用這套說辭回絕對方，正如鈔文所引用的那樣。直到後來向佛陀稟白，才有了七種特別開許。在「若依」以下，接著藉由起因緣起來說明個別乞食。

【1181-0007】資持記/09c_中三上#24
【原文】難調人即召提婆，明佛制戒，為攝彼故。〔本宗止有此二。〕《多論》具三，皆論不集，初句總標。亦下，別列。上云亦明者，亦前律文；下云亦有者，亦上二種。分相解中，總標。云各明緣者，三位各具七緣，如下所列。引據證別者，即下多見二論辨三相不同。僧次中，初科。
【譯文】「剛強難調伏之人」就是指提婆達多，這說明佛陀制定此戒，是為了收攝防範那幫惡人的緣故。〔本宗四分律僅有這兩種面向。〕《薩婆多論》具備三種面向，都是探討眾僧未能集會的情況，第一句是總括標明。「亦」字以下，分項列舉。上文說「亦明者」，是同樣闡明前面的律文；下文說「亦有者」，是兼具上述兩種情況。在逐一分析相狀的解釋中，先作總括標明。所謂「各自辨明成犯事緣」，是指這三種情境各自具備七項條件，正如後文所羅列的。引用文獻佐證其差異，即指後文多處引用兩部論典來辨析這三種情狀的不同。在依僧倫次受請的科判中，進入第一科。
