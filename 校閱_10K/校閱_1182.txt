# 校閱材料　第1182檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1182-0001】資持記/09c_中三上#25
【原文】且據僧次，餘二例同，但改第二為異。次科有二，初明僧界開法。須布薩處，即知法者所居，以布薩是攝眾之法；請彼一人，則表眾集。自處不須者，即彼二處不相請送，與下俗舍不同。若下，次明聚落，初明作法。加打犍槌。僧界人多，不可作相，但有二法。更下，明重作。以後來者，復成別故。或下，明互轉。
【譯文】此處姑且根據「依僧倫次受請」為準，其餘兩種情況均可比照辦理，只是將第二項條件改換為其特有的相狀。下一科分為兩部分，首先說明僧團結界處所的開許作法。必須在「布薩場所」，也就是通達戒法的主事者所居住之處，因為布薩是統攝全體僧眾的法事；迎請那裡的一位僧人，就象徵著全體僧眾齊集。在自己原處則不需要另行作法，因為那兩處之間互不迎請送達，這與後文世俗房舍的作法不同。在「若」字以下，接著說明村落聚落的情況，首先說明進行羯磨法事。增加了敲擊犍槌的儀式。僧團界內人數眾多，不可能一一當面作意宣白，所以只有這兩種法事。在「更」字以下，說明重新作法。因為對於後來才抵達的僧人，又會再次構成個別隔離的過咎。或者「或」字以下，說明彼此身分的互相轉換。

【1182-0002】資持記/09c_中三上#26
【原文】如後廣之。如下，結示。別乞中，《見論》。四句，且引初句，餘三如後。《多論》。各乞同處，反明同乞異處成別。別請中。作法即鳴鐘，唱令召夏臘等。遮食罪準理是吉。若下，約集明犯。準上界內無人之文。下引文證，同坐異味，亦即集犯。準決中。總斷三位，不集皆同，集犯有別。
【譯文】這如後文所詳細闡述。在「如」字以下，結語指示。在「個別乞食」中，引用《善見論》。列出四種情況，此處暫且引述第一句，其餘三句如後文所述。《薩婆多論》提到：各自乞食卻聚集在同一處所受用，反過來證明：共同乞食卻分開在不同處所受用，便構成了別眾。在「個別受請」中。其法事即是鳴響鐘聲、唱導號令並依照戒臘長幼唱名等。阻擋他人進食的罪過，依照常理推斷應屬於突吉羅輕罪。在「若」字以下，針對齊集僧眾來辨明是否犯戒。比照前文僧團結界內無人的文句。下文引用經文為證，同處就坐卻享用不同的飲食，這同樣構成了齊集時犯戒。在權衡裁決中，總結判斷三種情境，在未曾齊集大眾這一點上完全相同，但在齊集時是否成犯則有所差異。

【1182-0003】資持記/09c_中三上#27
【原文】僧次若集，則無有過；餘二集犯者，別請如上，別乞準同。次重釋中。標云約緣者，即上七緣。文中但釋五種，三七易解故。令下二句，出重廣之意。初中，前明揀濫。今世有人，一概但云別眾，不知僧食自犯重盜；又有見將異味在眾獨噉，便言別眾食者；
【譯文】依僧倫次受請的情況若是大眾齊集，便沒有過失；其餘兩種在齊集時仍屬犯戒，個別受請已如上述，個別乞食亦比照處理。接著在重新解釋中，標題寫著「依據條件緣由」，即指上述的七項條件。條文中僅僅解釋了其中五種，因為第三與第七項容易理解的緣故。「令」字以下這兩句，說明了重新擴充解釋的用意。在第一項中，前段先辨析排除混淆之說。當今世上有些人，不分青紅皂白一概稱作「別眾」，殊不知盜用僧眾常住公物本自構成嚴重的偷盜重罪；又有人看到僧人私自將特殊美食帶到大眾中獨自食用，便指責這是「別眾食」；

【1182-0004】資持記/09c_中三上#28
【原文】事雖非理，名教天乖，不可濫也。故下引證。僧祇翻眾，即目常住眾物耳。上卷即〈僧網〉中。第二緣。標云別僧者，即如下云施主別請僧次四人是也。但不定名，故云僧次。僧次中《五分》為三，初簡能受人。文列五種，並堪預數，不可揀擇。除惡戒者，疏云：僧次一種，必以淨戒為先；
【譯文】這種事雖然不合情理，但與戒律教法的本名差距甚遠，絕對不可含混混淆。因此下文引用經文為證。僧祇翻譯為「大眾」，指的正純是常住僧眾的公物罷了。上卷即指〈僧網篇〉中。第二項條件。標題寫著「個別從僧團中挑選」，即如後文所說施主特別指名迎請僧倫次序中的四位僧人。只要不限定特定人名，所以稱為「僧次」。在僧次中，《五分律》將其分為三個層次，首先甄別合乎資格的受請人。經文列舉了五類僧人，全部都有資格列入計數，不得加以挑肥揀瘦。除了犯毀滅戒的惡戒之人，義疏解釋：僧次這項法事，必定以持戒清淨者為優先；

【1182-0005】資持記/09c_中三上#29
【原文】微犯憲章，不令受利等。〔準犯小罪即為所簡。〕若下，二示僧次法又二，初正示。以下，顯非。以法取者，雖不定名；簡其所學，即非僧次；此謂雖通而別，非平等故。《十誦》下，三引文證。彼云：有人請佛五百羅漢，佛言不名請僧福田；
【譯文】稍有違犯戒律憲規，就不應當讓其接受利養等。〔依此推準，哪怕觸犯小罪也應在剔除之列。〕在「若」字以下，第二項是指示如法進行僧次的規矩，又分為兩節，首先是正面指示。在「以」字以下，揭示錯誤的行徑。若依所學法門（如指名請禪師）揀擇，縱然未指明姓名；如果甄別挑揀僧人的修學門派，這就不屬於依僧次迎請；這叫作雖然形式通於僧次、實質卻存有分別心，並非真正的平等普供。在引用《十誦律》以下，第三項是引用經文作證。經中說：有人迎請佛陀以及五百位阿羅漢，佛陀卻說這不叫作「供養全體僧寶的福田」；

【1182-0006】資持記/09c_中三上#30
【原文】若能於僧中請一似像極惡比丘，猶得無量果報；與下《增一》意同。如下，指略，即下卷〈赴請篇〉。別請中，初科；初至不清淨來，明初請法。二若九十日下，明續供法。初中復二，初明先請。長請謂不限日也。至下，明來集，初明無遮盡集。
【譯文】若是能夠在僧團大眾中，依照倫次迎請一位形象具足的極惡比丘，所獲得的福報依然無量無邊；這與後文《增一阿含經》的意旨完全相符。在「如」字以下，指示內容予以精簡，即見於下卷的〈赴請篇〉。在「個別受請」中，進入第一科；從最前段一直到「不清淨來」，說明最初應邀受請的法則。第二部分從「若九十日」以下，說明連續供養時的法則。在第一部分中又分為兩節，首先說明先前的迎請。「長請」是指不限定宴請天數的供養。在「至」字以下，說明僧眾前來齊集，首先說明沒有阻攔、全體齊集的情形。

【1182-0007】資持記/09c_中三上#31
【原文】先無別請者，謂長請之外，一切普設，無別召者；則二日已去，縱遮無過。不能下，次明有遮免過。不能無遮者，食不足供也。勸化比丘，即是門師。言六十臘者，趣舉多者為言；乃至者，五十九下，次第減唱。言都無者，虛唱成法，為免後患。若不下，明違教結犯。
【譯文】所謂「事先沒有單獨受請」，是指在長期受請之外，施主全面普設齋供，並未另外個別召請特定人；那麼從第二天起，縱然阻攔其他人赴請也沒有過失。在「不能」以下，接著說明在有阻礙限制的情況下如何免除過失。所謂「無法全面普供」，是指食物不足以供應全體僧眾。在旁勸勉教化的比丘，即是施主的依止師父。提到「六十個戒臘」，只是隨意舉出最高壽數作為範例；所謂「乃至」，是指從五十九臘往下，依照順序逐一遞減唱導。所謂「全然沒有其人」，是指虛設唱名來完成儀軌法事，純粹是為了免除後續結罪的後患。在「若不」以下，說明違背戒規將被結罪。

【1182-0008】資持記/09c_中三上#32
【原文】有無皆罪，文相可知。二法即打槌唱臘。〔或可初日及日日為二。〕次續供中。即前法者，以相續不絕故。僧房等須唱者，準似夏初四事皆唱；食味是通，唱法亦續，故不更唱；房舍別屬，期限已滿，故須別唱。二就界中文有三節，初明食一處異。味同不犯。二若大界下，明一界兩院。
【譯文】無論有沒有其人皆構成罪過，文句義理極為明瞭。兩種法事即指敲擊犍槌以及唱念戒臘。〔或者也可以指最初第一天以及往後每一天的兩道作法。〕接著在「連續供養」中，指的正是前面那項法事，因為供養相續不斷的緣故。僧房等處之所以必須唱名宣白，比照解夏之初四事供養皆須唱名的規矩；飲食風味是共通受用的，唱名儀軌既然在延續，所以不必每天重新唱名；但房舍僧居屬於個別僧人專屬配受，期限已滿，所以必須另外重新唱白分配。第二、在劃定結界範圍內，經文分為三節，首先說明「吃同一處食物但內容不同」。只要食物滋味品質相同便不犯戒。第二在「若大界」以下，說明同一個大界內分為兩個院落。
