# 校閱材料　第1435檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1435-0001】04_比丘尼鈔/03a_卷中之上#73
【原文】第九無師住時節者此律開先洗足飲水已然後依止伽論云初至他處不相諳委二三日選擇師十誦云無好師者聽五六夜有好師者乃至一夜不依止者得罪。
【譯文】第九門「無師時節」：本律開許比丘剛到一處，先洗腳、喝水休息，然後再去尋求依止。《摩得勒伽論》說：剛到其他地方，彼此情況不熟悉，可以在兩三天內挑選合適的師長。《十誦律》說：如果沒有德行完備的好師長，聽許停留五至六個夜晚；如果已經有具德的好師長，哪怕只有一個晚上不依止受教，就得罪。

【1435-0002】04_比丘尼鈔/03a_卷中之上#74
【原文】第十簡師德者此律阿闍棃有五種一出家阿闍棃謂依教受十戒者是二受戒阿闍棃謂為受具足秉羯磨者是三教授阿闍棃謂教授威儀者是四受經阿闍棃謂所從受經者是五依止阿闍棃謂受依止者是義云前四通名阿闍棃今此所明準論依止闍棃以替和尚處故必須諳究經律圓解明白方始得為僧祗云不得輒請依止須成就五法一受念二恭敬三慚四愧五樂住伽論云凡欲依止人者當好量宜能長善法者及問餘人云此比丘尼戒德何似能教誡否眷屬復何似無有諍訟否若都無者然後依止此律明二師德者有三一簡少取老十二夏已上為和尚至六夏已上為闍棃二夏數雖滿必須智慧三雖具上二德然要勤教詔弟子闍棃亦七種共行法如前和尚中說。
【譯文】第十門「審選師德」：本律規定阿闍梨共有五種：一是「出家阿闍梨」，也就是依據其教導而受持十戒的師長；二是「受戒阿闍梨」，也就是在受具足戒時主持宣讀羯磨的師長；三是「教授阿闍梨」，也就是傳授威儀禮節的師長；四是「受經阿闍梨」，也就是跟從其受學經文的師長；五是「依止阿闍梨」，也就是接受其依止教導的師長。義理上分析：前四種統稱為阿闍梨；而現在這裡所說明的，依準論典指的是依止阿闍梨，因為他是用來替代和尚位置的，所以必須精研通曉經藏與律藏、解行圓滿透徹明白，才能夠擔任。《僧祇律》說：不得隨意請求依止，求請依止者必須具備五種心法：一是心存愛重敬念（受念／愛念），二是具有恭敬心，三是有慚，四是有愧，五是樂於安住。《摩得勒伽論》說：凡是想要依止別人，應當好好審度考量，選擇能夠讓自己增長善法的人；並且應當探問其他人說：「這位比丘尼的戒行道德如何？能否勝任教誡？她的弟子徒眾相處如何？有沒有紛爭訴訟？」如果完全沒有過失，然後才可以去依止。本律說明具備和尚與阿闍梨二師資格的德行有三種：一是淘汰年少而選取老成者，具備十二夏以上才能當和尚，六夏以上才可以當阿闍梨；二是戒臘雖然足夠，但必須具備智慧；三是雖然具備上面兩種資歷與德行，但還必須勤於教導訓示弟子。阿闍梨也有七種共同行持之法，如同前面和尚章節中所說的一樣。

【1435-0003】04_比丘尼鈔/03a_卷中之上#75
【原文】第十一請師法者此律由和尚命終無人教授故多壞威儀佛令聽有依止闍棃相依教訓如和尚法展轉相依令佛法倍增益流布請時具修威儀至彼師所云。
【譯文】第十一門「請師儀軌」：本律指出：因為和尚去世後無人教授指導，以致許多人敗壞了威儀禮法，佛陀便聽許尋求依止阿闍梨，互相依傍接受教誨訓導，如同依止和尚之法一樣，展轉相依，使得佛法能夠加倍增長廣傳流布。請師的時候，應當具足端正威儀，來到該師長住處說道：

【1435-0004】04_比丘尼鈔/03a_卷中之上#76
【原文】大姉一心念。我比丘尼某甲。今求大姉。為依止阿闍棃。願大姉為我。作依止阿闍棃。我依大姉故。得如法住。
【譯文】「大姊請一心專念。我比丘尼某甲，如今懇求大姊做我的依止阿闍梨。祈願大姊為我擔任依止阿闍梨，我依靠大姊的緣故，得以如法安住。」

【1435-0005】04_比丘尼鈔/03a_卷中之上#77
【原文】彼師告云可爾與汝依止莫放逸五分云若師不答許可者不成依止法。
【譯文】那位師長應當答覆說：「可以，給你依止，切莫放逸。」《五分律》說：如果師長沒有答腔許可，依止法就不能成立。

【1435-0006】04_比丘尼鈔/03a_卷中之上#78
【原文】第十二攝受法者僧祇云日別三時教三藏教法不得廣者下至略知戒經輕重陰界入義若受經時共誦時坐禪時即名教授若不爾者下至云莫放逸義云若請師須具四意一作請彼攝我我當依彼慈念憐愍意二請取道法資神令教授行成智立意三自申己意我能依止愛念恭敬如父母想意四彰己能依止而行謂慚愧二心也具此四法方無過咎若不爾者徒自悠悠終無成辦五分受戒已師應六年自攝若教他攝違者犯提弟子亦應六年依承和尚此律受戒已不得離和尚見論云和尚多有弟子留一人供給餘者隨意令讀誦僧祇云弟子為王難師必經理若賊抄掠等覓錢救贖否者犯罪十誦云和尚有四種法弟子應量宜一與法不與食應住二與食不與法不應住三法食俱與應住四若法食俱不與者不須問師若晝若夜應捨去闍梨亦然僧祇云苦住樂住四句同前五百問事云其師無非法而誘將他沙彌去犯重。
【譯文】第十二門「師長攝受之法」：《僧祇律》說：每天應當在三時中講授三藏教法；若無法博泛廣傳，最低限度也應當粗略明了戒經的輕重罪行，以及五陰、十八界、十二入的法相名義；若是講受經卷時、共同讀誦時、坐禪指導時，就叫做教授指導；如果連這些都做不到，最低限度也得叮嚀說一句「切莫放逸」。義理上分析：如果請求拜師，必須具備四種心意：一是發心懇請對方攝受自己、自己應當依賴師長的慈悲哀憫之心；二是懇求汲取佛法精髓資養心神，讓師長教授成就自己的德行與智慧；三是親自表明自己的誠意，表示自己能夠全心依止，如同對待生身父母一般親愛、敬順；四是彰顯自己能夠確實遵奉依止而行持，也就是發自內心的慚愧心。具備這四種發心，才不會產生過失；若非如此，只是徒然悠閒度日，終究一無所成。《五分律》規定：受戒完畢之後，師長應當親自攝受教導六年；如果隨意委託別人代管，違者犯波逸提罪；弟子也應當跟隨承事和尚滿六年。本律說：受戒之後，不得擅自脫離和尚。《善見論》說：和尚若有眾多弟子，可以留一人在身邊侍奉供給，其餘的任憑他們的意向去攻讀背誦經律。《僧祇律》說：弟子如果遭遇官府王難，師長必須設法奔走營救；如果被盜賊劫持掠奪等，應當籌措錢財前往贖救，不盡力者犯戒有罪。《十誦律》說：和尚有四種情況，弟子應當自行考量抉擇：一是只給予正法而不供給飲食，應當留住；二是只給予飲食而不傳授正法，不應當留住；三是法與飲食兩者都供給，應當留住；四是若佛法與飲食兩者都不給予，不必向師長告辭，無論白天或夜晚，都應當收拾離去。對阿闍梨也是同樣道理。《僧祇律》說的辛苦同住、安樂同住等四句，含義與上述完全相同。《五百問事》說：如果一位師長並沒有不如法的事情，別人卻以利誘哄騙帶走他的沙彌門徒，這樣做便犯了重戒。
