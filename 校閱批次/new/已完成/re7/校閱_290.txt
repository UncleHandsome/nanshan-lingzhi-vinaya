# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】【疏】世中有人用餻糜等，非是「飯」攝。如粥出釜畫成字者，則是足、正。準此以求，可以例矣。
【譯文】【疏文】世間有人食用米糕、爛麵糊等，認為這些不屬於「飯」所攝受。如果稀粥剛出鍋時濃稠到表面可以用筷子劃出字痕的，這就屬於食足與正食。依照這個標準去推求，就可以類推其餘食物了。

【290-0003】02_戒疏/15b_卷三下之三#81
【原文】【記】斥濫中，初科。初出濫。「餻糜」，謂以飯為餻，蒸令糜爛者。「如」下，準決。粥分稠薄，文出《善見》，此同稠粥，義歸「正」收。
【譯文】【記文】斥責謬誤中，第一段。首先指出混淆之處。「餻糜」，是指拿米飯做成糕，蒸到糜爛的食品。「如」字以下，依照規則判定。粥分為濃稠與稀薄兩種，文句出自《善見律》，這種濃稠的粥，在義理上歸屬於「正食」所收攝。

【譯文】【疏文】又有人拿糕點麵餅，當作同米飯一樣的正食。其實這是由細粉研磨製成的，應當歸屬於非正食（佉闍尼）所攝受。

【譯文】【疏文】魚和肉這兩種，小乘教法中是因特殊緣故曲意通融開許。通貫來說，大乘與小乘教法其實都嚴格禁止。詳細內容如同《事鈔》中的辨析。

【290-0009】02_戒疏/15b_卷三下之三#87
【原文】【記】三中。初引所廢。言「曲開」者，事不已也。又準《涅槃》，前聽食者，非實眾生，但化現耳。「通」下，次明能廢。「大」如《稜伽》、《涅槃》，「小」即《僧祇》、《四分》。《僧祇》云：「若為比丘殺者，一切七眾不應食。」《四分》：「持十善家得肉，乃得食之。」斯則小教，非一向開也。下指「如《鈔》」，見《四藥篇》。
【譯文】【記文】第三段中。首先引出被廢除的舊說。所謂「曲開」，是因為在特殊情勢下不得已而開許。又依據《涅槃經》，先前聽許食用的，並不是真正的眾生肉，只是佛力變化顯現的罷了。「通」字以下，接著說明廢除開許的定製。「大」是指《楞伽經》、《涅槃經》，「小」是指《僧祇律》、《四分律》。《僧祇律》說：「若是專門為比丘殺害的，一切七眾弟子都不應當食用。」《四分律》說：「從持守十善的人家化緣得到肉，才可以食用。」由此可見小乘教法也並非一概毫無限制地開許。下文指出「詳如事鈔」，請參閱《四藥篇》。

【290-0010】02_戒疏/15b_卷三下之三#88
【原文】【疏】二、明非時藥體。《律》中八漿，古昔無欲仙人所飲故，有渴病者開之。若加口法，隨何時受，至於昧爽。若不加法，隨受隨飲，限在須臾。《律》無定判，《僧祇》如此。
【譯文】【疏文】第二、說明非時藥的體質。《律》中記載的八種果漿，是古時候斷絕欲望的仙人所飲用的，所以比丘若患了口渴病，佛陀就開許飲用。如果依法口頭作了受持加持法，無論何時受持，都可以飲用到次日黎明破曉時。如果不作加持法，則是隨時受取隨時飲用，時間僅限在極短的時間之內。《四分律》中沒有明確判定，《僧祇律》則是這樣規定的。

【290-0011】02_戒疏/15b_卷三下之三#89
【原文】【記】第二，非時，定體中，初科。初示體。「八漿」：一、棃，二、酸棗，三、甘蔗，四、𮒂果，五、蒲萄，六、舍樓伽，七、閻浮果，八、波樓伽果。「無欲仙」，謂無貪欲者。「若」下，明時限，又二。初明有法限。「昧」，暗也，「爽」，明也，謂夜分將盡，欲明未明之時。次明無法限。「律」下，示所出。《鈔》引《僧祇》云：「非時受，不得置地停。」謂時中受者，則容停久；非時中受，即須加法，不可放地停過須臾。準明非時即受即服，不須加法，故云「《僧祇》如此」。
【譯文】【記文】第二、非時藥，判定體質中，第一段。首先指示體質。「八漿」是：第一、梨漿，第二、酸棗漿，第三、甘蔗漿，第四、𮒂果漿，第五、葡萄漿，第六、舍樓伽漿，第七、閻浮果漿，第八、波樓伽果漿。「無欲仙」，是指沒有貪欲的仙人。「若」字往下，說明時間界限，又分兩層。首先說明有作法加持的期限。「昧」，是黑暗；「爽」，是明朗，指黑夜將盡、將亮未亮的拂曉時分。接著說明不作法的期限。「律」字以下，指出資料出處。《事鈔》引用《僧祇律》說：「在非時受取，不可以放在地上久停。」意思是如果在應食時間內受取，則容許放置較久；若在非時受取，就必須立刻作法加持，不能放置在地上停滯超過片刻。由此證明在非時中現受現喝，不需要繁瑣作法，所以說「《僧祇律》就是這樣規定的」。

【290-0013】資持記/14c_下二#50
【原文】《智論》但明計功一境，初句標能觀心。墾下，列所觀境又三，初觀功力。墾，耕也。植，種也。耘除謂去穢草。收穫即刈禾，穫音鑊。蹂治即踐󰝿；蹂音柔，或上呼。須下，次觀變穢。纔入生藏，食即酸臭；次入熟藏，即成屎尿。我下，三觀來報。故下，論家結勸。《僧祇》具明二境，初句總告。
【譯文】《智論》只說明計功這一種境界，開頭一句標出能觀的心。「墾」以下，列出所觀的境界，又分三節，第一是觀功力。墾就是耕，植就是種，耘除是說除去雜草，收穫就是割取稻禾，「穫」讀音同「鑊」。蹂治就是踐踏整治，「蹂」讀音同「柔」，或者讀上聲。「須」以下，其次觀變穢：才進入生藏，食物就變酸臭；接著進入熟藏，就變成屎尿。「我」以下，第三是觀來報；「故」以下，是論主總結勸勉。《僧祇律》完備地說明兩種境界，開頭一句是總告。

【290-0014】資持記/14c_下二#51
【原文】計下，示觀。上二句觀功。文舉一粒，以少況多。次二句觀來處。末句斥損費。二中，標。云忖者，亦即觀智，此謂量己所修行業，即此行業是所觀境。《母論》具明能所二人，意彰所施無德，不堪受故，初簡德業。具列三種，禪誦是自行，營事即利他。三業即上三種。
