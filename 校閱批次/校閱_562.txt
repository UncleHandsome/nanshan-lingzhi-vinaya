# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【562-0001】03_業疏/15b_卷三之四#85
【原文】彼部通曰：言無作非礙非色者，不同可見不可見有對色礙，故言非色非礙，非不是無對色礙。若聞無作雖非色礙，謂是非色礙者，即〈界品〉云「過去色雖非礙曾礙故，未來色當礙故，現在微塵雖非礙眾微集則礙」，豈以微塵不可觸而得名非色？然則微塵是微色即是微礙。故知非者，謂非麤現之色礙也
【譯文】薩婆多部通釋說：所說無作戒非質礙、非色者，只是不同於可見與不可見的有對色之質礙，所以才說非色、非質礙，並非它不屬於無對色的質礙。如果聽到無作戒雖然不是粗顯的色礙，就認為它完全不具有色法之質礙，那麼〈界品〉又說「過去色雖然現在不礙但過去曾經質礙，未來色未來應當質礙，現在的極微細塵雖然不礙但眾多極微聚集就產生質礙」，難道能因為極微細塵不可觸摸就稱它為非色嗎？然而極微細塵既然是極微之色，那就是極微之質礙。因此知道經論所說的「非」，是指並非粗顯現前的色法質礙罷了。

【562-0002】03_業疏/15b_卷三之四#86
【原文】次科，初釋通前文。「非礙非色」，牒上兩文。「有對色礙」謂五根五塵，「無對色礙」即法入假色。「若」下引論反質，又三：初引文，彼三世色並云非礙，不可執此便云非色；「豈以」下質謬；「然」下顯正。「麤現色」者，如前十四、二十等。且明假宗引據之誤，必應實宗反用《成論》，避繁不引，故云「略敘」耳
【譯文】第二科，首先解釋通達前面的文義。「非礙非色」，是引述上面兩處引文。「有對色礙」是指五根五塵，「無對色礙」就是法入處所收的假色。「若」字以下引用論書反詰質疑，又分為三層：首先引證論文，那裡的三世色都說是非礙，不能執持這一點就硬說是非色；「豈以」以下是質難其謬誤；「然」以下是顯發正義。「粗顯現前之色」，就是前面所說的十四種、二十種顯色形色等。這裡且先辨明假名宗引用論據的錯誤，實法宗必定也會反過來引用《成實論》進行辯難，為了避免繁冗而不予引用，所以說是「略敘」罷了。

【562-0017】03_業疏/16a_卷三之五#1
【原文】示三宗中，初科初略示體貌。納是能受心，聖法即所受戒。能所相冥，心法和合而成於業。攬法為業，為道基本，故名戒體。體充正報，心為總主，故云「心胸」。初受則心為能納、法為所納；受已則法為能依、心是所依。問：即法是體，法、體何分？答：若望未受，但名為法，體是無情；若加期誓要緣領納，依心成業，此法有功，乃名為體。是故言法未必是體，言體其必是法。如藥丸喻：藥味各別，如戒法也；和合成丸，如戒體也。丸非他物，即藥成丸，雖異而同，雖同而別，如是知之。「依體起用」，即隨行也。「今」下次標宗別釋
【譯文】在開示三宗的文字中，第一科首先簡略標示戒體的體貌。「納」是能受的心，「聖法」就是所受的戒。能受與所受相冥合，心與法和合而成就業體。攬取戒法成為自體之業，作為證道的根本基石，所以稱為「戒體」。戒體充盈於正報身心之中，心是總主宰，所以說「心胸」。最初領受時，心是能納受者，法是所納受者；受戒完畢之後，法是能依之法，心是所依之處。問：既然戒法就是戒體，法與體如何區分？答：若就尚未領受而言，只稱為法，法體屬於無情；如果加上期約誓願與重要緣境而領受接納，依附自心而成就業力，此法便產生了防非止惡的功能，這才稱為體。因此說到「法」未必就是「體」，說到「體」則必定是「法」。如同藥丸的譬喻：藥草的各味藥材各自不同，比喻戒法；將藥劑調和凝聚成藥丸，比喻戒體。藥丸並非其他事物，就是匯集藥材成就藥丸，雖有差別而同一，雖是同一而有別，應當這樣來理解。「依體起用」，就是隨行持戒。「今」字以下接著標明宗派分別解釋。
