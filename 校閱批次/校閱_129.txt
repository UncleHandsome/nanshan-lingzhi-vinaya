# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【129-0001】02_戒疏/05d_卷二上之一#56
【原文】【疏】答：「深有旨也。若為鈍根，無由離惡，且勸持戒，徙惡從善，故舉世樂，以勸彼持，如文是也。若又樂福，無心涉道，非佛本意，故又訶毀。如上《涅槃》，即《戒本》末『戒淨有智慧，便得第一道』。轉鈍為利，豈不然乎？依此修行，不名為利。是於二法，立不犯行。」
【譯文】【疏文】回答：「這其中有極深奧的旨趣。如果是針對根性鈍劣的眾生，他們無從遠離惡業，便暫且勸勉他們受持戒律，遷改惡習以趨向善行，所以提出世間的安樂來勸勉他們持守，正如戒本中的文句所言。但如果一味耽溺於世間福報，全無心志趣向解脫聖道，這便違反了佛陀的本意，所以經中才會予以呵斥非議。正如前文所引《大涅槃經》，即對應戒本末尾的『持戒清淨而具備智慧，便能證得第一聖道』。使鈍根轉化為利根，難道不是這個意思嗎？若僅依此世樂而修行，就不能稱為利根（不名為利）。這就是從世樂與對治這兩種法門上，安立不犯之行。」

【129-0002】02_戒疏/05d_卷二上之一#57
【原文】【記】問中。引《戒本》偈，並上經文，呵、歎相違，故須通會。答中分三。初句總歎，「若」下，別釋。初釋戒文。「徙」，猶改也。「世樂」，即名、利、生天。「若又」下，次出《經》意。初正釋。引《戒本》以合《經》文。準知《經》局利根，《戒》通利鈍。利根捨福從道，故云「轉鈍」。非出離道，故「不為利」。「是」下，三、結示。「二法」，即以世樂、對治為不犯法。「鈍」對世樂立不犯行，「利」就對治立不犯行。是知世樂，鈍者成持，利者名犯。
【譯文】【記文】提問中，引用戒本中的偈頌，與前面引用的經文相對照，兩者一呵斥、一讚歎，彼此互相矛盾，所以必須加以會通解釋。回答分為三部分：第一句總括讚歎教旨；自「若」字以下個別解釋：首先解釋戒本文義，「徙」是改換的意思，「世樂」即指名利與投生天界。自「若又」以下，進一步道出佛經的真意：先作正面解釋，引用戒本以契合經文，由此可推知經文局限於對利根者說，戒本則通於利根與鈍根兩類人。利根之人捨棄世福而歸向聖道，所以說是「轉鈍為利」；因為這不是世間名利而是出離之道，所以「不稱為功利」。自「是」字以下，第三、作結語示明。「二法」就是指將世間安樂法與出世對治法當作不犯之法：對「鈍根」而言，追求世樂便能安立不犯之行；對「利根」而言，唯有專修對治才能安立不犯之行。由此可知世間安樂，對鈍根人來說算作持戒，對利根人來說便算違犯。

【129-0003】資持記/13b_下一#50
【原文】後引《十誦》明隨失者。疏云：衣法假本，本失末亡；而非正則，亂倫獲罪。〔倫即次也，亂次犯吉。〕坐具中。梵云尼師壇，此翻隨坐衣。制意中，初顯意。為身者，恐坐地上有所損故；次為衣者，恐無所籍，三衣易壞故；為臥具者，恐身不淨，污僧床榻故。長下，示量。注中，前示正體。應法謂合字書。

【129-0004】01_行事鈔/09a_卷下之一#44
【原文】《僧祇》：坐具者，此是隨坐衣，不得淨施，及取薪草，盛巨磨，唯得敷坐。《善見》云：須受持，不合淨施。不出其文。義加云：「大德一心念！我比丘某甲，此尼師壇應量作，今受持」三說。若破壞須換易者，當捨之。文同受法，改下云：「今捨」也。
【譯文】《摩訶僧祇律》說：所謂坐具，這是隨身用來敷坐的法衣，不得拿去作淨施（說淨），也不得拿去包裹柴薪青草，或者用來盛裝巨摩（牛糞），只可以用來鋪設敷坐。《善見律毘婆沙》說：必須加法受持，不適合拿去作淨施。但該書沒有給出具體的受持白文。如今依律義擬定補加作白文句說：「大德一心念！我比丘某甲，此尼師壇應量作，現在受持。」說三遍。如果坐具破損而需要替換更換時，應當作法捨棄它。白文與受持法相同，只把結尾改說為：「現在捨棄。」即可。

【129-0005】資持記/13b_下一#51
【原文】若準《戒疏》，從石為正，即訓張也。足下，點非。佛一搩長二尺，二搩即四尺，廣搩半即三尺，是本制量。更增者，律因迦留陀夷身大，對佛說之，即聽廣長各增半搩。《戒疏》云：更增者，開緣也；還從本制，限外別開。〔謂從本制量限，外增之。
【譯文】如果依照《戒疏》，從「石」字旁的字才是正體，也就是訓讀為「張開」的意思。從「足」字以下，指出錯誤之處。佛陀的一搩手長二尺，兩搩手就是四尺，寬一搩手半就是三尺，這是原本規定的基本尺寸。所謂「更增」，是律典中因為迦留陀夷比丘身體龐大，當面向佛陀陳述，佛陀就聽許長與寬各增加半搩手。《戒疏》說：更增是屬於開許的特殊因緣；依然是依循本來的規定，在基本限度之外另外開許（意思是在本制尺寸限度之外，額外增加）。

【129-0007】資持記/13b_下一#53
【原文】欽跋羅，毛氈之類，麁厚故不可複。屈頭，謂轉尺頭也。縮量，謂不預桄張也。水洒，意令退縮也。《鼻柰耶》。亂謂參亂，即《四分》云，為壞色故。不揲則已；已，止也，謂揲不揲兩皆得耳。《四分》。疊兩重者，謂得過量者，襵而刺之。注意可見。三中，《十誦》。
【譯文】「欽跋羅」是指毛氈一類的東西，因為粗硬厚重所以不能重疊。「屈頭」是指轉動尺規的起點。「縮量」是指沒有預先拉伸張緊。「灑水」的用意是為了讓布料縮水。《鼻柰耶律》所說的「亂」是指參雜紊亂，也就是《四分律》所說的「為了破壞原本的好色」。如果不加綴補布也可以；「已」是停止的意思，是指加不加綴補布兩者都可以。《四分律》所說的「重疊兩層」，是指得到了超量過長的布料時，折疊起來縫刺固定。夾註的用意自然顯明。第三項中，《十誦律》規定：

【129-0008】資持記/13b_下一#54
【原文】不得單者，本為籍身，制必厚重。離宿吉者，一物常隨，離希非重。《伽論》。非佛制者，謂捨墮中無此戒故。不應但吉，亦不失受。四中，初科三段；《僧祇》明增量，初示增法。二三重者，並隨本物。對頭謂兩緣相鬪。下制限量，止得一尺。
