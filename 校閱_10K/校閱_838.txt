# 校閱材料　第838檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【記】八十九，略指中。制緣亦同上。緣起，毗舍佉母發願常供僧尼雨衣。「六群大作」者，謂以衣財令彼自作，不依量故。《戒本》亦四句，並同上分，長一丈二尺，廣五尺。

【838-0007】02_戒疏/20b_卷四下之二#17
【原文】【疏】《多論》：「佛身丈六，常人半之，故衣量皆半。難陀短佛無幾，故衣減之，長中一尺，短中四寸。」《僧祇》：「難陀，愛道所生，有三十相。」衣色與佛異。諸比丘衣色與佛同。六群見已，謂量亦同，遂便等作。
【譯文】【疏文】《薩婆多論》說：「佛身長一丈六尺，平常人只有佛的一半，所以衣服的尺寸也都減半。難陀比佛矮不了多少，所以他的衣量要減少：長度減一尺，幅寬（短邊）減四寸。」《僧祇律》說：「難陀是愛道所生，具有三十相。」他的衣色與佛不同，而諸比丘的衣色與佛相同。六群比丘看見了，以為尺寸也相同，於是便照著等量製作。

【838-0008】02_戒疏/20b_卷四下之二#18
【原文】【記】九十，制緣中。初《多論》。佛與常人身與衣量，並見後釋。難陀短佛四指，即是八寸，故云「無幾」，言不多也。衣長一丈七尺，廣一丈一尺六寸，一、身不勝，二、不僭聖。《僧祇》，難陀少佛二相，無見頂、千輻輪，唯佛有之。「衣色與佛異」者，佛制難陀著黑色衣，餘諸比丘無濫佛義，故「與佛同」。六群不知量別，便等量作，以為發起。
【譯文】【記文】第九十戒，在制戒因緣中。首先引用《薩婆多論》。佛陀與常人的身長以及衣物尺寸，都會在後文解釋。難陀比佛矮了四指，也就是八寸，所以說「無幾」，表示短少不多。衣長一丈七尺，寬一丈一尺六寸，一是因為自身無法勝任過大之衣，二是不敢僭越聖人。《僧祇律》說，難陀比佛缺少二相，沒有無見頂相與千輻輪相，這兩相唯獨佛才具足。「衣服顏色與佛不同」是因為佛陀規定難陀穿著黑色衣，其餘比丘並無混淆佛陀相好之虞，所以「與佛相同」。六群比丘不知道尺寸有別，便等量仿製，以此作為發起本戒的因緣。

【838-0009】02_戒疏/20b_卷四下之二#19
【原文】【註】佛在釋翅瘦。難陀短佛四指，比丘遙見，謂佛奉迎，至乃知非，各懷慚愧。佛制難陀著黑衣。六群與佛等量或過量作，比丘舉過，佛因制戒。
【譯文】【註文】佛在釋翅瘦。難陀比佛矮四指，比丘們遠遠看見，以為是佛來了，便上前迎接，走到近前才知道不是，各人心懷慚愧。佛因此規定難陀穿黑衣。六群比丘卻做與佛等量或超過佛量的衣服，比丘們舉發他們的過失，佛於是制定這條戒。

【838-0011】02_戒疏/20b_卷四下之二#21

【838-0015】02_戒疏/20b_卷四下之二#25
【原文】【疏】問：「餘之三戒，依佛搩手，定出量限。『三衣』一戒，但隨己身，不定出量者？」
【譯文】【疏文】問：「其餘三條戒，都依佛的搩手（磔手）明確訂出尺寸限度；唯獨『三衣』這一條戒，只隨著自己的身材，不固定訂出尺寸，這是為什麼？」

【838-0016】02_戒疏/20b_卷四下之二#26
【原文】【疏】答：「餘非沙門道服外儀，隨其大小，皆得受用，故有定量。此三法衣，道服標式，若定出量，人有長短，不稱威儀，外不生善，內無軌物，故隨身分，不定出量。由不定故，得有與佛等、過作衣。」
【譯文】【疏文】答：「其餘幾種（覆瘡衣、雨衣、尼師壇）並不是沙門道服的外在儀表，隨著各人身材大小，都可以受用，所以有固定的尺寸。這三種法衣是道服的標誌樣式，如果固定訂出尺寸，人的身材有長有短，穿起來不合威儀，對外不能令人生善，對內也沒有軌範的作用，所以隨著各人的身材分際，不固定尺寸。正因為不固定，才會有與佛衣等量、或超過佛衣尺寸而製作的情形。」

【838-0017】02_戒疏/20b_卷四下之二#27
【原文】【記】問答中，初問。三戒並就比丘制量，此戒但制與佛等過，則比丘衣不出定量。答中，初示餘三定量。「此」下，次明法衣不定。「外不生善」，謂俗容生慢；「內無軌物」，謂令道無取則。「由」下，示後戒元因。若有定制，不容等佛。
【譯文】【記文】問答中，首先提問。其他三戒都是針對比丘身量來制定尺寸，唯獨此戒只限制不可與佛相等或超過，那麼比丘自己的三衣便沒有定出具體極限。回答中，先指明其餘三戒有定量的原因。「此」以下，接著說明法衣尺寸不定的緣由。「對外不生善」是說世俗之人見之容易生起慢心；「對內無軌物」是說使修道者失去標準法則。「由」字以下，指出引發此戒的根本原因。如果有固定限制，就不可能發生等同佛衣之事。

【838-0020】02_戒疏/20b_卷四下之二#30
【原文】【記】私釋：佛衣等戒，即是比丘三衣定制，已內皆通，等過不得，豈非定制？所以標云「過量三衣戒」也。
【譯文】【記文】私下解釋：與佛衣等量戒，實質上就是比丘三衣的極限規範，在佛衣尺寸以內都可通融，若是等同或超過便不可以，這難道不也是一種定制？所以科題標為「過量三衣戒」。
