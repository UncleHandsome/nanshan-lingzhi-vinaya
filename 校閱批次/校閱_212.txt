# 校閱材料　第212檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第二違損者大品經云我若不持戒當墮三惡道中尚不得下賤人身況得成就眾生淨佛國土一切種智薩遮尼犍經云若不持戒乃至不得疥癩野干身何況當得功德之身梵網經云若佛子信心出家受佛淨戒故起心毀犯其戒者不得受一切檀越供養亦不得國王地上行不得飲國王水五千大鬼常遮其前鬼言大賊入房舍城邑宅中鬼復掃其脚跡一切世人罵言佛法中賊一切眾生眼不欲見犯戒人畜生無異木頭無別涅槃經云樂好衣服縱逸嬉戲奴為比丘婢為比丘尼不樂不淨觀毀謗毗尼互用三寶物等是名法滅盡相佛三昧經云犯四重禁虗受信施過殺八萬四千父母等罪此律云有五種疾滅正法一有比丘不誦律喜忘文句復教他人文既不具其義有闕二為僧中勝人上座一國所宗而多不持戒但修不善後生倣習放捨戒行三有比丘持法持律持摩夷不教道俗便即命終令法斷絕四比丘難可教授不受善語餘善比丘捨置五共相罵詈互求長短疾滅正法又破戒之人有五過失一自害二為智者所訶三惡名流布四命終生悔五死墮惡道又上座不學戒亦不讚歎戒有餘比丘樂學戒者不能以時勸讚我見如是上座過失故不讚歎恐餘人習傚長夜受苦十誦云有諸比丘廢學毗尼便讀修多羅阿毗曇世尊種種訶責五分律諸比丘不誦羯磨不得受具足戒善見云若不解律但解經論不得度沙彌作依止師。
【譯文】第二部分、違背犯戒的損害：《大品般若經》說：我如果不持守戒律，將會墮入地獄、餓鬼、畜生三惡道中，連下賤的人身都得不到，更何況是教化成就眾生、清淨佛國淨土以及證得一切種智？《薩遮尼犍子經》說：如果不持守戒律，乃至連生長疥癬癩病的野干（狐狼類）之身都得不到，何況能夠證得具足功德的聖者之身？《梵網經》說：佛子若是出於信心而出家，受持了佛陀的清淨戒律，卻故意生起惡念毀犯戒律，就不得接受任何施主的供養，也不能在國王的土地上行走，不能飲用國王領地內的水；常有五千大鬼擋在他的面前，鬼魅呼喊他是『大賊』，當他進入房屋、市鎮、聚落之中時，鬼魅還會掃去他的腳印；世間所有的人都唾罵他是佛法中的盜賊，一切眾生連看都不想看到他，犯戒的人與畜生沒有兩樣，與枯木沒有分別。《涅槃經》說：貪戀美好的衣物，放縱享樂嬉戲，奴隸出家作比丘，婢女出家作比丘尼，不喜愛修習不淨觀，毀謗毗尼戒律，相互挪用侵佔常住三寶財物等，這就稱為正法滅盡的徵兆。《佛三昧經》說：犯了波羅夷四重戒而虛妄受納信徒施捨，其罪過超過殺害八萬四千父母的重罪。本部《四分律》說：有五種因緣會迅速毀滅正法：一是有的比丘不背誦戒律，容易遺忘文句，卻又去教授他人，文句既然殘缺不全，義理也就隨之虧缺；二是身為僧團中的尊長上座、為舉國上下所尊崇敬仰，自己大多不持守戒律，只造作不良行為，後輩學人紛紛起而仿效，從而廢棄捨離了戒行；三是有比丘受持經法、受持律藏、受持論藏，卻不傳授教化出家與在家大眾，不久便壽終離世，使得教法斷絕不傳；四是比丘頑劣難以教導，不肯接受善意勸導，其餘善良的比丘便對其放任置之不理；五是僧眾相互謾罵詆毀，彼此挑剔刺探長短過失，這些都會迅速滅絕正法。此外，破毀戒律的人有五種嚴重過失：一是自害己身；二是受到智者的喝斥譴責；三是惡名遠播四方；四是臨命終時生起無盡懊悔；五是死後墮入惡道之中。另外，如果上座自己不修學戒律，也不讚歎戒律，有其餘比丘樂意修學戒律時，上座又不能及時給予勉勵與讚許；我看見這樣的上座有如此過失，所以絕不給予稱讚，深怕其他人跟著模仿學習，在漫長黑夜的生死輪迴中承受無量痛苦。《十誦律》說：有的比丘荒廢修習毗尼，只去研讀經藏與阿毗達磨論藏，世尊對此給予了種種嚴厲訶責。《五分律》說：比丘若不能背誦僧團羯磨作法，就不得為人授具足戒。《善見律》說：如果不懂得戒律，只懂得經藏與論藏，就不得剃度沙彌，也不得擔任依止師。

【原文】問曰諸經律中或名尸羅或名戒或名毗尼或名律或名波羅提木叉或名解脫既有多種云何取別耶答曰若廢名談體體即是一總不出戒戒是防非止惡為義所以諸名竝欲防非齊兼止惡故攝別歸總莫過於戒故經云戒定慧也此據三學行法以立總也若廢體談名名則有別言毗尼者謂西梵正音此翻為滅然滅非毗尼謂能滅諸過故名滅此從功行以立其名言律者法也法有楷模能詮輕重疏染淨故名為法就能詮之教以立其名此上二種竝從能治行以立名也此下尸羅及與木叉皆從所詮之行以立其名言尸羅者智論云秦言性善謂體是善非惡無記亦名為戒戒有防非之功亦有善因之義此從善因以立名言波羅提木叉者此云處處解脫謂身口七支非一名為處處果名為解脫隨分得脫即是果義此從果善以立名雖因果竝論然防非中要生善義強故以戒攝別用為宗極由有戒故久助資成便招世間出世間多種樂果故名戒也若欲互攝隨以何名皆有互攝之義如戒是防非止惡即是滅惡義戒有楷模能詮輕重即是法義法義既成便是性善性善既成便為因義因義招生即攝果義餘名互起亦皆如此上明因果二名復有受隨兩義言受戒者謂創發要期納法在心名之為受有懸防之能又名為戒二隨戒者謂持心後起義順於前名之為隨隨有防非之功亦名為戒隨有兩種一是精持不犯二犯已能悔若對精持不犯便具止作二持若對犯已能悔即辨止作二犯所言止持者如受戒已止不作惡即名為持持由止生故名止持言作持者謂動身口戒意離非順本所受不犯前過號之為持持由作生故名作持言止犯者謂止不修善違本所受名之為犯犯由止成故名止犯此則止犯翻前作持也言作犯者謂動身口造作前非違本要期名之為犯犯由作成故名作犯翻前止持也故二持翻兩犯二犯翻二持逆順不相妨善惡體相違。
【譯文】有人問：在各部經藏與律藏之中，或者稱作尸羅，或者稱作戒，或者稱作毗尼，或者稱作律，或者稱作波羅提木叉，或者稱作解脫，既然有這麼多種稱呼，究竟該如何辨析它們的區別呢？回答說：如果拋開名相只談論實質本體，本體其實是同一的，總歸都不出於「戒」的範疇。戒的含義就是防範過非、止息惡行。所以所有這些名稱，全都是為了防非，共同兼具止惡的功能，因此化零為整、統攝個別名相歸於總體，沒有比「戒」更貼切的了。所以經中說有戒、定、慧三學，這是依據三學修行法門而立下的總稱。如果拋開一體而專論各個名相，名稱之間則各有不同。所謂「毗尼」，是西域梵文的正確發音，漢語翻譯為「滅」；然而滅並非毗尼的字面直譯，而是指它能滅除種種過患，所以稱為滅，這是從滅惡的功用修行來立名的。所謂「律」，就是法度規範；法度具有準則楷模的功能，能詮釋罪責的輕重，區分染汙與清淨，所以稱為法；這是就律法能詮釋教理的教文層面來立名的。上面這兩種名稱，都是依循能對治惡行的法義來建立名稱。以下所說的「尸羅」與「木叉」，則是依據所詮顯的修行實踐來立名。所謂「尸羅」，《大智度論》說秦地語言稱為「性善」，意思是其本質是善法，而非惡性或無記性，也通稱為戒；戒既具有防範過錯的功效，也蘊含著成就善業的因種意義，這是從善因的角度來立名。所謂「波羅提木叉」，漢語翻譯為「處處解脫」，意思是身業與口業的七種支分過患各有不同，稱為處處；證得解脫的善果，稱為解脫；隨順持守相應的戒條就能分分獲得解脫，這就是果報的意義，這是從果德善法的角度來立名。雖然因與果同時討論，但是在防非止惡的過程中，引生善法的功能更為強烈，所以用「戒」來統攝所有名目，作為最根本的宗要；由於有了戒法，長久資助長養善根，便能招感世間與出世間的多種安樂善果，所以稱為戒。如果要相互統攝，無論依隨哪一個名稱，都具有彼此圓融統攝的含義：例如「戒」能防非止惡，這本身就是「滅」（毗尼）惡的含義；戒具有法度規範、能衡量輕重，這就是「法」（律）的含義；法的體質既然確立，本性就是善良的（尸羅性善）；性善既然確立，就具備了成聖的「善因」意義；善因既然能招引善果，自然就統攝了「解脫」（木叉）的果位意義；其餘名稱的相互引發涵蓋，也全都是這個道理。以上說明了因果這兩個層面的名稱，此外還含有「受戒」與「隨戒」兩種意義：所謂「受戒」，是指最初發起誓願期許，將清淨戒法領納於心中，稱之為受；因為具有防患未然的功能，所以稱為戒。第二、所謂「隨戒」，是指受戒之後所生起的心念行持，在義理上隨順遵從當初的誓願，稱之為隨；隨順持守同樣具有防非止惡的功德，所以也稱為戒。隨戒又包含兩種行持：一是精進持守而絕不違犯，二是萬一毀犯了能立刻如法懺悔。如果對應於精進持守不犯，就具備了「止持」與「作持」兩種持戒相貌；如果對應於毀犯之後能懺悔，就能辨析出「止犯」與「作犯」兩種犯戒相貌。所謂「止持」，是指受戒之後，止息惡念而不造作惡業，這就稱為持；持戒的功德由止惡而產生，所以稱為止持。所謂「作持」，是指運用身業與口業，戒慎心意遠離過非，順應當初所受的戒律而不違犯先前的規約，號稱為持；持戒的功德由實踐造作善法而產生，所以稱為作持。所謂「止犯」，是指終止懈怠而不修習善法，違背了當初所受的誓願，稱之為犯；犯戒的過失由停止作善而構成，所以稱為止犯，這正是止犯反轉了前述的作持。所謂「作犯」，是指妄動身業口業，去造作原先所禁止的非分惡行，違背了最初的戒誓期許，稱之為犯；犯戒的過失由造作惡事而構成，所以稱為作犯，這正是作犯反轉了前述的止持。因此，兩種持戒正好翻轉兩種犯戒，兩種犯戒也正好翻轉兩種持戒；在理路上逆與順各自成立而不互相混淆，而善業與惡業的體質則是徹底截然對立的。
