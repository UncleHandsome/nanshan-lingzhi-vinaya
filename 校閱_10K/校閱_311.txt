# 校閱材料　第311檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【311-0001】02_戒疏/01b_卷一上之一#76
【原文】【記】顯今中。初科為三，初標舉。「如」下，列示五義。初「性善」者，離諸染惡法故，《論》自釋云「好行善道，不自放逸。」「如心」下，即次義。「別解脫」者，隨境清淨故，此出「《心論》」；「學調諸根」者，對塵抑制故，此出「《善生》」。二釋並據所治，故云從「心」。「如諸」下，是第三。指「諸論」者，《成》、《多》、《俱》、《雜》，非出一文，故通指之。
【譯文】【記文】在顯發本疏正義的段落中。第一科分為三部分，起初標明列舉。從「如」以下，列出並展示五種義理。初「性善」者，是因為遠離了一切染污惡法的緣故，《大智度論》自己解釋說「樂於奉行善道，不自放逸懈怠」。從「如心」以下，即是第二種義理。所謂「別解脫」，指的是隨順所面對的境界而得清淨，此語出自《阿毗曇心論》；所謂「學調諸根」，指的是面對外在塵境能夠加以抑制，此語出自《善生經》。這兩種解釋都是依據所對治的心地來立論，所以說從「心」立論。從「如諸」以下，是第三種義理。所指的「諸論」，包含《成實論》、《薩婆多論》、《俱舍論》、《雜阿毗曇心論》，並非出自單一論典，所以統括稱呼。

【311-0002】02_戒疏/01b_卷一上之一#77
【原文】【記】問：「『業』與『體』何別？」
【譯文】【記文】有人問：「『業』與『體』有何差別？」

【311-0003】02_戒疏/01b_卷一上之一#78
【原文】【記】答：「『體』取戒法，『業』據受體。」
【譯文】【記文】回答道：「『體』著重在普遍的戒法自體，『業』著重在受戒當下行者所得的受體。」

【311-0004】02_戒疏/01b_卷一上之一#79
【原文】【記】「若爾，《鈔》中何以指『作』、『無作』為體者？」
【譯文】【記文】「如果是這樣，《行事鈔》中為何把『作』與『無作』直接指為戒體呢？」

【311-0005】02_戒疏/01b_卷一上之一#80
【原文】【記】答：「彼約受體，與今『業』同，故不相違。」
【譯文】【記文】回答道：「那也是從領納受體的角度來談，與此處的『業』是同一個概念，所以並不相互違背。」

【311-0006】02_戒疏/01b_卷一上之一#81
【原文】【記】「或名」下，即第四，亦《善生》文。遮煩惱熱，故名「清涼」；性不容惡，故名「迮隘」；能上天堂，至無上道，故云「上」：此三皆喻。「能」即功能。「或云」下，未詳何出，疑是《善生》，連上文故，不復別標。「以戒自觀」，即指《戒經》，用撿三業。此約戒本，故言「就教」。「諸」下，結顯，指上五義，皆偏舉耳。
【譯文】【記文】從「或名」以下，即是第四種義理，也是出自《善生經》之文。能遮蔽止息煩惱熱惱，所以名為「清涼」；戒性純淨容不得絲毫惡事，所以名為「迮隘」；能令人超生天界乃至抵達無上菩提，所以稱為「上」：這三者全都是譬喻。「能」就是指功能效益。從「或云」以下，尚不清楚確切出自何經，懷疑也是出自《善生經》，因為緊接著上文而來，所以不再另外標明出處。「以戒自觀」，指的就是依據《戒經》條文，用來檢驗審查自己的身口意三業。這是依據戒本文字而言，所以說是「就教說」。從「諸」以下，總結顯發，指出上述五種定義，全都只是偏取善法一邊而立論罷了。

【311-0007】02_戒疏/01b_卷一上之一#82
【原文】【疏】依如《成實》、《善生》所明善惡二戒，互受互亡，功用齊倫，名義無別。止得通解，戒為「禁」也，隨用兩得。何以知之？若解善戒，善法禁惡，警持不起。若解惡戒，惡法禁善，護攝不生。以斯義求，想無惑矣。
【譯文】【疏文】如果依照《成實論》與《善生經》所闡明的善戒與惡戒二者，受了善戒則惡戒消亡，受了惡戒則善戒消亡，兩者的防範功用平起平坐，名義上沒有實質差別。那麼就只能從通貫的義理來解釋，將「戒」定義為「禁制」，這樣無論放在善或惡的語境下都能講得通。憑什麼知道是這樣呢？如果解釋為善戒，那就是以善法禁絕惡行，警惕把持自己不使惡念生起；如果解釋為惡戒，那就是以惡法禁絕善行，護持攝防自己不讓善心萌生。依循這樣的義理來推求，想必就不會有疑惑了。

【311-0008】02_戒疏/01b_卷一上之一#83
【原文】【記】次兩通中。初引示義同。「止」下，顯今正解。「何」下，徵釋通相。然文約善惡互禁釋之。今是善戒，禁斷諸惡，故前經論多從善義。如上訓警，亦據善邊。今從「禁」義，釋戒彌親，故《經》云「如來立禁戒」，斯可證矣。
【譯文】【記文】在兼通善惡二戒的段落中。起初引經證說明兩者的功用義理相同。從「止」以下，顯發本疏如今確立的正解。從「何」以下，詰問並解釋貫通兩者的相狀。這段文字是就善惡相互禁制的角度來作解釋的。然而如今我們所學的是善戒，目的在於禁絕斬斷種種惡行，所以前面各部經論大多依從善法的一邊來界定。正如前面將戒訓詁為警惕，也是站在善戒的立場而言。如今從「禁絕約束」的通義來解釋戒，比以往的定義更為親切切題，所以《經》中說「如來確立禁戒」，這就可以作為有力的明證了。

【譯文】【記文】在解釋「木叉」的段落中，此為翻譯名號。文義顯明易懂。或者有人翻譯為「別別解脫」，或者翻譯為「處處解脫」。

【311-0011】02_戒疏/01b_卷一上之一#86
【原文】【疏】如論所引，道戒名「解脫」也，事戒名「別脫」也。
【譯文】【疏文】如同論典所引述的，與聖道相應的心體之戒稱為「解脫」，依憑事相所受持的戒條稱為「別解脫」。

【311-0012】02_戒疏/01b_卷一上之一#87
【原文】【疏】隨分果得，寄以明之。以道性虗通，舉法類遣，不隨緣別，但名解脫。
【譯文】【疏文】這是隨著所證得的部分果位，寄託其位次來加以說明的。因為空道聖性虛融通達，一發動真觀之法就能類推遣除一切煩惱，不隨著外在特定境緣而有差別，所以單純稱為「解脫」。

【311-0013】02_戒疏/01b_卷一上之一#88
【原文】【疏】事戒不爾，緣別而生。緣通萬境，行亦隨徧，持行陵犯，則名得脫。餘非未行，不名解脫。
【譯文】【疏文】依憑事相所受的戒律則不是這樣，它是伴隨著個別境緣而生起的。外在境緣通於世間萬物，戒行也就隨著萬物而遍布，行者持守某條戒行戰勝了該項犯戒之境，就稱為在那一事相上獲得解脫。至於其餘未曾針對行持的惡行，就不能稱之為解脫。
