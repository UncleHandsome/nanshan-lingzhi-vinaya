整體讀來通順，專業術語（聽＝允許、差＝病癒、伎倆、反切「施亦反」＝釋、非／畜＝非人與畜生）都處理得不錯。以下按「意思偏離 → 用語可調 → 體例」分層列出問題，附建議改法。

---

## 一、意思偏離，建議修正

### 1. 「定／不定」是「心決定」，不是「佔有穩定」（0001、0002、0003）
《記》0005 明說：「**次句以賊心猶豫，盜業未成**，故云『緣不具』」——可知「賊主（不）定」指**賊心是否已決定認定為己物**，「財主（不）定」指財主心意（捨／不捨）是否已決。譯文把它落到「佔有穩定／不穩定」的事相上，偏了：

- 0001「盜賊的佔有尚未穩定」→「盜賊心中仍猶豫未定」
- 0002「盜賊的佔有已經穩定」→「盜賊心中已決定（認定為己物）」
- 0003「兩方都還不穩定」→「財主與賊主雙方心意都還未決定」（後半句已譯對，前後應一致）

另外兩處：
- 0002「心中還在**遲疑不捨**」：原文只作「遲疑」，補「不捨」反而與「不定」相矛盾（不捨已決即是「定」）。宜作「還在遲疑（未決定是否捨棄）」。
- 0001「**斷絕追討之心**雖然已經確定」：這是推測性補義，原文無「追討」字樣。建議保守作「財主（捨棄、不再期望收回）的心意雖已決定」，或加括注說明所據。

### 2. 「緣成」應指「盜業之緣」（0002）
「因為**盜賊奪得的因緣**已經成立」語意含混，且與 0001「盜取的各項要素」、0005「盜竊罪業尚未圓滿」不一致。宜統一為：「因為**盜業（盜罪）的因緣已經成就**」。
「何問本主」可稍補足：「何必再問本主（心意如何）呢？」

### 3. 「現前盜」不宜譯為「搶奪」（0005）
原文「對面現前**盜**及不現前**盜**」，兩者都是「盜」，只分當面／不當面。譯成「當面現前**搶奪**」會與律中「劫／強盜」混濫。建議：「當面（對面）現前的偷盜，以及不現前（暗中）的偷盜」。

### 4. 「例通」＝舉例類推貫通，不是「通達之理」（0007、0008）
- 0008「舉出世間的事例來**說明通達之理**」→「舉世間錢幣為例，**以類推貫通（其餘情形）**」。
- 0007「可以依此理類推**通達**」→「可以此例類推而通於一切（其他情況）」。

### 5. 「胸行」不可寫成「腹行」（0013 與 0014 自相矛盾）
0014 已依論作「治**胸行**蛇毒之藥師」，0013 卻寫「精通咒治**腹行**蛇毒的『胸行師』」。且未交代「胸行」即蛇（蛇以胸腹貼地而行）。
建議 0013：「例如有些仙人是『胸行師』（即治蛇毒的藥師；『胸行』指蛇）」。又「**咒**治」是添義，《記》只作「藥師」，可逕作「治蛇毒」。

### 6. 「有呪扇藥塗」的斷句與前提（0015）
可讀為「有**咒扇、藥塗**（兩種治病法）」，也可如譯文讀為「塗有咒藥之扇」一事；下文只云「偷搖」，取一物之解可通，但宜加注另一讀法。
更重要的是：此段省略了「**扇病能癒、須付價值**」的前提，譯文直接說「不肯支付費用」，讀者不知所付何費。建議補：「有人以咒加持扇子（塗藥）為人治病，須付費；比丘暗中偷搖此扇，不付價值，這就叫『盜風』。」

## 二、用語／詮釋可再收斂

| 條號 | 現譯 | 建議 |
|---|---|---|
| 0004 | 「這四句**準則**」 | 「四句」是四種情況的分別（四句分別），非準則 →「現在就用這四句（四種情況）加以判定」 |
| 0005 | 「在分析四句的**文理**中」 | 科判語 →「第二科，是逐句（歷句）分別」；「文理」為添字 |
| 0009 | 「**這就像**《行事鈔》所引《明了論》中的解釋」 | 此處是「依照／如下所引」，下句「故又引之」正說要再引一次 →「如《行事鈔》所引《明了論》的解釋（如下）」 |
| 0010 | 「是**標示文義**」 | 「標文」為科判用語（對下「釋中」）→「第三科中，（先是）總標之文」 |
| 0011 | 「盜竊的**定義與內涵**極為廣泛」 | 下記云「盜境該通無窮」，重點在種類 →「盜的情形（義類）極多」 |
| 0011 | 「偷盜了**外在的**六大」 | 六大含「識」，非全屬外在 → 刪「外在的」，或作「六大（地水火風空識）」 |
| 0012 | 「所盜取的**境象**」「被盜取的**境界**」 | 律家「境」＝對象 → 統一作「所盜的對象」 |
| 0013 | 「看時即**犯戒**」 | 宜作「即犯（盜罪）」，與下文「犯重」相應 |
| 0013 | 「損失何止達到五錢？」 | 「何啻在五」＝何止五錢 →「（其價值）何止五錢呢（故犯重）」 |
| 0015 | 「比丘**用盡心機**」 | 「方便」＝以種種手段，語氣不宜過重 →「比丘以種種方便（手段），向他學得」 |
| 0015 | 「妨礙了別人在**其空間**建造」 | 「其」指誰不清 →「妨礙他人（在自己地上）建造」 |
| 0003 | 「罪業尚未**圓滿通暢**」 | 可保留，但「通暢」是律家「業道通暢」術語，宜略注「（盜業尚未成就）」 |
| 0016 | 「前後各自標示」 | 可補足：「（六大與六界）體同名異，疏文前後分別標舉（前云六大，後云六界）」 |

另 0007「隨人隨用，隨處隨定，隨損隨結」為三組對句，譯文散文化後「隨處隨定」的「定＝定屬誰」靠補語帶出，尚可；若想更貼原文可作：「隨人、隨用而轉移，隨處而定其所属，隨（誰）受損而（向誰）結罪」。

## 三、體例一致性（多條）

**句號應在引號外**：0013「胸行師。」「眼根偷盜。」、0015「盜風。」「盜空。」「盜識。」→ 應作「胸行師」。／「盜風」。等。

## 四、判讀無誤、可保留者

- 0006「賊施得取物不」補「比丘」合理。
- 0007「據理成也」判為「可以收取」，與下文「物非定屬，隨後作主」及《記》「恐疑共盜」的問意相合，正確。
- 0013「得直**聽**寫」譯「才准許抄寫」、「病緣即**差**」譯「病癒」、0014「螫，施亦反」譯「音釋」、0015「不空**度**他」譯「不肯平白傳授」——這幾處關鍵訓詁都對。
- 0017「非、畜物」、0018「可尋《鈔》中罪輕重」無問題。
- 0013 末「心緣得差」譯為「意根攀緣此方術而病得癒」，屬可通之解（另一讀法為「為他治病得癒」），建議加一注記標明取捨即可。

**最需優先處理的是第一項（定／不定＝心定）與第五項（胸行／腹行）**，前者關係四句判義，後者是明顯的前後矛盾。
