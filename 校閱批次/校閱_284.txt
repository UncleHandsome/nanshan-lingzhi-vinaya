# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【284-0001】資持記/15d_下三#41
【原文】四中。說已入禪；大聖垂則，嚴勗後來。儒中，君子言之不出，恥躬不逮；又云：先行其言，而後從之。況佛法修真，言行相反。深嗟彼徒，那無慚色。五中。引佛說法，取悟為先；隨宜權巧，令後學之。初為樂總好略之機，攝多為一說。行即觀行，法即法門。
【譯文】第四段中，佛陀說法完畢隨即進入禪定；這是大聖世尊親自樹立的典範準則，嚴格策勉告誡後世修行人。儒家也說過：「君子言之不出，恥躬不逮（君子唯恐言論輕易出口，以自身行持跟不上為恥辱）」；又說：「先行其言，而後從之（先實踐自己要說的話，然後再說出來）」。世間法尚且如此，何況佛法修持真實真理，如果言論與行持背道而馳，實在令人深感悲嘆惋惜，那幫狂徒難道就沒有一點慚愧之色嗎？第五段中，引用佛陀隨機說法，以引導眾生開悟為首要原則；隨順機宜運用權巧方便，令後世學人依此效法。最初針對樂好總括、喜愛簡要的根機，將繁多的法門收攝為一種來宣說。「行」是指觀行修持，「法」是指化導法門。

【284-0002】資持記/15d_下三#42
【原文】乃至下，次對樂別好廣之機，開一為多說。或二或三，乃至八萬。若據經云：無量無數方便，亦何止上數；言八萬者，真諦云：佛始成道，終至涅槃；經三百五十度說法，一一皆具六波羅蜜，成二千一百；一一皆配四大、小塵、十法，成二萬一千；又配三毒等分，成八萬四千；今舉大數，但云八萬耳。
【譯文】「乃至下」接著針對樂好分別、喜愛廣博的根機，將單一法門開展為多種來宣說。或分成兩種，或分成三種，乃至開展為八萬法門。若依照經典所言：「有無量無數的權巧方便」，所開顯的法門又哪裡只局限於上述的數字；之所以稱為「八萬」，真諦三藏解釋說：佛陀從最初成道，一直到最後入涅槃；一生歷經三百五十次大型宣揚說法，每一次說法都圓滿具足六波羅蜜，乘積成為二千一百法門；每一種法門再配以地水火風四大、微細色塵、以及十善等法，乘積成為二萬一千法門；接著再配對貪瞋癡三毒及各自分量，最終化成八萬四千法門；此處僅舉整數大數，所以統稱「八萬」而已。

【284-0003】01_行事鈔/11c_卷下之三#8
【原文】《十誦》：說法人者，應一心說，生慈愍心、利益心，莊嚴語言、次第相續，辯才無盡，隨順諸法實相；為法故說，不為利養。此中上座，應觀察所說；若不如法說，應呵止。又聽取佛經義，莊嚴言辭，次第解說；其佛經本，當直讀誦，莫雜論議。《五分》：白衣說法，歡喜布施者，聽之。《十誦》：說法呪願讚法時，不得食。
【譯文】《十誦律》說：說法的人，應當一心專注宣說，生起慈愍心、利益眾生心，文飾莊嚴語言、講述井然有序連貫相續，具備無盡的辯才，隨順諸法的實相；應純粹為了正法而說，不可為了利養而說。在場的上座比丘，應當審視觀察說法者所說的內容；如果說法不如法，應當及時呵責終止。此外，准許採取佛經的深義，修飾莊嚴言辭，依序逐層解說；但若是佛經的本文，應當直接讀誦，不要夾雜世俗的雜論辯議。《五分律》說：在家的白衣說法，能令大眾心生歡喜而行布施的，准許其說法。《十誦律》說：在說法、祝願、讚頌佛法時，不得進食。

【284-0004】03_業疏/19b_卷四之二#61
【原文】若爾，何故不知不脫者？答：若語自行，不以不智，隨犯依治也。若據眾法，謂不犯得聞說戒，無違心故；不犯謂犯，不得聞戒，心不淨故。又據自行，實犯謂無、不犯謂有，俱須兩識，不可任情。前言不得強逼者，恐發諍競，故且任之。不同殘中忘謂無覆，雖逼無諍，故戒文中強與覆法。
【譯文】問：既然如此，為什麼又說不知罪就不能脫罪呢？答：如果就個人自修的行持而言，不能因為不知犯戒而免咎，隨其所犯依律治罪。如果依據僧眾大眾法來說，自認為沒犯的人得以聽聞說戒，因為其內心沒有相違背之故；本未犯卻自以為犯的人，則不得聽聞說戒，因為自心不淨之故。再者依據個人自修，確實犯了卻自認未犯、未犯卻自認犯了，這兩種情況都必須辨明了知，不可聽任私情妄執。前面所說的不得強行逼迫，是唯恐引發諍端爭執，所以暫且由他；這不同於僧殘罪中遺忘而自認未覆藏的情形，那時即便逼問也不會引起諍訟，所以戒文中強制給予覆藏治罪之法。

【284-0005】03_業疏/19b_卷四之二#62
【原文】次問意謂既許聞戒，罪何不脫？答中有二：初約眾自二行對明：自行據體，有犯隨治；眾行取和，不疑許聽，無犯疑有，約心不開。又下次單就自行以辨，實犯謂無，理須舉悔；不犯謂有，義不妄施。前下決上律文，且為護眾，仍簡僧殘次死須救，故逼無諍也
【譯文】接著提問，意在指出既然准許聽聞說戒，罪過為何不能脫免？答文中分為兩層：首先約大眾行與個人自行相對辨明：自行依據戒體，有犯就隨律治罪；大眾行取僧團和合，自無疑惑者准許聽戒，本無犯而起疑為有犯者，依其心態不予開許。自「又」以下，單就個人自行來辨析：確實犯了卻自認未犯，理應舉發懺悔；未犯卻自認有犯，義理上不可隨便施予治罰。自「前」以下決斷前引律文之意，暫時不逼是為了護持僧眾和合，進一步簡別僧殘罪是僅次於四棄之重罪，必須救治，因此縱使逼問也不會有諍訟。
