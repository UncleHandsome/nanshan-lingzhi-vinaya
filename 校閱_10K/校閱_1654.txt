# 校閱材料　第1654檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1654-0001】03_業疏/07a_卷二之一#74
【原文】今解此文不許接者，恐兩界相通，但得有隔，何論大小？如前二繩，繩即體也。可以情通，云山石者，亦恐相涉耳，須得意也
【譯文】如今解釋此文：律中不允許兩界相接，是恐怕兩界界相發生混淆相通；只要中間有所隔開即可，何必拘泥於大小？如同前面提到的「二繩相」，繩索本身就是界體。從情理上可以相通，論中之所以提及大山巨石，也是恐怕兩界互相混淆牽涉罷了，對此必須領會其深意。

【1654-0002】03_業疏/07a_卷二之一#75
【原文】今解中初通《十誦》。「如」下次釋《了論》，彼尚用繩為標，則知山石未必須大
【譯文】在「如今解釋」中，首先融通《十誦律》之意。「如前」以下，其次解釋《明了論》，論中尚且可以使用繩索作為界標，由此便可知山石未必一定要多麼巨大。

【1654-0003】03_業疏/07a_卷二之一#76
【原文】四、唱方相
【譯文】第四門「宣唱四方界相」。

【1654-0004】03_業疏/07a_卷二之一#77
【原文】律使舊住者唱，諳練方隅，有所分次。雖是舊住，未了前緣，不妨新客，深閑內外，依標而唱，義當舊者。律制堪能，豈局客主？竝識標體及相，三種通別
【譯文】戒律規定應當差遣常住舊住的僧人宣唱，因為他們熟悉四方方位，劃分有其次第。然而即使是舊住僧人，若不明了先前的立界因緣，亦不妨由新來的客僧，只要他深入熟悉界內界外之相，依照界標予以宣唱，在義理上就等同於舊住者。律中所制定的核心在於「有堪能者」，豈會拘泥於客僧還是主僧？關鍵在於必須辨識界標、界體與界相，以及這三種概念的相通與區別。

【1654-0005】03_業疏/07a_卷二之一#78
【原文】第四唱相簡人中，初通律意。「雖」下次約義決，當猶同也。律文凡作羯磨，皆云「眾中堪能者作」，故可取證。「竝」下示堪能之相。標即體為通，標異體即別
【譯文】在第四門「宣唱界相揀擇人員」中，首先通達律文的原意。「雖是」以下，其次依照義理加以決斷，判定新客僧若熟悉情況則等同於舊住者。律文中凡是作羯磨，都說「僧眾中有堪能者作」，因此可以作為明證。「竝識」以下，指明具備堪能的具體相貌：界標即是界體稱為「通」，界標不同於界體則稱為「別」。

【1654-0006】03_業疏/07a_卷二之一#79
【原文】五分》中使一比丘唱四方界相，又唱除內地為安戒場故，須除也。今時結者，內外兩相，前後別唱，所除之外相是空地，事最顯也。至文更述
【譯文】《五分律》中差使一名比丘宣唱四方界相，並且宣唱排除內部土地，這是為了安置戒場的緣故，所以必須予以排除。現今我們結界時，內相與外相前後分別宣唱，所排除的戒場之外相本身就是空地，事相最為清楚顯明。到後文時還會進一步闡述。

【1654-0007】03_業疏/07a_卷二之一#80
【原文】次唱法中，初引文示除內地者，但唱外相，相中牒除內地，即不唱內相也。「今」下示今法，但唱兩相，不須牒除。至文述者，即戒場中
【譯文】在次段「宣唱之法」中，首先引述律文說明排除內部土地的做法，那只是宣唱外相，在唱外相中同時申明排除內部土地，就不再宣唱內相了。「今時」以下指示如今的做法，只是分別宣唱兩重界相，不需要特別申明排除。所謂「到後文進一步闡述」，即是在講述戒場之處。

【1654-0008】03_業疏/07a_卷二之一#81
【原文】五、集僧相
【譯文】第五門「集會僧眾之相」。

【1654-0009】03_業疏/07a_卷二之一#82
【原文】五百問》云：不得夜結，結亦應成，恐非不顯。又云：欲結時，四角標頭安人立望，不使人入，入則不成，當先結戒場等。亦以人雜是非，不可通練，非數何損？是數可遮耳
【譯文】《五百問論》說：不得在夜間結界；即使夜間結界理應也能成就，但恐別眾及足數情況不易辨明。又說：準備結界時，應在四角標記之處安排專人守望，不許外人闖入，若有人闖入則結界不成，應當先結戒場等。這也是因為人群雜沓混亂，無法徹底審查揀別；如果是不合僧數的人進入又有何損害？只有合乎僧數的人進入才會遮障羯磨法罷了。

【1654-0010】03_業疏/07a_卷二之一#83
【原文】五、明集僧引誡中，初引論有三：前定時節，「恐非不顯」者，謂別眾不足，暗處難知，必燈燭分明，理應無損。「又」下次明撿察，恐入自然。「當」下三、明先後。「亦」下疏家顯上時節撿察之意。「非數」等者，謂不得滿者，不集無損；得滿之人，別則成遮
【譯文】在第五門「說明集僧並引誡文」中，最初引述論藏有三層意思：首先限定時節，所謂「恐怕非法之相未能顯現」，是指若有界外別眾或僧數不足，在黑暗處難以察知，但如果燈火燭光十分明亮，理應沒有損害。「又云」以下，其次說明嚴格檢查，是唯恐他人誤入自然界內。「當先」以下，第三說明結界的先後次第。「亦以」以下，疏主顯明上述限定時節與檢查的用意。所謂「非數」等語，是指不能計入羯磨人數資格的人，不集會並無損害；而具有計入僧數資格的人，如果別立不集就會遮障羯磨成就。

【1654-0011】03_業疏/07a_卷二之一#84
【原文】若六種自然相中結者，標狹相寬，盡自然集，故《僧祇》七樹之外異眾不犯，可以準收；若標寬相狹者，盡標集之
【譯文】如果是在六種自然界相之中結界，若界標範圍狹小而實際界相寬廣，就必須在整個自然界範圍內全部召集僧眾，所以《僧祇律》說在七樹之外有異眾不犯別眾之罪，可以依此標準採納；如果是界標範圍寬廣而實際界相狹小，則必須在整個界標所圍範圍內全部召集僧眾。

【1654-0012】03_業疏/07a_卷二之一#85
【原文】次明集中初文有二：標狹則相在標外，須出標集；標寬則相在標內，須出相集
【譯文】在接下來說明集僧的初文中包含兩點：界標狹小則界相落在界標之外，必須走出界標外召集僧眾；界標寬廣則界相落在界標之內，必須走出界相外去召集僧眾。

【1654-0013】03_業疏/07a_卷二之一#86
【原文】有人言：但盡自然亦得，以相外標內是無法地，未是法被，何勞遠集
【譯文】有人說：只要召集齊全自然界內的人即可，因為界相之外、界標之內屬於沒有作法之處，尚未被羯磨法力所加被，何必勞師動眾遠去召集？

【1654-0014】03_業疏/07a_卷二之一#87
【原文】次科，古謂標寬相狹，未結在自然外，不妨作法；結已雖同法界，結法已成，故不須集
【譯文】下一科中，古德認為界標寬而界相狹時，未結界前處在自然界之外，不妨礙作羯磨法；結界之後雖然同屬作法界，但結界之法已經完成，所以不需要前去召集。

【1654-0015】03_業疏/07a_卷二之一#88
【原文】今解云：雖在自然之外，非別所收，然作法文中通牒標內，擬成二同。唱時結時，別眾在內，律無所開，何得非別？界為法本，義必深防，既無正文，亦須比用。故《僧祇》避難界云：三由旬內，彼有比丘，若呼來，若出界去，然後結之。無問相之內外，有尼界者不妨，必有僧界內有比丘，但不出界，亦不須喚。此則明文召集，不可人語有依也
【譯文】如今解釋說：雖然此處處在自然界之外，不屬該處別眾所收攝，然而羯磨作法文中通盤申明界標之內，旨在成就「二同大界」。在宣唱界相之時與正式結界之時，若有未集會的僧眾處在界內，戒律並無開許之例，怎能不算作別眾？界是僧法的根本，在義理上必須嚴加防範；既然沒有直接的正文，也應當比照類似條文施行。因此《僧祇律》論及避難界時說：三由旬之內如果有比丘，或者將他叫來，或者讓他離開出界，然後方可結界。此時不問是界相的內還是外；若界內有比丘尼界則不妨礙，但若界內已有比丘僧界且其中有比丘，只要他不走出自己的界，也就不需要呼喚他。這就是律中要求召集僧眾的明文，不可盲目依憑個人的私說。

【1654-0016】03_業疏/07a_卷二之一#89
【原文】三中，初以義通。唱相所圍，結法所牒，明非異處，故判成別界。「下」次引比例。眾法所依，故為法本。《僧祇》難界三由旬集，豈非據標？尼界兩不相礙，僧界義須隔出。「此下」準判，所謂依法不依人也
【譯文】在第三段中，首先從義理上加以通融。宣唱界相所包圍的範圍，就是羯磨結法中所申明的區域，顯明兩者並非不同處所，所以判定會構成別界。「故《僧祇》」以下，其次引用相類之例進行比照。由於是一切大眾僧法所依止的基石，所以稱為「法本」。《僧祇律》避難界要求在三由旬之內全體集僧，豈不正是依據標記範圍而定？比丘尼界與比丘僧界兩不互相妨礙，若是其他僧界則在義理上必須將其隔開或令其出界。「此則」以下依準律文予以判定，這正是所謂的「依法不依人」。

【1654-0017】03_業疏/07a_卷二之一#90
【原文】六、不得受欲者，有三義
【譯文】第六門「不得受欲（不得接受轉達意見）」包含三種義理。
