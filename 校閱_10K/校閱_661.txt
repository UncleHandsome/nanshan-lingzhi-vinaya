# 校閱材料　第661檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【661-0001】02_戒疏/14a_卷三下之二#101
【原文】【疏】四、為己乞應量衣。《十誦》中：「作寒暑相，方便說法，得亦是犯。」
【譯文】【疏文】第四、為自己乞求滿結犯標準尺度的衣料。《十誦律》中說：「故意現出不耐寒暑的模樣，以此方便為人說法而得衣，得到的也算犯戒。」

【661-0002】02_戒疏/14a_卷三下之二#102
【原文】【記】四中。「應量」者，《僧祇》乞得四肘已上者犯。準，已下應輕。「寒暑相」，「寒」現單薄，「暑」現厚重。
【譯文】【記文】第四緣中。「應量」，《僧祇律》指乞討得到四肘以上的布料便算犯戒。按此推準，四肘以下應屬輕罪。「寒暑相」，「寒」是指故意穿得單薄顯現寒冷，「暑」是指刻意穿得厚重顯現酷熱。

【661-0003】02_戒疏/14a_卷三下之二#103
【原文】【疏】準此為言，今行道者，實無道可行，止存世福！口雖讀經說法，身雖在座斂容，心路規度，常擬散席與我何物。如斯取者，同律邪命，何得不犯？故制正命。
【譯文】【疏文】準照此義而言，如今的修行人，實在沒有什麼道行可談，只不過是圖謀世間福報罷了！口中雖然誦經說法，身體雖然在法座上嚴肅端坐，心思卻不斷籌算計度，老是在想著下座散場後會供養我什麼東西。像這樣取得物品，在戒律上等同邪命，怎能不犯戒？所以佛陀才制定合於正命的清淨戒律。

【661-0004】02_戒疏/14a_卷三下之二#104
【原文】【記】斥非中，初科，又三。初標舉。言「行道」而「無道」者，謂有名無實也。「無道可行」者，不省自心故。「止存世福」，但事外儀。「口」下，二、釋成。初二句示存福，次三句明無道。「如」下，結過。
【譯文】【記文】在斥責非行中，第一小節，又分為三層。起初標示提出。說其「行道」卻「無道」，是指虛有名相而無實德。「無道可行」，是因為不能反省自己的自心。「止存世福」，是說只做表面外相威儀。「口」字以下，第二層釋成。前兩句指出心存世俗福報，後三句說明其全無修道之心。「如」字以下，結定其過失。

【661-0005】02_戒疏/14a_卷三下之二#105
【原文】【疏】今世講師，至此常不敢語。以親行故，羞不語他。何以不行而隱不道？何妨有人行之？則此戒或末法一人持也。慎之哉！慎之哉！
【譯文】【疏文】現今的法師講席，講到這條戒時往往不敢開口宣講。因為自己私下就在犯這條戒，感到羞愧而不敢向別人說。為什麼自己不能力行就隱諱不說呢？何妨有人能切實力行呢？這樣的話，這條戒在末法時期或許還能有一人受持。慎重啊！必須慎重啊！

【661-0006】02_戒疏/14a_卷三下之二#106
【原文】【記】次科。初明覆隱所以。「親行」，謂自犯也。「羞不語」者，說行相反故。此指當時，猶能知愧，而今無恥，身犯口說，何足議也！「何」下，正斥。古本作「可以」。己雖不行，講須明示，令他行之。則「末法或有一人」，不可期也。此言激勵之切，末學聽尋，當如何耶？下誡講者，不可隱教。再言「慎之」，誡之極也。
【譯文】【記文】第二小節。起初說明隱瞞遮蓋的原因。「親行」，是指自己就在犯戒。「羞不語」，是因為言行相違背的緣故。這是指當時的法師，還懂得感到慚愧；而今人不知羞恥，身在犯戒口中卻大言不慚地講述，哪裡還值得評議呢！「何」字以下，正式予以斥責。古本作「可以」。自己縱然做不到，宣講時必須明白開示，讓他人能夠如法奉行。那麼「末法中或許還能有一人守持」，這是不可預料的善果。這番激勵之辭極為切要，後世末學閱讀追尋之時，應當如何自處呢？下文戒飭宣講戒律者，不可隱沒佛法教制。連說兩次「慎之」，是告誡到了極點。

【661-0007】02_戒疏/14a_卷三下之二#107
【原文】【疏】《十誦》中：「但不作相，乞諸小小補衣物一條，及拭手面巾，不犯。若作念言『但乞小者，容施全者』，得，亦是犯。」先無心者不犯，可非心邪？
【譯文】【疏文】《十誦律》中說：「只要不故作姿態乞求，乞討各類補衣服用的小布片一條，以及擦手擦臉的毛巾，不犯。如果心中作念想著『我只要討小東西，對方就可能布施整塊好料』，這樣得到也算犯戒。」起初心中若無圖謀之心則不犯；（而作念而得者亦犯），難道不是因為其心術不正（心邪）嗎？

【661-0008】02_戒疏/14a_卷三下之二#108
【原文】【記】三中。《十誦》「不作相乞」，即非邪心，故得不犯。「若作念」下，即是邪心，故得皆犯。
【譯文】【記文】第三小節。《十誦律》說「不作相乞求」，就是沒有邪妄諂曲之心，所以能不犯。「若作念」以下，就是生起了邪心，所以得到布料皆犯戒。

【661-0009】02_戒疏/14a_卷三下之二#109
【原文】【疏】五、彼與；六、領受，便犯。
【譯文】【疏文】第五、對方給予；第六、領受之時，便構成犯戒。

【661-0010】02_戒疏/14a_卷三下之二#110
【原文】【註】佛在舍衛國。時，跋難陀為人說法，從索所著衣。俛仰與己，單衣入城，便云：「祇垣中被賊。」諸俗譏嫌。比丘舉過，佛便制戒。
【譯文】【註文】佛陀在舍衛國。當時，跋難陀比丘為人說法，隨後向聽法者索取對方身上穿的衣服。那人無可奈何地給了他，只穿一件單衣走進城內，便說：「我在祇樹給孤獨園裡遇到賊了。」引來居士們的譏嫌非議。其他比丘揭發此過，佛陀便制定此戒。

【661-0011】02_戒疏/14a_卷三下之二#111
【原文】【疏】就緣起中。因說法取衣，致為過非。今諸難免，亦易檢挍。但是一貪，既共俱生，可共滅邪？
【譯文】【疏文】在戒緣之中。因為借說法來索取衣服，導致產生重大過患。如今人人難免有此習氣，但檢點省察自己其實並不困難。這只不過是一念貪心罷了，既然這貪心與身俱生，難道可以（任由放縱而）與它一同毀滅嗎？

【661-0012】02_戒疏/14a_卷三下之二#112
【原文】【記】戒緣中。注中「俛仰與」者，事不得已故。「單衣入城」，人問其故，云「被賊」者，即刺跋難陀也。假法為由，公索他物，不殊白盜，宜與斯名。《疏》中躡意，以申誡勸。「難免」即指著世之流，「易檢」則勉有道之士。「但一貪」者，指出病根，令自明識。無始貪習，既與「俱生」，宜須抑制，如何反縱，與之同死耶？
【譯文】【記文】制戒緣起中。注文說「俛仰與」者，是迫於情勢不得已的緣故。「單衣入城」，別人問他原因，他回答「遇賊」，這正是諷刺跋難陀比丘。假借佛法為名義，公然索要他人財物，與白晝劫盜毫無分別，正應當承受這個罵名。《義疏》中承接律文深意，以此申述誡免勸導。「難免」是指貪著世間名利的人，「易檢」則是勉勵有志修道之士。「但一貪」這句話，指出了病苦的根源，令行者自己清楚認識。無始劫來的貪欲習氣，既然與自身「俱生」共存，就應當加以抑制克服，怎麼反而縱容放任，乃至與貪心一同沉淪赴死呢？

【661-0016】02_戒疏/14a_卷三下之二#116
【原文】【律】餘時者，若奪衣。
【譯文】【律文】所謂特殊的時節，是指衣服被強盜掠奪之時。
