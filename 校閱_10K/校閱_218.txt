# 校閱材料　第218檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【218-0001】01_行事鈔/10a_卷下之二#8
【原文】七日藥者。《四分》：穌、油、生穌、蜜、石蜜等五種，世人所識，當食當藥，如食飯、乾飯，不令麁現。《伽論》：糖漿亦得七日受，乃至未捨自性。《僧祇》加脂一種。《四分》：舍利弗風病，醫教服五種脂，熊、羆、猪、驢、魚等也。《僧祇》：此藥清淨，無時食氣；一時受，七日服。有四百四病：風大百一用油脂治，火大熟病用穌治之，水病蜜治，雜病用上三藥治之。《五分》：見作石蜜，搗米著中。佛言：作法應爾。若合藥法如此者，聽非時服。《十誦》：石蜜不得輒噉，除五種人：遠行人、病人、食少不足人、不得食人；若施水處，和水飲之。《五分》：飢、渴二時，以水和飲。《僧祇》：食上多得酪，食不盡者，動作生穌，七日受服；若長，煎作熟穌，七日受。若乞食時多得穌者，貧病比丘，以細緻㲲淨漉，取穌，得七日受。若有緣事不得中前作者，當對一比丘記識言：此中淨物生，我當作七日藥受。若忘誤不受、不作淨，過時是名不淨。若得多油，如穌中說。得胡麻，食殘不盡，即煮取油，七日受之；若事緣不得作，如穌中說。若熊、猪等脂，如上進不。得甘蔗及果，並如上。《善見》：受酪，記酪中穌為七日，至第七日鑽得即日服，八日犯捨。油、蜜亦爾。《摩得伽》：非時受甘蔗，作法不成，時內並成。然蜜味美重，凡聖常言，長貪壞行，勿先於此，兼得必彊力劫掠辨之；自非極病，難用進口。故《僧祇》：佛受獼猴無蜂熟蜜等。
【譯文】所謂七日藥：《四分律》說：熟酥、油、生酥、蜂蜜、石蜜等五種，為世人所通曉，既當作食物又當作藥品，如同食用米飯、乾飯一樣（能充飢滋益），但食用時不可顯露粗重貪相。《摩得伽論》說：糖漿也可以受持七日，乃至未失去原本自性為止。《摩訶僧祇律》增加「動物脂肪」一種。《四分律》說：舍利弗患風病，醫生教他服用五種動物脂肪，即熊、羆、豬、驢、魚等脂肪。《摩訶僧祇律》說：此藥體性清淨，沒有時食之濁氣；一次受持，可服用七日。人身有四百零四種病：風大引起的一百零一種病用油脂治療，火大引起的熱熟病用酥治療，水大之病用蜂蜜治療，各類雜病則合用上述三種藥物治療。《五分律》說：見到製作石蜜時，搗碎米粒放入其中。佛說：製作方法本該如此。如果配藥之法本是如此，聽許在非時服用。《十誦律》說：石蜜不得隨便食用，除了五種人：遠行之人、生病之人、食少不足之人、未得食物之人，以及在施水處（渴乏）之人，可調和水來飲用。《五分律》說：飢餓、口渴二時，以水調和飲用。《摩訶僧祇律》說：在供僧食中得到很多乳酪，吃不完的，攪動提煉為生酥，作七日法受持服用；若有多餘，煎熬成熟酥，作七日受持。如果乞食時得到很多酥，貧病比丘可以用細密白布清淨過濾，取得純酥，得以作七日受持。如果有事緣無法在正午前製成的，應當對一位比丘表白標記說：「這裡面生出淨物，我將要作為七日藥受持。」如果遺忘疏忽未作受持、未作淨，過了正午，這就稱為不淨。如果得到很多油，處理之法如酥中所說。得到胡麻，吃剩不盡的，隨即熬煮榨取其油，作七日受持；若因事緣無法及時製作，如酥中所說。若是熊、豬等動物脂肪，比照上述原則決定進止（是否受服）。得到甘蔗及果實，也都比照上述辦理。《善見律》說：受持乳酪時，標記酪中之酥為七日藥，至第七日攪拌提煉出來，必須當天服用，到了第八天便犯捨墮（尼薩耆波逸提）。油、蜜也是如此。《摩得伽論》說：在非時（午後）受持甘蔗，作法不能成就；在時內（正午前）則皆能成就。然而蜂蜜滋味甘美濃重，凡夫聖者常言：增長貪愛、敗壞梵行，莫過於此，況且要取得蜂蜜，必定是強力摧毀蜂巢劫掠而來；自己若非患了極重之病，很難以此為由服食入口。因此《摩訶僧祇律》記載：佛陀只接受獼猴所獻的無蜜蜂傷亡的熟蜜等。

【218-0002】01_行事鈔/10a_卷下之二#9
【原文】盡形體者。《僧祇》：胡椒、蓽茇、呵梨勒等，此藥無時食氣，頓受，病比丘終身服。《四分》云：不任為食者，一切鹹、苦、辛、甘等，不任為食，名盡形藥體。《善見》：一切樹木及草根、莖、枝、葉，為食不任者，盡形服之。又樹木、草，無問根、莖，並是時藥；或根是時藥，莖是盡形；互有俱是，不可名示。但令堪食，時藥所攝；不任者，盡形藥。《明了論疏》云：若病服七日藥，隨病為量，若差須捨；若無病復不飢，非時食者，得非時食罪。油、蜜、膏亦爾，故論中舉穌等。終身藥則不爾，有身必有病，佛許服此藥，防護一期果報身；若無客病，又不飢渴，非時不得服。《十誦》：淨苦酒無酒氣無糟者，過中得飲。上來辨者，一切經律，隨事辨體；同此宗者，具列如上。今有愚夫，非時妄噉諸杏子湯、乾棗汁、果漿含滓、藕根米汁，乾地黃、茯苓末、諸藥酒煎非鹹苦格口者，非時噉之，並出在自心，妄憑聖教；不如噉飯，未必長惡，引誤後生，罪流長世。
【譯文】所謂盡形壽藥體：《摩訶僧祇律》說：胡椒、蓽茇、呵梨勒等，這類藥材沒有時食的氣味，一次受持，病比丘可終身服用。《四分律》說：不堪充當食物的，一切鹹、苦、辛、甘等物，凡不堪作為食物充飢者，稱為盡形藥體。《善見律》說：一切樹木及草本植物的根、莖、枝、葉，不堪充當食物的，皆可盡形壽服用。又有樹木、草類，不論是根還是莖，全都是時藥；或者根是時藥，莖是盡形藥；或者相反（莖是時藥、根是盡形藥）；或者兩者皆是盡形藥，無法一一盡列標示。只要堪供食用充飢的，即屬時藥所攝；不堪充當食物的，則是盡形藥。《律二十二明了論疏》說：若是因病服用七日藥，應當隨病情為限度，病若痊癒就必須捨去；若無病又無飢餓，在非時食用的，得非時食罪。油、蜜、脂膏也是如此，所以論中舉出酥等為例。終身藥則不如此，只要有肉身就必定有疾苦，佛陀聽許服用此藥，是用來防護一期果報之身；但如果沒有外來的新病，又無飢渴，在非時仍然不得服用。《十誦律》說：清淨苦酒（醋）無酒氣、無酒糟者，過正午後得以飲用。以上所辨析者，是綜合一切經律，隨事相辨明藥體；合乎本律宗義者，已具體列於前文。如今有些愚昧之人，在非時妄自喝各類杏子湯、乾棗汁、含有渣滓之果漿、藕根米汁，乃至食用乾地黃、茯苓末、以各類藥酒煎煮而非鹹苦格口之補藥，在非時食用它們，這完全出自於自己的貪心，卻妄稱依憑聖教；這樣做還不如直接去吃飯，吃飯未必會長養這般偽善之惡，如今引導延誤後學，罪業將流毒萬世。

【218-0003】01_行事鈔/10a_卷下之二#10
【原文】次二，六味定者。《明了論》云：五種量，乃至大開，攝一切物皆盡。《疏》云：藥有五種：甘味物中，除甘草、蜜、沙糖、穌、油，餘甘味是時量；酸味除阿摩勒果汁等，餘酸味是時量；辛味中除薑、椒、萆茇、呵梨勒，餘辛味是時量；一切苦澁物非食，作終身藥。七日藥外，一切可食物，名依時量食；從平旦至正中，為時；過此，不得食。一切漿、甘蔗等，名依更量；日夜各分五時，從平旦受至二更，過則不得服，如是輪轉，乃至五更；此間漬飯為漿，屬時量。穌、油、蜜、沙糖等，名依七日量。甘草等，名依一期量；從受戒後，臨一期報終，名一期也；於此時中，無問晝夜，恒得服之。灰、土、水、屎、尿此五，名依大開量；不須受，隨意取服，是世間所棄，非所惜故。《四分》：須受灰、土等。
【譯文】第二、依六味決定藥量：《律二十二明了論》說：有五種限度（量），乃至大開許，將一切物品攝盡無餘。《律二十二明了論疏》說：藥物分為五種：在甜味物品中，除甘草、蜂蜜、砂糖、熟酥、油之外，其餘甜味皆屬依時量；酸味物品中，除阿摩勒果汁等之外，其餘酸味皆屬依時量；辛辣味中，除生薑、胡椒、蓽茇、呵梨勒之外，其餘辛味皆屬依時量；一切苦澀之物不是食物，皆作為終身藥。除了七日藥之外，一切可充飢食用之物，稱為「依時量食」；從平旦至正午，稱為「時」；過了此時限，便不得食用。一切果漿、甘蔗等，稱為「依更量」；一日一夜各分為五更（五時），從平旦受持至第二更，過時便不得服用，如此輾轉輪替，乃至第五更；中土浸泡米飯所成的米漿，則屬於依時量。熟酥、油、蜂蜜、砂糖等，稱為「依七日量」。甘草等，稱為「依一期量」；從受具足戒之後，直至一期生命果報終結，稱為「一期」；在此時間之中，不論白天黑夜，恆常得以服用。草木灰、土、水、屎、尿這五種，稱為「依大開量」；不需要作受持法，隨意取來服用，因為這是世間所拋棄之物，並非世人所顧惜之故。《四分律》則規定：必須作法受持灰、土等。
