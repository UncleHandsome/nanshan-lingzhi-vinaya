### 【007-0001】
1. **可議**｜「行作法事，坐則非法」譯成「行走著做羯磨法事，坐著的人就是非法」，主語不明（誰在走？）。原意是**大眾經行中作法，其中坐著不隨眾者威儀不同故非法**。
 → 建議：「僧眾邊行走邊作法事時，坐著（不隨眾）的人就不如法。」
2. **誤譯**｜「如行時食，食住則犯足」。「行時食」是**邊走邊吃**，不是「行走時受食」；「食住」是停住腳步（捨威儀），一停住即構成「足食（食竟）」，**其後再食才犯足食戒**。譯文把「成足食」與「犯戒」混為一事。
 → 建議：「就像邊走邊吃，一旦停住（捨威儀）便成『足食』，再吃就犯足食戒。」
3. **誤譯**｜「別眾中說」指**本書下文「別眾」一節再作解說**，不是「在別眾之中說明」。
 → 建議：「依理這不是和合之相，下文『別眾』處會再說明。」
4. **潤飾**｜「嚴加訶責」的「嚴加」為原文所無；「別眾」首見宜加註（各別成眾、不成和合，羯磨無效）。

### 【007-0002】
1. **潤飾**｜「也能成就證成羯磨之法」繞口且「證法／證成」重複。此處屬「足數」問題。
 → 建議：「只要身口外相隨順，內心雖不同意，仍算是證成羯磨的人（可足僧數）。」
2. **誤譯（歧義）**｜「現場應當訶責的人不訶責」會被讀成「該被罵的人不罵人」。「應訶」是**應出言訶止、表示反對**。
 → 建議：「律文說：『在場本應出言訶止（反對）的人，卻不訶止。』（默然即成同意）」
3. **可議**｜第二則引文「雖然心中不同意」句子未收束。
 → 建議：「又說：『見是如法羯磨，內心雖不認同（但未表示反對，仍成和合）』，即如前文所列的情形。」

### 【007-0003】
1. **可議**｜「暫且等待」語氣太輕，「且待…竟，方始作白」是必要條件。
 → 建議：「必須等答話的人坐定之後，才開始作白（宣告）。」
2. **潤飾**｜問句主語未點出。
 → 建議：「作法時，（秉羯磨者）問僧說：……」
3. **潤飾**｜「廣泛的取捨廢立」仍是文言。
 → 建議：「其中種種取捨抉擇（何者可省、何者必存），詳如《四分律拾毗尼義鈔》所說。」

### 【007-0004】
1. **可議**｜原文是直述句，譯文改成設問「聽許有站立的人嗎？」並自補「其餘皆不可立」，把敘述變問答。
 → 建議：「僧眾都坐著時，其中允許有站立者，那就是被治罰的人；因為他是此次羯磨所對的當事人，不算入僧數（故不受威儀相同之限）。」
2. **潤飾**｜「其餘凡有所祈請辦事的人」語意含糊。
 → 建議：「其餘有事求僧作法的人（如求受戒、乞懺悔者），都應坐著陳乞才如法；律文與義理都說得很明白。」

### 【007-0005】
1. **可議（註解疑誤）**｜「威儀師（知事僧）」。此處威儀師應指**受僧差遣、立作單白後即須外出辦事的執事**（如受戒法中的教授阿闍梨，屏處問遮難、教導威儀），與寺職「知事」不同。建議核對《資持記》後改註。
 → 建議：「威儀師（受僧差遣、負責問遮難與教導威儀的教授師）」，或暫不加註。
2. **潤飾**｜「二是開許站立說戒」缺主語，與「除二種人」不對應。
 → 建議：「二是說戒師，開許他站立說戒，為使大眾都能聽聞。」

### 【007-0006】、【007-0007】
1. **可議**｜兩條篇題原樣照抄，未白話也未加註，讀者不知「受欲」「是非」何指。
 → 建議：保留原題＋白話標題，如「4 受欲是非篇（上之一）——論接受他人委託『與欲』（同意權）是否如法」；「受欲是非篇第四」→「第四篇 受欲是非：受託代達同意（欲）的合法與不合法」。並與下文「與欲／受欲」用語統一。

### 【007-0008】
1. **可議（疑反解）**｜「法出恒情」譯為「僧法軌度出自僧團常規」。此句與「事生不意」對舉，通行理解是**如來之法超乎常情**（於「身心俱集」的常規之外別開方便），故下文才結「開與欲」。譯成「出自常規」與語脈不合。
 → 建議：「事情的發生往往出乎意料，而佛所制之法又超乎常情（別開方便）……」，或加註標明異解。
2. **誤譯**｜「對情而順其心」譯成「病僧面對僧團常法而以己心隨順大眾之心」。「情」不是「僧團常法」，「病僧」也是增譯。
 → 建議：「所以就當事者的實情，使其心隨順僧眾；心既隨順，於法便無過失。」
3. **誤譯（註解）**｜「欲」註為「委託同意**外出或請假**之意願」不確。與欲非外出／請假，而是因緣不能赴集，託人代達同意（說戒時兼表清淨）。
 → 建議：註作「欲：把自己的同意（意願）託人轉達僧眾」。
4. **潤飾**｜「情事相反」一段過度迂迴。
 → 建議：「然而心裡雖願赴集，事緣卻相違（身不能到），所以制立『與欲』之法來檢核攝持……」

### 【007-0009】
1. **可議**｜「將何拔濟」補成「拔濟僧眾」縮小對象；機教不相應則**群生**無由得益。
 → 建議：「那麼根機與教法便無法相應，還靠什麼來拔濟（眾生）呢！」
2. **潤飾**｜「身心俱集／和集」用語生硬。
 → 建議：「必須身、心都到齊（身親到、心同意），才算和合。」
3. **潤飾**｜「不開心集」處直接補「透過授欲」，宜用括號標示為譯者補註。

### 【007-0010】
1. **誤譯（書名）**｜註「薩婆多部毘尼摩得伽」漏字，應作 **《薩婆多部毘尼摩得勒伽》**（「摩得伽」即「摩得勒伽／摩夷、本母」之略）。
2. **可議**｜「因緣差錯」易解成犯錯；「緣差」是事緣不巧、臨時有障礙。
 → 建議：「只因事緣不巧（臨時有障礙），不能如願親到。」
3. **潤飾**｜「歡喜隨喜」疊詞。
 → 建議：「所謂欲，就是對所作之事樂意認同隨喜，共同成就如法的僧事。」
4. **潤飾**｜「欲名發心」宜加註：發心＝發起同意之心。

### 【007-0011】
1. **可議**｜「佛陀對個人並未嚴格正制」：「正制」未白話，「嚴格」為增字。
 → 建議：「佛並沒有正式制定個人非與欲不可。」
2. **潤飾**｜「捨懺」「時限」宜稍展開。
 → 建議：「如受戒、捨墮（尼薩耆）罪的懺悔等」；「因佛制有固定時日（如半月說戒、安居自恣）」。

### 【007-0012】
1. **可議**｜「律藏中」過泛，本篇「律中」指《四分律》。
 → 建議：「《四分律》中唯除結界一事，其餘羯磨都開許與欲。」（可加註：結界須身集，故不得與欲。）
2. **潤飾**｜「沒有禁制便意味著開許」是譯者推衍，原文僅「以非制故」。
 → 建議：「雖然律中並非一一明文開許，但因為佛並未遮制的緣故（故視為開許）。」推衍句放括號內。

### 【007-0013】
1. **誤譯**｜「雖非正制」譯成「雖然不是**正當的**規定」，語意偏為「不正當」。原意是**不是律中正式明制的開緣**，非指其非法。
 → 建議：「六群比丘為作衣而說欲，雖不是律中正式制定的開緣，僧眾仍接受採用。」
2. **潤飾**｜首句「如果有犯戒的情事，事情屬於非法的緣由而給予欲法的」重複拗口。
 → 建議：「若為犯戒之事、或非法的因緣而與欲，由於事由非法，即不合規定、欲法不成。」
3. **潤飾**｜「律文中具足正式列出」未白話。
 → 建議：「這六事在律文中有正式而完整的列舉。」
4. **可議**｜「為修塔」窄化「塔事」。
 → 建議：「塔事（供養、修治佛塔等）」。

### 【007-0014】
1. **誤譯**｜「三波逸提」是**三個（三次）波逸提罪**，非「三種」；对应病、淨、欲三句妄語。
 → 建議：「隨在場僧眾人數多寡，於每一位僧人處各結三個波逸提罪（單墮）——即謊稱有病、謊稱清淨、謊稱與欲三句妄語。」後文「一一三罪」比照處理。
2. **潤飾**｜「輕慢這項**法規**」偏世俗法律語。
 → 建議：「多半輕慢這一『與欲』之法」。
3. **潤飾**｜「不欲言欲」可白話為「心裡並不同意，卻謊稱與欲」。

### 【007-0015】
1. **誤譯（科判層次）**｜外層「初明與法」與內層「前明與法」都譯成「授與欲法」，兩層重疊看不出差別。外層是總科，內層分「本人與欲」與「受託者向僧宣說」。
 → 建議：「第二、說明欲法，分三：一、與欲之法（總）；二、欲法失效的情況；三、遇特殊因緣時欲法成否。第一科又分二：先明本人如何與欲，次明受託者如何在僧中宣說。」

### 【007-0016】
1. **誤譯**｜「不須云云，取他外部」譯成「不需要紛繁議論，**非要採用**其他部派的規定」，語意斷裂甚至相反。原意是「**不必**紛紜議論**而去採用**他部（僧祇三說）的做法」。
 → 建議：「不必紛紜聚訟，去採其他部派的說法。」
2. **可議**｜「結略之文」未解釋，讀者不解何謂「重複結略」。
 → 建議：「凡一說即成的法，律文都不會有『第二、第三亦如是說』這類結略（省略後續重複）的文句；須三說才成的，才會這樣標明。」
3. **可議**｜「依文直成」譯為「直接說一遍即可成就」略嫌武斷（白二是一白一羯磨）。
 → 建議：「比照白二羯磨、說淨等法，都是依律文所定的遍數直說即成（不必增為三說）。」
4. **潤飾**｜「《四分》文不具足」宜點明「律中未完整載明與欲的說辭」；「與欲清淨」可加註「表示同意，並宣告自身清淨」。

### 共通建議
- **術語首見加註並統一**：羯磨、別眾、單白／白二、足食、與欲／受欲、說淨、波逸提（單墮）。
- **增譯一律用括號**：如「嚴加」「沒有禁制便意味著開許」「其餘皆不可立」等原文所無之語，避免與原文混淆。
- **書名統一**：《僧祇律》＝《摩訶僧祇律》；《摩得伽》＝《薩婆多部毘尼摩得勒伽》；《義鈔》＝《四分律拾毗尼義鈔》（首次全稱、其後簡稱）。
- **兩處建議查《資持記》再定稿**：0005「威儀師」的身分、0008「法出恒情」的取解。
