# 校閱材料　第1552檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1552-0001】05_拾毗尼義鈔/04b_卷中之二#27
【原文】第三總別通塞者總以收攝為義別以區分立稱通以體徧諸處塞乃唯局自分此中名有總別體殊通塞毗尼之名是總以有收攝義故若論現前名等是則以名各不相收然現前是體通用通故名為總餘六不獨行要假現前方得滅諍即是明用通餘六六自相望六六常別憶念現前非是不癡現前故知是別若以餘六望現前現前常是總若以現前望下六即是其別如似羯磨望受日結界受日結界是別若以結界受日望羯磨羯磨即是總問現前該六名為通者自言亦通何故落在塞中答汎爾自言應說為通但今自言唯取攬短歸己名自言毗尼故不在通餘無攬短之義如憶念之人本亦不犯木癡之人病差不為多人語者各言我是罪處之人後便解違艸布地者不說名種是故不說自言為通指文辨相廣如別章如此七滅論義皆有三法現前若如文辨者唯現前自言二毗尼有三五現前餘五各五其中界現前五中皆同法滅位通隨相各別人亦通五毗尼唯多人語中人可在斷諍數中餘皆不爾僧亦位通隨相不同何者現前毗尼中僧具十德者集餘不在例多人語中僧不問愚智悉集并起諍人自判艸覆中僧不揀愚智要是兩朋眾皆集即此彼互作僧人憶念不癡罪處所中僧應簡取具不愛等四諸門如律。
【譯文】第三、說明總名、別名、共通與局限：總，以收攝統括為義；別，以區分各相而立名；通，指其體性能遍及諸處；塞，指其法局限於自分之內。在此七法中，有名稱上的總別，也有體性上的通塞。「毘尼」之名是總名，因為具有收攝一切滅法之義；若論「現前」等名，則屬於別名，因為各自的名相互不相涉。然而「現前」本身是體性，其功能共通於後六種滅法，所以稱為總；其餘六種滅法不能單獨運作，必須憑藉現前法才能滅諍，這便說明現前的體用通於其餘六滅。後六滅法彼此相對，六法之間常是各自差別的，「憶念現前」絕非「不癡現前」，所以知道是各自獨立之別法。若將其餘六滅對照現前，現前永遠是總；若將現前對照後六滅，後六滅相對於現前即是其別。這如同「羯磨」對照「受日」與「結界」，受日與結界是別法；若將結界與受日對照羯磨，羯磨便是總法。問：現前涵蓋了後六法所以稱為通法，「自言」也貫通於諸處，為何卻落在局塞之中？答：一般廣泛意義的自言懺悔，本可說為共通之法；但此處的自言毘尼，專門取「攬取短處歸於自己、發露認罪」為義，所以不列入共通之列。其餘諸法都沒有攬短認錯的意思，如憶念者本來就沒有犯戒，不癡者是狂病已癒後即不復犯作，多人語者是各自堅持己見，罪處所者是事後翻供矛盾，草覆地者是不說具體罪名與種類；所以不將自言稱為通法。依據經文辨別各自行相，詳細載於別章。這七種滅諍法在義理推論上，都含有「三法現前」；如果按照律文辨析，唯獨「現前毘尼」與「自言毘尼」兼具三法與五法現前，其餘五滅都各自具足五法現前。其中「界現前」在這五種滅諍中全體相同；「法」與「滅」（毘尼）的名位通於各滅，隨其事相各自不同；「人」也通於五種毘尼，唯獨在多人語羯磨中，引發爭端之人可以列入裁斷爭端的僧數之中，其餘皆非如此；「僧」的名位也是相通的，隨其事相而有不同：在現前毘尼中，僧眾必須具足十德，不符合者不在此列；在多人語中，不論愚昧或聰慧之僧全體齊集，連引發爭諍之人也親自參與判決；在草覆地中，僧團不挑選愚智，必須是爭執的兩派陣營全體到齊，雙方互為秉法之僧與受懺之人；在憶念、不癡、罪處所中，僧眾應當揀選具備不愛、不恚、不怖、不癡等四德的清淨僧，各種門徑皆如律中所述。

【1552-0002】05_拾毗尼義鈔/04b_卷中之二#28
【原文】第四滅罪諍及以治人者自言艸覆罪諍俱滅罪處一種不滅罪俱滅諍自餘四種唯滅諍而無罪可滅其七中六種但滅諍不治人以人無過故諍是𩰖亂故須滅之罪處所亦滅諍亦治人諍須滅如上以人諱罪觸僧故須治人與處所竟應奪三十五事又五分云本言治有二種一可悔二不可悔不可悔者與作盡形壽不可悔白四羯磨餘無此過故不論解此中問法之與藥有何別答如現前毗尼法者簡集智慧羯磨是也藥者正用三藏教法判者是也不如憶念等三法藥同體今疏家作法藥通解所以不出法藥體者一解滅不究竟故若作此解不出法者且得如是藥是究竟何以不出此責難自言毗尼諍應得滅從多論同言未滅第二作不定解者覔中三品上中下定言犯二諍執情流轉不定用藥無準故不出義可爾又解餘四所以不出法藥者現前通滅四諍智出何體若欲具論謂皆竝用正欲隨分少序恐謂常定謂皆滅諍是故隱之如現前中五法三法人有增減等是名不定雖簡眾白竟諍復未滅故言不究竟如自言或對一二三四或自引犯不犯輕重等故知無準雖假和白諍罪未滅故知亦不究竟多人語中三種行舍羅五四不同故知無準雖作差白羯磨等諍情未息滅亦不究竟艸覆中用法應定但以滅不究竟是故不出法體。
【譯文】第四、說明滅除罪事、諍事以及懲處當事人：在自言與草覆地中，罪與諍全部滅除；罪處所這一種不滅除罪，但滅除諍；其餘四種滅法只滅除諍事，而無罪可滅。在七滅諍中，有六種只滅諍而不懲處人，因為當事人並沒有過失，爭諍只是大眾心生擾亂，所以應當平息；罪處所既要滅諍，也要治處當事人——諍端必須平息如前所述，而當事人隱瞞罪行、觸惱僧團，所以必須予以懲戒。給予罪處所羯磨之後，應剝奪其三十五項僧事權利。又《五分律》說：原本所說的懲治有兩種，一是可悔，二是不可悔；不可悔者，應當對他作盡形壽不可悔的白四羯磨，其餘各法沒有這種過咎，所以不論。在此問：「法」與「藥」有何差別？答：如在現前毘尼中，「法」是指揀選聚集具備智慧的僧眾所作的羯磨；「藥」是指真正運用經律論三藏教法來裁定是非者。這與憶念等三滅法不同，那三法的「法」與「藥」體性相同。現在律疏家將法與藥作共通解釋，之所以沒有明確列出法藥體性，一種解釋是因為平息得不夠究竟徹底：如果作此解釋，而不標出羯磨法體，暫且說得通，但三藏教藥本身是徹底究竟的，何以也不標出？這是針對藥體所作的責難。又若問：在自言毘尼中諍事應當已得平息，何以也不標出？答：依從《薩婆多論》同樣說自言未徹底滅諍。第二種解釋是作「不定解」：覓諍之中上、中、下三品是固定的，言諍與犯諍這兩種諍的情執輾轉流動不定，用藥沒有固定標準，所以不予標出，這在義理上是行得通的。另一種解釋說，其餘四種滅法之所以不標出法藥體性，是因為現前通滅四種爭諍，智慧究竟以何為法體？若想完全論述，就是全部並用；若只想隨分稍作介紹，又恐學者誤以為是固定常軌、以為已經完全滅諍，所以隱而不發。如同現前法中有五法、三法，人數有增有減等，這都稱為不定；雖然已經揀選大眾作白羯磨完畢，諍事卻尚未平息，所以說不究竟。如自言中，或者對一人、二人、三人、四人，或者自己招供有犯、無犯、罪重、罪輕等，由此可知沒有固定準則；雖然藉助和合宣白，諍事與罪業並未完全滅盡，所以知道也是不究竟。在多人語中，三種發籌表決方式，五德或四德之僧各有不同，所以知道無定準；雖然作了差派行籌的白羯磨等，爭諍之情未息，滅諍亦不究竟。草覆地中，所用的法應當是固定的，只因為滅得不徹底，所以不標明法體。
