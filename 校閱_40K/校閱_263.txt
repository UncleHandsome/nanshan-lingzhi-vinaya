# 校閱材料　第263檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【263-0001】資持記/07b_中一下#28
【原文】損字寫誤，準疏合作增。下二句申理。謂所能生非能中，戒則有減；非能生能中，戒則容增，故云互轉生也。疏云：如獵持猪羊戒，死生麞鹿，戒則減也；或鹿生羊中，戒則增也。屠者例爾。第二過中。若爾者，躡上增減義。則下，指過。以戒受捨，竝假因緣；今自增減，正乖戒義。
【譯文】原書中的「損」字是抄寫錯誤，依照《業疏》應當改為「增」字。下面兩句申述正確的義理：是指能持境若投生到非能持境當中，戒體就會減少；非能持境若投生到能持境當中，戒體就可能增加，所以稱為「互轉受生」。《業疏》說：例如獵人受持不殺豬羊的戒，豬羊死後若投生為獐鹿，戒體就會減少；或者獐鹿死後投生為羊，戒體就會增加。屠夫的情況也是依此類推。在「第二種過失」當中，「如果這樣」一詞，是順著上面的增減之義推論。「則」字以下，指出過失所在：因為戒體的受持與捨棄，全都要依憑相應的因緣儀式；如今戒體卻會自行增減，這完全違背了戒法的定義。

【263-0002】資持記/07b_中一下#29
【原文】第三過中，初縱許上義。謂戒自增減，不假因緣，義亦何失。惡下，指過。由害心不盡，縱所能境，心亦不定。疏云：如獵者持家畜，行獵不獲，路逢猪羊，心還起殺。準知得戒之心，不容毫髮之惡。高超萬善，軌導五乘；眾聖稱揚，良由於此。三釋增減。《婆沙》問者，即《俱舍》自引。
【譯文】在「第三種過失」當中，起初姑且順從承認上述的義理：意思是戒體自行增減而不憑藉儀軌因緣，在義理上又有什麼損害呢？「惡」字以下，指出真正的過失所在：因為內心的加害念頭沒有斷盡，縱然面對自己發心能持的境界，心念依然是不穩定的。《業疏》說：例如獵人受持不殺家畜的戒，上山打獵卻一無所獲，半路上遇到豬羊，心中依然會生起殺念。由此可知，要獲得戒體的心，絕不能容納絲毫的惡念。戒法之所以能高超萬種世間善行，成為引導天人聲聞五乘的軌範，歷代聖賢無不稱揚讚歎，實在就是導源於這份周遍清淨的心。第三「解釋增減之難」。《大毘婆沙論》所提出的提問，也就是《俱舍論》自己引用的問題。

【263-0003】資持記/07b_中一下#30
【原文】若爾者，躡前為難，前云互轉有增減過；今難，縱令普周，不免此過，故須釋之。文中，先約非情有增減過。未有者，如冬受春生，戒則有增；有時者，如春受秋滅，戒則有減。次約有情，唯有減過。入般者，證阿羅漢，大般涅槃；此約灰身入無餘者，不於三界受生，即眾生減也。答中，初句。
【譯文】「如果這樣」一詞，是承接著前面的論點而發起責難；前面說能所互轉會產生戒體增減的過失，現在責難說：縱使發心普周一切境界，也同樣免不了戒體增減的過失，所以必須加以解釋澄清。在文句中，先就無情物來說明戒體有增減的過失：所謂「尚未存在的」，例如冬天受戒時春天草木才萌生，戒體就會增加；所謂「已經存在的」，例如春天受戒到了秋天草木枯滅，戒體就會減少。其次就「有情眾生」來說，則唯獨有減少的過失：所謂「入涅槃」，是指證得阿羅漢果、證入大般涅槃；這是就灰身滅智進入無餘涅槃而言，不再於三界中受生，眾生的總數就減少了。回答中，第一句先作解答：

【263-0004】資持記/07b_中一下#31
【原文】世疑戒本防非，三乘果人，煩惑既傾，業非永喪，何用戒為？又經律中，如來成道，方始感戒，羅漢破結上法得戒。準此初句，頗決深疑；更有別通，文在《義鈔》。境不盡者，經云：眾生無盡，戒亦無盡；此舉正報必兼依報，故非情境亦無盡也。第二句。正通前難，餘三相因而來。
【譯文】世人常疑惑戒律本是用來防範過非的，三乘聖果之人既然已經拔除煩惱迷惑，惡業過非已經永遠滅盡，又何必還要戒法呢？再者經律中提到，如來成道之後才開始感得戒法，阿羅漢破除煩惱結使後依上品善法得戒。依據這第一句，很大程度能化解這層深微的疑惑；另外還有其他會通的說法，記錄在《拾毘尼義鈔》中。所謂「境界無有窮盡」，佛經說：「眾生無窮無盡，戒法也無窮無盡」；這裡舉出正報眾生，必定連帶包含依報環境，所以無情的境界也是無窮無盡的。第二句，正是正面會通先前的難問，其餘三句則是順著文理推演而來。

【263-0005】資持記/07b_中一下#32
【原文】心過在者，以惑心未破，妄業隨興；害生斷草，心不息故。三二俱句。凡夫現境，二皆存故。四中。不同者，如初四重，名僧尼同戒；後四重，尼有僧無；漏觸麁歎，僧有尼無，名不同戒。如僧轉為尼，漏觸等境，非我所防，復無能防，故云俱謝。此句論謝，即不同前謝滅之謝，比之可知。
【譯文】「心念的過非依舊存在」，是因為凡夫內心的惑業尚未破除，虛妄的業力隨時生起；傷害眾生、砍折草木的心始終沒有止息。第三句「兩者俱存」，是說凡夫面對當前的境界，能造惡的心與所造的境兩者都依然存在。第四句當中，所謂「不相同」，例如最初的四波羅夷罪，稱為僧尼共戒；後面的四重罪，比丘尼有而比丘沒有；故出精、摩觸、說麤惡語、讚歎自身索供等戒，比丘有而比丘尼沒有，稱為僧尼不共戒。例如比丘變性為比丘尼時，摩觸等戒所緣的境界不再是自己所要防範的對象，自己也沒有了比丘那種能防範的身分，所以說能防所防「全都謝滅」。這一句所論述的謝滅，與前面所說動作停止的謝滅不同，互相比較便能清楚。

【263-0006】資持記/07b_中一下#33
【原文】次明非情中，初文。論約大千者，據宗限也；下文多云法界，其語猶通；須約大小簡辨寬狹，此意常切知之。罪福，即善惡也。《善生》中。且舉無情，四義，如下配戒中。以下，結勸。可知。三情境中。阿鼻非想，別舉上下，統攝中間。可不可者，或約三世；可即現在，不可即過未；
【譯文】接著說明「無情境」，第一段文字中：論典以「大千世界」來作界定，是依據該宗派教理的局限；下文多次提到「法界」，語意就比較寬廣圓通；必須依據大乘或小乘的教義來簡別寬狹，這個要點應當隨時精準掌握。所謂「罪福」，就是惡業與善業。《善生經》中，姑且舉出無情境的四種涵義，下文會將它們配屬在戒法中。自此以下，是結尾的勸勉，道理十分明確。在第三「有情境」當中：阿鼻地獄與非想非非想處天，是分別舉出三界的極下與極上，以此統攝中間的所有世界。所謂「能加害與不能加害（可不可）」，也可以從三世來論：能夠加害的指現在世，不能加害的指過去與未來世；

【263-0007】資持記/07b_中一下#34
【原文】又現在中，五道相隔；又人中，遠近不及；又近中，凡聖可否等。乃至者，略淫盜也。如來者，獨指釋迦；亦當分義，大取恒沙。三因緣者，即三善也。又下，結歎。通五眾者，境量同故。戒德瓶者，即喻受體；《智論》云：持戒之人，無事不得；破戒之人，一切皆失；譬如有人，常供養天，以求富貴；
【譯文】又在現在世當中，五道輪迴彼此隔絕；在人道當中，遠方與近處的力量所達不到；在身邊近處當中，凡夫與聖人的境界是否能夠觸及等等。「乃至」一詞，是簡略帶過了淫戒與盜戒。「如來」，在小乘單指釋迦牟尼佛；這也是就小乘本分的教義而言，若依大乘則通指恆河沙數諸佛。「三種因緣」，就是指無貪、無瞋、無癡三善根。「又」字以下，總結讚歎。說「通於五眾」，是因為五眾所面對的戒境廣度是完全相同的。「戒德瓶」，就是用來比喻戒體；《大智度論》說：持戒的人，沒有什麼善願不能達成；破戒的人，一切功德全都喪失；這就好比有人長期供養天神以祈求財富富貴；
