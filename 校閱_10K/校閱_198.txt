# 校閱材料　第198檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【198-0001】01_行事鈔/09a_卷下之一#42
【原文】二明作法攝衣界。其自然攝衣界十五種不同，如〈隨相〉中；此但明加羯磨者，大義如鈔別疏。今略明之：一切大界，凡有三種。若界大無伽藍，但有住舍，此須結之；謂僧院外勢分內得護衣，勢外界內不免失衣。二界與伽藍等，及界小於伽藍，此二不須結；結竟院外勢分內，反成失衣故也。諸家立法不同，有立無村結法者。今解，不問有無，並須結之；以結除其妨難故。若有村者，現除懸結；若無村者，現結懸除。以先結成故。直由染礙、情礙、隔礙、界礙故失衣；不由村來去，便令衣界增減也。此是定義，《五分》等律明文，任情量取。《薩婆多》中，所以除者五義：一聚落不定，衣界是定；二為除誹謗，為除鬪諍，為護梵行等。《四分》中初結衣界，界有村住；後因有事，方言除之。加法：「大德僧聽！此處同一住處，同一說戒。若僧時到僧忍聽：結不失衣界，除村、村外界。白如是。」「大德僧聽！此處同一住處，同一說戒，今僧結不失衣界，除村、村外界。誰諸長老忍：僧於此處同一住處同一說戒，結不失衣界，除村外界者，默然；誰不忍者，說。僧已忍，此處同一住處同一說戒，結不失衣界，除村村外界竟。僧忍，默然故。是事如是持。」解衣界法，文云：「大德僧聽！此住處同一住處，同一說戒。若僧時到僧忍聽：今解不失衣界。白如是。」「大德僧聽！此住處同一住處同一說戒，解不失衣界。誰諸長老忍：僧同一住處同一說戒，解不失衣界者，默然；誰不忍者，說。僧已忍，同一住處同一說戒，解不失衣界竟。僧忍，默然故。是事如是持。」
【譯文】第二、說明透過作法結界來收攝衣服的結界法（攝衣界/不失衣界）。至於天然形成的自然攝衣界共有十五種不同類型，正如〈隨相釋罪篇〉中所說；這裡只說明透過僧團羯磨作法所結定的攝衣界，其深廣宏義詳見本《鈔》的其他別疏之中。現在概略說明如下：一切僧團大界，大體上有三種情形。如果所結的大界範圍很大卻沒有正式的僧伽藍（寺院），只有個別的散住僧舍，這種情況必須結攝衣界；因為若不結界，就只能在僧舍之外、勢分之內保護衣服，而在勢分之外、大界之內依然免不了會失衣（結界則能使全界通體護衣）。第二種是大界與僧伽藍範圍相等，以及第三種大界範圍小於僧伽藍，這兩種情況都不需要結攝衣界；因為如果結了界，在僧院之外、勢分之內，反而會變成離衣失衣的緣故。各家律師立論規範不同，有人立論主張沒有村落時才使用結攝衣界之法。現在我的見解是：不論有無村落，都必須結攝衣界；因為結界是為了遣除各種防礙與難緣的緣故。如果有村落存在，應當在當下劃除村落、懸空預結；如果暫時沒有村落，便在當下結定、預先劃除未來可能出現的村落。因為結界必須預先成就的緣故。比丘只會因為染礙（貪愛執著）、情礙（心生疑慮）、隔礙（阻隔阻礙）、界礙（界域阻隔）而喪失法衣；絕不會因為村落的建立或遷移，就隨之使攝衣界產生增減變化。這是定論準則，在《五分律》等各部律典中有明確的文字記載，聽憑各自的心量加以酌取。《薩婆多論》中提到排除村落的五種含義：第一、聚落的存滅是不固定的，而攝衣界是固定不變的；第二、為了消除俗人的譏嫌誹謗，第三、為了免除爭執鬥諍，第四、為了護持出家人的清淨梵行等。《四分律》中起初結攝衣界時，界內是有村落民居的；後來因為產生了事端，才指示在結界中將村落排除。羯磨加法白文如下：「大德僧聽！此處屬於同一個住處，同一個說戒羯磨之處。如果僧眾時機已成熟，僧眾聽許：在此結立不失衣界，排除村落及村落外勢分的結界。單白如是。」「大德僧聽！此處屬於同一個住處，同一個說戒羯磨之處，如今僧團結立不失衣界，排除村落及村落外勢分的結界。哪些長老贊同：僧團在此同一個住處、同一個說戒羯磨之處，結立不失衣界，排除村落及村落外勢分者，請保持默然；哪一位不贊同者，請說明。僧團已經贊同，在此同一個住處、同一個說戒羯磨之處，結立不失衣界，排除村落及村落外勢分完畢。因僧眾贊同而默然故。這件事就這樣遵照奉持。」解除攝衣界的羯磨法，文句說道：「大德僧聽！此住處屬於同一個住處，同一個說戒羯磨之處。如果僧眾時機已成熟，僧眾聽許：如今解除不失衣界。單白如是。」「大德僧聽！此住處屬於同一個住處，同一個說戒羯磨之處，如今僧團解除不失衣界。哪些長老贊同：僧團在此同一個住處、同一個說戒羯磨之處，解除不失衣界者，請保持默然；哪一位不贊同者，請說明。僧團已經贊同，在同一個住處、同一個說戒羯磨之處，解除不失衣界完畢。因僧眾贊同而默然故。這件事就這樣遵照奉持。」
