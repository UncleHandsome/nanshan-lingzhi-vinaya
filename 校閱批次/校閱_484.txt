# 校閱材料　第484檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【484-0001】資持記/09b_中三上#56
【原文】《五分》草瓦板等皆可為覆，此多用瓦；應取縱橫三行，即為三節。如疏廣之。四中。問：《戒本》過三方犯，此言竟者？答：戒制指授；三節未竟，若去非過；看竟即過。此據看過，非三節過。不犯者。注戒云：如上指授，遠離見聞，即不犯。二十一。〔佛在舍衛，愛道請教授；佛令僧次，六群次往說世論因制。〕名中。
【譯文】《五分律》記載用草、瓦、木板等各類建材都可以用來做屋頂覆蓋，中國本地多數習慣使用磚瓦；應當採取橫直各鋪設三行磚瓦，這就算作是三節。詳細情況如同《戒疏》所發揮闡述的。第四個條件中。有人問：《戒本》規定必須「超過三層」才算犯戒，這裡為什麼說「看著工人鋪蓋完畢」就結犯？回答：這條戒的核心是禁制在現場指點教導他人施工；如果三節工程尚未鋪完，此時比丘若是抽身離去就不算過失；如果一直監督看到完工，那便構成了過錯。這純粹是就比丘「監督看工過程」逾矩來論斷，並非單純指屋頂「超過了三層工序」本身。不犯戒的情況。戒本的注文說：如果按照上述規範指點教授工人，並且自身遠遠脫離了視線與聽覺範圍，這樣便不犯戒。第二十一條戒律〔佛陀住在舍衛城時，大愛道比丘尼前來懇請佛陀派遣僧人去為尼眾教授訓誡；佛陀命令按照僧倫戒臘的次序輪流前往，六群比丘輪到前往時，卻只對尼眾宣說世俗荒誕的言論，佛陀因而制戒〕。戒名之中。

【484-0002】資持記/09b_中三上#57
【原文】不差擅往，故云輒也。緣中。疏列五種，前加佛開說法八敬，餘四同此。初不差者，律制白二僧法差往。二中。疏云簡別房別說不犯。釋中，初文，前明教誡。說法八敬者，律云：非教授日說八敬，吉；僧不差，與說法，墮。古師執文，謂日非說敬，二吉；不差說法，二提；今師不爾，日非故吉；
【譯文】未經僧團羯磨差派而擅自前往，所以稱作「隨意擅自（輒）」。犯戒條件中。《戒疏》列出了五種要件，在最前面加上了「佛陀開許為尼眾宣說佛法及八敬法」，其餘四項與這裡相同。第一個要件「未受差派」，指律典嚴格規定必須經過「白二羯磨」的僧團法定程序差派才能前往。第二個要件中。《戒疏》說排除掉在另外的個別房間作個別的私人開示，這樣的情況不犯這條戒。解釋的文句中，第一段文字，前面先說明何謂教誡。所謂宣說佛法與八敬法，律文說：如果不是規定的教授之日卻前去宣說八敬法，犯輕微罪（吉羅）；未經僧團合法差派，卻擅自前去為尼眾說法，犯墮罪（提罪）。古代律師死板執著於字面，誤以為「日子不對卻宣說八敬法」這算犯了兩種吉羅罪；「未經差派卻擅自說法」算犯了兩種提罪；現在的法師則不贊同這種看法，認為「日子不對」本身是犯吉羅的關鍵；

【484-0003】資持記/09b_中三上#58
【原文】不差故提；八敬說法，文中互列。故知受差日非，說二俱吉；不差輒教，二亦俱提。如彼廣之。〔八敬名相，如尼篇列。〕次明日非。引《僧祇》者，律無文故。前三者，彼云時未至也。注中，後三日即十六十七十八。〔黑月說戒，即初一初二初三。〕後二者，彼云過時。
【譯文】「未經合法差派」本身才是犯提罪的關鍵；八敬法與普通佛法，只是在文句中交互列舉指稱而已。由此可知受了僧團合法差派但在非規定的日子前往，不管是說八敬法還是說普通佛法，兩者都同樣只犯吉羅罪；若是完全沒有受過差派卻擅自前去教誡，那麼不管是說八敬法還是說佛法，兩者也同樣都要結犯提罪。詳細道理如同那部論疏中所充分開展的〔有關八敬法的各項名相內容，在後面的〈比丘尼篇〉中有詳細列舉〕。其次說明非規定日子的定義。這裡引用《僧祇律》，是因為本部律典中沒有明文界定。前三日，該律說是教誡的時間還沒有來到。注文中，所謂後三日就是指農曆十六、十七、十八這三天〔如果是在黑月半月說戒，那就是指初一、初二、初三這三天〕。所謂後二日，該律說這已經超過了教授的時間。

【484-0004】資持記/09b_中三上#59
【原文】注中去猶至也。二日，即二十九、三十日。〔白月即十四十五。〕又云：無間黑白，中間十日當往。〔白月十九至二十八，黑月初四至十三。〕次科，上明廣法稀行；今下，指略法如別。十德如〈說戒篇〉。二十二。〔佛在舍衛，難陀僧差往教授已，愛道重請至暮；尼出祇桓，還至舍衛；
【譯文】注文中「去」字的意思就等同於「至」。後兩日，就是指農曆二十九日與三十日這兩天〔如果是在白月半月說戒，那就是指十四日與十五日這兩天〕。該律又說：不論是黑月還是白月，中間相隔的十天才是比丘應當前往教誡的合法日子〔白月期間是指十九日到二十八日，黑月期間是指初四到十三日〕。在下一科中。上面說明的是完整的長篇教誡儀軌，在日常中極少舉行；「今」字以下，指示簡略的教誡儀軌則另有專文。合格教授師應當具備的十種德行，正如〈說戒篇〉中所詳細記載的。第二十二條戒律〔佛陀住在舍衛城時，難陀比丘受僧團差派前去教授完畢，大愛道比丘尼一再熱情挽留請法直到天黑；比丘尼們離開祇桓精舍，返回舍衛城時；

【484-0005】資持記/09b_中三上#60
【原文】城門已閉，宿城塹中，俗譏故制。〕疏云：本在僧寺，因過方制，令往尼寺。緣中可見。列緣中。初緣，以不差者，但犯前戒。釋中兩節，初約法簡。若問即問義。餘事，離上諸緣，通收一切，遷延及暮也。疏云：餘誦受經至暮譏同，如何輕者？以教授有法，集尼易故重；
【譯文】城門已經關閉鎖上，尼眾只得夜宿在城牆外的護城壕溝中，引來世俗之人的非難與譏嫌，佛陀因而制戒〕。《戒疏》說：起初教誡本來是在僧眾的寺院裡舉行，正是因為發生了這起夜歸宿溝的過失，後來才重新制定，規定比丘必須親自前往尼寺去施行教誡。因緣之中事實看得很清楚。列出的條件中。第一個條件，因為若是根本未受僧團差派的人，就只會直接違犯前面那一條擅自教誡戒了。解釋的文句分為兩節，首先從所講授的法義內容來篩選區分。所謂「若問」就是指尼眾提出經義來問難。所謂「其餘事務」，是指除開上述正規因緣之外，總括收納了一切閒雜事由，以致拖延耽擱直到夕陽西下天黑。《戒疏》說：其餘像是一起誦經、傳授經文而拖延至天黑，引來的世俗譏嫌是完全相同的，為什麼定罪卻比較輕呢？這是因為正規教誡具有嚴肅的法制軌範，聚集召集尼眾特別容易，責任重大所以結犯重罪；

【484-0006】資持記/09b_中三上#61
【原文】餘無攝法故輕。除尼下，次約人簡。亦具上四，略舉受經。文脫等字，注戒有之。不犯中。且列六段。初是順教。除下，次對男子，此開吉罪。三船濟處，四與客行，二並別緣，尼因聽故。五至尼寺者，由本緣起，尼來僧寺，故有此開；若取後制，應非開也。六因人請，此亦僧寺；
【譯文】其餘事務缺乏這種強大的號召攝受法制，所以結罪較輕。「除尼」以下，其次從受教誡的人員身分來篩選區分。同樣必須具備上面所說的四種法義，此處僅僅簡略舉出接受經文教授這一項。文字中脫漏了一個「等」字，在戒本的注文中是保有這個字的。不犯戒的情況中。暫且列出六個段落。第一種是完全順從遵照佛陀的教敕。在「除」字以下，其次是面對世俗男子，這項開許可以免除原本的吉羅小罪。第三是在乘船渡河渡江的場所，第四是與其他外來客人結伴同行之時，這兩者都屬於偶發的特殊因緣，比丘尼只是順道在一旁聽聞法義而已。第五種是親自來到比丘尼寺院，這是因為最初的制戒緣起，是比丘尼主動來到比丘僧寺才釀成過失，所以才有此項在尼寺說法的開許；若取後來的重新制戒，這恐怕就不能算作開許條款了。第六種是因為他人熱情主動請法，這種情況也是發生在比丘僧寺之中；

【譯文】在文義解釋中，本律首先說明了比丘尼讚歎的情狀。前兩句是指十二頭陀苦行，此處只概略舉出最初與最後的三種苦行，所以用了「乃至」一詞。在稱讚的下文，列出了四種名相，內容顯而易見。接著在解釋食物時，首先說明了正餐時段的食物。義疏指出，早晨與中午兩餐正食受請都算犯戒。「除」字以下，說明其餘的物品。義疏解釋：衣物判罪較輕，是因為大眾對財物執著難捨，而燈油等物品價值微薄的緣故。《僧祇律》將此分為七種情況，第一句是緣起。那是因為長者看見年長德高的比丘，便準備食物前來供養；有位比丘尼在旁張羅協助，前往請示並稟報時間已到、可以行食等等；

【原文】比丘疑不敢食，乃至白佛，佛聽除舊檀越。此明元是舊識，非因彼歎而致請故。二乃至下，彼云：有唱供時歎，始下食時歎，初作食時歎，作食辨已歎，有請時歎，此五並以更有至墮等文該之。今舉二種，故云乃至。前云更有比丘非歎不犯；復言此是頭陀，正歎故墮。
【譯文】比丘心生疑慮不敢進食，乃至向佛陀稟白，佛陀這才開許若原本就是舊有的施主則不在此限。這是說明施主本來就是老相識，非因那位比丘尼的讚歎才發心迎請。第二項從「乃至」以下，《僧祇律》說：有在唱導行供時稱讚的，有剛開始分發食物時稱讚的，有最初製作食物時稱讚的，有食物烹調完畢時稱讚的，有剛發起迎請時稱讚的，這五種情況都被「更有乃至墮」等經文全數涵蓋。現在僅舉出其中兩端，所以說「乃至」。前文說如果有其他比丘在場、並非因受讚歎而得食則不犯；又說如果說「這位是修苦行者」，正因為當場讚歎的緣故所以結墮罪。
