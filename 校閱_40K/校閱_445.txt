# 校閱材料　第445檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【445-0001】03_業疏/19b_卷四之二#107
【原文】僧祇》令掃塔院僧院，內香汁灑地，散華香等，故律中莊嚴說戒堂也
【譯文】《摩訶僧祇律》令清掃塔院與僧院，在室內以香水灑地，散布名花香料等，所以律中要莊嚴說戒堂。

【445-0002】03_業疏/19b_卷四之二#108
【原文】四中，掃灑香華，示非常務，發動物心，尊法重道也
【譯文】在第四科中，清掃、灑香水、散名花，是顯示這並非尋常的事務，以此啟發動轉眾人之心，尊重戒法而崇重聖道。

【445-0003】03_業疏/19b_卷四之二#109
【原文】問：僧說戒者，一人秉說，餘皆默坐；下至對首，皆各表淨者？答：僧法位強，成辨力大，故白說戒通四方故；別人力弱，但表內淨，應上教也，何得一說餘同坐默
【譯文】問：僧中說戒時，是由一人主持宣說，其餘人皆靜默而坐；降至對首法時，為何每個人都要各自表述清淨呢？答：僧法在位次上威權重大，成辨羯磨的力量廣大，所以作白說戒能通達於十方大眾；個人的力量微弱，只能表達自己內心的清淨，以此順應前述僧法之制，哪裡能一人宣說而其餘人一同默坐呢？

【445-0004】03_業疏/19b_卷四之二#110
【原文】次法問中，欲彰僧別二法優劣。答文初明眾法通收，本攝僧故；別下次明對首為別，旦表淨故。上教即僧法
【譯文】在接下來的問答中，旨在彰顯僧法與別法二者的力量優劣。答文首先說明大眾僧法通體統收，因為本來就是為了統攝僧眾；自「別」以下，說明對首法屬於個別之法，僅在於陳表個人內心清淨。「上教」即是指僧法。

【445-0005】03_業疏/19b_卷四之二#111
【原文】心念說中，如文可知
【譯文】在心念說戒的內容中，如律文所述即可明白。

【445-0006】03_業疏/19b_卷四之二#112
【原文】僧祇》文如《四分》，若無客者作念：若得清淨比丘，罪如法除。念已，當心念口言三說布薩。此即向四方僧發露，大如僧中，如《五百問》中文具列者是也。縱使三人，亦準為法
【譯文】《摩訶僧祇律》的文字與《四分律》相同，若沒有客比丘到來，就應當作念：「若得見清淨比丘，我的罪過當如法除滅。」作念之後，應當心念口言三番陳說布薩。這也就是向十方僧發露，大體如同在僧眾中一樣，正如《五百問經》文中所具體列出的一樣。縱使只有三人，也以此為基準而作法。

【445-0007】03_業疏/19b_卷四之二#113
【原文】三心念釋中，初引《僧祇》，無客來者，顯獨作故。先作念發露，後方陳詞。此下合《五百問》。縱下例通對首，謂罪須僧懺，待眾不滿，亦先發露，然後互說
【譯文】在第三心念說戒的解釋中，首先引用《摩訶僧祇律》說「無客僧來者」，是顯明獨自一人作法的緣故。先心念發露，然後才陳述文詞。自「此」以下會合《五百問經》。自「縱」以下例行通達於對首法，是指所犯之罪原本必須向僧眾大眾懺悔，但在等待大眾人數不足之時，也應當先發露罪過，然後再相互宣說布薩。

【445-0008】03_業疏/19b_卷四之二#114
【原文】懺說戒相由常作故，即是住持，莫不折伏慢幢，崇仰至教，分傾煩惱
【譯文】懺悔與說戒的事相由於常常修作的緣故，就是正法住持的體現，無不能夠折伏高傲的慢幢，崇敬瞻仰無上的聖教，分分傾覆摧破心中的煩惱。

【445-0009】03_業疏/19b_卷四之二#115
【原文】次科，初句徵起何故說戒先須懺露。由下釋通：初二句示說戒意，謂半月常作，頻令洗懺，戒品既淨，定慧乃明，即住持相。莫下明懺露意，慢幢即人我，至教即戒法，伏我仰法，聖道可期，故傾煩惱。且據兩凡，故云分也
【譯文】其次一科，第一句徵問發起：為什麼說戒之前必須先懺悔發露？自「由」以下解釋導通：前兩句開示說戒的用意，說明半月經常修作，頻頻洗滌懺悔，戒品既然清淨，定慧之光自然明朗，這就是佛法住持的相貌。自「莫」以下說明發露懺悔的深意：「慢幢」是指人我執著之傲慢，「至教」是指如來戒法；折伏我執慢心、尊崇仰戴戒法，聖道即指日可期，所以能傾覆煩惱。這暫且就內外二凡夫位而言，所以說「分」。

【445-0010】03_業疏/20a_卷四之三#1
【原文】釋安居篇。
【譯文】解釋〈安居篇〉。

【445-0011】03_業疏/20a_卷四之三#2
【原文】篇目中「諸眾」者，若就人明眾，即五眾也；若約位明眾，即對、念也；若約法多明眾，即前、中、後、對、念、忘及等，並見文中。「安居」如下自釋。
【譯文】篇目中所說的「諸眾」：如果就人而言「眾」，就是指五眾出家人；如果就作法的位次而言「眾」，就是指對首、心念；如果就法式的多樣而言「眾」，就是指前安居、中安居、後安居、對首、心念、忘成以及及界等，都見於下文中。「安居」二字，如下文自行解釋。

【445-0012】03_業疏/20a_卷四之三#3
【原文】出家慕道，馳散非業，故當計時擇念，義無浮逸。今乃㳂隨邑野，追逐情塵，顛仆巨壑，無思返迹。是以大聖以法遮防，不許遊涉，當居靜慮，故律文中三時通制。
【譯文】出家修道是為了欣慕聖道，奔波馳求散亂絕不是正業，所以應當珍惜分秒光陰、簡擇心念觀照，義理上絕不可浮躁放逸。如今卻往往遊走於城鎮村野，追逐情欲塵勞，顛覆跌落於業報的巨大深壑之中，全無思量回頭之意。因此偉大的聖者以戒法遮止防範，不許隨便遊行跋涉，應當安居靜修思慮，所以律文中對春、夏、冬三時都通通有所禁制。

【445-0013】03_業疏/20a_卷四之三#4
【原文】敘意中初科，初敘所應。「計時」，謂惜分陰不虗度也；「擇念」，謂專心觀行離妄緣也。「今」下明不應，邑野即城邑村野，逐情塵者營世務也，巨壑喻現業來報。「是」下示制意，準通三時，知開非意。此據上根絕世之流，單坐夏時，乃被中下，況俱不坐，何足議哉！
【譯文】敘述立意中的第一科，首先敘述出家之人理所應為的事。「計時」，是指珍惜一分一秒的光陰而不虛度；「擇念」，是指專注於觀行而遠離虛妄外緣。自「今」以下說明不應該做的事：「邑野」即是城鎮村落，「逐情塵」是指經營世俗事務，「巨壑」比喻現世造業所引生的來世惡報。自「是」以下指示制戒的意圖；依照通制三時之說，可知開許出遊並非佛陀的本意。這是依據斷絕世務的上根之流而言；僅在夏季安居，乃是為了普被中下根機之人；何況如果春夏冬三時都不安居，那還有什麼可談的呢！

【445-0014】03_業疏/20a_卷四之三#5
【原文】然有待之形，託緣不一，必量過起，夏暑偏多：一則損生害命，深乖慈道；二、招世譏謗，不及禽獸；三、為過既深，故非道業。春冬過少，待緣開赴，有斯別故，名曰安居。
【譯文】然而需要衣食資助的這個色身，依託的世緣各不相同；如果衡量罪過的生起，夏季暑熱之時偏偏最多：一是損傷草木生靈、殘害微細性命，深深違背大慈之道；二是招致世人的譏嫌毀謗，被指斥為連飛禽走獸都不如；三是造作的過失既然深重，所以根本不是修道之業。春冬二季過失較少，等待因緣方開許前往，有這些差別緣故，所以名為「安居」。

【445-0015】03_業疏/20a_卷四之三#6
【原文】次科。「託緣不一」，世緣無定，不可常故。「損生命」者，夏月地多蟲故。「招世謗」者，如緣起說，彼云：蟲鳥尚有巢窟，故曰不及禽獸。春冬止有第三，故云過少
【譯文】其次一科。「託緣不一」，是指世俗因緣無有定準，不可恆常執持。「損生命」，是因為夏月大地上多有蟲蟻滋生。「招世謗」，正如緣起文中所說，外道譏嫌說：連蟲鳥尚且有自己的巢穴，所以說比丘不及禽獸。春冬兩季只有第三種妨害道業的過失，所以說過失較少。

【445-0016】03_業疏/20a_卷四之三#7
【原文】釋名者，形心攝靜曰安，要期在住曰居也
【譯文】解釋名稱：身體與內心收攝歸於靜寂稱為「安」，要約約期定在一處止住稱為「居」。

【445-0017】03_業疏/20a_卷四之三#8
【原文】釋名中，形心攝靜，無雜緣故；要期在住，無奔馳故
【譯文】在解釋名稱中，「身體與內心收攝歸於靜寂」，是因為沒有雜亂的攀緣；「約期定在一處止住」，是因為不再到處奔波奔馳。

【445-0018】03_業疏/20a_卷四之三#9
【原文】就文分二：初明住法，後出界法
