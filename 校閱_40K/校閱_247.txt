# 校閱材料　第247檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【247-0001】資持記/05b_上四#33
【原文】不說序略，準《注羯磨》乃依《僧祇》；中間各題通結，自出《母論》，故後文云《四分》文不了等。〔古記反引本宗十五略配之，致增迷昧，《注羯磨》亦云：律有三五略法，文非明了，故依《母論》，故知非也。〕以昔多迷，不免繁細；餘所未盡，備在釋中。略法中，初科。
【譯文】不說序文就直接簡略的作法，依照《注羯磨》則是依據《僧祇律》；中間各篇分頭標提篇名而作總結，是出自《毘尼母論》，所以後文才說《四分律》文義不明了等等。〔古代的撰記反而引述本宗的十五種略法來硬加湊配，這只會徒然增加迷茫困惑，《注羯磨》也說：律藏雖然有三組五種略法（共十五種），但文句並非明白清楚，所以必須依憑《毘尼母論》，由此可知舊說是不對的。〕因為古人多有迷惑，所以不得不在這裡詳盡辨析；其餘未曾說盡的意思，全都完備地收在下文的注解中。在簡略儀式（略法）中，第一科。

【247-0002】資持記/05b_上四#34
【原文】緩急兩相，事在高座；緩則可進，急則宜否；並準上緣，須令應教。文中，初雙標。緩下，牒釋。急緣語通多種，如下所明。別顯中，初文，初指前緣。即十緣中上九種也。說竟儀式，亦同廣法；由緣不定，多不至後，故且指前。至下，示略法為三；問清淨已者，即廣前序也。應言下，略中間七篇。
【譯文】寬裕與緊急這兩種情況，全在於高座上的戒師臨機掌握；情勢從容就可以推進詳誦，情勢急迫就應當及時中止；這一切都必須比照上面的事緣，務必使儀軌契合佛陀的教敕。在經文中，最初是雙雙標出。從「緩」字以下，是分別解釋。所謂「急緣」一詞通指許多種類，如同下文所說明的。在特別顯發（別顯）中，第一篇文字，首先指出前面的事緣。也就是十種事緣中排在前面的九種。說戒完畢時的儀式，也與詳盡的廣法相同；由於事緣隨機不定，多數無法堅持進行到最後，所以暫且先指明前面部分。從「至」字以下，是將簡略方法分為三項；所謂「問清淨已」，就是將前面的戒序作了詳盡廣讀。從「應言」以下，是簡略中間的七篇戒條。

【247-0003】資持記/05b_上四#35
【原文】言各題者，七名別舉也。通結者，並云僧常聞也。七滅下，廣後文也。不略七滅者，戒少言約，復接後文，是可說故。若準《尼鈔》，八並通略；無勞臆說，以誤來蒙。故疏云：今有行略，多無法式；就緣緩急，稱時為要；常途寒熱，容所敘致，可廣始終〔前序及七滅已下也〕，而略中廣〔即七篇也〕；
【譯文】所謂「各題」，是指七篇的名目分別舉出。所謂「通結」，是指每一篇都統一說「僧眾平日所常聞」。從「七滅」以下，是將後面的文句全部廣誦。之所以不省略七滅諍法，是因為該法戒條極少、文字約簡，又能直接承接後面的迴向文，所以是完全可以讀誦的。如果依照《尼鈔》，那麼八篇全都可以通用簡略；實在不必徒勞地妄加揣度，以致誤導未來的後學。所以戒疏中說：如今推行略法，多數人毫無法度軌則；其實全憑事緣的緩和與緊急，以契合當前時局為最要緊；平常的嚴寒酷暑，尚有從容交代敘說的空間，這時可以廣誦始尾〔即前序以及七滅諍以下〕，而唯獨簡略中間那段篇幅極廣的條文〔也就是那七篇〕；

【247-0004】資持記/05b_上四#36
【原文】準此明據，豈復疑乎。《四分》下，指所出，初點本律。不題篇首，故云不了。今下，取他文。即指上法有誠據也。本律〈說戒犍度〉，初明先廣後略次第八段；彼云：比丘作是念，今以難緣聽略說戒，難來猶遠，我等得廣說；彼比丘應廣說，不說如法治。〔下七例此作之。〕又云：我曹不得廣說，可說至九十；
【譯文】依照這樣明白確鑿的證據，哪裡還需要懷疑呢！從「四分」以下，是指明出處來源，首先點評本宗的《四分律》。由於它沒有在篇首單列題綱，所以才說文意「不了（不夠清晰）」。從「今」字以下，是採納其他論典的文字。也就是指明上述這套作法具有真實可靠的依據。本律〈說戒犍度〉中，先是說明先廣後略的連續八個段落；那裡說：比丘心中這樣想，如今因為危難事緣雖然聽許簡略說戒，但危難距離尚遠，我們還可以詳盡廣說；那位比丘就應當詳盡廣說，若不廣說就依照戒法加以處分。〔後面七個段落比照這條體例進行。〕又說：我們不能全部廣說，可以廣說到九十單墮戒為止；

【247-0005】資持記/05b_上四#37
【原文】又云：不得說九十，可說至三十；又云：不得說三十，可說至二不定；又云：不得說二不定，可說十三；又云：不得說十三，可說四事；又云：不得說四事，可說戒序；又云：不得說序，即從座起去。〔次第八段，前一是廣，後七是略，古人妄傳為七略一直者，非也。
【譯文】又說：如果不能說到九十，可以說到三十捨墮戒為止；又說：如果不能說到三十，可以說到二不定法為止；又說：如果不能說到二不定，可以說到十三僧殘法為止；又說：如果不能說到十三，可以說到四波羅夷法為止；又說：如果不能說到四波羅夷，可以說到戒經序文為止；又說：如果連戒序都來不及說，就應當立即從座上起立離去。〔這井然有序的八個段落，前一個是廣法，後面七個是略法，古人妄加流傳說是七種略法加一種直說法，那是錯誤的。〕

【247-0006】資持記/05b_上四#38
【原文】後明先略後廣三五說戒，彼云：有五種說戒：一說序已，餘者應言僧常聞〔已下並從說序去，一一皆以餘者等結之。〕；二至四事；三至十三；四至二不定；五廣說〔三十已後〕。復有五種：一說序四事已，餘者略之；二至十三；三至不定；四至三十；五廣說〔九十已下〕。
【譯文】後來又說明先略後廣的三組五種說戒之法，那裡說：有五種說戒方法：第一是說完戒序之後，其餘篇章應當說「僧眾平日所常聞」〔從宣說序文開始，每一條都用「其餘的等等」這句話來作結尾〕；第二是說到四波羅夷法；第三是說到十三僧殘法；第四是說到二不定法；第五是全部廣說〔即三十捨墮戒以後全部誦出〕。復有五種：第一是說完戒序四事已，其餘的加以簡略；第二是說到十三；第三是說到二不定；第四是說到三十；第五是全部廣說〔即九十單墮戒以下全部誦出〕。

【247-0007】資持記/05b_上四#39
【原文】復有五種：一說序至十三；二至不定；三至三十；四至九十；五廣說〔提舍已下〕。律本甚廣，今云不了，明非正用；恐人未曉，略引令知。二中。且約說序竟，舉初例後。故《羯磨》云，應隨到處云：已說至某處，餘者僧常聞；
【譯文】復有五種：第一是說完戒序直至十三僧殘；第二是說到二不定；第三是說到三十；第四是說到九十；第五是全部廣說〔即提舍尼戒以下全部誦出〕。律藏原本文字極其浩繁，現在說它「不了（不明了）」，是為了挑明它並非眼下正用的法度；唯恐後人懵懂不解，所以簡略引述出來使大家明白。在第二段中，暫且是以宣說戒序完畢為例，舉出最初的例子來比照後面的情況。所以《羯磨》中說，應當隨著誦讀所到的段落說道：「已經說到某個篇章，其餘的篇目僧眾平日所常聞」；

【247-0008】資持記/05b_上四#40
【原文】又疏釋云：誦至隨戒，難卒排門，不可轉誦，故知通後也。三中。此出《僧祇》。〔古記將此為本律一直者，非。〕未說序者，謂作白纔竟也。問：必未作白，難至如何？答：不成略法，理須再說。或待難靜，或出界外；或眾或別，隨緣作之。結斷中，初結勸。
