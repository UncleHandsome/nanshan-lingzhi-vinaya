```python
def _split_col3(out):
    """切出第 3 欄（修正後的譯文）：回傳 (前段, 第3欄)。"""
    m = re.search(
        r'(?:^|\n)\s*[#*\s]*(?:第\s*)?(?:3|三)\s*(?:欄\s*[｜|：:]|[.、．：:])[^\n]{0,10}修正後的譯文[^\n]*\n?',
        out,
    )
    if m:
        return out[:m.end()], out[m.end():]
    matches = list(re.finditer(r'(?:^|\n)\s*【(?:疏文|鈔文)】', out))
    if matches:
        pos = matches[-1].start()
        return out[:pos], out[pos:]
    return '', out
```

```python
def _quota(text):
```

### 二、純「找碴專用」提示詞（`AUDIT_PROMPT`）

這份提示詞故意**不讓模型重寫整段譯文**（大幅減少輸出 token，也避免模型一邊想怎麼保留句型一邊漏錯），並強制把問題分成**必改硬傷**與**可斟酌微瑕**兩級，防止模型為了表現有做事而亂挑純修辭：

```python
2. **邏輯與條件**：有無主語人／物偷換、能所施受反轉、對仗或選擇問答失衡、擅改範圍（放寬／窄化），或刪除／漏譯前提與開遮條件。
3. **忠實與增刪**：有無漏譯、望文生義臆造詞義，或無據補入原文所無之實詞、程度詞與他書字眼（但依律脈補出省略關係、刪之反致違背律義之必要消歧義不計為錯）。
```

#### 2. 檢索怎麼開？（防二審亂燒錢）
* 二審這份提示詞**沒有長表格、也沒有第 3 欄全譯**，輸出本身會非常省；主要成本會落在**檢索次數**。
* 建議系統層把二審檢索限制收緊一點：
  * 固定上限 **`max_search = 2`、`max_fetch = 1`、`MAX_TOOL_ROUNDS = 4`**，`budget = 2`。
  * **觸發原則**：只有懷疑「律學專名（如名數、衣鉢界場制）、部別異同、疑似底本訛字或跨書引用有誤」時才搜；**純邏輯、語病、漏譯、對仗、疏記矛盾直接在內文判斷，不准為此呼叫搜尋**。

#### 3. 如何處理二審挑出來的 `FIX`？
跑完一批後，寫一段 10 行的篩選腳本掃描所有二審回覆：
* **`【結論】：PASS`**（通常佔 6～8 成）→ 直接放行定稿（最多人工抽檢 10%）。
* **`【結論】：FIX`**（約 2～4 成）→ 匯出成一份清單（包含：`原文` ＋ `一審譯文` ＋ `二審指出的必改硬傷`）：
  * 數量少的話，人工直接照二審建議 30 秒改完最準；
  * 數量多的話，可以把「原文＋一審譯文＋二審硬傷清單」餵回一次極短的**定點修訂呼叫（只修清單點出的那幾句，不重寫全段）**，再人工過目。
