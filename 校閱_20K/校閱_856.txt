# 校閱材料　第856檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【856-0004】03_業疏/14b_卷三之三#105
【原文】約律明趣，但說為三，謂人、非人及畜生也。以人、畜兩趣，形現易知；天、鬼、神等，幽通難識，故合天、修、鬼、獄四道為一趣也。莫不分得五通，異於人類，故號非人。故律中諸戒，時有離之，如同宿戒「天子、阿修羅子、餓鬼子」等；地獄輕繫，義應得同，從重者多，故輕不說。如此分別，略識非人
【譯文】就律典說明趣別而言，只說為三種趣，即人類、非人以及畜生。因為人與畜生這兩趣，形體顯露容易辨識；而天人、鬼、神等，冥通幽隱難以辨識，所以把天道、阿修羅道、餓鬼道、地獄道四道合併為一趣。它們無不部分具備五種神通，與人類不同，所以稱為「非人」。因此律中諸多戒條，有時也分別開列，比如同宿戒中說「天子、阿修羅子、餓鬼子」等；地獄道受輕微繫縛罪報的眾生，在義理上也應當相同，但因大多數都是重罪繫縛不能自由前來，所以對輕罪繫縛者便未予述說。經過這樣的辨別，便能大略認識非人的含義。

【856-0005】03_業疏/14b_卷三之三#106

【譯文】第二段中，首先指出律文。人趣與畜生趣各局限為一道，非人則合併了四道，所以只有三趣。從「以」字以下，其次開示合併與分開的用意。首先說明合併的用意。從「故律」以下，第二說明分開說明的用意。同宿戒雖然只開列了三趣，在義理上則收攝了地獄趣；隨後又指明律文不另說地獄的原因。

【譯文】在第三部分中，首先敘述錯誤之處。《觀音》就是指《普門品》中的天、龍、夜叉等天龍八部。認為因為頭頂長角所以稱為非人。「想」字以下，結語呵斥。世間有人畫鬼戴冠束帶如同人形，說是佛經裡的人非人；又訛傳辟支佛（獨覺）頭上長一隻角，畫婆藪仙人則形貌如老婦。望文生義而不明實情，自古至今都是如此。

【856-0014】03_業疏/14b_卷三之三#115
【原文】制列遮相，諸律竝同。及論難體，《十誦》、《五分》但問「曾為比丘，如法持、捨不？」此邊相也，餘悉不問；及至僧中，亦爾。《四分》亦同。如律中制十三難已，若不問者，不名得戒，故諸結者引之集坐，在遮前問。《僧祇》有二，所言略者：「今僧中當問，汝有無當答。」僧中一一問之，大如《四分》及諸遮相，不可抄盡，須者觀之。乃至問「曾為比丘，四重、十三事」，一一隨問；若有犯者，重則令去，殘令後悔
【譯文】規定列出遮相，諸部律典大體相同。至於論及十三難的本體，《十誦律》、《五分律》只問「是否曾作過比丘，是否如法持戒、如法捨戒？」這屬於邊罪之相，其餘的難一概不問；到了僧眾之中也是如此。《四分律》也是一樣。如律中制定了十三難之後，若不詢問，就不算得戒，所以各位編撰集錄羯磨之人將難引錄並集於一處，放在問遮之前詢問。《僧祇律》則有廣略兩種，所謂略法是說：「如今在僧中將會詢問，你有或沒有應當據實回答。」到了僧中則一一詳細詢問，大致與《四分律》相同，以及諸多遮相，無法全部抄錄，需要的人可自行閱覽。乃至問「是否曾作過比丘，犯過四波羅夷、十三僧殘事」，一一隨即詢問；若有犯者，犯重罪的就令其離去，犯殘罪的令其受戒後懺悔。

【856-0015】03_業疏/14b_卷三之三#116
【原文】次科，初、示遮同。「及」下，次、明難別。初、《十》、《五》二律屏處、僧中，止問邊相。次、《四分》亦同，謂差問、正問亦不列難。言諸結者，即集羯磨人，引難冠遮，依律具問。坐，猶著也。三、《僧祇》有二，謂廣、略也。廣則具問；略即如文，謂屏問時，但囑累而已。「下」指遮相，如《事鈔》備引。仍問篇聚，重是邊罪故令去，「殘」下非難故令悔，受已方悔，故云後悔也
