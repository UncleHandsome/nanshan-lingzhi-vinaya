# 校閱材料　第504檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【504-0001】資持記/05c_上四#47
【原文】言兩失者，依界依藍，各有一失一不失。即約本心有違不違；而非明文，故云義張也。法界多寬故緩，房處從狹故急。必有行人棲止大界，自意依房；捨緩從急，彌符教旨。遇緣去中。二難，即命梵為己緣，破和即為他緣。律中，本處因我住故破，他界因我往故和；為害事重，故並開之。
【譯文】所謂「兩失（兩種喪失）」，是指依止結界與依止僧園，各自有一種喪失、一種不喪失的情形。這都是依據行者當初的本心是否有違背來論定的；然而這並非律典的明文規定，所以說是「義張（依義理開展建立）」。如法所結的大界大多比較寬廣，所以情勢較為寬緩；個別房舍範圍狹小，所以情勢較為急迫。如果真有修道人棲息止步於大界之中，自己決心只依止於一間僧房；捨棄寬緩而遵從緊迫，這便更加契合戒律教法的深旨了。在「遇緣離去」之中，所謂「二難」，是指生命的危難與梵行的危難，這屬於自身的因緣；「破僧與和僧」，則屬於他人的因緣。律中記載，原住處所因為我留住的緣故而將發生破僧，他處結界因為我前往的緣故而能促成僧團和合；因為這牽涉到極為嚴重的損害，所以全都開許可以離去。

【504-0002】資持記/05c_上四#48
【原文】諍見僧壞，西土多然；此方罕有，故云希也。受日逢難，引文中，初是親緣。若下，即命難。律文佛判並言得歲。同上親留，故云同前。義決中。在文尤緩，恐致妄行，故須準急。初正決。二引證。可知。五中，迦提分三；初明時限。比謂無衣常開一月。二釋名義。引論翻名，注文釋義。三指廣。
【譯文】因為爭端執見而導致僧團破壞，西域印度經常發生這種事；但在東土華夏卻極為罕見，所以說是「希（罕見）」。在受日期間遭遇災難的引述律文中，首先是俗家親屬的牽纏之緣。「若」字以下，就是指生命的危難。律文記載佛陀的判定，都明說是「獲得一歲之夏」。這與上面被親屬強行挽留的情形相同，所以說「同前」。在義理決斷之中：律文的文字過於寬緩，唯恐導致有人肆意妄行，所以必須準照嚴急的標準來規範。首先是正面的決斷。第二是引證。其義理清楚易懂。在第五項中，受迦絺那衣（功德衣）分為三部分：第一是說明時間期限，這裡是指常規下如果沒有作功德衣，一般開許為期一個月。第二是解釋名稱與義理。引述論部翻譯其名稱，注文中則解釋其涵義。第三是指引參閱詳文。

【504-0003】資持記/05c_上四#49
【原文】問：下篇既廣，此何重示？答：若論受利，雖自恣後；然所獲利，全由夏功。又彰夏時四月制開分齊。又此論無衣，後約有衣。若爾，有衣受法，此何不明？答：行事次第，合在自恣後故。解界中。此章來意，為破古執以息後疑，非關夏限，故曰因明。
【譯文】有人問：後面的章篇既然有詳細說明，這裡為何又重複提示呢？回答說：如果就受取五種利養而言，雖然是在自恣之後；然而所獲得的這份利益，卻完全是憑藉一夏九十天的安居功德而來。再者，這也是為了彰顯安居時限在四個月之中，各項開遮制止的界限分齊。又此處是論述沒有獲得功德衣的情況，後面則是就受得功德衣而論。如果真是這樣，那麼有衣時的受納方法，這裡為何不明確解說呢？回答說：依照行事作法的先後次第，理應安排在自恣之後的緣故。在「解界（解除結界）」之中，這一章之所以出現，是為了破除古代的執著見解以平息後人的疑慮，與夏安居的九十天時限無關，所以稱為順帶說明（因明）。

【504-0004】資持記/05c_上四#50
【原文】以〈迦絺犍度〉中云：安居竟，有四事應作：自恣、應解界、應結界、應受功德衣；前引《母論》亦然；古師據比，故有妄釋。引古中，初出彼計。疏云：有人言：本依界故成安居，若解本界，便失夏也；以失所依，即日雖結，亦不成就；故文云安居竟應解界，未竟而解，故知非也。
【譯文】因為〈迦絺犍度〉中記載：夏安居結束後，有四件事應當作：自恣、應當解除結界、應當重新結界、應當受納功德衣；前面所引述的《毘尼母論》也是如此記載；古德律師依據這些文字，所以產生了錯誤的解釋。在引述古說中，首先列出他們的觀點。《業疏》說：有人主張：本來是因為依止結界才成辦安居，如果解除了本有的結界，便會喪失夏安居；因為失去了所依憑之處，當天縱使重新結界，安居也不能成就；因此律文說安居結束才應當解界，若尚未結束就解除，所以知道是不可以的。

【504-0005】資持記/05c_上四#51
【原文】此下，難破有四，初斥妄。律下，二顯正；初牒律文。為下，示意。但文非明顯，致令錯會；故準《十誦》德衣之文，方決疑壅。廣下，指彼三十五云：夏竟，眾多僧坊共結一界受功德衣已，捨是大界，諸比丘皆名受功德衣否？答：一切皆得受之。又下，三引證。舊記云，指首師《律疏》。
【譯文】「此」字以下，進行難問破斥，共有四點：首先斥責其妄說。「律」字以下，第二點顯發正理：首先宣讀律文。「為」字以下，說明立教的意圖。只是因為文字不夠直白明顯，才導致大家產生誤解；所以必須準照《十誦律》受功德衣的文字，才能徹底破除疑惑阻滯。「廣」字以下，指出該律第三十五卷說道：夏安居結束後，許多僧坊共同結為一個大界以受納功德衣，受納完畢後，又廢除了這個大界，請問諸比丘還算不算受納了功德衣？回答說：所有比丘全都算獲得了功德衣。「又」字以下，第三點引述典籍作證。過去的筆記說，這是指法首大師的《律疏》。

【504-0006】資持記/05c_上四#52
【原文】本非為夏，乃顯別有所為；文雖不示，義應同上。古下，四引難。古人云者，已為前代古德難破，今引用之，疏中標云有人言是也。前引律云安居竟應解界應自恣，二文不異，故引相並。然律通三日自恣，十四十五未竟皆成；及中後人隨前自恣，住待日滿；
【譯文】當時解除結界原本就不是為了夏安居的事，而是彰顯另有其他公務作為；文字雖然沒有明示，義理應當與上述相通。「古」字以下，第四點引述問難。所謂「古人云」，是指這在早先就已經被前代古德難破，現在予以引用，《業疏》中所標出的「有人言」指的就是這件事。前面引述律文說安居結束應當解界、應當自恣，這兩處律文並無不同，所以引來互相對比。然而律中通融自恣可在十四日、十五日、十六日三天舉行，在十四、十五日自恣雖未全滿但也都算成辦；以及中安居、後安居之人跟隨前安居之人自恣後，留住等待日數算滿；

【504-0007】資持記/05c_上四#53
【原文】用此相並，明知解結非破夏矣。文兼等者，不竟解結若云破，不竟自恣亦應破；自恣既不破，解結云何破！上句示文同，下句明義合；破則齊破，成則俱成，不可偏故。疏又難云：如在攝衣界中，護衣緣故須解，亦應失本所依，即日明離；然未經宿，不說離衣；夏亦同此，何得即破。〔前云：解界即日破夏，不待經宿，故有此難。
【譯文】拿這點相互比對，就能明確知道解界與結界絕對不是導致破夏的原因。所謂「文兼」等語，如果說夏未全滿就解界結界算破夏，那麼夏未全滿就先行自恣也應該算破夏；自恣既然不算破夏，解界又何以會算破夏呢！上一句說明律文句式相同，下一句說明箇中義理相合；若算破壞則應當一同算破壞，若算成辦則應當一同算成辦，絕不可偏執一端。《業疏》又責問說：如同在「攝衣界」之中，為了守護僧衣的因緣所以必須解除該界，照你們的說法這也應該喪失了原本所依憑的界，當天看見明相便算離衣犯戒了；然而只要還沒有在外過夜，律中絕不說是離衣犯戒；夏安居也是如此，怎能說解界當天就立刻破夏呢！（前面古德說：解界當天即刻破夏，不須等待過夜，所以道宣律師才提出這項問難）。

【504-0008】資持記/05c_上四#54
【原文】今解中，初二句判定。但下，明前後寬狹，初生起。若下，示相為二；初明依界前狹後寬。《僧祇》：避難界，縱廣三由旬。問：先廣後狹，為依何處？答：準下自然，亦應依本。從狹彌勝。若下，二明依藍。疏中，又有師云：自然中安居已，結界受日，失本自然，亦破夏也。

【原文】三中。古執三種次受，不得前後；今此反之。須知古師執法，故不許差；今師義緣隨緣即得，故不同也。釋疑中。即古所計，疏云：昔人云：先受七日，後便十五；以文云受過七日法故。答中。道謂口言，方俗之語，使人易解。三法半倍，半月倍七日，一月倍半月，故知文牒倍過之過。
【譯文】在第三項中，古人執著這三種期限必須依序受取，不得顛倒先後；現在此處則推翻這種說法。必須知道古德死執法條形式，所以不容許前後參差；而當前大師則是從義理因緣出發，主張隨所遇到的具體因緣即可隨機受取，所以看法有所不同。在「釋疑」之中，所解釋的正是古人的妄計，《業疏》說：過去有人主張：必須先受七天的法，之後才能受十五天的法；因為律文中有「受過七日之法」的詞句。在回答中指出：「道」是指口中宣說，這是世俗方言，為了使人容易聽懂。這三種法後後都是前前的倍數，半個月是七天的加倍（兩倍），一個月又是半個月的倍數，由此可知律文宣讀「過」，指的是倍數超過之意。
