# 校閱材料　第408檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【408-0001】02_戒疏/04b_卷一下之二#52
【原文】【疏】問：「異境若強，差我不殺，『強』是本境，『異』非罪者。異境忽弱，而被我害，未害之前，方便屬誰？若見異已去，別有方便，此則本境方便自立。若見異已去，無別方便，害異果罪，因還本境，若此立義，則無境差。」
【譯文】【疏文】問：「異境若是強大，阻止我行殺，既然『境強』是歸於本境，『異境』不構成犯罪。那麼若異境忽然轉弱，而被我殺害，在殺害之前，方便罪到底歸屬於誰？若是看見異境之後，另外生起方便，那麼本境的方便罪自當成立。若是看見異境之後，沒有另外的方便，殺害異境的果罪，其因仍是本境之因，如果依此立論，就根本沒有『境差』了。」

【408-0002】02_戒疏/04b_卷一下之二#53
【原文】【記】次、今釋中，初文分三。初牒前義。「異」下，反以境弱為問。「若見」下，雙難。初約有方便難，則本異兩境，皆有罪故。次以無方便難，則異境果成，本境因沒，故云「無境差」也。
【譯文】【記文】接著，在當前的解釋中，初文分為三部分。最初重提先前的義理。「異」字以下，反過來以境界轉弱來提問。「若見」以下，進行雙向詰難。首先就「另有方便」來發難，這樣一來本境與異境兩方都各有罪。其次就「沒有方便」來發難，那麼異境之果既然成立，本境之因隨之消滅，所以說「就沒有境差了」。

【408-0003】02_戒疏/04b_卷一下之二#54
【原文】【疏】今明正解。本境一品，齊是偷蘭。異境來差，人境緣人，有強有疑，莫不殺心，皆結蘭罪。若至非、畜，例有強、疑。以懷人想，強從本境，非、畜異境，一向無罪。若兼疑心，從兩境生，本境疑蘭，非、畜疑吉。若至杌木，並結本境，以杌異境，非生罪緣。
【譯文】【疏文】如今說明正確的解釋。原本對象的這一類，一律全都是偷蘭遮罪。替代對象前來差錯時，如果替代境界同是人類，因其同屬人類，無論是強大還是生疑，無一不是抱持殺害之心，全都要結偷蘭遮罪。如果輪到非人、畜生，同樣也有強大或疑惑的情況。因為心中懷抱著人的想法，境強則歸於本境，非人、畜生這兩種異境，一概不結罪。若兼帶有疑惑之心，疑惑從兩境同時產生，對本境結疑心偷蘭遮，對非人與畜生則結疑心突吉羅。如果是枯木，全都只在原本對象上結罪，因為枯木作為異境，並非能夠產生罪過的緣。

【408-0004】02_戒疏/04b_卷一下之二#55
【原文】【記】正解中。初明本境通結，「異」下明異境別結。又復為二，初明人異境，「若至」下，次明非、畜境。又二，初通標強疑，「以」下別釋。初釋境強，「若兼」下，釋疑心。「非、畜」二異，正犯蘭提，疑故並吉。「杌」非罪緣，故無所犯。
【譯文】【記文】正解之中。首先說明本境一概結罪，「異」字以下說明異境分別結罪。又再分為兩部分，首先說明人類異境，「若至」以下，接著說明非人與畜生境界。又分兩段，首先普遍標示境強與疑惑，「以」字以下分別解釋。首先解釋境強，「若兼」以下，解釋疑心。「非人、畜生」這兩個異境，正犯時原分別是偷蘭遮與波逸提（蘭提），因懷疑之故所以都只結突吉羅。「枯木」不是生罪之緣，所以毫無違犯。

【408-0005】02_戒疏/04b_卷一下之二#56
【原文】【記】初師局就本境，異則不結。次師疑心兩緣，異境皆蘭，不簡輕重。觀今所判，文理精詳，比前可鑒。
【譯文】【記文】第一位律師局限於本境結罪，異境則完全不結。第二位律師認為疑心緣及兩境，異境皆結偷蘭遮，不論罪名輕重。觀察如今此處所作的判斷，文義與理趣皆極為精微詳盡，比照前者自可明白照察。

【408-0009】02_戒疏/04b_卷一下之二#60

【譯文】【疏文】第四，境界差錯而心念不差的究竟罪，例如想要殺害或欺誑張三，張三離開而李四前來，對著李四卻誤認為張三，不論是欺誑或殺害，境界雖然皆差錯，但同樣構成究竟重罪。

【408-0015】02_戒疏/04b_卷一下之二#66
【原文】【記】五、想差中。此門八位，前四互歷，後四具兼。一、三全是想差，五、六心境兼差。此門唯收四句。二、四屬前境差，七、八即境想初句，故此四句皆非科意，句法相從，故為八位耳。五、六二句，令「以事思」者：五中，如欲殺張，王人替處，是境差，心復轉想，謂為非人，即想差成方便；第六，如欲殺張，王人替處，心作李想，還成究竟。言「互差」者，「互」即是俱，承上第五，故云「即此」，或恐字誤。七中，出血一罪，永無根本，境強、緣差，事不究竟，心境無改。
【譯文】【記文】第五，想差之中。此門所開展的八位，前四句互相交錯推演，後四句同時兼具雙方。第一、第三完全是想差，第五、第六是心念與境界同時差錯。本門嚴格來說只收攝這四句。第二、第四句應歸屬於前面的境差，第七、第八句則是境想分別的第一句，所以這四句都不是這一部份的本意，只是因為句法互相順應，所以湊成八位。第五、第六兩句，令讀者「依據事相去思維」：第五句中，例如想殺張三，李四替代了位置，這是境差，心中又轉變想法，誤認為是非人，這就是想差而構成方便罪；第六句，例如想殺張三，李四替代了位置，心中卻誤認為是趙六，結果殺害依然促成究竟重罪。所謂「互差」，「互」就是兩者皆是，承接上面的第五句，所以說「即此」，或者是文字傳抄有誤。第七句中，出佛身血這一條罪，在方便階段永遠無法圓滿殺死佛陀的根本重果；境強、緣差也是事情未能達到究竟，而心境皆無改變。

【408-0016】02_戒疏/04b_卷一下之二#67
【原文】【疏】就此想中，或有從輕向重，如殺盜畜生，轉想向人者是。或從重至輕，即反上句是。或互轉者，如彼婬、酒、破僧，俱是正境，想、疑或生，無非究竟。
【譯文】【疏文】就這想差當中，有的從輕罪轉向重罪，例如本想殺害或盜取畜生，轉變心想認為是人便是如此。有的從重罪轉向輕罪，也就是反過來與上一句相反的情況。有的則是互相轉變，例如淫戒、酒戒、破僧戒，面對的都是正確的境界，心想或疑惑雖然生起，但無不構成究竟重罪。
