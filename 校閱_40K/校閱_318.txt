# 校閱材料　第318檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【318-0001】資持記/15b_下三#44
【原文】五眾下略及塔字。相禮者，若五眾相對，則四位尊卑；二眾沙彌，同一位故；若五眾各論，自分大小；當眾同臘，則須對禮。如來及塔，五眾齊敬；一向是尊，故云通禮。塔即墳塚。初下，別列。次科，《五百問》中。決前禮塔，引佛為比，意在報恩。死下，義準。論明禮塚，不言屍故。
【譯文】「五眾」二字之下，省略了「及塔」二字。所謂「相互敬禮」，如果是五眾弟子互相比對，則存在四個尊卑階位；出家男女二眾沙彌，屬於同一個階位；如果是五眾各自內部論處，自然劃分長幼尊卑；在同一眾中若是戒臘相同，就必須互相談對行禮。至於如來與佛塔，則是出家五眾一律齊心敬重；這純然是至高無上的尊境，所以說是通受敬禮。塔就是指安置舍利的墳塚。「初」字以下，分別逐一列出。下一個科判引用《五百問》。對前文禮拜佛塔作了決斷，引佛陀來作比對，本意在於知恩報恩。「死」字以下，是依義理推斷。因為論典只載明禮拜墳塚，並未提及頂禮遺體。

【318-0002】資持記/15b_下三#45
【原文】別示中，初文。若據沙彌，亦取受戒前後，分上中下；此約多人初受，排次為言。生年，即俗年長幼。出家年，即入道先後。次科。問意，恐謂下眾同大僧故。答中二義，初約戒等釋。未具總名者，同號沙彌故。無勝德者，戒體同故。又下，次約非師釋。大僧不爾，反上二義；
【譯文】在「分別開示（別示）」的第一段經文中，如果就沙彌而言，原本也是依照受戒先後來區分上中下座；此處是就多數人同時初次受戒、排定座次的情形來說的。「生年」是指世俗年歲的長幼。「出家年」則是指遁入佛道時間的先後。下一個科判中，發問的本意，是擔心有人會誤以為下座沙彌等同於大僧比丘。回答中包含了兩種義理，第一是從戒體平等來解釋。所謂「未具足通名」，是因為大家都同樣被稱為沙彌的緣故。所謂「沒有殊勝德行」，是因為所領受的戒體完全相同的緣故。「又」字以下，第二是從對方並非自己和尚師長的立場來解釋。大僧比丘則不是這樣，正好反轉了上述兩種義理；

【318-0003】資持記/15b_下三#46
【原文】故百歲比丘尼，禮初夏比丘足也。三中，初示禮儀。身口虔恭，用彰意重。出下，顯華梵。五下，明總別。中下，明受俗禮。《恭敬經》，即《中含》所集，彼云：爾時世尊告諸比丘，當行恭敬，及善觀敬重諸梵行人；若不恭敬，必無是處。四中。《母論》四名，局據夏限；
【譯文】所以縱使是百歲高齡的比丘尼，也必須頂禮剛受具足戒初夏比丘的雙足。第三段中，首先開示敬禮的威儀。身業與口業都要虔誠恭敬，以此彰顯內心意業的敬重。「出」字以下，辨析華語與梵語的轉譯。「五」字以下，說明總相與別相的區分。「中」字以下，說明接受世俗之人行禮的規範。《恭敬經》就是《中阿含經》所結集的經典，經中說：那時世尊告諸位比丘，應當力行恭敬，並且要善於觀察、敬重一切修持梵行之人；如果不行恭敬，是絕對沒有道理的。第四段中，《薩婆多毘尼母論》提出的四種稱呼，是嚴格局限於戒臘年限的；

【318-0004】資持記/15b_下三#47
【原文】若如《五分》，取上無人，隨時受稱，則通大小。今時禪眾，無論老小，例稱上座，不知孰為下座乎！五中，初科，前明共坐限齊。若下，次明床敷大小，有三，初明床座。臥床三人坐者，謂減三肘者。坐床肘半，二尺七寸；若減併與者，不容並坐故。
【譯文】如果依照《五分律》的說法，只要當場上方沒有地位更高的人，隨時都能接受相應的稱呼，那麼這種稱謂便可通貫大僧與小僧。如今禪宗門下的僧眾，不論年長年幼，一概統稱為上座，真不知到底誰才算是下座呢！第五部分的第一科中，前半段說明共同坐在一處的年限限制。「若」字以下，接著說明床榻鋪設尺寸的大小，共有三項：首先說明床座。所謂「臥床允許三人同坐」，是指長度不足三肘的床榻。坐床寬度是一肘半，折合世俗尺寸為二尺七寸；如果尺寸減小（不足一肘半）而全讓給上座獨坐，是因為無法容納兩人並坐的緣故。

【318-0005】資持記/15b_下三#48
【原文】臥床過三肘者，五尺四已上，三人有餘，故加至四；降四歲者，如六歲得共十歲坐也。大會得連床者，一以床少，二不許動，故暫開之。若方下，次明氈褥。準前床量。若散下，後明敷草。由無限量，故得共坐。次科，《伽論》。地敷，義是長連不可動者。《多論》。
【譯文】臥床長度若是超過三肘，折合五尺四寸以上，坐三個人還有富餘，所以可以增加到四人；所謂「相降四歲」，例如六臘的比丘可以與十臘的比丘同坐一張床。「大集會時允許連床並坐」，一來是因為床榻數量不足，二來是因為在法會中不被允許隨意走動，所以暫時開許。「若方」以下，接著說明毛氈褥墊。這要依照前面床榻的尺寸標準來推算。「若散」以下，最後說明鋪設草墊。由於草墊沒有特定的形制限量，所以眾人可以共同坐在一起。下一個科判引用《薩婆多部毘尼摩得勒伽》（伽論）。所謂「地鋪」，按義理是指長條相連、不可隨意移動的鋪具。《薩婆多論》中。

【318-0006】資持記/15b_下三#49
【原文】床連席異，謂床上敷席也。中空絕者，準須相遠，方免譏過。論明俗女，俗士可知。六中，初明受禮。義無忽傲。如啞羊者，彼有啞羊外道，受不語法。世有持不語者，謂為上行；此外道法，宜速捨之。問訊之語，隨時適變，不必依此，故云等也。共下，明呼召。慧命名通，不專下座；
【譯文】所謂「床榻相連但座席分開」，是指在同一張長床上各自鋪設不同的坐席。所謂「中間留空隔斷」，依照標準必須保持一定的距離，才能免遭世人的譏嫌非議。論典中指明的是世俗女子，世俗男子的情況自然也可以類推而知。第六段中，首先說明接受行禮的規範。在義理上絕不可以有輕忽傲慢之心。所謂「如同啞羊」，那是因為世間有一種啞羊外道，受持終生不說話的苦行之法。世間有些人修持閉口不語，還自以為是高尚的行持；這完全是外道的法門，應當趕緊捨棄。問候致意的辭句，應當隨著時空情境靈活變通，不必拘泥於此處的定詞，所以經文說「等」。從「共」字以下，說明呼喚招呼的稱謂。「慧命」這個稱呼涵義廣通，並非專門用在下座身上；

【318-0007】資持記/15b_下三#50
【原文】故雖耆宿，亦得呼之，即如經中慧命須菩提是也。第二法附，造像中，初科，上句標示。如來下，正明。現在，即化相佛法，一期益近；未來，即住持佛法，三時益遠；即經云：應可度者，皆悉已度；其未度，作得度緣，是也。次正明中，初文，先敘目連圖寫；
【譯文】因此即便面對長老耆宿，也可以這樣稱呼他，這就如同經典中常見的「慧命須菩提」那樣。第二部分是隨法附錄，在「造立佛像」的第一科中，上面一句是標示提示。「如來」以下，則是正式闡明。所謂「現在」，是指化相佛法，那一時期的利益較為切近；所謂「未來」，是指住持佛法，在正、像、末三時的利益則更為悠遠；這正如經中所說：「應當度化的眾生，都已經度化完畢；那些尚未得度的眾生，也已經為他們種下了得度的因緣。」這就是其意旨。在正式說明的內容中，第一段首先敘述目犍連圖繪佛陀聖相；

【318-0008】資持記/15b_下三#51
【原文】至下，後引如來垂誡。以佛生七日，摩耶命終，生忉利天；佛後成道，思報母恩，昇天說法，經于一夏；按《造像經》，時優填王思念如來，命目連引三十二匠，往彼天中，以旃檀木各圖一相；如是至三，方得圓足；文云恐者，若論圖寫，似指目連；取後垂誡，須推佛意；雖緣在優填，意存來世。
