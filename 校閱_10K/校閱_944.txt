# 校閱材料　第944檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【944-0001】資持記/02d_上一下#21
【原文】答：食中能別局四，三人無過。所別同上。又食有九緣可開，法無方便得別。食則犯提，制重業輕；法唯犯吉，制輕業重。若一界之內，兩眾各秉，則是破僧，犯中品蘭。問：別眾之名，為能為所？答：制過在能，從能立號。《戒疏》云：若取語便，應云眾別。可以決之。問：何名為別？答：別是異義。
【譯文】答：受食中能別的局限於四人，三個人受食不算有罪。所別的人數與上面相同。又受食有九種因緣可以開許，作法事則沒有任何方便可以個別分開。受食只是犯波逸提，制戒雖重但罪業較輕；作法則唯獨犯突吉羅，制戒雖輕但壞僧業重。如果同一個結界之內，兩群僧眾各自秉持羯磨，那就是破僧，犯中品偷蘭遮罪。問：別眾這個名稱，是就「能別」還是「所別」立名的？答：制止過失是在於能別的人，是順從能別而建立稱號。《戒疏》說：如果就語詞順暢而言，應當稱為「眾別」。可以用這句話來裁決。問：何名為別？答：別是異義。

【944-0002】資持記/02d_上一下#22
【原文】一三業異，二四儀異，三向背異。並如下明。〔食中但是食不同味，名同事別。〕三業中，初科，文出〈瞻波犍度〉。應來者，謂應羯磨人；簡前體淨緣差中瘂聾狂亂重病癡鈍等，及體境俱非一門之人，皆不應來故。二應與欲者，有如法緣，簡非緣者不合與故。三得呵者，謂具德知法；
【譯文】第一是三業相異，第二是四種威儀相異，第三是面向與背向相異。這都在下文加以說明。〔受食中只是吃的食物味道不同，稱為名稱相同而事相有別。〕在三業之中，第一個科判，文句出自〈瞻波犍度〉。所謂「應當來集的人」，是指應當參與羯磨的人；這簡別了前面戒體清淨但因緣有阻隔的啞巴、聾子、瘋狂發亂、重病、愚癡遲鈍等，以及戒體與境地都不合的一門之內所有人，這些人都根本不應當前來。第二種「應當交付欲意的人」，是指具有如法的因緣，簡別非因緣者不合適交付欲意。第三種「能夠呵責阻止的人」，是指具足戒德且通曉教法的人；

【944-0003】資持記/02d_上一下#23
【原文】簡不合訶者，如四羯磨等。問：不與欲人，口亦不集，何不列者？答：身既不集，理無訶故。若爾，初人身亦不集？答：彼無欲緣，身合當集；容有口訶，故同不集。此則不爾，有如法緣，許不集故。若准《業疏》，單配三業，乃為盡理；初身不集，次心不集，後口不集。反為三和，亦從單歷。次科。上二人可知。
【譯文】這簡別了不合適呵責的人，例如受四種羯磨處分者等。問：不交付欲意的人，口頭也沒有表達和合集會，為什麼不列出呢？答：身體既然沒有前來集會，按理自然無法開口呵責。如果這樣的話，第一種人身體也沒有前來集會啊？答：那個人沒有交付欲意的因緣，身體本來應當前來集會；他有可能在口頭上提出呵阻，所以等同於口不集會。這個人則不相同，他有如法的因緣，律中開許他不集會的緣故。如果依照《業疏》的說法，單純將這三種人配對三業，才算是最窮盡義理；第一是身不集，其次是心不集，最後是口不集。反過來成為三種和合，也是依循單項依次經歷。下一個科判。上面兩種人可以理解。

【944-0004】資持記/02d_上一下#24
【原文】後人心不集者，此謂有可訶事，心不同忍。必無訶事，則同初人。故下，引證，初即〈瞻波〉文。彼明非法和合羯磨云：有同一住處同一和合一處羯磨，應與欲者與欲，現前應得訶者不訶，作白二乃作白四，白此事乃為彼事。此文可證相順心違。
【譯文】最後一個人屬於「心不集」，這是指有應當呵責的事，心裡並不贊同忍可。如果確實沒有應當呵責的事，那就等同於第一種人。所以從「故」以下引證，起初就是〈瞻波犍度〉的律文。那裡說明非法和合羯磨時說：有在同一住處、同以一種和合方式、在同一處所作羯磨，應當交付欲意的人交付了欲意，在場應當能夠呵責的人不提出呵責，本該作白二羯磨卻作了白四羯磨，宣告這件事卻辦了那件事。這段經文可以證明表面順從而內心相違的情況。

【944-0005】資持記/02d_上一下#25
【原文】又下，即〈雜法〉中文，初引身子懷疑問佛。上如法字寫誤，彼正作非法。應下，是佛所斷。彼云佛言聽默然，即具出十五種默，如〈羯磨篇〉引。四儀中，初引本律。即說戒法中，彼云六群念言：我往說戒處不坐；恐餘比丘為我作羯磨，若遮說戒，佛言不應爾。今以非法替之，顯是別眾也。次引《五分》。
【譯文】又從「又」以下，就是〈雜法〉中的律文，起初引述舍利弗心懷疑惑而請問佛陀。上面「如法」兩字是抄寫錯誤，原文正寫作「非法」。從「應」以下，是佛陀所作的裁斷。那裡說佛陀說聽憑其默然不語，隨即具體列出了十五種默然，如同〈羯磨篇〉所引用的內容。在四種威儀中，起初引述本律。也就是在說戒法中，那裡說六群比丘心想：我前往說戒的處所但不坐下；唯恐其餘比丘為我作羯磨、或者阻止我說戒，佛說不應當這樣做（前往而不坐）。現在用非法來替代它，彰顯這就是別眾。其次引述《五分律》。

【944-0006】資持記/02d_上一下#26
【原文】四儀縱同，身面向背以論同別。下引《僧祇》。文如前解。大約乖儀同上《四分》，然彼文歷句顯相猶詳。料簡中，初科。大分，一往以判。不妨身不至僧而是不足，隱沒與欲樹上之類。自有來至僧中，得成別眾，如上乖儀面背等。簡淨穢中。淨即初例，穢即第二例。然三舉二滅，可得云穢；
【譯文】四種威儀縱使相同，也是以身體的面向與背對來論斷屬於同眾還是別眾。下文引述《僧祇律》。文義如同前面所作的解釋。大致上威儀相乖違的情況與上述《四分律》相同，然而那裡的律文逐句顯示外在行相更加詳細。在詳加簡別（料簡）中，第一個科判。大致區分，是暫時從表面來判斷。不妨礙身體未到僧眾中卻是不算足數的情形，例如隱身不見、交付欲意、身在樹上之類。自然也有親自來到僧眾中，卻構成別眾的情形，如同上述威儀乖違、面向背對等。在簡別清淨與垢穢之中。清淨就是第一個例項，垢穢就是第二個例項。然而三舉、二滅，可以稱之為垢穢；

【944-0007】資持記/02d_上一下#27
【原文】尼等四人，未必約犯；十三難人，無體可破；然今但取境非淨僧，通云穢耳。穢本不足，淨相難知；所以注中但示淨者。清淨一色，且據不犯四重為言。色，猶類也。下指句法。準《業疏》云：一是別非足〔應來不來，及不與欲。〕；二是足非別〔即善比丘身參眾侶〕；
【譯文】比丘尼等四種人，未必是就犯戒來說；十三難人，則是根本無戒體可破壞；然而現在只是選取其人境不是清淨的比丘，統稱為垢穢罷了。垢穢本就不算足數，清淨的行相卻難以知曉；所以注釋中只指示清淨的人。所謂清淨同一個類別，姑且是就沒有違犯四重禁戒來說的。「色」，就如同類別的意思。下文指出四種句型邏輯。依照《業疏》說：一是屬於別眾而非足數〔應當來而沒來，以及不交給欲意的人。〕；二是屬於足數而非別眾〔也就是善良比丘身在僧眾行列中〕；

【944-0008】資持記/02d_上一下#28
【原文】三亦足亦別〔得訶人訶〕；四非足非別〔睡定瘂聾等〕。彼文甚廣，非學不知，故略引示。簡學悔中，初示不足。前未明故。問：究論學悔，四例何收？答：既毀根本，體非淨僧，故非初例。來否隨意，復開秉法，故非第二。生善滅惡，一切不足，復非第四。
【譯文】三是既屬足數又屬別眾〔能夠呵責的人當場提出呵責〕；四是既非足數又非別眾〔睡眠、入定、啞巴、聾子等〕。那裡的文字非常廣博，不深學的人無法知曉，所以簡略引述提示。在簡別修學悔過人之中，起初說明不算足數。前面尚未說明清楚的緣故。問：追究推論修學悔過的人，四個例項中屬於哪一類所收攝？答：既然毀犯了根本重戒，戒體已非清淨僧寶，所以不屬於第一個例項。來與不來聽憑其隨意，又開許他秉持僧法，所以不屬於第二個例項。無論是生長善法還是滅除惡業，一切羯磨都不能算入足數，所以又不屬於第四個例項。
