# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【241-0001】02_戒疏/11c_卷三上之二#80
【原文】【記】次別配中，初科。二十七中除四長，故有「二十三」。此為所染，三種長衣，即為能染。「六戒」不染，上四如前，「藥」即七日，「鉢」謂乞鉢，此二體別，故不相染。「餘」下，明十七戒懺淨入長，容有相染。據本即還，止由隨長，故同隔宿。
【譯文】【記文】次論分別配屬中，這是第一科。二十七條戒中除去四種長衣，所以剩下「二十三條」。這是被沾染之物，三種長衣就是能沾染之物。「六條戒」不受沾染，前四種如前所述；「藥」就是七日藥，「缽」指乞缽，這兩種器質不同，所以互不沾染。從「其餘」以下，說明其餘十七條戒懺除清淨後歸入長物，容有相互沾染的可能；按原本規定當即歸還，純粹因為隨附長衣，所以一同隔夜。

【241-0005】02_戒疏/11c_卷三上之二#84
【原文】【記】三中。上標四長，對明相染經宿不宿，長藥即在所染之中。今此所明，不論經宿。但藥通三捨，二是與他，恐謂相染，隨捨與他，故須辨示。藥須與人，餘自還主，故云「並歸」。「以」下，顯示不染所以。標中合云「二十二戒」，以長藥即在二十三中，摘出為能染故，思之。
【譯文】【記文】第三種情況。上面標舉四種長物，用來對照說明沾染是隔夜或不隔夜，長藥本來就在被沾染之列。現在這裡所要闡明的，並不是論述隔夜與否；只是因為藥物通於三種捨法，有兩種是要給予他人，唯恐有人以為發生沾染而隨著捨給他人，所以必須辨明清楚。長藥必須給予他人，其餘衣物則自然歸還原主，所以說「一同歸還」。從「因為」以下，顯明不沾染的原由。標目中理應說是「二十二條戒」，因為長藥原本就在二十三條戒當中，如今抽出來作為能沾染之物，請深思此處文意。

【241-0009】02_戒疏/11c_卷三上之二#88
【原文】【疏】就五長戒，本由貪貯，故犯令捨，反彼貪心。不得即日還主，必有他緣，如文所開。如《多論》中「即日得受異財，不染長過，以心斷故」。所以本財不得者，曾經畜過，須以宿隔其心。必若不斷，多宿亦犯。不同過藥，當日得還，制不服用。
【譯文】【疏文】就五種長物戒來說，本來是由於貪求貯存，所以犯戒時令其捨棄，以反制原來的貪心。物不能當天歸還給原主，除非遇到特殊的緣由，正如經文所開許的那樣。好比《薩婆多論》中所說：「當天得以接受其他財物，不受長物過失的沾染，因為蓄積之心已經斷除的緣故。」至於原本的財物之所以不得接受，是因為曾經蓄存有過，必須用過夜的時間來阻隔這份貪心。如果貪心必定不曾斷除，即使過了許多夜也依然算犯戒。這不同於過期的藥物，當天就可以歸還，只是制令不得自行服用。

【241-0024】02_戒疏/11c_卷三上之二#103
【原文】【記】今解中。初敘悔法。「故抽前者」，別「九十」故。「豈可」等者，財罪兩難，不可偏故。「隨」下，出今判。初正示。「縱一人」者，悔通三位，以無僧處，故開別人，雖對一人，界須盡集，無非僧法。「如律」下，釋妨。綿衣、二寶，《律》不明悔，後師執此以立依文，故須通決。初示《律》意。「財是別捨」者，綿則斬壞，二寶與俗，不對僧故。「乘」，猶因也。「四分」下，引據。《僧祇》云：「金銀錢，一切不得捉，捉得提，應僧中悔。」《多論》云：「一切重寶，捨與同意淨人，罪僧中悔。」、「至」下，指後。「餘」下，示略。
【譯文】【記文】如今的解釋中。起初敘述懺悔法。「抽調在前面」，是為了區別於「九十單提」。「哪有」等語，是說明財物與罪障兩者都困難，不可偏廢一邊。從「隨其」以下，提出如今的判定。起初正式闡明。「縱使一人」，說明懺悔通於三種位階，因為在沒有具足僧團的地方，所以開許對個人；雖然只對一人，只要界內僧眾全部到齊，無非都是合法的僧法。從「好比律本」以下，解釋疑難。蠶綿衣與二寶在《律》中沒有明載懺法，後面的法師執著此點而主張依文解讀，所以必須融通決斷。首先指明《律》本的立意。「財物個別捨」，是指蠶綿剪壞、二寶給予俗人，不對著僧團的緣故。「乘」就是順應、依循的意思。從「四分律」以下，引用依據。《僧祇律》說：「金銀錢財，一切不得拿取，若拿取了犯提罪，應在僧團中懺悔。」《薩婆多論》說：「一切珍重寶物，捨給志同道合的淨人，罪過要在僧中懺悔。」從「到了」以下，指引後文；從「其餘」以下，說明此處略去。

【241-0027】02_戒疏/11c_卷三上之二#106
【原文】【疏】如長衣、月望、長鉢、長藥、急施過後。此五長戒，佛令淨施如法受之。依教奉說名作持，不越佛制名止持。「作」謂䇿修奉行，「止」謂如教非越，此則名體各別。故違不說名止犯，越於期限名作犯，此亦名體各別，翻對自顯。並如上卷「持犯」中說。
【譯文】【疏文】好比長衣、月望衣、長缽、長藥、急施衣過期之後，這五種長物戒，佛陀制令必須透過如法的說淨法來受持它。依照教令實行奉持稱為「作持」，不逾越佛陀的規制稱為「止持」。「作」是指警策修行、如法奉持，「止」是指順從教導、不加逾越，這兩者的名稱與本質各別不同。故意違背戒法而不作說淨表白稱為「止犯」，超越了期限稱為「作犯」，這兩者的名稱與本質也各別不同，相互反照自然顯明。這些正如上卷「持犯」篇章當中所說。
