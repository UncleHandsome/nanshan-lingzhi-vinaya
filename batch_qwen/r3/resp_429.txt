整體看下來，譯文流暢、術語多半掌握得住（瞥爾／重緣／遠方便／假實二宗等都對），但有幾處**義理判讀**與**術語對譯**的問題會誤導讀者，建議修正。以下按輕重分列。

---

## 一、需要修正的實質問題

### 1.【0002／0004／0008】「心念作」譯成「心念籌劃去做」──與後文自相矛盾（最要緊）

【0005】記文明判：「**上是方便**，期成彼事；**下是果頭**」。
也就是：

* **發心作**＝起心欲作、將由身口（遠方便）
* **心念作**＝單就意地本身即結犯（果罪，如惡覺、默妄、染心看女）

「籌劃去做」正是「方便」的意思，用來譯「心念作」，恰好把疏主要區別的两者的後半譯成了前半，讀者讀到【0005】【0008】會接不上。

**建議**：保留原詞再括注——
「發心作（起心欲作，將由身口）／心念作（唯是心念，當體即犯）」。
【0008】末句改作：「所以律文才說『心念作』（單就心念即結犯）。」

### 2.【0019】「不學無知」不是「因不學而造成的無知」

律中「**不學**」與「**無知**」是**兩條各別的罪**（不學罪、無知罪），各有有無、輕重，故須「二九」十八句料簡。譯成因果關係，等於把二罪併成一罪，「皆須二九」也就沒了著落。

**建議**：「專明『不學』與『無知』二罪，在止犯中罪相的有無與輕重。隨一一事、法，各須兩組九句（合為十八句）料簡，故云『位列』。」

### 3.【0016／0017】「增微」≠「增減」

記文自釋：「第六**優劣**，即是**增微**」。「增微」是**增勝／微劣**，即罪的輕重高下，不是數量上的增減。【0016】「罪業增減微細」、【0017】「指的就是罪業『增減』」都應改為「**優劣輕重（增勝微劣）**」。

### 4.【0009】「初約大乘，釋前不犯」譯法會顛倒宗義

大乘（圓教宗）**正是瞥爾即犯**，所以不能說「從大乘的角度解釋為什麼不犯」。此處是疏文以「制**聲聞**戒」簡別大乘，元照點出這是**對顯大乘**而成立聲聞之不犯。

**建議**：「先是對顯大乘（大乘瞥爾即制），以解釋前文『獨頭不犯』之義。」

### 5.【0005】「果頭」譯「根本罪果」易生誤會

所舉惡覺、默妄、染心看女皆是**突吉羅**，「果頭」指**當戒的果罪**（相對於方便罪），不是波羅夷意義的「根本罪」。建議作「後者已是（該戒的）果罪本身」。

### 6.【0007】「單意」的括注釋義偏了

「故非單意」是因為「**將由身口**」，不是因為有無「行動意圖」。單意＝唯意業、未及身口。
**建議**：「所以已不是『唯是意業、未及身口』的單意。」

### 7.【0012】「任情兩取」＝兩說皆可取，不是「取捨」

「取捨」暗示二擇一，與下句「後為正義」的**縱奪**結構不合。
**建議**：「兩說可隨情任取（皆通），但以第二說為正義。」
連帶【0013】：「上句是**縱**（暫且寬許兩說），下句是**奪**（剋定一說為正）」，比「寬容放任／明確擇定」貼切。

### 8.【0021】「不可學迷」是術語，不宜拆譯

「不可學迷」指**非由不學所致、雖學亦不免**的境想迷忘（相對於「可學迷」因不學而迷故結犯）。譯成「不可修學的突發迷惘」意思含混。
**建議**：「這就是『不可學迷』——不是靠修學所能免除的迷忘（故律判不犯）。」

## 二、科判與用詞可再斟酌

| 編號 | 譯文 | 問題／建議 |
|---|---|---|
| 0003 | 「在通達疑難中」 | 「難通」是科名，宜作「在『通難』（會通疑難）這一科中」；又「**二文**相違」指前文（單意非犯）與所引律文，逕稱「兩處律文」恐不確，改「前後兩文」較穩 |
| 0001 | 「根據律文來確立義理」 | 「據文立義」的「文」可含疏文，不必坐實為律文 |
| 0006 | 「雖然身體動作的相貌」 | 疏云「未動**相**」兼身口，宜作「身口之相尚未動顯」 |
| 0015 | 「三宗歷歷分明」 | 上文只列實、假二宗，讀者不知第三宗為何；宜補注「三宗＝實法宗、假名宗、圓教宗（大乘）」 |
| 0016 | 「衡量研習時間有所需要」 | 「量時須者」是**酌量時機、若有需要者**（記云「囑後講習輩」），非單指時間 |
| 0016 | 〈持犯篇〉 | 應作〈**持犯方軌**篇〉 |
| 0017 | 「《行事鈔》中共有七門」 | 是〈持犯方軌篇〉七門，非全鈔七門 |
| 0017 | 「又細分為四個階位」 | 「自分四位」是四類／四門料簡，非修證階位 |
| 0018 | 「排列各個階位的持戒與犯戒」 | 「位列」之「位」即二九十八句之**句位**；建議「依句位排列表列（不學無知的）持犯相」 |
| 0020 | 「教法的行相」 | 「行相」是特定術語（心行相狀），此處「教相」宜作「教法（教門施設）之相」 |
| 0011 | 「全都是遠方便」 | 與下句「少分有之」是通論／別論，宜加「（大體而言）」以免看似矛盾 |
| 0009 | 「不斷追逐回味前面的惡事」 | 「還追前事」只是「後念再緣前事」，「回味」「不斷」屬增譯 |
| 0008 | 「構成了犯戒科處」 | 「犯科」＝結罪科判，「科處」偏量刑語感，可作「即結犯罪」 |

## 三、可保留但建議加註的地方

* 【0001】增譯「聲聞律典不制瞥爾」本身無誤（因限定「瞥爾」），但與【0015】「假宗制意（重緣）」並讀易生混淆，建議改為「**瞥爾之制限在大乘**」。
* 【0005】三個律例宜簡注：惡覺＝欲／恚／害等不善覺觀；默妄＝說戒問清淨時默然覆藏，成故妄語；染心看女＝以淫染心視女人（皆吉羅）。
* 【0021】「忽於境想」宜注：即於境起想（人作非人想等）時忽然迷忘。

## 四、通則建議

1. **術語一律「保留原詞＋首次括注」**：單意、瞥爾、獨頭、重緣向念、方便／果頭、遠方便、不學無知、可學迷／不可學迷、位列、縱奪。目前有的保留（瞥爾）、有的意譯（心念作、不可學迷），正是出錯的地方。
2. **前後對譯要一致**：同一詞在【0002】【0004】【0008】都譯「心念籌劃」，錯誤就被放大三次。
3. **科判語（初科、次釋、難通、結中、指略）** 建議統一格式為「在○○這一科中」，避免像「在通達疑難中」這種把科名當動賓結構直譯的情形。

修正上述第 1～8 點後，這一段的義理脈絡（單意→瞥爾不犯→重緣結犯→假實二宗深淺→三宗無濫）就能清楚呈現了。
