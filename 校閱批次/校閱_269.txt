# 校閱材料　第269檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】次科，文中通說，但標破僧故；必須此示，須分輕重故。「故」下，汎論解行，勸令明識，不唯此也
【譯文】次一科中，律文中通括論述，只是標立「破僧」之名；必須作這樣的開示，是因為需要劃分罪過輕重的緣故。從「故」字以下，廣泛討論理解與力行，勸勉人們深刻明了辨識，並非僅僅局限於破僧這一條。

【269-0002】03_業疏/14b_卷三之三#93
【原文】十、惡心出佛血者，故論說言：出血一也，由心善惡耳，故善登梵天、惡沈鼻獄，俱一劫也
【譯文】第十、惡心出佛身血：所以論典中說：使佛身出血這件事雖然相同，但關鍵在於發心的善惡罷了；因此發善心者上升梵天，懷惡念者沉淪阿鼻地獄，受報時間同樣都是長達一劫。

【269-0003】03_業疏/14b_卷三之三#94
【原文】出血中初文，引論，即《多論》耆婆針醫、調達殺害。出血事同，而心不等，耆婆生天，調達墮獄。準前《多論》，耆婆自生忉利，今云梵天，定非色界
【譯文】在出血的第一段文中，引用論典，就是指《薩婆多論》所記載的耆婆用針醫治、與提婆達多謀殺加害之事。刺破出血的事相雖然相同，但其動機發心卻不平等，耆婆得以升天，提婆達多則墮入地獄。依照前面《薩婆多論》的說法，耆婆自己是生到忉利天，如今疏中說是梵天，但必定不是指色界的梵天。

【269-0004】03_業疏/14b_卷三之三#95

【269-0005】03_業疏/14b_卷三之三#96

【269-0008】03_業疏/14b_卷三之三#99
【原文】有人言：不可感於血光，但論惡心損是逆例。如設像代真，敬福齊等；今行惡毀，受罪義一。如尼破法，豈同調達？立諫設治，則無與二。彼既不疑，堂堂行事，敬像如真，損何獨別？義不可也。俗律云「僧尼毀佛像者絞之」，意有在矣。餘即盜論，非所奉矣
【譯文】有人說：不能拘泥於感召血光等異相，只要以惡意損毀佛像，就應當比照逆罪之例。如同設立佛像代替真佛，恭敬佛像所得的福報與恭敬真佛相等；如今以惡心進行毀損，所獲罪報在義理上也是一致的。這就像比丘尼破僧，難道與提婆達多一模一樣嗎？然而佛陀同樣設立三諫、施加懲處，這在法治上是毫無二致的。彼人既然毫無顧忌、公然肆行毀損；而世人恭敬佛像既如同面對真佛，損毀佛像在治罪上為何獨獨要區別對待？這在義理上是說不通的。世俗國法說「僧尼毀壞佛像者處以絞刑」，其用意就在於此。至於損毀其餘菩薩等像，則按盜竊罪論處，因為不是至尊所奉敬的佛陀極則。

【269-0009】03_業疏/14b_卷三之三#100
【原文】次釋中，初、立理。如「下」，舉例有二：初、約敬福反例，次、約尼眾破僧比例。「彼」下，顯過，謂凶頑之人，不疑毀之有罪。堂堂，公顯之貌。下引俗律毀佛死罪，可驗同逆。餘盜論者，謂菩薩等像也
【譯文】在第二種解釋中，首先確立義理。從「如」字以下，列舉兩個例子：第一是就恭敬得福作反面例證，其次是就比丘尼破僧作同等比照。從「彼」字以下，顯明過失，是指兇頑之人，心中毫不顧忌、不認為毀像會有罪報。「堂堂」，是公然彰顯的樣子。下面引用世俗法律中毀佛處以死罪的條文，可以驗證等同於逆罪。所謂其他按盜罪論處的，是指菩薩等聖像。

【269-0014】03_業疏/14b_卷三之三#105
【原文】約律明趣，但說為三，謂人、非人及畜生也。以人、畜兩趣，形現易知；天、鬼、神等，幽通難識，故合天、修、鬼、獄四道為一趣也。莫不分得五通，異於人類，故號非人。故律中諸戒，時有離之，如同宿戒「天子、阿修羅子、餓鬼子」等；地獄輕繫，義應得同，從重者多，故輕不說。如此分別，略識非人
【譯文】就律典說明趣別而言，只說為三種趣，即人類、非人以及畜生。因為人與畜生這兩趣，形體顯露容易辨識；而天人、鬼、神等，冥通幽隱難以辨識，所以把天道、阿修羅道、餓鬼道、地獄道四道合併為一趣。它們無不部分具備五種神通，與人類不同，所以稱為「非人」。因此律中諸多戒條，有時也分別開列，比如同宿戒中說「天子、阿修羅子、餓鬼子」等；地獄道受輕微繫縛罪報的眾生，在義理上也應當相同，但因大多數都是重罪繫縛不能自由前來，所以對輕罪繫縛者便未予述說。經過這樣的辨別，便能大略認識非人的含義。

【269-0015】03_業疏/14b_卷三之三#106
【原文】二中，初、指律文。人、畜局一，非人合四，故止三趣。「以」下，次、示離合。初、明合意。「故律」下，二、明離意。同宿戒但開三趣，義收地獄；仍示律文不說所以
【譯文】第二段中，首先指出律文。人趣與畜生趣各局限為一道，非人則合併了四道，所以只有三趣。從「以」字以下，其次開示合併與分開的用意。首先說明合併的用意。從「故律」以下，第二說明分開說明的用意。同宿戒雖然只開列了三趣，在義理上則收攝了地獄趣；隨後又指明律文不另說地獄的原因。

【269-0017】03_業疏/14b_卷三之三#108
【原文】三中，初、敘非。《觀音》，即《普門品》八部天、龍、夜叉等。謂頂生角故號非人。「想」下，結斥。世有𦘕鬼冠帶似人，云是經中人非人者；又傳獨覺則頭安一角，寫婆藪則貌如老嫗。循名昧實，今古皆然

【原文】答中，必應他師有立此句，故標今解。初立義，名雖可立，體無合理，故云不可。「一」下次顯別，有三：一即自性別，二謂起時別，三即體相別。「長短強弱」等結上三別，無作長強，作則短弱。「均」，和也。「故」下引類，即《增一》文。彼云有五句語無第三句：一時、非時，此句無第三句；二實、與不實；三損減、利益；四麤獷、柔和；五嗔恚、慈心。並無第三句，謂二種性別，不可立第三合句也。「此」下結示所立。此約體論，謂能防受體無出此二；所防無量，文見前答
【譯文】在答文中，必定是因為其他法師有立「作無作俱」這一句，所以標出「今解」以示辨析。首先確立論點，指出名義雖然可以假立，但在體性上沒有相合的道理，所以說「不可」。「一」字以下其次顯明兩者的差別，共有三點：第一是自性差別，第二是生起時間差別，第三是體相差別。「長短強弱」等語總結上述三種差別，無作戒長而強，作戒則短而弱。「均」，就是和順齊等的意思。「故」字以下引同類之義作證，就是《增一阿含經》的經文。經中說有五組語句沒有第三句：第一、應時與非時，此句沒有第三句；第二、真實與不實；第三、損減與利益；第四、粗獷與柔和；第五、瞋恚與慈心。這五組都沒有第三句，是說兩種體性相違背，不能建立第三種相合之句。「此」字以下結語指示所建立的義理。這是就戒體來論述，意指能防範的受戒戒體不出這兩種；至於所防範的境界則是無量的，相關文字詳見前面的答文。
