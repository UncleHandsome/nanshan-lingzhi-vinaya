# 校閱材料　第392檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【392-0001】資持記/05e_上四#6
【原文】不應下，遮非。次科，初示別答。若下，指通答。行草中，初科為四，初示所出。如前所明。當下，二令預辦。人別一剪者，意使各敷，恐相連布故；當用一握，長二尺許，剪已束之；須令展布，可容一坐，即為準矣。至下，三明次行。上座跪授，餘人不須。各下，四明敷布。
【譯文】「不應」以下，制止錯誤的作法。下一科，首先指出特別的回答。「若」字以下，指明通例的回答。在鋪設草座的段落中，第一科分為四部分，首先說明草座的出處。正如前面所解釋的。「當」字以下，第二是令眾人預先備辦。每人各自剪取一把，用意是讓大家各自鋪設，擔心會連綿散布在一起；應當取用一握的量，長約二尺左右，剪齊後捆成一束；必須使其展開攤平後，足夠容納一人坐下，這就符合標準了。「至」字以下，第三說明依次鋪行。對上座應當跪著奉遞，其餘之人則不需要。「各」字以下，第四說明鋪設排列。

【392-0002】資持記/05e_上四#7
【原文】於座前者，即所坐席外地上也。注文。有云：重囑預覓。或云：定是預覓，何必重囑？今謂此文。注上敷草；謂若至五德唱已始敷事容倉卒，眾復稽遲；故令受已前敷，待唱即坐；有不依此，特注示之；辨，謂布草備擬坐處也。唱告中。就草座者，告令即時離本座處。偏袒等者，囑後自恣，具儀致敬。
【譯文】「在座前」的意思，就是指所坐席位外面的空地上。注文部分，有人說：這是再次囑咐預先尋覓。也有人說：本來就確定要預先尋覓，何必再次囑咐？現在我認為這段注文，是註解上面鋪草之事；意思是指若等到五德唱白完畢才開始鋪草，事情未免顯得倉促，大眾又會因此延遲耽誤；所以命令接受草料後預先鋪好，等待唱告完畢隨即坐下；有人不依照這套規矩，所以特別註記指明；「辨」，是指鋪設草料以預備坐處。在唱白宣告的段落中。「就草座」這句話，是宣告大眾即刻離開原本的正式座位。「偏袒右肩」等語，是囑咐後續自恣時，必須具足威儀來致敬。

【392-0003】資持記/05e_上四#8
【原文】注令從之，非謂合眾即皆互跪；下云：見五德來，方從座起；故知爾前，但坐草上。人多錯解，令眾疲極，迷文故也。問：所以須坐草者？答：自恣一法，異餘眾事；由是露過，求他誨示，必現卑遜。褥席坐具，不以𭣋藉；屈身平地，同彼罪囚；恐損身衣，故令布草。
【譯文】注文要求依從此法，並不是說全體大眾就要立即同時單膝互跪；下面說：見到五德前來，才從座位站起；由此可知在此之前，只是坐在草座上。世人大多錯誤理解，導致大眾疲累不堪，這都是因為迷失了經文旨意所致。問：為什麼必須坐在草座上？答：自恣這項法事，有別於其餘僧團眾事；由於這是為了披露過失、求取他人誨導開示，必定要顯現卑下謙遜之態。各類褥席坐具，都不得襯墊鋪借；屈曲身軀坐在平地，就如同那些罪犯囚徒一般；因為擔心損傷身體和衣服，所以命令鋪草。

【392-0004】資持記/05e_上四#9
【原文】疏云：言離座者，捨憍慢故；布草坐者，恐有損故；斯為明證，豈復疑乎！〔舊云：佛成道時，吉祥童子施草，今傚佛故；因又妄述受草偈，穿鑿大甚；請以疏驗，早宜廢之。〕然今行事，多從妄習；隨用少草，繫以繒綵；五色間鬪，事同兒戲。又令管句之僧，或復淨人；
【譯文】戒疏說：說要「離座」，是為了捨棄憍慢之心；鋪草而坐，是擔心有所損傷；這就是明確的證明，哪裡還需要懷疑呢！〔古人說：佛成道時，吉祥童子奉獻草座，如今是效法佛陀；並因此妄自造作受草偈頌，牽強附會得太過分了；請依照戒疏來驗證，應當早早將其廢止。〕然而當今行事，大多順從虛妄的習氣；隨意使用少許青草，用彩綢繫縛；五彩繽紛雜亂爭奇，事情弄得像兒戲一般。又派遣經管事務的僧人，或者是淨人；

【392-0005】資持記/05e_上四#10
【原文】分頭俵散，平身拋擲。及至唱告，手擎頂戴；依古謬傳，誦吉祥偈；然後揭起坐具，投之於下。身不離座，復不敷草；違背正教，恣任妄情。況自矜誇，我能講說；至於行事，還逐訛風；臨此明文，信同夢海。況氷情固執，見善不遷；畢身長負於無知，來報更增於愚塞。
【譯文】分頭派散，站著身子隨意拋擲。等到宣告時，用手捧著頂戴在頭上；依照古老荒謬的傳說，念誦吉祥偈；然後掀起坐具，將草投入坐具之下。身體不離開正式座位，也不真正鋪草；違背了正確的教法，任由妄想私情作祟。更何況有人自誇說我善於講說；但到了實際行事時，依然追逐錯誤的風氣；面對這段明文記載，實在如同置身夢海般迷惘。更何況心懷成見頑固執著，見到良善也不思遷改；終身背負著無知的包袱，來世的果報更加增添愚鈍蔽塞。

【392-0006】資持記/05e_上四#11
【原文】知非改過，其唯智人乎！對說中，初引聖儀，誡令倣上。大聖尚爾，下凡不稟，其可得乎！疏具引云：佛坐草座，告諸比丘：汝各坐草座。默久，告諸比丘：我欲受歲，我無過咎於眾人乎？又不犯身口意乎？如是至三，舍利弗言：無三業過，所以然者，不度者度，作眼目醫王，大千界尊，何有過也！
【譯文】知曉錯誤而能改過，難道不只有具足智慧的人才做得到嗎！在對面陳說自恣的段落中，首先引用聖者世尊的威儀，告誡應當效法上聖。大聖佛陀尚且如此，下等凡夫若不稟承遵循，又怎麼說得過去呢！戒疏完備引證說：佛陀坐在草座上，告訴諸比丘：你們各自坐在草座上。沉默許久後，告訴諸比丘：我想要接受歲末自恣，我在大眾之中有過失嗎？又是否曾犯了身口意三業呢？這樣連問三次，舍利弗說：世尊沒有三業之過，之所以如此，是因為能度化未度之人，作為眾生的眼目與大醫王，身為三千大千世界的至尊，怎麼會有過失呢！

【392-0007】資持記/05e_上四#12
【原文】指《新歲經》者，彼云：時三千大千世界，六反震動；一萬比丘得道跡，八千比丘得羅漢；空中八萬四千諸天，皆發無上正真道意等。正自恣法四科，初中。二五德來，一跪一立者，明非雙頭一時說也。今多竝跪，深乖法律；縱前後說，外儀相濫，不能顯別，亦非法也。
【譯文】指稱《新歲經》的內容，是經中記載：當時三千大千世界發生六種震動；一萬名比丘證得初果道跡，八千名比丘證得阿羅漢果；虛空中有八萬四千諸天，全都發起無上正等正覺的道心等等。在正式進行自恣法的四個科判中，第一科判裡。兩位五德前來時，一人下跪一人站立，這表明並不是兩方同時開口陳說。現在的人大多一同下跪，極為違背法律規範；縱然有先後陳說，但外在威儀混淆不清，無法彰顯差別，這也是不合法的。

【392-0008】資持記/05e_上四#13
【原文】次科，上座法中，初修敬者。律因六群反抄衣，衣纏頸裹頭，通肩披衣，著革屣；地上坐，床上坐自恣；佛因制具儀。律列四禮，文略脫屣；偏袒一法，此土不宜。僧隨上座者，律因上座具儀自恣，餘人猶故在座，佛又制之；此亦據五德來時，非謂大眾齊跪；
【譯文】下一科判，上座比丘的儀軌中，首先修持敬禮。律典中因為六群比丘倒撩袈裟、袈裟纏頸包頭、通肩披衣、穿著皮鞋；坐在地上或坐在床上行自恣；佛陀因此制定必須具足威儀。律文列出四種禮敬，文字上略去了脫鞋；偏袒右肩這種作法，在東土並不適宜。僧眾隨同上座比丘行禮，律典中是因為上座具足威儀自恣，其餘大眾依然坐在座上，佛陀因此又作了規定；這也是依據五德前來時而言，並不是指大眾同時下跪；
