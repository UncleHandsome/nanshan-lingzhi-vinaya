# 校閱材料　第584檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【584-0001】03_業疏/02a_卷一之二#7
【原文】次解第三能秉御僧者，四門分別：初制意釋名，二定僧體狀，三明人法相對，四廣顯是非
【譯文】接下來解釋第三門「能秉持操作的僧伽」，分為四門來分別辨析：第一、制戒用意與解釋名稱；第二、判定僧伽的體性狀相；第三、說明人與法的相對關係；第四、廣泛顯明其是與非。

【584-0002】03_業疏/02a_卷一之二#8
【原文】初制意者，僧寶流世，元為生善；然生善在事，假法成立；法不自建，弘斯在人。故制羯磨，必由僧秉。良以五眾為出世之田，凡所造修，無非拔濟，故以僧和之法，能成勝業之緣。何以知然？如果向俗人，雖參聖限，以形乖法別，未許傳授，所以五戒等受授必出家，其意可見
【譯文】第一、制戒的用意：僧寶流傳於世間，本來是為了令眾生生起善法；然而生起善法在於具體的事修，事修又必須藉助如法之規矩才能成立；法規不能自行建立，弘揚它全在於人。所以制定羯磨，必定要由僧伽來秉持操作。這確實是因為出家五眾是超脫世間的福田，凡所造作修持，無不是為了拔苦濟度，所以用僧眾和合之法，能夠成就殊勝善業的勝緣。如何得知是這樣呢？例如證得四果四向的在家俗人，雖然已列入聖者的等位，但因為形貌相違、法軌有別，並不聽許他們傳授戒法，所以受授五戒等必須由出家人傳授，其中的用意便清晰可見。

【584-0003】03_業疏/02a_卷一之二#9
【原文】三能秉制意中，初敘立意，二「良」下推所以。初中「生善」之言，通於自他、世及出世。事即眾別行相，僧非事則不能生善，事非法不立，法非人不弘，則知事法竝依人矣。次所以中，初敘勝能，五眾皆為解脫出家，能生他福，故喻如田；「勝業」即羯磨。「何」下次舉事顯，「果向」即四果四向，「未許傳授」者，此明雖聖而非師也；五八二戒通五眾授，此明雖居下眾，即堪軌物也
【譯文】在第三「能秉御僧」的制戒用意中，起初敘述立意的宗旨，第二自「良」以下推究其所以然。第一部分中，「生善」這句話通於自己與他人、世間法以及出世間法。「事」就是大眾與個人的行持相貌，僧伽若沒有具體法事就不能生善，法事若沒有法軌就不能成立，法軌若無人就不能弘揚，由此可知事相與法軌都依賴於人。在第二部分推究所以然中，起初敘述殊勝的功用，五眾都是為了求得解脫而出家，能夠為他人出生福德，所以比喻為良田；「勝業」就是指羯磨。自「何」以下接著舉出事例顯發，「果向」就是四果四向，「未許傳授」是說明雖然位列聖者卻不可作為傳戒師；五戒與八戒通通聽許由出家五眾傳授，這是說明雖然位居下眾，卻堪能做他人的軌範規範。

【584-0004】03_業疏/02a_卷一之二#10
【原文】言僧伽者，中梵本音，此土無名，比眾以譯，有加和合，乃是義用。故文云：「僧者四人若過，和者羯磨說戒。」即如經律佛法眾也
【譯文】所說的「僧伽」，是中印度梵語的本音，此地沒有完全對應的名詞，便比附「眾」字來翻譯，有的加上「和合」，則是取其義理與作用。所以律文說：「僧是指四人或者超過四人，和是指一同行羯磨與說戒。」正如經律中所說的「佛、法、僧（眾）」那樣。

【584-0005】03_業疏/02a_卷一之二#11
【原文】釋名中，初科初翻名，僧出中梵，故此無名，既無正翻，故取比譯。「有」下點異，或翻和合眾，以眾是名體，故和合為義用。次引律文，顯體用兩別。下指經律，證上單翻
【譯文】在解釋名稱中，第一科起初是翻譯名稱，「僧」出自中梵語，所以此地沒有對應名稱，既然沒有直接的正翻，所以採取比附翻譯。自「有」以下指出相異之處，有人翻譯為「和合眾」，因為「眾」是名稱與體性，所以「和合」是其義理與功用。接著引用律文，顯明體性與功用兩者有別。下面指出經律，以印證上面單獨翻譯為「眾」。

【584-0006】03_業疏/02a_卷一之二#12
【原文】若以眾翻，則通三二；據別顯德，非四不成，故存僧名，知非三也。餘經云眾者，彼不明僧義，故從此翻；律中恐濫，故存本也
【譯文】如果單用「眾」字來翻譯，就會通含兩三人；依據個別法顯發殊勝功德而言，不是四人就不能成就僧團，所以保留「僧」的原名，讓人知道這不是指二三人。其餘經典說「眾」的，那是因為那裡不著重闡明僧伽羯磨的定義，所以順從此方習慣翻譯；律典中唯恐混淆失準，所以保留了梵語的原本音稱。

【584-0007】03_業疏/02a_卷一之二#13
【原文】次科：雖翻為眾，律但稱僧，故須示意。以通名則濫於小眾，據別德則唯局四人，簡通標別，故存梵號。「餘」下釋妨，以餘經中有從華語，故此通之。若爾，上指經律云「佛法眾」，是則律中亦有從華，如《十誦》、《伽論》五眾、十眾受戒，即五十、二僧也；又如當部戒場緣云「有四眾、五眾事起」等。今作二釋：一者從多為言，雖諸律中華梵互舉，多云僧故；二者諸律餘處或標為眾，正明能秉，竝云僧故，如下引律「四種僧」等是也
【譯文】第二科：雖然翻譯為「眾」，但律典中只稱「僧」，所以必須說明用意。因為若用通稱就會混淆於少數人（小眾），依據別德則唯獨限定在四人以上，為了簡別通稱而標顯別德，所以保留梵語稱號。自「餘」以下解釋難阻，因為其他經典中有順從華語的，所以在此加以通釋。如果這樣的話，上面指出經律中說「佛法眾」，那麼律典中也有順從漢語的，例如《十誦律》、《僧伽論》中說五眾、十眾受戒，也就是五人僧、十人僧以及二部僧；又如本部律典在戒場因緣中說「有四眾、五眾事起」等等。現在作出兩種解釋：第一是就多數而言，雖然各部律典中漢梵夾雜互用，但多數稱「僧」的緣故；第二是各部律典在其他地方或許標示為「眾」，但在正式說明能秉持法事時，一律都稱「僧」，正如後文所引律文「四種僧」等便是如此。

【584-0008】03_業疏/02a_卷一之二#14
【原文】相從和義，不無其理；單兩相翻，比眾是本
【譯文】順從附隨「和」的義理，並非沒有其道理；若是單字與雙字互為對譯，「比附為眾」才是其根本。

【584-0009】03_業疏/02a_卷一之二#15
【原文】三中，上二句縱古，以義助名，故曰相從；下二句奪歸前譯。本梵唯標名體，彼加和合，則名義雙標，體用齊舉。梵語唯一，華言兼二，故云單兩相翻。然終非對翻，故云比眾是本
【譯文】在第三科中，前兩句縱容認可古代說法，用義理來輔助名稱，所以說「相從」；後兩句破斥奪回歸於先前的翻譯。原本梵語只標明名稱與體性，古譯加上「和合」，則是名稱與義理雙雙標示，體性與功用一同舉出。梵語只有一個詞，漢語則兼含兩個字，所以說單字與雙字相對翻譯。然而這終究不是字對字的直接正翻，所以說「比附為眾才是其根本」。

【584-0010】03_業疏/02a_卷一之二#16
【原文】然此俗眾二人已上，佛法顯僧其必四人，莫不攬假成用，義相類也
【譯文】然而世俗所稱的「眾」是指二人以上，佛法中要彰顯「僧伽」則必定要四人，無不是藉由假合而成就其功用，在義理上是相類似的。

【584-0011】03_業疏/02a_卷一之二#17
【原文】四中，初示數異；「莫」下顯義同，即前所謂「比眾以譯」，義見此也
【譯文】在第四點中，起初說明人數的差異；自「莫」字以下顯明其涵義相同，這也就是前面所說的「比擬大眾來翻譯」，其意義就在這裡顯現。

【584-0012】03_業疏/02a_卷一之二#18
【原文】二定體狀，就分為三：初列數定體，二立相所由，三攝用分齊并釋除疑執
【譯文】第二、確定體狀，就文義分為三部分：第一是列出人數以確定體質，第二是說明安立相狀的原由，第三是統攝功用範圍並解釋消除疑惑與執著。

【584-0013】03_業疏/02a_卷一之二#19
【原文】就初列數：或凡聖分二，或儀寶分二，或功用以分，即事理兩和。理取會正，非此所明；事取即用，是所機教
【譯文】就第一部分列出人數而言：或者區分為凡僧與聖僧兩種，或者區分為僧儀與僧寶兩種，或者依功用來區分，也就是事和與理和兩種和合。理和著眼於契會正理（證悟聖道），不是這裡所要說明的；事和著眼於當下的具體行事作用，才是此處所對應化導的教法。
