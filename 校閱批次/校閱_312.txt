# 校閱材料　第312檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【312-0006】02_戒疏/20a_卷四下之二#196
【原文】【疏】三、「更增」者，開緣也。還從本制，限外別增。若通取量，即䟦闍子非法之教，廣流於世。
【譯文】【疏文】第三句，「更增」這句話，是屬於開許的事緣。依然必須依照原本的制約，在既定限度之外另行拼接增補。如果一開始就全面按照加大尺寸通體裁剪，那就是跋闍子比丘破壞戒律的非法邪說，如今這類非法作法正在世間廣泛流傳。

【312-0007】02_戒疏/20a_卷四下之二#197
【原文】【記】三中，初科。注引緣起「對佛說」者，即白佛也。「更增各半搩」者，長、廣各一尺，則長五廣四。自昔並於一邊一頭增之，《感通傳》中天神所示，始增四面耳。文中，初牒釋。「開緣、本制」，極分明也。謂先依本制，長四廣三，截落縫緣竟，後於四向各裨五寸，故云「還從本制，限外別增」也。「若」下，顯非。或有不截，直取長五廣四之量，即䟦闍法，《七百結集》中已斷也。今時皆爾，縱截其面，統其底者，亦同非法。
【譯文】【記文】第三句之中，第一段科文。注文引述緣起中「向佛陳說」，就是當面向佛陀稟白陳述。「長寬各自再增加半磔手」，也就是長寬各自再加一尺，那麼總長就是五尺、總寬為四尺。從古以來，都是在坐具的其中一邊或一端進行拼接增長；直到《感通傳》中天神降臨開示，才開創出在四邊周圍均勻增補的做法。疏文中，首先提引解釋。「開許之事緣、根本之制約」，分得極為清楚明白。意思是必須先依照原本的制約，裁成四尺長、三尺寬，裁切並縫合好邊緣之後，然後才在四面邊緣各拼接增補五寸，所以說「依然依照原本制約，在限度外另行增補」。「若通」以下，指出其錯誤。世上有些人不遵循先截斷的原制，直接通體裁剪成五尺長、四尺寬的整塊大料，這正是跋闍子比丘的邪法，在《七百比丘結集》中就已經被判定為非法而斷絕廢除了。現今世人全都是如此違犯，縱使有人將正面表面拼接，底布卻依然使用整塊連貫大料的，同樣屬於違法。

【312-0009】02_戒疏/20a_卷四下之二#199
【原文】【記】次誡約中，又四。初敘恣情。「至」下，次明昧教。「豈」下，三、明愚蔽。初明愚不知過。「求」下，歎智人難得。「求他道過」，謂師友之教。「用自徵治」，謂責己悔露。「知」字去呼。「故」下，四、明非法。今時任意廣作，何論尺量，又不截增。見依法作，反生輕笑。祖師所謂「一生無如法坐處」。臨此慈訓，宜速改迷。
【譯文】【記文】第二段誡勉約束之中，又分為四個層次。首先敘述放縱私情慾念。「至」以下，接著說明對戒律教法的昏聵無知。「豈」以下，第三、說明愚癡障蔽。先說明愚人不知自己的過失。「求」以下，感嘆有智慧的人難能可貴。「求他人指出過失」，是指樂意接受師長與法友的規勸受教。「用以自我檢束懲治」，是指自責與坦露懺悔。「知」字在此讀作去聲（智）。「故」以下，第四、闡明違法的現狀。現今的人任意做大坐具，哪裡還管什麼尺寸限度，更不用說先依原制裁剪後再增邊了。看見有人嚴格遵照戒法製作，反而生起輕視嗤笑。祖師感嘆說「一生當中竟然沒有一處如法的坐臥之地」。面對如此慈悲的垂訓，大家應當儘速改除迷惑。

【312-0039】02_戒疏/20b_卷四下之二#26
【原文】【疏】答：「餘非沙門道服外儀，隨其大小，皆得受用，故有定量。此三法衣，道服標式，若定出量，人有長短，不稱威儀，外不生善，內無軌物，故隨身分，不定出量。由不定故，得有與佛等、過作衣。」
【譯文】【疏文】答：「其餘幾種（覆瘡衣、雨衣、尼師壇）並不是沙門道服的外在儀表，隨著各人身材大小，都可以受用，所以有固定的尺寸。這三種法衣是道服的標誌樣式，如果固定訂出尺寸，人的身材有長有短，穿起來不合威儀，對外不能令人生善，對內也沒有軌範的作用，所以隨著各人的身材分際，不固定尺寸。正因為不固定，才會有與佛衣等量、或超過佛衣尺寸而製作的情形。」

【312-0040】02_戒疏/20b_卷四下之二#27
【原文】【記】問答中，初問。三戒並就比丘制量，此戒但制與佛等過，則比丘衣不出定量。答中，初示餘三定量。「此」下，次明法衣不定。「外不生善」，謂俗容生慢；「內無軌物」，謂令道無取則。「由」下，示後戒元因。若有定制，不容等佛。
【譯文】【記文】問答中，首先提問。其他三戒都是針對比丘身量來制定尺寸，唯獨此戒只限制不可與佛相等或超過，那麼比丘自己的三衣便沒有定出具體極限。回答中，先指明其餘三戒有定量的原因。「此」以下，接著說明法衣尺寸不定的緣由。「對外不生善」是說世俗之人見之容易生起慢心；「對內無軌物」是說使修道者失去標準法則。「由」字以下，指出引發此戒的根本原因。如果有固定限制，就不可能發生等同佛衣之事。

【312-0046】02_戒疏/20b_卷四下之二#33
【原文】【記】次問。或有戒本作「十搩」，故問決之。答中，初示九搩。佛身倍人，故半折之。「故」下，次明十搩。「疑偏狹」者，人情妄謂，故輙加之。周尺「二丈」，若「半」折者，常人一丈。「當今八尺」，即唐尺也。準有八尺四寸，且據全數。「準五肘」者，更引九尺，以挍唐尺。一肘尺八，五肘九尺，將周八尺四寸，為唐「七尺」，餘六寸作「五寸」。「故」下，結示。恐有執諍，故無定奪。
【譯文】【記文】次一個提問。有的戒本寫作「十磔手」，所以提問予以決疑。答覆中，先說明九磔手之說。佛身是常人一倍，所以減半折算。「故」字以下，說明十磔手之說。「懷疑偏窄」是由於人情妄加揣測，所以擅自增加。周尺「二丈」，若折半計算，常人應為一丈。「相當於唐尺八尺」，即以唐尺折算。細準應有八尺四寸，姑且依整數言之。「準五肘」是進一步引用九尺來比校唐尺。一肘為一尺八寸，五肘即九尺，將周尺的八尺四寸折為唐尺「七尺」，其餘六寸折作「五寸」。「故」字以下作總結說明。因為擔心引發執著諍論，所以不作硬性定論。

【312-0049】02_戒疏/20b_卷四下之二#36
【原文】【記】三問。衣鉢事同，何得偏制。答中，初明衣須制，由許隨身，故制過等。次明鉢不須制，三品永定，不容有過。
【譯文】【記文】第三個提問。衣與缽皆是隨身資具，為何只偏在衣服上制戒？答覆中，先說明衣服必須制戒，因為准許隨身形製作，所以必須限制等同或超過佛衣。次說明缽不需要另外制戒，因為大中小三品容量已永久固定，不容許再有過失。

【312-0050】02_戒疏/20b_卷四下之二#37
【原文】【疏】「若爾，佛衣何定量？」
【譯文】【疏文】「既然如此，佛衣為什麼有固定的尺寸呢？」

【312-0051】02_戒疏/20b_卷四下之二#38
【原文】【疏】答：「弟子無限，不可定準。世唯一佛，故衣是定。」
【譯文】【疏文】答：「弟子人數無限，不能訂出確定的標準；世間只有一尊佛，所以佛衣的尺寸是固定的。」

【312-0052】02_戒疏/20b_卷四下之二#39
【原文】【疏】又解：「衣過得截，喜過故制。鉢過無截，希故不制。」
【譯文】【疏文】又有一種解釋：「衣服超過尺寸還可以裁剪，且容易（往往）做過量，所以制戒。鉢超過了無法裁剪，因為這種情形稀少，所以不制戒。」

【312-0053】02_戒疏/20b_卷四下之二#40
【原文】【記】轉難中，初難。答中兩解。初約師徒一多釋。「又」下，次約截除希數釋。
【譯文】【記文】轉接問難中，第一難。回答有兩種解釋。第一種是依從師徒一多之別來解釋。「又」字以下，第二種是依截除過剩的難易與機率來解釋。
