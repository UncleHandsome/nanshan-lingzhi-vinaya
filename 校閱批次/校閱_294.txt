# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【294-0001】02_戒疏/15c_卷三下之三#49
【原文】【疏】二、非時漿。手防二罪：一、防一往不受，二、防不受而捉惡觸，同時食也。口防亦二：一、防過時失受不受；二、防過時失受惡觸也。
【譯文】【疏文】第二、非時漿。手受能防範兩種罪過：第一是防範完全未經接受而飲用，第二是防範未受而捉持造成惡觸，這與時食（手受所防之二罪）相同。口受也能防範兩種罪過：第一是防範超過正午失去受法效力而變成未受食；第二是防範超過正午失去受法效力而造成惡觸。

【294-0002】02_戒疏/15c_卷三下之三#50
【原文】【記】非時中。「口防二」者，若不加法，「過時失受」，則有「不受」「惡觸」二罪。
【譯文】【記文】在非時漿之中。「口受防範兩種罪」是指如果不用口法加持，「過時便失去受法」，就會產生「未受食」與「惡觸」兩種罪過。

【294-0003】02_戒疏/15c_卷三下之三#51
【原文】【疏】三、七日藥中。手受防二，同前二藥。口法防四：一、防過時失受不受；二、防失受惡觸；三、防經夜無殘宿罪；四、防經夜無內宿罪也。據《律》文中，內宿一罪盡形藥開，七日不明。故知閉也。則口法防三，不防內宿。故《僧祇》中比丘七日藥，與僧食同處者，是知淨地攝也。
【譯文】【疏文】第三、在七日藥之中。手受能防範兩種罪過，與前面的兩種藥相同。口法能防範四種罪過：第一、防範過時失去受法而變成未受；第二、防範失去受法而造成惡觸；第三、防範隔夜存放而無殘宿罪；第四、防範隔夜存放而無內宿罪。但是依據《四分律》的原文，內宿罪只在盡形壽藥中開許免犯，七日藥中並未明文開許。因此可知本律是禁止七日藥內宿的。如此一來口法只能防範三種罪過，並不能防範內宿罪。所以《僧祇律》記載比丘的七日藥如果與僧團常住的食物放在一處，由此可知必須是收置在淨地之中才可以。

【294-0004】02_戒疏/15c_卷三下之三#52
【原文】【記】七日中。口法防四，且依昔判。彼謂七日得同內宿，初二同上非時，下二越宿，由加口法而無殘、內。「據」下，次明今判。《律》中非時、七日限內，但開殘宿、惡觸、非時等罪；唯盡形藥開內宿、內煑、自煑等。準此，照前不開七日，則知口法不防內宿，故但三罪。「故」下，引證。既安淨地，決知不開。
【譯文】【記文】在七日藥之中。口法能防範四種罪，暫且是依據古德的判定。古德認為七日藥可以如同免除內宿一樣，前兩種罪與前面的非時漿相同，後兩種是跨越黑夜，由於加持了口法而免除殘宿罪與內宿罪。「據」字以下，接著說明今師的正判。本律在非時藥與七日藥的期限之內，只開許免犯殘宿、惡觸、非時等罪；唯獨盡形壽藥才開許免除內宿、內煮、自煮等罪。依照這個標準，對照前面並未對七日藥開許內宿，便可知口法無法防範內宿罪，所以只能防範三種罪過。「故」字以下，引用律文作證。既然必須安放在淨地，就堅決可知律典並未開許內宿。

【294-0010】02_戒疏/15c_卷三下之三#58

【294-0011】02_戒疏/15c_卷三下之三#59
【原文】【記】非時中。「口三罪」者，明出限外，故犯「非時」，此即時中犯非時也；由曾加受，故有「殘宿」；由失受法，即有「惡觸」。但加非時，故云「與手少異」。若據手受過午，合有非時，那不明者？思之可解。

【294-0018】02_戒疏/15c_卷三下之三#66
【原文】【記】「有」下，次斥六罪。彼謂更有不受一提。「今」下，彰非。謂過限法失藥體，任運自是不受，不同非時、殘宿，當體是過，故云「非罪攝」也。縱不受服，亦非因受而生，此明生罪，故不可立。
【譯文】【記文】「有」字以下，接著駁斥六種罪的說法。對方認為還應當滋生一條未受食的波逸提罪。「今」字以下，闡明其謬誤。意思是說一旦超過期限受法失效，藥物本質自然就變成未受之物，不同於非時罪、殘宿罪本身就是罪咎本體，所以說「不屬於此處所討論的生罪範疇」。縱使未經手受而服用，也不是因為當初口受而滋生的，此處是在討論由受法滋生的罪過，所以不能成立此說。

【294-0019】02_戒疏/15c_卷三下之三#67
【原文】【疏】盡形藥者。手生二罪，同上可知。口不生罪，由聖開加，法不失故。
【譯文】【疏文】盡形壽藥：手受滋生兩種罪過，如同上述可以明瞭。口法不會滋生罪過，因為聖者佛陀開許加持，只要生命未終受法便不會失效。

【294-0020】02_戒疏/15c_卷三下之三#68
【原文】【記】盡形中。「口法不生罪」者，由加口法為防諸過，法無限齊故不生罪。若據《鈔》中，言生六罪，五同七日，更加不病而服，猶循古義。今此所明，乃為盡理。
【譯文】【記文】在盡形壽藥之中。「口法不生罪」，是因為加持口法是為了防禦各種過失，而此法沒有時間終點的限制，所以不會滋生罪過。如果按照《行事鈔》所說，說會滋生六種罪，其中五種與七日藥相同，再加上無病而服藥的一罪，那是沿襲古德的說法。現在疏文此處所闡明的，才是最究竟透徹的法理。

【294-0021】02_戒疏/15c_卷三下之三#69
【原文】【疏】「若爾，被觸何不須受？」
【譯文】【疏文】問：「如果這樣，藥物被觸碰破壞時為什麼不需要重新受法呢？」

【294-0022】02_戒疏/15c_卷三下之三#70
【原文】【疏】答：「作法加持，雖觸不失。如《僧祇》中：『石蜜與俗，又施比丘，本法不失。』誠知盡形無由失法。如《善見》中：『病雖暫止，本法不失。』故《律》中『無病因緣，服但吉羅』，以有法也。若不加法，還同墮矣。」
【譯文】【疏文】回答：「作法加持之後，縱使被觸摸也不會失法。如同《僧祇律》記載：『石蜜送給俗人，俗人又轉贈給比丘，原來的受法並未失去。』由此切實可知盡形壽藥完全沒有失法的理由。如同《善見律》所說：『病情雖然暫時痊癒，原本的受法依然不失。』所以本律中說『若無疾病因緣，服用只犯突吉羅罪』，就是因為身上受法還在的緣故。如果未曾加持口法，隨便服用就還是等同犯波逸提罪了。」

【294-0023】02_戒疏/15c_卷三下之三#71
【原文】【記】問中。疑有觸失生惡觸故。答中。初義判。「如」下，引證。《僧祇》，彼因比丘以第七日石蜜與優婆塞，彼乃持與餘比丘，即日得石蜜，不作淨而取。此準七日以例盡形。則知《僧祇》七日限內，例無觸失，與上《多論》部計不同。次引《善見》，病止法存，何由生過？「故」下，後準本律，無病服輕，則知盡形口法一加，終身不失。
【譯文】【記文】在問難之中，是懷疑藥物會因觸摸失法而滋生惡觸罪。在回答之中，起初先依法理判定。「如」字以下，引用律文作證。《僧祇律》中，是因為比丘將第七天的石蜜送給優婆塞，優婆塞又拿去轉送給其他比丘，當天得到石蜜的比丘，不必作說淨法就可以直接領取。這是拿七日藥的特例來比照盡形壽藥。由此可知《僧祇律》在七日之內，一概沒有觸摸失法的規定，這與上面《薩婆多論》的部派主張不同。接著引用《善見律》，既然病好了受法依舊存在，哪裡會滋生罪過？「故」字以下，最後對照本律，無病服藥罪責極輕，由此可知盡形壽口法一旦加持，終身都不會失法。

【294-0024】02_戒疏/15c_卷三下之三#72

【294-0026】02_戒疏/15c_卷三下之三#74
【原文】【疏】三、畜用輕重者。
【譯文】【疏文】第三、論述蓄存與使用的輕重差別。

【294-0027】02_戒疏/15c_卷三下之三#75
【原文】【疏】四藥之中，七日畜重，餘三並輕。所以然者？蘇、油資重，體存貪貯，垢心重故；又由常存，說淨離著，反違聖教，過期不說。所以制重。時藥一種，雖資用強，體現交盡，多無久延，不制說淨，無應說不說之過，故輕。非時漿者，時狹體微，情無久畜。盡形壽藥，雖得久延，療患義微，畜心皆薄，既無貪貯，不制說淨，故輕。
【譯文】【疏文】在四種藥之中，七日藥蓄存的罪責最重，其餘三種都很輕。為什麼會這樣呢？酥油等物滋補力強，容易讓人心生貪戀儲存的念頭，染污之心非常重；又因為能夠長期存放，必須透過說淨法來遠離執著，若反過來違背佛陀聖教，超過期限也不說淨，所以制定的罪責特別重。時藥這一種，雖然資補身體的作用強烈，但本質上當下就會吃完，大多無法久留，律中不強制要求說淨，沒有應說淨而不說淨的過失，所以罪責輕。非時漿的飲用時段狹窄、體質微弱，心裡不會想要久蓄。盡形壽藥雖然能長久保留，但治療特殊疾病的意義微弱，蓄存的貪心都很淡薄，既然沒有貪心積存，就不強制規定說淨，所以罪責輕。

【294-0028】02_戒疏/15c_卷三下之三#76
【原文】【記】三、明畜用。初明畜中，初科為二。初總示。「重」謂犯提，「輕」即結吉。「所以」下，別釋，又二。初明七日畜重，有四義：一、資重，二、貪畜，三、常存，四、違教。「時」下，次明三藥輕。時藥但有初義，非時四義俱無，盡形止有第三一義。然非時一種，義無久畜，計非所論，所以文中不云輕也。或容暫畜，故例明之。
【譯文】【記文】第三、說明蓄存與使用。在起初說明蓄存中，第一小科分為兩部分。首先總括開示：「重」是指犯波逸提罪，「輕」就是結突吉羅罪。「所以然者」以下，個別解釋，又分為兩部分。首先說明七日藥蓄存罪重，具有四種意義：第一是資補重，第二是起貪蓄，第三是常久存，第四是違佛教。「時」字以下，接著說明其餘三種藥罪責輕。時藥只具備第一種資補意義，非時漿四種意義全無，盡形壽藥僅有第三種久存的意義。然而非時漿這一種，理應無法長久蓄存，本來不應列入長蓄的討論範疇，所以文中沒有明言其輕。但也容許有短暫蓄存的可能，所以一併例行說明。
