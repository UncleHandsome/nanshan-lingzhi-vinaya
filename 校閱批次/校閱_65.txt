# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【譯文】【疏文】是哪十種助緣呢？第一是審量前面的事由；第二是依託界限以成立作法；第三是召集僧眾的威儀軌度；第四是以羯磨法成就合格僧眾；第五是和合與分立之相的辨別；第六是簡別大眾的清淨與染污；第七是呈交意願以表達和合；第八是陳述說戒的本事由來；第九是提出詢問確立所宗之法；第十是標舉宗要圓滿回答。

【65-0002】02_戒疏/02d_卷一上之二#38
【原文】【記】別列中。大約為言，一、八及十，緣通事別；餘之七種，緣相俱通。今文第八，隨事顯緣，故云「陳戒」，即行籌告令也。四中「以法成」者，謂自然、作法，各攝分齊，即《羯磨》云「約界明集」是也。
【譯文】【記文】在分別列舉十緣之中。大體說來，第一、第八以及第十緣，其助緣通於一切法，但具體事項各自不同；其餘的七種，助緣的體相則全都是相通的。現在經文中的第八緣，是隨著眼前說戒之事來顯發助緣，所以說「陳戒」，也就是行籌告令的大眾集會。第四緣中的「以法成」，是指在自然界或作法界中，各自收攝其應有的法規分限，也就是《隨機羯磨》所說的「依界限以辨明僧集」。

【65-0003】02_戒疏/02d_卷一上之二#39
【原文】【疏】斯之十緣，即十門義。各有量據，不可卒施。具如所撰《刪補羯磨》及彼疏中具辨。臨機引用，廣略隨宜也。其中問答釋疑，一同彼說。若欲寫取，此復何難？以紙墨易繁，時功難駐。不獲已者，時復疏之。此既大義，業相因由，理須遙指，何得復略？然有不見彼文者，此乃往緣，以業自責。余老矣，桑榆轉迫，不暇重述也。
【譯文】【疏文】這十種助緣，就是十門精深的義理。各自具有嚴格的分寸與法度依據，絕不可草率行事。詳細的情形，如同我在所撰述的《刪補隨機羯磨》以及《隨機羯磨疏》中所詳細辨析的。在面臨具體機緣引用時，詳盡或簡略應隨宜掌握。其中的問答與釋疑，完全與該書所說的一樣。如果想要將它抄錄到此處，這又有什麼困難呢？只是因為紙張墨水容易造成文字繁冗，而寶貴的光陰卻難以停留挽留。不到迫不得已的情況，才偶爾在此略加疏解。這既然是至關重要的大義、是羯磨行相的起因緣由，在道理上本來就必須遠遠指引學者去查閱彼書，怎麼可以又簡略略過呢？然而有些學者未能得見那部著述，這也是過去世的因緣使然，應當以自身的業障而自加省責。我如今年事已高，桑榆暮年日漸逼近，實在沒有多餘的精力再次重複敘述了。

【65-0004】02_戒疏/02d_卷一上之二#40
【原文】【記】結略中二，初指廣。《隨機羯磨》有二卷，「十緣」見上卷之首。《疏》本四卷，今為八卷。「若欲」下，二、顯略，有二：一慮文繁不逗機故，二恐費時妨自行故。「不」下，示下有所明。「此」下，顯上須對指。「然」下，傷後世不遇。《羯磨疏》者，彼文委辨緣成，廣明非相。作業成敗，被事如非。示眾別之行儀，顯僧宗之綱要。維持修奉，不學焉知？故不見者則投心無所，舉事成非。教既不通，行何所託？況疾滅三寶，無利羣生！實由往世業緣，致使難遭正法。然今鏤板，教府盛傳，我輩獲聞，實唯宿慶。然常情淺狹，貴少賤多，雖復聽尋，尠能注意，寄言後學，勿事悠悠。「余」下，重示略意。日之西垂，影在樹端，謂之「桑榆」。「迫」即訓近，言居世不久，以重修時，七十許矣。
【譯文】【記文】在結語簡略的文句中分為兩層，首先指出廣博的著述。《隨機羯磨》有兩卷，「十緣」見於上卷的卷首。《羯磨疏》原本為四卷，如今改編為八卷。「若欲」以下，是第二層，顯明簡略之意，這有兩點考慮：第一是擔憂文字繁多無法切合當前學人的根機，第二是恐怕耗費光陰妨礙自身的修行工夫。「不」字以下，說明下文中仍會有所闡發。「此」字以下，顯明上述內容必須與彼書對照指引。「然」字以下，感嘆後世學人難以值遇正法。《羯磨疏》這部書，在其中極其詳細地辨明了助緣如何成就，廣泛揭示了非法非相的過咎。羯磨法事的成功或失敗、所對應的事相如法或違法，都展示了大眾與個別行事的軌儀，彰顯了整個僧團律宗的根本綱領。這維持正法與修持奉行的關鍵，若不深入研學又如何能得知呢？所以沒見過此書的人，用心往往無所適從，一有所舉動便成了過失。戒律教理既然不通達，行持又該寄託在何處呢？更何況這會加速三寶的滅亡，對一切眾生毫無利益！這實在是由於過去世的業力因緣，才導致難以值遇這無上的正法。然而如今該書已經雕刻版印、在佛教界廣泛流傳，我們這一代能有幸聽聞獲閱，實在全憑宿世的大福報。然而凡俗之情多半淺陋狹隘，珍貴稀有之法卻賤視常見之物，雖然時常聽聞探尋，卻很少有人能夠真正用心注意。在此謹寄語後世學人，切莫悠悠度日、虛擲光陰。「余」字以下，再次表明文字簡略的苦衷。太陽向西落下，餘光映在樹梢，稱為「桑榆」。「迫」就是逼近的意思，說明自己在世間的時日已經不多，在重修此疏之時，年紀已經大約七十歲了。

【65-0008】02_戒疏/02d_卷一上之二#44

【65-0009】02_戒疏/02d_卷一上之二#45
【原文】【記】和合中，初科。「情事」，「情」即僧心，「事」即說戒。事涉是非，情容異見，故有「相違」。
【譯文】【記文】在「和合」的第一個科判中。「情事」的「情」是指大眾的心意，「事」是指說戒法事。事相牽涉到正確與錯誤，心意容易產生不同的見解，所以才會有「相違」。

【65-0010】02_戒疏/02d_卷一上之二#46
【原文】【註】時，有與同師、知識別部說戒。法當尊重承事，恭敬布薩，一處住和合說戒；違者與罪。佛言，有三種和合：一、應來者來；二、應與欲者與欲；三、現前得訶者不訶。反此，別眾也。
【譯文】【註文】當時，有比丘與同門師長、知己道友分開，另外在不同部眾處所說戒。依律法應當尊重承事、恭敬舉行布薩，在同一個處所住處和合共同說戒；若有違背者，便結相應之罪。佛陀宣示，有三種和合：第一、應當到場的人都到齊；第二、應當傳達與欲的人都傳達了與欲；第三、在座可以提出異議的人都不提出反對。反過來這三點，就是分立成別眾。

【65-0011】02_戒疏/02d_卷一上之二#47
【原文】【疏】注中引「與師友別說戒」者，為表教法所被，元在機緣，緣有和、別。即界無二，遠表無我之理，近成兼濟之能。故須「尊重承事」，用開相利之道也。
【譯文】【疏文】註解中引用「與師長同道分開另外說戒」的典故，是為了表明教法所要化導的，原本在於大眾的機緣，而機緣有和合與分裂的不同。在同一個戒界之內不能分為兩派，向遠處說是為了表徵無我的真理，在眼前則能成就自他兼濟的道德功德。所以必須「尊重承事」，用來開闢彼此互利的菩提大道。

【65-0012】02_戒疏/02d_卷一上之二#48
【原文】【記】釋注中，初文。前釋緣起。「教法」即和合之制。「在機緣」者，顯教不孤起。「緣和別」者，「同師」是和，「別部」即別。「即」下，釋制意。未證真理，即事表之，故云「遠」也。「兼濟」謂自他二利，「能」謂功德。
【譯文】【記文】在解釋註解的第一段文中。首先解釋因緣的發起。「教法」是指和合說戒的這條制度。「在機緣」顯明了教法絕非憑空孤立發起。「緣有和別」是指「同師」就是和合，「別部」就是分裂。「即」字以下，解釋制戒的深意。在尚未親證真諦之前，藉由事相上的和合來表彰真理，所以說是「遠」。「兼濟」指自利與利他兩方面，「能」就是功德。

【65-0013】02_戒疏/02d_卷一上之二#49
【原文】【疏】「有三種和」下，開其相也。初和，身集也；二、心；三、口也。「反成別眾」者，以僧之為義，同具六和，三業片乖，不名僧務。廣如彼說也。
【譯文】【疏文】「有三種和」以下，是展開說明和合的具體行相。第一種和合，是身業的聚集；第二種是意業；第三種是口業。「反成別眾」的意思是，僧團之所以稱為僧，本質在於共同具備「六和敬」，三業之中只要稍有一點違背，就不能稱為清淨成辦的僧事。詳細情形正如彼處《羯磨疏》中所說。

【65-0014】02_戒疏/02d_卷一上之二#50
【原文】【記】次和別中，初釋三和。上但通制，此分三相，故云「開」也。「反」下，釋三別。謂應來者不來，是身別；應與欲者不與欲來，是心別；現前得訶者訶，是口別。「具六和」者，且通舉之。此中但取相和，故下別指「三業」。餘三體和，屬下「僧集」。下指「如彼」，即《羯磨疏》。
【譯文】【記文】在接下來的「和別」段落中，首先解釋三種和合。上面只是泛論制作規定，這裡分析出三種行相，所以說「開」。「反」字以下，解釋三種別眾。也就是說應當到場的人不到，這是身業分裂；應當傳達與欲的人不給欲而私自不來，這是意業分裂；現場可以提出異議的人出言反對，這是口業分裂。所謂「具備六和」，是暫且通泛地列舉。這裡只取事相上的三業和合，所以下文特別指出「三業」。其餘的三種理體和合（同戒、同見、同利），則屬於下文的「僧集」。下文指出的「如彼」，就是指《羯磨疏》。

【65-0015】02_戒疏/02d_卷一上之二#51
【原文】【律】僧集會？
【譯文】【律文】僧眾都集會了嗎？

【65-0016】02_戒疏/02d_卷一上之二#52
【原文】【疏】二、「僧集會」者，廣說和白，非僧不行。前雖送和，未顯成僧之法。必須戒、見、利三，名表圓成之相，故言「僧集會」也。
【譯文】【疏文】第二個問答「僧集會」，是因為詳細說戒以及作白法羯磨，如果不是如法的僧眾就無法施行。前面雖然已經送來了和合之意，但尚未顯明構成合格僧眾的實質法度。必定要以戒律、見解、利養這三種理體和合，名副其實地表彰出功德圓滿的體相，所以才問「僧集會」。

【65-0017】02_戒疏/02d_卷一上之二#53
【原文】【記】僧集中，初敘廣說須僧。「前」下，簡前相濫。三業外相，猶非僧體，故云「未顯」等。「必」下，正釋今文。內外兩和，體相俱備，故云「圓成相」也。
【譯文】【記文】在「僧集」的科判中，首先敘述廣說戒法必須依靠合格僧團。「前」字以下，簡別與前文看似混淆之處。三業的外在表相，依然不是僧團的內在體質，所以說「未顯」等。「必」字以下，正式解釋現有的文句。內在理體與外在事相兩種和合、體與相全都具備，所以稱為「圓成相」。

【65-0018】02_戒疏/02d_卷一上之二#54
【原文】【疏】有人合之，兩成一句。今言「僧會」，是和合也。如《律》「功德衣」中「僧集和合」，則前後不同。據理通得，分為二分，顯義易見也。
【譯文】【疏文】有人將這兩問合併，兩句合為一句。照他們看來「僧會」指的就是「和合」。但正如《四分律》在「功德衣」一節中所說的「僧集和合」，先後的排序截然不同。依據法理兩者雖然都能說得通，但將它們分為兩個獨立部分，文義才能彰顯得清楚易辨。

【65-0019】02_戒疏/02d_卷一上之二#55
【原文】【記】指異中。初出異見。「今」下，顯今釋。「是和合」者，謂舉三體，成前三相故。「如」下，舉例。彼此二處，前後列異，可驗非合。「據」下，縱奪顯意。「分」即段也。
【譯文】【記文】在指出異解的文字中。首先提出他人的不同看法。「今」字以下，顯明當前疏文的解釋。所謂「是和合」，是指舉出體和的三者，來成就前面相和的三業。「如」字以下，列舉先例。在不同的地方，先後排序各有差異，足可驗證兩者並非同一件事。「據」字以下，退一步承認兩說皆通並彰顯本疏取捨的意旨。「分」指的就是段落。

【65-0020】02_戒疏/02d_卷一上之二#56
【原文】【註】時，有比丘說戒日，若在界內，若有戒場，不往說戒處。佛言：「應求，應喚，是我所教。若出界外，若往而不坐者，如法治之。」
【譯文】【註文】當時，有比丘在說戒的日子裡，無論是在結界內、或是有專設的戒場，都不肯前往說戒的處所。佛陀宣示：「應當去尋找他、應當去喚召他，這是我所教導的。如果他逃出界外，或是到了現場卻不肯坐下來參與，都要依照戒法懲治他。」

【65-0021】02_戒疏/02d_卷一上之二#57
【原文】【疏】注中引「說戒時，界之內外不集坐」者，為表法本為人，人通勤惰，理必相攝，故雖界外，亦須內集。
【譯文】【疏文】註解中引用「說戒的時候，戒界的界內界外都不聚集坐定」的公案，是為了表明教法原本是為人而設立的，而人的性情通於勤奮與懈怠兩種，在道理上必定要彼此引導攝受，所以即便有人走到了界外，也必須讓他聚集到界內來。

【65-0022】02_戒疏/02d_卷一上之二#58
【原文】【記】釋注，約界集中，初科。「人通勤惰」者，勤者至期奔集，惰者不往須求。
【譯文】【記文】在解釋註解、探討依界集會的段落中，這是第一小節。「人通勤惰」的意思是，精勤的人到了約定日期便會奔走集會，懈怠的人不肯前去就必須去尋求呼喚。

【65-0023】02_戒疏/02d_卷一上之二#59
【原文】【疏】問：「元結界法，為欲簡人。通界無別，自得說戒，何須外集？若須集者，用結何為？」
【譯文】【疏文】有人發問：「當初結界的法規，就是為了簡別淘汰人。在同一結界內既然沒有分裂，自己本就可以說戒，何必非要讓界外的人也聚集成一處呢？如果非要叫界外的人聚集，那當初又何必結界呢？」

【65-0024】02_戒疏/02d_卷一上之二#60
【原文】【疏】答：「結界之意，為行僧法。法有通別，故制開遮。羯磨多為別興，不集無過。說戒通收淨穢，有背結罪。欲使淨者行教，染者順方，則機教兩舉，定慧斯剋，化流不絕，成護法也。」
【譯文】【疏文】回答：「結界的真正用意，是為了能如法推行僧團的羯磨法。法度有一般與特殊的差別，所以戒律制定了開許與遮止。一般的羯磨多半是為個別特定的事項而發起，界外的人不來集會並沒有過失。然而說戒卻普遍收攝清淨與染污的大眾，若有違背便結相應之罪。這是為了使清淨者得以奉行教法，染污者也能順從相應的悔過軌範，如此一來根機與教法雙雙得以振興，定學與慧學就能因而成就，正法教化才能流傳不絕，從而成就護持正法的大業。」
