# 校閱材料　第902檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【902-0001】資持記/01d_上一上#12
【原文】次科，上二句敘分宗。《義鈔》云：毱多受法既少，不能均融，故分五部；然既大聖懸記，蓋是時機所宜；執諍雖殊，無非證道；即《大集》云：五部雖異，不妨諸佛法界涅槃是也。下二句明各集。競謂爭馳。言大眾者，此濫窟外部。《高僧傳》論云：上座大眾，創分結集之場；
【譯文】下一個科判，前兩句敘述分立宗派。《義鈔》說：優波毱多尊者所承受傳承的法藏已有所減損，不能普遍融通，所以分裂為五部；然而既然大聖佛陀早已有所預言，這大抵也是順應了當時根機的需要；彼此的見解爭論雖然殊異，無一不是為了證悟聖道；這就是《大集經》所說的：五部派雖然有差別，卻無礙於諸佛所開顯的法界與大般涅槃。後兩句說明各自結集律典。「競」是指爭相奔走。所謂「大眾部」，這裡容易與洞窟外的結集大眾相混淆。《高僧傳》論評說：上座部與大眾部，最初分立結集的道場；

【902-0002】資持記/01d_上一上#13
【原文】彼言大眾，乃是窟外；此云大眾，定是窟內，即今《摩訶僧祇》。此翻大眾，以五百人亦大眾故〔《智論》則云千人〕。是則大眾名通二部，上座唯局窟內，學者須細辨之。一家者，且據五部各自為言。三中。初輕重異者。一約罪釋。本宗初篇重犯，餘部但吉。本宗犯罪方便隨滅，餘律仍存。
【譯文】那裡所說的大眾部，是指窟外結集的大眾；這裡所說的大眾部，必定是指窟內結集的大眾，也就是現在的《摩訶僧祇律》。「僧祇」翻譯為大眾，因為五百位阿羅漢也是廣大的僧眾〔《大智度論》則說是千人結集〕。由此看來，「大眾」這個名稱通於這兩個部類，而「上座」的名稱則唯獨局限於窟內，修學者必須仔細明辨。「各成一家」，暫且是依據五部分立各自的學說來立論。在第三項中。第一是罪責輕重的差異。第一種就判罪的角度解釋：本宗在初篇波羅夷罪中判為重複犯罪，其他部派律典則只結吉羅罪。本宗判定犯戒的預備前方便行為隨之消滅，其他律典則判定預備行為的罪名依然留存。

【902-0003】資持記/01d_上一上#14
【原文】《四分》女觸比丘蘭，《十誦》結殘。《十誦》身根互壞，觸者蘭；《四分》捉髮亦殘。〔且略遣文，餘尋〈釋相〉。〕二約亡物釋。下云然此亡物，諸部未融等。錫杖澡罐針錐等物，《四分》歸重；餘律並輕〔如〈二衣〉中〕。三約事釋。如《四分》受戒，緣具方成故重；餘宗緣闕並開〔如無和尚無衣鉢等〕。
【譯文】《四分律》判定女人觸碰比丘結偷蘭遮罪，《十誦律》則結僧殘罪。《十誦律》判定身體諸根互有殘壞者，若行觸碰結偷蘭遮罪；《四分律》則判定只要牽扯頭髮也結僧殘罪。〔暫且簡略引述經文，其餘請查尋〈釋相篇〉。〕第二種就處理亡僧遺物的角度解釋。下文說：然而關於這類亡僧的遺物，各部律典尚未融通貫徹等。錫杖、水罐、針錐等日用物品，《四分律》歸屬於重物（僧團常住物）；其餘律典則都判定為輕物（亡僧隨身物）〔如同〈二衣篇〉所說〕。第三種就辦理僧事的角度解釋。例如依照《四分律》傳授具足戒，必須各項緣備齊全才能成就戒體，所以要求嚴謹偏重；其他宗派在緣法欠缺時大多予以開許〔例如缺少和尚、缺少衣缽等情形〕。

【902-0004】資持記/01d_上一上#15
【原文】本宗轉欲則輕，餘宗不開故重。本宗悔殘，微乖法式，悔罪不出，故重；《十誦》不行別住六夜，直得出罪，故輕。二持犯分途者。即如上引境想不同。又《四分》婬戒，並據毛頭；《十誦》論犯過皮過齒。《四分》隨處盜五成犯，《十誦》取本古錢方結。《僧祇》通夜護衣，《四分》限在明相。三有無遞出者。
【譯文】本宗開許轉達欲法（轉託代理投票）故行事寬簡，其餘宗派不許轉託故要求嚴格。本宗懺悔僧殘罪，只要稍微違背法度儀式，懺悔的罪過就無法消除，所以要求嚴格；《十誦律》若未依規履行別住與六夜行法而直接與其出罪，受懺者依然得出罪，所以處分較寬鬆。第二是持犯界限互異。也就是如同上面所引述的，在境想判定上存在差異。又如《四分律》判定犯淫戒，完全依據接觸毛髮之端即成犯；《十誦律》論定犯戒則必須超過皮層、穿過齒列。《四分律》隨不同處所只要偷盜達五錢即構成犯戒，《十誦律》則必須參照古代的錢幣標準才結定罪名。《僧祇律》通融整夜都能守護衣物，《四分律》則嚴格限制在破曉天明時分。第三是條文有無互見。

【902-0005】資持記/01d_上一上#16
【原文】遞亦互也。即如上引眾學有無。及盜非畜物，《四分》無文，並準《十誦》。《四分》二寶蠶綿並無悔法，《十誦》出之。又《四分》衣界通有勢分，餘部皆無等。四廢興互顯者。《四分》歌聲說戒用廢，《五分》直說取興。《四分》開結淨地用廢，《十誦》制斷取興。
【譯文】「遞」也是交互的意思。也就是如同上面所引述的，眾學法各部條文互有有無。以及偷盜非人類與畜生財物的行為，《四分律》沒有明文規定，都必須比照《十誦律》處理。《四分律》對於佛法二寶物以及蠶絲綿綢並沒有制訂悔過之法，《十誦律》則明確列出。又如《四分律》判定衣界普遍設有勢分地界，其他部派則全都未設等。第四是廢教與興教在各部互有顯現。《四分律》仍採用了已被廢除之法（歌聲說戒），《五分律》則採用了後興之正制（平直說戒）；《四分律》採用了前開之教（開結淨地），《十誦律》則採用了後制之斷禁。

【902-0006】資持記/01d_上一上#17
【原文】又如《僧祇》牒事說欲用廢，《四分》不牒取興之類。次明取用，初科，標示中。立四分為本者，順本受體，離前互判過也。須用諸部者，行事有據，離後執隅過也。引論中。欲明取舍有所準故。此論五百羅漢造，釋《四分律》；初牒釋婬戒緣起已，將入戒本，即變為宗論。
【譯文】又如同《僧祇律》採用了已被廢除之法（逐條呈白具體事由以說欲），《四分律》不逐條陳述而取用興行之類。其次說明取捨引用的準則，在第一小節標明示知中。立定《四分律》為根本宗乘，是為了隨順受戒時所納受的根本戒體，避免前面所說互用他律判罪的過失。必須兼用其餘各部律典，是為了讓羯磨行事具有正當依據，避免後面執著於一隅的偏失。在引用論典的段落中。是為了闡明取捨教法時都具有準則依據。這部論典是由五百位阿羅漢所造，用來解釋《四分律》；最初條分縷析解釋完淫戒的緣起之後，即將進入戒本正文時，論調就轉變為立宗的專論。

【902-0007】資持記/01d_上一上#18
【原文】其中一羅漢曰：於戒句中〔即下隨本。〕，於戒本中〔即下本也。〕，於問難中〔即法師語。〕，若欲知者，有四毘尼；諸大德等，如鈔所引。然諸羅漢並具神通，不無勝劣，故選召能者耳。抄出者，傳于貝葉也。上是告眾之詞。一本下，出四法之相。初本中。
【譯文】其中一位阿羅漢說：在戒相的細微名句之中〔也就是下文的隨本。〕，在戒本的正文之中〔也就是下文的根本。〕，在問難釋疑的論辯之中〔也就是法師語。〕，如果想要通曉了解，有四種毘尼法則；各位大德等人，正如《行事鈔》所引用的。然而各位羅漢雖然都具備神通，智慧論辯不免仍有高下之分，所以才選拔召集其中的能者罷了。「抄出」，是指將義理抄寫流傳在貝葉經上。以上是向大眾宣告的話語。從「一本」往下，是列出四種法則的名相。在第一項「根本」之中。

【902-0008】資持記/01d_上一上#19
【原文】云一切律藏，即指當部諸戒，非謂通諸律也。二隨本下，略其釋文。論云：四大處名為隨本〔論文難解，諸釋不同；且依古記約通別二緣注之。〕，佛告諸比丘：我說不淨〔性惡遮惡，俱是不善，故不清淨。〕而不制〔癡狂心亂，並通開故。〕，然此隨入不淨〔一念心憶，是比丘便入犯位。〕；
【譯文】經文說「一切律藏」，就是指本部所屬的各條戒律，並非指通融所有的律典。在第二項「隨本」往下，略去了論典的解釋文句。論中說：有四種大準則名為隨本〔論典的文意難以理解，古來各種解釋各有不同；暫且依照古代筆記，根據通緣與別緣兩種情況來作註解。〕，佛陀告訴各位比丘：我說明是不淨的行為〔屬於性惡罪或遮惡罪，全都是不善之法，所以在自性上不清淨。〕而不加以制約結罪〔對於癡狂癲亂之人，全都普遍開許的原故。〕，然而此人卻隨順趨入了不淨〔動了一念清醒憶知之心，這位比丘就立刻墮入犯戒的境位。〕；
