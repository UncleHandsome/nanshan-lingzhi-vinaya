# 校閱材料　第597檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【597-0001】02_戒疏/10d_卷三上之一#51
【原文】【記】勸行中。「異學」謂各從師。「同釋姓」者，非異族也。「師無殊」者，非異稟也。
【譯文】【記文】在勸導行持同和當中。「異學」是指各隨不同的世俗師長。「同釋姓」，是指大家都不再分彼此不同的宗族了。「師無殊」，是指大家的法脈傳承並無不同。

【597-0002】02_戒疏/10d_卷三上之一#52
【原文】【疏】「如水乳合」者，師乖見異，義則有殊，師同見合，理則無別。如乳合乳，如水合水。不得云「乳合水」，以相合非體，鵝能別故。
【譯文】【疏文】「如水乳合」的意思，如果師承乖違、見解相左，義理上就會產生懸殊；若是導師相同、正見契合，在道理上就不應有分別。就如同把乳汁融入乳汁，把清水融入清水一樣。不能說是「乳融入水」，因為水乳相融畢竟非同一體性，鵝王尚且能把乳汁與水分別開來的緣故。

【597-0003】02_戒疏/10d_卷三上之一#53
【原文】【記】釋喻中。「乳」即水之甘味，與水體別，唯鵝王能別取而食之。既非一體，法喻有乖，必須二物各自論合，故云「不得」等。
【譯文】【記文】在解釋比喻當中。「乳」是水中的甘甜滋味，與水的自體不同，只有鵝王能單獨把它吸取飲用。水乳既然不是徹底一體，在法與比喻上就會有所偏差，所以必須是兩種同質之物各自論其相合，因此疏文才說「不得」等話。

【597-0004】02_戒疏/10d_卷三上之一#54
【原文】【疏】二、「於佛法中增益安樂」者，良由捨除異見，同體行和，如法修道，必除生死，得涅槃樂，故曰也。「增益」者，超凡夫界也。「安樂」者，絕三苦也。
【譯文】【疏文】第二、「在佛法中增益安樂」，確實是由於捨棄消除了異端邪見，體性同和、行持同和，依照正法修行辦道，就必定能夠斷除生死輪迴，證得涅槃之樂，所以經文這樣說。「增益」，是指超越凡夫的界限。「安樂」，是指徹底斷絕三苦（苦苦、壞苦、行苦）。

【597-0005】02_戒疏/10d_卷三上之一#55
【原文】【記】舉益勸中。初通釋。「同體行和」，躡上二勸也。「除生死」者，即增益也。「得涅槃」者，即安樂也。「增」下，別釋。「凡夫界」，即三有也。「三苦」者，一、苦苦，二、壞苦，三、行苦。既超三有，永絕三苦，故「安樂」。
【譯文】【記文】在舉出利益以勸勉的段落中。首先是通盤解釋。「同體行和」，是承接前面兩種同和的勸導。「除生死」，就是增益的意思。「得涅槃」，就是安樂的意思。「增」字以下，分別解釋。「凡夫界」，就是指三界六道。「三苦」，一是指苦苦，二是指壞苦，三是指行苦。既然超越了三有界限，永遠斷絕了三苦，所以稱為「安樂」。

【597-0006】02_戒疏/10d_卷三上之一#56
【原文】【註】應語彼言：「可捨此事，莫令僧作訶諫而犯重罪。」若用語者，善。若不用語，復令餘比丘、尼、優婆塞、優婆夷，若王，若大臣，種種異道沙門、婆羅門求；第餘方比丘，聞知其人信用語者，應求諫之。是屏諫也。
【譯文】【註文】應當對他說：「可以捨棄這件事了，不要讓僧團對你進行公眾羯磨呵責規勸，以致犯下重罪。」如果他聽從規勸，那就很好。如果不肯聽從，應當再讓其餘的比丘、比丘尼、優婆塞、優婆夷，或者國王，或者大臣，以及種種外道沙門、婆羅門前去求告規勸；甚至其餘遠方的比丘，只要聽說那個人平日信任且聽從其話語的，都應當求請前來規勸他。這就是私下規勸。

【597-0007】02_戒疏/10d_卷三上之一#57
【原文】【疏】注中，可知。
【譯文】【疏文】注文的內容，依文即可明白。

【597-0008】02_戒疏/10d_卷三上之一#58
【原文】【記】點注中。文有二段。初自諫。「若不」下，求他諫。初求近人，「若餘方」下，求遠人。
【譯文】【記文】點明注文的一段中。經文有兩個層次：首先是自己親自規勸。「若不」以下，是求請其他人前來規勸。先求請身邊親近的人，「若餘方」以下，是求請遠方的人。

【597-0009】02_戒疏/10d_卷三上之一#59
【原文】【律】是比丘，如是諫時，堅持不捨。
【譯文】【律文】這位比丘，當別人這樣規勸他時，仍然固執己見不肯捨棄。

【597-0010】02_戒疏/10d_卷三上之一#60
【原文】【疏】「是比丘如是諫」下，四、拒屏諫也。「是比丘」者，通能所也。就拒諫時，望殘未成，但結小罪。
【譯文】【疏文】「是比丘如是諫」以下，第四、抗拒私下規勸。「是比丘」，在文意上可以通指能勸者與被勸者。在抗拒私勸的時候，相對於僧殘重罪尚未構成，只結下輕微的小罪。

【597-0011】02_戒疏/10d_卷三上之一#61
【原文】【記】拒屏諫中。「通能所」者，義兼兩釋，從所尤親。「就」下，判罪，如上已明。
【譯文】【記文】抗拒私勸當中。「通能所」的意思，在義理上兼具兩種解釋，但依文義順理成章，解為被勸者更為親切貼切。「就」字以下，判定罪名，如上面已經說明過了。

【597-0012】02_戒疏/10d_卷三上之一#62
【原文】【律】彼比丘應三諫，捨此事故，乃至三諫，捨者，善。
【譯文】【律文】那些比丘應當三次規勸他，為了讓他捨棄這件事的緣故；乃至經過三次規勸，如果肯捨棄的，那就很好。

【597-0013】02_戒疏/10d_卷三上之一#63
【原文】【疏】「彼比丘」下，明僧諫相。「乃至三諫捨者善」，何等「善」邪？一、以本諫不成殘故，二、以屏諫非提罪故，三、以所犯不成蘭故，曰「善」也。
【譯文】【疏文】「彼比丘」以下，說明僧團公眾規勸的相狀。「乃至三諫捨者善」，是哪一種「善」呢？第一、因為原先發動規勸的事由不再構成僧殘重罪；第二、因為在私下規勸時不至於結成波逸提罪；第三、因為所造的破僧惡事不再構成偷蘭遮果罪，所以稱作「善」。

【597-0014】02_戒疏/10d_卷三上之一#64
【原文】【記】第三雙，初科。釋文。三義釋善，無非離犯。「不成蘭」，即破輪罪也。
【譯文】【記文】第三對句中，第一科段。解釋經文。用三種義理來解釋善，無非都是遠離了犯戒罪過。「不成蘭」，是指不構成破法輪的偷蘭遮重罪。

【597-0015】02_戒疏/10d_卷三上之一#65
【原文】【註】彼比丘應集僧羯磨，如諫作白已，應更求。乃至一羯磨、二羯磨亦爾。
【譯文】【註文】那些比丘應當召集僧眾作羯磨，依照規勸法作完單白宣告之後，應當再次要求其捨棄（此事）。乃至作完第一次羯磨、第二次羯磨時，也都是這樣要求。

【597-0016】02_戒疏/10d_卷三上之一#66
【原文】【疏】注中明僧和相。隨其白、羯磨，一一住問者，明諫法也。故約白、羯磨中間住諫，冀彼迴心從善。何得誦過成犯？則非本意也。
【譯文】【疏文】注文中說明僧團如法和合之相。隨著每一次作白、羯磨，都在中間停頓詢問的，是為了闡明規勸之法。所以依據單白、羯磨的中間停頓給予勸誡，是期望對方能夠回心向善。哪裡能夠直接一路念完羯磨讓他成罪呢？那樣就完全違背了規勸的本意了。

【597-0017】02_戒疏/10d_卷三上之一#67
【原文】【記】釋注中。「明諫法」者，以白四羯磨，止是告僧，故須隨法加勸，方名諫法。「中間住」者，謂四法三住，欲彰諫意，不為成罪。
【譯文】【記文】解釋注文當中。「明諫法」，是因為白四羯磨本來只是宣告僧眾，所以必須在羯磨法進行中隨機加以勸勉，才稱得上是真正的規勸之法。「中間住」，是指在四個作法程序之間有三次停頓，是為了彰顯慈悲規勸的意旨，而不是為了要讓他結罪。

【597-0018】02_戒疏/10d_卷三上之一#68
【原文】【律】不捨者，僧伽婆尸沙。
【譯文】【律文】如果仍然不肯捨棄的，犯僧伽婆尸沙（僧殘）罪。

【597-0019】02_戒疏/10d_卷三上之一#69
【原文】【疏】「不捨者」，拒僧成業相也。
【譯文】【疏文】「不捨者」，是說明抗拒僧團規勸而最終構成定業的相狀。

【597-0020】02_戒疏/10d_卷三上之一#70
【原文】【疏】問：「此三羯磨竟得僧殘者，為攬因成果不？」
【譯文】【疏文】提問：「在進行完第三次羯磨完畢而得僧殘罪的時候，是合併前期的因位小罪共同構成這一重大極果呢，還是不合併呢？」
