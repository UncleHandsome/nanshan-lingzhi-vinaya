# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

# 材料開始

# 校閱材料　第253檔
# 本檔編號一律為 253-NNNN，回報時整串照抄。

【253-0001】02_戒疏/13a_卷三下之一#65
【原文】【疏】「若爾，何故《多論》『王來入寺，不得安衣』？」
【譯文】【疏文】「如果這樣，為什麼《薩婆多論》說『國王來進入寺院，比丘不得在該處安放法衣』？」

【253-0002】02_戒疏/13a_卷三下之一#66
【原文】【疏】解云：「須識四礙，方知攝護。
【譯文】【疏文】解答說：「必須認識四種障礙，才能明白攝持與防護法衣的道理。

【253-0003】02_戒疏/13a_卷三下之一#67
【原文】【疏】「一者，染礙，明失。如《多論》中『所以除村，為護梵行，為止譏嫌』等五義。比丘與女，性非親好，動即相染，譏過隨生。故使戒中制約非少，『說法』、『取衣』、『同行』、『同坐』，無論屏、露，未約親疎，但使與取，皆制其犯。若衣在此，往會是難，故名染礙。
【譯文】【疏文】「第一是染污障礙，其結果是失去對法衣的管領。如同《薩婆多論》中所說：『之所以在結界時扣除村落，是為了防護清淨梵行、為了止息外在譏嫌』等五種義理。比丘與女性，在性別上非屬親近相宜，稍有不慎就會產生染著，譏嫌過失隨之而生。因此戒律之中的防範約束非常繁多，例如『說法』、『取衣』、『同行』、『同坐』，無論是在隱蔽處還是露天處，也不論關係親疏，只要有給予或收取，都制定為犯戒。如果衣服放在該處，比丘前往拿取將極為困難，所以稱為染污障礙。

【253-0004】02_戒疏/13a_卷三下之一#68
【原文】【疏】「二者，隔礙。如《僧祇》中『人在門外，須捉戶鑰』等。
【譯文】【疏文】「第二是隔斷障礙。如同《僧祇律》所說『人在門外，必須握住門鑰匙』等等。

【253-0005】02_戒疏/13a_卷三下之一#69
【原文】【疏】「三、情礙。如《僧祇》中『兄弟分齊』等。如《多論》中『王來入寺，取水處，大小便處，近王左右，盡非衣界。又有幻人、戲樂人入來亦爾』。
【譯文】【疏文】「第三是情意障礙。如同《僧祇律》所說的『兄弟家產分界』等。又如同《薩婆多論》所說『國王來到寺院，取水的地方、大小便處、以及靠近國王左右之處，全部都不算作衣界。此外如果有幻術師、歌舞藝人進入寺院也是如此』。

【253-0006】02_戒疏/13a_卷三下之一#70
【原文】【疏】「四、就界礙。如《律》十一是。
【譯文】【疏文】「第四是依界域障礙。如同《四分律》所指出的十一種自然界就是。

【253-0007】02_戒疏/13a_卷三下之一#71
【原文】【疏】「今依《四分》，具有此四。」
【譯文】【疏文】「如今依據《四分律》，這四種障礙都是齊備的。」

【253-0008】02_戒疏/13a_卷三下之一#72
【原文】【記】次釋妨中。「《多論》王來不得安衣」，顯是俗強，則違上義。「解」下，釋通，初總示。
【譯文】【記文】接著是解釋疑問。「《多論》說國王來寺不得安衣」，顯然是世俗強盛，那麼就違背了上述的義理。「解云」以下是解釋通達，先作總體指示。

【253-0009】02_戒疏/13a_卷三下之一#73
【原文】【記】「一」下，別解「染礙」中。初明染相。《多論》「五義」，文略餘三，即村界不定，生疑，除諍。「故使」下，引類。「說法」即與女說法，取尼衣，與尼女同行，及與同坐。「若衣」下，次示礙義。
【譯文】【記文】「一者」以下，個別解釋「染污障礙」。先說明染污的相狀；《多論》的「五義」，文中省略了其餘三種，也就是村界範圍不定、容易生疑、為了消除爭端。「故使」以下，引證同類戒條；「說法」是指為女人說法、接受比丘尼法衣、與比丘尼或女人同行，以及一同坐處。「若衣」以下，接著說明造成障礙的意涵。

【253-0010】02_戒疏/13a_卷三下之一#74
【原文】【記】「隔礙」中。《僧祇》不立「勢分」，故須門外捉鑰及梯，則不失衣，反則成礙。
【譯文】【記文】「隔礙」之中，《僧祇律》不設立「勢分（延伸範圍）」，所以必須人在門外握住鑰匙或扶梯，才算未失衣，反之就形成障礙。

【253-0011】02_戒疏/13a_卷三下之一#75
【原文】【記】「情礙」中。「兄弟分齊」，謂同居別食之家。「取水」等處，竝眾同處，恐往於彼遭隔絕故。「兄弟」則恐生嫌忌。「王」則畏其勢力。「幻、樂」等人，則慮誘調。
【譯文】【記文】「情礙」之中，「兄弟分齊」，是指同住一處卻各自分炊過活的家庭。「取水」等處，都是眾人共同使用之處，恐怕前往該處會遭到阻隔。「兄弟」是恐怕引發嫌棄忌諱。「國王」是畏懼其威權勢力。「幻術、藝人」等，則是防備受到誘惑調笑。

【253-0012】02_戒疏/13a_卷三下之一#76
【原文】【記】「界礙」，可解。「今」下，會本宗。界礙出廣解，三礙見不犯。
【譯文】【記文】「界礙」之意很容易理解。「今依」以下，會通回歸本宗。界域障礙在廣解中說明，其餘三種障礙見於不犯戒的條文中。

【253-0013】02_戒疏/13a_卷三下之一#77
【原文】【疏】就餘樹、車，八界相望。有師解云：「根本是強，寄來者弱，如場上有車，豈有別相？」今言無者，據有垣相為言，如庫、堂中，有車轝等，何有別界？
【譯文】【疏文】至於其餘樹木、車輛等八種界域相互對照，有律師解釋說：「本有的界域是強，借住前來的界域是弱，例如打穀場上有車輛，難道會產生各自的界相嗎？」現在說沒有強弱，是依據本來就具備院牆界相而言，例如庫房、大堂之中停放著車輛轎輿，怎麼會有另外的獨立界域呢？

【253-0014】02_戒疏/13a_卷三下之一#78
【原文】【記】餘八中，初出古解。「今」下，示今義。若有垣相，可有強弱，無垣各立，則非所論。
【譯文】【記文】其餘八界之中，首先引出古德的解釋。「今言」以下，指出現在的正確義理。如果本來就有院牆界相，才可以論強弱；若是各自獨立並無圍牆，就不在討論之列。

【253-0015】02_戒疏/13a_卷三下之一#79
【原文】【疏】第七、第八，兩門合論。義應相對，四句分別。
【譯文】【疏文】第七門與第八門，兩門合併討論。在義理上應當互為對照，以四句分別的方式來辨析。

【253-0016】02_戒疏/13a_卷三下之一#80
【原文】【記】七八合論者，七是寬狹，八明多少，各兼四句，所以合之。
【譯文】【記文】第七與第八合併討論，是因為第七門是說明範圍寬狹，第八門是說明數量多寡，各自兼具四句分別，所以將兩者合併。

【253-0017】02_戒疏/13a_卷三下之一#81
【原文】【疏】初自然攝僧與自然攝衣，寬狹、一多，各為四句，互顯其相。
【譯文】【疏文】首先，自然攝僧界與自然攝衣界，在寬狹、多寡上，各自形成四句，互相顯發其相狀。

【253-0018】02_戒疏/13a_卷三下之一#82
【原文】【記】初句。標云「寬狹、一多」、「各四句」，而下但列六者，「寬狹」中止出二互，略二俱故。
【譯文】【記文】第一句。標題雖說「寬狹、多寡」「各自形成四句」，而下文只列出六句，是因為「寬狹」之中只列出了兩相對照的互異情況，省略了兩者俱寬與兩者俱狹的緣故。

【253-0019】02_戒疏/13a_卷三下之一#83
【原文】【疏】初、攝僧寬攝衣狹。如蘭若中，僧作法，必方五里；衣若遠身，止七十步。故曰也。
【譯文】【疏文】第一、攝僧界寬而攝衣界狹：例如在阿蘭若中，僧團作法集僧，必須達到方圓五里；法衣如果遠離身邊，界限僅限於七十步。所以說是如此。

【253-0020】02_戒疏/13a_卷三下之一#84
【原文】【疏】二、攝僧狹攝衣寬。如不可分別聚落中有一家，方二百步內通攝衣，外兼勢分；若論攝僧，則六十三步。
【譯文】【疏文】第二、攝僧界狹而攝衣界寬：例如不可分別聚落中有一戶人家，其莊園舍宅方圓二百步之內皆可攝衣，外圍還兼具延伸勢分；但若論及召集僧眾，則局限於六十三步之內。

【253-0021】02_戒疏/13a_卷三下之一#85
【原文】【疏】三、攝僧一攝衣多。如一小村，眾多家住，可村僧集；家別攝衣。
【譯文】【疏文】第三、攝僧界為一而攝衣界為多：例如一個小村落，住了許多戶人家，整個村落可以共同召集僧眾；但各家各戶則分別攝持法衣。

【253-0022】02_戒疏/13a_卷三下之一#86
【原文】【疏】四、攝衣一攝僧多。如不可分聚，方二百步為一家，衣雖通攝；僧則限約。
【譯文】【疏文】第四、攝衣界為一而攝僧界為多：例如在不可分別的聚落中，方圓二百步屬於同一戶人家，法衣雖然通攝整片範圍；但攝僧則各自被局限在相應的步數之內。

【原文】【疏】六、僧衣俱一。如一處伽藍，正可五十步許；衣界隨藍，取其勢分，與僧界等。
【譯文】【疏文】第六、攝僧界與攝衣界兩者皆為單一：例如一處僧伽藍，大小剛好約五十步；衣界依附僧伽藍，加上向外投石所及的勢分，剛好與攝僧界完全相等。

【253-0025】02_戒疏/13a_卷三下之一#89
【原文】【記】列釋中。初二句，易會。今義加二句：言俱寬者，如可分聚，唯一家也；言俱狹，如蘭若有難，與衣界同也。從三已下，即「一多」四句。三中，「可村」語略，即可分別聚落。四中，「僧限約」者，謂僧界各據六十三步故。五、「加三礙」者，來往不通，彼此各攝，則衣界多也。六中，伽藍五十步，藍外更取十三步，則六十三步。衣界依藍外有十三步勢分，故與集僧正等也。
【譯文】【記文】在列出解釋中，前兩句很容易理解。若依現在的義理應當補齊兩句：所謂兩者俱寬，例如可以分別的聚落中，剛好只有一戶人家；所謂兩者俱狹，例如阿蘭若遇到危難時，攝僧範圍就與衣界相同。從第三句以下，就是「多寡」的四句。第三句中，「可村」文句簡略，其實是指可以分別的聚落。第四句中「僧則限約」，是指僧界各自依據六十三步為限。第五句「加三礙」，是指來往道路不通，彼此各自攝衣，因此衣界就變多了。第六句中，僧伽藍有五十步，僧伽藍外再加上十三步勢分，就成了六十三步；衣界依據僧伽藍外有十三步的延伸勢分，所以與召集僧眾的範圍剛好相等。

【253-0034】02_戒疏/13a_卷三下之一#98
【原文】【記】第二句中。前是二種自然，此約作法僧界與自然衣界相對為句。此亦合有八句，文中寬狹、一多，各出三句，並第四句不可立故。初句，「以衣隨院」者，釋失衣所以。二中，「以界隨相」者，釋破夏意也。三中，「可」即相等，謂結大界出藍相外一十三步，與衣勢分正等。第四句下，即一多三句，舉事可解。
【譯文】【記文】在第二句中，前面是兩種自然界的對照，此處是以作法僧界與自然衣界相對來成立句式。此處原本也應當有八句，文中在寬狹與多寡上各列出三句，都是因為第四句無法成立的緣故。第一句「以衣隨院」，是解釋丟失衣服的原由。第二句「以界隨相」，是解釋破夏安居的含義。第三句「可」，就是相等的意思，是指結作法大界超出僧伽藍外十三步，剛好與衣界的延伸勢分相等。第四句以下，就是關於多寡的三句，列舉的事相很清楚，可以理解。
