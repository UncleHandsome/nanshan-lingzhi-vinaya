# 校閱材料　第390檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【390-0001】02_戒疏/03c_卷一下之一#54
【原文】【疏】答：「大聖如來，深鑒物情，濁世根鈍，須立麤刑，逗彼時機，聞名息過。如俗本禁，蒲鞭示恥；季世深酷，故有徒流。可以通望也。」
【譯文】【疏文】回答：「大聖如來深切洞察眾生的心性情態，五濁惡世眾生根性駑鈍，必須設立顯著嚴格的刑條規範，以投合適應當時的機緣，使眾生聽到罪名就止息過惡。這就好比世俗起初的法令，只是用蒲草鞭象徵性處罰以示羞恥；末法末世刑法日益殘酷嚴苛，所以才有了徒刑與流放等律法。這兩者之間的道理是可以相互貫通對照的。」

【390-0002】02_戒疏/03c_卷一下之一#55
【原文】【記】第二置名，明所以中。答文為二。初敘立意。以篇聚所立，指身口過惡以為別相，從治懺獄報而作通名，故言「麤」也。略教被利，相非麤顯，「威德」、「教授」，由是而彰。「如」下，舉類。「蒲鞭」喻略，「徒流」如廣。古者以蒲杖辱之，則能改過。「酷」謂酷虐。以俗況道，教意可見，故云「通望」也。
【譯文】【記文】在第二項命名、說明設立由來的文段中。回答的文字分為兩個層次。首先敘述設立名稱的意旨。因為篇聚之所以安立，是直接以身、口的過失惡行為其個別相貌，而從懲治、懺悔以及地獄果報的角度來安立其共通名稱，所以說是「顯著嚴格（麤）」。簡略的教誡是用來化導利根器者，罪相並不粗顯；如來的「威德」與「教誡開導」，正是由此得以彰顯。從「這就好比」往後，舉出世俗事例作為類比。「蒲草鞭」比喻略教，「徒流之刑」比喻廣教。古代用蒲草做成鞭子懲辱犯人，人就能改過自新。「酷」是指殘酷暴虐。用世俗之道來比況出世正法，立教的深意便昭然若揭，所以說「相互貫通對照（通望）」。

【390-0003】02_戒疏/03c_卷一下之一#56
【原文】【疏】「又此五名有通有別，別如下釋，通須略知。如本《四分》，但云『五種犯，或五犯聚，或五種制』，《僧祇》云『篇』，《十誦》云『品』。名雖或異，攝罪義同。」
【譯文】【疏文】「此外，這五種名稱有共通的稱呼，也有個別的稱呼。個別的稱呼如後文所解釋，共通的稱呼必須在此略微明瞭。例如我們的根本律典《四分律》，只稱作『五種犯』，或者稱作『五犯聚』，或者稱作『五種制』；《僧祇律》稱之為『篇』；《十誦律》稱之為『品』。名稱雖然有所不同，但統攝收納罪過的義理是完全一致的。」

【390-0004】02_戒疏/03c_卷一下之一#57
【原文】【記】次科。初標指。「如本」下，正示。本律三名，上二約罪，下一從教。《僧祇》、《十誦》並從條類。《了論》為「部」，義亦同之。「名」下，會同。可解。
【譯文】【記文】這是第二個層次。首先標示指出；從「例如我們的根本」往後正式說明。本律所用的三個名稱，前兩個是就罪過而言，後一個是依據教令而立。《僧祇律》與《十誦律》都是依照條目類別來安立名稱。《明了論》稱之為「部」，意義也完全相同。從「名稱雖然」往後進行會通。文意淺顯可解。

【390-0006】02_戒疏/03c_卷一下之一#59
【原文】【疏】初「波羅夷」者，此無可譯。如世五刑，今古乃異，西梵同此，可以相翻。初罪不爾，東土本無，不知以何罪同，止得事義相譯。
【譯文】【疏文】第一種「波羅夷」，這個詞在漢地沒有現成的詞彙可以直接對譯。正如世俗的五種刑罰，古今制度各有不同；古印度若是也有這類刑名，原本可以互相對翻。但這初篇大罪並非如此，東土漢地本來就沒有對應的這種罪罰觀念，不知道能拿世間什麼罪名來對等相稱，所以只能從事理的涵義來互相翻譯。

【390-0007】02_戒疏/03c_卷一下之一#60
【原文】【記】別名中，夷罪，初科。初標「無譯」，謂無正譯。「如」下，次明義譯。初示兩土不同，意謂同者則容可對譯，今此不同，故須從義。
【譯文】【記文】在個別名稱中，關於波羅夷罪，這是第一個綱目。首先標出「沒有對譯」，是指沒有直接相應的正式對翻詞彙。從「正如」往後，接著說明從義理角度翻譯的方法。首先指出兩土社會文化的差異，意思是說如果本質相同就容許對翻，現在既然不同，就必須依照義理來翻譯。

【390-0008】02_戒疏/03c_卷一下之一#61
【原文】【疏】故本律云：「波羅夷者，譬如斷人頭不可復起。」世之極法，勿過此刑，由犯斯罪，於彼聖果永不可克。又名「無餘」者，從眾法絕分為名，故文云「惡行死屍，眾所不受」。又名「不共住」者，亦同上解。
【譯文】【疏文】所以本律說：「所謂波羅夷，就好比砍斷了人的頭顱，再也不可能復活起立一樣。」世間最極限的刑罰，沒有超過這種死刑的了；比丘由於犯了這種重罪，對於出世間的聖道道果，就永遠不可能證得克成了。又稱之為「無餘」，是從永遠斷絕被涵蓋在僧團法事中的資格來命名的，所以經文說「這就像惡臭的死屍，清淨的大眾僧團絕不收受容納」。又稱之為「不共住」，意義也與上面的解釋相同。

【390-0009】02_戒疏/03c_卷一下之一#62
【原文】【記】引示中，本律三段。初是約喻，後二從法。說戒、羯磨二種眾法，皆不預數，故云「絕分」。下引文證，即「律序」偈，略其詞耳。「不共住」義，《律》文還約二種眾法釋之，故云「同上」。
【譯文】【記文】在引用律文說明的段落中，本律包含了三段文字。第一段是用譬喻來說明，後兩段是從律法體制來界定。說戒和羯磨這兩種僧團的集體法事，犯此罪者都完全不能列入法定人數，所以說「永遠斷絕資格（絕分）」。下文引用文句作為佐證，也就是《律序》中的偈頌，只是文詞予以簡略罷了。「不共住」的義理，《廣律》本文同樣也是依照「說戒」與「羯磨」這兩種僧團大眾法事來解釋的，所以說「與上面相同」。

【390-0010】02_戒疏/03c_卷一下之一#63
【原文】【疏】《僧祇》解云，此罪名墮，非唯失道、不入二種僧中，捨身便墮阿鼻地獄。生報不久，何得不畏？《十誦》、《多論》亦有明解，廣如《事鈔》，下名別著。
【譯文】【疏文】《僧祇律》解釋說：這種罪稱為「墮」，不僅僅是喪失修道資格、不得列入比丘與比丘尼兩種僧團之中，只要捨棄了這個報身，隨即墮入阿鼻無間地獄。來生受報（生報）之期為時不久，怎能不讓人敬畏恐懼呢？《十誦律》和《薩婆多論》也有詳細明白的解釋，詳細內容正如《行事鈔》中所記載，在下文中會個別標示出來。

【390-0011】02_戒疏/03c_卷一下之一#64
【原文】【記】他部中。《僧祇》三義，二義同前。「失道」即「斷頭」，「不入」即「無餘」。後加「墮」義，故曰「非唯」。「報」有三種：一、現報；二、生報，謂後生即受；三、後報，謂生報已後，通及未來。下指「《十誦》」，彼亦翻「墮」。「《多論》」釋云「由與魔鬪墮在負處，謂毀根本，無勝力故」，與今《僧祇》釋義不同，故云「下名別著」。「著」，顯也。
【譯文】【記文】在介紹其他部派律典的段落中。《僧祇律》提出三種涵義，前兩種涵義與前面相同。「喪失修道資格」就是對應「斷頭」，「不得列入二眾僧中」就是對應「無餘」。後面特別增加了「墮落」的涵義，所以說「不僅僅是」。「報應」分為三種：第一是現報；第二是生報，就是指來生隨即受報；第三是後報，就是指來生之後，通達涵蓋於未來的無量受報。下文指出的《十誦律》，該律也將此罪翻譯為「墮」。《薩婆多論》則解釋說「因為與魔王交戰而墮落在落敗的處境，是指毀壞了根本戒體、毫無勝過煩惱的力量」，這與現在《僧祇律》所解釋的深意有所不同，所以說「下文中個別標示出來」。「著」就是顯明、標著的意思。
