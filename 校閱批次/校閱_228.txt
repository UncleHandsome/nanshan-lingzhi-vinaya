# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【228-0001】02_戒疏/11a_卷三上之二#58
【原文】【疏】然則法由人興，人能通法。德人懷道，明達取捨，理宜憑仗，請決進不。所以聖教勸依三藏，開導愚迷，以成資訓。然今闡陀內實無德，聞諫不受，反傍勝人，恃己陵物。便言：「佛是我家佛，因釋種故。法是我家法，因佛說故。汝今依我釋種佛法出家，我是佛法根本，正應教諸大德，何用大德教我？」言說相似，愚叢謂是。須諫開示，是非路分。有德相誨，為除迷結，是以須諫。
【譯文】【疏文】話說回來，正法是依靠人才能興盛，人能夠弘傳貫通正法。有德行之人胸懷道業，明瞭通達取捨的分寸，在戒理上應當依憑投靠他們，請求裁決修行上的進退取捨。所以佛陀聖教一再勸勉大家應當依止精通三藏的師長，啟發引導愚昧昏迷之心，藉以成就受教訓導的資糧。然而現在闡陀內在實質上毫無道德修養，聽到勸告也不接受，反而攀附非凡殊勝之人，依仗私交而傲視欺凌眾人。竟然聲明說：「佛陀是我家的佛陀，因為世尊出自釋迦族的緣故。佛法是我家的佛法，因為是由佛陀宣說的緣故。你們如今依附我釋迦族的佛陀與正法出家，我是佛法的根本根基，本來就應該由我教導各位大德，哪裡用得著大德來教訓我？」這番言詞聽起來似乎煞有介事，愚昧的僧眾還真以為有理。因此必須進行勸諫給予開示，將是非對錯的界線劃分清楚。由具足德行者出面勸勉訓誨，以破除大眾與其自身的迷惑結縛，這就是必須進行勸諫的緣由。

【228-0002】02_戒疏/11a_卷三上之二#59
【原文】【記】二中。初通敘諫人。謂此四種多不從諫：初即恃老，二即恃長，三恃少能，四恃他勢。用此自檢，孰可逃乎？似此等人，並須設諫。今此闡陀即同第四，故云「正當」也。
【譯文】【記文】在第二點中。首先全面敘述接受勸諫之人。意指這四種人大多不服從勸諫：第一種是仗恃年邁，第二種是仗恃身居僧首，第三種是仗恃微薄才智，第四種是仗恃他人權勢威德。拿這四點來自作檢點，誰又能倖免於傲慢呢？像這幾類人，都必須給予勸諫。如今這位闡陀正等同於第四種，所以義疏說「正當此人」。

【228-0003】02_戒疏/11a_卷三上之二#60
【原文】【記】「然」下，正敘今意。初通明依師學法。「聖教」即律文，如《受戒》中選師須通達三藏、勤教授者，當須依之。「資訓」，謂資稟教訓。「然今」下，正示須諫所以。初敘諫緣後。「闡陀」即車匿，本王宮侍人，為佛控馬踰城入山，最先親侍，故常以此自負，故云「我家」也。「言說」下，正明立諫。「迷結」，即上「愚叢謂是」。
【譯文】【記文】「然」字以下，正式敘述現今制戒的本意。首先全面說明應當依止師長學習佛法。「聖教」指的就是律文，例如在《受戒篇》中規定選擇依止師，必須通達三藏、勤於教授弟子者，方應當依止。「資訓」，是指稟受教誨訓誡。「然今」以下，正式指出必須勸諫的原由。先敘述勸諫因緣的背景。「闡陀」即是車匿，本是釋迦王宮的侍僕，曾為佛陀牽馬踰越城牆進入深山修行，是最早親自侍奉佛陀的人，所以經常以此自負，故而口口聲聲說是「我家」。「言說」以下，正式說明建立勸諫的理由。「迷結」，就是指前文所說的「愚昧僧眾誤以為其說得有理」。

【228-0005】02_戒疏/11a_卷三上之二#62

【228-0010】02_戒疏/11a_卷三上之二#67
【原文】【註】佛在拘睒彌國。尊者闡陀惡性拒諫，反言：「我應教諸大德，何以故？我聖主得正覺故。」比丘舉過白佛。便訶責已，而制此戒。

【228-0011】02_戒疏/11a_卷三上之二#68
【原文】【疏】就戒緣中：從初至「我聖主得正覺」來，過起所由；二、「比丘舉過」，明訶制戒。初中所以云「我聖主」者，本是佛家使人也。故《見》云：「佛是我家佛，我將佛入山學道，不見諸長老一人侍佛者，乃至得轉法輪故，法是我家法。」與僧競故，不云僧也。《僧祇》云：「我常隨佛，佛唯教我，我當受持。」如是陵慢。
【譯文】【疏文】在此戒的因緣中：從最初至「我聖主得正覺」為止，是過失發起的原由；第二段「比丘舉過」，是說明呵責並制定戒律。第一段中之所以會說「我的聖主」，是因為他原本是佛陀家族的僕役。《善見律毘婆沙》說：「佛陀是我家的佛陀，是我護送佛陀入山修道，當時沒見到各位長老有任何一人侍奉佛陀，甚至一直到佛陀轉法輪為止；所以佛法也是我家的佛法。」因為他正在與僧團抗爭賭氣，所以絕口不提僧寶。《僧祇律》記載他說：「我常年跟隨佛陀，佛陀唯教導我一人，唯有我應當領受奉持。」就是如此傲慢自大、輕視他人。

【228-0012】02_戒疏/11a_卷三上之二#69
【原文】【記】釋戒緣中。初科分。「初」下，牒釋。《善見》三寶中，獨「不云僧」者，由「與僧競」，顯非「我家」故。《僧祇》「我常隨佛」，恃其最久也。
【譯文】【記文】解釋制戒因緣中。首先劃分科段。「初」字以下，引文解釋。《善見律》在三寶之中，唯獨「不提僧寶」，是因為他「正在與僧團爭執抗衡」，藉以表明僧眾不是「我家的人」。《僧祇律》記載其自稱「我長年跟隨佛陀」，正是仗恃自己跟隨佛陀的時間最長久。

【原文】【註】以戒律如法教授者，有七犯聚：波羅夷、僧伽婆尸沙、波逸提、波羅提提舍尼、偷蘭遮、吉羅、惡說。
【譯文】【註文】以戒律及如法教導他人者，牽涉七種犯戒聚罪：波羅夷、僧伽婆尸沙、波逸提、波羅提提舍尼、偷蘭遮、突吉羅、惡說。

【228-0015】資持記/14c_下二#12
【原文】出下，別示鍵𨩲。上文示異名，下文顯體相。二中，初老病開作。挽即牽也。輦謂小車，或用畜駕，或是人荷。牸牛𮪏馬，皆謂雌者之異名；深防觸染，故簡除之。若得下，次明他施得畜。轅音袁，即車前兩木，引而舉前以駕軛〔音厄。〕皮繩用以束輦。枕橙並輦上所須。應下，明駕輦人。
【譯文】「出」以下，別示鍵𨩲。上文示異名，下文顯體相。第二中，先開許老病者作。挽就是牽。輦是小車，或用畜力駕，或由人擔荷。牸牛、𮪏馬，都是雌者的異名；深防觸染，所以簡除。「若得」以下，其次說明他人布施可以畜。轅音袁，就是車前兩木，引而舉前以駕軛（音厄）。皮繩用來束輦。枕、橙都是輦上所需。「應」以下，說明駕輦的人。

【228-0016】01_行事鈔/10c_卷下之二#8
【原文】《十誦》：比丘無鍼，不得外行。
【譯文】《十誦律》說：比丘身邊若無縫針，不得出外遠行。

【228-0017】資持記/14c_下二#13
【原文】簡比丘故。若下，指例。車即大者。應下，簡非。織皮，有華文故。髮繩，同外道故。三中。彼以針綴衣，無故衣解形露，因制帶行。今用鉤紐，則不須之。此中但明聽畜耳。四中。非行來處，即僻隱處也。五中，《十誦》。尾拂得受，非己用故。犛牛莫交反，多出西方，鬃尾皆赤，多用為拂。《僧祇》中。
【譯文】這是簡別比丘的緣故。「若」以下，指例。車就是大的。「應」以下，簡別非法。織皮，因為有華文。髮繩，因為同於外道。第三中。他們用針綴衣，若沒有針，衣服散解便會導致身體顯露，因此制令帶行。現在用鉤紐，就不需要了。這裡只是說明聽許畜而已。第四中。非行來之處，就是偏僻隱密的地方。第五中，《十誦》。尾拂可以受，因為不是自己用的。犛牛，莫交反，多出西方，鬃尾都是赤色，多用來作拂。《僧祇》中。

【228-0018】01_行事鈔/10c_卷下之二#9
【原文】《五分》：非行來處，若大小便及洗手脚時，聽著屐。《四分》亦爾。《僧祇》：畜塼瓦擬揩脚。
【譯文】《五分律》說：在非尋常走動的特定場所，如大小便溺以及洗手洗腳時，聽許穿著木屐。《四分律》也是如此規定。《僧祇律》說：聽許蓄留磚瓦，用以擦拭腳底。

【228-0019】01_行事鈔/10c_卷下之二#10
【原文】《十誦》：犛牛尾拂，用拂佛塔故受。《僧祇》：自今已去，聽捉線拂、裂㲲、樹皮等；除犛牛尾、馬尾、金銀柄，一切不聽捉；若白色，染壞用；不得如淫女捉作姿作相，是名拂法。《五百問》云：若僧中說法、高座上、不病，不得憑几。捉麈尾，犯墮；非毛者得。《四分》：得尾拂，開畜；不得畜織毛𣭱。
【譯文】《十誦律》說：犛牛尾做成的拂塵，是為了拂拭清掃佛塔才受持蓄用的。《僧祇律》說：自今以後，聽許手持以線繩、撕裂的細棉布（裂㲲）、樹皮等製成的拂子；除了犛牛尾、馬尾以及金銀手柄的拂子一律不聽許拿持；如果是白色的拂子，應當染成壞色後使用；不得像淫女執拂那樣擺弄姿態賣弄風騷，這才是執拂的如法規矩。《五百問》說：如果在僧眾中說法、升於高座之上而並無疾病，不得倚靠几案。若執持麈尾（獸毛拂塵），犯波逸提（單墮罪）；非獸毛製成的則可以拿持。《四分律》說：若得到獸尾拂塵，開許蓄持；但不得蓄持以毛編織的精緻織物（織毛𣭱〔註：𣭱，音義同罽或氈褥毛席〕）。

【228-0020】01_行事鈔/10c_卷下之二#11
【原文】《十誦》：四人已上坐處，長床所攝。
【譯文】《十誦律》說：可供四人以上坐臥的地方，歸屬於「長床」所攝。

【228-0021】資持記/14c_下二#14
【原文】初明自畜，則簡畜尾。裂㲲謂剪絹布為條。樹皮即麻苧楊樹等，今多用椶櫚為之。今時後生持扇執拂，多作女態；教名婬女，豈不懷慚。《五百問》中。几即几案，麈謂鹿之大者，群鹿行時，看尾指處，即隨所往；講者持拂指授聽眾，故以為名；但不得畜毛為之，故制犯罪。《四分》。
【譯文】首先說明自己蓄存的規定，就排除了動物尾巴製成者。「裂㲲」是指剪裁細絹棉布成為布條。「樹皮」就是指大麻、苧麻、楊樹等樹皮，現在多用棕櫚樹皮製作。現代的年輕出家人拿扇持拂，多半裝模作樣像女人的體態；戒教中稱為如淫女之態，難道不感到慚愧嗎？在《五百問經》中：「几」就是几案。「麈」是指鹿群中體型較大者，鹿群奔跑時，看麈尾所指的方向便隨之跑去；講經者持麈尾拂指授聽眾，所以取名為麈尾；但不得蓄存獸毛所製成的麈尾，故制定結罪。引《四分律》中：

【228-0022】資持記/14c_下二#15
【原文】尾拂似聽毛者，但不得長𣭱者耳。𣭱，所交反。六中。長床即明開畜。七中，文相交雜，故細節之。初文為十，初明器具。剃刀隔絕本習，故不聽畜，餘人應得。若得下，明衣具。若不下，明算子。為下，明治病眾具。㓟，符碑反，剝也。三種瓶，即銅鐵土也。𨫼，五到反。若鉢下，明鉢具。若須下，明擔物。
【譯文】尾拂似乎聽許用毛的，只是不得用長的𣭱罷了。𣭱，所交反。第六中。長床就是說明開許畜。第七中，文句交錯雜亂，所以細細區分。第一段文分十項，先說明器具。剃刀隔絕本來的習氣，所以不聽許畜，其餘的人應可得。從「若得」以下，說明洗衣作衣之用具。從「若不」以下，說明算籌籌子。從「為」以下，說明治病的各種器具。「㓟」音符碑反，是剖開、剝除之意。三種瓶，是指銅瓶、鐵瓶、陶土瓶。「𨫼」音五到反。從「若鉢」以下，說明修整護持鉢具之用具。從「若須」以下，說明挑擔搬運之物。
