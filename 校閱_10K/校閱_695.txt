# 校閱材料　第695檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【695-0001】02_戒疏/15b_卷三下之三#6
【原文】【記】次對簡中。前是己物，故約「作成」；此由他施，故須「領受」。
【譯文】【記文】接著在兩戒的對比簡別中。前一戒是由於用了自己的絲線物料，所以依「織成」來定罪；本戒是由於他人布施，所以必須等到「領受」才結罪。

【695-0002】02_戒疏/15b_卷三下之三#7
【原文】【疏】問：「此戒損縷，與前一、二居士何異？」
【譯文】【疏文】有人問：「這條戒損耗了施主的絲線，與前面一居士、二居士那兩條戒有什麼不同？」

【695-0003】02_戒疏/15b_卷三下之三#8
【原文】【疏】答：「前面對縷主，此屏勸織師，故兩制也。」
【譯文】【疏文】回答說：「前面是當面向絲線的主人索求，本戒則是背著施主私下勸請織師，所以分為兩處制定制約。」

【695-0004】02_戒疏/15b_卷三下之三#9
【原文】【記】初問。以一、二居士，亦是勸增，故須顯異。答中，可解。
【譯文】【記文】首先提問。因為向一、二位居士索求也是勸其增多，所以必須闡明兩者的差異。答語的內容淺顯易懂。

【695-0005】02_戒疏/15b_卷三下之三#10
【原文】【疏】問：「前後兩戒，皆由織師，何以取分？」
【譯文】【疏文】又問：「前後這兩條戒，都是經由織師織造，憑什麼標準來作區分？」

【695-0006】02_戒疏/15b_卷三下之三#11
【原文】【疏】答：「不同有四：一、前損織師，自得縷故，此損縷主；二、前損織師，不與價犯，此損縷主，與價便犯；三、前戒開親，後戒俱犯，損義通也；四、前是己物，織成即犯，此本屬他，要受方犯。」
【譯文】【疏文】回答說：「不同之處有四點：第一、前戒損害的是織師，因為比丘自己提供了絲線；本戒損害的是絲線的主人。第二、前戒損害織師，不給工錢才犯戒；本戒損害絲線主人，給了織師工資反而犯戒。第三、前戒開許由親屬織造不犯，後戒無論親疏全都犯戒，因為損害他人利益的實質是一樣的。第四、前戒本是自己的物料，織成之時便結犯；本戒物料原屬於他人，必須等到正式接受衣物時才結犯。」

【695-0007】02_戒疏/15b_卷三下之三#12
【原文】【記】次問。二戒不同，緣相可見，欲生料簡，故發此問。答中。第三「後戒」親、非親「俱犯」者，謂織師也。上列緣中，明簡親者，據縷主也。
【譯文】【記文】第二個提問。兩條戒律的情形不同，事緣行相顯而易見，為了進一步辨析簡別，所以提出這個問題。答語中提到第三點「後戒」無論是親是疏「全都犯戒」，指的是對織師而言；上文所列的犯緣中，明確簡別親疏的，則是就絲線主人來說的。

【695-0008】02_戒疏/15b_卷三下之三#13
【原文】【註】佛在舍衛國。居士出線與織師為跋難陀作衣，彼後至家，擇取好線與織師織，又許與價。居士譏嫌，比丘舉過。佛因訶制。
【譯文】【註文】佛陀住在舍衛國時。有位居士拿出絲線交給織師為跋難陀比丘縫製僧衣，跋難陀後來到了織師家裡，挑選取用了上好的絲線交給織師織造，並且許諾增加工錢。居士為此生起譏嫌，其他比丘舉發了他的過失。佛陀因此呵責並制定了戒律。

【695-0009】02_戒疏/15b_卷三下之三#14
【原文】【疏】就戒緣中，「擇取好線」，正是貪相，為起過源。
【譯文】【疏文】在制戒因緣當中，「挑選取用上好絲線」，正顯露了貪著的模樣，也是滋生過失的源頭。

【695-0010】02_戒疏/15b_卷三下之三#15
【原文】【記】戒緣兩過：一、擇好線，二、許與價。業由斯起，教因此制。
【譯文】【記文】戒律緣起中有兩大過失：第一是挑選好線，第二是承諾增加工價。罪業由此生起，戒教也因這兩項過失而制定。

【695-0011】02_戒疏/15b_卷三下之三#16
【原文】【律】若比丘，居士、居士婦使織師為比丘織作衣，彼比丘先不受自恣請。
【譯文】【律文】如果比丘，遇到在家男居士、女居士差遣織師為該比丘織造僧衣，而該比丘事先並未受到施主的任隨尊意的供養邀請（自恣請）。

【695-0012】02_戒疏/15b_卷三下之三#17
【原文】【註】若居士與比丘貴價衣，聽少欲知足索不如者，隨意也。
【譯文】【註文】若是居士原本要送給比丘昂貴的僧衣，佛陀開許為了少欲知足而索取品質較差的，這可以聽隨自己的心意。

【695-0013】02_戒疏/15b_卷三下之三#18
【原文】【律】便往織師所，語言：「此衣為我作，與我極好織，令廣大堅緻，我當多少與汝價。」是比丘與價，乃至一食直，若得衣者，尼薩耆波逸提。
【譯文】【律文】這名比丘便前往織師的住處，對他說：「這件衣服是為我製作的，請替我好好織造，務必織得又寬大又結實細密，我會相應地多貼補你一些工錢。」這名比丘給予了工資，哪怕少至一餐飯的價值，如果最後得到了這件衣服，就犯了尼薩耆波逸提罪。

【695-0014】02_戒疏/15b_卷三下之三#19
【原文】【註】若求衣不得，突吉羅。尼同犯。不犯者，減少求，從親里索、出家人索，他為己者是也。
【譯文】【註文】如果求取衣服最後沒有得到，犯突吉羅罪。比丘尼犯同樣的罪。不犯的情況包括：減少索求、向自己的親屬索求、向出家人索求，或是他人主動為自己辦理等情況。

【695-0015】02_戒疏/15b_卷三下之三#20
【原文】【疏】戒本七句：一、犯人；二、衣主；三、令織；四、「彼比丘」下，犯相；五、「若得衣者」，結犯；下二，可知。
【譯文】【疏文】戒本正文可分為七句：第一、違犯的人；第二、衣服的主人；第三、差遣織造；第四、「彼比丘」以下，說明犯戒的行為相狀；第五、「若得衣者」，正式結成違犯；其餘最後兩句，意思顯而易見。

【695-0016】02_戒疏/15b_卷三下之三#21
【原文】【記】戒本，分句，自別。
【譯文】【記文】戒本的正文，各自分句，界限自然分明。

【695-0017】02_戒疏/15b_卷三下之三#22
【原文】【疏】注解「自恣請」者，謂許好取惡耳，非長貪壞信而索好也。《僧祇》云「若俗家兄弟令自往營，疾成，得好」，是自恣相。
【譯文】【疏文】註文中所解釋的「自恣請」，意思是施主原本許諾給好的，自己卻選取粗劣的，並不是放縱貪心、破壞施主信心反而索取更好的。《僧祇律》說「如果俗家的兄弟讓比丘自己去督造操辦，以便早日織成、織得更好」，這便是屬於隨意請供的行相。

【695-0018】02_戒疏/15b_卷三下之三#23
【原文】【記】釋注中。初牒釋。言「自恣」者，任比丘意也。「僧祇」下，引示。彼文約親，本無所犯，且欲顯示「自恣相」耳。
【譯文】【記文】解釋注文的內容。首先摘錄註文加以解釋。所謂「自恣」，就是完全聽憑比丘的心意。「僧祇」以下，引用律文來指示說明。該條文是針對親屬而言，本來就沒有犯戒的嫌疑，此處引用只是為了顯示「自恣請的行相」罷了。

【695-0019】02_戒疏/15b_卷三下之三#24
【原文】【律】二十五、奪比丘衣戒。
【譯文】【律文】第二十五、強奪比丘衣戒。

【695-0020】02_戒疏/15b_卷三下之三#25
【原文】【疏】第二十五，奪比丘衣戒。
【譯文】【疏文】第二十五條，強奪比丘僧衣戒。

【695-0021】02_戒疏/15b_卷三下之三#26
【原文】【疏】與衣規伴，已是邪源。後既不行，和取無犯。今瞋心強奪，逼惱情深，特乖儀節，故聖制止。光律師云「先與衣不分強奪戒」。
【譯文】【疏文】以贈送僧衣為條件去圖謀同行的伴侶，這本身就已經是邪曲的源頭。後來對方既然不願同行，平和地討回本不犯戒。如今卻以瞋恨心強行奪回，逼迫惱亂他人情態嚴重，極其違背威儀行節，因此聖者佛陀立法加以禁止。慧光律師稱此戒為「先與衣不分明強奪戒」。

【695-0022】02_戒疏/15b_卷三下之三#27
【原文】【記】二十五，制意中。初二句，敘先與之由。「規」，求也。次二句，明理須和取。「今」下，顯過興故制。「乖儀節」者，「儀」即威儀，「節」謂節行。後引光師立名，以合制意。「不分明」者，與否未決故。
【譯文】【記文】第二十五條，制戒本意。前兩句敘述起初贈送衣服的原由。「規」，就是圖謀、求取的意思。接下來兩句說明理應以和氣的方式收回。「今」字往下，彰顯出過咎生起所以需要立戒制止。「乖儀節」的「儀」就是威儀，「節」是指節操操行。最後引用慧光律師所立的戒名，以契合制戒的本意。所謂「不分明」，是指給予還是借用並未明確決斷。

【695-0023】02_戒疏/15b_卷三下之三#28
【原文】【疏】成犯五緣。
【譯文】【疏文】構成違犯的正罪共有五項因緣。

【695-0024】02_戒疏/15b_卷三下之三#29
【原文】【疏】初是比丘。簡下四眾，本非伴類，假奪但吉。
【譯文】【疏文】第一、對方必須是受具足戒的比丘。簡別排除了下位的沙彌等四眾弟子，因為他們本來就不是並肩同行的同類伴侶，如果強行奪回僅犯突吉羅罪。
