# 校閱材料　第876檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【876-0001】02_戒疏/21c_卷四下之三#106
【原文】【疏】大哉戒德，方行資始。《百論》盲跛之譬，《牟子》之說行之解如之何乎？苟守一隅而固辭，則早晚使挑，慧矩蒼生，照正行之路。因而利其器，從事於斯矣。而戒本注疏文段鉤鏁，不唯一重。殆病符合，而賴繹文逐節排布。《疏》、《記》循科分會綸次，今將法彼曲成從，天地易簡，五部俱會，一覽使普矣。茲稔功成，更以異本校讐，猶恐爽靈鑒多矣。恭候后喆之琢磨，非敢功於比先輩，纔酬佛恩，少答祖德矣。冀稱性微勳，彌編法界，佛日增輝，法壽無窮矣，云爾。
【譯文】【疏文】巍峨廣大啊戒律的功德，正是修持品行資糧的最初始端。《百論》中盲人與跛子相助的譬喻，《牟子理惑論》中關於行道與明理不可偏廢的精闢議論，難道可以等閒視之嗎？如果固守一隅而堅決推辭，那麼究竟何時才能挑亮智慧的明炬，照亮芸芸蒼生修持正行的道路？因此必須先磨利其器物工具，我也就欣然從事於這項編纂事業了。然而這部《戒本注疏》的文字段落如鎖鏈般相勾，往往不止一層重疊。最讓人苦惱的是五部文段要像符節般逐一相合對齊，全憑抽繹文本、依照段落逐一排比鋪展。使《疏》與《記》依循科判分條縷析、絲絲入扣地編纂成序，如今將取法宇宙天地曲成萬物的至理，順從天地化繁為簡的要妙，將經本、注文、科判、注疏、記文五部徹底合編，使人一展卷便能全盤洞悉。如今整年辛勤大功告成，進一步採用不同的版本互為校勘比對，內心依然深恐錯漏疏失之處甚多。恭謹等候後世賢哲仁人的琢磨修正，我絕不敢妄將此功績與古代前輩相提並論，只求藉此稍稍酬謝佛陀的大恩、些許報答祖師的厚德罷了。唯願這依順真如自性所生起的微末微勳，周遍充盈於十方法界，令佛法慧日增長光輝，令法脈壽命歷久無窮，如此而已。

【876-0003】資持記/01a_上一上#1
【原文】四分律行事鈔資持記上一上〔并序〕大宋餘杭沙門釋元照撰序序出家之士，稟戒為體，聚法居身；行必據體而修，故因名隨行；身必稱法而動，故果號法身。誠由發趣有宗，依因得所故也。且夫一識元明，垢淨叵得。從緣流變，彼我熾然；觸物生情，隨妄興業；繫諸有獄，受萬類形；
【譯文】《四分律行事鈔資持記》卷上一之上（並附序文）。大宋餘杭沙門釋元照撰述。序文：出家之士，以承受戒法為自體，聚合教法而居於身心；行為必定依托戒體而修持，因此因位的修持稱為「隨行」；身心必定契合法度而動作，所以果位的功德號為「法身」。這確實是由於發心趣向有其宗要，依止正因而各得其所的緣故。再者，眾生的一念心識本來靈明，原本無所謂染垢與清淨。但隨逐塵緣流轉變遷，你我的妄執熾然生起；接觸外物便生情執，順隨妄念便興造諸業；於是被拘繫在三界的牢獄中，領受萬類不同的形軀；

【876-0004】資持記/01a_上一上#2
【原文】億劫昇沈，罔有寧息。故我如來乘真實道，闢大慈門，將令究盡苦源，故制先除漏業。譬夫伐樹，始必刊枝；豈唯種果無依，抑使根株漸朽；毘尼為教，厥致在茲。伏自蘊結中天，五宗競演。譯傳東夏，四分偏弘；雖九代相承，而六師異轍。而我祖師示四依之像，秉一字之權；
【譯文】在億劫之中浮沉流轉，未曾有片刻安息。因此我釋迦如來乘著真實之道降世，開啟廣大的慈悲之門，欲令眾生徹盡痛苦的根源，是以制定戒律先斷除有漏的惡業。好比砍伐樹木，起初必定先削去枝條；這不僅使結成果實無所依托，更使樹木的根株逐漸朽爛；毗尼戒律作為教化，其深意就在於此。自佛滅度後戒律結集於中印度，五個部派競相宣揚。翻譯傳播到東土漢地，唯獨《四分律》偏盛弘傳；雖然歷經九代相承，但各派六位宗師的觀點途徑各異。而我們的祖師（道宣律師）示現四依菩薩的行相，執持如《春秋》一字褒貶筆削的大權（刪繁補闕、裁定是非）；

【876-0005】資持記/01a_上一上#3
【原文】軫力扶顛，為如來所使。垂慈軌物，作群生導師。首著斯文，統被時眾；莫不五乘竝駕，七眾俱霑；攝僧護法之儀，橫提綱要；日用時須之務，曲盡規猷。是故歷代重之以為大訓。然則理致淵奧，討論者鮮得其門；事類森羅，駕說者或容遺謬。由是研詳可否，搜括古今；
【譯文】竭盡全力匡扶衰落的律乘，作為如來的特使。垂賜慈悲規範萬物，作一切眾生的導師。他首先著述了這部《行事鈔》，總體利益當時的大眾；無不使五乘行者並駕齊驅，七眾弟子普遍蒙受教益；統攝僧眾、護持正法的儀軌，橫向提揭其綱領要旨；日常生活中隨時所需的戒務，皆委曲詳盡地制定規範。因此歷代都尊崇此書，視為極重要的指引訓誡。然而其義理深奧淵博，討論研習的人很少能窺其門徑；涉及的事相繁多紛呈，立論講解者有時難免遺留謬誤。因此我詳盡研討是非，搜羅考訂古今的著述；

【876-0006】資持記/01a_上一上#4
【原文】罄所見聞，備舒翰墨。仰承行事之旨，題曰資持。不違三行之宗，勒開卷軸。良以一部統歸三行，三行無越二持；科釋文言，貴深明於法相；銓量事用，使剋奉於受隨。是則教行雙弘，自他兼利；首題一舉，部意全彰。但由聖智通宏，凡情寡陋；以䗍酌海，長嗟罔測其深；
【譯文】傾盡自己所見所聞的義理，全部鋪舒在筆墨之中。敬仰秉承祖師行事的宗旨，將這部註記命名為《資持》。不違背行事鈔所立三行的宗綱，而編輯展開為卷軸。這確實是因為整部《行事鈔》統歸於三行，而三行不外乎止持與作持；分科解釋文句言辭，貴在深刻通達法相；衡量事相的運作取用，旨在讓人能夠切實奉行受戒與隨行。如此則教理與實踐雙雙弘傳，自利與利他都能兼得；只要書題一標舉，整部鈔的旨意便全然顯彰。但由於聖人的智慧通達廣博，而凡夫的情識淺陋；用海螺去舀海水，只能長聲感嘆無法測得其深廣；

【876-0007】資持記/01a_上一上#5
【原文】捧土塞河，實愧不知其量。式酬祖德，少副夙心；庶永流通，冀裨萬一者爾。歷觀往古述作，凡五十餘家；各謂指南，俱稱盡理。然今所立，頗異昔傳；故於卷首略標五例。一曰定宗，二謂辨教，三敘引用，四明破立，五示闕疑。初定宗者。三藏分宗，所詮乃異。
【譯文】用雙手捧土企圖阻塞巨河，實在慚愧自己不知力量的輕重。以此聊表酬謝祖師的大德，略微契合往昔發下的宿願；希望此書能長久流傳流通，期盼能有萬分之一的補益助益罷了。歷覽往昔的述作，共有五十多個注家；大家都自稱是指路指南，皆宣稱窮盡了精微之理。然而我如今所建立的註解，與過去流傳的頗有不同；所以在卷首略微標示五個條例。第一是「定宗」，第二是「辨教」，第三是「敘引用」，第四是「明破立」，第五是「示闕疑」。首先說「定宗」：三藏劃分宗旨，所詮釋的義理本不相同。

【876-0008】資持記/01a_上一上#6
【原文】據行則雖通兼濟，在教則各有司存。往哲未詳，固多濫涉。竝廣談論學，以亂律乘。〔即增輝等記，隨文結釋涅槃四果等，竝依法相廣列章門是也。〕況復所引之論，多依《俱舍》、《婆沙》，蓋用實宗釋今假部。可謂宗骨顛倒，理味差僻，致令後銳枉費時功。忝在傳持，義當糺正。
【譯文】如果按照實際修行來說，雖然可以共通兼濟，但就教相職責而言，經律論三藏各有其專職管轄。往昔的大德未能詳察，固然多有隨意牽扯越界之失。他們紛紛廣談論宗之學，以致擾亂了律藏正宗。（這即是像《增輝記》等書，隨文牽強解釋涅槃、四果等名相，全都依據阿毗達磨法相廣列章門的情形。）何況他們所引用的論典，大多依據《俱舍論》、《大毗婆沙論》，這是用「實法宗」來解釋現在這部「假名宗」。可以說是宗旨骨架完全顛倒，法味義理偏差乖謬，致使後世精進之士枉費光陰精力。我忝列傳持律學之位，按義理應當予以糾正。
