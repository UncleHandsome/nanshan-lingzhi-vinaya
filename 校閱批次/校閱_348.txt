# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【348-0001】02_戒疏/18c_卷四上之三#31
【原文】【疏】有三過故。一、異學情反，恒多疎外，難與理親。雖復惠施，不荷其恩，反生譏謗。二、邪見乖宗，非真福田，以信心之食，授與外道，施主聞之，特生不忍。又損施福，不得功德，田中不獲反報故。三、躬自奉食授與外道，容生外人愚倒己見，謂外道勝，比丘不如。以斯諸過，故制。
【譯文】【疏文】制定這條戒律是為了防止三種過患。第一、信奉外道異學的人心思與佛門相悖，平時多抱持疏遠排斥的態度，很難以佛法正理與其真心結交。縱使慈悲布施給他們，他們非但不感念這分恩德，反而常常轉向生起毀謗與譏嫌。第二、外道懷抱顛倒邪見，違背清淨正宗，根本不是能夠生長功德的真正福田；若將信徒帶著誠敬心供養的食物轉送給外道，施主聽聞之後，內心必定深感不忍與不快。同時這也損害了施主的布施功德，無法獲得殊勝善報，因為在不良的田地裡播種無法得到應有的豐收回報。第三、如果比丘親自動手捧著食物遞奉給外道，很容易讓世俗愚昧大眾產生倒錯的偏見，誤以為外道的德行勝過三寶、比丘反而不如外道。因為存在這許多的深重過患，所以佛陀制定了這項禁止。

【348-0002】02_戒疏/18c_卷四上之三#32
【原文】【記】四十一，制意三。初招反謗，即如緣起。二、非福田，復有二意：一、惱施心；「又」下，二、損施福。三、罔時俗。「以」下，總結。
【譯文】【記文】第四十一條說明制戒用意，分為三個方面。第一是招致外道反過來毀謗，這與制戒緣起的事實相符。第二是外道並非合格的福田，這又包含兩層意涵：第一是令人煩惱退失布施的誠心；「同時」以下，第二層是損耗了施主的功德果報。第三是愚弄迷惑了世俗凡夫。「因為」以下，是全文的總結歸納。

【348-0003】02_戒疏/18c_卷四上之三#33
【原文】【疏】論犯六緣。一、是出家外道，以在家者但犯小罪。由出家名同，真偽難別，生人惑倒故重。二、知是。三、非親里，開與父母。《僧祇》中：「父母、兄弟外道出家者，使淨人與。無者，語令自取。若嫌者，答云：『汝出家不得處，佛制戒如是，不食者隨意。』」四、是食，除與衣犯小罪。五、自手與。以食味是通，理無獨食，置地使人，不生感倒故開。六、領受犯。
【譯文】【疏文】若論定構成犯戒，必須具備六項條件：第一、對方必須是已經出家的外道人士，如果只是給予在家外道，僅結犯輕微的小罪。這是因為出家之名相同，世俗人極難辨別真偽，容易令人產生迷惑顛倒，所以從嚴治罪。第二、自己明知對方是出家外道。第三、對方不是自己的至親眷屬；若對方是親生父母，則在開許容許給予的例外之中。《僧祇律》記載：「如果父母或兄弟成為了出家外道，比丘應當派遣佛門淨人代為轉送食物。如果沒有淨人，就開口吩咐他們自己動手拿取。如果他們心生抱怨怨恨，比丘就應當回答說：『你們出家加入外道，並非我所能干涉決定的；佛陀制定的戒律本來就是如此，如果不想吃的話就隨你們的便。』」第四、所給予的必須是食物；如果贈與的是衣服，只結犯突吉羅小罪。第五、必須是比丘用自己的雙手親自遞交給對方。因為食物美味是通於大眾滋養之物，法理上本不應完全自私獨吞，若是把食物放在地上或吩咐他人代送，並不會引起世人崇仰外道的顛倒錯覺，因此特許開緣。第六、外道親手受領完畢，此時正式構成犯戒。

【348-0004】02_戒疏/18c_卷四上之三#34
【原文】【記】列緣中。初緣，「在家小罪」者，即汙家犯吉。三、引《僧祇》，彼不開親，還須遣置，今何引者？一、彰部別，二、令兼用，欲使暫加折辱，冀彼迴邪。五中，「食味通」者，容兼濟故。
【譯文】【記文】在列舉犯戒條件中。第一項條件提到「給予在家外道犯小罪」，指的是這種行為類似於阿諛世俗的「汙家」之失，結犯突吉羅罪。第三項引用《僧祇律》，那部律典並未開許親屬例外，依然必須吩咐他人代送或放在地上，那麼此處為何要引用呢？第一是為了彰顯各個部派律典的細部差別，第二是為了讓本宗修行者能兼融運用，藉此暫時給予外道親屬一些折服與羞辱，希望能引導他們悔改回頭、摒棄邪道。在第五項條件中提到「食物美味通於大眾」，是因為食物容許有分甘濟貧、照顧弱小的餘地。

【348-0015】02_戒疏/18c_卷四上之三#45
【原文】【疏】《多論》云：「外道本唯六師，一師教十五弟子，各各受行異見。六師各別有法，與資不同。師及資通數九十六。如是相傳，常有不絕。」
【譯文】【疏文】《薩婆多論》記載：「外道原本只有六位大宗師，每位宗師各自傳授十五名得力弟子，師徒各自奉行不同的偏狹邪見。六位宗師各有其獨特的修法規矩，與佛法資益身心完全不同。連同師長與門資徒弟通盤計算共有九十六種派別。這種邪見門徑代代相傳，世世代代從未間斷。」

【348-0016】02_戒疏/18c_卷四上之三#46
【原文】【記】戒本，釋第二中。引《論》示數。若準《僧祇》，但云「九十六道」，佛道在中，則九十五屬外道。此則各從所出，不須和會。然今此方但約李張之徒，及南方多有未魔之家，即為犯境。注「裸形」者，且標一種，實有多類。「波私婆羅闍」，即外道通名，未詳所譯。第三句，注中，先列九種不正，同前「足食」，故略舉之。「食者」下，即明五正。前犯緣中，唯衣犯吉，故知此戒制通四藥。
【譯文】【記文】在解釋戒本第二部分的文句中。引證《多論》以闡明外道門派的具體數字。如果依照《僧祇律》的說法，只籠統提到「九十六種道」，若將佛道也算在其中，則屬於邪門外道的正好有九十五種。這只是各個部派律典傳承的記述不同，並不需要強求融通一致。然而在如今東土漢地，凡是指老莊道家、方士之流，以及南方廣泛存在的各類妖妄左道之家，只要面對他們，便構成本戒所禁止的對象境界。註解中提及的「裸形外道」，只是舉出一種最醒目的典型類別，實際上外道的派別非常多樣。「波私婆羅闍」，即是古印度對出家異學外道的梵語通稱，具體的意譯內涵尚待進一步考證。第三句的註解中，先列舉了九種不正當的雜嚼類食物，與前面「足食戒」所列的名稱相同，所以此處只是簡略提過。「可食用的食」以下，則是說明五種正統的正食。依照前面的犯戒要件，只有布施衣服算作突吉羅小罪，由此可知本條戒律所禁止的範圍，通貫涵蓋了四種不同期限的所有藥食。

【348-0017】02_戒疏/18c_卷四上之三#47
【原文】【疏】尼犯亦提。今結吉羅，取方便耳。作異戒故。
【譯文】【疏文】比丘尼若是違犯本戒，依律也應當結犯波逸提墮罪。此處暫且判定為突吉羅罪，只是權宜採取方便結罪的方式罷了，目的是為了區別兩部僧團所受持的條文差異。

【348-0018】02_戒疏/18c_卷四上之三#48

【譯文】【記文】在解釋比丘尼犯戒的段落中，比丘尼戒的條文同時連帶嚴格禁止向在家的白衣男子布施，規範對象與比丘僧截然不同，所以才稱作「異戒」。

【348-0020】02_戒疏/18c_卷四上之三#50
【原文】【疏】食前後至他家戒四十二。
【譯文】【疏文】食前、食後前往其他人家（的戒），是第四十二條。

【348-0021】02_戒疏/18c_卷四上之三#51
【原文】【疏】有三過制。一、俗里多緣，為善事難，輟己家業，專崇福會。已許彼請，行至他家，脫有事差，惱處極重。二、既有食處，息緣修道，無事游散，妨廢所習。三、共僧受請，背入聚落，令他施主見彼不集，竟不設食。稽留眾僧，使不充足，惱處不輕，故制。
【譯文】【疏文】佛陀基於三種過患而制定此戒。第一、世俗村里人事紛繁牽涉極廣，一般人想要成就一件供僧善事本就非常艱難，往往需要放下自家的營生產業，一心一意專門籌辦這場福田盛會。比丘既然已經答應了施主的應供邀請，卻在去應供的途中又隨意轉往其他居士家，萬一因此延誤了時辰而生出差錯，帶給原施主的煩惱與傷害是極其沉重的。第二、既然已經有了預定受食的處所，理應收攝身心萬緣回歸修行，如果無故在外遊蕩閒逛，必然會荒廢荒耽平日所修習的戒定慧課業。第三、與僧團大眾一同接受居士請托，卻獨自脫隊轉入其他村落居宅，導致原本的施主看見應邀的僧眾人數殘缺不全，一時間猶豫著不敢正式擺設膳食。這樣一來拖延耽誤了全體大眾僧的用餐時間，甚至害得大眾倉促之間無法飽足，帶給整個僧團的困擾與煩擾非同小可，因此必須制定本戒。

【348-0022】02_戒疏/18c_卷四上之三#52
【原文】【記】四十二，制意三中。初、惱俗過，二、多事過，三、惱僧過。「使不充足」，謂時促，食不飽也。此中後意，即本緣起。
【譯文】【記文】第四十二條說明制戒用意的三個層面中。第一是帶給世俗施主惱亂的過失，第二是徒增紛擾雜事的過失，第三是耽擱擾亂大眾僧的過失。所謂「使僧眾不能充足」，是指用齋的時間被嚴重壓縮，大眾無法從容吃飽。這三層用意中的最後一條，正是引發制定本戒的原始因緣。

【348-0023】02_戒疏/18c_卷四上之三#53
【原文】【疏】論犯五緣：一、先受他請；二、不囑授；三、往聚落中；四、無因緣，除病、衣時；五、入門便犯。
【譯文】【疏文】若論定構成犯戒，必須具備五項條件：第一、比丘預先接受了施主的專門請齋；第二、中途若要轉往別處，沒有事先向同行比丘告白囑託；第三、擅自走向世俗村落聚落的宅院之中；第四、本身沒有合法的免責因緣，除了身患疾病或正值縫製僧衣的時節之外；第五、只要腳步踏進他人家門的門檻，便立即構成犯戒。

【348-0024】02_戒疏/18c_卷四上之三#54
【原文】【記】具緣。四中，三種開緣，如戒所列。
【譯文】【記文】具備犯戒要件。在第四項條件中所包含的三種合法的開許因緣，正如戒本條文所明文列出的那樣。

【348-0025】02_戒疏/18c_卷四上之三#55
【原文】【註】佛在舍衛。長者為跋難陀故飯僧，彼時欲過方來，比丘食竟不足。又羅閱城中大臣得果，令跋難陀於僧中分；後食已，詣餘家。比丘告二過，佛雙制此戒。
【譯文】【註文】佛陀住在舍衛國時。有位富有的長者為了跋難陀比丘的緣故出資供養全體僧眾，但跋難陀卻拖拖拉拉直到日影將正、時限快過時才姍姍來遲，導致其他比丘用齋十分匆促無法吃飽。另外在王舍城中，有位朝廷大臣得到了一批鮮美的水果，特地送給跋難陀，希望由他在僧團大眾中負責分發；誰知跋難陀在吃飽之後，轉身又去了其他居士家中閒晃。比丘們向佛陀揭發了這兩樁過失，佛陀於是將兩件事合併審酌，正式制定了這條戒律。

【348-0026】02_戒疏/18c_卷四上之三#56
【原文】【疏】就緣中，初明食前游行，僧食不足。「羅閱」下，食後遵行，遂不得果，為犯之緣。
【譯文】【疏文】在探討戒律的緣起過程時，前段說明跋難陀在用齋之前到處遊蕩閒逛，導致大眾僧用齋匆忙不足。「王舍城」以下是第二段，說明跋難陀在用齋之後隨意漫遊造訪他人家中，終致耽誤了分發果品而令大眾無法享用水果，這兩件事共同構成了制戒的犯罪緣起。

【348-0027】02_戒疏/18c_卷四上之三#57
【原文】【記】戒緣，二段。後云「不得果」者，大臣持果待跋難陀歸為僧分，而彼食已往至他家，歸遲，遂致過時。此謂中前，若在中後，則犯後戒。
【譯文】【記文】制戒緣起分為前後兩段。後段所說的「終致無法獲得水果」，是指大臣捧著鮮果苦苦等待跋難陀回來為僧眾分發，然而跋難陀吃飽之後卻逕自跑去其他人家裡，回來得太遲，最終導致過了解正午的受食時限。此處所指的是日中之前（辰時過後至午前）的時間，如果是在日正當中之後的午後漫遊，那就違犯了後續另一條非時入聚落的戒律。
