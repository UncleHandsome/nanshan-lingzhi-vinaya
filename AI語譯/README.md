# AI 語譯工作區

## 用法（手動）
1. 開 AI Studio，選模型，thinking level 設 high。
2. 貼上 prompt.txt 全文，接上 TXT_分卷 裡的一個 chunk。
3. 把回覆存成與 chunk 同名的 .txt，放進 out/（例：out/01_行事鈔__01a_卷上之一.txt）。
4. 全部到齊後告訴我，我負責合併、校對、排成對照本與全白話本。

## 命名規則
out/<書資料夾>__<chunk檔名>.txt
例：out/01_行事鈔__01a_卷上之一.txt

## 注意
- 一段原文對一段譯文，勿合併段落。
- 術語保留原文並加括號簡註。
- 疑字照錄，另加〔註〕。
