整體讀來流暢，科判術語（作白、羯磨、眾緣、分齊）大體掌握得住。但有幾處**義理誤譯**和**前后自相矛盾**，另有一批「增字解經」與贅詞問題。按輕重分列如下。

---

## 一、明顯誤譯（建議必改）

**1. 【370-0008】第四「以法成僧」——與下一段記文自相矛盾**
- 原譯：「以羯磨法成就合格僧眾」
- 問題：此「法」不是羯磨法，而是**界法**。緊接的【370-0009】記文自釋：「四中『以法成』者，謂自然、作法，各攝分齊，即《羯磨》云『約界明集』是也。」譯文自己在下一段譯成「自然界或作法界……依界限以辨明僧集」，可見此處誤讀；「合格」二字亦無據。
- 建議：「第四是以（自然界、作法界之）界法決定所集僧眾的分齊。」

**2. 【370-0011】「貴少賤多」——語意譯反、句不成話**
- 原譯：「珍貴稀有之法卻賤視常見之物」
- 問題：「貴少賤多」是說**人情以少為貴、以多為賤**（承上文「鏤板盛傳」而言：書一多就不珍惜），主語是「常情」，不是「法」。原譯把「法」當主語，句意不通。
- 建議：「然而常人心情淺狹，（法本）少見便覺珍貴，一多了就輕賤（不加珍惜）。」

**3. 【370-0008】第五「和別相形」**
- 原譯：「和合與分立之相的辨別」
- 問題：「別」是律家術語**別眾**（與和合眾相對），不是「分立」；「相形」是互相對照而顯，不是「辨別」。
- 建議：「第五是（以）和合眾與別眾互相對照（而顯和合）。」

**4. 【370-0002】【370-0012】「經文」用詞錯誤**
- 這是《含注戒本疏》解釋**戒本**之文，非「經」。兩處「經文分為兩個部分」「在經文中體現為七個項目」都應作「戒本文」（或逕作「文」）。「別序」也建議保留原術語，不必譯成「個別序分」。

**5. 【370-0012】「即文為七／但意言也」——文、意對比失落**
- 原譯：「在經文中體現為七個項目。有人認為只有六個項目的，那純粹只是主觀的想法罷了。」
- 問題：原文是 **「依文」分七 vs「依意」分六**的對舉；「但意言」是說「只就義意上說」，並非貶為「主觀想法」。
- 建議：「就前面『緣成』部分，依文相分為七句。也有分作六句的，那只是就義意上說（不依文相）。」

**6. 【370-0005】「能辨」譯成「工具」**
- 原譯：「它就屬於能承辦說戒的工具」
- 問題：「能辨（成辦）」是相對於「所成」而言的**能成辦者**，「工具」是現代物化譬喻，不妥。又「所為即辨」的「辨」是成辦、辦妥，譯「成立」略偏。
- 建議：「白法才刚宣告完成，所要辦的事隨即成辦……若相對於說戒而言，它就屬於能成辦（說戒）者。」

**7. 【370-0001】「廣序」不宜擅增為「廣教端序」；「緣法」誤合為一詞**
- 「廣序」是科判名，若無確據不應展開（記中未見「廣教端序」之說）。
- 「通示緣法之意」的「緣」「法」分指**前七句眾緣**與**作白之法**，譯成「成辦緣法的大意」把它當複合詞，且「成辦」為添字。建議：「通泛顯示前緣與作法的用意。」

**8. 【370-0011】「七十許矣」的主語**
- 原譯：「說明自己在世間的時日已經不多，在重修此疏之時，年紀已經大約七十歲了」
- 問題：此是記主元照解釋**疏主道宣**「余老矣」之語，「自己」在【記文】譯語中极易被讀成元照。建議明點：「（疏主）在世不久，因重修此疏時，年已七十左右。」

## 二、增字／術語偏移（建議斟酌）

| 出處 | 原譯 | 問題與建議 |
|---|---|---|
| 0001 | 「以戒法住持三寶的功效強大」 | 「三寶」為添字；原文只說「住持功強，攝僧義勝」，主語是說戒之法 |
| 0001 | 「不容許虛妄混聽」 | 「混聽」生造；宜「不容輕率（妄濫）聽聞」 |
| 0003 | 「七個問答文句」 | 原文只作「七句」，「問答」是添加的解釋，可刪或加括號 |
| 0006 | 「圓滿僧寶所肩負的弘法道業」 | 「僧寶成務」指僧團法務成辦，「弘法」過度具體化；且「統明羯磨作業，僧寶成務」是並列兩句明羯磨功用，譯成因果長句稍失原貌 |
| 0007 | 「羯磨的功德妙用」 | 「功用」即功能作用，「功德」為溢譯 |
| 0007 | 「大眾作法還是個別作法」 | 宜作「眾法（羯磨）與別法（對首、心念）」，避免誤解為個人修行 |
| 0008 | 「審量前面的事由」 | 「前事」是**現前所要辦之事**，非「前面的（已過去的）事」 |
| 0008 | 「提出詢問確立所宗之法」／「標舉宗要圓滿回答」 | 「確立……法」「圓滿」皆添字；宜「提問所為之宗旨」「舉出所宗以成其答（答：說戒羯磨）」 |
| 0009 | 「助緣的體相則全都是相通的」 | 「緣相俱通」宜作「緣與相都通於諸法」 |
| 0009 | 「各自收攝其應有的法規分限」 | 「分齊」即界所攝的範圍，「法規」含糊；宜「自然界、作法界各自攝定的範圍」 |
| 0010 | 「十門精深的義理」／「嚴格的分寸」 | 「精深」「嚴格」為修飾添字 |

| 0011 | 「廣泛揭示了非法非相的過咎」 | 「非相」即不如法之相，「非法非相」重複、「過咎」添字 |

| 0011 | 「實在全憑宿世的大福報」 | 「宿慶」即宿世善慶，「大」可省 |
| 0011 | 「雖然時常聽聞探尋」 | 「雖復」是「雖然」，非「時常」 |

## 三、語句不通／贅詞

- 【0010】「**不到**迫不得已的情況，**才**偶爾在此略加疏解」——句式不合漢語習慣。改：「不得已時，才偶爾在此稍作疏解。」
- 【0010】「寶貴的光陰卻難以**停留挽留**」——同義重複。改：「時間功夫卻難以留住。」
- 【0010】「怎麼可以又**簡略略過**呢」——贅。改：「豈可再予省略？」（另：此句「理須遙指，何得復略」與上記「顯上須對指」的呼應，語氣宜再核，重點在「須指彼文」而非責備簡略。）
- 【0011】「羯磨法事的成功或失敗、所對應的事相如法或違法，**都展示了**大眾與個別行事的軌儀」——原文「作業成敗，被事如非。示眾別之行儀，顯僧宗之綱要」是並列陳述該書內容，譯文把前兩句變成後兩句的主語，句構走樣。建議四句平列：「（該書）辨作業的成敗、所被之事的如法與非法，顯示眾法別法的行儀，彰顯僧事的綱要。」
- 【0011】「在結語簡略的文句中分為兩層」——「結略」是科名（結示省略），宜「結略中分二，初、指廣」。
- 【0005】「在解釋之中，屬於第一個科判的段落拆分中」——可簡作「解釋中，初科分文」。

## 四、體例建議

1. **術語統一**：「作白」（0001）與「白法」（0005）宜一致或加註；「眾別」一律作「眾法／別法」；「界」不宜譯成一般語「界限」，至少首見加註「結界所定的範圍」。
2. **形容詞節制**：原記文極簡峭，譯文大量添加「精深、嚴格、極其、往往、大、真正」等語，個別處（如「弘法道業」「律宗」「合格僧眾」）已造成義理偏移，建議只在必要處補足，其餘從簡。
3. **前後互校**：0008 十緣的譯名應與 0009 記文的自釋對齊（尤其第四緣），這類「疏—記」同段互釋處最容易露出矛盾。

最關鍵的是 **0008 第四緣、0011「貴少賤多」、0012「即文／意言」** 三處，以及兩處「經文」誤稱，改動後全段義理就順了。
