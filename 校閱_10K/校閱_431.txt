# 校閱材料　第431檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【431-0001】02_戒疏/05a_卷二上之一#104
【原文】【記】問中。「地居天」者，謂須彌已下，依地住者，簡異空界。然盜空天物，結罪無殊，但取下地有可盜義，故偏舉之。「報勝解多」，即上人中初二兩義，而天又勝，故曰「相違」。答中。初二句，對上人中前二義。報解雖勝，盜取稀故。「於」下，反上後三義。著少、惱微，義兼護弱。「如」下，引例，可解。
【譯文】【記文】問答之中。「地居天」，是指居住在須彌山及以下依地而住的四王天、忉利天等，用以簡別空居天。然而偷盜空居天之物，結罪本無不同，此處只取地居天尚有可盜之情理，所以特加列舉。「報勝解多」，即對應上述人道中的前兩條義理，而天人比人類更勝，故發難說「豈不相違」。解答中，前兩句對應上述人道前兩義，說明福報知解雖勝，但行盜之事極稀少；「於」字以下，反對人道後三義，天人執著少、惱恨微，義理上也兼帶守護心薄弱；「如」字以下，引北洲為例，文意易明。

【431-0002】02_戒疏/05a_卷二上之一#105
【原文】【疏】殺相亦爾，人重餘輕。何以知者？亦由人趣報勝，根器有緣，能修諸善，出家成聖。然彼形心，俱是道器。今若加害，斷彼相續，即是障道，為過情深，故制極重。餘趣反上，報微故輕。
【譯文】【疏文】殺生的行相也是如此，在人趣造犯為重，其餘諸趣為輕。何以得知呢？也是因為人趣果報殊勝，是具足善緣之修道根器，能夠修行種種善法，進而出家成辦聖果。由此可見，人的形體與心靈，全都是載道的法器。如今若加害於人，斬斷了他生命相續之流，就是阻礙了他成就聖道，在過咎上情節極其深重，所以佛制結極重之罪。其餘諸趣反於上述條件，法器果報微劣，所以結罪從輕。

【431-0003】02_戒疏/05a_卷二上之一#106
【原文】【記】殺戒，勝劣中，初科。上二句指同。「何以」下，釋所以。初明人重。「亦由」者，亦前盜戒。「有緣」者，南洲具四緣，謂見佛、聞法、出家、成道；東西二洲，無見佛緣；北洲難地，故非所論。文中，且舉下二緣耳。「然彼」等者，示制重之意。「餘」下，次簡非畜，以不具諸緣，故云「反上」。
【譯文】【記文】殺戒勝劣之中，第一節。上兩句指同盜戒。「何以」以下，解釋原因。先明殺人罪重。「亦由」，指同於前之盜戒。「有緣」，指南贍部洲具足四緣，即見佛、聞法、出家、成道；東、西二洲無見佛緣；北洲乃八難之一，故不在討論之列。文中暫且舉出後兩緣。「然彼」等句，顯示立制結重之深意。「餘」字以下，簡別非人與畜生，因彼等不具備成道諸緣，故說「反於上述」。

【431-0004】02_戒疏/05a_卷二上之一#107
【原文】【疏】是以《多》云：「三歸五戒、木叉解脫，沙門四果、佛及辟支，必在人道，漏盡成聖。」故有損害，便得重罪。天雖報勝，不能出家以成僧寶。
【譯文】【疏文】因此《薩婆多論》說：「受持三歸依、五戒，得別解脫木叉，證沙門四果，乃至成辦辟支佛與無上佛果，必定都在人道之中漏盡煩惱而成就聖位。」所以對人有所損害，便犯下極重之罪。諸天福報雖勝，卻不能出家以成就僧寶。

【431-0005】02_戒疏/05a_卷二上之一#108
【原文】【記】引證中。彼論問曰「何以但害人得波羅夷」，答如文引。「木叉解脫」，即是具戒。上明三種因法，則在凡地；「沙門」下，三種果人，唯局聖位。修因剋果，俱在人中。「天雖」下，簡餘趣。「不能出家」者，彼論帝釋語目連云：「一天子、一天女，妓樂自娛，不能自割。況作天王，種種宮觀，無數天女，天須陀食，自然百味，百千妓樂以自娛樂。雖知佛世難遇，正法難聞，而染樂纏縛，不得自在。善心力弱，何由出家？」然此，且據一相以論。至如諸經，帝釋、梵王多臨法會，諸天聞法，得道亦多，則非言限。
【譯文】【記文】引論印證之中。彼論提問說「為何唯獨殺死人得波羅夷罪」，解答正如文中所引。「木叉解脫」，即是具足戒。上述三種為因之法，乃是在凡夫地所修；「沙門」以下三種為果之聖人，純屬聖位。修因證果，全在人道之中。「天雖」以下，簡別其餘諸趣。「不能出家」，如彼論記述帝釋天對目犍連說：「單是一個天子配一個天女，沈溺於伎樂歡娛，尚且割捨不下。何況身為天王，擁有種種宮殿樓觀、無數天女眷屬，吃的是天須陀食、自然化現百味珍饈，耳聽百千伎樂自娛自樂。雖然深知佛世難遇、正法難聞，但已被染樂緊緊纏縛，身心不得自在。善心力量微弱，從何因緣得出家？」然而這只是依據常態之相而論；至於各部經典中，帝釋、梵王多次降臨法會，天眾聞法悟道者亦極多，那就不在此常規限度之中了。

【431-0009】02_戒疏/05a_卷二上之一#112
【原文】【疏】答：「天位高遠，理絕恒心。但婬欲熾盛，不擇境之美惡，容有下赴。為之義數，過於殺盜，故制重罪。如《律》文中，天女事證。又如人道，下染畜趣，即此良證，何事疑？」
【譯文】【疏文】答：「天界地位高遠，照理斷絕了相續不斷的欲心。但淫欲之火極其熾盛之時，根本不揀擇境界的美醜好壞，容有屈身下就之事。行淫造作的次數頻繁，遠遠超過殺生與偷盜，所以制定為重罪。正如律文中所載，有比丘與天女行淫為證。又如同人道眾生，下就去淫染畜生，這正是確鑿的證明，還有什麼值得疑惑的呢？」

【431-0010】02_戒疏/05a_卷二上之一#113
【原文】【記】問中，以婬天亦重故引為難。答中。初承來問。「絕恒心」者，不同下地，欲心相續故。「但」下，正答。婬數餘疎，重輕乃異。「如」下，引證。《律》中，有比丘與天女行婬已疑，佛言「波羅夷」。「又」下，舉例。即《律》中，有比丘與獼猴行婬，因制「共畜生」等。以人染畜，例天就人，於理明顯，故云「良證」。
【譯文】【記文】提問之中，以淫天人亦結重罪為由提出難問。答覆之中，先承接問意。「斷絕常心」，指天人不同於地界凡夫那樣欲心相續。「但」字以下，正式解答。淫欲之事頻繁而其餘殺盜疏稀，所以重罪與輕罪遂有不同。「如」字以下，引律為證。律中記載，曾有比丘與天女行淫，事後心生疑慮，佛陀判定犯波羅夷。「又」以下，舉例類推。即律中載有比丘與母獼猴行淫，佛陀因而立制「若比丘共畜生行淫」等。以人類下染畜生，比照天人下就人類，在法理上至為顯明，故說是「確鑿證明」。
