# 校閱材料　第1893檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1893-0001】03_業疏/22a_卷四之五#7
【原文】故論說言：「地獄中陰身，猶如鎔鐵聚，熱惱燒然苦，不可得譬喻。宜當除懈怠，晝夜不休息，精勤修聖道，必使盡苦際。」斯為聖言量也，同舟各審知之
【譯文】所以論典中說：「地獄的中陰身，就像融化的鐵塊聚集在一起，受熱惱焚燒的痛苦，根本無法用言語譬喻。應當除去懈怠之心，晝夜不停地精勤修持聖道，務必窮盡一切痛苦的邊際。」這是至高無上的聖言量，同在一艘航船上的各位道友各自要審慎明白這個道理。

【1893-0002】03_業疏/22a_卷四之五#8
【原文】三中，《智論》四趣各有一偈，此引地獄偈。上一偈示苦報，陰即五陰，如鎔鐵聚，略譬少分，故云不可譬喻；下一偈勸修。餓鬼偈云：「餓鬼受穢形，其類百千種，不聞漿水名，動經千萬劫。」畜生偈云：「畜生相殘害，日夜常逼迫，愚癡暗障故，無由思解脫。」修羅偈云：「修羅被五道，威武抗諸天，多疑不信故，燒然諸善根。」「斯」下，結告。舟喻聖法，可以濟渡。同法、同道、同行、同學等，皆召出家奉持之士
【譯文】第三段中，《大智度論》對四惡趣各自有一首偈頌，這裡引用的是地獄偈。前一偈開示地獄的苦報，「陰」就是五陰，猶如融鐵聚合，只是大略譬喻極少部分，所以說不可譬喻；後一偈是勸勉修行。餓鬼偈說：「餓鬼承受污穢的身形，其種類有百千之多，連水漿的名字都聽不到，動輒歷經千萬劫。」畜生偈說：「畜生互相殘害，日夜常受恐怖逼迫，因為愚癡蒙蔽障礙的緣故，根本無從思索求取解脫。」阿修羅偈說：「阿修羅被五道所攝，以威武之勢對抗諸天，因為多有懷疑而不信順的緣故，焚燒毀滅了一切善根。」自「斯」字以下是總結告誡。船舟譬喻聖法，可以用來救濟度脫。同法、同道、同行、同學等人，都是用來稱呼出家奉持戒律之士。

【1893-0003】03_業疏/22a_卷四之五#9
【原文】將欲解文，先以義顯。四門分之一：對治方法，二：理事不同，三：小大對緣，四：滅伏之意
【譯文】在將要解釋律文之前，先以義理來予以顯發。分為四門來闡明：第一、對治方法，第二、理與事懺悔的不同，第三、小乘與大乘對境因緣的不同，第四、滅罪與伏斷罪惑的意旨。

【1893-0005】03_業疏/22a_卷四之五#11
【原文】凡罪生也，託因從緣。因即妄心，非有謂有，隨有興我，便計彼此，即起集業。故經說言：「一切諸法自本來今，性相空寂；而眾生虗妄，橫計得失彼我，起不善念，造眾惡業，輪迴五道，億劫不出。」二者妄緣，境有色心，由之造業，不知心變，妄謂他有，還緣自心，故反纏裹。如說「三界上下法，我說皆是心」，向造諸業，但知唯心，則無分別是彼此也
【譯文】大凡罪業的生起，都是依託內因而順從外緣。所謂「因」，就是妄心，原本非有卻妄認為有，隨著妄執的有而生起我見，隨即計度彼我分別，由此便發起積集惡業。所以佛經中說：「一切諸法從無始以來至今，其本性與行相皆是空寂；然而眾生虛妄，橫加計度得失與彼我，生起不善之念，造作種種惡業，輪迴流轉於五道之中，億劫不得出離。」第二是「妄緣」，所緣境界包含色法與心法，依此造作罪業，卻不知道一切境界皆是唯心所變，妄自認為心外別有他境，反過來又以自心緣取妄境，所以反被自身纏縛包裹。就如佛所說「三界上下的一切法，我說全都是自心所現」，從前所造的種種罪業，只要通達唯是自心，那麼也就不會去妄自分別彼此了。

【1893-0006】03_業疏/22a_卷四之五#12
【原文】義門第一立懺意中，初科初總標。「因」下，別釋，又二：初示罪因。妄，無也，無而謂有，即是妄義。由隨境有，謂之六塵緣影，亦名六境界心，幻化、陽𦦨、龜毛、兔角皆喻此心。興我起業，生死輪迴。由不了此，故下引證。「諸法本空」，證非有也；「眾生妄計」，證謂有也。「橫計」等是惑道，「起不善」等是業道，「輪迴不出」即苦道。二明罪緣。色、心二法攝境盡故。「不知心變」，迷唯心故；「妄謂他有」，計心為境故；以心緣心，造業自縛，如蠶繭故。已上敘迷，如下顯悟。三界中，色、無色天為上，欲界為下。或云「三界無別法，唯是一心作」，語少異耳。既了唯心，反觀前罪皆非他法，故云「向」也
【譯文】義門第一「立懺之意」中，第一科起初是總標。自「因」字以下作分別解釋，又分為兩部分：首先開示罪業的內因。「妄」，就是虛無，本無而妄認為有，這就是「妄」的意思。因為隨逐境相而執為實有，稱為六塵緣影，也稱為六境界心，幻化、陽焰、龜毛、兔角都是用來比喻這種心念。由執我而造起業行，導致生死輪迴。由於不明白這個道理，所以下文引經為證。「諸法本空」，證明本來非有；「眾生妄計」，證明妄自認為有。「橫計」等等屬於惑道，「起不善」等等屬於業道，「輪迴不出」即是苦道。其次說明罪業的外緣。色法與心法兩種法門已將一切境界攝盡。「不知心變」，是因為迷失了唯心的實相；「妄謂他有」，是因為執取自心妄現之相為心外實境；以心去攀緣自心，造業而自我繫縛，就如同春蠶作繭自縛一樣。以上是敘述迷亂之狀，以下則是顯發覺悟之態。在三界之中，色界與無色界天為上，欲界為下。有的經文說「三界無別法，唯是一心作」，只是用詞稍有差異而已。既然明了唯心，反觀先前所造的罪業全都不是心外之法，所以說「向（從前）」了。

【1893-0007】03_業疏/22a_卷四之五#13
【原文】既識起因，能感後習：一、感種類相續而起，二、招苦報生後當受。今改前非，將修後是，從緣生滅，斯苦世法，於彼惡業特生厭賤，發重慚愧，立對治過，洗心懺悔
【譯文】既然認識了罪業生起的因緣，知道它能感召未來的習染之果：第一、感召同類惡習相續不斷生起，第二、招感痛苦惡報在來生或後世必定承受。如今痛改先前的過非，將要修持未來的正行；既然明白善惡都是從因緣生滅，這些痛苦都是世間輪迴之法，便對那些惡業特別生起厭離鄙賤之心，發起深重的慚愧，確立對治罪過的行法，洗滌內心而勇猛懺悔。

【1893-0008】03_業疏/22a_卷四之五#14
【原文】次科初指因，即躡上文。「能」下，顯果。後習有二：一即習果，二即報果。「今」下，敘懺意，有三：一生厭，二發愧，三立治。「從緣生滅」即上因果，苦、集二諦並世間法
【譯文】下一科起初指出內因，即是承接上文而來。自「能」字以下顯明果報。「後習」有兩種：一是習果（等流果），二是報果（異熟果）。自「今」字以下敘述懺悔的心意，包含三個層面：第一生起厭離，第二發起慚愧，第三確立對治。「從緣生滅」就是指上述的因果，苦諦與集諦二者全都屬於世間法。

【1893-0009】03_業疏/22a_卷四之五#15
【原文】懺者，梵語本曰懺摩，唐言悔往，亦曰卑敬，存二方言，故曰懺悔。懺字後立，非此書也。取其義意，謂不造新，則此懺謂止斷未來；非悔，謂耻心於往犯。由斯善故，已起無緣，當生無續，雙礙緣續，說名行除；又由斯善來感樂報，差彼苦緣，名為報除。若欲懺者，略知此意
【譯文】所謂「懺」，梵語原本叫做「懺摩（kṣama）」，唐言（漢語）翻譯為悔過以往，也翻譯為自居卑下恭敬他人，兼存梵漢兩種方言，所以稱為「懺悔」。「懺」這個字是後人所造，本非此土固有之書契字彙。若取其義理意涵，「不造新業」是指這「懺」字乃是用來止息阻斷未來的惡業；而「悔」則是以羞恥慚愧之心面對過往所犯之罪。由於這種悔罪之善行，已生起的惡業便無緣得以增長，當來應生的惡業也不再相續，同時阻斷了惡緣與惡念相續，這就稱為「行除（業行之除滅）」；又由於這種善行能夠在未來感得安樂果報，改變並抵消了那些苦報之緣，這就稱為「報除（苦報之免除）」。如果想要修行懺悔的人，應當大略明白這個道理。

【1893-0010】03_業疏/22a_卷四之五#16
【原文】三中，初翻名。懺是略梵，悔即略華。今時篇韻皆有懺字，乃是後加。「取」下，次以義分。斷後為懺，耻前為悔。轉因為行除，易果為報除
【譯文】第三段中，起初翻譯名義。「懺」是梵語的略稱，「悔」就是漢語的簡稱。如今的字書韻書中都有「懺」字，乃是佛教傳入後所追加的。自「取」字以下接著依據義理來分別：斷絕未來的惡業稱為懺，以過往的罪業為恥稱為悔。扭轉業因稱為「行除」，轉變果報稱為「報除」。
