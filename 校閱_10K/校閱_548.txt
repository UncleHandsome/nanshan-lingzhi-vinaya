# 校閱材料　第548檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【548-0001】02_戒疏/09b_卷二下之二#106
【原文】【記】三、麤語戒，指制意中。探引後戒，雙指同前。「莫非」下，略示大意。四戒並因迦留陀夷避制相由而結，如注委引。
【譯文】【記文】第三、麤語戒，在指出制戒意旨的部分中，預先引及後面的歎身戒，兩者都指向前面所說的摩觸戒。「莫非」以下，簡略顯示大意。這四條戒（失精、摩觸、麤語、歎身）都是由於迦留陀夷為逃避佛制而衍生事端，才結成的，如註文所詳細引述。

【548-0002】02_戒疏/09b_卷二下之二#107
【原文】【疏】釋戒名者，婬欲鄙惡，極是不善，故名為「麤」。今說其狀，表彰於口，故曰「語」也。
【譯文】【疏文】解釋戒名：婬欲之事卑鄙惡濁，極其不善，所以名為「麤」；如今說出它的情狀，由口中表彰出來，所以叫做「語」。

【548-0003】02_戒疏/09b_卷二下之二#108
【原文】【疏】犯緣有七：一、女人；二、作人女想；三、有染心；四、麤惡語；五、麤語想；六、言章了；七、前人知解。

【548-0008】02_戒疏/09b_卷二下之二#113
【原文】【疏】就《戒本》中，有五：初出犯人；二、明內染；三、出犯境；四、陳過相；五、「隨說」下，結罪也。

【548-0009】02_戒疏/09b_卷二下之二#114
【原文】【註】女人有智，命根不斷。
【譯文】【註文】所對的女人須有知解能力，且命根未斷（仍是活人）。

【548-0010】02_戒疏/09b_卷二下之二#115
【原文】【疏】三、出語境中。注解「人女有智，命根不斷」者，異於「觸」境。彼境通於死活，此則唯是其生，故云「命根不斷」也。彼則通於昏睡、孩童，此則唯論有智，時可知言染淨、迷悟，罪分輕重。故此戒「女」，異於前也。
【譯文】【疏文】第三、指出言語對境的部分。註解說「人女有智，命根不斷」，是為了與「摩觸」戒的對境有所區別：摩觸戒的對境通於活人與死屍，這裡則只取活著的人，所以說「命根不斷」；摩觸戒的對境也通於昏睡的人與幼童，這裡則只論有智慧、能聽懂話的人。因為能聽懂言語，在比丘說話時，女人能辨知言語是染污（粗惡）或清淨（非粗惡），且能辨明女方是誤解還是領解，比丘結罪也就有輕重之別。因此這條戒所說的「女」，與前面摩觸戒不同。

【548-0011】02_戒疏/09b_卷二下之二#116
【原文】【記】戒本，第三中。初總示。以摩觸境通，麤語境局，故對前「觸」以顯別相。「彼」下，別簡。初簡死壞，「彼則」下，次簡昏小。「知言染淨」，即辨麤非麤。「迷悟」，即知誤非誤。「罪輕重」者，《律》云：「情相領，結殘。解語不解義，偷蘭。」、「故」下，結顯。
【譯文】【記文】戒本第三句（指出語境）之中，首先總體指示：因為摩觸戒的對境寬通，麤語戒的對境狹窄，所以相對前面的「觸」戒來顯示差別相。「彼」字以下，是分別簡別：首先簡去死屍壞爛的對境；「彼則」以下，其次簡去昏睡與幼童。「知言染淨」，是辨別所說的是麤語或不是麤語；「迷悟」，是辨別對方是誤解還是不誤解。「罪輕重」方面，《律》中說：「彼此情意相互領受，結僧殘罪；聽懂言語而不解其義，結偷蘭遮。」「故」字以下，是總結顯示。

【548-0012】02_戒疏/09b_卷二下之二#117
【原文】【律】麤惡婬欲語。
【譯文】【律文】粗惡的淫欲之語。

【548-0013】02_戒疏/09b_卷二下之二#118
【原文】【疏】「麤惡婬欲」者，正是《戒本》所防業也。
【譯文】【疏文】所說的「麤惡婬欲」，正是《戒本》所要防制的業行。

【548-0014】02_戒疏/09b_卷二下之二#119
【原文】【註】麤惡者，非梵行也。婬欲語者，稱二道好惡也。若求，若教他求，若問，若答，若解，若說，若教，若罵。所言「求」者，「與我二道作如是事」，若復作餘語，如是解者是也。
【譯文】【註文】所謂「麤惡」，就是非梵行（不淨的淫行）。所謂「婬欲語」，就是稱說二道（大便道、小便道）的好惡美醜。或者自己求，或者教他人求，或者問，或者答，或者解說，或者稱說，或者教導，或者責罵。所說的「求」，就是說「和我二道做這樣的事」；或者再說其他的話，對方這樣理解，就是犯戒。

【548-0015】02_戒疏/09b_卷二下之二#120
【原文】【疏】注解中。「非梵行」者，釋「麤惡」相也。說「二道好惡」，明其欲相。文須識者，恐未明了，妄為次死之罪，下有八相，律文具解。既離非相，故廣列之。
【譯文】【疏文】這是註解的部分。所說的「非梵行」，是在解釋「麤惡」的相狀；講到「二道好惡」，是在說明貪欲的表現。這段文句必須辨識清楚，恐怕有人還沒弄明白，就誤犯了僅次於死（波羅夷）的重罪。下文列有八種相狀，律文中有完整的解說。既然是要分別說明過非的相狀，所以廣泛地列舉出來。

【548-0016】02_戒疏/09b_卷二下之二#121
【原文】【記】第四，釋注中。初分語相。「文」下，顯示注中的指之意。下點「八相」，竝謂對女說上麤語，差別之事，且出八種，臨事何窮？注中次列，但釋第一，餘七略之。今為具引，《律》云「若教求者，若復作餘語教他求二道也；若問者，即問言『汝二道何似』；若答者，即云『汝二道如是』，若解若說亦如是；若教者，言『我教汝如是治二道，可令敬愛』；若罵者，即言『汝二道破壞腐爛』」等。「既」下，示注引意。
【譯文】【記文】第四節，是解釋註文的部分。先分辨言語的相狀；「文」字以下，是顯示註文所指的意思。下面點出「八相」，都是指對著女人說上面那些粗惡的話，屬於種種差別情況，這裡姑且舉出八種，真正遇到事情哪能列得完？註文接著列舉，只解釋第一種，其餘七種省略。現在為它完整引出：《律》中說「若教人去求，或者用其他的話教他去求二道；若是問，就問說『妳的二道是什麼樣子』；若是答，就說『妳的二道是這樣』，不論是解釋或述說都一樣；若是教，就說『我教妳這樣整治二道，可以使人敬愛』；若是罵，就說『妳的二道破壞腐爛』」等等。「既」字以下，是顯示註文引文的用意。

【548-0017】02_戒疏/09b_卷二下之二#122
【原文】【疏】此律約緣，明比丘向女人說也。就後解中「若問若答」，明知女說，染心相領，亦同犯也。故《五分》中「彼此互說，皆犯殘罪」，下戒亦同。
【譯文】【疏文】這條律是就著因緣，說明比丘對女人所說的話。在後面的解釋中講到「若問若答」，就可以明白知道：即使是女人說，以染污心互相領受，也同樣犯戒。所以《五分律》中說「彼此互相說，都犯殘罪」，下一條戒也是一樣。

【548-0018】02_戒疏/09b_卷二下之二#123
【原文】【記】通互中。初示本律前後二文。「約緣」者，據本迦留，則無「互」義。「後解」，即八相中，既容問對，顯通彼此，互說皆成。「故」下，次引他文為證。「下戒同」者，即指「歎身」互說同犯。
【譯文】【記文】這是「互通」這一段。先指出本律前後兩處文句。「約緣」是說：根據原本迦留陀夷的事緣，並沒有「互相」的意思。「後解」就是八相之中，既然容許一問一答，就顯示彼此相通，互相說都成立。「故」字以下，其次引用其他律文作證明。「下戒同」是指「歎身」戒中互相說也同樣犯。

【原文】【疏】「若復作餘語」者，言極非染，表事是穢故也。廣如《鈔》中。
【譯文】【疏文】「若復作餘語」這一句，是指言語表面極無染污，表示所說的事情是污穢的。詳細如《鈔》中所說。
