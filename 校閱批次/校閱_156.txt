# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【156-0002】01_行事鈔/10a_卷下之二#11
【原文】三明轉變者。《中論》云：如蒲萄漿，持戒者應飲；若變作酒，不應飲；若變為苦酒，還復得飲。《十誦》：甘蔗是時藥，清汁是非時分，作石蜜是七日，燒作灰是盡形。肉是時藥，煎取脂是七日，燒作灰是盡形。胡麻同肉法。酪是時藥，清汁如水是非時，作穌是七日，燒為灰名盡形。
【譯文】第三、闡明藥物的轉變：《中論》說：比如葡萄漿，持戒之人應當飲用；如果發酵變成了酒，就不應當飲用；如果進一步變成了苦酒（醋），又恢復得以飲用。《十誦律》說：甘蔗本身是時藥，榨出的澄清汁液屬於非時分，加工熬成石蜜則是七日藥，燒成炭灰則是盡形壽藥。肉類是時藥，煎熬提取的脂肪是七日藥，燒成灰則是盡形壽藥。胡麻的律法規定與肉類相同。乳酪是時藥，澄清如水的汁液是非時藥，提煉成酥是七日藥，燒成炭灰則稱為盡形壽藥。

【156-0003】資持記/14a_下二#29
【原文】《涅槃》云：有六種味：一苦，二酢，三甘，四辛，五鹹，六淡時量中，初對味別簡。六味中，缺鹹淡二味。甘味中，甘草是盡形，蜜等即七日。酸中，果汁是非時。辛味中，薑椒等皆盡形。苦味不入時食，故唯在終身。次對七日總簡。以七日體別，同是可食，故除已外，一切名時。從下，顯示時義。
【譯文】《涅槃經》說：有六種滋味：一是苦，二是醋（酸），三是甘（甜），四是辛（辣），五是鹹，六是淡。在「時量」之中，首先對照不同滋味分別進行簡別。六味之中，缺少鹹味與淡味。在甘味之中，甘草是盡形壽藥，蜜等則是七日藥。酸味之中，果汁是非時漿。辛味之中，生薑花椒等都是盡形壽藥。苦味不列入日常正餐，所以唯獨屬於終身服用的藥。接著對照七日藥作總體簡別。因為七日藥體性不同，但同樣可以食用，所以除去七日藥之外，其餘一切皆稱為時藥。從下文開始，顯明時藥的意義。

【156-0004】資持記/14a_下二#30
【原文】若論時及盡形，皆通六味。但時藥微通辛苦，盡形少於甘肥，非時多是甘酸，七日唯局甘味，如是求之。更量者，日中受藥，以五更為限故。日夜各五時者，無論長短，但將一日分為五時，對夜五更。〔不可定約寅卯等時；以夜五更，亦不限此時故。
【譯文】若論時藥與盡形壽藥，兩者都通於六味。但時藥稍微通於辛辣與苦味，盡形壽藥則缺少甘甜與肥美，非時漿多是甘甜與酸味，七日藥則唯局限於甘甜之味，應當依此準則去探求。所謂「更量」，是指受藥以夜間五更為時限的計算方法。所謂「晝夜各分五時」，不論時間長短，只是將一天分為五個時段，對應夜晚的五更。（不可死板限定在寅時卯時等時辰，因為夜晚的五更也不局限於固定的鐘點。

【原文】【疏】四、取多非重，不得而重者。如《伽論》云：「數取四錢，數作斷意，乃至五千，不犯重也。」又如《四分》，燒、埋、壞色，或教他不為己，亦犯重故。

【156-0006】02_戒疏/07b_卷二上之三#84
【原文】【疏】五、不滿五結重，過五但輕者。如《律》，眾多人遣一人盜五錢，多人共分，隨本一分，滿五通犯。如《十誦》中，盜眾多人未分物，雖多而輕，謂亡比丘輕物也。

【156-0007】02_戒疏/07b_卷二上之三#85
【原文】【疏】六、盜一人一錢重。如《僧祇》，五人各以一錢，同遣一人掌之，若盜望護主結是也。又如《善見》，欲識盜相。如師徒四人，相教互盜一人六錢，各得一夷一蘭。此義應知。如師語三弟子曰：「彼有六錢，大者取三，次小各取一，我自取一。」乃至小弟子亦作此言：「彼有六錢，和尚取三，同學各一，我自取一。」教人滿「五」夷，自偷不入教人業故，但蘭。可以類知。
【譯文】【疏文】第六、偷盜一個人的一個錢卻結重罪。如同《僧祇律》所載，五個人各自拿一個錢，共同交付一個人掌管，如果有人偷取，是針對那位保管者來結罪，所以成立重罪。又如同《善見律毘婆沙》記載，想要明白盜罪的行相。好比師徒四人，彼此教唆相互去偷同一人的六個錢，四人各自得到一個重罪（波羅夷）與一個中罪（偷蘭遮）。這個義理應當知曉。好比師父對三個徒弟說：「那裡有六個錢，大徒弟去拿三個，二徒弟與三徒弟各拿一個，我自己拿一個。」乃至最小的徒弟也說這話：「那裡有六個錢，師父拿三個，同學每人各拿一個，我自己拿一個。」因為指使他人偷盜滿了「五個錢」而犯不可悔重罪（波羅夷），自己動手偷那一個錢，並未算進指使他人的罪業之中，所以只結粗惡罪（偷蘭遮）。其餘情況可以依此推知。

【156-0013】02_戒疏/07b_卷二上之三#91
【原文】【記】六中。初標句，「如」下，引釋。《僧祇》中，且從本主，以立句義，然望護主成重，自是盜五耳。《善見》中。初立義。「如」下，示相。「四人互教」，乃約異時為言。若一時中，止可一人為能教，三為所教。能教「取一」，即是盜一成重之義。「自偷」即自業相成，「教人」即假異緣剋果。二業緣別，故「不相入」。
【譯文】【記文】在第六門中。先標出語句，「如」以下，引律論解釋。《僧祇律》中，暫且是順著原物主的立場來設立文句的涵義，然而針對那位掌管者而言成立重罪，本質上自然是因為所偷總額達到了五錢。《善見律毘婆沙》中。首先確立義理。「如」以下，展示具體行相。「四人相互教唆」，是指在不同時間發生的情況。如果在同一個時間，只能有一人作為能教唆者，其餘三人為被教唆者。能教唆者自己「拿一個」，這就是偷盜一個錢卻藉由整件事成立重罪的道理。「自己動手偷」是由自身的惡業單獨成立，「指使他人」則是憑藉外在不同的緣起促成惡果。這兩種業力緣起各不相同，所以「互不歸併混雜」。

【156-0014】02_戒疏/07b_卷二上之三#92
【原文】【律】若為王、王大臣所捉，若殺，若縛，若驅出國，「汝是賊，汝癡，汝無所知」，是比丘波羅夷。
【譯文】【律文】：如果不幸被國王、或國王大臣逮捕捉拿，或者被處死，或者被綑綁囚禁，或者被驅逐出國境，並被痛斥斥責道：「你是賊，你愚癡，你毫無所知」，這個比丘便構成不可悔的棄損重罪（波羅夷）。

【156-0017】02_戒疏/07b_卷二上之三#95
【原文】【疏】所以列者？欲明盜損，道俗同弊，輕仁薄義，勿過於此。故列此相，用懲後犯。
【譯文】【疏文】：為什麼要列出這些內容呢？是為了說明盜竊損人，在佛門修道人與世俗凡夫之中都同樣是惡劣之極的弊病，輕蔑仁愛、薄待道義的行徑，沒有比這個更嚴重的了。所以列舉出這些行相，用來警惕懲戒後來的違犯者。

【156-0018】02_戒疏/07b_卷二上之三#96
【原文】【記】顯意中。初句徵問。「欲」下，引釋。初約誡後釋。「弊」，惡也。皆有此惡，故云「同弊」。「輕仁」，謂無濟惠之心。「薄義」，謂非義而取。「懲」，音澄，誡也。
【譯文】【記文】在顯發立意這一科判中。第一句提出徵問。「欲明」以下，引申解釋。先就告誡後人來解釋。「弊」就是惡劣。世俗佛門都有這等惡行，所以說「同弊」。「輕仁」是指毫無救濟周濟他人的仁愛之心。「薄義」是指以不合道義的手段強取。「懲」的讀音是「澄」，意思是警戒懲戒。

【156-0019】02_戒疏/07b_卷二上之三#97
【原文】【疏】又人解云：「初篇四夷，餘三自犯，無多過失。顯盜是公白，尚盜王材，況餘凡庶，而得免者？故舉貴類賤，舉難況易，意可見也。」
【譯文】【疏文】：又有人解釋說：「戒律第一篇的四條根本重罪中，其餘三條都是自己暗中違犯，在世俗看來沒有引發太大的擾動過失。而列舉這條是為了突顯盜竊是在光天化日之下公然損害他人，連國王的資財都敢偷盜，更何況一般平民百姓，又怎麼可能倖免呢？因此列出尊貴的國王來比類卑微的小民，列出難以下手的國王資財來比況容易盜取的庶民財物，佛陀的深意由此便可以看出了。」

【156-0020】02_戒疏/07b_卷二上之三#98
【原文】【記】次科，約彰過釋。「貴」則無過國王，「難」則無過王物，故舉其極，以況其餘。
【譯文】【記文】在第二小科中，是就彰顯罪過的角度來解釋。「尊貴」莫過於國王，「難以盜取」莫過於王家財物，所以舉出極端的例子，以此比況其餘尋常事物。

【156-0021】02_戒疏/07b_卷二上之三#99
【原文】【疏】捉殺四相，輕重文亂。若欲糾正，應言捉、縛、驅、殺也。
【譯文】【疏文】：捉拿、處死這四種處罰相，律文中的輕重順序有所錯亂。如果要糾正順序，理應當說是：捉拿、綑綁、驅逐、處死。

【156-0022】02_戒疏/07b_卷二上之三#100
【原文】【記】牒釋中，初科。以殺第二，治法不次，義須後列。「糾」，定也。
【譯文】【記文】在逐句解釋中，這是第一小科。因為處死排在第二位，處罰的先後次序並不合理，在法理上必須排在最後。「糾」是定奪校正的意思。

【156-0023】02_戒疏/07b_卷二上之三#101
【原文】【疏】所言「捉」者，《僧祇》云：「瓶沙王遠祖治賊，但令栴陀羅拍頭捉手，便自愧恥，永不行盜。」所言「縛」者，世濁情澆，雖捉猶作，乃於多人之處，祖王使人以灰圍之。及至父時，止故灰圍，行「驅出」法。至瓶沙登位，七反驅出，還入為盜。乃截一指，愁悔無極。佛為王說過去為養千愚事。至阿闍世，乃行殺戮也。
【譯文】【疏文】：所說的「捉拿」，《僧祇律》記載：「頻婆娑羅王的遠祖治理處罰盜賊時，只要命令旃陀羅（下賤階級的行刑者）拍拍盜賊的頭、捉捉他的手，盜賊便深感慚愧羞恥，永遠不再行盜。」所說的「綑綁」，是因為後來世風日下、人情澆薄，盜賊即便被捉拿訓誡依然照常作案，於是祖王便在聚集眾人的處所，派人撒石灰畫圈將盜賊圍在中間。等到其父王即位時，停止了撒石灰圍困的作法，改為施行「驅逐出國境」的刑罰。等到頻婆娑羅王登基時，曾將一個盜賊七次驅逐出境，那盜賊卻一再折返回來偷盜作亂。國王於是下令斬斷他的一根手指，事後國王憂愁悔恨到了極點。佛陀為國王講述了他過去世曾收養一千個愚人的因緣故事。到了阿闍世王的時候，世風更壞，就真正開始施行殺戮死刑了。
