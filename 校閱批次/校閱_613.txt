# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【613-0001】04_比丘尼鈔/05a_卷下之上#12
【原文】第二淨地處此門有四一籬牆不周淨此律云半有籬障多無籬障都無籬障垣牆壍柵亦如是二檀越淨一食具是他物故律云自今已去應作檀越食食淨人掌舉不得自受若有所須隨意索取二處所是他物故律云若為僧作伽藍未施與僧雖食在中不名有犯三食及處俱是他物不屬僧用三處分淨者此律云若檀越若經營比丘為僧作伽藍時處分如是言某處僧作淨地是名處分淨四白二羯磨結淨地者義云謂伽藍院相周帀比丘尼在中有宿煑過無問久近隨處結之除去比丘尼然後結之母論云大界內無淨廚者一切宿煑不得食乃至藥草亦爾此律云因比丘餓死故聽在伽藍內邊房靜處結作淨地五分云諸比丘欲羯磨一房一角半房半角或中庭通結坊內作淨地並聽。
【譯文】第二「清淨處所的界定」（淨地處）：這一門分為四種：第一是籬牆不周全的清淨處，本律說明：半邊有籬笆圍障、大部分無圍障、或者全無籬笆圍障，垣牆、壕塹、柵欄的情況也是如此。第二是檀越（施主）清淨處，一是食器用具屬於他人財物，所以戒律說：從今以後應當作為施主供奉之食，由淨人掌管拿取，僧人不得擅自手受，若有所需，隨意向淨人索取；二是處所空間屬於他人所有，所以戒律說：若是為僧團建造寺院，尚未正式布施交給僧團之前，雖然在其中儲煮飲食，不算犯戒；三是食物與處所全屬他人所有，不屬於僧團公用。第三是指定分界清淨處（處分淨），本律說明：如果是施主或者營建比丘為僧眾建造寺院時，具體指定說明：「僧團將某處作為淨地」，這就稱為處分淨。第四是透過白二羯磨正式結定的淨地。《義釋》指出：這是指寺院圍牆界線周圍完備，比丘尼安住其中，容易有隔夜宿食同煮的過失，無論住期長短，皆可隨處結定淨地；先請比丘尼離席，然後正式結定。《毘尼母論》說：大界之內如果沒有淨廚，一切隔夜煮熟之物皆不得食用，乃至藥草也是如此。本律說：因為曾有比丘餓死，所以開許在寺院內偏僻僻靜處結為淨地。《五分律》說：諸比丘若欲透過羯磨，將一間房、一個角落、半間房、半個角落、或者天井中庭通體結為房內淨地，皆屬開許認可。

【613-0007】01_行事鈔/11c_卷下之三#21
【原文】凡入寺之行，與俗人作入道之緣；建立寺者，開淨土之因；供養僧者，為出離之軼也。今末法中，善根淺薄，不感聖人示導，僅知有寺而已。不體法意，都無敬重佛法，超生因緣；供養福田，而來入寺也。多有人情來往，非法聚會。又在寺止宿，坐臥床褥，隨意食噉；乞索取借，如俗去還；遂意則喜，違心必瞋；繫綴胸抱，望當圖剝；猶牛羊之抵突，恣頑癡之鄙情。或用力勢逼掠，打撲抄奪。具造惡業，必死何疑。一旦橫骸，神何可滅，隨業受苦，永無救護，可共悲哉。若有智之人，終不行此；敬重寺法，準而行之；護惜三寶，諮請法訓，自招大益。故經云：眾僧良福田，亦是蒺䔧園。斯言實矣！當知衰利由心，非前境咎。

【613-0008】資持記/15e_下三#38
【原文】舉況引證，尋文可了。經中，即《寶即手經》，又《文殊問經》云：死坐鐵床上。若下，不後起。斥非中，初文。入道緣者，善根由發故。淨土因者，心清淨故。出離軼者，期解脫故。軼即是轍，車所從之道也。次科，初敘無知。僅，猶略也。不體法意者，總迷上三也。都無下二句，反上因緣也；
【譯文】經文中透過舉例比況引經作證，只要尋繹經文便可清楚明了。所引經典即是《寶手經》，另外《文殊師利問經》也說：死後將坐在大鐵床上受苦。自「若」字以下，規定不得比僧人晚起床。在斥責非法的文字中，首先第一段。所謂「入道之緣」，是因為善根由此而得以引發的緣故。「淨土之因」，是因為自心得以清淨無染的緣故。「出離之軼」，是因為誓願期求究竟解脫的緣故。「軼」就是車轍，指車輛所依循行駛的軌道。下一小科，首先敘述無知之人。所謂「僅」，在此當作「略微」之意。所謂「不體法意」，是總體迷失了上述的三種意旨。「都無」以下兩句，正好與上面的殊勝因緣完全相違；

【613-0009】01_行事鈔/11c_卷下之三#22
【原文】清信女人入寺，儀式同前。唯不得在男子上坐，形相語笑；脂粉塗面，畫眉假飾；非法調戲，共相排盪，持手𢴤人。必須攝心整容，隨人教令；依次持香，一心供養。懺悔自責，生女人中，常成礙絕；於此妙法，修奉無因；不得自專，由他而辦，一何苦哉！應深生鄙悼。若見沙彌，禮如大僧，勿以位小而不加敬。
【譯文】在家清信女（優婆夷）進入寺院，儀規禮節與前面大體相同。唯獨不可坐在男眾之上席，不可眉來眼去、談笑風生；不可塗脂抹粉、描眉畫眼弄虛作假地裝扮修飾；不可有非法的輕浮調戲，互相推搡放縱，乃至動手拉扯抓搯他人。必須端肅收斂心神、整肅容儀，服從知事師僧的教導指示；依照次序持香，專心一志恭敬供養。應當深自懺悔責備自己，感歎自己不幸投生在女身之中，障礙深重；對於如此殊勝微妙的正法，平日修持奉行缺乏自主因緣；凡事不得隨己專斷，事事受制於他人驅遣，這是何等痛苦悲哀啊！應當對此女身深生厭離鄙薄哀悼。如果在寺中見到年幼的沙彌，行禮也要如同對待大僧比丘一般，切莫因為沙彌戒臘地位較小就輕慢不加以敬重。〔註：「𢴤」，音掏或搯，指以手牽扯、拉扯或搯捏。〕

【613-0010】資持記/15e_下三#39
【原文】供養福田，反上出離軼也。注中，非全無者，不掩有信故。多下，出非法三節，初敘無智造業，前斥聚會。今世多然。又下，斥侵毀。圖剝，謂謀害。低突，即觸犯。恣頑癡者，即不畏因果。或下，斥規奪。具下，總示因果。二明有智獲益。三引經合證。經文雙喻，下云衰利，即合田園。蒺䔧有刺，如菱而小。
【譯文】前去供養福田，反倒違背了上述出離的清淨車軌。註文中說「非全無」者，是不願抹煞淹沒那些仍然帶有一念信心之人。自「多」字以下，列舉出非法行徑的三個段落：首先敘述毫無智慧者在此造作惡業，前半部分斥責聚會喧鬧的惡態。這在當今世間最為普遍常見。自「又」字以下，斥責侵犯損毀寺產的惡行。所謂「圖剝」，是指謀圖盤剝陷害。「低突」，即是橫加衝撞觸犯。所謂「恣頑癡」者，就是指完全不畏懼因果報應。自「或」字以下，斥責圖謀搶奪寺產。自「具」字以下，總括開示必定會召感的因果報應。第二段說明有智者能因此獲得無上法益。第三段引證佛經文句來合勘印證。經文中作了雙重比喻，下文所說的衰損與利益，正好合乎田園獲利的比喻。蒺藜是一種帶有硬刺的植物，形狀像菱角卻比較微小。

【613-0011】資持記/15e_下三#40
【原文】前境，謂僧寺。女人法中，初指同。唯下，彰異，又二，初指過。假，謂虛假。排，謂推排，即牽推等；盪，謂縱放。𢴤，觸也。必下，示法。礙絕，謂繫屬於人，不自在故。鄙，謂厭惡；悼，即悔恨。敬沙彌者，恐謂未具，不加敬故。注顯可知。出寺法中，初結前。所下，正示，初教禮辭。凡下，令捨施。
【譯文】所謂「前境」，是指僧人居住的寺院。在女人入寺的法則中，首先指明與一般人相同之處。自「唯」字以下，彰顯其不同與特殊之處，這又分為兩部分：首先指出可能招致的過失。所謂「假」，是指裝模作樣的虛假造作。「排」，是指推推擠擠，也就是拉扯牽推等動作；「盪」，是指舉止輕佻縱放。「𢴤」，就是用手觸摸。「必」字以下，開示相應的法度。所謂「礙絕」，是指身心繫屬於夫家他人，無法真正隨心自在修行。所謂「鄙」，是指內心厭惡賤視；「悼」，就是心懷悔恨恐懼。特別告誡要恭敬沙彌的原因，是擔心世人以為沙彌戒品尚未具足，因而起慢心不加以敬重。註文的意思十分顯明，容易理解。出寺法中，首先總結前文。自「所」字以下，正式開示，首先教導離去前應當禮拜辭別。自「凡」字以下，教令行布施捨捨之行。

【原文】如此等，在寺中，竭力而行。所為事訖，辭出寺門，如法作禮。凡以穢俗之身，入寺踐金剛淨剎法地，自多乖於儀式；若去時，須自贖其過，隨施多少，示有不空。
【譯文】像上述這些清規法則，在寺院之中時，務必竭盡心力嚴格奉行。所辦理的事務結束之後，辭別步出寺門時，應當如法躬身作禮。凡是以凡夫染污垢濁的世俗之軀，踏入寺院踐踏這如同金剛般堅固清淨的梵剎法地，言行舉止自知難免多有違背儀軌之處；因此在離開之時，必須自行贖除其過咎，隨己所能隨意布施若干錢物，以表明自己入寶山不空手而歸、兼以布施贖除微過。

【613-0014】04_比丘尼鈔/05a_卷下之上#19

【613-0015】04_比丘尼鈔/05a_卷下之上#20
【原文】大姉僧聽。僧今解某處淨地。誰諸大姉忍。僧解某處淨地者默然。誰不忍者說。僧已忍解某處淨地竟。僧忍默然故。是事如是持。
【譯文】「大姊僧眾請聽，僧團如今解除某處淨地。哪位大姊同意僧團解除某處淨地者請默然，誰不同意者請說出。僧團已同意解除某處淨地完畢。正因為大姊們默然同意，此事便如此奉持。」
