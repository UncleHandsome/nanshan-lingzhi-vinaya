# 校閱材料　第593檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【593-0001】02_戒疏/10c_卷三上之一#120
【原文】【記】三中，二。初釋犯。髮過半月不剃，瓜過一麥不剪，竝吉。彼謂繫屬人身，生長不息，即同有命，剪除成損，不剪無害。「言」下，次釋不犯。意地心念，小機不制，彼不知機，例說為犯。下引《了論》，與上小異。彼名「罪」、「非罪」。「過」佛制是罪，彼說非罪；「順」佛制非罪，彼反說罪。「過」字彼正作「違」。
【譯文】【記文】在第三對之中，分為兩層。首先解釋「犯」。頭髮超過半個月不剃、指甲超過一麥長度不剪，在律制上都是突吉羅輕罪。提婆達多卻認為毛髮附著在人體上且不斷生長，就如同具有生命一樣，剪除就是殘害殺生，不剪除才不傷生。「言」字以下，接著解釋「不犯」。意業起心動念之過，對小乘根器的修行者而言律制不加治罪，提婆達多不知因機施教的深意，一律硬說是犯戒。下文引用《了論》，說法與上述略有小異。該論稱為「有罪」與「非罪」。「逾越」佛陀戒制屬於有罪，提婆達多卻說無罪；「順應」佛陀戒制本屬非罪，他反而宣稱是有罪。「過」字在該論原本中正是作「違背」的意思。

【593-0002】02_戒疏/10c_卷三上之一#121
【原文】【疏】言「輕重」者，《多》云：「犯遮惡者為輕。調見壞葉墮龍，便謂一切草木皆重。重者，初篇，業思一形永障為重。調見先作無犯，便言婬、盜俱是輕也。」
【譯文】【疏文】說到「情節輕與情節重」這一對。《多論》說：「凡是違犯佛陀因事制宜所遮止的惡行，稱為輕罪。提婆達多看見迦葉佛時有比丘只因折損了伊羅樹葉就墮落為龍身，便妄下斷語說損壞一切草木皆是極重之罪。所謂重罪，是指初篇波羅夷戒，一經造作其思業便終身徹底障礙聖道，所以極重。提婆達多看見初篇四重戒都開許最初造犯者免罪，便妄說行淫與偷盜全都只是無關痛癢的輕罪。」

【593-0003】02_戒疏/10c_卷三上之一#122
【原文】【記】四中，初科。初明輕說重。彼「見壞葉墮龍」者，即伊鉢羅龍曾斷伊羅葉，今受龍報故。次釋重說輕。彼謂四重，並開最初故。
【譯文】【記文】在第四對之中，此為第一小段。首先說明他把輕罪說成重罪。所謂「看見迦葉佛時損毀樹葉墮為龍身」，是指伊鉢羅龍王過去生曾折斷伊羅樹葉，今生因而承受龍身畜生果報的事蹟。接著解釋他把重罪說成輕罪。提婆達多是藉口佛陀在初制定四條波羅夷罪時，都開許最初破戒的第一個人免於受重罰，因而藉題發揮宣稱根本大戒都是輕罪。

【593-0004】02_戒疏/10c_卷三上之一#123
【原文】【疏】《了論》云：「輕重兩相，各有二緣。由於罪、制，各有四句。一、由罪重，不由制重。如殺畜生，性罪故重；不在前二，故非制重。二、由制重，不由罪重。如殺草木，非後二篇，名制重；體遮故罪輕。三、由罪重，亦由制重。如初四夷，是性罪故罪重；即初篇中，制亦重故。四、不由制重，不由罪重。如眾學戒，是遮非罪重；末篇非制重。」輕有四句，比前反取可知。
【譯文】【疏文】《了論》說：「輕與重這兩種罪相，各自具有兩種成因。由於罪業本質的重輕、以及如來制戒的重輕，互相交織各自形成四種情況。第一、由於罪業本質深重，而不是由於佛陀制戒嚴厲。比如殺害畜生，因為屬於性罪惡業所以極重；但因為不屬於前二篇的大罪，所以制戒上不屬於重戒。第二、由於佛陀制戒嚴厲，而不是由於罪業本質深重。比如殺害草木，不在後二篇（提舍尼、突吉羅）之列，所以稱為制戒嚴厲；但因為本質屬於遮戒，所以罪業性質較輕。第三、既由於罪業本質深重，也由於佛陀制戒嚴厲。比如初篇的四波羅夷罪，本質即是極大性罪所以罪重；而且正是列在初篇之中，戒律處分也最嚴厲。第四、既不是由於佛陀制戒嚴厲，也不是由於罪業本質深重。比如眾學戒，純屬遮戒所以罪質不重；列在末篇之中所以戒律處分也不深重。」談到輕罪也有四種情況，比照前文反推即可明白。

【593-0005】02_戒疏/10c_卷三上之一#124
【原文】【記】次科。《了論》，即約業、制，相對互織為句。初出重句。「輕」下，例出輕句。應云：一、由罪輕，不由制輕；二、由制輕，不由罪輕；三、由罪輕，亦由制輕；四、不由制輕，不由罪輕。還約上戒，反對配之。此明佛制輕重之相，彼於諸句一一反說耳。
【譯文】【記文】第二小段。《了論》正是將業道性罪與教制遮罪兩方面，相對交織組合為四種句型。首先列出「重」的四句。「輕」字以下，按例類推「輕」的四句。應當是：第一、由罪業輕，非制戒輕；第二、由制戒輕，非罪業輕；第三、由罪業輕，亦由制戒輕；第四、非制戒輕，亦非罪業輕。依然依照上述戒條，反向配對即可。這本是說明佛陀制戒中輕重的真實行相，提婆達多卻對這每一條四句都反其道而胡亂曲解。

【593-0006】02_戒疏/10c_卷三上之一#125
【原文】【疏】「有殘、無殘」者，《多》云：「犯下四篇，非一生障，名曰『有殘』，調說『無殘』。若犯初篇，永喪道芽，則名『無殘』，調說『有殘』。」
【譯文】【疏文】「有殘罪與無殘罪」這一對。《多論》說：「凡是違犯僧殘以下後四篇的戒條，不會造成這一生永遠障礙證道，所以稱為『有殘』，提婆達多卻硬說這是『無殘』。如果違犯了初篇波羅夷戒，永遠喪失了成道的法芽善根，這才稱為『無殘』，提婆達多卻硬說這是『有殘』。」

【593-0007】02_戒疏/10c_卷三上之一#126
【原文】【記】五中，初科。《多論》，可解。但明相反，不出其意。
【譯文】【記文】在第五對之中，此為第一小段。《多論》的文字淺顯易懂。但論中只陳述了提婆達多顛倒黑白，並未進一步分析其中的深層意涵。

【593-0008】02_戒疏/10c_卷三上之一#127
【原文】【疏】《了論》解云：「正量、上座二部所釋，同上多部。」云七聚之戒，從下第七，上至第一。若犯第七名無殘，上六不犯名有殘。乃至第二篇犯者，下之六聚名無殘，雖未並犯，即兼破義，上之一聚名有殘。若犯第一，隨一戒，一切諸戒並無殘。
【譯文】【疏文】《了論》解釋說：「正量部與上座部這兩個部派的解釋，與上述的薩婆多部相同。」論中說，將戒律分為七聚，從最下等的第七聚，層層向上推算到第一聚。如果觸犯了第七聚稱為無殘，上面的六聚未犯稱為有殘。乃至違犯了第二篇僧殘戒的人，下面六聚全都稱為無殘，雖然並非全部都去違犯，但犯了僧殘就已兼具了破壞下位戒品之意，唯獨最上的一聚稱為有殘。若是違犯了第一聚波羅夷罪，只要觸犯了其中隨便一條戒，所有的整套戒律便徹底喪失，全部都落入無殘了。

【593-0009】02_戒疏/10c_卷三上之一#128
【原文】【記】《了論》中。初指三部義同。「云」下，復加細釋。前對五篇，此約七聚。「乃至」者，合云若犯第六，下二聚名無殘，上五名有殘。第五、第四、第三，並以下為無殘，上名有殘。上必兼下，下不通上。此明犯下六聚，通得有殘；若犯初聚，一向無殘。彼並反說，如上已明。
【譯文】【記文】《了論》的段落中。首先指出三個部派的法義完全相同。「云」字以下，又作了更細緻的闡述。前文是針對「五篇」來劃分，此處則是依照「七聚」來論述。「乃至」這段文意，完整說來應該是：如果觸犯了第六聚，下面兩聚稱為無殘，上面五聚稱為有殘。違犯第五聚、第四聚、第三聚時，全都是以下位各聚稱為無殘，上位各聚稱為有殘。破了上位必定涵蓋連帶破除下位，破了下位則不會波及上位。這說明了違犯下面六聚戒律時，都還通稱為有殘存修補的生機；如果觸犯了初聚波羅夷戒，就一律屬於無可挽回的無殘重罪。提婆達多全都不顧事實反向胡說，如同前文已說明的一樣。

【593-0010】02_戒疏/10c_卷三上之一#129
【原文】【疏】問：「犯一重戒，止於餘聚種類可破。自餘三重，不可兼犯。云何一切名無殘邪？」
【譯文】【疏文】問：「違犯了一條根本重戒，只會破壞其餘各篇聚中同種類的戒品。至於剩下的其餘三條根本重戒，不可能連帶一併違犯。怎麼能說一切戒條全都變成了『無殘』呢？」

【593-0011】02_戒疏/10c_卷三上之一#130
【原文】【疏】答：「如人四處，不可損傷。傷一即死，不待餘處。重戒例之。」
【譯文】【疏文】回答：「正如人體有四個致命要害，絕不可受創傷。只要傷及其中一處立刻就會喪命，根本不需要再傷及其他部位。四條根本重戒的道理也是如此。」
