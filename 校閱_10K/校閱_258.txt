# 校閱材料　第258檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【258-0001】01_行事鈔/11c_卷下之三#15
【原文】三明八戒法。《薩婆多》等云：若從五眾受。必無人者，但心念口言，自歸三寶，我持八戒，亦得。次受法者，《智論》云：受一日戒法，長跪合掌，應作是言：「我某甲，今一日一夜，歸依佛，歸依法，歸依僧，為淨行優婆塞。」「某甲歸依佛竟，乃至僧竟，一日一夜為淨行優婆塞竟。」次為懺悔：「我某甲，若身業、口業、意業不善，貪瞋癡故。若今世、先世，有如是罪，今日誠心懺悔。三業清淨，受行八齋，是則布薩。」次為說相：「一如諸佛盡壽不殺生，我某甲一日一夜不殺生亦如是；如諸佛盡壽不盜，我某甲一日一夜不盜亦如是；如諸佛盡壽不婬，我某甲一日一夜不婬亦如是；如諸佛盡壽不妄語，我某甲一日一夜不妄語亦如是；不飲酒、不坐高大床上、不著華鬘瓔珞及香塗身熏衣、不自歌舞作樂及故往觀聽，亦如是。已受八戒，如諸佛盡壽不過中食，我某甲一日一夜不過中食亦如是。我某甲，受行八戒，隨學諸佛法，名為布薩。願持是布薩福報，願生生不墮三惡道、八難；我亦不求轉輪聖王、梵釋天王世界之樂；願諸煩惱盡，逮得薩云若，成就佛道。」《增一阿含》：八關齋法，廣發大願。一如三十八卷，具如《鈔》、《疏》。《僧祇》：佛告比丘，今是齋日，喚優婆塞，淨洗浴，著淨衣，受布薩法。《十誦》：聚落上座，見俗人來，為說深法，示邪正道；應說知見，教布施、持戒、忍辱、行善、受持八戒。《增一》：若受八齋，先懺悔罪，後便受戒。廣如十六卷中。《中含》：多聞聖弟子持八支齋時，憶念如來十號名字，若有惡思不善，皆滅。廣如《齋經》中。《善生》云：受八戒者，除五逆罪，餘一切罪皆滅。《成實》云：功德與無漏人等。亦得隨受一二三，及日月長短，並成。《俱舍》云：莊嚴者，除非舊莊嚴，不生極醉亂心。《善生》：受八戒，不得多，唯獨受。《五分》：比丘成就八法，毀三寶及戒，欲不利諸五戒，五戒人應不敬信。若優婆塞瞋，比丘不往其家，聚落亦爾。《雜含》云：何名優婆塞？在家清白，修習淨住，男相成就，口說三歸是也。
【譯文】第三、說明八戒之法。《薩婆多論》等記載說：如果求受，應當從出家五眾處求受。如果確實無人可從受，只要心念口言，自己歸依三寶並發誓說「我持守八戒」，也能得戒。其次是受戒的儀軌作法，《大智度論》說：受持一日戒法，受者長跪合掌，應當這樣說：「我某甲，今日一日一夜，歸依佛，歸依法，歸依僧，為淨行優婆塞。」（三說）「某甲歸依佛竟，乃至歸依僧竟，一日一夜為淨行優婆塞竟。」（三說）次為懺悔：「我某甲，若身業、口業、意業不善，貪瞋癡故。若今世、先世，有如是罪，今日誠心懺悔。三業清淨，受行八齋，是則布薩。」次為說相：「第一，正如諸佛終身不殺生，我某甲一日一夜不殺生也是如此；正如諸佛終身不偷盜，我某甲一日一夜不偷盜也是如此；正如諸佛終身不婬（斷絕一切淫行），我某甲一日一夜不婬也是如此；正如諸佛終身不妄語，我某甲一日一夜不妄語也是如此；不飲酒、不坐臥高廣大床上、不著花鬘瓔珞及香塗身熏衣、不自歌舞作樂及故往觀看聆聽，也是如此。已經受持八戒，正如諸佛終身不過中食（日中一食，過午不食），我某甲一日一夜不過中食也是如此。我某甲，受行八戒，隨順修學諸佛之法，名為布薩。願持守此布薩的福報，祈願生生世世不墮入三惡道與八難；我也不希求轉輪聖王、大梵天王、釋提桓因天王世界之樂；願諸煩惱盡，逮得薩云若（一切種智，即佛智），成就佛道。」《增一阿含經》中記載：受持八關齋法，應當廣泛發廣大誓願。詳如經中第三十八卷所說，備載於有關的《行事鈔》與《戒疏》之中。《摩訶僧祇律》說：佛陀告訴比丘，今日是齋日，召喚優婆塞前來，洗沐乾淨，換上潔淨衣服，受持布薩之法。《十誦律》說：村落寺院的上座，見到在家人前來，應當為他們宣說深法，指明邪正道路；應當宣講正知見，教導他們布施、持戒、忍辱、修行眾善、受持八戒。《增一阿含經》說：若受八齋，必須先發露懺悔罪障，然後才接受戒律。詳如第十六卷中所載。《中阿含經》說：多聞聖弟子持守八支齋時，憶念如來十號名字，若有惡念不善之心，皆得以悉數滅除。詳如《齋經》中所載。《優婆塞戒經》說：受持八戒的人，除五逆重罪之外，其餘一切罪業都能消滅。《成實論》說：持八戒的功德，與證得無漏聖果之人相等。也可以隨意只受其中一條、二條、三條戒，以及隨意限定持戒天數的長短，都能成就得戒。《俱舍論》說：所謂不得飾身莊嚴，若是原有的舊裝飾則除外，因為不會生起極度沈醉狂亂之心。《優婆塞戒經》說：受八戒時，不可多人同時共受，只能單獨一人求受。《五分律》說：比丘若具足八種惡法，毀謗三寶及戒律，圖謀不利於諸持五戒者，五戒在家信眾便不應恭敬信奉他。如果有優婆塞生起瞋恚，比丘不可前往他家，對於聚落也是如此。《雜阿含經》說：怎樣才稱作優婆塞？身處在家而心行清白，修習清淨梵行，男子之相成就，親口宣說三歸依者，就是優婆塞。
