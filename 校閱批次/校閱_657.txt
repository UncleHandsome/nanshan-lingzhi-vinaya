# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【譯文】問：衣服本來違背前一家而取後一家的不犯戒，難道飲食違背前一家而取後一家的也應當不犯嗎？答：飲食的實體在受用後會毀壞，因而會惱亂施主，所以犯戒；衣服的實體始終長久存在，不會惱亂施主，所以不犯戒。就像違背九十日安居的請託只得突吉羅罪，因為那是未煮熟的生食，實體尚未毀壞；違背一日的請託罪過很重，因為那是熟食，實體會毀壞廢棄。問：依照《摩訶僧祇律》，生起心念而捨請必須說三次，不像本部律只要切實捨棄即可；不知道在六念法當中，為什麼第二念要說三次，其餘念只要說一次？答：第二念一是防範不作心念的突吉羅罪，二是防範背請食的單墮罪；因為要防範這二種罪，所以必須說三次；其餘各念缺少後面的防罪意涵，所以都只說一次。問：第四念為什麼不在作念之後防範不說淨的單墮罪？答：衣服本來個別有所屬，不能當場立刻作說淨，所以無法防範；而飲食之味通於眾人，所以能夠藉著作念來防範。問：如果是這樣，別眾食也是食味通於大眾，作念完畢之後應當也能防範別眾食的單墮罪？答：食味雖然通於大眾，但如果聽任各自分別去吃，會引發破僧的念頭，所以不予開許。另一種解釋：前面的捨請，其意涵通達，食味也是相通的，所以作念應當予以捨除；而別眾食，心念本來就打算分別私用，往後更是分別去吃，不順應食味通同的大眾之義，所以不能防範。這當中《四分律》說：如果一天接受十家邀請，在第二家如果吃了，就犯一個單墮罪與八個突吉羅罪；因為第一家是前請，其餘九家都是後面的邀請；如果背棄了九家，就得到九個突吉羅罪，因為沒有捨請；如果捨請了就沒有罪過。《伽論》說：如果接受了前一家的邀請，前往到了座位上，還沒有吃前一家的食物，又有別家送食物來；如果吃了後一家的食物，就犯背請罪；如果先吃完前一家的食物之後，當場在座位上再吃後一家的食物，則不犯戒。《四分律》說：或者吃飽之後又得到食物，接受了前一家的食物之後，又接受其餘一家的食物，這只會犯足食戒，而不犯背請戒。或者同一個地方有前食與後食，是指同一位施主前後兩次陳設五種正食；食物雖然分為兩次，但因為主人是同一個，所以也沒有背請之罪，只會構成犯足食戒。《律二十二明了論》說：在鄰家邊接受邀請不能算作具足受食。註疏解釋說：有施主邀請比丘去吃中飯，比丘隨即前往赴約，途中從另一位施主家門邊走過；這家的施主看見比丘，請求道：「請大德暫時停留，路途遙遠，請為我吃一點少許食物。」隨即陳設五種正食（蒲闍尼），比丘吃了一點點便離開；後來到了原本預定那家吃飯，沒有罪過，因為這並非事先預先約定的邀請。該論又說：教化作得食。解釋說：比丘進入施主家教化募得正食，沒有吃飽，進一步到另一家又募得正食，這也沒有罪過，因為不是預先約定的邀請。該論又說：常食。解釋說：在施主家吃完正食之後，回到自己原本的住處吃常住僧食，沒有罪過；如果已經接受他人邀請，在中午之前先在自己本住處吃了正食，然後又前往施主家去吃，則得單墮罪。該論又說：憐愍食，這種食物不障礙按順序傳遞受食。解釋說：如果接受了三家的邀請，依照前面的約定順序輾轉去吃兩家的正食，沒有罪過；如果逆著順序去吃，則得單墮罪。吃第三家的食物時，不得罪；吃第二家的食物，吞下一口就得單墮罪；如果為了衣食具足，或是因為疾病的緣故逆向受食，則不犯戒。該論又說：有因緣受四月請。解釋說：比丘接受邀請最多能達四個月，超過就得突吉羅罪；如果是長久邀請的常請，決定權屬於施主；一年三季當中聽許接受一季。如果接受了四個月的常請，中午之前在別處吃了正食，中午之前又回到這受請之處再次吃正食，沒有罪過，因為這是常食之處的緣故；詳細如另一章中所說。問：別眾食戒中所說的「施主」，是通於出家人與在家人，還是單指在家人？答：《薩婆多論》說：不論是出家人還是在家人，都能成為施主，都具有別眾食的過失。另一種解釋：必須是在家人作為施主，才構成別眾食。為什麼呢？因為在家人囤積貯蓄食用器具，有時會有分別單獨的邀請；出家人則不應如此，所以律中說「為了愍念白衣居士家的緣故」。又《善見論》說：沙門食不犯戒的情況，是指同法沙門以及外道沙門。首位律師解釋說：四方僧食沒有別眾食的罪，所以必須說有施主，就是為了簡別僧團常住食。兩種解釋既然都成立，應當以急切切要者為好。所以說沙門施食者，是指在這沙門釋子佛法之外出家的人，由此可知佛教內部的沙門也是結犯的對象；而經律中說憐愍白衣，也可以說是順應多數情況，或是順著當初制戒的起因而說。雖然如此，必須是持戒之人前來，不給他吃才犯戒；對於破戒之人則不犯。如安居條文中說：善比丘前來應當給食，惡比丘前來不應給食。

【譯文】問：如果有施主指名邀請坐禪等大師，然而依照僧次輪到卻無法前往時，該如何？答：有一種解釋認為，坐禪、誦經、以及協助大眾事務的人，施主指名也應當去吃，唯獨除開惡戒之人，如《五分律》中所說。另一種解釋認為，禪師等是個別邀請，不是僧次的邀請，法師、律師也是如此。

【657-0003】05_拾毗尼義鈔/04a_卷中之二#32
【原文】問要一處四人食方犯別提耶答不爾故善見云一時受食已各分二處食犯何故為一時受食故別乞亦爾故彼云各去一時受各一處食及別乞別去一時受食皆犯問何故得僧次者不犯答即是雜眾異人不敢異計故亦可既遍四方僧皆蒙請故無別眾首解雖是別請若非正食無一日充身長道之義本自無罪故婆論云四人已上非正食故無罪昔解不淨食不合同味不犯別眾若爾非法羯磨亦不合同遵應不犯別眾答非法詳集容可反非為如故制令犯食中不爾既是不淨設往不能迴令作淨往而無益是故不犯今解成別雖是不淨得同情異計還成背別非時不受足食勸足以不相假異計故亦犯問若爾何故販賣衣不淨藥不犯長耶答彼有過故不合說淨而不淨食得犯別者以罪不擇境淨法簡境故。
【譯文】問：必須是在同一個地方四人共食，才犯別眾單提耶？答：不是這樣的。所以《善見論》說：同一個時間接受食物之後，各自拆分在兩個地方吃，依然犯戒。為什麼呢？因為是在同一個時間接受食物的緣故。分開乞食也是如此，所以該論說：各自前去但同時受請、在同一處吃，以及各自乞食、各自離去但同時受食，全部都犯戒。問：為什麼得到僧次輪請的人就不犯戒？答：因為是摻雜在大眾中的不同僧人，施主不敢有分別私心的計度；也可以說既然遍及四方僧伽都蒙受邀請，所以沒有別眾的過失。首位律師解釋：雖然是個別邀請，但如果不是正食，就沒有在一日內充飽色身、增長道業的意義，本來就沒有罪過；所以《薩婆多論》說：四人以上如果不是吃正食，就沒有罪過。過去的解釋認為：不清淨的食物，依法不能共同食用，所以不犯別眾食。如果是這樣，非法的羯磨法也不合乎共同遵從，理應也不犯別眾罪了？答：非法的羯磨如果大家和合集會，容許有轉非為是的可能，所以制定讓他們犯戒；飲食當中則不是這樣，既然是非法不淨食，縱使前去，也不能將它轉化為清淨食，去了毫無益處，所以不犯戒。現在的解釋認為：這構成分別受食，雖然是不淨食，但既然是同情異心、各自計度，依然構成違背大眾而私別；如同非時食、不受食、足食、勸足食，因為不依仗如法、各自計度，所以也都犯戒。問：如果是這樣，為什麼販賣而得的衣物、不清淨的藥品，不構成犯長物罪？答：因為那些物品本來就有過失，不合乎作說淨；而不淨食之所以犯別眾罪，是因為犯罪不挑揀外境，而說淨法必須挑選清淨的外境。

【657-0004】05_拾毗尼義鈔/04a_卷中之二#33
【原文】問按婆論云四人各乞於一處食無別眾罪何故律云家家乞食通己五人佛訶制戒答論就散乞一處食律據一家併乞共食是故無違問比丘有物一處共三人食竝犯提不答婆論云四人中一人有食於僧界內或行路中於俱盧舍界內一處與三人食三人犯提食主無犯善見云二俱不犯以比丘不成施主故二論既別不須通和問如僧盡集未食僧食或食檀越食有一施主別請四人在僧中次第竝坐受此食食犯提以不答不與僧同味咽咽犯提若四人先取僧中食一口已後得益者無犯婆論如此。
【譯文】問：依照《薩婆多論》說：四個人各自去乞食，在同一個地方吃，沒有別眾罪；為什麼律中說：一家一家乞食，連同自己共五人，佛陀呵責而制定戒條？答：論典是針對各自散開乞食而在同一處吃的情況，律文是依據在同一家合併乞求而共同食用，所以兩者並不相違背。問：比丘自己擁有食物，在同一個地方與三個人共食，全都犯單墮罪嗎？答：《薩婆多論》說：四個人當中有一人擁有食物，在僧團界內或行路途中，在一俱盧舍界內，同一個地方分給三人吃，吃食的三人犯單墮罪，食物的主人不犯。《善見論》說：兩邊全都不犯，因為比丘不能成為此處所定義的施主。二部論典既然說法不同，不需要強行會通。問：如果僧眾全部集會尚未吃僧食，或者正在吃檀越施食，有一位施主單獨邀請四個人，在僧眾當中依次並排坐著受用這食物，吃的人犯單墮罪嗎？答：因為沒有與僧眾同味共食，每一口嚥下都犯單墮罪；如果這四人先吃了僧眾中的食物一口之後，再接受這份食物添進來，則不犯戒。《薩婆多論》就是這樣說的。

【657-0005】05_拾毗尼義鈔/04a_卷中之二#34
【原文】問沙彌不成足數不成別者僧次請來不應免四比丘罪答別得破僧沙彌無破僧故不成別眾而同是福田故成僧次此中若對法食能別處要四人已上方犯以廣誦作法作僧事故法食無限多即轉好故若論所別亦有三一食有豐儉開不開別由人有多少如婆論云食難得處所別四人已上便開不犯以食無倍供故三人已下犯以容有兼濟故若食易得多少悉犯四分許村落既小食復難得彼此限局各不相容不問多少悉開不犯不爾皆犯其法食者所別之處若一乃至百千悉皆是犯理無限故二作法不作法別所別不作輕就作法中秉於眾法別三人已下對首作法但犯輕非正眾故若彼此成眾俱秉眾法相知俱重食即不爾三人已下不問正不正足不足無犯四人已上正足俱提不正足吉三損有輕重所別之處但使不秉於法假令秉法非正法不問多少能別得吉以法食遠資別不同味即惱情微故所以輕別眾食中食資身近別不同味即惱情重故別得提若作法者別三即吉人不得益別四得蘭僧不得益。
【譯文】問：沙彌不能算作足數的僧人，不能構成別眾，那麼依僧次邀請沙彌前來，就不應當能免除四位比丘的罪？答：別眾食會導致破僧，沙彌沒有參與破僧的資格，所以不能構成別眾；然而沙彌同樣是福田，所以能成就僧次請食。這當中如果相對於法食而言，能分別的處所必須要四人以上才犯戒，因為廣泛讀誦、作法、造作僧事，法食是無有界限的，人越多就越好；如果論及所分別的大眾，也有三種情況：第一、食物有豐盛與匱乏，開許與不開許別眾食，取決於人數的多寡。如同《薩婆多論》說：食物難以獲得的地方，所分別的僧眾在四人以上，就開許不犯，因為食物無法提供加倍的供養；三人以下則犯戒，因為容許兼濟周全。如果食物容易獲得，無論人數多寡全部都犯戒。《四分律》准許：村落既然很小，食物又難以得到，彼此條件受局限各不相容，不論人數多寡全部開許不犯；如果不是這種情況，全都犯戒。而法食，所分別的僧眾處所，如果從一人乃至百千萬人，全都是犯戒，因為法理是沒有限制的。第二、依作法與不作法來分別：所分別的僧眾不作法，結罪較輕；如果是在作法當中，秉行大眾法事，所分別者在三人以下，對首作法只犯輕罪，因為不是正式的大眾僧；如果彼此都構成大眾僧，全都秉行大眾法事，相互知曉，雙方都得重罪。飲食則不是這樣，三人以下不論正不正、足不足數，都不犯戒；四人以上，正眾足數都犯單墮罪，不正眾足數犯突吉羅罪。第三、損害有輕重：所分別的大眾處所，只要不秉行法事，假使秉行法事而非如法之法，不論人數多少，能分別的人都得突吉羅罪；因為法食是長遠資助慧命，私自分別未能同味，對大眾引發的惱亂之情較微薄，所以罪輕。別眾食當中，食物是切近資養色身，私自分別未能同味，引發的惱亂之情極重，所以私自吃便得單墮罪；如果是作法事的人，分別三人即得突吉羅罪，人不得法益，分別四人則得偷蘭遮罪，僧團得不到法益。

【657-0006】05_拾毗尼義鈔/04a_卷中之二#35
【原文】問法與食開緣何異答食中有僧次無與欲者食是事資食方成益故法是理資送心表和彼此獲益故無僧次而有與欲。
【譯文】問：法與食開許的因緣有何不同？答：飲食中有僧次的輪請，沒有「與欲」；因為飲食是事相上的資助，必須切實吃下去才成就利益。法是理體上的資助，傳送心念表達和合，彼此都能獲得利益，所以沒有僧次卻有「與欲」。
