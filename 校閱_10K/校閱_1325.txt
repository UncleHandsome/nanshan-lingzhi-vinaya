# 校閱材料　第1325檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1325-0001】資持記/15a_下三#61
【原文】《五分》受請犯吉，旦約乞食為言；餘之十一，例皆違犯。準《解脫道論》。糞掃衣，受居士施衣即失；但三衣，畜長衣即失；乞食，受請即失〔如上〕；不作餘食法，作則名失；一摶食，再食則失〔此二論無，準義明之。〕；蘭若，聚落住即失；塚間，餘勝處坐即失；樹下，屋舍住即失；
【譯文】《五分律》中接受應請犯突吉羅罪，暫且是就乞食這一條來說的；其餘十一項，照例全都是違犯。依照《解脫道論》：修糞掃衣，接受了居士布施的衣服就失去行法；修但三衣，蓄存了長衣就失去行法；修常乞食，接受了應請就失去行法（如同上面所說）；不作餘食法，若作了就稱為失去行法；一摶食，再吃第二餐就失去行法（這兩條論書中沒有，是依據法理闡明的）；修阿蘭若，住進聚落就失去行法；修塚間住，坐在其餘殊勝處就失去行法；修樹下坐，住進房屋舍宅就失去行法；

【1325-0002】資持記/15a_下三#62
【原文】露地，覆處即失；隨坐，貪樂處坐即失；常坐，寢臥即失；不捨而違，例皆犯吉。不能令捨者，應云：我從今日捨乞食等。則知此十二行，竝須作法受行；不能，須捨；不受，不成；不捨，違犯知之。22 釋僧像篇(下三)釋僧像篇題中，上二字即所敬境，下二字即能敬儀。
【譯文】修露地坐，到了有遮蔽的地方就失去行法；修隨處坐，坐在貪愛喜樂的地方就失去行法；修常坐不臥，躺下睡覺就失去行法；如果不捨棄誓願而有所違背，照例全都犯突吉羅罪。如果不能堅持而令其捨棄，應當說：「我從今天起捨棄乞食等法。」由此可知，這十二種頭陀行，全都要透過作法來受持修習；如果做不到，必須作法捨棄；沒有如法受持，就不能算成就；受持後不作法捨棄而違背，就會構成違犯，應當明白這一點。之二十二：解釋僧像致敬篇（下三）解釋僧像致敬篇。題目的文字中，前兩個字「僧像」就是所尊敬的境地，後兩個字「致敬」就是能尊敬的儀表威儀。

【1325-0003】資持記/15a_下三#63
【原文】僧即總於眾別，像即攝於經法，即下立敬儀中三科之文；則三寶勝境，通為所敬矣。〔古云：僧是能敬，像為所敬者，誤矣。〕取其語便，故僧在初；準下敬儀，佛在前列。致即訓至，《說文》云：送詣也，謂以至敬之心，投詣勝境故也。敘意中，初文，上二句，明弘通立法。謂比丘之眾，舉事有法，化被於時；
【譯文】「僧」總括了集體僧團與個別僧人，「像」涵蓋了畫像與經書法寶，這正是下文建立敬儀的三科文字；可見三寶的殊勝境地，通通都是敬奉的對象（古人說：僧是能尊敬的人，像是所尊敬的對象，這種說法是錯誤的）。為了行文順暢，所以「僧」排在開頭；若依照後文羅列的敬儀，則是「佛」排在最前面。「致」就是訓釋為「至」，《說文解字》說：是送達、抵達的意思，是指用極其恭敬的心，歸向投奔於殊勝境地。在敘述主旨（敘意）中，第一段文字的前面兩句，說明弘揚流通、建立儀軌的法則。這是說比丘僧眾，舉止作事合乎法則，教化普及於當時代；

【1325-0004】資持記/15a_下三#64
【原文】光世生善，發生物信；則彰佛法高深，人知歸嚮，故云景仰斯立也。謙下四句，明道俗所宗。謙恭遜恪，言其內心；斂敬攝儀，言其外貌。退己自卑，謂之謙遜；尊他專謹，謂之恭恪。儒宗有《禮記》，首云無不敬；是知敬者，禮之主也；又儒教不出五常，而禮統焉；
【譯文】光耀世間、催生善念，啟發眾生生起正信；從而彰顯佛法的深遠高超，使世人知道依止歸向，所以說「景仰斯立」（崇敬仰慕由此確立）。「謙」字以下四句，說明出家與世俗共同尊崇的準則。謙遜、恭敬、和遜、謹恪，說的是內在的心理；收斂敬肅、整飭儀表，說的是外在的相貌。退讓自我、謙卑自處，稱為「謙遜」；尊崇他人、專一嚴謹，稱為「恭恪」。儒家經典有《禮記》，開篇就說「毋不敬」（無處不敬）；由此可知恭敬，是禮的核心主旨；而且儒家教化不出仁義禮智信五常，而禮在其中統攝一切；

【1325-0005】資持記/15a_下三#65
【原文】故《論語》云：恭而無禮則勞；則知謙敬，俗典明示，故云命章。又下引佛制，敬佛法僧；師資相攝，上中下座，互相禮敬；則知遜恪，佛法推先，故云爰始；或可凡對勝境，或見尊上，必先致敬故云始也。豈下，明敬慢可不。上二句，示非所宜；下二句，明須立敬。形謂削髮，服即壞衣，倨慢謂傲物。
【譯文】所以《論語》說：「恭敬卻不知禮節就會勞頓疲憊」；便可知謙遜恭敬，世俗經典早已明確指出，所以說「命章」（開宗明義）。再者，事鈔下文引用佛陀的制約（又下引佛制），要恭敬佛、法、僧三寶；師徒之間相互攝受，上座、中座、下座之間，彼此相互禮拜致敬；便可知謙遜恪敬，佛法是推為最先的，所以說「爰始」（從此開始）；或者可以說，凡是面對殊勝境地，或者見到尊長前輩，必定要先表達敬意，所以說是「始」。在「豈」字以下，辨明敬奉與傲慢的應當與否。上面兩句，指出傲慢是極不合適的；下面兩句，說明必須建立致敬之禮。「形」是指剃除頭髮，「服」就是指壞色染衣，「倨慢」是指傲視他人與事物。


【1325-0006】資持記/15b_下三#1
【原文】方謂法度，即下所明；然出家異世，不但外儀，必由內法，故云清革。引證中。省已所短，則內懷慚愧；由有慚愧，則推重於他，則知慚愧是敬之本。倨慢自矜，無慚故也。是下，勸修。凡在吾門，宜遵佛語。三中，初敘禮壞。上二句通示。移謂遷變，淡謂浮薄。次六句別釋。
【譯文】「方」是指行為法度，這在下文會具體闡明；然而出家本就超脫世俗，絕不只是表面儀態有別，必定要由內在心法來主導，所以才說是徹底整飭與革新。在引經證成的部分中，審視自己短處，內心就會生起慚愧；因為有了慚愧，便會推崇敬重他人，由此可知慚愧是恭敬的根本。傲慢自大、自以為了不起，正是因為沒有慚愧心的緣故。「是」字以下，是勸勉大家修持。凡是入我佛門者，都應當恪遵佛陀的教誨。第三段中，首先敘述禮法敗壞的現象。前兩句是通盤說明，「移」是指遷流變質，「淡」是指風氣浮薄。接下來六句則是分別解釋。

【1325-0007】資持記/15b_下三#2
【原文】鄙謂庸惡，末謂卑下；輒為領袖，故參眾首。眉謂尤眉，壽即高臘；反相欺壓，故在下行。武力，謂恃勢陵物之者。文華，謂世俗文筆之流。上四句，敘坐次乖道；下二句，明推舉同俗。彼時尚爾，況今衰末，不足怪矣。如下，結歎生起。提引者，即指當篇明誡者，乃彰垂訓。次科，分章中。
【譯文】「鄙」是指庸碌惡劣，「末」是指地位卑下；這類人往往擅自充當領袖，因而擠入大眾首位。「眉」是指尨眉（花白長眉的老人），「壽」是指戒臘深厚的前輩；反而遭到這輩人的欺凌壓迫，所以只能位居下座。所謂「武力」，是指依仗權勢欺凌外物的人；所謂「文華」，則是指鑽研世俗浮華筆墨的文士。上面四句，是敘述座位次序背離了道法；下面兩句，則是說明舉薦推崇的風氣全同世俗。當時的情形尚且如此，何況到了如今這衰頹末世，就更不足為奇了。「如」字以下，是結尾感嘆並引起後文。所謂「提引」，就是指在本篇中加以提點引導；所謂「明誡」，則是彰顯佛陀所垂示的訓誡。在下一個科判「分章」之中。

【1325-0008】資持記/15b_下三#3
【原文】指如題者，即本篇法附也。制意中，初科，《智論》，前示真境。以佛生身，是法身所依器故。如下，引緣證。佛升忉利天，為母說法；將從天下，眾皆迎接；須菩提在石室中，行空三昧；念言，佛常說云：若人以智慧眼，觀佛法身，為先見佛；念已，但坐室中；蓮華色尼，欲先見佛；
【譯文】指出「正如篇題所標明」的意思，就是指篇題中所包含的「本篇」（僧像致敬）與「法附」（造立像寺法附）這兩部分。在「制立意旨（制意）」中，第一段引用《大智度論》，首先開示真實的境地。這是因為佛的應化肉身，正是法身所依憑的器物。鈔文自「如」字以下，是引用事緣來作為證明：佛陀升到忉利天為母親說法，即將從天宮降回人間時，大眾都爭相前去迎接；此時須菩提正在石室中安住於空三昧，心裡思惟著：佛陀常說「如果有人能用智慧之眼觀察佛的法身，才算最先見到佛」；思惟完畢後，他就安坐在石室裡不動；這時蓮華色比丘尼想要搶先見佛；
