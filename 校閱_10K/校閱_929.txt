# 校閱材料　第929檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【929-0003】資持記/02b_上一下#28
【原文】二道俗反故；三乖道行故；四惡黨盛故；五善人弱故。此五滅法，竝因毀戒。云小得心者，心即是定，如五停四念也。此謂未證謂證，惑眾駭世。今時即佛，事亦同之。第二。《業疏》云：俗人無法，但專信奉，故得生天。出家有法，為世福田；
【譯文】第二種是因為出家與在家的身分顛倒混亂；第三種是因為違背清淨道行；第四種是因為作惡的黨羽勢力熾盛；第五種是因為修善之人勢單力薄。這五種使正法滅亡的非法事，全都是因為毀犯戒律所導致。經文說「稍得定心（小得心）」的「心」，就是指禪定，如同修習五停心觀與四念處。這是指修行者尚未證得境界卻自稱已經證得，藉此迷惑大眾、驚駭世人。現在那些妄稱即心是佛的狂徒，其情事也是完全相同。第二種非法事。《羯磨疏》說：俗人沒有受持出家法，但能專心信奉三寶，所以得以升天。出家人受持戒法，本應當作為世間福田；

【原文】乃至菩薩辟支羅漢精進修德等眾，魔比丘咸共憎嫉，擯出，不令得住。〔上竝《古記》所引，在文雖繁，甚資心行，故依錄之。況是今時目覩之事，知佛懸鑒，可自策勤。〕五怖畏者，佛告波離文也。前四妄攝眷屬過，後一懈怠過。初云不修身戒心慧者，此句貫下讀之；一往以分，戒屬身口，慧是心觀。

【929-0007】資持記/02b_上一下#32
【原文】或可心即是定，備舉三學。此明自行既闕，必無利他故。三相，文中自列。溉水亦是損地。竝須淨語。既迷戒相，直使作之，是為滅法。《四分》。五種滅法，即〈增一〉文。學者深思，彌須弘護。初慢學誤他，二居上作惡，三能教慳法，四所教愚鈍，五彼此鬪諍。倣謂相效。持法即經，摩夷即論。
【譯文】或者說「心」就是指禪定，此處完整列出了戒、定、慧三學。這是說明自己的修持既然殘缺不全，必定無法利益開導他人。至於三種相貌，經文中自然有列舉。澆灌植物之水若滲入土中也是損害地層。這些都必須使用符合戒律的清淨言語來指派。既然對戒相迷昧無知，直接支使他人動手勞作，這便成了消滅正法的因緣。《四分律》。五種滅法，出自〈增一阿含〉的經文。修學之人應當深切思維，更加必須宏揚護持戒律。第一是傲慢修學而誤導他人，第二是身居上位卻帶頭作惡，第三是傳授者吝惜法義，第四是受教者愚鈍難化，第五是彼此之間爭鬥諍執。所謂「倣」，是指相互效尤模仿。「持法」是指受持經藏，「摩夷」是指受持論藏。

【929-0008】資持記/02b_上一下#33
【原文】《十誦》中。佛制比丘，五夏已前，專精律部。若達持犯，辨比丘事，然後乃可學習經論。今越次而學，行既失序，入道無由；大聖呵責，終非徒爾。又彼律云：佛見諸比丘不學毘尼，遂讚歎毘尼，面前讚歎波離持律第一。後諸上座長老比丘，從波離學律也。
【譯文】《十誦律》中。佛陀制定比丘在受戒五夏（五年）以前，必須專心精研律部。如果通達了持戒與犯戒的界限，能清楚辨別處理比丘僧團的一切事務，然後才可以修學習讀經藏與論藏。現在的人顛倒越級修學，行持既然喪失了先後次序，進入聖道便毫無門徑；大聖佛陀的嚴厲呵責，絕非徒勞無益的空話。又該律記載：佛陀見到諸比丘不修學毘尼，遂讚歎毘尼法門，並當眾讚歎優波離尊者持律第一。後來諸位上座長老比丘，便紛紛跟隨優波離尊者修學戒律。
