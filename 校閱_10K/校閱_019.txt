# 校閱材料　第019檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【019-0001】01_行事鈔/02a_卷上之二#34
【原文】此外朱圓者，自然界相。若先在戒壇內集僧者。亦四面集之。圖中所列。據結大界時，自然集僧也。其北朱圓，院外僧去中央結界僧，相去六十三步。中僧去南圓界外僧亦爾。南北二僧相去百二十六步。各得成法。在內不成。乃至餘方並準此。若結作法已，隨相標遠近。且據聚落不可分別者為言。若可分別聚落，乃至道行水界，五相遠近，義類相別，並如前〈集僧〉中所述。
【譯文】圖中外圍紅圈，代表自然界相。如果預先在戒壇內召集僧眾，也是從四面圍繞召集。圖中所列出的位置，是依據結大界時自然界召集僧眾的規範。那北邊的紅圈，代表院外的僧人距離中央結界的僧人相距六十三步。中央僧人距離南邊紅圈界外的僧人也是如此。南北兩處僧人彼此相距一百二十六步。這樣兩處各能成就各自的法事；如果處在界限以內，則法事不成。乃至其他方位也都準照此例。如果已經作法結界完畢，則隨界標界相的遠近來論。這裡姑且是依據無法明確劃分區隔的聚落村莊而言的。如果是可以劃分區隔的聚落，乃至行路、水界等五種界相的遠近距離與義理類別劃分，皆如前面〈集僧篇〉中所述。

【019-0002】01_行事鈔/02a_卷上之二#35
【原文】此之界圖，謂自然界寬於作法，標外周圓取界。必有別界，亦隨斜曲也。
【譯文】這幅界圖，是指自然界的範圍比作法界寬闊，在界標之外周圓取定界限。若是另有別處界限，也是隨當地的斜折曲屈而定。

【019-0003】01_行事鈔/02a_卷上之二#36
【原文】其內朱方，是戒場也。中間周匝，號曰自然。東北二邊，即用小牆下上為自然界體。南西二邊，大界牆內，則無別相者，應釘杙豎標，繩連相著。當於戒場東南角，去大界牆尺八地旁小牆施一杙。又於西南角斜去大牆二尺許下一杙。又於西北角至小牆南旁小牆下一杙，正西令去大牆尺八許。釘三杙已，仍以繩連三標，則為自然界。南西二邊，若作二法竟，若二界各有法事，此中有人，不妨二處。其戒場外相，東北二邊之相，即以小牆內院為相。西南二畔，即用繩標內邊為相。
【譯文】圖中內部紅色方框，就是戒場。戒場與大界中間環繞的空隙，稱作自然界。在東北兩邊，就用內側矮牆的上下立面作為自然界體。在西南兩邊，大界圍牆之內若是沒有其他別致的界相，就應當打下木樁、立起標竿，並用繩子連綴相繫。應當在戒場的東南角，距離大界外牆一尺八寸處、靠著矮牆釘下一根木樁；又在西南角斜對大牆約二尺許之處釘下一根木樁；又在西北角走到矮牆南端、靠著矮牆釘下一根木樁，使其正西面距離大牆約一尺八寸許。釘妥這三根木樁後，再用繩子連綴這三個界標，這便構成了自然界的西南兩邊。如果兩處作法都已完成，兩界各自有羯磨法事時，即使這中間的自然界內有人，也不會妨礙到這兩處法事。戒場的外相，東北兩邊的界相，就以矮牆的內院側為相；西南兩側，就以繫繩界標的內側為相。

【019-0004】01_行事鈔/02a_卷上之二#37
【原文】其大界內相，東北二面，以小牆外院為相。南西二面，以大院牆內為相。若明外相，必在院外唱之。若在牆內唱者，至西南角戒場外自然界邊，則與內相俱合，則不分彼此之異。又不得入大院牆唱之，由不見其相故。
【譯文】大界的內相，東北兩面是以矮牆的外院側為界相；西南兩面，則以大院牆的內側為界相。如果要闡明外相，必須在院牆之外唱相。如果在牆內唱外相，等唱到西南角戒場外的自然界邊緣時，外相就會與內相重合，就無法分辨兩者彼此的差異了。又不可走入大院圍牆之內唱外相，這是因為在牆內便看不見界標外相的緣故。

【019-0005】01_行事鈔/02a_卷上之二#38
【原文】上且略寄一緣，以為相貌。作法之時，未必如圖。若不依此解生，餘處亦準不得。
【譯文】以上暫且借用一種具體因緣格局作為示範形貌。實際作法的時候，未必全然與圖畫相同。但如果不能藉由這個例子產生正解，遇到其他處所也同樣無法準例操作。

【019-0006】01_行事鈔/02a_卷上之二#39
【原文】今明結法，分三；初緣前後者。《五分》云：應先結戒場，後結大界。若先結大界者，當捨已，更前結之，然後唱相結大界。《毘尼母》、《善見》亦同此說。今猶有人先結大界者，此不讀聖教，唯信意言。問：先結大界者，戒場成不？答：《五分》所明，應捨已更結，故知成也。但不成後法，故須解之。《五百問》云：後結戒場者，於中受戒，恐無所獲。又云：不知同於未制。賴有此路，則通僥倖。今時結者，多有非法。或將五六人徑往戒場中，界內不集，總唱三相已，具加二種羯磨者。或有界內通唱三相已，隨界加法者。或於大界內遙結者。或先結戒場已，但唱大界外相，不唱內相，而加法者。此等諸濫，結並不成。故須當界各唱各結，方得成就。
【譯文】現在說明結界的方法，分為三點；第一是因緣的先後順序。《五分律》說：應當先結戒場，後結大界。如果先結了大界，應當解捨大界之後，先結戒場，然後唱相結大界。《毘尼母論》、《善見律毘婆沙》也持相同說法。如今還有人先結大界的，這是沒有研讀聖教律部、只憑個人主觀臆說。問：如果先結大界，戒場究竟成就不成？答：《五分律》所明，應當解捨之後重新結，由此可知戒場是結成了的，只是無法成就後續法事，所以必須將其解除。《五百問》說：先結大界而後結戒場者，在戒場中受戒，恐怕得不到戒體。又說：不知律法者，則視同尚未制戒之時。全靠這一條通融開許之路，才有一絲僥倖獲戒的可能。當今結界的人，多數存有非法之失：有的是帶五、六個人逕自前往戒場中，大界之內僧眾並不召集，統括唱出三重界相之後，連續作兩種羯磨結界的；有的則在大界之內總括唱出三重界相後，隨各處直接作羯磨加法的；有的是人在大界之內遠遠隔空結戒場的；有的則是先結了戒場已，但只唱大界外相、不唱內相就直接加法結界的。這諸多混亂的做法，結界全都不成。所以必須在各自的界域當處各別唱相、各別作法結界，方能圓滿成就。

【019-0007】01_行事鈔/02a_卷上之二#40
【原文】二明唱相。先於自然界內集僧已，一比丘具修威儀唱云：「大德僧聽！我比丘為僧唱四方小界場相。從此處東南角標內旁繩西下，至西南角標；從此旁繩內北下，至西北角標；即旁小牆內東下，至小牆東北內角；從此旁牆內南下，至東南角標。此是戒場外相一周訖。」三說已。羯磨者言：「何所作為？」答云：「結戒場羯磨。」「大德僧聽！此住處比丘稱四方小界相。若僧時到僧忍聽：僧今於此四方小界相內，結作戒場，白如是。」「大德僧聽！此住處比丘稱四方小界相，僧今於此四方小界相內結戒場。誰諸長老忍僧今於此四方小界相內結戒場者，默然；誰不忍者說。」「僧已忍，於此四方相內結戒場竟。僧忍，默故，是事如是持。」結已，餘僧且坐。應將四五人知法相者，入大界內，安坐定已。集界無人，方乃作法。
【譯文】第二、說明唱相，也就是宣唱界相。先在自然形成的界域內集合僧眾完畢，由一位比丘整肅威儀，高聲唱說：「大德僧請聽！我比丘為僧眾宣唱四方小界場的界相。從此處東南角的標記起，沿著繩子向西而下，到西南角的標記；再從這條繩子內側向北而下，到西北角的標記；接著沿著小牆內側向東而下，到小牆東北的內角；再從這道牆內側向南而下，到東南角的標記。這就是戒場外相繞行一周完畢。」唱說三遍之後，主持羯磨的人說：「現在作什麼？」回答說：「結戒場羯磨。」於是說：「大德僧請聽！此住處的比丘已宣唱四方小界的界相。如果僧眾時機成熟、能夠容忍聽許，僧眾現在就在這四方小界相之內結作戒場，先這樣告白。」「大德僧請聽！此住處的比丘已宣唱四方小界的界相，僧眾現在要在此四方小界相內結戒場。各位長老若同意僧眾現在於此四方小界相內結戒場的，請默然；不同意的請說。」「僧眾已經同意，在此四方界相之內結戒場完成。僧眾同意而默然，所以這件事就這樣定持。」結戒場完畢後，其餘僧眾暫且坐著。應當帶領四、五位通曉法相的人進入大界之內，安坐妥當之後，確認集僧的界內沒有其他人，才正式作法。

【019-0008】01_行事鈔/02a_卷上之二#41
【原文】次結大界法。先明唱相，有二不同：言別唱者，先唱內相三周已，次唱外相；三周後，總結合。二者總牒內外一遍相已，隨遍合之。
【譯文】其次是結大界之法。先說明唱相，有兩種不同做法：所謂「分別唱」，是先將內相唱完三遍後，接著唱外相三遍，三遍之後再總合宣唱結語（總結內外相）。第二種是將內外相唱詞總括提請一遍，隨每一遍即總結內外相。
