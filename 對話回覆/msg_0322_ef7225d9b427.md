## 卡在哪

**裁決的輸出格式變了**：11 份裁決回覆都沒有寫「修正後的譯文」這個標題，而是直接接譯文：

```
## 1. 結論
## 2. 分歧與裁決
## 3. 【疏文】問：結淨地時……
```

`col3()` 只認「修正後的譯文」四個字，找不到就把 11 份全判為異常檔跳過 → 審核 0 份 → 後面全空。

## 修法

`col3()` 加第二層備援：**找不到標題時，從「分歧與裁決」之後第一個 `【疏文】／【記文】／【鈔文】` 起取**。

實測 07 組（最極端，標題完全沒寫）：

```
取到 603 字，開頭「【疏文】問：結淨地時，不豎立四方的界相……」
```
