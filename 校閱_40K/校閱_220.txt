# 校閱材料　第220檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【220-0001】資持記/02a_上一下#12
【原文】二常不失潮限；三五大河皆投於海而失本名；四五大河及天雨盡歸於海，無有增減；五海水盡醎，同為一味；六不受死屍；七多出珍寶；八大形者所居。此中略舉，未必全同；如戒本序，但明二德；必欲強配，臨文自裁。勸持中，初科，明出家之人所務唯二：一須稟戒，二當學道。
【譯文】二是常不失落潮水的時限；三是五條大河注入大海後都失去原有名稱；四是五大河與天降之雨全部流入大海，大海卻無增無減；五是海水全都發鹹，共同為同一味道；六是不收容死屍；七是盛產奇珍異寶；八是體型龐大的巨獸所居之處。此處只是簡略列舉，未必與八法完全相同；如同戒本的序文，也僅闡明了其中兩種德相；若是硬要牽強附會地配對，研讀時可自行裁奪。在勸勉受持的文字中，第一科說明出家之人所經營的事務唯有兩件：第一必須稟受戒律，第二應當研學道法。

【220-0002】資持記/02a_上一下#13
【原文】初中，上句標人。凡謂非一。廁預者，對下沐心，即指身口。佛法深妙，有信得入，故曰玄門。克下，示所學。克猶必也。清禁即戒法。戒防七業，故不容非。二學道中。初句標人。正道清澄，洗沐塵垢，故喻如水。慕下，明所修。慕即志念。出要即指定慧。定靜慧明，不隨塵欲，故無染世。
【譯文】在第一點中，上一句標明所指之人，「凡」表示並非單一之人；「參預」相對於下文的「洗沐心性」，是指身口二業。佛法幽深玄妙，具有信心才能進入，所以稱作「玄門」。「克」字以下，說明所應修學的內容，「克」是必定之意，「清淨禁戒」即指戒法；戒律防禦身口七種惡業（七支業），所以容不得絲毫非理。第二在研學道法中，第一句標明所指之人；正道清澈澄清，能洗滌塵俗污垢，所以譬喻為水。「慕」字以下，說明所修的法門；「慕」是立志繫念，「出離要道」專制定力與智慧；定力寂靜而智慧清明，不隨塵勞欲染起伏，所以不染世間。

【220-0003】資持記/02a_上一下#14
【原文】上約三學，事理業惑，相對以明。乃知出家之士，義無偏學；專事昧道，未異凡流；樂道忘事，何由修證？上是對明三學。故下，合示兩利，初二句正示。德益時者，外用無非，住持生善，成利他也。超塵網者，寡欲絕累，成自利也。良下，推其所以。上二句顯利他之功，本由淨戒；
【譯文】以上是就戒定慧三學，結合事相、理性、業因與惑障相對照來說明。由此可知出家的志士，理應不可偏廢修學；若一味專注事相而昧於至理道法，便與一般俗流無異；若只耽樂至理而廢棄戒相律事，又憑藉什麼來修證？以上是對照說明三學。因此接下來綜合展示自利與利他的兩種好處，前兩句正是直接明示：德行能有益於時世，這是指外在作為合乎律則而無非違，能住持正法並生發善念，成就利他之功；超拔於塵世網絡之外，是指寡欲而斷絕掛礙，成就自利之德。「良」字以下，推究其中的原因：上面兩句顯示利他的功勳，根本源自於清淨戒律；

【220-0004】資持記/02a_上一下#15
【原文】下二句明自利之德，實因定慧。法即是戒，道即定慧。敘不學中，初科，上二句標人。澆末是時。淺識者，無所解故。庸見者，同塵俗故。雖下，示庸淺之相。先且分定；初二句，明學寡；次二句，明行薄。又次二句，明情疎；復次二句，明志塞。局下至體之，明言論鄙俗。名參者，無實德故。
【譯文】下面兩句說明自利的德相，實則起因於定力與智慧。「法」即是指戒律，「道」即是指定慧。在記述不肯修學的文字中，第一科的前兩句指明這類人：「末世澆漓」是指時代背景，「見識淺薄」是因為毫無正解，「見解庸俗」是因為同於世俗。從「雖」字開始，展現庸淺之人的具體相貌，先大致加以劃分：初兩句說明所學極少，接下兩句說明操行微薄，再下兩句說明情意疏頑，再下兩句說明心志閉塞。從「局」字往下到「體之」，說明這類人的言論鄙陋庸俗。「掛名參列」是因為缺乏真實德行；

【220-0005】資持記/02a_上一下#16
【原文】緇服即黑色衣。不依律者，違聖教故。疎野者，無所拘故。真要與下真趣，竝指前三學。封猶閉也。守株喻其愚也。〔《韓子》曰：宋人有耕者，見田中株，兔走觸之，折頸而死。因釋耕守株，冀復得兔。〕志即是心。絕通望者，無所見也。就言論中，初二句謂無稽實。局塞也。之猶於也。首即頭也。
【譯文】「緇服」是指僧人所穿的黑衣。「不依憑律制」是因為違背了聖人的教誨，「粗疏狂野」是因為身心不受拘束戒管。「真實要道」與下文的「真實行徑」，都指向前面的三學。「封」就是自我封閉，「守株」是用以比喻其愚昧（《韓非子》載：宋國有位農夫，見田中有樹樁，野兔奔跑撞上樹樁折頸而死，他便放下農具守在樹樁旁，希望再次拾獲野兔）。「志」就是心意，「斷絕圓通之望」是指毫無正見智慧。在言論的批評中，前兩句是指說話沒有根據實徵，「局」是閉塞，「之」作「於」字解，「首」就是頭（指心頭）；

【220-0006】資持記/02a_上一下#17
【原文】此句躡上生下。次四句明混同流俗。事即所說之事。研下，舉積學比況。闇託，謂不達前事，冥然為之。體即解也。彰過中四，初明濫教。所行違制，妄謂依律，故云濫委。法司即律宗。律實不然，愚者謂是，故為彼亂。即世學者說律訓人。自貿椹衣，言遵王制；夜粥晏齋，謂是隨方。
【譯文】這句承接上文而引出下文。接下來四句說明其混同世俗之流，「事」是指口中所說之事。「研」字以下，列舉長年積累學識的智者來做比況；「冥頑假託」是指對事情的原委一竅不通，盲目混亂地行事；「體」就是理解了達。在揭露過失的四個要點中，首先說明混淆教規：自身所行違背戒制，卻妄稱完全依循律典，所以說是混淆寄託；「法司」是指律宗法席；律法實質並非如此，愚人卻自以為是，因此造成教法紊亂。這就是世間一些學律者說律教人的通病：自己出資購買非法紫衣，卻藉口說是遵從朝廷王制；夜間食粥、過午晚食齋飯，妄稱是隨方風土；

【220-0007】資持記/02a_上一下#18
【原文】非時噉飯，妄言未必長惡；貪飲藥酒，便言有病療治；不學愚僧，傳為口實。誣聖亂法，豈復過是！來者有識，慎勿隨邪。肆下，次明專任。肆，恣也。順己情者，非制而制，曰縱。違我意者，是制便斷，名奪。事既非法，人有不從，即以威武抑而挫之。
【譯文】在非規定時間飲食，妄言說這未必會助長惡法；貪圖飲用藥酒，便謊稱是患病需要療治；不學無術的愚蠢僧人，竟輾轉以此作為擋箭牌。誣衊聖人、紊亂法制，哪裡還有比這更嚴重的！後世有智慧的學者，千萬要警惕不可隨逐邪說。從「肆」字以下，其次說明專橫任性；「肆」是放肆；順從自己私情的心意，不是佛制的卻擅自制定，這叫作「放縱」；違背自己心意的規章，明明是佛制卻擅自廢斷，這叫作「剝奪」。事情既然非法，大眾若有不服從的，便依仗威勢蠻橫壓制挫敗對方；

【220-0008】資持記/02a_上一下#19
【原文】所謂持戒比丘，反遭治擯，乃至羅漢亦被打罵，即其事也。暴謂兇惡，剋即侵害。尚非下，三舉況。俗節即世禮，禮以節人故也。孔子云：非禮勿視，非禮勿聽，非禮勿言，非禮勿動。《曲禮》曰：傲不可長，欲不可縱。是則儒典動必合禮，不容縱傲。
【譯文】這正是所謂持戒的比丘反而遭受懲治擯除，甚至連阿羅漢也會遭到打罵，指的就是這種行徑；「暴」是兇惡，「剋」就是侵害。「尚非」以下，第三舉世俗之禮來做比況：「世俗節度」是指人間禮法，因為禮法是用來節制人心的緣故。孔子說：「非禮勿視，非禮勿聽，非禮勿言，非禮勿動。」《曲禮》說：「傲慢不可助長，欲望不可放縱。」如此看來，儒家經典中一舉一動都必須合乎禮數，不容許放縱傲慢；
