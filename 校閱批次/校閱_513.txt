# 校閱材料　第513檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【513-0001】資持記/16c_下四#56
【原文】又女人多樂畜眾，由本習也；年年度人，不能教授，多有違犯，故制乞法，令眾量之；不乞，受具犯墮；受人依止，度餘二眾，並制乞法，不乞皆吉；比丘通吉者，制乞同尼，但除式又；違犯一等，而無差降。其下，指乞法，文見《隨機羯磨》、及《尼鈔》。若下，示制限。受戒標中，非法濫相，如下正受斥古，是也。
【譯文】再者，女性多半習慣好樂蓄養大批徒眾，這是源於過去世養育照顧的宿習；如果每年都隨意度人出家，自己又沒有足夠能力訓誨教導，往往會導致弟子多有違犯，因此佛陀制定必須向尼僧團求乞聽許度人的法度，由全體僧眾審核裁量；若不求乞就擅自為人授具足戒，傳戒師要犯波逸提單墮罪；若收受他人作為依止弟子，或是剃度沙彌尼、式叉摩那其餘二眾，也全都制定必須向尼僧團求乞聽許，未事先求乞者一律結突吉羅輕罪；比丘違犯一律結突吉羅罪，是因為制度上乞法與尼眾相同，只是除去了式叉摩那；違犯的罪責一律相同，並無差別等降。在「其」字以下，指明如何舉行求乞法會，相關文辭詳見於《隨機羯磨》以及《比丘尼鈔》。在「若」字以下，指出受戒次數與名額的嚴格限制。在受戒的標題之中，提及種種不如法且混淆濫用的現象，正如後文正式受戒章節中斥責古德錯誤見解所說的那樣。

【513-0002】資持記/16c_下四#57
【原文】本法中，初示前緣；八法者，一請師，二安置立處，三差威儀師，四出眾問難，五單白召入，六對眾乞戒，七戒師白和，八對眾問難。文中，但示一四兩種，律文，請詞云：願阿姨為我作和尚等，故此釋之；十三難中，若據尼女，號佛無信，本無破僧，然有伴助，亦須問之；
【譯文】在比丘尼根本法受戒儀式中，首先指明先前的預備緣由；所謂的「八種法規」，第一是延請親教師，第二是安置受戒者站立的適當位置，第三是派遣端正威儀師，第四是領其步出大眾詢問遮難，第五是宣唱單白將其召入法堂，第六是令其面對尼僧大眾如法乞求戒法，第七是戒師宣唱和合白文，第八是正式面對尼僧大眾再次詳審詢問遮難。在正文中，只列舉了第一項請師與第四項出眾問難這兩種程序，律藏原文中，迎請的詞句說：「懇願阿姨慈悲為我擔任傳戒和尚」等，所以在此特別對此做出解釋；在十三種重難之中，若依照比丘尼身為女性的特質，即便自號為佛也無人信從，本來沒有能力作為首領破法輪僧，然而考慮到有可能在旁參與協助策劃，因此受戒時也必須嚴格詢問；

【513-0003】資持記/16c_下四#58
【原文】十六遮，於父母聽下，更問夫主；先問有無，無則不須。乃下，次明正受。餘下，指略；《隨機羯磨》甚備，須者尋對。正受中，初緣明是中，正教明制；必往僧中，《尼戒本》云：若比丘尼，與人授具足戒已〔即本法也。〕；經宿方往僧中，與受具足戒者，波逸提。《業疏》，問云：經宿失本法不？
【譯文】在十六種遮難之中，在「父母是否聽許出家」這項提問之下，還要更進一步詢問是否有「夫婿丈夫的允許」；程序上應當先詢問是否嫁人有丈夫，若未婚沒有丈夫則不須再問。在「乃」字以下，接著說明正式納受具足大戒的程序。在「餘」字以下，指明此處省略了其餘細節；因為《隨機羯磨》中記載得極為詳盡齊備，需要遵行實踐的人應當自行翻閱對照修持。在正式受戒的段落中，第一科說明來往是非之中，以聖教正文明示制令；受本法後必定要前往大僧僧團中，《比丘尼戒本》中明文說：如果比丘尼為弟子授完具足本法之後；竟然放置隔夜才帶往比丘僧團之中為其傳受具足戒者，傳戒尼師要犯波逸提單墮罪。《業疏》中提問道：如果放置隔了一夜，先前在尼僧中所受的本法戒體是否會失效退失呢？

【513-0004】資持記/16c_下四#59
【原文】答：不失法，由捨故，不由隔日；若當日不去，明日須捨故受新，方得。斥非中，二，初斥僧來尼寺。《師資傳》，明判；遣信明例，是非可見矣。次斥寺外結界，律無定決，不云成不，故以義通之；僧須得罪，尼應得戒。釋難中，初問；由制作本法已，方往僧中；恐違此教，故問決之。
【譯文】回答說：先前的本法並不會失效，戒法的退失是因為當事人主動捨戒，並不是單純因為時間隔了一天；但是如果受了本法當天不及時前往僧中，第二天就必須重新捨去前法、重新傳受新的本法，然後才能前往大僧處求戒。在斥責非法的段落中，分為兩個部分，首先是嚴厲斥責比丘僧親自前往尼寺傳戒的荒謬行徑。《師資傳》中有極為明斷的判定；律中開許派遣可信賴的代理人受戒已經有明確的範例，比丘親往尼寺是非對錯自然顯而易見。其次是斥責在寺院外任意結界傳戒的弊病，律典中對此沒有下死定論，並沒有直接言明這樣做到底算不算結界成功，所以我們在此純粹從法理上予以融通剖析；比丘這樣做必定要獲結違制之罪，但比丘尼在法理上應該還是能如願得到具足戒體。在解釋各方難題中，首先提出疑問；因為律制規定必須先在尼僧中圓滿本法之後，然後才能前往比丘僧團中求戒；大家擔心違背這項聖教訓示，所以特別提出問題請求裁決明斷。

【513-0005】資持記/16c_下四#60
【原文】答中，《了論》既容互結，義通諸法，故云理得。次問。以受本法，三位不收；故雙牒名體，問以決之。答中，初答體。言戒緣者，是正受方便故。問：既加羯磨，理必發體；既不發體，用受可為？問：五為十緣，十為具緣；五十二戒，各自有體；本法無體，其意云何？而下，次答名。由未發戒，體是下位；
【譯文】在回答之中，《律二十二明了論》既然開許比丘與比丘尼可以互相共同結界，這種法理自然可以貫通應用於各項僧事羯磨之中，所以在法理上是完全行得通的。接著提出第二個疑問。因為剛受完尼僧本法的人，在比丘尼、式叉摩那、沙彌尼這三個既定法位中都無法被歸納收攝；因此同時提出這時的名分稱謂與實質戒體究竟為何，以此提問以求明斷決斷。在回答之中，首先解答「體性」的問題。文中所稱的「戒緣」，是指此時所受的本法純粹只是正式納受具足大戒的增上方便緣起而已。有人問：既然已經舉行了如法的羯磨大作法，在法理上必定會引發無作戒體；如果說此時根本沒有引發具足戒體，那當初何必多此一舉去受這道本法呢？又問：五戒是受持十戒的增上緣，十戒是受持具足戒的增上緣；五戒與十戒各自都擁有其獨立圓滿的戒體；為何獨獨這道本法卻沒有獨立的戒體，這其中的法義深意究竟是什麼？「而」字以下，接著解答「名稱」的問題。因為真正的具足大戒尚未完全生發出來，所以實質體性上依然處於下位眾的階次；

【513-0006】資持記/16c_下四#61
【原文】由加本法，名同上位；以於三眾，無所收故。第二斥非中，初引古。若下，今斥，初引當宗。律本，即〈尼犍度〉。乃至文云者，即說相中文。次引他部。《僧祇》，八種受具，僧受名十眾，尼受名二十眾；名數既顯，可驗昔非。次科，《五分》人數，事儀委悉，宜應準行；小遠者，若在露處，亦須尋內。
【譯文】但因為已經如法加持受過了本法羯磨，在稱謂名分上已經等同於上位的大僧階位；正是因為在原有的常規三眾之中，沒有任何一個位置可以恰當收攝她們的緣故。在第二個斥責非法的段落中，首先引用古代學者的舊說。在「若」字以下，是本宗今日的嚴正駁斥，首先引用本部根本的《四分律》。所謂「律本」，指的就是律藏中的〈尼犍度〉。乃至律文中明文記載的字句，指的就是宣說戒相時的莊嚴文句。接著引用其他部派的律典。《僧祇律》記載，佛門中八種受具足戒的儀軌中，比丘受戒稱為「十眾僧集」，比丘尼受大戒則明確稱為「二十眾僧集」；名號與人數既然記載得如此清晰顯豁，完全可以印證古德的見解是根本錯誤的。下一個小科判，《五分律》對於傳戒的人數規定與威儀事宜記載得極為詳盡完備，後世理應嚴格遵照推行；文中所說的「距離稍遠」，是指如果在空曠露天之處受戒，也必須在一尋（伸手可及）之內。
