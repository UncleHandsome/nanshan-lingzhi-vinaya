# 校閱材料　第062檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【062-0001】01_行事鈔/04b_卷上之四#4
【原文】問：受一月日，得攝閏六十日不？答：不得。以安居策修，靜住有益；受日出界，亂業曲開，非是正修；限依一月，不得過法。問：五事賞勞，得攝五月一月，含閏二六不？答：《十誦》不開，由是開奢法故。
【譯文】問：請受一個月的受日法，能否包含閏月而攝為六十天？答：不能。因為安居是為了策勵修持，靜住對道業有益；受日出界，是因紛亂事務而作的委曲開許，並非正修；期限只能依據一個月，不得超越戒法。問：五事賞勞（受迦絺那衣所得之五利）的期限，能否涵蓋由五個月延為六個月、或由一個月延為兩個月（含閏二六）？答：《十誦律》不開許，因為這本是寬放開許之法（開奢法）的緣故。

【062-0002】01_行事鈔/04b_卷上之四#5
【原文】今約閏月結之，進不三例：若閏五月六月，定百二十日住。若閏四月者，從四月十六日至閏月一日結者，並四月住；若閏月二日已後結者，漸漸轉少，以越閏月過，取五月一日，實夏成正結故；若五月一日後結者，皆三月住，以數滿九十日故。三若閏七月者，從四月十六日後，五月一日結者，盡三月住，由未至閏故；五月二日已後結者，皆四月住，由九十日未滿，入閏月不成數故。餘如《疏鈔》。
【譯文】如今就依閏月結夏安居而言，日數增減有三種條例：若閏五月或閏六月，必定安住一百二十天。若是閏四月，從四月十六日起至閏四月一日結夏者，皆安住四個月；若是閏四月二日以後結夏者，安住日數漸漸減少，因為跨過閏月，取五月一日作為真實夏季成立正式結夏的緣故；若是五月一日之後結夏者，皆安住三個月，因為日數滿九十天的緣故。第三種情況，若是閏七月，從四月十六日之後，至五月一日結夏者，皆安住三個月，由於尚未到達閏月的緣故；五月二日以後結夏者，皆安住四個月，由於九十天尚未期滿，進入閏月不算入正常日數的緣故。其餘詳情如《疏鈔》所述。

【062-0003】01_行事鈔/04b_卷上之四#6
【原文】二明分房舍臥具法。《四分》。因客僧受房，得不好者，嫌責。佛令客僧欲安居者，自往看房舍臥具已，然後分之。白二差一人，具不愛等五法，知可分不可分五德已，羯磨言：「大德僧聽！若僧時到僧忍聽：僧差比丘某甲，分房舍臥具。白如是。」「大德僧聽！僧差比丘某甲，分房舍臥具。誰諸長老忍僧差比丘某甲，分房舍臥具者，默然；誰不忍者，說。僧已忍，差比丘某甲分房舍臥具竟。僧忍，默然故。是事如是持。」彼比丘得法已，起禮僧足，白云：「一切僧各將衣物集堂，不得使住處有餘物。」眾僧一時房內各將道具赴集訖。彼知事人依律數房舍臥具，何者好惡？何者經營房主？先問經營者欲住何處房，已後便數知僧數，至上座前，白言：「大德上座，有如是房舍臥具，隨意所樂便取。」先與第一上座房，次與第二第三，乃至下座。若有餘者，從上座更分。復有餘者，更如上分。故多者，開客比丘住處。若惡比丘來，不應與。時有得缺壞房不受，佛言：隨力修治之。問：僧食上下平等，房舍不爾，隨上座選者？答：食可平融一味，義通十方；房舍臥具，事有好惡，兼復美好不同，限日非促，故任上座而選。問：若爾，利養等物，何制相參，不見者擲籌？答：此現前等分，通有一分，故制參亂投策而取。《僧祇》：不得與沙彌房；若師言，但與，我自為料理者，得。若房多者，一人與兩口已，不得不受；語云：不為受用故與，為治事故與。若春冬付房，具通二與。若上座來，隨次第住。若安居付房已，上座來，不應與住，當令餘處住。《四分》：安居竟，客來不應移。若分房舍，不得分眾集處。若有別房好窟，當於夏前書知名字；坐夏訖，便滅名而去。
【譯文】二明分房舍臥具法。《四分》。因客僧接受分配房屋，分得不好的人，便生嫌恨責怪。佛陀命令想要安居的客僧，自己先去察看房舍臥具之後，然後再進行分配。以白二羯磨差派一人，此人須具足不隨貪愛等五法，明瞭可分與不可分等五德之後，羯磨文說：「大德僧聽！若僧時到僧忍聽：僧差比丘某甲，分房舍臥具。白如是。」「大德僧聽！僧差比丘某甲，分房舍臥具。誰諸長老忍僧差比丘某甲，分房舍臥具者，默然；誰不忍者，說。僧已忍，差比丘某甲分房舍臥具竟。僧忍，默然故。是事如是持。」那位比丘領受作法任命後，起立頂禮僧足，宣告說：「一切僧眾各自將衣物聚集於僧堂（或講堂、大堂），不得使原住處留有剩餘物品。」大眾僧一時之間各自將房內道具帶往集合完畢。那位知事比丘依照戒律清點房舍臥具，何者完好、何者粗劣？何者是經手營建的房主？先詢問營建房主想住何處的房間，之後便點數明瞭僧眾人數，走到上座面前宣告說：「大德上座，有這樣的房舍臥具，隨您心意所樂便請選取。」先分給第一上座房間，次分給第二、第三上座，乃至依序分至下座。若還有剩餘的，再從上座重新分配。若又有剩餘，再如同上述方式分配。因此房屋若有多餘，便開許作為客比丘的住處。若是有惡行的比丘來，不應當分給他。當時有分得殘缺毀壞房屋而不肯接受者，佛陀說：隨自己的力量修繕它。問：僧眾的飲食上下平等，房舍卻不是這樣，而是隨上座挑選，這是何故？答：飲食可以均融調和為同一味道，義理通於十方僧眾；房舍臥具在事實上有好壞之別，加之精美程度不同，安居限期又非短促，故聽任上座挑選。問：若是如此，利養等物，為何制定要相互參雜、看不見時抽籤（擲籌）領取？答：利養屬於現前僧物等分，每人普遍都有一份，所以制定混合投籤來選取。《僧祇律》說：不得分房給沙彌；如果他的師父說「儘管分給他，我自己替他照料」，這樣便可以。如果房屋很多，一人分給兩間以上，不得拒絕接受；知事者對他說：「不是為了讓你享用而分給你，是為了讓你維護修繕而分給你。」如果是春冬二季分配房屋，兼通這兩種分配理由。如果有上座到來，應當依戒臘次第移住。如果是安居分配房屋之後，有上座到來，不應當讓出給他住，應當讓他住到其餘處所。《四分律》說：安居結束後，客僧來訪，原住僧不應當遷移。若分配房舍，不得分配大眾集會之處。如果有特別的房屋或優良的洞窟，應當在結夏之前書寫標明姓名；坐夏結束後，便抹去名字離去。

【062-0004】01_行事鈔/04b_卷上之四#7
【原文】三明作法不同。分二：一設教對緣，二用法分齊。
【譯文】第三、說明作法之不同。分為兩部分：一是施設教法對應事緣，二是行用法度的界限分齊。
