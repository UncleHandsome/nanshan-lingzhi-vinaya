# 校閱材料　第998檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【998-0001】資持記/04a_上三#60
【原文】即蓮花色尼勸化婦女出家之語，如中卷引。後引《大經》，但證其損。文明極有，勝報尚爾，餘凡可知。往謂昇天，返即入惡。結勸中。隨機者，須觀利鈍所宜廣略；《大論》示導，取解為期。浮謂不重，昧即不明。薩下，引示得否由心重輕。誡令策進，必使開解。心量中。
【譯文】也就是蓮花色比丘尼勸導化育婦女出家的那些話語，正如行事鈔中卷所引用的。後半段引用《大涅槃經》，則純粹用來證明不受戒（無戒）的巨大損害。經文明白指出即便生到三界之頂（非想非非想處天）擁有最高層次的殊勝福報，尚且因為沒有受戒而命終墮入惡道，其餘不受戒的凡夫之受損由此便可想而知。「往」是指死後上升天界，「返」就是指福盡墮入惡道。在總結勸勉的文段中，所謂「隨機」，是指必須仔細觀察受戒者根機是利根還是鈍根，來決定宜當廣說還是略說；《大智度論》指引教導受者，純粹是以使其真正理解開悟為限期。「浮」是指受戒之心浮泛而不深厚，「昧」就是指心地昏昧而不通達。從「薩」字以下，引用論典說明能否真正得戒完全取決於心力是鄭重還是輕浮。以此誡勉受戒者必須策勵精進，務必使心智徹底開悟明了。在心態體量的文段中。

【998-0002】資持記/04a_上三#61
【原文】如諸律論，多言上品。前引《多論》，但云增上。彼論又於五十具中，各分上中下心，則為九品。然是通論心之濃薄，亦不明示三品之相。此中欲令受者知心限量，故約文義次第明之。獨此精詳，餘皆不述。勸發中。唯言上品，故知中下非是正意；為顯上品，令知優劣。
【譯文】正如諸部律論之中，大多標明應當發起「上品心」。前面引用的《薩婆多論》，也只稱之為「增上心」。彼論又在五戒、十戒、具足戒三種戒法之中，各自細分出上品、中品、下品三種發心，合起來便成為九品。然而那只是通泛論述受戒心意的濃厚與薄弱，並沒有明確開示這三品發心的具體行相。此處為了讓求受戒者清楚知道自己內心的標準限量，所以依照經文義理循序漸進地予以辨析。唯獨此處剖析得精緻詳盡，其餘諸家著述皆未曾探討。在勸發正心的文段中，通篇只強調「上品心」，由此可知中品心與下品心並非受戒的正宗原意；之所以列出中下品，純粹是為了襯托顯發上品，令人明白其中的優劣差距。

【998-0003】資持記/04a_上三#62
【原文】若下，《毘曇》所明：有一羅漢，戒是下品；年少比丘，却得上品，皆由最初發心有異。乃至者，始從凡夫，終至無學；歷諸階位，更不增長。或云：受體是定，隨行有增；或約作戒永定，無作通增，並具如後。下品中。《毘跋律》，藏錄不出。言求道者，所期果也。
【譯文】從「若」字以下，說明《阿毘曇論》中所開示的法義：有一位阿羅漢，所得的戒體卻是下品戒；有一位剛受戒的年輕比丘，反而得到上品戒體，這完全是由於最初受戒時發心層次有所不同的緣故。所謂「乃至」，是指從最初發心的凡夫位起，一直到證得無學阿羅漢果；經歷所有修行階位，戒體一旦納受便再也不會增長。也有人主張：受戒所納受的根本體性是恆定不變的，只是隨著後天的持戒行持而有所增勝；或者有人認為作戒是一成永定，而無作戒體則通於隨行增長，這些說法全都詳細記載在後文。在下品心的文段中，《毘跋律》在經藏目錄中未能查考出處。所謂「求道」，是受戒者內心所期盼證得的果位。

【998-0004】資持記/04a_上三#63
【原文】救眾生者，所修行也。然雖救生，行有深淺。一不害彼命，二以法開導，三令得究竟度；前不得後，後必兼前。約義推之。初但護命，不令得脫，即二乘心。前云求道，正據小果。中品所修，以法開解，自他兩利；度非究竟，即小菩薩。雖期佛果，行處中間；望前雖勝，比後猶劣。
【譯文】所謂「救度眾生」，是受戒者內心所願修持的行持。然而雖然名為救度眾生，其行持層次卻有深淺之分：第一種僅僅是不損害眾生的性命，第二種能進一步以佛法開導化育，第三種能使眾生徹底獲得究竟解脫；前者無法涵蓋後者，後者則必定兼備前者。若依照教理來推敲：第一種僅僅止於護持眾生命根，而無法令其脫離生死，這純屬二乘小乘人的心量。前面所說的「求道」，正是指證得聲聞的小乘極果。中品心所修持的，是以佛法為眾生開解破惑，自己與他人兩獲利益；但救度眾生並未達到究竟成佛之地，這屬於小菩薩的行持。雖然心中企盼佛果，但實際行持只停留在半途；與前者相比雖然殊勝，但比起後者來說依然有所欠缺。

【998-0005】資持記/04a_上三#64
【原文】上品引導，令至涅槃，同歸佛道，即大菩薩行。準〈沙彌篇〉，三位配之，恰然符合。學者至此，宜須明辨三心所期行果分齊；舊記解釋，但述名言；執卷討尋，殊無緇素；故當剖析，不可籠通。中品中，初明期果，須約佛乘。解下，期行，明兼兩利。津梁是喻。眾生墮疑，故受生死；
【譯文】上品心是引導化育一切眾生，令其徹底證入究竟涅槃，一同歸於無上佛道，這才是大乘菩薩的大行。依照〈沙彌篇〉中的三種出家發心位階來比照相配，完全絲絲入扣、恰好符合。修學之人研究到這裡，應當明確辨識出三種發心所企盼的行持與果位之間的清晰界限；舊有的註記在解釋時，只是重複名詞概念；捧著書卷尋求探討，完全分不清黑白對錯；所以此處應當逐一剖析分明，絕對不可含混籠統帶過。在中品心的文段中，首先說明期盼的果位，須約定以佛乘為目標。從「解」字以下說明期盼的行持，明示其兼顧自利與利他兩方面。「津梁」是個譬喻。眾生由於墮入疑惑無明，所以沉淪受生死劇苦；

【998-0006】資持記/04a_上三#65
【原文】能為開解，令彼得度。生死如津，我身如梁，法喻可見。上品中，初明自利行；又下，明利他行；令法下，明護法行。初中。發心受者，即今正受比丘戒也；為成下，明遠期也。上二句大乘三學，即因行也。下句求大涅槃，即圓果也。三聚戒者，出《纓絡經》。聚即總攝為義。小乘七聚，從教以論。
【譯文】若能為其宣說開解破除疑惑，就能使他們得到救度脫離苦海。生死猶如波濤洶湧的渡口，我自身則願作濟渡眾生的橋樑，法理與譬喻顯而易見。在上品心的文段中，首先說明自利之行持；從「又」字以下，說明利他之行持；從「令法」以下，說明護持正法之行持。在第一部分中，「發心受戒」，就是指現今當下正求受比丘具足戒；從「為成」以下，說明遠大的期盼。上面兩句屬於大乘三無漏學，也就是成佛的因地行持；下面一句是希求證得大般涅槃，也就是圓滿的至極果位。所謂「三聚淨戒」，出自《瓔珞經》。「聚」是總體含攝融通的意思。小乘將戒律分為七聚，是純粹依從教規條目來論斷。

【998-0007】資持記/04a_上三#66
【原文】菩薩三聚，攝行斯盡；一攝律儀戒〔律儀禁惡，結業煩惱，究竟斷故，即止行也。〕，二攝善法戒〔世出世間大小修證，究竟修故，即作行也。〕，三攝眾生戒〔一切含識，究竟度故，即四攝行，謂布施、愛語、利行、同事，亦名饒益有情戒。此三須配三脫四弘三身三德，如別所明。〕。
【譯文】大乘菩薩的三聚淨戒，則將一切萬行徹底收攝無遺：第一是「攝律儀戒」（以律儀禁絕一切諸惡，使結使業力煩惱徹底究竟斷除，這屬於止惡門的止行）；第二是「攝善法戒」（世間與出世間、大乘與小乘的一切修證善法，無不究竟圓滿修持，這屬於行善門的作行）；第三是「攝眾生戒」（對所有一切含靈受生之眾生，誓願徹底究竟救度，這即是布施、愛語、利行、同事四攝法之行，也稱為饒益有情戒。這三聚淨戒必須配對三解脫門、四弘誓願、佛之三身與三德祕藏，如同在其他專篇中所明示）。

【998-0008】資持記/04a_上三#67
【原文】三解脫者，雖是觀慧，非定不發，即定慧二學。絕縛證真，由此得入，故號三解脫門。然名通小教。今對三聚，須局大乘。一空解脫門〔即性空也〕，二無相解脫門〔即相空也〕，三無作解脫門〔即唯識也，亦名無願。〕。〈懺篇〉三觀別配三位，此明大行，須約圓修。
【譯文】所謂「三解脫門」，雖然本質屬於觀照的智慧，但若非依託深定則智慧無法生發，所以正是指定、慧二學。斬斷煩惱繫縛、親證真如實相，皆是由此法門而得以證入，所以稱為「三解脫門」。然而這個名詞其實通於小乘教法。現在既然用來配對菩薩三聚淨戒，就必須局限於大乘義理來解釋：第一是「空解脫門」（即照見諸法自性皆空），第二是「無相解脫門」（即照見諸法因緣生相皆不可得），第三是「無作解脫門」（即悟入萬法唯識、於三界無所願求，亦名為無願解脫門）。〈懺悔篇〉中的三種觀法是分別配合三個修行位階來修持，此處闡明菩薩的大乘行願，必須約定以圓頓一心的圓融修持來理解。
