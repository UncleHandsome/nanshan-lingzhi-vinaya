# 校閱材料　第1294檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1294-0001】資持記/13e_下一#3
【原文】此明賞給由僧，不必須問。次科。上座告者，即獎飾之意。看病謙者，不自伐也。僧抑伏者，上座應云：此佛嚴制，不在辭遜；當受羯磨，便即互跪。羯磨中。四處牒緣皆不同者，由物不定，意令隨故，如前注中。後注從物，名相多少，尋文可知。次差人中，初科，前標示律文。今下，準用時事。
【譯文】這說明給予犒賞是由僧團自主決斷，並不一定要當面詢問對方。第二個小段落中，由上座長老宣告，這代表獎勵與讚許的意思。看護病人者表示謙讓，是不自我誇耀功德。僧眾予以勸解堅持，上座此時應當說：「這是佛陀制定的嚴格規範，不可一味推辭謙遜；應當接受羯磨法式。」看護者隨即互跪接受。在羯磨法之中，四處宣讀事由文句之所以各不相同，是因為所涉及的物品情況並不固定，用意是讓文句隨具體情況調整，就如同前面注文所述。後續的注文則是依據具體物品，其名稱相貌與數量多寡，查閱經文便可了知。接著在推派人選（差人）的內容中，第一個小段落先標明並出示律藏原文。在「今下」部分，則是依據實際情況彈性運用。

【1294-0002】資持記/13e_下一#4
【原文】《注羯磨》云：有人存三番作法，此思文未了〔一差人，二付衣，三分次；律云持衣與一比丘，令白二分，然律即指付分一法，彼謂有二，故是未了。〕；亦有存二番法者〔一差人，二付分，古記謂是口差，今家即者，非也。〕：今鈔所用，即一番法者；以口差人，但作付分，故不作差法；
【譯文】《注羯磨》中提到：有人主張要經過三道作法程序，這是對律文思考得不夠透徹（第一是推派人選，第二是交付衣物，第三是分配順序；律典說將衣物交給一位比丘，令其作一白一羯磨（白二羯磨）來分配，然而律典所指的其實只是交付分配這一種作法，他們誤以為有兩套獨立程序，所以是不透徹）；也有人主張保留兩道程序（第一是推派人選，第二是交付分配，古代的註記認為推派是用口頭指定，並稱這就是今家行事鈔的做法，這種說法是不對的，因為今家實為一番法）。如今行事鈔所採用的，乃是單一一道程序的作法；這是因為由僧團口頭推派人選，只須施行交付分配的羯磨，因此不再另外舉行推派的羯磨法；

【1294-0003】資持記/13e_下一#5
【原文】反上律文，故云違法。知事則本由公選，口差則亦顯眾和，故云通得。間既云違法，何不白二差之？答：律雖明制，不出法故。諸家所立，竝是意裁。今家不行，恐成專擅。〔作《行事策》者，亦妄出法；古記相㳂，雷同引用，都迷聖旨。
【譯文】這與前述的律文有所不同，所以才稱作與法相違。知事人員本來就是經由大眾公開推選，口頭指派人選也能彰顯大眾的和合，因此說兩者皆可行得通。有人詰問既然說與法相違，為何不用一白一羯磨（白二羯磨）來推派差請？回答是：律典雖然明確規定要推派，卻沒有給出具體的作法文詞。各家所創立的文句，全憑各自的心思裁量。我們本派之所以不推行，是擔心變成擅自專斷。（寫作《行事策》的人，也是妄自制定程序文句；古代註記相沿承襲，隨波逐流地引用，完全迷失了佛陀的聖意。

【1294-0004】資持記/13e_下一#6
【原文】即《注羯磨》云：今準律文，具含付分二法，餘無故不出是也。若爾，違法即應有過。答：律既不出，非故不行。況知事口差，通和義顯，理應無過。次科，初總示。持律者即指五德。以瞻病德缺，及沙彌分法，不行賞勞；作分衣羯磨已，直爾處分；故令先知，方可作法。
【譯文】）這就是《注羯磨》所說的：如今依照律典文字，其內容已完整涵蓋交付與分配這兩重意涵，此外沒有別的法式，所以才不另外列出。如果真是這樣，與法相違豈不應當有過失？回答是：律典既然沒有明確寫出儀軌，便不是故意不去遵行。更何況知事人員經由口頭指派，體現了大眾通融和合的精神，在義理上自然應當判定為沒有過失。下一個小段落中，首先是總體開示。所謂精通戒律者，就是指具備五種德行的人。如果照料病人者的德行有所欠缺，以及在沙彌參與分配的情況下，都不實行犒賞看護的程序；在完成分衣羯磨之後，直接給予處置發落；因此必須讓這些執事者預先知曉，隨後方可如法操作。

【1294-0005】資持記/13e_下一#7
【原文】多下，別釋，初釋具德。注中，上句明彼得分，普該十方故；下句顯此分賞，隨與少物故。三五肘外應白僧者，由是長物，不合持賞；復連法衣，不可截去；白僧和與，彼此通成。十下，次釋沙彌。前引《僧祇》，望入和尚；故是直分，沙彌自物。羯磨同僧，乃據《十誦》；意令準用，故此引之；
【譯文】在「多下」的部分，則是分別解釋，首先解釋具備德行者。注文中，上半句說明彼處僧眾得以分得衣物，這是因為利益普及十方僧眾的緣故；下半句則表明此處分配犒賞，只是隨機給予少量的物品。如果超過三至五肘以外的長度應當稟白僧眾，這是因為屬於多餘之物，依法不應當全部拿來犒賞；再加上這與如法衣物相連，無法隨意裁剪分離；所以必須秉白僧眾、眾人和合予以同意，這樣做對雙方而言都符合戒律。在「十下」的部分，接著解釋沙彌。先前引用《僧祇律》，是將沙彌的份額歸入剃度恩師名下；因此這是直接分配，屬於沙彌自己的物品。至於羯磨程序如同大僧的比丘，乃是根據《十誦律》的規定；用意是讓人有所依憑借鑑，所以在此處加以徵引；

【1294-0006】資持記/13e_下一#8
【原文】本部羯磨唯有大僧。付分法中，初科。注中，示法所出。律中賞勞法，下注云：若僧中羯磨，差一人分亡者衣物羯磨，與此無異；唯益一句：僧與某甲比丘衣，某甲當還與僧，白如是。〔已上律注。〕彼但例指，故云不具。或可賞法緣中自牒六物，又不云若衣非衣等；用有不便，故準後法。羯磨中。
【譯文】然而本部的羯磨法中，參與受法的只有具足戒大僧。在交付分配的法式中，首先是第一個小段落。注文裡指出了該法式所依據的出處。在律典犒賞看護的法式中，下方的注文說道：若是在僧團羯磨中，推派一人來分配亡者的衣物，其羯磨詞句與這個法式並無差別；只須多增添一句：「僧眾將衣物交給某甲比丘，某甲應當代僧眾分還，白告程序就是這樣。」（以上為律典的注文。）那裡只是援引慣例作為指引，所以說詞句並不完備。又或者在犒賞法的事由中，本身列舉了六種僧物，卻沒有提到「若是衣物或非衣物」等字句；在實際運用上會造成不便，因此必須依循後續的法式。羯磨文句之中。

【1294-0007】資持記/13e_下一#9
【原文】誰諸長老忍下，多牒緣十五字，僧下又多今字；準諸羯磨比之，定是傳訛，義須刪去。或當秉御，不須謹誦。大僧物中，初科。作上法已，限人已定。五德潛數人數，打搥白眾已，於籌物上各據字號。先行籌已，然後以籌對物付之。二中。初與無衣猶善，下令隨付實難。
【譯文】從「誰諸長老忍」這句以下，多出記載緣由的十五個字，在「僧」字下方又多出一個「今」字；拿其他各種羯磨法來對比參照，這必定是傳抄過程中的錯誤，在義理上必須予以刪除。或者在僧團秉持運作之際，不需要拘泥讀誦這幾個字。在大僧物品的章節中，第一個小段落。完成上述法式之後，參與分配的人數便已確定。具足五德的執事者在暗中清點人數，鳴槌告白大眾之後，在各別籌碼與物品上分別標註字號。先分發完行籌之後，然後依據籌碼核對相對應的物品進行交付。在第二個小段落中。起初把衣物分給缺少衣服的人固然是件好事，但下文依需要直接交付確實極為困難。

【1294-0008】資持記/13e_下一#10
【原文】注令折破，最為精要，宜準行之。三中，初勸依教。此下，次顯功深。不下，遮餘用。縱設謂設齋等。四中，留物，公私兩判。私緣囑授，亦不開與。次沙彌中。等興，同僧分也。四中與一，謂僧一分四破分之。準應白搥，一同僧式。五中與一，準上亦然。淨人不可預眾，應白僧已，屏處付之。
【譯文】注文中指示將過長的大布裁剪折破分配，這是最為精準切要的作法，應當依此準則來推行。在第三個小段落中，首先勸勉應當依循佛陀教法。在「此下」的部分，接著彰顯依教奉行的深遠功德。在「不下」的部分，禁止將物品挪作其他用途。所謂「縱設」，是指縱然設齋供僧等。在第四個小段落中，對於留存下來的物品，從公眾與私人兩個層面進行判斷。即便是出於私下交情的囑託贈與，也不開放私自給予。接著在沙彌的段落中。所謂同等興起，是指與大僧享有同等的分配權。在「四中與一」的部分，是指將僧眾一份物品拆成四份來分配。依照規矩應當擊搥宣白，規格儀式完全與大僧相同。在「五中與一」的部分，比照上述原則也是如此。淨人不能混雜參與僧團大眾，應當先稟告僧眾後，在隱蔽偏僻之處交付給他。
