# 校閱材料　第357檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【357-0001】02_戒疏/02c_卷一上之二#113
【原文】【記】總判中。初示四門俱通。「約」下，簡第三通局。初明教局，本被道眾。「取」下，次明行通。由無罪聚，同十業故。「方」，法也。「如」下，引例。過通教局，義無異故。「五」、「八」俗教，篇聚道教，故云「兩分」。如前二判，義無去取，故云「各有理」也。
【譯文】【記文】在總體判定的段落中。首先說明這四門義理都是共通於道俗的。「如果就」以下，辨析第三種略教的通達與局限。首先說明教法形式有所局限，本來是專門針對出家僧眾而設。「若是採取」以下，接著說明其修行準則是普遍相通的。因為沒有具體的篇聚罪相，其本質就等同於十善業道。「方」就是指法度。「正如」以下，引用實例對照。過失的本質是共通的，只是教法形式各有分工，其義理沒有兩樣。「五戒」與「八戒」是在家人的世俗教法，篇聚戒律則是出家人的道眾教法，所以說「分列其位」。如同前面兩種判定，在義理上沒有絕對的取捨，所以說「各自具備其道理」。

【357-0006】02_戒疏/02c_卷一上之二#118
【原文】【疏】有人云：「一、遮未起教，如僧尼所制戒等。二、滅已起教，如訶人、覆、滅等。」

【357-0007】02_戒疏/02c_卷一上之二#119
【原文】【記】二中。「遮未起」者，通收止作，以受說等，雖是作善，還須離過故。「滅已起」者，唯局作持。「訶人」等者，即《訶責》、《覆藏》、《滅諍》、《俱睒彌》、《遮犍度》也。
【譯文】【記文】在第二種說法中。「遮止未發生」全面涵蓋了止惡與作善兩方面，因為受戒、說戒等程序，雖然是為了造作善法，但也必須要遠離過錯才能成辦。「滅除已發生」則純粹局限在作持的範疇。「斥責違紀之人」等語，指的就是《訶責犍度》、《覆藏犍度》、《滅諍犍度》、《俱睒彌犍度》、《遮犍度》等專章。

【357-0008】02_戒疏/02c_卷一上之二#120
【原文】【疏】有人云：「如上所說，非無其致。然教所被，止在根機。今分廣律，不出三品。如受、說等法，為上人教；德衣、財食，為中人教；訶人、滅諍，為下人教。」據此為論，則此篇聚大歸，不在上二也。
【譯文】【疏文】還有人主張說：「正如前面所說的各家觀點，並非沒有其道理。然而教法所應用的核心，關鍵還是在於受教者的根機。現在如果劃分這部大廣律，不出三種品第：例如受戒、說戒等羯磨法度，是專為上等根機之人設立的教法；受迦絺那衣、以及處理錢財衣物的規矩，是專為中等根機之人設立的教法；斥責惡人、滅除紛諍等治罪法度，是專為下等根機之人設立的教法。」依據這種標準來論定，那麼這部戒本中的各篇聚罪條大體而言，並不屬於上面兩種上中等根機了。

【357-0009】02_戒疏/02c_卷一上之二#121
【原文】【記】三中，初敘立。「如」下，列示。「受、說等」者，「等」取安居、自恣。「德衣」即《迦絺那犍度》，「財食」即《衣》、《藥》、《皮革》等犍度也。「據」下，準判。上約三機，但對犍度。篇聚止惡，義是下人故也。
【譯文】【記文】在第三種說法中，首先敘述其立論依據。「正如」以下，是具體列舉開示。「受戒、說戒等」的「等」字，包含安居與自恣等法度。「德衣」指的就是《迦絺那衣犍度》，「財食」指的就是《衣犍度》、《藥犍度》、《皮革犍度》等章節。「依據」以下，是比照判定。上面依據三種根機，只是對應各個犍度而言。至於篇聚戒律重在止惡，義理上是專門針對下等根機的人所設立的。

【357-0012】02_戒疏/02c_卷一上之二#124
【原文】【疏】初、根條異：略教不待犯制，根本法輪；廣教略壞方有，則枝條也。二、為人異：略教利機，無過可起；廣教待犯，犯必鈍根。三、對過異：略教不因過制，無問自說；廣教必待犯後，制通淨穢。四、請不請異：廣必待請，如補壞衣；略不待請，一往便說。
【譯文】【疏文】第一、根本與枝葉的差別：略教不需要等待有人犯戒就預先制定，是根本的核心法輪；廣教則是略教遭毀壞之後才衍生出現的，屬於枝末的教法。第二、所針對的對象差別：略教針對的是利根之人，他們內心本來就不會生起過失；廣教則必須等待有人犯戒，而犯戒者必定屬於鈍根之人。第三、對應過失的方式差別：略教並不是因為犯過而制定，是佛陀不待他人提問而主動開演的；廣教則必定要等待犯戒行為發生之後，其規範同時通貫於清淨者與染汙者。第四、經由請法與未經請法的差別：廣教必定要等待他人請法才會制定，如同衣服破了才請求補綴；略教則不需要等待請法，佛陀直接主動就宣說開示。

【357-0013】02_戒疏/02c_卷一上之二#125
【原文】【記】別釋有四。初、後約教，中二在機。初云「根本」者，能生廣故；「法輪」者，摧業惑故。三中「廣通淨穢」，即顯略教純被淨也。四中，《律》明舍利弗請佛制廣，故言「待請」。「補衣」之喻，即佛答詞。
【譯文】【記文】在分別解釋中有四項內容。第一與第四是著眼於教法本身，中間兩項是著眼於受教根機。第一項說「根本」，是因為它能衍生出廣教；稱作「法輪」，是因為它能摧碎惡業與迷惑。第三項說「廣教通於淨穢」，正反襯出略教是純粹只針對身心清淨之人而說的。第四項中，《律藏》記載舍利弗曾主動祈請佛陀制定廣教條規，所以說「等待請求」。「縫補破衣」的比喻，正是佛陀當時給舍利弗的回答之詞。
