# 校閱材料　第914檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】六法者：一摩觸，二盜四錢，三殺畜，四小妄，五非時食，六飲酒。學宗謂行本也。言學有三：一學根本〔謂四重也〕，二學法〔即六法也〕，三學行〔一切大尼行〕。不重發者，以式叉尼轉根為男，即入僧沙彌故。《業疏》云：此學法女無戒體也，但受別教，位過沙彌；
【譯文】所謂六法是指：第一摩觸，第二偷盜四錢，第三殺畜生，第四小妄語，第五非時食，第六飲酒。「學宗」是指修行的根本。說到修學包含三種：第一學根本（也就是四重戒），第二學法（也就是六法），第三學行（也就是一切大比丘尼的行持）。之所以不再重複引發戒體，是因為式叉摩那如果轉變成男性，就直接進入僧團沙彌之列的緣故。《業疏》說：這位學法女並沒有另外獨立的戒體，只是領受了個別教法，地位超過沙彌；

【914-0002】資持記/01e_上一上#48
【原文】以人不解，謂分三眾，有三戒體等。問：沙彌尼戒，既遍塵沙，何以式叉方行此六？答：選其喜犯，重更約勒；無體再發，即其義矣。同三眾者，指下文也；同大僧則具在諸篇；同大尼沙彌，則各如別篇。沙彌合一，故言三眾。別行中。如無沙彌尼，得與大尼授食之類，下文具委。
【譯文】因為世人不理解，便誤以為分為三眾，就必定有三種戒體等。請問：沙彌尼戒既然普遍多如塵沙，為什麼式叉摩那才開始奉行這六條？回答：挑選其中最容易違犯的，重新加以約束管教；沒有另外的戒體再次引發，就是這個意思。所謂「同於三眾」，是指下文；若同於大僧則完整具備在各篇之中；若同於大尼、沙彌，則各自如同別篇所載。沙彌與沙彌尼合為一種，所以說是三眾。（在個別行持中）。例如如果沒有沙彌尼，可以為大比丘尼授食之類，下文有詳細具體的說明。

【914-0003】資持記/01e_上一上#49
【原文】第十門，標分中。鈔者祖師自號也。引下三句，即括三科。但科酌之言，對下少異。然下云鈔興，但明抄略之意；此言科酌，正明量處之謀；前後異名，共成一意。言正經者，正謂入諸正錄，經者訓法訓常，名兼通別；通該三藏，別在修多；今此從通，以收群部。
【譯文】（在第十門，標示分科的段落中）。所謂「鈔」，是祖師對自己這部著述的稱號。「引」字以下三句，就是總括了三個分科。只不過「科酌」這個詞，相對於下面稍微有些差異。然而下文說「鈔興」，只是說明抄錄簡略的意思；這裡說「科酌」，是正式說明審量處置的謀畫；前後名稱雖然不同，共同成就同一個意旨。所謂「正經」，「正」是指被載入各部正統經錄，「經」有訓為法則、訓為恆常的涵義，名稱兼具普遍與個別；通泛而言涵蓋三藏，個別而言專指修多羅；現在這裡是取其通意，用來收攝群部典籍。

【914-0006】資持記/01e_上一上#52
【原文】毘尼下，次列諸論。此科所列，名為律論，亦名戒論。《婆沙》、《成實》等，自屬經論。昔人不曉，例云小乘論，傳濫久矣。《多論》下注并傳者，即《師資傳》。《了論》注云：釋正量部者，此亦上座部中分出，律本不到此方，即《了論》所宗也。真諦即陳朝翻經三藏，出疏五卷，解釋《了論》，其文未流東南。
【譯文】「毘尼」以下，接著列出諸論。這個分科中所列出的，稱為「律論」，也稱為「戒論」。像《大毘婆沙論》、《成實論》等，本來屬於經論範疇。過去的人不明白，一概稱為「小乘論」，這在流傳中的混淆已經很久了。《十誦律多論》下面的註解提到「并傳」，就是指《師資傳》。《明了論》註解說「解釋正量部者」，這也是從上座部中分支出來的部派，其律本並未傳到此地，該律本正是《明了論》所尊奉的依據。「真諦」就是陳朝的翻譯三藏法師，他撰寫了五卷註疏來解釋《明了論》，但那些文字尚未流布到東南地區。

【原文】費長房後周高僧，周武滅法，遂為翻經學士。隋文帝開皇十七年，撰《歷代三寶錄》凡十五卷，今見大藏。次明異執，標中，有人謂聰覆二師，首傳《四分》，祖師不合科為異執。今謂異執之言，目其各計，有何毀斥！縱容妄解，豈不思所稟首師，亦列于後。

【914-0009】資持記/01e_上一上#55
【原文】又前云五部異執，則所宗部主亦在其中，又何獨黨於聰覆耶！非聖人者無法，即斯人也。列示中。所列諸師，並出《續高僧傳》。古記廣引，今不同之。若依寫取，此復何難；但恐徒喪時功，糅雜鈔旨；必欲知者，取傳尋之，今但列名略注師稟耳。法聰〔元魏朝人，本學《僧祇》，初弘《四分》。傳論云：自初開律師號法聰是也。
