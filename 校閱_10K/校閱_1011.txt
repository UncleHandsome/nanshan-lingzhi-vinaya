# 校閱材料　第1011檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1011-0001】資持記/04c_上三#33
【原文】世多念云食僧常食，此局不受請者，安得濫用！又言有請不背，意謂無請則食僧食，有請則赴他請，兩期言之；若此濫通，何名剋念；妄情憶度，全乖律檢；故須清晨念定，不容後改。亦有念已復從他請，貪情恣任，無由約也。受請中，初科。準《羯磨》云：謂不常定者〔有作若無請者〕。有請中，不背。可解。
【譯文】世人大多隨口念誦說「常吃僧眾的常住飲食」，這只限於不接受請齋的人，怎能隨便通用混淆！又有人念誦說「若有邀請也不推辭違背」，意思是沒有邀請就吃常住僧食，有邀請就去赴他人的請齋，把兩頭的話都含混說盡了；如果像這樣含糊籠統，又哪能稱得上是專一剋期的正念呢！這種妄動情識的盲目揣測，完全違背了戒律的檢視繩墨；因此必須在清晨就將心念堅定下來，不容許過後隨意更改。也有人清晨觀想完畢後，中途又改變主意去赴別人的請齋，這種放縱貪欲心念、隨心所欲的行為，就再也沒有辦法加以約束節制了。在「受請」的第一科中，依照《羯磨》所說，是指心意不固定、沒有常規限定的人（有的版本寫作「如果沒有邀請的人」）。在「有邀請」的條目中，「不違背請約」的道理很容易理解。

【1011-0002】資持記/04c_上三#34
【原文】開背有二，初有緣背法。註列三緣，即展轉食戒開通文也。《羯磨》，念云：我有請處，今依背緣。若無下，無緣背法。文中但出捨法。準《羯磨》念云：我有請處，今捨與人，然後捨之。〔先捨後念，理通。〕注五眾者，此出《僧祇》，彼云我今得食，施與某甲比丘，乃至沙彌尼。
【譯文】開許可以違背請約的情況有兩種：第一種是有正當因緣而違背的法度。注文中列出三種因緣，也就是「展轉食戒」中開許通融的律文。《羯磨》中教人念誦說：「我原本有應請的地方，如今依照開許違背的因緣而不能赴約。」下文「如果沒有……」，是指沒有正當因緣而必須違背請約的法度。律文中只開出了「捨請」的方法。依照《羯磨》應當念誦說：「我原本有應請的地方，如今將這份齋飯捨給別人」，然後再把請齋轉捨出去。（先向他人轉捨然後再作六念稱念，這在理路上也是通達的。）注文中提到的「五眾」，是出自《僧祇律》，那部律說：我今天得到這份飲食，布施給某某比丘，乃至轉施給沙彌尼。

【1011-0003】資持記/04c_上三#35
【原文】準此，本眾對作，餘則言告，並通捨之。以彼四眾皆福田故。〔舊云：當眾相對，未善文意。〕心念中。迴施某甲者，漫指一人；但自離過，不必人往。注中五種，《十誦》開者；彼因波斯匿王請佛及阿難食，阿難先已受請，不憶後受，王請明日入王宮食；
【譯文】依照這個準則，對於比丘同眾（本眾）要當面相對作法，對其餘四眾則透過言語告知，全都可以通融轉捨。因為這其餘四眾也都是福田。（古舊的說法認為：必須各自在所屬本眾中當面相對作法，這是不懂得律文深意的誤解。）在「心念轉施」中，所謂「轉施給某某人」，只是泛泛意指某一個特定的對象即可；只要自己能遠離犯戒的過失就可以了，不必非要親自派人前往轉告不可。注文中所列出的五種人，是《十誦律》所特別開許的特例；這是起因於波斯匿王迎請佛陀及阿難尊者應供，阿難先前已經答應了別人的請齋，自己忘了卻又答應了國王的後請，國王請他明天入王宮應供；

【1011-0004】資持記/04c_上三#36
【原文】入口已，方憶前請不與他，佛知阿難心悔，告云：心念與他已，便食；波離問佛，餘人得爾不；佛言不得，除五人：一者坐禪〔即今蘭若，坐禪語通，故用替之。〕，二獨住〔非蘭若處，今在初列，趣舉不次。〕，餘三如注。飢時依親里住，此即第五一種。〔有將為二，誤也，此三亦據無人。〕第三念。
【譯文】直到食物已經放入口中，阿難才猛然想起先前的請齋還沒有轉捨給別人，佛陀知道阿難心中悔恨不安，便告訴他說：「只要在心裡默念轉施給別人之後，就可以吃了」；優波離尊者請問佛陀：其餘的人也可以這樣做嗎？佛陀說不可以，唯獨除開五種人：第一是修習坐禪的人（也就是現在住在阿蘭若靜處的人，「坐禪」的語意涵蓋面廣，所以用來指代靜修者），第二是單獨一人居住的人（指不住在蘭若處的獨居者，現在將其列在首位，是隨意列舉而次序稍有調換），其餘三種情況就如注文所列。在飢荒之時依止親戚鄰里居住，這就是第五種情況。（有人把它分拆成兩種情況，那是錯誤的；這三種情況也都是基於身邊沒有其他僧人可供轉捨而設的。）在「第三念」中：

【1011-0005】資持記/04c_上三#37
【原文】依文但稱年月日時，不必妄加甲子乙丑等。第四注云隨有無者，謂衣鉢制物，攝理須具；遇緣暫闕，繫念早營。及餘三長，限內未暇，恐忘須憶。今人常無制物，生不說淨；逐日對聖，言稱闕衣及未說淨；迷教慢法，一至於此；法語之言，改之為貴。五念中，上明無緣不別法。
【譯文】依照律文只須稱念某年、某月、某日以及某個時辰即可，完全不必盲目胡亂添加甲子、乙丑等世俗的干支曆法。在「第四念」的注文中說「隨其身邊有無」，意思是三衣和缽盂等戒律規定的隨身法物，在攝持修道上是必須具備的；如果碰上特殊因緣暫時欠缺，心念就要時時繫掛著早點籌措齊全。至於其餘三種長物（長衣、長缽等），若在律定期限內還沒來得及說淨，恐怕遺忘也必須時刻警惕憶念。現今的人身邊常常沒有如法的制約之物，一輩子也不作說淨法；每天面對著佛聖像前，口中卻念叨著欠缺三衣以及尚未說淨；對戒教昏昧無知、對佛法輕慢懈怠，竟然到了這般田地；凡是真心修道的人，應當深切體會這些法語，痛加改正才是最尊貴的。在「第五念」中，前半段說明沒有特殊因緣時不單獨赴請（不別眾食）的法則。

【1011-0006】資持記/04c_上三#38
【原文】準《羯磨》云：我今不別眾食。然別眾唯約受請為言；若常住食，則無別過；可準此文，但云依眾。必下，有緣開別。九緣別眾，戒中委出，故指如後。六中。康謂安健，羸即有病。文出二法，隨時兩用。已上六事，總束為三。一三是戒；二四及五，內外兩資；第六即身。身是道器，衣食道緣，戒即道基。
【譯文】依照《羯磨》應當念誦說：「我從今日起不單獨接受別眾請齋。」然而「別眾」這條戒律，純粹是專就接受信眾請齋而言；如果是吃常住大眾的普請飲食，就根本沒有「別眾」的過失；可以依照這裡的律文，只要稱念「依止僧眾而食」即可。下文「若……」，是指遇有特殊因緣而開許別眾食的情況。律中開許了九種特殊因緣可以別眾受食，在隨後的戒相篇中會詳細列出，所以這裡指引參看後文。在「第六念」中：「康」是指身體安適康健，「羸」就是指患病羸弱。律文中開出了兩種念誦的方法，行者可以隨著自己當下的身體狀況靈活選用。以上這六件事，總括收攝起來不外乎三大門類：第一念與第三念屬於「戒律」門；第二、第四及第五念，屬於調攝身心的「內外道糧資助」門；第六念則屬於「身相」門。身體是載道的器具，衣食是修道的助緣，戒律則是修道的基石。

【1011-0007】資持記/04c_上三#39
【原文】三皆助道，故制常念。晨朝不作，止犯六吉。此是羯磨，須合四緣；法須口說，言章無濫；事即六緣，無非詣實；人唯獨作，處通兩界；緣乖法敗，隨有結犯。〔古記云防二十七罪，又印行六念云：晨朝不作，得三十二罪；此無所出，妄穿鑿耳。〕雜相，初科。應法澡罐，謂一斗已下小者。
【譯文】這三者全都是資助成辦菩提大道的殊勝因緣，所以佛陀規定行者清晨必須常常繫念。早晨如果不作六念觀想，只會結成六個突吉羅的小罪。這本身也是一種羯磨作法，必須具備四種緣起才能成就：在作法上必須親口宣說，言辭章句不得含糊濫套；在事相上就是這六種境界，無一不是真實懇切的事實；在人員上只能由自己單獨作法，在處所上則通於自然界與作法界兩界；如果緣起相違、作法失敗，隨著各別的過失都會結罪。（古代的記注說六念可以防範二十七種罪過，又有坊間印行的《六念法》說：早晨若不作六念，會招致三十二種罪；這些在律藏中都毫無出處，純粹是後人胡亂穿鑿附會罷了。）在「雜相」的第一科中：所謂「合乎律法的洗滌澡罐」，是指容量在一斗以下的小水罐。
