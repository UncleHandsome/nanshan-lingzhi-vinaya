# 校閱材料　第246檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【246-0001】01_行事鈔/11b_卷下之三#1
【原文】初明造經像法意者。如來出世，有二益：一為現在生身說法。二未來經像流布，令諸眾生，於彌勒佛聞法悟解，超升離生。此大意也。恐後生造像，無所表彰，故目連躬將匠工，上天圖取，如是三反，方乃近真。至于下天，此像垂地來迎；世尊命曰：汝於來世，廣作佛事。因垂勅云：我滅度後，造立形像，一一似佛，使見者得法身儀則；乃至幡華供養，皆於來世，得念佛三昧，具諸相好。如是造立，是佛像體。今人隨情而造，各生奇薄；不追本實，競封世染。所以中國傳像，在嶺東者，並皆風骨勁壯，儀肅隆重；每發神瑞，光世生善。逮于漢世，髣髴入真；流之晉宋，頗皆近實。並由敬心殷重，意存景仰，準聖模樣，故所造靈異。今隨世末，人務情巧，得在福敬，失在法式。但問尺寸短長，不論耳目全具；或爭價利鈍，計供厚薄。酒肉餉遺，貪婬俗務；身無潔淨，心唯涉利。致使尊像雖樹，無復威靈。菩薩立形，譬類婬女之像；金剛顯貌，等逾妬婦之儀。乃至抄寫經卷，唯務賤得；弱筆麁紙，惡匠鄙養。致使前工無敬，自心有慢；彼此通賤，法儀滅矣。致令經像訓世，為諸信首；反自輕侮，威靈焉在。故致偷盜毀壞，私竊治鑄，焚經受用，多陷罪咎。並由違背世、出世法。現在未來受無量苦，皆由失法之所致也。若使道俗存法，造得真儀，鳥獸不敢汙踐，何況人乎！但能奉聖像儀，佛亦垂形示迹。《善見》云：佛右牙，帝釋處；右缺盆骨，師子國中。《增一》：優填王造栴檀，波斯匿王造紫金，二像各長五尺。
【譯文】首先說明造立經像的法義宗旨。如來出興於世，能帶來兩重利益：一是為當時的眾生，以應化生身宣說正法；二是使經卷與佛像流布於未來世，令後世眾生能於將來彌勒佛出世時聽聞佛法、開悟明解，超拔流轉而脫離生死輪迴。這便是造立經像的主要旨趣。因唯恐後世眾生造立佛像時無所準的與表率，所以大目犍連尊者親自帶領工匠，升上天宮圖摹佛陀聖容，如此往返三次，才得以接近真實相好。等到世尊從天宮降回人間時，這尊佛像低首曲身（垂身至地）前來迎接；世尊對佛像宣說道：「你將在未來的世代中，廣作種種佛事。」世尊因而垂示敕戒說：「我滅度之後，造立佛形像時，每一處都應當肖似於佛，使見到佛像的人皆能體會法身的威儀軌則；乃至以幡旗、香花進行供養者，都能在未來世證得念佛三昧，具足佛的種種相好。」按照這樣的標準與精神來造立，才合乎佛像的本質體相。然而現今之人卻隨順個人私情意想隨意造作，競相追求新奇而顯得輕佻刻薄；不追循佛像的根本真實法式，反而爭相沾染世俗流俗之風。所以從古印度（中國）流傳到蔥嶺以東漢地（嶺東）的佛像，全都風骨剛勁雄健，儀容莊嚴肅穆；常常顯發神異祥瑞，照耀世間並啟發眾生的善心。到了漢代，造像風格大體神似而能契入真實真容；流傳到了晉、宋時期，也大多還能切近佛身實相。這都是由於當時造像者恭敬之心至為殷重，意念深懷景仰，嚴格依準聖者的法相模樣，所以造出的佛像往往能感應出靈驗奇異之事。如今隨著世道漸入末法，人們只致力於機巧與私情，縱使尚有一念求福恭敬之心，卻完全喪失了如法的儀軌法式。只計較佛像尺寸的長短，卻不講求耳目等相好是否圓滿齊全；或者爭論價錢的貴賤高低，斤斤計較供養禮酬的厚薄。工匠與主家之間以酒肉相互饋贈，沉溺於貪欲、淫行等俗務；身體沒有清淨齋戒，心中唯有算計名利。以致於尊貴的佛像雖然建立起來，卻不再有威德與靈驗。菩薩塑立的形貌，比類同於淫蕩之女；金剛顯露的面貌，更勝於妒悍婦人的神態。乃至於抄寫經卷時，只圖便宜省費；使用軟弱劣筆與粗糙薄紙，聘用拙劣寫匠並給予微薄鄙陋的酬勞。以致執筆抄寫的工匠毫無恭敬心，委託者自己心中也存有怠慢；彼此皆輕賤佛法，正法儀則因而蕩然無存。導致本應用以訓化世間、作為眾生歸信首要的經書與佛像，反而遭到自家人輕蔑侮慢，其威德靈驗又從何而生？所以招致被盜竊毀壞、私下熔鑄佛像以牟利、乃至焚毀經卷以挪作他用，許多人深陷滔天罪愆之中。這全是因為違背了世間法與出世間正法。於現生及未來招受無量無邊的苦報，皆是失卻正法法式所導致的。倘若僧俗大眾皆能恪守法度，造出真實合度的威儀聖相，連鳥獸都不敢污損踐踏，又何況是人呢！只要能如法奉持聖像儀則，佛陀亦必垂形感應、顯現聖蹟。《善見律》說：佛陀的右側佛牙，供奉在帝釋天處；右側缺盆骨（鎖骨），供奉在師子國（斯里蘭卡）中。《增一阿含經》記載：優填王以牛頭栴檀木造佛像，波斯匿王以紫磨真金造佛像，這兩尊像各高五尺。
