# 校閱材料　第512檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【512-0001】02_戒疏/08b_卷二下之一#31
【原文】【疏】三、言人者。俗人及四眾，唯四逆，除破僧故。比丘具五可知。《俱舍》云：「北洲及餘道，皆無無間業，何況於餘界？解云：『人道男女，能作此業。黃門等不許，彼無戒因。父母於其恩少，由不具身分為增長故，愛念少故。又其於父母，不起重慚羞故。畜生、鬼神道，不許有無間業故。若智明了，如聰慧馬，有五無間也。』」
【譯文】【疏文】第三點論及造罪之人。在俗凡夫以及比丘尼、式叉摩那、沙彌、沙彌尼這四眾弟子，只會造作四種逆罪，因為排除破僧罪的緣故。大僧比丘則五逆俱備，這是顯而易知的。《俱舍論》說：「北俱盧洲以及其餘各道眾生，都沒有造作無間重業的可能，更何況在色界、無色界？論中解釋說：『人道中的男女性別，能造作這種惡業。黃門等性別不全者不包含在內，因為他們沒有領受戒法的善因。父母對黃門的生育撫養恩德較薄，因為他們的身體殘缺不全，形體果報不能增上殊勝，父母對其慈愛憐念也較少的緣故。又黃門對於父母，不會生起深重的慚恥敬畏之心。畜生、鬼神道眾生，不被認定能造作無間重業。如果心智極為明了聰黠，如同有智慧的駿馬，則能造作五無間業。』」

【512-0002】02_戒疏/08b_卷二下之一#32
【原文】【記】三中，初正明。「俗人」無濫，下眾未具，無破僧理，故但有四。亦通伴助，如後所明。「俱」下，引《論》。初引《論》偈。「餘界」，即色、無色天。次引《論》解，前簡人道，別除黃門，文列三義。初「無戒因」者，以具戒者，方能具造，「黃門」當體，即戒障故。次「父母」下，明上恩疎。「增上」，謂身不具，形報非勝故。「又」下，顯下敬薄。故有殺者，不成逆業，然文中但明父母二逆，餘不能作，於義可知。「畜」下，簡餘趣。文約愚智，以明有無。據《論》「有」者，可對三逆。豈有非、畜而能破僧、出血耶？《論》無「五」字，必是傳訛。
【譯文】【記文】第三小科中，首先正面闡明。「在俗之人」界限分明，未受具足戒的下四眾弟子尚未圓具大戒，依律絕無單獨破僧的道理，所以他們只有四種逆罪。但他們也可以作為破僧的同伴或隨助者，如後面所明示。從「《俱舍》」往下，引用論典。首先引用《俱舍論》的偈頌。「其餘界」，就是指色界與無色界諸天。接著引用論中的解釋，前面先簡別在人道當中，特別排除黃門（性殘缺者），文中列出三種理由。第一是「無戒因」，因為唯有具足完備戒體之人，才能完全造作逆罪，黃門其身當下就是戒法的障礙。第二從「父母於其恩少」往下，說明父母所施的恩德相對疏淡。「增上」，是說身體有殘疾，所得的果報並非殊勝。第三從「又其於父母」往下，顯明為子者孝敬之心淡薄。所以黃門若有殺害父母之事，並不構成真正的無間逆罪，然而文中只針對殺父母兩種逆罪來說明，其餘逆罪他們無法造作，在道理上顯而易見。從「畜生」往下，簡別排除人道以外的其餘各趣。論文依據愚笨與智慧的差別，來說明能否造業。依照《俱舍論》所說「有智者能造」，頂多只能對應三種殺逆罪。怎麼可能非人、畜生能去破僧、使佛身出血呢？原本論典中沒有「五」這個字，必定是傳抄過程中的錯誤。

【512-0006】02_戒疏/08b_卷二下之一#36
【原文】【疏】言「不淨觀」者，如來立藥，對治心病。多貪不淨，瞋以慈心，癡不覺了，陰、界分別。初對貪者，故云「不淨」。
【譯文】【疏文】所謂「不淨觀」，是如來設立的一種對治心靈疾病的良藥。貪欲熾盛者修不淨觀來對治，瞋恚熾盛者以慈悲心來對治，愚癡昏昧者修分別五陰、十八界的智慧觀來對治。（三者中）第一項是針對多貪之人，所以（此處）宣說「不淨觀」。

【512-0007】02_戒疏/08b_卷二下之一#37
【原文】【記】次科，總明中。初通示三種藥病。「陰」即五陰，「界」即十八界，文略「十二入」，配對三迷，如前已示。若對五停，前二同此。三、愚癡多，觀十二因緣；四、我慢多，觀十八界；五、亂想多，數出入息。「初」下，別指今文。
【譯文】【記文】在總體說明的第二小科中。首先通盤列出三種藥物與病症的對應。「陰」就是五陰，「界」就是十八界，文字中省略了「十二入」，用來配對凡夫的三種愚迷，如同前面已經指出的。若對照五停心觀，前兩種與這裡相同。第三、愚癡深重者，觀十二因緣；第四、傲慢深重者，觀十八界；第五、思緒散亂者，修數出入息觀。從「初對貪者」往下，具體指明本段經文的用意。

【原文】【疏】如《智論》說，具有五種。
【譯文】【疏文】如同《大智度論》中所說，不淨觀總共包含五種層面。

【512-0009】02_戒疏/08b_卷二下之一#39
【原文】【疏】一、種子不淨，攬父母形以為己有。故偈云：「是身種不淨，非餘妙寶物，不由白淨生，但從穢道出。」
【譯文】【疏文】第一、種子不淨，攬取父母的精血形相作為自己的身體。所以偈頌說：「這個身體的種子本來就不乾淨，並不是世間其他美妙的珍寶，它不是由清白潔淨之物所產生，純粹是從污穢的孔道中流出。」

【512-0010】02_戒疏/08b_卷二下之一#40
【原文】【記】引示中，初「不淨」中。《論》云：「父母以妄想邪憶念風，婬欲火故，血髓膏流，熱變成精。宿行因緣，識種子在赤白精中住，是名身種。」偈中，初句標示，下三句釋成。上句明當體不淨，下二句生出不淨。「穢道」，即父母便利處也。
【譯文】【記文】在引論開示中，第一種「不淨觀」中。《大智度論》說：「父母因為妄想顛倒的邪念欲風，引動淫欲之火，以致血髓脂膏流動，受熱轉變成為精液。眾生往昔所作的宿業因緣，使神識種子安住在赤白精血當中，這就稱為身軀的種子。」偈頌中，第一句標明提示，後三句解釋成立。前一句說明種子本身當體不淨，後兩句說明產生的管道不淨。「穢道」，就是指父母排泄大小便的污穢部位。

【512-0011】02_戒疏/08b_卷二下之一#41
【原文】【疏】二、依處不淨，謂在生熟兩藏中間。故偈云：「是身為臭穢。不從華間生，亦不從薝蔔，又不出寶山。」
【譯文】【疏文】第二、住處（依處）不淨，也就是胎兒處在母體的生藏與熟藏兩者之間。所以偈頌說：「這個身體本來就是發臭污穢的。它不是在花叢花朵之間誕生，也不是從清香的瞻蔔花中生出，更不是產自珍貴的寶山之中。」

【512-0012】02_戒疏/08b_卷二下之一#42
【原文】【記】第二。「依處」，亦名生處。人有生熟二藏，食在生藏，猶未變動，流入熟藏，即成糞穢，胎處于中，故云「不淨」。偈中，初句標，下三句簡非淨處，以顯不淨。「薝蔔」，亦花，而別舉者，以花極好，彼國所貴，經論多引，蓋此意也。此翻「黃花」。
【譯文】【記文】第二種。「依處」也叫做生處。人體內有生臟與熟臟，食物剛進入生臟時，尚未消化腐壞，流進熟臟之後，就轉變成了糞便污穢，胎兒就夾處在二者正中間，所以說是「不淨」。偈頌中，第一句標示體質，後三句排除了各種清淨高雅的處所，以此顯發其污穢本質。「薝蔔」也是一種花，之所以特別提出，是因為此花芬芳美好，在印度極受尊崇，經論經常引作比喻，正是這個用意。中文翻譯為「黃花」。

【512-0013】02_戒疏/08b_卷二下之一#43
【原文】【疏】三、當體不淨，謂三十六物，成身十二，內外兩相，各十二也。故偈云：「地水火風質，能變餘不淨，傾海洗此身，不能令香潔！」
【譯文】【疏文】第三、本體（當體）不淨，是指由三十六種不淨物質構成，塑造身體結構的有十二種，內在與外在的體相各有十二種。所以偈頌說：「地、水、火、風四大構成的肉體，能把其餘攝入之物轉化成不淨，即使傾倒整個大海的水來清洗這個身體，也絕對無法讓它變得芳香純潔！」
