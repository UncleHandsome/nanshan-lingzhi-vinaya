# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【524-0001】03_業疏/12a_卷三之一#48
【原文】問：如上邊方開減五人，又加持律乃成制也，何名為開？有人言：中國制十人者，四人善解法律，六人足數便得；邊地開五，要須持律。今解不然。持律之言，豈局中表？僧徒多處知法不難，依教依緣義必成濟；邊僧既少，知法行稀，恐約數成，不專識教。夫作業藉緣，緣乖業敗，非假持律，焉得遂成？故遣此疑，文列行德，方能拯拔，樹此良基，不虗設也
【譯文】問：如上面所說，邊方開許減少為五人，卻又增加「必須有持律者」才算合乎規制，這怎能稱為開許呢？有人說：在中國（中印度）規制十人者，只要其中四人通達理解法律，其餘六人充備人數即可；而邊地開許五人，則必須具備持律之人。現在我的解釋並非如此。持律之說，難道只局限於境內或邊地？在僧人眾多之處，通曉教法並不困難，依循教法與因緣在義理上必定能夠成辦濟度；而邊地僧人既然稀少，通曉教法與具足戒行的人罕見，唯恐只是湊足人數作法，卻完全不通曉教法。羯磨造業必須依憑因緣，因緣若有違失羯磨作業便告失敗，如果不藉助精通持律之人，哪裡能夠順利圓成？所以為了遣除這種疑惑，經文中特別列出持律的行持與德相，才能拔濟戒子，樹立起這殊勝的戒體根基，這絕非徒然設立的文字。

【524-0002】03_業疏/12a_卷三之一#49
【原文】問答中。初問：減五少於中國是開，持律嚴於中國為制，開不成開，故須問釋。「有」下，次答為二：初引古義，其謬可知；二今解中，初三句通示，中謂中國，表即邊表。「僧」下，別釋。前釋中國不著，後明邊土須加行德，即持律之言。良基即戒體也
【譯文】在問答之中。起初發問：減免五人少於中印度的規定是開許，要求持律者比中印度更嚴格是限制，這樣一來開許就不成其為開許了，所以需要問難解釋。自「有人言」以下，隨後的回答分為兩部分：首先引述古人的見解，其謬誤顯而易見；第二、在當前的新解釋中，前三句作通體指示，「中」是指中印度，「表」就是指邊陲外境。自「僧徒多處」以下，作個別解釋：前半段解釋中印度不必特別標明持律，後半段說明邊地必須額外強調行持道德，也就是必須強調「持律者」之言。「良基」也就是指戒體。

【524-0007】03_業疏/12a_卷三之一#54

【譯文】在第二門「就受戒探討通局」之中。首先說明四種受戒的方法與機緣都偏局，法就是作法，緣就是受戒之緣。「五」字以下，接著說明六種受戒是機緣偏局而作法相通。因此下文總體提示開合，收束歸納為五種受戒，是因為將六種羯磨受合併為一種的緣故；顯示偏局是指列出前面的四種受戒，顯發相通即是開展後面的羯磨受，這樣就成為十種受了。

【524-0022】03_業疏/12a_卷三之一#69
【原文】三中言就時者，即在世、滅後也。三局二通，如文。五千年前，謂第一千年也。通達三世，名三達智。然下會異。《付法藏傳》說阿難臨滅，於恒河水中度五百仙人，皆善來得戒，恐引為妨，故特通之。言別緣者：一則機在阿難，非通他故；二則一時之用，非通後故
【譯文】在第三科中說「就時代」者，即指佛在世與佛滅度之後。三種偏局、兩種相通，如文中所述。「五千年之前」，是指（正法）五個一千年中的第一個一千年。通達過去、現在、未來三世，稱為三達智。自「然」字以下會通相異的記載。《付法藏因緣傳》說阿難臨近入滅時，在恆河水中度化五百位仙人，都是以善來而得戒，恐有人以此提出難破，所以特地予以會通。所謂特別的因緣：一是因為此感應之機在於阿難，並不能通於他人；二是因為這只是一時的權用，並不能通於後世。

【譯文】善來與八敬局限在南洲（南閻浮提），因為佛在此洲成道，由佛親自主持的緣故。問：為何佛陀一代教化不遊行於其餘三天下？答：南洲具有四種殊勝的別緣，即見佛、聞法、出家、悟道，其餘三洲缺乏親見佛陀的機緣，這且是依據一種共通的相狀來作如此判定。至於像舍衛國九億人口中也有未見未聞者，不妨礙其餘洲中也有具足此四種緣者，但這只是就多數情況而言，並非不如果上所述。

【524-0025】03_業疏/12a_卷三之一#72
【原文】第四明三洲中初科。初正示。問下次釋疑。問中三天，即三天下。答中，初約局說，以見佛等四種勝緣異於餘洲，故云別也。「且」下次就通論。舍衛國中人有九億：三億見佛聞法，三億見佛不聞法，三億不見佛不聞法。餘洲具四，謂隨機普應，無方所故。據通則四洲具缺互有，從多則南洲多具少缺
【譯文】在第四說明三洲的第一科中。首先正面提示。自「問」字以下接著釋除疑難。問話中的「三天」，就是三天下。答語中，先就偏局而論，因為見佛等四種殊勝機緣不同於其他諸洲，所以稱為「別緣」。「且」字以下，接著就圓通而論。舍衛國中有人口九億：三億人見佛聞法，三億人見佛卻未聞法，三億人不見佛亦未聞法。其餘諸洲也能具足四緣，是指佛陀隨機感而普遍應化，沒有固定方所的緣故。若就通途而論，四大洲各有具足與欠缺；若就多數而言，南洲則是多具備而少欠缺。

【譯文】羯磨與破結通於東、西、南三洲，這毫無疑問。三語這一種受戒在成道八年以前興行，當時尚未擯斥賓頭盧尊者，東、西二洲尚無佛法，怎麼可能相通呢？因此《鼻柰耶》說：「我現在擯斥你，讓你終身不得取證涅槃。」賓頭盧尊者便在此洲隱沒，顯現在西洲，結夏安居度化眾生，大興佛事。《十誦律》記載大體相同，只是增加了建造僧坊的內容。《薩婆多論》說：「東洲也是因為他而有了佛法的教化，才得以建立四部大眾等。」

【原文】次科。初明羯磨等但通三者，準下除北洲故。次三語中，賓頭盧為現神足，取竿上旃檀鉢，為佛所擯，往餘三洲，因有佛法；既在八年之後，則三語局南明矣。《鼻柰耶》中但云西洲，又不言起僧坊，故引《十誦》、《多論》續之
