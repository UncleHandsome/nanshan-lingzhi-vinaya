# 校閱材料　第725檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【725-0001】02_戒疏/16a_卷四上之一#88
【原文】【疏】次解止犯九句，謂於教行明昧，修學人根不同，得為九句。有立八句者。今解：翻解明止犯，唯八，不得立九。既迷教行，無法、犯兩識也。翻修明止犯，託相具九。如「九十」中，不作教法，輙行、輙食、輙語、輙取，望不作法名止，隨作即違名犯。
【譯文】【疏文】接著解釋止犯的九句，這是指對於教法行持的明瞭與昏昧，由於修學之人根機不同，故形成九句。也有立為八句的主張。現在的解釋是：如果從「翻轉理解（無知之惑）」來明析止犯，只有八句，不能立九句。因為既然對教行昏昧，就不可能同時具備「通曉法」與「通曉犯」這兩種明瞭。如果從「翻轉修持（違事而作）」來明析止犯，依託事相則具備九句。如同在「九十單提」中，不作教法儀軌，擅自行走、擅自飲食、擅自言語、擅自索取，相對於不作法則名為「止」，隨即動身造作即違背戒條而名為「犯」。

【725-0002】02_戒疏/16a_卷四上之一#89
【原文】【記】次明止犯，敘立中。初標敘立意。「有」下，次示古解。古師「八句」，除識法識犯，唯收不學止犯。今師八、九雙立，則收兩種止犯。「今」下，後出正解。「翻解」即不學無知罪，所謂教行止犯也。「翻修」即諸作持戒相翻罪，所謂事法止犯也。翻解中。初定句。「既」下，明無下品之意。約迷論犯，識則非迷。
【譯文】【記文】次一科闡明止犯，在敘述安立之中。先標示敘述立論之本意。自「有」以下，次指出古人的解釋。古師立「八句」，去除了法犯俱曉，唯獨收攝不學之止犯。今師八句與九句雙雙安立，則收攝了兩種止犯。自「今」以下，後提出正確的解釋。「翻轉理解」即是不學無知之罪，也就是所謂教法行持上的止犯。「翻轉修持」即是各個作持戒相翻轉所生之罪，也就是所謂事相法度上的止犯。在翻轉理解中：先確定句數。自「既」以下，說明沒有下品單句的本意。因為若依據昏昧來論違犯，通曉了便非昏昧。

【725-0005】02_戒疏/16a_卷四上之一#92
【原文】【記】翻修中。初定句。言「託相」者，即諸戒相。「如」下，舉戒以示。四「輒」者，總前十二戒：「輙行」有三，「輙食」六，「輙語」二，「輙取」一。「隨作」謂造事，「即違」謂違法，此示二犯同時，不妨體別。
【譯文】【記文】在翻轉修持中：先確定句數。所謂「依託事相」，即是各種戒相。自「如」以下，舉出具體戒條來開示。四個「擅自」，總括了前面十二條戒：「擅自行走」有三條，「擅自飲食」有六條，「擅自言語」有兩條，「擅自索取」有一條。「隨即動身造作」是指做出犯戒事，「即違背戒條」是指違背了教法，這是展示兩種違犯同時發生，但罪體互不妨礙各自成立。

【725-0006】02_戒疏/16a_卷四上之一#93
【原文】【疏】然識教相，無有愚迷，此下位一句。中品四句，如上所列，各有二罪，故合八也。上位有四：初不識法不識犯；二、不識法疑犯；三、疑法不識犯；四、法犯俱疑也。句各四罪，兼於學迷，故十六也。
【譯文】【疏文】然而通曉教相法度、完全沒有愚癡迷惘者，這是下位的一句。中品有四句，正如上面所列出的，各自帶有兩種罪過，所以合起來是八種罪。上位有四句：第一、不識法亦不識犯；第二、不識法而疑犯；第三、疑法而不識犯；第四、法與犯俱起疑。每句各有四種罪過，兼含了廢學與昏昧之罪，所以合起來是十六種罪。

【725-0007】02_戒疏/16a_卷四上之一#94
【原文】【記】正列中。三品可數而知。言「學迷」者，學即不學，迷即無知，通收疑、不識也。
【譯文】【記文】正式列舉之中。三個品位可以計數而得知。所謂「廢學與昏昧」，學即是不學，迷即是無知，全面收攝了起疑與不通曉。

【725-0008】02_戒疏/16a_卷四上之一#95
【原文】【疏】犯門解義，罪多為上，翻持中可以知也。順持解犯，何為不得？恐多誦文，自昏覺慧，故倒動之。心若明了，亂亦無苦，如鳥群飛，自分牝牡也。
【譯文】【疏文】在違犯門中解釋義理，以罪過最多的列為上品，從持戒門翻轉過來看便可以明白。若順著持戒門的順序來解釋犯戒，何嘗不可呢？只是擔心一般人誦讀文句多了，會自我障蔽覺性智慧，所以才特意倒置變動次序。內心如果完全明朗透徹，即使次序混亂也無妨礙，好比群鳥在空中飛翔，自然能分出雌雄一樣。

【725-0009】02_戒疏/16a_卷四上之一#96
【原文】【記】明倒中。初正明。「翻持中」者，持門解義，無罪為上。又復犯門列句，從重至輕，故上品以二不識為初句，與持相反，對上可知。「順」下，次出倒列之意。「牝牡」即雌雄。
【譯文】【記文】說明倒置列序之中。先正示其意。「從持戒門翻轉」是指在持戒門解釋義理時，以毫無罪過者為上位。再者，犯戒門列出條句，是從重罪排列至輕罪，所以上位以兩個不識為第一句，與持戒門正好相反，對比前文即可知曉。「若順著」以下，次說明倒置排列的意圖。「牝牡」即是雌雄之別。

【725-0011】02_戒疏/16a_卷四上之一#98
【原文】【疏】九十戒中，六十九戒僧尼同犯。故《尼律》中單列戒本，辨相同僧，文不繁也。
【譯文】【疏文】在九十條戒中，有六十九條戒是僧尼共同違犯的。因此在《比丘尼律》中只單獨列出戒本，辨明其戒相完全如同僧眾，條文便不繁複贅述。

【725-0012】02_戒疏/16a_卷四上之一#99
【原文】【記】第五，僧尼，同犯中。初示數。尼有一百七十八提，今且約僧數對明同異。「故」下，引證。「尼律」即《尼戒本》。同僧犯者，緣起、廣解，例皆略之，為省文故。
【譯文】【記文】第五門甄別僧尼，在同犯之中。先標示數目。比丘尼有一百七十八條單提，現在且依據比丘的數目來對照闡明同異。「因此」以下引律文為證。「尼律」即指《比丘尼戒本》。凡是與比丘相同的戒條，其起因緣起、廣解，律例全都予以省略，是為了節省篇幅文字。

【725-0014】02_戒疏/16a_卷四上之一#101
【原文】【疏】初有無不同有三，謂「輙教誡尼」、「說法至暮」、「譏訶教誡」。尼非師位，次第即無。
【譯文】【疏文】第一、有無不同類例，共有三條：即「擅自教誡尼」、「為尼說法至日暮」、「譏嫌呵責教誡尼者」。比丘尼本非師長的地位，依戒法次第自然便沒有這幾條戒。

【725-0016】02_戒疏/16a_卷四上之一#103
【原文】【疏】就中輕重不同，有十三戒，偈言：「作衣持屏坐，三期受贊食，勸足美牙角，過量覆三衣。」論其罪相，至文當解。
【譯文】【疏文】在這之中罪名輕重不同的，共有十三條戒。偈頌說：「作衣、持、屏處坐，三期、受讚食，勸足、美、牙角，過量、覆、三衣。」論及它們的罪相，到各戒經文時自當解釋。

【725-0017】02_戒疏/16a_卷四上之一#104
【原文】【記】次輕重中。作衣持屏坐，三期受贊食，勸足美牙角，過量覆三衣。已上，並僧提尼吉。
【譯文】【記文】次說明輕重不同之中。包括：為尼作衣、持衣與非親尼、與尼屏處坐、三種約期、受讚歎食、勸足食、索美食、牙角針筒、過量尼師壇（坐具）、過量覆瘡衣、作佛衣等量三衣。以上，僧人犯結波逸提，尼眾犯結突吉羅。

【725-0018】02_戒疏/16a_卷四上之一#105
【原文】【疏】後有五戒，犯同緣異，偈云：「背請足外道，小年雨浴衣。」皆謂犯罪即齊，開緣有異，故《尼律》中別立戒本。至文更出。
【譯文】【疏文】後面有五條戒，犯罪罪名相同而開遮緣起各異。偈頌說：「背請、足食、給外道，未滿年、以及雨浴衣。」這都是指所犯的罪名相等，但開許的因緣有所不同，所以《比丘尼律》中另外成立戒條。到了具體經文時會再列出。
