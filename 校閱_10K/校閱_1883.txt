# 校閱材料　第1883檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1883-0001】03_業疏/21a_卷四之四#48
【原文】次難以和僧問答，唯出功德衣及說戒二法，餘皆準著，故引為並。答中初句美其來問，「謂」下釋通。凡諸羯磨前有乞訶，羯磨必牒故
【譯文】在第二個問難中，以和僧問答律中唯獨出現在功德衣以及布薩說戒這兩種羯磨中，其餘羯磨大家都比照載入，因此引來作為並論反問。回答中第一句先讚許其提問切中要害，從「謂」字以下進行解釋融通。因為凡是羯磨之前若有乞請或呵責，羯磨正文中必定要宣讀的緣故。

【1883-0002】03_業疏/21a_卷四之四#49
【原文】問：德衣一法，何故偏和？答：此攝利奢，受者多故；今捨須眾，故偏問也
【譯文】問：功德衣這一法，為什麼律文偏偏要特別載明問和合？ 答：此法牽涉利養廣大豐厚，有資格受衣的人很多；如今要將利養捨給某一人，必須僧眾全體同意，所以才特別審問大眾是否和合。

【1883-0003】03_業疏/21a_卷四之四#50
【原文】三問答，欲顯律文偏出所以
【譯文】第三番問答，旨在顯明律文偏偏在功德衣中明文載出和僧的緣由。

【1883-0004】03_業疏/21a_卷四之四#51
【原文】若爾，半月說戒不是奢法，應不須和？答：說戒攝僧，住持萬載，若不和合，不成僧義，故須同法，表無乖競也。有人解云：一切眾法俱有和也，文或全缺，故致不同；餘不出者，但是漏略
【譯文】如果這樣的話，半月布薩說戒並不是涉及豐厚利養的法門，應該就不需要問和合了嗎？ 答：說戒是為了統攝僧眾、令正法久住萬年，如果不和合，就構不成清淨僧伽的意義，所以必須共同行法，以表彰沒有乖違抗爭。有人解釋說：一切大眾法本來都應當問和合，只是律文有時完全缺失，所以才顯得不同；其餘羯磨中未曾載出的，純粹只是經文遺漏簡略而已。

【1883-0005】03_業疏/21a_卷四之四#52
【原文】四難中，說戒亦和，當有別意，故問申之。答中初示教意，「有」下出他解
【譯文】在第四個問難中，既然說戒法也載明問和合，自應當有其特殊的用意，所以發問加以申辨。回答中起初開示制教的深意，從「有」字以下列出其他各家的解釋。

【1883-0006】03_業疏/21a_卷四之四#53
【原文】有人言：諸師解繁，以意分二。若僧差、難起，不專私意，但依律作用，乞何為？如沓婆被差、五德知事等例。必為衣藥、看病、問苦，既是私緣，非乞不委，加乞不妨，故前三家集意在此，不由此乞號加羯磨。故律中「增應作一白，眾多白，是名增也；文句非應，妄有所加」，即律文云「不如白法而作白」也。今時加乞準諸乞辭，及入法作亦準諸法，何得專制獨斷不成？義不可也
【譯文】有人說：各位律師的解釋過於繁瑣，依義理應當分為兩種：如果是僧團差派、或者災難突起，這並非專屬個人的私事，只要依照律文行事作法即可，何必陳乞？如同沓婆摩羅子被差派分房、差派五德知事等事例一樣。但如果是為了衣服、醫藥、看視病人、慰問疾苦，這既然屬於個人私事，若不陳述乞請便無法詳審其情由，因此補加乞辭並無妨礙，所以前面三家編集羯磨的本意就在於此，不能因為增加了乞辭就稱之為非法增法羯磨。律文中所說的增，是指「本應作一白，卻作了多次白告，這叫做增；或者言詞文句不合理，妄自有所增添」，也就是律文所說的「不如白法而作白」。如今所加的乞辭是比照其餘律典的乞請辭句，正式入羯磨作法時也比照其餘正法，怎能擅自獨斷判定羯磨不能成就呢？這種武斷判定在義理上是行不通的。

【1883-0007】03_業疏/21a_卷四之四#54
【原文】三兩通中，初總標。「若」下別釋。初明僧事不乞。僧差如營幹三寶等緣，難起如救寺、和僧之類，律中差知事、五德竝無乞請，故舉為例。「必」下次明私緣須乞。初示緣相，問苦謂濟他急難。「故」下救前諸師雖各加乞，不違律制。律明增加有二非法：一、多增白法，二、妄增詞句。今皆有準，故是可用
【譯文】在第三段兩相融通的辨釋中，起初總括標示。從「若」字以下分別解釋：首先說明公家僧事不需乞請。僧團差派如同營辦照料三寶等事緣，災難突起如同救護寺院、和合僧眾之類，律中差派知事僧與五德僧都沒有陳乞之辭，所以舉此為例。從「必」字以下接著說明個人私事必須乞請：首先開示事緣的相貌，「問苦」是指救濟他人的急難危困。從「故」字以下為前面各位律師辯護，說明他們雖然各自增加了乞辭，卻不違背律制。律中明示增法有兩種非法：第一是多增加了白告法式，第二是妄自增加了言詞語句。如今所加的乞辭皆有所依準，所以是可以採用的。

【1883-0008】03_業疏/21a_卷四之四#55
【原文】羯磨文中前告情者，是乞家緣也。當量機轉勢，不可冰執
【譯文】羯磨文之前先行向大眾告白情由，這就是求乞者陳述事緣。應當審度根機情況而靈活變通，不可僵化固執。

【1883-0009】03_業疏/21a_卷四之四#56
【原文】次釋法中初科。告情即牒法緣，白僧知委，而非加乞，故云「乞緣」。令隨機者，此示通意，去留皆得，以息諍情
【譯文】在接下來解釋作法的初科中。告情就是宣述受法之事緣，白告僧眾讓大眾知悉明瞭，而不是額外加設乞辭，所以稱為「乞緣」。令其隨機變通，這是開示圓融會通的意旨，告情保留或省去皆無不可，藉此平息紛爭對立的情緒。

【1883-0010】03_業疏/21a_卷四之四#57
【原文】文列二法者，以不及七日還，則但加半月法；不及半月者，但加一月法。不得俱誦二法，則四十五日也
【譯文】文中列出兩種大眾法，是因為若來不及在七日內返回，就只加受半月法；若來不及在半月內返回，就只加受一月法。絕對不能把兩種法一併誦出，否則就變成四十五日了。

【1883-0011】03_業疏/21a_卷四之四#58
【原文】次羯磨中初科，即點注中集牒二法。律文大字連寫，遮謹誦故
【譯文】在下一科羯磨文中，即是指點注文中連續編錄兩種羯磨法的情況。因為律文正文大字連寫在一起，此處特為點明，是為了防止拘謹死板的誦法人一併連誦的緣故。

【1883-0012】03_業疏/21a_卷四之四#59
【原文】問：受月法時，何不言過半月者？解云：七日別人，餘皆眾法。但云「過七日」，明知餘二俱白二也，同是眾故，不說分也
【譯文】問：受一月法時，為什麼不說「超過半月」呢？ 解釋說：七日法是對首法，其餘半月法與一月法都是大眾法。羯磨中只要說「超過七日」，便明白可知其餘兩種都屬於白二羯磨，既然同屬大眾法，所以就不再細加分別了。

【1883-0013】03_業疏/21a_卷四之四#60
【原文】初問三法合須次第云過，後二眾法竝云「過七日」，故須釋之。解中羯磨欲顯眾、別兩緣，半月、一月短長雖異，無非過別故
【譯文】起初提問：三種受法理應依序說明超過若干天，但後兩種大眾法卻都一律說「超過七日」，所以必須加以解釋。解釋之中指出：羯磨文旨在顯明大眾法與個人別法的兩類事緣，半月法與一月法時間長短雖然有別，但本質上無非都是超越了對首別法的期限而已。

【1883-0014】03_業疏/21a_卷四之四#61
【原文】問：今受半月、一月法者，若值小月，如何數之？答：依律文也。半月加法云十五日，則不問大小，數日滿還返，如《十誦》中三十九夜也；若受一月，則依大小，不可數日，如律云「住三月」等，小攝其內也
【譯文】問：如今受半月法或一月法的人，如果遇到農曆小月，應當如何計算日數？ 答：應當依照律文來定。半月加法中明言十五日，那麼無論月份大或小，都要數滿足足十五天才返回，如同《十誦律》中所說的受三十九夜法一樣；如果受的是一月法，則依照月份的實際大小，不可以拘泥數滿三十天，如同律文所說「住三月」等，小月自然包含在其中。

【1883-0015】03_業疏/21a_卷四之四#62
【原文】次問答中，言依律者，以羯磨中半月牒日故數日滿，一月牒月故隨大小。下引律文，即以安居以證受日
【譯文】在接下來的問答之中，所謂依照律文，是因為羯磨文中半月法宣讀的是具體日數，所以必須數滿日數；一月法宣讀的是整個月份，所以隨順月份大小而定。下文所引用的律文，就是以安居期「住三月」的規定來印證受日法。

【1883-0016】03_業疏/21a_卷四之四#63
【原文】次對首中，雖無正法，準白中用
【譯文】在接下來的對首法中，雖然沒有專門的正法文句，但可以比照白文中的文句來運用。

【1883-0017】03_業疏/21a_卷四之四#64
【原文】對首中初科。「準白用」者，即牒緣文，比前可見
【譯文】在對首法中的第一科。「準白用」，就是指宣讀事緣的文句，對比前面的羯磨文即可明白。

【1883-0018】03_業疏/21a_卷四之四#65
【原文】十誦》令從四眾，可是正教，如前解之，文非可用
【譯文】《十誦律》中規定准許對其餘四眾受法，這固然是佛陀的明文正教，但正如前文所解釋的那樣，這段律文是不可依用的。
