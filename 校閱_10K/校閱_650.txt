# 校閱材料　第650檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【650-0001】02_戒疏/13b_卷三下之一#25
【原文】【記】三中。「假弓樹」者，一弓四肘，一肘尺八，七弓共五丈四寸，六尺為步得八步，餘二尺四寸，八樹有七間，共得五十八步四尺八寸，加十三步勢分，故云「七十餘」也。「如上」，指前義門。
【譯文】【記文】第三段中，所謂「假借弓樹」，一弓為四肘，一肘為一尺八寸，七弓共長五丈零四寸，以六尺為一步則折合為八步，餘下二尺四寸；八棵樹之間有七個間隔，共計五十八步四尺八寸，再加上十三步的勢力延伸範圍（勢分），所以說是「七十多步」。「如上」，是指前面義理門中的計算。

【650-0002】02_戒疏/13b_卷三下之一#26
【原文】【疏】自餘道行、洲上、水、中并例。及上「藍」、「樹」，十五自然。諸相行護，其量非一，既是行事，廣如《事鈔》，故不繁出。臨時引用，如織綜也。
【譯文】【疏文】其餘如道路行走、沙洲之上、水界、井界（原文訛作中）等界域全都比照辦理。加上前面所說的「僧伽藍」、「樹界」，共有十五種自然界。這許多行相在實踐防護時，其範圍大小各有不同，既然屬於具體行事的範疇，詳細內容如同《事鈔》所述，所以此處不再繁複列舉。面臨具體情況時引用發揮，就像織布穿梭引線一樣條理分明。

【650-0003】02_戒疏/13b_卷三下之一#27
【原文】【記】諸部中。「道行」出《十誦》，彼云「四十九尋內」。「洲界」出《善見》，彼云「十四肘內」。「水」及「井」界兩出《僧祇》，竝據「二十五肘內」。「及」下，通結。「諸」下，指廣。「臨」下，令引說。「綜」，子宋反，線也，謂引用交互，猶如織線使成紋耳。
【譯文】【記文】在引用諸律部中，「道行界」出自《十誦律》，該律說是「四十九尋之內」。「洲界」出自《善見論》，該論說是「十四肘之內」。「水界」與「井界」兩者皆出自《僧祇律》，都依據「二十五肘之內」為準。從「加上」以下，通盤總結。從「許多」以下，指示詳見他處。從「面臨」以下，吩咐應當善巧引證說明。「綜」字讀音為子宋反，就是線的意思，是指引用條文相互交錯配合，如同織線交織成為織錦花紋一樣。

【650-0004】02_戒疏/13b_卷三下之一#28
【原文】【疏】上雖列體足明得離，未顯兩界相接，通成護不。所以第三，明彼此不相收攝。
【譯文】【疏文】上面雖然列出了界域名體足以說明人衣何時可以分離，但尚未顯示兩個界域互相交接時，能否共通構成護衣的效力。所以第三段說明彼此之間互不收攝涵蓋的道理。

【650-0005】02_戒疏/13b_卷三下之一#29
【原文】【記】第三，釋中。此彼不攝，即界義也。
【譯文】【記文】第三段在解釋之中，彼此不相收攝，正是「界域」的本義。

【650-0006】02_戒疏/13b_卷三下之一#30
【原文】【疏】文云「此藍非彼藍」。乃至「此樹非彼樹」等例之，故云「亦如是」也。
【譯文】【疏文】律文中說「這個寺院界並非那個寺院界」。乃至「這棵樹界並非那棵樹界」等依此類推，所以說「也是如此」。

【650-0007】02_戒疏/13b_卷三下之一#31
【原文】【記】初舉藍示相，謂以「藍」為頭，乃至「非彼十一種」也。「乃至」下，例諸界。謂樹、車等互舉為顯，歷餘十一竝同藍界，共有一百二十一句。更通他部四種，則有二百二十五句，思之。
【譯文】【記文】先舉出僧伽藍來指示其行相，是指以「僧伽藍」為開頭，乃至於「並非其餘十一種界域」。從「乃至」以下，例推各個界域。這是指將樹、車等互相列舉以彰顯其義，歷經其餘十一種界域皆與僧伽藍界相同，總共有一百二十一句。若再通融採納其他部派的四種界域，則會有二百二十五句，學者應當深思。

【650-0008】02_戒疏/13b_卷三下之一#32
【原文】【疏】上雖明相互不相攝，未知自然相外攝衣以不，是故第四，明勢分義。
【譯文】【疏文】上面雖然說明了各界相狀彼此不相涵蓋，但還不知道自然界相的外圍究竟能不能收攝衣物，因此第四段說明勢力延伸範圍（勢分）的義理。

【650-0009】02_戒疏/13b_卷三下之一#33
【原文】【疏】諸部明相，並無勢分，唯此《四分》獨開外護。
【譯文】【疏文】其餘各個律部說明界相時，全都沒有「勢分」的說法，唯獨這部《四分律》特別開許向外防護的延伸範圍。

【650-0010】02_戒疏/13b_卷三下之一#34
【原文】【記】第四，示所出中，初科。上二句總示諸部，下二句別顯本宗。
【譯文】【記文】第四段在說明出處之中，屬於第一科。上面兩句總體指示其餘各律部，下面兩句專門彰顯本宗《四分律》的特點。

【650-0011】02_戒疏/13b_卷三下之一#35
【原文】【疏】故《十誦》云：「僧坊聚落，齊墻、壁、塹、柵來，名『不離衣』。」若作羯磨，隨意遠近。故知無勢分也。
【譯文】【疏文】因此《十誦律》說：「僧人房舍與聚落，一律緊貼著牆壁、圍牆、壕溝、木柵之內，才稱為『不離開衣物』。」如果是以羯磨作法結界，界域遠近則任憑心意決定。由此可知該律並無勢分之說。

【650-0012】02_戒疏/13b_卷三下之一#36
【原文】【記】次《十誦》中。初是自然，但「齊墻壁」，則無勢分。「若」下，次示作法。
【譯文】【記文】接著在《十誦律》的說明中，前面屬於自然界，只要「緊貼牆壁」為界，就沒有外延的勢分。從「如果」以下，接著說明羯磨作法的界域。

【650-0013】02_戒疏/13b_卷三下之一#37
【原文】【疏】《僧祇》「寺門外手把戶鑰」、「船上曬衣風吹墮水，則明失」者，亦無勢分。
【譯文】【疏文】《僧祇律》記載「在寺院門外用手握著門鑰匙」、「在船上曬衣服被風吹落水中，律文即判定為失去衣物」，這也表示沒有勢分。

【650-0014】02_戒疏/13b_卷三下之一#38
【原文】【記】《僧祇》，引示中。「手把戶鉤」，有可入義。「船上曬衣墮水失」者，界別故失；今引彼文，證無勢分，未詳何意。
【譯文】【記文】在引述《僧祇律》的指示中，「手握門鎖扣」具有隨時可進入的含義。「在船上曬衣服落水即算失去衣物」，是因為界域不同而失去；現在引用這段律文來證明沒有勢分，暫時還不清楚作者的確切意圖。

【650-0015】02_戒疏/13b_卷三下之一#39
【原文】【疏】「若爾無者，何故彼律車、樹四周二十五步？」
【譯文】【疏文】有人質疑：「如果真的沒有勢分，為什麼該律規定車界、樹界的四周各有二十五步呢？」

【650-0016】02_戒疏/13b_卷三下之一#40
【原文】【疏】答：「此是界體。若有勢分，一切通給，何故寺外須捉戶鉤？」
【譯文】【疏文】回答：「這是界域本身的實體。如果有勢分的話，一切處所都應當普遍賦予延伸範圍，何以在寺院外還必須親手握住門鎖扣呢？」

【650-0017】02_戒疏/13b_卷三下之一#41
【原文】【記】釋難中，初引難。以彼樹、車、水、井等，並「二十五肘」故。「步」字寫錯。答中。初句釋通。「若」下，反質。若是勢分，不應有開不開。
【譯文】【記文】在解釋質難中，首先提出問難。這是因為該律中對於樹、車、水、井等處，皆規定為「二十五肘」的緣故，原文中的「步」字是傳抄錯誤。在回答之中，第一句先作會通解釋。從「如果」以下，反過來質問對方。如果這屬於外延的勢分，就不應當有的情況開許、有的情況不開許。

【650-0018】02_戒疏/13b_卷三下之一#42
【原文】【疏】《五分》無文，故知學者不可通用。
【譯文】【疏文】《五分律》中沒有相關明文，因此可知修學律宗者不可隨意通用於該部。

【650-0019】02_戒疏/13b_卷三下之一#43
【原文】【記】《五分》。無文開許，而彼宗學者濫用，故特點之。
【譯文】【記文】在《五分律》中，並沒有明文開許勢分，而該宗派的學者卻往往混淆濫用，所以特別予以指出。

【650-0020】02_戒疏/13b_卷三下之一#44
【原文】【疏】自古相傳，「中人擲石」取其下處，可有一十三步。例諸自然皆通，故云「亦爾」。
【譯文】【疏文】自古相傳，「中等人投擲石塊」是採取石塊落地的位置為準，大約有一十三步之遠。其餘各個自然界也都通通依此類推，所以說「也是如此」。

【650-0021】02_戒疏/13b_卷三下之一#45
【原文】【記】定遠近中。「中人」者，《善見》云：「不健、不羸人，盡力擲至落處，不取轉處。」
【譯文】【記文】在判定遠近距離中，所謂「中等人」，《善見論》解釋說：「既不特別強健、也不特別羸弱的人，竭盡全力投擲，以石塊落下的位置為準，不計算落地後滾動的距離。」

【650-0022】02_戒疏/13b_卷三下之一#46
【原文】【疏】上明行護，次明犯相。
【譯文】【疏文】上面說明了如法守護衣物，接下來說明犯戒的具體行相。
