`定稿/` 由 **`_終審` + 修訂回覆** 抽出，不再從 `docs/` 反向抽。

## 每筆欄位

```json
{
  "book": "戒疏",
  "book_id": "jieshu",
  "key": "01a_卷一上之一_0007",
  "label": "疏文",
  "source": "原文",
  "translation": "白話",
  "revised": true
}
```

- 來源：`_終審【原文】`
- 譯文：修訂回覆優先；沒有才用 `_終審【待審譯文】`
- `revised`：是否用了修訂回覆

## 舊資料

`定稿/_舊_頁面抽樣/` 是先前從 `docs/` 抽出的頁面版，只供比對，不是定稿。

## 規則

1. 改資料只改 `定稿/*.jsonl`
2. 材料與定稿衝突，以定稿為準
3. 頁面由定稿重建，不再從舊頁抽
4. 重建後跑 `python -X utf8 _src/pipeline_guard.py`

## 注意

定稿是「終審單位」，不是「網站 pair」。

一個定稿單位可能含多個段別，重建頁面時要再依標籤拆分；不能直接把一個單位當一個 pair。
