# 校閱材料　第530檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】大姉一心念。我比丘尼某甲。依某僧伽藍。後三月夏安居。房舍破修治故。
【譯文】「大姊請一心專念。我比丘尼某甲，依止某某僧伽藍，進行後三個月的夏安居。為了修繕破舊的房舍。」

【530-0002】04_比丘尼鈔/03a_卷中之上#13
【原文】第五心念者計尼不合心念今依十誦饑儉時開尼依親獨住所以偏出此文具修威儀至佛前云。
【譯文】第五門「心中默念作法（心念）」：照理說比丘尼是不合適採用心念法的，如今依據《十誦律》，在飢荒缺糧時開許比丘尼依附親族獨自居住，所以特別列出這段作法。應當具足修持威儀，走到佛像面前說：

【530-0003】04_比丘尼鈔/03a_卷中之上#14
【原文】若比丘尼某甲今依某聚落某家。前三月夏安居。
【譯文】「我比丘尼某甲，如今依止某聚落某家，進行前三個月的夏安居。」

【530-0004】04_比丘尼鈔/03a_卷中之上#15
【原文】第六忘成者此律忘不心念若為安居故來便成安居義云既言為來者舊住之人良恐不開若舊住人要此期夏忽忘不說亦須量行若外來尼不為益事者此便不成。
【譯文】第六門「遺忘卻成就」：本律規定，如果心中忘記發起心念，只要是專門為了安居而前來這座寺院，安居就算成立。義理上分析：既然說是「為了安居而前來」，原先就常住在此地的人，恐怕不能開許此例；但如果常住之人本來就堅定立約要在此結夏，只是忽然忘記宣說作法，也必須斟酌通融；若是外地來的比丘尼，並不是為了常住利益等正事而來，這樣安居就不能成立。

【530-0005】04_比丘尼鈔/03a_卷中之上#16
【原文】第七及界者此律云一一脚入界二雙脚入界三一脚入園四雙脚入園東方明相若出亦開外來者不說得成。
【譯文】第七門「及時入界」：本律說：一隻腳踏入界線內、兩隻腳都踏入界線內、一隻腳踏入寺院園區、兩隻腳都踏入寺院園區，只要此時東方破曉的曙光顯現，也開許這類外來者即使未宣說作法，安居依然成立。

【530-0006】04_比丘尼鈔/03a_卷中之上#17
【原文】第八移夏者此律難有二種謂命梵二難也一命難者謂鬼神賊等及惡獸毒蟲不得如意飲食醫藥及隨意使人若安居住此便則斷命故律云我在此住必為我命作留難佛皆聽去二梵難者謂被男子誘調畏犯重戒佛亦聽去若至彼結成者從初去日即須勤覓安身處若住處未得已來雖曾經宿不破安居以非故心輕慢意也反前不成若得住處夏法隨食於彼無緣不得出界恐破夏也若本處無難亦不得來由已結成故此律俗家安居見有二難當白檀越求移去若聽不聽但應自去若依餘部不云得夏今準母論得夏故論云移夏不破安居也問遇緣出界經宿忘不受日得夏否答諸部竝無文斷唯五百問事云夏中忘不受七日出界憶即悔者得一坐中不得過三悔不成歲問遇緣出界忽值水陸道斷諸難不及本界失夏以否答諸部亦無文斷古昔大德校量三藏義開得夏若為三寶益事友已大事不及界者開自餘悠悠無益之事破夏不疑。
【譯文】第八門「中途移夏」：本律規定難事有兩種，即生命之難與清淨梵行之難。第一是生命之難，是指遇到鬼神、盜賊等，以及兇禽毒蟲，或是得不到合適的飲食醫藥與隨順的差使僕役；如果繼續在此安居，就會斷送性命。因此戒律說：我在這裡居住，必定會對我的生命造成留難；對於這種情況，佛陀都聽許離開。第二是梵行之難，是指遭到男子誘惑挑逗，唯恐破犯重戒，佛陀也聽許離開。如果到達新地方結夏成立，從最初動身的那一天起，就必須勤奮尋找安身之處；在住處尚未找妥之前，雖然經過了住宿，也不算毀破安居，因為並不是出於輕蔑安居的放縱之心；若是相反的情況，安居就不能算數成立。一旦找到住處，夏安居的法規就隨之重新確立，如果沒有重大緣故，不得走出界外，唯恐毀壞夏安居。如果原先的處所危難已平息，也不得返回，因為已經在新規定的界內結成了。本律規定：在在家人家中安居，發現有這兩種災難，應當告知施主懇求遷移離開；無論對方答應與否，都應當逕自離去。若依其他部派的說法，並不認為遷移後還算獲得夏歲；如今依準《摩得勒伽論》，是可以保住夏歲的，所以論中說：移夏並不破壞安居。有人問：因事走出界外過夜，忘記辦理請假受日的作法，還能得到夏歲嗎？回答說：各部律典都沒有明確的斷定文句，唯有《五百問事》說：夏安居中忘記受持七日法就出界，一旦察覺立即懺悔者，算得夏；但一次結夏期中，不得超過三次懺悔，超過就不成夏歲。又問：因事走出界外，忽然遇到水陸交通中斷等各類險難，來不及回到本界，是否會失去夏歲？回答說：各部派也沒有明文斷定；古代大德考量三藏義理，開許這類情況能保住夏歲：如果是為了三寶的利益大事，或者是師友的生死大事，因而來不及返界者，得以通融開許；至於其餘無關緊要、悠閒無益的事由，則無疑絕對算破壞夏安居。

【530-0009】04_比丘尼鈔/03a_卷中之上#20
【原文】第一受緣者此律云凡受日之緣要為三寶利益大事檀越請喚生善滅惡得去十誦云為誰受日為七眾受並為生善滅惡應去若遣使不遣使俱得受若中路聞死反戒入外道眾八難事絕皆不應去僧祇若為私己求覓衣鉢藥草等悉成受日義云貧者應開富者宜禁若病重不堪受日直去不破夏故律云不得隨意及看病人等得去無犯若為治生覓利假託貴勝乞穀麥等或受雇撿校經像營造佛盆或悠悠請喚心不段重或為一緣受日遂歷眾事或即事不實虗搆外緣如是無益之事並不合受日既不合受妄數為夏無德自大冐受信施計滿犯重見論云自長己夏受施犯重五百問事破戒治生得財造佛尚不免地獄何況得福。
【譯文】第一門「受假事由」：本律說：凡是受日請假的緣由，必須是為了三寶利益的大事，或者是施主懇請呼喚，為了生起善法、滅除惡法，才可以前往。《十誦律》說：是為了誰而受日呢？是為了七眾弟子而受日，並且是為了生起善法、滅除惡法才應當前往；施主無論是否派遣使者前來，都可以受日前往。如果半路上聽說對方已經死亡、破戒還俗、墮入外道眾中，或者遭遇八難、或者受日之事已經了絕，就都不應當前往。《僧祇律》說：若是為了私己之事尋求衣服、缽器、藥草等，全都允許算作受日。義理上分析：貧困的人應當開許，富有的人則應當禁止。如果病情嚴重無法親自受日，直接離開也不破壞安居，所以戒律說：無法自主的病人以及看護病人的人等，離去都不算犯戒。如果是為了經商營利，攀附權貴乞討穀物麥子等，或者受雇監督校對佛經造像、營造盂蘭盆供，或是應付悠閒平淡的邀請而內心毫無莊重之意，或是為了一件事受日請假，卻趁機遊歷辦理諸多雜事，或是事情根本不實、憑空捏造外在由頭，像這類毫無益處的事，全都不合乎受日的條件。既然不合乎條件，卻虛妄地計算為夏歲，自己沒有道德卻自高自大，冒然接受信眾的供養，若是累計滿足了盜取的數額便犯重戒。《善見論》說：自己虛報夏歲而接受供養，犯重戒。《五百問事》也說：破壞戒律去經商謀利，賺得財富來建造佛像，尚且免不了墮入地獄，何況還妄想獲得福報。

【530-0031】04_比丘尼鈔/03a_卷中之上#42
【原文】宣已諸尼一時合掌頂上各云頂戴持然後尼僧安庠自恣律云大僧十四日自恣已僧十五日自恣此二眾相依故局日時若大僧病別眾眾不和眾不滿等尼應遣使問訊大僧若尼眾病乃至不滿亦須問訊大僧問尼眾不知所以須問訊大僧耶答若知不和便能為其和解。
【譯文】宣讀完畢，各位比丘尼同時將合掌舉至頭頂，各自說：「謹記在心！」然後尼僧安詳地進行自恣。戒律規定：大僧在十四日自恣完畢，尼僧在十五日自恣，這二眾是互相依止的，所以在日期時間上有所拘限。如果大僧有疾病、另外別眾、大眾不和合、人數不滿等情況，比丘尼應當派使者前往問候大僧；如果尼眾患病乃至人數不滿，也必須前往向大僧問候。有人問：尼眾有困境，為什麼必須前往問候大僧呢？回答說：大僧如果知道了彼此不和合，就能夠替她們調停調解。
