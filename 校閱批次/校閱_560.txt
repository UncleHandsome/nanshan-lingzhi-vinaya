# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【560-0001】03_業疏/15b_卷三之四#55
【原文】就三聲中，簡不受聲，如風鈴等，體唯無記，不發業性；取餘二聲，謂因受聲，如言令等，及因俱聲，如擊皷等，俱通三性。今取善聲為口作體
【譯文】在三種聲音當中，簡除無執受聲，例如風鈴等，體性純屬無記，不能引發業性；選取其餘兩種聲音，也就是因執受聲，如言語教令等，以及因俱聲（內外合發聲），如擊鼓等，這兩種聲音都通於三性。現在只選取善聲作為口作戒的體。

【560-0002】03_業疏/15b_卷三之四#56
【原文】次簡聲中初列諸聲。「不受」者，謂諸無情物鼓擊發聲，無執受者故。「取餘二聲」者，皆發業性，故通舉之。準明口作，止取因受耳。言因受者，謂有四大為因，鼓擊發聲，有所分別執受。「因俱」者，情與非情兩相兼故。因受通三性者，言令善惡，醉夢無心中語；因俱如擊鐘鼓講法禮誦為善，作樂誡兵等為不善，無緣妄擊等為無記。「今」下次剋定今體，簡聲局性，則無通濫
【譯文】在接著簡別聲音中，首先列出各種聲音。「不受（無執受聲）」，是指各種無情物撞擊所發出的聲音，因為沒有心識執受的緣故。「取其餘二聲」，是因為它們都能引發業性，所以普遍列舉。依照辨明口作戒的標準，只選取因執受聲罷了。所謂因執受聲，是指以有情身內的四大為因，敲擊發聲，具有分別與心識執受。「因俱聲」，是指有情與無情兩者相互兼合之故。因執受聲通於三性：言語教令有善有惡，醉酒或睡夢無心時所說的話則屬無記；因俱聲如敲擊鐘鼓用於講法、禮拜誦經為善，奏樂催戰命令軍隊等為不善，無故隨意敲擊等為無記。「今」字以下接著嚴格限定此處之戒體，簡別聲音局限於善性，就不會產生通雜濫漫之弊。

【560-0006】03_業疏/15b_卷三之四#60
【原文】此善作中，義通始終。覈論成業，據終非始。以從請師至二羯磨，要心未暢，善而非戒；第三唱已，剎那思滿，即善是戒
【譯文】在此善作戒當中，義理通於從始至終。但若嚴格考究成就戒業而言，則是依據終點而非起點。因為從迎請戒師一直到第二番羯磨，期要之心尚未圓滿通達，只是善心善行而非戒體；到了第三番羯磨宣唱完畢，剎那間造作思心所圓滿，此時的善行便成就為戒。

【560-0009】03_業疏/15b_卷三之四#63
【原文】問中欲彰戒善別故。答中初判今作戒。「自」下次指餘汎善。戒有二義：一有本期誓，二徧該生境；餘善反之，故不名戒
【譯文】提問是為了彰顯戒與善的差別。回答中首先判定現在所說的作戒。「自」字以下接著指出其餘泛常的善行。戒具有兩種涵義：第一是具有根本的期約誓願，第二是普遍涵蓋一切眾生境界；其餘善行則相反，所以不稱為戒。

【560-0010】03_業疏/15b_卷三之四#64
【原文】又解云：始終通收，竝作戒體。若唯一念，前緣不如亦應感戒；然既不爾，故知通收。又身口色體為發戒緣，身作色者始終相續為眼所見，口止之業非耳所聞，若唯第三當時無聲應無口作，故知通緣。至三說滿，論家剋取成就為言
【譯文】另一種解釋說：從始至終普遍收攝，全都是作戒體。如果只有最後一念，那麼前面受戒緣境不如法也應當能感得戒體；然而事實既然並非如此，所以知道應當通收始終。又身、口色法之體作為發起戒體的因緣，身作色從始至終相續為肉眼所見，口部止息不語之時並非耳朵所能聽聞，如果只在第三番羯磨完畢時當時並未出聲，就應當沒有口作，因此知道整個過程通為因緣。到了第三番羯磨宣說圓滿，論主是嚴格就業體成就之處而說的。

【譯文】在第二種解釋建立道理中，首先正面確立義理。「若」字以下反詰質疑：先是提出前緣不如法的詰難；「又」字以下接著依據口作止息來質難。「論」字以下會通前面論書的原意，理路上沒有妨礙。

【560-0013】03_業疏/15b_卷三之四#67

【譯文】在反覆救解中，就是前面所說的「身口得以互相造作，如同向前跪拜表顯言語之故」，這就顯明仍然有口作戒，還是回歸到前一種主張。

【560-0014】03_業疏/15b_卷三之四#68
【原文】今解：戒是有為緣成緣法，不請不乞，後戒無從，理須如前通始終也。故光律師因立三喻：如麝、如輪、如獨樂也。桑揄報色也，匠治方便也，與繩俱轉作戒也，廢繩獨轉無作戒也。《善生經》中亦同斯喻
【譯文】現在的解釋是：戒法屬於有為法，是藉由眾緣成就的因緣所生法，若不迎請師長、不乞求戒法，後面的戒體便無由生起，理當如同前說通取從始至終。所以慧光律師因此建立了三種譬喻：如麝香、如車輪、如陀螺。桑榆木比喻報色，工匠雕琢削治比喻方便，陀螺與繩索一同旋轉比喻作戒，抽離繩索陀螺獨自旋轉比喻無作戒。《優婆塞戒經》（善生經）中也有相同的譬喻。

【560-0015】03_業疏/15b_卷三之四#69
【原文】今斷中，初敘法假緣，後戒即是無作。「理」下正判，剋取次師。故下引喻有三，但釋獨樂，今傚配之：麝身如報色，割取如方便，以香熏物如作戒，香去氣在如無作；輪謂車輪木體，匠治運動自轉，比上獨樂，合法可見。引此可證作戒通於始終。下指《善生》，即如前引「如人手執極香臭木」是也。問：此明身口色聲，與成宗次師何異？答：前取相續，法入所收；此宗不立相續，唯歸前二所攝
【譯文】在如今的論斷中，首先敘述戒法必須假藉因緣，後戒就是無作戒。「理」字以下作正式判定，明確採取第二位法師之說。所以下文引用的譬喻共有三個，原文只解釋了陀螺，現在仿照其意配當其餘二喻：麝的身體如同報色，割取麝香如同方便，用香熏染物品如同作戒，香料離去而香氣猶存如同無作戒；輪是指車輪的木質本體，工匠修治、運轉自轉，比照上面的陀螺，相合於法理顯而易見。引用這些可以證合作戒是通貫始終的。下文指出《善生經》，就是如前所引用的「如同有人手拿極香或極臭的木頭」之喻。問：這裡所說的身口色聲，與成實宗第二位法師有何不同？答：前者選取相續假色，屬於法入所收攝；本宗（有部）不立相續假法，完全歸屬於前二入（色入、聲入）所攝。

【560-0016】03_業疏/15b_卷三之四#70
【原文】上通為言，作、無作戒俱色為體。故《涅槃》云：戒有七種，從於身口有無作色。《善生經》云：是十種法，或有作色及無作色，謂有莊嚴及成已者；或有作色無無作色，謂無方便及成已者。故薩婆多云：初念戒色，第二念戒色等。故知俱色
【譯文】綜合以上通論而言，作戒與無作戒都是以色法為體。因此《涅槃經》說：戒有七種，從身口生起無作色。《優婆塞戒經》說：這十種法中，或者具有作色與無作色，即是具有前方便加行（莊嚴）以及業道成就完畢者；或者具有作色而沒有無作色，即是沒有前方便加行但業道成就完畢者。因此薩婆多部說：初念是戒色，第二念也是戒色等。所以知道二戒都是色法。

【譯文】在問答中，首先發難質疑，是承接前面以三種色法所作的判定。回答中首先確立義理。色法具有二種涵義：第一是有對，第二是質礙，現在這無作戒具備後一種涵義。「無」字以下解釋成就其理。四大是指地、水、火、風，有內四大與外四大的分別，這裡是指內四大。《俱舍論》稱作大種所造，「大」取其寬廣普遍之義，「種」就是因生之義，正如《雜心論》所說「一切身口業都屬於色性，因為是四大所造之故」。由於能造的四大具有質礙，所造的業——身色、口聲、善、惡、無記，體性各自不同，所以說「更相障礙」；界限歷歷分明而不混淆，所以說「據所可分」。
