整體來說譯得相當通順，理解方向大體正確。以下按段列出**需要修正**與**建議斟酌**之處，並附改譯供參。

---

## 【1601-0001】大致無誤，幾處用語可調

1. **「初中」**：這是資持記的科文用語（初科之中），若全書體例統一，宜作「第一科中」；「第一層」不算錯，但要前後一致。
2. **「明即帝號」→「諡號」**：明帝確為諡號，可通；但原文只說「帝號」，直譯「皇帝的稱號」較貼原文，若要點明諡號可加註。
3. **「此方午時天陰」**：「此方」＝此土／中國（與西域相對），譯「此地」稍含糊，建議「此土（中國）正午時分」。
4. 「太微」宜作「太微垣」並加註（星垣名），「太微星宮」略生造。

## 【1601-0002】

1. **「將必是乎」語氣譯反了強度**（必改）：「將」是推測副詞（想必、恐怕），原文是試探性推斷，譯「必定就是這位聖人吧！」既過強，「必定…吧」本身也矛盾。
 → 建議：「陛下所夢見的，想必就是這位聖人吧？」
2. **「帝以為然」→「深表贊同」**：「深」是添加，原意只是「認為他說得對」。
3. **「迦竺者，傳法僧名」**（建議）：「迦竺」是**迦葉摩騰＋竺法蘭二人名字的合稱簡稱**，譯「是傳法僧人的名字」易被讀成一個人的名字。
 → 建議：「『迦竺』是兩位傳法僧人名字的簡稱，即迦葉摩騰與竺法蘭。」
4. 「西國」此處譯「西域」，與前段「西域有神」用語混同，建議前後統一（西國／西域擇一並註）。

## 【1601-0003】

1. **「又齎畫釋迦像」主語脫落**（建議）：攜回畫像者是蔡愔等，但譯文緊接「迎請他們來到洛陽，翻譯了……」之後，讀者會誤以為是騰蘭攜來。
 → 建議：「（蔡愔等人）又帶回所繪的釋迦牟尼佛像。」
2. **「未稟等者」→「未曾承受……」**：「未稟」指未稟受**三歸五戒**，「承受」語意太空。
 → 建議：「所謂『未稟（歸戒）』等文」。
3. **「設復等者」→「就算又有……」**（必改）：「設復」是「縱使、即使」的複合連詞，不宜拆出「又」字。
 → 建議：「所謂『設復（即使）……』等文」。
4. **「體俗形異」語意懸空**：現在譯「本質還是俗人而只有外表形象不同」，「不同」缺比較對象。
 → 建議：「戒體上仍是俗人（未得戒體），只是外形（剃髮染衣）異於俗人。」
5. **「法闕事非」→「戒法欠缺而事相非如法」**：「事相非如法」生硬。
 → 建議：「（羯磨）法欠缺，故受戒之事不如法。」
6. 「為有後魏相濫」譯「因為後世還有北魏容易混淆」：「後世還有」是添加，建議保留原詞並加註——「因為與後魏（北魏）相混濫，所以加姓氏來簡別」。

## 【1601-0004】

1. **「受緣」是篇名簡稱**（建議）：指〈受戒緣集篇〉，屬科判，不是泛指「受戒的因緣」。
 → 建議：「〈受戒緣集〉（受緣）之中又分二科，初科明迦羅施行（羯磨）受戒。」
2. **「行十僧受戒」譯法不順**（必改）：「奉行十位僧人如法授戒」語法不通。
 → 建議：「施行十僧（三師七證）授戒之法。」並註明「十僧」即三師七證。
3. 「異前形同」：「大不相同」的「大」是添加；且「形同」宜補足——「與先前只是外形與僧相同（而無戒體）者不同」。
4. 「歸戒」譯「三皈五戒」是解釋性擴充，可保留但宜加註（歸＝三歸，戒通五、十）。
5. 「嘉平……凡得五年」照原文譯即可（史實嘉平六年，**不要自行改正**，可出註說明記文與史異）。

## 【1601-0005】

1. **「《四分》之文」→「範本」**（必改）：「文」指律文／羯磨文，不是「範本」。
 → 建議：「就受戒而言，都誦《四分律》的（羯磨）文。」
2. **「即此為始矣」的「此」**：指迦羅立羯磨受戒**這件事**，譯「從此處」易誤為地點。
 → 建議：「便是從這件事開始的。」
3. **「數典忘本」成語誤用**（必改）：應作「數典忘祖」，或直接譯「忘失根本」。
4. **「文中但云羯磨，則三歸五十，義必具矣」**：「雖然……那麼……」連接不順，「理路上」偏口語。
 → 建議：「鈔文雖只說『羯磨』，但三歸、五戒、十戒之義必然已含具其中。」
5. **「乃閻浮之中心可」**：句末「可」疑為「耳」之訛或語末助詞，譯成「罷了」屬猜測，宜出註；且「才是……罷了」語感相衝。
 → 建議：「其實西方的梵土印度，才是閻浮提的中心。」（另註「可」字疑訛）
6. **「盲妄」**：非慣用詞，宜作「虛妄」；並可點明「妄習」是指出家眾仍如俗人從事祠祀的舊習。
7. **「出謂翻文」→「翻譯經文」**（必改）：《戒心》屬**律**（《僧祇戒心》＝僧祇律戒本），非經。
 → 建議：「『出』是指翻譯（律）文，『心』取總攝綱要之義。」並建議首次出現時補全名《僧祇戒心》，因下文「教宗之亂」「盛弘僧祇」皆由此而來。

## 【1601-0006】

1. **「教宗之亂，自此為始」指代含糊**（必改）：「此」緊承上文「出《僧祇戒心》」——受戒用四分羯磨、誦戒用僧祇戒本，故部派宗途混濫；譯「從這個時期開始產生」把因果變成了時間。
 → 建議：「教法宗旨的混亂，就從（迦羅出《僧祇戒心》）這件事開始；法聰律師以前盛行弘揚《僧祇律》，也正是由此而來。」（可加註說明受、誦分屬二部）
2. **「未詳華語」主體錯置**（必改）：這是元照說「（其）華言義譯不詳」，不是譯者「尚未詳實考證」。
 → 建議：「『曇諦』是梵語音譯，其中文義譯不詳。」
3. **「僧鎧羯磨，亦出曹魏」**：建議「（康）僧鎧所譯的羯磨，也是在曹魏時譯出的」，並註明僧鎧即康僧鎧。
4. 「胡僧」譯「外國胡僧」略贅，可作「胡僧（西域僧）」。
5. **「故今但推曇諦」的「今」**：指鈔文（道宣）如今只推曇諦，建議補「（鈔中）如今只推重曇諦」。
6. **「未之思耳」**：語尾「耳」是「罷了」，語氣較輕。
 → 建議：「只是沒有好好想過罷了。」
7. **括注缺收尾「〕」**（必補）：原文此段夾註亦未見閉合，譯文應補「〕」並註明「原文括注未閉，今補」。

## 綜合建議

- **體例統一**：三皈／三歸、此方／此土、西國／西域、科文「初中／又下」的譯法，宜全書一致。
- **釋詞句保留原詞**：凡資持記在解釋鈔文字詞（迄、未稟、設復、中夏、出、心、祠、祀），建議採「『原詞』＋解釋」格式，避免像「未曾承受……」「就算又有……」這種把被釋詞改寫後讀者對不上原文的情況。
- **夾註語氣**：元照兩處夾註（忘本、未之思）都是帶批評的感嘆，譯文可保留「實在是……罷了」的語氣，但不宜加重（如「未曾深思熟慮」）。
- 需優先修的硬傷：0005「範本」「經文」「數典忘本」、0006「未詳華語」「教宗之亂指代」、0002「將必是乎」、0003「設復」、0004「行十僧受戒」。
