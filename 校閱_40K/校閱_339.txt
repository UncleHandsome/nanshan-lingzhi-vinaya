# 校閱材料　第339檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【339-0001】04_比丘尼鈔/02b_卷上之下#28
【原文】第十六敬護者十誦云護三衣如自皮鉢如己眼著大衣者不得摙木石土艸掃地敷具等又不得脚躡敷坐臥上及襯身著若不持三衣入聚落俗人處犯吉羅遺教三昧經云比丘行時僧伽棃袈裟衣鉢鍚杖等當與身俱不得去身六尺五百問事云不能著大衣入聚落但持著肩上行無犯僧祇云敬三衣如塔若入聚落必須帶紐行若無紐者用鍼綴無鍼者下至手捉若無紐隨入家家得越心悔有而不著亦越毗尼披時當通肩披齊兩角左手捉時不得手中出角頭如羊耳律中至佛前上座所竝令偏袒經中通肩披衣五百世中入鐵甲地獄五分云得四褺大衣枕之中阿含經多處有文開枕大衣臥七條中三千威儀經云不著泥洹僧不得著僧祇支如是重重乃至最上著僧伽棃故知三衣得上下重著也五分云若出村為艸木鈎衣破裂塵入葉中聽為護衣故聚落外反著衣下數壞聽倒著衣上下安鈎紐及帶雨時不應倒著此律尼不著祇支入白衣舍提毗尼母及此律袈裟不得簾牀及脚躡三千威儀經云三衣在下地身不得高牀處坐決正二部毗尼論云若著大衣入村不得禮拜師僧上座等五百問事云無中衣時得著大衣上講禮拜小衣不近身淨潔無七條者五條亦得著入眾食及禮拜不著三衣食犯罪十誦亦然。
【譯文】第十六、敬重與護持（敬護）：《十誦律》說：愛護三衣應當如同保護自己的皮膚，珍惜缽器應當如同愛護自己的眼睛。穿著大衣時，不可搬運木材、石塊、泥土、割草、掃地、鋪墊坐臥具等，也不可以用腳踩踏、鋪在坐臥之處，更不可貼身肉體直接穿著；如果不帶三衣就進入村落聚落的俗人處所，犯突吉羅罪。《遺教三昧經》說：比丘行走時，僧伽梨袈裟、衣缽、錫杖等，都應當與自身相隨，不可離開身體超過六尺。《五百問事》說：若無法整套穿著大衣進入聚落，只要搭掛在肩上行走，就不算違犯。《僧祇律》說：敬重三衣應當如同敬仰佛塔；進入聚落時，必須扣好帶鈕前行，如果沒有帶鈕，要用針別好，如果連針也沒有，至少要用手握緊衣緣；若無帶鈕而隨意步入各家戶，每進一家便結一次越毗尼罪，需心念懺悔；若是備有帶鈕卻不繫好，也犯越毗尼罪。披衣時應當通肩披著，使兩角齊整；左手握持衣角時，不可讓衣角在手中散露突出如羊耳的形狀。律中規定到佛前或長老上座處，都必須偏袒右肩；而經文提到若通肩披衣禮拜，將有五百世墮入鐵甲地獄的果報。《五分律》說：大衣可以折疊成四層當作枕頭使用；《中阿含經》等多處經文中，均開許將大衣當枕頭、臥在七條衣中。《三千威儀經》說：若不先穿泥洹僧（下裙），就不可穿僧祇支，應當這樣層層內外相套，直到最外層穿上僧伽梨；由此可知三衣是可以上下重疊穿著的。《五分律》說：如果出村時，為了防止草木鉤破衣服、塵土灌入衣條摺葉中，為了護惜衣服，聽許在聚落外把衣服反過來穿；若下緣磨損嚴重，聽許倒過來穿，上下皆安設鉤紐與帶子，但在下雨時不應倒著穿。本律規定：比丘尼若不穿僧祇支便進入俗人家舍，犯波逸提罪。《毗尼母論》與本律皆規定：袈裟不可垂掛遮蔽床沿，也不可用腳踐踏。《三千威儀經》說：三衣若放在低處地上，自身不可坐在高床之上。《決正二部毗尼論》說：如果穿著大衣進入村落，不可在俗舍中向師長僧眾及上座禮拜。《五百問事》說：若缺少中衣，可以穿大衣登座說法或禮拜；五條小衣若未貼身且乾淨整潔，在缺少七條衣時，也可以穿著五條衣進入大眾中應供及禮拜；若完全不穿三衣就去用餐，則構成犯罪，《十誦律》亦同此規定。
