# 校閱材料　第691檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【691-0001】02_戒疏/15a_卷三下之三#97
【原文】【註】是中捨者。於此住處僧中捨鉢已，單白受懺，便說罪名、種、相，責心生厭離。鉢若好者，應奪留置，取最下不如者與之：便作單白，以鉢次第向上座易之，持上座鉢與次座，若與彼比丘，如是展轉乃至下座也。
【譯文】【註文】此處所謂的捨棄。是在此住處的常住僧眾面前捨出該鉢之後，以單白羯磨的方式接受其求懺悔，比丘便當面說出罪名、種類、犯相，至誠自責以生起厭離之心。這個鉢若是上好的，應當沒收留下，另取一個最下等劣質的鉢交給他：隨即作單白羯磨，拿著這個好鉢依序向上座比丘換取其鉢，再將上座的鉢交給次座，或者直接將次座的鉢換給該比丘，像這樣輾轉互換乃至輪到最下座為止。

【691-0002】02_戒疏/15a_卷三下之三#98
【原文】【律】波逸提。彼比丘應往僧中捨，展轉取最下鉢與之令持，乃至破，應持。此是時。
【譯文】【律文】波逸提。那名比丘應當前往僧團中捨棄該鉢，僧眾輾轉調換並取最下等的鉢交給他，責令他受持，乃至這個鉢破裂為止，都應當持續受持。這是制定的規矩。

【691-0003】02_戒疏/15a_卷三下之三#99
【原文】【註】僧以下鉢白二與，彼應守護。不得著瓦石落處，倚杖、刀下，著懸物下、道中、石上、果樹下及不平地，不得著戶牖內、戶扉下，若狀下、狀角，除暫著。不得著兩牀間，及立蕩鉢乃至足令破。彼不應故壞、故失、非鉢用者，吉羅。不犯者：若五綴漏，若減漏，求新者；若從親索；若從出家人索；若為他；他為己；不求而得；若施次得；若自有價買畜者——皆不犯。
【譯文】【註文】僧團以白二羯磨的方式將下等鉢交給他，他應當妥善護持。不得放置在磚瓦石塊容易掉落的地方，不得倚靠在手杖、刀子下方，不得置於懸掛物之下、道路當中、石頭上、果樹下以及不平整的地面，也不得放在門窗內側、門扇底下，或者床鋪下方、床角周圍，除非只是暫時放置。也不得卡放在兩張床鋪之間，以及立著劇烈晃動淘洗該鉢乃至足以使之破裂。他不得故意毀壞、故意遺失，或拿來作非鉢應有的雜用，違者得突吉羅罪。不犯的情況包括：若修補已達五道綴線且會漏水，或修補雖未滿五道但確實會漏水，因而尋求新鉢的人；若是向有親屬關係的人索求；若是向出家人索求；若是為別人代求；或者別人主動為自己求取；不求而主動獲得；若是按照僧團布施次序分配所得；若是自己花錢購買而蓄留者——以上全都算不犯戒。

【691-0006】02_戒疏/15a_卷三下之三#102
【原文】【疏】二、本鉢未滿「五綴」相。《五分》云：「若本無綴，乃至四綴，更乞如上鉢者，亦墮。若乞五綴，得吉。」注中「相去兩指間一綴」，準此為量，縱未綴而量過，亦不名犯。
【譯文】【疏文】第二句，說明原有的舊鉢尚未達到「修補滿五道綴線」的狀態。《五分律》說：「如果原本沒有綴線，乃至只有四道綴線，再去乞求上述好鉢的人，同樣構成捨墮罪。如果乞求的是修補過五道綴線的舊鉢，得突吉羅罪。」註釋中提到「兩道綴線之間相距兩指寬算作一綴」，依據這個標準來衡量，縱使還沒有打孔縫綴，但裂痕長度已經超過了這個尺度，也不算犯戒。

【691-0007】02_戒疏/15a_卷三下之三#103
【原文】【記】戒本，第二。《五分》中「更乞如上」，即「無綴乃至四綴」，此謂本有後求，皆不滿五，故齊得墮。「若乞五綴吉」者，本有不滿，後求滿故。本若滿五，則無有過。次釋注中。「兩指」，若據佛指面二寸，二指即四寸，五綴即二尺；若取人指面闊一寸，五綴止有一尺。文中不明。然前後多用如來磔指以為揩定。今言五綴，但取痕脉滿二尺許，不必須綴，故云「準此為量」等。
【譯文】【記文】戒本正文第二句。在《五分律》中「再去乞求上述好鉢」，就是指「原本無修補乃至只有四道修補」，這是說原本的鉢與後來求得的鉢，破損都沒有達到五道綴線的程度，所以同樣判定為捨墮罪。「如果乞求五道綴線的鉢得突吉羅」這點，是因為原本的鉢未達標準，而後求的鉢已經達到了五綴修補的標準。原本的鉢若是已經縫滿了五道綴線，重新乞求便沒有過失。接著解釋註釋的內容。「兩指寬」，如果是按照佛陀手指表面寬兩寸來算，兩指就是四寸，五道綴線的總長度就是兩尺；若是取常人手指表面寬一寸來算，五道綴線的總長度只有一尺。文中沒有明確說明。然而律典前後多半採用如來舒展手指的尺寸作為準繩。現在所說的五綴，只要裂痕脈絡的長度滿兩尺左右，不一定非要真正鑽孔修綴，所以說「依據這個標準來衡量」等。

【691-0008】02_戒疏/15a_卷三下之三#104
【原文】【疏】三、「更求新」者，是犯法也。
【譯文】【疏文】第三句「再去尋求新鉢」，是指觸犯戒律的行為。

【691-0009】02_戒疏/15a_卷三下之三#105
【原文】【疏】四、制捨。注解云「於此住處僧中」者，以鉢無多用，好者奪留入僧庫中，為益本寺，故言「此住處」也。
【譯文】【疏文】第四句，規定必須捨出物品。註釋說「在此住處的僧眾當中」捨棄，是因為鉢並沒有多種用處，上好的鉢應當收繳留在常住僧庫之中，以利益本地寺院，所以說是「在此住處」。

【691-0010】02_戒疏/15a_卷三下之三#106
【原文】【記】第四，住處中。「為益本寺」，由本多求，損本寺故。
【譯文】【記文】第四點，在住處的部分。「為了利益本地寺院」，是因為該比丘原本過度索求，在名譽與經濟上損害了本地寺院的緣故。

【691-0011】02_戒疏/15a_卷三下之三#107
【原文】【疏】問：「乞衣惱多，亦損寺舍，何不同鉢？」
【譯文】【疏文】有人問：「乞求衣服招來的惱亂也很多，同樣會損害寺院常住，為什麼處理方式不像鉢這樣沒收呢？」

【691-0012】02_戒疏/15a_卷三下之三#108
【原文】【疏】答：「衣資用寬，故須還主，不奪入僧。鉢無多用，得一便足，餘奪入僧。」
【譯文】【疏文】回答說：「衣服日常資助生活的用途比較寬廣，所以必須歸還給原主，不強行沒收入常住僧團。鉢則沒有多種用途，得到一個就已經足夠了，多餘的就要沒收歸入僧團。」

【691-0013】02_戒疏/15a_卷三下之三#109
【原文】【記】問中，乞衣不罰入庫，故問所以。答中，「衣用寬」者，隨時更易，用非一故。
【譯文】【記文】在問題中，乞求衣服受罰時並不沒收入庫，所以詢問其中的緣由。在回答中，「衣服用途寬廣」，是指隨著四季時令需要更換，用途不止一種。

【691-0014】02_戒疏/15a_卷三下之三#110
【原文】【疏】「若爾，長鉢無用，何不入僧？」
【譯文】【疏文】又詰難說：「既然如此，多餘蓄留的長鉢也沒有多大用處，為什麼不沒收入僧團呢？」

【691-0015】02_戒疏/15a_卷三下之三#111
【原文】【疏】答：「或自貿得，或虗心施，既無外惱，故不同乞。」
【譯文】【疏文】回答說：「長鉢或者是由自己交換所得，或者是信徒誠心布施而來，既然沒有對外造成惱亂，所以處理方式不同於非分乞求所得的鉢。」

【691-0016】02_戒疏/15a_卷三下之三#112
【原文】【記】轉難中。既無多用，前戒長鉢不合還主。答中。鉢分長、乞，不乞屬前，違說淨犯，故復還主。乞則屬後，惱施主犯，故罸入僧。又長不損僧，乞有損故。
【譯文】【記文】在進一步的詰難中。提問者認為既然沒有多大用途，前一條戒律中的長鉢照理就不該退還給原主。回答中指出：鉢分為「蓄長」與「非分乞討」兩種，不屬於乞求而來的長鉢歸屬前一條戒，只是因為違反了十天說淨的規定而犯戒，所以物歸原主。乞求而來的鉢則歸屬於後一條戒，是因為貪求惱亂了施主而犯戒，所以必須沒收充公入僧團。再者，單純蓄留長鉢並沒有損害僧團的名譽，非分乞求則對僧團造成了實質損害。

【691-0017】02_戒疏/15a_卷三下之三#113
【原文】【疏】《僧祇》：「若鉢大貴，應賣取十鉢，九者入僧厨，下者還主。乃至乞鉢直入僧，一直買鉢還此比丘。」
【譯文】【疏文】《僧祇律》記載：「如果乞得的鉢價值極其昂貴，應當將它賣掉換取十個一般的鉢，其中九個充入僧團廚庫，最下等的一個歸還給原比丘。乃至若是乞求鉢的折現款項，款項應當沒收入僧團，只從中提撥一筆買鉢的費用，買一個鉢歸還給這位比丘。」
