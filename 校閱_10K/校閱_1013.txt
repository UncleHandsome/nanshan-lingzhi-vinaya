# 校閱材料　第1013檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1013-0001】資持記/04c_上三#48
【原文】但事繁行廣，故兩分之。來意中，初科，上二句明立教之意。住持三寶，全賴人弘；師徒相攝，僧寶不斷，則佛法增廣也。增益謂從微至著，廣大即遍布流通。互下，示相攝之益，上二句通舉三攝。敦遇即心相攝，謂厚顧也。日下，示解行二益。業謂所學，文通師資，義在弟子。
【譯文】只是因為這方面牽涉的事相繁複、實踐行持極其廣大，所以才分拆為兩個篇章來論述。在「本篇由來意趣」的第一科中，上面兩句闡明了佛陀立教的深遠本意。護持正法、令三寶常住於世間，完全依賴於後人的弘揚開拓；師長與弟子之間能夠以道相契、緊密攝受，清淨的僧寶才能燈燈相續永不斷絕，佛法也才能日益增長廣大。「增益」是指德業由微小逐漸顯著，「廣大」是指正法法脈周遍流布暢通。下文「互……」，是揭示師徒相互攝受的殊勝利益，上面兩句話統括列舉了三種相攝法門。「敦遇」就是心意上的互相攝受，是指深厚懇切的照料與顧念。下文「日……」，是展示在教理理解與實際行持兩方面的長足利益。「業」是指所修學的戒定慧道業，文字雖然貫通師徒二人，但核心用意主要在於成就弟子。

【1013-0002】資持記/04c_上三#49
【原文】彰非中，上四句敘非法。初句明教壞，次句明人愚，三即俗輕，四謂道妄。並下，推所因。率，猶引也。二下，示所損，上明損自他。欲下，損佛法。篇意中，上句示悲懷。拯急即拔苦故。次句明慈行。安危即與樂故。愚教任情，動成惡業；墮在苦處，喻如倒懸。〔《孟子》云：當今之時，萬乘之國行仁政，民之悅之，猶解倒懸。
【譯文】在「彰顯過非」的段落中，上面四句話是在敘述那些不合律法的混亂亂象：第一句說明神聖教法遭受破壞，第二句說明出家人心智愚昧無知，第三句是指引起世俗之人的輕賤鄙視，第四句是指修道者動輒妄念紛飛、道風敗壞。下文「並……」，是追究這種敗壞現象的根本起因。「率」是引導、率領的意思。下文「二……」，是展示這種做法所造成的雙重損害，上面說明這對自己和他人都有嚴重的損害。下文「欲……」，是說明這將徹底損毀如來正法。在「闡明作篇用意」中，上一句顯露出祖師無比慈悲的本懷。「拯急」就是拔除沉淪苦難的意思。下一句表明慈愛利他的深廣行持。「安危」就是給予安穩快樂的意思。若是師長以愚鈍的觀念隨順私情去教育弟子，一舉一動全都會造下無邊惡業；師徒一同墮入三惡道苦境之中，那種慘痛就如同被倒懸在虛空一樣難受。（《孟子》說過：「在當今這時代，萬乘之尊的大國若是能施行仁政，人民的欣喜雀躍，就像是被解開了倒懸之苦一般。」）

【1013-0003】資持記/04c_上三#50
【原文】下二句勸修彰益。師名中，問標三名。師是華言，義通二師，文指和尚。答中初句略答。非此本有，故無正翻。顯下諸文，皆義翻耳。善下，引示，初引《見論》。師即和尚。彼因瞿陀沙彌為育王說法，王以八分食供養；沙彌云：迴與我師及闍梨；王問二名，沙彌隨答。文引答詞。
【譯文】下面兩句話是勸導大家依律修持，以彰顯殊勝的功德利益。在「解釋師長名義」中，提問中標指了三個名稱。「師」是此方震旦的漢語，義理上通稱和尚與阿闍梨兩位大師，在律文中則專指和尚。回答中第一句是扼要的總答。因為這個概念並非震旦本土原本就有的，所以沒有完全對等的正統翻譯。這也表明下文引用的種種經文，全都是依照義理所作的靈活翻譯罷了。下文「善……」以下是引經據論予以開示，首先引用《善見論》。「師」就是指和尚。那是起因於瞿陀沙彌為阿育王宣講妙法，阿育王拿出八份上等美食供養沙彌；沙彌推辭說：「請將這些美食轉供養給我的和尚及依止阿闍梨」；國王便詢問這兩個名稱的意涵，沙彌隨即作了解答。律文引述的就是當時沙彌回答的話。

【1013-0004】資持記/04c_上三#51
【原文】無罪者，令無所犯故；共於者，兼彼和尚故。論下，會上師名。初《論傳》者，諸記並云《見論》及〈法顯傳〉，疑是一文。外國者，中梵自指五天之外。次引《四分》。呵和尚者，即云：我犯戒和尚不呵，不犯戒亦不知等，如後具引。三引《了論》。正本者，中天語也。
【譯文】所謂「無罪」，是指和尚能教導弟子免於造作一切戒律過犯；所謂「共於」，是指阿闍梨兼領了和尚部分教化的責任。在《論》下文，會通上述「師」的各部名稱。首先提到的《論傳》，歷代諸家筆記都認為是指《善見論》與《法顯傳》，懷疑本是一部文獻。所謂「外國」，是天竺中印度對五天竺以外邊遠國家的自稱。接著引用《四分律》。所謂「呵責和尚」，就是弟子抱怨說：「我犯了戒和尚不呵責我，我不犯戒和尚也一無所知」等等，就如後面所詳細引述的那樣。第三是引用《明了論》。所謂「正本」，是指中印度正統的梵音梵語。

【1013-0005】資持記/04c_上三#52
【原文】準《疏》本音鄔波陀耶。彼云《明了論疏》，稍近梵音，猶乖《聲論》；余親參譯，委問本音，如上所述。即下，點示邊語。《疏》云：如昔人解和中最上，此逐字釋，不知音本。四引相傳。糾猶舉也。《疏》云阿闍梨者，亦訛略也；如梵天音阿遮利耶，唐翻教授。五引《雜含》。示通邪正。
【譯文】依照《戒疏》所考證，最根本的梵音應當是「鄔波陀耶」。《戒疏》說：《明了論疏》的音譯稍微接近正統梵音，但依然違背了梵語《聲論》的聲韻法規；我（道宣律師）曾親自參與譯場，詳細諮詢叩問過西方三藏法師關於根本梵音的發音，正如上面所考定記述的那樣。下文「即……」，是點明指出古來譯語屬於邊方俚俗的方言。《戒疏》說：如同往昔的古德解釋為「力生」或「知罪知否」，甚至解作「大眾僧和合之中地位最上者」，這都是望文生義、逐字穿鑿的附會解釋，根本不知道原本梵音的字根意涵。第四是引用歷代相傳的通俗說法。「糾」是舉發、檢校糾察的意思。《戒疏》說「阿闍梨」這個稱呼，也是音節訛誤簡略之後的叫法；如果依照色界天神所傳的純粹梵音應當念作「阿遮利耶」，唐朝正確的翻譯稱為「教授」。第五是引用《雜阿含經》，以此表明這個名號可以通貫外道邪師與佛門正法之師。

【1013-0006】資持記/04c_上三#53
【原文】已上且引諸出不同，華梵二音，準《疏》為定。資名中。以師望資，猶弟猶子；以資望師，如兄如父。祖師義釋，獨出今文；諸宗製撰，率多承用。總相攝者。通論彼此心相向慕。對下共行別行，事條各異，故云總也。《六方禮經》。佛世有長者名尸迦羅越，早起六方各禮四拜；
【譯文】以上暫且引證了各部經論中互有出入的翻譯，至於漢語梵音的究竟考定，應當完全以《戒疏》的正論作為最後準則。在「解釋弟子名義」中：若是從師長的視角來看望弟子，弟子就如同自己的親弟弟或親生兒子一樣；若是從弟子的視角來看望師長，師長就如同自己的親哥哥或親生父親一般。祖師以親情天倫來作這番義理發揮，是獨特創見於今日這部律鈔之中；後世佛教各宗各派的著述立論，大多直接沿襲承用了這個精闢觀點。所謂「總體相互攝受」，是普遍探討師徒雙方在心靈深處如何彼此仰慕、互相關懷。這與下文所開展的「師資共行」與「各自別行」中各條具體事務的行持互不相同，所以稱之為「總相」。《六方禮經》中記載：佛陀在世時，有一位名叫尸迦羅越的長者子，每天清晨起來向東、南、西、北、下、上六個方位各自禮拜四拜；
