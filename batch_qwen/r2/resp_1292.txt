以下逐段核對，先講**跨段的通則性問題**（這幾類幾乎每段都有），再列**各段的具體毛病與建議譯法**。整體理解方向大致不錯，主要問題出在「引號失真」「自行增字釋義」「幾處實詞誤讀」。

---

## 一、通則性問題（建議全面修訂）

**1. 引號內自造文句（最嚴重的系統性毛病）**
元照的行文體例是「**某字下**」「**故云某某**」，引的是《行事鈔》原文的字面。譯文卻把「解釋後的白話」放進引號，變成假引文：

| 原文所引 | 譯文引號內容 | 問題 |
|---|---|---|
| 故云**亦須**等也 | 「亦必須研讀」 | 原文只有「亦須」二字 |
| **後終**謂比丘亡時 | 「在後臨終」 | 憑空多出四字 |
| 故云**通用** | 「通用諸部」 | 增字 |
| **衣亦爾**者 | 「衣物亦是如此」 | 白話當原文引 |
| **差死**謂或差或死 | 「痊癒或亡故」 | 同上 |
| 與**究竟**者 | 「至終局者」 | 同上 |
| 故云**依律** | 「依循本律」 | 同上 |

建議一律：**引號保留原字詞，白話解釋放在引號外**。例如「所以（鈔中）說『亦須……』等語」「所謂『後終』，指的是比丘命過之時」。

**2. 未標記的增字釋義**
「修為」「貪染」「（難以伺候的表現）」「蛇」「純粹」「發願」「共營」等，都是原文沒有的判斷或限定。有些還改變了原意（見下）。若要保留，應加括號或「意指」標示為譯者補充。

**3. 語域、敬語不當且不一致**
- 「圓寂」：原文只是「死」「命過」「身死」，且此處泛指出家人（含奴婢之主），用「圓寂」過度抬高，又與同段「亡故」混用。建議統一作「命過／亡故」。
- 「私囊」：原文「入己」是中性的律學判定語（歸己所有），譯成「私囊」帶貪墨貶義。
- 「命令大家依循」：「令」在此是「勸令、教令」，不是命令語氣。

**4. 科判語處理不統一**
「四中／第五／若下／次科／注中／初科／指略中」是元照的科文標記，譯文時而「在第四項中」、時而「在第五類中」、時而「在『指示從略（指略）』中」，體例凌亂。建議統一格式，如「〔科〕第四門中」「〔科〕指略中：初、顯略」。

**5. 「注」與「儀」應交代清楚**
- 「注」指 **《行事鈔》道宣自注（夾註）**，不是泛泛的「註解」；譯文「註解特別加以決斷」易被誤會為他人注釋。
- 「儀」首次出現（第2段）宜標全名：道宣 **《量處輕重儀》**。

## 二、逐段問題

### 【1292-0001】
1. **「即準量也」→「依照此一容量尺寸作為準則」：誤讀。**
 「準量」是「作為準則來衡量（輕重）」，與容量、尺寸無關。
 建議：「《十誦律》所作的判定，即可作為（衡量輕重的）準則。」
2. **「須量亡者生乎所業」→「所從事的修為」：偏移。**
 「所業」指生平所作所為（此處正指世俗營為），「修為」暗示道業修持，與上下文「附俗、樂世法」相牴。改「生平所作的行業」。
3. **「園果等物，因而引之，正判養生之具故」：因果倒置。**
 原意是「因為（論文）正判的是養生之具，所以順便把園果等也引來」；譯文變成「園果是用來判定……的器具」，不通。
4. **「此中正取養畜具耳」→「正在於選取養育畜生的器具」**：讀來像在挑選實物。應作「此處只取『畜養牲畜之具』這一義」。
5. 「莊嚴華麗章句」文句不順，宜作「用來修飾文辭章句」。

### 【1292-0002】
1. **「入私己者，謂還彼也」：譯文前後打架。**
 前半「私物歸入私己」、後半「歸還給奴僕自己」，主體不一。原意應是「（律云）『入私己』，是說還給奴婢本人（聽其自主）」。另「判奴物」的「物」被漏掉，宜作「判定奴婢（及其物）的歸屬」。
2. **「若能給盡形」／「若所給盡形」的對比沒譯出來。**
 這是關鍵對句：前者「若（奴婢）能終身供給（不限定某一位主人）→ 隨僧處分」；後者「若所供給的期限只到（原主人）盡形 → 主死後任意去留」。譯文兩句都写成「發願……」，且第二句「發願供養者僅限於亡僧在世之期」主語錯置（受限的是**供給期限**，不是「供養者」）。
3. 「後情自改」宜點明主體：「（奴婢）後來的心意自然改變」。
4. 「依本入僧」→「依照根本歸入僧團常住」語意含糊，應作「依其本來所屬，仍歸入僧團」。
5. 「律據一向」→「律文只就一往（一概）而言」；「此五」是**五種情形**，不是「五種原則」。
6. 「前僧既死」譯「圓寂」，見通則3。

### 【1292-0003】
1. **首句主體混亂。**
 「同活取入己者，謂任主僧也」是說：律文「同活者取入己」一句，指（奴的遺物）**聽任主僧收取歸己**。譯文寫成「共同生活營生者將遺物收取歸入私囊」，動作主變成了同活者，與後半自相矛盾，且「私囊」貶義。
2. **「不同利共營」自相矛盾。**
 原文只作「不同利」（不與僧同財利），「共營」是硬加上去、意思相反。直接作「不同利」。
3. **〔謂盡主形〕→「指服侍主人至死」語意游移**（誰死？）。應作「指以主人的一生為期」。
4. 「不可攝入己」宜補主體：「（主僧）不能收歸自己所有」。

### 【1292-0004】
1. 引號問題二處：「依循本律」應作「依律」；「在後臨終」應作「後終」。
2. 「賜姓從良」→「回復良民身分」：「回復」暗示原本為良，原意是**由賤籍轉為良民**，改「賜姓放為良民」。
3. 「通無分限」宜作「一概沒有（約定的）期限分齊」，比「沒有明確約定界限」貼切。
4. 「湯九」為「湯丸」之訛，譯作「湯藥丸劑」正確，可加校註。

### 【1292-0005】
1. **「心斷清淨」不宜逕譯為「斷除貪染」。**
 這是《母論》成語，宜保留原語再釋：「論說『心斷清淨』——（對食之）心斷則成淨」。「貪染」屬推測性增字，且此處「心斷」所指（亡者抑看病者、貪心抑希望心）應覆核前後文，必要時加註存疑。
2. 「分衣語通」→「語意涵蓋廣泛」失焦。應作「『分衣』一語通於前後兩種情形，所以（鈔）自注加以抉擇」。
3. 「衣亦爾」引號同上，保留原三字。
4. 「請已命過」宜補主體：「（施主）已作請施之後，比丘命過」。
5. 「指略」是科名，譯文「在『指示從略（指略）』中」疊床架屋，直接作「〔科〕指略中：初、顯略」。

### 【1292-0006】
1. 引號二處：「亦必須研讀」→「亦須」；「通用諸部」→「通用」。
2. **「澡罐」→「洗滌罐」不詞。** 應作「澡瓶（洗手、洗浴用的水罐）」。
3. 「諸部互有廢立」→「互有廢棄與創立」生硬，宜「各部律對同物或廢或立（取捨不一）」。
4. 「警蟲獸」譯成「驚驅蛇蟲野獸」，「蛇」為添字；可作「驚走蟲獸（免於踩踏）」。
5. 「正表道儀」→「純粹是表彰修道的威儀」尚可，但「道儀」更近「修道者的儀相／法器表法」，可微調。

### 【1292-0007】
1. **「五事立約病者」的括號「（難以伺候的表現）」是原文所無的價值判斷，應刪。**
 原意僅：這五事是**就病人（的情況）而安立**（與看病五德相對）。
2. 「賞勞」是科名（賞賜看病人之勞），譯「勞績賞賜」生硬，宜「賞勞（賞看病者）」。
3. 「初科顯德」→「顯明看護者的功德」：此「德」是**德行條件（五德）**，非「功德」，改「顯明看病者的德行」。
4. 「令依次師」→「命令大家依循」語氣過重，改「勸令依第二師之說」。
5. 「七門」宜註明是《輕重儀》的七門分類，非泛指「七個門類」。

### 【1292-0008】
1. 引號二處：「痊癒或亡故」→「差死」；「至終局者」→「究竟」。
2. 「五行不出三業二利」→「不出於……」易誤讀為「不源自」。應作「五德之行不超出三業、二利的範圍」。
3. 「直到結束到底」贅字重疊，刪為「直到最後（究竟）」。
4. 「與究竟者，由存始終」建議：「（《五分》）給與看病到『究竟』者，是因他自始至終用心照護，即行持圓滿之故。」
5. 「前簡上下」的「上下」所指（上物下物／上品下品／上眾下眾）譯文含糊帶過，宜依前後文確定後補註。

## 三、需覆核、不宜遽定的三處

1. **「即準量也」**：若第四門所判恰為度量衡器，則「量」或有雙關；但依一般用法仍以「準則衡量」為是。請查該門《十誦》原文再定。
2. **「入私己／謂還彼也」的「彼」**：指奴婢本人或本主，須看《四分》原文與《輕重儀》五例的對應，譯文目前兩說並陳而不自知。
3. **「心斷清淨」**：如上，宜保留原語並加註，不要單一義定譯。
