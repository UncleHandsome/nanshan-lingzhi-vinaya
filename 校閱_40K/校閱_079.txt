# 校閱材料　第079檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【079-0001】02_戒疏/02b_卷一上之二#83
【原文】【記】次科，深廣喻中，初文。二釋：初、周徧義；二、離染義。「眾善」即世出世間凡聖行業。「體周法界」者，就境示量也。「律」下，會釋。初指「律序」，彼云：「譬如有死屍，大海不容受，為疾風所漂，棄之於岸上。諸作惡行者，猶如彼死屍，眾所不容受，以是當持戒。」此即但有「清澄」一義。「戒」下，會今文，謂文偏而義具。
【譯文】【記文】接著下一科，在深廣海喻中，這是第一段文。此處有兩種解釋：一是遍周周遍之義；二是脫離染污之義。「眾善」就是指世間與出世間的一切凡聖行門。「體周法界」，是就戒法所緣之境來顯發其廣大體量。「律」字以下，進行會通解釋。首先指出「律序」，該處說道：「譬如有一具死屍，大海絕不接納包容，立刻會被迅疾的風浪漂送，丟棄在海岸之上。凡是造作惡行的人，就像那一具死屍，僧團大眾絕不接納包容，正因如此應當持守戒律。」這就是只有「清澄」這一個含義。「戒」字以下，會通眼前的《戒本》文句，說明經文字面上雖有偏重，但深意卻完全具備。

【079-0002】02_戒疏/02b_卷一上之二#84
【原文】【疏】然「涯」之一字，世濫者多。或「山」下安「厓」，則山邊險處；若「水」右安「厓」，則水邊畔際。今喻海界，不可兼山。或名為「儀」，傍通非正；楚夏之異，何得妄言？應從改正，「五佳反」也。乃是世語，隨俗無過；脫經學識，不涉上迷。
【譯文】【疏文】然而「涯」這一個字，在世間混淆誤用的人很多。如果是在「山」字下方安置「厓」字（作「崖」），那就是山邊險峻的懸崖；如果是水字旁右邊加上「厓」，那才是水流的邊際涯岸。如今是用來比喻大海的邊界，絕不可附帶從山字旁。有人把它讀為「儀」，這只是方言旁通的訛音而非正讀；南腔北調的方言差異，怎能隨意胡亂妄言？應當依循正音改正，為「五佳切（發yá音）」。這本是世俗語言，隨順大眾習慣固然沒有大礙；但倘若經過嚴謹的學識考究，就不該陷入上述的迷惑。

【079-0003】02_戒疏/02b_卷一上之二#85
【原文】【記】次科，初定字體。字、義兩別，不可相濫。「或」下，正語音。「楚夏」，謂南北音異。「佳」字音「街」，則與山「崖」字別音同；今時略韻，亦通「厓」字。「乃」下，示意。上二句遮情，下二句勸學。「脫」，猶或也。
【譯文】【記文】接著下一科，首先考定義理字體。文字與意義各不相同，不可互相混淆。「或」字以下，矯正字音與讀法。「楚夏」，是指南方與北方的語音差異。「佳」字讀如「街」，與山「崖」字在形體上雖別但音相通；如今的通俗韻書，也常與「厓」字相通。「乃」字以下，說明立意。上面兩句阻斷無端的爭論，下面兩句勸勉後學精勤考證。「脫」，在此作「倘若、或者」解釋。

【079-0004】02_戒疏/02b_卷一上之二#86
【原文】【疏】二、如寶喻中。「寶」為世重，「求」得「無厭」。欲明戒海非但清澄，兼生道品，三聖所重，故言「寶」也。常行志求，無時暫息，故云「無厭」也。
【譯文】【疏文】第二、在如同珍寶的譬喻中。「珍寶」為世間所尊貴珍重，「求取」獲得之時「永不滿足」。此處旨在說明戒海不僅僅是澄清純淨，更能生出三十七道品，為三乘聖人所尊崇珍重，所以稱作「寶」。恆常精進立志求索，沒有片刻稍作停歇，所以稱作「無厭」。

【079-0005】02_戒疏/02b_卷一上之二#87
【原文】【記】次出寶喻，正釋中，初科。「道品」者，約行次第，三十七品。約人進位，大小賢聖。
【譯文】【記文】接著引出如寶之譬喻，在正解的文句中，這是第一科。「道品」，若就修行的次第來說，就是三十七道品。若就修行者的階位來說，則包含小乘與大乘的賢聖各階位。

【079-0006】02_戒疏/02b_卷一上之二#88
【原文】【疏】然戒寶豐積，贍周生類。故使前聖果圓，後賢因滿。引生來業，展轉住持，眾生無盡，戒寶無竭也。據文，能求之懷也；從義，所求無限也。
【譯文】【疏文】然而戒寶豐盈蓄積，能夠廣大周濟救度一切眾生。因此能使過去的聖人道果圓滿，後世的賢人修行福慧具足。它引導啟發生起未來的功德業行，展轉傳承住持正法，眾生無窮無盡，戒寶也永遠不會枯竭。若依照文字，是指能求索之人的無限渴仰之情；若順從深意，是指所求取的戒寶本就無窮無盡。

【079-0007】02_戒疏/02b_卷一上之二#89
【原文】【記】次文。初句明體量之廣，欲句顯被物無遺。「故」下，示無窮之益。「前聖」、「後賢」，並通三乘。上是自行，「引」下，明化他。「來業」謂戒善功德。法體常住，在人所興；人相繼接，法何有盡？有同世寶，滋長無窮。「據」下，合文意。偈云「無厭」，正約「能求」；然由「無限」，故使不厭，以示此科「從義」釋故。
【譯文】【記文】接著第二段文。首句說明戒體含攝的廣大，次句顯明戒法化度眾生毫無遺漏。「故」字以下，展現無窮無盡的利益。「前聖」與「後賢」，均通括聲聞、緣覺、菩薩三乘。上面是屬於自利修行，「引」字以下，闡明化導利他的功用。「來業」是指戒善的功德之業。戒法之體性是常住的，全靠人力來振興發揚；人若能代代相傳相續，法又怎麼會斷絕？如同世間的珍寶，能夠滋生增長無有窮盡。「據」字以下，會合偈文之義。偈頌說「無厭」，正是針對修行者「能求的心境」而言；然而正因為戒寶「無限」，所以才使人永不厭足，以此顯示本科是「依循義理」所作的解釋。

【079-0008】02_戒疏/02b_卷一上之二#90
【原文】【疏】又寶有二能：一、現除貧苦者，顯戒現止業非，能感名利，交免三塗之貧苦也；二、資成形命者，顯戒近獲人天，遠成五分。斯益既厚，故「求無厭」。
【譯文】【疏文】再者，珍寶具有兩種功能：第一、現世能消除貧窮苦難，這比喻戒律在現世能止息惡業過非，感得福報美名，並徹底免除墮入地獄、餓鬼、畜生三途的貧乏痛苦；第二、能夠滋養成就身形與壽命，這比喻戒律近處能感得人道天道的善果，遠處能圓滿戒、定、慧、解脫、解脫知見這五分法身。這項利益既然如此深厚，所以令人「求無厭足」。

【079-0009】02_戒疏/02b_卷一上之二#91
【原文】【記】三中，二義。初句標喻，「顯」下，法合。初除現生貧苦，止惡積善故「不貧」，人天聖道故「無苦」。「交」，俱也。次義中，標喻法合，亦如上分。凡聖兩報，由戒資成，世出世別，故分「近遠」。「斯」下，雙結。
【譯文】【記文】在第三個層次中，包含兩種含義。首句標出譬喻，「顯」字以下，以法來會合譬喻。第一種功能是拔除現世的貧窮困苦，止惡積善所以「不貧」，獲得人天尊榮乃至解脫聖道所以「無苦」。「交」，就是都、俱備的意思。在第二種含義中，標出譬喻並以法會合，劃分方法也如同上面所述。凡夫的善報與聖人的道果，全都依賴戒律來資養成就，世間與出世間既然有別，所以劃分為「近果與遠果」。「斯」字以下，對這兩種功用進行雙重總結。

【079-0010】02_戒疏/02b_卷一上之二#92
【原文】【疏】問：「如經論說，海喻多種，今此偈中止列二者？」
【譯文】【疏文】提問：「正如經論中所說的，大海的譬喻有多種，如今這首偈頌中為何僅僅列出這兩種？」

【079-0011】02_戒疏/02b_卷一上之二#93
【原文】【記】問中。「多種」者，海有八德：一、漸深漸入；二、潮不過限；三、不宿死屍；四、百川來會，無復本名；五、萬派悉歸，而無增減；六、出眾珍寶；七、大身眾生所居；八、同一醎味。《戒本》上句可配初德，次句對第六，旁兼「清澄」，即是第三。欲顯戒文出二之意，故問申之。
【譯文】【記文】在提問的設問中。「多種」的意思，是指大海具備八種功德德行：第一、海水漸次深邃；第二、潮水漲落不逾越界限；第三、海中不住留死屍；第四、百川百河匯聚而來，不再保留原本的名字；第五、萬條江河悉數歸入，海水卻不增不減；第六、孕育出眾多奇珍異寶；第七、極大體型的巨海眾生所棲居；第八、海水皆具備同一種鹹味。《戒本》偈頌的第一句可以配屬第一種德行，第二句對應第六種德行，旁側兼具的「清澄」含義，就是第三種德行。為了顯發《戒本》偈文單單列出這兩項的深意，所以設立問答來加以申述。

【079-0012】02_戒疏/02b_卷一上之二#94
【原文】【疏】答：「作者知時，明喻舉要。初明深廣清澄喻，顯說戒儀專被行淨，如有纖過，非聽說之儀也。是以今初開宗，即明簡眾喻。眾成由行，能懷聖寶，故次辨求無厭喻。此二攝化始終，餘非要務，故略不敘。」
