# 校閱材料　第377檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【377-0003】03_業疏/02a_卷一之二#70
【原文】問：如說恣等眾法通下，人位分三，據緣應異，何者是耶？答：有多異。一人有少多；二對法三別；三約界通局，謂僧局別通也；四欲無欲異，僧秉不開，唯在結界，別人俱閉故；五別相異，僧中具三別，若對眾多人則無不與欲別，若對一人但有應來不來別，所以可知
【譯文】問：例如說戒、自恣等大眾法通融降下行辦，人數的位階分為三種，依據所具的因緣應當有所差異，具體有哪些呢？ 答：有許多差異。第一是人數有多寡的差別；第二是對應的法有三種差別；第三是依結界而言有局限與通融的差別，也就是僧眾大眾法局限於當界，個別之人作法則通於兩界；第四是有無「說欲」的差別，大眾僧秉法時不開許說欲的情形唯獨在結界羯磨（其餘大眾法皆開許說欲），個別之人作法時則完全閉塞不開許與欲；第五是個別相狀的差別，在大眾僧中具備三種個別差別相，若面對眾多人則沒有「不與欲」的差別，若面對一人則只有「應來而不來」的差別，其原由由此可知。

【377-0004】03_業疏/02a_卷一之二#71
【原文】三中，問意欲簡前通，使無濫故，通下對念，更兼本位，故云分三。答中五異：初二可解；三中僧局作法，別通兩界；四中說欲，僧唯不開結界，則顯餘法通開；五中僧具可知，眾多人中對首無欲，故但有二，心念無訶，故唯有一，將別對人以明有無，故兩云「若對
【譯文】在第三項中，提問的用意是想簡別前面的相通之處，使法相不致混淆失當，大眾法通融降至對首與心念，再加上原本的大眾位階，所以說分為三種。回答當中有五種相異：前兩種容易理解；第三種是僧團大眾局限在當界作法，個別之人則通於界內界外兩界；第四種是說欲受欲，大眾僧只有在結界時絕對不開許與欲，這就顯明其餘大眾法皆普遍開許與欲；第五種是大眾僧具足三種差別相顯而易見，在眾多人當中的對首法沒有與欲這回事，所以只有兩種差別相，心念法沒有口言反對（訶阻）這回事，所以只有一種差別相，這是將三種別相對照不同人位以說明有無，所以兩次說到「若對……」。

【譯文】第二、在僧尼相互作法當中：

【377-0006】03_業疏/02a_卷一之二#73
【原文】僧得被尼事，但有三：受戒、半月、出罪也。約法分齊，則一白問難、三番白四，自餘不行。其教授、自恣，非無互差互往，然是各行眾法，至彼此部，無面對作，不同前三兩部通秉，故文云「二十眾受」也。《五分》云：「四十人出罪，減一不成」等。然上局僧唱，故約一相為言耳。律云：「僧不得為尼作羯磨令受，誦已，當部作之
【譯文】比丘僧得以加被比丘尼的僧事，只有三種：受具足戒、半月摩那埵（懺殘罪）、以及出罪。就法的範圍界限而言，只有一次單白問難、三次白四羯磨，其餘的法則不能由比丘僧直接為尼舉行。至於派遣教授、自恣，並非沒有彼此互差、互往來之事，然而那是在各部僧中分別舉行大眾法，前往對方所屬部派時，並不是面對面直接作法羯磨，不同於前面那三種是兩部僧共同主持秉持，所以律文說「二十眾（僧十人、尼十人）前受具足戒」。《五分律》說：「四十人（僧二十人、尼二十人）為尼出罪，少一人都不能成就」等。然而上面是局限於比丘僧作唱導宣告而言，所以只是就單一相狀來說罷了。律文說：「大僧不得為尼僧作羯磨（指說戒等），若尼不解誦戒，開許令其至大僧中受學誦習，誦習通達之後，回歸尼寺由尼僧本部自行作法。」

【譯文】問：這四種僧團在主持秉行僧法時，可行與受阻的相狀究竟是如何？

【377-0017】03_業疏/02a_卷一之二#84
【原文】次廣問答明通塞中，初問四僧即四位僧
【譯文】其次在廣泛的問答中闡明可行與受阻，最初提問的「四僧」，指的就是四個位階的僧團。

【377-0018】03_業疏/02a_卷一之二#85
【原文】解云：但據四人，尚通秉法，何況餘三？又人解云：四人作務，通秉眾法，以體成僧故也。如說戒、滅諍、形法二同、觸惱諸制，謂單白也；差人被緣、受日處分，謂秉日（）二也；七法治人、諫證等法，謂秉白四也。故法雖多，以二攝盡，謂說戒、羯磨，四人通持，意可見也
【譯文】有人解釋說：僅僅依據四人僧，尚且能夠通融秉持各項僧法，何況其餘三種僧呢？又有人解釋說：四人僧辦理事務，能夠通融秉持各項大眾法，因為其自體已構成僧團的緣故。例如說戒、平息爭事（滅諍）、形同羯磨與法同羯磨、觸犯惱亂等各項處分羯磨，這是指單白羯磨；差遣人員加被機緣、受日處置，這是指秉持白二羯磨；以七種羯磨治罰違紀之人、諫責作證等法，這是指秉持白四羯磨。所以法雖然繁多，用兩大類便能收攝殆盡，也就是說戒與羯磨，四人僧都能通融主持，其意旨由此可見。

【377-0019】03_業疏/02a_卷一之二#86
【原文】答中二解意同，但初師粗略，故復引後解。文中但敘四人，餘三可見，略舉三法，復據二攝，證上四人通秉一切
【譯文】在回答當中，兩種解釋的意思是相同的，只是前一位論師說得粗略，所以又引述後一種解釋。文中雖然只敘述了四人僧，其餘三種僧的涵義便可比照推知；此處粗略舉出三種法（白、白二、白四），又依說戒與羯磨兩類來收攝，用以證明上面所說四人僧可以普遍秉持一切僧事。

【377-0020】03_業疏/02a_卷一之二#87
【原文】問：初僧既通，何以文中除三法耶
【譯文】問：第一種四人僧既然能通融秉持一切，為何律文中卻排除了三種法呢？

【377-0021】03_業疏/02a_卷一之二#88
【原文】第三難中，文既簡除，通持安在
【譯文】在第三個難問中，律文既然明確簡別排除，所謂的「普遍主持秉持」又體現在何處呢？

【377-0022】03_業疏/02a_卷一之二#89
【原文】答：此除前事，不除法也。以自恣、受、懺境緣須具，故倍三人，除三單白、二白四法，非謂餘事不通四人。故文云：「一切羯磨皆作。」五人通論通秉三法，約事就用，但據自恣一白、邊受二白，是五人僧用。若作餘法，收在初四。十人僧者，但一白四。二十人僧，但一出罪。自餘三法，皆四人僧攝之
【譯文】答：這只是排除了特定的機緣情事，並不是排除這種羯磨法門本身。因為自恣、受戒、懺悔僧殘罪所面對的境緣必須完備，所以成倍增加三人以上，從而排除了三次單白、二次白四之法，並不是說其餘各項僧事都不能由四人僧通融舉行。所以律文說：「一切羯磨都可以舉行。」就五人僧通論而言，普遍能秉持三種法（單白、白二、白四），但若就具體事相與功用而論，只有自恣的一次單白、邊地受戒的二次單白，屬於五人僧的特定功用。如果舉行其餘之法，仍收攝在最初的四人僧中。十人僧的特定功用，只有授具足戒的一次白四羯磨。二十人僧的特定功用，只有出罪的一次白四羯磨。其餘的一切僧法，全都是由四人僧所收攝。

【377-0023】03_業疏/02a_卷一之二#90
【原文】答中分二：初釋四人除法所以。初二句略示法自通秉，事有不行，故但除事耳。「以」下委釋自恣、受戒、懺（即出罪），倍三人者，五十、二十。除三單白（自恣和僧一白）、（受戒召入對問二白）、二白四者（正受一白四、出罪一白四）。若自恣差五德、受戒差教師、出罪中覆藏六夜，竝四人法，不在所除，次科自見。舊記解此差謬，叵言學者相承，至今傳誦，恐亂正解，不復別破也。下指「文云」，即除法後續有此語，故知除此通餘一切。「五人」下，二簡三位所秉分齊，如文次列，止有五法，自餘一百二十九法，皆歸初位
【譯文】回答當中分為兩部分：首先解釋四人僧排除三種法的原因。起初兩句簡略說明羯磨法門本身本自通融秉持，只是特定的事相不可行，所以只是排除特定的事相罷了。「以」字以下詳細解釋自恣、受戒、懺悔（即出罪），所謂成倍增加於三人者，指增為五人、十人、二十人。排除的三次單白（自恣和合僧眾的一次單白、受戒召受戒者入僧中及當面詢問的兩次單白）、兩次白四羯磨（正式授戒的一次白四羯磨、出罪的一次白四羯磨）。至於自恣時差派具足五德之人、受戒時差派教授師、出罪當中的覆藏與六夜摩那埵，全都是四人僧所行之法，並不在排除之列，下一科自然會見到。舊有的注記解釋此處錯謬百出，難以形容，學人代代相承，至今仍傳習誦讀，唯恐擾亂正確理解，此處不再個別予以破斥。下文所指的「文云」，就是排除特定法之後接續有這句話，由此可知除了這幾件事之外，普遍通達其餘一切事。「五人」以下，第二是簡別後三種位階所主持秉持的範圍界限，如同文中依次排列，只有五種特定的法，其餘的一百二十九種羯磨法，全部歸屬於最初的四人僧位階。
