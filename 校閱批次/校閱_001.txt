# 校閱材料　第001檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【001-0041】01_行事鈔/00_卷首#41
【原文】第一序教興意。夫至人興世，益物有方；隨機設教，理無虛授。論云：依大慈門，說於毘尼。故律云：世尊慈念故，而為說法。二為對外道無法自居，顯佛法人尊道高，故制斯戒。觀下律中，凡所制者，並懷異術。故文云：若不撰結，則令外道以致餘言。三為對異宗故來。宗則有其多別：且如薩婆多部，戒本繁略，指體未圓；接俗楷定於時數，御法例通於無準。今曇無德部，人法有序，軌用多方；提誘唯存生善，立教意居顯約。
【譯文】第一，說明教法興起的用意。至人（佛陀）出現於世，利益眾生有其方法；隨眾生根機施設教法，道理上不會有虛妄的給予。《論》中說：依大慈之門，宣說毘尼。所以律中說：世尊因為慈念的緣故，而為眾生說法。第二，是為了對治外道沒有正法可依卻自居有法，彰顯佛法中人是尊貴的、道是高超的，所以制定這些戒。看下文律中，凡所制定的，都含有特殊的對治方便。所以文說：如果不加以撰述結集，就會讓外道藉此致其餘的言論。第三，是為了對治不同宗派而來的問題。宗派有許多差別：譬如薩婆多部，戒本有繁有略，指陳戒體並不圓滿；接引俗眾則固定於時節數目，統御教法則一律通用而沒有準則。現在曇無德部，人與法都有次序，軌則的運用有多種方式；提攜誘導只在於使人生善，立教的用意在於明顯而簡約。

【001-0044】01_行事鈔/00_卷首#44

【譯文】第一，從遮戒與性戒來區分：性惡的性戒通於化教與制教，遮戒則是因過失才生起的。然而性戒的文字寬緩而義理急切，就是說隨著各種重戒，都有開緣的明文；文字雖是開緣，開緣實際上仍會結成犯；縱然成了持戒，持守它實在很難。例如淫戒，三時（前、中、後）都不可有樂受；毀訾語戒（惡口罵詈戒），則始終都要慈心救護；這些既然是根本的貪與瞋，怎麼能禁制其心而無放逸？所以知道其義在於急切地防護！遮戒則一概先加制止，若有益便開許；開了之後過失興起，又再令其制止；這豈不是為了保存在俗的教化，恐怕人墜入枉曲的坑陷？大慈施設教法，用意只在於檢點過失，所以《毘尼母論》具足建立緩、急兩種儀則，讓人循此去通盤觀望。

【001-0053】01_行事鈔/00_卷首#53
【原文】第三對事約教判處意。自佛法東流，幾六百載，諸師穿鑿，判割是非；競封同異，不可稱說。良由尋討者不識宗旨，行事者昏於本趣。故須學師必約經遠，執教必佩真文。何事被於毀譏，豈復淪乎蚩責？今判其持犯，還約其受體；體既《四分》而受，豈得異部明隨？猶恐不曉大綱，更示其分齊。謂輒將己所學者，判他持犯；脫罹愆失，其唯不學愚癡！今通立定格，共成較準，一披條領，釋然大觀。

【001-0055】01_行事鈔/00_卷首#55
【原文】今立《四分》為本；若行事之時，必須用諸部者，不可不用。故《善見》云：毘尼有四法，諸大德有神通者，抄出令人知。一本者，謂一切律藏。二隨本。三法師語者，謂佛先說本，五百羅漢廣分別流通，即論主也。四意用，謂以意方便度用及三藏等廣說也。先觀根本，次及句義，後觀法師語；與文句等者用，不等者莫取。正文如此。
【譯文】現在以《四分律》為根本；如果在實際行事時，必須用到諸部（其他部派）的，就不可不用。所以《善見論》說：毘尼有四種法，諸位有大神通的大德把它抄錄出來讓人知道。第一是「本」，就是一切律藏。第二是「隨本」。第三是「法師語」，就是佛先說了根本，五百羅漢廣泛分別而流通，也就是論主。第四是「意用」，就是以心意方便度量運用，以及三藏等廣為宣說。先觀根本，其次及於句義，最後再觀法師語；與文句相等的就用，不相等的就不要取。正文就是這樣說的。

【原文】夫戒者以隨器為功，行者以領納為趣。而能善淨身心，稱緣而受者，方克相應之道；若情無遠趣，差之毫微者，則徒染法流，將何以為道之淨器？為世良田，義復安在？是以凡欲清身行徒，遠希圓果者，無宜妄造；必須專志攝慮，令契入無滯。故經云：雖無形色，而可護持，斯文明矣！何者？但戒相多途，非唯一軼；心有分限，取之不同；若任境彰名，乃有無量；且據樞要，略標四種：一者戒法，二者戒體，三者戒行，四者戒相。

【001-0099】01_行事鈔/01a_卷上之一#17
【原文】言戒法者，語法而談，不局凡聖。直明此法，必能軌成出離之道，要令受者信知有此。雖復凡聖通有此法，今所受者，就已成而言，名為聖法。但令反彼生死，仰廁僧徒，建志要期，高栖累外者；必豫長養此心，使隨人成就，乃可秉聖法在懷，習聖行居體，故得名為隨法之行也。
【譯文】所謂「戒法」，若純粹就其法門自體而言，並不局限於凡夫或聖人。直接說明此法，必然能夠範軌並成就出離生死之道，關鍵是要讓受戒者深信確知有這項解脫之法。雖然凡夫與聖人共同具備此戒法之理，但現在受戒者所納受的，就其圓成之功德而言，稱為「聖法」。只要能夠背離生死流轉，仰慕加入僧伽行列，立下誓願要期，高蹈於塵勞繫縛之外；受戒者必須預先長養這種出離向道之心，使戒法隨著受戒者自身的願力而成就，如此方能將聖法秉持於懷抱之中，將聖行修習於自體之內，所以稱之為順應戒法的修行。

【譯文】第四說明「戒相」。當威儀操行修習圓滿，隨順日常一切施設作為，一舉一動都能合乎戒法軌度，美好德行外彰光顯，所以稱為「戒相」。

【001-0103】01_行事鈔/01a_卷上之一#21
【原文】此之四條，並出道者之本依，成果者之宗極，故標於鈔表，令寄心有在；知自身心，懷佩聖法，下為六道福田，上則三乘因種；自餘紹隆佛種，興建法幢，功德不可思議，豈唯言論能盡！直引聖說成證，令持法高士，詳而鏡諸。就中分二：初明順戒，則三寶住持，辨比丘事。二明違戒，便覆滅正法，翻種苦業。但諸經論歎戒文多，隨部具舒，相亦難盡。今通括一化，所說正文，且引數條，餘便存略。
【譯文】這四條綱要，都是修道出離者根本的依憑，證得聖果者至極的歸宿，因此標列於本鈔卷首，使學人寄託發心有所方向；讓人明白自己的身心，已經佩帶奉持著出世聖法，向下可以作為六道眾生的福田，向上則是成就三乘聖道的因種；其餘延續光大佛法僧種、建立正法寶幢的不可思議功德，哪裡只是言語論述所能說得盡的！現在直接引證佛聖言教作為憑證，使秉持佛法的高尚之士，能夠詳審審察明鑑。其中分為兩部分：首先說明順從戒律，則三寶得以久住維持，辨析比丘應行之事。其次說明違背戒律，便會覆滅正法，反倒播下受苦的業因。然而諸部經論讚歎持戒的文句極多，若隨各部完全鋪陳，義相難以窮盡。現在綜括佛陀一代教化所說的正文，暫且引錄數條，其餘則予省略。

【001-0104】01_行事鈔/01a_卷上之一#22
【原文】初中分二。前約化教。後就制門。
【譯文】第一部分中又分為二：前半依據化教（通途教化之經論），後半依據制門（僧團戒律之制法）。

【001-0105】01_行事鈔/01a_卷上之一#23
【原文】初又分四。一就小乘經者。如《般泥洹經》明：佛垂滅度，世間無師，阿難啟請。佛言：比丘若能奉戒者，是汝大師，若我在世，無異此也。《遺教》等經並同斯示。然發趣萬行，戒為宗主，故經云：若欲生天等，必須護戒足。又如大地能生成萬物，故經云：若無淨戒，諸善功德不生。又云：依因此戒得有定慧。又經云：戒者，行根住持。即喻如地能生成住持也。
【譯文】化教中又分為四項。第一依小乘經典：如《般泥洹經》中所載：佛陀臨近滅度時，世間將失去導師，阿難尊者向佛啟請。佛陀說：「比丘若能奉持戒律，戒律就是你們的大師，這與我親自在世教導沒有任何差別。」《佛遺教經》等經也同樣作此昭示。而且發起趨向萬種善行，戒律是其宗主，所以經典說：「如果想要投生天界等善趣，必須保護好自己的戒足。」戒律又如大地能化育生成萬物，所以經典說：「若是沒有清淨戒律，一切善法功德皆不得生起。」又說：「依憑於此戒，方能發起禪定與智慧。」又經中說：「戒律，是一切行門善根的住持依託。」這就是以大地能化育生成與安住執持萬物作為譬喻。

【001-0106】01_行事鈔/01a_卷上之一#24
【原文】二小乘論，如《成實》云：道品樓觀以戒為柱，禪定心城以戒為郭，入善人眾要佩戒印。是故特須尊重於戒。《解脫道論．戒品》中，具多讚美，文繁不出。須者看之，戒則不羸。《毘婆沙》云：具戒足者，戒言尸羅，亦言行也，亦云守信，亦名為器。尸羅言冷，無破戒熱及三惡道熱故；亦名善夢，持者常得善夢故；亦名為習，由善習戒法故；亦名為定，若住戒者心易得定故；亦名為池，群聖所浴故；亦名纓絡，老少中年服常好故；亦名如鏡，由戒淨故無我像現故；又名威勢，如來在世有威力者，是尸羅之力故。餘如驅龍事，五百羅漢不能逐之，有一羅漢，但以護戒力故便即驅出，以輕重等持也！又戒名為頭，能見苦諦諸色，乃至知色陰等法故；能善護故，言守信也；能至涅槃城，故言行也；功德所依，名器也。尊者瞿沙說曰：不破義是尸羅義。如人不破足，能有所至。行者不破尸羅故，能至涅槃。
【譯文】第二依小乘論典，如《成實論》說：三十七道品的樓閣以戒為柱石，禪定內觀的心城以戒為外郭，要加入賢善之人的僧眾中必須佩帶戒法的信印。因此特別需要尊重戒律。《解脫道論．戒品》中，具備許多讚美之語，因篇幅繁多在此不引出。有需要的人可以前去參閱，持戒便不會羸弱動搖。《阿毘曇毘婆沙論》說：具備「戒足」的人，所謂「戒」，梵語稱為尸羅（śīla），也稱為「行」，又稱為「守信」，也稱為「器」。尸羅之義為「清涼」，因為沒有破戒所生之熱惱以及三惡道的火熱之故；又稱為「善夢」，因為持戒者常做好夢之故；又稱為「習」，因為妥善熏習戒法之故；又稱為「定」，因為安住於戒律者心念容易得定之故；又稱為「池」，因為是一切聖者沐浴淨化之處；又稱為「瓔珞」，因為不論老、少、中年佩戴，永遠莊嚴美好之故；又稱為「如鏡」，因為戒法清淨便能顯現諸法無我真相之故；又稱為「威勢」，如來在世時具備大威德力，即是尸羅的力量之故。其餘如同驅逐毒龍之事，五百位阿羅漢都不能驅逐牠，有一位羅漢，僅僅憑藉著護持戒律的力量，就立刻將毒龍驅趕出去，這是因為他對微細輕戒與根本重戒平等嚴持的緣故！又戒法被稱為「頭」，因為能藉此照見苦諦等種種色法、乃至徹知色陰等法之故；因為能善加守護，所以稱為「守信」；因為能到達涅槃城，所以稱為「行」；是一切功德的所依，所以稱為「器」。瞿沙尊者說：不破損、不毀壞，就是尸羅的意義。如同人的雙足沒有破損殘缺，就能走到想去的地方。修行者若不毀損尸羅，便能抵達大般涅槃。

【001-0107】01_行事鈔/01a_卷上之一#25
【原文】三大乘經者。《華嚴》云：具足受持威儀教法，行六和敬善御大眾，心無憂悔，去來今佛所說正法，不違其教；能令三寶不斷，法得久住。《大集》云：十方世界菩薩請佛為五滓眾生制於禁戒，如餘佛土，為法久住故。佛後許之，便制禁戒。《薩遮尼犍》云：若不持戒，乃至不得疥癩野干身，何況當得功德之身。《月燈三昧》云：雖有色族及多聞，若無戒智猶禽獸；雖處卑下少聞見，能淨持戒名勝士。《涅槃》云：欲見佛性證大涅槃，必須深心修持淨戒；若持是經而毀淨戒，是魔眷屬，非我弟子，我亦不聽受持是經。《華嚴》偈言：戒是無上菩提本，應當具足持淨戒，若能堅持於禁戒，則是如來所讚歎。故重引之，令誦心首。
【譯文】第三依大乘經典。《華嚴經》說：圓滿具足受持一切威儀教法，實行六和敬善巧統領大眾，內心沒有憂慮悔恨，對於過去、未來、現在諸佛所說的正法，不違背其教誨；如此能使三寶傳承不絕，正法得以長久住世。《大集經》說：十方世界的菩薩懇請佛陀為五濁滓穢的眾生制定戒律，如同其餘佛國淨土一樣，是為了讓正法久住之故。佛陀隨後答應了請求，便制定了禁戒。《薩遮尼犍子經》說：如果不持守戒律，將來連長滿疥癬的野干（狐狼類）之身都得不到，更何況能得到具足功德的尊貴身軀。《月燈三昧經》說：雖然容貌端正、出身名族且見多識廣，如果沒有持戒與智慧，依然如同禽獸；雖然出身卑微、見聞寡少，但能清淨持守戒律的人，就稱為殊勝之士。《大般涅槃經》說：想要照見佛性、證悟大般涅槃，必須以深切懇切之心修持清淨戒律；若是受持這部大乘經典卻毀壞清淨戒律，這人便是魔王眷屬，不是我的弟子，我也不允許他受持這部經。《華嚴經》偈頌說：「戒是一切無上菩提的根本，應當圓滿具足持守清淨戒律，如果能夠堅定持守禁戒，這就是如來所讚歎之人。」因此在此重新引述，讓大家牢記誦持於心中。
