# 校閱材料　第1402檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1402-0001】04_比丘尼鈔/01b_卷上之上#4
【原文】第一擇眾者十誦云有十一人不足僧數謂睡眠比丘若聞白已睡者得成未白已前不足數亂語人憒閙人入定人瘂人聾人具二人狂人亂心人病壞心人樹上比丘等竝不足數伽論云有三人不足數重病人邊地人癡鈍人等受戒自恣一切不成足數僧祇云有七人不足數謂和尚足十授戒不成若與欲人若隔障若半覆半露中間隔障若半覆半露伸手不相及露地不相及乃至行作羯磨坐則犯別住坐臥互乖亦爾義加醉尼亦不足數十誦白衣亦不足數婆論亦不足數此律有二十八人不足數謂為比丘作羯磨比丘尼及式叉沙彌沙彌尼十三難三舉已擯應擯等此二十二人由非類故不足別住戒場上神足在空隱沒離見聞處此等五人雖是同類由與僧居相中是乖故不足數為羯磨人由為僧量故不足數和尚一人不足受戒羯磨為他所量故訶責擯出依止遮不至白衣家等四人得應一切羯磨摩那埵本日治出罪等三人及十誦中行本日治竟行摩那埵竟合有五人不足前摩那埵等三種羯磨得應餘法事用義云十三難等若未自言已前同僧法事竝得成就若雖自言當作法時無人知者亦成僧事由相不違辨得前事故此律云不得以天眼觀他淨穢應以肉眼看也十誦云若犯重人賊詐作比丘本白衣時破戒人等若言過後羯磨不成若不言者一切法成乃至亦不聽天眼看他持犯義云自言者要告前人云我犯淫盜等令前人了了知解方為自言若雖不自言然眾竝知是犯重十三難人等舉國知聞眾人共悉此等諸人不待自言亦不足數假令同界不喚無過若爾何故律云竝要自言又不應以天眼觀他淨穢耶答律要自言者據不知者論今既知犯豈待自言又不許天眼觀應以肉眼看我還以肉眼看不用天眼觀何為得足數故婆論云犯重比丘眾僧知犯不須自言及以現前直爾滅擯驅出義云若審知有此犯重人其人兇惡不可揀出秉法之人若在露地作法必令眾僧肩膝相拄周帀而坐不得間隔好人單行而坐伸手之外便成別眾若行此法宜可密為不得向說前人若知反成礙法若在堂內覆障處作法者雖好惡相參法成無過今時末法犯者極多恐法難辨故別標記。
【譯文】第一部分「揀選合格僧眾」：《十誦律》指出有十一種人不能計入僧團有效人數，也就是睡眠中的比丘，如果在羯磨單白結束後睡著還可以算入，如果在單白之前就睡著便不能計入；此外，言語顛狂錯亂者、神志昏擾混亂者、入於禪定者、啞者、聾者、兼具聾啞二病者（啞聾俱人）、狂病者、心神散亂者、因重病神智崩潰者、坐在樹上的比丘等，全都不能計入僧數。《摩得勒伽論》（伽論）說有三種人不能計入人數：身患重病者、來自邊地不懂法規者、愚癡遲鈍不知法事者等，若由這些人參與受戒或自恣，一切法事都不算合格僧數。《僧祇律》指出有七種人不能計入人數：作為得戒和尚不能充當湊成十人的受戒僧數，若充數則授戒不成立；還有已經遞交欲意委託的人、隔著屏障的人、處在半遮蔽半露天環境而中間有阻礙的人、處在半遮蔽半露天且伸手無法相及的人、在露天中相距過遠手不能及的人，乃至作法時有人站立有人坐著而構成犯別眾過失，或者坐臥姿態互不協調也同樣不算數。依義理補充，喝醉的比丘尼也不能計入人數。《十誦律》指出在家白衣不能計入人數，《薩婆多論》也指出白衣不可計入。本部《四分律》中則明定有二十八種人不能計入僧數：如果是為比丘作羯磨，比丘尼、式叉摩那、沙彌、沙彌尼等四眾，以及十三種受戒難緣之人、遭受三種舉罰而被擯除出僧團的人，還有理應被擯除的人，這二十二人由於與作法者非屬同類，所以不能計入；處在別住狀態的人、站在戒場邊界標誌上的人、以神通隱身於空中或隱沒身形的人、遠離了大眾視線與聲音所及範圍的人，這五個人雖然同為出家同類，但因其處境與僧團共同居住的相狀相違背，所以不能計入人數；此外，被作羯磨的當事人（所為作羯磨人），因為是被僧團稱量審查的對象，不能計入僧數；得戒和尚一人，不能在受戒羯磨中充當審查者的人數，因為和尚是被他人（秉法僧眾）所稱量審查的對象；至於受過訶責羯磨、擯出羯磨、依止羯磨、遮不至白衣家羯磨等四種處分的人，則可以參與並充當一切其他羯磨的人數；而處於摩那埵期間的人、正在受本日治處分的人、正準備出罪的人等三人，加上《十誦律》所說已經服完本日治處分、服完摩那埵處分的人，總共有五人不能計入前述摩那埵等三種懺除僧殘罪的羯磨人數，但可以充當其餘日常僧事的人數。從義理上說：具有十三難等障礙的人，如果在作法前尚未自己承認，在此之前共同參與的僧事羯磨都算有效成就；如果本人私下雖然自述過，但在正式作法時全場無人知曉，法事依然成立，因為當時外相並未違犯，能夠成就眼前的僧事。所以本律強調：不能用天眼通去照察他人的內在淨穢，應當用肉眼所見的常規標準來判定。《十誦律》說：若是犯了根本重罪的人、以盜心冒充比丘身分的人、原本在做白衣時破戒作惡的人等，如果當面說出自己的罪過，法事便不成立；如果他們沒有說出來，一切法事均算成立，乃至佛陀也不允許用天眼去觀察別人的持戒與犯戒情況。義理上所說的「自言（自己承認）」，是指必須親口明確告訴在場僧人「我犯了邪淫或偷盜等重罪」，使對方清清楚楚理解，這才算自言；如果雖然沒有親口承認，但僧團大眾全都知道他是犯了重戒或具有十三難障礙之人，甚至全國皆知、眾所周知，這類人無須等待他自己陳述，本身就不能計入僧數，假使同在一界之內不召集他們參與作法，也不算犯別眾罪。如果這樣，為什麼律典又說必須由其本人自言，且不許用天眼觀察淨穢呢？答案是：律中要求自言，是針對大眾不知情的情況而言；如今大眾既然已經明確知道他犯了重罪，哪裡還需要等他自言？再者，佛陀不許用天眼觀察，要求用肉眼審視，我們依憑肉眼現前所見就已經知道其罪行，並非使用天眼通，那他憑什麼還能湊數？所以《薩婆多論》說：對於犯重罪的比丘，只要僧團大眾知道其犯戒，不需要等他自首，也不用讓他出現在法會現場，直接予以滅擯驅逐即可。義理上進一步補充：如果確切知道僧中有這名犯重罪之人，而其人生性凶惡暴戾，無法當面將其挑出驅離，那麼主持法事的人如果在露天作法，必須命令大眾僧肩靠肩、膝碰膝緊密圍坐成一圈，絕對不能讓戒行清淨的人孤單隔開單坐，因為一旦超出伸手可及的範圍就會形成別眾過失；若要使用這種圍坐防範之法，應當暗中秘密進行，不可向外聲張，如果被那個惡人察覺，反而會引發阻礙破壞法事；如果是在僧舍堂內有遮蔽屏障的處所作法，雖然賢善與罪惡之人混雜在一處，法事依然能夠成立而無過失。如今正處末法時代，犯戒之風極其普遍，唯恐如法僧事難以辦成，所以特別在此詳細標記註明。

【1402-0002】04_比丘尼鈔/01b_卷上之上#5
【原文】第二簡相者夫論眾法但取外淨不論內染但令相順心違便成法事故律云見如法羯磨而心不同得成如法準此取相不論心非若欲秉法問和待答人坐竟然後為之為濟被治許立得成若乞受戒懺悔等坐乞彌善雖無正文義準應得唯有二人立秉得成一威儀師為僧所使不得輒坐二半月說戒眾大難聞開立說戒自餘一切竝須坐秉也如律云為眾大開作轉輪高座說戒未必立說得成舊開立說戒者良恐不成若依此說但開威儀師一人得立秉法餘者不成五分云病人背羯磨佛言犯別眾。
【譯文】第二部分「審定僧眾外在威儀相狀」：大凡論及僧團羯磨如法與否，只取外在行相的和合清淨，不深究內心的隱私染污；只要外在相貌遵從法規，即使內心有所違逆，法事依然能成就。所以律中說：眼見如法舉行的羯磨，雖然心中不同意，法事依然依如法而成立。依照這個原則，羯磨只取外在的行相，不論內心的非難。如果想要秉持法事，問詢和合時必須等待全體僧眾坐定應答完畢，然後才能宣讀羯磨；若是慈濟或處治之法，特許站立，法事也能成立；如果是乞求受戒、乞求懺悔等，能坐著乞求最為圓滿，雖然律中沒有明文硬性規定，依義理推斷應該可行。在所有秉法者中，只有兩種人可以站立主持而羯磨依然成就：一是威儀師（維那），因為肩負僧團差遣維持秩序的職責，不能隨意坐下；二是半月說戒時，如果大眾人數極多、在後方難以聽聞，特許站立說戒。其餘一切羯磨法事，全部都必須端坐秉持。正如律中所說：為了大眾人數眾多，特許設置高大的轉輪法座坐在上面說戒，並非站著說戒就能合法成立。過去有人開許站立說戒，實在令人擔憂無法如法成立；如果依照嚴格的律說，只開許威儀師一人可以站立秉法，其餘人都不能站立。《五分律》說：若是生病的僧人背對著羯磨現場，佛陀判定此舉違犯了「別眾」的過失。

【1402-0003】04_比丘尼鈔/01b_卷上之上#6
【原文】○受欲篇第六
【譯文】○ 受欲篇（接受委託與表白清淨章）第六
