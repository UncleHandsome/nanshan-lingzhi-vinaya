# 校閱材料　第195檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【195-0001】01_行事鈔/09a_卷下之一#35
【原文】今先受法。應前安陀會為始。此衣正有三品，謂割截、襵葉、揲葉也。加法云：「大德一心念！我比丘某甲，此衣安陀會，五條衣受，一長一短，割截衣持。」亦云：「屈襵衣持。」：「揲葉衣持。」餘同《十誦》。若論從者：「大德一心念！我比丘某甲，此安多會，二十五條衣受，四長一短，割截衣持。」若縵衣者。《十誦》云：「大德一心念！我比丘某甲，是縵僧伽梨，受持。」若中衣云：「大德一心念！我比丘某甲，此衣欝多羅僧，七條衣受，兩長一短，割截衣持。」若上衣者云：「此僧伽梨，若干條受，若干長若干短，割截衣持。」上明三衣受竟。律制並須三說。彼律受戒前教言：「我某甲，此衣僧伽梨，若干條受，若割截、若未割截，是衣持。」三說。乃至安陀會亦爾。《薩婆多》云：五大色者，不成受，則孝僧白布袈裟等非法。如是例之，多有黑青赤黃四色，無多白者，正言如上不成。今以凡情苦受，此則一生無衣覆身，一死自負聖責；何慮無惡道分，悲哉！
【譯文】現在先說明受持之法。應當以先受安陀會（下衣）為起始。此衣的正品有三種，即割截縫合、折疊衣葉（襵葉）、貼加衣葉（揲葉）。加法作白時說：「大德一心念！我比丘某甲，此衣安陀會，以五條衣受，一長一短，作為割截衣持。」也可以說：「作為屈襵衣持。」或說：「作為揲葉衣持。」其餘文句如同《十誦律》。如果是從品的五條衣，則說：「大德一心念！我比丘某甲，此安陀會，以二十五條衣受，四長一短，作為割截衣持。」如果是縵衣（不割截衣），《十誦律》說白文為：「大德一心念！我比丘某甲，這是縵僧伽梨，受持。」如果是中衣（七條衣），說：「大德一心念！我比丘某甲，此衣欝多羅僧，以七條衣受，兩長一短，作為割截衣持。」如果是上衣（大衣），說：「此僧伽梨，以若干條受，若干長若干短，作為割截衣持。」以上說明了三衣受持完畢。律法規定都必須連說三遍。該律在受戒前教授說：「我某甲，此衣僧伽梨，以若干條受，或者割截、或者未割截，作為此衣持。」說三遍。乃至受持安陀會也是這樣。《薩婆多論》說：具有五種大純正色彩的衣服，不能成就受持，那麼守孝之僧所披的白布袈裟等就是非法的。以此類推，世間袈裟多有染成深黑、正青、純赤、純黃四種純正色彩的，雖然較少用純白色，但正如同前面所說的全都不能成就受持。如今如果以凡俗凡夫的情執硬要去受持這種非法衣，這將導致一生之中在戒法上等於沒有合法法衣覆身，一旦命終自己便要承擔聖教律法的責罰；哪裡還用擔心墮入惡道沒有自己的份呢？真是可悲啊！

【195-0002】01_行事鈔/09a_卷下之一#36
【原文】次明捨法：「大德一心念！我比丘某甲，此僧伽梨，是我三衣數；先受持，今捨。」餘二衣同之。一時受一時捨，越毘尼。若尼受餘二衣者，《十誦》云：「大姊一心念！我比丘尼某甲，是衣厥修羅受，長四肘廣二肘半，是厥修羅衣持。」三說。「是衣覆肩衣，長四肘廣二肘半，是覆肩衣持。」三說。《僧祇》云：當作衣覆肩，名覆肩衣，不者越罪。兩衣祇支，得提罪。尼祇支長佛四搩手，廣二搩手，互減過亦提。尼五衣者，覆肩衣、水浴衣、及三衣也。
【譯文】其次說明捨衣之法。白文為：「大德一心念！我比丘某甲，此僧伽梨，是我三衣之數；先前受持，現在捨棄。」其餘兩件衣服也依此類推。如果同時受持或同時捨棄三衣，犯越毘尼（突吉羅罪）。如果是比丘尼受持額外的兩種衣服，《十誦律》說白文為：「大姊一心念！我比丘尼某甲，此衣以厥修羅（內衣/筒裙）受，長四肘、寬二肘半，作為此厥修羅衣持。」說三遍。又說：「此衣以覆肩衣受，長四肘、寬二肘半，作為此覆肩衣持。」說三遍。《摩訶僧祇律》說：應當製作衣服覆蓋肩膀，稱為覆肩衣，如果不做便犯越毘尼罪。雨衣（底本作兩衣）與僧祇支，若不畜持則犯波逸提罪。比丘尼的僧祇支尺寸為長佛四搩手、寬二搩手，尺寸互相超過或減少也犯波逸提。比丘尼的「五衣」，是指覆肩衣、水浴衣，以及原本的三衣。

【195-0003】01_行事鈔/09a_卷下之一#37
【原文】二明心念法。《五分》：獨住比丘，三衣中須有所換易，應具儀，手執衣，心生口言：「我比丘某甲，此僧伽梨若干條，今捨。」三說已。然後受所長之衣，亦如前威儀，云：「我比丘某甲，此衣僧伽梨，若干條受。」餘二衣同準。
【譯文】第二、說明心念受捨法。《五分律》說：獨自一人居住的比丘，若在三衣之中需要替換更動某件衣服，應當具足威儀，手拿著衣服，心中生起念頭、口中說道：「我比丘某甲，此僧伽梨若干條，現在捨棄。」說完三遍之後。然後受持所多出的新衣，同樣如同前面的威儀，說：「我比丘某甲，此衣僧伽梨，以若干條受。」其餘兩件衣服依此準則比照辦理。

【195-0004】01_行事鈔/09a_卷下之一#38
【原文】四雜料簡分三。
【譯文】第四、雜項問題的審核辨析，分為三部分。

【195-0005】01_行事鈔/09a_卷下之一#39
【原文】初明受捨是非者。《十誦》云：借衣離宿，但懺墮罪，不得捨衣。《五分》諸比丘不捨先受持衣，更受餘衣，成受；先三衣說淨，亦得；不捨故吉羅。《善見》：欲易三衣，無人可對，以手捉衣，自說名字者成；若不捉不說者不成。諸受持衣，雖被穿破，不失受。若上二衣，廣邊八指內，長邊一搩手內穿，不失；餘處穿如小指甲，失受；有橫縷者，不失。安陀會廣邊四指內，長邊一搩手內穿，不失；餘處穿失；補竟受持。《薩婆多》：但使緣斷，則失受。《善見》云：若施人、賊奪，若失、罷道、作沙彌、若捨、若離宿，並名失。《四分》中：若失想、道斷、難緣等失受，具有四礙、染隔情界，失不失、犯不犯，並如〈隨相〉及《鈔》、《疏》。《薩婆多》：三衣雖不受持，過日無離衣罪；有壞威儀、缺衣二罪。若本說淨，今作三衣，即失本淨。又捨此衣已，更受餘衣；前衣說淨，不者犯長。
【譯文】第一項、說明受持與捨棄的是非準則。《十誦律》說：借用他人的衣服而離開過夜，只要懺悔波逸提（單墮罪）即可，不能作捨衣處理。《五分律》說：比丘若沒有捨棄先前已受持的衣服，便直接再受持其他衣服，新的受持依然成就；先前的那套三衣如果拿去作說淨，也可以；但因為未預先捨棄的緣故犯突吉羅罪。《善見律毘婆沙》說：若想要更換三衣，卻找不到人可以對首作白，用手拿著衣服，口中自稱自己的法名作白便能成就；如果不拿著衣服、口中不自稱名字則不能成就。凡是經過加法受持的法衣，即使被穿磨破損，也不會喪失受持體。如果是上二衣（大衣與七條衣），在寬邊的八指以內、長邊的一搩手以內破損穿孔，不會喪失受持體；若在其他部位穿孔如小指甲般大小，就喪失受持體；但如果破洞處還有橫向的織線相連，則不喪失受持體。安陀會（五條衣）在寬邊四指以內、長邊一搩手以內穿孔，不失受持體；其他部位穿孔則喪失受持體；修補完畢之後必須重新受持。《薩婆多論》說：只要包邊緣線斷裂，就會喪失受持體。《善見律毘婆沙》說：如果將衣服布施給他人、被盜賊搶奪、自己遺失、還俗罷道、降為沙彌、自行作法捨棄、離開衣服過夜，都稱作喪失受持體。《四分律》中說：如果誤以為衣服已遺失（失想）、路途阻隔斷絕、遭遇危難因緣等情況而喪失受持，其中具有四種阻礙（染礙、情礙、隔礙、界礙），關於何時喪失與不喪失受持體、何時結罪與不結罪，都記載於〈隨相釋罪篇〉以及本《行事鈔》、《戒本疏》之中。《薩婆多論》說：三衣如果沒有經過加法受持，即使過了夜晚也不會結犯「離衣宿」的罪過；但會結犯破壞威儀罪與缺衣罪兩種罪。如果布料原本已經作過說淨，如今裁製受持為三衣，就隨即失去原本的說淨效力。又如果捨棄了這件法衣之後，重新受持其他衣服；那麼先前的那件衣服必須重新進行說淨，否則就會犯蓄持長物罪（犯長）。
