# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【691-0001】01_行事鈔/12c_卷下之四#14
【原文】四明安居法。大同僧中。尼無獨住，必依大僧。律云：不依犯墮。《僧祇》：若親里請尼安居者，先教請比丘；不肯者，不得受請。餘如彼說。《善見》云：尼去比丘住處半由旬，得安居，過者不得。一切僧尼，二時集會；夏初請法，夏竟說證。若檀越為請比丘來，而尼結安居竟，乃至後夏初，比丘有緣事不來，當更請比丘來；若不得，應去；路有難事，得安居。若初安居竟，比丘有緣去，尼後方知；已結安居者，不得移，住無罪。若夏竟，不得無比丘自恣，應覓。《僧祇》：雖在一比丘處，半月應請問布薩；卒無者，三由旬內有僧處，通結取。
【譯文】四明安居法。大致與比丘僧中相同。比丘尼不可單獨居住，必須依止比丘僧。律藏說：不依止者犯波逸提（單墮罪）。《摩訶僧祇律》記載：如果有親族親戚邀請尼僧前去安居，尼僧應當先教導施主邀請比丘；若施主不肯邀請，尼僧就不能接受邀請。其餘如該律所述。《善見律毘婆沙》說：比丘尼距離比丘住處在半由旬（約二十里）以內，得以安居，超過此距離則不得安居。一切比丘僧與比丘尼，在兩個時期集會：夏初請法，夏竟說證。如果施主為她們請來比丘，而尼僧結夏安居完畢，乃至到後夏初時，比丘因有事故而無法前來，應當重新迎請比丘前來；如果請不到，尼僧應當離去；途中若有危難事故，准許就地安居。如果初安居結界已畢，比丘因事離去，尼僧事後才知曉；已經結夏安居者，不得移轉住處，留住無罪。如果夏安居結束，不可在沒有比丘的情況下自恣，應當尋求比丘。《摩訶僧祇律》說：即使只在有一位比丘的處所，每半個月也應當前往請問布薩日期；如果連一人也沒有，在三由旬內有僧人的處所，都可以通連結取安居界。

【691-0002】01_行事鈔/12c_卷下之四#15
【原文】五自恣法。《四分》：尼夏安居竟，聽差一比丘尼，為尼僧故，往大僧中說自恣。當白二差之，文如常也，又差二三人為伴。往大僧中，禮足已，曲身低頭合掌，作如是語：「比丘尼僧夏安居竟，比丘僧夏安居竟。比丘尼僧，說三事自恣，見、聞、疑；大德慈愍故，語我；我若見罪，當如法懺悔」。彼尼受教已，當於明日，尼自恣時，鳴椎，尼僧集已；如前教誡中，白尼僧，傳自恣時大僧所告之語，乃至諸尼頂戴訖；依上大僧自恣法，然後散去。
【譯文】五自恣法。《四分律》記載：比丘尼夏安居結束後，開許差遣一位比丘尼，代表尼僧大眾前往比丘僧中陳說自恣（任由他人檢舉己過並懺悔）。應當以白二羯磨差遣，羯磨文如常規，並另外差遣二、三人作為同伴。前往比丘僧中，頂禮足禮之後，彎腰低頭合掌，作這樣的陳白：「比丘尼僧夏安居已畢，比丘僧夏安居已畢。比丘尼僧依見、聞、疑三事向大僧說自恣；祈請大德慈悲愍念的緣故，開示教導我；我若見到自己有罪過，應當如法懺悔。」那位比丘尼接受教導之後，應當在次日尼僧自恣之時，敲擊木槌，尼僧集合完畢；如同先前請教誡時一樣，向尼僧大眾稟告，轉達自恣時大僧所告知的話語，乃至眾尼頂戴受持完畢；依照上述大僧自恣法行事，然後各自散去。

【691-0005】01_行事鈔/12c_卷下之四#16
【原文】律云：僧十四日自恣，比丘尼僧十五日自恣。若大僧病、別眾、眾不和眾、不滿等，尼應遣問訊。尼眾病，乃至不滿，亦須問訊大僧。《十誦》云：差二勦了知法尼，往大僧中。
【譯文】律藏說：比丘僧於十四日自恣，比丘尼僧於十五日自恣。如果大僧（比丘僧）全體有病、別眾分黨、僧眾不和合、人數不足法定僧數等情況，尼眾應當派遣信使前往問訊。尼眾全體患病，乃至人數不滿，也必須問訊大僧。《十誦律》說：應當差遣兩位精明敏捷且通曉戒法（勦了知法）的比丘尼，前往大僧之中。

【691-0006】資持記/16d_下四#12
【原文】注僧中下，上座誡勅，文指上篇，不復煩引。彼下，使尼傳教。次科，初明日別。此制相依，從僧請說，使還自恣，理須隔日；必是近處，同日何妨。若下，次明開略。亦同說戒。《十誦》，明選使尼。勦，鋤交反。勦了，謂緊捷幹濟，簡遲怠者。知法，簡愚昧者。三中。受、說、安、恣，並制依僧。
【譯文】注釋「僧中」以下，是上座的誡勉敕令，文字指引見於上篇，不再繁複引述。彼以下，是使者尼傳達教誡。次一科，首先說明日期應有差別。這是規定彼此相依，既然從僧團祈請宣說，使者返回後再行自恣，理應當間隔一日；如果是極近之處，同一天舉行又有何妨。若以下，接著說明開許簡略。也與說戒之法相同。《十誦律》說明挑選使者尼的標準。「勦」，音鋤交反。勦了，是指敏捷能幹、辦事有條理，揀除遲緩懈怠之人。知法，是揀除愚昧無知之人。第三門中，受戒、說戒、安居、自恣，全都規定必須依止比丘僧。

【原文】故通問之，總申教意。答中。經明女性，且示五相。惑色，謂著顏色；益壽，為欲壽長；畜弟子，即好多眷屬；不學問，即懈怠；知須臾事，謂短識見。賦性既爾，自無志節，義必從師，教意可見。此據大約，未必皆然。六中。此門理合廣釋尼戒。但與僧同者，〈釋相〉具分。餘有不同，略提時要；
【譯文】所以通盤提問，總體開展教化的意旨。回答之中。佛經說明女人的性情，暫且列示五種相貌：迷惑於美色，是指執著容顏色彩；貪求益壽，是為了想要長壽；蓄養弟子，就是喜愛眷屬眾多；不從事學問，就是懈怠放逸；只知片刻之事，是指見識短淺狹隘。天賦性情既然如此，自然缺乏志氣節操，義理上必然應當跟從導師，制教的深意由此可見。這只是依據大致情況而言，未必人人皆是如此。第六門中。此門在義理上理應詳細解釋比丘尼戒。然而與比丘戒相同之處，在〈釋相篇〉中已經具足剖析。其餘不同的部分，略微提出時下的要務；

【691-0010】01_行事鈔/12c_卷下之四#19
【原文】摩觸戒。六緣成犯：一是人男子。二作人男子想。三彼此有染心。律云：謂意相染著也。四腋以下，膝以上，腕以後身分。甄去輕境，染心既微，必無陵逼之過，故犯輕罪。若尼以輕觸男重境，男以輕境觸尼重境，此二皆重；不要取二重境相觸也。五身相觸。除一有衣，一無衣；二俱有衣，不犯重。六隨觸多少，一一結重。尼摩觸戒，與大僧四種不同：一大僧就壞行中制，莫問死活，但觸著便犯，據有淫心；尼就陵逼中制，死者不犯。律云：染污心男子也。二僧則不簡女人大小；尼觸男子，取能行淫事。《十誦》：人男者，謂能作淫事。三僧隨觸境便犯；尼簡境有上下。四僧不問境染淨；尼觸必俱染心。《僧祇》：若尼輕處有瘡癰，得使男子治之，先令二女急捉，令不覺男子手；若重處者，使女人師治。《善見》：若比丘觸尼，尼身不動，受樂，隨處得罪。《四分》，同僧中。《十誦》：不犯者，父兄弟兒想，若水火刀杖惡緣等，一切無著心故；非無吉羅。
【譯文】摩觸戒。具足六種因緣構成犯戒：第一、對方是人類男子。第二、作人類男子想。第三、彼此雙方都有染著之心。律藏說：指心意互相染污貪著。第四、腋下以下，膝蓋以上，手腕以後的身分部位。甄別除去輕微部位，染著心既微弱，必定沒有受陵逼侵害的過失，所以只犯輕罪。如果比丘尼以自己的輕罪部位觸碰男子的重罪部位，或者男子以其輕微部位觸碰比丘尼的重罪部位，這兩種情況都結重罪；並不一定要雙方的重罪部位互相觸碰。第五、身體相觸。若排除「一方有衣、一方無衣」以及「雙方皆有衣」這兩種不犯重罪的情形（唯有雙方皆無衣而肌膚直接相觸，才犯波羅夷重罪）。第六、隨著碰觸的次數多少，每一次都結重罪。比丘尼的摩觸戒，與大僧有四種不同之處：第一、大僧是從敗壞梵行的角度制定，不論死人活人，只要觸及便犯，以具有淫心為準；比丘尼是從遭受陵辱逼迫的角度制定，碰觸死者不犯。律藏說：必須是有染污心的活男子。第二、比丘犯戒不挑選女人年齡大小；尼僧碰觸男子，以男子已具備行淫能力為限。《十誦律》說：人類男子，是指能夠行淫事的人。第三、比丘隨意碰觸任何身體部位便構成犯戒；尼僧則有區分身體部位的上下輕重。第四、比丘犯戒不論對方是否有染著心或清淨；尼僧犯戒必須雙方都具備染著之心。《摩訶僧祇律》記載：如果比丘尼在身體輕微部位長了瘡癰，可以讓男子為其醫治，但必須先讓兩位女子緊緊按住她，使她感覺不到男子的手；如果長在重罪部位，則必須讓女醫治病。《善見律毘婆沙》說：如果比丘碰觸比丘尼，尼僧身體不動，但領納快感，隨碰觸部位各得其罪。《四分律》則與僧中相同。《十誦律》記載：不犯的情況是，作父親、兄弟、兒子想，或者遭遇水溺、火燒、刀杖等險惡因緣（為救難而觸碰），全都是因為沒有貪著之心的緣故；但並非完全沒有突吉羅輕過。

【691-0012】資持記/10a_中三下#49
【原文】外道上樹取果擲地與之，比丘言我法不得不受而食；故云並答等。第二《了論》，初引論文。準彼無令字，寫錯不疑。次引疏解，初釋自性。即指戒體。欲下，釋求得。謂有所須。此下，釋此處。謂受食處。下云地及水中是也。與餘不須者，顯示能受法通他故。即下，簡濫，初指上能受。
【譯文】外道親自上樹摘下果實扔在地上給他，比丘說「我的戒法規定不可以不經授予而進食」；所以說「都一一回答」等等。第二部《了論》，首先引用論文。對照該論原本並沒有「令」字，是傳抄錯誤無疑。其次引用戒疏的解釋，首先解釋「自性」。指的就是戒體。從「欲」以下，解釋「求得」。是指有所需求。從「此」以下，解釋「此處」。是指接受食物的地點。下文所說「在地上及水中」就是指這個。說給予其餘人不需要，顯示能受食之法可以通達於他人。從「即」以下，甄別混淆，首先指出上面所說的能夠受食之人。

【691-0013】01_行事鈔/07c_卷中之三#7
【原文】三所對境。《了論》解云：除自己及同類，餘三類眾生，隨一被教不被教，知比丘不得自取食食，又知此可食物，知比丘是受施人，度與比丘。若不解此義，雖與不成受。《多論》：為作證明故，若在人中，非人畜生，悉不成受。《五分》：曠野無淨人處，聽自洗燒器安水，淨人安米，自煮；若熟，從他受。《僧祇》：曠野中行，牛上受食。長袋連紐，一日一繫，置牛上，人不得觸之；至時，一比丘引繩，一比丘受取，口云受受等。《十誦》：蠅不可遮，故非觸。鳥來啄一口去，但棄啄處，餘殘得食。《善見》，天人鬼神畜生飛鳥皆成受。《五分》，迦葉從帝釋受食。《僧祇》中，獼猴邊受蜜。《十誦》，輕繫地獄，亦應得受。準此六道知解者成，反則不成。
【譯文】第三、所對的境緣。《律二十二明了論》解釋說：除了自己以及同類（其他比丘）之外，其餘三類眾生，無論受過教化還是未受教化，只要知道比丘不能自己隨意拿食物來吃，又知道這是可以吃的食物，並且知道比丘是接受布施的人，而將食物遞給比丘。如果施者不懂得這個道理，即使給予了，受食也不能成立。《薩婆多論》說：因為受食是為了作為給予的證明，所以在有人之處，若從非人、畜生處受食，全都不能成立。《五分律》說：在曠野沒有淨人的地方，允許比丘自己清洗炊具、注入清水，由淨人放入米，比丘自己煮；煮熟之後，再從別人那裡接受授予。《摩訶僧祇律》說：在曠野中行走時，可以在牛背上接受食物。用長袋子連結繩紐，一天繫綁一次，放置在牛背上，人不可隨意觸碰它；到了用餐時間，由一位比丘牽引繩子，另一位比丘接取，口中說「受、受」等詞句。《十誦律》說：蒼蠅無法阻擋，所以落入不算觸碰破壞受食。鳥雀飛來啄吃了一口就飛走，只要除去被啄過的地方，剩餘的食物仍可以吃。《善見律毗婆沙》說：諸天、人類、鬼神、畜生、飛鳥給予，都可以成立受食。《五分律》中記載，大迦葉尊者從天帝釋那裡接受食物；《摩訶僧祇律》中記載，比丘從獼猴那裡接受蜂蜜；《十誦律》中甚至認為從輕繫地獄的眾生處，也應當能成立受食。依照這些說法，六道眾生只要具有知解心意的，給予就能成立受食；反之，若無知解則不能成立。
