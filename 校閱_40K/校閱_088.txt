# 校閱材料　第088檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【088-0001】02_戒疏/03b_卷一下之一#78
【原文】【記】今解中。初二句明引古之意。言「不容」者，顯非所取。「容」或作「融」，言其滯塞，意在不存，故先出耳。「隨」下，略示今解。言「問下」者，世多不曉，乃謂說初篇時，但問犯夷，乃至眾學，亦問本篇。今應難云「犯下諸罪應聞上篇，則違律文『犯者不得聞戒』」，如何通耶？今言「問下」，謂將說下篇，通問眾中，於七聚罪微犯憲章，不合同聽，非謂但問本篇而已。下文當見。
【譯文】【記文】在今師的解釋中。前兩句說明引述古德說法的用意。所謂「不容（不能容許）」，顯示彼說不可採信。「容」字有的本子寫作「融」，是說彼說窒礙不通融，意在予以揚棄，故先揭示出來。「隨」字以下，略示今師正解。所謂「向下通問」，世人多不理解，竟誤以為宣說初篇時只問是否犯波羅夷，乃至宣說眾學法時也只問本篇。如今應當反問質難彼人：「難道犯了下篇各罪的人，就可以聽聞上篇了嗎？若可以聽，這便違背了律文中『凡有犯者皆不得聽戒』的規定」，這又如何解釋得通呢？此處所謂「向下通問」，是指在即將宣說下篇之前，普遍詢問在座僧眾，對於七聚罪法中即便有輕微違犯，都不應一同聽戒，絕非僅僅詢問本篇而已。這在下文中便能明白。

【088-0002】02_戒疏/03b_卷一下之一#79
【原文】【疏】三、對問緣得罪多少。
【譯文】【疏文】第三、對照發問的因緣辨明所獲罪數之多寡。

【088-0003】02_戒疏/03b_卷一下之一#80
【原文】【疏】如昔解云：「雖經三問，共成一法，故今默者，但犯一罪。如諸乞辭，及以白四，言雖重彰，皆成一法。」
【譯文】【疏文】正如過去古德的解釋說：「雖然歷經三次提問，但共同成就同一項說戒法事，因此如今沉默不言的人，僅僅結犯一項罪名。如同各種乞求文詞，以及白四羯磨，言詞雖然重複彰顯，但始終共同成就同一法事。」

【088-0004】02_戒疏/03b_卷一下之一#81
【原文】【記】三、問緣中，昔解。初立義。「如」下，引例。「如諸乞辭」，即受懺等，前皆三乞。「白四」者，且如受戒，四番羯磨，共成一受，餘亦例爾。
【譯文】【記文】第三、依詢問因緣論罪的章節中，先出古德之解。首先確立立論。「如」字以下引出事例。「如諸乞辭」是指受戒、懺悔等法事，事前皆須三度乞求。「白四羯磨」是指例如受大戒時，由一白三羯磨共四番宣示，共同成就一項受戒法，其餘法事亦依此類推。

【088-0005】02_戒疏/03b_卷一下之一#82
【原文】【疏】今解不同：「既有三問，隨問覆默，還得三罪。如白四諫，共成一法，隨白羯磨，結四偷蘭。莫不對問對諫，俱有拒心，故結多罪。」
【譯文】【疏文】如今我的見解不同：「既然主法者有三次提問，受問者隨著每一次提問而覆藏沉默，便應當相應得到三條罪過。如同白四羯磨的勸諫之法，全體雖共同成就同一法事，但隨著每一次白告與羯磨宣讀，皆逐次結犯一品偷蘭遮罪。無非是因為每次面對詢問或面對勸諫，內心都存有抗拒之意，所以應當結犯多項罪名。」

【088-0006】02_戒疏/03b_卷一下之一#83
【原文】【記】今解中，初科。前立理。「如」下，舉例。「白四諫法」，隨徧結蘭，例今三問，隨問犯吉。
【譯文】【記文】在今師解釋中，此為第一科。前半段確立論理。「如」字以下舉出事例。「白四諫法」是隨每一回宣讀即結犯偷蘭遮，以此類推今日的三次提問，自然隨每一次提問便各自結犯一次突吉羅。

【088-0007】02_戒疏/03b_卷一下之一#84
【原文】【疏】問：「以諫例問，故得多罪。違諫第四，便得僧殘，亦可默妄加四犯墮？」
【譯文】【疏文】提問質難：「若用勸諫法來類比說戒提問，因而結犯多項罪名；那麼違抗勸諫到了第四度羯磨完畢，便直接成立僧殘重罪，是否也可以說沉默妄語在第四番之後便應加重結犯墮戒？」

【088-0008】02_戒疏/03b_卷一下之一#85
【原文】【疏】答：「諫對別人，違僧命重。說戒直問，前過未彰，故成僧法，三問便止。此在僧中默故犯吉。若據對首有罪陳淨，具有三墮。心念例知。」
【譯文】【疏文】回答：「羯磨勸諫是針對個別特定之人，違抗全體僧眾的命令其罪極重；說戒時則是直接普問大眾，被問者先前的過失尚未在座前彰顯，這純粹是為了成就僧中常規法事，問滿三次便告終止。這是在大眾僧中因沉默而結犯突吉羅。但若是屬於私下對首，明知有罪卻口頭宣稱清淨，則具足結犯三個單墮罪。若是心念說戒，亦可依此原則類推。」

【088-0009】02_戒疏/03b_卷一下之一#86
【原文】【記】釋妨中。約諫根本，相比為難。答中，考文凡有四異：一、別人僧法，二、違拒默覆，三、諫勸直問，四、過彰未彰。情事不同，未可比例。「此」下，辨異。對念口陳，二俱語妄。「心念例」者，說不對人，理得三吉。
【譯文】【記文】在釋除妨難的章節中。以勸諫法達到根本究竟罪的歷程，相對比作為問難。回答中，考究文義共有四點差異：第一、針對個別之人與施行僧團常規法事不同；第二、當面違逆抗拒與默然覆藏不同；第三、針對具體事件勸諫與例行性提問不同；第四、過失已被揭發與過失尚未彰顯不同。兩者情節事態完全不同，不可牽強類比。「此」字以下辨明差異。對首與心念口頭陳述，兩者都屬於言說妄語。「心念例知」是指心念說戒時雖不面對他人，但依理亦應結犯三個突吉羅。

【088-0010】02_戒疏/03b_卷一下之一#87
【原文】【疏】四、約犯罪論者。
【譯文】【疏文】第四、依據所犯的罪聚多少來論定。

【088-0011】02_戒疏/03b_卷一下之一#88
【原文】【疏】問：「今有犯多罪者，既違序問，為得幾罪？」
【譯文】【疏文】提問：「如今若有人犯了多種罪過，既然違背了戒序中的提問，究竟應當結犯幾條罪？」

【088-0012】02_戒疏/03b_卷一下之一#89
【原文】【記】四、約罪中，問詞。且舉「違序」，餘八皆爾。
【譯文】【記文】第四、依所犯罪聚論罪的章節中，此為問詞。此處暫且以「違背戒序提問」為例，其餘八篇亦同此理。

【088-0013】02_戒疏/03b_卷一下之一#90
【原文】【疏】答：「默淨誑僧，但得一罪，以罪從問緣生，不由誑罪生。有問故違，無問不結，故知一罪。不同覆藏由覆罪生，但經明相，則隨罪結。」
【譯文】【疏文】古德回答：「以沉默詐稱清淨欺誑僧眾，僅僅結犯一條罪。因為這條默妄罪是順著主法者的『發問因緣』而生起，並非由自己所隱瞞的『諸多罪過』衍生而來。既然有問才構成違犯、無問便不結罪，由此可知只犯一條罪。這不同於一般的覆藏罪是由所覆蓋的罪行直接衍生，只要經過破曉天明，便會隨著所犯各罪分別逐一結罪。」

【088-0014】02_戒疏/03b_卷一下之一#91
【原文】【記】古答有二，初立義。問雖有三，共成一法，既從問生，故無多罪。「不」下，二、遮妨。由覆結犯，隨罪少多，恐引為難，故預簡之。
【譯文】【記文】古德的回答包含兩層意思，首先確立立論。發問雖然有三次，但共同成辦一個法事，罪過既是因提問而起，自然不會因罪多而增多。「不」字以下，第二點在於預先排除妨難。覆藏結罪是隨著原本所犯之罪的多寡而定，古德擔心他人以此發難，故預先加以揀別區隔。

【088-0015】02_戒疏/03b_卷一下之一#92
【原文】【疏】今解不同：「問緣、明相，俱得多罪。以此二緣結罪之位，覆藏既得從罪生罪，問緣豈非從罪生罪？問緣若不從罪生罪，同聽之人悉應有犯，以有問緣之可違故。然今不爾，有罪違問，無罪不違。故知有罪，便懷默妄，何得上云『不從罪生』？」
【譯文】【疏文】如今我的見解不同：「發問因緣與破曉天明，兩者同樣都會衍生多重罪名。因為這兩種因緣所確定的結罪地位，覆藏既然能夠『從罪生罪』，發問因緣又怎能說不是『從罪生罪』？如果發問因緣不是從罪生罪，那麼在座一同聽戒的清淨之人豈不全都有罪？因為現場同樣存在著發問因緣可供違背。然而如今事實並非如此，只有身負罪過的人才會違背發問，本無罪過的人便不構成違背。由此可知，是先具備了罪過，才會懷抱沉默妄語之心，怎能如上文所言『不是從罪生罪』？」

【088-0016】02_戒疏/03b_卷一下之一#93
【原文】【記】今解，初中。前明默覆結犯，從罪義同。「問緣若不」下，次立理奪破，從問義失。
【譯文】【記文】在今師論解的第一科中。前半段闡明沉默與覆藏在結犯的法理上，同樣都是「從罪生罪」。「問緣若不」以下，進一步確立論理以推翻古說，指出古德「從問生罪」的理論無法自圓其說。
