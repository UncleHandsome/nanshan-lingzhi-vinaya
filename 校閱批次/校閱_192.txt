# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【192-0009】02_戒疏/09c_卷二下之二#49

【192-0010】02_戒疏/09c_卷二下之二#50
【原文】【記】歷句數中。初示互句之多。「且」下，略舉直句。言「四百」者，且約語媒。「如是」下，例通餘四。五種總二千句，用此參互，則不可數，故云「無量」。但識下文受、說、報三，明犯分齊，無不通矣。
【譯文】【記文】推求組合句數當中。首先指出互相搭配的句數極多。從「且」字以下，簡略舉出直接的句式。所說的「四百」，暫且只是依據語言做媒來說。從「如是」以下，比照通達其餘四種方式。五種方式總共有兩千種句型，以此相互參雜，則無法計數，所以說「無量」。但只要明白下文所述的接受託付、前往說合、回頭通報這三種程序，搞清楚結犯的界限，就無不通達貫通了。

【192-0012】02_戒疏/09c_卷二下之二#52
【原文】【疏】四、言「若為成婦事」下，除疑網也。世云「媒」者，為盡生也。「婦」是伏事之言，箕箒終於命報，可有重殘；私通暫時，未必有犯。為除此妄，故結終始。從「婦」至於「須臾」，無非欲事，故並犯重，收綱攝網也。
【譯文】【疏文】第四句、說到「若為成婦事」以下，是為了斷除疑惑。世人常說的「媒人」，是指為了維持一生的名分。「婦」是侍奉順從的意思，一生拿著畚箕掃帚服侍到底，如果做媒促成這種事，可以判為重罪僧殘；而私通只是一時的苟合，未必會結犯重罪。為了破除這種妄見，所以結罪涵蓋了長久與短暫的始終。從正室「成婦」到短暫的「須臾」，無一不是男女淫欲之事，所以全都結犯僧殘重罪，將一切情況徹底籠罩網羅無遺。

【192-0013】02_戒疏/09c_卷二下之二#53
【原文】【記】釋第四句，初文。前總示文意。「世」下，出疑情。「箕箒」者，即掃洒之具，明伏事之禮。俗書並謂掃洒是婦人之職。「為」下，明斷疑。「始」謂婦事，「終」即須臾，「私通」居次，故云「至於」等。
【譯文】【記文】解釋第四句，第一段。前面總體指出經文意旨。從「世」字以下，指出凡人的疑心。「箕箒」是打掃清掃的用具，用來說明服侍順從的禮節。世俗書籍都說打掃應對是婦人的職責。從「為」字以下，說明斷除疑惑。「始」是指成就正婦之事，「終」就是片刻須臾，「私通」介於兩者之間，所以說「從……至於……」等。

【192-0014】02_戒疏/09c_卷二下之二#54
【原文】【疏】言「須臾」者，時之異名也。《僧祇》云：「二十念為瞬，二十瞬為彈指，二十彈指為羅預，二十羅預為一須臾。日極長時，晝則十八須臾，夜則十二須臾。」若夜長日短，反上可知。此則西梵約日夜為度數法也。此方《漏刻經》中，不問冬夏兩至，例分百刻，約箭在水，用刻分時。未遑廣述，所謂「時節學」也。
【譯文】【疏文】所說的「須臾」，是時間長度的另一種名稱。《僧祇律》說：「二十個念頭的時間為一瞬，二十瞬為一彈指，二十彈指為一羅預，二十羅預為一須臾。白晝最長的時候，白天有十八個須臾，夜晚有十二個須臾。」如果是夜長晝短，情況與上述顛倒便能明白。這是西天印度依照晝夜來劃分時間度量的方法。此地中土的《漏刻經》中，不管冬至夏至，一律將一天分為一百刻，依照浮箭在水中的升降，用刻度來劃分時間。此處來不及詳細敘述，這就是所謂的「時節之學」。

【192-0015】02_戒疏/09c_卷二下之二#55
【原文】【記】次科，為三。初標示。由是時之別相，故云「異名」。「僧祇」下，次引釋。「瞬」，謂目一開合也。「羅預」，亦是西梵時名，未詳所釋。「日極長」者，且舉夏至。「夜長日短」，即謂冬至，晝則十二，夜則十八，故云「反上」。春秋二分，則晝夜半分焉。「此」下，三、明二土不同。《漏刻經》，梁朝出之，明置漏刻之法。「不問」下，冬至日四十刻夜六十刻，夏至反之，春秋二分亦各等半。「箭在水」者，刻漏制云：「箭長四尺五寸，分四面，每面三時二十五刻，四面共成百刻。其箭在水壺中，壺上安木蓮華。作木人，高七寸，跪坐花心，兩手捧盤。壺中浮箭，自盤心涌出，以驗時刻之數。水漏下一刻，箭上涌一刻。每箭上壺二十五刻，一度放水，故四度而成晝夜。」、「未」下，顯略。「遑」，及也。「時節學」者，謂知時刻，別是一家之學，非可於此具論。
【譯文】【記文】下一科分為三段。首先標出名相。因為這是時間的不同劃分相狀，所以稱為「異名」。從「僧祇」以下，接著引文解釋。「瞬」是指眼睛一張一合的時間。「羅預」也是天竺的時間名詞，詳細意義尚不清楚。「日極長」是暫且舉出夏至。「夜長日短」就是指冬至，白天十二須臾，夜晚十八須臾，所以說「反之即可知」。春秋分則是晝夜各半。從「此」字以下，第三、說明中印兩國的不同。《漏刻經》是梁代翻譯出來的，說明設置滴漏計時的方法。從「不問」以下，冬至白天四十刻夜晚六十刻，夏至則相反，春秋分也是各佔一半。「箭在水」的意思，滴漏儀軌規定：「浮箭長四尺五寸，分為四面，每面有三個時辰又二十五刻，四面合起來共是一百刻。那支浮箭放在水壺中，壺上安置木雕蓮花。做一個木人高七寸，跪坐在花心，雙手捧著盤子。壺中的浮箭從木人手中盤心湧出，以此檢驗時刻的數值。水漏下一刻，浮箭就上升一刻。每當浮箭上升二十五刻，就放水一次，所以四次放水就剛好構成一個晝夜。」從「未」字以下，說明省略的原因。「遑」是顧及。「時節學」是指推算時刻的專門學問，本是獨立的一家學問，無法在這裡全面討論。

【192-0016】02_戒疏/09c_卷二下之二#56
【原文】【註】若初受語，吉羅。往說不報，偷蘭。若還報者，僧殘。若遣使，若書、指印、現相，隨媒多少，說而了了，隨其往反，一一僧殘；若不了者，偷蘭。除二道，說餘身支節而媒嫁者，偷蘭。若媒非人、黃門、二根者，偷蘭。若媒畜生及人男者，吉羅。若持他書往而不看，若為白衣作餘使者，吉羅。比丘尼同犯。不犯者：若男女先通，後離，還合；若為父母疾患、繫閉，看書持往；信心精進俗人亦爾；若為佛、法、比丘使，亦同。
【譯文】【註文】如果剛開始接受了託付之語，犯吉羅罪（突吉羅）。前往向對方說合卻沒有回來回報結果，犯偷蘭遮罪。如果回報了結果，犯僧殘罪。如果是差遣使者，或者藉由書信、手印、擺出形相，無論做媒的次數多寡，只要表達得清楚明白，隨著每次信差的往返，一次就結犯一個僧殘罪；如果表達得不明確，犯偷蘭遮罪。如果不牽涉男女二道，只是為了牽合其餘肢體部位而做媒的，犯偷蘭遮罪。如果做媒的對象是非人、黃門（閹人或性功能障礙者）、雙性人，犯偷蘭遮罪。如果替畜生或者男人之間做媒搞同性淫事，犯吉羅罪。如果攜帶他人的書信前往但自己沒有偷看，或者為在家俗人跑腿傳遞其餘世俗信件的，犯吉羅罪。比丘尼同樣犯此罪。不犯的情況：如果男女雙方本來就曾通姦，後來分離，如今只是撮合他們復合；如果是為了父母生病或被關押囚禁，代為送信看信而前往；對於具有信心且精進的俗人也是如此開許；如果是為了佛法僧三寶的事務充當使者，同樣不犯。

【192-0019】02_戒疏/09c_卷二下之二#59
【原文】【疏】「受語吉羅」者，計應是蘭，僧殘方便而吉者，意不往說，對往輕也。
【譯文】【疏文】「剛接受口信犯吉羅罪」，按理說這本是偷蘭遮罪，因為是僧殘罪的方便預備階段卻只結犯輕微的吉羅罪，是因為他心裡並不想真的前去說合，相較於真的前往，罪過較輕。

【192-0020】02_戒疏/09c_卷二下之二#60
【原文】【記】釋注，受語中。「對往輕」者，謂受而不往，故結輕吉。
【譯文】【記文】解釋註文中接受口信的一節。「對往輕」的意思，是指接受了委託但並未真正前往，所以只結犯輕微的吉羅罪。

【192-0021】02_戒疏/09c_卷二下之二#61
【原文】【疏】二、「往就說而不返報」，若報成重，故但偷蘭。
【譯文】【疏文】第二、「前往向對方說合卻沒有回去回報」，如果回去回報了就構成僧殘重罪，如今既然沒回報，所以只結犯偷蘭遮罪。

【譯文】【記文】前往說合就犯偷蘭遮罪，這是僧殘罪的預備方便階段。

【192-0023】02_戒疏/09c_卷二下之二#63
【原文】【疏】「若爾，初罪是蘭而言吉者，則殘罪方便唯是一蘭？」
【譯文】【疏文】問：「如果是這樣，最初接受口信本該是偷蘭遮罪卻說是吉羅罪，那麼僧殘罪的方便預備罪豈不是只剩一個偷蘭遮罪了嗎？」

【192-0024】02_戒疏/09c_卷二下之二#64
【原文】【疏】答：「所言吉者，望為作使，非是威儀，故犯一吉；又傳情欲，更犯一吉。止為息心，故不行往。所以方便，罪同偷蘭，如上『方便義』中，二篇則兩蘭也。」
【譯文】【疏文】回答：「所說的吉羅罪，是針對替人充當差使這件事，這不符合僧人的威儀，所以犯了一個吉羅罪；另外又替人傳遞情欲之念，又犯了一個吉羅罪。只因他後來歇止了念頭，所以沒有真正前去說合。因此這個方便預備罪等同於偷蘭遮罪，就如同上面『方便義』中所說，在第二篇（僧殘篇）中，方便罪便有兩種偷蘭遮（中品蘭與下品蘭）。」

【192-0025】02_戒疏/09c_卷二下之二#65
【原文】【記】問意，躡上二罪，可解。答中。初釋不往犯輕。文明二吉，由此篇犯相，故心雙結：一者應懺，二則非儀。今「傳情欲」，即是應懺也。「所以」下，次明往即結重。指「如上」者，謂作意欲往即吉，受語即下品蘭，還報未及又中品蘭，同上次第三方便矣。文中承前一吉，故云「兩蘭」。
【譯文】【記文】問話的意圖，是緊扣上面兩種罪名而來，很容易理解。答覆當中，首先解釋不前往為何結罪較輕。經文闡明犯了兩個吉羅罪，是由於本篇戒律的罪相，因此起心時雙重結罪：第一是應當懺悔的性罪，第二是違背僧儀的遮罪。現在「傳達情欲」，就是指應當懺悔的過失。從「所以」以下，接著說明前往說合就結犯重罪。指稱「如上」的意思，是指動念想要前往就結犯吉羅，剛接受委託就結犯下品偷蘭遮，前往說合而尚未回報時又結犯中品偷蘭遮，這與前面依序排列的三種方便罪完全相同。文中承接前面的一個吉羅，所以說「兩個偷蘭遮」。
