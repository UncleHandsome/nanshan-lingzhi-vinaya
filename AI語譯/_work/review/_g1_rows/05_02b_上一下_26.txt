== PROBLEM ==
典籍名相張冠李戴。「功德論」是指《分別功德論》（東晉譯，增一阿含經注釋），並非《大智度論》（《大智度論》在律記中通稱為《智論》）。引文「毘尼猶王者祕藏，非外官所司，故曰內藏」正出自《分別功德論》卷一。

== SUGGESTION ==
將「《大智度論》（功德論）」更正為「《分別功德論》（功德論）」。

== ORIG ==
`功德論雙證勝祕。密即祕也。彼云：毘尼猶王者祕藏，非外官所司，故曰內藏。此戒律藏者亦爾。`

== CURRENT ==
「又」字以下，引用兩部論典進一步轉為印證。〔上面是小乘經論，下面則是大乘論典。由於是用來輾轉證明《多論》的觀點，所以在這裏引述。〕《大智度論》（功德論）同時印證了「殊勝」與「祕密」二義。密就是祕的意思。該論說：毘尼就像帝王的祕藏，不是朝廷外官所能掌管的，所以稱為內藏。這戒律藏也是如此。絕非沙彌、沙彌尼以及優婆塞、優婆夷等清信士女所能聽聞見到的，所以稱為律藏。現在只是攝取其深義，用三句話加以概括。《大乘莊嚴經論》則單獨印證「祕密」的涵義。那是偈頌的形式：
