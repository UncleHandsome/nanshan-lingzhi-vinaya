## 一、硬傷：未譯／漏譯／註記錯位（必須改）

### 1. #1「應更從他受」原句照抄
- 原譯：「其餘各種塵土飛來時若沒有作意受食，**應更從他受**。」
- 建議：「……其餘各種情況，若不是作意受的，**就應該再從別人（淨人）重新受一次**。」

### 2. #1 十誦條整句未譯（最嚴重）
- 原譯：「若特輕故觸比丘手，不應受〔「特輕」文可疑〕」——等於沒譯。
- 「不應受」在律語中多指「**不成受／不算是已受（須更受）**」，不宜留白。至少要給出框架譯＋存疑：
  > 「分發食物時，淨人碰到比丘的手；若〔『特輕』二字疑有訛脫〕……碰到比丘的手，就不算受食成立。」

### 3. #1 僧祇「懸空放」條後半照抄
- 原譯：「應語云：『懸空放。』果墮草上即去，不名為受；小停者得為受。」
- 建議：
  > 「淨人分送水果、蔬菜時，（比丘尼）應先告訴他：『懸空放下來。』**果子落到草上、淨人隨即離開，就不算受食；若淨人稍作停留（讓比丘尼取得），才算受食。**」
- 注意「即去」的主語是**淨人**，譯文須補出，否則讀者會誤解成果子滾走。

### 4. #2「火淨已，生芽處更淨」照抄
- 建議：
  > 「若先前已作過**火淨**，後來**發芽的部位要重新作淨**，沒發芽的部位可以吃。」
- 並加註：火淨是律中「作淨」法之一，以火觸（燒）使種子失去生機，屬**不壞生**的規定，與「受食」是兩套制度——這正是本條「生薑發芽不失受，但發芽處要更淨」的關鍵，不注釋讀者看不懂。

### 5. #2 第三種失受只有標題、沒有白話
- 原譯：「三、自變（生變熟）失。」（且與前面「第一是…第二是…」體例不一致）
- 建議：
  > 「第三是**自變失**：所受的生食自己變成熟食，原來的受食效力即喪失，必須重受。」

### 6. #1 段末註記錯位、越界引用
- 原文本段只到「若鎗鑊」，「不得受者」屬 **#2**；譯文卻提前借入，兩段重複。
- 更明顯的是〔**沉重之說為推測**〕這條註——正文裡根本沒有出現「沉重」的解釋，註與文脫節（應是草稿殘留）。
- 建議：
  > 「若鎗（三足釜）、鑊（大鍋）〔這類重器無法如法手授，句未完，下接次段〕。」
  並把「因沉重難以手授」的推測寫進正文或改成〔按：……〕。

## 二、詞義／理解可商榷處

| 出處 | 原譯 | 問題與建議 |
|---|---|---|
| #1「鉢下草」 | 缽底的草墊 | 「鉢下草」是**缽下（墊缽）所鋪的草**，不是「缽底」。改「缽下鋪的草」。 |
| #1「為作證明故」 | 受食必須有人作證明 | 邏輯沒補足。宜作：「受食須由**能作證的人**授與；非人、畜生、無知小兒不能作證，所以都不成受。」 |
| #1「眼暗比丘」 | 視力昏暗的比丘 | 中文不順，且律中「眼闇」多指**眼盲／視力不良**，宜改。 |
| #1「比丘受取行之（自行受取後行食分送）」 | 用括號塞文言 | 應寫成白話：「可由比丘（尼）先受取，再自行分送大眾」；並可加註：已受之食於僧眾間轉授不須更受（與 #2「三失」相呼應）。 |
| #1「作意者得名為受」 | 一律解為「比丘起心作意接受」 | 「作意」的主體（**授者有意施與** vs **受者心中領納**）在「行麨」條有歧義，譯文等於默默選了一邊。建議核《摩訶僧祇律》原文後加註說明。 |
| #1「落比丘上」 | 落在比丘身上 | 「上」所指不明（身上／手上／鉢上皆有可能），不宜坐實，建議「落到比丘（身、手）上〔『上』字所指未詳〕」。 |
| #1「鎗、鑊（三足釜類炊具）」 | 兩器合釋 | 「鎗」音鐺，三足釜；「鑊」是大鍋，未必三足。宜分釋。 |
| #2「鹽變成水得食」 | 依然可以食用 | 法律效果沒點出：應作「**受食效力不失**，仍可食用」；「（受潮）」是譯者添加，宜標〔按〕。 |
| #2「任運失」 | 已過合法進食時間 | 可再落實：「**過了食時（日中之後）**，時限一到自然失受」。 |
| #2「兩木橫置地…脚躡上」 | 直譯動作 | 建議補原理一句：「腳踏木、木承器，即成**以身相連之物受食**」，讀者才懂為何「說受」就成立。 |
| #3「三是身邊沒有第三人」 | — | 宜作「沒有 **（合格的）** 第三人」，因下文僧祇正是在排除睡眠、癡狂、嬰兒、非人、畜生等無效第三人。 |
| #3「便犯」 | 只要坐下即犯波逸提 | 易誤讀成「坐下就犯」。改：「**四緣具足，一坐下即犯波逸提**」。 |
| #3「非人」「淨人」「識別人在邊」「有難緣」 | 沿用術語 | 「非人」宜注（鬼神等）；「識別人在邊」宜作「有能識別（懂事、能見聞辨別）的人在旁」；「危難險緣」生硬，改「有危難等特殊因緣」。 |
| #4「半尋（依八尺為尋計，半尋約四尺）」 | 用漢制換算 | 律中「尋」≈兩臂平伸之長（一庹），半尋≈**一臂之距**，正好呼應第四緣「伸手內共坐」。建議：「相去半尋（約一臂之距，仍在伸手可及範圍內）犯波逸提；一尋半犯突吉羅；二尋以上不犯。」 |
| #1「比丘（尼）」 | 只此處加「（尼）」 | 引律文一律作「比丘」較妥，另於凡例統一說明「尼眾準用」，避免時加時不加。 |

## 三、校勘與存疑的處理方式

1. **「午駝」→「牛駝」**：譯文已逕改為「牛或駱駝」，方向正確，但**逕改未標**。應補〔「午」疑「牛」之形訛〕。
2. **「萆」**：猜「草蓆」方向可從，但只寫〔待考〕而不給理由，說服力不足。可補一條理據：此條與 #2「兩木橫置地、脚躡上而言受」同屬「**以身相連之物受食**」的原理，故「萆」當是可按住、可承食的墊具或盛器，疑為「**蓆**」或「**箄**」（竹托盤）之訛。建議譯：
   > 「視力不良的比丘，可以按住〔蓆／箄一類的墊具或盛器〕受食〔『萆』字疑訛，待考〕。」
3. **「特輕」**：除標〔疑〕外，可提出假說供核對——「特」疑為「**持**」之形訛；律中常見以**所持物輕重**判觸手之開遮（重物不得不觸則開，輕物可避而故觸則不成受）。若屬此類，可暫譯「若所持之物輕（本可避免接觸）而仍故意碰到比丘的手，就不成受」，但**務必標為推測**，並回查《十誦律》(T23, no.1435) 受食相關文。
4. 建議所有存疑一律採「**白話主文＋〔校注〕**」，**不要把文言原句留在正文當譯文**（目前 #1 有三處、#2 有一處）。必要時可附（原文：……）供對照。

## 四、體例一致性

- 序號體例統一：#2「第一是…第二是…三、…」不一致。
- 律名：首次出全名（如《四分律》），其後可用「本律」；#1「此律除水及楊枝」宜註明此即**戒本**本文，並補「（本戒為波逸提）」。
- 術語統一：受食成立／得受／失受，目前「受食成功」「合法受食」「受食效力」混用，雖不算錯，但同一篇宜收斂為一組固定說法。
- 跨段斷句：#1 末「若鎗鑊」與 #2 首「不得受者」為同一句，建議兩段都標〔句未完／承上段〕，避免重複或斷裂。
- 可加一則短註說明「受食」的制度意義（由淨人手授、比丘尼如法領納，未受而食即犯），讀者才知這一大段塵土、汗水、擲果的討論在爭什麼。
