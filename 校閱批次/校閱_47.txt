# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【47-0001】資持記/10c_中三下#57
【原文】八十二。〔佛在舍衛，外道路中止息，忘千兩金，比丘見之持還，便言金少，王斷罰謫入宮，因制。〕正名中，初示名有據。論如下引。因下，廢古所立。彼執緣起，謂拾遺犯提，手捉但吉，故召為拾遺。戒緣中。此戒犯相有二：若但捉寶，唯有三緣，初二及五；若於聚落，拾他遺寶，方具五緣；
【譯文】第八十二條戒。〔佛陀在舍衛國時，有外道在路途中間歇息，遺忘了千兩黃金，比丘看見了替他收存送還，外道竟然反咬誣陷說金子短少了，國王查核後對其施以罰責送入宮中，佛陀因而制戒。〕在確立戒名中，首先表明戒名是有經論根據的。論典的依據如下文所引。「因」字以下，廢棄古代大德所立的名目。彼等拘泥於制戒的由來起因，認為拾取遺失物犯波逸提罪，親手觸摸只是結突吉羅罪，所以稱之為「拾遺戒」。在戒條犯緣中。這條戒的犯戒相狀有兩種：如果單純是觸摸捉持寶物，只有三種犯緣，也就是第一、第二及第五項；如果是在村莊聚落之中，拾取他人遺失的寶物，才需要具備全部五種犯緣；

【47-0002】01_行事鈔/07d_卷中之三#22
【原文】非時入聚落戒八十三。五緣：一非時分，二無啟白喚緣，三不囑授，四向俗人舍，五入門結。《十誦》：若入聚落僧坊、入蘭若處、入本住處，無犯。《四分》：非時者，從中後至明相未出。不囑授比丘，初入村門墮。若僧塔寺事病事，當囑比丘。若獨處一房，當囑比房。《十誦》：無比丘白者，四衢見應白。又無者，發心已去。無者，應白尼三眾。《僧祇》：食雖早竟，即是非時，作白言：「長老！我非時入聚落。」前人言：「可爾！」若道從聚落中過，村中有塔天祠者，當順行直過；若下道左右旋去者墮。《智論》：一切白衣舍，皆名聚落。準此，寺內淨人房院，何為不白？慎之哉！慎之哉！《五分》：若路所經暮須往宿，八難起等，並不須白。《多論》，若總白：「隨到所至處。」若別相白亦善。若先不白，見異寺比丘白，無犯。《明了論》：若有緣須入，先簡擇此事，謂白同戒，觀察正行；律中威儀者得，不者不合。律不犯者：若道由村過，若有所啟白，若喚若請，皆不囑授直往；有三寶緣者，開囑如上。
【譯文】非時入聚落戒八十三。構成犯戒有五種因緣：一、時間屬於「非時」（非食時）；二、沒有信眾召喚祈請的因緣；三、未曾向同住比丘告白囑託（不囑授）；四、前往俗人在家人的房舍；五、一邁入村門或舍門即結犯墮罪。《十誦律》說：如果是進入村落裡的僧人精舍（僧坊）、進入阿蘭若處、返回自己原本的住處，不犯。《四分律》說：所謂「非時」，是指從正午後到次日黎明天明（明相未出）這段時間。不向比丘囑託告知，剛邁入村門即結犯墮罪。如果有為了僧團佛塔寺院的事務或看視病人的事務，應當向同住比丘告白囑託。如果是獨自住一間房，應當向鄰近房間的比丘告白。《十誦律》說：如果身邊沒有比丘可以告白，在十字街頭碰見比丘應當向其告白；如果還是沒有，在心中發起告白的心念然後前往；如果沒有大比丘，應當向比丘尼、式叉摩那、沙彌尼等尼部三眾告白。《摩訶僧祇律》說：午齊吃完即便時間尚早，也是屬於「非時」，應當告白說：「長老！我非時要進入聚落。」對方回答說：「可以！」如果道路剛好穿過聚落，村中有佛塔或天祠天廟，應當順著道路筆直走過；如果離開大道在村中左拐右逛遊走，結犯墮罪。《大智度論》說：所有在家人居住的房舍，都稱作「聚落」。照此看來，寺院內俗人淨人居住的院落房舍，為什麼不事先告白呢？務必審慎！務必審慎！《五分律》說：如果是趕路途中天色已晚必須借宿、或者發生八難災患等危急情況，全都不需要告白。《薩婆多毘尼毘婆沙》說：如果作概括性的總告白說「我隨處走到某地」，或者作具體詳細的分別告白，都是好的。如果起初沒有告白，路上遇見其他寺院的比丘而向其告白，也不犯。《律二十二明了論》說：如果有因緣必須進入村落，應當先審慎抉擇這件事，也就是向同戒比丘告白，自我檢察身心端正正行；符合律中所規定的威儀才可以進入，不符合則不合理。律典中不犯的情況：如果是道路穿過村落必須經過；或者是有事需要前往村中向人稟白說明、或是受村人召喚、或是受人邀請，都可以不經向僧人囑託而直接前往；若有涉及三寶之事的因緣，則開許依前法囑託同住比丘後前往。

【47-0003】資持記/10c_中三下#58
【原文】共拾遺衣，但應得吉；伽灆宿處，有寶無寶，一切開拾。如下引明。三非住處，即非伽灆；及宿處者，謂非俗舍。釋第一中，《多論》，初明真寶。七名即金、銀、摩尼、真殊、珊瑚、硨礛、碼碯，律中又有琥珀、琉璃、具玉。〔彼論錢入似寶。〕若下，次明似寶。取得吉者，論云為畜故取也。
【譯文】如果只是共同撿拾遺落的衣服，只應當結突吉羅罪；在僧寺僧伽藍以及寄宿處，無論遺失的是不是寶物，一切都開許撿拾保管。正如文後引用闡明。第三項「非住處及宿處」，非住處是指並非僧伽藍，非宿處是指並非俗人居舍。在解釋第一項中，《薩婆多論》首先說明真正的寶物。七種名稱就是金、銀、摩尼寶珠、真珠、珊瑚、硨磲、瑪瑙，律中另外還有琥珀、琉璃、美玉。〔彼論將銅錢列入似寶之中。〕「若」字以下，接著說明似寶。拿取結突吉羅罪，是論中說因為想蓄積佔有而拿取。

【47-0004】資持記/10c_中三下#59
【原文】不取者，論作不應自取，如法說淨。〔準不為畜，捉應無過。〕上文通論畜捉。若捉下，單明捉犯。金薄謂裹貼之物，金像或貼或鑄者。似寶入百一，捉畜皆開，已外俱吉。《僧祇》中，初通明制意。知事當開，教亦不許，而況餘人，故云乃至。若下，別示供具又三，初通列供會。供養具下，明鋪設供興。
【譯文】「不自取」，在論中寫作不應當自己拿取，應當如法說淨轉移。〔照此推論如果不為了蓄積，單純觸摸應當沒有罪過。〕上文是通貫討論蓄積與觸摸。「若捉」以下，單獨說明觸摸的結罪。金箔是指包裹張貼之物，金像有的是貼金箔有的是鑄金造成的。似寶如果屬於百一長物之內，觸摸與蓄積都開許不犯，在此之外的情況全都要結突吉羅罪。《僧祇律》中，首先全面闡述制戒的意圖。僧團知事原本應當開許，教法中尚且不許他觸碰，更何況是其餘尋常人，所以說「乃至」。若「若」字以下，分別開示各類供具又有三項，首先通列種種供養法會。「供養具」以下，說明鋪設陳列供品法器。

【47-0005】資持記/10c_中三下#60
【原文】裹手捉者，恐損壞故，暫開佐助；世有持戒者，裹手捉錢，愚教之甚。若浴下，正明浴像。不得後放者，必須先放，意表助他故。釋第二中，《多論》，初明女飾。下簡男物。兵樂二器，捉亦犯吉，所以除之。矟所角反，矛之長者。若下，明使同類，能所俱重。律下，次引本律。即不犯中文。
【譯文】以布裹手觸拿，是擔心器物損壞，所以暫時開許從旁輔助協助；世間有些自命持戒的人，用布包裹著手去拿錢幣，這真是愚昧不解教理到了極點。「若浴」以下，正式說明浴佛像的規定。「不得後放」，是必須（比淨人）先放手，用意在於表明自己只是輔助他人洗沐。在解釋第二項中，《薩婆多論》首先說明婦女的飾品。下文簡別男子的用品。兵器與樂器這兩種器具，觸摸了也犯突吉羅罪，所以將其排除。矟，音所角反，指的是長矛。「若」字以下，說明若是驅使同類的器具，主使者與被使者罪過同樣沉重。在「律」字以下，接著引用本律。就是指不犯條文中的文字。

【47-0015】02_戒疏/02a_卷一上之二#79
【原文】【疏】如理體三寶，同上次列。若覈其本，證理方具，法寶為初；但理不自顯，託行以彰，故先五分，佛寶居首。又解：理由人顯，道假行成，釋尊出世，方聞三寶，還依化相，故理無別。
【譯文】【疏文】例如理體三寶，順序如同前面所列出的那樣。如果深究其本源，必定是證得真理之後三寶功德才得以具足，因此在理體上法寶應當居於最先；然而至理不會自行顯露，必須寄託於修行實踐才能彰顯，所以先推崇五分法身，佛寶因而位居首位。又有一種解釋：真理是借由人才能顯揚，正道是憑藉修行才能成就，釋迦牟尼世尊出興於世間，眾生才得以聽聞三寶之名，終究還是必須依循化相三寶的次序，所以在理體上三者的先後並無分別。

【47-0016】02_戒疏/02a_卷一上之二#80
【原文】【記】理寶中。初二句指前眾相。「若」下，進退以釋。約證，法合居先；從行，佛當在首。「又」下，重解。比例化相，並佛為初。
【譯文】【記文】在理體三寶的科判中。前面兩句是指向前面眾相科判中所排列的順序。「若」字以下，從進一步與退一步的角度來互為解釋。若就證悟實體的先後來論，法寶理當排在最前面；若從起行實踐的角度來說，佛寶應當排在最首要。「又」字以下，是另一重解釋。比照化相三寶的規律，同樣都是以佛寶居於第一。

【47-0017】02_戒疏/02a_卷一上之二#81
【原文】【疏】二、明化相，佛先、法次、僧後者。以釋迦初證，唯佛獨尊，非尊不可在初，故為首也。大聖雖現，止得動其耳目，至於煩惑，要假法除，次演聲教，用滌心惱。教之所及，行是所歸，雖說無證，還同不說，故拘鄰會正，方僧寶現。此則化儀次第，不可乖也。
【譯文】【疏文】第二、說明化相三寶中，佛寶在先、法寶次之、僧寶在後的理由。這是因為釋迦牟尼佛最初成道證悟之時，全宇宙唯有佛一人最為獨尊，非至尊者不可位居初始，所以立為首位。大聖佛陀雖然示現於世間，但如果只是端坐世間，頂多只能震撼引動眾生的耳目聽聞，至於眾生內在幽深的煩惱惑業，必定要憑藉法寶才能斷除，所以緊接著演說音聲言教，用以洗滌眾生心中的塵勞熱惱。然而言教的化導力量所至，實踐行持才是歸宿，如果光有說法而沒有人起行證得，那就如同沒有說法一樣，直到拘鄰會入正道，此時僧寶才正式顯現。這就是化相示現教儀的先後秩序，是絕對不能混淆違背的。

【47-0019】02_戒疏/02a_卷一上之二#83
【原文】【疏】三、住持中，僧初、法次、佛後者。由道假人弘，世途法爾。故迦、竺初達，現僧儀也；述五乘為善因，明三途為惡果，現法儀也；斯法遠大，非凡小之所開，故表畫像於涼臺，推其所說，現佛儀也。
【譯文】【疏文】第三、在住持三寶之中，僧寶居初、法寶次之、佛寶居後的理由。這是因為大道全憑人去弘傳推廣，世間大道的常態本來就是如此。所以迦葉摩騰與竺法蘭兩位尊者最初抵達中土，首先展現出剃染僧寶的威儀；接著向世人講述五乘教法作為修善的因，闡明三途為造惡的果，這才展現出法寶的教規儀制；然而這些佛法深遠廣大，絕非一般凡夫小乘的心量所能開顯創立，於是漢明帝為了表彰法源，在涼臺繪畫佛陀聖像，推究其所說法源，這才顯現出佛寶的形像儀軌。
