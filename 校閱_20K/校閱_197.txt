# 校閱材料　第197檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【197-0001】02_戒疏/04b_卷一下之二#140
【原文】【記】所持中。標示但云「持」者，下列四行，合須云「犯」。或是語略，或可翻「持」，自可明故。下約制聽二門，止作互歷，故言「交絡」。
【譯文】【記文】在所持法之中。標題雖然只說「持」，但下文列出四種行持，按理應該兼說「犯」。這或許是文句省略，或者只要反轉「持」的意義，犯相自然清楚明白的緣故。下文依照制、聽二門，將止持與作持交互推演，所以稱作「交絡」。

【197-0002】02_戒疏/04b_卷一下之二#141
【原文】【疏】先出二教之意。
【譯文】【疏文】首先說明這兩種教法的立意。

【197-0003】02_戒疏/04b_卷一下之二#142
【原文】【記】「先出二教」者。今明持犯，唯據律藏，文雖浩愽，不出制聽。特異古師濫通餘行。故須先示二教大綱。
【譯文】【記文】「先出二教」這句話。如今說明持戒與犯戒，完全依據律藏，律藏文字雖然博大浩瀚，但不出制教與聽教。這特別有別於古代論師含糊濫雜其他修善行門的說法。所以必須先標示出這兩種教門的大綱。

【197-0004】02_戒疏/04b_卷一下之二#143
【原文】【疏】言「制教」者，禁諸出家，有惡皆斷，名「制止」也。有善斯習，名「制作」也。若斯以明，是大略也。若違此二，雙結兩罪。並由制成，故號「制教」。
【譯文】【疏文】所說的「制教」，是約束所有出家人，凡是有惡法皆須斷除，稱作「制止」；凡是有善法皆須學習奉行，稱作「制作」。若能這樣明白其旨趣，這就是整體的大略綱領。如果違背了這兩種教令，兩者皆會結罪（違制止結作犯罪、違制作結止犯罪，雙雙結成兩罪）。這些全是由於佛陀的強制戒律而成立的，所以號稱「制教」。

【197-0005】02_戒疏/04b_卷一下之二#144
【原文】【記】制教中。初示二持。未陳別相，退舉總意，故云「大略」。「若」下，明兩犯。制止反作，制作反止，皆名違教，一一結罪。
【譯文】【記文】在制教之中。最初標示出兩種持戒。在尚未陳述個別戒相之前，先總括提出整體大意，所以說「大略」。「若」字以下，說明兩種犯戒。對制止的戒反而去作，對制作的戒反而止步不作，都稱作違背教法，一項一項都要結罪。

【197-0006】02_戒疏/04b_卷一下之二#145
【原文】【疏】言「聽教」者，作與不作，一切無罪。
【譯文】【疏文】所說的「聽教」，是指去做或不去做，全都完全沒有罪過。

【197-0007】02_戒疏/04b_卷一下之二#146
【原文】【記】聽教中。如造房、畜長，必不俯從，乃成上行。依開而作，自攝下根。今望「作」、「不作」邊，故言「無罪」。然至作時，還須依教，房舍尺量，長衣日限，違則有罪。
【譯文】【記文】在聽教之中。例如建造房舍、蓄留長物，如果不刻意順從這些開許，那就是成就清苦卓絕的上等行持；若是依照開許去作，自然可以包容攝受中下根器。如今單就「作」與「不作」本身而言，所以說「沒有罪過」。然而到了真正去作的時候，還是必須遵照教法的規範，房舍必須合乎長寬尺度，長衣必須符合留置天數的限制，若有違背依然是有罪的。

【197-0008】02_戒疏/04b_卷一下之二#147
【原文】【疏】故《地持》云：「有罪，行者制；無罪，行者聽。」文成證也。
【譯文】【疏文】所以《菩薩地持經》說：「若是有罪過的行為，佛法便予以禁制；若是無罪過的行為，佛法便予以聽許開行。」這段經文正可作為明證。

【197-0009】02_戒疏/04b_卷一下之二#148
【原文】【記】引證中。「行」字平呼，謂造作也。
【譯文】【記文】引證之中。「行」字讀作平聲，是指造作（即造作之事）。

【197-0010】02_戒疏/04b_卷一下之二#149
【原文】【疏】所以須二者。唯制不開，中下絕分，進道無由。唯開不制，則令上行慢求，息於自勵。故立此二，攝機斯盡。
【譯文】【疏文】之所以必須具備這二教的緣故：如果只有嚴格的禁制而沒有方便的開許，中下根器的人將徹底無分於戒法，進修聖道便無從著手；如果只有寬鬆的開許而沒有嚴厲的禁制，則會使上等修行人產生放慢偷安之求，止息了自我策勵的道念。因此確立這兩種教法，所攝受的根機才算毫無遺漏。

【197-0011】02_戒疏/04b_卷一下之二#150
【原文】【記】出意中。初句總徵。「唯」下，別釋。初明須聽。「唯開」下，次明須制。上行忻制，乃能勇進，唯開退屈，故云「慢求」。「故」下，通結。立斯二教，攝彼三根，故云「斯盡」。然上根稟制，未必從聽。中下二根，制聽齊奉。
【譯文】【記文】在說明立意之中。第一句總括發問。「唯」字以下，分別解釋。首先說明何以需要聽教。「唯開」以下，接著說明何以需要制教。上根之人欣樂佛制，才能勇猛精進，若只有開許則會退轉懦弱，所以說「慢求」。「故」字以下，通盤總結。確立這兩種教法，便能徹底攝受上中下三根之人，所以說「斯盡」。然而上根者奉行制教，未必會依從聽教的開許；中下二根之人，則必須制教與聽教一併奉行。

【197-0012】02_戒疏/04b_卷一下之二#151
【原文】【記】上來諸文，且陳兩教大體，未顯持犯體狀。有人即以二教為體。又復有立萬境為體。並由錯認前文，致斯妄立。委如《事鈔》所破。
【譯文】【記文】以上這些文句，暫且陳述兩大教門的總體大綱，尚未顯明持犯的具體實質體狀。有人便直接拿這兩種教法當作持犯的本體；又有人設立世間形形色色的萬千境界當作持犯體。這全是由於錯認了前文的本意，才導致如此妄加設立。詳細的辨正正如《事鈔》所破斥的那樣。

【197-0013】02_戒疏/04b_卷一下之二#152
【原文】【疏】如昔解云：「二教攝法，各有分齊。止持作犯，唯對二教事相以明；作持止犯，通對二教法、事以辨。所以前段不通法者，法唯進修方知，事但離過自攝，故所以異。」
【譯文】【疏文】正如往昔的解釋說：「這二種教法所攝受的事法，各有其範圍界限。止持與作犯，唯獨對照二教之中具體的事相來加以說明；作持與止犯，則通盤對照二教之中的法軌與事相來進行辨析。之所以前一段不通於法軌，是因為法軌唯有在積極進修時才能顯發，事相只要遠離過失自身收攝即可，所以兩者才有所不同。」

【197-0014】02_戒疏/04b_卷一下之二#153
【原文】【記】正明體中，初科，昔解。「止持作犯」，局事無法，與今少異。餘則大同。「所以」下，自釋不通之意。以律制法，正在進修；止持離過，非進修故。又事通善惡，故該二持；法唯是善，故唯局作。
【譯文】【記文】在正式說明本體之中，此為初科，乃是往昔的解釋。「止持作犯」局限於事相而不通於法軌，這點與當前的觀點稍有不同，其餘部分則大致相同。「所以」字以下，是古人自行解釋不通法軌的緣由。因為律中所制的法軌，主旨正在於精進修持；止持只是遠離過失，並非精進修作之故。又因為事相通於善與惡，所以能包含二持；法軌則純粹是善法，所以唯獨局限在作持。

【197-0015】02_戒疏/04b_卷一下之二#154
【原文】【疏】問：「如上立義，止持唯事，不通法者，如五邪、七非，並非正法，若作有違，義須止約。此法與事殺、盜不殊，有何等故不在止攝？如昔解止，但對事明，於義有乖。今不同彼。無論事、法，聖制止作，則通持犯。下以位分，體狀無別。」
【譯文】【疏文】問：「如果按照上面所立的義理，止持唯獨局限於事相，而不通於法軌，那麼例如調達五邪法、七種非法羯磨（七非），這些全都不符合正法，如果去造作便屬違犯，按理必須加以抑止約束。這類非法與具體事相上的殺生、偷盜並無二致，有什麼緣故不能被收攝在止持之中呢？如同古人解釋止持只對照事相來說明，在義理上顯然有所乖違。如今我的主張與彼不同：不論是事相還是法軌，只要是聖教所制定的止與作，全都通於持犯四行。下文雖然以階位作劃分，但它們作為持犯體狀的本質並無差別。」

【197-0016】02_戒疏/04b_卷一下之二#155
【原文】【記】今義中。初牒彼解；「如五」下，舉法比難；「如昔」下，斥非立義。此謂事法既有止作，則通四行。「下以位分」者，即後四門並舉事法，對可學、不可學以明體狀。方顯止門與作齊等，故云「無別」。則異古師單複偏對也。
【譯文】【記文】當前正義之中。最初重提對方的解釋；「如五」以下，舉出非法之例來作對比詰難；「如昔」以下，駁斥其謬誤並確立今義。這是說事相與法軌既然都存在著止與作的規範，自然通貫於持犯四行。「下以位分」，是指後面的四門都同時舉出事與法，對照著「可學」與「不可學」來說明持犯體狀。如此方能彰顯止門與作門是完全平等的，所以說「無別」。這就與古德只偏頗地以單一事相或雙重事法來相對待的情況不同了。

【197-0032】02_戒疏/04b_卷一下之二#171
【原文】【記】答：「但由持犯，必對境緣。如犯淫戒，須託三境。如持殺戒，亦對三趣。至論持犯，自指淫殺。《論》云『託境』，豈不思之？又境是局狹，收緣不盡。如諸戒列緣，境唯一種；若言淫事，一切皆收。又復於一男境，自發五十六戒。若但言『境』，境即通漫；今言『事』者，即指別戒。」

【197-0037】02_戒疏/04c_卷一下之二#1
【原文】【記】法中。「五邪」，即調達五法：一、乞食；二、糞衣；三、露坐；四、不食酥鹽；五、不食魚肉。五皆盡形，一制無開，故名「邪」也。「七非」者，謂所作羯磨違律制也：一、非法非毗尼；二、非法別眾；三、非法和合；四、如法別眾；五、法相似別眾；六、法相似和合；七、呵不止。廣如《業疏》。此二惡法，不殊淫盜，故云「同止」。
【譯文】【記文】在法規方面。所謂「五種邪法」，就是提婆達多所立的五項規定：第一、常行乞食；第二、常穿糞掃衣；第三、常露天而坐；第四、終身不吃酥油與鹽；第五、終身不吃魚和肉。這五條都要求終身奉行，一律強制遵守且絕無開許，所以稱為「邪法」。所謂「七種非法僧事（七非）」，是指僧團所舉行的羯磨會議違反了戒律規定：第一、作法不合佛法也不合毗尼；第二、作法不合法且僧眾未全體出席（非法別眾）；第三、作法不合法且強行假和合（非法和合）；第四、作法合乎律法但僧眾未全體出席（如法別眾）；第五、作法看似合法但僧眾未全體出席（法相似別眾）；第六、作法看似合法且強行假和合（法相似和合）；第七、有人抗議制止卻仍強行表決（呵不止）。詳細內容如同《業疏》所載。這兩種惡法，罪過與淫戒、盜戒沒有差別，所以疏文說同樣屬於止持（同止）。

【197-0038】02_戒疏/04c_卷一下之二#2
【原文】【疏】言不可學事者，由心迷倒，隨境不了，於殺盜境，疑慮不分，望非犯位，故是「止持」。而心不了，是「不可學」。
