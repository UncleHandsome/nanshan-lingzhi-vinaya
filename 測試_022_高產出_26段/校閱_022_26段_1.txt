# 校閱材料（022）第1份

以下提示詞請連同材料一起貼給 AI：

你是南山律典譯文的校勘者。逐段比對原文與白話譯文，找出譯文的錯誤。

### 第一階段：逐段點名（**每段都必須有一行，不可跳過**）

對每一段輸出一行，格式固定：

```
022-0001｜OK
022-0002｜P1 主詞：譯文把「不作」改成「為其作」
022-0003｜P0 相反：開緣被譯成遮止
```

- `OK` ＝ 這段沒有問題。
- 有問題就寫 `P0/P1/P2` ＋類型（主詞／範圍／術語／相反／漏譯／增譯／程序／數目／引文界線／標點）＋**10 字內**摘要。
- 這階段不要寫理由、不要寫建議，一行為限。

### 第二階段：只對第一階段標了問題的段，補完整說明

```
### 022-0002｜P1｜主詞
- 問題：（30 字內，指出原文哪句、譯文錯在哪）
- 改法：（直接給要換上的字句，不要整段重寫）
```

- **不要**貼原文、不要貼譯文全文（材料裡已有）。
- **不要**寫「依據」欄，除非引用出處是判斷關鍵（如《資持記》某句）。

### 第三階段：回頭找漏（重要）

第一、二階段寫完後，重新讀一次材料，針對剛才標 `OK` 的段，逐段自問三題：

1. 主詞／施受關係對嗎？
2. 範圍（誰、何時、幾人、幾處）有被放大或縮小嗎？
3. 律學術語（波羅夷、僧殘、偷蘭遮、突吉羅、羯磨、說淨、受隨…）用對了嗎？

只要有一題答不上「確定對」，就補一條到第二階段。

### 輸出上限與取捨

- 寧可誤報，不可漏報。誤報由第二人複核，漏報沒人補。
- 每段最多報 3 條，同一段的問題合併寫。
- 不確定就標 `P2 待確認`，不要寫「材料不足」或「存疑」——那等於沒報。

### 收尾

最後一行固定：

```
已檢查 N／M 段；OK x 段、P0 a、P1 b、P2 c
```

若 N < M，另列未檢查的編號。

【022-0001】01_行事鈔/07b_卷中之三#1
【原文】用蟲水戒十九。四緣：一是蟲水，二知有蟲，三不作漉法，四隨所用犯。律云：若以草土擲蟲水中。若蟲酪漿、清酪漿、若漬麥漿、若醋，有蟲，以澆泥草，若以草土擲中，一切皆墮；教人亦同。《五分》：隨用蟲，一一墮。律中若以草土擲水中，隨河池中魚蟲，一一提。《大集》云：畜生身細猶如微塵十分之一，乃至大者百千萬由延。《僧祇》：蟲細者，三重漉，猶有者，捨去。若用水者，日日諦視，無蟲便用；以蟲生無定，或先無今有故。《五分》：蟲水者，漉囊所得，肉眼所見；若用水，蟲蟲墮。無漉囊不得半由旬行，若無者用衣角漉之。律不犯中：不知有蟲，作無蟲想；若蟲大，以手動水令蟲去；若漉水洒地，若教人漉者，一切不犯。
【譯文】用蟲水戒十九。具備四種緣成犯：一、確實是有蟲的水；二、明知水中含有蟲；三、不依律法進行過濾（漉水）；四、隨著使用該水而結罪。《四分律》說：如果將草木或泥土丟擲到有蟲的水中；或者生了蟲的酪漿、清酪漿、浸麥漿或是醋，其中生有蟲，卻拿來澆灌泥土和草木，或者將草土擲入其中，所有這些行為皆結波逸提（單墮罪）；教唆他人去做也是同樣結罪。《五分律》說：隨所使用的水中每一隻蟲，每有一蟲便各結一個波逸提（單墮罪）。《四分律》中說：如果將草木泥土擲入水中，隨著江河池沼中受害的魚類與微蟲，每一條生命皆各結一個波逸提（提）。《大集經》說：畜生的身體細小者，猶如微塵的十分之一，乃至巨大者可達百千萬由延（由旬）。《僧祇律》說：如果蟲體極其細小，應當用三層濾水囊過濾，若過濾後依然有蟲，則應將水捨棄不用。如果要用水，每天都必須仔細端詳審視，確認無蟲便可使用；因為蟲類的生長沒有定規，或許先前沒有而如今卻生出了。《五分律》說：所謂蟲水，是指濾水囊過濾所得、肉眼所能見到的微蟲；若使用含有這類蟲的水，每害一蟲皆結一個波逸提（單墮罪）。比丘若無濾水囊，不得出行半由旬；若實在沒有濾水囊，應當使用衣角來過濾水。《四分律》所定不犯的情況包括：不知道水中有蟲，作無蟲想而使用；如果蟲體較大，用手撥動水流使蟲自行離去；如果是過濾之後的水用來灑地；或者教人依律過濾者，一切都不結罪。

【022-0003】01_行事鈔/07b_卷中之三#3
【原文】輒教尼戒二十一。四緣：一不為僧差，二集於尼眾，三說法教誡，四言了使犯。律中僧不差說法八敬，俱墮；日非，吉羅。《僧祇》：前三後二，此日去者，名為日非。但德須具十，人行又布；今但為略法，如刪補羯磨。
【譯文】輒教尼戒二十一。具備四種緣成犯：一、未經僧團差派（不為僧差）；二、召集比丘尼眾；三、為其說法教誡；四、言語說畢便結犯。《四分律》中說：未經僧團差派而為尼眾說法或教誡八敬法，皆結波逸提（單墮罪）；若非在指定時日前往（日非），結突吉羅（吉羅）。《僧祇律》說：以半月布薩日為準，前三天與後兩天，若於這些日子前往教誡，稱為「日非」（非時）。但能教誡尼眾的比丘必須具備十種德行，且其人格操行又當廣布著稱；如今只作簡略的教誡法，如同《刪繁補闕隨機羯磨》（刪補羯磨）中所述。

【022-0004】01_行事鈔/07b_卷中之三#4
【原文】與尼說法至日暮戒二十二。六緣：一是僧差，二尼眾來集，三教誡說法，四日暮，五知想，六說法不止，犯。律中：除教授，若受經、誦經、若問、若以餘事，乃至日暮。除尼，若為餘女受經至暮，一切吉羅。不犯者：教授尼至日未暮便休；除婦女已，為餘人；若船濟處說法，尼聽；若與賈客共行，夜說法；至尼寺中；若因人請，值說便聽者，一切不犯。
【譯文】與尼說法至日暮戒二十二。具備六種緣成犯：一、是受僧團差派；二、比丘尼眾前來集會；三、為其教誡說法；四、時值日暮；五、明知且認定已到日暮（知想）；六、依然說法不休止，便結犯。《四分律》中說：除了受差教授之外，如果是為尼眾傳授經文、領誦經文、解答疑問，或者因為其他事情而延續到日暮，以及除了比丘尼之外為其他婦女傳授經典至日暮，這一切皆結突吉羅（吉羅）。不犯的情況包括：教誡尼眾在日落之前便及時停歇；排除婦女之後，只為其餘男子說法；在渡口渡船處說法而比丘尼從旁聽聞；與商旅結伴同行而在夜間說法；比丘親至比丘尼寺中；或是因他人迎請，比丘尼正好遇上說法而隨眾聽聞者，一切皆不犯。

【譯文】譏教尼人戒二十三。具備六種緣成犯：一、對方是受僧團合法差派的教誡比丘；二、對方本心完全是為了弘法（情存為法）；三、自己內心懷有嫉妒嫌恨；四、譏嫌毀謗他是為了貪圖飲食供養才去教誡；五、譏諷之言說畢；六、對方聽聞並明白其意。不犯的情況包括：該比丘確實就是為了飲食才去教化，實情本來如此；或者對方本來就是為了獲取供養而進行教授、領誦經文、傳授經典或解答疑問；或者是開玩笑（戲笑）、口誤說錯，一切皆不犯。

【022-0007】01_行事鈔/07b_卷中之三#7
【原文】與非親尼作衣戒二十五。具三緣成犯：一是尼，二非親，三隨作，犯。律中：隨刀截多少，隨一縫一針，皆墮。若復披著牽挽熨治，以手摩捫，若捉角頭挽方正安揲，若緣索線，一切吉羅。不犯者：與親里尼作，若佛塔僧作，若借著者浣染治還主等。
【譯文】與非親尼作衣戒二十五。具備三種緣成犯：一、對方是比丘尼；二、非親屬關係；三、隨作，犯。《四分律》中說：隨剪刀每裁剪一刀、隨縫線每穿縫一針，皆結波逸提（單墮罪）。如果替其披掛試穿、拉扯牽引、熨燙整理、用手撫平摩撫，或者執持衣角拉正疊齊（安揲），或是穿引繫帶索線，這一切附帶動作皆結突吉羅（吉羅）。不犯的情況包括：替具有親里關係的比丘尼縫製；替佛塔、佛像及僧團裁作衣物；若是借穿比丘尼的衣物，將其洗滌、染色、縫補修治完畢後歸還原主等，皆不犯。

【022-0008】01_行事鈔/07b_卷中之三#8
【原文】獨與尼屏露坐戒二十六。四緣：一是比丘尼，二無第三人，三在屏露二處，四共坐便犯。《十誦》：屏處相去一丈墮，丈五吉羅；二丈若過不犯。《僧祇》：共一尼屏坐；或尼請一比丘食，一尼共比丘坐，一尼往來益食。益食去時，隨一一墮。比丘爾時應起，語言：「我欲起。」莫令彼疑作非法。若尼去者不犯。《多論》：比丘坐住屏覆處者，無慚愧處，可作淫處。律中見聞二屏，如二不定中說。若盲而不聾，聾而不盲，若立住，一切吉羅。不犯者：比丘有伴；若有知人，非盲聾；若行過倒地；若勢力持，命梵難者。
【譯文】獨與尼屏露坐戒二十六。具備四種緣成犯：一、對方是比丘尼；二、身旁無第三人；三、處於屏處（隱蔽處）或露處（露天處）這兩種場所；四、一同坐下即結犯。《十誦律》說：在屏障隱蔽處，兩人相距在一丈之內結波逸提（單墮罪），相距一丈五尺結突吉羅（吉羅）；若相距達二丈或超過二丈，則不犯。《僧祇律》說：與一位比丘尼單獨在屏處共坐；或者比丘尼迎請一位比丘應供，一位比丘尼陪同比丘坐著，另一位比丘尼來回添飯加菜。當添飯的比丘尼離開時，單獨相對，隨著每一次獨坐即結一個波逸提（單墮罪）。比丘在那個時候應當立刻起立，並對她說：「我想要站起身來。」切莫讓旁人懷疑比丘在行非法之事。如果是比丘尼主動離開，比丘則不犯。《薩婆多論》（多論）說：比丘坐著或停留在隱蔽屏障處，是指沒有慚愧心之人可以施行淫亂的地方。《四分律》中所指的見屏（眼不見處）與聞屏（耳不聞處），如「二不定法」中所說明。如果第三人眼盲而不耳聾，或耳聾而不眼盲，又或者兩人只是站立停留，這一切皆結突吉羅（吉羅）。不犯的情況包括：比丘身邊有同伴；有通曉事理的第三人在場，且非盲非聾；行路經過時失足跌倒在地；被強有力的勢力強行扣留阻攔；或者遭遇危及性命與梵行之危難（命梵難者），皆不犯。

【022-0009】01_行事鈔/07b_卷中之三#9
【原文】與尼期行戒二十七。五緣：一是尼，二言許共行，三無緣，四同一道，五度界，犯。律不犯者：不共期，若大伴行疑恐怖處，若往彼得安隱，命梵等不犯。《十誦》：開為尼負衣過險徑。
【譯文】與尼期行戒二十七。具備五種緣成犯：一、對方是比丘尼；二、言許共行，承諾同行；三、無合法的因緣；四、走在同一條道路上；五、跨越一個聚落之界限（度界），便結犯。《四分律》中不犯的情況包括：事前未曾相約同行；如果是跟隨龐大的商旅旅伴同行於令人疑懼怖畏的險難之處；或者前往該處能獲致平安安隱；或者為了避免性命或梵行遭遇危難等，皆不犯。《十誦律》開許：為比丘尼背負衣物涉過危險狹隘的險徑，不犯。

【022-0010】01_行事鈔/07b_卷中之三#10
【原文】與尼同船戒二十八。四緣：一是尼，二共期，三同乘上下，四入船，犯。律中，除直度，船師失濟上下水者，不犯。
【譯文】與尼同船戒二十八。具備四種緣成犯：一、對方是比丘尼；二、彼此約定同行；三、同乘一船逆流而上或順流而下；四、登入船中，便結犯。《四分律》中說：若是橫渡水流（直度），或是船夫操作失控偏離擺渡航道而隨順或逆向漂流者，皆不犯。

【022-0011】01_行事鈔/07b_卷中之三#11
【原文】食尼歎食戒二十九。四緣：一尼三眾歎得食，二知，三受得，四咽咽墮。律云：讚歎者，謂阿練若、乞食、乃至持三衣，讚多聞、法師、持律、坐禪。食者，從旦至中所得食，食咽咽墮。除飲食，得餘䞋衣燈油，吉羅。《僧祇》：除舊檀越。乃至下食已，唱等供時，更有餘比丘來，尼言更有比丘，施主言善哉者，不犯。若尼言此十二頭陀者，墮。若言多與好食，平等與，不犯。若言某甲徒眾多聞精進，當通請一眾，一切犯墮。若言某甲眾主精進，為是比丘故通請二十人；一人名讚歎，餘者不犯。若有歎食，不得捨去，當展轉貿食。若比座垢穢不淨，不喜與貿者；當念此鉢中食，是某甲比丘許，我當食者，不犯。若言某甲尊者可常乞食者，不犯。《五分》：若先不知，臨食時言好與比丘食者，不犯。律中不犯者：若不知，若檀越先有意，若無教化想，若尼自作檀越，若檀越令尼經營，若不故教化而與食，不犯。
【譯文】食尼歎食戒二十九。具備四種緣成犯：一、比丘尼等女眾三眾讚歎比丘而令施主布施食物；二、比丘明知此事；三、接受了該項食物；四、每吞咽一口皆結一個波逸提（單墮罪）。《四分律》說：所謂讚歎，是指稱讚比丘住阿練若（寂靜處）、行乞食、乃至受持三衣等頭陀行，或者讚歎其多聞、身為法師、持律嚴謹、精進坐禪等。所謂食物，是指從清晨至正午這段時間內所得的食物，食用時每吞咽一口結一個波逸提（單墮罪）。除了飲食之外，若因此獲得其餘䞋衣（布施衣料）或燈油等物，結突吉羅（吉羅）。《僧祇律》說：原本的老施主（舊檀越）除外。乃至於已經分發食物完畢、宣告普遍平等供養時，正巧又有其餘比丘到來，比丘尼說「還有其他比丘到了」，施主回應說「善哉」而給予食物者，不犯。如果比丘尼稱讚說「這位是修持十二頭陀行的行者」，受食者結墮罪。如果比丘尼說「請多給這位比丘好食」，而施主平等普施給一切比丘，則不結罪。如果比丘尼說「某某長老的門徒大眾多聞精進，應當普請整個僧團」，凡受請者一切皆犯墮罪。如果說「某某僧首大德極其精進」，施主單單為了這位比丘的緣故而一併迎請了二十人；則只有該位被讚歎的比丘結墮罪，其餘被迎請的人不犯。如果所得食物是因讚歎而得，不可逕自拋棄離去，應當與其他比丘展轉交換食物。如果鄰座的比丘身器垢穢不淨，自己不樂意與之交換；應當心中作念：『此缽中之食，是來自某某比丘處（視同已與其交換），我理當受食』，如此食用便不犯。如果比丘尼只是說「某某尊者平時皆可常行乞食」，則不犯。《五分律》說：如果比丘事前並不知情，臨到用齋時比丘尼才隨口說「請好好供養比丘食物」，比丘食用不犯。《四分律》所定不犯的情況包括：比丘不知對方曾作讚歎；施主原本就早有布施之意；比丘於尼之教化作無教化想（誤認非讚歎所得）；比丘尼自己充當施主供養；施主原本就委託比丘尼經辦設供之事；比丘尼並非故意以此教化施主而施主自行給予食物者，皆不犯。

【022-0012】01_行事鈔/07b_卷中之三#12
【原文】與女人期同行戒三十。具犯同尼行戒。律緣以無學為教興，尚被打幾死，何況凡夫！故云，若村內一界行者，吉羅。不犯者：先不知若不共期，須往安隱，命梵緣者。
【譯文】與女人期同行戒三十。成犯的條件與前述「與比丘尼同行戒」完全相同。《四分律》中結戒的緣起，是因為連阿羅漢（無學）以此因緣立教興戒時，尚且遭到女人夫家的毆打幾乎致死，更何況是未斷煩惱的凡夫！因此律中說，若在同一個村落界內相伴同行者，結突吉羅（吉羅）。不犯的情況包括：事先並不知情；未曾相互約定同行；必須前往彼處方能獲得安隱；以及為了維護性命與梵行等因緣，皆不犯。

【022-0013】01_行事鈔/07b_卷中之三#13
【原文】施一食處過受戒三十一。五緣：一施主期限一食，二知是，三重過受，四無因緣，五食便犯。律中開病者，離彼村增劇也。不犯者：一宿受食，病過受食，若諸居士請大德住與食，若次第請與食，若水陸道斷等，不犯。
【譯文】施一食處過受戒三十一。具備五種緣成犯：一、施主設定期限僅提供一餐食物（施一食處）；二、明知施主只有供一餐之限；三、重疊超過限制而再次接受；四、缺乏合法的正當因緣；五、食用該食物便結犯。《四分律》中開許患病的比丘，因為若離開該村落，其病情將會加劇惡化。不犯的情況包括：停留一宿只接受一次食物（一宿受食）；因生病而獲准超過一食的限制受食；眾多居士特別迎請大德長老長住於該處並供養飲食；諸多施主依序輪流迎請供養食物；以及水路或陸路交通斷絕阻隔等，皆不犯。
