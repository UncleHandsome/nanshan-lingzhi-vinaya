# 校閱材料　第412檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【412-0001】02_戒疏/04b_卷一下之二#119
【原文】【疏】有人問曰：「止不行施、禮拜、讀誦，悉為犯者，出在何律，何聚所收？如《律》文云『佛不制者，不應制』也。何以得知不施非犯？如《智論》中『兄弟二人，出家造業，各於施、戒，互不修行。弟為白象，以不持戒；兄獲羅漢，乞食不得，由不行施』，如何而言不施犯罪？」
【譯文】【疏文】有人詰問道：「如果不去布施、禮拜、讀誦，全都算作犯戒的話，這出自哪一部律典？屬於哪一罪聚所收攝？正如《律》中所說『佛陀未曾制定的，不應擅自制定』。憑什麼知道不布施不是犯戒？如《智論》中『兄弟二人出家造業，各自對於布施與持戒互相不肯兼修。弟弟轉世成為白象，因為生前不持戒；哥哥證得阿羅漢果，托缽乞食卻空缽而回，正是因為生前不修布施』，既然如此，怎能說不修布施就是破戒犯罪？」

【412-0002】02_戒疏/04b_卷一下之二#120
【原文】【記】次引正解，斥破中。標「有人」者，即是首師。初難中四。初牒彼計。「出」下，責其無據。「如」下，引文顯妄，即《律》中「非制不制，是制便行」文也。「何」下，舉事證非。迦葉佛時，曾為兄弟，兄但持戒，弟專行施，故云「互不修」也。至釋迦時，感報乃異。今謂兄「不行施」，乃名持戒，明知不施非破戒也。
【譯文】【記文】接著引用正確的解釋來駁斥破除。標示「有人」的，就是指首律師。在第一個詰難中分為四部分。最初重提對方的論點。「出」字以下，責備其沒有律文依據。「如」字以下，引用律文顯明其虛妄，即是《律》中「非佛所制不可制，凡是佛制便奉行」的文字。「何」字以下，舉出故事證明其非。在迦葉佛的時代，曾有兄弟二人，哥哥專持戒律，弟弟專修布施，所以說「互不修」。到了釋迦佛出世時，感召的果報截然不同。如今認為哥哥「不修布施」仍能被稱作持戒並證果，由此可知不布施絕不是破戒犯戒。

【412-0003】02_戒疏/04b_卷一下之二#121
【原文】【疏】「又且律中，但約身口。至於意地，未聞戒訓。如何而言不修四弘，便是犯也？」
【譯文】【疏文】「況且在律藏之中，戒條只針對身業與口業來規範約束。至於起心動念的意地，從未聽聞有任何結罪的戒條訓誡。怎麼可以說不修習四無量心，就算作是犯戒呢？」

【412-0004】02_戒疏/04b_卷一下之二#122
【原文】【記】次難中。即《善見》云：「凡夫常緣欲境，聖人若制心犯，無有得脫之期。」
【譯文】【記文】第二個詰難中。正是如《善見律》所說：「凡夫的心念念攀緣五欲之境，聖人如果連起心動念都要制戒結罪，那麼凡夫就永遠沒有解脫成道的一天了。」

【412-0005】02_戒疏/04b_卷一下之二#123
【原文】【疏】「又若犯者，何曾見悔不施等罪？故《智論》云『不行十二頭陀、四無量心，不名犯戒，但是於戒闕莊嚴耳』。」
【譯文】【疏文】「再者，如果是犯戒，何曾見過律中有懺悔『不修布施』等罪的儀軌？所以《大智度論》說『不修持十二頭陀、四無量心，不叫做犯戒，只不過是對於戒行缺少了莊嚴點綴罷了』。」

【412-0006】02_戒疏/04b_卷一下之二#124
【原文】【記】三難中。由律悔法，必據犯制。「不施等善」，律既不制，豈得有懺？「故」下，引《論》，可見。
【譯文】【記文】第三個詰難中。因為律中的懺悔方法，必定是根據所犯的具體制戒來設立的。「不布施等善行」，律典既然根本沒有制定為戒，豈能有懺悔的法門？「故」字以下引用《大智度論》，意思很明顯。

【412-0007】02_戒疏/04b_卷一下之二#125
【原文】【疏】故知上立違於律、論。若論自行，止可違理。若不修慈，何成道業？毒蛇未出，義不安眠，如救頭然，名「有慚者」。
【譯文】【疏文】因此可知上述古人的立論違背了律藏與論藏。若是就個人的自行修持而言，不修善行頂多只能說是違背了善理。倘若不修持慈悲，如何能夠成就菩提道業？體內的毒蛇若是尚未驅出，按理根本不得安然沉睡；應當如同搶救頭頂燃燒的烈火一般精進，這才稱得上是『具有慚愧心的人』。

【412-0008】02_戒疏/04b_卷一下之二#126
【原文】【記】結顯中。「律、論」即如上引。「若論」下，遮疑。非謂施慈等行，都不修之，但非持犯體耳。須知善行約教二別。如上所列，但屬化教，道俗通修。如後制聽所攝事法，局於制教，唯道行之。故云「止可違理」，則明非違制也。「若不」下，顯示須修，可解。
【譯文】【記文】結語顯正之中。「律、論」就是指上面所引用的文獻。「若論」字以下，排除疑惑。並非主張布施慈悲等行門都不必修習，只是它們並非律宗「持犯」所要探討的本體罷了。必須明白善行依據教別有兩種差異：如上述古人所列舉的，僅屬於「化教」，通於出家與在家人共同修持；至於後文隨佛陀制戒與開許所收攝的僧團事法，則局限於「制教」，唯獨出家人遵行。所以說「頂多只能說是違背善理」，以此表明這絕非違背佛制戒律。「若不」字以下，顯示出家修行者仍必須精進修善，理應明白。

【412-0009】02_戒疏/04b_卷一下之二#127
【原文】【記】問：「此中但破止犯，彼立作犯，有何過失？」
【譯文】【記文】問：「這裡只破斥止犯，古人所立的作犯又有何過失？」

【412-0010】02_戒疏/04b_卷一下之二#128
【原文】【記】答：「前舉十惡，還是化教。十中前七，乃入律制。本宗心犯，如別所論。」
【譯文】【記文】答：「前面古人舉出的十惡業，依然屬於化教範疇。十惡中的前七支（身三口四），才納入律宗制戒。本宗對於起心動念的心犯如何判定，在其他章節有特別論述。」

【412-0011】02_戒疏/04b_卷一下之二#129
【原文】【疏】今更依教，立持犯體，能所分別。
【譯文】【疏文】如今進一步依照律教，確立持犯的本體，並從「能持犯之主體」與「所持犯之客體法」來作分別。

【412-0012】02_戒疏/04b_卷一下之二#130
【原文】【記】正立中，標。云「依教」者，「能所」二體，皆出本律。以《四分》結犯，並問何心。「律序」又云「當審觀意」，雖兼身口，由是無記，非罪福性。今明「持犯」，必約成業，故專取心為能持體。
【譯文】【記文】在確立正確觀點的標題中。說「依教」，是因為能持與所持兩種體，都出自本部廣律。因為《四分律》在結罪判犯時，都會審問是何等心態。「律序」又說「應當詳細審察心意」，雖然也連帶檢視身口二業，但身口動作本身是無記性的，不具備罪業或福德的本質。如今說明「持犯」，必定是根據能否成就善惡業道來論定，所以專門選取「內心」作為能持戒的本體。

【412-0013】02_戒疏/04b_卷一下之二#131
【原文】【記】問：「受中作戒，色心為體。今此能持，即是隨作，但云思心。受隨應等，那不同者？」
【譯文】【記文】問：「在受戒時的『作戒』，是以色法與心法二者為體。如今這能持的體，屬於受戒之後的『隨作』，卻只說是思惟之心。受戒與隨行應當平等相稱，為何會不相同？」

【412-0014】02_戒疏/04b_卷一下之二#132
【原文】【記】答：「受取緣成，必須兼色。隨取成業，但約心論。學者深思，方見遠致。」
【譯文】【記文】答：「受戒著眼於外在儀軌因緣的圓滿成就，所以必須兼顧形體動作的色法。隨行持戒著眼於起心動念是否成就罪福之業，所以單單就心念來論述。學者深入思維，才能看見這層高遠的義理。」

【412-0015】02_戒疏/04b_卷一下之二#133
【原文】【疏】言能持者，即心為體。身口是具，不名為業。若不思慮，不成持犯。
【譯文】【疏文】所說的「能持犯者」，是以心為本體。身與口只是造作的工具，工具本身不能稱作業。如果沒有心思謀慮，就不能構成持戒或犯戒。

【412-0016】02_戒疏/04b_卷一下之二#134
【原文】【記】能持體中，初科。雖通指心，正取思業。
【譯文】【記文】在能持犯的主體中，此為初科。雖然普遍指涉心靈，但真正選取的是發動造作的「思業」。

【412-0017】02_戒疏/04b_卷一下之二#135
【原文】【疏】故《成論》云：「是三種業，皆但是心。離心無思，無身口業。」又云：「身口者，乃是造善惡具，非善惡業體。」
【譯文】【疏文】因此《成實論》說：「這身口意三種業，其本質全都是心。離開了心就沒有造作思慮，也就沒有身業與口業。」又說：「身與口，只不過是造作善惡的工具，而不是善惡業的本體。」
