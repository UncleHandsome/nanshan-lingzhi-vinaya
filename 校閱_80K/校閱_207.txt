# 校閱材料　第207檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】三語中。二無學及教，即人法也。律云彼欲往佛所，中途而止，佛令諸比丘三語度之。欲，即求心

【譯文】八敬受同於三語受的五緣是：第一、大愛道與五百位女人各自剃髮穿上袈裟，依傍佇立在祇洹精舍門外的緣故；第二、就是阿難尊者轉傳八敬法；第三、就是大愛道請求出家；第四、第五種因緣即可依此類推而知。

【207-0004】03_業疏/12b_卷三之一#72
【原文】問：善一受得道為緣，餘三反者？答：對佛德大，不假相具，能轉變故；餘則不爾，如上說也
【譯文】問：為什麼唯獨善來受是以得道為受戒因緣，其餘三種受戒法卻相反（不以得道為因緣）？答：善來受是直接面對佛陀，佛的威德廣大，不須假借外相具足，佛力就能轉變其身相與衣服的緣故；其餘受戒法则不然，就如上面所說的那樣。

【207-0005】03_業疏/12b_卷三之一#73
【原文】問答中。善來對佛，必變形服，故須得道為緣。餘不爾者，不對佛也。破結證聖，形服自變；餘二對資，力不能變。如上說者，即師資中
【譯文】在問答之中。善來受是面對佛陀，必定會自然轉變身形與衣服，所以必須以得道作為得戒的因緣。其餘的不這樣，是因為並非面對佛陀。破結受是證得聖果，身形衣服自然隨之轉變；其餘兩種（三語、八敬）是面對弟子（資），弟子的威德力不能讓受者轉變形服。所謂「如上說」，就是指前面師資差別那一科所說的內容。

【譯文】在羯磨受之中，總括與個別的各種因緣，既然是用來覆被下劣根機，就應當詳細廣泛地彰顯，全部依循律文的註解依序來說明。

【207-0009】03_業疏/12b_卷三之一#77
【原文】初說結不同者，善來、八敬一徧便得，以唱教人大，不假叮嚀，渴法心重，又不須結；三語之法，初受法弱，故須三說，前受心奢，又假三結；羯磨在僧，通和非易，故須四徧，眾心齊忍，與奪已決，故結一也
【譯文】第一是宣說與結告次數的不同：善來受與八敬受宣說一遍便能得戒，因為宣唱教令的人德行尊大，不須多加叮嚀囑咐，而且受者求法之心懇切渴仰，因此也不需要作結告；三語之法，起初傳授的法力較弱，所以必須宣說三次，受戒者先前的求戒之心較為寬散放逸，所以又須假藉三次結告；羯磨受是在僧團中進行，要達到全體和合通融並不容易，所以必須宣說四遍（一白三羯磨），僧眾的心意既然齊一默忍，贊同或反對已經決定，所以只結告一次。

【207-0010】03_業疏/12b_卷三之一#78
【原文】二對同異初中。善來、八敬，機教俱勝，不假叮嚀，謂不須多徧。三語初受法弱，謂能授教劣，一說難感，故至於三；前受心奢，謂所受機劣，恐有陵犯，加結囑之。羯磨四徧，一白三羯磨，以和難故，說須多也。眾既和忍，不假多結。與奪即可否。不同三語別人獨授，故須三徧。破結無法，故非所論
【譯文】在第二「相對辨別異同」的第一點中。善來受與八敬受，根機與教法都極為殊勝，不假借叮嚀囑咐，是指不需要宣說多遍。三語受起初傳授的法力較弱，是指能傳授教法的弟子威德較劣，只說一遍難以感發戒體，所以必須重複到三次；受戒者先前的發心寬散，是指受戒者的根機較劣，恐怕日後有所凌逼毀犯，所以增加結告來囑咐他。羯磨受要宣說四遍，也就是一白三羯磨，因為僧團和合困難的緣故，所以宣說必須多次。僧眾既然已經和合默忍，就不需要多次結告。所謂「與奪」，就是指同意或否決。這不同於三語受是由一位比丘單獨傳授，所以三語受必須結告三遍。破結受沒有特定的作法儀軌，所以不在此討論之列。

【207-0011】03_業疏/12b_卷三之一#79
【原文】二乞有無者，通論四受，理須前告，如今「我欲」即是其相；但羯磨者，通情稍難，若不遜請，無由牒法，故制乞也
【譯文】第二是乞求戒法的有無：普遍來說這四種受戒法，在理則上都必須在事前向師長稟白，如同經文所說的「我想要……」就是乞戒的表現；然而唯獨羯磨受，要讓全體僧眾的心意通達和諧稍有困難，如果受戒者不謙遜地請求，僧團就無從引據法度來為他作羯磨，所以制定了乞戒的儀式。

【207-0012】03_業疏/12b_卷三之一#80
【原文】二中。初通明四受，亦除破結，既不對人，故無從乞。如今「我欲」，「今」合作「文」，即前善來文云「我欲於如來法中」等，即是求乞。三語、八敬並如上引。「但」下別顯羯磨。稍，猶漸也
【譯文】在第二點之中。開頭先普遍說明四種受戒法，這也是除去了破結受，破結受既然不對著人受戒，所以沒有地方可以乞求。如經文說「我欲」，原文中的「今」字應當作「文」字，也就是前面善來受的律文說「我想要在如來正法之中」等語，這就是乞求。三語受與八敬受也都如同上面所引用的律文。「但」字以下個別彰顯羯磨受的特殊性。「稍」，意思如同漸漸、稍顯。

【207-0013】03_業疏/12b_卷三之一#81
【原文】三立名相者，初皆無相，羯磨約緣。由前三受內凡已上，羯磨具縛，有犯性重，故制相也。五、八、十戒，或對俗化儀，或是羯磨犯後，故十戒中列和上名，明知非制前也
【譯文】第三是確立受戒名稱與戒相（立名與相）：起初各種受戒法都沒有宣說具體的戒相，只有羯磨受是依事緣而宣說戒相。因為前面的三種受戒法（善來、三語、八敬）都是內凡位以上的人受持，羯磨受則是具足煩惱繫縛的凡夫所受，可能毀犯自性重罪，所以才制定宣說戒相。至於五戒、八戒、十戒，有些是針對在俗信眾的教化儀軌，有些則是在羯磨受戒有人犯戒之後才制定的，所以在傳授十戒時列出和尚的名字，由此明顯可知並不是在羯磨受之前制定的。

【207-0014】03_業疏/12b_卷三之一#82
【原文】三立名相。名謂受名，相即戒相。初二句略示，上句通舉四受，羯磨受法初亦無相；下句別點羯磨後因犯重方制說相，緣即緣起。「由」下委釋所以。初明三受無相，內凡初果少犯性重，破結無犯，故不在言；「羯」下次明羯磨有相，雖通上聖，正為凡下，故云「具縛」等。「五」下因決餘戒立相之意。對俗化儀謂五、八也；羯磨犯後謂十戒也。由羯磨法制依和尚，故準十戒作法詞中牒和尚名，可驗在後，義見次科
【譯文】在第三「安立名相」中。名是指受戒的名稱，相就是戒相。開頭兩句簡略標示，上一句普遍舉出四種受戒法，羯磨受法在最初也是沒有宣說戒相的；下一句特別指出羯磨受後來是因為有人犯了重戒才制定宣說戒相，所謂「緣」就是指犯戒的緣起。「由」字以下詳細解釋其緣由。首先說明三種受戒法沒有宣說戒相，是因為內凡與初果聖人很少會犯自性重罪，破結受的阿羅漢根本不會犯戒，所以更不用說了；「羯」字以下接著說明羯磨受有宣說戒相，雖然也通於上乘聖人，但主要是為了凡夫下劣之人，所以說「具縛」等。「五」字以下順帶斷定其餘戒法安立戒相的用意。針對在俗的教化儀軌是指五戒、八戒；羯磨受犯戒之後才制定是指十戒。因為羯磨法制定了必須依止和尚，所以比照十戒作法詞中必須稱提和尚名字這一點，可以驗知十戒是在羯磨受之後才制定的，其義理見於下一科。

【207-0015】03_業疏/12b_卷三之一#83
【原文】四立和上者，三語已前未論相攝，因過須師，方制和上。故羯磨興者，意存師資，道成彼此，兼濟文中兩攝也
【譯文】第四是確立和尚的制度：在三語受以前並未論及師資互相攝受，後來因為弟子產生過失而必須依賴戒師管教，才制定了立和尚的規定。所以羯磨法的興立，用意在於確立師徒關係，讓彼此的修道得以成就，同時落實律文中師徒互相攝受之義。

【207-0051】03_業疏/13a_卷三之二#19
【原文】文列《多論》者，以五、八、十戒是具者基，基既先頹，無所加也，何況毀具，反道重受，不可接也。下引諸業者，如汙尼、逆罪，雖無戒犯，然業在生報，戒障三途，正與相違，故成難攝
【譯文】文中列引《薩婆多論》的說法，是因為五戒、八戒、十戒是具足戒的基礎，基礎既然先行崩壞毀塌，就無法再加受具足戒，更何況毀犯具足戒後還俗、如今又想重新受戒，更不可接引。以下引用各類造惡業者，例如淫污比丘尼（污尼）、造作五逆罪等，此時雖然沒有戒律可犯，然而惡業感得來世必受三途生報，而受戒是能阻障三途之法，兩者正好根本相違，所以納入遮難所攝。

【譯文】在「確立弟子」的第一科中：「資」字訓詁為「取」，是指向師長求取法益。因為比丘生病無人瞻視導致殞命，這是制立師弟相依制度的發起由來。

【207-0099】03_業疏/13a_卷三之二#67
【原文】言弟子者，學後解生，故得名也。所以師名隨本音者，此土本無，故不可譯。俗中博士，微有相扶，然備束脩，乖則非禮；佛法不爾，導以義方，開示出道，過恒俗訓，若行贈遺，則是邪緣，故從本也。弟子受學，義相似也，故從此方之言
【譯文】所謂「弟子」，是因為隨師學修之後智慧生起，所以獲得此名。之所以對和尚師尊之名保留梵文原音，是因為東土本土本無此種身分，所以不可直接套譯。世俗中的「博士」，雖稍有相近之處，然而世人備辦肉脯束脩為酬，若有違背便被視為失禮；佛法之中絕不如此，師僧以至高義理導引學子，開示出離生死之道，遠遠超越尋常世俗教訓，若行賄賂饋贈等世俗之禮，反倒成了邪命之緣，所以師名保留梵本原音。而「弟子」從師領受教誨修學，其意趣與世俗相類似，所以採用了此方本有的稱謂。

【207-0100】03_業疏/13a_卷三之二#68
【原文】次科：初釋資名，在後故為弟，從生故為子。「所」下次辨師名。出家之法，始於西梵，故和尚名此土本無。下舉俗禮，明不翻之意。自漢已來，國家多置五經、諸子博士，即學者之師。《禮記》云「君子知至學之難易，而知其美惡，然後能博喻，然後能為師」。束修即肉脯，古者用為見師之禮，今則名通金帛等物，故《論語》云「自行束修已上，吾未嘗無誨焉」。師名恐濫，故不取之；弟子義同，故可比用
【譯文】在第二科中：首先解釋弟子之稱，「居於師長之後」所以稱為「弟」，「由教法化生」所以稱為「子」。自「所」字以下辨析師長之名。出家求道之法源始於西方天竺，所以「和尚」這一名號在此土本來沒有。以下引舉世俗禮儀，說明不直翻的用意。自漢代以來，朝廷多設置五經、諸子「博士」，也就是求學者的師長。《禮記》說「君子懂得進修學業的難易，並知道資質的高下美惡，然後才能廣泛設喻教導，然後才能為人師表」。「束脩」即是成束的肉脯，古代用作初次拜謁師長之禮，後世則通稱金帛禮物，所以《論語》說「只要自行奉上束脩以上的禮物，我未嘗不給予教誨」。佛家師長之名恐與世俗混淆相濫，所以不採用博士等名；而弟子領受教導的意涵與世俗相同，所以可以借用此方之詞。

【207-0101】03_業疏/13a_卷三之二#69
【原文】師弟相攝云敬重者，以出道在心，形雖在卑，以懷道故，敬而後授，故無虗往也。彼我和敬，正法由生，光大遠世，皆賴開悟，深有致也
【譯文】師徒之間互相關照攝受之所以稱為「敬重」，是因為出離生死之道根源於內心，弟子身分雖然卑下，但因其懷抱道心，師長先存恭敬然後傳授法教，所以不會徒勞無功。彼此和合恭敬，正法才能由此滋長顯現，發揚光大於後世，全都仰賴教導開解省悟，這具有極為深刻的道理。

【207-0102】03_業疏/13a_卷三之二#70
【原文】三中：初明師敬資意。以文令共相敬重，恐疑反倒，故特示之。尊卑據形，相敬約心，由心懷道，不可輕故。無虗往者，言資必受教也。「彼」下次釋功益，展轉開悟，相生不絕，至於無窮
【譯文】在第三項中：首先說明師父敬重弟子的深意。因律文命令師弟雙方「共相敬重」，恐人懷疑尊卑顛倒，所以特別加以明示。尊卑貴賤是依外在形儀而言，互相敬重是就內在心志而言，由於內心懷抱道法，決不可輕慢。「無虛往」是指弟子必定真誠受教而無虛度。自「彼」字以下解釋其功德利益，如此展轉開示覺悟，燈燈相傳綿延不絕，以至於無窮無盡。

【207-0103】03_業疏/13a_卷三之二#71
【原文】善見》不請起過者，為束惡緣，制請結之，無輒離也。餘諸法訓，廣如受後及《行事鈔》也
【譯文】《善見論》說若不依禮請師便會生起過咎，這是為了約束惡緣，所以制定必須正式請師建立師徒關係，不得隨意捨離。其餘各項法式訓誨，詳廣內容如受戒之後的章節以及《行事鈔》中所載。

【207-0104】03_業疏/13a_卷三之二#72
【原文】釋制請中：先無請法，度已起過，和尚呵責，便云「誰請汝耶？」因制請之。束惡緣者，令不作過也；請結之者，結為父子也。指如受後，即〈依止〉中；事鈔，即〈師資篇
【譯文】在解釋「制定請師」中：原先沒有請師之法，度人出家之後弟子生起過咎，和尚呵斥責怪時，弟子便頂撞說「是誰請你當師父的？」佛陀因此制定必須正式請師。「約束惡緣」，是使弟子不致放逸造過；「請師建立關係」，是結合成法身父子的關係。文末指引「如受戒之後」，即指〈依止篇〉；指引「事鈔」，即指〈師資篇〉。

【207-0105】03_業疏/13a_卷三之二#73
【原文】文列請法在僧中，欲令受者覩相發敬也。必預須受前一年一月，亦無傷也。人云「一席加法，不延久者，恐心怠也」，於義似失。次第隨禮者，以凡多慢習，戒在敬慎，故折伏形骸，希求淨法，後必思犯，非我輒授也
【譯文】文中列明請師法式要在僧眾大眾之中進行，是為了令受戒者親睹僧伽威儀法相而生起恭敬心。若必定要在受戒前一年或一月預先延請，也無妨礙。有人主張「請師加法須局限在受戒同一法席中進行，不得提早延及久前，是恐受者時間一久心生懈怠」，這在義理上似乎有所欠缺。依序隨位禮拜，是因為凡夫大多具有傲慢習氣，受戒的要旨在於敬奉謹慎，所以必須折伏傲慢之形體身軀，一心希求清淨正法，受戒之後每逢想犯戒時便會反思：這不是師長隨便傳授給我的。
