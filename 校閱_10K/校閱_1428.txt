# 校閱材料　第1428檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1428-0001】04_比丘尼鈔/03a_卷中之上#5
【原文】第二結時者此律雖云前中後三時若據結文正自有二謂四月十六結者是前十七日已去迄至五月十六日來皆稱於後唯一日為前二十九日為後此律大僧不結前安居吉尼不結前同吉不結後提不依大僧安居亦提明了論云無五過處得安居一太遠聚落求須難得二太近城市妨修道業三多有蟻蚊自他兩損四無可依人依人須具五德一求聞令聞二已聞令清淨三能決疑網四通道達俗無滯五除邪見得正見五無施主供給藥食有此五過不可安居僧祇云若親里請尼者先教請比丘不肎者不得受請見論云尼依比丘住處半由旬得安居過者不得前夏檀越為尼請比丘來而尼已安居竟乃至後夏初比丘有緣事不來當更請餘比丘來若不得來應去路有難事者得安居若初安居竟比丘有緣事去尼後方知已結安居者不得移去得住無罪若夏竟不得無比丘處自恣應覓作法僧祇云雖在一比丘處安居至半月時亦應請問布薩無者三由旬內有僧通結取故五分云有比丘自不持律不依持律人安居夏中生疑又無問處乃至佛言依持律處安居若房舍迮者聽近持律師七日往還處於中遙依安居有疑往問此律不依廣誦二部律師得提義云大僧丈夫尚令依律師處住有疑皆須往問譬如嬰兒無時暫離乳母恐生罪累自溺長津今時尼眾觸事無知動乖法式志性昏滯好染俗風孤遊自在不承戒律或伽藍偏僻獨處邊荒或憒閙城隍無僧迥立所以舉動不仁行步失禮八敬罕自無聞三業唯加蜂蠆敬俗倒為闍棃慢僧反為師弟靜言此事良用愾然。
【譯文】第二門「結夏時間」：本律雖然提到前、中、後三種時間，但若依據結夏作法的條文，實際上只有兩種。也就是四月十六日結夏的是前安居；從十七日開始一直到五月十六日之間結夏的，都稱為後安居。其中唯有十六日這一天算前安居，其餘二十九天都算後安居。依本律規定，比丘若不結前安居得突吉羅罪；比丘尼不結前安居同樣得突吉羅罪，但若不結後安居則得波逸提罪；若是不依止比丘僧安居，也得波逸提罪。《明了論》說：沒有五種過失的地方才可以安居：一是距離村落太遠，生活所需難以求得；二是太靠近城市，妨礙修習道業；三是多有蚊蟲蟻穴，對自己與蟲蟻雙方都有損害；四是沒有可以依止的明師，依止的對象必須具備五種德行，即能讓想聽聞正法的人聽聞、能讓已聽聞的人身心清淨、能斷除疑團網絡、能通達出世正道與世俗事務而無障礙、能破除邪見而獲得正見；五是沒有施主供給醫藥和飲食。若有這五種過失，便不可在此安居。《僧祇律》說：如果有親友只邀請比丘尼，應當先勸他們也邀請比丘，若施主不肯，比丘尼便不得接受邀請。《善見論》說：比丘尼依止比丘住處半由旬以內才可以安居，超過這個距離就不行。如果前安居時施主為比丘尼延請比丘，而比丘尼已經結夏安居完畢，到了後安居之初，比丘因故無法前來，應當另外請其他比丘前來；如果請不到人，比丘尼就應當離開；倘若路上有險難阻礙，則獲准就地安居。如果在剛結夏完畢後，比丘因事離去，比丘尼事後才知道，既然已經結夏，就不可遷移離開，繼續安住是沒有罪過的。如果夏安居結束，比丘尼不得在沒有比丘的地方舉行自恣，應當尋求比丘來作法。《僧祇律》說：即使只在有一位比丘的處所安居，每逢半月之時，也應當前往請問布薩事宜；如果沒有比丘，在三由旬之內有僧眾，也可以一同結界作法。《五分律》說：有比丘自己不持戒律，又不依附持律的人安居，在夏天中心生戒法上的疑惑，又無處詢問；佛陀因此指示，必須依止有持律者的地方安居。如果房舍狹窄，聽許在靠近持律律師七天往返路程之內，在該處遙遠依止安居，有了疑問就前往請教。本律規定：不依止博通兩部律藏的律師，得波逸提罪。義理上說：大僧大丈夫尚且被勒令依止律師居住，有了疑慮都必須前往詢問，就像嬰兒一刻也不能暫時離開乳母，唯恐造作罪業過咎而讓自己沉溺在長劫生死之中。如今這時代的尼眾，遇到事情茫然無知，舉手投足都違背法規儀式，心性昏昧閉塞，喜好沾染世俗習氣，獨自雲遊放任自得，完全不遵承戒律；或者寺院偏遠幽僻，孤身住在邊緣荒野，或者身處紛擾喧鬧的市鎮，在沒有比丘僧的地方傲然獨立。因此一舉一動毫無仁慈，行步之間失去禮儀，八敬法自己極少聽聞，身口意三業唯獨像蜂蠍般傷人，恭敬在家人反將其當作阿闍梨，傲慢對待僧眾反視同己出的弟子，靜靜思量這些事，實在令人長嘆悲痛。
