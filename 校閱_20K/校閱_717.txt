# 校閱材料　第717檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【717-0001】04_比丘尼鈔/06b_卷下之下#49
【原文】第六遇賊者此律比丘被剝不得露身行得罪當以輭草樹葉覆形應取長衣著知友僧中覓衣著乞衣得已應還本處否者犯罪母論云令虗發己聲使賊去僧祇云若賊言僧物何處不得示實處又不得妄語應示房舍牀等佛物指塔邊供具等若道中行有露令年少在前若有賊獸難老僧在中央欲令賊起慈心者老僧前行。
【譯文】第六門遭遇盜賊（遇賊），本律規定比丘被盜賊剝光衣服後，不得裸露身體行走，違者得罪；應當用柔軟的草葉遮蔽身體，取用多餘衣物穿上，或在知友僧眾中尋找衣服穿著；乞討得衣物後，應當返回原處，否則即是犯罪；《毘尼母論》說可以虛張聲勢發出聲音以使盜賊退去；《僧祇律》說若盜賊問僧團財物放在何處，不得指出真實位置，又不得說謊，應當指著房舍、床榻等物說是僧物，指著佛塔旁的供具等物說是佛物；如果在路上行走草木有露水，應讓年輕僧人走在前面；若有盜賊、猛獸之險難，年老僧人應走在中間；若想讓盜賊生起慈悲心，則由老僧走在前面。

【717-0002】04_比丘尼鈔/06b_卷下之下#50
【原文】第七濟畜生者律中慈心解他被繫狗子被溺豚子解蘭若處賊繫牛等不犯僧祗云有神力奪賊劫人放諸禽獸皆慈心作者不犯十誦云若悲壞羅網及獄但犯吉羅五百問事云行路寄鬼神屋宿不得有觸擾意違者犯墮。
【譯文】第七門救濟眾生（濟生），律中規定出於慈悲心解救他人被拴縛的狗、將要被溺斃的小豬，或解救阿蘭若處被盜賊拴綁的牛等，都不犯戒；《僧祇律》說有神通力奪回盜賊劫持之人、放走各類禽獸，凡是出於慈悲心所作者，皆不犯戒；《十誦律》說若因悲憫心而破壞捕獸羅網及牢獄，只犯突吉羅罪；《五百問事》說趕路時借宿在鬼神祠廟中，不得有觸動侵擾之意，違犯者犯墮罪。

【717-0003】04_比丘尼鈔/06b_卷下之下#51
【原文】第八雜事者僧祗云然火有七事無利一壞眼二壞色三身羸四衣垢五臥具壞六生犯戒緣七增世俗語五百問事云續佛光明晝不得滅佛無明暗以本無言念齊限故滅有罪大唐波頗三藏法師云佛前燈以物傍取不損光者得僧祗云不得卒持燈入堂唱言諸大德燈欲入乃至滅亦爾以手遮語之不聽用口吹滅應以手扇衣角扇當攲折頭焦成實論云出家之人應捨五慳一財物慳二法慳三家慳四住處慳五稱歎慳染著眷屬愛樂住處故墮迦陵伽等餓鬼中生阿含經云四恩者謂父母師僧國王檀越四輩者謂天龍人鬼此律云非行來處若有小便及洗手足時聽著屐又不得裸身上廁三千威儀經云不洗大小便處不得坐僧坐具上上座禮拜三寶若禮無福應脫袈裟僧祇支大小便不洗大小便不得臥僧臥具若坐臥者吉羅此律云不嚼楊枝有五過一口氣臰二不別味三熱陰不消四不別食五眼不明五分云嚼已應洗棄以蟲食死故又不忍辱人有五過失一兇惡不忍二後生悔恨三多人不愛四惡聲流布五死墮惡道此律云經行有五益一堪遠行二能思惟三少病四消飲食五得定久住母論云詣寺乞人無糧食者嬰兒獄囚懷妊等類施之無過僧祇云作樂供養佛有欲心者即須捨去增一云阿闍世王信心後無令事佛之家貲輸迎送五百問事云若施軍器不須受母論云若為在家人作師教化作福有五事一不應檀越舍止住二不繫念貪利三為別別說法布施持戒八齋等四不與共娛樂五繫心貪利常欲相見又五事為檀越尊重恭敬一非親舊處不往反二不求形勢料理檀越家業三不共竊語令家中生疑四不教良時吉日祠祀鬼神五不過度所求此律喜往白衣家有五過失一數見男子二既相見便附近三轉親友四便生欲意五為欲意故或至死苦若次死苦地持云若見眾生當即慰問舒顏先語平視和色正念在前此律若白衣嚏者呪願長壽僧祇云聽畜甎瓦擬揩脚母論云寒處聽著俗人鞾五分云作鞾䩺太深聽齊踝上母論云何以脫革屣遶佛行者以生俗人訶言起嫌慢心故此律令僧畜斗解升合及秤若住房內臰者以香泥乃至以四角懸香僧祇云浴時不病人揩者越母論云洗浴不為令嚴身淨潔故但令除身中風冷得安隱行道當為厭患身法調伏心法應生慈心為得少欲知足故此律若營事人作房成就莊嚴香熏所須具足者與房住九十日一移更不得受餘房若人能治房者白二與之五分云若月直監食人欲知生熟酸鹹者得貯掌中䑛甞之齋法經云不許甞謂貪心甞也大五濁經云佛涅槃後當有五亂一者當來比丘從白衣學法世之一亂二者白衣坐上比丘處下世之二亂三者比丘說法不行承受白衣說法以為無上世之三亂四者魔家比丘自生現在於世間以為其道諦自不明詐為信世之四亂五者當來比丘畜養妻子奴僕治生販賣諍訟不承佛教世之五亂不得塔院內染曬衣著華屣涕唾見論云頭陁者抖擻智論云以無生法忍為頭陀菩薩住於煩惱觀無上法忍是上頭陀或有經云頭者少欲陀者知足西云阿蘭若東云空閑處雜心論云知足於現在處起難少欲於未來轉生易涅槃經云於未得之財不生貪名少欲於已得之財不生貪名知足知足是現在少欲是未來又少欲猶有欲知足更無欲。
【譯文】第八門雜項事物（雜事），《僧祇律》說燃火有七種弊害無利：一是損害眼睛，二是損害氣色，三是身體衰弱，四是衣服薰黑受污，五是弄壞臥具，六是滋生犯戒因緣，七是增加世俗雜話；《五百問事》說延續佛前光明，白天也不得熄滅，佛陀無明暗之別，因原本就沒有發願限時之故，隨意滅燈有罪；大唐波頗三藏法師說，佛前油燈若用器物從旁取火而不減損其光亮，是可以的；《僧祇律》說不得突然持燈進入堂內高呼說「諸大德，燈要進來了」，乃至滅燈時也是如此，應當用手遮擋輕語告知；不准用口吹滅，應當用手扇風或用衣角扇滅，應將燒焦之燭芯折斷；《成實論》說出家之人應當捨棄五種慳吝：一是財物慳，二是佛法慳，三是俗家眷屬慳，四是住處慳，五是稱讚讚歎慳；因為貪著眷屬、留戀愛著住處的緣故，死後墮入迦陵伽等餓鬼道中投生；《阿含經》說「四恩」是指父母、師僧、國王、檀越施主；「四輩」是指天、龍、人、鬼；本律說非平時行走之處，如果有小便及洗手足之時，聽許穿木屐，又不得赤身裸體上廁所；《三千威儀經》說若未清洗大小便處，不得坐在僧團坐具上；上座正在禮拜三寶之時，若向其禮拜則無福德；大小便時應脫下袈裟及僧祇支，大小便後若不清洗便溺之處，不得臥在僧團臥具上，若隨意坐臥則犯突吉羅罪；本律說不嚼楊枝刷牙有五種過患：一是一口臭氣，二是辨別不出食物美味，三是熱氣陰聚不化，四是辨別不出飲食好壞，五是眼睛昏暗不明；《五分律》說咀嚼完楊枝後應當洗淨丟棄，以免蟲類啃食致死；又不能忍辱之人有五種過失：一是性情兇暴無法忍耐，二是日後生起悔恨，三是許多人不喜愛，四是惡名四處流傳，五是死後墮入惡道；本律說經行有五種益處：一是能耐長途遠行，二是能深入思惟，三是少患疾病，四是容易消化飲食，五是能得定力長久維持；《毘尼母論》說前往寺院乞討糧食之人，若是嬰兒、囚犯、孕婦之流，施捨食物給他們並無過失；《僧祇律》說奏樂供養佛陀時，若心生染污愛欲之念，就必須立即停止離去；《增一阿含經》說阿闍世王生起信心之後，下令不得讓事奉佛法之家庭承擔徭役運輸、迎送差役；《五百問事》說若有人布施兵器軍用品，不得接受；《毘尼母論》說若為在家人做導師教化修福，有五種原則：一是不應在施主家住宿停留，二是不存心貪求利益，三是為其分別宣說布施、持戒、八關齋戒等法，四是不與施主共同娛樂，五是不心生貪著、常常想與之相見；又有五件事能令施主尊重恭敬比丘：一是若非舊識親友處便不隨意往返，二是不可依仗權勢干預掌理施主家業，三是不私下竊竊私語引發其家人懷疑，四是不教導推算良辰吉日祭祀鬼神，五是不索求過度；本律說喜歡前往俗人家中有五種過失：一是屢次見到男子，二是既然相見便容易親近，三是漸漸轉為親暱朋友，四是隨即生起情欲，五是因為欲念之故或至喪身劇苦，或次於死苦；《菩薩地持經》說若見到一切眾生，應當立即親切慰問，面容舒展先開口致意，平視和顏悅色，正念現前；本律說若俗人打噴嚏，應祝願其長壽；《僧祇律》說聽許蓄存磚瓦用來擦腳；《毘尼母論》說寒冷地區聽許穿著俗人的長靴；《五分律》說製作靴統若太深，聽許截齊腳踝之上；《毘尼母論》說為什麼要脫掉皮鞋繞佛經行？因為那樣會招致俗人責斥而生起輕慢嫌惡之心；本律命令僧團蓄備斗、升、合等量具及秤斤器具；若住僧房內有臭氣，應當用香泥塗壁，乃至在四角懸掛香囊；《僧祇律》說沐浴時無病者若讓他人擦拭身體，犯越毘尼罪；《毘尼母論》說洗浴不是為了修飾身體潔淨，只是為了去除體內的風冷病氣、獲得安穩以修行道業，應當為了厭患身體之法、調伏內心之法，應當發起慈悲心，為了少欲知足而洗浴；本律說若掌管營造房舍之僧人把房舍建造完成，莊嚴香薰、所需物品全皆具備，僧團應分給其房屋居住九十天，此後依序輪移，不得再霸佔其他房屋，若有人善於修繕房屋，作白二羯磨將房屋分給他住；《五分律》說每月值日監管廚食之人，若想知道菜餚生熟、酸鹹，可以盛少許在手掌中舔嘗；《齋法經》說不許嘗食，是指存著貪心而嘗；《大五濁經》說佛陀涅槃之後將有五種混亂：一是未來的比丘反而向白衣學法，這是世間第一種混亂；二是白衣坐在高位，比丘處於下位，這是世間第二種混亂；三是比丘說法無人承受奉行，反而將白衣說法奉為至高無上，這是世間第三種混亂；四是魔家比丘出現在世間，自以為通達道諦而實不明瞭，偽裝博取信仰，這是世間第四種混亂；五是未來的比丘蓄養妻子奴僕、經營販賣、諍訟不休、不承順佛陀教戒，這是世間第五種混亂；不得在佛塔院內染色、曬衣服、穿著彩花鞋履、吐痰便溺；《善見論》說「頭陀」是抖擻煩惱之意；《大智度論》說以「無生法忍」為頭陀行，菩薩住於煩惱之中而觀無上法忍，是上等頭陀行；或有經典說：「頭」是少欲，「陀」是知足；梵語稱為「阿蘭若」，華語翻譯為「空閑處」；《阿毘曇雜心論》說知足在當前現境中較難生起，少欲在未來未得之境中較易生起；《涅槃經》說對於未得之財物不起貪念名為少欲，對於已得之財物不貪求更多名為知足；知足是就現在而言，少欲是就未來而言；又少欲尚有一絲欲求，知足則全然無欲。

【717-0005】04_比丘尼鈔/06b_卷下之下#53
【原文】葢夫佛教興行則僧尼之異途不可不知故我大師示僧撰事鈔等三大部示尼撰此書三卷也於是律燈稍熾後世揭其焰者巍巍於宇內所以祖訓之存也雖然不覩有此書而尼眾之信油欲漏戒光隨減余自蚤游眼律部纔覩此書之在歡喜頂戴攤是机上卒多蠧損首尾不全頃日禮誦之間考大部之文茲補茲正且傍加和訓為便新學也讀者乞子細覃研僧尼別行顯然易通今鋟梓于書林某氏以廣其傳惟願開卷舉目直入薩婆若海續佛慧命無窮斯余志願滿矣或謂此四分律比丘尼鈔者唐道世律師述也不然彼知其題目之同不知卷數之異也。
【譯文】佛法教化的推行，僧眾與尼眾行事的途徑不同，不可不清楚明辨；因此我們開宗大師針對比丘僧撰述了《行事鈔》等三大部，針對比丘尼便撰寫了本部書三卷；從此戒律之燈更加熾熱明亮，後世弘揚發揚其光芒者巍巍聳立於天下，這全賴祖師遺訓的保存；然而，由於未能親見有這部書，尼眾信心的油膏漸將耗盡，戒律之光隨之衰減；我早年閱覽律宗典籍，甫見此書存世，歡喜無比頂戴受持，攤展在几案上時，見其大多蠹蝕破損、首尾殘缺不全；近日在禮佛誦經的間歇，考證參酌大部律文，在此處補齊、彼處匡正，並且隨文附加上日語和訓，以方便後學閱讀；希望讀者仔細深入研讀，僧尼兩眾行事的不同之處，便清晰明白容易通達；如今交由書坊某氏刻版印刷，以擴大其流傳；唯願開卷閱覽之際，便能直入諸佛一切種智之海，續佛慧命永無止盡，如此我的志願便算圓滿實現了；有人說這部《四分律比丘尼鈔》是唐代道世律師所撰述的，其實不然，那是因為他只知道兩書題目相同，卻不知道卷數實有差異。
