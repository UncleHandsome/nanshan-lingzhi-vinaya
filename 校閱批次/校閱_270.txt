# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【270-0001】01_行事鈔/10c_卷下之二#29
【原文】三明立觀有教者。《智論》云：若不觀食法，嗜美心堅著，墮不淨蟲中，洋銅灌口，噉燒鐵丸。《十誦》云：每食時，應生厭心，為存身命故。《摩得伽》云：若得食時，當觀從倉中，出地中，以糞屎和合，種子得生，還養糞身云云。《毘尼母》云：若利根比丘，得食時，口口作念；得衣時，著著作念；若入房時，入入作念。若鈍根者，初得衣、食、房舍，總作一念。《佛藏》云：從聚落中乞食得已，從聚而出，住至水邊可修道處；置食一面，結加趺坐，當觀其食種種可惡，及觀自身極是惡器。廣如彼說。
【譯文】三明立觀有教者。《大智度論》說：如果在進食時不依教法作觀想，貪嗜美味之心堅固染著，命終將墮入不淨糞坑化為蛆蟲，在地獄中被熱沸融化的銅汁灌入口中，吞食燒紅的鐵丸。《十誦律》說：每次進食的時候，都應當生起厭離之心，純粹是為了保全維繫色身性命以修行之故。《薩婆多部摩得伽》說：當獲得飲食之時，應當觀察此穀物是出自糧倉、生於泥地之中，是以糞便污穢混合施肥，種子才得以萌芽生長，如今取之又來滋養自己這具由糞穢所成的肉身，如此等等。《毘尼母經》說：若是利根聰慧的比丘，在獲得食物進食時，每一口都要提起正念作觀；在得到僧衣穿著時，每一次穿衣都要作念觀想；若進入僧房時，每一次步入都要作念觀想。若是根機較鈍的比丘，在最初得到衣服、食物、房舍的時候，通總提起一次觀念即可。《佛藏經》說：從村落聚落中乞食完畢之後，走出聚落，前往水邊合適修習道業之處；將食物放在一旁，結跏趺坐，應當細緻觀察面前的食物有種種污穢可惡之相，並且觀察自身的色身本質上就是個極度腥臭骯髒的器具。其詳細情形正如該經所宣說。

【270-0002】資持記/14c_下二#42
【原文】作下，總結上段示名。不可樂者，即遠離行，是解脫因。若下，歎人。如實法者，了達貪著是虛妄故；遠離虛妄，見淨心故。又解：貪心無我，性本空故；復知如幻，相亦空故；復知無境，唯一識故。由此觀察，出離聖行，是真實法。《四分》中，初舉現苦比校。
【譯文】「作」以下，總結上面一段，顯示名稱。「不可樂」就是指遠離行，這是解脫之因。「若」以下，讚歎修行的人。「如實法」，是因為通達貪著是虛妄的；遠離虛妄，就能見到清淨心。另一種解釋：貪心沒有我，因為其性本來空；又知道它如幻，因為相也是空；又知道沒有外境，唯有一識。由此觀察，出離的聖行，就是真實之法。《四分律》中，首先舉出眼前的苦來比對。

【270-0005】02_戒疏/14b_卷三下之二#79
【原文】【疏】故《多論》云：「敷具者，衣名也。」外國以綿作衣，凡有二種，細擗如氈，作縷織成，故犯罪也。《五分》、《十誦》、《多論》、《涅槃》，並云「憍奢耶」也。《論》云：「此是綿名，養蠶所得，如秦地法。」
【譯文】【疏文】因此《薩婆多論》說：「所謂敷具，就是衣服的名稱。」外國用蠶綿製作衣服，大體有兩種形式：一是將綿撕成細絮如同毛氈，二是紡成絲線編織成匹，所以都構成犯罪。《五分律》、《十誦律》、《薩婆多論》、《涅槃經》，都稱之為『憍奢耶』。《論》中解釋說：『這是蠶綿的名稱，是飼養蠶蟲繅絲所得，就如同秦地（中原）的作法一樣。』

【270-0006】02_戒疏/14b_卷三下之二#80
【原文】【記】引示中。初引《多論》示名體。「細擗如氈」，似今衣絮；「作縷織成」，如今細絹。下引四文，但明體耳。「憍奢耶」此翻蠶口初絲。《多論》云「綿」，翻名異耳。「如秦地」者，指此方也。
【譯文】【記文】在引用教證說明中。首先引用《多論》來指出它的名稱與材質本質。「弄碎成細絨如同毛氈」，就像今天衣服裡填塞的絲絮；「紡成細線編織成匹」，就像今天的細絹。下面所引用的四部典籍，只是用來指明材質的本質罷了。「憍奢耶」在此地翻譯為蠶嘴剛吐出來的初絲。《多論》翻譯成「綿」，只是譯名用字不同而已。「就像秦地的作法」，是指中原當地的飼養繅絲方法。

【270-0016】02_戒疏/14b_卷三下之二#90
【原文】【疏】二、「雜野蠶綿」，此正戒家境也。雜作尚犯，何況純者？野蠶尚犯，況復家蠶？以踈制親也。所言「雜」者，如注具解。《僧祇》云：「經緯間穿，羊毛亦犯。」《見》云：「雜憍奢耶一毛亦犯。憍奢耶者，絲中極微者。」若準此方，名為「忽」也。
【譯文】【疏文】第二、「雜野蠶綿」，這是本戒所直接規範的對象境緣。拿來混雜製作尚且犯戒，何況是純粹使用呢？野蠶綿尚且犯戒，何況是家蠶呢？這是用規範關係疏遠的來涵蓋約束關係密切的。所謂的「雜」，如同注釋中詳細的解釋。《摩訶僧祇律》說：「如果在經線緯線之間穿插織入，就算是羊毛也犯戒。」《善見律》說：「只要摻雜了一根憍奢耶的微絲也犯戒。所謂憍奢耶，是蠶絲中最極微細的初絲。」如果依照此地的稱呼，就稱為「忽」。

【270-0017】02_戒疏/14b_卷三下之二#91
【原文】【記】戒本，第二句。初通示。「雜」、「野」為「疎」，「純」、「家」是「親」，疎者尚犯，何況親耶？「野蠶」，天然生者，依樹作蠒，有取為綿。「所」下，牒釋。指「如注」者，注中「毳」、「劫貝」等，與綿相雜也。《僧祇》「經緯間穿」者，彼云：「若經是憍奢耶，緯是羊毛，若經是羊毛，緯是憍奢耶，自作、使人作成，皆犯捨墮。」次《善見》中，「一毛」者，謂如一毛許也。下示梵名。「忽」即蠶口初出，名為忽，十忽為絲是也。
【譯文】【記文】戒本中的第二個文句。首先通盤說明。「摻雜」、「野蠶」關係較「疏」，「純粹」、「家蠶」關係較「親」，疏遠的尚且構成犯戒，更何況是親近的呢？所謂「野蠶」，是天生自然生長的蠶，依附在樹木上結繭，有人採集其絲作成綿。「所謂」以下，解釋經文。指涉「如同注釋」的，是指注釋中所提到的「毳毛」、「迦貝棉」等，拿來與蠶綿相互摻雜的情況。《僧祇律》所說的「經線緯線之間穿插織入」，該律文說：「如果經線是憍奢耶絲，緯線是羊毛；或者經線是羊毛，緯線是憍奢耶絲，無論是自己做、還是指使他人做成，都犯捨墮罪。」其次在《善見律》中，所謂「一毛」，是指如同只有一根毫毛那樣微小。下面標明梵文名稱。「忽」就是指蠶嘴剛吐出的第一縷微絲，稱之為忽，十忽為絲是也。
