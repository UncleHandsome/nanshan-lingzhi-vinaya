# 校閱材料　第130檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【130-0001】02_戒疏/02c_卷一上之二#45
【原文】【疏】奉教兩眾，依常集聽；以行觀說，「如人照鏡」。「鏡」即教也。止持行成，能喪作犯之醜，令戒威嚴，名為「好」也；作犯之惡，能摧止持之善，名為「醜」也。斯並兩託教鏡而「生」；「欣戚」、「好醜」，因說而現也。
【譯文】【疏文】遵奉教法的持戒與犯戒兩類大眾，依照常規聚集聽戒；以自己的行為對照所宣說的戒法，如同「好比一個人對著鏡子照察」。「鏡子」指的就是佛陀的教法。止持的戒行成就，能夠消除作犯的醜陋惡名，讓戒律儀表顯得威嚴，這稱作「好」；作犯的惡業，能夠摧折止持的善根功德，這稱作「醜」。這些好與醜全都依託著教法這面明鏡而「顯現生起」；內心的「欣慰或憂慼」、「美好或醜陋」，都是因為聽聞宣說戒相而顯露出來的。

【130-0002】02_戒疏/02c_卷一上之二#46
【原文】【記】隨釋中，初科。「兩眾」者，持及犯也。「依常」者，黑白兩半也。
【譯文】【記文】在隨後解釋的段落中，這是第一科。「兩眾」指的是持戒之人與犯戒之人。「依照常規」指的是每個月的黑月與白月兩個半月誦戒之期。

【130-0006】02_戒疏/02c_卷一上之二#50
【原文】【疏】如譬所明，作持戒者，妙在方便，約止非緣，對境相陵，同「兩陣」也。強弱相傾，如「共戰」也。正智達過，明白無違，如「勇」者「進」也。癡墮居懷，無心遮約，如「怯」者「退」也。
【譯文】【疏文】正如比喻中所闡明的，修習「作持」戒法的人，其精妙之處在於善巧方便，透過自我約束來止息非理之緣，在面對外境誘惑時彼此相抗衡，這如同「兩軍對陣」。力量的強弱相互對決傾軋，如同「雙方交戰」。以正知正見明達自己的過咎，心思明白清朗而絕不違犯，如同「勇敢之人挺身前進」；愚癡放逸常駐心懷，毫無遮止約束之心，如同「膽怯之人臨陣退縮」。

【130-0007】02_戒疏/02c_卷一上之二#51
【原文】【記】次科，喻中。「約止」即能持心，「非緣」是所防過。能持、所防，則為「兩陣」。「正智」等者，謂心強過弱，持心勝也。「癡墮」等者，過強心弱，非境勝也。
【譯文】【記文】在第二科說明譬喻的段落中。「約束止息」指的是能持戒的心念，「非理之緣」是指所要防範的過失。能持戒的心與所防範的境，便構成了「兩軍對陣」。「正知正見」等語，是指持戒的心力強大而罪過微弱，持戒之心佔了上風。「愚癡放逸」等語，是指惡境力量強大而持戒心力羸弱，被非理的外境所壓制。

【130-0008】02_戒疏/02c_卷一上之二#52
【原文】【疏】下法合中，「說戒亦如是」合初句。何以知耶？由說、聽交對，愚智、勤怠彼此相違，如陣合戰也。下句中，覩己行淨，由持故成名「淨」，是則戒淨心「安」趣道，合上「勇進」也。怠惰不學，心昏境慢，止犯「穢」心，將鄰苦趣，故常「畏」，合上「怯退」也。
【譯文】【疏文】在下面「落實法理」的段落中，「宣說戒律也是這個道理」這句話對應了前文的第一句。怎麼知道是這樣呢？因為說戒者與聽戒者相互問答交對，愚昧與智慧、精進與懈怠彼此衝突抗衡，如同兩軍合陣交戰一般。在下一句中，看見自己的戒行清淨，由於堅持持守而成就的德行稱作「淨」，如此一來戒行清淨、內心「安穩」而能趣向聖道，這對應了前文的「勇往邁進」。若懈怠懶惰而不肯學習戒律，心思昏昧而對外境漫不經心，因止犯而導致內心「汙穢」，眼看即將鄰近三惡道的痛苦果報，因此常常心懷「畏懼」，這對應了前文的「膽怯退縮」。

【130-0009】02_戒疏/02c_卷一上之二#53
【原文】【記】法合中，初句。以說戒師提示過境，同集聽眾，隨事觀緣，故如合戰。「愚智」約性，「勤怠」據行，即淨穢二機，淨勇穢怯，故曰「相違」。下句，對喻可見。「心安」是成因，「趣道」即慕果。「止犯」即不學無知罪。
【譯文】【記文】在落實法理的段落中，這是第一句。因為說戒師提示各種可能犯戒的情境，同聚一處的聽戒大眾，隨著每一項戒條審視自己的行持因緣，所以如同合陣交戰。「愚昧與智慧」著眼於天性資質，「精進與懈怠」著眼於行持造作，也就是具備清淨與垢穢這兩種根機的人，清淨者勇敢、垢穢者膽怯，所以說「彼此相違」。下一句經文，對照比喻即可明白。「內心安穩」是成就修行的正因，「趣向聖道」就是欣慕道果。「止犯」指的就是不肯修學戒律所招致的無知罪愆。

【130-0010】02_戒疏/02c_卷一上之二#54
【原文】【疏】何以得知？前喻作犯，文彰全毀，故知已起重罪也。後彰淨穢，故知將興輕罪。既不違教，是非莫知，隨作恐犯，故云「穢」、「畏」也。
【譯文】【疏文】怎麼知道是這樣呢？因為前一個比喻提到「作犯」，經文明確顯示出圓滿與毀壞兩種極端，由此可知是已經造作了嚴重的重罪。後一個比喻則凸顯出清淨與垢穢，由此可知是即將生起輕微的小罪。由於不懂得教法條規，連是對是錯都茫然不知，隨便有所造作都唯恐犯戒，所以經文說感到「汙穢」與「畏懼」。
