# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【358-0001】資持記/15a_下三#50
【原文】十何中，一二可解，三謂無所讓故，四即不令避故，五約希望，六約他事，八約已務，九謂不惱他故，彼具云：不起諍訟因緣。十二初科，《多論》，前明坐法。然下，示制意。次科，初標行相。即身業也。如下，引示心行。明不徒坐也。經中四法，前二治過，即自利；
【譯文】十種利益（原文作「十何」，當為「十利」）中，第一、二條容易理解，第三條是指無須退讓給別人，第四條就是不逼迫別人避讓，第五條就個人的希求期望而言，第六條就他人事務而言，第八條就自身事務而言，第九條是指不惱亂他人，那部論完整說：不會引發諍端爭論的因緣。在第十二種行持（常坐不臥）的第一科中，《薩婆多論》前面先說明坐法。「然」字以下，顯示制戒的用意。下一個科判，首先標示行持的相貌，這屬於身業。「如下」，引用經文指示內心的行持，說明並不是徒勞地空坐。經中的四種法門，前兩種對治過失，屬於自利；

【358-0002】01_行事鈔/11a_卷下之三#20
【原文】三諸部異行。《毘尼母》中云：若瞋心不止，我則不食；待瞋滅方食。《智論》：中後不飲漿。由此緣故，心生樂著，不一其心修習善法。《寶雲經》云：四分之一食。凡乞得食，分為四分：一分與同梵行者，第二分與窮下乞匃之者，第三分與諸鬼神，第四分自供身食。但念修道，於食中不生貪染心。若乞食時，繫念威儀，終不輕躁。諦視目前，不過一尋。次第乞之，除惡狗、惡牛，先破禁戒；隨有人畜能擾惱者，皆悉不往；可譏嫌處，亦不往彼。餘如彼〈十二頭陀〉中說。《十住婆沙》有著毳衣、食後不受非時飲食；各有十利，如彼說。《解脫道》中有十三頭陀：衣二、食五、處五，十三是常坐勇猛之分。《十誦》：多雨國土，四月在露地，八月在覆處；少雨國，反前。上列十二，依《四分》而言。統明經論所述，並不及《解脫道論》次第詳悉。正行既成，定慧斯立。彼論廣有次第法，略不述之。
【譯文】第三、諸部律典記載的不同行持。《毘尼母論》中說：如果瞋恨心不能止息，我就不進食；一定要等到瞋心泯滅之後才吃飯。《大智度論》說：過午之後不飲用米湯果漿等飲品。因為如果飲漿，內心會產生貪戀執著，就無法專一其心修習善法。《寶雲經》說：「四分之一食」。凡是乞食得來的食物，均分為四份：一份布施給同修的清淨梵行人，第二份施捨給貧窮下賤的行乞者，第三份施予一切鬼神，第四份才留給自己滋養色身。心中唯念精進修道，在飲食之中絕不生起貪愛染著。乞食的時候，端正繫念於身行威儀，始終不輕浮急躁。凝視前方地面，目光不超過一尋（八尺）。依次第挨門挨戶乞食，但要避開有惡狗、惡牛的地方，以及原本就破壞禁戒之家；凡是有能擾亂惱害身心的人或牲畜之處，全都不去；容易引起世俗譏嫌詬病的地方，也絕不前往。其餘細節正如該經〈十二頭陀品〉中所述。《十住毘婆沙論》還有穿著毳衣（毛織粗衣）、食後不接受非時飲食等行持；各有十種利益，正如該論所說。《解脫道論》中則列有十三種頭陀行：衣服兩種、飲食五種、處所五種，第十三項「常坐不臥」是屬於勇猛精進之分支。《十誦律》記載：在多雨的國土，四個月露天而坐，八個月在有遮蔽的屋下；少雨的國土，則與此相反。上述所列的十二種頭陀行，是依據《四分律》系統而言的。總括統覽經論中所述，其實都比不上《解脫道論》的編排次第那麼詳盡周密。頭陀正行既然成就，禪定與智慧自然確立。那部論中有極為廣泛的修持階次之法，此處略過不加贅述。

【358-0003】資持記/15a_下三#51
【原文】三是利他；四即投心勝境，睡眠掉散，則離念佛，故不臥也。下指論者，即《解脫論》；彼云：常坐功德，斷生怠處，除為身疾〔開病緣也〕，離染觸樂，少於纏睡；常多寂靜，堪修禪定，善人所行，是業無疑。三中。十利，前三治樂，四即離苦，五不縱情，六七成業，八神爽，九身安，十業輕。
【譯文】第三種是利益他人；第四種就是將心念寄託於殊勝境地；如果睡眠或者掉舉散亂，就會離開憶念諸佛，所以不躺臥。下面指出論書，也就是《解脫道論》；那部論說：長坐不臥的功德，能斷除產生懈怠之處，除非是為了身體生病（開許疾病的因緣），遠離貪著觸覺的安樂，減少纏繞的睡意；恆常保持清淨寂靜，能夠堪受修習禪定，這是善人所行持的法，修習這種善業是毫無疑義的。第三段中。十種利益，前三項對治貪圖享樂，第四項就是脫離苦惱，第五項是不放縱性情，第六、七項是成就道業，第八項是心神爽朗，第九項是身體安穩，第十項是業障減輕。

【358-0004】資持記/15a_下三#52
【原文】四中，《四分》，初引緣。佛下，明設教，初句立制。應下，教修。思惟即修觀。此中不明，故指如後，即〈主客篇〉四儀法中。〔或指〈沙彌篇〉三觀。〕《智論》中，初讚坐法。求下，誡睡眠。大事，即指聖道。伺，候也。即經云：無以睡眠因緣令一生空過，無所得也；
【譯文】第四段中，《四分律》起初引述因緣。「佛」字以下，說明設立教法，第一句立下制度。「應」字以下，教導如何修習。「思惟」就是修習觀照。這裏沒有詳細說明，所以指示參見後文，也就是〈主客篇〉四威儀法之中（或者是指〈沙彌篇〉的三觀）。《大智度論》中，首先讚歎坐禪之法。「求」字以下，告誡提防睡眠。「大事」，就是指成辦聖道。「伺」，是窺伺守候的意思。正如佛經說：不要因為睡眠的因緣，讓一生虛度空過而一無所獲；

【358-0009】02_戒疏/19a_卷四下之一#112
【原文】【疏】答：「彼諫止犯，先是不學之人發言拒諫，道已不學即是止犯，違諫義成。此諫作犯，雖發言拒諫未是作犯，違諫未成，要待作事，違諫義足。故不相並也。」

【358-0010】02_戒疏/19a_卷四下之一#113
【原文】【記】轉難中。由下勸學同是別人，諫竟即犯，則違上義。答中，諫止則因止故勸，故止在先。諫作則欲作便可，故作在後。是以諫止即結，諫作待成。
【譯文】【記文】在轉折問難之中。由於下文勸學戒同樣是面對單獨一人，勸諫完畢就立即結罪，這就違背了上面的說法。在答覆中：若是勸諫『止犯（不肯學戒）』，是因為對方已經有了消極不學的行為而後才加勸勉，所以『止犯』已發生在先；若是勸諫『作犯（動手作惡）』，則是見對方想要作惡便可以勸阻，所以惡事的『作』還在後頭。因此，勸諫止犯當下便結罪，勸諫作犯則須等待事情做成才結罪。

【358-0015】02_戒疏/19a_卷四下之一#118
【原文】【疏】出家之士，理宜迭相將護，許無觸惱。今以六塵等相，恐怖前人，令生惶悸，廢修正業，惱深過重，故制。
【譯文】【疏文】出家修道之士，在理法上應當相互護持體恤，承諾絕不彼此觸怒驚擾。如今竟然藉由色、聲等六塵的幻異假相，恐嚇驚嚇同修道友，使人心生驚恐惶怖，荒廢修持正業，帶給人極深惱亂而過患深重，所以必須制定此戒。

【358-0016】02_戒疏/19a_卷四下之一#119
【原文】【記】五十五，制意中。初敘所宜。「今」下，顯過狀。「六塵」，如下釋。「惶」，懼也。「悸」，其季反，心驚動貌。
【譯文】【記文】第五十五條，在制戒用意中。起初敘述出家人應有的相處原則。從「如今竟然」以下，彰顯過咎的實態。「六塵」，如後文所作解釋。「惶」，就是恐懼。「悸」，音同季，是內心受驚動盪不安的神態。

【358-0017】02_戒疏/19a_卷四下之一#120
【原文】【註】佛在波羅犁毗國。那迦波羅侍佛左右。諸佛常法，若經行時，供養人在經行道頭立。彼初、中、後夜白佛令還，便反披拘執怖佛。明旦集僧，因制此戒。
【譯文】【註文】佛陀住在波羅犁毗國時。那迦波羅比丘侍奉在佛陀身旁。諸佛世尊行持的常規法則，經行修法時，隨侍侍奉的人應肅立在經行道路的端頭。該比丘在初夜、中夜、後夜時分，屢次稟白佛陀請佛回室就寢，佛陀依然經行，他便反披著獸皮裝神弄鬼恐嚇佛陀。隔天清晨佛陀召集僧眾，因而制定了此戒。

【358-0018】02_戒疏/19a_卷四下之一#121
【原文】【疏】戒緣，「怖佛」者，欲明輕怖，極聖尚遭，況餘下例，義須滅迹。又顯佛無怖心，怖在能怖，約同人相，無論怖與不怖，皆結重提。
【譯文】【疏文】在制戒因緣中，提到「恐嚇佛陀」，是為了闡明即使是輕微的恐嚇行徑，連至高無上的大聖佛陀都會被人施加，何況其餘資質較差的凡流，在義理上必須徹底禁絕這種惡劣行跡。另外也顯示佛陀具備圓滿清淨，心中絕無絲毫恐懼之念，恐嚇的罪過全在能行恐嚇之人的惡念惡行，只要對象符合人類同修的形貌標準，無論對方受驚或未受驚，恐嚇者一律結犯重波逸提。

【358-0019】02_戒疏/19a_卷四下之一#122
【原文】【記】戒緣中二。初約舉況釋。「例」，猶類也。「滅迹」，謂須制斷也。「又」下，次約判犯釋。謂此戒中舉佛為緣，欲明此犯不論所怖，以佛無怖故。
【譯文】【記文】制戒因緣中包含兩層意思。起初依據舉出聖者以比況凡夫來作解釋。「例」，就如同「同類」之意。「徹底禁絕」，是指必須立法嚴禁斷絕。從「另外也顯示」以下，次要是依據定罪標準來作解釋。也就是說在此條戒中以佛陀作為制戒緣起，是為了闡明此罪的成立並不取決於受害者到底害不害怕，因為佛陀本來就沒有恐懼之心。

【358-0020】02_戒疏/19a_卷四下之一#123
【原文】【疏】「若爾，亦可殺佛為緣，死與不死，俱得重罪？」
【譯文】【疏文】「如果這樣的話，難道也可以用謀殺佛陀作為殺戒的緣起，無論佛陀命終與否，行凶者全都犯重罪嗎？」

【358-0021】02_戒疏/19a_卷四下之一#124
【原文】【疏】答：「不爾。殺凡人戒，以凡為緣。因明破僧，遂明殺佛，不即以此而為戒緣也。」
【譯文】【疏文】回答：「不能這樣類比。傷害凡夫的殺戒，是以能將凡人致死為成立條件。律中是因為闡明破和合僧的極惡重罪，順帶提及出佛身血的殺佛之過，並未直接以此種特例作為一切殺戮罪行的普遍制戒標準。」

【358-0022】02_戒疏/19a_卷四下之一#125
【原文】【記】釋難中。以怖例殺，不應別故。釋中，緣起不同，故不可例。注中，「那迦波」即比丘名。「供養人」亦即侍者。「白佛令還」，謂請佛還臥室也。「拘執」即獸皮。
【譯文】【記文】在化解詰難中。質疑者試圖拿恐嚇戒的例子來比附殺人戒，認為兩者不該有差別待遇。解釋中說明，兩者的緣起機制截然不同，所以絕不能硬行類比。隨律註解中，「那迦波羅」是當事比丘的名字。「隨侍供養人」也就是侍者。「請佛回室」，是指敦請佛陀回臥室安歇。「拘執」就是野獸的皮毛。

【358-0024】02_戒疏/19a_卷四下之一#127
【原文】【註】若以色、聲、香、味、觸、法恐怖人，彼怖以不怖，皆一一墮；彼不知，吉羅。若說色、聲等六塵恐怖，說而了了者，波逸提；不了了，突吉羅。不犯者：或闇無火，或大小便處，謂是惡獸便怖，乃至行聲、咳聲、觸聲而恐怖；若以色等示人，不作恐意；若實有是相，或夢見當死、罷道、失物，和尚、父母重病若死，語彼令知；若戲，若誤——一切無犯。
【譯文】【註文】若用色、聲、香、味、觸、法這六塵假相恐嚇他人，對方無論害怕還是不害怕，行恐嚇者每一次舉動全結犯墮罪；若對方根本未察覺，行恐嚇者犯突吉羅。若是藉由言語宣說色、聲等六塵境界來恐嚇他人，言詞說得清楚明了的，犯波逸提；說得含混不明顯的，犯突吉羅。不犯的情況：或者是身處黑暗中沒有燈火，或是在大小便溺處，自行疑心以為有惡獸出沒因而受驚，乃至聽聞走路聲、咳嗽聲、器具碰觸聲而自己心生恐怖；如果是以色等外相展示給人看，但本無恐嚇戲弄的意圖；若是實有其事，或者夢見對方將要身亡、退道還俗、遺失財物，或是其和尚親教師、父母身患重病乃至亡故，據實相告令對方知悉；如果是純屬玩笑、或是無心誤會——一切都不算犯戒。
