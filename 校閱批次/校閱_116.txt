# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【116-0001】02_戒疏/05b_卷二上之一#41
【原文】【疏】答：「盜相為言，離處有損，必不損主，故有錯、誤。妄語不爾，言了誑成，故無錯誤。又云：『物還本主，心無惱故，本無盜心，錯、誤不犯。妄有心誑，前境相應，言聲一吐，則無退悔，故不同盜。』」
【譯文】【疏文】答：「就偷盜的相狀而言，必須將財物移離原處並造成了主人的損失；如果必定不會使主人蒙受損害，所以才容許有錯與誤的免責。妄語則不是這樣，謊言一說完，欺騙的行為就已經達成了，所以沒有錯與誤的開許。又有人說：『偷盜若是把財物物歸原主，原主心裡就不會產生苦惱，而且下手時原本就沒有偷取這件物品的心，所以錯與誤不犯根本罪；妄語則是在心中存有欺誑之意，且眼前的客觀境界與之相合，話語之聲一旦吐露出口，欺瞞的事實就無法退還追悔，所以與偷盜戒不同。』」

【116-0002】02_戒疏/05b_卷二上之一#42
【原文】【記】問中。前明對人，剋心俱犯，與盜不同。又似即上錯說聖法，比前盜戒，同主俱開。答中。初約前境釋。盜容後還，故不損主；妄令虗解，無非欺誑。「又」下，次約本心釋。盜本無心，於事可解。若據妄語，本亦無心，但望對境，非無心故。
【譯文】【記文】提問的段落中。前面說明針對人類，特定心也同樣犯重罪，這與偷盜戒不同。而且這也類似於上面錯說聖法的例子，比照前面偷盜戒同一物主的情況，偷盜是雙雙開許免犯的。回答的段落中，首先從「對境」的角度來解釋。偷盜容許事後歸還，所以可以不造成主人的損害；妄語則造成了別人的虛假領解，無非欺誑。「又有人說」以下，接著從「本心」的角度來解釋。偷盜原本對此物就沒有盜心，在事理上可以化解；若是就妄語而言，原本雖然沒有欺騙這個具體細節的心，但就面對境界企圖騙人來說，並非毫無欺妄之心。

【116-0004】02_戒疏/05b_卷二上之一#44
【原文】【疏】原聖制戒，本為止惡，業之所興，要唯三毒。故《十住》云「三三九種，三煩惱生」是也。又《成論》云「前行後三，後行前七」。故制四戒，為對此三：對於貪故，立前二戒；瞋癡當分，故立三、四。
【譯文】【疏文】探尋佛陀聖人制定戒律的初衷，本來就是為了止息惡行；而惡業之所以會生起，其樞紐完全在於貪、瞋、癡三毒。所以《十住婆沙論》中說「三三共九種惡業，都是由三種煩惱所生起」，就是這個道理。又如《成實論》中說「先運行後面的意地三業，接著才運行前面的身口七業」。因此佛陀制定這四條根本重戒，就是為了對治這三毒煩惱：為了對治貪心，所以確立了前兩條戒（淫戒、盜戒）；瞋心與癡心各自有其對應的分劑，所以確立了第三殺生戒、第四妄語戒。

【116-0005】02_戒疏/05b_卷二上之一#45
【原文】【記】第八，正示中三。初示制意。「惡」通業惑，「止」分近遠。今明教本，須對惑論。「業所興」者，推示業本。「三毒」之言，大小兩乘，並通惑業。業謂意地三業，即瞥爾、重緣以分相；惑謂性中三妄，即見、思、無明以為體。良以無始結情，熏積日深，觸境發情，徧造諸業。業雖無量，不出三毒，以為業本。然佛制戒，現止業非。究其遠圖，為清心惑。是則深窮制意，曲盡教源。四重既然，餘篇皆爾。「故」下，次引文證。《十住婆沙．除業品》文，「三三九種」：身、口、意為一三；自作、教他、見作隨喜，為二三；現報、生報、後報，為三三。「三煩惱」：欲、色、無色三界繫。然則界繫，即毒為體，由毒起業，由業感苦，故云從三「生」也。次引《成論．業道品》。彼問曰：「何故名為業道？」答：「意即是業，於此中行，故名業道。先行後三中，後行前七中。」此明意思先起三毒，後至七業，則顯七業發自三心。「故」下三，分戒配毒，以彰教意。
【譯文】【記文】第八門，正式開示的段落分為三部分。首先指出制戒的本意。「惡」通於造作的業與內在的惑，「止」則分為眼前的防護與長遠的斷除。現在要闡明教法的根本，必須針對煩惱惑障來論述。「惡業之所以會生起」，是推原並指出造業的根源。「三毒」這個名詞，在大小兩乘中都通含於惑與業。業指的是意地的三種業，也就是以微細生起與再三思量來劃分其相狀；惑指的是自性中的三種妄執，也就是以見惑、思惑、無明作為其本體。實在是因為無始劫以來的結縛情染，日積月累地熏習漸深，一接觸到外境便引發妄情，普遍造作出種種罪業。業雖然有不可勝數之多，但其造業的根本都不出於三毒。然而佛陀制定戒律，表面上是為了在當下制止惡業的過非，但窮究其長遠的圖謀，則是為了滌清內心的迷惑妄想。如果這樣去深入窮究制戒的本意，才能徹底通達教法的源頭。四條重戒既然是如此，其餘各篇戒律也全都是這樣。「所以」以下，接著引用經論來作證明。《十住婆沙論·除業品》中的文句，所謂「三三九種」：身、口、意是第一組三；自己作、教唆他人作、看見他人作而心生隨喜，是第二組三；現世受報、來生受報、後生受報，是第三組三。「三種煩惱」是指被欲界、色界、無色界三界所繫縛的煩惱。然而所謂的三界繫縛，就是以三毒為本質體性，因為三毒而造作惡業，因為惡業而感召苦報，所以說恶業是從三毒「生」出來的。接著引用《成實論·業道品》。該論問道：「為什麼稱為業道？」回答說：「心意本身就是業，在這種心意中造作運行，所以稱為業道。心念先運行於後面的意地三業之中，然後才運行落實於前面的身口七業之中。」這說明了心念動向是先發起三毒，其後才演變成身口的七種罪業，這就顯明了七種罪業完全是從貪瞋癡三種心所引發出來的。「因此」以下第三點，將四戒分別配屬三毒，以此顯彰教法興起的意圖。

【116-0008】02_戒疏/05b_卷二上之一#48
【原文】【疏】答：「貪心雖一，境殊內外；通須歷止，故因立二。瞋境亦二，罪則有差。癡慢誑境，局唯在情。故有殊也。」

【116-0009】02_戒疏/05b_卷二上之一#49
【原文】【記】答中。初示前雙對。「內外」，即情非情。然盜亦通人，且就多分為言耳。「瞋」下，明後隻對。初二句明瞋毒。「境亦二」者，內境易解，外即草土，掘壞犯提，罪不同篇，故無雙對。據論掘壞，未必由瞋，但俗計有命，譏責無慈，故望損傷，義同瞋殺故也。次二句明癡毒。非情無誑，唯隻可知。下一句結異。
【譯文】【記文】回答的段落中。首先說明前面雙重對應的情況。「內在與外在」，就是指有情眾生與無情財物。不過偷盜其實也涉及活人，這裡只是就多數情況而言罷了。「瞋恨心」以下，說明後面單一對應的情況。前兩句說明瞋毒。「境界也有兩類」，內在境界（殺人）容易理解；外在境界則是指掘鑿損壞草木泥土，這只犯波逸提罪，罪名不屬於同一個篇章，所以沒有雙雙列為重戒。若依理而論，掘壞土地未必是出於瞋恨，但因為世俗之人認為草木泥土中有生命，會譏嫌責備修行人毫無慈悲心，所以就造成損傷這一點而言，其義理等同於瞋恨殺害。後兩句說明癡毒。對無情之物無法進行欺騙，所以只能單獨對應有情，這是不言而喻的。最後一句總結其產生差異的緣由。

【116-0010】02_戒疏/05b_卷二上之一#50
【原文】【疏】如《律》文云：「婆羅門問阿難：『汝世尊，何故為諸比丘制增戒學？』答：『為調貪欲瞋癡令盡。』」如此文證，故知不疑。
【譯文】【疏文】正如《律》文中所記載的：「有婆羅門問阿難：『你們的世尊，為什麼要為各位比丘制定增上戒學呢？』阿難回答說：『是為了調伏貪欲、瞋恚、愚癡，使它們徹底斷盡。』」有了這樣的律文作為明證，就可以完全確定而無可懷疑了。

【原文】【記】引證中。即孔雀冠婆羅門，請問阿難制戒之意。初引問詞。但云「制戒」，不唯四重。然種類所收，皆歸根本。雖明四戒，即見諸篇。下引答詞，證前有據。
【譯文】【記文】引用經文證明的段落中。這就是指孔雀冠婆羅門向阿難請問制戒意圖的事蹟。首先引述問話。文中只說「制定戒律」，並非僅限於四條根本重戒；然而所有戒律種類的含攝，都歸結於根本重戒。雖然此處只闡明四重戒，其實就已經涵蓋見於全部篇章了。下方引述答話，證實前面的立論完全有憑有據。

【116-0017】02_戒疏/05b_卷二上之一#57
【原文】【記】第三問。尼有八重，前四同僧，後四即摩觸、八事、覆重、隨舉。答中。上指前四，下明後四。「觸」、「八」及「隨」，並是婬類，同對貪毒。「覆」是妄類，即對癡慢。故曰「同前」。
【譯文】【記文】第三個提問。比丘尼有八條重戒，前四條與比丘僧相同，後四條則是指摩觸、八事成重、覆藏重罪、隨順被舉比丘。回答的段落中，上方指示前四條，下方說明後四條。「摩觸」、「八事」以及「隨順」，都屬於淫戒的分支流類，同樣對治貪毒；「覆藏重罪」屬於妄語的分支流類，也就是對治癡慢。所以說「比照前面的原則」。

【116-0021】02_戒疏/05b_卷二上之一#61
【原文】【疏】有人言：「由愛染氣分，無始故習，喜懷犯故，所以先明。如是次第，終於妄語。如諸篇首，漏失、長衣、妄語等類，可以求也。」
【譯文】【疏文】有人說：「由於貪愛染著的氣息勢力，是無始劫以來根深蒂固的積習，最容易在心中萌發而違犯，所以首先列出闡明。依照這樣的次第，最終排到妄語戒。這就像各篇戒條的篇首，僧殘篇以漏失精液為首、捨墮篇以蓄留長衣為首、單墮篇以妄語為首等各種類型一樣，都可以由此尋求其規律。」

【116-0022】02_戒疏/05b_卷二上之一#62
【原文】【記】初門，人解中，初科。初句明現起婬心，「氣分」，謂勢力也。次句明積劫熏習，釋上氣分之盛，發下喜數之由。即下《論》云「心心繫縛」，自可知矣。餘之三戒，次第漸稀，故云「如是」等。上正敘本篇，「如」下，舉餘篇為例。
【譯文】【記文】第一門，他人見解的第一個科判中。第一句說明現前生起的淫欲之心，「氣分」就是指煩惱的勢力。下一句說明累劫以來的熏習，以此解釋上面所說的氣力強盛，以及引發下文違犯頻率極高的原因。這正如後文《大智度論》所說的「心心念念都被繫縛拘束」，自然就可以理解了。其餘的三條戒，違犯的頻率次第漸漸稀少，所以說「依照這樣的次第」等語。上面是正面敘述本篇的次第，「這就像」以下是列舉其餘各篇作為同類範例。

【116-0025】02_戒疏/05b_卷二上之一#65
【原文】【疏】如《僧祇》中「佛成道後，五年冬分，第五半月十二日，中後一人半影，為邪舍犯，故制初戒」，則當此間十月二十七日也。第二戒者，「六年冬分，第二半月十日，食後二人半影制」，則當此間九月十日也。第三戒者，同是「六年冬分，第三半月九日，食前一人半影制」，則當此間九月二十四日也。第四戒者，「同年冬分，第四半月十三日，食後三人半影制」，則當此間十月十三日也。若如上制，從犯次第，文相甚明。
【譯文】【疏文】正如《僧祇律》中所說：「佛陀成道之後，在第五年的冬分，第五個半月的第十二天，午後一個半人影的時刻，因為耶舍違犯，所以制定了第一條重戒」，這相當於此地的十月二十七日。第二條戒，「在第六年的冬分，第二個半月的第十天，食後兩個人半影的時刻制定」，相當於此地的九月十日。第三條戒，同樣是在「第六年的冬分，第三個半月的第九天，食前一個半人影的時刻制定」，相當於此地的九月二十四日。第四條戒，「在同一年的冬分，第四個半月的第十三天，食後三個人半影的時刻制定」，相當於此地的十月十三日。如果按照上述制戒的由來，依照犯戒的前後次序排列，其文辭相狀是非常明白顯著的。
