# 校閱材料　第364檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【364-0001】02_戒疏/02d_卷一上之二#76
【原文】【記】舉例中。初示止持，通一切戒。「房」下，別舉作持，例成上義。「作」是搆造，既成「止善」，口止無言，得成惡說。相翻取例，故云「可類」。「房」即二房，「衣」如「離」、「長」，「財」即「畜寶」，「食」如「足」、「別」等，凡此諸戒，並具雙持。
【譯文】【記文】在舉例說明的文字中。首先指出「止持」通於一切戒法。「房」字以下，特別舉出「作持」的各條戒，以旁例來成就上面的論點。「作」是指如法造作營辦，既然能夠成就「止善」，那麼口中停止不說，自然也能構成「惡說」之罪。兩者互相對翻取作譬例，所以說「可以類推」。「房」就是指二房戒，「衣」如「離衣宿戒」、「長衣戒」，「財」是指「蓄寶戒」，「食」如「過足食戒」、「別眾食戒」等，凡是這諸多戒相，全都是同時具備止持與作持兩重意義的。

【364-0002】02_戒疏/02d_卷一上之二#77
【原文】【律】未受大戒者出？
【譯文】【律文】尚未受具足大戒的人都出去了嗎？

【364-0003】02_戒疏/02d_卷一上之二#78
【原文】【疏】三、明未受具戒者。上既擊磬詳集，五眾同來。僧集說戒，四眾俱出，但明「未具」，亦應兼尼。
【譯文】【疏文】第三個問答，是查明未受具足大戒的人是否離開。前面既然已經鳴鐘擊磬、詳盡齊集大眾，出家五眾自然一同前來。但當僧眾聚集準備說戒時，其餘四眾都必須退出，經文雖然只說「未具戒者」，但依義理也應當涵蓋比丘尼在內。

【364-0004】02_戒疏/02d_卷一上之二#79
【原文】【記】遣未具中，初科，攝前文意。「僧」下，正明簡眾。「但明未具」者，點文之局，止收三眾；「尼」雖已具，義須同遣。
【譯文】【記文】在遣除未受具足戒者的科判中，第一小節承接前面的文意。「僧」字以下，正式說明簡別淘汰不合規定的大眾。「但明未具」這句話，是點出經文用詞的局限，表面上只收攝了沙彌、沙彌尼、式叉摩那三眾；比丘尼雖然已經受了具足戒，但在法理上必須一同遣離現場。

【364-0005】02_戒疏/02d_卷一上之二#80
【原文】【疏】所以遣者？以說戒眾法，彼學未周，體不同流，故須遣去。
【譯文】【疏文】為什麼要將他們遣送離開呢？因為說戒是專屬於比丘僧團的大法，他們的學業尚未周圓具足，其身份本質與大僧也不屬於同一階流，所以必須請他們離去。

【364-0006】02_戒疏/02d_卷一上之二#81
【原文】【記】次科。初徵，「以」下，釋。「學未周」者，即沙彌有願。「不同流」者，即尼眾報別。式叉、沙彌尼，具兼二句。
【譯文】【記文】在第二小節中。先發起徵問，「以」字以下予以解釋。「學未周」是指沙彌雖然發願求受大戒但戒品尚未具足。「不同流」是指比丘尼大眾的業報身分男女有別。至於式叉摩那與沙彌尼，則是兩項理由同時兼具。

【364-0007】02_戒疏/02d_卷一上之二#82
【原文】【疏】行事之家，務須周給。既聽序偈，如法召下。上座約勅，無逸為先。廣如所撰《刪補事鈔》。
【譯文】【疏文】主持僧團行事的主事者，辦事務必要周詳完備。既然讓大眾聽完了序分偈頌，就應當如法地召請他們退席到堂下。上座長老應當告誡飭勉他們，以不可懈怠放逸為第一要務。詳細內容正如我在所撰述的《刪補事鈔》中所說。

【364-0008】02_戒疏/02d_卷一上之二#83
【原文】【記】三中。言「周給」者，事須有序，不可闕故。言「召下」者，準知尼等，得同聽序。「約勅」之詞，指「事鈔」者，彼云：「此眾僧布薩，汝未受具，不預聞之。各隨本業誦習，謹慎莫放逸。」
【譯文】【記文】在第三小節中。所謂「周給」，是說事務必須有條不紊、井然有序，不可有所缺漏。所謂「召下」，可以依此準知沙彌與比丘尼等人，是可以一同在場聽聞前面序分偈頌的。「約勅」的文辭，指引讀者查閱《事鈔》，彼處記載說：「這是大僧僧眾的布薩法會，你們尚未受具足戒，不得在場參與聽受。你們各自隨順自己本分內的課業去誦讀修習，萬要謹慎、切莫放逸。」

【364-0009】02_戒疏/02d_卷一上之二#84
【原文】【註】時，有比丘令餘人遮說戒事。
【譯文】【註文】當時，有比丘指使其他人去阻撓遮止僧眾說戒的法事。

【364-0010】02_戒疏/02d_卷一上之二#85
【原文】【疏】注中引「遮說戒事」者，表淨法穢人不樂聞也。佛世尚爾，況末代乎？止得勤勤自勵，一死知生何道也！
【譯文】【疏文】註解中引用「阻撓說戒法事」的公案，表明了這清淨之法是身心污穢之人所不樂意聽聞的。佛陀在世時尚且會有這種事發生，更何況是末法時代呢？我們唯有精勤不懈地自我勉勵，誰知道一旦死了之後又將轉生到哪一道去呢！

【364-0011】02_戒疏/02d_卷一上之二#86
【原文】【記】釋注，初中。注云「令餘人」者，即三眾及白衣。「遮」謂不令眾僧作「說戒事」。初釋遮意。「佛」下，嗟時。「止」下，誡眾。「一死」之語，請為思之。經云：「從人身中得人身者，如爪上塵；失人身者，如大地土。」且現身微病，欲聽無由，況當死去，前途未委。縱使即還人道，猶經二十餘年，脫於餘趣受生，何啻百千萬劫！既沉戒障，永背真乘。其有卒世不聞，無非重障；其或始終無闕，須慶宿因。宜自深思，更增勇勵。
【譯文】【記文】在解釋註解的第一段中。註解說「令餘人」，這「餘人」指的就是下三眾以及在家的白衣。「遮」是指阻止僧眾如法進行「說戒」的佛事。首先解釋遮止的意圖。「佛」字以下，感嘆末世時運。「止」字以下，告誡警勉與會大眾。所謂「一旦死去」，這句話請諸位務必深思體會。佛經說：「從人身中死後還能再得人身的，就像指甲縫上的泥土那樣稀少；失掉人身而墮入惡道的，卻如大地的泥土那般無窮無盡。」更何況現世中只要稍染輕病，就已經無法前來聽聞戒法，何況面臨大限死去之時，前途將去往何處完全無法預料。縱然能夠立即重返人間投胎，也還要經歷二十多年的蒙昧無知，若是投生到其他惡趣受苦，那又何止是百千萬劫的時間！既然沉溺在戒罪障礙之中，就將永遠背離真實解脫的一乘極果。若是有人一輩子無法得聞戒律正法，無非全都是罪障深重；如果有人一生自始至終都能無所缺漏地聽習，正該慶幸自己宿世所種下的殊勝善因。各位應當深自反省，更加倍增進勇猛精進的行持。

【364-0012】02_戒疏/02d_卷一上之二#87
【原文】【註】佛並令至不見聞處，餘人未受戒者。
【譯文】【註文】佛陀並且命令將他們安置在耳不能聞、眼不能見的處所，其他一切未受具足戒的人也是如此。

【364-0013】02_戒疏/02d_卷一上之二#88
【原文】【疏】注中「令至不見聞處」者，以六眾下類，不令上僭。大僧淨法，非彼見聞。
【譯文】【疏文】註解中說「令至不見聞處」，是因為下位階的六眾弟子，不容許他們僭越上位。大僧清淨的法事，絕非他們所能窺見聽聞的。

【364-0014】02_戒疏/02d_卷一上之二#89
【原文】【記】次安置中。「六眾」，道四、俗二。「僭」謂濫上。《十誦》：「白衣前說戒，除為瓶沙王，令心清淨。」
【譯文】【記文】在接下來說明安置處所的段落中。「六眾」是指受戒四眾（比丘尼、式叉摩那、沙彌、沙彌尼）與在家俗人二眾。「僭」就是以卑微濫冒尊貴。《十誦律》記載：「在白衣面前不得說戒，除非是專門為了頻婆娑羅王，為了令他內心生起清淨信心的特殊情況除外。」

【364-0015】02_戒疏/02d_卷一上之二#90
【原文】【疏】問：「聞非可行，故不合聽；目對僧集，如何不許？」
【譯文】【疏文】有人發問：「既然他們聽了戒法也不被允許去行持，所以不合適聽聞；但如果只是眼睛看著僧眾集會，為什麼連看也不准許呢？」

【364-0016】02_戒疏/02d_卷一上之二#91
【原文】【疏】答：「計理應爾。下眾無知，多生慢習，制令耳目不矚，則重法尊人，生其欽仰也。」
【譯文】【疏文】回答：「按常理推求本該如此。但下位階的眾生智慧不足無明未斷，極容易生起輕慢傲慢的習氣，因此制定條規令他們的耳目都看不到，如此才能彰顯對佛法的重視與對僧寶的尊崇，從而生起由衷的欽佩瞻仰之心。」

【364-0017】02_戒疏/02d_卷一上之二#92
【原文】【記】問中。難前「著不見處」。答文，初句縱前所問，目對不聞，義亦無過，故云「應爾」。「下」下，正釋制意。慢業本有，轉令增長，故云「慢習」。
【譯文】【記文】在發問的文句中。這是針對前面「安置在看不見之處」提出問難。在回答中，第一句先退一步順應前文所問，眼睛只看而不聽，照理說本無大過，所以說「應爾」。「下」字以下，正式解釋制戒的用意。傲慢的惡業本就人人自帶，若令其隨意觀看只會更加增長，所以稱為「慢習」。
