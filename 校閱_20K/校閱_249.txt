# 校閱材料　第249檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【249-0007】02_戒疏/08d_卷二下之一#21
【原文】【疏】就注解中。言「自稱說有信」者，釋上行妄語者言也。「信」，謂理解不壞之信；「戒」，謂八正、定道之戒；「施」，謂亡我之施；「聞」，謂道分無漏聞慧；「智慧」，謂思修懷正之「智」；「辯才」，謂四無礙辯，非凡所得也。此之六相，唯聖所感，在凡人上，故曰「上人法」故。
【譯文】【疏文】就注文的解釋中。說「自稱說有信」，是解釋上面造作妄語者的言詞。「信」，是指理解真理而不可動搖的信心；「戒」，是指八正道、定共戒與道共戒；「施」，是指忘卻自我的布施；「聞」，是指聖道分中的無漏聞慧；「智慧」，是指思慧與修慧懷抱成就聖道的智慧；「辯才」，是指四無礙辯，不是凡夫所能證得的。這六種特相，唯有聖者才能感得，高居於凡人之上，所以稱為「上人法」。

【249-0008】02_戒疏/08d_卷二下之一#22
【原文】【記】注中，初科。前總示注意。「信」下，別釋言相。初明「信」者，準《業疏》云：「信有二種：一、事信，此有退失；二、理信，謂內凡分見真理，善根堅固，不可傾動，故云『不壞』。」釋「戒」云「八正」者，初果已去，得無漏智，故彰「正」名，亦名「聖道」。初三「戒」攝：一、正語，二、正業，三、正命。「定道」者，若得色無色定，及初果已上，得無漏道時，身口任運，離諸業非，與定、道同時，故二並名「共」，亦名為「俱」。文云「八正」即八中前三，「定道」即指二共，並聖戒耳。釋「施」云「亡我」者，能施、所施，及中間物，三皆不可得，則心不望福求報，名不住相施。釋「聞」及「智」，乃約「聞思修」三慧，配之可見。「懷」即思修，「正」即聖道。釋「辯才」云「四辯」者，一義，二法，三辭，四樂說。四皆通達，俱名「無礙」。「此」下，探取下注，合釋上《經》。
【譯文】【記文】注文之中，第一科判。前面總體指出注文之意。從「信」字以下，分別解釋言詞的行相。首先說明「信」，依照《業疏》所說：「信心有兩種：一是事相之信，這會退失；二是理性之信，指內凡位部分照見真理，善根堅固，不可動搖，所以稱為『不壞』。」解釋「戒」說是「八正」，是指初果以上，證得無漏智慧，所以彰顯「正」的名稱，也稱為「聖道」。八正道的前三項屬於「戒」所攝：一是正語，二是正業，三是正命。所謂「定道」，如果證得色界、無色界定，以及初果以上證得無漏道時，身口任運自然遠離一切業非，與禪定、聖道同時相應，所以兩者都稱為「共」，也稱為「俱」。文中說「八正」就是指八項中的前三項，「定道」就是指定共戒與道共戒這二共，全都屬於聖戒。解釋「施」說是「亡我」，是指能施者、所施對象以及中間的施物，三者皆不可得，內心不貪求福德善報，稱為不住相布施。解釋「聞」與「智」，則是配屬「聞、思、修」三慧，比對即可明瞭。「懷」即思修，「正」即聖道。解釋「辯才」說是「四辯」，是指第一義無礙、第二法無礙、第三辭無礙、第四樂說無礙。四者全都通達，都稱為「無礙」。從「此」字以下，探取下文的注文，合起來解釋上面的《經律》。

【249-0010】02_戒疏/08d_卷二下之一#24
【原文】【記】釋人法，定名中。初牒示，「古」下，引釋。古云「積聚」者，語出《雜心》。「字書無訓」，點其非也。「今」下，即唐翻。「如」下，謂秦、晉所翻，多云「五眾」。「蘊」、「眾」二名，並符「聚」義。故《俱舍》云：「諸有為法和聚故是蘊義。」
【譯文】【記文】解釋人法、確立名稱的部分。首先引述標明，從「古」字以下，引用並加以解釋。古人說「積聚」，這話出自《雜心論》。「字書無訓」，是指出其不當之處。所謂「今」，是指唐代的翻譯。所謂「如」，是指秦代、晉代所翻譯的，多數稱為「五眾」。「蘊」和「眾」這兩個名稱，都符合「積聚」的意思。所以《俱舍論》說：「所有有為法聚集在一起，所以是蘊的含義。」

【249-0011】02_戒疏/08d_卷二下之一#25
【原文】【疏】如《論》中說，陰、界一也。論本成人，但色心耳。眾生迷執，多不解悟，故隨病設藥治之，不須諍也。秪恐誦藥，而迷愈疾，非聖意也。
【譯文】【疏文】如同論典中所說，陰和界是一樣的。論典本來用以指成人的要素，不過就是色法與心法而已。眾生迷妄執著，多數不能解悟，所以隨順眾生的病情施設藥方來對治，不需要爭論。只怕一味背誦藥方，卻迷失了服藥治病的根本目的，這不是聖人的本意。

【249-0012】02_戒疏/08d_卷二下之一#26
【原文】【記】次科，總標中。「如論」，即《成實》。「陰、界一」者，體不異也，義必兼「入」，文中語略。「論本」下，示同相。「眾生」下，明別相。若準《雜心》，凡有三義：一、約欲，二、約迷，三、約根。雖開多別，名別體同，則無所諍。「秖恐」下，以世學者，多誦少行，說食數寶，終成無益，故此責之。
【譯文】【記文】第二科判，總體標示中。所謂「如論」，就是指《成實論》。說「陰、界一」，是指兩者本體沒有差別，含義必定涵蓋「處（入）」，文中語句簡略。從「論本」以下，揭示相同的本質。從「眾生」以下，說明不同的行相。如果依照《雜心論》，總共有三種含義：第一、依據貪欲；第二、依據迷惘；第三、依據根器。雖然開展出許多差別，名稱不同而本體相同，就不需要諍論。從「秖恐」以下，因為世間學者多數空談背誦而少於實修，如同說食數寶，終究毫無益處，所以在此責備他們。

【249-0013】02_戒疏/08d_卷二下之一#27
【原文】【疏】故彼文云「迷於心者為說陰」。色相為一，分心為四。令知識、想、受三，猶未成業；若至行心，三毒三善隨發成業，則不可治。故當「常爾一心，念除諸蓋」，斯成藥也。對病之時，並亡去矣。病成方憶，難可言也。
【譯文】【疏文】所以該論說「對心法迷惑的人為他說陰」。將色法合為一種，將心法分為四種。讓眾生明白識、想、受這三者，還沒有形成業力；如果到了行心，三毒或三善隨之發動而形成業力，就不可救治了。所以應當「經常一心專注，收攝意念消除各種蓋障」，這才能成為良藥。待以藥對治除病之際，病與藥便應一併泯除（病癒藥亡）。等業病已成才回想對治，那就難以挽回了。

【249-0014】02_戒疏/08d_卷二下之一#28
【原文】【記】釋陰中三。初明立法；「令」下，次顯分心開迷之意；「故」下，三、勸對治。既識四心，知行成業，乃達生因，即窮苦本。體三毒源，息有漏業，縛著可解，出離有期矣。「常一心」者，即教藥也。「諸蓋」，即機病也。一、欲蓋，二、恚蓋，三、睡眠，四、掉悔，五、疑，由此五種，能覆真性，故通名「蓋」。「對病」、「竝亡」者，藥病俱除也。若存於藥，還成其病，如船渡岸，似指標月，喻可曉也。「病成」「難言」，傷縱怠也。任毒不治，起行成業，後覺叵追，悠悠不覺，生死長矣。
【譯文】【記文】解釋五陰的文段分為三部分。首先說明施設教法；從「令」字以下，接著顯明剖析心法以開啟迷妄的意圖；從「故」字以下，第三部分是勸告及時對治。既然認識了這四種心法，知道行心會造作行業，就能通達受生的根由，窮究痛苦的根本。體會三毒的源頭，止息有漏的造業，執著束縛便可解除，出離生死就有期盼了。「常一心」，這就是教法的藥方。「諸蓋」，就是根機的疾病。一是貪欲蓋、二是瞋恚蓋、三是睡眠蓋、四是掉悔蓋、五是懷疑蓋，由於這五種心病能夠覆蓋真如本性，所以統稱為「蓋」。「對病」、「竝亡」，是指藥與病都要同時消除。如果執著於藥方，藥又成了新的病，如同坐船渡岸、用手指指示月亮，比喻淺顯易懂。「病成」「難言」，是感傷眾生的放縱懈怠。聽任煩惱之毒不加對治，生起行心造作惡業，事後覺察已難以追悔，悠悠忽忽毫無所覺，生死輪迴就極其漫長了。

【249-0018】02_戒疏/08d_卷二下之一#32
【原文】【記】後釋界者。就上意根，更開六識，為十八界。「界」是別義，體相各異故，亦是因義，相假成用故。然法塵二界，兼通色心，故使經論開合不定：或攝在心，則色十心八；或分為二，則十色七心，各兼少分。今收於「色」，故云「十一」。「至於」下，示上入界通須勸治。良由根、境和合起用，造諸妄業，遂受輪轉。今既了達，隨境制根。然此諸根，心為其主，亦當「常爾一心」等。界中加「識」，對治亦爾，故云「例上」也。
【譯文】【記文】最後解釋「界」的文段。在上面的意根之外，再開展出六識，合為十八界。「界」是界限分別的意思，因為體相各自不同；也是因的意思，因為互為條件而生起作用。然而法塵與法界，同時涵蓋色法與心法，所以使得經論中的歸納開合並不固定：有的歸納在心法，則色法有十種、心法有八種；有的分為兩種，則色法十種、心法七種，各自兼帶少部分。現在將它收攝在「色法」之中，所以說「十一種」。從「至於」以下，指出上面「入」和「界」都必須勸令對治。實在是因為根與境和合生起作用，造作種種妄業，於是遭受生死輪迴。現在既然通達明了，就要隨著所對之境克制根門。然而這些根門，心是它們的主宰，也應當「經常一心專注」等。十八界中增加了「識」，對治方法也是如此，所以說「比照上面」。
