# 校閱材料　第1669檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1669-0001】03_業疏/08a_卷二之二#116
【原文】問：戒場不許僧住，文何牒者？答：住有多種，四儀一時之目，不可怪也。如初結場，猶稱住處，何況解也
【譯文】問：戒場不准許僧眾固定居住，解界文中為何宣讀「住處」呢？答：「住」有多種類型，行住坐臥四威儀中一時的停住也是住，不可感到奇怪。例如最初結戒場時，尚且稱為住處，何況是解界之時呢。

【1669-0002】03_業疏/08a_卷二之二#117
【原文】釋法中初問，以文違前答，故須決破。「住多種」者，有永、暫故，四儀之住，明非長久。今此所牒，止是暫時。下文引結況解，因知結法亦暫時耳
【譯文】在解釋作法的第一個問答中，因為文詞似乎違背了前面的回答，所以必須予以決斷破除。「住有多種」，是指有永久居住與暫時停住的區別，四威儀中的住，顯然不是長久居住。如今文中所宣讀的，只不過是暫時停留罷了。下文以最初結場來比況解場，便可知結界法中所稱的住處也只是暫時的。

【1669-0003】03_業疏/08a_卷二之二#118
【原文】問：結場既竟，須結通界，文何明解？答：立法須也，可即依文，任時行藏，義不連誦，餘並準此
【譯文】問：戒場既然結好了，接下來必須結通圍大界，文句中為何在此說明解法呢？答：這是創立教法儀軌所必須的次第，豈可隨即照著文句順序（立刻依文解界）呢？應當任隨時機需要而行用或存置不用，在義理上並不是要連續宣讀，其餘各處的結解次第皆準此辦理。

【1669-0004】03_業疏/08a_卷二之二#119
【原文】次問，結後明解，立法次第諸界皆然，故此總決。通界即通圍大界。答中文雖次列，舉用在時耳。「行藏」，即用、不用也
【譯文】第二個問答，關於結界之後隨即說明解界，設立法式的次第在所有界域中都是如此，所以在此作了總體決斷。「通界」就是指通圍大界。回答中說明文句雖然依序排列，但實際舉用全在於相應的時機。「行藏」就是用或不用。

【1669-0005】03_業疏/08a_卷二之二#120
【原文】後結通圍大界法中分三：初標緣起，二相，三結
【譯文】在其後結立通圍大界之法中分為三部分：一是標示緣起，二是劃分標相，三是正式結界。

【1669-0006】03_業疏/08a_卷二之二#121
【原文】初中不得合河結者，以水難不恒，卒增障集，機緣既阻，僧義不成，徒張拯溺之名，終喪乘權之實，既無津渡，結不成也。《僧祇》中，水中有洲，五處據標結：兩邊水內取三由旬，恐持欲渡，飄出界故；三陸地上，隨時大小
【譯文】在第一部分中，不能跨越江河合併結界的原因，是因為水患災難不可預料，突如其來的漲水會障礙僧眾聚集，作法的時機因緣既然受阻，僧團和合的義理就不能成就，這只不過徒然張顯拯救溺水之美名，最終卻喪失了因應權變的實效，既然沒有渡口舟橋，結界是不能成就的。《僧祇律》中說，水中如果有沙洲，應在五個處所依據標相結界：兩邊水域內各取三由旬，唯恐持欲人渡水時，被水流漂出界外的緣故；其餘三處在陸地上，隨當時需要決定大小。

【1669-0007】03_業疏/08a_卷二之二#122
【原文】後結大界緣中初科，正釋為二：初示制意。既障僧集，無由應事，故機緣阻也；復乖和合，故僧義不成也。是則如來乘權制法，拯濟沉溺，但有虗名，終無實效，故云「徒張」等。津渡即船橋梁。《僧祇》下，次引開成。「五處據標結」者，彼因摩頭羅國藂林精舍，隔河東岸有仙人聚落精舍，時二處比丘共結為一布薩界。乃至若河中有洲，應五處作羯磨：一、摩頭精舍，二、水中，三、洲上，四、水中，五、仙人聚落精舍。如陸地道兩邊各二十五肘，水中亦爾。一時夏水泛漲，比丘受欲來應羯磨，為水漂出界，殆死得出，白諸比丘乞廣結界，即於上下水三由旬作標結界
【譯文】在後文結大界緣起的第一科中，正式解釋分為兩層：首先揭示制教的用意。既然阻礙僧眾聚集，就無從順應僧事，所以說時機因緣受阻；又違背了僧團和合，所以說僧眾的意義不能成就。這樣一來，如來順應權機而制定教法以拯救沉溺眾生，便只有虛名，終究沒有實效，所以說「徒張」等。津渡就是指船隻與橋樑。自「僧祇」以下，其次引用開許成就之例。「五處據標結」者，是因為摩頭羅國的叢林精舍，隔著河流在東岸有仙人聚落精舍，當時兩處比丘共同結為一個布薩界。乃至如果河流當中有沙洲，應當在五個處所舉行羯磨：第一在摩頭精舍，第二在水中，第三在沙洲上，第四在水中，第五在仙人聚落精舍。如同陸地道路兩側各留二十五肘，水中也是如此。有一回夏季水勢暴漲，比丘受了欲意前來應赴羯磨，被水漂出界外，九死一生才得以脫身，便向諸比丘陳請乞求擴大結界範圍，僧眾便在水流上下游各三由旬立標結界。

【1669-0008】03_業疏/08a_卷二之二#123
【原文】問：水陸二界互相攝不？答：如上說竟。自然界中兩不相攝，僧祇得者據作法言之
【譯文】問：水界與陸界這兩界是否相互統攝呢？答：如同上面已經說過的。在自然界中兩者互不相攝；而《僧祇律》中判定可以相攝的，是就作法結界而言的。

【1669-0009】03_業疏/08a_卷二之二#124
【原文】問答中，欲顯作法、自然攝不攝異，故問通之。答中，初指自然，即前緣成明六相中；「僧」下，次通作法
【譯文】在問答之中，是想要顯明作法界與自然界在相互統攝與否上的差異，所以發問予以通達闡明。在回答中，首先指出自然界的情形，就是前面緣成門說明六相之中的內容；自「僧」以下，其次通達說明作法界的情形。

【1669-0010】03_業疏/08a_卷二之二#125
【原文】不得二界相接者，以界體限約，各分位局，今若連接，終非別住，故制之也。如上相去一肘，無有正文，約同二繩，得分便罷，故文云「應留中間」，即空地也
【譯文】不能讓兩個界相互緊密連接的原因，是因為界體各有其分界約束，各自的界域地位都有限定，如今若是緊緊連接，終究失去了各自獨立別住的意義，所以世尊對此加以規制。正如上面所說的「兩界相距一肘」，其實律中並沒有明確正文，只要如同兩條繩索並置而能明確劃分界限即可，所以律文說「應留中間」，這就是指空地。

【1669-0011】03_業疏/08a_卷二之二#126
【原文】次科，初示制意；「如」下次明分隔不定濶狹，前引古師局執一肘，故復點古非，引文顯正。
【譯文】下一科中，首先明示制戒的用意；自「如上」以下，其次說明兩界間隔的寬狹並無固定標準，因前面引用古師拘泥執著於「一肘」之說，所以此處再次指出古師的非理，並引用文證顯明正確之理。

【1669-0012】03_業疏/08a_卷二之二#127
【原文】云「不唱方相」者，今有結者臨時迷事：或坐場內通唱三重者；或於大界內通唱通結場界兩所者；或但唱外相者；或但唱內相者；雖唱諸相，互不周帀者，皆謂異界相攝，內外通濫，三界混亂，定斷不成
【譯文】律文中說「不唱方相」的情況，是如今有些結界者臨時迷失了具體事相：有的是坐在戒場之內通體唱明三重標相；有的是在大界之內通唱通結戒場與大界這兩處界域；有的只是唱明外層標相；有的只是唱明內層標相；或者雖然唱明了各個標相，卻彼此交錯不能完全周遍圍繞，這些都屬於不同界相互混雜包攝、內界與外界互通混淆、三界混亂不清，律法裁決必定判定結界不能成就。

【1669-0013】03_業疏/08a_卷二之二#128
【原文】二明相中初科，初通標。「或」下別列，有五：一、場中遙唱，隨界各結；二、大界通唱通結，遙加戒場；三、四兩種，兩相互缺；五、雖具唱相，有差訛。「皆」下總結。「異界相攝」，即前二；「內外通濫」，即後三；或可二句通該五過。戒場、大界中隔自然，故云三界
【譯文】在第二「明相」的第一科中，首先是通論標示。自「或」以下分別列舉，共有五種：第一、在戒場中遙遙宣唱標相，然後隨各別界域各自結界；第二、對大界作通同宣唱與通同結界，並遙將戒場加在其中；第三與第四這兩種，是內相與外相兩種標相各自有所缺漏；第五、雖然具備宣唱標相，但有差訛錯誤。自「皆」以下作總結。「異界相攝」即是指前兩種過失；「內外通濫」即是指後三種過失；或者這兩句也可通貫涵蓋這五種過失。戒場與大界之間隔著自然界，所以稱為「三界」。
