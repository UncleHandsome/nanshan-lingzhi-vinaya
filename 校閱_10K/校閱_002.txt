# 校閱材料　第002檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【002-0001】01_行事鈔/01a_卷上之一#39
【原文】若論自然，隨處遠近，則有四別：謂聚落、蘭若、道行、水界。皆不為物造，隨人所居，即有分局，故曰自然。當律無文，諸部詳用。
【譯文】如果是談論「自然界（未經僧團作法結界，依自然環境天然形成的界限）」，隨著處所的遠近，則有四種差別：即聚落（村落）、蘭若（空閒處阿蘭若）、道行（行路旅宿）、水界（江河湖海）。這些都不是為了特定事物由人工羯磨所建造，而是隨順眾人所居住活動之處，自然便有了分限局限，所以稱為「自然界」。本宗《四分律》中沒有明文，但各部派律典均有詳細規範與採用。

【002-0002】01_行事鈔/01a_卷上之一#40
【原文】初聚落中，有二。
【譯文】首先在「聚落自然界」中，有兩種情況：

【002-0003】01_行事鈔/01a_卷上之一#41
【原文】若可分別者。《十誦》云：於無僧坊聚落中，初作僧坊，未結界，隨聚落界是僧坊界，此內不得別眾。問：蘭若處有僧坊，欲結界，何處集僧？答：《十誦》云：隨聚落即僧坊界。今周匝院相，與聚落之相不分，不須五里集人。故下文，無聚落蘭若，初起僧坊，乃云一拘盧界。故知先有僧坊，即同村界。律中，僧村四相，二界不別。必院相不周，乃可依蘭若集僧。
【譯文】若是村落界限可以明確分別的：《十誦律》說：在原本沒有僧舍的聚落之中，剛開始建造僧舍，還沒有作法結界，此時隨順聚落的界限就是僧舍的界限，在此聚落範圍之內不得別眾（部分僧人私自另行集會作法）。問：如果在阿蘭若空閒處有僧舍，想要作法結界，應在何處召集僧眾？答：《十誦律》說：隨順聚落範圍即是僧舍的界限。如今僧坊四周的圍院相狀，與律中聚落的四種界相並無分別（皆有牆垣圍繞），因此便同於村界，不需要到蘭若方圓五里之內去召集僧人。所以下文才說，在沒有聚落的空閒蘭若處，初次興建僧舍，才稱為以一拘盧舍（約五里）為界限。因此可知，原先已有僧舍聚落者，即等同於村落自然界。律典中，僧坊與村落皆具備律中的四種界相（四周牆、柵籬、籬牆不周、四周有屋），這兩種界限並無分別。必定是僧院圍牆標界不完整時，才可以依照蘭若集的標準去召集僧眾。

【002-0004】01_行事鈔/01a_卷上之一#42
【原文】若聚落有僧不可知者。《僧祇》中：若城邑、聚落，界分不可知者，用五肘弓，七弓種一樹；齊七樹相去，使異眾相見，不犯別眾，各得成就。準相通計，七樹六間，得六十三步。不同前解，七間七十三步半，如《義鈔》廢立。
【譯文】如果聚落中是否有其餘僧人不可確知，或者聚落太大界分無法明了者：《摩訶僧祇律》說：若是城邑、聚落的界限範圍無法知曉，可用長五肘的弓為尺規，每相距七弓便種植一棵樹；彼此相距達到七棵樹的間距，即使兩處不同的僧眾互能相見，也不犯別眾之罪，各自所作的羯磨都能成就。依據標相總括計算，七棵樹之間有六個間隔，合計得六十三步。這不同於古德「七個間隔得七十三步半」的解釋，具體如《四分律拾毗尼義鈔》中所作的辨析取捨。

【002-0005】01_行事鈔/01a_卷上之一#43
【原文】二明蘭若者。統明蘭若，乃有多種：謂頭陀、寄衣、盜戒、僧界、衣界、難事。且明僧界，餘下隨明。蘭若一界，諸部不定，多言僧界盡一拘盧舍。《雜寶藏》中翻為五里，相傳用此為定。若有難者，如《善見》云：阿蘭若界者，極小方圓七槃陀，一槃陀二十八肘。若不同意者，於外得作法事。計有百九十六肘，肘各尺八，總有五十八步四尺八寸。
【譯文】第二說明「蘭若自然界」。統明蘭若，乃有多種：也就是修頭陀行、寄放衣服、防範盜戒、劃定僧界、不失衣界，以及避難之事等六種。此處暫且只說明「僧事自然界」，其餘各類隨下文相應章節再作說明。蘭若這一個自然界，各部派律典規定不一，多數主張僧事界限以一拘盧舍（krośa）之內為限。《雜寶藏經》中將拘盧舍翻譯為五里，歷來相傳便以此作為定準。如果有特殊難事緣故，如《善見律毘婆沙》說：阿蘭若自然界，極小者方圓為七槃陀（bandha），一槃陀為二十八肘。如果有不同意和合的僧人，在七槃陀之外就可以另行作法事。合計共有單邊一百九十六肘，若一肘折算為一尺八寸，總共為五十八步四尺八寸。

【002-0006】01_行事鈔/01a_卷上之一#44
【原文】三道行界者。《薩婆多》云：比丘遊行時，隨所住處縱廣，有拘盧舍界；此中不得別食、別布薩。亦不明大小？此論解《十誦》律文云：六百步為拘盧舍。
【譯文】第三說明「道行自然界」。《薩婆多論》說：比丘在道路遊行時，隨著所住宿的處所，其縱橫廣度即形成一個拘盧舍自然界；在此範圍之中，僧眾不得別食、別布薩。此處律文雖未說明拘盧舍範圍之大小，但彼論在解釋《十誦律》文時指出：以六百步為一拘盧舍。

【002-0007】01_行事鈔/01a_卷上之一#45
【原文】四明水界者。《五分》云：水中自然界者，若在水中行，眾中有力人水灑及處。《善見》云：若擲水、若散沙，已外比丘不妨。取水常流處，深淺皆得作自然，潮水不得。若船上布薩，應下矴，不得繫著岸及水中樹根，謂與陸地界相連。若水中石、木、樹等，悉是水界，謂離陸地者。
【譯文】第四說明「水界自然界」。《五分律》說：水中的自然界，是指如果徒步涉水行走於水中，以僧眾中有力氣的人用手潑水所能到達的範圍為界。《善見律毘婆沙》說：以有力者潑水或拋灑泥沙所及之處為界，在此範圍之外的比丘就不妨礙作法。水界應取水流恆常流動之處，不論水深水淺都可以作為自然界，但潮水漲落無常之處則不可作為自然界。如果是在船上舉行布薩，應當拋下鐵錨定住船隻，不可繫纜在岸邊或水中的樹根上，因為那樣便與陸地自然界相連了。若是水中的石頭、木樁、獨立樹木等，只要是脫離陸地的，都屬於水界範圍。

【002-0008】01_行事鈔/01a_卷上之一#46
【原文】今更總論二界之體。
【譯文】現在再進一步總體討論作法界與自然界這兩種界體。

【002-0009】01_行事鈔/01a_卷上之一#47
【原文】若三種作法，隨處限局，不約方隅。若論自然，則有不定：若聚落中，界分可知，隨其分齊，亦無方圓；不可分別，人解不同。
【譯文】若三種作法界，隨其處所局定範圍，不受限於特定方位與方圓形狀。若論及自然界，則有不定的情況：如果是在聚落中，四周界標分明可知，就隨其天然界限為準，也沒有固定要求是方是圓；若是界限模糊不可分別者，歷來各家見解便有所不同。
