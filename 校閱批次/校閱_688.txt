# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【688-0002】01_行事鈔/12b_卷下之四#45
【原文】《毘尼母》：沙彌法，應知慚愧，善住。奉事師法中，不應懈怠放恣。當自慎身口，卑己敬人；常樂持戒，莫樂調戲；不應自恃才力，復莫輕躁；應知羞耻，不說無定亂言；唯庠序合理，自知淨不淨法。常逐二師，讀誦經法。一切僧中，若有所作，皆不得違。如是廣知。
【譯文】《毘尼母經》說：沙彌的安身立命之法，應當深知慚愧，安住於清淨善法之中。在侍奉師長的法則中，切不可懈怠傲慢、放縱任性。應當自我謹慎守護身業與口業，謙卑處事、恭敬待人；恆常欣樂於受持戒律，切莫喜好嬉笑調戲；不應當自恃聰明才智或體力，更不可舉止浮躁輕狂；應當知曉羞恥，不說毫無根據、散亂荒唐的話語；言行舉止唯求端莊安詳、合乎正理，自己能明確辨別何為如法清淨、何為不如法不清淨。應當常常跟隨和尚與阿闍梨二師，讀誦經書、修習法義。在全體僧團大眾之中，若是僧眾有所差派作務，一概不得違抗抗拒。以上各端應當廣泛明了。

【688-0003】01_行事鈔/12b_卷下之四#46
【原文】《薩婆多》：沙彌不為三寶緣有利益者而掘地，犯罪。《五分》：下三眾，無故造罪，亦吉羅。《四分律》結吉羅，謂無緣而損傷。乃至不受食、殘宿、自煮等，無人則開；有淨人故作，則結吉羅。例之。
【譯文】《薩婆多論》記載：沙彌如果不是為了三寶有直接利益的因緣而去挖掘土地，便犯掘地罪。《五分律》記載：下三眾如果無故造作罪業，同樣結突吉羅罪。《四分律》中結犯突吉羅罪，是指沒有特殊合法因緣而挖掘損傷草木土地。乃至未經受食而擅自取食、吃殘宿之食、自己親自煮食等戒條，若沒有居士淨人服侍時則特別開許；如果有淨人在場卻故意自己去煮食造作者，則結犯突吉羅罪。其餘各條皆可依此類推。

【688-0004】資持記/16c_下四#53
【原文】淨不淨，或約為僧作淨，或據自知持犯。二中，《多論》唯明掘地開制。《五分》通示一切法制。《四分》略列犯相。餘可準知，故云例之。三中，初明語師。若治下，次示治相。若不下，三制奉給。不應下，四明同利。《四分》給房，當量可否。斥謬中。古謂下眾，犯同五八，不係篇聚。故有此通。剩，即多也。
【譯文】清淨與不淨，或是指替僧團準備符合戒規的清淨飲食物品，或是指自己內心明了持戒與犯戒的差別相貌。在第二項中，《薩婆多論》唯獨指出了掘地一事的開許與禁止規範。《五分律》則是通盤開示了一切戒法的禁止規定。《四分律》只是略微列出了違犯的相貌。其餘各條皆可依此類推而知，所以說「依照此例推衍」。在第三項中，首先說明應當如何向師長稟白報告。在「若治」字以下，接著說明如法懲戒治罰的具體相貌。在「若不」字以下，第三項規定如何供應日常服侍與所需用度。在「不應」字以下，第四項說明如何公平共享僧團利益。《四分律》中分配僧房，應當詳細裁量其資格是否合適。在斥責荒謬觀點的段落中。古代學者誤以為下位三眾，其所違犯的過失只等同於在家的五戒、八戒，並不隸屬於出家法規的五篇七聚之中，因此才產生了這種似是而非的通融說法。「剩」就是多餘繁瑣的意思。

【688-0005】01_行事鈔/12b_卷下之四#47
【原文】《五分》：若罰沙彌，先語其師；師亦不應非法助沙彌。若治罰，應作種種苦使，掃地、除糞、摙石治階道。若不為和尚、闍梨及餘人作使，應語如法供給和尚、眾僧作使，次至應作。不應遮不與僧中利養，此是施主物。《四分》：從大比丘下，次第與沙彌房舍、臥具；若不能愛護，不應與。若利養，隨次與之。
【譯文】《五分律》記載：僧團若要懲罰處分沙彌，應當先告知其師父；師父也不應當不如法地偏袒庇護沙彌。如果要進行懲罰治罰，應當責令他承擔種種艱辛勞役，比如打掃庭院、清除糞穢、搬運石塊修治階梯道路等。如果沙彌不願為自己的和尚、阿闍梨及其他僧人服勞役，應當告誡他如法供給侍奉和尚與僧團作務，輪到自己時就應當承擔。但不應當阻攔苛扣、不分給他在僧團中應得的飲食利養，因為這些是施主布施給所有出家人的信物。《四分律》記載：在大比丘分配完畢之後，應當依照次第分配給沙彌房舍與臥具；如果沙彌不知愛惜維護常住物，則不應當分給他。至於日常利養，則應依長幼次第平均分發給他。

【688-0008】01_行事鈔/12b_卷下之四#51
【原文】比丘尼眾，細行眾多。同大僧者，如上所列；有無輕重，隨事已分。今簡取唯別者，共為此科；使臨事即披，不事浮漫也。所以在沙彌後者，《智論》云：尼得無量律儀故，次應比丘後；佛以儀法不便，故在沙彌後。

【688-0009】資持記/16c_下四#54
【原文】此下，正斥。人語，出於凡情；正教，出於聖意。故須準教，不可依人。29 釋尼眾篇(下四)釋尼眾篇題中，上二字，通收三位。別行，如前釋。注中。翻名，總云阿摩尼，此云母女。即佛呼姨母之稱，故云重尼也。敘意，初科；上三句，標廣。女流情著，行相倍增故。同下，示同別；
【譯文】在「此」字以下，正式予以嚴正斥責。世俗之人的言語，完全出自於凡夫的虛妄情執；如來的純正教法，才是徹底流露自聖者的圓滿聖意。因此行事必須嚴格遵循聖教規範，萬萬不可盲目聽信個人的私意妄談。第二十九卷，解釋〈尼眾篇〉（本篇下分四科）。在解釋〈尼眾篇〉的標題中，前面「尼眾」這兩個字，廣泛涵蓋了比丘尼、式叉摩那以及沙彌尼這三個法位。個別行持的法式，如同前文已經解釋過的一樣。在註解之中。翻譯名義時，梵語總體稱為「阿摩尼」，漢語翻譯為「母女」。這原本是佛陀呼喚親生姨母大愛道時的尊稱，所以將比丘尼的尊稱視為極其隆重的稱謂。在敘述本篇意旨的部分，第一個小段落；前面三句，標示出其戒相繁多廣大。因為女性的情執與貪著較重，所以防範過失的戒律行相相較於大僧倍增繁多。在「同」字以下，指出相同與相異之處；

【688-0010】資持記/16c_下四#55
【原文】初指同，即上諸篇；今下，正敘此篇；即披，是教有所準故；不浮漫，是行無所昧故。次科，初徵；以約類雖然，據位則亂故。次引論釋，言不便者，男女相配，涉譏疑故。大尼受戒中，初文；十二歲者，是師位故；僧則十歲，《業疏》云：所以加二歲者，顯其志弱，累年為德也；
【譯文】首先指出共通之處，指的就是前面已敘述過的各篇章；「今」字以下，正式展開陳述本篇的正旨；立即翻閱披讀，是因為言行舉止完全有聖教作為依準規範；不至於散漫浮泛，是為了讓修道行持時內心明朗不致迷茫昏昧。下一個小段落，首先提出詰問反思；因為若單純依照男女類別來劃分似乎可行，但若按照出家受戒的法位相較，隨意配列則會導致僧團體制尊卑混亂。接著引用論典來做解釋，文中所說的「不便」，是指若將男女法位直接互相配對，容易招致世人的譏嫌與猜疑。在比丘尼受具足戒的章節中，最初的文段；規定必須年滿「十二歲」，是因為這已經是為人師表的長老資格；大僧比丘則只需要受戒滿十年即可，《業疏》中解釋說：之所以為比丘尼額外增加兩年的年限，是為了彰顯女性在道心上容易怯弱，必須累積更多的年資修持才能成就厚重德行；

【688-0012】01_行事鈔/12b_卷下之四#53
【原文】初中，前明畜眾。《四分》：尼滿十二歲，欲度人者，應白二羯磨，請尼僧聽許。不乞者，受具，犯墮；依止、式叉、沙彌尼，吉羅。比丘通結吉羅。其乞法與白二法，如常所顯。若得羯磨已，一年中度一大尼，一六法，一沙彌尼，一依止。隔年又得，義須重與法也。
【譯文】第一、在受戒法中，首先說明蓄徒度眾的規定。《四分律》規定：比丘尼受具足戒滿十二臘，若想度人出家的，應當作「白二羯磨」（一白一羯磨），向尼僧團乞求開許。如果未向僧團乞求開許便私自度人的，被度者受具足戒時，度人師犯墮罪（波逸提）；若是收納依止弟子、傳度式叉摩那、傳度沙彌尼，則犯突吉羅罪。比丘若未得僧聽而度人，則普遍結突吉羅罪。其中的乞求文法與白二羯磨文法，正如通常律典所昭示。如果已經獲得尼僧團羯磨通過認可，在一年之中只允許度一名大尼（比丘尼受具戒）、一名受持六法的式叉摩那、一名沙彌尼，並收納一名依止弟子。隔年若想再度人，按義理規定必須再次向僧團祈請並給予定法羯磨。

【688-0014】資持記/16c_下四#56
【原文】又女人多樂畜眾，由本習也；年年度人，不能教授，多有違犯，故制乞法，令眾量之；不乞，受具犯墮；受人依止，度餘二眾，並制乞法，不乞皆吉；比丘通吉者，制乞同尼，但除式又；違犯一等，而無差降。其下，指乞法，文見《隨機羯磨》、及《尼鈔》。若下，示制限。受戒標中，非法濫相，如下正受斥古，是也。
【譯文】再者，女性多半習慣好樂蓄養大批徒眾，這是源於過去世養育照顧的宿習；如果每年都隨意度人出家，自己又沒有足夠能力訓誨教導，往往會導致弟子多有違犯，因此佛陀制定必須向尼僧團求乞聽許度人的法度，由全體僧眾審核裁量；若不求乞就擅自為人授具足戒，傳戒師要犯波逸提單墮罪；若收受他人作為依止弟子，或是剃度沙彌尼、式叉摩那其餘二眾，也全都制定必須向尼僧團求乞聽許，不事先求乞的大眾全都獲結吉羅輕罪；比丘違犯一律結突吉羅罪，是因為制度上乞法與尼眾相同，只是除去了式叉摩那；違犯的罪責一律相同，並無差別等降。在「其」字以下，指明如何舉行求乞法會，相關文辭詳見於《隨機羯磨》以及《比丘尼鈔》。在「若」字以下，指出受戒次數與名額的嚴格限制。在受戒的標題之中，提及種種不如法且混淆濫用的現象，正如後文正式受戒章節中斥責古德錯誤見解所說的那樣。

【688-0015】01_行事鈔/12b_卷下之四#55
【原文】受前八法。初請和尚、二闍梨，一準僧中。所以云，我依阿姨者，此學佛召愛道之號，相傳不絕。威儀問難中，必須委曲顯示難相，并及諸遮，亦如僧中，以正要急故。乃至本法以來，具依常法；一事或差，不成受也。餘並如前〈受戒〉中。
【譯文】在正受大戒之前應修持「八法」（如請師、審遮難等）：首先迎請和尚尼、兩位阿闍梨（羯磨師、教授師），一切標準皆依循比丘僧中之法。文詞中之所以自稱「我依止阿姨」，這是仿效佛陀當初稱呼大愛道（憍曇彌）的稱謂，代代相傳未曾斷絕。在威儀師問訊檢驗「遮難」的程序中，必須委曲詳盡地開導開示各項難法相狀，以及各種障礙遮條，也完全同於比丘僧中，因為這是受戒最為關鍵要緊之處。乃至從受尼部「本法」（本宮受法）以來，全都要依循常規法則；其中只要有一件事情違背律規，就不能成就受戒。其餘各項儀軌，皆如前面〈受戒篇〉中所述。

【688-0016】資持記/16c_下四#57
【原文】本法中，初示前緣；八法者，一請師，二安置立處，三差威儀師，四出眾問難，五單白召入，六對眾乞戒，七戒師白和，八對眾問難。文中，但示一四兩種，律文，請詞云：願阿姨為我作和尚等，故此釋之；十三難中，若據尼女，號佛無信，本無破僧，然有伴助，亦須問之；
【譯文】在比丘尼根本法受戒儀式中，首先指明先前的預備緣由；所謂的「八種法規」，第一是延請親教師，第二是安置受戒者站立的適當位置，第三是派遣端正威儀師，第四是領其步出大眾詢問遮難，第五是宣唱單白將其召入法堂，第六是令其面對尼僧大眾如法乞求戒法，第七是戒師宣唱和合白文，第八是正式面對尼僧大眾再次詳審詢問遮難。在正文中，只列舉了第一項請師與第四項出眾問難這兩種程序，律藏原文中，迎請的詞句說：「懇願阿姨慈悲為我擔任傳戒和尚」等，所以在此特別對此做出解釋；在十三種重難之中，若依照比丘尼身為女性的特質，號稱對佛陀教法缺乏堅固信仰，本來就沒有能力單獨破壞和合僧團，然而考慮到有可能在旁參與協助策劃，因此受戒時也必須嚴格詢問；
