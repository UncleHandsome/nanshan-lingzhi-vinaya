# 校閱材料　第161檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【161-0001】資持記/15e_下三#44
【原文】乍觀語勢，似總一篇；細詳文意，止結此科耳。25 釋主客篇(下三)釋主客篇舊住名主，時過名客；若對三界，則無有主客；今望伽藍，不無久暫；強分主客，以明待遇。然據律中制主待客，但主須筵款，客至有儀，故云相待耳。制意中。初二句示出家超世，無繫之人，故如賓也。
【譯文】猛然一讀語句的氣勢，似乎是在總結整整一篇的內容；但若仔細審核其文字脈絡與義理，其實僅僅是用來總結這一科的教誡而已。第二十五篇 釋主客篇（下之三）
釋主客篇。久住在寺院的僧人稱為主，暫時路過借住的僧人稱為客；若是對待整個無常的三界牢獄而言，本來就沒有什麼真正的主人與客人；如今就伽藍這處道場來看，修道人居留在此自然有長久與暫時的差別；因此勉強劃分出主與客的界限，用來闡明彼此接待相處的禮儀法度。然而依據律藏中所制定的主僧接待客僧的規則，只要求主僧必須設宴款待安頓，客僧到來時必須具備客禮儀規，所以說主客雙方當以禮「相待」而已。制定義理科中。前兩句開示出家人本是超越世俗、無牽無掛的世外之人，所以自身就如同匆匆過客一般。

【161-0002】資持記/15e_下三#45
【原文】次二句明遊方漂泊，隨處暫止；即以寺字，況於逆旅。謂同迎客之舍，既無定止，義當迎待，故云頗存於此。故下，顯制。曲即委備。云云，生起下文。初科中，前明客來入寺，後明舊住迎接。知佛塔等者，或問於人，或自瞻視。至門應開，謂無關鎖，容自開者。若不能者，即反上也；
【譯文】接下兩句說明僧人雲遊四方漂泊不定，隨順因緣在各處暫時止息；所以用「寺」這個字，來比況人世間的逆旅驛站。意思是說寺院就等同於專門迎納賓客的舍所，修行者既然沒有固定的定居之處，在道義上自當設禮迎納款待，所以說「這層深意多半寄託保存在這裡」。自「故」字以下，正式顯明制戒的條規。所謂「曲」，就是委曲周全、詳盡齊備之意。「云云」，是用來啟發引導引申後面的詳細文義。在第一小科中，前半部分說明客僧進入寺院的規矩，後半部分說明舊住僧人出門迎接的禮儀。所謂「知佛塔等」，或者直接開口詢問他人，或者自己細心瞻視觀察。走到門前應當自行推開，是指寺門並未上鎖、允許自行推門而入的情況。如果不能自行推開，就是與上述情況相反的封閉狀態；

【161-0003】資持記/15e_下三#46
【原文】此間晝日，不尚閉門，事亦稀也。下牆，謂低處。踰入，此方所忌，未可依用。次科，《四分》，初求房舍。自述歲數，令知上下也。有當取者，舊住給與也。丸藥舉之，不拾他物；特舉至微，例其餘也。次問處所。《五分》。不眠，為防難故。三中，《四分》。禮僧，止於四座，以成眾故；
【譯文】我們這方國土在白天，向來不崇尚緊閉寺門，這種吃閉門羹的事也是極為少見的。所謂「下牆」，是指牆身低矮之處。如果翻越矮牆而入，這是我們此方國土極為忌諱厭惡的失儀行為，絕不可仿效依用。下一小科，引《四分律》，首先說明客僧請求分配房舍之法。自己主動陳述戒臘歲數，是為了讓舊住僧人清楚長幼上下的次序。所謂「有當取者」，是指由舊住僧人按規定如法分配給予。鈔文說收存丸藥，難道不收拾其他物品嗎？這是特地舉出最微細的物品，藉此類推其餘一切遺留物品皆當妥善收管。接著說明詢問寺內各處處所之法。引《五分律》：不可同床共眠，是為了防範危難與譏嫌的緣故。第三小科中，引《四分律》。頂禮僧眾時，頂禮以四座為限就應當停止，因為四位僧人就已足以成就一僧團法事；

【161-0004】資持記/15e_下三#47
【原文】餘座不禮，恐勞擾故。思惟，即禪定；禮誦同之。《十誦》。時見，謂近處也。四中，初文，先問法食之處。又下，次問利養，有六。僧差，即僧次；檀越送食，謂將入寺；月八十五，即六齋日，人多設供。〔《業疏》云：黑白俱有三日，文少十四。〕月初，彼國重之，亦多營設；
【譯文】其餘座次的上座僧人就不必一一禮拜，這是擔心頻繁頂禮會造成僧眾勞累困擾的緣故。所謂「思惟」，就是指坐禪入定；禮佛誦經的場合也是同樣的道理。引《十誦律》。所謂「時見」，是指在近處能看見彼此的地方。第四小科中，第一段文，先詢問領受法食的地方。自「又」字以下，接著詢問利養食物的來源情況，共有六種情形。所謂「僧差」，就是指僧次的常規輪流差派；所謂「檀越送食」，是指信眾親自將飲食送到寺院來；所謂「月八十五」，就是指每月的六齋日，信眾大多會在這些日子設齋供養。（《業疏》中說：黑月與白月各有三天，此處律文省略了十四日。）月初第一天，在彼印度諸國極為重視，所以也常常大辦供設；

【161-0005】資持記/15e_下三#48
【原文】檀越請，即別請。〔舊云僧次者，非。〕三問人畜。並據俗舍。次科，初示僧制。若下，明筵留。不語知者，恐追伴故，仍安慰之。給糧食者，準須出己，必非常住。三中。十事與者，前二與物，後八與語。習俗，謂風俗所宜。僧教令，則隨方制度。某事可食，事即物也。法附中，初科，上二句敘教法之功。
【譯文】所謂「檀越請」，是指居士發心的個別請僧供養。（舊時有人解釋為依僧次差請，那是錯誤的。）第三是詢問有關人眾與牲畜的情況。這些全都是依據世俗村落舍宅的情形而言。下一小科，首先開示僧團的共住規約。自「若」字以下，說明挽留延緩客僧行程之法。之所以不告知客僧使其知曉，是擔心客僧會因急於追趕同伴而匆忙離去（遭遇危險），所以應當耐心安慰留宿。為其給予供應糧食，準照戒律必須出自僧人自己的私物，絕不可私自動用常住公物。第三小科中。所謂以十種事情來給予，前兩項是給予物資資助，後八項是給予言語上的引導開示。所謂「習俗」，是指當地的風土人情所適宜的規矩。所謂「僧教令」，就是隨順各地僧團所立的制度。所謂「某事可食」，「事」指的就是物品食物。在隨法附錄中，第一科，前兩句敘述教法的偉大功德。

【161-0006】資持記/15e_下三#49
【原文】以能成善故。有由，謂由於教也。次二句敘威儀之勝。以能成因感果故。冥因者，心業未形故；顯果者，報相可見故。宗即是本。是以下，引證。阿說，亦云阿說嗜，此云馬勝；從佛受學，方經七日，便備威儀；以宿五百世為獼猴，今猶躁擾；出家七日，即改本轍；
【譯文】因為教法能夠成就一切善行。所謂「有由」，就是指善行都是導源於戒律教法的規範。接下兩句敘述威儀的無比殊勝。因為莊嚴的威儀能夠成就清淨之因、感發殊勝之果。所謂「冥因」，是因為內心的善惡業因尚未在外表顯形；所謂「顯果」，是因為外在的受報相貌是歷歷可見的。「宗」就是根本樞紐。自「是以」以下，引證具體事例。阿說，也稱作阿說嗜，此處翻譯為「馬勝」比丘；他跟隨佛陀受教修學，才僅僅過了七天，就具足了極其嚴整的威儀；他由於過去五百世中一直投生為獼猴，所以身上還殘留著躁動輕浮的習氣；但出家僅僅七天，就徹底革除了原本的躁動習氣；

【161-0007】資持記/15e_下三#50
【原文】以威儀悟物，故稱威儀第一。身子與目連為友，共結契云：若得甘露，必當同味；後時身子見馬勝，威儀庠序；乃問汝師是誰？為說何法？答云：法從緣生，亦從緣滅；一切諸法，空無有主。〔此依《五分》引，或有出云：諸法從緣生，亦從因緣滅；我佛大沙門，常作如是說。〕身子聞已，便證初果；
【譯文】以威儀化導啟悟物類，所以被稱讚為威儀第一。舍利弗（身子）與目犍連為好友，共同約定立誓說：『若誰先獲得不死甘露妙法，必定要一同分享法味。』後來舍利弗見到馬勝比丘，行止威儀安詳整肅；便詢問他說：『你的師父是誰？為你宣說什麼法？』馬勝比丘回答說：『諸法從因緣而生，亦從因緣而滅；一切諸法，本性皆空、沒有主宰。』〔這是依據《五分律》所引，或者有的典籍記載為：『諸法從緣生，亦從因緣滅；我佛大沙門，常作如是說。』〕舍利弗聽聞之後，當下便證得初果；
