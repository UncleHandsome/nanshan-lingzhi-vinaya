# 校閱材料　第385檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【385-0001】02_戒疏/03b_卷一下之一#132
【原文】【疏】注中「默妄但犯吉羅」者，有輕重也。望僧虗解，斯業重也；望非言述，重而制輕。勿謂為小，九百千歲亦難堪也。一犯尚爾，多犯如何？不可救也。故《論》說「言如小團鐵，入水沈」也。又引海喻，文相可知。
【譯文】【疏文】夾註中提及「沉默妄語只犯突吉羅罪」，這是在輕重層面作權衡。相對於在大眾僧中造成大眾虛妄的領解，這股業障是極其深重的；但相對於並未動用言語直接說謊，佛陀在制罪上乃從重而判輕。切莫以為這是微細小過，在地獄中承受九百千年的極苦亦是難以忍受的。違犯一項尚且如此，多重違犯又該如何？那時可就萬劫難救了。所以論典中說「如同微小的一團鐵球，落入水中依然沉沒無疑」。夾註中接著引用大海的比喻，文相顯明可以理解。

【385-0002】02_戒疏/03b_卷一下之一#133
【原文】【記】釋注為二。前釋罪相。初通示，「望」下，別釋。誑僧境勝故「業重」，即如《五分》「僧中妄語，重百羅漢前」是也。默表無言故「制輕」。「勿」下，指報誡勸。《目連問經》列六聚犯報，犯突吉羅，九百千歲墮泥黎中。準《雜心論》，即墮等活地獄一晝夜耳。委示歲數，具如《鈔》中。「一」下，舉況。「故」下，引證。《婆沙》云：「愚作小罪永墮惡，智為大罪亦脫苦；為團鐵小亦沉水，為鉢鐵大亦能浮。」又《涅槃》云：「莫輕小罪，以為無殃，水滴雖微，漸盈大器。」有智思之。注中「三空」，謂空、無相、無願三解脫也。「又」下，次點餘文。《疏》但略指，而文相難解，略為科釋。從「告諸比丘」下，大分為二：初明覆過；「故知」下，結示。初中又二：前舉喻，可解；「我」下，二、合法。初二句對合，「謂」下，委釋。初釋死屍，「雖」下，釋不受。初中又二，初通標；「犯」下，別釋。初至「覆藏」，釋上「非沙門」句。「犯戒不淨」，即身口業；「穢汙邪見」等，即是意業。「內懷」下，次釋上自言句。「空中樹」，謂中心枯朽者。
【譯文】【記文】解釋夾註分為兩段。前半段解釋罪相。首先通泛指示，「望」字以下作分別辨析。欺誑僧眾對境殊勝所以「業力極重」，正如《五分律》所載「在僧眾中說妄語，其過失重於在百位羅漢前妄語」。以沉默表示而無言說所以「制教罪輕」。「勿」字以下引果報嚴加誡勉勸導。《目連問戒律中五百輕重事經》列舉六聚罪報，違犯突吉羅罪者，將於泥梨地獄中感受九百千歲之苦。依《雜阿毘曇心論》，這相當於墮入等活地獄一晝夜的時間。詳細歲數說明，完整載於《事鈔》之中。「一」字以下以單況多。「故」字以下引論為證。《大毘婆沙論》說：「愚人造作微小之罪而永墮惡道，智者縱造大罪亦能解脫重苦；微小的鐵團落水亦沉，巨大的鐵缽卻能漂浮。」《涅槃經》亦云：「莫輕小罪，以為無殃，水滴雖微，漸盈大器。」有智慧之人當深長思之。夾註中所說的「三空」，是指空、無相、無願三三昧解脫門。「又」字以下，點出夾註後續文意。《疏》文在此僅略微提示，而註文脈絡深奧難辨，故在此略作科條析釋。從「告諸比丘」以下，大體分為兩部分：前半段闡明隱匿過失的行相；「故知」以下作總結提示。前半段中又分兩節：前半舉出大海之喻，顯明易解；「我」字以下，第二節以法合喻。最初兩句直接對合，「謂」字以下作詳細解釋。首先解釋何為「死屍」，「雖」字以下解釋何以「不容受」。在解釋死屍的文義中又分兩小節，首先總綱標立；「犯」字以下作分別闡釋。從「犯戒」到「覆藏」，是解釋上文「非沙門」這一句。「犯戒不清淨」是指身業與口業，「穢汙邪見」等則是指意業。「內懷」以下，是進一步解釋上文「自言」這一句。「空中樹」是指樹木中心已經乾枯朽敗者。

【385-0016】02_戒疏/03b_卷一下之一#147
【原文】【記】三釋撿問，標分中。云「正問眾中」者，《戒本》「是中」兩字，世人不曉，謂指戒文，所以或謂問前，或云問後。準今科判，乃問「僧中」，則由來疑諍，渙然冰釋。傳迷斯久，學者須知。
【譯文】【記文】在第三段解釋檢驗詢問的標列分段中。所謂「正問眾中」，《戒本》中「是中（在其中）」這兩個字，世人多未能徹解，誤以為是指戒文條文之中，所以才會有人爭論是問前篇、還是問後篇。依照今疏的科判，此語乃是直接詢問「大眾僧團之中」，如此一來，歷來所有的疑慮爭端皆如冰雪消融。此一誤傳盲信已歷時甚久，修學律法之人必須審慎明辨。

【385-0019】02_戒疏/03b_卷一下之一#150
【原文】【疏】答：「解有多途。說戒為於行淨，有犯不應說儀。羯磨別為前緣，緣成則合事辨，故隨白問，終為成法，不別舉也。」
【譯文】【疏文】回答：「對此問題歷來有多種解釋。說戒的核心完全是為了使僧眾戒行清淨，若身有違犯者原本就不合乎參與說戒的威儀軌範。一般羯磨則是專門為了承辦當前的特定事緣，只要因緣具備便應當把事情合力辦妥，所以只要隨著單白發問認可，終究以成就該項法事為旨歸，無須另外再提出清淨與否的專門檢驗。」
