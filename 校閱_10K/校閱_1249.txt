# 校閱材料　第1249檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1249-0001】資持記/12a_中四下#33
【原文】知唯本識隨緣流動，趣向於理，故云無違唯識也。理則達妄者，即了此心妄緣境起；達境即心，心外無境；唯一真識，清淨本然，故云外塵本無也。故下，引證。即《攝大乘論》。唯識不失者，證上緣理也。不無能取所取者，證上緣事也；能取即心，所取即境；此除疑執，恐聞緣理，便謂自心兀然不動；
【譯文】知道唯是本識隨緣流動，而趣向於理，所以說「無違唯識」。「理則達妄」，就是了解此心是虛妄地緣境而生起；通達境就是心，心外沒有境；只有一真識，清淨本然，所以說「外塵本無」。下文「故」字以下是引證。就是《攝大乘論》。「唯識不失」，是證明上面的緣理。「不無能取所取」，是證明上面的緣事；能取就是心，所取就是境；這是為了除去疑惑執著，恐怕有人聽說緣理，就認為自心兀然不動；

【1249-0002】資持記/12a_中四下#34
【原文】恐聞無境，便謂境界豁達都無。今時愚者，錯解佛乘；皆謂理觀寂爾無思，空然無境，取舍不得，能所俱亡；頑然寂住，便是真如；放蕩任情，即為妙用；由是不禮聖像，不讀真經；毀戒破齋，嗜酒噉肉；誇為大道，傳化於人；惡業相投，率多承習。此乃虛妄臆度，顛倒輪迴。
【譯文】恐怕有人聽說無境，就認為境界空蕩蕩地一無所有。現今愚癡的人，錯解佛乘；都說理觀是寂然無思，空空洞洞沒有境界，取捨都不可得，能所雙亡；頑然安住不動，就是真如；放縱任性，就是妙用；因此不禮拜聖像，不讀誦真經；毀壞戒律、破除齋法，嗜酒吃肉；誇耀為大道，傳授教化他人；惡業相投的人，大多承襲學習。這是虛妄的臆測，是顛倒輪迴。

【1249-0003】資持記/12a_中四下#35
【原文】豈知達法皆真，何妨泯淨；了真即用，豈礙修行！是故悟理則萬行齊修，涉事則一毫不立。自非通鑒，餘復何言！若下，次明俗眾局化教，初顯略。福道兩經，通目化教；福經如《佛名》、《方等》，道經如諸《般若》等。廣下，指示。凡聖行法，舊云道整禪師撰，未見本文。嘗考諸祖教觀，無非適機。
【譯文】哪裡知道通達諸法皆真，又何妨泯除淨盡；了解真如即是作用，又哪裡妨礙修行！所以悟理則萬行一齊修，涉事則一毫也不立。若不是通達明鑒的人，其餘還有什麼好說！下文「若」字以下是其次說明俗眾限於化教，先是簡略顯示。「福」「道」兩類經，通稱為化教；福經如《佛名經》、《方等經》，道經如諸《般若經》等。下文「廣」字以下是指示。凡聖行法，舊說是道整禪師所撰，未見本文。曾考察諸祖的教觀，無非是適應根機。

【1249-0004】資持記/12a_中四下#36
【原文】若乃決白自心，的指妙境；甄別大小，簡練偏圓；歷位淺深，涉道次序；唯天台《摩訶止觀》，是可投心；但末世弘傳，變成名相，故令晚進取悟無從；必欲深明，當求哲匠。次明制懺，波羅夷法中，前示業報，欲令犯者識過求悔；《觀佛經》中，初示報。一下，列罪。初絕所依。二杜智解。
【譯文】若是審察決擇自心，確切直指玄妙境界；甄別大乘與小乘，簡擇淘鍊偏教與圓教；歷述修行位階的淺深，履歷證道的次第階梯；唯有天台智者大師的《摩訶止觀》，才是可以全心寄託投歸的法門；但末世弘傳之時，演變成了名相口頭之爭，致使後進學人無從獲致體悟；如果一定要深刻明瞭，應當尋求深明教理的明師指引。接著說明制教律懺，在波羅夷（斷頭重罪）法中，前半段揭示其業力果報，旨在令犯戒者認清過非而懇求悔改；《觀佛三昧海經》中，首先揭示惡報。「一下」依次列舉罪狀。第一是斷絕了所依託的歸宿。第二是杜絕了智慧與正解。

【1249-0005】資持記/12a_中四下#37
【原文】三撥正信。四五盜勝境。僧物重於三寶者，僧物有四，今簡常住常住為最重故。信奉者施，故云信施；犯重非僧，食則成盜。六七陵辱尊上；準經污尼語通染淨，若論戒障，必約淨境。六親者，據經但云姊妹親戚；今文易之，使通收故。並下，指廣。請將七過反照身心。
【譯文】第三是撥無正信。第四、第五是盜取殊勝境界。僧物比三寶物更重，因為僧物有四種，現在簡別取出其中最重的常住常住物。由信奉者布施，所以叫「信施」；犯重罪的人已不是僧，吃了就成盜。第六、第七是陵辱尊長；依據經文，「污尼」一語通於染淨，若論戒障，必定是就淨境說。「六親」，依據經文只說姊妹親戚；現在文中改換它，是為了通收一切親屬的緣故。下文「並」字以下是指示廣說。請將這七種過失反照自己的身心。

【1249-0006】資持記/12a_中四下#38
【原文】儻曾有犯，寧不畏乎。《涅槃》文為三，初示罪報。若下，二明犯心，初約護法說破為不破。善業勝故，犯心輕故；此據化教，故言不破；若約制教，還即成破。亦欲進彼護法者故。未捨遠者，謂於佛法猶戀慕故。若犯下，次約壞法說為犯。言多過咎，即說佛法中多過失故。一闡提此云無信。
【譯文】倘若曾經犯過，怎能不畏懼呢。《涅槃經》的文分三段，第一是顯示罪報。下文「若」字以下是第二，說明犯心，先就護持佛法說「破」而判為「不破」。因為善業殊勝，犯心輕微；這是依化教說，所以說不破；若依制教，仍然成為破。也是想鼓勵那些護法的人。「未捨遠」，是說對佛法仍然戀慕。下文「若犯」以下是其次就破壞佛法說為「犯」。說「多過咎」，就是說在佛法中多有過失。「一闡提」，此土譯為「無信」。

【1249-0007】資持記/12a_中四下#39
【原文】云下，三示悔法，初標問。謂下，答釋，初明懺者現報即受。所謂轉重為輕也。橫謂非橫，羅猶墮也。若下，明不懺者生報方受。彼經云：若不觀身無常，名不修身；不觀戒是善梯隥，名不修戒；不觀心躁動制伏，名不修心；不觀智慧有力能斷，名不修慧。
【譯文】下文「云」字以下是第三，顯示懺悔的方法，先標出提問。下文「謂」字以下是回答解釋，先說明懺悔的人現報就受。所謂轉重為輕。「橫」是說非橫，「羅」還是「墮」的意思。下文「若」字以下是說明不懺悔的人生報才受。那部經說：若不觀察身是無常，名叫不修身；不觀察戒是善的階梯，名叫不修戒；不觀察心躁動而加以制伏，名叫不修心；不觀察智慧有力能斷，名叫不修慧。

【1249-0008】資持記/12a_中四下#40
【原文】次明懺法，辨異中，初科引律本文。諸下，示古今兩判，初指古非。古釋都無覆者，謂從犯已後，曾無一念覆心方開，有則不開；又見律中懺法，因犯婬為緣，便謂唯婬開悔，餘重不開，故云互有是非也。今下，申今解，初二句示教意。立教接機，不可抑塞，故云理無滯結也。但下，二顯正解。
【譯文】其次說明懺法，在「辨異」中，第一科引用律的本文。下文「諸」字以下是顯示古今兩種判釋，先是指出古人的錯誤。古人解釋「都無覆」，是說從犯罪以後，從來沒有一念覆藏之心才開許，有覆藏就不開；又看到律中的懺法，是因為犯婬為緣而說，便認為只有婬罪開許懺悔，其餘重罪不開，所以說「互有是非」。下文「今」字以下是申明今解，最初兩句顯示教法的用意。建立教法接引根機，不可壓抑阻塞，所以說「理無滯結」。下文「但」字以下是第二，顯示正確的理解。

【1249-0009】資持記/12a_中四下#41
【原文】謂曾犯多罪，必須盡悔，故云都無覆耳。不下，三簡異僧殘容不盡悔，文又為三，初直示不同。初下，比校兩篇不同所以。凡有三別：一犯重本壞，二悔出自心，三抑令首盡；僧殘反上。言有餘者，反上一也；得強加法，反上二也；隱顯隨懺，反上三也。有下，結示。諸異，即上三義相反。
【譯文】這是說曾經犯了多種罪，必須全部懺悔，所以說「都無覆」。下文「不」字以下是第三，簡別僧殘容許不全部懺悔，文中又分三，先是直接顯示不同。下文「初」字以下是比較兩篇不同的理由。共有三種差別：一是犯重罪根本已壞，二是懺悔出自自心，三是強制令其全部發露；僧殘與此相反。說「有餘」，是反於第一；「得強加法」，是反於第二；「隱顯隨懺」，是反於第三。下文「有」字以下是總結指示。「諸異」就是指上面三種相反之義。
