# 對話材料 #1099

你的格式是對的：

```text
【記文】原文
【記文】白話
【疏文】原文
【疏文】白話
【註文】原文
【註文】白話
```

但目前材料做不到，因為很多 `_終審` 單元只有**疏文的譯文**，記文只放在背景：

```text
【待審譯文】
【疏文】
大宋餘杭郡沙門元照撰述。

【後文背景】
【記】心隨物轉……
【記】若夫翻疇昔之沉迷……
```

那些 `【記】` 是**參考背景，不是已翻譯的白話**。

所以現況是：

- 疏文：有原文、有白話
- 記文：有原文，但常常沒有獨立白話
- 註文／律文：也不一定有完整譯文

不是我不想拆，是資料裡沒有「每個型別各自的白話」。

要做出你要的結構，必須：

1. 每個 `■ 記文（原文）` 都有獨立譯文
2. 每個 `■ 疏文（原文）` 都有獨立譯文
3. 每個 `■ 註文（原文）` 都有獨立譯文
4. 再按「記 → 疏 → 註 → 律 → 序」排成 pair

目前只有部分 `_終修` 回覆有這種完整分段，不是全書。

所以現在不能直接把同一段拆成「原文記／白話記／原文疏／白話疏」；會出現有原文但沒有白話的空 pair。

這才是真正卡住的地方。
