# 校閱材料　第305檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【305-0001】資持記/13b_下一#47
【原文】一者理通，如上所述；二者有據，如除所引。不存舊解，故云定義。《五分》下，證有無通結。《十誦、多論》並同，故云等也。《五分》云：若本無村，結不失衣界竟，村後入者，不須更結，先已結故。〔謂村去後仍前攝衣。
【譯文】第一是法理通達，就如上面所陳述的那樣；第二是有所憑據，就如同下面所引述的那樣。不再存留舊有的見解，所以稱為「定論正義」。從《五分律》以下，證明無論有無村落都能通體結界。《十誦律》、《薩婆多論》的主張也都相同，所以說是「等等」。《五分律》說：如果原本沒有村落，完成結成不失衣界之後，村落後來才遷入的，不需要重新結界，因為先前已經結界過了（意思是村落遷走後依然照舊攝受法衣）。

【305-0002】資持記/13b_下一#48
【原文】若本有村，結衣界已，村移出界，即此空處有不失衣界。是非既顯，猶恐執迷，故云任情量取；量謂評量。薩下，證除緣礙，初引《多論》五義。初云聚落不定，謂遷徙散落，不上一處；衣界定者，謂作法自然，分齊不可亂故。次義如《四分》緣起。三除諍者，或入聚會衣，容生忌故。
【譯文】如果原本有村落，結成衣界之後，村落遷出了界外，那麼這塊空出來的地方就自然具備不失衣界。是非對錯既然已經顯明，卻唯恐人們依舊固執迷惘，所以說「任由心意自行衡量選取」；「量」是指評斷衡量。從「薩」字以下，證明排除障礙緣由的說法，開頭先引述《薩婆多論》的五種意涵。第一種說聚落不固定，是指村落遷徙散落、居無定所；而衣界是固定的，是指作法界與自然界的分界限度不可紊亂之故。第二種意涵就如《四分律》的緣起所述。第三種「消除爭執」，是因為進入村落聚會衣物，容易引發嫌隙嫉妒的緣故。

【305-0003】資持記/13b_下一#49
【原文】四護梵行，等取第五為除嫌疑，此二可解。次引本制緣。律因比丘置衣在村，脫著時形露；以事白佛，因制除村。加結中。除村謂村界分齊，村外界即村外勢分。解法。注中，初引本律，次第解者。疏云：法儀倫式，前後有據，不可亂也。以結時先僧次衣後食，解則反之為次。
【譯文】第四種「護持梵行」，以及第五種「消除嫌疑」，這兩點容易理解。接著引述當初制戒的緣起。律典因為有比丘把衣服放在村落裡，脫換時裸露了形體；便把這件事稟告佛陀，佛陀因而制定了排除村落的規定。在加結的章節中，「除村」是指村落的界限範圍，「村外界」是指村落外圍的十三步勢分地帶。在解界方法中，夾註開頭引述本律，指出應當依照次第來解除界相。律疏說：儀軌法式的先後倫常都是有所憑據的，不可紊亂。因為結界時是先僧界、次衣界、後食界，解界時就剛好反過來作為次序。

【305-0004】資持記/13b_下一#50
【原文】後引《十誦》明隨失者。疏云：衣法假本，本失末亡；而非正則，亂倫獲罪。〔倫即次也，亂次犯吉。〕坐具中。梵云尼師壇，此翻隨坐衣。制意中，初顯意。為身者，恐坐地上有所損故；次為衣者，恐無所籍，三衣易壞故；為臥具者，恐身不淨，污僧床榻故。長下，示量。注中，前示正體。應法謂合字書。
【譯文】後面引述《十誦律》說明隨之失效的狀況。律疏說：攝衣界法假託於本界（大界），本界既然消失了，末端的法界也就隨之亡失；但這並非正規的做法，紊亂了法度的倫次是要獲致罪過的（「倫」就是次序，紊亂次序要結犯突吉羅罪）。在坐具的章節中，梵文稱為「尼師壇」，這裡翻譯為「隨坐衣」。在制戒用意中，開頭先顯明其深意：第一是為了身體，是擔心直接坐在地上會有所損傷之故；第二是為了衣服，是擔心沒有墊借之物，三衣容易磨損破壞之故；第三是為了臥具，是擔心身體不潔淨，會染污僧團的大眾床榻之故。從「長」字以下，指示尺寸規範。夾註中，前面先指明標準的正體字。「應法」是指合乎字書的規範。

【305-0005】資持記/13b_下一#51
【原文】若準《戒疏》，從石為正，即訓張也。足下，點非。佛一搩長二尺，二搩即四尺，廣搩半即三尺，是本制量。更增者，律因迦留陀夷身大，對佛說之，即聽廣長各增半搩。《戒疏》云：更增者，開緣也；還從本制，限外別開。〔謂從本制量限，外增之。
【譯文】如果依照《戒疏》，從「石」字旁的字才是正體，也就是訓讀為「張開」的意思。從「足」字以下，指出錯誤之處。佛陀的一搩手長二尺，兩搩手就是四尺，寬一搩手半就是三尺，這是原本規定的基本尺寸。所謂「更增」，是律典中因為迦留陀夷比丘身體龐大，當面向佛陀陳述，佛陀就聽許長與寬各增加半搩手。《戒疏》說：更增是屬於開許的特殊因緣；依然是依循本來的規定，在基本限度之外另外開許（意思是在本制尺寸限度之外，額外增加）。

【305-0006】資持記/13b_下一#52
【原文】定搩量中，初指諸部不定。具如〈隨相〉無主房中。此但撮略彼文，對之可見。今下，示今所取。周尺一尺二寸，為唐一尺，七寸二分為六寸；所餘八分，為唐七分不啻，故云強也。唐令及五六種尺等，並如〈釋相〉房戒委辨。次科，《十誦、伽論》。新故重數，制同三衣。《僧祇》。厭課謂不已而為。
【譯文】在判定搩手尺寸的章節中，開頭先指明各部派的說法並不一致。詳情就如同在〈隨相〉篇的「無主房戒」中所辨明的那樣。這裡只是摘要撮取彼處的文字，兩相對照即可看明。從「今」字以下，指示現今所採取的標準。周尺的一尺二寸相當於唐尺的一尺，七寸二分相當於唐尺的六寸；所剩餘的八分，相當於唐尺的七分還不止，所以說是「強」。唐代的法令制度以及五六種尺度的分別等等，都如在〈釋相〉篇的房戒中所委細辨明的那樣。下一科中引述《十誦律》、《毘尼母論》，對於布料新舊與重疊層數的要求，制定得與三衣相同。《僧祇律》所說的「厭課」，是指不得不為而勉強為之。

【305-0007】資持記/13b_下一#53
【原文】欽跋羅，毛氈之類，麁厚故不可複。屈頭，謂轉尺頭也。縮量，謂不預桄張也。水洒，意令退縮也。《鼻柰耶》。亂謂參亂，即《四分》云，為壞色故。不揲則已；已，止也，謂揲不揲兩皆得耳。《四分》。疊兩重者，謂得過量者，襵而刺之。注意可見。三中，《十誦》。
【譯文】「欽跋羅」是指毛氈一類的東西，因為粗硬厚重所以不能重疊。「屈頭」是指轉動尺規的起點。「縮量」是指沒有預先拉伸張緊。「灑水」的用意是為了讓布料縮水。《鼻柰耶律》所說的「亂」是指參雜紊亂，也就是《四分律》所說的「為了破壞原本的好色」。如果不加綴補布也可以；「已」是停止的意思，是指加不加綴補布兩者都可以。《四分律》所說的「重疊兩層」，是指得到了超量過長的布料時，折疊起來縫刺固定。夾註的用意自然顯明。第三項中，《十誦律》規定：

【305-0008】資持記/13b_下一#54
【原文】不得單者，本為籍身，制必厚重。離宿吉者，一物常隨，離希非重。《伽論》。非佛制者，謂捨墮中無此戒故。不應但吉，亦不失受。四中，初科三段；《僧祇》明增量，初示增法。二三重者，並隨本物。對頭謂兩緣相鬪。下制限量，止得一尺。
【譯文】坐具不得做成單層，因為原本就是為了墊隔身體，所以規定必須厚重。離宿犯吉羅罪，是因為一件物品常隨在身，離開的情況較為罕見所以罪責不算極重。《毘尼母論》所說的「非佛制」，是指捨墮戒中沒有這條戒律之故。論中所說的「不應」，是指僅犯突吉羅罪（但吉），同時也不會失去受持法。第四項中，第一科包含三段；《僧祇律》說明增加尺寸，開頭先出示增加的法式。所謂兩層或三層，都隨順原本布料的厚薄。所謂「對頭」，是指兩邊的邊緣互相比對拼縫。下文限制尺寸範圍，最多只能增加一尺。
