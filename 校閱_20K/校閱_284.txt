# 校閱材料　第284檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【284-0002】02_戒疏/10c_卷三上之一#75
【原文】【疏】問：「對舉以論，何故彼有此無者？」
【譯文】【疏文】問：「若是對比『宣舉』處分來討論，為什麼彼處的單墮戒有舉法，此處的四條僧殘戒卻沒有舉法？」

【284-0003】02_戒疏/10c_卷三上之一#76
【原文】【疏】答：「『九十』諫竟，便即出舉者，為明能隨舉人有同犯故。若不出舉，無由得結能隨之過。此四諫竟，若有不見，亦合作舉。以隨不見，但得吉故。既不同犯，不勞須出。」
【譯文】【疏文】回答：「九十單提中的規勸完畢後，隨即宣告舉法處分，是為了表明隨順受舉之人也有同犯之罪的緣故。若不宣告舉法，就無從判定隨順者之罪過。而此處這四條戒在勸諫完畢之後，如果犯僧仍不承認自身有罪（不見罪），理應也要對其作不見舉處分。但因為盲從隨順此不見罪者，僅僅只得突吉羅罪。既然隨順者與受舉者並非同犯一罪，律文中就不必多此一舉列出舉法（另制隨舉戒）了。」

【284-0004】02_戒疏/10c_卷三上之一#77
【原文】【記】次舉不舉。問意，可解。答中。初明後戒有舉，以隨舉戒相連次故。次明四諫無舉。論舉有三：一、不見舉，二、不懺舉，隨順此二犯吉；三、惡邪不捨舉，即說欲不障也，隨順犯提。今此四諫，舉唯上二，隨但輕吉。能所各篇，故不同上。
【譯文】【記文】其次是關於有無「舉法」處分的辨析。提問的用意很清楚。回答之中。首先說明後面的單墮戒之所以要有舉法處分，是因為與盲從隨順受舉者的戒條是前後緊密相連的。接著說明四條僧殘戒之後律文之所以未列出舉法（另制隨舉戒）。論及舉法處分共有三種：第一是不見罪舉，第二是不懺悔舉，盲從隨順這兩者的人都犯突吉羅輕罪；第三是堅持惡見不捨舉，即宣稱淫欲不障道這一類，盲從隨順這種舉法的人會犯波逸提罪。如今這四條違諫戒，所能構成的舉法只有前兩種，盲從者只得輕微的突吉羅罪。能隨順者與所隨受舉者的罪名屬於不同篇聚，所以不同於上述單墮戒的情況。

【284-0009】02_戒疏/10c_卷三上之一#82
【原文】【疏】所以不聽破僧者。僧眾和合，義無乖異，理應詳遵，如水乳合。今反倚傍理教，說相似語，惑亂羣心，壞僧斷法，墜陷無辜，為惡滋甚。故須聖制，意在於斯。
【譯文】【疏文】之所以不准許破壞僧團。是因為僧眾理應清淨和睦、和合共處，義理上不容有絲毫乖謬殊異，大眾理當審慎遵奉戒法，就如同水與乳般水乳交融。如今破僧之人反而假借依傍佛法教理，口吐似是而非的言辭，惑亂群眾心志，摧毀僧團制度並斷絕正法傳承，使無辜之人深陷罪網，所造的罪惡極其深重。因此必須由聖人制定戒律，其用意就在於此。

【284-0010】02_戒疏/10c_卷三上之一#83
【原文】【記】第十，制意中，初科。初敘僧義。「詳」謂審其邪正。「遵」謂稟其法制。「今」下，明破義。文敘四過：一、倚教，二、惑眾，三、滅法，四、損他。具上諸惡，故云「滋甚」。「滋」，益也。
【譯文】【記文】在第十項制戒旨趣的第一小段。首先敘述僧團原本的和合義理。「詳」是指詳審辨別法與非法的邪正。「遵」是指恭敬稟承佛陀的制度法規。「今」字以下，指明破僧行為的嚴重性質。文中陳述了四種罪過：第一、依傍偽托教法，第二、惑亂大眾視聽，第三、滅絕正統法脈，第四、陷害牽連他人。具備了上述種種罪惡，所以說是「滋甚」。「滋」是更加、增長的意思。

【284-0011】02_戒疏/10c_卷三上之一#84
【原文】【疏】二、須諫意。然彼邪人，倚傍佛教。乞食等四，生聖之緣，趣道遠因，說緣為種。正語等八，生聖之因，趣道近法，正為聖體。稱法而談，名為正見。邪人反說，顛倒教理，是非兩濫，言同意異，真偽難分。迷情墜惡，實可憐愍。須僧設諫，開示是非。冀彼改迷從正，棄惡就善。是以須諫，意在於此。
【譯文】【疏文】第二、必須設立勸諫的用意。提婆達多那樣的邪人，往往依託附會佛教教義。乞食等四依法，本來只是生起聖道的輔助資緣、是趨向佛道的遠程助緣，他卻將助緣誇大為根本種子。正語等八正道，才是生起聖道的真正內因、是趨向聖道的核心正法，也是聖者人格的實體所在。完全契合正法來談論，才稱為正見。邪見之人卻反其道而說，完全顛倒了佛教的義理，使是非正邪兩相混淆，言詞表面雷同而實質意涵完全相違，真偽極難分辨。無知的僧眾被蒙蔽情志而墮入惡道，實在令人哀憐悲痛。所以必須由僧團出面設立嚴正的勸諫，向其剖析開示是非對錯。無非是希望他能改迷成悟、歸向正道，改惡向善。這就是必須設立三諫程序的深意所在。

【284-0012】02_戒疏/10c_卷三上之一#85
【原文】【記】次科三。初敘法輪。「邪人」下，次明破滅。「顛倒教理」者，《業疏》云「彼以八正為緣，四依為因。五法倣同四依，又並制盡形，出過四正」，故云「是非濫」也。「須」下，正明立諫。「冀」，望也。
【譯文】【記文】第二小段包含三層意思。首先敘述正統法輪的核心。「邪人」以下，進一步說明正法如何遭到破滅。「顛倒教理」這句話，《業疏》解釋說「提婆達多將八正道降為外在助緣，反將四依法提升為成佛正因。他立五種邪法去附會四依法，並且硬性規定必須終身嚴格奉行，自稱這超越了四種正行」，所以說是「是非兩相混淆」。「須」字以下，正式說明建立勸諫制度的用意。「冀」是希望、期盼的意思。

【原文】【註】佛在彌尼樓國，度八釋子。詣瞻波國。並證增上地，唯提婆達得神足證。佛還羅閱祇。提婆教人害佛，事發，惡名流布，利養斷絕，便別眾食。為佛訶責，因即破僧。舉過設諫，而制此戒。

【284-0028】02_戒疏/10c_卷三上之一#101
【原文】【疏】就此戒緣。初明「八釋出家，提婆神足證」者，為取此人為諫事主故。次明「別眾食」緣，分屬「九十」，文相可解。
【譯文】【疏文】針對這條戒的制戒緣起。開頭說明「八位釋迦族王子出家，提婆達多證得神足通」，是為了點出這個人正是本戒中被勸諫的主要當事人。接著說明「別眾食」這段緣由，則屬於「九十單墮」中的別眾食戒，文義線索十分清楚可以理解。

【284-0029】02_戒疏/10c_卷三上之一#102
【原文】【記】別釋中。戒緣二段。初釋出血。但出其意，即注中初至「斷絕」一段文也。「八釋子」皆如來宗族。「提婆」是斛飯王子，佛之堂弟。梵云提婆達多，或云調達，此翻天熱，生時諸天心熱故。餘人皆「證增上地」，即初果也。唯提婆為利養故，詣佛求學神通，佛不為說。復至舍利弗、目連，乃至五百弟子，皆不為說。阿難是親，未得他心，授與通法。提婆入山，學得五通。教闍王殺父，語言：「我作新佛，汝作新王，豈不快耶！」、「佛還羅閱祇」，即王舍城。提婆遣人害佛不遂，乃自推山壓佛，密跡金剛以杵擬之，碎石迸來傷佛足指，是為出佛身血也。「次」下，釋破僧。以「別食」為始。「分屬九十」者，後別眾食，亦由此緣。
【譯文】【記文】具體註釋之中。戒律緣起分為兩大段。前段解釋出佛身血。這裡只點明其意圖，就是注文從開頭到「利養斷絕」這一段文字。「八位釋迦王子」全都是如來的同宗親族。「提婆達多」是斛飯王的兒子，佛陀的堂弟。梵語稱為提婆達多，也有音譯為調達，中文翻譯為「天熱」，因為他出生時諸天天人的心意感到燥熱。其餘諸位王子全都「證得了殊勝地」，也就是初果的聖位。唯獨提婆達多是為了名聞利養，親自去向佛陀請求學習神通法，佛陀不肯傳授。他又轉而懇求舍利弗、目犍連，乃至五百位大弟子，大家全都不肯傳授。阿難尊者因為與他是至親，當時尚未證得他心通，便將修習神通的方法傳授給他。提婆達多入山苦修，修得了五種世俗神通。他教唆阿闍世王子弒父篡位，並對他說：「我來當新佛，你來當新國王，難道不是很痛快嗎！」、「佛還羅閱祇」，羅閱祇就是王舍城。提婆達多派遣刺客謀害佛陀未能得逞，於是親自在山頂推下巨石企圖砸死佛陀，密跡金剛神以金剛杵迎頭痛擊巨石，碎裂的飛石迸濺擊傷了佛陀的腳趾，這就是「出佛身血」。「次」字以下，解釋破壞僧團的始末。是以「別眾食」作為禍端之始。「分屬九十」這句話，是指後面的別眾食戒，也是因提婆達多這段緣起而制定的。

【284-0031】02_戒疏/10c_卷三上之一#104
【原文】【疏】就戒本中，三雙一隻也。謂諫所諫人、諫所諫事，為一雙；二、「彼比丘」下，屏諫、拒屏諫，為第二雙也；三、「彼應三諫」下，僧諫、拒僧諫，為第三雙。末有僧殘，是一隻罪也。一切諫戒，例皆準此。若解分齊，無由混亂。
【譯文】【疏文】在戒本經文之中，結構上包含了「三雙配一單」。也就是被勸諫的對象、勸諫所針對的具體事項，這構成第一雙；第二、從「彼比丘」以下，私下私處規勸、以及抗拒私下規勸，這構成第二雙；第三、從「彼應當三諫」以下，僧團如法公諫、以及抗拒僧團公諫，這構成第三雙。經文末尾結成僧殘罪，這是一單獨的罪名。所有涉及三諫的戒條，通通比照這個結構來理解。如果能徹底釐清這些分際，法理就不可能產生混亂。

【284-0032】02_戒疏/10c_卷三上之一#105
【原文】【記】次釋戒本，總分中。初標，「謂」下，釋。「三雙」者，初是所諫，餘二並能諫，屏諫旁引，僧諫正被。「一隻」即犯科。「一切」下，點示。類通諸諫，不復分也。
【譯文】【記文】接下來解釋戒本經文，在總體劃分之中。開頭先立下標目，「謂」字以下，展開解釋。「三雙」之中，第一組是被勸諫的對象，其餘兩組都是實施勸諫的過程，私下規勸是在一旁引導，僧團勸諫則是正式針對其人實施羯磨。「一單」就是指最後結成的法科罪名。「一切」以下，提綱挈領點明要領。這項規律貫通所有勸諫戒條，後文便不再重複細分了。
