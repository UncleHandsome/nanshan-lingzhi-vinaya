整體看下來，譯文對科判（「然」下、「今」下、「但」下等）的處理清楚，多數句義也掌握得住。以下按「必須改」→「建議斟酌」→「體例與原文疑點」分層列出。

---

## 一、實質錯誤（建議必改）

### 1. 【557-0014】「加妨、難二吉」譯錯 —— 最嚴重
> 譯文：「包含四罪」是指加上了**妨礙僧眾**與有危難這兩個吉羅罪。

「妨、難」是律中的 **「妨處」「難處」**（難處：有虎狼惡獸乃至蟲蟻；妨處：處所迫迮，不通草車迴轉），造房於此二處各結突吉羅。譯者把「妨」誤接成前面五過中的「礙僧事」了。

「四含」＝過量、不處分二**僧殘** ＋ 妨處、難處二**突吉羅**。
建議改：「『四含』是指（過量、不處分二僧殘之外）再加上妨處、難處兩種突吉羅罪。」

### 2. 【557-0003】「制墮」不宜限定為「單墮」
> 譯文：所以只制定為波逸提（**單墮罪**）。

對照【557-0004】記文自列的「畜長、取衣、長藥」等，都屬**捨墮**（尼薩耆波逸提），「別眾、展轉、足食」才是單墮。此處「墮」是與「殘」對舉的通稱，含捨墮、單墮。
建議：「所以只制墮罪（波逸提，通含捨墮與單墮）。」【557-0004】「並見墮中」同樣宜作「都見於捨墮、單墮諸戒中」，前後才一致。

### 3. 【557-0003】「依成上品／便當中下」不是「功德」
> 譯文：遵依奉行就是**上品功德**……便**退居**中品與下品。

記文明說「但由**機劣**，力所不堪」「開對**下機**」，可知上品／中下指的是**根機、行人品位**，非功德；且「退居」暗示原為上品而退墮，原文「便當中下」只是判屬。
建議：「能依教奉行便成上品之機；假使不行，便屬中、下之機。」

### 4. 【557-0001】「雙徵事法」不是「雙重質詢」
「雙」指**事、法二端**同時徵問，不是「兩重／反覆」質詢。
建議：「最初就事相與法度兩方面一併徵問。」

### 5. 【557-0013】兩個「俱有……罪」把罪名譯掉了
> 譯文：只要不向僧團請求審查處分**都有罪**；……只要過量建造就**都有罪**。

原文是「俱有**不乞罪**」「俱有**過量罪**」，重點在「互顯」——各罪名不因另一條件成立與否而免除。
建議：「無論過量或不過量，都同樣有『不乞處分』之罪；無論已處分或未處分，都同樣有『過量』之罪。」

## 二、語意偏差／用詞可議

| 編號 | 譯文 | 問題與建議 |
|---|---|---|
| 0001 | 「反而**自我毀滅正法**」 | 「自我毀滅」是現代固定詞，讀來像自盡。且前二句作「反正行」「反少欲」，此句宜作「反而自壞（自滅）正法」。 |
| 0001 | 「『違慈』就是**障礙梵行**」 | 記文是在**對釋名相**：「自損」＝命難，「違慈」＝梵行難。直譯成「障礙梵行」會丟掉「違慈」二字，建議保留：「『自損』指命難，『違慈』指梵行難（傷生違慈，故成梵行難）。」 |
| 0001 | 「**少欲知足**順應聖教」 | 「知足」為衍增；原文只作「少欲」。 |
| 0001 | 「僧團法事**無法如法**推行」 | 「眾法不行」即僧團（處分）羯磨無法進行，「如法」是添字。 |
| 0001 | 「從『以』字以下，全面總結」 | 本科為三段，此處宜補「**第三**、通結」，與前「初」「二」呼應。 |
| 0002 | 「四依的**苦行**」 | 四依是頭陀上行，佛門忌與外道「苦行」混稱，建議作「四依（四種依止法）」或「四依頭陀行」。 |
| 0003 | 「**如果連**在自己的分位上都不守規矩，**所以才**……」 | 一、「如果…所以才…」句式不順；二、「自分」記文已釋為「開中制法」，宜直譯：「若於自己應守的開中制法不能奉行，便有輕重各別的制罪。」 |
| 0003 | 「較為**疏離的外在因緣**」 | 「疎緣」是與「資身正要」相對的**非切要助緣**，非「疏離」；建議「房舍只是疏緩（非切要）之助緣」。 |
| 0004 | 「開許**蓄存長物衣**、**接受施衣**」 | 「畜長」＝畜長衣（三衣以外的餘衣）；「取衣」在捨墮中指向非親里乞取、過分取衣，譯「接受施衣」偏離。建議「畜長衣、（向人）取衣等」。 |
| 0004 | 「請求**特定**藥品」 | 「特定」為添字，「請藥」即向人請索藥物。 |
| 0006 | 「在**第一部分**中」 | 「初中」承上「次釋名辨離合」，宜明確作「第一、『釋名』當中」。 |
| 0006 | 「其餘**名詞**與上面相同」 | 易誤讀成「用語相同」；應是「其餘（名稱的解釋）同前所說」。 |
| 0007 | 「但比對下面『有主房戒』也標明『為己』」 | 句子缺主語、不順。建議：「但比對下文『有主房戒』，戒本亦說『為己』。」 |
| 0010 | 「羯磨法中兩者的**對白詞句**正好相反」 | 羯磨非「對白」，宜作「羯磨文中所牒稱的用語正好相反」。另「有量無量異」建議加註：前戒（無主房）有定量，後戒（有主房）不限尺寸，否則讀者會與「過量」混淆。 |
| 0011 | 「前一條戒要**稟白**」 | 「牒」是牒舉、稱舉，作「牒稱」較準。 |
| 0014 | 「在**轉接的質難**中」 | 「轉難」＝承前再設難，宜作「進一步的質難中」。 |
| 0014 | 「以**相互彰顯法度**來作答」 | 「互顯」指二罪互相顯示（見0013），非「彰顯法度」。建議「接著就二罪互顯作答」。 |

## 三、體例與一致性

1. **「處分」**：現代漢語「處分」＝懲罰，極易誤解。建議首次出現（0001）加注：「處分：僧眾至現場察看、指授並羯磨認可建房地點」，其後統一作「請求僧團處分」，不必每次寫成「審查處分」。
2. **罪名单元**：文中「吉羅／突吉羅」「殘／僧殘」「墮／波逸提」混用，建議統一（首次出現附全称，如「突吉羅（吉羅、惡作）」）。
3. **「二趣」**：可保留「人、非人二趣」，再補「（即人與鬼神之類）」，比直接譯成「世人與非人鬼神」更貼近原文用語。

## 四、原文疑誤，建議出註而非默默改動

1. 【557-0004】「**食依房藥**」——依上下文當為「衣食房藥」之訛，譯文已逕補為四依，宜加校註。
2. 【557-0004】「**腐樂**中開長藥」——「樂」為「藥」之訛，譯文已改，同樣宜註。
3. 【557-0013】「房雖**一口**」——「口」作房舍量詞罕見，亦可能指「戒文雖只一條（一口）」，與「罪則四含」對舉。譯作「房舍雖然只有一間」是其中一解，建議存疑出註，或譯為「房（戒）雖只一條（一間）」並附說明。
4. 【557-0003】「義不**交**急」——記文已說「交猶至也，《義鈔》作要急，或恐傳誤」，譯文處理正確，可在疏文處加註呼應，讀者才知為何譯作「並非至急」。

## 五、示例修訂（0003 全文）

> 回答：「四依旨在少欲，能依教奉行便成上品之機；假使不行，便屬中、下之機。因此雖立四依而不行，佛陀並不結其犯。四開並非殊勝之行，只是稱合機緣而設；若於自己應守的開中制法不能奉行，便有輕重各別的制罪。只因房舍是疏緩之助緣，義非至急，營造過多便具足前面五種過失，所以制僧殘罪。其餘三依的開許（衣、食、藥），是資身正所須要，事不獲已而必須服用，約情論過較微，所以只制墮罪（波逸提，通含捨墮、單墮）。」
