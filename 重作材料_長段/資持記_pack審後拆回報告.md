# 資持記 pack 審後拆回報告

## 目的

解決 `pack_audit` 整包 FIX 必須整包送修的問題。

做法：審核仍打包，審完立刻依 `[n]` 拆回單段。

## 結果

```text
已審 pack：579
拆回單位：926
PASS：778
FIX：148
整包安全退路：1
```

輸出：

```text
測試/重譯/資持記/_終審_拆回/回覆/<key>_回.txt
```

## 邊界處理

- 單成員包：整份原樣搬，不拆裡面的巢狀 `[n]`
- 只認行首 `[n]`，不抓引文中的方括號數字
- 支援 `[2][3]`、`[2,3]`、`[2-3]`
- 有硬傷未標 `[n]`：該包全部成員保留 FIX
- `_evid.json` 一併複製給 FIX 成員
