# 校閱材料　第605檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【605-0001】資持記/12b_中四下#60
【原文】上二是他緣，遠行即己緣。由此諸緣，雖是五長，即日便還。應還彼者，彼即代受比丘。展轉羯磨，文不具出。今依《刪補羯磨》引之。白云：大德僧聽！某甲比丘故畜〔眾多若干〕長衣犯捨墮，此衣已捨與僧；若僧時到僧忍聽，僧今持是衣與某甲比丘，某甲比丘當還此比丘〔準須提名〕，白如是。羯磨云：大德僧聽！
【譯文】上面兩種是外緣，「遠行」則是自己的緣。由於這些因緣，雖然是五長，當天就可以還。所謂「應還彼」，那個「彼」就是代為接受的比丘。「展轉羯磨」的全文沒有具出，現在依《刪補羯磨》引出。白文說：「大德僧眾請聽！某甲比丘故意畜積〔眾多若干〕長衣，犯了捨墮，這件衣已經捨給僧眾；如果僧眾時機已到、能夠聽許，僧眾現在就把這件衣給某甲比丘，某甲比丘應當把它還給這位比丘〔依準則須唱名〕，就像這樣白告。」羯磨文說：大德僧眾請聽！

【605-0002】資持記/12b_中四下#61
【原文】某甲比丘故畜眾多長衣犯捨墮，此衣已捨與僧，僧今持此衣與某甲比丘，某甲比丘當還此比丘，誰諸長老忍，僧持此衣與某甲比丘，某甲比丘當還此比丘者默然，誰不忍者說；僧已忍，持此衣與某甲比丘，某甲比丘當還某甲比丘竟；僧忍默然故，是事如是持。
【譯文】某甲比丘故意畜積眾多長衣，犯了捨墮，這件衣已經捨給僧眾；僧眾現在拿這件衣給某甲比丘，某甲比丘應當把它還給這位比丘。諸位長老若忍可僧眾拿這件衣給某甲比丘、某甲比丘把它還給這位比丘，就默然不語；誰不忍可，就說出來。僧眾已經忍可：拿這件衣給某甲比丘、某甲比丘把它還給這位比丘，已經作辦完成；因為僧眾忍可默然的緣故，這件事就這樣奉持。

【605-0003】資持記/12b_中四下#62
【原文】律令問彼者，即問懺罪比丘，令誰代受，準須羯磨前問。彼應稱名答僧，與某甲比丘。直還中，初標所被。由前五長不許即還，故開展轉，是則前法唯局五長〔準疏局四〕。此明直還，則通二十七戒。又復五長兼通兩法，二十二戒唯局直還。和下，正作法。雜相中，初科，前示本宗制還。
【譯文】律文要求「詢問那個人」，就是指詢問懺罪的比丘，要由誰代為出面受領，按照規定必須在羯磨之前先行詢問。他應當指稱代受者的名字回答僧眾說：「給與比丘某某。」在直接歸還（直還）的內容中，首先標明所適用的對象。由於前面五長之物不允許當場直接歸還，所以才開許透過輾轉代領的羯磨，因此前面的法則唯獨局限於五長（依照義疏則是局限於四長）。這裡所說的直接歸還，則普遍通達於二十七條戒。此外五長同時兼通直還與輾轉兩種法則，其餘二十二條戒則唯獨局限於直接歸還。從「和」字以下，正式進行作法。在雜碎行相（雜相）的內容中，第一科前面先指明本宗規定必須歸還。

【605-0004】資持記/12b_中四下#63
【原文】若下，明他部多別。前後已出，故但兩指。如前即捨心中。次科，問中。根條互倒，恐謂成法故。答中。例決，律中懺殘；先悔覆藏，後出本罪，法有倫次。倒作違教，準理不成。後問中，或決當時妄行，或遮後世濫用。答中。指前即懺蘭中。上卷亦指〈集僧〉。指餘中。
【譯文】「若」字以下，說明其他部派有許多差別。前後已經說出，所以只作兩處指點。「如前」就是指捨心一科之中。下一科是問答中的問。「根」與「條」互相顛倒，恐怕有人認為這樣也能成辦作法，所以提出。答中是依例決斷：律中懺僧殘，先悔覆藏，後出本罪，作法是有次序的。顛倒而作，違背教法，依理不能成立。後一個問，或者是決斷當時的妄行，或者是遮止後世的濫用。答中，「指前」就是懺偷蘭遮一節之中；上卷也指〈集僧〉一篇。


【605-0005】資持記/12c_中四下#1
【原文】謂蠶綿二寶長藥，並如〈隨相〉明之。眾多人中，初總指三位並同。若下，別示捨罪有異。言六種者，準前偷蘭，不入乞懺；故下別標，用捨隨人，意是不用。餘同上者，準須具列。一請懺主。二問邊人，詞句如文，唯此為別。三說罪相。四正悔罪。五呵責。六立誓。
【譯文】這是指蠶綿、金銀二寶以及蓄存過量藥品等罪，都如同〈隨相釋罪篇〉中所詳細說明的。在對眾多人（別眾）捨法一節中，第一段總體指出面對四位、三位或兩位清淨僧的三種情況作法皆同。「若論」以下，則是分別說明懺除罪相（捨罪）與僧法有所不同。此處所說的「六種法」，是參照前文偷蘭遮罪的規則，不包含乞求懺悔的環節；因此下文特別標明，是否採用乞求程序全憑各人意願，本意其實是不需採用。其餘程序與上文相同的，依照規矩必須全數列出：第一是延請懺悔主；第二是詢問在座旁聽之人，其對白詞句如律文所示，唯獨此項與他法有別；第三是陳說所犯的罪相；第四是正式悔除罪愆；第五是由懺主呵責；第六是立誓不再重犯。

【605-0006】資持記/12c_中四下#2
【原文】〔若入乞懺，則具七法。〕三二人中，初示同。既下，顯別，初明捨衣。言全別者，對前四人，兼僧別故。準《羯磨》云：諸大德聽！我某甲比丘故畜眾多長衣犯捨墮，我今捨與諸大德。次捨罪。須其六法，列次同前。二下，後明還衣。二部即四人與三二人。其三二人法，文中不出。
【譯文】（如果加入乞求懺悔的程序，就具備了七種法。）在面對三人或二人懺悔的部分中，第一段先指明與前文相同之處。「既然……」以下，則是彰顯其相異之點，首先說明捨棄長衣。所謂全是別眾法，是相較於前面面對四人時，因為前面四人法兼具僧法與別法之故。依照《羯磨》的規定，應當說：「各位大德請聽！我某某比丘蓄意蓄存了眾多過量的長衣，犯了捨墮罪，我現在將這些長衣捨給各位大德。」其次是懺除罪過，這必須具備六種法，排列順序與前文相同。從「二部」以下，隨後說明將長衣歸還給犯戒比丘。所謂兩部，就是指四人僧團與三人或二人的不同作法。至於面對三人或二人時的還衣作法，律鈔本文並未載明。

【605-0007】資持記/12c_中四下#3
【原文】《羯磨》令準捨衣法，應云：諸大德！若大德聽我還某甲比丘衣者，我當還之。對首中。捨衣應云：大德一心念！我某甲比丘〔故畜長財或離僧伽梨等〕犯捨墮，今捨與大德。還衣不出詞句，《羯磨》令準捨衣法。應云：長老！我今持是衣還汝。除罪中，無人可問，故但五法。
【譯文】《羯磨》指示應當參照捨衣之法，詞句應當說：「各位大德！如果大德們同意我將長衣還給某某比丘，我就將它歸還。」在單獨對首懺悔的作法中，捨衣時應當說：「大德請一心垂念！我某某比丘（因蓄意蓄存長財或離開大衣過宿等緣故）犯了捨墮罪，現在將此物捨給大德。」還衣的作法則未列出詞句，《羯磨》指示應當參照捨衣的原則，應當說：「長老！我現在拿這件衣服歸還給你。」在除去罪過時，由於現場沒有旁人可以詢問，所以僅採用五種法。

【605-0008】資持記/12c_中四下#4
【原文】一請懺主，二說罪相，三正悔，四訶責，五立誓。五並無異，故令謹依。次懺九十，前緣中，初指法同前。恐下，明今重示。且下，舉事出法。若下，略示從生。九品六品者，示其不定也。如過量等者，別提著用。正懺中，初請主。即初法也。當下，說罪。即第二法。次科初重示次第。恐妄行故。
【譯文】這五種法包括：第一延請懺悔主，第二陳說犯罪之相，第三正式悔罪，第四懺主呵責，第五自己立誓。這五項與前文毫無差異，因此交代必須嚴謹依循。接下來是懺除九十單墮罪，在先前的準備緣起中，第一段指出作法與前文相同。「唯恐……」以下，說明現在重新開示的緣由。「暫且……」以下，是列舉實際事相以展示作法。「若是……」以下，略微說明由根本罪衍生而出的枝條罪。提到九品、六品等罪，是為了說明從生罪的品數並不固定。像超過規定尺寸等情況，則是特別提出涉及穿著受用（著用罪）的情形。在正式懺悔的程序中，第一是延請懺悔主，這也就是第一法。「應當……」以下，是陳說罪相，這也就是第二法。下一個科判的開頭重新提示懺悔的先後順序，是唯恐大家錯誤實行。
