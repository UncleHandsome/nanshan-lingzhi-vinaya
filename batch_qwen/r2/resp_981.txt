整體讀來流暢，科判（「○下」「初五」「二五」等）大致掌握得住，但有幾處**實質誤譯**與**替古人加推測**的問題，以下按輕重分列。

---

## 一、明顯誤譯（建議必改）

**1.【0004】「提下相望」誤認成「提舍尼」**
- 原文：「注餘罪中，且約殘論；**提下相望**，例亦應爾；但至吉羅，則無餘也。」
- 譯文：「這與**提舍尼等罪名**相互參照……」
- 問題：律學慣用縮稱「夷、殘、**提**、尼、吉」，「提」＝波逸提，「提下」＝**波逸提以下（提舍尼、吉羅）**。此段是說「此罪／餘罪」的相對关系：治僧殘則望殘下諸罪，治波逸提則望提下諸罪，到吉羅就無「餘」可望。
- 建議：「（注文說『餘罪』）姑且就僧殘而言；**波逸提以下諸罪彼此對望**，例同此理；只是到了突吉羅，就沒有更下的餘罪了。」

**2.【0001】「別眾不足」漏譯「別眾」**
- 原文：「人謂**別眾不足**。」
- 譯文：「人員是指參與的僧眾不足成事法定的要求。」
- 問題：「別眾」與「不足」是**兩件事**——別眾指僧不和集（應與欲者不與欲、應訶者訶等），不足指人數不滿法定。譯文把兩者併成「人數不足」。
- 建議：「所謂人非，是指**別眾（僧不和集）或人數不足**。」

**3.【0001】「並下」句式誤讀**
- 原文：「**並下**，通結上九。」
- 譯文：「隨後**並列的文句**，通盤總結……」
- 問題：與前句「及下」、後文「於下」「僧下」「倒下」「故下」同例，都是「**某字以下**」的科判語。此處不一致。
- 建議：「『並』字以下，是通結上面九種（非法情形）。」

**4.【0001】「倒說四事」譯成「四種法事」**
- 「四事」不是「法事」。而且【0007】同一語又譯作「四件事」，前後不一。
- 建議：兩處一律保留「四事」，另加註考（律中「倒說四事」多與向白衣說僧「有愛、有恚、有怖、有癡」有關，須核《行事鈔》原文與律文），**不要自行坐實為「法事」**。

**5.【0007】「通於七九」憑空坐實**
- 譯文：「通貫於前述**七種治罰羯磨與後續九種處罰**」——原文無此依據，且與下句「但約對道對俗、有信無信以分異」語脈不合（下句講的是**同一過失因對象不同而罪有差別**）。
- 建議：保留「通於七、九」並標存疑（一說可能指七聚與九十單墮，待查），不要編出「七種羯磨、九種處罰」。

**6.【0007】「不至四」「僧不舉僧」**
- 譯文：「人數不能達到四人……僧團不能舉發**整座僧團**」
- 問題：（a）主語不明，應是**受治罰者**最多三人；（b）「僧不舉僧」是「四人以上即成僧，僧不得對僧作舉治羯磨」，不是「整座僧團」這種全体概念。
- 建議：「（受罰者）不滿四人，是因律制『僧不舉僧』（四人即成僧，不得以僧為舉治對象），恐致破僧、別眾之故。」

**7.【0007】「初指所出」→「過失的源頭」**
- 「所出」是**所應擯出之過**，非「源頭」。建議：「首先指出所擯之過。」

## 二、語意偏差／增譯（宜修）

| 出處 | 譯文 | 問題與建議 |
|---|---|---|
| 0001 | 「這並不合適只作訶責」 | 句法不通；「只」為贅加。改「不適合以訶責羯磨處理」 |
| 0001 | 「挫折剛強難伏的**氣焰**」 | 「剛強」指人；「折辱」的「辱」未譯。改「折伏屈辱剛強難調之人」 |
| 0002 | 「誡令**諦受**」→「懇切接受」 | 諦＝審諦，宜作「認真審諦地領受」 |
| 0003 | 「治者同然」→「也比照這種待遇」 | 太含糊。應作「受治罰者同樣不得列入其數」 |
| 0003 | 「不應**異語**」→「不得異樣言語」 | 異語＝答非所問、支吾搪塞（異語惱他），非「異樣言語」 |
| 0003 | 「制親近」→「制令親近**比丘**」 | 賓語為譯者所加，原文未出，宜留白或標註 |
| 0005 | 「上下互舉」→「上下語句相互指陳」 | 應點明**互文見義**：四舉嫌、五舉訶，各舉一邊互相補足 |
| 0005 | 「證他是非」→「為他人的**非違諍論**作證」 | 宜作「為他人的是非（諍事）作證」 |
| 0005 | 「下二犯事」→「違犯**威儀**行事」 | 「威儀」為增譯，宜作「後二屬違犯『事』（行事）」 |
| 0005 | 「四約訶法」→「訶斥**法度**」 | 易讀成「批評佛法制度」。宜作「就所訶之『法』說／就所訶之『人』說」 |
| 0005 | 「比丘知他有犯，**應當**對僧舉告」 | 原文是敘述遮法作法，非制令，「應當」可刪 |
| 0006 | 「準僧殘者，即行別住也」 | 宜作「比照僧殘罪人**行別住者的坐次**」，語意才落實到「坐處」 |
| 0008 | 「隨戒」→「隨從的戒條」 | 生硬。宜作「所涉的別戒（戒本隨行戒相）」 |
| 0004 | 「兩相」→「兩種**行相**」 | 「行相」是唯識術語，此處只是「兩種情形」 |

**特別提醒【0006】的括號**：
> 「（抄寫者因見前後羯磨都列出二人，遂誤抄為二）」

原文只說「傳寫之誤；前後羯磨，並牒二人故」——這句是元照**給出的理據**，譯文卻改寫成「抄誤的成因」，方向可疑，且替古人補了心理過程。建議直譯：「……是傳抄之誤；因前後羯磨文都牒舉二人之故。」不加括號推測。

## 三、體例一致性

1. **「○下」譯法要統一**：目前「及下／於下／僧下／倒下」都作「某字以下」，唯「並下」「指如上者」走樣。
2. **「隔空遙相施罰」**：「隔空」太現代口語，宜作「當事人不現前而遙作法加之」。
3. **增譯宜標記**：如「受罰後禁止」「全面禁絕」「很不方便」等，都是原文沒有的限定或語氣詞；解釋性補充建議一律用括號或註腳，與正文區隔。
4. 【0002】「四五事同，受往分異」可補一句「（同指教誡比丘尼事），只分『受差』與『前往』」，讀者才接得上後面「既不聽受，何有差者」。

## 四、待考項（建議查證後再定稿）

- **「四事」確指**（0001、0007）
- **「七九」確指**（0007）
- **「治法中，前總指四種」的「四種」**（0008）——目前譯文只寫「四種」，賓語懸空，讀者無從理解，宜查明是四種治法或四種過。

這三處若能對照《行事鈔·僧網大綱篇》原文與《四分律》相關羯磨文，譯文的可靠度會明顯提升。
