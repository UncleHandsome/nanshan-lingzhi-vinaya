# 校閱材料　第366檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【366-0002】02_戒疏/02d_卷一上之二#108
【原文】【疏】文云「尼眾遣何人來」者，此問尼也。或云「尼遣何人傳信從僧乞教授」者，即謂所告比丘也。以言中不了，故光師製戒序云：「誰遣尼來請邪？」此謂比丘受信者。得意忘言，任通無在。但知行德兼備，不可妄傳，故須待請，方往教授也。
【譯文】【疏文】經文中說「尼眾遣何人來」，這是詢問前來的使者尼僧是誰。或者是說「比丘尼派遣了什麼人傳遞信函前來向大僧祈請教授教誡」，那就是指接受請託告白的大僧比丘。因為經文言辭不夠明確，所以光律師在編製戒本序時寫道：「是誰派遣尼僧前來求請教誡呢？」這是指受尼僧委託的比丘。只要領會其精神意旨而忘卻文字表相，不論採用哪種解釋都各通其理、全無妨礙。但必須知道擔任教誡之人必須道行與功德兼備，絕不可隨意委託傳授，所以必須等待比丘尼前來懇請，然後才前往教授。

【366-0003】02_戒疏/02d_卷一上之二#109
【原文】【記】次科，文列三出。初云「此問尼」者，點「何人」字，指使尼也。次釋「何人是所告」者，即尼遣僧，事儀不便。後約「受信」，釋上「誰」字，即僧遣尼，語意無失。謂受囑者令尼來問可否，即為「遣」也，《刪定戒》中亦同此示。「得」下，遣執。「但」下，示意。「行德」即所請人，須具十德，如《鈔》具引。
【譯文】【記文】在下一小節中，文理列出了三種不同的見解。疏文開頭說的「這是問尼僧」，是扣緊「何人」二字，指代所差遣的使者尼僧。第二種解釋認為「何人是指接受告白的比丘」，但這便成了尼僧指使大僧，事相軌儀上極不合宜。最後一種依據「接受囑託」，來解釋上面的「誰」字，這就是指大僧派遣尼僧前來，在文言語意上就毫無缺失了。也就是接受尼僧囑託的比丘，吩咐尼僧前來探問是否可派人教誡，這就算是「遣」，在《刪定戒本》中也是如此指示的。「得」字以下，排遣名相偏執。「但」字以下，闡明立意要旨。「行德」指受請去教誡的人，必須具備十種德行，正如《事鈔》中所詳細引證的那樣。

【366-0015】02_戒疏/02d_卷一上之二#121
【原文】【疏】有云或答「布薩說戒」者。「布薩」西音，「說戒」東語。乃知「布薩」名含，不妨「淨住」義攝。二名體一，不可重言。欲顯「羯磨」名通，「說戒」事別，故陳此二，則表眾義盡。
【譯文】【疏文】有人說也可以回答為「布薩說戒」。「布薩」是西域印度的梵音，「說戒」是東土震旦的漢語。由此可知「布薩」這個詞涵義廣博，不妨以「清淨安住」之義來統攝。這兩個名稱的體質實為一體，不可在文字上重疊贅述。為了要顯發「羯磨」是通稱一切僧事，「說戒」是今天這件特殊個別的事相，所以陳述這兩個名詞，便能將僧眾集會的完整義理表述無遺。

【366-0016】02_戒疏/02d_卷一上之二#122
【原文】【記】指異中。初標異，即古戒本。「布薩」下，示二名。「東西」二音，非正翻度。「乃知」等者，出不標梵言之意。「含」謂通含，不專一相，故《鈔》中或翻「長養」，或云「斷增長」等，懺罪、八戒，皆號「布薩」。《三千威儀》，翻為「淨住」，「淨」身口意，「住」於戒故。雖具多翻，不出此義，故云「攝」也。「二名」下，指前非。「欲」下，明今意。「表眾」者，即《律》文中「二種攝僧」，統收眾行，故云「盡」也。
【譯文】【記文】在指出異解的文字中。先提出不同的見解，就是指古舊的戒本。「布薩」以下，展示這兩個名稱的關係。「東與西」這兩種語言，並非單純的字面翻譯對轉。「乃知」等文字，是點出本律戒本不單獨標立梵語的用意。「含」是指涵括多義，並非專指一種相貌，所以《事鈔》中有的地方翻譯為「長養」，有的地方說是「斷惡增長善法」等，舉凡懺罪、八關齋戒，都可以稱為「布薩」。《三千威儀經》則將它翻譯為「淨住」，也就是「清淨」身口意三業、「安住」在淨戒之中的意思。雖然有著多種翻譯，但終究離不開這個內涵，所以說「攝」。「二名」以下，指責前人重疊贅述之非。「欲」字以下，顯發當前疏文的用意。「表眾」是指《四分律》原文中所說的「兩種攝受僧眾的方法」（以說戒羯磨攝僧），總體收攝了僧眾的一切行持，所以說「盡」。

【366-0017】02_戒疏/02d_卷一上之二#123
【原文】【註】佛言：「若說戒日，不得在房。」
【譯文】【註文】佛陀宣示：「在說戒之日，不得私自留在僧房之中。」
