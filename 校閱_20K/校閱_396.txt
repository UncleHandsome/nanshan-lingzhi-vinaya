# 校閱材料　第396檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【396-0003】02_戒疏/20a_卷四下之二#3
【原文】【疏】凡如法事，理宜同遵，許無乖競。今停僧作法，輒便捨者，心不和同，障礙僧事，惱眾不輕，故制。
【譯文】【疏文】大凡符合戒律的僧團事務，按理應當共同遵從，以期沒有違逆與抗爭。現在若暫停僧團行作羯磨，隨意擅自捨離離去，便是內心不和合協同，障礙了僧團事務，擾惱大眾的情節非輕，因此制定此戒。

【396-0004】02_戒疏/20a_卷四下之二#4
【原文】【記】七十五，制意。初敘僧法。「今」下，明起過。「停」，止也。
【譯文】【記文】第七十五條，制戒意圖。首先敘述僧團如法之事的常理。「現在」以下，說明過失的生起。「停」，是止息暫停的意思。

【396-0005】02_戒疏/20a_卷四下之二#5
【原文】【疏】論犯五緣：一、是如法僧事；二、知如法；三、不與欲；四、輒起去；五、雙足出門犯。
【譯文】【疏文】論及其犯戒的五個條件（五緣）：第一、是合乎戒律的僧團事務；第二、明知是合法的；第三、沒有給予同意權（不與欲）；第四、擅自起身離去；第五、雙腳跨出門檻即構成犯戒。

【396-0006】02_戒疏/20a_卷四下之二#6
【原文】【記】犯緣。第一，「如法」，簡非法無犯，準下又局斷諍，簡餘法但輕。
【譯文】【記文】犯戒條件（犯緣）。第一點，「合乎戒律」，是為了排除非法的羯磨則不犯戒；依據後文來看，此戒又特別局限於裁斷諍事的羯磨，排除其餘的僧事，若擅離則僅犯輕微過失。

【396-0007】02_戒疏/20a_卷四下之二#7
【原文】【註】佛在舍衛。多比丘集，論法毗尼。六群相謂「看諸比丘，似為我等作羯磨」，從座起去。比丘喚住而故去。以事白佛，便訶而制戒。
【譯文】【註文】佛陀住在舍衛國。許多比丘聚集，討論佛法與毗尼。六群比丘彼此私語說：「看那些比丘的樣子，好像要為我們作處分的羯磨」，便從座位起身離去。其他比丘出聲呼喚挽留，他們仍故意離去。比丘們將此事稟告佛陀，佛陀便喝責他們並制定此戒。

【396-0008】02_戒疏/20a_卷四下之二#8
【原文】【律】若比丘，眾僧斷事未竟，不與欲而起去，波逸提。
【譯文】【律文】若有比丘，在僧團裁斷爭議尚未結束時，不給予同意權便起座離去，犯波逸提罪。

【396-0009】02_戒疏/20a_卷四下之二#9
【原文】【註】若斷事未竟，動足出戶外者，犯墮。一足在戶內，方便欲去而不去，吉羅。尼波逸提。不犯者，若與欲，若口噤。若非法羯磨，若為僧、塔、寺、和尚、闍棃、同學作損減，不與欲而去者，得。
【譯文】【註文】如果裁斷諍事尚未結束，動步邁出門戶之外者，犯墮罪（波逸提）。一隻腳在門戶之內，起意想要離去卻未真正離去，犯突吉羅罪。比丘尼亦犯波逸提。不犯戒的情況：如果已經給予同意權，或者因病口不能言（口噤）；如果是違法的羯磨；若是為了避免僧團、佛塔、寺院、和尚、阿闍梨、同學遭受損害，不給予同意權而離去者，是可以開許的。

【396-0010】02_戒疏/20a_卷四下之二#10
【原文】【疏】此唯斷四諍事，不與欲者提。餘者吉羅。如《戒本》、《鈔》說。
【譯文】【疏文】這裏唯獨局限於裁斷四種諍事的場合，不給予同意權而離去者才結波逸提罪。其餘的僧務羯磨則僅結突吉羅罪。詳如《戒本》與《事鈔》中所說。

【396-0011】02_戒疏/20a_卷四下之二#11
【原文】【記】簡判中。初正簡。「如」下，示略。戒緣，注中，「論法毗尼」，即斷諍事。「六群相謂」者，由多犯過，故自生疑，因茲起過。戒本六句，三、「斷事」中，注云「十八法」，且舉言諍，餘三例爾。四、「不與欲」，注中略出開與欲緣，準《鈔》具開六緣，三寶、有病、看病、作衣並開與欲。後注辨相中，「出戶外」者，據有堂宇為言，義詳必無門戶，須離見聞。「不犯」中，「噤」字因禁反，口閉也。
【譯文】【記文】甄別判定之中。首先正面甄別。「如」以下，指示此處從略。制戒的緣起，注文中「討論佛法與毗尼」，指的就是裁斷諍事。「六群比丘彼此私語」這段，是因為他們經常犯過，所以自己心中生起猜疑，並因此產生過失。戒本有六個語句，第三句「斷事」中，注文提到「十八種法」，這只是暫且列舉言論之諍，其餘三種諍事依此類推。第四句「不與欲」，注文中略微列舉了開許給予同意權的事緣，依據《事鈔》則具體開許有六種事緣：為三寶事、自身有病、探視照料病人、縫製僧衣，皆開許給予同意權。後文注文辨明戒相之中，「邁出門戶之外」，是依據有房舍殿宇的場合來說，按義理詳審，若在沒有門戶的空曠處，則必須脫離見聞之處才算。「不犯」條文中，「噤」字讀因禁切，也就是嘴閉不能言語的意思。

【譯文】【律文】第七十六條、給予同意權後又反悔戒。

【396-0013】02_戒疏/20a_卷四下之二#13
【原文】【疏】與欲後悔戒七十六。
【譯文】【疏文】給予同意權後又反悔戒，為第七十六條。

【396-0014】02_戒疏/20a_卷四下之二#14
【原文】【疏】凡如法僧事，理須順可。先已與欲，見治已伴，偏情相親，輒便後悔，反說不成，相朋毀法，惱眾是重，故制。
【譯文】【疏文】大凡合法的僧團事務，按理應當順從認可。先前已經給予了同意權，後來看見受處分的是自己的同伴，因私情偏袒親近，便隨意反悔，反過來說羯磨不成立；相互結黨朋比以毀壞僧法，嚴重擾惱僧眾，因此制定此戒。

【396-0015】02_戒疏/20a_卷四下之二#15
【原文】【記】七十六，制意中。初敘欲法。「順可」即與欲也。「先已」下，次明後悔。
【譯文】【記文】第七十六條，制戒意圖之中。首先敘述同意權之法。「順從認可」就是給予同意權。「先前已經」以下，接著說明反悔的情形。

【譯文】【疏文】論及其犯戒的四個條件（四緣）：第一、是合法的羯磨；第二、如法給予同意權；第三、隨意反悔推翻；第四、言語表達完畢便構成罪名。

【396-0020】02_戒疏/20a_卷四下之二#20
【原文】【註】佛在舍衛。六群恐舉，六人相隨，無由得作。後時作衣，僧喚受欲，即與比丘作舉羯磨。後六群言：「我以彼事與欲。」比丘舉過，佛因訶責制戒。
【譯文】【註文】佛陀住在舍衛國。六群比丘害怕被僧團舉發處分，六人總是同行相隨，使僧團無法集眾作成處分。後來遇上縫製僧衣的時節，僧團呼喚他們交付同意權，僧眾隨即為其中一位比丘作舉發處分的羯磨。事後六群比丘說：「我是為了做衣服那件事給予同意權的。」比丘們舉發其過失，佛陀因此喝責並制定此戒。

【396-0021】02_戒疏/20a_卷四下之二#21
【原文】【記】戒緣。「六群相隨」，以成僧故，人不敢舉。六群與欲，僧舉同伴，故悔前欲。
【譯文】【記文】制戒緣起。「六人相隨」，是因為他們自成一股僧數，別人不敢對他們舉過。六群比丘交出了同意權，僧團便藉此舉發其同伴，他們因而反悔先前的同意。

【396-0022】02_戒疏/20a_卷四下之二#22
【原文】【律】若比丘，與欲已，後悔者。
【譯文】【律文】若有比丘，給予同意權之後，又反悔者。

【396-0032】02_戒疏/20a_卷四下之二#32
【原文】【疏】論犯五緣：一、是先起四諍，《十誦》「一切諍」，《多》云「往聽者，以能破佛法，令僧為二部，是故重也」；二、他人屏處評量；三、作鬬亂意，為和自改，不用此律；四、往聽不令覺知；五、聞語便犯。
【譯文】【疏文】論及其犯戒的五個條件（五緣）：第一、是先前已經生起四種諍事，《十誦律》說是「一切諍事」，《薩婆多論》說「前去偷聽的人，因為能破壞佛法，使僧團分裂為兩部，所以罪過嚴重」；第二、他人在隱蔽處評議度量；第三、存有挑撥爭鬥擾亂的心意，若是為了促成和解或自己反省改過，則不適用此戒條；第四、前往偷聽而不讓人察覺知曉；第五、一聽到話語便構成犯戒。

【396-0033】02_戒疏/20a_卷四下之二#33
【原文】【記】犯緣。第一，《十誦》「一切諍」，即四諍。《多論》顯過，通壞三寶故。三中，「為和自改」，即非鬪亂，開聽無犯，故云「不用此律」。
【譯文】【記文】犯戒條件（犯緣）。第一點，《十誦律》所說的「一切諍事」，指的就是四諍。《薩婆多論》闡明其過失，是因為這會全面損壞三寶的緣故。第三點中，「促成和解或自己改過」，就不是出於鬥亂之意，開許去聽而不犯戒，所以說「不適用此戒條」。
