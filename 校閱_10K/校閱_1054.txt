# 校閱材料　第1054檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1054-0001】資持記/05e_上四#18
【原文】今時行事，五德歸位已，呪願迴向，然後梵唄說自慶偈，三歸禮散。〔多見不說偈者，非也。〕舉罪中，依篇治者，約心違順，通收懺罰。初科分二，初明五德眾僧舉。必無私曲，依法加治，不假窮勘。若下，二明別人舉。恐懷損減，須究虛實。初明事根俱實。依遮法者，作舉憶念。
【譯文】現今行事時，五德回到座位後，祝願迴向，然後梵唄唱誦自慶偈，三皈依禮拜後散會。〔常見有人不唱誦偈頌，那是錯誤的。〕在舉罪的段落中，依照各篇戒相來懲治，是考量當事人內心是順從還是違抗，全面涵括懺悔與處罰。第一科分為兩部分，首先說明由五德與大眾僧檢舉。兩者必定沒有私心偏袒，所以依律施加懲治，不需要藉助窮究勘問。「若」字以下，第二說明由個別僧人檢舉。擔心檢舉者懷有毀損排擠之意，必須追究虛實。先說明事實與舉罪之根皆屬真實的情況。依照遮止過非之法，作舉罪憶念羯磨。

【1054-0002】資持記/05e_上四#19
【原文】若下，明事實根謬。反治者，降等治之。注指前篇，尋之可見。反治中，初簡五德不治。有二義故，一是眾差，二謂具德。言推繩者，覈實加刑也。不同下，次明別人須治。反前二義，在文顯然。僧具缺中，初舉極位僧，辦法備故。若下，明次位僧被事不足故。指後法者，令發露也。
【譯文】「若」字以下，說明事實存在但舉罪之根錯誤的情況。所謂反治，是降一等來懲罰檢舉者。注文指引參見前一篇，查閱即可明瞭。在反治的段落中，首先簡別五德不予懲治。有兩個理由，一是大眾差派的，二是本身具足德行。所謂「推繩」，是指核實罪狀並施加刑罰處分。在「不同」以下，接著說明個別僧人必須受處治。因為與前面兩個理由相反，這在經文中很明顯。在僧眾人數具足與殘缺的段落中，首先舉出極致僧位的人數，因為辦事條件完備之故。「若」字以下，說明次一階位的僧眾人數因所對治之事而有所不足。指稱後面的法度，是指令其發露懺悔。

【1054-0003】資持記/05e_上四#20
【原文】尼來請說，初無尼中。以說戒時，尼請教誡身不現前，有無俱問；自恣不爾，縱有不問。白日法中，初科為三，初安尼立處。眾下，止僧自恣。當下，命尼陳說。指別法者，下具云：比丘尼僧，夏安居竟；比丘僧，夏安居竟；比丘尼僧，說三事自恣見聞疑；大德！
【譯文】比丘尼前來請求自恣說法的段落中，最初無尼的科判。是因為半月說戒時，比丘尼請求教授教誡，人不須現前，有沒有尼僧都要詢問；自恣法則不然，縱然有尼僧也不主動詢問。在白天作法的段落中，第一科分為三部分，首先安排比丘尼站立的處所。「眾」字以下，中止僧團的自恣儀軌。「當」字以下，命令比丘尼陳說。指稱個別法度之處，下文完整說明為：比丘尼僧眾夏安居已結束；比丘僧眾夏安居已結束；比丘尼僧眾以見、聞、疑三事自恣；大德！

【1054-0004】資持記/05e_上四#21
【原文】慈愍故語我，我若見罪，當如法懺悔。〔三說。〕次科。上告下名勅，古語通用，今唯王者所稱。餘下，指後；彼云：尼於自恣時，傳僧所告；諸尼頂戴訖，然後自恣等。隔日法中。以夜中作法，尼來不及，故制重集。唯此為異，餘竝同前。問中。以欲應羯磨；
【譯文】慈悲憐愍我並對我說明，我若發現罪過，當會如法懺悔。〔說三遍。〕下一科。上位告誡下位稱為「勅」，在古代這是通用的詞語，當今則專指皇帝君王的詔令。「餘」字以下，指引後文；後文記載：比丘尼在自恣之時，傳達僧團的告白；諸比丘尼頂戴完畢，然後才各自進行自恣等事。在隔日作法的段落中。因為夜間作法，比丘尼趕不上時間，所以制定隔日重新集會。只有這一點不同，其餘全都同前。在提問中。本來應當以欲法來配合羯磨；

【1054-0005】資持記/05e_上四#22
【原文】今既不作，而制傳欲，故須問釋。答中，初申理。尼八敬中，依僧自恣；眾不和集，非依僧故。故律下，引證，初引開略文。處下，反彰廣法。《僧祇》下，準例，初舉文。彼明尼請教誡，還寺傳告；亦制尼僧盡集，不來說欲。由下，合例。尼來中。
【譯文】現在既然不做羯磨，卻又規定傳欲，所以必須發問解釋。回答中，首先申述法理。比丘尼八敬法中，必須依傍比丘僧舉行自恣；僧眾未和合集會，就稱不上是依傍比丘僧。所以律典以下，引用經文證實，首先引用開許簡略的律文。「處」字以下，反顯完整廣大之法。《僧祇律》以下，比照通例，先舉出律文。該文說明比丘尼請求教授教誡後，回到尼寺傳達告知；也規定比丘尼僧眾必須全部集會，不來者則須說欲。在「由」字以下，合於通例。比丘尼前來的段落中。

【1054-0006】資持記/05e_上四#23
【原文】言犯重者，僧殘戒分，望下為言。身既有過，不堪自恣也。今時尼法，節制不行；幸而聞之，無復見矣。略說中。標云雜行者，緣法二種，各有多別故。指緣中。令量時者，事在五德；眾法選舉，非庸昧所堪，可不慎乎！五德對略中，初文為二，初標略緣。時所有者，略舉四種。當下，示略法，初明先廣。
【譯文】說到「犯重罪」，是指僧殘戒的分限，是相對於下位過失而言的。自身既然有了嚴重過失，就不堪承受自恣法。當今的比丘尼法，節制規範早已廢弛不行；萬幸能聽聞此法，現實中卻再也見不到了。在略說自恣的段落中。科判標明「雜行」，是因為因緣與儀軌這兩種，各自有許多區別的緣故。在指明因緣的段落中。命令審量時間，責任在於五德；僧團的選舉任命，絕不是庸庸碌碌之輩所能勝任，怎能不謹慎呢！五德相對簡略法中，第一段文字分為兩部分，首先標明簡略的因緣。當時所具有的緣由，大略列舉出四種。「當」字以下，指示簡略之法，首先說明應先採廣法。

【1054-0007】資持記/05e_上四#24
【原文】已下，明次略。文略再說，疏云：對五德有二略，二說、一說也。〔人云無再說，非。〕受兩人者，縱受三人，理亦無損，但不得至四耳。斥非中，初示非。雙頭者，二五德齊跪。一時者，兩座同說也。律下，引證，初引本律。因非特制。次引《十誦》，上句示法。
【譯文】「已」字以下，說明接著轉為略法。鈔文中略去了說兩遍之法（再說），戒疏說：對著五德有兩種略法，即說兩遍或說一遍。〔有人說沒有說兩遍之法，是錯誤的。〕每次承受兩人，縱然承受三人，在理上也不會有損害，只是不得多達四人而已。在斥責非法的段落中，首先指出錯誤之相。所謂「雙頭」，是指兩位五德一同下跪。所謂「一時」，是指兩個席位同時說話。律文以下，引用證據，首先引用本律。是因有非法之舉而特別制定的。接著引用《十誦律》，上一句說明正法。

【1054-0008】資持記/05e_上四#25
【原文】不下，遮非有四。逆作者，從下至上也。行行者，分頭各取也。超越者，間隔坐次也。總唱者，合眾同聲也。僧對略中，初標難緣。五下，五德白告。便下，眾僧對說。疏云：不對五德有三略，如百人為五十對，一時彼此三說再說一說也。三說，望法是廣，對人為略。下二人法俱略；
【譯文】「不」字以下，遮止四種非法行徑。所謂「逆作」，是從下座開始往上座行事。所謂「行行」，是分頭各自選取。所謂「超越」，是跳躍間隔座次。所謂「總唱」，是全體僧眾齊聲高呼。在僧眾相對略說法中，首先標明遭難的因緣。「五」字以下，五德唱白宣告。「便」字以下，大眾僧相對陳說。戒疏說：不對五德進行自恣有三種略法，好比百人分成五十對，同時彼此各說三遍、說兩遍或說一遍。說三遍，相對於法而言是完整，相對於人而言則是簡略。後面兩種略法（再說與一說），在人員與儀軌上都是簡略的；

【1054-0009】資持記/05e_上四#26
【原文】單白中，唯改再一為異。明作白中，初明須白。不下，簡前不須。直去中，初句總舉。五種如上，下別示第六。〔廣略合論去為七法。〕直爾去者，由難卒至，不容對說，此據五德和白已後；未白難來，待靜自恣，即《五百問》通一月也。〔舊云落增減者，非也。彼為外界諍緣，非八難故。
【譯文】在單白羯磨中，只更改「兩遍」或「一遍」這點差異。在說明作白的段落中，首先說明必須作白。「不」字以下，簡別前面情況不需要作白。在逕行離去的段落中，第一句總結提出。五種簡略之法如同上面所說，下面另外指出第六種。〔廣法與略法合起來討論，逕行離去便屬於第七法。〕所謂直接離去，是因為災難突然降臨，不容許互相對面陳說，這是在五德和白之後；若在尚未和白前災難就來了，應等待安靜平息再自恣，這在《五百問》中通融開許延期一個月。〔舊說認為這屬於增減自恣的範疇，是錯誤的。那是因為界外諍論之緣，而不是由於八難。
