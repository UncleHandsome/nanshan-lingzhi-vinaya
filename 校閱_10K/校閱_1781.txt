# 校閱材料　第1781檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？

# 材料開始

【1781-0001】03_業疏/15a_卷三之四#96
【原文】初師示體中，初準論立義，即本《成論》。色心即總三業，拜跪登降是身，陳乞對答是口，此二並色。色不自發，要由心助，故兩兼之。「非直音聲」，直猶獨也。「論」下釋成。身口非記，實不能造，假之成業，故云造具，如世器具要假人用。如下舉例。律殺戒中，心境迷忘，一切無心，竝開不犯。故下引證，「皆但是心」謂心王也。心王起意思，意思起身口，若離心王，三業無託，故三竝無也
【譯文】在第一位法師標示戒體中，首先依準論典確立教義，所依的就是本宗《成實論》。色與心即是總括了身、口、意三業，禮拜跪拜升降壇場是身業，陳白乞戒對答問難是口業，這兩者都屬於色法。色法不能自行發動，必須由心識力量予以助發，所以二者兼取。「非直音聲」的「直」，如同「獨」字。「論」字以下，解釋成立其理。身業與口業本身並非善惡有記之法，實在不能自主造業，只是借假它們來成就業行，所以稱為「造具」，就像世間的器具必須假借人力使用一樣。如下文所舉的例子。律典殺戒之中，若對境心識迷亂忘失，全無殺害之心，一律開許判定為不犯戒。所以下文引論作證，「皆但是心」指的是心王。心王發起思心所，思心所驅動身業與口業，如果離開了心王，三業就無所寄託，所以身口意三業就全都無從生起了。

【1781-0002】03_業疏/15a_卷三之四#97
【原文】若解色為業體，十四種色悉是無記，非罪福性，何得名業
【譯文】如果解釋為單純以色法作為業體，那麼十四種色法全都是無記性，不是構成罪業或福德的體性，又怎麼能稱之為業呢？

【1781-0003】03_業疏/15a_卷三之四#98
【原文】次科，多宗所明身口二業悉判為色，故此攻之。五根、五塵、四大為十四色。業取有記，無記非業，罪福即是善惡
【譯文】下一段科文中，有宗所闡明的身業與口業全都判定為色法，所以這裡予以駁斥。五根、五塵與四大合稱為十四種色法。業必定要取具有善惡有記性質之法，無記之法不能構成業，所謂「罪福」也就是惡與善。

【1781-0004】03_業疏/15a_卷三之四#99
【原文】有人言：以色聲為身口業體。故論云：身口業依止四大，意業依心。若身業非四大為性者，意業依心亦不應以心為體。故知身業以四大動故，名動為業，業即四大，更無別體。若論口業，四大相擊，於中出聲，聲成音曲，有所表彰以為名字句，還即此名句為口作業，業無別體，用聲作體
【譯文】有人說：是以顯色形色與聲音作為身業與口業的戒體。所以論典說：身業與口業依止四大而生，意業依止心而生。如果身業不是以四大為自性，那麼意業依止於心也就不應當以心為體了。因此可知，身業是由於四大的運動，將這種運動稱為業，業就是四大本身，此外再無別的自體。如果談到口業，四大相互擊觸，在其中發出聲音，聲音連綴成曲調音韻，有所表白宣示而成為名身、句身、文身，就直接以這名句作為口作之業，業沒有別的自體，就是用聲音作為體。

【1781-0005】03_業疏/15a_卷三之四#100
【原文】次師初科初立義。此師但取前色離為色聲，不談心造，頗符小教。故下準論反質。彼分三業所依各異，身口既依四大，故不應以心為體。故下正出體相。初明身業，四大是色，色動為業，動無別體，即色是體。若下次明口業，聲非報法，由擊而發，音曲是業，音曲無體，即聲為體
【譯文】在第二位法師的第一科中，首先確立義理。這位法師只取前面所說的色法，將其析為色與聲，不談由心念所造，相當符合小乘教義。所以下文依準論典進行反問質問。該論分別三業所依止的各不相同，身業口業既然依止四大，所以就不應當以心為體。所以下文正式標出戒體的相貌。首先說明身業，四大屬於色法，色法的運動稱為業，運動沒有別的自體，就是以色法為自體。自「若」字以下，其次說明口業，聲音並非受生的異熟果報法，是由四大互相擊觸而發出，所形成的音聲曲調就是業，音韻曲調沒有獨立的自體，就是以聲音為體。

【1781-0006】03_業疏/15a_卷三之四#101
【原文】問：此宗五塵非罪福性，何得以色聲為體？答：非外五塵及報色，不妨內方便色也。又云：一念色聲，眼耳所得，非罪福性；相續色聲，法入所攝，意識所得，是罪福性。故論云：名字句者，是法名聲性，法入所攝
【譯文】問：本宗主張外境五塵並非善惡罪福之性，為什麼能以色、聲作為戒體？答：這裡所說的不是外在的五塵以及與生俱來的異熟報色，並不妨礙它可以是內在由加行方便所發起的色法。答中又說：剎那間的一念色聲，為眼根、耳根所緣取感知，並不是罪福之性；但是相續不斷的色聲，則被攝屬於法處（法入），為意識所緣取感知，這就具備了罪福之性。所以論典說：名身、句身等，是法處所攝以聲為體性的法，歸屬於法入所收攝。

【1781-0007】03_業疏/15a_卷三之四#102
【原文】問答中初難。此宗即《成論》，前云「十四種色悉是無記」，今明色聲，故摘五塵為難。答中初簡色體：一簡外塵，由是內報色聲，非無情外物；二簡內報，謂取方便動作，非頑然報法，故云「不妨內方便也」。「內」即對外，「方便」對報。又下次辨業性。瞥爾一念見聞非業，即屬色聲二入；緣慮相續則有成業，即落法塵，故云「法入所攝」。謂拜跪俯仰為目所緣，陳詞乞戒為耳所屬，故云「意識所得」。既為意得，關乎內心，即成記業，故云「是罪福性」。下仍引論，且證口業「是法名聲性」，謂是法之名句聲為體性，判歸法入，明非心業
【譯文】問答之中首先提出詰難。「此宗」就是指《成實論》宗，前面說「十四種色全都是無記」，現在卻說明以色、聲為體，所以挑出五塵來發難。回答中首先簡別色法的體性：第一、簡除外在塵境，因為這是屬於內在正報所發出的色聲，而不是無情外物；第二、簡除單純的報法，也就是選取由意樂加行所帶動的動作，而不是頑鈍無記的果報法，所以說「不妨礙它是內在的方便色」。「內」是相對於外在而言，「方便」是相對於異熟報法而言。「又」字以下，其次辨別業的自性。剎那一念間的見與聞並不能構成業，只屬於色入與聲入；如果心念攀緣思慮相續不斷，就會造構成功業，就落入法塵之中，所以說「法入所攝」。也就是說，拜跪屈伸俯仰為眼睛所緣取，陳詞乞戒為耳朵所聽聞，意識在其中加以分別，所以說「意識所得」。既然為意識所緣取，關聯著內心意樂，就構成了善惡有記之業，所以說「是罪福性」。下文接著引用論典，姑且證明口業「是法名聲性」，意思是這法處所攝的名言字句以聲音為自性，判定歸屬於法入，表明它並非心業。

【1781-0008】03_業疏/15a_卷三之四#103
【原文】問：若色為業體者，何故論云「口業者非直音聲，要以心力助成」？答：聲為業體，以心助成名字句也。用此名句即為口業，心是助業之因，非正業體
【譯文】問：如果是以色聲為業體，為什麼論典說「口業不單只是聲音，必須由心力助發而成」？答：聲音本身是業體，只是憑藉心力助發成就了名字章句。使用這些名句就構成了口業，心只是助成業行的助緣因由，並不是真正的業體本身。

【原文】次難，既不許心為體，正違上文，故須通釋。答中，心可助業而非正體
【譯文】第二次發難，既然不承認以心為體，就正好違背了上文所引論義，所以必須融通解釋。回答中說明：心可以助成業行，但不是真正的業體。

【1781-0010】03_業疏/15a_卷三之四#105
【原文】問：前言「離心無思，無身口業」，而心即思體，身口業起亦不離心，應同用心為體？答：破外人義，思、心同時而體別，故言心即是思。然心未必是思，思必是心故。又破外道身口二業不假心助，故說離心無身口業
【譯文】問：前面說「離開了心就沒有思心所，也就沒有身業與口業」，而心就是思心所的本體，身業與口業生起時也離不開心，難道不應當同樣以心為戒體嗎？答：那是為了破斥外道執著「思與心同時存在而實體各別」的觀點，所以才說心就是思。然而心王不一定就是思心所，而思心所必定依心王而起。另外也是為了破斥外道主張「身業與口業不需要假藉心力助成」的邪見，所以才說離開了心就沒有身業與口業。
