# 校閱材料　第1184檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1184-0001】資持記/09c_中三上#40
【原文】第五，緣釋中，初科。《五分》即約僧次，施心無擇，普召為言；以下三眾同福田故。對界中，論文初列四界。不出作法自然。聚落有二，如〈結界〉中。家即村舍，亦屬聚界。曠野即蘭若，一拘盧準論二里。道行水界，文雖不明，義須準說；但有難蘭若，則非所論。
【譯文】第五、在成犯條件的解釋中，進入第一科。《五分律》是就「依僧次迎請」而言，施主的心意毫無揀擇挑剔，是以普遍迎請大眾為出發點；因為連同下方的出家三眾在內，全都是同一福田的緣故。在對比結界範圍中，論典一開始列出了四種結界，不外乎是「作法界」與「自然界」兩大類。村落聚落分為兩種情況，正如〈結界篇〉中所說。「家」是指村民的房舍，同樣隸屬於聚落界。「曠野」就是指阿蘭若寂靜處，論中折算一拘盧舍相當於兩里。旅途道路以及水上界域，經文中雖然沒有載明，在義理上也必須比照上述原則；但如果有危難發生的阿蘭若，就不在正常的討論範圍之內。

【1184-0002】資持記/09c_中三上#41
【原文】別布薩者，相因而引，非此中意。若僧下，辨成犯相；初明所別，食竟無犯。以前僧必無重食之理，故云不合也。若僧下，明未食結犯。下文簡境，且列三人，如向備引。注文兩節，初通示三人不障僧食。恐謂非別，不與食故。其中滅擯，財法雖亡，然體猶存；除餘僧施，尚沾食分。若下，別示沙彌。
【譯文】所謂「個別舉行布薩」，是順帶牽引出來的旁論，並非本戒的核心意旨。在「若僧」以下，辨析構成犯罪的相貌；首先說明被脫離的大眾，如果已經用餐完畢則不犯戒。因為先前的僧眾絕無重複進餐的道理，所以說「不合再食」。在「若僧」以下，說明未進食時則結罪。下文揀別所對之境，暫且列舉了三種人，正如前面詳細引證的那樣。注文分為兩節，首先通盤說明這三種人並不會障礙僧眾受用常住食物。唯恐有人誤以為這不屬於個別，而不肯給予食物。這其中被驅逐滅擯的人，其常住財物與法事身分雖然已被剝奪，但出家人的肉體依然存在；除了其他一般的僧眾施捨之外，依然能分得一口進食的份額。在「若」字以下，單獨說明沙彌。

【1184-0003】資持記/09c_中三上#42
【原文】以別雖無損，而集則有益；即前唱法乃至沙彌是也。〔僧次取淨，狂擯不成。〕明三位中，初示諸部止有二種。次明《多論》復加僧次。注指上者，前文廣引。問：戒初已列三位，何以重明？答：前文但標所出，此明三位通有不集，故不同也。第六緣中，初引《善見》五足。前二乃是轉別成僧，故免別過；
【譯文】因為在別請中沙彌不入雖然無所損害，但依僧次齊集則能增添法益；這就是前面所說的「唱導法事乃至涵蓋沙彌」的道理。〔依僧倫次迎請重在戒律清淨，發狂與滅擯者皆不能湊數。〕在說明三種情狀中，首先指明其餘諸部律典僅列有兩種。接著說明《薩婆多論》又額外增加了「僧次」這一種。注文中指示參見上文，因為前文已經廣泛引證。有人問：在戒條開頭就已經列出這三種情狀，此處為何要重複說明？回答：前文只是標明其出處來源，此處則是要說明這三種情狀普遍都存在著「大眾未能齊集」的過患，所以用意截然不同。在第六項成犯條件中，首先引用《善見論》的五種豁免情況。前兩種實際上是將「別請」轉變為「僧次」，所以免除了個別的過咎；

【1184-0004】資持記/09c_中三上#43
【原文】下三並謂眾不滿四，非別可知。第五注中，恐濫病時，故特簡之。以病但開己，狂等開他故也。本宗七緣，一病緣中。且舉至輕以攝餘重。劈普激反，之裂也。疏云：身抱患惱，若不開別，無由濟命。二作衣中。一月五月者，與後《五分》衣時何異？今準疏釋前云：作衣延久，恐廢正業；
【譯文】後三種都是指在場僧眾人數未滿四人，算不上別立僧眾，這是顯而易見的。在第五項的注文中，唯恐與「患病之時」混淆不清，所以特地予以甄別澄清。因為生病只是開許給自己個別受用，發狂等情況則是開許給其他人免受牽連之故。本宗四分律所開許的七種特殊事緣中，在第一項「患病緣由」中，暫且舉出最輕微的病況來涵蓋其餘更為嚴重的重症。「劈」字音讀為普激反，意思是皮膚乾裂破裂。義疏說：身體遭受疾苦病痛折磨，如果不及時開許個別受食，就無法保全性命。第二項在「縫製衣服」中。所謂一個月或五個月的期限，與後文《五分律》提到的「衣時」有何不同？如今依據義疏解釋，前文說：製作衣服耗時長久，唯恐耽擱了出家人的正修道業；

【1184-0005】資持記/09c_中三上#44
【原文】釋後云：衣時通給，為補夏勞。故知雖並時中，而前約製造；後通時內，不作皆開。第三，前云：十二月中，隨有衣食請處開背，二戒緣同，故略指耳。疏云：施衣不受，後須難得故。四五道船二行。云下至者，示極小量；已上皆開，減應須制。疏云道船途路多有留難。六中，初科。
【譯文】解釋後文時則說：衣時是全面普發的福利，純粹是為了補償夏季安居修行的辛勞。由此可知雖然都在相同的時段內，但前文著重在「動手裁剪縫製」；後文則通指在整個時段內，即使沒有動工製作也全面開許。第三項，前文說：在十二個月整年當中，只要遇到同時供養衣物與飲食的宴請，就開許背棄先前的受請，這兩條戒的成犯條件相同，所以此處僅僅略作指點。義疏說：如果施主布施衣服而不肯接受，日後若有匱乏就很難再次獲得。第四與第五項是關於乘船以及在道路上行走這兩件事。文中所說「下至」，是顯示極小的距離（半由旬）；在此距離以上往來皆得開許，短於此限則應以戒律約束禁止。義疏說道路乘船途中往往充斥著留難阻礙。在第六項中，進入第一科。

【1184-0006】資持記/09c_中三上#45
【原文】四人百人，此謂能別必須滿眾。長一人者，此謂所別未必多人。能使彼眾皆犯別過，故云為患。此以本犯反釋開意。但語意難曉，故須注釋。初約儉開示相。又下，釋成開意。言限約者，謂施家物少也。乞難得者，明比丘不可避也。疏云：食少人多，不開送故。次科，初敘過。
【譯文】四人乃至百人，這是指能夠發起別眾行為的人數必須達到法定的一堂僧眾。多出一人，這是指被脫離孤立的大眾未必需要很多的人數。這一個人能讓全體僧眾全數陷入別眾的過失之中，所以說這是「為患」。這是藉由原本犯戒的法義，反過來闡釋給予開許的深意。只是文句意旨晦澀難懂，所以必須特加註釋。首先就饑饉之世開許受食來指示開相。在「又」字以下，進一步解釋成就開許的用意。所謂「受到限制約束」，是指布施之家物資匱乏短少。所謂「乞討難以獲得」，是說明比丘根本無處避開這項窘境。義疏說：食物既少而人數又多，無法開許一一分送出去的緣故。下一科中，首先敘述弊端過患。

【1184-0007】資持記/09c_中三上#46
【原文】京輦即京兆府。〔王者都處，謂之輦下。〕不依疏僧，非名請者。闐音田，𨶮音噎，謂隘塞也。親下，訶誡。遮客獨噉，下流所為；況僧海同和，友自安忍，故云過深。斂迹謂掩其惡迹，勿復為之。《五分》下，引證。彼云應語主聽入；若不許者，始令往寺，故云乃至。七中。
【譯文】「京輦」就是指京兆府長安地區。〔帝王建都之處，便稱為輦下。〕所謂「不依疏僧」，是指非指名被請的僧人。闐音讀為田，𨶮音讀為噎，意思是指人多擁擠狹隘阻塞。在「親」字以下，嚴厲呵責告誡。排擠阻攔外來的客僧而由少數人私自獨享美食，純屬下流卑劣之人的行徑；更何況僧團如大海般水乳交融、和合共處，又怎能安心忍受這種自私，所以說這種罪過極其深重。「斂跡」是指收斂掩蓋自己的惡劣劣跡，切莫再重蹈覆轍。在引用《五分律》以下，引用經文作證。彼律說應當勸導施主允許外來僧人一同入內就餐；如果施主不肯答應，這才吩咐客僧返回寺院，所以用「乃至」來概括其過程。第七項中。
