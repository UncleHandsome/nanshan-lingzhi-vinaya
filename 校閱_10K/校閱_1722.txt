# 校閱材料　第1722檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1722-0001】03_業疏/11b_卷二之五#26
【原文】文列羅睺為初者，如未曾有經九歲出家也。西方沙彌每至夏末，多以香華於空奉散，以羅睺報身盡，法猶有故也
【譯文】律文中列舉羅睺羅為沙彌之始，就像《未曾有經》所載九歲出家那樣。西方天竺的沙彌每逢結夏安居結束之時，大多將香花向虛空中散灑奉供，這是因為羅睺羅的報身雖然已盡，而法身猶存的緣故。

【1722-0002】03_業疏/11b_卷二之五#27
【原文】次釋注中初科，初引經文以示年幼。羅睺羅，此翻障蔽，是佛之子，以障佛出家，如羅睺之障日月也。「西下」次舉現事可驗最初，法猶存者，謂法身常在也
【譯文】在第二解釋注文的第一科中，起初引用經文以表明其年幼。羅睺羅，此處翻譯為「障蔽」，是佛陀之子，因他曾障蔽佛陀出家，猶如羅睺阿修羅之障蔽日月一般。自「西」字以下接著舉出當前現行之事以驗證其為最初沙彌；說「法猶存」，是指其法身常在之意。

【1722-0003】03_業疏/11b_卷二之五#28
【原文】文列僧祇約年為位者，以出家之人要修道業為本，老小非務，何勤苦於三學也？故涅槃云：「誦經、坐禪、勸助眾事，老無三味，有四山臨
【譯文】律文中列出《僧祇律》依年齡劃分位階，是因為出家之人必須以修持道業為根本，太老或太幼都不堪承擔僧務，哪能在戒定慧三學上勤苦修持？所以《涅槃經》說：「誦經、坐禪、勸勉協助大眾事務，年老之人對這三件事皆無滋味，且有生老病死四山逼臨。」

【1722-0004】03_業疏/11b_卷二之五#29
【原文】二中初示簡意。老謂過七十，小即未七歲，故下引經但證老者。經列三事，即是道業；年老力衰，故竝無味；將死不久，如四山來逼。成論云：「行者見死有大力勢，如大石山從四方來，無逃避處
【譯文】在第二部分中，起初說明揀選排斥的用意。太老是指超過七十歲，太幼則是指未滿七歲，所以下文引經只用來證成年老者不可。經中列出三件事，指的就是道業；年老體衰，所以對這三件事都無力體會法味；將死不久，宛如四座大山逼迫而來。《成實論》說：「修行者見到死亡擁有極大力量，猶如巨大的石山從四方合攏而來，毫無逃避之處。」

【1722-0005】03_業疏/11b_卷二之五#30
【原文】又云為說苦事者，以世網苦辛，多厭求樂，初雖慈許，終有退敗。故經論中有「現世苦、未來樂」者，出家人也。晝夜鞭心，常收正念，不覺妄緣，尋悔訶責。故智論中菩薩日三夜三，每行三事，謂懺悔、隨喜、勸請也。三千云必行坐禪等三，不爾徒生徒死。即遺教曰「中夜誦經以自消息」，餘時須依律文常爾一心念除諸葢
【譯文】又說為他宣說出家苦事，是因為世俗羅網艱辛困苦，人多半生起厭離而想尋求安樂，最初為師者雖然慈悲應允度其出家，最終往往退轉失敗。所以經論中提到「現世受苦、未來得樂」的人，指的就是出家人。晝夜鞭策心念，時常收攝正念，若不知不覺攀緣妄境，隨即悔過訶責自己。因此《大智度論》中說菩薩白天三次、夜晚三次，每次都奉行三件事，即懺悔、隨喜、勸請。《三千威儀》說必須實踐坐禪等三事，否則只是徒然受生、徒然枉死。即如《遺教經》所說「中夜誦經以自消息」，其餘時間必須依循律文，時常一心專注、念茲在茲除去各種煩惱蓋障。

【1722-0006】03_業疏/11b_卷二之五#31
【原文】三中初示須說之意。世網苦辛，謂工商士農經營求趁，不容自安，人多厭之，求安閑樂，故反說苦事，知其志願。初慈許者，謂師輒受也；終退敗者，謂資疲厭也。「故經下」二、引苦事之相，初通示。指經論者，多所出故。在家欲樂是苦因，出家苦行是樂因，事似相反，理實相應。言鞭心者，心如鈍驢，常須鞭䇿可得前進；常收正念，不隨塵也；不覺尋悔，縱之不久也。「故下」引證。智論日夜各分初、中、後分，以為六時。三千經中坐禪等三，同上涅槃，近故略之。徒，空也。夜準遺教，三時無廢；晝依本律，四儀常攝
【譯文】在第三點中，起初說明必須宣說苦事的用意。世俗羅網艱辛困苦，是指士農工商營謀奔波，不得安寧，人們多半厭苦而尋求安閑快樂，所以反過來向他說明出家之苦，以考驗他的志願。最初慈悲應允，是指師父隨意收受；最終退轉失敗，是指弟子感到疲倦厭怠。自「故經」以下，第二部分引述出家苦事的具體行相，起初通體說明。指稱經論，是因為處處皆有記載。在家的欲望享樂是受苦之因，出家的刻苦修行則是獲樂之因，事相上看似相反，法理上實相契合。說「鞭心」，心猶如愚鈍之驢，時常需要鞭策才能前進；「時常收攝正念」，是不隨逐塵境；「不知不覺隨即悔過」，是不讓放縱持續太久。自「故」字以下引文為證。《大智度論》將白天與黑夜各分為初、中、後三分，合為六時。《三千威儀經》中所說的坐禪等三事，同於前述《涅槃經》，因剛提過故予以省略。「徒」，就是空過。夜晚依照《遺教經》，三時皆不廢棄道業；白天依循本律，四威儀中常自攝心。
