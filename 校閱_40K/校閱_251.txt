# 校閱材料　第251檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【251-0001】資持記/05e_上四#48
【原文】若得新者，即時非時施，本非作德衣也。檀越施者，正為作德衣施，通七眾也。糞衣下，準律，合有若是新衣，若是故衣二句，竝釋上糞衣耳。新物揲淨，即上新衣，以故揲也。浣納淨者，明上故衣，不勞更揲也。〔即日來一種，準律在應法字上，今科於下。
【譯文】如果得到的是新衣，那就是時施、非時施，本來不是為製作功德衣而施的。檀越所施，正是為了製作功德衣而施，通於七眾。「糞衣」以下，依據律文，應該有「若是新衣」「若是故衣」兩句，都是解釋上面的糞衣罷了。新物揲淨，就是上面的新衣，用舊布來揲貼它。浣納淨，是說明上面的故衣，不必再勞煩揲貼。〔「即日來」這一種，依據律文在「應法」二字之上，現在科判放在下面。〕

【251-0002】資持記/05e_上四#49
【原文】不以下，次明求乞離過。次列六種。上五簡非，如〈二衣〉釋。下一顯如，謂道眾所施，說淨長物也。〔《僧祇》亦云：淨財得作。〕三上云即日來及應法，此二明受法。言應法者，即下簡人秉法，皆須合教。四周下，四明作衣法，又三，初示堤條。若過是者，謂七條大衣也。
【譯文】「不」字以下，其次說明求乞而遠離過失。接著列出六種。上面五種是簡別不合法的，如〈二衣篇〉所解釋。下面一種顯示如法的情形，是指道眾所布施的，作說淨的長物。〔《僧祇律》也說：淨財可以製作。〕第三，上面所說的「即日來」以及「應法」，這兩種是說明受衣之法。所說的「應法」，就是下面簡別人員主持法事，都必須合乎教法。「四周」以下，第四是說明作衣之法，又分為三：第一是顯示衣的條隔。如果超過這個數的，就是指七條大衣。

【251-0003】資持記/05e_上四#50
【原文】應云：七條二十一隔，大衣亦類增之。應自下，明裁製。且示下衣，餘可例準。又下，明色相。律因六群以大色染衣，錦衣白色衣作之，佛因制斷。律云：云何僧不成受功德衣？謂不浣、不碾、不治、不安緣、不裁隔、不編邊〔不刺緣口〕、不安紐、不作葉、不安鉤、邪命得、諂曲得、相得、激發得、離宿衣捨墮、不作淨〔前不捨墮，兼收離衣。
【譯文】應當說：七條衣有二十一隔，大衣也照這一類推增。「應自」以下，說明裁剪製作。暫且舉出下衣，其餘可以依例比準。「又」字以下，說明顏色的相狀。律中因為六群比丘用大色染衣，用錦衣、白色衣來製作，佛因此制斷。律中說：什麼情形下僧眾不能成受功德衣？就是：不洗、不碾、不整治、不安緣、不裁隔、不編邊〔不刺緣口〕、不安紐、不作葉、不安鉤、以邪命而得、以諂曲而得、以現相而得、以激發而得、離宿衣犯捨墮、不作淨〔前面所說的不捨墮，這裡兼收離衣之罪〕。

【251-0004】資持記/05e_上四#51
【原文】不即日來、不應法受衣〔反前應法可解〕，不四周安緣〔自下三種，如後簡人中引。〕，不在僧前受、若有難、若界外住，如是竝不成；反之則成。《十誦》中，初簡作。若故下，簡體。到塚取者，釋上覆死衣。注中和會前文。應知《四分》常用糞衣，亦無所擇。若揲下，示如法。《伽論》。
【譯文】不是當天送來、不如法受衣〔與前面所說的「應法」相反，可以理解〕、四周不縫製邊緣〔從以下三種，如後面「簡人」中所引〕、不在僧眾面前受、有災難、住在界外，這些都不成受；反過來就成受。《十誦律》中，最初是簡別作法。「若故」以下，是簡別衣體。「到塚取」這句，是解釋上面的「覆死衣」。注文是會通前面的文義。應當知道《四分律》常用糞衣，也沒有什麼揀擇。「若揲」以下，顯示如法。《伽論》。

【251-0005】資持記/05e_上四#52
【原文】急施及時衣，本非德衣施，經宿亦成受。《僧祇》。未用，即上新衣。《五分》。明非有七，竝以若字標之。上四簡衣，即製造體色量，皆非法也。第五簡時，六七竝簡受人。故捨五事者，準彼上有若欲二字；五事，即畜長等五戒。上明貪利，下即慢戒。〔有以五事為五利，彼文不然。〕三明簡人，初簡受中，《四分》四種。
【譯文】急施衣和時衣，本來不是為功德衣而施，經過一夜也成為受。《僧祇律》。尚未使用，就是上面的新衣。《五分律》。說明「非」的情形有七種，都用「若」字標示。上面四種是簡別衣，也就是製作、衣體、顏色、分量，都屬於非法。第五是簡別時節，第六、第七都是簡別受衣的人。「故捨五事」，依據彼文上面有「若欲」二字；五事，就是畜長等五條戒。上面說明貪圖利益，下面就是輕慢戒法。〔有人把五事當作五利，彼文不是這個意思。〕第三是說明簡別人員，最初在「簡受」中，《四分律》有四種。

【251-0006】資持記/05e_上四#53
【原文】有難者，謂王賊等難，眾不得受，即簡受人也。《戒疏》云：律云：有難無大衣；今既賊難，故不合受；無難應成。〔文見蘭若離衣戒，古云十三難人，謬矣。〕無僧伽梨者，非本開意，如前緣中。若爾，無下二衣，成受不？答：文中不簡，思之可知。
【譯文】「有難」，是指國王、盜賊等災難，大眾不能受衣，就是簡別受衣的人。《戒疏》說：律中說「有難無大衣」；現在既然有賊難，所以不應該受；沒有災難就應當成受。〔這段文見於〈蘭若離衣戒〉，古人說是「十三難人」，錯了。〕「無僧伽梨」，不是本來開許的用意，如前面因緣中所說。若這樣，沒有下面二衣，能成受嗎？答：文中沒有簡別，想一想就可以知道。

【251-0007】資持記/05e_上四#54
【原文】界外住者，身雖現前，相不足數故。《善見》，初通簡是非。文中必該中安居不安居者。若下，別示界外。初不滿，及後滿五不解，竝簡異界不得。中明僧及沙彌，僧為受已，成足得利，竝顯當界成受。〔謂請僧為受戒已，但共新戒受衣。〕《十誦》，初明曲開異界。
【譯文】住在界外的人，肉身雖然在眼前，但因界限標相不符而不能算入人數。《善見律》，首先整體簡別合適與否。文中必定涵蓋了中安居與不安居（或後安居）之人。「若」字以下，分別指出結界之外的情況。最初未滿五人，以及後面滿了五人卻不懂受衣之法，這兩種情形都是簡別異界僧人不得享受衣利。中間說明僧眾以及沙彌，僧眾替其受戒完畢後，人數具足而得以獲得衣利，這全都是顯明在當前結界之內能成辦受衣。〔是指迎請僧眾為其受具足戒完畢後，僅僅是共同與新受戒者一同受衣。〕《十誦律》，首先說明破例開許在不同結界的情形。

【251-0008】資持記/05e_上四#55
【原文】同結者，彼云：安居竟，四邊僧坊若八若九若十若過，共結一界受迦絺那衣；一切比丘，皆得名受。後別結者，謂作法受已，即解即結，非五月滿也。彼問：如上僧坊，共結受已，捨是大界；是諸比丘，名受衣耶？答：皆名受。捨者等者，如有一處，眾不樂利，不待時滿；或作法捨，或遇緣失，不妨餘處故也。
【譯文】「同結」，彼律說：安居結束後，四邊的僧坊若八處、九處、十處或更多，共同結成一個界來受迦絺那衣；一切比丘，都可以名為受衣。「後別結」，是說作法受衣之後，隨即解界隨即再結，不是等到五個月滿。「彼問」：像上面所說的僧坊，共同結界受衣之後，捨掉這個大界；這些比丘還名為受衣嗎？答：都名為受。「捨者等」，譬如有一處，大眾不喜歡這份利益，不等時限屆滿，或者作法捨，或者遇到因緣而失，並不妨礙其他處所的緣故。

【251-0009】資持記/05e_上四#56
【原文】彼問：眾多僧坊，共結受已，捨是界已，捨迦絺那衣；一切比丘，皆名捨耶？答：捨者捨，不捨者不捨；今引答詞，仍變其語耳。二簡犯過。擯人，即滅擯。彼文止列四人，今加等字，更收應擯及三舉人；以棄眾外，不合同法故。〔諸文不簡四羯磨人，義詳似得。〕持人中，《十誦》。五德，上四可解。
【譯文】彼問：眾多僧坊共同結界受衣之後，捨掉這個界，再捨迦絺那衣；一切比丘都名為捨嗎？答：捨的人就是捨，不捨的人就是不捨；現在引用答詞，仍舊改變了它的語句。第二是簡別犯過的人。「擯人」，就是滅擯。彼文只列出四種人，現在加上「等」字，更加收攝應擯以及三舉的人；因為棄於眾外，不能共同參與法事故。〔諸文沒有簡別四羯磨人，義理上詳細推究似乎可以。〕「持人」中，《十誦律》。五德，上面四種可以理解。
