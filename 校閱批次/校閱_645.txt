# 校閱材料　第645檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【645-0001】03_業疏/12a_卷三之一#103
【原文】十誦自然中。初引律示，謂佛成道斷惑證真，自然感戒。如下引論決上自然必由緣發，不假他教謂無師也，非不自假謂由教生無教也。準此如來果中得戒，《僧祇》亦然；若依《五分》，因中得戒，隨機異見，廣如《義鈔》。二中自誓即大迦葉，森然即眾多來集之貌。三中五拘鄰即鹿園初度五人也，拘鄰即五中之首，此翻本際，即憍陳如，二曰阿濕卑、三曰摩訶摩南、四曰婆提、五曰婆敷。若依《善見》，善來得戒，與此不同。四中彼經云：佛在摩竭提國波沙山中，清且從靜室起，在外經行，時須陀沙彌在佛後行，佛曰：「我今問卿義，有常色及無常色，為一義？為有若干？」對曰：「此義非一。所以然者？有常色是內，無常色是外。」佛言：「汝快說此義，今即聽汝為大比丘。」故云說法無滯等，廣如第二十二卷。《善見》佛問云：「汝年幾？」答：「我年七歲。」餘同《增一
【譯文】在《十誦律》自然戒一科中。首先引律文提示，是指佛陀成道斷除惑業證悟真諦，自然感發得戒。自「如」字以下引用論典斷決上面的自然得戒必定是由機緣引發，不假他教是指無師自悟，非不自假是指由身口表業（教）生起無表戒體（無教）。依此推準如來是在道果之中得戒，《摩訶僧祇律》亦然；若依《五分律》，則是在因位之中得戒，這是隨根機不同而見解互異，詳如《拾毗尼義鈔》所載。第二自誓受中，即指大迦葉；森然是指眾多齊全的樣貌。第三得道受中，五拘鄰即鹿野苑最初度化的五人，拘鄰是五人中的首席，此處翻譯為本際，即憍陳如；第二位名叫阿濕卑，第三位名叫摩訶摩南，第四位名叫婆提，第五位名叫婆敷。若依《善見律》，他們是善來得戒，與此處不同。第四論義受中，該經記載：佛在摩竭提國波沙山中，清晨自靜室起，在戶外經行，當時須陀沙彌走在佛後，佛說：「我現在問你法義，有常色與無常色，是一個義理？還是有多種差別？」答道：「這義理不是同一個。為什麼呢？有常色屬於內，無常色屬於外。」佛說：「你對這義理說得極好，現在就聽許你成為大比丘。」所以說說法無滯礙等，詳如第二十二卷所述。《善見律》記載佛問：「你年紀幾歲？」答：「我年紀七歲。」其餘情節與《增一阿含經》相同。

【645-0008】03_業疏/12b_卷三之一#4
【原文】問：《四分》律文但云三語，此文更列三歸者？答：以義約之，歸猶結也。作法既久，宗奉漸漓，如結成受。故《多論》云：「宿業力故，應三語得戒者，三語則止；三歸亦然，自然使爾。」牛呞比丘兄弟七萬比丘，盡以三語受戒。《四分》文中但云「歸依三寶隨佛出家」，本無歸結
【譯文】問：《四分律》文只說「三語」，此處為何又另外列出「三歸」？答：依義理來探討，歸就像是結白。這種作法行之既久之後，宗奉之心漸趨澆薄，便如同結句作法而成就受戒。所以《薩婆多論》說：「由於宿世業力的緣故，應當以三語得戒的人，說完三語即得戒；三歸也是如此，法爾自然使其如此。」牛呞比丘兄弟七萬比丘，全部都是以三語受戒。《四分律》文中只說「歸依佛、歸依法、歸依僧，隨佛出家」，本來沒有後續的結白之語。

【645-0009】03_業疏/12b_卷三之一#5
【原文】問答中。初示名義。作法久者，謂三語也。漓即是薄，故下引文證。《多論》宿業，謂往緣也；三歸亦然，亦宿業也。梵云憍梵波提，此翻牛呞，亦云牛跡，過去為牛，故口有牛呞，足有牛跡。呞，音詩，《說文》云「吐而噍也」。彼云兄弟七萬詣諸比丘所，諸比丘各盡以三語受戒。《四分》三語亦有加結，今云本無，未詳何意。有云：《四分》雖有結歸，而得戒在於三語，不同彼宗結歸方獲
【譯文】在問答之中。首先指示名相之義。「作法既久」，是指三語法。「漓」就是薄，所以下文引文為證。《薩婆多論》所說的「宿業」，是指過去世的宿緣；「三歸亦然」，也是宿業所致。梵語憍梵波提，此處翻譯為牛呞，也稱牛跡，因過去世曾轉生為牛，所以口有牛反芻咀嚼之相，足有牛蹄之跡。呞，音同「詩」，《說文解字》說：「反芻吐出而咀嚼。」該論說牛呞兄弟七萬人前往眾比丘處，眾比丘各自全都以三語為其授戒。《四分律》的三語法中其實也有加上結句，如今說本無結句，尚不清楚是何意趣。有人說：《四分律》中雖然也有結句歸依，但得戒在於說三語之時，不同於彼宗要到結句歸依時才獲取戒體。

【645-0035】03_業疏/12b_卷三之一#31
【原文】次二受中。文牒二種，不釋有量，反佛無量自可知故。若據餘部，通歸自然；今取位別心境廣狹，故分二焉。阿僧祇劫翻無數時，而言三者，且約釋迦修菩薩道時以論分齊：從古釋迦至尸棄佛，值七萬五千佛，名初僧祇；次從尸棄至然燈佛，值七萬六千佛，名第二僧祇；又從然燈至毗婆尸佛，值七萬七千佛，名三僧祇。若望聲聞，當內凡位。萬行者，萬是數之通名，行實無量，不必一萬。最後生，謂王宮所生也。菩薩戒者，謂久修菩薩行，習性自然，遠惡住善，故云性得。若爾，前云小戒為大方便，今何倒耶？答：此菩薩戒亦即小乘義說為戒，非從他受，不同《梵網》善戒受者方獲。苦法忍時，即證見道無漏聖慧斷惑之時，準此初果即得具戒。「盡無生智起」句絕，謂盡智與無生智，二智發起，即證無學道時。謂證滅諦，結惑斷盡，故名盡智；從盡智後，無漏智起，一切結惑無再生理，名無生智。三種功德者：一菩薩戒、二出家具戒、三佛法圓滿。前二是因，後一是果，皆徧生境，故無邊量。然此且據小教明佛；若約大乘，出生成道無非示現，隨緣垂應，非實爾也
【譯文】在其次兩種受戒中。疏文標舉這兩種，未解釋「有量」，是因為相對照佛陀的「無量」，獨覺的有量自然即可反推明了。若依其餘律部，都總括歸為「自然得戒」；此處則取名位差異與心境的廣狹不同，所以分為兩種。阿僧祇劫翻譯為「無數時」，而說「三」者，且依釋迦牟尼佛修行菩薩道時來界定階段：從古釋迦佛至尸棄佛，值遇七萬五千尊佛，稱為第一僧祇；其次從尸棄佛至燃燈佛，值遇七萬六千尊佛，稱為第二僧祇；又從燃燈佛至毘婆尸佛，值遇七萬七千尊佛，稱為第三僧祇。若對望聲聞位次，相當於內凡位。所謂萬行，「萬」是數量的通稱，行持實屬無量，未必剛好是一萬。最後生，是指在王宮中所受生的一世。菩薩戒，是指久遠修習菩薩行，習性已成自然，遠離諸惡而安住善法，所以說是自性本得。若是如此，前文說小乘戒是大乘戒的前行方便，如今為何顛倒過來？答：此處所謂的菩薩戒，也是依小乘義理假稱為戒，並非從師受得，不同於《梵網經》或《菩薩善戒經》那樣必須受戒方能獲取。苦法忍時，即是證入見道位、以無漏聖慧斷除疑惑之時，照此看來證初果時即獲得具足戒。「盡無生智起」此句斷句，是指盡智與無生智這二種智慧生起之時，即是證得無學道之位。意謂證得滅諦，結縛疑惑斷盡，所以稱為盡智；在盡智之後，無漏聖智現起，一切惑業絕無再生之理，稱為無生智。三種功德是指：第一菩薩戒、第二出家具足戒、第三佛法圓滿。前二者是因，後一者是果，皆遍及一切眾生之境，所以沒有邊際限量。然而這只是且就小乘教理來說明佛陀；若依大乘教理，降生王宮、出家成道無非皆是方便示現，隨眾生機緣而垂跡應化，並非實有如此歷程。
