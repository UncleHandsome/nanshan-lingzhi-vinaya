# 校閱材料　第452檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【452-0001】資持記/02d_上一下#15
【原文】應下，明成法。以所犯情過非極重故。但下，示少缺。由是犯過白四治罰故。不得訶者以三十五事中所制故，律中科為得滿不得訶人。餘如下科。犯殘七人，初列名數。具如〈懺篇〉。本宗四人，但據正行。第四人，《業疏》上加將字，於相甚顯。〔此四出人法中，不在四滿句。〕《十誦》三人，並約行竟；
【譯文】從「應」以下，說明可以成辦羯磨法。因為所犯的情節過失並非極度嚴重。從「但」以下，顯示有些微缺陷。由於是犯過而被白四羯磨處罰的人。不得提出反對（訶阻）者，是因為在三十五事中所制定的緣故，律中將其科判為「能充人數但不得訶止之人」。其餘的如同下個科判。犯僧殘的七種人，起初列出名稱與人數。詳細內容如同〈懺罪篇〉。本宗的四種人，只依據正行處罰期間而言。第四種人，《業疏》在上面加上「將」字，在行相上就非常明顯。〔這四種人出現在人法之中，不在四種滿足的句型裡。〕《十誦律》的三種人，都是就已經行法完畢而言；

【452-0002】資持記/02d_上一下#16
【原文】恐謂行竟，妄將充數故。《業疏》云：六夜竟與將出罪何異？答：律文兩位，約遠近耳。〔六夜竟，望出罪遠，將出即近。〕又問與四羯磨人何異？答：前但小犯，情過可訶，故足數收；此犯次死，罪深難拔，故不足也。不足下，示少分義。
【譯文】這是唯恐有人以為行法完畢，就胡亂抓來充抵人數的緣故。《業疏》說：六夜行法完畢與將要出罪有何差異？回答：律文的兩個階位，是就時間的遠近來論罷了。〔六夜完畢，距離出罪尚遠，將要出罪就是距離很近。〕又問：這與四種羯磨處分的人有何差異？回答：前面只是輕微犯戒，情節過失尚可訶責，所以仍收錄在足數之中；這裡犯的是次於死罪的僧殘，罪過深重難以拔除，所以不能算入足數。從「不足」以下，顯示局部不足數的意義。

【452-0003】資持記/02d_上一下#17
【原文】謂唯除悔殘四法，是不足耳，以同犯者不合同治故。不妨下，明應法。此十一人，準疏別判；乃知今鈔全依律出，猶同古解；彼云：有人云：四羯磨者，眾法皆通；僧殘諸治，局二篇悔。若作此解，焉有被訶責者得更治人？犯二篇者，開餘懺主！審約事情，律文不了。以義糺定，應分二途。若同犯同治，理無預加。
【譯文】意思是唯獨除了懺悔僧殘的四種羯磨法，才不算足數，因為同犯戒的人不應當共同懲處治罪。從「不妨」以下，說明可以相應於一般的羯磨法。這十一人，依照《業疏》特別加以判定；這才明白現在這部行事鈔完全是依照律文寫出，依然如同古師之解；《業疏》說：有人認為：受四種羯磨的人，通於一切大眾羯磨法；犯僧殘的各項懲治，只限於第二篇（僧殘）罪的懺悔法。如果作這種解釋，哪有遭受呵責處分的人，反而能夠再去懲處別人？犯了第二篇（僧殘）罪的人，竟然開許成為別人的懺悔主！仔細審查事理情態，律文在這裡講得不夠透徹。如果用義理加以糾正裁定，應當分為兩條途徑。如果是同犯此罪而一同治罪，按理決無參與施加治罰的可能。

【452-0004】資持記/02d_上一下#18
【原文】律言足數，謂差結等。〔此一途也。〕若自有犯，必無清過，以有罪人不合解罪。乍可應餘非罪羯磨。〔此一途也。〕若作斯通，始終無妨。〔準此決前十一人，但應生善名足；一切滅惡犯治，並不成足；鈔存不了義，用疏廢之。〕問：前四後七，有何別耶？
【譯文】律文說算入足數，是指派遣、結界等法。〔這是一條途徑。〕如果是自己有犯，必定無法洗清過失，因為有罪的人不合適去為別人解罪。姑且只可以相應於其餘非關治罪的羯磨。〔這也是一條途徑。〕如果作這樣的通融解釋，始終都沒有扞格妨礙。〔依照此理來決斷前面這十一人，只要是相應於生長善法的羯磨都算足數；一切滅除惡業、懲罰犯戒的羯磨，一概不能算入足數；鈔文保留了不透徹的義理，應當用《業疏》的見解來廢除它。〕問：前四種人與後七種人，有什麼差別呢？

【452-0005】資持記/02d_上一下#19
【原文】答：據律則別，疏決無殊；不妨同歸少分不足，得為一例。問：四門同別，可得聞乎？答：初二兩門一向不足，第三相翻名足，第四或足不足。又初後具戒。中二多別，尼等四人，有而非類；邊等十三全無，舉滅皆有，全壞以分。問：三例不足，為總幾人？答：初例三十一，次門二十三，第四十一。
【譯文】答：依照律文則有差別，依照《業疏》決斷則無差別；不妨同樣歸為局部不算足數，可以列為同一個例項。問：四個門類的共同點與差異點，可以聽您說說嗎？答：前兩個門類一律不算足數，第三個門類反過來就算足數，第四個門類則是有時算、有時不算。此外，第一個和最後一個門類都具足戒體。中間兩個門類則多有差別，比丘尼等四種人，有戒體但非同類；犯邊罪等十三難人是完全沒有戒體，三舉、二滅則本來有戒體，這是以戒體全壞與否來區分的。問：三個不算足數的例項，總共有多少人？答：第一個例項三十一人，第二個門類二十三人，第四個門類有十一人。

【452-0006】資持記/02d_上一下#20
【原文】共六十五。準下別眾，學悔不足；《業疏》更加背說戒坐，共為二人，不係前例。別眾法附，標列中。注釋，前二句示相。上句明異界非別，下句言通三業四儀。後二句結名，可知。然別通能所。就能別中，下至一人；眾法心念，亦制盡集。若論所別，並通多少。問：此與別食何異？
【譯文】總共六十五人。依照下文別眾的內容，修學悔過法的人也不算足數；《業疏》更加上背對說戒而坐的人，共為兩人，不屬於前面的例項。在附帶說明別眾法、標示並列舉的內容中。注釋部分，前面兩句顯示行相。上一句說明不在同一個結界內就不構成別眾，下一句說明這種分別通於身口意三業以及行住坐臥四種威儀。後面兩句結成名稱，意思很明白。然而「別」通於能別與所別。就「能別」的人而言，最少甚至只要一人；大眾羯磨與心念羯磨，也都規定必須全部集合。如果就「所別」的僧眾而言，則人多人少都通。問：這與個別受食（別眾食）有何不同？

【452-0007】資持記/02d_上一下#21
【原文】答：食中能別局四，三人無過。所別同上。又食有九緣可開，法無方便得別。食則犯提，制重業輕；法唯犯吉，制輕業重。若一界之內，兩眾各秉，則是破僧，犯中品蘭。問：別眾之名，為能為所？答：制過在能，從能立號。《戒疏》云：若取語便，應云眾別。可以決之。問：何名為別？答：別是異義。
【譯文】答：受食中能別的局限於四人，三個人受食不算有罪。所別的人數與上面相同。又受食有九種因緣可以開許，作法事則沒有任何方便可以個別分開。受食只是犯波逸提，制戒雖重但罪業較輕；作法則唯獨犯突吉羅，制戒雖輕但壞僧業重。如果同一個結界之內，兩群僧眾各自秉持羯磨，那就是破僧，犯中品偷蘭遮罪。問：別眾這個名稱，是就「能別」還是「所別」立名的？答：制止過失是在於能別的人，是順從能別而建立稱號。《戒疏》說：如果就語詞順暢而言，應當稱為「眾別」。可以用這句話來裁決。問：何名為別？答：別是異義。

【452-0008】資持記/02d_上一下#22
【原文】一三業異，二四儀異，三向背異。並如下明。〔食中但是食不同味，名同事別。〕三業中，初科，文出〈瞻波犍度〉。應來者，謂應羯磨人；簡前體淨緣差中瘂聾狂亂重病癡鈍等，及體境俱非一門之人，皆不應來故。二應與欲者，有如法緣，簡非緣者不合與故。三得呵者，謂具德知法；
【譯文】第一是三業相異，第二是四種威儀相異，第三是面向與背向相異。這都在下文加以說明。〔受食中只是吃的食物味道不同，稱為名稱相同而事相有別。〕在三業之中，第一個科判，文句出自〈瞻波犍度〉。所謂「應當來集的人」，是指應當參與羯磨的人；這簡別了前面戒體清淨但因緣有阻隔的啞巴、聾子、瘋狂發亂、重病、愚癡遲鈍等，以及戒體與境地都不合的一門之內所有人，這些人都根本不應當前來。第二種「應當交付欲意的人」，是指具有如法的因緣，簡別非因緣者不合適交付欲意。第三種「能夠呵責阻止的人」，是指具足戒德且通曉教法的人；

【原文】簡不合訶者，如四羯磨等。問：不與欲人，口亦不集，何不列者？答：身既不集，理無訶故。若爾，初人身亦不集？答：彼無欲緣，身合當集；容有口訶，故同不集。此則不爾，有如法緣，許不集故。若准《業疏》，單配三業，乃為盡理；初身不集，次心不集，後口不集。反為三和，亦從單歷。次科。上二人可知。
【譯文】這簡別了不合適呵責的人，例如受四種羯磨處分者等。問：不交付欲意的人，口頭也沒有表達和合集會，為什麼不列出呢？答：身體既然沒有前來集會，按理自然無法開口呵責。如果這樣的話，第一種人身體也沒有前來集會啊？答：那個人沒有交付欲意的因緣，身體本來應當前來集會；他有可能在口頭上提出呵阻，所以等同於口不集會。這個人則不相同，他有如法的因緣，律中開許他不集會的緣故。如果依照《業疏》的說法，單純將這三種人配對三業，才算是最窮盡義理；第一是身不集，其次是心不集，最後是口不集。反過來成為三種和合，也是依循單項依次經歷。下一個科判。上面兩種人可以理解。

【原文】後人心不集者，此謂有可訶事，心不同忍。必無訶事，則同初人。故下，引證，初即〈瞻波〉文。彼明非法和合羯磨云：有同一住處同一和合一處羯磨，應與欲者與欲，現前應得訶者不訶，作白二乃作白四，白此事乃為彼事。此文可證相順心違。
【譯文】最後一個人屬於「心不集」，這是指有應當呵責的事，心裡並不贊同忍可。如果確實沒有應當呵責的事，那就等同於第一種人。所以從「故」以下引證，起初就是〈瞻波犍度〉的律文。那裡說明非法和合羯磨時說：有在同一住處、同以一種和合方式、在同一處所作羯磨，應當交付欲意的人交付了欲意，在場應當能夠呵責的人不提出呵責，本該作白二羯磨卻作了白四羯磨，宣告這件事卻辦了那件事。這段經文可以證明表面順從而內心相違的情況。

【原文】次成否中，即明別眾成不成相。正簡中，初科，上二句明成。別犯下諸篇，不壞本故。別犯下，明不成。根本已壞，眾法絕故。文又為二，初約不知明成法。引律無作有想，以例穢作淨想，理無差故。羯磨成者，佛判法成；即彰非別。罪即吉羅。心不同者，出結罪意。審下，二約眾知明隨別。
【譯文】其次在「成否」一科中，就是說明別眾究竟構成與否的行相。在正式簡別中，第一個科判，上面兩句說明構成別眾。別眾之人若犯以下各篇輕罪，因為沒有毀壞根本戒體的緣故（仍成別眾）。從「別犯」以下，說明不構成別眾。根本重戒既然已經毀壞，參與大眾僧法的資格就斷絕了（故不成別眾）。內文又分為兩部分，起初是就不知情來說明構成別眾之相。引述戒律中「無比丘而作有比丘想」，以此來比照「將垢穢者當作清淨者想」，在道理上是沒有差錯的。羯磨成就，是指佛陀判定此法成立；這就彰顯出他們並不構成別眾。所犯的罪過就是突吉羅。內心不同意，是點出結罪的原由。從「審」以下，第二是就大眾知情來說明可隨意別開他（不障僧法）。
