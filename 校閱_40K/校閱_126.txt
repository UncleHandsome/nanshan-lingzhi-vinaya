# 校閱材料　第126檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【126-0001】02_戒疏/09a_卷二下之二#77
【原文】【疏】今解持犯之生，皆從法起，違順教相，故有犯持。據房為言，事、法分二，各具二持，名體須顯。安有端坐不修為持？如殺盜等，隨境制禦，識達業相，方成前行，號曰「止持」。豈可臥地「我不殺生」，便於生境能發隨戒？戒隨三善，緣境而生。前立義中，約行明持，無問止作，前之三心，不名持犯。云何此中，「我不造房」，名為止持？義不可也。
【譯文】【疏文】現在我們解釋持犯的產生，全都是依託戒法教制而生起，順應或違背了教誡相狀，才產生了持戒或犯戒。拿建造房屋這件事來說，事相與法度必須拆分為二，兩者各自都具足了止持與作持，其名相與實體必須清晰顯露。哪裡有端坐什麼都不修持就能算作持戒的？例如殺生、偷盜等戒，必須是面對現前境緣時能克制抵禦、心中清楚了達業行相貌，才能成就前一種行持，稱為「止持」。難道躺在地上心想「我不殺生」，便能對一切眾生境界引發出圓滿的隨行戒體嗎？隨行戒體是隨著三種善心、依託所對境界而生起的。先前立論時，是針對實際行持來明辨持戒，無論止持或作持，在行心之前的識、想、受三心，都不能稱為持犯。為何在此處卻認為「我不造房」便可稱為止持呢？法理上絕對說不通。

【126-0002】02_戒疏/09a_卷二下之二#78
【原文】【記】今破中。初通示持犯之本。「法」即是教，未立教法，無持犯故。「據」下，別示房戒。初立正義，反古三失。「事」、「法」各具「止」、「作」，「名體」如下所顯。「安」下，次斥古非。初舉重戒例破。「禦」謂正念離非，即能治之行。「識達」謂明辨行相，即解教之智。必須此二，方得成持，自餘悠悠，但名泛善，學者臨文，細意詳究。「戒隨」下，次約隨戒飜破。指「前立義」者，即「持犯成就」中。今師必據造房以明，與古全異，故此斥之。
【譯文】【記文】現在進行破斥。起初通貫說明持犯的根本根源。「法」就是佛陀的教法，未制立教法之前，本無持犯可言。「拿建造房屋」以下，個別說明造房戒。首先樹立正確義理，反破古人的三項缺失。「事相」與「教法」各自具備「止」與「作」，其「名目與體性」就如下文所彰顯。「哪裡有」以下，接著斥責古人的謬誤。起初列舉根本重戒為例來破斥。「克制抵禦」是指以正念遠離過失，這是能對治惡業的行持；「清楚了達」是指明晰辨別業行相貌，這是通達教法的智慧。必須這兩者兼備，才能成就真正的持戒，其餘悠忽漫不經心之態，只不過是泛泛浮善，修學者讀到此處，必須細密推究。「隨行戒體」以下，接著就隨戒生起的法義翻破古說。所指稱的「先前立論」，就是「持犯成就」那一章節。如今祖師必定依據實際造房的動作來闡明，與古說截然不同，所以在此加以痛斥。

【譯文】【疏文】所以在前面先樹立整體法義，後面再藉由事相與法度來彰顯持犯行相，如此便能清晰辨識。

【126-0004】02_戒疏/09a_卷二下之二#80
【原文】【記】次科，生起中。上句結前，餘文生後。「事理」合作「事法」，寫誤。
【譯文】【記文】第二段是承先啟後的發端。上半句總結前面，其餘文句引出後文。原稿中的「事理」二字應當是「事法」，屬於傳抄抄錯。

【126-0005】02_戒疏/09a_卷二下之二#81
【原文】【疏】就房事明持犯者，依教不越名「止持」，驗教知量名「作持」，出於教量名「作犯」，不順教故名「止犯」。此則約其度量，顯其違順，止作持犯，名體各別。
【譯文】【疏文】從造房的事相規模來明辨持犯：依照教制規範不超越尺寸稱為「止持」；審核檢驗教制、明察法定限量稱為「作持」；超出教法所限定的尺寸稱為「作犯」；不順應教法尺寸任意營造稱為「止犯」。這就是依據房舍的長寬度量，來顯明其違逆或順應，此處止、作、持、犯四者，其名相與實體皆各自清晰分明。

【126-0006】02_戒疏/09a_卷二下之二#82
【原文】【記】次分事法中，初科。四行舉要為言：止取離過，望不犯罪，則名「止持」，反成「作犯」；作取修善，望依制法，名曰「作持」，反則「止犯」。方顯四行，名體不濫。「驗」，合作撿。「度量」，即長廣制法。
【譯文】【記文】接著分剖事相與法度，這是第一段。這四種行持提綱挈領來說：止是著眼於遠離過失，望向不犯戒的結果，就稱為「止持」，反之即成「作犯」；作是著眼於奉行善法，望向依循制法而建，就稱為「作持」，反之即成「止犯」。如此方能顯現四行名實不相混淆。「驗」，應當寫作「撿」。「度量」，就是指佛制長度與寬度的法則規制。

【126-0007】02_戒疏/09a_卷二下之二#83
【原文】【疏】次就法論，恐犯教制，如法無違名「止持」，從僧乞法名「作持」，故違不乞名「作犯」，即此違教名「止犯」。此亦名體各別。「止」據無違，「作」據順教，極分明也。若有昧者，翻犯可知。
【譯文】【疏文】其次就求法的羯磨程序來談：唯恐觸犯教法禁令、如法而無違背稱為「止持」；主動向僧團如法乞求作法稱為「作持」；故意違背戒法而不乞求處分稱為「作犯」；當下這份荒廢教法的怠慢稱為「止犯」。這同樣是名相與實體各自獨立分明。「止」是基於沒有違背，「作」是基於順從教法，界限極其明朗。如果還有人茫然不解，只要將犯戒相狀反轉對照，便能了然於胸。

【126-0008】02_戒疏/09a_卷二下之二#84
【原文】【記】後法中，先列四行。「止據」下，重示二持。令「翻犯」者，古謂乞法，但有作持及以兩犯。既存兩犯，必具二持，以翻「作犯」即「止持」故。
【譯文】【記文】後半部探討法度，先列出四種行持。「止是基於」以下，重新提示兩種持戒。文中所說「反轉對照」，是因為古人認為向僧團乞法只有作持以及止作二犯。既然承認有二犯，其背後必定對應具備二持，因為只要反轉「作犯」的本質，即是「止持」的安立。

【126-0009】02_戒疏/09a_卷二下之二#85
【原文】【疏】問：「準此持犯，與前既乖。約事明作，身營可悉，故犯僧殘。約法明作，其相如何？」
【譯文】【疏文】提問：「依照此處的持犯之說，與前面的傳統解釋既有不同。就造房事相而言屬於動作造作，親身營建勞作顯而易見，所以違犯僧殘罪。而就乞請教法而言屬於制度作法，這當中的『作犯』動態相貌又是如何呢？」

【126-0010】02_戒疏/09a_卷二下之二#86
【原文】【疏】答：「此之過量及以不乞，緣雖兩望，果由房結。對相思事，隨有四違，纔一舉手，營搆土木，即有偷、吉四罪隨生。安有過量，偏屬作犯？若如此問，後戒無過，無作犯矣。準此成例，身業是過，約緣分罪，隨多少也。」
【譯文】【疏文】回答：「這超限過量以及不向僧團乞法，所依仗的緣由雖然分屬事與法兩端，但究竟結罪的果報全都是由建造這棟房屋而統攝結成。當面對房舍境界、心中思量營構事務時，只要伴隨有這四種違背，才一舉手動工、營造砍伐泥木，當下便有偷蘭遮與突吉羅四種罪過隨之生起。哪裡會有過量單單偏屬於作犯的道理？若是如你這般詰問，後面的無主大房戒並沒有尺寸限制的過失，豈不就完全沒有作犯了？依照這個常例推論，身業造作即是過咎所在，只是依據所涉及的因緣來分配罪過，隨各人違犯情節的多寡而定罷了。」

【126-0011】02_戒疏/09a_卷二下之二#87
【原文】【記】問中意者，以不乞法，但是不為，何有作犯？故躡前事，相比徵之。答中。初正答。「兩望」，即過重、處分，此謂不乞，還望造房，得有作義。「對」下，次斥偏局，又二。初約多罪難。「對相」即房境。「思事」即行心籌度。事、法，各有止、作兩犯，故云「四違」。「偷、吉」，此約方便，二作犯兩蘭，二止犯兩吉。「若」下，次引後戒例難。此二重難，雖釋前問，乃是對破古師耳。「準」下，結顯。後戒無過，而有作犯，可例此戒，具二作犯。既有二作，則兼兩止，並望身業造作過量，具兼四犯。又復乞、過有無不定，故云「約緣」等也。
【譯文】【記文】提問的深意是：不向僧團乞法，表面上只是單純的不作為，何來動態的「作犯」？所以攀附前述的事相，兩相對比來提出詰難。回答中，起初作正面答覆。「分屬兩端」是指過度超量與未經處分，這是說不乞請法度，終究還是要歸結到實際動工造房上，從而具備了「造作」的意義。「當面對」以下，接著破斥片面狹隘的執著，又分為兩節。首先就同時引發多種罪過來駁難。「對相」就是房舍的境界，「思事」就是造作之心審慎籌劃。事相與法度各自有止犯與作犯，所以稱為「四種違背」。「偷蘭遮與突吉羅」，這是就加行階段而言，兩個作犯結兩個偷蘭遮，兩個止犯結兩個突吉羅。「若是」以下，接著引用後續的無主大房戒作為例證反難。這兩重駁難，表面上是回答前面的提問，實質上是用來徹底擊破古代法師的偏頗見解。「依照這個常例」以下，總結顯明。大房戒沒有超出尺寸的過咎，卻同樣成立作犯，這即可作為此戒兼具兩種作犯的例證。既然具備二作，就同時兼具二止，全都是依託著身業逾矩造作這同一實體，同時具足了四種犯相。況且乞法與超量在具體個案中存廢不一，所以說「依據因緣來分配」等。
