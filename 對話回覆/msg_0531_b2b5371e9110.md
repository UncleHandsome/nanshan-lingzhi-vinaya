### 1. `local_corpus.py` 的 `_add_file()` 會把南山六部書中「含『卷』字的短行」整行刪掉
前面提過 `BOOKS` 走 `_juan_label()` 時有擋掉單獨的 `'卷'`；但載入《業疏》《戒疏》《行事鈔》《義鈔》《尼鈔》《資持記》這 6 部核心書的 **`_add_file()`** 寫成了這樣：
```python
if m and len(s) <= 40 and (_head or _pure) and not s.startswith(('如', '見', '若')):
    _v = m.group(0)
    if _v not in ('卷', '卷第'):
        juan = _v
    continue
```
因為 `JUAN_RE` 後綴全是可選項，任何 `<=24` 字且無標點（或前 6 行 `<=40` 字）的短句／科題只要包含一個「卷」字（例如 `"次釋卷題"`、`"分卷大意"`），雖然 `if _v not in ('卷', '卷第')` 擋住了覆寫 `juan`，**但 `continue` 寫在外面**，照樣會把這行從南山書庫裡直接丟掉。

### 2. `run_pipeline.py` 與 `run_all_books.py` 遇到「批次目錄內的 `STOP`」會誤判成功繼續跑下一關
- `qwen_local.py` 優雅停止時（收到 `SIGTERM` 或批次子目錄裡的 `STOP` 檔），會寫出 `STOPPED.txt`、**不寫 `.stage_partial`**，並以 **exit code `0`** 正常結束。
- 但 `run_pipeline.py` 和 `run_all_books.py` 的 `_stop()` **只檢查專案根目錄的 `B/STOP`**，不會檢查批次子目錄的 `STOP` 或 `STOPPED.txt`。
- 結果：如果你只停止單一子目錄批次（沒在根目錄放 `STOP`），中斷跑一半的 `qwen_local.py` 回傳 `0` 後，管線會以為該階段已 100% 完成，**直接拿跑了一半的缺檔目錄繼續推進下一關**（`merge_long`、`mk_judge_materials` 等）。

### 3. `book_config.py` 的 `book_of()` 判斷順序會把「行事鈔資持記」誤判成《行事鈔》
在 `book_of(path_or_text)` 裡：
```python
if '行事鈔' in p:
    return '行事鈔'
if '資持記' in p or '資持' in p:
    return '資持記'
```
`行事鈔` 排在 `資持記` 前面。只要批次資料夾或路徑名稱出現 `行事鈔資持記`（或未來傳入內文文字判斷），就會搶先命中 `行事鈔`，套用成《行事鈔》的【鈔文】格式與比丘制 note，而不是《資持記》的【記文】規則。
