# 校閱材料　第1051檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1051-0001】資持記/05d_上四#56
【原文】次句別指戒中釋衣時應畜文，彼云：若自恣十日在〔七月六日〕得急施衣，受已，至一月〔無衣〕五月畜〔有衣也，此即時前開十日，後無所增。〕；乃至明日自恣應受〔十五受衣，十六自恣，故言明日。〕，一月五月外，更增九日〔謂初七得衣，前減一日，後增一日；
【譯文】下一句特指戒條中解釋「於衣時應蓄長衣」的文字，彼處說：如果在自恣前十天內〔即七月六日〕獲得急施衣，接受之後，在一個月〔無衣時〕或五個月內蓄持〔有衣時；這就是指在正常衣時前開許十天，其後並無所增加〕；乃至明天就要自恣而今日應當接受〔十五日受衣，十六日自恣，所以說明天〕，一個月或五個月之外，還要再增加九天〔意思是初七得到衣物，前面減少一天，後面增加一天；

【1051-0002】資持記/05d_上四#57
【原文】乃至十五，前減九日，後增九日，故云次第增也。〕；此明十六自恣，合上犍度三日明矣。引〈增三〉中，律云：有三種自恣，十四十五月初日〔十六是黑月初〕。律云下，正定。此亦犍度中文。雖通三日，前二非竟，不符文意，故取十六也。律又下，二釋妨，初引文。
【譯文】乃至十五日得衣，前面減少九天，後面增加九天，所以說是依序遞增〕；這明確顯示了在十六日自恣，完全符合上述犍度的三天之說。引用增三法中，律文說：有三種自恣日，即十四日、十五日與月初第一天〔十六日即是下半月黑月之初〕。從「律云」以下，正式判定。這也是犍度中的文字。雖然通許這三天，但前兩天安居尚未竟期，不符合律文意旨，所以取定十六日。從「律又」以下，第二部分化解妨難，首先引用律文。

【1051-0003】資持記/05d_上四#58
【原文】此出〈尼犍度〉中，恐人固執，故須釋通。此文且約處遠為言；準理，須云僧十五日，尼十六日。又尼近處，不勞隔日；如下文中，雙出二法是也。此下，正釋，初二句釋通。言相依者，疏云：僧須在前自恣，白眾治舉；既犯清淨，方合受尼故。及下，示通局。文既通三，今取十六；亦非專必，故云一期。
【譯文】此處出自〈比丘尼犍度〉中，恐怕有人固執不通，所以必須解釋明瞭。這段文字姑且是針對路途遙遠的情況而言；依照道理，應當說大僧在十五日，尼眾在十六日。又若尼眾住在近處，就不必隔日；正如後面律文中，同時列出兩種行法即是。從「此」字以下，正式解釋，前兩句化解疑惑。說到「相依」，疏中說：大僧必須先在前面自恣，對大眾宣告懲治舉罪；既然罪犯已經澄清恢復清淨，才合乎接受尼眾請法的資格。從「及」字以下，指示通融與局限。律文既然通於三天，現今取定十六日；但也非絕對不可變通，所以說是權宜一期。

【1051-0004】資持記/05d_上四#59
【原文】克，猶約也。恐無知者，前自恣已，出界破夏。今世多然，為過斯久；封懷昧教，聞之不行，深可悲矣！人是非中，列三種人。初先結後破，二一向不結，三結有中後。恐疑上二不可同法，故此辨之，通成應教。文中，初明前二種。《四分》下，示後一種。
【譯文】「克」，如同約束約定的意思。擔心有無知之人，在提前自恣之後，便走出大界而破夏。現今世人多半如此，這項弊端已經存在很久了；心胸蔽塞、昧於教理，聽聞了正法卻不奉行，真是令人深感悲痛！在審查人員是否合法中，列出了三種人。第一種是先結夏而後破夏，第二種是一向不曾結夏，第三種是結夏屬於中安居或後安居。恐怕有人懷疑上面兩種人不可一同行法，所以在此加以辨明，使其全都符合教規。鈔文中，首先說明前兩種人；從《四分律》以下，指示後一種人。

【1051-0005】資持記/05d_上四#60
【原文】但云後者，義必兼中，亦約望前通名後耳。方法中。標云三人者。對法，即眾法對首心念也。僧中又二，六五兩分。初中四門，對下五人，唯第二門，差五德法，雙單有異；餘三竝同。緣起中，初科為二，初示人法分齊。當下，正明緣相，有四，一作相。各下，次敷座。
【譯文】律文中只說「後」，義理上必定涵蓋了「中」，也是相對於前安居而通稱為「後」。行事方法中。標明「三人」者。對應於作法，即是大眾羯磨法、對首法、心念法。僧眾作法中又分兩類，即六人以上與五人。第一類中有四個門徑，相對於下面五人的作法，只有第二門差派具備五德之人的法度，有單獨與成雙指派的差異；其餘三門全都相同。在因緣生起中，第一科分為兩部分，首先指示人數與法度的界限。從「當」字以下，正式說明事緣形態，共有四項：一是鳴鐘作相（發出集僧信號）。從「各」字以下，其次是敷設坐席。

【1051-0006】資持記/05d_上四#61
【原文】準餘法事，床席兩通；獨此自恣，唯局席地。律下，三布草。上二句遮非，下句示法。不在座者，謂所坐席處。不在地者，為護身衣，須以草藉。應離座者，捨席就草也。〔古云互跪者，非。〕然不許在地，義須草上；而文中不明，故引《五分》以決。竝下，四修敬。次科。
【譯文】比照其餘法事，坐床與鋪席兩者皆通；唯獨這項自恣法，完全局限於鋪席坐地。從「律」字以下，第三項是敷鋪青草。上面兩句防範非法，下一句指示作法。所謂「不在座上」，是指大眾原本坐席之處。所謂「不在地上」，是為了保護身軀衣物，必須用青草墊藉。應當離開座位，是指捨棄坐席來到草墊上。〔古代有人解釋為互跪，是錯誤的。〕然而律中既然不許直接坐在地上，義理上必須坐在草上；但文中並未明講，所以引用《五分律》來加以斷定。從「竝」字以下，第四項是修持敬禮。下一科。

【1051-0007】資持記/05d_上四#62
【原文】指同前者，即諸偈詞，及唱告言令；言布薩處，竝須改之。然行事之時，須知次第。至於說清淨妙偈已，即須梵唄，散洒華水，亦須供養。〔有云：說戒須供戒法，自恣不須，非也。此供三寶，豈唯戒法；又自恣法，豈不須供！〕梵唄既畢，說傳香偈已；上座即敘事告眾，選擇德人；
【譯文】指出如同前法者，即是各種偈頌詞句，以及唱告指令的言辭；凡說到「布薩」之處，全部都必須改為「自恣」。然而在行事的時候，必須明瞭先後次第。到了宣說清淨妙偈之後，隨即必須進行梵唄唱誦，散撒香花清水，也必須進行供養。〔有人說：說戒必須供養戒法，自恣則不需要，這種說法是錯誤的。這是供養三寶，豈止單供戒法；況且自恣之法，難道不應當供養嗎！〕梵唄既然完畢，唱誦傳香偈之後；上座比丘便陳述事情告白大眾，挑選具備德行之人；

【1051-0008】資持記/05d_上四#63
【原文】後秉差法，方接下科行事。小眾中，同別二法。同法者，既唱出已，至僧自恣竟，鳴鐘召來，依次坐草，對五德自恣。別法者，送籌入僧已，口差沙彌為五德，餘事竝同僧。五德中。標分二者，其五人法，跨指略法之後，欲彰差法之異。簡人中，初科，上二句雙標。謂下，別釋，初五德中。
【譯文】隨後秉行差派之法，方能銜接下一科來行事。在小眾（沙彌）中，有共同與個別兩種法度。共同行法者，唱令遣出堂外之後，等到僧眾自恣完畢，鳴鐘召請前來，依照次第坐在草上，對著具備五德的人行自恣。個別行法者，將籌送交僧團之後，以口頭差派沙彌擔任五德之人，其餘各項事宜全都與大僧相同。五德之中。標明分為兩種情況者，那五個人的法度，跨越指示在略法的後面，是想彰顯差派法度的差異。在挑選人員中，第一科，上面兩句雙雙標明。從「謂」字以下分別解釋，在最先的五德之中。

【1051-0009】資持記/05d_上四#64
【原文】上四通德，如前篇分房中。下一別德，初約人釋；破夏、不結、前後等人，並應自恣；三舉二滅、抱過不露等，名不自恣。次約時釋，三日是時，餘為非時；增減難事，並須曉故。三約法者，一廣六略；觀緣緩急，並合宜故。疏云：眾雜是非，染淨同住；無宜枉濫，坌污僧倫〔謂知人也〕；知時、知法〔共上為三〕；
【譯文】上面四種通用的德行，如前篇分房篇中所說。最後一種特別德行，首先依據「人」來解釋：破夏、不結夏、中後安居等各類人，都應當行自恣；遭受三舉罪、二種滅檳、懷抱過失不肯發露等人，稱為不可自恣。其次依據「時節」來解釋：十四、十五、十六這三天是正當時宜，其餘日子為非時；日數增減與遭遇危難之事，全都必須通達明瞭之故。第三依據「作法」來解釋：有一種廣說法與六種略說法；觀察因緣的寬緩與緊迫，都必須恰合時宜之故。疏中說：大眾雜亂是非紛紜，染污與清淨者混雜同住；不可枉加冤濫，污染了清淨的僧倫〔這是指明曉鑑別人品〕；知曉時節、知曉法度〔連同上面合為三項〕；
