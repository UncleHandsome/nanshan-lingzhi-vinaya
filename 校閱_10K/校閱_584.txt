# 校閱材料　第584檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【584-0001】02_戒疏/10b_卷三上之一#140
【原文】【記】「一」下，別釋。行輪，又三。初示輪。四依道緣，故曰「資成」。破惑證聖，故云「斷業」。「乃」下，明破。「故」下，引示，有二。「四聖種」即四依法：糞掃衣、常乞食、樹下坐、腐爛藥。聖道由生，故云「聖種」。提婆立五法，破上四依。《律》云：「提婆告三聞達言：『我有五法，亦是頭陀勝，少欲知足、樂出離者，所謂盡形乞食、著糞衣、露坐、不食酥鹽、不食魚肉。我今持此五，教諸比丘，足令信樂。』」、「又」下，《律》云：「佛告優波離：『有二事破僧，妄語、相似語。』」
【譯文】【記文】從「一」往下，分別解釋。破行輪，又分為三點。首先指出法輪本體。四依法是修道的助緣，所以說是「資成」。破除無明煩惱而證得聖道，所以說是「斷業」。從「乃」往下，說明如何破壞。從「故」往下，引用律文昭示，共有兩處。「四聖種」就是四依法：穿著糞掃衣、常行乞食、樹下靜坐、服用陳腐之藥。聖人的道業由此而生，所以稱為「聖種」。提婆達多樹立了五種邪法，藉此推翻破壞前面的四依法。《律》中記載：「提婆達多告訴三聞達說：『我有五種法，也是極殊勝的頭陀行，能令心少欲知足、樂於出離，這五法就是：終身乞食、終身穿糞掃衣、終身露天而坐、終身不吃酥和鹽、終身不吃魚和肉。我現在就持這五種法去教導各位比丘，足以讓大家信服樂從。』」從「又」往下，《律》中說：「佛陀告訴優波離：『有兩件事會導致破僧，那就是虛妄語以及模稜兩可的相似語。』」

【584-0002】02_戒疏/10b_卷三上之一#141
【原文】【記】次釋眾輪。初標示。「說」下，正明。初句示輪，下句明破。「故」下，引證。亦是告波離文。「羯磨」法別，「舍羅」翻「籌」即是事別。此二既別，六和乖矣。所言「輪」者，摧碾惑業，故得名耳。《伽論》局理，《律》通理事。又理論中《論》據八正，《律》約四依，四依道緣，八正道因，兩文互出，義必相兼。
【譯文】【記文】其次解釋眾輪。首先標出。從「說」往下，正式說明。第一句指出法輪僧團之相，下一句說明如何破壞。從「故」往下，引用律文作證。這也是佛陀告誡優波離的經文。「羯磨」各自舉行代表法軌分裂，「舍羅」翻譯為「籌」，分開行籌代表事相分立。這兩項既然分裂，六和敬的法度便蕩然無存了。之所以稱為「輪」，是因為它具有摧毀輾平煩惱惑業的功用，因而得名。《摩得伽論》局限於理體，《四分律》則通貫理與事。再者，在理輪（破理和法輪）的論述中，《論》是依據八正道，《律》則是依據四依法；四依法是修道的資助因緣，八正道是成道的直接正因，兩部文獻互相闡發，義理必定是相互兼具融通的。

【584-0003】02_戒疏/10b_卷三上之一#142
【原文】【疏】上顯兩僧，如何言「破」？亦無別有破。以八正、四依，成僧之法，差此惑亂，應悟不悟，故明「破」也。又此羯磨說戒，是御眾之法，同界各行，互不相成，故明「破」也。
【譯文】【疏文】上面彰顯了理和與事和兩種僧團，怎麼能稱之為「破」呢？其實並沒有另外一個單獨名為「破」的東西。因為八正道與四依法，是成就僧團道業的根本法則，一旦出現了差池惑亂，本來應該覺悟的人反而不能覺悟，所以稱之為「破」。再者，羯磨與說戒是統攝統領大眾的法度，如果在同一個界內各自舉行，彼此互不承認、互不成全，所以稱之為「破」。

【原文】【記】三中。初總徵。「兩僧」即理、事也。「亦」下，別釋。初明破理和僧。「又」下，次明破事和僧。
【譯文】【記文】第三點中。首先總括徵問。「兩僧」就是指理和僧與事和僧。從「亦無」往下，分別解釋。首先說明破壞理和僧。從「又」往下，其次說明破壞事和僧。

【584-0005】02_戒疏/10b_卷三上之一#144
【原文】【疏】二、明體者。有云：「僧和以非色心為體。」《律》中約相，全無出體，以委《論》故。如《律》云：「僧者，四人若過也。」、「僧」義，如《刪補羯磨疏》中廣之。
【譯文】【疏文】第二、說明僧團的體性。有人說：「僧團的和合，是以非色非心法（不相應行法）為實體。」《律》中只從外在事相來說明，完全沒有明言其自體，這是為了交給論典去詳盡發揮的緣故。正如《律》中說：「所謂僧，是指四位比丘或四位以上的比丘。」關於「僧」的深義，在《刪補隨機羯磨疏》中有極其廣泛的闡述。

【584-0006】02_戒疏/10b_卷三上之一#145
【原文】【記】二、明體中。初引示。「非色心」者，即目人假，是「非二」攝。「律」下，指文。初示意。言「委《論》」者，即上所明，出《成論》故。「如」下，正引。「僧義」下，指略。彼有五家，出體不同，今當第二是彼正取，餘四不引，須者自尋。
【譯文】【記文】第二、在說明體性中。首先引述開示。所謂「非色非心」，就是指眾人合和而成的假名假相，歸屬於「非色非心」的不相應行蘊所統攝。從「律」往下，指出律文的表述。首先說明其用意。所謂「交給論典」，就是指前面所明示的，出自《成實論》的主張。從「如」往下，正式引用律文。從「僧義」往下，指明詳情從略。該處有五家古代律師，對於僧體的主張各有不同，現在採用的是第二家，也就是作者本部真正認同的主張，其餘四家不再贅引，需要了解的人可以自行去翻尋查閱。

【584-0009】02_戒疏/10b_卷三上之一#148
【原文】【疏】所言「行」者，無過八正。用譬世輪：語、業、命三，以為戒轂；見、思二正，以為慧輻；念、定二正，以為定輞；方便精進，為轉輪人。若依修行，出生死道，故名「行」也。
【譯文】【疏文】所謂「行法輪」，無外乎就是八正道。可以用世間的車輪來做比喻：正語、正業、正命這三項，作為戒律的車軸中心（轂）；正見、正思維這兩項，作為智慧的輪輻（輻）；正念、正定這兩項，作為禪定的外輪圈（輞）；方便精進的正精進，則是推動轉動車輪的人。如果依此修行，就能跳脫輪迴生死之道，所以稱為「行法輪」。

【584-0010】02_戒疏/10b_卷三上之一#149
【原文】【記】第二，對明，定體中。初科三。初標示。開三學為八正道，一切行相無不攝盡，故云「無過」也。「用」下，喻顯世輪，「轂」在於中，眾「輻」所湊，「輞」在於外，圍於眾輻。即喻戒是定、慧所依，定是慧之外護。「若」下，三、結合。
【譯文】【記文】第二、對照說明，在確定體性中。第一科分為三點。首先標示。將戒定慧三學開展為八正道，一切修行的行相沒有不包含其中的，所以說「無過（無出其右）」。從「用」往下，以比喻來顯明世間車輪，「軸心（轂）」位於正中央，是所有「輪輻（輻）」所匯聚之處，「外圈（輞）」包圍在最外層，圍繞統攝所有的輪輻。這就是比喻戒是定慧所依憑的基石，禪定則是智慧的外在守護。從「若」往下，第三、結名與合喻（結合）。

【584-0011】02_戒疏/10b_卷三上之一#150
【原文】【疏】二、就「教」者，本是一和，今分兩別。以如來法輪，化被三千，該通道俗故也。是以調達唱說「五法是，四依非」，乃至地神、天神唱告「三千世界禪誦不行」。如《鼻奈邪》云：「諸佛常法，食時僧壞，至暮還復。中間天、人無悟道者。天地闇冥。若暮不和，天地翻覆故。」
【譯文】【疏文】第二、就「教法輪」而言，原本是整個僧團的統一步調，如今被撕裂成了兩派。因為如來的法輪，教化廣被大千世界，涵蓋貫通了出家與世俗大眾。正因如此，調達（提婆達多）唱導宣說「五法才是對的，四依法是錯的」，乃至引得地神、天神四處悲痛唱告「大千世界的禪修和誦經正法已經無法推行了」。正如《鼻奈耶律》說：「一切諸佛的常規法則是：僧團在吃飯的時間被破壞分裂，到了傍晚就必定恢復和合。在這破僧的期間，天界與人間沒有任何人能悟道證果。天地一片昏暗冥蒙。如果到了傍晚僧團還不恢復和合，天地就會崩潰顛覆翻轉過來。」
