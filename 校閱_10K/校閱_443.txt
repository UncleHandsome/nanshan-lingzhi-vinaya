# 校閱材料　第443檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【443-0002】02_戒疏/05b_卷二上之一#121
【原文】【記】「初名」下，次牒解。初解標章。「示」，告也。「梗槩」，猶言大略。「雖」下，解釋章。「標」下，解結章。「恐生疑」者，準後釋云「諸大德，我已說」等，是正結章。「若比丘」下，除兩種疑。「不得共住」等，釋同住疑，恐人不曉「不共住」是不住二種僧中故。「後犯亦爾」等，釋重犯疑，恐謂後犯非重故。須此結文，方決前相，故云「若非」等。「收」即正結，「解」對釋疑。
【譯文】【記文】「最初稱為標」以下，接著逐字逐句解釋。首先解釋標章。「示」是告知的意思；「梗概」就是大略的意思。「雖然」以下解釋釋章。「標舉」以下解釋結章。所謂「恐怕生起疑惑」，依照後文的解釋說，「諸位大德，我已經說過了」等句是正式的結章。「若有比丘」以下是除免兩種疑惑：「不得共同居住」等句是為了解釋「如何共住」的疑惑，唯恐大家不明白「不共住」是指不能住在兩類僧團之中；「後面再犯也同樣如此」等句是為了解釋「重犯是否算罪」的疑惑，唯恐有人以為後來重犯就不算重罪。必須有了這段總結的文句，才能徹底裁決先前的各種相狀，所以說「如果沒有總括的收束」等語。「收」就是正面總結，「解」就是對治並釋除疑慮。

【443-0014】02_戒疏/05b_卷二上之一#133
【原文】【疏】言通意者，如上所引，為止毒源。又如《多論》有四義意：一、先作無罪，得除憂悔；二、滅將來非法不起；三、決疑網；四、有十利。
【譯文】【疏文】所謂共通的意圖，正如上面所引述的，是為了杜絕三毒煩惱的根源。又如《薩婆多論》中所說的四種義理意圖：第一、使戒條制定前造作者不獲定罪，得以消除心中的憂傷悔恨；第二、消滅未來的不正當行為，使非法之事不再生起；第三、徹底裁決斷除大眾心中的疑惑蛛網；第四、具有十種利益眾生的功德。

【443-0015】02_戒疏/05b_卷二上之一#134
【原文】【記】次釋章門，婬戒，制意中。「通意」者，義該諸戒，不局婬故。文中二意。初止三毒，指上「教興」。「又」下，次為四義。初義，如須提那最先犯已，常懷憂悔，由佛制戒，知先無犯。次義，即立戒正意。三「決疑」者，以佛制戒，得知輕重、殘無殘、可懺不可懺故。四「十利」者，如下戒緣廣釋。餘制皆爾，故云「通」也。
【譯文】【記文】接下來解釋章節內容中，淫戒，制戒意圖的段落。「共通的意圖」是指其義理涵蓋所有戒條，並不局限於淫戒。文中有兩層意圖：首先是止息三毒，這指引見於上文的「教興門」；「又如」以下是第二層，分為四種義理。第一種義理，例如須提那最先破戒之後，內心常常懷抱著憂傷與悔恨，由於佛陀隨後制定了戒條，他才知道在制戒之前造作是不算犯戒的。第二種義理就是立戒的主要意圖。第三「裁決斷除疑惑」，是因為佛陀制定了戒相，大家才能知道罪過的輕重、是僧殘還是非僧殘、是可以懺悔還是不可懺悔。第四「十種利益」，正如後文在戒條緣起處所廣泛解釋的那樣。其餘戒條的制定也全都是這樣，所以稱為「共通」。

【443-0020】02_戒疏/05c_卷二上之一#1
【原文】【疏】言「不淨行戒」者。愛染汙心，名為「不淨」。隨染境界，汙淨戒品，故名為「行」。「行」，即業也，謂所防之罪。「戒」者，能治之行。能所通舉，故曰「不淨行戒」。
【譯文】【疏文】講到「不淨行戒」這個名稱：貪愛染污的妄心，就叫做「不淨」；順著染污的外境而動身造作，玷污了清淨的戒體，所以稱為「行」。「行」就是造作的業，指戒律所防範的罪過；「戒」則是能對治這種罪過的修持行法。將「能防的戒」與「所防的罪」合併標舉，所以稱為「不淨行戒」。
