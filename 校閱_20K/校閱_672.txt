# 校閱材料　第672檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【672-0001】資持記/16e_下四#9
【原文】不問等者，顯僧海深，廣無不攝也。不受法，即無戒也。七中。〈隨相〉事多，且出一條特異之者。初明行懺違法開成。更下，次開不懺，直得清淨。此六種人，初二恐壞眾信，為護法故；三四身心怯弱，為接引故；五六行法闕緣，為命難故。心念懺悔，即復本淨，後不須悔；
【譯文】經文中說「不論」等語，是為了彰顯僧海的深廣，浩大得無所不包。所謂「不受法」，就是指沒有受持戒法。在第七部分中，〈隨相釋罪篇〉的事項非常繁瑣，此處暫且列出一條極為特殊的規定。首先說明懺悔作法雖有違律制，但仍開許其懺罪成立。在「更」字以下，接著開許不須經由懺罪程序，直接恢復清淨。這六種人當中，前兩種是擔心敗壞信眾對佛法的信心，為了護持大局之故；第三、第四種是由於身心怯弱，為了接引攝受之故；第五、第六種是因為行持懺法時缺少外在因緣，為了避開生命危難之故。他們只要在內心起念懺悔，就能恢復本有的清淨，日後也不需要重新發露懺悔；

【672-0002】資持記/16e_下四#10
【原文】若準《四分》，一切不成。律下，引注伸誡，遮後倚濫；唐，虛也。第三批文，為三；初年月等，記其時也；且閉戶者，即終南苧麻蘭若，此記處也；但下，即彰述作之本。祖師降生於隋世，弘化于唐朝；高祖神堯皇帝受隋恭禪位，始號唐國，改元武德。九年六月，絕筆時也。
【譯文】如果依照《四分律》的通則，這些作法全都不算成立。在「律」字以下，引述夾注來申明誡勉，以防後人隨意依傍而濫用開緣；「唐」字的意思是虛設。第三段題跋的文字，分為三個層次：首先說明年代與月份等，是記錄寫作的時間；所謂「暫且閉門」，是指在終南山的苧麻蘭若，這是記錄寫作的地點；在「但」字以下，則是表明撰寫這部論著的根本旨趣。道宣祖師誕生於隋代，並在唐朝弘揚教化；唐高祖神堯皇帝接受隋恭帝禪讓皇位，建國號為唐，改年號為武德。武德九年六月，正是此書最終撰畢停筆的時間。

【672-0003】資持記/16e_下四#11
【原文】爾前太史傅奕，黨助道宗，誣謗釋氏，奏請沙汰，高祖依之；於是抱道碩德，遁于巖野；故祖師隱于終南苧麻蘭若，首撰此鈔；至九年，太宗復興吾教，搜揚有德；祖師是輔相之子，道德著聞，皆被搜選，故云爾時等。俗譽，此謂俗中聲譽，無所傷也。言閉戶者，明避難也。依所學者，彰有承也。
【譯文】在此之前，太史令傅奕偏袒道教，誣蔑毀謗佛教，奏請高祖淘汰沙門，高祖准許了他的奏請；於是懷抱道風的大德高僧，紛紛隱匿於深山荒野之中；因此道宣祖師隱居在終南山的苧麻蘭若，開始撰寫這部《行事鈔》；到了武德九年，唐太宗重新興隆佛教，搜訪提拔有德行的高僧；祖師原是宰相之子，道德學問顯著聞名，也被朝廷搜訪選拔，所以才說「在那個時候」等語。文中所稱的「俗譽」，是指世俗間的聲望名譽，並無損於道業。所說的「閉門」，是說明為了避開教難。提到「依照所學」，是彰顯自己的傳承有憑有據。

【672-0004】資持記/16e_下四#12
【原文】但下二句，述本志也。直筆書者，不演義章；刪除異論，離諸曲碎故。不下二句，示謙損也。龍身有文彩者，謂之虬。語澁故蹇，文鄙則陋。想下二句，囑審悉。有識謂智高，通士謂鑒遠。文多記字，疑是傳錯。
【譯文】在「但」字以下的兩句，是記述原本的志向抱負。所謂「直率下筆書寫」，是指不鋪陳瑣碎的義理章句；直接刪除歧異紛雜的言論，遠離各種曲折繁碎的枝節。在「不」字以下的兩句，表現出謙遜退讓的美德。龍身上有彩色斑紋的，稱為「虬」。言語蹇澀所以顯得遲鈍，文字質樸就顯得簡陋。在「想」字以下的兩句，是囑咐後人詳細審度明察。有識之士是指智慧高超的人，通達之士是指見識遠大的人。鈔文文句中多出了一個「記」字，懷疑是傳抄時產生的訛誤。
