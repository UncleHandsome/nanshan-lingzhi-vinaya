# 校閱材料　第057檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【057-0001】01_行事鈔/04a_卷上之四#18
【原文】維那後來打靜一下，云：「次行沙彌籌。」三說已。有沙彌者，徑往坐所行之，并取囑授者。乃至僧中一遍通告，云沙彌籌，或有大僧將欲來者。如是收已，依前付數。維那復至上座所，互跪取數，時上座當告云：「僧有若干，沙彌若干，都合若干。」維那即起打靜云：「大德僧聽！此一住處一布薩。大僧若干，沙彌若干，都合若干人；各於佛法中清淨出家，和合布薩；上順佛教，中報四恩，下為含識；各誦經中，清淨妙偈。」《僧祇》說云：「清淨如滿月，清淨得布薩，身口業清淨，爾乃應布薩。」若沙彌別處說戒，如後〈別法〉。
【譯文】維那隨後擊打靜槌一下，說：「接下來分發沙彌籌。」宣告三遍之後。有沙彌在場的，便直接前往其坐處分發，並且收取受委託轉交之籌。乃至在僧中全面通告一遍，宣稱是發放沙彌籌，使受沙彌囑託之大僧得代受籌，亦防行籌之際或有大僧即將後至者（得於此時補受大僧籌）。如此收取完畢後，依照前面的做法呈交計數。維那再次來到上座處，互跪獲取清點數目，此時上座應當告知說：「大僧有若干人，沙彌有若干人，合計共若干人。」維那隨即起立打靜說：「大德僧聽！在此一共住處舉行同一布薩。大僧若干人，沙彌若干人，合計共若干人；各自在佛法之中清淨出家，和合舉行布薩；上順佛陀教誨，中報四重深恩，下為一切有情；各自誦讀經中的清淨妙偈。」《僧祇律》說應唱云：「清淨如滿月，清淨得布薩，身口業清淨，爾乃應布薩。」如果沙彌在另外處所說戒，做法如後面的〈別法篇〉所載。

【057-0002】01_行事鈔/04a_卷上之四#19
【原文】七明請說戒師。佛令上座說戒，縱前已別差，終須前請。應至上座前，具修威儀已，合掌白言：「大德慈悲！為僧說戒。」若堪說者：「此說戒事正當我作。」便即唱之。若不堪者云：「但此說戒，任當某甲；但為老病，言辭濁鈍，恐惱眾僧；令次座說。」即至次座亦如前請。若辭不說者，應至上座云：「次座亦辭不堪。」上座先預知有誦利者，應語維那，至某甲所云：「僧差說戒。」彼至前所，具述已，還至打靜處，陳告之。若次座不堪，不須次第問下；準上《僧祇》，但得次座也。彼應告僧言：「大德僧聽！僧差律師某甲，為僧誦律；梵音某甲，律師升高座。」彼應具儀至僧中，四面禮僧已，互跪白言：「小比丘某甲，稽首和南，敬白眾僧：僧差誦律，恐有錯誤，願同誦者，指授。」白已，一禮，升座。
【譯文】第七、說明迎請說戒師。佛陀敕令由上座說戒，縱然事前已經另行差派他人，終究必須先行迎請上座。維那應當來到上座面前，具足修持威儀之後，合掌陳白說：「大德慈悲！請為僧眾說戒。」如果上座堪能宣說，便說：「這說戒之事正應當由我來作。」隨即宣告答應。如果不能勝任，便說：「這說戒的責任，本應當由某甲承擔；只是因為年老多病，言語濁鈍，恐怕擾惱大眾；請讓次座宣說。」維那便隨即前往次座面前，如同前面一樣迎請。如果次座也推辭不說，應當回到上座處稟白說：「次座也推辭不堪勝任。」上座若預先知曉有熟練流利誦戒之人，應當告訴維那，前往某甲處說：「僧團差派您說戒。」維那前往其人面前，具體轉述完畢後，返回打靜處，向僧眾陳詞宣告。如果次座不堪勝任，不需要依序逐一往下詢問；準照上述《僧祇律》，只能推至次座。維那應當宣告僧眾說：「大德僧聽！僧眾差派律師某甲，為僧眾誦律；由某甲領作梵音，請律師升高座。」那名說戒比丘應當具足威儀來到僧眾中央，面向四方頂禮僧眾後，互跪陳白說：「下座比丘某甲，稽首和南，敬白大眾僧：僧團差派我誦律，恐有錯誤紕漏，懇願一同誦戒者，予以指明教授。」陳白完畢，禮拜一次，然後登上高座。

【057-0003】01_行事鈔/04a_卷上之四#20
【原文】八明供養說戒法。若有高座最善；無者，在聖僧座上，抽聖僧座在下。彼說戒者坐已，維那打靜，小者供養，梵唄作之。若準律文，唄匿如法。《出要律儀》云：如此欝鞞國語，翻為止斷也，又云止息。由是外緣已止已斷，爾時寂靜，任為法事也。彼三五年少比丘持香水，僧前左右灑水；留中空處，擬行來也。香湯及華，亦同水法。散灑已，餘有中央；當持水華合著一槃，總從一頭，却行布散，使及兩邊。空器復本處。使人復座。當散華時，各說偈云，《華嚴經》云：「散華莊嚴淨光明，莊嚴寶華以為帳，散眾寶華遍十方，供養一切諸如來。」彼供養者，待散華已，然後作禮。三捻香已，執鑪，向上座所坐方，互跪，炷香鑪中。維那云：「行香說偈。」此法安師每有僧集，人別供養；後見繁久，令一人代眾為之。廣如本文。各說偈言，《華嚴》云：「戒香定香解脫香，光明雲臺遍法界，供養十方無量佛，見聞普熏證寂滅。」維那打靜訖，供養者復座，維那仍本位。
【譯文】第八、說明供養說戒之法。若設有高座最為妥善；如果沒有，就在聖僧座（僧首位或賓頭盧座）上說戒，而將聖僧座抽換移至下方。那名說戒者坐定之後，維那擊打靜槌，由下座比丘行供養，並作梵唄。若準照律文，唄匿（讚唄之聲）應當合乎法度。《出要律儀》說：這相當於鬱鞞國語（梵語），翻譯為「止斷」，又說是「止息」。由於種種外緣已經止息斷除，此時大眾寂靜肅穆，正堪承辦各項法事。那三到五位年少比丘手持香水，在僧眾前方左右灑水；留下中央空處，預備供人行走往來。香湯與散花，也依照灑水之法辦理。散花灑水之後，剩餘中央通道；應當手持水與花合放在一個盤中，總括從一頭開始，倒退行走分布散灑，使兩邊都能遍及。騰空的器皿放回原處。執事人歸座。當散花之時，各自宣說偈頌，《華嚴經》說：「散華莊嚴淨光明，莊嚴寶華以為帳，散眾寶華遍十方，供養一切諸如來。」那些行供養的比丘，等待散花完畢後，然後禮拜。三次捻香之後，手持香爐，面向著上座所坐的方向，互跪，將香插入香爐中。維那唱道：「行香說偈。」此法在道安法師時，每當有僧眾集合，每個人各自單獨行供養；後來見其過於繁瑣耗時，便令一人代表大眾行之。詳情如其原文所載。各自宣說偈頌，《華嚴經》說：「戒香定香解脫香，光明雲臺遍法界，供養十方無量佛，見聞普熏證寂滅。」維那打靜完畢，行供養的人歸座，維那仍回到原本的位處。
