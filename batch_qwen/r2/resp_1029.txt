以下逐則核對，並把問題分成「明顯誤譯」「語意失準／可斟酌」「潤飾過度」三類。整體而言譯筆流暢、科判術語（「若下」「示下」「故下」）處理正確，但有幾處**主語誤植、術語誤認、以及把「律文」一律寫成「經文」** 的系統性毛病，需要修正。

## 一、逐則檢查

### 【1029-0001】

1. **「疏云」逕譯為「戒疏」——出處待考。** 《資持記》引「疏」或為《戒本疏》、或為《羯磨疏》（業疏）。此段講的是「尼來請教誡、上座不能對答」，屬教誡尼法，判為《戒疏》並無明證。建議保留作「疏中說」，或查證後再標書名。
2. **「等經文」→應作「等律文」。** 《善見》（善見律毘婆沙）、《十誦》、《僧祇》全是律典／律釋，不是經。
3. **「指廣法中」譯得太含糊。** 此處「廣法」與前文「略教」相對，特指**廣教誡（廣教授尼法）**，不是泛指「廣泛儀軌」。建議：「這是指『廣教誡法』而說。所謂『時希』（時機稀少），即〈尼篇〉所說……」。
4. 「曾不對答」譯「竟然不知如何對答」略增語意，原意是「竟不能應對答覆」；「識者齊恥」的「識者」是**有識見之人同感羞恥**，不必限定為「識法之人」。
5. 「何啻」可補本義「何止」，讀者才知道何以訓為「德有餘」。

### 【1029-0002】

1. **「在文可見」「指證」不宜譯成「經文條文」「經典依據」。** 這裡的「文」是指 **《行事鈔》本文**，「指證」是引出證明（下文即引《四分律》），與「經」無關。
2. **「遮濫」譯「防止浮濫偽造」——「偽造」是添出来的。** 遮濫＝遮止混濫（避免與古羯磨混用），建議「防止混濫」。
3. **「二名無異」宜點明所指**：即「布薩（梵）」與「說戒（華）」二名同義；下文「華梵齊舉」正是承此而斥。譯文只說「兩種名稱」，讀者無法與下句連貫。
4. **「三十四卷初」宜標明《四分律》**，「律藏第三十四卷」太籠統。
5. 「事宗」譯「明了作事原則」可斟酌：此科與文末「雜相」相對，指的是**說戒行事的主體正軌**（十科行事），建議「正明行事（事宗）」。
6. 「一律儀」譯「一種律儀」偏字面，宜作「同一（統一）的律儀規範」，並保留原詞待考。

### 【1029-0003】

1. **「唱告時處」譯成「唱名宣告時間地點」——「唱名」錯。** 唱告＝宣告、白告，不是唱名點名。
2. **「又應知廣誦五篇戒」譯成「知曉何時詳盡誦讀」——「何時」是無中生有。** 原文是「應知（如何）廣誦五篇戒」。
3. **「下至四事及偈」**：下至＝最少也要；「四事」宜註明即**四波羅夷**。譯作「甚至減少到」語氣略偏。
4. **「餘者僧常聞」是略誦時的表白語**（誦至四事及偈後，向其餘戒條作交待：「其餘的，僧眾平常都已聽聞」），譯文寫成「其餘篇幅則為僧眾平日所常聞」，變成客觀敘述，失了「制上座應如此說」的意思。
5. **「上座」「第二上座」不宜譯為「首座」。** 首座是禪門職稱，律中「上座」指臘高主持之長老，且與【1029-0004】的「第二首座」用法一併改回較妥。
6. 「行籌」譯「發放籌碼」——「籌碼」今義近賭具，宜作「分發（計數用的）籌」。
7. 「後來已即去」主語是難陀，白話可補出，免與「大眾」混淆。

### 【1029-0004】（此則問題最嚴重）

1. **「為彼慚愧者，攝諸不慚愧」譯文加了主語「如來」——誤。**
 依注文判讀：前二句〔此舉世喻〕、次二句〔為善攝惡〕屬**世喻**（神仙咒術），後二句〔合上喻也〕才是**合法**（如來立戒）。譯文提前把「如來」放進喻中，喻／合結構被打亂。應譯：「（那咒術）是為了有慚愧心的人，用以攝伏無慚愧的人」。
2. **「為善攝惡」譯「為了揚善並攝伏惡劣者」——「為善」是「為了善人」，不是「揚善」。**
3. **「神仙五通人」譯句語法不通**：「神仙具備五種神通的人」應作「具足五通的神仙（仙人）」。
4. 「無上如來立下嚴謹的禁戒」——「無上」「嚴謹」皆原文所無；「造設於咒術」加「世間的」也可省（注文已說世喻）。

### 【1029-0005】

1. **「即序初二偈」譯「戒序」，與前則「律序」不一致。** 兩處同指《四分律》卷首之律序（「稽首禮諸佛……諸賢咸共聽」正在律序開頭），應統一作「律序」。
2. **兩個「前唄」指涉不同，譯文都寫成「前一個梵唄」會混淆。**
 - 《尼鈔》「若不解前唄」的前唄＝**前文剛引的那首**（神仙五通人偈）；
 - 「因示前唄。即序初二偈」的前唄＝**說戒之初所唱的那首**。
 建議分別明寫。
3. **「止息」譯「終止休息」——誤。** 律中作唄的「止息」是**止息喧動、令眾寂靜**。另此句斷句可作「不同前作，為止息故」，語意須依鈔文再確認，但不論哪種讀法，「終止休息」都不對。
4. 「親身證果的聖者」尚可；「確鑿的信證」的「確鑿」是添飾。

### 【1029-0006】

1. **「二中」「三中」**：指偈頌次第，宜作「第二偈中」「第三偈中」，「第二段」太泛。
2. **「正乖法律」譯「正好違背了戒律法規」**——「正好」今義為「恰巧／剛好」，易生歧義，宜作「恰恰違背律制」。
3. **「雖非大害」譯「不算滔天大禍」——過度誇張**，原意只是「雖無大損」。「寧免無知」的「無知」在律中是「不學無知」之罪，可加註。
4. 「四並言快」的「四」承上「上三句、下句」而來，指該偈四句，譯文作「四句話」可通，但建議明寫「（此偈）四句都說到『快』」，並核對鈔文偈數。
5. 「舉事誡眾」譯「舉出眼前大事」——「眼前大」是添飾。

### 【1029-0007】

1. **「故云寂滅」譯「所以說是寂靜止息」——術語流失。** 這裡是在解釋偈中為何用「寂滅」一詞（與「安隱」對舉），應保留原詞：「所以稱為『寂滅』」。
2. **「並據正文」譯「正統經文」——同前，應作「（四分）律的正文」。**
3. **「下一喜他」譯「利益他人」失「喜」義**，宜作「後一句是慶喜（隨喜）他人」，才與「上三慶己」對仗。
4. 「況經聖心」的「聖心」所指（佛陀制律？南山祖師編排？）宜覆核，逕譯「聖人」略嫌含糊。
5. 「極為安隱」的「極為」可省。

### 【1029-0008】

1. **「或多輕略」譯「有的人多數輕忽略過」語意不順。** 「或」＝有人，「多」＝往往，「輕略」＝輕忽簡略。建議：「有人往往輕忽簡略，擱置而不實行」。
2. **「事起臨機」譯「面臨各種隨機變化」**——「隨機」今義太強，宜作「臨時應機而生的事務」。
3. 「且據一途」譯「暫且依照常規途徑的一端」稍拗，可作「只是就一般常規的作法而說」。
4. 其餘（業繩、苦海、天齡、厭課）處理得當。

## 二、貫穿全篇的系統性問題

| 類型 | 說明 | 建議 |
|---|---|---|
| **「文」一律譯成「經文」** | 0001「等經文」、0002「經文條文／經典依據」、0007「正統經文」 | 本段全是律學文獻：鈔文＝《行事鈔》本文；正文＝律典正文；引書皆律。一律改「律文／鈔文」 |
| **術語被口語化取代** | 寂滅→寂靜止息、上座→首座、籌→籌碼、唱告→唱名 | 專有名詞保留原詞＋括號簡註，勿用近義白話詞替換 |
| **前後稱名不一致** | 律序／戒序；首座／首席；前唄兩義同譯 | 統一 |
| **形容詞、副詞膨脹** | 滔天大禍、無上、嚴謹、殊勝、極為、確鑿、眼前大事、隨機 | 律疏文體簡峻，白話宜克制，避免把「非大害」放大成「滔天大禍」這類反向失真 |
| **偈頌主語與喻合結構** | 0004 誤加「如來」 | 譯偈務必先依注文判定喻／合、能／所，再補主語 |
| **可補的義註** | 二名（布薩／說戒）、四事（四波羅夷）、五篇、三十四卷（《四分律》）、廣法／略教、時希 | 適度加註，讀者才接得上前後科判 |

## 三、優先修改建議（若只改五處）

1. 【0004】刪去「為彼慚愧者」句的「如來」，並改正「為善攝惡」＝為善人而攝惡人。
2. 【0005】「終止休息」改為「止息喧鬧、令眾寂靜」；「戒序」改「律序」。
3. 【0003】「唱名」刪；「何時」刪；「餘者僧常聞」還原為表白語。
4. 全篇「經文」改「律文／鈔文」。
5. 【0001】「指廣法中」明譯為「廣教誡法」，與「略教」對顯。
