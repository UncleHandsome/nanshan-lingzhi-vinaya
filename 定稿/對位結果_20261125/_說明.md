# 對位結果（合編本句級對位）

此資料夾是「行事鈔 × 資持記 句級合編」的對位來源資料，與 `定稿/` 同層保存，屬網站生成資料的一部分。

## 檔案
| 檔案／目錄 | 內容 |
|:--|:--|
| `pairs_v2.jsonl` | 每行一個對位方向（鈔→記、記→鈔），含 type／why |
| `pairs_v2_index.json` | 索引 `{chao: {key:[記…]}, ji: {key:[鈔…]}}`，**合編網站直接讀這份** |
| `pairs_v2_統計.md` | pair 數、覆蓋率、orphan、未對到的記段等統計 |
| `seg_groups.json` | 575 等長鈔段的句段細配（168 鈔段，記段全部對映） |
| `pian*.jsonl` | 各篇的對位結果（pian00 序、pian01…pian30、二衣 part01/02、隨戒釋相 part01–05） |
| `回/` | 對位模型的原始回覆（resume／重跑用） |
| `_人工回填_*.jsonl`、`AA.txt`、`_AA_part0*.txt` | 人工裁決與回填資料 |
| `run.log`、`progress.jsonl`、`usage.json` | 對位執行記錄 |

## 用途
- 網站：`_src/site_hebian2.py` 讀 `pairs_v2_index.json`＋`seg_groups.json` 產生 `docs/hebian/`。
- 材料：`_src/build_seg_materials.py` 讀 `seg_groups.json`／`pairs_v2_index.json` 產生句段細配材料。

## 維護
- 由 `_src/mk_pairs_v2.py`（合併 pian*.jsonl）、`_src/ingest_align_window.py`（匯入對位回覆）、`_src/ingest_orphan_fill.py`（orphan 回填）、`_src/ingest_seg_replies.py`（句段細配回覆）產生／更新。
- 路徑已改為 `定稿/對位結果_20261125/`；相關腳本內的常數已同步更新。
- 不要手動改 `pairs_v2_index.json`／`seg_groups.json`：改資料請走上述腳本或重新生成。
