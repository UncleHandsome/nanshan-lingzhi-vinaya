# 校閱材料　第1789檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1789-0001】03_業疏/15b_卷三之四#74
【原文】問：無作是色，色即是礙，復對意根，即是障對，如何上言出三有對？答：障對有二義：一者、能所俱對色故，二者、能所兩緣俱障礙故。如眼唯見色、不聞聲故，名障礙有對。無作不爾，雖對意根通緣非礙，色、非色別，故非障對
【譯文】問：無作戒既然是色法，色法就是質礙，它又相對待於意根，那就是障礙有對，為何上面說它超出三種有對之外？答：障礙有對有兩種涵義：第一是能對與所對二者俱是相對待之色法之故，第二是能緣與所緣二者都有障礙之故。比如眼根只能見色法、不能聞聲音，所以稱為障礙有對。無作戒並非如此，雖然相對待於意根，但意根普遍攀緣而沒有障礙，能緣的心與所緣的色有所差別，所以不是障礙有對。

【1789-0002】03_業疏/15b_卷三之四#75
【原文】次難問中，初二句承上答文，次二句躡前三色中判在法入，故「對意根即是障對」者，障即是礙，雙括兩文難前無對。答中初汎敘對障：初義五根是能，五塵為所，二並是色，此即對義也；次義五根不能互緣，五塵不能互入，文舉眼根，餘四例爾，此即礙義也。「無」下正通來難。「雖對意根」等者，能通而所礙，反上次義，意根通緣落謝五塵，如前已說；「色非色別」者，能心而所色，反上初義，故非障對。雙結兩非，故出有對也
【譯文】在第二個難問中，前兩句承接上面的回答文字，後兩句承接前文三色中將其判定在法入，所以說「對待意根即是障礙有對」，「障」就是礙，總括這兩處文意來詰難前面所說的「無對」。回答中首先通泛敘述對與障：第一種涵義是五根為能緣，五塵為所緣，二者都是色法，這就是「對」的涵義；第二種涵義是五根不能互相攀緣，五塵不能相互混入，文中舉出眼根，其餘四根也是如此，這就是「礙」的涵義。「無」字以下正式通達解答來難。「雖對意根」等句，是說能緣圓通而所緣有礙，反乎上述第二種涵義，意根普遍攀緣過去落謝的五塵影子，如前面已經說過；「色、非色別」，是說能緣是心法而所緣是色法，反乎上述第一種涵義，所以不是障礙有對。同時結斷這兩種不符合之處，所以說它超出了有對的範疇。

【1789-0004】03_業疏/15b_卷三之四#77
【原文】自金河已後，名教互張，五部、十八隨機而舉，各謂指南，皆通經論。年代綿遠，餘執漸離，唯婆多、正量、上座、大眾斯之四宗，今盛西域。此方所傳，四部乃翻；今時弘者，曇無德部、薩婆多部最為殷矣
【譯文】自從佛在金河入滅之後，各家名言教法競相鋪展，五部、十八部隨順根機而立說，各自號稱為指南圭臬，全都精通經論。隨著年代久遠，其餘的部派執見逐漸離散凋零，只有薩婆多部、正量部、上座部、大眾部這四個部派，如今盛行於西域。此方所傳入的，共翻譯了四部律；如今弘傳的，以曇無德部與薩婆多部最為盛行。

【1789-0005】03_業疏/15b_卷三之四#78
【原文】三列異執法執中初科為二：初敘西竺分宗。「金河」者，河中產閻浮金故以為名，在拘尸城西北三四里，西至娑羅林不遠，即如來入滅之處，謂佛滅已來也。「名教互張」，此句總舉四位分部。佛初滅度，迦葉結集，即分二部：一上座部，窟內五百羅漢集者；二大眾部，窟外千人集者。一百年後分為五部，四百年後分十八部。下云「餘執漸離」，即五百部。「隨機舉」者，推分派之由。「各謂指南」，明所見之異。「皆通經論」，示所宗也。「綿」即是長。「婆多」是五部之一，「正量」即十八中一，「上座、大眾」即根本二部。「此」下次明此方傳譯。初明翻度，言四部者，《僧祇》本部之一，《十誦》、《五分》、《四分》即五部中三。「今」下次示弘傳，二部最殷，即空、有二宗，「殷」即訓盛
【譯文】在第三列出異執中的法執第一科中分為兩部分：首先敘述西土印度分立宗派。「金河」，是因為河中產閻浮檀金所以以此為名，位於拘尸那城西北三四里處，往西到娑羅雙樹林不遠，就是如來入滅的地方，也就是指佛滅度以來。「名教互張」，這句話總括列舉四個時期的分部情況。佛剛滅度時，大迦葉結集，便分出兩部：一是上座部，在窟內由五百位羅漢結集；二是大眾部，在窟外由千人結集。百年之後分裂為五部，四百年後分裂為十八部。下文所說的「其餘執見漸漸離散」，是指五百部。「隨機而舉」，是推究分立宗派的緣由。「各自號稱指南」，是表明各派見解的差異。「全都通達經論」，是標示各派所宗仰的根據。「綿」就是悠長。「婆多（薩婆多）」是五部之一，「正量」是十八部之一，「上座、大眾」是根本二部。「此」字以下接著說明此方漢地的傳譯。先說明翻譯，所說的四部律，《摩訶僧祇律》是根本部派之一，《十誦律》、《五分律》、《四分律》則是五部律當中的三部。「今」字以下接著標示弘傳情況，以曇無德部與薩婆多二部最為盛行，也就是空、有二宗，「殷」就是盛大的意思。

【1789-0006】03_業疏/15b_卷三之四#79
【原文】然諸講士，偏競不倫，各尚學宗，尠懷通量。自晉南遷，迄于陳世，釋門義府多師《成實》；彼土傳律，偏弘《十誦》，以假名宗出有部體。中原擾攘，聲教奔飛，元魏、高齊大弘《心論》，便依多、雜出《四分》體
【譯文】然而各位講經論的法師，偏狹爭勝而不相上下，各自崇尚自己所學的宗派，很少有人胸懷融通全局的識見。自從西晉南遷，一直到陳代，佛門的義理學府大多以《成實論》為宗師；江南一帶傳授戒律，偏向弘揚《十誦律》，竟用假名宗（成實宗）的觀點來立有部律的戒體。北方中原動盪混亂，正聲與教化顛沛流離，元魏、高齊時期極力弘揚《阿毘曇心論》，便依照《薩婆多論》、《雜心論》的觀點來立《四分律》的戒體。

【1789-0007】03_業疏/15b_卷三之四#80
【原文】別示此方中初科，初敘偏執。「倫」，等也。「各尚學宗」，黨所習也。「尠懷通量」，無大見也。「自」下次敘宗亂。初明南朝，古晉自宣帝至愍帝凡七帝，皆都中原，至元帝渡江南始鎮建業凡十一帝，自此分東西兩晉。自東晉及宋、齊、梁、陳並都江南，故云「南遷」等。義府即學舍異名。彼弘《十誦》，乃準《成論》立色為體。「中」下次明北朝。中原即京兆，自西晉已來分為十六國，故云擾攘，即罹亂也。「奔飛」謂零替也。元魏、高齊並都於彼，元是魏姓，簡曹魏、拓䟦魏；高亦北齊之姓，簡南齊蕭氏。彼弘《四分》，乃依《雜心》、《多論》立非色心為體
【譯文】在分別開示此方漢地的情況中，第一科首先敘述偏執。「倫」，就是齊等。「各自崇尚所學宗派」，是偏袒自己所習學的內容。「很少胸懷通融器量」，是缺乏宏大的見識。「自」字以下接著敘述宗派混亂。先說明南朝，古代西晉從司馬宣帝（追封）到愍帝共七位帝王，都建都於中原，到了晉元帝渡江南渡才鎮守建業共十一位帝王，自此分為東晉與西晉。從東晉以及宋、齊、梁、陳都建都江南，所以說「南遷」等。義府就是義學修持道場的異名。南朝弘揚《十誦律》，卻依照《成實論》立色為戒體。「中」字以下接著說明北朝。中原指北方關中京兆一帶，從西晉以來分裂為十六國，所以說擾攘，就是遭遇禍亂。「奔飛」是指零落衰微。元魏、高齊都建都於北方，元是元魏的皇室之姓，用以簡別曹魏與拓跋魏改姓前；高也是北齊的皇室之姓，用以簡別南齊蕭氏。北方弘揚《四分律》，卻依照《雜心論》、《薩婆多論》立非色非心為戒體。

【1789-0009】03_業疏/15b_卷三之四#82
【原文】次科，碩學者，美其通博，未知何人。此師即依《成實》出《四分》體，準多、雜出《十誦》體，故云「通觀兩宗」等。前文定宗，即準此師
【譯文】第二科，所謂「碩學」，是讚美他通達博洽，不知具體是哪位法師。這位法師就是依據《成實論》立《四分律》的戒體，依照《薩婆多論》、《雜心論》立《十誦律》的戒體，所以說「通觀兩宗」等。前面文中判定宗屬，就是依準這位法師。
