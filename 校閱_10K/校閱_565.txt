# 校閱材料　第565檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【565-0001】02_戒疏/09d_卷二下之二#92
【原文】【疏】就注解中，分三：從初至「無者應與」來，商度彼人堪可進不；二、「眾中應差」下，至「如是持」來，明與白二之相也；三、「彼作房」下，明作成分齊也。相中可解。
【譯文】【疏文】在隨文注文的解釋中，分為三部分：從最初到「無者應與」為止，是審查評量該比丘的德行是否可以准許進展；第二部分從「眾中應差」以下，直到「如是持」為止，是說明給予處分的白二羯磨具體儀式相貌；第三部分從「彼作房」以下，是說明造房完成的判定界限。其中的文相很容易理解。

【565-0002】02_戒疏/09d_卷二下之二#93
【原文】【記】第八，釋注。云「相中可解」，即指三科文相。然第二與白二中，先列四位，簡能秉人。上二約臘次，下二取智能。「不誦律」者，但解義故。以舉法被事，必曉如非，律擇堪能，不容妄作。
【譯文】【記文】第八段在解釋注文。所謂「文相中容易理解」，就是指這三個科判的文理。然而在第二部分給予白二羯磨中，首先列出了四種僧位，用以簡擇甄選具有主持資格的人。前兩者是依據戒臘的先後次第，後兩者是取其智慧與辦事才能。「不能背誦戒律的人」，是指雖然不會死記條文，但能通曉戒律的真實義理。因為發起僧法來裁決實務，必須明曉合法與非法的界限，戒律嚴格挑選具備堪能之人，絕不容許草率胡亂作法。

【565-0003】02_戒疏/09d_卷二下之二#94
【原文】【律】無難處。
【譯文】【律文】沒有危難的處所。

【565-0004】02_戒疏/09d_卷二下之二#95
【原文】【註】有虎、狼、師子諸獸者，下至蟻子。若不為此諸蟲獸所惱，應治平地。若有石、樹、株杌、荊棘，使人掘出。若有坑、溝、渠、陂池，當使填滿。若畏水淹漬，當豫設堤防。若地為人所認，當共斷，當無使他有語。是謂難處也。
【譯文】【註文】是指有老虎、豺狼、獅子等各種猛獸出沒的地方，乃至極微小的螞蟻巢穴。如果不被這些蟲蟻野獸所侵擾妨害，就應當修整夷平地面。如果有巨石、樹木、樹樁、荊棘，應當僱人挖掘清除。如果有坑窪、土溝、水渠、池塘，應當讓人填平補齊。如果害怕被積水浸泡淹沒，應當預先修築好堤防。如果土地引來他人產權爭認，應當一同調解斷決清楚，千萬不要讓他人事後生起糾紛爭端。這就叫做有危難的處所（難處）。

【565-0005】02_戒疏/09d_卷二下之二#96
【原文】【疏】九、言「無難」者，注中所列，命、梵而已。如「虎狼」等為命，「蟻子」等為梵。「若有石樹，乃至水漬」，無非在後為命留難也。「為人認」者，計是「妨」緣，今入難位者，恐後諍競起，非淨行也。
【譯文】【疏文】第九句所說「沒有危難」，注文中所列舉的，都不外乎是身命與梵行這兩大根本障難。像是「虎狼」等猛獸會戕害生命，「蟻子」等微蟲若被輾壓會損及梵行清淨。「如果有巨石樹木，乃至雨水淹漬」，無一不是日後威脅生命安全的潛在留難。「土地引來他人爭認」，原本算得上是「妨礙」的因緣，現在歸入「危難」的範疇，是因為唯恐日後引發激烈的訟爭訴端，這就完全喪失出家人的清淨梵行了。

【565-0006】02_戒疏/09d_卷二下之二#97
【原文】【記】九中。初通示二難。「若」下，別點餘相。諍競相言，則違佛戒，故云「非淨行」也。
【譯文】【記文】在第九句中。首先總括說明威脅生命與損害梵行這兩種危難。從「如果」以下，分別點明其他的具體表象。若因為土地紛爭而鬧上官府互有諍言，就直接違背了佛陀的教誡，所以說「失去了清淨梵行」。

【565-0007】02_戒疏/09d_卷二下之二#98
【原文】【律】無妨處。
【譯文】【律文】沒有妨礙的處所。

【565-0008】02_戒疏/09d_卷二下之二#99
【原文】【註】謂通草車迴轉往來者。
【譯文】【註文】是指四周空間足夠容納載草的大車迴轉往來通行。

【565-0009】02_戒疏/09d_卷二下之二#100
【原文】【疏】十、「妨處」者，止存一緣，如諸部論中廣引。必欲締搆，理須精博，不爾陷非，良由不學故也。
【譯文】【疏文】第十句「妨礙處所」，此處只保留了載草車通行這一種緣相，但在諸部論典中則有廣泛的引申說明。如果真的想要營造建築，在法理上必須精深博通諸部律文，否則一旦陷於非法的過犯之中，完全是由於平日不肯用功研學所致。

【565-0010】02_戒疏/09d_卷二下之二#101
【原文】【記】十中。云「一緣」者，即如注引。「草車」，謂大車也。「如諸部」者，《十誦》「四周一尋，內有塔地、官地、居士、外道等地」，《善見》「是人田園、尸陀林、王誌護」等，備如《鈔》中。「必」下，恐專據本律，誡令通曉。
【譯文】【記文】在第十句中。所說的「一種緣相」，就如同隨文注文所引述。「草車」，是指天竺的大型牛車。所謂「如諸部論」，是指《十誦律》規定「房舍四周必須留出一尋（八尺）寬度，內部不可侵佔佛塔地、官有地、居士地、外道地等處」；《善見律》也說「不可侵佔他人田園、棄屍的墓林、國王專門設立標誌保護的禁地」等等，都詳細記錄在《行事鈔》中。從「如果真想」以下，是唯恐行者只知機械依憑本律一家之言，因而嚴厲告誡必須博通並明瞭所有律部的規範。

【565-0011】02_戒疏/09d_卷二下之二#102
【原文】【律】若比丘有難處、妨處，自求作屋，無主，自為己，不將諸比丘指示處所，若過量作者，僧伽婆尸沙。
【譯文】【律文】如果比丘在有危難、有妨礙的處所，自己乞求物料建造房屋，沒有施主，純粹為了自己，不帶領諸位比丘前往指點劃定處所，或者建造超過了規定尺寸，結犯僧伽婆尸沙（僧殘罪）。

【565-0012】02_戒疏/09d_卷二下之二#103
【原文】【疏】就後犯本，亦分十句。初犯人，二、難，三、妨。
【譯文】【疏文】關於後文正式列出犯戒條文的根本，也分為十句。第一句是犯戒的人，第二是危難，第三是妨礙。

【565-0013】02_戒疏/09d_卷二下之二#104
【原文】【疏】「所以立法最末論，此中而先述者？」
【譯文】【疏文】有人問：「為什麼在最初確立戒相法式時將妨難放在最後論述，而在此處判定犯相時卻放在最前面列舉呢？」

【565-0014】02_戒疏/09d_卷二下之二#105
【原文】【疏】答：「立法在後，行之次第，由僧處分，止為妨難也。此中論初作之次第，非所起也。」
【譯文】【疏文】答：「當初立法排在最後，是依據行事的先後次第，因為僧伽給予指劃處分，純粹就是為了排除妨難；而在這裡列舉則是依據造房最初的實務程序，乃是罪過所由生起的次第。」

【565-0015】02_戒疏/09d_卷二下之二#106
【原文】【疏】餘句易識，可解耳。
【譯文】【疏文】其餘的文句都很容易辨認，可以自然理解。

【565-0016】02_戒疏/09d_卷二下之二#107
【原文】【記】後犯本中，初科。前標三句。「所」下，次明妨難前後不同。「非所起」者，「非」即是過。「餘」下，略指七句：四、自求，五、作屋，六、無主，七、自為，八、不乞處分，九、過量，十、結罪。
【譯文】【記文】在後文列舉犯罪條本中，這是第一科。前面先標出前三句。從「為什麼」以下，接著說明妨難在立法與犯罪條文中前後順序不同的原因。「非所起」，「非」字就是指過犯。從「其餘」以下，簡略指出剩下的七句：四、自己乞求；五、建造房屋；六、沒有施主；七、為了自己；八、不乞求處分；九、超過尺寸規格；十、正式結定罪名。

【565-0017】02_戒疏/09d_卷二下之二#108
【原文】【註】若彼作房，於妨、難二處者，二突吉羅；不處分，過量，二僧殘；互相有無者，隨其所犯。若使他作，成犯亦爾。為他作，成者，二偷蘭，二吉羅。若以繩絣地作，受教者過量作者，犯；殘不還報，又不問彼，並犯吉羅。比丘尼偷蘭。不犯者：如量作，減量作，僧處分，無難處，無妨處，如法絣作，若為僧，為佛圖，講堂，草庵，葉庵，小容身屋，若作多人住屋，如法者是。
【譯文】【註文】如果那位比丘建造房屋，是在妨礙與危難這兩個處所動工，結犯兩個突吉羅輕罪；若不經僧伽處分、又超過規定尺寸，結犯兩個僧殘重罪；如果這些過失彼此互有互無，就隨其所犯的項目分別結罪。如果指使別人代為建造，成就犯罪的相貌也是這樣。如果比丘替別人違法建造，一旦做成，結犯兩個偷蘭遮粗罪，兩個突吉羅輕罪。如果已經用墨繩在地上彈直線標定範圍，受指使的人若超量建造，施工者有過犯；施工後不向房主回報（『殘』字係注文衍文），房主也不向施工者詢問驗收，雙方皆結犯突吉羅罪。比丘尼犯此戒則結偷蘭遮罪。不犯的情況是：完全合乎規格建造、小於規定尺寸建造、經過僧伽指劃處分、在沒有危難的處所、在沒有妨礙的處所、合乎戒法彈繩施工，如果是為了僧團全體建造、為了佛塔建造、建造說法講堂、茅草庵、樹葉庵、只能容納單人居住的小屋，或者建造多人共同居住的大屋，只要合乎如法程序的，都不犯。
