# 校閱材料　第199檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【199-0001】02_戒疏/09a_卷二下之二#37
【原文】【疏】有人云：「不同犯。所以然者？若教他言：『持我三根，往謗彼人。』僧若撿校，不問所教，故知是輕。故《善見》云：『慈地得殘，能教人也；尼得吉羅，所教人也。』」
【譯文】【疏文】有人主張：「兩者結罪不同。為什麼呢？如果教唆他人說：『拿著我的三根見聞疑，去毀謗那個人。』僧團若追究核查，並不會怪罪受教唆的人，由此可知受教者罪較輕。所以《善見論》說：『慈地比丘獲得僧殘罪，因為他是能教唆的人；慈地比丘尼只得突吉羅罪，因為她是受教唆的人。』」

【199-0002】02_戒疏/09a_卷二下之二#38
【原文】【記】次科。初標所立。「所」下，釋成。「故」下，引證。以慈地比丘教妹尼，對眾僧前謗沓婆故。
【譯文】【記文】第二段。起初標示他人立論。「為什麼」以下解釋立論依據。「所以」以下引用論典為證。這是因為慈地比丘教唆其妹慈地比丘尼，當著大眾僧面前毀謗沓婆尊者的緣故。

【199-0003】02_戒疏/09a_卷二下之二#39
【原文】【疏】任情所存。然作業是重，未可同於外部。
【譯文】【疏文】這任憑各家見解保留。然而造作毀謗的業行極其嚴重，不應輕易苟同於其他部派的主張。

【199-0004】02_戒疏/09a_卷二下之二#40
【原文】【記】三中。初句縱古，「然」下，奪歸今判。古據《善見》，乃執異部耳。
【譯文】【記文】第三段中。第一句寬容姑且聽從古說，「然而」以下則破斥並收歸當前正統的判定。古人依據《善見論》，其實只是執著了異部律典的說法而已。

【199-0005】02_戒疏/09a_卷二下之二#41
【原文】【疏】次有六戒，教人但輕，漏失、摩觸及四諫戒。若僧未設諫，教者但吉；若僧設諫，教「莫捨」者蘭，以有僧命眾法可違故。漏、觸教人，成者，犯蘭，義不待言。
【譯文】【疏文】接下來有六條戒，教唆他人只結輕罪，即漏失、摩觸以及四條規諫戒。如果僧團尚未正式舉發規諫，教唆者只犯突吉羅；如果僧團已經舉行白四羯磨正式規諫，教唆違犯者「不要放棄異見」的人犯偷蘭遮罪，因為這違背了僧團不可抗拒的公法羯磨命令。至於漏失、摩觸二戒若教唆他人做去，事成之時，教唆者犯偷蘭遮罪，這道理顯而易見無須贅述。

【199-0006】02_戒疏/09a_卷二下之二#42
【原文】【記】釋後六戒，正示中。初總示。「若」下，別釋，先釋四諫。「漏」下，次釋漏觸。「不待言」者，以易知故。
【譯文】【記文】解釋後六條戒的正文陳示中。起初總體標示。「如果」以下作個別解釋，先解釋四條規諫戒。「漏失」以下，接著解釋漏失與摩觸。「無須贅述」，是因為法理淺顯易懂。

【199-0007】02_戒疏/09a_卷二下之二#43
【原文】【疏】問：「如漏、觸，教若未成，但犯吉羅。如何四諫作未成犯，已結蘭者？」
【譯文】【疏文】提問：「例如漏失與摩觸，教唆如果尚未究竟，只犯突吉羅。為何四條規諫戒其教唆的事實尚未徹底完成，就已經結成偷蘭遮罪？」

【199-0008】02_戒疏/09a_卷二下之二#44
【原文】【疏】答：「不同也。彼但自壞損他，又無僧命可違，故待事成方蘭。此諫教人，自他俱損，復有違於眾法，反前故重。」
【譯文】【疏文】回答：「兩者本質不同。漏失摩觸只是敗壞自性與損害他人，又沒有僧團的羯磨號令可以違逆，所以必須等待事情究竟成辦才結偷蘭遮。而這規諫戒若教唆他人拒諫，是自他兩相損害，更違背了僧團的最高羯磨公法，違犯性質與前者相反，所以判罪較重。」

【199-0009】02_戒疏/09a_卷二下之二#45
【原文】【記】初問，以漏、觸、四諫，教人未成，結犯輕、重，故問釋之。答中，初句略示。「彼」下，正釋。初明漏、觸，反下二義。文多「自壞」二字，《義鈔》云「彼教人者，但是損他」，可驗傳誤。「此」下，次明四諫。相比可知。
【譯文】【記文】第一個提問，因為漏失、摩觸與四條規諫戒在教唆未遂時，結罪卻有輕重不同，所以提問並加以解釋。回答中，首句略作提示。「漏失摩觸」以下作正式解釋。首先說明漏失與摩觸，不具備後者所擁有的兩項嚴重特質。疏文字面多出「自壞」二字，但《義鈔》寫作「那教唆他人者，純粹只是損害他人」，可驗證此處傳抄有誤。「而這規諫戒」以下，接著說明四條規諫戒的特點。互相比較便能明瞭。

【199-0010】02_戒疏/09a_卷二下之二#46
【原文】【疏】問：「所諫之人違白未竟，但結吉羅。何以能教犯重，所教輕者？」
【譯文】【疏文】提問：「被規諫的本人在違抗羯磨初白尚未完成時，只結突吉羅罪。為何能教唆的人反而犯重罪偷蘭遮，而受教唆者卻犯輕罪突吉羅？」

【199-0011】02_戒疏/09a_卷二下之二#47
【原文】【疏】解云：「所諫結罪，因果分齊。違白若竟，其果是蘭。故白未竟，其因但吉。又有僧殘重果可趣。能教之人無果可趣，隨語違命，故但偷蘭。」
【譯文】【疏文】解釋道：「被規諫者結罪的輕重，是依循因位與果位的分寸節次來劃定。違抗僧團的羯磨初白若是完畢，其果罪是偷蘭遮，所以在初白未竟之時，其前方便因罪僅是突吉羅；況且後面還有僧殘的大重果罪在等待成立。而能教唆的人並無後續的羯磨果罪可循，當他一出口教唆唆使違抗僧命時，當下即是違令之果，所以直接結犯偷蘭遮罪。」

【199-0012】02_戒疏/09a_卷二下之二#48
【原文】【記】次問。所教拒眾，應合犯重。能教語助，理合過輕。事乖常理，故須問釋。解中。初明所諫犯輕，二義通之。初對前輕過釋。此就一白，自分因果，果既是蘭，因不當重。「又」下，望後重果釋。由後有重，故結前輕。「能」下，次釋能教重義。言「無果」者，無上二果，當體即果故。
【譯文】【記文】第二個提問。受教唆而親身抗拒僧團的人，理應犯重罪；從旁以言語教唆助長的人，按理過失應當較輕。這看似違背常規常理，所以需要問答析解。解釋中，首先說明被規諫者犯輕罪的緣由，以兩種義理通達解釋。第一是相對於前行輕過來解釋。這是就羯磨單一階段中，自行區分前因與後果，果既是偷蘭遮，前因自然不應判重。「況且」以下，是瞻望後續的重果來解釋。由於後面有僧殘重罪，所以前面的過程只結輕罪。「而能教唆的人」以下，接著解釋能教唆者反而判重的義理。所謂「無果可循」，是指教唆者沒有前文所說蘭、殘二果可趣向，其教唆言語當體便是罪滿的究竟果罪。

【199-0013】02_戒疏/09a_卷二下之二#49
【原文】【疏】次明遣人。謂九戒遣人為己作者，同於自犯，如漏、觸於己身之類也。四諫無有教人為己違諫，故所不論。
【譯文】【疏文】其次說明派遣他人的情形。是指有九條戒若是派遣他人為自己造作，其結罪等同於自己親犯，例如派遣他人來使自己身體漏失或摩觸等情況。至於四條規諫戒，絕不可能派遣他人代替自己去違抗僧團的當面規諫，所以不在討論之列。

【199-0014】02_戒疏/09a_卷二下之二#50
【原文】【記】遣人中。「教」謂令彼自為，「遣」即使他就己，如漏、觸等，舉事可為。眾法行諫，必對犯人，止容自拒，故無「遣」義。
【譯文】【記文】派遣他人的討論中。「教唆」是指命令對方替他自己去作，「派遣」則是驅使他人配合自己來作，如同漏失、摩觸等事，可以借他人手來對自身行事。僧團依法規諫，必定是當面對著犯戒本人宣讀，只能由本人親自抗拒，因此沒有「派遣他人代抗」的空間。

【199-0015】02_戒疏/09a_卷二下之二#51
【原文】【疏】第四，明於遮性之義。
【譯文】【疏文】第四，說明遮戒與性戒的法義。

【199-0016】02_戒疏/09a_卷二下之二#52
【原文】【疏】媒嫁、二房是惡，名「遮」。自餘十戒，體是不善，名「性惡」也。以媒、房等自損妨道，等同殘業者，如《母論》云「結戒法異，輕制重名」，欲令行者稀而不為，令進道也。
【譯文】【疏文】撮合媒嫁、兩條造房本非殺盜淫等自性大惡，稱為「遮戒」；其餘十條戒，本質就是不善惡行，稱為「性惡戒」。之所以將媒嫁、造房等障礙自心與修道之事，等同看待而歸入僧殘重罪，如同《毘尼母論》所說「結戒的法度各有不同，有的是事相輕微而以極重名目加以禁制」，這是為了讓修行者心生警惕而罕有造作，促使道業精進。

【199-0037】02_戒疏/09a_卷二下之二#73
【原文】【記】彼以「止不作房」而為止持，則全不曉「持」義。前約四心，分為二別：行前三心，體無汙染，義名「止持」；行心思慮，業相顯彰，方得名「持」。豈有不為而名持耶？又止持、作犯，須約一事相翻以明。若謂不作名止持，作成名作犯，則事非一體，義非相翻。
【譯文】【記文】古人將「止息不造房」當作止持，這完全沒有弄懂「持戒」的真正義涵。先前將持戒之心分為前後兩別：在行心之前的受、想、識三心，其本體雖無染污，名義上可稱為「止持」；唯有在真正起行造作時審慎思慮、防過顯德的業相清楚彰顯，才能稱之為「持」。豈有什麼事都沒做、單純不為就能稱為持戒的道理？再者，止持與作犯，必須依託同一件事情正反相對來闡明。如果說不造作叫止持、造成了叫作犯，那麼兩者所依的事相並非同一個實體，義理上就不是互為正反翻轉。

【199-0038】02_戒疏/09a_卷二下之二#74
【原文】【記】又若不作即名止持，則應不問量之如非，但使作房，即成作犯。又復依量而造，為屬何持？若屬止持，理應不可；若屬作持，且非乞法。是則二持俱無所屬。
【譯文】【記文】再者，如果不造房就直接算作止持，那麼就應當不問房屋尺寸是否合乎法度，只要一動工造房，就全成了作犯。而且，如果依照法定尺寸去建造，這行為究竟屬於何種持戒？若說屬於止持，法理上顯然說不通；若說屬於作持，造房本身又不是向僧團乞法。如此一來，兩種持戒都落了空、無所歸屬。

【199-0039】02_戒疏/09a_卷二下之二#75

【199-0041】02_戒疏/09a_卷二下之二#77
【原文】【疏】今解持犯之生，皆從法起，違順教相，故有犯持。據房為言，事、法分二，各具二持，名體須顯。安有端坐不修為持？如殺盜等，隨境制禦，識達業相，方成前行，號曰「止持」。豈可臥地「我不殺生」，便於生境能發隨戒？戒隨三善，緣境而生。前立義中，約行明持，無問止作，前之三心，不名持犯。云何此中，「我不造房」，名為止持？義不可也。
【譯文】【疏文】現在我們解釋持犯的產生，全都是依託戒法教制而生起，順應或違背了教誡相狀，才產生了持戒或犯戒。拿建造房屋這件事來說，事相與法度必須拆分為二，兩者各自都具足了止持與作持，其名相與實體必須清晰顯露。哪裡有端坐什麼都不修持就能算作持戒的？例如殺生、偷盜等戒，必須是面對現前境緣時能克制抵禦、心中清楚了達業行相貌，才能成就前一種行持，稱為「止持」。難道躺在地上心想「我不殺生」，便能對一切眾生境界引發出圓滿的隨行戒體嗎？隨行戒體是隨著三種善心、依託所對境界而生起的。先前立論時，是針對實際行持來明辨持戒，無論止持或作持，在行心之前的識、想、受三心，都不能稱為持犯。為何在此處卻認為「我不造房」便可稱為止持呢？法理上絕對說不通。
