# 校閱材料　第822檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【822-0001】03_業疏/10a_卷二之四#128
【原文】文列善生簡人中，還約性重者為問也。故彼經中問戒相者，以法行務意存始終，不取受具致有隨缺，觀其志力，察其智愚，量功進法，不徒虗受。故文云：雖隨言能，當須久處，六月供養出家智者，審知可教，待限滿已，和僧為受。由能所知量，願行齊具，依法而受，不負眾生。目驗不堪，強令受戒，致使毀汙，二俱沈溺，可謂虗妄，善惡其蹤，叵追誡之哉
【譯文】文中列舉《善生經》甄別人選的內容中，也是就性罪中極重者來發問。因此該經中審問戒相，是因為修持戒法務必貫徹始終，不能隨便讓人具足受戒以致後續產生隨行毀缺，必須觀察其心志毅力，審察其智慧愚昧，衡量其功行再進一步授法，不讓他徒然虛妄受戒。所以經文說：受戒者雖然口中答稱「能持」，仍應與其長久共處，讓他供養出家有智慧之師長達六個月，審查確認其堪受教化，等待期限屆滿後，僧團和合為其授戒。由於能授者與所受者皆知自量，誓願與實行皆悉具備，依照正法而領受，才不致辜負眾生。如果親眼檢驗已知其無法堪受，卻勉強令其受戒，導致其毀犯玷污戒體，雙方都將沉淪墮落，這可謂善惡夾雜而虛妄不實，毫無真實功德善跡可尋，應當戒慎警惕啊！

【822-0002】03_業疏/10a_卷二之四#129
【原文】次科釋《善生》中兩段：初釋問難。注中四種，乃性重中極重之者。白衣有犯，障戒不發。不列大妄，非彼犯故；「見病棄去」，可攝殺中。故下次釋問相。注中先歎戒功，次示戒相，後問「欲受何戒」，即問戒相也。今釋後段：初明分受所以。受具謂具受五條也，隨缺謂受已毀犯也。「故下次」明簡練。此約出家欲受十戒，當先試練，即如《多論》先以五戒調伏身心，信樂漸增，方受十戒是也。供養即是給侍眾僧，出家智者即和尚師僧，和僧受者即法同單白。「由下」三正彰問意。前敘如法之益，能所即指師資，願行即目受隨，負，違也。「目下」後彰非法之損，任情非法，善惡兩兼，故云虗妄，事無實跡，故不可追
【譯文】下一科解釋《善生經》中的兩段：首先解釋審問障難。注文中所列四種，乃是性罪中最極深重者。在家人若有犯此，便會障礙戒體不得發起。此處不列大妄語，是因為在家人不易犯此的緣故；「見到病患棄捨離去」，則可攝歸於殺生罪中。自「故彼經中」以下，次是解釋審問戒相。注文中先讚歎戒法功德，次開示戒相，最後問「想要受何種戒」，即是審問戒相。如今解釋後段：首先說明分開受戒的原因。「受具」是指五條戒全部具受，「隨缺」是指受了之後隨行毀犯。自「故文云」以下，次是說明考驗簡練。這是指在家人若想出家受十戒，應當先加試驗磨練，就如同《薩婆多論》所說，先以五戒調伏身心，信受樂欲逐漸增長，然後才受十戒。「供養」就是給事奉事眾僧，「出家智者」就是和尚戒師等僧眾，「和僧受」就是其作法如同單白羯磨。自「由於」以下，第三是正式顯明審問的本意。前半段敘述合乎戒法的益處，「能所」是指師長與弟子，「願行」是指受體與隨行，「負」是違背的意思。自「目驗」以下，最後顯明違背正法的損害；任憑私情而不合法度，牽連善惡兩端，所以說是虛妄；事已至此無有真實軌轍，所以悔不可追。

【822-0003】03_業疏/10a_卷二之四#130
【原文】如成論中五逆罪者、賊住、汙尼，毗尼不許者，是人為惡所汙，能障聖道，故不許出家。若為白衣，得善律儀，不遮修行施、慈等善，有世間戒。準此有過，如文不合，必懺蕩己，二教無違，但業重障深，不發具戒也
【譯文】如《成實論》中所說，犯五逆罪者、賊住者、污尼者，律藏不准許出家，是因為這等人已被惡業所玷污，能障礙證得聖道，所以不許出家。如果作為在家人，仍可得善律儀，並不阻礙其修持布施、慈悲等善法，仍保有世間善戒。照此而論，犯有過咎者，若與律文規定不合，必須先行懺悔蕩滌清淨，如此與世教及佛制二者便不相違背；只是由於其業障深重，不能發得具足戒而已。

【822-0004】03_業疏/10b_卷二之四#1
【原文】若準多論，五戒三歸不具分受則不得戒。縱引經證，謂持二三，不言受體。如是釋者，義有未融。如比丘受具，不能全持，可名少分
【譯文】如果依照《薩婆多論》，五戒與三歸若不具足受而只分受一二，便不能得戒。縱然有人引經文為證，說經中提到持二戒、三戒，但那是指持戒隨行，並不是指所受的戒體。如果作這樣的解釋，在義理上尚有不通融之處。就如同比丘受具足戒後，不能全持所有戒條，難道可以稱他為「少分比丘」嗎？

【822-0005】03_業疏/10b_卷二之四#2
【原文】第二法中初科，受緣漸頓中，初文初引彼計。「不具分受」謂不受五而受一二，則不發戒體。「縱引經」者，論家防難，即下《善生》明分五受。彼謂受時具發五戒，但由隨中持有多少，故有一分、少分等。「如下」躡斥，謂若許受體具五，隨行不具而名少分，即應比丘具受分持，得名少分比丘耶？當知全分定約受體耳。融，通也
【譯文】第二項論法中的第一科，在說明受戒因緣的漸次與頓受中，第一篇文字首先引述對方的觀點。「不具分受」是指不全受五條戒而只受一條或二條，則不能發起戒體。「縱然引經證」這句話，是論主防範問難之語，也就是底下《善生經》中明示將五戒分受之說。彼論認為受戒時必定具足發起五戒體，只是由於後續隨行中持戒有多少的不同，所以才有一分、少分等名稱。自「如比丘」以下，是步步追究並加以呵斥，意思是說：如果承認戒體本具五條，僅因隨行不具足就被稱為少分，那麼比丘具足受戒而只分持部分戒律，難道也可以稱作「少分比丘」嗎？應當知道，全分與少分必定是就受戒體而言的。「融」，是通達融徹之意。

【822-0006】03_業疏/10b_卷二之四#3
【原文】成論云：有人言五戒木叉唯頓無漸，此事如何？論答：隨受一、二、三皆得律儀。《善生》所列一分、二分、少分、多分、滿分是也。準斯明漸，五師受一，得戒不疑，如薄俱羅唯受不殺例也
【譯文】《成實論》說：有人主張五戒別解脫木叉唯有頓受而沒有漸受，這件事究竟如何？論中回答：隨順受持一戒、二戒、三戒，皆可獲得別解脫律儀。這就是《善生經》所列的一分、二分、少分、多分、滿分優婆塞。依照這個道理明示漸受，即使分別從五位戒師各受一戒，其得戒也是無庸置疑的，就如同薄俱羅尊者昔日僅受持一條不殺生戒的例子一樣。

【822-0007】03_業疏/10b_卷二之四#4
【原文】次《成論》中，初牒前義以為問端。頓謂具受，漸即分受。答中正答，律儀即戒體。「善下」引證。分即支義，五法一體，總中彰別，故名為分。「準下」義決。以前三歸不許互缺、異師別受，竝判不成，恐謂同彼，故準決之。薄俱羅，此翻善容，以彼好容儀故，婆羅門種，天竺國人。昔毗婆尸佛時，曾作貧人，持一訶棃勒果施病比丘，服訖病愈。以此因緣，九十一劫天上人中受福快樂。今生婆羅門家，其母早亡，後母惡之，嘗就母求餅，被投於餅爐，父見救之，火不能死；又嘗從母求肉，被投釜內，湯不能死；又嘗牽母衣，被推於河中，大魚吞之，會父買魚，剖腹了無所損，水不能死。後求佛出家，得阿羅漢，年一百六十歲，未曾有病，葢從昔嘗持一不殺戒故，受斯報。準知分受理無所疑
【譯文】接著是《成實論》的段落，首先提撕前面的義理作為發問端緒。「頓」是指具足受，「漸」就是分開受。答文中給予正面回答，「律儀」就是戒體。自「善生所列」以下是引經作證。「分」即是支分之義，五條戒法合為一體，於總體中顯發各別之支，所以稱為分。自「準斯明漸」以下是義理的判定決擇。因為先前所說的三歸依不允許相互殘缺，也不許從不同師長處分別受，皆判定為不能成就，恐怕有人誤以為五戒也同三歸一樣，所以特地比照判定之。薄俱羅，此處翻譯為「善容」，因為他容貌儀表美好的緣故，屬於婆羅門種姓，是天竺國人。過去在毘婆尸佛時代，他曾是一個窮人，拿一顆訶梨勒果布施給生病的比丘，比丘服用後病就好了。以此因緣，九十一劫之中在天上人間享受福樂。今生投生於婆羅門家，其母早亡，繼母厭惡他，他曾向繼母討餅，被扔進烤餅的爐子裡，父親看見救了他，火燒不死他；又曾向繼母要肉，被扔進大鍋裡，熱水燙不死他；又曾拉著母親衣服，被推入河中，大魚將他吞下，剛好父親買了這條魚，剖開魚腹發現他毫髮無傷，水淹不死他。後來他隨佛出家，證得阿羅漢果，活到一百六十歲，一生從未生過病，這大概是因為往昔曾經受持過一條不殺生戒的緣故，才感得如此福報。由此可知，分開受戒在理上是毫無可疑的。
