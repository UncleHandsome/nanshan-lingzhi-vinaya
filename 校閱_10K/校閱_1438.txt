# 校閱材料　第1438檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1438-0001】04_比丘尼鈔/03b_卷中之上#7
【原文】第四敬僧者惟末世僧尼諳究既微積罪尤大服玩乖於內典舉動同於外俗知解類若管窺升駮剩為大匠更相扇動共作愆瑕互求長短諍情難息或有縱蕩六情馳騁三毒明黨癡惡思厭清眾恃官形勢枉厭良善枷禁囹圄退令歸俗自作好人獨標眾首或有共一伽藍兩處結界大院禪院不同布薩法服名利苟自貪榮佛制聽戒便推認惡或有兩處鳴鐘各集徒眾諍為多少致成忿諍遂使道俗有向背之心伽藍有不和之相佛藏有鳥鼠之喻大集有獼猴之況昔者學步耶鄲不謂匍匐而歸鷄欲朝鳴何期反成烏調哀哉哀哉痛傷難忍永惟期理深可慎歟故大寶積經云出家有二種縛一見縛二利養縛又二種癰瘡一求見他過二自覆己罪像法決疑經云諸比丘自稱我是法師我是律師我是禪師此三種學人能滅我法更非他人迭相毀呰正法念經云為求財利說法名為下施為名聞勝他說法名為中施為增長眾生智慧而為說法名為上施或有比丘不樂禪誦賣樂求財於他病者不相應治生於黑繩地獄五百問事云比丘志樂衣服晝夜染著因病致死後生蛇中還來纏衣眾僧葬亡比丘訖取衣鉢作法蛇延頸吐毒僧共看之有得道者勸蛇令去遂入草中毒盛火出燒身命終死入地獄大悲經云佛過去時見一切人故無不傾側謙下禮敬以是義故成佛已來山林人畜見佛行時無不傾側低頭禮拜此律云其敬長老者是人能護法現世有名譽將來生善道。
【譯文】第四、恭敬僧團（敬僧）：念及末世的僧尼，對經教的研究既淺薄，積累的罪業又極深重。衣著玩好違背內典教規，舉止行動完全混同於世俗之人。見解淺陋猶如管中窺豹，稍微懂得一點皮毛就自命為一代大師；彼此煽風點火，共同製造罪過瑕疵，互相找尋長短過失，爭執之心難以止息。或者有人縱容放蕩六根情欲，任由貪瞋癡三毒馳騁，公然結黨作惡，厭惡排擠清修之士；依仗官府權勢，構陷冤枉善良清修之人，將他們關入監牢枷鎖，逼迫其退轉還俗；自己卻假充好人，獨自標榜傲立於大眾之首。或者有人在同一個寺院之中，竟在兩處各自結界，大院與禪院各自分開布薩誦戒；為了僧服與名聞利養，苟且貪圖自身虛榮；佛陀制戒要求聽聞戒相以檢察過非，便推諉卸責、拒不認罪。或者在兩處各自敲鐘，分別聚集徒眾，爭競人數多寡，以致演變成忿恨爭鬥；遂使出家與在家之人產生向背偏私之心，伽藍寺院呈現出不和睦之象。《佛藏經》中有「鳥鼠同處」的譬喻，《大集經》中有「獼猴亂群」的況味。從前邯鄲學步，不料最後只能爬著回家；公雞本應在清晨報曉，怎料反倒發出烏鴉般的怪調？令人哀傷痛惜，痛苦實在難以忍受，深思這期許中的至理，實在應當深加警惕戒慎啊！因此《大寶積經》說：出家有兩種束縛，一是惡見之縛，二是利養之縛；又有兩種惡瘡，一是專求探見他人過失，二是掩飾遮蓋自己罪惡。《像法決疑經》說：諸比丘各自宣稱「我是法師」、「我是律師」、「我是禪師」，這三種修學之人最能敗壞我的正法，並非他人能毀，全因他們輾轉互相毀謗指責。《正法念處經》說：為了謀求財利而說法，稱為下品布施；為了名聲顯赫、勝過他人而說法，稱為中品布施；為了增長眾生智慧而說法，稱為上品布施。或者有些比丘不樂於修習禪定誦經，反而靠演奏賣弄音樂牟取財利，面對別人生病也不予相應救治，死後將墮入黑繩地獄。《五百問事》說：曾有比丘一心思慕喜愛衣服，晝夜貪愛執著，因病死去後投生為毒蛇，又回到僧房纏繞著原先的衣服。眾僧埋葬亡僧完畢，前去收取其衣鉢依法處置，毒蛇伸長脖子吐出毒氣，眾僧一同圍觀；其中有位證得道果的人，勸化毒蛇令其離去，毒蛇遂鑽入草叢中，由於瞋毒熾盛而引火焚燒己身，命終之後死入地獄。《大悲經》說：佛在過去修行時，看見一切眾生，沒有不側身謙遜下拜行禮的；由於這個緣故，成佛以來，凡在山林人畜見到佛陀行進之時，無不側身低頭頂禮拜謁。本律說：凡是恭敬長老尊宿的人，這人就能護持正法，在現世享有令譽，未來世將投生於善道之中。

【1438-0002】04_比丘尼鈔/03b_卷中之上#8
【原文】第五定尊者母論云下座稱上座為尊者上座稱下座為慧命又無夏至九夏是下座十夏至十九夏名中座二十夏至四十九夏名上座五十夏已上者一切沙門國王之所尊敬是名耆舊長老五分云上無人者即名上座婆論云內道一切皆是上座外道一切皆是年少僧祇云無歲比丘得共三歲坐乃至七歲得共十歲坐若臥牀得三人坐坐牀得二人坐伽論云地敷得共未受具人坐。
【譯文】第五、排定長幼尊卑之序（定尊）：《母論》說：下座稱呼上座為「尊者」，上座稱呼下座為「慧命」。又規定：沒有戒臘至九夏的稱為「下座」；十夏至十九夏的稱為「中座」；二十夏至四十九夏的稱為「上座」；五十夏以上的，是一切沙門與國王所共同尊敬的，稱為「耆舊長老」。《五分律》說：在他之上沒有更高戒臘者的，即稱為「上座」。《婆沙論》說：佛法內道之人相對於外道全都是上座，外道的一切人則全算作年少後輩。《僧祇律》說：無戒歲的比丘可以與三歲戒臘者同坐，乃至七歲者可以與十歲戒臘者同坐；如果是臥鋪大床，可以三人同坐；如果是坐椅，可以兩人同坐。《伽論》說：鋪設在地面上的坐具，可以與尚未受具足戒的人同坐。
