整體讀來流暢，科判、罪名的對應大致掌握得不錯（「斯豈道邪」的反問、「先有後無／始終無心」的分判都譯對了）。以下按「必須改」→「宜調整」→「術語統一」分項列出。

---

## 一、實質性問題（建議必改）

### 1. 【490-0002】「闕心緣」譯成「欠缺盜心之緣」——恐是錯解
這是最要緊的一處。此段「二、明疑心」「三、明雙闕」是接在**闕第二緣（有主想）** 之下，「雙闕」＝闕境＋闕「想心」。文中所疑是「為人物？為非人物？」——疑的是**物的歸屬（想／認知）**，盜心其實仍在。

關鍵證據在【490-0014】記文自答：「**闕想有心**，此據無心」——闕想（含疑心、雙闕）是**有盜心**的；真正「無盜心」才是後面【490-0006】的闕第四緣。譯文在此作「欠缺盜心之緣」，會與後文自相矛盾。

建議：「這屬於欠缺（對境作）想心之緣（即第二緣『有主想』）。」標題「心境雙缺」可保留，但「心」宜註明指「想心」。

### 2. 【490-0007】「糞掃、親厚等取」譯錯方向
「至親密友等擅自取用」變成「親友去擅自拿東西」，且「擅自取用」帶貶義，與**開緣＝無犯**相違。

原意是：**取糞掃物（他人丟棄的無主物）**、**以親厚想取親友之物**（彼此不分你我，律開不犯）。
建議：「如開緣中所說：取糞掃（棄置無主）物、以親厚想取用親友之物等。」

### 3. 【490-0004】「緣由」與「結算」兩個詞不当
* 「緣」在此是**構成犯相的要件**（五緣：有主物／有主想／重物值五錢／盜心／舉離本處），不是「緣由、原因」。全篇「欠缺第三個緣由」「具足緣由」宜一律改為「**（成犯）要件**」。
* 「結前方便蘭」的「結」是**結罪、判結**，不是會計的「結算」。
* 「微薄輕物」宜明說「**不滿五錢的輕物**」，與前半「滿五錢」對稱。

建議：「欠缺第三個要件。對價值滿五錢的重物，作不滿五錢的輕物想，即結成前面方便階段的偷蘭遮罪。」

### 4. 「次方便」不是「次要著手」
遠／次／近三方便是**時間次第**（遠→次→近），不是重要性主次。【490-0007、0011、0012、0016】一律把「次要著手」改為「**中階段的方便（次方便）**」，「切近著手」可作「**臨近成犯的方便（近方便）**」。

### 5. 【490-0020】「託緣」＋「陽遂卿侯」
* 「初示託緣之意」的「託緣」＝**藉此段事緣（靜居坐禪）來顯示義理**，不是「假託」（含造假貶義，與前面「詐宣王教」撞詞）。建議：「首先說明疏文藉此事緣所要顯示的用意。」
* 「封為陽遂卿侯」：原文「陽遂卿候」是訛字，當作「**陽遂鄉侯**」（《吳志》顧雍傳）。譯文照抄「卿侯」應改，並可加校註。
* 「輕其勢祿／輕其財利」的「輕忽」易讀成「疏忽」，宜作「**不看重權勢俸祿／不把財利放在心上**」。

## 二、宜調整（不算大錯，但語意走味）

| 編號 | 問題 | 建議 |
|---|---|---|
| 0001 | 「**原本**是人類財物」與0002雙闕的「境轉」混淆；記文明說「前疑據**境定**」 | 「境（確實）是人的財物，境不變而心中生疑」 |
| 0002 | 「卻被非人財物**替換**」像是外力掉換 | 「現前之境已轉為非人的財物」；「並例準知」→「皆可依此例類推而知」 |
| 0002 | 原文「為**闕**為畜邪」應是「為**人**為畜邪」之訛 | 譯文依義譯對了，宜補一則校勘註 |
| 0003 | 「作圖示之」譯成「**可以**繪製圖表說明」，語氣像建議 | 元照記中實際列圖：「（今）繪圖以顯示之」 |
| 0010 | 「望未動身」 | 「就尚未發動身（口）行而言，還不构成盜罪等」 |
| 0012 | 「盜業已**彰**」譯「顯露」偏弱，重點是**盜業已成立**，故不名闕心 | 「盜業已經成立」，並補「（所以不名闕心），只名闕第五緣」 |
| 0013 | 「缺少心想」含糊 | 「闕第二緣的『有主想』（認知錯誤）」 |
| 0015/0016 | 「隨相分別」譯「隨情狀」略空泛 | 「隨（次方便／近方便）罪相分別輕重」；0016可補「次方便結輕蘭、近方便結重蘭」 |
| 0017 | 「假託**傳遞**國王的敕令」＝像真有其令 | 「詐稱王命（謊稱國王已允准）」 |
| 0017 | 「佛陀**如上**制定了這條盜戒」語序拗 | 「因此因緣，制定了上面所引的這條盜戒」 |
| 0017 | 「全成瓦屋」 | 「整座用陶瓦燒造而成的屋子」；「要材」可註「國王所守護、備修城用的重要木料」 |
| 0019 | 「偷盜的情相**最容易**牽動心念」——「最」是添譯 | 刪「最」 |
| 0019 | 「況餘滯境」譯「其餘執著境界的**凡夫**」 | 記文釋為「貪吝之人」，且此處是誡道，對象未必是凡夫：「其餘貪著境物（貪吝）的人」 |
| 0019 | 「萬戶侯」 | 疏作「萬戶封」、記作「陽遂鄉侯」，詳略不同；可譯「受封萬戶食邑」並略註 |
| 0021 | 主語不明 | 「（佛令）打破瓦屋，（打破的人）難道不犯損壞財物之罪嗎？」 |

## 三、譯得妥當、可保留者
* 【0006】【0008】【0009】先有後無／始終無心、闕方便與闕心的分判，準確。
* 【0014】「闕想有心，此據無心」「動身後轉／初心即轉」的對比譯得清楚（唯「闕想」宜補緣次）。
* 【0019】「斯豈道邪？」作「這兩人難道是修道人嗎」，並補「世俗凡夫尚且如此，修行人當自勵」——反問語意處理正確（此處常有人誤譯成「這難道不是道嗎」）。
* 【0018】科判分段、引文起訖（「為王臣」下、「便詐宣教」下）都對得上。
