# 校閱提示詞．術語清單版

## 材料

```
【03-0150】資持記/01c_上一上#18
【原文】…
【譯文】…
```

## 提示詞（複製整段）

```text
你是南山律典白話譯文的校閱者。下面每段附原文與現行白話。

【第一關：術語核對】
先只做一件事：逐段掃描原文，若出現下列任一術語（**完整表見 術語表.md，共 60 條**），就核對譯文是否用對：

| 原文用語 | 正確理解 | 常見錯誤 |
|---|---|---|
| 三趣 | 人、非人、畜生 三道 | 誤作「三惡趣」 |
| 伽論／《伽》 | 《薩婆多部毘尼摩得勒伽論》（摩得勒伽論） | 誤作《善見論》《毘尼母論》 |
| 母論 | 《毘尼母論》 | 誤作《摩得勒伽論》 |
| 見論／善見 | 《善見律毘婆沙》 | 誤作《摩得勒伽論》 |
| 鈔 | 《行事鈔》 | 與「疏」「記」混稱 |
| 疏 | 《含註戒本疏》 | 誤作《行事鈔》 |
| 記 | 《資持記》或《行宗記》 | 張冠李戴 |
| 提 | 波逸提（九十單提） | 誤作「提舍」 |
| 提舍 | 波羅提提舍尼（向彼悔） | 與「波逸提」混 |
| 法直倍三 | 單白、白二、白四 三種羯磨 | 誤作「三品加倍」「人數加倍」 |
| 增三 | 《四分律》〈增一犍度〉三法門 | 誤作《增一阿含經》 |
| 中國 | 中印度（天竺） | 誤作「漢地」「中國本土」 |
| 光師 | 慧光律師（光統） | 誤作「智光律師」 |
| 二滅 | 已滅擯、應滅擯 | 誤作「兩種滅法」 |
| 和忍 | 和同忍可 | 誤作「和合忍耐」 |
| 持說 | 受持與說淨 | 誤作「持誦解說」 |
| 兩頭兩綴 | 兩端各一綴，合計兩綴 | 誤作「兩頭各兩綴」 |
| 百一物 | 僧物種類（百一諸物） | 誤作「一百件衣物」 |
| 四位分之 | 依四種位次區分 | 望文生義 |

【第二關：義理】
術語對了，還要看整段意思對不對。逐段問這六件事：
1. 主詞：誰做、誰受？有沒有顛倒？
2. 因果：因與果、條件與結果有沒有反過來？
3. 肯否：原文說「不犯」的，譯文有沒有變成「犯」？
4. 程序：先後次序、能作所作，是否與原文一致？
5. 範圍：原文「一切」有沒有被縮小成「部分」，或反之？
6. 增減：譯文有沒有添加原文沒有的內容（例如把「近王宮」譯成「御用溫泉」）？

凡是這六項有疑慮，即使術語無誤，也要標 P1 或 P0。

【第三關：數字與矛盾】
凡譯文出現數字，回頭核對原文：數目、單位、加總是否一致（例：「兩綴＋三綴＝五綴」）。

【第四關：引文與書名】
《》〈〉「」內的文字，是否與譯文一致；書名簡稱是否指對。

【第五關：標籤體例】
譯文開頭是否重複加了標籤已有的「義理疏文說」「【疏文】」等；句末是否多出標點。

【輸出】
對每一段輸出一行：
編號 ｜ OK 或 P0/P1/P2 ｜ 一句理由（OK 也要寫你核對了哪一項，例如「術語與義理相符」）

最後對非 OK 的段，給整段替換文字。
```

## 重點

1. 術語表只是第一關；**義理（主詞、因果、肯否、程序、範圍、增減）仍是主戰場**。
2. 數字與引文是 AI 做得到的，優先抓。
3. 表格可以陸續補：每抓到一個新錯誤，就把該詞加進表裡。
