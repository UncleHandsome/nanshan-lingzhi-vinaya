# 校閱材料　第240檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【240-0001】03_業疏/02b_卷一之二#17
【原文】問：能秉法僧有於四別，僧所秉法何但三耶
【譯文】問：能秉持羯磨法的僧團有四種差別，而僧團所秉持的法為何只有三種呢？

【240-0002】03_業疏/02b_卷一之二#18
【原文】初問可解
【譯文】第一個提問容易理解。

【240-0003】03_業疏/02b_卷一之二#19
【原文】答：非是初僧不秉三法，但四人僧者本是僧體，餘之三僧隨事淳薄故隨分耳。僧體加一，得遂僧事，號五人僧；事情須發，倍五加十，號十人僧；心輕罪重，倍十加人，號二十人僧。對法亦爾：說戒等被情，事不難，初則問和，連辭即決，故制單白；諸差、諸結非常行務，和忍稍難，白加羯磨，倍增一法，故名白二；治、諫等事成辨最難，倍加二法，故名白四。對人三反，約法亦三，是則人法相因，皆由三事也
【譯文】答：並不是第一個四人僧不能秉持三種法，而是四人僧本來就是僧團的根本自體，其餘的三種僧則是隨著事務的淳厚或澆薄（輕重）而隨順分化罷了。僧體外加一人，得以成辦特殊的僧事，稱為五人僧；事涉發露受戒等要務，在五人之上加倍為十人，稱為十人僧；造罪者心意輕慢而罪障深重，在十人之上加倍為二十人，稱為二十人僧。對應法也是如此：說戒等是順應情理之事，難度不高，最初只需問和，連帶言辭即可裁決，所以制定義為單白；各種差派、各種結界非常規事務，眾共和忍稍難，在白文之外加上羯磨，倍增一法，所以名為白二；治罰、諫責等事成辦最難，倍加兩倍法（一白三羯磨），所以名為白四。對人有三次增倍，依據法也分為三品，這就是人與法互為因由，都緣於事務難易的三種差別。

【240-0004】03_業疏/02b_卷一之二#20
【原文】答中，初二句通示。「但」下別釋，又二：初敘四僧，「對」下次明三法，略舉一二以彰難易。「對人」下總結
【譯文】解答之中，前兩句通貫開示。自「但」字以下分別解釋，又分為二部分：首先敘述四種僧，自「對」字以下其次說明三種法，略舉一二例以彰顯其難易。自「對人」以下作總結。

【240-0005】03_業疏/02b_卷一之二#21
【原文】問：法中約事無體，直陳單白、白二、白四，三法半倍。若準僧中，亦應五人為體，就五加十自決恒務，更何須四以為僧本
【譯文】問：法之中依據事務而沒有獨立的體，只是直接陳述單白、白二、白四，三種法依序半數加倍。如果比照僧團中，也應當以五人為體，依五人再加至十人以自行裁決常規事務，又何須四人作為僧團的根本呢？

【240-0006】03_業疏/02b_卷一之二#22
【原文】三問中，人分體相，法直倍三，於義不齊，故以法例人，應除初體
【譯文】在第三段提問中，人有體與相的分別，法只是直接分為單白、白二、白四三種，在義理上顯得不齊整，所以用法來例證人，認為應當除去最初的四人僧體。

【240-0007】03_業疏/02b_卷一之二#23
【原文】解云：四人成體，加一為事，故後三僧不名本也。法則不爾，當白自體，隨體附事有上中下，故倍增法，無非本體。猶如邊受，白召和入自是為事，四人秉法還依本體；但事須問，非差不成，故僧外加一。白則不爾，法自是體，何須重加
【譯文】解釋說：四人成就僧體，加一人是為了成辦具體事務，所以後面的三種僧不稱為根本。法的情況則不是這樣，當前的白文自身即是法體，隨著法體依附事務而有上、中、下的深淺難易，所以加倍遞增的羯磨法，無一不是根本自體。就像邊地受戒，作白召喚、和合入僧自然是為了成辦事務，四人秉持羯磨法依然是依據僧體；只不過事務需要審問，不經過差派就無法成辦，所以在僧體之外加一人。白法就不是這樣，法本身就是體，何須重複再加。

【240-0008】03_業疏/02b_卷一之二#24
【原文】四答中，初明三人具體，且舉五人，故言「加一」，十人加六，二十人加十六，後之三位體蘊其中。「法」下次明三法即體，言「當白」者通目三法。上約義釋，下舉事顯，且舉邊受，餘法準知
【譯文】在第四段解答中，首先說明三種僧都具備僧體，且以五人僧為例，所以說「加一」，十人僧則是加六人，二十人僧則是加十六人，後面的三種僧位其僧體都蘊含在其中。自「法」字以下，其次說明三法本身即是體，所說的「當白」是通稱三品之法。上面是依義理解釋，下方舉出具體事務來顯明，暫且以邊地受戒為例，其餘的法則依此類推可知。

【240-0009】03_業疏/02b_卷一之二#25
【原文】問：就後四僧，減則不成，過便得；就羯磨教法，過減俱非者何
【譯文】問：就後面的四位僧而言，人數減少就不能成辦，超過了卻可以；而就羯磨教法而言，過多或減少都是非法的，這是為什麼呢？

【240-0010】03_業疏/02b_卷一之二#26
【原文】明過減中初問，律列四僧，後云「況復過是」；白及羯磨竝云「增減非法」，欲申教旨，問以通之
【譯文】在辨明過與減之中首先提問，律中列舉了四種僧，後文說「更何況超過此數」；而單白及羯磨都說「增多或減少均屬非法」，此處為了闡明教旨，故設問以求通達。

【240-0011】03_業疏/02b_卷一之二#27
【原文】答：僧取詳集無乖表和，若制數定，乖別過起，不名僧義，是以過成減別；非用法取濟時通名和白，既非情惱，不慮乖別，但順軌模便成正法，故云「如白法作白」等
【譯文】答：僧團講求周詳集會、毫無乖違以表明和合，如果把人數限定死，就會產生乖違別眾的過失，不符合僧團的義理，因此人數超額可以成辦，人數減少則成別眾非法。羯磨之法是為救濟時宜，通稱為和白，羯磨法既然不是有情煩惱之境，不需顧慮乖違別眾，只要順應軌範規模便能成就正法，所以律說「如同單白之法而作單白」等。

【240-0012】03_業疏/02b_卷一之二#28
【原文】答中初解：人別生惱，過則通收；法無此義，理須楷定。下指「文云」，即見本注
【譯文】解答之中的第一種解釋：僧人若隔別（成別眾）就會生起過惱，人數超額則能通通包納；法並沒有這種顧慮，在理則上必須嚴格楷定。下文所指的「文云」，即見於原本的夾注。

【240-0013】03_業疏/02b_卷一之二#29
【原文】又解：被事聖教，咸準佛言，若有過減，便由凡語，淳薄斯異，缺不成務也。然則制僧數定，既是聖教，越度在凡，應非辨法？然情在通和，非集不顯，隨集無乖，方成法事，故文云「況復過數」等，又云「更無方便得別眾也
【譯文】又有一種解釋：被施於事務的聖教，都完全以佛言為準繩，如果有所增過或減少，就是出自凡夫的話語，聖凡淳厚澆薄有此差異，缺損就無法成辦事務。既然如此，制定僧數的定額，既然也是聖教，逾越界限是由於凡夫，難道不也應該無法成辦法事嗎？然而有情的心意在於通達和合，不經由集會就無法顯現，隨其集會只要沒有乖違，才能成就法事，所以律文說「更何況超過數量」等，又說「更沒有任何方便可以構成別眾」。

【240-0014】03_業疏/02b_卷一之二#30
【原文】次解：初明法須準教；「然」下次明人取通和，據數似違文，約事正合教。下引兩文，頗彰聖制。私釋：法取楷定，不容改作；人須和合，義必通收。律文對事局分四位，竝據極限，至於臨事，唯多彌勝
【譯文】第二種解釋：首先說明法必須依準教法；自「然」字以下其次說明人講求通同和合，依據人數看來似乎違背律文，但就事務本質而言正好符合聖教。下文引用兩段律文，頗能彰顯聖者的定制。私家解釋：羯磨法講求楷定法式，不容隨意改作；僧人講求和合無礙，義理上必須全數包容。律文中針對各項事務局限劃分為四個階位，都是依據最低極限而言，至於臨機行事，只有人數越多越殊勝。

【240-0015】03_業疏/02b_卷一之二#31
【原文】若準《十誦》、《僧祇》，人法相類，重加成就，減少不得，文廣如彼
【譯文】如果依照《十誦律》、《僧祇律》，人與法是相互類似的，多重累加可以成就，減少則不可以，詳細文句如彼律所說。

【240-0016】03_業疏/02b_卷一之二#32
【原文】他部中，彼宗合作單白，加為白二；合作白二，而加白四，加則愈勝，減則非法。鈔云「御法例通於無準」是也
【譯文】在他部律中，彼宗認為應當作單白的，加倍作白二；應當作白二的，而加倍作白四，加多則更為殊勝，減少則為非法。《事鈔》所說的「御法例通於無準」指的就是這種情況。

【240-0017】03_業疏/02b_卷一之二#33
【原文】四廣顯是非，如後文中不足數說
【譯文】第四、廣泛顯明合儀與非法，如後文中所說的不足數等內容。

【譯文】眾法之中起初列示總數。自「一」字以下顯明通塞：起初通論三種法。如今說明辦事，必須區分兩條途徑：一是就整體通相中簡別個別之法，如一場受戒中四種羯磨各自被及不同環節；二是攝受各別之法歸於總體，如受戒的四項法緣通力成就一場受戒，現在文中是依據後者來劃分通塞，按原本而言各有所被及，依義理而言則顯明其相通。「統就眾緣」的意思，例如若要在受戒處行法，若在自然界必須先結界，和尚度人必須乞求蓄眾，這些都可以收攝歸入受戒，用以彰顯多種法成就一事的意義，自恣、懺捨墮、罰乞鉢、分亡僧衣物都具有這種意義，臨到具體律文自會列舉。自「白二」以下特別甄別白二羯磨，七種結界法不可重結是閉塞不通，其餘都以作法界為通，所以說反照上述可知。

【240-0126】03_業疏/02b_卷一之二#142
【原文】就人而論：一人心念，自秉口言，是當分也；設通上二，是傍非正，必界有人，豈得獨作。眾多對首，為前證境，必是通情告事，相領方能成遂；雖通眾法，亦是開位。四人成僧，勝用非一，約事乃三，宗歸初位，過則彌勝，若減非法
【譯文】就僧人而論：一人心念羯磨，自己秉持並口中陳說，這是其當分正法；假使通於上面兩種，也是傍通而非正途，界內若有人在，豈能單獨作法？多人對首，是作為對面作證的境界，必須是彼此通達情意、陳告其事，互相領解方能成辦遂心；雖然也通於眾法，但也是開許的位次。四人成立僧團，殊勝作用不止一種，按事相來說分為三種，其宗旨都歸於最初的四人僧位，人數超過四人則更為殊勝，若是短少則構成非法。

【240-0127】03_業疏/02b_卷一之二#143
【原文】三明人中，初明一人，雖通三法，旁正須分。「眾」下次明眾多，同上兩別。「四」下三明大眾，一體三用，用還依體，故歸初位
【譯文】在第三項說明僧人之中，起初說明一人，雖然通於三種羯磨，但旁通與正格必須區分。自「眾」字以下次說明多人對首，如同上面有一人那樣分為旁通與正格兩種情況。自「四」字以下第三說明僧眾，僧團一個體性而有三種作用，作用終究依託於體性，所以宗旨歸於最初的四人僧位。

【240-0128】03_業疏/02b_卷一之二#144
【原文】就界而論：自然是弱，不通僧務，若不開結，僧法無因，唯聽白二；作法七界，互不相通，文不許重及相接也。然三大三小，名多義一；戒場自分，故須圍繞，雖相乃重，兩間空也
【譯文】就結界而論：自然界力量薄弱，不通於僧團重要事務，若不開許結界，僧法就沒有依托之由，所以只聽許作結界的白二；作法界有七種界，彼此互不相通，律文不允許重疊以及互相交接。然而三大界與三小界，名目雖多而界體之義是一致的；戒場自成一區分，所以必須被外圍大界圍繞，外相雖然看似重疊，但兩者之間有空隙相隔。
