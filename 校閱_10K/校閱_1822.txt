# 校閱材料　第1822檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1822-0001】03_業疏/17a_卷三之六#137
【原文】「依律下」，委釋為三：初示名體。律十種者：一、牛嚼，二、鼠嚙，三、火燒，四、月水，五、產婦，六、神廟，七、塚間，八、求願，九、往還，十、王軄。俗賤道貴，示相反也。「此下」，次議其名。常人謂淺識者，若卓拔君子，豈以衣為糞掃耶？「故下」，三引況。初《論語》，「未可與議」，言此庸人不足語道。《劉子》即劉晝也，著書二卷五十五篇，窮悴無由自達，乃負其書候沈約於車前獻之，約覽而異之，遂呼登車定交，時人號此書為《劉子》。今引〈防欲篇〉，彼云「明者刳情以遣累，約欲以守貞」，方接「食足」等語。「斯言是」者，美其有理也。「至下」，敘厭榮。冠、衣二字去呼。章甫，殷時冠也；縫掖，大袖衣也。《家語》孔子對哀公曰：「丘少居魯，衣縫掖之衣；長居宋，冠章甫之冠。」嘉肴謂品饌，非穀而食曰肴；芳音謂歌樂之聲。高位是貴，厚味是富，未詳何書。「俱不可久」，勢有退也。「是以」下，明向道。《易·謙卦》云：「人道惡盈而好謙，謙尊而光，卑而不可踰，君子之終也。」「忍人」等者，謂眾人所不能者，我則勉力為之。文出《淨住子》，本唯三句，疏加配釋，助顯其文。以俗況道，俗淺道深，理必過之，況不及乎？況相反乎？「知下」，三結意。
【譯文】自「依律下」句起，詳細解釋分為三部分：第一、顯示名稱與體相。律中所列十種糞掃衣是：一、被牛嚼破之衣，二、被老鼠咬破之衣，三、被火燒殘之衣，四、沾染月經之衣，五、產婦用過之衣，六、神廟祭祀之衣，七、墳墓塚間死人之衣，八、祈願祭神後捨棄之衣，九、從遠途往返廢棄之衣，十、王職（受刑死者或王官廢棄）之衣。世俗所賤而道人所貴，顯示二者正相反對。自「此下」句起，第二評議其名稱。「常人」是指見識淺陋之輩，若是超卓拔萃的君子，哪會把這衣物看作糞土塵芥呢？自「故下」句起，第三引用世間典籍作比況。首先引用《論語》，「未可與議」是說這種庸俗之人不值得同他論道。《劉子》即劉晝，著書兩卷五十五篇，因貧困潦倒無由自我顯達，便背著自己的書在沈約的車前等候並進獻，沈約展讀後深感其奇異，於是呼喚他登車結為好友，當時人便稱這部書為《劉子》。此處引用其〈防欲篇〉，該篇說「明智之士剖除情執以排遣牽累，節約欲望以堅守貞節」，隨後才接上「食足」等語。「斯言是」一句，是讚賞這話極有道理。自「至下」句起，敘述厭離榮華。「冠」、「衣」二字讀去聲（作動詞用）。章甫是殷商時期的冠帽；縫掖是大袖之儒服。《孔子家語》載孔子回答魯哀公說：「我丘年少時住在魯國，身穿縫掖之衣；年長後住在宋國，頭戴章甫之冠。」「嘉肴」指各類美味菜餚，非五穀主食的菜味稱為肴；「芳音」是指歌舞音樂之聲。「高位」代表顯貴，「厚味」代表富有，具體出自何書尚不詳備。「俱不可久」，是說權勢與富貴終有退失之時。自「是以」以下，明示心向於道。《易經·謙卦》說：「人道惡盈而好謙，謙尊而光，卑而不可踰，君子之終也。」「忍人」等句，是指眾人所不能做到的，我則盡勉力去踐行。文句出自《淨住子》，原文只有三句，疏文加上了對應配釋，以助顯其深意。以世俗之事比況修道，世俗尚淺而聖道至深，其義理必定超越世俗，又怎會及不上呢？又怎會反其道而行呢？自「知下」句起，第三總結其立意。

【1822-0007】03_業疏/17a_卷三之六#143
【原文】問：受體乃在白四，如何方問「能」者？答：計實如問。但機鈍須示，不贊不知。上機善達教旨，不勞示相，如善來三語也；鈍濁有生，更須明示。如不顯然，文中但云受戒，知戒何境？故前止四境，後行四相，分明曉喻，後猶輕陵，何況不語？又不作誓，知誰不犯？故不徒設也。
【譯文】問：納受戒體明明是在白四羯磨之時，為什麼羯磨完畢之後才詢問「能持否」呢？答：若按常理推度確實如你所問。但因為受戒者根機遲鈍必須予以開示，若不輔助點撥他就無法了知。上根之人善於通達教理意旨，不勞費心開示相狀，就像「善來比丘」或受「三歸語」那樣即可得戒；而鈍濁執著的眾生，更必須明確開示。如果不顯明告知，文辭中只說「受戒」，他又哪裡知道所防護的戒是針對什麼境界？所以前面先說明止持的四重境緣，後面闡明作持的四依相狀，如此分明顯白地曉喻開導，事後尚且有人輕慢陵犯，更何況根本不對他說呢？而且如果不立下誓願，又怎能保證日後誰不違犯？所以這絕非徒然設立的。

【1822-0008】03_業疏/17a_卷三之六#144
【原文】問中，先受後問，義似倒故。答中，初通敘二機須否，贊即是助。「鈍下」，次別明鈍機須意。有生，謂著有眾生。羯磨言通，非列不顯。若此猶犯，況不爾邪？
【譯文】在提問中，先受戒而後發問，在義理上看似顛倒之故。在回答中，首先通泛敘述兩類根機是否需要，所謂「贊」就是指贊助、扶助。自「鈍下」句起，接著分別說明鈍根眾生之所以需要的用意。「有生」是指執著於有為世間的眾生。羯磨的言辭通泛，若不一一條列便不能顯明其相狀。若是像這樣明確開示猶且還會違犯，更何況不這樣做呢？

【1822-0009】03_業疏/17a_卷三之六#145
【原文】就衣開中，云「長利」者，對本制外，餘皆長也。「檀越施衣」者，不問道俗，持來淨施，故任納也。「割壞衣」者，前通俗服，此專道相，故二列也。
【譯文】在衣服開許的文句中，所謂「長利」，是相對於根本制戒之外，其餘的都屬於多餘長物。「檀越施衣」，是不管出家人還是俗人，拿來作為清淨布施，所以聽任受納。「割壞衣」，前一句通指世俗的衣服形式，這一句專指僧道法服的相狀（經過裁割截斷以壞其色相），所以分開並列。

【1822-0012】03_業疏/17a_卷三之六#148
【原文】二乞食總分中，初制後開，大分二段。制中亦四：一、舉名，二、示行本，三、問，四、誓，並同上分，後二亦爾。
