# 校閱材料　第1330檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1330-0001】資持記/15b_下三#38
【原文】文中且舉見聞，準論，具云：舍衛九億家，三億家眼見佛，三億家耳聞有佛而眼不見，三億家不聞不見佛，在舍衛二十五年，而此眾生不聞不見，何況遠者。〔論舉王舍億數，不說見聞。〕由慢業者，出不見及不聞之所以。我輩生不值佛，豈非慢重。撫膺自責，深痛沈淪。嗚呼！佛下，舉況。
【譯文】文中姑且列舉見聞佛陀的情形，依照論典完整記載則是：舍衛國共有九億人家，其中三億家親眼見過佛，三億家耳聞有佛卻未曾親眼得見，還有三億家不曾聽聞也未曾見過佛；佛在舍衛國常住了二十五年，當地的眾生尚且有人不曾聽聞也未曾得見，何況是遠方之人呢！〔論典中列出王舍城的億數人口，並未說明見聞的情況。〕所謂「由於傲慢惡業」，這點明了不見佛與不聞佛的原因。我們這輩人生來未能親值佛陀在世，難道不正是因為傲慢習氣太深重了嗎？撫胸自省責備，為自己長劫沉淪感到無比痛心。悲哀啊！「佛」字以下，舉出比況。

【1330-0002】資持記/15b_下三#39
【原文】滅後正法，不及現在；像不及正，末不及像，故云轉輕，謂奉佛之心薄也。心業，即慢習也。〔古記，並以夏殷周三代正朔，和會諸文者，甚違租意；若可和會，即非見聞不同；況復經論，並據西竺日月，那將此方正朔和會耶！〕《感通傳》祖師問天人云：此土傳佛生時不定，如何指的？
【譯文】佛滅度之後的正法時期，已比不上佛在世之時；像法時期比不上正法時期，末法時期又比不上像法時期，所以說是每況愈下，指敬奉佛陀的心意日漸微薄。所謂「心業」，就是指傲慢的惡習。〔古代的註記，多半拿夏、殷、周三代的正朔曆法，來牽強附會諸部經文，這極度違背了祖師的本意；如果能夠這樣和會，就不能稱作眾生見聞各有不同了；何況經論全都是依據西印度的曆法月份，哪裡能用此地的世俗正朔來牽強附會呢！〕《感通傳》中道宣祖師曾詢問天人說：「此方流傳佛陀降生的時間各不相同，究竟該如何確指？」

【1330-0003】資持記/15b_下三#40
【原文】天人答云：皆有所以，弟子是夏桀時生，具見佛之垂跡；然佛有三身，法報二身，非人天所見；化身普被三千，故有百億釋迦，隨機所感，前後不定，不足疑也。〔準知昔記，不可依也。〕四中，初標比丘啟問。下佛答中。三寶及戒，住持綱領；敬慢興廢，必其然乎。二敬僧者。謂四人已上大眾也。
【譯文】天人回答說：「這都是有因由的，弟子我是在夏朝桀王時出生的，親眼備悉佛陀降世垂跡的始末；然而佛陀具有三身，其中的法身與報身，並不是凡夫天人所能見到的；應化身普門救度三千大千世界，所以有一百億個釋迦化身，隨著眾生根機感應的不同，降世的先後時間自然不定，這完全不足為怪。」〔依照這個說法便可知，過去那些和會的註記是不足為憑的。〕在《四分律》引文中，起初標明比丘啟問。下文佛陀的回答之中提到，三寶與戒律是正法住持的綱領大則；佛法的敬仰與輕慢、興盛與衰廢，必然是與此息息相關的。「敬重僧寶（敬僧）」這部分，是指敬重四人以上的僧伽大眾。

【1330-0004】資持記/15b_下三#41
【原文】釋中，初科，前明徒眾侍立。無有違者，謂順教也。傳下，指妄。傳字平呼。今時禪講，不知禮法，端受眾禮，壞滅僧宗。且四人僧者，辨事功高；別人力弱，理無反敬；為存教誡，暫開眾立。況外無軌範，內德空虛；但欲自尊，寧思來報。必負高識，願聽直言；或對大眾，必須起敬；
【譯文】在解釋之中，第一科前半段說明徒眾侍立的規矩。所謂「無有違犯」，是指順應戒律的教導。「傳」字以下，指出錯誤的作法。「傳」字讀作平聲。如今那些參禪講學之人，不懂得戒律規矩，端然高坐接受大眾頂禮，這是在毀壞消滅僧門宗風。要知道四人以上的清淨僧伽，辦理僧事功德極高；單獨一人的力量微弱，僧伽於理絕無反過來禮敬個人的道理；只是為了維持教誡之儀，才暫時開許眾人肅立。何況這些人外表毫無儀軌風範，內在德行一片空虛；一心只想自我尊大，哪裡會去思量未來的惡報！若真懷有高明見識，但願能聽得進直言規勸；若是面對僧團大眾，自己必須起立致敬；

【1330-0005】資持記/15b_下三#42
【原文】或受眾禮，止可三人；或眾圍立，恒知非便。既居師表，豈得懵然。次科。僧殘已下者，以犯初篇，失師位故。弟子經理者，謂求僧行法，弟子預數故。亦須敬禮者，謂師乞懺設禮陳詞也。為下二句，明反敬之意。是知弟子在僧，但據僧別強弱，不論師資高下也。
【譯文】若是接受眾人頂禮，至多只能有三個人；若是被大眾圍繞侍立，心中要時刻明白這是不合宜的。既然身為人師表率，哪裡能夠這般茫然無知！下一個科判中，所謂「犯僧殘罪以下者」，是因為若犯了波羅夷初篇重罪，便徹底喪失師長身分的緣故。所謂「弟子經理營辦」，是指為了祈請僧伽推行懺罪之法，弟子也參與列入僧數的緣由。所謂「亦必須恭敬頂禮」，是指師長向僧團乞求懺悔時，必須親自設禮陳詞。這「為」字開頭的兩句，說明了反向行禮的意旨。由此可知，當弟子列入僧伽之中時，只看僧團與個人的集體力量消長，而不再論及平日師徒名位的高低。

【1330-0006】資持記/15b_下三#43
【原文】行懺既爾，齋講餘事，準義皆同，故注以示之。大小相敬中，初科；初《母論》，即佛垂滅囑累之詞，初令奉戒。以木叉住持中勝，故制依之。當下，次令相敬。淨法即律範。尊者，謂臘高德重，為人所尊；慧命，謂博聞強識，以慧為命，皆相美讚之辭也。第二次禮中，初通示。
【譯文】推行懺悔法事尚且如此，其餘設齋、講經等諸多法事，依此義理推斷完全相同，所以注文特意指明這一點。在「尊卑長幼互致敬重（大小相敬）」的第一科之中；起初引用《薩婆多毘尼母論》，這是佛陀臨近滅度時的咐囑叮嚀之語，起初命令大家必須恪奉戒律。因為波羅提木叉在住持正法中最為殊勝，所以制定必須依憑於它。「當」字以下，接著命令彼此要相互敬重。「淨法」是指戒律威儀的規範。「尊者」是指戒臘高深、道德厚重，為大眾所尊崇的人；「慧命」是指博學多聞、記憶堅固，以智慧為身命的人，這都是彼此稱讚讚歎的敬語。第二、次明敬禮的內容中，首先通盤說明。

【1330-0007】資持記/15b_下三#44
【原文】五眾下略及塔字。相禮者，若五眾相對，則四位尊卑；二眾沙彌，同一位故；若五眾各論，自分大小；當眾同臘，則須對禮。如來及塔，五眾齊敬；一向是尊，故云通禮。塔即墳塚。初下，別列。次科，《五百問》中。決前禮塔，引佛為比，意在報恩。死下，義準。論明禮塚，不言屍故。
【譯文】「五眾」二字之下，省略了「及塔」二字。所謂「相互敬禮」，如果是五眾弟子互相比對，則存在四個尊卑階位；出家男女二眾沙彌，屬於同一個階位；如果是五眾各自內部論處，自然劃分長幼尊卑；在同一眾中若是戒臘相同，就必須互相談對行禮。至於如來與佛塔，則是出家五眾一律齊心敬重；這純然是至高無上的尊境，所以說是通受敬禮。塔就是指安置舍利的墳塚。「初」字以下，分別逐一列出。下一個科判引用《五百問》。對前文禮拜佛塔作了決斷，引佛陀來作比對，本意在於知恩報恩。「死」字以下，是依義理推斷。因為論典只載明禮拜墳塚，並未提及頂禮遺體。

【1330-0008】資持記/15b_下三#45
【原文】別示中，初文。若據沙彌，亦取受戒前後，分上中下；此約多人初受，排次為言。生年，即俗年長幼。出家年，即入道先後。次科。問意，恐謂下眾同大僧故。答中二義，初約戒等釋。未具總名者，同號沙彌故。無勝德者，戒體同故。又下，次約非師釋。大僧不爾，反上二義；
【譯文】在「分別開示（別示）」的第一段經文中，如果就沙彌而言，原本也是依照受戒先後來區分上中下座；此處是就多數人同時初次受戒、排定座次的情形來說的。「生年」是指世俗年歲的長幼。「出家年」則是指遁入佛道時間的先後。下一個科判中，發問的本意，是擔心有人會誤以為下座沙彌等同於大僧比丘。回答中包含了兩種義理，第一是從戒體平等來解釋。所謂「未具足通名」，是因為大家都同樣被稱為沙彌的緣故。所謂「沒有殊勝德行」，是因為所領受的戒體完全相同的緣故。「又」字以下，第二是從對方並非自己和尚師長的立場來解釋。大僧比丘則不是這樣，正好反轉了上述兩種義理；
