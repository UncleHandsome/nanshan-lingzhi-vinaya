# 校閱材料　第1069檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1069-0001】資持記/06b_中一上#3
【原文】尼無十六戒：輒教、日暮、譏教、作衣、與衣、屏座、尼期行、期乘船、女期行、受贊食、勸足、索美、牙角、坐具、覆瘡、佛衣；自餘尼中一百四戒，尼戒具列；名數既繁，不可具引，須者看之。指如別者，同如〈釋相〉，別在〈尼篇〉；又《義鈔》、《戒疏》，具有料簡。
【譯文】比丘尼沒有比丘戒中的十六條戒：輒教、日暮、譏教、作衣、與衣、屏座、尼期行、期乘船、女期行、受贊食、勸足、索美、牙角、坐具、覆瘡、佛衣；其餘比丘尼戒中的一百零四條戒（即除去與僧相同的七十四戒外，尼戒另有一百零四戒），尼戒本中皆有完整列出；名目條數既然繁多，在此無法一一引錄，有需要者可自行查閱。原文指出「詳細內容如別處所載」，相同的部分如〈釋相篇〉所述，相異的部分則收錄在〈尼篇〉；此外在《義鈔》與《戒疏》中，也都有非常詳盡的料簡辨析。

【1069-0002】資持記/06b_中一上#4
【原文】別翻中，初引《出要律儀》。單翻薩耆而云墮者，因而雙牒；墮名同上，自可解故。〔舊云：上略波逸提字者，非。〕《聲論》。盡捨者，準下懺法捨有三種：一財，二心，三罪；義雖通三，名專財事；長染有遺，不成捨懺，故云盡也。下波逸提，但正梵言；
【譯文】在個別翻譯戒名的段落中，首先引用《出要律儀》。其中單單翻譯「薩耆」卻連帶稱為「墮」者，是因為順著文勢而將兩詞並列標出；「墮」的意涵與前述相同，自然容易理解。〔舊註說：上面是省略了波逸提三個字，這種說法是錯誤的。〕接著引用《聲論》。所謂「盡捨」，依照下文懺悔法門的解釋，捨棄包含三種層面：第一是捨棄財物，第二是捨棄慳貪之心，第三是捨棄罪法；義理雖然貫通這三種，但在此處名稱上專指捨棄財物之事；如果蓄積愛染而仍有絲毫殘留，就不能構成合法的捨財懺罪，所以稱作「完全捨棄（盡）」。後面的「波逸提」，只是訂正其梵文發音；

【1069-0003】資持記/06b_中一上#5
【原文】名義同上，故不重釋。五中亦三，初示總數。二翻名義，次引三律所譯不同；正量三義，共釋一名；初約繁細。一百二十，數過諸篇，故云罪多；體是威儀，故云輕細。二約參濫。制即是遮。異上兩篇但除媒房餘竝性罪，已後諸篇皆是遮罪。三約數犯。由前二義，以成第三，故結名在後。
【譯文】名相與義理都與前面相同，所以不再重複解釋。第五項中也包含三個部分，首先標示總數。第二是翻譯名義，接著引用三部律典的不同翻譯；正量部提出了三種義理，共同解釋這一個名稱：第一是依據戒相繁瑣細碎來解釋。此篇有一百二十條，數目超過其他各篇，所以說是「罪多」；體性屬於威儀，所以說是「輕細」。第二是依據可能參雜混淆來解釋。佛陀制定此戒即是遮止之法。此篇不同於前兩篇（前兩篇除了媒嫁與房舍二戒外其餘全都是自性罪），自此篇之後的各篇全都是遮止罪。第三是依據容易頻繁違犯來解釋。正是由於前兩種義理，才構成了這第三點，因此將名稱總結在最後。

【1069-0004】資持記/06b_中一上#6
【原文】應，即佛制；功用，不出解行。問：此與眾學立名何異？答：此具三義，治行尤難，故須功用；吉非性業，制行亦輕，但云當學。次引《婆論》。與前正量語有少殊，義同後一。前之二部，竝就能治行為名。後上座部。即從不善業體為目，即同墮義也。此業能污善淨之心，故因中如焦然也；
【譯文】所謂「應」，就是佛陀的制約；所謂「功用」，不外乎理解與實踐。問：此篇名稱與「眾學」在立名上有何不同？答：此篇具備上述三種義理，要對治調伏極為困難，所以必須付出極大功用；突吉羅並非自性業道罪，佛陀制戒要求奉行的程度也較輕，因此只說「應當學習」。接著引用《婆沙論》。它的文字與前面正量部的說法有些微差異，但義理與後一種說法相同。前面這兩個部派，都是依據能夠對治的修行實踐來立名。最後引用的上座部，則是直接從不善業的自體來立名，這與「墮」的意義完全相同。這種惡業能染污清淨善良的本心，所以在因位時就像被烈火焦灼一般；

【1069-0005】資持記/06b_中一上#7
【原文】復能轉變獄報炎熾，故果時受燒熱也。三但下，明方便罪。但二罪者，示現重輕有差降故。五提舍尼，翻名中，初示名。言向彼者，即對首人，故云對治境也。次引證。《僧祇》，得上悔義，不兼所對。戒本具明，即云：應向餘比丘悔過等是也。次科。
【譯文】它又能轉變招感極為熾烈的地獄果報，所以在受果報時必須承受熱鐵燒煮之苦。第三從「但」字往下的文段，說明方便罪。此處只列出兩種方便罪，是為了顯示情節輕重有其遞減的等次。在第五「提舍尼」翻譯名稱的段落中，首先標示名稱。所謂「向彼」，就是指面對具格的對首比丘，所以說是「對治之境界」。接著引證。《僧祇律》只具備向上悔過的意思，並不兼含所面對的對象。戒本中則有完整說明，也就是說：「應當向其他比丘悔過」等等就是這項意涵。進入下一科。

【1069-0006】資持記/06b_中一上#8
【原文】尼有八者，即無病乞酥、油、蜜、石蜜、乳、酪、魚、肉；對此八物，而制八戒。示數中。四戒各二方便，故有十二。各對者，即對別人，顯非眾也。六突吉羅，初科，前翻律中名。言惡作者，通收身口。《四分》下，翻戒本名，初翻名有二。
【譯文】比丘尼有八條戒，是指在無病狀態下索求酥、油、蜜、石蜜、乳、酪、魚、肉；針對這八種食物，因而制定了八條戒。在標示數目的文段中，這四條戒各自具有兩種方便罪，所以共有十二種罪過。所謂「各對」，就是面對個別的人，藉此顯示並不是在僧團大眾中懺悔。在第六「突吉羅」中，第一科首先翻譯律典中的原名。所謂「惡作」，是通泛涵蓋了身體與語言兩方面的過失。從「四分」往下的文段，翻譯戒本中的名稱，首先在翻譯名稱部分有兩種解說。

【1069-0007】資持記/06b_中一上#9
【原文】《善見》云：式叉翻學，迦羅尼云應當，今迴其語順此方言；胡僧，即祖師親承，非所出也。疏云：若就所防，應名眾突吉羅，今就能治行以立目也。此下，雙釋。《多論》。問：何故此篇獨名應當學？答：餘戒易持而罪重，犯懺是難；此戒難持而易犯，常須念學故。《十誦》下，結顯。
【譯文】《善見論》說：「式叉」翻譯為學習，「迦羅尼」翻譯為應當，現在將語序倒轉以順應漢地的語言習慣；胡僧的說法，是祖師道宣親自承襲得來的，並非律文原出的譯詞。疏文說：如果就所防範的過失而言，應當命名為「眾突吉羅」，現在則是依據能對治的修行來確立名稱。從此往下的文段，雙重解釋這兩層含義。接著引用《多論》。問：為什麼這一篇單獨命名為「應當學」？答：其他戒條容易持守但罪過沉重，一旦違犯要懺悔極為困難；這一篇戒條極難持守卻極易違犯，必須時常憶念學習的緣故。從《十誦律》往下的文段，總結並彰顯此意。

【1069-0008】資持記/06b_中一上#10
【原文】文舉疾雨，喻其犯者甚多，意顯持之非易。豈下二句，雙結兩名。專翫在心，即學義也。僧尼中。諸部名數不同，《僧祇》六十六，《十誦》百單七，《五分》數同而相別，故標此律簡之。尼戒本中，不列眾學；指略如僧，相同故也。三中。律文前後列七聚名，第六或異，乃華梵互舉耳。
【譯文】經文中以急風暴雨作為比喻，形容違犯的人非常多，目的在於彰顯持守這類戒律並不容易。後面的「豈……」兩句，雙重總結這兩個名稱。專注玩味並銘記於心，就是「學」的真正意義。在比丘與比丘尼戒的比較中，各個部派的名稱條數並不相同，《僧祇律》有六十六條，《十誦律》有一百零七條，《五分律》條數相同但戒相有別，所以特別標明此律以資甄別。在尼戒本中，並未一一列出眾學戒；只是省略並指明如同比丘戒，因為兩者戒相完全相同的緣故。在第三科中，律文前後所列的七聚名稱，第六聚有時用詞不同，那只是梵文音譯與華語意譯交替使用罷了。
