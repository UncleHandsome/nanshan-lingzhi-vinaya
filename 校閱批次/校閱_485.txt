# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【485-0002】03_業疏/08b_卷二之二#74
【原文】問：有村結已，不得會衣，與本無村何須著除？無村無結，村來障衣，與有結同，何須著除？答：為釋疑故。未結之前，院內界外，不免失衣，由諸界故；今既結竟，車、樹界滅，疑謂村界亦隨不生，為釋此疑，故二俱除。村有五義，如論故除：一、聚落界散亂不定，衣界是定故；二、為除誹謗故；三、為除鬬諍故；四、為護梵行故；五、為除嫌疑令清淨故。餘界無情，故不須除
【譯文】問：有村落處結界之後，不能在村中攝會衣物，這與本來無村相比，為何需要宣明除去？本無村落亦未結衣界之處，村落遷來時會障礙攝衣，與有結界者相同，又何須宣明除去？答：是為了釋除疑惑的緣故。在未結界之前，在僧院之外、大界之內，免不了會失去衣物，這是由於存在各種自然界的緣故；如今既然結界完畢，車界、樹界等自然界皆隨之消滅，人們便會懷疑以為村落界也隨之不生，為了釋除這種疑惑，所以兩者都要宣讀除去。村落具有五種意義，正如論中所說所以必須除去：第一、聚落界散亂不定，而衣界是固定不變的；第二、為了消除誹謗；第三、為了消除鬥諍；第四、為了守護梵行；第五、為了消除嫌疑令得清淨。其餘自然界屬於無情之物，所以不需要宣明除去。

【485-0003】03_業疏/08b_卷二之二#75
【原文】次問有二：初、有村障衣，結須牒除，無村通護，著除何益？此明無村不須牒也。二問、無村不結之處，不曾牒除，村來亦障，比於有村結者，牒則無功，此顯有村亦不須除也。「與」，猶比也。答中初釋通。「院內界外」，內外字倒，傳文誤也。未結則院外自然樹、車各立，故有失衣；結已則作法勢強，諸餘即滅，唯村自攝，故必須除。「村」下，次釋偏除所以。五義中，初是難護，餘並招譏。村聚則移徙不常，衣界須分齊可準，故云定不定也。四中，第四護己，餘三護他。上明村界須除，「餘」下次簡餘界不須，以樹、車等無情染故
【譯文】第二問包含兩個層面：第一、有村落會障礙攝衣，結界時必須宣讀除去；無村落處全面攝護，宣明除去有何益處？這是說明無村時不需要宣讀。第二問、無村而未結界之處，不曾宣讀除去，村落遷來時同樣障礙攝衣，相比於有村而結界者，宣讀便毫無功用，這顯示有村落時也不需要宣除。「與」就像相比的意思。答語中首先解釋會通。「院內界外」的「內」、「外」二字顛倒了，是傳抄文本的訛誤。未結界時，院外自然界如樹木、車輛各自獨立，所以會有失衣；結界完畢後作法之勢強大，其餘自然界隨即消滅，唯獨村落自有界限攝受，所以必須宣讀除去。自「村」以下，其次解釋唯獨除去村落的原因。五種意義中，第一條是難於守護，其餘各條都是招致譏嫌。村落聚落則遷徙不定，衣界必須界限明確可循，所以說「定與不定」。在後四條中，第四是護持自己，其餘三條是護持他人。上面說明村落界必須除去，自「餘」以下其次簡別其餘自然界不須除去，因為樹木、車輛等無情物不會產生染著之故。

【485-0005】資持記/15c_下三#16
【原文】次無法中，初科。綿積，猶言長久。秉，即執也。錯舉，謂每事廢立，皆任意耳。倣斆，謂互習訛風。競心，謂鬪競為懷。力志，即竭力用意。高顯，即副競妙之心。過彼，乃稱勝他之志。次科。明俗人愚暗，文敘本主，義通餘人。毀壞，約物；損辱，約僧。承即奉事。此科大字，並引《寺誥》，故注以助之。
【譯文】）接著在明示「無有法度」的科判中，是第一小科。所謂「綿積」，就是指年代久遠、積累長久之意。秉，就是執持執掌的意思。所謂「錯舉」，是指每件事無論是廢除還是建立，全憑個人私意隨興亂來。所謂「倣斆」，是指彼此盲目模仿沿襲錯誤的陋習風氣。所謂「競心」，是指內心始終懷抱著爭強好勝的念頭。所謂「力志」，就是竭盡全力、挖空心思。所謂「高顯」，正是為了符合那種想要爭奇鬥勝、炫耀誇耀的心態。所謂「過彼」，才算真正稱合了企圖超越壓倒他人的好勝意志。接著是下一個小科。說明俗世凡夫的心智愚痴闇鈍，經文表面上雖在敘述寺院原有的施主，但義理上通於其餘一切在家人。所謂「毀壞」，是就侵奪破壞物質用度而言；所謂「損辱」，是就輕慢侮辱僧眾尊嚴而言。承就是指奉承事奉。這一科中的大字正文，全部出自《寺誥》，所以撰者特加註釋以輔助理解。

【485-0016】03_業疏/08b_卷二之二#80
【原文】十誦》云：除聚落及聚落界，結取空地及住處。村及勢分，衣界不生。故《善見》云：村外界者，中人擲石以還，是也。人即解云：《十誦》結時，現除懸結，以文云「結取空地」者，即村外勢分也；「及住處」者，謂村體也。後村移出，更不須結。《四分》無預結文，故現除懸不結也
【譯文】《十誦律》說：除去聚落以及聚落界，結取空地與住處。村落及其勢分之內，衣界不生。所以《善見論》說：村落外面的界，是指中等力氣之人投擲石塊所及以內的範圍，即是此意。有人就解釋說：《十誦律》在結界時，是當前宣讀除去而預先通結，因為文中說「結取空地」，就是指村外的勢分；「及住處」，就是指村落的本體。日後村落遷出，便不再需要結界。《四分律》中沒有預先結界的文句，所以是當前宣讀除去而預先不結。

【485-0017】03_業疏/08b_卷二之二#81
【原文】次科，《十誦》四句，即彼羯磨中牒除文也。上二句同今《四分》，後二句彼部所加。「村」下，釋上二句，村即聚落，勢分即聚落界也，文既牒除，故界不生。仍引《善見》示上勢分，即十三步。「人」下，次出他解，彼謂《十誦》四句，上二句是現除，下二句是懸結；《四分》止有二句現除，文無下二句預結文，故云懸不結也
【譯文】下一科中，《十誦律》的四句，就是彼律羯磨文中宣讀除去的語句。上兩句與現今《四分律》相同，後兩句是該部律所增加的。自「村」以下解釋上兩句：村就是聚落，勢分就是聚落界，文中既然宣讀除去，所以衣界不在彼處生起。隨後引用《善見論》指示上述的勢分，也就是十三步的距離。自「人」以下，其次列出他人的解釋，彼人認為《十誦律》的四句中，上兩句是當前宣除，下兩句是預先加結；而《四分律》只有兩句當前宣除，文中沒有下兩句預結之文，所以說預先不結。

【485-0018】03_業疏/08b_卷二之二#82
【原文】今解不然。既除聚落，明有所除；「結取空地」者，僧坊外地；「及住處」者，謂僧坊也。此內攝衣，餘是所除，故不徧也
