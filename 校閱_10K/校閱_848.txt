# 校閱材料　第848檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【848-0001】02_戒疏/20c_卷四下之二#22
【原文】【記】初戒，通釋中，初科。初示本宗文略。後「三衣戒」，云「觀三世」，初戒不敘，故云「不委悉」。「如」下，引他部以示。《十誦》，「淨居天」，通指色界諸天。云「天報」者，即告佛也，《義鈔》云「聞淨居空言『齊著』，故制此戒」是也。《多論》初問，謂佛制戒，據合並觀三世，何獨此戒耶？「答」中，有四。初約漏落釋。「又」下，次約先制釋。「又」下，三、約遮慢釋。古本「淨居天」下有「答」字，即前天報也。「又」下，四、約盡同釋。「觀佛天」者，觀佛取式，觀天令報故。
【譯文】【記文】第一條戒在通盤解釋的段落中，這是第一小科。起初點出本宗律文敘述較為簡略。後文的「三衣戒」提到「觀察三世諸佛」，本戒卻沒有敘述，所以說「不夠詳盡」。「如」字以下的文句，引用其他部派律典來作說明。《十誦律》所說的「淨居天」，泛指色界諸天。說「天人回報」，就是指向佛陀稟告，《義鈔》說「聽聞淨居天人於虛空中稟告說『應當齊整穿著』，所以制定此戒」，就是指這件事。《薩婆多論》最初的提問，是認為佛陀制戒，按理都應該觀察三世諸佛，為何唯獨此戒特別記載？在「回答」中，共有四種觀點。第一是從文字漏落的角度來解釋。「又」字以下，第二是從原本先制定的角度來解釋。「又」字以下，第三是從防杜慢心的角度來解釋。古本在「淨居天」之下有「答」字，即是指前面的天人回報。「又」字以下，第四是從諸佛完全一致的角度來解釋。「觀察佛陀與天人」，是指觀察諸佛以取為法式，觀察天人令其回報實情。

【848-0003】02_戒疏/20c_卷四下之二#24
【原文】【記】答：「三世杳邈，凡情莫知，然彼諸天皆服袈裟，故《業疏》云『梵天行四等，恒服法衣。』彼知三世，又復親行，足堪為證。欲令深信奉行，垂萬代之正軌也。」
【譯文】【記文】回答說：「三世時代久遠廣闊，凡夫情見無法測知，然而色界諸天都穿著袈裟，所以《業疏》說『梵天修行四無量心，恆常穿著如來法衣。』彼天人明了三世諸佛之事，自己又親身奉行，足以作為明證。佛陀這是為了讓凡夫深信奉行，垂範為萬代的法軌。」

【848-0004】02_戒疏/20c_卷四下之二#25
【原文】【疏】疏者言，此是輕小之戒。緣起、廣辨，皆威儀違失之過。唯《戒本》中偏舉能治行者舉教勸學，不明所防。彼此互顯，令尋條有據也。
【譯文】【疏文】寫疏的古德說，這是輕微細小的戒條。其緣起與廣泛辨析，都是在說明違失威儀的過失。唯獨在《戒本》中，單單舉出能夠對治的行持，以此舉示教法勸勉學者，而沒有明說所要防範的過失。二者互相參照發明，才能使求索條理的人有所依憑。

【848-0005】02_戒疏/20c_卷四下之二#26
【原文】【記】次會不同中。「緣起、廣辨」，並見注中。且如初戒，緣六群著衣不齊整，又如「廣辨」，示高下不齊整之相，故云皆示過也。《戒本》但云「齊整」，即「能治行」，而不顯過，故云「不明所防」。「彼」下，示不同意。
【譯文】【記文】接著在融會相異之處的文句中。「緣起與廣泛辨析」，都見於註解之中。就如第一條戒，緣起是由於六群比丘穿衣不齊整，又如「廣泛辨析」，指示了過高、過低等不齊整的外相，所以說都是在揭示過失。《戒本》只說「應當齊整」，這就是「能治之行」，而沒有顯露過失，所以說「沒有明示所防」。「彼」字以下的文句，顯示兩者表述不同的用意。

【848-0008】02_戒疏/20c_卷四下之二#29
【原文】【疏】然西土之僧，所有內衣，直將橫㲲，皆後前遮，手張兩角，左右掖掩，仍以長繩四帀纏腰，抽拔使正，安四襵而已。若繩斷解，裙即在地。身子覆面，其事驗乎？今此唐僧，例加腰襻，四帶紐結，實有齊焉。而闊緣垂地，有乖法律。
【譯文】【疏文】然而西域印度的僧人，所擁有的內衣，只是一塊橫幅的白細布，都是從身後向前圍裹遮蔽，用雙手張開兩個布角，在左右兩側掖塞掩裹，再用長繩在腰間繞上四圈緊緊綁住，抽拔平整，安設四個皺折而已。如果繩子斷裂鬆開，長裙就會隨即掉落在地。舍利弗長裙滑落而掩面仆地，這件事不就是明證嗎？如今這唐土的僧人，大都額外縫製了腰襻，用四條帶子紐結繫緊，確實穿得很整齊。然而若是裙襬過於寬大拖垂在地上，就違背了戒律的規範。

【848-0009】02_戒疏/20c_卷四下之二#30
【原文】【記】正釋中，初科。先示梵國著法。「安四襵」者，前後及兩邊。「身子覆面」者，舍利弗裙解，恐形露遂什于地，可驗西土本無腰帶。「今」下，次明唐土不同。腰襻應教，闊緣乖法。「四帶」未詳，今但兩帶耳。
【譯文】【記文】在正式解釋的文句中，這是第一小科。先說明印度西域的穿著方法。「安設四個皺折」，是指前後以及兩側。「舍利弗掩面」，是指舍利弗的長裙鬆脫，他唯恐身體暴露於是撲倒在地上，這可以證明西域本來是沒有腰帶縫在裙上的。「今」字以下，接著說明唐土習慣的差異。腰襻是符合教規的，但寬邊垂地就違背了法則。「四條帶子」的制度尚不詳明，現今通常只用兩條帶子而已。

【848-0010】02_戒疏/20c_卷四下之二#31
【原文】【疏】《四分》辨相，唯明其非，諸部互說，各有高下。如《多論》、《十誦》，聽至踝上一磔手，遠行二磔手，上至膝。尼三眾正使行來，止在踝上一磔手也。故《僧傳》中「納衣半脛」，誠有依矣。《母論》：「踝上三指。衣長四肘，廣一肘半，是內衣量。」《五分》：「從跟上取一磔手，左掩其上，兩邊兩葉，當後兩葉。不解，不問，而作著者，吉。若解，不依著，吉。輕戒輕人，作此著者，提。」為通引文。《十誦》疑高，《母論》處中，又扶本律。
【譯文】【疏文】《四分律》辨析衣相，只說明怎樣是不對的，其餘部派各有說法，對於高低尺寸各有規定。例如《薩婆多論》、《十誦律》，准許裙襬高至腳踝以上一磔手，出遠門時可高至二磔手，最高到膝蓋。比丘尼等三眾即使行路走動，高度也僅限在腳踝以上一磔手。所以《高僧傳》中記載「法衣高至小腿肚的一半」，確實是有依據的。《毘尼母論》（《毘尼母經》）說：「腳踝以上三指。內衣長度為四肘，寬度為一肘半，這就是內衣的法定尺寸。」《五分律》說：「從腳後跟往上取一磔手，左邊掩覆在上面，兩側各有葉折，身前身後各有葉折（前後兩邊共成四折）。不理解教法、也不去請教，就盲目穿著者，犯突吉羅罪。如果理解了，卻不依規定穿著，也犯突吉羅罪。若是輕蔑戒律、輕慢持戒之人，故意學著這樣穿來戲弄者，犯波逸提罪。」這是為了融通而引用的文獻。《十誦律》的規定令人懷疑太高，《毘尼母論》的尺度適中，又恰好符順本宗戒律。
