# 校閱材料　第095檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【095-0001】02_戒疏/04b_卷一下之二#96
【原文】【疏】問：「此七方便依何而述？」
【譯文】【疏文】問：「這七種方便是依據什麼而陳述的？」

【095-0002】02_戒疏/04b_卷一下之二#97
【原文】【疏】答：「出在《律》文境想五句。以彼文言『人，非人想』、『人，非人疑』，即是向述想、疑二位。『非人，人想』，則是境差，如前所指。餘四方便，義通剋漫，境想無文。是故《律》云『不成，偷蘭』，則攝四位，可以知也。」
【譯文】【疏文】答：「出自《律》文中的境想五句。因為律文中說『是人，作非人想』、『是人，作非人疑』，這就是剛才所陳述的想差、疑心兩項。『是非人，作人想』，則屬於境界差錯，如前文所指示。其餘四種方便，義理上通於剋心與漫心，在境想文中並無明文。因此《律》中說『若事未成，犯偷蘭遮』，這句話就包攬了這四種情況，由此便可以知道了。」

【095-0003】02_戒疏/04b_卷一下之二#98
【原文】【記】宗致者，顯示七緣，皆有誠據。「宗」，即文之所出，「致」，謂立之所以。問意可見。答中，初指三種所出。「《律》中境想五句」：初、人作人想，夷；二、人作非人疑，蘭；三、人作非人想，蘭；四、非人人想，蘭；五、非人非人疑，蘭。「餘」下，次明四種義立。「剋」、「漫」二位，本出境想，今此四緣，皆可具之，故云「義通」，則明境想有義無文也。「是」下，指通文以攝。由此四緣，皆不至果，故可通準「不成」之文。私謂「闕比丘緣」，準諸戒末並云「顛狂、心亂，痛惱所纏」，即其文矣。
【譯文】【記文】宗致，是指顯示這七種緣皆有確實的依據。「宗」是經律文字的出處，「致」是指設立的緣由道理。提問的用意顯而易見。回答中，首先指出其中三種的出處。《律》中的境想五句是：一、是人而作人想，犯波羅夷；二、是人而作非人疑，犯偷蘭遮；三、是人而作非人想，犯偷蘭遮；四、是非人而作人想，犯偷蘭遮；五、是非人而作非人疑，犯偷蘭遮。「餘」字以下，接著說明其餘四種是依義理設立。「剋心」與「漫心」兩種心態，原本出自境想條文，如今這四種緣，都可以具備這兩種心態，所以說「義理相通」，這說明了在境想文中有其義理而無特定死文字。「是」字以下，指出共通的律文來收攝。由於這四種緣，最終都沒有達到究竟果罪，所以可以通盤準用律中「不成，偷蘭」的經文。我私下認為「缺比丘緣」，準照各條戒律末尾皆說「精神發狂、心智散亂、被極度痛苦逼惱所纏」，就是該項的律文依據了。

【譯文】【疏文】第四大門，說明持戒與犯戒的義理（持犯義）。

【095-0005】02_戒疏/04b_卷一下之二#100
【原文】【疏】略分四門：初、知名字；二、明體狀；三、釋成就；四、辨位致。
【譯文】【疏文】大略分為四門：第一、明白名稱（知名字）；第二、說明實質體狀（明體狀）；第三、解釋成辦與具備（釋成就）；第四、辨析階位與立意（辨位致）。

【095-0006】02_戒疏/04b_卷一下之二#101
【原文】【記】四、明持犯。《鈔》具七門，此但明四，故云「略分」。名必召體，體成有處，心容明昧，四段辨相，大途已顯。餘如對篇，逐位別配。
【譯文】【記文】第四，說明持犯。《行事鈔》具備七門，此處僅說明四門，所以說「略分」。名稱必定會召示實質本體，本體成立必有其處所，心念則容有明白與昧昧之分，透過四個階段來辨別行相，持犯的大致綱要便已顯明。其餘細節則如對照戒本各篇時，依照各個階位個別配當。

【095-0007】02_戒疏/04b_卷一下之二#102
【原文】【疏】就初門中，言「名字」者，持有兩種，犯亦同然，各有止作，例分為四。
【譯文】【疏文】在第一門中，說到「名稱」，持戒有兩種，犯戒也是如此，各自包含「止」與「作」，依例可劃分為四種。

【095-0008】02_戒疏/04b_卷一下之二#103
【原文】【記】名字中。「名」即是「字」，無別所以，不必強分。然須先了二名，並依受體而立。由本受時，不出二心，一者斷惡，二者修善。所發業性，即本願體。隨中守護，對分兩持，違反本受，即戒兩犯。
【譯文】【記文】在名稱之中。「名」就是「字」，沒有別的深意，不必強行分別。然而必須先明瞭這兩個名稱，都是依託所受的戒體而建立。因為最初受戒之時，不外乎兩種心願：一是斷除一切惡，二是修持一切善。內心所生起的業性，就是原本誓願的戒體。在隨後的行持中加以守護，對應劃分為兩種「持」；違背了最初所受的誓願，那就是戒律上的兩種「犯」。

【095-0009】02_戒疏/04b_卷一下之二#104
【原文】【疏】先明二持。
【譯文】【疏文】首先說明兩種持戒（二持）。

【095-0010】02_戒疏/04b_卷一下之二#105
【原文】【疏】所言「止」者，方便正念，護本所受，禁防身口，不造諸惡，目之為「止」。止而無違，戒體光潔，順本所受，稱之曰「持」。持由止成，號「止持戒」。如初篇等，可以自明。此對不作惡法為宗。
【譯文】【疏文】所說的「止」，是指運用善巧方便提起正念，守護原本所領受的戒體，禁阻防範身口二業，不去造作種種惡行，將此指稱為「止」。能止惡而無所違犯，戒體清光皎潔，順從了原本所受之戒，稱之為「持」。持戒是藉由止惡而成立的，所以號稱「止持戒」。例如初篇波羅夷等戒，看其戒相自然就能明白。這是以「不造作惡法」為其宗旨。

【095-0011】02_戒疏/04b_卷一下之二#106
【原文】【記】止持中二。初牒名，「方」下，釋五節。初釋止義。言「方便」者，或但攝心離過，或復修諸對治。「止而」下，明持義。「持由」下，總合。「如」下，舉事以顯。「此」下，指歸行宗。所以爾者，欲使四行無濫故。
【譯文】【記文】在止持之中分為兩段。最初列出名稱，「方」字以下，分為五節來解釋。首先解釋「止」的意義。所謂「方便」，或者是僅僅收攝身心遠離過失，或者是進一步修習種種對治之法。「止而」以下，說明「持」的意義。「持由」以下，總合二字。「如」以下，舉出具體事相來顯明。「此」以下，指歸修行的宗旨。之所以要如此，是為了使四種行相不相混淆。

【095-0012】02_戒疏/04b_卷一下之二#107
【原文】【疏】惡既已離，事須修善。必當勤䇿三業，修習戒行。有善斯護，名之為「持」。持由作成，故號「作持」。如衣食四緣，威儀雜行，作意防擬，方成戒淨。此對修習善法為宗。
【譯文】【疏文】惡行既然已經遠離，理應當修持善法。必須精進策勵身口意三業，修習戒律的行持。凡有善法皆能精勤守護實踐，稱之為「持」。持戒是由積極作為而促成的，所以號稱「作持」。例如衣、食等四種資生之緣（四緣），威儀以及各項僧中雜行，用心防護與准擬規劃，才能成就戒行的清淨。這是以「修習善法」為其宗旨。

【095-0013】02_戒疏/04b_卷一下之二#108
【原文】【記】作持中，躡前生起。「必」下，釋義，亦五。初釋作。「有」下，明持。「持由」下，合名。「如」下，指事。衣、食、藥三，皆通受淨，房有制量、乞法。或可糞衣、乞食、樹下、腐藥，《羯磨疏》中科為「根本作持」。修道假此，故名「四緣」。「雜行」，總收眾共，皆作持攝。「此」下，示宗，可知。
【譯文】【記文】在作持之中，是接續前文止惡而生起的。「必」字以下解釋其意義，也是分為五節。首先解釋「作」。「有」字以下說明「持」。「持由」以下合稱其名。「如」以下指示具體事相。衣、食、藥這三項，皆通於受持與淨施之法，建造房舍則有規定的尺碼容量、以及向僧眾乞請的合法程序。或者糞掃衣、常乞食、樹下坐、腐爛藥（四依），在《羯磨疏》中科判為「根本作持」。修道仰賴這些條件，所以稱作「四緣」。「雜行」，總括收羅僧團大眾共住共行的規範，全都被作持所包攝。「此」以下指示宗旨，道理顯而易見。

【095-0014】02_戒疏/04b_卷一下之二#109
【原文】【疏】所以前後不同者。《論》云「戒相止，行相作」也。又云「惡止善行，義之次第」。
【譯文】【疏文】前後次序之所以不同的原因：《論》中說「戒的行相是止息，行的行相是作為」。又說「止息惡行、力行善法，是義理上的必然次第」。

【095-0015】02_戒疏/04b_卷一下之二#110
【原文】【記】次所以中。初徵意者。以修捨義順，今相反故；又止作體同，今分異故。《論》下，次引釋。《論》即《百論》，文有二段。初釋不同。彼明佛說法有二種：一止相，二行相。謂息一切惡名止，修一切善名行。外道難曰：「已說善行，不應復說惡止，以惡止即善行故。」內曰：「止相息，行相作，性相違故。」今變其語，取其義耳。「又」下，次釋前後。彼云：「外人又難曰：『善行應在初，以善法有妙果故。』內曰：『次第法故，先除麤垢，後染善法。』」
【譯文】【記文】接著說明次序緣由。最初探問用意。因為就修持與捨棄而言，修似乎應在前，如今卻將止惡放在前面；又因為止與作的體性相同，如今卻區分前後，所以提問。《論》以下，接著引文解釋。「論」就是指《百論》，文中有兩段。首先解釋兩者的相異。彼論說明佛陀說法有兩種：一是止相，二是行相。也就是止息一切惡稱作止，修習一切善稱作行。外道詰難說：「既然已經說了行善，就不應再說止惡，因為止惡本身就是行善。」佛法內宗回答：「止的行相是休止，行的行相是起作（造作），兩者的性質是相反的。」如今疏文變更了論中的語句，擷取其義理罷了。「又」字以下，接著解釋前後順序。彼論說：「外道又詰難說：『善行應當排在最初，因為善法具有殊勝的果報。』內宗回答：『這是由於修持的先後次第，必須先除掉粗重的垢穢，之後才能染習善法。』」

【原文】【記】次科。《成論》由是當宗，故可為證。「皆是心」者，此指意識，猶通四陰。若據成業，須至行心。「行」即意思。以思從心起，身口二業，復由思成。今從業本，故言「心」耳。
【譯文】【記文】第二科。《成實論》原本就是本宗所依據的論部，所以可以作為確鑿的證明。「全都是心」，是指意識，在此仍通於受、想、行、識四陰。但若就成就業道來說，必須落實到行陰的心。「行」就是意念之思。因為造作思慮是由心而起，身口兩業又是藉由思慮而成就。如今追溯業力的根源，所以只稱作「心」。

【095-0058】02_戒疏/04b_卷一下之二#153
【原文】【記】正明體中，初科，昔解。「止持作犯」，局事無法，與今少異。餘則大同。「所以」下，自釋不通之意。以律制法，正在進修；止持離過，非進修故。又事通善惡，故該二持；法唯是善，故唯局作。
【譯文】【記文】在正式說明本體之中，此為初科，乃是往昔的解釋。「止持作犯」局限於事相而不通於法軌，這點與當前的觀點稍有不同，其餘部分則大致相同。「所以」字以下，是古人自行解釋不通法軌的緣由。因為律中所制的法軌，主旨正在於精進修持；止持只是遠離過失，並非精進修作之故。又因為事相通於善與惡，所以能包含二持；法軌則純粹是善法，所以唯獨局限在作持。

【095-0059】02_戒疏/04b_卷一下之二#154
【原文】【疏】問：「如上立義，止持唯事，不通法者，如五邪、七非，並非正法，若作有違，義須止約。此法與事殺、盜不殊，有何等故不在止攝？如昔解止，但對事明，於義有乖。今不同彼。無論事、法，聖制止作，則通持犯。下以位分，體狀無別。」
【譯文】【疏文】問：「如果按照上面所立的義理，止持唯獨局限於事相，而不通於法軌，那麼例如調達五邪法、七種非法羯磨（七非），這些全都不符合正法，如果去造作便屬違犯，按理必須加以抑止約束。這類非法與具體事相上的殺生、偷盜並無二致，有什麼緣故不能被收攝在止持之中呢？如同古人解釋止持只對照事相來說明，在義理上顯然有所乖違。如今我的主張與彼不同：不論是事相還是法軌，只要是聖教所制定的止與作，全都通於持犯四行。下文雖然以階位作劃分，但它們作為持犯體狀的本質並無差別。」

【095-0060】02_戒疏/04b_卷一下之二#155
【原文】【記】今義中。初牒彼解；「如五」下，舉法比難；「如昔」下，斥非立義。此謂事法既有止作，則通四行。「下以位分」者，即後四門並舉事法，對可學、不可學以明體狀。方顯止門與作齊等，故云「無別」。則異古師單複偏對也。
【譯文】【記文】當前正義之中。最初重提對方的解釋；「如五」以下，舉出非法之例來作對比詰難；「如昔」以下，駁斥其謬誤並確立今義。這是說事相與法軌既然都存在著止與作的規範，自然通貫於持犯四行。「下以位分」，是指後面的四門都同時舉出事與法，對照著「可學」與「不可學」來說明持犯體狀。如此方能彰顯止門與作門是完全平等的，所以說「無別」。這就與古德只偏頗地以單一事相或雙重事法來相對待的情況不同了。
