# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【81-0001】02_戒疏/03c_卷一下之一#12
【原文】【疏】言「淨故默」者，眾非口呈行淨，繁亂伐德成勞，但默便表答辭也。言「是事持」者，淨行得聞正戒，機教相應，定慧由斯成剋，理須持奉故也。「事」即淨行，如文可知。
【譯文】【疏文】經文說「因清淨故默然」的意思是，大眾若不是以言語親口報告自己行持清淨，大家紛紛出聲就會雜亂失序、損害德操徒增疲勞，因此只要保持沉默，就代表給予肯定的答覆。經文說「這件事應當這樣受持」的意思是，唯有行持清淨者才能聽聞這清淨的正戒，根機與教法相應，定力和智慧才能藉此修行成就，在道理上應當全力奉持受奉。「這件事」就是指清淨行持，依據經文脈絡便可明瞭。

【81-0002】02_戒疏/03c_卷一下之一#13
【原文】【記】釋勸持中。初釋默然。「繁亂」乖儀，「伐德」非理。默然自表，則離諸過。次釋是事等。初敘勸持，「事」下，點文相。「事」即戒相。以人稟教，指教歸人，故云「淨行」。《經》中「如是」二字，指法之詞，即指後文也。
【譯文】【記文】這是解釋勸勉大眾受持的內容。前半段解釋「默然」。「繁瑣雜亂」違背儀軌，「損害德操」不合道理。以保持沉默自然表態，就能遠離各種過失。後半段解釋「這件事應當受持」等語。首先敘述勸勉受持的意思；從「這件事」往後，點出文句的意涵。「事」就是指戒相。因為是人領受教法，將教法落實歸結到人身上，所以稱為「清淨行持」。經文中的「如是（這件事應當這樣）」兩個字，是指陳法義的詞語，也就是指後面的戒文。

【81-0005】資持記/15d_下三#24
【原文】後一教俗，令僧傳告。說法儀中，初科，初勸俗護法。以佛讚故，經云：若有人能護持法，當知是人，乃是十方諸佛大檀越也。又下，誡道受施，初示誡。葶藶子，喻其至少。次釋破相。後示惡名。滓，謂不清淨；曲，即不正直；幻，謂無真實；賊，謂侵奪妄損信施；醉，謂神性昏迷；
【譯文】最後一章教導世俗，令僧人將教法傳達告知他們。在「說法儀」中，第一科首先勸勉俗人護持正法。因為佛陀極力讚歎的緣故，經中說：如果有人能夠護持正法，應當知道這個人就是十方諸佛的大檀越。「又下」告誡僧道受取布施的態度，首先予以誡勉。「葶藶子」是比喻極其微細微小。接著解釋破戒之相。最後指出種種惡劣名聲。「滓」是指心念不清淨；「曲」就是心術不正直；「幻」是指內無真實德行；「賊」是指侵奪妄耗信徒的布施；「醉」是指神智性情昏聵沉淪；

【81-0006】01_行事鈔/11b_卷下之三#21
【原文】初中。《大集》云：無量眾生白佛，護持法故，佛讚言：善哉！諸大檀越。又云：破戒比丘，處眾說法，不得受信施，如葶藶子。破戒相者，乃至受畜八不淨物。名滓、曲、幻、賊、醉、旃陀羅等沙門也。廣如三十一卷中說。
【譯文】在第一部分之中。《大集經》說：有無量無邊的眾生向佛陀稟白，誓願護持正法的緣故，佛陀讚歎道：「善哉！諸大檀越！」該經又說：毀犯重戒的比丘，若在大眾之中登座說法，連如同葶藶子那麼微少的信施之物都沒有資格受用。所謂毀犯戒律之相，乃至包括受納並蓄積八種不淨之物（如田宅、奴婢、牛羊金銀等不合沙門之物）。這種人被稱為浮渣（滓）、諂曲（曲）、幻妄（幻）、盜賊（賊）、沉醉（醉）、乃至賤民旃陀羅一般的沙門等。廣如三十一卷中說。

【81-0007】01_行事鈔/11b_卷下之三#22
【原文】《四分》：為檀越說法，聽說契經及分別義，得不具說文句。不得二比丘同一高座說法，或共相諍，或說義互求長短，或共相逼切，或二人同聲合唄，及歌詠聲說法等。因說歌聲有五過：一自貪著聲，二令聞者生愛，三令他習學，四令俗人生慢心，五以亂定意。若說法人少，應次第請說；下至一偈，諸惡莫作等。夜集說法座，高卑無在。
【譯文】《四分律》規定：為施主檀越說法，聽許宣說契經經文以及分別解說其法義，可以不必逐字逐句完整背誦整部經文文句。不得讓兩位比丘並坐在同一個高座上說法，唯恐他們相互爭辯論詰、或在解說義理時互相比量長短挑剔毛病、或彼此爭競逼迫壓制，或者二人同聲合唱梵唄，以及用世俗歌詠曼唱的腔調來說法等。佛陀因而開示以歌詠聲說法有五種過患：一是自己會貪圖執著於悠揚美妙的歌喉聲音，二是會令聽聞的大眾心生貪愛情執，三是會誘導他人仿傚學習這種浮靡之風，四是會讓俗人生起輕慢戲弄之心，五是會擾亂內心專注的定意（禪定智慧）。如果精通說法的僧人很少，應當按照戒臘次第恭請宣說；乃至最少說一首經偈，如「諸惡莫作」等偈頌即可。夜間聚會說法的法座，其高矮高低則無特定拘泥限制。

【81-0008】資持記/15d_下三#25
【原文】旃陀羅，謂能害人慧命。指如三十一，今見二十八。二中，初開撮要。不得下，制非法有六種。二人同座，尊無二故，復喧亂故；相諍，謂對較勝負；互求長短，謂掩長拾短；逼切，謂詰難；不能合唄，無所辨故；歌聲過失，如文自列。五過，初後損己，餘並損他。若說下，三開略說。
【譯文】「旃陀羅」是指這種人會斷喪他人的智慧生命。文中指示參見第三十一卷，如今見於第二十八卷。第二段內容中，首先開許可以節錄要點講述。「不得下」規定了六種非法的行為：兩人同坐一高座，因為至尊的席位不應有二，且兩人擠在一起容易喧嘩混亂；互相諍辯，是指當場爭較勝負高下；彼此挑剔長短，是指掩蓋優點而專抓缺點；逼迫追問，是指故意詰難駁斥；兩人同聲合唱梵唄，會使聲音喧雜而令人無從辨聽法義；唱誦聲音過度帶來的過失，如同律文自身所列舉的。這五種過失，第一種與最後一種損害自己，其餘幾種全都是損害他人。「若說下」第三點開許可以簡略宣講。

【81-0009】01_行事鈔/11b_卷下之三#23
【原文】《三千威儀》：上高座讀經，先禮佛，次禮經法及上座；後在座正坐，向上座坐；楗稚聲絕，先讚偈唄，如法而說；若不如法問，不如法聽，便止。
【譯文】《三千威儀》說：登上高法座讀誦經典時，應當先行禮拜佛陀，其次頂禮經卷法寶以及上座長老；然後在法座上端身正坐，面向著上座的方向而坐；待寺中的楗稚（犍稚鐘磬）擊奏之聲停歇之後，先唱讚偈頌梵唄，然後如法平實地開演經教；如果聽眾提出不如法的詰難提問，或者聽眾舉止怠慢不如法諦聽，法師便應當立即停止說法。

【81-0010】資持記/15d_下三#26
【原文】雖依次請，亦須選能。《智論》云：少德無智慧，不應處高座；如豺見師子，竄伏不敢出；大智無所畏，應處師子座；譬如師子吼，眾獸皆怖畏。必為他請，準此自量；當須無畏，勿令竄伏。夜下，明設座。或是逼夜，不暇陳設，故開隨坐。三中。六法：初禮三寶；二昇高座；三打磬靜眾〔今多打木。〕；
【譯文】雖然是依照順序受請說法，但也必須挑選具有能力的人。《大智度論》說：「缺乏德行沒有智慧的人，不應當高居尊貴的法座；就像豺狼看見獅子一樣，只會縮首竄伏不敢出來；具備大智慧而無所怖畏的人，才能坐上這獅子寶座；猶如獅子大聲哮吼，百獸無不震驚畏服。」如果接受了他人的恭請，應當依此自我衡量；登座時必須心懷無畏，切不可像野獸般瑟縮竄伏。「夜下」說明安置座席。如果時間已逼近夜晚，來不及從容鋪陳陳設，所以開許隨地適意而坐。第三段中包含六種法則：第一是禮拜三寶；第二是登上高座；第三是敲擊鳴磬使大眾安靜肅穆（現在多半敲擊木魚）；

【81-0011】01_行事鈔/11c_卷下之三#1
【原文】《毘尼母》云：說法比丘，應籌量大眾，應說何法而得受解？若聞深法得解，應為說深，謂五分、十二因緣、涅槃等論；淺法者，謂布施、持戒、生天等論。若眾樂淺不樂深，不益前人，名惡說；反此名善說。又應知文義之句，男女之音。又應除貪心，不自輕心，不輕大眾心；應慈心、喜心、利益心、不動心；立此等心，乃至一四句，令前人如實解者，長夜安樂。又不應起怖心，何以故？怖心說法，令身疲頓，音不辨了，言不次比，說法不妙，義亦難解；應庠序安心為說。又應為眾說厭患法、遠離法，觀身苦、空、無常、無我、不淨等；如第七卷中。
