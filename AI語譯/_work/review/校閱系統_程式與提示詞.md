# 校閱系統：流程架構、提示詞與程式碼

> 更新：2026-11-14（含 33 部本地書庫、凍版提示詞、W／L1–L4 實測）

---

## 一、整體架構

```
底本（TXT_分卷）＋ 現譯（AI語譯/out）
        ↓  mk_review_materials.py（前 6 後 4 段、保留【疏】【記】標籤）
   審校材料 NN.md
        ↓
  ┌─────────────┬──────────────┐
  │ 盲翻 B      │ 一審 A1      │
  │ 只給原文    │ 原文＋現譯   │
  └──────┬──────┴──────┬───────┘
         └──────┬───────┘
                ↓  裁決 J（甲＝B，乙＝A0／A1）
            定稿草案
                ↓  審核（只挑錯，PASS／FIX＋依據）
                ↓  修訂（只改 FIX 清單，可駁回）
            最終定稿
```

五支提示詞各司其職：

| 提示詞 | 位置 | 職責 |
|:--|:--|:--|
| 系統 prompt | `qwen_local.py` | 何時檢索、查什麼書、禁止臆造出處 |
| `BASE_PROMPT` | `mk_review_materials.py` | 一審：逐句對位＋四原則＋三欄輸出 |
| `BLIND_PROMPT` | `mk_blind_materials.py` | 盲翻：只譯原文，不給現譯 |
| `JUDGE_PROMPT` | `mk_judge_materials.py` | 裁決：甲乙對照、互斥必查、體例不倒退 |
| `AUDIT_PROMPT` | `mk_audit_materials.py` | 審核：只挑錯、附依據、不改寫 |
| `REVISE_PROMPT` | `mk_revise_materials.py` | 修訂：只依清單改、可駁回 |

## 二、五支提示詞（現行版）

### 2.1 系統 prompt

```text
你是精通南山律宗與漢文大藏經的譯校助手，依當前任務（翻譯／裁決／審核／修訂）行事。
檢索原則：
1. 按需檢索：一般文句依本段與前後背景即可判定者，無須呼叫搜尋；僅於下列情況檢索：
   (a) 省文致義理不明，或主客、空間、開遮邏輯疑似自相矛盾；
   (b) 專名、度量數理、儀式階段或律學特定用語不確定；
   (c) 懷疑引文原意衝突或疑有訛字；
   (d) 科判層級或科名不確定。
2. 工具用法：使用 web_search（同一疑點以 2～3 組核心詞為限），查平行文用古籍原名，勿用現代簡稱
   - local_search：支援多詞鄰近共現；短語查無時，改以空格分隔 2～3 個實詞。僅在確知要查某一部書時才填 work；查平行文或跨書用語時務必留空。跨書所得異釋僅供參照，不得硬套覆蓋本段原制與文脈。
   - 檢索節奏：顯明文意勿為求安心重複搜尋；次數以每次回傳的 `remaining` 為準，用完即不得再呼叫。
3. 典籍簡稱勿展開錯：伽論＝《薩婆多部毘尼摩得勒伽》（非《瑜伽師地論》）；婆沙／婆論／多論＝《薩婆多毘尼毘婆沙》（非《大毘婆沙論》）；善生＝《優婆塞戒經》；成論＝《成實論》；雜心＝《雜阿毘曇心論》；明了論＝《律二十二明了論》。
4. 反切音訓若無確據，保留「某某反」原訓釋字面即可，勿盲猜現代讀音。
5. 嚴禁未經檢索就憑記憶臆測經文出處或行號。若有查證，於理由或依據中簡註書名卷次，並摘錄關鍵原句 1–2 句，嚴禁寫入最終譯文。
```

### 2.2 一審（疏記版；尼鈔版由 `get_prompt(True)` 產生）

```text
你是南山律典審校編輯，負責校訂【疏文與記文】。

### 原則
1. 先依【原文】與律脈獨立拆解文法與主客關係，再核對【現譯】，勿順著譯文流暢度讀過；無誤之句照原譯保留，勿為修辭改動。
2. 只改實質錯誤：主客施受、開遮模態、範圍與否定、斷句（含句尾虛字辨結上／領下）與引文邊界、部別與科判、無據增補或實詞漏譯，以及文言直抄、歐化倒裝等硬性語病。
3. 正文不加解說圓括號（原文實質夾注與讀音除外）；須補明之主賓與條件直接融入正句。`〔補字〕`／`〔疑作X〕` 得保留，空白占位括號不強留。
4. 《業疏》所釋「文／注」指《隨機羯磨》文注，《戒疏》所釋指《含注戒本》文注，「律／本律」方指《四分律》；**【疏】【記】須雙向互核**：【記文】釋義須與【疏文】相契（不誤導、亦不隱沒所牒實詞），亦須以【疏文】前提檢核【記文】科判動詞。

### 輸出（【疏文】與【記文】；同一欄標籤只在開頭寫一次）：
     【疏文】……
     【記文】……
```

### 2.3 盲翻

```text
你是南山律宗白話譯者，負責將《四分律》與南山著作（{scope}）譯為自然流暢的現代正體書面白話。

只翻譯【本次待譯單元】；前後背景僅供確認指代與律脈，切勿譯入正文{shuji_ban}。

### 原則
1. **忠實**：不漏條件、實質夾注、音訓與實詞；不增原文所無的細目、背景或考訂。省略之主賓與條件直接融入句中；背景截斷而未見所指時，寧用中性泛稱，不臆補。
2. **律義與文法**：{book_ctx}{shuji_rule}辨古今與同形異義、數理度量（保留原稱）、部別稱謂、科判層級與「文」之所指；嚴核主客施受、持犯開遮與模態強弱、想疑心念、作法時序與界限條件、範圍與否定作用域；句尾虛字須辨結上或領下，引文起迄須分明，勿混同著者評論。{tail_rule}
3. **表達**：消除文言直抄與歐化倒裝，輸出語法自足、簡明自然的現代正體書面白話；科判標題與條目綱要保持短語，勿擴寫；涉及戒相、身體或行為要件之實詞須精準直譯，勿改為籠統委婉語。除原文實質夾注與讀音釋義外，不用圓括號添加解說；脫訛補字用 `〔補字〕`，存疑用 `〔疑作X〕`，空白占位括號不強留，勿寫校勘按語。
照下列完整標籤輸出，勿簡寫或自創標籤：
{out_format}
```

### 2.4 裁決

```text
你是南山律典雙譯裁決編輯。同一段原文附有【譯本甲】（主底本）與【譯本乙】（對照）。

只針對【本次待審單元】中立比對原文與前後背景，切勿把前後背景譯入正文，亦勿因看似流暢或已有括注而盲目偏袒任一方。

### 原則
1. **依原文與律脈裁定**（{book_note}）：主客施受、開遮模態、範圍與否定作用域、句尾虛字斷句、引文與評論邊界、古今與同形異義、數理度量（保留原稱）、科判層級與「文」之所指；分清本宗《四分》定論與他部異說。除原文實質夾注與讀音釋義外，不用圓括號添加解說（必要之省略主賓或前提條件直接融入正句）。
2. **防範同誤**：即使甲、乙譯法一致，仍須獨立對照原文核驗，防範共同漏譯、施受反轉、誤斷句讀或文言直抄。
3. **最小改動與體例一致**：有實質修正或防同誤重修者判 `REVISED`，未列分歧之句照甲保留，所有改動處皆須列入第 2 欄，且第 3 欄須嚴格貫徹第 2 欄之取捨，勿殘留雙譯並存或同義疊詞；實質無誤且僅純修辭差異者判 `PASS_A`。

### 輸出
1. **結論**：`PASS_A` 或 `REVISED`
2. **分歧與裁決**：PASS_A 寫「沿用譯本甲」或「乙有誤：……；甲優」；REVISED 逐條寫 `[疏/記/鈔/律/註/序，打包段加[n]] 原文「……」｜甲作「……」vs 乙作「……」（或甲乙同作「……」）｜裁決（甲優／乙優／重修）：……`
3. **修正後的譯文**：PASS_A 時只寫一行 `PASS_A_KEEP_A`（勿加括號）；REVISED 時完整輸出，須照原樣以原標籤開頭，嚴禁自創標籤（若材料附【分段要求】，依其規定只列改動段號）：
{out_format}
```

### 2.5 審核

```text
你是南山律典終審校勘員，對照原文找出【待審譯文】的實質錯誤。

請逐句從【原文】獨立拆解文法與律義，再反向驗收【待審譯文】，切勿順著譯文流暢度讀過去；裁決未列分歧之處仍須核對，防範雙譯同誤；即使已發現一處硬傷，仍須核完其餘各句。若有【裁決分歧參考】，逐項驗明所採是否與原文相容，但不得因此忽略未列分歧處。一眼可見之漏譯或贅注直接判定，勿為求安心重複搜尋。{dual_note}{long_note}

### 檢核（只抓實質錯誤，不挑純修辭潤飾）
1. **律義與部別**（{book_note}）：違背律宗常制、錯混部別、混淆本宗定論與他部異說、科判層級或「文」之所指有誤、引文與著者評論混同、【疏】【記】義理不能互核。
2. **文法與邏輯**：主客施受反轉、持犯開遮與模態強弱錯置、想疑心念與行為要件失真、時序與界限條件模糊、範圍與否定作用域偏差、句尾虛字斷句致因果轉折反轉、引文起迄錯亂。
3. **忠實與增刪**：漏譯條件、實質夾注、音訓或實詞；無據增補細目、背景或考訂；誤將背景或他欄專論混入正文；依文脈腦補譯文所無之詞。原文實質夾注、讀音與確須存疑之 `〔補字〕`／`〔疑作X〕` 得保留，空白占位括號不強留。
4. **表達與殘留**：古今與同形異義誤讀、文言直抄、歐化倒裝、動詞缺主賓、同義重複疊詞、違規添加解說性圓括號、同一核心術語前後譯法歧出，以及網址／按語／自創標籤殘留。

凡涉上述四項實質問題或致語意歧義者，一律列為硬傷判 `FIX`。

### 輸出（勿改寫整段，勿在建議中代寫完整替換句）
1. **【逐句簡核】**：逐句對照【原文】與【待審譯文】實際字面，核明核心實詞、動詞、主客與界限之實際譯法（禁止按段概括或僅複述原文大意帶過），註明查證結果。
2. **【結論】**：`PASS` 或 `FIX`（判 FIX 須列至少 1 項硬傷；判 PASS 則下欄只寫「無」）。
3. **【必改硬傷】**（無硬傷時**只寫「無」一字**，勿寫「經核對…」等說明）：
   - `[疏/記/鈔/律/註/序，打包段附[n]] 原文「……」→ 待審譯文「……」｜問題：……｜依據：……（引原文或查證書名，摘錄關鍵原句 1–2 句）｜修正方向：……（只寫須補齊或糾正之要素；所涉專詞須兼顧現代白話清晰而不生古今歧義）`
```

### 2.6 修訂

```text
你是南山律典譯文修訂編輯（本段所屬：{book_note}）。下面提供【原文】、【目前譯文】、【終審硬傷清單】（若有【裁決分歧參考】，一併供核對）。

動手前須自行核對【原文】與前後背景：只依硬傷清單逐項局部修正，清單未提及之處一律照【目前譯文】保留（勿為修辭改動），修訂時亦嚴禁新增解說性圓括號。修正時須辨明古今異義，以自然現代正體白話落實清單要素；若清單判斷反將導致誤譯、漏譯、破壞文氣或違背體例，應駁回該項、維持原譯（若有【裁決分歧參考】且原譯法更準，得參照採回）。駁回時只保留原句，不得書寫任何理由、按語或說明括號。

### 硬傷清單：
{fixes}

### 輸出（完整譯文，勿重貼原文、勿輸出清單）：
{out_format}
```

## 三、材料格式

```text
【前文背景（僅供參考，嚴禁譯入正文）】
【疏】…前第 6 段…
【記】…前第 5 段…

【本次待審單元】

■ 疏文（原文）
■ 疏文（現譯）
■ 記文（原文）
■ 記文（現譯）

【後文背景（僅供參考，嚴禁譯入正文）】
…後 4 段…
```

裁決材料的「譯本甲／乙」、審核材料的「【原文】＋【待審譯文】」都由同一套規則轉出。

### 3.1 JSON 資料層

每份材料同時輸出 `NN.md`（供人看）與 `NN.json`（供程式讀）：

```json
{"key":"01","ex":"01a_卷一之一，第 21–22 段",
 "pre":"【疏】…","post":"【記】…",
 "units":[{"lab":"疏文","orig":"…"}]}
```

下游一律 `materials_io.load()`：有 JSON 讀 JSON，沒有才回退解析 `.md`。

### 4.7 動態配額與跨書放寬

前後背景上限：前文 900 字（**以最近段優先保留**）、後文 600 字。


本地檢索上限依原文長度自動調整：

| 原文長度 | 本地 | 網搜／抓取 |
|:--|--:|:--|
| ≤30 字 | 1 | 1／1 |
| <100 字 | 2 | 1／1 |
| 100–300 字 | 3 | 2／1 |
| >300 字 | 5 | 2／1 |

配額以「待審原文」計算（非整份材料），故短段與長段上限確實不同。每次 local_search 回傳都附 `remaining`，用完即不得再呼叫。

**跨書放寬**：若指定 `work` 查無，自動以全庫再查一次，並在回傳附註「原指定《…》查無，已改從全庫查得；請依各筆 book 欄位確認實際所屬部別」。

**查無提示**：`若曾指定 work，請拿掉 work 改搜全庫（含辭典與科文），勿以同一詞反覆換字試搜。`

未採「拆 2 字 OR 近似匹配」：會撈出無關律條製造幻覺，且查無反而回傳上千 token。

        raw = json.dumps(data, ensure_ascii=False)
        with _cache_lock:
            con = sqlite3.connect(CACHE_DB, timeout=15)
            con.execute(
                'INSERT OR REPLACE INTO ds_cache (k, kind, payload, created_at) VALUES (?, ?, ?, ?)',
                (key, kind, raw, time.time()),
            )
            con.commit()
            con.close()
    except Exception:
        pass


def _allowed(u):
    try:
        host = urllib.parse.urlparse(u).netloc.lower().split(':')[0]
    except Exception:
        return False
    return any(host == w or host.endswith('.' + w) for w in WHITELIST)


_VAR_MAP = str.maketrans('煑竪虗汙竝説爲於着衆盋鉢艸羣裏呪眞婬覩牀徧却麤纔',
                         '煮豎虛污並說為于著眾缽缽草群裡咒真淫睹床遍卻粗才')
_STRIP_RE = re.compile(r'[^\u4e00-\u9fffA-Za-z0-9]')


def _norm_with_map(s):
    chars, idx_map = [], []
    for idx, ch in enumerate(s):
        if _STRIP_RE.match(ch):
            continue
        chars.append(ch.translate(_VAR_MAP))
        idx_map.append(idx)
    return ''.join(chars), idx_map


def _extract_window(text, query, radius=1800, max_len=3600):
    """去標點＋異體字正規化後定位最密視窗，同分取較後位置避開網頁頂端標題列。"""
    if not text:
        return ''
    if len(text) <= max_len:
        return text

    clean_q = re.sub(r'site:\S+|["「」『』《》〈〉、，。；：？！\s]+', ' ', query or '').strip()
    raw_tokens = [t for t in clean_q.split() if len(t) >= 2]
    norm_tokens = [_STRIP_RE.sub('', t).translate(_VAR_MAP) for t in raw_tokens]
    norm_tokens = [t for t in norm_tokens if len(t) >= 2]
    if not norm_tokens:
        return text[:max_len] + '\n…（無查詢詞，僅示開頭）'

    plain_text, idx_map = _norm_with_map(text)
    positions = []
    for t in norm_tokens:
        start, hit = 0, 0
        while hit < 20:
            i = plain_text.find(t, start)
            if i < 0:
                break
            positions.append((idx_map[i], t))
            start = i + len(t)
            hit += 1

    if not positions:
        probes = []
        for t in norm_tokens:
            if len(t) >= 4:
                probes.extend(t[k:k + 3] for k in range(0, len(t) - 2))
        for p in probes[:12]:
            start, hit = 0, 0
            while hit < 10:
                i = plain_text.find(p, start)
                if i < 0:
                    break
                positions.append((idx_map[i], p))
                start = i + len(p)
                hit += 1
        if not positions:
            return text[:max_len] + '\n…（未定位到關鍵字，僅示開頭）'
        norm_tokens = list(dict.fromkeys(probes))

    best_lo, best_hi, best_score, best_center = 0, min(len(text), max_len), -1, -1
    for i, _t in positions:
        lo = max(0, i - radius)
        hi = min(len(text), i + radius)
        win_norm = _STRIP_RE.sub('', text[lo:hi]).translate(_VAR_MAP)
        score = sum(1 for t in norm_tokens if t in win_norm)
        center = (lo + hi) // 2
        if score > best_score or (score == best_score and center > best_center):
            best_lo, best_hi, best_score, best_center = lo, hi, score, center

    if best_hi - best_lo > max_len:
        center = min(positions, key=lambda p: abs(p[0] - (best_lo + best_hi) // 2))[0]
        best_lo = max(0, center - max_len // 2)
        best_hi = min(len(text), best_lo + max_len)

    prefix = '…（前略）\n' if best_lo > 0 else ''
    suffix = '\n…（後略）' if best_hi < len(text) else ''
    return prefix + text[best_lo:best_hi] + suffix



def _ds_post(url, payload, sem, timeout=90):
    if not DS_KEY:
        raise FatalAPIError('未設定 .deepseek_key')
    data = json.dumps(payload, ensure_ascii=False).encode('utf-8')
    for attempt in range(4):
        _wait = 0.0
        try:
            with sem:
                req = urllib.request.Request(
                    url, data=data,
                    headers={'Authorization': 'Bearer ' + DS_KEY,
                             'Content-Type': 'application/json'}, method='POST')
                raw = urllib.request.urlopen(req, timeout=timeout).read().decode('utf-8')
            return json.loads(raw)
        except urllib.error.HTTPError as e:
            body = e.read().decode('utf-8', errors='replace')[:240]
            if e.code in (401, 402):
                raise FatalAPIError('DeepSeek HTTP %d（金鑰無效或餘額不足）: %s' % (e.code, body))
            if e.code in (408, 429, 500, 502, 503, 504) and attempt < 3:
                _wait = (1.5 * (2 ** attempt)) + random.uniform(0.1, 0.8)
            else:
                raise RuntimeError('DeepSeek HTTP %d: %s' % (e.code, body))
        except Exception as e:
            if attempt < 3:
                _wait = 1.5 * (2 ** attempt)
            else:
                raise
        if _wait:
            if _stop_requested():
                raise FatalAPIError('STOP')
            time.sleep(_wait)

def _cached_or_fetch(ck, kind, do_call):
    hit = _cache_get(ck)
    if hit is not None:
        return hit, True
    with _inflight_lock:
        ev = _inflight.get(ck)
        owner = ev is None
        if owner:
            ev = threading.Event()
            _inflight[ck] = ev
    if not owner:
        ev.wait(timeout=180)
        hit = _cache_get(ck)
        return (hit, True) if hit is not None else (None, False)
    try:
        data = do_call()
        _empty = (isinstance(data, dict) and not (data.get('results') or data.get('hits')))
        if isinstance(data, dict) and not _empty:
            _cache_set(ck, kind, data)
        return data, False
    finally:
        with _inflight_lock:
            _inflight.pop(ck, None)
        ev.set()


def web_search(query, ori_question=None, rows=10, stats=None, **kwargs):
    _ms = (stats or {}).get('max_search', MAX_SEARCH_PER_GROUP)
    if stats is not None:
        if stats.get('searches', 0) >= _ms:
            return json.dumps({'error': '本組搜尋已達上限（%d 次），請直接用現有資料完成判定。'
                                        % _ms}, ensure_ascii=False)
        stats['searches'] = stats.get('searches', 0) + 1
        stats.setdefault('queries', []).append(str(query)[:60])

    q = str(query).strip()[:128]
    cnt = min(max(int(rows or 15), 10), 25)
    ck = hashlib.sha256(('search|%d|%s' % (cnt, q)).encode('utf-8')).hexdigest()

    def _call():
        payload = {'query': q, 'count': cnt, 'need_content': True}
        if ori_question:
            payload['ori_question'] = str(ori_question).strip()[:128]
        if stats is not None:
            stats['ds_calls'] += 1
        return _ds_post(DS_SEARCH, payload, _ds_search_sem, timeout=90)

    r, from_cache = _cached_or_fetch(ck, 'search', _call)
    if r is None:
        return json.dumps({'error': '搜尋暫時失敗'}, ensure_ascii=False)
    if from_cache and stats is not None:
        stats['cache_hits'] += 1

    ranked = sorted(r.get('results') or [],
                    key=lambda x: (_allowed(x.get('url') or ''),
                                   float(x.get('rerank_score') or 0.0)), reverse=True)
    out = []
    budget = 2
    for x in ranked:
        u = x.get('url') or ''
        if not _allowed(u):
            continue
        item = {'title': (x.get('title') or '')[:100], 'url': u, 'trusted': True,
                'summary': (x.get('summary') or '')[:300]}
        raw = x.get('content') or ''
        if raw and budget > 0:
            item['excerpt'] = _extract_window(raw, q, radius=450, max_len=900)
            budget -= 1
        stats.setdefault('hits', []).append(
            {'q': q[:40], 'url': u[:120], 'title': item['title'][:60]})
        out.append(item)
        if len(out) >= 3:
            break

    if not out:
        return json.dumps({'results': [], 'note': '查無白名單來源（非白名單結果已略去）'},
                          ensure_ascii=False)
    return json.dumps({'results': out}, ensure_ascii=False)


def web_fetch(url, keyword=None, stats=None, **kwargs):
    _mf = (stats or {}).get('max_fetch', MAX_FETCH_PER_GROUP)
    if stats is not None:
        if stats.get('fetches', 0) >= _mf:
            return json.dumps({'error': '本組抓取已達上限（%d 次），請直接判定。'
                                        % _mf}, ensure_ascii=False)
        stats['fetches'] = stats.get('fetches', 0) + 1

    u = str(url).strip()
    if not _allowed(u):
        return json.dumps({'error': '網域不在白名單，請改用其他來源', 'url': u}, ensure_ascii=False)

    ck = hashlib.sha256(('fetch|' + u).encode('utf-8')).hexdigest()

    def _call():
        if stats is not None:
            stats['ds_calls'] += 1
        return _ds_post(DS_FETCH, {'url': u}, _ds_fetch_sem, timeout=120)

    r, from_cache = _cached_or_fetch(ck, 'fetch', _call)
    if r is None:
        return json.dumps({'error': '抓取暫時失敗'}, ensure_ascii=False)
    if from_cache and stats is not None:
        stats['cache_hits'] += 1

    c = r.get('content') or ''
    excerpt = _extract_window(c, keyword or '', radius=1800, max_len=3600)
    return json.dumps({'url': u, 'total_chars': len(c), 'content': excerpt},
                      ensure_ascii=False)

HAN = re.compile(r'[\u4e00-\u9fff]')


def _split_col3(out):
    """切出第 3 欄（修正後／修訂後／定稿／最終譯文）：回傳 (前段, 第3欄)。"""
    m = re.search(r'(?:^|\n)[^\n]{0,40}?(?:修正後|修訂後|定稿|最終)(?:的)?譯文[\*\s：:]*', out)
    if not m:
        return '', out
    i = m.start()
    j = m.end()
    body = _strip_fence(out[j:].lstrip('*：: \t\r\n'))
    if body[:1] in ('（', '('):
        _m = re.match(r'[（(][^）)]*[）)]\s*[：:]?\s*\n?', body)
        if _m and re.search(r'註|注|按|說明|沿用|未改|以下|全文|白話|修訂|完整', _m.group(0)):
            body = body[_m.end():]
    return out[:j].rstrip() + '\n\n', body

def _src_unit(src_text):
    """從材料取出待審原文（■ 疏文（原文）之後那段）。"""
    m = re.search(r'■ (?:疏文|記文|鈔文|律文|註文|序文)（原文）(?:\[\d+\])?\s*\n+(.+?)(?=\n\n■ |\n+【(?:後文背景|待審譯文|裁決分歧參考|目前譯文|分段要求|舊譯參考)|\Z)', src_text, re.S)
    return m.group(1).strip() if m else ''


def _strip_fence(out):
    return re.sub(r'(?m)^\s*```[a-zA-Z]*\s*$', '', out or '').strip()


def _strip_dup_labels(out):
    """同一欄位標籤只保留第一次出現，後續段落的重複標籤剝掉。

    只應作用於第 3 欄；若對整份回覆掃描，會誤把第 3 欄開頭的真標籤當重複剝掉。
    """
    seen = set()
    res = []
    for ln in out.split('\n'):
        m = re.match(r'^(【(?:疏文|記文|鈔文|律文|註文|序文)】)\s*', ln)
        if m:
            lab = m.group(1)
            if lab in seen:
                ln = ln[m.end():]
            else:
                seen.add(lab)
        res.append(ln)
    return '\n'.join(res)


def _looks_pasted(col3, src_unit):
    """第 3 欄開頭若與待審原文前 20 漢字高度重疊，判定為重貼原文。"""
    if not src_unit:
        return False
    col3 = re.sub(r'^\s*【(?:疏文|記文|鈔文|律文|註文|序文)】\s*', '', col3 or '')
    a = ''.join(HAN.findall(col3))[:20]
    b = ''.join(HAN.findall(src_unit))[:20]
    if len(a) < 8 or len(b) < 8 or len(src_unit) <= 40:
        return False
    if len(HAN.findall(col3)) > len(HAN.findall(src_unit)) * 1.15:
        return False
    same = 0
    for x, y in zip(a, b):
        if x != y:
            break
        same += 1
    return same >= 18 and len(HAN.findall(col3)) < len(HAN.findall(src_unit)) * 1.5


def _save_result(dst, choice, stats, extra_tag='', src_text=''):
    if src_text:
        stats['src_hash'] = hashlib.md5(
            src_text.encode('utf-8')).hexdigest()[:12]
    out = _strip_fence(choice['message'].get('content') or '')
    if (len(HAN_CHK.findall(out)) < 2
            and 'PASS_A_KEEP_A' not in out and 'PASS_A' not in out):
        return ('empty', '空回覆')
    for _old_sfx in ('_截斷.txt', '_重貼原文.txt', '_400審查.txt'):
        _oldp = dst.replace('_回.txt', _old_sfx)
        if out.strip() and os.path.exists(_oldp):
            try:
                os.remove(_oldp)
            except Exception:
                pass
    for _sfx in ('_截斷.txt', '_重貼原文.txt', '_400審查.txt'):
        _old = dst.replace('_回.txt', _sfx)
        if out.strip() and os.path.exists(_old):
            try:
                os.remove(_old)
            except Exception:
                pass
    if choice.get('finish_reason') == 'content_filter':

    if os.environ.get('QWEN_RAW_SAVE') == '1':
        pass  # 保留完整報告，勿剝行首標籤

        WORKERS = max(1, min(len(files) or 1, 40))

        f'待送 {len(files)} 份｜併發 {WORKERS}｜模型 {MODEL}｜effort={REASONING_EFFORT}'
        f'｜max_rounds={MAX_TOOL_ROUNDS}｜max_completion_tokens=未設',
        flush=True,
    )

    stop = threading.Event()

    def _handler(signum, frame):
        if not stop.is_set():
            print('  ⏸ 收到停止訊號：不再送出新工作，等進行中的請求完成…', flush=True)
        stop.set()

    for _sig in ('SIGINT', 'SIGTERM', 'SIGBREAK'):
        try:
            signal.signal(getattr(signal, _sig), _handler)
        except Exception:
            pass

    ok = fail = 0
    inflight = {}
    it = iter(files)
    pending = len(files)

    def _submit_next(ex):
        nonlocal pending
        while len(inflight) < WORKERS:
            if _stop_requested():
                return
            try:
                f = next(it)
            except StopIteration:
                return
            pending -= 1
            inflight[ex.submit(run, f)] = f

    if _LOCAL:
        _LC.load()
    with ThreadPoolExecutor(max_workers=WORKERS) as ex:
        _submit_next(ex)
        while inflight:
            done, _ = wait(inflight, return_when=FIRST_COMPLETED)
            for fu in done:
                f = inflight.pop(fu)
                try:
                    _, st = fu.result()

                    ok += 1
                    print(' ', st, f, flush=True)
                else:
                    fail += 1
                    print('  ✗', f, st, flush=True)

    remaining = pending + len(inflight)
    if _FATAL:

                '已優雅停止 %s\n完成 %d、失敗 %d、未送 %d\n'
                % (time.strftime('%Y-%m-%d %H:%M:%S'), ok, fail, remaining))
        except Exception:
            pass
        print(f'已停止：完成 {ok}、失敗 {fail}、未送 {remaining}（重跑會自動跳過已完成）', flush=True)
    else:

def _norm_book(s):
    """書名正規化：先精確比對，再剝《》與空白並套 ALIASES。"""
    q = str(s).strip().strip('《》〈〉「」『』 ')
    if q in KNOWN_BOOKS:
        return q
    for alias, target in sorted(ALIASES, key=lambda x: len(x[0]), reverse=True):
        if q == alias or q.startswith(alias):
            return target
    for nm in sorted(KNOWN_BOOKS, key=len, reverse=True):
        if q.startswith(nm):
            return nm
    return q

    return str(s).replace('《', '').replace('》', '').strip()


def _split_work(query):
    """查詢若以書名（含別名）開頭，拆成 (work, 核心詞)。"""
    names = set(BOOKS) | set(EXTRA.keys()) | set(a for a, _ in ALIASES)
    q = _norm_query(query)
    parts = q.split()
    if len(parts) >= 2 and parts[0] in names:
        return dict(ALIASES).get(parts[0], parts[0]), ' '.join(parts[1:])
    for nm in sorted(names, key=len, reverse=True):
        if q.startswith(nm) and len(q) > len(nm) + 1 and q[len(nm)] in ' 　:：':
            _rest = q[len(nm):].strip()
            if _rest.startswith(tuple(names)):
                return None, q
            return dict(ALIASES).get(nm, nm), _rest
    return None, q


JUAN_RE = re.compile(r'卷[第]?[上中下]?(?:之[上中下\d一二三四五六七八九十]{1,3})?[一二三四五六七八九十百千零〇\d]{0,3}')

def _orig_index(text, plain_pos):
    """把去標點字串的位置映射回原行索引。"""
    cnt = 0
    for idx, ch in enumerate(text):
        if PUNCT_RE.match(ch):
            continue
        if cnt == plain_pos:
            return idx
        cnt += 1
    return max(0, len(text) - 1)


def _juan_label(line, book):
    s = line.strip()
    if len(s) > 24 or re.search(r'[。！？，、；：]', s) or s.startswith(('如', '見', '若')):
        return None
    m = JUAN_RE.search(s)
    if not m or m.start() != 0:
        return None
    v = m.group(0)
    if v in ('卷', '卷第'):
        return None
    return v


def _add_file(path, book, juan_default='卷首'):
    juan = juan_default
    try:
        raw = io.open(path, encoding='utf-8', errors='ignore').read()
    except Exception:
        return
    for i, line in enumerate(raw.split('\n')):
        s = line.strip()
        if not s:
            continue
        m = JUAN_RE.search(s)
        _head = i < 6
        _pure = not re.search(r'[。！？，、；：]', s) and len(s) <= 24
        if m and len(s) <= 40 and (_head or _pure) and not s.startswith(('如', '見', '若')):
            _v = m.group(0)
            if _v not in ('卷', '卷第'):
                juan = _v
                continue
        if not HAN.search(s):
            continue
        rec = {'id': '%s|%s|%d' % (book, os.path.basename(path), i), 'book': book,
               'juan': juan, 'no': i, 'text': s, 'plain': _plain(s)}
        BOOK_LINES.setdefault(book, []).append(len(LINES))
        LINES.append(rec)

    # 分層配額：每層最多取 2 筆，保證律藏也看得到
    by_layer = {}
    for item in hits:
        by_layer.setdefault(layer.get(item[1]['book'], 3), []).append(item)
    ordered = []
    for round_i in range(2):
        for lv in sorted(by_layer):
            if len(by_layer[lv]) > round_i:
                ordered.append(by_layer[lv][round_i])
    _seen = {h[1]['id'] for h in ordered if isinstance(h[1], dict) and 'id' in h[1]}
    for h in hits:
        _hid = h[1].get('id') if isinstance(h[1], dict) else None
        if _hid in _seen:
            continue
        _seen.add(_hid)
        ordered.append(h)

    out = []
    used = {}
    for idx, r in ordered:
        if used.get(r['book'], 0) >= per_book:
            continue
        used[r['book']] = used.get(r['book'], 0) + 1
        lo_i = max(0, idx - 2)
        hi_i = min(len(LINES), idx + 3)
        ctx = '\n'.join(LINES[j]['text'] for j in range(lo_i, hi_i)
                         if LINES[j]['book'] == r['book'])
        _pos_line = _plain(r['text']).find(anchor)
        _needle = _plain(r['text'])[:20]
        _start = _plain(ctx).find(_needle)
        if _start >= 0 and _pos_line >= 0:
            pos = _start + _pos_line
        else:
            pos = _plain(ctx).find(anchor)
        oi = _orig_index(ctx, max(0, pos))
        lo = max(0, oi - pad)
        hi = min(len(ctx), oi + len(anchor) + pad)
        out.append({'linehead': r['id'], 'book': r['book'], 'juan': r['juan'],
                    'kwic': ctx[lo:hi], 'book_counts': counts})
        if len(out) >= int(limit or 6):
            break
    return out

"""材料資料層：以 JSON 傳遞，取代各腳本重複用正則爬 .md。"""

def write_json(outdir, key, data):
    os.makedirs(outdir, exist_ok=True)
    p = os.path.join(outdir, key + '.json')
    io.open(p, 'w', encoding='utf-8').write(

    p = os.path.join(dirpath, key + '.json')
    if not os.path.exists(p):
        return None
    try:
        return json.load(io.open(p, encoding='utf-8'))
    except Exception:

SRC_RE = re.compile(r'■ (疏文|記文|鈔文|律文|註文|序文)（原文）(?:\[\d+\])?\s*\n+(.+?)'
                    r'(?=\n+■ |\n+【(?:後文背景|待審譯文|裁決分歧參考|目前譯文|分段要求)|\Z)', re.S)
TR_RE = re.compile(r'■ (疏文|記文|鈔文|律文|註文|序文)（現譯）\s*\n+(.+?)'
                   r'(?=\n+■ |\n+【(?:後文背景|待審譯文|裁決分歧參考|目前譯文|分段要求)|\Z)', re.S)
PRE_RE = re.compile(r'【前文背景[^】]*】\s*\n+(.+?)\n+\n*(?:【本次待審單元】|【本次待譯單元】|【分段要求】|【原文】)', re.S)

EX_RE = re.compile(r'（出處：(.+?)）')


def parse_md(text):
    """從 .md 材料抽出結構（向後相容）。"""
    ex = EX_RE.search(text)
    pre = PRE_RE.search(text)
    post = POST_RE.search(text)
    units = []
    trs = dict(TR_RE.findall(text))
    for lab, orig in SRC_RE.findall(text):
        units.append({'lab': lab, 'orig': orig.strip(), 'tr': trs.get(lab, '').strip()})
    return {
        'ex': ex.group(1) if ex else '',
        'pre': pre.group(1).strip() if pre else '',
        'post': post.group(1).strip() if post else '',
        'units': units,
    }


def load(dirpath, key):
    """優先讀 JSON，沒有就回頭解析 .md。"""
    d = read_json(dirpath, key)
    if d:
        return d
    p = os.path.join(dirpath, key + '.md')
    if not os.path.exists(p):
        return None
    return parse_md(io.open(p, encoding='utf-8').read())


def from_jia(md_text):
    hits = re.findall(
        r'■ (疏文|記文|鈔文|律文|註文|序文)（譯本甲）\s*\n+(.+?)(?=\n+■ |\n+【(?:後文背景|待審譯文|裁決分歧參考|目前譯文|分段要求)|\Z)',
        md_text or '', re.S)
    return '\n\n'.join('【%s】\n%s' % (lab, body.strip()) for lab, body in hits)


KEEP_A = 'PASS_A_KEEP_A'


def is_keep_a(body):
    s = (body or '').strip(' \t\r\n`*。.')
    if s == KEEP_A:
        return True
    if KEEP_A in s and len(s) <= 60:
        return True
    return bool(re.fullmatch(r'[【\[（(]?\s*沿用譯本甲\s*[】\]）)]?', s))


def verdict(rt):
    """回傳 'FIX' 或 'PASS'（審核成果判定，統一邏輯）。"""
    rt = rt or ''
    m = re.search(r'【結論】[^A-Za-z]{0,40}(PASS_A|PASS|FIX)', rt)
    if not m:
        _ms = list(re.finditer(r'(?m)^[#*\s\d.、]*結論[^A-Za-z]{0,40}(PASS_A|PASS|FIX)', rt))
        m = _ms[-1] if _ms else None
    if m:
        if m.group(1) == 'FIX':
            return 'PASS' if re.search(r'無\s*FIX|沒有\s*FIX|非\s*FIX', rt) else 'FIX'
        # 結論 PASS 但硬傷欄有內容 → 從嚴判 FIX，避免漏改
        h = re.search(r'【必改硬傷】\s*(.{0,300}?)(?=【可斟酌微瑕】|\n\s*\**\s*4[.、．]|\Z)', rt, re.S)
        if h:
            seg = h.group(1).lstrip(' 　\t\r\n*#：:-')
            seg = re.sub(r'^(?:本段|全段|本單元|本組)\s*', '', seg)
            seg = re.sub(r'^(?:經核對[^，。；]{0,12}|經逐句核對[^，。；]{0,12}|譯文正確|無需修改|正確無誤)[，。；：]?\s*', '', seg)
            for _ in range(3):
                _n2 = re.sub(r'^[（(【][^）)】]{0,16}[）)】]', '', seg)
                _n2 = re.sub(r'^(?:\d+[.、．]|[一二三四][.、．])\s*', '', _n2)
                _n2 = _n2.lstrip(' 　\t\r\n*#：:-')
                if _n2 == seg:
                    break
                seg = _n2
            if seg and not seg.startswith(('無', '暫無', '沒有', 'none', 'None', '皆無', '經核無',
                                 '查無', '並無', '未發現', '未見', '均無', '悉無', '無任何', '無硬傷', '無必改', '無需修改', '正確無誤')):
                return 'FIX'
        return 'PASS'
    m2 = re.search(r'【必改硬傷】\s*(.{0,40})', rt, re.S)
    if m2 and not m2.group(1).strip().lstrip('*：: -').startswith('無'):
        return 'FIX'
    return 'PASS'

    tr = os.path.join(B, spec['tr'].replace('/', os.sep), chunk + '.txt')
    if not (os.path.exists(src) and os.path.exists(tr)):
        return None
    a = [x.strip() for x in
         io.open(src, encoding='utf-8', errors='ignore').read().split('\n')[spec.get('skip', 0):]
         if x.strip()]
    o = [x.strip() for x in re.split(r'(?:\r?\n){2,}',
                                     io.open(tr, encoding='utf-8', errors='ignore').read()) if x.strip()]
    if len(a) != len(o):
        print('  ⚠ 段落數不合，略過：%s（原文 %d／譯文 %d）' % (chunk, len(a), len(o)))
        return None
    labels = []
    for x in a:
        m = re.match(r'【(.)】', x)
        labels.append(m.group(1) if m else '?')
    return a, o, labels


def build_groups(spec):
    d = os.path.join(B, spec['src'].replace('/', os.sep))
    groups = []
    for fn in sorted(os.listdir(d)):
        if not fn.endswith('.txt'):
            continue
        chunk = fn[:-4]
        got = load_pair(spec, chunk)
        if not got:
            continue
        a, o, lab = got
        if spec.get('shu') is None:          # 無記文（如尼鈔）：逐段為一組
            n = len(a)
            k = 0
            while k < n:
                L = len(a[k])
                if spec.get('pack', True) and L < 100:
                    j, acc = k, 0
                    while (j < n and len(a[j]) < 100 and acc < 220 and (j - k) < 4):
                        acc += len(a[j])
                        j += 1
                    if j - k >= 2:
                        groups.append(dict(chunk=chunk, s0=k, s1=j, g0=j, g1=j,
                                           sl=acc, gl=0, a=a, o=o, no_ji=True,
                                           unit=spec.get('unit'), packed=True))
                        k = j
                        continue
                    # 孤立短段：併入後段，或併回前一組
                    if L <= ORPHAN_CHARS:
                        if k + 1 < n and len(a[k + 1]) <= 420:
                            groups.append(dict(chunk=chunk, s0=k, s1=k + 2, g0=k + 2,
                                               g1=k + 2, sl=L + len(a[k + 1]), gl=0,
                                               a=a, o=o, no_ji=True,
                                               unit=spec.get('unit'), packed=True))
                            k += 2
                            continue
                        if (groups and groups[-1]['chunk'] == chunk
                                and groups[-1]['s1'] == k and len(a[k - 1]) <= 420):
                            g = groups[-1]
                            g['s1'] = k + 1
                            g['g0'] = g['s1']
                            g['g1'] = g['s1']
                            g['sl'] += L
                            g['packed'] = True
                            k += 1
                            continue
                if spec['min_shu'] <= L <= spec['max_shu']:
                    groups.append(dict(chunk=chunk, s0=k, s1=k + 1, g0=k + 1, g1=k + 1,
                                       sl=L, gl=0, a=a, o=o, no_ji=True,
                                       unit=spec.get('unit')))
                k += 1
            continue
        i = 0
        covered = set()
        while i < len(a):
            if lab[i] != spec['shu']:
                i += 1
                continue
            s0 = i
            while i < len(a) and lab[i] == spec['shu']:
                i += 1
            s1 = i
            if s1 >= len(a) or lab[s1] != spec['ji']:
                continue
            g0 = s1
            while i < len(a) and lab[i] == spec['ji']:
                i += 1
            g1 = i
            sl = sum(len(a[k]) for k in range(s0, s1))
            gl = sum(len(a[k]) for k in range(g0, g1))
            if sl <= 0 or gl <= 0 or sl > spec['max_shu'] or gl > spec['max_ji']:
                continue
            groups.append(dict(chunk=chunk, s0=s0, s1=s1, g0=g0, g1=g1,
                               sl=sl, gl=gl, a=a, o=o))
            covered.update(range(s0, g1))

        # 未配對段（單邊疏／記、律文／註文／序文）另建單欄組，避免漏段
        unit_map = {'疏': '疏文', '記': '記文', '鈔': '鈔文',
                    '律': '律文', '註': '註文', '序': '序文'}
        i = 0
        while i < len(a):
            if i in covered:
                i += 1
                continue
            L = len(a[i])
            lb = unit_map.get(lab[i])
            if lb is None and L > 5:
                lb = ('疏文' if spec.get('shu') else '鈔文')
            if not (lb and L <= spec['max_shu'] and L >= 1):
                i += 1
                continue
            if L < 120:                      # 連續短段打包
                j, acc = i, 0
                while (j < len(a) and j not in covered
                       and unit_map.get(lab[j]) == lb
                       and len(a[j]) < 120 and acc < 460 and (j - i) < 10):
                    acc += len(a[j])
                    j += 1
                if j - i >= 2:
                    groups.append(dict(chunk=chunk, s0=i, s1=j, g0=j, g1=j,
                                       sl=acc, gl=0, a=a, o=o, no_ji=True,
                                       unit=lb, packed=True))
                    i = j
                    continue
            groups.append(dict(chunk=chunk, s0=i, s1=i + 1, g0=i + 1, g1=i + 1,
                               sl=L, gl=0, a=a, o=o, no_ji=True, unit=lb))
            i += 1
    return groups


ORPHAN_CHARS = 30
MAX_PRE_CHARS = 900
MAX_POST_CHARS = 600


def _cap(lines, max_chars):
    out, acc = [], 0
    for ln in lines:
        if acc + len(ln) > max_chars and out:
            break
        out.append(ln)
        acc += len(ln)
    return out or lines[:1]


def emit(g, front, back, outdir, idx, book=None):
    a, o = g['a'], g['o']
    s0, s1, g0, g1 = g['s0'], g['s1'], g['g0'], g['g1']

    def ctx(lo, hi):
        seg = [a[k] for k in range(lo, hi)]          # 保留【疏】【記】標籤
        return seg if seg else ['（本卷開頭）' if lo == 0 else '（本卷末尾）']

    pre = list(reversed(_cap(list(reversed(ctx(max(0, s0 - front), s0))),
                             MAX_PRE_CHARS)))
    post = _cap(ctx(g1, min(len(a), g1 + back)), MAX_POST_CHARS)
    unit = g.get('unit') or ('鈔文' if g.get('no_ji') else '疏文')
    body_prompt = (get_prompt(False) if (unit == '疏文' and g1 > g0)
                   else prompt_for(unit, book or ''))
    L = [body_prompt, '', '---', '',
         '（出處：《%s》%s，第 %d–%d 段）' % (book or '未知', g['chunk'], s0 + 1, g1), '',
         '【前文背景（僅供參考，嚴禁譯入正文）】', ''] + pre + ['']
    L += ['【本次待審單元】', '', '■ %s（原文）' % unit, '']
    _packed = bool(g.get('packed')) and (s1 - s0) > 1
    for n, k in enumerate(range(s0, s1), 1):
        _txt = re.sub(r'^【.】', '', a[k])
        L += [('[%d] ' % n if _packed else '') + _txt, '']
    if _packed:
        L += ['【分段要求】標籤只需寫在最開頭一次；其後逐條換行以 `[1] …`、`[2] …` 對應，'
              '勿在每個編號後重複標籤，亦勿合併、增減或改動編號；正文內部子條目序數一律用一、二、（一）（二），嚴禁額外使用 `[數字]`。', '']
    L += ['■ %s（現譯）' % unit, '']
    for n, k in enumerate(range(s0, s1), 1):
        _txt = re.sub(r'^【(?:疏文|記文|鈔文|律文|註文|序文)】\s*', '', o[k])
        L += [('[%d] ' % n if _packed else '') + _txt, '']
    if g1 > g0:                      # 有記文才輸出記文區塊
        L += ['■ 記文（原文）', '']
        for k in range(g0, g1):
            L += [re.sub(r'^【.】', '', a[k]), '']
        L += ['■ 記文（現譯）', '']
        for k in range(g0, g1):
            L += [re.sub(r'^【(?:疏文|記文|鈔文|律文|註文|序文)】\s*', '', o[k]), '']
    L += ['【後文背景（僅供參考，嚴禁譯入正文）】', ''] + post + ['']
    key = '%s_%04d' % (g['chunk'], s0 + 1)
    p = os.path.join(outdir, key + '.md')
    io.open(p, 'w', encoding='utf-8').write('\n'.join(L))
    def _mk(seq, start, end, strip_re):
        rows = []
        for n, k in enumerate(range(start, end), 1):
            txt = re.sub(strip_re, '', seq[k])
            rows.append((('[%d] ' % n) if _packed else '') + txt)
        return chr(10).join(rows)

    units = [{'lab': unit,
              'orig': _mk(a, s0, s1, r'^【.】'),
              'tr': _mk(o, s0, s1, r'^【(?:疏文|記文|鈔文|律文|註文|序文)】\s*')}]
    if g1 > g0:
        units.append({'lab': '記文',
                      'orig': chr(10).join(re.sub(r'^【.】', '', a[k]) for k in range(g0, g1)),
                      'tr': chr(10).join(re.sub(r'^【(?:疏文|記文|鈔文|律文|註文|序文)】\s*', '', o[k])
                                         for k in range(g0, g1))})
    MI.write_json(outdir, key, {
        'key': key,
        'chunk': g['chunk'], 's0': s0, 's1': s1, 'g0': g0, 'g1': g1,
        'ex': '%s，第 %d–%d 段' % (g['chunk'], s0 + 1, g1),
        'pre': chr(10).join(pre),
        'post': chr(10).join(post),
        'book': book or '',
        'packed': bool(g.get('packed')),
        'segments': [re.sub(r'^【.】', '', a[k]) for k in range(s0, s1)]
                    if g.get('packed') else [],
        'units': units,
    })
    return p


def main():

              ensure_ascii=False, indent=1)

def do_pack(mat, out):
    os.makedirs(out, exist_ok=True)
    for _f in os.listdir(out):
        if _f.endswith(('.md', '.json')):
            os.remove(os.path.join(out, _f))
    items = []
    for f in sorted(os.listdir(mat)):
        if not f.endswith('.md'):
            continue
        t = io.open(os.path.join(mat, f), encoding='utf-8').read()
        md = MI.load(mat, f[:-3]) or {}
        m = re.search(r'（出處：([^，]+)', t)
        ch = md.get('chunk') or (m.group(1) if m else f[:-3].rsplit('_', 1)[0])
        bl = blocks(t)
        total = sum(norm_len(v.get('原文', '')) for v in bl.values())
        items.append(dict(key=f[:-3], chunk=ch, md=md, text=t, bl=bl, n=total,
                          packed=bool(md.get('packed'))))

    def _sk(it):
        _s = it['md'].get('s0')
        if _s is None:
            _m = re.search(r'(\d+)$', it['key'])
            _s = int(_m.group(1)) if _m else 0
        return (str(it['md'].get('chunk') or it['chunk']), int(_s))
    items.sort(key=_sk)
    packs = []
    cur = []
    for it in items:
        if it['packed']:
            if cur:
                packs.append(cur)
                cur = []
            packs.append([it])
            continue
        _prev = cur[-1]['md'] if cur else {}
        _cont = (not cur) or (_prev.get('g1') is not None and it['md'].get('s0') is not None
                             and int(_prev.get('g1')) == int(it['md'].get('s0')))
        _na = re.search(r'(\d+)$', it['key'])
        _nb = re.search(r'(\d+)$', cur[-1]['key']) if cur else None
        _gap = bool(cur and not _cont and _na and _nb and int(_na.group(1)) - int(_nb.group(1)) != 1)
        if cur and (_gap
                    or sorted(it['bl']) != sorted(cur[0]['bl'])
                    or it['chunk'] != cur[0]['chunk'] or len(cur) >= MAX_GROUPS
                    or sum(x['n'] for x in cur) + it['n'] > MAX_CHARS):
            packs.append(cur)
            cur = []
        cur.append(it)
    if cur:
        packs.append(cur)

    index = {}
    n = 0
    for pack in packs:
        if len(pack) < 2:
            _emit_single(mat, out, pack[0]['key'])
            n += 1
            continue
        key = 'p%04d' % (len(index) + 1)
        head = pack[0]['text'].split('【本次待審單元】')[0].rstrip()
        labs = []
        for it in pack:
            for lab in it['bl']:
                if lab not in labs:
                    labs.append(lab)
        lines = [head, '', '【本次待審單元】', '', RULE.format(n=len(pack)), '',
                 '【輸出標籤】' + '／'.join('【%s】' % x for x in labs) + '（標籤寫在該欄最前一次，'
                 '其下逐條列 [n]）', '']
        for i, it in enumerate(pack, 1):
            for lab, v in it['bl'].items():
                for kind in ('原文', '譯本甲', '譯本乙'):
                    if v.get(kind):
                        lines += ['■ %s（%s）[%d]' % (lab, kind, i), '', v[kind], '']
        post = ''
        if '【後文背景' in pack[-1]['text']:
            post = '【後文背景' + pack[-1]['text'].split('【後文背景', 1)[1]
        if post:
            lines += ['', post.strip(), '']
        io.open(os.path.join(out, key + '.md'), 'w', encoding='utf-8').write('\n'.join(lines))
        index[key] = [x['key'] for x in pack]
        n += 1
    io.open(os.path.join(out, '索引_pack.json'), 'w', encoding='utf-8').write(
        json.dumps(index, ensure_ascii=False, indent=1))
    print('打包完成：%d 份材料（%d 個打包組，涵蓋 %d 組）→ %s'
          % (n, len(index), sum(len(v) for v in index.values()), out))

def split_units(body, default_lab='疏文'):
    body = (body or '').strip(' \t\r\n*')

def _strip_head_paren(s):
    s = (s or '').lstrip('*：: \t\r\n')
    if s[:1] in ('（', '('):
        m = re.match(r'[（(][^）)]*[）)]\s*[：:*]*\s*\n?', s)
        if m and re.search(r'註|注|按|說明|沿用|未改|以下|全文|白話|修訂|完整', m.group(0)):
            s = s[m.end():]
    return s.lstrip('*：: \t\r\n')


def col3(rt):
    m = re.search(
        r'(?:^|\n)\s*[#*\s]*(?:第\s*)?(?:3|三)\s*(?:(?:欄\s*[｜|：:]|[.、．：:]|\*\*)\s*)*(?:修正後|修訂後|定稿|最終)(?:的)?譯文\**\s*[：:\s]*\n?',
        rt,
    )
    if m:
        body = _strip_head_paren(rt[m.end():])
    else:
        i = rt.rfind('修正後的譯文')
        if i < 0:
            _k = rt.rfind('修正')
            if _k < 0:
                _k = rt.rfind('分歧與裁決')
            _from = _k if _k >= 0 else 0
            mm = re.compile(r'(?m)^\s*【(?:疏文|記文|鈔文|律文|註文|序文)】').search(rt, _from)
            if mm:
                return re.sub(r'\n{3,}', '\n\n',
                              rt[mm.start():].lstrip('*：: \t\r\n')).strip()
            raise ValueError('回覆檔找不到「修正後的譯文」欄位')
        body = rt[i + len('修正後的譯文'):].lstrip('：: \t')
        if body.startswith('\n'):
            body = body[1:]
    body = body.lstrip('*：: \t\r\n')
    return re.sub(r'\n{3,}', '\n\n', _strip_head_paren(body)).strip()


def col3_safe(rt):
    try:
        body = col3(rt)
    except ValueError:
        return None
    _has_lab = re.search(r'【(?:疏文|記文|鈔文|律文|註文|序文)】', body)
    _looks_report = re.search(r'結論|分歧與裁決', body[:80])

        return None
    if len(re.sub(r'【(?:疏文|記文|鈔文|律文|註文|序文)】', '', body).strip()) < 1:
        return None
    return _strip_head_paren(body)

def normalize(text):

def split_sentences(text, max_len):
    parts, buf = [], ''
    _depth = 0
    for ch in text:
        buf += ch
        if ch in '「『':
            _depth += 1
        elif ch in '」』':
            _depth = max(0, _depth - 1)
        if ch in SENT_END and _depth == 0 and len(buf) >= max_len * 0.6:
            parts.append(buf)
            buf = ''
    if buf:
        if parts and len(buf) < max_len * 0.3:
            parts[-1] += buf
        else:
            parts.append(buf)
    out = []
    for p in parts:
        while len(p) > max_len * 1.8:
            _cut = max(p.rfind('，', 0, max_len), p.rfind('、', 0, max_len),
                       p.rfind('；', 0, max_len), p.rfind('。', 0, max_len),
                       p.rfind('！', 0, max_len), p.rfind('？', 0, max_len))
            if _cut >= int(max_len * 0.6):
                out.append(p[:_cut + 1])
                p = p[_cut + 1:]
            else:
                out.append(p[:max_len])
                p = p[max_len:]
        if p:
            out.append(p)
    # 進得來（原文已 > min）就必須至少兩段，否則下游會整段漏掉
    if len(out) < 2 and len(text) > max_len:
        chunks = [c for c in re.split(r'(?<=[，、；])', text) if c]
        if len(chunks) >= 2:
            half, acc, out2 = len(text) // 2, 0, []
            for c in chunks:
                acc += len(c)
                out2.append(c)
                if acc >= half and len(out2) < len(chunks):
                    break
            out = [''.join(out2), ''.join(chunks[len(out2):])]
        else:
            mid = len(text) // 2
            _q = text.rfind('，', 0, mid)
            if _q > mid * 0.6:
                mid = _q + 1
            out = [text[:mid], text[mid:]]
    return [x for x in out if x]

def split_marked(text, n):
    _head = ''
    _mh = re.match(r'\s*(【(?:疏文|記文|鈔文|律文|註文|序文)】)\s*', text)
    if _mh:
        _head = _mh.group(1)
        text = text[_mh.end():]
    parts = re.split(r'(?m)^\s*`?\s*(?:[-*•]|\d+[.、])?\s*\[\s*(\d+)\s*\]\s*', text)
    segs = [(int(parts[i]), parts[i + 1].strip())
            for i in range(1, len(parts) - 1, 2)]
    if len(segs) != n:
        _labm = re.findall(r'【(疏文|記文|鈔文|律文|註文|序文)】([\s\S]*?)(?=【(?:疏文|記文|鈔文|律文|註文|序文)】|\Z)', text)
        if _labm:
            _per = {}
            for _lb, _body in _labm:
                _pp = re.split(r'(?m)^\s*\[\s*(\d+)\s*\]\s*', _body)
                for _ii in range(1, len(_pp) - 1, 2):
                    _per.setdefault(int(_pp[_ii]), []).append((_lb, _pp[_ii + 1].strip()))
            if len(_per) == n:
                return ['\n\n'.join('【%s】\n%s' % (a, b) for a, b in _per[i])
                        for i in sorted(_per)]
        return None
    out = [b for _, b in sorted(segs)]
    if _head:
        out = [(_head + '\n' + b) if not re.match(r'【', b) else b for b in out]
    return out

def main():

    ap.add_argument('--pack', required=True)

    ok = bad = 0
    for key, members in mp.items():
        body = ''
        rp = os.path.join(rv, '回覆', key + '_回.txt') if rv else ''
        if rp and os.path.exists(rp):
            body = io.open(rp, encoding='utf-8').read().strip()
        if not body:
            md = os.path.join(pk, key + '.md')
            if os.path.exists(md):
                t = io.open(md, encoding='utf-8').read()
                i = t.find('【待審譯文】')
                j = t.find('【後文背景', i)
                body = t[i + len('【待審譯文】'):j if j > 0 else None].strip()
        if len(members) == 1:
            body = re.sub(r'^\[\d+\]\s*', '', body).strip()
            io.open(os.path.join(out, members[0] + '.txt'), 'w',
                    encoding='utf-8').write(body + '\n')
            ok += 1
            continue
        segs = split_marked(body, len(members))

                    encoding='utf-8').write(body + '\n')
            bad += 1
            continue
        for m, seg in zip(members, segs):
            seg = re.sub(r'^\[\d+\]\s*', '', seg).strip()
            io.open(os.path.join(out, m + '.txt'), 'w', encoding='utf-8').write(norm.normalize(seg) + '\n')
        ok += 1
    print('拆回：%d 包成功、%d 包異常 → %s' % (ok, bad, os.path.relpath(out, B)))

"""全書回拼：一般段定稿＋長段定稿＋短卷題，按原卷順序合成完整 .txt 並對帳。

import materials_io as MI          # noqa: E402

LONG_MIN = 500


def _groups(mdir, chunk):
    """回傳該卷的 [(s0, g1, key)]，來源為 _材料 的 .json 或 .md。"""
    out = []
    if not os.path.isdir(mdir):
        return out
    _seen = set()
    for f in sorted(os.listdir(mdir)):
        if not f.endswith(('.md', '.json')):
            continue
        key = f[:-5] if f.endswith('.json') else f[:-3]
        if key in _seen:
            continue
        _seen.add(key)
        md = MI.load(mdir, key) or {}
        if not isinstance(md, dict):
            continue
        _ch = md.get('chunk')
        _s0 = md.get('s0')
        _g1 = md.get('g1')
        if not _ch:
            _ex = md.get('ex') or ''
            _m = re.search(r'，第 (\d+)', _ex)
            _m2 = re.match(r'^(?:《[^》]+》)?([^，]+)，', _ex)
            _ch = _m2.group(1) if _m2 else ''
            _s0 = int(_m.group(1)) - 1 if _m else 0
            _g1 = _s0 + 1
        if _ch != chunk:
            continue
        out.append((int(_s0 or 0), int(_g1 or 0), key))
    out.sort()
    return out


def assemble(book, out_path=None, check_only=False):
    spec = M.BOOKS[book]
    sd = os.path.join(B, spec['src'].replace('/', os.sep))
    root = os.path.join(B, '測試', '重譯', book)
    mdir = os.path.join(root, '_材料')
    fin = os.path.join(root, '_定稿')
    lfin = os.path.join(root, '_長段', '_定稿')
    lmap = os.path.join(root, '_長段', '_對應.json')
    long_map = {}
    if os.path.exists(lmap):
        for it in json.load(io.open(lmap, encoding='utf-8')):
            long_map.setdefault(it['chunk'], {})[it['idx']] = it.get('total', 1)

    out, miss = [], []
    exp_chars = got_chars = 0
    n_seg = n_done = n_missing = 0
    for fn in sorted(os.listdir(sd)):
        if not fn.endswith('.txt'):
            continue
        chunk = fn[:-4]
        a = [x.strip() for x in
             io.open(os.path.join(sd, fn), encoding='utf-8', errors='ignore')
             .read().split('\n')[spec.get('skip', 0):] if x.strip()]
        groups = _groups(mdir, chunk)
        covered = {}
        for s0, g1, key in groups:
            for k in range(s0, g1):
                covered[k] = key
        long_idx = 0
        i = 0
        while i < len(a):
            exp_chars += len(a[i])
            if i in covered:
                key = covered[i]
                n_seg += 1
                p = os.path.join(fin, key + '.txt')
                if os.path.exists(p):
                    out.append(io.open(p, encoding='utf-8').read().strip())
                    got_chars += len(a[i])
                    n_done += 1
                else:
                    miss.append('%s\t%s\t缺一般段定稿' % (chunk, key))
                    n_missing += 1
                i += 1
                continue
            if len(a[i]) >= LONG_MIN:
                n_seg += 1
                p = os.path.join(lfin, '%s_L%04d.txt' % (chunk, i + 1))
                if os.path.exists(p):
                    out.append(io.open(p, encoding='utf-8').read().strip())
                    got_chars += len(a[i])
                    n_done += 1
                else:
                    miss.append('%s\t長段 idx=%d\t缺長段定稿' % (chunk, long_idx))
                    n_missing += 1
                long_idx += 1
                i += 1
                continue
            if len(a[i]) <= 5:
                out.append(a[i])
                got_chars += len(a[i])
                n_done += 1
                n_seg += 1
            else:
                miss.append('%s\t第 %d 段\t未分組且非長段' % (chunk, i))
                n_missing += 1
                n_seg += 1
            i += 1

    print('%s：預期 %d 段／%d 字；完成 %d 段／%d 字；缺 %d'
          % (book, n_seg, exp_chars, n_done, got_chars, n_missing))
    if miss:
        print('  缺段清單前 10 筆：')
        for x in miss[:10]:
            print('   ', x)
    if check_only:
        return n_missing
    out_path = out_path or os.path.join(root, '_全書.txt')
    os.makedirs(os.path.dirname(out_path), exist_ok=True)
    io.open(out_path, 'w', encoding='utf-8').write('\n'.join(out) + '\n')
    if miss:
        io.open(out_path + '.missing.txt', 'w', encoding='utf-8').write('\n'.join(miss) + '\n')
    print('  已寫出：', os.path.relpath(out_path, B))
    return n_missing


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument('--book', required=True)
    ap.add_argument('--out', default='')
    ap.add_argument('--check-only', action='store_true')
    args = ap.parse_args()
    op = os.path.join(B, args.out.replace('/', os.sep)) if args.out else None

"""把盲翻回覆對齊到現行材料：以 3-gram 重合率配對，產出 _盲翻_對齊/回覆。

用法： python -X utf8 _src/realign_blind.py --books 業疏,行事鈔,義鈔

import io

import sys

B = r'C:\Users\lionc\OneDrive\桌面\XW\三大部'
T = os.path.join(B, '測試')

import materials_io as MI  # noqa: E402

SUF = '_回.txt'
MIN_SAME = 0.06      # 與同 key 材料低於此值 → 視為錯位
MIN_MATCH = 0.18     # 重新配對的最低門檻


def grams(t, n=3):
    s = ''.join(ch for ch in t if '\u4e00' <= ch <= '\u9fff')
    return set(s[i:i + n] for i in range(0, max(0, len(s) - n + 1)))


def ov(a, b):
    return len(a & b) / max(1, len(a))


def do_book(bk):
    d = os.path.join(T, '重譯', bk, '_材料')
    rep = os.path.join(T, '重譯', bk, '_盲翻', '回覆')
    dst = os.path.join(T, '重譯', bk, '_盲翻_對齊', '回覆')
    os.makedirs(dst, exist_ok=True)

    mats = {}
    for f in os.listdir(d):
        if f.endswith('.md'):
            md = MI.parse_md(io.open(os.path.join(d, f), encoding='utf-8').read())
            mats[f[:-3]] = grams(''.join(u['tr'] for u in md.get('units', [])))

    reps = {}
    for f in os.listdir(rep):
        if f.endswith(SUF):
            reps[f[:-len(SUF)]] = grams(
                io.open(os.path.join(rep, f), encoding='utf-8').read())

    same = {k: ov(v, mats.get(k, set())) for k, v in reps.items()}
    bad = [k for k, v in same.items() if v < MIN_SAME]
    badset = set(bad)

    assign = {}
    orphans = []
    for k in bad:
        R = reps[k]
        best_v, best_k = 0.0, None
        for mk, mg in mats.items():
            if mk in badset:          # 只挑「目前沒有可用回覆」的目標
                v = ov(R, mg)
                if v > best_v:
                    best_v, best_k = v, mk
        if best_k and best_v >= MIN_MATCH:
            assign.setdefault(best_k, []).append((best_v, k))
        else:
            orphans.append(k)

    final = {}
    for k, v in reps.items():
        if k not in badset:
            final[k] = (k, ov(v, mats.get(k, set())))
    for mk, cands in assign.items():
        cands.sort(reverse=True)
        final[mk] = (cands[0][1], cands[0][0])

    for mk, (src_k, score) in final.items():
        shutil.copy2(os.path.join(rep, src_k + SUF), os.path.join(dst, mk + SUF))

    miss = [k for k in mats if k not in final]
    print('%s：材料 %d｜回覆 %d｜對齊 %d｜孤兒 %d｜仍缺 %d'
          % (bk, len(mats), len(reps), len(final), len(orphans), len(miss)), flush=True)
    if orphans:
        io.open(os.path.join(T, '重譯', bk, '_盲翻_對齊', '_孤兒.txt'), 'w',
                encoding='utf-8').write('\n'.join(orphans))
    if miss:
        io.open(os.path.join(T, '重譯', bk, '_盲翻_對齊', '_缺漏.txt'), 'w',
                encoding='utf-8').write('\n'.join(miss))
    return len(final), len(orphans), len(miss)

    ap.add_argument('--books', default='業疏,戒疏,尼鈔,行事鈔,義鈔,資持記')
    args = ap.parse_args()
    for bk in [x.strip() for x in args.books.split(',') if x.strip()]:
        do_book(bk)


if __name__ == '__main__':
    main()

### 7.6 檢索撞牆成因與對策（L7 實測）

| 觀察 | 數據 |
|:--|:--|
| 撞牆只發生在本地次數用滿（=5）的檔案 | 用滿 5 次的 16 檔，被擋 20 次；未用滿者 0 次 |
| 高檢索檔吃掉大部分輸入 | 16 檔平均輸入 46,398；未用滿者平均 15,880 |
| 全批輸入分布 | 100 萬 token 中約 74 萬來自這 16 檔 |

**成因**：一輪平行呼叫 2–4 個本地檢索，一次吃掉多次額度；查無結果仍計次；最後一次額度用完時沒有任何提示，模型再叫一次即被擋，白重送整段歷史。

**已採對策**（不動提示詞）：

| 對策 | 效果 |
|:--|:--|
| 額度用盡那次回傳附 `notice` | 少一輪空轉 |
| 查無結果前 2 次免扣額度 | 打錯詞不浪費名額 |
| 相同查詢直接沿用結果、不計額度 | 消除重複搜尋 |
| `pad` 400→240、`rows` 5→3、`book_counts` 只回一次 | 單次回傳字數減半 |
| 分層輪流取樣（每層先各 1 筆） | 少量筆數仍看到科記／南山／律藏三層 |
| 前後背景上限 900／600 字 | 擋極端長鄰居 |

未採「每輪最多 2 個本地呼叫」：多一輪即重送整段歷史與思考，實測反而更貴。
