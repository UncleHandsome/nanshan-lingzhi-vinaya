# 校閱材料　第794檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【794-0001】02_戒疏/18c_卷四上之三#136
【原文】【記】釋初緣中。欲釋後文，須明來意。由《律本》中犯相不顯，致令古判過藥限提，過夜限吉。是以《鈔》中猶存古義。今《疏》欲翻舊解，以立夜重藥輕，故引明據會釋相違。如是尋之。初定罪中，先引《十誦》。四藥明犯，並據過限。初「時食」中，「餘事吉」者，衣等餘物也。下三藥中，「非時吉」者，藥味輕也。「此」下，會同。以今戒本不明時藥，故引彼證。此乃舉「施一食戒」，例成今犯通於四藥。
【譯文】【記文】解釋第一犯緣中。欲明了後文的法義，必須先明白此處的立論脈絡。由於《四分律》根本律文中犯相未曾明言，致使古時律師多判定為「過限索藥結提，逾期過夜結吉」。因此《行事鈔》在早期仍保留了這種古解。如今本《疏》意欲推翻舊說，確立「過夜日限罪重、索藥品類罪輕」的新標準，所以引述明確教據前來融會貫通表面相違之處。大家應循此深入探究。在首先裁定具體罪刑時，先引《十誦律》。該律以四種藥物明定犯相，皆依「過限」而論。初句時食中，「索餘事吉」是指衣服等身外之物。後面三種藥物中，「索非時藥吉」是因為非時藥的藥性與滋味最為輕微。「此亦同彼」以下，予以會通。因為今《四分律》戒本中未明言是否包含時藥（時食），故引彼律為證。這是藉由「施一食戒」之例，推知本戒所制同樣通於四種藥物。

【794-0007】02_戒疏/18c_卷四上之三#142
【原文】【疏】答：「隨義以彰。此戒索輕，過限重也。故《善見》云『施油索蘇，但犯吉羅』，是知輕也。所以然者？先有好心四月與藥，期限已滿，供養心息，過受置惱，敗處深損。又承前受請，人喜過日，故重。」
【譯文】【疏文】答：「應順應律法之深刻深義來彰明。本戒之中，索求藥物之品類偏差僅結輕罪，唯有『逾越期限受用』才結重罪。所以《善見律》說『施主原本發心施油，比丘開口索酥，僅犯突吉羅』，由此確知單純索藥出格其罪甚輕。何以如此呢？因為施主當初滿懷善心承諾四個月給與醫藥，如今期限已滿，其供養之心業已平息；比丘若再逾期強受，帶給施主深切的惱亂，徹底敗壞其善信，損害極其深重。又出家人承接先前受請之便利，最易放縱得寸進尺、逾期賴留，所以結罪極重。」

【794-0008】02_戒疏/18c_卷四上之三#143
【原文】【記】答中。初判定。戒本語暗，理須義決，故云「隨義」。「索輕過重」，此翻古解，正示今判。「故」下，引文證上索輕。「所以」下，約義示過限重。上標隨義，於此方彰。文列二過，顯知須重。初約違施惱深；「又」下，二、即承勢喜作。
【譯文】【記文】答覆之中。首先做出確切判定。戒本文字含蓄，法理上必須依義決斷，所以說「隨義」。指出「索藥輕、過限重」，這徹底翻轉了古代舊解，正式昭示今時本疏的新判準。「故善見」以下，引權威論典證實索藥為輕。「所以然者」以下，從純理層面闡明何以逾越期限之過犯極重。上文標明隨義，在此才充分顯發。文中列舉兩大過失，顯見非判重不可：初者違背施主之意而惱亂極深；「又」以下，第二層是比丘承其方便習以為常而易犯此過。

【794-0011】02_戒疏/18c_卷四上之三#146
【原文】【記】初難。戒緣因索而制，那得過限判犯。答中，初句是縱，由本緣起實因索故。「然」下，即奪。三處求文，兩處同故，不可執緣。「辨相」即是廣解，如注引云「夜、藥分齊，夏四月應受」等。「及戒本」者，即「四月與藥」，乃至「若過」。「既」下，雙結二文。
【譯文】【記文】第一輪問難中。質疑緣起純因比丘索藥而制，怎可如今全依逾限過期來判罪？答覆中，第一句先作讓步縱容，承認最初緣起確實因索藥而引發。「然」以下則是正式駁斥奪正。於律典三處求證文義，有兩處是一致明判的，不可偏執於緣起字句。「辨相」即是廣解之文，如隨文註解所引「夜、藥分齊，夏四月應受」等。「及戒本」是指戒文本句中說「四月與藥……若過」。下文「既明」二字，總結這兩處權威文句，證成其非指索藥之相。

【794-0014】02_戒疏/18c_卷四上之三#149
【原文】【記】次難中。《律》分四句。一、夜有分齊藥無分齊，二、夜有分齊藥有分齊，此二應夏四月受。三、藥有分齊夜無分齊，四、夜無分齊藥無分齊，此二應隨施時受。難意云：若言廣解、戒本約夜成犯，非索犯者，則第三句不應列之。此由《律》文不定輕重，故生此難。答中，上二句明《律》列所以。因前過夜歷句而來，故云「同初」等。「過」下，約義定犯，如上已明。今更總判：《律》中四句，前二犯提，第三句吉，第四無犯。
【譯文】【記文】第二次質疑中。《四分律》將情況分為四句：第一、夜有分齊而藥無分齊；第二、夜有分齊且藥有分齊——此二種情況皆應在夏季四個月內如期受用。第三、藥有分齊而夜無分齊；第四、夜無分齊且藥亦無分齊——此二種情況則應隨施主每次布施之時隨緣受用。問意指：若謂廣解與戒本皆以過夜論犯、非因索藥而犯，則第三句根本不應列出。此因《四分律》原文未曾明定輕重，方生此難。答覆中，前兩句說明《律》文之所以四句並列之原由，純是因承接前文探討過夜期限而歷句推演而來，故云「同初」等。「過索」以下，依律理精準定罪，如上文所已明示。如今再為大家作出一座總判：《律》中四句，前二句逾越約定天數者結犯波逸提墮罪；第三句僅藥物逾限者結吉羅；第四句無期限約束者則無犯。
