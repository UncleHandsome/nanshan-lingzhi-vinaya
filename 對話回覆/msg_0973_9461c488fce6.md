### 一、必修的 3 個實質 Bug

#### 1. `pack_judge.py` 拆回時會直接 `NameError` 當機
- **位置**：`do_split()` 內的 `_only_a_line` 與 `_only_a_grp`。
- **原因**：`def _only_a_line(ln):` 目前縮排在 `if not raw_segs and i in _by_i:` 裡面。只要包內有某段是正常改動（`raw_segs` 非空）且第 2 欄有提到該段（`i in _by_i`），`if` 不會進入，緊接著執行到 `_only_a_grp` 裡的 `all(_only_a_line(ln) ...)` 就會直接噴出 **`NameError: name '_only_a_line' is not defined`**。
- **修法**：把 `_only_a_line` 移到 `for i, ok_key in enumerate(originals, 1):` 外面，並替 `_only_a_grp` 加上 `not _has_body` 保護（避免第 3 欄有改動譯文卻被誤判成 `PASS_A`）：
  ```python
  def _only_a_line(ln):
      _m = re.search(r'裁決[（(]([^）)]*)[）)]', ln)
      if not _m:
          return (('沿用' in ln or '無分歧' in ln)
                  and ('乙優' not in ln) and ('重修' not in ln))
      _g = _m.group(1)
      return ('甲優' in _g) and ('乙優' not in _g) and ('重修' not in _g)

  for i, ok_key in enumerate(originals, 1):
      ...
      _only_a_grp = ((not _has_body)
                     and ((i not in _by_i) or all(_only_a_line(ln) for ln in _by_i[i])))
  ```

#### 2. `qwen_local.py` 的「重貼原文保護」已完全失效
- **位置**：`_looks_pasted(col3, src_unit)`。
- **原因**：`a = ''.join(HAN.findall(col3))[:20]` 和 `b = ...[:20]` 最多只取 **20 個字**，底下卻改成了 `if same < 24: return False`。`zip(a, b)` 最多只跑 20 次，`same` 永遠不可能達到 24，等於整個函式永遠回傳 `False`。
- **修法**：要以 24 字為門檻，就把前面切片同步放大到 `[:30]`（或把門檻改回 `18`）：
  ```python
  a = ''.join(HAN.findall(col3))[:30]
  b = ''.join(HAN.findall(src_unit))[:30]
  ```

#### 3. `check_align.py` 一執行就會 `UnboundLocalError`
- **位置**：`check_book(bk)` 迴圈內外。
- **原因**：`lens[f[:-3]] = ...` 寫在迴圈裡，但 `lens = {}` 卻寫在迴圈**後面**（而且連寫了兩次），一執行就會在 `mats` 迴圈報 `UnboundLocalError`。
- **修法**：把 `lens = {}` 移到 `mats = {}` 下面、迴圈之前，並刪掉迴圈後重複的兩行 `lens = {}`。
