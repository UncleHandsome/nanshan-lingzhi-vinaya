整體看下來，譯文讀得懂、方向也大致正確，但有幾類問題值得修：**科文術語誤譯**（牒斥、雙結、遮轉計、並之）、**引文與原文不一致**、**增字造成語意偏移**、以及 **「開急就緩」「相可」「正制」等關鍵詞未統一或譯得含糊**。以下逐則列出。

## 一、逐則檢視

### 【#115】問題較多（建議重譯）

| 原文 | 現譯 | 問題 |
|---|---|---|
| 初牒斥 | 首先指出詰難 | 「牒」＝牒舉對方之語，「斥」＝斥破。譯文把「引述＋破斥」的科文結構丟掉了 |
| 「此有餘」 | 「此**亦**有餘」 | 引文多一字，與原文不符 |
| 立義不盡 | 立論不夠**透徹**周全 | 「不盡」是「未窮盡、尚有遺漏」，不是「不透徹」 |
| 雙結 | 作**雙重**總結 | 「雙結」是把僧、衣**二界一併結破**，不是「雙重」 |
| 遮轉計 | 預先堵絕**狡辯** | 「轉計」是論辯術語：轉而另立主張。譯成「狡辯」帶情緒、失準 |
| 容有不定 | **難免**不固定 | 「容」＝或許、可能；「難免」變成必然，語氣過重 |
| 為聚所侵 | 被聚落所**侵犯** | 應作「被聚落（界）所侵奪／擠佔」 |
| 故以僧界並之 | 拿僧界來**同等對質** | 「並」＝並例責破（舉僧界同樣情形一併破斥），「對質」語意含糊 |

另外「可分別聚」是術語（可分別聚落／不可分別聚落），建議保留原詞再加注，不要只散譯成「可以分別的聚落」。

**建議改譯：**
> 其次難破第三義。文中先牒舉（對方之語）加以斥破。所謂「此有餘」，是說對方立義不夠周盡。「衣界」以下，列舉顯示。先就衣界說：十一種中「蘭若（界）是定」，怎能說不定？其次就僧界說：六相之中，可分別聚落隨處所而寬狹不同，怎能說「一定」？「此」字以下，僧、衣二界一併結破。「若」字以下，遮防對方轉立異計。恐對方說「蘭若緊鄰聚落時，為聚落界所侵奪，或許有不定」，所以再舉僧界並例責破。

### 【#116】
1. 「今準**諸部**」譯成「其餘**部派**」→ 應作「諸部律（其他律典）」，此處指律本不是部派學說。
2. 「隨聚落是僧房」譯「隨順聚落之處即是僧房」略嫌直譯；意思是**僧房（僧界）範圍隨聚落界而定**，可譯「（僧房界）隨聚落界為範圍」。
3. 開頭加「如果說」方向對（這是牒舉所破之義），但建議明示，如「（他義立云）衣界定有、僧界定無」，讀者才不會誤以為是道宣自宗。

### 【#117】
1. 「本律僧界雖無勢分」→ 譯文加「**明文**」二字，變成「律有而未明說」，屬增字失真，宜刪。
2. 「那得云無」→「怎能說**完全**沒有」，「完全」可刪。
3. 「本律」建議補注《四分律》。
4. 「反是相可」可補一句因由：**二種自然界同有勢分，故反而相可**，讀者才接得上前文。

### 【#118】★最需處理的一則
1. **「開急就緩」譯成「都是開許嚴急而依循寬緩」語意自相矛盾**（「開許嚴急」讀起來像「允許嚴格」）。此語一般應讀作「**開其急、就其緩**」——把根本（自然界）的侷促限定放寬而趨於寬緩。建議照此改譯，並加校注說明此句未見《行宗記》正面解釋，屬待考之語，不宜含混帶過。
2. 「相可（**相等**）」的括注不妥。「相可」是**性質相類、可以相例（相齊）**，非指範圍相等；且他處都譯「吻合」，宜統一。
3. 「比前四義」譯「對比前面的四種義理，因此是相互吻合」邏輯不順——前面四義是**相非**，此處是**一一翻反**而說相可。建議：「比照前面（相非的）四義一一相反，故說相可。」

### 【#119】
1. 「僧、衣自然，並是根本」→「都是**根本法規**」：這裡「根本」指界體的本源（相對於枝條），不是「法規」，宜刪「法規」。
2. 「兩界相假」譯「互為依託」尚可，但建議保留術語「相假（互相依憑藉）」並加注（衣界依僧界而結等）。
3. 「故云『比前四義』等」——記文只引「比前」，引號內宜作「比前」，補字放括號。

### 【#120】
「明勢分有無者」→ 加「的差別」可接受（此門本在比較），但屬增譯，可保留原樣作「第十、明勢分有無」。

### 【#121】
「同是攝衣」建議補主語：「（自然界與作法界）同樣是攝衣界」，並可注「攝衣＝界能攝護衣，令不犯離宿」，比單說「攝持衣服」精確。

### 【#122】無問題。

### 【#123】★
「以無教法」譯成「**沒有教法的作法界線**」自相矛盾（既無教法又是作法界？）。應作「因為沒有（羯磨結界的）教法制限」。
> 建議：「有（作法）法故無（勢分），無（作法）法故有（勢分），有何可怪？正因沒有教法制限，便隨（自然）界相開許有勢分。」

### 【#124】
1. 「『**以無**』以下」→ 原文作「『以』下」，引文宜一致。
2. 「**正好**反顯上句」→ 原文「**可**反上句」，是「可由此反推」，語氣宜放軟：「可反顯上句『有法』則不開勢分」。

### 【#125】大致無誤。「界外既無作法」是合理補足，可保留。

### 【#126】
「界體在**劃界內外實質**是否相同」贅字且拗口。
> 建議：「第二解：是說界體內外（性質）有同、有不同，所以勢分有有、有無。」

### 【#127】
1. 「正制」譯「最初制定的**正條**」用詞生硬，且與 #128「最初制約」不一致。建議統一作「**正制（本制、正式制定之法）**」，「最初」義可放括注。
2. 「作法限約」可譯「作法界既已限定分齊（有明確界限）」，比「本有限制約束」貼切。

### 【#128】
1. 「初反前釋」譯「先依反向對照來解釋」丟了對應的疏文。宜作「第一是約『反前』而釋（即疏『作法反前，故無勢分』一句）」，並把「比上二義」明點為「根本」「正制」二義。
2. 「約開制釋」譯「開許與**制戒**的法理」→ 此處「制」是**正制／本制**（與「後開」相對），不是「制戒」；宜作「約開、制而釋」。
3. 「自然是制」→「自然界是最初**制約**」與前則統一為「正制」。
4. 「恐太緩故」→「唯恐**戒法**流於太過寬緩」：增譯「戒法」把它導向戒律鬆弛，原意應是**攝衣範圍開得太寬緩**，建議改「怕（開得）太過寬緩」。
5. 錯字：「重**覆**開許」→「重**複**」。

## 二、建議統一的術語

| 術語 | 建議處理 |
|---|---|
| 勢分 | 首次出現注「界外延伸的勢力範圍」，之後一律保留「勢分」，不要時而「延伸的勢分」時而「向外延伸的勢分」 |
| 相可／相非 | 相可＝性質相類、可相例；相非＝相異、不能相例。全篇統一（避免「相等」） |
| 根本／枝條 | 保留原詞＋注（本源界體／從根本開出者），勿譯成「根本法規」 |
| 正制／後開 | 正制（本制）／後開（後來開許），勿混用「制戒」「制約」 |
| 作法（界） | 一律作「作法界（羯磨所結之界）」 |
| 牒／斥／雙結／遮轉計／並之 | 科文語建議固定譯法：牒舉／斥破／二義併結／遮防轉計／並例責破 |

## 三、通則提醒
1. **引號內務必與原文逐字相符**（此有餘、以、又、比前），補字用括號。
2. **增譯節制**：「明文」「完全」「法規」「戒法」「狡辯」等屬解釋性添加，會改變論斷強度或對象，宜刪或移入注腳。
3. **情態詞對準**：容（或許）≠難免；可（可以反推）≠正好。
4. 「開急就緩」這類未見記文正解的語句，建議加校注標「待考」，比強行順譯安全。
