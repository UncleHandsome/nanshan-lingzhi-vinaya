# 校閱材料　第420檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】佛即制斷，如文所引。龍為緣起，餘畜皆然。轉問中，初明問意。脫下，教改轉。如下自出也。脫猶忽也。二形中，初示相。《善見》三種：一能自受胎，復能令他受胎；二但能自受；三但令他受。三並是難，皆二形故。若下，以失況受。即四捨中一。準《疏》，三障收者。黃門愛欲多，煩惱障收；
【譯文】佛陀於是制戒斷除，如文中所引。以龍作為緣起，其餘畜生也都一樣。「轉問」中，先說明問的用意。「脫」字以下，教導對方改口轉說。（轉問的具體方法）在下文自然會列出。「脫」就是「忽」的意思，即倘若、忽然。「二形」中，先顯示相狀。《善見》說有三種：一、自己能受胎，也能令他人受胎；二、只能自己受胎；三、只能令他人受胎。這三種都是障難，因為都是二形的緣故。「若」字以下，以失戒比況受戒。這就是四種捨戒中的一種。依《疏》所說，用三障來收攝：黃門愛欲多，歸煩惱障所收；

【420-0006】資持記/04b_上三#50
【原文】然非明文，容多異解；今師義判，故在後列。問：據定不發，何不名難？答：名可改稱，年容待滿。非同永障，不在難收。年不滿者，須論胎閏；頻大布薩，增不滿者。《五分》中，初列是遮。制僧輒度。或下，次明非遮。制僧作難。《僧祇》多種，大同《四分》。略舉七相。雀目即屬盲中。
【譯文】然而這並非明文規定，容許有多種不同的解釋；現在律師依義理判定，所以列在後面。問：依據確定不發戒，為什麼不稱作「難」呢？答：名字可以改稱，年齡可以等到滿。不同於永久的障礙，所以不歸入「難」所收。年齡不足二十歲的，必須核算在母胎中的月份與閏月；至於因連續逢大月布薩而藉機虛增歲數者，佛判定依然屬於年歲不滿（不得戒）。《五分律》中，先列出的是「遮」，制戒：僧眾不可隨便剃度。「或」字以下，其次說明不是「遮」的情況，制戒禁止僧眾故意刁難。《僧祇律》有多種，大致與《四分律》相同，略舉七種相狀。雀目也就是夜盲，即屬於「盲」一類之中。

【原文】聾人下，準彼合有瘂者，下科牒解，必應寫脫。躄音辟，不能行也。尻，苦高反，臀也。鞭瘢音盤，杖痕也。凸，起也，徒結反。凹，陷也，烏洽反。印瘢，今謂雕青也。獸形，彼云作種種鳥獸像。侏儒，短人也。彼律諸遮，皆以不應等語別別結之；今此總括，故云一切等。

【420-0008】資持記/04b_上三#52

【原文】意彰開得。下引果人，釋成初義。《疏》云：由惑盡此生，業終報故，總集受也。若下，明受已病生。因而引之。或可已受既共僧事，故知未受必不障戒。餘事中。言所以者，謂受戒事重，諸部制嚴；所明餘事，重彰此意故也。初科。《五分》，反顯相識猶通暗受。續引燈照，不容濫委。
【譯文】探究病因是為了顯明佛陀開許受戒的意旨。下文引用證得聖果之人的例子，來解釋並成立前面的義理。《戒疏》說：這是由於阿羅漢此生的煩惱已經斷盡，宿世惡業終究要受報，所以諸病總集在此生受償。下文提到「如果受戒之後才生病」，也是順帶引出以作對照。或者可以說，已經受戒的人既然生病還能參與僧事，由此便可推知，未受戒者只要不具障礙，疾病也必定不障礙其得戒。在「其餘事宜」的科判中，之所以詳細說明，是因為受戒是一件極為隆重的大事，各部律宗的規制都極其嚴格；所闡明的其餘細項，正是為了反覆申明這個要旨。第一科引《五分律》，是反向顯明若是彼此熟識的僧眾，即使在昏暗中受戒也能通融。接著又引「需有燈火照明」，是為了杜絕一切含混隨便、托辭委過的情況。
