# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【242-0004】02_戒疏/11c_卷三上之二#111
【原文】【疏】餘諸戒。如取尼衣，將衣來施，自量量他，見無法利，止心不受，恐犯戒故名止持。不但無心緣念便名止也。此止無記，非隨戒也。翻止受納，名作犯也。犯必依記，成於業也。
【譯文】【疏文】其餘各條戒。好比取比丘尼衣戒，比丘尼把衣服拿來布施，自己衡量自身與他人，見到沒有正法的利益，便收攝自心不加接受，因為恐懼犯戒的緣故所以稱為「止持」。這絕不僅僅是內心無念無想就叫做止；這種無所用心的停止屬於無記性，並不是隨順戒法而生起的持戒。翻轉過來不止住而領納受用，就稱為「作犯」；犯戒必定依附於善或惡的心念，從而構成業力。

【242-0005】02_戒疏/11c_卷三上之二#112
【原文】【記】次單持中。初句總示二十一戒。「如」下，別舉示相，又二。初明止持。「自量」等者，謂先觀察，即是智也。然後「不受」，即是行也。「不但」下，反古。彼謂任運不作即是止持，如前已破。「此」下，決破。因臨此語，不覺喟然，嗟往者之不聞，喜來蒙之獲遇。可謂毗尼教旨，皎在目前；萬行修持，坦然有據。寄言學者，熟而思之。「翻」下，明作犯。
【譯文】【記文】次論單純止持當中。第一句總括說明其餘二十一條戒。從「好比」以下，分別列舉行相，又分為兩層。首先說明止持。「自量」等語，是說事先省察，這就是智慧；然後「不受」，這就是修行實踐。從「絕不僅僅」以下，駁斥古說；古說認為任運無為不做就是止持，如前面已經破斥。從「這種」以下，作決斷破斥。在讀到這段話時，不由得令人慨然長嘆：既哀傷於往昔前人未曾得聞此理，又慶幸於後世蒙昧者得以遭遇此法。這可以說是讓毘尼戒律的深意，清清楚楚顯露於眼前；萬種修持之行，坦蕩穩實而有所依憑。寄語後世參學者，應當深思熟慮。從「翻轉」以下，說明作犯。

【242-0027】02_戒疏/11c_卷三上之二#134

【原文】【疏】未受具前，先教人作十五戒。
【譯文】【疏文】在尚未受具足戒之前，預先教唆他人製作，牽涉到十五條戒。

【242-0031】02_戒疏/11c_卷三上之二#138
【原文】【疏】謂長衣、鉢、月望、急過後。此四戒者，沙彌時受財屬已，受具後數過十日，謂通受前，三性之中任運犯提。藥法不爾，沙彌時作手、口二受竟，進具後即失受法，故無任運也。
【譯文】【疏文】也就是長衣、長缽、月望衣、急施衣過期之後這四條戒。沙彌時期接受了財物歸為己有，受具足戒之後計算天數超過十天，也就是通計受戒前受戒後的日子，在善、惡、無記三性之中自然任運構成捨墮。七日藥法则不是這樣，沙彌時期親手受取並口中受法完畢，進受具足戒之後便立即喪失了先前的受藥法，所以不會任運構成犯戒。

【242-0032】02_戒疏/11c_卷三上之二#139
【原文】【記】初科，四長中。準《義鈔》，此有二義。「受後數過」，即初義也。「謂通受前」，即是次義，《義鈔》云「亦可通前日數，前後滿十」，「謂」合作「或」。又詳，彼存二義，此取後義，釋上「數過十日」，故云「謂通受前」也。然須更簡，犯有二別，一、正受日過，二、受竟限滿，並三性犯。下簡長藥。雖是長數，由有受法，故異上四。「受法失」者，以位別故。
【譯文】【記文】第一科，在四種長物戒中。依照《義鈔》，這裡包含兩種義理。「受戒後計算天數超過」，這是第一種義理；「通計受戒前受戒後的日子」，這是第二種義理，《義鈔》說「也可以通算受戒前的天數，前後合滿十天」，「謂」字應當作「或」字。再詳加審核，彼處存留了兩種義理，此處採用後一種義理，用以解釋上面的「數過十日」，所以說「謂通受前」。然而必須再加簡別，犯戒有兩種不同：第一是在正受具戒之日超期，第二是受戒完畢後期限屆滿，兩者都通於三性犯戒。下文簡別長藥。雖然同是計算長期的日數，但由於長藥包含特殊的受持法，所以不同於上面四條。「受法失效」，是因為果位品階不同的緣故。
