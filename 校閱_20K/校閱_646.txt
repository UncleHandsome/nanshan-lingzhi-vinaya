# 校閱材料　第646檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【646-0001】資持記/15c_下三#26
【原文】古今多有，世事昭。23 釋訃請篇(下三)釋訃請篇訃是比丘允許，請即施主邀命。往訃前請，意存化導；必施法式，發越彼心，故云設則也。敘意中，初明俗眾營福所以。《智論》明福智二分，俗修福分，謂布施也；道修智分，謂學慧也。塵網所縈，故云昏俗。
【譯文】這種慘痛的教訓從古至今屢見不鮮，世間的真實事跡已經昭然若揭。第二十三篇 解釋訃請篇（屬於下卷第三部分）。解釋訃請篇所謂「訃」，是指比丘答應接受應請；所謂「請」，是指施主發心邀請降臨。僧人前往應赴施主先前的邀請，其本意全在於慈悲化導眾生；因此必須施設合宜的威儀法度，才能真正啟發彰顯施主內心的善根，所以說是「設則」。在敘述主旨緣起中，首先說明世俗大眾經營修植福報的原因。《大智度論》開示修福與修慧兩大部分，在家人主要修持福德部分，也就是行布施；出家人主要修持智慧部分，也就是學佛法智慧。世人常被塵世情網所牽纏束縛，所以形容為「昏俗」。

【646-0002】資持記/15c_下三#27
【原文】制謂教示，非禁制也。接愚惑者，即前所謂作出家得道因緣；或復且令遠離惡道，生人天中，堪受化故。而下，次明道眾受訃乖儀。施通四事，故云雜繁。生譏即損他，癡慢即損自，苦趣，即自他俱墜。故下，示今所述。如別，即下十科。列章有十，攝盡始終。一六及九，事通僧俗，餘並在僧。
【譯文】此處所謂「制」，是指教化開示，並不是指禁止防制之意。所謂「接引愚昧迷惑之人」，也就是前面所說為他們種下未來出家得道的殊勝因緣；或者退一步說，暫且令他們遠離三惡道的痛苦，轉生於人間天上，以便未來堪能接受佛法教化。自「而」以下，接著說明出家大眾在接受赴請時違背威儀法度的弊病。施主的布施通於衣食住藥等四事供養，所以說是「雜繁」。招致世人譏嫌就會損害他人善根，僧人生起愚癡傲慢就會損害自身德行，最終自他共同墮入「苦趣」惡道受苦。自「故」以下，標示本書當前所要闡述的核心。所謂「如別」，就是指下文所列出的十個科判。條列的篇章共有十門，總括包攬了赴請從始至終的所有規範。其中第一、第六以及第九門，事理通於僧眾與俗眾雙方，其餘各門則全在於規範僧團內部。

【646-0003】資持記/15c_下三#28
【原文】具如後釋。初門，來請中，《十誦》。明立維那，下翻寺護，謂監護寺事也。餘名如上卷。《僧祇》，初教答請。恐為緣阻，故不定答。若有下，令審實。不得下，明預探。此約生分，必是舊識，則不須之。次科，《五分》。開借僧物。《僧祇》。開僧作務。
【譯文】詳情如同後文逐一解釋。第一門，施主前來請僧的科判中引用《十誦律》。說明僧團應當設立維那這個執事，下文翻譯為「寺護」，意思是指監護管理整座寺院的事務。其餘執事的名稱已在上卷詳細說明。《僧祇律》中，首先教導如何如法應答施主的邀請。唯恐臨時被其他僧務因緣所阻礙，所以不宜立刻把話說滿、作絕對肯定的回答。自「若有」以下，指示應當審慎查明事實狀況。自「不得」以下，說明應先遣人預往探訪。這主要是針對不熟悉的生疏施主而言，如果必定是相熟的舊識，就不需要如此防備。下一個小科引用《五分律》。開許借用僧團公物給施主辦齋。《僧祇律》。開許僧人前往施主家協助操辦事務。

【646-0004】資持記/15c_下三#29
【原文】且據無能，必有能者，但可指授。輿合作舁，共擡物也。文中，但簡對舁；恐謂得為造食，故注決之。一避觸煮，二為乖儀。《四分》。明離過。引本緣起，以規後世。為未來者，或恐過奢，招世譏謗；或恐末世福尠，不堪銷故。三中。引佛真規，以為後則。文列三相，隨一即成。
【譯文】這暫且是針對施主家中無人能操辦的情況而言，如果施主家有能幹之人，僧人只要在旁指點指導即可。經文中的「輿」字應當作「舁」，意思是大家合力共同抬抬物品。律文中僅僅揀選排除兩人相對合抬一物；唯恐有人誤以為僧人可以親自為俗家下廚烹煮造食，所以在注文中特別加以判決禁止。第一是為了避免觸摸食物與親自烹煮（犯惡觸與自煮）的過失，第二是因為這樣做嚴重違背僧人威儀。《四分律》。說明應當遠離的過失。引用當初制戒的根本緣起，來作為規範後世弟子的準繩法則。之所以為未來著想，一方面是唯恐排場過度奢華，引來世人的譏諷毀謗；另一方面是唯恐末法時代眾生福報微薄，無法消受這般厚供。第三段中。引述佛陀當年的真實規則，作為後世萬代的標準典範。經文中列出佛陀認可的三種相狀，只要具備隨便一種便算應允成功。

【646-0005】資持記/15c_下三#30
【原文】儼頭，《經音義》云：字合作頷，世謂點頭是也。四中，《五百問》有五事，初審施物。作佛物，即今彫畫佛像之家，兼通道俗。若先下，次明賽願。謂施家力所不及，欲以三遍行香，三迴施物，即當三會；以違本心，故云不了。若下，三受神食。
【譯文】所謂「儼頭」，《經音義》中說：這個字應當作「頷」，也就是世俗所說的點頭應允。第四段中，《五百問經》中列出了五件事，首先是審查布施財物的來源與性質。所謂製作佛物，就是指現今從事雕刻繪製佛像的工匠家庭，這項規矩兼通於僧人與在家人。自「若先」以下，接著說明還願謝恩的規矩。意思是說施主家財力有所不及，想要以三次行香、三次布施物品的方式，當作已經辦了三次齋會；因為這違背了最初許願的本心，所以說是「不了」。自「若」以下，第三是說明接受神祇祭祀飲食的規範。

【646-0006】資持記/15c_下三#31
【原文】《鬼子母經》云：佛遊大兜國，有一母性惡，常盜人子；佛為說法，告云：從是已去，止佛精舍邊；人民無子者，來求當與；今或有人設食，持施比丘也。呪願，即為施主求願也，廣在第六。沽下，四擇施家。屠沽之家，由涉譏疑，不令輒入。前制餘時，故云一切。餘門得者，必約有緣。
【譯文】《鬼子母經》中記載：佛陀遊化至大兜國時，有一位性格凶狠殘暴的鬼子母，經常偷盜抓取人類的孩子吃掉；佛陀為她說法化度，並告誡她說：從今以後，妳應當安住在佛陀精舍旁邊；民間若有膝下無子的人，前來祈求妳就應當賜給他們孩子；如今若有人特地施設飲食祭拜，也可以拿來布施給比丘僧。所謂「咒願」，就是比丘為施主祈求福願，詳細內容在第六門中解說。自「沽」以下，第四是選擇應請的施主家庭。屠宰殺生與販賣酒漿的人家，因為容易招致世人的譏諷懷疑，所以不准僧人隨便進入其家。前面曾制訂其餘時段皆不可入，所以說是「一切」。若有其他門戶（偏門、側門）開許進入的，也必定是局限於有特定的因緣。

【646-0007】資持記/15c_下三#32
【原文】請僧設食，令彼持戒停業，方便接引故也。若共下，五開同師坐。五中，有三，初引文示。《四分》通二請；律開下，諸文並明僧次。《梵網》云：一切不得受別請，利養入已；而此利養，屬十方僧；而別請者，即取十方賢聖僧物。〔此制受請。
【譯文】邀請僧人前去施設飲食，是為了勸令屠沽之人持守戒殺、暫停殺業，這是為了慈悲方便接引他們所作的權巧。自「若共」以下，第五是開許同師的弟子可以同座而坐。第五段中分為三個部分，首先引述律文作出說明。《四分律》通達兩種請僧方式；自「律開」以下，各部律文與經論全部嚴格指明必須依「僧次」接受順序邀請。《梵網經》說：一切比丘都不得隨意接受施主的個別挑選邀請，把供養利養納入個人私囊；須知這種利養原本屬於十方僧眾共有；如果私自接受個別挑選邀請，就等於侵佔了十方賢聖僧眾的財物。（這是嚴加防制僧人私自受請。）

【646-0008】資持記/15c_下三#33
【原文】又云：次第請者，即得十方聖賢僧；而世人別請五百羅漢菩薩僧，不如僧次一凡夫僧；若別請者，是外道法，七佛無別請法。〔此制施主。〕《仁王》亦呵責者，彼云：諸惡比丘受別請者，是外道法，都非我教等。《十誦、善生》等文，中卷〈隨相〉已引。

【646-0010】資持記/15c_下三#35
【原文】令書言訃，欲彰大度。訃至也。〔今時字書，告喪曰訃，即凶訃字。雖是祖訓，不可用之，亦隨時之義也。〕此下，顯意。苟有所不知，則令俗輕道；雖小而大，誠有所補。高望謂德望高遠也。然恐後世忽為小事，仍引諺語證之；諺，謂傳世常言，不稽典者。初句謂暫借他物，應念即時還之；
【譯文】令請帖書寫為「訃」，是為了彰顯大乘僧寶的尊崇大度。訃也就是到達應約的意思。（現今各類字書中，通告喪事才稱為訃，也就是凶訃的意思。這雖然是祖師當年的訓勉指示，但現今不可盲目沿用，這也是必須隨順時代通變的道理。）自「此」以下，顯明其中的深刻用意。僧人若對世俗常識一無所知，就會導致俗人輕蔑鄙視道風；這件事表面雖小但牽涉甚大，確實能彌補僧格形象的不足。所謂「高望」，是指道德聲望崇高遠大。然而唯恐後世之人輕忽這些小節，所以特地引用世俗諺語來證明它；所謂諺語，是指世間流傳已久的常言習語，雖然未見得查考得出經史典故。諺語第一句是說暫時借用別人的東西，心念中應當想著立即奉還；

【646-0011】資持記/15c_下三#36
【原文】次句謂貸取人財，須思早覓償之。言鄙陋者，謂雖世俗常事；苟有違者，甚失君子之行，故云廉恥本也。〔《指歸》云：此出《郗嘉賓要覽》中文，彼作羊太傅云：故知人語也。時償彼作早償，鄙陋作輕小。〕七中，《多論》五制，初制同往。不白先入，惱眾故墮。〔據律，往他家犯不白同利戒；今是施家，應吉。〕主下，二制隔日先往。
【譯文】第二句是說向人借貸了錢財，心裡必須時刻想著早日找錢償還。所謂「鄙陋」，意思是說這雖然只是世俗之間的尋常小事；但若是違背了這項準則，就嚴重喪失了君子的立身品行，所以說是「廉恥之本」。（《指歸》中說：這段話出自晉代《郗嘉賓要覽》一書，該書記載是羊祜太傅所說的話：因此可知這是古人傳世的名言。當時的「時償」在該書中寫作「早償」，「鄙陋」在該書中寫作「輕小」。）第七段中，《薩婆多論》提出五條制令，第一是制訂必須大眾一同前往。如果未向大眾稟白就私自先進施主家，會擾惱大眾心神，所以結犯墮罪。（依據本律，私自前往他人家中結犯「不白僧入聚落戒」；如今此處是指前往施主家應齋，依律應當結犯吉羅罪。）自「主」以下，第二是制訂不可提前一天先行前往。

【646-0012】資持記/15c_下三#37
【原文】以招譏故。若下，三制食訖自住。經下，四制知事後至。以營事人合先往故。食未下，五制未嚫輒起。謂未施財呪願。今僧未行嚫施，終無先去。纔得嚫已，不待呪願者多矣。餘人，謂非首領上位者。私行，謂潛去。報同學者，令知所緣。雖下，覆釋初制。前明施家，此文似是他家。
【譯文】因為這樣做容易招致外人的譏嫌非議。自「若」以下，第三是制訂用齋完畢後不可私自逗留。自「經」以下，第四是制訂管理寺務的知事僧不可遲到後至。因為負責籌辦營造公務的人，理應在僧眾之前早早前往照料。自「食未」以下，第五是制訂施主尚未行布施時不可擅自離席離去。這是指施主尚未分發布施財物及進行咒願迴向之時。現今的僧人若是施主尚未行施布施，絕沒有肯提前離開的。然而才剛拿到布施的嚫錢，便急不可耐、不等僧長為施主咒願迴向就溜之大吉的人，實在是太多了。所謂「餘人」，是指不是擔任首領上座的其餘清眾。所謂「私行」，是指私下暗中離去。所謂「報同學」，是為了讓同參道友知道自己離席的原委。自「雖」以下，反過來重新解釋第一條制令。前面說明的是施主家，這段文字表面看起來似乎是指一般平常人家。

【原文】八中。二文並明僧次。論約法同，經聽形同；無非皆為解脫出家，即堪受供。《涅槃》云：雖未受戒，已墮僧數。九中。《僧祇》作念，即晨起六念，念食處故。餘處悔過者，違念吉羅。《十誦》結犯，且據俗舍別請為言。下引論決，作相免過，此通施家，不唯常住。〔古云此據僧舍者，非。
【譯文】第八段中。經、論兩處文段都同樣闡明應當遵從僧團長幼次序受請。論典是從如法受戒的角度來界定，經典則是開許只要形貌剃染出家就同等看待；因為無非全都是為了求取解脫而捨俗出家，所以就堪能接受世間的信施供養。《大般涅槃經》說：沙彌雖然尚未受具足戒，但實質上已經算列在僧寶的數目之中了。第九段中。《僧祇律》要求必須用心作念，也就是清晨起床時的「六念」之一，要清楚憶念自己今日受請用齋的處所。鈔文說到其他處所受食就要悔過，是因為違背了晨朝作念而結犯吉羅罪。《十誦律》中所結犯的罪名，暫且是就俗家私室單獨挑選別請的情況而言。下文引用論典作出判決，只要預先標定作相就能免除過失，這種開許通於一切施主家，並不僅限於常住寺院之內。（古來有人認為這段純粹是就寺內僧舍而言，那是不正確的。）

【646-0014】資持記/15c_下三#39
【原文】第二門《四分》，初明眾集。言欲受者，謂將往也。若檀越下，次明往赴，有三，初示威儀。隨後相次，如飛雁焉。若下，二開前去。三寶看病是緩緣，故制須白；命梵急難，故通不問。若上座下，三令相待。據文所明，下待於上；義準上下並須相待，恐不及眾，容失道故。
【譯文】第二門《四分律》，首先說明僧眾集合的儀軌。所謂「欲受」，是指大眾將要前往應供之時。自「若檀越」以下，接著說明前往赴請的行止威儀，分為三個部分，首先示導威儀秩序。大眾應當依序相隨前進，整齊有序就像空中飛翔的雁行一樣。自「若」以下，第二是開許可以提前先行的特殊因緣。為了三寶公事或前往探視重病是屬於較為寬緩的因緣，所以制訂必須事先稟白（上座）；若是事關性命安危或梵行清淨的緊急災難，則通融開許不必事先稟白。自「若上座」以下，第三是命令彼此應當停步等待。依據律文表面所闡明，是下座等待上座；但在義理準則上，無論長幼上下全都必須互相守候等待，唯恐有人跟不上大眾隊伍，容易在路上失卻比丘應有的威儀道法。
