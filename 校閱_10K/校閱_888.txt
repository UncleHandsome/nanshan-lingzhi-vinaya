# 校閱材料　第888檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【888-0005】資持記/01b_上一上#39
【原文】如〈結界篇〉重明集僧，又〈羯磨篇〉中，復列集僧結界簡人受欲等，及〈受戒篇〉還述集僧等，〈釋相篇〉復明受戒具緣等。〈釋相〉、〈對施〉兩出五觀食法等。如是並為顯於行事，不可闕略；即下所謂若略減取其梗概，用事恒有不足是也。第二略指者。初約諸篇互指。
【譯文】例如〈結界篇〉重新說明集合僧眾，又在〈羯磨篇〉中，再次列出集僧、結界、簡別與會人員、受欲法等，以及〈受戒篇〉又敘述集僧等，〈釋相篇〉又說明受戒應具備的因緣條件等。〈釋相篇〉與〈對施篇〉兩度列出五觀食法等。這些全都是為了顯現實踐行事，萬萬不可闕漏省去；也就是後文所謂的「如果簡略節取其大略梗概，推行法事時往往會有不足之處」這句話。第二句是「略指」。首先是就各篇之間互相指引指稱。

【888-0006】資持記/01b_上一上#40
【原文】如〈集僧〉指結界在後，〈結界〉指集僧如前，〈說戒〉指白眾在〈僧網〉，〈安居〉指五利如〈自恣〉，〈羯磨〉中簡眾與欲並指前篇。又各就當篇明者。如〈足數〉中指四儀別相，廣如〈別眾〉；懺殘指覆藏如後。如此相指，遍該一部，且舉一二。類謂同流，從即訓順。
【譯文】例如〈集僧篇〉指稱結界之法在後文，〈結界篇〉指稱集僧之法如同前文，〈說戒篇〉指稱告白大眾之法在〈僧網篇〉，〈安居篇〉指稱受五種利益之法如同〈自恣篇〉，〈羯磨篇〉中簡別大眾與給予欲法都指引至前面的篇章。又各就本篇之內來說明。例如〈足數篇〉中指稱四種威儀的個別形相，詳細內容如同〈別眾篇〉；懺僧殘罪指稱覆藏罪相如同後文。像這樣的互相指引，遍布貫穿一部書，在此暫且舉出一兩例。「類」是指同類流派，「從」字訓釋為依順。

【888-0007】資持記/01b_上一上#41
【原文】如安居竟，合明迦提五利，不欲更繁；然夏竟受利，與下自恣同流相順，故指如彼。餘皆倣此。又釋：如無場大界，已出結法；後有場大界，即指如前。乃至加三衣法，具出一法餘並例指。受日中出半月羯磨已，一月如前。此釋亦通，不無其義。三文斷者。
【譯文】例如安居結束，理應說明迦提五利，為了不使篇幅更加繁複；然而夏末享受利養，與後文的自恣法事同屬一類且體例相順，所以指引到那裡去。其餘的都依此類推。另一種解釋：例如無戒場的大界，已經列出了結界方法；後文的有戒場大界，就指稱「如同前面」。乃至於加持三衣的方法，具體列出一種法則，其餘的便依例指引。受日外出的法式中列出半月的羯磨之後，一個月的便指稱「如同前面」。這種解釋也能通達，並非沒有道理。第三是「文斷」。

【888-0008】資持記/01b_上一上#42
【原文】如〈受欲〉中明說欲相，引《五分》、《僧祇》文，斷已續云義評等；下諸篇中義云義曰義詳義準等，皆同此例。〔古解云云，一無可取。〕四徵詞者。即推覈之語，謂推覈深隱，必假問端以為發起；汎論問答，為立賓主；賓則申疑推究，主則隨義決通；欲使言議相持，教理明顯。一咨請問〔即〈結界〉中諸問，如云大界有村得合結否？
【譯文】例如〈受欲篇〉中說明陳說欲法的相貌，引用了《五分律》、《僧祇律》的經文，引文截斷後便接著說「義理評析」等；後文各篇中說「義云、義曰、義詳、義準」等，都屬於這一類例。〔古人的種種解釋，毫無可取之處。〕第四是「徵詞」。也就是推究審核的話語，意思是推究審核深奧隱微的義理，必須借助發問的由頭來引發；大體論述問答的形式，是為了確立主客雙方；客人提出疑慮進行推究，主人則隨順義理加以決斷通達；目的是使言論議論相互辯詰，教理因此徹底彰顯。第一是諮詢請教的問難〔也就是〈結界篇〉中的種種發問，例如說大界之中若有村落是否可以合結？〕
