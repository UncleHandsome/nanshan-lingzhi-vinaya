# 校閱材料　第625檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【625-0001】02_戒疏/11c_卷三上之二#79
【原文】【疏】若以二十三戒，共長衣、月望、急施過後合捨之時，六戒即還，二離、二毛、藥、鉢是也。餘者經宿，以取尼衣前雖別犯，及捨財已，通是長淨。還財之時，以長未宿，染心還起，於新捨衣，更復相染。故令經宿，共長同還也。
【譯文】【疏文】如果拿其餘二十三條戒，與長衣、月望衣、急施衣過期後合併捨棄的時候，有六條戒是當天即刻歸還，也就是二種離衣、二種羊毛、長藥與長缽。其餘的都必須經過一夜；拿取尼衣等戒來說，在捨前雖然各別結犯，等到捨去財物之後，通通都成了長物淨施的性質。歸還財物的時候，因為長衣尚未過夜，貪染之心重新生起，對新捨的衣服又再度發生沾染，所以令其經過一夜，與長衣一同歸還。

【625-0002】02_戒疏/11c_卷三上之二#80
【原文】【記】次別配中，初科。二十七中除四長，故有「二十三」。此為所染，三種長衣，即為能染。「六戒」不染，上四如前，「藥」即七日，「鉢」謂乞鉢，此二體別，故不相染。「餘」下，明十七戒懺淨入長，容有相染。據本即還，止由隨長，故同隔宿。
【譯文】【記文】次論分別配屬中，這是第一科。二十七條戒中除去四種長衣，所以剩下「二十三條」。這是被沾染之物，三種長衣就是能沾染之物。「六條戒」不受沾染，前四種如前所述；「藥」就是七日藥，「缽」指乞缽，這兩種器質不同，所以互不沾染。從「其餘」以下，說明其餘十七條戒懺除清淨後歸入長物，容有相互沾染的可能；按原本規定當即歸還，純粹因為隨附長衣，所以一同隔夜。

【625-0003】02_戒疏/11c_卷三上之二#81
【原文】【疏】若以二十三戒，共長鉢合捨。唯乞鉢須宿，餘皆即還也。
【譯文】【疏文】如果拿這二十三條戒，與長缽合併捨棄，只有過量乞缽需要經過一夜，其餘全都在當天即刻歸還。

【625-0004】02_戒疏/11c_卷三上之二#82
【原文】【記】次對長鉢。唯一乞鉢，染故經宿。鉢不染衣，故並即還。
【譯文】【記文】其次是比對長缽。唯有一條乞缽，因為沾染之故必須經過一夜；缽不會沾染衣物，所以全都當天歸還。

【625-0005】02_戒疏/11c_卷三上之二#83
【原文】【疏】若以二十三戒，共長藥合捨，一時並歸。以其衣食內外資別，並不相染故。
【譯文】【疏文】如果拿這二十三條戒，與長藥合併捨棄，同時各有所歸（長藥給予他人，其餘衣物歸還原主）。因為衣物與飲食在身體內外的資助功能不同，完全不會互相沾染的緣故。

【625-0006】02_戒疏/11c_卷三上之二#84
【原文】【記】三中。上標四長，對明相染經宿不宿，長藥即在所染之中。今此所明，不論經宿。但藥通三捨，二是與他，恐謂相染，隨捨與他，故須辨示。藥須與人，餘自還主，故云「並歸」。「以」下，顯示不染所以。標中合云「二十二戒」，以長藥即在二十三中，摘出為能染故，思之。
【譯文】【記文】第三種情況。上面標舉四種長物，用來對照說明沾染是隔夜或不隔夜，長藥本來就在被沾染之列。現在這裡所要闡明的，並不是論述隔夜與否；只是因為藥物通於三種捨法，有兩種是要給予他人，唯恐有人以為發生沾染而隨著捨給他人，所以必須辨明清楚。長藥必須給予他人，其餘衣物則自然歸還原主，所以說「一同歸還」。從「因為」以下，顯明不沾染的原由。標目中理應說是「二十二條戒」，因為長藥原本就在二十三條戒當中，如今抽出來作為能沾染之物，請深思此處文意。

【原文】【疏】第二，明捨心。
【譯文】【疏文】第二，說明捨棄罪心。

【625-0008】02_戒疏/11c_卷三上之二#86
【原文】【疏】捨墮之中，斷畜為本。懺罪甚易，清心者難。既有明文，正義不得輒隱。廣如《刪補羯磨》及《行事鈔》中。恐不見彼文，故重疏出。
【譯文】【疏文】在捨墮戒法當中，以斷除蓄積之心為根本。懺悔罪業非常容易，想要自心清淨卻很困難。戒經中既然已有明文，正當的義理就不得隨意隱沒。詳細情況如《刪補羯磨》以及《行事鈔》中所記載；唯恐有人未曾見過那些論述，所以重新疏導開闢出來。

【625-0009】02_戒疏/11c_卷三上之二#87
【原文】【記】第二，捨心，生起中。初二句示懺本。次二句明捨心難。無始貪習，非有智對治，無由脫故。「既」下，示須出之意。「疏」字平呼，理也。
【譯文】【記文】第二，捨棄罪心的發起文中。前兩句指出懺悔的根本；後兩句說明捨棄內心貪念的艱難。無始以來的貪愛習氣，如果沒有智慧加以對治，根本無從解脫。從「既然」以下，表明必須寫出的意圖。「疏」字讀平聲，是疏導整理的意思。

【625-0010】02_戒疏/11c_卷三上之二#88
【原文】【疏】就五長戒，本由貪貯，故犯令捨，反彼貪心。不得即日還主，必有他緣，如文所開。如《多論》中「即日得受異財，不染長過，以心斷故」。所以本財不得者，曾經畜過，須以宿隔其心。必若不斷，多宿亦犯。不同過藥，當日得還，制不服用。
【譯文】【疏文】就五種長物戒來說，本來是由於貪求貯存，所以犯戒時令其捨棄，以反制原來的貪心。物不能當天歸還給原主，除非遇到特殊的緣由，正如經文所開許的那樣。好比《薩婆多論》中所說：「當天得以接受其他財物，不受長物過失的沾染，因為蓄積之心已經斷除的緣故。」至於原本的財物之所以不得接受，是因為曾經蓄存有過，必須用過夜的時間來阻隔這份貪心。如果貪心必定不曾斷除，即使過了許多夜也依然算犯戒。這不同於過期的藥物，當天就可以歸還，只是制令不得自行服用。

【625-0011】02_戒疏/11c_卷三上之二#89
【原文】【記】正明中。初敘五長捨意。「他緣」即難集遠行，開展轉還。「如」下，引示捨心。初明得受異財，即下第三句。「所以」下，示不開本財。「不」下，簡長藥。以同貪貯，不隔宿故。
【譯文】【記文】在正式論述中。起初敘述五長戒捨財的意圖。「特殊的緣由」就是遇到集眾困難或長途遠行，開許可以展轉託人歸還。從「好比」以下，引證說明捨心。首先說明可以接受其他財物，這對應於下文的第三句。從「至於原本」以下，說明為何不開許收回原物。從「這不同」以下，簡別長藥；因為雖然同是貪求貯藏，藥物卻不需要隔夜。

【原文】【疏】故《多論》中六句分別。
【譯文】【疏文】所以《薩婆多論》中採用六種句型來加以分別。

【625-0013】02_戒疏/11c_卷三上之二#91
【原文】【疏】初、衣已捨，罪已悔，畜心未斷，更受異衣，為前衣所染。二、衣捨罪悔，求心不斷，乃至一月得所求衣及意外衣，皆染犯捨，心不斷故。
【譯文】【疏文】第一、衣服已經捨棄，罪業已經懺悔，但蓄積之心尚未斷除，如果又接受別的衣服，就會被先前的衣服所沾染。第二、衣服已捨、罪已懺悔，索求之心卻未斷除，乃至在一個月內獲得所求的衣服以及意料之外的衣服，都受沾染而犯捨墮，這是因為貪心未斷的緣故。

【625-0014】02_戒疏/11c_卷三上之二#92
【原文】【記】次引句數中。前二中，有二別：一、畜求心別，二、久近時別。
【譯文】【記文】其次在引述句數中。前兩句有兩種分別：第一是蓄存心與索求心的不同；第二是時間久與暫時的不同。

【625-0015】02_戒疏/11c_卷三上之二#93
【原文】【疏】下有四句，由心斷故不染者，前緣無罪，後心吉羅。三、衣已捨，罪已悔，畜心斷，即日得衣無犯，以心斷故。四、衣已捨，罪已悔，畜心斷，後日更求得衣不犯，中間心捨故。五、地了時，衣捨、罪悔、畜心斷，向暮更求得衣，犯吉羅。六、衣已捨，罪未悔，畜心斷，正使多日得衣，犯吉。
【譯文】【疏文】以下有四句，由於心念已斷所以不受沾染的情況：前一段因緣沒有罪業，後起之心只犯突吉羅。第三、衣服已捨，罪已懺悔，蓄積之心已斷，當天得到衣服不犯戒，因為貪心已斷的緣故。第四、衣服已捨，罪已懺悔，蓄積之心已斷，日後再去求得衣服不犯戒，因為中間的心念已經捨棄的緣故。第五、在天色破曉時，衣服已捨、罪已懺悔、蓄積之心已斷，接近傍晚時又去求得衣服，犯突吉羅罪。第六、衣服已捨，罪業尚未懺悔，蓄積之心已斷，即使隔了許多天得到衣服，也犯突吉羅。

【625-0016】02_戒疏/11c_卷三上之二#94
【原文】【記】後四句中。初總示。「三」下，別列。二與六，並約得衣而悔罪已未別。「四」與「五」並約再求，而後日即日別。引此句數，則知捨心為悔本矣。
【譯文】【記文】在後四句當中。起初總體提示；從「第三」以下，分別陳列。第二句與第六句，都是針對得衣時罪業已懺或未懺的分別；第四句與第五句，都是針對再度求取，而在後日或當日求得的分別。引用這幾種句型，就能明白捨棄罪心乃是懺悔的根本。
