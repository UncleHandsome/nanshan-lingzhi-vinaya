# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【71-0001】02_戒疏/03a_卷一下之一#51
【原文】【記】次餘國中。「五月十六為前夏」，則九月十六為冬初，正月十六為春首，即《善見》中「六月十六為後安居」是也。「覩貨羅」者，《西域記》云「此國地南北千餘里，東西三千餘里，東阨葱嶺，西接波斯，南至雪山，北據鐵門。其國冬末春初，霖雨相繼，加以風土，率多瘟疾。而諸僧徒以十二月十六日入安居，三月十五日自恣」等。《業疏》云「余參傳譯，親問來人」是也。「此」下，會通。
【譯文】【記文】接著談到其他國家的情況。「五月十六日為前安居」，那麼九月十六日就是冬季開端，正月十六日就是春季首日，這就是《善見律毗婆沙》中所說的「六月十六日為後安居」。所謂「覩貨羅國」，《大唐西域記》記載「該國土地南北一千餘里，東西三千餘里，東邊緊鄰蔥嶺，西邊連接波斯，南面直抵雪山，北面依據鐵門關。該國冬末春初之際，連綿大雨接續不斷，加上當地的風土氣候，極常流行各類瘟疫。因此僧眾多在十二月十六日進入安居，三月十五日舉行自恣」等。《業疏》中說「我曾參與經典翻譯，親自向西域來人詢問」即是此意。「這都是」以下是融會融通之語。

【71-0002】02_戒疏/03a_卷一下之一#52
【原文】【疏】半黑白者，隨月晦望也。閒以淨法，隨位說之。《律》文「日日說戒，妨廢道業」，故限晦望，折中之宜也。
【譯文】【疏文】所謂半黑半白，是隨著每個月的晦日（月底）與望日（十五月圓）來劃分。在期間穿插以清淨戒法，隨其所處的時序輪替宣說。《律》中提到「如果天天都說戒，將會妨礙耽誤道業的修持」，所以限定在晦日與望日，這是折衷適宜的制度。

【71-0003】02_戒疏/03a_卷一下之一#53
【原文】【記】釋兩半中。初牒釋。「閒」下，明說意。「《律》」下，示制緣。
【譯文】【記文】在解釋兩個半月中。首先引文解釋。「在期間」以下說明誦戒的用意。「《律》中」以下指出制戒的因緣。

【71-0004】02_戒疏/03a_卷一下之一#54
【原文】【疏】先黑後白者，舉三時三始，必十六日為初也。又云：「十六日已去，白虧黑生；月一日已去，白生黑虧。約相取分，故有斯召。」
【譯文】【疏文】之所以先算黑月後算白月，是列舉一年三時的三個開端，必定都是以十六日為最初一天。又有一種說法：「從十六日開始，月光虧損而黑暗漸生；從初一日開始，光明漸生而黑暗退損。依據天象特徵來區分時段，所以有了這樣的稱呼。」

【71-0005】02_戒疏/03a_卷一下之一#55
【原文】【記】先後中，初正示。文中不顯所表，亦以「白虧黑生」表無常敗壞，使觀厭也。「又」下，示得名所以。
【譯文】【記文】在辨析前後次序中，首先是正式說明。疏文中雖然沒有明言所象徵的法義，但同樣是藉由「白月虧損黑暗滋生」來象徵世間的無常破敗，使人觀照而生厭離之心。「又有一說」以下指出得名的由來。

【71-0012】02_戒疏/03a_卷一下之一#62

【譯文】【疏文】然而這部清淨正戒，本是僧眾全體應當共同聽聞的，理應尊崇恪守，絕不容有任何違逆脫節。因此第二段要求大家「齊聚在一處」，彰顯大眾形體與心意的一致無別。

【譯文】【疏文】身形與心意既然已經和睦，辦理法事就必須詳細審慎，傾聽時如果心不在焉另有所想，就違背了宣說戒律的本意。因此第三段「諦聽善思」，正是明確地給予警惕誡飭，具有開啟明了正解的作用。

【71-0014】02_戒疏/03a_卷一下之一#64

【71-0015】02_戒疏/03a_卷一下之一#65
【原文】【疏】染者既誡，無過當機。自表已淨，世號「伐德」。但止默然，聞成義顯，即名答對，應上問意。是以第五「不犯者」下，省己之順，默表已淨。
【譯文】【疏文】有染犯過失的人既然已經告誡，毫無過咎的人就成為當機之眾。如果自己宣告自己已經清淨，世俗常稱這是「自我誇耀德行」。只要安住於靜默，聽聞成立而法義顯發，這就是一種具體的應對作答，回應了上面的審問之意。因此第五段「不犯者」以下，是省察自己的隨順合戒，以沈默表達自身清淨。

【71-0016】02_戒疏/03a_卷一下之一#66
【原文】【疏】上五通告，止在別緣。三根外彰，眾網須正。必有他舉，理須對實。是以第六「若有他問」下，誡勸時座，犯持之士，深懷二答。
【譯文】【疏文】上面五段是通同告誡，僅止於各自個人的私自行持。但如果身口意三根過犯已經外顯彰露，僧團的綱紀就必須匡正。若是有人出面舉發檢舉，理當依據實情對質答覆。因此第六段「若有他問」以下，誡勉勸導在座大眾中，無論是犯戒還是持戒之人，內心都應深深明白兩種應對答話的道理。

【71-0017】02_戒疏/03a_卷一下之一#67

【譯文】【記文】第六段中所說的「各自個人的私自行持」，就是指自己的身心行持。「兩種應對」在下文解釋為「有犯過者如實發露回答，無過犯者安住沈默作答」。

【71-0018】02_戒疏/03a_卷一下之一#68
【原文】【疏】若內實犯，而外表淨，令僧妄解，罪障尤深。是以第七「如是比丘」下，明隱覆之瑕，不實之損，行穢自纏，特由抱過，勸發露也。
【譯文】【疏文】如果內心確實有犯戒，表面上卻裝作清淨無染，讓僧眾產生錯誤的理解，這樣的罪業障礙最為深重。因此第七段「如是比丘」以下，揭示隱瞞覆藏過失的瑕疵，以及不老實面對的巨大損害，行為汙穢作繭自縛，完全是由於懷抱過失不肯放捨，以此勸勉眾人應當坦誠發露。

【譯文】【疏文】若是順從佛法教導來修持，在義理上具有極深廣的利益。因此第八段「若彼比丘」以下，說明知曉犯戒且懂得依法懺悔，就能重回清淨並使戒行向上生起，戒定慧三學益發光明，必定能成就解脫道業，這是真實不虛的殊勝利益。

【71-0020】02_戒疏/03a_卷一下之一#70
【原文】【記】八中。「上起」即懺悔，名出《了論》，謂翻前犯時居下，故名為「上」；戒法續生，稱之為「起」。「克」，能也。

【71-0021】02_戒疏/03a_卷一下之一#71
【原文】【疏】生起此文，非教本意，講說之家，務傳言相。西梵諸師凡欲敷演，但依文義，廣說所由；至於科約，蓋闕如也。縱有分判，大通無局，如龍樹解《大品》以為二道，天親釋《涅槃》以為七分，須知意也。不可浪事悠悠，費於紙墨，大破正功，無任法利。顧諸學者，可不思哉！今欲消文，就義分之。更有科約，終非大濟，故削略也。
【譯文】【疏文】梳理生起此文的層次，原本並非佛陀立教的根本意圖，而是講經說法的法師為了傳承文義名相所作的施設。印度西方的論師們凡是要講經說法，多半只依循經文義理，廣泛闡述其源由背景；至於科判章節的分割約束，向來大多是缺漏不設的。縱然有所劃分判定，也多是大體貫通而不拘泥細節，例如龍樹菩薩解釋《大品般若經》只統攝為兩道，天親菩薩註解《涅槃經》只區分為七分，我們必須明白這個宗旨。切不可漫無邊際地隨意鋪張，空耗紙墨，嚴重破壞了真實修行的功用，對求取佛法實益毫無幫助。回顧各位參學之人，豈能不深加反思！如今為了消解文句，姑且順著義理加以區分。若再立更多的繁瑣科判，終究對修行沒有實質助益，所以全部予以刪削省減。

【71-0022】02_戒疏/03a_卷一下之一#72
【原文】【記】結略中三，初示意。教本資行，非圖多說，今此敘致，但利講解，故「非本」也。「西梵」下，二、舉中梵例顯，初敘本無。如今藏中大小乘論，止是長途散釋而已。「縱」下，遮妨。其間亦有科判之者，故須此示。「大通」者，謂以義總分；「無局」者，非隨文細碎。「龍樹」下，即《智度論》，釋《大品般若》，彼分二道判盡一經：一、聲聞道，二、菩提薩埵道。「天親」造《涅槃論》，分經為七：一、不思議通達示分，二、成就種性遣執分，三、正法實義分，四、方便修成分，五、離諸放逸入證分，六、慈光善巧住持分，七、顯相分。據彼西梵敷演之式，則知科判本非急要，故云「須知意」也。「不可」下，三、顯略。「浪」，橫也。「費」，損也。「破正功」者，妨自行也。「無法利」者，無益他也。

【71-0027】02_戒疏/03a_卷一下之一#77
【原文】【疏】問：「廣說戒法，其必在僧，如何今告，乃言別也？」
【譯文】【疏文】有人問：「廣泛宣說戒法，必定是要面對全體僧團，為什麼現在的宣告稱呼，卻用了稱呼個別對象的用詞呢？」

【71-0028】02_戒疏/03a_卷一下之一#78
【原文】【疏】答：「戒法通收，何隔僧別。望法是僧，望機是別，法被在人，故須問別，不足怪也。」
【譯文】【疏文】回答說：「戒法全面統攝一切，哪裡有僧團與個別成員的隔閡？從法事的角度來看面對的是整個僧團，從教化對象的個人反省來看面對的是各個成員；因為戒法是加被落在每個人身上，所以必須向個別人員發問，這一點不足為奇。」

【71-0029】02_戒疏/03a_卷一下之一#79
【原文】【記】問中。如羯磨告眾，則云「大德僧聽」；單對一人，則云「大德心念」。今此對僧，反彰別號，故須問釋。答文，初二句通示戒法。以制總十方，法分三位，故曰「通收」。「望」下，正答來問。「望法是僧」者，單白廣說故。「望機別」者，檢問自行故。私釋：若準羯磨，初令同聽，乃是告僧；後責同忍，云「諸長老」，亦是問別。今此說戒，前陳單白，已是告僧，後文勅聽，例皆召別。據斯比擬，義無異也。
【譯文】【記文】提問中。好比羯磨法宣告大眾時，就說「大德僧聽」；若是單獨面對一個人，就說「大德心念」。如今此處明明是對著僧團，反而顯現出個別稱呼，所以需要提問辨析。回答的文字中，前兩句通論說明戒法。因為戒律的制定總攝十方，法制分為心念、對首、眾法三種層次，所以說「全面統攝」。「從」以下正式回答提問。「從法事來看是僧團」，是因為這是透過單白通告而廣泛宣說的緣故。「從教化對象來看是個人」，是因為需要大家檢點審問自己行持的緣故。私下補充解釋：如果比照羯磨法，起初讓大家一同聽聞，那是向全僧團宣告；隨後要求大家默許同意，說「諸位長老」，那也是轉向詢問個人。如今這項說戒儀軌，前面陳述單白表白，已經是對僧團的宣告，後文誡敕大眾傾聽，例行都是呼召個別個人。依據這種體例相互對照，義理上並沒有差別。
