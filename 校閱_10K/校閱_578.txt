# 校閱材料　第578檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【578-0001】02_戒疏/10b_卷三上之一#33
【原文】【記】初科，總分中。「二逆」，即破僧、出血。此入制科，故容謗、說。
【譯文】【記文】第一科，總括劃分中。所謂「二逆」，就是破僧和出佛身血。因為這列入了戒律條文，所以容許有毀謗和宣說罪名的成立。

【578-0002】02_戒疏/10b_卷三上之一#34
【原文】【疏】就初四重，明謗、覆、說。
【譯文】【疏文】就最初的四重罪，說明毀謗、覆藏與宣說的情況。

【578-0003】02_戒疏/10b_卷三上之一#35
【原文】【疏】問：「約謗初、二，輕重罪別；覆、說初、二，同結提者？」
【譯文】【疏文】提問：「就毀謗第一篇（波羅夷）、第二篇（僧殘）而言，結罪有重與輕的區別；為何覆藏、宣說第一篇和第二篇罪，卻同樣都結為波逸提（單提）罪呢？」

【578-0004】02_戒疏/10b_卷三上之一#36
【原文】【疏】答：「謗就治罰為言，隨篇故有輕重。『覆初二』所以同犯者，重屏覆稀，輕露覆數，稀須輕制，數須重制，上下相就，故合一科。又云，初、二護心義一，壞眾不殊，故同一墮。『說初二同提』者，以重稀輕數，同護外信，俗人不練，輕重譏齊，故同一墮。」
【譯文】【疏文】回答：「毀謗是依據懲處治罰的角度來說的，隨著所謗之罪所屬篇聚的不同，所以有輕重的區別。『覆藏初篇與二篇』之所以同等治犯，是因為重罪多在隱蔽處造作，覆藏的次數較少；輕罪多在顯露處造作，覆藏的次數較多。次數少的罪需要從輕制戒，次數多的罪需要從重制戒，上下兩者互相折抵牽就，所以合併為同一罰則。另一種說法是，初篇與二篇覆藏掩護的心理意圖是一樣的，對破壞僧團清淨的損害沒有差別，所以同樣結為墮罪。『宣說初篇與二篇同結單提』，是因為重罪宣說稀少、輕罪宣說頻繁，同是為了維護俗人對外的信心；俗人不明事理細節，無論是重罪還是輕罪一概譏嫌，所以同樣結為墮罪。」

【578-0005】02_戒疏/10b_卷三上之一#37
【原文】【記】明四重中。初問。言「初、二」者，即是夷、殘。謗既兩別，覆說那同？
【譯文】【記文】說明四重罪中。首先發問。所謂「初、二」，就是波羅夷與僧殘。毀謗的罪既分成兩種，覆藏和宣說怎麼會結罪相同呢？

【578-0006】02_戒疏/10b_卷三上之一#38
【原文】【記】答中。初釋謗別，治既重輕，情容深淺，所以不同。「覆」下，次釋覆說。初釋覆罪，二義釋之。初約稀數釋，謂「重」多「屏」造，知少「覆稀」，殘多「露」為，知多「覆數」。「又」下，次約壞眾釋。「護」即覆也。覆過不悔，眾法不成，故云「壞眾」。二、釋說罪，亦二。初云「稀數」，即同上義；次「護外信」，譏無異故。
【譯文】【記文】回答中。首先解釋毀謗的差異，治罪既然有重有輕，心理的情節容有深淺，所以結罪不同。從「覆」往下，其次解釋覆藏與宣說。首先解釋覆藏罪，用兩個義理來解釋。第一是依據發生頻率的稀密來解釋，意思是「重罪」多在「隱蔽處」造作，知情的人少故而「覆藏的次數少」，僧殘罪多在「顯露處」造作，知情的人多故而「覆藏的次數多」。「又」往下，其次依據破壞僧團來解釋。「護」就是覆藏。覆藏過錯不悔，如法的僧事便不能成就，所以說「破壞僧團」。第二、解釋宣說罪，也分為二。首先說「稀少與頻繁」，意思同上；其次說「維護對外信心」，因為俗人的譏嫌並無差別。

【578-0007】02_戒疏/10b_卷三上之一#39
【原文】【疏】問：「謗罪結三階，論覆結二品。毀、惱、諫等戒，約篇則輕重，何故同提邪？」
【譯文】【疏文】提問：「毀謗罪的結罪分為三階（僧殘、波逸提、突吉羅），論及覆藏則分為兩品（波逸提、突吉羅）。而毀呰、疑惱、不受諫等戒，依據所牽涉的篇聚本有輕重之別，為何全都一律結為單提罪呢？」

【578-0008】02_戒疏/10b_卷三上之一#40
【原文】【疏】答：「謗就治罪論，覆從壞眾說，輕重理須分。不同毀、疑等，彼以汎惱故，當時不論犯。如罵『車、木師』，可是對犯也？」
【譯文】【疏文】回答：「毀謗是針對懲處之罪而論，覆藏是從破壞僧團的角度而論，罪過輕重在理趣上必須區分。這不同於毀呰、疑惱等戒，那幾條戒是屬於泛泛惱亂他人的性質，在當下並不論及對方到底犯了何罪。就像罵人是『做車的匠人、做木器的匠人』，難道是針對具體所犯之罪來結犯嗎？」

【578-0009】02_戒疏/10b_卷三上之一#41
【原文】【記】次問中。初敘謗覆差別。謗對六聚有殘、提、吉，故云「三階」，覆對六聚則有提、吉，說麤亦同。次難三戒混同，即毀呰、疑惱、不受諫，此三戒並通六聚，皆共一提。答中。初釋謗覆，如上已明。「不同」下，次辨餘三通是「泛惱」。「如」下，引事別證毀呰。《律》出罵相，云「汝是除糞種，竹師種，車師種」等。造車即「木師」也。
【譯文】【記文】第二個提問中。首先敘述毀謗與覆藏的差別。毀謗對應六聚罪有僧殘、波逸提、突吉羅，所以說「三階」；覆藏對應六聚罪則有波逸提、突吉羅，宣說粗惡罪也是如此。其次詰難三條戒混同歸罪，即毀呰戒、疑惱戒、不受諫戒，這三條戒雖然都通於六聚，卻一概只結一個單提。回答中。首先解釋毀謗與覆藏，如前文已經說明。從「不同」往下，其次辨明其餘三條戒都是「泛泛惱亂」性質。從「如」往下，引用事例特別證明毀呰戒。《律》中列出罵人的相狀，說「你是挑糞種姓、竹工種姓、車匠種姓」等。造車也就是「木師」。

【578-0010】02_戒疏/10b_卷三上之一#42
【原文】【疏】次明二逆、十三難者。
【譯文】【疏文】其次說明涉及二逆罪與十三難事的情況。

【578-0011】02_戒疏/10b_卷三上之一#43
【原文】【疏】謗逆得殘，教輕擯齊故也。若實非比丘，是有難者，內無三根，冥然著實，則無謗罪，容得小罪。不同四重謗人，體雖汙戒，是比丘故。比丘身上有難，與未罷道，謗亦殘也。
【譯文】【疏文】毀謗他人造二逆罪，結犯僧殘，因為教法上判罪雖輕，但擯黜驅逐的治罰等同於重罪的緣故。如果被謗者確實不是比丘，本是有難事之人，毀謗者內心雖無見聞疑三根的依憑，暗中卻巧合切中事實，則毀謗者不構成毀謗僧殘罪，僅容許結犯小罪（突吉羅）。這不同於毀謗犯了四重罪的人，犯四重者其體性雖然染污了戒體，但他原本畢竟是比丘的緣故。如果比丘身上後來出現了難事，只要尚未捨戒罷道，毀謗他同樣犯僧殘罪。

【578-0012】02_戒疏/10b_卷三上之一#44
【原文】【記】次明逆難，明謗中三。初明謗逆。「教輕」，謂犯蘭也。「擯齊」，謂治同也。「若」下，辨謗難，又二。初明謗實犯輕，謂先受不得者，由無三根，故獲吉罪。「不同」下，簡異，對上可知。「比丘」下，次明謗實亦重。即先受後難生者，如黃門、二形之類。
【譯文】【記文】其次說明逆罪與難事，在說明毀謗中有三點。首先說明毀謗逆罪。「教輕」，是指犯逆罪在律中判為偷蘭遮；「擯齊」，是指驅逐治罰與犯重相同。從「若」往下，辨析毀謗難事，又分為二。第一說明毀謗實情犯輕罪，指原本受戒時就不得戒的人，毀謗者雖然沒有見聞疑三根的憑據，但因所謗著實，故毀謗者僅獲突吉羅罪。從「不同」往下，進行簡別，對照前文即可明了。從「比丘」往下，其次說明毀謗實情亦得重罪。就是指原本先受了戒，其後才發生難事的情況，例如黃門（不男）、二形（雙性）之類。

【578-0013】02_戒疏/10b_卷三上之一#45
【原文】【疏】說逆亦墮，如舍利弗事證也。覆罪同之。若十三難實有，無覆、說過；若虗，便無可覆、說也。
【譯文】【疏文】宣說他人造二逆罪同樣犯墮罪，如舍利弗的事蹟可以作證。覆藏二逆罪的結犯也是相同。如果十三難事確實存在，覆藏或宣說都不成罪犯；如果是虛假的難事，便根本沒有事實可供覆藏或宣說。

【578-0014】02_戒疏/10b_卷三上之一#46
【原文】【記】次覆說中。初明逆罪，下引緣證。《律》云：「舍利弗白大眾說提婆所為非佛法僧事。舍利弗心疑，即往白佛：『我當云何在白衣眾中說其惡？』佛言：『僧差故不犯。』」是知不差，說即成犯。「若」下，次明難事。實則非犯，虗則不成。覆、說據實，思之可會。
【譯文】【記文】其次在覆藏與宣說中。首先說明逆罪，下面引用因緣來證明。《律》中記載：「舍利弗向大眾宣說提婆達多所作所為不是佛法僧事。舍利弗心生懷疑，隨即前去向佛稟告：『我怎麼可以在在家人大眾中宣揚他的惡行？』佛陀說：『這是僧團差派你的緣故，所以不犯。』」由此可知如果未經差派，擅自宣說就構成犯罪。從「若」往下，其次說明難事。如果屬實就不犯，如果虛妄就不成立。覆藏與宣說都是依據事實來判斷的，深入思考便能領會。
