== PROBLEM ==
「相解」是指問答雙方「**相互領解**（受戒者與問難戒師彼此心意明了通達）」。古德執著受戒問難只要依文讀誦十三難、受者回答「無」即可得戒，不採取「當面互相領會理解（不取相解）」。譯文望文生義，誤將「相解」當成佛學名相概念的「通解法相」。

== SUGGESTION ==
改為：「這是由於古代律師執著審問遮難不需要雙方互相領會理解，仍舊唯恐受戒者妄自計度讀文等同於羯磨而不可預先讀誦，所以暫且加以排除遮止。」

== ORIG ==
此由古執問難不取相解，猶恐妄計同於羯磨不可預讀，故一往遮之。

== CURRENT ==
從「使」字以下，是要讓問者與受者雙方都明白理解。從「若」字以下，是指示非法之處。這就是舉出邊界與中國僧數不足來作為例證。在「預先教授（預教）」中，首先引用制戒文。從「故」字以下，說明必須理解文意。從「應」字以下，說明應當預先教導。從「此」字以下，是排除疑惑。依論典而言，賊住必須與僧團共同行法方才成立；如果只是預先讀誦羯磨文，理應不構成障難，這是由於古代律師執持審問遮難不需通解法相，仍舊唯恐有人妄自認定讀文等同於羯磨而不可預讀，所以暫且加以排除遮止。下文正式闡明賊住，便引《四分律》，說明必須在一、二、三人乃至眾僧之處，共同作法方才成立。
