# 校閱材料　第076檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【076-0001】01_行事鈔/05a_卷中之一#11
【原文】初中，五篇七聚，約義差分；正結罪科，止樹六法。今依六聚，且釋其名：一波羅夷，二僧伽婆尸沙，三偷蘭遮，四波逸提，五波羅提提舍尼，六突吉羅。此上六名，並無正譯；但用義翻，略知途路。
【譯文】在第一部分中，「五篇」與「七聚」是依循義理的寬狹而有所差異區分；而真正判定罪科的名目，只樹立了六種法。現在依照「六聚」的形式，暫且解釋它們的名稱：第一是波羅夷，第二是僧伽婆尸沙，第三是偷蘭遮，第四是波逸提，第五是波羅提提舍尼，第六是突吉羅。以上這六種名稱，並沒有完全字字相扣的直接正譯；只是採用意義來翻譯，讓人大致知曉其旨趣門徑。

【076-0002】01_行事鈔/05a_卷中之一#12
【原文】初言波羅夷者。《僧祇》義當極惡。三意釋之：一者退沒，由犯此戒，道果無分故。二者不共住，非失道而已，更不入二種僧數。三者墮落，捨此身已，墮在阿鼻地獄故。《十誦》云：墮不如意處。《薩婆多》解云：由與魔鬪，以犯此戒，便墮負處。《四分》云：波羅夷者，譬如斷人頭，不可復起；若犯此法，不復成比丘故；此從行法非用為名。又云：波羅夷者，無餘也；此從眾法絕分為名；故偈云：「諸作惡行者，猶如彼死尸，眾所不容受，以此當持戒。」又名不共住者，不得於說戒、羯磨二種僧中共住故。
【譯文】首先說「波羅夷」：《摩訶僧祇律》認為其義當作「極惡」。可以用三種意義來解釋它：第一是「退沒」，因為犯了此戒，對聖道聖果便再無緣分的緣故。第二是「不共住」，不僅僅是失去道果而已，更是從此不再計入說戒僧與羯磨僧這二種僧眾之數。第三是「墮落」，捨棄此生肉身之後，墮入阿鼻地獄的緣故。《十誦律》說：墮落於不如意之處。《薩婆多部（說一切有部）》解釋說：由於與煩惱魔戰鬥，因為毀犯了此戒，便墮於失敗輸落的境地。《四分律》說：波羅夷，好比砍斷了人的頭顱，不可復生；如果犯了此法，就不再成就比丘身分的緣故；這是從所行之法不堪再任僧用而立名的。又說：波羅夷即是「無餘（不可救濟殘存者）」；這是從被僧團僧事徹底斷絕資格而立名的；所以偈頌說：「諸作惡行者，猶如彼死尸，眾所不容受，以此當持戒。」又稱作「不共住」，是因為不能再在說戒、羯磨（僧團會議僧事）這兩種僧團中共住共事的緣故。

【076-0003】01_行事鈔/05a_卷中之一#13
【原文】問：上言若犯此法，名為斷頭；準此而言，必無重犯，戒亦非有。答：戒之有無，此入諍論。《雜心》中解：有戒，非無。若論重犯，律自明斷；隨犯多少，一一波羅夷。此篇最初四戒各別，隨重犯淫，眾多重犯；餘盜殺妄，重犯亦爾。此說別脫戒，由境緣別，得戒不同；故後犯時，還隨別犯。如《薩婆多》云：寧可一時發一切戒，不可一時犯一切戒。且如淫戒，女人身上發得二十一戒，男子身上得十四戒，餘法界中男女亦爾。今或貪心，犯一女一道，但名污一淫戒；比丘自餘諸淫，戒體光潔，無行可違，稱本受體。如懺初篇，還得清淨；不言更受，由有本戒。又如律云：打謗犯重比丘，皆結墮罪；若無戒者，止同吉羅。問：應當足數，不名斷頭？答：懺本清淨，理當足數，如得作說戒、自恣羯磨等；但由情過深厚，不任僧用，故云來不隨意。斷頭之諭，此望不階聖果為言。問：淫戒雖被污染，但名犯戒，出在何文？答：上已明示。更廣張相，如下〈懺法〉中說；戒體定在，常恒清淨。世中有人犯一淫戒，初乃惶懾，後復思審，謂言失戒，遂即雷同隨過皆犯；豈不由愚於教網，自陷流俗。焉知但犯一淫，諸淫並皆不犯；當篇殺盜，常淨儼然；下之五聚，義同初受。故同法之儔，理須明察。若先嚴淨識，託對五塵，欲染不生，由前方便。若元非攝慮，對境不能不犯。既犯業成，必須無覆，早懺還成本淨，進入僧儔。若迷上所設，自懷藏疾，不參眾務，財法並亡，便冐受用，自他俱負，豈不悲乎！不亦誤哉！問：淫已被染，諸戒猶全，何故不階聖位？答：《明了論》解：此四重戒，隨毀一重，諸餘戒分，用則無力；如人身中，四處得死，隨損一處，身命便死。由戒力弱，不發定慧也。《十輪》云：若犯四重，毀法謗聖，死入阿鼻；如是之人，於其一身，不能盡結，必墮惡道。若有於我法中出家，持根本戒，常勤勇猛，一切供養，終不虛受。何以故？志求解脫，乃至捨命，終不犯毀。何以故？以四根本，三乘依住故。
【譯文】問：上面說如果犯了此法，名為「斷頭」；照此看來，必定不會有重複犯戒的情形，戒體也應該蕩然無存了。答：戒體究竟是有還是無，此在各部論典中屬於爭論的焦點。《雜阿毘曇心論》中解釋：依然保有戒體，並非全無。如果論及重複犯戒，律本中自有明確的判定；隨其所犯次數的多寡，每一次都結成一個波羅夷罪。這一篇最初的四條重戒各各不同，隨著再度犯淫，便構成多次重複犯戒；其餘的盜戒、殺戒、大妄語戒，重複犯也是如此。這是就「別解脫戒」而言，因為所對的境緣各有分別，當初發心納受的戒體也隨境各別；所以在後來毀犯時，依然隨個別的境緣而分別結犯。如同《薩婆多論》所說：寧可在一時之中發起一切戒體，不可在一時之中毀犯一切戒體。姑且以淫戒為例，在一個女人身上所發得的戒就有二十一條，在一個男子身上發得十四條戒，法界中其餘的男女也是如此。現在若因貪心，對一個女人的其中一道行淫，只名為染污了其中一條淫戒；此比丘其餘的一切淫戒，戒體依舊光亮皎潔，沒有實際違逆的行為，依然契合原本所領受的戒體。如同懺悔初篇重罪之後，還能重獲清淨；並不要求他重新受戒，便是因為原本的戒體猶在。又如律中說：毆打、毀謗犯了重罪的比丘，都要結波逸提（單墮罪）；如果他完全沒有戒體，毆謗者至多只等同於犯突吉羅（輕罪）。問：既然戒體猶在，就應該能充當僧數，不該名為斷頭？答：懺除本罪而獲清淨，在理法上本當算入僧數，例如能夠參與說戒、自恣等羯磨法事；只是因為情執過咎深重，不堪再受僧團重用，所以律中說他前來僧中不得隨其自意（須依僧召喚，不得擅往）。「斷頭」的比喻，這是針對此生不能證入聖果而言的。問：淫戒雖被染污，但只算犯了一戒（其餘戒體仍在），這出自哪部經文？答：上面已經明確開示。若要更廣泛彰顯其相狀，如後文〈懺法〉中所說；戒體確實存在，自性常恆清淨。世上有人犯了一條淫戒，起初驚恐恐懼，後來反覆思量，自以為已經喪失戒體，便破罐子破摔、隨逐各種過非一概違犯；這難道不是由於愚昧於如來教網，使自己陷於流俗嗎？哪裡知道僅僅犯了一條淫戒，其餘未犯的淫戒並未違犯；當篇中的殺戒、盜戒，依舊恆常清淨如初；底下的其餘五聚戒，其戒體本質依然如同初受時一般。因此同修道侶，理應審察明瞭。若能預先莊嚴清淨心識，託對五塵境界時，貪染便不會生起，這是由於事前防護的功勞。如果原本就不曾收攝思慮，面對境界時便不可能不犯。既然犯戒罪業已成，就必須毫無覆藏，及早發露懺悔使其恢復原本的清淨，重新進入清淨僧眾之列。若是迷失於上述佛制軌範，私自心懷過失加以隱匿，不敢參與僧團事務，導致財利與法益兩皆喪失，卻又冒名受用信施，使自己與施主雙雙虧負，這豈不是太可悲、太荒謬了嗎！問：淫戒已被染污，其餘諸戒既然完好，為何不能證入聖位？答：《律二十二明了論》解釋說：這四條根本重戒，只要毀犯了其中一條，其餘各戒的戒力在起用時便衰弱無力；就如同人體之中，有四處要害受創足以致命，隨便損壞其中一處，身命便告死亡。由於戒力轉弱，便不能發起真正的禪定與智慧。《地藏十輪經》說：若犯了四重禁戒，毀壞正法、毀謗聖賢，死後墮入阿鼻地獄；這樣的人，在此生一身之中，不可能斷盡煩惱結縛，必定墮落惡道。若有人在我的正法中出家，受持根本禁戒，常能精勤勇猛，受用一切信施供養，終究不會虛耗承受。為什麼呢？因為立志追求生死解脫，乃至寧捨身命，終究不肯毀犯禁戒。為什麼呢？因為四根本戒乃是三乘聖人所依止安住的根本基石。

【076-0004】01_行事鈔/05a_卷中之一#14
【原文】《四分》中：尼有八波羅夷，前四同於大僧，後四如〈別〉所說。
【譯文】在《四分律》中，比丘尼有八條波羅夷戒，前四條與大僧（比丘）相同，後四條則如後文〈尼戒別相〉中所說。
