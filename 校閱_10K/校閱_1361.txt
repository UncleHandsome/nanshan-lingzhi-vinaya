# 校閱材料　第1361檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1361-0001】資持記/16a_下四#28
【原文】經云者，此出《莊嚴論》，彼云：昔有國王名難陀，貪聚金寶，乃以女置高樓；若求合者，令其納寶，乃集一國珍寶皆盡；時有一人貧匱，求合無由，因而成疾，其母知之，語云：汝父死後，口中有一金錢，可發塚取之送王；
【譯文】所謂「經中說道」，這段典故出自《大莊嚴論》，該論記載：從前有一位名叫難陀的國王，貪婪聚斂金銀珠寶，甚至將親生女兒安置在高樓上；凡是前來求歡交合的人，都命令他們必須奉納珍寶，就這樣搜刮殆盡了全國所有的奇珍異寶；當時有一個極度貧困的青年，苦於無法籌措寶物求歡，憂思之下染上了重病，他的母親知道後告訴他說：『你父親死後，口中含有一枚金錢，你可以去掘開墳墓將它取出來送給國王；』

【1361-0002】資持記/16a_下四#29
【原文】王怪問曰：何處更有寶，彼具述之，王由此悟曰：死後一錢，尚不能為主，何苦欲之，遂却散施。上勸捨慳。亦下，次勸依法。顏面，謂取面情，以物餉遺也。如是下，結示。恐心輕動，故不可違；恐念世事，故不可順。以下，出須諫所以。臨終念善，生善道則昇；念惡，墮惡道故沈；
【譯文】國王感到奇怪而質問道：『國中哪裡還能找到金寶？』那青年便如實陳述了原委，國王因此大徹大悟感歎道：『人死之後連口中的一枚銅錢，尚且都不能自己作主保留，我何苦這樣貪得無厭呢！』於是退還並廣泛散發布施所有的寶物。以上是勸導病患捨離慳貪之心。從「也」字以下，接著勸勉一切應當依循正法行事。所謂「顧全顏面」，是指貪戀世俗人情，而拿私物去厚贈遺贈他人。從「像這樣」以下，總結開示其重要性。唯恐病人的心意輕易動搖浮躁，所以不可隨意違背他的正念；唯恐他轉而憶念世間俗事，所以絕不可順從他的非分妄求。從「以」字以下，說明必須竭力規勸諫止的原由。臨終時如果生起善念，投生善道就能超昇；如果生起惡念，墮入惡道便會沉淪；

【1361-0003】資持記/16a_下四#30
【原文】昇沈止在剎那，故是一期大要。期，時也。三中，初示經像。引《華嚴》為證。經文兩偈，傳寫訛脫；此出〈賢首菩薩品〉，初偈云：又放光明名見佛，彼光覺悟命終者；念佛三昧必見佛，命終之後生佛前。次偈脫初句，彼云：見彼命終勸念佛，方接鈔中三句；
【譯文】生命的超昇或沉淪僅僅取決於那一剎那之間，因此這是關乎此生一期生死最重大的樞紐關頭。所謂「期」，便是指這決定去向的關鍵時刻。第三段中，首先明示應當安置佛經與尊像。引述《華嚴經》作為證成。律抄中引述的兩首偈頌，歷來傳寫出現了訛誤脫漏；這段偈頌出自〈賢首菩薩品〉，第一首偈頌說道：「如來又放出光明名叫『見佛』，這道光明能使將命終的人覺悟；藉由念佛三昧必定得見諸佛，命終之後投生在諸佛面前。」第二首偈頌脫漏了開頭第一句，原文說道：「看見有人命終時勸他念佛」，之後才接上本鈔中的下三句；

【1361-0004】資持記/16a_下四#31
【原文】若新譯本云：又放光明名見佛，此光覺悟將終者；令隨憶念見如來，命終得生其淨國。〔此偈贊佛果一光明功德。〕見有臨終勸念佛，及示尊像令瞻敬；俾於佛所深歸仰，是故得成此光明。〔此偈讚佛因中修此光明之行。〕四中，初請他勸。《善見》明看病自勸，《母論》明互違結犯。依前斟酌，指上次科。
【譯文】若是依照新翻譯的八十華嚴譯本，則寫作：「佛又放光明名為『見佛』，此光能覺悟即將命終之人；令其隨順憶念得見如來，命終得以投生彼佛淨國。」（這首偈頌是讚歎佛陀果地上一種光明的不可思議功德。）「看見有人臨終勸勉稱念佛名，並且出示佛陀尊像令其瞻仰恭敬；使其對佛陀生起至深之歸向仰賴，因此修因得以圓滿成就這道光明。」（這首偈頌則是讚歎佛陀在因地修行時圓滿此一光明的行持。）第四段中，首先是請託他人代為勸導。《善見律》闡明負責照看病患的人應親自勸勉，《毘尼母論》則闡明如果看病者與病人互相違逆彼此的責任便結獲罪愆。所謂依照前面的原則審慎斟酌，是指上面那一段科判所立下的標準。

【1361-0005】資持記/16a_下四#32
【原文】若下，明將死打磬，令聞生善。天台智者，臨終語維那曰：人命將終，得聞鍾磬，增其正念；唯長唯久，氣盡為期；云何身冷，方聲磬耶？〔今時死已方打，故知無益。〕第二送終，敘意中，初示道俗異儀。厚葬，謂多費財也。若下，次明奢儉取中。將屍出中，初科，前明安屍處。
【譯文】從「若」字以下，說明在病人瀕死氣絕之際敲擊磬聲，使他聽聞正音而生起純善正念。天台智者大師在臨終時曾對維那師說道：「人命即將終結之時，若能聽聞鐘磬清明之聲，便能增長他的清淨正念；這鐘磬之聲應當悠遠持久，以病患氣絕身亡作為終止的時限；為何如今的大眾都在病人身體冰冷之後，才開始敲擊磬聲呢？」（現在的人往往等死後才擊磬，由此可知對於亡者的往生是毫無益處的。）第二部分「送終」的敘述緣由中，首先揭示出家僧道與世俗凡情在喪儀上的迥異。所謂「厚葬」，是指耗費過多資財求取體面。從「若」字以下，接著說明在奢華與儉約之間應當取其中道。在「抬出屍體」的第一科中，前面先說明安置屍首的處所。

【1361-0006】資持記/16a_下四#33
【原文】絹棺比地所尚，此間多用木棺，或加絹蓋。次明師徒坐處。吊慰，吊即訓至，謂至喪所而慰問也。布草者，此間有用薦席，或用床橙。次科，初引文示制。律中，以尼女情懦，多好哀泣；僧則反之，故罪分輕重。若下，次準義明開，初引涅槃為例。即《遺教》云：若所作未辦者，見佛滅度，當有悲感。
【譯文】以絹覆棺是彼方西域所崇尚的習俗，此方漢地多數使用木質棺木，或者額外覆蓋一層絹帛。其次說明亡者的師尊與弟子（喪主）守靈受弔的席位處所。所謂「弔慰」，「弔」字訓解為「至」，意思是指親自來到喪葬之處進行慰問。所謂「鋪設稻草」，在漢地有的是使用草蓆薦席，有的則是使用床榻或長凳。下一科中，首先引述律文昭示戒律規制。在戒律中，由於比丘尼等女眾性情柔懦，多數容易哀傷痛哭；比丘僧眾則理應持重沉靜，所以嚎哭之罪依照情節分判輕重。從「若」字以下，接著依照義理說明特別開許的情況，首先引佛陀涅槃（雙林入滅）之事為例。這正如《佛遺教經》所說：「如果是道業未成、所作未辦的人，見到佛陀滅度入涅槃，心中難免會生起深切的悲傷感懷。」

【1361-0007】資持記/16a_下四#34
【原文】據位，則內凡已還，故云未離欲者。若下，次明不泣反非。高節之人，不妄哀喜，故云不局世情。任情之者，不展哀苦，即非孝誠，故云道俗同恥。三中，初小者吊大，又二：一近處至者，容緩吊慰。二遠來奔赴，未暇慰問。次明大者吊小。依本儀者，謂不設禮。隨時坐立，謂任彼意。
【譯文】若論證悟的階位，這屬於內凡位以下的凡夫境界，所以才說「未曾離欲的人」。從「若」字以下，接著說明不知哀悼反而不合義理。具備清高志節的出塵之人，不會妄自大悲大喜，所以才說「不局限於世俗凡情」。至於放任凡俗情欲的人，若連哀戚之痛都不願表達，那便是不具孝道誠信，所以才說「僧俗大眾都會引以為恥」。第三段中，首先說明年輕後輩弔唁尊長前輩的情形，其中又分為兩種：一是從鄰近處前來的人，可以寬緩行禮弔慰。二是從遠地急奔趕來的人，因哀傷悲慟一時還無暇正式慰問。其次說明尊長前輩弔唁年輕後輩的情況。所謂「依照原本的儀軌」，是指不必過度陳設繁文縟禮。所謂「隨時決定或坐或立」，是指完全任隨大德上座自己的意思便可。

【1361-0008】資持記/16a_下四#35
【原文】四中，《五分》。覆根，準應裸露。《五百問》，初明覆屍。須白僧者，是僧物故。裙及祇支，今須準用。〔世云：須披五條者非，以制物令賞看病故。〕不得下，次明殯送。由並屬僧，過五成盜。文明所出次第有三：一出親屬，即師僧等；
【譯文】第四段中，《五分律》提到應遮蔽下體器官，比照原則此處應指亡者身體裸露的狀態。《五百問》首先說明覆蓋屍體的規範。之所以必須向僧團白眾說明，是因為所用的布物是僧團常住所有的緣故。至於下裙與僧祇支，現今都必須依照律例準則來使用。（世間傳說：亡者必須披搭五條袈裟，這種說法是錯誤的；因為戒律規定亡者的衣物應當保留下來，用以賞賜犒勞負責照看病患的人。）從「不得」以下，接著說明出殯送葬的規矩。由於亡者的資財全部歸屬於僧團，如果擅自取用超過五錢便構成偷盜重罪。律文中所列出操辦喪葬費用的來源，順序共有三種：第一是由死者的親屬出資，也就是他的師父、徒弟等同門；
