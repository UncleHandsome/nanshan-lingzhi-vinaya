# 校閱材料　第345檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【345-0001】02_戒疏/02b_卷一上之二#90
【原文】【疏】又寶有二能：一、現除貧苦者，顯戒現止業非，能感名利，交免三塗之貧苦也；二、資成形命者，顯戒近獲人天，遠成五分。斯益既厚，故「求無厭」。
【譯文】【疏文】再者，珍寶具有兩種功能：第一、現世能消除貧窮苦難，這比喻戒律在現世能止息惡業過非，感得福報美名，並徹底免除墮入地獄、餓鬼、畜生三途的貧乏痛苦；第二、能夠滋養成就身形與壽命，這比喻戒律近處能感得人道天道的善果，遠處能圓滿戒、定、慧、解脫、解脫知見這五分法身。這項利益既然如此深厚，所以令人「求無厭足」。

【345-0002】02_戒疏/02b_卷一上之二#91
【原文】【記】三中，二義。初句標喻，「顯」下，法合。初除現生貧苦，止惡積善故「不貧」，人天聖道故「無苦」。「交」，俱也。次義中，標喻法合，亦如上分。凡聖兩報，由戒資成，世出世別，故分「近遠」。「斯」下，雙結。
【譯文】【記文】在第三個層次中，包含兩種含義。首句標出譬喻，「顯」字以下，以法來會合譬喻。第一種功能是拔除現世的貧窮困苦，止惡積善所以「不貧」，獲得人天尊榮乃至解脫聖道所以「無苦」。「交」，就是都、俱備的意思。在第二種含義中，標出譬喻並以法會合，劃分方法也如同上面所述。凡夫的善報與聖人的道果，全都依賴戒律來資養成就，世間與出世間既然有別，所以劃分為「近果與遠果」。「斯」字以下，對這兩種功用進行雙重總結。

【345-0003】02_戒疏/02b_卷一上之二#92
【原文】【疏】問：「如經論說，海喻多種，今此偈中止列二者？」
【譯文】【疏文】提問：「正如經論中所說的，大海的譬喻有多種，如今這首偈頌中為何僅僅列出這兩種？」

【345-0004】02_戒疏/02b_卷一上之二#93
【原文】【記】問中。「多種」者，海有八德：一、漸深漸入；二、潮不過限；三、不宿死屍；四、百川來會，無復本名；五、萬派悉歸，而無增減；六、出眾珍寶；七、大身眾生所居；八、同一醎味。《戒本》上句可配初德，次句對第六，旁兼「清澄」，即是第三。欲顯戒文出二之意，故問申之。
【譯文】【記文】在提問的設問中。「多種」的意思，是指大海具備八種功德德行：第一、海水漸次深邃；第二、潮水漲落不逾越界限；第三、海中不住留死屍；第四、百川百河匯聚而來，不再保留原本的名字；第五、萬條江河悉數歸入，海水卻不增不減；第六、孕育出眾多奇珍異寶；第七、極大體型的巨海眾生所棲居；第八、海水皆具備同一種鹹味。《戒本》偈頌的第一句可以配屬第一種德行，第二句對應第六種德行，旁側兼具的「清澄」含義，就是第三種德行。為了顯發《戒本》偈文單單列出這兩項的深意，所以設立問答來加以申述。

【345-0005】02_戒疏/02b_卷一上之二#94
【原文】【疏】答：「作者知時，明喻舉要。初明深廣清澄喻，顯說戒儀專被行淨，如有纖過，非聽說之儀也。是以今初開宗，即明簡眾喻。眾成由行，能懷聖寶，故次辨求無厭喻。此二攝化始終，餘非要務，故略不敘。」
【譯文】【疏文】回答：「造作者通達時機，明智的譬喻當擷取精要。首先闡明深廣澄清的譬喻，是為了顯明宣說戒律的儀軌，專門是為了加被身心行持清淨的僧眾，如果有絲毫的過失，就不得參與聽說戒律的儀軌。因此如今開宗明義，一開始就以大海譬喻來簡別淘汰僧眾。僧團的成就仰賴於戒行的清淨，能懷抱如上的聖道珍寶，所以緊接著辨明如求寶無厭的譬喻。這兩種譬喻已經將化導攝受的始終完全包攬，其餘的並非當務之急，所以省略而不贅述。」

【345-0006】02_戒疏/02b_卷一上之二#95
【原文】【記】答中。初歎美部主。「初」下，次正申所以。前明「無涯」喻，「深廣」、「清澄」，兼含兩義。「眾成」下，次示「求寶」喻。「此二」下，正通來問。前喻眾行，後喻自行；說戒攝僧，要唯此二故也。
【譯文】【記文】在回答的文句中。首先讚歎部派教主之宏才。「初」字以下，接著正面申明其緣由。前面闡述「無涯」的譬喻，「深廣」與「清澄」兼含了這兩層含義。「眾成」以下，接著開示「求寶」的譬喻。「此二」以下，正面解答來問。前面的譬喻對應大眾的集體行持，後面的譬喻對應自身的個別修行；說戒法事用以攝持僧團，其要點僅僅在於這兩方面而已。

【345-0007】02_戒疏/02b_卷一上之二#96
【原文】【疏】就法說中。初舉喻益，勸護聖財；後明體不虗圓，必假說聽之力。方便攝持，名之為「欲」；對治行成，非緣不起，名之為「護」。戒德內充，資神養聖，目之為「財」。「財」即道品，恐濫於世，故云「聖法」。合上「寶」也。
【譯文】【疏文】在以法義直說的文句中。首先舉出譬喻所帶來的利益，勸勉眾人應當護持這殊勝的法財；其後闡明戒體不會憑空圓滿，必須假借宣說與聆聽的力量。以方便善巧攝持戒心，稱之為「欲（願求）」；對治煩惱的行持得以成就、非適宜之緣境不起現行，稱之為「護」。戒律的功德充滿內在，資養心神並長養聖道，稱之為「財」。「財」就是指三十七道品，因恐懼與世間財物相混淆，所以稱為「聖法」。這正對應了上面的「珍寶」譬喻。

【345-0008】02_戒疏/02b_卷一上之二#97
【原文】【記】次法說，勸護中，初文。「欲」、「護」二字，即是能持始終二心。「神」即心神，「聖」謂聖道。
【譯文】【記文】接著以法說勸勉護持的文句中，這是第一段。「欲」與「護」這兩個字，就是指能夠持戒的發端與持續（始心與終心）這兩種心。「神」就是指心神，「聖」就是指聖道。

【345-0009】02_戒疏/02b_卷一上之二#98
【原文】【疏】所以不合初喻者，前顯戒體，量周無際；後顯多寶，充足所求。求在無限，終從戒海，故所出之寶無窮，則知能生之海無際。是則聖財通於三道，欲護聽眾，亦被三乘。若作此解，具兼兩喻。
【譯文】【疏文】之所以不單獨去會合最初的大海譬喻，是因為前面已經顯發了戒體的廣大、周遍無際；後面則顯發了戒寶的多樣，能充分滿足一切祈求。既然求索無限，終究是源於這座戒海，所以由它出產的珍寶無窮無盡，由此便可知曉那能孕育珍寶的大海是多麼浩瀚無際。這就說明聖道法財通貫諦、緣、度三道，想要護持法財的聽戒大眾，同樣也涵蓋了三乘行者。如果做這樣的理解，就能完全兼顧這兩種譬喻了。

【345-0010】02_戒疏/02b_卷一上之二#99
【原文】【記】次科。初徵起。「前」下，正示。意以「所出」之多，足顯「能生」之廣，故但合「寶」，即兼「海」矣。「是」下，點前聖財不專戒學，方顯出生無窮之義。「三道」約法，諦、緣、度也。「三乘」約人，可知。「若」下，結示文旨。
【譯文】【記文】接著下一科。首先發起探討。「前」字以下，正式予以開示。用意是認為由「所出產」之珍寶眾多，足以彰顯「能孕育」之大海何等遼闊，所以只要會合了「珍寶」，便自然兼攝了「大海」。「是」字以下，點明前面的聖法資財並不專屬於戒學一門，如此才能顯發出生無窮無盡的含義。「三道」是就教法而言，指四諦、十二因緣、六度。「三乘」是就修行人而言，顯而易見。「若」字以下，總結指示出經文的主旨。

【345-0011】02_戒疏/02b_卷一上之二#100
【原文】【疏】說戒明約，非別所弘；既同奉行，義無不集。故云「眾集聽我說」也。
【譯文】【疏文】說戒具有明晰的約定制規，絕非單獨一人所能私自弘傳；既然同處僧團共同奉行，義理上就沒有不前來聚集的道理。所以說「大眾雲集聽我宣說」。

【345-0012】02_戒疏/02b_卷一上之二#101
【原文】【記】說聽中。別人對、念，無人曲開；文從本制，故云「非別」等。「約」，即制也。
【譯文】【記文】在說戒聽戒的文句中。個別人的對首說戒或心念說戒，是在沒有大眾僧時的委曲開許；此處經文則是順從戒律的根本制規，所以說「非別」等等。「約」，就是指制規約束。

【345-0014】02_戒疏/02b_卷一上之二#103
【原文】【記】次釋三偈，初科。上二句結前。「無際」、「無厭」，即指二喻。
【譯文】【記文】接著解釋後面的三首偈頌，這是第一科。上面兩句總結前文。「無際」與「無厭」，就是指前面的兩種譬喻。
