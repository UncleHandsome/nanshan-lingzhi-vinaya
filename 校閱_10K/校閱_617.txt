# 校閱材料　第617檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【617-0003】02_戒疏/11b_卷三上之二#99
【原文】【疏】八、「有信優婆私」下，明所舉人也。注解中舉「三歸五戒」者，成上優婆私也。「善憶持」下，成有信也。「優婆私」、「尼」、「夷」等，名雖少異，傳梵訛僻。如唐正翻「鄔波私迦」，此云「清信女」也。《多》云：「此人終不為自身、財命乃至父母而作妄語，以深樂佛法故。」
【譯文】【疏文】第八、從「有深具信心的優婆夷」以下，說明具備舉發資格的證人。小註之中舉出她必須「受持三歸五戒」，這是為了成就具格優婆夷的身分；「能善於憶念堅持」以下，是為了成就其「深具信德」的品格。「優婆私」、「優婆尼」、「優婆夷」等稱呼，名稱雖然稍有差異，那是歷代梵語傳譯音韻上的訛誤。正如唐代玄奘大師正確認定的梵語翻譯應為「鄔波斯迦」，此處翻譯為「清信女」。《薩婆多論》說：「這樣的人深心愛樂喜悅佛法的緣故，絕不會為了自己的身家、財富、性命、乃致為了父母眷屬而蓄意說出妄語。」

【617-0004】02_戒疏/11b_卷三上之二#100
【原文】【疏】「是坐比丘自言」下，第九句，明自言相也。
【譯文】【疏文】第九句「這名坐著的比丘自己承認」以下，說明比丘親自承認陳白罪過的情況。

【617-0005】02_戒疏/11b_卷三上之二#101

【617-0006】02_戒疏/11b_卷三上之二#102
【原文】【記】戒本。次句，指「九十」者，即屏坐戒，彼云「申手不及戶坐，便犯」。三中，注文止簡小、騃、已死，而不明親非親等，故引《僧祇》決之。文中「大」字誤，古本作「女」。四中，《僧祇》所列，雖有此等，亦名為「獨」。五中。初別釋屏處。注云「三種」，寫誤。初釋見屏，「緣來」，即塵霧等。次釋聞屏，「目見不聞」，明其遠也。《見論》所列，並非第三人，「無眼」即見屏，「聾」即聞屏，「睡」即兼二。雖有「多女」，還同屏處。準知，第三必約有智男子矣。「覆」下，通簡三相。八中。初點文。二、釋注。初牒釋；次「優婆私」下，翻名。「私、尼、夷」者，並謂下一字，有三不同。「多」下，引示「有信」。凡作妄語，多因四緣：一、身，二、財，三、命，四、親友等。九、十，二句，即二種毗尼。用此二法，即兼現前也。
【譯文】【記文】戒經本文中。第二句指引至「九十單提」之處，就是指那條屏處同坐戒，彼處規定「在伸手搆不到門扉之處而坐，便構成犯戒」。在第三點中，小註原本只排除了年幼痴呆、或已死之人，卻沒有闡明親屬或非親眷的差別，所以引用《僧祇律》來作決斷。文中的「大」字是筆誤，古代刻本寫作「女」字。在第四點中，《僧祇律》所列出的這些人，縱然在場，律法上也依然判定為「獨自一人」。在第五點中，首先分別解釋隱蔽之處。注文中說「三種」，也是抄寫的錯誤。先解釋視覺屏障，「因緣而至」指的就是塵沙濃霧遮蔽。接著解釋聽覺屏障，「眼見卻聽不見」，指距離相隔甚遠。《善見論》所列舉的這些人，都不能算作有效的第三者：「眼盲」就是視覺屏障，「耳聾」就是聽覺屏障，「熟睡」則兩者兼具。身邊即便圍繞著「多名女子」，在律法上也依然等同於在隱蔽之處。由此可知，有效的第三人，必然必須是具有辨析判斷能力的成年男子。「遮覆」以下，通達簡要地總結三種情境。在第八點中，首先點出經文。二是解釋小註。先標註解釋；接著從「優婆私」以下，考證其梵音譯名。「私、尼、夷」三種稱呼，都是指最後一個字在音譯上的三種歧異。「薩婆多論」以下，引用說明何謂「具信」。世人蓄意說妄語，大多不出四種原因：一是為自身私利，二是為爭奪財富，三是為保全性命，四是為親友庇護。第九、第十這兩句，就代表了兩種滅諍法。運用這兩種方法，同時也就兼顧了現前毘尼的成立。

【617-0007】02_戒疏/11b_卷三上之二#103
【原文】【註】是中自言所趣向處、所到處，若坐若臥若作。若不自言，並如憂婆私所說治也。
【譯文】【註文】在此程序中，比丘自己承認去往的處所、抵達的處所，若有坐下、或有躺臥、或有實施作為。如果他不承認，則一概依照優婆夷所指證的內容予以處罰。

【617-0008】02_戒疏/11b_卷三上之二#104
【原文】【疏】就注解中。言「所趣向處」者，謂向彼女家道行也；「所到處」者，至女家也；「若坐若臥」，犯殘、提也；「若作」者，犯夷罪也。交互明罪，有無不定。罪犯隨篇，疑須舉處。故言「並如可信語治」。
【譯文】【疏文】就小註的文義而言。所謂「去往的處所」，是指走向那名女子家宅的道路之中；「抵達的處所」，是指已經到了女子的房舍之內；「若是坐下或是躺臥」，這便構成犯下僧殘或波逸提罪；「若有實施作為」，這就是觸犯了根本的波羅夷罪。這些行為交錯互見以顯明所涉罪嫌，是否存在尚未確定。所犯罪名隨其所屬篇聚懲治；若屬嫌疑，則須依所舉之疑處（結當篇吉羅罪）。所以說「一概依照可信賴之人的言詞予以懲治」。

【617-0009】02_戒疏/11b_卷三上之二#105
【原文】【記】辨注中。初釋自言相。「坐臥殘提」，由兼觸、語故。「交」下，釋治罪。「罪犯隨篇」，謂夷、殘等。「疑須舉處」，即當篇吉罪。
【譯文】【記文】辨明小註的段落中。首先解釋自承犯戒的情節。「坐臥引致僧殘與波逸提」，是因為同時夾帶了身觸與粗語的緣故。「交錯」以下，解釋如何治罪。「所犯罪名隨篇懲處」，指真正的波羅夷或僧殘重罪。「若屬嫌疑則須依所舉之處結罪」，指的就是結當篇的突吉羅罪。

【原文】【疏】諸大德！是中清淨，默然故。是事如是持。
【譯文】【疏文】各位大德！在此戒中大家都清淨無犯，因為大家都默然不語。這件事就這樣認定堅持。
