# 校閱材料　第616檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【616-0001】資持記/13b_下一#33
【原文】經中未詳何經，謂對佛僧不恭敬故。八中，初明遇難暫開不著。準知無難不暫離身。彼有四事，到彼國不著，如文所列，但略去標數耳。若下，制敬護。九中。不禮皆據對別，不約對僧。注出所以。敬處尊者，即指大衣。恐彼不知，故須陳意；應云：某甲身著大衣，不得設禮。十中。
【譯文】經文部分尚無法詳知是出自哪一部經典，大意是說在佛陀與僧眾面前若不偏袒便是不恭敬之故。第八項中，開頭先說明遭遇災難時暫時開許不必穿著法服。由此可以推知，若是沒有災難，就不能片刻脫離自身。彼處記載有四件事，到了那個國家就可以不穿著，就如經文所列舉的那樣，只是略去了標明條數的字眼而已。從「若」字以下，規定必須恭敬護持。第九項中，凡是不予禮拜的情況，都是基於個別面對單獨一位僧人而言，並不是指面對大眾僧團。夾註中點明了個中原由。「敬處尊」是指大衣的尊貴崇高。唯恐對方不明白這層道理，所以必須陳明意由，應當說：「某甲身上披著大衣，不能向您行禮。」第十項中：

【616-0002】資持記/13b_下一#34
【原文】初明著時或對佛僧，不得向背；理應側身，要須屏處。口銜手奮，恐污損故。《毘柰耶》中注云象鼻，即犯眾學不齊整戒。文注顯然，今皆垂肘，豈知步步越儀犯吉。今準《感通傳》，天人所示，凡經四制。世多迷執，略為引之。彼云：元佛初度五人，爰及迦葉兄弟，並制袈裟左臂，坐具在袈裟下；
【譯文】開頭先說明穿著衣服時如果面對佛陀或僧眾，不得正向迎面或背對著披衣；理應側轉身軀，且必須在隱蔽避人的處所進行。用口銜著衣角或用手用力抖開衣服，都是擔心造成污染和破損。《毘柰耶》的夾註中說到「象鼻」，就是指違犯了眾學法中「著衣不整齊」的戒條。經文與夾註非常顯明，現今的人都任由衣角垂掛在手肘之下，哪裡知道每走一步都違背威儀、結犯突吉羅罪。如今依照《感通傳》中天神所開示的，歷經了四次制度變革。世人大多迷惑固執，在此略加引述。彼處說：當初佛陀最初度化五比丘，乃至到迦葉尊者三兄弟時，都是規定袈裟掛在左臂上，坐具墊在袈裟下面；

【616-0003】資持記/13b_下一#35
【原文】西土王臣，皆披白㲲，搭左肩上，故佛制衣角居臂異俗。〔此一制也。〕後徒侶漸多，年少比丘儀容端美，入城乞食，多為女愛，由是制衣角在肩後；為風飄，聽以尼師壇鎮之。〔此二制也。〕後有比丘為外道難言，袈裟既為可貴，有大威靈，豈得以所坐之布而居其上；比丘不能答，以事白佛；
【譯文】西方印度的國王與大臣，都是披著白色的細棉布搭在左肩上，所以佛陀規定將衣角放置在手臂上，以此區別於世俗凡人（這是第一次制定）。後來跟隨出家的徒眾漸漸增多，年輕比丘儀容端正美好，進入城中托缽乞食時，多被婦女產生愛戀之心，因此改制令衣角放置在肩膀後面；因為容易被風吹動飄揚，便聽許用尼師壇壓在上面（這是第二次制定）。後來有比丘被外道詰難說：「袈裟既然無比珍貴、具有大威神力，怎麼可以把拿來坐臥的布墊放在它的上面？」比丘無法回答，就把這件事稟告佛陀；

【616-0004】資持記/13b_下一#36
【原文】由此佛制還以衣角居于左臂，坐具還在衣下。〔此三制也。〕於後比丘著衣不齊整，外道譏言狀如婬女，猶如象鼻；由此始制上安鉤紐，令以衣角達于左臂〔達即到也〕；置於腋下，不得令垂，如上過也。〔今須準此，乍可排著左肩；若垂臂肘，定判非法，步步結罪。舊云：今在左臂為正，但不得垂尖角者。非也。
【譯文】因此佛陀又改制，依舊讓衣角放置在左臂上，坐具依舊放置在袈裟下面（這是第三次制定）。在此之後，比丘穿衣不夠整齊，外道譏笑說那模樣像淫蕩的女人，又像是晃動的象鼻；從此才開始制定在袈裟上安設鉤紐，讓衣角引領到達左臂上（「達」就是「到達」的意思）；然後放置在腋下，不得讓它下垂，以免產生上述的過失（如今必須依循此法，暫且可以排列搭在左肩上；如果垂落在手肘臂膀上，必定判定為非法，每走一步都要結罪。舊時說法認為：如今放置在左臂是正確的，只是不得垂下尖角而已。這種說法是錯誤的）。

【616-0005】資持記/13b_下一#37
【原文】十一中，《五百問》三段，初明互著。無中衣者，謂闕七條。大衣本非入眾，闕故開之。小衣即五條淨者，亦開入眾。準此若闕大衣，下二應開入聚；若闕下衣，大衣不許作務，七條應得。注中，以道行中多著下衣，或有見塔而設禮者，論中無衣暫開，故知常途不許。今時入塔禮誦，多不易衣；
【譯文】第十一項中，《五百問》包含三段文字，開頭先說明相互替代穿著的情況。所謂「沒有中衣」，是指缺少七條衣。大衣原本不是用來穿入大眾僧團之中的，因為缺少七條衣的緣故才予以開許。小衣就是指五條衣，如果是乾淨清淨的，也開許穿著進入大眾之中。依照這個道理，如果缺少了大衣，下面兩件衣應當開許穿著進入聚落；如果缺少了下衣，大衣既然不允許穿新作務（穿著做粗重勞務），七條衣就應當可以使用。夾註中指出，因為在路上行走時多半穿著下衣，有時見到佛塔便想行禮跪拜，論典中是因為無衣可換才暫時開許，由此可知常態之下是不允許的。如今的人進入塔廟禮拜誦經，多半不更換如法的大衣；

【616-0006】資持記/13b_下一#38
【原文】薰觸靈儀，更增慢業，識者誡之。次明受食。制須法衣。三明借衣。制須在界。下引《十誦》。決上論文，似制三衣重著受食，或局受持。袈裟語通，隨著一事；或復餘長，皆無有過。言得罪者，準犯吉羅。〔準此判犯不用前論。〕十二中。《五分、僧祇》，並謂法隨人勝；《雜含》顯著故得道，《賢愚》明敬故成佛。
【譯文】讓身上的汗垢穢氣薰染觸犯了神聖的威容，反而更加增長了慢心的罪業，明白事理的人應當引以為戒。接著說明接受飲食的規矩，規定必須穿著如法的衣服。第三說明借用衣物，規定必須是在同一結界之內。下文引述《十誦律》，用以化解上述論典的說法，那部論典似乎規定必須將三衣重疊穿著才能接受飲食，或者局限於受持的法衣。袈裟這個名詞是通稱，隨身穿著任何一件都可以；或者穿著其餘長衣，也都沒有過失。文中所謂「得罪」，依照規定是結犯突吉羅（依照這個標準來評判罪名，就不採用前面的論點了）。第十二項中，《五分律》、《僧祇律》都認為法衣（袈裟）的功德會隨著穿著者的戒德而顯得殊勝；《雜阿含經》彰顯了穿著袈裟因此得以證道，《賢愚經》則說明了恭敬袈裟因此得以成佛。

【616-0007】資持記/13b_下一#39
【原文】《雜含》云：此女有七子，六子相續命終，念子發狂；裸形被髮至佛所，遂得本心；慚愧蹲坐，佛令阿難取欝多羅僧與著已，為說法生信；後第七子又終，都不悲泣；化夫與己投佛出家，得阿羅漢。《賢愚》云：有一師子名堅誓，軀體金色，不害群生；
【譯文】《雜阿含經》說：這個女人有七個兒子，其中六個相繼死亡，她因為思念兒子而發狂；裸露身體、披散頭髮奔跑到佛陀住處，隨即恢復了本心；她慚愧地蹲坐在地，佛陀命令阿難拿取鬱多羅僧給她穿上之後，為她宣說佛法使她生起信心；後來第七個兒子也死了，她卻一點也不悲傷哭泣；反而化導丈夫與自己一同投奔佛陀出家，最終證得阿羅漢果。《賢愚經》說：有一隻獅子名叫堅誓，身體呈現金色，從不傷害各類眾生；

【原文】若本有村，結衣界已，村移出界，即此空處有不失衣界。是非既顯，猶恐執迷，故云任情量取；量謂評量。薩下，證除緣礙，初引《多論》五義。初云聚落不定，謂遷徙散落，不上一處；衣界定者，謂作法自然，分齊不可亂故。次義如《四分》緣起。三除諍者，或入聚會衣，容生忌故。
【譯文】如果原本有村落，結成衣界之後，村落遷出了界外，那麼這塊空出來的地方就自然具備不失衣界。是非對錯既然已經顯明，卻唯恐人們依舊固執迷惘，所以說「任由心意自行衡量選取」；「量」是指評斷衡量。從「薩」字以下，證明排除障礙緣由的說法，開頭先引述《薩婆多論》的五種意涵。第一種說聚落不固定，是指村落遷徙散落、居無定所；而衣界是固定的，是指作法界與自然界的分界限度不可紊亂之故。第二種意涵就如《四分律》的緣起所述。第三種「消除爭執」，是因為進入村落聚會衣物，容易引發嫌隙嫉妒的緣故。
