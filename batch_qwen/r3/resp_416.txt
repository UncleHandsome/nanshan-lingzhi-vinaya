整體看下來，譯文對文脈（境差／攬因成果／方便罪與究竟罪的判別）掌握得不錯，語意大方向沒有錯解。但有**幾處系統性的問題**與**零星硬傷**，建議修訂。以下分「通則問題」「逐則問題」「建議改寫」三部分。

---

## 一、通則性問題（影響最大）

**1. 「王」譯成「李四」，前後不一致，且與術語脫節〔必改〕**
#25～#29 一律作「李四」，但 #38 又作「王人（王某）」。更嚴重的是「**王境差**」是科判中定名的專有罪名，譯成「李四境差」後，讀者無法與原文術語對應。
→ 建議全文統一保留「張／王」（或「張某／王某」），「王境差」原樣保留。

**2. 「攬相成」譯成「互相擷取促成」是誤讀〔必改〕**
「攬」是**單向**的：攬（前）因以成（後）果，不是因果「互相」促成。
- #25「故攬相成」＝所以攬取因來成就果
- #28「不攬相成」＝不能攬張因去成王果（否定的是「張因→王果」這一條線）
- #31「故得相成」＝所以得以攬因成果
另外「擷取」用詞生硬，建議統一作「**攬取／取…以成…**」。

**3. 「究竟圓滿」（#35）〔必改〕**
此處「究竟」指**成罪究竟（根本罪）**，與「方便（未遂加行）」相對，不是修行意義的圓滿，易嚴重誤導。→「究竟（成罪）階段」。

**4. 「前方」（#40）〔必改〕**
「初躡前人異境」的「前」是**前文**，非空間的「前方」。

**5. 術語白話對譯不一致、缺乏註解**
「方便」時譯「運用方便」、時譯「採取行動」；「杌木」譯「枯木」；「境強」直譯「境界強大」；「業道」譯「造作惡業之道」——建議統一並酌加括註（見文末術語表）。

## 二、逐則問題

| 編號 | 問題 | 建議 |
|---|---|---|
| #25 | 「互相擷取促成」「相擷取而成」 | 「攬取因以成就果」；「這也是因果二者有別、而仍取因成果的例子」 |
| #25 | 「運用方便企圖盜取」 | 「方便」是加行／預備行為，非「方法」。可作「起加行欲盜取超過五錢」 |
| #26 | 「李四的重果」 | 原文只作「王果」，「重」是增譯（雖合義），可保留「果」或註明波羅夷 |
| #27 | 「在當前義解的最初科段」 | 「『今正解』中的第一科（即設問）」較精確；「認為如果…」宜改為「（此問意謂）若攬因成果…」 |
| #28 | 「不能互相擷取促成」 | 「不能攬張因以成王果」〔必改〕 |
| #28 | 「**還是**由此促成李四的正果」 | 「還」＝即／就，非「還是」；「正果」宜註「究竟根本罪」，避免與修證正果混淆〔必改〕 |
| #28 | 「在尚未與李四相接觸之前，屬於…」 | 主語缺失，補「（此前的種種加行）屬於先前對張的因」 |
| #29 | 「隨順替代的異境」 | 「從」＝依／就，作「依異境（王）而立名」較準 |
| #29 | 「不能稱作『差錯』」 | 「差」是專名，作「（張為本境）不得名為『差』」 |
| #31 | 「自始至終皆有犯意」 | 「元來」＝本來。應作「本來就有（盜過五錢之）心」，「自始至終」屬增譯 |
| #31 | 「互相促成」 | 同上，改「得以攬因成果」 |
| #32 | 「古德執著於彼例作為依據」 | 「向古師」＝前面（主張古解之）諸師，宜補「前面」 |
| #32 | 「使後人不生疑惑」 | 「後惑」宜作「使不再留有後續疑惑」 |
| #33 | 「這本疏文通解戒本」 | 語意含混。應作「此處只是通泛（從略）解釋戒本」，與下句「若解廣律則可展開」成對比 |
| #34 | 「枯木」 | 「杌木」是木樁／樹樁，非枯木（#36 同）|
| #34 | 「沒有境界強大的意義」 | 「無『境強』（所對境殊勝）之義」＋簡註，否則讀者不解為何只三句 |
| #34 | 「首律師之疏」 | 可作「智首律師《四分律疏》（首疏）」 |
| #34 | 「三種有情趣類」「四種境界」 | 宜括註：人、非人、畜生／加杌木為四境 |
| #35 | 「究竟圓滿」 | 見上〔必改〕 |
| #35 | 「造作惡業之道」 | 「業道（性罪、業報之罪）」，與「制罪（遮罪）」對舉才清楚 |
| #36 | 「全體相對於…」 | 「通」＝一概、都；「全體」生硬 |
| #38 | 「王人（王某）」 | 與前文「李四」衝突，須統一 |
| #40 | 「前方人類替代異境」 | 「前文所說的人異境」〔必改〕 |
| #43 | 「殺人的心想並未捨棄」 | 「人想不捨」＝仍不捨「對方是人」之想（境想之「想」），非「殺人的心」 |
| #43 | 「怎能說殺它的起因階段就已經結為方便偷蘭遮呢」 | 邏輯未點透：應補「**果（究竟）才偷蘭，因（方便）豈可與果同罪**」 |

## 三、建議改寫示例

**#28（疏）**
> 如今正確的解釋是：「雖同屬人趣，但各別身形（個體）有異，故不能攬取張的因來成就王的果。尚未與王交涉之前（的加行），屬先前對張的因；面對王以後，則別起方便，即是攬取王自身的因，由此成就（殺王的）正果〔究竟根本罪〕。至於本境張的因，則被壅阻而停在方便階段；稱此方便罪為『王境差』。」

**#43（疏）**
> 答：「這是由境差而結的方便罪。由於非人前來（替代本境），作『人』之想不捨，殺張之心已成，而所對之境乖違差替，故就張這邊結方便罪；就非人這邊，本來無罪。殺非人具足五緣、成究竟罪，也只結偷蘭遮，哪有它的因（方便位）就已與果同為偷蘭遮的道理？所以此說不通。」

**結論**：內容理解正確率很高，主要需修的是①人名與「王境差」的一致性、②「攬相成」的單向性、③「究竟圓滿」「前方」兩處硬傷，以及④幾處增譯（自始至終、還是、重果）與術語註解。修完即可達到可發布水準。
