# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【譯文】【記文】在發問的文句中。這是針對前面「安置在看不見之處」提出問難。在回答中，第一句先退一步順應前文所問，眼睛只看而不聽，照理說本無大過，所以說「應爾」。「下」字以下，正式解釋制戒的用意。傲慢的惡業本就人人自帶，若令其隨意觀看只會更加增長，所以稱為「慢習」。

【67-0003】02_戒疏/02d_卷一上之二#94
【原文】【疏】所以注中「除人，開鬼」者，以非人具通，隱顯徹見，自生深信，不勞事約也。人則反之。
【譯文】【疏文】之所以在註解中「排除人類，唯獨開許鬼神非人」，是因為非人具備神通，不論隱蔽還是顯露的處所都能洞徹照見，他們目睹僧團清淨自然會生起深厚的信心，用不著依靠事相上的禁令去約束他們。人類的情形則正好相反。

【67-0004】02_戒疏/02d_卷一上之二#95
【原文】【記】三中。「非人具通」者，得通有二：一者修得，如諸聖人具六通者；二業報得，鬼神外道，亦具五通，但無漏盡耳。「徹見」即天眼通，明見善惡，眾僧行淨，必無輕易。
【譯文】【記文】在第三小節中。「非人具備神通」，得神通有兩種途徑：第一種是修道所得，如同證得六通的諸位阿羅漢聖人；第二種是業報自然招感所得，諸多鬼神與外道也能自然具備五種神通，只是沒有斷盡煩惱的漏盡通罷了。所謂「徹見」是指天眼通，能明察善惡諸事，眼見僧眾行持清淨，必定不敢生起輕蔑隨便的心態。

【67-0009】02_戒疏/02d_卷一上之二#100
【原文】【疏】四、明不來說欲者。小學乖法，已出清眾；同儔不來，恐生異結。或諸緣障，心達事壅，故聽傳情，應僧和義。自分為二，「欲」表成僧，「淨」陳行具，可以知也。
【譯文】【疏文】第四個問答，是查問未能到場者是否有傳達「與欲」。年幼學戒而戒行未全之人，既然已經被請出清淨僧眾之外；同修的法侶若有不來的，唯恐他們會私下結派分立。或者因為諸多障礙因緣，內心雖想通達法會而事相上受阻，所以聽許他們傳遞心意，以契合僧團和合的大義。這自然分為兩個方面，「與欲」代表贊成羯磨以成就合格僧團，「清淨」是陳述自己持戒清淨無犯而戒行具備，這是不言而喻的。

【67-0010】02_戒疏/02d_卷一上之二#101
【原文】【記】四、明說欲。釋文中，初躡前起後。「異結」即各結別部，令僧破故。「或」下，明開意。「諸緣」，如下注釋。「自」下，釋欲法。初制欲、淨各傳，「欲」應羯磨，「淨」應說戒。後廢前教，例須合傳，故從此釋。
【譯文】【記文】在第四、說明「說欲」的段落中。在解釋經文時，首先承接前文引發下文。「異結」是指各自在不同住處分立結成別部，從而導致僧團破裂破僧。「或」字以下，說明開許代傳心意的用意。「諸緣」正如後文註解中所解釋的。「自」字以下，解釋欲法的名義。起初佛制中「與欲」和「清淨」是分開傳達的，「與欲」是用來相應羯磨，「清淨」是用來相應說戒。後來廢除了先前的教令，通例必須合在一起傳達，所以依照這個原則來解釋。

【67-0012】01_行事鈔/08a_卷中之四#63
【原文】次論止犯。或九或八。言九句者：上品四句，有十六罪。中品四句，有八罪。下品一句，但犯根本一罪；如不乞處分造房，但犯一僧殘；由識法識犯故，無不學無知罪。所以顛倒前句不同者，以犯門解義，罪多為上品；犯四根本、僧殘，各加不學無知；如前列數，非多何謂？言八句者，對教行不學以明，則無識法、識犯下品一句。若對事明，亦有兩箇九句，謂可學迷及不可學迷。如不說淨、見犯不發，即是可學；若迷、若忘，即不可學。如此廣知，隨指一戒，達之則類遍法界也。
【譯文】其次討論「止犯」。或為九句或為八句。所謂九句：上品四句，共有十六罪。中品四句，共有八罪。下品一句，只犯根本一個罪；例如不求得僧團處分便私自造作房舍，只犯一個僧殘罪；由於「識法識犯」的緣故，沒有不學與無知之罪。之所以將前文的句式顛倒而有所不同，是因為在犯罪門中解釋義理，罪多者列為上品；在上品四句中各犯一個根本僧殘罪，且每句各自加上不學與無知之罪（共十六罪）；如同前面所列數目，若非罪多怎麼算得上？所謂八句，是對應於教法與行持上的「不學」來闡明，便沒有「識法識犯」這下品的一句。若是對應於具體事相來說，亦有兩個九句，即「可學之迷」與「不可學之迷」。例如不作說淨、見到他人犯戒而不舉發，這就是可學；如果是昏迷、或遺忘，那就是不可學。如此廣博通達地理解，隨手指出一條戒，若能徹底了達，便能類推通曉遍法界的一切戒律了。

【67-0013】資持記/11c_中四上#24
【原文】欲使是非兩異，今古雙明，立破俱存，取舍無惑故也。〔下止犯中，亦同比意。〕釋中，初科為二；初敘略，上三句明事法句別。但下，明略出法句。明用別者，此明事法異也；且如房戒，尺量是事，白二是法；長衣，過日是事，說淨是法等。階降不異者，此示作句同也。唯對可學者，彰古局也。
【譯文】這是想要讓對與錯兩相分明，使現今與古代的義理都能清楚照見，立論與破斥同時並存，在取捨之間不再產生疑惑的緣故。（下面止犯門中，也是基於同樣的意趣。）在解釋之中，第一科分為兩部分；首先是敘述略說，前三句說明事件與法則的句型是有別的。從「但下」開始，說明大略列出法句。所謂「明用別」，這是說明事與法是不同的；姑且以造房戒為例，尺寸丈量屬於「事」，白二羯磨則屬於「法」；又如長衣戒，超過期限屬於「事」，作說淨羯磨屬於「法」等。所謂「階降不異」，這是顯示句型的鋪設是相同的。所謂「唯對可學」，是彰顯古師觀點的狹隘局限。

【67-0014】資持記/11c_中四上#25
【原文】今下，指例，初句標今略示。所下，例前廣釋，上二句指同。言所以者，括前有四：一者辨釋疑不識義；二者顯罪有無多少；三者結宗；謂不犯本罪，名為作持；四者分品，謂三品作持等。次此下，點異。列句中。為圖示之。
【譯文】從「今下」這段開始指涉通例，第一句標示今日在此略作開示。從「所下」開始，比照前面做廣泛解釋，前兩句是指示相同之處。所謂「所以」，總括前面共有四點：第一是辨析解釋懷疑與不識的義理；第二是顯明罪責的有無與多少；第三是結歸宗義，也就是不觸犯根本罪，稱之為作持；第四是劃分品位，也就是三品作持等。其次從「此下」開始，點明相異之處。在列出句法中，以圖表展示之。

【原文】以明罪少，故為下也。顯異中，初徵。對前作持，順倒別故。以下，釋所以。中品不動，上下通倒，文中但出上品罪多；中下漸降，則可知矣。問：止犯既爾，作犯如何？答：兩犯是同，準須迴倒；而作順止倒者，欲彰順倒，皆無在故。次八句中。此謂隨對事法，心緣不解，結不學無知；

【原文】犯門解義，必須有罪；既無根本，下品不立，故唯八句。二九中，初明立句。言對事者，止犯有二；事法止犯，此約造修；不學止犯，但望昧教；法及不學，如上所明，故但標事。以事例法，亦具二九；不學唯八，不通迷故。如下，舉事證成。長衣覆罪，故犯忘開，並通二九。
【譯文】論述犯戒之門在解釋義理時，必須以有罪為前提；既然沒有根本罪，下品便無法建立，所以只有八句。在「二九」之中，首先說明立句。所謂「對事」，止犯包含兩種：事法止犯，這是就造作修習而言；不學止犯，純粹是就昏昧於教法而言；法與不學的內容，如上面所闡明的，所以這裡只標示「事」。以事來比照法，同樣具備兩個九句；不學則只有八句，因為它不能通於迷忘的緣故。從「如下」開始，舉出實際事例加以證成。蓄留長衣與隱覆重罪，故意犯戒與遺忘開許，全都通於兩個九句。
