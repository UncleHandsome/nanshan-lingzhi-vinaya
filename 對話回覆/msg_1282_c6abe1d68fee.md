這種東西不是原文，也不是翻譯模型自己生的，是**材料切段時就切壞了**。

流程是：

```text
TXT/02 原文
→ _材料 切單元
→ _裁決
→ _終審
→ 頁面 pair
```

`_材料` 切單元時，把：

```text
……身。
```

切成一個獨立單元：

```text
■ 律文（原文）
身。
```

到了 `_裁決`、`_終審`，它就被當成一個合法單元；頁面重建時「一單元一 pair」，所以照樣產生：

```text
【律文】身。
【律文】身體。
```

頁面 builder 沒有判斷：

- 這是不是完整句子
- 是不是只有一個字
- 是不是應該接回上一段

它只負責把單元轉成 pair。

所以責任鏈是：

```text
_材料 切太細
→ _裁決 照收
→ _終審 照收
→ 頁面 照建
```

我之前只檢查 pair 有沒有字、有沒有白話，沒有檢查單元是不是完整語意，才會讓這種東西一路通過。

這不是查原文就能解決，是**材料切段的最小單位規則**出問題。
