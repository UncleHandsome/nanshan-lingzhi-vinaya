# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【618-0001】04_比丘尼鈔/05b_卷下之上#13
【原文】第一入寺者此律云舊比丘聞客來應出外迎為受衣鉢安置溫室重閣及經行處供給水器等問舊比丘我若干歲有房分否答言有問有人住否若無人者應問有臥具利養器物房衣等否有者當取至房受已又問何處大小行淨地佛塔聲聞塔第一上座房乃至第四上座房等一一別問若不問者主人一一示語客受房問主人已應禮佛塔次禮聲聞塔後禮第一上座乃至第四上座應偏袒右肩脫革屣右膝著地捉兩脚如是言大德我禮第四上座房內思惟應隨座次禮房主人一一示語十誦云若上座時見應禮難見遠者則止三千威儀經云若入他房具五法一於外彈指二當脫帽三作禮四正住教坐乃坐五不應經行五分住處迮不相識者聽同牀坐不得眠僧祗云舊比丘應語客僧一切僧家制限若伴已去者不得語令知云不及伴應語可小停息更應有伴必有急去者應給粮食囑累行伴五分云白衣入寺應借臥具受用三千威儀經云新至比丘以十事與之一當避與房二當給所須三朝暮問訊四語以習俗五當教避諱六當語請到處七語僧教令八當某事可食九示縣官禁忌十語以賊盜處所也。
【譯文】第一、進入寺院的規矩（入寺）。本律說：原住寺院的比丘聽聞有客僧前來，應當出門迎接，替客僧接過衣缽，引導安置於溫室、樓閣及經行之處，並供給水盆等器物。客僧應當詢問住寺比丘：「我戒臘若干歲，此處是否有分配給我的房間？」答說：「有。」又問：「房內是否有人居住？」若無人居住，應當詢問：「是否有分配的臥具、日常生活器具、房舍用品及防護衣物等？」若有，應當拿取至房間內，如法受用。接受之後又應詢問：「何處是大小便處？何處是清淨地？佛塔在何處？聲聞塔在何處？第一上座的房間在何處？乃至第四上座的房間在何處？」一一分別詢問；如果不詢問，主僧也應當一一指示告知。客僧受領房舍並問詢主僧完畢後，應當先前往禮拜佛塔，次禮聲聞塔，最後禮拜第一上座乃至第四上座；禮拜時應偏袒右肩，脫去皮鞋，右膝著地，雙手握持上座雙足，口中這樣說：「大德，我頂禮您。」若四位上座正在房內禪坐思惟，客僧應依座次向其房室頂禮，由舊住主僧一一指示告知。《十誦律》說：見到上座時理應禮拜，若因距離遙遠難以相見，則可作罷。《三千威儀經》說：進入他人的房舍時應當具備五種法則：一應在門外彈指弄出聲響，二應當脫下帽子，三應當作禮問訊，四應當端正站立，待主人請坐時方才坐下，五不應隨意在房內經行遊走。《五分律》說：住處若過於狹窄，彼此縱使不相識，也聽許在同一張床上並坐，但不得同床睡眠。《僧祇律》說：住寺比丘應當將僧團所有一切規約限制明確告知客僧；如果同行同伴已經離去，不得直接告知使其心慌說「你追趕不上同伴了」，應當勸告說「可以稍微在此停歇休息，之後應當還會有其他同伴同行」；若確實有十萬火急之事必須離去，應當供給糧食乾糧，並妥善託付給同行的同伴照應。《五分律》說：居士若寄宿寺院，僧家應當借給臥具受用。《三千威儀經》說：對新到達的客比丘，應當以十件事予以關照：一應當騰出房間讓給其居住，二應當供應各項生活所需，三應當早晚問候探望，四應當將當地的風俗習尚告知，五應當教導其避開禁忌忌諱，六應當告知受請應供的處所去向，七應當宣示僧眾的清規教令，八應當告知何種食物可以食用，九應當明示官府朝廷的法規禁忌，十應當提醒防範盜賊時常出沒的地點。

【譯文】第二、日常威儀法式（儀式）。《五分律》說：行住坐臥四種威儀若不如法，就無法為世間作為照破冥暗的明燈。《僧祇律》說：行走時應當平視前方，轉身回顧時應當全身上下一併轉動。《中阿含經》說：清晨出外乞食，應當收攝防護各部根門；乞食完畢，收妥收拾好衣缽，洗淨手腳，將坐具（尼師壇）披在肩上，前往無人打擾的寂靜處，或經行、或坐禪，淨除內心的煩惱障礙；到了中夜時分，進入室內睡眠，將鬱多羅僧摺疊四層鋪在床上，將僧伽梨摺疊當作枕頭，以右脅貼床側臥，頭面向佛像的方向，兩腳上下重疊，心中專注繫念光明之相；到了後夜時分，迅速起床，依照初夜的方法精進修持。《僧祇律》說：頭部應當朝向袈裟以及和尚、長老比丘的方位；初夜時分深入思維省察自身所造的善惡業；到了中夜，右脅貼席而臥，兩腳相疊，閉合口唇，舌尖頂住上顎，右手枕在頭下，左手伸直平放順著身體，始終不捨棄正念正慧，心中時時繫念著起身的念頭。義理解釋說：一切天人龍神鬼怪，都是出家人修持道業的助緣護持；對於幽微不可見的鬼神及顯露在外的世人，都不可有輕忽冒犯與觸怒；雖然獨自居於暗室之中，也常當返照自省自我警惕。《十誦律》說：燈光明亮之時不得睡臥。《薩婆多部毗尼摩得勒伽》說：戒臘若已超過十年，若遇有如法的佛事必定能利益眾生者，縱使師父不同意，自行前往亦無過失。《僧祇律》說：行走時應當腳跟先著地，腳趾後著地；在道路上前行，若打算投宿，應當差派兩位年輕比丘在前方尋覓歇宿之處，並求取午前的食物及日後的備用食物；非時進入村落聚落時應當稟白大眾；尋得宿處後返回通報，應當輾轉告知所有人，然後一同入村。《大智度論》說：出入往來皆安詳專注，舉足下足之時審慎觀照地面而行，避開散亂的心念，只為了護念一切眾生，這便是「不退轉菩薩」的相貌。《僧祇律》說：坐時不得如同駱駝那樣蹲坐，應當結跏趺坐；若是極度疲勞，准許交替舒展一隻腳放鬆。《增一阿含經》說：現在聽許比丘先以手扶托座位，然後方才坐下，這是我的教導。《十誦律》說：身體無病者，白天不得躺臥；若是昏沉嗜睡，應當起身經行消除睡意。《善見論》說：臨睡臥之時，應當先觀照思維「六念」（念佛、法、僧、戒、施、天）。《三千威儀經》說：不得在上座的座位上坐，亦不得與剃度恩師等「三師」並排同坐。《十誦律》說：聽法之時，上座若走來，不應當起立迎候；若是起立者，犯突吉羅罪；若是和尚或阿闍梨走來，出於極度恭敬自己可以起立，但不得呼喚他人一同起立，否則犯突吉羅罪；甚至在聽法時，不得與沙彌同坐一張床席；沙彌可以與白衣同坐一張床席；大比丘若同住受過三個夏安居，亦准許同坐一張床席。《三千威儀經》說：準備上床就寢時，應當具備七種法則：一應當徐緩退步安坐上床，二不得匍匐趴著爬上床，三不得讓床鋪晃動發出聲響，四不得大力拍拂床席發出聲音，五不得大力打呵欠、咂嘴嘆息及思量世俗雜事，六不得如群狗般蜷縮雜亂而臥，七起床必須合乎時節時程，若心緒紛亂游移不定，應當自我苛責初發出家的根本道心。《薩婆多部毗尼摩得勒伽》說：比丘若貪著睡眠，荒廢拋棄身口意三業，不再精進修道，金剛力士將出面訶責懲罰；佛陀說：受食他人的信施，不應當懈怠懶惰；在夜晚的初夜與後夜二個時段中，應當坐禪、誦經，並以一個時段經行，以此調劑消息身心，這才稱為合法的臥寢之法。《僧祇律》說：睡眠之法應當如同獅子之王，不得貪睡昏沉直到日出；應當在後夜時分便立即起床，端正思維自作之業；此外，仰臥是阿修羅的睡法，覆臥趴睡是餓鬼的睡法，朝左脅側臥則是貪著欲望之人的睡法。

【618-0005】04_比丘尼鈔/05b_卷下之上#17
【原文】第一懺波羅夷法者此有三種一懺儀二懺法三行法第一懺儀者此律比丘比丘尼犯波羅夷已都無覆藏心令如法懺僧祇云若犯罪已啼哭不欲脫去袈裟深樂佛法令與學悔羯磨比丘不淨食彼亦不淨食得與比丘授食除火淨五生種及捉餘金銀等應從沙彌尼受食十誦云若有犯此重戒者如法乞羯磨佛所結戒一切受行在大比丘尼下坐不得與大比丘尼過三夜宿自不得與白衣沙彌尼過三夜宿得為僧作布薩自恣二種羯磨仍不得自足僧數餘一切羯磨皆不得作得受夏也伽論云謂無能作者得作前二種法大唐波頗三藏云縱自言犯重及有三根自他相對並成說淨受衣等阿毗䟦律云有比丘名僧伽婆藪遂犯婬便自覺悟捨鍚杖法衣著小舍勒出入大唱云我是十方三世佛賊徧求自悔至持律所知其犯重即化作一大火坑僧伽婆藪便束身走投火火即變成涼池律云汝心如是戒還得之無破戒罪即得羅漢如僧伽婆四事皆爾母論云與白四悔法已名清淨持戒但此一身不得超生離死然障不入地獄治禪病經云犯重比丘將欲懺悔者脫去僧伽梨著安陀會五體投地如泰山崩心生慚愧供僧苦役掃廁擔糞如是經八百日已後香湯洗浴著僧伽梨入塔觀像見好瑞應有證後為僧誦戒滿八百徧方得清淨也虗空藏經佛名等經若比丘比丘尼犯四重五逆悉許得懺然此諸經並是大乘若欲捨懺特須自驗根性審看經意然後得悔不得見有斯經便慢律教。
【譯文】第一、懺悔波羅夷罪的法則（懺波羅夷法）。此項分為三種：一是懺儀，二是懺法，三是行法。第一、懺悔儀式：本律規定，比丘或比丘尼犯了波羅夷重罪之後，心中完全沒有掩飾隱瞞的意圖，僧團應當令其如法懺悔。《僧祇律》說：若犯罪之後，痛哭流涕，不願脫去袈裟，內心深樂佛法者，僧團應當為其舉行「學悔羯磨」；比丘視為不淨的食物，彼犯戒者亦視為不淨而不得食；准許為比丘授食，但除去了以火作淨及五種具有生機的種子，以及不得捉持剩餘的金銀等物；應當從沙彌尼手中受食。《十誦律》說：若有觸犯此重戒者，能夠如法祈求羯磨，則佛所制定的一切戒律皆嚴格承受奉行；席位列在大比丘尼之下座；不得與大比丘尼同宿超過三夜，自己亦不得與白衣、沙彌尼同宿超過三夜；准許為僧團作「布薩」與「自恣」這兩種羯磨，但自身依然不能算入成就羯磨所需的法定僧數之中；其餘一切羯磨法皆不得作；但准許受夏安居。《伽論》說：是指在沒有能作羯磨者的情況下，方得作前兩種羯磨法。唐代波頗三藏說：縱使自行表白犯重罪，且有見、聞、疑三根為憑，若彼此相對處理，皆能成就說淨及受衣等法事。《阿毗跋律》中說：有一位名叫僧伽婆藪的比丘，遂觸犯了淫戒，隨後猛然自覺悔悟，於是捨去錫杖與如法法衣，只穿短小的舍勒布裙，出入各處大聲呼喊：「我是十方三世佛的大賊！」走遍各處祈求自我悔過；當他來到持律律師處所，律師知其犯重罪，隨即化作一座大火坑；僧伽婆藪便縱身奔投火中，烈火瞬間轉化為清涼池；律師說：「你的心能如此，戒體重新獲得，無破戒大罪。」隨後便證得羅漢果；如同僧伽婆藪的例子，四事皆是如此。《薩婆多部毗尼摩得勒伽》說：僧團為其行白四羯磨給予悔法之後，名為清淨持戒，但這一身已無法超脫生死證得果位，然而障礙消除不再墮入地獄之中。《治禪病經》說：觸犯重戒的比丘將欲懺悔者，應當脫去僧伽梨，只穿安陀會，五體投地撲倒如同泰山崩塌，內心生起慚愧；承擔供僧的勞苦雜役，打掃廁所、挑擔糞便，像這樣歷經八百天之後，以香湯洗浴，穿著僧伽梨，進入佛塔瞻仰聖像，若見到殊勝祥瑞的感應證明之後，再為僧眾誦持戒本圓滿八百遍，方才重新獲得清淨。《虛空藏經》及《佛名經》等經中均載，若比丘、比丘尼犯四重、五逆等罪，全皆開許得以懺悔；然而這些經典全部屬於大乘法門，若想依此捨罪懺悔，必須特別審慎檢驗自己的根性，仔細研審經文深意，隨後方得悔除，萬萬不可看見有這些經典，便輕慢律宗教誡。

【原文】第二懺法者犯尼應具威儀脫新衣著故五條至心懇惻來至僧中五體投地舉聲大哭如泰山崩自發露云我是佛法中大賊偷形出家行非犯重冐霑清眾自非他懺罪中之極惡中之大省己患過誰逾於我污辱凡聖壞滅佛法恨不碎身如塵歷劫重謝苟貪性命但延朝夕蒙世尊慈訓懺法携誘罪人冀免來報願大眾慈悲布施悔法作如是已然後請云。
【譯文】第二、懺悔法式（懺法）。犯戒的比丘尼應當整肅威儀，脫去新衣，改穿陳舊的五條衣，以至誠懇切悲戚之心來到僧眾之中，五體投地，放聲大哭如同泰山崩塌，自行表白發露說：「我是佛法中的大賊，偷形出家，所作所為違逆戒律觸犯重罪，冒昧沾染清淨的大眾僧。這本非其他平常懺法所能滌除，乃是罪業中最深重、罪惡中最大極者；省察自己的過患罪愆，天下有誰能超過於我！污辱了凡聖僧團，壞滅了如來正法，恨不得粉身碎骨如微塵，歷劫重重謝罪；我苟且貪戀性命，只是為了延緩朝夕殘生，仰蒙世尊慈悲訓誨懺悔法門，攜手引導罪人，冀望能免除未來的惡報。願大眾慈悲，布施我悔罪除障之法！」如此表白完畢之後，然後祈請說：
