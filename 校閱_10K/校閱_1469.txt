# 校閱材料　第1469檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1469-0001】04_比丘尼鈔/05a_卷下之上#22
【原文】第六對緣者初明惡觸者十誦云比丘食竟以不淨鉢及食與沙彌白衣洗鉢竟還著僧器中是名淨一心過與則無惡觸僧祇云若曬穀時比丘在上行者當脚處使淨人扟却難事急雖蹈無罪必天雨無淨人時得自遙擲物覆捉淨甎石鎮之忘覆食器亦爾比丘錯把淨麨者非故名淨若還放缾中即為不淨槃緣沒𪍿麥為器船在水中非器岸上為器車駕牛時非器無牛者為器若食時或甘蔗蘿蔔束豆囊上令比丘坐不動身亦不得問若動問者一切不淨若船車上載諸穀覆者比丘得坐上下不得名字若小車有淨物若取衣鉢時動車者一切不淨當令淨人取應令淨人先上比丘尼後上若下時比丘尼先下若在載物車中忽即車翻離牛者一切不淨若牛繩尾未離車者名淨十誦云比丘與沙彌擔食道中食時與沙彌沙彌還與比丘者先不共要得食反此不得飯粥羮器傾側聽佐淨人正已不得復觸若佐搘釜亦爾人驢車牛等負食傾側亦爾此律若蘇油缾不覆無淨人覆者自手捉蓋遙擲置上若居士持食寄比丘掌舉後索還與比丘者得洗手受之五分云若惡人以僧不淨米一把投淨米中可分者除之不可分者趣去一把　二自煑者僧祇云薑湯不得自煑以變生故乞得冷食自溫者不犯若作食時淨人小者得捉其手教淘抒飯等　三內宿者五分云使淨人於不淨地洗菜未竟明相出者犯此律有比丘持食來覓淨地未得明相出不犯四內煑者若在界內為他者不礙私己與他有餘洗手受食不犯此律式叉尼得與大尼過食不得同宿。
【譯文】第六「面對境界的持犯」（對緣）：首先說明「惡觸」：《十誦律》說：比丘用齋完畢，把不淨的缽和剩餘食物交給沙彌或在家人，洗完缽後再放回僧器之中，這稱為清淨；一心傳遞交付，就不算惡觸。《僧祇律》說：如果曬穀時，比丘在上行走，比丘落腳之處，應當讓淨人撥除拋棄；遇危急之時，踩踏了雖不算犯戒，但若天下雨又沒有淨人，可以自己從遠處拋擲布物覆蓋，拿乾淨磚石壓住；忘記蓋好食器也是如此。比丘若誤抓了乾淨炒麵，這不是故意的，依然算淨；如果放回瓶子中，整瓶就成了不淨。盤子邊緣深度足以沒過大麥粒者，算作器皿；船在水中不算器皿，拖到岸上就算器皿；車子套上牛時不算器皿，解開牛時就算器皿。受食時，若在甘蔗、蘿蔔、豆捆、糧囊上讓比丘坐著，比丘必須端身不動，也不得詢問；如果晃動或詢問，一切糧食都算不淨。若車船上載運各種穀物且有遮蓋，比丘可以坐於其上，坐於其上時不得稱說其（穀物之）名字。若小車上載有淨物，拿取衣缽時晃動了車輛，一切食物皆成不淨，應當讓淨人去拿；應當讓淨人先上車，比丘尼後上；下車時，比丘尼先下。若在載運淨物的車中，車輛忽然翻覆脫離了拉車之牛，一切食物皆成不淨；如果套牛的繩子與尾巴尚未脫離車輛，則仍算清淨。《十誦律》說：比丘與沙彌在途中挑運食物，受食時把食物交給沙彌，沙彌隨後又還給比丘，只要原先未曾相約，可以食用；反之若先相約好，則不得食用。飯菜粥羹的器皿傾斜時，准許協助淨人扶正，扶正之後不得再碰觸；幫忙支撐大鍋也是如此；人、驢、車、牛等載負食物傾斜時，也是同樣道理。本律說明：酥油瓶若沒蓋好又無淨人可蓋，比丘尼可以手執瓶蓋遠遠拋在上面覆蓋。如果居士拿食物寄託比丘尼代為保管，之後索回又重新轉贈比丘尼，比丘尼可以洗淨雙手如法受取。《五分律》說：若有惡人將一把不淨的僧米丟入淨米中，若能分揀挑出者應當剔除；若已混雜無法挑揀，抓出一把丟棄即可。第二「自己煮食」（自煮）：《僧祇律》說：生薑湯不得自己煮，因為使生食轉熟的緣故；乞討來的冷食自己溫熱，不算犯戒；煮飯時若淨人年幼，可以握著他的手教他淘米攪飯等。第三「內宿」（留在住處過夜）：《五分律》說：差遣淨人在不淨地洗菜尚未完畢，黎明破曉（明相出）者，算犯戒。本律說：有比丘帶著食物前來尋找淨地，尚未找到黎明已至，不算犯戒。第四「內煮」（在住處內煮食）：如果在界內為他人煮食，並不礙於自己私用；留給別人還有剩餘，洗手受食不算犯戒。本律規定：式叉摩那（正學女）可以為比丘尼遞送食物，但不得與比丘尼在同一屋同宿。

【1469-0002】04_比丘尼鈔/05a_卷下之上#23
【原文】第七互墮者此律云安食具在樹上並從根斷若根在不淨地枝覆淨地果墮淨地或為風吹雨打鳥獸墮者但無人觸知遇緣而墮雖經明相不成內宿謂長足果也若不淨地未長足來運運重生則無內宿隨時而取得入淨厨若果菜已離本處者隨經明相比丘尼若知即不得食。
【譯文】第七「互墮情況的判定」（互墮）：本律說明：若把盛食器具安置在樹上，判定時一律從樹根處起算。如果樹根在不淨地，枝葉延伸覆蓋在淨地之上，果實掉落在淨地中，或者是被風吹雨打、鳥獸弄落下來，只要沒人碰觸、知曉，隨緣墜落，即使歷經黎明破曉，也不算內宿（過夜留食），這是指成熟圓滿的果實。如果是不淨地中尚未完全長成的果實，隨生長生長重重孕育，則沒有內宿之患，可隨時摘取送入淨廚；若果菜已採離本株，隨後經歷黎明，比丘尼若知曉，就不得食用。

【1469-0003】04_比丘尼鈔/05a_卷下之上#24
【原文】第八儉開者此律為穀米勇貴人民饑餓乞食難得為賊持去佛憐愍故開界內共食宿內煑自取食僧俗二食水陸兩界並不作餘食法舊解尼無餘食法開若據敬僧戒中似尼犯足有餘食法今且論無者若儉時應開七罪謂內宿內煑自煑惡觸不受足食殘宿等三提四吉兼壞生種如水陸果子不受而食豈令淨耶此律若時世還賤故開食者佛言不得如法治之十誦云若饑儉時食竟得持殘去語施主知。
【譯文】第八「饑荒時期的開許」（儉開）：本律說明：米穀飛漲暴貴、百姓飢荒挨餓之際，乞食難得，且容易被盜賊搶奪；佛陀憐愍的緣故，特地開許在界內可以一同食宿、內宿、內煮、自取食物，僧團食與俗家食、水產與陸產，皆不再作「殘食法」（餘食法）。古昔解釋說比丘尼沒有殘食法的開許；若根據敬僧戒中的文意，似乎尼僧犯了足食戒之後仍有殘食法。如今暫且依據無殘食法來論：若在饑荒之時，應當開許免受七種罪過，即內宿、內煮、自煮、惡觸、不受食、受已足食而食、殘宿食等三種波逸提罪與四種突吉羅罪；兼開損壞有生命的生種，如水陸果子未經受食作法而食用，豈能稱為清淨呢？本律指出：如果物價回穩變賤，仍舊依照開許隨意受食者，佛陀說應當依律法懲治。《十誦律》說：若是饑荒之年，受食用齋完畢後，可以把剩餘食物帶走，但必須讓施主知曉。
