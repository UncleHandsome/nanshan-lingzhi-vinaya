# 校閱材料　第809檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【809-0001】02_戒疏/19b_卷四下之一#98
【原文】【記】釋不犯中。初總示。「次第」六段，前五並以「其事實爾」為頭，「又為性」下，即第六也。初云「如餘人生」，謂非同他人生年滿也。「生」下，別示。初點前二。「若」下，次點中二。《律》文「令還本處更受」，故須示意。「事法有疑」，「事」即受戒，「法」即羯磨。「審詳」謂窮問虗實，「知過」謂知是非法。「餘」下，指後二種，義無反問。
【譯文】【記文】解釋「不犯」的部分。先是總說。「次第」所列的六段，前五段都以「其事實爾」開頭，從「又為性」以下，就是第六段。開頭說「如餘人生」，是說不同於其他人生年已滿。「生」字以下，是逐項別說。先點出前兩種。「若」字以下，接著點出中間兩種。《律》文說「令還本處更受」，所以必須說明它的意旨。「事法有疑」，「事」指受戒這件事，「法」指羯磨作法。「審詳」是徹底問明虛實，「知過」是知道它是非法的（不如法的）。「餘」字以下，是指後面兩種，義理上不必再作反詰。

【809-0004】02_戒疏/19b_卷四下之一#101
【原文】【疏】出家同法，見有犯重宜即彰露，表己心淨，亦使前人息於後犯，則彼我俱益，眾法清淨，道理法然。今故迭相容隱，無思露過，致前造者罪根滋漫，永不可息。又自壞心行，將欲造罪，自他俱損，敗於眾法，過是不輕，故制。
【譯文】【疏文】出家之人同受佛法，看見有人犯了重罪，應當立即揭露，一方面表示自己的心清淨，一方面也使前面犯戒的人停止日後的再犯，這樣自他兩方面都得到利益，僧眾的法也清淨，道理本來就該如此。如今卻互相包容隱藏，不想把過失揭露出來，致使先前造罪的人罪根蔓延增長，永遠無法止息。又自己敗壞心行，將要造作罪業，自他兩方面都受損害，破壞了僧眾的法，這個過失不輕，所以制戒。

【809-0005】02_戒疏/19b_卷四下之一#102
【原文】【記】六十四，制意中。初敘三益：一、自，二、他，三、眾法清淨。言「犯重」者，通含夷、殘兩篇。「道理法然」，謂法爾當然。「今」下，次明三損，對反可知。「滋漫」，言其增廣無涯畔也。
【譯文】【記文】第六十四條，制戒意趣的部分。開頭敘述三種利益：一是自利，二是利他，三是眾法清淨。所說的「犯重」，通含波羅夷、僧殘兩篇。「道理法然」，是說法爾如此、理所當然。「今」字以下，接著說明三種損害，與前面對照即可明白。「滋漫」，是說它增長廣大沒有邊際。

【809-0006】02_戒疏/19b_卷四下之一#103
【原文】【疏】論犯六緣。一、是大比丘，除下三眾。二、犯麤罪，除下三篇，非壞眾故。三、知犯。《見論》云：「但知犯者，乃至百千，展轉共覆，皆犯提罪。」若露罪已，彼聞便止，更不須露。若露，如上。四、作覆罪心。五、不發露。六、經明相便犯。餘如《鈔》所引。
【譯文】【疏文】判定犯戒有六種因緣：一、是大比丘，排除下三眾。二、所犯是麤罪，排除下三篇，因為它們不會破壞僧眾。三、知道對方犯罪。《見論》說：「只要知道有人犯罪，乃至百人千人，展轉共同覆藏，都犯波逸提罪。」如果知犯者已向人發露其罪，對方聽聞之後便可止住，不須再向他人發露。至於發露的方法，則如上面所說。四、生起覆藏罪過的心。五、不發露。六、經過明相就結犯。其餘如《鈔》中所引。

【809-0007】02_戒疏/19b_卷四下之一#104
【原文】【記】犯緣。第二，覆下三篇，但犯吉罪，所以除之。三中，引論。初明多人共覆同犯。「若」下，次示發露之法。「以」字，合作「已」。「若露如上」者，令依上法也。下指「如《鈔》」，彼云「若犯者兇惡，不露不犯」、「若疑未了，不須說」等。
【譯文】【記文】犯緣的部分。第二，覆藏下三篇只犯突吉羅罪，所以把它排除。第三項中，引用論典。先是說明多人共同覆藏，同樣犯戒。「若」字以下，接著顯示發露的方法。「以」字，應該作「已」。「若露如上」，是教人依照上面的方法去做。下面指出「如《鈔》」，那裡說「如果犯戒的人兇惡，不發露也不犯」、又說「如果懷疑未明，不必說」等等。

【809-0015】02_戒疏/19b_卷四下之一#112
【原文】【疏】所以覆他重，自覆輕者？覆他名重而治輕，自覆名輕而治重。又覆他有本，重制令露，以戒自淨故；自覆本壞，不須重制。亦可覆他三損，自覆唯二故輕。如「十三」中，謗戒料簡說。
【譯文】【疏文】為什麼覆藏他人的罪重，覆藏自己的罪輕呢？覆藏他人，名義上重而治罪輕；覆藏自己，名義上輕而治罪重。又，覆藏他人的人，根本還在，所以制定重罪令他發露，因為戒要自己清淨的緣故；覆藏自己的人，根本已壞，不必制定重罪。也可以說，覆藏他人有三種損害，覆藏自己只有兩種，所以輕。如「十三」中，謗戒的料簡所說。
