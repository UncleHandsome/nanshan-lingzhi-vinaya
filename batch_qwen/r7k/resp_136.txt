## 一、【136-0001】#28 逐條檢核

### （1）無記心的釋義用詞
- 譯：「無記心（**非善非惡之平常心**）」
- 問題：「平常心」在漢傳語境（平常心是道）帶有褒義、灑脫義，與律學「無記＝不記為善、不記為惡」的技術義不同，易誤導。
- 建議：「無記心（不屬善、也不屬惡，故不記別為善惡的心）」，或簡作「非善非惡之心」。

### （2）元非攝護
- 譯：「原本就**不懂得**收攝防護」
- 問題：原文是「不作攝護」（不去守攝），不是「不懂」。加上「不懂得」會把責任推給無知，與下文「反上所懷，並結正犯」的判準（有無恆常護持心）不合。
- 建議：「從來就不加以收攝防護」。

### （3）方坐／虛論 ★較要緊
- 譯：「比丘正在**坐席**時，高談闊論**虛妄之語**」
- 問題：
 - 「坐席」易讀成宴會席位；「方坐」宜作「正當（端）坐時」，如坐禪、坐眾之際。
 - 「虛論」是**無義空談、戲論**，不是「虛妄之語」。「虛妄語」在律中是另一條（妄語）戒，混用會錯判罪相。
- 建議：「例如比丘正當端坐（坐禪、坐眾）時，卻高談闊論、空談無益之言」。

### （4）和僧媒娶
- 譯：「附和僧眾為人作媒婚娶（**如附同知事為淨人媒娶**）」
- 問題：括號內是具體化的推測性解釋（唐代寺院為淨人婚配之說），原文與此處文脈並無明文。
- 建議：正文保持「隨順僧中為人作媒嫁娶（僧殘媒嫁戒）」，括號那層若無注疏依據，宜移到腳注並標「一說」。

### （5）非時入俗
- 譯：「**不在規定時間**進入世俗村落」
- 問題：語意含糊，讀來像「該進村時不進村」。「非時」是**在不該入村的時分（一般指過午之後）入聚落**。
- 建議：「在非時（不恰當的時分，如過午之後）進入世俗村落」。

### （6）手觸僧器
- 譯：「雙手隨意觸摸僧團公用器具」
- 建議：可補出律中本意「以未淨之手觸碰僧用淨器」（與下文《五百問》知事誤觸淨器相呼應），但屬補充，宜加括號。

### （7）「非即如上」 ★斷句理解需交代
- 譯：「這不同於上述的情形。」
- 問題：這四字是壓縮的轉折語，譯文「這」指前指後不明，讀者無法判斷。依文勢應是「**並非（都）如上面所說那樣不犯**」，用以帶出下句「前有方便、後入眠醉狂」仍須結罪。
- 建議：「但並非都同於上面所說的開緣不犯——（例如）先前已起犯意、作了方便……」，並可加注說明此句異讀。

### （8）「無記無業」 ★誤譯
- 譯：「無記心**不招感業道**，為什麼會有果報呢？」
- 問題：「業道」是十善／十惡業道的專名，原文只說「無記不造業、不感業」。
- 建議：「無記心既不造業（不感業），為什麼還會有果報？」

### （9）頭陀比丘因緣中的增譯
- 譯：「無意間**踩踏**殺生」「在山上**拱動**石頭」「**回頭**砸死了這位比丘」
- 問題：
 - 「踩踏」原文無（只作「不覺殺生」），且眾生種類未定，不宜坐實。
 - 「拱動」勉強可通（野豬），但仍屬添加，可作「掀舉石頭」。
 - 「回頭」語體不合，「還」是「反而／回過來」。
- 建議：「無意中殺了眾生；那個眾生命終之後墮為野豬，在山上掀舉石頭，石因崩落而下，反而砸死了那位比丘。」

### （10）《五百問》《成論》兩處的增譯
- 「知事誤觸淨器」→ 譯加「**用污手**」「**死後**」：合理但屬補釋，建議加括號。
- 「睡眠成業」→ 譯加「**損他之業**」：原文無此限定，建議刪，作「睡眠中（也能）成就業，這就是無記業」。
- 另：原文作「啖糞鬼」，譯文作「噉糞鬼」，全書宜統一用字。

### （11）由非意緣
- 譯：「由於並非出於**本心的意圖攀緣**」
- 問題：語句糾結。原意是「不是作意（故意）去攀緣犯境」。
- 建議：「由於不是有意作意去攀緣（犯境）」。

### （12）三善／三惡 ★宜存疑加注
- 譯：「沒有**三種善根**可以依附，只會平白增加**三惡道**的苦痛輪迴」
- 問題：「三善」可解為三善根（無貪無瞋無癡），亦可解為三善道；此處與「三惡（道）」對舉，兩說皆有人主張。譯文單取一說而不加注，等於替讀者定了讞。
- 建議：正文保留「三善」「三惡」，加注並列兩解。

### （13）末段小詞
- 「虛縱身口」→「**虛妄**放縱」：此「虛」是徒然、白白，非虛妄。建議「白白地放縱身口」。
- 「污染塵境」→「染污於**塵勞**境界」：「塵境」指六塵境界，「塵勞」偏煩惱義，建議「在六塵境界中造作染污」。
- 「並結正犯」→「判定為**正式犯戒**」：口語味重且與他處「結正罪」不一致，建議統一作「結成正罪（根本犯）」。

## 二、【136-0002】#29 ★最大問題：整段未譯

 presently 只有頭尾兩句是白話，中間整段經文（六篇罪報＋涅槃）**原文照抄**，讀者看不懂，也與 #28、#30 的體例不一致。必須補譯，並處理下列諸點：

**A. 專名須出義**
| 原文 | 建議白話 |
|---|---|
| 泥犁 | 地獄（niraya） |
| 突吉羅・眾學戒 | 突吉羅（惡作、輕垢罪）中的（百）眾學戒 |
| 波羅提提舍尼 | 悔過法（向他發露悔過之罪） |
| 波逸提 | 墮罪 |
| 偷蘭遮 | 粗惡罪（大障善道） |
| 僧伽婆尸沙 | 僧殘 |
| 波羅夷 | 斷頭罪／棄罪（不共住） |
| 三十三天 | 忉利天 |
| 不憍樂天 | 化樂天 |
| 十六千歲 | 一萬六千歲 |

**B.「於人間數○歲」要譯出換算語意**：如「（此地獄壽量）換算成人間年數為……」。

**C. 數字本身有坑，切勿自行換算**
- 古代「億」有十萬、百萬、千萬、萬萬諸說，這正是道宣末句要會通的地方。
- 且傳本數字與天壽推算未必吻合：四天王天壽 500 歲，以人間 50 年為一日、一年 360 日計，應為 500×360×50＝**900 萬人間年**，經文卻作「九百千歲（＝90 萬）」；其後幾條也參差。
- 建議：**照錄原數＋加注**（註明「億」之大小數異說，及傳本數字與天壽換算互有出入，姑存原文），不要譯成現代確定數字。

**D. 末句「此處」指涉不清 ★**
- 譯：「這是因為計算單位的進位法有大數與小數的分別，**此處**是採用以萬萬為一億的計算量級。」
- 問題：「此處」到底指《涅槃》還是《目連問經》？依文意應是 **《涅槃》用大數（萬萬為億）**，故與上經小數不同。
- 建議：「《涅槃經》所說與上面經文不同，是因為計數有大小數之別——（《涅槃》）是以『萬萬為億』的大數計量的。」另可加注：二經除數字外，所舉天別亦不同（此經作四天王天，《涅槃》作忉利天）。

**E.「二引證誠報」的「誠」**
- 譯作「證實確切的果報」可通，但「誠」多通「誡」，配合下文「勿得縱心罪境」的勸誡語氣，讀作「引經證以**警誡**罪報」更順。建議至少加注一說。

**補譯示例（頭尾＋第一條，其餘依此）**
> 第二、引經證以警誡罪報。如《目連問罪報經》說：若比丘、比丘尼無慚愧心、輕慢佛語，犯了突吉羅（惡作）中的眾學戒罪，（其地獄苦報）相當於四天王天五百歲的天壽，墮在泥犁（地獄）中，換算人間年數為九百千歲。……

## 三、【136-0003】#30 小修即可

1. 「**從**以上所引證的經文」——「從」多餘，改「以上所引的經典」。
2. 「正統翻譯傳入」——「正翻」重點在**譯主可考、如法譯出**，建議「都是佛所說、且有正式譯本的經典」。
3. 「譯者失傳」——「失譯」是**譯者不詳（失譯人名）**的目錄學術語，建議直作「失譯（譯者不詳）」，與「疑經、偽經」並列。
4. 「如此**酷烈**刑科的制裁」——「酷烈」為添加形容，可刪或加括號；「刑科」宜點明是地獄刑罰之罪科。
5. 「在**理法上**必定要歷經長遠劫數」——「理須」＝按理必然，「在理法上」生硬，改「按理必然要經歷長劫受苦」。

## 四、通則建議

1. **增譯要標記**：本批出現「踩踏／用污手／死後／損他之業／附同知事為淨人媒娶／酷烈」等原文所無的成分。建議一律用括號或腳注，避免把推測讀成律文定說。
2. **術語統一**：結正犯／正罪、啖／噉、方便（前方便＝預備動作與意圖，非「方便企圖」的口語義）等，全書宜定一套。
3. **判準要譯清楚**：本段核心是「**恆懷護持＋誤忘 → 不犯**；**元不攝護＋汎爾而造 → 結犯**；**前有方便 → 通前結正**」三層。譯文若把「元非攝護」譯成「不懂得」、把「非即如上」譯得指涉不明，這個判準鏈就會鬆掉，建議在段末加一句譯者小結或科判提示。
