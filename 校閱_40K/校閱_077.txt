# 校閱材料　第077檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【077-0001】02_戒疏/01d_卷一上之一#86
【原文】【疏】前列「四分」，乃異他本。雖且分目，不無相濫，故重舉人，永除疑執。
【譯文】【疏文】前面列出「四分」，已經能用來區別其他的傳本了。雖然暫且界定了名稱，但仍難免會與其他部派產生混淆，所以再次標舉出祖師的大名，徹底消除後人的疑慮與偏執。

【077-0002】02_戒疏/01d_卷一上之一#87
【原文】【記】標意中。「不無相濫」者，猶慮他宗亦以「四分」為目故。
【譯文】【記文】在標明立意這部分。「難免產生混淆」是指心中依然顧慮其他部派可能也碰巧採用「四分」作為篇名的緣故。

【077-0003】02_戒疏/01d_卷一上之一#88
【原文】【疏】梵音「曇無德」、「曇摩德」與「毱多」，傳有訛僻。唐言「度之」，同云「法正」，謂法正律主，明慧卓朗，除邪倒也。又言「法護」者，能興建正法，不墜於時，即十八部中「法護部」是也。又言「法鏡」者，能照達萬法也。
【譯文】【疏文】梵音的「曇無德」、「曇摩德」與「毱多」，流傳之間存在著語音翻譯上的訛誤差異。唐朝話翻譯過來，一致稱作「法正」，意思是指法正律主，具備明利的智慧卓越超群，能夠滌除一切偏邪顛倒。又有人翻譯為「法護」，意思是能夠興旺建立正法，使之不至於在世間墜落湮沒，也就是十八個部派當中的「法護部」。還有人翻譯為「法鏡」，意思是能像明鏡般徹照了達世間的萬法。

【077-0004】02_戒疏/01d_卷一上之一#89
【原文】【記】翻名中。初列梵號。「唐」下，翻華言，三釋如文。總諸梵號，故曰「同云」。次指「十八部」者，即上座部中第九部也。或云「法藏」、「法密」，隨義不同。
【譯文】【記文】在翻譯名稱這部分。首先列出幾種不同的梵音名號。「唐朝話」以下，翻譯為漢語，共有三種解釋正如文中所見。疏文因總括了上述諸多梵號，所以說「都稱作」。接著指稱「十八部」中的歸屬，就是上座部中所分出的第九個部派。也有人翻譯為「法藏」或「法密」，都是隨順不同的含意而有不同的譯法。

【077-0009】02_戒疏/01d_卷一上之一#94
【原文】【疏】此門據行，微似賖遲，而於教本，最是急要。若不標舉，疑偽假生。戒行所詮，無宜不曉。縱是佛說，猶有憲章，況非究竟，豈妄承奉？讀者得意，不用計文。今後所列，時代為次。
【譯文】【疏文】這個章門如果單就實修實踐的行持來看，稍微顯得有些迂迴延宕，但對於掌握整個教法的根源來說，卻是最緊迫重要的一環。如果不在卷首明確標舉交代，後人就會妄生懷疑、誤以為是偽造託名之作。戒行條文中所詮顯的根本軌範，絕不容許有絲毫模糊不清。縱使同為佛陀親口所說，依然有廣律正文的繁衍演變，更何況文獻並非最為究竟極則，後人豈能盲目隨便地承接信奉呢？讀者應當領會其中的深意，不必斤斤計較於文字的枝末。以下所列出的傳承，是依照時代的先後為順序。

【077-0010】02_戒疏/01d_卷一上之一#95
【原文】【記】敘意中，四。初敘緩急。「賖遲」，猶緩慢也。在行雖緩，於教則急。「若不」下，次顯須知。古藏錄中，或無翻傳朝代人名，則入「疑」、「偽」二錄，意謂不示翻傳，將令後世謂非正譯。情由此起，教曰「假生」。教本詮行，行依教立，教源不曉，行亦浮濫，故云「戒行」等。「縱」下，舉況。「憲章」，即律廣文。雖並佛說，不無繁演，雖非究竟，義須承奉。「讀」下，屬付。「今」下，標舉。
【譯文】【記文】在敘述撰述用意的內容中，分為四個層次。首先敘述緩急之別。「賖遲」就是緩慢遲延的意思。對於當下的具體行持而言雖然顯得較為遲緩，但在考訂教法的源頭上卻極其緊迫。「如果不」以下，接著顯明必須知曉的道理。古代的大藏經目錄中，如果沒有標記翻譯傳承的朝代與譯師名字，就會被歸入「疑品」或「偽造」這兩類目錄中，意思是如果不交代清楚翻譯傳承，將會導致後世的人懷疑這不是正規傳譯的經典。後人的猜疑隨之而起，教法就會被視為「憑空捏造」。教典原本是用來指導實踐的，修行全憑教法而立，如果教理的源頭含混不清，修行就會變得空泛荒誕，所以說「戒行條文」等等。「縱使」以下，進一步舉例反襯。「憲章」就是指律藏中詳細完備的廣部正文。雖然都是佛陀的金口宣說，但在傳承中不免有詳略繁簡的演變，即便並非究竟了義，在義理上依然必須鄭重承奉。「讀者」以下，將旨趣交付囑託給後人。「從今」以下，標明論述的先後次第。

【077-0011】02_戒疏/01d_卷一上之一#96
【原文】【疏】自漢明夜夢之始，迦竺傳法已來，草創鎡基，未遑具體，眾分道俗，無受歸戒。年過二百，至魏齊帝嘉平年中，有天竺沙門曇摩迦羅，魏言「法時」，出《僧祇戒心》，方立大僧羯磨受戒。至高貴鄉公正元元年，有安息國沙門曇諦，出《曇無德部羯磨》。斯二部初在洛陽，是謂戒律之先也。餘如《鈔》說。
【譯文】【疏文】自從漢明帝夜夢金人的開端，迦葉摩騰與竺法蘭東來傳法以來，佛教在此地僅僅是草創開基，還來不及完備具體的制度規模，信眾雖然劃分出了僧人與居士的界限，卻未曾真正領受過皈依與具足戒法。這段摸索時期長達二百多年，直到曹魏齊王嘉平年間，才有天竺沙門曇摩迦羅（曹魏話翻譯為「法時」），翻譯出《僧祇戒心》，從那時起才正式確立比丘依白四羯磨受具足戒的制度。到了高貴鄉公正元元年，又有安息國的沙門曇諦，翻譯出《曇無德部羯磨》。這兩部律典最初都是在洛陽譯出推行，這可以說是中土戒律傳承的最早開端。其餘詳細歷史正如《事鈔》中所記載。

【077-0012】02_戒疏/01d_卷一上之一#97
【原文】【記】列示中。初文先敘本緣。「漢明」即後漢第二主明帝。永平五年，夜夢金人項有光明，飛行而至，且問群臣，奏言「西竺佛法將流此土」，乃遣使往逆也。「迦」即迦葉摩騰，「竺」即竺法蘭，竝中天竺人。同契遊化，齎白㲲像及梵夾經至月支，與漢使相遇，同歸漢地。「草創」言其初始，「鎡基」取其未備。「鎡」即耒耟，治田具也；「基」即田地。「眾分道俗」，釋上「草創」；「無受歸戒」，釋上「未遑」。「年」下，正敘二部之始。初明《僧祇》。「魏」即曹魏，齊帝當第四主。「迦羅」或云柯羅。「戒心」即戒本，居中統要，故喻心焉。若據迦羅行受，初依《四分羯磨》，出《僧祇戒心》，是則兼通二律。但出《羯磨》在於曇諦，故以《四分》推於諦耳。「至」下，次明《四分》。「高貴鄉公」即魏第五主廢帝之號。「曇諦」未詳華語，傳云亦善律學，正元中來遊洛陽，出《四分羯磨》。《迦羅傳》云「請胡僧出羯磨」者，即指諦也。準知迦羅行受，曇諦譯文。若據藏中，有《僧鎧羯磨》，曹魏時翻，但時不見用，故所不明。「斯」下，結示二部。《僧祇》始有《戒心》，《四分》但傳《羯磨》，未有廣律。「洛陽」即今西京。下指「《事鈔》」，見《釋相篇》。

【077-0046】02_戒疏/02a_卷一上之二#26
【原文】【疏】言「佛」者，梵云「佛陀」，或云「浮陀」、「佛駄」、「步他」、「浮圖」、「浮頭」，蓋傳音之訛耳。此無其人，以義翻之，名為「覺者」。具二義故：言「覺察」者，對煩惱障，四住如賊，唯聖覺知；言「覺悟」者，對所知障，無明如睡，唯聖獨悟。無明有二：一、迷事無明，善覺三趣；二、迷理無明，覺法實性。通而獨悟，並名為「覺」。
【譯文】【疏文】說到「佛」，梵文稱為「佛陀」，或者音譯為「浮陀」、「佛駄」、「步他」、「浮圖」、「浮頭」，大概都只是傳播翻譯時語音的差訛而已。此方中土並沒有能完全對應此等德行的人，因此依照義理翻譯，稱為「覺者」。這是因為具足了兩種義理：所謂「覺察」，是相對於煩惱障而言，四種住地惑如同賊寇，唯有聖者能夠清楚覺察了知；所謂「覺悟」，是相對於所知障而言，根本無明如同長夜大睡，唯有聖者能獨自徹悟。無明又分為兩種：第一是迷於事相的無明，佛能善巧覺照知曉善惡三趣的一切因緣；第二是迷於理體的無明，佛能徹悟諸法真實平等的體性。統貫一切而獨自覺悟，兩者都合稱為「覺」。
