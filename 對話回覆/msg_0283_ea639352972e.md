### 新抓出的 5 個隱藏程式 Bug（上一輪沒列到的）

#### 1. `qwen_local.py`：三個執行模式開關都有邏輯破洞
- **破洞 A（`QWEN_NO_WEB=1` 其實沒拔掉 `web_search` 工具）**：第 355–359 行的過濾寫了 `if _LOCAL:` 留下 `local_search`／`local_get_lines`，卻**完全忘了寫 `if NO_WEB:` 把 `web_search` 與 `web_fetch` 從 `TOOLS` 踢掉**（目前純靠提示詞拜託模型不要呼叫，每輪還白送這兩個工具的 JSON schema 佔用輸入 token）。
  - *修法*：補一行 `if NO_WEB: TOOLS = [t for t in TOOLS if not t['function']['name'].startswith('web_')]`。
- **破洞 B（`QWEN_NO_TOOLS=1` 送出 `tools=[]` 會觸發 API 400）**：開 `QWEN_NO_TOOLS=1` 時 `TOOLS = []`，但第 446 行 `payload` 依然硬帶了 `'tools': TOOLS, 'tool_choice': 'auto'`。相容 OpenAI 的端點收到空陣列 `tools=[]` 搭配 `tool_choice='auto'` 常會直接回 400 Error（可對照你第 424 行的 `_fallback_no_tools` 就沒帶這兩個欄位）。
  - *修法*：建完 `payload` 後，改成 `if TOOLS: payload['tools'] = TOOLS; payload['tool_choice'] = 'auto'`。
- **破洞 C（`審核` 跑 `QWEN_NO_CITE=1` 會把 `依據：` 殺掉）**：如果跑「審核」時沿用了 `盲翻/修訂` 的 `$env:QWEN_NO_CITE='1'`，`SYSTEM_PROMPT` 第 5 條會禁止附上任何出處，`_save_result` 還會把 `見…辭典` 跟網址刪掉——這跟 `AUDIT_PROMPT` 強制要求「`｜依據：……（須引原文、前後文或檢索實據）`」正好衝突！
  - *修法*：在文件第五節寫死：**只有 `盲翻` 與 `修訂` 設 `QWEN_NO_CITE=1`；`裁決` 與 `審核` 必須保持 `QWEN_NO_CITE=0`。**

#### 2. `local_corpus.py`：用 `work not in r['book']` 子字串比對，搜《業疏》會先撞進《業疏科》！
看第 645 行：`if work and str(work) not in r['book']: continue`
- 因為 `'業疏' in '業疏科'`、`'戒疏' in '戒疏科'` 都成立，而且 **`業疏科`／`戒疏科`（在 `BOOKS` 裡）比 `業疏`／`戒疏`（在 `EXTRA` 裡）更早載入 `LINES`**！
- 模型只要填 `work='業疏'` 搜一個疏文與科題都有的詞，前 5 筆命中會在 `業疏科` 大綱就滿額 `break`，**真正要查的《業疏》正文一筆都回不來**！
- *修法*：先建 `KNOWN_BOOKS = set(BOOKS) | set(EXTRA.keys())`；若 `work in KNOWN_BOOKS` 就用精確比對 `r['book'] != work`，只有不在已知書名內才退回子字串比對。

#### 3. `mk_review_materials.py` ＋ `mk_split_blind.py`：擴大到六部書與長段時會掉段／錯標！
1. **`資持記` 兩頭都錯標**：
   - 在 `mk_review_materials.py` 裡 `資持記` 設了 `shu=None, ji=None`，導致 `no_ji=True`、`unit='鈔文'`，把《資持記》貼上 **`■ 鈔文（原文）`／`【鈔文】`** 並套用尼鈔提示詞；
   - 在 `mk_split_blind.py` 裡 `資持記` 設了 `nicao=False`，結果 `fmt` 變成 **`【疏文】……\n【記文】……`**，硬叫模型為只有記文的《資持記》生出一欄《疏文》！
2. **中長段（141–500 字）與無配對段在兩支腳本之間有「三不管地帶」**：
   - `mk_review_materials.py` 對《業疏》《戒疏》仍限制 `max_shu=140, max_ji=260`，且只配對「疏＋記」；而 `mk_split_blind.py` 預設 `--min 500` 才切。如果 `run_all_books.py` 沒有另外覆蓋這些門檻，全書量產時 **141–500 字的疏／記、以及《戒疏》的【律】【註】與《業疏》的【序】段會全部漏掉**；
   - 更要注意：`mk_split_blind.py` 若切到 `【律】`、`【註】`、`【序】` 段落，會產出 `■ 律文（原文）`、`■ 註文（原文）`，而下游 `mk_judge_materials.py`／`mk_audit_materials.py`／`mk_revise_materials.py` 全都只認 `(疏文|記文|鈔文)`，讀進去會變成空題目！
3. **`load_pair()` 靜默跳過整卷**：`if len(a) != len(o): return None` 完全沒印任何訊息，若六部書裡有任何一卷譯文空行沒對齊，整卷會無聲消失。務必加 `print('⚠ 段落數不合，略過:', chunk, len(a), len(o))`。

#### 4. `mk_audit_materials.py` ＋ `mk_revise_materials.py`：1 個異常檔就會讓整批崩潰
- 這兩支腳本在掃整個資料夾時，只要有 **任何 1 份**回覆檔格式微偏或截斷找不到「修正後的譯文」，`col3(rt)` 就會 `raise ValueError`，**直接把整個迴圈炸斷、後面幾百份都不產了**。
