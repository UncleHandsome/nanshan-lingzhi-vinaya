# 校閱材料　第606檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【606-0001】03_業疏/05b_卷一之五#85
【原文】豈唯眾法須此十緣，對首、心念非十不得。以是非俱通，持犯冥會，竝須條貫終始，方乃引事作業。恐未閑曉，試為略指
【譯文】豈止眾僧之法必須具備這十緣，乃至對首法、心念法若不具足十緣也不能成就。因為是與非都通於一切法，持戒與犯戒的道理暗相冥契，都必須始終條理貫通，才能據事引發羯磨作業。恐怕大家尚未熟知明瞭，姑且試著簡略指出其要點。

【606-0002】03_業疏/05b_卷一之五#86
【原文】別法中，是非約緣，持犯據罪；是故成持，非故是犯。眾、別雖殊，斯義不別，故須齊具
【譯文】在別法（對首與心念）中，「是」與「非」是就因緣而言，「持」與「犯」則是依據罪相而論；具足正緣即成持戒，有違非緣便成犯戒。眾法與別法雖然有別，但這個義理並無不同，所以必須同樣具足十緣。

【606-0003】03_業疏/05b_卷一之五#87
【原文】但對首一法，用歷十緣，餘者例通取悟也。如受衣法：五大上色義加不成，即初緣也；事通兩界，即第二緣；口召對人，即第三緣；約界明集，有則對首，無則心念，即第四緣；前對相可，即第五緣；癡鈍非數，即第六緣；取欲非法，即第七緣；執衣言議，即第八緣；勅前審諦，即第九緣；答問可者，即終緣也。誰不知繁？義張所為，不可怪也
【譯文】僅就對首這一法，拿來歷對十緣，其餘的法便可依此類推而領悟。例如受持衣法：若是五大正色或上色，在義理上即便加法也不能成就，這就是第一緣（稱量）；事情通於自然界與作法界，這就是第二緣（託處）；口頭召請相對之人，這就是第三緣（集僧作相）；依照界限來明辨僧眾聚集，有人在界內則作對首法，無人則作心念法，這就是第四緣（僧集約界）；相對之人首肯答應，這就是第五緣（和合）；若相手癡呆愚鈍則不入其數，這就是第六緣（簡人）；對首法中若去取欲則屬非法，這就是第七緣（取欲）；手執衣物陳情言白，這就是第八緣（正陳情事）；敕命對方審慎諦聽，這就是第九緣（問緣）；相手回答許可，這就是最後一緣（答問）。誰會不知道這樣做很繁瑣？但這是為了在義理上鋪陳顯發其軌則，不可對此感到奇怪。

【606-0004】03_業疏/05b_卷一之五#88
【原文】對首中，初總標；「如」下別列。「前對相可」，謂許與對首，即和合也；「執衣言議」，謂能受人有所白也；「勅前審諦」，囑彼對證也；「答問可者」，所對許也。「誰」下示意
【譯文】在對首法中，起初總括標明；自「如」字以下個別羅列。「前對相可」，是指對方答應與之作對首法，這就是和合；「執衣言議」，是指受持衣法者有所陳白；「勅前審諦」，是指囑咐對方仔細作對證；「答問可者」，是指作為相對之人的對方表示贊許答應。自「誰」字以下，說明其立論的意旨。

【606-0005】03_業疏/05b_卷一之五#89
【原文】心念等法，例亦如之。且如眾法心念說戒一法以歷十緣：一、商度時節，二、審諸界相，三、作法撾擊，四、約處無人，五、觀其和別，六、自量是非，七、獨集非欲，八、具理籌水，九、激動說緣，十、如緣作業。餘者例也
【譯文】心念等法，依此比例也是如此。姑且以眾法心念說戒這一法來歷對十緣：一是商量揣度時節，二是審察各處界相，三是依作法敲擊楗槌，四是確認此處並無他人，五是觀察是否和合或別眾，六是自我衡量身心的是非（有無犯戒），七是單獨聚集而不需與欲，八是如法備齊算籌與水，九是激發自心宣說其因緣，十是依照因緣秉持作業。其餘的法皆可依此類推。

【606-0006】03_業疏/05b_卷一之五#90
【原文】心念中，「五觀和別」者，界中無人即和，有則成別；「九激動說緣」，即具儀斂念，有如問事；「十如緣作業」，謂將作未作，審慮如緣，即同答問。眾法心念可爾，但心念法如何具十？如晨朝六念：初、二同前；三、自至像前；四、知唯獨秉；五、三業無乖；六、七可知；八、審知日月身康羸等；九、十亦同。隨義意裁，無不通說
【譯文】在心念法中，「五、觀察和合或別眾」，界內沒有其他人就是和合，如果有人在界內則成為別眾；「九、激發宣說因緣」，是指端肅威儀、收斂心念，如同問事一般；「十、如緣作業」，是指將作而未作之際，審慎思慮皆如所應具之緣，就等同於答問。眾法心念可以如此，但純粹的「但心念法」又如何具足十緣？例如晨朝修持六念法：第一、第二緣與前述相同；第三緣是自己來到佛像前；第四緣是明知唯有自己一人單獨秉行；第五緣是身口意三業無有乖違；第六、第七緣其相可知；第八緣是審知當天日月時節、自身康泰或羸弱等情況；第九、第十緣也與前相同。隨順義理用意裁定，無不可融通說明。

【606-0007】03_業疏/05b_卷一之五#91
【原文】三、明先後者，法、事分二
【譯文】第三門，辨明「先後順序」，分為法之先後與事之先後兩種。

【606-0008】03_業疏/05b_卷一之五#92
【原文】諸律先和後欲，由取答緣以應欲務也；《四分》先欲後和，文如戒序及德衣法，由說欲時但言如法，知何不通？必和居前，義亦無妨，不由前後即說成敗
【譯文】其餘諸部律典都是先問和合、後索與欲，這是由於先取得答覆作何事的因緣，來與所欲辦的事務相應；《四分律》則是先索與欲、後問和合，律文如〈戒序〉及功德衣法所載，因為在說欲時只要說「如法（僧事）」，怎知不能通融？如果一定要將問和合置於前面，在義理上也沒有妨礙，不能單憑前後順序就斷定羯磨的成辦或失敗。

【606-0009】03_業疏/05b_卷一之五#93
【原文】先後法中，初引示不同。諸律先和後欲，謂問答在前，問欲在後，如《十誦》羯磨首云：「作羯磨者唱：『僧和集，欲作何事？』僧中一人應隨答云：『作某羯磨。』又唱：『不來諸比丘說欲。』說已，唱白羯磨。」《四分》先欲後和，如前所列羯磨前緣，唯出〈戒序〉及出〈德衣〉二處，故此指之。文中各顯教意：諸律則先審所為，應我所欲；《四分》則通應如法，不簡前緣。「必」下會通彼此，不必固執
【譯文】在「先後」辨「法」之中，首先引文指示各部的不同。其他諸部律是先和後欲，即問答在前，問欲在後，例如《十誦律》羯磨開頭說：「作羯磨者高唱：『僧眾和合聚集，想要作何事？』僧中一人應當隨之回答說：『作某某羯磨。』接著又唱：『未到場的諸比丘請傳達其與欲。』說欲完畢，宣唱白羯磨。」《四分律》則是先欲後和，如前面所列舉的羯磨前緣，律文只見於〈戒序〉及出〈迦絺那衣〉兩處，所以此處指出這點。文中各自顯明其立教之意：諸部律是先審問所作何事，以順應我所要表達的意願；《四分律》則是通融地回應如法之事，不論前面所問之緣。自「必」字以下，融會貫通彼此，說明不必固執成見。

【606-0012】03_業疏/05b_卷一之五#96
【原文】四、成敗者
【譯文】第四門，辨明「羯磨之成敗（成壞）」。

【606-0013】03_業疏/05b_卷一之五#97
【原文】第二、四、五、六、七五緣，事現方成，有闕名壞。何以然耶？二界分相，為法不同，少有差違，不成羯磨；餘之四緣，通是別眾，或是非數，不成人用
【譯文】第二、第四、第五、第六、第七這五緣，必須在具體事實中如實呈現才能成就，若有欠缺便稱為敗壞。何以如此呢？自然界與作法界兩界的界相劃分，因為所秉之法不同，稍有差錯違逆，羯磨便不能成就；其餘的四緣，全都會導致「別眾」，或者屬於「非僧數（不入僧數）」，不能成全人力的作用。

【606-0014】03_業疏/05b_卷一之五#98
【原文】成壞初五緣中，初通列。「何」下推釋所以：初別明第二；次合示餘四：界中不集、三業不和、體相有乖、不送心欲，竝歸別眾；六兼非數，故竝不成
