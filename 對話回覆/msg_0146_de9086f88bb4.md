提示詞已更新；20 份材料都改成**第三欄直接輸出完整修正譯文**。

## 新版第三欄

```
3. 修正後的譯文（完整輸出，可直接取代現譯）：
   - 格式固定為兩行：
     【疏文】……
     【記文】……
   - 給完整譯文，不是只給改動處；未需修改的部分照原譯抄回。
   - 不要加「（未改）」「（原文如此）」「※修正」這類標記，也不要夾註說明。
   - 譯文用自然流暢的現代中文，段落不換行。
```

## 與舊版的差別

| 項目 | 舊 | 新 |

| 第三欄 | 判定三選一（有問題／待查／可） | **完整修正譯文** |
| 產出 | 問題清單 | **可直接取代的成品** |
| 下游 | 還要人工套用 | 可以直接回貼 |

## 保留的部分

前兩欄（逐句對位、錯誤檢查）沒有更動，因為它們是讓模型先檢查再改，避免它直接亂改。
