# 校閱材料　第376檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【376-0001】資持記/04c_上三#24
【原文】第三羯磨。重提心量，益令勇進。救生護法，括束上品，盡此二句。時逼心切，不宜枝蔓；囑令直依，意在於此。加法竟時，剎那思滿，戒業成就，此處合辨無作體相。然是眾行，正出受儀。識體攝修，宗歸中卷。廣文如後，故此不論。三明教示，時節中，初科。
【譯文】在「第三番羯磨」中，要再次重申拉拔心靈的廣闊度量，使戒子的勇猛精進之心倍增。「救護一切眾生、護持如來正法」，上品戒體的無上功德完全概括在這兩句話之中。此時時機迫切、心念專一，千萬不可枝蔓雜陳、多說廢話；叮囑他直接依照教導如實觀想，用意完全就在這裡。羯磨加法圓滿結束的一剎那，受戒者的善願思惟圓滿具足，防非止惡的戒業徹底成就，在這個關頭本來應當辨析無作戒體的形相本質。然而本篇屬於大眾僧事法（眾行），正宗旨在於演述受戒儀軌。至於如何識得戒體、如何攝受修持，宗旨全歸入中卷之中。後面會有廣大的文句詳細闡述，所以在此不再重贅討論。在「第三、明了傳授教誡指示」的「時節」段落中，先看第一科。

【376-0002】資持記/04c_上三#25
【原文】隨竟記時者，此間不行影法，多用俗中年月日時；每一時中，分上中下，以定前後。《四分》中，初引制緣。不及後安居者，謂五月十七已後受者。應下，示量法。計尺寸者，若食前受，影長為上，影短為下；食後反之。《善見》中。謂令一人立於日中，齊頭影處，以脚相接；
【譯文】所謂「法事一結束隨即記錄時間」，是因為東土這裡不行量日影定時的方法，多半採用世俗的年月日和時辰；在每一個時辰當中，又細分為上初、中正、下末，用來判定戒臘的前後先後順序。《四分律》中，首先引述佛陀制戒的緣起。所謂「趕不上後安居」，是指在五月十七日以後才受具足戒的人。下文「應當……」，是展示測量日影的方法。所謂計算日影的尺寸，如果是在午食之前受戒，日影越長代表時間越早（為上），日影越短代表越接近正午（為下）；如果是在午食之後受戒，情況正好相反。《善見論》中記載：做法是讓一個人筆直立於日光之下，在頭頂陰影的端點處，用腳跟接著腳尖向前測量步數；

【376-0003】資持記/04c_上三#26
【原文】或約全脚半脚及指，隨計多少，以分上下；食前食後，同上分之。眾數多少，即指受人，而語通上下；若連上釋，即謂示時定眾不亂；若貫下釋，即謂受已同聽說相。次安置中，初示坐處。在僧下者，壇場界廣，準此可知；今時壇窄，故出界外。乃下，明說相。不必戒師者，此示古非；
【譯文】或者是以全腳掌、半腳掌乃至腳趾為單位，隨順計算測量出來的數量多寡，來區分時間的先後早晚；在午食前與午食後，同樣依照上述的原則來劃分。所謂「大眾人數的多寡」，是指受戒弟子的名額，而這句話可以通貫前後文來解釋：如果連接上文來解釋，就是指明記錄時間是為了確定大眾的戒臘次序不致紊亂；如果貫通下文來解釋，就是指受戒完畢後，大家一同聽聞傳授戒相。在接下來的「安置位次」中，首先展示就坐的位置。所謂「坐在僧眾下方」，是因為古代戒壇結界的範圍寬廣，依照這一點便可推知；現在的戒壇空間狹窄，所以受戒完畢後通常引導至結界之外就坐。下文「乃……」，是闡明宣說戒相。所謂「不必一定由主戒師宣說」，是指出古人做法的謬誤；

【376-0004】資持記/04c_上三#27
【原文】《疏》云：有人行事，十人登壇，隨人說相，一一誡語；今解羯磨加法，隨緣至三，示相誨約，任時前後，不專局也。釋疑中。前約通答，後人受時，直爾作法，故須此問，別答不須。準此通答，止被現僧；必有外來，更須別問。說相中，初科。為緣起者，《律》因比丘受具已，與本二行不淨行；
【譯文】《戒疏》說：過去有人行事，十位受戒者登上戒壇，隨著不同的人分別說戒相，一個人挨著一個人叮嚀告誡；現在正解應當是羯磨的加法儀軌，可以隨順因緣合併到三人，至於開示戒相、訓誨約束，則可以任由時間先後靈活安排，並不拘泥於非得戒師不可。在「釋疑」的段落中：前面若是針對大眾統一回答僧和，後面的人受戒時，便是直接進行羯磨作法（不再逐一問和），所以鈔中才需要提出此一疑問；如果每次受戒都是個別回答僧和，就不需要此問。依照這個道理，大眾統一作答的效力，僅限於在場的現前僧眾；如果中途有外來的僧人加入，就必須對他另外單獨詢問。在「宣說戒相」的第一科中：所謂「以此作為制戒的緣起」，是因為《律藏》記載有位比丘受了具足戒之後，又與過去世俗的妻子行不淨行；

【376-0005】資持記/04c_上三#28
【原文】諸比丘呵擯，彼云何不先語我耶，白佛因制為說四夷。《十誦》、《僧祇》，更說僧殘，是戒分故。次科為二，初敘勸。然後下，正說。初中二節，前勸護本體。初舉受隨相須勸；但下，次舉四難勸；故下，三舉上根勸。經論如此者，如〈標宗〉所引勸持等文。必須下，勸修三學。會正即三乘聖道。
【譯文】同修的比丘們呵責並擯黜他，他卻推託說「你們當初為什麼不先告訴我不能這樣做呢」，比丘們向佛陀稟白，佛陀才因此制定受戒後必須立刻宣說四波羅夷戒。《十誦律》和《僧祇律》甚至還要宣說僧殘戒，因為這都是戒律的核心分節。第二科分為兩個部分：首先是敘述並勸勉，然後下文「然後……」是正式宣說。在前面的第一節中又分為兩小節：前半段是勸導守護本具的戒體，先舉出「受戒」與「隨行持戒」必須互相依靠來勸勉；下文「但是……」接著舉出「四難」（人身難得、佛法難聞等）來勸勉；下文「所以……」第三是舉出上根利智之人的行持來勸勉。經論中所說這般道理，就像在〈標宗篇〉中所引用的勸勉持戒等文句一樣。下文「必須……」，是勸導修持戒定慧三學。所謂「會正」，就是契會三乘聖道。

【376-0006】資持記/04c_上三#29
【原文】已外雜學者，謂世俗典籍，醫卜伎藝，皆非本業，故知出家專崇道行。道行雖多，不出三學。如〈沙彌篇〉廣示學本，宜須隱括，取悟於心。下引《律》文，證須當學。至聖乃已，故云長益沙門果也。正說中。但云說相，必兼四依。言依文者，即指《律本》；但文相具委，人多誦之，故略不出。
【譯文】除此以外的雜學，是指世俗的經史典籍、醫卜星相、技藝雜術等，這些全都不是出家人的根本道業，由此可知出家應當一心專注崇尚修持道行。道行雖然萬殊，總歸離不開戒定慧三學。正如〈沙彌篇〉中廣泛開示的修學根本一樣，應當加以涵融體會、融會貫通，求得自心真正的省悟。下文引用《律藏》的經文，證明理應精進修學，直到證得無漏聖果才算圓滿止境，所以說是「長久增長沙門的殊勝道果」。在「正式宣說」的段落中：只要提到宣說戒相，必定同時包含宣說「四依法」。所謂「依據律文」，就是指《四分律本》；只因為律文相貌詳盡周全，多數人都已能背誦，所以這裡稍微省略不再全部列出。

【376-0007】資持記/04c_上三#30
【原文】然今備載《隨機羯磨》，須者尋誦，此更不引；寫之甚易，不欲兩繁。既說相已，次說四依。受淨中。初明受衣等者，此猶同古；《戒壇經》云：諸部並在問難前，今時在受戒後；無文所出，不足行用。又《疏》云：安有受後方事持衣，相越常模，故乖正教。若下，明教淨施。已未兩相，尋文可委。法附中。
【譯文】然而如今這些內容都完備收錄在《隨機羯磨》之中，需要的人可以自行查閱誦持，此處便不再重複引錄；抄寫一遍固然很容易，但不想讓全書產生兩處重複繁瑣的弊病。宣說完戒相之後，接著宣說四依法。在「受持與淨施」的段落中，首先說明受持三衣等法，這依然是承襲古老傳統；《戒壇經》說：各部律典的受衣缽都在審問遮難之前，現今的風氣卻改在受戒之後；這在律文中毫無根據，不足以作為如法施行的依據。另外《戒疏》也說：哪有受了具足戒之後才去忙著受持三衣的道理，這種做法完全逾越了常規模範，所以是違背佛陀正教的。下文「若……」，是說明教導淨施的方法。包括已經說淨和未曾說淨的兩種行相，細讀律文就可以詳盡明了。在「附錄律法」的段落中：

【376-0008】資持記/04c_上三#31
【原文】既受具戒，即須六念，憶戒緣身。師當先授。因附此篇。牒章中，注明所出。若準《四分》，衣食起觀，俯仰威儀，常爾一心，念除諸蓋。此據通相，觀行尤難。今此《僧祇》，別指六緣，制令繫意。近而可別，簡而易成。故引彼文，通成今用。初念中，前示念法。此下，顯意有二，上約憶戒。下據異俗。
