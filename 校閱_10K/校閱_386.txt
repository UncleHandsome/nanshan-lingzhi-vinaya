# 校閱材料　第386檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【386-0001】02_戒疏/03b_卷一下之一#151
【原文】【記】答中。初句總示。下引五解，前四明異，後一顯同。初約所為自他不同。「前緣」即法所被事。「緣成」即通十種方便。「隨白問」者，謂單白羯磨並問忍可。意專被事，故云「終為成法」。無勞撿淨，故云「不別舉」也。
【譯文】【記文】回答章節中。首句作總括開示。下文引出五種解釋，前四種在說明兩者的相異之處，最後一種在顯發共通點。第一種是依據「所成辦目的屬於自利或利他」的不同來劃分。「前緣」是指羯磨法事所要利益處理的特定對象與事件。「緣成」是通貫十種受戒或處分的方便要件。「隨白問」是指單白與羯磨（白二、白四羯磨）都發問徵求忍可。其意旨全在於成辦事件本身，所以說「終為成法」。既然無須勞師動眾逐一檢驗清淨，所以說「不另外提出檢問」。


【386-0002】02_戒疏/03c_卷一下之一#1
【原文】【疏】又解：「說戒僧別兩舉，說聽必約清修。羯磨多為別緣，僧成即堪御法。」
【譯文】【疏文】另一種解釋說：「說戒時，大眾僧法與個人私行必須同時舉揚檢點，說戒與聽戒都必須限定在清淨修持者之間進行。而僧團法事（羯磨）多半是為了解決特定的個別因緣，只要僧團合法成立，就足以執行法事。」

【386-0003】02_戒疏/03c_卷一下之一#2
【原文】【記】次解。約眾法、別行，單具往分。「別」即自行。說戒為僧，兼別須問；羯磨為別，單眾不須。
【譯文】【記文】這段文字是第二種解釋。這是就全體僧團的集體法事（眾法）與個人的單獨行持（別行）是兼具還是單一來加以區分。「別行」就是指個人的行持。說戒是為了整個僧團，但也兼顧個人的行持，所以必須審問清淨與否；僧團法事只是為了解決特定事件，只要僧團人數合乎法定要求即可，不需要審問個人。

【386-0004】02_戒疏/03c_卷一下之一#3
【原文】【疏】又解：「兩法在僧，俱須行淨。說戒制問，為清行染之人；羯磨不制，法通純雜之士。如僧殘行法，開停為他，明知罪未出也。聞戒知犯，必開默露，明知說被淨也。」
【譯文】【疏文】又有一種解釋說：「這兩種法事都在僧團中進行，按理都應當行持清淨。但說戒時規定必須審問，是為了查出並清滌行為染污的人；僧團法事不規定審問，是因為該法事通於純淨者與染污者共同參與。例如僧殘罪的行法，允許為他人暫停進行，由此清楚知道他的罪過尚未徹底解除。而聽聞戒律時若察覺自己犯戒，就必須開口坦白發露、不得隱瞞默然，由此清楚知道說戒只涵蓋身心清淨之人。」

【386-0005】02_戒疏/03c_卷一下之一#4
【原文】【記】三約淨穢，通局不同。初二句通示，「說」下，別分。「如」下，引證。初證羯磨通雜，「聞」下，證說戒局淨。
【譯文】【記文】這是第三種解釋，從「清淨」與「染污」是普遍適用還是有所局限的差異來說明。前兩句是總體提示；從「說戒」往後，是分別剖析；從「例如」往後，是引文以為證。前半段證明僧團法事可通於混雜染污之人，後半段「聞戒」往後，則證明說戒局限於完全清淨之人。

【386-0006】02_戒疏/03c_卷一下之一#5
【原文】【疏】又解：「羯磨所為在事也，說戒所為在犯也。『有犯不得聞戒』，斯明證也。故說戒之作，為兩種人：持者為能清，犯者為所清。若知有犯，即須遮舉懺洗令淨，方聞後戒。乃至《律》文見犯不說，經二十年。羯磨不爾，標舉時事。三根五法，相圓無染，即成僧用，故不制問。」
【譯文】【疏文】還有一種解釋說：「僧團法事所著重的是特定事務，說戒所著重的是防範與止息犯戒。『若有犯戒者，不得聽聞戒律』，這就是明確的證明。因此舉行說戒，是為了兩種人：持戒清淨的人屬於能引導清淨者，犯戒的人屬於被清滌的對象。如果持戒者知道有人犯戒，就必須立即遮止其聽戒、舉發其罪過並令其懺悔洗滌罪垢而恢復清淨，然後才能聽聞後續的戒條。甚至《律藏》記載，看見大眾中有犯戒者便不宣說戒本，佛陀長達二十年不說戒。僧團法事則不同，它只是標明並處理當下的特定事務。只要具備『三根清淨』與『五法現前』，法事的儀相圓滿無缺、不被染污，就能成就僧團的法定功用，所以不需要規定審問。」

【386-0007】02_戒疏/03c_卷一下之一#6
【原文】【記】四明立教所為，罪事差別。初雙標，「有」下，別釋。初釋為犯有四：初據聖制證；「故」下，約所為證；「若」下，引遮舉證；「乃」下，引廢說證，即《僧祇》比丘鬪諍緣也。「羯磨」下，次釋為事。「相圓」對「五法」，「無染」對「三根」。「五法」即五現前。此謂說戒必取體淨，有犯不開，故須責問；羯磨但取相淨，便成僧法，故不勞問。
【譯文】【記文】這是第四種解釋，說明設立教法的根本目的，在於「治罪」與「辦事」的差別。前兩句同時標出兩者，從「若有犯戒」往後分別解釋。先解釋著重於「犯戒」方面有四點：首先依據佛陀的聖制為證；「因此」往後，就其教化對象為證；「如果知道」往後，引用制止與檢舉為證；「甚至」往後，引用廢止說戒的典故為證，也就是《僧祇律》中比丘紛爭鬥亂的因緣。從「僧團法事」往後，接著解釋著重於「辦事」方面。「法相圓滿」對應「五法」，「無染污」對應「三根」。「五法」就是指五種現前。這段話的意思是說，說戒必須要求實體本質徹底清淨，有犯戒者絕不通融，所以必須責問；僧團法事只要儀軌相貌清淨，就能成就僧團的法定效力，所以無須費事審問。

【386-0013】02_戒疏/03c_卷一下之一#12
【原文】【疏】言「淨故默」者，眾非口呈行淨，繁亂伐德成勞，但默便表答辭也。言「是事持」者，淨行得聞正戒，機教相應，定慧由斯成剋，理須持奉故也。「事」即淨行，如文可知。
【譯文】【疏文】經文說「因清淨故默然」的意思是，大眾不用以口頭呈報自己行持清淨，因為（若各各開口呈報）便會繁瑣喧亂、損害德操、徒增疲勞，因此只要保持沉默，就代表給予答覆。經文說「這件事應當這樣受持」的意思是，唯有行持清淨者才能聽聞這清淨的正戒，根機與教法相應，定力和智慧才能藉此修行成就，在道理上應當全力奉持受奉。「這件事」就是指清淨行持，依據經文脈絡便可明瞭。

【386-0014】02_戒疏/03c_卷一下之一#13
【原文】【記】釋勸持中。初釋默然。「繁亂」乖儀，「伐德」非理。默然自表，則離諸過。次釋是事等。初敘勸持，「事」下，點文相。「事」即戒相。以人稟教，指教歸人，故云「淨行」。《經》中「如是」二字，指法之詞，即指後文也。
【譯文】【記文】這是解釋勸勉大眾受持的內容。前半段解釋「默然」。「繁瑣雜亂」違背儀軌，「損害德操」不合道理。以保持沉默自然表態，就能遠離各種過失。後半段解釋「這件事應當受持」等語。首先敘述勸勉受持的意思；從「這件事」往後，點出文句的意涵。「事」就是指戒相。因為是人領受教法，將教法落實歸結到人身上，所以稱為「清淨行持」。經文中的「如是（這件事應當這樣）」兩個字，是指陳法義的詞語，也就是指後面的戒文。
