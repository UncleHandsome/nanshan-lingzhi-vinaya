整體看，這十幾則譯文的文義掌握大致不差（如「補佛處」「料非庸流」「慢幢」「旦＝但」等處都處理得對），主要問題集中在**術語誤讀／前後不一致**，以及幾處**生硬或增譯**。以下按嚴重度分項說明。

---

## 一、實質性問題（建議必改）

### 1. 「別人」不等於「個人」（#106、#109、#110）
- #106「準律說欲不開**別人**」→ 譯「並不對**個人**開許」
- #109「**別人**力弱」→ 譯「**個人**的力量微弱」

「別人」是業疏的固定術語，指**行別法者**（對首的二～三人、心念的一人），與「僧（四人以上）」相對，並非單指一個人。#110 元照自己就說「別下次明**對首**為別」，可證。
譯成「個人」會直接與 #105「三人已下不得受欲」矛盾（變成只有單人不得與欲）。

**建議**：「別法之人（對首、心念）」或「行別法者」。#110「旦表淨故」宜作「只是各各自表己淨」。

### 2. 「四方（僧）」不宜改寫成「十方」（#109、#112）
- #109「故白說戒通**四方**故」→ 譯「通達於**十方大眾**」
- #112「此即向**四方僧**發露」→ 譯「向**十方僧**發露」

「四方僧」是與「現前僧」相對的律學專名（四方僧物／現前僧物），#110「眾法通收，本攝僧故」正是說僧法通攝四方僧。改成「十方」會丟掉這個對照，且兩處都改，屬系統性偏移。
**建議**：一律保留「四方僧」；#109 可作「所以作白說戒之法通及於四方僧」。

### 3. #101「眾具」譯成「僧眾的**法具**與條件」可疑
「眾具」在此大概率是「眾（僧）具（足）」——即成辦眾法所需的人數、和合等條件（參 #103「此**具僧**也」、#104「滿四白說，屬前僧法」，一路都在講人數）。「法具」（法器、資具）於此無著落。
**建議**：「先辨明成辦眾法所須的條件（僧眾具足）」；若上下文另有資具之義，請再核對科判，但「法具」一詞宜刪。

### 4. #102「望剎為居」譯成「即可**安居**」——術語誤用
「安居」是結夏安居的專名，與「望剎為居（望見寺剎就以之為住處）」完全不同，且此處正要說明僧人**無定住**，用「安居」反而自相矛盾。
**建議**：「望見寺剎便作為住處」。

### 5. #105「總集各說」與 #106「界中不集」前後打架
- #105 譯：「僧眾須**全體集合**、各各說淨」
- #106 譯：「界內僧眾**並未全體集會**罷了」

元照釋「法別眾」為「對首如法，界中不集耳」——正因為別法本不須盡界集僧（不來者亦無與欲之制），所以現前者須同集、各各自說。#105 的「全體集合」若指「界內僧全集」，就與 #106 衝突。
**建議**：#105 改為「這是別法，界內之眾（本）不盡集，故須現前同集、各各說淨」；「三人已下」宜明寫「三人乃至一人（含三人）」，避免現代漢語「以下」的歧義。「與欲」也宜加短注（把自己的清淨／同意託他人代說）。

### 6. #103、#104「白說戒」未加解釋
「白」＝單白羯磨（宣告）。白話譯文直接照抄「作白說戒」，讀者無從理解。
**建議**：「應先作白（單白宣告）而後說戒」；#103「此具僧也」宜作「這就具足了僧法（眾法）的人數」，比「具備僧團大眾的資格」貼切。

## 二、用詞生硬／增譯（逐則）

| 出處 | 譯文 | 問題與建議 |
|---|---|---|
| #101 | 「前前後後各種飲食一律供給周全」 | 「前後諸食」宜作「（正餐）前後的種種飲食」，「前前後後」語意含混 |
| #101 | 「四事**如法**供給」 | 「如法」為增譯，可刪 |
| #101 | 「能廣泛**辨析通達**諸法」 | 「廣分別諸法」重在**廣為解說分別**（能為人說法），可作「能廣為分別解說諸法」 |
| #102 | 「就去**乞討**」 | 語感偏貶，作「就去乞食」 |
| #107 | 「在**室內**以香水灑地」 | 「內」承上指**院內**，未必室內 |
| #107、#108 | 「散布**名花**香料」／「散**名花**」 | 「散華香」即散花、散香，「名花」是無據的增譯 |
| #107 | 「所以律中要莊嚴說戒堂」 | 語意是「這就是（四分）律中所說的莊嚴說戒堂」，非因果勸令 |
| #108 | 「啟發**動轉**眾人之心」 | 「動轉」不成詞；作「啟發感動人心」或「激發大眾敬重之心」 |
| #109 | 「僧法在位次上**威權重大**」 | 「威權」政治味太重；作「僧法的法位尊勝（力用強）」。「成辨」＝成辦 |
| #109 | 「以此順應前述僧法之制」 | 依 #110「上教即僧法」可通，但宜簡作「以相應於上文僧法之教」，並保留疑義 |
| #110 | 「大眾僧法**通體統收**」 | 生硬難解；作「僧法能通攝（四方僧眾）」 |
| #111 | 「**如律文所述**即可明白」 | 「如文可知」是「看（上）文自明，不須別釋」，「文」指上文羯磨／疏文，未必是律文 |
| #112 | 「應當心念口言三番陳說布薩」 | 術語未譯；作「應當心中憶念、口中出聲，三遍說布薩（說戒）」 |
| #112 | 「也**以此為基準而作法**」 | 太空泛；依 #113 應作「也準照此法（先發露、後說戒）」 |
| #113 | 「自『此』以下**會合**《五百問經》」 | 「合」是引來印證；作「引《五百問經》相印證」 |
| #113 | 「在等待大眾人數不足之時」 | 語意扭曲；作「等待僧眾而人數仍不足（不滿四人）時」 |
| #114 | 「無不能夠折伏**高傲的慢幢**」 | 可保留譬喻但稍加注：「折伏我慢高幢」；「分傾煩惱」譯「分分傾除煩惱」即可，「傾覆摧破」略贅 |

## 三、建議統一的術語

- 僧法／眾法 ↔ 別法（對首、心念）；**別人＝行別法者**
- **四方僧**（勿改十方）／現前僧
- 與欲（受欲）＝託付清淨、代為傳達；布薩羯磨＝懺罪（依元照釋）；木叉會坐＝說戒
- 白＝單白（宣告）；心念口言＝心憶口說

## 四、原文校勘小注（可一併處理）

1. #107、#112 開頭作「僧祇》」，缺前書名號，宜補「《摩訶僧祇律》」。
2. #110「**旦**表淨故」當為「**但**」之訛（譯文已按「但」處理，正確，可出校）。
3. #109「成**辨**」＝成辦；#105「三人**已**下」＝以下。
4. #114「懺說戒相」宜斷為「懺、說戒相，由常作故……」，譯文理解無誤。

**小結**：最需要動的是第 1～5 項（別人／四方僧／眾具／安居／總集與界中不集的矛盾），這些會影響讀者對「僧法—別法」制度的理解；其餘多屬潤色與去除增譯。若你願意，我可以直接把 #101～#114 依上述建議改寫成一份修訂版譯文。
