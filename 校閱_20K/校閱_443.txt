# 校閱材料　第443檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【443-0001】資持記/02a_上一下#52
【原文】即同《遺教》喻堤塘也，謂四禪四空定及餘無漏諸禪三昧。戒為郭者，郭謂外城。三入眾者，即屬戒學；謂羯磨說戒二種僧中，具戒清淨方可預故。下二句結勸。《解脫論》，第二〈分別戒品〉。指令尋之，今為略引。彼云：若人有戒。為有戒故，成就無畏；
【譯文】這就如同《遺教經》把禪定比喻為防護水流的堤防一樣，是指四禪、四空定以及其餘一切無漏諸禪定三昧；以戒律作為「郭」，「郭」是指外城的防禦城牆。第三項談到「進入大眾」，這屬於戒學的範疇；也就是在舉行羯磨法與說戒這兩種僧團集會中，必須具足戒體且操行清淨，才可以參與；下面兩句是總結勸勉。《解脫道論》第二卷〈分別戒品〉，鈔文中指示讀者自行查尋，現在為大家簡略摘引；那部論說：如果人能具足戒律，因為有戒律的緣故，便能成就無所畏懼的德能；

【443-0002】資持記/02a_上一下#53
【原文】榮顯親友，聖所憐愍，是親友依，是善莊嚴，是領諸行，是功德處，是供養處，是可貴同學處，於諸善法不畏不退，成就一切意願清淨，雖死不忘，成伏解脫樂方便，如是無邊戒功德。《毘婆沙論》，初中。初句牒所受，下列四義。尸羅，梵言，此翻為戒。今以梵語，猶含多義，故反釋之。
【譯文】能讓親族朋友感到光榮顯耀，受諸佛聖賢所憐憫愛護，是親友的依靠，是最善妙的莊嚴，是統領一切修行的綱領，是一切功德的所聚之處，是值得受人供養之處，是同修道友所尊貴敬重之處；在一切善法中不再畏懼退轉，能圓滿成就一切清淨的善願；即使肉身死亡戒德也不會忘失，能成為降伏煩惱、獲致解脫安樂的善巧方便，戒律具有如此無量無邊的功德。《阿毘曇毘婆沙論》中，第一段裡：第一句標示出所受持之法，下面列舉四種義理；「尸羅」是梵語，此地翻譯為「戒」；現在因為梵語一詞涵蓋了多種深義，所以反過來進行訓釋；

【443-0003】資持記/02a_上一下#54
【原文】次科，初明尸羅。義含九種，故須皆以尸羅二字貫之。冷、池、纓、鏡、頭，此五從喻；夢、習、定、勢，此四從法。又第四明生定，鏡頭喻發慧，餘六當體是戒。又六中，初明體，二是所感，三即牽行，池謂滅惑，纓謂德彰，勢謂功勝。破戒熱是因中結業，三惡熱是果上受苦。
【譯文】下一科首先說明「尸羅」的涵義，它內含九種深意，所以每一種都應當貫穿「尸羅」這兩個字。清涼、水池、瓔珞、明鏡、頭顱，這五項是順著譬喻來說明；夢想、習性、定力、威勢，這四項是順著法義本身來說明。又第四項說明能生起禪定，明鏡與頭顱比喻能啟發智慧，其餘六項就當體而言純粹是指戒律。又在這六項之中，第一項闡明戒體，第二項是戒法所感得的善境，第三項是能牽引後續善行，水池是指滅除煩惱惑業，瓔珞是指道德彰顯於外，威勢是指功德殊勝超拔；破戒的熱惱是因地造作惡業所致，三惡道的熱惱則是果報上感受極苦；

【443-0004】資持記/02a_上一下#55
【原文】纓絡者，論明世纓老少中年有好不好，戒纓則常好。如鏡者，鏡明則像現；戒淨，無我理顯。無我字，祖師加之。威勢中，初舉聖以明。如來德懾魔軍，威伏外道；若親在眾，破僧不成；強狠眾生，見即歸命。餘下，引事以證。論云：罽賓國有龍名阿利那，受性暴惡；住處近僧伽藍，數為暴害。
【譯文】所謂瓔珞，論中說明世俗的珠寶瓔珞，人在老年、少壯或中年配戴各有合適與不合適之處，而戒律的瓔珞則無論何時配戴都永遠美好莊嚴。好比明鏡，鏡面明亮影子自然顯現；戒行清淨，無我的真實妙理自然彰顯；「無我」這兩個字，是祖師（道宣律師）特別加上去的。在威勢的涵義中，先舉出聖人來說明：如來的威德能震懾魔軍、威伏外道；如果佛陀親自在大眾之中，旁人便無法破壞僧團的和合；性格頑劣強悍的眾生，一見到佛陀立刻歸依服從；「其餘」以下，引用實際事例來作證明：論中說罽賓國有一條龍名叫阿利那，生性殘暴兇惡；牠居住的地方靠近僧伽藍寺院，多次興風作浪危害人畜；

【443-0005】資持記/02a_上一下#56
【原文】時有五百羅漢共集，以禪定神力而不能遣；後有一人不入禪定，直彈指語言：賢善遠此處去，龍即遠去。諸羅漢問之。彼云：我不以禪定力，直以謹慎於戒；守護輕戒，猶如重禁。文中但以下，即引彼答，但束其詞耳。如頭者，頭則具納六塵，戒則總收眾善，故以喻焉。
【譯文】當時有五百位羅漢共同聚集，運轉禪定神通力量卻無法把牠驅逐走；後來有一位僧人並未入定，只是彈指對那條龍說道：「仁慈賢善的龍啊，請遠離此處！」那條龍立刻乖乖遠走離開；諸位羅漢驚訝地詢問他；那位僧人回答說：「我並不是憑藉禪定的力量，只是在戒律上極其謹慎持守；守護最細微的輕戒，就像守護根本重戒一樣毫無違犯。」鈔文中的「但以」以下，就是引用那位僧人的回答，只是把文字凝鍊精簡罷了。好比頭顱，頭顱完整收納了六根面對六塵的知覺，戒律則總體收攝了一切善法，所以用頭顱作比喻；

【443-0006】資持記/02a_上一下#57
【原文】論中備對六塵，今舉初後，略其中間，故云乃至。今引足之，謂聞名身等義，嗅覺意華〔即七覺支〕，甞出離無事寂靜三菩提味〔三菩提翻正覺〕，覺禪定解脫等觸。苦是三界果相，故如色也。色陰等者，即餘四陰，論云：知總相別相。〔總即心色。五陰則色總心別，十二入則心總色別，十八界心色俱別。〕二守信者。
【譯文】論典之中完整地一一對應了六塵，現在這部書只列舉了最初與最後一項，略去了中間的四項，所以用了「乃至」二字；現在我們將它完整補足，也就是：耳朵聽聞名相言句等深義，鼻子嗅到覺意之華（即七覺支）的芬芳，舌頭品嚐出離無為、寂靜至極的三菩提之味（三菩提翻為正覺），身體覺知禪定解脫等殊勝觸感。苦是三界流轉的果報表相，所以比喻為色塵；「色陰」等項，是指受、想、行、識其餘四陰，論中說：能知曉總相與別相（總相是指心法與色法；若就五陰而言，色陰是總相，其餘四陰心法是別相；若就十二入而言，意入心法是總相，其餘十一入色法是別相；若就十八界而言，心法與色法各自分別）。第二「守信」的意思；

【443-0007】資持記/02a_上一下#58
【原文】以違本受，則為無信。三行，四器，二並從喻。覆釋中。瞿沙，《師資傳》云：五十二餘師之數，善能說法。彼以別義釋上尸羅，故論取之。如下，舉喻。行下，合法。即同戒本護戒足也。通前共為十義。大乘經，《華嚴》有多譯。今引晉譯六十卷者。即第八〈明法品〉文，文有四段。
【譯文】是因為違背最初受戒的誓願，就是失去信用。第三「行持」、第四「器皿」，這兩者都是順著譬喻來立名。在重複解釋的段落中，「瞿沙」法師，《法門師資傳》記載：是五十二位餘部論師之一，極為善於演說法義；他用另外的意涵來解釋上面的「尸羅」，所以論典採納了他的見解；「如」字以下提出譬喻；「行」字以下配合法義，這就如同戒本中所說要守護雙足一樣；加上前面的涵義總共成為十種深意。大乘經典之中，《華嚴經》有許多種譯本；現在引用的是東晉時期翻譯的六十卷本；這正是出自第八卷〈明法品〉的文字，這段經文包含四個層次；

【443-0008】資持記/02a_上一下#59
【原文】彼云：菩薩摩訶薩教化眾生發菩提心，是故能令佛寶不斷。開示甚深諸妙法藏，是故能令法寶不斷。具足受持威儀教法，是故能令僧寶不斷。〔此初段也。〕復次，悉能讚歎一切大願，是故能令佛寶不斷。分別解說十二緣起，是故能令法寶不斷；行六和敬，是故能令僧寶不斷。〔即第二段。
【譯文】那段經文說：菩薩摩訶薩教化眾生發起無上菩提心，因此能夠讓佛寶相續不斷；向眾生開示甚深微妙的法藏，因此能夠讓法寶相續不斷；具足受持威儀教法，因此能夠讓僧寶相續不斷（這是第一層次）；再次，全都能讚歎一切廣大誓願，因此能夠讓佛寶相續不斷；分別解說十二因緣甚深妙理，因此能夠讓法寶相續不斷；奉行身和同住、口和無諍等六和敬，因此能夠讓僧寶相續不斷（這是第二層次）；

【443-0009】資持記/02a_上一下#60
【原文】復次，下佛種子於眾生田，生正覺芽，是故能令佛寶不斷。不惜身命護持正法，是故能令法寶不斷。善御大眾，心不憂悔，是故能令僧寶不斷。〔即第三段。〕今鈔上五句竝摘僧寶中文。初二句明別行，次句即眾行，後二句明攝眾。行必依法，故無憂悔。去來已下，即第四段總結中文。

【原文】我亦下，遮其受經。所以然者。經明眾生佛性，如雜血乳；停搆煎煖，乃出醍醐。佛性亦爾，為煩惱雜；三學修治，漸至佛果。欲斷煩惱，先須止業。止業之要，豈過戒律。今時濫染大乘，便言不拘不檢，無持無犯，何善何罪。師徒傳妄，作惡無窮。又云：持戒人天果報。請詳佛語，宜息邪情。

【原文】大利如上二經。一切下，二敘功勸。諸德根及下善法處，同前大地喻也。出家要者，同前《華嚴》文也。如下，舉世二物，喻令護惜。又下，三約無戒損失勸，上舉三喻。若下，法合。好果語通五乘，對前大利，須指佛果。若棄下，四舉無益苦行勸。文列諸外道法。
【譯文】所謂大利益，如同上述兩部經典所言。「一切」以下，第二段敘述持戒功德來勸勉。「諸德之根」以及下面的「善法居處」，與前面將戒比喻為大地的意義相同。「出家的要道」，與前面《華嚴經》的經文義理相同。「如」字以下，舉出世間的兩種事物，作為比喻讓人好好愛護珍惜。「又」字以下，第三段從缺乏戒律所招致的損失來勸勉，上面先舉出三種比喻。「若」字以下，將比喻與法理相結合。結出美好果報這句話通於五乘，但對應前文所說的大利益，這裡必須特指成佛之果。「若棄」以下，第四段舉出無益的苦行來勸勉。經文中列舉了各種外道的修法。
