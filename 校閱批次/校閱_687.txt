# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【687-0001】資持記/16c_下四#46
【原文】結中，初句指前。次二句示問意。《善見》下，引證。何法，即依何部受戒。更問誰是和尚闍梨，故云等也。第四通簡中，初科。羯磨不在數者，以作眾法，必簡除故。說恣不得別者，望本眾為言。約界同僧者，文指自然，準須二界；作法一界，依僧分齊；以眾別二法，必託界故。
【譯文】在總結的文字中，第一句指涉前面所列的數目法義。接續的兩句指明盤問沙彌的深意所在。「善見」字以下，引用律論作為佐證。所謂「依何法」，指的就是依止哪一部律典傳受戒法。還要更進一步詢問誰是傳戒和尚、誰是引導的阿闍梨，所以用「等」字概括。在第四項全面揀別簡擇的法規中，第一個小段落。沙彌之所以在羯磨作法時「不算入合法僧數」，是因為如法僧事的運作，必定要嚴格剔除未受具足戒者。在說戒與自恣等大眾僧事中「不得另行獨立舉行」，是相對於比丘僧眾本體而言。在結界範圍內與大僧相同，律文指的是天然的「自然界」，依規矩必須具備兩種結界；正式作法的界限只有一種，完全依照大僧劃定的界限範疇；因為無論是大眾僧事或個別僧事，都必須依託同一個結界才能成就之故。

【687-0003】資持記/16c_下四#47
【原文】明下，引證。彼有十七別住，如〈結界〉引。尼等下眾皆有別住，故云乃至。別界，謂各有住處，非作法結也。別施，謂施主標意施何等人，不通餘眾故。次科，初標古非。今下，顯正義。然法多別。自恣僧法，沙彌自恣，大小相對。非時入聚，通告下眾。尼白入寺，則對比丘。《五百問》中。
【譯文】在「明」字以下，引用文獻佐證。該律載有十七種個別安住的特殊規定，如同〈結界篇〉中所引用的內容。比丘尼等下位三眾也都有各自獨立安住的房舍結界，所以用「乃至」予以涵蓋。所謂「別界」，是指各眾弟子各自有其合法的居處，並不是指另外正式作法所結的僧界。所謂「別施」，是指供養施主在布施時明確指定要供養哪一類僧眾，其財物飲食便不得流通挪用到其他僧眾身上。下一個小段落，首先指出古德主張的錯誤。在「今」字以下，闡明律宗的正宗要義。然而法規的運作有許多差別。自恣是屬於大僧大眾之法，沙彌若要行自恣，必須是大僧與小沙彌相對而行。在非規定時間欲進入聚落村莊，只需向同住的下位僧眾通告即可。若是比丘尼要作白進入寺院，則必須親自對著比丘陳白。《五百問》律論中。

【687-0004】資持記/16c_下四#48
【原文】開無本眾，或是不通心念之法。古有所據，故許存之。別示，別法中，初科，前示受持。當字去呼，皆言當者，非正衣故。唯下，出受法。受戒，即十戒；無犯，取行淨。次科，初受鉢及坐具法。三眾俱同。次明百一。若下，三明說淨。道俗二主，衣寶兩淨，與僧無異。三中，初明捨墮。
【譯文】開許在身邊沒有同眾的情形下，或許是不通融單純只在心念中作意自恣之法。古德的見解並非毫無依據，所以在此允許保留其說法。在逐項辨明個別行法的章節中，第一個小段落，前面先指明如何受持法服。「當」這個字應當讀作去聲，之所以一概稱呼為「當」，是因為沙彌法衣不是正規大僧袈裟的緣故。在「唯」字以下，說明正式受持的法規。所謂「受戒」，指的就是納受十戒；所謂「無犯」，是要求受持之後戒行必須純潔無染。下一個小段落，首先說明受持鐵鉢與尼師壇坐具的儀軌法式。這在沙彌、沙彌尼等下位三眾是完全相同的。接著說明如何受持百一等長物法服。在「若」字以下，第三項說明如何進行「說淨」程序。出家與在家兩位物主，法衣與金銀兩類長物的說淨儀軌，與大僧的做法完全沒有兩樣。在第三項中，首先說明如何捨除墮落之罪。

【687-0005】01_行事鈔/12b_卷下之四#39
【原文】先明對首持二衣法。《薩婆多》：沙彌受戒已，應持上下二衣，一當欝多羅僧，二當安陀會。財體是非、作之方法、失衣分齊，一同僧中，唯受持少別。應對一受戒無犯沙彌，手執上衣云：「長老一心念！我某甲沙彌，此漫欝多羅僧受持。」受持鉢法、受持坐具，一同僧法，唯改沙彌名為異；乃至尼中二眾，亦同持之。百一供具，例同無異。若畜長衣，請二衣施主，亦同僧法；說淨之本亦同；藥鉢準此。若得錢寶，《薩婆多》亦請白衣為之。以沙彌戒中，正同僧故，不得自畜。若犯長衣鉢等，皆犯捨墮；懺罪一同僧法，界內集人作之；不受戒者，亦無別眾；文同大僧，唯以突吉羅一罪為別，至時改之。若犯提舍已下，上及僧殘，並須懺悔；有覆須治，唯以吉羅為定。若波羅夷，律云：三眾突吉羅，滅擯。餘有安居、受日等事，例同大僧。《十誦》：制五眾安居，五眾受日。《四分》：三時遊行戒，三眾亦結罪。故須知之。
【譯文】首先說明沙彌以「對首法」受持二衣的儀軌。《薩婆多論》說：沙彌受戒之後，應當受持上下一共兩件法衣，一件相當於欝多羅僧（七條衣、中價衣），另一件相當於安陀會（五條衣、下衣）。這兩件衣的布料材質合法與否、縫製的方法、喪失法衣的界限規定，完全與比丘僧中一致，唯有在宣讀受持文詞時略有差別。沙彌應當面對一位已經受戒且無犯戒瑕疵的清淨沙彌，手裡拿著上衣說道：「長老一心專念！我某甲沙彌，受持此件漫欝多羅僧。」受持鉢具之法、受持坐具尼師壇之法，完全與比丘僧法一致，只將名號改稱沙彌為差異；乃至尼部中的下二眾（式叉摩那、沙彌尼），也是同樣受持。其餘「百一供身資具」，全部照此比照辦理而毫無二致。如果蓄存多餘的長衣，請示「二衣施主」的儀軌也同比丘僧法相同；「說淨」的法本依據也是一樣；蓄存多餘的藥物與鉢具也比照辦理。如果獲得金銀錢寶，《薩婆多論》規定同樣要請俗人白衣代為管理說淨。因為在沙彌戒條中，這一項正與比丘僧相同，自己絕不得私自蓄藏錢寶。如果違犯了蓄存長衣、多餘長鉢等過失，都犯捨墮罪（尼薩耆波逸提）；懺除罪過的方法完全與僧法相同，必須在同一結界內集齊人員來作羯磨；未受具足戒的沙彌，彼此集會亦不構成破僧之別眾罪；懺罪文詞雖然同於大僧，唯獨罪名一律改判為「突吉羅」（輕垢罪），臨場作法時將罪名相應更改即可。如果違犯了提舍尼以下的罪，或者向上乃至違犯僧殘罪，都必須隨犯隨懺悔；若有覆藏隱瞞情事的必須依律治罰，其罪責一律定為突吉羅罪。若是違犯了波羅夷重罪，律典說：下三眾犯波羅夷結突吉羅罪，並予以「滅擯」（徹底驅逐出僧團）。其餘諸如夏安居結夏、受日外出等律制事務，完全比照大僧之例。《十誦律》規定：制定五眾（比丘、比丘尼、式叉摩那、沙彌、沙彌尼）都必須安居，五眾皆可受日外出。《四分律》中規定：在春夏冬三時不按律制如法遊行的戒條，下三眾違犯時同樣要結罪。所以這些都是沙彌必須清楚知曉的。

【687-0007】資持記/16c_下四#49
【原文】若犯下，次明上下諸篇。有覆須治者，謂行別住者。若波下，三明犯重。懺法竝同，唯罪為別；犯重唯擯，必無開悔。四中，初正示。十下，引證。《四分》遊行戒，即尼戒也。次明眾法，說戒中，初文為四，初明眾具。鳴下，次明來集。囑授，即說欲。至下，三明出眾又三，一起座。二禮眾。三受教勅。
【譯文】如果犯了下文所述上下各篇的罪行。「有隱覆罪行必須予以治罰」，是指必須依照律法行別住之罰者。在「若波」字以下，第三項說明違犯根本重罪的處置。懺悔的儀軌大致相同，只有所獲罪名輕重有所差別；然而一旦違犯根本重罪唯有徹底擯除出僧團一途，在律法上絕沒有重新開許懺悔的餘地。在第四項中，首先正面指出常規。在「十」字以下，引用經教為證。《四分律》中提及的遊行戒，指的就是比丘尼戒本中的戒條。接著說明大眾僧事的法度，在「說戒」的章節中，前面文段細分為四項，首先說明大眾齊聚必須具備的威儀器物。「鳴」字以下，接著說明僧眾如何前來集會。「囑授」指的就是如法傳達欲產與清淨意願。在「至」字以下，第三項說明沙彌如何退出僧團大眾，這又細分為三個步驟：第一是從座位起立，第二是向僧眾頂禮，第三是恭敬接受上座的教誡與飭令。

【687-0008】01_行事鈔/12b_卷下之四#41
【原文】若通行者。大僧說戒日，沙彌多具華香湯水，供僧眾具，於布薩處，張施羅列。鳴稚將了，並須盡集；有緣，囑授受籌。大僧作法，一如常式。至說戒序訖，戒師云：「未受具戒者出。」諸沙彌等各從座起；執坐具，在僧前禮已，互跪；上座告云：「此眾僧布薩說戒，汝未受具足，不豫聞之；各隨本業誦習，謹慎莫放逸！至鳴稚時，同赴堂來。」告已，隨次出。
【譯文】如果是「共通舉行」的方式：大僧（比丘）說戒之日，沙彌應當多多備辦鮮花、名香、熱水、茶湯等各項供養僧眾的器具，在布薩（說戒堂）處陳設羅列整齊。當敲擊木楗槌即將結束之時，全體沙彌必須悉數到齊；若有特殊事務因緣，應當依照法度囑託代表並接受行籌計數。此時大僧作法，完全依照平常的儀軌程序。等到比丘宣讀說戒序文完畢，戒師高唱：「未受具足戒的人請退出。」各位沙彌便各自從座位起身；手持坐具，在比丘僧大眾前頂禮完畢，互跪在旁；僧中上座便告誡說：「這是僧團大眾布薩說戒的殊勝聚會，你們尚未受具足戒，不得預先聽聞；你們各自隨順原本的功課去讀誦修習，務必謹慎自持、切莫放逸！等到再次敲擊木楗槌時，大家一同前來法堂。」宣告告誡完畢後，沙彌們便依長幼順序走出戒堂。

【687-0009】01_行事鈔/12b_卷下之四#42
【原文】若別行者。沙彌有都集處，鳴稚訖，二眾各集。行法一同僧中。行籌訖，將至僧中，付僧維那，總合唱數；彼送籌者，還來本處。差一人為說戒師，誦《沙彌戒經》，謂《愛道尼經》，及五德十數等。若誦訖，僧中未徹者，隨時誦經說法。至鳴稚時，總來赴堂；隨次入僧中，於常坐處，互跪合掌；彼說戒師，為說明人能護戒已後文。此與大僧相涉行用，看僧說戒中。若自恣者，準說戒中，別堂作法，送籌合唱。若通作者，僧自恣已，五德來向沙彌處；互跪，說僧自恣之文，以犯舉兩通故。

【原文】豫，合作預，謂廁預也。鳴椎時，即誦略教竟，重集聽後序。別行中，初明集眾。注令檢校，恐有不集故。次明行事。云法同僧，即唱白行水等。送簡入僧者，以財法依僧故也。三明說戒。《沙彌戒經》，亦云《沙彌威儀戒本》一卷。謂字寫誤，合作誦字。至下，四明入僧。此下，指前令看。
【譯文】經文中的「豫」字，原本應當寫作「預」，是指參與、列名其間。到了擊鳴楗槌的時候，也就是大僧誦讀略教完畢之時，沙彌應當重新回到大殿聽受後序偈頌。在沙彌獨立修行的部分，首先說明如何召集眾人。註文特別交代必須詳細檢點巡查，是擔心有人散漫沒有到齊。接著說明如何進行僧事。所謂「作法與大僧相同」，指的就是宣唱白文、分派行水等各項程序。之所以要「送籌簡進入大僧僧團之中」，是因為沙彌的生活物資與如法戒行，通通依賴大僧而得以成立之故。第三是說明為其宣說戒法。《沙彌戒經》又稱為《沙彌威儀戒本》，共有一卷。經文中的「謂」字是傳抄筆誤，應當修正為「誦」字。在「至」字以下，第四項說明沙彌重新進入大僧眾中。在「此」字以下，指示讀者回看前文。

【原文】尋之自見。所以得聽前後二序者，由是部主所述，非正戒本故。問：律制，比丘不得為沙彌說五篇名，而前序云四棄等，何以得聽？答：通舉總名，不示別相。但令預眾，生彼忻慕，故得聽也。自恣中，通別同上。準如說戒，前既遣出；至僧自恣訖，應須鳴鍾再集。
【譯文】仔細尋繹前文自然就能通達明了。之所以被允許聽受戒本的前序與後序，是因為這兩部分是結集律藏的部主尊者所附加的述說，並不是正宗核心的戒本內文。有人問：律法嚴格明定比丘絕不能為沙彌宣說五篇罪名的具體細目，而前序中卻提及了「四棄」等罪名，沙彌為什麼可以被允許聽聞呢？回答說：序文只是廣泛列舉出總括的名稱，並未詳細剖析展現具體的犯相細節。這純粹是為了讓初發心者參與法會大眾，藉此生起仰慕渴求大戒的心念，所以開許可以聽聞。在自恣的儀軌中，通則與特殊法規都與前文相同。依照說戒的常規，前面既然已經遣令沙彌退出大殿；等到比丘大僧相互自恣完畢之後，應當再次撞擊大鐘召集沙彌進殿。

【687-0013】資持記/16c_下四#52
【原文】兩通者，犯相同僧，故犯通；上得治下，故舉通。別法中。一切同僧，故不出之。第五略指中。雖是下位，俱發塵沙，與僧無別，故竝指之。廣引中，初科。知慚愧，謂不作諸過。善住，謂住於善處。師法中，初總誡。當下，次別示。文示善惡，不出三業。無定亂言者，由亂言故，則無定也。
【譯文】之所以稱「兩者皆通」，是因為違犯戒律的相貌沙彌與大僧完全相同，所以違犯之法共通；大僧在上位有權舉發並懲治在下位的沙彌，所以舉罪懲處之法也共通。在個別特法之中，一切規範全與大僧無異，所以在此不再一一列舉。第五項簡略指引之中。沙彌雖然身處下位，但受戒時心性同樣能引發遍滿如塵沙法界的清淨戒體，在這點上與大僧毫無差別，所以在此一併予以指明。在廣泛引證之中，第一個小段落。「知慚知愧」，是指內心自律不再造作種種惡業過失。「善住」，是指身心安住在善美的正法境界之中。在對待師長侍奉的法則中，首先提出總體的告誡訓導。「當」字以下，接著逐條分別指示。經文中所昭示的善惡規範，總括來說不離身、口、意三業。所謂「沒有定力而胡亂言語」，就是因為平日言語散亂放蕩，所以內心無法生起深厚的定力。
