# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【149-0001】01_行事鈔/11c_卷下之三#2
【原文】《涅槃》：若比丘為利養故說法，所有徒眾，亦効是師，是人如是，便自壞眾。眾有三種：一破戒雜僧者，雖持禁戒，為利養故，與破戒者坐起行來，同其事業。二愚癡僧，在蘭若處，諸根不利，少欲乞食，於自恣說戒日，教諸弟子清淨懺悔；見非弟子多犯禁戒，不能教令清淨懺悔，而便與共說戒自恣。云何清淨僧？不染利養，善知戒相：云何知重？如四重禁，出家不作，作者非沙門釋子。云何知輕者？三諫能止等。非律不證者，若有讚說受用不淨物者，不共同止。是律應證者，若學戒律，不近破戒；見順律者，心生歡喜；善能解說，是名律師，善解一字。若為利益眾生，至非法處，若是聲聞，不應為也。
【譯文】《大般涅槃經》說：如果比丘為了名聞利養而說法，他的所有徒眾也會仿效這個師父，這個人若如此作為，便會自行敗壞僧團大眾。僧眾有三種：第一是「破戒雜僧」，雖然自己持守戒律，但為了利養的緣故，卻與破戒者同坐同起、同行同往，共同參與其事務。第二是「愚癡僧」，住在阿蘭若（空閑處），根性魯鈍，少欲乞食，在自恣（僧眾結夏圓滿互相檢舉過失之法）與說戒（布薩）的日子，雖然教導自己的弟子清淨懺悔；但是看見不是自己弟子的僧人多犯戒律時，卻不能教導令其清淨懺悔，就直接與他們共同說戒、自恣。怎樣才叫做「清淨僧」？不染著利養，善於通達戒相：怎樣叫做通曉重罪？例如四重禁戒（波羅夷罪），出家人絕不可作，犯者便不再是沙門釋子。怎樣叫做通曉輕罪？例如經過三次勸諫便能終止非法等罪過。所謂「非律不證」（不認同違背戒律之事），是指如果有人讚揚宣說受用不淨物（如金銀等非法物），絕不與他共同止住。所謂「是律應證」（印證肯定符合戒律之事），是指修學戒律而不親近破戒者；見到隨順戒律的人，內心生起歡喜；善於為人解說戒律，這樣的人就稱為律師，能善解戒律中哪怕一個字的意思。如果聲稱是為了利益眾生而前往非法場所，若是聲聞乘人，是不應當這樣做的。

【149-0002】資持記/15d_下三#29
【原文】惡說者，《成論》謂之綺語是也。二明解音義。男女音者，以男女性乖，事業乃異；隨其品類，言相須分；差互混同，不名善說。三教用心，前明遠離三心。貪、縱，慢也；若為名聞利養眷屬，皆是貪心。下明成就四心。
【譯文】所謂「惡說」，《成實論》指的就是輕浮無義的綺語。第二點是說明必須通達音聲與辭義。所謂「男女音」，是因為男女在性格稟賦上有所差異，各自操持的事業也互不相同；隨順各別的品類，在言詞語態上必須有所分別；如果彼此錯亂混雜不分，就不能稱為善於說法。第三點教導說法時的用心，前一部分說明應遠離三種不良心態。所謂三心，即貪心、自輕放縱之心，以及傲慢輕視大眾之心；如果是為了名聞利養與眷屬，全都屬於貪心。後一部分說明應成就四種清淨善心。

【149-0003】資持記/15d_下三#30
【原文】慈謂愍彼未悟，喜即令眾心安，利益謂使他開解，不動謂達法本空，無捨著故。《般若》云：云何為人演說，如如不動？一切有為法，如夢幻泡影，如露亦如電，應作如是觀。又《法華》云：大慈悲為室〔對今慈喜〕，柔和忍辱衣〔利益〕，諸法空為座〔不動〕。能如是者，始可說法；
【譯文】「慈」是哀憫那些尚未開悟的眾生，「喜」是讓大眾聞法心生安穩，「利益」是令他人心開意解，「不動」是通達諸法自性本空，不再心生取捨執著。《金剛般若經》說：「如何為他人演說？應當不取於相、如如不動。一切有為法，如夢幻泡影，如露亦如電，應作如是觀。」此外《妙法蓮華經》也說：「以大慈悲為室（對應此處的慈與喜），以柔和忍辱為衣（對應利益），以諸法空相為座（對應不動）。」能夠做到這樣，才可以登座說法；
