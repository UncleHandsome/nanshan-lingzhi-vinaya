== PROBLEM ==
動作方向與事相反。「下道」是指「離開道路、步下道路走入阿蘭若」（下道即離道，所以後文才解釋「道是一界，下是蘭若」），譯文誤將「下道」譯為「走向道路」，動作方向完全說反。

== SUGGESTION ==
改為「義疏說雖然本部律中沒有明文提及自然界，但經文提到『在不同處所離開道路（步下道路）』，這就是確切的經文依據；道路本身為一界，走下道路處即是阿蘭若。」

== ORIG ==
`疏云雖當部中無自然界，異處下道，即是誠文；道是一界，下是蘭若。`

== CURRENT ==
這是相對於作法界而言，是藉助自然外緣構建而成的。當下，標明其出處。提問：為何本律完全不建立自然界？回答：只是律文闕略而已，在義理上必定完備具足。準照三種小界，明確指出了集僧的處所；義疏說雖然在本部律中沒有明言自然界，但在不同處所走向道路，這就是確切的經文依據；道路是一界，下方就是阿蘭若。現在說本部沒有，或許是因為沒有明確經文，或者是沒有劃定界限範圍的緣故。起初說明村落「界限可明確分別（可分別）」的情形。依照義疏分為兩點：即僧人住或不住容易明瞭〔人員可分別〕，村落也是四周圍院界線清楚可辨〔處所可分別〕。
