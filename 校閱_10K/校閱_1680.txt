# 校閱材料　第1680檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1680-0002】03_業疏/09a_卷二之三#22
【原文】母論：佛見比丘諍昨日食，因制殘宿食，及大界內食無淨厨者一切不得食。準上結界中，界內別結，通團大界則不相容，既非同住，且得相順，此得從文失制意也
【譯文】《毗尼母論》說：佛陀見到比丘爭奪昨日留下來的食物，因此制定禁止食用殘宿之食，以及大界內的食物如果沒有淨廚貯放者，一切都不得食用。依準上面結界法中所說，若在大界內另外結淨地，則與通周環繞的大界不能相容，既然不屬於僧同住，暫且得以順從律文（制斷之文），這只是依循了文字表面而失卻了佛陀制戒的本意。

【1680-0003】03_業疏/09a_卷二之三#23
【原文】次科《母論》，初引制文有二：一、制殘宿，二、制內宿。則知界中須結淨地，同四分也。「準」下，次點前文，即結場中，先結小界作淨地已，外結大界，欲彰大界中不容淨地，以順《十誦》制斷之文；雖順而違，故云「既非」等。引此亦彰彼論不廢淨地
【譯文】在第二科《毗尼母論》中，首先引述制定戒律之文，共有兩項：第一是禁制殘宿食，第二是禁制內宿食。由此可知大界中必須結立淨地，這與《四分律》相同。「準」字以下，接著指點前文，也就是在結戒場時，先結小界作為淨地之後，再在外面結大界，想藉此彰顯大界之中不容許結立淨地，以順應《十誦律》制斷之文；雖然表面順應但實則違背制意，所以說「既非」等等。引述這段文，也是為了彰顯該論並未廢除淨地。

【1680-0004】03_業疏/09a_卷二之三#24
【原文】有人準律、論文，但是大界，雖無院宇，與食同住，隨犯宿者
【譯文】有人依照律文與論義，認為只要是在僧大界內，即使沒有院落屋宇，只要僧人與食物同在界內住過一夜，隨即便犯內宿之罪。

【1680-0005】03_業疏/09a_卷二之三#25
【原文】三斥異古解。「古準律論」者，律中淨地須依大界，又上《母論》亦在大界，不約院宇即犯內宿。前師隨處竝為他物，此師無院同界制犯。前則太緩，此又大急，莫非任情，故須引破
【譯文】第三科是斥責古師的不同解釋。「古準律論」，是指律中規定淨地必須依託大界，而且上面《毗尼母論》也是就大界而言，古師不論有無院落屋宇便判犯內宿罪。前面的論師隨處都當作他物淨，這位論師則主張沒有院落只要同在大界就判定犯戒。前者過於寬緩，後者又過於苛刻緊急，無非都是任隨己情臆斷，所以必須引述來予以破斥。

【1680-0006】03_業疏/09a_卷二之三#26
【原文】今解：言界者，是院周界，豈局作法？縱結攝僧，無僧坊院，不成儲畜，譏過則無；院雖周成，不結攝僧，亦是宿攝，能生過故。所以律云持食露地，賊所持去，因開寺內；若約界成，不應四淨半有籬障，非唯自然，義通作法
【譯文】今家的理解是：經律中所說的「界」，是指院落周圍的邊界，哪裡局限於作法所結之界呢？縱然作法結了統攝僧人的大界，如果沒有僧坊院牆，就構不成封閉儲蓄之相，譏嫌過咎也就不會產生；院牆雖然周匝完備，即使沒有作法結為攝僧大界，也屬於內宿所統攝的範圍，因為能夠滋生過咎的緣故。所以律中說把食物放在露天之地，被賊人偷走，佛陀因此開許移入寺院之內；如果是依作法結界來判定內宿，那麼律中四種淨地就不應當有『半有籬障』（院相不周淨）這一條，可見這不僅僅是指自然界，義理上也通於作法之界。

【1680-0007】03_業疏/09a_卷二之三#27
【原文】今解中初科為三：初、立義。「是院周界」，謂律論云界，乃是院相周帀之界；至於成宿，但取院相，故云「豈局作法」。準文三句：初「院周界」者，即院、界俱有，成犯可知。「縱結」下，即有界無院，縱畜無過，與古不同。「院雖」下，即有院無界，攝相義強，故有宿過。「所」下，引證。既因露地，開移寺內結作淨地，可驗露處無過明矣。「若」下，反質。律有四淨，若不約院，則缺不周，但有三耳；又復不周通於兩界，故知不爾
【譯文】在今家解釋的第一科中分為三部分：第一是立論。「是院周界」，是說律、論中所稱的界，乃是指院相圍繞周匝之界；至於構成內宿之過，只取院落相狀，所以說「豈局限於作法之界」。依準文義有三種情況：第一「院周界」，即是院相與作法界兩者俱備，構成犯戒是顯而易知的。「縱結」以下，即是有作法界而無院落，縱然儲存也沒有過失，這與古師見解不同。「院雖」以下，即是有院落而無作法界，由於封閉統攝的相狀義理顯著，所以產生內宿之過。「所」字以下，引證。既然是因為放在露天之地，佛才開許移入寺內結為淨地，可驗知在露地儲存並無過咎，這是極為明白的。「若」字以下，反詰質問。律中列有四種淨地，如果不就院落而言，那麼就會欠缺「院相不周」這一條，而只剩下三種了；而且不周淨通於自然界與作法界兩者，所以可知古師之說並不合理。

【1680-0008】03_業疏/09a_卷二之三#28
【原文】問：有界無院，不集別眾；無界有院，如何犯宿？答：僧、食兩異，何得例也？由方相合，儲過譏生，故有罪也；法事取和，不從譏過，故有斯異
【譯文】問：如果境內有界而無院落，界內不集合僧眾便成別眾之罪；那麼無界而有院落，又怎麼會犯內宿呢？答：僧眾之事與飲食之事兩者本質不同，怎能混為一談來比照呢？由於四方院相合圍封閉，儲存的過咎與譏嫌便隨之產生，所以結成有罪；而僧中行法事求取的是僧眾和合，並不取決於外界有無飲食儲蓄的譏嫌，因此兩者有這樣的差異。

【1680-0009】03_業疏/09a_卷二之三#29
【原文】釋妨中，問舉別眾例難無界不當犯宿。答中，初總示；「由」下別釋。兩途各異，在文可見
【譯文】在釋除疑難中，提問舉出僧中別眾之例，責難無界有院之處不應當犯內宿罪。在回答中，首先作了總體開示；自「由」字以下分別解釋。兩條途徑各自不同，在文句中可以清楚看見。

【1680-0012】03_業疏/09a_卷二之三#32
【原文】一者、檀越淨。文中由是他物，貪儲不生，故直開也。義分為三：初、處所是他物，食具是自許，既是俗家，我固絕起；二、處是僧坊，食具俗有，律云聽作檀越食，令淨人掌舉，不應自受，所須隨索之；三、處、食俱他，如今俗設噉會者是也
【譯文】第一是「檀越淨（施主淨）」。經文中因為屬於他人的財物，比丘貪著儲存之心不起，所以直接開許。義理上分為三種情況：第一，處所是他人物品，食具與食物是自己所有；既然是在俗人家中，我自當絕不起貪心執著；第二，處所是僧坊，而食具與食物屬於俗人所有；律中說聽許製作施主供僧飲食，令淨人掌管收藏，比丘不應當親自接受，有所需要時隨時向其索取；第三，處所與食物全都是他人所有，如同現今俗人所設的齋會供僧便是這種情形。

【1680-0013】03_業疏/09a_卷二之三#33
【原文】檀越淨中初科，初敘意；「義」下顯相。初云「食具」，即通器物、生熟之者；「許」，猶有也；「固」，即是執。二中「不自受」者，恐成己物故。三中一時齋供，謂之噉會
【譯文】在檀越淨的第一科中，首先敘述立教用意；自「義」字以下顯明其相狀。第一條所說的「食具」，通指盛食器物以及生熟食物；「許」，相當於「有」；「固」，就是執持不捨。第二條中所說的「不自受」，是恐怕變成自己所屬之物的緣故。第三條中一時所設的齋糧供養，就稱為噉會。
