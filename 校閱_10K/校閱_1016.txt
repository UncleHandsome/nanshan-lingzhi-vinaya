# 校閱材料　第1016檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1016-0001】資持記/04d_上三#3
【原文】非堅法者，有漏世福，容謝滅故；若達法空，不取施相，成無漏善，則是堅法。若欲下，明出行白。若不下，明通白，染衣事中所攝多事，皆不須白。又如經營佛法僧事，隨舉總相一事白之，故云通耳。古記並立通白法云：從今清旦至明清旦所作一切事，白阿闍梨知；
【譯文】「非堅固之法」，是指世間有漏的福德，容易隨時間謝滅消亡；若是通達法空，不執著布施的相狀，成就無漏善法，這才是堅固之法。「若想要」以下，說明外出時的稟白。「若不」以下，說明通白（總括稟白），染衣過程中所包含的諸多細事，全都不需要一一稟白。又例如營辦佛、法、僧的三寶事業，只需隨機提出總括的一件事稟白即可，所以稱為「通白」。古代的注記中全都立下通白的條文說：從今天清晨到明天清晨所做的一切事，都稟白阿闍梨知悉；

【1016-0002】資持記/04d_上三#4
【原文】便謂晨朝白已，一日不須。此不出正教，妄生搆立。且《律》制白師，本取可不；但云一切，為是何事，如何量宜？況前引諸教多種白法，皆應無用。今猶行之，無知故也。《善見》中。彼有七法：一太遠，恐不聞；二太近，恐踏師影；三上風，恐臭氣熏師；四高處，恐成憍慢；五當前，礙師觀望；
【譯文】於是便認為早晨稟白過後，一整天都不再需要稟白。這種做法並非出自正統經教，而是胡亂杜撰設立。況且《律》中規定稟白師長，本意在於徵求是否准許；只說「一切事情」，到底是何事，又該如何依宜考量？更何況前面所引諸多教法中的各種稟白規定，豈不都成了毫無用處。如今竟然還有人照著行持，全因愚昧無知的緣故。在《善見律》中，彼處有七種站立規矩：一是距離太遠，唯恐聽不清楚；二是距離太近，唯恐踩到師長身影；三是站在上風處，唯恐氣味熏及師長；四是站在高處，唯恐流露驕慢；五是正對著前方，會阻礙師長視線；

【1016-0003】資持記/04d_上三#5
【原文】六當後，迴顧喚難；七立於左右七尺許。今引二七兩法。《四分》，可解。受法中。指下依止，下云日別三時教三藏教法等。報恩中，《四分》為二，前略引行相。二事者，《律》云：一修理房舍，二補浣衣服。廣下，二指文勸依。即〈受戒揵度〉第三十一卷末；彼云：自今已去，制弟子法，應行；
【譯文】六是正對著背後，師長回頭呼喚困難；七是站在師長左右大約七尺的地方。此處引述了第二與第七這兩種規矩。《四分律》文意容易明白。在受法之中，指向後文的依止，後文說每天分成三時教導三藏法義等。在報恩之中，《四分律》分為兩部分，前半部簡略引述行持的事相。「兩件事」，《律》中說：一是修補房屋，二是縫補清洗衣服。「廣」字以下，第二部分指出律文篇幅以勸勉依教遵行。這即是出自〈受戒犍度〉第三十一卷的卷末；那裡說：從今以後，制定弟子應遵守的法則，應當遵行；

【1016-0004】資持記/04d_上三#6
【原文】若不行，應如法治，然後列相。此不繁引，須者尋之。《僧祇》中。右脚者，傍門左入，以從順故。同《四分》者，除大小器等。《十誦》，初明弟子勤勞。先脚至上，浴法須爾。病用物者，謂藥餌之資。日下，明師攝濟。惡知識者，順己欲情，染習易故；最不可近，故切訓之。
【譯文】如果不遵行，應當如法懲治，隨後列舉具體事相。此處不再繁複引述，有需要者可自行查尋。《僧祇律》中。「右腳」是指靠門的左側進入，因為這樣合乎順行規矩。其餘與《四分律》相同之處，包括清理倒除大小便器等事。《十誦律》開頭說明弟子的勤勉辛勞。從腳開始洗起直到上方，洗浴的方法就應當如此。「生病所需的物品」，是指藥物滋補的資糧。「日」字以下，說明師長的攝受資助。「惡知識」，是順從自己欲望情感之人，容易受其染污習氣薰染；最不可親近，所以切實訓誡。

【1016-0005】資持記/04d_上三#7
【原文】一壞名聞，二障學業，三喪德行，四失正信，五伐善根，六墮惡道。近善知識，反上可知。《智論》云：隨逐惡者，皆由無智。古儒云：見賢思齊，見不賢而內自省。《成論》四輪：一住善處，二依善人，三發正願，四植善根。況今末劫，人非上智；志性無定，好惡隨緣；
【譯文】一是敗壞名譽聲望，二是障礙修習道業，三是喪失德行修養，四是失落正知正見之信，五是折損善根，六是墮落惡道。親近善知識，與上述情況相反，理應可知。《智度論》說：跟隨追逐惡人，都是由於缺乏智慧。古儒家說：見到賢德之人便想向他看齊，見到不賢之人則自我反省。《成實論》提出「四輪」：一是安居善處，二是親近善人，三是發起正願，四是培植善根。何況如今處於末法時代，人多非上等智慧；心性沒有定準，好惡隨緣轉變；

【1016-0006】資持記/04d_上三#8
【原文】凡在學流，切宜擇善；因茲言及，聞者三思。佛所歎者，看病福勝，如下卷引。《雜含》中，初明弟子如法。上二句離二過。諂偽是心，欺誑即口。信下三句，修三業。義分五行：一離惑倒，二無放逸，三不懈怠，四絕妄緣，五遠塵染。次第對之。深下，奉教行。志下，期聖道。如是下，勸師敬念。〔授字古本作愛。
【譯文】凡是身在修學行列中的人，切實應當慎選善知識；藉此因緣談及此處，聽聞者應當再三深思。佛陀所讚歎的，即探視照料病人的福德最為殊勝，如下卷所引文證。《雜阿含經》中，前半部說明弟子行持如法。前面兩句指遠離兩種過失。諂媚虛偽是出自內心，欺詐狂妄則是表現在口業。從「信」字以下的幾句，是指修行三業。義理上分為五種修行：一是遠離愚癡顛倒，二是不放逸，三是不懈怠，四是斷絕妄緣，五是遠離世俗塵染。依序相互對應。「深」字以下，說明遵奉教誨而行持。「志」字以下，說明期許證得聖道。「如此」以下，勸勉師長敬愛眷顧弟子（「授」字在古本中寫作「愛」字）。

【1016-0007】資持記/04d_上三#9
【原文】二明攝受，標示中。和尚攝行同者下七門中，三及五六，通明二師，餘四唯局依止。制意中，初敘由。故下，引制。咨承是資行，匠成即師德，此二句出制教之意。二中，《四分》。因比丘不洗足飲水，便依止，迷悶倒地。佛因開之。《十誦》。開五六夜，為選擇故。與下《伽論》延促少異。《五百問》中。
【譯文】第二「明示攝受」（明攝受），在「標示說明」（標示）中。和尚攝受與行持相同者，在下列七門之中，第三以及第五、第六門，通論兩種師長，其餘四門則唯獨侷限在依止師。「制定義理」（制意）中，開頭敘述緣由。「故」字以下，引述戒律規定。「諮承」是弟子的行持，「匠成」則是師長的德性，這兩句話點出了制定教法的用意。第二段中，《四分律》記載：因為有比丘不洗腳飲水，就去依止，導致神智昏迷倒在地上。佛陀因此開許延緩。《十誦律》開許五到六個夜晚，是為了讓彼此有選擇的時間。這與後文《摩得勒伽論》（《伽論》）規定的時間長短略有不同。《五百問》中。

【1016-0008】資持記/04d_上三#10
【原文】初不依止受用犯盜者，須約私物；師復不許，既非相攝，輒用同盜。必是僧物，十方同分；或師通允，不為竊盜；理如《十誦》，違教吉羅。或可論家制急，約緣辨犯，義非重夷。若下，不誦戒者，臘同師位，教行無知，不堪利養，故同犯盜。亦如上通。第三列名中。初出家者，即十戒師。
【譯文】最初說明未依止而受用物資構成犯偷盜罪，這必須就私人物品而言；師長又未准許，既然彼此沒有攝受關係，隨意使用便如同竊盜。如果必定是僧團公物，則屬於十方僧眾共有；或者師長全面應允，那就不構成偷盜；理趣如同《十誦律》所說，屬於違背教令的突吉羅罪。或者可以說是論師制定極其嚴格，依從緣起辨析犯相，其罪責義理並非極重的波羅夷罪。「若」字以下，針對不誦戒者，其僧臘雖已達到為師的位階，但教理行持皆極無知，承擔不起信眾供養，所以等同於犯偷盜。這也如同前文那樣融通。第三「列舉名稱」（列名）中。最初引導出家的，就是十戒師。
