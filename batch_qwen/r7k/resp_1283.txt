整體看，譯文對疏、記的語氣與科判骨架掌握得不錯，但有幾處**術語誤解**、**科判讀錯**、**引號內牒文被改譯**的問題，另有一些贅字與前後不一致。以下逐則列出。

---

## 一、逐則檢查

### 【1283-0001】

1. **「點異」譯成「指出異本文字」——明顯錯誤。**
 元照記文的「點異」是「點出（與前釋）不同之處」，不是校勘學的「異本」。證據就在下一句：「『初入』、『自觀』，同前初釋」——正因前面點了「異」，這裡才要交代哪些部分「同」。
 建議：**「『又有』以下，是點出與前面解釋不同之處。」**

2. **「合法」宜點明是「以法合喻」。**
 「配合比喻的說明」語意含糊。建議：**「在以法義合於譬喻（合法）的段落中。」**

3. **「初牒釋」→「起初引錄解釋」** ：「牒」是牒舉疏文再作解，可譯「先是牒舉疏文加以解釋，其中分兩段」。

4. **「乞已出還」→「走出來返回僧團」** ：「僧團」是增譯。原意只是乞食完畢出聚落而返（住處／寺）。建議「乞食完畢、出聚落返回」即可。

### 【1283-0002】

1. **「別人不預」漏譯「別人」——影響疏文對句結構。**
 疏是「眾行不乖」對「別人不預」，即**眾／別**對舉（記文特別點出「眾別兩行，並屬他故」）。譯文只寫「不去辨別評判（他作或不作）」，把「別人」這層對比弄丟了。
 建議：**「『不觀作不作』，是指對個別他人（作或不作）不去辨別評判。」**

2. **「下偈」譯「下方偈頌」** ：宜作「後面那首偈頌」，與 0006「後一首偈頌」一致。

3. **「上／下」譯「前半段／後半段」**：此處指上半偈、下半偈，建議統一作「上半偈／下半偈」（0003、0004 已用「上半偈」）。

4. **「凡夫遂有去取」→「執取或捨棄之心」**：「去取」是「捨去與執取」兩者並存，用「或」略失原意，可作「於是有了捨棄與執取」。

5. **引號內「自觀」被寫成「但自觀」**：牒文宜照原文，不要補字（詳見下方綜合建議）。

### 【1283-0003】

1. **「往往」重複——贅字錯誤。**
 原文：「取舍不以道，往往愛起於『貪』」。譯文寫成「其取捨**往往**不依循正道，**往往**喜愛源自於貪心」，把一個「往往」拆成兩個。
 建議：**「其取捨不依正道，喜愛多半源自『貪心』，憎恨出自『瞋怒』。」**

2. **「指略」未譯。**
 「『下』下，指略下半」譯為「是指略下半偈」，等於沒譯。意思是：疏文只點出下半偈而**略去不詳釋**（故疏云「如常解」），記文再代為補說。
 建議：**「『下』字以下，是點出下半偈而略去不詳釋；意思是……」**

3. **「剋己」→「克制自己」偏了。**
 依下文「正則守之，不正則改之」，「剋己」是**剋責自己、反求諸己（自我檢省）**，不是壓抑克制。
 建議：**「必須自我檢責（反求諸己）」**。

4. **「個別專屬的行為」**：「別」指**個別他人**，宜作「個別他人的行為」，才接得上「並屬他故」。

5. **「不須過問窺探」**：「窺探」帶貶義，原文只是「不須觀察（分別）」，建議去掉「窺探」。

### 【1283-0004】

1. **「又通作自行解」的「通」宜說清楚。**
 「通」是**兩偈通（都）作自行解**，有別於前解「下偈明自行」。建議：**「另外，也可將兩首偈頌都作個人修持（自行）來解釋。」**

2. **「將入眾中」的「眾」**：依記文「此約入眾學法為『採』」、「入聚，謂預眾也」，此處是**僧眾**，建議明寫「進入僧眾之中」，不要只寫「大眾」。

3. **「取味」譯名前後不一**：文中先作「採納其滋味」，後作「採納滋味」；且「取味」是偈頌原文的牒詞，建議保留「取味」再加括號解釋。

4. **「資神用」→「滋養心神」**：可，但更貼切是「資益心神（慧命）」；「感果用」的「善」是增譯，可留但宜知是補義。

### 【1283-0005】

1. **「初釋」譯成「先牒第一種解釋」——科判讀法可議。**
 記文此處是層層科分：「次自行中 → 初釋 → 初總分 → 『行』下別釋為二」。「初釋」是**第一科「釋」**（與 0007「次釋」相對），不是「第一種解釋」，「牒」字也是憑空加的。
 建議：**「其次，『通作自行』的解釋中，首先是解釋（疏文）。一開始是總體劃分……」**
 並與 0007「次釋中」採同一套譯法，避免讀者誤以為在數「第幾種解釋」。

2. **引號內「入聚」→「入聚落」**：牒文宜照原樣（見綜合建議）。

### 【1283-0006】

1. **「力未兼濟」→「兼善天下」——用語過重。**
 「兼濟」是**自利之外兼能利他**，不是儒家「達則兼善天下」的格局。且「若」是加上去的假設語氣，原文是直陳。
 建議：**「（自身）力量還不足以自他兼濟（兼顧利他）」**。

2. **「故自外護」→「只對外謹慎防護」——對象不清，易誤讀為「保護自己」。**
 依記文「次偈『處眾』護僧」，「外護」的對象是**僧眾**。
 建議：**「所以自己對外（對僧眾）加以護持，這就是後一首偈頌的意思。」**

3. **「恐惱僧儀」→「驚擾了僧團的威儀」**：「惱」是惱亂、干擾；「僧儀」指僧眾儀則。建議「唯恐惱亂僧眾的儀則」。

4. **「隨機處默」**：可補足為「隨順機緣而安處靜默（不評論他人）」，語意更明白。

### 【1283-0007】

* 內容基本無誤。
* 「但從大判，不復碎分」可再白一點：**「只是就大要判定，不再逐句細分。」**
* 「次釋中」的譯法須與 0005「初釋」一致（見上）。

## 二、綜合性建議（跨則）

1. **引號內的「牒文」不要改譯。**
 疏、記是在逐字牒舉戒本偈頌與前文（「不違」「自觀」「但自觀」「入聚」「取味」「不壞」……）。譯文把它們改成「不違背」「但自觀察」「入聚落」「採納其滋味」，會**斷開疏↔記↔戒本的對應關係**，讀者無法對回原文。
 建議體例：**保留原詞＋括號補義**，例如「『不違』等半偈（不違戾彼、不觀作不作）」「『取味』（採取其滋味）」。

2. **科判術語統一譯法。**
 「牒釋／總分／別釋／指略／點異／初釋、次釋」建議固定一套：牒舉解釋／總體劃分／分別解釋／點出而略釋／點出異處／初、釋（次、釋）。目前「初釋」時而當科、時而當「第一種解釋」，最容易造成誤讀。

3. **眾／別、僧眾用語統一。**
 「眾」在這些段落多指**僧眾**，建議一律譯「僧眾」；「別」一律譯「個別他人」，以保住疏記反覆強調的「眾別兩行，並屬他故」。

4. **「捨護」的處理。**
 兩則都譯「平等捨心與護持之德」，屬合理引申（記云「平一其心」），但「護」的對象在 0006、0007 明確是**護僧**。建議 0002／0003 補一句「（護持自他／護僧）」或加註，避免讀者只理解為抽象德目。

5. **譯得好的地方**：同一個「預」字，在「別人不預」譯「辨別評判」、在「謂預眾也」譯「參與」，處理正確；「反成自累」「處眾立身之要術」等語氣也譯得貼切。
