# 校閱材料　第142檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【142-0001】02_戒疏/03b_卷一下之一#130
【原文】【記】釋文中。初總示文意，「良」下，牒釋文相。初通釋。云「習起」者，相續不止也。「無定」不成「禪」，「無慧」不至「果」。「禪果」二字，即下「二道」。「此遠資」者，以犯戒墮惡，但障欲有福報，文言「障道」，故是遠資也。卷初已明，故指「如上」。「所」下，牒解。初釋「道」字，通含「禪」、「果」，「禪」通凡聖，「果」唯局聖。「梵天道」者，且舉初禪，通收上地色、無色報，凡唯漏業，聖即助道。天台云：「神通變化無漏觀慧，悉從四禪出。」言「四禪」者，即色界四天所修之定。「禪」是梵語，此云棄惡，能棄欲界五蓋等一切諸惡故。「四定」者，無色四天定：一、虗空處，二、識處，三、無所有處，四、非非想處。總上二界，故云「八定」。「聖道」可解。定慧是因，二道並果。由先毀戒，定慧不發；既無因行，寧有果剋？覆過默淨，障道在茲。「既」下，次釋障字。「持」合作「執」。
【譯文】【記文】在解釋經文中。首先總體指示文意，「良」字以下逐句銷釋經文詞句。先作通解。所謂「習起」，是指相續不斷地造作。「沒有定力」便成就不了「禪」，「沒有智慧」便達不到「果」。「禪果」二字，就是指下文所說的「二道」。「此遠資」是指犯戒墮入惡道，直接障礙的是欲界的福報，經文稱其「障道」，是因為它摧毀了遠向佛道的核心資糧。卷初已詳明此理，故指引「如上」。「所」字以下逐字銷解。首先解釋「道」字，同時涵括「禪定」與「聖果」，「禪」通於凡夫與聖人，「果」則唯獨局限在聖者。「梵天道」是以初禪為代表，通括整個上界色界與無色界的果報；在凡夫純屬有漏業因，在聖者則轉為助道因緣。天台宗指出：「一切神通變化與無漏觀慧，全都由四禪之中流出。」所謂「四禪」，是指色界四禪天所修持的根本定。「禪」是梵語，此處譯為「棄惡」，因為它能屏棄欲界的五蓋等一切惡法。「四定」是指無色界四天的空定：第一、空無邊處定，第二、識無邊處定，第三、無所有處定，第四、非想非非想處定。總括色界與無色界，故稱為「八定」。「聖道」文義顯明可解。定與慧是修行之因，二道則是所證之果。由於先前毀犯了戒律，定慧便無由生起；既然缺乏能成之因行，又豈能證得所期之果證？隱覆罪過而沉默佯表清淨，障礙聖道的關鍵即在此處。「既」字以下，進一步解釋「障」字。「持」字在字義上應作「執著」之「執」。

【142-0002】02_戒疏/03b_卷一下之一#131
【原文】【註】佛言：「僧說戒時，默妄語故，犯突吉羅。」言「障道」者，障於四禪、三空、四果。告諸比丘：「如彼大海不受死屍，設有，漂出；我法亦爾，不受死屍。謂『死屍』者，非沙門梵行，自言沙門梵行，犯戒惡法不清淨，穢汙邪見覆藏，內懷腐爛，外現完淨，如空中樹；雖在眾坐，常遠離眾，眾亦遠彼。」故知懺罪方成聞戒也。
【譯文】【註文】佛陀開示：「大眾僧說戒之時，因為沉默做妄語的緣故，結犯突吉羅罪。」經文說「障道」，是指障礙了證得四禪、三無漏解脫與四種沙門果。佛陀告誡諸位比丘：「如同浩瀚的大海絕不容納死屍，縱使有死屍落入，也會被波浪漂送上岸；我的正法大海也是如此，絕不容受破戒死屍。所謂『死屍』，是指自身不具備沙門清淨梵行，卻口口聲聲自稱是沙門梵行；其人違犯戒律、行惡法而不得清淨，身懷垢穢邪見又極力隱瞞覆藏；內心早已徹底腐爛，外表卻裝現得完好清淨，就像內部枯空的朽樹一般；雖然人坐在大眾席位之中，但在法性上永遠遠離了大眾僧，大眾僧在實質上也徹底遠離了他。」由此可知，唯有如法懺悔清淨，才有資格聽聞宣說戒律。

【142-0003】02_戒疏/03b_卷一下之一#132
【原文】【疏】注中「默妄但犯吉羅」者，有輕重也。望僧虗解，斯業重也；望非言述，重而制輕。勿謂為小，九百千歲亦難堪也。一犯尚爾，多犯如何？不可救也。故《論》說「言如小團鐵，入水沈」也。又引海喻，文相可知。
【譯文】【疏文】夾註中提及「沉默妄語只犯突吉羅罪」，這是在輕重層面作權衡。相對於在大眾僧中造成大眾虛妄的領解，這股業障是極其深重的；但相對於並未動用言語直接說謊，佛陀在制罪上乃從重而判輕。切莫以為這是微細小過，在地獄中承受九百千年的極苦亦是難以忍受的。違犯一項尚且如此，多重違犯又該如何？那時可就萬劫難救了。所以論典中說「如同微小的一團鐵球，落入水中依然沉沒無疑」。夾註中接著引用大海的比喻，文相顯明可以理解。

【142-0004】02_戒疏/03b_卷一下之一#133
【原文】【記】釋注為二。前釋罪相。初通示，「望」下，別釋。誑僧境勝故「業重」，即如《五分》「僧中妄語，重百羅漢前」是也。默表無言故「制輕」。「勿」下，指報誡勸。《目連問經》列六聚犯報，犯突吉羅，九百千歲墮泥黎中。準《雜心論》，即墮等活地獄一晝夜耳。委示歲數，具如《鈔》中。「一」下，舉況。「故」下，引證。《婆沙》云：「愚作小罪永墮惡，智為大罪亦脫苦；為團鐵小亦沉水，為鉢鐵大亦能浮。」又《涅槃》云：「莫輕小罪，以為無殃，水滴雖微，漸盈大器。」有智思之。注中「三空」，謂空、無相、無願三解脫也。「又」下，次點餘文。《疏》但略指，而文相難解，略為科釋。從「告諸比丘」下，大分為二：初明覆過；「故知」下，結示。初中又二：前舉喻，可解；「我」下，二、合法。初二句對合，「謂」下，委釋。初釋死屍，「雖」下，釋不受。初中又二，初通標；「犯」下，別釋。初至「覆藏」，釋上「非沙門」句。「犯戒不淨」，即身口業；「穢汙邪見」等，即是意業。「內懷」下，次釋上自言句。「空中樹」，謂中心枯朽者。
【譯文】【記文】解釋夾註分為兩段。前半段解釋罪相。首先通泛指示，「望」字以下作分別辨析。欺誑僧眾對境殊勝所以「業力極重」，正如《五分律》所載「在僧眾中說妄語，其過失重於在百位羅漢前妄語」。以沉默表示而無言說所以「制教罪輕」。「勿」字以下引果報嚴加誡勉勸導。《目連問戒律中五百輕重事經》列舉六聚罪報，違犯突吉羅罪者，將於泥梨地獄中感受九百千歲之苦。依《雜阿毘曇心論》，這相當於墮入等活地獄一晝夜的時間。詳細歲數說明，完整載於《事鈔》之中。「一」字以下以單況多。「故」字以下引論為證。《大毘婆沙論》說：「愚人造作微小之罪而永墮惡道，智者縱造大罪亦能解脫重苦；微小的鐵團落水亦沉，巨大的鐵缽卻能漂浮。」《涅槃經》亦云：「莫輕小罪，以為無殃，水滴雖微，漸盈大器。」有智慧之人當深長思之。夾註中所說的「三空」，是指空、無相、無願三三昧解脫門。「又」字以下，點出夾註後續文意。《疏》文在此僅略微提示，而註文脈絡深奧難辨，故在此略作科條析釋。從「告諸比丘」以下，大體分為兩部分：前半段闡明隱匿過失的行相；「故知」以下作總結提示。前半段中又分兩節：前半舉出大海之喻，顯明易解；「我」字以下，第二節以法合喻。最初兩句直接對合，「謂」字以下作詳細解釋。首先解釋何為「死屍」，「雖」字以下解釋何以「不容受」。在解釋死屍的文義中又分兩小節，首先總綱標立；「犯」字以下作分別闡釋。從「犯戒」到「覆藏」，是解釋上文「非沙門」這一句。「犯戒不清淨」是指身業與口業，「穢汙邪見」等則是指意業。「內懷」以下，是進一步解釋上文「自言」這一句。「空中樹」是指樹木中心已經乾枯朽敗者。

【142-0038】02_戒疏/03c_卷一下之一#16
【原文】【疏】所以正宗廣教何為興者？良由五眾不攝情根，於諸名利，無思檢約，廣生有漏。隨塵起染，外纏邪慢，內增癡惑。是以如來隨其所犯，略教既壞，制廣補之。使夫持犯的明，愚智齊曉，戒禁時機，深有弘益。即斯言教，號曰「廣宗」。
【譯文】【疏文】正宗分中的廣教究竟是為了什麼而興起的呢？主要是由於五眾弟子不能收攝情識與六根，對於世間的各種名利，沒有深思檢點約束，從而廣泛生起有漏的煩惱造業。心念隨著外在塵境生起染污，外在纏縛著諂媚邪妄與貢高我慢，內在則增長了無明愚癡與迷惑。因此，如來隨著弟子們所犯的過錯，在先前簡略的教誡遭到破壞之後，制定了詳細周備的廣教來補救。好讓犯戒與持戒的界線明確顯著，愚鈍與智慧之人都能共同明瞭，使戒律禁令在適應當機時勢上，產生極其宏大的利益。這一部言說教法，就稱為「廣教之正宗（廣宗）」。
