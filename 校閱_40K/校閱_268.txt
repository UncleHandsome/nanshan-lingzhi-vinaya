# 校閱材料　第268檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【268-0001】資持記/07e_中一下#12
【原文】文中，先引《十誦》示盜相。次引《五分》明賭博。七中。彼明盜四足者，驅向所期，足遍犯重，不隨所向者輕〔雖離，但得蘭罪。〕；本期不定，舉遍即重；本主來逐，心未得者輕〔即文中所謂未作得想也。〕。第八句。《善見》得心已決，微動即犯，不待離處。如下，舉喻。可解。九中。
【譯文】文中，先引用《十誦律》指示盜竊的形相。接著引用《五分律》說明賭博的過失。第七句中，那裡說明偷盜四足牲畜，驅趕牠們朝向預定的地方，牲畜四足全部走過就犯重罪，不遵從驅趕方向的則犯輕罪〔雖然離開原地，但只得偷蘭遮罪。〕；若原本預定的界限不明確，牲畜四足全部抬起走動就犯重罪；原主人前來追趕，盜者心想尚未得手的則犯輕罪〔也就是文中所謂尚未生起得物之想。〕。第八句，《善見律》認為盜心既然已定，物品稍微移動就構成犯罪，不必等脫離原處。如下文所舉的譬喻，容易理解。第九句中。

【268-0002】資持記/07e_中一下#13
【原文】田宅等物，永不可離；不同上句，可離不離。第十。且出空弋水注三相。律中明處，則有十三；疏中次解，今略引示。初地中〔即是伏藏，有主望主結；佛僧𮋭，屬佛僧。〕，二地上〔如今道地得物〕，三乘〔謂象馬等乘，乘盜乘上物，離乘方犯；若兼乘盜，乘離即犯。
【譯文】田地房屋等不動產，永遠不可能搬離原處；這不同於上一句，屬於可以搬離而不去搬離的情況。第十句，暫且列舉出空中、木樁、流水三種相狀。律中說明的處所共有十三種；《戒疏》中依次作了解釋，現在簡略引用說明。第一「地中」〔就是地下埋藏之物，有主的對物主結罪；若是佛物或僧物，則歸屬佛僧。〕，第二「地上」〔如同現今在路上拾得物品〕，第三「乘」〔是指象、馬等騎乘工具，如果偷取乘坐工具上的物品，物品脫離乘具才算犯戒；若是連同乘具一起偷走，乘具一動就犯戒。

【268-0003】資持記/07e_中一下#14
【原文】四擔〔同乘兩分〕，五空〔謂衣物鳥等，從風所吹，而欲盜取；即此空處，以辨離處。《善見》：盜空中鳥，左翅過右翅，尾處至頭，上下亦爾，俱得重罪。〕，六架〔即曲弋也，若盜物者，物離方犯；若連架者，架離即犯。〕，七村〔或盜村物，或盜村體，擊破壞等。〕，八阿練若〔村外空地，同村可知。〕。九田〔《十誦》：若為田故，相言得勝者，重；不如者輕。
【譯文】第四「擔」〔與乘具一樣分為偷物或兼偷擔具兩種情形〕，第五「空」〔是指衣服、鳥雀等，被風吹在空中，而企圖盜取；就在這虛空之中，來判定是否脫離原位。《善見律》說：盜取空中的飛鳥，左翅越過右翅的原位，尾部移到了頭部的原位，上下挪移也是如此，都構成重罪。〕，第六「架」〔就是曲柄的掛木，如果只偷懸掛之物，物品脫離木架才犯；若是連同木架一起偷，木架移位就犯。〕，第七「村」〔或者盜取村裡的財物，或者毀壞村落本身，進行破壞搗毀等。〕，第八「阿練若」〔村莊外的荒野空地，情況如同村莊一樣可以推知。〕。第九「田」〔《十誦律》：如果為了爭奪田地，訴訟而勝訴者犯重罪；敗訴者犯輕罪。

【268-0004】資持記/07e_中一下#15
【原文】若作異相，過分勝者，重。〕，十處所〔如店肆作處，盜物盜體，同上村中。〕，十一船處〔盜物即以船為處；盜船體者，斷繩離處方犯。〕，十二盜水〔即斷水注也，《僧祇》：溉灌水，或一宿，直一文，或至四五；若壞彼渠，得越；水入田蘭，滿五者夷。〕，十三私度關〔如律：比丘無稅，白衣應稅，為彼過物重。
【譯文】如果私自偽造界標，越界霸佔勝訴的，犯重罪。〕，第十「處所」〔如同店鋪、作坊等處，盜取其中的財物或破壞處所本身，都與前面村落的情況相同。〕，第十一「船處」〔偷取船上的財物，就以船為處所；若是偷取船隻本身，必須斬斷纜繩離開原位才構成犯罪。〕，第十二「盜水」〔就是截斷水流引水，如《僧祇律》說：灌溉用的水，引灌一宿，價值一錢，有的甚至價值四五錢；如果破壞他人的水渠，犯越法罪（突吉羅）；水流引入自己的田地犯偷蘭遮，若價值滿五錢則犯波羅夷。〕，第十三「私度關」〔如律中所說：比丘免除稅負，白衣應當納稅，如果替白衣夾帶貨物過關則犯重罪。

【268-0005】資持記/07e_中一下#16
【原文】《十誦》：比丘應稅不稅亦重，餘廣如疏。〕。結示中，文為三段，初示前略意。憂下，二明人有順違；初明知足之人，懼犯退藏；若下，明多事求進，為盜所陷。言憂心者，心之可畏，難可禁制；微縱成業，殃及累世，是可憂故。念道者，慕出離也。緣境局者，為教所禁也。
【譯文】《十誦律》說：比丘應當納稅而不納稅的也犯重罪，其餘詳細內容如同《戒疏》所說。〕。在結語示導中，文章分為三段，首先說明前面略述的用意。從「憂」字以下，第二段說明人有順從與違背戒法兩種情況；先說明知足的人，懼怕犯戒而退避隱藏；從「若」字以下，說明多攬事務、追求升遷之人，往往被盜戒之罪所陷害。說到「憂心」，是因為這顆心實在可怕，難以節制；稍微放縱就會造作惡業，禍害波及累世，所以令人擔憂。所謂「念道」，是指企求脫離輪迴。「所攀緣的境界受限」，是因為受到戒教的禁制。

【268-0006】資持記/07e_中一下#17
【原文】多眾務者，或好為人師，或樂營世福也。欲高升者，名位過人也。羅盜網者，結業成也。無有出者，苦報無窮也。何下，微示其意，如前《寶梁》所揀人也。有下，三勸修。初句，召後人也。細讀者，勸尋教也。附事者，以教照境也。深思者，以境觀心也。乃知者，自省心行也。
【譯文】「事務繁多」，是指或者喜歡收徒為人師表，或者熱衷營造世間福報。「想要步步高升」，是指希求名位超群拔萃。「落入盜竊羅網」，是指惡業已經造作圓滿。「永無出離之日」，是指承受苦報無有窮盡。從「何」字以下，稍微點明其中的意旨，如同前面《寶梁經》中所揀選淘汰的那種人。從「有」字以下，第三段是勸勉後人修持。第一句，是呼喚後世之人。「細細研讀」，是勸勉尋求戒教真義。「附著於事相」，是用教法來觀照外境。「深刻思維」，是以所對之境來反觀內心。「方才知曉」，是自我省察內心的起心動念。

【268-0007】資持記/07e_中一下#18
【原文】故下，引論以勸。論中，初句通示教意；此下，別指今戒，必須繁文。曲碎解釋者，論涉三卷故也。其義理等者，勸詳審也。論下，準論顯意。初二句指上列釋，蓋準論文；猶下，遮後妄謂，以彰略意。不犯中，初引五想。皆謂無盜心也。與想者，意謂他與也；己有者，謂非他物也；
【譯文】所以下文，引用論典來進行勸勉。論典中，第一句普遍顯示戒教的用意；從「此」字以下，特別指出眼前的盜戒，必須用繁複的文字來說明。所謂「曲碎解釋（詳盡細緻地剖析）」，是因為相關論述牽涉了三卷之多。所謂「其義理」等語，是勸人詳加審查。從「論」字以下，是依照論典來彰顯用意。最初兩句指稱上面的陳列解釋，乃是依據論書文字；「猶」字以下，是為了防範後人妄加非議，藉以表明之所以從略的用意。在不犯的範疇中，首先引用五種無犯罪之想，都指內心沒有偷盜之意。所謂「與想」，是心裡認為對方要送給自己；「己有想」，是認為這並非別人的物品；

【268-0008】資持記/07e_中一下#19
【原文】糞掃者，謂無主也；暫取者，即持還也；親厚者，無彼此也。律下，別釋第五。七法中，一竭力代勞，為之不厭；二己所重物，與之不悋；三極相違惱，了無所恨；四吐露私心，而無所隱；五掩惡揚善，恐傷外望；六囚繫患難，多方拯濟；七貴賤貧富，終始一如。如是下，結顯。
