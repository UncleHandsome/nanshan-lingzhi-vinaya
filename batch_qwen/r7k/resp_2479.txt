以下按「系統性問題 → 逐則檢核」的方式整理。整體說來譯文方向正確、可讀性不錯，主要毛病集中在**術語界定前後不一致**、**幾處科文的省略義沒補出來**，以及**一、二處可能的誤讀**。

---

## 一、三個系統性問題（優先處理）

**1. 「觸」與「惡」在四句中界定不一致（#7、#8，最嚴重）**

- 第一句譯「觸碰而非**惡觸**」→ 把「惡」當成惡觸。
- 第二句譯「有**惡意**而非惡觸」→ 卻把「觸」當成惡觸。
- 第三句又回到「既是觸碰又是惡觸」。

同一組四句裡，兩個關鍵字互相換位，讀者必然混亂。依科注 #8「**初句忘故不惡**」（因為忘誤，所以不惡）可判定：**「惡」是「惡心／犯罪」義，「觸」是「捉觸之事／食成惡觸」義**，四句應統一為：

> 一、有觸而無惡（罪）；二、有惡（罪）而食不成觸；三、亦觸亦惡；四、非觸非惡（清淨食）。

**2. 「惡觸」的釋義不精確（#1、#7 等）**

譯文注為「不合法的觸碰（惡觸）」，偏在「動作非法」。惡觸是**四不淨食（內宿、內煮、自煮、惡觸）之一**，重點在**食物因不當觸碰等而成不淨、比丘不得食**。建議首次出現時統一注為：「惡觸：食物成不淨，不得食用」。

**3. 「受」的用詞不統一**

同一篇中出現「領受／受領／受食法效／受食效力／加法領受」。建議統一作「受食（作法受）」、「失受」，必要時才加白話說明。另「簡別甄別」（#2）疊義、「抓摸」（#5）過俗，宜作「簡別」「捉持」。

## 二、逐則檢核

### 【#82 / 0001】
- ⚠️「具足戒者有三種情形」語意懸空。原文是科判「約人成觸」，應作「**受具戒的比丘，構成惡觸的情形有三種**」，才能與下文「淨人只有一種」對照。
- ⚠️「就比照時藥處理」太含糊。原文「類同時藥」＝**也一樣過正午即失受**，宜補明。
- △「義加口法」譯文逕作「若以口頭加法」——依 #83 科注這是对的，但**宜加校注**：「原文作『義』，依科注應作『若』」。否則讀者對照原文會以為譯錯。
- △「如上《十誦》、《多論》所除」：照科注「除即簡也」譯為「所簡別」雖不誤，但白話仍不懂。建議確認前文犯緣處，明確寫成「所簡別（揀除、開許不犯）的情形」。
- △「本觸名觸」可更貼原意：「**本是開許（比丘）自觸之物，如今反成惡觸**」。

### 【#83 / 0002】
- ⚠️ **「四種藥物過了正午、三種藥物超過期限」易生誤解**。依疏文脈絡，「四藥過中」是指**未加口法者**（時藥＋三藥未加法）過中失受；「三藥過期」是指**已加口法者**各越本期限。否則讀者會誤以為七日藥、盡形壽藥過中也失受（實則加口法後可非時服）。
 建議：「四藥（未加口法的）過中失受，三藥（已加口法的）超過各自期限失受，都會失受而成惡觸。」
- △「第一項指出上述的律與論」語序失真。應作「**第一項中所指的律、論，就是前面明犯緣處所引的**」。
- △「『除』就是簡別甄別」→「『除』是簡別（揀除）的意思」。
- △「污染之觸」可保留術語並釋義：「即『污觸』（油膩污染所成的惡觸）」。

### 【#84 / 0003】
- △「淨人只有一種情形」→「**就淨人（未受具戒、可為比丘執持食物者）而言，只有一種成觸的情形**」。
- △「如果如法奉授」宜把科注 #85 的關鍵補進來：「**（比丘）不自己拿取交付**，直接令淨人授與」，這樣「淨人手不須洗穢」的因果才成立（否則讀者不解為何淨人不必洗手）。
- 其餘（自執令授、前食汙手、又觸餘淨）譯得準確。

### 【#85 / 0004】
- 基本無誤。△「起初說明非法之相」可作「先明非法（成觸）的情形」；「合乎法則的緣故」可作「因為如法（受）的緣故」。

### 【#86 / 0005】
- △「是觸非犯」宜點明主體關係：「**雖有觸事，卻不構成犯（食者不犯）**」。
- △第三「破戒之人故意抓摸食物」→「破戒比丘故意捉持（他）食」；並補一句「**故食未觸者不犯**」，才看得出為何列在「非犯」。
- △第四「如上面因緣中所說仍屬清淨」：原文「如上緣淨」是專指上文的「**緣淨**」一詞（忘誤開緣故淨），建議保留術語：「如上文『緣淨』（開緣）所說」，並與 #87 用語一致。
- △「遇到特殊因緣」的「特殊」是添字，可刪。

### 【#87 / 0006】
- △「觸摸導致失受而重新加法，是指再次受食時的觸碰」語意打結。建議：「**因（淨人）觸而失受，於是重加法受；這是為了再受而有的觸，故不犯。**」
- △「第四項指因緣清淨」是把術語「緣淨」直譯，意義不明。建議：「**第四項所說的『緣淨』**，即上面《摩訶僧祇律》所說忘念、誤失而觸捉等」。
- 「次不成中初科」＝「其次『明不成（犯）』一科中的第一科」，譯文可再明確。

### 【#88 / 0007】
- ⚠️ 四句譯名須重寫（見上「系統性問題 1」）。
- ⚠️ **「不觸得噉」的譯法待核**：譯作「未被觸碰到的食物仍可食用」是字面讀法，但與該句標目「**惡而非觸**」相衝——若被觸處仍成惡觸，就該歸第三句「亦觸亦惡」。故另一讀法「**（食）不成觸，仍可食**」在義理上更順。建議覈對所引律文原文後定案，並加註說明取捨。
- △「如律文說」：原文「如文」多指**前面疏文所引之文**，可作「如前文所引」。
- △第三句「隨意觸摸造作者」可作「隨意造作（觸食）之人」，「怠墮奉持」宜作「懈怠不肯奉持」。

### 【#89 / 0008】
- ⚠️「因為是遺忘所以不算**惡意**」→ 依四句體例應作「**不成惡（罪）**」；「惡意」只講心，漏了「不犯」的結論。
- △「『坐』就是承擔罪名」→「『坐』即**結罪、定罪**（罪歸於能觸之人）」較貼律家用語。
- △「三、四可知」宜保留科注口吻：「第三、四句可知（略而不釋）」，不要擴寫成「道理很容易理解」。

### 【#90 / 0009】
- ⚠️ **「通其生熟」漏了「犯」義**。科注 #91 明說「初明通犯」，故應譯：「**生食、熟食通皆成犯（惡觸）**」，現譯「通於生食與熟食」等於沒說到重點。
- △「所以律中自己種植的蔬菜生長出來」句構不順，且「自種」的關鍵在**親手種植（手觸）**，宜補：「所以律中說：**自己親手種植**的菜蔬仍在生長，因時時變動的緣故，沒有內宿、惡觸之過。」
- △「內宿」未釋而「惡觸」有釋，體例不一；建議首次出現補注「內宿：食物於比丘住處（界內）經宿而成的不淨食」。

### 【#91 / 0010】
- 大致無誤。△「活的植物」→「**仍在生長之物（生物）**」較貼律家語；「生熟通皆成犯」這句正好可用來回頭修正 #90。

## 三、建議統一的小詞表

| 原文 | 建議譯法 |
|---|---|
| 具戒（者） | 受具足戒的比丘 |
| 淨人 | 未受具戒、可為比丘執持食物者（俗人／沙彌） |
| 受／受法／失受 | 受食（作法受）／受食之法／失去受（食）之效力 |
| 惡觸 | 食物成不淨、不得食（四不淨食之一） |
| 污觸 | 油膩等污染所成的惡觸 |
| 內宿 | 食物於界內經宿而成的不淨食 |
| 緣淨 | 開緣故（食）淨、不犯 |
| 坐（罪） | 結罪、罪歸於某人 |
| 觸／惡（四句） | 觸＝捉觸之事／食成觸；惡＝惡心犯罪 |

**最需動筆的三處**：#88 四句術語、#83「四藥過中／三藥過期」的分位、#90「通其生熟」補「通犯」。#88「不觸得噉」則建議查律文原句後再定，並在注中交代。
