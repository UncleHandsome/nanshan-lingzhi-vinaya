# 校閱材料　第383檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【383-0001】資持記/05a_上四#63
【原文】下句冥想，如彼光雲。所供中，初句明上求，下句即下化。涅槃翻寂滅，即果德也。維那下，明復位。可見。九問，緣中，初文。言準上者，即前雜法，或令恭敬，或令直聲，或不錯謬等。〔有本準上下有法字。〕或可指戒本前序。下指別法，彼明禮僧互跪上座誡勅等法。此明簡眾，不唯沙彌；
【譯文】第二句「光明雲臺遍法界」，是觀想光明雲臺，如同經中所說的光雲一般。下半偈的所供部分：第一句說明上求諸佛，第二句就是下化眾生。「涅槃」翻譯為「寂滅」，就是果上的功德。「維那打靜訖」以下，說明回到本位，這很明顯。第九門「問答法」中，在敘緣部分是第一段文。所說「準上」，就是指前面的雜法，或者令其恭敬，或者令其聲音正直，或者令其不發生錯誤等。〔有的版本在「準上」下有一個「法」字。〕或者也可以指戒本前面的序文。下文所指的〈別法〉，那裡說明禮僧、互跪、上座誡勅等法。這裡是說明簡別大眾，不只是沙彌。

【383-0002】資持記/05b_上四#1
【原文】或尼三眾俗士瞻禮，並須遣出；及十三難三舉二滅有犯等人，三根明委，亦須簡練，或令懺露。人不知法，但遣沙彌；白衣叢聽，雜穢同聞。深乖法律，極成輕易，悲夫！二中。若有說者，答云說欲及清淨已。三中，召問之辭。若依古戒本云：比丘尼眾遣何人來耶？今準光師戒本而問。
【譯文】若是尼部三眾或在家人前來瞻仰禮拜，都必須請他們退出場外；還有犯了十三難、三舉、二滅以及有戒罪在身的人，也必須以見、聞、疑三根審查清楚，予以甄別剔除，或者命其發露懺悔。現在的人不懂戒律法規，只懂得遣退沙彌；卻任由在家人聚集偷聽，讓身心雜染不淨者一同聽聞戒律。這極度違背佛制法律，實在太過輕浮隨便，真令人痛惜悲傷！在第二段中，如果有人代為說欲，就回答說已經宣說了欲及清淨。在第三段中，是傳喚詢問的言辭。如果依照古戒本所載為：比丘尼眾派什麼人來呢？現在則依據慧光律師的戒本來問。

【383-0003】資持記/05b_上四#2
【原文】誰字，亦即召彼尼眾。略法中，初科。儀法可解。次科。尼唯長跪，僧通長互；如《三千威儀》、《圓覺》等經，並云長跪，豈唯尼耶！〔舊云長跪表代尼者，謬矣。〕言別德者，教尼須具十德：一、具持戒行；二、多聞；三、誦二部戒本利；四、決斷無疑；五、善能說法；六、族姓出家；
【譯文】經文中的「誰」字，也就是呼召那些比丘尼眾。在簡略儀式（略法）中，第一科的儀軌法則容易理解。第二科中，比丘尼只能雙膝跪地（長跪），僧眾則通於互跪或長跪；就像《三千威儀經》、《圓覺經》等經典所記載，都說長跪，哪裡只是比丘尼才長跪呢！〔古人說長跪代表代替尼眾，那是完全錯誤的。〕說到「特別具備的德行（別德）」，教誡比丘尼必須具備十種德行：一是具足清淨戒行；二是博學多聞；三是背誦兩部戒本極其熟練；四是善於決斷疑難而無猶豫；五是善巧能說法要；六是出身尊貴家族而出家；

【383-0004】資持記/05b_上四#3
【原文】七、顏貌端正；八、堪為尼說法，令尼歡喜；九、非為佛出家，被三法衣而犯重法；十、二十夏若過。〔第八第十唯局教尼，名別德，餘名通德。〕三中，初受屬反白。上下，正出答法。
【譯文】七是相貌端嚴正派；八是堪能為比丘尼說法並令她們歡喜；九是不曾有在佛法中出家、身披三法衣而違犯重罪之事；十是出家滿二十個戒臘甚至更多。〔其中第八與第十兩條專門局限於教導尼眾，所以稱為特別德行，其餘八條稱為普遍德行。〕在第三段中，先是接受尼眾囑託後轉身稟白大眾。自鈔文「上座云」以下，正式標明回答的法度。

【383-0005】資持記/05b_上四#4
【原文】疏云：以見不學識者，年高座首，動無法則，空遣尼還，曾不對答，識者齊恥，故具引之。初褒美大眾。何啻者，言德有餘也。若下，令傳略教也。注中，初示前。餘下，指後。即〈尼篇〉中更引《善見》、《十誦》、《僧祇》等文，尋之可見。指廣法中。言時希者，〈尼篇〉云良由廣德難具故也。
【譯文】戒疏中說：因為看到不學無術的人，雖然年紀大高坐首席，舉止卻毫無軌則，只是徒然打發尼眾回去，竟然不知如何對答，讓識法之人都深感羞恥，所以才完整引出這套儀式。最初是讚美與會僧眾。「何啻」的意思，是說德行綽綽有餘。從「若」字以下，是吩咐傳達簡要的教誡。注文之中，先指示前面的內容。從「餘」字以下，是指向後面的文獻。也就是在〈尼篇〉中還會引用《善見論》、《十誦律》、《僧祇律》等經文，翻檢即可看見。這是指廣泛儀軌中的情況。說到「時希」，就是〈尼篇〉所說實在是因為廣博的德行很難圓滿具備的緣故。

【383-0006】資持記/05b_上四#5
【原文】事宗中，初科。注文斥古羯磨。言通用者，二名無異故。不了彼此者，華梵齊舉故。如〈羯磨篇〉中已明。不得下，遮濫。指過斥非，在文可見。次科，初垂誡。示下，勸依。一律儀者，即指上誡。故下，指證。云云者，三十四卷初，因難陀布薩時不來；
【譯文】在明了作事原則（事宗）中，第一科的注文斥責古代的羯磨文。說「可以通用」，是因為兩種名稱意義沒有差別。說「分不清彼此」，是因為把梵文和漢譯名詞同時並列。這在〈羯磨篇〉中已經解釋過了。從「不得」以下，是防止浮濫偽造。指出過錯、斥責缺失，在經文條文中可以明白看見。第二科中，先是垂示誡勉。從「示」字以下，是勸勉大眾依從。所謂「一種律儀」，就是指上面的誡約。從「故」字以下，是指出經典依據。文字說到「云云」，是指在律藏第三十四卷初，因為難陀在半月布薩時不來；

【383-0007】資持記/05b_上四#6
【原文】後來已即去，眾皆不知，白佛，因制上座法，應知十四十五日布薩若晝若夜；又當知處所，若溫室講堂林中；又應知廣誦五篇戒，下至四事及偈，餘者僧常聞；又應令人唱告時處，又應先使人掃治，誰應呪願行籌。〔此制知說戒也。〕又應知說戒時，檀越來；當為說法，共相勞問。
【譯文】後來來了之後隨即又離開，大眾都不知道，於是向佛稟白，佛便因此制定首座的職掌法規，應當知曉十四日或十五日布薩、是在白天還是夜晚；又應當知曉布薩的地點，是在溫室、講堂還是樹林之中；又應當知曉何時詳盡誦讀五篇戒，甚至減少到誦四事及偈頌，其餘篇幅則為僧眾平日所常聞；又應當派人唱名宣告時間地點，還應當預先使人打掃修治場地，並安排誰來咒願、誰來發放籌碼。〔這是制定首座要通曉說戒的規矩。〕又應當知曉說戒的時候，若有施主前來；應當為他宣說佛法，彼此問候慰勞。

【383-0008】資持記/05b_上四#7
【原文】〔此制知說法也。〕乃至第二上座亦爾，廣在彼文。十說竟中，初科。再鳴鐘者，必無小眾，亦不須之。若下，明梵唄。即律序末後二偈：神仙五通人，造設於呪術〔此舉世喻〕；為彼慚愧者，攝諸不慚愧〔為善攝惡〕；如來立禁戒，半月半月說〔合上喻也〕；
【譯文】〔這是制定首座要通曉說法之道。〕以至第二首座也是如此，詳盡記載在該部律文裡。在第十「說戒完畢（說竟）」中，第一科提到再次敲擊鐘磬，如果確定沒有沙彌等小眾在場，也就不需要敲。從「若」字以下，是說明梵唄。也就是律序最後面的兩首偈頌：「神仙具備五種神通的人，創造並施設了世間的咒術〔這是舉出世間的譬喻〕；如來為了護持那有慚愧心的人，從而統攝防備那些無慚無愧之徒〔為了揚善並攝伏惡劣者〕；無上如來立下嚴謹的禁戒，每半個月每半個月都要宣說〔與上文的比喻相合〕；

【原文】若約聞戒通塞，則六聚並同；若論別眾成不，則根條兩異。如律顯者，即如戒本，有犯懺悔，無犯默然。八中二，初明對首。露言對眾者，謂於眾前對人作法。律云：當至一清淨比丘所，具威儀，說所犯名種，白云：大德憶念我比丘某甲犯某罪，今向大德發露，後如法懺悔。〔三說。
【譯文】如果就聽聞戒律的准許或隔絕而言，那麼六聚罪相完全相同；如果就私自分割僧眾是否合法而言，那麼根本重罪與枝條輕罪便截然不同。如同律藏中所顯明的，就如戒本所定，有犯罪的人應當懺悔，沒有犯罪的人則保持默然。第八段分為兩部分，首先說明當面相對發露（對首）。「發露說面對眾人」，是指在僧眾面前對著特定一人如法作法。律藏說：應當走到一位清淨比丘身邊，端正具足僧人威儀，說出自己所犯的罪名和種類，稟白說：「大德請為我作證，我比丘某甲犯了某條罪，現在向大德發露陳述，過後當依照戒法如法懺悔。」〔說三遍。
