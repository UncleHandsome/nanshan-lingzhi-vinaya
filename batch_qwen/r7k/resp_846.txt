整體看下來，這批譯文對疏、記的科判（「初難／次難」「初師／次師」「引證／舉例」）掌握得不錯，文句也通順。問題主要集中在**幾處義理判讀**、**增譯過多**與**術語未加註**三類。以下按輕重排列。

---

## 一、判讀上應修正的地方

### 1. 【846-0003】「打、謗同罪」──主詞對象錯置（最需修正）

* 原文：「不同餘律，打、謗同罪。」
* 現譯：「其餘部派**毆打與誣謗是同等結罪**的。」
* 問題：這樣讀會變成「打罪＝謗罪」，但打是波逸提、謗是僧殘，任何律都不可能同罪。此句是承上文「謗尼同僧、打尼同小學」而來，意思是**餘律中不論對僧或對尼，打與謗各自同罪**（打尼亦提、謗尼亦殘），故與本律「打約位卑」不同。
* 建議：「這與其他部派的律典不同，餘律中（對尼）毆打與誣謗，都與對比丘結同樣的罪。」

### 2. 【846-0013】「但取見聞」譯成「二相」，與【846-0016】自相矛盾

* #13 譯「只取見、聞**二相**」，#16 記文卻明說「『但取見聞』者，**三根**外淨」。
* 「見聞」是略舉，實含「疑」，即見、聞、疑三根。譯成「二相」既與記文相違，也失去「三根外淨」的立論根據。
* 建議：「只取見、聞（疑）三根的外在表象」。

### 3. 【846-0001】「奉承」用詞不當；「隨」宜補出所隨對象

* 「僧無奉下」譯「比丘沒有**奉承**下位的道理」──「奉承」帶諂媚義，與律意不合。此處「奉」是敬奉、承事，「下」指下眾（尼）。
  → 建議：「比丘無須敬奉下眾（比丘尼）」。
* 「尼隨僧犯夷，僧隨尼犯吉」譯「比丘尼隨順比丘犯波羅夷……」，**易被誤讀為「跟著比丘一起犯夷」**。依上下文（「亦同違眾」＝違逆僧眾的擯舉羯磨），此應指尼八夷中「隨順被僧所舉比丘」，比丘隨順被舉尼則犯吉。
  → 建議：「比丘尼隨順（被僧團擯舉的）比丘，犯波羅夷；比丘隨順（被擯舉的）比丘尼，只犯突吉羅」。請再核對前文疏科確認。
* 「尼倚教」的「倚」是依恃、依憑，譯「依教」稍平；可作「比丘尼依恃（八敬）教制」。

### 4. 【846-0016】「不論內德」→「不論其內心道德如何」

「內德」指**實際的內在戒德（有無真犯）**，不是泛指的「內心道德」。此句是第二師的核心：只論三根外相清淨，不論實際是否犯戒。
→ 建議：「不論他實際的戒行有無染犯」。

### 5. 【846-0003】「謗約修行」→「依據修行受阻來考量」

「修行受阻」是自行添入的推論。原文只是說：謗是就對方「修行（梵行）」而論——尼與僧同受具戒、同修梵行，謗損梵行相同，故同殘。
→ 建議：「誣謗則是就（對方的）修行梵行而論」。

## 二、語句可再潤飾（不影響大意，但讀來不順或語意偏移）

| 編號 | 現譯 | 問題／建議 |
|---|---|---|
| 0006 | 「必須**取得**所對境是清淨者」 | 「取境」誤作「取得」，語病。→「可驗知所對之境須是清淨，才構成正式犯戒」 |
| 0006 | 「簡別出非犯重者」 | 雙重否定繞口。→「戒本以『非波羅夷』簡除已犯重罪者」 |
| 0007 | 「**加罪**誣謗他」 | 「加謗」即「加以誣謗」，「加罪」多餘且易誤解為判罪。→「加以誣謗」 |
| 0009 | 「**通暢說明**這裡所謂的不清淨」 | 「釋通」是會通、疏通。→「會通『不清淨』一語的含義」 |
| 0012 | 「所以引來**互相並論**」 | 「引為並」是引來作「並難」（以彼例此而反詰），非單純並列比較。→「所以引來作對比反難」 |
| 0012 | 「與對待清淨境一樣**都要結罪**」 | 原文重點在「同罪（同得提）」，不只是「都結罪」。→「打犯重者與打清淨者同樣犯波逸提」 |
| 0011 / 0013 | 「混濁」 | 「濁」指染犯、戒行染污，「混濁」偏物理義。→「染污（犯重）」 |
| 0011 | 「**身分**清淨與混濁」 | 清濁論戒行不論身分。→「所對境的清淨與染犯」 |
| 0014 | 「**憑什麼**去加以誣謗呢」 | 語氣變成質問正當性；原意是「若非心想對方清淨，何從起謗」。→「又怎會加以誣謗呢」 |
| 0014 | 「會有比丘尼**參與**嗎」 | 含糊。爭點是「緣起中被謗的對象沒有尼」。→「初制此戒的緣起中，（被謗的對象）哪有比丘尼呢」 |
| 0005 | 「但還須**他本身**戒體清淨」 | 指代不明，易與能謗者混淆。→「（所謗的）比丘還須戒體清淨」 |

| 0006 / 0016 | 「確立義理」／「確立論理」 | 同為「初立義／初立理」，用語宜統一 |

## 三、術語宜加註（白話譯文的關鍵）

1. **【0002】「大僧」「小學」**：現譯原樣照搬，一般讀者不解。建議首次出現加註——大僧＝受具足戒的比丘；小學＝沙彌、沙彌尼等未受具者。另「比丘尼」是依上下文補入的（原文未出），建議用括號標示補字，如「（對比丘尼）行謗」。
2. **【0008】「下四篇」**：宜註明「五篇中除初篇波羅夷外的後四篇（僧殘、波逸提、提舍尼、突吉羅）」，讀者才明白「不清淨」為何仍可構成謗殘。【0009】的「下篇」用語也宜與此一致。
3. **【0005】「出聚」「出房」**：建議註出所引戒條（九十波逸提中牽出房舍等戒），並確認「出聚」是否即「驅出聚落」；現譯「驅逐出村落」屬合理推斷，但宜留註。
4. **【0001】「八敬」「反前」**：「反前」是疏中原語，譯文直接改寫為「與前述相反」尚可，但可保留原詞再加括號解釋，方便對讀。

## 四、體例建議

* 譯文中補入的主詞、限定語（如「比丘尼」「未犯波羅夷」「同樣」「仍然」「完全」）建議一律用括號，維持「原文無、譯者補」的可辨識性；目前有的加括號（0005、0011）、有的直接融入（0002、0003、0010、0014），體例不一。
* 「律師」（0006、0016 對「師」的譯法）建議改作「（古）師／第一家解釋」，因元照此處指的是古解諸家，未必實指某位律師。

## 五、判讀正確、值得保留的部分

* 【0001】「亦同違眾，不當犯別」的難意、【0004】科判「初以義分／簡部別」、【0006】「破戒、破見、破威儀」的展開、【0010】「墮」譯波逸提、【0013】「眾法」譯僧團羯磨之法、【0014】「三根想實」、【0016】「三根外淨」──這些都準確，第二師「外相淨即成謗」與第一師「须體淨」的對立也譯得清楚。

**最優先處理順序**：0003（同罪對象）→ 0013（二相／三根）→ 0001（奉承、隨舉）→ 0016（內德）→ 其餘潤飾與加註。
