# 校閱材料　第1338檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1338-0001】資持記/15c_下三#37
【原文】以招譏故。若下，三制食訖自住。經下，四制知事後至。以營事人合先往故。食未下，五制未嚫輒起。謂未施財呪願。今僧未行嚫施，終無先去。纔得嚫已，不待呪願者多矣。餘人，謂非首領上位者。私行，謂潛去。報同學者，令知所緣。雖下，覆釋初制。前明施家，此文似是他家。
【譯文】因為這樣做容易招致外人的譏嫌非議。自「若」以下，第三是制訂用齋完畢後不可私自逗留。自「經」以下，第四是制訂管理寺務的知事僧不可遲到後至。因為負責籌辦營造公務的人，理應在僧眾之前早早前往照料。自「食未」以下，第五是制訂施主尚未行布施時不可擅自離席離去。這是指施主尚未分發布施財物及進行咒願迴向之時。現今的僧人若是施主尚未行施布施，絕沒有肯提前離開的。然而才剛拿到布施的嚫錢，便急不可耐、不等僧長為施主咒願迴向就溜之大吉的人，實在是太多了。所謂「餘人」，是指不是擔任首領上座的其餘清眾。所謂「私行」，是指私下暗中離去。所謂「報同學」，是為了讓同參道友知道自己離席的原委。自「雖」以下，反過來重新解釋第一條制令。前面說明的是施主家，這段文字表面看起來似乎是指一般平常人家。

【1338-0002】資持記/15c_下三#38
【原文】八中。二文並明僧次。論約法同，經聽形同；無非皆為解脫出家，即堪受供。《涅槃》云：雖未受戒，已墮僧數。九中。《僧祇》作念，即晨起六念，念食處故。餘處悔過者，違念吉羅。《十誦》結犯，且據俗舍別請為言。下引論決，作相免過，此通施家，不唯常住。〔古云此據僧舍者，非。
【譯文】第八段中。經、論兩處文段都同樣闡明應當遵從僧團長幼次序受請。論典是從如法受戒的角度來界定，經典則是開許只要形貌剃染出家就同等看待；因為無非全都是為了求取解脫而捨俗出家，所以就堪能接受世間的信施供養。《大般涅槃經》說：沙彌雖然尚未受具足戒，但實質上已經算列在僧寶的數目之中了。第九段中。《僧祇律》要求必須用心作念，也就是清晨起床時的「六念」之一，要清楚憶念自己今日受請用齋的處所。鈔文說到其他處所受食就要悔過，是因為違背了晨朝作念而結犯吉羅罪。《十誦律》中所結犯的罪名，暫且是就俗家私室單獨挑選別請的情況而言。下文引用論典作出判決，只要預先標定作相就能免除過失，這種開許通於一切施主家，並不僅限於常住寺院之內。（古來有人認為這段純粹是就寺內僧舍而言，那是不正確的。）

【1338-0003】資持記/15c_下三#39
【原文】第二門《四分》，初明眾集。言欲受者，謂將往也。若檀越下，次明往赴，有三，初示威儀。隨後相次，如飛雁焉。若下，二開前去。三寶看病是緩緣，故制須白；命梵急難，故通不問。若上座下，三令相待。據文所明，下待於上；義準上下並須相待，恐不及眾，容失道故。
【譯文】第二門《四分律》，首先說明僧眾集合的儀軌。所謂「欲受」，是指大眾將要前往應供之時。自「若檀越」以下，接著說明前往赴請的行止威儀，分為三個部分，首先示導威儀秩序。大眾應當依序相隨前進，整齊有序就像空中飛翔的雁行一樣。自「若」以下，第二是開許可以提前先行的特殊因緣。為了三寶公事或前往探視重病是屬於較為寬緩的因緣，所以制訂必須事先稟白（上座）；若是事關性命安危或梵行清淨的緊急災難，則通融開許不必事先稟白。自「若上座」以下，第三是命令彼此應當停步等待。依據律文表面所闡明，是下座等待上座；但在義理準則上，無論長幼上下全都必須互相守候等待，唯恐有人跟不上大眾隊伍，容易在路上失卻比丘應有的威儀道法。

【1338-0004】資持記/15c_下三#40
【原文】第三安聖位中，初科，先明佛像位。或有別堂，則就本處。然下，次排聖僧座，為三，初引所據。梁武所出，其文已亡。《賓頭盧經》，藏中見有，具明請法；由彼尊者，佛勅在世，為末法四部，作大福田；志誠虔請，多有感應。預宿請者，經云：新床新褥綿敷，以白練覆綿上。〔即虛軟也。〕初夜如法請之，無不至也；
【譯文】第三門安置聖位（聖者席位）的科判中，第一小科首先說明佛像的安奉方位。如果施主家中設有獨立的佛堂，就直接依原處恭敬禮拜供養。自「然」以下，接著安排聖僧的座位，分為三個層次，首先引述所依憑的經典依據。梁武帝所編訂的文獻，其原文在現今早已佚失。《賓頭盧經》在大藏經中目前尚有收錄，經中極詳細地說明了延請尊者的儀軌；因為那位賓頭盧頗羅墮尊者，蒙佛陀慈命長久住世不入涅槃，要為末法時代的四部弟子作為廣種福田的大福田；只要弟子以志誠懇切之心虔誠迎請，往往能產生不可思議的靈驗感應。所謂預先在宿夜先行迎請，經中說：要準備全新的床鋪與全新的褥墊，裡面鋪上細軟棉絮，再用潔白的細絹覆蓋在棉絮之上（也就是要極其虛軟舒適）。在初夜時分依照教法至誠迎請，尊者無不應感降臨；

【1338-0005】資持記/15c_下三#41
【原文】來則褥上現有臥處，浴室亦現用湯水處；大會請時，或在上中下座，現作僧形；人求其異，終不可得；去後見花不萎，乃知之也。〔謂以鮮花布座，聖位不萎為驗。〕今此束略，但云坐處有相耳。今下，次令教示。請聖事難，故云不易。俗人咨稟，謂之門師；俗家之人，即門徒也。〔今反召僧為門徒非。〕必下，三明自設。
【譯文】若是尊者降臨，褥墊上自然會顯現出有人躺臥壓過的痕跡，浴室之中也會顯現出有人使用過溫水洗浴的痕跡；在舉行盛大的齋會延請時，尊者有時會坐在上座、中座或下座，隨緣示現成普通僧人的形相；人們若想從外表找出神異奇特之處，始終是無法看出來的；直到法會結束散席之後，看見唯獨尊者座席上的鮮花依然鮮豔不萎縮，人們這才恍然知曉尊者方才確實降臨過了（這就是指用鮮花鋪散在座位上，以聖僧座上的花朵不枯萎作為驗證）。如今此處只是高度概括簡略說明，所以僅僅說坐處自然會有神異徵驗罷了。自「今」以下，接著指示僧人應當負責教導示導施主。迎請聖僧這件事極其嚴肅困難，所以說「不易」。在家凡夫前來請教稟受法義的僧人，稱之為「門師」；俗家受教的信徒，就是門師的「門徒」（現今世人反過來把出家僧人稱呼為門徒，那是完全顛倒錯誤的）。自「必」以下，第三是說明若俗人不會，僧人應當親自協助施設。

【1338-0006】資持記/15c_下三#42
【原文】斥非中，初示非。坐訖，即慢聖。在地佛前，並非處。狹小，謂薄略。按《尼鈔》，座不得高尺六；又不以常住僧器供養，由護戒同凡故；或有嚫施，還入聖僧用。〔準俗舍無用，應付所請僧寺，聖僧用之。〕又但設虛座，不得上安形像等〔云云。〕如下，正斥。
【譯文】在斥責不如法的段落中，首先指出錯謬之處。僧人自己坐定之後，那就是嚴重輕慢褻瀆聖僧。隨便安置在地面上或直接擠在佛像正前方，全部都不合規矩體統。所謂「狹小」，是指鋪設得過於粗糙薄劣簡陋。依照《尼鈔》的規制，聖僧的座位高度不得超過一尺六寸；又絕對不能用常住僧眾自用的器具拿來供養聖僧，這是由於聖僧護持戒律、示同凡僧之故；如果法會中有布施給聖僧的嚫錢財物，事後應當全部歸入供奉聖僧的用途之中。（依照準則，俗人家中若無處可用，應當交付給所迎請僧人所屬的寺院，專供聖僧修福之用。）此外，現場只能陳設虛懸的空座，絕對不可在空座上方隨意安放實體形像等等（此處義理極廣，不再贅述）。自「如」以下，為正面斥責。
