# 校閱材料　第126檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【126-0001】資持記/05e_上四#60
【原文】大德僧聽〔合牒白中緣本〕！諸大德忍某甲比丘〔云云如上〕者，默然；若不忍者，便說；僧已忍某甲比丘〔云云〕竟；僧忍默然等，如常。〔必有用者，依本宗綱緣改之。〕次科，初明開制。不得說道德者，遮其詞，免作留難。若不共作，令彼經宿，不成受故。所以下，示意。
【譯文】大德僧聽〔應當全體宣讀白告中之緣起根本〕！諸大德若贊同某甲比丘〔文詞如同上述〕的人，請保持沉默；若不贊同的人，請發言；僧眾已經贊同某甲比丘〔云云〕完畢；僧眾贊同而沉默等，程序如同常規。〔如果有需要使用的場合，依照本宗的提綱緣由加以更改。〕下一科，首先說明開許與制約。不得講說佛法義道，是為了遏止其言詞，免得造成拖延留難。若不共同製作，使得衣料放置隔夜，就不能成辦受衣之故。「所以」以下，顯明其中的用意。

【126-0002】資持記/05e_上四#61
【原文】諸佛贊者，能使得利，安樂修道故。論云：昔有佛名蓮華，有弟子名須闍多，作迦絺那衣未成，故與諸比丘共作。後科指廣，仍申略意。此雖不出，前衣體中，文亦詳矣。更引《僧祇》示之；彼云：若外人施衣財，不得默受；應作是說，我今受迦絺那衣財，受已；到僧中白二，告僧云：大德僧聽！
【譯文】諸佛之所以讚歎，是因為能讓僧眾獲得利益，從而安樂修持道業之故。論典說：過去有尊佛名叫蓮華佛，有名弟子名叫須闍多，製作迦絺那衣尚未完成，所以佛陀便與諸比丘共同縫製。後面的科判指引詳廣的內容，並進一步闡述簡略的用意。這裡雖然沒有全盤開出，但在前面衣服體質的段落中，文字已經非常詳盡了。在此進一步引用《僧祇律》來說明；該律記載：若是界外之人（或俗人施主）布施衣料，不得默默接受；應當這樣說道：我現在接受迦絺那衣料，接受完畢後；來到僧眾之中行白二羯磨，稟告僧眾說：大德僧聽！

【126-0003】資持記/05e_上四#62
【原文】僧得此時衣財；若僧時到，僧取此迦絺那衣，白如是。〔羯磨準作，合上緣本，為第二句。〕次差能作衣者，若一人、若二三人，白二差之〔如上。〕差已，一人作主；受衣財時，應作是言：受此迦絺那衣財，僧當受。〔三說。〕浣時，應云：浣是迦絺那衣，僧當受；
【譯文】僧眾得到這件應時衣料；若僧眾時機已到，僧眾領取這件迦絺那衣，白告程序如是。〔羯磨法比照製作，結合前面的緣起根本，作為第二句。〕接著差派能夠裁製衣服的人，或者一人、或者兩三人，以白二羯磨來差派他們〔如同上面所述。〕差派完畢後，由一人來主持其事；在接受衣料時，應當這樣說：接受這件迦絺那衣料，大眾僧應當受持。〔說三遍。〕清洗時，應當說：清洗這件迦絺那衣，大眾僧應當受持；

【126-0004】資持記/05e_上四#63
【原文】如是裁時、縫時、染時、點淨時，隨所作，如上三說；不說而作亦成，但得越毘尼罪。正受中，初科。橫疊者，從長量也。疊即是欇。兩頭兩綴，中間三綴，五綴則為四疊。〔準此，長量止八尺許明矣。〕秉法中，初簡眾。總前諸部，共十一人；一與欲人〔即不現前。〕，二有難〔此通一眾。
【譯文】像這樣在裁切時、縫紉時、染色時、點淨時，隨應各個製作動作，都要如同上述念誦三遍；即便沒有口說而直接製作也能成辦，只是會犯下越毘尼罪而已。在正式受衣的段落中，第一科。所謂「橫疊」，是順著長度的方向來折疊。疊就是折疊收攏。兩端共兩處縫綴固定（兩端各一綴），中間有三處縫綴固定，五處縫綴固定便會形成四重折疊。〔依此看來，長度尺寸只有八尺左右，這是顯而易見的。〕在主持羯磨法中，首先簡選僧眾資格。總合前面諸部律典，總共有十一種人；第一是傳送欲法的人〔也就是本人不在現場。〕，第二是遭遇難事的人〔這通於全體僧眾。


【126-0005】資持記/05f_上四#1
【原文】〕，三無大衣，四異界，五中後安居，六破，七不結，八犯殘，九別住，十學悔，十一擯人。令別坐者，以合受人，必相連接；行事便故，不依次第也。雖下，遮情。恐謂雨分，容乖別故。問答中。且據通衣，通下三法。若行別答，隨法牒之。白中。問：此與自恣法，差白前後者？
【譯文】〕第三是沒有大衣，第四是身在不同結界，第五是屬於中安居或後安居，第六是破夏（中途破壞夏安居），第七是未結夏安居，第八是犯僧殘罪，第九是處於別住期，第十是正在學悔，第十一是被擯除出僧團的人。之所以命令這些人另外坐，是因為符合受衣資格的人必須坐在一起互相緊接；這是為了行事方便，所以不按戒臘次第排坐。「雖然」以下的話，是為了排除眾人疑慮，唯恐有人認為大眾分成兩處分開坐，就容或構成了非法別眾的緣故。在問答之中，暫且是依據能通用的三衣，貫通下文的三種作法。如果要分開回答，就隨著作法來具體陳述。在單白羯磨之中。有人問：這個法門與自恣法的推選和告白，先後順序為何相反？

【126-0006】資持記/05f_上四#2
【原文】答：有人言：德衣聽教，通作不作；先和告眾，許作方差；自恣嚴制，無慮不行；直爾先差，後方和眾。或可德衣三法，竝上座作；自恣白和，須五德秉，故不等也。又可制法不同，不須比難。差人中。注示儀式。與一比丘者，與謂相對。問答文似別對餘人；準律，即是五德。與衣中。注文，先示五德具儀；
【譯文】回答是：有人說：受功德衣是聽任僧眾決定的教法，可做也可不做；因此要先和合告知大眾，大家答應做了才能推選人員。自恣則是佛陀嚴格制定的，無須顧慮不去做；所以可以直接先推選人，之後才去和合大眾。又或者說，受功德衣的三種法門，都由上座來操作；而自恣的告白和合，必須由具備五德的人來主持，因此兩者並不相同。又或者可以說，兩者的制定法則本來就不同，不需要硬拿來互相比照問難。在「差人」（推選人員）之中，注文指示了具體儀式。「與一比丘」中的「與」字，是指彼此相對面對面。問答的文字看起來像是另外面對其他人；但依照律藏，對象其實就是那位五德比丘。在「與衣」（交付衣物）之中，注文先說明五德比丘應當具備的威儀；

【126-0007】資持記/05f_上四#3
【原文】當下，上座作法羯磨。緣中，可分衣，即目輕物，此牒緣也。僧下，牒本；上二句，示僧眾付衣；此比丘下，明五德受衣。次受衣中，次科。上座跪者，準下三座皆然。却行，即退身也。所以自恣對二三人，今對四人者，思之可解。陳詞中三，初五德作法。未受令受，曰當；正受是今，結今名已。
【譯文】「當」字以下，是上座施行作法羯磨的內容。在因緣之中，提到「可以分衣」，就是指輕賤的物品，這是在陳述受衣的由來因緣。「僧伽」以下，是在重述本事的文句；上面兩句是說明僧眾交付衣物，從「這位比丘」以下，則是說明五德比丘接受衣物。接下來是受衣的內容，這是第二個科判。上座跪著，按照下文其餘三座也都是如此。「卻行」就是身體向後退步。之所以自恣時只面對兩三個人，而現在受衣卻要面對四個人，仔細思索就能理解其中的道理。陳述受衣辭句中分為三部分，首先是五德比丘依作法陳詞。尚未接受而令其接受，稱為「當」；正在接受則是「今」，結定當前受事已成，則稱為「已」。

【126-0008】資持記/05f_上四#4
【原文】二僧受詞中。其受者，通指眾僧。善受者，無非法過。此中者，指所受衣。衣名功德，名必有實，功既屬我，必獲五利。各各說者，非合誦也。三五德對答。四人說已，總以一答。〔《四分》唯有僧法；《僧祇》開對首心念受者，應是部別，故所不引。〕捨法中。
【譯文】第二部分是僧眾受衣的辭句。文中的「受者」，普遍是指在場的全體僧眾。「善受者」，是指受衣如法而沒有違犯戒律的過失。「此中」是指所接受的衣物。這件衣服名為「功德」，名稱必然有名實相符的內涵，功德既然屬於我們，就一定能獲得五種利益。「各各說」是指每個人各自開口陳述，而不是大家一起合誦。第三部分是五德比丘對大家作回答。四個人說完之後，五德比丘總共以一句話來答覆。〔《四分律》中只有僧團共同作法；《僧祇律》則開許對面首向或以心念來領受，這應當是部派傳承不同，因此這裡沒有引用。〕在捨衣法之中。

【原文】律因六群不出功德衣，以久得五事故捨，故佛因制捨。若不出，過功德衣分齊，突吉羅。本部中，初科。上二可解。又下，律云：有八種因緣，捨功德衣：一去〔作不還意，出去便失；由本受時，竝有要心，後違故失也。〕，二竟〔出界作衣，作竟即失。〕，三不竟〔出界得念，亦不作衣；

【原文】以後果本，不可頓犯，假彼相成故。若根本下，釋隨順義。纔至果罪，共成一體，無別方便。此同《四分》，則異十祇。餘下，指例。會通中，初引三文。《四分》不成，不言多少。《了論》一品，不顯重輕。唯茲《十誦》，甚有眉目；
