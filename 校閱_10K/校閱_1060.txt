# 校閱材料　第1060檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1060-0001】資持記/05f_上四#7
【原文】前五違本要心，故失；後三還因羯磨出之。問：後三與前僧和合出，有何異耶？答：前是時滿，後三不定，故不同也。別顯中。初明問和者。律中，唯此羯磨，及戒本序，前具列之。餘皆例用。故須詳示，令知所出。文中六緣，且據問者，終須具十，如上篇中。他部。《僧祇》有十種：一衣竟捨〔受已作念，衣竟當捨，後竟即捨。
【譯文】前五種因緣是因為違背了最初立下的約定之心，所以失去；後三種則是依靠羯磨作法而捨出。有人問：後三種情形與前面僧眾和合捨出，有什麼差別呢？回答：前面那是時間期限已滿，後三種則是時間並不固定，所以不相同。在「特別顯明」（別顯）之中，首先說明詢問僧眾和合的文句。律典之中，只有這個羯磨以及戒本的序文，在前面完整地列出這些文句，其餘各處都援例套用。所以必須詳細列示出來，讓大家知道它的出處。文中所說的六種緣由，只是暫時依據詢問時所提的項目，實際上最終必須具備十種條件，如同前一篇中所說的那樣。至於其他部派，《僧祇律》列有十種捨衣因緣：第一是衣服做完捨〔受衣後心想，衣服做完就應當捨去，後來做完時就捨去。

【1060-0002】資持記/05f_上四#8
【原文】二受時捨〔作念受衣時當捨，後受即捨。〕，三時竟捨〔作念爾許時當捨，期滿即捨。〕，四聞捨〔作念聞和上闍梨捨時當捨，後聞即捨。〕，五送捨〔作念是衣與他已當捨，後送即捨。〕，六壞捨〔受已，中間自言我今捨，作是語時即捨。
【譯文】第二是受衣時捨〔心裡想著接受衣服的時候就應當捨去，後來接受時就捨去。〕第三是期限結束捨〔心裡想著到了某個特定時間就應當捨去，期限一到就捨去。〕第四是聽聞捨〔心裡想著聽說和尚或阿闍梨捨衣時我就捨去，後來聽說了便捨去。〕第五是贈送捨〔心裡想著把這件衣服送給別人之後就應當捨去，後來送出時就捨去。〕第六是毀損捨〔接受之後，中途自己說我現在要捨棄，說這句話的當下就捨去。

【1060-0003】資持記/05f_上四#9
【原文】七失捨〔作念是衣中間敗壞失不現當捨，後壞失即捨。〕，八出去捨〔作念此中住，去時當捨，後去即捨。〕，九過時捨〔如鈔所引，彼云得越毘尼。〕，十究竟捨〔至臘月十五日，僧中一人唱云：大德僧！今日僧捨迦絺那衣。三說。〕。
【譯文】第七是遺失捨〔心裡想著這件衣服若中途破損或丟失不見就應當捨去，後來毀壞遺失時就捨去。〕第八是出走捨〔心裡想著在此處居住，離開的時候就應當捨去，後來離開時就捨去。〕第九是超逾期限捨〔如同《行事鈔》所引用的，該律說這會犯越毘尼罪。〕第十是究竟徹底捨〔到了十二月十五日那天，僧眾中由一人宣唱：大德僧！今天僧團捨去迦絺那衣。共宣說三遍。〕。

【1060-0004】資持記/05f_上四#10
【原文】指餘部者，《五分》八事失：一時竟〔即《僧祇》過時〕，二失衣，三聞失，四遠去，五望斷〔此四同上《四分》〕，六衣出界〔將德衣出界經宿也。〕，七人出界〔同《四分》持人出界宿〕，八白二捨〔《四分》單白〕。
【譯文】指引其他部派的內容，《五分律》說有八件事會失去利益：第一是時間已到〔也就是《僧祇律》說的過時〕，第二是丟失衣物，第三是聽聞他人已捨而失去，第四是遠走離去，第五是求衣希望斷絕〔這四種情況與上述《四分律》相同〕，第六是衣服出界〔帶著功德衣離開結界在外過夜。〕第七是人出界〔與《四分律》所說帶著衣物的人在界外過夜相同〕，第八是行白二羯磨來捨衣〔《四分律》則是用單白羯磨〕。

【1060-0005】資持記/05f_上四#11
【原文】《了論》有八：一竟，二成就〔未詳〕，三出離〔同前去也〕，四失，五聞，六過位〔即時過也〕，七望斷，八共拔除〔作法出也〕，十種，如上《僧祇》。各隨下，通示諸文之意。違本心者，且據多分，其間不無作法過時。五利中。標云通塞者，通謂五月得利，塞即時外不開。〔此中止論有衣五月，其一刀常開；
【譯文】《律二十二明了論》列有八種：第一是做完，第二是成就〔具體含義不詳〕，第三是脫離而去〔與前面的離去相同〕，第四是遺失，第五是聽聞，第六是超越時限〔也就是時間過期〕，第七是希望斷絕，第八是共同廢除〔透過作法來捨去〕；若說十種，就如同前述《僧祇律》所說。「各隨」以下，是綜合說明各部文義的總體意旨。說違背本來心願的，只是暫且就大部分情況而言，其中也不乏透過作法或者超逾時限的情形。在「五種利益」（五利）之中，標題標明「通塞」，「通」是指在五個月之內可以獲得利益，「塞」則是指在規定時間之外不開許享受特權。〔此處單純只討論有衣在身的五個月，至於無功德衣時常途開許的一個月；

【1060-0006】資持記/05f_上四#12
【原文】如〈安居篇〉，不可相濫。〕通塞中，初通列五相。總開八罪，畜長攝三〔十日月望急施〕，離衣含二〔聚蘭〕。〈釋相〉具明，竝指如後。所以開者，夏竟營衣，出入多務；若不開通，無成濟故也。
【譯文】這與〈安居篇〉所說的情況相同，不可互相混淆。〕在「通塞」之中，首先普遍列出五種情況的行相。總共開許免除八種罪過，允許蓄留長衣涵蓋了三種情況〔十天期限、月望以及緊急布施〕，離衣而宿則包含了兩種罪過〔聚落與蘭若〕。〈釋相篇〉中有詳細說明，都指示在後文。之所以給予開許，是因為夏安居剛結束需要經營縫製衣物，進出事務繁多；如果不給予通融，事情就無法辦理成功。

【1060-0007】資持記/05f_上四#13
【原文】準《十誦》，得九利：一十夜〔長衣〕，二六夜，三一夜〔即二離衣〕，四五緣留僧伽梨〔一恐怖，二雨，三營大衣，四浣染，五深藏。〕，五五緣留雨衣，六數數食，七別眾，八九二時不白入聚落。〔《四分》不開非時，部別不同〕。其下，別簡畜長，初明分齊。一年之中，五月為時；七月名非時。
【譯文】依照《十誦律》的規定，共可獲得九種利益：第一是可留十夜〔長衣〕，第二是可留六夜，第三是可留一夜〔此二條即離衣的開許〕，第四是允許因五種緣由把大衣留在原處〔一是有恐怖威脅，二是下雨，三是營辦大衣，四是清洗染色，五是妥善收藏。〕第五是允許因五種緣由把雨衣留在原處，第六是可多次進食，第七是可以別眾食，第八與第九是在食前與食後這兩個時段不需告知同伴就能進入村落。〔《四分律》並不開許在非時隨意入村，這是部派規定不同〕。其下專門挑出「蓄留長衣」來討論，首先說明期限的界線。一年之中，有五個月屬於正當時限；其餘七個月則稱為非時。

【1060-0008】資持記/05f_上四#14
【原文】餘下，指相攝。時前十日開受急施，即非時攝時也；自恣竟不為安居施者，時攝非時也。誡等心中，恐於利養，得失動懷；故引經示，令心平等。初列四法。即是八風，四違四順。文先舉違，故云有四；後方合辨，則云八法。無恐是心，以安住故。不轉即身口，以守常故。
【譯文】「其餘」以下，是指兩者相互涵蓋包容的情況。在正當時限之前的十天內，開許接受緊急施捨的衣物，這就是非時期間包攝了時衣（非時攝時）；自恣結束後卻不為了安居而施捨衣物的，這就是正當時限包攝了非時衣（時攝非時）。在「告誡保持平等心」之中，是恐怕大家對於供養利養的得到與失去而心生動搖；因此引用經典開示，讓內心保持平等。首先列出四種情況。這其實就是世間「八風」，也就是四種違逆、四種順境。文中先列出違逆的一面，所以說是四種；後面合併起來辨析，就稱作八種境界。心中毫無畏懼，是因為內心安住的緣故。身口沒有改變，是因為堅守常規的緣故。

【1060-0009】資持記/05f_上四#15
【原文】得下，示得失平等。初別釋第一，是今正意；餘三因引，故所不明。八法者，一利，二衰〔即上得失。〕，三毀，四譽，五稱，六譏，七苦，八樂。四違對上四順，相反可知。上即修己。為下，示他。得失榮辱，皆本業緣；違順風來，故無忻慼也。〔即本以前段作注字，又無經文傳之訛脫。
【譯文】「得」字以下，展示了得與失應當看作平等。首先特別解釋第一種情況，這是現在主要要表達的意思；其餘三種只是順便引出，所以不作詳細說明。所謂的八種境界，第一是利，第二是衰〔也就是上面說的得到與失去。〕第三是毀謗，第四是讚譽，第五是稱揚，第六是譏刺，第七是痛苦，第八是快樂。四種違逆與上面的四種順境相對，正好相反，這是很容易明白的。上面所說的是修持自身。從「為了」以下，是教導開示他人。得到、失去、榮耀、恥辱，全都是由於自己過去的業力因緣所致；無論是違逆還是順應的八風吹拂而來，因此心中都不會生起欣喜或悲傷。〔此處原文在舊版本中本來被當作小字注文，又因為缺乏經文對照，所以流傳過程中出現了訛誤缺漏。〕
