# 校閱材料　第511檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【511-0001】資持記/05e_上四#42
【原文】《五分》。受請，正據俗舍；有惱請主，故結重提。非請處者，即是僧舍；反上得住，準前應吉。次約化教顯過。五中，一二可見；或下，三句為三種。二三相濫，以義分之；上是慳悋，下即貪求，或可上約田宅園林，下是錢寶󰝿帛。此五，無非慳貪多事，非出家業；遠離此者，成德可知矣。
【譯文】《五分律》。受請，正是就著俗人的房舍而說；因為會惱亂施主，所以結成重的波逸提。不是受請的地方，就是僧舍；與上面相反，可以停留；比照前面，應當得突吉羅。其次就化教顯示過失。五種之中，第一、第二可以明白；「或」字以下三句，分為三種。第二與第三容易混淆，要按義理區分：上面是慳吝，下面就是貪求；或者可以說上面是就田宅園林而說，下面是就錢財珍寶、穀米布帛而說。這五種，無非都是慳貪和好事多務，不是出家人的本業；能遠離這些，成就德行就可想而知了。

【511-0002】資持記/05e_上四#43
【原文】迦絺那衣。律中，佛在舍衛拘薩羅國；諸比丘夏安居竟，往見世尊；道路值雨，衣濕僧伽梨重，疲極；又寒雪國，糞掃衣比丘，來見世尊；亦值天雨，疲極；因聽受功德衣，開五種利。注中翻名，《了論》四名。第二從施主，餘三就功能。上二名下，自釋。無敗壞者，補舊易新也。
【譯文】迦絺那衣。律典記載，佛陀住在舍衛國拘薩羅國時；諸比丘結束夏安居後，前往探視拜見世尊；在半路上遭遇大雨，衣服濕透使得大衣僧伽梨極為沉重，身體困頓疲極；又有寒雪國的糞掃衣比丘前來拜見世尊；同樣遭遇天下大雨，困頓疲極；佛陀因此聽許接受功德衣，開許五種便利權益。注文中翻譯名義，《了論》列出四種名稱。第二個名稱是順從施主而立，其餘三種是依據功能來立名。「上二名」以下，自作解釋。所謂「無敗壞」，是指修補舊衣換成新衣。

【511-0003】資持記/05e_上四#44
【原文】〔有云：畜長過限，不犯捨，非也。〕堅固者，能使五戒無缺也。癊覆者，令眾得五利也。次古翻二名，可解。五利，如下說；開竝為益，故同名利。分章中。竝雜出者，即下五利時非時等。初科，本宗中，初定時分齊。前引文，示開受之始；後引文，證制捨之終；
【譯文】〔有人說：畜長衣超過期限，也不犯捨墮（尼薩耆波逸提），這種說法不對。〕「堅固」這一名稱，是說它能使五戒無所缺犯；「癊覆」這一名稱，是說它能使僧眾得到五種利益。其次古譯的兩個名稱，字面就可以理解。五利，如下文所說；這些開許都是為了利益，所以同樣稱為「利」。分章中，「竝雜出」這一句，就是指下文所說的五利、時、非時等。第一科，本宗的部分，先確定時間的界限：前面所引的文，顯示開許受衣的開始；後面所引的文，證明制約捨衣的終止。

【511-0004】資持記/05e_上四#45
【原文】中間則下，準知五月明矣。應受者，即佛聽也。前安居，簡除中後也。冬四月者，連夏一月，共為五也。如下，明餘日得受。故下，引證；謂下，轉釋。但云即日，故知不局。所以不許經宿者，二意詳之：一恐久延，過時失受；二是開奢，必須制約。《十誦》。證上受通一月，是明文也。
【譯文】在前後二文中間，鈔文「則」字以下，準知五個月的期限已甚為明瞭。所謂「應當受」，就是佛陀開許聽任。所謂「前安居」，是簡別剔除了中安居與後安居。所謂「冬四月」，是連同夏天最後一個月，總共合為五個月。如後文所說，說明其餘日子也能受衣。所以以下，引用律文作證；「謂」字以下，轉述解釋。文中只說「即日」，所以知道時間並不局限。之所以不允許經過一夜，詳細審度有兩層用意：一是擔心拖延太久，過了時限而失去受衣機會；二是這項寬鬆開許之法，必須加以規範制約。《十誦律》。證實上面所說受衣通達一整個月，這是明確的依據。

【511-0005】資持記/05e_上四#46
【原文】《四分》、《十誦》，受有三十日，捨唯一日；下引《母論》亦然。《五分》中。受同諸部，捨法獨異。彼約得衣日去，數滿四月；事同安居，前減後增，竝通一月。問：何以異耶？答：準詳諸部，皆開四月；但是宗計，各見不同。《五分》則取受衣為始；
【譯文】《四分律》與《十誦律》說：受衣有三十日，而捨衣只有一日；下面所引的《母論》也是如此。《五分律》中，受衣與諸部相同，捨衣的方法卻獨自不同。它是從得到衣的那一天算起，數滿四個月；情形與安居一樣，前面減少、後面增加，都通於一個月。問：為什麼不同呢？答：依據諸部仔細考察，都開許四個月；只是各宗的主張，見解不同。《五分律》是以受衣為起算點；

【511-0006】資持記/05e_上四#47
【原文】《四分》以迦提常開，不在其數。若據八月十五受者，不妨《四分》，還成四月；《五分》却得五月，思之可解。《母論》，初明受捨；後七月下，計日數。事緣不及，謂衣未辦；或似緣礙，亦開隔日。〔上諸文中，且據作法捨，餘捨則不定。〕《十誦》。不得攝閏，是奢法故。衣體中四，初示體。
【譯文】《四分律》因為迦提月本來就常有開緣，所以不計算在內。如果就八月十五日受衣的人來說，並不妨礙《四分律》仍然算成四個月；《五分律》反而得到五個月，仔細思考就可以明白。《母論》中，最初說明受衣與捨衣；後面「七月」以下，是計算日數。事緣來不及，是指衣還沒有辦好；或者似乎有因緣障礙，也開許隔日。〔上面諸文中，暫且是就作法捨而說，其餘的捨法則不固定。〕《十誦律》。不得把閏月計算進去，因為這是寬緩之法的緣故。「衣體」一段中有四科，第一是顯示衣體。

【511-0007】資持記/05e_上四#48
【原文】若得新者，即時非時施，本非作德衣也。檀越施者，正為作德衣施，通七眾也。糞衣下，準律，合有若是新衣，若是故衣二句，竝釋上糞衣耳。新物揲淨，即上新衣，以故揲也。浣納淨者，明上故衣，不勞更揲也。〔即日來一種，準律在應法字上，今科於下。
【譯文】如果得到的是新衣，那就是時施、非時施，本來不是為製作功德衣而施的。檀越所施，正是為了製作功德衣而施，通於七眾。「糞衣」以下，依據律文，應該有「若是新衣」「若是故衣」兩句，都是解釋上面的糞衣罷了。新物揲淨，就是上面的新衣，用舊布來揲貼它。浣納淨，是說明上面的故衣，不必再勞煩揲貼。〔「即日來」這一種，依據律文在「應法」二字之上，現在科判放在下面。〕

【511-0008】資持記/05e_上四#49
【原文】不以下，次明求乞離過。次列六種。上五簡非，如〈二衣〉釋。下一顯如，謂道眾所施，說淨長物也。〔《僧祇》亦云：淨財得作。〕三上云即日來及應法，此二明受法。言應法者，即下簡人秉法，皆須合教。四周下，四明作衣法，又三，初示堤條。若過是者，謂七條大衣也。
【譯文】「不」字以下，其次說明求乞而遠離過失。接著列出六種。上面五種是簡別不合法的，如〈二衣篇〉所解釋。下面一種顯示如法的情形，是指道眾所布施的，作說淨的長物。〔《僧祇律》也說：淨財可以製作。〕第三，上面所說的「即日來」以及「應法」，這兩種是說明受衣之法。所說的「應法」，就是下面簡別人員主持法事，都必須合乎教法。「四周」以下，第四是說明作衣之法，又分為三：第一是顯示衣的條隔。如果超過這個數的，就是指七條大衣。

【511-0009】資持記/05e_上四#50
【原文】應云：七條二十一隔，大衣亦類增之。應自下，明裁製。且示下衣，餘可例準。又下，明色相。律因六群以大色染衣，錦衣白色衣作之，佛因制斷。律云：云何僧不成受功德衣？謂不浣、不碾、不治、不安緣、不裁隔、不編邊〔不刺緣口〕、不安紐、不作葉、不安鉤、邪命得、諂曲得、相得、激發得、離宿衣捨墮、不作淨〔前不捨墮，兼收離衣。
【譯文】應當說：七條衣有二十一隔，大衣也照這一類推增。「應自」以下，說明裁剪製作。暫且舉出下衣，其餘可以依例比準。「又」字以下，說明顏色的相狀。律中因為六群比丘用大色染衣，用錦衣、白色衣來製作，佛因此制斷。律中說：什麼情形下僧眾不能成受功德衣？就是：不洗、不碾、不整治、不安緣、不裁隔、不編邊〔不刺緣口〕、不安紐、不作葉、不安鉤、以邪命而得、以諂曲而得、以現相而得、以激發而得、離宿衣犯捨墮、不作淨〔前面所說的不捨墮，這裡兼收離衣之罪〕。
