# 校閱材料　第441檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【441-0001】資持記/10a_中三下#1
【原文】四分律行事鈔資持記中三下三十四。〔佛在舍衛，婦人將還夫家；辨食頻施，經時不還，夫別取婦；又取商客食分路中數施，為賊所劫，因此二緣，合制一戒。〕列緣。第一指上標名。第三疏云即《戒本》中無病過受，則知開有病也。第四疏云：《多論》上鉢取一無罪，二鉢是犯；
【譯文】《四分律行事鈔資持記》卷中三之下第三十四條。〔佛在舍衛國時，有一位婦人準備返回夫家；她準備了食物頻頻布施僧眾，經過許久都未回去，丈夫便另娶了妻子；婦人又拿了客商的食物在路途中多次布施，結果客商被盜賊劫掠。因為這兩種緣起，佛陀合併制定了一條戒律。〕這是列出制戒緣起。第一點是指向上文標示的戒名。第三點戒疏說，這就是《戒本》中所說的無病而過量受取，由此便知有病是可以開許的。第四點戒疏說：《薩婆多論》認為大鉢取一鉢無罪，取兩鉢就犯戒；

【441-0002】資持記/10a_中三下#2
【原文】中鉢取二，下鉢取三，各不犯；過則犯。一人取過三鉢犯，謂下鉢也；若四人取過三鉢，前三人不犯，後一人犯。律中不犯。齊兩三鉢，若病，若自送寺中等。三十五。〔佛在舍衛說一食法，乃至諸比丘憔悴，佛聽得食取飽，又因看病人開餘食法；後有比丘貪食不知足，得便食之，因制。〕初緣，可足，即是正食。
【譯文】中鉢取兩鉢、下鉢取三鉢，各自都不犯戒；超過這個數量就犯戒。一個人拿取超過三鉢就犯戒，這指的是下鉢；如果是四個人拿取超過三鉢，前三個人不犯戒，最後一人犯戒。在律文中則是不犯的。限度在兩三鉢之間，如果是生病，或者親自送回寺院中等情況都不犯。第三十五條。〔佛在舍衛國時宣說日中一食之法，以致諸位比丘身體憔悴，佛陀便聽許可以吃飽，又因為看顧病人的緣故開許了「作餘食法」；後來有比丘貪吃不知滿足，得到食物就隨便吃，因而制定此戒。〕最初的緣起，只要食物充足，那就是正食。

【441-0003】資持記/10a_中三下#3
【原文】第四或病或作餘食法，則無犯故。通釋中，律文分三，初示名相。次列五緣。初簡食體；二須曾受；三明食境多少，成遮不遮，如注所顯；四約制教；五據正犯二緣，似同而異。足下，三明結犯。《僧祇》八中，上四通約四儀，與前無異；下四別就坐相以明離處，由坐通地物不犯故。
【譯文】第四種情況，若是生病或者作了餘食法，就沒有違犯。在通篇解釋中，律文分為三部分：首先說明名相。其次列出五種緣起。第一是甄別食物的本質；第二是必須曾經接受過布施；第三是說明食物境況的多少，是否構成遮止，如同注文所顯示的那樣；第四是依據戒律的教制；第五是根據構成正犯的兩種因緣，看似相同卻有差異。從「足」字以下，第三部分是說明結罪的規範。《僧祇律》卷八中，前四種情況通論行住坐臥四種威儀，與前面沒有差別；後四種情況則是特別就坐著的姿態來說明離開座位，因為坐著無論是接觸地面或物品都不犯戒的緣故。

【441-0004】資持記/10a_中三下#4
【原文】且下，舉床示相；餘船乘例同。初約動身明犯。若正下，次約擡舁明犯。問：倒地等緣，既非故作，何得結犯？答：此有法開，自可作法；故違而食，不復重開。彼云：在船上船築岸觸木石迴波，身離本處；若在乘上乘上坂下坂〔坂謂大坡，不平故有上下。〕，若翻身離本處等。《五分》中。第四不益者，顯境足也。
【譯文】從「且」字以下，是舉出繩床來顯示具體情形；其餘如船隻、車乘等也依此類推。起初是依照身體移動來說明犯戒。從「若正」以下，其次是依照抬運移動來說明犯戒。有人問：倒地等意外情況，既然不是故意為之，為什麼要結罪犯戒呢？回答說：這種情況有開許的法則，自己本來可以作法；故意違反而進食，就不再重新開許了。該律說：在船上時，船撞擊岸邊、觸碰木石或波浪迴旋，使得身體離開了原本的位置；或者在車乘上，車乘爬上陡坡或走下斜坡〔坡是指大斜坡，因為地不平所以有上下起伏〕，或者翻身離開原本的位置等情況。《五分律》中。第四點不再接受添加，顯示外在食物已經足夠了。

【441-0005】資持記/10a_中三下#5
【原文】注中，初出異計。彼謂足食飽足方犯；但少一口，即不名足。此下，責非法。今準《五分》不受益緣，明取境足，誠有據矣。餘四可解。國下明別開。以󰉓是正食，隨方所宜故。釋初緣，食體中，《十誦》有三，初明五正。糒音備，此與前異，故特出之。〔前引三種，更兼魚肉為五正；梵語蒲闍尼，此云正食。〕五似中。
【譯文】注文中，首先列出不同的見解。對方認為必須是食物充足、真正吃飽了才算犯戒；只要少吃一口，就不能稱為充足。從「此」字以下，是斥責這種說法不合戒法。現在依照《五分律》中不再接受添加的條件，明確取決於食物境況已經充足，這確實是有根據的。其餘四點可以理解。從「國」字以下說明特別的開許。因為麨（炒米麥粉）屬於正食，應當順應當地的風俗適宜。在解釋第一條犯緣（食物本體）中，《十誦律》分為三類，首先說明五種正食。乾飯的「糒」字音同備，這個字與前面不同，所以特別標註出來。〔前面引用的三種，再算上魚和肉，一共是五種正食；梵語稱為蒲闍尼，這裡翻譯為正食。〕在五種似正食中。

【441-0006】資持記/10a_中三下#6
【原文】𢇲音眉，即𬖴子也。󰎣麥，通名大小諸麥。莠音酉，即稗草子。錯麥是華言，迦師即梵語，謂碎麥飯也。〔以錯碎故，有云麵者，濫下未磨食。〕彼文明五似，或言錯麥，則不言迦師；或言迦師，則不言錯麥；鈔中華梵並列，意彰一物二名耳。五種佉陀，即不正也。
【譯文】「𢇲」字音同眉，就是𬖴子。「󰎣麥」是大麥和小麥的通稱。「莠」字音同酉，就是稗草的種子。「錯麥」是漢語，「迦師」是梵語，指的就是碎麥飯。〔因為是錯雜碎裂的，有人說是麵粉，這就混淆了下面未經研磨的食物。〕該律文中說明五種似正食，有時說錯麥，就不說迦師；有時說迦師，就不說錯麥；《行事鈔》中漢語與梵語並列，用意在於表明同一種東西有兩個名稱而已。五種佉陀，指的就是不正食。

【441-0007】資持記/10a_中三下#7
【原文】四中，稻即正食，麥是似食；但磨細故，入不正收。〔已上《十誦》總十五種。〕《僧祇》，初明五正。言同此者，即指《十誦》，彼云：󰉓飯麥飯魚肉。彼無乾飯，而言同此者；以麥飯乃當五似故。次明五雜正者〔即不正也〕，與《四分》同，故引合之。佉闍尼，此云不正。〔對上《十誦》，枝即是莖，此無彼根，彼無此花。
【譯文】在第四項「磨食」中，稻穀原本屬於正食，麥屬於似正食；但因為研磨得十分細碎，所以歸入不正食中收錄。〔以上《十誦律》總共列出十五種。〕《僧祇律》中，首先說明五種正食。鈔文所說『同此』，是指同於《十誦律》；但《僧祇律》所說的是：麨（糗）、熟飯、麥飯、魚、肉。《僧祇律》中本來沒有乾飯，鈔文卻說與《十誦律》相同，這是因為《僧祇律》的麥飯正相當於《十誦律》五似食中的麥類之故。其次說明五種雜正食〔也就是不正食〕，與《四分律》相同，所以引來互相參照。佉闍尼，這裡翻譯為不正食。〔對照上面的《十誦律》，「枝」就是指莖，這裡沒有那裡的根，那裡也沒有這裡的花。〕

【441-0008】資持記/10a_中三下#8
【原文】《僧祇》下，三明餘物。米麥等皆謂磨作餅也。歡喜丸，古記云西國多用酥油砂糖為檲，故名丸也。一切下，牒上諸物以明不犯。肉是正食，故特除之。別眾、處處，此前二戒，相因而列。滿足，即此戒也。《善見》，初通示二食。與前少異。初不正唯果，應收枝葉等。

【441-0022】資持記/10a_中三下#22
【原文】又準佛說則彼二皆是假名，隨彼而言，故云實耳。〕文云我已說者，即指上文。世界法有故，不妨說時非時；非實故，不妨無時；立論已明，不審重問，故反責之云不應難。〔有下闕時字，實下脫法字，論本有之。〕亦是下，次隨世釋。世界實者，俗所計也。〔論文實下有非第一實一句，又無有字。〕眾人呵者，即指緣起。
【譯文】又依照佛陀所說，那麼這兩種說法都是假名，只是隨順世俗而言，所以稱為實體罷了。〕文中說「我已經說過」，就是指上文。因為世間法存在的緣故，不妨礙說適當時限與非適當時限；因為不是真實體性的緣故，也不妨礙時間本無實體；論點已經立得很清楚，不再審查卻重複發問，所以反過來責備他說不應當這樣問難。〔「有」字下面缺少「時」字，「實」字下面脫漏「法」字，論典原本中是有的。〕從「亦是」以下，其次是隨順世間來解釋。世間的真實性，是俗人所執著的。〔論典文字在「實」字下面有「非第一實」一句，又沒有「有」字。〕眾人訶責，就是指制戒的緣起。

【441-0023】資持記/10a_中三下#23
【原文】〔律中女人呵迦留陀夷云：寧自破腹，不應夜食。〕由彼計實而致譏訶，律附世相遮譏故制。亦欲下，三護法釋。謂受戒時分定上中下，互相敬事，令法不滅，故云使久存等。〔初義約假從道以釋，後二約實從俗而釋。〕遮來難中。以毘尼制教，隨順世諦，從權建立，不可橫以真理而難俗事；
【譯文】〔律文中婦女呵責迦留陀夷說：寧願自己剖破肚子，也不應當在夜間進食。〕由於世人執著實時而招致譏諷呵責，戒律依循世間相狀以制止譏嫌，所以才制定此戒。從「亦欲」以下，第三是為了護持正法來解釋。這是說受戒的時間先後決定了上座、中座、下座的次序，彼此恭敬事奉，使得正法不致滅亡，所以說能讓佛法長久存在等。〔第一種義理是就假名而言、順從修道來解釋，後兩種則是就實時而言、順從世俗來解釋。〕在阻擋詰難中。因為戒律的制止教化，隨順世俗的諦理，是依權巧而建立的，不可強行用勝義真理來詰難世俗事相；
