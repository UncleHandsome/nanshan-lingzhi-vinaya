## 一、必須修正：漏譯與誤譯

### 1.【900-0001】夾註整條漏譯
原文〔如故斷畜命，知水有虫等。〕在譯文中**完全不見**。這是「標知故字」的举例，不可省。
→ 補：〔如「故斷畜生命」、「知水有蟲（而故用）」等。〕

### 2.【900-0001】「初句情虛」誤解為「境相虛妄」
譯文：「第一句**心懷惡意而境相虛妄**者其罪極重」——**錯**。
「情虛／情實」讲的是**能犯之心**（明知不實而故犯／心謂真實而誤作），不是所對境的真假。境想初句正是「人作人想」——**境與想相符、明知是人而故犯**，境一點也不「虛妄」。
→ 改：「境想分別的初句（境、想相當，明知而故犯），因心存虛詐故結重罪；疑句、誤想句屬情實，皆結輕罪。」

### 3.【900-0001】「諸戒」被縮小為「各大重戒」
原文〔諸戒不犯文中〕泛指一切戒的不犯開緣文，不限重戒。→ 「諸戒的不犯文中」。

### 4.【900-0002】「乃至畜生」漏譯
原文「乃至**畜生**毛頭即犯」，譯文只剩「入如毛頭之微細許即成犯」，把「乃至畜生（連對畜生行婬亦然）」這一層递进語意丟了。
→ 「乃至對畜生，僅入如毛頭許即成犯」。

### 5.【900-0002】「後開畜長」誤作「後世」
譯文「**後世**再度開許可以蓄積多餘的長衣」——錯。此處「本制／次開／復制／後開／仍制」是**同一制開脈絡中的先後次第**，畜長衣、說淨都是佛世所制所開，與「後世」無關。
→ 「其後又開許蓄長衣，但仍制須說淨」。

### 6.【900-0003】「又云在文自顯」誤作「經文」
譯文「**經文**又強調『在律文中自然彰顯明白』」——錯。此夾註是元照說明**鈔主（道宣）**之語：鈔文既說「在文自顯」，故須就本律詳求。主詞應是**鈔文**，非佛經。
→ 「鈔文又說『在文自顯』，故須緊扣本律詳審尋求」。

### 7.【900-0006】「跨及曹魏，將二百年」時序誤讀
譯文「歷經曹魏時期，將近兩百年」，讀來像「曹魏一代近兩百年」（曹魏僅四十餘年）。原文是說：**從後漢明帝佛法初傳，一直沿跨到曹魏曇摩柯羅立十人受戒，將近二百年**都「未有歸戒」。
→ 「（此種情形）從東漢一直沿跨至曹魏，將近二百年」。

### 8.【900-0006】【900-0007】「差」譯成「錯亂」失準
「第一差／此二差／此三差」的「差」是**乖違、差失**，特指**受體與隨行所依之律不相應**（依《四分》羯磨受戒，卻誦《僧祇》戒本；後又改依《十誦》；再捨《十誦》演《僧祇》）。「錯亂」語意過重且模糊，讀者看不出「差」在哪裡。
→ 「這是第一處乖違（受依《四分》、誦依《僧祇》，受隨不相應）」，二、三處類推。

## 二、宜調整：義理與術語精準度

| 出處 | 譯文 | 問題與建議 |
|---|---|---|
| #62 | 「其罪刑一概**減輕**」 | 「俱輕」是**結輕罪**（相對於初句結重），不是「重罪減刑」。→「皆結輕罪」 |
| #62 | 「誹謗、大妄語」 | 「謗」宜點明是**無根謗（僧殘）**，「妄」是**大妄語（波羅夷）**；「情實皆開」在謗戒即**實有見聞疑三根**而說，非僅「誤信」 |
| #62 | 〔除婬酒戒〕 | 可補一句理由：**此二戒不論想、疑，皆犯**，故不在減例 |
| #62 | 「必然先**盤問**」 | 「犯必問心」是律中詰問「汝何心犯」，用「審問其心／問其犯時之心」較合律語 |
| #63 | 「**極其寬縱**的開許」 | 「寬縱」帶貶義，且與律意不合；「開中制」只是開許之中仍有限制。→「開許之中仍立制約」 |
| #63 | 「制教重輕」 | 「制教」是與「化教」對揚的專名，宜保留術語或加註，不宜泛譯為「佛陀制定教規」 |
| #64 | 「受請外出**受日**」 | 術語未釋。→「作法受日（如受七日法等請假外出）」 |
| #64 | 「**徹底撤離**不再返回」 | 過重。原文只是「開難緣不返（不犯）」，宜作「遇難緣開許不返回而不犯」 |
| #64 | 「結犯**墮罪**」 | 十日不說淨是**尼薩耆波逸提（捨墮）**，宜标明「捨墮」 |
| #64 | 「第七個**範例**」／#65「這七種**範例**」 | 這是七門料簡的「門／項」，非舉例。→「第七門」「七門」 |
| #64 | 「四依／四開」 | 宜加註：四依＝糞掃衣、常乞食、樹下坐、腐爛藥；四開＝開檀越施衣、僧食（請食）、房舍、酥油等藥 |
| #65 | 「第一項**受捨漸頓**」 | 本段原文只作「一是背於受體」，此名稱是譯者補入，**須核對鈔文前所列七門名目**再定，否則宜刪或加「（按：即前所列○○門）」 |
| #65 | 「上一句屬於佛陀的大智裁度，下一句屬於鈔主…」 | 讀者不知「上句／下句」指哪兩句。建議引出鈔文原句或加註說明 |
| #65 | 「就止持門之中**能犯的心識與所犯的境界**」 | 「能所簡」含三項：所犯罪、所對境、能犯心；標題漏了「所犯罪」 |
| #65 | 「一約判罪」→「判定**罪名**」 | 全篇主題是**輕重**，宜作「判定罪之輕重」 |
| #65 | 「第三標中」→「第三個**大**科判的標題」 | 層級待確認（對照#66「敘古中，初科」的科判層次），不宜逕加「大」 |
| #66 | 「未有歸戒」→「沒有正式歸依受戒的**儀軌**」 | 重點是**尚無三歸及受戒之法**（只剃髮染衣而已），非僅儀軌未備 |
| #66 | 「这才開始**推出**《僧祇戒本》」 | 「推出」現代商業語，宜作「譯出／出《僧祇戒本》」 |
| #67 | 「**義學界**依然紛擾混亂」 | 「尚有紛紜」指諸說仍紛歧，未必指整個義學界；宜作「（諸說）仍有紛歧」 |

## 三、系統性問題：增譯過度、語域混雜

1. **形容詞與評價語大量添加**：「慈悲的開緣」「嚴厲制約」「嚴密防範」「大智裁度」「垂範指引」「萬無一失的**境界**」「**徹底**依循」「**深入**探尋」「**極其**嚴急沉重」「高超上根」等，原文都只是平實的「開／制／據本制懷」。**每段反覆出現，會把元照的判律文字讀成讚頌文**，建議一律收斂。
2. **世俗法律語彙入侵**：「罪刑、治罪、免予治罪、盤問、寬限期、犯意」與律學「結罪、不犯、開緣、問心」語域不合，且「罪刑」在律中應是「犯罪輕重」。建議全篇統一為律學用語。
3. **無據添加**：「聚落**市集**」「**後秦姚興**時代（原文只作姚秦）」「**大多**」「**始終**未曾**廣泛**弘傳」等，屬可省或宜省的推衍。
4. **術語一致性**：「制」時譯「制約」時譯「嚴令制約」，「開」時譯「開緣」時譯「開許」——建議固定為「制（制止）／開（開許、開緣）」，並保留「制教、化教、受體、隨行、止持、作持、境想、說淨、加持、受日」等專名，必要時隨文短註。

## 四、關鍵句修正示例

**#62（改譯）**
> 這有多種解說。一、如無根謗、大妄語等戒，明知不實而故犯（情虛）故結重罪；心中確實認為真有其事（情實），則一概開許不犯。〔諸戒不犯文中都標「實爾」（心謂真實如此）、「無心」（無犯心）等，即是此意。〕二、諸戒境想分別中，初句境想相當、明知故犯，屬情虛故結重；疑句、誤想句屬情實，皆結輕罪。〔婬、酒二戒除外，以彼不論想疑皆犯。〕三、諸戒中凡標「知」「故」等字者，即顯情虛〔如「故斷畜命」、「知水有蟲」等〕；非故、不知，即是情實。就如本律判犯必問其心，無心則不犯。

**#63（改譯節錄）**
> 且如婬戒，乃至對畜生，入如毛頭許即成犯，卻仍開許遭怨家強逼（三時無樂者不犯），這就是「制中有開」；雖許境合，然要求初入、入已、出時三時皆不受樂，這就是「開中有制」。又如本制只畜三衣，其次開許百一供身之物，又制須作法加持；其後開許畜長衣，仍制須說淨。

**#66（改譯節錄）**
> （此情形）從東漢沿跨至曹魏，將近二百年。曇摩柯羅〔或作迦羅，此譯「法時」〕依《四分》羯磨立十人受戒，並開始譯出《僧祇戒本》令眾誦習。〔這是第一處乖違：受戒依《四分》，誦習卻依《僧祇》，受隨不相應。〕

---

**總結**：整體理解方向大致無誤，但有 **1 處夾註漏譯、1 處「畜生」漏譯、4 處實質誤譯（情虛誤為境虛、後開誤為後世、鈔文誤為經文、跨及曹魏年數誤讀）**，加上「差」字譯法失準與形容詞過度增譯。優先處理第一節八項，再統一術語與語氣即可。
