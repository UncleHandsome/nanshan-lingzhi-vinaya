以下逐段核對，先列**明顯要改**的，再列**可斟酌**的。整體而言譯者對科判術語（初科、次科、X下、引證）掌握不錯，主要毛病集中在：**增字添義、術語誤解、以及主語／邏輯關係錯置**。

## 【1630-0001】

**須改**

1. **「不出心境」→「不出妄心與外境」**
 「妄」字是無中生有。此处「心」泛指能盜之心、想心、方便心，不必是「妄心」；律家判犯緣只分「心／境」兩攝。建議：「不出心與境兩方面」。
2. **「佛法（二）物」**
 括號補字體例怪異，且與全文其他補語方式不一致。建議直譯「佛物與法物」。
3. **「用與多過」→「挪用與給予極容易產生過錯」**
 「用與」＝自用、與人（給別人），是中性動詞；「挪用」已預設違法，語意過重；「極容易」也是加出來的。建議：「取用或給與他人，多半會招致過失」。
4. **「賜予」**
 「用與由人」的「與」只是一般給予，「賜予」是上對下的語體，不合律文語境。建議：「取用、給與全憑人意（無主可制約）」。
5. **「互用」→「相互借用挪用」**
 「互用」是律中专指**三寶物彼此挪用**（佛物移作僧用等），不是「相互借用」（借用含歸還義）。建議：「即下文『互用』（三寶物互相挪用）與『瞻待』（供待賓客）兩部分中」。

**可斟酌**

- 「先簡知事」：此「簡」是**揀選／揀別誰堪能擔任知事**，譯「簡別知事僧人」讀者不易懂，可補「先揀別（何人可任）知事（掌管三寶物者）」。
- 「文理同故」→「完全相同」；「初示難護」→「極難守護」：「完全」「極」都是添加的強調詞，宜刪。
- 「難護」宜補出對象：「三寶物難以守護」。

## 【1630-0002】

**須改**

1. **「從『我下』開始」**
 與前段「自鈔文『若』字以下」體例不一致。應作「鈔文『我』字以下」。
2. **「文中列舉初果與後果」**
 「後果」在現代漢語是「consequence」，嚴重歧義。應作「初果（須陀洹）與最後的第四果（阿羅漢）」。
3. **「初人知因，後人懼果」→「前一種人知曉因果」**
 原文是**因／果對舉**（一類人明業因、一類人畏苦果），譯成「知曉因果」把對文抹平了。建議：「前一類人明白業因，後一類人畏懼苦果」。
4. **「或約二惑究盡處故」**
 譯「見思二惑徹底斷盡的界限」含混——原意是**就二惑各自斷盡之處立說**：初果斷見惑盡、四果斷思惑盡，故只舉初、後二果。建議補足此義。

**可斟酌**

- 「上簡精持，下容犯悔」：「簡拔」「寬容」用語生硬，宜作「上文揀取精嚴持守者，下文則容許犯後能懺悔者」。
- 「無瘡疣」：疣是贅瘤，非「傷痕」，可作「沒有瘡疤贅瘤（喻戒體無缺）」。
- 「示制罪」→「指示制罪的標準」：「標準」為添加，宜作「顯示佛所制的罪相」。
- 「不識業因」→「不認識造業的起因」：原意是**不知如此侵損即是招苦之業因**，可調為「不明白這是招苦的業因」。
- 「申誡」譯「重申戒誡」：「重申」暗示重複，此處是「申明告誡」。

## 【1630-0003】

**須改**

1. **「非無我所」→「並非沒有執持物主」**
 這句譯壞了。「我所」＝「我所有」的執持，指**非人（鬼神）仍執物為己有，故仍是無主中之有主**。建議：「並非沒有『我所』（物主的執持之心）」。
2. **「與人相降」→「與人類相比稍有降次」**
 語意不明。律中盜非人物結偷蘭遮，比盜人物（波羅夷）**降一等**。建議：「（結罪）比盜人物降減一等」。
3. **「今殿塔靈儀」→「殿堂塔寺的靈異儀相」**
 「靈儀」即**佛像／聖像**，非「靈異的儀相」。建議：「如今殿堂佛塔中的佛像」。
4. **「有同神像」→「有些等同於神像」**
 「有同」＝「有如」，不是「有些」。建議：「有如世間神像一般（人對之亦生我所執）」。
5. **「不問取」→「不過問就逕自取走」**
 現代漢語「不過問」＝不關心，與原意相反。原意是**不先問過（主／擲卜請示）而取**。建議：「不先徵詢（物主）就取用」。

**可斟酌**

- 「斯地獄人」加「未來的」屬合理推衍，但可簡作「這種人簡直是地獄中人，無可救拔」。
- 「望惱微」：宜作「對非人造成的惱害輕微」，「惱怒」偏情緒，律文重「惱主」之義。
- 「初舉例證」：此「例」是**以非人為例**，譯「同類事例」略泛。

## 【1630-0004】

**須改**

1. **「大乘約境判」→「大乘戒依據境界來判定」**
 **誤譯。**此「境」是「所對之境／對象」（佛物、法物、僧物、人、非人等），不是修證「境界」。建議：「大乘戒是依所對境（對象）來判罪」。
2. **「望主中」→「在對待物主方面」**
 「望」是**就……而結罪**，不是「對待」。建議：「就（守護）主結罪而言」。
3. **「初文」→「第一篇文字」**（兩處）
 「文」是段落，非篇章。應作「第一段文」。

**可斟酌**

- 「正望佛結」→「純粹對著佛陀來結罪」：「正」＝「正是」，非「純粹」。建議：「正是就佛（物主）而結罪」。
- 「經家不論」：「經家」指**結集（譯）經者**，即「經文中不談」，譯「經論作者」略偏；又「縱有主掌」加「僧人」為限定，守護者未必是僧，宜作「縱然有人掌管守護」。
- 「罪名雖輕……極其沉重」：「看似」「極其」為添加語氣，可刪。

## 【1630-0005】

**須改（本段最重要）**

1. **「謂檀越施與塔寺，斷彼施主福」**
 譯文「**如果施主布施給塔寺，斷絕了那位施主的福德**」——讀來變成「施主自己布施、自己斷福」，**主語錯置，義理講反**。斷施主福的是**盜者**：盜取檀越施與塔寺之物，使施主的施福（相續）被截斷，故結重。
 建議：「是說（盜取）施主布施給塔寺之物，便斷了那位施主的福德（相續），故成棄捐不受之罪」。
2. **「不受，即不共住也」→「不再共同止住」**
 「共住」是僧團術語（同住、同法、同受用），「共同止住」不成話。建議：「不受（僧團不納受），即不得與僧共住」。
3. **「彼因波離問佛」→「那是因為波離尊者向佛請教」**
 「彼」指**前面所引的那部經**，不是泛指的「那」。建議：「彼經因優波離請問於佛（而說），鈔中引佛的答文」。

**可斟酌**

- 「非人罪通兩結」→「通貫兩方面結罪」：宜作「通於**兩種結罪**」，並視上下文補注（如望本主／望守護主，或蘭、夷二罪）——此處建議核對鈔文再定，勿含糊帶過。
- 「引此似證損福」：「似」是元照的保留語氣（彷彿可證、非正證），譯「似乎」得之，可再作「引此文約略可證『損福』之義」。
- 「佛塔上掃得土」：宜「從佛塔上掃下的塵土」。

## 【1630-0006】

**須改**

1. **「下明不勒掌錄，有填償義故」→「不強制主管僧官登錄賠償，具有必須予以填補償還的義務」**
 **把兩件事黏成一件，句意錯亂。**「勒掌錄」與「填償」是兩層：
 (甲) 不勒令（知事人）掌管登錄（帳冊）；(乙) 但（若侵用）義須填賠償還。
 建議：「下文說明（佛物）不強令知事人掌管登錄帳目，然而（取用者）有填賠償還之義」。
 另，「僧官」是後世官制用語，「知事」不宜譯作「僧官」，逕作「知事人／掌管者」。
2. **「自下，示淨心相」→「從『自下』開始」**
 體例錯誤：「X下」若指鈔文某字以下，應作「鈔文『自』字以下」；若「自下」是「自此以下」，則應直譯「自此以下，顯示淨心之相」。二者擇一，不可把「自下」整個當引號詞。（此處請核對鈔文有無「自」字起句。）
3. **「即非盜業」→「並非出於偷盜的造業意圖」**
 「非盜業」是**不構成盜業**（結業層面），不只「意圖」。建議：「即不構成偷盜之業」。

**可斟酌**

- 「佛圖，即全梵語」：宜作「『佛圖』是完整的梵語音譯（全稱），『塔』則是略稱」，比「完整的梵語發音」清楚。
- 「從人為目」：即**依人（佛）而立名**，「順著佛陀本身來立名」可再收緊。
- 「所以中」：與其他段「自鈔文X字以下」體例不一，可作「在解釋緣由（所以）的部分」。
- 「《婆論》決之」：「決」是**決通疑滯、會通相違**，譯「決斷」略硬，可作「引《薩婆多論》加以會通」。
- 「與上相違」宜補「與上文（淨心不犯）相違」。

## 通用問題（建議全稿統一）

| 項目 | 問題 | 建議 |
|---|---|---|
| 增字 | 妄心、極、完全、純粹、徹底、看似、有些 | 一律回歸原文語度 |
| 「X下」 | 有時作「自鈔文X字以下」，有時「從『我下』開始」 | 統一「鈔文『X』字以下」 |
| 「初文／次文」 | 譯「第一篇文字」 | 統一「第一段文／第二段文」 |
| 「簡」 | 簡別／簡拔混用 | 統一「揀別」（並適時補白話說明） |
| 「望」 | 誤作「對待」 | 統一「就……（而結罪）」 |
| 「境」 | 誤作「境界」 | 「所對之境／對象」 |
| 補注體例 | 「佛法（二）物」 | 直接補成「佛物、法物」，或統一用〔〕 |
| 語體 | 賜予、僧官 | 改為與律文相稱的用語 |

**優先處理順序**：#5「斷彼施主福」主語錯置 → #6「不勒掌錄／填償」黏連 → #4「約境判」誤譯 → #3「非無我所」「不問取」 → #2「後果」「知因懼果」 → #1「妄心」「互用」。前兩項已影響義理正確性，不只是文字潤飾問題。
