# 義鈔定稿檢查提示詞

你要檢查的是：

```text
定稿/yichao.jsonl
```

共 215 筆，每筆欄位：

```json
{
  "key": "01",
  "label": "鈔文",
  "source": "原文",
  "translation": "白話",
  "raw_start": 123,
  "raw_end": 456
}
```

## 任務

逐筆檢查，只回報問題，不要重寫整份檔案。

### 1. 原文

- `source` 是否為乾淨原文，不含提示詞、裁決、底本 metadata、白話
- 是否與 `TXT/05_四分律拾毗尼義鈔.txt` 對應區間一致
- 是否有缺字、贅字、錯字

### 2. 白話

- 是否忠實對應原文
- 是否有漏譯、無據增補、主客倒置
- 是否有文言直抄、現代詞錯義
- 專有名詞是否一致

### 3. 區間

- `raw_start`／`raw_end` 是否覆蓋正確原文
- 是否有區間重疊
- 是否有区间空白

### 4. 合併缺口

`key` 為 `GAP01`–`GAP25` 的 25 筆，是從頁面多個小 pair 合併補入的譯文，優先檢查：

- 譯文是否連貫
- 是否前後重複
- 是否漏掉中間段落

## 輸出格式

| key | 問題類型 | 嚴重度 | 說明 | 建議 |
|:--|:--|:--|:--|:--|

嚴重度只用：

```text
P0：原文／譯文實質錯誤
P1：區間或連貫性問題
P2：用詞／格式
```

## 禁止

- 不要重寫整個 JSONL
- 不要自行新增 key
- 不要把提示詞或底本 metadata 當原文
- 不要用比例切分譯文
