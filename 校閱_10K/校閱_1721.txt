# 校閱材料　第1721檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1721-0001】03_業疏/11b_卷二之五#9
【原文】合掌中，初示立意。無二緣者，緣即想念。「有下」辨相，又二：初示異。叉手似今擎拳之類；或云等者，出法華玅莊嚴品。「四下」出律意。手指必合，不在言之，但標一端云合掌耳
【譯文】在合掌儀軌中，起初說明立法的本意。無第二種攀緣對象，「緣」就是念頭想念。自「有」字以下辨明行相，又分為兩部分：首先指出異說。「叉手」類似於現今的拱手抱拳之類；說「或云」等語，出自《法華經·妙莊嚴王本事品》。自「四」字以下指明律意。手指必然要相合，這本就不必贅言，律中只是標舉一端稱為合掌罷了。

【1721-0002】03_業疏/11b_卷二之五#10
【原文】問：佛法威儀，義遵上下，焉有師來乞法，而弟子端拱受禮？此不可也。答：律據從緣，禮有從俗。僧無別僧，即假成用。師今乞法，為別而陳；弟子秉法，據僧能辨。在緣既別，理須禮僧；事休餘務，則反依敬。世中常事，何得懷疑
【譯文】問：佛法的威儀，在義理上遵循尊卑長幼的上下秩序，哪有師長前來乞求羯磨法，而弟子卻端坐拱手接受頂禮的道理？這是不可以的。 答：律典是根據具體事緣而定，禮節也有隨順世俗處境之處。僧團並無脫離個別僧眾而另外存在的僧體，乃是假藉個別僧眾聚合而成僧團的功用。師長如今前來乞法，是以個人身分向僧團陳情；弟子秉持僧法，是依憑僧團身分方能成辦羯磨。在當時事緣中師徒身分既然有別，理當向僧團禮拜；待羯磨事畢、恢復尋常事務之後，弟子自當回歸依止恭敬師長之禮。這是世間與佛門常有之事，何必產生懷疑？

【1721-0003】03_業疏/11b_卷二之五#11
【原文】重徵中，初問。以事乖常，恐懷疑故。答中，初二句通示。律據緣者，如下釋也。禮從俗者，曲禮云「禮從宜，使從俗」，謂雖是禮，須合時之所宜，為使他邦，當隨彼之風俗，皆謂事不可常守也。「僧下」正釋。四人別假，聚成僧用，故無別僧也。下明師資所為各異，不比常時，事已明決，故不在疑
【譯文】在再次徵詰中，起初提出質問。因為此事違背常情，恐怕引起懷疑的緣故。回答中，前兩句通體說明。「律據緣」，正如底下所解釋的。「禮從俗」，《曲禮》說「禮從宜，使從俗」，意思是說雖然是禮法，必須合乎時節之所宜；奉命出使他國，應當隨順當地的風俗，這都是說明事情不可固守常規。自「僧」字以下正式解釋。四個各別假名之人，聚合而成僧團的功用，所以沒有脫離個人的另外僧團。下文說明師父與弟子在此事中所處身分各異，不同於平日，事情既已明白決斷，所以用不著懷疑。

【1721-0004】03_業疏/11b_卷二之五#12
【原文】文中列受具，餘有剃髮及受十戒，齊須乞法。以無德者妄為師故，四分簡和尚德中具有兼也。諸欲受時，先須乞請，多不自量，任僧籌議
【譯文】律文中雖然只列出受具足戒，其餘還有剃髮以及受十戒，一概都必須向僧團乞法。因為無德之人會妄自為人師長的緣故，《四分律》在揀選和尚德行的規定中兼通此二者（剃髮與十戒）。凡是要為人受戒剃度之時，必須先向僧團乞請恩准，許多人不自量力，應由僧眾共同籌量審議。

【1721-0005】03_業疏/11b_卷二之五#13
【原文】乞法中，初明例通。剃髮、受十戒，即畜沙彌，文略畜依止。「四下」指證，即如注引受戒中文，本簡受具，兼通餘二，故云具兼。「諸下」勸依，總上多事，故云諸也
【譯文】在乞法這一節中，起初說明通例皆同。剃髮、受十戒，即蓄養沙彌，疏文中省略了蓄養依止弟子。自「四」字以下指引教證，正如注文引用受戒文中所說，本來是揀選受具足戒的和尚，同時兼通於其餘二種（剃髮與十戒），所以說「具有兼也」。自「諸」字以下勸勉依行，總結上述多種事項，所以說「諸」。

【1721-0006】03_業疏/11b_卷二之五#14
【原文】三、明與法，緣法為二
【譯文】第三、說明與法（授予蓄眾之法），分為事緣與白法兩個部分。

【1721-0007】03_業疏/11b_卷二之五#15
【原文】緣中觀察者，凡度人法，要在拔俗出道為先，非以財食事資而為師訓。雖列法、食兩位，然以法務為先，故初即云「能教授」者，明存法本以資慧命；後以「衣食」用攝形累，有親疎也
【譯文】在事緣中進行觀察考察：大凡度人出家之法，關鍵在於以超拔世俗、趣向解脫道為首要，絕非以錢財飲食資給弟子而作為為師的教導。雖然列出「法」與「食」兩個位階，然而必須以佛法事務為先，所以一開始就說「能教授」，說明應當保存佛法之根本以資助弟子的慧命；其後再以「衣食」來攝受照顧肉體生計的拖累，二者有親疏本末之別。

【1721-0008】03_業疏/11b_卷二之五#16
【原文】與法釋緣中初科，初敘度人之本。「雖下」次通律意。法能資神故親，食但養形故疎，所以文列前後也
【譯文】在與法解釋事緣的第一科中，起初敘述度人的根本宗旨。自「雖」字以下接著通達律意。佛法能夠資養心神，所以為親近本源；飲食只是滋養色身，所以較為疏淺，因此律文將二者排列於前後。

【1721-0009】03_業疏/11b_卷二之五#17
【原文】就簡德中，律分三位：簡小取大，十夏已上；簡愚取智，解通持犯；簡墮取勤，不具此三，文中令止；具兼統攝，義須和與
【譯文】在揀選德行之中，律典分為三個層面：揀退小年資而選取大年資，須十夏以上；揀退愚鈍而選取智慧，須通達理解持戒與犯戒；揀退怠惰而選取勤勉，若不具備這三德，律文中敕令停止蓄眾；若是完全具備並能統攝統領，在義理上僧團應當和合給與畜眾之法。

【1721-0010】03_業疏/11b_卷二之五#18
【原文】次科，初釋不堪。次列三位，缺一須止。「簡墮取勤」下脫一句，準鈔合云「能勤教授」。「具下」次釋堪能，備上三德，總收餘行，故云具兼統攝
【譯文】在第二科中，起初解釋不堪為師的情形。接著列出三種位階，缺少其中一項就必須停止蓄眾。「簡墮取勤」之下脫落了一句，依照《事鈔》應當作「能勤教授」。自「具」字以下接著解釋堪能為師者，具備上述三德，總體統收其餘德行，所以說「具兼統攝」。

【1721-0011】03_業疏/11b_卷二之五#19
【原文】問：沙彌剃髮已乞畜法，至後受時更須法不？答：二受後生，俱須乞與，容有德退，不可準前
【譯文】問：為沙彌剃髮時既然已經向僧團乞求過蓄眾之法，等到日後受具足戒時，還需要再乞法嗎？ 答：剃髮與受戒這兩次受法是前後發生的，兩次都必須乞求與授予，因為期間或許可能德行退失，不能一概依照先前的乞法為準。

【1721-0012】03_業疏/11b_卷二之五#20
【原文】問答中，恐謂前乞後不須故。容德退者，出其重意。若爾，德苟不退，須重乞否？答：退與不退，非簡不知，須僧量可，例皆乞法
【譯文】在問答之中，是恐怕有人認為先前已經乞過、日後就不必再乞的緣故。「容德退」，點出重新乞法的用意。如果這樣，德行若沒有退失，還需要重新乞法嗎？回答說：退失與否，不經過審查考量便無從得知，必須由僧團評量認可，因此通例都必須重新乞法。

【1721-0017】03_業疏/11b_卷二之五#25
【原文】二正度法僧受沙彌標緣中初科，初翻名。「有下」釋義，有二：初師約止作釋；次師單就止惡解。慈戀即是情愛，用懷大哀等乃言外之意耳
【譯文】在第二正式度法比丘僧受沙彌戒標示事緣的第一科中，起初翻譯名稱。自「有」字以下解釋義理，有兩家說法：前一位法師依據止持與作持來解釋；後一位法師則單就止息惡行來解讀。「慈戀」就是世俗情愛，「用懷大哀」等語則是文字之外引申出的深意罷了。
