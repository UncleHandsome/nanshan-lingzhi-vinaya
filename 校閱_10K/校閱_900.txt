# 校閱材料　第900檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【900-0001】資持記/01c_上一上#62
【原文】此有多釋。一如謗妄等戒，情虛故重，情實皆開。〔諸戒不犯文中，並標實爾無心等是也。〕又諸戒境想，初句情虛故重，疑想情實俱輕。〔除婬酒戒。〕又諸戒中或標知故字者，即顯情虛。〔如故斷畜命，知水有虫等。〕非故不知，即是情實；即如本律犯必問心，無心不犯；
【譯文】對此有許多層面的解釋。第一，如同誹謗、大妄語等戒條，存心虛妄欺誑所以罪情極重，若是內心誤信實有其事則都屬於不犯之列。〔各大重戒的不犯開緣條文中，普遍標明「若是實見如此、自心並無欺妄之意」等皆免予治罪，指的就是這個道理。〕再者，在一切戒條的「境想分別」之中，第一句心懷惡意而境相虛妄者其罪極重，若屬於對境界懷疑或生起誤想的情實心態，其罪刑一概減輕。〔但行婬與飲酒這兩條戒除外。〕再者，諸戒條文中若是明確標註「知而故犯」等字句者，就是為了顯露行者內心是蓄意欺瞞；若是出於不知、非存心故意，那就是心念情實無欺；這就如同本律在判定有罪時必然先盤問其犯戒時的自心動機，如果毫無犯意便不算犯戒；

【900-0002】資持記/01c_上一上#63
【原文】制教重輕，尋之可見。六開制互立者。一切諸戒，若止若作，有制未始不開，有開未嘗不制；二教相待，義無獨立。且如婬戒，乃至畜生毛頭即犯，仍開怨逼，此即制中開也；雖許境合，三時無樂，開中制也。又如本制三衣，次開百一，復制加持；後開畜長，仍制說淨；
【譯文】佛陀制定教規的輕與重，深入探尋此處便一目了然。第六項是「開許與制約相輔並立」。一切所有的戒律，無論屬於止惡的止持還是行善的作持，存在嚴厲制約之處從來就不曾沒有慈悲的開緣，存在慈悲開緣之處也從來不曾沒有嚴密的防範制約；這兩種教門互為依待、相輔相成，在義理上絕不可能孤立存在。且如根本婬戒，乃至即便入如毛頭之微細許即成犯，但律中依然開許若遭怨賊強行逼迫者不算犯戒，這正是「在絕對嚴急的制約之中施展慈悲的開許」；然而即便開許肉體境界無奈相合，在初入、入已、拔出這三時之中內心卻絕不允許生起絲毫受樂，這正是「在極其寬縱的開許之中再度立下極嚴厲的制約」。又例如佛陀原本規定只能蓄持三衣，次後慈悲開許可以儲備百一供身之物，卻隨即又制定必須經過作法加持才能合法；後世再度開許可以蓄積多餘的長衣，卻依然嚴密制定必須對人說淨才能保留；

【900-0003】資持記/01c_上一上#64
【原文】時緣不暇，復開十日，不說則犯。又如本制安居，緣開受日，復制限內須還，又開難緣不返等。但制即是重，開並為輕；如是類求，方體教意。七中。喧即聚落中下兩根，靜即蘭若頭陀上行。四依教重，四開教輕。〔此明如來制教重輕，又云在文自顯，須就本律詳而求之；故今所釋，頗與昔異。〕結示中。
【譯文】遇到因緣匆忙無暇辦理說淨時，隨後又開許長達十天的寬限期，但如果滿十天仍不進行說淨則依然結犯墮罪。又例如佛陀原本嚴令結夏安居期間不得隨意離開界內，但因有要事開許可以受請外出受日，隨後又嚴格限制在受日限度之內必須按時返回僧團，若遭逢水火盜賊等重大難緣時，又再度慈悲開許可以徹底撤離不再返回等等。凡是嚴令制約的處所其法度就代表著嚴急加重，凡是慈悲開許的處所其條文就代表著寬緩減輕；唯有依照這套規則去類推尋求，才算是真正體悟了佛陀立教的深遠本懷。在第七個範例中。「喧鬧」是指聚落市集，對應的是中根與下根的修行人；「寂靜」是指山林阿蘭若，對應的是力行頭陀苦行的高超上根。依循四依苦行的教法極其嚴急沉重，隨順四種開緣的教法則相對安閒寬輕。〔這是在闡明如來制定教法何以有輕有重，經文又強調「在律文中自然彰顯明白」，行者必須緊扣本律深入詳審探求；因此我如今所作的這番解釋，著實與古代的見解有相當大的不同。〕在總結開示的文句中。

【900-0004】資持記/01c_上一上#65
【原文】上句屬佛，下句屬鈔主。據本制懷，臨事處斷；則輕重合教，萬無一失。料簡七種。初受隨簡，一是背於受體，餘六制於隨行。二就行中止作簡，二三四五是止，第七是作，六通止作。三就止中能所簡，第二是所犯罪，三四即所對境，五即能犯心。如是知之。第三標中。
【譯文】上一句屬於佛陀的大智裁度，下一句屬於鈔主道宣律祖的垂範指引。只要能透徹依循佛陀制戒的原始本懷，面臨實際事端去處分裁決；那麼戒法輕重的拿捏就必定能完全契合佛陀聖教，達到萬無一失的境界。以下對這七種範例作綜合的剖析比對。首先是「就受體與隨行來作抉擇辨析」：第一項受捨漸頓是違背了當初所受的戒體本身，其餘六項則是規範受戒之後身口實踐的隨行。其次是「就隨行中屬於止持與作持來作辨析」：第二、第三、第四、第五項屬於止惡的止持門，第七項屬於修善的作持門，第六項開制互立則通貫了止持與作持這兩大門徑。第三是「就止持門之中能犯的心識與所犯的境界來作辨析」：第二項是指所犯下的具體罪刑，第三與第四項是指造罪時所面對的外在境象，第五項則是指行者自身能造作犯罪的意圖動機。學者應當如是深入了知。在第三個大科判的標題之中。


【900-0005】資持記/01d_上一上#1
【原文】言對事者，一約判罪，二據行法，三謂亡物。〔〈二衣篇〉云：隨本受體，何律受戒，即以此律而定輕重。〕應須問曰：教門輕重，聖意可知；然現翻四律，互有乖違重輕不定；今之學者，依何為準？此門所立，其意在茲。敘古中，初科。佛滅千年，至後漢明帝時，騰蘭初至；人雖剃染，未有歸戒。
【譯文】所謂「對應具體事項」，第一是用來判定罪名，第二是作為行持作法的依據，第三是指處理亡僧的遺物。〔〈二衣篇〉說：順隨原本受戒時所納受的戒體，依據哪一部律受戒，就依據該部律來判定罪行的輕重。〕這裡應當提出疑問：教門所定罪責的輕重，佛陀的聖意本當可以理解；然而目前翻譯出的四部廣律，彼此相互違背，罪刑輕重各有不同；現在的修學者，究竟該以哪一部為準則？本門之所以設立，用意就在於此。在敘述古德傳承的段落中，這是第一小節。佛陀滅度千年之後，到了東漢明帝時期，迦葉摩騰與竺法蘭兩位尊者才初次來到中土；當時出家人雖然剃除鬚髮、身著染衣，卻還沒有正式歸依受戒的儀軌。

【900-0006】資持記/01d_上一上#2
【原文】跨及曹魏，將二百年；曇摩柯羅〔或作迦羅，此云法時。〕依《四分羯磨》，立十人受戒；為始出《僧祇戒本》，令眾誦習。〔第一差也。〕至姚秦時，十誦廣律初翻，人即依用。〔此二差也。〕其次《四分》、《僧祇》、《五分》三部廣文，並傳此地；

【900-0007】資持記/01d_上一上#3
【原文】人謂《僧祇》與先戒本文理相合，乃捨《十誦》多演《僧祇》。〔此三差也。〕唯《四分》、《五分》，曾未弘通。至于元魏法聰律師，方悟前非；於即罷講《僧祇》，首傳《四分》；然以人情執舊，多未伏從。及乎隋朝智首律師作《五部區分鈔》，往往未能盡理，尚有紛紜；
【譯文】當時的人們認為《僧祇律》與先前翻譯的戒本在文字與義理上十分相合，於是捨棄了《十誦律》，大多轉而弘傳演說《僧祇律》。〔這是第三種錯亂。〕唯獨《四分律》與《五分律》，始終未曾廣泛弘傳。直到北魏法聰律師，才覺悟到先前的偏失；隨即停止講授《僧祇律》，率先傳授《四分律》；然而由於常人習於執守舊法，多數人都未能順服依從。及至隋代智首律師撰寫《五部區分鈔》，往往還未能徹底闡明義理，義學界依然紛擾混亂；
