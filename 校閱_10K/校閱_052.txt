# 校閱材料　第052檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【052-0001】01_行事鈔/03b_卷上之三#35
【原文】四明辭謝法。《十誦》云：比丘、沙彌得和尚，知不能增長善法者，應白師言：「持我付囑某甲比丘。」師應籌量，彼比丘教化弟子何似？其眾僧復何似？好者，應付之；知不具足，更付餘師。若和尚不好，當捨去。和尚有四種：與法不與食，應住；與食不與法，不應住；法食俱與，應住；法食俱不與，不應住，不問若晝若夜，應捨去。阿闍梨亦爾。《僧祇》大同，有苦樂住別。若師令作非法事：「喚汝來！取酒來！」應耎語云：「我聞佛言，如是非法事，不應作。」第二十八、九卷中，多有行法，須者看之。《五百問》事：若弟子師，命令販賣，作諸非法，得捨遠去。《四分》：若弟子被師訶責，令餘比丘為將順故，於和尚闍梨所調和，令早受懺。應知折伏柔和，知時而受。律云：應向二師，具修威儀，合掌云：「大德和尚！我今懺悔，更不復作。」若不聽者，當更日三時懺悔如上。猶不許者，當下意隨順，求方便解其所犯。若下意無有違逆，求解其過，二師當受；不受者，如法治。若知不長益，令餘人誘將去。若弟子見和尚五種非法，應懺謝而去，白和尚言：「我如法，和尚不知；我不如法，和尚不知；我犯戒，和尚捨不教訶；若不犯，亦不知；若犯而懺者，亦不知。」問：前共行法，令弟子攝和尚；今諸律中，云何辭去？答：上言攝者，據初雖有過，弟子諫喻，有可從遂。今諫而不受，無同法義，故須去也。《僧祇》云：若師受諫者，言弟子：「汝須早語我，我無所知。」即承用之。若師言：「汝若諫我，我則是汝，汝則是我。」依前二師，方便而去。
【譯文】第四、明示辭謝捨離師長之法。《十誦律》說：比丘或沙彌拜投得和尚之後，若深知跟隨該師長不能增長清淨善法，應當向師父稟白說：「請把我的依止託付給某甲比丘。」師父此時應當客觀審酌籌量：那位某甲比丘教化弟子的德行行誼究竟如何？他身邊的大眾僧眾道風又如何？如果確實良好，應當將弟子正式付託給彼師；若查知對方亦德行欠缺不具足，應當再轉行付託給其他賢德明師。如果和尚本身行持極為不善，弟子應當毅然捨離他去。和尚有四種類型：能授與正法教化但不供給充足衣食的，應當安住追隨；只供給豐厚衣食卻不傳授正法的，不應當盲目安住；正法與衣食皆能充分給予的，應當堅固安住；正法與衣食兩皆匱乏不能給予的，絕不應當盲目留住，不論是白天還是黑夜，皆應立即捨離而去。依止阿闍梨也是如此。《僧祇律》記載大體相同，只是另外區分了在苦受與樂受環境下的不同安住抉擇。如果師父命令弟子去作違犯戒律之非法事，例如呼喝：「叫你過來！去給我拿酒來！」弟子應當以至誠柔和的語調進諫說：「我聽聞佛陀親口教誨，像這樣的非法之事，弟子是決不應當去作的。」在《僧祇律》第二十八、第二十九卷之中，載有諸多處事法軌，需要者可自行查閱研讀。《五百問》中說：如果師父命令其弟子從事商賈販賣牟利、造作諸般非法惡行，弟子得以開許捨離師長遠走他方。《四分律》記載：弟子若遭受師父嚴厲訶責處罰，為使其能重新順服受教，應當請託其他比丘從中周旋，在和尚與阿闍梨面前從容居間調解，促成師父早日接納弟子的悔過懺悔。為師者應當審知弟子此時傲慢已被折伏、神意已然柔順溫和，應當知曉適當時機而接受其悔過。律中說：受責罰的弟子應當走向二師面前，具足整理嚴整威儀，胡跪合掌陳白說：「大德和尚！我如今發心至誠懺悔，發誓從今以後絕不再犯！」若是師父當下仍不允准聽許，應當每天早中晚三時如同上述那樣持續殷勤求懺。師父若依然不肯准許，弟子應當更加低聲下氣、謙卑屈服隨順師長意旨，多方設法尋求方便解免自己所犯之過咎。弟子如果已經極盡謙抑下心全無任何違逆抗拒之態，一心乞求開解除滅過咎，身為和尚與阿闍梨的二師便應當順理成章接納懺悔；若為師者固執成見無故堅不接受者，僧團將依法對為師者處以違法之罪罰。如果確知弟子在此處身心備受壓抑、道業無法增長進益，律中允許第三者用方便智巧將弟子勸誘帶離他去。弟子如果眼見和尚具有五種嚴重的愚昧非法表現，便應當辭謝頂禮而去，當面向和尚陳白說：「我若合乎正法行持，和尚渾然不知；我若違背正法胡作非為，和尚也漠然不知；我即便犯了戒律，和尚竟放任棄置全不教誡訶斥；我即便嚴守不犯戒律，和尚亦不知褒獎勉勵；我即便犯戒後如法痛切懺悔，和尚也同樣一無所知。」有人發問：前面共行法中，分明要求弟子應當盡心攝護引導和尚；如今各部律中，為何卻又教導弟子辭別捨離而去呢？回答說：前面所說的「攝護」，是基於師父最初雖有過失，但弟子誠懇規諫勸諭之後，師長尚有順從採納改過的可能。如今的情況是弟子屢次規諫而師長剛愎自用堅決不納，彼此之間已蕩然無存互為善知識的同法同修道義，所以弟子必須決然求去。《僧祇律》說：為師者若是能虛心納受諫言，自會對弟子寬慰說：「你應當早點提醒告訴我，我方才對此確實渾然無知。」隨即便採納修正自己的過失。若是做師父的反唇相譏說：「你如果敢跑來規諫我，那我豈不成了你，你反倒成了我的師父！」遇到這種怙惡不悛的師長，弟子當依循上述辭別二師之法，以善巧方便遠離而去。
