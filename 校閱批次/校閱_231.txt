# 校閱材料　第231檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【231-0001】02_戒疏/11c_卷三上之二#7
【原文】【記】三、奪衣闕初義。準《義鈔》，前問答後，「即不應淨」下，續云：「奪衣一戒，是受持衣，或可說淨。捨與他時，失其淨法，故奪得入捨。」準此破文，顯前寫脫。「四句」者：一、不定與，決定取，奪犯捨；二、不定與，不定取，奪犯吉；三、決定與，不定取，四、二俱決定，此二奪者犯重。
【譯文】【記文】第三，奪衣戒闕失第一條義理。依照《義鈔》，在前面的問答之後，於「便不應當說淨」一句之下，接著說：「奪衣這一條戒，所奪之衣是受持之衣，或者可以說是說淨之衣。捨給他人時，便失去了說淨的法效，所以奪回後要歸入捨墮。」依照此處破斥的文意，顯出前面有傳抄脫漏之處。所謂「四句分別」：第一，心中猶豫給予、對方卻決定奪取，奪者犯捨墮；第二，雙方都猶豫不決，奪者犯突吉羅；第三，決定給予、對方猶豫奪取；第四，雙方都心意決定。後兩種情況下奪取者，都構成不可悔的重罪。

【231-0002】02_戒疏/11c_卷三上之二#8

【譯文】【記文】第四，從「乞取超過」以下，合併說明過量領受與真實說淨，反而證明它已不是別人的財物。

【231-0003】02_戒疏/11c_卷三上之二#9
【原文】【記】五、「又」下，明五敷闕第三緣。初難非妨業，五敷並自作教人同犯，又且舉黑毛戒純色方犯，故今難云：若是妨業，則應教人非犯，雜色亦應犯；若約體不如制者，則捨還亦不可用，則闕第三矣。
【譯文】【記文】第五，從「此外」以下，說明五種敷具闕失第三條緣由。起初問難這並非為了防礙正業，因為五種敷具戒不管是親自做或教他人做，罪名完全相同；況且又舉出黑毛敷具必須純黑才犯戒，所以現在反難說：如果是為了防礙正業，那麼指使別人做就應該不犯，而摻雜雜色也應當算犯戒；如果純粹是因為敷具材質不合規範而制戒，那麼即便捨棄了不合規範的物品，收回後也依然不能使用，這就闕失了第三條義理。

【231-0004】02_戒疏/11c_卷三上之二#10

【譯文】【記文】第六，從「再者」以下，說明浣衣等四條戒闕失第一條義理。二種離衣戒局限於受持之衣，這一點固然清楚；但是浣衣、雨浴衣這兩種衣，並不必然局限於受持之衣。如果認為必須是受持之衣，那麼難道其餘長衣就沒有浣洗和蓄存的過失嗎？

【231-0006】02_戒疏/11c_卷三上之二#12
【原文】【疏】今用兩意，以定前後。「三十」中犯，莫非貪心尤重，取物失方，妨道招譏。過重制捨，違本貪心故也。「九十」不爾。設因財犯，皆由造作，受用失方，不為貪貯，故不制捨。對於二離，雖非貪畜，輕慢聖教，違宿失法。制其捨懺，反淨令持也。
【譯文】【疏文】如今採用兩種立意，來判定兩部戒律的前後分別。三十捨墮當中的犯戒，無一不是由於貪心極重，索取財物不守法則，既障礙道業又招致譏嫌。因為過失嚴重，所以制令捨棄財物，以違逆本來的貪婪之心。九十單提則不是這樣。假使是因為財物而犯戒，也全都是由於製作、受用不合體統，並不是為了貪求蓄積，所以不制令捨棄財物。至於面對二種離衣戒，雖然不是為了貪求蓄積，但由於輕慢聖人教法，違背了過夜的規制而失去法效，所以制令捨棄並懺悔，反過來重新說淨而令其受持。

【231-0009】02_戒疏/11c_卷三上之二#15
【原文】【疏】一人並犯，此何所疑？四方僧者，一向不犯。由情無主當，通擬一化，但得受用，不得屬己。
【譯文】【疏文】單獨一人犯戒，這有什麼可懷疑的？至於四方僧團，則一概不犯。這是因為眾人心念中沒有具體執持的主管者，財物普遍供整個化區使用，只能共同受用，不可歸為私己所有。

【231-0017】02_戒疏/11c_卷三上之二#23
【原文】【疏】今解同活，有五戒不共犯，二離、六年、不揲、雨衣。並是受持，無共奉義。豈有我離，令彼得罪？

【231-0019】02_戒疏/11c_卷三上之二#25
【原文】【疏】有七戒不定其犯，如五長、浣、奪等。同住現在，何得不犯？必有他行，先要令說，不說者犯，何干餘者？奪、浣，受持，身現不犯。長等共使，亦得同犯。

【231-0041】02_戒疏/11c_卷三上之二#47
【原文】【記】問中。以《律》云「若自奪及教人奪而藏者，犯墮」，又云「若著樹上等處，離處犯墮」。文似重犯，故問釋之。答中，奪有二判：若對面奪，約藏論犯；若不面奪，約離處犯。文中「不面」即後判，「現前」即初判。《律》出犯相，故云「立法須爾」。而非重犯，故云「犯事不然」。

【譯文】【疏文】第一、不對著境界而捨。好比蠶綿衣不合戒法，其本質是傷害生命，如果不予以剪截毀壞，這份貪愛如何斷絕？第二、在對著境界捨當中，又有出家僧與在俗人的分別。好比蓄存、買賣金銀二寶，其質地貴重且滋長貪念，絕不是出家人所應蓄積使用的，所以制令捨給在俗之人，以表明這不是修道者的習氣。其餘各項捨財，都在出家僧人的範圍內，通於全體僧眾或個別受捨而各有不同。詳細情況正如《事鈔》中所說。

【原文】【記】捨財有五，初科。初、不對境，唯一蠶綿，餘並對境。二、對境中，二寶對俗，餘並對僧。乞鉢一戒，僧中行鉢，不通別人。餘並通三，故云「通別不同」也。
【譯文】【記文】捨財有五種，這是第一科。第一、不對境而捨，只有蠶綿衣這一項，其餘都要對境。第二、對境當中，二寶對俗人捨，其餘都對僧眾捨。乞缽這一條戒，必須在僧團中行缽，不通於對個人；其餘則通於僧團、眾多、個人三種，所以說「通別不同」。
