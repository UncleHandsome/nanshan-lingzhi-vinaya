整體看，這批譯文語意通順、術語大致掌握得住，但有幾處**義理偏移**與**前後不一致**需要修。以下按嚴重程度分則列出。

---

## 一、義理有誤，建議必改

### 【627-0006】「故無離犯」譯錯範圍
- 譯文：「所以**沒有離衣犯戒的條文**」
- 問題：比丘尼三十捨墮中**同樣有離衣（宿）戒**（屬十八同戒之一），此處所無的只是「**蘭若離衣六夜**」這一條。譯成「沒有離衣犯戒的條文」會與前文十八同戒自相矛盾。
- 建議：「所以（尼）沒有『蘭若離衣六夜』的犯相。」
- 另，「蘭若不行」重點在**佛制尼不於阿蘭若處住**，「不能獨自住」是自行添加的推論，宜改為「不住（不行）阿蘭若處」。

### 【627-0006】「非制所及」語意過寬
- 譯文：「就不在制戒的範圍之內」——易被讀成「尼浴衣完全不受戒規範」。
- 原意：既無時節限齊，就不是「**過前用**」這類時限制戒所要規範的對象，故無此戒。
- 建議：「既無時節期限，便非『過前用』之制所能及（故無此戒）。」

### 【627-0001】「不但無心緣念便名止也」句式與詞義走偏
- 譯文：「這絕不僅僅是內心**無念無想**就叫做止」
- 兩個問題：
 1. 「不僅僅是……就叫做止」的中文句式，容易被讀成「不只叫止，還叫別的」，與原文**否定**（破古）之意相反。配合【0002】「『不但』下，反古。彼謂任運不作即是止持」，可知是**破斥**。
 2. 「無心緣念」是「**沒有作意去緣慮（戒境）**」，不是「無念無想」（那是定境語），易誤導。
- 建議：「並非只要無心緣慮、任運不作，就可稱為『止（持）』。」（【0002】的引文「從『絕不僅僅』以下」須一併改）

### 【627-0004】「僧尼同犯」≠「共同犯」
- 譯文：「十八條戒比丘與比丘尼**共同犯**」——字面像「一起犯戒」。
- 建議：「有十八條戒，比丘與比丘尼**同制同犯（罪名相同）**」。
- 「單列戒本」宜作「只**單獨列出戒本條文**（不再敘緣起、廣解）」，與【0005】記文相呼應。

### 【627-0018】「但三衣者」是頭陀行名相，非「僅有三衣」
- 譯文：「針對**僅有三衣**的比丘尼來說」——會被讀成「身邊剛好只有三衣的人」。
- 「但三衣」是十二頭陀之一：**只受持三衣、不畜長衣，故不作說淨**；正因不說淨，才須開十日令作成。【0019】記文「由不說淨，故開十日」正是此意。
- 建議：「是就**受持『但三衣』法（不畜長衣、不作淨施）** 的比丘尼而言，因開許在十日內作成，不須淨施。」
- 「若說淨者」宜作「若是**作說淨的人**（非但三衣者）」，非「可以說淨的情況」。

### 【627-0019】「餘則不開」指人，不是「情況」
- 建議：「其餘（作說淨的）人則不開十日。」
- 「上雖兩分，未通伴義」譯為「分了兩面……未圓滿通達同伴的義理」過於空泛。宜：「上文雖就**鉢與衣兩方面**分別解釋，仍**未能會通『尼有伴可即時說淨』這一難點**。」

### 【627-0021】「一開已後」不是「開許一個人」
- 「一」是「一旦」，非「一人」。
- 建議：「（為但三衣人）一經開許之後，（說淨人）也同樣開至十日。如因病開粥，不病者亦開，依此類推可知。」
- 【0020】的問句可補足對象：「為何（不論但三衣人與說淨人）一律同開十日？」問答邏輯才清楚。

## 二、前後不一致（校對層面）

1. **【627-0017】「何為不得」補成「只限制**一日**」**，但【0008】明說「尼制**一夜**」；同段【0018】原文作「一日」。建議【0017】補為「為何不能（比照鉢）只限**一夜**？」並統一全篇一日／一夜的處理（可加註「一日，即一夜之限」）。
2. **鉢／缽混用**：原文一律作「鉢」，譯文【0005】【0008】【0015】【0016】【0017】出現「缽」。建議統一（宜從原文作「鉢」）。
3. **毗／毘混用**：原文「毗尼」，譯文「毘尼」。
4. **簡繁混字**：【0017】「尚未**缝**成」應作「縫」。
5. **引文對應**：記文以「從『××』以下」科判，所引二字必須與疏文譯文用语一致（如【0001】改譯後，【0002】「絕不僅僅」「這種」「翻轉」都要同步）。

## 三、用詞可再精確（不算錯，但會失真）

| 出處 | 現譯 | 建議 |
|---|---|---|
| 0001 | 「非隨戒也」→「不是隨順戒法而生起的持戒」 | 可保留並加註：隨戒＝**受後隨行護體之戒**；無記之止不成持戒功德 |
| 0001 | 「受納」→「領納**受用**」 | 「受用」是添加，作「**接受收納**」即可 |
| 0002 | 「任運**無為**不做」 | 「無為」易與無為法混淆；作「**任運（不加作意）不作**」 |
| 0002 | 「因臨此語，不覺喟然」→「不由得**令人**慨然長嘆」 | 這是記主自述，宜「（我）每面對此文，不覺喟然長嘆」 |
| 0002 | 「坦然有據」→「**坦蕩**穩實」 | 「坦蕩」多指心胸；作「**平坦明白、確有依據**」 |
| 0002 | 「熟而思之」→「深思熟慮」 | 宜「**反覆熟思玩味**」（深思熟慮現代義偏決策） |
| 0002 | 「次單持中」→「單純止持」 | 建議保留術語：「**單持**（唯止持、無作持對辨）」 |
| 0008 | 「犯同緣異」→「犯戒性質相同而引發的因緣相異」 | 「**所犯罪名相同，成犯之緣（開限日數）不同**」更貼切 |
| 0012 | 「尼則反前故也」→「比丘尼則恰恰相反的緣故」 | 句子未完；補「尼則相反（**制須伴**），**故只限一夜**」 |
| 0013 | 「擇淨境以作對首」→「選擇清淨之人作為對首」 | 「**揀擇清淨的所對境（人）來作對首說淨**」；對首是作法名，非身分 |
| 0016 | 「如法熏治都竟」→「如法**熏洗燒烤**完全完備」 | 「洗」為添加；作「如法**熏治（熏燒、修治）全部完成**」 |
| 0016 | 「過日成長」→「超過限期（**十日**）」 | 「十日」是過度指定，此處正說衣**得體即計、過日成長**，不待作成；建議去掉括註或作「經過限日」 |

## 四、小結（優先處理順序）

1. **0006「故無離犯」**（會與十八同戒衝突）
2. **0001「不但……」句式**（破古變成半肯定）
3. **0018／0019「但三衣」「餘則不開」**（頭陀名相錯讀，問答邏輯斷）
4. **0004「共同犯」、0021「一開」**（字面誤讀）
5. 一日／一夜、鉢／缽、簡繁與引文一致性校對

其餘部分（0003、0005、0007、0009、0010、0011、0014、0015）語意與律義都無明顯問題，可維持。
