# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【381-0013】02_戒疏/20a_卷四下之二#197
【原文】【記】三中，初科。注引緣起「對佛說」者，即白佛也。「更增各半搩」者，長、廣各一尺，則長五廣四。自昔並於一邊一頭增之，《感通傳》中天神所示，始增四面耳。文中，初牒釋。「開緣、本制」，極分明也。謂先依本制，長四廣三，截落縫緣竟，後於四向各裨五寸，故云「還從本制，限外別增」也。「若」下，顯非。或有不截，直取長五廣四之量，即䟦闍法，《七百結集》中已斷也。今時皆爾，縱截其面，統其底者，亦同非法。
【譯文】【記文】第三句之中，第一段科文。注文引述緣起中「向佛陳說」，就是當面向佛陀稟白陳述。「長寬各自再增加半磔手」，也就是長寬各自再加一尺，那麼總長就是五尺、總寬為四尺。從古以來，都是在坐具的其中一邊或一端進行拼接增長；直到《感通傳》中天神降臨開示，才開創出在四邊周圍均勻增補的做法。疏文中，首先提引解釋。「開許之事緣、根本之制約」，分得極為清楚明白。意思是必須先依照原本的制約，裁成四尺長、三尺寬，裁切並縫合好邊緣之後，然後才在四面邊緣各拼接增補五寸，所以說「依然依照原本制約，在限度外另行增補」。「若通」以下，指出其錯誤。世上有些人不遵循先截斷的原制，直接通體裁剪成五尺長、四尺寬的整塊大料，這正是跋闍子比丘的邪法，在《七百比丘結集》中就已經被判定為非法而斷絕廢除了。現今世人全都是如此違犯，縱使有人將正面表面拼接，底布卻依然使用整塊連貫大料的，同樣屬於違法。

【381-0019】02_戒疏/20a_卷四下之二#203
【原文】【註】佛在舍衛。比丘患瘡，膿血流出，汙僧臥具。聽以大價衣覆瘡著涅槃僧。至白衣家，言「我有患」，當褰涅槃僧，以此覆瘡坐。六群便大作，比丘舉過，佛因制戒。
【譯文】【註文】佛陀住在舍衛國。有比丘患了皮膚瘡瘍，膿血流淌出來，污染了僧團的臥具。佛陀便聽許以昂貴貴重之衣來覆蓋瘡口，穿在下裙（涅槃僧）裡面。如果到了俗人家中，說一聲「我身上有瘡患」，應當提起下裙，用這件覆瘡衣遮蔽瘡處而坐。六群比丘便將它做得極其肥大，比丘們舉發其過失，佛陀因而制定了此戒。

【381-0020】02_戒疏/20b_卷四下之二#1
【原文】【律】若比丘，作覆瘡衣，當應量作；是中量者，長佛四磔手，廣二磔手；裁竟，過者，波逸提。
【譯文】【律文】如果有比丘製作覆瘡衣（遮蓋身上瘡患的衣服），就應當按照規定的尺寸來做；所謂規定的尺寸，是長為佛的四磔手、寬為二磔手；裁剪完成後，超過這個尺寸的，犯波逸提（單墮）。

【381-0021】02_戒疏/20b_卷四下之二#2
【原文】【註】若俱過、互減，自作、教他，成者，犯墮；不成，吉羅。為他作，成、不成，吉羅。尼等吉羅。不犯者，應量，減量，得已成者裁割如量，疊作也。
【譯文】【註文】如果長、寬都超過，或者長寬互有增減，不論是自己做或教別人做，做成了就犯墮罪（波逸提）；沒有做成，犯突吉羅。為別人做，做成或沒做成，都犯突吉羅。比丘尼等人犯突吉羅。不犯的情形是：照規定的尺寸做、做得比規定小，以及得到已經做成的衣物，把它裁剪成合於尺寸，或者疊合起來製作。

【381-0023】02_戒疏/20b_卷四下之二#4
【原文】【記】八十八。文中不釋。制意、犯緣，並同上。緣起中，初敘開緣。「涅槃僧」，即內裙也。「至白衣家言」者，或往赴請，先白彼知。「六群」下，起過興制。《戒本》四句，同上分之。長八尺，廣四尺。辨相並同。
【譯文】【記文】第八十八戒。本戒律文中不再繁瑣解釋。制戒用意與犯戒條件都與前戒相同。緣起之中，首先敘述開許的因緣。「涅槃僧」就是內裙。「到俗人家中告知」的意思是，如果要前去赴請應供，應當先告知施主。「六群」以下，敘述生起過失而制定戒律。《戒本》分為四句，與前戒的分判相同。長八尺，寬四尺。辨識相狀也都相同。

【381-0032】02_戒疏/20b_卷四下之二#13
【原文】【疏】答：「女人身染外露，喜大雨衣，故犯同僧。餘三常資著用，尼好小衣，過量事少，是以輕僧。」

【381-0036】02_戒疏/20b_卷四下之二#17
【原文】【疏】《多論》：「佛身丈六，常人半之，故衣量皆半。難陀短佛無幾，故衣減之，長中一尺，短中四寸。」《僧祇》：「難陀，愛道所生，有三十相。」衣色與佛異。諸比丘衣色與佛同。六群見已，謂量亦同，遂便等作。
【譯文】【疏文】《薩婆多論》說：「佛身長一丈六尺，平常人只有佛的一半，所以衣服的尺寸也都減半。難陀比佛矮不了多少，所以他的衣量要減少：長度減一尺，幅寬（短邊）減四寸。」《僧祇律》說：「難陀是愛道所生，具有三十相。」他的衣色與佛不同，而諸比丘的衣色與佛相同。六群比丘看見了，以為尺寸也相同，於是便照著等量製作。
