# 校閱材料　第378檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【378-0001】資持記/01b_上一上#53
【原文】遵即奉持之心。機謂時須之急。託事即衣藥等緣。並下，結示無闕。紊音問，亦亂也。如古所傳，三卷三位，即名眾自共三行；今更以義判，略為三別。初約止作。上下對事造修，名作持行。中卷守戒離過，名止持行。二約眾別。上卷僧務名眾行，中下自修名別行。三約純雜。
【譯文】「遵」就是奉行持守的心意。「機」是指當務之急的需求。「託事」就是依附衣物、藥物等因緣。「並皆」以下，結尾開示全書毫無殘闕。「紊」音讀作問，也是混亂的意思。如同古人所傳承的，上中下三卷三種層次，分別稱為眾行、自行、共行三種行持；如今進一步依據義理來判定，大致分為三種差別：第一是就止持與作持而言。上卷與下卷面對事相造作修持，稱為「作持行」。中卷守持戒律遠離過非，稱為「止持行」。第二是就大眾與個人而言。上卷的僧團法務稱為「眾行」，中卷與下卷的個人修持稱為「別行」。第三是就純粹與繁雜而言。

【378-0002】資持記/01b_上一上#54
【原文】上中各局故純，下卷隨機故雜。至論互相投寄，不無相兼。且據大途，如上所判。分篇，敘意中，初明難判。人為能行，事是所造，故云境事。科謂分節，擬即度量。今下，正分。言物類者，今先舉示，如〈安居〉分房，〈釋相〉明法體，〈懺六聚〉中明事理兩懺，〈二衣〉分亡人物，〈導俗〉明說法儀，〈沙彌〉中出家業，及七篇中所注法附。
【譯文】上卷與中卷各自局限於特定範疇所以純粹，下卷隨順大眾根機廣博應對所以繁雜。若論及法門之間的互相依託寄託，也未嘗沒有互相兼通。這裡暫且依據大致的脈絡，做出如上的判定。在「劃分篇章、敘述意旨」的段落中，首先說明難以判定劃分。人是能行實踐的主體，事是所造作的對象，所以說是「境事」。「科」是指劃分章節，「擬」就是度量審度。「今」字以下，正式劃分。說到「事物種類」，現在先舉例指示：如〈安居篇〉中分派房舍，〈釋相篇〉中闡明戒體，〈懺六聚篇〉中說明事懺與理懺兩種懺法，〈二衣篇〉中處分亡人物品，〈導俗篇〉中說明說法儀軌，〈沙彌篇〉中開示出家道業，以及七篇之中所標註的附帶法式。

【378-0003】資持記/01b_上一上#55
【原文】若據篇題，實非該攝；然夏中分房，同安居類；故但標安居，其餘自攝。餘皆準此。是則三十首題，並據一篇之主耳。若爾，何以有注法附或不注者？答：有親疎故。列名中。據從敘意之下即列篇名，則文理相貫；然以十門生起間之，甚有不便。
【譯文】如果單看篇章題目，確實沒有全部涵蓋容納；然而在結夏安居中分派房舍，與安居屬於同類；所以只標示安居，其餘的自然涵蓋在內。其餘篇章全都依此類推。由此可見這三十篇的卷首相題，都是依據每一篇的主體內容而立的。既然如此，為什麼有的標註附帶法式、有的卻不標註呢？回答說：因為內容有親近與疏遠的差別。在「列舉名稱」的段落中。按理從敘述意旨之後就應當直接列出各篇名稱，這樣文字與義理才能互相貫通；然而中間用「十門生起」隔開，非常不便。

【378-0004】資持記/01b_上一上#56
【原文】古科列名在十門之首，釋云為顯諸篇是十門所括。今謂不爾，豈有敘致於前，列名在後！況勒卷分篇，次第有序。今詳，至於已下二十二字，合在列名之後，則使篇名接前敘意，生起冠後十門，文次義顯，永無疑濫。今文倒亂，恐是傳誤；豕亥之訛，古今皆爾；
【譯文】古代的科判把各篇名稱列在十門之首，解釋說這是為了顯明諸篇都在十門的總括範圍之內。如今我認為並非如此，哪裡有把序文敘述放在前面、卻把各篇名稱列在後面的道理！更何況編勒卷帙、劃分篇章，本來就有井然的順序。如今詳加審度，從「至於」以下二十二個字，應當排在列出篇名之後，這樣才能使篇名承接前面的敘述意旨，使十門生起冠在後面的十門之前，文字次序與義理才能徹底彰顯，永遠不再有疑慮混亂。如今的文句次序顛倒錯亂，恐怕是傳抄過程中的訛誤；將「豕」寫成「亥」之類的傳抄訛變，古往今來都是如此；

【378-0005】資持記/01b_上一上#57
【原文】以理為正，豈不然乎。〔講者至以標名首已，即讀篇名；入後十門，覆讀生起。〕大段第二諸篇大綱，敘意中。統大綱者，諸篇事相，皆別目故。言條流者，總中別相，義類異故。上二句即顯前文。但敘述作，不明義例，故云未委。更以下，生後意。括謂包收。鏡，明也。遠詮謂教相大旨。
【譯文】以義理順暢為準則，難道不應該這樣嗎？〔講經者講到「以標名首」之後，就直接宣讀各篇名稱；進入後面的十門時，再回頭重讀生起之文。〕大段落第二是「諸篇之大綱」，在敘述意旨中。所謂「統攝大綱」，是因為各篇的事相，都各自有獨立篇目的緣故。說到「條理流派」，是因為總綱之中有具體別相，義理與類別各自不同的緣故。上面兩句就是彰顯前面的文字。前面只敘述了撰寫著述的緣由，未說明義理的凡例，所以說「未委」。從「更以」以下，引發後面的文意。「括」是包羅收攝。「鏡」就是照亮闡明。「遠詮」是指教相大旨。

【378-0006】資持記/01b_上一上#58
【原文】將釋十門，略知次第。大聖立教，為顯一乘，欲使群迷咸歸實道。不堪受化，暫用權方。適物隨宜，凡心叵測。然則將傳遺教，必曉來源；俾夫學有所歸，行非虛造，教興之意，故在初明。既達此門，粗知來旨。何因制度輕重不倫，故次明也。上列二門，通論律藏；宗部既別，教相莫融。
【譯文】在將要解釋十門之前，應當大略明曉其先後次序。大聖釋迦牟尼佛建立教化，是為了顯明一佛乘的實相，想讓所有沉迷的眾生全都回歸真實道果。眾生不堪承受大法教化，世尊暫且採用權巧方便。適應眾生機宜而隨順施教，凡夫的心思難以揣度測量。然而將要傳承佛陀的遺留教法，必須先明白其源頭出處；為了讓學者有所歸宿，實踐不是憑空盲從，因此「教興之意」放在最初予以說明。既然通達了這一門，就能大略明曉教法由來的主旨。因何緣故戒律制度中的輕罪重罪如此參差不齊，所以接下來加以說明。上面所列的兩門，是通論全部律藏；部派宗屬既然有別，教相體系便不能混融。

【378-0007】資持記/01b_上一上#59
【原文】必有事興，依何處斷，故有三也。雖知用教約體有宗；此土受緣，並遵《四分》；或於本部攝事不周，餘部誠文，如何取用，故有四也。上且據文，文容乖闕；乖須義定，闕必文通；廢立既難，須明軌式，故有五也。已前辨教，並約能詮。教不徒施，必詮正行；
【譯文】若必然有法事發生，應當依據何者來裁斷，所以有了第三門。雖然明曉運用教法依據戒體各有本宗；但此土求受戒法的因緣，全都遵循《四分律》；倘若本部律對某些法事的涵蓋不夠周延，其餘部派的確鑿經文，到底應當如何取用，所以有了第四門。上面暫且是依據經文，但經文內容難免有所違背殘缺；違背之處必須依據義理判定，殘缺之處必須依據經文通達；法義的廢止與建立既然艱難，就必須明曉具體的軌範準則，所以有了第五門。此前辨別教理，都是就「能詮釋的文字」而言。教法絕不會徒然施設，必定是為了詮釋真實的行持；

【378-0008】資持記/01b_上一上#60
【原文】行非一轍，須指大宗，故有六也。上來六意，教行具彰；教行被機，機分多異，故七八九通局次明。前之九段，機教兩明，頗彰化意。然教傳此土，真偽相參；若不甄除，容生疑濫；又斯文之作，特異前修；元意所存，來學須曉，故次第十委而示之。次第相由，大略已顯；至下別釋，隨更明之。
【譯文】行持法門並非只有一條道路，必須指出根本大宗，所以有了第六門。上述六種深意，將教法與行持全都彰顯無遺；教法與行持是為了契合眾生根機，而眾生根機千差萬別，所以第七、第八、第九門依次說明其通達與局限。前面的九個段落，將根機與教法雙雙闡明，極其顯著地彰顯了佛陀教化的深意。然而教法傳入此土，真實與偽妄相互參雜；若不加以甄別剔除，容易產生疑惑混淆；再加上這部著作的創作，極其迥異於前代律師；原本的意旨所在，後來的學者必須通達明曉，所以依次在第十門詳細委細地予以指示。各門之間承前啟後的相由次第，大略已經彰顯；到了下文的分別解釋中，再隨文進一步予以說明。

【原文】亦引後文，用彰元意；此為明例，何事疑乎！〔此約迦葉結集意釋。〕又佛始歸真，便譏法滅；反知在日，對彼何疑。〔此取外道譏謗意釋，古記錯解，故特委示。〕對異宗中，初科，上句明佛意。毘尼之教，因茲而制，故云來也。即《義鈔》云：如來始於鹿苑，終至鶴林，隨根制戒，乃有萬差；
【譯文】同時也引用滅後結集的記載，用來彰顯當初制戒的原意；這正是再明白不過的例證，有什麼值得懷疑的呢！〔這是依照大迦葉結集戒法的意圖來作解釋。〕再者，佛陀才剛入涅槃，外道便譏諷戒法隨即泯滅；反推便可知道佛陀在世時，針對外道而制戒還有什麼好懷疑的呢？〔這是抓取外道譏嫌毀謗的角度來解釋，古記的理解有誤，所以特地詳細指明。〕在「針對各異部派」這科判中，第一段的上句說明佛陀的本懷。毘尼戒律的教法正是因此而制定，所以說是隨機而來。這就如《義鈔》所說：如來從鹿野苑初轉法輪開始，直到鶴樹林間雙圓涅槃為止，隨順不同根機而制定戒律，因而產生了成千上萬的差別；
