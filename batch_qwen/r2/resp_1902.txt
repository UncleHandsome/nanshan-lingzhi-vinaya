以下逐則校對，先列**較嚴重的義理／術語錯誤**，再逐條細評並附建議改譯。

---

## 一、最需要修正的四處

| 出處 | 問題 | 嚴重度 |
|---|---|---|
| 0004 | 「此根本罪，聖道之源」被譯成「罪是通向聖道的源泉」——**主語錯置，義理顛倒** | ★★★ |
| 0003 | 「六聚」譯成「六篇罪聚」——**篇／聚混用**（律制為「五篇六聚」） | ★★★ |
| 0015 | 「為之生勤」譯成「生起憐憫」——**勤≠憐憫**，屬增字解經 | ★★ |
| 0004 | 「九百二十一億六十千歲」逕改為「九百二十一億六萬歲」——**古今數詞單位混用** | ★★ |

## 二、逐則細評

### 【0001】
1. **「損物情」→「損害了眾生情識」**：不妥。「物」指他人／眾生，「情」指情命、情感，南山文中「損物情」即「損惱傷害眾生」。「情識」是心識術語，與此處語意不合。
 → 建議：「因為所犯屬**性戒**（體性本惡），會損惱傷害眾生。」
2. 「這是性戒」宜補主語：「**所犯之戒**屬于性戒」。
3. 「六聚」首次出現宜加注（波羅夷、僧殘、偷蘭遮、波逸提、提舍尼、突吉羅），讀者才知「六聚所結的制罪」所指。
4. 「增上忍」宜加注：四善根（煖、頂、忍、世第一）中**忍位之上品**，至此位不墮惡趣。譯文「才會止息」的「才」字可保留。

### 【0002】
1. **「違理」→「違背理性因果」**：「理性」在現代漢語指 rationality，易生誤解。
 → 建議：「業道罪是違背**業道正理（真理）**」；後句「違背理性之罪」改「違背正理之罪」。
2. 引文語譯「唯任自心靜心思維觀照」略嫌疊贅。
 → 建議：「篇聚之罪依教法作法即能滅除，業道之罪則**任憑自己靜心思惟觀照**。」
3. 「事伏即淨」譯「以事相懺悔壓伏即得清淨」可，若作「依事作法懺，罪即伏滅而得清淨」更貼近。

### 【0003】
**「不分自六」語意流失＋篇聚誤用。**
原文是「不必（另作）分別，自然即是六聚」，譯文卻說「自然**區分**為六**篇**罪聚」，既與「不分」相違，又把六聚寫成六篇。
→ 建議：「就懺悔之法依罪聚而論，不須另加分別，自然就是**六聚**。」

### 【0004】
1. **「此根本罪，聖道之源」**：應讀作「此（所犯者乃）根本重罪，（根本戒為）聖道之源」。譯成「這是極根本的戒罪，**是通向聖道的源泉**」，變成「罪是道源」，義理顛倒。
 → 建議：「波羅夷是根本重罪，**而所受的根本戒正是聖道的源頭**；既已毀犯，此生便與聖道絕分。」
2. **數字**：「六十千」直譯「六萬」雖合字面，但前面「億」用今制（10⁸），古今單位混用會失真（《目連問經》原意在換算他化自在天壽之人間年數）。
 → 建議：**保留原文「九百二十一億六十千歲」**，另加注「古譯數詞單位與今制不同」。
3. **「與他化天同壽受苦」**：經意是「地獄壽量如他化自在天壽（十六千歲），換算人間年數即上述數字」。譯文把人間年數與天壽直接畫等號，易誤導。
 → 建議：「其受苦壽量與他化自在天相同（換算人間年數如上）。」
4. 「得以往僧團序列中收留」**語法不通**（「往…中收留」主動被動混雜），且「預入僧儔」重點在「忝列僧末、不足僧數」（見 0005）。
 → 建議：「得以**忝列僧眾之末**」。
5. 「後發勝心」譯「勇猛勝進之心」略增；作「殊勝的悔改之心」較穩。
6. 「一生絕分」可作「此生於聖道果證已**無分**」，比「絕斷了證道的因緣」貼切。

### 【0005】
1. **科判層次**：「第二釋法波羅夷敘開中」應是「第二科『釋法』中，『波羅夷·敘開』一段」。譯文把「釋法」與「波羅夷」併讀為「解釋波羅夷法」，層次略失。
2. 「不充當僧團僧數」語意含混。
 → 建議：「**不得充入僧數**（不能作羯磨足數之人），地位排在眾僧之末。」
3. 「終身堅持所犯的重戒不再犯」譯得好，可保留。
4. 「此云無間」→「漢譯為無間」即可，「地獄」為增字（可留，但宜知是補足）。

### 【0006】
1. 「才准許為其**作法行懺悔法**」疊贅。
 → 建議：「才為他作『**與學悔**』的羯磨法。」
2. 「都無覆者」「犯竟無覆」直譯為「完全沒有覆藏」，與下一則（0007）「乃據臨懺同篇盡露，非謂從初始終無覆」的判定會打架。
 → 建議：此處加短注：「依下疏釋，『都無覆』指臨懺時同篇之罪全部發露，非謂犯後從未覆藏。」

### 【0007】
1. **「次明二篇隨懺皆得」→「只要隨所犯發露懺悔皆可成就」**：原文重點正是「**不必盡露**亦可與法」，譯文加「發露」反而與結論自相矛盾。
 → 建議：「其次說明第二篇僧殘，**隨其懺悔（不論覆藏與否）皆得與法**。」
2. 末句「僧殘篇**隨犯隨懺**」為原文所無。
 → 建議：「由此可知，隨其懺悔即可與法，不必（同篇）一切罪都已發露。」
3. 「牒釋」建議作「牒文解釋」；「古今兩義通塞」可補「何者通、何者塞」使讀者易懂。
4. 「罪夜離合」的解釋（各隨長短／以短從長）譯得準確，可保留。

### 【0008】
1. **原文「知蹊術」疑有脫文**（或應作「未知／尠知蹊術」）。譯文直接補「未」而未出注，屬**默默改字**。
 → 建議：譯文保留，但加注「原刊作『知蹊術』，疑脫否定詞，一說讀作『（令）知蹊術』」。或改譯為「因懺者學解疏薄，**故須令知其門徑**」。
2. 「至時口判」→「**隨口**裁決判定」帶有輕率意味。
 → 建議：「**臨事時再口頭判示**。」
3. 「往往」為增字，可刪。

### 【0009】
1. **「蹊術，小徑也」→「偏門小徑」**：「偏門」為原文所無，且帶貶義（走後門、旁門），與疏主「小徑＝門徑」的中性比喻不符。
 → 建議：「『蹊術』就是小路，**比喻（作法的）門徑**。」
2. 「示今注」可作「顯示**現今疏中所加的注文**」，比「當前的注文」清楚。

### 【0010】
「義張四位」→「四個**位階**」不妥。此四者（覆藏罪、覆藏情過、僧殘情過、僧殘本罪）是**四科分類**，非階位高低。
→ 建議：「義理上開為**四科（四項）**。」

### 【0011】
1. 「隨夜隱者，得吉羅」宜點明**計夜結罪**：「隨覆藏的夜數，**一夜結一突吉羅**。」
2. 「在此之前」指代不明。
 → 建議：「在（受別住等正懺之）前，必須先懺除此覆藏罪。」

### 【0012】
1. 「本應貫通六聚**罪名**」：「本應」為增字，「罪名」是現代法律語。
 → 建議：「若就覆藏而言，**通於六聚**（凡覆藏六聚之罪，皆結突吉羅）。」
2. 「懺已須治」譯「覆藏罪懺悔之後還必須接受治罰」正確，可補「（即別住、六夜等）」使對照更明。

### 【0013】
1. **「輕斯法律」→「輕慢了這部神聖戒律」**：「神聖」為增字渲染，「斯」即「此」。
 → 建議：「輕慢此戒律之法。」
2. 「折服挫折其身形與心志」疊詞。
 → 建議：「**折伏其身心（驕慢）**。」
3. 「作法補行苦行」：原文只作「作法補行」（補行覆藏日數之行），「苦行」是解釋性增字，可加括號處理。
4. 「不與**大僧**同住」易與「大僧／沙彌」的位階混淆（此人仍是比丘）。
 → 建議：「不與**清淨僧眾**同住。」
5. 「情過」全篇譯作「情理過失」尚可，但更精確是「**約情（存心欺隱之情）所論之過，非另結罪體**」，建議首次出現時加此注，後文沿用。

### 【0014】
1. 「無論年月時間長短，所受的覆藏治罰**必須**與隱藏的日數相當」——「無論…必須」句式是增出來的讓步語氣。
 → 建議：「指覆藏的年月長短，與所受治罰（日數）**相應**。」
2. 「翻名釋義，即治罰相」譯得可，惟「即顯明了受罰的具體相狀」稍鬆，可作「即是顯示治罰之相」。

### 【0015】
1. **「為之生勤」→「生起憐憫」**：勤＝殷勤、勤勞（為他作法奔走），非憐憫。括號內雖補「為之勤勞作法」，但正文已誤導。
 → 建議：「同持戒的僧眾心懷此念，**為他殷勤辛勞（作法）**。」
2. **「過隨事逆」**譯「情理之過隨著治罰之法而受折挫違逆」屬一解，但另有讀法：「只要覆藏之心仍在，其過即隨事而乖違不順（難以除滅）」，與上句「罪易而懺難」語脈更順。
 → 建議：此句**存疑並列兩解**，或採後者，勿定於一譯。
3. 「情不可容」→「不可**輕易**寬容」：「輕易」軟化了原意，宜刪。
4. 「制與六夜僧中苦行」→「制定**義務**讓他…」：現代法律語，建議「因此制定給與六夜，令在僧中行苦行」。「六日六夜」可，但宜注「摩那埵，此云意喜，義譯六夜」。
5. 「望以勗勉，慚耻至極」→「以此勉勵其惕勵自新」疊贅，可簡化為「藉此策勵，令其慚愧至極，永為鑑誡」。
6. 「故自**私**喜」→「自己**私下**歡喜」：「私」是自心之意，非秘密。
 → 建議：「所以**自心歡喜**，不辭勞苦。」
7. 「求懺**極**難」的「極」為增字，可刪。
8. 「亦為僧喜」譯「為僧眾所歡喜」語意可通，但更順是「**也令僧眾歡喜**」。

## 三、系統性建議

1. **術語統一表**：篇（五篇）／聚（六聚、七聚）必須分明；「情過」「制罪／業道罪」「覆藏／發露」「與法／作法」宜固定譯法並首見加注。
2. **節制增字**：本批譯文多處加入原文無有的評價詞——神聖、偏門、輕易、極、往往、勇猛、憐憫——佛典白話宜「寧質勿文」，解釋性內容放括號或注腳。
3. **改字必出注**：0008「知蹊術」補「未」、0004 數字換算，都應以校注方式處理，不宜在正文默默改動。
4. **避免現代法律／行政語**：義務、罪名、准予、收留、位階等，換成「制令、罪、開許、攝列、科」較合律疏語境。
5. **科判層次**：0005「第二釋法／波羅夷敘開」、0012「列釋初中」等，建議用「第○科『…』中，『…』一段」的固定格式，讀者才看得出疏記的層層科分。
6. **前後照應**：0006 與 0007 對「都無覆」的界定必須互注，否則單看 0006 會誤解為「犯後從未覆藏才可懺」。

整體而言，多數句子（0007 罪夜離合、0013 別住釋名、0014 覆罰相應、0015 意喜釋義）理解正確、可讀性也好；主要風險集中在 **0004 的道源錯置**、**0003 篇聚混淆**、**0015 生勤誤譯**與**數字／增字**四類，建議優先修訂。
