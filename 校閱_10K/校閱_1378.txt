# 校閱材料　第1378檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1378-0001】資持記/16c_下四#37
【原文】俱堪物養，人天師範；故使誦持，無輕受體及形服也。六念中，初指同。不同俗者，簡濫也；化教，令念三寶及戒天施，名為六念。制通沙彌者，明須念所以也；五眾通制，不唯大僧。至下，顯別。今年若干，即生年也；某年等受戒，出家年也。以下，示意。大僧但記得戒時分，不念生年。
【譯文】正因為具備此德才能承受世間一切供養，堪作人天眾生的引導師範；因此必須常常誦念受持，切不可輕易忽視所得的無作戒體與身上的出家法服。在六念之中，首先指出與大僧相同之處。強調不同於世俗之法，是為了區隔混淆；在一般的化導教法中，教導念佛、念法、念僧以及念戒、念天、念施，稱為「六念」。佛制六念法通於沙彌也要修持，是說明必須念想的根本理由；這是五眾弟子共同受持的法規，並不僅僅限於比丘大僧。「至」字以下，顯發沙彌特殊的差別之處。「今年若干歲」，是指自己肉身出生的歲數；「某年某月受戒」，是指自己受戒出家的法臘年資。「以」字以下，指明法義內涵。比丘大僧只需要牢記受具足戒的確切年月時刻，不需要天天記掛出生年歲。

【1378-0002】資持記/16c_下四#38
【原文】沙彌生法二年以分上下，故須雙念。十數中。第一但出外計。《業疏》續云：佛法不爾，身假食資。食取濟形，道取濟神。故假形食，緣修道行。至論道也，要修離著為本；不識道元，乃以斷食為道，故須破之。二中。疏云：佛法不爾。內報外報，皆有本因。諸眾生有，皆因名色。〔名，即心也。
【譯文】沙彌則需要依據肉身出生的歲數與受法的年限，兩者兼看以區分僧團中的長幼次序，因此必須兩者同時繫念。在十數之中。第一數（鈔文）只列出了外道的計執。《業疏》接著闡述道：佛法完全不是外道所說的那樣，人的色身必須假借食物來滋養維持。食物是用來保全生命形體，正道則是用來長養心性神識。因此暫時假借飲食滋養形體，作為因緣以修持正道之行。若真要探究正道本體，必定以修持遠離一切貪愛執著為根本；外道不識正道的源頭本質，竟然把斷絕飲食當作得道，所以必須予以痛斥破除。在第二數中。註疏中說：佛法並非如此。無論是正報的身心還是依報的世界，都有其根本因緣。一切眾生之所以流轉三有，都是源於「名色」。〔名，指的就是心識。〕

【1378-0003】資持記/16c_下四#39
【原文】心不可見，止可名談。初始識支，故轉為名；假染持識，即染為色。託彼胎藏，展轉增長；月滿便生，何得自然也。三中。前標云：痛痒想者，古翻語質，即三受也；痛即苦受，痒即樂受，想即捨受。文出外計。疏云：佛法不爾。生憎愛者，實由陰本，何干天也。
【譯文】心是無形無相看不見的，只能藉由名稱加以指涉宣說。投胎最初一念的識支，轉化立名為「名」；假借父精母血的染愛以受持心識，這血肉體質就稱為「色」。寄託在母體的胎藏之中，隨著時日輾轉長大增厚；懷胎十月圓滿便降生人間，哪裡是外道胡說的「自然而生」呢。在第三數中。前面標示說「痛痒想」，這是古代翻譯的古樸名詞，指的就是苦、樂、捨三受；「痛」就是苦受，「痒」就是樂受，「想」在此處即代表不苦不樂的捨受。文句是引述外道的錯誤見解。註疏中說：佛法完全不是這樣。眾生之所以生起憎惡與貪愛，根本是由於五陰業因所致，跟大梵天或天神有什麼關係呢！

【1378-0004】資持記/16c_下四#40
【原文】初念緣色名識，了達染淨為想，領納違順曰受。由三想〔苦、樂、捨也〕，便生三受；由三受故，便有三行。故長淪歷，無解脫也。四中。疏云：佛法不爾。苦集世俗因果，滅道出世因果。眾生知苦無諦，聖人解苦有諦。凡聖皆由因果，那云無也！五中。
【譯文】最初一念緣取色境攀緣稱為「識」，明了通達境界是染是淨稱為「想」，領納逆境或順境稱為「受」。由苦、樂、捨三種分別之想，隨即生起苦、樂、捨三種受領納於心；因為有了三種受，便引發貪、瞋、癡三種造作之行。因此眾生長劫沉淪於生死巨浪之中，永遠找不到解脫的出路。在第四數中。註疏中說：佛法完全不是這樣。苦諦與集諦是世俗生死的流轉因果，滅諦與道諦則是出世間涅槃的還滅因果。凡夫眾生縱然身受無量痛苦卻不能明了苦諦的真實，出世聖人體解苦相因此具足通達真諦。無論凡夫還是聖人，都離不開因果業報的法則，外道怎能妄稱因果皆空無所有呢！在第五數中。

【1378-0005】資持記/16c_下四#41
【原文】疏云：佛法廣破，我在何處？為在色中？為在識中？計此身中，但有五陰；隨陰計我，則有五種。如是離合〔為復五陰，各有一我，則是離也；若惟一我，則在色時，餘四應無，即是合也。〕，次第求之。覓我無從，便悟妄執；得無我理，分成無漏相似聖人。六中。扃，即門戶，疏作六窓。佛法不爾。
【譯文】註疏中說：佛法以廣大智慧全面破斥這種謬論，所謂的「我」究竟存在於何處？是在色身之中嗎？還是在心識之中？審視反觀這具身心，不過就只是五陰假和合而已；若執著於五陰之中有我，就會衍生出五種我見。像這樣透過「分開獨立」與「混合同一」〔究竟是五陰每一陰各自擁有一個獨立的我，這就是分開尋求；若只有唯一一個我，那麼當我在色身時，其餘受想行識四陰就該沒有我，這就是混合同一。〕，依次層層追究尋找。找尋自我根本了不可得，便能當下覺悟那純粹是虛妄的執著；一旦證悟「諸法無我」的真理，就能證入無漏解脫，分證相似位聖人的境界。在第六數中。「扃」就是指門戶，註疏中則寫作「六個窗戶」。佛法完全不是這樣主張。

【1378-0006】資持記/16c_下四#42
【原文】識隨根起，若是一識，豈眼根中而聞聲耶！七中。却，即逆也。觀前為逆，觀後即順。疏云：由得五通，逆順觀中，八萬劫外，冥然不委，計為冥諦。轉縷丸者，舉喻顯也；謂以縷繫丸，高山放下；縷盡丸止，以喻無修。疏破云：佛法不爾。要須方便增修乃剋。
【譯文】眼、耳等心識是隨順各自的根門而生起的，如果六根裡面只有唯一同一個心識，難道眼睛能夠代替耳朵聽聞到聲音嗎！在第七數中。「却」就是逆向反觀的意思。向前逆推過去生稱為逆觀，向後順看未來世稱為順觀。註疏中說：外道因為修得了五種世俗神通，在逆推與順看的極限中，對於八萬大劫之外的幽遠境界，茫然無知無法徹底探究，於是便妄自執著該處為原始的「冥諦」。以「滾動絲線線團」為例，是舉出譬喻來彰顯其謬執；意思是把絲線繫在線團上，從萬仞高山向下丟擲；絲線放盡之時線團自然停止，以此比喻不需要修行、業盡自然解脫。註疏破斥道：佛法完全不是這樣。必須依賴方便善巧不斷精勤增上修持才能剋期證果。

【1378-0007】資持記/16c_下四#43
【原文】如七覺支，簡擇正理，方能至詣，何有不修耶！八中。外道三學皆邪。烏雞等者，以見禽畜，今報已盡，遠業將起，生彼色天；不思遠因，謂即報是；便効彼畜，噉草不淨等。八禪，謂修世禪，謂為涅槃。邪慧，即彼所見；邪進，如投嵓臥灰棘等。佛法不爾。四依為聖道緣。
【譯文】如同修習「七覺支」，必須明智揀擇正理，然後才能通達究竟極致，哪裡有完全不修行就能自然解脫的道理呢！在第八數中。外道所持守的戒、定、慧三學全都是邪妄的。所謂的「烏鴉戒」、「野雞戒」等，是因為外道以天眼看到某種禽鳥或畜生，今生的畜生報身受盡之後，極久遠以前的善業即將成熟起現行，生到彼色界天；外道不知深究那遙遠的前世宿因，誤以為單憑今生做野雞、烏鴉的畜生果報就是生天的原因；於是盲目模仿那些畜生，低頭吃草、吞食不淨糞穢。所謂「八禪」，是指修習世俗的四禪八定，誤以為那就是究竟涅槃。所謂「邪慧」，指的就是他們偏邪的斷常知見；所謂「邪精進」，就是如跳崖自戕、赤身臥在骨灰與荊棘之中殘害身體等。佛法絕不是這樣。佛法以「四依止」作為入聖道的緣由。
