# 校閱材料　第1256檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1256-0001】資持記/12b_中四下#28
【原文】或迷忘者，謂疑不識，或直牒迷忘而懺者。如下，結示。或違教罪，或不學無知，故云罪非逃也。故下，勸令依法。水鏡清明，而又過之，故云逾也。彼即能懺，此即受懺者。何下，徵釋所以。三報，現報生報後報也。餘下，指廣。三十，標中。本是僧法，由界僧少，次開二位。
【譯文】所謂「或者迷惑遺忘」，是指心中存疑而無法辨識，或者是直接說「凡是迷惑忘記的罪一併懺悔」。從「如」字以下，作總結開示。這不是違反了戒律的制裁，就是屬於不肯修學而產生的無知，所以說「罪業是無從逃避的」。從「故」字以下，勸勉大家應當依律而行。懺主的內心如明鏡般清澈光明，甚至比鏡子還要透澈，所以說是「逾」。前者是指能懺悔的人，後者是指受領懺悔的人。從「何」字以下，追究並解釋其中的原因。所謂三報，就是指現世受報（現報）、次生受報（生報）與後世受報（後報）。從「餘」字以下，指明詳細內容見於其他處。在三十捨墮的標題中，這原本屬於全體僧團的羯磨僧法，但由於界內僧人太少，隨後開許了兩種處置位階。

【1256-0002】資持記/12b_中四下#29
【原文】就下二位，皆是別法；但事儀有別，故兩分之。僧法中。財是犯緣，心是業本，罪是已成之業，必能感報。雖具三捨，得名唯據捨財，就意正在捨心，心捨罪除；衣仍清淨，故復還之。立此四科，括懺盡矣。捨財中，捨法差別。從寬至狹，四重料簡。初僧尼相對；僧捨下，就僧分自他。
【譯文】就後面的這兩種位階而言，全都是個別處理的別法；只是在作法儀軌上有所差別，所以才分成兩種。在僧法當中，財物是引發犯戒的助緣，內心是招感罪業的根本，罪過則是已經造就的業力，必定會招感未來的苦報。雖然具備了捨財、捨心、捨罪這三種捨，但名稱上單單依據「捨財」來建立，而就其深層用意來說，真正的關鍵在於「捨心」，內心貪念捨除了，罪過才能消滅；財物依然是清淨的，所以僧眾又再歸還給他。設立了這四個項目，就將懺悔的規範總括無遺了。在捨財法中，捨納的法則各有差異。從寬泛到狹隘，共經過四重篩選辨別。首先是比丘與比丘尼相對辨析；從「僧捨」以下，就比丘捨墮劃分為自行剪斬（自捨）與對他人捨除（對他捨）。

【1256-0003】資持記/12b_中四下#30
【原文】簡去蠶綿一戒。二下，他中分道俗。次簡畜貿兩戒。通下，道中分通局。復簡乞鉢一戒。言局有二，一局當界，二局僧中。通則反之，故云餘二十六等。定體中，初科。三五者，三即長離販賣，五即更加乞受。上三最數，下二次之，故云通犯否；餘戒非無，但是稀耳。
【譯文】這裡先簡別除去「蠶綿」一條戒。在「二」字以下，把「他」的部分分為道（出家）與俗（在家）。其次簡去「畜」「貿」兩條戒。在「通」字以下，於道的部分再分通、局。又再簡去「乞鉢」一條戒。所說的「局」有兩種：一是局限於本界之內，二是局限於僧眾之中；「通」則與此相反，所以說「其餘二十六條」等。在「定體」一科中，這是第一小科。所謂「三」「五」：三是指長衣、離衣、販賣，五則是在這三條之外再加乞、受。前面三條違犯最多，後面兩條次之，所以說「通犯與否」；其餘各戒並非沒有違犯，只是稀少罷了。

【1256-0004】資持記/12b_中四下#31
【原文】長體中，初科，前明六物。若下，明百一物。受持則一向不說。不受則有說不說，如雨衣覆瘡衣等；縱不加法，並不須說；餘衣巾等，即同長物須說。二隨百一者。若合加受法，已見上科；此謂一向不須加者，故別簡之。屩音脚，草履也。十六枚器，釜瓶各二，盆蓋杓各四；僧尼俱開，說不說異。三中。
【譯文】在長物本質（長體）的內容中，第一科前面先說明六種生活必備衣物。從「若」字以下，說明百一項隨身器物。如果已經依法加持受持，就一概不需要說淨。若是未受持的，則有需要說淨與不需要說淨的分別，例如雨衣、覆瘡衣等；縱使不作法加持，也全都不需要說淨；其餘的衣巾之類，就等同於蓄長之物而必須說淨。第二是隨屬百一物的器物。如果理應加入受持法，前面科判已經說明；這裡是指那一類一向不需要作法加持的物資，所以特別加以揀選區分。「屩」字音同腳，就是草鞋。十六枚生活器皿，鍋釜、水瓶各兩件，水盆、器蓋、水杓各四件；比丘與比丘尼都開許蓄留，但需要說淨與不需要說淨則各有不同。在第三點中。

【1256-0005】資持記/12b_中四下#32
【原文】言隨重物者，謂隨身所須；八穢體非，被褥用重。既不入淨，故無長過。四中，初正明。不下，斥古，初引古非。今下，顯今解，初示正義。不下，簡部別。《四分》、《多論》，如長衣戒引。五中。五種緣開，上三並未入，下二約已入。相染指上者，亦即長戒。
【譯文】所謂「隨身貴重物品」，是指隨身所必需的事物；八種不淨穢物本來就不是如法資具，被褥這類物品在生活使用上極其重要。既然不納入說淨的範圍，也就不存在蓄長的過失。在第四點中，開頭先正面說明。從「不」字以下，駁斥古德的說法，首先引出古說的謬誤。從「今」字以下，顯明現今的正確理解，首先指出正確認識。從「不」字以下，辨析各部派的區別。《四分律》與《薩婆多論》的觀點，就如同長衣戒中所引述的那樣。在第五點中，提出了五種開許不犯的緣由，前三種屬於財物尚未真正歸屬於自己，後兩種則是屬於財物已經正式入於自己名下。所謂互相染污是比照前述原則，也是指長衣戒而言。

【1256-0006】資持記/12b_中四下#33
【原文】如十日中皆得衣，初日為能染，餘日為所染，皆隨能染判犯。離衣中。隨二三者，謂須提名別牒。非下，遮濫。販賣，標中。三事名相各別，前戒已分，不重引也。明入捨中，初列輕物入捨。佛所開物，犯者數故。若下，次明重物不入。由佛不聽，為之稀故。
【譯文】例如在十天之中都得到了衣服，第一天的衣服為「能染」，其餘各天的衣服為「所染」，都依照第一天的情況來判斷犯罪。在離衣戒中，所謂「隨二三」，是指必須個別點出衣物的名稱來單獨陳述。從「非」字以下，防範混淆濫用。在販賣戒的標題中，這三種事項的名稱與實體各有不同，前一條戒已經做過分析，此處不再重複引述。在說明納入捨財的內容中，首先列出輕賤的物品應當納入捨財。因為這是佛陀所開許擁有的物品，違犯的人較多的緣故。從「若」字以下，接著說明貴重物品不得納入捨財。由於這是佛陀所不聽許擁有的，這類犯行較為少見的緣故。

【1256-0007】資持記/12b_中四下#34
【原文】總別中，初明別捨別還，罪得合懺。若下，次簡捨衣有染不染。三十戒中，唯五長有相染義，謂衣中有三，十日、月望、急施，及長鉢長藥為五。此明唯畜長，制須盡捨；離衣販乞等，隨別捨之，不盡相染。忘見，標中。謂懺長罪捨衣時，遺忘不盡；及懺罪已，方見忘物；而染不染別，故須辨之。
【譯文】在總懺與別懺的內容中，首先說明分別捨財、分別還給，罪過可以合併總懺。從「若」字以下，接著揀別所捨的衣服是否有互相染污的性質。在三十捨墮戒中，只有五種蓄長物具有互相染污的義理，也就是衣物當中有三種：滿十日未說淨衣、過一月蓄長衣（月望衣）、急施衣，再加上蓄長缽與蓄長藥，共為五長。這裡說明只有蓄積長物，才規定必須全部捨出；若是離衣、販賣、求乞等罪，則隨著個別事項分別捨棄即可，並不會全體互相染污。在遺忘與尋獲（忘見）的標題中，是指在為了蓄長之罪而捨衣時，遺漏忘記而沒有全數取出；等到懺完罪之後，才看見遺忘的衣物；這其中有染污與不染污的差別，所以必須深入辨析。

【1256-0008】資持記/12b_中四下#35
【原文】正明中，初科，上二句示義。決字，古記云：字誤，合作污。〔有節決字在下，於文非便。〕若下，辨相染，初明不染。由入淨故。前捨說淨，即是二法。若還財下染，次明相染。田未說淨，無法簡故。前財即已懺者。乞販亦捨者，但使忘物是長，不論捨者是長非長。次科，初示。
【譯文】在正面說明的內容中，第一科上面兩句說明其義理。其中的「決」字，古記認為是傳寫筆誤，應當作「污」字（因為若將「決」字斷句在下文，語氣上並不順暢）。從「若」字以下，辨析互相染污的行相，首先說明不構成染污的情形。這是因為已經作過說淨法的緣故。先前的捨財與說淨，原本就是兩道法式。從「若還財」以下屬於構成染污的情況，接著說明互相染污的行相。由於歸還之財物尚未進行說淨，沒有法式可以劃清界限的緣故。所謂「前財」，就是指已經懺過罪的財物。求乞或販買的衣物也一併要捨出，只要遺忘之物屬於蓄長之物，就不論所捨棄的是長物還是非長物了。在下一科中，首先指出。
