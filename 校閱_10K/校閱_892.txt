# 校閱材料　第892檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【892-0001】資持記/01c_上一上#4
【原文】引證中二，初通指制戒證。觀下律者，即諸犍度。據前戒本，諸俗譏言無有正法，外道無異；佛因制戒，頗符此意。然是他譏，佛意未顯，故指下文制法以明。如〈說戒犍度〉，因諸外道八日十四十五三時集會，瓶沙王見已白佛，因制半月說戒。
【譯文】「引律為證」的內容分為兩部分，首先是廣泛指稱制定戒條的證明。若審視律典後續的內容，正是指各個「犍度」。根據前面戒本的記載，世俗常有人譏諷批評說僧團沒有正法，與外道毫無差別；佛陀因而制定戒律，這正好與戒本的意旨相吻合。然而世人的譏諷只是一端，佛陀的深意尚未完全彰顯，所以藉由後文制立各項事法來加以闡明。例如在〈說戒犍度〉中，因為外道每逢八日、十四日、十五日這三天聚會，瓶沙王看見後便向佛陀稟白，佛陀才因此制定了每半個月集合說戒的僧法。

【892-0002】資持記/01c_上一上#5
【原文】〈安居犍度〉，因六群春夏冬三時遊行，居士譏言諸外道尚三月安居，此諸釋子一切時遊行，因制安居。〈自恣犍度〉，因諸比丘結安居已，作制不共語問訊；佛言汝曹癡人，同於外道共受瘂法。〈衣犍度〉中，有比丘持木鉢；佛言不應持如是鉢，此是外道法；
【譯文】又如〈安居犍度〉中，因為六群比丘在春、夏、冬三季都到處遊行化緣，在家人譏諷說外道尚且懂得在三個月的雨季中安居，釋迦牟尼佛的弟子卻一年到頭都在奔走遊蕩，佛陀因此制定了結夏安居之法。在〈自恣犍度〉中，因為比丘們結夏安居之後，立下約定彼此不互相談話、不互相問候；佛陀喝責說：「你們這些愚癡之人，竟然如同外道一樣，共同受持這種不能開口的啞巴法。」在〈衣犍度〉中，有比丘拿著木製的鉢；佛陀教誡說：「不應該拿這樣的鉢，這是外道的做法。」

【892-0003】資持記/01c_上一上#6
【原文】乃至比丘畜繡手衣，著草衣、樹皮衣、葉衣、瓔珞衣、皮衣、鳥毛衣、人髮衣、馬尾牛尾衣露身，佛一一皆言不應爾，此是外道法，乃至結云：如是一切外道法不應作。且引一二以息世疑；下諸犍度，其文非一。故云凡所及並懷也。〔舊記指下結集中譏謗之文，則凡所竝懷之語，如何釋耶？
【譯文】比丘乃至蓄積繡花手巾，穿著草衣、樹皮衣、樹葉衣、瓔珞飾衣、獸皮衣、鳥毛衣、人髮衣、馬尾或牛尾所編之衣，甚至裸露身體，佛陀一一呵責說不應當如此，這都是外道的法度；最後總結說道：像這一切的外道行法，都不得造作。此處且略引一兩項事例以止息世人的疑惑；律典後續各犍度之中，類似的條文不勝枚舉。因此才說凡所制約的條目，都深懷此意。〔舊有的註記認為這是指後文佛滅結集中外道譏毀誹謗的文句，那麼原文「凡所及並懷」這句話，又該如何解釋呢？〕

【892-0004】資持記/01c_上一上#7
【原文】懷即佛意，異術即外道。〔術音述，道也。〕故下，別引結集證。此即本律五百結集緣起之文。以佛滅後，外道譏言沙門瞿曇法律若煙耳！世尊在日，皆共學戒；而今滅後無學戒者。於是迦葉遂興結集，即告眾曰：我等可共論法毘尼，勿令外道以致餘言。〔祖師取意加上一句，使文易見。
【譯文】「懷」就是佛陀的本意，「異術」就是指外道。〔術的音讀為「述」，意思就是道術。〕自鈔文「故」字以下，是個別引用結集為證的段落。這就是本律五百結集緣起的文句。因為佛滅度之後，外道譏諷說：「沙門瞿曇所制定的法律，薄弱得就像輕煙一樣！佛陀在世的時候，大家共同學戒；如今佛陀滅度了，就再也沒有人學戒了。」大迦葉尊者聽聞後便發起結集，告訴大眾說：「我們應當共同集會討論經法與毘尼，切莫讓外道引發譏嫌毀謗的話柄。」〔祖師依照文意在前面加上了一句話，使整段文句脈絡更加易懂。〕

【892-0005】資持記/01c_上一上#8
【原文】問：今明佛意，那引結集文耶？答：當科所明，竝引佛世；文既非一，不可別舉，故通指之。然結集之文，語意彰顯，故得更引展轉為證。問：結集時事，既在滅後，那證聖心？答：結集存法，既為絕於餘言；佛意本興，信專懷於異道。如下五例，開制往徵；
【譯文】有人提問：現在既然是要說明佛陀在世時的本意，為何要引用滅後的結集文獻呢？回答：本段科判所要說明的，本就一概引用佛陀在世時的事例；文字既然繁多，無法逐一列舉，所以才作廣泛的指稱。然而結集時的文句，語意非常顯豁明白，所以特地再引用過來，轉相佐證。又問：結集的事情既然發生在佛陀入滅之後，如何能證明佛陀當初制戒的聖心呢？回答：結集是為了留存戒法，本就是為了杜絕外道的閒言非語；佛陀當初制戒的深意，確實專注於防範外道邪法。就像後文所舉的五種範例，藉由開許與制約去推究徵驗；

【892-0006】資持記/01c_上一上#9
【原文】亦引後文，用彰元意；此為明例，何事疑乎！〔此約迦葉結集意釋。〕又佛始歸真，便譏法滅；反知在日，對彼何疑。〔此取外道譏謗意釋，古記錯解，故特委示。〕對異宗中，初科，上句明佛意。毘尼之教，因茲而制，故云來也。即《義鈔》云：如來始於鹿苑，終至鶴林，隨根制戒，乃有萬差；
【譯文】同時也引用滅後結集的記載，用來彰顯當初制戒的原意；這正是再明白不過的例證，有什麼值得懷疑的呢！〔這是依照大迦葉結集戒法的意圖來作解釋。〕再者，佛陀才剛入涅槃，外道便譏諷戒法隨即泯滅；反推便可知道佛陀在世時，針對外道而制戒還有什麼好懷疑的呢？〔這是抓取外道譏嫌毀謗的角度來解釋，古記的理解有誤，所以特地詳細指明。〕在「針對各異部派」這科判中，第一段的上句說明佛陀的本懷。毘尼戒律的教法正是因此而制定，所以說是隨機而來。這就如《義鈔》所說：如來從鹿野苑初轉法輪開始，直到鶴樹林間雙圓涅槃為止，隨順不同根機而制定戒律，因而產生了成千上萬的差別；

【892-0007】資持記/01c_上一上#10
【原文】良由眾生根器不同，樂聞有異，故令聖制輕重不等，緩急有殊；諸部輕重乃有無量，雖復不同，各稱根性；皆有奉行之益，以是義故，聖制本有五名。又引《付法藏傳》，佛現在世，分為五部等。〔大集夢㲲亦同此意。〕若爾，《義鈔》下文復云無五意者？
【譯文】這確實是因為眾生的根器資質不同，所喜好聽聞的教法有差異，所以使得聖人制定的戒規有輕有重，緩急各有所別；諸部派律典的輕重差別多至無量，雖然規定互不相同，卻各自切合該部眾生的根性；只要遵行都能獲得解脫的實益，正因為這個緣故，聖人所立之法原本就有五種部派之名。又引《付法藏傳》說，佛陀在世之時，便已懸記分作五部等等。〔《大集經》夢見氎布碎裂的事蹟，也表達相同的意旨。〕如果這樣，為何《義鈔》後文又說佛在世時並無五部的意圖呢？

【892-0008】資持記/01c_上一上#11
【原文】答：此明佛在不分之意，謂隨機立制，豈有五意！故使現在但有五名，不分五別；不妨輕重緣急，即是懸被將來。故彼云聖者之制，現無五意，但有懸記之言；佛去世後，始有諸部分張等。次句彰異。言多別者，統論分部。初則二部剏初各集；
【譯文】回答：那是說明佛在世時僧團尚未分化為五部的深意，意思是佛陀只是隨順機緣制戒，哪裡預先存有分割出五個宗派的企圖！因此佛在世時戒律只有五種名稱的區分，並沒有真正分立出五個獨立部派；但這並不妨礙佛隨緣制訂的輕重緩急，正是為了在冥冥之中預先護佑未來的學人。因此那部書說，聖者的制度在佛世時並無分立五部之意，僅有預作懸記的預言；直到佛陀去世之後，各部派才真正分道揚鑣。次句是用來彰顯宗派的差異。所謂「多別」，是總括論述部派的分化。最初是上座部與大眾部兩部開端各自結集；

【892-0009】資持記/01c_上一上#12
【原文】次一百年後，上座部中分出五部；又云：二百年後分十二部；四百年後分十八部〔通根本為二十〕；乃至復分五百部。〔備如《義鈔》，此不煩引。〕相傳云：本作宗則有其十八，後修時改為多別。故知此語通含，非唯五部。引證中。既云多別，不可備陳；略引二部，以明異相，故云且如等。
【譯文】接著佛滅百年之後，從上座部中分化出五個部派；又有說法認為佛滅二百年後分化為十二部；佛滅四百年後進一步分化為十八部〔若算上根本二部則總為二十部〕；乃至最後細分至五百部之多。〔詳細內容如《義鈔》所載，此處不再繁複引用。〕依古德相傳：此處原文原本寫作「宗派則有十八」，後來重修時改為「多別」。因此可知這句話涵蓋廣泛，並非僅僅侷限在五部而已。在「引證」的段落中。既然說部派差異甚多，無法全部列舉；只能略引其中兩部，用以說明互異之相，所以說「暫且以某某為例」等等。
