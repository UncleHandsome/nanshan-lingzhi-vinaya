## 總評

這一段譯文整體理解正確，脈絡（差五德→上座作法→展轉至下座→病者開緣→五德自恣→舉罪處理→人數不足）都掌握住了，六聚的名目也列得準確。問題主要不在「讀錯」，而在 **「主語省略處補錯或補得太死」「斷句造成的邏輯未點明」「幾處律學術語未加注或注得不精確」**。以下分層列出。

---

## 一、語意需要修正／補足之處

**1.「應作法言」的主語不宜鎖定為「上座」**
- 原文：`應加捉足之言，應作法言：「大德一心念……」`
- 譯文：「**上座**應當依法說道」
- 問題：這段自恣詞是**一切自恣者通用**的作法文，只是此處依序由上座先說。譯成「上座應當依法說道」，會讓人誤以為此詞專屬上座。
- 建議：「（自恣者）應當這樣作法說：『……』（此詞通於一切自恣者，此處先由上座說）。」

**2.「即破《十誦》家法」的破斥點沒有譯出來**
- 譯文只說「這就破斥了《十誦律》一家的做法，彼律規定：僧眾說畢，五德到上座前稟告……」——讀者看不出**哪裡被破**。
- 破的是：十誦的安排讓五德**等到大眾全部自恣說畢**才（到上座前）處理自己的自恣；僧祇則要求五德**回本座、隨次第自恣**。
- 建議加一句夾注點明：「（十誦之意，五德係待僧眾說竟才自恣並宣告；僧祇則不許，故云『破』。）」

**3.「依律遮法治之」不是「懲處」**
- 譯文：「依照律典中『遮（禁止受自恣）』之法**懲處**」
- 問題：「遮法」即本篇的**遮自恣法**——作羯磨遮止其自恣，先把罪事處理掉，屬**程序性處置**，不是刑罰意義的「懲處」。
- 建議：「便依律中『遮自恣』之法處理（先遮止他自恣，待罪事處斷完毕）。」

**4.「並反治謗罪」的被治者是誰，譯文沒交代**
- 譯文：「都要反過來治以毀謗之罪」——主語懸空，易被誤讀成治「犯戒者」的謗罪。
- 建議：「也一律反過來治**舉罪者**的謗罪（無根而舉，即使所舉屬實仍成謗）。」這是本段與下文「五德舉過無問虛實」對比的關鍵，務必補出。

**5.「則且白停進不」的斷句與斷定**
- 譯文：「暫且作**單白羯磨**暫停**其**自恣，**再議其能否進求自恣**」
- 三個疑點：
 (a) 此句宜讀作「則且白停，**進不**如四人法中說」，「進不（否）」是「後續可否進行／如何處理」，譯成「再議其能否進求自恣」是**過度具體化**。
 (b) 「白停」一般指**單白停自恣**，但暫停的對象應是**大眾的自恣**（非僅該犯者一人），譯文的「其」指涉不清。
 (c) 「單白羯磨」的斷定建議核對《資持記》及四人法原文後再定。
- 建議：「就先作白暫停自恣；至於之後進行與否（如何處理），如『四人法』中所說。」

**6.「若五人已上」宜補足區間**
- 譯文括注「（不滿出罪人數）」方向對，但白話宜直說：「五人以上、**未滿二十人**」，與上句「滿二十」形成對照。

**7.「舉得出罪之事」譯成「大事」不精確**
- 建議：「舉發了**須作『出罪』羯磨才能處理的罪事（即僧殘罪）**」，去掉「大事」這種含混用語。

**8.「若五德及僧」的「及」**
- 譯文「五德**以及**僧眾舉發了……」易讀成兩者共同舉發；此處是列舉可能的舉罪者，宜作「五德**或**僧眾舉發（某人）犯六聚之罪」。

## 二、措辭與白話化建議

| 譯文 | 建議 |
|---|---|
| 「其中一位五德」 | 「**第一位**五德」（與下文「第二位五德」成對） |
| 「受歲（自恣受歲）」 | 循環注釋，等於沒注。改「受歲（即受自恣；安居圓滿、受新歲）」 |
| 「若是五德舉發過失，無論是否屬實；」 | 此處用分號使句子懸空。改「五德舉發過失，則**不論虛實（皆不治罰）**：因為……」 |
| 「雖然理合推求糾繩」 | 半文言。改「按理雖應追究糾責」 |
| 「反倒生起諍端之本」 | 改「反而成為諍訟的根源」 |
| 「哪裡談得上**安撫**大眾」 | 「安眾」是令僧眾安樂、和合，改「**安定僧眾**」 |
| 「其他比丘（別人）」「其他個人」 | 律中「別人」是**相對於「僧（眾）」的個別比丘**，非「其他的人」。統一作「個別比丘（未經僧差遣者）」 |
| 「本人自己承認伏罪」 | 「（犯者）自己坦白認罪」 |
| 「便如常禮退」 | 未翻。改「便依常法作禮而退」 |
| 「第三位上座」 | 「第三席（第三位次第的上座）」，避免誤會為「三位上座」 |
| 「各自依照相應的篇章」 | 「各依所犯所屬的**篇聚**（如僧殘篇等）如法治罰」 |

## 三、術語加注建議（首次出現處）

- **五德**：受僧白二羯磨差遣、具足五德（不愛、不恚、不怖、不癡、知自恣不自恣）而負責接受大眾自恣的比丘。全段反覆出現，務必首見即注，否則易被讀成「五種德」。
- **互跪**：律中跪式（一般解為胡跪、右膝著地）。
- **捉足**：執捉長老之足以表敬（印度敬禮法），即自恣詞中加「我捉長老足」之語。「五德是上座者」譯為「五德戒臘高於自恣者」是可從的一讀，但建議注明係依文義推定。
- **當篇／六聚**：五篇七聚的判罪分類；偷蘭遮無獨立篇，故「當篇」宜作「所屬篇聚」。
- **出罪**：僧殘罪的最後解罪羯磨（阿浮訶那），**須二十清淨僧**——這正是下文「滿二十」「五人已上」的分判依據，值得補注。
- **白停**：作白暫停自恣之法。

## 四、建議修訂版（供參）

> 第四、說明對僧眾自恣的方法。《增一阿含經》說：如來與僧眾同坐草座，告訴諸比丘：「你們各自就草座而坐，我要受歲（即受自恣）。」詳細如《新歲經》所載。
>
> 接著正式說明對僧自恣之法。第一位五德（受僧差遣、具五德而接受大眾自恣者）走到上座面前，大展坐具（尼師壇），互跪；第二位五德則到次座前站立。《四分律》說：上座見五德前來，即從座起，互跪、偏袒右肩、合掌；其餘僧眾都比照上座的作法。《十誦律》說：若接受自恣的五德是上座（戒臘高於自恣者），自恣者應加「捉足」之語。作法時應這樣說：「大德一心念！眾僧今日自恣，我比丘某甲亦自恣；若見、聞、疑罪，大德長老哀愍故，語我；我若見罪，當如法懺悔。」（此詞通於一切自恣者，此處先由上座說。）上座說完回到本座，第一位五德便移到第三席前站立；原在次座前的第二位五德，也如上法接受次座自恣。如此依次展轉，直到最下座；各人說完，就回到自己的本座。律中開許病比丘，可隨身體所安（姿勢不拘）。
>
> 若兩位五德自己也要自恣，《僧祇律》說：五德應各回本座處，隨其次第自恣，不得等全僧自恣完畢才自恣。這正是破斥《十誦》一家的作法——十誦主張：大眾自恣說畢，五德才到上座前稟告：「僧一心自恣竟！」然後依常法作禮而退（意即五德待僧竟才自恣）。
>
> 若五德或僧眾舉發某人犯六聚之罪（波羅夷、僧殘、偷蘭遮、波逸提、提舍尼、突吉羅），或犯者自己坦白認罪，僧眾應當檢核查驗；審查屬實的，各依所犯所屬篇聚如法治罰完畢，然後才自恣。
>
> 若是個別比丘（未經僧差遣者）舉罪，應窮究勘問是非、覈實其事；確認所舉無有虛假浮濫，便依律中「遮自恣」之法處理（先遮止其自恣，待罪事處斷）。縱然所舉確實是犯，但舉罪者的見、聞、疑三根交代不清（無根而舉），也一律反過來治**舉罪者**的謗罪。
>
> 至於五德舉發過失，則不論虛實，皆不治罰：因為他是僧所差遣，又兼具德行；縱使所舉成虛，三根容有錯謬，按理雖應追究糾責，但其用心在於令人離惡，所以不在治罰之列。這與個別比丘不同：未經僧差遣，動輒擅自陳說他人過失，恐濫及清白之人；又內無德行，多不知時宜，反成諍訟的根源，哪裡談得上安定僧眾？所以所舉若虛，即結成謗罪。
>
> 若僧眾滿二十人，隨其所犯何罪都能如法治處（乃至僧殘的出罪）。若五人以上而未滿二十人，舉出須作「出罪」的罪事（僧殘），就先作白暫停自恣；至於之後進行與否，如「四人法」中所說。
