# 校閱材料　第657檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【657-0001】02_戒疏/14a_卷三下之二#17
【原文】【記】戒本，第二句。「三種別望」，謂各開一月。「二月滿」者，謂上二衣月滿即作，餘一可待。不作過月，例皆染犯。
【譯文】【記文】戒本第二句。「三種別望」，是指三件衣各自開許一個月。「二月滿」，是指前兩件衣滿一個月就必須製成，剩下的一件才可以繼續等待。如果超過一個月不製衣，例同皆犯捨墮。

【657-0002】02_戒疏/14a_卷三下之二#18
【原文】【律】迦絺那衣已出。
【譯文】【律文】迦絺那衣（功德衣）之期已經捨除。

【657-0003】02_戒疏/14a_卷三下之二#19
【原文】【疏】三、「迦絺那出」者，開緣謝也。其人雖不受開，而是開故，不犯。
【譯文】【疏文】第三句、「功德衣捨除」，是指開許蓄衣的因緣已經結束。該比丘雖然沒有享受功德衣的開許利益，但因為仍屬於制度規定的開許期間，所以此期間內不犯。

【657-0004】02_戒疏/14a_卷三下之二#20
【原文】【記】第三，云「其人不受開」者，由是但三衣人，不受五利故。
【譯文】【記文】第三句中，說「該人不受開許」，是因為他是唯持三衣的人，本來就不受持功德衣五種利益的緣故。

【657-0005】02_戒疏/14a_卷三下之二#21
【原文】【律】若比丘得非時衣。
【譯文】【律文】若比丘得到非時衣。

【657-0006】02_戒疏/14a_卷三下之二#22
【原文】【註】時者，無迦絺那衣，自恣後一月；有迦絺那衣，自恣後五月。非時者，謂過此限。
【譯文】【註文】所謂「時」，沒有受持迦絺那衣時，是自恣日後的一個月內；若有受持迦絺那衣，是自恣日後的五個月內。所謂「非時」，是指超過這個期限。

【657-0007】02_戒疏/14a_卷三下之二#23
【原文】【疏】四、「非時衣」者。注解約時，謂於時外，故曰「非時」。以時內通開，無論替故，今非時中，故限一月。
【譯文】【疏文】第四句、「非時衣」。注文依據時節來解釋，是指在做衣時節之外得到的衣物，所以稱為「非時」。因為在做衣時節之內普遍開許蓄留，無論是否為了替換舊衣；如今是在非時期間，所以限定蓄留一個月。

【657-0008】02_戒疏/14a_卷三下之二#24
【原文】【記】四中。注「約時」者，一月、五月也。「時外」曰「非時」，無衣十一月，有衣七月也。「以」下，明簡時所以。
【譯文】【記文】第四句中。注文「約時」，是指一個月或五個月。「時外」稱為「非時」，未受功德衣者有十一個月，受功德衣者有七個月。「以」字以下，說明揀擇時節之所以然。

【657-0009】02_戒疏/14a_卷三下之二#25
【原文】【律】欲須便受，受已疾成。若足者，善。
【譯文】【律文】需要時便應接受，接受後應當迅速製成。如果布料已足夠，那是最好的。

【657-0010】02_戒疏/14a_卷三下之二#26
【原文】【註】若十日中同衣足者，裁割如上；不者，至十一日，隨衣多少，並犯捨墮。
【譯文】【註文】如果在十天之內同類布料已齊足，便如前文所述裁割縫製；若不依此裁製，到了第十一天，隨衣物多寡，皆犯尼薩耆波逸提（捨墮）。

【657-0011】02_戒疏/14a_卷三下之二#27
【原文】【疏】「欲須便受」下，顯成衣相也。言「疾成」者，以初日得衣未足，十日得足，當日須成。不爾，明出便犯。故云「疾」也。約分三位。上解初位，此是通開，如注解者是也。
【譯文】【疏文】「欲須便受」以下，顯明製衣的時間規律。所謂「迅速製成」，是因為第一天得衣時不足，第十天布料齊足，當天就必須製成。不然的話，到了明天黎明破曉便構成犯戒。所以說要「迅速」。就期限而言劃分為三個時期。上面解釋的是第一時期，這是普遍開許的時期，正如注文所解釋的。

【657-0012】02_戒疏/14a_卷三下之二#28
【原文】【記】第五中。初總示。「言」下，別釋。恐過十日，故令「疾成」。「約」下，示位。此即初位，餘二位見次科。「此通開」者，謂同長衣常開耳。
【譯文】【記文】第五句中。起初總體提示。「言」字以下，分別解釋。唯恐超過十天，所以命令「迅速製成」。「約」字以下，標示時期的劃分。這就是第一時期，其餘兩個時期見於下一科。「此是通開」，是指如同長衣戒平常開許十天的規定。

【657-0013】02_戒疏/14a_卷三下之二#29
【原文】【律】若不足者，得畜一月，為滿足故。
【譯文】【律文】如果布料不足，為了等待齊足的緣故，得蓄留一個月。

【657-0014】02_戒疏/14a_卷三下之二#30
【原文】【註】若同衣不足者，至十一日同衣足者，即十一日應如上作，違者至十二日隨衣並犯。乃至二十九日亦爾。至三十日，若足、不足，同衣、不同，即日並如上法。
【譯文】【註文】如果同類布料不足，到了第十一天同類布料才齊足者，當天第十一天就應當如上法裁製，違犯者到了第十二天隨衣物皆犯。乃至第二十九天也是如此。到了第三十天，無論齊足或不足、同類或不同類，當天都必須依上述法則處理。

【657-0015】02_戒疏/14a_卷三下之二#31
【原文】【律】若過畜者，尼薩耆波逸提。
【譯文】【律文】如果蓄留超過這個限期，犯尼薩耆波逸提。

【657-0016】02_戒疏/14a_卷三下之二#32
【原文】【註】比丘尼同犯。不犯者：若十日內同衣足作，乃至三十日即日作衣；餘有緣同「長衣戒」。
【譯文】【註文】比丘尼同犯此罪。不犯的情況：若在十天內同類齊足即裁製，乃至第三十天當天裁製衣服；其餘開許因緣與「長衣戒」相同。

【657-0017】02_戒疏/14a_卷三下之二#33
【原文】【疏】「若不足者得畜一月」，此第二位中，從十一日至二十九日來，得同相合，當日即作。不同，更開明日望。此則約日持犯，故又「疾成」，如注解「二十九日亦爾」者是也。第三位者，「至三十日」，無論得不，俱同說持。明日已去，更不開也。
【譯文】【疏文】「若不足者得蓄一月」，這是在第二個時期中，從第十一天起到第二十九天為止，只要得到相同的布料湊合齊足，當天就必須製衣。如果不同類，可以再開許留待明日指望。這是依據單日來論斷持犯，所以也必須「迅速製成」，如注文所說「第二十九日亦爾」。第三個時期，是指「到了第三十天」，不論得到布料與否，都必須同一律作說淨加持。過了明天以後，就不再開許蓄留了。

【657-0018】02_戒疏/14a_卷三下之二#34
【原文】【記】第六中。以不足故，更開二十日，共為一月。初釋第二位，總十九日。「得同相合」，即同衣足也。「當日即作」，不作，明日犯。「不同」，謂得不同衣。「更開明日望」，即後位三十日也。「約日持犯」，初位猶通十日內成，從十一日去，止限一日，故又「疾」也。或恐不成，則令麤行急竟，加受法已，更復細刺。「第三位者」，唯開一日。「得不」者，得則加持，不得則說淨。不爾，明日齊犯。
【譯文】【記文】第六句中。因為不足的緣故，再額外開許二十天，合計為一個月。起初解釋第二時期，共十九天。「得同相合」，是指同類布料已足。「當日即作」，若不作，明天就犯戒。「不同」，是指得到不同類的布料。「更開明日望」，就是指後面的第三時期第三十天。「約日持犯」，第一時期還通融在十天之內製成，從第十一天起，期限只限一天，所以又要求「迅速」。或者唯恐來不及縫好，便聽許粗粗縫製應急完工，加持受法完畢後，日後再細緻縫刺。「第三位者」，僅開許最後這一天。「得不」，得到布料就加持受持，得不到就作說淨法。若不如此，明天一律犯戒。

【657-0021】02_戒疏/14a_卷三下之二#37
【原文】【疏】此戒如前長衣相似，為但衣故，所以立之。餘文可解。
【譯文】【疏文】這條戒與前面的蓄長衣戒相似，正是為了唯持三衣者，才特別設立這條戒。其餘文句意思容易明白。

【657-0022】02_戒疏/14a_卷三下之二#38
【原文】【記】顯同異中。上二句示同，謂犯相與前無別。下二句顯別，此被但三衣，前開畜長者。「餘可解」者，即「若過」下三句，注文辨相，皆易曉故。
【譯文】【記文】在辨析同異中。前兩句指出相同之處，是指犯相與前戒並無差別。後兩句顯明差別，本戒是針對唯持三衣者，前戒是開許平常蓄留長衣者。「餘文可解」，是指「若過」以下三句，注文辨明罪相，都容易通曉。

【657-0023】02_戒疏/14a_卷三下之二#39
【原文】【律】四、取非親尼衣戒。
【譯文】【律文】四、取非親屬比丘尼衣戒。
