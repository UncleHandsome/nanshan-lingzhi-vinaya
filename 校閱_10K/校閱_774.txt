# 校閱材料　第774檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【774-0001】02_戒疏/18a_卷四上之三#44
【原文】【記】戒本，六句，對文可解。
【譯文】【記文】戒本經文的六個文句，對照經文即可理解。

【774-0002】02_戒疏/18a_卷四上之三#45
【原文】【疏】就釋開緣。言開「病」者，身抱患惱，若不開別，無由濟命，自救不閑，終無異計。「作衣」久延，恐廢正業。「施衣」不受，後須難得，自濟形苦，亦福施主。「道船」途路，多有留難。「大眾」既集，村落又小，食少人多，不開送食。「沙門施」者，將化入道，故開受供。「衣時」通給，為補夏勞。「僧次」福大，道俗俱益。略敘大意，至時張展。
【譯文】【疏文】關於解釋各項開許的因緣。所謂開許「生病」，是指身體遭受病患苦惱，若不開許私下個別進食，就無法保全性命，自己救護自身都來不及了，絕不可能還有分裂僧團的異心。「作衣服」耗時長久，恐怕耽誤正修道業。「施主布施衣服」若不及時接受，日後需要時就難以獲得，接受布施既可救濟色身的寒苦，也能為施主種福。「走陸路或乘船」旅行途中，多有阻礙與險難。「大批僧眾」既然雲集，而村落又狹小，食物少而人數多，又不開許分送食物外出。「其他沙門布施」的情況，是為了將來度化他們進入佛道，所以開許接受供養。「受衣的時節」普遍發給，是為了補償夏安居的辛勞。「按僧團次序受供」福德廣大，對僧俗雙方都有利益。在此簡略敘述大體旨意，到了解釋具體條目時再予以詳細鋪展。

【774-0003】02_戒疏/18a_卷四上之三#46
【原文】【記】釋九緣中，初標。「言」下，列釋。次第九相，前七牒戒文，後二出他部。隨相顯意，細尋分取。「略」下，結示，囑後廣之。
【譯文】【記文】解釋九種開緣（釋九緣）中，首先是標名。從「所謂（言）」字以下，逐一列舉解釋。依照次第排列有九種相貌，前面七種是照錄本律的戒文，後面兩種是出自其他部派的律典。隨著條相顯露其制意，仔細推尋即可辨析分明。從「簡略（略）」字以下，是結尾提示，囑咐在後文再行詳加發揮。

【774-0004】02_戒疏/18a_卷四上之三#47
【原文】【疏】律列七緣，衣、僧二開，《五分》、《多論》。
【譯文】【疏文】本律一共列出了七種因緣，而衣服時節、僧團次序受供這兩種開許，是補充自《五分律》與《薩婆多論》。

【774-0005】02_戒疏/18a_卷四上之三#48
【原文】【記】總示中。「衣、僧」即後二種，「衣時」出《五分》，「僧次」出《多論》。餘八易解。僧次開者，不簡名行，作相無遮。及先別請，食時通召，縱界有僧，亦無別過。即《賢愚》云「僧次一人，福不可量，如飲大海，則飲眾流」等。
【譯文】【記文】在總體提示（總示）之中。所謂「衣服時節與僧團次序受供」，就是指後面的這兩種，「受衣時節」出自《五分律》，「僧團次序」出自《薩婆多論》。其餘的八種容易理解。僧團次序受供之所以開許，是因為不苛求對方的名聲與德行，發出信號作法便無所遮阻排拒。以及先前雖然是個別邀請，但在受食之際通同召請眾僧，縱使結界內還有其他僧人，也沒有脫離大眾的過失。這就是《賢愚經》所說的「僧團輪次受請哪怕只有一人，其福報不可限量，就如同飲用了一滴大海水，就等於飲用了百川眾流的水」等語。

【774-0006】02_戒疏/18a_卷四上之三#49
【原文】【疏】問：「《律》明『作衣』已是時限，何用『衣時』？」
【譯文】【疏文】有人問：「《律藏》中說明『縫製衣服』已經是一定的期限了，何必還需要另外立『受衣時節』？」

【774-0007】02_戒疏/18a_卷四上之三#50
【原文】【疏】答：「據本受意，有長短也。文云『下至一縫』者，極短也。餘如《鈔》解。」
【譯文】【疏文】回答說：「根據原本領受利益的意趣，時間有長有短。經文說『甚至只縫一道線』，這是極為短暫的情況。其餘的道理如同《行事鈔》所解釋。」

【774-0008】02_戒疏/18a_卷四上之三#51
【原文】【記】問答中。言「長短」者，「衣時」則一月、五月，受利時長，「作衣」則隨得衣財，受作時短。《義鈔》答云：「此舉受持之時是也。」故知《四分》唯據作時，時內不作，於義未顯，故引《五分》別出此緣。《義鈔》又云：「九中『作衣』、『衣時』，唯在時中，不通非時。餘七通時、非時。」又云：「施衣新得，彼此有益；作衣己物，更無勝利。是故不同。」「餘」下，即指《義鈔》。
【譯文】【記文】在問答辨析（問答）之中。所謂「長短」，「受衣時節」長達一個月或五個月，承受利養的時間較長；「縫製衣服」則是隨著獲得布料之後，動手製作的時間很短。《義鈔》回答說：「這是指受持功德衣的時限。」由此可知《四分律》僅依據具體裁作的時間，在該時節內若未裁作，其開許的義理就不夠明顯，所以才引用《五分律》另外分立出這一項開緣。《義鈔》又說：「九種因緣中，『縫製衣服』與『受衣時節』這兩項，只限於正當的受食時間，不通於非時受食。其餘七種則通於正當時間與非時受食。」又說：「接受施衣是新獲得資具，對彼此都有利益；自己縫衣是修整自己的衣物，施主並無增上的殊勝利益。所以兩者並不相同。」從「其餘（餘）」字以下，就是指參見《義鈔》。

【774-0009】02_戒疏/18a_卷四上之三#52
【原文】【疏】又大眾集中，「食足四人，長一人為患」者。
【譯文】【疏文】又在大批僧眾集會之中，所謂「受食者滿四人，多出一人便成為犯戒之患」。

【774-0010】02_戒疏/18a_卷四上之三#53
【原文】【疏】有人言：「謂食處四中，長一添眾故，非謂外人，由是三人隨意食也。『乃至百人長一人為患』者，應云『九十七人為患』，但以『長』名義同，故云『一』也。如和先六十，同名『一供養人』。」
【譯文】【疏文】有人解釋說：「這是指受食的四個人之中，多出的一人讓總人數變成了僧團的規模（成眾），並非是指外在來的人，因為三個人是可以隨意進食的。經文說『乃至一百人多出一人為患』，按道理應該說是『多出九十七人為患』，只是因為『多出（長）』的名義相同，所以統稱為『一』罷了。就如同和先比丘等六十位頭陀，共同被稱作『一位供養侍奉人』一樣。」

【774-0011】02_戒疏/18a_卷四上之三#54
【原文】【記】釋大眾中，初解。即就能別明之，三人之外，加一成眾，即容犯別，故此一人即為犯患。「乃至」下，防難。應先難云：「四人可爾，注中五十至百，三外則多，何名長一？」故此通之：「人數雖多，望長是一。」、「如」下，引證。佛安居竟，入室禪寂，勑諸弟子不得輙見，唯除一供養人。及和先比丘六十頭陀至，世尊聽見。此亦以「一」目多，故引為例。
【譯文】【記文】在解釋大眾集會（釋大眾）之中，這是第一種解釋。這是直接從能脫離大眾結夥受食的人來闡明，三個人之外，加上一人就達到了四人而結成僧團（成眾），這就具備了犯別眾罪的可能，所以這多出的一人就是造成犯戒的禍患。從「乃至」以下，是防範問難。原本應當先發難說：「四個人的情況確實如此，但注文中說五十人乃至一百人，在三人之外多出了很多，怎能稱作多出一人？」所以此處予以會通：「人數雖然眾多，從多出來的角度來看同樣都屬於『多出』。」從「就如同（如）」以下，引用經文作為佐證。佛陀結夏安居結束後，進入密室禪坐靜修，命令所有弟子不得隨意求見，唯除一供養人。後來和先比丘帶著六十位修頭陀行的僧人到來，世尊准許他們晉見。這裡也是用「一位」來指稱多數人，所以引來作為先例。

【774-0012】02_戒疏/18a_卷四上之三#55
【原文】【疏】有人言：「彼此八人，名為大眾，食無陪供，又難得處，開別不犯。七人已下，名為小眾，食雖難得，容有兼濟，如《多論》中，故不開之，故云『長一為患』。」
【譯文】【疏文】有人解釋說：「彼此各有四人，合為八人，才稱為大批僧眾，在食物無法供應充足、而且在取得困難的地方，開許私下受食而不構成犯戒。七個人以下，稱作小僧眾，食物雖然取得困難，但還可以勉強周濟均分，如同《薩婆多論》中所說，所以不予開許，因此才說『多出一人便成為犯戒之患』。」
