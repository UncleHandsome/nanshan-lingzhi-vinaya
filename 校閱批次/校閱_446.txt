# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【446-0001】03_業疏/04b_卷一之四#33
【原文】次破中三：初明本宗不定。二十八人出瞻波犍度，癡狂、捨戒等出婬戒及受戒犍度，行覆藏等出人犍度，故云律文隱顯等。「若下次」引捨戒例難。引彼開緩，竝今制急，可驗癡狂定是非數。「故下」三示須用諸部
【譯文】在第二「破斥」中分三層：首先說明本宗律文自身隱顯不固定。二十八人出自〈瞻波犍度〉，癡狂、捨戒等出自淫戒條文及〈受戒犍度〉，行覆藏等出自〈人犍度〉，所以說律文隱顯不定等。自「若有」以下，第二引捨戒的例子來詰難。引捨戒對象本來開許較寬緩，對照如今秉持僧事的制戒極為嚴謹，足可驗證癡狂、入定之人必定不合充數。自「故須」以下，第三指示必須採用諸部律論。

【446-0002】03_業疏/04b_卷一之四#34
【原文】文中若為比丘作法，以尼等四人足數者，或由報別，或法未具，故不開之。翻對及尼受具二十、懺罪八人、出罪四十者，各成兩足，互不相通
【譯文】文中如果為比丘作羯磨法，而用比丘尼等四眾來充當足數的話，或者是由於果報形別不同，或者是由於戒法尚未具足，所以不予開許。若是反過來相對（如為尼作法），以及比丘尼受具足戒需要二十人、懺罪需要八人、出罪需要四十人，則是兩部僧各成足數，互不相通借用。

【446-0003】03_業疏/04b_卷一之四#35
【原文】初本宗尼四人中初通示。大尼報別，沙彌未具，尼下二眾即兼二義。「翻下」別簡。據尼本不足僧，然僧得與共秉，故云翻對。懺罪八人，即摩那埵
【譯文】在第一「本宗比丘尼等四人」中，首先通泛指示。大尼（比丘尼）是果報形別不同，沙彌是戒法未具，比丘尼之下的二眾（式叉摩那、沙彌尼）則是兼具此二種義理。自「翻對」以下，個別揀擇。按規定比丘尼本不能充當比丘僧數，然而大僧（比丘）得與她們共同秉行（如受具等），所以說「翻對」。懺罪八人，就是指行摩那埵法。

【446-0007】03_業疏/04b_卷一之四#39
【原文】若滅擯者，為非既重，加覆染心，故作法除出海岸也。若應擯者，根本已壞，去僧彌遠，將欲擯遣，逢緣且散，故文云「入波羅夷說中」也。亦可為非公顯，不懼覆藏；或屏犯重，而過跡陳露，義須驅遣，無力遮治，行本既虧，俱是應擯也
【譯文】如果是被滅擯的人，所作罪過既然深重，又加上覆藏的染污之心，所以僧團依法將其除名逐出海岸之外。如果是應當被擯除的人，根本重戒已經毀壞，距離僧團越來越遠，大眾將要擯遣他，卻碰上緣故暫時散會，所以律文說「歸入波羅夷法之說中」。也可以說是他造作罪非公然顯露，不害怕覆藏；或者在背地裡犯了重罪，而罪過行跡已然暴露，義理上必須將他驅逐遣送，但僧團一時無力加以遮止懲治，其修行的根本既然已經毀損，這些都屬於應擯之人。

【446-0008】03_業疏/04b_卷一之四#40
【原文】二擯中初釋滅擯。為非重者，局四夷故；覆染心者，不學悔故；出海岸者，眾不容故。「若下次」釋應擯，有三：初是可擯初篇刑科，名為夷說，已犯重者在此所收，故云入也。「亦下」二種公屏雖殊，俱不可擯，兇頑強狠，僧力不加，但可自知，勿將係數
【譯文】在兩種擯罰中，首先解釋滅擯。所作罪非深重，是因為僅局限於四波羅夷罪；有覆藏染污之心，是因為不肯學悔；逐出海岸，是因為僧眾不再容納。自「若應擯」以下，第二解釋應擯，有三種情形：第一是應受擯除的初篇刑罰律條，稱為波羅夷說，已經犯了重戒的人就被收攝於此處，所以說「入」。自「亦可」以下，公開與私下這兩種情況雖然不同，但都屬於暫時無法施以擯罰者，因其兇頑剛強狠戾，僧團力量一時無法加諸其身，大眾只能心中有數，切勿將其列入足數之限。

【446-0011】03_業疏/04b_卷一之四#43
【原文】有師解言：僧取體如上，既乖法冥然不足，云自言者，結集列相也
【譯文】有法師解釋說：僧眾取體如前面所說，既然違背戒法，本質上暗中就已經不足數了；律文所說的「自言」，是指結集三藏時標列出此一行相而已。

【446-0012】03_業疏/04b_卷一之四#44
【原文】初師解中初立義。「云下」釋妨。律文列相竝云「若言」，恐謂口說，故推結集，為彰別相，故標簡耳
【譯文】在第一師的解釋中，首先確立論點。自「云自言者」以下，解釋疑難。因為律文列舉行相都說「若言（若說）」，唯恐人們以為是口頭說出，所以推向結集者的記錄，是為了彰顯不同的行相，才標舉加以揀擇罷了。

【446-0013】03_業疏/04b_卷一之四#45
【原文】又解人雖體非，相有僧用，各不相知，理開成足。故《十誦》云：犯重罪人、賊住、邊等，若先言有是過，作法不成，反上得也。故律論竝云「同住之法，肉眼三根淨，不用天眼見他犯過」，廣如《鈔》中。是以文中「若言犯罪」與彼不殊，故知自言自述，使人聞也。又《四分》中，於不持戒和尚受具足，前三句者由不知不得，故開；第四句知不得故方閉，廣文如欲法中
【譯文】又有一種解釋：此人雖然本質並非如法，但外相上具備僧人的功用，若彼此互相不知情，按理開許算作足數。所以《十誦律》說：犯重罪之人、賊住、犯邊罪等，如果在作法前先說出有這等過咎，作法便不成；反之若不說，羯磨便得成。所以律與論都說「共住之法，只要肉眼所見的三根（眼見、耳聞、疑心）清淨即可，無須用天眼去觀照他人是否有犯過」，詳細如《事鈔》中所明。因此律文中的「若言犯罪」，與那裡的說法並無不同，由此可知是指自己口頭陳述、讓人聽聞。又如《四分律》中，在不持戒的和尚座下受具足戒，前三句由於不知情所以未得非戒，因而開許得戒；第四句因為知情且不得戒，所以才閉塞不開許，詳細律文如同說欲法中所載。

【446-0014】03_業疏/04b_卷一之四#46
【原文】次師初立理故下引證初引他部十誦文相甚明律論即十誦多論下舉當文會同十誦又下引本律受戒法中文云時有從不持戒和尚受戒後疑問佛佛言汝知和尚不持戒否報云不知佛言得戒復有如上緣佛亦如上問彼報言知佛又問汝知不應從如此人邊受否報言不知佛言得戒復有如上緣佛次問二種彼竝云知佛又問汝知從如此人受不得戒否報云不知佛言得戒復有如上緣佛次問三種竝云知佛言不名受具足。
【譯文】在第二師的解釋中，首先確立義理。自「故下」以下引文作證。首先引述其他部派，《十誦律》的文義相狀極為明確。「律論」即是指《十誦律》與《薩婆多論》。「下舉」即舉出當前律文，會同於《十誦律》之意。自「又下」引述本律受戒法中的記載，文中說：當時有人跟隨不持戒的和尚受戒，事後起疑請問佛陀，佛陀問：「你知道和尚不持戒嗎？」回答說：「不知。」佛說：「得戒。」又有如上同樣的因緣，佛陀也同樣問他，他回答說：「知道。」佛陀又問：「你知道不應當在此等人身邊受戒嗎？」回答說：「不知。」佛說：「得戒。」又有如上因緣，佛陀接連問了這兩種情況，他都回答說：「知道。」佛陀又問：「你知道從這樣的人受不得戒嗎？」回答說：「不知。」佛說：「得戒。」又有如上因緣，佛陀接連問了三種情況，他都回答說：「知道。」佛陀說：「這不名為受具足戒。」

【譯文】第二十種、「在戒場上」。這兩種情況都屬於異界，為何要重複列出兩條呢？因為有人見到外界人數不足，以為戒場處於大界之內，應當可以充任外面的僧數；然而戒場雖然被大界所包圍，但兩者的界線互不相接，中間留有空地，所以屬於異界。

【446-0025】03_業疏/04b_卷一之四#57
【原文】二十四、所為作羯磨人者，以為僧所量，牒名入法，安得成數？又前乞是所為，後和是能為，秉法專制，訶足俱成；除受大戒，餘不合語
【譯文】第二十四種、「被為其作羯磨的人」，因為他正由僧團加以審量，名號已被宣讀載入法事之中，怎能充當僧數？再者，前面乞求畜眾時是被動的「所為」，後面的和合表決則是主動的「能為」；秉持法度、專行制度的權能，主要偏在和尚身上，所以和尚出言訶阻或充當足數都能成立；除了受大戒的和尚之外，其餘各項羯磨中被為其作法之人都不合言語。

【446-0026】03_業疏/04b_卷一之四#58
【原文】所為中初通釋。「又下」簡受戒和尚，雖牒名入法，而與餘不同。前乞謂乞畜眾，後和即通正受。秉法專制，謂主其制度，偏在和尚，故成訶足。除下示局，自餘諸法羯磨牒名，無非所為，不成訶足，故云餘不合語
【譯文】在「所為」一科中，首先通泛解釋。自「又下」以下，簡別受戒時的和尚，雖然也是宣名載入羯磨法中，但與其他人不同。前面乞請是指乞求畜弟子，後面的和合則通於正受具戒。秉法專制，是指主持其度人制度，權限偏重在和尚身上，所以能成訶阻與足數。自「除受大戒」以下，明示其局限；此外其餘各項羯磨中被宣讀姓名者，無一不是所為之人，都不能充當訶阻與足數，所以說「其餘不合言語」。
