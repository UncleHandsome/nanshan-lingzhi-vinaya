## 1. `BY_ID` 主鍵碰撞

**問題**：`id` 只有「書名｜卷次｜行號」，沒帶檔名，多子檔的《資持記》《善見》《濟緣記》會互相覆寫。

**修法**：`id` 改為 **書名｜檔名｜行號**。

**驗證**：

| 項目 | 之前 | 現在 |
|:--|--:|--:|
| 索引行數 | 230,828 | 230,828 |
| `BY_ID` 筆數 | 會少於行數 | **230,828** |
| 唯一性 | ❌ | ✅ **完全相等** |

## 2. `split_sj` 讓記文變空

**問題**：《資持記》只有記文，譯本若沒帶 `【記文】` 前綴，`a_j` 會變空字串。

**修法**：無疏文標籤時**整段歸記文**。

| 輸入 | 結果 |
|:--|:--|
| 無標籤單段（記文） | `('', '整段內容')` ✅ |
| 只有 `【記文】` | `('', '內容')` ✅ |
| 疏＋記 | `('A', 'B')` ✅ |

**實測**：資持記裁決材料「甲/乙皆有內容」✅

## 3. 流水號檔名錯位

**問題**：`01.md` 重產後對應段落位移，舊 `回覆/01_回.txt` 會被誤用。

**修法**：改用**穩定座標**。

```
舊：01.md  02.md  03.md
新：01a_卷一之一_0015.md
    01a_卷一之一_0021.md
    01a_卷一之一_0025.md
```

座標 = `卷檔名_起始段號`，段落增刪不會位移。

## 4. 400 保底寫死三欄格式

**問題**：盲翻、審核、修訂觸發保底時，會被逼吐舊三欄格式。

**修法**：系統提示改中性——

> 請只依據提供之材料完成任務，並嚴格依照使用者指令的格式輸出。

## 5. `build_a2` 未審核也計入 PASS

**修法**：新增 `unaudited` 清單，另寫 `_未審核清單.txt`；統計改為：

```
定稿：FIX x、沿用 y、缺 z、未審核 n、未修訂 m
```

## 6. `_init_cache()` 綁在 `test_apis()`

**問題**：略過連測就沒建表，快取靜默失效、每次重付搜尋費。

**修法**：`_init_cache()` 移到 `main()` 最開頭。
