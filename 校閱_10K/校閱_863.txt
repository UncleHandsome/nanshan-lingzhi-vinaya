# 校閱材料　第863檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【863-0001】02_戒疏/21b_卷四下之三#1
【原文】【註】佛在王舍城。時，沓婆摩羅子為僧知事。六群中得惡房臥具、惡請處，起瞋謗言「有愛、恚、怖、癡」，遂以婬事誣謗。親於眾中，佛問虗實，彼言：「我從生來，乃至夢中不婬，況於覺寤？」比丘以事詰問六群，便言：「沓婆清淨，無如是事。」佛言：「沓婆無著人，不故犯戒，應白四羯磨與憶念法也。」
【譯文】【註文】佛陀住在王舍城時。那時，沓婆摩羅子比丘擔任僧團的知事。六群比丘分到了較差的房舍臥具和較差的受請齋處，便生起瞋恨心譭謗他說「有偏愛、瞋恚、怖畏、愚癡」，隨後更以淫行誣衊譭謗。佛陀親自在大眾中查問虛實，沓婆回答：「我從出生以來，乃至在夢中都不曾行淫，何況是清醒的時候？」比丘們便拿這件事質問六群比丘，六群比丘才說：「沓婆是清淨的，並沒有這樣的事。」佛陀說：「沓婆是斷除執著的阿羅漢，不會故意犯戒，應當作『白四羯磨』為他施行『憶念法』。」

【863-0002】02_戒疏/21b_卷四下之三#2
【原文】【疏】二、明「憶念」者，與法證明，憶記無犯也。無著羅漢，方行此法，自餘下凡，不可依據，不合行也。
【譯文】【疏文】第二科、說明「憶念毗尼」。這是給予羯磨如法證明，憶持記起自己並無犯戒。唯有對無著阿羅漢，才能施行這種羯磨，至於其餘凡夫，則不能以此為依據，不合施行此法。

【863-0003】02_戒疏/21b_卷四下之三#3
【原文】【記】第二。準前亦合分文為二，後五亦然。初略示。「無著」下，簡濫。注中，初緣起，即上「二謗」戒緣，前云慈地嗔謗，即六群一數也。「親」下，制法，又二。前對眾撿勘，後與羯磨。
【譯文】【記文】第二段。依循前面原則，也應將疏文分為兩部分，後面五種羯磨也是如此。起初先簡略開示。從「無著」以下，是簡別浮濫（防止凡夫妄用）。註文中，起初是緣起，也就是前文「二謗」戒的制戒緣由，前面所說慈地比丘瞋恨譭謗，就是六群比丘中的一人。從「親於眾中」以下，是制定作法，又分為兩部分：前面是當著大眾面前檢驗勘問（當事人），後面是給予作羯磨。

【863-0004】02_戒疏/21b_卷四下之三#4
【原文】【律】應與不癡毗尼，當與不癡毗尼。
【譯文】【律文】應當給予不癡毗尼，就應當給予不癡毗尼。

【863-0005】02_戒疏/21b_卷四下之三#5
【原文】【註】佛在王舍城。時，難提比丘得癲狂病，行來出入，不順威儀，多犯眾罪。比丘詰問。便言：「癡時造罪，病差不作。」以事白佛，佛言：「三種狂癡：一者，常憶，說戒常來；二者，不憶，說戒不來；三者，或憶或來或不來。此人應白四與不癡羯磨，證知病時造過，差後不造，應僧清淨，得足數。」故制。
【譯文】【註文】佛陀住在王舍城時。那時，難提比丘得了癲狂病，行動出入都不合威儀，多處違犯眾多罪行。比丘們質問他。他就說：「愚癡狂亂時造了罪，病好後就不再作了。」比丘將此事稟告佛陀，佛陀說：「有三種狂癡：第一種，常能憶念，說戒時常常能來；第二種，完全不能憶念，說戒時不能來；第三種，有時能憶念、有時能來、有時不能來。對於第三種人，僧團應當作『白四羯磨』給予『不癡羯磨』，證明並了知他是病發時造下過失，痊癒後不再造作，應當算入僧團清淨、能合於作法的人數。」因此制定此法。

【863-0006】02_戒疏/21b_卷四下之三#6
【原文】【疏】三、明「不癡」者。以癡造罪，非心所懷，於教不制。癡解不作，未可徵治，不無前犯。故作白四，證癡不犯。與癡狂法，則行白二，由諍是非，稍難除殄，故此狂法，便行白四也。
【譯文】【疏文】第三科、說明「不癡毗尼」。因為在愚癡顛狂時造罪，並非本心所要策謀，所以在戒教上不加以制罪處罰。狂病平息後不再造作，未可依法檢舉治罰，但也並非先前沒有違犯過。因此作「白四羯磨」，證明他先前因癡病而不算犯戒。若要授予「癡狂羯磨」（免責身分），則用「白二羯磨」；但由於平息病癒後的爭論是非，較難徹底除滅，所以這項「不癡羯磨」，就採用「白四羯磨」。

【863-0007】02_戒疏/21b_卷四下之三#7
【原文】【記】第三，為二。初正釋。「癡」，即顛狂心亂。「癡解」，謂狂病已止，得法解竟。「不無前犯」者，示有他疑，不與同法故。「與癡狂」下，簡濫。顛狂羯磨，及與解法，並用「白二」。此有二意：一、為簡二法，二、為彰別意。注中，初緣；「以事白佛」下，是相。文出三狂：初是下品，二即上品，此二不與法；三即中品，故須與法。
【譯文】【記文】第三段，分為兩部分。起初是正面解釋。「癡」，就是顛狂且心神錯亂。「癡解」，是指狂病已經止息，已經依法作羯磨解除顛狂身分。「不無前犯」，是指顯示別人對他尚有懷疑，不肯與他同共行法。「與癡狂」以下，是簡別浮濫。給予顛狂身分的羯磨，以及病癒解除的作法，都使用「白二羯磨」。這裡有兩個含意：第一是為了簡別兩種法規的不同，第二是為了彰顯事情輕重的特別用意。註文中，起初是緣起；「以事白佛」以下，是作法相狀。經文明示了三種癲狂：第一種是下品輕狂，第二種是上品重狂，這兩種都不給予不癡羯磨；第三種就是中品，所以必須給予不癡羯磨。

【863-0009】02_戒疏/21b_卷四下之三#9
【原文】【註】佛在瞻波國。白月十五日僧說戒時，佛在眾坐，默不說戒。初夜已過，阿難請說，佛言：「欲令如來於不淨眾中說戒者，無此理也。」中夜、後夜請，答亦爾。時大目連即以天眼觀犯戒者去佛不遠，內懷腐爛，外現完淨，即手牽出，來白佛言：「眾已清淨，應得說戒。」佛言：「自今已後不應為。取自言治。」因制此戒。
【譯文】【註文】佛陀住在瞻波國。在白月（前半月）十五日僧團說戒的時候，佛陀坐在大眾之中，沉默不說戒。初夜過去了，阿難尊者請佛說戒，佛說：「想讓如來在不潔淨的大眾中說戒，沒有這樣的道理。」中夜、後夜阿難再次啟請，佛陀的回答也是一樣。這時大目犍連尊者立即以天眼觀察，發現犯戒的人距離佛陀不遠，內心敗壞墮落，外表卻裝作完好清淨，目犍連尊者便親手將他拉出門外，來稟白佛陀說：「大眾已經清淨，應當可以說戒了。」佛陀說：「從今以後不應當這麼做。必須取得犯者自己承認才進行治處。」因而制定了這條戒規。

【863-0010】02_戒疏/21b_卷四下之三#10
【原文】【疏】四、「自言治」者。罪是自生，還須自露。對於人眾，面陳其失，故曰「自言」，因言其罪，情無隱伏，則曰「治」也。緣中，由不取自言，恐後清人，濫被驅逐，因制斯藥。亦有三法自言，五法自言，如上現前，可以知也。
【譯文】【疏文】第四科、「自言治毗尼」。罪過既然是自己生起的，還必須由自己親自發露。面對大眾，當面陳述自己的過失，所以稱為「自言」；藉由親口陳說罪過，內情不再隱瞞遮掩，就稱為「治」。制戒緣起中，由於先前沒有取得當事人自己承認，恐防以後清白的人會遭到浮濫驅逐，因而制定了這帖法藥。另外也有「三法自言」與「五法自言」，如同前面「現前毗尼」中所說，可以參照得知。

【863-0011】02_戒疏/21b_卷四下之三#11
【原文】【記】第四，初釋文。「緣」下，釋注。初緣後相，尋文可解。
【譯文】【記文】第四段，起初是解釋文義。「緣中」以下，是解釋註文。先講緣起，後講相狀，順著文字便可理解。

【863-0013】02_戒疏/21b_卷四下之三#13
【原文】【註】佛在舍衛國。時，諸比丘於十八事諍不息，遂至僧中斷，不了。以事白佛，佛言：「應與多覓罪相。法、非法語同一處，應差比丘令行舍羅。行有三種：一者，顯露；二者，覆藏；三者，耳語。若上座標首智人、和尚、闍棃住如法地，應顯露行舍羅；若住非法地者，作下二法行之；若非法語人多，彼應作亂起去故。」此律本云「求覓罪相」，意亦同之。
【譯文】【註文】佛陀住在舍衛國。那時，比丘們對於十八種事端諍論不休，最終告到僧團中決斷，卻無法結案。比丘將此事稟白佛陀，佛陀說：「應當給予作多覓罪相（多人語）羯磨。說法與說非法的人集中在同一處，應當差派比丘前去分發籌籤（舍羅）。發籌有三種方式：第一是公開發籌表決；第二是秘密投票；第三是耳邊私語投票。如果上座長老、首領智者、和尚、阿闍梨站在合法的立場，應當公開發籌表決；如果他們站在非法的立場，則依照後兩種方法行籌；如果堅持非法言論的人佔多數，他們可能會鬧事離去，因此需要審慎。」此處《四分律》戒本稱為「求覓罪相」，意思也是一樣。
