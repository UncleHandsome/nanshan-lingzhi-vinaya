== PROBLEM ==
把重（zhòng，重遮）誤解為重（chóng，重複）。此處是指回顧點出前文盲聾等遮難中病情嚴重的「重者」（一向不得受戒者），而非「重複的部分」。

== SUGGESTION ==
改為：「從『前』字以下，回頭點明遮難嚴重者（一向不得戒者）。」

== ORIG ==
前下，覆點重者。

== CURRENT ==
其次是一向不得之中。「遣書」以下，彼文有「遣印手」等字；現在把這些合起來說，就是指寄信代為受戒。「舉手作相」，就是不用言語而求乞受戒；彼文沒有「舉手」二字，現在加上以輔助說明。「不現前」，指身體不到僧眾面前。「如是等」，彼文說：不問〔不問遮難〕、前人不欲〔沒有受戒的心〕、非法、不和合、眾不成就、白不成就、羯磨不成就；若一一都不成就，就不名受具足。「前」字以下，再點出重複的部分。
