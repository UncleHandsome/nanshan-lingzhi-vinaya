整體看下來，這一批譯文對律、註、疏、記的文義掌握大致無誤，專有名相（波逸提、突吉羅、羯磨、戒體等）處理也一致。需要修的主要集中在 **「十七群」的讀法、「一食」未釋、「立法／制戒」混為一句、“亦大明據”的理解、科判句式生硬**，以及 **「四種」的兩重內涵未區分**。以下逐則列出。

---

## 一、需要修改的地方

### 【1197-0001】#126
1. **「有十七個一群的童子」語意不通。** 律文「十七群童子」是群名（如「六群比丘」之例），指**一群共十七人的童子**（大者十七、小者十一，正好十七人）。
 → 建議：「有一群共十七人的童子（『十七群』童子）」。
2. **「不堪一食」直譯成「不能忍受一食」，讀者無法理解。** 一食＝日中一食、過午不食；童子受不了飢餓，故夜啼索食。
 → 建議：「他們受不了『一食』（日中一食、過午不食）的飢餓，夜裡啼哭。」
3. **「便立下法制戒」句讀混濁。** 此處「立法」與「制戒」是兩事，且正對應下文疏判「戒本分二：初立法、二正本」——先立「年滿二十應受大戒」之法，再制波逸提戒條。
 → 建議：「於是先立法（規定『年滿二十應受大戒』），再制定此戒。」
4. 小處：「比丘即度受大戒」可作「諸比丘便度他們受具足戒」；「夜過」可補「（天亮）之後」。

### 【1197-0003】#128
- 「又不能持戒以及忍受一食」略拗口，且與上文同一名相宜一致加註。
 → 「也無法持戒，也受不了『一食』（日中一食）之法。」
- 「若身苦痛，不能堪忍」是列舉不堪忍之事（記文把「惡言、痛苦」合計為第八事），譯成「如果身體苦痛」偏向條件句。
 → 可作「乃至他人惡言罵詈、身體的苦痛，都不能忍受」。

### 【1197-0005】#130
1. **「是中四種」宜點明所指**：即「知、疑、謂（自以為滿）、不知」四種心態，否則讀者數不出四。
2. **「若中間」的補釋宜用括號標示**：「白已竟、第三羯磨未竟」是依律通例所作的補充，非原文字面。
 → 「若是（白已竟、三羯磨未竟的）中間階段……」
3. **「俱不犯」宜補主體**：「和尚與眾僧都不犯」。
4. **「若數一切十四日說戒以為年數」全句無釋，讀者必不解。** 此是補足年歲的算法（將小月十四日布薩的日數一併計入／作十五日計，累積所缺日數）。建議加括號說明或腳註，並註明所據（行宗記、行事鈔相關算法），不要只留「計算……次數作為年數」。
5. **「滿者開」太含混**：滿什麼、開什麼都不清楚。
 → 「若這樣補算後已滿二十歲，就開許（不犯）。」
6. 「墮罪」首次出現可加註「（即波逸提）」；「吉羅」譯作突吉羅很好，可維持。

### 【1197-0007】#132
- 「其緣由如文句所具列」——**「文」依下一則記文明言「即指注中文」**，宜直接點出。
 → 「其（不堪忍苦的）緣由，如注文中所詳列。」

### 【1197-0008】#133
1. **「戒本，解釋『立法』的部分」句不成文。** 這是科判標語，應還原主從關係。
 → 「（疏文）此下是解釋戒本中『立法』的部分。」
2. **十事的算法要交代清楚**，否則讀者會把蚊、虻、毒蟲算成三事、惡言與痛苦算成兩事，湊不出十。
 → 「『蚊虻、毒蟲』合為第七，『惡言、身苦痛』合為第八」。

### 【1197-0010】#135
- **「初敘能受之誡」的「誡」字有問題**：疏文作「本受者心，為欲感戒」，故記所指當是受者求戒之「誠（心）」，「誡」疑為「誠」之訛（或形近致誤）。譯文逕譯為「本心（求感得戒體）」義理可通，但**應加校註說明所據**，不宜默默改字。
- 「『過』字平呼」的處理正確（平聲取「超過、過越」義，與去聲「過失」區別），可保留。

### 【1197-0011】#136 ★理解偏差
- 「亦大明據」譯成「也大體有明白的依據」，把「據」當成「有」的賓語，語意走偏；且與下則記文「**略示而已**」不相呼應。原意應是：**（注文）也只是大略明示判犯不犯的準據**，須讀者細讀細分方能明了。
 → 建議：「在辨別犯相這部分，（注文）也只是大略明示（犯不犯的）依據，仔細閱讀、細加分析便可明白。」

### 【1197-0012】#137
1. 「釋注，犯中」同樣是科判語。
 → 「這是解釋注文中『辨犯相』的部分。」
2. 「只是簡略指示而已，現在為它分科」宜補主語：**（疏文）只是略示，（記）現在為注文分科**。
3. **「『疑』與『不知』合起來共有『四種』」易被誤讀成「疑＋不知＝四種」。**
 → 「答『滿』與答『不滿』都是就『知』而說，再加上『疑』與『不知』，共成『四種』。」
4. **「四種」的兩重內涵宜加註區分**：記文此處的四種是就**答**說（滿、不滿、疑、不知）；#130 注文的四種是就**心**說（知、疑、謂、不知）。兩處都只寫「四種」，讀者會錯亂，建議加一句腳註。
5. 「一向犯輕」的「一向」在白話易誤解為「一直」。
 → 「其餘僧眾一律只犯輕罪（突吉羅）」。

## 二、可保留、僅微調者

- **#127**：「年滿二十歲，才應該受大戒」——加「才」符合立法本意，可。
- **#129**：文義無誤。可微調為「那位（授戒的）比丘應受訶責，因愚癡而犯波逸提」，「不得戒（不得戒體）」的括註很好。
- **#131**：正確。建議把三句所對應的戒本原文標出：一、「人」（若比丘）；二、「知」（知年不滿二十）；三、「年不滿」以下。另「正本」可加註「（正式戒條）」。
- **#134**：文義通順。唯「師有授法之功」是讓步語，作「師父**雖**有傳授戒法之功」更能帶出下句「然」的轉折；「何有過者」譯「還有什麼能超過這樣的愚癡」與記文平聲之訓一致，很好。

## 三、通用建議

1. **名相首見加註**：和尚（親教師／戒和尚）、一食（日中一食、過午不食）、白（白告）、羯磨（白四羯磨）、墮（波逸提）、吉羅（突吉羅）、十四日說戒（小月布薩）。
2. **科判語統一譯法**：記文「戒本，釋立法中」「釋注，犯中」「正本中，初文」這類標題，一律還原為「（疏文）此下是解釋……的部分／第幾段」，避免出現「戒本，解釋立法的部分」這種無主語斷句。
3. **補釋一律用括號或腳註**（如「白已竟、第三羯磨未竟」「不得戒體」「超過義」），讓讀者分辨原文與增補；目前多數已用括號，但 #130「中間」一處未標示。
4. **涉及文本疑義處（如「誡」字）加校註**，不要只在譯文中悄悄改讀。
5. 最需優先處理的三處：**#126「十七群／一食／立法制戒」、#136「亦大明據」、#130＋#137「四種」與「十四日說戒」**。
