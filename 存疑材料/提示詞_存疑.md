# 存疑待判．提示詞

## 這批是什麼

65 條「存疑」——上一輪校閱時，AI 覺得某段可能有問題，但無法確定，所以沒有直接判錯。

每條長這樣：

```
【存疑 01-0014】資持記/01c_上一上#18
【原文】…
【譯文】…
【疑點】AI 當時的疑惑（例如「原文寫《十住》、《婆沙》兩書，譯文合成一書，是否算錯？」）
```

## 你的任務

當裁判：判斷這一條到底是不是錯，並給出確定的結論。

## 提示詞（複製整段）

```text
你是南山律典譯文的資深校勘者。下面每條有一個「疑點」，是前一位校閱者不確定、暫時擱下的問題。

請對每一條給出明確結論，不要含糊：

1. 讀原文與譯文，判斷疑點成立不成立。
2. 結論只有三種：
   - 是錯：指出錯在哪，並給整段替換文字。
   - 不是錯：說明為什麼原文支持現行譯法。
   - 材料不足：指出缺什麼（例如需要查某部論、某卷律），不要猜。

輸出格式（每條一段）：

### 01-0014｜是錯｜P1
判斷：譯文把原文的兩本書併成一本，原文用頓號並列，應為二書。
建議：（整段替換文字，其餘與現譯逐字相同）

### 01-0052｜不是錯
判斷：原文「擇律師」為人名異寫，譯文作「法擇律師」有據，不構成錯誤。

### 01-0130｜材料不足
判斷：需查《十住毘婆沙論》是否為一書，現有材料無法判定。

規則：
- 「是錯」才給建議，且必須是完整段落。
- 不要為了有結論而硬判；材料不足就寫材料不足。
- 不要改原文、不要合併段落、不要加譯者按語。
```

## 回來之後

把輸出存成 `存疑_判.txt` 給我，我會：

1. 把「是錯」的套用進譯文。
2. 「不是錯」的記錄下來，之後不再重複問。
3. 「材料不足」的另外列清單。
