# 校閱材料　第619檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【619-0001】02_戒疏/11b_卷三上之二#131
【原文】【記】別解八門，初門，初師，通列中。「三義」，上二可見，第三謂捨懺已，僧作法還，得受用故。
【譯文】【記文】個別解說的八門中，第一門，第一位律師的觀點，在通盤列舉之中。「三種要件」，上面兩種顯而易見，第三種是指在沒收懺悔完畢之後，僧伽通過作法將其退還，比丘仍然被允許合法使用。

【619-0002】02_戒疏/11b_卷三上之二#132
【原文】【疏】為舉其相。如坐脫脚，屏、露敷，高脚牀，此之四戒，闕初緣，非己物也。
【譯文】【疏文】現在列舉出這些具體戒相。例如坐臥脫腳床戒、在隱蔽處敷設臥具戒、在露天處敷設臥具戒、使用過高床腳的床鋪戒，這四條戒律，都缺少了第一個條件，因為那些根本不是屬於自己私有的財物。

【619-0003】02_戒疏/11b_卷三上之二#133
【原文】【記】初七戒中，前四雙闕，可解。
【譯文】【記文】在前七條戒中，前面四條同時缺少了第一與第三個要件，此理易明。

【619-0004】02_戒疏/11b_卷三上之二#134
【原文】【疏】又闕第三，捨還非用。又如輒用施、過三鉢、與外道食，此三亦闕初緣。莫不已入他手，即是他物，共他食故。
【譯文】【疏文】而且同時也缺少了第三個條件，因為就算棄捨繳庫，作法返還後也無法再度合法受用。又例如擅自挪用施主指名僧眾的供養物戒、接受超過三缽的食物戒、將食物施捨給外道戒，這三條戒同樣缺少了第一個條件。無非是因為這些物品早已落入他人手中，變成了別人的所有物，或者是與他人一同分享飲食的緣故。

【619-0005】02_戒疏/11b_卷三上之二#135
【原文】【疏】問：「取過三鉢，未食生罪，何不制捨？」
【譯文】【疏文】提問：「如果接受了超過三個缽盂的食物，在尚未食用之前就已經構成了罪名，為何佛陀不規定將其沒收棄捨呢？」

【619-0006】02_戒疏/11b_卷三上之二#136
【原文】【疏】答：「財雖現在，佛制共分，不專己故。」
【譯文】【疏文】回答：「食物雖然此刻擺在眼前，但佛陀早已規定必須與全體僧眾共同分享分攤，並非比丘自己一人專屬擁有的財物。」

【619-0007】02_戒疏/11b_卷三上之二#137
【原文】【記】次三戒，問答中，初問。「未食生罪」，顯是已食故。
【譯文】【記文】在接下來的三條戒律的問答中，首先是提問。「尚未食用即滋生罪過」，是為了顯明其餘因食諸戒顯然都是吃完之後才結罪的緣故。

【619-0008】02_戒疏/11b_卷三上之二#138
【原文】【疏】「若爾，販愽得食，亦是味通，何故制捨？」
【譯文】【疏文】「如果是這樣的話，那麼透過經商販賣換取所得的食物，同樣也是供口腹之用的通用之物，為何佛陀卻規定必須沒收棄捨呢？」

【619-0009】02_戒疏/11b_卷三上之二#139
【原文】【疏】答：「屬己物故，不合同食，由有罪故。既是偏局，故得入捨。」
【譯文】【疏文】回答：「因為那本來就屬於犯戒者個人的私產，本就不准許大家共同分食，因為它自始至終帶有非法的罪咎。正因為它具有專屬私人的排他性質，所以才必須納入捨墮的範圍。」

【619-0010】02_戒疏/11b_卷三上之二#140
【原文】【記】次難中。「販愽食」即「三十」中販賣得食，亦制捨故。答中，上三句明不開食，下二句明須入捨。
【譯文】【記文】在接下來的詰難中。「販賣所得的食物」，指三十捨墮戒中因經商做買賣而獲取的飲食，律法同樣規定要沒收捨棄。在回答之中，上面三句說明不開許大家分食，下面兩句說明它必須列入捨墮。

【619-0011】02_戒疏/11b_卷三上之二#141
【原文】【疏】又就食中，有十二戒，如尼歎食、施一食、展轉食、別眾食、足食、勸足食、非時食、殘宿、不受、索食、索藥、飲酒，未食無罪，食已方生，體不現故，闕第二緣。
【譯文】【疏文】再者就與飲食相關的戒條中，共有十二條，例如接受比丘尼讚歎而得食戒、接受外道施主一宿食戒、展轉食戒、別眾食戒、吃飽之後再次受食戒、勸誘已飽足者再次受食戒、非時食戒、食用殘宿宿儲食物戒、食用未經受授之食戒、向非親屬白衣索求美食戒、無病而向人索求醫藥戒、飲用酒精飲料戒，在尚未吃進去之前都沒有罪，一旦吃下去之後罪過才立刻成立，但此時食物的實體已經不復存在，所以缺少了第二個條件（財物猶在手中生過）。

【619-0012】02_戒疏/11b_卷三上之二#142
【原文】【記】次十二戒中。「索食」即索美食。「索藥」即四月過請。
【譯文】【記文】在接下來的十二條戒律之中。「索取食物」是指無病貪求美食。「索取醫藥」是指超出施主所請許的四個月期限去索求。

【619-0013】02_戒疏/11b_卷三上之二#143
【原文】【疏】財中有八，闕第三緣。如覆過三、百衣、兜羅、牙筒、尼壇、覆瘡、雨衣等，捨竟過在故。
【譯文】【疏文】在涉及財物的戒條之中有八條，缺少了第三個條件（捨後不能返還受用）。例如覆蓋屋頂草葉超過三層戒、蓄純白衣戒、使用兜羅綿絮製成寢具戒、使用象牙骨骼製成針筒戒、製作過量坐具戒、製作過量覆瘡衣戒、製作過量雨浴衣戒，以及「等」字所攝取的佛衣戒，即使向僧團沒收棄捨完畢，其過失與制度上的不合規格依舊存在，所以無法返還合法使用。

【619-0014】02_戒疏/11b_卷三上之二#144
【原文】【記】次八戒中。「覆過三」，即覆屋戒。「雨衣等」者，等取佛衣。
【譯文】【記文】在接下來的八條戒律中。「覆蓋超過三層」，是指修造房舍時的覆屋戒。「雨浴衣等」，這個「等」字涵蓋了製作與佛衣同等大小的衣物。

【619-0015】02_戒疏/11b_卷三上之二#145
【原文】【疏】又如強敷、與衣、作衣、遺落、藏他物等，既非三緣，亦須分別。
【譯文】【疏文】又例如強佔他人物品來鋪設敷具戒、強搶贈與他人的僧衣戒、強使他人為己縫製僧衣戒、捉持撿拾掉落的貴重寶物戒、故意藏匿他人衣物戒等，這些既然都不符合這三項要件，自然也需要予以個別辨別簡析。

【619-0016】02_戒疏/11b_卷三上之二#146
【原文】【記】後五戒中。第四「遺落」即捉寶。此五全是他物，無有停留還用之義，故「非三緣」所攝也。
【譯文】【記文】在最後五條戒之中。第四條「遺落」指的就是捉持金銀寶物戒。這五條戒涉及的全都是屬於他人的物品，根本不存在在自己手中停留、日後還能合法返還使用的道理，所以「不屬於三要件」所攝納的範圍。

【619-0017】02_戒疏/11b_卷三上之二#147
【原文】【疏】問：「真淨輒用，局主闕初緣者，三十戒中，並不說淨邪？」
【譯文】【疏文】提問：「若作真實淨施而擅自挪用，因財物專屬他人而缺少了第一要件（屬己之財），那麼在三十捨墮戒之中，難道全都未曾經過『說淨法』（展轉託付他人作淨）嗎？」

【619-0018】02_戒疏/11b_卷三上之二#148
【原文】【疏】答：「然。何以知之？如浣打、二離、雨衣四戒，是受持故；長、月、鉢、藥，由不說故；五敷、擔、擗、乞縷等八，未成無量，故不合說，已成造作故成過。自餘領受過生，即不應淨。」
【譯文】【疏文】回答：「是的，完全沒有。何以得知呢？例如使非親尼浣打羊毛戒、兩條離衣宿戒、製作過度雨浴衣戒這四條戒，是因為已經正式受持作法歸屬自身專用的緣故；而長衣、長月望衣、多餘缽具、蓄留過期醫藥這四條戒，正是因為沒有進行說淨才犯戒；五種臥具（蠶絲被、純黑羊毛褥、雜色毛褥、未滿六年重做褥、不拼縫舊布坐具），以及擔運羊毛戒、委託紡毛戒、向非親屬索求縫線等八條戒，在尚未製成衣物形量時根本不合進行說淨，而一旦縫製完成其規格就已造作成了過咎。至於其餘各戒，只要一經領受過失便隨之滋生，本就絕不能施以說淨法。」
