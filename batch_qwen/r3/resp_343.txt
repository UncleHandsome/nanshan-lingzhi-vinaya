整體看下來，這批譯文**文氣通順、四種三寶的術語掌握大致到位**，主要毛病集中在兩類：（一）幾個關鍵詞誤讀；（二）增譯（自行補入原文沒有的形容、判斷）偏多，稀釋了疏記原本簡潔的判釋語氣。以下按輕重分列。

---

## 一、需要訂正的實質問題

### 1.【343-0005】「住持佛、法」誤作動詞解 ⚠️ 最明顯的錯誤
- 原文：**住持佛、法，由僧弘顯**
- 原譯：「**住持世間的**佛寶與法寶，全賴僧寶加以弘揚顯發」
- 問題：「住持」是四種三寶之一的**住持三寶**（佛像、經卷、剃染僧），不是「住持世間」的動作。
- 建議：「住持三寶中的佛寶（佛像）與法寶（經卷），要靠僧寶來弘揚顯發，所以毀僧就連帶毀了佛、法，因此說『通壞』。」

### 2.【343-0001】「如後自委」句型譯錯
- 原文：**「三相」如後自委**
- 原譯：「『三相』的義理**就如同**下文自會詳細闡明**的那樣**」
- 問題：「如後自委」＝「後文自會詳明」，是**指向下文的交代語**，不是比較句。譯成「如同……那樣」語意懸空。
- 建議：「『三相』的義理，後文自會詳細說明。」

### 3.【343-0008／0009】「本緣」譯得含糊
- 原文：**皆望本緣**／記：**「本緣」即佛**
- 原譯：「其罪福全都歸屬於**根本的主體因緣**」
- 問題：「本緣」是「根本所緣」，記文已明判為「佛」。譯成「主體因緣」既抽象又偏義。
- 建議：疏文「都是望著根本所緣（即佛）而結罪福」；記文「『本緣』就是指佛」。

### 4.【343-0005】「破法輪」宜點明是「破僧」
- 原文：**如破法輪，正望真諦無證入故**
- 原譯：「例如破壞轉正法輪」
- 問題：此處與「殺羅漢」並列，講的是**五逆中的破法輪僧（破和合僧）**；破僧期間無人證聖，故「望真諦無證入」。只譯「破壞轉正法輪」會被讀成一般的毀法。
- 建議：「例如破法輪僧（破和合僧），正是就真諦而論——破僧使人無法證入聖道的緣故。」

### 5.【343-0009】「三乘弟子」縮小為「三乘聖人」
- 原文：**「賢聖」即三乘弟子**
- 原譯：「三乘**聖人**弟子」
- 問題：「賢聖」兼含**賢位（內凡）與聖位**，加「聖人」反而排除了賢位，也與原文用詞不符。
- 建議：「『賢聖』指三乘弟子（賢位與聖位）。」

### 6.【343-0013】「學人」範圍有漏
- 原譯：「**初果至三果**的學人是枝末，四果無學阿羅漢是根本」
- 問題：有學含**初果至四果向**，四果向仍是有學。
- 建議：「有學（初果乃至四果向）為末，無學（四果阿羅漢）為本。」

### 7.【343-0013】「體絕名言」不宜譯成「斷絕」
- 原譯：「本體**徹底斷絕**一切名相言說」
- 問題：「絕」是**超越、離**，不是斷滅；「斷絕名言」易生誤解。
- 建議：「所顯的真理，體性超越名言，是本。」（「無上」二字亦為增譯，可刪）

### 8.【343-0009】「僧以具戒為本」的所指
- 原譯：「僧寶以**圓滿具足出家大戒**為根本」
- 問題：與「佛像為本、經卷為本」並列，此處「具戒」宜指**受具足戒的比丘（人）**，末是「常住僧物、受用資具」。譯成戒法本身，本末的「人／物」對舉就散了。
- 建議：「僧寶以受具足戒的比丘為根本，以常住受用的資具為枝末。」（「產業」二字可刪）

### 9.【343-0008】「殿宇廊廟」不宜拆成宮殿、廟堂
- 原譯：「**宮殿**、寺宇、廊廡、**廟堂**」
- 問題：语境是寺院建築（殿堂廊廡），「宮殿」「廟堂」帶入世俗宮廟義。
- 建議：「所以寺院的殿堂廊廡，以及（塑畫的）神鬼禽獸……」

### 10.【343-0004】「化佛無心」增譯失準
- 原譯：「因為應化佛身**沒有凡夫血肉的**心識」
- 問題：「凡夫血肉的」為原文所無，且與「化佛」義相混。原意只是：化現之身本無心識、屬非情，故損之無惱。
- 建議：「因為化佛本無心識，屬無情之物，損傷它並不造成惱害。」
- 同段「法身所依託的**器質**」→ 建議作「法身所依託的**色身**」，正好呼應下文《多論》「色身是法身器」。

### 11.【343-0005】「隨前敬慢」不限於內心
- 原譯：「隨著**瞻仰者內心**的敬奉或怠慢輕視」
- 問題：敬慢通身口意（禮拜、毀壞皆攝），限縮為「內心」與上文「若作若損」不相應。
- 建議：「隨對佛像的恭敬或輕慢，而招致罪福。」
- 同段「體是**無知無記**」：無記是「非善非惡」的專名，加「無知」易誤導，建議「體性屬無記（非善非惡）」。

## 二、增譯／語氣偏離（可修但不算錯）

| 段號 | 原譯 | 建議 |
|---|---|---|
| 0004 | 「其餘三種都是**從外相而衍生顯現**的」 | 「餘三從相」＝就事相而安立，宜作「其餘三種都是就事相而立」 |
| 0004 | 「將整個三寶的**尊嚴**全都毀壞**殆盡**」 | 「三寶就一併被毀壞了」（尊嚴、殆盡皆增字） |
| 0004 | 「形服代表了超脫世俗的表徵，作為出世聖道的標誌旗幟」 | 語意重複，可簡為「其形貌法服超越世俗，是聖道的標幟」 |
| 0004 | 「結成**最重**的逆罪」 | 「結成五逆重罪」 |
| 0004 | 「**無漏**法身」 | 原文無「無漏」，可省 |
| 0005 | 「這是指化相三寶是依據理體為根本，化現的應身，所以稱為『化佛』」 | 句法不順，建議：「這是說明化相三寶：以理體為根本，化相即是應身，所以稱作『化佛』。」 |
| 0008 | 「歷來各家論師都**隱蔽不談**」 | 「都略而未說」較中性 |
| 0008 | 「這本來就是心中**常應思維**之理」 | 「常懷」是常存於心／日常所悉，非規範性的「應」；建議「這原是日常常存於心的事，怎能不認識？」（此句古來無明解，宜保守） |
| 0008 | 「敬奉它們又何以能產生功德福分？」 | 語氣宜明確為設問：「（既然不是寶）為什麼也能生福呢？」下句才是解答 |
| 0010 | 「**有人**問」 | 元照自設問答，作「設問」即可 |
| 0012 | 滅理「所開顯的**究竟實體**」 | 「實體」易生實有化誤解，宜「所顯的真理」 |
| 0012 | 括號「（以佛、僧身為本，所受用物為末）」 | 屬合理推斷，但原文只說「亦取受用以分本末」，建議保留但加註明為推解 |
| 0013 | 「五分法身的**事相修證顯發**」 | 建議直譯「五分法身屬事相之身，應判為末」 |
| 0013 | 「共同證悟的**真空**真理」 | 「真空」為增詞，作「同證的真理，通稱『理和』」 |
| 0014 | 「**昏沉**躁動」 | 「昏沉」是別指煩惱名相，與「寂照」對舉宜作「昏昧擾動」 |

## 三、標點與體例

1. **引號內句號位置**：
 - 「所以稱為「化佛 **。」**」→ 「化佛」**。**
 - 「所以說「通通毀壞 **。」**」→ 建議「所以說『通壞』**。**」（並保留疏文原詞「通壞」，「通通毀壞」略口語）
2. **跨段引號**：#0011 譯文開「未閉，#0012、#0013 未再開口引號，#0014 收尾閉」——全組合起來雖平衡，但與原文每段都開口引號的體例不一致，建議統一（要么每段照原文開口引號，要么全部只在首尾處理）。
3. **科判語統一**：「在總體說明的科判中／在問答的科判中／在回答的科判中」體例一致，很好；#0003、#0016「這是第二／三個……的科判」也一致，可保留。

## 四、可建一張術語對譯表（避免前後漂移）

- 理寶／理體三寶、化相三寶、住持三寶、一體三寶（目前一致，維持）
- 「本／末」統一譯「根本／枝末」（目前一致）
- 「望」＝「就……而論／望著……而結罪福」（0004「據相」、0005「望理寶」、0008「望本緣」宜同一處理）
- 「無記」「有學／無學」「理和」「五分法身」「苦依」等專名，首次出現時夾註一次即可，勿逐處加形容詞。

---

**結論**：真正要改的是第 1～8 條（尤其「住持佛法」「如後自委」「本緣」「破法輪」「三乘弟子」「學人」），其餘多屬增譯與行文修飾。把不必要的形容詞（無漏、無上、真空、尊嚴、殆盡、究竟實體、凡夫血肉）拿掉，譯文會更貼近道宣疏、元照記那種「判得乾淨、說得簡要」的筆調。
