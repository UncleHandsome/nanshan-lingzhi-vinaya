# 校閱材料　第1906檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1906-0001】03_業疏/22b_卷四之五#67
【原文】上定三位，餘希不列。若財產繁多，徧歷餘處，不可通集，隨處各捨，然後一時加懺法已，次第還得
【譯文】上面判定了三種品位，其餘稀少的情況不再列舉。如果財物眾多，分散遍布在各處，無法全部集中在一起，便隨所在各處分別捨棄，然後在同一時間施行懺悔法完畢後，再依序取回。

【1906-0002】03_業疏/22b_卷四之五#68
【原文】結示中，初示略。「若」下，次明難集各捨合懺，隨處各還
【譯文】在結語指示中，首先說明省略之意。自「若」字以下，接著說明難以集中的物品應當在各處分別捨棄、合併進行懺悔，再隨所在處各自發還。

【1906-0003】03_業疏/22b_卷四之五#69
【原文】二、明對忘成不者：若捨心淨，還衣未說，見本忘物，尋即相染，須通更捨，作犯長法。若說竟見，及未還見，皆依後捨，不染前淨，以無畜故。若本畜心，捨而不離，雖無忘染，有心貯故，捨不成捨，還依本長
【譯文】第二、說明對待遺忘之物捨法成不成立：如果捨心清淨，發還衣服後尚未作說淨，見到原本遺忘的物品，隨即互相染著，必須連同前面的衣服重新捨棄，依觸犯蓄長法辦理。如果說淨完畢後才見到，以及在尚未歸還前就見到，都只依照後見之物去捨棄，不會染著先前清淨之物，因為沒有蓄積之心的緣故。如果原本就存有蓄積之心，形式上捨棄而內心並未捨離，雖然沒有遺忘之物的染著，但因心存貯藏之念，捨棄便不能成立為捨，依然依原本的蓄長之罪論處。

【1906-0004】03_業疏/22b_卷四之五#70
【原文】二對忘中，初科有三：初明成染，通前重捨；「若說」下，次明不成染，但捨後見；「若本」下，三明畜心不斷，雖捨不成
【譯文】在第二「對待遺忘之物」中，第一科包含三點：首先說明構成染著，須連同先前之物重新捨棄；自「若說」以下，接著說明不構成染著，只需捨棄後見之物；自「若本」以下，第三說明蓄積之心未斷，即使作了捨法也不能成立。

【1906-0005】03_業疏/22b_卷四之五#71
【原文】有人云：我後見忘，作心施人，何得染者？答：卿心麤也。見便生我，即是染竟；後方施人，又是佛制，具兼兩犯，何得無心
【譯文】有人說：我後來見到遺忘之物，起心布施給別人，怎麼會構成染著呢？回答：你的心太粗疏了。一見到物品便生起執著為我所有的念頭，這就已經染著完畢了；隨後才要施捨給人，這又違背了佛制，同時具備兩種犯戒，哪能說沒有蓄積之心呢？

【1906-0006】03_業疏/22b_卷四之五#72
【原文】次科初敘異說，答下正斥。言心麤者，不自審也。心念微細，前執後捨，自不覺故，謂言不染。佛令捨已方遣與人，一是相染，二違佛制，犯提及吉，故云兩犯
【譯文】下一科中，首先敘述異說，自「答」以下進行正面駁斥。說「心粗」是指不能自我審察。心念極其微細，前面先執著而後才施捨，自己沒有察覺的緣故，才說沒有染著。佛陀命令必須先捨棄罪物之後才准遣送給人，一是彼此互相染著，二是違背佛陀制戒，觸犯了波逸提（提）與突吉羅（吉），所以說是兩種過犯。

【1906-0007】03_業疏/22b_卷四之五#73
【原文】問：捨財實有，謂無成捨；界實別眾，謂無應同？答：忘財不集，非情不礙；別是情礙，同故成僧。故有謂無，各有其致
【譯文】問：捨財時實有長物，誤以為沒有而能成就捨法；界內作法時實有別眾，誤以為沒有是否也應同理成立？回答：遺忘之財物未集合，無情之物不構成障礙；別眾屬於有情眾生的障礙，僧眾齊同才能成就僧事。所以同樣是「實有而誤以為無」，各自有其道理所在。

【1906-0008】03_業疏/22b_卷四之五#74
【原文】三中初問：律中作法，界中有人無想，作法不成，引以相並。答中，情、非情別，有礙、無礙不同，可見
【譯文】在第三段中，首先發問：律中作羯磨法時，結界內若有人而主事者誤以為無人，作法便不能成就，以此相提並論。回答中，有情與非情有差別，構成障礙與不構成障礙不同，義理顯而易見。

【1906-0009】03_業疏/22b_卷四之五#75
【原文】文中「僧捨有三：財是罪緣」者，非法貪貯，輕慢戒禁，故是緣也。言「捨心」者，貪慢為本，最須先捨，故捨猶畜，不名淨心。言「捨罪」者，若不洗懺，苦業長劫，故須瞻曉，即是稱量之謂也
【譯文】文中說「對僧捨懺有三種：財物是罪之緣」，是指非法貪圖貯藏，輕慢戒律禁令，所以是罪緣。所謂「捨心」，貪著與輕慢是造罪的根本，最需要先行捨棄，所以如果形式上捨了財而心裡仍想蓄積，不能稱作清淨之心。所謂「捨罪」，如果不洗除懺悔，招感受苦的惡業歷經長劫，所以必須審視明曉，這也就是稱量罪過的意思。

【1906-0010】03_業疏/22b_卷四之五#76
【原文】次牒釋中次第三節：由財起心，故財為罪緣；由心成罪，故心為罪因；由罪感報，故罪為生死業。故下通結，囑令明曉。稱量即十緣之一，所謂稱量所犯也
【譯文】在下一段引文解釋中依序分為三節：由於財物而生起心念，所以財物是造罪之緣；由於心念而構成罪過，所以心念是造罪之因；由於罪過而招感果報，所以罪過是生死之業。因此往下通盤總結，叮囑令其審慎明了。稱量就是十種懺罪因緣之一，也就是所謂「稱量所犯的罪名」。

【1906-0011】03_業疏/22b_卷四之五#77
【原文】就捨儀中，列三物者：以長能染，須宿淨心，故別還也；離衣雖捨，即座須還，本非貪積，由慢惰故，若又經宿，令他得罪，不得同長一處束也；取尼、迴僧之物，單是事違，若捨量時，故又別襆相連。總說各段別捨，餘如文相，至時更顯，可引《鈔》中相足消釋
【譯文】在捨財儀軌中，列出三種物品：因為長物能生染著，必須過宿以清淨其心，所以要另外歸還；離衣宿雖然也要捨棄，但當座就必須歸還，因為原本並非貪求積蓄，而是由於怠慢懶惰所致，如果又經過一夜，反而會令別人得罪，因此不能與長衣捆束在一處；索取比丘尼衣、回轉僧物等物品，純粹是事相上的違犯，在捨棄與稱量時，所以又要各自用包袱包裹連綴。總體而言各段分別捨棄，其餘的如同律文法相，到具體行事時會更加顯明，可以引用《事鈔》中的內容互相補充消融解釋。

【1906-0012】03_業疏/22b_卷四之五#78

【1906-0018】03_業疏/22b_卷四之五#84
【原文】問：上解須宿為欲淨心，今文當日，何不同者？答：若心不淨，多日亦犯，如論第二句也；今此淨心，故開受故，如《四分》中遠行等緣，當日開取，同斯意也。或可本財自是己物，未曾入己，後得非染；及異財者，非望送故
【譯文】問：上面解釋必須經過一夜是為了清淨其心，現在律文卻說當天即可，為什麼不同呢？回答：如果內心不清淨，即使經過多日也照樣犯戒，如同論典中的第二句；現在這是因為心已清淨，所以開許接受，如同《四分律》中因為遠行等因緣，開許當天取回，也是同樣的用意。或者可以說，原本的財物本身雖是自己的物品，但尚未曾真正落入自己手中，事後得到便不構成染著；以及若換成別的財物，並不是當初指望送來的緣故。
