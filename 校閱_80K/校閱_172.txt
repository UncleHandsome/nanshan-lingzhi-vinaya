# 校閱材料　第172檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】壞生種子戒具五緣犯一是五生種二作生種想三自壞四不作知淨語五傷物便犯此律生種有五一根二枝三節四覆羅五子子種淨法亦有五一火二刀三瘡四鳥破五不中種僧祇云根莖種者以刀中破淨節種者以刀破或以摘去芽目淨心種者如蘿勤蓼等是應揉𫝽淨子種者如穀麥等是脫皮淨若總用火淨便通上五種五果中裹核種者如棗杏等是應掐破淨得去核食火淨者得合核食膚果種者如蓽茇棃柰等是皆須火淨若一切熟果自然落下觸木石傷如蚊脚者成淨應去子食殻果種者椰子胡桃石榴等是皆須火淨𥢶果種者如香葇蘇荏等是無子應揉𫝽淨有子應火淨角果種子如大小豆是子未成應揉𫝽淨子成應火淨摩摩帝有穀倉未淨畏年少尼不知法應使人火淨乃至後時恒言舂去不犯若以五生種擲著池中井水中大小便中糞掃中越毗尼罪死者提草木中行欲使死者越毗尼罪傷如蚊子脚提石上生衣餅上生毛皆須淨人知不爾犯罪若日乾得剝却水中浮萍不得手撥有牛馬行處得取水用若無行處捉土塊若石仰擲言至梵天上去若下時打水開處即得用水中翻覆浮萍越毗尼罪若著岸上提若入水洗時水草著身者以水復澆令入水若斷朝菌越毗尼罪見論云若須華果得自攀枝下使淨人取亦得抱淨人取五分云凡諸草木若有所須語淨人言汝知是若不解復語言汝看是若不解復語言我須是此律不言看是吉壞地亦然草生覆道徧繫開路枝折葉落者無犯以不故為也。
【譯文】破壞生長種子戒具備五個條件即構成犯罪：一是屬於五種具有生機的種子；二是認定為生長種子；三是親自破壞；四是未作合律的知淨語；五是傷損物品便犯本戒。本律說：生長種子有五種：一根、二枝、三節、四覆羅（如蔓藤倒插接枝）、五子。生種的知淨作法也有五種：一用火、二用刀、三以爪刻創傷、四鳥啄破、五天生不能發芽（不中種）。《僧祇律》說：根莖類的種子，用刀從中間切破作淨；節種，用刀切破或摘除芽眼作淨；心種如蘿蔔、芹菜、蓼草等，應當揉搓搓損作淨；子種如穀物、麥子等，應脫去外皮作淨；若統一使用火烤作淨，便可通盤適用於上述五種種子。五種果實中，包核類的果實如紅棗、杏子等，應當用指甲掐破作淨，然後去掉果核食用；經火烤作淨者，可以連核一同食用；肉質果皮類的果實如嗶茇、梨子、蘋果等，都必須用火作淨。若一切成熟果實自然脫落，碰撞樹木石頭造成的傷痕哪怕只有蚊子腳般細小，也算作淨成立，應當除去種子食用；硬殼類的果實如椰子、核桃、石榴等，都必須用火作淨；細軟多囊果實如香薷、紫蘇、荏草等，若無種子應當揉搓作淨，若有種子應當用火作淨；豆莢類果實如大豆小豆等，若是種子尚未成熟，應揉搓作淨，種子已成熟者應當用火作淨。掌管糧倉的執事者處有穀倉尚未作淨，若擔心年輕比丘尼不懂戒法，應派人先行用火作淨，乃至日後經常囑咐他人『拿去舂米』，這樣便不犯戒。如果把五種生長種子扔進池塘中、水井中、大小便溺中、垃圾堆中，得越毗尼罪；使種子腐爛喪失生機者，犯波逸提罪。在草木叢中行走，若存心想踩死草木者，得越毗尼罪；使草木傷損如蚊子腳般細微者，犯波逸提罪。石頭上長青苔、糕餅上長菌毛，都必須讓淨人知曉處理，否則犯戒；若是經烈日曬乾，准許剝除丟棄。水中的浮萍，不得用手隨意撥動；若是有牛馬走過踩開的地方，准許取水使用；若是沒有走過之處，可抓取土塊或石頭向上拋擲並口稱『飛到梵天上去吧』，落下時砸開水面浮萍之處，隨即可以用該處的水。在水中翻動撥弄浮萍，得越毗尼罪；若是將浮萍撈起放在岸上，犯波逸提罪。若入水洗浴時，水草沾附在身上，應當用水再沖洗讓它回到水中；若是採摘折斷朝生暮死的菌菇，得越毗尼罪。《善見論》說：若需要花朵果實，可以自己把樹枝拉低，讓淨人採摘，也可以抱起淨人去採摘。《五分律》說：凡是對草木有所需求時，應告訴淨人說：『你知曉這事嗎？』對方若不明白，再對他說：『你看看這個。』對方若還不明白，再對他說：『我需要這個。』本律規定：若不說『你看看這個』，得突吉羅罪；破壞地面也是同樣的規矩。雜草生長覆蓋道路，為了通行而全面綁紮開闢道路，因非故意而導致枝折葉落者，不犯戒，因為並非蓄意破壞。

【譯文】（非時無故進入聚落戒）具備五個條件即構成犯罪：一是時間不合規矩（過了正午的非進食時段），二是沒有事先受請或召喚的因緣，三是沒有向同住同修託付告知，四是走向俗家人的住舍，五是一腳跨進家門即犯波逸提罪。《十誦律》說，如果阿蘭若處的比丘向同修告白後進城入聚落，返回阿蘭若處之後，又憑著剛才的告白再次進入聚落，犯波逸提罪；如果告白進入聚落，從聚落出來到了原來的僧坊，又再次折返進入聚落，也以此前的告白為由擅自進入，犯波逸提罪；在同一結界內若有同修善比丘在，不先向其告白就擅入聚落，犯波逸提罪。不向同修告白的比丘，每經過一條大街或小巷，就各犯一個突吉羅罪；每進入一家白衣舍宅，就各犯一個波逸提罪。如果進入阿蘭若處，或者進入靠近聚落的僧坊，就算不告白也沒有罪過。《薩婆多毘尼毘婆沙》說，如果總體向同修告白要進聚落，之後在聚落中隨意走動前往各處，都不算犯戒。《摩訶僧祇律》說，如果多人結伴在路上行走想要進入聚落，應當輾轉互相告白，然後才可以進入；如果已經抵達住宿之處，又想外出砍取柴草木料，若是沿著原本走的路出去則不犯戒，若是改從其他道路出去卻沒有告白，犯波逸提罪。《大智度論》說，一切在家人居住的房舍都總稱為聚落。《善見律毘婆沙》說，有集市買賣的稱為聚落，沒有集市買賣的稱為村界。依照本律，如果有事先告白，或者受人請託召喚，或者只是趕路途中穿過聚落，都不算犯戒。

【172-0033】04_比丘尼鈔/04b_卷中之下#26
【原文】剃三處毛戒具緣可解母論云剃髮者但除頭毛及鬚餘毛一切不聽却所以剃髮者為除憍慢自恃心不聽利木刀刮汗却毛若斷一一毛一一吉羅除頭上毛不犯若斷餘毛一一偷蘭剃髮有四種次第一上座二髮長三先洗頭四有緣欲行五分云尼過半月不剃髮提涅槃云髮爪長利破戒之相此律不得為白衣剃髮驅使提除欲出家者不犯頭髮極長若兩月若廣二指一剃爪極長如一麥即剪髮不得用剪刀剪半月應剃髮一剪爪違者吉羅聽畜盛髮器十誦云髮當埋坑中若髮長者開畜剃刀及鞘若刀卷者手上波石上磨其石內刀囊中。
【譯文】（剃除三處體毛戒）犯此戒的構成要件容易理解。《毘尼母論》說，出家人剃除毛髮，只能剃除頭髮和鬍鬚，其餘部位的體毛一律不准刮除。剃除頭髮的本意，是為了斷除傲慢與自命不凡之心；戒律不許使用銳利的木刀在刮汗時順便剔除體毛，若是剃斷一根毛就各犯一個突吉羅罪（剃除頭上的毛髮不犯戒）；若是刮斷其餘部位的體毛，每刮斷一根各犯一個偷蘭遮罪。剃髮有四種先後順序：一是按照戒臘從上座先剃，二是頭髮長的人先剃，三是洗好頭的人先剃，四是有要事即將遠行的人先剃。《五分律》說，比丘尼超過半個月不剃髮，犯波逸提罪。《涅槃經》說，指甲和頭髮留得又長又尖銳，是破戒的徵相。依照本律，不得為在家人剃髮供其驅使役使，違者犯波逸提罪；但如果是為發心準備出家的人剃髮，則不犯戒。頭髮長到極限，若是過了兩個月，或者長度達二指長，就必須剃除一次；指甲最長若達到一粒麥子的長度，就必須修剪；頭髮不得用剪刀剪截，每半個月應剃頭一次、修剪指甲一次，違背規矩者犯突吉羅罪。允許蓄備裝盛剃落頭髮的器具。《十誦律》說，頭髮應當深埋在坑穴中；如果頭髮長了，開許蓄備剃刀及刀鞘；如果刀刃捲口，可以在手掌上或砥石上打磨，打磨用的砥石應收納在刀囊之中。
