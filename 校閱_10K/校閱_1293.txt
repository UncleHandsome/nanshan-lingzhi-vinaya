# 校閱材料　第1293檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1293-0001】資持記/13d_下一#59
【原文】律不論者，指文漫也。若不知等者，以義定也。且約衣多者為言；若但三事，具缺與之。《十誦》下，次明審悉。先問，謂瞻病問病人也。不信，謂瞻病不可憑也。薩下，三明重衣。不刺不入，非一體故。《四分》下，示物數。漉囊針筒，出沒有異，隨有皆通。器襆袋等，竝隨六物，通入賞勞。
【譯文】律中不加細論，是指律文敘述較為概括寬泛。所謂「如果不知情」等，是以義理來加以判定。這暫且是就亡僧遺衣較多的情況而言；如果只有基本的三件隨身物，則視德行具足或欠缺而酌量給予。從《十誦律》往下，接著闡明必須審慎詳盡。「預先詢問」，是指照料病患前先詢問病患的心意。「不予採信」，是指看病者的言行不可憑信。從「薩」字往下，第三項闡明重縫之衣。若不用針刺綴縫合，便不得歸入看病僧，因為並非單一物件之故。從《四分律》往下，指出物品項目的數量。濾水囊與針筒，在律文出處各有隱顯不同，隨手邊所有皆可通融。盛衣器、包袱巾（襆）、布袋等，全都隨順六種隨身物，通通歸入勞績賞賜之列。

【1293-0002】資持記/13d_下一#60
【原文】次科，初別簡具缺，初句全與。下三句分與。竝須量可，故令商度。然德具物缺，或六物不足，則隨有與之；或是全無，則與餘物。二俱缺者，或不須與，或與少餘衣。德缺物具，事涉進否；故下別標。以人性既殊，行難求備；或減略物件，不可輕微。縱德少缺，而加全賞，理亦無損；
【譯文】下一科，首先分別簡擇功德與物件的具足或欠缺，第一句是全數給予。下三句是部分給予。全都必須衡量是否適可，所以令大眾共同商量裁度。然而，如果看病德行具足而物品欠缺，或是六物不齊全，就隨現有的給予；或者是隨身物完全沒有，則給與其餘的物品。如果看病德行與物品兩者都欠缺，或者根本不須給予，或者只給予少許其餘的衣物。若是德行有欠缺而物品具足，事情便牽涉到應當給予還是不給予的游移；所以下文特別標立。因為人的品性既然各有不同，行持本來就難以苛求全備；或者有所刪減節略的物件，也不宜給得太輕微寒酸。縱然德行稍有欠缺，但加恩全數賞賜，在法理上也沒有損害；

【1293-0003】資持記/13d_下一#61
【原文】故云亦須優及，謂多與也。竝下，總示和與。若德物俱具，須先賞勞；餘不具者，或與少物，義應直付；須至分衣法後，方可與之；乞字去呼。敏字訓疾，謂無滯礙；或可字誤，合作允。簡人中，初科。謂看病通七眾，非謂共看也。前明僧病，次明尼病。皆本眾合賞，俗眾非分。
【譯文】所以說「亦必須優厚恩及」，意思是要多加給予。從「竝」字往下，總體指示經由大眾和合共議給予。如果德行與物品兩者都具備，必須優先給予勞績賞賜；其餘德物不齊全的情況，或者給予少許物品，在義理上應當直接給付；必須等到分配遺衣的如法羯磨完成之後，才可以交付給他；「乞」字此處讀作去聲。「敏」字解釋為迅速敏捷，意思是處理通暢沒有凝滯阻礙；或者也可能是文字抄寫有誤，應當作「允諾」之「允」。在「揀選人員」中，第一科。所謂看病通於出家在家的七眾弟子，並不是說七眾共同看病。前面闡明比丘患病，其次闡明比丘尼患病。都是由本僧團的大眾共同給予賞賜，俗人不在分配之限。

【1293-0004】資持記/13d_下一#62
【原文】注云勞者，即前二五德也。《伽論》開與餘眾。沙彌六物，於後有用，故須具與。準下，義決。共看與究竟者，謂前後替看。齊竟屏分，謂賞一首者，令後自分。次科，初明留付。亦可等者，以身不現，不可羯磨，故令白眾直和待還。若下，次簡合賞。以捨己修道，遠相濟故。《伽論》雖非夏制，頗見懷慈。
【譯文】註解中所說的「辛勞功勞」，指的就是前面所說的「兩種五德」。《摩得勒伽論》開許給予其餘眾。沙彌的六種生活用物，在日後受具足戒時有用處，所以必須全數具足給予。從「準」字往下，依義理加以斷決。共同看病照料直到終局者，指的是前後輪替看病。「齊同究竟照護者私下均分」，指的是賞給其中一位領頭代表者，令他們事後自行分配。下一科，首先闡明保留寄存交付。所謂「也可以」等語，是因為當事人身不在場，無法如法舉行羯磨，所以命知事僧秉白大眾，直接和合共議等待他返回交付。從「若」字往下，接著簡別應受賞賜者。這是因為看病者捨棄自己的道業修行，不辭辛勞遠道救助病僧的緣故。《摩得勒伽論》雖然不限於結夏安居的制度，卻極能顯現悲愍包容的慈懷。

【1293-0005】資持記/13d_下一#63
【原文】時節中，初科。共行弟子，或稟戒、或依止，師資相濟七種共行，如上卷中。舍利即死屍。次科，《十誦》屍去後。謂葬訖也。在異處者，離屍邊也。《母論》同之。然準上文，即後皆得；而《母論》有序，是可行之。第九集財中。不勝舉謂重大者，不必現前。
【譯文】在「處分時節」中，第一科。「共行弟子」，或者受持戒法、或者依止依附，師長與弟子之間相互提攜扶濟的七種共行關係，正如上卷所述。「舍利」指的就是死者遺體。下一科，《十誦律》說遺體送走之後，指的是安葬完畢之後。所說在別處者，是指離開停屍的場所。《毘尼母論》也持相同看法。然而依照上文，當即分配或事後分配兩種作法均可採行；而《毘尼母論》的處分程序井然有序，是可以奉行採用的。第九「收集遺財」中。所謂搬運困難拿不動者，是指龐大笨重的物品，不一定非要呈現在大眾面前不可。

【1293-0006】資持記/13d_下一#64
【原文】須歷帳者，無論大小現不現物，皆須錄示；至僧集時，先令維那打槌披讀。加法中。五人已上，行法整足，故別明之。處判中，次科。注中。據律合牒六物。上文但云若衣非衣，蓋準《多論》，容不集故。彼云：三衣在餘處者，索來此賞；若此德不具，則隨彼分等。《母論》亦爾。
【譯文】必須登載帳冊，是因為無論大小、在場或不在場的物品，都必須詳細登錄揭示；等到僧眾集會時，先令維那敲擊槌木，宣讀帳目清冊。在「加行作法」中。有五人以上參與，羯磨行法整肅完足，所以特別加以闡明。在「處斷判定」中，下一科。註解中，根據律典原本應當逐一列舉六種隨身物。上文僅僅提及「若是衣服或非衣服」，大概是依照《薩婆多論》，容許物品不全數集中之故。該論說：如果三衣散落在其餘處所，索取到此處再來賞賜；如果這裏看病者的德行不具足，就隨順彼處的規定去分配等等。《毘尼母論》也有相同的規定。


【1293-0007】資持記/13e_下一#1
【原文】判物中有三，先問有三，一問負債，二問囑授，三問同活。應令一人答其有無。次判輕重。如上分者，即應對僧逐物提示重輕之意，然後各著一處。三索送喪物。三唱還者，應先告僧若千件數津送亡者，此是看病者物，將替入法，應須還波；唱云：大德僧聽！
【譯文】辨別物品（判物）這部分包含三項程序。首先是詢問三件事：一是詢問是否有積欠債務，二是詢問是否曾有交代託付，三是詢問是否有同甘共苦共同生活的同修。僧團應指定一人來回答這些狀況的有或無。接著是辨別物品的輕重。按照先前分類的標準，應當面對僧眾逐一出示物品並說明輕重之意，然後分別放置在不同的地方。第三是索還用於辦理喪事的物品。三次唱告索還時，應先向僧眾稟告：「拿出若干件數的物品是用來料理亡者後事，這是屬於照料病人者的私物，先前暫時代替亡者之物納入僧物規範，如今理應歸還給他。」唱告詞為：「大德僧聽！」

【1293-0008】資持記/13e_下一#2
【原文】僧今持此衣還某甲比丘。〔三說。〕若無，謂不將亡物送喪也。賞勞中，初科，前標合賞。今下，次辨須否，初斥時對問。以答具不具，二皆不便。俗所恥者，《論語．顏子》云：願無伐善。〔謂自稱己德。〕與下，顯今不須。律云：即引結說戒堂文，故云結不結也。
【譯文】僧眾現在拿這件衣物歸還給某甲比丘。」（此句重複宣說三次。）如果沒有這項手續，是指當初並未動用亡者遺物來料理喪事。在犒勞看護者（賞勞）的章節中，第一個小段落是先前標明理當給予犒賞。接著在「今下」的部分，則是辨析是否需要詢問對方。首先斥責當面訊問當時看護者的作法。因為無論回答具足看護之德或不具足，兩種回答都令人尷尬難堪。世俗之人所引以為恥的，就如《論語》中顏子所說：「希望自己不誇耀功勞。」（意思是不主動自稱有德行。）從「與下」開始，顯明現今不需要當面詢問。律典所說的內容，即是引用結定說戒堂的文句，因此才用是否要「結」來作比喻。
