# 校閱材料　第148檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【148-0001】01_行事鈔/07b_卷中之三#35
【原文】食殘宿戒三十八。三緣：一是殘宿，二知是，三食咽咽犯。律中殘宿食者，今日受已至明日；於一切沙門釋子受大戒者，皆不清淨。四藥以論，過限結罪如前戒。《善見》、《十誦》、《五分》：大比丘受食已，或食未食，經夜名殘宿。問：殘之與宿，為一為異？四句答之：一殘而非宿，吉羅。二宿而非殘亦吉。三亦殘亦宿，提。四非殘非宿可知。殘宿、內宿，亦作四句：一是殘宿非內宿，得墮。二是內非殘。三四俱句，類知。有云，淨地無內宿。文云除去比丘，故知有也。律中，殘宿、不受食戒，以坐禪比丘為緣起者，為防未來惡比丘故。內無道觀，煩惱未伏；妄倚道業，便輕聖戒。此乃心涉愛憎，大我未伐；故諸三乘道人，並不輕戒。以深伐我根，傾慢使幢；敬戒而增道業，可不欽尚之哉。
【譯文】食殘宿戒三十八。具備三種緣成犯：一、食物確實是屬於吃剩或經夜的殘宿食；二、明知是殘宿食；三、下咽食用，每吞咽一口便結犯。《四分律》中說明：所謂殘宿食，是指今天正式接受了施主的受授之後，留存放置到了隔天黎明；這對於所有受了具足大戒的釋迦門下沙門弟子而言，通通都屬於不清淨的食物。若是就「四種藥物」的期限來論斷，凡是超過受持期限者，其結罪正如前一條戒中所明定。《善見律》、《十誦律》、《五分律》均指出：大比丘正式接受了食物之後，不論是已經吃過剩餘下來的，還是完全未吃過而留存下來的，只要經過了一夜，便統稱為殘宿。設問道：「殘」與「宿」，兩者是一樣的概念還是有所不同？以四種關係（四句）來解答：第一、是殘食而非宿食（如早晨接受三藥（非時、七日、盡形）而未加口法受持，過午失法），結突吉羅（吉羅）。第二、是宿食而非殘食（指食物尚未經受授，但與比丘同室共宿過夜，結內宿突吉羅；若不共宿則無犯），亦結突吉羅（吉）。第三、既是殘食又是宿食（昨天吃剩且又留置過夜），食用每咽一口結波逸提（提）。第四、既非殘食又非宿食，其合於律制之清淨自是不言而喻。關於殘宿與內宿（在僧房宿處內貯存過夜），同樣可以列為四句來辨析：第一、是殘宿而非內宿（在屋外經夜，或在界外放置），結波逸提（單墮罪）。第二、是內宿而非殘宿。第三與第四種俱全或俱非之句，依此類推可知。有人聲稱：「如法作法的淨地之中不存在內宿之罪過。」然而律文中明白記載說，作法之淨地必須排除比丘在內起居住宿（方得宿食），由此可知（若不除去比丘）淨地之中確實也存在內宿之罪。在律典中，佛陀制定「殘宿食戒」與「不受食戒」，追溯其最初結戒的起因，皆是以山林中坐禪比丘為緣起；這是佛陀為了防範未來世中借修行為名之惡比丘而特別制定的。這類人內心缺乏深細的聖道觀照，貪嗔煩惱根本未曾降伏；卻虛妄依託自己有些許坐禪道業，便輕慢蔑視佛陀制定的清淨聖戒。這完全是心緒牽涉於貪愛與憎惡，心頭巨大的我執慢毒尚未鏟除討伐之表徵；因此真正修證三乘道果的得道聖人，絕對不會輕賤戒律。因為他們已經深深斬斷了自我的執念根源，推倒了驕慢傲慢的煩惱魔幢；他們以敬重奉持戒律來增上自己的聖道道業，吾輩修行者又怎能不欽奉崇尚呢！

【148-0002】01_行事鈔/07b_卷中之三#36
【原文】《十誦》：若鉢著不淨脂蘇，受麨食，應寫淨鉢中食之，著鉢者棄。繩綴鉢，受粥脂出，但棄膩處，餘者得食。若新熏鉢及手穌脂油著，二三澡豆洗，餘膩氣不盡，名淨。不淨殘宿鹽，食吉羅。《伽論》：膩故不去者，非食膩故。
【譯文】《十誦律》說：如果鐵缽中沾黏了不清淨的油脂或生酥，又用它來受盛麨粉進食，應當將乾淨的麨粉傾倒至乾淨的缽中來食用，而沾黏在原缽內壁油脂上的部分則應當捨棄。如果是用鐵絲繩線修補綴合的破裂之缽，盛裝稀粥時縫隙中滲出了油脂，只要把沾染油膩的那一部分剔除丟棄，其餘的粥食依然可以食用。如果是全新熏製的缽，或是雙手上殘留沾染的酥油油脂，用澡豆（洗滌粉）反覆洗滌了兩三次之後，即便殘餘的油膩氣味尚未徹底除盡，在律制上也認定為是清淨的。食用未經合法受授而不清淨的殘宿鹽巴，結突吉羅（吉羅）。《薩婆多部毘尼摩得勒伽》（《摩得勒伽論》，簡稱《伽論》）說：油膩殘存是因為材質本身吸附而無法洗除乾淨，這並非屬於又故意殘留食物油漬之故，因此無過。

【148-0003】01_行事鈔/07b_卷中之三#37
【原文】《善見》云：多比丘一沙彌行，比丘各自擔食，至時各各自分；分已，沙彌語比丘云：「我持己分，與大德易之。」易得已，復與第二比丘易，乃至下座。若沙彌不解者，比丘自持食與，教共易得，無犯。乃至持米行，沙彌小，比丘得作飯，唯不得然火。若沸，不得吹攪，吉羅。熟已，如上分，展轉易者，得。《十誦》：比丘傳食與沙彌，沙彌傳鉢食與比丘，比丘洗手更受；以一心實與沙彌，故淨也。遠行難得食處，聽自持食從他易淨食者，得。今有直將食乞淨人，還從乞取；二彼俱無受捨，不名交淨。有比丘使沙彌持鉢，沙彌食已，持不淨鉢與師。佛言：無急事不應使沙彌持鉢；若使持，應從沙彌受。
【譯文】《善見律毘婆沙》（善見）說：多位比丘與一位沙彌結伴同行遠足，比丘們各自挑擔著生乾糧食物，到了用齋的時辰各自劃分出一份一份；分完之後，沙彌主動對比丘說：「我拿我自己的這一份食物，與大德您互相交換。」交換得到之後，沙彌又拿這份食物再去與第二位比丘交換，依此類推乃至交換到最末席的下座比丘。如果沙彌年幼懵懂不知此法，比丘可以主動拿著食物交給他，教導他共同依此交割互換，如此大家受食皆不犯戒。乃至於攜帶生米同行時，若沙彌年紀幼小無法掌廚，比丘可以親自動手淘米做飯，唯獨絕對不得親自去點火燃柴。煮飯水滾沸騰之時，比丘亦不得用嘴去吹氣或用勺子去攪動，若吹攪則結突吉羅（吉羅）。待米飯煮熟之後，如同上述方法分份，讓沙彌展轉互相交換之後，大家便可以食用。《十誦律》說：比丘把未經受授的食物傳遞給沙彌，沙彌將盛入缽中的食物正式遞呈受授給比丘，比丘洗淨雙手後重新正式領受；因為比丘起初是真心實意將食物徹底給予了沙彌，由沙彌持有轉化為清淨物後再行供奉，所以在律法上算作清淨合法。比丘出遠門若遇到難以化緣乞食之處，佛陀開許可以自己攜帶生乾糧，在途中向他人交換合法的清淨熟食，這是允許的。如今有的人只是形式上將食物塞給淨人，隨即立刻又向淨人索要回來；這雙方自始至終都沒有真正的割捨與領受之心（俱無受捨），根本不能稱作合法的「交淨」（交換使清淨）。曾有比丘差使沙彌代為拿持其飯缽，沙彌用完齋後，拿著盛過食物未經清洗受授的不淨缽遞還給師父。佛陀開示說：若沒有緊急迫切之事，不應當隨便指使沙彌拿持自己的飯缽；如果迫不得已差使他拿持，師父要重新使用時，應當如同接受新物一般正式從沙彌手中重新受授。

【148-0004】01_行事鈔/07c_卷中之三#1
【原文】《十誦》：無水處，水上有食，棄上飲取下；若下有食，飲取上；乃至穌油等，吹去飲取。水泉池中，有食亦爾。《僧祇》、《多論》：乞食食已，有殘，棄曠野石上；明日乞食不得，不作本意，還從本道，石上故飯在者，無淨人自取，有烏鳥食處，當扟去。《五百問》因緣同上。所以開者，以信施重故。又無主物，如欝單越法，取食者得。《五分》：比丘殘果與淨人已，不作還意，後淨人還與比丘。佛言：離手已名淨，食之。
【譯文】《十誦律》說：在缺乏水的地方，如果水面上漂著食物，應當撇去上面漂食的水，飲用下面的水；如果水底有食物，就舀取上面的水飲用；乃至於浮著酥油等物，吹開後飲用。水泉、水池之中若有食物也是這樣。《摩訶僧祇律》、《薩婆多論》說：乞食吃完後，有剩餘的食物，丟棄在曠野的石頭上；第二天乞食沒得到，自己本來沒有預先打算回去取食，順著原路返回時，看到石頭上的舊飯還在，如果沒有淨人（為僧人服務的俗人），可以自己拿取；如果有烏鴉或鳥雀啄食過的地方，應當挑除丟棄。〔註：「扟」，音義同「捵」，挑除、排除之意。〕《五百問事》中的因緣與上面相同。之所以開許，是因為信眾布施的恩德深重不可浪費。又因為屬於無主之物，如同北俱盧洲（欝單越）的法則，拿來食用是可以的。《五分律》說：比丘把吃剩的水果給了淨人之後，心裡沒有想著要索回；後來淨人又把水果還給比丘。佛說：食物一旦離開比丘的手，就已經算是清淨了，可以食用。
