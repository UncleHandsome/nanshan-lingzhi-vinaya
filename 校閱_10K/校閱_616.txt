# 校閱材料　第616檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【616-0004】02_戒疏/11b_卷三上之二#83
【原文】【疏】今云解意。《多》云所以制者：「一、為止誹謗故，二、為除鬬諍故，三、為增上佛法故。出家之人，理宜迹絕塵染，為人天所宗，以道化物。而與女人屏說非法，上違聖意，下失人天宗敬心故。四、為斷惡業次第法故。」
【譯文】【疏文】現在說明制定此戒的深層用意。《薩婆多論》說明制戒的原因：「第一、為了止息世人的誹謗；第二、為了消除僧俗之間的鬥爭；第三、為了讓正法更加增長弘大。出家修道之人，在道理上應當超然物外、斷絕世塵的染污，作天人共尊的模範，以正道來教化眾生。如果與女人在隱蔽處談論非法之語，往上違背了佛陀聖者的教敕本懷，往下則喪失了天人敬仰信奉的道心。第四、是為了斷除造作極重惡業的相續之法。」

【616-0005】02_戒疏/11b_卷三上之二#84
【原文】【記】第一中，制意有四。即斷四過：初、人多嫌疑；二、夫多見嫉；三、汙辱佛法；四、因成極重。由成四益，故聖制之。
【譯文】【記文】在第一項中，制戒的用意共有四點。也就是為了斷絕四種過失：第一、眾人多起嫌疑猜忌；第二、人夫容易心生嫉妒；第三、玷污羞辱了佛法僧寶；第四、從微漸著終致釀成極重之罪。由於能成就這四種利益，所以聖者佛陀制定了此戒。

【616-0006】02_戒疏/11b_卷三上之二#85
【原文】【疏】論犯四緣：一、是屏處；二、女人；三、無第三人；四、隨作，犯。
【譯文】【疏文】論述犯戒的四種因緣：第一、處在隱蔽之處；第二、對方是女子；第三、身旁沒有第三者在場；第四、只要與之同坐談論，即構成犯戒。

【616-0007】02_戒疏/11b_卷三上之二#86
【原文】【記】犯緣中。「第三人」者，比丘、女外，更有一人，名為第三。
【譯文】【記文】在犯戒因緣之中。「第三者」是指比丘與女子之外，另外還有一人在場，就稱為第三人。

【616-0008】02_戒疏/11b_卷三上之二#87
【原文】【註】佛在舍衛國。迦留陀夷先俗友婦齋優婆私，形並端正，各有繫意。時到詣彼，共屏覆坐，說非法語。毗舍佉母闚見起過，疾往白佛，因訶制戒。
【譯文】【註文】佛陀在舍衛國時。迦留陀夷比丘過去在俗世時有一位朋友的妻子，是受持八關齋戒的優婆夷，兩個人長得都非常端莊俊美，彼此互相關懷繫念。到了用餐時間，比丘前往她家中，兩人一同在隱蔽遮覆之處坐下，談說世俗非法的言語。毘舍佉母從旁窺見，認為這種行為有違戒法，便趕緊前去向佛陀報告，佛陀因而呵責並制定了這條戒。

【616-0009】02_戒疏/11b_卷三上之二#88
【原文】【疏】就戒緣中。言「毗舍佉母」者，《多》云：「此人聰明，已入道迹。常聞佛說聽法五利：一、得未聞法；二、清淨堅固；三、除邪見；四、得正見；五、解深法。故來屏聽，不以嫌疑。」《見》云：「毗舍佉母有十男十女，各有二十兒孫，合四百二十人，國中稱之婚法準則。」
【譯文】【疏文】在制戒的緣起之中。提及「毘舍佉母」此人，《薩婆多論》記載：「此人聰明睿智，已證得初果聖位（入道跡）。她經常聽聞佛陀開示聽法的五種利益：第一、能聽聞未曾聽過的正法；第二、使清淨信心更加堅固；第三、能破除種種邪知邪見；第四、得以獲得真實的正知正見；第五、能通達解了甚深微妙之法。因此她特地走到隱蔽處旁聽，並非出於世俗嫌惡猜忌之心。」《善見論》說：「毘舍佉母生有十個兒子與十個女兒，這些兒女又各自生了二十名兒孫，合起來共有四百二十人，在拘薩羅國中被公認為福德家族的婚事榜樣。」

【616-0010】02_戒疏/11b_卷三上之二#89
【原文】【記】戒緣中。初引《多論》明彼聽意。《論》先問云：「毗舍佉母聰明利根，大德重人，何故往聽也？」《疏》引答詞。「道跡」謂初果。「聽法五利」：一、解，二、行，三、識非，四、達是，五、資深。彼持佛說，故來聽法，不謂惡語故也。次引《見論》示其族望。一男一女，各生二十子，即有四百孫。「婚法準則」，謂有家豐，為人所法也。
【譯文】【記文】在戒條的緣起中。首先引用《薩婆多論》說明她前去旁聽的意圖。《薩婆多論》先前問道：「毘舍佉母是位聰明利根、極具大德受人尊崇之人，為何要特意前往旁聽呢？」《疏文》引用論中的回答。「道跡」指的就是初果聖人。「聽法的五種利益」：一是增長理解，二是策勵行持，三是辨識非理，四是達致正見，五是資益甚深法義。她心懷佛陀所說的利益，所以是為了聽法而靠近，並非預料他們會講粗惡之語。接著引用《善見論》展示其家族聲望。每個兒女各自生了二十個小孩，孫輩就達四百人。「婚法準則」，是指她家境殷實圓滿，被世人視為效仿的典範。

【616-0011】02_戒疏/11b_卷三上之二#90
【原文】【律】若比丘，共女人獨在屏處、覆處、障處可作婬處坐，說非法語，有住信憂婆私於三法中以一一法說，若波羅夷，若僧伽婆尸沙，若波逸提；是坐比丘自言「我犯是罪」，於三法中應一一治，若波羅夷，若僧伽婆尸沙，若波逸提，如住信憂婆私所說，應如法治是比丘，是名不定法。
【譯文】【律文】若有比丘，與女人單獨在屏障處、遮覆處、阻隔處，足以行淫之處同坐，談說非法的言語；此時有一位深具信心的優婆夷，在三種罪法中指陳其中任一罪，或是波羅夷，或是僧伽婆尸沙，或是波逸提；這名坐著的比丘若是自己承認說「我確實犯了此罪」，僧眾便應依照其自陳，於三種法度中隨所犯而治其罪，或是波羅夷，或是僧伽婆尸沙，或是波逸提；應當如同具足信心的優婆夷所指證的那樣，如法懲治這名比丘，這就稱為不定法。

【616-0015】02_戒疏/11b_卷三上之二#94
【原文】【疏】三、「女人」者，注解「有智」。「大」者，《僧祇》云：「母女姉妹，親與非親，老少道俗，同是一犯。」

【616-0016】02_戒疏/11b_卷三上之二#95
【原文】【疏】四、言「獨」者，注中易解。《僧祇》云：「若眠、若狂、嬰兒等，不名為證。」
【譯文】【疏文】第四、說到「獨」這個字，小註之中很容易明白。《僧祇律》說：「如果身旁只有睡著的人、瘋癲狂亂之人、或不懂事的嬰兒等在場，都不能算作具有見證能力的旁人。」

【616-0017】02_戒疏/11b_卷三上之二#96
【原文】【疏】五、「屏處」，注分為二：初云「見屏」，中無隔障，但為緣來，兩不相見也；二、言「聞屏」，目兩見在，但不聞聲故。如《見論》中，約對第三人，「若無眼，或聾，或眠，或女人多」者，隨犯多墮。「覆障二處」，約緣相為言，屏處一種，約見聞根辨。
【譯文】【疏文】第五、「屏處」，小註將其分為兩種：第一種稱為「視覺屏障」，中間雖無遮蔽障礙，但因外在因緣干擾（如沙塵、迷霧），導致彼此互看不見；第二種稱為「聽覺屏障」，眼睛雖然能看見兩人同處，但完全聽不到彼此交談的聲音。正如《善見論》中相對於第三者而言：「如果身旁第三人眼瞎，或是耳聾，或是熟睡，或者旁邊只是一群普通女子」，這都隨順犯下多種墮罪。「遮蔽與障隔這兩處」，是就物體外在的形態障礙而言；而「屏處」這一種，則是專就眼睛與耳朵這兩處感官根門的隔絕來辨析。
