# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】言羯磨者，事現在前，非法則息。羯磨八種，通鏡行藏，達則事法俱成，迷則翻種苦業，故須稱量也
【譯文】所謂「羯磨」：事情顯現在眼前，若是非法之事則應止息。羯磨有八種，通盤鑑照著當行與當止；通達了則事相與羯磨皆得成辦，迷惑不解則反過來種下苦報惡業，所以必須事先審查稱量。

【439-0002】03_業疏/04a_卷一之四#25
【原文】三中，事現在前，謂機生也；非法則息，謂事不成濟也。如教則須行，非法即宜藏。鏡，明也
【譯文】在第三點中，「事現在前」，是指因緣機緣生起；「非法則息」，是指非法之事不能成辦救拔。符合教規就應當奉行，違背教法就應當隱退止息。「鏡」，是照亮、明達的意思。

【439-0003】03_業疏/04a_卷一之四#26
【原文】言所犯者，謂凡所造過，無越七階，或涉疑濫，或預迷塞，理須分別。事等晨昏，無宜持犯相干，多少委冐也
【譯文】所謂「所犯的罪過」：凡是所造作的過失，不出七個階位（七聚罪）；或者牽涉到疑似混濫，或者預先陷於昏昧閉塞，在法理上必須加以甄別。持與犯的分際就如同清晨與黃昏一般界限分明，不應當讓持戒與犯戒彼此混淆，對罪過的多少任意草率含糊。

【439-0004】03_業疏/04a_卷一之四#27
【原文】四中，七階即七聚。犯有三心：一、識，二、疑，三、不識。迷塞即不識也。等晨昏者，謂同晝夜晷刻定也。持犯相干，謂不識犯緣；多少委冐，謂不知犯相
【譯文】在第四點中，「七階」就是指七聚罪。犯戒時有三種心態：第一是明知而犯（識），第二是起疑而犯（疑），第三是昏昧不知而犯（不識）。「迷塞」就是指不識。所謂「如同晨昏」，是指如同晝夜的日晷時刻那樣確定不移。「持犯相干」，是指不知道犯戒的因緣界限；「多少委冒」，是指不知道罪名罪相的輕重多寡。

【439-0005】03_業疏/04a_卷一之四#28
【原文】言量事者，乃含多義，今但取當時達僧法所評者。隨人法物，皆事所收，宜須商度，重輕前後、離合同篇、異聚因果雜相，未可即施，先宜窮考故也
【譯文】所謂「衡量事情」：包含著諸多義理，如今只選取當時通達僧法之人所評定裁決的事宜。無論是人、法、物，都屬於「事」所收攝；應當審慎商討考量其罪過的輕重、犯案的前後、離散與合併、同篇之罪或異聚之罪、因位與果位的駁雜相狀等，不可冒然立即施行法事，應當先徹底窮究考查。

【439-0008】03_業疏/04a_卷一之四#31

【譯文】第一部分中，隨順事相而受戒是「為人」：因為善信之人歸心三寶，最初依投修行之根本，所以受戒之法從屬於人。若著眼於所受之法，本是聖者教法，理應歸屬於「法」；然而教法的生起依託於人，所以隨順能受戒者而安立名稱。所謂懺悔、差遣等相狀，唯獨是為了他人而發起；治罰、擯出、呵責等法，則是自己與他人通受加被，以此來剪除田中的稗草雜草，增長嘉好的苗稼，難道不是這樣嗎！或者也可以隨著義理的通塞來靈活理解，何必局限於此呢？

【439-0009】03_業疏/04a_卷一之四#32
【原文】次義開釋三種中，初文隨相，二望總舉。「受戒下」別釋。初釋受戒。行本即戒體。望戒是法，據受歸人。「言下」次釋懺治。懺差偏局，治擯兩通。斷除稊稗喻被他，增長嘉苗喻被自。稊，音啼；稗，傍卦反，田中穢草也。「或下」點上所分不定義也
【譯文】在接下來隨義理展開解釋三種事項中，起初的文字依據事相，從「兩望」來作總體列舉。自「受戒」以下作分別解釋。起初解釋受戒：「修行之本」就是指戒體；著眼於戒體而言是「法」，依據受戒行為而言歸屬於「人」。自「言懺差」以下接著解釋懺罪與治罰：懺悔與差使偏於局限為他，治罰與擯出則自他兩通。剪除稊稗比喻加被於受治罰者，增長嘉苗比喻加被於僧伽自體。「稊」音啼（tí）；「稗」為傍卦切（bài），是田間的有害雜草。自「或可」以下點明上述區分並非死板固定的定義。

【439-0016】03_業疏/04a_卷一之四#39
【原文】有人解云：隨作一法皆須三量，何以明耶？如四人結界，即人事也；白二加之，即具法也；對首亦爾，衣之是非，事也；彼此相解，人也，故文云「言議往返，人現前也」，口說持文，即為法也；心念亦爾，常存懷記，為人也，前境不一，為事，心生口言，為法。不違此法，業成奉戒，豈非具三
【譯文】有人解釋說：凡是作任何一種法，都必須具備三種考量（人、法、事），用什麼來闡明呢？例如四人結界，這就是人事；施加白二羯磨，這就是具備了法；對首法也是如此，衣物是否合法，這是事；彼此相互解了明白，這是人，所以律文說「言語商議往來，即是人現前」，口中宣說受持的文句，就是法；心念法也是如此，心中常常憶念掛記，這是人；眼前所對的境界種種不同，這是事；心中生起、口中宣陳，這就是法。不違背這種法則，法業成就、奉持戒律，難道不是三者具備嗎？

【439-0018】03_業疏/04a_卷一之四#41
【原文】今解不無其致，太為通混。玅識羯磨所牒之辭，則據本緣，互不通也。如受法中，但云乞戒者，人也；諸結法中，但云限約，限即界也。自有人事合者，如人病、衣重等；「如是語者，捉全籌」等。無問僧別，皆有單具、交絡雙單，終合七緣，以從羯磨，攝事皆盡
【譯文】如今辨析：古人的解釋並非沒有道理，但未免太過通融混淆了。若能精妙識別羯磨文中重申陳述的詞句，就會發現那是依據根本發起之緣，彼此並不互相混通。例如受戒法中，只稱說乞受戒者，這是「人」；各種結界法中，只稱說界限約定，「限」就是結界之「事」。自然也有人與事相合的情形，例如人病、衣重（開許離衣羯磨）等；又如「若贊成此話語者，請取完好籌」等。無論是僧法還是別法，都有單句、全具句、交互穿插的雙句單句，最終匯合為七種因緣，以此來依順羯磨，就能把一切事項收攝無遺。

【439-0019】03_業疏/04a_卷一之四#42
【原文】今解中，初句縱與，次句斥奪。彼分三量，不辨能、所，故云「通混」。「玅」下示正義，羯磨所牒，即正陳所為，法法各別，故不互通。略舉受、結，餘可類知。「自有」下，即複具四句：人病衣重即離衣法，此二合也；「如是語捉全籌」，即具足句，本律滅諍中云行籌應有白，云「如是語者捉完籌，如是語者捉破籌」，如是語是法者即是人，籌豈非事？又如延日自恣，修道是人，日即是事，自恣即法。更就別法例此尋之，略為圖示，使能所兩分焉。
【譯文】在疏家如今的解釋中，第一句是暫予承認（縱與），第二句是嚴加駁斥（斥奪）。古人劃分三量，不能明辨能作與所作，所以說是「通混」。自「玅識」以下開示正統義理：羯磨文中所重述陳辭，正是端正陳述所辦之事，法與法各自有別，所以並不互相混通。大略列舉受戒與結界，其餘法皆可照此推知。自「自有人事合者」以下，就是指複合具備的四句：因人有病、衣物過重而作的離衣法，這是人與事二者合一；「若贊成此語者捉完好籌」，這就是人、法、事具足的句子；本律滅諍犍度中說行籌時應當宣白說「贊成此語者捉完籌，贊成彼語者捉破籌」，「贊成此語」既是法也連帶指持此觀點之人，而籌碼豈非是事？又如延後日期自恣，進修道業是人，日期就是事，自恣就是法。再就個別之法照此尋究類推，大略以圖表展示，使能作與所作兩者劃分明晰。

【439-0024】03_業疏/04a_卷一之四#47
【原文】第二法起託處
【譯文】第二、羯磨法生起所依託的處所。

【439-0025】03_業疏/04a_卷一之四#48
【原文】先以文據，後以義求。取《僧祇》文釋成羯磨所起必在法界，自然地弱，不勝僧事。何以然耶？夫僧法軌模，起還法地；若先未加，事乖法式。即如義證，難事已臨，欲行說恣，猶先結界。然依本法，雖無文證，即此成準
【譯文】首先依據律文，其後以義理推求。引用《摩訶僧祇律》的律文，來闡明羯磨法的生起必定要在如法所結的界內（作法界），因為自然界的地力薄弱，不足以承擔僧團羯磨大事。為什麼會這樣呢？因為僧團羯磨的法度軌則，其生起必須回歸於作法之處（法地）；如果事先未曾加法結界，僧事就會違背法規準則。這正如義理上的證明：即便危難之事已經逼近，想要舉行說戒或自恣，仍舊要先結界。然而依照本部《四分律》，雖然沒有明文證成，但依此例即可成為準則。

【439-0026】03_業疏/04a_卷一之四#49
【原文】二法起處釋注初科為二：初標分。文據即《僧祇》，義求即本律。「取下」次牒釋。初釋文據。未加聖法，故云地弱；僧事功強，所以不勝。「即下」釋義求。此引說恣小界，可驗眾法不許自然。本法即本律法聚，謂當部中無文有義，即用義決。若準五現秉法須界，亦是明據，但非正意，故云無耳
【譯文】在解釋第二「法起處」注文的最初一科中，分為兩個部分：首先標明劃分。「文據」即是指《摩訶僧祇律》，「義求」即是指本宗《四分律》。自「取（《僧祇》文）」以下，其次牒出並作解釋。首先解釋文獻依據：由於未曾施加聖法結界，所以說地力薄弱；僧團之事的功力強大，所以自然界無法承擔。自「即（如義證）」以下，解釋義理推求：這裡引用在急難時為說戒、自恣而結小界的例子，便可驗證僧眾之法絕不允許在自然界中舉行。「本法」即是本律的法聚，意思是說在本部律文中雖無明文但具有此義理，便依義理來決斷。如果比照「五現前」中秉持羯磨必須有界限，也是明確的依據，但並非此處的主旨，所以說沒有明文罷了。

【439-0027】03_業疏/04a_卷一之四#50
【原文】言處有二者，顯相通局也。非謂僧法唯在法地，結界一法非作法界，由是草創所依，開此居宗；若不自然，後諸眾法無緣加被。故此羯磨偏與餘反，如受戒者聞法非障等，自餘竝在法界，可以例知。別人行法，二界通塞如上也
【譯文】說到「處所分為兩種」，是為了顯示其體相的通融與局限。這並不是說僧事之法只能在作法地（法界）中進行，結界這項羯磨就並非在作法界中進行，因為它是最初草創僧事的依託處，所以開許此法作為根本主宗；如果不在自然界中結界，後續的各種僧眾之法就無從加法建立。因此這項羯磨偏偏與其他羯磨相反，就像受戒者在現場聽聞羯磨文並不算障礙一樣；其餘一切僧事都在作法界中進行，依此即可例推而知。單個人所行持之法，在作法界與自然界這兩種界中的通行與阻隔，如同前述。
