# 校閱材料　第117檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【117-0001】02_戒疏/01c_卷一上之一#44
【原文】【疏】答：「重罪懺、擯，覆、露兩殊，法通開、閉，故有常準。斷頭喻無聖分，秉法據本戒儀。適機見有重、輕，當部規模不失。即斯量據，非法何邪？」
【譯文】【疏文】回答說：「重罪之所以有准予懺悔與徹底驅擯的差別，是因為發露懺悔與覆藏掩飾這兩種心態完全不同，戒律條文通達於開許與遮止，因此自有其恆常固定的法度標準。斷頭的譬喻是形容犯者徹底喪失了證得聖果的分證，而重新准予參與法事則是依據他原本所受戒體的儀規。佛陀隨應眾生根機而使教法顯現有輕有重，但就該部派內部的規範體制而言卻是絲毫不失準則的。單憑這種條理分明的規矩法度，若不是法則規範，又能是什麼呢？」

【117-0002】02_戒疏/01c_卷一上之一#45
【原文】【記】答有二。初六句答前難。「懺」、「𢷤」謂「露」者許懺，「覆」則滅擯，開制有儀，明非不定。「斷頭無聖」，喻體無功；「秉法據戒」，顯體全在。「適」下二句，答次難。上句明互望不定，下句示各論還定。「適機」謂佛本設教。「見」即諸師計情。「即」下，通結兩釋，還歸上義。
【譯文】【記文】回答包含兩層意思。前六句回答第一個詰難。「懺」與「擯」，是指發「露」者允許如法懺悔，隱「覆」者則予以滅擯逐出僧團，開許與制止皆有其軌儀規範，明證了其並非混亂不定。「斷頭喻無聖」，是譬喻其戒體已失去發起聖道的功用；「秉法據本戒」，是彰顯其戒體依然完全具在。「適」字以下兩句，回答第二個詰難。前一句說明彼此對照雖有不同，後一句說明各部派內部自成一套恆常體系。「適機」是指佛陀最初依機設教的化導之意。「見」就是指各部派論師的分別計度情見。「即」字以下，總括結語兩種解釋，重新歸向於上文「律即是法」的義旨。

【譯文】【疏文】第三、對照不同名稱來確立教法的意義。

【117-0004】02_戒疏/01c_卷一上之一#47
【原文】【疏】問：「三藏得号偏從於『律』，餘二沒名，斯有何意？」
【譯文】【疏文】有人問：「三藏的總稱，為何單單偏向採用『律』這個字，而戒與解脫這其餘兩個名稱卻隱沒不顯，這是有什麼用意呢？」

【117-0005】02_戒疏/01c_卷一上之一#48
【原文】【記】對名立教，釋中，初問。謂前有三名，獨標「毗尼」而入三藏，餘二不列，故問以申之。
【譯文】【記文】在對照名稱以確立教法、進行解釋的文段中，最初是提問。意思是說先前列出了三種名稱，為何唯獨標舉「毗尼（律）」來列入三藏之中，其餘兩個名稱不被採用列出，所以發問來深入申述其意。

【117-0006】02_戒疏/01c_卷一上之一#49
【原文】【疏】答：「律者，教也，能生行解。以大聖設教，具列行途，五眾依資，奉持圓德，故名戒也。依戒剋翦，業惑斯亡，名解脫也。是則因、果兩行，皆由教生，故偏舉教，用攝斯二。若舉戒藏，互不相收。又戒是行，於教不顯故也。」
【譯文】【疏文】回答說：「律，代表的是教法，能夠生起實踐的行持與理體的解悟。因為大聖佛陀施設教導，具足列明了修行的完整路徑，五眾弟子依憑資助，遵奉守持具足戒，所以稱為『戒』。依憑戒法剋制剪除煩惱，業障與惑亂從此消亡，所以稱為『解脫』。由此可知，因位的持戒與果位的解脫這兩種行相，全部是由律教所衍生出來的，因此單單標舉能生的『教法（律）』，用以統攝戒與解脫這兩者。如果單單標舉『戒藏』，戒與解脫便各自相別不能相互統攝。再者，『戒』純屬於實修的行持，單用它無法完全顯揚廣大能詮的教法全體，所以才偏向稱之為律。」

【117-0007】02_戒疏/01c_卷一上之一#50
【原文】【記】答中。先敘相生。初二句明毗尼在初。「以」下，明戒居其次。「圓德」即目具戒，名出《了論》。「依」下，明木叉最後。「是則」下，正答前問。初明偏從所以。「若」下，示餘二沒名之意，有二：一、「不相收」，行果是別故；二、「不顯教」，二皆所詮故。文且舉戒，木叉例說。
【譯文】【記文】回答的文段中。首先敘述三者相輔相生的次序。前兩句說明「毗尼（教）」居於最先。「以」字以下，說明「戒（行）」位居其次。「圓德」是指具足戒，名詞出自《了論》。「依」字以下，說明「木叉（果）」位列最後。「是則」以下，正式回答前面的提問。首先說明偏向採用律教命名的緣由。「若」字以下，揭示其餘兩個名稱隱沒不顯的原因，共有兩點：第一、「不相收」，因為實修行持與所證極果彼此有別不能相統；第二、「不顯教」，因為這二者都只是被教法所詮釋的內容。經文中暫且拿「戒」來舉例，「木叉」亦可依此例推知。

【117-0008】02_戒疏/01c_卷一上之一#51
【原文】【疏】問：「若如此言，則半月說，應云『律藏』，何云『戒經』及『木叉』耶？」
【譯文】【疏文】有人問：「如果照這樣說，那麼半個月一次的僧團布薩說戒，就應當稱之為說『律藏』，為什麼反而稱為說『戒經』以及『木叉』呢？」

【117-0009】02_戒疏/01c_卷一上之一#52
【原文】【記】轉難中。「戒經」之語，徧在《戒本》；「木叉」之名，標下「序」首。「律」既總收，何獨不舉？
【譯文】【記文】在轉接詰難的文段中。「戒經」這個字眼，普遍散見於《戒本》之中；「木叉」這個名詞，則標舉在下文序文的開頭。「律」既然能總體統攝一切，為何在布薩說戒時唯獨不標舉它呢？

【117-0010】02_戒疏/01c_卷一上之一#53
【原文】【疏】答：「如上已解，須通玄意。三藏之說，經遠大歸。半月常聞，偏被時眾；羅列罪目，即警行緣；何得舉教，其義舒緩？依承脫縛，舉果動心，並是教詮，故通歸行。」
【譯文】【疏文】回答說：「正如上面已經解釋過的，必須融通教法深奧幽玄的核心本旨。三藏的命名安立，是著眼於長遠久住的整體宏觀歸趣。而每半月常規聽聞的布薩，則是特別用來加被臨場參與的當前僧眾；一一羅列各項罪名條目，正是在當下警惕激發修持的緣起；這時候怎能僅僅標舉空泛的教理框架，使教導的義理顯得拖沓鬆散呢？依憑承持戒律以解脫繫縛，藉由標舉極果來撼動策厲自心，這全都是教法所詮顯的實踐，因此在布薩時全部歸趣於實修的『行持』。」

【117-0011】02_戒疏/01c_卷一上之一#54
【原文】【記】答中。初二句通示。指「如上」者，即教興中。「玄」，猶深也。「三」下，正釋。初明三藏從教意。謂令久學識其大趣，非同說戒即座警䇿，故云「經遠」等。「半」下，正答說戒舉二名意，初明舉戒意。戒能成行，故云「行緣」。「依」下，次明木叉意。戒文「舉果」，亦歸「警行」耳。
【譯文】【記文】回答的文段中。前兩句做總體開示。所指的「如上」，就是指教法興起章節中的內容。「玄」就是深妙之意。「三」字以下，正式解釋。首先說明三藏名稱依從教法命名的意涵。是指讓長久修學之人能了知佛教宏大的旨趣，並非等同於臨場說戒時需要當座警策策勵，所以說「經遠」等。「半」字以下，正式回答說戒時標舉戒與木叉這兩個名稱的深意，首先說明標舉「戒」的用意。因為戒能夠成就實修之行，所以說「行緣」。「依」字以下，次而說明標舉「木叉」的用意。戒文「舉果」，也是歸結於「警惕實修之行」罷了。

【117-0014】02_戒疏/01c_卷一上之一#57
【原文】【疏】有人解云：「兩舉因、果，同目於教。」今解不爾，聖說不徒，終有遠致，豈浮涉也？

【原文】【疏】若據緣本，其流「上座」，何以知耶？大迦葉波初秉宗教，將事集法，簡練通德故。五百無學，《智論》千人，並是釋門達化之士，故號斯侶名為「上座」。如《律》中說：「結後召眾重述前法。時大眾曰：『佛是智人，立法須定，何得開制？』迦葉告曰：『由是智人，制已更開，開已還制。』」自非達化，何以明斯？故得任持三藏御世。如《部執》解，於佛滅後夏竟涅槃。《大悲》、《智論》咸陳滅相。如《付法藏傳》說，付法與阿難等。
【譯文】【疏文】如果追溯這一脈派系的源頭本底，它正是流傳自「上座部」，憑什麼知道呢？大迦葉尊者起初執掌佛陀的宗教大法，將要著手結集經律之時，極其嚴格地甄別挑選了通達六通且戒德圓滿的聖僧。這五百名無學阿羅漢（《大智度論》則說是千人），全都是釋迦教門中深達佛陀化導機宜的傑出人物，因此尊稱這群長老聖侶為「上座」。正如《四分律》中記載：「結集圓滿之後大迦葉召集大眾，重新重述宣講剛結集的法規。當時有大眾長老提出質疑：『佛陀是具足大智慧的人，創立法規必須恆常確定，怎能開許之後又禁止、制定之後又開許呢？』大迦葉回答說：『正因為佛陀是具足大智慧的人，才會在制定戒律之後又依緣開許，開許之後又依緣重新禁止。』」若非親身體認達通佛陀深邃化導的智者，怎能闡明這個道理？因此大迦葉能夠主持護持三藏教法以統理化導世間。如同《異部宗輪論（十八部執論）》所解釋，尊者在佛滅度後的首個結夏安居結束便示寂入滅。《大悲經》、《大智度論》都詳細陳述了他入滅入定時的神異景象。又如同《付法藏因緣傳》所載，大迦葉臨入滅前將正法眼藏交付付囑給了阿難尊者等人。
