# 校閱材料　第362檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【362-0001】資持記/03a_上二#62
【原文】然圖中標為戒壇者，謂於場中別更封土。若據初開，未必有壇。所以律中約通從本，但云場耳。三標內外，尋圖可見。敘意中，初示意。今下，斥世，上二句通斥愚暗。漠落，喻不明也。曾下，出不明之相。定下，決破。必下，誡慎。觀夫祖訓極明，人誰不讀。及乎臨事，還溺此迷。豈非妄習積深，良醫莫治。
【譯文】然而圖中標示為「戒壇」，是指在戒場之中另外加高築土成壇。如果依據最初開許的體制，未必築有高壇。所以律中依循通常體制、順從根本名稱，僅僅稱為「場」而已。三道標相的內界與外界，查閱圖示即可清楚明瞭。在敘述用意中，首先展示本意。「今」字以下，斥責當世弊端，上兩句普遍斥責僧人的昏庸愚暗。「漠落」是比喻模糊不明、混亂不清。「曾」字以下，列舉不明界法的具體相貌。「定」字以下，斷然予以破除瓦解。「必」字以下，嚴正告誡謹慎。綜觀祖師的訓示極為顯豁明瞭，哪個人沒有讀過呢？但是一到了臨事之際，卻又再次沉溺在這種昏迷之中。這難道不是妄想積習太深，連良醫也無法救治嗎！

【362-0002】資持記/03a_上二#63
【原文】今略引示，幸宜改之。謂主法者一月已前，自錄界相，令他暗誦。唱者未甞目覩，同住都無曉知。而乃對眾執文，號為證相；秉燈數字，不使差訛。側耳尋聲，莫知方詣。況自然分齊，曾不觀量；作相集僧，寧思足別。白告則巧莊對偶，不異伶倫；秉結則引弄音聲，便同歌伎。
【譯文】如今大略引導昭示，希望諸位有幸及早改過。往往是主持僧法的主法者在一個月之前，自己私下抄錄了界相，命令他人暗中背誦。去唱界相的人從未親眼目睹標相實地，同住的僧眾也完全無人知曉。卻在眾人面前拿著文稿，號稱是「印證界相」；拿著油燈逐字照讀，生怕字音出現差錯。旁人側耳尋聲傾聽，根本不知道方位邊界究竟指向何處。何況對自然界的界限範圍，何曾實地進行過勘量；設立標相、召集僧眾時，哪裡還會思索人數是否足夠或構成分黨別眾。白告羯磨時則刻意修飾對仗詞句，與伶人樂師毫無分別；秉宣結界時則拖長玩弄腔調音聲，便如同歌妓一般。

【362-0003】資持記/03a_上二#64
【原文】唯念明晨散席，坐位高低；更憂請主相酬，施利多少。如斯罔世，非是一朝。誤彼大緣，自沈萬劫。來學有恥，極須誡之。圖中，圖相。正意為分三標，令唱法易見。二復示前無場唱法。三明穿牆之相。四明自然體圓。五明相望作法自然遠近。六明循門出入離過。
【譯文】只惦念著隔天散席時座次的高低，更憂心施主酬謝的財利有多少。像這樣欺罔世人，已經不是一朝一夕；耽誤眾人的大事，自己沉淪萬劫。後來學戒的人若還有羞恥心，極須以此為誡。圖中的圖相：主要用意是為了劃分出三種標相，使唱相時容易辨識；二是再示沒有戒場時的唱法；三是說明穿牆之相；四是說明自然界的體圓；五是說明相望作法時自然界的遠近；六是說明循門出入以免犯過。

【362-0004】資持記/03b_上二#1
【原文】七大小二牆，絣繩釘杙，為顯一標兩相。八復示標通大小，不必一肘。九明中隔自然，隨物可分。十明大牆外唱，不相錯涉。略求十意，餘更尋之。注中。初明自然者，以結場時更出西南，別取步量。圖中不可雙示，故特點之。遠近中，先明自然。若下，示作法。餘界中。點示同別。
【譯文】第七，在內外兩道大、小矮牆處拉繩釘樁，是為了清楚標明「一個界標、兼具內外兩種界相」。第八，再次說明界標通於大界與戒場，長度不必硬性規定為一肘。第九，說明兩者中間所隔開的自然界，隨周遭地物即可劃分。第十，說明應在大牆外側唱告界相，讓內外界相不致相互交錯牽扯。此處僅略舉十種用意，其餘細節可再行推求。註文當中：起初說明自然界，是因為結戒場時還須向西南方跨出，另外測量步數；在圖中無法同時完整呈現兩處，所以特別加點標示。說明距離遠近的文字中，先解釋自然界；從「若」字以下，則是說明僧團作法的規矩。至於其餘各界，是加點標明它們相同與相異之處。

【362-0005】資持記/03b_上二#2
【原文】唯可分聚一向為別。餘之四種，廣狹雖別，周圓則同。問：前定自然各半減取，唯約不可分別聚落，餘五如何？答：疏云：此一既爾，餘之自然大小乃殊；例有通局，皆半約之。〔異界已分，共論為通，各半名局。〕然可分聚落，唯局不通；以僧在外，既非同聚；
【譯文】只有可分別聚落純粹屬於「各自有別」。其餘四種自然界，範圍寬狹雖然不同，但以自身為中心、向外圍繞成圓形則是一致的。有人問：前面規定自然界以各取一半來扣減劃界，只針對不可分別聚落，那麼其餘五種又該如何？回答：《業疏》解釋說，不可分別聚落既然如此，其餘自然界的大小雖然不同，但依例都有「全體共用」與「各取一半之局限」兩種情況，全都要依折半的原則來裁定。〔當不同界域已經劃分，合在一起論述時稱為通；各自折半劃取時稱為局。〕然而可分別聚落只屬於局限而不能共通；因為僧眾身在聚落之外，既然彼此不屬於同一個聚落；

【362-0006】資持記/03b_上二#3
【原文】自有別界，餘皆同處各半可知。釋中，自然界相。不必定圓，示知別相。戒場中三，初示場體。中下，二明中隔自然，初二句通標。東下，先示東北。言下上者，下即牆際，上謂地面。次明西南，初示竪標。云尺八者，不必可知。後南西下，明結已作法。若論說恣，即須通集。其戒場下，三示場外相。
【譯文】各自本就具有獨立的界域，其餘自然界則都是在同一處所各取一半，其理自明。解說之中，自然界的形相不一定非得是正圓形，此處是為了讓人明瞭它與眾不同的特點。戒場部分分為三段：第一段標示戒場本體。從「中」字以下，第二段說明中間所隔開的自然界，開頭兩句為通體標示。從「東」字以下，先標明東北方。文中說到「下、上」，「下」是指矮牆的邊緣基底，「上」則是指地面。接著說明西南方，先標明直立界標。文中提到的「一尺八寸」，不必死守其數，其理自明。其後從「南西」以下，說明結界完畢後的作法；若談到說戒與自恣，就必須召集全體僧眾。從「其戒場」以下，第三段標示戒場的外側界相。

【362-0007】資持記/03b_上二#4
【原文】大界相中，初示內相。若下，明外相。此圖不通內唱，特示西南相涉，令識過相。又下，恐避參涉而穿牆心唱。故此遮之。結示中，初二句結前。一緣者，通指圖相。作下，示不定。若下，明須立。結法中，初明前後。以昔相傳後結戒場，人猶執舊，故須決破。
【譯文】大界界相之中，先標明內側界相。從「若」字以下，說明外側界相。這幅圖不允許在內側唱相，特別標示出西南方容易互相涉入的狀況，是為了讓人認清錯誤的過患。從「又」字以下，是擔心有人為了避免牽涉不清而穿過牆體中心去唱相，因此在此預先加以防堵遮止。結尾提示中，前兩句總結前文。「一緣」這句話，是通指整體的圖形界相。從「作」字以下，說明作法並不固定。從「若」字以下，說明必須建立的原因。結界方法中，先說明先後順序；因為過去相傳都是後結戒場，世人仍舊執著於舊說，所以必須加以決斷破除。

【362-0008】資持記/03b_上二#5
【原文】引據中，先引《五分》，上二句示正法。若下，明倒結。先結大界者，示忘誤也。當捨者，解二界也。更前結者，即戒場也。更字去呼，望前重也；亦可平呼，改前倒也。然後下，即大界也。毘尼下，略指二論。同故不引。《母論》第一云：結界法先結小界，後結大界；
【譯文】引證依據中，先引用《五分律》，前兩句開示正確的結法。從「若」字以下，說明倒反顛倒的結法。所謂「先結大界」，是表示遺忘或出現差錯。「應當捨棄」，是指將兩個界都加以解除。「再次在前面結」，指的就是戒場；「更」字讀作去聲，是相較於前面而言屬於重新再做；也可以讀作平聲，意為改正前面的顛倒錯誤。從「然後」以下，指的就是大界。從「毘尼」以下，略微指出兩部論典；因為內容相同所以不全引。《毘尼母論》第一卷說：結界的方法，應當先結小界，之後再結大界；
