# 校閱材料　第1777檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1777-0001】03_業疏/15a_卷三之四#44
【原文】問：何以不立一無作戒，及以三者
【譯文】問：為什麼不單單建立一種無作戒，或者建立三種戒呢？

【1777-0002】03_業疏/15a_卷三之四#45
【原文】次科問多少中，問意欲顯唯二所以
【譯文】在次一科詢問數量多少的內容中，發問的用意是想顯明唯獨建立二戒的緣由。

【1777-0003】03_業疏/15a_卷三之四#46
【原文】答：事義相假，故唯有二。何以明之？若唯立作，但在一念，非通一形，何能防也？一受已難，義非數作，故須無作長時能防。念念之中得未曾得，故若但無作，不能自生，要由作發。以作防非則短，無作起無所從，二法緣具，作願方遂
【譯文】答：事相與義理相互假借依託，所以唯有這兩種戒。何以明了這一點？如果只建立作戒，作戒僅在一念之間，不能通貫一生盡形壽，如何能夠防非止惡呢？一經受戒已很難得，在義理上不可能頻繁重複去作，所以必須有無作戒體能長時防護。在每一個心念之中任運增長得到未曾有之善法，因此如果只有無作戒，無作戒不能自然憑空產生，必須依賴作戒的動作表業來引發。因為作戒防非的時間短促，而無作戒若無作戒引發則無從生起，二法因緣具足，當初誓作之願才能圓滿成就。

【1777-0004】03_業疏/15a_卷三之四#47
【原文】正答中初總示。「何」下別釋。前明須無作意：一則作戒時短，由作法竟剎那即謝，故但至一念；二者作戒唯一念，義無頻數。「念念中」者，謂隨中防遏；「得未曾得」謂任運增新。「若但」下後明須立作意，以下雙結
【譯文】在正面回答中，首先作總體提示。「何」字以下作分別解釋。前段說明必須有無作戒的用意：第一是因為作戒的時間短暫，作法完成之後一剎那間隨即謝滅，所以只延續到那一念；第二是因為作戒只有一念，在義理上不能頻繁重複造作。「念念中」，是指在隨行之中恆常防範止遏過非；「得未曾得」，是指任運增長嶄新的善功德。「若但」以下，後段說明必須建立作戒的用意，再往後則是作戒與無作戒雙雙結語。

【1777-0005】03_業疏/15a_卷三之四#48
【原文】上據下機，故說相藉；必如聖戒，道力所成
【譯文】以上是依據下位凡夫根機而言，所以說作與無作二者相互依藉；假使是聖人所得的道共戒等，則是由聖道之力任運成就的。

【1777-0006】03_業疏/15a_卷三之四#49
【原文】對簡中，上明二法相藉，乃據羯磨受者為言。若見諦破結自誓之徒，斷證之時，任運獲得。據發無作，必有先期，但不同凡多緣多力耳
【譯文】在對比簡別中，上面闡明作與無作二法相互依藉，是依據通過羯磨作法受戒的人來說的。如果是見諦斷結、自誓得戒的那類聖者，在斷除煩惱證得聖果之時，自然任運獲得戒體。就發起無作戒體而言，聖者必定也有先前的期許誓願，只是不像凡夫那樣需要藉助諸多外緣與多種造作之力罷了。

【1777-0007】03_業疏/15a_卷三之四#50
【原文】問：既立二戒，何不三合
【譯文】問：既然建立了作與無作二戒，為什麼不把兩者合併建立第三種作無作合呢？

【1777-0008】03_業疏/15a_卷三之四#51
【原文】問三合中，問意以無作體或與作俱，合立第三作無作合
【譯文】在詢問合立第三合句的科節中，發問的用意在於認為無作戒體有時與作戒同時並存，可以合起來建立第三種作無作合。

【1777-0009】03_業疏/15a_卷三之四#52
【原文】今解：不可以法體唯二，名實互乖。廢體論名，不無三合；今據實論，故唯分二，不可合也。一、作者是色心，無作非色心；二、作者初緣，無作後業；三、作是運動，無作非故。如是長短、強弱、性不均通，理不三合。故律中慈、瞋五句無第三者，可以類說。此約體論唯斯二戒，對彼所防，如上廣說
【譯文】如今解釋道：不能如此，因為法體實質唯有兩種，若立第三則名與實相違。如果拋開法體只在名義上論說，不妨有第三種相合之名（作無作合）；現在是依據真實體性來論定，所以唯獨分為作、無作二戒，不可相合立第三。原因有三：第一、作戒是色法與心法，無作戒則非色非心；第二、作戒是最初的造作緣起，無作戒是隨後的任運業體；第三、作戒是運動造作，無作戒則不是運動。像這樣長短、強弱、體性各不齊等融通，在義理上絕無可能合為第三句。所以律中慈心、瞋心等五句中都沒有雙俱的第三句，可以用這個道理來類推說明。這是就戒體而言唯有這兩種戒，若對望於所防之過境，則如上文所廣泛論述的那樣。

【1777-0010】03_業疏/15a_卷三之四#53
【原文】答中，必應他師有立此句，故標今解。初立義，名雖可立，體無合理，故云不可。「一」下次顯別，有三：一即自性別，二謂起時別，三即體相別。「長短強弱」等結上三別，無作長強，作則短弱。「均」，和也。「故」下引類，即《增一》文。彼云有五句語無第三句：一時、非時，此句無第三句；二實、與不實；三損減、利益；四麤獷、柔和；五嗔恚、慈心。並無第三句，謂二種性別，不可立第三合句也。「此」下結示所立。此約體論，謂能防受體無出此二；所防無量，文見前答
【譯文】在答文中，必定是因為其他法師有立「作無作俱」這一句，所以標出「今解」以示辨析。首先確立論點，指出名義雖然可以假立，但在體性上沒有相合的道理，所以說「不可」。「一」字以下其次顯明兩者的差別，共有三點：第一是自性差別，第二是生起時間差別，第三是體相差別。「長短強弱」等語總結上述三種差別，無作戒長而強，作戒則短而弱。「均」，就是和順齊等的意思。「故」字以下引同類之義作證，就是《增一阿含經》的經文。經中說有五組語句沒有第三句：第一、應時與非時，此句沒有第三句；第二、真實與不實；第三、損減與利益；第四、粗獷與柔和；第五、瞋恚與慈心。這五組都沒有第三句，是說兩種體性相違背，不能建立第三種相合之句。「此」字以下結語指示所建立的義理。這是就戒體來論述，意指能防範的受戒戒體不出這兩種；至於所防範的境界則是無量的，相關文字詳見前面的答文。

【1777-0011】03_業疏/15a_卷三之四#54
【原文】二引證門
【譯文】第二、引述經論作證之門。

【1777-0012】03_業疏/15a_卷三之四#55
【原文】如《涅槃》云：戒有二種，謂作、無作。是人唯具作戒，不具無作，是則名為戒不具足
【譯文】如同《大般涅槃經》所說：戒有兩種，也就是作戒與無作戒。這個人如果只具備作戒而不具備無作戒，這就叫做戒不具足。

【1777-0013】03_業疏/15a_卷三之四#56
【原文】引證中，《涅槃》「唯具作不具無作」，謂輕浮心受者
【譯文】在引文作證中，《涅槃經》所說的「唯具作不具無作」，是指以輕浮之心受戒的人。

【1777-0014】03_業疏/15a_卷三之四#57
【原文】又《善生》云：是十種法，或有作色無無作色，或有作色及無作色，如人手執極香臭木
【譯文】又如《優婆塞戒經》（善生經）說：這十種法，有的只有作色而沒有無作色，有的既有作色也有無作色，如同人手中拿著極香或極臭的木頭。

【1777-0015】03_業疏/15a_卷三之四#58
【原文】善生》中初示有無。十種法即十業道。如下舉喻，極香臭物喻善惡業，手執喻作色，放物有餘香臭即喻無作色，木喻無記業，但有執持而無餘氣，對合可見
【譯文】在《優婆塞戒經》引文中，首先指出有與無。十種法就是十業道。如下文所舉的比喻，極香、極臭的物品比喻善業與惡業，手拿著物品比喻作色，放下物品後手上仍留有餘香或餘臭就比喻無作色，木頭比喻無記業，手中雖然執持過卻沒有留下氣味，將比喻與法義對照結合即可明了。

【1777-0016】03_業疏/15a_卷三之四#59
【原文】又《心論》云：第三羯磨一剎那頃，作及無作是名根本業道
【譯文】又如《阿毘曇心論》所說：第三度羯磨念畢的那一剎那間，作戒與無作戒就稱為根本業道。

【1777-0017】03_業疏/15a_卷三之四#60
【原文】心論》中，一剎那時作戒滿足，無作發現。根本業者，望前後方便為言。彼云：如沙彌受具，入戒場禮僧求和尚，乃至第二羯磨皆是方便，即接今文。又云次說四依乃至身口所作及無作，是名為後
【譯文】在《阿毘曇心論》引文中，那一剎那之時作戒圓滿具足，無作戒體隨之顯發。所謂「根本業」，是相對於前行與後續的方便而言。該論說道：好比沙彌受具足戒，進入戒場禮拜僧眾、祈求和尚，乃至第二度羯磨為止，全都是前方便，隨後即銜接此處的引文。該論又說隨後宣說四依法，乃至身口所生起的作戒與無作戒，這稱為後續方便。

【1777-0018】03_業疏/15a_卷三之四#61
【原文】如是多文，證唯有二
【譯文】像這樣諸多的經論文字，證明戒體唯有作與無作這兩種。
