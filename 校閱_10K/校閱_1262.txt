# 校閱材料　第1262檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1262-0001】資持記/12c_中四下#15
【原文】宗計各異，不可輒用。誤作中，出相分三，初通示三業。如下，舉事顯相。律下，引證，初句總標。比丘下，別釋。文中不出三業，初並身業，語默口業，一心即意業；身口是別，意業為通。又前身中不出四儀，內外資緣便利睡臥等，括盡日事，皆須攝心。眠睡語重，止是一事；律作睡眠覺悟是也。
【譯文】各宗派的主張既然不同，便不可輕率照搬套用。在過失誤犯的作法中，列出罪相共分為三段：第一段總體開示身、口、意三業。「例如……」以下，是列舉具體事相來顯明罪相。「律文……」以下，是引用律文作為證明，第一句是總括標明。「比丘……」以下，則是分別解釋。文中雖然未明言三業名稱，但起初所列皆屬身業，說話或沉默屬於口業，專注一心則屬意業；身業與口業是個別的表現，意業則是貫穿其中的主導。又前面身業之中，不外乎四種威儀、內外資生物資、大小便利、睡眠起臥等，囊括了整日生活瑣事，全都必須攝受心念。文中提到「眠」又提到「睡」，詞語重複，其實只是同一件事；正如律本中所寫的「睡眠與覺悟」就是指這件事。

【1262-0002】資持記/12c_中四下#16
【原文】若違下，示犯。準此有犯並須責心，故知真出家人，無時忘念。此制微細，逗彼上根；末世下愚，故非力分。準如《母論》，衣食作觀，利根之人，著著口口；鈍根，總作一念；然須勵力，望上增修；未可自屈，甘為下根，便即縱怠。故當勤策，準此攝修，是則出家不徒然矣。
【譯文】「如果違犯……」以下，是指出犯罪的情形。依照這個規定，只要有所違失全都必須責心悔過，由此可知真正的出家之人，沒有一刻可以失卻正念。這種戒律規制極其微細，是為了投合那些上根利智的人而設；末法時期的下愚之人，確實不是能力所能企及的。依照《摩得勒伽論》的說法，受用衣服飲食時應當作正念觀察，利根之人每穿一件、每吃一口都能作觀；鈍根之人，則在整體受用時生起一次正念即可；然而大家仍須自勉發奮，向著上等根基增進修行；切不可自甘菲薄，甘心淪為下根之人，隨即放縱懈怠。因此應當勤勉自勵，依照此法攝心修持，這樣出家才不算虛度一生。

【1262-0003】資持記/12c_中四下#17
【原文】問：誤心迷忘，即不可學，那得結罪？答：凡誤有二，一者對境迷心，二則放情忽忘；諦知兩相，想必無疑。作法中，初悔從生。即覆藏等。後根本中。止有二法。一對靈像具儀露過，義同請主說罪兩緣；二陳悔詞，即正捨罪；雖無呵誓，理當自責；後更無違，還同三法。
【譯文】問：失誤之心屬於昏迷忘失，根本無從預先學習防備，怎麼能夠結罪呢？答：大凡過失有兩種：第一種是面對境界時心意昏迷，第二種是放縱心性隨意而忽然忘失；若能切實明瞭這兩種情狀的分別，心中想必就不會再有疑慮了。在作法之中，第一先懺悔衍生之罪，也就是指覆藏等罪。其後在懺悔根本罪時，僅有兩項法度：第一是面對佛像端肅儀表、發露過錯，這在義理上等同於延請懺悔主與陳說罪相這兩個緣起；第二是陳述悔過詞句，這就是正式捨除罪業；雖然形式上沒有懺主的呵責與自己的立誓，但理當在心中深切自責；從此以後不再違犯，在意義上還是等同具備了捨罪、呵責與立誓這三法。

【1262-0004】資持記/12c_中四下#18
【原文】餘準此者，且舉一法類通一切故也。〔若準《戒疏》，眾學諸戒故心犯者犯二罪，一應懺吉，對首悔；二非威儀吉，責心悔。準此責心不必誤犯，學者詳之。〕若彼《了論》，但云不應起如此心，即名責心；然無軌式，不足準用。第二發露法。識疑兩露，該通六聚；相從事類，寄此明之。
【譯文】所謂其餘皆比照此例，只是暫且舉出一種方法，以類推貫通一切懺法罷了。（如果依照《四分律戒疏》的說法，眾學法中的各條戒若是故意違犯，會結兩種罪：一是屬於應當懺悔的吉羅罪，須對首悔過；二是屬於違失威儀的吉羅罪，須責心悔過。依照此說，責心悔過未必只限於過失誤犯，修學者應當仔細審查。）至於那部《波羅提木叉了論》，只說心中默念「我不應該生起這樣的心念」，就稱為責心悔過；然而它缺乏正式的儀軌法則，不足以作為我們依循的準繩。第二項是發露罪過之法。確知已犯與懷疑有犯這兩種發露，通貫於六聚一切罪法；因為屬於同類事相，所以寄託在此處一併說明。

【1262-0005】資持記/12c_中四下#19
【原文】識罪中，初示法。此下，次簡辨；初簡覆露差別又三，初明即露。若已下，次明後露。若雖下，後明重露。若犯下，二簡所免罪相。準覆六聚，犯通一吉。疑罪中，初指具儀。應下，示詞句。若說戒座上，亦有識疑兩露，如〈說戒〉中。第三重示中二，初引《智論》，先明化制兩業不同。如下，舉戒顯相。
【譯文】在確知犯罪的發露中，第一先展示作法。「自此……」以下，其次是進行簡別辨析；首先簡別覆藏與發露的差別，這又分為三段：第一說明當下立即發露。「如果已經……」以下，第二說明事後才發露。「如果雖然……」以下，第三說明反覆重新發露。「如果犯了……」以下，第二是簡別得以免除的罪相。依照覆藏六聚罪的通則，所犯的覆藏罪一律通屬於一重吉羅罪。在懷疑犯罪的發露中，第一先指明應具足的儀表體態。「應當……」以下，是展示陳白詞句。如果在宣說戒相的法座上，同樣也有確知與懷疑這兩種發露方式，這正如〈說戒篇〉中所載。在第三項重新提示之中，分為兩部分：第一引述《大智度論》，先說明教化性業道罪與戒律制裁罪兩種業報的差異。「例如……」以下，是舉出具體戒條以顯明相狀。

【1262-0006】資持記/12c_中四下#20
【原文】謂提罪雖滅，業道猶存。前下，示重明之意。餘下，指廣，亦即凡聖行法。明儀式中，初引《善見》明稱召。大小不同者，此亦一往以分；若就通相，德重為長，臘高名老。次明禮法。初《四分》。明大小具缺，小者於上座具五，上座於小者但四。
【譯文】這是指單墮罪雖然在律儀上已經滅除，但造業輪迴的業道因果依然存在。「前文……」以下，是說明重新申述此理的用意。「其餘……」以下，是指引參閱詳盡的文獻，那同時也是凡夫與聖者通用的行持之法。在說明儀式之中，第一引述《善見律》來說明彼此的稱謂與呼召。大僧與小僧的稱呼不同，這也是姑且大略劃分；若就通融的實況而言，凡是德高望重者稱為「長」，戒臘年長者名為「老」。其次是說明禮敬之法。第一引述《四分律》，說明尊卑之間禮儀的具足與減省，地位較低者對上座必須具足五種禮法，上座對地位較低者只需四種。

【1262-0007】資持記/12c_中四下#21
【原文】言五法，謂偏露右肩，脫革屣，禮足，互跪，合掌也。《十誦》。亦同《四分》，而闕合掌。捉足即是設禮，然今不必手捉，但作仰承之勢耳。如悔過者，謂同從尊謝過之相；欲清淨即傳欲時，受歲即自恣，出罪即悔六聚；餘諸乞法，皆準此儀，故云等也。上明具儀之相。
【譯文】所謂五種禮法，是指偏袒右肩、脫去革履鞋靴、頂禮雙足、單膝著地互跪、合掌致敬。《十誦律》的規定也與《四分律》相同，唯獨缺少合掌一項。用手抓握尊者之足便是行禮之法，但現在不一定非得用手抓握不可，只需做出雙手仰起承接的姿態即可。所謂「如同悔過時的儀容」，是指如同隨順尊長向其謝罪時的容貌姿態；傳送「欲清淨」就是指托付欲意之時，「受歲」就是指自恣羯磨，「出罪」就是指懺除六聚罪愆；其餘各類乞求僧事的法度，全都要參照這套儀式，所以文末說「等等」。以上是說明具足威儀的相狀。

【1262-0008】資持記/12c_中四下#22
【原文】有下，示數犯之人。四句括情，情可見矣。通結中，初句指所詮。次句示所被。舒下，顯略。幸下，勸修。四分律行事鈔資持記中四下
【譯文】「有……」以下，是指出頻繁犯戒之人的情狀。律文用四句法總括了眾生的情執心態，其情執之相已經彰顯易見了。在總結全文之中，第一句是指明本部律文所詮述的教理，第二句是展示其所教化的對象。「延展……」以下，是顯明本文略去繁複、提綱挈領的用意。自「希望……（幸）」以下，是勸勉大家精勤研習修持。《四分律行事鈔資持記》第四卷下半部至此結束。
