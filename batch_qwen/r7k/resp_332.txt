整體讀來通順、大體忠實，沒有漏譯。問題集中在**幾處誤讀**、**幾處把註解寫進正文的增譯**，以及**律學術語未加注**。分項如下。

---

## 一、明顯要改的

**1.「自非極病」——誤把「自」讀成「自己」**
- 譯文：「**自己**若非患了極重之病，實在難以入口。」
- 「自非」是複合連詞，等於「若非、除非」（如「自非亭午夜分」），與「自己」無關。
- 建議：「**若不是**極重之病，實在難以（忍心）入口。」

**2.「除五種人」——原文只列四種，譯文硬湊第五種並自行補字**
- 原文：「除五種人：遠行人、病人、食少不足人、不得食人；**若施水處，和水飲之**。」
- 譯文把「若施水處，和水飲之」改寫成「以及在施水處（**渴乏**）之人」，既補了「渴乏」，又把一個獨立句式併入人名清單，連「可調和水來飲用」也變成五種人共通的開緣。
- 建議：照原文結構譯——「除五種人〔按：文中僅列四種，第五或即施水處者，或疑有脫文〕：遠行人、病人、食少不足人、不得食人；又若在施水之處，可和水而飲。」存疑處以注處理，不要在正文補齊。

**3.「不令麁現」——「貪」字是添加的**
- 譯文：「但食用時不可顯露**粗重貪相**。」
- 「麁現」是顯露粗（食）之相：這五種世人既當食物吃（如飯、乾飯），非時服用時須細微而服，不使如進食般的粗相顯露。與「貪」無直接關係。
- 建議：「但服食時不使粗（食）相顯露。」另「（能充飢滋益）」也是增譯，宜移到注中或刪。

**4.「火大熟病」——「熟」疑為「熱」之訛，譯文「熱熟病」不成詞**
- 建議：「火大（引起）的**熱病**用酥治」，並出校注「熟，疑當作熱」。

**5.「風大百一用油脂治」——「油脂」是兩物，不是一個現代詞**
- 此处指「油」與「脂（動物脂肪）」，正承上文《僧祇》加脂、《四分》五脂而來。譯成「油脂」會被讀成單一的油膏。
- 建議：「用**油與脂**治」。同理「雜病用上三藥治之」的「**合用**」也宜改為「用上列三種藥對治」（原文未必要求併用）。

**6.「此藥清淨」的「此藥」宜點明所指**
- 承上《僧祇》加脂、五脂而來，「此藥」當指**脂**類。逕譯「此藥」讀者易誤會泛稱五藥，建議作「此藥（脂）」。

## 二、增譯／可斟酌處

| 原文 | 譯文 | 說明 |
|---|---|---|
| 食上多得酪 | 「在**供僧**食中」 | 「食上」＝進食時、受食時，「供僧」是添加 |
| 動作生穌 | 「**攪動提煉**為生酥」 | 「動作」＝製作成；工法說明可留，但屬增譯 |
| 細緻㲲 | 「細密**白**布」 | 㲲（氎）＝棉布，宜作「細密棉布」；「白」可注不必入文 |
| 即煮取油 | 「熬煮**榨**取其油」 | 「榨」為添加 |
| 兼得必彊力劫掠辨之 | 「強力**摧毀蜂巢**劫掠而來」 | 「辨」＝「辦」（辦得）；劫掠對象是蜂所積之蜜，「摧毀蜂巢」宜刪或入注 |
| 此中淨物生 | 「這裡面生出淨物」 | 記識是**預先**宣告，宜作「此中（將來）會生出淨物（酥／油）」 |
| 蜜味美重 | 「甘美**濃重**」 | 「重」或指為世所貴重、或指味厚，可兩存；不宜遽定 |
| 凡聖常言 | 「凡夫聖者常言 **：**」 | 加冒號變成引語，改「凡夫與聖者都常說」較穩 |
| 如上進不 | 「決定進止」 | 可通（不＝否），但宜注「謂依上例定其可否」 |
| 過時是名不淨 | 「過了正午」 | 依上文「中前」判斷應是過日中，可加注「過時：過了日中之限」，以免與「過七日」混 |
| 貧病比丘 | 直譯 | 語意略突兀，可注「貧乏而病、無力另得藥者」 |
| 八日犯捨 | 「到了第八天便犯捨墮」 | 建議「若延至第八日（仍服／仍畜），即犯捨墮」，語意更足 |

「無蜂熟蜜」建議注一句背景（獼猴獻蜜，中有蜂子，佛不受；去蜂子後乃受），並注「熟蜜」或指蜂釀熟之蜜，非人工煮熟；否則末句「等」字與全文「勿劫掠」的論旨接不上。

## 三、術語與體例

1. **《善見》≠《善見律》**：應作《善見律毘婆沙》（亦稱《善見論》），是律的注释書。
2. **《伽論》**：即《摩得勒伽論》（《薩婆多毘尼摩得勒伽》）。譯文用《摩得伽論》與鈔中「摩得伽」一致，可，但首見宜出全名。
3. **首見宜加注的关键词**：七日藥（作法受持後可於七日內服食之藥）、石蜜（甘蔗汁熬成的硬糖塊）、非時（日中後至翌日明相未出）、時內（明相出至日中）、受持／作淨／記識（三種作法，宜保留原詞並簡注）。
4. 原文「穌」即「酥」；《四分》五藥之「酥」一般解為熟酥，譯文作「熟酥」可，但宜注「原文作酥」。
5. 「捨墮（尼薩耆波逸提）」的展開、「四百四病」的處理都得當，可保留。

## 四、修訂參考譯文

所謂七日藥（作法受持後得於七日內服食之藥）：

《四分律》：酥（熟酥）、油、生酥、蜜、石蜜（甘蔗汁熬成的硬糖塊）等五種，為世人所熟知，既可當食物、也可當藥物，如同吃飯、乾飯一般；但服食時不使粗（食）相顯露。《摩得勒伽論》：糖漿也可受為七日藥，只要尚未捨失本性（未變質轉成他物）。《摩訶僧祇律》再加「脂（動物脂肪）」一種。《四分律》：舍利弗患風病，醫家教他服五種脂，即熊、羆（棕熊）、豬、驢、魚等之脂。《僧祇律》：此藥（脂）體性清淨，無時食（正食）的氣分；一次受持，可服七日。人有四百零四病：風大的一百零一病用油與脂治，火大的熱病用酥治，水病用蜜治，雜病則用上列三種藥對治。

《五分律》：（比丘）見人製作石蜜時，把米搗碎摻入其中（因而生疑）；佛說：製法本應如此。若合藥之法本屬如此，聽許非時服用。《十誦律》：石蜜不得隨意吃，除五種人〔文中僅列四種〕：遠行人、病人、食少不足人、得不到食物的人；又若在施水之處，可和水而飲。《五分律》：飢、渴二時，以水和飲。

《僧祇律》：進食時得到很多酪，吃不完的可作成生酥，受為七日藥服用；若仍有餘，煎成熟酥，受為七日藥。若乞食時得到很多酥（雜有食渣），貧病比丘可用細密棉布如法濾過，取得淨酥，得受為七日藥。若有事緣不能在日中以前作成的，應向一位比丘作記識說：「此中（將來）會生出淨物（酥），我當受持為七日藥。」若忘失疏忽而未受持、未作淨，過了日中，即名不淨。若得到很多油，作法如酥中所說。得到胡麻，吃剩不盡的，就煮取油，受為七日藥；若因事緣不能作成，如酥中所說。若是熊、豬等脂，比照上例定其可否。得甘蔗及果實，也都比照上述。

《善見律毘婆沙》：受酪時，預先記別酪中所出之酥為七日藥；至第七日攪酪取酥，當日即得服食；若延至第八日，便犯捨墮（尼薩耆波逸提）。油、蜜亦同。《摩得勒伽論》：非時受持甘蔗，作法不成；在時中（明相出至日中）受持，則皆得成。

然而蜂蜜滋味甘美、為世所重，凡夫與聖者都常說：增長貪愛、敗壞道行，沒有比它更甚的；況且要得蜜，必是靠強力劫奪（蜂所積之蜜）而辦得；若不是極重之病，實在難以入口。所以《僧祇律》說：佛接受獼猴所獻無蜂子的熟蜜等。
