# 校閱材料　第211檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【211-0001】02_戒疏/09d_卷二下之二#157
【原文】【疏】就《戒本》中，先明立法，有八句，除自求及量限。後戒本中，除自求及過量，文相可解。餘如《鈔》。
【譯文】【疏文】在《戒本》的經文中，首先說明立法規範，共有八句，排除了「自己乞求物料」以及「尺寸限量」這兩條。在後文犯戒條文的根本中，同樣排除了「自己乞求」與「超量建造」，經文相貌很容易理解。其餘的微細規定，都正如《事鈔》所記載。

【211-0002】02_戒疏/09d_卷二下之二#158
【原文】【記】戒本中，立法、犯本，除句並同。下指《鈔》者，彼云：「此房屬於己，身若死，遠去不還，隨念分處。若與三寶、親友、白衣，自賣取錢，隨心自在。唯不得賣地，地是僧物，僧不許賣，房僧得罪。若房主不自處分者，屬四方僧，次第住之。」
【譯文】【記文】在戒本的解釋中，確立戒相法式與後文犯罪根本這兩段，所排除刪減的文句完全相同。下文指引參閱《行事鈔》，那本書說：「這間大房產權屬於比丘個人，他若是死亡、或者遠行長久不歸，隨他的意願可以自由分配處分。若是想要轉贈給三寶常住、親朋摯友、在家白衣，或者自己變賣換取錢財，完全隨他心意自主決定。唯獨絕對不可以出賣土地，因為土地屬於全體僧團的常住物，僧團絕不允許私賣土地，若賣土地房主比丘得罪（成盜罪）。如果房主比丘圓寂前自己沒有預作遺囑處置，這間房子就直接歸屬於十方常住僧團，由大眾依戒臘次第輪流居住。」

【211-0014】02_戒疏/10a_卷三上之一#12
【原文】【記】「今」下，明不應為。又三，初敘過。「自」下，彰損，有三：初即損自；「以」下，滅法；「又」下，損他。「甄在眾外」者，以犯四重，即應滅擯故。「欺」下，三、示立教。
【譯文】【記文】從「今」字以下，說明不應當做的事。又分為三點：首先敘述過失；從「自」字以下，彰顯其損害，共有三種損害：第一是損害自己，從「以」字以下是毀滅佛法，從「又」字以下是損害他人。「甄在眾外」，是指如果犯了四波羅夷重罪，就應當被滅擯逐出僧團。「欺」字以下，第三點是開示訂立教戒的必要。

【211-0016】02_戒疏/10a_卷三上之一#14
【原文】【疏】次釋名者。內無三實，故曰「無根」，以重加誣，名之為「謗」。「無根謗」非是戒，乃是戒家所防。「戒」者，能治之行。能所通舉，故曰也。
【譯文】【疏文】其次是解釋名義。由於內心毫無見、聞、疑三種事實依據，所以稱作「無根」；拿重罪橫加誣衊，稱之為「謗」。「無根謗」並非戒律本身，而是戒法所要防範的過失。「戒」，則是能對治調伏的行持。將能治與所治通融並提，所以如此命名。

【211-0017】02_戒疏/10a_卷三上之一#15
【原文】【記】釋名中，初牒釋。「三實」，即見、聞、疑。言「以重」者，簡下諸聚，罪輕降故。「無」下，次總示。言「所防」者，顯是過相。
【譯文】【記文】在解釋名義中，首先照錄名目來解說。「三實」，就是親見、親聞、生疑這三種實事。說到「以重」，是為了簡別排除其餘各聚罪法，因為那些罪較輕且層次遞降。「無」字以下，其次是總體開示。說到「所防」，是顯明這是所要防範的過失之相。

【211-0029】02_戒疏/10a_卷三上之一#27
【原文】【記】次約義中。初總標。下約兩意，故曰「別論」。「元」下，別示。約心單複，釋通兩解。以業隨心結，故罪有雙單，善達持犯，於茲見矣。「如」下，舉例，有二。初舉殺戒，故指「如前」。謂父成羅漢而行殺者，若但殺父，不知成聖，止得一逆；若知是聖，則兼二逆。次引兩舌戒，即《多論》中以口三過互歷為句，故云「相對」。一、是兩舌，非妄語、惡口；二、是兩舌，非妄語，是惡口；三、是兩舌，是妄語，非惡口；四、三種俱是。餘二為頭，互歷亦爾。並由心緣兼獨，故使犯有雙單。證今謗、妄，不可偏判矣。
【譯文】【記文】其次是依理抉擇分析。首先是總體標明。下面依據兩種心意來判別，所以稱為「別論」。「元」字以下，個別指明。依照心念的單純或兼帶，通暢地解釋了兩種看法。由於造業是隨著發心而結罪，所以罪名有雙犯與單犯之別，能夠善於通達持犯之理，在此處就能看出來了。「如」字以下，舉出兩個例子。首先舉出殺戒為例，所以指稱「如前」。意思是如果父親成就了阿羅漢而行殺害，如果只知道是殺父，不知道父親已成聖人，只得一重逆罪；如果明知是聖人，就兼犯兩重逆罪。其次引述兩舌戒，即《薩婆多論》中將口業的三種過失互相歷經配置成句型，所以說是「相對」。第一種，是兩舌，但不是妄語、惡口；第二種，是兩舌，不是妄語，而是惡口；第三種，是兩舌，也是妄語，但不是惡口；第四種，是三種過失全都具備。以其餘二者作為開頭，相互歷對也是如此。這全都是由於心念所緣境是兼帶或是單一，因而使得犯戒有雙犯與單犯之別。由此證實如今討論誣謗與妄語，不可偏頗地執定一種判法。

【譯文】【疏文】另一種解釋說：「誣謗不清淨的人，同樣構成誣謗。凡是論及僧團羯磨之法，只取見、聞二相，所以違背了眼前所見的清淨相，硬說對方犯罪，既自生惱害又惱害他人，因此不論境是清淨還是混濁，結罪都是一樣的。

【211-0055】02_戒疏/10a_卷三上之一#53
【原文】【疏】「不可如緣。如初戒緣，可有尼也？戒本言『非』者，據緣起說。亦可就於謗情，非想淨者，何由加謗故也？下云『說實』，三根想實也。
【譯文】【疏文】「不可完全拘泥於發起因緣。難道像最初制戒的緣起，會有比丘尼參與嗎？戒本之所以說『非』，是依據當初緣起的情境而說的。也可以就誣謗的心意來論，若非心中將其想作清淨，憑什麼去加以誣謗呢？下文所說的『說實情』，是指對見、聞、疑三根自以為確有實情。

【211-0056】02_戒疏/10a_卷三上之一#54
【原文】【疏】「故《律》云：『彼人不清淨，不見彼犯，故謗成殘。』如犯重打提之相。」
【譯文】【疏文】「所以《律》中說：『那個人並不清淨，但自己並沒有親見其犯重，因而行謗仍犯僧殘。』這就像毆打犯了重罪的人同樣犯波逸提的相狀一樣。」
