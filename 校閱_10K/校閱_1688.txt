# 校閱材料　第1688檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1688-0001】03_業疏/09b_卷二之三#57
【原文】此聖言量不可輕也。生涯漸迫，日月逝矣，徒恣口腹，死終不隨。可為心師，於此見矣。余常覩行德諸僧，康徤之時，清舉高世；及乎疾苦，知何不噉！保命如斯，終歸後世。無識之儔，未曾隱括，排斥教網，希貪口腹，為之陷溺，如是長劫，誠可悲矣
【譯文】這聖言量絕不可輕忽。生命漸漸迫近終點，歲月飛逝，徒然放縱口腹之欲，死後終究帶不走任何東西。什麼能作為自心的導師，從這裡就能看出來了。我常看見一些素有行持道德的僧人，健康之時清雅高潔、超然出世；可是一旦面臨疾病痛苦，還有什麼不敢吃的！如此貪生保命，終究難逃死後隨業受報。那些缺乏正見的人，未曾查考研讀聖教，反而排斥佛陀教網，貪戀口腹之欲，因而沉淪陷溺，如此經歷漫長劫數，實在太可悲了。

【1688-0002】03_業疏/09b_卷二之三#58
【原文】結斥中二：初、指教以勸。「生涯迫」者，死將近也；「日月逝」者，年光速也；「死不隨」者，弃其所養也；「可為心師」者，勸其自勵也。「余」下，指事以斥。初敘其乖謬；「保」下，歎其愚暗；「無」下，責其毀教。耻躬不逮，輕貶律乘，謂為小教，不披聖教，故未隱括；陷溺長劫，無出期也
【譯文】在結尾斥責中分為兩部分：第一、指出聖教以勸勉。「生涯迫」是指死亡即將臨近；「日月逝」是指光陰飛逝；「死不隨」是指死時終將拋棄平生所保養的色身；「可為心師」是勸勉其自我策勵。自「余」以下，是指具體事實來斥責。起初敘述他們的乖違謬妄；自「保」以下，感嘆他們的愚蠢冥暗；自「無」以下，責備他們毀謗教法。他們因自身做不到而感到羞恥，便輕視貶損律乘，稱之為小乘教法，不翻閱研讀聖教，所以未曾查考研讀聖教；因而陷溺於長劫之中，永無出離之期。

【1688-0003】03_業疏/09b_卷二之三#59
【原文】二、明過中，先緣後法
【譯文】第二、在說明過失中，先明成犯的因緣（犯緣），後對各項法位（處、時、人、食）進行分別。

【1688-0004】03_業疏/09b_卷二之三#60
【原文】次明罪中分緣、法者，緣即四過成犯之緣相，法即以罪對四法之通塞
【譯文】其次在說明罪相中分為「緣」與「法」：「緣」就是四種過失構成犯戒的緣相；「法」就是將罪相與四種法位（處、時、人、食）相對照，辨明其適用與否（通與塞）。

【1688-0005】03_業疏/09b_卷二之三#61
【原文】初、約緣明，且據內宿，《四分》文不了
【譯文】第一、依據成犯因緣來說明，姑且根據「內宿」（在僧坊內過夜），《四分律》的經文並不詳盡明確。

【1688-0006】03_業疏/09b_卷二之三#62
【原文】初緣標示中，《四分》但列罪名，而不明人位差別，故云不了
【譯文】在最初標示成犯因緣中，《四分律》僅列出罪名，卻未辨明人員品位的差別，所以說「不了」（不明確）。

【1688-0007】03_業疏/09b_卷二之三#63
【原文】如《十誦》云：共三種人同食宿，不應食，食得吉羅。初、共比丘，謂與同宿也。二、比丘僧者，謂一具戒者同宿，則通一切皆被染也。如《四分》殘食戒云「今日受已至明日，一切沙門釋子受大戒者皆不清淨」，此通僧也；或釋疑故，如衣不淨犯起別人，謂食同此也，衣有別屬，食味是通，故一切染則通餘也。三、共與學沙彌者，由行違體順、相同故染也。尼中有四，加式叉尼，同宿同罪也
【譯文】如《十誦律》說：與三種人同處留宿飲食，便不應當食用，若吃了便得突吉羅罪。第一、與個別比丘同宿，是指個別比丘與其飲食同處留宿（自己染污了自己的食物）。第二、比丘僧，指只要與一位具足戒者同宿，則普遍染污所有僧眾。如同《四分律》宿食戒所說：「今日領受之後放到明日，所有受了大戒的沙門釋子都算不清淨」，這就是通及全體僧眾；或者為了釋疑，比如衣服不清淨只在特定人身上結罪，若以為食物也是這樣，其實衣服各有專屬之人，而飲食美味是大家共通享用的，所以一人受染就會普遍染污其餘大眾。第三、與「與學沙彌」（受處罰而學悔的沙彌）同宿，由於他行為雖有違犯但戒體依然隨順、形相相同的緣故，所以食物也會被染污（成內宿食）。比丘尼中則有四種人，增加式叉摩那，同處留宿也是同樣結罪。

【1688-0008】03_業疏/09b_卷二之三#64
【原文】十誦》內宿中初科，初總示；「初」下別列。「共比丘」者，即約別人自染己食也。二「比丘僧」中二：初、約通染釋，謂宿約別人，犯通僧故，下引殘宿類顯通僧；「或」下，次約釋疑釋，衣別食通，恐濫須出。三「與學沙彌」，即學悔也。尼中三竝同僧，唯加式叉
【譯文】在《十誦律》關於內宿的第一科中，起初作總體提示；自「初」以下分別列出。「共比丘」是指個別之人自己染污了自己的食物。第二「比丘僧」中分為兩點：首先依普遍染污來解釋，說明留宿雖是個別之人，但犯戒卻通及全體僧眾，下文引宿食戒為例來顯明通及全僧之義；自「或」以下，其次依釋除疑惑來解釋，衣服屬個別所有而食物則共通享用，唯恐產生混淆所以必須加以辨明。第三「與學沙彌」，就是指正在學悔的沙彌。比丘尼中的三種人都與僧眾相同，只是另外加上式叉摩那。

【1688-0009】03_業疏/09b_卷二之三#65
【原文】故彼文云：言內宿者，羯磨結淨地已，僧坊內宿飲食者是。若取後制，義通淨地；約相從文，違教無宿可知也
【譯文】所以該律文說：所謂「內宿」，是指通過羯磨作法結立淨地之後，在僧坊之內留宿飲食的情形。如果依據後來的制約，法義應通及淨地；若依據表面事相順從律文，則順應教法（結了淨地）便無內宿之罪，這也是顯而易見的。

【1688-0010】03_業疏/09b_卷二之三#66
【原文】次科，初引文；「若」下，義決。上文但云僧坊，後制須通淨地；據文似淨地中達教不犯，故云「約相」等
【譯文】下一科中，起初引用律文；自「若」以下作義理裁決。上文雖然只說僧坊，但後來的制戒必須通及淨地；依字面意思看來，似乎在淨地中即便違背後制教令也不犯內宿罪，所以說「約相」等語。

【1688-0011】03_業疏/09b_卷二之三#67
【原文】十誦》又云：言內熟者，結淨地已，僧坊內煑飲食者是。文言自熟者，大比丘自作，如上三人互不應食。言惡捉者，未受而觸是也；比丘自取果與淨人已，而從受噉，制犯吉羅，名惡捉也
【譯文】《十誦律》又說：所謂「內熟」（在內煮食），是指結立淨地之後，在僧坊之內煮飲食的情形。文中說「自熟」（自己煮食），是指大比丘自己烹煮，如同上述的三種人，彼此都不應當食用。所謂「惡捉」（不合法的觸摸），是指未經合法領受就去觸摸；比丘自己拿取水果交給淨人之後，再從淨人手中領受食用，依制犯突吉羅罪，這就叫做「惡捉」。

【1688-0012】03_業疏/09b_卷二之三#68
【原文】後三罪中，初、明內熟，熟即煑也。「文」下，次明自煑，指上三人，即比丘僧及學悔也。「言」下，三明惡觸，有二：一、直爾自捉，二、捉令人受
【譯文】在後三種罪相中：第一、說明內熟，「熟」就是烹煮。自「文」以下，第二、說明自煮，指上述的三種人，也就是個別比丘、比丘僧以及學悔沙彌。自「言」以下，第三、說明惡觸，分為兩種：一是直接自己拿取觸摸，二是拿取後交給他人再讓自己領受。

【1688-0013】03_業疏/09b_卷二之三#69
【原文】多論》共宿三種：若受食已，作已有想，不共同宿，經宿吉羅，食則犯墮；若自捉食，名惡捉，捉時吉羅，作已有想，經宿亦吉羅；若食不受、不捉，作已有想，經宿吉羅，食亦吉羅，此內宿也。若食作已有想，縱不共宿，經宿吉羅者，以心貯畜故犯。《四分》無文，義豈通許
【譯文】《薩婆多毘尼毘婆沙》說留宿有三種情形：如果已經如法受食，生起據為己有的念頭，即使沒有同處過夜，經過一夜結突吉羅罪，若是吃了便犯波逸提（墮罪）；如果是自己抓取食物，稱為「惡捉」，抓取時結突吉羅罪，若生起據為己有的念頭，經過一夜也結突吉羅罪；如果食物既未如法受領，也未抓取，但生起據為己有的念頭，經過一夜結突吉羅罪，吃了也結突吉羅罪，這就是「內宿」。如果食物生起據為己有的念頭，縱然沒有同處過夜，經過一夜結突吉羅罪，是因為心存積蓄收藏的念頭所以構成犯戒。《四分律》雖然沒有明文，但義理上難道會通融允許嗎？
