整體看，這六則譯文的**大方向都對**，科判（「謂下」「二下」「今下」「若下」「直下」）的處理方式一致，兩師「現／懸」的對照也譯得清楚。但有幾處**詞義誤判**、**術語不一致**和**校勘未交代**的問題，建議修改。以下逐則列出。

---

## 一、逐則問題

### 【0001】

| 原文 | 問題 | 建議 |
|---|---|---|
| 但隨住舍 | 「隨順個人的住處房舍」——「隨順」是「依從」義，此處是說**自然衣界只以所住之舍為範圍** | 「（衣界）僅隨所住的房舍為限」 |
| 遍界通護 | 「通體護持」語意含混，「通體」是多餘的現代語 | 「整個大界之內都能普遍護衣」 |
| 初示相判定 | 「出示形相」太字面 | 「先列示（三種）情形，判定須結與否」 |
| 勢分內者，一切自然衣界之外，各有十三步勢分 | 譯成「是指……外圍，各自擁有……」句法鬆散，且「勢分內」是**牒鈔文**再解釋 | 「所謂『勢分內』：一切自然衣界之外，都各有十三步的勢分（護衣勢力所及的範圍）」 |
| 則通兩相 | 「這兩種情形」讀者不知是哪兩種 | 補註「（即『無藍』與『界寬藍狹』）」 |

### 【0002】

1. **「藍界等者」譯「寺院界地等同於大界」**——「寺院界地」易與「結界」混淆。應作「僧伽藍（的範圍）與大界相等的」。
2. **「比由羯磨文牒除村」的「比」**：此處「比」多作「**近來**」解（比來、比者），譯成「以往」時間方向相反。建議改「近來由於……」。
3. **「準疏」**：這裡的「疏」是道宣《羯磨疏》（《業疏》），不宜泛譯「律疏」。
4. **「立法中，初科」**：「立法」是科段名（相對於前面「示相判定」），譯成「在『結界法式』中」可以，但最好標示為段名：「（鈔文）『立法』一段中，第一科……」。
5. **「上二句……上句……」**：宜補「（這二句中的）第一句」，避免與後文「下句」脫節。
6. **「二相俱有，院外失衣」譯得對**，但讀者不易懂。建議加譯註：結衣界後作法界取代自然界，藍外十三步勢分不再護衣，故「院外失衣」。

### 【0003】

1. **「攝衣」譯作「攝受衣物」不妥**：
 - 「攝受」是攝受眾生之義，與「攝衣（護衣，衣離此處不犯離衣）」不同；
 - 「衣物」範圍過寬，此處指**受持的三衣**。
 → 建議統一作「攝護法衣」或「攝衣（護衣不犯離）」。「不合攝衣」＝「該處不能攝護衣（衣離即犯）」。
2. **「下句別指初解」**：宜註明是**鈔文「標古法」二句中的第二句**，否則與前文「上一句」隔了兩師解釋，讀者接不上。

### 【0004】（問題最集中）

1. **「上二句明結法俱通」譯「結界方法彼此貫通」——這是誤譯。**
 「俱通」指**通於「有村」「無村」兩種情形**（下文「雙釋」正是釋「結遍」與「除通」）。
 → 「上二句說明結衣界之法通於有村、無村兩種情形」。
2. **「除村村外」是羯磨成語，不應逕譯。**
 這是羯磨緣文中的定句，譯成「排除村落與村落之外」會失去「引文」性質。
 → 保留「除村村外」，再加註「（即除去村落及村外之地）」。
3. **「彼謂除體據現無村，則於羯磨詞中除去除村等語」**：
 - 「則」是**推論語氣**（那麼就該……），譯成「所以……刪除了」變成既成事實；
 - 「彼」指誰（古師？舊記？）譯文自行補「（古師）」，屬推測，宜出註存疑。
 → 建議：「若依彼師『所除是村體』之說，就『現在無村』而言，羯磨詞中便應刪去『除村』等語，所以稱為『無村結法』。」
4. **「舊記妄出古解」**：「出」是**提出／杜撰**，非「解釋」；且「舊記」是前人對《鈔》的註記（書名性質），與「古師」不同。
 → 「舊記妄自杜撰古師之解，完全違背《業疏》原文」。
5. 「羯磨緣」可譯「羯磨前唱緣（告白事緣）」，比「羯磨文事緣」清楚。

### 【0005】

1. **「三雙釋」譯「進行雙重解釋」——誤。**
 「雙釋」是**同時解釋「結」與「除」二者**（結遍／除通），不是「解釋兩次」。
 → 「第三項『雙釋』（同時說明結遍與除通）」。
2. **「以除緣難，不除體故」**：「緣難」即「難緣」（能為障難之緣），譯「障礙緣由」語意走樣。
 → 「因為所除的是能為障難的『緣』（村為難緣），並非除去村的地體」。
3. **「不礙法」**：宜作「不妨礙衣界之法遍於全界」，比「整個羯磨法的成立」貼切。
4. **「村有二字寫倒」**：可補「（應作『有村』）」，讀者才知結論。
5. **「不得通攝」**：「不能普遍攝受」→「（村處）不能一併攝護衣」。
6. **科判與牒文的歸屬待核**：「上句明結遍。以雖有村，不礙法故。直下，顯除通。以除緣難，不除體故。」——這很可能是「科判＋牒鈔文」的写法（「以……」與「直……」正是鈔文起首字）。譯文一律處理成「因為……」的解釋句，若實為牒文就失真。建議改成兼容写法：
 「『以』以下第三段雙釋：上句明『結遍』——以雖有村，不礙法故；『直』以下顯『除通』——以除緣難，不除體故。」

### 【0006】

1. **「一者理通」譯「法理通達」——誤。**
 「理通」是說**義理上通於有村無村而無妨**，不是「通達法理」。
 → 「一是義理上通於（有村、無村）兩種情形」。
2. **「如除所引」譯「如同下面所引述」——這是改字翻譯，未出校。**
 「除」字於此難通，疑為「下」（或「餘」）之訛。既然譯文已按「下」讀，**必須加校註**：「原文作『除』，疑當作『下』，今據文義改讀」，不能默默改掉。
3. **「證有無通結」**：「有無」＝有村／無村，「通結」＝一律可結（皆須唱除）。譯「都能通體結界」又出現「通體」，宜改「證明有村、無村都可結界（皆須唱除）」。
4. **《多論》**：可補全名《薩婆多毘尼毘婆沙》，並註明簡稱。
5. **原文〔未閉合**（「〔謂村去後仍前攝衣。」缺「〕」），譯文自行補上，宜出校說明。

## 二、跨則的一致性問題

| 術語 |  presently 譯法 | 建議統一 |
|---|---|---|
| 攝衣／通攝 | 攝受衣物、攝受功能、攝受法衣、護持 | **攝護（法）衣**；並註明「衣離此界不犯離衣」 |
| 衣 | 衣物／受持法衣／法衣 | **受持之三衣／法衣**（勿用「衣物」） |
| 通 | 一律譯「通體」 | 分清兩義：①遍（遍界通護→普遍）②通於二種（結法俱通、有無通結→通於有村無村） |
| 藍 | 寺院／寺院界地／僧院 | **僧伽藍（寺院）**，「界」專指大界 |
| 疏 | 律疏 | **《業疏》（道宣《羯磨疏》）** |
| 舊記／古師 | 混用 | 明確區分「舊記（前人註記之書）」與「古師（古來諸律師）」 |

另：「通體」一詞在 0001、0005、0006 反覆出現，屬生造的現代語，建議全部改寫。

## 三、譯得準確、可保留之處

- 0002「二相俱有，院外失衣；界小於藍，院內亦失」的判讀**正確**（兩種情況都失於院外勢分，界小於藍者又失於院內）。
- 0003 兩師「現除懸不結／現結懸除」與夾註「除村體／但村來為礙」的對比譯得清楚。
- 0005「即異古師懸不結也」的按語、「村有二字寫倒」的判斷都對。
- 0006《五分律》引文與「村去後仍前攝衣」的按語無誤。

## 四、優先修改順序

1. **必改（語意錯）**：0004「結法俱通」、0006「理通」、0005「雙釋」、0002「比由」、0001「隨順住舍」。
2. **必補（校勘）**：0006「如除所引」改字未出校、括號未閉合。
3. **應改（術語）**：攝衣→攝護法衣；「通體」系列；「除村村外」保留羯磨原語。
4. **宜補（可讀性）**：0002「院外失衣」加譯註、0001「兩相」加註、0003「下句」标明鈔文、0005「村有」補正讀。
