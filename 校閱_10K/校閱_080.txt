# 校閱材料　第080檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【080-0001】01_行事鈔/05a_卷中之一#25
【原文】初中，起業要託三毒而生；然毒之所起，我心為本。此義廣張，行人須識；如懺法中，具明業相。今略述起罪，必約三性而生；受報淺深，並由意業為本。故《明了論》解云：破戒得罪，輕重不定。有重心，破輕戒，得罪重。無慚羞心，作無畏難。或由見起，謂無因果。或由不信生，謂非佛制此戒；或不信破此戒得此報。或由疑生，為定佛制？為非佛制？為定得報？不定得報？若由如此心破，得罪便重。若不由如此心，偶爾破戒，重翻成輕。今隨三性，具列罪相。
【譯文】在第一部分中，造作罪業必定要依託貪、瞋、癡三毒而生起；然而三毒之所以生起，是以「我執之心」為根本。此項義理鋪陳極廣，修行人必須認識清楚；如後文懺法之中，詳細闡明了種種業相。現在概略敘述生起罪過的情況，必定是依約善、惡、無記「三性」之心而生起；受報的深淺，全都是以意業為根本。所以《律二十二明了論》解釋說：破戒所招致的罪過，輕重並不固定。若以極重的心，破了輕戒，招得的罪過極重。例如毫無慚愧羞恥之心，造作時毫無畏憚顧忌。或者由於邪見而生起，認為根本沒有因果。或者由於不信而生起，認為這條戒不是佛陀所制的；或者不相信破了此戒會遭受此種惡報。或者由於懷疑而生起，懷疑這必定是佛制的嗎？還是非佛所制？犯了必定會受報嗎？還是不一定受報？如果是由這樣的心念去破戒，招得的罪便極重。如果不是由於這種心念，只是偶然失念破戒，原本深重的罪過反而轉為較輕。現在依隨善、惡、無記三性，具體列出罪相。

【080-0002】01_行事鈔/05a_卷中之一#26
【原文】一者善心犯戒。謂如《僧祇》中：知事比丘，闇於戒相，互用三寶物；隨所違者，並波羅夷。或見他厭生，與其死具；看俗殺生，教令早與，勿使苦惱。此並慈心造罪，而前境違重。不以無知，便開不犯；由是可學，皆結根本。即律文云，愚癡波羅夷，乃至吉羅亦爾。又如《薩婆多》云：年少比丘，不知戒相，塔上拔草，罪福俱得。若論來報，受罪則輕；由本善念，更不增苦；不免地獄，由違受體。若犯性戒，具受二罪，謂業道也，及以違制；若犯遮戒，如壞草木，但得一罪，以化教中本不制故。無情可惱，若後懺洗，復本清淨；不同犯性。廣如下《智論》中說。
【譯文】第一是「善心犯戒」。指例如《摩訶僧祇律》中所載：執事比丘由於對戒相懵然無知，互相挪用佛、法、僧三寶之物；凡是挪用違犯者，全都結成波羅夷罪。或者看見他人厭惡生命求死，便給予他自殺的工具；看見世俗之人屠殺牲畜，教令對方儘早一刀了結，不要讓動物受苦惱。這些全都是出自慈悲之心而造作罪過，然而所對的境界深重違犯了戒律。不能因為自己無知，律典便開許為不犯；因為這是屬於應當修學的戒相，因此全都結成根本罪。也就是律文所說的「愚癡波羅夷」，乃至結成突吉羅也是如此。又如《薩婆多論》說：年少比丘不懂得戒相，在佛塔上拔草，結果罪過與福報同時獲得。若論未來的果報，受罪相較而言則較輕微；因為當初本是出於善念，果報中不再額外增加苦楚；但仍不免墮入地獄，是因為違背了當初所受戒體的緣故。如果違犯的是「性戒（殺盜淫妄等本質即罪者）」，則具足遭受雙重罪報，也就是世間業道之罪，以及違犯佛制的罪；如果違犯的是「遮戒（壞草木等佛所制止者）」，例如毀壞草木，則只得一種罪，因為在化教（一般教化法門）中本來不予制止之故。草木等無情物無心識可受惱害，如果事後如法懺悔洗除，便能恢復原本的清淨；這與毀犯性戒是不同的。詳盡內容如下文引《大智度論》中所說。

【080-0003】01_行事鈔/05a_卷中之一#27
【原文】二不善心者。謂識知戒相，或復闇學；輕慢教網，毀訾佛語。如《明了論》述云：有四種麁惡言犯罪：一者濁重貪瞋癡心，二者不信業報，三者不惜所受戒，四者輕慢佛語；故心而造，則得重果。以此文證，由無慚愧，初無改悔，是不善心。故《成論》害心殺蟻，重於慈心殺人。由根本業重，決定受報；縱懺墮罪，業道不除。如《十誦》：調達破僧，犯偷蘭已，佛令僧中悔之，而於業道，尚墮阿鼻。故《地獄經》云：一作業定，二受果定，諸佛威神所不能轉。廣如卷末陳說。
【譯文】第二是「不善心（惡心）犯戒」。是指明明認識知曉戒相，或者雖然昏暗未學，卻輕視怠慢戒法教網，詆毀毀謗佛陀聖言。如同《律二十二明了論》敘述說：有四種麁惡心態造作罪過：第一是染濁深重的貪、瞋、癡心，第二是不信業因果報，第三是不愛惜自己所受的戒體，第四是輕蔑怠慢佛陀法語；以故意放縱之心造作，便會感得深重惡果。以此論文為證，由於毫無慚愧之心，自始至終沒有改悔之意，這便是「不善心」。所以《成實論》說：懷著害心殺死一隻螞蟻，罪過重於懷著慈心而殺人。由於根本惡業深重，決定要受惡報；即使依律懺除了違制的墮罪，世間業道之報依然不能免除。例如《十誦律》中記載：提婆達多破和合僧，犯了偷蘭遮罪之後，佛陀令他在僧團中懺悔，然而就其破僧之業道而言，依然墮入了阿鼻地獄。所以《泥犁（地獄）經》說：一是造業已經決定，二是受果已經決定，連諸佛的神通威德也無法將其扭轉。這在卷末還會有詳盡的陳述。
