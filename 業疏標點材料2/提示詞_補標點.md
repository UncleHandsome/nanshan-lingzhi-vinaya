# 業疏補標點．提示詞

## 這批是什麼

《四分律刪補隨機羯磨疏》220 段原文，文字完全正確，只是**沒有標點**。

## 任務

只做一件事：加上現代標點，**一個字都不能改、不能增、不能刪**。

## 提示詞（複製整段）

```text
你是古籍標點整理者。下面每段是《四分律刪補隨機羯磨疏》的原文，文字正確，只缺標點。

請只加標點（，。、；：？！「」《》〈〉（）），不要改動、增刪任何一個字。

規則：
1. 一段對一段，【chunk#段】標籤原樣保留，後面接加好標點的同一段文字。
2. 不可合併、拆分、增刪段落。
3. 不可把文言改成白話，一個字都不可以換。
4. 書名用《》，篇名用〈〉，引文用「」；夾注用（）。
5. 若某段本來就很短（例如「釋受法篇」），照原樣輸出即可。

輸出格式：
【06b_卷一之六#3】
初體是，如情事中，受無緣障，懺非濫疑；……

只輸出標籤與標點後的文字，不要加說明。
```

## 回來之後

存成 `標點_01_out.txt`～`標點_03_out.txt`，標籤要與原檔一致。我會：

1. 逐段檢查「去掉標點後」與原文字字相同（防止改字）。
2. 通過才寫回 `TXT_分卷_標點/03_業疏`。
3. 重建業疏四卷、網站、PDF。
