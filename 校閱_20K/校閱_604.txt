# 校閱材料　第604檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【604-0001】資持記/12a_中四下#39
【原文】云下，三示悔法，初標問。謂下，答釋，初明懺者現報即受。所謂轉重為輕也。橫謂非橫，羅猶墮也。若下，明不懺者生報方受。彼經云：若不觀身無常，名不修身；不觀戒是善梯隥，名不修戒；不觀心躁動制伏，名不修心；不觀智慧有力能斷，名不修慧。
【譯文】下文「云」字以下是第三，顯示懺悔的方法，先標出提問。下文「謂」字以下是回答解釋，先說明懺悔的人現報就受。所謂轉重為輕。「橫」是說非橫，「羅」還是「墮」的意思。下文「若」字以下是說明不懺悔的人生報才受。那部經說：若不觀察身是無常，名叫不修身；不觀察戒是善的階梯，名叫不修戒；不觀察心躁動而加以制伏，名叫不修心；不觀察智慧有力能斷，名叫不修慧。

【604-0002】資持記/12a_中四下#40
【原文】次明懺法，辨異中，初科引律本文。諸下，示古今兩判，初指古非。古釋都無覆者，謂從犯已後，曾無一念覆心方開，有則不開；又見律中懺法，因犯婬為緣，便謂唯婬開悔，餘重不開，故云互有是非也。今下，申今解，初二句示教意。立教接機，不可抑塞，故云理無滯結也。但下，二顯正解。
【譯文】其次說明懺法，在「辨異」中，第一科引用律的本文。下文「諸」字以下是顯示古今兩種判釋，先是指出古人的錯誤。古人解釋「都無覆」，是說從犯罪以後，從來沒有一念覆藏之心才開許，有覆藏就不開；又看到律中的懺法，是因為犯婬為緣而說，便認為只有婬罪開許懺悔，其餘重罪不開，所以說「互有是非」。下文「今」字以下是申明今解，最初兩句顯示教法的用意。建立教法接引根機，不可壓抑阻塞，所以說「理無滯結」。下文「但」字以下是第二，顯示正確的理解。

【604-0003】資持記/12a_中四下#41
【原文】謂曾犯多罪，必須盡悔，故云都無覆耳。不下，三簡異僧殘容不盡悔，文又為三，初直示不同。初下，比校兩篇不同所以。凡有三別：一犯重本壞，二悔出自心，三抑令首盡；僧殘反上。言有餘者，反上一也；得強加法，反上二也；隱顯隨懺，反上三也。有下，結示。諸異，即上三義相反。
【譯文】這是說曾經犯了多種罪，必須全部懺悔，所以說「都無覆」。下文「不」字以下是第三，簡別僧殘容許不全部懺悔，文中又分三，先是直接顯示不同。下文「初」字以下是比較兩篇不同的理由。共有三種差別：一是犯重罪根本已壞，二是懺悔出自自心，三是強制令其全部發露；僧殘與此相反。說「有餘」，是反於第一；「得強加法」，是反於第二；「隱顯隨懺」，是反於第三。下文「有」字以下是總結指示。「諸異」就是指上面三種相反之義。

【604-0004】資持記/12a_中四下#42
【原文】兩儀即指二篇懺法差別。須治中，《僧祇》三節，初示悔心。令下，明開懺。比丘下，出行法，初明同行。彼此不淨者，宿觸同故。下明別行。得受食者，同下位故。除火淨者，異下位故；及金銀者，異淨人故。從沙彌受食者，不自捉故。《十誦》中，初明開懺。如法乞者，即悔心也。
【譯文】「兩儀」就是指兩篇懺法的差別。在「須治」中，《僧祇律》分三節，先是顯示懺悔心。下文「令」字以下是說明開許懺悔。下文「比丘」以下是列出實行的方法，先說明同行。彼此不淨，因為同樣有宿觸的緣故。下面說明別行。「得受食」，因為與下位相同的緣故。「除火淨」，因為與下位不同的緣故；「及金銀」，因為與淨人不同的緣故。「從沙彌受食」，因為自己不捉取的緣故。《十誦律》中，先是說明開許懺悔。「如法乞」，就是懺悔心。

【604-0005】資持記/12a_中四下#43
【原文】佛下，簡行法，初通示同行。在下，別示不同行有四，一明坐次。二明宿臥。三明秉御。所以唯開此二法者，住持之要，不可暫廢，事不已故；餘不開者，由無限制，容別求故。四明受歲，雖不依大僧臘次，不妨增臘故。下引論。決上秉法，非是常開。《母論》中，初明得法。名下，示復本。但下，顯無勝用。
【譯文】下文「佛」字以下是簡別行法，先通示同行。下文「在」字以下是別示不同行，有四項：一說明坐次。二說明住宿臥息。三說明秉御。之所以只開許說戒、自恣這二法，是因為住持佛法的要務不可暫時廢止，事情不能就此停下；其餘不開，是因為沒有這個限制，可以另外求請的緣故。四說明受歲，雖然不依大僧的戒臘次序，但不妨礙增加戒臘。下面引論。判斷上面的秉法，並不是經常開許。《母論》中，先說明得法。下文「名」字以下是顯示回復本位。下文「但」字以下是顯示沒有殊勝作用。

【604-0006】資持記/12a_中四下#44
【原文】然下，明障來苦。《治禪病經》。脫著衣者，示卑下故。生慚愧者，示悔心也；供僧等，假事折辱，示盡誠也。經有二卷。彼云除糞八百日後，洗浴，著僧伽梨，入塔觀像；若見好相，令誦戒滿八百遍，得成清淨比丘。問：懺既清淨，那不足數？答：戒德劣故，不任僧用。
【譯文】下文「然」字以下是說明能遮障未來的苦報。《治禪病經》。「脫著衣」，是顯示謙卑低下。「生慚愧」，是顯示懺悔心；「供僧」等，是假藉事相折辱自己，顯示竭盡誠意。這部經有二卷。經中說：除糞八百日之後，沐浴，穿上僧伽梨，入塔觀像；如果見到好相，就讓他誦戒滿八百遍，可以成為清淨比丘。問：懺悔既已清淨，為什麼不算入僧數？答：因為戒德低劣，不能擔當僧事的緣故。

【604-0007】資持記/12a_中四下#45
【原文】問：既不足數，開懺何為？答：若不求懺，財法兩亡，僧須滅擯。由懺淨故，得入僧中，但不足數；又復能除獄報九百二十一億六十千歲地獄之苦，頓然清淨，豈非益耶。問：世中皆云小乘無懺重之文，今諸律中云何開懺？答：律開懺者，為同財法，及障來報；
【譯文】問：既然不算入僧數，開許懺悔又有什麼用？答：如果不求懺悔，則財施與法利兩方面都失去，僧團必須把他滅擯。由於懺悔清淨的緣故，得以重新進入僧中，只是不算入僧數；又能除去九百二十一億六十千歲地獄之苦的果報，頓時清淨，難道不是利益嗎。問：世間人都說小乘沒有懺除重罪的文字，如今諸律中為什麼開許懺悔？答：律中開許懺悔，是為了讓他同受財法，以及遮障未來的果報；

【604-0008】資持記/12a_中四下#46
【原文】若望體壞，無任僧用，不復本位，猶同不懺，故云無耳；非謂不許懺也。問：依前化教理事二懺，得罪淨不？答：若修理懺，罪無不遣。若修事懺，或不違行法，或得好相，重罪得滅；如《佛名》、《方等》、《虛空藏》、《治禪病經》等，並有明文。問：若依理事，懺已，制罪滅否？
【譯文】若就戒體已壞、不能擔當僧事、不能回復本位來說，仍然等同於沒有懺悔，所以說「無」；並不是說不許懺悔。問：依前面化教所說的理懺、事懺二種懺法，罪能得到清淨嗎？答：若修理懺，沒有罪不被遣除。若修事懺，或者不違背行法，或者得到好相，重罪就能消滅；如《佛名經》、《方等經》、《虛空藏經》、《治禪病經》等，都有明文。問：若依理懺、事懺，懺悔之後，制教所說的罪滅不滅？

【604-0009】資持記/12a_中四下#47
【原文】答：滅否難知，須準教判，化懺心業，制懺違教，準知制罪不滅。問：得相驗淨，可足數否？答：事懺得相，乃約化經；足數作法，自是律制；兩不相涉，那得致疑。古德云：安用大教懺夷，以足小乘僧數也。欲辨化制，四句明之。初業滅制不滅，二制滅業不滅，三俱滅，四俱不滅。思之可見。
【譯文】答：滅與不滅難以知道，必須依教來判。化教所懺的是心業，制教所懺的是違教之罪，由此可知制罪不滅。問：得到好相驗證清淨，可以算入僧數嗎？答：事懺得到好相，是就化教經典說的；足數作法，自是律制的事；兩者互不相涉，哪裡值得懷疑。古德說：何必用大教的懺法懺除波羅夷罪，來充小乘的僧數呢。要辨明化教與制教，可用四句說明：一是業滅而制罪不滅，二是制罪滅而業不滅，三是兩者俱滅，四是兩者俱不滅。想一想就可以明白。

【604-0010】資持記/12a_中四下#48
【原文】問：有人言準《虛空藏經》得足數者？答：此猶不辨化制故也。問：有人準《初教經》，三十僧中懺重，得入僧數者？答：此引偽經，不足為據，如序所簡。次明立法，陳乞中。律令教乞，事同初受；縱使自能，亦須他教。問：此明懺罪，那云乞戒？答：根本既喪，從僧重受；終身奉持，即是懺悔。

【604-0017】資持記/12a_中四下#55
【原文】恐下，示論意。僧下，引證。有罪知者，謂知犯也。無罪知者，知不犯也。文通諸聚，不局此篇；但取有無兩知，證須觀察。第二方中，初科，前明成覆。僧殘罪見者，謂自知有犯也。若下，次明不成覆。次對律解十門。初云形差，謂罷道反俗，形服別故。三中有二，初不成根本。
【譯文】在「恐下」揭示論典深意。在「僧下」引用經文作證。所謂「知有罪」，是指明了對方有所違犯；所謂「知無罪」，是指明了對方並未違犯。文義通達於所有罪聚，並不局限於此僧殘一篇；只是藉由「知有」與「知無」這兩種了知，來證成行者必須進行詳細觀察。在第二種法度（第二方）中，第一科，前半段說明構成覆藏。所謂「生起僧殘罪見」，是指自身清楚知道有所違犯。在「若下」後半段說明不構成覆藏。接著對照律典解釋十個門徑。第一門稱為「形差」，是指放棄戒法返回世俗，因為形貌衣服已經改變了的緣故。在第三門中分為兩種情況，首先是不構成根本罪。
