# 校閱材料　第1544檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1544-0001】05_拾毗尼義鈔/04a_卷中之二#36
【原文】問別眾食中開有九緣何意答病謂脚[月*(臣-巨)*辛]以異惱僧義故難濟命故言作衣者十誦云不問應量不應量衣一切盡聽要食難得處易得不聽首解作衣久延恐廢正業故言施衣者施時不受後須難得自得濟形亦福施主故言道行船行者昨日來今日食明日行今日食皆犯即日行極小半由旬來去食者不犯婆論云若到所至受食亦無犯義言道中多難亦難得食故言大眾集者食足四人長一人為患者謂四人中長非謂四外別有一人乃至百人長一例此可知又解彼此成眾八人已上名為大眾食無倍供食難得故開使不犯七人不爾故言長一為患若食易得處雖大眾集別食得提又解大眾者四人已上故尼律云大眾者四人若過又婆論沙門施食者外道沙門除佛五眾一切出家皆名沙門義云為小益外化以道法改邪入正開使不犯若沙門請已復俗作白衣或作五眾持食與比丘白衣請已入外道出家作沙門手持食與此二俱提先是出家五眾請後作沙門外道亦犯十誦云白衣請比丘後作外道沙門持食乞受請吉食者無犯。
【譯文】問：別眾食戒中開許有九種因緣，是什麼意思？答：有病是指腳部拘攣（腳病抽搐攣縮），因為這有別於故意惱亂僧眾的意義，而且關乎搶救性命的危急。說到作衣，十誦律說：不論是如量衣還是不如量衣，一切全部聽許，但必須在食物難得之處，食物容易獲得之處則不聽許。智首律師解釋：作衣曠日持久，恐怕耽誤正業，所以開許。說到施衣，在施衣的季節如果不接受，往後需要時難以獲得，接受既能資養身體，也能利益施主得福。說到道路行走與乘船航行，昨天來今天吃，或者明天要走今天吃，都犯戒；必須在當天行走至少半由旬來回而吃的人，才不犯戒。《薩婆多論》說：如果到達了目的地而受食，也沒有犯罪；義理上是說路途中艱難多，而且難以獲得食物。說到大眾集會，是指受食者滿四人成眾，多添一人便成為結犯別眾之過患；這是指在四個人當中多出一人，不是指四個人之外另外有一人乃至百人多出來，以此類推可知。另一種解釋：彼此都構成僧團大眾，八人以上稱為大眾，食物無法雙倍供奉，食物又難以得到，所以開許使其不犯；七人則不是如此，所以說多出一人成為患累。如果食物容易獲得之處，縱然大眾集會，私自別眾吃也得單墮罪。另一種解釋：所謂大眾，是指四人以上，所以比丘尼律說大眾是指四人或者超過四人。又《薩婆多論》說沙門施食，是指外道沙門；除佛法五眾弟子之外，一切出家者都統稱為沙門；義理上是說為了微小的利益而進行化導，用佛法引導他們改邪歸正，所以開許使其不犯。如果沙門邀請之後，還俗成為白衣在家人，或者成為五眾弟子，拿著食物給比丘；或是白衣在家人邀請之後，轉入外道出家成為沙門，親手拿著食物給比丘；這兩種情況吃下去都犯單墮罪。起先是出家五眾邀請，後來轉作外道沙門，也同樣犯戒。《十誦律》說：白衣邀請比丘，後來轉作外道沙門，拿著食物求乞比丘受請，接受邀請得突吉羅罪，吃的人則沒有罪過。

【1544-0002】05_拾毗尼義鈔/04a_卷中之二#37
【原文】問所以白衣俗人不開者答闍王信心施主愛重比丘遂助破僧外道情疎無相親附助成破僧以小益故開。

【1544-0003】05_拾毗尼義鈔/04a_卷中之二#38
【原文】問將九緣配時非時者解云九中作衣衣時唯在時中不通非時餘七通時非時施衣時內不犯時外亦開問若爾時外作衣亦應不犯答施對新得彼此有益作衣已物更無勝利是故不同故四分作衣時者自恣竟無迦絺一月有衣五月廣如彼說問若爾直就時中自得別何須作衣答此舉受持之時。
【譯文】問：將這九種開許因緣配合時與非時來分析：解說者認為：九種因緣當中，作衣與衣時唯獨局限在規定的衣時之中，不通於衣時之外（非時）；其餘七種因緣則通於衣時與非衣時。在施衣時之內不犯戒，在施衣時之外也予以開許。問：如果是這樣，在施衣時間之外作衣，也應當不犯戒？答：施衣是針對新獲得的布施，彼此都有利益；作衣則是處理已有的物品，沒有更多的殊勝利益，所以不相同。因此《四分律》說作衣的時間，是指自恣結束之後，沒有受迦絺那衣時是一個月，受了迦絺那衣時是五個月，詳如彼律所說。問：如果是這樣，直接在規定的時間內自然就能別眾食，何必還要強調「作衣」？答：這是為了舉出受持衣服的時間點。

【1544-0004】05_拾毗尼義鈔/04a_卷中之二#39
【原文】問若有緣不白入不犯重者我有三寶緣不白入聚落亦應犯輕答此須白者為釋他意非所防故白入聚落不同此也問若爾行覆藏六夜有緣出界不白應輕不應失夜答明其病等六緣對治別眾不防於白六夜出界正防失宿不防於白何得將對治難不對治也。
【譯文】問：如果有特殊因緣，不事先陳白便進入聚落不犯重罪，那麼我為了三寶的因緣，不陳白便進入聚落，也應當只犯輕罪才對？答：這條戒必須陳白，是為了釋除他人的疑慮，並非這條戒本來所防範的重點；所以這與為了三寶因緣不白入聚落的情況是不同的。問：如果是這樣，比丘行覆藏罪的六夜苦修，有因緣出界不陳白，也應當只犯輕罪，不應當喪失這六夜的修持？答：這說明了疾病等六種因緣是對治別眾食的，並非用來防範陳白這件事；行覆藏六夜出界，正是在於防範失去夜數，並非防範陳白，怎麼能拿有對治的戒條來難問沒有對治的戒條呢？

【1544-0005】05_拾毗尼義鈔/04a_卷中之二#40
【原文】問別眾食何以不計所別境界多少結罪而結咽咽罪者答本制意為愍白衣為惱僧眾故制不專為損於所別何得偏就所別境界故隨業結不就於境。
【譯文】問：別眾食為什麼不計算所分別大眾境界的人數多寡來結罪，而是隨著每一口嚥下結罪？答：本戒制定的意旨，是為了憐愍白衣施主、避免惱亂僧團大眾而制定，並不是專門為了損害所分別的特定對象；哪裡能偏偏就所分別的大眾境界來論罪呢？所以是隨著自身的犯業而結罪，不依賴於對象境界。

【1544-0006】05_拾毗尼義鈔/04a_卷中之二#41
【原文】問足食勸足二戒有餘食法開讚歎過一食背請別眾過三鉢索美食非時不受殘宿如是九戒何故無耶答二戒曾前犯足貪心更食須法作殘息彼貪過是藥病相當故須開之餘九戒中前六未足一向即犯非對治藥故後三亦未犯足然是非時食體不淨若開作法前人得罪己自招殃復非對治故所以不開。
【譯文】問：足食戒與勸足食二戒，有做殘食法的開許，讚歎戒、過一食戒、背請戒、別眾戒、過三鉢戒、索美食戒、非時食戒、不受食戒、殘宿食戒，這九條戒為什麼沒有殘食法的開許？答：因為足食與勸足食二戒，是先前已經犯了足食，生起貪心還想再吃，必須透過如法作成殘食，來止息那貪心的過失，這是藥物與病情完全相當，所以必須予以開許。其餘九條戒當中，前六條戒在尚未足食時，一造作就直接犯戒，殘食法並不是對治這六條戒的藥物；後三條戒雖然也尚未犯足食，然而或者屬於非時，或者食物本體不清淨，如果開許作殘食法，對方吃下去得罪，自己也招致禍殃，又不是對治之藥，所以不予開許。

【1544-0007】05_拾毗尼義鈔/04a_卷中之二#42
【原文】問別眾戒有六緣此不開何答彼未犯足故以六開既得食充身又長道益此曾前食五正飽足堪一日資身長道若更以六開轉增貪心開成大損非對治藥依四分云對俗人作成小罪足食人前不成法明了祇律皆許成也。
【譯文】問：別眾食戒有六種開許因緣，這足食戒為什麼不開許？答：因為別眾食戒是在尚未犯足食之時，所以用六種因緣來開許，既能讓食物充飽色身，又能長養道業利益；而足食戒是先前已經吃了五種正食吃飽滿足，已經足夠一日資養色身、增長道業；如果再用六種因緣來開許，反而會更加增長貪心，開許將成為極大損害，不是對治之藥。依照《四分律》說：對著俗人作成殘食法，只得小罪（突吉羅），在足食人面前作法是不能成就殘食法的；《明了論》與《摩訶僧祇律》則都准許成就。
