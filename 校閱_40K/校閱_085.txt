# 校閱材料　第085檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【085-0001】02_戒疏/02d_卷一上之二#35
【原文】【疏】就初緣中。統明羯磨作業，僧寶成務。而事有因集，不可妄施，必具十緣方辨前業。
【譯文】【疏文】就最初的助緣部分來說。總體而言，這是在說明透過羯磨來營辦教法事務，從而圓滿僧寶所肩負的弘法道業。然而各項法事都有賴眾緣和合而成就，絕對不可胡亂施行，必定要具備十種助緣，才能成就前面所說的羯磨法事。

【085-0002】02_戒疏/02d_卷一上之二#36
【原文】【記】緣成中，標文。上二句明羯磨功用。言「統明」者，總一百八十餘件，眾別皆然。「而事」下，明作法具緣。「因集」謂假緣成也。
【譯文】【記文】在「緣成」的段落中，標示文意。上兩句說明羯磨的功德妙用。所謂「統明」，是總括了一百八十多種羯磨，不論是大眾作法還是個別作法都是如此。「而事」以下，說明施行法事必須具備助緣。「因集」是指憑藉眾緣和合而成立。

【085-0003】02_戒疏/02d_卷一上之二#37
【原文】【疏】何等為十？一、稱量前事；二、託界成法；三、集僧方軌；四、以法成僧；五、和別相形；六、簡眾淨穢；七、心欲表和；八、陳戒本事；九、提問所宗；十、舉宗成答。
【譯文】【疏文】是哪十種助緣呢？第一是審量前面的事由；第二是依託界限以成立作法；第三是召集僧眾的威儀軌度；第四是以羯磨法成就合格僧眾；第五是和合與分立之相的辨別；第六是簡別大眾的清淨與染污；第七是呈交意願以表達和合；第八是陳述說戒的本事由來；第九是提出詢問確立所宗之法；第十是標舉宗要圓滿回答。

【085-0004】02_戒疏/02d_卷一上之二#38
【原文】【記】別列中。大約為言，一、八及十，緣通事別；餘之七種，緣相俱通。今文第八，隨事顯緣，故云「陳戒」，即行籌告令也。四中「以法成」者，謂自然、作法，各攝分齊，即《羯磨》云「約界明集」是也。
【譯文】【記文】在分別列舉十緣之中。大體說來，第一、第八以及第十緣，其助緣通於一切法，但具體事項各自不同；其餘的七種，助緣的體相則全都是相通的。現在疏文中的第八緣，是隨著眼前說戒之事來顯發助緣，所以說「陳戒」，也就是行籌與告令。第四緣中的「以法成」，是指在自然界或作法界中，各自收攝其應有的法規分限，也就是《隨機羯磨》所說的「依界限以辨明僧集」。

【085-0005】02_戒疏/02d_卷一上之二#39
【原文】【疏】斯之十緣，即十門義。各有量據，不可卒施。具如所撰《刪補羯磨》及彼疏中具辨。臨機引用，廣略隨宜也。其中問答釋疑，一同彼說。若欲寫取，此復何難？以紙墨易繁，時功難駐。不獲已者，時復疏之。此既大義，業相因由，理須遙指，何得復略？然有不見彼文者，此乃往緣，以業自責。余老矣，桑榆轉迫，不暇重述也。
【譯文】【疏文】這十種助緣，就是十門精深的義理。各自具有嚴格的分寸與法度依據，絕不可草率行事。詳細的情形，如同我在所撰述的《刪補隨機羯磨》以及《隨機羯磨疏》中所詳細辨析的。在面臨具體機緣引用時，詳盡或簡略應隨宜掌握。其中的問答與釋疑，完全與該書所說的一樣。如果想要將它抄錄到此處，這又有什麼困難呢？只是因為紙張墨水容易造成文字繁冗，而寶貴的光陰卻難以停留挽留。不到迫不得已的情況，才偶爾在此略加疏解。這既然是至關重要的大義、是羯磨行相的起因緣由，在道理上本來就必須遠遠指引學者去查閱彼書，怎麼可以又簡略略過呢？然而有些學者未能得見那部著述，這也是過去世的因緣使然，應當以自身的業障而自加省責。我如今年事已高，桑榆暮年日漸逼近，實在沒有多餘的精力再次重複敘述了。

【085-0006】02_戒疏/02d_卷一上之二#40
【原文】【記】結略中二，初指廣。《隨機羯磨》有二卷，「十緣」見上卷之首。《疏》本四卷，今為八卷。「若欲」下，二、顯略，有二：一慮文繁不逗機故，二恐費時妨自行故。「不」下，示下有所明。「此」下，顯上須對指。「然」下，傷後世不遇。《羯磨疏》者，彼文委辨緣成，廣明非相。作業成敗，被事如非。示眾別之行儀，顯僧宗之綱要。維持修奉，不學焉知？故不見者則投心無所，舉事成非。教既不通，行何所託？況疾滅三寶，無利羣生！實由往世業緣，致使難遭正法。然今鏤板，教府盛傳，我輩獲聞，實唯宿慶。然常情淺狹，貴少賤多，雖復聽尋，尠能注意，寄言後學，勿事悠悠。「余」下，重示略意。日之西垂，影在樹端，謂之「桑榆」。「迫」即訓近，言居世不久，以重修時，七十許矣。
【譯文】【記文】在結語簡略的文句中分為兩層，首先指出廣博的著述。《隨機羯磨》有兩卷，「十緣」見於上卷的卷首。《羯磨疏》原本為四卷，如今改編為八卷。「若欲」以下，是第二層，顯明簡略之意，這有兩點考慮：第一是擔憂文字繁多無法切合當前學人的根機，第二是恐怕耗費光陰妨礙自身的修行工夫。「不」字以下，說明下文中仍會有所闡發。「此」字以下，顯明上述內容必須與彼書對照指引。「然」字以下，感嘆後世學人難以值遇正法。《羯磨疏》這部書，在其中極其詳細地辨明了助緣如何成就，廣泛揭示了非法非相的過咎。羯磨法事的成功或失敗、所對應的事相如法或違法，都展示了大眾與個別行事的軌儀，彰顯了整個僧團律宗的根本綱領。這維持正法與修持奉行的關鍵，若不深入研學又如何能得知呢？所以沒見過此書的人，用心往往無所適從，一有所舉動便成了過失。戒律教理既然不通達，行持又該寄託在何處呢？更何況這會加速三寶的滅亡，對一切眾生毫無利益！這實在是由於過去世的業力因緣，才導致難以值遇這無上的正法。然而如今該書已經雕刻版印、在佛教界廣泛流傳，我們這一代能有幸聽聞獲閱，實在全憑宿世的大福報。然而凡俗之情多半淺陋狹隘，珍貴稀有之法卻賤視常見之物，雖然時常聽聞探尋，卻很少有人能夠真正用心注意。在此謹寄語後世學人，切莫悠悠度日、虛擲光陰。「余」字以下，再次表明文字簡略的苦衷。太陽向西落下，餘光映在樹梢，稱為「桑榆」。「迫」就是逼近的意思，說明自己在世間的時日已經不多，在重修此疏之時，年紀已經大約七十歲了。

【085-0009】02_戒疏/02d_卷一上之二#43
【原文】【律】和合？
【譯文】【律文】大眾是否和合？

【085-0010】02_戒疏/02d_卷一上之二#44
【原文】【疏】言「和合」者，將欲廣說，情事相違，義須先和，方應後集，故言「和」也。
【譯文】【疏文】說到「和合」，是因為將要詳細宣說戒條，而個人的情意與所辦的事務難免會有分歧相違，在道理上必須先讓眾人和順協調，然後才能順應接下來的集會，所以說「和」。

【085-0011】02_戒疏/02d_卷一上之二#45
【原文】【記】和合中，初科。「情事」，「情」即僧心，「事」即說戒。事涉是非，情容異見，故有「相違」。
【譯文】【記文】在「和合」的第一個科判中。「情事」的「情」是指大眾的心意，「事」是指說戒法事。事相牽涉到正確與錯誤，心意容易產生不同的見解，所以才會有「相違」。

【085-0012】02_戒疏/02d_卷一上之二#46
【原文】【註】時，有與同師、知識別部說戒。法當尊重承事，恭敬布薩，一處住和合說戒；違者與罪。佛言，有三種和合：一、應來者來；二、應與欲者與欲；三、現前得訶者不訶。反此，別眾也。
【譯文】【註文】當時，有比丘與同門師長、知己道友分開，另外在不同部眾處所說戒。依律法應當尊重承事、恭敬舉行布薩，在同一個處所住處和合共同說戒；若有違背者，便結相應之罪。佛陀宣示，有三種和合：第一、應當到場的人都到齊；第二、應當給欲的人都給了欲（委託意願）；第三、在座可以提出異議的人都不提出反對。反過來這三點，就是分立成別眾。

【085-0013】02_戒疏/02d_卷一上之二#47
【原文】【疏】注中引「與師友別說戒」者，為表教法所被，元在機緣，緣有和、別。即界無二，遠表無我之理，近成兼濟之能。故須「尊重承事」，用開相利之道也。

【譯文】【記文】在回答中，第一句先判定所犯的罪名。「說」字以下，加以論釋成立。先反推其表面看來的非理。「但」字以下，說明可以比照定罪。「可以」等字句，是說不可以被名相所障礙。「今」字以下，顯示立名的深義。「慮」指的就是「思心所」。雖然沒有形諸言語，但思念發動便如同言說，所以說「依然等同」，這就像默認虛妄妄語同樣被判定收攝在口業之中是一樣的道理。

【原文】【疏】「如諸制戒，相是止善。房、衣、財、食，作法而生，近表作持，遠防作犯。犯既不起，便是止善。可以類也。」
【譯文】【疏文】「就如同戒律中制定的各條戒相，其本質都是防非止惡的『止善』。而房舍、衣物、金錢財物、飲食等戒條，卻是透過具體如法的作法而成立，就眼前看是彰顯『作持』之善，從長遠看則是防範造作罪過。罪犯既然不再生起，這本質便是『止善』。這兩者是可以相互類推的。」

【085-0042】02_戒疏/02d_卷一上之二#76
【原文】【記】舉例中。初示止持，通一切戒。「房」下，別舉作持，例成上義。「作」是搆造，既成「止善」，口止無言，得成惡說。相翻取例，故云「可類」。「房」即二房，「衣」如「離」、「長」，「財」即「畜寶」，「食」如「足」、「別」等，凡此諸戒，並具雙持。
【譯文】【記文】在舉例說明的文字中。首先指出「止持」通於一切戒法。「房」字以下，特別舉出「作持」的各條戒，以旁例來成就上面的論點。「作」是指如法造作營辦，既然能夠成就「止善」，那麼口中停止不說，自然也能構成「惡說」之罪。兩者互相對翻取作譬例，所以說「可以類推」。「房」就是指二房戒，「衣」如「離衣宿戒」、「長衣戒」，「財」是指「蓄寶戒」，「食」如「過足食戒」、「別眾食戒」等，凡是這諸多戒相，全都是同時具備止持與作持兩重意義的。
