# 校閱材料　第253檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【253-0001】03_業疏/08a_卷二之二#86
【原文】次科以前《母論》先結淨厨似在自然，故問決之。答中，初約義釋，以《十誦》中制斷淨地，故先結別界，於中結淨，自然分隔，即彰僧界不結淨厨，故云順《十誦》也。「若」下，結示必然。雖處分淨通在自然，而論明作法，故非所明
【譯文】下一科因為前面《母論》提到先結淨廚似乎是在自然界中進行，所以提出問難予以裁斷。在回答中，首先依據義理進行解釋：由於《十誦律》中明令斷絕大界內部的淨地，所以必須先結一個別立的小界，在其中結立淨廚，自然與大界分隔開來，這便顯明僧界之內不直接結立淨廚，所以說是隨順《十誦律》的旨意。自「若不如此」以下，總結指出必然之理。雖然透過唱白處分的淨地可以通於自然界，但本論所闡明的是羯磨作法結界，所以處分淨地不是此處所要說明的內容。

【253-0002】03_業疏/08a_卷二之二#87
【原文】三、正加法，文中分三：「作者竪三標」下，初列子注，義張相位；「作是言」下，唱也；「羯磨者」下，正明結也
【譯文】第三、正式加行結界之法，文中分為三部分：自「作者豎立三標」以下，首先列出細字注文，按義理劃分標相的位置；自「作是言」以下，是唱明界相；自「羯磨者」以下，是正式宣告羯磨作法結界。

【253-0003】03_業疏/08a_卷二之二#88
【原文】三結解者，亦即前義第四門也。分文云「義張相位」，即立三標，分三相也
【譯文】第三明結解法，也正是前述義門中的第四門。文中所分的「按義理劃分標相位置」，就是指樹立三座標示，以劃分出三種標相。

【253-0004】03_業疏/08a_卷二之二#89
【原文】初中且舉大界一塲，故列三相三體。必更緣須諸界，亦隨界立體，可以準知。盡自然集，不云標者，以塲多小，不越自然；必更寬廣，終妨後法，理不開也。然律文中，場中相覓卒不能得，據此復寬，宜從制也
【譯文】在第一部分中，暫且舉出一個大界圍繞一座戒場的情況，所以列出了三種標相與三種實體。如果另外依因緣需要增設其他各界，也是隨各個界立其界體，其理可以準此得知。文說「盡自然界限集僧」而不說特定標相者，是因為戒場大多狹小，不會超越自然界的範圍；如果戒場更加寬廣，終究會妨礙日後的僧事作法，在法理上是不開許的。然而律文中記載，在戒場中互相尋找竟急切不能找到，根據這段文看來，戒場也有可能過寬，因此理應依循限制法度。

【253-0005】03_業疏/08a_卷二之二#90
【原文】隨釋中初科，初明三相。「緣須諸界」，謂眾院、別房，皆通別結，隨有更立，不止三重。「盡」下，次釋集僧標相，兩集今但依相，故須顯意。下引律文，場界太寬，令從本制，即前所引說戒法中比丘在場或求不得，明非狹矣
【譯文】在隨文釋義的第一科中，首先說明三種標相。「緣須諸界」是指大眾院舍、個別房舍，都通許個別結界，隨其需要另行立界，就不止於三重界圍了。自「盡自然集」以下，其次解釋集僧的標相，大界與戒場這兩處集僧如今只依標相而定，所以必須彰顯其意旨。其下引用律文，指出戒場若太寬廣，應當令其依從原本制度，也就是前面所引說戒法中比丘在戒場上甚至尋求不到他人，這顯明戒場絕非狹小之處。

【253-0009】03_業疏/08a_卷二之二#94

【253-0010】03_業疏/08a_卷二之二#95

【253-0011】03_業疏/08a_卷二之二#96
【原文】問：場與大界兩是別住，應具二同，何得無者？答：場興本為作業，不在安僧，故無住處；住既非有，故說亦無。大界不爾，元對別說、別利，故彰二同；戒場無有所對，故俱無也
【譯文】問：戒場與大界兩者都是各自獨立的別住界域，理應具備住、說二同，為什麼戒場完全沒有呢？答：戒場的興立原本是為了羯磨作法，目的不在於安頓居住僧眾，所以沒有住處的含義；住既然不存在，說戒也就無從談起。大界則不是這樣，大界最初是為了防範個別私下說戒與個別受取利養，所以要彰顯同住與同說「二同」；戒場沒有這類相對治的過失，所以兩者都沒有。

【譯文】第二個問答正是針對不設立「同住」而發問，因其連帶涉及「同說」，所以一併具足提出。在回答中，首先敘述戒場不宣讀二同有兩層含義：一不是為了安頓僧眾居住，二沒有相對治的非法境界。下文說明大界宣讀二同的用意與此正好相反，其理顯而易知。

【253-0013】03_業疏/08a_卷二之二#98
【原文】問：所以說、恣二法須場僧集，餘法不須者？答：此二攝取僧法，位居行淨之人，故制界之內外，普同遵故。羯磨餘法，所被多途，無局於時，多緣別務。若制通集，還復相勞，徒有前開，終無後益。故作法時，異界有人，不兩相集，所以文中無「同說戒
【譯文】問：為什麼說戒、自恣這兩種法必須戒場僧人前來合集，而其餘作法卻不需要（場僧前來）呢？答：這兩種是統攝包容全體僧眾之法，參與者的地位都是梵行清淨之人，所以制度要求界內與界外的僧眾普遍共同遵行。而羯磨的其餘各法，所應用的因緣門徑很多，在時間上沒有嚴格局限，多半是因緣於個別事務而發起。如果強制要求全體普遍集合，又會相互拖累勞頓，徒然有了前面開許結場的美意，最終卻沒有後續減輕負擔的實益。所以在作其他法時，不同界內雖有人在，並不兩相召集，因此文中沒有「同說戒」的文詞。

【253-0014】03_業疏/08a_卷二之二#99
【原文】三問，據前緣集已明，今欲更申教意，雖重而別，對尋可見。答中，初明說、恣，羯磨「下」，次明餘法。「所被多途」，反上專被行淨；「故無局時」者，反上時限定故；「多緣別務」，反上唯攝僧故。「所以」下，準通別兩集，復決前義。大界有通集，故牒二同；戒場唯別集，故無同說；既無同說，因無同住，故不牒二同，義益顯矣
【譯文】第三個問答，依據前面的因緣召集原則本已闡明，如今想要進一步申說佛陀制教的意旨，雖然看似重複但有所區別，對照推尋便可明白。在回答中，首先闡明說戒與自恣；自「羯磨餘法」以下，其次闡明其他羯磨。「所被多途」是反照前文的專門加被行淨之人；「無局於時」是反照前文的時間規定固定；「多緣別務」是反照前文的專一統攝僧眾。自「所以」以下，準照通集（全體集合）與別集（部分集合）兩種情況，再次決斷前面的義理。大界有全體通集，所以宣讀二同；戒場只有個別別集，所以沒有同說；既然沒有同說，也就因而沒有同住，所以不宣讀二同，其義理更加顯明了。
