# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】四雜法。《四分》：蘭若比丘，乞食至蘭若中，往常食處，淨掃灑，具水器、殘食器、床座、洗脚石、盛水器、拭脚巾。若見餘蘭若來，應遠迎，為取鉢、取衣，舒張有污者，應拭揉、抖擻、浣暴；等令其坐訖，與彼水器及水、洗足石、拭脚巾，持革屣安左邊，勿令水漬；彼洗足已，洗足諸器物復本處，將澡豆，淨洗手。別留賊食。便授水，與彼比丘已；次授食，供給所須苦酒鹽菜等；若熱應扇。若日時欲過，應俱食；不爾者待彼食已，取鉢自食已。有餘食者，應與人、若非人；若淨地無草處，無蟲水中。餘諸食具淨洗，復本處，淨掃食地。有賊來者，語言：此是水，此是食，為汝等故，別留淨潔，若欲食便食之。須善知夜時節，及以方相星名，恐賊來問答有失。《十誦》開練若讀星經。若見人來，先共語，和悅顏色，不應垂頭，應正憶念。餘如《四分》。《四分》開用鑽木出火，在屏處亦開用火珠。《善見》：若頭陀比丘，雖住寺中，不住僧房，不食眾食，施主自為起房，僧不得差為知事。若比丘有能讀誦、教化、說法，能利僧者，亦不得差為知事；好房舍衣鉢先與之，飲食果木得加分與。《五分》：若不捨十二頭陀法，在人間受請，一一吉羅；若不能者，皆應捨頭陀法。
【譯文】第三種是利益他人；第四種就是將心念寄託於殊勝境地；如果睡眠或者掉舉散亂，就會離開憶念諸佛，所以不躺臥。下面指出論書，也就是《解脫道論》；那部論說：長坐不臥的功德，能斷除產生懈怠之處，除非是為了身體生病（開許疾病的因緣），遠離貪著觸覺的安樂，減少纏繞的睡意；恆常保持清淨寂靜，能夠堪受修習禪定，這是善人所行持的法，修習這種善業是毫無疑義的。第三段中。十種利益，前三項對治貪圖享樂，第四項就是脫離苦惱，第五項是不放縱性情，第六、七項是成就道業，第八項是心神爽朗，第九項是身體安穩，第十項是營求之業輕省。

【原文】四分之一，即乞食別行。初正示行相。匃音蓋，亦乞也。與鬼神者，即今施食。若下，因引乞法。先破禁戒者，或在家破五八，或出家反道者。可譏嫌處，即婬女家酒肆等。十住中。彼無餘食一揣，故有此二，與上不同。各有十利者，彼云：受毳衣有十利：一在麁衣數〔謂同糞掃衣行。

【364-0004】資持記/15a_下三#56
【原文】彼云：一法衣相應，謂糞衣、及三衣〔即衣二也〕；五法食相應，謂乞食、次第乞、一坐、節量、時後不食〔食五是也〕；五法坐臥相應，無事處〔蘭若〕、樹下、露地、塚間、遇得處〔處五是也〕；一勇猛相應，謂常坐不臥。然是勇猛之一事，故加之分二字。〔食中多次第乞，餘同《四分》。〕《十誦》。

【364-0005】資持記/15a_下三#57
【原文】多雨處，四月在露，即冬分也；八月在覆，春夏雨多也。少雨反前者，冬春八月在露，夏四月在覆。結指中，初指前列。統下，揀諸文。彼論先總列名，次總顯相，後逐行別明；一一行中，竝先示過，二明受，三顯德，四辨失，故云次第詳悉等。
【譯文】多雨的地方，四個月在露天，也就是冬季；八個月在有掩蔽的地方，因為春夏兩季雨水多。雨水少的地方則與之相反，冬春八個月在露天，夏天四個月在掩蔽處。在結尾指示（結指）中，首先指示前面的羅列說明。「統」字以下，辨析簡別各部文獻。那部論先是總體列出名稱，次總體顯明行相，最後逐條行持分別說明；每一項行持之中，全都是先指明過患，第二說明如何受持，第三顯明功德，第四辨識失缺，所以說次序詳盡周全等等。

【364-0008】資持記/15a_下三#59
【原文】雜法，即蘭若中所須之事。初中，《四分》，前明備所須。若見下，次明待同學；又三，初迎接。令其下，浣濯。便授下，與食。有餘下，三明食已法。與人，即乞匃者。非人，即施鬼神禽畜等。淨地水中，或無人畜；留置淨處，擬後施故。有賊下，四明待賊法。制知時節，防賊難故。下引《十誦》。

【364-0009】02_戒疏/19c_卷四下之一#5
【原文】【記】二中。初引古，有四：一、謂「三年一閏」；二、謂「減小成閏」；三、「減大」，謂取頻大；四、「布薩」法。彼謂後二「不合」抽減。「並」下，斥非。初句總斥。「不」下，別斥閏餘。「勘餘曆」者，通指諸家陰陽曆術。「日餘」等者，謂日別抽減，豈唯小月？「三十二、三月」等者，謂數月成閏，則有五年再閏，豈唯三年？下文備筭，方見昔非。
【譯文】【記文】在第二段中。首先引述古說，共有四點：第一、主張「三年一閏」；第二、主張「縮減小月以湊成閏月」；第三、「減大」，是指連續出現大月的情形；第四、「布薩」之日。古人認為後兩種情況「不合道理」，不可隨意抽取縮減。從「並非」以下，是駁斥其謬誤。第一句為總體駁斥。「不入」以下，是分別駁斥其對閏餘的錯誤理解。「查驗其他曆法」，廣泛指涉各家陰陽曆算之學。「每日餘分」等語，是說明每天都有零星餘分被抽減，豈會僅限於小月？「三十二、三個月」等語，是說積累若干月方成一閏，因此也會有五年兩閏的情況，哪裡只有三年一閏？下文將詳細運算，屆時便能看清古說的錯謬。

【364-0010】02_戒疏/19c_卷四下之一#6
【原文】【疏】又云：「必是受後疑方開之，無容先開，以年小故。」今亦不同。此開得戒，非謂「筭出方得」。此戒體業，乃是壇上白四時生。故知胎、閏積成歲者，理是滿位，故說得戒。今先筭出，深知能持，與戒無損。
【譯文】【疏文】古人又說：「必定是受戒之後生起懷疑，才能開許推算，絕不容許在受戒前就預先推算，因為當時年歲尚小。」現在的見解也與此不同。這裡開許算足而得戒，並非是指「要等推算出來的當下才得到戒體」。戒體之業，乃是在戒壇上行白四羯磨的那一刻生起的。因此可知，以胎月與閏月積累成歲者，在法理上本來就已達到滿足之位，所以說能夠得戒。如今預先推算明白，確切知道他有能力持戒，這對得戒並無任何損害。

【364-0011】02_戒疏/19c_卷四下之一#7
【原文】【記】三中。彼謂本受不知，後疑開筭，若先知不滿，則不開之。「今」下，斥非。初明受已開筭，為決前疑。「今」下，次明未受先筭，據理同得。
【譯文】【記文】在第三段中。古德認為受戒時原本不知情，事後生疑才開許推算，若事先已知年歲不足，則不予開許。「今解」以下，駁斥其非。先說明受戒後開許推算，是為了解決先前的疑惑。「今先」以下，接著說明未受戒前預先推算，依理而言同樣可以得戒。

【364-0012】02_戒疏/19c_卷四下之一#8
【原文】【疏】故訪諸部廣明受相，然後為依《四分》開法。
【譯文】【疏文】因此必須遍查各部律藏，廣泛探究受戒的法相，然後才能依照《四分律》確立開許推算之法。

【364-0013】02_戒疏/19c_卷四下之一#9
【原文】【記】今解中，標分。云「訪諸部」者，「訪」謂尋討也。
【譯文】【記文】在現今的解釋中，這是標示綱要之處。經文說「遍查各部律」，所謂「訪」，即是尋訪考討的意思。

【364-0014】02_戒疏/19c_卷四下之一#10
【原文】【疏】《十誦》中：「若年不滿二十，自想不滿，或忘不知，僧問滿不，答『滿』得戒，『不滿』不得戒。若年滿二十，若知、不知或疑，答僧言『滿』得戒，答『不滿』不得。若答『不知』，若疑，皆得戒，僧犯吉羅，不審諦故。」
【譯文】【疏文】《十誦律》中記載：「若是年歲不滿二十，自己認為不滿，或者遺忘而不知，僧團詢問年歲滿否時，若回答『已滿』則得戒，若回答『不滿』則不得戒。若是年歲已滿二十，無論自己知道、不知道或心生懷疑，只要回答僧團說『已滿』就得戒，回答『不滿』則不得戒。若是回答『不知』或『懷疑』，都能得戒，但僧團犯突吉羅罪，因為沒有詳加審查考實的緣故。」

【364-0015】02_戒疏/19c_卷四下之一#11
【原文】【記】初《十誦》。初約不滿，答僧有二。「若」下，次約年滿，答僧有四。得否可見。
【譯文】【記文】首先是《十誦律》。前半段就年歲未滿而言，回答僧團的情形有兩種。「若年滿」以下，次就年歲已滿而言，回答僧團的情形有四種。能否得戒，條文清晰可見。

【364-0016】02_戒疏/19c_卷四下之一#12
【原文】【疏】問：「知滿二十，答『不滿』者？」
【譯文】【疏文】提問：「如果自己明知已滿二十歲，卻回答『不滿』，情況如何？」

【364-0017】02_戒疏/19c_卷四下之一#13
【原文】【疏】《多論》解云：「不欲受戒，師強與受，故言『不滿』。若不知若忘，縱答『不滿』，亦得戒，以從實故。」
【譯文】【疏文】《薩婆多論》解釋說：「這是因為當事人不想受戒，戒師勉強為其授戒，所以故意說『不滿』。若是因為不知或遺忘，縱使回答『不滿』，也能得戒，因為必須以客觀事實為準。」

【364-0018】02_戒疏/19c_卷四下之一#14
【原文】【記】問中。以自知滿豈答不滿，又復實滿云何不得？故引《多論》，決前《十誦》。
【譯文】【記文】在問答中。既然自知已滿，為何還會回答不滿？又既然實際上已滿，為何會不得戒？因此引述《薩婆多論》，來決斷前述《十誦律》的意涵。

【364-0019】02_戒疏/19c_卷四下之一#15
【原文】【疏】《僧祇》中：「若不滿二十兩，半謂滿無犯，半謂不滿者提，名受具足。俱謂不滿，不名受具。雖滿二十兩，俱謂不滿，不名受具。」
【譯文】【疏文】《僧祇律》中記載：「若不滿二十個雙年，羯磨僧中半數認為已滿則無犯，半數認為不滿則犯波逸提，此時名為受具足戒。若全體都認為不滿，則不成受具足戒。即使已滿二十個雙年，若全體都認為不滿，也不成受具足戒。」

【364-0020】02_戒疏/19c_卷四下之一#16
【原文】【記】二、《僧祇》。「二十兩」者，「兩」即數也，或可彼取俗年滿二十，又須僧臘滿，故云「兩」也。彼具云：「如冬時生冬時受，春時生春時受，前安居生前安居受，後安居生後安居受，此四皆未經安居竟，皆名不滿。若冬時生，若春時生，若前安居生，並經前安居竟受，後安居生後安居竟受，皆名滿二十，滿二十兩。」文中，初明不滿得否。「半謂滿不滿」者，即十僧中，半僧不知而受，故無犯也，半僧知而為受，故犯提，不妨得戒。「俱謂不滿」，合眾同知，則不得戒，師、僧有犯。「雖」下，次明滿者容有不得，謂究勘不知，想謂不滿，情虗強受，無戒得罪。
【譯文】【記文】第二引述《僧祇律》。所謂「二十兩（雙）」，「兩」就是數目，或者可能指世俗年齡滿二十歲，同時僧臘的結夏安居也須圓滿，所以稱為「雙」。該律具體說明：「例如冬天出生冬天受戒，春天出生春天受戒，前安居出生前安居受戒，後安居出生後安居受戒，這四種情況都未曾完整經歷一期安居結束，全算作不滿。若冬天出生、春天出生、或前安居出生，都經歷前安居結束之後才受戒；後安居出生在後安居結束之後受戒，這都算滿二十歲，也就是滿二十個雙期。」經文中，首先說明年歲未滿時的得戒與否。「半數認為滿或不滿」，是指十位僧人中，有半數不知內情而授戒，所以無犯；另半數知情卻仍為其授戒，所以犯波逸提罪，但這並不妨礙戒子得戒。「全體都認為不滿」，僧眾全體明知不滿而授戒，則不得戒，戒師與全體僧眾皆獲罪。「雖滿」以下，次說明已滿二十歲者也有可能不得戒，即僧團未曾仔細核查，心想認定年歲未滿，在心懷虛妄懷疑下勉強授戒，則戒子不得戒而僧眾得罪。
