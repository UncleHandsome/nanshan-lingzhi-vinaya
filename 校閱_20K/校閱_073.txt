# 校閱材料　第073檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【073-0001】01_行事鈔/07c_卷中之三#11
【原文】七食須觀門。五別：一計功多少，量彼來處；二自忖己德行，全缺多減；三防心顯過，不過三毒；四正事良藥，取濟形苦；五為成道業，世報非意。故《明了論》中云：餘一切文句縱廣道應知，解云：出家人受食時或受竟，先須觀食，然後啖之。廣如下卷〈對施興治〉中。但每日恒須。恐未見後文，故略知大旨。不爾，徒自衣食，終為聖訶。《毘尼母》中：鈍根比丘總作一念；利根比丘口口作念，著衣者著著作念，入房入入作念。不爾食出腹中，亦如後卷。
【譯文】第七、進食必須作觀想的法門（五觀）。分為五項：第一、計算食物經過了多少工序勞力，思量它從施主處得來之不易；第二、自我反省審度自己的道德德行，究竟是圓滿還是殘缺、是增多還是減少；第三、防護自心、顯發省察過失，貪瞋癡三毒不起貪求最為關鍵；第四、把食物正確認識為治病的良藥，只是為了療愈身體飢渴之苦；第五、進食純粹是為了成就無上道業，並非貪求世俗名聞利養果報。所以《律二十二明了論》中說：「其餘一切戒律文句縱廣深遠的道理都應當了知。」解釋說：出家人接受食物時或接受完畢後，必須先觀想食物的實相，然後再吃。詳細內容如同後卷〈對施興治〉篇中所說。但這是每日日常都必須修行的，擔心大家還沒看到後卷文義，所以在此先略述大旨。否則，白白接受信眾衣食供養，最終必遭聖人呵斥。《毗尼母經》說：鈍根的比丘總括作一次觀想即可；利根的比丘則每吃一口都作觀想，穿衣時一邊穿一邊作念，進入房中時每進一步都作念。若不如此，所食之物會破腹而出（裂腹而出），這也正如後卷所述。

【073-0002】01_行事鈔/07c_卷中之三#12
【原文】八正受食法。《四分》：受有五種：手與手受，手與持物受，持物與手受，若持物授持物受，若遙過物如上說。復有五種：身衣曲肘器與，還以上四受；若有因緣置地與。《十誦》：淨人不解行食，半在鉢半棄地。若墮所受草上，應食；若著土，吹却食；土多者，水洗食之。《僧祇》：下時覺，墮鉢中時不覺；二初下不覺，墮時覺。此二俱非威儀，名受食。《十誦》：行食時，淨人輕比丘，故觸比丘手，不應受；不輕者，得。
【譯文】第八、正式接受食物的法則。《四分律》說：受食有五種方式：用手給予、用手接受；用手給予、手持器物接受；手持器物給予、用手接受；手持器物給予、手持器物接受；或者隔空拋遞物品如同前述。又有五種方式：施主用身體、衣服、彎屈臂肘、器皿來給予，比丘也是以上述四種方式接受；若有特殊因緣，放置在地上給予。《十誦律》說：淨人不懂得如何分發食物，弄得一半落入鉢中、一半掉在地上。如果掉在已經接受過的清淨草墊上，可以食用；如果沾上了泥土，吹掉泥土後可以吃；如果泥土沾得太多，用水清洗後食用。《摩訶僧祇律》說：食物落下時覺知，落入鉢中時不覺知；或者一開始落下時不覺知，落入鉢時才覺知。這兩種情況雖然都有失威儀，但都算受食成立。《十誦律》說：分發食物時，淨人若輕慢鄙視比丘，故意碰觸比丘的手，比丘不應當接受；若不是出於輕慢之意，則可以接受。

【073-0003】01_行事鈔/07c_卷中之三#13
【原文】九明失受法。一決意棄捨失。《了論》：若人不須此物，決捨此食，失受，更食得罪。二捨戒失。《了論》云：先受食已，後捨戒，餘比丘須者，更受。三捨命失。一切退沒故，即如亡人不淨食器，皆不須翻穢。四任運失。謂曾受四藥過時，法滿更無有受，如後律中。五轉變失。如麻出油、漿變成酒、酒變成醋、生變成熟，並失本受。若爾，《僧祇》中，何故展轉不失？答：此謂時中加記識故，後得無過；若時中不記者，皆不成法。六遇緣觸失。如《多論》淨人觸失，更洗手受。《僧祇》亦爾。
【譯文】第九、說明失去受食效力的情況（失受法）。第一是決意棄捨而失去效力。《律二十二明了論》說：如果有人不再需要這件食物，堅決捨棄它，這件食物就失去了受食效力，如果再去吃它就會犯罪。第二是捨戒而失去效力。《律二十二明了論》說：比丘原先已經受了食物，後來捨戒還俗，其他比丘若需要這份食物，必須重新接受受食。第三是捨命而失去效力。因為身命已終，一切權利歸屬皆已退失消滅，就像亡僧的不淨食器一樣，都不需要再依翻穢法清洗令淨。第四是任運自然失效。指接受了四種藥物超過了規定的時限，期限一滿，受食效力自然消失，如同後文戒律中所述。第五是性質轉變而失去效力。例如胡麻榨出油、果漿發酵變成酒、酒發酵變成醋、生食烹煮變成熟食，都失去原本的受食效力。若這樣的話，《摩訶僧祇律》中為何說輾轉加工不失受食效力？回答：這是指在規定的有效時間內加持作了記識，所以後續加工沒有過失；如果未在時限內作記識，都不能成立如法受食。第六是遇緣觸碰而失去效力。如《薩婆多論》說被淨人碰觸而失去效力，比丘應當重新洗手再接受。《摩訶僧祇律》也是這樣規定的。

【073-0004】01_行事鈔/07c_卷中之三#14
【原文】十依文解。《四分》，食五種蒲闍尼，飯、乾飯、麨、魚、肉也。五種佉闍尼如上。五種奢邪尼，穌、油、生穌、蜜、石蜜也。若不與食，自取著口中，咽咽墮。非時、七日，限過亦墮。盡形無緣不受食吉羅。不犯者：取淨水、楊枝。若不受穌油灌鼻，與唾俱出，餘不犯。若乞食時，鳥銜食，若風吹墮鉢中，除去此食，乃至一指爪可除去，餘者不犯。
【譯文】第十、依據戒相條文解釋。《四分律》中，正食（蒲闍尼，即軟食）有五種：煮飯、乾飯、炒麵（麨）、魚、肉。五種咀嚼副食（佉闍尼，即硬食）如前文所述。五種舔舐飲品（奢邪尼）是：熟酥、油、生酥、蜂蜜、石蜜。如果無人給予食物，自己拿取放入口中，每咽下一口就犯一次波逸提（「咽咽墮」）。若是非時藥、七日藥，未經受食或超過受持期限服用，也是犯墮罪。終生服用的盡形壽藥，若無正當緣由而不經受食就吃，犯突吉羅（惡作罪）。不犯的情況：自己取用清淨之水、嚼楊枝。如果未經受食而將酥油灌入鼻腔，酥油隨唾液一同吐出棄置，殘留體內的其餘微量不犯戒。如果在乞食時，飛鳥嘴銜食物掉落、或被風吹落入鉢中，只要把這塊外來的食物剔除，乃至挖除一指甲蓋大小被沾染的部位，吃其餘的食物就不犯戒。

【073-0005】01_行事鈔/07c_卷中之三#15
【原文】索美食戒四十。四緣：一是美食，二無病，三自為已，四食咽犯。《祇》中：不得從屠家乞肉汁；八種，乳酪家亦不得，恐招譏過。蠶家乞綿，亦同於此。《五百問》：不病索好食犯重。律不犯者：病人自乞，為病人乞，或自他交乞，不求自得，一切得。
【譯文】索求美食戒第四十。具備四個條件構成犯戒：一是確實為精美食物；二是身體無病；三是為自己索求；四是吃了並咽下即犯波逸提。《摩訶僧祇律》中說：不得向屠戶索求肉汁；八種珍貴美味，向售賣乳酪的商家索求也不可以，恐怕招致世人的譏嫌毀謗。向養蠶人家乞討絲綿，道理也是這樣。《五百問事》說：沒有疾病而主動索求美食，犯重罪。戒律中開許不犯的情況：生病之人為自己乞求、為了照顧病僧而代為乞求，或者彼此互相為對方乞求，以及不經主動索求而施主自願供養得到的，這一切都可以食用。

【073-0006】01_行事鈔/07c_卷中之三#16
【原文】與外道食戒四十一。五緣：一是外道，二知，三自與食，四非置地使人，五彼手受便犯。《五分》：乞食乞兒乞狗畜，量己食分減施。《十誦》：外道伺求長短，與食不名污家。《多論》：與無見人不犯，若眾僧與外道食無過，不得手與。
【譯文】親手給予外道飲食戒第四十一。具備五個條件構成犯戒：一是對方確實是外道異教徒；二是自己明知對方是外道；三是親自親手給予食物；四是沒有放置在地上或差遣淨人轉交；五是對方用手接過食物便立即犯波逸提。《五分律》說：以乞得的食物施與小兒、施與犬等牲畜時，應衡量自己的食量，分減一部分布施給牠們。《十誦律》說：外道常在暗中窺伺挑剔比丘的長短，布施食物給他們，並不屬於破壞信徒信心的「污家」過失。《薩婆多論》說：如果給予邪空外道（住邪見無正見者）食物，則不犯戒；如果是僧團公眾給予外道食物也沒有過錯，但依然不得親手遞給他們。

【073-0007】01_行事鈔/07c_卷中之三#17
【原文】不囑同利入聚戒四十二。五緣：一先受他請，以不受故，佛開不囑入村；二食前後；三不囑授；四詣餘家無緣；五入門犯。《僧祇》：若乞食比丘，次行乞食到檀越家，即請令住，因往他家，得二墮。如上背請中。義準若一人受請，無同請者，須白請家，或白淨人，後得餘行。一不惱食主，來問知處故。彼律又云：若二比丘各受常請，交往亦爾，須白施主。《四分》云：食前者，明相出至食時；食後者，從食時至日中。家者，男子女人所居。白餘比丘者，同一界住。若囑授，詣村而中道還，或至餘家，或至寺內庫藏處，及邊房，若至尼寺中，若出彼白衣家；並失前囑授，當更囑他；不者，入門墮。不犯者：若病，若白，若迦提時，若施衣時，若無比丘囑，至餘庫藏及尼寺，若家家多敷坐具請比丘。《十誦》：若食不足，若不正，餘處求，不犯。《多論》：主人明日供，今日往，墮；除主人喚。廣如下卷。
【譯文】受請後不告別同住比丘而擅入村落戒第四十二。具備五個條件構成犯戒：一是先前已接受他人的齋食請供（若未接受邀請，佛陀開許不需告別即可入村）；二是在食前或食後的時段；三是沒有向同住的比丘囑託告知；四是無特殊因緣而前往其他人家；五是腳一跨入門檻即犯波逸提。《摩訶僧祇律》說：如果是依序行乞的比丘，挨家行乞到某施主家時，施主隨即邀請他在家用餐，比丘中途又前往別人家，犯兩個波逸提罪，正如前文「背請戒」中所述。依照義理推準，如果只有一人接受邀請，沒有共同受請的比丘在場，則必須告知請客的主人家，或者告知淨人，然後才能去別處行走。一來是不讓請客的施主生煩惱，二來是施主若來探問時能知道去處。該律又說：如果兩位比丘各自接受長期的固定供請，互訪交往也是如此，必須先告知施主。《四分律》說：「食前」，是指天明破曉（明相出）到進食之時；「食後」，是指從進食完畢到正午日中之時。「家」，是指俗家男女居住的屋舍。「白餘比丘」，是指告知在同一結界內共住的比丘。如果已經囑託告別，走向村落而在半路折返，或者轉往其他人家，或者前往寺內的庫房藏室，以及偏遠邊房，或者前往比丘尼寺，或者走出該居士家門；這些都會使先前的囑託失效，應當重新向人囑託；如果不重新囑託，踏入他人家門便犯波逸提。開許不犯的情況：自己生病時、已經告白囑託過、在迦絺那衣月期間、在布施衣物之時、寺內無其他比丘可供囑託、前往其他庫房以及比丘尼寺、或者各家各戶普遍陳設坐具隨時恭請比丘。《十誦律》說：如果受請處的食物不足以飽腹，或者供養不如法不正當，因而前往別處乞求，不犯戒。《薩婆多論》說：施主預定明天供僧，比丘今天就擅自前往，犯波逸提；除非施主臨時召喚。詳細內容如後卷所述。

【073-0009】01_行事鈔/07c_卷中之三#19
【原文】屏與女坐戒四十四。四緣：一是俗女，二屏處，三無第三人，四申手不及戶坐，犯。《多論》：閉戶無淨人墮；開戶，外有淨人吉；戶內有淨人，不犯；《僧祇》：若母、姊、妹、若大小淨人、睡眠、癡狂、嬰兒，雖有是人，名獨。若淨人作務來往不斷，若門向道有行人如食頃不斷，若閣上閣下淨人遙見者，不犯。律不犯者：舒手及戶坐，使乞食比丘見，若二比丘為伴，若有識別人在邊，及難緣，並開。
【譯文】在隱蔽處與女人同坐戒第四十四。具備四個條件構成犯戒：一是對方是俗家女人；二是身處隱蔽不見外人的屏處；三是沒有第三人在場；四是伸手搆不到門戶的地方坐下，即犯波逸提。《薩婆多論》說：關上門且無淨人在場，犯波逸提；打開門，門外有淨人在，犯突吉羅；門內有淨人在場，則不犯。《摩訶僧祇律》說：如果是自己的母親、姊姊、妹妹，或者是大淨人、小淨人處於睡眠狀態，以及瘋癲痴狂者、嬰兒，雖然有這些人在場，在律法上仍視為「單獨一人」。如果淨人因為操持勞務在場穿梭來往不絕，或者門口正對著道路有一頓飯時間行人絡繹不絕，或者樓閣上下有淨人能夠遠遠看見，這些情況都不犯。戒律中開許不犯的情況：伸出手能夠觸及門戶而坐，能讓路過的乞食比丘看見；或者有兩位比丘結伴同行；或者有懂得事理的別人在身旁；以及遭遇危難因緣，都屬開許之列。
