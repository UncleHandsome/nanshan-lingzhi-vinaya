# 校閱材料　第195檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【195-0001】02_戒疏/19c_卷四下之一#42
【原文】【疏】有人依《多論》，數實月為十九年者。今準《四分》，與俗計同。如尼六法云：「十八童女二歲學戒，年滿二十，與受具足。」據此十八，未必年盡為歲，滿十八年朝即是十八，依教便受六法，明年十九方二歲學，後年正朝，豈非二十？如此例之，縱極小者，年暮受法，即此一日便當一年，明年具行，後年正月一日受戒，豈非二十也？若不爾者，要滿十八，至十九年初，方受六法，明年二十，始學一年，年滿學終，後年二十一方與受者。又無律文如此延引。故知剋定以俗年為定。餘文云云，何由可盡！
【譯文】【疏文】有人依照《薩婆多論》，主張必須計算實足的月份達到十九整年。現在依照《四分律》，其年歲的算法與世俗相同。正如比丘尼六法中所說：「滿十八歲的童女應當給予兩年時間學戒，年滿二十歲，再為其授具足戒。」依據這裡所謂的十八歲，未必是指十八個整年全都過盡才算一年，只要進入滿十八歲的那一年正月初一就算十八歲，依教法便能領受六法；到了明年十九歲正好修行兩年，後年的正月初一，豈非就是二十歲？照此推例，縱使是年齡極小的極端例子，在歲末最後一天領受六法，光是這一天便充當了一年，第二年整年修行，第三年正月一日受戒，豈非也是二十歲嗎？若不如此解釋，非要實足滿十八年，等到第十九年之初才准許受六法，到了第二十年才開始學習了一年，學期圓滿結束，要等到第二十一年才為其授戒。但各大律藏中根本沒有如此拖延拉長年限的明文。由此可知，律中規定完全是以世俗通行的跨年算法為準定。其餘律文的議論繁多，哪裡能說得盡！

【195-0002】02_戒疏/19c_卷四下之一#43
【原文】【記】五中。初引彼妄執。《多論》云：「真實不滿，乃至無十九故，所以不開也。」彼謂十九，乃約實月，則俗年二十也。「今」下，舉例難破。成上俗年十九，八月得受之義。初二句，通示。「準《四分》」者，即如下引。「與俗同」者，謂俗中論年齒，亦取跨涉，不數實月。「如」下，引例，又二。初舉文。「據」下，示年數。初約跨涉，合教以證今義。「若不爾」下，次約實月乖文，以顯昔非。「故」下，準決。「餘」下，指廣。
【譯文】【記文】在第五段中。首先引述那些人的妄加固執。《薩婆多論》說：「若真實年歲不滿，甚至連十九歲都不到，所以不予開許。」古人認為所謂十九歲，是指實足計算月份，換算起來世俗虛歲就是二十歲。「今準」以下，舉出先例加以難破。藉此確立上述世俗虛歲十九、在八月即可受戒的主張。開頭兩句為通體開示。「準《四分律》」，即如同下文所引。「與世俗相同」，是說世俗計算年歲，也是採用跨越年份的算法，並不逐月累計實足月份。「如尼」以下，引律例證明，又分為兩層。初舉出律文。「據此」以下，說明年數計算。首先依跨年算法，契合教理以印證今義。「若不爾者」以下，次就實月算法會違背律文，以顯明古說之謬。「故知」以下，依準決斷。「餘文」以下，指示其餘廣泛文證。

【195-0005】02_戒疏/19c_卷四下之一#46
【原文】【疏】凡四諍之興，乖理違法，惱亂僧眾，事必請殄。故須備德，量情安帖，僧眾始靜，方修道業。今輒發起，更增凶熾，助惡揚波，轉成彌漫，壞眾惱僧，過中之甚，故制。
【譯文】【疏文】凡是四種諍事的興起，皆是違背正理、乖違戒法之舉，會惱害擾亂僧眾，依事理必須予以徹底平息。因此必須由德行具足的長老，審度眾人的情緒使之安定平和，僧眾才能恢復清靜，進而修持道業。如今竟然擅自重翻舊帳，使爭執再度熾盛，宛如助長惡行、推波助瀾，讓事態擴散氾濫，破壞僧團和合、惱亂大眾，這在過失中屬於極其嚴重的，所以佛陀制定此戒。

【195-0006】02_戒疏/19c_卷四下之一#47
【原文】【記】六十六，制意中。初敘四諍已滅。「乖理」，即言諍，「違法」，即覓、犯、事三諍。「殄」即是滅。「備德」謂有德之人。「量情」，謂觀察眾心。「安帖」，謂和平令息，「帖」合作「帖」，訓靜也。「今」下，次明重更發起。「揚波」喻上「助惡」，如風波動蕩，隨更鼓之。「彌漫」謂泛廣，「彌」合作「瀰」，大水之貌。
【譯文】【記文】第六十六條，制定戒律的用意中。首先敘述四諍平息之後的狀況。「乖理」即言諍，「違法」即覓諍、犯諍、事諍這三種諍。「殄」就是平息消滅。「備德」是指具備德行之人。「量情」是指觀察大眾的心態。「安帖」是指以平和手段使其止息，「帖」應作「帖」，訓詁為安靜。「今輒」以下，次說明重新挑起諍事之過。「揚波」比喻上面的「助惡」，如同風浪動盪，隨之鼓動波濤。「彌漫」是指大水蔓延廣大，「彌」應當寫作「瀰」，是大水漫溢的樣子。

【195-0011】02_戒疏/19c_卷四下之一#52
【原文】【註】說不了了，突吉羅。除此諍，若餘鬬罵發者；若發已諍；除二眾，若餘人諍，而發起者——一切吉羅。尼同犯。不犯者：若先不知；若觀作不觀想；若事實爾，語言「不善觀」等。若戲，若錯說者，不犯。
【譯文】【註文】若言說表述不夠清楚明白，犯突吉羅罪。除了這四種僧團諍事之外，若是挑起其餘私人間的爭鬥罵詈；或者是挑起自己個人的爭執；或是除僧尼二眾之外、挑起其他人的諍事者——全都犯突吉羅罪。比丘尼同樣犯此戒。在不犯的情況中：如果起初確實不知諍事已平息；或者誤把如法止諍當作非法止諍；或者事實本就如此，而言語只是在客觀指出「未能妥善止諍」等；若是開玩笑，或是口誤說錯話，都不算犯戒。

【195-0012】02_戒疏/19c_卷四下之一#53
【原文】【疏】戒本四句：一、人；二、是四諍，簡餘鬬諍不能陷僧；三、如法滅；四、發起結。
【譯文】【疏文】戒本分為四個文句：第一、指明造業者為人；第二、指明是四種僧團諍事，藉此簡別其餘私下爭鬥不致於陷僧團於不義；第三、該諍事已如法平息；第四、重新挑起即結罪。

【195-0013】02_戒疏/19c_卷四下之一#54
【原文】【記】戒本。第二中，「餘諍不能陷僧」者，以四諍須僧法滅，若重發舉，即是陷僧。四中，「發起」是過業，「結」即罪相。
【譯文】【記文】戒本條文。第二句中所謂「其餘爭鬥不能陷僧團於不義」，是因為四諍必須透過僧團羯磨如法平息，若重新挑起，便是陷僧團於非法。第四句中，「發起」是過失行為，「結」即是判定罪相。

【195-0014】02_戒疏/19c_卷四下之一#55
【原文】【疏】言「如法懺悔」者，正是相謝之言，如草覆地，兩朋面地相謝之例。亦未必有罪，言諍非罪。亦可有罪之諍，上品如草掩泥，罪、諍同滅，至後為解。
【譯文】【疏文】戒本所謂「如法懺悔」，正是互相謝罪之意，就如同如草覆地止諍法中，雙方代表伏於地面互相謝過之例。這其中也未必一定涉及戒罪，純粹的教理諍論（言諍）本就不是戒罪。但也可以是有罪性質的諍事，例如嚴重的犯諍採用如草覆地法平息，此時戒罪與諍事同時止息，這在後文會詳細解釋。

【195-0015】02_戒疏/19c_卷四下之一#56
【原文】【記】釋中。初科二釋。初約相謝釋。「以草覆地」，兩朋相爭，經年難滅，德人作法，兩眾相對互相伏地。舉此為例，自餘滅諍，義必相謝。此明文中懺悔之言，非謂懺罪，故云「未必有罪」。以四諍中，覓、犯二諍，則可有罪。「言諍」教理，事諍羯磨，故非有罪。「亦可」下，次約懺罪釋。「有罪之諍」，即犯諍。上品犯諍，用草覆滅，毗尼如草，罪諍如泥，則有懺罪之義。後篇廣釋，故此指之。
【譯文】【記文】在解釋中。第一科有兩種解釋。首先就「互相謝過」來解釋。「以草覆地」，是兩派相互爭論、長年難以平息時，由德高望重之人主持法事，兩派代表相對跪伏於地互相謝罪。以此為例，其餘平息諍事之法，在義理上也必然要相互謝罪。這是說明條文中的「懺悔」之詞，並非特指懺除罪業，所以說「未必有罪」。因為在四諍之中，覓諍與犯諍這兩種可能涉及戒罪；而論辯教理的「言諍」與執行羯磨的「事諍」，本來就沒有戒罪可言。「亦可」以下，次就「懺除罪業」來解釋。「有罪之諍」即是犯諍。上品的犯諍採用草覆地法來滅除，以律法如草覆蓋罪惡如泥，此時便含有懺罪的意涵。後篇會詳細解釋，所以此處先作指引。

【195-0038】02_戒疏/19c_卷四下之一#79
【原文】【疏】又解云，欲是非法，濫義安寄？然聖辨障道，結有強弱，上品障見道，下品障思惟，是以道成初果猶有欲事。執此教迹說言不障，言同意異，故須標列。聖言非障者，以治道品殊，敵對而遣，當分障除，異則非此所斷故。有非我障，非謂不障於彼，若生深解，此惑思盡。而今偏執，通言欲性非障，邪正殊途，理在於此。須僧設諫，開示是非。
【譯文】【疏文】另一種解釋說：淫欲本是非法之行，牽強附會的理由從何立足？然而聖者在辨明障道之惑時，結使有深淺強弱之分，上品的結使障礙見道，下品的結使障礙修道（思惟），因此初果聖人證得道果後，在習氣上依然會有欲事。執迷於這種教理跡象的人便藉此宣稱行淫不障道，名詞雖然相同但內涵完全有別，所以必須標明列出。聖者之所以說行淫不障道，是因為對治的道品層次各不相同，各自正對特定的惑業而予以破除，當下的障礙已經去除，其餘細微惑業則非當前道力所要斷除的。因此這只是「不妨礙我當前的證位」，並非指「完全不會障礙後續的高階聖道」；如果能生起甚深的解脫慧，這類思惑最終也將斷盡。如今此人偏執一端，概括宣稱淫欲的本質完全不障道，邪見與正見的途徑在此分道揚鑣，根本原因就在這裡。所以必須由僧團出面勸諫，為其剖析是非正邪。

【原文】【記】次釋中。初二句徵起。由是麤惡，倚濫無從，故云「安寄」。「然」下，正示，又三：初出濫相；「聖言」下，二、明偏執所以；「須僧」下，三、結示須諫。初中，「聖辨障道」者，即就四果以論也。「結有強弱」等者，「結」即結使，不出有十：貪、瞋、癡、慢、疑；身見、邊見、邪見、見取、戒取。此十能「障見諦」，故名見惑，麤故名「強」，又為「上品」。貪等四使，能「障思惟」，故名思惑，細故名「弱」，又為「下品」。初果但破見惑，愛染未亡，故云「有欲」。二果已去，方斷思惑，乃至四果，方能離欲。如《僧祇》中「須、斯二尼，被汙受樂」，《律》中「見諦學家」，猶有夫婦，又有「初果欲心起故，捨戒還家，欲飽還來」等。彼謂得道聖人「猶作欲事」，顯是不障，故興妄說。「須標列」者，發下文也。二、明所以中。「聖言非障」，躡上諸文。「治道殊」者，即斷證之智有淺深故。淺斷麤惡，深除細障，故云「敵對」。「當分除」者，如初果止能除見，未能斷思，故云「異此非所斷」也。「有非我障」，謂有作欲者，但能不障當分見道，「非不障彼」未證修道故。「若生深解」，方入修道，乃至無學，故云「惑思盡」也。反明染欲障道明矣。「而」下，正示倚濫。「通言非障」者，不如上簡也。「邪」、「正」二說，因此而生，故云「理在此」也。三、結示，可知。
【譯文】【記文】在第二種解釋中。前兩句為發起提問。既然淫欲是粗惡的行為，附會的說法根本無從寄託，所以說「安寄」。「然而」以下，正式剖析，又分為三層：第一、指出混淆的根源；「聖言」以下，第二、說明其偏執的緣由；「須僧」以下，第三、總結說明必須勸諫。在第一層中，「聖辨障道」，是就四種果位來論述。「結有強弱」等語，「結」即結使，不外乎十種：貪、瞋、癡、慢、疑；身見、邊見、邪見、見取見、戒禁取見。這十種能「障礙見道」，所以稱為見惑，因其粗顯故稱為「強」，屬於「上品」。貪等四種煩惱能「障礙修道」，所以稱為思惑，因其微細故稱為「弱」，屬於「下品」。初果聖人只破除了見惑，愛染習氣尚未全盡，所以說「猶有欲事」。二果以上才逐漸斷除思惑，直到四果阿羅漢才能徹底離欲。如《僧祇律》記載「須陀洹與斯陀含二位證果比丘尼，被強暴受染時於生理生樂」，《律》中提到「見諦學家」（證得見諦果位的在家人家庭），依然有夫婦生活，又有「初果聖人因欲心生起，捨戒還俗，在欲望滿足之後又回歸出家」等記載。邪見者認為得道聖人「依然有欲事」，便妄自推論這顯然不障道，從而興起狂妄的邪說。「須標列」，是為了引發下文。在第二層說明緣由中，「聖言非障」承接上文各處引證。「治道殊」，是指斷惑證真的智慧有淺深差別。淺層斷除粗惡惑業，深層破除微細障礙，所以說「敵對而遣」。「當分除」，是指如初果只能破除見惑，未能斷除思惑，所以說「非當前所能斷」。「有非我障」，是指有人行欲，只不過不障礙他當前已得的見道層次，但「絕非不障礙」他尚未證得的修道層次。「若生深解」，才能進入修道位乃至無學位，所以說「思惑斷盡」。這反過來更證明了染欲障道是極其分明的。「而今」以下，正式指出牽強附會之病。「通言非障」，是沒有依照上述位次進行細緻簡別。「邪說」與「正法」兩條路途，就是因此分歧而生，所以說「理在於此」。第三層結論文意，容易理解。

【195-0059】02_戒疏/19d_卷四下之一#5
【原文】【疏】答：「說欲非障，言說相似，濫於理教以滅正法。又自壞行，障學路。亦順人情，多喜隨順故。餘二條然是非，無滅法過。雖有自壞，隨順者希，無壞人義，故結輕也。」
【譯文】【疏文】答：「主張行欲不障蔽聖道，其言論聽起來似是而非，容易混淆正理與教義從而毀滅正法。再者，這也會敗壞自己的梵行，障礙修學之路。而且這種說法順應世俗人情，眾人多半喜歡隨順迎合。至於另外兩種舉罰（不見罪、不懺罪），是非分明、條理清楚，沒有毀滅正法的過失。（這另外兩種被舉之人）自身雖然有所敗壞，但隨順附和他們的人極少，不具有敗壞他人的性質，所以（隨順者）只結判為輕罪。」
