# 校閱材料　第355檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【記】釋後句中。初二句述意。上句示眾同之制，次句明制集之意。「故」下，貼釋。「晦望」即黑白兩半。促則廢業，延則浮慢，故曰「折中」。
【譯文】【記文】在解釋最後一句的段落中。前面兩句是敘述制戒的用意。上一句明示大眾應當齊集同遵的法規，下一句說明強制召集集會的目的。「所以」以下，是緊扣字句作解釋。「晦望」就是指每月的黑月與白月兩個半月期。時間如果太緊湊就會荒廢道業，時間如果拖太久就會滋生散漫浮躁之心，所以每半個月一次稱作「適宜的中道」。

【355-0011】02_戒疏/02c_卷一上之二#91
【原文】【疏】何名「略教」？以佛初成道，將開化法。創起希仰，寄心無地。故先示行法，令依奉行。不待犯戒，未有罪故，不得懷疑起謗。略陳教法，故曰「略教」。
【譯文】【疏文】什麼叫做「略教」？因為佛陀最初成就聖道時，即將開展教化眾生的法度。弟子們初初生起仰慕向道之心，心念尚且沒有依託歸向之處。所以佛陀先開示修行的通則法度，讓大家依循奉持推行。這不需要等待有人犯戒，因為當時還沒有任何罪愆產生，也就不會對教法生起懷疑毀謗。只是簡略地陳述法度大綱，所以稱作「略教」。

【355-0012】02_戒疏/02c_卷一上之二#92
【原文】【記】初章，略名中。初標徵。「以」下，正釋。初二句示教興之時。「創」下，明機緣已發。「故」下，明立教。「不」下，示名相。「不待犯」者，異廣教故。「不得懷疑」者，謂若即制廣，容生疑謗，知機制略，不得生故。
【譯文】【記文】在第一章說明「略教」名稱的段落中。首先標出問題提出徵問。「因為」以下，是正式解答。前兩句指出教法興起的歷史時機。「初初」以下，說明眾生的求道機緣已經引發成熟。「所以」以下，說明建立教法的緣由。「不需要」以下，顯示其名詞的法相。「不需要等待有人違犯」是為了有別於後來的廣教。「不容許懷疑」是說如果在一開始就制定極其繁瑣的廣教條文，容易讓人起疑謗法；佛陀深知根機而制定簡略條文，正是為了杜絕疑謗的產生。

【355-0013】02_戒疏/02c_卷一上之二#93
【原文】【疏】言「廣教」者。由略名含，未曉前相，雖造諸非，不謂有犯。故須廣張網目，收攝罪聚。鈍根之流，聞便得解。因廣說故，名為「廣教」。
【譯文】【疏文】所謂的「廣教」。是由於簡略的名稱含意較為籠統，鈍根之人無法明瞭具體的造惡行相，縱使造作了各種非理的行為，也往往不認為自己是在犯戒。所以佛陀必須廣泛鋪展如同網目般細密的條文，用篇聚條目來收攝罪相。那些根機愚鈍的人，聽聞了詳細條文之後便能徹底明白。因為是廣泛詳盡宣說的緣故，所以稱作「廣教」。

【355-0014】02_戒疏/02c_卷一上之二#94
【原文】【記】廣名中。初標，「由」下，釋。準前釋略，亦應四節，但闕初時，廣在略後，自可知故。初明違略，即廣教機生。通禁三業，未列過相，故曰「名含」等。「故」下，明立教。「張網目」者，隨事別制也。「收罪聚」者，科約篇聚也。「因」下，結名。
【譯文】【記文】在說明「廣教」名稱的段落中。首先標出名稱，「是由於」以下，進行解釋。比照前面解釋略教的體例，此處本來也應包含四個環節，只不過省略了最初興起的時節，因為大家都知道廣教必然是在略教之後才出現的。首先說明違犯略教的情形，這正是廣教根機生起的緣由。略教只通盤禁戒身口意三業，並未詳列具體的犯過罪相，所以說「含意籠統」等等。「所以」以下，說明建立教法。「鋪展網目」是指隨著個別犯戒事件分別制訂條例。「收攝罪愆聚集」是指將罪過分門別類歸納於各篇聚之中。「因為」以下，是總結定名。
