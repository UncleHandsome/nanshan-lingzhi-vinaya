== PROBLEM ==
半譯（文白夾雜，整句未譯）。文中「然今行事不可從緩；有病堪能，亦須廣說，方契聖心」十四字完全直接抄錄文言原文，未翻為白話。

== SUGGESTION ==
將該句翻譯為「然而現在推行法事絕不可流於寬緩放任；若有疾病而體力尚堪能者，也必須廣說欲詞，才契合佛陀聖心。」

== ORIG ==
`所以斷語猶進退者，由無明文，且據義決；況略是律開，欲取通意，未可一向，故云難定。然今行事不可從緩；有病堪能，亦須廣說，方契聖心。問現相者。本律有名無相，欲引外部明之，故設此問。`

== CURRENT ==
引述生病的事例來比照健康人，在道理上是難以成辦的。之所以斷定時的語詞還有進退留有餘地，是因為沒有明確的白紙黑字律文，暫且依憑義理來決斷；何況略說是戒律所開許的，若要取其融通的意旨，尚不可一概全然抹煞，所以說是「難以定奪」。然今行事不可從緩；有病堪能，亦須廣說，方契聖心。在詢問顯現身體動作行相的項目中。本律只列出名稱而沒有具體行相，想要引述外部律典來闡明，所以設立這個問答。在回答中，起初列出五種行相。隨順病患所能作出的動作，但也並不僅限於這幾種。從「律」以下，其次告誡必須詳細審查。
