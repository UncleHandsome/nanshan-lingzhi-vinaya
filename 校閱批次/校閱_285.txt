# 校閱材料　第285檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【285-0003】03_業疏/20b_卷四之三#64

【譯文】第二門離合的通篇提示中，首先為總標。自「皆得別受」以下為分別解釋，首句明示分開受。自「就總受中」以下顯明合併受，引懺罪為例證。同名即同篇罪名，律中開許合併懺悔。

【285-0004】03_業疏/20b_卷四之三#65
【原文】或張、王兩緣各是七日，不可合用羯磨半月，以事各是別人所行，止得前後受七日也。如是例之，若俱三日或復互減，可同七日彼此兼用。眾法離合，可例成之
【譯文】或者張家與王家兩緣各自皆需七日，不可合併使用羯磨法受半月，因為兩事各自屬於個人所行之別法，只可前後分別受七日。依此類推，若兩事各需三日或天數互有增減，便可在七日內彼此兼帶共用。僧眾法的分開與合併，亦可依此例推成立。

【285-0005】03_業疏/20b_卷四之三#66

【譯文】個別甄別的首段文字中，必須明白三種事緣的界限範圍：一日至七日皆屬七日緣，八日以上為半月緣，十六日以上為一月緣。文中指明兩家的個別事緣，不得合併改用僧眾法。前後受法者，或指依序作法，或指用盡後再受。互有增減者，如張家需五日、王家需一日等。僧眾法依例成立者，如張家需十日、王家需二十日，便可合併受一個月。

【譯文】在下一科關於增加的辨析中，初段列舉三種版本。第一種就是康僧鎧所出的羯磨，先向大僧乞請，但不將乞請之辭納入羯磨文中，他認為律的正文中本來就沒有乞辭，該本在曹魏時期最初譯出，所以稱為「古」。

【285-0113】03_業疏/21a_卷四之四#37
【原文】第二人雖著乞辭，準乞覆藏，兩徧牒事，時到已前增加乞辭，忍聽已後略事而作，羯磨亦爾，此光師魏集，世盛行也
【譯文】第二種人雖然寫入了乞請辭句，卻是比照乞求覆藏羯磨的做法，兩次宣讀事由：在「時到」之前增加乞請之辭，在「忍聽」之後則簡略事由而作法，羯磨文也是如此，這是慧光律師在北魏時期所編集的羯磨，世間非常盛行。

【285-0114】03_業疏/21a_卷四之四#38
【原文】第二即曇諦本，光師用之，開拓注釋，遂為光本。覆藏羯磨前陳三乞，後方與法。白與羯磨第二句中牒前所乞，故云「兩徧牒事」；第四句單云與法，故云「略事
【譯文】第二種版本原本是曇諦的本子，慧光律師採用它並加以開拓註釋，遂成為「光本」。覆藏羯磨是先陳述三番乞請，之後大僧才給與羯磨法。單白與羯磨的第二句中要宣讀前面所乞之事，所以說「兩遍宣讀事由」；第四句則單純說給與其法，所以說「簡略事由」。

【285-0115】03_業疏/21a_卷四之四#39
【原文】第三人但準六夜乞法，牒緣誦事竝盡，以律文云「不如白法作故，今若增減，竝不成」也
【譯文】第三種人則完全比照六夜乞法，宣讀事緣與誦念事由都詳盡無遺，因為律文說「若不依照如法白告之法而作白，如今若任意增減，羯磨一概不能成就」。

【285-0116】03_業疏/21a_卷四之四#40
【原文】第三即願師本。六夜乞辭，牒前覆藏乞法行日等已，方乞後法。諸羯磨中此最委悉，故特準之，不許簡略，故云「竝盡」。白及羯磨兩徧牒事，大同覆藏，仍引律證明有所準。若論加乞，豈非增耶
【譯文】第三種就是法願律師的版本。六夜乞請辭句，是在宣讀前面覆藏乞法、行摩那埵天數等完畢之後，才乞求後面的出罪法。在各種羯磨法中以此最為詳盡周密，所以他特別比照此法，不允許簡略，因此說「詳盡無遺」。單白與羯磨中兩次宣讀事由，大體如同覆藏羯磨，並且引用律文來證明有所依憑。但若就加入乞辭這點來論，難道不也算是增法嗎？

【285-0117】03_業疏/21a_卷四之四#41
【原文】凡斯三集，文局義通。有人定判依受夏破，今解不然，俱順教故。增乞減乞，各有所憑；羯磨大途，猷規在故。依受不失，至時口解
【譯文】凡這三種羯磨集本，文字雖各有局限，但義理上是相通的。有人斷定判定若依照這些版本受法就會破夏，我們現在的解釋並非如此，因為它們都順應了佛陀的教法。增加乞辭或減少乞辭，都各自有所憑據；羯磨的基本章程，軌範準則依然具足。依之受法並不會失夏，到了期滿時只要口頭解除即可。

【285-0118】03_業疏/21a_卷四之四#42
【原文】次科，初結前所引。「有」下，責其妄判。初雖加乞，法依律文；餘雖入法，各有所準，不可判非。猷，法也。「下令口解」，即如上說
【譯文】下一科中，起初總結前面所引的三本。從「有」字以下，斥責其妄加判定。第一種版本雖然增加了乞辭，但羯磨正法依然依照律文；其餘版本雖然將乞辭納入法中，也各自有所依準，不可判定為非法。「猷」就是法則之意。疏文在下文指示應當口頭解除，就如同上面所說。

【285-0119】03_業疏/21a_卷四之四#43
【原文】近世諸師不加乞辭，準律直誦，以律制斷加乞是增，不敢輙用
【譯文】近世的各位律師則不加乞請辭句，完全依準律文直接誦念，因為律中明文判定增加乞辭屬於增法，所以不敢輕易採用。
