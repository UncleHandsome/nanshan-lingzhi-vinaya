# 校閱材料　第1795檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1795-0001】03_業疏/16a_卷三之五#21
【原文】三、顯體者。一切大乘，莫不皆以常住佛性妙理為體。諸佛所證，安住其中；眾生所遺，日用不覺；包徧十虗，含育萬有。隨順物宜，種種異說：法界、涅槃、中道、實相、圓覺、般若、真如、真空、法性、佛性、唯心、唯識、佛藏、佛母等，故於一法說種種名。今依《楞伽》、《起信》、《唯識》、《攝論》以明藏識。梵云阿梨耶，或云阿賴耶，此云含藏識，謂含藏一切善惡因果、染淨種子。此有二宗：唯識師謂真如隨緣，不生滅與生滅和合，非一非異，名阿賴耶，即真妄和合識；攝論師謂外塵本無，實唯有識，是大菩薩佛果證行，此即全指真如為真識。此亦如來隨宜異說。後有宗師，第八識外別立第九清淨真識。今準《楞伽》略明三種。經云：略說有三種識，廣說有八種相。何等為三？謂真識、現識、分別事識。此約真如隨緣不變、不與妄合為真識，不變隨緣、和合現起為現識（譬如明鏡，眾色像現），餘之七識為分別事識。用此三種，統收諸說。彼經又云：如來藏名阿賴耶，而與無明七識共俱，如大海波常爾不絕。又云：如來藏者，為無始虗偽惡習所熏，名為藏識。今明此識，體本真淨，隨緣妄動，積藏業種，名為第八；轉趣諸根，為第七；流於心意，為第六；徧至五根，為五識。所造成業，第七攬歸第八含藏，成熟來果。果有善惡、依正差別。今就已成差別法中，了無差別，故云唯識。即知十界依正因果同一識體，未有一法而非識者。《楞伽》偈云：「譬如巨海浪，無有若干相，諸識心如是，異亦不可得。」今明戒體，造雖在六，起必因八；造已成種，還依於八。問：八識之相，可得知乎？答：通而為言，法法皆是；別就己身現前陰入，無非識變。始來末去，任持報命，六識依止，憶持往事，睡眠魂夢，故習瞥起，皆可知也。四、出立意。問：二宗談體自足，何須別立圓教？答：兩宗出體，教限各殊。若唯依彼，則辨體不明；若復不依，則宗途紊亂。故準二經，別立一教，窮理盡性，究竟決了。使夫學者，修持有託，發趣知歸，為諸有福田，紹眾聖因種，興隆佛法，超越生死。萬劫未聞，此生獲遇，除茲一道，更無餘途。若非究我祖乘，須信投心無地，一生虗度，豈不誤哉！嗚呼
【譯文】第三、彰顯體性。一切大乘教法，無不都以常住的佛性妙理為體性。這是諸佛所證悟並安住其中的真理，卻為眾生所遺忘、在日用之間毫無知覺；它包容周遍十方虛空，孕育涵蓋萬事萬物。順應眾生的根宜，而有種種不同的說法：法界、涅槃、中道、實相、圓覺、般若、真如、真空、法性、佛性、唯心、唯識、佛藏、佛母等，因此是對同一法而安立了種種名稱。如今依據《楞伽經》、《大乘起信論》、《成唯識論》、《攝大乘論》來闡明藏識。梵語稱「阿梨耶」或「阿賴耶」，漢譯為「含藏識」，意思是含藏一切善惡因果與染淨種子。此中分有兩大派別：唯識宗師認為真如隨緣，不生不滅與生滅和合，非一非異，名為阿賴耶識，即是「真妄和合識」；攝論宗師則認為外在塵境本來虛無，實質上唯有心識，這是大菩薩與佛果所證得的行境，這便是完全指真如為「真識」。這也是如來隨順機宜所作的不同說法。後世有的宗師，在第八識之外另行安立第九清淨真識（菴摩羅識）。如今依照《楞伽經》大略說明三種識。經中說：簡要來說有三種識，廣泛來說有八種相貌。是哪三種？就是真識、現識、分別事識。這裡就真如隨緣而不變、不與妄念和合而言稱為真識；就不變而隨緣、和合現起而言稱為現識（好比一面明鏡，各種形色影像顯現其中）；其餘的前七識則為分別事識。運用這三種識，便能統攝收納各家說法。該經又說：如來藏名為阿賴耶，而與具足無明的前七識共同俱在，宛如大海的波浪常時湧動而不斷絕。又說：如來藏被無始以來的虛偽惡習所熏習，便名為藏識。如今闡明這個心識，體性本來真實清淨，隨順外緣而妄動，累積含藏業力種子，便稱為第八識；轉而趨向各個根門，便為第七識（末那識）；奔流於心意志念之中，便為第六識（意識）；普遍到達五根之中，便為前五識。所造作而成的業力，由第七識收攬回歸到第八識含藏起來，成熟為未來的果報。果報具有善惡、依報與正報的種種差別。如今在已經形成的種種差別事法中，徹悟其完全沒有自性差別，所以稱為「唯識」。由此便能了知，十法界的依報、正報、原因與結果，本是同一個識體，未曾有一法不是心識。《楞伽經》偈頌說：「譬如大海中的波浪，並沒有種種各別的實體相狀；種種心識也是如此，想求其真實差異也是不可得的。」如今闡明戒體：造作雖然在於第六意識，但生起必定憑藉第八藏識；造作完成而凝聚成種子，又回頭依附於第八識。問：第八識的行相，可以得知嗎？答：普遍而言，一切事法無一不是；特別就自身當前的五陰、十二入來看，無一不是心識所轉變。最初投胎時先來、死時最後離去，維持承載果報生命，作為前六識的依止，記憶執持往昔之事，睡眠時的魂魄夢境，過去習氣的倏忽萌發，全都可以藉此了知。第四、說明立論的意圖。問：前面兩宗談論體性已經很充足，何須另外創立圓教？答：前兩宗揭示體性，教法的局限各有不同。如果單單依憑他們，那麼辨明戒體便不夠明朗徹了；如果完全不依據他們，宗門的途徑又會混亂無序。所以依準《法華》、《涅槃》二經，另外設立這一圓融教法，窮究至理、窮盡心性，達到究竟決斷了達。使得修學之人，在修持上有其依靠寄託，在發心趨向時了知歸宿，成為各界眾生的福田，紹繼諸聖賢的因位種子，振興興隆佛法，超越生死輪迴。歷經萬劫都未曾聽聞，今生得以有幸遭遇，除此一條正道之外，再無其餘捷徑。若不是窮究我終南祖師所立的圓教乘門，必須相信將投心無處，一生虛度光陰，難道不是大大的誤入歧途嗎！嗚呼！

【原文】五、示所據。問：依何教義立此教耶？答：下引《法華》、《涅槃》二經為證。《法華》開聲聞而作佛，《涅槃》扶小律以談常。舍此二經，餘無此義。《華嚴》隔出，《方等》彈訶，是以《梵網》斥二乘為邪見，學則有違；《善戒》指小法為方便，不學成犯。二部之異，於此自明。問：前二云宗，此標教者？答：據云三宗，理無偏局。然既別標，不無其致。由前兩計各有宗黨，今此直以大乘圓義以決前體，故但云教耳
【譯文】第五、指示所依據的教典。問：是依據什麼教法義理而建立這一教門的呢？答：下文引述《法華經》與《涅槃經》二部經典作為明證。《法華經》開顯聲聞人皆當成佛，《涅槃經》扶助小乘戒律來闡明常住佛性。捨離了這兩部經，其餘經典皆無此圓通義理。《華嚴經》隔別小乘而不納入，《方等經》彈偏斥小、予以呵責；所以《梵網經》斥責二乘為邪見，若學習小乘便有所違背；《善戒經》則指出小乘之法乃是方便法門，不學便構成犯戒。這兩部經的差異，在此自然明了。問：前面兩者稱為「宗」，這裡為何標示為「教」呢？答：雖然通稱為「三宗」，理體上並無偏頗局限。然而既然另行標示，自有其深致緣由。因為前面兩種見解各自有其門派宗黨，如今此處直接以大乘圓融極致之義來決斷前面的戒體，所以僅稱為「教」。

【1795-0003】03_業疏/16a_卷三之五#23
【原文】戒是警意之緣也以凡夫無始隨妄興業動與妄會無思返本是以大聖樹戒警心不得墮妄還淪生死故律中云欲修梵行盡苦源者便命召之入聖戒數此根利也後漸澆濁不可示本乃就傍緣廣聞衢路終依心起妄分前境。
【譯文】戒律是警醒心意的助緣。因為凡夫無始以來順著妄念造作罪業，舉心動念無不與妄念相合，從不思慮返歸本真。因此大聖佛陀設立戒律以警策其心，令人不致沉淪妄執、再度墮入生死輪迴。所以律藏中說「想要修持清淨梵行、窮盡痛苦根源的人」，佛便呼召其名，令其入於聖戒之列。這是針對利根之人而言。後來世道漸漸澆漓混濁，不可直接開示本源，於是便順應旁帶的境界條緣，廣泛開闢持戒的途徑；但這終究還是依自心而生起，只是凡夫妄自去分別當前的外境。
