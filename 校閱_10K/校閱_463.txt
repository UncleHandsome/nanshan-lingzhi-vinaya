# 校閱材料　第463檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【463-0001】02_戒疏/06a_卷二上之二#21
【原文】【疏】初句「比丘」，義該八篇，文局上六。「眾學」、「七滅」單列持相。然非比丘，無由可犯。故《律》眾學，廣解辨相，明比丘義。但結集翻譯，不欲繁文，故略不出，可以知也。
【譯文】【疏文】第一句「比丘」，其義理普遍涵蓋八篇戒律，但文字僅局限在前六篇。「眾學」與「滅諍」兩篇僅單純列出持守的行相。然而若不是比丘，根本不可能違犯。因此《律藏》在眾學篇中，廣泛解釋並辨析行相時，明確指出了比丘的定義。只是當年結集與翻譯時，為了不想讓行文過於繁複，所以簡略而不逐條列出，這是可以理解明白的。

【463-0002】02_戒疏/06a_卷二上之二#22
【原文】【記】決通中。初句分二。前總示通、局，「眾學」下，別顯後二。上二句示文無，次二句顯義有。「故」下，準《律》廣解，可驗文略，故知西土梵本必具。
【譯文】【記文】在貫通抉擇的段落中，第一句分為兩部分：前面總體指出通貫與局限，「眾學」以下，特別顯示最後兩篇。上面兩句說明文字上的缺漏，接著兩句顯明義理上的存在。「故」字以下，對照《律藏》的廣泛解釋，可以證驗文字確實有所省略，由此可知印度梵文本中必定完備俱足。

【463-0003】02_戒疏/06a_卷二上之二#23
【原文】【疏】第二、第三，「共」、「同」兩句，釋成得戒之人，成初「比丘」之義。通、局雖別，義該八篇，文局初戒。四、五兩句，文義俱同。
【譯文】【疏文】第二句與第三句「共比丘」與「同戒」，是用來解釋成就得戒之人的資格，進而成就第一句「比丘」的內涵。通貫與局限雖然有別，義理普遍涵蓋八篇，文字則局限在第一條戒。第四與第五兩句，在文與義的通局情況上完全相同。

【463-0004】02_戒疏/06a_卷二上之二#24
【原文】【記】次四句中。前釋二、三。云「通、局」者，「通」謂初句，總舉受、隨；「局」則二、三，各明受、隨。兼前釋後，意顯通該。次釋四、五。亦是文局義通，故指同也。
【譯文】【記文】在接著的四句中，前面先解釋第二與第三句。所說的「通與局」：「通」是指第一句，總括舉出受體與隨行；「局」則是指第二與第三句，分別說明受體與隨行。結合前面的文句來解釋後面，意在彰顯義理其實是通貫涵蓋的。接著解釋第四與第五句，同樣是文字局限而義理通貫，所以指出情況完全相同。

【463-0005】02_戒疏/06a_卷二上之二#25
【原文】【疏】昔解云：「此戒愛染久習，卒難捨離，不障初果，故開捨染。殺、盜不爾，違損事大，不開捨也。」
【譯文】【疏文】過去古德解釋說：「這條婬戒由於貪愛染著習氣已久，極難立刻捨離，而且貪愛並不障礙證得初果，所以特別開許捨戒以隨順情染。殺生與偷盜則不是這樣，它們違犯損害的後果極其重大，所以不開許為了行殺盜而捨戒。」

【463-0006】02_戒疏/06a_卷二上之二#26
【原文】【記】斥古中，初文。彼謂唯婬開捨，四、五二句，不通餘戒。初果見惑已破，思惑全在，雖起貪欲，非婦不婬。故在僧中，欲心設起，則捨戒還家，故有欲飽還來之事，故云「不障初果」也。
【譯文】【記文】在駁斥古德的段落中，首先引用古德的說法。古德認為唯有婬戒開許捨戒，第四與第五兩句不能貫通到其他戒律。初果見惑已破，思惑全在，雖起貪欲，非妻子不行婬。因此在僧團中若起欲心，就捨戒返家，所以有欲求飽足後又回來出家之事，故說「不障礙初果」。

【463-0007】02_戒疏/06a_卷二上之二#27
【原文】【疏】今解不同，強、羸二捨，義通諸戒。文約婬法，欲成極罪，故須「不捨」之言。如《律》云「若犯波羅夷，無覆開懺」，此則通也。諸篇不明者，略也。
【譯文】【疏文】現在我們的解釋不同：無論是戒力堅強或微弱這兩種捨戒，其義理通貫於一切戒律。戒相文字之所以依據婬戒來說，是因為要構成極重之罪，所以必須特別說明是在「未捨戒」的前提下。正如《律藏》中所說「如果犯了波羅夷重罪，只要沒有覆藏就開許懺悔」，這個原則也是通貫的。其他各篇戒律沒有明文寫出，純粹是行文省略罷了。

【463-0008】02_戒疏/06a_卷二上之二#28
【原文】【記】正解中。初二句明義通；「文」下，示文局；「如」下，舉例。「無覆開懺」，六聚皆然，豈得滯文，不通餘聚？故知不爾。
【譯文】【記文】在正確解釋的段落中，前兩句顯明義理是通貫的；「文」字以下，指出文字有其局限；「如」字以下，舉出先例。所謂「無覆藏開許懺悔」這件事，六聚罪名全都適用，怎麼可以拘泥於字面，就認為不通於其他戒聚呢？因此可知古德的說法是不對的。

【463-0009】02_戒疏/06a_卷二上之二#29
【原文】【疏】又解：「此之四句，並釋比丘具戒成犯。初戒立法故有，餘篇準式故無。」亦有道理，智能解也。
【譯文】【疏文】又有一種解釋說：「這四句全部都是在解釋比丘具備完整戒體因而構成犯罪。初戒在最初立法時具體列出，其餘各篇戒律依此標準比照，所以文字省略不寫。」這也是很有道理的，有智慧的人應當這樣理解。

【463-0010】02_戒疏/06a_卷二上之二#30
【原文】【記】他解中，初示。初有餘無，於義可見。「亦」下，歎美所解，於義可取。
【譯文】【記文】在引用其他解釋的段落中，首先展示其觀點。初戒有寫而其餘省略，從義理上是可以理解的。「亦有」以下，讚歎稱許這個解釋，在義理上是值得採納的。

【463-0012】02_戒疏/06a_卷二上之二#32

【譯文】【記文】第六與第七句，正是說明造業與對境，由於條條戒律各自不同，所以文字與義理都局限於本戒。

【譯文】【疏文】第八與第九兩句，義理兼通於下各篇戒律，文字則只列在最初四條重戒。因為即使有微小的違犯，就不應該參與說戒，這就是「不同住」，其精神就如同被棄絕於僧事之外一樣。

【463-0016】02_戒疏/06a_卷二上之二#36
【原文】【疏】約人明之，無制戒時事義足者。既無後犯，一結便足。若文不具，生疑託緣，則更開結。或約一緣，或至七、八，如「為女說法」及「別眾」等戒。
【譯文】【疏文】從當事人的角度來探討，在佛陀制定戒律時，不可能一次性將所有的狀況與義理都規範完足。既然當下沒有後續的違犯，制定一次就暫時滿足了。如果戒文規範不夠完備，大眾因境緣生起疑惑，佛陀就會再度開許或補訂戒條。有的戒律依據單一因緣制定，有的甚至補訂到了七次、八次，例如「為女人說法戒」以及「別眾食戒」等戒律。

【463-0017】02_戒疏/06a_卷二上之二#37
【原文】【記】第四，通明中。初明制無頓足，以機起不時，故多重制。「既」下，明隨犯單、重。初、明單結。「若」下，次、明重結。「為女說法」，初制不得，後開智男。「別眾戒」，初制不得，次開病時、施衣、作衣、道行、船行、大會、沙門施等七緣，凡七番再制。文言「七、八」，且趣舉之，尋《戒本》中，無至八者。
【譯文】【記文】在第四項通論說明中，首先說明制定戒律無法一次到位，因為眾生的根機與犯錯是在不同時間發生的，所以多有重複制定的情況。「既」字以下，說明隨著犯戒情況而有單純一次制定與多次重修制定的區別。首先說明單次制定。「若」字以下，接著說明多次重複制定。例如「為女人說法戒」，最初制定不得說法，後來開許有具智男子在場；「別眾戒」最初制定不得別眾受食，隨後陸續開許生病時、布施衣時、作衣時、行路時、乘船時、大聚會時、沙門施食等七種因緣，總共反覆修訂了七次。文中說「七、八次」，只是舉個大概的數目，若詳細查閱《戒本》，並沒有重複修訂達到八次的。

【463-0018】02_戒疏/06a_卷二上之二#38
【原文】【疏】今約初戒，一人隨結。配句屬當，則有三位：
【譯文】【疏文】現在針對最初這條婬戒，是各隨一人犯過而隨後制結（一人隨結）。若將戒本文句與違犯的人事配對對應，可以分為三種層次：
