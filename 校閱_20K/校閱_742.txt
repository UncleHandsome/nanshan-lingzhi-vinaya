# 校閱材料　第742檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【742-0001】05_拾毗尼義鈔/04a_卷中之二#3
【原文】第一配三業解成犯相者九十之中有三十一戒是身而非口如總頌言女未強脫覆與屏施別過非殘不外坐屏露四三軍酒水擊半白二隨打搏宮有二十一戒是口而非身如頌言故毀兩同說道女異嫌尼譏法恐怖疑發起欲拒毗同欲無根謗二十一毗尼昔解與年不滿是口業犯今解不然律云和尚提眾僧吉故知自身作業假他口也三十八戒亦口亦身三十一戒口家作業共身心犯有七戒口家止業共身心犯論前作業亦有三一身口作業假他身成有十九戒若論自作唯身心犯若就教人名自口作業假他身故頌言掘壞牽用勸然藏飲殺驅與尼捉落寶高牀七戒俱次有七戒自口作業假自他身犯且如與尼同行要假自口共期後身業行越界方犯如頌言屏露二處敷四期索美食有五戒自身作業假他口者如食尼歎食假尼口業歎身業咽方犯餘者亦例同頌言讚諫及二聽與年不滿五違諫之罪亦有口違諫且就一相言不盡理次論止業共身犯者覆藏一戒論解不同伽論云意業犯此就根本說非但意犯摩夷亦爾十誦亦說尼覆重罪亦單心犯善見云身心犯者見聞他犯此通名身業未即成犯若口發露本自無罪由所見聞止不發露意地覆藏故口家止業假身心故頌言覆背足非時家真不與欲。
【譯文】第一門、配合三業解釋成犯之相：在九十條戒當中，有三十一條戒純屬身業犯而非口業犯。如同總括的偈頌所說：與女人同宿、未受具足戒人同宿、強敷坐臥具、脫（坐臥脫腳床）、覆（覆屋過量）、與（與尼作衣）、屏處坐、施一食、別眾食、過受三鉢、非時食、殘宿食、不受食、外（自手與外道食）、坐（食家強坐）、屏處坐、露處坐、四月受請、觀軍、軍中宿、軍中發威儀、飲酒、水中戲、擊水或擊人、半月浴、白（白色三衣）、二種隨順惡見、打比丘、搏比丘、突入王宮。有二十一條戒純屬口業犯而非身業犯。如同偈頌所說：故妄語、毀呰、兩舌、同誦、說人粗罪、向未受具人說得道、與女人說法、異語、嫌罵、教誡尼、譏諷說法者、恐嚇、疑惱、發起僧諍、惡見說欲不障道、拒勸學、毀毗尼、同羯磨後悔、與欲後悔、無根僧殘謗，此二十一條戒為口業犯。過去的解釋認為「給予未滿二十歲人受具足戒」是口業犯，現在的解釋認為並非如此；因為律中說和尚得單墮罪，眾僧得突吉羅罪，由此可知是自身造作羯磨業，藉助他人的口語表白而成就。有三十八條戒屬於亦口業亦身業：其中有三十一條戒是自己口中造作之業，共同伴隨身、心而犯；有七條戒是自己口中的止息之業（應說而不說），共同伴隨身、心而犯。討論前述自己口中造作之業，又分為三類：第一類、身、口造作業，藉由他人之身而成就，共有十九條戒。如果論及自己親自去作，純粹只是身、心犯；如果是教唆他人去作，就稱為自口造作業藉由他身而成就。如同偈頌所說：掘地、壞生草木、牽引出房、用蟲水澆草木泥土（或用蟲水）、勸足食、燃火、藏他衣鉢、飲蟲水、故斷畜生命、驅逐出房、與比丘尼同行、捉取落寶、坐臥高牀，連同教唆者自作共犯的七條戒（指教唆共犯之條目），一併計算在此。第二類、自口造作業，藉助自己與他人之身而犯，共有七條戒。例如與比丘尼同行，必須藉由自己口中共同約定，隨後身業行走越過一界界限，才構成犯罪。如同偈頌所說：屏處與露處二處敷坐具、四種約期、索求美食等。第三類、自身造作業，藉助他人之口而犯，共有五條戒。例如吃比丘尼讚歎所獲之食，必須藉助比丘尼口業讚歎，自己的身業吞嚥，才構成犯罪；其餘各條也是同樣的例則。如同偈頌所說：讚食、諫諍、以及二種屏處偷聽諍論（或覆聽諍論）、給予年未滿者受具，這五條戒皆屬此類。違抗諫誡的罪，雖然也有口業違抗的情況，但這裡暫且就身業違抗這一種相狀來說，並未完全窮盡法理。其次討論口中止息之業共同伴隨身業而犯的情形：「覆藏罪過」這一條戒，論典中的解釋各有不同。《摩得勒伽論》（《伽論》）說這是意業犯，這是針對其根本犯心來說的，並非單純只有意業犯；《毘尼母論》（《摩夷》）也是這麼說。《十誦律》也說比丘尼覆藏重罪純由自心起犯。《善見律毗婆沙》說這是身、心犯，因為見到或聽到他人犯戒，這統稱為身業，但此時尚未立即成犯；如果口中發露陳白，本來就沒有罪過，正是由於見聞之後停止而不發露，在意識深處加以隱覆藏匿，所以是口中的止息之業藉由身、心而犯。如同偈頌所說：覆藏、背請、足食、非時食、自入白衣家、真實具足、不與欲。

【742-0002】05_拾毗尼義鈔/04a_卷中之二#4
【原文】第二身口業自作教他不同之義者有十二戒自作教他同犯餘者自作正犯教人即輕頌言掘壞牽用勸恐然藏殺飲無根捉落寶自作教他同莫問為己不為己過中是損悉同犯有十戒教人不為己於身無潤雖損是可已得小罪何者是耶頌言屏露與尼衣高牀七戒俱此前十戒教人為己能教犯提受使者吉若不為己受教者提能教犯吉此義未盡如打搏等亦自他俱惱何不同犯而獨無根謗飲蟲水等俱是無文義決即齊故知不盡此中善見云輒教誡尼是遮非性故但三十戒以為性惡自餘六十悉名為遮今且序性不須遮名故頌云故毀兩說異嫌強牽用譏不驅恐覆疑故飲發說隨隨拒毀同與不屏打搏無。
【譯文】第二門、身口業自作與教唆他人同犯或不同犯的意涵：有十二條戒，自己作與教唆他人作，犯同樣的罪；其餘各條戒，自己作屬於正犯，教唆他人作則較輕。偈頌說：掘地、壞生草、牽出房、用蟲水、勸足食、恐嚇、燃火、藏衣鉢、殺生、飲蟲水、無根謗、捉取落寶，這些戒自己作與教唆他人作犯罪相同；不用過問是為了自己還是不為了自己，只要損害成立，全部同犯。有十條戒，教唆他人如果不是為了自己，對自身沒有利益潤澤，雖然造成損害，但可以止於教唆者得小罪（突吉羅）。是哪些戒呢？偈頌說：屏處坐、露處坐、與比丘尼衣、高牀，連同教唆自作共犯的七條戒都在其內。這前述十條戒，如果教唆他人是為了自己，能教唆者犯單墮罪，接受指使去作的人犯突吉羅；如果不是為了自己，接受教唆去作的人犯單墮罪，能教唆者犯突吉羅。這種解釋法理尚未完全窮盡。例如打人、搏擊人等戒，也是自己與他人都受到苦惱，為什麼不一同判為重犯？而唯獨無根謗、飲用蟲水等戒，律文雖然沒有明文列出教他犯，但在義理決斷上卻完全相等，由此可知上述歸納並不完全。這當中的《善見論》說：擅自教誡比丘尼是遮戒而非性戒；所以只有三十條戒被認為是性惡戒，其餘六十條戒都稱為遮戒。現在暫且列舉性惡之名，不須廣說遮戒之名。如同偈頌所說：故妄語、毀呰、兩舌、向未受具人說得道、異語、嫌罵、強敷坐臥具、牽出房、用蟲水、譏訶說法者、不驅擯惡見沙彌、恐嚇、覆藏、疑惱、故殺畜生、飲用蟲水、說人粗罪、惡見說欲不障道、隨順受擯比丘、隨順受擯沙彌、拒諫、毀破戒法、毗尼同羯磨後悔、與欲後悔、不與欲、屏聽諍論、打比丘、搏比丘、無根謗。

【742-0003】05_拾毗尼義鈔/04a_卷中之二#5

【譯文】第三門、持戒與犯戒的差別：九十條戒當中有十二條戒具足「作持、作犯、止持、止犯」四種情形。是哪些戒呢？由於得到羯磨法差遣，得以向未受具人說粗罪；得到羯磨得以教誡比丘尼；受了功德衣，得以背請食與別眾食；經過囑託傳話而入村，不犯非時入聚落戒與食前食後入他家戒；作殘食法，不犯足食戒與勸足食戒；七日藥與盡形壽藥作口頭受持法，受持之後不犯殘宿食戒與不受而食戒；對衣物作淨施並問過主人便著用，不犯著不作淨衣戒；如法僧事時與欲而後起座離去。這十二條戒，由於聖者開許聽聞作法順應佛教，就沒有罪過，這稱為「作持」。如果止息不作法，身行卻違背戒相，稱為「止犯」；如果就其身行造作違背之事而言，稱為「作犯」；這「止犯」與「作犯」二種犯業，思心體性是一體的，只是名稱不同。止息非法之法、止息非法之事，徹底不去造作，稱為「止持」。「止持」與「作持」二種持戒，名稱與實體各自不同。過去的解釋認為：七日藥在手中與口中受持完畢，防止了非時食罪，這稱為「作持」。現在的解釋認為並非如此：七日藥如果沒有作口法受持，其本體原本就合乎非時食罪，本來沒有七日的期限；是由於作了口法受持，超過七天才稱為非時食；這分明是由作口法而生起的，怎麼能說是為了防非而稱為「作持」呢？過去對「覆藏罪過」的解釋也說是作持，這也是不對的：難道有順應聖教作法去覆藏而得以無罪的嗎？如同我們非時入村，順應佛教作法，因此非時入村而沒有罪過，這才能稱為「作持」。因此可知過去的解釋不對，現在確立只有這十二條戒；其餘戒沒有作法順應佛教的義理，不能稱為「作持」。問：教唆他人掘地，聖者開許說知淨語，從而防範教唆他人無罪，這難道不是「作持」嗎？答：這十二條戒是順應佛教作法後，自身得以親自造作而沒有罪過，才能稱為「作持」；知淨語當中只開許教唆他人，由於沒有開許自己親自作，所以不能稱為「作持」。其次，有二條戒是「有所造作便是持，止息不作便是犯」，也就是覆藏罪戒與不收攝耳朵聽戒（不往聽教誡戒）。其餘七十六條戒，都是「止息便持，造作便犯」；作持與作犯的義理如同上述所解。現在說明「止犯」與「止持」：所謂「止持」，共有九種句型，分為三品：上品一句：識知戒法、識知成犯，不觸犯根本戒，又沒有愚癡不學的無知，戒行清淨皎潔，稱為上品。中品四句：一、識法而疑犯，二、識法而不識犯，三、疑法而識犯，四、不識法而識犯。這四種情況都不觸犯根本戒，制定為止持；但因為有四種無知，比不上上品，稱為中品。下品四句：一、疑法疑犯，二、疑法不識犯，三、不識法疑犯，四、不識法不識犯。這四種情況也都不觸犯根本戒，稱為止持；但帶有八種無知罪過，劣於前二品，稱為下品。其次討論「止犯」的九句：有人主張只有八句，沒有「識法識犯」這一句，這是倒轉進趣修學的義理來闡明止犯；既然稱為止犯，是由於不修學而生起，哪裡還會有「識法識犯」呢？所以只立八句。現在的解釋認為：如果倒轉「理解」來闡明止犯，確實只有八句，不能有九句；但如果是倒轉「修持」來闡明止犯，就應當有九句。例如不納受三衣、不說淨等戒，明明理解戒相卻不肯依教修作，怎麼會沒有九句呢？「識法識犯」相對於根本不作法而言，稱為止犯；然而因為識知教理相狀，沒有愚癡之罪，稱為下品。中品四句各自招得一重罪過，上品四句各自招得二重罪過；因為在「犯門」解釋義理時，以罪過多的作為上品，這正好倒轉了前面「持門」中以無罪為上品的原則；句法上下互相替換，是可以理解的。
