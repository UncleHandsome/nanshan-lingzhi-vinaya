# 校閱材料　第420檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【420-0001】02_戒疏/04c_卷一下之二#93
【原文】【記】次釋中。初約大乘，釋前不犯。「獨頭」，即「瞥爾」異名。「重」下，次據本宗，決後犯文。謂後念還追前事，故云「重緣」。「向」即前也。
【譯文】【記文】第二種解釋中。首先從大乘的角度，解釋前面為什麼不犯。「獨頭心念」，就是「突然閃過的一念（瞥爾）」的另一種名稱。「重緣」以下，接著根據本宗（四分律宗）的立場，來決斷後文判定為犯戒的律文。這是指後面的心念還在不斷追逐回味前面的惡事，所以稱為「重緣」。「向」就是指先前的事。

【420-0003】02_戒疏/04c_卷一下之二#95

【420-0007】02_戒疏/04c_卷一下之二#99
【原文】【記】答：「此由不辨假實兩宗制限深淺故也。小乘實宗，定不制意，動色成犯。假宗制意，但約重緣，簡非瞥爾。是則三宗歷然，大小無濫。學者至此，宜須精究。」
【譯文】【記文】回答：「這是因為沒有辨明實法宗（有部）與假名宗（成實四分）兩宗在戒律規範程度上的深淺差別所致。小乘的實法宗，絕對不規範單純的意念，必須發動身口色法才算犯戒。假名宗雖然規範意念，但也僅限於念念相續的追思（重緣），排除突發的一念（瞥爾）。這樣一來，三宗的界限歷歷分明，大乘與小乘絕對不會混淆。學者研究到這裡，應當要深刻精研詳究。」

【420-0008】02_戒疏/04c_卷一下之二#100
【原文】【疏】上明成就竟。餘有通塞諸門，增微雜相。量時須者，可尋《事鈔》中卷《持犯》。兩以相成，故斯略也。

【420-0009】02_戒疏/04c_卷一下之二#101
【原文】【記】指略中。初結前，「餘」下總指。《事鈔》七門：三門同上；第四「通塞」，自分四位，故云「諸門」；第五「漸頓」，文中不指；第六「優劣」，即是「增微」；七「雜料簡」，即今「雜相」。「量」下，囑後講習輩也。
【譯文】【記文】在指出省略內容中。首先總結前文，「其餘」以下總括指出。《行事鈔》中共有七門：前三門與此處相同；第四門「通達與阻礙」，又細分為四個階位，所以說「諸門」；第五門「漸成與頓就」，文中沒有特別指明；第六門「優劣差別」，指的就是罪業「增減」；第七門「雜項料簡」，指的就是現在所說的「雜類相貌」。「衡量」以下，是囑咐後續講習戒律的學者們。

【420-0011】02_戒疏/04c_卷一下之二#103
【原文】【記】第四門中。唯明不學無知，止犯罪相，有無輕重。隨一事法，皆須二九，故云「位列」。
【譯文】【記文】在第四大門中。專門闡明因為不去修學而造成的無知，其止犯罪相的有無與輕重層次。隨著任何一項事相或法規，都必須展開兩組九句的辨析，所以稱為「位列」。

【420-0012】02_戒疏/04c_卷一下之二#104
【原文】【疏】佛立教相，止為奉行，若但讀誦，非本意也。
【譯文】【疏文】佛陀確立戒律教法的行相，只是為了讓人切實奉行，如果只是拿來讀誦口談，那絕非佛陀立戒的本意。

【420-0013】02_戒疏/04c_卷一下之二#105
【原文】【疏】然受戒後，勤學教行，於諸事法，明若指掌，忽於境想，迷忘而造，律制非犯。此不可學迷也。
【譯文】【疏文】然而受戒之後，若能勤奮學習教理與行持，對於各項事相與法規，都明了得如同看手掌心一樣清楚，如果突然對於境界的認知產生混亂遺忘而做了違律的事，戒律特別規定這不算犯戒。這就是屬於不可修學的突發迷惘。

【420-0014】02_戒疏/04c_卷一下之二#106
【原文】【疏】若由來不學，不思過犯，隨所造作，不問事法，但作有違，皆犯根本。緣而不了，結無知。若於二持，雖不違負，望非明決，不名為福。若緣不解，但是無知。是以佛言「隨作犯根本，更增無知罪」。
【譯文】【疏文】如果從一開始就不肯修學，從不思考什麼是過失違犯，隨著自己的作為，不管面對的是具體事相還是僧事法規，只要造作時有所違背，全都觸犯了根本戒。若面臨境界卻懵懂不解，就要加結無知罪。如果在止持或作持這兩方面，雖然沒有違背戒條，但因為心中並非明確堅定而行，所以不能算作真正的福德功德。如果在面對境界時茫然不解，這單純就是犯了無知罪。因此佛陀說：「凡是違犯就結根本罪，更要額外增結一條無知罪。」

【420-0015】02_戒疏/04c_卷一下之二#107
【原文】【記】敘結分三。初明立教之旨，「然」下敘結之所以。初明學人開迷。文中明學，須具二義。言「學教」者，謂精窮三藏。「學行」者，謂專修對治。若此為學，方開迷忘，自餘泛爾，皆不學收。舉世相傳，纔過學肆，便稱「學人」，自謂無罪。觀其所業，曾未勤勞；求其所行，略無奉慎。豈能全免不學無知！請詳此文，足為龜鏡。「律制」者，即諸戒後境想中開。「若由」下，次明不學須結。又三，先明迷犯。「若」下，次明昧持。故知不學，由不曉教，持亦成犯。「是」下，引證。即「不攝耳聽戒」文。
【譯文】【記文】在敘述與判定中分為三部分。首先說明佛陀立戒的主旨，「然而」以下敘述判罪的原由。第一、說明有學之人在遇到迷惘時獲得開許。文中說明「修學」，必須具備兩層意義。所謂「修學教理」，是指精研窮究經律論三藏；所謂「修學行持」，是指專心修習對治煩惱惡法。只有達到這種程度的修學，才開許突發的遺忘迷惘，其餘那些泛泛度日的人，全都收歸於不學之流。現在世俗相傳，才稍微進過幾天講堂學肆，就自稱為「學戒之人」，自以為沒有罪過了。檢視他所修的學業，未曾真正下過苦功勤勞；考察他平素的行持，絲毫談不上謹慎奉行。這樣的人怎麼可能完全免除「不學無知罪」呢！請深細審視這段文字，足可以作為修行的大明鏡。「戒律規定」這句話，是指各條戒後面關於境界想念中所給予的開許。「如果從」以下，第二、說明不肯修學的人必須判定結罪。又細分為三點：首先說明因迷惘而犯戒；「如果」以下，接著說明對於持戒的盲目，由此可知不肯修學的人，由於不懂戒律，即便守戒也可能轉成獲罪；「因此」以下，引用律文為證，也就是引自〈不攝耳聽戒〉的戒文。

【420-0016】02_戒疏/04c_卷一下之二#108
【原文】【疏】今略標舉，須配位法。此立兩箇九句，交絡有無，為持犯方軌。
【譯文】【疏文】現在略微標舉列出，必須將其配對在具體的階位與法規上。此處設立了兩組九句，相互交織錯綜出有罪與無罪的狀況，作為判定持戒與犯戒的準則規範。

【420-0017】02_戒疏/04c_卷一下之二#109
【原文】【記】總標中。初句指前，「須」下生後。言「交絡」者，即於事犯，各有識、疑、不識三心，互織作句，如圖所顯。言「方軌」者，若解二九，隨一事法，無不該通，故《事鈔》云「類通法界」是也。
【譯文】【記文】在總標題中。第一句承指前面，「必須」以下引發後文。所謂「相互交織」，是指對於事相與罪犯這兩方面，各自具備「明識」、「疑惑」、「不識」這三種心態，互相交錯交織編組成九句，如同圖表中所顯示的那樣。所謂「準則規範」，是指如果參透了這兩組九句，隨便面對任何一項事相或法規，都能無不貫通周延，所以《行事鈔》說「能夠類推貫通法界一切事」，指的就是這個道理。
