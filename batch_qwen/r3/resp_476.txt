整體讀來通順、術語大致掌握得不錯（六和敬的配對、「隨行／通行」、「受戒／隨戒相須」等都對）。但有幾處**實質誤譯**，以及一個貫穿全篇的毛病：**把《記》文的解釋或自己的推論塞進《疏》／《註》的譯文裡**，導致名相被提前定義、甚至定義錯誤。以下按輕重分列。

---

## 一、必須修正的實質錯誤

**1. #96「『不同』無犯」→「不構成犯重罪」（最嚴重）**
- 原文：「『不同』無犯，文據甚明。」
- 問題：(a)「無犯」是**根本不構成犯戒**（因未得戒體，無戒可犯），不是「不犯重罪」；(b)「不同」是承 #81 註文科判的 **「不同（戒）」者，即本受不得戒之人**，不是「戒體不同」。
- 建議：「（註文所說）『不同』（本受未得戒）者無犯，經論的文證非常明白。」

**2. #87「百歲比丘」→「百歲的高僧」**
- 律中「百歲」指**戒臘百夏（受具足戒滿百年）**，不是年齡；「高僧」又加了評價色彩。
- 建議：「戒臘百夏的老比丘與初受戒者相同……」

**3. #83「隨行通行」被合併成一個句子**
- 原文「佛所制戒，隨行通行」是**並列兩個名目**，#84《記》正是分別釋之（依體起持＝隨行；一化齊奉＝通行）。譯文「必須由隨順戒體的行持（隨行）來普遍奉行」把「通行」吃掉了，也與下文《記》的科判脫節。
- 建議：「佛陀所制的戒，是依戒體而起持的『隨行』，是一化之下大眾齊奉的『通行』。」

**4. #83「法不同也」→「在戒律法則上的判定是截然不同的」**
- 依 #84「亦非同戒」、#96「『不同』無犯」，此處「不同」＝**不名同戒**（故無犯），不是「判定不同」。
- 建議：「所以這種人即使有所違犯，就戒法而言也不屬於『同戒』（無戒可犯）。」
- 另：譯文括號「（受時不起持意，不能納受戒體）」是下一則《記》的內容，疏文本身無此語，宜移出或標明為引《記》補注。

**5. #85「一戒、同戒、等戒」自行套入解釋**
- 譯文「受持同一個戒法／共享同樣的戒行／領受均等的戒品」是提前定義，且與疏文不符：疏釋「等戒」為**數齊（皆納具足）／齊防塵沙**，非「均等的戒品」；「同戒」為**對人共學／對人興治**，非「共享戒行」。
- 建議：三個名相保留原詞，交給 #87、#89 去解釋：「在此之中，與其餘比丘『一戒、同戒、等戒』，這就是『同戒』的意義。」

**6. #89「對人興治」→「面對同修互相勉勵匡正」**
- 「興治」是**生起對治（持行對治過惡）**，「對人」是與他人相對而言；#90《記》說「後二同前，約行為別」，可見它對應前文的「對人共學」，並無「互相勉勵匡正」之義。
- 建議：「對人（與他人一樣）起對治之行，持戒的意義沒有兩樣，所以稱為『同戒』。」

**7. #94「立句本意」→「建立這句經文」**
- 此處所釋是**戒本的註文（律家之語）**，稱「經文」不當。改「安立此文句的本意」。

**8. #95「作戒」釋為「身表禮拜等」**
- 作戒通**身、口**二業（乞戒、白四羯磨等造作），只講「身表禮拜」偏窄。
- 建議：「只具備身口造作的『作戒』」；另「他的戒律是不圓滿具足的」易誤讀成「戒律本身不完整」，宜作「他所得的戒並不具足」。

## 二、語意偏移或增字

| 出處 | 譯文 | 問題／建議 |
|---|---|---|
| #81 | 「缺乏**真心**乞求戒體」 | 「無心乞受」是**根本沒有求受之心**，非「不夠真誠」。改「沒有乞求受戒的心」。 |
| #81 | 「排除**不能受戒的**北俱盧洲」 | 「不被北洲」只是說教化**不及於**北洲，「不能受戒」是加注（雖合義理，但屬增字）。 |
| #81 | 「涵蓋**整整**六萬年」 | 「盡六萬年」是「直到六萬年（法滅）為止」，「整整」是多餘的語氣。 |
| #81 | 「根本**沒有戒體可犯**」 | 犯的是「戒」不是「戒體」。改「既然未得戒體，自然無所謂犯戒」。 |
| #81 | 「但透過白四羯磨得戒的**本質**相同」 | 「羯磨受同」只說**受法（白四羯磨）相同**，「本質」是加注。 |
| #89 | 「如同塵沙一般繁複的**煩惱微過**」 | 「塵沙」重在**數量眾多**（所防之境／過非），「微」是添義。 |
| #90 | 「從**個人的具體**行持來做**區隔差別**」 | 「約行為別」＝改從行持角度說，與前面約教有別；並無「個人／區隔」之義。 |
| #93 | 「必須發起**弘誓大願**」 | 此處「願」是**受戒時的期願（受願）**，用「弘誓大願」帶入菩薩色彩，宜改「受戒的期願」。 |
| #93 | 「共同隨行修持的**心念**」 | 「明同隨行」指**行持**相同，加「心念」把行弱化成心。 |
| #93 | 「只是**口頭空談**受戒誓願」 | 「且論受願」＝僅有受願，無「空談／虛偽」之貶義；「虗願」宜作「空願」。 |
| #87 | 「面對**僧團大眾**共同學習遵守」 | 與 #88《記》「三乘俱稟」不合，宜作「與他人（三乘行人）共同修學」。 |
| #88 | 「新受與**舊住**相同」 | 「新舊」指新受／久受（戒臘），「舊住」是另一概念（舊住比丘）。改「新學與久受」。 |

## 三、行文與一致性

1. **#81 語法不順**：「但也不出人、法、事、處這四種要素產生了乖違」→「但也不出人、法、事、處這四者有所乖違」。
2. **術語前後不一**：#81 前作「所受境」、後作「所對境」，原文一律是「所對」，宜統一為「所對境」。
3. **「通攬列出」**（#81）生硬，「通舉之」即「一併舉出」。
4. **#91 雙重否定繞口**：「難道就可以算作不是犯戒者嗎」→「那豈不成了犯戒者（而非同戒）嗎？」語意相同但明快。
5. **語氣詞過度**：「根本」「真正的」「毫無」「非常」等在多則反覆出現（#83、#84、#93、#96），原文多為平敘，可酌減。

## 四、一個方法上的建議

這批譯文的主要風險不在讀不通，而在**分工界線**：《疏》只立名目，《記》才作解釋。建議：
- 《疏》《註》中的「一戒／同戒／等戒」「隨行／通行」「同／不同」等**被定義項一律保留原詞**，解釋留給《記》；
- 需要補注時，統一用「（依《記》：……）」標示，避免像 #83 那樣把《記》義混入《疏》文，也避免 #85 出現與後文相衝的定義。

改妥上述幾處（尤其 #96「無犯」、#87「百歲」、#83「法不同」、#85 三名相、#89「興治」），這一段的白話就相當可靠了。
