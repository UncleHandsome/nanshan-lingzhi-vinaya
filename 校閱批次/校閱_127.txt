# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【127-0001】03_業疏/18a_卷四之一#44
【原文】故相傳云：安陀會者，是內衣也；鬱多羅僧，是上衣也，在內衣上常服用故；僧伽梨者，是高勝衣。如此釋名，皆從事也。或有說者：下衣名院內道行，中衣名入眾常服，上衣名入聚落及伏外眾也。故僧伽為眾，梨翻為伏，即從用以翻也。或從相者，即五條、七條、九條等是也。或從價量，或從寒暑及輕重等
【譯文】因此相傳說道：「安陀會」是內衣；「鬱多羅僧」是上衣，因為穿在內衣之上常常穿著的緣故；「僧伽梨」是尊高殊勝之衣。像這樣的解釋名稱，都是從事相上著眼的。或者有人說：下衣（安陀會）稱為寺院內經行或操作之服，中衣（鬱多羅僧）稱為進入大眾時的常服，上衣（僧伽梨）稱為進入聚落及降伏外道外眾之服。因此「僧伽」意為大眾，「梨」翻譯為降伏，這就是依功用來翻譯的。或者有從外相來命名的，也就是五條、七條、九條等。或者有從價格數量、或從寒暑氣候及輕重厚薄等來命名的。

【127-0002】03_業疏/18a_卷四之一#45
【原文】次科有五：初從事，「內衣」最在裏故，「高勝」入王宮聚落說法時著故。「或下」，二從用。下衣中院內道行，更加作務，此三時服用故。上衣且舉二用，翻名可見。「或下」，三從相。「或下」，四從價者，鈔云七條名中價衣。「或下」，五寒暑輕重即從時也。《分別功德論》云：為三時故制有三衣，冬則著重，夏則著輕，春則服中，是也
【譯文】在次一科中有五種釋名方式：第一、從事相命名，「內衣」穿在最裡面的緣故；「高勝」是進入王宮、聚落說法時所穿著的緣故。「或下」自此以下是第二、從功用命名。下衣用於寺院內經行行走，更加上從事勞務，是在這三種情況下穿用的緣故。上衣暫且列舉兩種用途，翻譯名稱便可了知。「或下」自此以下是第三、從條相命名。「或下」自此以下是第四、從價值命名，《事鈔》說七條衣稱為「中價衣」。「或下」自此以下是第五、從寒暑輕重命名，也就是依時節而定。《分別功德論》說：為了三種時節的緣故而制定三衣，冬天則穿厚重的，夏天則穿輕薄的，春天則穿適中的，就是這個意思。

【127-0003】03_業疏/18a_卷四之一#46
【原文】文云「不得捨墮物作」下，即第二門義。由是法衣，體須清淨，犯捨過財，無任受法，故不許也

【127-0010】03_業疏/18a_卷四之一#53

【127-0011】03_業疏/18a_卷四之一#54
【原文】雖求清淨，財體應法。綾羅錦繡，俱不合故。世多用絹紬者，以體由害命，亦通制約。今五天及諸胡僧，俱無用絹作袈裟者，來此神州乃隨著耳。親問彼云：絹亦有也，但慈念故，以衣為梵服，行四無量，審知行殺而故服之，義不應也

【127-0012】03_業疏/18a_卷四之一#55
【原文】財體中，初簡文綺、輕綃、紗縠、生踈、葛苧，並非應法。「世」下次辨絹帛，初示制意，蠶家乞得律制捨墮，然非蠶家展轉來者準律猶通，今準大乘深求義意竝不許之，廣如《章服儀》中所辨。「今」下引事證，五天即四方中間五天竺國，諸胡即五竺之外，親見親問，可驗非虗。「彼云」下，竝胡僧語，梵天所著，故云「梵服」。

【127-0019】03_業疏/18a_卷四之一#62
【原文】然袈裟者，但翻為染，則諸色者非染不成，知何不是？故非剋相也。今依《善見》云：善來比丘，衣同赤也；《大莊嚴論》云：我著赤色衣；《涅槃》亦云：被服皆赤。即今梵僧皆服赤色。真諦云：中國僧雖五部，赤色皆同一也。用斯事證，袈裟染赤，頗近實矣
