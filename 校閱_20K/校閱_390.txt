# 校閱材料　第390檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【390-0001】02_戒疏/19c_卷四下之一#42
【原文】【疏】有人依《多論》，數實月為十九年者。今準《四分》，與俗計同。如尼六法云：「十八童女二歲學戒，年滿二十，與受具足。」據此十八，未必年盡為歲，滿十八年朝即是十八，依教便受六法，明年十九方二歲學，後年正朝，豈非二十？如此例之，縱極小者，年暮受法，即此一日便當一年，明年具行，後年正月一日受戒，豈非二十也？若不爾者，要滿十八，至十九年初，方受六法，明年二十，始學一年，年滿學終，後年二十一方與受者。又無律文如此延引。故知剋定以俗年為定。餘文云云，何由可盡！
【譯文】【疏文】有人依照《薩婆多論》，主張必須計算實足的月份達到十九整年。現在依照《四分律》，其年歲的算法與世俗相同。正如比丘尼六法中所說：「滿十八歲的童女應當給予兩年時間學戒，年滿二十歲，再為其授具足戒。」依據這裡所謂的十八歲，未必是指十八個整年全都過盡才算一年，只要進入滿十八歲的那一年正月初一就算十八歲，依教法便能領受六法；到了明年十九歲正好修行兩年，後年的正月初一，豈非就是二十歲？照此推例，縱使是年齡極小的極端例子，在歲末最後一天領受六法，光是這一天便充當了一年，第二年整年修行，第三年正月一日受戒，豈非也是二十歲嗎？若不如此解釋，非要實足滿十八年，等到第十九年之初才准許受六法，到了第二十年才開始學習了一年，學期圓滿結束，要等到第二十一年才為其授戒。但各大律藏中根本沒有如此拖延拉長年限的明文。由此可知，律中規定完全是以世俗通行的跨年算法為準定。其餘律文的議論繁多，哪裡能說得盡！

【390-0002】02_戒疏/19c_卷四下之一#43
【原文】【記】五中。初引彼妄執。《多論》云：「真實不滿，乃至無十九故，所以不開也。」彼謂十九，乃約實月，則俗年二十也。「今」下，舉例難破。成上俗年十九，八月得受之義。初二句，通示。「準《四分》」者，即如下引。「與俗同」者，謂俗中論年齒，亦取跨涉，不數實月。「如」下，引例，又二。初舉文。「據」下，示年數。初約跨涉，合教以證今義。「若不爾」下，次約實月乖文，以顯昔非。「故」下，準決。「餘」下，指廣。
【譯文】【記文】在第五段中。首先引述那些人的妄加固執。《薩婆多論》說：「若真實年歲不滿，甚至連十九歲都不到，所以不予開許。」古人認為所謂十九歲，是指實足計算月份，換算起來世俗虛歲就是二十歲。「今準」以下，舉出先例加以難破。藉此確立上述世俗虛歲十九、在八月即可受戒的主張。開頭兩句為通體開示。「準《四分律》」，即如同下文所引。「與世俗相同」，是說世俗計算年歲，也是採用跨越年份的算法，並不逐月累計實足月份。「如尼」以下，引律例證明，又分為兩層。初舉出律文。「據此」以下，說明年數計算。首先依跨年算法，契合教理以印證今義。「若不爾者」以下，次就實月算法會違背律文，以顯明古說之謬。「故知」以下，依準決斷。「餘文」以下，指示其餘廣泛文證。

【390-0005】02_戒疏/19c_卷四下之一#46
【原文】【疏】凡四諍之興，乖理違法，惱亂僧眾，事必請殄。故須備德，量情安帖，僧眾始靜，方修道業。今輒發起，更增凶熾，助惡揚波，轉成彌漫，壞眾惱僧，過中之甚，故制。
【譯文】【疏文】凡是四種諍事的興起，皆是違背正理、乖違戒法之舉，會惱害擾亂僧眾，依事理必須予以徹底平息。因此必須由德行具足的長老，審度眾人的情緒使之安定平和，僧眾才能恢復清靜，進而修持道業。如今竟然擅自重翻舊帳，使爭執再度熾盛，宛如助長惡行、推波助瀾，讓事態擴散氾濫，破壞僧團和合、惱亂大眾，這在過失中屬於極其嚴重的，所以佛陀制定此戒。

【390-0006】02_戒疏/19c_卷四下之一#47
【原文】【記】六十六，制意中。初敘四諍已滅。「乖理」，即言諍，「違法」，即覓、犯、事三諍。「殄」即是滅。「備德」謂有德之人。「量情」，謂觀察眾心。「安帖」，謂和平令息，「帖」合作「帖」，訓靜也。「今」下，次明重更發起。「揚波」喻上「助惡」，如風波動蕩，隨更鼓之。「彌漫」謂泛廣，「彌」合作「瀰」，大水之貌。
【譯文】【記文】第六十六條，制定戒律的用意中。首先敘述四諍平息之後的狀況。「乖理」即言諍，「違法」即覓諍、犯諍、事諍這三種諍。「殄」就是平息消滅。「備德」是指具備德行之人。「量情」是指觀察大眾的心態。「安帖」是指以平和手段使其止息，「帖」應作「帖」，訓詁為安靜。「今輒」以下，次說明重新挑起諍事之過。「揚波」比喻上面的「助惡」，如同風浪動盪，隨之鼓動波濤。「彌漫」是指大水蔓延廣大，「彌」應當寫作「瀰」，是大水漫溢的樣子。

【390-0011】02_戒疏/19c_卷四下之一#52
【原文】【註】說不了了，突吉羅。除此諍，若餘鬬罵發者；若發已諍；除二眾，若餘人諍，而發起者——一切吉羅。尼同犯。不犯者：若先不知；若觀作不觀想；若事實爾，語言「不善觀」等。若戲，若錯說者，不犯。
【譯文】【註文】若言說表述不夠清楚明白，犯突吉羅罪。除了這四種僧團諍事之外，若是挑起其餘私人間的爭鬥罵詈；或者是挑起自己個人的爭執；或是除僧尼二眾之外、挑起其他人的諍事者——全都犯突吉羅罪。比丘尼同樣犯此戒。在不犯的情況中：如果起初確實不知諍事已平息；或者誤把如法止諍當作非法止諍；或者事實本就如此，而言語只是在客觀指出「未能妥善止諍」等；若是開玩笑，或是口誤說錯話，都不算犯戒。

【390-0012】02_戒疏/19c_卷四下之一#53
【原文】【疏】戒本四句：一、人；二、是四諍，簡餘鬬諍不能陷僧；三、如法滅；四、發起結。
【譯文】【疏文】戒本分為四個文句：第一、指明造業者為人；第二、指明是四種僧團諍事，藉此簡別其餘私下爭鬥不致於陷僧團於不義；第三、該諍事已如法平息；第四、重新挑起即結罪。

【390-0013】02_戒疏/19c_卷四下之一#54
【原文】【記】戒本。第二中，「餘諍不能陷僧」者，以四諍須僧法滅，若重發舉，即是陷僧。四中，「發起」是過業，「結」即罪相。
【譯文】【記文】戒本條文。第二句中所謂「其餘爭鬥不能陷僧團於不義」，是因為四諍必須透過僧團羯磨如法平息，若重新挑起，便是陷僧團於非法。第四句中，「發起」是過失行為，「結」即是判定罪相。

【390-0014】02_戒疏/19c_卷四下之一#55
【原文】【疏】言「如法懺悔」者，正是相謝之言，如草覆地，兩朋面地相謝之例。亦未必有罪，言諍非罪。亦可有罪之諍，上品如草掩泥，罪、諍同滅，至後為解。
【譯文】【疏文】戒本所謂「如法懺悔」，正是互相謝罪之意，就如同如草覆地止諍法中，雙方代表伏於地面互相謝過之例。這其中也未必一定涉及戒罪，純粹的教理諍論（言諍）本就不是戒罪。但也可以是有罪性質的諍事，例如嚴重的犯諍採用如草覆地法平息，此時戒罪與諍事同時止息，這在後文會詳細解釋。

【390-0015】02_戒疏/19c_卷四下之一#56
【原文】【記】釋中。初科二釋。初約相謝釋。「以草覆地」，兩朋相爭，經年難滅，德人作法，兩眾相對互相伏地。舉此為例，自餘滅諍，義必相謝。此明文中懺悔之言，非謂懺罪，故云「未必有罪」。以四諍中，覓、犯二諍，則可有罪。「言諍」教理，事諍羯磨，故非有罪。「亦可」下，次約懺罪釋。「有罪之諍」，即犯諍。上品犯諍，用草覆滅，毗尼如草，罪諍如泥，則有懺罪之義。後篇廣釋，故此指之。
【譯文】【記文】在解釋中。第一科有兩種解釋。首先就「互相謝過」來解釋。「以草覆地」，是兩派相互爭論、長年難以平息時，由德高望重之人主持法事，兩派代表相對跪伏於地互相謝罪。以此為例，其餘平息諍事之法，在義理上也必然要相互謝罪。這是說明條文中的「懺悔」之詞，並非特指懺除罪業，所以說「未必有罪」。因為在四諍之中，覓諍與犯諍這兩種可能涉及戒罪；而論辯教理的「言諍」與執行羯磨的「事諍」，本來就沒有戒罪可言。「亦可」以下，次就「懺除罪業」來解釋。「有罪之諍」即是犯諍。上品的犯諍採用草覆地法來滅除，以律法如草覆蓋罪惡如泥，此時便含有懺罪的意涵。後篇會詳細解釋，所以此處先作指引。
