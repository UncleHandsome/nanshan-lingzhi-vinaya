# 校閱材料　第579檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【579-0001】03_業疏/01a_卷一之一#20
【原文】次科通敘中，初總分兩教，「三輪」下別敘毗尼。初中，從古皆爾，故曰「咸分」。就文，二教對明兩別：道俗、出家，被機異也；信解、修奉，立法異也。《戒疏》云：「何名化教？開演化導，令識邪正，教本化人，令開慧解，本非對過而立斯教。言行教者，起必因過，隨過制約，言唯持犯，事通止作，戒律一宗局斯教矣。」就別敘中又二：初四句總判所歸，「止作」下別示宗要。初中，上二句通對餘藏，下二句局就律宗。三輪者，一者神足，為無信也；二曰說法，為無解也；三須憶念，為無證也。由此三種運轉不絕，故竝名輪。前之二輪攝餘二藏，後之一輪即攝律藏，雖復互兼，不無偏勝。言「憶念」者，謂毗尼立法，殷勤囑累，制令記憶，不使遺忘，所以常爾一心，違皆制犯，故知常勤觀察，始號奉持。四藏者，三藏外加一雜藏，用收眾典。今明戒律，四中之一，制法雖多，毗尼總攝，故云「統」也。「義約」者，從理而判，此即取上總分別收律藏；「從文」者，且就本律二眾戒本、二十犍度皆名法聚。準《五百結集》文，比丘事聚在一處名比丘戒本，尼戒亦然；受戒法聚在一處名受戒犍度，乃至諸犍度亦爾。犍度梵言，即翻法聚，是則一部始末通歸法聚所收。別示中，「止作兩善」即二持，名即名字，實即體相，「昧」謂艸昧，取剏始之義，《周易》云「天造艸昧」；「即機」與下「時眾」，竝目當時稟化之者。「受隨二戒」，受戒是壇場願體，隨戒即後起行相，故云「願行」；「標」謂指其大端，未為盡理。「所以」下，結示。上二句示前世傳持，下二句明後代訛濫。凡古今文字播於眾口、相傳誦習者，謂之「成誦」；「浮訛」言其時變，「㳂濫」謂其義乖
【譯文】在通論敘述的次一科中，先總體劃分化、行兩教，自「三輪」以下個別敘述毗尼（律藏）。在第一部分中，從古以來皆是如此，所以說「咸分（全都劃分）」。就文句而言，兩教相對闡明兩項區別：道俗與出家，是所受教化的根機不同；信解與修奉，是立法之目的不同。《戒疏》說：「什麼叫作化教？開演化導，令人辨識邪正，教法根本在於教化眾生，令其開啟智慧解悟，本來不是針對過失而建立此教。所說的行教，生起必定是因為過失，隨著過失而設制定約，言說唯在於持戒與犯戒，行事通於止持與作持，戒律一宗專門局限於此教。」在個別敘述中又分為兩部分：前四句總括判定其歸屬，自「止作」以下個別指示宗趣綱要。在第一部分中，上兩句通對其餘經、論等藏，下兩句專局針對律宗而言。所謂「三輪」：第一是神足輪（神通輪），是為了令沒有信心的人生起信心；第二是說法輪，是為了令沒有解悟的人生起解悟；第三必須有憶念輪，是為了令沒有證果的人成就證悟。由於這三種作用運轉不絕，所以都稱為「輪」。前面的二輪收攝其餘二藏，後面的憶念輪則收攝律藏，雖然彼此互有兼涉，但不能說沒有偏勝側重。所說的「憶念」，是指毗尼立法時，世尊殷勤囑託叮嚀，規定必須記憶，不讓其遺忘，所以必須常在一心，違背規定都判為犯戒，由此可知常時精勤觀察省察，才稱得上是遵奉修持。所謂「四藏」，是在經、律、論三藏之外加上雜藏，用以收錄諸多典籍。現在闡明戒律，是四藏之一，制定的法度雖然繁多，律藏總括收攝，所以說「統」。所說的「義約」，是從義理上判定，這就是承取前面總體分別而將其收歸於律藏；「從文」，是暫且就本部律典而言，比丘與比丘尼二眾的戒本、二十犍度都稱為法聚。依據《五百結集》的文句，比丘的事項聚在一處稱為〈比丘戒本〉，比丘尼戒也是如此；受戒的方法聚在一處稱為〈受戒犍度〉，乃至各個犍度也是如此。「犍度」是梵語，翻譯為漢語就是「法聚」，這樣看來，本部律典從始至終全部歸屬於法聚所收攝。在個別指示中，「止作兩善」就是止持與作持，「名」就是名字，「實」就是體性行相，「昧」是指草昧，取其創始之義，《周易》說「天造草昧」；「即機」與下文的「時眾」，都是指稱當時領受教化的人。「受隨二戒」，受戒是在戒壇上所領納的願體，隨戒則是受戒後生起的行持相狀，所以說「願行」；「標」是指示出其大要端倪，尚未達到窮盡究竟之理。自「所以」以下，予以結語開示。上兩句指明前代人的傳持，下兩句說明後代的訛變雜濫。凡是古今文字流播於眾人之口、代代相傳念誦修習的，稱為「成誦」；「浮訛」是指隨著時代推移而產生的偽變，「㳂濫」是指義理已經乖違走樣。

【579-0002】03_業疏/01a_卷一之一#21
【原文】自法流東夏，開務寔繁，戒本羯磨，爭分異轍。良由受體止持，攝修之極無越戒本；據行作持，量處之要其唯羯磨
【譯文】自從佛法流傳至東土華夏，開創開演的律務確實繁多，〈戒本〉與〈羯磨〉爭相分途、各走不同軌轍。這實在是由於領受戒體與奉行止持，統攝修持的極致沒有能超越〈戒本〉的；而依據行持以推動作持，考量決斷僧事的要領，唯獨在於〈羯磨〉。

【579-0003】03_業疏/01a_卷一之一#22
【原文】次別明羯磨敘古集本中，初文初二句推往古弘傳。自漢至唐，涉于九代，對西曰東，大國曰夏。或弘傳三藏，或立法行事，皆謂開務，歷代非一，故曰「寔繁」。「戒」下次明二文獨盛。體、行、止、作、攝修、量處，即二文之宗旨，祇由極要，致使𮞏代弘持甚眾。所見既別，故曰「爭分」；各立宗途，故云「異轍」，轍即車所由之道
【譯文】在接下來個別說明羯磨、敘述古人輯集的版本中，第一段文字的前兩句推溯往昔以來的弘揚流傳。從東漢到唐朝，歷經了九個朝代；相對西方印度稱為「東」，中原大國稱為「夏」。或者弘傳經律論三藏，或者訂立軌範推行僧事，都稱為「開務」，歷經諸代不止一次，所以說「寔繁（確實繁多）」。「戒」字以下，接著說明〈戒本〉與〈羯磨〉二文獨為興盛。體、行、止、作、攝修、量處，就是這兩部典籍的宗旨，只因為極為要緊，致使歷代弘揚受持的人非常多。由於各人的見解既有不同，所以說「爭分」；各自建立宗門途徑，所以說「異轍」，「轍」就是車輪所行經的道路。

【579-0004】03_業疏/01a_卷一之一#23
【原文】戒本序致，如別所陳。羯磨眾氏，義須詳顯。或單翻出，或依律文，或準義用，或引緣據，酬校諸本，成務紛綸，增減繁略，互見得失。單翻則失於文旨，包舉難尋；依本則得在執據，前後易惑；準義理雖無爽，藏跡可嫌；緣據似是具周，止存別見。竝隨事尋誦，臧否冥然，唯可卷收，信殊龜鏡

【579-0013】03_業疏/01a_卷一之一#32
【原文】次科初敘惜於時功，「大」下次顯審其宗旨。若唯循舊，一則虗費，二乃乖宗，斯疏所興深意在此。準下批文，貞觀九年剏製，將近六十；至二十二年重修，已及七十，故云「老矣」，前著後加，皆未可測。「晷」即日影。「無益辭」者，諸古疏也。「有涯命」者，報有期也。《大集》第七〈寶女品〉云：「世尊！云何菩薩修行法行？」佛告寶女：「菩薩不捨親舊，知恩報恩，憐愍一切，修於忍辱，難施能施，慈心護戒，思惟善義，護持正法，善護眾生，淨身、口、意，清淨其行，乃至勤修六波羅蜜、四念處、八正道，是名菩薩修行法行。」《四分》〈大小持犍度〉云：「初夜後夜，精進覺悟；若在晝日，若行若坐，常爾一心，念除諸葢。」「頒」，賜也。經稱法行，旨在修行；律制常一，意存攝念。苟不體此，則失宗要，被物無功，終成浪述，故云「此而不審」等。仍知今疏專被攝修，講學討論，勿忘斯意。
【譯文】下一科中，起初敘述憐惜時光與工夫；自「大」字以下，接著彰顯應當審究其宗旨。如果只是墨守舊說，一來是白白虛費光陰，二來會違背宗旨，這部疏之所以造作，其深意就在於此。依據下文的批注，祖師於貞觀九年初次撰作時，年紀已將近六十歲；到了貞觀二十二年重加修訂時，已年屆七十，所以說「老矣」；哪些是前次所著、哪些是後次所加，都難以確測。「晷」就是日影。「無益之辭」，是指古師的各部疏本。「有涯之命」，是指果報之身壽限有限。《大集經》第七卷〈寶女品〉說：「世尊！什麼是菩薩修行法行？」佛告訴寶女：「菩薩不捨棄舊雨親朋，知恩報恩，憐愍一切眾生，修持忍辱，難捨能捨，以慈心護持禁戒，思惟善妙義理，護持正法，妥善護念眾生，清淨身、口、意業，使其行為清淨，乃至勤修六波羅蜜、四念處、八正道，這就稱為菩薩修行法行。」《四分律》〈大小持犍度〉中說：「在初夜與後夜，精進覺悟；若在白天，無論經行或端坐，常時保持一心，繫念除去各種煩惱蓋纏。」「頒」是賜予的意思。經典中稱為「法行」，宗旨全在於實踐修行；律典中制定「常爾一心」，用意在於攝持心念。如果不體會這一點，就會失去宗旨綱要，教化利導眾生便毫無功德，最終只成了浪費筆墨的空話，所以說「此而不審」等。由此可知，本疏專門是為了攝持修行而造，後人講學討論之時，切勿忘記這個宗旨。

【579-0014】03_業疏/01a_卷一之一#33
【原文】所題曇無德者，中梵本音，唐言譯之名為法鏡；部謂黨類之別名，運起正法之初位；四分即說之斷章；言律乃行所詮教；對彼繁略故題刪補；對彼潛務故曰隨機；羯磨天音，人翻為業。凡百所被，莫不成濟。且開大略，廣要如後
【譯文】題目中所稱的「曇無德」，是中印度梵語的原本讀音，翻譯為唐語稱為「法鏡」；「部」是同類部派的別名，在此指於正法初期的時代運數中建立興起；「四分」是指宣說完畢的段落章節；稱為「律」，是指指導行持、所詮釋的教法；針對古本的過繁與過略，所以題目冠以「刪補」；針對那些時下隱沒不行之事，所以稱為「隨機」；「羯磨」是天竺梵音，此方翻譯為「業」。凡是所加被的一切事務，無不成就圓滿。暫且在此開顯其大略，詳細要點見於後文。
