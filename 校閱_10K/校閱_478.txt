# 校閱材料　第478檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【478-0001】02_戒疏/06c_卷二上之二#6
【原文】【疏】「戒」者，能治之行。能所通舉，故云「盜戒」。
【譯文】【疏文】「戒」字，是指能夠對治惡業的行持。將所對治的惡與能對治的行一併舉出，所以稱為「盜戒」。

【478-0002】02_戒疏/06c_卷二上之二#7
【原文】【記】釋戒中。「盜」是所觀之境，「治」謂能觀之智。境、智相合，思修業成，故名為「行」。
【譯文】【記文】在解釋「戒」字中，「盜」是所觀照的境界，「對治」是指能觀照的智慧。境界與智慧相互契合，思維修習的善業成就，所以稱為「行持」。

【478-0003】02_戒疏/06c_卷二上之二#8
【原文】【疏】三、具緣成犯者。此戒五緣。
【譯文】【疏文】第三、具備緣由構成犯戒（具緣成犯）。這條戒具備五種緣由。

【478-0004】02_戒疏/06c_卷二上之二#9
【原文】【疏】初、是人物。以盜餘趣，不成重故。
【譯文】【疏文】第一、所盜的是人類的財物。因為偷盜其餘道眾生的物品，不構成極重罪的緣故。

【478-0005】02_戒疏/06c_卷二上之二#10
【原文】【記】具緣中，初緣。雖通三寶，至於結重，多從主掌。是以初緣，通云「人物」，對簡非、畜，如後自分。
【譯文】【記文】在具緣之中，這是第一緣。雖然涵蓋常住三寶之物，但論及結成極重罪，多半是依從有主掌看管之處而定。因此第一緣，總體稱為「人類財物」，藉以對照簡別非人與畜生的物品，後文自然會分別說明。

【478-0006】02_戒疏/06c_卷二上之二#11
【原文】【疏】物雖人主，及至盜損，還須人想。若生餘想，疑謂別境，則是輕犯，非此戒收。是以第二作人物想。
【譯文】【疏文】物品雖然有其人主，等到要進行盜竊損害時，內心還必須作是人類財物的想法。如果生起其餘的想法，或者起疑以為是別種境界，就屬於輕微犯戒，不被這條重戒所收攝。因此第二個緣由，是必須作人類財物的想法。

【478-0007】02_戒疏/06c_卷二上之二#12
【原文】【記】二中，初躡前。「及」下，敘。文明「疑」、「想」，即境想中二、三兩句。
【譯文】【記文】在第二緣中，一開始承接前文。從「等到」往下，是敘述文義。文中說明「懷疑」與「異想」，就是境想分別中的第二句與第三句。

【478-0008】02_戒疏/06c_卷二上之二#13
【原文】【疏】問：「想、知二心，有差別不？」
【譯文】【疏文】有人問：「『想』與『知』這兩種心態，有差別嗎？」

【478-0009】02_戒疏/06c_卷二上之二#14
【原文】【疏】答：「有同、異也。了境無疑曰『知』，當境意謂為『想』。俱能了境，『想』與『知』同。然『知』唯了境，『想』通迷悟，故與『知』異。若以此心，知是人物，於下『闕緣』，轉想不便，謂實達境，非迷忘故。若謂人物想，即順闕緣，不乖《律》文境想互義。」
【譯文】【疏文】回答說：「有相同處，也有相異處。明了境界而毫無疑惑，稱為『知』；面對境界心中起意認定，稱為『想』。兩者都能夠了別境界，在這點上『想』與『知』是相同的。然而『知』純粹是明了當前境界，『想』卻通於迷謬或覺悟，所以在這點上與『知』不同。如果採用這種心態，界定為『確知是人類財物』，那麼在下文『闕緣不成』的狀況中，轉變心想的情形便難以成立，因為這意味著已經切實通達境界，而不是處於迷謬忘失之中。如果界定為『作人類財物的想法』，便能順應闕緣不成的狀況，也不會違背《律》文中所說心境想法互有偏差的涵義。」

【478-0010】02_戒疏/06c_卷二上之二#15
【原文】【記】問中。或有立云「知是人物」，故問決之。答中。初、答知想差別，上句通標；「了」下，分示；「俱」下，顯同異。「若」下，次、明立緣是非。前敘立「知」有濫，意謂若具緣中標云「知者」，則人謂後「闕緣」中，轉想皆是明了之心，故不可立。「若」下，次明立想順教，以《律》但有「想差」，不言「知」故。「互」即差也。
【譯文】【記文】在提問之中，有些人主張安立為「確知是人類財物」，所以提出問題來決斷判別。在回答之中，首先回答「知」與「想」的差異，第一句是總括標明；從「明了」往下，分別開示；從「兩者皆能」往下，顯明其同異之處。從「如果」往下，接著說明安立條件的是非對錯。前面敘述立為「知」會有混淆弊端，意思是如果具備緣由中標示為「知者」，人們就會認為在後面「闕緣」之中，轉變心想都是明了分別的心，所以不可這樣安立。從「如果認定為想」往下，接著說明立為「想」才順應佛陀教法，因為《律》中只說「心想有差」，不曾說「知」的緣故。「互」就是偏差相錯的意思。

【478-0011】02_戒疏/06c_卷二上之二#16
【原文】【疏】想雖當境，若盜輕物，不成重罪。故次第三，明是重物。
【譯文】【疏文】心想雖然恰當對應境界，但如果偷盜的是輕微物品，不能構成極重罪。所以接著第三緣，說明必須是屬於重物。

【478-0012】02_戒疏/06c_卷二上之二#17
【原文】【疏】財雖滿五，若無盜心，本自無咎。故次第四，明有盜心。
【譯文】【疏文】財物雖然達到五錢以上，如果內心沒有偷盜之意，本質上自然沒有過咎。所以接著第四緣，說明必須具有偷盜的心思。

【478-0013】02_戒疏/06c_卷二上之二#18
【原文】【疏】心雖起盜，財未離處，損主未就，屬己不顯，亦未成重。故次第五，明舉離處。
【譯文】【疏文】心中雖然發起偷盜之念，但財物尚未離開原處，對物主的損害還沒造成，物品歸屬於自己的狀態也不明顯，這時也還不構成極重罪。所以接著第五緣，說明必須移動離開原處。

【478-0014】02_戒疏/06c_卷二上之二#19
【原文】【記】餘三，可解。
【譯文】【記文】其餘的三種緣由，文義容易理解。

【478-0015】02_戒疏/06c_卷二上之二#20
【原文】【記】總五為三：初、三是境；二、四是心；五心境合。
【譯文】【記文】總括這五種緣由為三類：第一與第三屬於境界；第二與第四屬於內心；第五則是心與境相互合致。

【478-0016】02_戒疏/06c_卷二上之二#21
【原文】【疏】問：「前後諸戒，緣具方便。今此盜緣，無方便者？」
【譯文】【疏文】有人問：「前後各條戒律，具備緣由中大多含有預備著手（方便）的條件。如今這條盜戒的緣由中，為何沒有預備著手的條件？」

【478-0017】02_戒疏/06c_卷二上之二#22
【原文】【疏】答：「損財明盜，便成重罪。有盜成重，不假方便，恐涉濫故。縱有方便，亦俱不明，但知未離已前，並方便攝。」
【譯文】【疏文】回答說：「損害財物以確立偷盜，當下就構成重罪。有些偷盜構成重罪，並不假借方便階段，（不列方便）是擔心涉及混濫。縱使事實上有著手過程，（於此具緣中）也一概不特別標明，只需知道財物未曾離開原處之前，全都涵蓋在預備著手（方便）的範圍之內。」

【478-0018】02_戒疏/06c_卷二上之二#23
【原文】【記】初問，可見。若準《事鈔》，須具六緣，「五、興方便」。今此除之，故發是問。答中。初示成犯齊限。「有」下，次明避濫不出。如互用三寶，燒薶壞色，寄借抵拒之類，但使虧損，即成盜業，不必方便。然非一向都無，故云「縱有不明」等。
【譯文】【記文】第一個提問，文義顯而易見。如果依照《行事鈔》，必須具備六種緣由，其中「第五、發起方便」。如今此處將其刪除，所以提出這個問題。回答之中，首先開示構成犯戒的界限標準。從「有些偷盜」往下，接著說明為了避免混濫而不特別列出。例如挪用互換三寶物、焚燒埋藏破壞色澤、寄放借貸後賴帳抵賴之類，只要使他人產生虧損，當下就成就偷盜罪業，不一定需要預備著手動作。然而並非一概全然沒有，所以說「縱使有著手過程也不明列」等語。

【478-0019】02_戒疏/06c_卷二上之二#24
【原文】【疏】問：「經、論明盜，緣雖多少，皆無『重物』者何？」
【譯文】【疏文】有人問：「經文與論典說明偷盜，條件不論多少，為何全都不提『五錢重物』的標準呢？」

【478-0020】02_戒疏/06c_卷二上之二#25
【原文】【疏】答：「彼為成業，受苦招生，故無輕重。如牛呞比丘，但損一粟，五百生償。今雖遇聖，口猶是牛。《律》明持犯，盜輕，開悔得住；盜五，制重擯出。故使法律軌儀，其相在此。」
【譯文】【疏文】回答說：「經論是著眼於業報的成就，只要犯了就會招感受苦之生，所以不分輕重。如同牛呞比丘，過去生中只不過損毀了一顆穀粟，就償還了五百世做牛之身。如今雖然遇聖成道，口中依然保有牛反芻的習氣。《律》則是明定持戒與犯戒的規制，偷盜輕微之物，開許懺悔後仍得留住僧團；偷盜滿五錢，便制定為極重罪並永遠驅逐出僧團。因此佛法中的法律軌範儀則，其精準界限就在於此。」
