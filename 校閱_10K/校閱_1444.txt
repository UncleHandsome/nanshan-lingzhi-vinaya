# 校閱材料　第1444檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1444-0001】04_比丘尼鈔/03b_卷中之上#27
【原文】第十盜人物者見論云比丘為他別人乃至三寶守護財物若謹慎掌護堅鎖藏戶而賊或從孔中屋中竊取逼迫取非守護主能禁限者但望本主結罪皆不合徵若主掌懈慢不勤掌錄為賊所偷者守物比丘須償之以望守護主結罪十誦遠處受他寄物在道損破者好心投破者不應償惡心投破者須償借他物不問好心若破一切須償義云今多有好心為他洗治鉢器好心損破準此不合償主索計錢犯重有人不現前盜得物雖本心不捨後見不得奪犯重故此律十誦律時有比丘奪劫者物佛言波羅夷若現前盜者賊心猶豫本主不捨護心義強得取故僧祇云逐賊和喻得恐嚇得無犯或因他逐恐怖故施得取以成物主故但使不從賊乞他自與者得取已染壞色著若有主識認者應還若賊比丘尼邊認得衣本主見者不得直奪應還本直僧祇云若人被官收錄未抄物名寄付比丘者得取若已抄錄者不得取若施佛塔僧者得取應露現持出不得覆藏若問是何物應答言佛法僧物不許者還婆論云持國禁物出界罪入死者得重又違王教吉羅王民合死盜持出得重自外不聽無盜心者不犯僧祇云官稅比丘物方便自免不犯重一我不共要二非理稅我故此律云比丘無輸稅法不同白衣官須稅物比丘為他隱認者得重義云今時僧尼多為俗人影認車牛人物免稅計直犯重伽論云若狂人自持物施不知父母眷屬者比丘得取若父母可知不自手與不得取。
【譯文】第十、偷盜人物之財（盜人物）：《善見律》說：比丘替他人乃至為三寶守護管理財物，若是已謹慎保管防護、將庫房門戶嚴加鎖閉，而強盜賊人從牆洞或屋頂潛行竊取，或者以暴力逼迫搶奪，這並非守護僧人的力量所能阻擋防範，那麼只對最初的物主結下罪過，守護比丘不應當被強令賠償；但如果是主事管領者懈怠散漫、不勤於清點記錄，因而被盜賊偷走，守物比丘必須照價賠償，因為他是相對於守護責任的主事者而結罪的。《十誦律》說：在遠處接受他人寄託的物品，在路上遭到損壞，如果是出於好心而失手砸破損壞的，不應當賠償；如果是起惡意摔破損壞的，必須照價賠償。若是向他人借用物品，則無論發心是好是壞，只要破損損壞，一律必須賠償。依義理來說：如今常有發好心替他人清洗整理缽器，因好心失手砸碎的，按照這個道理不應當強令賠償，物主若強行索賠折算金錢，反犯重罪。有人非當面明搶而是暗中偷盜得物，原物主雖然本心並未捨棄，但事後遇到也不得強奪，強奪者犯重罪。因此本律與《十誦律》記載：當時有比丘從強盜手中奪回被劫之物，佛宣判其犯波羅夷罪；如果是在搶劫現場當場奪回，此時盜賊心中驚慌猶豫，原主追索護惜之心正盛，理法上是允許奪取的。所以《僧祇律》說：追趕盜賊，用溫和言語曉諭勸化得來的，或藉威勢恐嚇得來的，都不算犯戒；或者因他人追趕恐嚇之故，賊人棄物布施給僧，僧人可以收取，因為已成為無主遺棄之物的緣故。只要不是主動向賊乞求，而是對方自己扔下給予的，便可以拾取；染色壞色處理後即可穿用，如果原物主前來指認，應當歸還；若是從作賊的比丘尼手中認領衣服，原主見到了不得直接硬奪，應當償付買受的本錢。《僧祇律》說：如果有人被官府查抄拘捕，在尚未抄寫財產名冊之前，將物品寄託付給比丘，比丘可以代為收取；如果官府已經抄錄入冊，則不得收受藏匿；如果那人是指定布施給佛塔與僧團的，可以收取，但應當正大光明持出，不得暗中隱藏，若是官府盤問是何物品，應當回答說：「這是佛法僧三寶之物。」如果官府不准許帶走，則交還官府。《婆沙論》說：攜帶國家禁運管制之物出關跨境，若依國法罪當處死的，犯波羅夷重罪；此外，違背國王教令犯突吉羅罪；官府通緝必死的逃犯，若暗中偷運帶他逃出境外，犯重罪；除這類情況外，一概不允許掩護，若本身無偷盜私心者則不犯。《僧祇律》說：官府對比丘物品強行收稅，比丘施展善巧方便使自己免稅，不算犯重罪：一來我與官府並無契約約定，二來這是官府非法無理盤剝征稅之故。本律說：比丘在法理上沒有繳納關稅雜稅的義務，不同於俗人家；如果官府要對俗物收稅，比丘出面替他人冒名隱匿認領的，折算稅額犯重罪。依義理來說：如今僧尼大多為世俗凡人冒名影射認領車輛、耕牛、貨物以圖免稅，折算稅額滿五錢者皆犯波羅夷重罪。《伽論》說：如果是精神失常的狂人自己拿著物品前來布施，無法查知其父母眷屬是誰的，比丘得取；若父母可知，但父母並未親手交付布施的，不得取。

【1444-0002】04_比丘尼鈔/03b_卷中之上#28
【原文】第十一盜非人物者五分云盜他覆塚幡蓋神廟中衣他所守護物計直犯重僧祇云盜外道塔物神祀物得重十誦盜天神像衣及華鬘等物偷蘭婆論云取非人物五錢已上重蘭四錢已下輕蘭見論云取諸鬼神物繫樹物無守護者無罪。
【譯文】第十一、偷盜非人類神鬼之物（盜非人物）：《五分律》說：偷盜覆蓋他人墓塚的幢幡寶蓋，或者偷盜神廟中的衣物，只要有人在守護看管該物，折算價值滿額犯重罪。《僧祇律》說：偷盜外道塔廟或神祇祠堂的物品，得重罪。《十誦律》說：偷盜天神雕像身上的衣服以及花鬘瓔珞等物，犯偷蘭遮罪。《婆沙論》說：竊取非人之物價值五錢以上的，犯重偷蘭遮；四錢以下的，犯輕偷蘭遮。《善見律》說：拿取諸多鬼神之物，或繫在樹上的祭祀之物，如果無人看守管領的，沒有偷盜罪。

【原文】第十二盜畜生物十誦盜虎殘者吉由不斷望故取師子殘者不犯由斷望故婆論云一切鳥獸食殘取者吉。
【譯文】第十二、偷盜畜牲動物之物（盜畜生物）：《十誦律》說：偷取老虎吃剩的殘肉，犯突吉羅罪，因為老虎有回頭再吃的習性、未曾斷絕覓食指望；若是拿取獅子吃剩的殘肉，不犯戒，因為獅子吃飽即捨去、斷絕了回顧之念。《婆沙論》說：一切鳥獸吃剩的殘食，人去拿取的，犯突吉羅輕罪。

【1444-0004】04_比丘尼鈔/03b_卷中之上#30
【原文】第十三雜明盜業者善見云貴賤處所等謂此土直減五彼土直過五或此土直過五彼土直減五並依本處斷若盜心唱地云定是我地地主生疑者犯蘭決失心者重若來問僧僧答同者皆重若共諍園田違理判與乃至口斷多端偷夏唱大等得物滿五皆重舉一標時重乃至一髮一麥許皆重以地深無價故十誦云或樗蒲轉齒圍棊移子等皆重不犯者律中與想取己有想取糞掃取暫取想親友意想取等皆不犯親友者要具七法一難作能作二難與能與三難忍能忍四密事相告五互相覆藏六遭苦不捨七貧賤不輕如是七法能行者是善親友應附之殺妄略如大僧辨。
【譯文】第十三、雜項說明偷盜業緣（雜明盜業）：《善見律》說：要考慮各處物價貴賤的差異，比如在甲地價值不足五錢，在乙地卻超過五錢；或者在甲地價值超過五錢，在乙地卻不足五錢；這些都要依照案發本地的物價標準來折算定罪。如果存偷盜之心，口中宣稱「這塊地絕對是我的地」，使原本地主產生狐疑動搖的，犯偷蘭遮罪；使地主心生絕望、徹底放棄產權的，犯波羅夷重罪。如果雙方前來請求僧團仲裁，僧眾同謀附和予以偏袒判決的，合謀僧眾全都犯重罪；如果是共同爭執田園房產，知事僧違背道理非法判給某一方，乃至用口舌巧辯、各種手段，靠虛報戒臘自居上位等手段謀得物資滿五錢的，全部犯波羅夷重罪；哪怕只是移動界石標記一標，甚至只侵占一根頭髮、一粒麥子那麼寬微小的土地，全都構成重罪，因為土地連通地脈深廣，原本就是無價的。《十誦律》說：賭博投擲骰子、圍棋挪移棋子以舞弊謀財滿額的，全部犯重罪。不構成犯戒的情況：律制中規定，若是誤以為是別人贈予而拿取、誤以為是自己的東西而拿取、當作被丟棄的無主糞掃物而拿取、當作暫時借用而拿取、確信是彼此交心好友之意而自取等，都不算犯戒。所說的親密好友，必須具備七種德行條件：一是艱難之事能代為承受；二是難捨財物能慷慨給予；三是難忍之辱能包容忍耐；四是隱秘之事能坦誠相告；五是彼此能互相掩蔽私隱；六是遭遇危難困苦不相捨棄；七是對方落魄貧賤絕不起輕慢心。能做到這七條法則的人，才是良善真摯的好朋友，才可以依此心意信任取用。至於殺生與妄語戒，簡略如大僧戒條中所剖析辨明，不再繁瑣重述。
