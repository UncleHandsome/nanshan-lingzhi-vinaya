# 校閱材料　第1204檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1204-0001】資持記/10c_中三下#20
【原文】用二十八日為月，則三百三十六日為一年，餘十二日在；帖前居零十七日，則成一月一日；通前則為二十年五月一日，故云長也。上是出古謬解。今算中。初明退法。此長者，指上五月一日也。約實者，謂用此虛月還填令實，則有四月三十日。
【譯文】以二十八天折算為一個月，那麼三百三十六天即折算為一年，還剩下十二天；再補加到前面零碎的十七天中，就成了一個月零一天；合併到前面就成了二十年五個月零一天，所以說是多出來了。以上是列舉古代錯誤的理解。在當今的算法中。首先說明退減的方法。所謂「此長」，是指上面推算出來的五月一日。「約實」，是指用這個虛增的月份回填使之成為實數，那麼就是四月三十天。

【1204-0002】資持記/10c_中三下#21
【原文】準《戒疏》出填補法，則有四月十八日；彼云：就五月中七大布薩減取七日〔二大月得四日，三小月得三日。〕，又減閏餘弱得五日〔四月十八日中有二小盡得二日，并每月餘二十八半分，即十四分；四月十八日共得六十五分；將六十四分為二日，共得四日零一分；
【譯文】依照《戒疏》所開出的填補法則，則是四月十八天；《戒疏》說：就在五個月中，扣除七次大月布薩的日數減去七天〔兩個大月得四天，三個小月得三天。〕，又扣除閏月的餘數稍弱算得五天〔四月十八天之中有兩個小月各盡其數得兩天，加上每個月餘下的二十八點五小分，即十四分；四月十八天總共得到六十五分；將六十四分折算為兩天，共得到四天零一分；

【1204-0003】資持記/10c_中三下#22
【原文】今總開前為一百二十九分。將為五日，本三十二分為一日，今始成二十六分，故云弱也。今鈔但還四日，不取弱得。〕，又減頻大弱得半日〔以八箇月方得半日，今四月十八日取半日，故云弱也；今鈔不還此日，以不成半日故。
【譯文】現在把前面的總數開展為一百二十九分。將其算作五天，原本三十二分為一天，現在才滿二十六分，所以說是「弱」不足額。如今《行事鈔》只折還四天，不採用此處弱算所得的天數。〕，又扣除連續大月弱算得半天〔因為要滿八個月才得半天，如今四月十八天就取半天，所以說是「弱」不足額；如今《行事鈔》不折還這一天，因為還不構成半天的緣故。

【1204-0004】資持記/10c_中三下#23
【原文】總計所減弱得十三日，減前五月一日，就實唯四月十八日；準此年暮日生滿十九者，八月十二日應預得受；若除頻大，則八月二十六日得受。今鈔閏還四日，頻大不還，則但虛增十一日；五月一日還十一日，豈非四月二十日實也。退減者，謂於十八年二日內退除四月二十日；
【譯文】總計所扣減的弱額得到十三天，減去前面的五月一日，推就實情只有四月十八天；依照這個算法，在年尾出生而實歲滿十九歲的人，八月十二日就應當可以預先受戒；如果剔除連續大月，那麼八月二十六日才可以受戒。如今《行事鈔》將閏月折還四天，連續大月不折還，那麼只虛增了十一天；從五月一日折還十一天，難道不正好是四月二十日的實數嗎。所謂「退減」，是指在十八年又兩天之內退除四個月又二十天；

【1204-0005】資持記/10c_中三下#24
【原文】故至八月九日後受者，即當十日，已滿二十矣。然於下細算，猶少二日，故疏中約弱得多填兩日，由閏與頻大皆沾少分，故深取所退成滿所增故也。然自古章記，不出今師算法；後學多迷，不免繁重，故略出之。今師約年月俱不滿者，開算此年；
【譯文】所以到八月九日以後受戒的人，到了第十天，就已經滿二十歲了。然而在下面仔細推算，依然缺少兩天，因此《戒疏》中依據弱數多填補了兩天，這是由於閏月與連續大月都沾到少許分數，所以深取其退減以補足所增長之數的緣故。然而自古以來的章疏記述，都沒有列出當今律師（道宣律師）的算法；後學之人大多迷惑不解，不免覺得繁重混亂，所以大略列出。如今律師依據年與月都不滿足的情況，開許推算這一整年；

【1204-0006】資持記/10c_中三下#25
【原文】十九者，前臘月盡日當一年，實唯十七年七箇月零十一日，還約四位明之。初胎法者，九月四日足前成十八年四月十五日。二閏者，十九為章，一章七閏，計十八年四月十五日，猶少七月十五日，則不滿一章；應得六月二十三日，將此足前，成十八年十一月八日也。
【譯文】所謂「十九歲」，是將前一年臘月最後一天當作一年，實際上只有十七年七個月又十一天，同樣依照四個名目來加以說明。第一是胎中法，以九個月零四天補足前面，成為十八年四個月十五天。第二是閏月，十九年為一章，一章有七個閏月，計算十八年四個月十五天，還缺少七個月十五天，就不滿一章；相應應當得到六個月二十三天，將此數補足前面，成為十八年十一月八天。

【1204-0007】資持記/10c_中三下#26
【原文】三頻大者，展前成二百二十七月零八日，四十九月為章，一章有三日；用一百九十六月為四章，得十二日；除三十一月零八日，應得二日，共十四日，足前成十八年十一月二十二日。四布薩者，十八年十一月抽得三百四十日，將三百三十六日為一年，添成十九年餘四日；添前十一月二十二日，成二十六日；
【譯文】第三是連續大月，展開前面年月成為二百二十七個月零八天，四十九個月為一章，一章有三天；取一百九十六個月作為四章，得到十二天；扣除三十一個月零八天，應當得到兩天，總共十四天，補足前面成為十八年十一月二十二天。第四是布薩日，十八年十一月總共抽出三百四十天，將其中的三百三十六天折算為一年，添加上去成為十九年還餘四天；再添入前面的十一月二十二天，成了二十六天；

【1204-0008】資持記/10c_中三下#27
【原文】約二十八日為月，則少二日在。《戒疏》至十二日方得，則於今鈔十日外更加二日，恰成一月，方得滿足二十年也。今則以疏為定。然此算法，連代共迷；講師至此，謬妄最甚；學者聽之，但增昏悶。故特委曲，勿謂繁長。至於詳細，卒書何盡，故且削之。三中，初指俗曆。
【譯文】若以二十八天折算為一個月，那麼還缺少兩天。《戒疏》認為要推算到十二日才可以，那麼就是在如今《行事鈔》的十日之外再增加兩天，恰好滿一個月，這樣才能滿足二十歲。現在就以《戒疏》的說法為準定論。然而這種推算法，歷代以來大家都感到困惑；講經法師講到這裡，所犯的荒謬錯誤最為嚴重；學者聽聞之後，只會徒增昏沉煩悶。所以特地委婉曲折地詳細說明，請不要認為這是繁瑣冗長。至於最詳細的演算，又豈是一時書寫得盡的，所以暫且刪除略過。第三項中，首先指明世俗曆法。

【1204-0009】資持記/10c_中三下#28
【原文】六七家者，此蓋鈔主所見，未詳誰撰。一家者，古記亦多妄指；但是億度，曾無所據，故今不定。易緯八卷，王弼撰，鄭玄注。至下，指餘義。不滿得戒者，即《十誦》中若年不滿二十；自想不滿，或忘不知，僧問滿不，答滿得戒，答不滿不得。又前引《五分》、《母論》，上法得戒，不待年滿。
【譯文】所謂「六七家」，這大概是鈔主親眼所見的書籍，未能詳細考證是誰所撰寫。所謂「一家」，古代的記錄大多妄加附會；全都是主觀臆測，根本毫無根據，所以如今不予定奪。《易緯》共有八卷，王弼撰寫，鄭玄作注。「至」字以下，指出其餘的涵義。年齡不滿而能得戒的情況，就是《十誦律》中所說如果年齡不滿二十歲；自己以為不滿，或者遺忘不知情，僧眾詢問滿不滿，回答說滿便能得戒，回答說不滿則不得戒。另外前面引用的《五分律》和《毘尼母論》，只要證得上人法就能得戒，不需要等待年齡圓滿。

【1204-0010】資持記/10c_中三下#29
【原文】指《戒疏》者，彼文甚廣，不學不知。六十六。〔佛在舍衛，六群鬪諍，如法滅已，後更發起，故制。〕初緣。四諍者，一言諍〔評教理是非，犯相輕重。〕，二覓諍〔評三根清濁，五德是非。〕，三犯諍〔於五犯聚懺評有濫〕，四事諍〔通上三種評羯磨是非，迷悟不決，名言中事諍；評用法治舉徵覈虛實，名覓中事諍；
【譯文】指示參閱《戒疏》，是因為彼處的文字非常博大精深，若不潛心學習就不會明了。第六十六條戒。〔佛陀在舍衛國時，六群比丘引起爭鬥，依法平息解決之後，後來又重新挑起諍端，因此制戒。〕最初的犯緣。所謂四種諍事：第一是「言諍」〔評定教理的是非、犯相的輕重。〕，第二是「覓諍」〔評定見、聞、疑三根是否清淨，長老五德是否具足。〕，第三是「犯諍」〔在五種犯戒罪聚的懺悔評定中產生混亂差錯〕，第四是「事諍」〔通於上面三種諍事，評定羯磨如法與否，迷執與覺悟未有定論，稱為言中事諍；評定依羯磨治罪檢舉、核驗事情虛實，稱為覓中事諍；
