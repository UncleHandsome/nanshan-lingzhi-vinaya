# 校閱材料　第190檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【190-0003】03_業疏/03b_卷一之三#69
【原文】第二、對首中，分科為二，即綱領、毛目也
【譯文】在第二項「對首法」中，科判分為兩部分，也就是總綱領與細目。

【190-0004】03_業疏/03b_卷一之三#70
【原文】初中言對首者，此提綱也。既對一人已上乃至三、四，無別可彰，但舉當時相當為目，故云對首，皆是三語告情引證
【譯文】第一部分說「對首」，這是提綱挈領之語。既然是面對一人以上乃至三、四人，沒有其他特別名稱可以彰顯，只是舉出當時面面相對作為名稱，所以稱為「對首」，全都是以三度口白陳告心意並延請作證。

【190-0005】03_業疏/03b_卷一之三#71
【原文】釋名中，初科「皆是三語」大約為言，然說欲、白告等但一說耳
【譯文】在解釋名義中，第一科所說「全都是以三度口白」，只是大體而言；然而轉達與欲、陳白告事等法，其實只說一次而已。

【190-0006】03_業疏/03b_卷一之三#72
【原文】然作法之中，又分三別：或止對一人，持衣、說淨之類；或通界同法，如說恣、捨懺；或但對三人，如中品蘭也。及論作法，又有三例：或直自陳述，前對默證，如持說等；或雖自言白，前須示誡，如安居、諸懺、入聚諸白；或彼此互作，交誦一文，如說恣清淨。竝隨機隱顯，莫非對首，諸賢斟之
【譯文】然而在作法之中，又分為三種區別：或者僅僅面對一人，如受持三衣、說淨之類；或者通結界內所有同法之人，如說戒、自恣、捨墮懺悔；或者只面對三人，如懺悔中品偷蘭遮罪。至於談論作法的方式，又有三種通例：或者直接自己陳述，對方默然作證，如受持、說淨等法；或者雖然自己陳白，對方必須給予開示訓誡，如安居、各種懺罪、進入村聚的各類告白；或者彼此互相作法，互相誦讀同一文句，如說戒、自恣時宣陳清淨。這些都是隨著不同機緣而有隱沒或彰顯，無一不是對首法，請各位賢德詳加斟酌。

【190-0007】03_業疏/03b_卷一之三#73
【原文】次科，前三別者，即三人通局，如上說也。後三例者，即法事隱顯也。前二但對，後一眾法。「竝下」結示同異，最末一句囑後自裁
【譯文】下一科中，前述三種區別，就是指面對對首者的通與局，如前面所說。後述三種通例，就是指法事儀軌的隱與顯。前兩種屬於單純對首法，後一種屬於眾法對首。自「竝隨機」以下，結語開示同異之處；最後一句則是囑咐後人自行裁奪抉擇。

【190-0008】03_業疏/03b_卷一之三#74
【原文】位置三十三者，謂大數也。通諸部為言，若對《四分》，但有安居、悔墮二、三而已，至於持說衣藥，竝缺其文，故引諸部共成，各如篇顯
【譯文】列出的項目共有三十三種，這是指大略的總數。這是通貫各部派律典而言的；如果單對《四分律》，其中只有安居、悔除單墮等兩三種罷了，至於受持、說淨衣物和醫藥等，都缺乏明文，所以引用其他各部律典共同補全，各自在後續各篇章中彰顯。

【190-0009】03_業疏/03b_卷一之三#75
【原文】顯數中言大數者，非止此故。上列眾法，唯據當宗；此明別法，多出他部，下皆標簡，故云「各如篇顯
【譯文】在顯明數目中說「大略的總數」，是因為實際數目不止於此。上面所列的僧眾法，僅僅依據本宗《四分律》；此處闡明個別之法，多數出自其他部派律典，後文都會一一標明甄別，所以說「各自在後續各篇章中彰顯」。

【190-0010】03_業疏/03b_卷一之三#76
【原文】文云三語名羯磨者，引證也。以習俗生常，唯言僧法得稱羯磨，故引《四分》受戒法中初三歸受，後便止之，因以除疑。前用三語羯磨如法，但後作者是不得耳，佛自斷云「三語羯磨」，則餘不勞爭名也
【譯文】文中說「三語也稱為羯磨」，這是引經據典作為證明。因為世俗習以為常，只認為僧團大眾法才可以稱為羯磨，所以引用《四分律》〈受戒犍度〉中最初用三歸答允受具足戒、後來才停止該法之文，以此來消除疑慮。先前使用三語羯磨是合法的，只是佛陀制訂白四之後再作便不得受戒而已；佛陀自己判斷說此為「三語羯磨」，那麼其餘情況就無須再爭論其名稱了。

【譯文】在解釋作法的第一科中，起初重申提示，自「以」以下顯明用意。《四分律》〈受戒犍度〉記載，佛制白四羯磨前八年間採用三歸三語受具足戒；後來制訂白四羯磨之後，舍利弗請示佛陀，佛陀隨即斷決說：「此前稱為善作羯磨，自制訂白四以後則不再算作受具足戒。」自「佛自斷云」以下，依準經文作出判定。

【190-0016】03_業疏/03b_卷一之三#82
【原文】義分二別者，依位顯相也。但以對首一言，濫通眾別，若不分相，名教不開。就義有三，離小眾懺也；約文但二，合眾多也，所以如上
【譯文】在義理上分為兩類，是依據法位來顯明其事相。只因「對首」這一詞，容易混同於眾法與個別法；如果不細分其事相，名相與教軌就無法開展。若就義理而言有三種，是獨立分出了向少數人（小眾）懺罪的作法；若依文句則只有兩種，是將小眾懺合併入大眾（眾法對首）之中，所以如上文所述。

【譯文】下一科，在「單純對首」中所謂局限於中下的，就是指中品罪與下品罪等較輕的情事。

【190-0020】03_業疏/03b_卷一之三#86
【原文】二、眾法對首者，本是僧秉，別人非分，道在兼濟，故通於下，如懺捨滅惡之方、說恣清心之術，若不許者，教非通瞻，不濟時緣，故兩被單對，俱成惠及
【譯文】第二、眾法對首：本來應由僧伽大眾秉持舉行，個別之人無權獨自秉辦；但佛法的精神在於兼顧救濟，所以通融開許至下位（人數不足僧法時）。例如懺捨以滅除惡業的方便、說戒自恣以清淨道心的軌則，如果不加開許，聖教就不能普被眾生，無法救濟當時的機緣；所以無論是單獨心念還是面對個人對首，都承蒙這種恩惠普及。

【190-0122】03_業疏/04a_卷一之四#68
【原文】今世有人言「知鐘」者，云是淨語言，「打鐘」者，不淨語也。元此知淨自不得為，令他作之，故云知也；鐘則不爾，自他通用，不有種相，何須避之？當部言打，其事極多，人、畜、非情咸有其戒，可亦改之為知淨也？《智論》「檛犍槌」，《阿含》「擊犍槌」，《五分》「打三通」，經中撞、擊、鐘、鼓，竝以知淨之言別有所為，故翻經之家隨以此方一相往翻，莫非物觸聲發也。故「知鐘」之言雖非巨害，然是知法者之大忌也
【譯文】當今世上有人稱鳴鐘為「知鐘」，說是清淨的用語，而稱「打鐘」為不清淨的用語。原本所謂「知淨」，是因為比丘自己不能親自去作，令他人代為作之，所以才說「知（知法認可）」；鐘鳴之事則不然，自己或他人皆可敲擊，鐘又沒有草木生長之種相，何須避諱？本部《四分律》中談到「打」，其事例非常多，對於打人、打畜生、打非情之物都有相關戒律，難道也可以將它們一概改稱為「知淨」嗎？《大智度論》說「檛（擊打）犍槌」，《阿含經》說「擊犍槌」，《五分律》說「打三通」，經文中所謂撞、擊、鐘、鼓，都因「知淨」之語另有特定用意，所以翻譯佛經的大德便隨順此方日常的一致意義進行翻譯，無非都是指器具相互觸擊而發出聲響。因此，「知鐘」這種說法雖然算不上天大的禍害，但卻是通曉戒法之人所極力避諱的笑柄。

【190-0123】03_業疏/04a_卷一之四#69
【原文】三斥濫中，初引濫。彼謂使人時，須云「知鐘」，不得云「打鐘」。「元下」次正斥，有四：初示知淨本制。一為比丘自不得為，此通掘壞、錢寶等；二為有生種相，此局壞生一戒。鐘竝反此，義不須之。「當下」次引餘戒例難。言人畜者，即打比丘提，乃至打畜生吉；非情，即打故衣。「智下」三引示。檛、擊、打、撞，事同語異，隨用翻之。「故下」四誡誥。在事雖非大害，於法深屬無知，凡在學流，故須避忌
【譯文】在第三項斥責浮濫之說中，最初引述浮濫之論。他們認為差遣他人時，必須說「知鐘」，不能說「打鐘」。自「元（此知淨）」以下，其次進行正式斥責，共有四點：第一、揭示「知淨」的根本制定原意。一是因為比丘自身不得去作，這通於掘壞地、捉持金銀錢寶等戒；二是因為物體具有萌芽生長之種相，這局限於損壞生種一戒。敲鐘之事完全與此相反，就義理而言根本不需要知淨。自「當（部言打）」以下，第二、引述其餘戒條作反例責難。所說的人與畜生，即是指打比丘犯波逸提（提），乃至打畜生犯突吉羅（吉）；非情之物，即是指拍打塵舊衣物。自「智（論）」以下，第三、引證說明。「檛」、「擊」、「打」、「撞」等詞，實質相同而字詞不同，只是隨順用法而翻譯罷了。自「故（知鐘之言）」以下，第四、誡勉告誡。在事相上雖然並非彌天大害，但在戒法上卻極屬無知，凡是修學戒律之士，所以必須對此引以為忌。
