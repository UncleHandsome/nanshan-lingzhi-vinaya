# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【352-0001】03_業疏/20b_卷四之三#1
【原文】第二明心念法。本是對首，以無所對，開心念也。一切心念皆須口言，唯說戒座上憶罪露者，恐閙眾故，直爾自聞言了為相也。文如前法，但略對境
【譯文】第二、說明心念安居之法。安居本來必須對首作法，因為沒有對首之人的緣故，才開許作心念安居。一切心念法都必須口中出聲言說，唯獨在說戒座上憶起罪過而發露懺悔時，唯恐擾亂大眾的緣故，才只以自己能聽清話語為限度。心念安居的文句如同前面的對首法，只是省略了對境之人的言詞。

【352-0002】03_業疏/20b_卷四之三#2
【原文】二心念中，初示制開。「一」下明作法，恐謂心念不須言故，因決餘法，故云一切。言了為相，三業具故。「文」下點同異。由是獨秉，前告後答義不可立
【譯文】在第二心念安居中，首先指明制法與開許。「一」字以下說明具體作法，唯恐有人以為心念法就不需要口頭言說，所以藉此順帶決斷其餘諸法，因此說「一切心念皆須口言」。以「言聲了了分明」為表相，是因為身口意三業都必須具足的緣故。「文」字以下點出與對首法的同異。因為是個人獨自秉持作法，所以先前警告、後面應答的義理便無法成立。

【352-0003】03_業疏/20b_卷四之三#3
【原文】十誦》五人，謂蘭若獨住、遠行、長病、饑時、依親，開作心念七事，謂布薩、自恣、受日、受衣、受七日藥、與捨請施衣等也
【譯文】《十誦律》中列出五種人，即：阿蘭若獨住者、遠行者、久病者、飢饉歉收之時、依附親友者，開許他們作心念行持七件事，也就是：布薩（說戒）、自恣、受日出界、受持衣物、受持七日藥、以及（受請後出界）捨請、說淨施衣等。

【352-0004】03_業疏/20b_卷四之三#4
【原文】次科。蘭若獨住為一人。饑時謂歉歲。依親謂在俗舍。並據無侶，故開獨念。七事中對前羯磨，前二即眾法心念，次三及下施衣即說淨並對首心念，捨請是但對首。前集法中對念有七，四種同此，餘三即安居、捨衣、受鉢也。則知心念安居，唯出本律
【譯文】第二科中。阿蘭若獨住算作一人。飢時是指歉收饑荒之年。依親是指住在俗人舍宅。這些都是依據身邊沒有同伴為由，所以開許獨自心念。在七件事中對照前面的羯磨：前兩項（布薩、自恣）就是大眾法的心念；隨後的三項（受日、受衣、受七日藥）以及下面的施衣，屬於說淨以及對首法的心念；捨請施衣則僅屬於對首法。在前面所輯錄的法規中，對首轉心念的情況有七種，其中四種與此處相同，其餘三種就是安居、捨衣、受鉢。由此可知，心念安居之法，唯獨出自本宗《四分律》。

【352-0005】03_業疏/20b_卷四之三#5
【原文】第三、忘成法中，文雖外來，義通主客。有要者成，如上解也。《五分》云：「有比丘為安故來受房臥具，己不念安居，口又不言。佛言：為安居受房，亦成安也。」
【譯文】第三、在「忘記作法而安居成就」之中，律文雖然記載的是外來比丘之事，但義理上通於主住者與客僧。只要心中有安居之要期的便能成就，正如上文所解釋。《五分律》說：「有比丘為了安居的緣故而來領受房舍臥具，自己心中既未念及安居，口中也沒有言說。佛陀說：既然是為了安居而領受僧房，也算成就了安居。」

【352-0006】03_業疏/20b_卷四之三#6
【原文】三忘成者，夏初在界忘不加法，後憶方加，許成前坐。初科初牒釋文，開外客義通舊住，古今異也。下引《五分》以示忘相。「不念」謂不起心，「不言」謂不加法
【譯文】第三、「忘記而成就」的意思是：夏初在界內忘記了舉行作法，事後憶起時才補行作法，佛陀聽許算作成就前安居。第一科首先引述並解釋律文，指出開許外來客僧的義理也通於原有的舊住僧，這是古今論師見解相異之處。下文引用《五分律》以顯示遺忘的具體相狀。「不念」是指心中未曾生起作法之念，「不言」是指口中未曾舉行作法之語。

【352-0007】03_業疏/20b_卷四之三#7
【原文】若爾，忘不受日得例此不？答：諸律無解。《五百問》云：夏中忘受七日出界行，憶即悔者，一坐中不得過三；悔過者，不成歲
【譯文】如果這樣，忘記受日出界是否可以比照此例？答：各部律典都沒有直接解釋。《五百問經》說：夏安居期間忘記受七日法而出界遊行，憶起時立即懺悔的人，在一次安居坐夏之中不得超過三次；若超過三次者，不能成就夏歲（算破夏）。

【352-0011】03_業疏/20b_卷四之三#11
【原文】界者，入攝僧界；園者，入僧伽藍園。故《伽論》云：云何名林？林名伽藍，即給孤園是其證也
【譯文】所謂「界」，是指進入了攝僧界；所謂「園」，是指進入了僧伽藍的園囿。所以《摩得勒伽論》（《薩婆多部毘尼摩得勒伽》）說：什麼叫做林？林就是指伽藍，給孤獨園就是其明證。

【352-0012】03_業疏/20b_卷四之三#12
【原文】二中，初通釋藍界。曾結則約界，未結則從藍；或可界寬藍狹則約界說，藍寬界狹即據藍論。山林、村聚，並同藍斷。故下別釋藍相。藍是梵語，此翻為園，本因給孤買園、祇陀施樹，不忘其始，故經律中皆以園林召之，即僧坊之通號。世有聞園林謂是野圃，又謂藍者乃是牆援，不學寡陋，取笑後生，豈不慎乎
【譯文】在第二部分中，首先通泛解釋僧伽藍與界地。曾作法結界的就依據界地來論，未曾作法結界的就依從伽藍來論；或者界地廣大而伽藍狹小時就依界地來說，伽藍廣大而界地狹小時就依據伽藍來論。山林、村聚等處，都同伽藍一樣判定。所以下文分別解釋伽藍的相狀。「伽藍」是梵語，此處翻譯為園，本來是因為給孤獨長者買園、祇陀太子布施樹木，為了不忘其起緣根本，所以經律之中都以「園林」來稱呼它，這就是僧坊精舍的通稱。世上有人聽到「園林」便以為是野外的菜圃園子，又認為「伽藍」是指圍牆籬笆，這真是未曾受學而孤陋寡聞，只會招致後學晚輩的恥笑，怎能不謹慎對待呢！

【352-0013】03_業疏/20b_卷四之三#13
【原文】今解所以前一脚入界明相出成者，以忽切不暇開不結成。我今兩足入界，雙單在園，處界既久，容預得結，未結遇明，應非前夏。佛判云：十六日夜分未盡入界，雖不說安，開成前故
【譯文】如今解釋：先前一隻腳踩入界內、明相出時便告成就，是因為事態倉促緊急、無暇作法，所以開許不用結夏便能成就。如果我現在雙腳都已踩入界內，或者雙腳或單腳已在僧園之中，處在界內的時間已經很長，本有充裕的時間從容結夏，卻沒有作法而迎來天明，照理應當不算成就前安居。但佛陀判定說：只要在十六日夜分尚未結束之時進入界內，縱使口中沒有陳說安居，也開許算作成就前安居。

【352-0014】03_業疏/20b_卷四之三#14
【原文】三正明中，初敘本開悤遽。「我」下次決入界容緩。隋慢越明，似非開限，故引佛判並成前夏。問：一脚既成，雙何復說？答：緣起次第，前雙後隻，初急次緩，因有兩開。既開已後，但須論隻，雙自可知
【譯文】在第三項「正明」中，首先敘述原本開許隻腳入界是由於情事匆忙急迫；自「我今兩足入界」以下，接著決斷進入界內從容和緩的情形。因怠惰遲緩而拖延至天明破曉，看似不在開許範圍之內，所以引述佛陀的判斷，認定都成立前安居。問：既然一隻腳踏入就已成立，為何還要再說雙腳？答：這是依據緣起的先後次第，先說雙足，後說隻足；起初是匆忙急迫，其後是從容和緩，因而有了這兩種開許。既然已經開許之後，便只需論述一隻腳，雙腳成立自然不言自明。

【352-0015】03_業疏/20b_卷四之三#15
【原文】問：雙足入出成敗相對，未知一足入出得例前不？答：要須兩足出界辯破，以利勝故。若一出破、一入不成，皆損行人，不名開制，大有理也
【譯文】問：雙足出入界線與安居的成敗彼此相對，不知一隻腳出界或入界，能否比照前例呢？答：必須要雙足都出界才判定為破夏，這是因為以利益行者為優先。如果一隻腳跨出就算破夏，一隻腳跨入卻不算成立，這都會損害修行人，就不能稱作慈悲的開許與制戒，因此這樣判定極有道理。

【352-0016】03_業疏/20b_卷四之三#16
【原文】問答中初問，入即成安，出謂破夏，雙足可知，隻足乃異，故問通之。答中出破論雙，入成約隻，有益無損，得教本意，故云有理
【譯文】問答中，首先提問：入界即成立安居，出界則是指破夏；雙足出入的情況容易明瞭，隻足出入則有所不同，因此發問以求通達釋疑。答文中說明出界破夏論雙足、入界成立安居約隻足，如此有益而無損，契合佛陀立教的本意，所以說「極有道理」。
