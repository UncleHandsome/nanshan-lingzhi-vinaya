整體看下來，這批譯文對「止持／作持」「制門／聽門」「可學／不可學」的架構掌握得不錯，語氣也通順。問題主要集中在**幾個關鍵詞誤譯**、**科文用語（牒、出體、標）失真**，以及**過度增譯**。以下按輕重分列。

---

## 一、建議必改（意思會偏掉）

**1. 0001：「加法」譯成「加持作法／進行加持」（出現兩次）**
律學的「加法」＝加上作法（白二處分、說淨、受持等羯磨作法），與一般佛教語境的「加持」（佛力加被、灌頂加持）完全不同。讀者極易誤解。
→ 建議：「理須依律作法（白二處分、說淨）」「依法不能作法」。

**2. 0017：「正攝止持」譯成「正統收攝的止持」**
「正／旁」是**正攝（正式歸屬）／旁收（兼帶收攝）** 的對舉，不是「正統／非正統」。
→ 建議：「一是斷惡門的止，正攝於止持；二是修善門的止，兼帶收於作持。」

**3. 0024：「如昔解云……非此所明」譯成「正如過去古德所解釋的……這並非本疏所要闡明」**
「正如」帶有認同語氣，與下句否定自相矛盾。此處「如」＝「像（那樣的主張）」，是**列舉古說而後否定**（記文 #35 已說「下文難破」）。
→ 建議：「像古德所解釋的『作持門中事法，唯可學、無不可學』那樣的主張，並不是本疏此處所要說的。」

**4. 0020：「事法無別」譯成「事相與法規並沒有差別」**
容易被讀成「事與法二者無別」；原意是「（此處聽門的）事、法與前面止持門聽門所說的**內容相同**」。
→ 建議：「這仍是指向止持，所說的事、法與前面並無不同，那要依什麼來區分呢？」

**5. 0008：「竝託事法」譯成「兩者都是依托著事相與法規」**
變成「事法依託事法」的循環句。「竝（並）」是說**作持之行一律依托事、法二體**而進修成滿。
→ 建議：「（這些行持）都是依托事相與作法，精進運用而修習成就，無所違犯，名為作持。」

**6. 0007「還通二位」譯成「通達……兩個範疇」；0024「通不可學」譯成「通向不可學」**
「通」是**通於、兼通（範圍涵蓋）**，不是「通達（證悟、精通）」或「通向（通往）」。
→ 建議：「作持同樣通於『可學』與『不可學』二位」「不像止持兼通不可學」。

## 二、術語與科文用語可再精準

| 出處 | 原譯 | 建議 |
|---|---|---|
| 0001 | 妨難→「障礙災難」 | 造房戒的「妨處、難處」（處所有妨礙、有危難），宜作「房舍處所有妨難」 |
| 0001 | 房財→「僧房和財物」 | 「房舍與（長）衣財」，與下文「犯過衣財」呼应 |
| 0005 | 標云→「標題說」 | 「疏文標舉處說『亦』」（科文的「標」指標舉之文，非標題） |
| 0007 | 出體→「列出體系」 | 「列舉其體（所指內容）」；「出體」是列出所攝法體，非「體系」 |
| 0009 | 初句牒示→「第一句提出標明」 | 「第一句牒舉前文（『可學』）而顯示」——「牒」＝引前文，宜保留 |
| 0009 | 所持體→「所持守的實體」 | 「所持之體（即事、法二種）」；「實體」易生形上學聯想 |
| 0008 | 衣鉢行護→「使用威儀與防護護持」 | 「衣鉢的行持與守護（受持、護淨、離宿等）」；「威儀」是加出來的 |
| 0011 | 無由可作→「絕不去做」 | 「惡法本無從造作（不許作）」——原語偏客觀無由，非主觀拒作 |
| 0011 | 各有意致→「各有其深奧的義理」 | 「各有其意趣（用意）」 |
| 0013 | 「前面制定有所作為當中的止」 | 「前面制門作持中的止」（原譯拗口） |
| 0014 | 「與那是相同的」 | 「與那（制門作持中的止）相同」 |
| 0023 | 及論→「但若詳細論究」 | 「至於論到止與作」（「及」是承接，非轉折） |

另兩處可加註避免歧義：
- **0016「還屬前門」**：譯「依然屬於前者的止持門」判斷正確，但上文剛談過「制止門／制作門」，「前者」指涉不清，建議直說「仍歸屬前面的**止持門**」。
- **0009「對簡止持，是離過故」**：原意是「（『制修學』）相對簡別於止持，因止持只是離過（作持則是進修）」，現譯「對比區分止持，是因為止持著重於遠離過失」略顯含糊。

## 三、過度增譯（建議瘦身）

- 0008「心中**戒慎恐懼**不敢逾越」→ 原文僅「不敢違越」。
- 0009 / 0023「雙持的**深義**」、0011「**深奧的**義理」→ 原文無此評價。
- 0017「**嚴格**限定」「**完全**侷限」→「局」即局限，不必加強調詞。
- 0003「昏昧惑亂**同時**生起」→「雜起」是夾雜而起，未必同時。
- 0003「望不違教」譯「沒有違背教誡**本心**」→ 可作「就其（非有意）不違教法而言」。
- 0024「**積極進取**修持」→ 用语偏現代business味，可作「進修之行」。

---

## 四、標點與一致性

1. **引號與句號**：多處寫成「開許停止。」／「止持。」／「作持。」——引號內只是詞語，句號應置於引號外：`所以「開許停止」。`（0001、0003、0008 等）
2. **制門譯名不一**：同一批文出現「強制制定（制門）」「制定門」「禁止惡行門（制止門）」「禁止命令」。建議固定為「制門（制止門）」，並視上下文補「制令修善／制止造惡」，避免讀者以為是不同門類。
3. **0018「僧房房舍」** 冗贅，「房舍」即可；「長財」建議作「長餘衣財（長財）」。
4. **0002「還復令制」** 譯「轉為禁止命令」生硬，可作「仍會回過來加以制止，所以聽門中也有『止』」。

## 五、兩則示範改寫

**0001**
> 所謂「可學的事、法」，是指房舍的尺寸限量、長衣的寬狹尺量、乞求僧團指授處所的白二羯磨、以及加作說淨之法。對這些事與法，也有「聽作」與「聽止」：若確實有房舍、衣財（且如法），理當依律作法，所以說「聽作」；若房舍處所有妨難，或衣財已犯過（如長衣過限），不合再作法，所以說「聽止」。

**0024**
> 像古德所解釋的「作持門中的事、法，唯有可學，沒有不可學」，並不是本疏此處所要說的。古德的理由是：「若不是進修之行，聖人便不制令修學；這不同於止持兼通不可學——因為止持只在離過，所以（在止持中）可以論說不可學。」

---

**小結**：真正需要動的是「加持」「正統」「正如……非此所明」「事法無別」「竝託事法」「通達／通向」這六處；其餘多屬術語精準度與贅詞問題，改完後整體可讀性與律學準確度都會明顯提升。
