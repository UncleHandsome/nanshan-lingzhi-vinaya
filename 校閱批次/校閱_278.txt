# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【278-0001】02_戒疏/14c_卷三下之二#104
【原文】【註】比丘尼同犯。若不語彼人「知是，看是」，突吉羅。不犯者：若語言「知是，看是」，如上捨法。若彼人不肯與衣者，餘比丘當語言：「佛有教，為淨故與汝；應還他物。」若又不與，自往語言：「佛教比丘作淨與汝，汝應與僧、塔、和尚、知識及本施主。」不欲令失彼信施故也。
【譯文】【註文】比丘尼同犯此罪。如果不對那人說「你應當知道這個、你且看看這個」等說淨辭令，結突吉羅罪。不構成犯戒的情況包括：如果已經說了「你應當知道這個、看看這個」，遵照上述的捨法辦理。如果那個人拿了錢卻不肯為比丘買衣，其餘的比丘應當對他說：「佛陀有教敕，是為了作淨法的緣故才把錢交給你；你應當歸還人家的財物。」如果他依然不肯交還，比丘應親自前往對他說：「佛陀教導比丘作淨法把錢交給你，你若不買衣，就應當將它轉施給僧團、佛塔、和尚、善知識或原本布施的施主。」這是為了不讓那位信眾的布施功德落空流失的緣故。

【278-0002】02_戒疏/14c_卷三下之二#105
【原文】【疏】戒本六句：一、人；二、「自手捉」者，戒之業也；三、「錢及金寶」，戒防境也；四、「教人受」下，同上業也；下二，可知。
【譯文】【疏文】戒本文字共有六句：第一、犯罪的人身；第二、「自手捉」這句，是戒律所禁止的親自造作行為；第三、「錢及金寶」，是戒律所防護的客體對象；第四、「教人受」以下，與上面的親自造作行為等同罪責；最末兩句，文意容易理解。

【278-0003】02_戒疏/14c_卷三下之二#106
【原文】【記】戒本，釋文中，初科。二是自作，四即教他，自他雖異，造作不殊，故指「同上」。「下二」，即捨與罪也。
【譯文】【記文】戒本釋文之中，第一科。第二句是親自作，第四句是指使他人作，親自作或叫別人作雖然形式不同，但造作的犯意罪質並無差別，所以指稱為「同上」。「最末兩句」，就是指捨棄與結罪的文句。

【278-0004】02_戒疏/14c_卷三下之二#107
【原文】【疏】此是畜寶戒，下「九十」是捉寶戒也。今文中不明畜者，略也。「自手」、「教人」，若可「置地」者，列彼受畜之相。受元為畜者，得捉、畜兩罪，捉依後科，畜自依此。若捉不畜，不犯此戒，犯後「九十」。故《多論》云：「捉金薄、金像及他寶者，若自說淨寶，俱得提罪。」《僧祇》亦爾：金銀錢隨國所用，相成就者，皆犯提罪。
【譯文】【疏文】這一條是「蓄存金寶戒」，後面九十單墮戒中的是「捉持金寶戒」。現在這條戒的經文中沒有明確寫出「蓄存」的字眼，這是文句上的省略。「親手」、「指使他人」，乃至「放在地上接受」，都是在列舉納受以供蓄存的各種情態。如果受取的初衷本就是為了蓄存，那就同時結得捉持與蓄存這兩種罪責，捉持之罪依後面的單墮科判定，蓄存之罪則依本條捨墮戒判定。如果只是隨手捉拿而並非為了自己蓄存，就不犯這條戒，而是違犯後面九十條中的單墮戒。所以《多論》說：「若捉持塗金箔、金屬佛像以及別人的寶物，或者是自己已經作了說淨法的金寶，這些全都只犯單墮提罪。」《僧祇律》也持同樣標準：金銀與錢幣只要是該國家所通行的，只要具備貨幣相狀的，捉持的人全都結犯提罪。

【278-0005】02_戒疏/14c_卷三下之二#108
【原文】【記】簡濫中。初分兩戒。「今」下，通文相。以文言「自手捉」，昔人乃謂此制捉寶，下是拾遺，故特分示。初釋文，「受」下判罪。準此應作四句：畜而不捉，如文「置地」，單犯此戒；二、捉而不畜，如下《多論》，單犯後戒；亦捉亦畜，如文「手捉」，二戒俱犯；四、俱非句，如指授捉金像等。「故」下，引證「九十」。《多論》「金薄」，即貼塗之物。《僧祇》錢寶，隨國所用，金銀銅鐵但成錢相，捉者皆犯。
【譯文】【記文】簡別混淆的論述中。首先劃分這兩條不同的戒。「今文」以下，通達理解文句的相狀。因為經文寫著「自手捉」，古人便以為這條戒是禁止捉寶，後面那條只是拾遺重述，所以特地辨別開示。首先解釋經文，「受元」以下判定結罪。準照此理應當列出四句邏輯來剖析：第一、蓄存但不親手捉拿，如同條文說的「放在地上受取」，單單只犯本條捨墮戒；第二、捉拿但不為己蓄存，如同後面《多論》所引，單單只犯後面那條單墮戒；第三、既親手捉拿又為己蓄存，如同條文說的「手捉」，兩條戒同時違犯；第四、兩者皆非的情況，如同指點他人放置、或拿取金佛像等。所以下面引用論典來證實「九十條」。《多論》所說的「金薄」，就是指貼在物體表面塗刷的金箔薄片。《僧祇律》所指的錢幣寶物，只要是各國所通行的，不論是用金、銀、銅、鐵製作，只要具備錢幣形制圖紋，比丘捉拿了就全都犯戒。

【278-0006】02_戒疏/14c_卷三下之二#109
【原文】【疏】注解文中。「是中捨」者，牒前制過也。二、「彼有信樂」下，明捨錢方便，覔淨主付也。三、「若彼取還與比丘」者，不達施意，佛為淨故令彼受之，彼不解故不敢即受，乖淨施法，故文云「即作彼人物受，後得衣鉢，更轉淨貿，方可持之」。四、「若彼取」下，既悟解意，即取迴淨，故無轉貿之文。
【譯文】【疏文】戒本注文的段落之中。「是中捨者」這句，是承接提引前面的違制過失。第二、「彼有信樂」以下，說明捨棄金錢的善巧方便，應尋求懂得戒法的淨人施主交付。第三、「若彼取還與比丘」這句，是指在家人不明白比丘作淨施的本意，佛陀本是為了清淨法度才讓居士接納這筆錢，居士因為不懂而不敢直接收下，這就違背了清淨施與的法則，所以注文說「比丘應視為受託暫管對方的物品而收下，日後換得了衣缽，必須再度透過轉手說淨貿易，然後才可以受持」。第四、「若彼取」以下，是指居士當下就徹底領悟了作淨施的本意，隨即拿去轉為清淨的衣缽送還，所以文中就沒有再次轉手貿易的交代了。

【278-0007】02_戒疏/14c_卷三下之二#110
【原文】【記】釋注，捨法，正釋有四。三中，「不達施意」，由不先語，不曉說淨之意也。「作彼物受」，令淨人賞，事同受寄也。「後易衣鉢更轉貿」者，由前淨法不成，後得之物，還非淨故。四中，即據解淨法為言。
【譯文】【記文】解釋注文捨法的段落，正式解釋共有四點。第三點中，「不明白布施的本意」，是因為出家人起初沒有先講明白，居士不懂得說淨的意思。「作為對方的物品代收」，是讓淨人代為保管，性質就像接受別人的寄放託管一樣。「日後換得衣缽必須再轉手貿易」，是因為前面的說淨手續並未圓滿成立，後來換得的物品依然不算清淨之物的緣故。第四點中，就是依據在家人完全懂得說淨之法的狀況來說的。

【278-0009】02_戒疏/14c_卷三下之二#112
【原文】【疏】答：「沙門達教，須語彼知。故《多論》云：『先求一知法白衣，令知比丘之法不畜錢寶。後若得者，於檀越作淨也。』《四分》之中，前由迷故，所以不成。物既見在即作彼物，後若得財更須貿易，方得加受。文極顯然，勿怪鄭重。」
【譯文】【疏文】回答：「沙門既然通達佛陀的教誡，就必須事先用話語告知對方。所以《多論》說：『比丘應當先尋找一位懂得戒律常識的在家人，讓他明白比丘的戒律是不得蓄存金錢寶物的。日後若獲得了金錢，才能在施主那裡如法作成說淨。』在《四分律》中，前面的情況是由於施主迷惘不解，所以淨法才無法成功辦妥。那筆錢既然還擺在那裡，就只能先權充對方的託管物，日後若換成了物資，還必須再度作貿易說淨，才能如法受持加持。律文的條理極其清晰明確，請不要嫌怪此處解說得太過周折鄭重。」

【278-0010】02_戒疏/14c_卷三下之二#113

【278-0011】02_戒疏/14c_卷三下之二#114

【原文】【記】次簡貿衣中。「五種」別者，一人，二業，三開，四捨，五還。總括二戒，始終皆備，尋下對之，不復引也。初云「賞衣唯俗」者，即在家二眾。五、云「本非本」者，貿衣即還本衣，貿寶與俗易淨，故非本也。又作四句以簡二戒：一、以衣易寶，二、以寶易衣，三、以寶易寶，四、以衣易衣。一、三犯此戒，二、四犯後戒。準此，但約所貿以分兩戒，不論能貿也。
【譯文】【記文】接著在與「買賣衣物戒」簡別的段落中。「五種」區別包括：一、交易人身，二、造作行為，三、開緣規範，四、捨物處理，五、歸還財物。這五點總括了這兩條戒從頭到尾的所有關鍵，只要順著後文對照即可，在此不再重複引述。第一條所說「買賣衣物唯對俗人」，是指優婆塞、優婆夷這在家二眾。第五條說「原物與非原物」，是指買賣衣物在捨懺後退還本來的衣料，買賣金寶則是交給俗人做淨化兌換，所以退回的不是原本的金寶。另外可以用四句邏輯來剖析這兩條戒：第一、拿衣服換金寶；第二、拿金寶換衣服；第三、拿金寶換金寶；第四、拿衣服換衣服。第一和第三種情況違犯本條買賣金寶戒，第二和第四種情況則違犯後面的買賣衣物戒。準照這個規律，僅僅只是依據交易「所換得的物品」來劃分這兩條戒，而不論你拿什麼出資去買賣。
