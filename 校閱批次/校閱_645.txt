# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【645-0001】01_行事鈔/11c_卷下之三#34
【原文】《僧祇》：不得作駱駝坐，應加趺坐；若疲極者，當互舒一脚。仰臥脩羅，伏者餓鬼，左脇如貪欲人；具如法者，出三十五卷中。《增一》云：今聽比丘，先以手憑座，後坐，此我之教。《十誦》：無病不得晝臥；若喜眠，應起經行。《善見》：臨欲眠時，先於六念中，一一念也。坐法有二：一結加趺，二踞坐。跪有二：一長跪，即兩膝及足指至地；二互跪，右膝至地。《三千》云：不得於上座前踞坐。踞坐五法：一不交足；二不雙竪兩足；三不却踞兩手，掉捎兩足；四不得搘拄一足，申一足；五不上足。五事正坐法：一不倚壁，二不手前據，三不肘據床，四不兩手捧頭，五不以手拄頰。《毘尼母》云：何名坐？眾僧集會，撿容整服，加趺而坐，儀用可觀；又如坐禪人，坐經劫，身不動搖，觀者無厭。人多者狹膝，見上座亦爾，不宜寬縱。《三千》云：不與三師並坐。《十誦》：聽法時，上座來，不應起下座；起者，吉羅。若和上阿闍梨，恭敬故，自起；不得起他，吉羅。乃至聽法，不得與沙彌同床坐。沙彌得與白衣同床坐；大比丘三夏，亦同床得坐。《三千》云：欲上床有七：一當徐却踞；二不得匍匐上；三不使床有聲；四不大拂床有聲；五不大㐸大吒歎息，思惟世事；六不狗群臥；七起以時節，心起不定，當自責本起。又若聞犍稚聲，即當著袈裟，出戶如法；二於堂外住，正衣脫帽；三有佛像，頭面作禮，却禮僧；四當隨次向上座，當遺上座處；五隨上座坐，若踞。
【譯文】《摩訶僧祇律》說：坐下時不得像駱駝般蜷曲雙膝趴坐，應當結跏趺坐；如果身體疲累到了極點，准許輪流伸展放鬆一隻腳。仰面朝天而臥是阿修羅的睡相，面朝下俯臥是餓鬼的睡相，側向左脇而臥是貪欲之人的睡相；完全合乎佛法的右脇吉祥臥，載於律本第三十五卷中。《增一阿含經》說：從今准許比丘，先用雙手扶按床座，然後緩緩坐下，這是我的教誨。《十誦律》說：身體無病不得在白天睡臥；如果頻頻昏沉嗜睡，應當立刻起身經行散步驅除睡意。《善見律毘婆沙》說：臨睡臥之前，應當先在六念處（念佛、念法、念僧、念戒、念施、念天）之中，逐一繫念觀想。僧人的坐法有兩種：一是結跏趺坐，二是端身踞坐。跪拜的方法有兩種：一是長跪，即兩膝及雙腳足趾一同著地直身而跪；二是互跪（胡跪），即右膝著地、左膝豎起立足。《大比丘三千威儀》說：不得在長老上座面前隨意踞坐。端正踞坐有五種禁令法度：一是不交叉雙腳；二是不將雙腳同時豎膝向前；三是不兩手向後撐座、前後隨意搖晃擺動雙腳；四是不得支撐屈起一隻腳而隨意伸長另一隻腳；五是不把雙腳擱放於高處。端正合儀正坐的五項法則：一是不靠倚牆壁，二是雙手不向前撐地，三是不以手肘撐靠床榻，四是不以雙手抱捧著頭部，五是不以手掌托支臉頰。《毘尼母經》說：怎樣才稱作如法的坐姿？大眾僧集會之時，檢點容貌、整飾衣冠，結跏趺端然而坐，威儀舉止令人望而肅然起敬；又如同修習坐禪的人，枯坐歷經無量劫數，身形依然端正不動不搖，令觀看者永不心生厭倦。僧眾人多時應當收攏夾緊雙膝端坐，見到上座時也是如此，絕不宜放鬆身姿寬縱放蕩。《大比丘三千威儀》說：不得與自己的三師（戒和尚、羯磨阿闍梨、教授阿闍梨）平起平坐。《十誦律》說：在大眾聽法的時候，如果有上座比丘走來，不應當強行叫起已經入座的下座比丘讓座；如果強令他人起座讓座者，犯突吉羅（吉羅，輕垢罪）。但如果是自己的和尚或阿闍梨前來，出於極度恭敬的緣故，自己應當主動起身讓座；但絕不得擅自去叫起其他比丘讓座，違者犯突吉羅。乃至在聽法之時，大比丘不得與未受具足戒的沙彌同坐一張床席。沙彌准許與在家的白衣同坐一張床榻；戒臘滿三夏以上的大比丘，彼此之間亦准許同床共坐。《大比丘三千威儀》說：若要登榻上床有七項規矩：一是應當緩慢倒退著轉身坐上；二是不得伏地爬行匍匐著爬上床；三是不可弄出床鋪震動搖晃聲響；四是抖拂被席不可大力弄出聲響；五是不大聲張口打呵欠、不大聲咋舌嘆息、不胡思亂想世俗雜事；六是不像群狗般擁擠雜亂團臥在一起；七是起床必須遵守規定的時節刻度，若心念浮動起臥無定規，應當反省自責初始的出家本心。此外，如果聽聞集眾的犍稚（木磬、鐘磬）之聲敲響，就應當立刻披搭袈裟，如法步出房門；二是在法堂之外稍作停留，整肅衣服、脫下帽子；三是堂內若供有佛像，先頭面著地頂禮佛像，退後再向僧眾行禮；四是應當依序走向上座席位，應當將尊貴席位讓留給上座長老；五是跟隨上座安坐，或端然踞坐。

【645-0003】01_行事鈔/11c_卷下之三#35
【原文】《善見》：睡時當須早起；浴竟睡者，念髮燥便起；如是，看星月光影為分齊。《三千》：臥當頭向佛；二不臥視佛；三不雙申兩足；四不向壁臥，又不伏臥；五不竪膝，要以手撿兩足，累兩膝。《毘尼母》：比丘貪著睡眠，廢捨三業，不復行道，金剛力士呵責。佛言：食人信施，不應懈怠；夜二時中，應坐禪誦經經行；一時中，以自消息；是名臥法。《僧祇》：臥如師子王法。不得眠至日出，應於後夜當起，正坐思惟己業。
【譯文】《善見律毘婆沙》說：睡臥之後必須早起；如果洗沐完畢小睡的人，心中估量著頭髮一乾就應當立即起身；像這樣，應當觀察夜空星宿月亮的光影位置作為作息的刻度節限。《大比丘三千威儀》說：睡臥時頭部應當朝向佛像；二是在床上仰臥時不可直接直視佛像；三是不得把兩條腿同時伸得筆直；四是不可面朝著牆壁側臥，也不可伏面趴著睡；五是不可屈起雙膝直立，一定要用手檢束安置好雙腳，使兩膝整齊疊合在一起。《毘尼母經》說：比丘若貪圖沉溺於睡眠，荒廢拋棄身口意三業的修行，不再精進辦道，金剛力士將會手持杵杖予以嚴厲呵責。佛陀說：受用世人的信施供養，絕不應當懈怠放逸；在漫漫長夜的三個時段之中（初夜、中夜、後夜），兩個時段之中應當坐禪、誦經、經行；僅僅以其中一個時段（中夜），用來睡眠調養安歇氣息；這才稱作合乎佛法的睡臥之法。《摩訶僧祇律》說：睡臥應當效法獅子獸王的吉祥右臥法。絕不得貪睡直至日出東方，應當在後夜黎明時分就必須起身，端身正坐思惟自己的行門道業。


【645-0004】資持記/15e_下三#56
【原文】如法，即右脇臥。指三十五者，彼云：應如師子獸王順身臥，若右脇有癰瘡，無罪，不者越威儀。《增一》。手按，彼因外道抽除床攊，故制。〔攊音曆，今謂床桄〕。《十誦》。制晝臥者，有病應開。喜眠令經行者，除昏思故。《善見》，初制繫想。三寶、戒、施、天，為六念。
【譯文】合乎佛法的如法臥姿，就是必須保持右脇著地而臥。所指的第三十五卷，彼律文中說：應當如獸王獅子般順著身體右脇而臥，如果右脇長了癰疽瘡痛，開許左臥無罪，若非如此則違越了威儀之戒。引《增一阿含經》。用手按摸檢視床具，彼處是因為外道曾故意抽掉床板的橫木床桄，想要陷害僧人摔倒，所以佛制定此防護規範。（「攊」字讀作曆，現在俗稱床桄。）引《十誦律》。戒律禁止在白天躺臥，若有疾病則應當開許。對貪嗜睡眠者命令他去經行，是為了消除昏沉睡眠的思緒。引《善見律》，首先規定應當繫念正法。心念三寶（佛、法、僧）、戒法、布施、諸天，合稱為「六念」法門。

【645-0005】05_拾毗尼義鈔/02b_卷上之二#2
【原文】四波羅夷
【譯文】四波羅夷——婬、盜、殺、大妄語四種極重之罪。犯此四者，如人斷頭，不可復活，永棄於佛法之外，不通懺悔。
