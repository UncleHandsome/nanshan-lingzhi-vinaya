# 校閱材料　第995檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【995-0001】資持記/04a_上三#36
【原文】遠行返道死等緣也。又下，約法異。或下，約德闕。故下，總結三義。十具各請，故云二對。請二師法，標示中。彼論但有請十戒闍梨法。非巧勝者，彼云：大德憶念！我某甲從大德乞出家，願大德度我出家，憐愍我，慈愍故。例通者，和尚一法，兼請二師，但改名字故。
【譯文】例如戒師遠行、還俗反道、死亡等因緣。從「又」字以下，是就傳承戒法的法義差異來解釋。從「或」字以下，是就戒德有所欠缺來解釋。從「故」字以下，總體總結上述三種義理。受十戒與受具足戒各自迎請，所以說是「兩度面對面迎請」。在迎請羯磨師與教授師（二師）的法式中，於標題指示處，那部論典只有迎請十戒阿闍梨的法式。所謂「非巧妙超勝」，彼論說：大德憶念！我某甲從大德乞求出家，願大德度我出家，憐愍我故，慈愍故。所謂「例皆通融」，是因為和尚這一套法式，可以通兼迎請兩位阿闍梨，只要更改請詞中的稱呼名目即可。

【995-0002】資持記/04a_上三#37
【原文】請羯磨中，初具儀。二教示。三正說。教授法中。分三同上。後請七證，立請中，初標定。以下，示義。言非獨者，《疏》云據成羯磨，合眾齊功，豈獨三師偏受其賜。《十誦》正則者，即上引云：一一禮僧已，然後請之。驗知非局，猶非明文，故云理例。則下，推益。斥世中，初正斥。若下，顯功等。可下，令準請。
【譯文】在迎請羯磨阿闍梨時，首先具足威儀。第二步由旁人教導指示。第三步由受者正式宣說請詞。在迎請教授阿闍梨的法式中，分為三步同上面一樣。其後迎請七位尊證師，在確立迎請的法式中，首先確立規定。從「以」字以下，說明其中的義理。所謂「非獨」，《業疏》說：就成就羯磨這件事來說，是大眾齊心合力之功，哪裡只是三師單獨承受此一殊榮恩賜。《十誦律》的正式法則，就是上面所引用的內容：一一禮拜僧眾之後，然後才迎請。這證明了並非局限於三師，但因律藏尚無明文，所以說是「理例應當如此」。從「則」字以下，推崇其利益功德。在斥責世俗做法的文段中，首先正式斥責。從「若」字以下，顯發尊證師與三師功德齊等。從「可」字以下，令人依照此法迎請。

【995-0003】資持記/04a_上三#38
【原文】亦應具儀至七師前總請。旁人教云：以羯磨法，非是獨秉，必須此人證無錯謬；若論發戒，功與三師齊德，故須請之。法中，但改尊證，或云七證為別。必下，遮濫。七證之外，不煩盡請。料簡十師，弟子知中，初引示。此即四句中一句，如〈足數〉具引。如下，準判。具知者，即上三種。
【譯文】也應當具備威儀走到七位尊證師面前總體迎請。旁人應當教導說：因為羯磨戒法不是單獨一人所能主持，必須藉由這些尊證師證明大眾作法沒有差錯謬誤；若論及發起戒體，尊證師的功德與三師是平起平坐的，所以必須迎請。請詞的法式中，只需改稱「尊證」、或者稱「七證」來作分別。從「必」字以下，遮止盲目濫請。七位尊證師之外的大眾，不必煩瑣地全部去迎請。在審查挑選十位戒師的文段中，關於弟子知曉戒師情況，首先引述律文說明。這就是四句料簡中的一句，如同〈足數篇〉中所具體引用的。從「如」字以下，依照準則判定。所謂「完全知曉」，就是指上述的三種知情條件。

【995-0004】資持記/04a_上三#39
【原文】餘下，例準。互知中，初約二師。所牒者，羯磨緣中牒和尚故。若下，次明十師。不共住者，不入羯磨僧中。此語簡絕一切犯重之人，故云知何不該。該，猶通也。決犯中，初示文缺。準下，義判。十師相知，局約四重；白停僧殘，得預數故。弟子知師，則通諸篇，故云乃至等。知下，責強受。
【譯文】從「餘」字以下，按例比照準則。在十師互相知曉的文段中，首先就和尚與羯磨二師而言。所謂「所牒唱」，是因為羯磨受戒文中需要牒唱和尚的名號。從「若」字以下，接著說明十位戒師整體。所謂「不共住」，就是不准進入羯磨僧團之中。這句話是絕對排除了一切犯重罪破戒的人，所以說「知曉又有什麼不涵蓋在內」。「該」就是通括、涵蓋的意思。在決斷所犯輕重的文段中，首先說明律文有所欠缺。從「準」字以下，依循法義來作判定。十師彼此相互知曉，嚴格局限於犯四波羅夷重罪；至於自白停留在僧殘罪位的人，仍然可以算入羯磨僧數之中。然而弟子知曉戒師破戒，則通於各篇大小戒律，所以說「乃至」等等。從「知」字以下，責備明知師有罪卻強行依其受戒。

【995-0005】資持記/04a_上三#40
【原文】既下，誡揀擇。文下，律云：彼不選擇人受依止，而師破戒見等，佛言：自今已去，不得不選擇師受依止。〔準明和尚。〕階漸中，初通指。準〈增五〉中，列二十六箇五句，今略引之：有五法不應授人大戒〔無戒、無定、無慧、無解脫、無知見，又云：復有五法應授人大戒，即反上五句，下諸五句皆爾。
【譯文】從「既」字以下，誡勉受者應當審慎挑選。從「文」字以下，律中說：如果有人不審慎挑選對象就受其依止，而戒師本身破戒、破見等，佛陀說：從今以後，不得隨意不挑選戒師就接受依止。（這標準可以比照說明和尚。）在德行階位相承漸次的文段中，首先通泛指引。依照〈增五法〉中所列出的二十六組五個條件，現在簡略引述：有五種條件的人不應當給人授具足戒（自己無戒、無定、無慧、無解脫、無解脫知見；律文又說：又有五種條件的人應當給人授具足戒，就是反過來具備上述五項，以下各組五個條件皆是如此。
