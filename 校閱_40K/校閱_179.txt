# 校閱材料　第179檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【179-0019】02_戒疏/17a_卷四上之二#49
【原文】【疏】凡物有限，事局彼此。情通則彼為我有，意隔則事論進不。然知他得住處，意不籌量，輙於中間強敷臥具，共相逼斥，非出家之儀，故制。
【譯文】【疏文】凡是空間物品皆有局限，事理上自然界分彼此。若人情相通，別人的地方亦可通融共用；若心意隔閡，事情便要分清是否准許進入。然而有人明知別的比丘已先取得住處，心裡毫不思量顧及，擅自硬在他人床鋪之間強行鋪設自己的臥具，彼此互相推擠排擠，這不是出家人的威儀體統，因此制定此戒。

【179-0020】02_戒疏/17a_卷四上之二#50
【原文】【記】十六，制意中。初明物有所主。「情」下，明人心通塞。可者與之，故「進」；不可者拒之，故「否」。「然」下，正敘制意。「斥」，即訓逐。
【譯文】【記文】第十六條制戒本意中。首先說明空間資具各有其歸屬主體。「人情」以下，說明人心溝通的通達與閉塞。可以通融者便給予留宿，所以說是「進」；不可以者則加以拒絕，所以說是「否」。「然而」以下，正式敘述制戒由來。「逼斥」的「斥」，訓解為驅逐排擠。

【179-0028】02_戒疏/17a_卷四上之二#58
【原文】【疏】「作是因緣非餘」者，非餘不犯。將不犯以望犯，不犯是犯義「餘」。但以不依不犯，故相逼惱，非是威儀，何得不犯？

【179-0029】02_戒疏/17a_卷四上之二#59
【原文】【記】釋非餘中。「餘」即是外。不犯在於犯外，即「非不犯」，顯是正犯。初牒示。「將」下，明「餘」義。「但」下，合文釋。
【譯文】【記文】解釋「非餘」的經文。「餘」就是在此之外。不犯的情形處於犯戒條件之外，所謂「並非不犯之餘由」，正顯明這屬於純正的違犯。首先提起標明。「把不犯」以下，闡明「餘」的意義。「只因」以下，結合文義進行解釋。

【179-0069】02_戒疏/17a_卷四上之二#99
【原文】【記】敘誡中。初通敘聖凡心異。「是」下，別示機教不同，大分二別。初明非情，「掘」、「壞」二戒，還存護命。「後」下，次明有情，則有四戒：一、殺人，二、殺畜，三、用蟲水，四、飲蟲水。「深」下，歎教主。「如《多論》」者，彼云：「此殺生戒，凡有四戒，此最先結；既不得用蟲水，便取飲之；由制不得，便故斷畜命；既制不得，便奪人命。」由善知機，故彰「聖」號。「今」下，傷末學。既號「道人」，不置漉具，反無慈念，則非有道，故云「未通」。下指《鈔》者，彼云「《僧祇》：『蟲細者三重漉，猶有者，捨去。若用水者，日日諦視，無蟲便用。』《五分》：『蟲者，漉囊所得，肉眼所見。無漉囊不得行半由旬』」等。又《二衣》中云：「物雖輕小，所為極大，出家慈濟，厥意在此。今上品高行，尚飲用蟲水，況諸不肖，焉可言哉？」
【譯文】【記文】敘述警誡教導中。首先通論聖人與凡夫心志的懸殊。「因此」以下，分別開示對應根機所施設的教法不同，大體分為兩類。首先說明針對無情物，「掘地」與「損壞生草」這兩條戒，本質上還是為了保護微細寄居的生命。「其後」以下，接著說明對待有情眾生，共有四條相關戒律：第一殺害人類，第二殺害牲畜，第三使用有蟲之水，第四飲用有蟲之水。「能如此洞見」以下，由衷讚歎制教之主佛陀。「如同《薩婆多論》」所言，論中說：「防護殺生的戒律共有四條，這一條是最先制立的；既然不准將有蟲之水拿來和泥等作務，比丘便直接取來飲用；因為制戒不許取飲，比丘便轉而故意殺死大牲畜；既然殺牲畜被制止，便進而有犯奪人性命者。」正因為佛陀善於洞悉根機之起伏演變，所以顯彰其「大聖」之尊號。「現今」以下，痛心感傷末世後學的懈怠。既然自號為「修道之人」，身邊卻不配備濾水袋，反倒缺乏一絲慈悲憐憫之念，這便根本不叫修道，所以說「未見其通」。下文指引《事鈔》處，《事鈔》說「《僧祇律》記載：『若是細小的蟲子，須用三重布濾水囊過濾；如果濾過後仍有微蟲，便須捨棄此水不用。若要用水，每天都要極仔細地檢視，確認無蟲方可用。』《五分律》說：『所謂微蟲，是指濾水囊所能濾出、肉眼所能看見的蟲子。出家人若身邊無濾水囊，連半由旬的路途都不可行走』」等等。又在《二衣篇》中說道：「過濾所用的器物雖然輕微短小，但其所成就的慈悲功德極其廣大，出家人行慈濟之道，其心意關鍵正落實於此處。如今即便是上品高德行者，尚且常有誤飲誤用含蟲之水的過失，何況是那些下劣不肖之人，又怎麼說得盡呢？」
