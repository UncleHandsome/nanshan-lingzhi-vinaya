# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【99-0001】02_戒疏/04b_卷一下之二#153
【原文】【記】正明體中，初科，昔解。「止持作犯」，局事無法，與今少異。餘則大同。「所以」下，自釋不通之意。以律制法，正在進修；止持離過，非進修故。又事通善惡，故該二持；法唯是善，故唯局作。
【譯文】【記文】在正式說明本體之中，此為初科，乃是往昔的解釋。「止持作犯」局限於事相而不通於法軌，這點與當前的觀點稍有不同，其餘部分則大致相同。「所以」字以下，是古人自行解釋不通法軌的緣由。因為律中所制的法軌，主旨正在於精進修持；止持只是遠離過失，並非精進修作之故。又因為事相通於善與惡，所以能包含二持；法軌則純粹是善法，所以唯獨局限在作持。

【99-0002】02_戒疏/04b_卷一下之二#154
【原文】【疏】問：「如上立義，止持唯事，不通法者，如五邪、七非，並非正法，若作有違，義須止約。此法與事殺、盜不殊，有何等故不在止攝？如昔解止，但對事明，於義有乖。今不同彼。無論事、法，聖制止作，則通持犯。下以位分，體狀無別。」
【譯文】【疏文】問：「如果按照上面所立的義理，止持唯獨局限於事相，而不通於法軌，那麼例如以五種邪命維生、或者犯下七種非法羯磨（七非），這些全都不符合正法，如果去造作便屬違犯，按理必須加以抑止約束。這類非法與具體事相上的殺生、偷盜並無二致，有什麼緣故不能被收攝在止持之中呢？如同古人解釋止持只對照事相來說明，在義理上顯然有所乖違。如今我的主張與彼不同：不論是事相還是法軌，只要是聖教所制定的止與作，全都通於持犯四行。下文雖然以階位作劃分，但它們作為持犯體狀的本質並無差別。」

【99-0003】02_戒疏/04b_卷一下之二#155
【原文】【記】今義中。初牒彼解；「如五」下，舉法比難；「如昔」下，斥非立義。此謂事法既有止作，則通四行。「下以位分」者，即後四門並舉事法，對可學、不可學以明體狀。方顯止門與作齊等，故云「無別」。則異古師單複偏對也。
【譯文】【記文】當前正義之中。最初重提對方的解釋；「如五」以下，舉出非法之例來作對比詰難；「如昔」以下，駁斥其謬誤並確立今義。這是說事相與法軌既然都存在著止與作的規範，自然通貫於持犯四行。「下以位分」，是指後面的四門都同時舉出事與法，對照著「可學」與「不可學」來說明持犯體狀。如此方能彰顯止門與作門是完全平等的，所以說「無別」。這就與古德只偏頗地以單一事相或雙重事法來相對待的情況不同了。

【99-0019】02_戒疏/04b_卷一下之二#171
【原文】【記】答：「但由持犯，必對境緣。如犯淫戒，須託三境。如持殺戒，亦對三趣。至論持犯，自指淫殺。《論》云『託境』，豈不思之？又境是局狹，收緣不盡。如諸戒列緣，境唯一種；若言淫事，一切皆收。又復於一男境，自發五十六戒。若但言『境』，境即通漫；今言『事』者，即指別戒。」
【譯文】【記文】答：「那只是因為持戒與犯戒，必定要面對境界因緣。例如違犯淫戒，必須託借三種淫境；例如持守殺戒，也是面對三種有情趣類。但真要論及持犯本體，自然是指淫行與殺生這些事業本身。《論》中說『託境』，難道你不深入思考其中的涵義嗎？再者，『境』的範圍過於狹隘，無法收攝所有的因緣。例如諸戒在列舉犯緣時，境通常只有一種；但若說到『淫事』，則所有相關因緣皆能收括在內。再者，單單面對一個男人的境界，自身就能生起五十六種戒相。如果只稱作『境』，境界就顯得籠統寬泛；如今稱作『事』，就是具體指涉那一條個別的戒法。」

【99-0021】02_戒疏/04b_卷一下之二#173
【原文】【疏】一者，可學事制止。何者是邪？如婬通三境，盜分四主，既是惡事，不可妄行，故須止也。
【譯文】【疏文】第一種，是對於可學的事相加以制止（可學事制止）。這是指什麼呢？例如淫欲通於三種對象境界，偷盜則分別涉及四種財主，這些既然是惡事，就不可任意妄為，所以必須加以止息。

【99-0022】02_戒疏/04b_卷一下之二#174
【原文】【記】可學事中。「三境」者，人、非人、畜。非人攝四，天、修、鬼、獄。故知此三，總收六趣。三皆犯重，故云「通」也。言「四主」者，三趣之外，加三寶境。四犯各別，故云「分」也。
【譯文】【記文】在可學事之中。「三境」，是指人、非人、畜生。非人包攝了四種：天人、阿修羅、鬼神、地獄。因此可知這三境總括收羅了六道輪迴。對這三種境界行淫皆犯根本重罪，所以說「通」。所說的「四主」，是指三趣之外，再加上三寶境界。對這四類主體行盜所犯各別，所以說「分」。

【99-0023】02_戒疏/04b_卷一下之二#175
【原文】【疏】二者，可學法制止。如五邪、七非，體乖聖教，明了其相，必不得行，故同止也。
【譯文】【疏文】第二種，是對於可學的法軌加以制止（可學法制止）。例如以五種邪命維生、或者犯下七種非法羯磨，其本質完全違背聖教，既然清楚明白了其過咎之相，就斷然不得去遵行造作，所以同樣屬於止持。

【99-0024】02_戒疏/04c_卷一下之二#1
【原文】【記】法中。「五邪」，即調達五法：一、乞食；二、糞衣；三、露坐；四、不食酥鹽；五、不食魚肉。五皆盡形，一制無開，故名「邪」也。「七非」者，謂所作羯磨違律制也：一、非法非毗尼；二、非法別眾；三、非法和合；四、如法別眾；五、法相似別眾；六、法相似和合；七、呵不止。廣如《業疏》。此二惡法，不殊淫盜，故云「同止」。
【譯文】【記文】在法規方面。所謂「五種邪法」，就是提婆達多所立的五項規定：第一、常行乞食；第二、常穿糞掃衣；第三、常露天而坐；第四、終身不吃酥油與鹽；第五、終身不吃魚和肉。這五條都要求終身奉行，一律強制遵守且絕無開許，所以稱為「邪法」。所謂「七種非法僧事（七非）」，是指僧團所舉行的羯磨會議違反了戒律規定：第一、作法不合佛法也不合毗尼；第二、作法不合法且僧眾未全體出席（非法別眾）；第三、作法不合法且強行假和合（非法和合）；第四、作法合乎律法但僧眾未全體出席（如法別眾）；第五、作法看似合法但僧眾未全體出席（法相似別眾）；第六、作法看似合法且強行假和合（法相似和合）；第七、有人抗議制止卻仍強行表決（呵不止）。詳細內容如同《業疏》所載。這兩種惡法，罪過與淫戒、盜戒沒有差別，所以疏文說同樣屬於止持（同止）。

【99-0025】02_戒疏/04c_卷一下之二#2
【原文】【疏】言不可學事者，由心迷倒，隨境不了，於殺盜境，疑慮不分，望非犯位，故是「止持」。而心不了，是「不可學」。
【譯文】【疏文】所謂不可修學的事相，是指心念產生迷亂顛倒，面對具體境界時無法明辨，在殺戒、盜戒的境界上，生起疑惑而無法辨明；但就沒有真正違犯根本戒而言，仍屬於「止持」。只是因為內心迷惑無法明了，所以稱為「不可學」。

【99-0026】02_戒疏/04c_卷一下之二#3
【原文】【記】不可學中。約迷忘者，謂臨事造境忽起之迷，非可預學令知，故言「不可」。
【譯文】【記文】在不可學的範疇中。若就迷亂遺忘的角度來說，是指面臨事情、身處境遇時突然產生的迷糊，並非事前修學就能預防得知的，所以稱為「不可學」。

【99-0027】02_戒疏/04c_卷一下之二#4
【原文】【疏】二者，不可學法。如四依、五邪，七非、三法，是非相濫，忘思不了，雖未依行，故名「止持」。非學所知，名「不可學」。
【譯文】【疏文】第二種，是指不可修學的法規。例如四聖種（四依）與五邪法、七種非法僧事與三種羯磨法，正確與錯誤混雜在一起，由於一時遺忘思索而無法辨識，雖然當下並未照著作，所以稱為「止持」。但這不是透過常規修學就能事先察覺預防的，因此稱為「不可學」。

【99-0028】02_戒疏/04c_卷一下之二#5
【原文】【記】法中。云「四依」者，以調達倚傍四依，而立五法，邪正相濫，容有迷昧。「三法」者，即單白、白二、白四，或可心念、對首、眾法。
【譯文】【記文】在法規方面。提及「四聖種（四依）」的原因，是因為提婆達多依附著四依法的名目，另外創立了五種邪法，正法與邪法混雜難辨，極容易使人迷惑。「三種羯磨法（三法）」，是指單白羯磨、白二羯磨、白四羯磨；或者也可指個人心念羯磨、面對面二人羯磨、僧團眾人羯磨。

【99-0029】02_戒疏/04c_卷一下之二#6
【原文】【疏】問：「如此生迷，與愚教者，復有何異？」
【譯文】【疏文】有人問：「這種當下產生的迷惘，和那些從不修學戒律的愚蠢之徒，又有什麼區別呢？」

【99-0030】02_戒疏/04c_卷一下之二#7
【原文】【疏】答：「愚教之徒，生來不學，故隨所壞，並結無知。今此不爾，素並明練，忽然迷忘，非學所知，故於教相，無罪可結。」
【譯文】【疏文】回答：「不學戒教的愚人，向來就不肯學習，所以隨著他所毀犯的戒相，都要判定結下不學無知罪。現在所說的情形並非如此，這個人平素對戒律極為精明熟練，只是臨時忽然迷惘遺忘，這不是光靠修學就能完全避免的，所以就戒律的教相來說，沒有罪名可以判定。」

【99-0031】02_戒疏/04c_卷一下之二#8
【原文】【記】問答分示愚迷兩相，在文可解。
【譯文】【記文】這段問答分別指出了愚昧與突發迷惘這兩種相狀，文意很清楚可以理解。

【99-0032】02_戒疏/04c_卷一下之二#9
【原文】【疏】二、就止持，對制門可學事中，制必作者，如衣鉢體量也。言「可學法」者，制必須作，如三羯磨等。
【譯文】【疏文】第二、就止持而言，在對應強制制定（制門）的可修學事相中，屬於強制必須實行的，例如衣鉢的材質與規格尺寸。所謂「可修學的法規」，是指強制規定必須舉行的，例如三種羯磨法等。

【99-0033】02_戒疏/04c_卷一下之二#10
【原文】【記】制作門中。今明止持，不宜論作。為欲顯示雙持犯義，如後問答。「衣」以布絹為體，長五廣三等為量；「鉢」以泥鐵為體，三斗斗半為量。「三羯磨」中，說、恣二法，必須常行，餘對別緣，有必依作。
【譯文】【記文】在制定門的範圍內。現在既然在說明止持，原本不該討論「有所作爲」。但為了揭示「止作二持兼具、違犯亦兼具」的深意，正如後面的問答所言。「衣」是以布或絹為實質材料，長五肘、寬三肘等為尺寸標準；「鉢」則以瓦泥或鐵為實質材料，容量以三斗至一斗半為標準。「三種羯磨法」中，半月說戒與解夏自恣這兩項，是僧團必須恆常舉行的；其餘的羯磨法則是針對特定的因緣，一旦遇到就必須依律舉行。
