# 校閱材料　第1701檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1701-0001】03_業疏/10a_卷二之四#120
【原文】次釋標中初科。「計是能授」者，以今立法，令師解故；然文中列相，但約所受，故隨列者，示無他意也。三歸、八戒同標所受，例此通之。十戒已後，始標能授，亦是隨列，無別所以
【譯文】接著解釋標題中的第一科。「按理應當屬於能授之法」，是因為如今制定儀軌法則，是為了讓戒師明白理解的緣故；然而文中列舉行相時，只就受戒者所受的內容而言，所以說「隨順標列」，表示並沒有其他特殊深意。三歸、八戒同樣標示為所受，皆可照此例貫通理解。十戒以後，才開始標示能授，這也只是隨順標列，並沒有其他特別的原因。

【1701-0002】03_業疏/10a_卷二之四#121
【原文】文列經施不及持戒者，明戒德高勝，即初門義也
【譯文】文中列舉經典所說布施不如持戒之處，是為了顯明戒德高尚殊勝，這就是第一門的意涵。

【1701-0003】03_業疏/10a_卷二之四#122
【原文】釋注標指中，注引經云，亦《善生》文
【譯文】在解釋注文的標示指引中，注文所引的經文，也是出自《善生經》（即《優婆塞戒經》）。

【1701-0004】03_業疏/10a_卷二之四#123
【原文】所以然者，初受戒時，已行三施，盡眾生界，故財有量，不及此也。盡形不盜者，已施法界有情之財；言不殺者，已施法界有情無畏；即用戒法行己化他，即名法施，徧眾生界。財為局狹集散之法，能開煩惑惱害之門，戒法清澄，故絕斯事
【譯文】之所以如此，是因為剛受戒時，就已經行持了三種布施，並且窮盡整個眾生界，所以財物布施數量有限，比不上受持戒法。盡形壽不偷盜，就是已經將財物布施給法界一切有情；說到不殺生，就是已經布施給法界一切有情無所畏懼；進而以戒法端正己行、化導他人，這就稱為法布施，普遍利益一切眾生界。財施是狹隘且涉及積聚與散耗的有為法，容易開啟煩惱惑業與惱害他人的門徑；戒法則清淨澄清，所以斷絕了這些過失。

【1701-0005】03_業疏/10a_卷二之四#124
【原文】牒釋中初科，初總示。以初受時立誓斷惡，徧生境故，財、法、無畏是為三施。「盡下」二別列。不盜不妄取，即是施財；不殺無侵惱，即施無畏；此二自行，令他倣之，即法施也。財施濟彼困窮，無畏令他安樂，此二即慈悲也；法施使彼開悟，即智慧也。三者既備，其勝可知。「財下」通結。初句示財施局狹，一不具三施，二不徧生境。「集下」明財施生過，集則不免貪求，散則寧無取捨，得者則喜，不得則嗔，能開煩惱，故不及戒
【譯文】在提撕解釋的第一科中，首先總體開示。因為剛受戒時立誓斷惡，遍及一切眾生境的緣故，財施、法施、無畏施便稱為三施。自「盡形壽」以下，第二是分別列出。不偷盜、不妄取，就是布施財物；不殺生、不侵害惱亂，就是布施無畏；這兩種戒行自己切實奉行，並讓他人效法，就是法布施。財施能救濟對方的困乏貧窮，無畏施能令他人安穩快樂，這兩種施就是慈悲；法施能使他人啟發悟境，這就是智慧。三者既然都具備，戒德的殊勝便可想而知。自「財為」以下，是通盤總結。第一句顯示財施的局限狹隘，一是不能具足三施，二是不能遍及一切眾生境。自「集散」以下，說明財施會產生過患：積聚時不免貪求，散發布施時豈能沒有分別取捨？得到的人就歡喜，得不到的人就瞋恨，容易開啟煩惱，所以遠遠比不上戒法。

【1701-0006】03_業疏/10a_卷二之四#125
【原文】又云由戒故施淨者，智論云：若不持戒得財施者，多貪不淨，以利求利，惡求、多求，故使來世受不淨果，如牛、羊、猪、狗，衣食麤惡。若持戒者，既絕惡求，清淨行絕，乃至佛果。故云六波羅蜜在心不在事等
【譯文】又說由於持戒的緣故布施才得清淨，《大智度論》說：如果不持戒而獲得財物行布施，往往多有貪著不淨，以利益追求利益，以邪惡不正的方式索求，或者貪得無厭地多求，因而導致來世遭受不淨的果報，如同牛、羊、豬、狗等畜生，所獲衣食粗劣惡濁。如果是持戒的人，既然斷絕了邪惡的求取，清淨行持超絕卓然，乃至能圓滿佛果。所以說六波羅蜜貴在發心而不在外在事相等等。

【1701-0007】03_業疏/10a_卷二之四#126
【原文】次科引論。前明破戒行施之損，以利求利謂販賣治生，惡求謂邪利活命，多求即貪婪無厭。惡因惡果，報應必然。文列牛羊等，且舉餘報。「若下次」明持戒行施之益。清淨則離上諸過，佛果則反上惡果。故下引證，還即論文。施、戒、忍、進、禪、智為六波羅蜜，翻「到彼岸」，修此六法能至佛果故。若心不淨，雖行六事，非波羅蜜，故云「在心不在事」。然此為破垢心之人，非謂廢除事行。今人不修戒施，妄以此語文飾己非，一何謬哉
【譯文】次一科是引論證成。前半段說明破戒行施的損害，「以利求利」是指經商販賣以謀生，「惡求」是指依賴邪命不正之利生活，「多求」就是貪得無厭。造惡因招致惡果，因果報應是必然的。文中列舉牛羊等畜生，只是姑且列舉餘報。自「若持戒者」以下，說明持戒行施的利益。清淨就能遠離上述種種過患，成就佛果則與上述惡果相反。所以底下引文為證，依舊是論中的文字。布施、持戒、忍辱、精進、禪定、智慧稱為六波羅蜜，意譯為「到彼岸」，因為修習這六種法門能達到佛果的緣故。如果發心不清淨，縱然行持這六件事，也不能稱為波羅蜜，所以說「在心不在事」。然而這是為了破除內心垢染之人的執著，並非說要廢除外在的事相行持。現代人不修持戒律與布施，妄自拿這句話來掩飾自己的過錯，何其荒謬啊！

【1701-0008】03_業疏/10a_卷二之四#127
【原文】二、當於受前問（下至）應隨為受來，簡人相即義門第二也
【譯文】第二、自「當於受前問」以下至「應隨為受」，甄別領受者資相的內容，就是第二個義門。

【1701-0009】03_業疏/10a_卷二之四#128
【原文】文列善生簡人中，還約性重者為問也。故彼經中問戒相者，以法行務意存始終，不取受具致有隨缺，觀其志力，察其智愚，量功進法，不徒虗受。故文云：雖隨言能，當須久處，六月供養出家智者，審知可教，待限滿已，和僧為受。由能所知量，願行齊具，依法而受，不負眾生。目驗不堪，強令受戒，致使毀汙，二俱沈溺，可謂虗妄，善惡其蹤，叵追誡之哉
【譯文】文中列舉《善生經》甄別人選的內容中，也是就性罪中極重者來發問。因此該經中審問戒相，是因為修持戒法務必貫徹始終，不能隨便讓人具足受戒以致後續產生隨行毀缺，必須觀察其心志毅力，審察其智慧愚昧，衡量其功行再進一步授法，不讓他徒然虛妄受戒。所以經文說：受戒者雖然口中答稱「能持」，仍應與其長久共處，讓他供養出家有智慧之師長達六個月，審查確認其堪受教化，等待期限屆滿後，僧團和合為其授戒。由於能授者與所受者皆知自量，誓願與實行皆悉具備，依照正法而領受，才不致辜負眾生。如果親眼檢驗已知其無法堪受，卻勉強令其受戒，導致其毀犯玷污戒體，雙方都將沉淪墮落，這可謂善惡夾雜而虛妄不實，毫無真實功德善跡可尋，應當戒慎警惕啊！
