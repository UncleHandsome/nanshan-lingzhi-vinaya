# 校閱材料　第1439檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1439-0001】04_比丘尼鈔/03b_卷中之上#9
【原文】第六致拜和南者出要律儀云和南者恭敬也聲論云槃那寐者此翻為禮智度論云禮有三法一口禮二屈膝三頭至地是為上禮又有三禮下者揖中者跪上者稽首菩薩禮佛有三品一者悔過品二者隨喜品三者請佛品地持論云當五輪至地作禮阿含經云二肘兩膝及頂名五輪五分云若人多但別禮師總禮餘人而去三千威儀經云繞塔有五一低頭視地二不得蹈蟲三不得左右視四不唾地五不與人語又當念佛法僧恩梵網經云出家人法不向國王禮拜亦不應向父母禮拜五百問事云弟子得禮師塚以報恩故律沙小此彌尼沙彌式叉摩那比丘尼比丘如來及塔如是展轉從下向上乃至大比丘得禮如來及塔五百問事云繞塔不得女眾隨有優婆塞者不犯見論云辭佛法繞佛三帀四方作禮而去合十指爪掌叉手於頂上却行絕不見如來更復作禮迴前而去增一云塔前不得禮餘人十誦云佛塔聲聞塔前自他不得禮五百問事云佛塔前禮比丘犯墮此律云大小便裸身剃髮說法嚼楊枝洗口飯食噉果等皆不應禮五百問事云淨潔鞾鞋履亦得著禮拜僧祇不得如瘂羊不語當相問訊少病少惱安樂否道路不疲苦否寶梁經云破戒比丘受他持戒者恭敬禮拜得八輕法一作愚癡二口瘖瘂三顏貌醜陋四其面側戾見者蚩笑五轉受女身作貧窮婢使六形體羸瘦夭損壽命七人所不敬常有惡名八不值佛世此破戒者乃至大地無涕唾處。
【譯文】第六、致敬行禮與問候（致拜和南）：《出要律儀》說：「和南」的意思就是恭敬。《聲論》說：「槃那寐」，這裡翻譯為「禮」。《大智度論》說：行禮有三種方法：一是口頭致敬，二是屈膝跪拜，三是頭部著地，這是最上等的禮節。又有三種行禮等級：下等是作揖，中等是長跪，上等是稽首磕頭。菩薩禮佛有三種品位：一是懺悔罪過品，二是隨喜功德品，三是請佛住世品。《地持論》說：應當以「五輪」著地來行禮拜。《阿含經》說：雙肘、雙膝以及頭頂，合稱為五輪。《五分律》說：如果人很多，只需單獨禮拜自己的師長，對其餘人總合行一個禮即可離去。《三千威儀經》說：繞塔禮敬有五種規矩：一是低頭注視地面，二是不踩踏蟲蟻，三是不左右張望，四是不吐痰於地，五是不與旁人交談，並應當念念不忘佛、法、僧三寶之深恩。《梵網經》說：出家人的法則，不向世間國王禮拜，也不應當向父母禮拜。《五百問事》說：弟子可以禮拜師長的墓塚，這是為了報答師恩的緣故。律制所列下座至上座順序：沙彌尼、沙彌、式叉摩那、比丘尼、大比丘、如來及佛塔，像這樣輾轉由下層向上層禮敬，乃至大比丘得以禮拜如來及佛塔。《五百問事》說：繞塔時不得讓女眾隨從跟在身後，若有優婆塞在場則不犯戒。《善見律》說：辭別佛陀之法則，應圍繞佛陀右旋三匝，向四方行禮後離去；雙手交叉手指置於頭頂上，緩緩倒退行走，直到完全看不見如來之時，再行禮敬，然後轉身離去。《增一阿含經》說：在佛塔前不得禮拜其他人。《十誦律》說：在佛塔或聲聞阿羅漢塔前，無論自己或他人，皆不得私相禮拜。《五百問事》說：在佛塔前若禮拜比丘，犯墮罪（波逸提）。本律說：大小便溺時、赤身裸體時、剃髮時、說法時、嚼楊枝刷牙時、漱口洗嘴時、進食飯菜時、咀嚼果品時，皆不應向其行禮拜。《五百問事》說：若是乾淨整潔的長靴、鞋履，也可以穿著行禮拜。《僧祇律》說：相遇時不得如同啞巴羊一般不發一語，應當互相問訊慰問：「少病少惱否？安樂平善否？路上奔波疲憊辛苦否？」《寶梁經》說：破戒比丘若是接受持戒清淨者的恭敬禮拜，將獲得八種輕賤惡法報應：一是轉生愚癡無知；二是口舌瘖啞不能說話；三是容貌醜陋不堪；四是面目歪斜不正，見者無不譏笑；五是轉受女身，淪為貧窮婢女受人驅使；六是形體極度羸弱消瘦，夭折短命；七是不受他人尊敬，常背負惡名；八是生逢無佛之世。這種破戒之人，在大地上甚至連一口唾沫大小的地方都無資格分得（片地無分、無其立足容身之處）。
