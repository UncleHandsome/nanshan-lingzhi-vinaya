# 校閱材料　第206檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【206-0001】資持記/15e_下三#21
【原文】親供母者，與登地菩薩齊；人或助檐者，紀曰：吾母也，非他之母；形骸之累，並吾身也；有身必苦，何得以苦勞人；所以身為苦先，幸勿相助。此乃大度，豈比常途；雖教有小違，而理歸大順；酬恩竭力，今古無之。三中，《涅槃》。三寶一體，體無生滅，故皆常住。啟，開也。
【譯文】親自供養母親的人，功德與登地菩薩平等；有時有人要幫忙挑擔，道紀法師說：這是我自己的母親，不是別人的母親；這個形骸軀體的牽累，也全是我自己的身體；只要有身體就必定有勞苦，怎能拿自己的勞苦去勞累別人呢；所以我應當身體力行為母親吃苦在先，希望大家千萬不要幫忙。這乃是菩薩的大度胸懷，豈是尋常凡情所能相比；雖然行跡上對戒律有微小的相違，但在至理上卻契合了至高的大順；竭盡全力報答父母重恩，古往今來罕有人及。第三段中，引《涅槃經》。佛法僧三寶本具一體，法體無生亦無滅，所以全都是常住不滅的。啟，是啟開、開悟的意思。

【206-0002】資持記/15e_下三#22
【原文】七世者，《北遠疏》云：無始皆開，何止七世；但隨世俗，且言七耳；即《梵網》云：六道眾生，皆是我父母；我生生，無不從之受生，是也。《母論》。貧者先法後食，不貧但法，無所乏故。《四分》。愛道求出家，如來不許，阿難代請之詞。
【譯文】所謂七世父母，《北遠疏》說：無始曠劫以來都應該開許，哪裡止於七世；只不過是隨順世俗的言談習慣，姑且說是七世罷了；這正如《梵網經》所說：六道之中的一切眾生，全都是我生生世世的父母；我在每一生受生之時，沒有哪一生不是從他們受生的，就是這個意思。《毘尼母論》。貧窮的父母先給予佛法教化後供給飲食，不貧窮的父母則純以法引導，因為物質上無所匱乏。《四分律》。大愛道瞿曇彌請求出家，如來最初不答應，這是阿難代為祈請時所說的話。

【206-0003】資持記/15e_下三#23
【原文】愛道是佛姨母，佛生七日，摩耶命終，姨母乳養長大。愛道在俗，已證初果，故云況得淨信。是知生育恩大雖百年肩荷，不報須臾；三寶一聞，即酬重德。故唯佛法，可報劬勞；自外供須，終名直養。四中。彼經第一云：佛言：我於過去世時，波羅奈國，有長者子，名慈童女；父喪賣薪，日得兩錢，奉養老母；
【譯文】大愛道是佛陀的姨母，佛陀降生七天後，摩耶夫人命終，全靠這位姨母哺乳撫養長大。愛道在俗家時，就已經證得了初果，所以經文說「更何況她已經獲得了清淨信心」。由此可知生身撫育的恩德至大，即使百年中用肩膀挑擔供養，也報答不了須臾之恩；然而只要令其聽聞三寶法音，便能真正酬報崇高的重德。所以唯有佛法，才能徹底報答父母辛勞的劬勞之恩；除了以佛法救度之外的其他物資供養，終究只能稱為形式上的侍養。第四段中。該經第一卷記載：佛陀說：我在過去世時，在波羅奈國中有一位長者的兒子，名叫慈童女；父親去世後靠賣柴度日，每天賺得兩錢來奉養老母親；

【206-0004】資持記/15e_下三#24
【原文】次得四錢、八錢、十六錢；後欲入海採寶，母即抱捉；子掣手，絕母數根髮，遂入海取寶；還發時，有水陸二道，即從陸道去；乃見有城，紺琉璃色，有四玉女，擎四如意珠，作樂來迎；四萬歲中，受大快樂〔酬上二錢〕；次復前行，見頗梨城，有八玉女，擎珠來迎，八萬歲受樂〔酬上四錢〕；
【譯文】後來賺得四錢、八錢、乃至十六錢；後來他想入海去採寶，母親就上前抱住他阻止；兒子用力摔開手，扯斷了母親的幾根頭髮，於是逕自出海採寶；採寶回程時，有水路與陸路兩條道，他選擇從陸路前進；便看見有一座城堡，呈現紺琉璃色，城中有四位玉女，手捧著四顆如意寶珠，奏樂前來迎接他；他在四萬年中享受了極大的快樂（這是酬償他當初奉養母親二錢的福報）；隨後他又往前走，看見一座頗梨城，有八位玉女手捧寶珠前來迎接，他在那裡享受了八萬年的快樂（這是酬償四錢的福報）；

【206-0005】資持記/15e_下三#25
【原文】復捨遠去，至白銀城，十六玉女，擎珠來迎，十六萬歲受樂〔酬上八錢〕；又復捨去，至黃金城，有三十二玉女，擎珠來迎，三十二萬歲受樂〔酬十六錢〕；又復捨，去遙見鐵城，心生疑怪；遂入鐵城，有一人，頭戴火輪，捨著童女頭上〔酬損母髮〕；
【譯文】他又捨離遠去，走到一座白銀城，十六位玉女手捧寶珠前來迎接，在此享受了十六萬年的快樂（這是酬償八錢的福報）；他又捨離前往，到達一座黃金城，有三十二位玉女手捧寶珠前來迎接，享受了三十二萬年的快樂（這是酬十六錢的福報）；他又捨離離去，遠遠看見一座鐵城，心中生起疑惑驚怪；於是他走入鐵城，只見有一人頭上戴著旋轉的火輪，那人隨即把火輪脫下丟在慈童女頭上（這是酬報他扯斷母親頭髮的罪報）；

【206-0006】資持記/15e_下三#26
【原文】童女問獄卒言：我戴此輪，何時可脫？答言：世間有人，罪福如汝，然後可代。又問：今獄中頗有受罪如我者否？答言：不可稱計，聞已思惟，願一切受苦者，盡集我身；作是念已，鐵輪墮地；獄卒以鐵又打頭，命終，生兜率天。時慈童女者，即我身是；當知父母少作不善，獲大苦報；少作供養，得無量福。
【譯文】童女問獄卒說：我戴著這個火輪，什麼時候才能解脫？獄卒回答說：世間若有人造作的罪業與福報和你完全一樣，到那時才能有人來替代你。童女又問：如今地獄中難道有受罪跟我一樣的人嗎？回答說：多到不可稱數。童女聽了之後深刻思維，發願說：願一切眾生所受的痛苦，全集中在我一人身上！剛發起這個善念，鐵輪立刻掉落在地；獄卒以鐵棒擊打他的頭，他隨即命終，超生到兜率天。那時的慈童女，就是我釋迦牟尼佛的前身；應當知道對父母若做了一點點不善，就會招致巨大的苦報；若做了一點點供養奉事，就能獲得無量的福德。

【206-0007】資持記/15e_下三#27
【原文】〔童女是長者名，非女人也。〕鸚鵡，彼云：過去雪山，有一鸚鵡，父母都盲；時有田主，初種󰝿時，願言：與眾生共食，鸚鵡子，即常於田採取，以供父母；田主按行苗稼，見諸虫鳥，剪󰝿穗處；嗔恚，便設網捕，鸚鵡子言：田主先有好心，何見網捕？且田者如母〔常生長故〕，種子如父〔相繼續故〕，實語如子〔可寶惜故〕；
【譯文】（童女是這位長者之子的名字，並不是指女子。）鸚鵡的公案，彼經說：過去雪山中有一隻鸚鵡，父母雙目失明；當時有一位田地主人，最初播種穀物時發願說：願將這田產與一切眾生共享。這隻小鸚鵡就常常飛到田裡採擷穀物，用來供養父母；田主巡視巡查莊稼，看見許多鳥雀啄食剪斷穀穗的地方；心中惱怒，便設下網羅捕捉，小鸚鵡說：田主你先前發過廣大的好心，為什麼現在反而設網捕捉？況且田地如同母親（能常生長五穀），種子如同父親（世代相承延續），真實的言語如同兒子（誠信可寶貴珍惜）；

【206-0008】資持記/15e_下三#28
【原文】田主如王，擁護由己〔得白在故〕。作是語已，田主歡喜；問言：汝取此󰝿何為？答言：有盲父母，願以奉之。佛言：鸚鵡者，我身是；田主者，舍利弗是；盲父母者，淨飯摩耶是。《增一》兩節，初校量功德。一生補處，即等覺菩薩。準知孝養，德唯降佛。《菩薩戒》云：孝順至道之法；儒書亦謂至德要道。

【譯文】從「若是沒有」以下，接著說明沒有車乘而必須徒步前往求助的狀況。不繞行佛塔等處，是唯恐耽誤時間導致行程延宕的緣故。至於「共同迎接」，是指延請護法檀越一同前往迎接，其道理與前述接引比丘相同。從「假若在路上」以下，接著說明尼僧大眾的情形，彼此相同與差異之處清晰可見。「闍維」在漢語中翻譯為焚燒。這是因為俗人嫌惡屍穢，所以應挑往遠處，不令俗人看見的緣故。從「其餘」以下，最後說明位階在下的沙彌等眾，律文中略過沒有詳載，所以應當比照辦理。在第三段中，首句指陳前面聖者所立的戒制，次句勸勉大眾切實遵循，後兩句則指引詳備的文獻，指的便是《僧祇律》的經文。在「供給物品」這部分的第一科，《五分律》中僅僅開許自行煮食。

【原文】《五百問》亦然，七日一受，更開過中失受，惡觸不受。先淨，謂令淨人火淨。下指《寶梁》，彼云：乞食比丘，或病不能乞食，當自伏心云：我獨無侶，一身出家，法是我伴等。《習禪經》今藏錄不出。二中，《僧祇》，先明九橫，令知看視。前七並食；八懈怠者，不勤調攝故；九無慧，謂執愚失治故。
【譯文】《五百問》的規定也是如此，米糧每七天作一次受法，更進一步開許了過中失受、惡觸以及未經受取而食等過失。所謂「先作清淨」，是指吩咐淨人以火作法使之合律淨潔。文末引指《寶梁經》，該經說道：行乞食的比丘，若是因病不能出外乞食，應當自己降伏其心並自念：我孤身一人毫無伴侶，一身出家，法是我的伴侶等等。《習禪經》在現今的藏經目錄中並未收錄。第二段中，《僧祇律》先指陳九種橫死因緣，讓看護者明白照料的重點。前面七種都與飲食調配相關；第八種是懈怠，指不能精勤調攝身體的緣故；第九種是缺乏智慧，指固執愚見而耽誤了治療調理。

【206-0046】資持記/16a_下四#7
【原文】又下，次明供給。據文有三：初須己物，二己無則僧物，三僧無則乞與。好食與看病者，獎其勤勞，令無退故。又不下，三制推免。《四分》。五德，文引第五，而略上四：一知可食應與；二不惡賤便穢；三懷慈愍，不為衣食；四能經理湯藥。《善見》。為病開餉俗士，不犯污家。
【譯文】從「又」字以下，接著說明物資的供給。根據律文共有三種途徑：第一必須先動用病患自己的財物，第二若是自己沒有就取用僧團的常住物，第三若僧團也沒有則向外托缽乞化給予。將美味的食物供養看護病患的人，是為了犒賞他們的辛勞，讓他們不起退轉的心意。從「又不」以下，第三是禁止推諉卸責。《四分律》提到看護病人的五種功德德行，文中僅引述了第五種，而略去了前四種：第一是深知何種食物適宜而給予；第二是不嫌棄厭惡糞便等污穢；第三是心懷慈悲憐憫，不是為了獲取衣食回報；第四是能善加經理調度湯藥。《善見律》記載，為病患的緣故開許餽贈俗人食物，不犯「污家」的過咎。

【原文】但不得下房，不容看病故。次文。中國本傳，《壇經》所謂別傳是也。日光沒處者，《壇經》云：西方為無常之院，由終歿於天傾之位也；今寺亦有，但方隅不定，不知法故。以下，出別堂所以。今號延壽，豈非相反？專心念法者，由非舊處，無心戀著；但念無常，必思勝法故也。其堂中下，次明設像。
【譯文】只是無論如何都不得安排在下等房舍，因為那裡狹隘簡陋，無法容納看病照料之事的緣故。下一段文字中，天竺本國的傳記，也就是《戒壇圖經》當中所指的別傳便是此意。所謂「太陽落下的地方」，《壇經》說道：西方是設置無常院的地方，這是因為世人最終歸宿於天位傾沒的方位；現在的寺院雖然也有這種設施，但座向方位並不固定，這是因為不懂得法度的緣故。從「以」字以下，說明設立別堂的緣由。如今卻稱為「延壽堂」，豈不是與本意背道而馳？所謂「專心憶念正法」，是因為搬離了原先居住之處，內心便不再貪戀執著；心裡只念著無常迅速，就必然會思求殊勝妙法的緣故。從「在那堂中」以下，接著說明供設佛像的規矩。

【206-0050】資持記/16a_下四#11
【原文】立彌陀者，歸心有處也。然十方淨土，而偏指西方者；繫心一境，想念易成故；西方諸佛，而獨歸彌陀者；誓願弘深，結緣成熟故。是以古今儒釋，靡不留心；況濁世凡愚，煩惱垢重；心猿未鎖，欲馬難調；捨此他求，終無出路；
【譯文】供立阿彌陀佛像，是為了讓病者心靈有所歸向。然而十方世界皆有淨土，卻偏偏指歸西方者，是因為將心念繫縛在單一境相上，觀想憶念比較容易成就的緣故；西方有眾多諸佛，卻唯獨歸投於阿彌陀佛者，是因為其弘深宏大的誓願，與此界眾生的結緣最為深厚成熟的緣故。因此古往今來的儒士與釋子，沒有不對此傾注心力的；更何況處在濁世中的凡夫愚眾，煩惱垢染深重；狂妄的心猿未能上鎖，奔馳的欲馬難以調伏；若是捨棄了這個法門向外尋求，終究沒有解脫出離的道路；
