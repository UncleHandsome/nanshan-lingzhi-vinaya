整體看，這十則白話譯文的掌握度不錯，科判、四句料簡、捨悔次第都譯對了。問題主要集中在**幾處術語的語感**、**兩處句意可能讀反**，以及 **「捨」字譯成「捨棄」易生誤解**。以下逐則列出。

---

## 一、需要修正的地方（句意層面）

### ❗【1002-0010】「故不勞揲」譯文走樣
- 原文：「不揲則舉體有過，過在須捨，**故不勞揲**。」
- 譯文：「…故須全物捨棄，**因此犯後無須再勞煩補貼**。」

問題：
1. 「犯後」二字原文所無，且語意含混（是「犯戒之後」？還是「後戒」？讀者無從判斷）。
2. 這一段是回答上一則「揲已同截，何須捨」的質疑，邏輯是**兩戒對治方式不同**：
 - 不揲 → 過失遍及**舉體** → 必須整件捨出 → **不須（也不能）以「補貼」代替「捨」**（不像過量戒先截後懺即可）。
 - 過量 → **量內無過** → 不須捨 → 只截去量外。

建議譯：「…過失既遍及全體，就必須整件捨出，**所以不必先補貼（補貼並不能免除捨法）**。」

### ❗【1002-0005】「初明因過」因果譯反
- 譯文：「首先說明**引發過失的緣由**。」
- 「因過」是指「（制戒）因由中的過失情形」，即狼藉、不專持等**過失本身**，不是「造成過失的原因」。
- 建議：「首先說明**導致制戒的過失情形**」。

### ❗【1002-0005】「確立定制」是誤植
「其次說明確立**定制**的用意」——「定制」今義為「訂製品」，此處「立制」是**建立規制／制定此戒**。建議改「確立此制的用意」。

### ⚠️【1002-0002】第四項「看諸病人不」增字解經
- 譯文：「察看**弟子是否照護**病患比丘」。
- 原文只有「看諸病人不（否）」，並無「弟子照護」一層；且前段《多論》明言「**佛親看病**，以福勝故」，一般讀法是**佛陀親自看視病人**。
- 建議：「第四、**看視諸病人（是否安好）**」。若要保留「弟子是否照護」的讀法（配合元照「前四撿校徒眾」），至少應加譯註說明兩讀並存。

---

## 二、「捨」不宜譯成「捨棄」（重要）

【1002-0009】「後何須捨」譯「何必還要把坐具**捨棄**」、【1002-0010】「故須全物**捨棄**」——這裡的「捨」是**捨財法（捨與僧／眾多人／一人，僧還本主後再懺）**，不是丟掉。譯成「捨棄」會讓讀者以為作廢丟棄，且與【0007】【0008】已正確譯出的「捨財（捨坐具與僧）」不一致。

建議統一作「**捨（與僧）**」「捨出」「行捨財法」。
【1002-0009】可改：「…補貼完成後就如同裁截超量一樣（都已整治如法），之後為何還須**捨（與僧）** 呢？」

## 三、語感／用詞建議（不影響義理）

| 出處 | 譯文 | 建議 |
|---|---|---|
| 0001 | 《多論》「五種**意圖**」 | 「意圖」今多帶負面語感，宜作「**五種用意／五點理由**」；與0002、0003的「五種利益」也較協調 |
| 0001 | 佛必「**巡房**」 | 「行房」今義極易誤讀，「巡房」仍略含糊，建議「**巡視僧房**」 |
| 0001 | 比丘們都出去了，正好適合入定禪修 | 宜補主語：「（**佛陀**）正好入禪」 |
| 0001 | 看病福德「**最為**殊勝」 | 「福勝」只是「殊勝」，「最」為添字（雖合「看病福田第一」義，仍屬增譯） |
| 0001 | 讓弟子們「**整肅嚴謹**」 | 「肅慎」＝肅敬謹慎，宜作「**恭謹自律／肅敬謹慎**」 |
| 0001 | 「佛親看病」→親自**探視**病人 | 律中「看病」含照護義，宜「**看視照護**」 |
| 0002 | 「世俗的**有為**雜務」 | 記已釋「有為事＝世間俗事」，逕譯「**世間俗務（有為事）**」更清爽 |
| 0002 | 生起歡喜「**向道**」之心 | 「向道」為添字，可刪或加括號 |
| 0004 | 新舊坐具「**隨意拋擲**」一片狼藉 | 原文僅「新故狼藉」，「隨意拋擲」屬增譯，可改「（隨意棄置）雜亂狼藉」 |
| 0005 | 「**以故**」以下 | 記文標記是「『**以**』下」（指「以故揲新」的以），宜作「『以（故揲新）』以下」，與0001「『又』字以下」體例一致 |
| 0005 | 引作「受用**致**虧」 | 記文引的是「受用虧」，引號內宜照記文 |
| 0007 | 「兩條戒都**受持未犯**」 | 「俱持」即二戒俱不犯，作「**兩戒皆持（都不違犯）**」較順 |
| 0010 | 「整件坐具的本體都構成過失，其過失遍及整件」 | 「舉體有過／過在須捨」被拆成兩句同義重述，可精簡為「**整件坐具全體都有過失；過既遍及全體，故須整件捨出**」 |

## 四、譯得正確、可保留的判斷

- **「九十」＝九十單墮（波逸提）**，0006、0009 補「後面的」正確。
- **「作故」＝已以故布貼揲而作**（與「作新＝不揲」相對），0007 的四句料簡完全成立：新／如量→犯前、故／過量→犯後、故／如量→俱持、新／過量→俱犯。括號補「（作故）」很好，建議再加一句譯註說明「作故＝以故布揲新」，讀者才不會誤以為是「作舊坐具」。
- **捨悔次第**（先截量外、單懺提罪；後入僧捨財、再懺不揲）0007、0008 譯得準確，「提罪」補為「波逸提罪」也對。
- 0003「次科／撿校徒眾／滅惡利、生善利」無誤。

## 五、術語統一建議

全篇「揲」出現 **縫綴補貼／縫綴／貼揲／補縫／補貼／縫綴舊布** 六七種說法，建議固定一個主譯語（如「**貼揲故布**」），首次出現加註「揲：以舊布縫貼於新坐具上，令壞色」，後文一律沿用，讀者比較不會迷失。
