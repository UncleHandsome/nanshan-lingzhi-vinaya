# 校閱材料　第1236檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1236-0002】資持記/11c_中四上#55
【原文】言以輕遮重，謂恐臨重境，預防輕過〔共女宿、未具宿、藏衣鉢等。〕；如上三句，無非過輕，故開二難。不開反上者，或雖遮惡，而事重故；如掘、壞、畜、捉、販、貿、背、別、非、殘、足、索、不受等例；或雖過輕，而無開理；如三十中，求畜製造諸衣戒等；
【譯文】所謂「用輕戒來遮防重戒」，是指唯恐面臨重大犯戒境界，因而預先防範細輕的過失（例如與女人同室宿夜、與未受大戒者同室宿夜、故意隱藏他人的衣缽等等）；如上述這三種情況，無一不是情節過失極其輕微，所以才對兩種危難（命難與梵難）給予開許免罪。不予開許的情形則與上述相反：或者是因為雖然只是為了遮惡，但事件本身性質較重；例如掘斷地皮、損壞草木、蓄積多餘衣物、捉持金銀錢寶、販賣交易、違背僧事、另立別眾、非時飲食、食用殘留食物、過飽受食、索求美食、未經手受而飲食等諸多範例；或者是因為雖然過失極輕，但在道理上沒有開許的餘地；例如三十捨墮戒中，貪求蓄積製作各類衣服的戒條；

【1236-0003】資持記/11c_中四上#56
【原文】及九十中，水、擊、怖、半、疑惱、減年、諸衣過量之類；本無命梵陵逼之義，何有開者？請以諸意，細尋注戒，更自攻討。次引論證。開不開意，緩急隨宜，故非一概。緣即緣起，如婬戒須提那；制即本制，如云犯不淨行；重制，後因比丘婬畜，復更前制；如云：乃至共畜生。
【譯文】以及九十單墮戒中，在水中遊戲、以手擊打他人、故意恐嚇、在半月內一再受請、蓄意令人生疑生惱、度不足年歲者受具足戒、穿著各類超過尺度的衣服之類；這些戒條原本就不存在會被生命或梵行所凌逼的緊迫危險，哪裡會有開許免罪的道理呢？請帶著這些考量的意趣，細心查閱每一條戒的注解，進一步深入鑽研探討。接著引用論典來證實。開許與不開許的立意，其寬緩與緊迫是隨順當下的情宜而定，所以不能一概而論。所謂「緣」就是指緣起的事端，例如淫戒起源於須提那；所謂「制」就是指原本的禁制，例如規定犯下不淨之行即成罪；所謂「重制」，是後來因為有比丘與畜生行淫，佛陀又再次更動補充原先的禁制；例如補充說道：「乃至與畜生行淫。」

【1236-0004】資持記/11c_中四上#57
【原文】制必攝護為急，開為時緣名緩。一一戒下，皆具此義。如序廣引。六中，初標緣。謂下，釋相。文舉三戒境差方便，反顯不差，方成究竟。此與第三，似同而別，比之可見。七中，初標緣。若下，反釋四義，以通諸戒，初總示。一下，別釋。前二事隔，後二心止；又初三好心，餘非好心。
【譯文】制戒必定是以收攝守護為緊急優先，開許則是因為順應特殊的時空因緣而顯得寬緩。在每一條戒法之下，都具備了這層義理。正如在序文中廣泛引述的那樣。在第六緣中，首先標示因緣。從「謂下」開始解釋行相。文中舉出了三條戒中境界產生差錯的方便罪，反過來顯明只有在對象境界沒有產生差錯的情況下，才能構成究竟的根本重罪。這一條與第三緣看似相同卻有細微差別，互相對照就能看出。在第七緣中，首先標示因緣。從「若下」開始，反向解釋四種義理，以此貫通所有的戒條，首先是總體開示。從「一下」開始分別解釋。前兩種屬於客觀事態的阻隔，後兩種屬於主觀心念的止息；此外第一與第三種屬於善好之心的止息，其餘則不屬於善心。

【1236-0005】資持記/11c_中四上#58
【原文】二中，緣壞離阻，謂緣差也；疏云：如欲殺盜，往逢異人；或恐有事，或要期未遂〔即此離阻〕，或刀杖毀壞〔即此緣壞〕。言強盛者，疏名境強，如行殺盜，反遭加害等。總結中，初令依用。謂須兩緣，可決犯懺。不下，止濫。第四制意中，初敘須意。浟亦是漫。

【1236-0006】資持記/11c_中四上#59
【原文】境想五句，初句皆重，後四俱輕；又第三一句，有罪則出，無罪則除；輕重有無對文可釋。故下，指所出，上二句示其通具。下二句點其所缺。委辨如後。次門五階。篇聚境想，數過塵沙；五位總收，罄無不盡矣。又復，此五不出二境，初總有情，四開非情；四中，二四竝世法；
【譯文】境想的五句式中，第一句全都是結為重罪，後面的四句全都是結為輕罪；再者第三句這一句，有罪的時候就列出，沒有罪的時候就刪除；其中的輕重與有無，對照文句就能予以解釋。在「故下」這段，是指示出自何處，前兩句顯示這些因緣在整體上是通同具備的。後兩句則是點明其中缺漏不具備的情況。詳細的辨析如同後文所述。下一個門類包含「五個階位」。律典篇聚中的境想，其數量超越塵沙；這五個階位能夠全面總括收攝，毫無遺漏了。再者這五個階位，不超出兩種對象境界：首先是總體的「有情境」，後四個階位則是開展為「非情境」；在後四者之中，第二與第四全都屬於世間之法；

【1236-0007】資持記/11d_中四上#1
【原文】五即制教，第三兼二，對下自明。內報六位，從寬至狹；別對諸戒，簡練精詳，在此而已。人不見之，但云萬境；不知何境，境作何相。況復自有一境通多戒，如情中尼女，非情衣食等；自有一戒而攝多境，如盜及漏失，通情非情等；自有一戒攝一境，如外道食入王宮，牙角，兜羅之類是。
【譯文】第五位是「制教」，第三位兼具前兩位（內報與外事），對照下文自然能夠明瞭。所對之有情果報境（內報）劃分為六個層次，範圍由寬至狹；分別對應各條戒律，其精鍊詳盡之處，完全體現在這裡。常人不理解這層深意，只泛泛地說是「萬境」；卻不知到底指什麼境，境又呈現出什麼樣的相狀。更何況，本來就有一種境通涉多條戒律的情況，例如有情之境中的比丘尼與女俗人，無情之境中的衣物、飲食等；也有一條戒律統攝多種境的情況，例如盜戒與漏失戒，都貫通有情與無情等境；還有一條戒律僅攝取一種特定境的情況，例如接受外道食物、進入王宮、象牙牛角、兜羅綿等戒律便是如此。
