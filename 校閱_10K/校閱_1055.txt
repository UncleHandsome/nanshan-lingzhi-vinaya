# 校閱材料　第1055檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1055-0001】資持記/05e_上四#27
【原文】難事小界。如〈結界〉中已明。難名通漫，略為簡示。受說安恣，竝以王賊水火等八難餘緣為難；增減說恣，即因他界鬪諍，來此為難；三小開者，竝以當界不和為難；緣相各別，不可混濫。〔人多錯用，故此示之。〕五人法中，初科。恐濫行者，往往有人，同上雙差五德故。
【譯文】災難發生時移至小界作法。如同在〈結界篇〉中已經說明。「難」的名稱含義廣泛，略微加以簡別說明。受日、說戒、安居、自恣，都是以國王、盜賊、水火等八難或其餘災緣作為難緣；增減日期的說戒與自恣，則是因為外地僧團爭鬥，波及到此地而成為難緣；三種小界之開許，則全都是因為本地僧團內部不和合而成為難緣；這些因緣的形相各不相同，不可混淆混同。〔世人大多錯誤套用，所以在此處明確指出。〕五人自恣法中，第一科判。擔心有人浮濫行事，往往有人如同前文那樣同時雙重差派兩位五德。

【1055-0002】資持記/05e_上四#28
【原文】次文為二，初明差法，初問和。便下，秉法。前後各差，互為能所故。不下，遮濫。取下，正對自恣。四人法中，初文。標緣作法，可解。四人二人，大同小異。次科，可懺中。自言，即自求也。舉來，約他舉也。不可懺中，初科。偷蘭三品，上品界內大眾懺；
【譯文】下一段文字分為兩部分，首先說明差派之法，先詢問是否和合。「便」字以下，主持羯磨法。因為前後輪流差派，彼此互為能差與所差的緣故。「不」字以下，遮止浮濫。在「取」字以下，正式相對行自恣。四人自恣法中，第一段文字。標示因緣與作法，容易理解。四人之法與兩人之法，大同小異。下一科，在可懺悔的段落中。所謂「自言」，就是指自己主動請求。所謂「舉來」，是指由他人提出檢舉。在不可懺悔的段落中，第一科。偷蘭遮罪分為三品，上品偷蘭遮要在結界之內由大眾僧懺悔；

【1055-0003】資持記/05e_上四#29
【原文】能所六人，方可行故。入說中者，意顯此人已入罪聚故。交即訓俱，僧數不滿，不應前事，故云俱無也。發露中，初準《十誦》。當悔未悔，故且白停，即同發露。犯者既露，餘戒皎然；義須自恣，故云不礙也。《四分》下，準例。以無文故。初舉事。即座上發露開聞說戒。既下，例同。說恣眾法，義無異故。
【譯文】必須能懺與所懺者共有六人，才能成辦。將所犯之罪列入自恣陳說詞中，意在表明此人已入於犯罪聚類之中（不得自言清淨）。「交」字作「俱」字解釋，僧人人數不足，就無法成辦前述的清淨事，所以說是全都沒有。在發露懺悔的段落中，首先依據《十誦律》。應當懺悔卻尚未懺悔，所以暫且宣告停住，這就等同於發露。犯罪者既然已經發露，其餘戒行依舊潔白；在義理上必須准予自恣，所以說「無礙」。《四分律》以下，比照通例。因為原律沒有明文。首先提出具體事相。即在座位上發露，被開許聽聞說戒。既然如此，以下便比照相同原則。說戒與自恣同為僧團大眾法，義理上沒有不同。

【1055-0004】資持記/05e_上四#30
【原文】文中有三：一淨行同者，俱護體故；二眾法同者，皆是攝僧本故；三攝治同者，有犯竝須悔露故。理下，改詞句。應具云：諸大德一心念！今日眾僧自恣，我比丘某甲，犯故漏失僧殘罪；即接文中以眾等語。詳此即是自恣；以身帶犯，不可言淨，須牒入法。
【譯文】文字中包含三點：第一、淨行相同，因為兩者都是在護持清淨戒體的緣故；第二、眾法相同，因為兩者都是攝受僧團的根本法度的緣故；第三、治罪相同，因為有所違犯全都需要懺悔發露的緣故。「理」字以下，更改陳詞語句。應當完整說道：諸大德一心專念！今日大眾僧舉行自恣，我比丘某甲，犯了故心漏失的僧殘罪；隨即接續鈔文中所說「以眾不滿，未得治之；餘者清淨」等語句。詳加推敲這其實就是自恣之法；因為自身帶有過犯，不能自稱清淨，所以必須把過犯宣告列入自恣法中。

【1055-0005】資持記/05e_上四#31
【原文】前云：五人已上舉得出罪，指如四人者；準應白停已，依常自恣，不必改詞；以僧自恣法中，不陳淨故。妄陳中。犯三提者，以三說故；一一人邊，皆結三罪。〔舊云望三比丘各得一提者，非也。以前對一二，不必定故。〕不下，簡異。彼不形言，犯緣缺故。一人法中，初文，前明備具者。由本眾法，無人乃開；
【譯文】前面說過：五人以上檢舉得以出罪，指示如四人法者；依照法理應當宣告暫停之後，依循常規進行自恣，不必更改陳詞；因為在大眾僧自恣法中，本來就不陳述清淨字眼。在虛妄陳白的段落中。犯下三個波逸提罪，是因為說了三次的緣故；在每一位對象面前，都結成三次罪過。〔舊說認為是相對於三位比丘而各自結得一個提罪，是錯誤的。因為前面所面對的人數可能是一人或兩人，並非必定是三人。〕「不」字以下，簡別不同情況。彼處並未用言語表達出來，缺乏了犯罪的相應條件。一人自恣法中，第一段文字，先說明備辦一切用具。由於本來屬於大眾法，在無人之下才得開許；

【1055-0006】資持記/05e_上四#32
【原文】故辦所須，擬同大眾也。若下，作法。可解。次科。約人被事，可不兩相。悔犯露過，並須對人，不可行故；然亦可準座上發露，牒犯自恣，故云依前。〔詞句例前作之。〕又〈說戒篇〉，準《五百問》：向四方僧懺已說戒，亦可例用。雜相中。前明緣法，徑顯行事；其教義差別是非之相，併列于後，故云大明。
【譯文】所以備辦各類所需物品，是為了模擬如同大眾僧同在一般。「若」字以下，正式作法。內容容易理解。下一科。就當事人與所犯罪事來論，無法兩相顧全。因為悔除過犯與發露罪咎，都必須對著他人進行，自己一人無法行辦；然而也可以比照在座位上發露之法，列舉過犯進行自恣，所以說「依前」辦理。〔陳詞語句比照前面來制定。〕又在〈說戒篇〉中，依據《五百問》：對著十方僧眾懺悔後再說戒，這個儀軌也可以比照引用。在雜相的段落中。前面說明因緣與儀軌，是直接顯發實際行事；而教法義理的差別與是非的相狀，全都羅列在後，所以稱為「大明」。

【1055-0007】資持記/05e_上四#33
【原文】初問。答中。僧治足者，上得通下故。一往對論，若約盡辦，必須二十；非謂大眾得作對念，但望人多是可行故。別人未盡者，下不攝上故。七聚為言，須分三位：一唯僧治，有三，夷殘重蘭。二唯別治，有六；中下二蘭，單提提舍重輕二吉。三通僧別者，懺捨墮也。
【譯文】第一個問答。回答之中。大眾僧治罪條件充足，是因為上位可以通達涵蓋下位。這是初步對照討論，如果以完全能承辦一切羯磨來說，必須具足二十人；這不是說大眾可以作對首自恣或心念自恣，而是著眼於人多在法理上必定可行。個別僧人治罪不能窮盡，是因為下位無法涵蓋上位。就七聚罪相而言，必須分為三個位階：第一、唯獨大眾僧能治，有三種，即波羅夷、僧殘、重偷蘭遮。第二、唯獨對首能治，有六種；中下二品偷蘭遮、單波逸提、波羅提提舍尼、重輕二品吉羅。第三、通於大眾與對首者，是懺悔捨墮罪。

【1055-0008】資持記/05e_上四#34
【原文】自恣攝僧，必取行淨；內彰不隱，口述無瑕，故云舉心應僧也。然對念二法，言相雖殊；俱須體淨，方堪陳說。第二問中。以所出不同，恐成偏計故。答中。俱出正法，隨人采用。《四分》云：諸比丘自恣竟說戒，坐久疲極；白佛，因開。文引佛語。三問中。律因六群尼來遮比丘，莫為六群作羯磨；
【譯文】自恣法用以攝受僧團，必定要求行持清淨；內心明白顯露不隱藏，口中所陳述沒有瑕疵，所以說是「舉心契應大眾僧」。然而對首自恣與心念自恣這兩種法，儀軌表相雖然不同；但都必須本體清淨，才堪當陳說自恣。第二個問題中。由於教法出處不同，擔心會產生偏頗執取的見解。回答之中。兩者皆出自佛陀正法，隨人挑選採用。《四分律》記載：諸比丘自恣完畢後接著說戒，坐得太久極為疲憊；向佛稟白，因而開許。律文引述了佛陀的金口之言。第三個問題中。律典中因為六群比丘尼前來阻礙比丘，要求不要為六群比丘作羯磨；
