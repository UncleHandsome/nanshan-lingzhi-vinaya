整體看，這批譯文對律文脈絡的掌握大致到位（十三難／十遮的次序、“陶誘”“通請”“襆之”等都有正確理解），但有幾類問題值得修：**語域（用詞口吻）失當、增譯未標註、術語前後不一、贅詞與斷句**。以下逐條列出。

---

## 052-0001

| 問題 | 說明／建議 |
|---|---|
| ❗「坐下之後。」 | 斷成殘句。原文「坐已。語令敷坐具」是連貫動作，譯文應作「……坐下之後，吩咐受戒者也鋪展坐具」。 |
| ❗「登上尊崇殊勝的**佛子寶位**」 | 「高勝處」指受具足戒、成大比丘的尊高地位（一說指戒壇僧中）。「佛子寶位」屬自行發揮的莊嚴語，過度增譯。建議：「片刻之後就帶你到尊高殊勝之處（指受具足戒、入比丘之位）」。 |
| ⚠️「受戒人**站立**之處」 | 原文只作「受者所」，「站立」是補入的情境，可删或加括號。 |
| ℹ️「相對相及申手內」 | 譯「兩人相對而坐，距離在彼此伸手可及之內」正確；可略補「（以便就近出示衣鉢）」說明用意，非必要。 |

## 052-0002

| 問題 | 說明／建議 |
|---|---|
| ❗「名稱與**行相**」 | 「名相」＝名稱與相狀（形制、樣貌）。「行相」是唯識學 ākāra 的專術語，用在此處會誤導。改「名稱與相狀」。 |
| ❗「舉行作法**加持**受衣鉢」 | 「受衣鉢」是作法**受持**衣鉢（受者依法受持三衣一鉢），不是「加持」，也不是別人「傳授」給他。建議統一譯為「在此處就為他作『受持衣鉢』的作法」。 |
| ⚠️「即便襆之」→「重新**包袱包裹**好」 | 「包袱」是名詞，不宜當動詞；且「重新」為增字。改「隨即把衣鉢包紮好」。 |
| ⚠️「亦隨兩存」 | 譯「這兩種做法亦隨順並存」，但前文列了「屏處受／眾中戒師受／受戒後才受持」三種，「兩」指哪兩者不清。宜補一句：「（受戒前受持或受戒後受持）兩說皆可並存」。 |
| ⚠️「如**前篇**所述」 | 「如前」多指同篇前文，未必是別篇。改「如前文所說」較穩妥。 |
| ℹ️「（應量器）」「（七條衣）」 | 屬合理注釋，但建議全書統一用括號標示為譯者補注。 |

## 052-0003（問題最集中）

| 問題 | 說明／建議 |
|---|---|
| ❗「讓你如實**招供**回答」 | 「招供」是犯人供認罪行，與受戒前「至誠實答」的語境完全相反，屬嚴重語域錯誤。改「所以要你如實回答」。 |
| ❗「**審問**」（全篇反覆出現） | 「審問」帶審訊犯人的意味。原文只是「問」，一律改「詢問」；052-0006 的「審問」同改。 |
| ⚠️「沉淪**淪沒**於生死苦海」 | 疊床架屋。改「沉沒在生死苦海中」。 |
| ⚠️「徒自浪受」→「徒然**虛妄**受戒」 | 「浪」＝白白、徒勞，重點在「受了也得不到戒」。改「只是白白受一場，終究得不到戒體」。 |
| ⚠️「犯了**重**遮難之人」 | 原文只作「犯遮難人」。嚴格說十三難障戒、十遮不障戒（但得罪），加「重」雖是合理判讀，仍宜作「犯了遮難的人」，或加括號注明「（此就『難』而言）」。 |
| ℹ️「捨離虛妄**分別**」 | 「分別」為增字，可省。 |

## 052-0004

| 問題 | 說明／建議 |
|---|---|
| ⚠️「戒法便可以**納受**了」 | 「納受」多用於接受供養、領納他人之物，此處「戒可得受」是「可以得戒」。改「就可以得受具足戒了」。 |
| ⚠️「詐稱**冒充**自己是大比丘」 | 「詐稱」「冒充」同義重複，留一即可。 |
| ⚠️「諸龍畜等」→「**龍神、畜生**等」 | 「龍畜」是「龍等畜生」（龍攝於畜生趣），拆成兩類略失原意。改「龍等能變化的畜生類」。 |
| ⚠️「又**反悔**回去作外道」 | 「還作外道」只是「又回去當外道」，「反悔」是推測性增譯，可删。 |
| ℹ️「曾受佛門禁戒」 | 「邊罪」通指曾受具足戒而犯四重，建議作「曾受佛戒（具足戒）」並加注「邊罪：犯四重被棄於佛法之外」。 |
| ℹ️答語處理不一 | 原文一律答「無」，此處第五、十一、十二改譯「不是」，其餘作「沒有」。語意雖通，但建議統一（如皆作「沒有」，或依問句語氣調整並保持一致）。「不是（我不是黃門）」的括號也可省。 |
| ℹ️「五種黃門」 | 未作任何說明，一般讀者難懂，可注「（生、犍、妒、變、半月五種）」。 |
| ℹ️語尾「吧」 | 「你不是殺過父親吧？」等口語化，與他處文言化敘述不一致，建議統一為「你是否曾殺父？」之類。 |

## 052-0005

| 問題 | 說明／建議 |
|---|---|
| ❗「身具官役的**官員體系之人**」 | 現代官僚用語，生硬且語意含混。改「你不是官府的人（現任官職或為官府服役者）嗎？」 |
| ⚠️「你如今**法名**叫什麼」 | 「汝今字誰」只問名字，是否專指法名各家解法不一，宜作「你叫什麼名字」，或「你的名字（法名）」。 |
| ⚠️病名處理不一致 | 「癩、白癩、顛狂」照抄未釋，唯「乾痟」加注，體例不齊。建議一律簡注：癩（麻風類惡疾）、癰疽（惡瘡）、白癩（白癜一類皮膚病）、乾痟（消瘦癆病，一說消渴）、顛狂（精神失常）。另，「乾痟」直接定為「肺結核」略嫌武斷，宜作「癆病一類的消耗性疾病」。 |
| ⚠️「是**能承擔道業的**大丈夫嗎」 | 屬合理引申，但律中「丈夫」兼指男根成就、堪能忍苦，建議把引申語放括號。 |
| ℹ️「回答：『具。』」 | 未白話化，改「具足了」。 |
| ℹ️「他賤人」 | 「他」（屬於他人的）漏译，可補「你不是他人的賤僕（佛不許度）吧？」 |

## 052-0006

- 大致無誤。只需把「審問」改「詢問」；「羯磨戒師」是補入的主語，可保留但加括號更嚴謹。

## 052-0007

| 問題 | 說明／建議 |
|---|---|
| ⚠️「搭在**左**肩上」 | 原文只作「肩上」，「左」是依律儀補入，宜加括號或删。 |
| ⚠️「衣鉢**包袱**端放在他的雙手中」 | 同前，「包袱」不宜作動詞／狀語。改「把包好的衣鉢交放在他手中」。 |
| ⚠️「令其**儀容威儀**整肅齊整」 | 重複。改「使他的威儀端正齊整」。 |
| ⚠️「是否有**隱蔽**重病」 | 原文「密如法視無重病不」，「密」是教授師暗中察看，不是「隱蔽的病」。改「暗中如法察看他有沒有重病」。 |
| ❗「為其**傳授**衣鉢之法」 | 與 052-0002 的「加持受衣鉢」譯法不一致，且「傳授」語意偏離。兩處統一為「為他作受持衣鉢的作法」。 |

## 跨條的系統性建議

1. **語域統一**：全篇剔除「審問／招供／吧」這類司法或口語詞，改用「詢問／回答／是否」。受戒前的問遮難是鄭重而慈悲的程序，語氣宜莊重平實。
2. **增譯一律加括號**：站立、左肩、法名、布薩、應量器、大妄語、能承擔道業、佛子寶位等，凡原文無字而譯者補入者，或用括號、或改成注腳，避免讀者誤以為律文原有。
3. **術語表先行**：「受衣鉢（作法受持）」「名相」「遮／難」「襆」「揲」等宜定一套固定譯法，目前「受衣鉢」出現三種譯法是最明顯的不一致。
4. **消除同義疊詞**：沉淪淪沒、詐稱冒充、儀容威儀、包袱包裹。
5. **可考慮統一補注**：十三難各條（尤其邊罪、賊住、五種黃門、二形）與十遮中的「官人」「賤人」「丈夫」，一般讀者最難理解，建議每條給一句极简注。
