# 校閱材料　第1611檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1611-0001】03_業疏/04a_卷一之四#91
【原文】就自然界四種分之。當部無文，通取諸律，四名如列，各解可知
【譯文】就自然界而言，將其劃分為四種。本部《四分律》中沒有明文，通體採納各部律典之說，四種名稱正如文中所列，各自的解釋亦可知曉。

【1611-0002】03_業疏/04a_卷一之四#92
【原文】自然中初科。本宗盜戒有聚落界，三小界中有蘭若、道行，但非明顯，故云無耳。所出諸部，文中自標
【譯文】在自然界的最初一科中。本宗在盜戒中提到了「聚落界」，在三種小界中提到了「阿蘭若界」與「道行界」，只是並非明顯標舉，所以說沒有明文罷了。其所出自的各部律典，在文中自然會有標明。

【1611-0003】03_業疏/04a_卷一之四#93
【原文】聚落為二，謂通局也
【譯文】聚落界分為兩種，即所謂「通（不可分別）」與「局（可分別）」。

【1611-0004】03_業疏/04a_卷一之四#94
【原文】聚落釋標云通局者，通即不可分別，局即可分別
【譯文】聚落界的解釋中標示為「通局」者，「通」即是指不可分別，「局」即是指可以分別。

【1611-0005】03_業疏/04a_卷一之四#95
【原文】初不可分別者，或約僧之來去難可知者，或約處所散落不知際域。故《僧祇》云：若城邑聚落，界分散亂不可知者，以五肘為弓，七弓種一樹，齊七樹為量。相去作法，雖有異眾，各不犯別。約相步之，則有六間六十三步
【譯文】第一種「不可分別者」，或者是就僧眾的往來去向難以得知而言，或者是就處所零星散落而不知道具體邊界而言。因此《摩訶僧祇律》說：如果城邑聚落之中，界限分散混亂不可知曉的，便以五肘為一弓之長，每隔七弓種植一棵樹，以相隔七棵樹的距離為衡量限度。相隔這樣的距離各自作法，雖然彼此有不同的僧眾，但各自都不犯別眾之罪。以步數來衡量其形相，則有六個間隔、共六十三步。

【1611-0006】03_業疏/04a_卷一之四#96
【原文】不可分中初科為二：初列相，即人、處二種不可別知，或俱或互，竝是此收；二俱可分，則屬後攝。故下引示，文唯約處，義必兼人。彼因婆羅門問種樹法，佛言以五肘弓量，七弓種一樹，能令根莖堅固，扶疏生長，不相妨礙。時優波離白佛：已聞種樹分齊，今復問：若有處所城邑聚落，界分不可知，若欲羯磨，應齊幾許，使異眾各各相見，而得成就，不犯別眾耶？文中上是請問，以下即佛答。五肘九尺，七弓六丈三尺，一樹得十步半
【譯文】在不可分別聚落的最初一科中分為兩部分：首先列出法相，即人與處所這兩種情況不可分別知曉，或者兩者皆不可知、或者其中一種不可知，都由本條收攝；如果人與處所兩者皆可分清，則屬於後條收攝。自「故下」引證說明，律文雖然只約處所而言，其義理必定兼指僧人。彼律起因於有婆羅門詢問種樹之法，佛陀回答說用五肘長度為一弓來度量，每隔七弓種一棵樹，能使樹木根莖堅固、枝葉茂盛生長而互不相妨礙。當時優波離尊者向佛陀稟告：已經聽聞了種樹的界限準則，現在再請教：如果有的地方其城邑聚落界限無法知曉，若想要舉行羯磨，應當以多大距離為限，才能使不同的僧眾縱然彼此相見，羯磨卻得以成就而不犯別眾之過？律文中前半段是尊者的請問，以下即是佛陀的回答。五肘折合為九尺，七弓折合為六丈三尺，一棵樹的間距合為十步半。

【1611-0007】03_業疏/04a_卷一之四#97
【原文】昔云七十三步半者，錯筭七間也。《僧祇疏》中七樹六間，猶如《四分》衣界八樹中間。諸師衣界止計七間，如何僧界七樹非六間也
【譯文】過去有人說是「七十三步半」，那是錯誤地計算成了七個間隔。《摩訶僧祇律疏》中明確指出七棵樹只有六個間隔，正如《四分律》中不失衣界是以八棵樹中間的距離為準。古德法師在計算衣界時只算七個間隔，為什麼在僧界中七棵樹卻不算六個間隔呢？

【1611-0008】03_業疏/04a_卷一之四#98
【原文】初錯筭步限中初科。一期之誤，多十步半，故云錯也。下據彼疏，會同本部蘭若衣界，決知誤矣
【譯文】在最初計算步數限度發生錯誤的一科中。一時的誤算，平白多算了十步半，所以說算錯了。下文依據彼律之疏，會通本部的阿蘭若處衣界，便確決知曉其謬誤了。

【1611-0009】03_業疏/04a_卷一之四#99
【原文】有人執舊見云：樹限兩頭各有勢分，故各分半，還是七間；又云周圓種樹如月暈也，故有七間；又改《僧祇》為八樹字。斯之我愛，穿鑿太甚！何處有樹，即以樹量？律約世情，假以相顯
【譯文】有人執持舊日成見說：樹木界限的兩頭各具有外延的勢力範圍，所以各分半個間隔，加起來依然是七個間隔；又有人說環繞周圍種樹如同月暈一樣形成圓周，所以有七個間隔；還有人甚至擅自將《摩訶僧祇律》改為「八樹」之字。這種對自我見解的偏愛執著，穿鑿附會太過分了！何處真有現成的樹木，就非得以樹木來丈量？戒律只是順應世俗實情，藉助樹木的形相來彰顯距離罷了。

【1611-0010】03_業疏/04a_卷一之四#100
【原文】次科初引彼執。次列三種：上二轉計，下一欺罔。月旁氣謂之暈。斯下總斥。初二句責其情執，次二句示今取量不必須樹，下二句顯律本緣依樹所以。假，即借也
【譯文】次一科起初引述那些人的偏執。其次列舉三種說法：前兩種屬於輾轉妄計，最後一種屬於欺瞞篡改。月亮旁邊的環狀氣暈稱為「暈」。自「斯（之我愛）」以下總體予以斥責。前兩句斥責其情執偏見，中間兩句說明如今所採用的度量不一定非要有樹，後兩句顯示戒律最初起因於依託樹木的緣由。「假」就是借用的意思。

【1611-0011】03_業疏/04a_卷一之四#101
【原文】中間七樹，二眾兩頭各行僧事，相對既爾，縱廣四維例集可知。律剋二身，故以樹限；若取當分，皆半折之，則自分之界，唯三十一步半耳。但以界體叵知，用身分相，廣如《鈔》顯。此一既爾，餘之自然大小乃殊，例有通局，皆半約之
【譯文】中間隔著七棵樹，兩組僧眾在兩端各自舉行僧事，相對而立的情形既然如此，縱橫四方各個方位的集會距離依例即可推知。戒律確切限定在兩造僧眾的坐身之間，所以用樹木間距為限；如果單取自己這一份，都應當折半計算，那麼屬於自己本分的界限，其實只有三十一步半罷了。只是因為自然界的界體難以辨知，故借用僧身來劃分相貌，詳盡如《事鈔》中所開顯。這一項既然如此，其餘各種自然界雖然大小有所懸殊，依例也都有「通（深防）」與「局（自分）」的差別，皆應折半來作約定。

【1611-0012】03_業疏/04a_卷一之四#102
【原文】三中有二：初定方圓。若無異界，體則定圓；必有相侵，尖斜不定。「律下」二辨通局。六十三步半是自分，半屬深防。叵，即不可。指廣如《鈔》，見集僧篇。此下例通。六相之中，除可分聚，餘皆半折，如蘭若五里，人各二里半等。自分、深防合舉是通，兩分為局。問：今若集僧，依通依局？答：若彼無人，止須依局；恐來不定，故必從通，名為深防，義在於此。若爾，縱有人來在我自分之外，理應無過？答：人雖在外界，己相侵故，有成別，尋《鈔》可知。問：可分別聚何不兩分？答：四周有院，攝相義強；若在相外，則彼此界別；若在相中，即同自分。餘無院相，約量通收，故皆半減
【譯文】在第三點中有兩個部分：首先確定形狀的方圓。如果沒有其他界限相干涉，界體必定是圓形的；若必定有相鄰界限侵入，則尖角斜曲形狀不固定。自「律（剋二身）」以下，第二、辨析通局。六十三步之中，一半（三十一步半）是自分，一半是深防。「叵」就是不可的意思。指引詳情如《事鈔》所開顯，見於〈集僧篇〉。自此以下例推共通原則：在六種自然界相之中，除了「可分別聚落」之外，其餘都折半計算，如同阿蘭若處定為五里，雙方各取二里半等。將自分與深防合併列舉即是「通」，將兩者分開即是「局」。問：如今如果要召集僧眾，應當依據通界還是依據局界？回答：如果那邊沒有人，只需依據局界；唯恐有人往來不定，所以必定要依從通界，稱之為「深防」，其意義就在於此。如果這樣，縱使有人來到了我方自分之外，在理路上應當算無過失吧？回答：他人雖然身在界外，但因為雙方勢力互相交涉侵入，依然會構成別眾之罪，翻閱查尋《事鈔》即可知曉。問：可分別聚落為什麼不折半劃分呢？回答：因為四周有圍院，圍院收攝界域的標相意義很強；如果在院相之外，彼此的界限截然有別；如果在院相之中，就等同於全屬自分。其餘自然界沒有圍院相貌，只能依據尺寸量度通括收攝，所以都要折半扣減。
