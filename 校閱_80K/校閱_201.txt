# 校閱材料　第201檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【201-0001】03_業疏/10a_卷二之四#5
【原文】戒法有幾而言諸者？約人則七眾不同，約體則四位階級。故二眾大受為一位，同奉具戒，無願也；二眾沙彌為一位，同奉未具，有願也；兩部在家為一位，同奉五支之戒也；淨行信心為一位，同奉九支齋戒也。由體同故，根轉戒存；報殊儀異，就緣類別，故曰「諸」也
【譯文】戒法到底有幾種而稱之為「諸」呢？就受戒的人來說有七眾的不同，就戒體來說有四種層次階位。因此，出家二眾（比丘、比丘尼）的大受（具足戒）為一個位階，共同奉持具足戒，沒有更高別解脫戒的願求了；出家二眾沙彌（沙彌、沙彌尼）為一個位階，共同奉持未具足戒，有願求受大戒的心願；男女兩部在家人為一個位階，共同奉持五支戒法（五戒）；修持淨行的信眾為一個位階，共同奉持九支齋戒（八關齋戒）。由於戒體本質相同的緣故，男女根相轉變時戒體依然存在；由於果報身軀相異、威儀軌範不同，依循受戒因緣劃分類別，所以稱為「諸戒」。

【201-0002】03_業疏/10a_卷二之四#6
【原文】本文標題釋「諸」字中，初科初牒問。「約下」釋通，又二：初總示。人即受人，體謂法體，故下列別四位。每一位中各兼男女，餘三則人法齊等，第二則兼收式叉，七眾備矣。初云「無願」，已獲具足，無願求故。問：道、定二戒豈不忻求？答：今此且望別脫中極；定、道心戒，不假緣受，隨功自感，故非所論。問：準《善戒經》，比丘具戒為菩薩方便，豈非有願？答：心雖企求，教有分齊，且據當教，故云「無願」。二明沙彌有願，反上可知。三在家五戒，不斷正婬，但名婆塞，簡下八戒未彰淨號。四九支者，若據諸教皆名八關，剋實有九，故云「九支」。「由下」通結。上二句明體同故合，根轉戒存通該四位，男女互轉不復重受，可驗體同；下二句明緣異故離，文列受法，一一位中各有不同，至下自見
【譯文】在解釋本文標題中的「諸」字時，第一科起初重述提問。自「約」以下解釋開通，又分為兩部分：首先總體說明。「人」就是受戒之人，「體」是指戒法之體，所以下文分別開列出四個位階。每一個位階中各自兼具男女兩眾，其餘三個位階都是男女的人與法平等齊同，第二個位階則另外兼收式叉摩那，七眾便全都具備了。第一位階說「無願」，是因為已經獲得具足戒，在別解脫戒中沒有更高的願求了。問：難道不欣求禪定戒（定共戒）與聖道戒（道共戒）嗎？答：現在這裡暫且是就別解脫戒中的最高極致而言；至於定共戒與道共戒這類心戒，不需要假借外緣傳授，而是隨著個人修證功行自然感得，所以不在這裡討論。問：依照《菩薩善戒經》，比丘具足戒是通往菩薩戒的方便階梯，難道沒有求受大乘戒的願心嗎？答：內心雖然有所企求，但教法自有界限範圍，暫且依據當前聲聞教法而言，所以說「無願」。第二、說明沙彌有願求，反照上面道理即可明白。第三、在家的五戒，不斷除正當的夫妻之淫，只稱為優婆塞（清信士），以此簡別於下文八戒，五戒並未標顯清淨專號（下文八戒方標顯「淨行」之號）。第四、「九支」，如果依據各部教典都稱為「八關」，但嚴格落實說來共有九項內容（含過中不食），所以稱為「九支」。自「由」以下總括結納。上面兩句說明因為戒體相同所以加以合論，轉變性徵而戒體依然留存的道理通貫這四個位階，男女互轉時不需要重新受戒，由此可以驗證戒體相同；下面兩句說明因為外在因緣不同所以分開論述，文中羅列的受戒儀軌，在每一個位階中各有不同，到下文自然就能見到。

【201-0003】03_業疏/10a_卷二之四#7
【原文】問：式叉別位，理有異持，何不在者？答：今據體論，如上分四，式叉增其學法，據本但唯十戒。如何知之？以轉根驗，還同沙彌也
【譯文】問：式叉摩那是獨立的階位，在法理上有特殊的行持，為什麼不在四個位階之中呢？答：現在純粹根據戒體來論述，所以如上分為四類；式叉摩那是增加了修學的法條，若就其根本戒體而言，其實依然只是十戒。如何知道這一點呢？從性徵轉變時的驗證來看，她轉為男根後便還同於沙彌。

【201-0004】03_業疏/10a_卷二之四#8
【原文】初問中，以前四位獨遺式叉，故須問決。重加六法，出過小眾，故云「異持」。答中，初指前通答。「式下」顯同小眾，既云增學，明不發體。《鈔》云「六法是其學宗，戒體更不重發」，還約轉根證同小眾
【譯文】在最初的問難中，因為前面四個位階獨獨遺漏了式叉摩那，所以必須發問予以決斷。式叉摩那額外加上六法，超越了尋常沙彌小眾，所以說是「異持」（特殊的行持）。在回答中，起初指涉前文做普遍回答。自「式」以下顯示其戒體等同於小眾，既然稱為「增長修學」，就表明並未重新發起新的戒體。《事鈔》說「六法是她學習的主旨，戒體並不再重新發起」，也是通過性徵轉變來證明她等同於小眾。

【201-0005】03_業疏/10a_卷二之四#9
【原文】問：體同沙彌，自有常學，何須增法有違缺戒？答：由於女報性涉虗羸，即授具足，恐有輕犯，故增戒法，加輔靈神，必事陵踐，隨法更學
【譯文】問：如果戒體等同於沙彌，本來就有一貫的學處，何必額外增加六法，使得一旦有所違犯就殘缺了戒法呢？答：由於女性果報體性較為軟弱脆弱，如果直接授予具足戒，恐怕會輕忽犯戒，所以額外增加戒法，用來輔助護衛其心神；如果真的有所踐踏違犯，就要依照法規重新修學兩年。

【201-0006】03_業疏/10a_卷二之四#10
【原文】次問中，「常學」即十戒也。六法制行二年，中間有犯，還復從初，故云「有違缺戒」。答中，初敘報劣，故下次明制法輔助也。靈神即心識。下云六法練心，恐輕犯故；二年練身，恐有胎故
【譯文】在第二個問難中，「常學」就是指十戒。六法規定必須奉行兩年，其間若有違犯，就要重新從頭算起，所以說是「有違缺戒」。在回答中，起初敘述果報羸劣，自「故」以下說明制定戒法是為了輔助。靈神就是指心識。下文說六法是為了鍛鍊心志，因為恐懼輕易犯戒的緣故；兩年是為了檢驗身體，因為恐懼懷有身孕的緣故。

【201-0007】03_業疏/10a_卷二之四#11
【原文】所言戒者，謂禁約止善為宗。雖有作用，終須謹攝，有越常規，無非制約，故云止也。有人言防非禁惡為戒者，非無一相，然佛有戒，未必防非，戒通善惡，不可偏解，餘如別顯
【譯文】所謂「戒」，是指以禁約規範、止惡行善（止善）為其主旨。雖然也有起心動念的作為作用（作持），但終究必須謹慎攝受持守；只要有所超越常規威儀，無不需要加以制約管束，所以稱為「止」。有人說「防範過非、禁絕罪惡」就是戒，這並非全無道理，然而佛陀制定的戒法，未必就能防非；而且「戒」的概念通於善與惡（如惡律儀），不能作片面的理解，其餘的道理如其他專文中所闡明。

【201-0008】03_業疏/10a_卷二之四#12
【原文】次釋戒中，初示今義。禁約言通，止善名局，以局簡通，即知善戒由止成善，故云「止善」。「雖有」等者，會通作持，依法離過，還歸止攝，則知止善通收二持。「有下」斥古解。初引古，「非無一相」，但得止義故。「然下」正斥。上二句斥「防非」，戒必防非，人何有犯？故知須假行人隨中嚴奉，始可離非，故云「未必」也。次二句斥「禁惡」，屠獵所持亦名為戒，今云禁惡，但局善戒，故云「偏解」。下句指廣，即《事鈔》中卷、《戒疏》初卷也
【譯文】其次在解釋「戒」字中，起初展示今家的正義。「禁約」一詞涵義廣泛，「止善」名稱則較為明確局限，用局限來甄別廣泛，便可知善戒是通過止惡而成辦善業，所以稱為「止善」。「雖有」等句，是會通作持，依法去行持而遠離過失，最終仍歸結於止惡防非的攝持，由此可知「止善」通收了止持與作持兩種行持。自「有」以下駁斥古人的解釋。起初引用古說，「非無一相」是指古說僅僅得到了「止」的一層涵義。自「然」以下進行正式駁斥。上面兩句駁斥「防非」：如果戒法必然能夠防非，為何受戒之人還會犯戒呢？由此可知必須依託修行者在隨行中嚴格奉持，才可能遠離過非，所以說「未必」。接下兩句駁斥「禁惡」：屠夫、獵戶所受持的惡誓也稱為「惡戒」，現在若說戒就是禁惡，就僅局限於善戒了，所以說是「片面理解」。最後一句指示詳細發揮處，就是指《事鈔》中卷以及《戒疏》第一卷。

【201-0009】03_業疏/10a_卷二之四#13

【譯文】所謂「法」，法是指楷模軌範，凡是所要依循裁量的標準，全都具備成辦因緣與法度軌相。

【譯文】就下一科而言，《薩婆多論》起初說明只准許領受三歸；自「又下」其次說明不聽許受戒。所謂「無所曉」，是因畜生類大多愚鈍，不堪承受持守。依照下文能夠得成三歸來看，也是取其具有知解能力的緣故。所謂「雖經等者」，即指《優婆塞戒經》（善生經）中記載龍受八戒，論師為了防禦詰難，因而依自意加以解釋。「齋」就是指八戒，但這是《成實論》所依據的說法，正如隨後所引。《四分律》中佛陀剛成道時，商客奉獻蜜糖，最初受了三歸，隨後又為龍傳授三歸，如今正要說明龍等畜生道眾生，因而順帶引證。下文引用兩部論典，三歸與戒法全都開許。《善見論》所說的「神」，指的就是鬼趣。

【201-0101】03_業疏/10a_卷二之四#105
【原文】義準多論據無知者，人猶不得，何況鬼畜？如餘得者，謂有知解。律中制罪，尚結偷蘭，以能變化、知解人語，可以類也
【譯文】在義理上準照《薩婆多論》所論，是依據毫無知解的眾生而言，若是人道無知尚且不能得受，何況是鬼神與畜生呢？如果像其餘論典說能得受的，是指具有知解能力者。律典中判定罪名，對這類眾生尚且結為偷蘭遮罪，因為牠們能變化形相、懂得人類語言，由此可以類推知曉。

【201-0104】03_業疏/10a_卷二之四#108
【原文】初中受三歸者，但得法被身，為佛弟子，無戒可持。文中多論已下，顯本從魔，歸心正覺。具列三寶體者，以妄作者多故，偏列云知真歸也。又引善見者，釋成作法不易，依緣而受亦不難也
【譯文】在起初「受三歸」中，只是獲得正法披加於身，成為佛陀的弟子，並無特定的戒條需要持守。文中自引用《薩婆多論》以下，是彰顯眾生原本盲從惡魔，如今歸心於正覺（佛寶）。具足列出三寶體性，是因為妄加造作者繁多的緣故，特意列出是為了讓人知道真正的所歸之境。又引用《善見論》文，是為了解釋作法並不草率容易，但若能依憑具足的因緣來領受，也並非難事。

【201-0105】03_業疏/10a_卷二之四#109
【原文】次解中標文三段：初示立法分齊。次釋《多論》，「歸正覺」者，對上從魔，且明佛寶，正覺即華言也；妄作多者，人師授法，不知體相，故三寶多種，唯明理體，故云偏列，簡住持、化相，故曰真歸，如上義門真偈中說。又下三釋《善見》，難易成否在於明昧，故須師學始可授人
【譯文】在隨後的解釋中標示疏文有三段：第一、明示立法的界限分齊。第二、解釋《薩婆多論》，「歸正覺」是相對於前面的盲從魔王，暫且用以闡明佛寶，「正覺」就是梵語佛陀的漢譯；「妄作者多」，是指各處的傳戒師在傳授教法時，不知曉三寶的體相，所以三寶雖然有多種，此處只闡明理體三寶，所以說是特意列出，甄別淘汰了住持三寶與化相三寶，所以稱為真正的歸依，如同上述義門真偽偈語中所說。自「又下」第三、解釋《善見論》，其難易與成否全在於內心的明了或愚昧，所以必須從師修學通達，才可以為人傳授。

【201-0106】03_業疏/10a_卷二之四#110

【201-0107】03_業疏/10a_卷二之四#111
【原文】次釋授法初科。「三說已」者，此據初念已前，通名為作；「無作便生」，即約次念，徹至盡報也。能授所受知業成處，故不昧也
【譯文】其次解釋傳授之法的第一科。「三說已」，這是依最初一念以前而言，通稱為「作」（表業）；「無作便生」，就是就緊接著的第二念起，一直貫徹延續到壽命窮盡之時。能授師與所受者都能明了業體成辦之處，所以稱為不昧。

【201-0110】03_業疏/10a_卷二之四#114

【201-0111】03_業疏/10a_卷二之四#115
【原文】三中，初釋除疑。有人用此授人五戒，故特決之。「又下次」釋引證。初二句點文，有加無加，用分歸戒，即此誠文是準的之處。灼，明也。下二句誡斥。晦，暗也
【譯文】在第三部分中，首先解釋破除疑惑。有人拿這種三歸儀軌來為人授五戒，所以特別加以裁決判定。自「又引母論」以下，是解釋引文作證。前兩句點明論文，說明是否有附加誓句，以此區分是單純三歸還是受戒，而這段確實的論文正是準確的依據標準。「灼」，是明了的意思。後兩句是告誡斥責。「晦」，是昏暗的意思。
