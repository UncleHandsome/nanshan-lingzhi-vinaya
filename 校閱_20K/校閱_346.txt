# 校閱材料　第346檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】【記文】戒本第二句，這是第一科。起初說「時」是總體標明第二句。「列非時」是點明經文與注文的內容。

【譯文】【疏文】問：「戒本中為什麼沒有提到『功德衣開許離衣』的規定呢？」

【346-0003】02_戒疏/15d_卷三下之三#108
【原文】【記】次科，問意，可解。
【譯文】【記文】這是第二科，提問的意圖很清楚。

【346-0004】02_戒疏/15d_卷三下之三#109
【原文】【疏】答：「上士翹勤，不受寬利。」
【譯文】【疏文】答：「修持頭陀行的高士勇猛精進，不願接受寬鬆的利益。」

【346-0005】02_戒疏/15d_卷三下之三#110
【原文】【記】初答中。以德衣五利，隨人受之，今是蘭若比丘修頭陀者，故云「上士翹勤」，謂翹企望上而進行功，唯務少欲，豈受寬利耶？
【譯文】【記文】在第一種回答中。因為功德衣帶來的五種利益，是隨人自願接受的；現在是在阿蘭若處修習頭陀行的比丘，所以說是「上士翹勤」，意思是不斷奮勉向上推進功行，一心務求少欲知足，哪裡還會去接受寬鬆的利益呢？

【346-0006】02_戒疏/15d_卷三下之三#111
【原文】【疏】「若爾，應無迦提月？」
【譯文】【疏文】「如果是這樣，經文中應該連迦提月也不必提吧？」

【346-0007】02_戒疏/15d_卷三下之三#112
【原文】【疏】答：「德衣作法有，迦提任運受。亦可文列『迦提月』，謂是夏竟時，非受於五利。」
【譯文】【疏文】答：「功德衣是透過僧團作法而擁有，迦提月則是時間到了自然享有。也可以解釋為文中列出『迦提月』，只是指夏安居結束的這個時節，並不是指去接受那五種利益。」

【346-0008】02_戒疏/15d_卷三下之三#113
【原文】【記】轉難中。以文云「迦提月滿」，既有迦提，亦受五利，那云無者？答中。初約同開釋。迦提一月夏竟常開，上士同霑，文中故列。雖教所開，自不受利。「亦」下，次約標時釋，謂文標時限，非是開利。
【譯文】【記文】在進一步反問的段落中。因為經文明確寫著「迦提月滿」，既然提到了迦提月，理應也享有五利，怎麼能說沒有呢？回答中，首先依據「共同享有開許」來解釋。迦提月滿一個月是夏安居結束後通行的開許，精進的上士也同樣沐浴在這種時間界定中，所以經文中順帶列出。雖然戒律開許，但自己並不受領特權利益。「亦可」以下，接著依據「標示時間」來解釋，意思是經文只是標明時間界限，並非指享受開許的利益。

【346-0009】02_戒疏/15d_卷三下之三#114
【原文】【疏】又解：「異界比丘不成受德衣。《律》云：『有難、無大衣。』今既賊難，故知不合受。無難亦應成。」
【譯文】【疏文】另一種解釋說：「如果比丘身在不同的結界，功德衣便不能受持成功。《律》中說：『若有禍難，或者沒有大衣，就不能受持功德衣。』如今既然有盜賊之難，可知本來就不合適受持功德衣。但若沒有難事，受持本應當是成立的。」

【346-0010】02_戒疏/15d_卷三下之三#115
【原文】【記】次答文，二。初約異界釋。以蘭若坐夏，往他寺受衣，即非同界，德衣簡故。「律」下，次約難緣釋。即王、賊等八難，不聽受德衣。文舉兩緣，正用「有難」，因引無衣。
【譯文】【記文】第二個回答的內文有兩點。第一點依照不同結界來解釋。因為在阿蘭若安居，若跑到其他寺院去受衣，就不是在同一個結界之內，受持功德衣時這是有所簡別排除的。「律云」以下，次依禍難因緣來解釋。也就是遇到國王、盜賊等八種難事，律中不許受持功德衣。經文中提出了兩種因緣，此處正是在運用「有難」這一點，順帶引用無衣的情況。

【346-0011】02_戒疏/15d_卷三下之三#116
【原文】【疏】三、「蘭若」者，注云「去村五百弓」、「弓長四肘」，肘長一尺八，以此為率，通計六尺為步，則二里也。此謂頭陀蘭若，「閑靜處」如盜戒說，離衣，僧界，難事，總有五。
【譯文】【疏文】第三句、「阿蘭若」，注文說「距離村落五百弓」、「弓長四肘」，一肘長一尺八寸，以此為標準折算，通計六尺為一步，那麼五百弓大約就是二里的距離。這指的是修頭陀行者的阿蘭若。此外還有如不與取戒所說的「閑靜處」、離衣戒、僧界、難事處，共有五種阿蘭若。

【346-0012】02_戒疏/15d_卷三下之三#117
【原文】【記】三中，釋注。初示分齊。每一百弓，成一百二十步，五百弓共成六百步，三百步為里，故有「二里」。「此」下，簡濫。「如盜戒」者，彼云若「閑靜處」，即蘭若也。三、「離衣」。四、「僧界」又二，即有難、無難。五、「難事」，即提舍蘭若受食也。
【譯文】【記文】第三句解釋注文。首先指出尺寸分齊。每一百弓折合成一百二十步，五百弓總共是六百步，三百步為一里，所以算下來剛好是「二里」。「此謂」以下，進行簡別以防混淆。「如盜戒說」，是說該處提到所謂「閑靜處」，就是阿蘭若。第三指「離衣」。第四指「僧界」，又分有難與無難兩種。第五指「難事」，也就是指在向彼悔過法阿蘭若處接受食物。

【346-0013】02_戒疏/15d_卷三下之三#118
【原文】【疏】四、「有疑」者，如注可解。《十誦》「乃至惡比丘畏」。
【譯文】【疏文】第四句、「有疑慮」，如同注文所寫，容易明了。《十誦律》中甚至提到「乃至害怕遭到惡比丘的侵害」。

【346-0014】02_戒疏/15d_卷三下之三#119
【原文】【記】四中。初指注。「十」下，引示。「惡比丘畏」，謂恐相侵損，亦開留寄。
【譯文】【記文】第四句中。首先指出注文。「十誦」以下，引用說明。「惡比丘畏」，是說害怕惡僧侵害毀損，這也開許留放寄託。

【346-0015】02_戒疏/15d_卷三下之三#120
【原文】【疏】五、「比丘」下，明既有難，即離衣宿，不作日限。如《五分》：「上二衣，隨所重者寄一。下衣隨身。禮拜、入寺、乞食，不得單著。」
【譯文】【疏文】第五句、「比丘」以下，說明既然遇到了禍難，就可以離開衣服過夜，而不設天數限制。如《五分律》所說：「三衣之中的上面兩件衣服，隨自己認為重要的一件寄放。下衣則隨身穿著。禮拜、進入僧寺、外出乞食時，都不得單穿一件衣服。」

【346-0016】02_戒疏/15d_卷三下之三#121
【原文】【記】五中。初明無日限。以文中但云留衣，不言日數故。此即暗指古非，下文顯斥。「如」下，示所離多少。一、唯開一衣，二、不開五條。
【譯文】【記文】第五句中。首先說明沒有日數限制。因為經文中只說留置衣服，並沒有提到限制多少天數。這就是暗中指出古人的錯誤，下文會明顯予以斥責。「如五分」以下，說明可以離開衣服的件數。第一、只開許離開一件衣服；第二、不開許離開五條衣。

【346-0017】02_戒疏/15d_卷三下之三#122
【原文】【疏】六、「置村舍內」。《僧祇》云：「還寄可疑俗人家，開留一衣，不作日限。」《五分》：「前後安居未滿，無怖不得離衣。彼國八月賊發，殺人取肉祀天，諸人至期不出，遂至蘭若害諸比丘。故開寄衣，不作日限，唯須十日一度往看，無有濕壞。免賊難故。」
【譯文】【疏文】第六句、「寄置在村舍內」。《僧祇律》說：「把衣服寄放在引起嫌疑的俗人家中，開許留下一件衣服，不設天數限制。」《五分律》說：「前安居或後安居尚未圓滿期間，在沒有恐怖恐慌的情況下不得離開衣服。那裡的國家在八月時盜賊猖獗，殺人取肉祭天，人們若到期不出村，盜賊就會殺入阿蘭若殺害比丘。所以特開准許寄放衣服，不設天數限制，但必須每十天去看一次，查看衣服有沒有受潮損壞。這是為了避免盜賊之難。」

【346-0018】02_戒疏/15d_卷三下之三#123
【原文】【記】六中。「《僧祇》可疑家」，即反委盜者，則無所慮。《五分》，初明夏分不開。「彼」下，次示本開緣。「祀」，即祭祀。「十日往看」，欲知濕壞，非是會衣。
【譯文】【記文】第六句中。「僧祇律中可疑家」，是指反而將衣服託付給有嫌疑盜竊的人家，這樣小偷就不會打這件衣服的主意。《五分律》中，首先說明夏安居期間無緣不開許。「彼國」以下，接著指出原本開許的因緣。「祀」就是指祭祀。「十日前往看視」，是為了知道有沒有受潮發霉損壞，並不是為了與衣服共宿會合。

【346-0019】02_戒疏/15d_卷三下之三#124
【原文】【疏】七、「諸比丘」下，明有別緣至於七夜。此律文略其緣。古來諸師尋文不了，謂是恐怖，故開六夜。今約戒本，文相自分。前是難緣，如上已解。今是別緣，故須引證。如《僧祇》云：「何故唯開六宿？因往斷事，為衣重故，時須六宿，故即捨衣六夜為戒。」《五分》：「有僧、塔事，和尚、闍棃及他事者，皆聽六夜留衣俗家。若一、二、三，乃至五夜亦爾。」餘如《鈔》。
【譯文】【疏文】第七句、「諸比丘」以下，說明如果有特殊的其他因緣（開許留衣，至第七夜為犯限）。本律的文字省略了這些因緣。自古以來的論師由於研讀經文未能徹了，以為是因為恐怖畏懼的緣故才開許六夜。現在依據戒本考察，文句的分段界線本來就清清楚楚。前面是面對禍難的因緣，上面已經解釋過了。現在是屬於特殊的個別因緣，所以必須引證說明。正如《僧祇律》所說：「為什麼只開許六宿？因為外出評斷是非諍事，由於衣服沉重，時間上剛好需要六夜，所以捨下衣服以六夜為限制定了戒律。」《五分律》說：「若有處理僧團事務、佛塔事務，為和尚、阿闍梨奔走以及其他事務，都准許在俗人家留放衣服六夜。如果是一夜、兩夜、三夜，乃至五夜也都是如此。」其餘內容如同《行事鈔》所載。
