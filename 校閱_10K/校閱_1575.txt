# 校閱材料　第1575檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1575-0010】03_業疏/02a_卷一之二#6
【原文】三中，初二句通標。以上三事攝一切事，一一事下各有是非，故云「互也」；竝由加被，其相方彰，故云「附法生也」。「總」下別示，初顯是。實事言通，須知其相。《鈔》云「竝令前境是實，片無錯涉，皆成法事；若一緣有差，悉竝不成」，如不覆藏與覆藏羯磨，即無事有法；又應與作訶責，乃作擯出，此即有藥有病，施不相當，佛竝判不成。故知事者必須稱實，方稱聖教。「設」下示非，破戒自惱是損自，如受具緣乖、懺治非法、戒場太界標相不明、淨地攝衣事容虗謬，隨有違教，無非結罪；招機妨業即損他，如無病離衣、妨難造房等，一一犯戒，又復招機。或可破戒招譏通前諸事，既容毀戒，豈不招譏？是則二損通該一切。「隨」下示意，隨文事多，無由委示，止可如上約義通明。
【譯文】在第三科中，開頭兩句為總標。以上述三類事相統攝一切事相，每一件事相之下都各有其「是」與「非」，所以說「互也」；都是由於羯磨法的加被，其行相才得以彰顯，所以說「附法生也」。「總」以下分別說明，首先顯明「是」（合法）。實事一詞涵蓋面很廣，必須明白其具體行相。《行事鈔》說「都必須使現前對境真實無訛，絲毫沒有錯謬混淆，才都能成就法事；只要有一項因緣有差錯，便全都不能成就」，例如沒有覆藏之罪卻作覆藏羯磨，這就是無事而妄作法；又如應當給予訶責處罰，卻作成擯出羯磨，這就是雖有藥也有病，但施藥與病情不相匹配，佛陀全都判定為不成就。由此可知，事相必須與實情完全符合，才符合聖者的教誡。「設」以下指出「非」（非法），破戒自惱是損害自身，例如受具足戒時因緣乖違、懺悔治罰非法、戒場大界的標相不分明、淨地攝持衣物之事容有虛假錯謬，隨順任何違背教誡之舉，無不結罪招過；招譏妨業則是損害他人，例如無病而離衣宿夜、在有妨害留難之處建造房舍等，每一項都違犯戒律，又招致外界譏嫌。或者說破戒與招譏通於前面所有事相，既然容有毀犯戒律，豈能不招致譏嫌？因此這兩種損害普遍涵蓋一切事相。「隨」以下說明用意，隨順律文之事極為繁多，無從在此詳盡開示，只能如同上面這樣就義理普遍說明。

【原文】次解第三能秉御僧者，四門分別：初制意釋名，二定僧體狀，三明人法相對，四廣顯是非
【譯文】接下來解釋第三門「能秉持操作的僧伽」，分為四門來分別辨析：第一、制戒用意與解釋名稱；第二、判定僧伽的體性狀相；第三、說明人與法的相對關係；第四、廣泛顯明其是與非。

【1575-0012】03_業疏/02a_卷一之二#8
【原文】初制意者，僧寶流世，元為生善；然生善在事，假法成立；法不自建，弘斯在人。故制羯磨，必由僧秉。良以五眾為出世之田，凡所造修，無非拔濟，故以僧和之法，能成勝業之緣。何以知然？如果向俗人，雖參聖限，以形乖法別，未許傳授，所以五戒等受授必出家，其意可見
【譯文】第一、制戒的用意：僧寶流傳於世間，本來是為了令眾生生起善法；然而生起善法在於具體的事修，事修又必須藉助如法之規矩才能成立；法規不能自行建立，弘揚它全在於人。所以制定羯磨，必定要由僧伽來秉持操作。這確實是因為出家五眾是超脫世間的福田，凡所造作修持，無不是為了拔苦濟度，所以用僧眾和合之法，能夠成就殊勝善業的勝緣。如何得知是這樣呢？例如證得四果四向的在家俗人，雖然已列入聖者的等位，但因為形貌相違、法軌有別，並不聽許他們傳授戒法，所以受授五戒等必須由出家人傳授，其中的用意便清晰可見。

【1575-0013】03_業疏/02a_卷一之二#9
【原文】三能秉制意中，初敘立意，二「良」下推所以。初中「生善」之言，通於自他、世及出世。事即眾別行相，僧非事則不能生善，事非法不立，法非人不弘，則知事法竝依人矣。次所以中，初敘勝能，五眾皆為解脫出家，能生他福，故喻如田；「勝業」即羯磨。「何」下次舉事顯，「果向」即四果四向，「未許傳授」者，此明雖聖而非師也；五八二戒通五眾授，此明雖居下眾，即堪軌物也
【譯文】在第三「能秉御僧」的制戒用意中，起初敘述立意的宗旨，第二自「良」以下推究其所以然。第一部分中，「生善」這句話通於自己與他人、世間法以及出世間法。「事」就是大眾與個人的行持相貌，僧伽若沒有具體法事就不能生善，法事若沒有法軌就不能成立，法軌若無人就不能弘揚，由此可知事相與法軌都依賴於人。在第二部分推究所以然中，起初敘述殊勝的功用，五眾都是為了求得解脫而出家，能夠為他人出生福德，所以比喻為良田；「勝業」就是指羯磨。自「何」以下接著舉出事例顯發，「果向」就是四果四向，「未許傳授」是說明雖然位列聖者卻不可作為傳戒師；五戒與八戒通通聽許由出家五眾傳授，這是說明雖然位居下眾，卻堪能做他人的軌範規範。

【1575-0014】03_業疏/02a_卷一之二#10
【原文】言僧伽者，中梵本音，此土無名，比眾以譯，有加和合，乃是義用。故文云：「僧者四人若過，和者羯磨說戒。」即如經律佛法眾也
【譯文】所說的「僧伽」，是中印度梵語的本音，此地沒有完全對應的名詞，便比附「眾」字來翻譯，有的加上「和合」，則是取其義理與作用。所以律文說：「僧是指四人或者超過四人，和是指一同行羯磨與說戒。」正如經律中所說的「佛、法、僧（眾）」那樣。
