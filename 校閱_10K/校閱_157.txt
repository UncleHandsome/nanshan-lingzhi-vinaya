# 校閱材料　第157檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【157-0001】01_行事鈔/07c_卷中之三#35
【原文】著新衣戒六十。四緣：一是三衣，二是己物，三不染壞，四無緣輒著犯。《善見》：若遭賊緣等，得權著五大色衣。《四分》：新衣者，若是新衣，若初從人得。《十誦》：得他故者，初得故，亦名新衣。《四分》云：壞色者，若青、黑、木欄也。彼得衣不作三種壞，著者墮。若重衣、若輕衣，不作淨而畜者吉羅。若非衣、鉢囊、革屣囊、針線囊、及諸巾，不作淨畜者吉羅。若未染衣，寄白衣家者吉羅。《五分》：所以淨者，異外道故；令與俗別；三種記故，失則易覓。《多論》：五大色衣，不成受。黃者，欝金根、黃藍染；赤者，落沙染；青者，藍黛染。若自染吉羅，不成受。應量、不應量，一切不得著；若點著，吉羅。更改如法色則成受。若先如法色，後以五大色者，不成受。若以五大色點淨者吉，還用青黑木欄三種，更互作點。若衣先已作淨，後更染色，不須更點；先已作淨，後洗脫，不須更淨。故紫草、柰皮、柏皮、地黃、絳緋色、黃櫨木，皆不如法色；以如法色覆，即成受也。《僧祇》：憍奢耶衣、欽婆羅衣、細耎者，染汁麁澁，損壞。佛言：如是好衣，二種淨：一割縷淨，二點淨。餘衣三淨，加一染法。青者，銅器覆苦酒甕上，著器者是；藍澱青、石青、硿青，不持是等作淨。黑者，諸果汁合一鐵器中作泥，若池井泥亦爾。水欄者，用上果，生鐵上磨，作點淨。餘如衣法中分別。《十誦》：作淨色者，謂以別色相點，如青衣以泥棧淨，餘互淨亦爾。《多論》：除靴履，一切並點淨。《十誦》：若衣不淨，試著吉羅。《五分》：得革屣，令本主著，下至五六步。《僧祇》：作淨者，極大齊四指，極小如豌豆。不得並作，或一三五七九。不得如華形作。若浣褻有泥污、鳥足污，即名為淨。若新僧伽梨，趣一角作；乃至一切衣、新細揲亦爾。若眾多碎衣一處合補者，一處作；別者一一作淨。
【譯文】穿著新衣未染壞色戒第六十。具備四個條件構成犯戒：一是所穿之物是出家三衣；二是屬於自己的物品；三是沒有用如法染料染色或作點淨（壞色）；四是沒有特殊因緣而擅自穿著，即犯波逸提。《善見律毗婆沙》說：如果遭遇盜賊搶劫等危難因緣，得以權宜穿著五大正色之衣。《四分律》說：所謂新衣，是指織造剛製成的新衣，或者是剛從別人那裡初次獲得的衣服。《十誦律》說：即使得到的是別人的舊衣服，因為是自己初次得到，也稱為新衣。《四分律》說：壞色，是指青色（銅青、灰青）、黑色（鐵泥黑）、木欄色（赤褐色）。比丘得到新衣如果不用這三種顏色作點染破壞純色，穿上了就犯波逸提。如果是不論厚重衣或輕薄衣，不作淨法而畜持的，犯突吉羅。如果是三衣之外的其他布物、鉢袋、皮鞋袋、針線包、以及各種手巾手帕，不作淨法就畜持的，犯突吉羅。如果尚未染壞色的布料，寄存在俗人家中的，犯突吉羅。《五分律》說：之所以要作點淨壞色，一是為了不同於外道，二是要與世俗在家人有別，三是以三種記號做標記，一旦遺失便於尋找認領。《薩婆多論》說：五大正色（純黃、純赤、純青、純黑、純白）製成的衣服，受持不能成立。所謂黃色，是指用鬱金根、紅藍花染出的純黃；赤色，是指用落沙（茜草或紅膠）染成的正紅；青色，是指用藍黛染出的純青。如果是自己親手染成這五大正色的，犯突吉羅，且衣物受持不成立。不論尺寸合量或不合量，全都不准穿著；若只點在衣服上穿著，也犯突吉羅。必須重新改染為合法的如法色，受持才能成立。如果原先是如法色，後來又染上五大正色，受持便失效。如果用五大正色來點淨作記號，犯突吉羅，還是必須使用青色、黑色、木欄色這三種顏色，相互交叉作點記。如果衣服原先已經作過點淨，後來重新染色，不需要再次作點淨；原先已經作過點淨，後來清洗時點記脫落，也不需要重新作淨。因此，紫草染成的紫色、柰樹皮染的色、柏樹皮染的色、地黃染的色、絳紅色與大緋色、黃櫨木染成的黃色，全都不是合乎戒律的如法色；必須再用合法的如法色覆蓋改染，受持才能成立。《摩訶僧祇律》說：憍奢耶衣（野蠶絲綢衣）、欽婆羅衣（毛織氈衣）等細緻柔軟的衣料，若是用粗澀的染汁浸染容易損壞。佛陀說：像這等精美的衣服，有兩種作淨法：一是裁割成條縫綴的「割縷淨」，二是塗點顏色的「點淨」。其餘衣服則須具備三種作淨法，即在上述二淨之外再加上一道染色法。青色，是指用銅器覆蓋在苦酒（陳醋）甕上，器皿表面凝結生成的銅青就是；藍澱青、石青、硿青，不准用這些礦物植物純青來作淨。黑色，是指將各種富含鞣酸的水果汁液混合在鐵器中研磨成的鐵泥，池塘或水井深處沉積的黑泥也是這樣。木欄色，是用上述的果汁在生鐵上研磨調製，用來作點淨。其餘詳細規範如〈衣法〉中所分別。《十誦律》說：作淨色，是指用相異的顏色作斑點記號，例如青色的衣服用泥土作黑斑點淨，其餘顏色互相點染作淨也是如此。《薩婆多論》說：除了皮靴皮鞋外，其餘一切衣物全都要作點淨。《十誦律》說：如果衣服未作點淨，試穿也犯突吉羅。《五分律》說：得到新的皮鞋，應當讓原主人先穿著走動，至少走上五、六步。《摩訶僧祇律》說：作點淨標記時，最大不得超過四指寬，最小如同豌豆大。點記不得排成並列，點數或是一、三、五、七、九個點。不得畫成花朵的形狀。如果洗滌揉搓時沾有泥污、或是鳥爪踩踏的污漬，也可以直接算作已作淨。如果是新製的大衣（僧伽梨），只在一處衣角作點淨即可；乃至一切衣物，新補綴的小塊布片也是如此。如果有許多塊碎布拼合在同一處補綴的，只在一處作點淨即可；如果是分散在不同處的，則每一塊都要各自作點淨。

【157-0002】01_行事鈔/07c_卷中之三#36
【原文】奪畜生命戒六十一。《多論》：一出家之人，四等為懷；乃加殺害，違慈非憫。二自損惱他，生死根本，障道惡業故。三為長信敬，息誹謗故。五緣成，同前大殺戒。
【譯文】斷奪畜生生命戒第六十一。《薩婆多論》提出制定此戒的用意：第一、出家人應當心懷四無量心（慈、悲、喜、捨四等心）；如果竟然加以殺害，這是違背慈心、全無悲憫；第二、殺生既損害自己的功德，又極度惱害其他眾生，這是流轉生死的根本，是障礙證道的重大惡業；第三、是為了增長世人的信心與崇敬，平息世俗的譏嫌毀謗。具備五個條件即構成犯戒，其結罪行相與前文殺人大戒相同。
