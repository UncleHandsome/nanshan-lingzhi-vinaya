# 校閱材料　第176檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【176-0001】02_戒疏/16b_卷四上之一#148
【原文】【記】第五，制意中，初科有三。初敘過明制。初二句明在家二眾，次二句即出家小眾。「近」下四句，正示制意。「所以」下，次示緣顯開。初明同在家人意。謂僧有緣，寄止俗舍，下引《十誦》，即明白衣來僧坊住，此中且據一相為言。「泊」，止也。「又」下，次明同未具意。「憑廕在此」，即指師僧。「是以」下，雙結二教之益。
【譯文】【記文】第五在制戒意圖之中，第一科包含三個層面。首先敘述過失以說明制戒的緣由。前兩句是說明在家的信眾男女，後兩句是指剛出家的沙彌等小眾。「過於親近」以下四句，正式指明制戒的意圖。「所以」以下，接著說明因緣以彰顯開許的用意。首先說明開許與在家人同宿的意圖。這是指比丘有因緣行腳，寄居借宿在俗人家中，下文引述《十誦律》，則是說明在家人來到寺院僧坊借住的情況，此處暫且依據行腳寄宿這一種相貌來說明。「泊」，就是止宿的意思。「又」以下，接著說明開許與未受具足戒的沙彌同宿的意圖。「完全依賴投靠在此」，就是指依止師長僧眾。「因此」以下，雙雙總結開、制二教的益處。

【176-0003】02_戒疏/16b_卷四上之一#150
【原文】【疏】就戒緣中，初同俗宿，過起令制。後在拘睒彌國，因羅睺遂開三宿。《十誦》：「告諸比丘：『沙彌可憐，既無父母，汝若不愍，何由得活？若遇苦惱，親里亦瞋，云「但能畜，不能守護」。為二利故，得與同宿：一、為沙彌，二、為白衣來僧坊故。』」

【176-0004】02_戒疏/16b_卷四上之一#151
【原文】【記】次緣相中。初點文。「初同俗宿」，即六群緣。「後因羅睺」者，具云羅睺羅，此云障蔽，以障佛出家，猶修羅障蔽日月故。《律》因佛制戒已，諸比丘言「當遣羅云出」。時羅云無屋住，往廁上宿。佛知之，往廁所問已，便云：「愚癡比丘，無有慈心，乃驅小兒出！況是佛子，不護我意耶？」《十誦》下，次引示。前敘未具。下明二利，即通俗流。
【譯文】【記文】在第二個緣起相貌中。首先點明文句。「最初與俗人同宿」，就是指六群比丘的這段因緣。「後來因為羅睺羅」，全稱是羅睺羅，翻譯為「障蔽」，因其出生障礙了佛陀出家，如同修羅障蔽日月一般。《四分律》記載因為佛陀制定了這條禁止同宿的戒律之後，比丘們便說「應當把羅雲趕出去」。當時羅雲年幼沒有地方可住，便跑到廁所裡過夜。佛陀知道了這件事，親自前往廁所詢問過後，便責備說：「愚癡的比丘，毫無慈悲之心，竟然把小孩子趕出房間！何況這還是我的佛子，你們怎麼一點都不體貼我的心意呢？」從「十誦律」以下，接著引證說明。前半段敘述對待未受具戒的沙彌。後半段說明兩種利益，這就涵蓋了世俗一般信眾。

【176-0008】02_戒疏/16b_卷四上之一#155
【原文】【疏】一、是未受具人男女。昔云：「男犯非女犯，以制隨宿罪，義無三夜開。」今解二俱犯，故《伽論》云：「曾前與男二夜，第三夜與女宿，隨臥轉側犯二墮也。」
【譯文】【疏文】一、對方是未受具足戒的男子或女人。過去有人主張：「此戒只在對方是男子時才犯，若是女人則不犯，因為對女人同宿隨時都會犯前一條同室宿戒，在法理上絕沒有開許過夜三宿的道理。」如今的正確解釋是兩者都犯，所以《摩得勒伽論》說：「先前如果已經與男子同宿了兩夜，第三夜又與女人同宿，那麼隨著躺臥與翻身轉側，同時觸犯兩個波逸提墮罪。」

【176-0009】02_戒疏/16b_卷四上之一#156
【原文】【疏】二、室相成。三、同宿。四、知同。五、過三夜犯。《多論》四句，人一室異，乃至人室俱異，皆犯。
【譯文】【疏文】二、房舍隔間的格局成立。三、同處在一室中過夜。四、心中明知同處。五、超過了三夜的期限便構成犯罪。《薩婆多論》提出四句分析：人同而房間換了，乃至人換了而房間也換了，全都構成犯罪。

【176-0010】02_戒疏/16b_卷四上之一#157
【原文】【記】犯緣，列示中。初緣通男女。昔謂女人自犯前戒，故局男犯。彼以意裁，今憑教斷，《伽論》二墮，豈非明據？下引《多論》，四句並犯者，恐謂人室同犯，異不犯故。人一室異，室一人異，二俱，比上可會。
【譯文】【記文】在列舉說明的犯罪因緣中。第一項因緣通於男性與女性。過去的人認為女人自身已經在前一條戒中規範了犯相，所以本戒只局限於男性對象。那是他們憑藉私意裁決，如今我們是依憑佛經論教來判定，《摩得勒伽論》明文判定結犯兩個墮罪，這難道不是最確鑿的明證嗎？下文引述《薩婆多論》，指出四種分析情況通通算犯戒，這是擔心有人誤以為必須人與房間都完全相同才算犯戒、只要有一項變換就不犯的緣故。人相同而房間換了，房間相同而人換了，人與房間全都換了，拿上述道理來對照即可完全理解。

【176-0012】02_戒疏/16b_卷四上之一#159
【原文】【疏】問：「如此宿戒，初令禁宿，後開三夜，同制一戒。何故『觀軍』初制直見，後開三夜，別立戒本，直見還犯者何邪？」
【譯文】【疏文】有人問：「如同這條過限宿戒，起初是全面禁止同宿，後來開許可以同宿三夜，將開遮統攝在同一個戒條中。為什麼『觀軍戒』最初是制定只要去看就犯戒，後來雖然開許可以停留三夜，卻另外單獨成立一條戒本，而直接去看依然算犯戒，這又是為什麼呢？」

【176-0013】02_戒疏/16b_卷四上之一#160
【原文】【疏】答：「未受同宿戒，本犯由於宿，後開二、三夜，永無初宿犯。軍本由觀犯，後緣開三夜，別戒過三犯。觀軍不是宿，猶有觀軍犯。」

【176-0034】02_戒疏/16c_卷四上之一#14
【原文】【疏】凡理藉言通，教為表義。言辨理通，詞亂義隱，通益智明，隱增情感。故《多論》中制有四意：「初為異外道；二、師資位別；三、為分別言章須了；四、依實義，不在音聲。」具斯四益，所以一制。
【譯文】【疏文】大凡至理需要憑藉言語才能通達，教法是用來彰顯意理的。言語清晰明瞭則道理通達，言詞雜亂則法義隱晦；道理通達有助於智慧光明，法義隱晦則會增長凡情執著。所以《薩婆多論》記載佛陀制定此戒有四種深意：「第一是為了有別於外道；第二是為了使師長與弟子的位次有別；第三是為了分別章句言辭必須清晰明白；第四是為了依循實質義理，不在於追求聲音歌詠。」具備這四種利益，所以制定了這一條戒。

【176-0035】02_戒疏/16c_卷四上之一#15
【原文】【記】第六，制意中。初敘教功。此言「理」者，須通二種，謂真如諦理、世俗道理。諦理絕相，道理微隱，非言不顯，故「藉言通」。「教」即三藏，該乎大小。言以通理，教以彰義，此之二句，並顯教功。「言辨」下，次明誦習損益，發起制意。《多論》「四意」，以翻四過：一、有法式，西竺外道多合誦故；二、有尊卑；三、能詮不亂；四、所詮不隱。教為顯義，故不在聲。若許同誦，但逐音聲而不解義，深乖教意。
【譯文】【記文】科判第六條，解釋制定戒律的用意（制意）。最初敘述教法的功用。這裡所說的「理」，必須通達兩種，也就是真如諦理與世俗道理。真如諦理絕離一切名相，世俗道理微細隱微，若非言語便無法顯發，所以說「藉言通」。「教」就是指三藏，含攝了大乘與小乘。言語用以通達至理，教法用以彰明法義，這兩句話都彰顯了教法的功用。「言辨」以下，接著說明誦讀研習的損益，以此發起制戒的本意。《薩婆多論》的「四種用意」，是用來翻轉四種過失：第一是具備威儀法式，因為西印度外道多半齊聲合誦；第二是明辨尊卑次序；第三是使能詮的文句不紊亂；第四是使所詮的義理不隱晦。教法本是為了顯發實義，所以重點不在於音聲。如果允許一同合誦，大家只會一味追求聲音整齊而不解義理，這就深深違背了教法的本意。

【176-0049】02_戒疏/16c_卷四上之一#29
【原文】【記】戒本，第三。須明三相。言「句義」者，如諸經偈頌，一偈半偈，義意已足，同誦無差，故《律》舉「諸惡莫作」一偈為例。「非句義」者，抄前輒誦，文義不辨，故云「非」也。二、「句味」者，一句之下，即見理味，《律》舉「眼無常」等為例。「非句味」，同上。三、「字義」者，「字」即文字，字下有義，如訓釋等，《律》舉「阿、那、波、遮、那」為例，今時所誦密語之類。「非」，亦如上。文中，初總示。三是三非，故「為六」矣。「言」下，別釋。第一對中，初釋「句義」，「同」、「抄」兩犯。「憲章」即犯科。「句味」下，指餘兩對，例同上解。
【譯文】【記文】科判解釋戒本第三句。必須明瞭三種行相。所謂「句義」，就像各種經典中的偈頌，一偈或半偈，文義意旨已經具足，齊聲同誦毫無參差，所以《律》本舉出「諸惡莫作」這一偈為例。「非句義」，是搶在他人之前擅自接誦，導致文意無法辨明，所以稱為「非」。第二所謂「句味」，是指一句話之下就能顯現至理的法味，《律》本舉「眼無常」等為例。「非句味」的道理同上。第三所謂「字義」，「字」就是文字，單字之下含藏深義，例如訓詁解釋等，《律》本舉「阿、那、波、遮、那」等梵字為例，就像今日所念誦的密咒之類。「非字義」也如同上述。疏文中，最初總括指示，三種「是」與三種「非」相對照，所以「分為六種」。「言」字以下，分別解釋。在第一對當中，先解釋「句義」，齊同與搶截兩種情況都構成犯戒。「憲章」就是指犯戒的科條。「句味」以下，指示其餘兩對，依此類推如同上文的解釋。

【176-0051】02_戒疏/16c_卷四上之一#31
【原文】【記】第四句。初點別本文闕。今《刪定戒》，例亦除之，或恐彼文寫脫。文牒「經法」，《戒本》亦無「經」字。「但」下，顯制。「凡聖」者，即注中四人，前二是聖，後二即凡。「通真俗」者，若論二諦，佛亦通談，今但通取出世理教為真。若佛所說，詮理化物，俱得名「真」。自餘三人，並通真俗，印可同真，不者皆俗。詮真之教，開物示道，同抄則不顯，故云「翳」也。下引《律》、《論》決通，可知。準此二文，今世疏、論、傳、集，多編入藏，並非正犯。
