== PROBLEM ==
字義誤解。「晏齋」之「晏」為遲晚之意，指過午晚食齋飯（犯非時食）；譯文望文生義誤將「晏」解作「宴席」，譯為「過午宴飲」。

== SUGGESTION ==
改為「夜間食粥、過午晚食齋飯，妄稱是隨方風土；」

== ORIG ==
`夜粥晏齋，謂是隨方。`

== CURRENT ==
這句承接上文而引出下文。接下來四句說明其混同世俗之流，「事」是指口中所說之事。「研」字以下，列舉長年積累學識的智者來做比況；「冥頑假託」是指對事情的原委一竅不通，盲目混亂地行事；「體」就是理解了達。在揭露過失的四個要點中，首先說明混淆教規：自身所行違背戒制，卻妄稱完全依循律典，所以說是混淆寄託；「法司」是指律宗法席；律法實質並非如此，愚人卻自以為是，因此造成教法紊亂。這就是世間一些學律者說律教人的通病：自己買賣違制蠶衣，卻藉口說是遵從王法；夜間食粥、過午宴飲，妄稱是隨方風土；
