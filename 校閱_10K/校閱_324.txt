# 校閱材料　第324檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【324-0001】02_戒疏/01d_卷一上之一#21
【原文】【疏】問：「上列四種異執不同。既是一化所宗，俱會聖道，何得更執？豈曰達人？」
【譯文】【疏文】有人提問：「上面所列出的四種相異見解與執著各有不同。但既然都是同一位世尊教化之下的正統宗派，最終都能契會於聖道，為什麼還要彼此堅執己見呢？這難道還能稱得上是通達真理的人嗎？」

【324-0002】02_戒疏/01d_卷一上之一#22
【原文】【記】問中。初二句牒前。「既」下，立難。「一化宗」者，師稟同故。「俱會道」者，所證一故。「更」字平呼，互也。
【譯文】【記文】提問之中。前兩句重述前面的內容。「既然」以下，正式提出詰難。「同一化導的宗派」是指大家所承接傳承的導師都是相同的。「都能契會於聖道」是指大家最終證得的果位是一致的。「更」字讀作平聲，是「互相」的意思（而非讀作去聲的「再度」）。

【324-0003】02_戒疏/01d_卷一上之一#23
【原文】【疏】答：「理本一也，悟有淺深，由機涉明昧，計有利鈍。故入觀也，人法俱亡，及其出也，不無緣習。教約相動，隨義以張；道據正理，分通會契。」
【譯文】【疏文】回答說：「至理本來是同一不二的，但個人的領悟卻有深淺的不同，這是由於各人的根機涵蓋著明朗與昏昧的差異，思維見解上也有敏銳與遲鈍之別。所以在深入禪觀之時，所觀的人境與能觀的心法雙雙泯除亡失（能所雙亡）；而當出定之時，卻免不了仍會攀緣過去的習氣。教法是依循名相事相而興起施設，隨順不同的義理而鋪陳開展；至道則是依憑絕對的真理而立，各派雖隨順不同法門分途深入，最終皆能融通契合於真理。」

【324-0004】02_戒疏/01d_卷一上之一#24
【原文】【記】答中二。初約理解正答。「理本一」者，答上「會聖」。「悟淺深」下，答上「更執」。「故」下，約觀行證成。「人」謂體析所觀，「法」即反照能觀。病除藥去，故云「俱亡」。「緣習」謂心緣舊習。入觀照理，理空故同；緣習隨事，事有故異。「教」下，申教道所以。「教約相」者，有所示故。「動」猶興也。相必有別，不可一致，故「隨義張」。「正理」即真空。離相無二，隨門得入，故云「分通」。
【譯文】【記文】回答的內容分為兩層。首先就真理的體認作正面回答。「至理本來是同一的」，是回答上面「都能契會於聖道」的疑問；「個人的領悟有深淺」以下，則是回答上面「為何彼此堅執」的疑問。「所以」以下，透過觀行實修來證實此一觀點。「人」是指所觀析的人相境，「法」則是指反照境象的能觀心法。執病的障礙既已消除，對治的藥法亦不再留存，所以說所觀的人與能觀的法俱皆泯除。「緣習」是指心念攀緣過去熟悉的習慣觀念。入定照見實相時，由於理體本空，所以彼此見解相同；出定後攀緣舊習隨順事相，而事相各別，所以便產生了差異。「教法」以下，闡明施設教化之道的緣由。「教法依循事相」是指必須有所指示啟發。「動」就是興起發生的意思。事相必定各有分別，無法整齊劃一，所以要「隨順義理開展」。「絕對的真理」就是真空實相。遠離一切虛妄事相則無二無別，修行者隨順不同的法門都能契入，所以說「分途深入而融通」。

【324-0005】02_戒疏/01d_卷一上之一#25
【原文】【疏】「故《無量義》云：『法水一也，江河井池分其異耳。初說四諦，本為聲聞，八萬諸天，發大道意。』用斯文證，何得懷疑？」
【譯文】【疏文】「因此《無量義經》說：『佛法的法水本來是同一的，只不過隨著江河、井池等不同容器而顯現出差別罷了。佛陀最初宣說四諦法，本意是為了聲聞人說的，然而在座卻有八萬諸天，當下發起了求取無上菩提的大道心。』用這段經文作為證明，還有什麼好心存疑惑的呢？」

【324-0006】02_戒疏/01d_卷一上之一#26
【原文】【記】引證中。「法水」喻理一，「江河」喻機差。「初說」等者，經中顯示一異之相。彼續云「次說方等、摩訶般若、花嚴海空，而百千比丘，無量人天，得須陀洹，乃至辟支」等。「八萬」，《經》作「八億」。
【譯文】【記文】引經印證的部分。「法水」用來比喻真理的唯一，「江河」用來比喻根機的千差萬別。「最初宣說」等句，是經文中用來顯示「同一」與「相異」的事實相貌。該經接下來說「隨後宣說方等經、大般若經、華嚴海空法門，而當時有百千比丘、無量的人天大眾，證得了須陀洹果，乃至證得辟支佛果」等等。疏文中的「八萬」，在《經》的原文中作「八億」。

【譯文】【疏文】《大方等大集經》說：「夢中見到一整段（匹）細棉布（氎布），後來被撕裂分成了五份。」

【324-0010】02_戒疏/01d_卷一上之一#30
【原文】【疏】「佛告長者：我滅度後，有諸弟子，顛倒解義，及以說法，覆隱法藏，名『曇摩毱多』。」此云「法正」，律名《四分》。凡解行法，先果後因。此就化儀，說相明顯，故倒解之。如四諦法，苦初道後，覆彼常途，因先義也。
【譯文】【疏文】經中說：「佛陀告訴長者：我滅度之後，將會有一些弟子，倒反常規地去理解教義，並以此宣揚說法，遮蔽掩蓋了正法寶藏，這一部派名叫『曇摩毱多』。」這裡翻譯為「法正」，所傳持的律法名稱叫作《四分律》。大凡解釋修行的法則時，都是先講果報、後談前因。這是就化導眾生的儀軌而言，為了讓說法的相貌清楚易懂，所以採取倒轉順序的方式來解說。正如四聖諦的教法，苦諦放在最前面，道諦放在最後面，遮蔽掩蓋了世間通常所循的因在果先的常規義理。

【324-0011】02_戒疏/01d_卷一上之一#31
【原文】【記】初師中。初通敘諸計。「顛倒」下，正示初師。初總敘見解、人、法、名號。「倒解」約自見，「倒說」約化他。「凡」下，別釋見解，初二句標示。且舉「果因」，餘皆類此。「此」下，正釋。謂是此師「化」物「儀」式。先示果相，後推其因。苦集世間果因，滅道出世果因。若從次第，合云集苦道滅。欲使知苦斷集，為滅修道，先解後修，教行易識。若據四諦，本是佛說，而言「曇摩」者，佛作倒說，本為隨宜，曇摩計此，用為常度故也。由倒解故，即是「覆隱」。
【譯文】【記文】在第一位大師的內容中，首先通泛敘述各派的執著見解。「顛倒」以下，正式指出第一位大師的情況。首先總結敘述他的見解、人物、法脈以及名號。「倒反理解」是就個人的自心見解而言，「倒反宣說」則是就教化他人而言。「大凡」以下，分別解釋其見解，前兩句予以標示說明。暫且列舉「果因」為例，其餘義理皆可依此類推。「這是」以下，正式進行解釋。這是指這位大師在「化」導有情時所採取的「儀」式。先展示果報的相貌，然後推求它的根源種因。苦集二諦是世間的果與因，滅道二諦是出世間的果與因。若依照因果的先後順序，應當說是集、苦、道、滅。之所以先說苦後說集、先說滅後說道，是為了讓眾生先知苦而後斷集，為了證滅而修道；先理解果相，然後才去起修，教法與行持才容易通曉明瞭。若按照四諦的道理，本來出自佛陀宣說，此處之所以歸之於「曇摩（法正尊者）」，是因為佛陀作顛倒次序的宣說本是隨順機宜的權巧方便，而曇摩鞠多尊者卻執持這種說法，將其作為常規法則。正由於這種顛倒的理解，所以說是「覆隱」了正法藏。

【324-0012】02_戒疏/01d_卷一上之一#32
【原文】【疏】二、彼《經》云：「受有三世及以內外，善能論議，破壞外道說一切性悉得受戒，凡所難問，善能答對，名『薩婆諦婆』。」此云「有」也，法名《十誦》。然異道所計「誅惡人畜、道路女人陵皆無罪」，此部難言：「但殺得罪，何簡善惡？戒出離因，要身器淨，非一切性悉得受故。」
【譯文】【疏文】第二，《大集經》說：「執持萬法實有於過去、現在、未來三世以及內身、外境之中，極其善於論議辯駁，能徹底破斥外道『主張一切有情皆可受戒』之說，凡是一切刁難詰問，都能巧妙應對回答，這一部派名叫『薩婆諦婆』。」這裡翻譯為「有」，所持的律法名稱叫作《十誦律》。然而外道所執持的邪見認為「殺死凶惡的人與畜牲、在半路上侵犯女性，全都沒有罪過」，這個部派便詰難反駁說：「只要行殺戮就會得罪，何須區分善惡？戒法是超脫生死的修因，必須身心為法器且清淨無染，並非一切種類的有情都能夠受戒的。」
