# 校閱材料　第039檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【039-0001】02_戒疏/02a_卷一上之二#42
【原文】【記】通名中，二。初約義略釋。上三句顯益。「近遠」二字，必對因果。「二死」者，一曰分段，三乘共亡；二曰變易，唯佛永盡。「希」下一句結名。「希世」者，世間無故。「獨達」者，超諸有故。「故」下，引文廣釋。
【譯文】【記文】在解釋三寶通名的科判中，分為兩部分。首先依據義理作簡略解釋。前三句顯明三寶的利益。「近」與「遠」兩個字，必定分別對應修行因地與果位的不同。所謂「二死」，第一稱為分段生死，三乘聖者共同滅除斷盡；第二稱為變易生死，唯有究竟佛果才能永恆斷盡。「希」以下一句是總結立名的由來。所謂「希世」，是因為世間根本不存在此種德能。「獨達」，是因為遠遠超脫了一切三界輪迴。「故」字以下，引用論典經文詳細闡釋。

【039-0002】02_戒疏/02a_卷一上之二#43
【原文】【記】今用四種三寶，對此六義。
【譯文】【記文】現在運用四種三寶的分類，來對應這六種意涵。

【039-0003】02_戒疏/02a_卷一上之二#44
【原文】【記】初義通四。住持，無信不遇；化相，無緣不遇，舍衛三億，可以明之；理體局聖，凡愚不遇；一體，二乘不遇。
【譯文】【記文】第一種稀有義，貫通於四種三寶。對於住持三寶，沒有純淨信仰的人無從得遇；對於化相三寶，沒有成熟善緣的人無從得見，例如舍衛城三億人不知不聞佛陀，便足以證明這點；理體三寶唯局限於出世聖者，凡夫愚夫無法得見；一體自性三寶，則是滯留二乘之人未能徹證得見。

【039-0004】02_戒疏/02a_卷一上之二#45
【原文】【記】第二義中，唯約理寶。《歸敬儀》云：「住持三寶，體是有為，具足漏染。」又云：「化相體是無常，四相所遷，滅過千載，但可追遠，用增翹敬。」據後一體，在迷隨染。故此三種，皆無此義。
【譯文】【記文】第二種離垢義，唯獨就理體三寶而言。《歸敬儀》中說：「住持三寶的本體屬於有為生滅法，仍然具足有漏與雜染之相。」又說：「化相三寶的本體具有無常之性，被生住異滅四相所遷流推移，佛滅度至今已過千載，今日只能追憶遙念，用以倍增虔敬仰慕之心。」若論及後面的自性一體三寶，在凡夫迷執時依然隨順著雜染而沉淪。所以這其餘三種，都不具備離垢義。

【039-0005】02_戒疏/02a_卷一上之二#46
【原文】【記】第三喻中，六通在人，唯對化相。神境、他心、天眼、天耳、宿命、漏盡，六皆明徹，總號為「通」。「毒」謂苦惱，下云寶能現除貧苦，與此頗同。
【譯文】【記文】第三種勢力譬喻中，六種神通依止於人身，唯有對應於化相三寶。神境通、他心通、天眼通、天耳通、宿命通、漏盡通，這六種都透澈明朗，總括統稱為「神通」。「毒」是指眾生的種種苦惱，下文說世間珍寶能現世拔除貧窮苦難，與此處頗為相符。

【039-0006】02_戒疏/02a_卷一上之二#47
【原文】【記】第四通四。住持、化相，能發信仰；理體、一體，可以修證：皆是「嚴身」。
【譯文】【記文】第四種莊嚴義，貫通於四種三寶。住持三寶與化相三寶，能啟發引導世人內心的正信；理體三寶與一體三寶，則能作為行者親自修習證悟的依歸：這些全都能夠用來「莊嚴法身」。

【039-0007】02_戒疏/02a_卷一上之二#48
【原文】【記】第五亦通四。餘三易解。住持佛法，雖是世物，莫不表示法身功用無極。《儀》云：「金木石土，體是非情，以造像故，敬毀之人，自獲罪福。」故知此寶，得名「無上」。法亦準同。剃染之僧，為世福田，人天中勝。破戒惡行，猶過外俗，況餘持奉，其勝可知。
【譯文】【記文】第五種最勝義，同樣貫通於四種三寶。其餘三種容易理解。住持佛寶與法寶雖然屬於世間物質形相，但無一不是象徵表露法身功德妙用的無窮無盡。《歸敬儀》說：「金屬、木頭、石頭、泥土，本體雖然屬於無知無情之物，但因為被塑造為佛像的緣故，前來禮敬或加以毀損的人，自身便會獲得無量福德或罪障。」由此可知連這住持佛寶，都能獲得「至高無上」之名。住持法寶也是同樣的道理。剃髮染衣的僧寶，作為世間的大福田，在人道天道之中最為尊貴殊勝。即便是有破戒惡行的比丘，其出世身分依然超越世俗常人，何況其餘精嚴持戒奉持律儀的僧眾，其殊勝無上更是不言而喻。

【039-0008】02_戒疏/02a_卷一上之二#49
【原文】【記】第六唯局理寶。《儀》云：「此之三寶，常住於世，不為世法之所陵慢。」一體雖常，然就迷邊，隨緣流變；餘二無常，非所論矣。「八法」者，《智論》云：衰利毀譽，稱譏苦樂，四違四順，能動物情，名為「八風」。理寶人法，皆是出世無漏聖道，不為八法之所動故。
【譯文】【記文】第六種不改義，唯獨局限於理體三寶。《歸敬儀》說：「這理體三寶常住於世間，絕不為一切世俗生滅法所凌辱侵害。」一體三寶本性雖然常住，然而就迷執的層面而言，仍隨緣產生遷流變異；其餘兩種本體無常，更非此處所論。「八法」，《大智度論》說：衰落、利益、毀損、名譽、稱讚、譏諷、痛苦、快樂，這四種違逆、四種順應之境，最能牽動凡夫的心情，所以名為「八風」。理體三寶中的行者與正法，全都是超越世間的無漏聖道，絕不會被世間八風所動搖。

【039-0015】02_戒疏/02a_卷一上之二#56
【原文】【疏】一、理體者，如五分法身為佛寶，滅理無為是法寶，聲聞學、無學功德是僧寶。

【039-0018】02_戒疏/02a_卷一上之二#59
【原文】【疏】四、一體者，如常所論，唯約心體，義分三相，如《涅槃》說三寶同性等。
【譯文】【疏文】第四、一體自性三寶：如同各部經論平常所論述的，純粹就眾生一念心體而言，在義理上分出三種相狀，正如《大般涅槃經》中所說三寶同具一個法性等義。

【039-0019】02_戒疏/02a_卷一上之二#60
【原文】【記】初明理寶，文出《多論》。「五分」者，戒、定、慧，從因受名，解脫、解脫知見，從果彰號。由慧斷惑，惑無之處，名解脫。出纏破障，反照觀心，名解脫知見。「滅理」，四諦、滅諦、涅槃。「學、無學」者，初果已去，同見真諦，名理和僧。然此理寶，亦即同體，但望佛、僧證理邊為別。故《多論》云：「佛亦是法，法亦是佛，僧亦是法。止是一法，相有差別，故分三寶。」

【039-0055】02_戒疏/02a_卷一上之二#96
【原文】【記】答中，初文。上二句縱許來問。「語」下，奪歸前解。上二句明一體劣，下二句顯理寶勝。理體雖一，生、佛異故。「故」下，引證。《迦葉問品》云：「善男子，或有佛性，一闡提有，善根人無。或有佛性，善根人有，一闡提無。或有佛性，二人俱有。或有佛性，二人俱無。善男子，我諸弟子若解如是四句義者，不應難言一闡提人定有佛性，定無佛性。若言眾生悉有佛性，是名如來隨自意語。」《經》明如來有三種語。前後三句，方便教中隨他意語。「俱有」一句，「一切悉有」，名隨自意語。又《經》云：「若說一切眾生悉有佛性，煩惱覆故，不能得見。我說如是，汝說亦爾，是名『隨自他意語』。」《經》明四句，此中略舉二俱，以證生、佛之異。「二人」即闡提、善根也。望佛所證，則二人「俱無」；望凡皆具，則二人「俱有」。「明知行果」即指如來修證，《經》云「十住菩薩少分見性」，故知唯佛證性究竟。凡夫但具，何得相擬？
【譯文】【記文】在回答科判的最初部分。上面兩句先順從認可來問者的觀點。「語」字以下，隨即扭轉回歸前述的定解。上面兩句說明一體自性三寶在凡夫分上的低劣，下面兩句顯明理體三寶在修證上的殊勝。理體的本質雖然是一致的，但眾生與佛陀在事相證境上卻有天淵之別。「故」字以下，引用經文為佐證。《大般涅槃經．迦葉菩薩品》說：「善男子，或者有一種佛性，一闡提人有，而具足世間善根的人反而沒有。或者有一種佛性，具足善根的人有，而一闡提人卻沒有。或者有一種佛性，這兩種人都同樣擁有。或者有一種佛性，這兩種人都完全沒有。善男子，我的各位弟子如果能徹底了悟這四句的深奧義理，就不應當執著發難說一闡提人必定具備佛性、或者必定不具備佛性。如果我說一切眾生皆悉具有佛性，這是名為如來隨順自己究竟證境所宣說的圓滿言教（隨自意語）。」《大般涅槃經》指出如來有三種宣說法要的形式。前後三句，是方便教法中隨順眾生根機的「隨他意語」。「兩者俱有」這一句，指出「一切眾生皆悉具有」，稱為「隨自意語」。經文又說：「如果宣說一切眾生全都具備佛性，只是被深重煩惱覆蓋的緣故而無法親見。我這樣宣說，你們諸佛菩薩隨順佛意也這樣宣說，這便稱為『隨自他意語』。」經文中提出了這四句，此處只是簡略列舉「俱有」與「俱無」這兩句，用來證實眾生與佛陀修證位階的巨大差異。「二人」就是指斷絕善根的闡提與具足善根的常人。對比佛陀究竟徹證的果位法身而言，這兩種人都「全都不具備」；若對比凡夫本具的佛性而言，這兩種人則「全都本自具足」。「明知行果」，就是指如來累劫修行所證得的究竟極果，經中說「圓教十住位菩薩也只能少分窺見佛性」，由此可知唯獨佛陀才能究竟窮盡自性真源。凡夫僅僅是自性本具而已，如何能與如來的實證境界相提並論？

【039-0084】02_戒疏/02a_卷一上之二#125
【原文】【疏】此方無人，以三義譯。一曰「怖魔」，或令魔怖。遵修三行，出三有也，由此義故，名之為「僧」。故《五分》云「為解脫出家，名為僧也」。二曰「乞士」，有二義故。上則乞法以練心，下則乞食以資身。得法奉持，驗以四教；受食觀厭，須離五邪。廣如常解。三曰「破煩惱者」，欲使依名思義，顧瞻有本，不至流俗，唯欣出要。故云「於我法中，快修梵行，盡苦源」也。

【039-0099】02_戒疏/02b_卷一上之二#13
【原文】【記】引文中。《母論》先示名。彼云：「毗尼能滅不善根，能滅障法，能滅五蓋惡行，名為毗尼。」今以「諸惡」一句總之。「所滅」下，列相。初、言「犯」者，方便趣果，污體成罪故。《論》云「從犯毗尼，出罪毗尼」是也。二、「諍」者，如四諍起，七毗尼滅，《論》云「能滅鬪諍故」。三、「煩惱」者，《論》云「能斷煩惱故」。四、「比丘」。五、「尼」者，即二眾不同戒。六、「少分」。七、「一切處」。「二」下，別點後二，非出彼論。戒實無量，且據數作，為持犯蹊徑，故云「少分」。「淨戒」即別脫，「心」即定共，「慧」謂道俱。「微細戒」者，總上三種。別脫微細者，謂《戒本》之外，八萬無量塵沙制也。
【譯文】【記文】在引述的論文中。《毗尼母論》首先標明名稱。該論說道：「毗尼能夠滅除不善根，能夠滅除障礙正法的過患，能夠滅除五蓋等惡行，所以稱為毗尼。」現在以「諸惡」這一句話來總括概括。「所滅」以下，逐一列出各種相狀。第一、所謂「犯」，是由於以方便手段趣向罪業結果，染污戒體而結成罪名。《毗尼母論》所說的「從犯戒產生的毗尼，用以出罪消滅的毗尼」指的就是這個。第二、所謂「諍」，例如四種諍事生起時，以七種毗尼來止息滅除，論中說「因為能平息鬥諍」。第三、所謂「煩惱」，論中說「因為能斷除煩惱」。第四、指「比丘」，第五、指「比丘尼」，這代表僧尼二眾各自不同的戒條。第六、指「少分戒」。第七、指「一切處戒」。「二百五十戒」以下，是單獨點明後兩種戒，並非直接出自那部論典。戒法在實質上是無量無邊的，暫且依據條數來制定，作為持戒犯戒的修行軌跡，所以稱為「少分戒」。「清淨戒」就是別解脫戒，「心」就是定共戒，「慧」就是道俱戒。「微細戒」，是總括前面這三種戒。別解脫戒中的微細戒，是指《戒本》條文之外，如同恆河沙數般無量無邊的八萬威儀制規。

【039-0122】02_戒疏/02b_卷一上之二#36
【原文】【記】五云「五品」者，《論》作「五部」。舊記準《發智論》云：「見苦所斷結，集所斷結，滅所斷結，道所斷結，修所斷結。三界各有五部，成十五部惑。」、「有願」者，具戒方便故；「無願」者，已滿足故。八中，《論》作一處，《疏》加「時」字。「如」下，明處；「昔」下，明時。此二並約「受」、「浴」顯相，餘事準說。
【譯文】【記文】第五項所說的「五品」，在《論》中稱為「五部」。舊日的註記依據《發智論》解釋說：「見苦諦所斷除的結縛，見集諦所斷除的結縛，見滅諦所斷除的結縛，見道諦所斷除的結縛，以及修道所斷除的結縛。欲界、色界、無色界各自具有這五部，合起來成為十五部煩惱惑。」「有願」的意思，是因為它屬於成就具足戒的前行方便；「無願」的意思，是因為戒體已經圓滿具足了。第八項中，《論》中稱為「一處」，本《疏》則額外增加了「時」字。「如」以下，說明處所；「昔」以下，說明時間。這兩項都是依據「受戒」與「洗浴」來顯發其事相特徵，其餘事相可依此類推。
