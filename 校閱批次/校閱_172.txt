# 校閱材料　第172檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【172-0001】資持記/08a_中二#36
【原文】不犯中二，前開本犯，後開因制。初中，先示本律，文相通濫。下引《十誦》，明分兩斷。在文可委。券書即今俗謂離書是也。次科中，前開濟俗急緣。及下，次開為道要事。第六。〔佛在羅閱祇，開聽作房，比丘大作；乞求惱俗，斫樹惱神，因制。〕名標無主，簡後戒故。過量不乞二過合制，同一房故。制意中。
【譯文】在不犯的段落中分為兩部分：前面是開許原本所犯的媒人罪，後面是開許因兼帶而制定的相關事項。在第一部分中，首先指出本律的文字相狀存在通用混淆之處。下文引用《十誦律》，明確劃分出兩種裁斷。在律文中可以詳細見到。所謂「券書」，就是現今世俗所說的離婚協議書。在下一段科判中，前面是開許為了救濟世俗急難因緣的情況。「及」字以下，接著開許為了僧團道法要務而進行的交涉。第六條戒（指無主作房戒）。〔佛陀在羅閱祇城時，開許比丘建造僧房，比丘們便大興土木；向世俗信眾四處索討乞求造成困擾，砍伐樹木激怒了樹神，佛陀因此制戒。〕戒名標明「無主」（無人出資供養），是為了區別後面有施主的戒條。建造過量與未向僧團乞請這兩種過失合併在一條戒律中懲處，是因為都在建造同一座僧房。在制戒用意中。

【172-0002】資持記/08a_中二#37
【原文】初是今加，四出《多論》。一是長業。二即增惑。三謂惱俗，律緣：曠野比丘乞覓多故，居士迴避；乃至迦葉入城亦避，此謂惱人也。又有比丘斫伐神樹，樹神白佛，佛為說法令住他樹等，此謂惱非人也。四即惱道，立法制乞，為取僧和；不乞自任，僧事不行，故云障也。
【譯文】第一點是本朝祖師所增補的，其餘四點出自《薩婆多論》。第一是增長世俗牽絆與有漏惡業。第二是助長內心的貪愛迷惑。第三是困擾惱害世俗大眾，律中的因緣記載：曠野比丘到處向人索討建材，使得在家居士紛紛走避；乃至大迦葉尊者進城乞食時居士們也躲避開，這叫做惱害人類。又有比丘砍伐了有鬼神寄居的神樹，樹神前去向佛陀哭訴，佛陀為樹神說法開示並讓它遷居到別的樹上等等，這叫做惱害非人鬼神。第四是障礙修道事業，佛陀立法規定必須先向僧團乞請處分，是為了促成僧眾和合；如果不經乞請擅自作主，僧團的羯磨僧事就無法推行，所以說是障道。

【172-0003】資持記/08a_中二#38
【原文】五中，上句標，下二句釋。違慈者，或惱二趣，或傷物命故。壞行者，非沙門法故。已上五意，總束為三；初二損自，三四損他，後一自他兩損。又復第四是制不乞法意，餘皆制過量意。犯緣中。四五二緣，文兼兩過。第六結犯，義總二殘。釋中，初科，《多論》。摶泥，示犯分齊。
【譯文】第五點用意中，第一句是標題，下兩句是解釋。違背慈悲心，是因為既惱害了人與非人兩趣眾生，又傷害了草木微細物命的緣故。敗壞道行，是因為這不是沙門應有的行徑。以上五種用意，總括歸納為三類：前兩種損害自己，第三、第四種損害他人，最後一種則是自他兩相損害。此外，第四種用意是專門針對「不向僧團乞求作法」而制戒，其餘用意都是針對「建造過量」而制戒。在犯戒條件中，第四和第五兩個緣，文字上兼涵了兩種過失。第六個緣結成罪過，在義理上總括了兩種僧殘重罪。在解釋的第一段科判中，《薩婆多論》以「最後一把塗泥」來指明構成重罪的界線節度。

【172-0004】資持記/08a_中二#39
【原文】彼宗，中下二蘭為殘方便；文中對輕，故言量耳。《善見》。結蘭同上。決罷殘者，雖留摶泥，事畢竟故。《僧祇》。諸物但取最後，不局摶泥。受用吉者，由本非法，制不聽用；彼云：於中熏鉢作衣，若受誦，若思惟，一切越毘尼。死等開僧用者，相續斷故。釋第四中，初科，前明來乞。若不下，明僧審量。
【譯文】該部派認為，中品和下品的偷蘭遮罪是僧殘罪的前行方便；文中相對於輕罪（輕蘭），所以稱為重罪（重蘭，底本或作「量」）罷了。《善見律》結偷蘭遮罪的判法與上述相同。之所以判定僧房蓋好時結僧殘罪，是因為雖然還留有一把泥巴沒塗，但整個建造工程實質上已經大功告成了。《摩訶僧祇律》則認為各種建材都只取最後一道工序完工為界，並不局限於塗泥。受用該房結突吉羅罪，是因為其興建本來就違法，所以律制不准比丘享用；該律說：在裡面熏染缽具、裁製衣服，或者受持諷誦經文，或者思惟道法，一切都算違犯毘尼罪。比丘死後開許給僧團大眾使用，是因為非法建房的相續個人業緣已經斷絕了。在解釋第四個緣的第一段科判中，前面說明比丘前來乞請房舍處分。「若不」二字以下，說明僧團實地查勘審度尺寸。

【172-0005】資持記/08a_中二#40
【原文】次科，長廣中。出量有二：前《善見》是乞法量，後《四分》即作房量。一磔二尺，計數可會。〔磔字當從石，張也；謂母指中指相去為磔。〕若不滿六磔，過乞俱無〔應有妨難〕；若十二磔已內，有乞無過，已外過乞俱有；若已得法，但有過量，如是知之。
【譯文】在下一段科判中，討論房舍的長度與寬度。指出尺寸規定有兩種：前面《善見律》所說的是向僧團乞法的標準規格，後面《四分律》所說的則是實際動手蓋房的限量尺寸。一磔手等於兩尺，推算數目就可以吻合相通。〔「磔」字應當從「石」字旁，是張開的意思；也就是大拇指到中指張開時兩端之間的距離叫做一磔手。〕如果不滿六磔手，過量與不乞法兩種罪名都不成立〔但可能會有其他妨礙修行的難處〕；如果在十二磔手以內，只有不乞法之罪而沒有過量之罪，若超過這尺寸則過量與不乞法兩罪同時成立；如果事先已經得到僧團如法批准，建造時就只有超量之罪，應當依此準則來理解判定。

【172-0006】資持記/08a_中二#41
【原文】勘尺量中，初文為三，初通標。僧下，二正引。《僧祇》、《了論》數同。《善見》即三尺。《多論》肘半，二尺七寸也。《五分》是今所取。已下，三出所以。有二：一譯處異，二譯人異。聞見不同，各據所見故。南即楊都，北指京洛；
【譯文】在查考尺寸長度中，第一段文字分為三個部分，首先作通盤標示。「僧」字以下，第二是正式引證文獻。《摩訶僧祇律》與《律二十二明了論》的數目相同。《善見律》則定為三尺。《薩婆多論》定為一肘半，也就是兩尺七寸。《五分律》的標準是當今所採納的。「已」字以下，第三說明出現分歧的原因。主要有兩點：一是翻譯的地理處所不同，二是翻譯的譯者不同。所聽聞見到的尺度各有不同，各自根據自己所見的制度來記錄罷了。南方是指建康楊都，北方是指長安京城洛陽；

【172-0007】資持記/08a_中二#42
【原文】又東晉宋齊梁陳相繼為南朝，後魏後周隋謂之北朝。《僧祇》，東晉佛陀羅與法顯譯；《了論》，陳真諦譯；《善見》，南齊僧伽跋陀羅譯；《多論》失譯，獲本西蜀；《五分》，宋佛陀什共竺道生譯；其間生顯是華人，餘並梵僧；故云生處不同也。矛即鏘戈，盾謂旁牌。〔《韓子》云：宋人有賣矛盾於市，有買矛者云：此矛甚利，所刺皆陷；
【譯文】此外，東晉、劉宋、南齊、蕭梁、南陳相繼統治南方，後魏、後周、隋朝則稱為北朝。《摩訶僧祇律》是東晉時佛陀跋陀羅與法顯大師共同翻譯的；《明了論》是陳朝真諦三藏翻譯的；《善見律》是南齊僧伽跋陀羅翻譯的；《薩婆多論》失落了譯者姓名，是從西蜀之地獲得的梵本；《五分律》是劉宋時佛陀什與竺道生大師共同翻譯的；這幾位譯師當中，道生和法顯是漢地華人，其餘全都是天竺梵僧；所以說譯師出生之處各有不同。矛就是長槍戈器，盾就是防護盾牌。〔《韓非子》記載：宋國有人在市集上賣矛和盾，誇讚自己的矛說：我的矛非常鋒利，什麼東西都能刺穿；

【原文】三中一一皆有身作口作，尋文可見。溉音蓋，澆也。倡伎，即作樂人。俳說，謂同俳優浮俗之語。《僧祇》中，先釋依義。若依下，簡惡行。若俗下，明污家。通括前後釋此二相，大約不出自他兩損。《多論》，通標中，初明污家。言種種者，如後所列。作下，明惡行。文舉因果以顯名義。
【譯文】這三類中每一項都包含身業所作與口業所作，尋察文義即可明瞭。「溉」音同「蓋」，是澆水的意思。「倡伎」就是奏樂演藝之人。「俳說」是指如同滑稽戲子那些浮華庸俗的話語。在《僧祇律》中，先解釋「依」的含義。「若依」以下，簡別何為惡行。「若俗」以下，說明何為污家。通盤總結前後對這兩種相狀的解釋，大體上都不出於損害自己與損害他人這兩種結果。《薩婆多論》在總括標明中，首先說明污家。所謂「種種」，就如下文所列的項目。「作」字以下，說明惡行。文中同時舉出因與果，藉此顯明其名稱與意涵。

【172-0047】資持記/08b_中二#19
【原文】別釋中五段，前四永制，後一暫開；又初四損自，二三損他。初云凡所求者，總收多事；不問公私善惡，皆不許之。何下，出意。以非沙門所宜為故。二中。縱賢善者，據比丘言之。三云贈遺，遺字去呼，獻也。四中。起塔等者，有為世善，猶不離過，罪福雙感故。不如靜坐等者，無漏淨業，出離因故。
【譯文】分別解釋中共有五段，前四段永久禁止，後一段暫時開許；又第一、第四段損害自身，第二、第三段損害他人。第一段說「凡是所求索的」，總體概括了許多事物；不論是公事私事、善意惡意，全都不被允許。「何」字以下，說明箇中意圖。因為這些都不是沙門所應當做的事。第二段中，「縱使是賢善之人」，是針對比丘而言。第三段說「贈遺」，「遺」字讀去聲，是進奉饋贈的意思。第四段中，「建造佛塔等事」，屬於世間有為的善事，仍然離不開過失，罪與福將會同時感召應驗。所謂「不如安靜坐禪等」，因為這是無漏清淨業，是超脫生死的正因。

【172-0048】資持記/08b_中二#20
【原文】真法身者，即是戒體。五中。難開緣如盜戒。寄語來學，細覽斯文。且心識非愚，耳目猶具；何事終年講讀，殊無一句染神；豈異盲聾，信同土木。必懷高操，勿混下流；不唯沈屈平生，更乃毀傷三寶。願詳聖訓，返照自心；忽悟前非，早須改迹。不犯中二，初污家不犯，得與七人。
【譯文】「真法身」就是指戒體。第五段中，遭遇危難的開緣就如同盜戒中的規定。寄語後來的學者，應當仔細閱讀這些經文。況且心智並非愚鈍，耳目也都健全；為何一年到頭講習閱讀，卻沒有一句話能沾染陶冶心神；這豈不是同盲人聾子無異，同土木頑石一般無知。如果自懷高尚的操守，就切莫混入下流鄙俗之中；這不僅會使自己平生屈沉墮落，更會毀辱中傷三寶。希望大家詳察佛陀聖訓，返觀自省本心；一旦覺悟先前的過錯，必須儘早改弦易轍。不犯條款中分為兩部分：首先污家不犯，允許給予七種人財物。

【172-0049】資持記/08b_中二#21
【原文】若種下，惡行不犯，得作五事，初非掘壞。自作教人，皆為供養。文言自取，義非自摘。若人下，開走。若度下，開揚跛行。〔即𨁑行也。此二前惡行中不出。〕若伴下，開呼嘯。若為下，開作使。〔律云若不肴書持往，及為白衣作使，皆突吉羅。前亦闕引。
【譯文】「若種」以下，惡行不犯，允許做五件事，第一種並非出於惡意挖掘毀壞。自己動手或教導他人，全都是為了供養之用。文中說「自己取用」，義理上並非自己去摘折採集。「若人」以下，開許奔跑。「若度」以下，開許提足跳躍跛行。〔也就是快速跳躍疾行。這兩種在前文惡行中並未列出。〕「若伴」以下，開許呼喊口哨。「若為」以下，開許充當差使。〔律中說如果不查驗信件內容就攜帶前往，以及為白衣充當差使，都要結突吉羅罪。前文也缺漏未引。〕

【172-0050】資持記/08b_中二#22
【原文】前列共女坐及歌舞等，此無開者，性惡之漸，蕩逸之端，故可知矣。十三。〔佛在拘睒彌，間陀惡性拒諫因制。〕列緣。云自恃者，即如闡陀；諸比丘諫時，反云我應教諸大德，我聖主得正覺故。〔由本侍佛控馬逾城入山成道，後乃出家，故常恃此陵慢於他。〕釋中，初文。
【譯文】前面列舉的與女子同坐以及歌舞等事，這裡沒有列出開緣，因為這是根本惡業的開端，是放蕩逸樂的源頭，所以其緣由可想而知。第十三條戒。〔佛在拘睒彌國時，闡陀比丘性格凶惡抗拒勸諫，佛陀因此制戒。〕列出犯緣。所謂「自恃」，就如同闡陀那樣；諸位比丘勸諫他時，他反而說「應當由我來教導各位大德，因為我的聖主成就了正等正覺」。〔由於他當初曾侍奉佛陀控馬逾越城牆入山成道，後來才出家，所以常常仗憑這一點凌辱怠慢他人。〕解釋文中，第一段。

【172-0051】資持記/08b_中二#23
【原文】旁略教者，即拘留孫偈。通會中。問引略偈，難今廣文。論指經中，即《十誦》戒本，與《四分》詞有少異。答中，初總舉。云因時者，隨機興制，不可一概故。言乖，謂文或有異；趣合，謂各有其理。一下，別示。六中，第五並是善事；自他二利，分之自別。
【譯文】「旁略教」是指拘留孫佛的略說教誡偈頌。在通融會通中，提問者引述略偈，來質難現今的廣博律文。論中指出的經文，就是指《十誦律》戒本，與《四分律》的文詞稍有不同。回答中，首先作總體提出。所謂「因時」，是指隨順機緣而興起制裁，不可一概而論。所謂「言乖」，是指文句或有不同；「趣合」是指各自都有其道理。「一」以下，分別予以指示。在六對之中，第五對全都是善事；自利與利他二者，區分開來自然清楚。
