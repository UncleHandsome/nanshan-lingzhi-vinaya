# 校閱材料　第1630檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1630-0001】03_業疏/05b_卷一之五#22
【原文】次科，初準例。準上持欲，以例在房，有難是同，非心不別故也。「若」下引決。初引他部開成出界，「不此來」句因引「遮不至」者，是今取證，謂同界內為難所遮，無別眾過，故云清淨。《四分》下次據本宗判別。初句示無開；「如」下引急制。餘之制教，多開境想，容有方便；唯此別眾，特反常途。比前成欲，緩急全殊，不可相例
【譯文】在下一科中，起初比照援例。依準上述持欲之義，來例推留在僧房中的情況，遭遇災難的情形相同，不是心懷背逆故不算別眾。「若」字以下引證決斷。起初引用他部律典開許成辦出界的情形，「不來此」之句連帶引出「被遮難所阻而未能到達」，正是如今引為證明之處，意思是同在結界之內為難事所阻遮，並無別眾的過失，所以稱為清淨。《四分律》以下接著依據本宗判定為別眾。第一句指示本宗無此開許；「如」字以下引用嚴格的制約。其餘的教制，多半開許境想（對境有疑無疑等情節），容許有權宜方便；唯獨這別眾之罪，特別與通常之例相反。相比於前面成辦欲法，二者的寬緩與嚴急完全不同，不可一概而論。

【1630-0002】03_業疏/05b_卷一之五#23
【原文】問：與欲事訖不來，成別不？答：文言應往，不者治之，未必有別。何以明耶？本取情和，心已應僧，相非乖背；事訖違教，得罪得成。如狂比丘得法在僧，病止法存，不往非別；不同受日，牒事而作，事謝法滅，理數宜然。欲本不稱，僧為又別，但知通意，故兩無違；義須應往，故結小犯
【譯文】問：給了欲之後，所辦之事已完畢卻不來集會，是否構成別眾？答：律文說應當前往，如果不去則治其罪責，但未必構成別眾。如何證明呢？因為原本取欲是為了心意和合，其心念已經順應僧眾，外相上也非違逆背向；事畢不往只是違背教令，得小罪而僧法依然成辦。如同癲狂比丘蒙僧開許成法而留在僧中，病癒之後僧法依然存在，不前往亦不構成別眾；這不同於受日出界之法，受日是牒明具體事項而作法，事項了結法便隨之消滅，理數本當如此。欲法原本未具體陳明其事，僧伽所為又是另一項事務，只要通達心意和合，所以兩者互不相違；按義理而言理應前往，所以結定輕微違犯（突吉羅）。

【1630-0003】03_業疏/05b_卷一之五#24
【原文】料簡中初問，恐疑事訖法謝成別，故問決之。答中，初準判；「何」下徵意，初敘非別所以；「如」下引例，病止例事訖，法存比欲在。「不同」下遮簡，恐取彼例，故預通之。「欲不稱」者，一不同也；「僧為別」者，由彼羯磨正為受日，今此送欲，僧為他緣，二不同也。「兩無違」者，彼欲不失，僧法得成故也
【譯文】在料簡辨析的初問中，唯恐有人懷疑事情了結後法隨之消滅而構成別眾，所以發問以作決斷。回答中，起初依準法理判定；「何」字以下探問其深意，起初敘述不構成別眾的緣由；「如」字以下引例，病癒比照事情了結，法存比照欲法依然存在。「不同」字以下遮止簡別，唯恐有人援取彼處為例，所以預先加以會通。「欲不稱名特定之事」，是第一處不同；「僧眾所為乃是別事」，因為彼處羯磨正是為了受日，如今此處遣送欲法，僧眾作法則是為了其他事緣，這是第二處不同。「兩無違」，是指那邊欲法不失，僧法亦得成辦。

【1630-0009】03_業疏/05b_卷一之五#30
【原文】正答中，初止來難；「此」下次伸所以。諸羯磨中，開立唯二；若準《尼鈔》，立說亦廢。以僧況私，準知不合。仍引諸文明判別眾：《五分》背坐、《僧祇》儀互，故云「小乖」；并下《四分》，竝如上引
【譯文】在正式回答中，起初止息來難之問；「此」字以下進一步申述其中的所以然。在各項羯磨中，開許站立的唯有這兩種情況；若是依準《尼鈔》，站立說戒之法也已被廢除。以僧中公事來比況私人欲法，照此便知絕對不合體規。隨後引用各部律文明確判定為別眾：《五分律》的背坐、《僧祇律》的威儀互乖，所以說「稍有違背」；連同下文《四分律》之文，都正如上面所引用的。

【原文】然就僧法，約相分之，不必據內。心違相順，開成應法，故文云「如法羯磨而心不同，佛開成和」；相乖心順，即是別眾，如上等文七百結集「後聽可」等。又須斟酌，不必皆爾
【譯文】然而就僧法而言，是依據外在相狀來區分的，不必完全拘泥於內心。心意違逆而外相順從，開許其成辦如法，所以律文說「如法作羯磨而內心不同意，佛陀開許算作和合」；外相乖違而內心順從，就是別眾，如同上引各文以及七百結集中所說的「事後認可」等等。但又必須審慎斟酌，未必全都如此。

【1630-0011】03_業疏/05b_卷一之五#32
【原文】次通明中初科初標示心下別釋又二初明心違相順成和引律雜法中文舍利弗見作非法羯磨佛聽默然故云開成二明相乖心順成別如上文者近取上答遠指前緣足別諸相復指律中七百結集即䟦闍擅行十事之一彼云在界內別眾羯磨已聽可謂先作法有不集者後取欲也彼稱佛說七百羅漢斷成別眾亦即同上相乖心順等之一字略束之詞又下結誥然有相順心違成別如得呵者呵亦有相乖心順成和如病開臥故云不必皆爾。
【譯文】在接下來通論說明的初科中，首先標示說明。「心」字以下分別解釋，又分為兩部分：第一、說明心違相順而成辦和合，引證律典雜法中的文句，舍利弗見到作非法羯磨，佛陀聽許他保持默然，所以說開許成和；第二、說明相乖心順而構成別眾，所謂「如上文者」，近處指取上面的答語，遠處指稱前面各緣中足數與別眾的種種相狀，又指稱律中七百結集之事，即跋闍子擅行「十事」之一，他們說在結界內作了別眾羯磨後再來認可（即先作法事，對未集會者事後再去取欲），他們聲稱佛陀曾作此說，七百羅漢斷定這屬於別眾，這也正如同上文相乖心順之義，「等」字是概略收束之詞。「又」字以下總結告誡，然而也有外相順從而內心違背卻構成別眾的（如得呵責權利者起而呵責），也有外相乖違而內心順從卻成辦和合的（如病者開許臥倒），所以說「未必全都如此」。

【1630-0012】03_業疏/05b_卷一之五#33
【原文】若能秉法人，如上兩開；就所為者，則有二例：被治、被諫，坐、立俱成。雖非數收，情用兩別：故治則極三，違惱處重；成四壞眾，諫通多少，莫不情求，無慮破別也。若乞受、乞懺，下情仰上，非具法儀，相似倨傲，義無授法，文自顯之
【譯文】若是能秉持羯磨之人，如上面所開許的兩種情況；就所受羯磨之人而言，則有兩種條例：被治罰、被勸諫之人，坐著或站立都能成辦法事。這類人雖然不列入足數之列，但其情意功用各有不同：在治罰時至多三人，因為違背惱亂情節嚴重；若是滿四人就構成破壞僧眾，而勸諫之法通於人數多少，無不是出於情求和合，不必擔憂構成破僧別眾。若是乞求受戒、乞求懺悔之人，下位之情仰戴上位，若不具足法度儀軌，就顯得怠慢傲慢，在義理上決不給予授法，律文自能明顯彰表此意。
