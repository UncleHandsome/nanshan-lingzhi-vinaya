# 校閱材料　第143檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【143-0001】資持記/10c_中三下#13
【原文】論約六十已上堪苦，則如律不遮；律據七十已還不堪，則同論亦制。故云兩通無損。牟合作予。不犯中二，初憑他語。師僧無過，受者無戒。若受下，次開後疑。有戒無過。據此止開三位，頻大一位，古師相傳，故《戒疏》中不用亦得。別示中，敘意為二，初指廣。言諸部者，《伽論》云：從母胎數，取一切閏月。
【譯文】《論》依據年滿六十歲以上但能耐受辛苦者，就如同本律不加阻攔；本律依據年滿七十歲以下卻不能耐苦者，就如同《論》一樣加以限制。所以說兩者互相通融而毫無妨礙。「牟」字應當寫作「予」。不犯的情況有兩種，首先是憑藉他人告知的年歲。戒師僧眾沒有過失，但受戒者得不到戒體。「若受」以下，接著開許事後生疑的情形。此時受戒者保有戒體且沒有過失。依據本律只開許三種補算年歲之法，連續大月這一項，是古代律師代代相傳的說法，所以在《戒疏》中不採用也可以。在特別開示中，敘述文意分為兩部分，首先指出詳見廣論。所謂諸部律論，《毘尼母伽論》說：從在母胎中開始計算，納入所有的閏月。

【143-0002】資持記/10c_中三下#14
【原文】〔不數布薩。〕《五分》中，初聽數胎，次聽數閏，後聽以沙門年足。〔亦無布薩，而有沙門果，亦《四分》上法，但《四分》不列開中。〕《母論》，初聽數胎中年，次聽數閏，三數十四布薩，四言實得羅漢。〔此同《四分》，羅漢即上法也。
【譯文】〔但不計算布薩日。〕《五分律》中，首先聽許計算胎中時間，其次聽許計算閏月，最後聽許以證得沙門果位的功德來補足年歲。〔也是沒有計算布薩日，但有沙門果法，這也是《四分律》的上人法，只是《四分律》並未列入開許條文中。〕《摩得勒伽論》中，首先聽許計算胎中的年歲，其次聽許計算閏月，第三聽許計算十四日的布薩，第四說如果確實證得阿羅漢果。〔這與《四分律》相同，阿羅漢果就是指上人法。〕

【143-0003】資持記/10c_中三下#15
【原文】勘曆者，古師云：此國用曆三年一閏，疏破云：勘餘曆術三十二三月方有一閏，何限三年。〔頻大亦出俗曆。〕但下，顯略，初敘略意。但通下示略法。言一句者，句通長短，即下今古二科，以自古算法立義極繁；今以數行總括大要，意彰至少，故云一句。次科，出古算中。
【譯文】勘查曆法方面，古代律師說：我國所用的曆法是三年一閏，《戒疏》反駁說：勘查其餘的曆算法則是三十二或三十三個月才有一個閏月，哪裡局限在三年。〔連續大月也是出自世俗曆法。〕「但」字以下，顯明簡略之意，首先敘述簡略的意圖。「但通」以下說明簡略的方法。所謂「一句」，文句可長可短，就是指下面的古算與今算兩科，因為自古以來的推算法所建立的理論極為繁雜；現在只用幾行文字總攬大要，意在彰顯其極其精簡，所以說「一句」。下一科，列出古代推算的方法。

【143-0004】資持記/10c_中三下#16
【原文】彼謂年滿月不滿方開增算，故取極小須十八年二日也。便以等者，疏文甚詳，此不細錄；但約四位直示算法，初算胎法；大約道俗文典，九月為胎，以胎中七日一轉如五王經七七日成人，如是總有三十八轉，一轉七日，總二百六十六日。〔五大四小共得九月。〕自此已前，與母同氣；
【譯文】古代律師認為年歲已滿（十九歲）而月數不滿（二十整年）時才開許追加計算，所以取年齡最小的底限必須是十八歲又兩天。「便以」等內容，《戒疏》的文字記載得非常詳盡，這裡不再細密抄錄；僅僅依據四種名目直接說明算法：第一是計算胎月之法；大體上世俗與佛門典籍都以懷胎九個月為準，因為胎兒在母腹中每七天轉變一次，如同《五王經》所說七七四十九天成形，像這樣總共有三十八次轉變，一次轉變七天，總共是二百六十六天。〔以五個大月、四個小月合計恰好是九個月。〕在此之前，胎兒與母親同呼吸共氣血；

【143-0005】資持記/10c_中三下#17
【原文】爾後四日，將欲趣產，與母別氣；約準成月，則九月四日通前十八年九月六日。二算閏法，大略為言，十九為章〔謂十九年為一大段〕，以七為閏〔十九年中有七閏月〕，三年一閏有三〔初中後共九年〕，五年再閏有四〔兩中間十年〕，故有七也；
【譯文】此後的四天，即將面臨生產，胎兒與母親各自呼吸有了分別；依照推算折合成月份，則是九個月零四天，加到前面的十八歲上，便是十八年九個月零六天。第二是計算閏月之法，大略來說，十九年為一「章」〔也就是十九年為一個大週期〕，其中有七個閏月〔十九年中包含七個閏月〕，三年一閏有三次〔前、中、後加起來共九年〕，五年兩閏有四次〔兩個中間期加起來共十年〕，所以總共有七個閏月；

【143-0006】資持記/10c_中三下#18

【143-0007】資持記/10c_中三下#19
【原文】如是周而復始，則用前一百九十六月成四章，一章有三日，總得十二日；餘三十六月得兩頻大，成十四日，通前成十九年四月十七日也。四布薩法，通以十四日布薩，謂抽大月布薩日數為歲；一年除閏，六大得十二日，六小得六日，準得十八日；通計十九年四月，抽得三百四十八日；
【譯文】像這樣周而復始循環，那麼用前面的期數取一百九十六個月構成四章，一章可得三天，總共得到十二天；剩下的三十六個月可得兩次連續大月，折成十四天，合併到前面就成為十九年四個月零十七天。第四是布薩之法，普遍採用十四日布薩的推算，意思是抽取大月布薩所節省的天數來湊成歲數；一年扣除閏月，六個大月可得十二天，六個小月可得六天，依準可得十八天；綜合計算十九年四個月，共抽取得到三百四十八天；

【143-0008】資持記/10c_中三下#20
【原文】用二十八日為月，則三百三十六日為一年，餘十二日在；帖前居零十七日，則成一月一日；通前則為二十年五月一日，故云長也。上是出古謬解。今算中。初明退法。此長者，指上五月一日也。約實者，謂用此虛月還填令實，則有四月三十日。
【譯文】以二十八天折算為一個月，那麼三百三十六天即折算為一年，還剩下十二天；再補加到前面零碎的十七天中，就成了一個月零一天；合併到前面就成了二十年五個月零一天，所以說是多出來了。以上是列舉古代錯誤的理解。在當今的算法中。首先說明退減的方法。所謂「此長」，是指上面推算出來的五月一日。「約實」，是指用這個虛增的月份回填使之成為實數，那麼就是四月三十天。

【143-0009】資持記/10c_中三下#21
【原文】準《戒疏》出填補法，則有四月十八日；彼云：就五月中七大布薩減取七日〔二大月得四日，三小月得三日。〕，又減閏餘弱得五日〔四月十八日中有二小盡得二日，并每月餘二十八半分，即十四分；四月十八日共得六十五分；將六十四分為二日，共得四日零一分；
【譯文】依照《戒疏》所開出的填補法則，則是四月十八天；《戒疏》說：就在五個月中，扣除七次大月布薩的日數減去七天〔兩個大月得四天，三個小月得三天。〕，又扣除閏月的餘數稍弱算得五天〔四月十八天之中有兩個小月各盡其數得兩天，加上每個月餘下的二十八點五小分，即十四分；四月十八天總共得到六十五分；將六十四分折算為兩天，共得到四天零一分；

【143-0010】資持記/10c_中三下#22
【原文】今總開前為一百二十九分。將為五日，本三十二分為一日，今始成二十六分，故云弱也。今鈔但還四日，不取弱得。〕，又減頻大弱得半日〔以八箇月方得半日，今四月十八日取半日，故云弱也；今鈔不還此日，以不成半日故。
【譯文】現在把前面的總數開展為一百二十九分。將其算作五天，原本三十二分為一天，現在才滿二十六分，所以說是「弱」不足額。如今《行事鈔》只折還四天，不採用此處弱算所得的天數。〕，又扣除連續大月弱算得半天〔因為要滿八個月才得半天，如今四月十八天就取半天，所以說是「弱」不足額；如今《行事鈔》不折還這一天，因為還不構成半天的緣故。
