# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【121-0001】資持記/13b_下一#42
【原文】前明無藍須結，初示相判定。由本不結，但隨住舍，難護易離；今若結之，遍界通護，故結有益。〔《注羯磨》作界寬藍狹，與此事別義同，故知須結，則通兩相。〕謂下，出不結之患。僧院即上住舍。勢分內者，一切自然衣界之外，各有十三步勢分。二下，次明餘二不須。
【譯文】前面先說明若沒有僧伽藍（寺院）就必須結界，開頭先出示形相並做出判定。由於原本沒有結界，只能隨順個人的住處房舍，這樣就很難護持而容易構成離衣之罪；如今若進行結界，就能普及全界通體護持，所以結界是有利益的（《注羯磨》寫作「界寬藍狹」，與這裡文字雖異但法理相同，由此可知必須結界的原則，通達於這兩種情況）。從「謂」字以下，指出不結界的弊病。「僧院」就是指上面的住處房舍。「勢分之內」，是指一切自然衣界的外圍，各自擁有十三步的防護勢分範圍。從「二」字以下，接著說明其餘兩種情況不需要結界。

【121-0002】資持記/13b_下一#43
【原文】藍界等者，尚不須結；況界小乎！借令大界出藍十三步許，結亦徒然。結竟下，示加結之過；二相俱有，院外失衣；界小於藍，院內亦失。立法中，初科，上二句標古法，上句通示諸家。比由羯磨文牒除村，故生異執。準疏凡有二解。初師云：有村須除，無村不須，何得雷同俱須除也。
【譯文】寺院界地等同於大界的，尚且不需要結界；何況自然界比寺院還要小的呢！假使大界超出寺院十三步左右，進行結界也是徒勞無益的。從「結竟」以下，指出強加結界的過失：若兩種形相兼具，在僧院之外就會失去受持的法衣；若大界小於僧院，在僧院之內也會失去法衣。在「結界法式」中，第一科前兩句標示出古代的做法，上一句通指各家的說法。以往是由於羯磨文辭中提到了排除村落的字眼，所以產生了不同的固執見解。依照律疏共有兩種解釋。第一位法師說：有村落的就必須排除，沒有村落的就不需要排除，怎能一概而論全都必須排除呢？

【121-0003】資持記/13b_下一#44
【原文】〔此依《曇諦羯磨》，彼注云：有村除村，無村不須唱除村。〕第二師云：有村結者，現除懸不結；後村移出，不合攝衣〔由本有村牒除，則村處無法；故云不結，彼謂除村體故。〕；無村結者，現結懸除；村來不攝，村去還會〔本無村結，遍界有法，但村來為礙耳。〕。下句別指初解。
【譯文】（這是依照《曇諦羯磨》，該書夾註說：有村落則排除村落，沒有村落就不需要宣唱排除村落。）第二位法師說：在有村落處結界者，眼下排除而懸想未來不予結界；日後村落遷徙離開，這裡也不具備攝受衣物的功能（因為原本有村落而唱明排除，那麼村落所在地便沒有法效；所以稱為不結，那是因為他認為排除的是村落實體之故）；在沒有村落處結界者，眼下結界而懸想未來予以排除；村落若是遷入就不予攝受，村落若是離開就又恢復攝受功能（原本無村而結界，全界都具備法效，只是村落遷來構成了障礙而已）。下一句則是特別指出第一種解釋。

【121-0004】資持記/13b_下一#45
【原文】彼謂除體據現無村，則於羯磨詞中，除去除村等語，故云無村結法。〔舊記妄出古解，全乖疏文。〕今下，立今義分三，初通立，上二句明結法俱通。下一句明牒除所以。若下，二別顯。現謂即今，懸謂擬後。羯磨緣云結不失衣界，此即結也；除村村外，即是除也。
【譯文】那人認為排除實體是針對當下沒有村落而言，所以在羯磨的文辭中，刪除了排除村落等語句，所以稱為「無村結法」（舊記胡亂解釋古代的見解，完全違背了律疏的文字）。從「今」字以下，樹立現今的正義，分為三部分：開頭先通盤樹立，上兩句說明結界方法彼此貫通。下一句說明文辭中提及排除的緣由。從「若」字以下，第二項分別顯明。「現」是指當下，「懸」是指擬定未來。羯磨的緣由說「結不失衣界」，這就是進行結界；「排除村落與村落之外」，這就是進行排除。

【121-0005】資持記/13b_下一#46
【原文】有村即除，故云現除；然其村處雖不攝衣，不妨通結擬後村去，故云懸結〔即異古師懸不結也〕。無村即遍，故云現結；雖現無村，擬後村至，不得通攝，故云懸除。注釋可見。下注村有二字寫倒。以下，三雙釋，上句明結遍。以雖有村，不礙法故。直下，顯除通。以除緣難，不除體故。次科，初句結斷。
【譯文】有村落就立即排除，所以說是「眼下排除」；然而村落所在之處雖然不能攝受法衣，卻不妨礙通體結界以擬備日後村落遷走，所以說是「懸想結界」（這就與古代法師所說的「懸想不結」不同了）。沒有村落就全界結界，所以說是「眼下結界」；雖然眼下沒有村落，但擬備日後村落遷來時便不能普遍攝受，所以說是「懸想排除」。夾註的解釋自然顯明。下面夾註中「村有」二字抄寫顛倒了。從「以」字以下，第三項進行雙向解釋，上一句說明結界遍及全處。因為雖然有村落，卻不妨礙整個羯磨法的成立。從「直」字以下，顯明排除具有通融性。因為排除的是障礙緣由，並不是排除土地本體之故。下一科中，第一句作出斷定評判。

【121-0006】資持記/13b_下一#47
【原文】一者理通，如上所述；二者有據，如除所引。不存舊解，故云定義。《五分》下，證有無通結。《十誦、多論》並同，故云等也。《五分》云：若本無村，結不失衣界竟，村後入者，不須更結，先已結故。〔謂村去後仍前攝衣。
【譯文】第一是法理通達，就如上面所陳述的那樣；第二是有所憑據，就如排除緣由中所引述的那樣。不再存留舊有的見解，所以稱為「定論正義」。從《五分律》以下，證明無論有無村落都能通體結界。《十誦律》、《薩婆多論》的主張也都相同，所以說是「等等」。《五分律》說：如果原本沒有村落，完成結成不失衣界之後，村落後來才遷入的，不需要重新結界，因為先前已經結界過了（意思是村落遷走後依然照舊攝受法衣）。

【121-0007】資持記/13b_下一#48
【原文】若本有村，結衣界已，村移出界，即此空處有不失衣界。是非既顯，猶恐執迷，故云任情量取；量謂評量。薩下，證除緣礙，初引《多論》五義。初云聚落不定，謂遷徙散落，不上一處；衣界定者，謂作法自然，分齊不可亂故。次義如《四分》緣起。三除諍者，或入聚會衣，容生忌故。
【譯文】如果原本有村落，結成衣界之後，村落遷出了界外，那麼這塊空出來的地方就自然具備不失衣界。是非對錯既然已經顯明，卻唯恐人們依舊固執迷惘，所以說「任由心意自行衡量選取」；「量」是指評斷衡量。從「薩」字以下，證明排除障礙緣由的說法，開頭先引述《薩婆多論》的五種意涵。第一種說聚落不固定，是指村落遷徙散落、居無定所；而衣界是固定的，是指作法界與自然界的分界限度不可紊亂之故。第二種意涵就如《四分律》的緣起所述。第三種「消除爭執」，是因為進入村落聚會衣物，容易引發嫌隙嫉妒的緣故。

【121-0008】資持記/13b_下一#49
【原文】四護梵行，等取第五為除嫌疑，此二可解。次引本制緣。律因比丘置衣在村，脫著時形露；以事白佛，因制除村。加結中。除村謂村界分齊，村外界即村外勢分。解法。注中，初引本律，次第解者。疏云：法儀倫式，前後有據，不可亂也。以結時先僧次衣後食，解則反之為次。
【譯文】第四種「護持梵行」，以及第五種「消除嫌疑」，這兩點容易理解。接著引述當初制戒的緣起。律典因為有比丘把衣服放在村落裡，脫換時裸露了形體；便把這件事稟告佛陀，佛陀因而制定了排除村落的規定。在加結的章節中，「除村」是指劃分村落的界限，「村外界」是指村落外圍的十三步勢分地帶。在解界方法中，夾註開頭引述本律，指出應當依照次第來解除界相。律疏說：儀軌法式的先後倫常都是有所憑據的，不可紊亂。因為結界時是先僧界、次衣界、後食界，解界時就剛好反過來作為次序。

【121-0026】02_戒疏/05c_卷二上之一#52
【原文】【疏】標舉戒名「大婬」。「婬」名是一，而有小大之殊。如「漏」、「觸」「語」，同成婬行。此就觸境有內外也，在內則夷，在外則殘也。如尼兩觸，夷蘭二結，相可知也。
【譯文】【疏文】標舉此戒名稱為「大淫戒」。「淫」的名稱雖然同為一個，卻有重大與細小的分別。例如「故意出精」、「摩觸女身」、「對女說粗惡淫語」，同樣都構成了淫心行為。此處是以觸及的身體境界分為體內與體外，如果侵入體內道處就結成波羅夷重罪，只在體外接觸就結成僧殘罪。就像比丘尼犯摩觸戒，有波羅夷與偷蘭遮兩種結罪，其界限道理是可以相互參照而明了的。

【121-0027】02_戒疏/05c_卷二上之一#53
【原文】【記】釋名中。初標示通別，「如」下，引戒顯相。初明通濫，「此」下，明所簡。「內」局三道，「外」通一身。下引「尼」例，《律》制「腋已下、膝已上、腕已後，身分犯夷，餘處犯蘭。」以尼內外俱重，與僧不同。然於外觸，自分重輕，頗同上義。
【譯文】【記文】在解釋戒名之中。開頭先標示出通稱與個別名稱，「如漏觸」以下引用其餘戒條來顯明行相。前半段說明名稱的混通之處，「此就」以下說明此戒所要甄別的界限。「內」局限於男女的三道部位，「外」則通於整個身體。其後引用比丘尼的戒律為例，律中規定「腋下以下、雙膝以上、手腕以後，觸碰這些身分部位犯波羅夷，其餘部位犯偷蘭遮」。因為比丘尼體內體外的觸摸都是重罪，與比丘不同。然而在體外觸摸上，本身也分輕重，這與上述體內外的區別大致相同。
