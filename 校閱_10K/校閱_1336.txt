# 校閱材料　第1336檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1336-0001】資持記/15c_下三#22
【原文】劉氏，即蜀先主劉備；孔明，即諸葛亮，字孔明，先主重之，親命為丞相，先主曰：孤之有孔明，猶魚之有水也。是知富於道德，尚為王者見重，餘人可知矣。次況道中，初明他敬。道士，本釋氏之美稱；後為黃巾濫竊，遂不稱之。披法衣者，言其形相。遊佛行處，言其內心；
【譯文】文中提到的「劉氏」，就是蜀漢先主劉備；「孔明」，就是諸葛亮，字孔明。先主劉備對他極其信重推崇，親自任命他為丞相，先主曾感慨地說：我有了孔明，就像魚有了水一樣啊。由此可知，一個人只要道德深厚充實，連世俗的帝王霸主尚且對他刮目相看、由衷尊崇，其餘一般凡夫大眾的敬仰之情就更可想而知了。接著在比況出家修道的段落中，首先說明外人敬重僧寶的根本。所謂「道士」，原本是佛教對出家修道者極為優雅的美稱；後來因為被黃巾道教徒冒用竊取，佛教界才逐漸不再沿用這個稱呼。所謂披著如來的法衣，是就其出家外在的形相而言。所謂遊歷於佛陀的行處，是就其內在清淨的心地而言；

【1336-0002】資持記/15c_下三#23
【原文】三學八正，六度四弘，是佛行處。威儀等者，言其動止。若下，誡自敬。由自失者，歸過於已也。無不敬者，謂於人無所釋也。敬則下，彰益。敬有儀者，心形於外也。豈惟等者，自利兼他也。注中，顯示冥招之義。上舉喻，田無求心，人將種之，故云自投。道下，法合；
【譯文】戒定慧三學、八正道、六波羅蜜、四弘誓願，這些都是佛陀所親歷躬行的聖道行處。所謂威儀庠序等，是就僧人一舉一動的行住坐臥而言。自「若」以下，告誡僧人必須懂得自尊自重。凡事若是招致侮辱，往往「由自失」，也就是應當把過失歸咎反省在自己身上。所謂「無不敬」，是指面對任何人都不應有放逸輕慢的舉動。自「敬則」以下，彰顯自重所帶來的宏大效益。所謂恭敬有其威儀法度，是指內在的誠意自然會形諸於外在舉止。所謂「豈惟」等語，是說明這樣做不僅是自利，更能普利兼顧他人。注文中，深刻顯示出至誠感通、冥冥之中招感福應的道理。上文舉出比喻說，田地本身並沒有希求播種的心念，但農人自然會前往播下種子，所以說是種子「自投」於田地。自「道」以下，進行法義的契合說明；

【1336-0003】資持記/15c_下三#24
【原文】僧無須意，人自供之，故云潛託，潛即是冥，托亦投也。三中，初示他輕。以下，次明自失。法滅身者，反上形心威儀等事；縱放身心，內外無法，故滅於身。若下，結勸。注示待遇王臣之法，初教外儀。不迎送者，以屈道故。不同床者，恐媟慢故。又下，誡內心。
【譯文】真正的僧寶內心本無貪求供養的非分意圖，但信徒大眾自然會虔誠前來布施供養，所以說是「潛託」；所謂「潛」就是冥冥之中自然感應，「託」也就是自然投歸交付的意思。第三段中，首先揭示遭受外人輕賤蔑視的現象。自「以」以下，接著說明這是出於自身的放逸失德。所謂「法滅於身」，剛好與上文所說端正形相、護持心念、謹守威儀等要求完全背道而馳；隨意放縱身心欲望，內心毫無戒法、外表毫無威儀，所以戒法自然在自己的身心上毀滅殆盡。自「若」以下，總結並給予切實的勸勉。注文中開示對待世俗王公大臣的如法準則，首先教導外在應持守的威儀。之所以「不迎不送」，是為了不可在世俗權威面前屈辱貶低佛法尊嚴。之所以「不同床而坐」，是唯恐過於親暱而生起放肆輕慢之心。自「又」以下，嚴格告誡內在心態的持守。

【1336-0004】資持記/15c_下三#25
【原文】然此乃約比丘內有實德，王臣並懷深信，故可行之；今時道俗，二俱寡薄，未可如文。縱令有道，猶更觀機；事在臨時，隨宜適變；量器度之寬窄，審祿位之高卑，觀信樂之淺深，顧情分之生熟，是故《禮記》貴於從俗，易書美於隨時。苟滯一端，必遭禍難；
【譯文】然而這些戒規乃是針對比丘內在具有真實戒德、世俗王臣又都懷有深厚信敬心的情況而言，才能如此嚴正施行；現今這個時代的僧道與世俗二者，德行與信敬都極其淺薄微弱，絕對不能生搬硬套、死板地照著文字去做。縱使僧人自身確實有道行，臨事時仍更應當審慎觀察對方的根機；行事必須審時度勢，隨順具體情境靈活變通；要先衡量對方的度量器識是寬宏還是狹隘，審查對方的官階祿位是崇高還是卑微，觀察對方對佛法的信受喜愛是深厚還是淺薄，顧及雙方過往交情的深淺生疏，因此《禮記》極推崇隨順世俗常禮，《易經》也由衷讚美隨順時勢變通。如果死板固執在一個極端，必定會給佛門招來難以預測的災禍患難；

【1336-0005】資持記/15c_下三#26
【原文】古今多有，世事昭。23 釋訃請篇(下三)釋訃請篇訃是比丘允許，請即施主邀命。往訃前請，意存化導；必施法式，發越彼心，故云設則也。敘意中，初明俗眾營福所以。《智論》明福智二分，俗修福分，謂布施也；道修智分，謂學慧也。塵網所縈，故云昏俗。
【譯文】這種慘痛的教訓從古至今屢見不鮮，世間的真實事跡已經昭然若揭。第二十三篇 解釋訃請篇（屬於下卷第三部分）。解釋訃請篇所謂「訃」，是指比丘答應接受應請；所謂「請」，是指施主發心邀請降臨。僧人前往應赴施主先前的邀請，其本意全在於慈悲化導眾生；因此必須施設合宜的威儀法度，才能真正啟發彰顯施主內心的善根，所以說是「設則」。在敘述主旨緣起中，首先說明世俗大眾經營修植福報的原因。《大智度論》開示修福與修慧兩大部分，在家人主要修持福德部分，也就是行布施；出家人主要修持智慧部分，也就是學佛法智慧。世人常被塵世情網所牽纏束縛，所以形容為「昏俗」。

【1336-0006】資持記/15c_下三#27
【原文】制謂教示，非禁制也。接愚惑者，即前所謂作出家得道因緣；或復且令遠離惡道，生人天中，堪受化故。而下，次明道眾受訃乖儀。施通四事，故云雜繁。生譏即損他，癡慢即損自，苦趣，即自他俱墜。故下，示今所述。如別，即下十科。列章有十，攝盡始終。一六及九，事通僧俗，餘並在僧。
【譯文】此處所謂「制」，是指教化開示，並不是指禁止防制之意。所謂「接引愚昧迷惑之人」，也就是前面所說為他們種下未來出家得道的殊勝因緣；或者退一步說，暫且令他們遠離三惡道的痛苦，轉生於人間天上，以便未來堪能接受佛法教化。自「而」以下，接著說明出家大眾在接受赴請時違背威儀法度的弊病。施主的布施通於衣食住藥等四事供養，所以說是「雜繁」。招致世人譏嫌就會損害他人善根，僧人生起愚癡傲慢就會損害自身德行，最終自他共同墮入「苦趣」惡道受苦。自「故」以下，標示本書當前所要闡述的核心。所謂「如別」，就是指下文所列出的十個科判。條列的篇章共有十門，總括包攬了赴請從始至終的所有規範。其中第一、第六以及第九門，事理通於僧眾與俗眾雙方，其餘各門則全在於規範僧團內部。

【1336-0007】資持記/15c_下三#28
【原文】具如後釋。初門，來請中，《十誦》。明立維那，下翻寺護，謂監護寺事也。餘名如上卷。《僧祇》，初教答請。恐為緣阻，故不定答。若有下，令審實。不得下，明預探。此約生分，必是舊識，則不須之。次科，《五分》。開借僧物。《僧祇》。開僧作務。
【譯文】詳情如同後文逐一解釋。第一門，施主前來請僧的科判中引用《十誦律》。說明僧團應當設立維那這個執事，下文翻譯為「寺護」，意思是指監護管理整座寺院的事務。其餘執事的名稱已在上卷詳細說明。《僧祇律》中，首先教導如何如法應答施主的邀請。唯恐臨時被其他僧務因緣所阻礙，所以不宜立刻把話說滿、作絕對肯定的回答。自「若有」以下，指示應當審慎查明事實狀況。自「不得」以下，說明應先遣人預往探訪。這主要是針對不熟悉的生疏施主而言，如果必定是相熟的舊識，就不需要如此防備。下一個小科引用《五分律》。開許借用僧團公物給施主辦齋。《僧祇律》。開許僧人前往施主家協助操辦事務。
