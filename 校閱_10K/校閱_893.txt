# 校閱材料　第893檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【893-0001】資持記/01c_上一上#13
【原文】所以特引此二部者，此方盛弘。假實二解，敵對相反，於義易見。或可部計雖多，不出空有。是以下明戒體，亦出兩宗耳。兩部勝劣，略列四種，今合釋之。初戒本繁略，對下立教顯約。
【譯文】之所以特別引用這兩部律，是因為它們在漢地弘傳最盛。假名宗與實法宗這兩種見解互相對立相反，在義理上最容易辨明。又或者說部派的主張雖然極多，卻不外乎「空」、「有」兩端。因此下文在闡明戒體時，也同樣列出這兩個宗派。這兩部律典的殊勝與平庸之處，略可列出四種對比，現在一併解釋。第一項是「戒本的繁瑣與簡略」，這正對照著下文所說「立教的顯著與精要」。

【893-0002】資持記/01c_上一上#14
【原文】《十誦》著三衣有六戒〔一太高、二太下、三象鼻、四多羅葉、五參差、六攝縐〕，內衣同上，共十二戒，則為繁也。大小便利，止有一戒；敬塔都無，此為略也。《四分》敬塔便唾，各隨別相，具列多戒，故云顯也。著衣立二，義無不收，故名約也。
【譯文】《十誦律》中關於穿著三衣的威儀有六條戒〔一是太高、二是太低、三是象鼻形、四是多羅葉形、五是長短參差、六是摺疊不整齊〕，穿著內衣的規定也與上面相同，合起來共有十二條戒，這就屬於「繁瑣」。但對於大小便利的威儀卻只有一條戒，敬拜佛塔的規矩全無記載，這就屬於「簡略」。《四分律》對於禮敬佛塔與隨處便溺吐痰等事，各自依照不同的事相詳細列出許多戒條，所以說「條理顯著」；而對於穿衣的威儀只立了兩條大綱，在義理上卻無所不包，所以稱為「精要」。

【893-0003】資持記/01c_上一上#15
【原文】或可二部廣律戒本對辨優劣，學者尋之。二指體未圓，對下軌用多方。《十誦》色為戒體；能造所造，二俱是色；俱不談心，未窮業本，故未圓也。《四分》二非為體，體從心發；然限在小宗，曲從權意，別立異名。退非是小，進不成大；密使行人心希實道，多方之義，其在茲焉。
【譯文】又或者可以將兩部律的廣律與戒本互相比對來辨析各自的長短，這有待學者自行去尋繹。第二項是「指陳戒體尚未圓滿」，這正對照著下文所說「軌範運用的多方權變」。《十誦律》主張以色法為戒體；能造的四大種與所造的身口無表，兩者都屬於色法；完全不談及心法，未能窮究造業的根本，所以戒體理論「尚未圓滿」。《四分律》則以非色非心法為戒體，承認戒體是依心而發起的；然而由於教義被局限在小乘宗派之內，為了曲順權巧接引之意，特地另立了不同的名相。退一步看它不是單純的小乘，進一步看它尚未圓具大乘；暗中指引修行人心向真實大道，所謂「軌範多方」的深義，正體現在此處。

【893-0004】資持記/01c_上一上#16
【原文】故《業疏》云：由此宗中分通大乘，業依心起，故勝前計等。問：此句既明戒體，何以但云軌用多方？答：此宗法相，不唯談體；如《羯磨疏》五義分通，故茲一句通含多意。復彰今體望前雖勝，對大猶偏；但云多方，足彰部意。
【譯文】因此《業疏》說：正是因為本宗在義理上分通大乘，明示身口業皆依心識而生起，所以在見解上勝過前面那個宗派等等。問：這句話既然是用來闡明戒體，為何只說「軌用多方」呢？答：本宗所闡發的法相，並不局限於探討戒體；例如《羯磨疏》指出本宗有五種深義分通大乘，因此這一句話便統括涵蓋了諸多深意。再者，這也顯示了本宗的戒體相較於前面宗派雖然殊勝，但對比於純圓大乘仍略有偏頗；僅以「多方」相稱，已足以彰顯該部的獨特宗意。

【893-0005】資持記/01c_上一上#17
【原文】故《戒疏》云：斯人博考三機，殷鑒兩典，包括權實，統收名理等。若爾，前宗何以直示？答：彼部所立，正合小宗，定為偏計，更無他意。故直顯體，義兼隨行，亦非圓故。三接俗楷定，對下提誘生善。多宗五戒，必須盡形；八戒唯止一日一夜，此時定也。二戒不開分受；
【譯文】因此《戒疏》說：這部律的結集者博採三乘根機，深鑑大小二典，兼容權法與實法，統攝名言與法理等等。如果是這樣，前面的宗派為何能直接指出其體性偏狹呢？答：該部律典所創立的學說，恰恰完全吻合小乘宗義，純然被判定為偏狹的主張，絕無其他深遠寓意。因此直接揭示其戒體，在義理上也連帶說明其隨行是不圓滿的。第三項是「接引俗人的規範固定僵化」，這正對照著下文所說「提攜誘導以促生善根」。薩婆多宗（說一切有部）受五戒必須是盡形壽受持；八戒則只限於受持一日一夜，這是「時間上的固定」。而且這二戒不允許分開隨分受持；

【893-0006】資持記/01c_上一上#18
【原文】縱有分受，得善無戒，此數定也。《四分》二戒長短並通，全分皆得；接俗之教，但存生善，故非楷定。四御法無準，對下人法有序。彼宗人位雖同，不無差異；如無和尚得成受戒；及界內一人四處足數；一界之內，多處作法，互相受欲，此人無準也。三種羯磨，加則彌善，減則不成，即法無準也。
【譯文】縱然有分受的形式，也只能獲得世俗的善報而無法成就真正的戒體，這是「戒數上的固定」。《四分律》中這兩種戒在時間長短上都可通融，隨分受或全受也都能得戒；其接引在俗之人的教化，純粹以促成眾生生起善心為目的，所以並非僵化的固定法式。第四項是「御法統理缺乏通規」，這正對照著下文所說「僧人與行法皆有嚴整次序」。那一部派在僧人的僧位安排上雖然看似相同，卻不免多有乖張缺失；例如沒有和尚的在場居然能成就受戒的儀軌；以及結界內同一人居然可以在四處充當法定人數；在同一個結界之內，還可以多處同時作法、互傳受欲之辭，這就叫做「人無準則」。對於單白、白二、白四這三種羯磨作法，多加宣告番次則認為更善，減少番次則不能成就，這就叫做「法無準則」。

【893-0007】資持記/01c_上一上#19
【原文】〔文中似單明法，然御之一字，即能秉人。對下須知二皆無序。〕《四分》僧有四位，四人除三法〔白志、受滅、悔殘〕，五人除二法〔中受，悔殘。〕，十人除一法〔梅殘〕，二十人通作一切。又須精簡足數別眾，即人有序也。
【譯文】〔經文表面上似乎單單在闡明行法，然而「御」這一個字，正是指能夠秉持主持羯磨的人。比照下文，便當明瞭此宗的人與法都缺乏嚴整規矩。〕《四分律》中的僧團組織設有四個等位：四人僧可主持除三種法之外的一切事〔除受戒、自恣、出罪（悔殘）〕，五人僧可主持除二種法之外的事〔除中國受戒、出罪（悔殘）〕，十人僧可主持除一種法之外的事〔除悔僧殘〕，二十人僧則通辦一切羯磨。而且必須嚴格揀擇具備法定資格者，杜絕個別私聚，這就代表「僧人井然有序」。

【893-0008】資持記/01c_上一上#20
【原文】法有八位，心念有三〔但對眾也〕，對首有二〔但及眾也〕，眾法有三〔單白、白二、白四〕，眾別羯磨，各攝分齊，互不相通；少有增減，判歸非法，此法有序也。上明兩宗不同之相，皆是如來隨機施教，淺深不等；懸鑒未來部計支分，作輕重說。教興之意，於茲明矣。〔古師科此為分部教興者，遠矣。
【譯文】作法的儀式有八個層級：心念法有三種〔即但心念、對首心念、眾法心念〕，對首法有二種〔即但對首、眾法對首〕，眾法有三種〔單白、白二、白四〕，眾僧與個別的羯磨作法，各自統攝其法定分際，彼此絕不紊亂混淆；稍有增減短缺，即判歸為非法的羯磨，這就代表「法度井然有序」。以上說明兩宗不同的行相，全都是如來隨順眾生根機所施設的教法，深淺程度互有不同；佛陀預先洞察未來部派分裂支離的景象，而作了輕重不同的宣說。戒律教法興起的原因，在這些地方便徹底明朗了。〔古德將此段科判為「部派分裂後教法興起的原因」，這就相去太遠了。〕
