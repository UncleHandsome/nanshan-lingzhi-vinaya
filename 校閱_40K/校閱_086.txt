# 校閱材料　第086檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【086-0001】02_戒疏/03a_卷一下之一#90
【原文】【疏】有人言：「斯非佛解，乃法正之言。」今解不爾。五部十八，乃是人分。至於律教，無非佛旨，何得無學妄敢錯辭！縱有披解，自為卷帙，可以尋也。所以斯戒，必有隱相，唯佛自通。下重有疑，如法聚條部，有問為解。豈非戒為眾善之宗，非佛餘聖故不達也？
【譯文】【疏文】有人說：「這並非佛陀親自的解釋，而是法正尊者結集時的言語。」現在我的理解並非如此。五部、十八部律的分歧，是後世傳承之人的劃分；至於律藏的根本教法，無一不是出自佛陀的聖旨，身為無學果的聖者怎敢妄自置入自己的言辭！縱然無學聖者有所披陳析解，也都是各自撰為獨立的卷帙論著，有據可查。更何況這部戒律必定有極深奧隱微的義相，唯有佛陀才能親自暢通解析。下文若重新遇到疑問，如法聚條例的各部條款，都是一問一答進行解析。這難道不是證明了戒律是萬種善法的根本宗綱，除了佛陀之外，其餘的聖者都無法全然洞達透徹嗎？

【086-0002】02_戒疏/03a_卷一下之一#91
【原文】【記】次科。初出古判。「今」下，正斥。初立理顯非。謂部類雖分，教旨不易，即前序云「賢聖緘默，但知祗奉」是也。「錯」音醋，置也。「自為卷」者，如《多》、《伽》、《見》、《母》諸戒論等。若許擅加，何須別解！於義自顯，故曰「可尋」。「所」下，彰佛獨說，上文證定。「豈」下，示意。私釋：「大千界內，佛為法王，律是佛敕，唯聖制立。自餘下位，但可依承。良以如來行果極圓，窮盡眾生重輕業性。等覺已下，猶非所堪，況餘小聖，輙敢擬議？有如國家，賞罰號令必從王出，臣下僭越，庶人失信，亡敗無日。佛法亦爾，若容他說，群生不奉，法不久住故也。」
【譯文】【記文】第二小節。首先提出古人的判定。「現在」以下正式斥責駁斥。起初樹立正理彰顯其謬誤。意思是部派分類雖然分歧，教法的宗趣絕不隨意改變，正如此前序文中所言「賢聖皆恭默奉持，只知恪尊遵奉」就是這意思。「錯」音讀為醋，是置放、安置之意。「各自著成卷帙」，就像《薩婆多論》、《摩得勒伽論》、《善見論》、《毗尼母論》等諸部戒律論典。如果容許後人擅自增添注釋於經文中，何需再另外撰述專論！其道理極為明顯，所以說「有據可查」。「更何況」以下彰顯唯佛獨宣的尊貴，以上文作為印證。「這難道不」以下指出其深刻用意。私下補充說明：「在大千世界之中，佛陀是至高法王，戒律是佛陀的王敕法令，唯有大聖佛陀才能制定建立。自此以下的其餘位階，都只能依教奉行。這是因為如來的修證果位極其圓滿，唯佛一人能徹照眾生極微細的輕重業性。縱使是等覺菩薩以下的聖者，尚且無法全盤洞悉承擔，更何況其餘小乘聖者，豈敢隨意擬議修改？這就好比國家天下，賞善罰惡的政令法令必須出自君王，臣下一旦越權僭越，百姓就會喪失信用，國家滅亡就指日可待了。佛法也是如此，如果允許其他人擅自制定改動經文，眾生就不肯恭敬奉行，正法也就無法久住於世了。」

【086-0008】02_戒疏/03a_卷一下之一#97
【原文】【疏】由斯戒法，能持七支，有過皆塞，名「自攝」也。身口既攝，光淨如珠，順本所受，故名「持」也。行善所及，各有憲章，名「威儀」也。「威」謂容儀可觀，「儀」謂軌度格物，並由內懷正法，故使器宇超倫也。
【譯文】【疏文】由於這項戒法，能夠規範守護身口七支惡業，一切過失都能防堵閉塞，所以稱為「自攝」。身業與口業既然得到收斂約束，身心光明潔淨有如寶珠，完全吻合當初受戒的本願，所以稱為「持」。善行所及之處，處處合乎威儀規範，稱為「威儀」。「威」是指莊嚴的儀容受人敬重觀仰，「儀」是指有法則準繩可供匡正導引大眾，這全都是因為內心懷抱正法，所以使得身心器宇氣質超凡脫俗。

【086-0009】02_戒疏/03a_卷一下之一#98
【原文】【記】別釋，初科有三。初、釋自攝，即含法體。「塞」，猶止也。次、釋持字，即戒行。三、釋威儀，即戒相。「憲章」指律教，行與教合，美德顯故。「格」，正也。「器宇」，即目形儀。「倫」，猶羣也。
【譯文】【記文】在分別解釋中，第一小節分為三層意思。第一、解釋「自攝」，即涵蓋了戒律的法體。「塞」如同防堵止絕的意思。第二、解釋「持」字，即是指受持的戒行。第三、解釋「威儀」，即是指具體的戒相。「憲章」是指律藏教法，修行與教導完美吻合，美德自能彰顯。「格」是匡正的意思。「器宇」指個人的身形威儀與心量氣度。「倫」是指同列儕輩。

【086-0010】02_戒疏/03a_卷一下之一#99
【原文】【疏】言「住處」者，正行由教而成，教是行之所依，故名「住處」。如《經》「戒為功德住處」也。
【譯文】【疏文】提到「安住之處」，正確的行持是依靠教法才能成就，教法是行持得以安住依止之所，所以稱為「住處」。正如《佛遺教經》所說：「戒是一切清淨功德的住處。」

【086-0011】02_戒疏/03a_卷一下之一#100
【原文】【記】次科。教、行對論，若約相成，則教能行所；若論相依，則行能教所。此釋「住處」，正取於教，上舉「能成」，顯下「所依」。
【譯文】【記文】第二小節。教法與行持相互對照來論述，若就相互成就而言，則是教法為主動、行持為成就；若是就依止歸宿而言，則是行持依止於教法。此處解釋「住處」，正是聚焦在教法上，上面舉出「能夠成就」，是為了顯明下面「所依止的教法」。

【086-0012】02_戒疏/03a_卷一下之一#101
【原文】【註】「行根、面首。」
【譯文】【註文】「是一切修行的根本、身相的面首。」

【086-0013】02_戒疏/03a_卷一下之一#102
【原文】【疏】注中「行根、面首」，此歎木叉生善相也。由戒能生成萬「行」，喻若於「根」；如《經》云「若無戒者，諸善不生」，即其證也。又如《論》云「戒為眾善之根，生善中勝，無過斯法」，喻同「面首」也。
【譯文】【疏文】注釋中所說的「行根、面首」，這是讚歎波羅提木叉能夠滋生善法的功德相貌。由於戒律能夠滋潤生成萬種德行，所以用「樹根」來作比喻；如同經中說「如果不持戒，一切善法皆不能生長」，這就是明證。又如同論典所說「戒律是一切善法的根本，在一切滋生善法的功能中最為殊勝，沒有任何法門能超過它」，所以用「面首頭面」來作尊貴的比喻。

【086-0014】02_戒疏/03a_卷一下之一#103
【原文】【記】生善中二喻，「根」喻出生，「面首」喻尊勝。初總判，「由」下，別釋。初據《遺教》，但合「根」喻。「又」下，次引《多論》，雙合二喻。「根」義同上。「首」居五體之尊，戒為萬善中勝故也。
【譯文】【記文】在滋生善法中包含兩個比喻，「根」比喻能夠滋生萬行，「面首」比喻最為尊貴殊勝。首先是整體判定，「由於」以下是逐一解釋。起初依據《佛遺教經》，只吻合了「根」的比喻。「又如同」以下進一步引證《薩婆多論》，同時融會貫通了這兩個比喻。「根」的涵義與上文相同。「首」位居全身五體的最上方最尊榮之處，象徵戒律是一切善法中最為殊勝無比的緣故。

【086-0015】02_戒疏/03a_卷一下之一#104
【原文】【註】「集眾善法，三昧成就。」
【譯文】【註文】「匯集一切眾善之法，成就三昧正定。」

【086-0038】02_戒疏/03a_卷一下之一#127
【原文】【記】佗解中三節，並約揀眾。一、簡足數。「過犯」謂三舉二滅人，更兼尼等四眾，瘂、聾、睡、狂等人。二、簡欲緣。「大急」即三寶、疾病等。三、簡合訶。「四羯磨」：一、訶責，二、擯出，三、依止，四、遮不至白衣家。此四，《律》名「得滿不得訶」。「諸雜治」者，即收行覆藏等人。竝由奪其智能，不得訶法；必非此等，方名「應訶」。「若」下，總結。「陶練」，即是揀擇。「實人」，謂合教者。
【譯文】【記文】在另一種解釋的三個層次中，全部都是針對甄選篩除會眾而論。第一、簡別合格的法定人數。「違犯過失」是指被判處三種擯舉、二種滅擯的人，還包括比丘尼等其餘四眾，以及啞巴、聾子、熟睡、狂亂失心等人。第二、簡別准許請假傳欲的因緣。「極重大因緣」是指守護三寶物資、突發重病等。第三、簡別有資格提出反對發言的人。「四種羯磨處分」是指：一、訶責羯磨，二、擯出羯磨，三、依止羯磨，四、遮不至白衣家羯磨。這四種在《律》中被稱為「得滿法定人數，但無權發言反對」。「各類受處分者」是指包括正在行履隱覆藏罪懺悔等處分的人。這些人全都被剝奪了正常的僧權智能，不能依法反對法事；必定要排除這些人，才稱得上是合格的「應訶止反對之人」。「必須經過」以下是總結。「甄查甄別」就是嚴格簡別挑選。「合格合法人員」是指完全合乎教法律儀的僧眾。

【086-0046】02_戒疏/03a_卷一下之一#135

【原文】【疏】言「客舊外集」者，法攝人也。如有違背，不無其罪，則人從法也。初來聞序，不勞告淨，以聞三問也。八篇中來，必須告淨，以不聞序。
【譯文】【疏文】提到「客比丘與舊住比丘在會外聚集前來」，這是以法制來統攝約束人員。如果有人違背法制作法，就免不了背負過失罪名，這就是讓人隨順於法制。如果是剛來時正巧聽到了戒序，就不必另外宣告清淨，因為已經聽聞了戒序中的三度發露審問。如果是在進入八篇正戒的誦讀過程中才到達，就必須依法宣告自己清淨，因為沒有聽到前面的序文。

【086-0066】02_戒疏/03b_卷一下之一#1
【原文】【註】佛言：「謂所犯事未懺悔也。有二種智人：有罪能見，見罪能如法懺悔。若欲悔者，當詣清淨比丘，說犯名字，如法除已，方得聞戒。乃至於罪有疑亦如是說。若僧並犯，無人可懺，不問識、疑，白懺後說。」
【譯文】【註文】佛陀開示：「這是指所犯的過失尚未如法懺悔。世間有兩種智者：一是犯了過錯能夠自己察覺，二是察覺過錯後能如法進行懺悔。如果想要懺悔，應當前往戒行清淨的比丘處，陳述所犯戒條的名稱，如法除滅罪過後，才有資格聽聞戒律。乃至於對自己是否有罪心中生疑，也應當照樣陳述。如果全體僧眾都犯了同樣的過失，無人可作受懺對首，那麼無論是明知有犯還是心中存疑，都應當在僧中作白告懺悔，然後才能說戒。」

【086-0067】02_戒疏/03b_卷一下之一#2
【原文】【疏】注中「犯事未悔」者，釋成有罪相也。但以無始無明想倒為本，動念緣境，何得蕭然？唯有智人，能見能懺；自餘惑重，何由開悟？故《律》文云「無學果人不故犯戒」，三果同凡，未免緣縛，可不思哉！
【譯文】【疏文】夾註中所說的「犯過未懺悔」，是用來解釋前文已具備罪過的狀態。這無非是以無始以來的無明妄想顛倒為根源，只要起心動念攀緣外境，又怎能保持超然無染、清淨無繫？唯有具足智慧的人，才能察覺罪過並能如法懺悔；其餘煩惱深重的人，又從何得以開悟解脫？因此律文指出「證得阿羅漢果的聖人不會故意犯戒」，而初果至三果聖人與凡夫相同，仍難免受外緣牽纏繫縛，這難道不值得深切省思嗎！

【086-0068】02_戒疏/03b_卷一下之一#3
【原文】【記】釋注中，初科。前牒示。「但」下，推釋。初敘犯多，上二句示惑，下二句明業。「蕭然」謂清靜無繫之貌。「唯」下，明懺少。「故」下，引聖誡凡。初、二兩果，故心犯性，三果故心犯遮，四果悞心犯遮。
