# 義鈔缺口原因

## 規模

```text
定稿：190 單位
頁面：558 段
缺口：25
```

## 不是定位問題

這 25 個缺口不是 unit 位置偏掉，是定稿真的沒有那些區間。

例：

| 缺口 | 長度 | 內容 |
|:--|--:|:--|
| G01 | 472 | 此鈔傳世其來久矣…… |
| G02 | 1,044 | 持犯等義兩鈔猶同…… |
| G05 | 2,933 | 第一序名略解者…… |
| G06 | 2,710 | 第六發戒時節者…… |
| G07 | 3,332 | 第一隨難略解者…… |
| G13 | 5,191 | 第一毒業成犯者…… |
| G14 | 3,572 | 第七隨難略解者…… |

這些都是正文，不是卷題、目錄、校勘。

## 為什麼對不上

義鈔 `_終審` 只有 207 個單位，但頁面有 558 段。

```text
終審：207
頁面：558
差：351
```

所以定稿只覆蓋一部分，其他區間自然變成 25 個大缺口。

## 翻譯有沒有

頁面 558 段裡可能有對應譯文；但那些沒有進 `定稿/yichao.jsonl`。

所以目前是：

```text
頁面有內容
定稿沒有 unit
```

不是完全沒有翻譯，是定稿沒收。

## 結論

```text
義鈔 25 缺口：定稿缺 unit
原因：終審只有 207 單位，不是全書
```

## 下一步

1. 從頁面或 `AI語譯/out/義鈔` 找回這 25 段
2. 補進 `定稿/yichao.jsonl`
3. 不要再用 fuzzy 定位硬拉
