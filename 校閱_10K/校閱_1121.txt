# 校閱材料　第1121檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1121-0001】資持記/07e_中一下#15
【原文】若作異相，過分勝者，重。〕，十處所〔如店肆作處，盜物盜體，同上村中。〕，十一船處〔盜物即以船為處；盜船體者，斷繩離處方犯。〕，十二盜水〔即斷水注也，《僧祇》：溉灌水，或一宿，直一文，或至四五；若壞彼渠，得越；水入田蘭，滿五者夷。〕，十三私度關〔如律：比丘無稅，白衣應稅，為彼過物重。
【譯文】如果私自偽造界標，越界霸佔勝訴的，犯重罪。〕，第十「處所」〔如同店鋪、作坊等處，盜取其中的財物或破壞處所本身，都與前面村落的情況相同。〕，第十一「船處」〔偷取船上的財物，就以船為處所；若是偷取船隻本身，必須斬斷纜繩離開原位才構成犯罪。〕，第十二「盜水」〔就是截斷水流引水，如《僧祇律》說：灌溉用的水，引灌一宿，價值一錢，有的甚至價值四五錢；如果破壞他人的水渠，犯越法罪（突吉羅）；水流引入自己的田地犯偷蘭遮，若價值滿五錢則犯波羅夷。〕，第十三「私度關」〔如律中所說：比丘免除稅負，白衣應當納稅，如果替白衣夾帶貨物過關則犯重罪。

【1121-0002】資持記/07e_中一下#16
【原文】《十誦》：比丘應稅不稅亦重，餘廣如疏。〕。結示中，文為三段，初示前略意。憂下，二明人有順違；初明知足之人，懼犯退藏；若下，明多事求進，為盜所陷。言憂心者，心之可畏，難可禁制；微縱成業，殃及累世，是可憂故。念道者，慕出離也。緣境局者，為教所禁也。
【譯文】《十誦律》說：比丘應當納稅而不納稅的也犯重罪，其餘詳細內容如同《戒疏》所說。〕。在結語示導中，文章分為三段，首先說明前面略述的用意。從「憂」字以下，第二段說明人有順從與違背戒法兩種情況；先說明知足的人，懼怕犯戒而退避隱藏；從「若」字以下，說明多攬事務、追求升遷之人，往往被盜戒之罪所陷害。說到「憂心」，是因為這顆心實在可怕，難以節制；稍微放縱就會造作惡業，禍害波及累世，所以令人擔憂。所謂「念道」，是指企求脫離輪迴。「所攀緣的境界受限」，是因為受到戒教的禁制。

【1121-0003】資持記/07e_中一下#17
【原文】多眾務者，或好為人師，或樂營世福也。欲高升者，名位過人也。羅盜網者，結業成也。無有出者，苦報無窮也。何下，微示其意，如前《寶梁》所揀人也。有下，三勸修。初句，召後人也。細讀者，勸尋教也。附事者，以教照境也。深思者，以境觀心也。乃知者，自省心行也。
【譯文】「事務繁多」，是指或者喜歡收徒為人師表，或者熱衷營造世間福報。「想要步步高升」，是指希求名位超群拔萃。「落入盜竊羅網」，是指惡業已經造作圓滿。「永無出離之日」，是指承受苦報無有窮盡。從「何」字以下，稍微點明其中的意旨，如同前面《寶梁經》中所揀選淘汰的那種人。從「有」字以下，第三段是勸勉後人修持。第一句，是呼喚後世之人。「細細研讀」，是勸勉尋求戒教真義。「附著於事相」，是用教法來觀照外境。「深刻思維」，是以所對之境來反觀內心。「方才知曉」，是自我省察內心的起心動念。

【1121-0004】資持記/07e_中一下#18
【原文】故下，引論以勸。論中，初句通示教意；此下，別指今戒，必須繁文。曲碎解釋者，論涉三卷故也。其義理等者，勸詳審也。論下，準論顯意。初二句指上列釋，蓋準論文；猶下，遮後妄謂，以彰略意。不犯中，初引五想。皆謂無盜心也。與想者，意謂他與也；己有者，謂非他物也；
【譯文】所以下文，引用論典來進行勸勉。論典中，第一句普遍顯示戒教的用意；從「此」字以下，特別指出眼前的盜戒，必須用繁複的文字來說明。所謂「曲碎解釋（詳盡細緻地剖析）」，是因為相關論述牽涉了三卷之多。所謂「其義理」等語，是勸人詳加審查。從「論」字以下，是依照論典來彰顯用意。最初兩句指稱上面的陳列解釋，乃是依據論書文字；「猶」字以下，是為了防範後人妄加非議，藉以表明之所以從略的用意。在不犯的範疇中，首先引用五種無犯罪之想，都指內心沒有偷盜之意。所謂「與想」，是心裡認為對方要送給自己；「己有想」，是認為這並非別人的物品；

【1121-0005】資持記/07e_中一下#19
【原文】糞掃者，謂無主也；暫取者，即持還也；親厚者，無彼此也。律下，別釋第五。七法中，一竭力代勞，為之不厭；二己所重物，與之不悋；三極相違惱，了無所恨；四吐露私心，而無所隱；五掩惡揚善，恐傷外望；六囚繫患難，多方拯濟；七貴賤貧富，終始一如。如是下，結顯。
【譯文】「糞掃想」，是認為這物無主而拋棄；「暫取想」，是指拿用後立刻歸還；「親厚想」，是彼此交情深厚而不分你我。從「律」字以下，特別解釋第五種「親厚」。在具備的七法中：一是竭盡全力代為操勞，替對方做事不知厭倦；二是自己看重的珍貴物品，贈給對方毫無吝嗇；三是彼此極為違逆惱怒時，心中了無懷恨；四是吐露內心隱私，彼此毫無隱瞞；五是隱惡揚善，擔心損害對方在外的好名聲；六是對方身陷囹圄患難時，想方設法給予拯救；七是無論對方富貴貧賤，從始至終待之如一。從「如是」以下，總結顯明。

【1121-0006】資持記/07e_中一下#20
【原文】故知誠實方入開位，自餘濫託，皆陷刑名。殺戒。〔佛在毘舍離，諸比丘修不淨觀，厭身歎死；外道比丘難提，受雇行殺，居士驚怖，因制。〕標名中。簡於非畜，不犯重故。或名大殺，簡後小故。隨釋中，初文。引律：極齊初後，總攝殺相。注中，初至所依，釋上初識。
【譯文】因此得知，唯有誠實相待才算符合開許的地位，其餘濫加託藉藉口的，全都會陷於刑律罪名之中。殺生戒。〔佛陀在毘舍離時，眾比丘修習不淨觀，厭惡自身而讚美死亡；外道比丘難提，受雇替人執行殺戮，居士們驚恐害怕，佛陀因此制定此戒。〕在標明名稱中，簡別非人與畜生，因為殺害牠們不犯重罪。或者稱作「大殺」，是為了簡別後面殺畜生等「小殺」的緣故。在隨文解釋中，第一段文字引用律文：涵蓋從最起初的投胎到最後的命終，總括攝受一切殺生的相狀。在注文中，從開始到「所依」，是解釋上面的「最初之識」。

【1121-0007】資持記/07e_中一下#21
【原文】《大集經》云：歌羅邏時〔此云雜穢，入胎七日，狀如凝酥，即凝滑也。〕，即有三事：一命，二煖，三識，出入息為命，不臭不爛為煖〔業持火大，色不臭爛。〕；此中，心意識為識，若壞凝滑，即壞識之所依，命煖隨謝，便名犯殺。乃至下，釋上後識。謂四大將解，識神未去，害亦成重；
【譯文】《大集經》說：處於歌羅邏時期〔此處譯為雜穢，是受胎第七天，形狀如同凝固的酥酪，也就是凝滑的狀態。〕，便具備三件事：第一是壽命，第二是體溫（煖），第三是心識。呼吸的出入便是壽命，身體不臭不爛便是有煖氣〔由業力持守火大之性，色身才不致腐臭潰爛。〕；這其中，心意識就是識，如果破壞了凝滑之胎，就是破壞了神識所依託之處，壽命與體溫隨之壞滅，便構成殺生之罪。從「乃至」以下，是解釋上面的「最後之識」。這是指四大肉體即將瓦解、神識尚未離體之際，加以害死也構成重罪；

【1121-0008】資持記/07e_中一下#22
【原文】疏云：隨有煖處，識在其中，即識住處，為命根攝。其下，顯略。辨相中，初科，先明自殺。初句標。謂下，列相。準《注戒》有八，今闕二種，下引足之。身現相〔或令怖畏墜墮，或示死相等。〕，口讚死相〔《注戒》作口現相，謂以言說勸教，或以大聲恐喝，今鈔語局初解。
【譯文】《戒疏》說：只要有體溫之處，神識便在其中，這神識止住之處，就為命根所攝持。從「其」字以下，表示文字有所省略。在辨明罪相中，第一個綱目，首先說明親自下手自殺（殺人）。第一句是總標。從「謂」字以下，列舉具體相狀。依照《注戒》原本有八種相，如今此處缺少兩種，下文引述加以補足。身體現相〔例如使人恐怖以致墜落，或者示現死相讓對方畏縮而亡等。〕，口中讚美死相〔《注戒》作口現相，是指用言語勸告唆使，或者以大聲恐嚇致死，如今《行事鈔》的文意僅侷限於第一種解釋。
