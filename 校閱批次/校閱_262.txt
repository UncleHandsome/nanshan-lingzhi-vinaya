# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【262-0016】03_業疏/19b_卷四之二#39
【原文】如何識罪同時犯耶？世所同行，雖罪不責。如受錢寶為利行道，禮佛誦經，所獲贓賄，合眾安坐，知非而受，是為一罪通於僧也。故律云「僧犯尼薩耆」者，即斯人也。或人別隨犯，名種不同，挍量其罪，俱非清淨。雖非同犯，無任應說，理總白懺，露過便滅
【譯文】如何辨識大眾是同時犯了罪過呢？世人共同實行的風氣，往往雖然是罪過卻不以為過。例如接受金銀錢寶，假借利益之名而修行辦道、禮佛誦經，所得的非法髒物與賄賂，全體大眾安然同坐，明知非法卻共同接受，這便是一罪通及全體僧眾。所以律中所說「僧眾犯尼薩耆捨墮」，就是指這種人。或者各人分別隨緣毀犯，罪名種類各有不同，衡量其罪相，全都不得清淨。這雖然不算共同犯同一罪，但全界已無合格之人可以登座說戒，按理應當總括宣告向大眾發露懺悔，罪過一經發露便得消滅。

【262-0030】03_業疏/19b_卷四之二#53
【原文】律文不言更懺，明知本罪隨滅。何以知耶？夫懺罪對人，令證瑕累；今作白告，通無纖隱，人俱非淨，法是除緣。如草覆白，罪諍同滅，亦俱有罪相向露也。故作此白，一切偷蘭下諸篇罪犯皆除也。上二篇罪，須僧別法，故非所論
【譯文】律文中沒有說事後還要再懺，顯然可知原犯之罪隨即滅除。憑何得知呢？因為懺罪通常需要面對他人，令對方印證自己的過失；如今透過作白宣告，全無絲毫隱瞞，在眾人皆非清淨的情況下，作白之法便是除罪之勝緣。正如「草覆地」的羯磨宣告，使罪過與諍端同時滅除，也是雙方皆有過失而彼此發露。因此作了這項宣告，一切偷蘭遮以下各篇的罪犯全皆滅除。至於波羅夷與僧殘前二篇重罪，必須依僧眾之別法處理，所以不在此例。

【262-0031】03_業疏/19b_卷四之二#54
【原文】三中，初準判。「何」下徵意：初敘所以，對眾無隱，心淨罪除，準此白前，必應告眾，慚耻自責，向僧發露。如下引例滅諍草覆，事義頗同，故下簡濫，除上二篇，餘皆可懺
【譯文】在第三段中，首先依律裁斷。「何」字以下探問其旨趣：先敘述何以如此——向僧眾發露而毫無隱瞞，心念清淨罪業便得消除，準照此理，在作白宣告之前，必定應當告誡大眾，心懷慚恥自我責備，向僧眾發露過咎。自「如」字以下引述「草覆地滅諍」為例，事相與法義十分相似；「故」字以下甄別濫同，指出除了前二篇重罪之外，其餘罪過全都可以以此懺除。

【262-0032】03_業疏/19b_卷四之二#55
【原文】二就疑罪者，此疑從事生，必對方除也。如旦食粥似於正食，至中還噉，有疑犯足，須待淨人方定罪目。但露無瑕，便應淨法。故雖白露本罪不滅，由未了知，不名懺斷。不同前白，識達無疑，告情及罪事，同對首有斯異也。《十誦》云：一切僧同犯，單白向四方僧，後如法懺。故知不滅矣
【譯文】第二、就「疑罪」而言，這種懷疑是因事而生，必須對著清淨僧人才能遣除。例如早晨喝的粥稠厚得如同正食，到了日中時分又再進食，這時就會懷疑是否犯了足食戒，必須等待淨人判定才能確定罪名。但只要發露而無隱瑕，就符合清淨之法。因此，雖然作了白告發露，但本罪並未消滅；由於尚未明了罪相，所以不名為懺斷除罪。這不同於前面的發露——前面是清楚明了而無疑惑，能陳告實情及所犯事相；雖然同樣是向對首發露，卻有這般差異。《十誦律》說：全體僧眾同犯時，以單白羯磨向十方僧發露，之後仍須如法懺悔。由此可知本罪並未消滅。
