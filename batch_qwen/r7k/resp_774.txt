整體看下來，譯文的**大方向與義理判讀是正確的**（身證實語／想心實語的分別、佛唯身證、聲聞有想心實語，都掌握到了）。主要問題集中在三類：**關鍵詞誤譯（謂言、劣用、悉）**、**增譯過多（感應、戲水、怪罪、純熟、殊勝…）**、以及 **「見／聞」前後不一致**。以下逐則說明，最後附建議修訂稿。

## 一、逐則檢查

### 【774-0001】疏文

| 級別 | 問題 | 說明／建議 |
|---|---|---|
| ★★★ | 「**謂言定體**」譯成「他卻**誤以為**這已經是正定的本體」 | 「謂言」是「**說、宣稱**」，不是心裡以為。此處正關乎妄語的構成（說了「我入某定」），下一則記文「彼謂定體，則同妄語」也是就「說」而判。應作「他卻**說**那就是定體」。 |
| ★★★ | 「見／聞」混亂 | 疏文本身「聞彼異域奇相」「定中見也」是**見聞互用**，但本事例（律文）實際是**聽聞象入水聲**。譯文一下「聽聞到…奇特**景象**」（動賓不搭）、一下「心中所**見**」「何以能**看見**這些奇異的**色相**」，讀者會誤以為是看見影像。建議統一作「見聞」，並註明此處以「聞」為主。 |
| ★★ | 「自然**感應**聽聞」 | 「自然」是「自然而然、不假作意」，非「神通感應」。加「感應」屬增譯，且易誤導。 |
| ★★ | 「**殊勝上法**」 | 「上法」＝**上人法（過人法）**，即禪定、神通、道果等超越凡夫之法，是大妄語戒的所稱對象。直譯「殊勝上法」語意含混，建議譯出「上人法」並略註。 |
| ★★ | 「其餘**不知情的人**」 | 記文明言「引**比丘**疑怪」，應作「其餘比丘」。 |
| ★★ | 「定不清淨」譯為「在定境**尚未純熟**清淨時」 | 原文是直判「（他的）定不清淨」——夾雜見聞，非真正的空定；譯文改成時間副句＋「純熟」，語氣被弱化。 |
| ★ | 「實爾」譯「目犍連所言確實屬實」 | 可，但宜作「確實有此事（他確實聽到）」，避免讀者誤會佛也認可「他在空慧定中」這句話。 |
| ★ | 「入定之前的**加行前行**」 | 加行＝前行＝方便，三詞疊用累贅，擇一即可。 |
| ★ | 《四分律**廣本**》 | 「律本」即道宣所宗的《四分律》本律（記文亦證「且據《四分·調部》」），作「《四分律》本律」較清楚。 |

### 【774-0002】記文

| 級別 | 問題 | 建議 |
|---|---|---|
| ★★ | 「走入難陀池中的**戲水聲**」 | 律文只作「入…池水聲」，「戲水」是添加的情節，應刪。 |
| ★★ | 引號與標點：「所以稱為『前方便加行 **。**』」 | 句號應在引號外；且疏文原引的是「**方便**」二字，譯文不宜把增補語塞進引號內。可作：所以稱為「方便」（入定前的加行）。 |
| ★★ | 「懷疑**怪罪**」 | 「疑怪」是疑惑詫異，未必含責備；0001 的「疑慮怪異」也不成詞。統一作「疑惑驚怪」。 |
| ★ | 「**分文**為四」→「將**文義**分為四部分」 | 「分文」是科分疏文段落，非分文義。作「將疏文分為四段」。 |
| ★ | 「佛陀為大眾**排解**斷疑」 | 「決疑」是裁決斷疑（律中佛作判），非調解。作「決斷眾疑」。 |
| ★ | 「結語**開示**」 | 「結示」＝總結標示（點出此即想心實語）。「開示」一般用於佛說法，此處是元照科文用語。 |
| ★ | 「故下指之」 | 可補一句「所以疏文後面（『如《僧祇》、《律本》』句）便指出它」，讀者才知「下」指哪裡。 |
| 建議 | 「四空定」「空慧定」「伊羅婆尼象」「難陀池」 | 全段無註，讀者難懂**比丘為何起疑**。建議加註：四空定＝四無色定；空慧定一般解為空無邊處定，**無色定中不應見聞色聲**，故疑其虛稱；伊羅婆尼＝帝釋天象王 Airāvaṇa；難陀池＝難陀龍王池。 |

### 【774-0003】
無錯誤。可補足問意的對比：「既是依親見親聞而說（應屬**身證實語**），為何只判為想心實語？」——否則「何但想實」的「但」字張力出不來。

### 【774-0004】
- ★★★ 同 0001：「彼**謂**定體」譯成「誤以為是根本定體」→ 應是「他卻**說**那是定體」。譯文先說「誤以為」，再說「等同於說了妄語」，邏輯斷了一環（只在心裡以為，何來妄語？）。
- ★★ 「所以判為**不犯大妄語重罪**」：原文只作「故無犯耳」，律中佛判「目連無犯」。加上「重罪」二字，易讓人誤會「仍犯輕罪」。建議逕作「所以不犯」。
- ★ 「這在**客觀上**就等同於妄語」是很好的增補（點出「境虛而想實」），可保留，但最好寫成「所說與事實相違，就等同妄語；但所說與所想一致，故不犯」，把**境／想**兩層判準交代清楚。

### 【774-0005】
- ★ 「舉彼大聖」的「舉」未譯出，可作「那麼**就佛陀這位大聖者而言**，是否也有這兩種實語呢？」
- ★ 「至高無上」為增譯，可略。

### 【774-0006】
| 級別 | 問題 | 說明 |
|---|---|---|
| ★★★ | 「二者**劣**用不同」→「定中與出定的**功用層次不同**」 | **「劣」字漏譯**。此句是說聲聞之用**下劣**且入出**不一致**（對照佛之勝用）。建議：「入定、出定二者的功用低劣而且前後不同」。「二者」宜明確點出是入／出二時。 |
| ★★ | 「**悉**見佛國」→「於**一切時**皆澈見諸佛國土」 | 「悉」是**遍見一切佛國**（空間），不是「一切時」（時間已含在「常在」）。應作「普見一切佛國」。（《維摩經·弟子品》原句：「有佛世尊，得真天眼，常在三昧，悉見諸佛國，不以二相。」譯文補主語「如來」是對的。） |
| ★ | 「永斷一切夢境、**虛妄的思想**與念頭」 | 「思、想、念」在佛教語彙是三個心所，不宜讀成現代複詞「思想」。建議「永斷夢妄與思、想、念等心念」，或保留原句加註。 |
| ★ | 「唯獨具有**自身證得的實語**」 | 生硬。可作「只有『身證實語』（親證其境而如實說）」。 |
| ★ | 「深妙三昧」「**絕**非如此」「**絕**無」 | 形容與語氣的加码，疏記體宜收斂。 |
| ✔ | 「常在三昧」主語判為如來 | 正確，與經文合。 |

## 二、建議修訂稿（僅列改動較大的四則）

**0001**
> 然而那位聖者（目犍連），在入定前的方便加行中，理上作空慧觀、事上仍有覺察，因而自然聽聞到他方遠處的奇異聲相。出定之後，便依心中所認定的情形向人陳說：「我是在空慧定中見聞到的。」其餘比丘不了解，便生起疑惑驚怪：空慧定中怎麼可能還見聞這些奇相？這麼說來，目連豈不是虛妄宣稱證得上人法？如《摩訶僧祇律》與《四分律》本律中，都有這類事例。佛陀裁決說：「確實有此事。只是他的定不清淨，那其實是入定前的方便，他卻說那就是定體。」像這樣的事相，就稱為「想心實語」。

**0002**（僅修關鍵處）
> ……將疏文分為四段：第一段顯示想心。將要入定時，收攝心念專注作想，忽然覺察到奇異之事，這並非真正的定，所以稱為「方便」。……《律》說：「目連告訴諸比丘：『我入空慧定，聽到伊羅婆尼象進入難陀池的水聲。』」從「餘」字以下，第三段引諸比丘的疑惑驚怪……《僧祇律》所記與此相同，所以疏文後面指出它；《十誦律》也是如此。從「佛」字以下，第四段引佛陀決斷眾疑。最後兩句，是總結標示。

**0004**
> 回答說：那本是入定前的方便，他卻說那就是定體，所說與事實相違，就等同於妄語。只是由於他不能辨識，心中作「這就是正定」之想（所說與所想一致），所以不犯罷了。

**0006**
> 回答說：如來觀照境界窮盡無餘，所以只有「身證實語」。為什麼呢？聲聞了達境界仍有限礙，入定與出定二者的功用低劣而且不同：入定時能徹見徹聞，出定後見聞便同於凡夫。有這樣的道理，所以才有「想心實語」。佛就不是如此，反過來對照前面所說即可明白。所以《淨名經》說：「（佛）常在三昧，悉見諸佛國。」又《無量義經》說：「永斷夢妄思想念」，因此佛沒有「想心實語」。

## 三、通則建議

1. **嚴守「說／想」的分際**：本段是妄語戒的境想判法，「謂言」＝說、「作…想」＝心想，兩者一混，犯不犯的理由就講不通。這是全篇最需要盯住的一點。
2. **形容詞節制**：感應、戲水、怪罪、純熟、殊勝、至高無上、深妙、絕…等，多屬譯者補入。疏記翻譯宜「寧質勿文」，解釋性內容放到註腳。
3. **術語統一並立表**：方便／加行／前行、正定／根本定／定體、上法／上人法、疑怪等，全篇宜一致。
4. **補三條關鍵註**：①空慧定與四空定的關係（無色定不應見聞色聲→比丘起疑的理由）；②上人法＝大妄語戒所稱之法；③伊羅婆尼象、難陀池。有這三註，整段的論證張力才出得來。
