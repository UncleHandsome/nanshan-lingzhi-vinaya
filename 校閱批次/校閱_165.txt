# 校閱材料　第165檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【165-0001】資持記/06c_中一上#44
【原文】言性善者，彼云：好行善道，不自放逸；謂性是善，不使從惡故。《善生》。五釋學義，摘在次科。二從心中。此就所治為名。身口五根，通須調伏；不唯在心，故云等也。三中，初示召體之名。如下，引論示體，初句舉名。此與從心語濫。以下，示體即約三性簡體，是善無作。問：此與上性善何異？
【譯文】論中所說的「性善」，該論解釋說：樂於奉行善道，使自己不致流於放逸自墮；這是指其本性原本向善，能約束自身不順從惡業的緣故。《優婆塞戒經》中將「學」的義理分為五種解釋，我們摘錄並列在下一科當中。第二「從心靈調伏的角度命名」，這是從所要對治滅除的對象來命名的。身、口以及五根，全部都需要予以調伏克制；防非止惡並非僅僅在於內心，所以用了「等」字來概括其餘身口各根。在第三點中，首先揭示用來稱呼戒體本質的名稱。接下「如下」引述論典來彰顯戒體的本質，第一句舉出名稱。這個名稱在文字上容易與前面「從心」的說法混淆不清。以下說明戒體是藉由三性（善、惡、無記）來簡擇判定其體性，它純粹屬於善的「無作戒體」。有人問：這個體性與上面所說的「性善」有什麼不同？

【165-0002】資持記/06c_中一上#45
【原文】答：準前論釋，望遮惡為言，故判屬功能也。四中。前引諸殺，而局善釋，於義未盡；是故鈔主以義繼之，故曰因明。名義兩通，故曰正義。初句示名不局；戒言性者，借訓顯義，勿滯《字書》。惡律儀，亦名惡戒；屠兒獵師旃陀羅輩，常行殺害，名受惡戒，持惡律儀。問：如何受耶？
【譯文】回答道：依據前面論典的解釋，它是著眼於「遮止阻絕惡法」的功能來發揮的，所以應當判定屬於外在功用的範疇。在第四點中，前面引述了諸多論著，大多局限在純善的範疇來解釋戒義，在義理上顯然尚未闡述周全；因此本鈔作者依照法理的推演繼續加以補充，所以稱為「因明其理」。戒這個字在名稱與義理上其實能貫通於善與惡兩方面，所以稱它為「正義」。第一句說明戒的名稱並不局限於善行；戒之所以被訓為「性」，是借用字訓來顯發義理，千萬不要死板地拘泥於一般《字書》的單一解釋。所謂「惡律儀」，也可以稱作「惡戒」；殺豬的屠夫、打獵的獵人、乃至以殺生殘害為業的旃陀羅之流，長年累月造作殺害生靈的惡業，這就叫做「受持惡戒、奉行惡律儀」。有人問：惡戒究竟是如何受得的？

【165-0003】資持記/06c_中一上#46
【原文】答：以殺為業，發意受行，即為受也；如《雜心》說，順惡易成，不假緣發；但望殺心，遍該生類，故名律儀；隨殺生命，即為持戒。不律儀者，非善故言不，類通故言律儀；即惡律儀，所出異耳。若此下，釋義，初二句通示。戒以性名，性通三性；且論善惡，互不相容，各得禁義。
【譯文】回答道：以殺生為職業，一旦動念發心立誓終身奉行這份殺業，在發心的當下就已經算作是受了惡戒；就如同《雜阿毘曇心論》所說，順從造惡本就極易成就，根本不需要假藉莊嚴的壇場因緣才能發起；只要那份殺心一旦確立，就已經普遍籠罩了一切有情生靈，所以也能稱作律儀；日後隨着殺害任何一條生命，就是在具體實踐持守他的惡戒。所謂「不律儀」，因為它絕非善法所以稱為「不」，因為它能普及類通各類生靈所以稱為「律儀」；這其實就是惡律儀的另一種翻譯稱呼，只是出自不同經論而已。接下「若此下」解釋法義，前兩句通體展示。戒既然是以性為名，性本來就貫通善、惡、無記三性；在此姑且只拿善與惡兩者來論對，善惡互不相容，但兩者各自都具備了約束的「禁制」意義。

【165-0004】資持記/06c_中一上#47
【原文】惡下，別釋，初明惡戒。通禁制止名律，造作有相名儀。若下，明善戒。令反解者，但應回倒善惡二字，改樂殺為慈護，即可見矣。五中。引律者，此說戒法中，釋戒序文。戒是因，木叉是果；今召戒為木叉，即是因從果也。解脫中，約近遠兩義釋之；近中，又二，初標。
【譯文】接下「惡下」分別深入解釋，首先說明惡戒的內涵。具有普遍禁制作為的規範稱為「律」，形諸於外在動作造作的形象稱為「儀」。接下「若下」說明善戒的內涵。若想讓人反向理解善戒，只要將上述文中的「善」與「惡」二字顛倒過來，把「樂於殺戮」改成「慈悲護生」，善戒的內涵自然就清晰可見了。在第五點中，引述廣律的內容，這是出自說戒法當中解釋戒序的文句。戒是修行的「因」，木叉解脫則是圓滿的「果」；如今直接稱呼戒為木叉，就是從果位的成就來稱呼因地的行持。在「解脫」的涵義中，是從「近處」與「遠處」這兩層深淺意義來解釋的；在近義當中又分為兩部分，首先標出綱領。

【165-0005】資持記/06c_中一上#48
【原文】言隨分者，顯非頓脫，即處處義也。謂下，釋。初二句，示境緣別也。次一句，明治行不頓也。下一句，示分果也。此望隨境起護，脫免過非，故云隨相。次遠義者。此以凡地所受，望後聖果，故云遠取；即前聖道本基義，故云因戒等。克，猶護也。聖總三乘，累該五住。故下，引證，亦律序偈；
【譯文】所謂「隨分」，是彰顯它並不是一蹴而就的頓時徹底解脫，這正是「處處、條條解脫」的涵義。接下「謂下」展開解釋。前兩句說明所面對的外境與因緣各有不同。下一句說明對治煩惱惡業的修行不可能一念頓消。最後一句說明所獲得的各個階段的局部解脫果分。這是著眼於行者隨順著境界生起防護之力，從而解脫免除了各個戒條的過失非行，所以稱為「隨相解脫」。其次所謂「遠處」的深義，是指以凡夫地所受持的戒律，最終期許求證日後的聖者極果，所以說是從遠程目標來著眼；這就是前面所闡述的「聖道根本基礎」的意義，所以說是「因戒而生定發慧」等等。「克」，猶如守護、保護的意思。「聖」總攬了三乘聖者，「累」涵括了見思二惑乃至五住煩惱。所以接下「故下」引證經文，這也是律序中的偈頌；

【165-0006】資持記/06c_中一上#49
【原文】彼云：眾經億百千，戒為第一最；欲求第一最，今世及後世，當持此禁戒，終身莫毀犯；餘二句如鈔。問：近遠兩釋，何以分之？答：此有多異：一近約止業，遠望除惑；二近是凡地，遠即聖道；三近是就因，遠即從果；四近是漸防，遠即頓破。即《戒疏》云：戒障有二：一者業非，二者煩惑；
【譯文】彼云：眾經億百千，戒為第一最；欲求第一最，今世及後世，當持此禁戒，終身莫毀犯；其餘二句就如同本鈔所引。有人問：這「近義」與「遠義」兩種解釋，究竟要如何進行分界判斷？回答道：這當中有許多本質上的差別：第一、近義偏重在止息身口惡業，遠義則期盼徹底滅除心靈深處的根本惑障；第二、近義適用於凡夫位階的防非止惡，遠義則是直通聖者階位的無漏解脫；第三、近義是立足於因地的實踐防護，遠義則是依循因果而成就極果；第四、近義是漸次防範惡業，遠義則是一朝斷盡惑障的頓然破除。這正如《戒疏》所說：戒障有二：一者業非，二者煩惑；

【165-0007】資持記/06c_中一上#50
【原文】戒淨障業，惑待智亡；望分所除，故云別脫。〔此明近義。〕後智除惑，乃稱究竟解脫。〔此證遠義。〕下文指後，即戒體中發戒數量門；彼明境量等，即別脫之義，可見。四具緣門，敘意中，初示受法。末代唯羯磨者，以五受中，善來、三語、八敬，唯局佛在；

【原文】幾種者，通論諸教，所說不定；約境，從制，就位〔五八十具〕，剋體〔作及無作〕，或對七支，或總三業，或分遮性，或據受隨；有斯多異，通而問之。答中，初約境示量。今下，舉要統收。今正明體，此二為要，故偏舉之。通收盡者，由此二戒懸防，總發體中含攝故。
【譯文】所謂「幾種」，若通論各派教法，所說並沒有定論：有依所緣境來分的，有順著制戒因緣分的，有就受戒位階（五戒、八戒、十戒、具足戒）來分的，有直接限定實體（作戒與無作戒）來分的；或對應身口七支，或總括身口意三業，或區分遮戒與性戒，或根據受體與隨行來分。正因為有如此多的歧異，所以通括起來發問。回答之中，起初是依照戒境來顯示其數量。從「今」字以下，是舉出綱要來總括統攝。如今正要顯明戒體，作與無作這二戒最為關鍵扼要，所以特別舉出它們。說能夠通統收攝無遺，是因為這二戒具有防非止惡的廣大功效，在受戒總發戒體之中就已全部含攝的緣故。

【165-0050】資持記/07a_中一下#4
【原文】此收法體，而言境者，欲明偏境之法，皆歸二戒故。第二科中。前但通立，次申所以。理趣既顯，引據復明；所立已定，即須顯示二種名義；故以解名，寄之於後。初科，問中。言不一者，欲顯相須，故約互廢以問。及以三者，《業疏》作何不三合；謂有作俱無作，二法同時；
【譯文】這裡本是在收攝法體，卻提及「境」，是為了說明即便周遍於一切境的法，最終全都要歸結到這二戒之中。在第二科裡，前面只是總體安立名稱，接下來申述這樣立名的緣由。理路旨趣既然已經顯露，引用的教證又已明朗；所安立的範疇既然底定，就必須顯發這兩種名相的深義；因此將解釋名義，寄託在後文之中。第一科的提問中，說「不一」，是為了彰顯二者互相依賴，所以假定偏廢其中一種來發問。至於問及「及以三者」，《業疏》中寫作「為何不三合」；這是指有「與作俱時而起的無作」，二法同時存在；

【165-0051】資持記/07a_中一下#5
【原文】直應更立一合，次前為三。初答為二，先明作須無作。作休不防者，以作短故；不可常作者，心或餘用故。次若單下，明無作須作。二下，結示。次答中。作無作別者，動靜異故；心非心別者，體相違故。《業疏》三句：一作是色心，無作非色心；二作者初緣，無作後業；三作是運動，無作非故。〔鈔無第二，餘二比對大同。
【譯文】理應順理成章再立一個合和的類別，接在前面兩者之後成為三種。最初回答分為兩部分，先說明作戒必須仰賴無作戒。作戒止息就不能再防非止惡，是因為作戒的作用短暫；不可能恆常保持作戒狀態，是因為心念有時會轉作其他用途。接著從「若單」以下，說明無作戒必須仰賴作戒而起。從「二」以下，予以總結開示。接著回答作與無作不能合為第三類：作戒與無作戒之所以不同，是因為運動與靜止的相貌相異；心法與非心法之所以不同，是因為二者體質互相違背。《業疏》提出了三句辨析：第一，作戒屬於色心，無作戒並非色心；第二，作戒是最初造作的因緣，無作戒是隨後相續的業力；第三，作戒具有動轉造作，無作戒則無造作。（鈔中略去了第二句，其餘兩句互相對照大體相同。）

【165-0052】資持記/07a_中一下#6
【原文】若下，釋疑。以不許立三，恐謂戒法唯局此二，故持釋之；顯上且據能防，故唯二也。引證中，《多論》，初二句，明從因感發。初下，明成就分齊。注中示名，初句會同，下句釋義。《業疏》云：此明業體，一發續現，不假緣辨；無由教示，方有成用；即體任運，能酬來世，故云無教；
【譯文】從「若」字以下，是釋除疑慮。因為不允許建立第三種戒，唯恐有人以為戒法僅僅侷限在這兩種，所以特地解釋；這是顯發上面暫且依憑「能防非止惡」的功能，所以只立兩種。在引用教證中，引用《薩婆多論》，前兩句說明戒體是從行者的心因而感應發起。從「初」字以下，說明戒體成就的限度與界分。註文之中指示名稱，第一句是會通名詞相同，下一句是解釋字義。《業疏》說：這是闡明業體一旦發起便相續顯現，不再假借外緣造作；不需要他人教導指點，當下就具備成就的功用；即是戒體任運自然，能夠酬引未來果報，所以稱為「無教」；

【165-0053】資持記/07a_中一下#7
【原文】今時經論，多云無作，義例同也。〔準此，注中他字，乃指業體，非屬人也。〕《俱舍》名無表，亦同此釋。二中，初示二戒。是下，明緣具因闕。下復指論，以顯經意。三中。彼明化教十不善道，然二色義同，故可為證。《業疏》作是十種法，則通善惡，頗應下喻。
【譯文】如今的經論之中，大多稱為「無作」，其法義與體例是相同的。（依照這個道理，註文中的「他」字，是指戒體本身任運，並非指他人。）《俱舍論》稱它為「無表」，也是相同的解釋。第二段引文中，先指示這兩種戒。從「是」字以下，說明作戒之緣雖具備、但受體之因卻闕漏的情況。後面又指出論義，以彰顯經文的旨趣。第三段引文中，那部經闡明的是化教中的十不善業道，然而其中作色與無作色這二種色法的義理相同，所以可以作為引證。《業疏》寫作「這是十種法」，那就通於善業與惡業，正好與底下的比喻相呼應。
