# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【527-0001】03_業疏/12b_卷三之一#4
【原文】問：《四分》律文但云三語，此文更列三歸者？答：以義約之，歸猶結也。作法既久，宗奉漸漓，如結成受。故《多論》云：「宿業力故，應三語得戒者，三語則止；三歸亦然，自然使爾。」牛呞比丘兄弟七萬比丘，盡以三語受戒。《四分》文中但云「歸依三寶隨佛出家」，本無歸結
【譯文】問：《四分律》文只說「三語」，此處為何又另外列出「三歸」？答：依義理來探討，歸就像是結白。這種作法行行既久之後，宗奉之心漸趨澆薄，便如同結句作法而成就受戒。所以《薩婆多論》說：「由於宿世業力的緣故，應當以三語得戒的人，說完三語即得戒；三歸也是如此，法爾自然使其如此。」牛呞比丘兄弟七萬比丘，全部都是以三語受戒。《四分律》文中只說「歸依佛、歸依法、歸依僧，隨佛出家」，本來沒有後續的結白之語。

【527-0002】03_業疏/12b_卷三之一#5
【原文】問答中。初示名義。作法久者，謂三語也。漓即是薄，故下引文證。《多論》宿業，謂往緣也；三歸亦然，亦宿業也。梵云憍梵波提，此翻牛呞，亦云牛跡，過去為牛，故口有牛呞，足有牛跡。呞，音詩，《說文》云「吐而噍也」。彼云兄弟七萬詣諸比丘所，諸比丘各盡以三語受戒。《四分》三語亦有加結，今云本無，未詳何意。有云：《四分》雖有結歸，而得戒在於三語，不同彼宗結歸方獲
【譯文】在問答之中。首先指示名相之義。「作法既久」，是指三語法。「漓」就是薄，所以下文引文為證。《薩婆多論》所說的「宿業」，是指過去世的宿緣；「三歸亦然」，也是宿業所致。梵語憍梵波提，此處翻譯為牛呞，也稱牛跡，因過去世曾轉生為牛，所以口有牛反芻咀嚼之相，足有牛蹄之跡。呞，音同「詩」，《說文解字》說：「反芻吐出而咀嚼。」該論說牛呞兄弟七萬人前往眾比丘處，眾比丘各自全都以三語為其授戒。《四分律》的三語法中其實也有加上結句，如今說本無結句，尚不清楚是何意趣。有人說：《四分律》中雖然也有結句歸依，但得戒在於說三語之時，不同於彼宗要到結句歸依時才獲取戒體。

【原文】了論》總示中。七種從師受，故云依他。獨覺與佛二種自然感發，則非依他。獨覺小乘境局大千，故猶有量；佛無量義如後自釋。究竟果滿，故稱波羅蜜
【譯文】在《律二十二明了論》總體提示中。七種受戒是從師長處領受，所以稱為「依他」。獨覺與佛陀這兩種是自然感發得戒，便不屬於依他。獨覺屬於小乘，心境局限於三千大千世界，所以仍屬「有量」；佛陀「無量」的涵義如後文自行解釋。修證究竟果位圓滿，所以稱為「波羅蜜」。

【527-0015】03_業疏/12b_卷三之一#18
【原文】一善來者，先白衣聖人，佛呼「善來比丘，修行清淨梵行，正說正法」，作是說已，髮落衣變，便得戒也。善比丘者，許其出家，許與大戒。來者，從白衣位來入出家位，從無戒位入具戒位。清淨梵行者，斷一切惡，修一切善也，《四分》云「快修梵行，盡苦源」即此是也。正說正法者，是梵行所依處也
【譯文】第一是善來受戒：原為在家的白衣聖人，佛呼喚道：「善來比丘，修行清淨梵行，如實宣說正法。」佛作此宣說後，其鬚髮自然脫落，俗服化為袈裟，便得戒了。「善比丘」，是准許他出家，准許授與他大戒。「來」，是指從白衣之位來到出家之位，從無戒之位進入具足戒之位。「清淨梵行」，是指斷除一切惡、修持一切善，《四分律》所說的「善巧修行梵行，窮盡苦之根源」即是此意。「正說正法」，則是梵行所依止的教法依處。

【527-0016】03_業疏/12b_卷三之一#19
【原文】僧善來中，初引論。「善」下，牒釋。斷惡是清淨，修善即梵行。引《四分》證，「快修梵行」證修善，「盡苦源」證斷惡。正說正法，言所說當依正教，行須憑教，故是所依
【譯文】在比丘善來一科中，首先引用論典。自「善」字以下，標舉原文逐詞解釋。斷惡即是清淨，修善即是梵行。引用《四分律》為證：「快修梵行」印證修善，「盡苦源」印證斷惡。所謂正說正法，是說所宣講的應當依循正教，修行必須依憑教法，所以是梵行的所依處。

【527-0017】03_業疏/12b_卷三之一#20
【原文】二三歸得戒者，善根稍薄，戒法難生，未說歸前，先誦佛語善來之法，後方說歸，竟感戒
【譯文】第二是三歸得戒：受戒者善根稍微淺薄，戒法難以直接生起，在宣說三歸依之前，先宣誦佛陀所說的善來之法，然後才宣說三歸依，說畢便感得戒體。

【527-0018】03_業疏/12b_卷三之一#21
【原文】三歸中。「稍」，少也。準此作法，先唱善來，後說三歸，獨異諸部
【譯文】在三歸一科中。「稍」即是微少。依循此論的作法，先宣唱善來，後宣說三歸，唯獨此處與其餘諸部不同。

【527-0019】03_業疏/12b_卷三之一#22
【原文】三略羯磨者，善根又薄，須立和上，先問遮法，後方和乞，與今不異，四人秉白，即發具戒
【譯文】第三是略羯磨受戒：受戒者善根又更澆薄，必須延請和尚，先詢問有無遮難之事，然後大家和合乞戒，這與現今並無不同，由四位僧人主持單白羯磨，隨即發起具足戒體。

【527-0020】03_業疏/12b_卷三之一#23

【譯文】在第四廣羯磨中。作法必須依白四羯磨，僧眾人數必須具足十人。

【527-0023】03_業疏/12b_卷三之一#26
【原文】尼中三受，無歸及略，是聖人者佛喚善來，非聖人者三歸、單白所不感也。言遣使者是愛道，言廣羯磨今二十眾也
【譯文】比丘尼中的三種受戒，沒有三歸以及略羯磨，若是聖人則佛陀召喚善來而度化，若非聖人，三歸與單白作法都無法感得戒體。所說的「遣使受」是指大愛道（遣使度法授尼），所說的「廣羯磨」即是如今二部僧共二十眾的受戒。

【527-0024】03_業疏/12b_卷三之一#27

【譯文】尼眾之中沒有三歸以及略羯磨。善來與廣羯磨法，這兩種與僧眾相通；遣使這一種，則唯獨局限於尼眾。

【527-0025】03_業疏/12b_卷三之一#28
【原文】此七種戒，悉依他得。言圓德者，即戒體也，所受徧周法界，無境不備，隨行奉修，德充一切，故稱圓德

【527-0026】03_業疏/12b_卷三之一#29
【原文】通釋中。初釋依他。「言」下，釋圓德。「即戒體」一句是總示也。「所受」等釋上圓義，「隨行」等釋上德義，故下一句通結
【譯文】在通論解釋之中。首先解釋「依他」。「言」字以下，解釋「圓德」。「即戒體」一句是總括提示。「所受」等句解釋上面的「圓」字之義，「隨行」等句解釋上面的「德」字之義，所以最後一句作總括結尾。

【527-0027】03_業疏/12b_卷三之一#30

【譯文】所謂獨覺有量、佛陀無量：在三大阿僧祇劫中廣泛修持萬行，於最後一生中自然具備菩薩戒，全都是自性任運而得的。在證得苦法忍之時，獲得出家具足戒；在盡智與無生智生起之時，一切佛法同一時刻圓滿無餘，這三種功德廣大而沒有邊際限量。
