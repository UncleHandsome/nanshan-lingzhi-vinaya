# 校閱材料　第1410檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1410-0001】04_比丘尼鈔/02a_卷上之下#11
【原文】問何故律中喚和尚等為阿姨答佛在世時大愛道尼是佛姨母諸尼因是得戒遂學佛語皆喚阿姨尼阿摩等善見云尼女也摩者母也義準重尼故稱之然阿非梵語漢地所稱女通大小母者耆年如世人喚其阿母義亦相類僧祇云和尚尼欲授人具戒應先求比丘尼不得臨時選眾若不可者當求半許若過半許而作法義云若和尚犯重羯磨師知不成受戒以所牒非比丘尼用十師互相知亦不成受了了知非則不應羯磨下至知有四人清淨者得成僧用故伽論云邊地五人持律者授若十人處五人受戒得比丘得可訶罪受戒人不知和尚是賊住依彼出家受具足得戒否答得戒僧犯吉羅此律大僧和尚十夏尼和尚十二夏大僧和尚開九夏而得小罪二種闍棃大僧五夏已上尼六夏已上方得成授餘師隨夏大小竝得五百問事云比丘五臘不滿度弟子知非而度犯提弟子不知是非得戒問緒方僧尼情識闇鈍不間戒律貪求徒弟白讀羯磨為人受戒得成已否答不成反結無知不學之罪故此律遣上座誦羯磨或報云誦或云先誦後忘遂稽留受戒事故須要誦方得五分諸比丘不誦羯磨不得受具戒義云末法時訛多有斯謬故引文證願依時誦。
【譯文】問：為什麼律中稱呼和尚等人為阿姨？答：佛陀在世時，大愛道比丘尼是佛陀的姨母，諸位比丘尼因她而得戒，於是學習佛陀的稱呼，都稱呼阿姨、尼阿摩等。《善見律》說：「尼」是女的意思，「摩」是母的意思，按義理是為了尊重比丘尼而如此稱呼。然而「阿」不是梵語，是漢地的稱謂，女子通稱長幼，稱「母」的是年長者，就像世人稱呼自己的母親為阿母，意思也是相類的。《僧祇律》說：和尚尼若想為人授具足戒，應當預先尋訪比丘尼，不得臨時在眾中挑選；若無法湊足全數，應當尋求半數左右的比丘尼（五人左右）；如果超過半數，便可如法作法傳戒。義理上說：如果和尚尼犯了重罪，羯磨師明知卻仍為其作法，受戒不成，因為所列舉名位者並非清淨比丘尼。若是十師互相包庇隱匿已知罪行，受戒也不成；如果明知是非，就不該進行羯磨。只要下至知道有四位清淨僧，便能成就僧事之用。所以《摩得勒伽論》說：在邊遠地區，由五位持律者傳授即可；若在應有十人的處所，只有五人為其受戒，雖然能得比丘戒，但傳戒之僧犯下可訶責之罪。受戒的人如果不知道和尚是賊住身分，依止他出家受具足戒，到底得戒否？答：得戒，但與會之僧犯突吉羅罪。在本律中，比丘和尚須滿十臘，比丘尼和尚須滿十二臘；比丘和尚若開緣九臘雖得授戒，但犯輕罪。二種阿闍梨，比丘須五臘以上，比丘尼須六臘以上，才能成就傳授資格；其餘尊證師則隨戒臘大小皆可擔任。《五百問事》說：比丘不滿五臘而度弟子，明知不合法度而度的，犯波逸提罪；弟子若不知是非，仍然得戒。問：遠方偏僻處的僧尼心智昏昧，不懂戒律，貪求徒弟，只是依文白讀羯磨為人受戒，到底算不算成就？答：不成受戒，反而結下無知不學的罪過。所以本律派遣上座背誦羯磨文，有時回報能誦，有時說原本會誦後來遺忘，因而耽擱受戒之事；所以必須熟練背誦方得成就。《五分律》說：諸比丘若不能背誦羯磨，不得為人受具足戒。義理上說：末法時代混亂，多有這種謬誤，因此引用律文為證，希望大家平時依教諷誦。

【1410-0002】04_比丘尼鈔/02a_卷上之下#12
【原文】第二發戒緣者義云所發之戒乃有無量隨境總論要而言之不過情與非情依正兩報有無二諦滅理涅槃佛說聖教文字經卷形像塔廟地水火風虗空識等六塵萬境法界等緣不可具陳何以故由不受故則於一一眾生莫問凡聖起塵沙等惡今翻為善則成塵沙等戒故善生經云眾生無邊戒亦無邊婆論云於非眾生上亦得無量戒善功德如十方世界所有大地下至水際空界已來若傷如微塵竝得其罪由受戒故成善且如壞一艸葉始從萌芽一一華葉得爾罪今翻爾罪得若干戒故善生經云大地無量戒亦無量乃至虗空有盜損之義故善生經虗空無邊戒亦無邊婆論云新受戒人與佛齊功以此推之出家之士真是善法功德之聚位尊人天良由於此不論持者假令毀戒亦得無邊戒利何以知之故十輪云破戒比丘雖是死人是戒餘力能大利益人天道俗猶如牛黃麝香等佛即說偈云薝蔔華雖萎勝於一切華破戒諸比丘猶勝諸外道是故行者受戒毀禁尚得功德況當清淨於法奉持則難思議汝當緣念如上諸境知所緣境已次為廣開心懷令彼受者增益道志應語云族姓女諦聽當發上品心得上品戒若發中下心得中下戒假令道成四果是戒猶是中下何名上品若言為正向泥洹故為趣三解脫門故為成三聚戒故為令法久住故為救眾生諸苦惱故為求佛道度眾生故如是如是真佛弟子得佛淨戒必須知者於受戒前一一提授使心心相續了法明淨方得為受。
【譯文】第二種「明發戒之緣」，義理上說：所生起的戒法無量無邊，隨所對應的境界總體來說，簡要而言不過是有情與非情、依報與正報、有諦與無諦（真俗二諦）、寂滅真理與涅槃境地。佛陀所說的聖教、文字經卷、形像塔廟，以及地、水、火、風、虛空、識等六塵萬境，乃至盡法界一切緣起，無法一一說盡。為什麼呢？因為在未受戒之前，對於每一個眾生，無論凡夫或聖人，都在其境界上生起如塵沙般的惡念；如今將惡翻轉為善，便成就了如塵沙般的戒法。所以《優婆塞戒經》說：眾生無邊，戒也無邊。《薩婆多論》說：在非眾生境界上，也能獲得無量的戒善功德。例如十方世界所有的土地，下至水際、空界以來，若是損壞如微塵許，都會獲得損害之罪；如今由於受戒而成就善心，且如毀壞一片草葉，從萌芽開始，每一花一葉都能結下罪報，如今翻轉那些罪業，就得到無量的戒體。所以《優婆塞戒經》說：大地無量，戒也無量。乃至對於虛空，也有可能產生盜損侵占的意念，因此《優婆塞戒經》說：虛空無邊，戒也無邊。《薩婆多論》說：新受戒的人，在戒善發起的一念與佛相等。以此推論，出家之士真正是善法功德的聚寶盆，地位尊榮超拔於人天之上，全是因為這個緣故。暫且不論持戒者，哪怕是犯戒毀禁之人，也能得到無邊的戒法利益。憑什麼知道這一點呢？《地藏十輪經》說：破戒比丘雖然如同死人，但依賴這戒法的殘餘力量，仍能極大饒益人天道俗，就像牛黃與麝香一般，即便牛死香在。佛陀隨即說偈言：瞻蔔花雖然萎縮凋謝，依然勝過所有雜花；破戒的諸多比丘，依舊勝過所有的外道。因此修行者受戒後即便毀壞禁戒，尚且能得功德，更何況能夠清淨無瑕地奉持戒法，那功德真是難以思議！你應當依循上述種種境界作深切念想；知道所緣的境地之後，接著應為其廣大開啟心懷，使受戒者增長向道之志。應當告訴她說：善女人仔細聽好，你應當發起上品的心，才能得到上品的戒體；若發中品或下品心，就只能得到中品或下品的戒體。即便將來修行證得四果阿羅漢，這戒體依然只是中下品。什麼叫做上品心？如果說：我是為了趣向大般涅槃，為了證入空、無相、無願三解脫門，為了圓滿攝律儀、攝善法、饒益有情三聚淨戒，為了令正法長久住世，為了救拔眾生的種種苦惱，為了求成無上佛道以度化眾生，如果發這樣的心，才是真正的佛弟子，才能得到佛陀清淨的戒體。這是一定要明白的，在受戒之前，應當一一提攜傳授，使受戒者的心念相續不絕，明了戒法清淨不染，然後才可以為其授戒。

【1410-0003】04_比丘尼鈔/02a_卷上之下#13
【原文】第三安置者此律云當安欲受戒人置眼見耳不聞處立若安見聞俱離處及界外者不名受戒故五分云以起過聽安戒場外眼見處。
【譯文】第三種「安置處所」，本律說：應當把想要受戒的人，安置在眼睛看得見、耳朵聽不見的地方站立。如果安置在眼不見、耳不聞的遠處，或者是界外，就不能稱作如法受戒。所以《五分律》說：因為生起過失的緣故，佛陀聽許安置在戒場外面眼睛看得見之處。
