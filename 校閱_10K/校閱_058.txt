# 校閱材料　第058檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【058-0001】01_行事鈔/04a_卷上之四#21
【原文】九明問答法。彼當準上誦之，至未受具戒者出，諸沙彌等隨次而出，儀式如〈別法〉中。不來者說欲，如前〈欲法〉；若無者，維那互跪答云：「無說欲者。」又云：「誰遣比丘尼來請教誡？」彼受尼囑者起，至僧中禮已，互跪合掌言，如《五分》法云：「大德僧聽！某寺尼眾和合，僧差比丘尼某甲，半月半月頂禮大德僧足，求請教誡尼人。」三說已。至上座前，長跪曲身合掌云：「大德慈悲！能教授比丘尼不？」答云：「年老無德。」乃至二十夏來，並須委問；不過下座，以無別德可明。若無者，還至上座前云：「遍問年德，並辭不堪。」上座云：「諸大德等，何啻堪任持，由惜自業故辭請耳！」若明日尼來請可不，當依《五分》云：「此無教誡尼人，又無善說法者。雖然，上座有教勅尼眾：『當勤精進，如法修道，謹慎莫放逸！』」彼受囑者復本座。尼明日來，依命傳告。若廣說法，時希故略。說戒者云：「僧今和合，何所作為？」維那互跪答云：「說戒羯磨！」維那復本座已，然後羯磨作白。不得未至座所便作，以坐立不同，即是別眾。此事往往有之；上座不教，致令僧眾，俱同非法。然處眾首，是非須知；不得低頭合眼，不知法網；示一律儀，永成常準。故《僧祇》中，說戒說法，並有上座法。
【譯文】第九、說明問答之法。那說戒者應當準照上述程序讀誦，誦到「未受具足戒者出堂」之處，眾沙彌等便依照順序出堂，儀式如〈別法篇〉中所載。未能前來者應當「說欲」（轉達布薩之願），如前面〈欲法篇〉所述；如果沒有，維那互跪回答說：「沒有說欲者。」又問：「誰受比丘尼差遣前來請求教誡？」那位接受比丘尼委託的比丘起立，走到僧眾中央頂禮後，互跪合掌，依照《五分律》之法說：「大德僧聽！某寺比丘尼眾和合，僧團差派比丘尼某甲，每半個月頂禮大德僧足，求請教誡比丘尼之人。」如此說三遍後。走到上座面前，長跪躬身合掌說：「大德慈悲！能否教授教誡比丘尼？」上座回答說：「年老無德。」乃至戒臘二十夏以來的資深長老，都必須詳加詢問；但不過問下座比丘，因為下座比丘尚無殊勝德望可表。如果都沒有人能勝任，便回到上座面前稟告說：「普遍詢問有年歲德行者，全都推辭說不堪勝任。」上座便說：「各位大德，何止能夠勝任任持，只是由於顧惜自修道業才推辭相請罷了！」如果問及明日比丘尼前來請求准可與否，應當依照《五分律》說：「此處沒有能教誡比丘尼之人，也沒有善於說法之人。雖然如此，上座有教勅尼眾的話：『應當勤勉精進，如法修道，謹慎切莫放逸！』」那位受委託者回到自己的座位。比丘尼明日來時，便依照此敕命傳達告知。至於廣為說法之事，因當前時代罕能行之，故略而不述。說戒者問：「僧眾現今和合，所作何事？」維那互跪回答說：「說戒羯磨！」維那回到自己座位之後，說戒者然後羯磨宣白。不得在維那尚未回到座位時便作白，因為一人坐著、一人站立不同，就成了「別眾」（破壞了和合僧相）。這種弊端往往時常發生；上座不加教導，致使僧眾全都流於非法。然而身處僧團首座，是非必須通曉；不得低頭閉眼、盲無所知於律法綱維；應當示現明確的律儀，使之永遠成為常行標準。因此在《摩訶僧祇律》中，說戒與說法，都有明確的上座職責之法。

【058-0002】01_行事鈔/04a_卷上之四#22
【原文】十明說戒竟法。若至略教已，當更鳴鐘，令沙彌集，然後誦「明人能護戒」等。若總說已，作「神仙五通人」偈梵。後作處世界唄。為令說者從容具儀，辭遜之暇。其說序前唄，亦誦律序，以為唄辭。說者辭云：「小比丘某甲，致敬眾僧足下，敬謝眾僧。僧差誦律，三業不勤，多有忘失；願僧慈悲，施以歡喜。」眾僧各各說自慶偈云：「諸佛出世第一快，聞法奉行安隱快，大眾和合寂滅快，眾生離苦安樂快。」
【譯文】第十、說明說戒完畢之法。如果誦到略教誡（後序結偈）處，應當再次鳴鐘，令沙彌集合，然後讀誦「明人能護戒」等偈頌。如果全部說戒完畢，便領唱「神仙五通人」偈之梵音。隨後唱「處世界」唄。這是為了讓說戒者能夠從容完備威儀、退避謙遜的空隙餘暇。在說戒序之前的讚唄，也是讀誦律序的文句，作為讚唄的歌詞。說戒者致謝謙辭說：「下座比丘某甲，致敬於眾僧足下，敬謝大眾僧。僧團差派我誦律，無奈身口意三業未能勤勉，多有遺忘差失；懇願大眾僧慈悲，賜予歡喜包容。」眾僧各自宣說自慶偈說：「諸佛出世第一快，聞法奉行安隱快，大眾和合寂滅快，眾生離苦安樂快。」
