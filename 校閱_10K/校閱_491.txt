# 校閱材料　第491檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【491-0001】02_戒疏/07a_卷二上之三#84
【原文】【記】五中。《律》文先列蛇、魚，續云「及餘無足眾生」，故云「為初」。《僧祇》。初明盜取。彼云「無足者，所謂蛇蟒」，或蛇師比丘盜取蛇或筐，滿五皆重。今云「龍」者，疑是文誤。「若」下，次明解放。下引律論，壞具皆輕，以非盜故。
【譯文】【記文】第五項中。《律》文中首先列出蛇與魚，接著說「以及其他沒有腳的眾生」，所以說「作為開端」。《僧祇律》首先說明盜取的罪相。彼處說「無足的，就是指蛇與大蟒」，曾為弄蛇師的比丘盜取蛇或竹筐，價值滿五錢都結重罪。這裡寫作「龍」，懷疑是文字傳抄有誤。從「若」字以下，接著說明放生的情形。下面引用律論，指出破壞捕獸工具都判輕罪，因為這不是出於偷盜之心。

【491-0002】02_戒疏/07a_卷二上之三#85
【原文】【疏】六、「二足」者，盜人為初。
【譯文】【疏文】第六、「二足動物」，以偷盜人類為首要對象。

【491-0003】02_戒疏/07a_卷二上之三#86
【原文】【記】六中。「人為初」者，《律》云：「人、非人、鳥，乃餘二足眾生，有主者重。」
【譯文】【記文】第六項中。「以人為首」的意思，《律》中說：「人類、非人、鳥類，乃至其餘兩隻腳的眾生，只要是有主人的，盜取都結重罪。」

【491-0004】02_戒疏/07a_卷二上之三#87
【原文】【疏】約《律》，盜人令出家去，如上可知。既非僕隷，則非別屬，雖違王教，如上《多論》。
【譯文】【疏文】依照《四分律》，私自帶走他人使得出家去，如同上面所述是可知罪相的。這被帶走的人既然不是奴僕奴隸，就不屬於別人的財產，雖然這違背了國王的法令，但就如上述《薩婆多論》所判。

【491-0005】02_戒疏/07a_卷二上之三#88
【原文】【記】盜出家中。初明成重。「如上」，即約有主結也。「既」下，揀輕。謂「僕隷」等，損主故重，餘無所損，止可結吉，故指「如《論》」，即上「度關」等。《善見》亦云「盜人無罪者，謂主人兒落度，父母所遣等，將去無罪」是也。
【譯文】【記文】在私帶他人出家的段落中。首先說明何時構成重罪。「如上」，就是指針對有主人的奴僕結重罪。從「既」字以下，揀別出屬於輕罪的情形。是說如果是「僕隸」之類，帶走會讓主人受損所以判重罪；若不是僕隸，對他人無實質資產損害，就只能結吉羅罪，所以指出「如同論中所說」，就是指前面「度關」的條文。《善見論》也說「盜人無罪的情況，是指主人家的兒子放蕩破落，被父母驅逐遣走等情況，比丘將他帶去出家是沒有盜罪的」，就是這個道理。

【491-0006】02_戒疏/07a_卷二上之三#89
【原文】【疏】義言：「若他兒子賊奪去將，便損父母依報力用，屬賊是強。不得教走，若自走來，則不負賊。」故《十誦》中：「賊捉弟子將去，師還奪取，犯重。賊未決想，無犯。弟子自偷身來者，不犯。」如昔解云：「師不得奪，身自得走者：父母感子力強，賊奪得重，已屬賊是強，師弱奪賊，故重；兒報正體是強，賊得力用則弱，走是強報相逐，弱用隨來，不犯。」
【譯文】【疏文】法理上說：「如果別人的兒子被盜賊搶走擄去，這就損害了父母賴以生活的勞動力，此時兒子歸屬於盜賊的權力之下是強勢的。比丘不得教唆他逃跑，如果他自己逃跑回來，就不算辜負盜賊。」所以《十誦律》中說：「盜賊抓了弟子帶走，師父跑去奪取回來，犯重罪。若是盜賊心中還沒有徹底佔有的念頭，奪回就不犯戒。若是弟子自己偷跑脫身回來，就不犯戒。」如同過去的解釋說：「師父不得強奪、弟子卻可以自己逃跑的原因在於：父母感得兒子的勞力回報強烈，盜賊奪得即結重罪，但此時人身已落入盜賊掌控而成為強勢，師父權力薄弱卻向強勢的盜賊強奪，所以犯重罪；兒子自體的身報才是本體最強的，盜賊所得的只是支配勞力，相對而言是弱勢，兒子逃跑是依憑自己強大的身報自主離去，賊方微弱的勞役支配權也只是隨同其身體而歸來，所以不犯戒。」

【491-0007】02_戒疏/07a_卷二上之三#90
【原文】【記】奪賊中三。初以義判，前明賊奪成重。子是父母所依，假其力用，所損處重，故「屬賊強」。「不」下，教比丘護盜。教走成重，以損賊故；自來無過，以非意故。「故」下，引證，可見。「如」下，引昔解。初牒前兩判。「父」下，釋出所以。初明師犯重意。「兒」下，次明自來無犯。「兒報強」者，自所有身，非他屬故。「賊得弱」者，非所生親，復非雇主故。「強報相逐」者，身隨己意故。「弱用隨來」者，賊無分故。
【譯文】【記文】在從盜賊手中奪回的論述中分為三層。首先依法理判定，前半段說明盜賊奪取（弟子）即構成重罪。兒子是父母的生活依靠，仰賴其勞動付出，被搶走所造成的損害極重，故「屬賊強」。從「不」字以下，教導比丘如何防範偷盜罪。教唆其逃跑構成重罪，因為損害了盜賊既得的利益；若是自己逃回就沒有罪過，因為不是被比丘教唆指使的。從「故」字以下，引用文獻為證，顯而易見。從「如」字以下，引用古德的解釋。首先重提上述兩項判定。從「父」字以下，解釋其中的根本原因。首先說明師父搶奪犯重罪的原因。從「兒」字以下，接著說明自己逃回不犯戒的道理。「兒子的身報強」，是因為自己的身體屬於自己，並非天生屬於他人。「盜賊所得弱」，是因為盜賊並非生身父母，又不是出資雇主。「強報相逐」，是身體聽從自己的意志行動。「弱用隨來」，是因為盜賊對他的支配權本就薄弱，自然隨著人走而消失。

【491-0008】02_戒疏/07a_卷二上之三#91
【原文】【疏】《十誦》云：「見他奴婢，語言：『辛苦！何不走去？』如語吉羅，舉一足蘭，舉二足重。若奴已叛，催令駛去，隨語得重。或言此儉彼豐，奴即叛去，不教故不犯。或問豐樂，逐比丘去，即驅使者，逢難喚走，皆不犯。」
【譯文】【疏文】《十誦律》說：「看見別人的奴婢，對他們說：『太辛苦了！何不逃跑呢？』話剛一說出口，比丘即犯吉羅罪，奴婢邁開一隻腳時比丘犯偷蘭遮，邁開兩隻腳跑離時比丘犯重罪。如果奴婢本來就已經叛逃，比丘催促使他快跑，隨著其催促言語也得重罪。或者比丘只是隨口說這地方歉收而某地豐收，奴婢聽了就叛逃離去，因為比丘沒有教唆逃跑的意圖所以不犯戒。或者奴婢詢問哪裡豐衣足食，隨後跟著比丘走，比丘便予以驅使差遣，路上遇到危難時叫奴婢快跑，這些都不犯戒。」

【491-0009】02_戒疏/07a_卷二上之三#92
【原文】【記】三中，四段。前二教走成重，後二不教無犯。初明誘引。「若」下，次明催去。「駛」，疾也。「或言」下，三、約比丘語彼。「或問」下，四、據彼問比丘。
【譯文】【記文】在第三項中，分為四個段落。前兩個段落說明教唆逃跑構成重罪，後兩個段落說明未蓄意教唆則不犯戒。首先說明言語誘惑引導。從「若」字以下，接著說明催促快跑。「駛」就是快速的意思。從「或言」以下，第三、是關於比丘隨口談論地方情況。從「或問」以下，第四、是依據對方主動詢問比丘的情況。

【491-0010】02_戒疏/07a_卷二上之三#93
【原文】【疏】七、「四足、多足」，《律》約畜論，亦可準上。
【譯文】【疏文】第七、「四足與多足動物」，《律》是就畜生來論述，也可以準照上述原則來處理。

【491-0011】02_戒疏/07a_卷二上之三#94
【原文】【記】七中。《律》云「象、馬、牛、駱駝、驢、鹿、羊及餘四足」等。「多足」者，《律》云「若蜂，若百足，及餘多足」等。並約有主成重，故令「準上」。
【譯文】【記文】第七項中。《律》中說「大象、馬、牛、駱駝、驢子、鹿、羊以及其他四隻腳的動物」等等。「多足動物」，《律》中說「若是蜜蜂、百足蟲，以及其他許多隻腳的生物」等等。都是就有人飼養佔有時，盜取滿額構成重罪，所以說「準照上述辦理」。

【491-0012】02_戒疏/07a_卷二上之三#95
【原文】【疏】「同財業」者，謂違契要，故此引也。據此同財，其相多種。或資生同，如今師資同活等。取五即犯，不假半分，以彼同財，全欺負故。或同活生，共營財業。若生心盜，則須計分，滿十方重，五是我分，五欺彼故。
【譯文】【疏文】說到「合夥財產的行業」，是指違背了當初的契約約定，所以在這處提出來。照這樣看來合夥財產，其行相有許多種。或者像是生活資財共有，如同現在師父與弟子共同生活一樣。這種情況只要私自偷取滿五錢就犯重罪，不必先扣除自己的一半份額，因為對於這種共有財產，私取是完全欺瞞辜負了對方。或者像是共同營生，合夥經營財富產業。如果生起盜心私取，就必須計算所盜的份額，私取滿十錢時才構成重罪，因為其中五錢本就是我應得的份額，另外五錢才是欺瞞了合夥人的份額。
