# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【542-0001】03_業疏/14a_卷三之三#27
【原文】答：據十三難，業寬、報中、煩惱最狹，如上所引。若泛論之，三障該通五道：報則是寬，煩惱是中，業即狹也。故論云：地獄具五業，北洲有四，餘則說十。又以八難配障：前七是報，世辨煩惱，無業障也
【譯文】答：依十三難來說，業障最寬、報障居中、煩惱障最為狹隘，如同上文所引。如果泛泛而論，三障普遍通於五道：報障則最寬，煩惱障居中，業障則最為狹隘。所以論典中說：地獄具足五種不善業，北俱盧洲有四種，其餘趣道則說具有十種。又如果以八難來配對三障：前七難屬於報障，世智辯聰屬於煩惱障，其中沒有業障。

【542-0002】03_業疏/14a_卷三之三#28
【原文】問答中初答，初、據前以示業九、報三、煩惱但一，寬狹可見。「若」下，次、約義泛論。煩惱及業，竝依於報，故報最寬；煩惱雖徧，隱而時發，故為中；造業不具，故最狹也。引論證業，即《雜心》文，彼云：地獄眾生有五不善業：惡口、綺語、貪、恚、邪見，無殺、盜、邪婬、妄語、兩舌；鬱單曰有後四不善業：綺語、貪、恚、邪見，無殺、盜等六故；餘三洲人、畜生、餓鬼及欲界天，竝具十業，故云餘說十也；有色、無色，無有不善業道。「又」下，因收八難，前七約報可解，世辯是分別見，故屬煩惱
【譯文】在問答的第一個回答中，首先依據前文指出業障有九種、報障有三種、煩惱障僅有一種，寬窄顯而易見。自「若」字以下，其次依義理泛泛而論。煩惱與業，都依附於果報之身，所以報障最為寬廣；煩惱雖然普遍存在，卻隱伏而時常發作，所以居中；造作惡業並不人人具足，所以最為狹隘。引證論典以證明業障狹隘，即是《雜阿毗曇心論》的經文，該論說：地獄眾生具有五種不善業：惡口、綺語、貪、恚、邪見，沒有殺生、偷盜、邪淫、妄語、兩舌；鬱單越（北俱盧洲）具有後四種不善業：綺語、貪、恚、邪見，因為沒有殺、盜等前六種的緣故；其餘三洲的人、畜生、餓鬼以及欲界天，都具足十種惡業，所以說其餘說十種；色界、無色界則沒有不善業道。自「又」字以下，順帶收攝八難，前七難就報障而言容易理解，世智辯聰屬於妄自分別的邪見，所以歸屬於煩惱障。

【542-0003】03_業疏/14a_卷三之三#29
【原文】言輕重者，煩惱為諸障本，故云「若無我者，諸業不集」也；業障為中；報是頑癡，故為輕也。言可轉者，報障難轉故重，餘可轉故為輕，如懺法中廣顯其相也
【譯文】談到輕重時，煩惱是一切障礙的根本，所以經論說「若是沒有我執，諸業就不會聚集」；業障居中；報障只是頑鈍愚癡，所以為輕。若就可否轉變來說，報障難以轉變所以為重，其餘煩惱與業可以轉變所以為輕，如同懺悔法中詳細顯明其相狀那樣。

【542-0004】03_業疏/14a_卷三之三#30
【原文】次答中，初、約本末釋。煩惱生業、報，故云「諸障本」。引文證者，即《成實》文。我即煩惱，業能招報，迭論可知。「言」下，次、約轉變釋。報果已定，故難轉。餘可轉者，業有二別：不定可除，定業可轉；煩惱心昏，反照即轉。小乘見思，一斷永盡；大教無明，體即覺性。在迷望悟，則迷悟分殊；以悟望迷，則迷悟叵得。無明常照，虗妄常真，不待剎那，轉凡為聖，所謂「百年闇室，一燈能破」。準知業次前輕，煩惱最輕也。指下懺法，尋以對之
【譯文】在第二個回答中，首先依根本與枝末來解釋。煩惱生起業障與報障，所以說是「諸障的根本」。引證文句者，即是《成實論》的文句。「我」就是煩惱，業力能招感果報，遞相推論便可明了。自「言」字以下，其次依能否轉變來解釋。果報已經判定，所以難以轉變。其餘可以轉變的情況中，業障有兩種差別：不定業可以消除，定業可以轉變；煩惱雖使心昏昧，只要反觀內照就能轉變。小乘的見惑與思惑，一經斷除便永遠斷盡；大教中的無明，其自體即是覺性。在迷惑處觀照覺悟，則迷與悟有顯著差別；以覺悟處觀照迷惑，則迷與悟了不可得。無明本自常照，虛妄體性常真，無須歷經一剎那，便能轉凡成聖，正所謂「百年的暗室，一盞明燈就能破除」。由此推知，業障比報障輕，煩惱障則是其中最輕的。此處指引下文的懺法，可以查尋對照。

【542-0006】03_業疏/14a_卷三之三#32
【原文】初中，非、畜局一難，人中具十一。以造業具故，說業有九；非、畜無惡戒，故不說業障，非無造別業，如《成實》說。又人中有受道故，說黃、形兩障；非、畜乃兼，體非道器，雖有不說難
【譯文】在第一項中，非人與畜生各自局限於一種難，人道之中則具足十一難。因為人道造作惡業齊全的緣故，所以說業障有九種；非人與畜生沒有受持惡戒，所以不說有業障，但並非不能造作個別業，如同《成實論》所說。又因為人道中能接受聖道的緣故，所以說明黃門、二形這兩種障礙；非人與畜生雖然也兼具這兩種情形，但其自體根本不是載道的法器，即使有也不另外說為障難。

【542-0007】03_業疏/14a_卷三之三#33
【原文】第五、三趣中初科，初、明非、畜不通餘難，故各局一。「人」下，次、明人趣。初、總示。「以」下，別簡。初、簡邊、逆等九。非、畜無惡戒者，《雜心》云「鬼、畜、欲天有十業，離不律儀」是也。然但不能造總，不妨造別。總謂牽生業，別即莊嚴業，無記感報，文見《成論》，如《鈔》所引。「又」下，次、明黃、形。非、畜兼者，律明三趣並有黃、形
【譯文】在第五大門三趣的第一科中，首先說明非人、畜生不通於其餘諸難，所以各自局限於一種。自「人」字以下，其次說明人趣。首先總相標示。自「以」字以下，分別甄別。首先甄別邊罪、五逆等九種。所謂非人、畜生沒有惡戒，《雜阿毗曇心論》說「鬼、畜、欲天具有十種業，但遠離不律儀」即是此意。然而牠們只是不能造作總業，並不妨礙造作個別業。「總業」是指牽引受生的業力，「個別業」即是莊嚴修飾的業力，屬於無記心所感召的果報，文句見於《成實論》，如同《行事鈔》所引。自「又」字以下，其次說明黃門與二形。所謂非人、畜生兼具，是因為律藏明確記載三趣之中皆有黃門與二形。
