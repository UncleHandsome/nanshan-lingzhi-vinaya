# 否決抽驗規則（分層＋序貫）

2026-11-13

## 目的
用最小成本判斷某卷的「否決」是否可信。

## 分層
| 否決數 | 抽樣 | 說明 |
|--:|:--|:--|
| ≤ 40 | **全部查** | 量少，直接做完 |
| 41–120 | **25 條** | 比例 20–60% |
| > 120 | **30 條** | 達 10% 精度（rule of three） |

## 序貫（超過門檻時）
```
第 1 批 10 條
├ 0 錯 → 續抽第 2 批 10 條
│    ├ 0 錯 → 續抽第 3 批 10 條
│    │    ├ 0 錯 → 通過（錯誤率上限 10%）
│    │    └ ≥1 錯 → 擴大至全卷複審
│    └ ≥1 錯 → 擴大至全卷複審
└ ≥2 錯 → 直接全卷複審
```

## 抽樣方式
- 從「未被採納」的意見中抽（對照現行文確認未採納）
- 優先抽**術語／主客／因果／範圍**四類
- 跳過純潤飾、加註要求、體例（篇題／引號／牒字）

## 判定
| 判定 | 定義 |
|:--|:--|
| 否決正確 | 現譯無誤（引原文或記文證明） |
| **否決錯誤** | 原譯確實有誤，被不當否決 |
| 難判 | 兩造皆無據 |

## 結論標準
| 抽樣結果 | 處置 |
|:--|:--|
| 0 錯（達抽樣數） | 通過，不複審 |
| 1 錯 | 擴大抽樣至全卷複審 |
| ≥2 錯 | 直接全卷複審 |

## 產出
- `測試/否決抽驗_<卷>.md`：逐條明細＋統計＋結論
- 錯誤的條目列出具體改法（不直接改檔，交給後續批次）

## 注意
- 記文只 grep（`TXT/02_四分律含注戒本疏.txt` 等），禁整檔讀
- 抽驗不改檔；改動另派
- 若某卷「登記否決數」與「實際未採納數」差距大，以實核為準並註明
