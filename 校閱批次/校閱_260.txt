# 校閱材料　第260檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【260-0001】02_戒疏/15b_卷三下之三#67
【原文】【記】二、得名中。上二可知。「七日約勢如《僧祇》」者。彼因佛問醫師：「比丘欲使畜藥，幾日得安穩？」答曰：「藥勢相接，七日可知。」佛言：「聽七日畜。」、「盡形可知」，上已明故。
【譯文】【記文】第二、得名依據中。上面兩項容易明白。「七日約勢如僧祇」這句話，起因於佛陀詢問醫師：「比丘若是想蓄留藥物，幾天之內可以保持身心平穩？」醫師回答說：「藥力相續接濟，七天之內就能明瞭效驗。」佛陀於是說：「聽許蓄留七天。」「盡形可知」，因為前文已經說明過了。

【260-0002】02_戒疏/15b_卷三下之三#68
【原文】【疏】三、立四所以。病有二種：一者，常病，易治數發；二、稀發，難治常差。對前常病，故立二藥：飢病既動，一食飽足，通日兼夜，病得消殄，故立時藥；渴病數發，隨發隨服，未局時節，故立非時。對後希病，故立二藥。七日功強，盡形力劣，故約功用長短不同。時與非時，位定各一，七日、盡形，通時非時。二定兩通，故立四藥。
【譯文】【疏文】第三、建立四種藥物的原因。疾病有兩種：第一種是經常性發作的病，容易醫治但頻繁發作；第二種是罕見發作的病，難以醫治且痊癒後不易復發。針對前一種常發的疾病，所以建立了兩種藥：飢餓之病既然發作，只要吃一餐飽足，整天乃至整夜，病態就能消滅除盡，所以建立了時藥；口渴之病頻繁發作，隨時發作就隨時飲用，沒有局限於特定時節，所以建立了非時藥。針對後一種罕見的疾病，所以建立了後兩種藥。七日藥的藥力強勁，盡形壽藥的藥力較為緩和微弱，所以依據功用時限的長短而有所不同。時藥與非時藥，其適用的時間固定各佔一處；七日藥與盡形壽藥，則通貫於時與非時皆可服用。由於有兩種時間固定、兩種時間通貫，所以總共確立了四種藥物。

【260-0003】02_戒疏/15b_卷三下之三#69
【原文】【記】三、立四中，初科為三。初示二病。「常病」即是飢渴，「稀病」即四百四病。亦名新故，亦曰主客。常病非患故「易治」，日別常生故「數發」；稀病違反故「難治」，治已永無故「常差」。「對前」下，二、明四藥。初明立前二藥。「殄」即滅也。「對後」下，次明立後二藥。「七日功強」，故限短；「盡形力劣」，故限長。「時與」下，三、結示通局。
【譯文】【記文】第三、建立四種藥物中，第一段分為三層。首先指出兩種疾病。「常病」就是飢渴，「稀病」就是四百零四種四大不調的病。也可以稱作新病舊病，或者稱為主病客病。常病本不算是重患所以「易治」，每天都會自然產生所以「數發」；罕見疾病因四大違逆所以「難治」，治癒後便長久平復所以「常差」。「對前」字以下，第二、說明四種藥物。起初說明建立前兩種藥。「殄」就是滅絕的意思。「對後」字以下，接著說明建立後兩種藥。「七日功強」，所以期限短；「盡形力劣」，所以期限長。「時與」字以下，第三、總結說明時限的通貫與局限。

【260-0004】02_戒疏/15b_卷三下之三#70
【原文】【疏】若依《明了》，藥則有五。一、依時量。二、依更量，即非時之異名。然彼論中，日夜分五時，隨時受藥，約至七時，如平旦至二更等輪轉為時，故曰「更」也。三、依七日量。四、依一期量，即盡形也。五、依大開量，謂灰、土、水、屎、尿也。此五世人所棄，不須受取，故曰「大開」。準《四分律》，有通塞也。
【譯文】【疏文】如果依照《明了論》，藥物則分為五種。第一、依時量。第二、依更量，這就是非時藥的另一種名稱。但在該論當中，白晝與夜晚各分為五個時段（白晝五時、夜間五更），隨著當時受持藥物，限制在七個時段之內，如平旦受藥可至二更，依序輪轉交替作為時段，所以稱為「更」。第三、依七日量。第四、依一期量，也就是盡形壽藥。第五、依大開量，指的就是灰、土、水、屎、尿這五種。這五種東西是世間人所遺棄的，不需要特別作法受取，所以稱為「大開」。若按照《四分律》，則有開許與禁制的不同規定。

【260-0005】02_戒疏/15b_卷三下之三#71
【原文】【記】次科。《了論》，五並名「量」，謂限齊也。「時量」，可知。「更量」者，即以五更為分齊更改也。「日分五時」者，寅、卯等時，乃是此方曆數，不可對之，但約一日分為五分，以對五更。「約至七時，如平旦至二更」，日夜共七時，日高時受，至三更；日中時受，至四更；日斜時受，至五更；日落時受，至夜分盡。若準本宗，無論早晚，皆盡夜分。五、「大開」者，無所制也。《四分》灰、土，有人須受，無人別開，故云「有通塞」也。《論》結云：「此五攝一切皆盡。」
【譯文】【記文】第二段。《明了論》中，五種都稱為「量」，是指期限標準。「時量」容易明白。「更量」，就是以五更的交替作為更換的分界。「日分五時」，寅、卯等時辰是此地的曆法算法，不能直接生硬對應，只是將白晝分為五個時段，用來對應夜間的五更。「約至七時，如平旦至二更」，晝夜共七個時段，太陽升高時受藥，可持續到三更；正午受藥，可持續到四更；夕陽西斜時受藥，可持續到五更；太陽落山時受藥，可持續到黑夜結束。如果依準本律宗的規矩，無論早晚受藥，都只能持續到當夜結束為止。第五、「大開」，是指毫無限制規定的意思。《四分律》中灰、土若有人看守則必須受取，無人看守才另外開許，所以說「有通塞」不同。《論》總結說：「這五類涵蓋了一切藥物。」

【260-0010】02_戒疏/15b_卷三下之三#76
【原文】【疏】就定體中。言時藥者，文有二種。一、蒲闍尼，謂飯、麨、乾飯、魚及肉也。此之五種，若食一口，是「正」，是「足」，是「背」，是「別」也。二、佉闍尼，謂枝、葉、華、果、細末磨食也。此五反上，非「足」非「正」也。
【譯文】【疏文】在判定體質中。說到時藥，律文記載有兩種。第一、蒲闍尼，指的是飯、乾炒麵麥粉（麨）、乾飯、魚肉以及獸肉。這五種食物，如果吃下一口，就構成了「正食」、構成了「飽足（食足）」、構成了「背請（展轉食）」、構成了「別眾食」。第二、佉闍尼，指的是樹枝、樹葉、花朵、果實，以及細末研磨做成的食物。這五種與上述相反，既不構成「食足」，也不算作「正食」。

【260-0011】02_戒疏/15b_卷三下之三#77
【原文】【記】定體中。初明正食。「是正」，即顯體。「足、背、別」，即下篇三戒，局正食犯。次明不正。文令「反上」，合云非正、非足、非背、非別。

【260-0034】02_戒疏/15b_卷三下之三#100

【譯文】【疏文】依此作為通例，物品的生與熟判定是不一定的。有的生熟全都是同一類，例如稻米、大麥、生薑、胡椒等；有的生時是時藥，熟了之後卻變成盡形壽藥；有的生時是盡形壽藥，煮熟之後卻變成了時藥，例如杏仁、山藥（署預）、芋頭、葛根。所以藥物的性狀轉變隨著時機而定，不可執著於固定一端。好比甘蔗這一種原料，轉變後可以通貫四種藥，難道加工製成了冰糖石蜜，就只能限定在應食的時段中吃嗎？這類的混濫情況非常多，這裡僅僅略微列舉一二罷了。

【260-0035】02_戒疏/15b_卷三下之三#101
【原文】【記】三中。初準上論，以例生熟。初句，「米、麥」俱時藥，「薑、椒」俱盡形。第二句，如米、麥、甘蔗燒灰之類。第三，列相可見，文無俱非，不可立故。「故轉變」下，顯示不定。「甘蔗通四」，如下自引，以本是時藥，若取清汁得非時服，若作石蜜得七日服，若燒作灰得終身服，故云「豈成」等。「斯」下，示略。
【譯文】【記文】第三段中。首先依照上文論述，用來類推生熟的變化。第一種情況，「稻米、大麥」生熟全都是時藥，「生薑、胡椒」生熟全都是盡形壽藥。第二種情況，例如把稻米、大麥、甘蔗燒成炭灰之類。第三種情況，列舉的行相顯而易見；文中沒有列出「生熟全非」的情況，因為根本無法成立。「故轉變」以下，顯示性狀並不固定。「甘蔗通四」，如下文自會引用，因為它本質是時藥，若榨取澄清果汁就可以在非時飲用，若熬製成石蜜就可以作為七日藥服用，若燒製成灰就可以作為終身盡形壽藥服用，所以說「難道製成石蜜」等語。「斯」字往下，表示此處僅作簡略說明。
