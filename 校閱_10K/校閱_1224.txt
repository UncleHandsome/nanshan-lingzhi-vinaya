# 校閱材料　第1224檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1224-0001】資持記/11b_中四上#18
【原文】此明凡夫稟持別脫，遠能趣果，非定道戒。七中。煩惱重處，為善者希；復由苦逼，心必猛盛，所以獨勝；餘二弱者，煩惱輕故。北洲難地，故所不論。經云：南洲一日一夜發心修行，勝東西二洲五十小劫，是也。八中，初標。前後，即約時也。次釋，有二，上約在滅以論。
【譯文】這是說明凡夫受持別解脫戒，長遠來看能夠趣向證果，而不是指禪定或道共戒。第七門中。在煩惱深重之處，能行善法的人極為稀少；又因為苦難逼迫，修行之心必定勇猛熾盛，所以此處持戒獨自殊勝；其餘二洲之所以軟弱，是因為煩惱較輕的緣故。北俱盧洲屬於難以聞法修道之地，所以不列入討論。經中說：在南贍部洲一日一夜發心修行，勝過在東勝神洲、西牛賀洲修行五十小劫，就是這個道理。第八門中，最初標示。「前後」就是指時間的先後。接下來進行解釋，分為二部分：上方就佛陀在世與滅度後而論。

【1224-0002】資持記/11b_中四上#19
【原文】下約三時而說。正法千年，具教理行果；像法千年，闕果；末法萬年，闕行果；人根轉濁，漸劣可知。以下，引證。《付法藏傳》，第五祖師，度人既多，時人號為無相好佛。〔行化同佛，但無相好。〕掘多意謂與佛同等，時有老尼，見佛在時事，多往問之；彼尼先以器盛油，安戶扉後；掘多入房，傾油數滴；
【譯文】下方就三時（正、像、末）而說。正法一千年，具備教、理、行、果；像法一千年，缺乏證果；末法一萬年，則缺乏如法修行與證果；人的根性愈來愈濁惡，持戒逐漸低劣，由此可知。在「以」字以下，引文為證。《付法藏傳》中記載，第五祖優波毱多尊者度化的人極多，當時的人稱他為「無相好佛」〔化導眾生的事業等同於佛，只是沒有三十二相八十種好〕。毱多尊者自以為修為已與佛同等。當時有一位老比丘尼，曾親見佛陀在世時的種種事蹟，尊者便前往向她請問；那位比丘尼預先用器皿盛滿油，安置在門扉之後；尊者推門進房時，濺出了幾滴油；

【1224-0003】資持記/11b_中四上#20
【原文】多問尼云：佛在世時，所化何如我耶？尼云：佛世六群，數入我房，未嘗傾油一滴；今尊者弗及六群；鈔撮其意，如文所云。掘多，亦云毱多。九中。約罪則性強遮弱，約治則遮優性劣，故云互也。十中。篇聚，準上兩意，互論優劣。第二犯中，十門；初門為三，初學無學相望。
【譯文】毱多尊者問比丘尼說：「佛在世時，弟子被教化的風範與我相比如何？」比丘尼說：「佛陀在世時的六群比丘，多次進入我的房間，從來不曾灑出一滴油；如今尊者的威儀還比不上六群比丘。」《事鈔》撮取其大意，就如文中所載。掘多，也就是指毱多。第九門中。若從罪過本質來看，則性罪過重而遮罪過輕；若從對治之功來看，則防護遮罪較優而防護性罪較劣，所以說是「互相參差」。第十門中。各篇聚的輕重，比照上述兩種意涵，互相討論其優劣。第二大項「犯戒」之中，有十個門類；第一門分為三節，最初是有學聖人與無學聖人相望。

【1224-0004】資持記/11b_中四上#21
【原文】無學見思已盡，故無故犯。事習未亡，故容有誤。三果殘思未盡，容有故心。〔上二但犯遮戒。〕初二兩果，欲惑未盡，故心犯性；但不造他，復不結業；不受總報，與凡為異。〔須斯二尼怨逼受樂，如〈受戒〉引。〕文云三果，亦指三位。次約聖凡相望。聖人見理，業不集故；
【譯文】無學聖人的見惑與思惑皆已斷盡，所以絕不會故意犯戒。但生活習慣習氣尚未完全消除，所以仍可能產生過失。三果（阿那含）聖人殘餘的思惑未盡，仍容許有故意犯戒之心〔上述二者都只會違犯遮戒〕。初果與二果聖人，欲界煩惱未斷盡，仍會起故意心違犯性罪；但不會以此加害他人，也不會招感牽引輪迴的引業；不再領受生死總報，這一點與凡夫不同〔如證得須陀洹與斯陀含二果的比丘尼被怨家逼迫而生起快感，如同〈受戒篇〉所引〕。文中說「三果」，也是指這三種果位。其次是依聖人與凡夫相望。聖人已照見真理，不再積集惡業；

【1224-0005】資持記/11b_中四上#22
【原文】內凡未證，惑全在故。三約內外相望。乃至者，合云：內凡分見真理，定慧力強故輕；外凡未緣，諦理，事行道劣故重。上約四位相望，總而為言，無學最劣；五停至優，中間互通，準前可解。文中，且據行位，故至外凡；更通簿地，極為優矣。二中。初止作者，約心對事。下故誤者，唯就心論；
【譯文】內凡夫尚未證得真理，煩惱仍全數具在。第三是依內凡與外凡相望。文中說「乃至」，應補充說明為：內凡夫已部分見到真理，定力與智慧較強，所以犯戒之罪較輕；外凡夫尚未緣見真理，事相上的修行道力軟弱，所以罪過較重。上述就四種位階相望，總體而言，無學聖人最劣（犯意最輕）；五停心位最優（犯意最重），中間互相比對，依此準理可解。文中暫且依修行的位階，只推論到外凡夫；若進一步通論煩惱極重的薄地凡夫，其犯戒之過就極為深重了。第二門中。最初的「止犯」與「作犯」，是就內心對應外在事緣而論。下方的「故意」與「誤犯」，純粹是就心態而論；

【1224-0006】資持記/11b_中四上#23
【原文】該上兩犯，各通二心。三中。指前，即〈篇聚〉中，不善為優，善心為劣，無記至劣。四中。指篇聚者，犯前戒分，重故為優；犯後威儀，輕故為劣。又復統約篇聚，夷優吉劣，迭望可解。五中。犯遮罪輕，但違制教；犯性罪重，制業俱違。指《智論》者，文見〈懺篇〉。六中。
【譯文】這涵蓋了上述兩種犯戒行為，各自都通於這兩種心態。第三門中。指涉前面，就是指〈篇聚〉之中，不善心所犯最重（為優），善心所犯較輕（為劣），無記心所犯最輕。第四門中。指涉篇聚，違犯前面的根本重戒，罪重所以為優；違犯後面的微細威儀戒，罪輕所以為劣。又總括所有篇聚來論，波羅夷罪最重為優，突吉羅罪最輕為劣，彼此互相對望即可明白。第五門中。違犯遮戒罪較輕，僅違背佛陀制定的教規；違犯性戒罪較重，教規與自性惡業同時違背。文中所引的《大智度論》，文字見於〈懺篇〉。第六門中。

【1224-0007】資持記/11b_中四上#24
【原文】指前持者，佛在根利犯輕，滅後漸濁犯重。三時相對，輕重亦然。〔準約三方，南優餘劣。〕第七，標中。謂心境相望，或等或互以顯優劣。引論中，初準文通示。以罪假緣成，緣即心境。境是外緣，故云託也；心是內緣，故云關也。心起不常，故有增微；境緣非一，故有優劣。
【譯文】指涉前述持戒之門：佛陀在世時根機利，犯戒罪較輕；佛滅度後世質轉濁，犯戒罪較重。三時（正像末）互相對照，其輕重也是如此〔依照三洲的劃分，南洲犯戒之業最重，其餘二洲較輕〕。第七門，標題中。這是指將心念與外境互相對照，顯現出平等或互有高下的優劣。引論之中，最初依據論文明顯通示。因為罪過是藉助外緣而成就的，這外緣就是心與境。境是外在因緣，所以說是「託」；心是內在因緣，所以說是「關」。心念的生起並不恆常，所以有增強與微弱之別；外在境緣不是單一的，所以有尊貴與卑劣之殊。

【1224-0008】資持記/11b_中四上#25
【原文】或下，歷句別簡。初句俱優，下二句互有優劣。義立俱劣一句，如非人作畜杌想之類。論下，點上論文，語通篇聚。句中且約殺戒顯相，故別歷四重，諸餘例通。婬中，初句通摽。畜下，別簡，有四，初句簡異類。理加非人，次於畜趣。二人中簡道俗。三道俗中各簡持破。
【譯文】在「或」字以下，依不同句式分別簡別。第一句是心與境都很重（俱優），下兩句則是心重境劣或境重心劣（互有優劣）。義理上尚可成立「心境皆輕（俱劣）」一句，例如將非人誤認為畜生、甚至當成枯木樁之類。在「論」字以下，指點上述論文，其文句通貫所有篇聚。各句之中暫且依殺戒來顯明行相，所以分別歷數四種重戒，其餘各戒皆可依此例推。淫戒中，第一句作總體標示。在「畜」字以下，分別簡別，共有四種：第一句簡別異類，理應加上非人，列在畜生道之後。第二是在人道中簡別修道人與世俗人。第三在道俗中各自簡別持戒者與破戒者。
