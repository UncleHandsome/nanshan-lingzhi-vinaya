# 校閱材料　第216檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【216-0001】03_業疏/17a_卷三之六#107
【原文】出體中，初標。「就下」，釋有二：初約境。色塵該四境，香、味收食、藥，觸塵有通別，通竝觸對，別但收衣、樹。《毗曇》、《有部》、《雜心》、《俱舍》，並明八微，謂四塵各起於極微故有四微，四塵之麤假四微所成，故通名八微。「就下」，次約心者，心即是行。《雜心》云：聖種何等性？答：無貪善根性，約眷屬論善五陰性。
【譯文】在顯明體性的段落中，起初標明。自「就下」句起，解釋分為兩部分：首先依境界而論。色塵涵蓋四種依怙的境界，香塵與味塵收攝飲食和藥品，觸塵則有通與別之分，共通而言皆能觸對，差別而言則僅收攝衣服與樹木。《阿毗曇》、《有部》、《雜心論》、《俱舍論》，都闡明八微之說，也就是色香味觸四塵各自生起於極微所以有四大極微，四塵粗顯之相假借四種微細極微所構成，所以通稱為八微。自「就下」句起，其次依自心而論，自心也就是內在修行。《雜心論》說：聖種是什麼體性？答：是無貪善根的體性，若就隨行眷屬而言，則是善五陰的體性。

【216-0003】03_業疏/17a_卷三之六#109
【原文】衣則無時不須，資身最要，理先明之。既得覆形，內惱須濟，故次乞食。身雖得立，威儀須託，故第三明樹下坐。無病三足，病起不救，則無治能，故立腐藥為第四也。
【譯文】衣服是沒有任何時刻不需要的，對於資助色身最為切要，理應首先加以說明。既然已經得以遮蔽形體，體內的飢餓熱惱必須救濟，所以接著說明常乞食。身體雖然得以存立，修行威儀必須有所依託，所以第三說明樹下坐。沒有疾病時這前三種已然充足，但若疾病生起而不救治，就沒有修道的精力能耐，所以確立腐爛陳藥為第四項。

【216-0004】03_業疏/17a_卷三之六#110
【原文】第四正釋中，躡前起後，次第相由，尋文易見。
【譯文】在第四項正式解釋中，承接前文引發後文，各項次第相互承接由來，循著文意很容易看出。

【216-0005】03_業疏/17a_卷三之六#111
【原文】此就受用行之次第，一人具四；不同頭陀機教列相，多人方具也。如離坐為五，不可分身，則可知也。
【譯文】這是就個人受用修行的次第而言，一人身上必須具備這四種；不同於十二頭陀行依根機設教而羅列相狀，必須多個人分別實踐才能具備。例如頭陀行中將處所坐法分為五種，一人不可能分身居於五處，由此便可明白。

【216-0006】03_業疏/17a_卷三之六#112
【原文】對簡中，初指前。「不下」，簡異。恐謂同彼十二頭陀，故特點之。機教列相，謂因機設教。離坐為五，《鈔》云：於處立五，一、蘭若，二、塜間，三、樹下，四、露坐，五、隨坐。此明多人各行之行，豈可一身而分五處？
【譯文】在對比揀擇的段落中，起初指陳前文。自「不下」句起，揀除差異。這是恐怕有人誤以為與那十二頭陀行相同，所以特別點明。「機教列相」，是指因應根機施設教法。將坐處分為五種，《戒本疏鈔》說：就處所設立五種，第一、阿蘭若，第二、塚間，第三、樹下，第四、露天而坐，第五、隨處坐。這是指由多個人各自實踐不同之行，怎能一個人分身在五處呢？

【譯文】第五、說明開許與遮止（開遮）。

【216-0008】03_業疏/17a_卷三之六#114
【原文】良由大聖識達根性，稱機授藥。報力增上，制前四法，即有資身長道獲益；中下力劣，事假眾緣，若不開聽著施衣等，則有退道，寧堪涉苦？若唯制者，報劣絕分；若唯開者，上行慢求。由有開遮，三人通備，皆能會正，故曰聖種。
【譯文】這確實是因為大聖佛陀通達了知眾生的根性，稱合其根機而施與藥方。對於果報根力增上者，制定了前述四種嚴格行法，就能資助形體、增長道業並獲得實益；中下根性者根力微劣，行事必須假借眾多外緣，若不開許准聽穿著施主所布施的衣服等，就會退失道心，哪裡堪忍經受苦行？如果一味加以遮制，根器微劣的人就斷絕了修道的份額；如果一味開許，行持上乘之行的人就會懈怠放任並滋生貪求。正因為有開許與遮制，三類根性的人都能被顧及兼備，皆能契會正道，所以稱為聖種。

【216-0009】03_業疏/17a_卷三之六#115
【原文】第五門正法中，初科初敘聖意。「報下」，次明開遮，遮即是制。初敘四制，專被上根；「中下」，次明四開，即攝中、下二根，且舉施衣，餘三類說。「若下」，三明二教相成，不可闕一。備合作被，會正即證果。
【譯文】在第五門說明正法的段落中，初科起初敘述佛聖之意趣。自「報下」句起，接著說明開遮，「遮」也就是「制」。起初敘述四種根本制法，專門普被上等根器；自「中下」句起，接著說明四種開許，也就是統攝中、下兩類根器，暫且以施主衣為例，其餘三種依此類推。自「若下」句起，第三說明制與開這兩類教法相輔相成，不可或缺其一。「備」字應作「被」（覆蓋、加被之意），「會正」就是指證得聖果。

【216-0010】03_業疏/17a_卷三之六#116
【原文】是知聖說具四種義：一、慈心益物；二、稱機設藥；三、善達開遮，非但開於中下服諸好衣，亦開上士有病及無糞衣聽受施服，由本通道，故有斯開，故《雜心》云「若僧和合，令超昇離生，得果漏盡，坐禪、學問、思惟業生」，餘之三依，例此可比；四者、佛說乞食等四能生道緣，正語等八能生道因，稱法而談，無謬濫過。
【譯文】由此可知佛聖的宣說具備四種深義：第一、以慈悲之心利益眾生；第二、契稱根機施設藥方；第三、善巧通達開許與遮止，不僅開許中下根器穿著各種美好衣服，也開許上等修道之士在患病及沒有糞掃衣時聽許受用施主衣服，由於其根本目的是為了通達聖道，所以才有這樣的開許，因此《雜阿毗曇心論》說「如果僧團和合，能令行者超昇出離生老病死，證得道果、斷盡煩惱漏失，從而引生坐禪、研學、思惟等功德業」，其餘三種四依，照此類推即可比知；第四、佛說常乞食等四種法能成為引生修道的助緣，正語等八正道能成為引生聖道的正因，稱合法理而宣談，毫無謬誤混濫之過失。

【216-0011】03_業疏/17a_卷三之六#117
【原文】次科初總舉。「一下」，別列。初是本誓，二即鑒機，三能達教。一開已後，通被三根；仍引《雜心》，顯示開聽必須存道。僧和無諍，容可進道；得果對超昇，漏盡對離生。上舉施衣，餘三有開，意不殊此。四即彰益，四依資道，故得名緣；八正修心，故云道因。
【譯文】次科起初總括標舉。自「一下」句起，分別羅列。第一項是如來的根本誓願，第二項是審鑒根機，第三項是通達教法。開許一經確立之後，便普遍普被三種根機；文中仍舊引用《雜阿毗曇心論》，顯示准聽開許的前提是內心必須存有求道之念。僧團和合而無諍論，才能進修道業；「得果」對應於「超昇」，「漏盡」對應於「離生」。上面舉出接受施衣，其餘三種四依也有開許，其意旨與此並無不同。第四項是彰顯利益，四依法資助修道，所以稱為道緣；八正道用於修治心神，所以稱為道因。

【216-0012】03_業疏/17a_卷三之六#118
【原文】調達效佛，乃說五法，唯制不開，謂納衣、乞食、樹下、不食酥鹽等也。一則不具四義，如上反說；二則顛倒說法，令墮邪見，謂語業八為道緣，乞食等五說為道因，逾於八正，廣說相似，惑亂正依，致令愚叢猶學此道，即調達部也。
【譯文】提婆達多仿效佛陀，竟然創立五種行法，只有遮制而沒有開許，也就是穿著補納衣、常乞食、樹下坐、不吃酥油與鹽等。一方面他不具備前述四種深義，正如上面反面所言；另一方面則顛倒說法，使人墮入邪見，把八正道（語業等八法）說成是修道的助緣，把乞食等五種法說成是得道的正因，凌駕於八正道之上，廣泛宣說似是而非的道理，惑亂了正法所依，致使愚痴的僧眾仍去修學這套教法，這便是提婆達多部派。

【216-0013】03_業疏/17a_卷三之六#119
【原文】邪法中，初敘立法。調達，具云提婆達多，此云天熱，生時諸天心熱惱故。立邪三寶，破佛正法；五法即法寶也。酥鹽，以酥脂煑鹽，彼為珍味故；而言「等」者，等取魚肉。「一下」，次顯過。不具四義：一、無慈心，二、不識機，三、不曉教，四、無利益。二、顛倒說法，以因為緣，以緣為因，即用五法以貶八正也。逾，過也。相似者，五中前三名相似語，後二為妄語。愚叢猶學，至今西竺尚有遺風。

【216-0030】03_業疏/17a_卷三之六#136
【原文】「依糞掃衣」者，舉名顯示也。依律中列十種，竝世所同棄，如糞掃喻耳。故俗所賤者，道所貴也。此據常人，故有言耳。故《論語》云：「君子不耻惡衣惡食，若耻則未可與議也。」《劉子》云：「食足充虗接氣，衣足葢形御寒。」斯言是也。至如冠章甫，衣縫掖，嘉肴溢目，芳音盈耳，一時之榮，故不足尚也。《書》云「高位厚味，俱不可久」，是以君子存謙光之道。忍人不忍，謂憎愛也；割人不割，即情欲也；行人不行，即仁義也。欲尚爾，況懷道乎？知是繁文，末俗多昧故也。
【譯文】「依糞掃衣」，是舉出名稱加以顯示。依照律中所列共有十種，全都是世人共同遺棄之物，就如同掃除的糞穢塵垢一般作比喻罷了。所以世俗所鄙賤的，正是修道所珍貴的。這是就普通人而言，所以才作這番議論。因此《論語》說：「君子不耻惡衣惡食，若耻則未可與議也。」《劉子》說：「食足充虗接氣，衣足葢形御寒。」這話確實很對。至於頭戴章甫冠，身著寬袖衣（縫掖），美味佳餚滿目琳瑯，美妙絲竹充盈於耳，這只是一時的虛榮，本來就不值得推崇。《尚書》說「高位厚味，俱不可久」，因此君子心存謙遜光大之道。忍受常人所不能忍受的，是指憎恨與貪愛；割捨常人所不能割捨的，就是指情執與欲望；踐行常人所不能踐行的，就是指仁義之道。在世俗欲望上尚且應當如此，更何況心懷至高聖道呢？明知這是繁複的文字，只因末世凡俗多有愚昧暗昧的緣故。

【216-0031】03_業疏/17a_卷三之六#137
【原文】「依律下」，委釋為三：初示名體。律十種者：一、牛嚼，二、鼠嚙，三、火燒，四、月水，五、產婦，六、神廟，七、塚間，八、求願，九、往還，十、王軄。俗賤道貴，示相反也。「此下」，次議其名。常人謂淺識者，若卓拔君子，豈以衣為糞掃耶？「故下」，三引況。初《論語》，「未可與議」，言此庸人不足語道。《劉子》即劉晝也，著書二卷五十五篇，窮悴無由自達，乃負其書候沈約於車前獻之，約覽而異之，遂呼登車定交，時人號此書為《劉子》。今引〈防欲篇〉，彼云「明者刳情以遣累，約欲以守貞」，方接「食足」等語。「斯言是」者，美其有理也。「至下」，敘厭榮。冠、衣二字去呼。章甫，殷時冠也；縫掖，大袖衣也。《家語》孔子對哀公曰：「丘少居魯，衣縫掖之衣；長居宋，冠章甫之冠。」嘉肴謂品饌，非穀而食曰肴；芳音謂歌樂之聲。高位是貴，厚味是富，未詳何書。「俱不可久」，勢有退也。「是以」下，明向道。《易·謙卦》云：「人道惡盈而好謙，謙尊而光，卑而不可踰，君子之終也。」「忍人」等者，謂眾人所不能者，我則勉力為之。文出《淨住子》，本唯三句，疏加配釋，助顯其文。以俗況道，俗淺道深，理必過之，況不及乎？況相反乎？「知下」，三結意。
【譯文】自「依律下」句起，詳細解釋分為三部分：第一、顯示名稱與體相。律中所列十種糞掃衣是：一、被牛嚼破之衣，二、被老鼠咬破之衣，三、被火燒殘之衣，四、沾染月經之衣，五、產婦用過之衣，六、神廟祭祀之衣，七、墳墓塚間死人之衣，八、祈願祭神後捨棄之衣，九、從遠途往返廢棄之衣，十、王職（受刑死者或王官廢棄）之衣。世俗所賤而道人所貴，顯示二者正相反對。自「此下」句起，第二評議其名稱。「常人」是指見識淺陋之輩，若是超卓拔萃的君子，哪會把這衣物看作糞土塵芥呢？自「故下」句起，第三引用世間典籍作比況。首先引用《論語》，「未可與議」是說這種庸俗之人不值得同他論道。《劉子》即劉晝，著書兩卷五十五篇，因貧困潦倒無由自我顯達，便背著自己的書在沈約的車前等候並進獻，沈約展讀後深感其奇異，於是呼喚他登車結為好友，當時人便稱這部書為《劉子》。此處引用其〈防欲篇〉，該篇說「明智之士剖除情執以排遣牽累，節約欲望以堅守貞節」，隨後才接上「食足」等語。「斯言是」一句，是讚賞這話極有道理。自「至下」句起，敘述厭離榮華。「冠」、「衣」二字讀去聲（作動詞用）。章甫是殷商時期的冠帽；縫掖是大袖之儒服。《孔子家語》載孔子回答魯哀公說：「我丘年少時住在魯國，身穿縫掖之衣；年長後住在宋國，頭戴章甫之冠。」「嘉肴」指各類美味菜餚，非五穀主食的菜味稱為肴；「芳音」是指歌舞音樂之聲。「高位」代表顯貴，「厚味」代表富有，具體出自何書尚不詳備。「俱不可久」，是說權勢與富貴終有退失之時。自「是以」以下，明示心向於道。《易經·謙卦》說：「人道惡盈而好謙，謙尊而光，卑而不可踰，君子之終也。」「忍人」等句，是指眾人所不能做到的，我則盡勉力去踐行。文句出自《淨住子》，原文只有三句，疏文加上了對應配釋，以助顯其深意。以世俗之事比況修道，世俗尚淺而聖道至深，其義理必定超越世俗，又怎會及不上呢？又怎會反其道而行呢？自「知下」句起，第三總結其立意。
