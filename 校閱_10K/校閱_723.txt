# 校閱材料　第723檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【723-0001】02_戒疏/16a_卷四上之一#56
【原文】【記】今解中。四行並據造作為言。指「如上」者，即僧殘中。「持犯約教」者，示其源也。「隨戒彰相」者，雙單別也。「如」下，略示名體。二持二犯，一一皆別，舉一例諸，自餘準說。「抑」謂抑塞。「不求」，即不乞羯磨。
【譯文】【記文】現在的正確解釋中。四種行持都是依據起心造作而言。指稱「如前面」，即指在僧殘篇中。「持犯依據教法」指明了它的源頭。「隨戒彰顯相狀」指明雙持與單持的差別。「例如」以下略微展示其名相與本體。二持二犯，每一項都各自不同，舉出一戒為例，其餘的準照此說。「抑」是指壓抑阻絕。「不求」是指不向僧眾請求羯磨。

【723-0002】02_戒疏/16a_卷四上之一#57
【原文】【疏】若懺罪時，但依戒悔。二犯據法，不在悔收。止學無知，別制別懺。
【譯文】【疏文】若是懺悔罪過的時候，只要依照根本戒條去悔過。雙犯之中的第二犯（止犯）是依據行法而論，不在通常的悔法中收攝。凡是停止學習所產生的無知罪，乃是另外制裁、另外懺悔。

【723-0003】02_戒疏/16a_卷四上之一#58
【原文】【記】明懺中。上既異古，二犯體別，須明行懺開合之相。初明本犯，「二」下，次示止犯。言「二犯」者，謂雙犯中止犯罪也。或可悔法中不收此罪。既是別制，故須別懺。言「別制」者，以更重增無知罪故。
【譯文】【記文】說明懺罪之中。上面既然與古義不同，二犯的體質各異，便須說明行懺時開許與合併的行相。先說明根本犯戒之罪，「二」以下，次說明止犯之罪。所謂「二犯」，是指雙犯之中的止犯之罪。或者說在通行的懺悔法中不收攬此罪。既然是另外制定的戒條，所以必須另外懺悔。所謂「另外制定」，是因為更重增了不學無知的罪過。

【723-0004】02_戒疏/16a_卷四上之一#59
【原文】【疏】如昔解云：「七日等藥，加二受竟，防無非時名作持。」今解不然。七日無法，非時得食，本無限約。由作口法，過限故有非時。此乃口生非時，何得口防非時？故知無也。
【譯文】【疏文】如過去的解釋說：「七日等藥物，加入手受與口受二法完畢之後，用以防護使其不成為非時食，稱為作持。」現在的解釋並非如此。七日藥若無作法，本來在非時也能吃，本來就沒有限制。正是由於作了口中說法受持，一旦過了期限反而有了非時之禁。這分明是由口法而產生非時犯，哪能說是口法用來防護非時呢？所以可知並無此種防護之義。

【723-0005】02_戒疏/16a_卷四上之一#60
【原文】【記】斥七日中。初引古解。「七日等」者，「等」取盡形，彼謂加口法已，非時得服故。次示今解，又二。初明非時本開暫服，則知口法不防非時。「由」下，次明過限能生非時，則知口法非是能防。「故知無」者，謂無防義也。
【譯文】【記文】破斥七日藥之中。先引古人的解釋。「七日等」，「等」字包括了盡形壽藥，彼古師認為加入口受法後，便可以在非時服用。次開示現在的正確解釋，又分兩點：先說明非時本來開許暫時服用，即可知口法並非用以防護非時。「正是由於」以下，次說明過期反而會產生非時之犯，即可知口法並不是能防護者。「所以可知並無」是指並無防護的涵義。

【723-0006】02_戒疏/16a_卷四上之一#61
【原文】【疏】「覆藏」昔解為作持，亦非義也。頗有順教覆，得說無罪邪？如非時入村依教作，與本入村時無別，故說為作持。
【譯文】【疏文】「覆藏」這條戒，過去解釋為作持，也是不合義理的。難道有順從教法去覆藏、進而宣說為無罪的道理嗎？好比在非時入村依教法作白，與原本入村之時並無差別，所以才能稱為作持。

【723-0007】02_戒疏/16a_卷四上之一#62
【原文】【記】斥「覆藏」中。初示非。彼謂發露即是作持。「頗」下，反詰。若許覆藏說而無罪，可名作持。然無此理，故不可立。「如」下，引前比顯。前十二戒，若本無法則成於犯，由開作法，故名為持。覆藏不爾，相比可知。
【譯文】【記文】破斥「覆藏」戒之中。先指出其錯誤。彼古師認為發露懺悔即是作持。「難道」以下反詰。如果容許順從教誡覆藏而宣稱無罪，那才可稱為作持。然而絕無此理，所以不能成立。「好比」以下引前文比照顯明。前述十二條戒，若是本來沒有作法就會構成違犯，是由於開許作法而稱之為作持。覆藏戒並非如此，兩相比較便可明白。

【723-0018】02_戒疏/16a_卷四上之一#73
【原文】【疏】言止持者，謂佛制教，令學行之。我依修學，於境無犯。然根機利鈍，不可齊準，至於萬境，由迷疑網，故以諸九，定品優劣，且分三位。
【譯文】【疏文】所謂止持，是指佛陀制定了教法，令人修學實踐。我依教修學，面對萬境不生違犯。然而眾生根機有利有鈍，無法齊一標準，面對森羅萬象的境界，由於迷惑困頓於疑惑網絡中，所以用各類的九句分別法，來判定品第的高下優劣，暫且分為三個品位。

【723-0019】02_戒疏/16a_卷四上之一#74
【原文】【記】止持，標敘中。初示立教之源。「我」下，明為學之本。「然」下，生起品位。言「諸九」者，據通為言，若法若事，不出可學、不可學二九句法。就戒別論，雙持犯者，法事兩別則有四九，單法單事但有二九。止犯加八，唯收不學教行之罪。言「優劣」者，持門則識優疑次，不識最劣，犯門反之。
【譯文】【記文】止持標題敘述之中。先開示立教的源頭。「我依教」以下，說明修學的根本。「然而」以下，引導生出品位的分別。所謂「各類九句」，是通泛而言，不論是法或是事，都不出於可學與不可學兩種九句法。就個別戒相而論，具備雙持雙犯者，因法與事兩者各異便有四個九句；單純於法或單純於事，則只有兩個九句。止犯再加上八句，唯獨收攝不學教法行持的罪過。所謂「優劣」，在持戒門中，明瞭者為上優，起疑者次之，不明了者最劣；在犯戒門中則恰恰相反。
