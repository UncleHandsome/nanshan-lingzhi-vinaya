#### 4. `_src/mk_split_blind.py`：第 1 小段把「自己」放進了【前文背景（嚴禁譯入正文）】
看第 1020 行：
```python
pre_lines += ['【%s】%s' % (lab, p) for p in parts[:1]] if len(parts) > 1 else []
```
`if pi > 1:` 才會把 `pre[:-1]` 蓋掉；**當 `pi == 1` 時，`parts[0]`（就是第 1 小段本身！）會直接留在【前文背景（嚴禁譯入正文）】裡**，等於一邊把第 1 小段放待譯區、一邊叫模型嚴禁譯入它！同時第 1、2 小段在【後文背景】也沒有帶「本段後文」，而是直接跳去下一整段。
**修正**：移除 `pre_lines += ... parts[:1]`，改成迴圈內 `if pi > 1: pre.append('【%s】（本段前文）%s' % (lab, parts[pi - 2][-260:]))`，且 `if pi < len(parts): post_lines = ['【%s】（本段後文）%s' % (lab, parts[pi][:260])] + post_lines`。
