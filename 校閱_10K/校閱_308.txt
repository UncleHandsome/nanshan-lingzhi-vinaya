# 校閱材料　第308檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【308-0001】02_戒疏/01b_卷一上之一#31
【原文】【疏】經論廣演，其量極多。如《涅槃》說「半」、「滿」兩字，用收大小。如餘經論，三藏攝文。或分大小，各立四藏，即三藏外加一雜藏。如大乘論，但立兩藏，菩薩、聲聞，攝教斯盡。
【譯文】【疏文】經論中廣泛闡述的教判準則，數量極為豐富。例如《涅槃經》提出「半字」與「滿字」兩種名稱，用來收攝小乘與大乘教法。又如其餘經論，以修多羅、阿毗曇、毗尼三藏來收攝一切法文。或者區分大乘與小乘，各自安立四藏，也就是在經律論三藏之外各加上一個「雜藏」。又如大乘論典之中，僅僅設立「菩薩藏」與「聲聞藏」這二藏，便將佛陀一切言教收攝殆盡。

【308-0002】02_戒疏/01b_卷一上之一#32
【原文】【記】次科，初二句總示。諸經論中，既有多判，理須準用，不當自裁。「如」下，引示，有三。
【譯文】【記文】下一個科判，起初兩句總體指示。諸部經論之中既然已有極其豐富的教判模式，理應當遵循沿用，萬萬不可隨意自行裁量。從「如」以下，引證說明，共有三處。

【308-0003】02_戒疏/01b_卷一上之一#33
【原文】【記】初、引《涅槃》兩字判。彼云：「『半』字義者，皆是煩惱言說之本；『滿』字者，乃是一切善法之根本也。」《涅槃論》云：「『半』字者漸教，『滿』字者涅槃滿足教。攝佛教果滿功德盡故名『滿』，聲聞緣覺，教不滿足，故名『半』也。」
【譯文】【記文】第一、引述《涅槃經》的「半滿二字判」。經中說：「『半字』的內涵，是一切煩惱言說思維的根本；『滿字』的內涵，乃是一切純善功德的根本。」《涅槃論》說：「所謂『半字』是指漸教，『滿字』是指涅槃圓滿的教法。因為它能窮盡攝受佛果圓滿功德的緣故稱為『滿』，而聲聞緣覺二乘的教法尚不圓滿，所以稱為『半』。」

【308-0004】02_戒疏/01b_卷一上之一#34
【原文】【記】「如」下，次、引經論諸藏判。「三藏」者，一、修多羅，二、阿毗曇，三、毗尼。「大、小各立四藏」，是為八藏。
【譯文】【記文】從「如」以下，第二、引述經論中的「諸藏教判」。所謂「三藏」，第一是修多羅（經），第二是阿毗曇（論），第三是毗尼（律）。而「大乘與小乘各安立四藏」，合計便是八藏。

【308-0005】02_戒疏/01b_卷一上之一#35
【原文】【記】「如」下，三、引大論兩藏判，即指《智論》，彼云：佛口所說，以文字語言分為二種，三藏是聲聞法，摩訶衍是大乘法，即菩薩藏也。
【譯文】【記文】從「如」以下，第三、引述大乘論典中的「二藏教判」，指的就是《大智度論》，論中說：佛陀金口所宣說的法，依其語言文字可分為兩種，三藏是聲聞小乘法，摩訶衍則是大乘法，也就是菩薩藏。

【308-0006】02_戒疏/01b_卷一上之一#36
【原文】【疏】昔立化行及制聽者，非無其言，言須憑據，本據莫從，故不可用。
【譯文】【疏文】過去論師所安立的「化行二教」以及「制聽二教」等說法，雖然言之成理，但言談必須具備可信的憑據，既然根本依據無從尋得，因此是不應採信的。

【308-0007】02_戒疏/01b_卷一上之一#37

【譯文】【記文】在第三科之中。只破斥前兩家，因為第三家「化制二教」沿襲了前面的說法，其錯謬自然不攻自破。

【308-0008】02_戒疏/01b_卷一上之一#38
【原文】【疏】二、徵昔宗者。
【譯文】【疏文】第二道門徑、審核以往各家的宗見。

【308-0009】02_戒疏/01b_卷一上之一#39
【原文】【疏】初明化、行。化通道俗，名理無乖；行但出家，此則有濫。大聖垂教，實在依持，何但虗談，不存行用？故聞教悟道，無經不傳，豈偏戒律，局推行攝？
【譯文】【疏文】首先辨明「化行二教」。化教通行於道俗二眾，其名義與理體沒有相違之處；然而行教卻唯獨局限在出家人，這在概念上就產生了混淆泛濫。大聖佛陀垂慈宣說教法，核心實質在於依教奉持力行，哪裡只是空談義理而不顧修行實踐呢？所以聽聞經教而悟道的情形，沒有哪部經典不作此記載，又哪裡能夠將修行偏私地劃歸戒律，並將修行之名局限地推由行教來收攝呢？

【308-0010】02_戒疏/01b_卷一上之一#40
【原文】【記】次徵昔宗，化行中。初通示二教得失。「大」下，次別斥行教濫通。經論化教，亦明觀行，非局律宗，故無所取。
【譯文】【記文】在審核以往宗見、討論化行二教的段落中。起初總體開示這兩種教判的得失。從「大」以下，其次個別斥責行教的名義混淆泛濫。經論中的化教，同樣闡明了定慧觀行，並非戒律一宗所獨佔，因此行教之判不足採信。

【308-0011】02_戒疏/01b_卷一上之一#41
【原文】【疏】二徵制、聽。立教之本，義通為先，今唯在道，理如上責。就徵制教，唯約性罪，罪通道俗，不偏出家，如五、八戒，經論盛張。即遮通制，如俗戒相。此則雖彈前過，還漏昔非，如何分教混濫若此？
【譯文】【疏文】其次審核「制聽二教」。安立教判的根本，義理涵蓋的普遍通達應當放在最優先考慮，如今這種分法卻唯獨侷限在出家修道之人，其道理正如前面所斥責的那樣。退一步就制教來審核，若主張它唯獨針對「自性之罪」而設，但自性之罪通於出家與在俗二眾，並不偏局在出家人身上，比如在家人的五戒與八關齋戒，經論中都有極具規模的闡述。而且「遮戒」之中同樣通於制罪，就像在俗戒律的行相一樣。這樣看來，這家主張雖然彈劾了前人「名義泛濫」的過失，自己卻又墮入了往昔的偏狹錯誤之中，怎麼能把教判分得如此混亂混淆呢？

【308-0012】02_戒疏/01b_卷一上之一#42
【原文】【記】制聽中，初斥所立偏局，如前躡破。「就」下，次斥制名通濫。初難性戒濫俗，則制通經論。次難遮戒通制，則不當局性。「俗戒相」者，五戒後一，八戒後四。且舉俗證，道中亦爾。故知制名，不獨收性。「此」下，結斥。此師斥前行教通濫，自立制教，還復濫俗，故云「還漏」等。「漏」猶墮也。
【譯文】【記文】在討論制聽的段落中，起初斥責所安立的教門偏狹局限，如同前面所作的順勢破斥。從「就」以下，其次斥責制教之名混雜泛濫。先難問性戒通於在俗，如此則制戒應當通於經論二藏；接著難問遮戒同樣包含佛制之罪，就不應當把制教局限在性戒上。所謂「俗戒相」，指的是五戒的最後一條（不飲酒），以及八關齋戒的後四條。這且舉在俗之戒為證，在出家戒中也是如此。由此可知制教之名，絕不能只單獨收攝性戒。從「此」以下，結尾斥責。這位論師斥責前人行教名目通泛，自己安立制教，結果又回頭混濫了世俗，所以說「還漏昔非」。「漏」就是墮入的意思。

【原文】【疏】三舉化、制。因循昔言，聯類已窮，未可徵覈。
【譯文】【疏文】第三審視「化制二教」。這只是依循過去論師的說法，其邏輯推演的漏洞已經被窮究完畢，根本用不著再去仔細推敲審查了。

【308-0016】02_戒疏/01b_卷一上之一#46
【原文】【記】三、立正義，明所取中，初科。「順初宗」者，即三輪師。但後「憶念」立義未圓，故云「徵言未盡」。義見次科。
【譯文】【記文】在第三、確立正當合理的義旨，顯明所選取的立場中，此為第一科。所謂「順初宗」，指的就是以三輪來判教的論師。只不過後來對於「憶念輪」的立論義理尚不圓滿，所以說「徵言未盡」。其具體義理見於下一科。

【原文】【疏】但初二輪，創開化本，至於受道，其義不無。如律文中現通說法，因見聖迹，其量不少，豈在後輪方悟正理？
【譯文】【疏文】然而最初的神足輪與說法輪，雖然是用來初次開啟化導的端緒，但至於令眾生受教得道，律藏之中並非沒有這些內涵。如同律文之中記述佛陀示現神通與宣說正法，眾生因此親見聖道證果的記載，其數量著實不少，哪裡是一定要等到後面的憶念輪才能證悟正理呢？
