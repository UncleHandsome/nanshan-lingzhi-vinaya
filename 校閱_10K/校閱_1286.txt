# 校閱材料　第1286檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1286-0001】資持記/13d_下一#2
【原文】六師持律，尋序可見。至下，點古未詳。臨下，示今要旨。三中十門。初二及十，各局一門；三下七科，次第行事。制意中，初意，上二句徵問。生下，釋通又二，初約義定。以下，出所以。故下，引決。次意中，初義判。僧下，引示，《僧祇》。具云阿若多，此翻解本際，又云知無，知空無故。
【譯文】六位持律的大師，探尋他們的著述序文即可明瞭。從「至」字往下，點出古德的見解尚有不夠詳盡之處。從「臨」字往下，提示現今所要依循的宗要綱領。「三」字之中包含十個門類。第一、第二以及第十門，各自局限於特定的事相範疇；從第三門往下的七個科判，則是依序進行羯磨行事。在「制定意趣」中，第一個意趣的前兩句是提出詰問。從「生」字以下，解釋通釋又分為兩部分，首先依憑法理來判定。從「以」字往下，說明其中的緣由。從「故」字往下，引證權威定論。在第二個意趣中，首先依法理判斷。從「僧」字往下，引述《僧祇律》作指示。「阿若多」完整地說，此處翻譯為「理解本際」，又稱作「了知空無」，因為他體悟空性與無我的緣故。

【1286-0002】資持記/13d_下一#3
【原文】憍陳如，此云火器，其先事火故。《十誦》，初引緣起。跋難陀，此云歡喜。剎利種，即諸釋種王子。次引佛判，初明不屬王親。僧下，次明唯屬於僧。分法十種，隨難釋之。二中。學悔可解。被擯即擯出，非滅擯也。守戒即清淨。此三同處，隨有死者，存者取之。三中。云中道死，謂往而未達。四中。
【譯文】「憍陳如」，此處翻譯為「火器」，因為他的祖先曾事奉火神的緣故。《十誦律》中，首先引述制戒的緣起。「跋難陀」，此處翻譯為「歡喜」。「剎帝利種」，指的就是諸位釋迦族的王子。接著引述佛陀的判決，首先闡明亡僧之物不屬於國王及親屬。從「僧」字往下，接著闡明唯獨歸屬於僧團。分配的方法共有十種，隨後針對難懂之處加以解釋。在第二種方法中，「學悔」之義容易理解。「被擯」指的是被暫時驅逐擯出，並非永遠斷絕僧籍的「滅擯」。「守戒」就是身心清淨。這三種人若身處同處，隨逢有人去世，在世的存者便可取得其遺物。在第三種方法中，所說「死於半途」，指的是前往某處而尚未抵達之時。在第四種方法中。

【1286-0003】資持記/13d_下一#4
【原文】被舉即三舉，唯本作法者得之。五中。二部，謂僧尼也。第六。單就一眾。彼論：有一比丘持衣鉢向彼寺，未至，在二界中間死；佛言，隨所去處僧得，若不知去處，隨面向處僧得。第七初引文。謂下，次釋。恐謂一向入和尚故。注中，上文引證。既同比丘，故知入僧。莫下，義決。
【譯文】「被舉」指的是遭受三種舉罪羯磨，遺物唯有當初參與作法舉罪的僧眾才能獲得。在第五種方法中，「二部」指的就是比丘與比丘尼二部僧團。第六種方法，單就其中一個僧眾群體而論。該論記載：有一位比丘帶著衣缽前往某寺院，尚未抵達，就在兩個結界的邊界之間圓寂；佛陀判定，隨其原本要去之處的僧眾獲得遺物，如果不知道他要去何處，則隨其面容朝向之處的僧眾獲得。第七種方法首先引述律文。從「謂」字往下，接著進行解釋，這是唯恐他人以為遺物一概歸入剃度和尚手中。註解之中，上文引出經據作為證明。既然與一般比丘同等對待，因此可知應當歸入大眾僧中。從「莫」字往下，依義理作出斷決。

【1286-0004】資持記/13d_下一#5
【原文】第八入俗，僧無分義。九中引《十誦》，初緣起。有比丘即牟羅比丘，能寄人即牟羅，所寄即阿難本居處，物處是阿難受寄處。下明佛判。十中，上二句簡前。直爾分者，謂隨於本界據現而分，不作羯磨。下二句正示。即後所明。對前一三五六九，故云一和；
【譯文】第八種是遺物歸入俗人，僧眾便沒有分得其遺物的法理依據。第九種情況引述《十誦律》，首先陳述緣起。「有比丘」指的是牟羅比丘，「能寄人」也是牟羅，「所寄處」即是阿難原本的居所，「物處」則是阿難受寄處。下文闡明佛陀的判決。第十種情況中，前兩句是用來簡別前面的情況。所謂「直接分配」，指的是直接在所屬的結界內，根據當前現前僧眾的狀況進行分配，並不另外舉行羯磨法。後兩句才是正面的指示，也就是後文所闡明的事理。對照前面的第一、第三、第五、第六、第九種情況，所以說「和合一致」；

【1286-0005】資持記/13d_下一#6
【原文】對前二四七八，故云清眾。前九竝是直分，故云方入。〔舊云前九直爾者，望一期攝入為言；若細推之，約攝歸後，須作法分；公違正言，其謬甚矣。〕同活中，初科，易解。同生，生亦活也。假冐，謂虛誑也。二中，初敘本契。此下，示分法。任清多少，謂餘財也。
【譯文】對照前面的第二、第四、第七、第八種情況，所以說「僧眾清淨」。前九種情況全都是直接分配，所以說「方能進入」。〔過去有說法認為前九種直接分配，是就一期的總攝歸納而言；如果仔細推究，若要收攝歸入後面的常規，仍必須透過作法來分配；這樣的主張公然違背經律正文，其謬誤非常嚴重。〕在「共同生活」的科判中，第一科容易理解。「同生」，「生」也是指活著共同生活。「假冒」，指的是虛妄誑詐。在第二科中，首先敘述原本約定的契約。從「此」字往下，說明分配之法。「任清（情）多少」，指的是任憑請取剩餘財物的多少。

【1286-0006】資持記/13d_下一#7
【原文】隨身服用，即亡者物也。三中，初立契。別活返道，謂本立要，預約後事。若下，分法。言準俗者，俗法爾故。已用服器未須分者，各屬定故。言依式者，即準俗法。四中。云能所，能即眾主輒斷，所謂妄取物者。下指《善生》兩斷，即夷蘭也。上約重輕二物，經中唯就輕物，但望羯磨前後分之。
【譯文】「隨身服用」，指的就是亡者生前的個人用品。在第三個科中，首先確立約定契約。「各自分開生活或反俗還道」，指的是原本就立下要約，預先約定日後之事。從「若」字往下，說明分配之法。所說「比照世俗法」，是因為世俗的法規原本就是如此。「已經使用過的器物衣物暫時不須分配」，是因為所有權各自確定之故。所說「依循式樣法度」，指的就是依照世俗法規辦理。在第四個科中。所稱「能處分與所處分」，「能」指的是僧中主事者擅自判定處分，「所」指的就是妄取財物的人。其下指出《善生經》中的兩處斷決，指的就是波羅夷與偷蘭遮二罪。以上是就重物與輕物兩類而言，經文中單單針對輕物，只是看是在羯磨前還是羯磨後予以分配。

【1286-0007】資持記/13d_下一#8
【原文】囑授中，初科四句，初中。順初受者，以受戒時稟四依故。生福即現因。上處期後報，謂善道也。三中。篤猶極也。此身未得無漏聖道，故云空無無漏。勸囑謂他人相勉。增字寫誤，合作憎；或與不與，心不等故。前業謂向前所作福業，或修聖道。佛誠斷者，判歸僧故。
【譯文】在「付託交代」的科判中，第一科有四句，首先在第一句中。「順應最初受戒之時」，是因為受具足戒時曾稟受「四依止」的教導。「生起福報」指的是現世的福因。「在上位處祈求後世善果」，指的就是善趣人天。在第三句中。「篤」就像是極甚的意思。此身尚未證得無漏聖道，所以說是「空無無漏功德」。「勸導付託」指的是他人互相勉勵勸告。「增」字是傳抄寫錯，應當作「憎恨」之「憎」；在給予或不給予之間，內心有所偏頗不平等。「前業」指的是先前所修作的福德善業，或是修習聖道之業。所謂「佛陀至誠斷決」，是判定歸屬於僧團常住。

【1286-0008】資持記/13d_下一#9
【原文】四中，初示相。慳施二心起滅不常，故云展轉。後引事證。二緣竝出《五百問論》。彼云：昔有比丘念著銅椀；僧分物時，便來求椀，僧遂還之，舌舐放地，臭不可用等；又有比丘喜樂衣服，因病致死，後化為蛇來纏衣等。銅椀見〈瞻病篇〉，慳衣在〈對施篇〉。
【譯文】在第四句中，首先指出心理形相。慳吝與布施這兩種心念生起與息滅無常不定，所以稱為「展轉交替」。其後引用事例作證。這兩個因緣都出自《五百問論》。該論記載：從前有一位比丘心念執著於銅碗；當僧團分配遺物時，他的鬼神便來索求銅碗，僧團於是還給他，他用舌頭舔舐後放置地上，臭穢得無法使用等等；又有比丘極為喜愛衣服，因病過世後，轉化為一條蛇來纏繞其衣物等等。銅碗的公案見於〈瞻病篇〉，慳貪衣服的公案見於〈對施篇〉。
