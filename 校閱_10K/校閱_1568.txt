# 校閱材料　第1568檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？

# 材料開始

【1568-0001】03_業疏/01b_卷一之一#8
【原文】次科初標古示名。《百論》但翻為「事」，相傳加字助之，《事鈔》猶存此翻。問：「前云成濟前務等，豈非辨事？今古那分？」答：「前以『業』翻名，以功能釋義；今此直以功能翻名，於義頗疎，故所不取。」「然」下依名釋義，文有兩段：前通約諸法釋，食即是藥，人謂差舉，法即說恣，夷，平也；「又」下次別約二法釋，「量同太虗」，法體廣徧故；「共佛齊位」，功德高深故。言「生報」者，凡報有三：一現報，二生報，三後報。犯重歲數出《目連問罪報經》，彼云「犯波羅夷罪，如他化自在天壽十六千歲，墮泥黎中，於人間數如文所引」，彼經不定獄名，此準《僧祇》云墮阿鼻。《經音義》云：「阿鼻翻為無間，一身無間，二苦無間。」學者多迷生善滅惡二事，請考此文，足為明據
【譯文】下一科中，起初標明古師說法並開示其名稱。《百論》中只翻譯為「事」，後世相傳加上一個「辦」字來輔助它，《行事鈔》中還保留著這種翻譯。有人問：「前面說成辦濟度當前事務等，難道不就是辦事嗎？古譯與今譯該如何區分？」回答說：「前面是以『業』來翻譯名稱，而用功能來解釋其含義；現在這裡古譯直接拿功能來當作名稱翻譯，在義理上顯得相當疏略，所以不予採納。」自「然」字以下依照名稱解釋義理，文段有兩層：前半段通括約取各種法來解釋，「食」就是指醫藥，「人」指差派推舉知事，「法」指說戒自恣，「夷」是平定的意思；自「又」字以下，接著特別就兩種根本大法（受戒與懺重）來解釋：「量同太虛」，是因為戒法之體廣大遍周的緣故；「共佛齊位」，是因為受戒功德崇高深邃的緣故。所說的「生報」，大凡果報有三種：一是現報，二是生報（來生受報），三是後報（第三生以後受報）。犯重罪應受地獄苦報的年歲數目出自《目連問罪報經》，經中說「凡犯波羅夷罪者，如他化自在天壽命一萬六千歲之長墮於泥梨地獄中，折算為人間的歲數即如文中所引之數」，彼經沒有確定地獄名號，此處依據《僧祇律》說是墮入阿鼻地獄。《經音義》說：「阿鼻翻譯為無間，一是身無間，二是受苦無間。」後世學者多對生善、滅惡這兩大事義理感到迷茫，請考究此文，足可作為明晰的依據。

【譯文】在簡別辨析之中，第一段文首先敘述漢語詞義容易通混泛濫。所謂「業義通」，例如身口七支業、十善業、福業、非福業、不動業等，並不局限於出家修道的緣故。名詞涵義既然相通，必定會產生疑惑與混淆，所以說「謂此」等。自「故」字以下，正式說明保留梵語音譯的原因，是為了簡別混淆、遮止疑慮，並且能令人對僧法生起恭敬善心的緣故。

【原文】自古諸師依法出體，但廣明非，翻非如法。今不同之，律有正體，無宜不立，故異由來所述法義。就門分二
【譯文】自古以來各位法師依據律法來判定法體，大多只是廣泛說明非法的羯磨，再以反轉非法來作為「如法」的體。如今我不贊同這種做法，律藏中本有正當的體性，沒有理由不予確立，所以不同於歷來所闡述的法義。在這一門中分為兩部分：

【1568-0010】03_業疏/01b_卷一之一#17
【原文】次定體相敘古中，「依法」者，法即羯磨，謂依律中七非羯磨辨示非體，以非顯如，如即法體，如後七非顯體中明。「今不同」者，律有三法，即法是體，何須別求？反驗古解，總有二過：一律既有體，不當強立；二翻律七非，但偏眾法，不收對、念。反上二過，故云「異」也
【譯文】在接下來的「定體相」中敘述古師觀點部分：所謂「依法」，「法」就是指羯磨，是指依循律中所說的「七非羯磨」來辨析指出非法的體相，以非法來反顯如法，認為如法就是法體，如後文在「七非顯體」中所闡述的。所謂「今不同之」，是律藏中原本就載有心念、對首、眾法這三種羯磨法，這三法本身就是體，何須另外旁求？反觀考證古師的解釋，總共有兩種過失：第一，律中既然已有正體，就不應當勉強另立；第二，反轉律中的七種非法，只偏限於僧眾法，不能收攝對首法與心念法。為了糾正反轉上述兩種過失，所以說「異於由來」。

【1568-0012】03_業疏/01b_卷一之一#19

【1568-0013】03_業疏/01b_卷一之一#20
【原文】約論中，初遮簡。「緣通內外」者，即有情、非情也，人唯局內，法、處局外，事通內外。緣相既多，從緣定體，體則不一，故云「繁」也。如上古師翻非明體，則涉諸緣，故特點之。「今」下正示，「剋相」謂定約所秉言教，「聲相」簡餘塵，「相續」簡一念，「善色」簡惡無記，聲是不可見有對色故。上約能被示體，「若」下指所發如後，「量」即體量，《戒業章》見《受戒篇》。問：「相續善色與作何異？」答：「尋後相比，自可通之
【譯文】在依論立體的辨析中，首先是遮除簡別。所謂「緣通內外」，就是指有情眾生與非情境界；人只局限於內在有情，法與處所局限於外在非情，而所辦之事則通於內外兩者。因緣的相狀既然極多，若順從眾緣來判定法體，法體就會紛雜不一，所以說是「繁」。如同前述古師以反轉非法來顯明法體，就牽涉到了各種因緣，所以特別指明這一點。自「今」字以下正式開示：所謂「剋相」，是指嚴格限定於所秉持的言教；「聲相」簡別了色、香、味、觸等其餘塵境；「相續」簡別了短暫單一的念頭；「善色」簡別了惡性與無記性，因為音聲是屬於「不可見有對色」之故。以上是就「能加被」的角度來顯明法體；自「若」字以下，則指歸其所引發的業體詳如後述，「量」就是指法體的形量，〈戒業章〉見於後面的〈諸戒受法篇〉。有人問：「此處相續的善色與作戒體有何不同？」回答說：「仔細尋繹後文進行對比，自然便能通達解了。」
