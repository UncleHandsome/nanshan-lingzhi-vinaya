# 校閱材料　第300檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【300-0001】02_戒疏/01a_卷一上之一#34
【原文】【疏】元魏季曆，慧光律師隨義約文，重出一本，首題「歸敬」者是也。此與姚秦覺明所出，頗得相符。
【譯文】【疏文】北魏末年，慧光律師依照法義約束文字，重新推出一部版本，卷首題寫「歸敬」之名者便是此本。這個版本與姚秦時期覺明所翻譯的內容，大體相當吻合。

【300-0002】02_戒疏/01a_卷一上之一#35
【原文】【記】光師本中。「元魏」即東魏元氏，簡曹魏、西魏。「季曆」即末年也。光師撰廣律疏，《羯磨》、《戒本》咸加刪定。「題歸敬」者，即「稽首」一偈。「此」下，舉前比校，大同小異，故曰「相符」。
【譯文】【記文】慧光律師版本這部分。「元魏」即是指東魏元氏，用以簡別三國的曹魏與後來的西魏。「季曆」就是末年的意思。慧光律師曾撰寫《廣律疏》，對於《羯磨》與《戒本》都予以刪減定正。「題歸敬」是指卷首冠有「稽首禮諸佛」這一首偈頌。「此」字以下，舉出前代版本互相校對，大體相同而有細微差異，因此說「相符」。

【300-0003】02_戒疏/01a_卷一上之一#36
【原文】【疏】高齊末祀，法願律師誦律計文，又出一本，略於「歸敬」，首題「戒德」者是也。
【譯文】【疏文】北齊末年，法願律師背誦律本、核計文句，又推出了一種版本，省略了「歸敬」偈頌，卷首題寫「戒德」之名者便是此本。

【300-0004】02_戒疏/01a_卷一上之一#37
【原文】【記】願師本中。「高齊」即北齊高氏，簡南齊故。「祀」亦年也。四律皆製義疏，至於《戒本》，復加纂集。「題戒德」者，直云「戒如海無涯」等。
【譯文】【記文】法願律師版本這部分。「高齊」即是指北齊高氏王朝，是為了區別南朝的蕭齊。「祀」也是年份的意思。法願律師對於四部廣律都曾撰著義疏，至於《戒本》，亦重新加以輯錄編纂。「題戒德」是指開頭直接寫作「戒如海無涯」等偈語。

【300-0005】02_戒疏/01a_卷一上之一#38
【原文】【記】二師德業，並見《僧傳》。又唐懷素律師，亦出《戒本》，見存大藏。
【譯文】【記文】這兩位大師的德行與功業，都記載在《高僧傳》中。此外，唐代懷素律師也曾輯出一部《戒本》，至今仍保存在大藏經內。

【300-0006】02_戒疏/01a_卷一上之一#39
【原文】【疏】斯則三本行世，弘魏者多。見心紛擾，于今未靜。考覈諸集，蓋不足陳；經遠大觀，義無讎抗。
【譯文】【疏文】這便是三種戒本法本通行於世間，弘傳北魏慧光本的人居多。門派見解的紛紛擾擾，直到今日依然未見平息。考察核實各家集的內容，實則大多不值一提；若以久遠修學的宏大眼界觀之，法義本質上根本沒有難以並立的對立抗衡。

【300-0007】02_戒疏/01a_卷一上之一#40
【原文】【記】結顯中。初明弘傳多寡；「見心」下，示宗黨諍競；「考覈」下，明讎校是非。「不足陳」者，言其所諍非要當也。「無讎抗」者，言其大槩無勝劣也。故《刪定戒．序》云：「如光所詮『我今說戒』，願之所出云『說木叉』，及披律解，『木叉戒』也。願出初戒，則云『不還』，光所傳詞，便言『不捨』，撿律誠釋，違願附光。取意統文，莫非還淨。如斯舉例，其相可知。」舉彼照此，文意可見。「蓋」，略也。學久謂之「經遠」。舍其小碎，求其梗槩，謂之「大觀」。「讎抗」，猶對敵也。
【譯文】【記文】總結顯發這部分。開頭說明弘揚傳播人數的多寡；「見心」以下，指出宗派門徒的諍執抗衡；「考覈」以下，說明校勘是非的結果。「不足陳」是指眾人所爭辯的細節並非要緊切中之處。「無讎抗」是指兩者大體而言沒有絕對的高下優劣。因此《刪定戒本序》中說：「如同慧光本所表述的文句是『我今說戒』，法願所出的本子則寫為『說木叉』，等到翻閱廣律的解釋，原文乃是『木叉戒』。法願本列出第一條戒時，文字是『不還』，慧光傳授的文詞，則說是『不捨』，檢視廣律確鑿的解釋，法願有違原意而慧光符合律意。但若取其核心深意來總覽經文，無一不是為了回歸清淨。如此列舉的種種情況，其爭論的面貌便可想而知。」拿那篇序文來對照此處，本處的文字意涵便清晰可見了。「蓋」是概略的意思。修學久長稱作「經遠」。捨棄瑣碎的細枝末節，探求大綱梗概，稱作「大觀」。「讎抗」猶如彼此對壘對抗。

【300-0008】02_戒疏/01a_卷一上之一#41
【原文】【疏】余以暇日，徧覽群篇。互擊波瀾，僅分其異；至於行事，盛結遲疑。豈非單寫本文，通略正解，致令後銳，罔冐愈深。
【譯文】【疏文】我在日常修持之餘的閒暇日子裡，普遍閱覽了各家論卷。見其互相激盪起辭鋒波瀾，不過僅僅分辨出字面差異而已；至於涉及具體的持犯實務，反而大幅積累了遲疑難決之困。難道這不是因為僅僅單純抄寫本文，一概略去了正統的法義解釋，以致使得後世精進勇銳的求學者，迷惘盲從的程度日益加深。

【300-0009】02_戒疏/01a_卷一上之一#42
【原文】【記】今本，明注中，初科。初示諸本之失；「豈非」下，次明失之所以。「暇日」謂正業之餘。「群篇」即前列諸本。「波瀾」喻彼此相攻，大波謂之「瀾」。「僅」，猶略也。「至於」下，正陳失相。夫戒本列相，為指行途，使犯相精明，持心易就。豈得競網目之大小，全迷得魚；諍標指之短長，都忘視月？且學律而不明行事，猶窮《易》而未識陰陽，竭慮封文，畢身何益？寄言後學，宜自深思。此乃三行之宏綱，一宗之大要。苟明此意，方體教源，則展卷臨文，渙然無滯矣！「事」有二種，止、作兩殊。止則離非，作唯營善，行斯二者，即成二持。此中所云，即止持事也。明所以中，上二句，顯古無注釋，明自失也；下二句，明因上自失，而致迷他也。「通」猶俱也，或指諸本，或約一本始終為言。
【譯文】【記文】說明今本註解（明注）這部分，是第一小節。開頭指出諸多版本的過失；「豈非」以下，接著說明造成過失的原因。「暇日」指日常功課修持之餘的閒暇時間。「群篇」就是指前面所列舉的諸家版本。「波瀾」比喻各版本之間互相駁難排擠，大波浪稱為「瀾」。「僅」猶如略微的意思。「至於」以下，正式陳述過失的相狀。戒本列出各條犯相，是為了指出實踐修行的道路，使人對犯相明白透徹，持戒之心易於成就。哪裡能夠只顧爭競魚網格目的大小，卻完全忘失了捕得游魚的目的；爭論所指手指的長短，卻徹底忘記了看見明月？況且修學律藏卻不明瞭戒律行事，猶如窮研《易經》卻不懂得陰陽變化，耗竭思慮固執於字句文面，終其一生又有何利益？寄語後世的修學者，應當對此深深自省。這乃是南山律三行（眾行、自行、共行）的宏大綱領，一整部律宗的至要所在。如果能明白這個旨趣，方能領會教化的根源，那麼展開卷冊面對經文時，便能渙然冰釋、毫無滯礙了！戒律中的「行事」有兩種，止持與作持各不相同。止持是遠離過非，作持專在經營善行，修行這兩方面，就成就了止、作二持。此處所說的行事，即是指止持這件事。在說明原因之中，上面兩句彰顯古德缺乏註解，說明了古德自身的缺失；下面兩句說明由於上述自身的缺失，進而導致迷惑誤導了他人。「通」猶如一概的意思，有的指涵括諸家版本，有的指一部版本從始至終的情況。

【300-0013】02_戒疏/01a_卷一上之一#46
【原文】【疏】所以敢依律部，具集正經；仍隨本律，即為注述。卷成流廣，隨務可歸。至於義理，未遑修葺。
【譯文】【疏文】因此我大膽地依傍律典文部，完整輯錄這部正統經文；隨即順沿原本的廣律內容，就地為其撰作註解闡述。經卷編撰告成並廣泛流通，使行人在隨順實務之際皆有所歸依準則。至於更為深細的微言義理，則尚未顧得上著手修整編纂。
