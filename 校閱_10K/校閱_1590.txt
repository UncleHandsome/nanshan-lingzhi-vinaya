# 校閱材料　第1590檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1590-0001】03_業疏/02b_卷一之二#137
【原文】對首中，初分通局，七通心念自屬初位，五通僧別眾法對首也，餘必對人即諸但對也。「至」下次釋兩通，言通僧者，中法行大事也；通心念者，中事開下法也。前云「中猶通」者，即其義焉
【譯文】在對首羯磨中，起初分別通與局，七種通心念自然歸屬於第一位，五種通僧別是眾法對首，其餘必定面對他人就是各種但對首法。自「至」字以下次解釋兩種相通，說通於僧法，是指用中等之法行辦大僧之事；通於心念，是指中等之事開許用下等心念法。前面所說的「中等即能通」，就是這個意思。

【1590-0002】03_業疏/02b_卷一之二#138
【原文】就眾法羯磨一百三十四法中，一法被一事，各互不相通，如差人問難，不與白召同；多法成一事，則有相通義，如受戒一也，三白一白四方得成無作也。統就眾緣，結界畜眾必須相有。白二中七結界法不得重加，唯局自然，不通作法；餘白二及單白、白四，反上可知
【譯文】在眾法羯磨一百三十四種法中，一種法被及一件事，彼此互不相通，例如差人問遮難的白二，與白召受戒人入眾的單白不同；若是多種法成就一件事，則有互相連通的意義，例如受戒這一件事，需要三種單白與一種白四才能成就無作戒體。總括各項助緣來看，結界與蓄眾必須相輔具足。白二羯磨中的七種結界法不能重複加結，只局限於自然界，不通於作法界；其餘的白二以及單白、白四，反照上述情況即可得知。

【1590-0003】03_業疏/02b_卷一之二#139
【原文】眾法中初示總數。「一」下顯通塞：初通論三法。今明事者，須分二途：一就通簡別，如一受戒四法各被；二攝別歸總，如受四緣通成一受，今文約此以分通塞，據本各被，約義明通。「統就眾緣」者，如欲行受地，或自然須先結界，和尚度人須乞畜眾，皆可攬歸受戒，以彰多法成一之義，自恣、捨墮、罰鉢、亡衣竝有斯義，臨文自舉。「白二」下別簡白二，七結不重是塞，餘竝法地為通，故云反上
【譯文】眾法之中起初列示總數。自「一」字以下顯明通塞：起初通論三種法。如今說明辦事，必須區分兩條途徑：一是就整體通相中簡別個別之法，如一場受戒中四種羯磨各自被及不同環節；二是攝受各別之法歸於總體，如受戒的四項法緣通力成就一場受戒，現在文中是依據後者來劃分通塞，按原本而言各有所被及，依義理而言則顯明其相通。「統就眾緣」的意思，例如若要在受戒處行法，若在自然界必須先結界，和尚度人必須乞求蓄眾，這些都可以收攝歸入受戒，用以彰顯多種法成就一事的意義，自恣、懺捨墮、罰乞鉢、分亡僧衣物都具有這種意義，臨到具體律文自會列舉。自「白二」以下特別甄別白二羯磨，七種結界法不可重結是閉塞不通，其餘都以作法界為通，所以說反照上述可知。

【1590-0006】03_業疏/02b_卷一之二#142
【原文】就人而論：一人心念，自秉口言，是當分也；設通上二，是傍非正，必界有人，豈得獨作。眾多對首，為前證境，必是通情告事，相領方能成遂；雖通眾法，亦是開位。四人成僧，勝用非一，約事乃三，宗歸初位，過則彌勝，若減非法
【譯文】就僧人而論：一人心念羯磨，自己秉持並口中陳說，這是其當分正法；假使通於上面兩種，也是傍通而非正途，界內若有人在，豈能單獨作法？多人對首，是作為對面作證的境界，必須是彼此通達情意、陳告其事，互相領解方能成辦遂心；雖然也通於眾法，但也是開許的位次。四人成立僧團，殊勝作用不止一種，按事相來說分為三種，其宗旨都歸於最初的四人僧位，人數超過四人則更為殊勝，若是短少則構成非法。

【1590-0008】03_業疏/02b_卷一之二#144
