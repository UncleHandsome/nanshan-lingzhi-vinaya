## 一、需要修改的問題

### 1.【774-0008】「時中／非時」誤解為「時食／非時食」── 最嚴重

> 原文：九中「作衣」、「衣時」，唯在**時**中，不通**非時**。餘七通時、非時。
> 現譯：只限於**正當的受食時間**，不通於**非時受食**。其餘七種則通於正當時間與非時受食。

這裡的「時」承上文「衣時則一月、五月」而來，指的是**衣時（迦提月，或受功德衣後的五個月）之內／之外**，不是「過午不食」的時食／非時食。理由有二：
- 別眾食戒本來就只在時食中論，不可能說「餘七通非時（食）」；
- 「作衣」「衣時」二緣正是與衣時綁定的，故說唯在時中。

**建議**：「九種開緣中，『作衣』與『衣時』這兩項只限於衣時（受功德衣或迦提月）之內，不通於非衣時；其餘七種則衣時、非衣時都通。」

### 2.【774-0007】《鈔》譯成《行事鈔》，與下一則《記》自相矛盾

> 原文：餘如《鈔》解。 → 現譯：如同《**行事鈔**》所解釋。
> 但【774-0008】《記》明說：「『餘』下，即指 **《義鈔》**。」

元照特別點出此處《鈔》指《義鈔》（《拾毘尼義鈔》），譯文卻判為《行事鈔》，前後打架。
**建議**：「其餘如《鈔》（即《義鈔》）所解。」或直接作《義鈔》並加註。

### 3.【774-0002】「終無異計」譯成「分裂僧團的異心」── 過度引申

「異計」只是「別的打算／他心」，此處指病者自救尚且無暇，不會另有別眾乖離的心思。**「分裂僧團」是破僧（五逆）**，與別眾食輕重懸殊。
**建議**：「自己救護都來不及了，終究不會另生其他（別眾乖離的）念頭。」

### 4.【774-0002】「不開送食」語意方向可疑

> 現譯：食物少而人數多，**又不開許分送食物外出**。

整段是逐條說明「**為什麼要開**」（病→無由濟命；作衣→恐廢正業；施衣→後須難得……），此句若譯成「不開許送食」，變成在陈述禁止，與行文邏輯相反。依文勢應是省略句：「（若）不開（別），（則）送食（不濟）」——村落小、食少人多，若不開別眾食，施主之食無法分送周供。
**建議**：改作「若不開許（別眾食），就無法分送食物普供大眾」，並請覆核後文《記》對「大眾集」的釋文再定。

### 5.【774-0010】與【774-0011】「和先六十」講法不一致

- #0010：「和先比丘**等**六十位頭陀」（共六十）
- #0011：「和先比丘**帶著**六十位修頭陀行的僧人」（共六十一）

同一典故兩譯法不同，應統一。原文「和先六十」「和先比丘六十頭陀至」本身可兩解，建議採中性譯法：「和先比丘與六十位頭陀比丘」，兩處一致。

## 二、可斟酌與體例問題

| 出處 | 問題 | 建議 |
|---|---|---|
| 0001、0007 | 「戒本**經文**」「**經文**說」——戒本屬律藏，非經 | 改「戒本（律）文」「律文說」 |
| 0001 | 「戒本經文的六個文句，對照經文即可理解」略嫌循環 | 「戒本此戒共六句，對照上文即可了解」 |
| 0002 | 「衣時**通給**」譯「普遍發給」易誤讀為發衣服 | 「（此開利）普遍給予大眾，為補償夏安居的辛勞」 |
| 0002 | 「其他沙門布施」易誤讀為其他佛教比丘 | 此「沙門」通指外道出家者，宜作「（外道）沙門施食」 |
| 0002 | 「自濟形苦」加譯「**寒**苦」 | 去「寒」，作「缺衣形體之苦」較穩 |
| 0003 | 「九種**相貌**」；「隨相顯其**制意**」 | 「九項（九種情形）」；此處是開緣，宜作「開許之意」 |
| 0005 | 「不**簡**名行」譯「不苛求」 | 「不揀擇（受請者的）名聲與德行」較確 |
| 0005 | 「如飲大海」加譯「**一滴**」 | 原文無「一滴」，屬解釋性增字，宜刪或加括號 |
| 0005 | 「亦無別過」譯「沒有脫離大眾的過失」 | 術語宜保留：「也無別眾（食）之過」 |
| 0009 | 「食足四人」譯「受食者滿四人」 | 依下文「百−三＝九十七」的算法可通，但「足」字面亦可讀「食物僅足四人」，建議保留原句並加註兩解 |
| 0009 | 「為患」逕譯「犯戒之患」 | 《疏》此處僅引文，二解在後；可先作中性「便成為問題（患）」，或註明依初解為犯患 |
| 0011 | 「入室禪寂」加譯「**密**室」 | 去「密」，作「進入室內禪坐靜修」 |
| 0011 | 「唯除一供養人」整句未白話 | 「只除一位送食供養的人之外」 |
| 全篇 | 「別眾食」時譯「私下個別進食」「私下受食」 | 建議統一保留術語「別眾食」，必要時首次加註「離開大眾而個別受食」 |
| 0012 | 「食無陪供」譯「食物無法供應充足」 | 更貼切：「食物沒有多餘可供（增添的人）」 |

## 三、譯得妥當、無須更動者

- 0004 七緣出本律、二開出《五分》《多論》——正確。
- 0006 問意、0007「下至一縫」——正確。
- 0008「時內不作，於義未顯」、施衣／作衣「彼此有益／更無勝利」——理解到位。
- 0010「應云九十七人為患」「長之名義同故云一」——算理與會通皆正確。
- 0011「世尊**聽**見」譯「准許晉見」、「以一**目**多」譯「用『一位』指稱多數」——關鍵字訓解無誤。
- 0012 八人大眾／七人以下小眾、《多論》證不開——正確。

**總結**：主要須改的是 #0008「時／非時」的誤判、#0007《鈔》的書名歸屬、#0002「異計」與「不開送食」兩處；其餘多為增字、術語統一與前後一致性的小問題。
