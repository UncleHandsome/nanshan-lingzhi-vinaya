# 校閱材料　第544檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【544-0001】02_戒疏/09b_卷二下之二#30
【原文】【疏】問：「僧尼俱觸，而罪有輕重，二人俱宿，而罪無階降者？」
【譯文】【疏文】提問：「比丘與比丘尼若同樣觸碰異性，罪責有輕有重；比丘與比丘尼二人若同樣犯同宿戒，罪名卻沒有差別，這是為什麼？」

【544-0002】02_戒疏/09b_卷二下之二#31
【原文】【疏】答：「觸對為言，陵不陵別，故夷、殘。宿中懸對，譏義是同，故俱提也。」
【譯文】【疏文】回答：「從肢體觸對來說，侵凌與被侵凌的情形不同，所以分別定為波羅夷（斷頭罪）與僧殘罪。而同宿是預先懸置的防護，受譏嫌的性質相同，所以都結為波逸提罪。」

【544-0003】02_戒疏/09b_卷二下之二#32
【原文】【記】輕重中。問意，以二眾觸、宿結犯不等故。答中，上明觸別，下示宿同。未即有譏，先防而制，故云「懸對」。
【譯文】【記文】辨析輕重之中。提問的意圖，是因為二眾在摩觸與同宿兩事上，定罪輕重不均等。回答之中，前段說明摩觸各有差別，後段指明同宿情狀相同。事情尚未立即引來譏嫌，先作防範而行禁制，所以稱為「預先懸對」。

【544-0004】02_戒疏/09b_卷二下之二#33
【原文】【疏】「若爾，如尼受染心衣食、共男入室，譏義不殊，何為階降？」答：「染心衣食，深防重罪，故重。共入闇室，當相譏疑，故輕。故非決也。」
【譯文】【疏文】「如果是這樣，比丘尼接受染心男子的衣食，與比丘尼共男子進入暗室，受譏嫌的性質並無差別，為何罪名有層級高低？」回答：「接受染心男子的衣食，是為深切防範大淫罪，所以罪責極重。共同進入暗室，只在此事相上受到譏嫌懷疑，所以罪責較輕。因此兩者不能硬性相比照。」

【544-0005】02_戒疏/09b_卷二下之二#34
【原文】【記】轉難中。「受染心衣食」犯殘，「共男入暗室」結提。此引尼戒，難前同宿，譏同罪等。答中，初明染心，不就譏論，故異。次明入室從譏，故同。異上「懸對」，故云「當相」。制緣既異，不可相決，故云「非」也。或可「決」合作「例」。
【譯文】【記文】轉進詰難之中。「接受染心男子的衣食」犯僧殘罪，「與男子共同進入暗室」結波逸提罪。這是引用比丘尼戒，來反問前面同宿譏嫌相同而罪責相等的說法。回答之中，首先說明染心受施不是單純就譏嫌來論斷，所以有差別。接著說明共入暗室是依循譏嫌定罪，所以情節相同。這與前面的「預先防對」不同，所以稱為「當下事相」。制戒的因緣既然不同，就不能相互套用判定，所以說「不能決斷」。或者「決」字應作「例（比照）」。

【544-0006】02_戒疏/09b_卷二下之二#35
【原文】【疏】言離合者，有人問曰：「九十制坐，則尼女分戒，十三明觸，則道俗同罪者何？」
【譯文】【疏文】所謂條文的分合，有人問道：「在九十條波逸提中規定同坐，僧尼與俗女分別立戒；而在十三僧殘中說明摩觸，為何觸碰出家女與世俗女卻結同樣的罪？」

【544-0007】02_戒疏/09b_卷二下之二#36
【原文】【記】離合中，問意，可解。
【譯文】【記文】分合之中，提問的意旨，可以理解。

【544-0008】02_戒疏/09b_卷二下之二#37
【原文】【疏】昔齊大德隱律師曰：「結罪便故，所以合之。若對比丘，二女俱殘，若對於尼，二男俱重，故不分戒。九十須離者，僧對二女俱提，理應須合，但結尼罪則道俗輕重不同，故使離之。」
【譯文】【疏文】過去北齊高僧曇隱律師說：「為了結罪判定簡便的緣故，所以合併立戒。如果對比丘而言，觸碰二種女人（尼與俗女）都犯僧殘；如果對比丘尼而言，觸碰二種男人（僧與俗男）都犯重罪，因此不用拆開立戒。九十條中必須分開的原因，是比丘對二種女人同坐都結波逸提，按理應當合併，但若結比丘尼的罪，則對僧與對俗人的輕重不同，所以讓它們分開立戒。」

【544-0009】02_戒疏/09b_卷二下之二#38
【原文】【記】釋中，初科。初總示，即高齊曇隱，依光師學律，撰《鈔》四卷，今用彼文。「若」下，別釋。初明觸合，僧尼二觸，並合制故。「九」下，次明坐離，尼對比丘屏坐吉，俗男則提，此謂因尼犯不同，致僧戒兩立。
【譯文】【記文】解釋之中，第一段。首先總體指示，即北齊曇隱律師依止慧光律師學律，撰述《四分律戒本疏鈔》四卷，此處採納其文句。「若」字以下，分別解釋。首先說明摩觸戒合併，比丘與比丘尼的兩部觸戒，都是合併制定的緣故。「九十條」以下，其次說明同坐戒分開，比丘尼對比丘在屏障處坐結突吉羅，對俗男則結波逸提，這是說因為比丘尼犯戒輕重不同，導致比丘戒必須分為兩條訂立。

【544-0010】02_戒疏/09b_卷二下之二#39
【原文】【疏】「若爾者，尼離五衣俱提，如僧對二女坐提；僧則三重二輕，相同尼對二男坐也。此亦輕重不同，何為得合？」
【譯文】【疏文】「如果按照這個道理，比丘尼離五衣過夜都結波逸提，如同比丘對二種女人同坐都結波逸提；比丘離五衣則三衣罪重、二衣罪輕，如同比丘尼對二種男人坐罪名不同。這也是輕重不同，為何比丘尼離衣戒能夠合併為一條？」

【544-0011】02_戒疏/09b_卷二下之二#40
【原文】【疏】答：「若就二、三結罪不同，實亦應離。俱對受法以明離，故合也。然前屏露，直是事中之譏，隨義故別。不同衣有聖法，對法以明同離，故不分之。」
【譯文】【疏文】回答：「若是單就二衣與三衣結罪的不同來看，確實也應當分開。但因都是對準『領受衣法』這一法制來界定離宿，所以予以合併。然而前面的屏障露處同坐，純粹是涉世事相上的譏嫌，隨著意義不同而有差別。這不同於法衣具有神聖戒法，是依對戒法來明確認定分離與否，所以不拆分戒條。」

【544-0012】02_戒疏/09b_卷二下之二#41
【原文】【記】次難中。初引僧尼離衣相並。前既尼犯兩別，僧坐因離，此亦僧制重輕，尼衣何合？答中，初縱奪釋通，「然」下，事法對簡。「事中譏」者，與尼坐戒，《律》因迦留陀夷與偷蘭難陀尼共坐，居士譏嫌；與女露坐，亦因迦留與優婆私坐，乞食比丘嫌故白佛等。「隨義別」者，即上對尼輕重之義。「不同衣」者，五衣加受，離失不異故。
【譯文】【記文】第二段詰難之中。首先引用比丘與比丘尼離衣戒來作對比。前面既然因為比丘尼犯相兩樣，比丘同坐戒因而分立，那麼此處比丘制罪也有重有輕，比丘尼離衣戒為何能合併？回答之中，首先作退一步與進一步的解通。「然而」以下，將具體事相與戒法體制作簡要對比。「事相中的譏嫌」，與尼同坐戒，律中起因是迦留陀夷與偷蘭難陀比丘尼共坐，受到居士譏嫌；與俗女露地同坐，也是起因於迦留陀夷與優婆夷私下同坐，乞食比丘見了嫌惡而稟告佛陀等。「隨著意義不同」，就是指上面對待比丘尼輕重不同的意義。「不同於法衣」，是因為五種法衣皆須受持作法，離宿失守的體制並無不同之故。

【544-0013】02_戒疏/09b_卷二下之二#42
【原文】【疏】又難：「若使結罪便故戒不分者，如下行戒，僧則二女俱提，尼則二男俱吉，此亦是便，何故分耶？」
【譯文】【疏文】又追問：「如果說結罪簡便就不分開立戒，那麼如同底下的同行戒，比丘對二種女人同行都結波逸提，比丘尼對二種男人同行都結突吉羅，這也是結罪簡便，為何又要分立戒條？」

【544-0014】02_戒疏/09b_卷二下之二#43
【原文】【疏】答：「結便應合。開緣有異，故離。如尼女同行，尼則開僧將援，俗女則無。又尼行必假多伴，為除譏醜，俗女但有第三，便無濫過，所以分也。」
【譯文】【疏文】回答：「單看結罪簡便確實應當合併。但因為開許豁免的因緣不同，所以分開。例如與尼、女同行，若是比丘尼，則開許在需要僧人護送時同行，俗女則沒有這種開許。再者比丘尼出行必須依賴多位伴侶，是為了免除醜陋譏嫌；俗女只要有第三人在場，就沒有嫌疑過錯，所以必須分開立戒。」

【544-0015】02_戒疏/09b_卷二下之二#44
【原文】【記】後難中。以同行戒彼此犯同，亦應須合。答中，初句縱，次句奪。「如」下，引緣以釋。初約將護有無釋。「又」下，次約伴行多少釋。下云：「行途逈遠，招譏過大。縱多比丘，一尼亦犯，要得多尼為伴方開。」
【譯文】【記文】後面的詰難之中。認為同行戒既然彼此犯戒罪名相同，也應當予以合併。回答之中，第一句先承認此理，第二句再予以轉折修正。「如」字以下，引用開許因緣來解釋。首先從有無護衛護送來解釋。「又」字以下，其次從同行伴侶的多少來解釋。下文說：「路途遙遠，招致的譏嫌過失極大。縱然有多位比丘，只要單獨一位比丘尼同行也算犯戒，必須有多位比丘尼結伴方得開許。」
