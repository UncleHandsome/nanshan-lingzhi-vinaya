== PROBLEM ==
把科判定位詞當實詞譯錯。原文「早下」是指鈔文「早」字以下（如「早須……」）為勸勉之文。譯文望文生義將位置標記「早下」譯為「早晨以下」，完全違背科判釋例。

== SUGGESTION ==
將「早晨以下，為勸勉之辭。」更正為「鈔文中自『早』字以下，為勸勉之辭。」

== ORIG ==
`知下，以理難破。……及自為者，所教局俗也；鐘亦不爾，通彼比丘，受教自打故。早下，勸勉。`

== CURRENT ==
「知」字以下，依循法理進行詰難攻破。前面說明打鐘，無論是能教者或受教者，都通於道俗二人；然而所謂「知」的清淨語，能教者不通於俗人，所教者不通於道人；兩件事性質不同無法並論，所以用這點來詰難他。知淨語不通於俗人，是因為能教者局限於道人；打鐘則不是如此，能通於俗人，可以差遣他人去打。至於自己去做的情況，所教者局限於俗人；打鐘也不是如此，通於比丘，可以接受教敕自己去打。早晨以下，為勸勉之辭。
