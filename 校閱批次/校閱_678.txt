# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【678-0001】資持記/16b_下四#30
【原文】明如來為眾生故，方便示現，出家修道。初一偈，開示令知；次一偈，引導令出。如來若不出家，當紹金輪王位，故云捨國財也。寂靜，即涅槃理也。以下，結示。菩薩，即釋迦本師；此明出家，從因彰號。下指二經。具云《郁伽羅越問菩薩行經》，彼云：佛告郁伽，出家菩薩，常念精進智慧，無所著也；
【譯文】說明如來為了度化眾生的緣故，方便示現出家修道。前一首偈頌，開導指示令眾生知曉；後一首偈頌，引導眾生令其出離世間。如來如果不出家，本應當繼承金輪王位，所以說「捨棄國家財寶」。寂靜，就是涅槃之理。「以」字以下，結語指示。「菩薩」就是釋迦本師；此處說明出家，是從因地彰顯名號。下文指示兩部經典。全名為《郁伽羅越問菩薩行經》，那裡說：佛告訴郁伽，出家的菩薩，常念精進智慧，心無所執著；

【678-0002】01_行事鈔/12b_卷下之四#14
【原文】二明勸出有益者。《華手經》：菩薩有四法，轉身當作善來比丘，蓮華化生，現增壽命：一自樂出家，亦勸助他人，令其出家；二求於佛法，無有懈倦，亦勸他人；三自行和忍，亦勸他人；四習行方便，深發大願。《出家功德經》云：若放男女奴婢人民出家，功德無量。譬四天下，滿中羅漢，百歲供養；不如有人，為涅槃故，一日一夜，出家受戒，功德無邊。又如起七寶塔，至三十三天，不如出家功德。《智論》云：出家人雖破戒，破戒墮罪，罪畢得解脫。如《蓮華色尼本生經》說。如佛度醉婆羅門，以無量世來，無出家心，因醉發心，後當得道，因說出家偈。《本緣經》云：一日一夜出家故，二十劫不墮三惡。《祇律》：一日一夜出家修梵行，離六百六千六十歲三塗苦。
【譯文】第二、說明勸導出家有大益處。《華手經》記載：菩薩若具足四種法，轉生後應當成為「善來比丘」（以佛喚善來而自然具足戒），於蓮華中化生，現世增長壽命：一是自己樂於出家，也勸勉協助他人令其出家；二是精求佛法無有懈怠疲倦，也勸勉他人如此；三是自己奉行調和忍辱，也勸勉他人如此；四是修習實踐善巧方便，深發大誓願。《出家功德經》說：如果放任兒女、奴婢、百姓出家，功德無量無邊。好比四大天下滿是阿羅漢，以百年時間供養他們，還不如有人為了證得涅槃，一日一夜出家受戒的功德廣大無邊。又如同建造七寶佛塔高聳到達三十三天（忉利天），其福報也不如出家的功德。《大智度論》說：出家人即使破了戒，雖然破戒會墮落受罪，但罪報受畢仍能獲得解脫，正如《蓮華色尼本生經》中所說的那樣。又如佛陀度化醉酒的婆羅門，他於無量世以來從無出家之心，只因酒醉而發心出家，佛便給他剃度，預言他未來定能成道，佛陀因而說了讚歎出家的偈頌。《菩薩本緣經》說：只因一日一夜出家的緣故，便能在二十劫中不墮入三惡道。《摩訶僧祇律》記載：一日一夜出家修持清淨梵行，便能遠離六百六千六十年的三塗惡道之苦。

【678-0008】資持記/16b_下四#35
【原文】一解脫，二精進，三忍辱，四饒益，一一皆具自行化他；此中正用第一，餘三相因而引。《功德經》中，初正明。二喻顯，有二。為道出家，無漏功德；供聖起塔，皆有為福，故所不及。一日一夜舉少況多。彼經，阿難問佛：若有人放人出家，若自出家，得幾所福？
【譯文】一是解脫，二是精進，三是忍辱，四是饒益，每一種都具足自行與化他；此處主要使用的是第一種，其餘三種是因緣相連而順帶引出。《出家功德經》中，首先正面說明。第二以比喻顯發，包含兩層意涵。為了求道而出家，具有無漏的真實功德；供養聖人、建造寶塔，都屬於有為的世間福德，所以比不上出家。以一日一夜極少的時間，來比況功德的大多數。該經中，阿難問佛：如果有人放縱他人出家，或者自己出家，能得多少福報？

【678-0013】01_行事鈔/12b_卷下之四#16
【原文】四明既出家已，行凡罪行。《大寶積經》云：出家有二種縛：一見縛，二利養縛。有二癰瘡：一者求見他過，二者自覆己罪。經中又言，有二毒箭，雙射其心：一邪命為利，二樂好衣鉢。《涅槃》云：我涅槃後，濁惡世時，多有為飢餓故，發心出家，名為禿人；見有持戒、威儀具足，清淨比丘，護持正法；驅逐令出，若殺若害。若論罪行，且列五種：所謂貪欲、瞋恚、愛親、求利、慳嫉等五。並如《別鈔》，隨事引文。
【譯文】第四、說明已經出家之後，卻行持凡夫罪惡之行。《大寶積經》說：出家人有兩種繫縛：一是邪見縛，二是利養縛。有兩種癰瘡：一是專門尋求挑剔他人的過失，二是掩蓋隱瞞自己的罪咎。經中又說，有兩支毒箭同時射中其心：一是依邪命謀取私利，二是貪愛喜好名貴的衣物鉢具。《大般涅槃經》說：我滅度之後，在五濁惡世之時，會有許多人因飢餓困頓的緣故發心出家，這些人被稱為「禿人」；他們見到有持守戒律、威儀具足的清淨比丘護持正法，反而將其驅逐驅趕出去，甚至加以殺害。如果要論述罪行，暫且列舉五種：即貪欲、瞋恚、貪戀親眷、追求名利、慳貪嫉妒等五種。這些都如《別鈔》中隨事引證經律之文所載。

【678-0014】01_行事鈔/12b_卷下之四#17
【原文】五明出家行凡福行。謂有比丘，出家已後，但知持戒，不志尚道；以戒為上，餘悉不為，用為非道；內多瞋怒，自污淨心，情無勝進。此戒取見，見取煩惱，欲界下業，非上界行；若修世禪，是上界業，終退生死，未有出期；乃至多聞、布施、講經、誦習，並是欲有，未成無漏。《智論》云：世間法者，孝順父母、供養沙門、布施持戒、四禪四無色定、念佛法僧、九想等是。《成論》云：於持戒、多聞、禪定等少利事中，自以為足；以貪著此少利事故，忘失大利。智者不應貪著小利，忘失大利。
【譯文】第五、說明出家後只行持凡俗的人天福報之行。這指的是有的比丘出家之後，只知道拘泥持戒，卻沒有慕求聖道的心志；自以為持戒最為崇高，其餘種種行門一概不做，甚至視其為非道；內心常多瞋怒，自己染污了清淨心，志向上毫無殊勝的精進。這屬於「戒禁取見」與「見取見」的煩惱，純屬欲界的低下善業，並非色界、無色界的上界之行；若是修持世間禪定，雖然屬於上界的善業，但終究還會退墮於生死輪迴之中，難有出離之期；乃至博學多聞、行布施、講說經論、諷誦修習，也全都是欲界的有漏之因，未能成就無漏解脫。《大智度論》說：所謂世間法，包括孝順父母、供養沙門、布施持戒、四禪四無色定、念佛法僧、九想觀等都是。《成實論》說：在持戒、多聞、禪定等小利益的事項中，自己便感到滿足；因為貪著於這些微小的利益，反而忘失了成佛解脫的大利益。有智慧的人絕不應當貪著眼前微利而忘失終極的大利。

【678-0015】資持記/16b_下四#40
【原文】慎勿自謾，謂是他也。見，謂執見，義兼於名，此利根也；利養，即財物，更兼欲色，此鈍根也；《業疏》云：鈍貪財色，利著名見；四科收之，尠無不盡。《涅槃》。為飢餓者，以出家人，衣食易得故。見有持戒，驅逐殺害者，自無戒德；恐相形比，失於利養，生嫉忌故。次科。
【譯文】千萬切勿自己欺瞞自己，以為是在說別人。「見」，是指偏執之見解，義理兼含名聲，這是利根之人；「利養」，就是財物，更兼含貪慾色相，這是鈍根之人；《業疏》說：鈍根者貪著財物美色，利根者執著虛名偏見；用這四個類別來收攝，極少有不被涵蓋殆盡的。《涅槃經》。為了飢餓而出家者，是因為出家人衣食容易獲得的緣故。見到有持戒之人而驅逐殺害者，是因為自己沒有戒德；害怕彼此相形見絀而失去利養，因而生起忌妒之心的緣故。下一個科判。
