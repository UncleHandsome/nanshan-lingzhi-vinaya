# 校閱材料　第316檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【316-0001】02_戒疏/01c_卷一上之一#23
【原文】【記】三、翻名義，正翻中，初文，先引古譯。蓋準《母論》，彼云「毗尼名『滅』，滅諸惡法故」，此即就能以翻。「今」下，出正翻，初二句徵起。以前云唐稱為「律」，故直徵其義。次一句訓字。「從」下，釋義。「斷割」等者，一一戒下，皆具此義。且如婬戒，入如毛頭犯夷，此名「重」也。半壞多分，方便非道，教他等皆蘭，教而不作，三眾同吉，此謂「輕」也。怨逼通境合，即是「開」也。受樂結重，「遮」也。離此諸過名「持」，反此名「犯」。舉此例通一切諸戒及餘法聚，則以「法」為義，皎然可解。對古所譯，故云「正翻」。
【譯文】【記文】第三、翻譯名稱與義理，在正式翻譯的名段中。最初一段，先引述古時的舊譯。這是依準《毘尼母論》，該論說「毗尼名為『滅』，是因為能滅除諸多惡法的緣故」，這就是依照功能功用來翻譯。「今」字以下，提出正式的正翻，前兩句發起詰問。因為前文提到唐朝稱為「律」，所以直接探究它得名的義理。緊接一句是訓解字義。「從」字以下，闡釋義理。「斷割」等句，每一條戒律之下，都具備這些內涵。姑且以婬戒為例，只要男女根相交如毛髮之頭即犯波羅夷罪，這稱為「重」。若於半腐壞或大半腐壞的死屍上行婬、造作前方便、於非道行婬、教唆他人行婬等都結偷蘭遮罪，教唆而對方未行，三眾都結吉羅罪，這稱為「輕」。被怨家強逼，即使二根相交（境合），只要不受樂便是「開」許不犯。若生受樂之心則結重罪，這是「遮」止。遠離上述種種過患稱為「持」，違犯上述各項稱為「犯」。以此為例可以通貫所有的戒條以及其餘法事集會，因此以「法」作為核心意涵，道理昭然明白易解。相對於古時的翻譯，所以稱作「正翻」。

【316-0002】02_戒疏/01c_卷一上之一#24
【原文】【疏】俗有九流，「法流」其一，故世付法皆約刑科。道與俗違，刑名乃異。至於處斷，必依恒法。故使「律」字「彳」旁兼「聿」者，為取筆也。處劾決正，非筆不定。筆即法家之象，致唯律翻。
【譯文】【疏文】世俗學問有九個流派，「法家」是其中之一，所以世俗判定罪過都依據刑法條款。佛門出世之道與世俗截然不同，刑罰的名稱也自然相異。但說到判斷處置罪愆，必定要依照恆常不變的準則法規。因此「律」這個字，在偏旁由「彳」兼帶「聿」，是取其手持筆墨記錄之義。審問處斷、裁決是非，如果不用筆墨書記確立就無法判定。筆正是法家辦案的表徵象徵，因此唯一能以「律」來對應翻譯。

【316-0003】02_戒疏/01c_卷一上之一#25
【原文】【記】次科。初列示俗法。《漢書．藝文志》云：全身保國，凡有「九流」。「法流」第四，今疏所指。「付法」，「付」即與也。「約刑科」者，按其科條，不妄加減也。「道」下，會同道俗。上二句示制異。五篇七聚為「道刑」，古今五刑為「俗刑」，如後所列。「至」下二句，明義同。「故」下，指字體顯義。「彳」，丑亦反，《說文》云：「少步也。象人脛三屈相連。」、「聿取筆」者，謂象人之執筆，《說文》云：「秦謂之筆，楚謂之聿，吳謂之律。」、「劾」，胡得反，推窮罪人也。「法家象」者，以法無象，假筆書示以成其形，故釋名云。「筆」，述也，述事而言也。
【譯文】【記文】下一科段。最初列舉展示世俗的法令法規。《漢書．藝文志》說：保全自身與國家的學說，共有「九流」。「法家」位列第四，正是本疏此處所指的對象。「付法」，「付」就是給予、施行的意思。「約刑科」，是按照條文科條，不隨意增減輕重。「道」字以下，會通佛門與世俗的異同。前兩句指出制度的不同。以五篇七聚作為「佛門僧伽的制罰（出家戒規）」，以古往今來的五刑作為「世俗的刑罰」，就如後文所列出的內容。「至」字以下兩句，說明兩者追求裁斷公正的理致是相同的。「故」字以下，剖析字形以彰顯字義。「彳」，音「斥（chì）」，《說文解字》說：「是小步行走。象徵人腿脛三處彎曲相連。」「聿取筆」，指聿字即取筆之義，是指其字形象徵人手執筆，《說文解字》說：「秦國稱之為筆，楚國稱之為聿，吳國稱之為律。」「劾」，音「核」，指審理追查犯罪之人。「法家象」，因為法則本身無形無相，必須藉由筆墨書寫公布以彰顯具體形態，所以《釋名》說：「筆，就是述，是記述事實而言說的意思。」

【316-0004】02_戒疏/01c_卷一上之一#26
【原文】【疏】如《增一》中七種律也，《四分》九法，亦有其證。
【譯文】【疏文】例如《增一阿含經》中提及的七種律法，《四分律》所載的九種非法與九種如法，也都是有力的明證。

【316-0005】02_戒疏/01c_卷一上之一#27
【原文】【記】三中。「《增一》七種律」者，即滅諍「七毗尼」也。彼從華語，足證今譯。「《四分》九法」者，調達九邪，破佛九正，名十八法，如「僧殘」中具釋。《律》中前後列名不定，第二一種，或云「律非律」，或言「毗尼非毗尼」，《鈔》云「毗尼及律二名不竝」是也。
【譯文】【記文】第三段中。「《增一》七種律」，就是用以息滅諍事的「七滅諍法（七毗尼）」。該經採用了華夏本土的語言名稱，足以證明如今翻譯為「律」是正確的。「《四分》九法」，是指提婆達多以九種邪法來破壞佛陀的九種正法（提婆達多之九邪與佛門之九正合稱為破僧十八法），如在「僧殘」章節中會有詳細解釋。《四分律》中前後列舉名稱並不一致，第二種名稱，有的寫作「律與非律」，有的寫作「毗尼與非毗尼」，這就是《行事鈔》所說「毗尼與律兩個名稱不能並立通用」的緣故。

【316-0006】02_戒疏/01c_卷一上之一#28
【原文】【疏】古同為「滅」，謂功用也。滅諍之能，非律不靜，如水滅火，水非名滅。自餘云云，或曰稱量輕重，或曰遮制流類，皆信意言，無有歸據。故「律」文言，科約篇聚，並有軌轍，同收「法」義，餘復何論？
【譯文】【疏文】古德一概翻譯為「滅」，所指的只是它的功用。平息諍論的效能，如果沒有律法就無法平定肅靜，正如水能夠滅火，但水本身的名稱並不叫做「滅」。至於其餘各家的紛紜說法，有的說是衡量罪行的輕重，有的說是遮止防範罪業流類，全都是隨心意杜撰而言，根本沒有權威經典為憑據。所以《律》本文中所說，將戒條篇聚分門別類，全都有跡可循、有法度軌範，全都收歸統攝於「法則（法）」的深義，其餘隨意立名的說法又有何值得議論的呢？

【316-0007】02_戒疏/01c_卷一上之一#29
【原文】【記】四中。初斥翻滅。名須剋體，不可從用，舉喻比例，是非可見。「自」下，斥餘名。且列二家，餘應更有。上謂依憑斷割，故曰「稱量」；下謂罪聚楷定，故云「流類」。然此二名，頗近「法」義，但無所憑，故云「意言」等。「故」下，示今有據，初指文。「文言」，即能詮也。「科」下，示義。「科約篇聚」者，示有重輕也。「有軌轍」者，言其楷定也。「同」下，結示。上句示今有歸，下句貶古無取。
【譯文】【記文】第四部分中。最初駁斥將毗尼翻譯為「滅」的說法。立名必須實質對應事物的本體，不能僅順從其發揮的功用，舉出水滅火的譬喻加以比照，是非對錯便一目了然。「自」字以下，駁斥其餘名稱的主張。暫且列出兩家，其餘應當還有更多。前者認為依憑它來裁斷判決，所以稱為「稱量」；後者認為將各種罪聚規範確立，所以稱為「流類」。然而這兩種名稱，雖然相當接近「法」的含義，但全無經典依據，所以指責為「意言」等。「故」字以下，指出現在的翻譯確有經文依據，起初指陳經文。「文言」，就是指能詮顯教理的文字。「科」字以下，顯發義理。「科約篇聚」，說明戒律有輕重的科條等級。「有軌轍」，是說其規矩標準楷定不移。「同」字以下，結語開示。前一句指出現在的立論有其正軌歸趣，後一句貶斥古代隨意立說全無可取之處。

【316-0008】02_戒疏/01c_卷一上之一#30
【原文】【疏】問：「律以法訓，施造有儀，與餘兩藏，復有何別？」
【譯文】【疏文】有人問：「律既然訓解為『法則』，制定興立都有一套儀軌，那麼它與三藏中的另外兩藏（經藏、論藏），又有什麼區別呢？」

【316-0009】02_戒疏/01c_卷一上之一#31
【原文】【記】簡濫中。初問意者。以「經」訓法、訓常，「論」亦翻為「對法」，是則「法」義皆通三藏，不局律宗，故發是問。
【譯文】【記文】在甄別混濫的文段中。最初提問的用意。因為「經」可訓解為法、訓解為常，「論」也翻譯為「對法」，這麼一來「法」的含義通達於三藏，並非局限於律宗一門，所以發起此問。
