# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【87-0001】02_戒疏/03c_卷一下之一#104
【原文】【記】轉難中。藥既在先，理應先設，此約漸制，以難常法。答中，顯示不先之意。前辨二教，已引《善見》，故此指之。彼云「如世醫師，未善治病，見人始欲生癰，未大成熟，輒為破之。病者曰：『我本無病，強為破之，受大痛苦！』聲聞弟子，亦復如是」云云。
【譯文】【記文】在進一步的反難之中。藥法既然在先，在道理上就應當預先設立，這是在藉由佛陀「隨犯隨制」的漸次立教原則，來詰難其屬於「諸佛常法」的觀點。回答之中，顯示出佛陀不預先公布具體戒條的深意。前面辨析兩種教法時已經引用過《善見論》，所以此處直接指引。彼處說「就好比世間的醫生不擅長治病，看見一個人才剛要長出癰瘡，還沒有完全熟透潰爛，就隨便動刀割破它。病人憤怒地說：『我本來沒有大病，你強行割破它，害我承受巨大的痛苦！』聲聞弟子的反應也是這樣」等等。

【87-0005】02_戒疏/03c_卷一下之一#108
【原文】【記】四、明次第，安布中。初躡前發問。「如前」即指「通敘教旨」中。「解」下，釋通。初正釋。以迦葉結集，稟佛囑累，乃差波離先集律藏，故云「命持律」等。「所」下，引證。即《五百結集》文，彼云「比丘一切事在一處，為比丘律；比丘尼事在一處，為比丘尼律；一切受戒法集一處，為受戒犍度；乃至二十雜犍度」等，竝如上文中，簡要總舉而已。

【87-0020】02_戒疏/03c_卷一下之一#123
【原文】【疏】問：「初篇過重，離則不難，理應是劣，何故說勝？」
【譯文】【疏文】有人問：「第一篇罪過深重，想要遠離它並不困難，在道理上其修行對治應當屬於淺劣，為什麼反而說它是最勝妙的呢？」

【87-0021】02_戒疏/03c_卷一下之一#124
【原文】【記】問中。若據根條重輕，則初篇最重；若望對治難易，則第五至難。今以對治難前根條，欲彰教旨不必一向。
【譯文】【記文】在提問之中。如果依照根本與枝條的輕重來看，第一篇罪過最為深重；但若對照修持對治的難易度而言，第五篇則是極度困難。現在發問者以對治的難易，來詰難前面以根本枝葉判斷輕重的說法，目的是想彰顯教化宗旨並非只有單一固定的角度。

【87-0022】02_戒疏/03c_卷一下之一#125
【原文】【疏】答：「義有多途，不可一槩。若就根條以判，初則行之所依，餘四枝條故劣。若就進趣修成，初篇過重易離，不假勝進修治，故名為劣。乃至第五，過微難護，必須專意，無由識相。是以《戒本》舉『應當學』者，勸能治行也。若就純淨無染，名為最勝。」
【譯文】【疏文】回答說：「義理的角度有多種途徑，不可以一概而論。如果單從『根本與枝條』的角度來評判，第一篇是所有行持的依止所在，其餘四篇只是枝條，所以相對顯得淺劣。如果就『修行進趣與修持成就』的難易來說，第一篇過患極其粗重而容易遠離，不需要假借高深的修為去特別對治，所以在這層意義上稱為淺劣。乃至到了第五篇，過失極其微細而極難防護，必須全神貫注，稍一不慎就無法察覺罪相。因此《戒本》中特別標明『應當如法修學』，就是為了勉勵修行者建立起高度的對治行持。但若就『保持純淨無染的根本行體』而言，第一篇自然被稱為最為尊勝。」

【87-0023】02_戒疏/03c_卷一下之一#126
【原文】【記】答中。初二句通示。「若」下，別釋。初重述前義。後「若就」下，正通來難。文中且示初劣後勝，中間相望，互兼勝劣，故云「乃至」。文舉《戒本》「應當學」者，以上諸篇，並列罪目，唯此第五獨立「學」名，足彰難護。
【譯文】【記文】在回答之中。前兩句總體開示。從「如果單從」往後分別解釋。首先重申前面的義理。後面從「如果就修行」往後，正式化解來難的質疑。文句中暫且提示最初為劣、最後為勝，至於中間各篇互相比照，也是各有勝劣互見，所以說「乃至」。文中舉出《戒本》說「應當如法修學」，是因為上面各篇全都直接列出罪行名稱，唯獨這第五篇獨立冠上「學」的名稱，這足以彰顯此篇最難防護。

【87-0024】02_戒疏/03c_卷一下之一#127
