# 校閱材料　第997檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【997-0001】資持記/04a_上三#51
【原文】束廣從略，亦不出下兩行之文。要下，撮示有三；情非情者，此二總攝十界依正。二空下五句，別舉二寶。據情非情，攝境斯盡；為遮疑濫，故須別示。上句，明化相法也。佛說四諦，即攝世及出世凡聖因果；苦、集、道三名有諦，滅即空諦，亦名真俗二諦。次句，理，即理體法也；
【譯文】若能刪繁就簡、由廣收縮入略，也絕不會超出下面短短兩行文字的範圍。從「要（而言之）」字以下，撮略提示有三類境界：有情與無情，這兩者總體統攝了十法界中的依報環境與正報身心。從「二空」以下的五句話，是特別列舉佛、法二寶境界。純粹就「有情」與「無情」來說，所涵括的境界就已經徹底圓盡了；但為了防止有人疑惑混濫，所以必須特別標示出來。上一句是說明化相之法。佛陀宣說苦集滅道四聖諦，便總攝了世間與出世間凡夫聖人的所有因果；苦、集、道三諦稱為「有諦」，滅諦即是「空諦」，這四諦也可以配稱為真諦與俗諦二諦。下一句所謂「理」，是指理體之法；

【997-0002】資持記/04a_上三#52
【原文】異上空諦，是教攝故。佛下三句，即住持二寶。問：此並非情，何須重舉？答：恐謂聖境非戒緣故。問：化理二法，云何發戒？答：《疏》云：俱有損壞毀謗義故，如提婆破法之類。問：化相不明佛，住持不言僧者？答：並情收故。理中佛僧俱無別體，所以可知。三地水下二句，別舉六大。上五非情，後一是情。
【譯文】它不同於上述的滅諦空理，因為那是屬於教法名相所收攝的緣故。從「佛」字以下的這三句，就是指住持二寶。問：這些全屬於無情物相，為何需要重複舉出？回答：這是唯恐有人誤以為聖人住持境界不是發起戒體的因緣。問：化相與理體這兩種法，如何能發起戒體？回答：《業疏》說：兩者都具有可能被毀損、破壞、誹謗的意義在內，例如提婆達多破壞僧團法事之類。問：化相法中沒有特別指名佛，住持法中沒有特別提及僧，這是為什麼？回答：因為化相佛與住持僧，都已經歸入「有情」之中收攝了。而在理體法性之中，佛與僧本來就沒有另外獨立的形體，所以原因於此可知。第三類「地水」以下的兩句，是特別舉出構成物質世界的六大要素。前面五個（地水火風空）屬於無情，最後一個（識大）屬於有情。

【997-0003】資持記/04a_上三#53
【原文】風空及識境相難見，故復示之，如盜戒說。又復須知隨戒多別。如婬殺等，單情境也。如掘壞，唯非情也。如盜妄等，則兼二種，謂盜分四主，物兼六大，妄對所誑，復規利養。法下，總結。言法界者，若就教限，則局三千大千；今從圓意，須論十方法界；
【譯文】風界、空界以及識界的境相比較隱微難見，所以在此重新開示，正如盜戒章節中所說明的。此外又必須明了，戒律隨犯隨持的境界千差萬別。例如婬戒與殺戒，純粹是針對有情境界而犯。例如掘地壞生草木戒，則純粹是針對無情境界而犯。至於盜戒與妄語戒等，則同時兼具兩者，譬如盜戒要分辨四種主人的所屬，被盜之物又兼括六大物質，妄語戒既面對所欺誑的有情對象，內心又貪圖名利供養的無情器物。從「法」字以下，作出總體結語。所謂「法界」，如果依據小乘教法的局限，就只劃限在三千大千世界之內；如今順從圓頓的開顯深意，必須論及十方法界；

【997-0004】資持記/04a_上三#54
【原文】無作之體，稱境而發，等法界量，故云並是戒體。〔古記云：令示戒境，又云此是能領心體，誤之甚矣。〕引證中，初證有情。薩下，二證非情。非情境廣，且舉地塵示其多相。即下，復引四物轉證。《善生》五種，前後離明。
【譯文】無作戒體的發起，是相稱於外境的廣大而隨之生起，其量度等同於整個法界，所以說「全都是戒體的本質」。（古人的註記說：教導人明示戒境，又說這就是能領受的心體，這真是錯謬到了極致。）在引用教證的文段中，首先證明有情境界能發戒。從「薩」字以下，第二部分證明無情境界能發戒。無情的外境極其廣闊，暫且舉出大地微塵來顯示其廣多之相。從「即」字以下，又進一步引用四種物境輾轉證明。《善生經》所說的五種境界，在文段前後分別拆開來闡明。

【997-0005】資持記/04a_上三#55
【原文】若復細論，飲食衣服房舍臥具，常住現前四種僧物，行住坐臥俯仰威儀，大小便利，一切作務，無非制法；所謂森然萬境，何事非持；若不爾者，豈名具足；若不先發，行自何生？故知受前，預須委學。沙彌建位，正存於此；今時昧教，誰復知之！
【譯文】如果再作微細的探討，飲食、衣服、房舍、臥具，常住僧物、現前僧物等四種僧家資具，乃至行住坐臥、俯仰顧盼的一切威儀，大小便利、僧中一切日常勞作事務，無一不是聖人所制戒法的落實之處；這正是所謂的「森羅萬象的萬法境界，又有哪一樣事情不需要持戒」；如果不這樣周遍了知，怎麼能稱得上是「具足戒」；如果在受戒時不預先發起這種涵蓋一切境的心量，未來的戒行又要從哪裡產生呢？所以應當知道，在受具足戒之前，必須預先詳盡修學。建立沙彌的階位，用意正是在於此處；現今這個時代大家對戒教盲昧無知，又有誰還懂得這層道理呢！

【997-0006】資持記/04a_上三#56
【原文】顯德中，初科，初引示。凡戒因行，佛戒果德；
【譯文】在顯揚戒德的文段中，第一科首先引用經論說明。凡夫的戒律屬於因地修行，佛陀的戒德乃是極果功德；

【997-0007】資持記/04a_上三#57
【原文】凡聖優劣，實非相擬；一往且望清淨義同，故云齊德。以下，就人顯勝。善法聚者。攬無邊戒法，歸無盡識藏；成善種子，作聖道基；翻無始惡緣，俱為戒善；變有漏苦報，即成法身，我等云何不自珍敬！佛恩深重，粉骨難酬；苦海導師，朽宅慈父；
【譯文】凡夫與聖人的高下優劣，實質上完全不可同日而語；此處暫且就因地守戒與果地清淨的含義相同這一點而言，所以說是「功德齊等」。從「以」字以下，就受戒者自身來彰顯戒德殊勝。所謂「善法聚」，是將無量無邊的廣大戒法，全體收攬回歸至自身無窮無盡的阿賴耶識田中；化作清淨的善種子，作為證入聖道的根本基礎；翻轉無始劫以來造作惡業的境界因緣，全部轉化為受持戒律的至善；轉變有漏的生死苦果之報，直接成就圓滿的清淨法身，我們自己怎能不恭敬自珍自愛呢！佛陀的深恩極其厚重，縱使粉身碎骨也難以報答；佛陀是茫茫苦海中的領航導師，是三界失火破宅之中的慈愛父親；

【997-0008】資持記/04a_上三#58
【原文】願從今日，盡於未來，竭力亡身，常贊三寶，廣度群品，少答聖慈。不下，舉毀破校量，初正明。故下，引證。經據犯重，故曰死人，如〈僧網〉具引。四喻中，略眼藥喻，故云等也。偈中，上半舉喻，下半合法。瞻蔔，此云黃花，花小而香；西土所貴，故多舉之。有毀戒者，見此言相，似順愚情；
【譯文】願我們從今天起，一直窮盡未來際，竭盡心力乃至不惜犧牲身命，永遠讚歎佛法僧三寶，廣度一切眾生，藉此微薄地報答聖人的慈悲大恩。從「不」字以下，舉出受戒後毀破戒律的情況來進行校量比較，首先正式說明。從「故」字以下，引用經典作證。經中依據犯下波羅夷重罪而言，所以稱之為「死人」，正如〈僧網篇〉中所具體引用的。在經中所說的四個譬喻中，此處省略了眼藥之喻，所以說「等等」。在偈頌中，前半截是舉出譬喻，後半截是合法以合顯法義。「瞻蔔」此處翻為黃花，花朵雖小但香氣濃烈；在西域天竺極為尊貴，所以經中經常引為譬喻。有些毀犯戒律的人，看見這段文字的表面說法，似乎順從了他們愚痴的情執；

【997-0009】資持記/04a_上三#59
【原文】妄自矜誇，謂犯猶勝。此乃一途引接隨時之義，聖制令受，意在成持；即下文云：寧起行用，不須願求；又云：若毀佛戒，不如不受。教旨甚明，慎勿錯會。勸受中，初躡前敘勸。即以破戒無戒比校損益。智下，引證，前引釋論雙證損益。
【譯文】便妄自驕傲誇口，宣稱破戒之人比起不受戒的白衣依然要殊勝得多。這其實是佛陀在某種特定情境下隨順凡機接引化導的權巧說法，聖人制戒令人受戒，真正的意圖是在於期望其如法成就並持守戒律；這正如鈔文下文所說的：「寧可生起真實持戒行持以發揮妙用，切不要只是求取掛名受戒」；又說：「如果受戒之後卻毀犯佛戒，那還不如當初不受戒為好。」經教的主旨極其分明，大家千萬切忌曲解會錯意旨。在勸勉受戒的文段中，首先承接前文敘述勸勉之意。這就是以「破戒」與「全不受戒」來比較校量其損害與利益。從「智」字以下，引用教證，前半段引用《大智度論》從損與益兩方面雙重證明。
