# 校閱材料　第1283檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1283-0001】資持記/13c_下一#41
【原文】前出法中為三，初財主捨物，恐犯長故。而云展轉，簡真實故。彼下，受者反問。以言展轉，不自專屬故。大德下，後明受者遙囑淨主，還付財主為彼守護。疏云：此有三轉，財主付淨，為一轉淨也；淨者遙囑，為二轉淨也；淨主不知，還付財主，三轉淨也。俱淨貪著之意。故云淨也。
【譯文】前面列出作法之中分為三段：最初是財物主人捨棄物品，唯恐犯長蓄罪，然而說這是「展轉」，是為了簡別真實淨；「彼……」以下，接受作法的人反問，因為既然說是展轉，自己便不能專權掌管；「大德……」以下，最後說明受法者在心中向遠方的淨主囑託，把衣物退還交付給財主為其看守照護。疏文說：這經過了三度展轉：財主付託給作淨者，是一轉淨；受淨者向遠方淨主作囑託，是二轉淨；作淨主並不知情，衣服仍還交由財主，是三轉淨。這都是為了清淨貪求執著的心意，所以稱之為「淨」。

【1283-0002】資持記/13c_下一#42
【原文】外下，次引制緣。三律即五、十、祇，次第三制。初制對面。即淨主前執據不還，故生諍競。因下，次制語知。又下，後制不須。彼謂己物，故恐犯長。真實中，初引示儀法。若正下，次出詞句。注中，通示二法，不用他宗。次文，初標。成就者，此明作法言相通濫成否之相。
【譯文】「外……」以下，接著引述制戒的緣起。三部律典即是指五分、十誦、僧祇，依序記載了三道禁制。第一道禁制是禁止當面作淨，因為當面作淨時淨主執衣不還，因而產生爭端。「因……」以下，第二道禁制是禁止告知淨主。「又……」以下，最後規定不須告知，那是因為對方自以為是己物，所以害怕犯長蓄罪。在真實法中，最初引導展示儀軌法則。「若正……」以下，接著寫出辭句。注文中，普遍指示這兩種作法，不採用其他宗派的說法。下一段文，最初標明。「成就」，這是說明作法時言詞相貌的通達混濫與成立與否的相狀。

【1283-0003】資持記/13c_下一#43
【原文】善下，引示，初明財主與詞。則通二淨。言受不成者，語似決施故。真下，次明受者答詞。局簡實淨。以展轉法無此答故。言當欲等不成者，似非決受故。一下，後示說數。似斥濫行，故云不須等。三中，初淨長財，文亦為三，初能施捨財。彼應下，受者審主。通指五眾，故云漫標。
【譯文】「善……」以下，引用顯明：最初說明財物主人的給與辭句，這通於兩種淨法。如果說「接受」就不算成就，因為話意聽起來像是斷然施捨；「真……」以下，接著說明接受者的回答辭句，局限於簡別真實淨，因為展轉法沒有這種應答。如果說「正想要」等字眼便不能成立，因為聽起來不像是斷然接受。「一……」以下，最後指出說法的次數，這似乎是在斥責混濫的行徑，所以說「不需要」等語。第三項中，最初是長財的作淨法，文字也分為三段：起初是能布施者捨棄財物；「彼應……」以下，受法者審核淨主，因為普遍指稱五眾，所以說是隨意標指；

【1283-0004】資持記/13c_下一#44
【原文】彼即下，彼為轉施。言某甲者，任彼受者趣與一人。注言展轉，對簡真實不通此法故。囑令記主者，由非別請，恐忽忘故。後明淨鞋履法。錢寶法中，初標舉。律下，示法。守園人，《戒經》所謂僧伽藍民也。文中但云持至，不顯自他。故下約義據文決之。令知是物，謂先須淨語也。
【譯文】「彼即……」以下，對方為他轉施。說「某甲」，是任憑那位受法者隨意給予其中一人。注文提到「展轉」，是用來對比簡別真實法不能通融此法。囑咐對方記住淨主，是因為這並非專門延請，唯恐漫不經心遺忘了。後面說明鞋履的作淨方法。在「錢寶法」中，最初提出標目。「律……」以下，展示作法。「守園人」，就是《戒經》中所說的「僧伽藍民」寺院僕役。經文中只說「攜帶前往」，並未挑明是自己還是別人，所以下方依照義理並根據律文來作決斷。「令知是物」，是指必須預先說出如法的「淨語」。

【1283-0008】資持記/13c_下一#48
【原文】恐謂不開，故特注之。《十誦》，初約呵責失。施主下，次約主亡失。注中，初重斥。彼謂實淨物屬於他，故須更說；展轉在己，故不須之。然上《十誦》真實主亡，物不入僧，可驗二淨並是屬己；義無偏判，故再斥之。又下，和會，初示相違。上文即前簡人中《十誦》文也。或下，義詳《五分》。
【譯文】唯恐有人誤以為完全不開許，所以特別加注說明。《十誦律》最初依據呵責而失去效力；「施主……」以下，接著依據主人亡故而失去效力。注文中，最初再次斥責。那些人認為真實淨的物品歸屬於他人，所以必須重新說淨；展轉淨的物品仍歸自己，所以不需要如此。然而上方《十誦律》說真實淨主亡故，物品並不沒入常住僧物，這足以檢驗兩種淨法其實都是歸屬於自己；義理上沒有偏頗評判的道理，所以再次痛加斥責。「又……」以下，進行調和融會，起初指出條文的相違之處。上文就是指前面簡擇人員中的《十誦律》條文；「或……」以下，依義理詳細探討《五分律》。
