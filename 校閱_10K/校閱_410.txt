# 校閱材料　第410檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【410-0001】02_戒疏/04b_卷一下之二#89
【原文】【記】次科。言「寬狹」者，謂異境多少也。初明剋心寬。「王、非、畜、杌」，即四異境。次明漫心狹。「杌境輕」者，非情無過，止有方便。上據大漫。若約小漫，如欲通害人趣，望剋為狹，對大猶寬。「乃至」下，此明境差，想疑二位，並通。剋漫二心，寬狹義同，故言「可解」。
【譯文】【記文】第二科。所謂「寬狹」，是指替代境界的多少。首先說明剋心境界較寬。「李四、非人、畜生、枯木」，就是四種替代異境。其次說明漫心境界較狹。「枯木境輕」，是因為無情物不生重過，只結方便罪。以上是就大漫心（不論何境皆殺）而言。如果是就小漫心來說，例如想要普遍殺害一切人類，相較於剋心而言較狹，但相對於大漫心而言仍然算寬。「乃至」以下，說明境差、想差、疑心這三個項目，都通於剋心與漫心二者，其寬狹之義完全相同，所以說「可以理解」。

【410-0009】02_戒疏/04b_卷一下之二#97
【原文】【疏】答：「出在《律》文境想五句。以彼文言『人，非人想』、『人，非人疑』，即是向述想、疑二位。『非人，人想』，則是境差，如前所指。餘四方便，義通剋漫，境想無文。是故《律》云『不成，偷蘭』，則攝四位，可以知也。」
【譯文】【疏文】答：「出自《律》文中的境想五句。因為律文中說『是人，作非人想』、『是人，作非人疑』，這就是剛才所陳述的想差、疑心兩項。『是非人，作人想』，則屬於境界差錯，如前文所指示。其餘四種方便，義理上通於剋心與漫心，在境想文中並無明文。因此《律》中說『若事未成，犯偷蘭遮』，這句話就包攬了這四種情況，由此便可以知道了。」

【410-0010】02_戒疏/04b_卷一下之二#98
【原文】【記】宗致者，顯示七緣，皆有誠據。「宗」，即文之所出，「致」，謂立之所以。問意可見。答中，初指三種所出。「《律》中境想五句」：初、人作人想，夷；二、人作非人疑，蘭；三、人作非人想，蘭；四、非人人想，蘭；五、非人非人疑，蘭。「餘」下，次明四種義立。「剋」、「漫」二位，本出境想，今此四緣，皆可具之，故云「義通」，則明境想有義無文也。「是」下，指通文以攝。由此四緣，皆不至果，故可通準「不成」之文。私謂「闕比丘緣」，準諸戒末並云「顛狂、心亂，痛惱所纏」，即其文矣。
【譯文】【記文】宗致，是指顯示這七種緣皆有確實的依據。「宗」是經律文字的出處，「致」是指設立的緣由道理。提問的用意顯而易見。回答中，首先指出其中三種的出處。《律》中的境想五句是：一、是人而作人想，犯波羅夷；二、是人而作非人疑，犯偷蘭遮；三、是人而作非人想，犯偷蘭遮；四、是非人而作人想，犯偷蘭遮；五、是非人而作非人疑，犯偷蘭遮。「餘」字以下，接著說明其餘四種是依義理設立。「剋心」與「漫心」兩種心態，原本出自境想條文，如今這四種緣，都可以具備這兩種心態，所以說「義理相通」，這說明了在境想文中有其義理而無特定死文字。「是」字以下，指出共通的律文來收攝。由於這四種緣，最終都沒有達到究竟果罪，所以可以通盤準用律中「不成，偷蘭」的經文。我私下認為「缺比丘緣」，準照各條戒律末尾皆說「精神發狂、心智散亂、被極度痛苦逼惱所纏」，就是該項的律文依據了。

【410-0015】02_戒疏/04b_卷一下之二#103
【原文】【記】名字中。「名」即是「字」，無別所以，不必強分。然須先了二名，並依受體而立。由本受時，不出二心，一者斷惡，二者修善。所發業性，即本願體。隨中守護，對分兩持，違反本受，即戒兩犯。
【譯文】【記文】在名稱之中。「名」就是「字」，沒有別的深意，不必強行分別。然而必須先明瞭這兩個名稱，都是依託所受的戒體而建立。因為最初受戒之時，不外乎兩種心願：一是斷除一切惡，二是修持一切善。內心所生起的業性，就是原本誓願的戒體。在隨後的行持中加以守護，對應劃分為兩種「持」；違背了最初所受的誓願，那就是戒律上的兩種「犯」。

【410-0017】02_戒疏/04b_卷一下之二#105
【原文】【疏】所言「止」者，方便正念，護本所受，禁防身口，不造諸惡，目之為「止」。止而無違，戒體光潔，順本所受，稱之曰「持」。持由止成，號「止持戒」。如初篇等，可以自明。此對不作惡法為宗。
【譯文】【疏文】所說的「止」，是指運用善巧方便提起正念，守護原本所領受的戒體，禁阻防範身口二業，不去造作種種惡行，將此指稱為「止」。能止惡而無所違犯，戒體清光皎潔，順從了原本所受之戒，稱之為「持」。持戒是藉由止惡而成立的，所以號稱「止持戒」。例如初篇波羅夷等戒，看其戒相自然就能明白。這是以「不造作惡法」為其宗旨。

【410-0018】02_戒疏/04b_卷一下之二#106
【原文】【記】止持中二。初牒名，「方」下，釋五節。初釋止義。言「方便」者，或但攝心離過，或復修諸對治。「止而」下，明持義。「持由」下，總合。「如」下，舉事以顯。「此」下，指歸行宗。所以爾者，欲使四行無濫故。
【譯文】【記文】在止持之中分為兩段。最初列出名稱，「方」字以下，分為五節來解釋。首先解釋「止」的意義。所謂「方便」，或者是僅僅收攝身心遠離過失，或者是進一步修習種種對治之法。「止而」以下，說明「持」的意義。「持由」以下，總合二字。「如」以下，舉出具體事相來顯明。「此」以下，指歸修行的宗旨。之所以要如此，是為了使四種行相不相混淆。
