整體看下來，譯文流暢、術語括注（僧次、四等觀、生藏熟藏、尸羅）大體到位，主要毛病集中在兩類：**（A）幾處句意讀錯或位移**、**（B）形容詞、副詞大量添譯，把平實的律文譯成誇飾語**。以下按輕重分列。

---

## 一、語意偏離（建議必改）

**1.《五分》「若坐禪、誦經、檢校僧事，並為解脫出家者」**
- 譯文：「如果是**為了**坐禪、誦經、監察護持僧團事務……」
- 問題：這三者是「所作之事／這一類人」，不是「出家的目的」。原文是說：坐禪者、誦經者、檢校僧事者，**這些人都算是為解脫出家**，故聽受僧次請。譯成「為了坐禪而出家」邏輯顛倒。另「檢校」是管理、營辦，非「監察護持」。
- 建議：「若是坐禪、誦經、料理僧事之人，這些都屬於為解脫而出家者，聽許受僧次請。」

**2.《中含》「下極至邊者」**
- 譯文：「最卑下屈辱、**走向極端**的」
- 問題：「至邊」是「至於邊際、到極點」，修飾「下極」，不是「偏激、走極端」。
- 建議：「最下劣、卑賤到極點的，就是沿門乞食。」

**3. 結勸「口口緣之」**
- 譯文：「每一口吞嚥皆心緣**正法**」
- 問題：「之」直指前句「五觀」，不宜擴大為「正法」。
- 建議：「每一口都緣念這五觀。」

**4.《毘尼母》三處「作念」**
- 譯文：「提起正念**說**」「作念**說**」
- 問題：「作念」是心中作意、默念，不是出聲說；「云／言」只是引出所念內容。另「房作念言」是**對房舍的受用**作念，不必限定為「入房時」。
- 建議：「（受用）衣服時應當作這樣的念想：只為除寒熱、遮羞恥……」

**5.《五百問》「取衣作法」**
- 譯文：「取其遺留的衣服**如法分配作羯磨**」
- 問題：一是語序不通（「分配作羯磨」）；二是時序錯——僧眾是**取衣要作法處分（尚未分）**，蛇因此才吐毒；譯文像是已分配完畢。
- 建議：「便取他的衣來作法（羯磨），準備處分給眾僧。」

**6.《四分》「趣足而已」**
- 譯文：「只要**充足**即可」
- 問題：「趣」＝但、僅；「趣足」是僅夠、勉強夠用，不是充足。與頭陀少欲語境不合。
- 建議：「只求夠用便罷。」

**7.《四分》「有力無事」**
- 譯文：「體力充足而**內心無事牽擾**」
- 問題：舊解多作「有氣力堪修道、無病患等事」，「內心無事」是心理化引申，宜改或加註存疑。

**8.「傳云：凡食不得過三匙」**
- 譯文擅加「**之初**」。雖避免了「整餐只吃三匙」的誤讀，但仍是添字成義。建議直譯「進食（作三願）以三匙為限」，並加註说明古德法：初進三匙各發一願，其餘菜食則迴向佛道。

## 二、添譯過度（宜刪減，屬系統性問題）

原文多為平實律文，譯文卻自行加了強度與範圍：

| 原文 | 譯文添譯 |
|---|---|
| 為法供養 | 以佛法作為**無上**供養 |
| 迴向佛道 | 迴向**無上**佛道 |
| 起種種煩惱、罪業、受苦果報 | **往往**……**無邊**罪業……**無窮**苦果惡報 |
| 唯是不淨 | **一灘惡臭**不淨之物 |
| 命終入地獄 | 命終之後**直接**墮入地獄 |
| 為除寒熱／風雨／飢渴（三處） | **純粹**是為了…… |
| 好樂衣服，晝夜染著 | **極其**喜好……**緊緊**纏繞 |
| 食知止足 | 適可而止、**知足常樂** |
| 而行思欲 | **營求放縱**思量欲望 |
| 為貪等毒所奪 | **必然**會……奪去**道業功德** |
| 必須準用 | **日常中**必須準照遵奉運用 |

建議一律回歸原文分寸：「無上／無邊／無窮／必然／直接／純粹」等可刪；「貪等毒所奪」作「被貪等毒奪去（正念）」即可。

**名物過度具體化：**
- 「化生蛇」→ 譯「**蟒蛇**」（兩處）：原文只作「蛇」，蟒蛇是特定物種；「化生」若未必取四生義，宜作「轉生為蛇」較穩。
- 「有得道者」→「證得聖道的**高僧**」、「為禿頭擎瓦鉢行」→「**被譏諷為**光頭**和尚**」：「高僧／和尚／被譏諷」皆添。
- 「僧共看之」→「齊來**圍觀**」：語感偏輕，宜「眾僧一同查看」。
- 「火出燒身」→「將自身**焚化**」：焚化＝燒成灰，原文只說燒身，宜「火從身出，燒灼其身」。
- 「毒盛」→「**瞋**毒熾盛至極」：屬引申解，可保留「毒氣熾盛」，瞋毒置括注。

**用詞失準（小）：**
- 「應默然一心」→「沉靜肅穆、端肅一心」：漏掉「**默然不語**」這一層，且「肅」字重複。
- 「淨持威儀」→「清淨守持**僧儀威儀**」：疊贅，作「清淨持守威儀」。
- 「難求、難得、難成辨」三層被壓縮成兩層，宜保留三難。
- 「世間大諱」→「避諱」不如「**忌諱**」；「向來」是添。
- 「為義故受」→「為了**道義**」：易誤讀為世間道義，宜「為（解脫之）義利」。
- 「聽餘事」→「其他**便宜**之事」：語感偏現代，宜「其他（衣食受用）之事」。
- 「雜出諸法」→「雜錄各項**法規**」：法律味太重，宜「雜明其他相關行法」。
- 「二列數明體」是並列二事（列其數、明其體），譯成「列出數量**以**說明行體」變成目的關係。

## 三、體例與 245-0004

1. **偈頌未白話**：「多食致病苦……如秤無高下」「是身如車……等同調滑」兩偈照抄原文，與全篇白話體例不一致，建議補譯或至少加白話串講（如：身如車，不擇好壞燃料；香油與臭脂，同樣起潤滑作用）。
2. **「乃至」照抄**：「比丘**乃至**說出偈頌道」——此「乃至」是鈔主省略故事的略詞，白話宜作「（事詳彼經，中略）比丘最後說偈道」。
3. **「夫報力增上，行成精潔」**：譯「**依憑**增上的果報之力」把並列兩句改成因果依存，屬添譯；「夫」是發語詞，「大凡」亦可商。建議：「（行頭陀者）果報身心之力強勝，行持精純潔淨。」
4. 「故凡所制者，並為多貪」宜點出「多貪**之人**」；「凡開教中，先揚此行」可補足語意：「凡在開許放寬的教法中，也先稱揚頭陀行（以為準的）。」
5. 生藏／熟藏括注胃／腸屬傳統對譯，可保留，建議加「依古說」二字。
6. 「五明隨治雜相」可補科判定位（〈對施興治篇〉第五科），讀者較易接上下文。

## 四、示例修訂（供參）

> 《五分律》說：若不是為求解脫而出家的人，不得受請；若是坐禪、誦經、料理僧事之人，這些都屬為解脫而出家者，聽許受僧次請。

> 《中阿含經》說：佛告諸比丘：在種種謀生方式中，最下劣、卑賤到極點的，就是沿門乞食；這是世間極大的忌諱——禿頭、擎著瓦缽而行乞。那些族姓子為（解脫）義利之故才受此法，因為厭患生老病死等諸苦惱。若愚人出家後仍思念欲事、持戒懈怠慢緩，就如以穢洗穢，怎能得脫！

> 前面已具列正教，必須準照奉行；臨食提起五觀，每一口都緣念此五觀；若正念時得時失，便被貪等毒所奪。

**結論**：無重大教理錯誤，但有 6–8 處句意需修正（尤以《五分》三事、「下極至邊」、「口口緣之」、「作念」、「取衣作法」為要），以及全篇性的誇飾添譯需收斂。修掉這兩類，譯文品質會明顯提升。
