# 校閱材料　第165檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【165-0001】02_戒疏/02c_卷一上之二#100
【原文】【記】廣相中，初總示。「初」下，別釋。此之三位，皆通六聚，文中且據「初篇」示相。「篇聚」名如後釋。「報」中，文列四重歲數，即墮𦦨熱地獄。僧殘二百三十億四十千歲，墮大叫獄；偷蘭五十七億六十千歲，墮嘷叫獄；波逸提十四億四十千歲，墮眾合獄；提舍尼三億六十千歲，墮黑繩獄；吉羅九百千歲，墮等活獄。餘如《事鈔》。治廣中，「治」含罰懺，文舉初篇，「永棄」即滅擯，「盡形」即學悔。七九治法，通該六聚，如《鈔．僧網》中。僧殘已下，眾、別悔法，廣如《懺篇》。「略」下，對略結顯。但此三種，在乎略教，蘊而未彰，故皆名「略」。
【譯文】【記文】在說明廣教行相的段落中，首先是總體開示。「第一」以下，是分別解釋。這三種層面其實貫通了全部六聚罪法，經文中暫且只是依據「第一篇」（四波羅夷）來展示具體行相。「篇聚」的具體名稱如同後文的解釋。在「果報」的內容中，文中列出了犯下四重罪的受苦年數，死後會墮入極熱地獄。犯僧殘罪會受報二百三十億四萬歲，墮入大叫地獄；犯偷蘭遮罪受報五十七億六萬歲，墮入嗥叫地獄；犯波逸提罪受報十四億四萬歲，墮入眾合地獄；犯提舍尼罪受報三億六萬歲，墮入黑繩地獄；犯突吉羅罪受報九十萬歲，墮入等活地獄。其餘細節如同《行事鈔》所述。在「處治廣」中，「處治」包含懲處處分與懺悔法，文中舉出第一篇為例，「永遠廢棄」就是指滅擯逐出僧團，「盡其一生」就是指學悔法。僧團懲罰的七種、九種治罪之法，通通涵蓋了六聚罪過，如同《行事鈔．僧網篇》中所說。僧殘罪以下的各種個人或大眾的懺悔方法，詳細內容如同《懺六聚篇》所述。「略教」以下，是相對於略教來作結尾顯明。只是這三種層面的內容在略教之中全被蘊含而未顯彰出來，所以統統稱之為「略」。

【165-0004】02_戒疏/02c_卷一上之二#103
【原文】【疏】答：「聖人布教，義不徒然，藥病相投，是其宗趣，故初不說，止是無機。所以《善見論》云：『若滿未起，輒先制者，生誹謗故。「我等出家，棄捨財色，於世名利無所希求，云何如來反以木叉繫縛我等？豈謂善識世人心器？」又於佛說不生敬重，令法疾滅。故不先制，待犯便制，則知聖恩，如醫破癰，待熟方舉。』」
【譯文】【疏文】回答：「聖人鋪設教化，其義理絕不會無端空設，如同給藥必須完全對應病症，這才是教化的根本宗趣，所以最初之所以不說廣教，純粹是因為當時還沒有那樣的根機。因此《善見論》說：『如果時機尚未成熟、尚未有人犯過，就貿然預先制訂戒律的話，會引起眾生生起誹謗，他們會說：「我們出家修道，連世間的財富與美色都捨棄了，對於世俗的名利毫無希求，為什麼如來反而用戒律木叉來捆綁束縛我們呢？這難道能算是善於辨識世間眾生的根器器量嗎？」同時他們對於佛陀所宣說的法也不會生起恭敬重戴之心，這樣反而會讓正法迅速滅亡。所以佛陀不在事前預先制戒，必須等到有人犯錯了隨即才制定戒條，這樣大家才會深切體會到聖人的深恩，就如同良醫要切開癰疽膿包，一定要等到濃瘡成熟化膿之後才會動手下針。』」」

【165-0005】02_戒疏/02c_卷一上之二#104
【原文】【記】答中，初敘教主知機。時機多利，奉略無違，故云「無機」。「所」下，引證。《論》有二意，初明生謗，即止惡意。「我等」已下，出其謗詞。「又」下，次明起敬住法，即生善意。「如」下，舉喻，於義易曉。「舉」謂以針刺也。
【譯文】【記文】在回答的段落中，首先敘述作為教主的佛陀深知受教者的根機。最初的求道機緣多為利根之人，奉持略教便毫無違犯，所以說是「沒有機緣」。「因此」以下，引用論典作為證明。《善見論》包含了兩層用意，首先是說明會引發毀謗，這屬於止惡的用意。「我們出家」以下，引述那些毀謗之詞。「同時」以下，接著說明能讓人升起敬重並令正法久住，這屬於生善的用意。「就如同」以下，舉出治病的譬喻，在義理上顯淺易懂。「下針」就是指用醫療針去挑刺患部。

【165-0012】02_戒疏/02c_卷一上之二#111
【原文】【記】定相，明略中，初科。四略，前二舉廣及釋。「呵欲」，文見「婬戒」。「勸修」亦初戒緣，云「當於如來清淨法中，於欲無欲」等。「修捨」即是「止觀」。「止」謂「捨」惡，對下「三毒」；「觀」即「修」行，對下「三善」。後二引略順釋。三指釋迦佛偈，四即迦葉佛偈。「《阿含》解」者，彼云：「『諸惡莫作』，淨戒具足，清白之行；『眾善奉行』，心意清淨；『自淨其意』，除邪顛倒；『是諸佛教』，去愚惑想。」
【譯文】【記文】在判定相貌、闡明「略教」的段落中，這是第一科。這四種簡略的相貌中，前兩種是借用廣教的經文與解釋來顯明。「斥責情欲」的經文見於「婬戒」。「勸導修捨」也是最初制定婬戒的因緣，經文說「應當在如來清淨的正法之中，面對欲望而心無欲望」等等。「修捨」指的就是「止觀」。「止」是指「捨離」惡行，對應後文的「斷三毒」；「觀」是指「修持」正行，對應後文的「修三善」。後兩種是直接引述略教經文予以順勢解說。第三種是指釋迦牟尼佛的偈頌，第四種是指迦葉佛的偈頌。「《阿含經》的解釋」是說，該經指出：「『諸惡莫作』是指具足清淨戒律、行持皎潔清白；『眾善奉行』是指心念意向徹底清淨；『自淨其意』是指除去邪妄與顛倒見解；『這是一切諸佛的教導』是指拔除愚昧與惑亂的妄想。」

【165-0013】02_戒疏/02c_卷一上之二#112
【原文】【疏】上明四略，義通道俗。約教被人，第三略中，教設在道。取其行方，理通於俗，亦不可怪。如初篇戒，過體則通；取其聲教，兩分其位。各有理也。
【譯文】【疏文】上面所說的四種略教行相，其義理本來就通貫於出家人與在家人。但如果就教法所主要應用的對象來說，第三種略教行相，其教法本來是為了出家道眾所設立的。若是採取其修行準則的角度來看，義理上通達於在家人，這也是不足為奇的。正如第一篇戒律中的罪過本質是共通的；若就具體的言聲名教制度來看，則將在家人與出家人分別劃分為不同位次。這兩種說法都各有其道理。

【165-0014】02_戒疏/02c_卷一上之二#113
【原文】【記】總判中。初示四門俱通。「約」下，簡第三通局。初明教局，本被道眾。「取」下，次明行通。由無罪聚，同十業故。「方」，法也。「如」下，引例。過通教局，義無異故。「五」、「八」俗教，篇聚道教，故云「兩分」。如前二判，義無去取，故云「各有理」也。

【165-0025】02_戒疏/02c_卷一上之二#124
【原文】【疏】初、根條異：略教不待犯制，根本法輪；廣教略壞方有，則枝條也。二、為人異：略教利機，無過可起；廣教待犯，犯必鈍根。三、對過異：略教不因過制，無問自說；廣教必待犯後，制通淨穢。四、請不請異：廣必待請，如補壞衣；略不待請，一往便說。
【譯文】【疏文】第一、根本與枝葉的差別：略教不需要等待有人犯戒就預先制定，是根本的核心法輪；廣教則是略教遭毀壞之後才衍生出現的，屬於枝末的教法。第二、所針對的對象差別：略教針對的是利根之人，他們內心本來就不會生起過失；廣教則必須等待有人犯戒，而犯戒者必定屬於鈍根之人。第三、對應過失的方式差別：略教並不是因為犯過而制定，是佛陀不待他人提問而主動開演的；廣教則必定要等待犯戒行為發生之後，其規範同時通貫於清淨者與染汙者。第四、經由請法與未經請法的差別：廣教必定要等待他人請法才會制定，如同衣服破了才請求補綴；略教則不需要等待請法，佛陀直接主動就宣說開示。

【165-0026】02_戒疏/02c_卷一上之二#125
【原文】【記】別釋有四。初、後約教，中二在機。初云「根本」者，能生廣故；「法輪」者，摧業惑故。三中「廣通淨穢」，即顯略教純被淨也。四中，《律》明舍利弗請佛制廣，故言「待請」。「補衣」之喻，即佛答詞。

【165-0030】02_戒疏/02c_卷一上之二#129
【原文】【疏】一、以時機須爾：末代鈍根，聞廣如睡，故聖前演，望有欽承；若為說略，則用全疎，微被少機，不可不用。二、隱顯故爾：廣教相彰，化用形勝，故前；略題三業，義通須後。三、功強故爾：略教既壞，制廣還興，從興攝護，功成先說；略教不爾，無補廣之能，且順別機，故須後說。
【譯文】【疏文】第一、因為時代根機必須如此：末法時代的鈍根之人，聽聞詳細的廣教條文尚且昏昏欲睡，所以聖人必須先宣演詳細的廣教，期望眾人能生起欽受奉行的敬畏心；如果一開始就只對他們宣說簡略的教法，那麼對於整體的戒律防護就會完全疏失，略教只能極其微細地利益極少數利根之人，但也不能完全棄置不用。第二、因為教相有隱蔽與顯露的緣故：廣教的法相分明顯露，其教化功用相形之下更為顯著殊勝，所以應當擺在前面；略教只概括性地提出三業防護，其義理涵融深邃，理應放在後面。第三、因為功用強弱不同的緣故：略教的綱領一旦毀壞，制定廣教就能讓戒律重新興盛，順應這種振興而產生的攝受防護功能，既然功德宏大就應當先說；略教則不具備這種力量，它沒有回頭補救廣教虧缺的能耐，而且只能隨順極少數特殊根機，所以必須放在後面宣說。
