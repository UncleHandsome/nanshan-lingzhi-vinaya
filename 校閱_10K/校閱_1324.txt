# 校閱材料　第1324檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1324-0001】資持記/15a_下三#52
【原文】四中，《四分》，初引緣。佛下，明設教，初句立制。應下，教修。思惟即修觀。此中不明，故指如後，即〈主客篇〉四儀法中。〔或指〈沙彌篇〉三觀。〕《智論》中，初讚坐法。求下，誡睡眠。大事，即指聖道。伺，候也。即經云：無以睡眠因緣令一生空過，無所得也；
【譯文】第四段中，《四分律》起初引述因緣。「佛」字以下，說明設立教法，第一句立下制度。「應」字以下，教導如何修習。「思惟」就是修習觀照。這裏沒有詳細說明，所以指示參見後文，也就是〈主客篇〉四威儀法之中（或者是指〈沙彌篇〉的三觀）。《大智度論》中，首先讚歎坐禪之法。「求」字以下，告誡提防睡眠。「大事」，就是指成辦聖道。「伺」，是窺伺守候的意思。正如佛經說：不要因為睡眠的因緣，讓一生虛度空過而一無所獲；

【1324-0002】資持記/15a_下三#53
【原文】又云：諸煩惱賊，常伺殺人，甚於怨家；安可睡眠，不自警悟等。若下，教臥法。脇不著席，謂倚臥也。三諸部中，《母論》。對食治瞋，折挫煩惱，即為上行。《智論》。斷漿，十二之外。不一心者，彼云：因飲漿故，遂求種種漿；謂果漿蜜漿等，如馬不著勒，左右噉草，不肯進路；若著勒，則噉草意斷。《寶雲經》。
【譯文】又說：各種煩惱盜賊，常在暗中窺伺想要害人性命，比怨家仇敵還要厲害；怎麼可以昏昏大睡，不讓自己警惕醒悟呢！「若」字以下，教導臥睡的方法。身側脅肋不沾臥席（即不倒臥在席上），意思是靠著坐具倚臥。在第三項諸部派異行中，《母論》說：面對飲食調伏瞋心，折服挫敗煩惱，這就屬於上等行持。《大智度論》中：斷除飲漿，是在十二頭陀行之外的法門。「不一心」，那部論說：因為喝漿湯的緣故，隨即追求各種各樣的漿湯；比如水果漿、蜂蜜漿等，就像馬沒有套上轡頭，在路左右亂吃雜草，不肯前行趕路；如果戴上了轡頭，吃草的念頭就會斷除。《寶雲經》中。

【1324-0003】資持記/15a_下三#54
【原文】四分之一，即乞食別行。初正示行相。匃音蓋，亦乞也。與鬼神者，即今施食。若下，因引乞法。先破禁戒者，或在家破五八，或出家反道者。可譏嫌處，即婬女家酒肆等。十住中。彼無餘食一揣，故有此二，與上不同。各有十利者，彼云：受毳衣有十利：一在麁衣數〔謂同糞掃衣行。
【譯文】四分之一，屬於乞食中的個別行持。首先正式指出行持的相貌。「匃」字音同蓋，也是乞求的意思。施捨給鬼神，就是現今的放蒙山施食。「若」字以下，順帶引述乞食的方法。「先破禁戒者」，或者是在家時破了五戒八戒，或者是出家後退失道心還俗的人。「可譏嫌處」，就是指妓院、酒肆之類的地方。《十住婆沙論》中。那部論沒有「不受食後食」和「一摶食」，所以列有這兩種，與上面不同。各自具有十種利益，那部論說：受持毳衣（毛布衣）有十種利益：一是列入粗劣衣服的範圍（意思是等同於糞掃衣的修行）；

【1324-0004】資持記/15a_下三#55
【原文】二少求索，三隨意可坐，四隨意可臥，五浣濯則易，六染時亦易，七少有虫壞，八難壞，九更不受餘衣，十不失求道。食後不受非時飲食有十利：一不多食，二不滿食，三不貪美味，四少所求欲，五少妨患，六少疾疾，七易滿，八易養，九知足，十禪誦身不疲極。《解脫道論》。
【譯文】二是很少對外索求，三是隨心意可以隨處坐下，四是隨心意可以隨處躺臥，五是清洗起來很容易，六是染色時也很容易，七是很少被蟲蟻蛀壞，八是不容易破損，九是不會再去接受多餘的衣服，十是不會喪失修道之心。吃過飯後不再接受非時的飲食有十種利益：一是不會吃得過多，二是不會吃得過飽，三是不貪求美味，四是很少有所追求貪欲，五是很少有妨礙患難，六是很少罹患疾病，七是容易滿足，八是容易撫養，九是知足常樂，十是坐禪誦經身體不會感到疲勞之極。《解脫道論》中。

【1324-0005】資持記/15a_下三#56
【原文】彼云：一法衣相應，謂糞衣、及三衣〔即衣二也〕；五法食相應，謂乞食、次第乞、一坐、節量、時後不食〔食五是也〕；五法坐臥相應，無事處〔蘭若〕、樹下、露地、塚間、遇得處〔處五是也〕；一勇猛相應，謂常坐不臥。然是勇猛之一事，故加之分二字。〔食中多次第乞，餘同《四分》。〕《十誦》。
【譯文】那部論說：一種是與法衣相應，是指糞掃衣以及但三衣（就是屬於衣的兩項）；五種是與食物相應，是指常乞食、次第乞、一坐食、節量食、時後不食（食物五項正是這些）；五種是與坐臥處所相應，是指無事處（阿蘭若）、樹下坐、露地坐、塚間住、遇得處坐（處所五項正是這些）；一種是與勇猛精進相應，是指常坐不臥。然而這只是勇猛精進中的一件事，所以加上了「之分」兩個字（飲食項中多出了次第乞食，其餘與《四分律》相同）。《十誦律》中。

【1324-0006】資持記/15a_下三#57
【原文】多雨處，四月在露，即冬分也；八月在覆，春夏雨多也。少雨反前者，冬春八月在露，夏四月在覆。結指中，初指前列。統下，揀諸文。彼論先總列名，次總顯相，後逐行別明；一一行中，竝先示過，二明受，三顯德，四辨失，故云次第詳悉等。
【譯文】多雨的地方，四個月在露天，也就是冬季；八個月在有掩蔽的地方，因為春夏兩季雨水多。雨水少的地方則與之相反，冬春八個月在露天，夏天四個月在掩蔽處。在結尾指示（結指）中，首先指示前面的羅列說明。「統」字以下，辨析簡別各部文獻。那部論先是總體列出名稱，次總體顯明行相，最後逐條行持分別說明；每一項行持之中，全都是先指明過患，第二說明如何受持，第三顯明功德，第四辨識失缺，所以說次序詳盡周全等等。

【1324-0007】資持記/15a_下三#58
【原文】且略引示，彼云：云何受乞食，若受他請，則妨自業〔示過〕；我從今日斷受他請，受乞食法。〔此郎受法，餘行，竝準此立誓受行，若不行，準下《五分》須捨。〕云何功德？依心所願，進止自由，銷除懈怠，斷滅憍慢〔顯德〕；若受他請，是失乞食〔辨失〕；餘行竝爾，具見第二，須者尋看。四中。
【譯文】暫且大略引用指示，那部論說：怎樣受持乞食法？如果接受他人的請召，就會妨礙自己的道業（指出過失）；我從今天起斷除接受他人的供請，受持常乞食之法（這就是受持的方法；其餘各項行持，全都要依此立下誓願受持修行，如果不修行，依照下文《五分律》必須作法捨去）。什麼是功德？依循內心的願望，行動進退自由自在，消除懈怠，斷滅傲慢（顯明功德）；如果接受了他人的供請，這就失去了乞食頭陀行（辨識失缺）；其餘行持全都是這樣，詳細內容見於該論第二卷，需要的人可以去查閱。第四部分。

【1324-0008】資持記/15a_下三#59
【原文】雜法，即蘭若中所須之事。初中，《四分》，前明備所須。若見下，次明待同學；又三，初迎接。令其下，浣濯。便授下，與食。有餘下，三明食已法。與人，即乞匃者。非人，即施鬼神禽畜等。淨地水中，或無人畜；留置淨處，擬後施故。有賊下，四明待賊法。制知時節，防賊難故。下引《十誦》。
【譯文】「雜法」，就是指在阿蘭若中所必需具備的事務。第一段中，《四分律》前面說明備辦生活必需品。「若見」以下，其次說明接待同修道友；又分為三點：首先是迎接入內；「令其」以下，是說明洗滌（如備水給客僧洗足、主僧洗手等事）；「便授」以下，是給予飲食。「有餘」以下，第三說明吃完飯後的規矩。分給「人」，就是指乞丐；分給「非人」，就是施捨給鬼神、鳥獸等。乾淨的地面或水中，有時可能沒有人或動物；放置在乾淨的地方，準備留待日後布施。「有賊」以下，第四說明防備盜賊的方法。規定要知曉時令節氣，是為了防備盜賊之難。下面引用《十誦律》。

【1324-0009】資持記/15a_下三#60
【原文】文證可知。星經，即陰陽書。下指《四分》，即留食等。二中。謂以木鑽鑽木，則有火出。火珠，即水精珠，日光照之，用艾引火；恐同出術，故開屏用。三中。前明頭陀，是今所用；後讀誦等，因之而引。如上等人放免差次，加分與物；皆謂推尊有德，誘進後人故也。四中。
【譯文】引用的文證可以明白。「星經」，就是推算陰陽曆數的書籍。下文指示《四分律》，就是指留存飲食等法。第二段中。是指用木鑽鑽擊木頭，就會生出火來。「火珠」，就是水晶珠，讓日光照射它，用艾絨引導生火；唯恐被當作施展幻術，所以開許在遮蔽處使用。第三段中。前面說明頭陀行，是現在所要適用的；後面讀誦經文等，是順帶引出的。對於上述這些有德之人免除當值輪差、多分給物品，全都是為了推崇尊重有德行者，誘導勉勵後進之人的緣故。第四段中。
