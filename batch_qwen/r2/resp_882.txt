整體讀來通順，理解方向大致正確，但有幾處**實詞誤讀**與**典故漏譯**，另有若干贅字、錯字與術語前後不一致。依段列出：

## 【882-0001】

| 問題 | 說明／建議 |
|---|---|
| ⚠️「遠觀化表」→「遊方遠觀教化境外」 | 這是本段最不通的一句。「化表」即「化外」，指教化不及的邊遠之地（泌部山在山西，相對於京師為邊地）。建議改作「**遠遊化外邊遠之地**」，並加註。 |
| ✏️「操觚染翰」→「提筆蘸墨」 | 「觚」是書寫用的木簡，「操觚」本指持簡作文。可作「**執簡（筆）濡墨**」，較存原意象。 |
| ✏️「筋脈相通」→「脈絡筋骨相通」 | 原文只作「筋脈」，不必添「骨」。作「**筋脈連貫相通**」即可。 |
| ✏️「後批」 | 宜註明是 **《事鈔》卷末道宣自題的批記**，否則讀者不知「後面的題記」是哪本書的。 |
| 💡可加註 | 史實上武德九年（626）八月太宗即位，**翌年**才改元貞觀。元照說「即改」是約其年相接而言，譯文照譯無妨，但可加一註避免誤解。 |
| ✅ | 「為擇律師」正確讀成人名（未誤作「挑選律師」），這點處理得好。 |

## 【882-0003】

| 問題 | 說明／建議 |
|---|---|
| ❌「非凡小心力所及」→「凡夫狹隘的心力」 | **「凡小」是「凡夫與小乘（二乘）」的固定簡稱**，不是「凡夫渺小」。應作「**絕非凡夫與二乘人的心力所能企及**」。這是本段最要緊的誤譯。 |
| ❌「冠為首飾」→「頭部首要的裝飾」 | 「首飾」＝頭上的飾物（首服），非「首要之飾」。改「**冠是頭上的飾物**」。 |

| ⚠️「理必兼之」→「義理必定兩者兼具」 | 「兩者」未交代是哪兩者。應明說：「**文句雖只局於『難思』，義理上必定兼含『難議』**」。 |
| ✏️「戒有四義」→「戒法具備四種涵義：戒法、戒體……」 | 以「戒法」作總稱又列為四義之一，邏輯打轉。改「 **『戒』有四義**」。 |
| ✏️「心思切近，口議疎遠」 | 「切近切要」語意含混。建議：「**心念思慮對境較為直接切近，口中議論則較疏遠間接**」。 |

| 問題 | 說明／建議 |

| ❌「雙樹重扶」→「在娑羅雙樹間最後垂範護持」 | **典故漏譯**。「雙樹」借指**涅槃會上／《涅槃經》**；「重扶」即 **「扶律談常」**——涅槃重扶戒律而談常住。應譯：「**若就涅槃會上重扶戒律（扶律談常）而言，則一切同歸常住佛性**」。現譯「最後垂範護持」語意空泛，讀者無法接上「咸歸常住」的推論。 |

## 綜合建議

1. **必改的实质錯誤**：凡小（#52）、如頭／王好國（#54）、雙樹重扶（#57）、遠觀化表（#50）。這四處會影響讀者對義理的理解。
2. **錯／衍字**：乘載→承載、鎖系→鎖繫、歸根結底→歸根結柢、「用心心思量」衍字。
3. **術語統一**：「標歎」一律作「標舉讚歎」；篇名一律用全名（標宗顯德篇、篇聚名報篇）。
4. **科判語的譯法**：「釋成」「冠下一句」「為下」等宜固定譯式（如「解釋以成立上義」「從『為』字以下」），目前 #51 的「是解釋成立」讀來最生硬。
5. **夾註與引文的處理**：#50 引《戒疏》後批、#54 引《戒本》序偈，建議都在註中給出完整原句，譯文才好對照（尤其「如寶求無厭」）。
