# 校閱材料　第462檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【462-0001】資持記/07d_中一下#47
【原文】擲卜，即投杯珓，卜問於神也。捨吝，謂非人護不護也。畜物中，初文。律中，比丘取鳥巢中物，及鼠穴中物，比丘疑，佛言：畜生無用，無犯，而不應受如是物。〔準不應，得吉，但文不顯。〕引古中，初解，上句判犯。故下，引據。律云：時去寺不遠有村，諸鼠往村中，取胡桃來寺內，成大聚；
【譯文】「擲卜」，就是投擲杯珓，占卜叩問神明。「捨吝」，是指非人願意捨棄還是吝嗇守護。在「畜生物產」中，最初文句。戒律中，比丘拿取鳥巢中的物品，以及老鼠洞穴中的物品，比丘心生懷疑，佛陀說：畜生無法受用，不犯重罪，但不應該接納這類物品。〔依準「不應該」這一點，應得突吉羅罪，只是文句沒有明說。〕引證古說中，最初的解釋，上一句判定罪名。接著「所以」以下，引用依據。戒律說：當時離寺院不遠處有一座村莊，諸多老鼠跑到村中，將核桃搬進寺院裡，積聚成一大堆；

【462-0002】資持記/07d_中一下#48
【原文】六群盜心取食，彼疑；佛言：波羅夷。正解中，初通本律犯重之意。以言六群盜心取故，顯知是彼村人之物，故判成重。鼠疑豫者，畜心難辨；但約未藏，或復未食，可以知耳。餘下，引他部定犯。《十誦》中：師子殘不犯者，舊云：此獸不食冷肉，所遺不繫故。第二緣中。律有四句：有主想犯重〔初句〕；
【譯文】六群比丘存著偷盜之心拿來吃，事後懷疑；佛陀說：犯波羅夷罪。正統解釋中，起初通達本律判定重罪的深意。因為說六群比丘是存著「盜心」去拿取，顯然知道那些核桃是村裡人的財物，所以判定構成重罪。至於老鼠猶豫不決，是因為畜生的心思難以辨識；只能從未曾藏妥、或是尚未食用的跡象，來加以推知罷了。接著「其餘」以下，引用其他部派戒律判定罪名。《十誦律》中說：吃獅子殘食不犯戒，古人解釋說：這種野獸不吃冷肉，所遺留下來的肉已經不再心生繫著。第二種因緣中，戒律包含四句：認定有主而取犯重罪〔第一句〕；

【462-0003】資持記/07d_中一下#49
【原文】若疑偷蘭〔次句〕；無主物，有主想疑偷蘭〔三四兩句〕；略無第三無主想句；準下〈持犯〉，義必具之。文中，初標成犯緣，即第一句。若下，簡闕緣，即第三句，初約本迷無犯。前下，據轉想。前作有主想，後轉無主，犯蘭；前作無主想，後轉有主，結夷，故云互得輕重也。疑及境差二句，並見後篇。
【譯文】如果心中懷疑犯偷蘭遮〔第二句〕；無主之物，認定有主或心存懷疑犯偷蘭遮〔第三與第四句〕；文中略去了第三種「認定無主」的文句；依準下文〈持犯篇〉，義理上必須具備此句。文句中，起初標明構成犯罪的因緣，就是第一句。接著「若」字以下，揀選缺少因緣的情況，也就是第三句，起初是就原本誤認而判不犯。接著「前」字以下，依據念頭轉換來判定。先前認定為有主，後來轉變為無主，犯偷蘭遮；先前認定為無主，後來轉變為有主，判定犯波羅夷，所以說「互為輕重之罪」。懷疑以及境界有差錯這兩句，都見於後面的篇章。

【462-0004】資持記/07d_中一下#50
【原文】第三緣，敘意中，初明難護。以貪染積深，觸物起念；麁心不覺，豈識邪緣；不體妄情，終羅罪網；實德尚當未免，庸流沒在其中；凡在同心，彌須勵志。但下，示結業。不望境是非者，境即前物；三寶互用，物無私涉為是，入己惡用為非；二皆結重，故知不簡也。故下，引證。
【譯文】第三種因緣中，敘述大意起初說明難以防護。因為貪愛染著積累深厚，接觸物體就生起念頭；粗疏的心思無法覺察，哪裡能識破邪僻的因緣；不能體察虛妄的心情，終究會陷入罪孽之網；實修有德之士尚且難免犯錯，平庸之輩更沉溺其中；凡是志同道合之人，更加需要惕勵心志。接著「但」以下，明示如何結成罪業。不論對象是與非，「境界」就是指前面所說的物品；三寶物品相互調用，物品完全不涉私利是「是」，納入己身惡意揮霍是「非」；兩者都結犯重罪，所以知道不必分別是否為私。接著「所以」以下，引導作證。

【462-0005】資持記/07d_中一下#51
【原文】望為三寶，故言好心；若論愚教，還是賊心。理下，生後所引。正明中，《十誦》。苦切，謂敦逼前人，同下《四分》迫喝取也。輕慢，謂現相陵物，及下觝突，並同第八〔準疏會之〕。名字同第十。受寄同第七。唯後出息，不同今宗；雖是盜心，彼此相允，故特除之。
【譯文】著眼於為了三寶，所以稱為「善心」；若是就愚昧不知戒律教導而言，終究還是屬於盜心。接著「理」以下，引導出後面所引的內容。正文說明中，《十誦律》的「苦切」，是指逼迫刁難對方，如同下文《四分律》中的強行逼取。「輕慢」，是指顯現傲慢相狀凌辱物主，以及下文的「觝突」，都等同於第八種〔依照戒疏予以融會〕。「名字」等同於第十種。「受寄」等同於第七種。只有後面的放貸生息，與本宗不同；雖然存有盜心，但彼此雙方互相允諾，所以特地予以排除。

【462-0006】資持記/07d_中一下#52
【原文】觝音底。《伽論》中。強奪同下第四〔疏依〕。軟語同辨說。施已還取，與後不同；謂決施與人，後還或取。《善生》同論，注以示之；偷罪，即犯盜也。《五分》中。諂心同下第二〔依疏〕。曲心同第九。瞋心同第三。恐怖同第四。《四分》十種。疏云：律中，具出二五盜心，前是五心，後名五取；
【譯文】「觝」字音底。《伽論》中，「強奪」等同於下文第四種〔戒疏所依據〕。「軟語」等同於善巧辨說。布施之後又強索取回，與後文不同；是指已經決意布施給他人，事後又反悔奪回。《善生經》與該論相同，加注予以明示；所謂「偷罪」，也就是犯盜戒。《五分律》中，「諂心」等同於下文第二種〔依戒疏〕。「曲心」等同於第九種。「瞋心」等同於第三種。「恐怖」等同於第四種。《四分律》列出十種。戒疏說：律文中完整列出兩組五種盜心，前面是五種心思，後面稱為五種取法；

【462-0007】資持記/07d_中一下#53
【原文】取是其業，對境行事也。一中。可學迷者，教是可學，不學故迷。二中。規，求也。壅，猶積也。三中。兩釋，虛實分之。四中。準疏又云：或說王官勢力。此與第八，名同相別；但約心取，兩以分之；言心未必取，言取必兼心。第九。律本注戒及疏，並作見便取；今文多一便字，必是傳誤，不勞異解。
【譯文】「取」是具體的造作，是面對外境付諸行動。第一種中，「可學而迷茫」，戒律教導是可以學習的，因為不去學習所以陷入迷茫。第二種中，「規」是圖謀求取。「壅」就是積聚。第三種中，有兩種解釋，分為虛假與真實兩種情況。第四種中，依照戒疏又說：或者聲稱官方勢力。這與第八種名稱相同而相狀各異；只是就起心與拿取，兩相分開說明；說起心時未必拿取，說拿取時必定兼具起心。第九種。戒本、注戒以及戒疏，都作「見便取」；現在本鈔文字多了一個「便」字，必定是傳抄訛誤，不需要大作其他解釋。

【462-0008】資持記/07d_中一下#54
【原文】〔或可下便字訓即。〕十中。五相釋之，前三身業，後二口業；又前三中，一是倚自，二倚他名，三倚他力；後二中，前但巧言，後是虛誑。今時講士，多尚乞求；諂笑趨時，巧言媚俗；或厚於餉遺，豈避污家；或勤於請謁，寧知屈道；不識者詐識，非親者強親；口說多方，心謀百計；
【譯文】〔或者下面的「便」字可以訓釋為「即」。〕第十種中，以五種相狀來解釋，前三種是身業，後兩種是口業；又在前三種中，第一是依仗自己，第二是依仗他人名聲，第三是依仗他人勢力；後兩種中，前者只是花言巧語，後者則是虛妄欺詐。當今的講經法師，大多崇尚化緣乞討；諂媚歡笑趨炎附勢，巧言令色迎合世俗；或者頻頻餽贈厚禮，哪裡懂得迴避污家之戒；或者殷勤請託拜謁，哪裡知曉屈辱佛道；不認識的人假裝認識，沒有親情的人硬拉關係；口中說出千方百計，心裡謀算百般計策；

【譯文】十方常住僧物，也與這種說法類似。第六句，是指偷盜微少物品卻構成重罪。首先引用《僧祇律》，意思容易理解。其次在《善見律》中，互相教唆偷盜的情況，比如師父教導三個徒弟說：那裡有六錢，年長的拿三錢，年幼的各拿一錢〔教唆別人合計滿五錢〕，我自己拿一錢〔自己的行為不滿五錢〕；甚至小徒弟也說：和尚拿三錢，同學各拿一錢，我自己拿一錢〔罪名也同上面一樣〕。得一個波羅夷罪，是因為教唆他人滿五錢而犯；

【原文】一偷蘭者，自作犯也。自下，釋結蘭義；恐疑共盜，應須犯夷故。第五離處，釋中，初科，《四分》明未離不成。下引《五分》，明已離方成。文列五罪，掘地一提，有無不定；餘四須具，是方便故。盜心吉者，遠方便也。掘地提者，謂生地也。〔《善見》犯吉，是盜方便故。
【譯文】得一個偷蘭遮（重大未遂）罪，是因為自己親手偷盜不足五錢而犯。從此往下，是解釋為何結偷蘭遮罪；這是擔心有人懷疑共同盜竊，理應都犯波羅夷罪的緣故。第五項「離處（脫離原處）」，在解釋中，第一個綱目說明《四分律》認為未脫離原處則盜罪不成。下文引用《五分律》，說明已經脫離原處盜罪才告成立。文中列出五罪，掘地犯波逸提（單墮罪），有無並不固定；其餘四種罪相必須具備，因為它們屬於盜竊的前方便。起盜心犯吉羅（惡作罪），屬於遠方便。掘地犯波逸提，是指掘動未經開墾的生地。〔《善見律》認為只犯吉羅，因為這屬於盜竊的方便行。
