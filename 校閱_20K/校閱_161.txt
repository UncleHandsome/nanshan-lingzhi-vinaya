# 校閱材料　第161檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【161-0001】02_戒疏/02b_卷一上之二#4
【原文】【記】問中。以因分二義，果偏對食，故問釋之。答中，初明法不至果。「筏、藥」二喻，以顯至果，因法無用。「形」下，重示餘三，因必至果。「乃至」者，略前「怖魔」。魔如怨賊，因中怖之，果上已殺。謂斷盡煩惱，不受後陰，永無死苦，天魔反懼，義同殺也。
【譯文】【記文】在問答的設問中。因為在因位中將乞食、乞法分為二義，而果位卻偏偏只對應乞食（應供），所以設立問答來解釋。在回答中，首先說明修法不能延續到果位。「船筏與良藥」這兩個譬喻，是用來顯明達到果位時，因位的修法便不再適用。「肉身」以下，重新開示其餘三個含義，必定能由因位圓滿達至果位。「乃至」這一句，是省略了前面的「怖魔」。魔如同怨賊，行者在因位時畏怖他，到了果位上則已將其誅滅。這是指斷盡一切煩惱，不再招感後世的五陰果報，永遠脫離死亡的痛苦，天魔反而心生恐懼，這在意義上就等同於殺賊。

【161-0009】02_戒疏/02b_卷一上之二#12
【原文】【疏】如《母論》云：「毗尼名『滅』，滅諸惡法，故曰毗尼。」所滅有七，謂犯、諍、煩惱、比丘及尼、少分、一切處也。二百五十戒，為少分也；淨戒、心、慧、微細戒者，是一切處也。
【譯文】【疏文】如同《毗尼母論》所說：「毗尼的名字叫做『滅』，因為能夠滅除一切惡法，所以稱為毗尼。」所要滅除的惡法共有七類，也就是：犯戒、諍事、煩惱、比丘戒、比丘尼戒、少分戒、一切處戒。二百五十條戒相，屬於少分戒；清淨戒、心戒（定共戒）、慧戒（道共戒）、微細戒，則屬於一切處戒。

【161-0010】02_戒疏/02b_卷一上之二#13
【原文】【記】引文中。《母論》先示名。彼云：「毗尼能滅不善根，能滅障法，能滅五蓋惡行，名為毗尼。」今以「諸惡」一句總之。「所滅」下，列相。初、言「犯」者，方便趣果，污體成罪故。《論》云「從犯毗尼，出罪毗尼」是也。二、「諍」者，如四諍起，七毗尼滅，《論》云「能滅鬪諍故」。三、「煩惱」者，《論》云「能斷煩惱故」。四、「比丘」。五、「尼」者，即二眾不同戒。六、「少分」。七、「一切處」。「二」下，別點後二，非出彼論。戒實無量，且據數作，為持犯蹊徑，故云「少分」。「淨戒」即別脫，「心」即定共，「慧」謂道俱。「微細戒」者，總上三種。別脫微細者，謂《戒本》之外，八萬無量塵沙制也。
【譯文】【記文】在引述的論文中。《毗尼母論》首先標明名稱。該論說道：「毗尼能夠滅除不善根，能夠滅除障礙正法的過患，能夠滅除五蓋等惡行，所以稱為毗尼。」現在以「諸惡」這一句話來總括概括。「所滅」以下，逐一列出各種相狀。第一、所謂「犯」，是由於以方便手段趣向罪業結果，染污戒體而結成罪名。《毗尼母論》所說的「從犯戒產生的毗尼，用以出罪消滅的毗尼」指的就是這個。第二、所謂「諍」，例如四種諍事生起時，以七種毗尼來止息滅除，論中說「因為能平息鬥諍」。第三、所謂「煩惱」，論中說「因為能斷除煩惱」。第四、指「比丘」，第五、指「比丘尼」，這代表僧尼二眾各自不同的戒條。第六、指「少分戒」。第七、指「一切處戒」。「二百五十戒」以下，是單獨點明後兩種戒，並非直接出自那部論典。戒法在實質上是無量無邊的，暫且依據條數來制定，作為持戒犯戒的修行軌跡，所以稱為「少分戒」。「清淨戒」就是別解脫戒，「心」就是定共戒，「慧」就是道俱戒。「微細戒」，是總括前面這三種戒。別解脫戒中的微細戒，是指《戒本》條文之外，如同恆河沙數般無量無邊的八萬威儀制規。

【161-0012】02_戒疏/02b_卷一上之二#15

【161-0033】02_戒疏/02b_卷一上之二#36
【原文】【記】五云「五品」者，《論》作「五部」。舊記準《發智論》云：「見苦所斷結，集所斷結，滅所斷結，道所斷結，修所斷結。三界各有五部，成十五部惑。」、「有願」者，具戒方便故；「無願」者，已滿足故。八中，《論》作一處，《疏》加「時」字。「如」下，明處；「昔」下，明時。此二並約「受」、「浴」顯相，餘事準說。
【譯文】【記文】第五項所說的「五品」，在《論》中稱為「五部」。舊日的註記依據《發智論》解釋說：「見苦諦所斷除的結縛，見集諦所斷除的結縛，見滅諦所斷除的結縛，見道諦所斷除的結縛，以及修道所斷除的結縛。欲界、色界、無色界各自具有這五部，合起來成為十五部煩惱惑。」「有願」的意思，是因為它屬於成就具足戒的前行方便；「無願」的意思，是因為戒體已經圓滿具足了。第八項中，《論》中稱為「一處」，本《疏》則額外增加了「時」字。「如」以下，說明處所；「昔」以下，說明時間。這兩項都是依據「受戒」與「洗浴」來顯發其事相特徵，其餘事相可依此類推。

【161-0034】02_戒疏/02b_卷一上之二#37
【原文】【疏】據此九位，罪、惑兩種「滅」義以明；餘有科條，並從「法」也。又解：「罪惑對治，事理多途，若非律教，何得詮別？故通歸『法』，方顯彼此也。」
【譯文】【疏文】依據這九個位階，罪過與惑障這兩項是以「滅除」的意義來闡述；其餘各項科條，全部都歸順於「法則」之義。另一種解釋說：「對治罪過與惑障的事相與理路極其繁多，如果不是藉助戒律的教法，又如何能夠詮釋辨析得清楚？所以應當全部通歸為『法』，才能完全顯發彼此之間的差別。」

【161-0035】02_戒疏/02b_卷一上之二#38
【原文】【記】示名中。先約兩判。「又」下，指歸一義。初示化制相濫。事行治「罪」，理觀治「惑」。事則篇聚重輕，理有性相等別，故云「多途」。「若」下，明律能簡別，故彰「法」義。
【譯文】【記文】在標示名稱的文句中。先依照兩重標準分別評判。「又」字以下，將其統攝指歸到同一個義理上。首先說明化教與制教容易互相混淆。事相修持用以對治「罪過」，理觀智慧用以對治「惑障」。事相上有篇聚的輕重差別，理觀上有法性、法相等層面的不同，所以說「多途」。「若」字以下，說明戒律具有辨析簡別的功能，因此彰顯出「法」的含義。

【161-0040】02_戒疏/02b_卷一上之二#43
【原文】【疏】答：「明義不同，各有兼正。據理深淺、能治功用，戒律指事，伏業方便，故劣明慧；若就住持、建興三寶，則律為勝。由世隨相有，律附緣生，親成大用，故文云『以眾和合故，佛法得久住』也。又約根條，定慧不及，自不能起，必由戒生，如《經》『依因此戒生定慧』等。教據斯義，故弘演之。」
【譯文】【疏文】回答：「所要闡明的意思各有不同，各自兼顧次要與主要。如果單依據義理的深淺、以及能對治惑障的功用來說，戒律偏重於規範事相，只是調伏惡業的方便法門，因此確實遜色於明慧；但如果就住持世間、建立興旺三寶的角度而言，戒律則最為殊勝。因為世俗法是隨著事相而存在的，戒律順應事緣而創立，能直接成就護法的宏大功用，所以律文說『因為大眾僧伽和合的緣故，佛法才能長久住世』。再者，若從根本與枝條的關係來看，定力與智慧不能比擬於戒，定慧自己無法憑空生起，必須依賴戒律才能產生，如佛經所說『依循憑藉此戒律而生起禪定與智慧』等。戒教就是依據這個義理，所以必須宏揚演說。」

【161-0041】02_戒疏/02b_卷一上之二#44
【原文】【記】答中。初通示，「據」下，別釋。先約斷證，推慧為勝。「若」下，次約住持，以明戒勝。初正示。真理體寂，非證不知，外無表示，住持義劣；律相昭顯，故獨標勝。「由」下，釋所以。初句示世諦隨事，對理體空，故言「相有」。次句明教依事立。「緣」即事相；止作二行，竝假眾緣以辨成否。下一句正顯功用，謂眾別兩行，生善滅惡，內軌道眾，外發俗信，維持光遠，功由於此，故云「親成大用」也。「故」下，引證，即「律序」偈。顯示久住，全由眾法，律藏獨勝，文據甚明。「又」下，次約根條，義如卷首「教興意」中。「教」下二句，總結二意，對合文旨。
【譯文】【記文】在回答的文句中。開頭先作通泛開示，「據」字以下進行分別解釋。首先從斷惑證理的角度，推崇智慧最為殊勝。「若」字以下，接著從住持佛法的角度，來闡明戒律的殊勝。先作正面開示。真理之體性是常寂的，非證悟者不能通達，對外沒有具體的表徵，所以住持佛法的功用較弱；而戒律行相昭彰顯露，所以獨自標榜其勝能。「由」字以下，解釋其中的緣由。首句說明世俗諦隨順事相而存，相對於真理體性的空寂而言，所以說是「相有」。次句說明教法是依憑事相而建立的。「緣」就是事相；止惡與行作這兩種實踐，都必須假借眾多條件因緣才能辨明成辦與否。最後一句正面彰顯其功用，說明大眾的羯磨行持與個人的個別行持，能生善滅惡，對內規範僧團大眾，對外啟發世俗信眾的信心，護持佛法並廣大流布，全仰賴這個功德，所以說「親自成就宏大功用」。「故」字以下引文作證，即是出自「律序」中的偈頌。表明正法久住完全仰賴大眾的法事羯磨，律藏的殊勝地位，文獻依據極為明晰。「又」字以下，接著從根本與枝條的角度立論，義理如同卷首「教法興起之由緒」中所闡述。「教」字以下的兩句，總結這兩層涵義，契合經文的主旨。
