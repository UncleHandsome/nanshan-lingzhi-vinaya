# 校閱材料　第143檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【143-0001】01_行事鈔/07b_卷中之三#23
【原文】二別僧、別乞、別請三種。先明別僧，即是僧次。《五分》：僧次請者，凡夫聖人、坐禪誦經、勸佐眾事、並為解脫出家者，得入僧次；唯除惡戒人。若言次第上座者，是僧次攝。又不知齊幾為上座？佛言：上無人者，皆名上座。以法取人，或言禪師等，是別請。若言禪師十人，便除法師、律師；甄簡異故，不名僧次。《十誦》、《善生》中：以羅漢法請人，不稱名字，猶名別請，為佛所呵。如〈訃請〉法中。《多論》：若施主長請比丘，或作日限；先隨意請人，各使令定。至初集日，先無別請，一切無遮，大善無過；不能無遮，應打楗稚。眾僧集已，先別請者，且住一處。勸化比丘，若施主，應立高處，舉聲大唱，六十臘入；若多若少，但得一人，即名清淨；乃至唱到一夏，及沙彌等，若都無者，亦名清淨。若初日不唱，應日日唱，如初日法。若初日唱訖，若遮不遮，一切無過。若不作此二法，若食時，有遮界內比丘乃至一人，此一切僧得別眾罪。設界內無比丘故，有遮食不清淨。若九十日請，或長請，如初日唱。九十日夏訖，施主設有續供一月半月，即前唱法為清淨，不須更唱。唯僧房臥具，九十日竟，日日唱，不者得罪。若施主就僧界內作食，堂舍不容，次第出，在異處食亦得。若大界內有二處，《僧祇》：一日中二處俱施食，布薩處無過；不布薩處，不請布薩處一人，不送一分食者，此僧犯墮。若施主別請僧次四人，入僧布薩界內食，或將食入界別請比丘，應布薩處請僧次一人，若送一分食；若二處三處亦爾；自處不須展轉取人送食。設請人送食已，外有異比丘，若遮不與食者墮。若不爾者，三人已下，各各異處食得。若作意請僧中一人，忽忘不請，在前作一分食，置上座頭，送與彼僧。若道界遠者，先取食，次第行之。若聚落界內，雖無僧界，設二檀越請四人已上，於二處食，應打楗稚。互謂一人，互送一分食。若有異比丘應入，乃至一人。若不互請送食，皆墮。若遮不與一人食，亦墮。假令一處欲如法者，應好隱悉知聚落比丘有無，不疑者得。不爾，應打楗稚；不打者，知有一人不來食，犯墮。疑有，吉羅。若不疑心，若打楗稚，不問有無，一切不犯。或先僧次請來，有客比丘，遮不聽入，即成別眾。或先別請，有客比丘來，比丘教化勿遮，即成僧次。不能不遮，乃至唱一人入等。《善見》：別乞四句：或四人一時乞，或別別乞，各不相知；而同一主，一時往受食者，犯。二各各去，一時受，各處食。三各去、各受、各食，不犯。四或別乞、別去，一時受食，犯。義云：僧次請，人至請家已，門外有比丘，不許入界內者，變為別請。設後食時無人，亦犯墮。若門外僧，與家內相去六十三步外者，食時外僧，乃名別請別眾，不名僧次別眾。
【譯文】二別僧、別乞、別請三種。先闡釋「別僧」，也就是指「僧次」。《五分律》說：所謂僧次請，凡夫、聖人、習坐禪者、誦經者、協助辦理僧團事務者，只要是為求生死解脫而出家者，均得列入僧次；唯有毀犯重戒之惡戒人除外。如果施主說「請依戒臘次序迎請上座」，這屬於僧次所含攝。若是不知道到第幾臘才算上座？佛說：在自己之上沒有更長之戒臘者，皆名為上座。若依修證功法來揀擇選人，例如指名「請禪師」等，這便屬於指名別請。如果指定「請十位禪師」，便排除了法師與律師；因為有了甄別揀擇之差異，故不稱為僧次。《十誦律》與《善生經》中說：以阿羅漢之果位來指名請人，縱然不直呼名字，依然屬於別請，為佛陀所呵斥。這正如〈赴請法〉（訃請法）中所明述。《薩婆多論》（多論）說：如果施主作長期的長供，或者預設了供養天數之期限；起初任意指定迎請人選，各自安排底定。到了第一天集會應供之日，若事先無指名別請之分別心，對全體僧眾一切全無阻攔遮障，這是極為殊勝而無有過失的；如果無法做到全無阻礙，就應當鳴敲楗稚（犍槌）。待大眾僧集合完畢後，先前被私下別請的比丘先暫住一處。勸化的大德比丘或施主，應當登立於高處，揚聲高唱大呼：「請六十戒臘以上者入席！」無論進來人數多寡，哪怕只招請到一人，大眾即得清淨；依此方式乃至唱名降至一夏戒臘、以及沙彌等等，若全界內都無人，也同樣名為清淨。如果第一天未依此法唱令，以後就應當每天都唱，如第一天之法。如果第一天已如法唱喚完畢，往後無論來僧受遮擋與否，一切皆無過失。如果不施行這兩種如法之手段，若到了用餐之時，有阻遮結界內比丘哪怕只有一人不得入食，這全體用餐僧眾皆結別眾罪。假使結界之內本無其他比丘，因動念作了遮食之法，亦得不清淨罪。如果是九十天的結夏供養，或是長期供請，做法均如同第一天之唱法。九十天安居結束後，施主若繼續追加供養一個月或半個月，那麼沿用先前的唱法即可保持清淨，不須重新再唱。唯有對於僧房中的臥具，在九十天期滿之後，每天都必須唱令普請，不這樣做就會結罪。如果施主來到僧團結界內烹調辦齋，僧堂房舍容納不下，僧人依戒臘次序移出到其他處所用餐亦無不可。如果在大界之內有兩處設食：《僧祇律》說：同一天之中在兩處都施設齋食，設在布薩處的那一邊無過失；而不在布薩處的那一邊，如果不從布薩處迎請一人過來，也不送一份食物過去，則這一處的僧眾結犯波逸提（單墮罪）。如果施主單獨迎請僧次比丘四人，進入僧團布薩界內用餐，或者攜帶食物入界來單獨供請部分比丘，應當從布薩處迎請一位僧次比丘，或者送過去一份食物；若有兩處、三處分設也是如此；布薩處本地則不須要展轉取人送食。若是已經迎請了僧人或送去了食物，外頭若有其他客比丘到來，如果加以阻擋不給予食物，則結墮罪。如果不屬於此類情況，若是三人以下，各自在不同的地方用餐是可以的。如果原先存心要迎請全體僧中的某一人，臨時忽然遺忘未請，應當在面前分出一份食物置於上座前頭，差人送去給該位比丘。如果路途或結界遙遠，應先將該比丘的一份食物取出差人送去，現場食物則依次分發給大眾僧受用。如果在此聚落村境之內，雖然未劃定僧界，設若有兩位施主迎請了四人以上，分在兩處用餐，應當鳴敲楗稚。雙方互相召請一人，互相送去一份食物。此時若有其他客比丘應當加入，哪怕只有一人，如果不互相迎請送食，兩處僧眾皆結墮罪。如果阻擋而不給予該位比丘食物，亦結墮罪。設若某一處想要完全如法，應當仔細周密地查明聚落中到底有沒有其他比丘，在毫無疑惑的情況下方得直接用餐。否則的話，必須鳴敲楗稚；如果不敲，明知有一人未獲前來受食，便犯墮罪；疑心有而未敲，結突吉羅（吉羅）。如果確無疑心，或者已經鳴敲了楗稚，那麼無論界內到底有沒有其他比丘，一切都不結罪。或者起初是依僧次受請而來，但當客比丘到來時，若加以阻攔不准進入，便即刻演變成了「別眾」。或者起初本是指名別請，當客比丘到來時，比丘若能勸導大眾切勿遮攔阻隔，便當場轉化成了如法的「僧次」。若實在無法做到完全不阻隔，至少也應當如前法唱令招請一人入席等等。《善見律》列出私自「別乞」的四種情況：一是四個人同一時間去乞食，或者是各自單獨去乞食而彼此不知情；但因同一位施主在同一時間接受食物，成犯。第二種情況是：各自單獨前去乞討，在同一時間受取食物，分在各自不同的處所進食（善見論判得罪成犯）。三是各自前去、各自受取、各自進食，不犯。四或者是私自分開乞討、分頭前去，卻聚在同一時間受食，成犯。古德義疏解釋說：若是依照僧次受請，僧人抵達施主家之後，門外有客比丘前來，如果主人或眾人不准他進入界內，那麼這次應供就演變成了「別請」。即使後來到了用餐時外頭已經無人，用餐者亦結犯波逸提（單墮罪）。如果門外的比丘與屋內相隔在六十三步之外，則用餐時屋內僧人所結之罪，乃稱為指名別請之別眾，而不稱為僧次之別眾。
