# 校閱材料　第762檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【762-0001】03_業疏/02a_卷一之二#49
【原文】總示中，初引他義，事、法、人三相因而立，則人隨法立也。境即是事，小、中、大事為三位，念、對、眾法為三法。「莫」下次示今解，初立義；「以」下點前非，謂若約三法，則人法相因，若離八品，則人法兩別，數則不齊，故云「異法分人，自有區別」，則知人位不隨法立，故下結成理歸隨事立也
【譯文】在總體提示中，起初引述他人的義理，認為事、法、人三者是相依而確立的，也就是人隨順著法而安立。境指的就是事，小事、中事、大事即是三種位階，心念法、對首法、大眾法即是三種僧法。「莫」字以下，其次顯示現今的解釋，先確立本宗義理；「以」字以下，指點前師的缺失，認為若是約定三種僧法，則是人與法互為因果，若是展開為八品羯磨，則人與法各自不同，數量就不能對等，所以說「不同的法區分不同的人，自然各有界限」，由此可知人的位階並非隨法而立，所以底下總結歸納出其正理應當是隨事相而安立。

【762-0002】03_業疏/02a_卷一之二#50
【原文】就後位中，分為四別：一者四人，乃至第四二十人僧
【譯文】就最後一種位階（大眾僧）之中，又劃分為四種差別：第一是四人僧，乃至第四是二十人僧。

【762-0003】03_業疏/02a_卷一之二#51
【原文】次科標示中，言「後位」者，即單就僧位自分四別
【譯文】在下一科的標明提示中，所說的「後位」，就是單就大眾僧位自身劃分出的四種差別。

【762-0004】03_業疏/02a_卷一之二#52
【原文】有人言：前二法爾也，說戒相綰，能所須四；自恣治罪，舉證須五。後二逐情也，中國僧多，善心浮雜，故制十人；二篇悔治，倍緣方濟，故加二十
【譯文】有人說：前兩種（四人與五人）是法爾如是的自然之理，說戒時彼此維繫關聯，能說者與聽受者合起來必須四人；自恣與舉治罪過，舉罪者與作證者必須五人。後兩種（十人與二十人）則是隨順人情而制定的，中印度僧眾眾多，善心浮動雜亂，所以制定為十人；懺悔治罰第二篇僧殘重罪，必須加倍藉助因緣才能成辦救濟，所以增加到二十人。

【762-0005】03_業疏/02a_卷一之二#53
【原文】次正顯中初師二意：初解為二，初釋前二理數合然，故云法爾。說戒雖分能說所聽，彼此同須，故云相綰（烏板反之），謂相綰繫也；自恣舉罪須一五德，事必五人。次釋後二，言「逐情」謂恐人情慢易，故兩倍增之也
【譯文】在接下來的正文闡明中，第一位論師有兩種意思：第一種解釋分為兩段，首先解釋前兩項在理則與數目上理應如此，所以說「法爾」。說戒雖然分為能說者與聽受者，但彼此雙方都同等需要此法，所以說「相綰」（音「綰」），意思是相互牽繫關聯；自恣舉罪時必須有一位具足五德的受自恣人，因此事情必定需要五個人。其次解釋後兩項，說「逐情」是指唯恐人情懈怠輕忽，所以將人數加倍遞增。

【762-0006】03_業疏/02a_卷一之二#54
【原文】受有中邊之殊，故五人、十人；隨有專精、第二，故四人、二十人也。戒律攝用，勿過受隨，故又因之而立四也
【譯文】受戒有中國與邊地的差別，所以有五人僧、十人僧；隨順戒行的持守有專精持戒與犯後第二白法的差別，所以有四人僧、二十人僧。戒律所統攝的功用，不超出受戒與隨戒，所以又依循這個道理而確立了這四種僧。

【762-0007】03_業疏/02a_卷一之二#55
【原文】次解：邊方僧少開五人，中國僧多制十人。專精即奉持清淨，堪應說戒；第二謂犯殘懺已，戒體復生，望初本受名第二白法，兼通此義，故云「又因立」也
【譯文】第二種解釋：邊地僧人稀少，所以開許五人授戒；中國僧人眾多，所以制定十人授戒。「專精」就是指奉持戒律清淨無染，堪能應對說戒之法；「第二」是指犯了僧殘罪懺悔清淨之後，戒體重新復得，相對於最初的根本得戒，這稱為「第二白法」，同時兼具這個涵義，所以說「又依之而確立」。

【762-0008】03_業疏/02a_卷一之二#56
【原文】有人言：僧雖有四，體相分二。初一為體，非四不名為僧；後隨事分，故有三別
【譯文】有人說：僧團雖然有四種，但自體與相狀只分為兩種。前一種（四人僧）是僧團的自體，若不滿四人就不稱為僧；後三種則是隨順僧事而劃分，所以有三種差別。

【762-0009】03_業疏/02a_卷一之二#57
【原文】後師正明中初科，「四人為體」者，體即是本，後三隨事，體在其中
【譯文】後一位論師在正式闡明中的第一科，所謂「以四人為體」，體就是根本，後三種隨順事相而增設的人數，其僧體本來就包涵在其中。

【762-0010】03_業疏/02a_卷一之二#58
【原文】自恣、邊受體須四人，但自陳己罪，即須舉處，若非德用，濫坌僧倫，故差一人為僧事境，和白面告，無言表淨也。方隅僧少，前受心殷，四實濟緣，事須別問，若不差遣，無由輙往，問淨反白，前緣方辨，事兼受隨，通用五也。中國僧多，前受生慢，故倍前五為十人僧。二篇鄰重，犯悔情浮，故倍中受為二十人僧。三僧乃異，莫非約事濃薄，半倍增人方成前境，猶受日法三品倍增，類知可解
【譯文】自恣與邊地受戒，僧體本來需要四人，但若要親自陳述自己的罪過，就必須有檢舉受訴之處，如果此人沒有殊勝德行作用，就會混淆擾亂僧眾之列，因此派遣一人作為僧事的對境，僧眾和合宣告、當面告知，眾人無言表示清淨。邊遠地區僧人稀少，前來受戒者求戒之心懇切，四人實已足夠救濟成緣，但依法必須私下個別詢問遮難，若不正式差遣，便不能隨意前往，詢問清淨後返回白僧，前面的因緣才算成辦，事情兼涉受戒與隨行，故通用五人。中國僧人眾多，前來受戒者容易生起輕慢心，所以將前面的五人加倍為十人僧。第二篇僧殘罪鄰近於根本重罪，犯戒與懺悔之心容易浮泛不實，所以將中國受戒的人數加倍為二十人僧。這三種僧雖然不同，無非都是依據事相情節的輕重厚薄，依半數或倍數增加人數，才能成就所對治的事境，正如受日法分為上中下三品而成倍增加人數一樣，依此比類推知即可明了。

【762-0011】03_業疏/02a_卷一之二#59
【原文】次科初別示三位，又三：初明五人，文敘自恣、邊受二法，雙標別釋合結如文。「別問」即教授師屏處問難，「反白」即召入中。「」下次明十人，「二」下後明二十人。「三僧」下總結，邊、恣為薄，中受次濃，倍五為十；悔殘最濃，倍十為二十。「成」謂成辨境即機事。下舉受日亦因前事三品倍增，足堪比顯
【譯文】下一科首先分別指示三種位階，又分為三個部分：第一說明五人僧，文中敘述了自恣與邊地受戒這兩種法，雙重標出、分別解釋、綜合結語正如文中所述。「別問」指的就是教授師在屏障無人之處詢問遮難；「反白」指的就是返回僧中白僧並召受戒者入內。自「中國僧多」以下其次說明十人僧；「二篇鄰重」以下最後說明二十人僧。「三僧」以下作總結，邊地受戒與自恣情節較輕薄，中國受戒次重，所以加倍五人成為十人；懺悔僧殘罪情節最重，所以加倍十人成為二十人。「成」是指成辦所面對的機緣僧事。下文舉出受日法也是因為前面事相分為三品而倍數遞增，足以相互比對顯明。

【762-0012】03_業疏/02a_卷一之二#60
【原文】問：受隨同五，邊受減半；據受比殘，邊方出罪開十人不？答：非類也。邊隅僧少，俗緣拘礙，若不開聽，永沈生死，開有益也。懺殘不爾，初既誓持，終便順犯，本無慚愧，垢心厚重，若開十僧，增長諸惡，謂懺易成，則乖機候。故文中不言十人者，除中國出罪也，餘如大疏
【譯文】問：受戒與隨戒同樣有五人之法，邊地受戒既然能減半為五人；若依據受戒來比照懺除僧殘罪，邊地出罪是否也開許只需十人？ 答：這不是同類情況。邊遠地區僧人稀少，世俗障礙牽絆拘束，如果不開許聽許五人授戒，求戒者將永沉生死輪迴，開許對其有莫大益處。懺悔僧殘罪則不然，當初既然已經立誓守持，最終卻隨順煩惱而犯戒，本來就缺乏慚愧心，污穢之心厚重，如果開許只需十位僧人，將會助長種種惡業，讓人以為懺悔輕易就能成就，這就違背了應機施教的節度。因此律文中並未對十人僧說「除中國出罪」（只通說除出罪，顯見邊地亦不開許十人出罪），其餘詳細內容正如《大疏》所說。
