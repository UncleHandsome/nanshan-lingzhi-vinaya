# 校閱材料　第356檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【356-0001】02_戒疏/16b_卷四上之一#164
【原文】【記】次問。「三戒」，即上二戒及後「屏敷」。開限既同，出沒何異？答中，初明二戒，去則無犯，故列在文。次明「屏敷」，去則有犯。「暫」去即還，則開三夜；作意永去，出門即犯。文中若列，恐謂永去亦三夜犯，故云「濫」也。
【譯文】【記文】接著發問。「三條戒律」，就是指上述兩條戒以及後面的「在室內（覆處）敷設僧物戒（屏敷）」。這三條戒開許的期限既然同樣都是三夜，在根本經文中的顯現與隱沒為什麼會有差別？回答之中，首先說明前兩條戒，只要人離開了就不算犯戒，所以直接列在律文正文中。接著說明「室內敷設僧物戒」，是人離開了反而構成犯罪。「暫時」離開隨後就回來，那麼就開許可以放置三夜；若是起心動念「永久」離去，只要一走出寺門就立刻犯戒。如果在根本律文中列入三夜的開許，恐怕會讓人誤以為永久離去也可以放寬到三夜才算犯戒，這樣就會產生「混淆濫用」，所以不列入正文之中。

【356-0012】02_戒疏/16c_卷四上之一#8

【譯文】【疏文】關於「超過住宿時限」當中，依循戒本來判定犯相，所謂「到了第三宿」就結墮罪。若嚴格依犯相的時間點來說，只要進入第三夜的時段，一躺下睡覺就是犯戒。所以《十誦律戒本》說「超過兩夜，便犯波逸提」。這導致後來的解釋者，依據戒本文句而有判定寬緩與嚴格的不同。

【356-0013】02_戒疏/16c_卷四上之一#9
【原文】【記】第四中，釋文為三。初約戒定犯，謂入第三初夜即犯。「故」下，會同《十誦》。「致」下，斥異解。「有緩急」者，急則同上所釋，緩謂執後廣解，謂過三夜，第四夜犯。此由不曉二處文相不同，故成紛諍。今據戒本，仍會《十誦》，入三夜犯。《鈔》依廣解，同彼《善見》，並至四夜。《鈔》、《疏》不同，下為會釋。
【譯文】【記文】科判第四句中，將疏文分為三段。最初依戒文定犯，指進入第三夜初夜即犯。「故」字以下，會合印證《十誦律》。「致」字以下，駁斥不同的異解。所謂「有緩急」，嚴格的見解就如同上方所作的解釋；寬緩的見解則是執著後文的廣解，認為必須超過三夜，到了第四夜才算犯戒。這全是由於不明白這兩處的文義行相本就不同，所以造成紛爭。如今依據戒本，並參照《十誦律》，主張進入第三夜就犯戒；《行事鈔》則依據廣解，如同《善見律》，都認為到了第四夜才犯。《行事鈔》與《戒本疏》說法不同，下文會加以會通解釋。

【356-0014】02_戒疏/16c_卷四上之一#10
【原文】【疏】注中「三夜明相未出，應起避去」，順戒本犯，不去便墮。《母論》解云：「無去處，加坐至明。」、「第四宿」時，《律》、《論》俱明自他定離。諸制開相，《鈔》中具之，大如前戒。
【譯文】【疏文】註文說「第三夜天亮前晨光尚未顯現，就應當起身離開迴避」，這是順應戒本判定犯戒的標準，若不離開便犯墮罪。《毘尼母論》解釋說：「若實在沒有可去之處，可以結跏趺坐端坐直到天明。」到了「第四宿」的時刻，《律》本與論典都明確規定自己與對方必定要分離。各種制定與開許的面相，《行事鈔》中已經詳盡記載，大體都與前一條戒相同。

【356-0015】02_戒疏/16c_卷四上之一#11
【原文】【記】釋注。「三夜明相不去墮」者，若準戒文，初夜即犯。然此猶在第三夜分，故云「順戒本」也。《鈔》文依古，第四夜犯，三夜不去，但結吉罪。下引《母論》，可決上文。今準明之，謂戒本、《十誦》至第三夜初夜犯者，即本制也。廣解、《善見》明相犯者，謂前無去處，開盡夜分。此有三判：一、《疏》順戒本，不去犯墮；二、《鈔》準他部，不去但吉；三、《母論》加坐，都無有犯。至第四宿，一切無開，故云「自他定離」。「《律》、《論》俱明」者，《律》如注引，《論》即《母論》。「諸」下，指廣。《鈔》引《五分》「同宿不犯者，常坐不臥，或互坐臥」，又引《僧祇》「犯竟未懺復共宿者，無二夜開」。
【譯文】【記文】科判解釋註文。所謂「第三夜天亮不走便結墮罪」，如果依照戒本文義，初夜就已經犯戒了；然而此時仍處於第三夜的時段內，所以說「順戒本」的判定。《行事鈔》文依循古德之說，認為第四夜才犯墮，第三夜不走只結突吉羅罪。下文引用《毘尼母論》，可以用來裁決上文的紛歧。如今依正理闡明：戒本與《十誦律》主張到了第三夜初夜就犯戒，這屬於戒律最初的根本制定；而廣解與《善見律》主張天亮晨光顯現時才犯戒，是指先前確實無處可去，因而開許可以待完整個夜分。這裏共有三種判定：一是《戒本疏》順應戒本，不離開便犯墮罪；二是《行事鈔》參照他部律典，不離開只結吉羅罪；三是《毘尼母論》主張端坐不臥，完全沒有犯戒。到了第四宿，一切情況皆不開許，所以說「自他必定分離」。「《律》與論典皆明確規定」，《律》就如同註文所引，論典即是《毘尼母論》。「諸」字以下，指示詳見廣本。《行事鈔》引用《五分律》說「同宿不犯戒的情況，是常坐不臥，或者輪流坐與臥」，又引用《摩訶僧祇律》說「犯了戒之後尚未懺悔又再度共宿者，不再享有兩夜的開許」。

【356-0018】02_戒疏/16c_卷四上之一#14
【原文】【疏】凡理藉言通，教為表義。言辨理通，詞亂義隱，通益智明，隱增情感。故《多論》中制有四意：「初為異外道；二、師資位別；三、為分別言章須了；四、依實義，不在音聲。」具斯四益，所以一制。
【譯文】【疏文】大凡至理需要憑藉言語才能通達，教法是用來彰顯意理的。言語清晰明瞭則道理通達，言詞雜亂則法義隱晦；道理通達有助於智慧光明，法義隱晦則會增長凡情執著。所以《薩婆多論》記載佛陀制定此戒有四種深意：「第一是為了有別於外道；第二是為了使師長與弟子的位次有別；第三是為了分別章句言辭必須清晰明白；第四是為了依循實質義理，不在於追求聲音歌詠。」具備這四種利益，所以制定了這一條戒。

【356-0019】02_戒疏/16c_卷四上之一#15
【原文】【記】第六，制意中。初敘教功。此言「理」者，須通二種，謂真如諦理、世俗道理。諦理絕相，道理微隱，非言不顯，故「藉言通」。「教」即三藏，該乎大小。言以通理，教以彰義，此之二句，並顯教功。「言辨」下，次明誦習損益，發起制意。《多論》「四意」，以翻四過：一、有法式，西竺外道多合誦故；二、有尊卑；三、能詮不亂；四、所詮不隱。教為顯義，故不在聲。若許同誦，但逐音聲而不解義，深乖教意。
【譯文】【記文】科判第六條，解釋制定戒律的用意（制意）。最初敘述教法的功用。這裡所說的「理」，必須通達兩種，也就是真如諦理與世俗道理。真如諦理絕離一切名相，世俗道理微細隱微，若非言語便無法顯發，所以說「藉言通」。「教」就是指三藏，含攝了大乘與小乘。言語用以通達至理，教法用以彰明法義，這兩句話都彰顯了教法的功用。「言辨」以下，接著說明誦讀研習的損益，以此發起制戒的本意。《薩婆多論》的「四種用意」，是用來翻轉四種過失：第一是具備威儀法式，因為西印度外道多半齊聲合誦；第二是明辨尊卑次序；第三是使能詮的文句不紊亂；第四是使所詮的義理不隱晦。教法本是為了顯發實義，所以重點不在於音聲。如果允許一同合誦，大家只會一味追求聲音整齊而不解義理，這就深深違背了教法的本意。

【356-0033】02_戒疏/16c_卷四上之一#29
【原文】【記】戒本，第三。須明三相。言「句義」者，如諸經偈頌，一偈半偈，義意已足，同誦無差，故《律》舉「諸惡莫作」一偈為例。「非句義」者，抄前輒誦，文義不辨，故云「非」也。二、「句味」者，一句之下，即見理味，《律》舉「眼無常」等為例。「非句味」，同上。三、「字義」者，「字」即文字，字下有義，如訓釋等，《律》舉「阿、那、波、遮、那」為例，今時所誦密語之類。「非」，亦如上。文中，初總示。三是三非，故「為六」矣。「言」下，別釋。第一對中，初釋「句義」，「同」、「抄」兩犯。「憲章」即犯科。「句味」下，指餘兩對，例同上解。
【譯文】【記文】科判解釋戒本第三句。必須明瞭三種行相。所謂「句義」，就像各種經典中的偈頌，一偈或半偈，文義意旨已經具足，齊聲同誦毫無參差，所以《律》本舉出「諸惡莫作」這一偈為例。「非句義」，是搶在他人之前擅自接誦，導致文意無法辨明，所以稱為「非」。第二所謂「句味」，是指一句話之下就能顯現至理的法味，《律》本舉「眼無常」等為例。「非句味」的道理同上。第三所謂「字義」，「字」就是文字，單字之下含藏深義，例如訓詁解釋等，《律》本舉「阿、那、波、遮、那」等梵字為例，就像今日所念誦的密咒之類。「非字義」也如同上述。疏文中，最初總括指示，三種「是」與三種「非」相對照，所以「分為六種」。「言」字以下，分別解釋。在第一對當中，先解釋「句義」，齊同與搶截兩種情況都構成犯戒。「憲章」就是指犯戒的科條。「句味」以下，指示其餘兩對，依此類推如同上文的解釋。
