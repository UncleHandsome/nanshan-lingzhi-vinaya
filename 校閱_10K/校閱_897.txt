# 校閱材料　第897檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【897-0001】資持記/01c_上一上#42
【原文】又諸部境想不同，《五分》不開疑想，《僧祇》性惡無疑想，《十誦》前有方便除疑想〔今鈔準用〕，《四分》除破僧婬酒不開疑想，餘戒通開，上竝此輕他重。下二句證成。異執即是各計，非貶斥也。問：此就當宗以辨興意，那以五部為證耶？答：此舉群宗，為顯《四分》。五中，初句通標。
【譯文】又如諸部派對於「境界與心念」的判定各有不同：《五分律》絕不開許心生懷疑或誤想的情況，《僧祇律》認為本性屬惡之事絕無開除疑想的餘地，《十誦律》規定前階段有方便造作則除去了疑想的開緣〔今日《行事鈔》亦準用此義〕，而《四分律》則除了破僧戒、行婬戒、飲酒戒這三條之外不開許疑想，其餘戒條全都可以因不知或誤想而免結根本罪，以上這些全都屬於「本律處置較寬而他部處置極重」的情況。下兩句引文證成。所謂「異執」就是指各部派獨特的見解主張，並非貶抑呵斥之詞。問：這明明是在依循本宗辨析佛陀立教的本懷，為何要借用其餘五部的記載來作證呢？答：這正是透過羅列諸多宗派的差別，好徹底顯發《四分律》自身獨特的深意。在第五個範例中，第一句是總體標明綱目。

【897-0002】資持記/01c_上一上#43
【原文】事謂止持門一切諸戒，如婬盜等。法即作持門一切制法，如結說安恣衣藥受淨，及餘一切眾別羯磨。法下，別釋。初二句明制法意。上列諸法，通制一化；行必有方，違則獲罪；如諸羯磨，竝託緣成；必須四準評量，七非撿校，故曰法唯等。事下四句出制事意。情謂有情，性即三性；
【譯文】「事」是指止持門中所包含的一切止惡戒條，例如嚴禁婬欲、偷盜等等。「法」是指作持門中所包含的一切行善制規，例如結界、說戒、安居、自恣、受衣、受藥、受戒、結淨，以及其餘所有大眾或個別所秉持的羯磨作法。在「法」字以下，展開個別解釋。前面兩句說明佛陀制定作持行法的深意。上面所列舉的種種法定軌則，普遍用以軌範一代化導的四眾弟子；行事必須有嚴整合法的方軌，若有違背便會獲致罪衍；正如所有的羯磨法事，全都必須依託清淨合法的外緣才能成辦；過程必須以「四種標準」去審度評量，用「七種非法之非」來檢點核校，所以才說「行法必須」等等。在「事」字以下的四句，揭示佛陀制定止惡戒事的深意。「情」是指有情眾生，「性」是指善、惡、無記這「三性」；

【897-0003】資持記/01c_上一上#44
【原文】性因情起，故云情性；然以情變不常，隨緣無量，故令聖制教等塵沙。事託境生，故云隨境。有犯不犯，故云得失。或託下，釋上隨制。三性犯戒，廣如中卷〈篇聚名報〉及《戒疏》中，今依疏文略引示之。
【譯文】三性原本就是依託有情的心識而生起，所以稱為「情性」；然而因為眾生的情識變異無常，隨順各種境界造作的惡業無量無邊，所以致使聖人制定的教誡多如塵沙。種種犯事都是依託境界而生起，所以說是「隨境而生」。造作之中有構罪與不構罪的分別，所以說是「得失」。在「或託」以下，逐一釋明上述隨機制作的道理。眾生依善、惡、無記這三性而犯戒的義理，詳細記載於中卷〈篇聚名報篇〉以及《戒疏》之中，現在依照疏文簡略引證開示。

【897-0004】資持記/01c_上一上#45
【原文】彼云：託善緣以興教者，如坐禪讀誦講導開悟，必以正命居懷，制伏煩惱，此名善法；方希名利邪命自居，相雖是善，反成貪毒；壞心障道，勿過於此，是故大聖興教防之。〔此通遮性，性如慈心斷命，好心互用三寶等；遮如乞衣過受勸增等類。
【譯文】《戒疏》說道：所謂「依託善法的因緣而興起戒教」，例如行者從事靜坐修禪、讀誦經典、為人講經開導以啟發覺悟，內心本應當抱持端正合法的正命，伏滅自身的煩惱妄想，這才稱得上是「真正的善法」；但如果行者內心轉為貪求世俗名利、甘居於邪命活命之中，外在的行相雖然看似在行善，內在實則反倒變成了貪婪猛毒；敗壞道心、障礙聖道之事，沒有比這更嚴重的了，正因如此大聖佛陀才特地興立教法來加以防範。〔這通貫了遮戒與性戒，性戒的例子如自以為出於慈悲而斷人性命、自以為出於好心而將三寶財物互相挪用流通等等；遮戒的例子如挨家乞衣超過了定額受取、勸誘施主增加供養等類。〕

【897-0005】資持記/01c_上一上#46
【原文】言不善緣以興教者，如十惡等體是不善，能廣三途增惱障道，故聖因過制教防之。〔此局性惡。〕言託無記以興教者，如草土等，體雖無記；數作不已，外彰譏醜，內增心亂；故制防約，作者犯墮。餘廣如後。〔此唯遮戒。〕言世譏者，即諸戒緣，多因俗譏起過方制。
【譯文】所謂「依託不善法的因緣而興起戒教」，例如殺、盜、婬、妄等十惡之業，其體質本身就是極其污穢的不善之法，能夠廣開三惡道的大門、增長煩惱塵勞、障礙解脫聖道，因此佛陀因應眾生的過患，特別制定戒規以徹底防堵。〔這專門局限於本質為惡的「性惡」。〕所謂「依託無記法的因緣而興起戒教」，例如踐踏青草、掘鑿泥土等事，其事相本質雖然非善非惡、純屬無記；但若放任無節制地頻繁去作，對外會顯露出招致世俗譏嫌的醜態，對內則會無端增長自心的浮躁散亂；因此佛陀制定戒規予以約束防範，違反造作者便結犯單墮之罪。其餘詳細意涵廣泛見於後文。〔這唯獨屬於「遮戒」的範圍。〕

【897-0006】資持記/01c_上一上#47
【原文】一往以分，則上句通遮性，下句唯局遮。然性戒緣起，亦兼世譏，故此二句不可偏判，思之可知。〔古多錯解，故為曲示。〕如上五例，三四約機，為顯於教；餘三就教，非不對機。又前二局就止持，後三通於止作。總意中，初文為二；上二句結前；總下，示意。大毘尼藏，興意極多；
【譯文】所謂「世間譏嫌」，是指諸多戒律的生起因緣，大多都是因為世俗之人的非議譏刺、行者產生了不良過患之後，佛陀才隨順制定。若粗略地作一劃分，則上一句通於性戒與遮戒，下一句則專門局限在遮戒之中。然而仔細審視，性戒當初的制戒起緣，往往也兼帶了世俗之人的譏嫌，所以這兩句話絕不可偏執一端地加以武斷判定，深思之後便能了然於胸。〔古德對此多有錯誤的解會，所以特地在此委曲詳盡地指正說明。〕如同上述五種範例，其中第三與第四例是就「眾生根機」來立論，藉以彰顯戒法；其餘的三個範例則是就「戒法本身」來立論，但其背後無一不對應著眾生的根機。再者，前兩種範例專門局限在「止持」的範疇，後三種範例則同時通貫了「止持」與「作持」這兩大門徑。在總括深意的論述中，第一段經文分為兩層：前面兩句總結前文；從「總」字以下，正式開示要旨。廣大的毘尼藏，其立教興起的深意極為廣博深遠；

【897-0007】資持記/01c_上一上#48
【原文】五例統收，大要略盡；望其別條，實為未備，故云且略等。薄知言可取解。方詣明有所歸。方謂方所，詣即至詣。統一律之始終，故云總撮。指一意以該攝，故云包舉。拯，拔也。凡庸者，若據所化，實通諸趣；若取可度，別在人中。三歸五戒，餘道俱霑；具足律儀，唯人可受，必約通別兩意釋之。
【譯文】但只要透過這五種範例加以統括歸納，最核心的要旨便已大略全備；當然若對比於各條各款的細部枝節，確實還不算鉅細靡遺，所以說「姑且提綱挈領」等等。「略微了知」是說只要這般掌握便能獲致正解。「方詣」是表明行者在修行與持戒上有所歸宿。「方」是指處所方向，「詣」就是指通達抵達。本篇統攝了一部廣律從始至終的骨髓，所以說「總相撮取」。標指佛陀的一大心意以含攝整部律藏，所以說「統括包舉」。「拯」就是拔濟救拔的意思。所謂「凡庸」，如果從如來所教化化導的對象來看，實則廣泛通達於六道諸趣；但如果從能夠聽聞領解、受持戒法而得度脫的角度而言，則專門只在「人道」之中。乃至三皈依與五戒，其餘各道眾生或許都能沾獲法益；但要想受持圓滿的大比丘具足律儀，唯獨人類的身器方能領納承受，此處必須兼顧通論六道與別顯人道這兩種意旨來作解釋。
