# 校閱材料　第1123檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1123-0001】資持記/07e_中一下#31
【原文】或先小後大，或先大後小；並從大判，不犯律儀。若此以明，粗分進否；豈得雷同，一概頓斥為非！然有勇暴之夫，情存矯誑，邀人利養，規世聲名；故壞法門，乃佛教之大賊；自殘形體，實儒宗之逆人；直是惡因，終無善報。今時頗盛，聾俗豈知；則義淨之誡，亦有取矣。又下，次斥與物。
【譯文】或者先受小乘戒後受大乘戒，或者先受大乘戒後受小乘戒；都應當依從大乘戒來裁斷，這並不違犯小乘律儀。如果像這樣闡明道理，便能粗略分清可行與不可行；豈能含混苟同，一概全盤斥責為錯誤！然而世間確實有些凶猛粗暴之人，內心存著巧詐欺誑，藉此邀取別人的供養利養，沽名釣譽於世俗；故意敗壞佛法法門，實在是佛教之中的大賊；殘害毀傷自己的形體，也是儒家名教的逆子；這純粹是惡劣的罪因，終究不會有善報。當今這種風氣十分盛行，昏聵無知的世俗凡夫哪裡懂得分辨；從這一點看，義淨三藏的告誡，也是很有可取之處的。從「又」字以下，其次是斥責給予自殺者器物。

【1123-0002】資持記/07e_中一下#32
【原文】命終重者，同前安殺具也。膾子，即殺者之名，以能膾割人故。《僧祇》下，三斥妄教。用語重者，即同遣使也。典刑者，或是官吏，或即膾子。七明自殺。二律制同。謂下，釋上結蘭。以命斷戒失，無可犯故。不犯中，初引本律，有二，前開誤失。及下，次開看病。以藥食者，因與而死也。
【譯文】若對方因此命終則犯重罪，等同於前面的安置殺生器具。膾子，就是行刑劊子手的稱呼，因為他能割切人肉的緣故。從《僧祇律》以下，第三是斥責妄加教唆。使用教唆話語而致人於死者犯重罪，就等同於派遣使者。所謂「典刑者」，或者是指主管刑戮的官吏，或者就是指劊子手。第七項說明自殺。兩部律的制法相同。從「謂」字以下，是解釋上面為何結偷蘭遮罪。因為生命斷絕的同時戒體也隨之失去，死後已無戒可犯的緣故。在不犯的範疇中，首先引用本律，有兩種情況，前面開許誤殺失手。從「及」字以下，其次開許看顧護理病人。給予藥食致死者，是指因給藥餵食而導致死亡。

【1123-0003】資持記/07e_中一下#33
【原文】往來出入者，《注戒》云：扶將病人，入房往反；此釋濫上扶抱，但上約臥起，下據往還耳；或可約看病者，出入闕事釋之。上引《伽論》，皆結蘭者；若無害心，不合有犯；若有害心，結犯復輕，進退難定。今以義求，但看病者，心有強弱；若懷慈濟，因而致死，如律所開；
【譯文】所謂往來出入，《注戒》說：攙扶帶領病人，進出房舍往返走動；這解釋可能與上面的「扶抱」相混淆，但上面偏重於起臥，這裡偏重於走動走動；或者也可以解釋為看顧病人者，為了出入料理事務而有所缺失所致。上面引用《摩得勒伽論》，全都結為偷蘭遮罪；如果沒有害人之心，理應不構成犯罪；若是存有危害之心，結犯偷蘭遮又嫌太輕，進退之間難以判定。如今以法理探求，只是看顧病人者，內心的意念有強有弱；如果是懷著慈悲救濟之心，因而致人死亡的，就如同本律所開許的那樣不犯；

【1123-0004】資持記/07e_中一下#34
【原文】汎爾為之，不顧得失，失治死者；由本無心，故不結重；近於殺業，緣闕故蘭，思之。一切無害者，上文略舉，此句通收；但約無心，不唯此二。故下，次引俗例。不意而死，謂之過失。以物贖罪，謂之贖刑。注中，上二句，示過誤之相；下二句，明因事而死。
【譯文】如果只是漫不經心敷衍照料，不顧及病人的安危利害，因而失誤救治致死的；由於原本沒有害人之心，所以不結重罪；但因其過失接近於殺業，只是因缺緣而未遂，所以結偷蘭遮罪，這一點應當深思。所謂「一切無害」，上文只是略舉幾例，這一句則是通盤收攝；只要是基於毫無殺害之心，就不僅僅局限於這兩種情況。因此下文，其次引用世俗法令作為例證。並非出於本意而致死的，稱作過失殺人。用繳納財物來抵免死罪的，稱作贖刑。注文之中，上面兩句，顯示過失差錯的形相；下面兩句，說明因勞作事故而致死。

【1123-0005】資持記/07e_中一下#35
【原文】舉重者，有所傾壓也。乘高履危，役使於人也。乘，登也。大妄戒。〔佛在毘舍離，時世󰝿貴。婆永河邊，有安居者，共相稱歎。得上人法，遂獲利養。佛呵而制。〕妄語名通，加大簡小，唯局稱聖。列緣。可別。緣中，初後屬所對，中七屬能犯；
【譯文】舉重物致死，是指承受重物發生傾倒壓迫。攀登高處踏臨危險之地，是被人役使而致死。乘，就是登高的意思。大妄語戒。〔佛陀在毘舍離時，遇上饑荒穀貴。婆永河邊，有安居的比丘，互相稱揚讚歎。謊稱得到了過人之法，於是獲得了信眾的利養。佛陀呵責並制定了此戒。〕妄語的名稱涵蓋很廣，冠上「大」字是為了簡別微小的口過，專門侷限在妄稱自己證得聖法。列舉構成犯罪的條件（列緣），條理分明。在這些條件中，最初與最後屬於所對的對象，中間七個屬於能犯的自體；

【1123-0006】資持記/07e_中一下#36
【原文】七中，前四是心，後三屬口。言境虛者，實無所知也。過人法者，無漏聖道，出過凡法故。釋相中，初科又二，前引犯相。然律論所明，聖法多種；文中舉要，總而收之；自外凡已去，徹至極果；所修觀行，皆名聖法。即五停心，總別相念，四禪四空等；例是凡法，並通聖門，故同一犯。
【譯文】在七個條件中，前四個屬於心態，後三個屬於口業。所謂「所緣境虛」，是指自己實質上一無所證知。所謂「過人法」，是指無漏的聖道，超越凡夫之法。在解釋具體犯相中，第一個綱目又分兩部分，前面引用具體的犯相。然而律藏與論書所說明的聖法有很多種；文中列舉綱要，全部加以收攝；從外凡位開始，一直徹至極果佛位；其間所修習的觀行，都稱為聖法。包括五停心觀、總相念住與別相念住、四禪四空定等；這些例常雖屬於凡夫之法，但都能通往聖道之門，所以妄稱時同犯一重罪。

【1123-0007】資持記/07e_中一下#37
【原文】三十七品、四向四果，即是聖法。若現下，簡互造。上是正業，出口成犯，不約他疑；此由身造，業相不顯，故約前人疑信兩判。《十誦》下，次引釋疑。言近小者，外凡初位所能修故。甘露味中最勝，可喻聖道。次科。
【譯文】三十七道品、四向四果，便是正式的聖法。從「若現」字以下，簡別身口互為造業的情形。上面是口說的直接造業，話一出口就構成犯罪，不取決於別人是否懷疑；這裡是由於身體動作造作，業相不明顯，所以要根據對方是懷疑還是信受兩種情況來判定。《十誦律》以下，其次引用以化解疑惑。說它鄰近於小乘初位，是因為這是外凡最初的階位所能修習的緣故。甘露在一切美味中最為殊勝，可以用來譬喻聖道。第二個綱目。

【1123-0008】資持記/07e_中一下#38
【原文】《戒疏》問：天龍來供，凡尚感發，有何罪故，乃入聖中：答：相與聖通，故齋一重，又過常人之所有故。三中。錯互。此戒不開。疏云：由詐顯道德，謀誑在人；表聖招利，境損義一；但使言竟，錯誤皆犯。若就所稱之法，誤錯則開。如下欲說此而錯說彼，是也。四中。
【譯文】《戒疏》提問：天龍前來供養，凡夫尚且能夠感發，究竟有什麼罪過，竟把這列入聖法之中？回答說：這種感應相狀與聖人相通，所以齊同列為一重罪，況且這也超過了尋常凡人所能擁有的境界。第三項中，關於對象交錯（欲向此人說卻向彼人說之錯互），這條戒律概不開許免罪。《戒疏》說：由於詐現道德神異，欺騙誘誑之意在於他人；假託聖相招攬利養，在損害對境這一點上本質是一樣的；只要言語表述完畢，無論對象交錯皆犯重罪。但如果是就自己心中原本想稱說的聖法而言，若是口誤說錯則予開許。如下文所說想要說這法卻誤說成了那法，就是屬於此類。第四項中。
