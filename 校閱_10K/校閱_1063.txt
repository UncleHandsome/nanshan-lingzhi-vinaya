# 校閱材料　第1063檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1063-0001】資持記/06a_中一上#18
【原文】特須先示，方顯後文。宗即是本。明戒護中，初科，先徵起。由下，釋通。定慧依因，萬行宗主，故云生善最也。匡攝僧宗，緣持佛法，故云建立強也。略舉兩端，以彰體用。標宗所謂順則三寶住持，辦比丘事；違則覆滅正法，翻種苦業，即同此意也。引論，標中，初示所出。
【譯文】特別需要先行揭示這點，方能突顯後文的警策。所謂「宗」，也就是本源。在「闡明戒律的守護」中，第一科判先提出徵問。從「由下」開始，予以通達的解釋。戒是定與慧所依託的因緣，是萬般修行的宗主，所以說「出生善法最為殊勝」。戒能匡正統攝僧團宗脈，住持守護佛陀正法，所以說「建樹安立的力量最強」。這裡簡略舉出這兩端，來彰顯戒的本體與大用。標示宗旨所謂的「順隨戒律則三寶住世、成就比丘之法；違背戒律則覆滅正法、反倒播下苦業的種子」，也就是同一個意思。引證論典，在標題中，首先指出典籍出處。

【1063-0002】資持記/06a_中一上#19
【原文】言戒護者，舉行目體，兼收法相。謂下，釋名相，初分對惑業。彼論治三界心惑，名對治護，故云在心也；防身口邪業，則名戒護，故云在身口也。〔今但云戒，一往別對〕。有護下，示單複。以惑為業本，若但護心惑，不至身口，故云不必有戒；
【譯文】說到「戒護」，是舉出行持來指稱本體，並同時涵括戒律名相。從「謂下」開始，解釋名相含義，首先將其分開對照惑業。該部論典認為對治三界的內心惑亂，稱為「對治護」，所以說「在於心」；防護身業口業的邪僻過失，則稱為「戒護」，所以說「在於身口」。（如今只單說「戒」，是暫且從別相作對應）。從「有護下」開始，說明單一層面與雙重層面。既然迷惑是罪業的根本，若只是防護內心迷惑，尚未表現在身口外業上，所以說「不一定具有戒」；

【1063-0003】資持記/06a_中一上#20
【原文】又業假惑成，若禁防邪業，必兼防心，故云其必是護。然護治惑，非謂理觀，即是戒行；彼論謂之惑毘尼是也。經中者，未詳何文，或恐《了疏》所引。〔古云：論中自指者，撿彼無文。〕列釋中。八段一一竝有法喻，前三喻戒體，後五竝言愛惜，即喻戒行。
【譯文】又因為罪業是依憑心惑而成辦的，若是禁阻防範身口的邪業，必定已經兼顧防護了內心，所以說「它必定是護」。然而防護對治心惑，並不是指深奧的理體觀照，本身就是戒行的一環；那部論典稱之為「惑毘尼」就是這個意思。經文所提到的，尚不清楚出於哪部經典，或許是《戒了論疏》中所引用的。（古人說：那是論中自指的，去查驗該論卻沒有這段文句。）在逐一列舉解釋中。八個段落每一段都兼具法義與譬喻，前三個譬喻是指戒體，後五個都提到愛惜，就是比喻戒行。

【1063-0004】資持記/06a_中一上#21
【原文】四與初濫，前以王子，直喻受體；後以父愛子，乃喻隨行。目喻正見，糧比助道，國謂具德，藥即除障，尋文可知。三中，如意珠者，《智論》云：龍腦中出，眾生得之，除貧去毒。〔或云金翅鳥心，或云古佛舍利。〕善道即人天，菩提即佛果；中略三乘，故云乃至。七中三事：足財，謂國富；
【譯文】第四個譬喻容易與第一個混淆，前文是用「國王的嫡子」直接比喻所領受的戒體；後文是用「父親愛惜兒子」來比喻隨順戒體的行持。「眼睛」比喻正知見，「行糧」比喻助道之資糧，「國土」意指具足萬德，「靈藥」也就是拔除障礙，依照正文尋思即可了知。第三段中，所謂如意寶珠，《大智度論》說：是從龍腦中生出的，眾生得到它，能除免貧困與解拔劇毒。（或者說是金翅鳥的心臟，或者說是古佛的舍利。）「善道」就是人天善趣，「菩提」就是究竟佛果；中間省略了三乘道果，所以說「乃至」。第七段中的三件事：「足財」是指國家富有；

【1063-0005】資持記/06a_中一上#22
【原文】欲塵，謂色聲等境；國足塵則王者適意，故下以心安合之；正法，即禮樂號令，不失其所。合法中，無量下三句，配上三事。結勸中。功業重者，總上八喻，歸前二義，餘竝生善中最；第一第四，及七中末喻，即建立功強也。次明篇聚，正明中，初科，前敘名數差互。
【譯文】「欲塵」是指色聲香味等境；國家富足、塵境豐饒則國王心意適悅，所以下文用「心神安泰」來印證；「正法」也就是禮樂政令，施行不失其節度。在配合法義時，「無量下」的三句，恰好配對上面的三件事。在總結勸勉中。「功德業力深重」，是總括前面的八個譬喻，歸納入前述的兩大義理之中，其餘的大多屬於「出生善法中最為殊勝」；第一、第四，以及第七中的後半譬喻，就是屬於「建樹安立的力量最強」。其次闡明篇聚，在正式闡明中，第一科判先敘述名稱與數量的互異。

【1063-0006】資持記/06a_中一上#23
【原文】五篇取均，七聚據雜，仍分身口，故云約義。吉羅罪眾，從具兩分，罪無異體，故但有六。問：前引古解，定五為篇，以七為聚；今家前後諸文，竝云五篇七聚，還同古執，其意云何？答：但攻彼局，即彰篇聚名通；既曰兩通，隨用有何不可！今下，約結罪列名。佛出中梵，立此刑名；
【譯文】五篇著重在「相等（均）」，七聚依據在「參雜（雜）」，並且更細分身業與口業，所以說「依約義理」。突吉羅罪數量極多，依身口二具分為兩種（身惡作與口惡說），罪過本身並沒有相異的體質，所以篇聚實質上只有六種。問：前面引用古德的解釋，判定「五」名為篇，以「七」名為聚；如今我們這一家宗派的前後各處文句，全都說「五篇七聚」，這豈不是與古人的執著相同嗎，用意何在？答：前文只是破斥他們的固執局限，以此彰顯「篇」與「聚」二詞意義本來相通；既然已經說明二者皆通，隨順使用又有什麼不可以！從「今下」開始，依據結罪的種類羅列名稱。佛陀降生在印度中土，制定了這些刑罰名稱；

【1063-0007】資持記/06a_中一上#24
【原文】此土本無，將何對譯？故下諸名，或望聖道〔如夷蘭也〕，或約行業〔夷殘吉羅〕，或對眾法〔夷殘〕，或就來報〔夷提〕，或從懺法〔僧殘捨墮提舍〕，大略如此，餘如後釋。初夷聚中，《僧祇》，初句總翻。三下，別釋。具兼三義，彰惡之極。初退沒義，如下問答。二種僧者，同下《四分》。
【譯文】此間漢土原本沒有這些制度，將用什麼來相對翻譯？所以下方的各種名目，有的對應聖道而言（例如波羅夷、偷蘭遮），有的依約修持行業而論（波羅夷、僧殘、突吉羅），有的對照僧伽作法而言（波羅夷、僧殘），有的著眼於來世苦報而定（波羅夷、波逸提），有的依從懺悔之法來立（僧殘、捨墮、提舍尼），大概就是如此，其餘的留待後面解釋。在最先的「波羅夷聚」中，《摩訶僧祇律》的第一句是總體翻譯。從「三下」開始，逐一分別解釋。它同時兼具三種義理，以此彰顯罪惡已到了極致。第一是「退沒」的意思，如同下文問答所示。「二種僧」，與後文《四分律》相同。

【1063-0008】資持記/06a_中一上#25
【原文】墮阿鼻者，《目連問經》：但示劫數，不顯獄名；《雜心》中，墮焰熱地獄一晝夜；此文明判，及《十輪經》，竝云阿鼻，即無間獄；如《涅槃》云：間無暫樂〔常受苦故〕，無間空處〔身與獄等八萬由旬〕，故言無間。智者觀此，寧無怖懼乎！《十誦》中。初引律文，彼翻波羅夷為墮；
【譯文】「墮阿鼻地獄」這點，《目連問經》只指出墮落的劫數，沒有點明地獄的名稱；《雜阿毘曇心論》中，則說墮入焰熱地獄一日一夜；本篇文句明確判定，以及《十輪經》，都指明是墮入阿鼻地獄，也就是無間地獄；正如《涅槃經》所說：時間上沒有哪怕暫短的歡樂（常受諸苦），空間上沒有多餘的空隙（一身與地獄同等，遍滿八萬由旬），所以稱為無間。有智慧的人看到這裡，難道能不生起恐懼嗎！在《十誦律》中。首先引用律文，該律將波羅夷翻譯為「墮」；
