整體看，這份譯文可讀性好、書名還原（多論→薩婆多毘尼毘婆沙、伽論→摩得勒伽、明了論→律二十二明了論）都正確，大方向也掌握得住。但有**幾處實質誤譯**、**一處自行補入而與原文相反**，以及不少「原文沒有的限定詞」被悄悄加進去。以下按輕重分級列出。

---

## 一、必須改的實質錯誤

### 1. 「正不正俱犯足」——誤譯最嚴重
- 原文：「如足食竟，正不正俱犯足。」
- 譯文：「就像食畢**受足食戒**之後，無論面對的是**正法之食或非正法之食**，只要再吃都會犯足食戒。」

兩個錯：
- **足食竟**＝已經「足食」（受食訖、表示不再受食）的狀態，不是「受足食戒」。
- **正／不正**＝**正食**（五正食：飯、麨、乾飯、魚、肉等主食）／**不正食**（五嚼食：根、莖、葉、華、果等非主食），與「正法／非正法」毫無關係。

建議改譯：
> 就像已經足食（吃飽並拒絕續食）之後，不作餘食法而再吃，不論是正食（主食）或不正食（嚼食），同樣都犯足食之罪。

並可加一句譯註說明譬喻用意：**能犯的「足食」身分，通於所犯的正、不正二類食物**，正如能染的應量衣通染應量與不應量。

### 2. 《四分》八門首段——括號內容是自造的，且與原文相反
- 原文：「若初日得衣，二日不得，乃至十一日，**通皆不犯**。」
- 譯文：「（**乃至第十天每日皆得，所得之衣盡犯捨墮**；但）在未得衣之日，則無相染之罪……」

括號整段原文全無，而且把「通皆不犯」翻成「盡犯捨墮」，等於逆轉文意。這句是《四分律》的壓縮引文，歷來須依《資持記》判讀，**不該用自行補句的方式「解決」它**。

建議保守直譯＋存疑注：
> 若第一天得衣，第二天未得（衣），乃至到第十一天（都未再得衣），都不犯。〔譯按：此為八門不相染之第一門，文句簡略，確解待依《資持記》。〕

### 3. 「餘方」＝「其餘富庶地區」
邊方／餘方之別在於**佛法邊地與「中國」（中區、律法完備處）**，不是貧富。「富庶」是憑空添加且誤導。
建議：「其他地區（中國、佛法興盛之處）則未必一定要親手執持才起算。」（「手親自接觸」亦宜改為「親手執持」）

### 4. 「今此且充衣色」→「充當衣的體色」
「體色」不成詞，讀者無法理解。此處「充衣色」是**暫且充作三衣之數（形式上具足三衣、應急）**。
建議：「現在只是暫時充作三衣之數（應急），罪仍須懺。」

### 5. 突吉羅譯作「輕垢罪」
「輕垢罪」是《梵網》菩薩戒四十八輕的用語，用來對譯聲聞律的 **突吉羅（惡作／惡說）** 不妥。建議統一作「突吉羅（惡作，輕罪）」。

### 6. 「淨施＝透過受託者作法保管」
說淨（淨施）是**對首作法，把長衣名義上（或真實地）施與他人**，分真實淨施／展轉淨施，重點在「所有權名義轉移」而非「請人保管」。這個注釋會誤導。
建議：「十日內作淨施（對首作法，將衣名義上施與他人，故不犯畜長衣）」。

## 二、術語解釋不到位

| 原文 | 譯文 | 問題／建議 |
|---|---|---|
| 應量、不應量 | 「應量尺寸」 | 未說明：**應量＝衣財足如法之量、堪受持為衣**；不應量＝零碎不足量之衣財（含未成衣的布料）。首見宜加注 |
| 眼所至得／身至得 | 「眼睛看得到／身體接觸得到」 | 「至得」是明了論術語，指由眼／身而成立「得（攝屬己有）」，不只是感官接觸。純用「看得到」會失掉「十日從何时起算」的關鍵。建議保留「眼至得／身至得」並加注 |
| 作想是我物 | 「生起……的**執念**」 | 原文只是「認定屬己」，「執念」添了情緒色彩。改「心中認定『這是我的東西』」 |
| 五大色 | 「俗人正色等」 | 宜明說「青、黃、赤、白、黑五種正色（未染壞之色）」 |
| 善毘尼人 | 「律師」 | 現代「律師」易誤解，改「通達毘尼的人」 |
| 一罪 | 「一個**罪名**」 | 是「結一罪（一件罪）」，不是罪名種類 |
| 故皆一染 | 「同一種長衣染著的範疇」 | 語意糊。應為「（應量與不應量）彼此都得相染，同屬一染」，強調**互為能染／所染** |
| 此衣不懺 | 「新衣服不必**捨出**」 | 原文是「不懺」（不須捨懺），宜作「不須捨懺，只懺先前的波逸提罪」 |
| 已入淨故 | 「已納入清淨範圍」 | 可作「因換得的衣財已成為淨物（別是一物，非先罪所染）」 |

## 三、原文沒有的增譯（建議刪或標為譯註）

- 病人囑授物 →「病人**臨終**囑託」：原文只作「囑授」，未必臨終。
- 擬施三寶 →「**由比丘**轉施給三寶**常住**」：「由比丘轉施」「常住」都是添加。
- 更貿得衣財 →「**變賣**換得」：貿＝交易換取，未必變賣。
- 畜心染犯 →「蓄積之**貪**心」：可，但屬解釋。
- 六作非衣 →「改成非衣服的**器具**」：宜「改作非衣之物（如被褥等用途）」。
- 末句 →「**依僧團法規**捨出」「**隨意**贈送」「**私自裁剪縫製**」：都是補語，可保留但宜節制。
- 「即說淨者**益善**」→「**最為**妥善」：益善＝更好，非最高級。
- 「若織衣未入手」→「**布料**尚未入手」：應是「織作的**衣**尚未到手」。
- 「餘無**法緣**是犯」→「沒有**合法**因緣」：宜作「如法因緣（開緣）」，避免法律聯想。
- 「具有八門」→「八個**門徑**」：宜「八類情形」。

## 四、語意含糊／建議查證後再定

1. **「若他與作被，不犯」** → 譯「如果他人給予做成被子，不犯」：誰給誰、誰作被，中文讀不通。此句古解有「（將衣）與他人作被用」與「他人施與作被之用」兩路，重點都在**被褥非「衣」所攝故不犯長衣**（下接《十誦》施僧被褥可證）。建議擇一明譯並加注，或直譯「若他與作被（供作被褥之用，非衣所攝），不犯」。
2. **「《十誦》更得十日開之」** → 譯「還可以再有十天的寬限」過泛：宜補情境（如失而復得、得知實情後重新起算十日），或標存疑。
3. **伽論答句「出界外，明相出」** → 譯文未交代**人與衣的處所關係**，讀者不知何以犯離宿。建議：「（衣留界內而）人出界外，至明相出時（未與衣同處），即犯離宿。」並可點出結論：**受持為三衣並不免除前罪，一衣可兼犯長衣過限與離宿**。
4. **「若人不許自受」** → 主語是施主或受者，古來有異解；譯文逕定為「施主不允許比丘自己納受」，宜加注存疑。
5. **「三遣與人」** → 「差遣使者」：「遣與人」多解為「送給他人」（遣＝送），不必派使者。建議「送給他人」，或注「一解遣使送與」。
6. **「若已分、多人共分」** → 譯文把兩層合併；可區分「已分給現前僧」與「多人共持一分」，故一人作法即可。

## 五、體例建議（很重要）

目前譯文把大量解釋**直接混入正文**，讀者分不清哪句是律文、哪句是譯者推論——第 2 項的自造括號就是這樣失控的。建議：

- 譯者補充一律用「〔譯按：…〕」或固定括號樣式標出；
- 疑義句（八門初門、他與作被、十誦十日、明了論「人不許自受」）**寧可直譯＋存疑注**，不要自行補成通順但無據的句子；
- 關鍵術語（說淨／受持／應量／捨墮／明相／至得）在**首次出現處**給一次簡注，之後統一用法。

## 六、譯得好的地方（可保留）

- 「昔以財去，畜心染犯。論中不爾」→ 古解「原物雖換去、畜心仍染及新衣」與論典不許，對比清楚，掌握準確。
- 「此據有本三衣」判為「本已有三衣」與「失衣應急」的區別，正確。
- 多論兩種情形（原物改作衣 vs 貿得衣財改作衣）的捨／不捨、懺本罪的分判，條理分明。
- 「一尼薩耆＝前衣墮罪，一吉羅＝不懺輒貿違佛語」的會通，譯得準確。

**優先處理順序**：①足食「正不正」 ②八門自造括號 ③「富庶」 ④「充衣色」 ⑤突吉羅／輕垢罪與淨施定義 ⑥其餘增譯與待查句。
