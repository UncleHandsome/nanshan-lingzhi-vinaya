## 總評

這一大段的骨架你掌握得不錯：**文科（初四句／下二句／初二句總標／上句下句／雙結）都對**，三宗判釋（實法—假名—圓教）的方向、元照破斥諸師「大小相亂」的理路也沒有譯反。問題主要集中在幾個術語的處理、少量增字與語意含混，其中有三、四處會實質影響讀者理解，建議修。

---

## 一、需要修正的地方

**1.「行即思心，行起願後，故曰超前」**
現譯：「行就是思心，**隨行**發起於誓願之後……」
→ 原文已明說「行即思心」，這個「行」就是思心業行；加上「隨」字，讀者會誤以為是律學「受體／隨行」對舉的那個**隨行**，反而與前文「行即思心」打架。
建議：「行就是思心；行在誓願之後生起（且相續不絕），所以說它『超前』——超越先前有限期的誓願。」

**2.「若據本教，翻作為名」**
現譯：「如果依據本教，是翻對作戒（相對於作戒造作）而立名」
→ 讀法沒錯（「翻作」＝翻對「作戒」），但**沒有點出所立之名是「無作」**，讀者不知道在命名什麼；括注「相對於作戒造作」也語意打轉。這句是回答「兩云強目」的第一重（本教立場：無作之名是相待而立，故曰強）。
建議：「若依本教（假名宗），『無作』只是相對於『作戒』反顯而立的名稱（相待假立，故說勉強）。」

**3.「今取通意」**
現譯：「如今採取**通達**大乘之意」
→ 這裡的「通」是與「本教／權」相對的**通於圓教（大乘）**，不是動詞「通達」（「通達」留在下句「識達體貌」即可）。
建議：「如今依通於圓教（大乘）之意」。

**4.「後又有人立為思種」**
現譯：「後來又有人**立名**為『思種』」
→ 這是主張戒體之**體**是思心所之種子，不只是安立名稱。
建議：「後來又有人主張戒體即是『思（心所）的種子』」。

**5.「畢竟其體是何法耶？答：種子義也」**
→ 這一問一答是 **《增輝記》自己的問答**，不是元照的答（否則與下文元照破「二非即種子」自相矛盾）。譯文照排容易誤讀。
建議加提示：「（增輝自答：）就是種子義。」

**6.「自昔傳律，皆以戒體為難」**
現譯：「都把戒體當作**最**難之處」
→ 「最」是原文所無的添字；「為難」宜作「視為疑難／據以發難」。
建議：「都把戒體看作難解（可疑難）的問題」。

## 二、可再精確、更通順的地方

| 原文 | 現譯 | 建議 |
|---|---|---|
| 思即緣境之心 | 緣對外境的心念 | 「思」即思心所，攀緣境界而起造作的心（「境」不限外境） |
| 委如下說 | 正如後文所述 | 「詳細如下文所說」（是**將說**，非已說） |
| 霅溪則和會二非，還同細色 | 將非色非心調和融會，仍歸同於微細色法 | 「霅溪把二非之說加以會通，結果仍把它等同於細色」——「還同」是元照的貶語（等於退回實法宗），語氣可再明顯 |
| 乃是聚名 | 只是聚類的名稱 | 語意含糊。宜作「只是就聚集而假立的名目（總聚之名）」，或保留「聚名」加註 |
| 若可直示 | 如果可以直接指明 | 缺賓語，補：「倘若（在假名宗中）可以直截指明戒體就是種子」 |
| 不能究出體相 | 不能窮盡指出體性的行相 | 「體相」＝體性相狀；改「未能徹底究明戒體的體相」 |
| 又使假宗但有空名而無實體 | 使假名宗徒有空名而毫無實質體性 | 可顯豁為「又會使假名宗只剩空名，而沒有自宗所立的體」 |
| 今宗／本教 | 當前本宗／本教 | 首次出現時點明「今此假名宗（四分宗）」，讀者才知所指 |
| 此示種能熏習 | 開示種子具有熏習之力 | 尚可，但此處只是**略示**（實義委在後文圓教），可譯「此處顯示熏習成種、種能熏習之義」，語氣不宜說得太滿 |
| 後習 | 逕引「後習」 | 術語未加說明，讀者難懂；建議保留原詞並略注（後起之熏習） |

另：「識既常存」譯「識既然常在」照字面無誤，但若加註，宜說明藏識是**恆轉相續**，非「常住不變」，以免被讀成常我。

## 三、校勘與名相注釋

1. **「乃慚入大乘」**：「慚」當為「**漸**」之訛（漸入大乘）。你的譯文已按「漸」譯，處理正確，但建議出一條校注，避免讀者以為原文作「慚」。
2. **通慧僧錄**：即**贊寧**（賜號通慧，任僧錄），可加注。
3. **四依**：可注「四依（四種依止之人，指弘法之聖者）」。
4. **四捨**：可加注四種捨戒因緣（命終、作法捨戒、斷善根、二形生一類），但請依本疏他文覈對後再定，不要憑印象填。
5. **霅溪／《增輝》**：文中未詳作者，若不確定其人身分，注釋宜從缺，不要硬指。

## 四、後兩則（0002、0003）

沒有實質問題。小建議：

- 「後約圓教明戒體者」是科判牒文，譯「最後，依據圓教來闡明戒體：」可以；若要貼合三宗次第，作「其次（第三），約圓教以明戒體」亦可。
- 「先開大意」→「先**開示**大意」比「開展出整體大意」乾淨；「略為五門」譯「大略分為五門」正確。

**結論**：可用，但上面第一節的 1～5 建議務必改（尤其「隨行」、「翻作為名未點出無作」、「通意」、「立為思種」、「增輝自答」），其餘屬精修。需要的話我可以把整段依上述建議重排成一份修訂譯文。
