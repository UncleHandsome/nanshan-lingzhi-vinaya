# 校閱材料　第1019檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1019-0001】資持記/04d_上三#29
【原文】彼云：迦葉佛時，有比丘度弟子不教，多作非法，命終生龍中，受苦不能忍。便觀宿命，本作沙彌，不持禁戒，師亦不教。作念瞋師。會其師與五百人乘船度海，龍即出水捉船，索此比丘。眾人即問，乃述本緣。眾不得已，欲捉比丘。彼曰：我自入水，不須見捉，即便投水喪命。釋疑中。
【譯文】那裡說：在迦葉佛的時代，有一位比丘度化弟子卻不予教導，弟子造作了許多非法之事，命終後墮入龍中，痛苦難以忍受。它便觀察宿命，發現自己前世曾為沙彌，不持守戒律，師長也不加教導。因而生起怨恨師長之念。正好碰上他的師長與五百人乘船渡海，這條龍立刻露出水面抓住了船隻，索討這位比丘。眾人隨即詢問原因，龍便敘述了當年的因緣。大眾不得已，想要抓住比丘交出。該比丘說：我自己跳入水中，不用你們捉拿我，隨即投水喪失了性命。在「解答疑惑」（釋疑）中。

【1019-0002】資持記/04d_上三#30
【原文】前引過相，八五列之；恐疑犯五方呵，故須明決。答中，初正答。又下，教酌情用舍。如文易會。引勸中。彼經，有一年少比丘，出家未久，不聞法律；當乞食時，不知前後次第；比丘訶諫不從，佛因垂誡。文如《鈔》中。不閑等者，謂愚教也。凡所下，明造過也。轉向下，示現報也。
【譯文】前文所引發的過失相狀，分為八組五事排列；唯恐有人懷疑必須犯滿五件事才給予訶斥，所以必須明確裁斷。回答中，開頭正面回答。「又」字以下，教導應當審度情節來決定取捨。如同文句所言極易領會。在「引證勸戒」（引勸）中，該經記載，有一位年輕比丘，出家為時不久，未曾聽聞法律；去乞食的時候，不知道先後的次序；比丘給予呵責諫止他卻不順從，佛陀因而垂示告誡。文義就如《鈔》中所寫。「不知曉」等句，是指愚於教理法度。「凡所」以下，說明造作過失。「轉向」以下，指出招感的現世果報。

【1019-0003】資持記/04d_上三#31
【原文】捨戒下，釋上轉向死也。犯正下，釋上同死苦也。是下，結勸。文中兩言謂同死苦，準經，上句合云謂向於死。經云：所言死者，謂捨戒等；同死苦者，謂犯正等。經中牒釋，今易於下結，語不當異。引經對校，定是傳誤；須考本文，無勞強釋。第二訶誡，敘如非中分三，初誡自量。若懷下，次示正法。
【譯文】「捨戒」以下，解釋前文所說的「轉向於死」。「犯根本罪」以下，解釋前文所說的「等同死苦」。「是」字以下，總結勸勉。文中兩次說到「謂同死苦」，依照佛經原義，上面一句應當作「謂向於死」。經中說：所謂「死」，是指捨戒等；所謂「等同死苦」，是指犯根本重戒等。經中是先標舉而後解釋，如今在下文結語時作了變動，語句不應當相異。將經文相互校對，必定是傳抄上的錯誤；應當考據原文，無須強作解釋。第二「訶斥告誡」（訶誡），在「敘述如法與非法」（敘如非）中分為三部分，開頭告誡應當自我衡量。「若懷」以下，次一步提示如法之道。

【1019-0004】資持記/04d_上三#32
【原文】次第有四。初句明利他。次句明觀察。又依下，出過相。依訶詞者，即下五種；重輕隨用，故云進退。依過下，正訶責。若過下，三勸依教，初列非。宜下正勸。停，止也。鄙懷者，即上諸非。出道者，即前四法。然言之甚易，為之極難；若不懷瞋，安見訶責。雖云世有，何甞見之！
【譯文】其次序步驟有四個。第一句說明利益他人。次一句說明觀察審視。「又依」以下，指出過失的相狀。所謂「依照訶斥的詞句」，就是下文的五種方式；嚴重或輕微隨情況採用，所以說「進退衡量」。「依照過失」以下，正面予以訶責。「若過」以下，第三部分勸勉依從教法，開頭列舉非法之情。「宜」字以下正面勸勉。「停」，是止息的意思。「卑鄙的心懷」，就是指上述的種種非行。「出世之道」，就是指前面的四種法則。然而說來極為容易，實踐起來卻極其困難；如果心中不懷著瞋恨，又哪裡看得見訶責之道。世間雖說有這種人，但又何曾真正見過！

【1019-0005】資持記/04d_上三#33
【原文】苟自識心，不如抑忍。列如法中。《四分》五種，注釋甚明，無勞煩釋。但初重後輕。中三互望，並通輕重。執《涅槃》中，敘過為二，初示正教。三世者，釋迦為現，已前為過，彌勒已後為當。然過去已滅，當來未立，安知其教！蓋諸佛道同，舉現可驗；又復現教並明過未，故可知也。
【譯文】假如能省察自己的內心，倒不如抑止忍耐。在「列舉如法相狀」（列如法）中，《四分律》列出五種相狀，夾注解釋極為明晰，無須繁瑣費解。只是最初者較重而最後者較輕。中間三種相互對望，都通於輕與重。在「執持《涅槃經》文」（執涅槃）中，敘述過失分為兩部分，開頭提示正宗教法。「三世」，釋迦佛代表現在，釋迦以前代表過去，彌勒以後代表未來。然而過去諸佛已經滅度，未來諸佛尚未出興，如何能知道他們的教法！這大概是因為諸佛之道同出一轍，舉出現在便能驗證過往；而且現在的教法中也同時說明了過去與未來，所以能夠知曉。

【1019-0006】資持記/04d_上三#34
【原文】但佛法仁慈，必無陵物；恒沙皆爾，豈止釋迦乎！比下，指非法。便下，斥妄引，初標破。彼經第三，因迦葉菩薩問長壽因，佛答應護眾生同於子想，迦葉白佛：若有破戒作逆毀正法者，何得皆子想？因此令以羯磨治罰，乃至云：若見比丘見壞法者，置不驅遣訶責舉處，當知是人佛法中怨等；
【譯文】然而佛法仁慈，絕不會凌辱侵犯物類；恆河沙數諸佛皆是如此，豈止只有釋迦牟尼佛呢！「比」字以下，指出非法之處。「便」字以下，痛斥妄自引證，開頭標明破斥。該經第三卷中，因為迦葉菩薩詢問長壽的因緣，佛陀回答應當護念眾生如同自己的子女，迦葉白佛說：若有人破毀戒律、造作逆罪、毀謗正法，怎能都視作子女看待？佛陀因此令僧眾以羯磨法治罰，甚至說：如果比丘見到毀壞正法之人，置之不理而不予驅逐、訶責、舉發治罪，應當知道這個人就是佛法中的怨仇等等；

【1019-0007】資持記/04d_上三#35
【原文】迦葉復白佛言：如佛所言，則不等視一切眾生，同一子想，如羅睺羅；乃至佛言：譬如國王、大臣、宰相，產育諸子；若二、三、四，將付嚴師教詔；假使三子病杖而死，餘有一子，必當苦治，要令成就；乃至如來亦爾，視壞法者，等如一子。愚人執此，故行杖罰。然下，委斥，初出經意。
【譯文】迦葉又白佛言：如果按照佛所說的，那就不算平等看待一切眾生，如同看待親生子羅睺羅那樣視為一子；甚至佛陀說：譬如國王、大臣、宰相，生養了幾個兒子；若有二、三、四個兒子，將他們交付給嚴厲的師長教導訓誨；假使三個兒子因受杖責生病而死，剩下的那一個兒子，必定還要嚴厲懲治，務必要讓他有所成就；乃至於如來也是如此，看待毀壞佛法的人，平等看待如同一個兒子。愚人執著這段文句，便任意施加杖刑責打。然而下文詳細破斥，開頭點出經文的深意。

【1019-0008】資持記/04d_上三#36
【原文】一子地悲者，若準經中，正明如來；下引《攝論》，則通初地。即下，引經反質。即第十卷偈云：一切畏刀杖，無不愛壽命；恕己可為喻，勿殺勿行杖。不知下，責其妄引。嚴師為喻，即如上引。引深位中，初正引。淨心者，即初地，亦名歡喜地。無分別智，於諸眾生同於一子，無取捨故。
【譯文】所謂「視眾生如同一子的境界之大悲」（一子地悲），若依照經文，主要是指如來；下文引用《攝大乘論》，則通指初地菩薩。「即」字以下，引述經文反向質難。就是指第十卷中的偈頌說：一切眾生都畏懼刀杖，沒有人不珍愛自己的壽命；將心比心寬恕自處，切莫殺害也不要施加杖刑。「不知」以下，責備其胡亂引證。嚴師作為比喻，就如同上面所引述的內容。在「引證深位菩薩」（引深位）中，開頭正面引證。「淨心」，是指初地，也稱為歡喜地。以離分別的無分別智，看待一切眾生如同看待一子，沒有取捨之念。
