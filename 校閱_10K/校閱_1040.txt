# 校閱材料　第1040檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1040-0001】資持記/05c_上四#28
【原文】房舍等者，料理資緣也。三說者，表無謬濫也。上出本律。次引《五分》續成對答。彼人即所對者。莫放逸者，誡勅之語。答受持者，言議往返也。後以義加者下，引本宗《五分》並制依人。準牒詞中，意令專奉。今多但誦三說，不道餘詞，準理應成，依文為善。改轉中。前文且約一相以明；
【譯文】「房舍等」，是負責料理照顧所資助的緣具物資。必須「說三次」，是為了表明慎重而無錯誤差謬。以上是依據本律所出的規範。接著引述《五分律》來補足雙方應答的程序。「彼人」就是指所面對的對首僧人。「莫放逸」，是警策勸誡的言語。回答「我依教奉行受持」，這是雙方言語的來回對答。所謂「後以義加」以下，是引述本宗與《五分律》皆規定必須依止明師大德。依照宣讀的詞句中，本意是令其專注奉行。現在的人多半只念誦三遍安居詞，不說其餘的囑咐對答，依照義理推敲雖然也能成辦，但嚴格依照律文做完才是最良善的。在變通改轉詞句中，前文暫且是就一種普遍情況來說明；

【1040-0002】資持記/05c_上四#29
【原文】處既多別，故須隨改。料理之語，唯局僧坊，不通餘處。不下，斥非。彼謂通依一國一城，則處寬易護。然束約攝修，唯狹彌善；如上引律，起不礙頭，坐趣容膝；安有畏失而通一國乎。恐無知倣習，故須指破。初問。答中有三，初通示制意。前人下，別列三世。若下，反彰違失。
【譯文】安居處所既然有許多差別，所以必須隨實際情況更改其詞句。其中「料理修治」這句話，僅局限於寺院僧坊，不能套用到其餘處所。「不」字以下，是斥責錯誤的觀點。有人認為只要籠統依止一個國家、一座城邑，那麼範圍廣大便容易防護持守。然而約束身心、攝伏修道，唯有範圍越狹小才越為殊勝；正如上面引述律文所說，站起來不碰到頭頂、坐下來剛好容納膝蓋即可；哪有因為害怕破戒失敗反而將範圍放寬到整個國家的道理呢！唯恐有人無知盲目效仿，所以必須將其謬誤指出攻破。第一個問答中，回答包含三層意思：首先通括說明制定戒條的本意。「前人」以下，分別列出依止在三世（過去、現在、未來）中的益處。「若」字以下，反面揭示違背戒律的過失。

【1040-0003】資持記/05c_上四#30
【原文】若據安居，攝靜修道，反令營事，全乖教本；後賢有智，宜求斯旨。次問答中。五種持律，且約誦文多少次第。然前四種通須解義，曉達持犯，方可依之。推究中，初句徵。《五分》下，釋；初引《五分》制法。有比丘者，即緣起也。乃下，立制。往彼處者，明親附也。若房下，明遙依也。
【譯文】若是就安居收攝身心、恬靜修道而言，反而指派他去大興土木經營俗事，這完全違背了佛陀立教的根本宗旨；後世有智慧的賢德之人，應當深思體究此中的微旨。在下一個問答之中，所列的五種持律者，暫且是就背誦律文的多少次序來排列。然而前四種人全部都需要通達理解戒律深義、曉悟明達持犯之相，然後才可以作為依止的對象。在推究深究中，第一句提出追問。「五分」以下進行解釋：首先引述《五分律》所制定的法規。所謂「有比丘」，就是指事情發生的因緣。「乃」字以下確立制度。「前往彼處」，是指親身隨從依附。「若房」以下，是指在遠處遙相依止。

【1040-0004】資持記/05c_上四#31
【原文】若已下，明往返遇緣隨結成者；請法因緣，非心慢故，準下還成前安。次引《四分》制犯。罪相階降，在文可知。中安居，初標。律下釋有五節，初句指律。有名者，即增三云前中後也。無法，即犍度中但出前後二位也。世下，示古。然下，義立；初二句準增三之名。謂由有三時，故列三名；
【譯文】「若已」以下，說明若在往返途中遇到阻緣、隨所在之處結夏成辦的情形；這是為了請益佛法的因緣，並非內心故意輕慢放逸，依照下文推定依然算作成辦前安居。接著引述《四分律》對於違犯者的罪名制定。罪相的輕重階梯遞降，在文字上可以清楚明白。在「中安居」一科中，首先列出標題。「律」字以下解釋，包含五個段落：第一句是指向律文。所謂「有名」，就是指《四分律》增三法中記載了前、中、後三種名稱。所謂「無法」，就是指犍度之中只列出了前、後兩種具體作法。「世」字以下，說明古代的見解。「然」字以下，依照義理予以確立：前兩句準照《四分律》增三法所立的名稱。這是因為既然有三種時段，所以列出三種名稱；

【1040-0005】資持記/05c_上四#32
【原文】以名顯時，故云分明。次三句決犍度義具，故可例立。注引鉢量律文，但出上下二品，與今頗同。應下，出法。既約山嵓，故除修治。必下，縱古。注羯磨，依律但出前後二法。疏中所謂莫不望前並名後故。後安中，初標。於下，釋。初句定日。同下，指法同異。心念中。注示開緣。當下，明儀法。
【譯文】用名稱來彰顯時節，所以說界限分明。接著的三句決斷犍度之中義理原本具足，所以可以依例建立中安居法。夾注中引述鉢量大小的律文，雖然只列出了上品與下品兩種，但其文理與此處極為相似。「應」字以下，列出具體的作法詞句。既然是就深山巖窟而言，所以除去了修治房舍等字眼。「必」字以下，姑且順從古人的說法。《注羯磨》依照律文，確實只列出了前安居與後安居兩種作法。這正是《業疏》中所說的「無非因為相對於最初一日而言，後面的全部都名之為後」的緣故。在「後安居」一科中，首先列標。「於」字以下進行解釋。第一句定出結夏的日期。「同」字以下，指出其作法與前安居的同異之處。在「心念安居」之中，夾注提示了開許的因緣。「當」字以下，說明行事的威儀與具體作法。

【1040-0006】資持記/05c_上四#33
【原文】住下，令改轉。忘成中，初釋名相。身已在界，不憶加結；佛開成夏，故云忘成。律下，引示。律中四法，次第相由。故指心念為忘。必忘對首，例亦同開。故知下，準決；初示文局。以律本緣開外來故。必下，顯義通。但約要心，不局內外。初明舊住有要亦通，下明外客無要反塞。
【譯文】「住」字以下，令其隨處所不同而改換詞句。在「忘記成夏（忘成）」之中，首先解釋名相概念。身體既然已經在結界之內，只是心中遺忘、沒有提起正念加行結夏作法；佛陀慈悲開許其依然成夏，所以稱為「忘成」。「律」字以下，引述律文以作明示。律中所說的四種法，具有前後相承的次第關聯。因此此處是指心中本想行心念安居而遺忘了。如果是遺忘了面對面作法，依例也是同樣獲得開許的。所謂「故知」以下，準照義理進行決斷：首先指出律文表面有局限，因為律本當中的因緣是專門開許給外來客僧的。「必」字以下，顯發義理實際上是通達的。只要審核其當初確有安居之本心即可，並不受限於寺內舊住還是外來客僧。開頭說明舊住僧若早有期約也能通融，下文說明外來客僧若無期約反而受阻。

【1040-0007】資持記/05c_上四#34
【原文】言為事者，別有所務，明非要故。及界中。疏云：界者入攝僧界，園者僧伽藍園。〔藍是梵語，園即華言，即院相也。〕此須料簡，若藍狹界寬，及藍界俱等，並約界論；或藍寬界狹，或復無界，則約園說。律據僧坊，準通俗舍。此收四種，疏云：園界兩所，足有雙隻。
【譯文】所謂「為事而來」，是指另有私事勞務在身，這就表明其並非抱著專誠安居的期約而來。在「跨入界內（及界）」之中，《業疏》說：所謂「界」，是指進入了統攝僧眾的大界；所謂「園」，是指僧伽藍的庭園（「藍」是梵語，而「園」是華語，指的就是整個寺院的外廓）。此處必須詳細分析：如果是僧園狹小而結界寬大，或者是僧園與結界範圍相等，全部都要依照結界來判定；如果是僧園寬大而結界狹小，或者該處根本沒有結界，那就必須依照僧園來論定。律文雖然是依據寺院僧坊而言，準照此理也可通用於俗家舍宅。此中總共收攝了四種情況，《業疏》說：僧園與結界這兩個處所，腳有雙足與單足之分。
