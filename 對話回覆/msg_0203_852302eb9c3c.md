## 一、現行提示詞的 5 個核心問題（對應本次測試錯誤）

### 1. 規則內部打架，模型在邊界處隨機搖擺
* **衝突 A：「原譯括號一律保留」vs.「句子骨架與邏輯完整」**
  * **測試錯誤**：《尼鈔》第 12 則原文「此但從**行法非用**為名，又無餘者，此從**眾法絕分**為名」。原譯把「非用」塞進「行法」的括號補註裡，正句只剩「從『行法』而立名」，破壞了與下句「絕分」的對仗。因為提示詞寫死**「原譯已有的圓括號補義，除明顯錯誤外一律原樣保留」**，模型不敢把「非用」移回正句。
* **衝突 B：「嚴禁偷搬記文進疏文」vs.「防比喻／成語誤讀」**
  * **測試錯誤**：《業疏》第 01 則「水乳無二」。原譯寫「如同水與水相合、乳與乳相融般同類無二」，但新提示詞嚴禁偷搬【記文】進【疏文】，模型便刪掉解釋改回「如『水乳無二』般和合無間」——反而讓現代讀者誤聯想成「水乳交融」，與記文「如水合水、如乳合乳，二物各論」完全相反！
* **衝突 C：「單段內部不斷行」vs.「小標題後是否換行須與【現譯】一致」**
  * **測試錯誤**：《尼鈔》原文裡「第二名……者」「第三唱形者」本來**不斷行**，但【現譯】在小標題後幾乎**都有換行**。兩條規則正面衝突，導致模型第 13、14、19、20 則合併成一段，第 15、17 則卻保留換行。
* **衝突 D：「外層引號須與【現譯】或前後保持一致」**
  * **測試錯誤**：第 09–11 則是一段跨組的長問答 `答：「……。」`，第 11 則卻把引號全拿掉；第 18 與 21 則同為當眾宣唱白文，18 留引號、21 卻刪引號。主因是提示詞「或前後」太模糊，且單組送審時「前後背景」只有**原文**沒有**譯文**，模型見 21 原文沒引號就刪掉了。

### 2. 缺「律制邏輯自洽」與「記文反證檢驗」
* **《尼鈔》第 19 則（最嚴重）**：「若有作法界者，但令寺尼莫出自然界，餘自然界通結亦得。」【改後】譯成「如果其中已有作法界，只要令本寺比丘尼不走出自己的自然界，其餘的自然界範圍也可一併結入」。
  * 這裡沒觸發檢索修正，是因為提示詞沒提醒兩件事：
    1. **內部物理／空間邏輯矛盾檢查**：人既在「作法界」裡，怎麼會「不走出自己的自然界」？且律制「二界不可重疊／一併結入」。
    2. **《尼鈔》節略自《行事鈔》的平行文獻線索**：目前 `SYSTEM_PROMPT` 沒提示「遇《尼鈔》空間／作法省文致邏輯疑似窒礙時，優先檢索《行事鈔》／《資持記》對應平行文」。
* **《業疏》第 03 則（改前重大誤譯）**：「經遠大觀，義無讎抗」錯譯成「無有能與之匹敵抗衡者」。其實緊接的【記文】已經明釋「『無讎抗』者，言其大槩無勝劣也」。現行提示詞原則 2 只問「記文釋字在疏文有無銜接」，**沒強制要求「用【記文】義理回頭反核【疏文】譯文有沒有譯反」**。
* **名相階段與部別指代混用**：《尼鈔》第 16 則「說欲」變「與欲」、第 20 則「受欲」變「接受說欲」（混用「與欲／受欲／說欲」）；第 19 則剛把「僧」界定為男眾比丘，第 20 則括注卻寫「界內有僧（指比丘尼）」。這都需要明確點名防範。

### 3. 「無據增譯」漏抓微詞，「現代漢語自足」漏抓贅字與異體字
* **微幅無據增詞**：第 12 則「不如意處」→「**極**不如意的處所」（無據程度副詞）；第 15 則「當順心學」→「隨順**教法**、用心修學」（無據實詞賓語）。模型以為沒亂補分類就不算無據增譯，略過了這類墊字。
* **文字潔淨度**：第 11 則「概括**引證**三處**文證**」、「足**跡**蹤**迹**」（同詞混用異體字）、第 21 則「**僧眾大眾**都已同意」（詞彙疊床架屋）。

### 4. 「禁用校註」造成脫字無聲偷補
* **《尼鈔》第 21 則**：原文「同一說者默然」疑脫「戒」字。原譯文末原本有 `[按：原文……疑脫「戒」字]`，模型為了遵守「禁止擅造校註」，直接把按語刪光並無聲補譯「共同說戒」，反而讓讀者對照原文時不知「戒」從何來。應區分「臆造校註」與「原文確有明顯脫訛時的最小標記（`〔戒〕` 或保留簡短脫字按語）」。

### 5. 禁令被長推論稀釋（指令遵循衰減）
* **第 20 則【改後】**：開頭重貼了整段加標點的原文。
* **第 07 則【改後】**：第二段疏文開頭殘留了一個 `【疏文】` 標籤。
* 儘管提示詞已有「嚴禁重貼原文」，但放在第 3 欄中間、後面還有長串體例說明，模型經過多輪思考後容易遺忘。必須把「禁重貼原文／單欄單標籤」放到**提示詞最後一行作終檢**，並搭配 3 行程式防呆。

### 2. 材料層 `PROMPT` 與 `_nicao_prompt()`（修改 `mk_review_materials.py`）

```python
PROMPT = '''你是南山律典審校編輯，負責核對《四分律》與南山三大部／三大記（疏文與記文）的白話譯文是否忠實、準確且自然。

請**只審查【本次待審段】**，前後背景僅供確認主詞、指代與律制脈絡，不需校對。

### 請依序輸出以下三欄：

1. **逐句對位與檢查**：
   - 將【疏文】與【記文】**逐句切開**，一對一核對譯文（段內每句都要查完，不可中途停止）。
   - 依序檢驗四項原則（只抓實質問題，不挑純修辭）：
     1. **忠實完整與邏輯自洽**：有無漏譯（含小註、限定條件）、無據增譯（含偷搬【記文】解釋進【疏文】、無把握亂補分類，以及原文未見的程度副詞如「極／徹底」或實詞賓語；**唯原譯已作簡短消歧義而刪掉會變質者除外**）、改壞邏輯（因果、並列、選擇關係、主客或作法／空間邏輯矛盾，如身處作法界卻說不出自然界、二界相疊等）。

     2. **古義、律典體例與疏記互證**：科判指標（如「X下／下一句」指自該字起）有無誤讀；律學專名（含動作階段如與欲／受欲／說欲不可混換）、部別指稱（如尼律中「僧」多指男眾比丘，括注不可混稱比丘尼為僧）與古今異義詞是否用現代精準詞表達、且同段譯名一致；【記文】釋字或引詞在【疏文】是否留有銜接字眼；**並須以【記文】義理反向核對【疏文】譯文，兩者絕不可自相抵觸（如【疏文】用詞在現代極易觸發反向聯想如「水乳無二」易誤為水乳交融，不可為避諱記文而留下誤導字眼，應以極簡括注或準確譯詞點明本義）**。
     3. **引文、脫字與括號邊界**：引文是否完整對譯、無半文半白殘句或引號內擅加擴寫；有無擅造校註或新增多餘注釋（**原譯既有的正確消歧義圓括號不得判為多餘注釋**；唯若誤置於引號內則移至引號外。**若原典確有明顯脫訛字且【現譯】已有簡短按語或須補字成句，應以 `〔補字〕` 或於段末保留極簡括號說明，不可無聲偷補後又刪光說明**）。

       2. `【疏文】`／`【記文】` 標籤各自只出現一次，無殘留重複標籤。

def _nicao_prompt():
    """尼鈔專用：無記文，只審鈔文。"""
    t = PROMPT
    t = t.replace('（疏文與記文）', '（鈔文）')
    t = t.replace('1. **逐句對位與檢查**：\n   - 將【疏文】與【記文】**逐句切開**，一對一核對譯文',
                  '1. **逐句對位與檢查**：\n   - 將【鈔文】**逐句切開**，一對一核對譯文')
    t = t.replace('（含偷搬【記文】解釋進【疏文】、無把握亂補分類，',
                  '（含無把握亂補分類或戒條名目，')
    t = t.replace('，與疏記互證', '')
    t = t.replace('；【記文】釋字或引詞在【疏文】是否留有銜接字眼；**並須以【記文】義理反向核對【疏文】譯文，兩者絕不可自相抵觸（如【疏文】用詞在現代極易觸發反向聯想如「水乳無二」易誤為水乳交融，不可為避諱記文而留下誤導字眼，應以極簡括注或準確譯詞點明本義）**',
                  '（若用詞在現代極易觸發反向聯想，應以極簡括注或準確譯詞點明本義）')
    t = t.replace('或「銜接記文釋字須附原字」', '')
    t = t.replace('     【疏文】……\n     【記文】……', '     【鈔文】……')
    t = t.replace('（原文無該欄則略去；', '（')
    t = t.replace('`【疏文】`／`【記文】`', '`【鈔文】`')
    return t
```

## 三、單靠提示詞解決不了、建議程式／流程順手補齊的 3 件事

這幾項屬於系統架構層面，花幾行程式處理比硬寫在提示詞裡可靠得多：

1. **跨段一致性問題（第 18/21 段「大姊僧聽」、第 19/20 段「自然界」首次加注、第 09–11 段跨段引號）**
   * **原因**：`mk_review_materials.py` 把每段獨立拆成 `NN.md` 平行送審，第 19 段根本不知道第 20 段有沒有解釋「自然界」，第 21 段也看不到第 18 段的譯文（背景區只放了原文）。
   * **建議解法**：
     * 維持目前平行送審的高吞吐，但可從已定稿的高頻白文與核心專名抽出一張簡短**《本卷定譯對照表》**（例如：`大姉僧聽 → 大姊僧眾請聽！`、`自然界 → 只在全篇首次定義`），直接附在 `PROMPT` 尾端或後處理統一；
     * 跨組長引語（如 09–11）與宣唱白文的引號，在最後寫回定稿檔時做一次整卷掃描檢查成對引號即可。

2. **第 20 則重貼原文／第 07 則殘留標籤的程式防呆**
   * 在 `qwen_local.py` 解析第 3 欄輸出後，加兩條簡單檢查：
     * 用正則移除同欄內第二段起多餘的 `^(【(?:疏文|記文|鈔文)】\s*)`（解決第 07 則）；
     * 若第 3 欄首句與待審原文的前 15 個漢字（去掉標點）相似度極高（例如 > 80%），直接判定異常或自動要求模型重吐一次純譯文（擋下第 20 則）。

3. **釐清《業疏》第 02、03、10 則為何觸發 HTTP 400 內容審查**
   * 目前系統備註寫「婬戒等段落會觸發 400」，但這次失敗的 `02、03、10` 都是 `卷一上之一` 的版本考據與三學總論，**完全不涉婬戒**。極可能是 `web_search` 在白名單結果不足 2 筆時（見 `qwen_local.py` 的 `if not is_trusted and trusted_count >= 2`），仍放行了最多 2 筆非白名單網站摘要進 `messages`，或者某筆檢索內容觸發審查。
   * **建議**：
     * 在 `_save_blocked()` 一併把該組最後送出的 `messages`（或觸發 400 前呼叫過的搜尋詞與回傳 URL）存進 `_400審查.txt`，才能定位真正元兇；
     * 若不想讓不可引用的雜訊污染上下文，可考慮在 `web_search` 直接過濾掉 `is_trusted=False` 的結果（反正系統規則 4 原本就規定 `trusted=false 不可引用`）。

上一版把測試中看到的具體詞例（像「水乳無二」「行法非用」「與欲／受欲／說欲」「作法界／自然界」「跡／迹」「引證…文證」）直接塞進規則裡，屬於典型的**「過度擬合（overfitting）打補丁」**，實戰上會有三個副作用：

1. **指令膨脹稀釋重點**：每條原則動輒破百字、塞滿括號舉例，模型在長推論後反而更容易漏掉最基本的格式禁令（例如第 20 則重貼原文）。
2. **治標不治本**：只防住了這 21 段出現過的案例，換到《戒疏》殺盜婬妄或《尼鈔》衣鉢懺法時，模型未必會舉一反三。
3. **撐爆 `_nicao_prompt()` 的字串替換**：你原本用 7 個 `.replace()` 去生出尼鈔提示詞，只要 `PROMPT` 多改幾個字就很容易暗中失效（像我上一版就出現了一個沒對到的逗號，幸好沒直接跑）。

## 一、如何從「Case by Case」抽離成「通用原則」？

把這 21 題漏掉的問題全部往上抽象一層，其實只需要補強 **5 條通用規則**＋**解決 1 個內部規則衝突**，完全不用寫任何具體佛典詞例：

| 本次漏掉的具體錯誤 | 抽象後的通用原則（改寫方向） |
|:--|:--|
| • 「行法**非用**」被關進括號裡（12）<br>• 引號內塞夾註（10） | **括號邊界與骨架完整**：保留消歧義括號，但括號不得置於引號內，亦不得吞沒原文的**核心謂語或立名／因果依據**而使正句殘缺或對仗失衡。 |
| • 「水乳無二」退回誤導直譯（01）<br>• 「無讎抗」完全譯反（03） | **疏記反向互證＋防誤導聯想**：須以【記文】義理反核【疏文】譯文，兩者不得相牴觸；【疏文】用詞若在現代易生反向誤讀，不可為避諱【記文】而留下誤導字眼。 |
| • 「作法界…不出自然界…通結」（19）<br>• 「說欲／與欲／受欲」混用（16, 20）<br>• 《尼鈔》尼眾括注寫「僧」（20） | **律制邏輯自洽與名相分際**：核對作法主體、對象與空間範圍是否邏輯自洽（遇省文致窒礙則查平行律典）；動作／儀式階段專名不可跨階段混換，稱謂須依本典部別（僧／尼）嚴格區分。 |
| • 多加「極」「教法」（12, 15）<br>• 刪掉脫字說明無聲補譯（21）<br>• 「引證…文證」「跡／迹」（11, 21） | **精準度與文字潔淨**：無據增譯涵蓋未見於原文的修飾副詞與實詞賓語；原典確有明顯脫訛須補字成句時，應留 `〔補字〕` 或簡短說明（勿無聲偷補）；消除鄰近重字與正文異體字混用。 |
| • 重貼原文（20）、重複標籤（07） | **末端終檢**：把「禁貼原文／單欄單標籤」移到提示詞最後 3 行利用近因效應（recency effect），比寫在中間有效得多。 |

### ⚠️ 還有一個「二選一衝突」必須拍板

《尼鈔》第 13–17 則換行不一致，是因為現行規則同時要求：
* 「單段內部不斷行」
* 「小標題後是否換行，須與【現譯】一致」

《尼鈔》原文沒有換行，但【現譯】大部分在小標題冒號後換了行（只有 12、16 沒換）。這兩條不擇一，模型就會一直搖擺。**建議二選一寫死：**
* **選項 A（最省事）**：「一律以【現譯】原有的分段與標題換行為準，勿自行合併或拆分。」
* **選項 B（最整齊）**：「單段原文對應單段譯文，即便【現譯】在小標題冒號後有換行，亦一律併為同段不斷行（條列項除外）。」

## 二、精簡版、去 Case 化的提示詞建議

下面這版字數與你原本的相當，**沒有任何具體測試案例**，而且改用模組化組裝取代脆弱的 `.replace()`，維護起來乾淨很多。

### 1. 系統層 `SYSTEM_PROMPT`（`qwen_local.py`）

SYSTEM_PROMPT = (

### 2. 材料層 `build_prompt(is_nicao=False)`（`mk_review_materials.py`）

```python
BASE_PROMPT = '''你是南山律典審校編輯，負責核對《四分律》與南山三大部／三大記（{scope}）的白話譯文是否忠實、準確且自然。

請**只審查【本次待審段】**，前後背景僅供確認主詞、指代與律制脈絡，不需校對。

### 請依序輸出以下三欄：

1. **逐句對位與檢查**：
   - {split_rule}
   - 依序檢驗四項原則（只抓實質問題，不挑純修辭）：
     1. **忠實完整與邏輯自洽**：有無漏譯（含小註、限定條件）、無據增譯（{extra_ban}無把握亂補分類，或原文未見的修飾副詞與實詞賓語；**唯原譯已作簡短消歧義而刪掉會變質者除外**）、改壞邏輯（因果、並列、選擇關係，以及主客、作法或空間範圍的矛盾）。
        **括號與骨架**：若原譯為承接省略而補出的詞符合律意且刪之會變質，應予保留；但若圓括號吞沒了原文的核心謂語或立名／因果依據，導致正句骨架殘缺或對仗失衡，必須移回正句。
     2. **古義與律典體例**：科判指標（如「X下／下一句」指自該字起）有無誤讀；律學專名、儀式動作階段專名與部別指稱（如僧／尼之別）是否精準且全段一致；古今異義詞是否避開易生反向誤讀的直譯。{shuji_check}
     3. **引文、脫訛與括號邊界**：引文是否完整對譯、無半文半白殘句或引號內擅加擴寫；有無擅造校註或新增多餘注釋（**原譯既有的正確消歧義圓括號不得判為多餘注釋**；誤置於引號內則移至引號外。**若原典確有明顯脫訛且須補字成句，應以 `〔補字〕` 或於段末保留簡短按語標明，不可無聲偷補後又刪去說明**）。
     4. **現代漢語自足與潔淨**：有無文言直抄未譯、動詞缺主賓語、介詞拗口、鄰近字詞重複冗贅、白話正文混用異體字（非引原字時一律用標準正體字），或白話字面無意中拼出容易誤斷的詞彙。

2. **錯誤清單**：
   - 簡要條列上述查出的實質錯誤與修改方向；若皆無實質問題，寫「無實質錯誤」。

3. **修正後的譯文（完整輸出，可直接取代現譯）**：
   - **格式固定**（{tag_note}同一欄內即使含多段譯文，標籤也只在開頭寫一次，後續段落不重複加標籤）：
{out_format}
   - 給**完整譯文**；原本正確的部分盡量照原譯保留，勿為潤飾而改壞原義或造成句法殘缺。
   - **通用體例**：
     - **引文與外層引號**：極簡短或須考證原字者，引號內保留完整文言原文並於外附白話；其餘直接譯成文法完整的現代白話。**【現譯】既有的外層引號（含對話、偈頌、宣唱白文及跨段僅存的單邊引號），均須完整保留，勿擅自單獨刪除。**
     - **括號**：禁用「（未改）」「※修正」等審校流程標籤；無把握的分類不補。僅在「不補會嚴重誤讀」{cite_ji}時才加極簡圓括號（同單元同一專名僅首次加注）；原譯已有的正確消歧義括號一律保留。
     - **分段**：保留原典原有的條列換行；一般敘述與小標題後是否換行，**一律以【現譯】既有格式為準**，勿任意改動。（※若你偏愛全書統一併段，改寫為「一律不斷行」即可）
     - **刪減原譯任何字詞前，須確認不會因此造成語意斷裂、條件放寬或比喻變質。**
     - **輸出前最後自檢**：
       1. 第 3 欄**只輸出純白話譯文，嚴禁重貼任何原文或標點版原文**。
       2. 欄位標籤各自只出現一次，無殘留重複標籤。
       3. 同一術語全段指涉一致，無重字贅詞與異體字混用。
'''

def get_prompt(is_nicao=False):
    if is_nicao:
        return BASE_PROMPT.format(
            scope='鈔文',
            split_rule='將【鈔文】**逐句切開**，一對一核對譯文（段內每句都要查完，不可中途停止）。',
            extra_ban='含',
            shuji_check='',
            tag_note='',
            out_format='     【鈔文】……',
            cite_ji='',
        )
    return BASE_PROMPT.format(
        scope='疏文與記文',
        split_rule='將【疏文】與【記文】**逐句切開**，一對一核對譯文（段內每句都要查完，不可中途停止）。',
        extra_ban='含偷搬【記文】解釋進【疏文】、',
        shuji_check='【記文】釋字或引詞在【疏文】是否留有銜接字眼；**並須以【記文】義理反向核對【疏文】譯文，確認兩者無任何矛盾**。',
        tag_note='原文無該欄則略去；',
        out_format='     【疏文】……\n     【記文】……',
        cite_ji='或「銜接記文釋字須附原字」',
    )
```

## 三、兩個補充提醒（非提示詞能解，交給程式最省力）

1. **跨段一致性（第 18/21 則、第 19/20 則）**：
   既然單元是平行送審，第 19 則不可能知道第 20 則已經解釋了「自然界」，第 21 則也看不到第 18 則的譯法。這類問題不需要塞進主提示詞，建議在**前處理或整卷合併後處理**解決（例如高頻儀軌固定套語 `大姉僧聽 → ……` 用對照表統一；整卷合併後再去重重複括注與檢查跨段引號）。
2. **第 20 則重貼原文／第 07 則重複標籤防呆**：
   可在 `qwen_local.py` 存檔前加 3 行後檢查：去掉同欄第二段起重複的 `【疏文】/【記文】/【鈔文】`，並檢查第 3 欄首句與待審原文的前 15 個漢字是否高度重疊，重疊就打回重跑或標記告警，比單靠提示詞祈禱模型聽話可靠。
