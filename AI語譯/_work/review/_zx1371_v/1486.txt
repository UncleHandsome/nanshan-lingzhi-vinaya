===== resp_1486.txt（3540 字）=====
整體讀來相當流暢，戒相的掌握也大多到位（如「三時」譯為春夏冬、保留比丘尼「五衣」、「洗淨過分」、「頂戴持」等都處理得不錯）。以下按「該改」→「可再斟酌」→「宜加註」分層列出，並附建議譯法。

## 一、比較明確、建議修改的地方

### 【1486-0001】#38

| 原文 |  presently 譯文 | 問題與建議 |
|---|---|---|
| **手搏比丘尼** | 用手掌擊打比丘尼 | 律中「打」與「搏」是兩條戒：「打」是實打，「搏」多解為**舉手（掌）作勢欲打而未打**。譯成「用手掌擊打」與前一條「瞋心打比丘尼」重複。建議：「（瞋心）舉手作勢要打比丘尼」。 |
| **屏處敷僧臥具** | 在私密處鋪設僧眾臥具 | 原文承前省略「不舉」。單說「鋪設僧眾臥具」會變成「不准鋪」，語意失真。應補：「在隱蔽處鋪設僧眾臥具（離去時）而不收起」。 |
| **百夏尼不禮小比丘** | 百夏臘比丘尼不禮拜剛受戒的年幼比丘 | 「小比丘」指**戒臘淺**，不是年紀小；「百夏」也是受戒年數（極言其久），非實歲。建議：「受戒已百夏（戒臘極高）的比丘尼，不禮拜新受具、戒臘淺的比丘」。 |
| **輒問大僧義** | 隨意向大僧探問深奧法義 | 「深奧」是添譯，原文無此義。建議：「未經允許（不白眾）便擅自向比丘請問法義」。 |
| **不攝耳聽戒** | 不收攝耳根靜聽戒律 | 直譯生硬且易誤解為修根門。此戒指**說戒時不專心諦聽**。建議：「（說戒時）不專心諦聽戒法」。 |
| **別眾食** | 脫離大眾自行別眾受食 | 「別眾食」律義是**四人以上不依僧次而受別請共食**，不是「自己單獨去吃」。建議：「四人以上不依僧次、受別請而食（別眾食）」。 |
| **不受食** | 不經受食而吃 | 循環解釋、讀者難懂。建議：「食物未經他人授與（未作法受）便取食」。 |
| **乞生五穀** | 乞討未熟的五穀 | 「未熟」易讀成「未成熟」。此指**生的、未經炊煮的穀米**。建議：「乞求生的（未煮的）五穀」。 |
| **壞生種** | 破壞植物種子 | 「生種」含根種、枝種、節生種、覆羅種、子子種等，重點在**損壞生長中的草木**，不限於種子。建議：「毀壞生長中的草木（生種）」。 |
| **背請** | 違背邀請赴食 | 即「展轉食」：已受某家請，又背棄前請轉往他家受食。建議把這層意思譯出。 |
| **乘行** | 乘車出行 | 應是「乘乘（而行）」，含象馬車轎等；且律有「無病」前提。建議：「（無病而）乘坐車乘等代步出行」。 |

另有兩處**原文句讀可疑，建議回查律文再定**，不宜逕依現譯：

1. **「強敷僧臥具。惱他比丘尼。」**——後文另有「口惱他」，此處很可能應連讀為一戒：「強敷僧臥具（以）惱他比丘尼」（律：知他尼先住，於中間強敷臥具，令彼嫌迮自避）。現譯拆成兩條，可能多出一項。
2. **「一槌𮌎露身」**——「𮌎」疑為「胸」之異體；此處或是「搥胸」與「露身」二事（或指瞋恚時搥胸、露形之舉）。現譯「一拳捶胸裸露身體」把兩個動作併成一個畫面，語意含混，建議核對《四分律》尼戒相關條文後分列或補註。

### 【1486-0009】#46（兩處理解問題）

1. **「如婬戒發心動身口而未起方便色等」**
 現譯：「動了念頭、**驅動身口**，但尚未引起前行動作」——前後自相矛盾（已動身口又未起動作）。原文「欲動身口」的「欲」不可漏。
 建議：「例如犯淫戒時，已起不善心、**想要**發動身口，但尚未真正現起（身口的）方便動作（表色）」。
2. **「乃至突吉羅中發心欲令身不齊整著五衣等」**
 現譯拆成「讓舉止不端莊」＋「胡亂穿戴五衣」兩事；其實「身不齊整著五衣」是**一事**（故意不整齊地穿著五衣，即眾學法「齊整著衣」之違犯）。
 建議：「乃至突吉羅中，故意要使自身不整齊地穿著五衣等」。

## 二、精確度／用語可再斟酌

**#38**
- 毀呰語 → 「毀謗謾罵」偏「謗」（易與無根謗混）；宜作「毀辱譏罵語」。
- 擊攊他 → 「**互相**搔癢戲弄」：此戒是以手指搔戳**他人**令癢笑，非雙向；宜「以手指搔癢戳弄他人」。
- 非時食 → 可明說「過午（日中之後至明旦）進食」。
- 泉渠水中 → 「泉流**池**水」：渠是溝渠水道，非池；宜「泉水、溝渠中」。
- 自手紡績 → 「紡紗**織布**」：紡績是紡紗績麻，織是另一事；宜「親手紡紗績麻」。
- 用香塗身 → 「用**香油**塗抹」原文未限油（末香、塗香皆攝），可作「以香塗身」。
- 於家生嫉妬 → 宜點出是**慳嫉施主家**（不願他人親近、分其供養），單說「對居士家生嫉妒」語意不明。
- 「僧」的所指前後不一致：「不詣僧自恣」譯「僧團」、「不依僧安居」譯「比丘僧」、「不白僧入寺」譯「僧眾」。此三處「僧」皆指**大僧（比丘僧）**，建議統一；「不詣僧自恣」並可補「求見、聞、疑三事自恣」；「不白僧入寺」宜作「不先告知比丘僧便擅入（比丘）寺院」。
- 不半月請教誡 → 「**未能**每半月」語帶「做不到」；宜「沒有每半月往比丘僧中求請教誡」。
- 度諸遮童女 → 「度化」較泛，宜「度有遮難（不合受戒資格）的童女出家受具」。
- 不以二事輒授弟子 → 「不用二法」只是把「事」換成「法」，讀者仍不知何指；**「二事」宜查明律文後加註**（一般解為法／教誡與衣食二種攝受），並把「輒授」的「擅自授戒（度弟子）」譯出。
- 受戒已離和尚出去 → 「離開戒和尚離去」重複；且尼之和尚為**和尚尼**，可作「受戒後即離和尚尼他去（不依止）」。
- 「屏處」一會兒譯「私密處」、一會兒「隱蔽處」，建議統一。
- 戒身具足 → 「戒體具足」是義解，可保留，但較貼原文為「戒身（戒法蘊）具足」。

**#43**
- 「蘇油等」是**酥、油等**兩類（尼提舍尼八事：酥、油、蜜、石蜜、乳、酪、魚、肉），現譯「酥油等物」易被讀成一個詞「酥油」。建議「酥、油等（八種食物）」並加註。
- 「經居士家」的「經」是經過／到，譯「進入居士家中」稍重，可作「（自行）到居士家」。

**#46**
- 「非威儀突吉羅」→ 「威儀敗壞」語氣偏重，宜「不合威儀的突吉羅」。
- 「各有三品吉羅」→ 「三種**等級**」易解為輕重三等；此「品」是品類、條數，宜「三種突吉羅」。
- 「若約諸篇方便獨頭犯乃至無量」→ 「違犯的**次數**無窮無盡」偏了，原意是**罪相品類**無量，宜「（罪相）多至無量」。
- 「從生／獨頭」首見時譯「方便罪／獨立罪」，後文又混用，建議保留原術語並首次加註。
- 「突吉羅惡說」宜作「突吉羅（惡作）、惡說」，明示第五篇兩支。
- 「初篇……第五篇」可加註篇名（波羅夷／僧殘／波逸提／提舍尼／突吉羅），讀者才好對照「輕重既殊」。

**#40**：兩個典故未加註，白話讀者無法理解「為何要像他們」——這正是本段的重點（寧死不犯輕戒）。建議：
> 「妳應當自責己心，對所犯之罪生起厭惡遠離之心。從今以後，絕不可再犯，要像**護鵝珠的比丘**（鵝吞了寶珠，他寧受珠師拷打垂死也不肯說出，以護鵝命）與**草繫比丘**（被賊以生草繫縛，寧不動身而壞草，堅守不壞生之戒）一樣，毫無差別。」答：「弟子定當頂戴受持，不敢重犯。」

「生厭離意」現譯「厭惡離絕的意念」也偏生硬，如上改即可。

**#45**：「誡責要期」可稍作展開——「（懺悔主的）告誡自責與立誓要期（『自今已去更莫重犯』）」，讀者較易對應前文。

**#41**：波羅提提舍尼首見可加意譯「向彼悔／悔過法」，與波逸提、突吉羅體例一致。

## 四、小結

- **必改**：手搏≠打；屏處敷具漏「不舉」；小比丘≠年幼；「深奧」添譯；不攝耳聽戒；別眾食；不受食；生五穀；壞生種；#46「欲動身口」漏「欲」與「不齊整著五衣」誤拆為二。
- **待查原文**：「強敷僧臥具／惱他比丘尼」是否一戒、「一槌𮌎露身」的斷句與字義、「不以二事」的二事所指。
- **加註**：護鵝珠、草繫比丘、提舍尼八事、二事、五篇篇名、僧祇支、麤罪（波羅夷僧殘）。
