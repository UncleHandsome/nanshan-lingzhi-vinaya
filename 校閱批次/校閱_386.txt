# 校閱材料　第386檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【386-0001】資持記/05b_上四#64
【原文】借義以訓，聽猶令也。謂使令作之，不可違故。若作此解，餘文無復壅矣。問中。一時四月，約過是同，而不盡制，故須問釋以彰教旨。答有二意，初約開後答。唯被前安居人。身為苦器，飢渴寒熱，隨時所須，故號待形。準通五利，且舉外資，是正開意，故但云衣服也。次約開前答。
【譯文】借用字義來訓釋，「聽」字就等同於「令（飭令）」的意思。意思是命令派遣僧眾必須去作，是絕對不可違背的。如果能夠作這樣的理解，那麼其餘經律文獻就再也沒有滯礙不通的地方了。在提問之中。一個季節各包含四個月，單就遊行可能產生的過失而言三季本是相同的，佛陀卻沒有在所有的時間都全部嚴禁遊行，所以必須透過問答解釋來彰顯立教設制的深奧意趣。回答有兩種意理，首先是針對「安居之後開許受衣」來回答。這唯獨普及到那些嚴格實行前安居的人。因為色身乃是承載痛苦的器皿，飢渴寒熱之苦隨時都需要資生之物來撫慰，所以稱為「待形（滋養色身）」。比照普遍通達的五種利養，這裡暫且舉出外在的物資，這是佛陀正宗開許的本意，所以才單單提及「衣服」。其次是針對「安居之初開許寬限續結」來回答。

【386-0002】資持記/05c_上四#1
【原文】則攝中後二位。教太急者，攝機不盡也。用難常者，機緩不及也；異緣或阻，不可期故。次別明三時，標中。結前生後：前明一年三時緩急，後明一夏三時前後。正示中，初文，前列三位。故下，引證。即增三文。疏云：增三，具明前中後也。據時定分，前後一日，中間安居二十九日。
【譯文】便能涵蓋中安居與後安居這兩種位次。若是教法規定得過於緊迫，就無法完全攝受各種根機。若行事運用上難以作為常規準則，根機較鈍者便會趕不上；更何況各類外緣隨時可能阻礙，是無法預先期定的。其次是個別說明三種時節，標題之中包含著承先啟後的作用：前半部說明一年之中春、夏、冬三時的寬緩與緊迫，後半部則說明一夏九十天之中前、中、後三期的先後次序。在正文說明中，開頭先列出三種位次。接著引律文作證，也就是《四分律》增三法的文句。道宣律師在《業疏》中說：《四分律》增三法完整說明了前、中、後三種安居。依照時間來劃分，前安居與後安居各佔一天，中間的中安居則有二十九天。

【386-0003】資持記/05c_上四#2
【原文】次科，初引文示。即〈安居犍度〉。彼云：佛言：有二種安居，有前安居，有後安居。住前三月，四月十六坐也。住後三月，五月十六結也。雖下，義決，初句點文缺。然下，顯義具。文指二日為前後，則義必含中，故云於理自明也。疏云：犍度中但明前後各住三月，則無中也；
【譯文】下一個科判，首先引述律文予以明示，即出自〈安居犍度〉。該處記載：佛陀說有兩種安居，一種是前安居，一種是後安居。住於前三個月的，是在四月十六日開始安居；住於後三個月的，是在五月十六日結夏。後文雖有義理的決斷，開頭一句卻點出律文有所缺漏。然而緊接著顯發義理本身是具足的。律文既然指出這兩天作為前與後，其義理必定包含著中間的中安居，所以說在道理上自然明白。《業疏》中說：犍度中只說明了前後各自安住三個月，便沒有提到中安居；

【386-0004】資持記/05c_上四#3
【原文】故舍利弗欲於佛所安居，十七日至，制後安居；據相以言，但前一日為前安居，餘三十日為後安居；莫不望初俱名後故，則缺中也。下指結文，三法別故。次科。標云泛明者，此中正明安居前後；而下三門名同事別，以類相從，故云泛也。初中。是前下，合云得受五利名賞。
【譯文】因此舍利弗想在佛陀處所安居，到了四月十七日才趕到，佛陀便為他制定後安居；若就事相而言，僅僅前一天算是前安居，其餘三十天都算作後安居；這無非是因為相對於一開始的初日而言，後面全部都稱為「後」，因此便缺落了中安居之名。下文指出作法的結文，乃是因為三種法各不相同的緣故。下一個科判，標題稱為「泛明（廣泛說明）」者，是因為此處原本主要在說明安居的前後時段；然而下面三門只是借用相同的名稱而事相各異，將其依同類歸納在一起，所以稱為「泛」。在第一項中，「是前」等語，文意應當接續為：能夠獲得五種利養，稱為賞賜。

【386-0005】資持記/05c_上四#4
【原文】結者下，合云是後；上下相映，在文省約。二中，初明前不結有犯不犯。十六日下，明後不結皆犯。除難事者，示開緣也。尼同別者，簡通濫也。同謂同前，別即別後；以尼外化義少，不許遊涉，故重於僧。三中，初明前者。乃至後夏不結者，雖未暇加法，而身已在界，故並成前坐。
【譯文】「結者」等語，文意應當接續為：這屬於後安居；上下文字相互呼應，在文筆上力求簡省約要。在第二項中，首先說明前安居若不結夏，何時有犯、何時無犯。「十六日」以下，說明後安居若不結夏則統統犯戒。「除難事者」，是在明示開許的特殊因緣。「比丘尼同別」一句，是為了簡別並防止相濫。所謂「同」，是指同於前安居；所謂「別」，是指後安居另有不同；這是因為比丘尼向外教化的意義較少，不被允許隨意外出遊行，所以戒律對她們的限制比僧眾更為嚴格。在第三項中，首先說明前安居的情形。乃至於到了後夏仍未結夏的人，雖然還沒來得及加行作法，但身體已經在結界之內，因此都算作成辦了前安居。

【386-0006】資持記/05c_上四#5
【原文】是名下，謂結夏日異，受歲日同。前一月中，隨日可結，故云三十日安居也。問：難事不息都不結者，為得夏否？答：疏云：或五日三日乃至一月，雖不結之，不失前坐；以難不結，非是故心。若下，明後。以後安居人本是八月十五日夏滿，聽隨前安居人探前自恣。
【譯文】「是名」以下，是指結夏的日期雖然不同，但受歲自恣的日期卻是相同的。在夏初的一個月內，隨哪一天都可以結夏，所以稱為「三十日安居」。有人問：如果災難阻礙一直沒有平息，完全不曾作法結夏，究竟算不算是獲得了一夏？回答說：《業疏》指出：即使耽誤了五天、三天，乃至一個月，雖然不曾作法結夏，卻不會失去先前安居的資格；因為這是由於災難而未能結夏，並不是出於故意放逸之心。「若」字以下，說明後安居的情形。因為後安居的人原本應當在八月十五日夏滿，律中開許他們跟隨前安居的人提前進行自恣。

【386-0007】資持記/05c_上四#6
【原文】令由難阻隨息開作，故通一月；此即結夏日同，受歲日異。問：前中二種，有難開否？答：準理應通。若爾，律中有難開增自恣者？答：彼是外界鬪諍，此即王賊等阻障；俱號難緣，名同事別。上三前後，初賞罰，以前安一日為前，後三十日為後。次得罪中，以前三十日為前，後安一日為後。
【譯文】為了因應災難阻礙、隨其平息而開許作法，所以時間通達整整一個月；這便是結夏的日子相同，而受歲自恣的日子互異。有人問：在前安居與中安居兩種情況下，遭遇災難時也有此類開許嗎？回答說：依照義理推敲應當也是通用的。如果真是這樣，律中為何又有遭遇災難而開許增加自恣日期的規定呢？回答說：那是因為界外發生了鬥爭，而此處則是指遭遇官府、盜賊等阻礙；雖然都稱為難緣，卻是同名而事相各異。以上三種前後：第一種賞罰，是以前安居的一天為「前」，其後的三十天為「後」。第二種結罪，是以開始的三十天為「前」，最後安居的一天為「後」。

【386-0008】資持記/05c_上四#7
【原文】三難事中，即約安恣互明前後。疏有六種。三種同前。第四位約前後，初後兩夏各十六日，中間二十九日。五明行住〔住謂舊住，行即外客。〕，對念二法，行住通用；忘成及界，以是行人，先有要故。〔又云：必舊有要，例亦開之。〕六據法不同，對念作法，以容預故。
【譯文】第三種難事之中，則是綜合安居與自恣的關係互論前後。《業疏》中列出六種情形。其中前三種與前面所說相同。第四種位次是就前後兩夏而言，初夏與後夏各有十六天，中間則有二十九天。第五種是說明行路人與定居者（「住」是指原住僧眾，「行」則是指外來客僧），面對面作法與心念作法這二種法，行路人與定居者皆可通用；至於忘記而自然成夏以及跨入界內，乃是因為此人身為行路者，先前心中已有確定的期約（疏中又說：如果原住僧人本來就有明確期約，依例也可獲得開許）。第六種是依據作法性質的不同：面對面與心念作法，因為時間較為寬裕從容；
