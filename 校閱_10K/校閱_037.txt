# 校閱材料　第037檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【037-0001】01_行事鈔/03a_卷上之三#17
【原文】統明師義，幸有老宿碩德，則生善於後。《五百問》云：比丘五臘不滿度弟子，知非而度，犯墮。弟子不知是非，得戒；若知，不得戒。《明了論疏》：若已得五夏，為受大戒作證人及作威儀師。七夏已去，得作羯磨闍梨。既是師位，故不得互共同床坐。
【譯文】統體說明為師之義理，慶幸能有戒臘深長、德高望重的長老碩德在座，便能使戒子在後續修道中生發善法。《五百問經》說：比丘戒臘不滿五夏就剃度弟子，明知非法而剃度的，犯墮罪（波逸提）。弟子若不知是非法，得戒；如果知情，則不得戒。《律二十二明了論疏》說：如果戒臘已滿五夏，可以為受具足戒作證戒人以及作威儀師。戒臘滿七夏以上，可以作羯磨阿闍梨。既然身處師長的尊位，所以諸位師長彼此不得同床而坐。

【037-0002】01_行事鈔/03a_卷上之三#18
【原文】三教發戒緣。《薩婆多》云：凡受戒法，先與說法，引導開解，令一切境上起慈愍心，便得增上戒。就文如此，今以事求，初明緣境，後明心量。初中，所發戒相，乃有無量。由未受戒前，惡遍法界；今欲進受，翻前惡境，並起善心；故戒發所因，還遍法界。若隨境論，別鈔應有三十餘紙；要而言之，不過情與非情，空有二諦、滅理涅槃、佛說聖教、文字卷軸、形像塔廟，地水火風虛空識等；法界為量，並是戒體。故《善生》云：眾生無邊故，戒亦無邊。《薩婆多》云：非眾生上，亦得無量。如十方大地，下至空界；若傷如塵，並得其罪。今翻為戒善，故遍陸地。即《善生》言：大地無邊，戒亦無邊；草木無量，海水無邊，虛空無際，戒亦同等。《薩婆多》云：新受戒人，與佛戒齊德也。以此而推，出家僧尼，真是功德善法之聚；位尊人天，良由於此。不論受而具持，功德難數；若毀破者，猶利無邊。故《十輪》云：破戒比丘，雖是死人；是戒餘力，猶能示於人天道行，猶如牛黃麝香燒香等喻。佛因說偈：「瞻蔔華雖萎，勝於一切華；破戒諸比丘，猶勝諸外道。」是故行者，破戒之人，功德無量，遠有出期；不受戒者，隨流苦海，永無解脫。《智論》說言：寧受戒而破，初入地獄，後得解脫；不受戒者，輪轉三界。《涅槃》亦云：雖復得受梵天之身，乃至非想，命終還入三惡道中。良由無戒，故致往返。如是隨機廣略，令其悟解；若不知者，心則浮昧，受戒不得，徒苦自他。《薩婆多》云：若淳重心，則發無教；輕則不發。豈可虛濫，理當殷重。
【譯文】第三、教導發起戒體的因緣。《薩婆多論》說：凡是傳授戒法，必須先為他宣說教法，引導使其開解明了，讓他在一切所對之境上生起慈愍之心，便能獲得殊勝的增上戒。經文意義如此，現在以實際事理推求，首先說明所緣之境，其次說明能緣的心量。在第一項中，所發起的戒相實有無量無邊。因為在未受戒之前，惡心惡業遍及法界；如今想要進一步受戒，便翻轉先前的惡境，對一切境普遍生起善心；所以戒體得以引發的所緣之境，同樣遍滿整個法界。如果順著所對之境來論述，另外撰寫鈔文應有三十多張紙那麼多；簡要來說，不外乎是有情與無情、空與有二諦、寂滅之理的涅槃、佛陀所說的聖教、文字經典卷軸、佛像塔廟，以及地、水、火、風、虛空、識等六大；以盡虛空遍法界為其數量範圍，全都是所發的戒體（量等法界）。所以《善生經》說：眾生無量無邊，所以戒也是無量無邊。《薩婆多論》說：在非眾生（無情物）之上，也能得到無量的戒善。比如十方大地，下至虛空法界；如果損傷哪怕如微塵許，都會結罪。如今翻轉過來化為護戒之善，所以戒善遍滿大地陸境。正如《善生經》所言：大地無量無邊，戒也是無量無邊；草木無量、海水無邊、虛空無際，戒也是同等無邊。《薩婆多論》說：新受戒的人，其戒德與佛陀的戒德功德齊等。由此推論，出家的僧尼真正是一切功德善法的匯聚；地位尊崇於人天之上，確實就是因為受持了這個戒體。且不論受戒之後圓滿具足受持，其功德難以計數；縱使有所毀犯破戒，戒體的殘餘功德仍然有無邊的利益。所以《大乘大集地藏十輪經》說：破戒比丘雖然在佛法中如同死人；但憑藉此戒的殘餘力量，依然能夠為人天眾生示導修行的善道，就如同牛黃、麝香、焚香等比喻一樣。佛陀因此說偈言：「瞻蔔花雖然枯萎，依然勝過世間一切鮮花；破戒的諸多比丘，依然遠勝世間一切外道。」因此修道者須知，受戒而破戒的人，因受戒功德無量，長遠之後終究有解脫脫離苦海的期會；而完全不受戒的人，只能隨波逐流於苦海之中，永遠沒有解脫的可能。《大智度論》說：寧可受戒而後破戒，起初雖墮入地獄，日後仍能得到解脫；不受戒的人，只能長劫輪轉於三界之中。《大般涅槃經》也說：縱然受生獲得大梵天之身，乃至達到非想非非想處天，天福享盡命終之後，還是會墮入三惡道之中。這確實是因為沒有受戒的緣故，才導致生死往返流轉。像這樣隨順受戒者的根機廣說或略說，令他省悟明解；如果不知道這些道理，心念就會浮泛昏昧，受戒不能得戒，白白勞苦自己與他人。《薩婆多論》說：如果以純厚至誠的心受戒，就能發起無作戒體（無教）；心念輕浮則不能發起。這怎可虛妄濫受，理當極盡殷重懇切。

【037-0003】01_行事鈔/03a_卷上之三#19
【原文】次令發戒。應語言，當發上品心，得上品戒；若下品心者，乃至羅漢，戒是下品。《毘跋律》曰：發心我今求道，當教一切眾生，眾生皆惜壽命。以此事受，是下品耎心，雖得佛戒，猶非上勝。餘二就義明之：云何中品？若言我今正心向道，解眾生疑，我為一切作津梁，亦能自利，復利他人，受持正戒。云何上品？若言，我今發心受戒，為成三聚戒故，趣三解脫門，正求泥洹果；又以此法，引導眾生，令至涅槃，令法久住。如此發心，尚是邪想；況不發者，定無尊尚。《智論》云：凡夫始學，邪心中語；那含果人，慢心中語；羅漢果者，名字語也。如此自知心之分齊，得佛淨戒亦有分齊。故文云：佛子亦如是，勤求禁戒本等。問：此教宗是何乘？而發大乘志耶？答：此四分宗，義當大乘。《戒本》文云：若有為自身，欲求於佛道，當尊重正戒，及迴施眾生共成佛道。律中多有誠例。光師亦判入大乘律限。如是發戒緣境，及心有增上；此之二途，必受前時，智者提授；使心心相續，見境明淨；不得臨時方言發心。若約臨時師授，法相尚自虛浮，豈能令受者得上品耶？或全不發，豈非大事。
【譯文】其次是令受戒者發起戒體。戒師應當對他說：應當發起上品之心，才能得上品戒體；如果是發下品心，即便證得阿羅漢果，所納受的戒也只是下品戒。《毘跋律》說：若發心想「我如今求道，應當教化一切眾生，眾生都愛惜生命」，以此心境來受戒，這是下品的軟弱之心，雖然能得到佛戒，但仍非殊勝上品。其餘中品與上品從義理上來闡明：何謂中品？如果說「我如今端正心念向道，為眾生排解疑惑，我作一切眾生的津梁渡口，既能自利，又能利益他人，以此發心受持正戒」，這就是中品心。何謂上品？如果說：「我如今發心受戒，是為了成就三聚淨戒的緣故，趣向空、無相、無願三解脫門，正求證得大般涅槃聖果；並以此正法引導一切眾生，令他們皆到達涅槃彼岸，令正法長久住世。」像這樣的發心，若依究竟實相而言尚且帶有妄想分別；更何況是完全不發心的人，必定毫無尊貴殊勝可言。《大智度論》說：凡夫初學者，是在妄想分別心（邪心）中說話；阿那含果聖人，是在微細我慢心（慢心）中說話；阿羅漢果聖人，只是順應假名說話（名字語）。像這樣自己明白自心的層次界限，所得佛陀淨戒也就有其相應的品第階位。所以經文說：「佛子也是如此，勤勉求索禁戒的根本」等。有人問：這部《四分律》教宗屬於哪一乘？為什麼要受戒者發起大乘的大志呢？回答說：本《四分律》宗，在義理上實通於大乘。《戒本》序文說：「若有為自身，欲求於佛道，當尊重正戒，及迴施眾生共成佛道。」律藏中多有這類真實例證。慧光律師亦判屬《四分律》進入大乘律的範疇。像這樣發戒的所緣境，以及能緣心之增上精進；這兩種軌轍，必定要在正式受戒之前，由具智慧的戒師提點傳授；使得受戒者念念相續不斷，觀察所緣境清淨明了；絕不能到了登壇受戒的當下臨時才講發心。如果在登壇受戒時戒師才臨時口授，所開示的緣境法相尚且虛浮草率，又怎能令受戒者得到上品戒體呢？甚至可能完全發不起戒體，這難道不是耽誤大事嗎？
