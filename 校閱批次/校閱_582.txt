# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第十正受戒者若答無遮難堪為正受將欲受戒先勗心懷令生上品意戒師語言善女人汝遮難竝無眾僧同共隨喜當與汝戒但戒善廣大亘周法界當起上品心得上品戒何等上品故前緣起云為趣泥洹果向三解脫門成就三聚淨戒令正法久住此是上品智度論云下持戒生人中持戒生六欲天上持戒生色無色天又下清淨持戒得阿羅漢道中清淨持戒得辟支佛道上清淨持戒得佛道當廣開汝懷所以爾者塵沙戒法注汝身中不以報得狹小而得受也當作虗空器量之身徧周法界一切凡聖依正兩報無問自他等境皆發塵沙等戒汝當願納此法又此戒法若是有色者入汝身時如天崩地陷之聲由是非色法故令汝不覺汝當起驚悚之意勿得懈慢今為汝作羯磨發此塵沙戒善所以法界善戒而得用羯磨發者汝不聞外道仙人用呪術之力尚能移山鎮海迴天轉日豈況如來六道之師所說聖教法中之上而無此力今白三羯磨世尊口出我傳佛教發汝戒體汝須知之正作法前白云眾僧慈悲布施某甲戒作此語已應四向顧望勿令入睡眠亂語非法別眾等坐若有即須喚令正坐向羯磨師一心聽說十誦云證他受戒各各入定亂語戲笑不知羯磨成否佛言不成若作羯磨者應分別之是第一羯磨第二第三亦如是莫餘覺餘思惟應起敬重憶念違者吉羅又文殊問經云四眾於何時不得作聲或身口木石及諸餘聲佛告文殊於六時中不得作聲一禮佛時二聽法時三眾和合時四乞食時五正食時六大小便時如是誡已然後白云。
【譯文】第十種「正受具戒」，如果回答沒有遮難，就具備正受戒法的資格。即將受戒時，先勸勉誡勉她的心懷，令她生起上品受戒心願。戒師告訴她說：善女人，你的遮障重難都沒有，大眾僧同心隨喜，將要傳授你戒法。然而戒善功德極其廣大，周遍涵蓋法界，應當生起上品之心，才能得上品之戒。什麼叫上品？就像前面明發戒緣中所說：為了趣向涅槃妙果，趣向三解脫門，圓滿成就三聚淨戒，令正法常久住世，這就是上品心。《大智度論》說：以下品心持戒，生於人道；以中品心持戒，生於六欲天；以上品心持戒，生於色界、無色界天。又說：以最下等的清淨持戒，能得阿羅漢道；以中等清淨持戒，得辟支佛道；以最上清淨持戒，圓滿佛道。你應當大大拓開你的胸懷心量！之所以要這樣，是因為無量如塵沙般的戒法要注入你的身心之中，不能以你所受業報之身的狹小來局限承受。應當作觀想：自己的身量猶如虛空容器一般，周遍法界一切凡夫聖人、依報正報，不論自他內外等境界，都引發起塵沙般的戒體。你應當發願全盤納受這戒法。又這戒法如果有形色形相，進入你的身體時，其震撼就如同天崩地陷的聲音一般；只因為它是無形色的精神心法，才使你毫無知覺。你應當生起戒慎驚懼、警惕肅敬之意，萬不可懈怠怠慢！現在為你作羯磨法事，發起這塵沙般的戒善功德。法界戒善之所以能用羯磨引發出來，難道你沒聽說過：外道仙人藉由咒術之力，尚且能移山填海、回轉天地日月，更何況是如來這位六道眾生的大導師，其所說的至高聖教法門，難道會沒有這種轉移造化的力量嗎？現在這「白一羯磨三說」（三番羯磨）是世尊親口所宣說，我傳承佛陀的教法，以此引發你的戒體，你必須深切明白這一點。在正式作法之前，應向大眾告白說：「僧眾慈悲，布施給某甲戒法。」說完這話後，戒師應當環顧四周，不要讓人陷入昏睡、雜亂私語、不合法度的離座等情況；如果有，就必須立刻叫她端正坐好，面向羯磨師一心專注聆聽。正如《十誦律》說：為他人作受戒證明時，如果各自入定、雜話嬉笑，不辨羯磨究竟成就不成就，佛說這羯磨不能成就。若在作羯磨時，應當清晰分別：這是第一次羯磨，第二次、第三次也是這樣，心中切莫雜想別的念頭、思維外緣，應當生起敬重心與正念；違犯的人結突吉羅罪。又《文殊問經》說：四眾弟子在什麼時候不得發出聲響，不論是身體動靜、口中言語、敲擊木石及其他一切雜音？佛陀告訴文殊師利菩薩：在六種時節之中不得發出聲音：一是禮佛時，二是聽法時，三是大眾和合行法時，四是乞食時，五是正受食時，六是大小便時。像這樣警戒告誡完畢後，接著宣說白文：

【原文】五問留髮白衣與受具足得戒否答有得不得問云何有得答得者謂志求出家厭世俗情王難不聽落髮出家具此意者得戒不疑故婆論問云不除髮得戒否答得但非威儀又伽論問云若白衣為和尚與白衣受具足戒得戒否答得戒僧犯吉羅又十誦波離問云若男子作女威儀女相女形制已如男子法受戒得戒否佛言得戒眾僧得罪女人作男子威儀得戒亦然五百問事云壇上師僧或著俗服或犯禁戒若受戒人知是非法不得不知者得若弟子著俗服當時不知者得問云何不得戒答數見邊方尼妄行戒律見有誠文無問善惡遂即雷同總與授戒觸事無知專習非法紡績機織俗務是常長眉高髻綺染恒式師有貪利門徒之心弟子有偷形避伇之意所以僧不揀弟子好惡得利便授弟子不擇師行是非苟求資蔭永惟斯理俗禮尚自不成況出世清虗何容得就故此律宗要出家相具應剃髮著袈裟與出家人同若著俗服外道服眾莊嚴具裸形等竝不名出家受具足戒若受戒人不自稱名不稱和尚名說乞而不乞若眠醉狂瞋恚無心受戒或心不當境或境不當心或心境俱不相應竝名非法不名受戒前後無違方名辨事今兩述宗取捨任從然諸經律竝令落髮同僧出家異俗輒依論開良恐非然又論非宗要宜就律儀。
【譯文】第五個問題：給蓄留頭髮的俗衣女子受具足戒，能得戒嗎？回答：有能得戒的，也有不能得戒的。問：什麼情況下能得戒？答：能得戒的情況，是指她立志誓願出家，厭離世俗情感，只是因為遭遇國法王難不准落髮出家；具備這種至誠心意的，無疑能得戒。所以《薩婆多論》問：不剃除頭髮能得戒嗎？答：能得戒，只是不合威儀。《僧伽羅論》也問：如果白衣居士作和尚，給白衣受具足戒，能得戒嗎？答：受戒者得戒，傳戒之僧犯突吉羅罪。又《十誦律》中優波離問：如果有男子裝扮成女人的威儀、女人的容相、女人的形體，卻依照男子的法度來受戒，得戒嗎？佛陀說：得戒，但與會僧眾犯戒罪。女人裝扮成男子威儀來受戒，也是如此。《五百問事》說：戒壇上的師僧，有的身穿俗服，或者犯了禁戒，受戒人如果明知這是不法，就不得戒；如果不知情，則能得戒。若是弟子身穿俗服，當時若不知情，也能得戒。問：那什麼情況下不得戒呢？答：屢次看見邊遠地區的尼僧妄行戒律，見律文有這些寬容開許之詞，便不論善惡，一律隨波逐流，全都為她們傳授具足戒。這些人對戒事一無所知，專門修習世俗非法，紡紗織布，視世俗勞務為家常便飯，畫長眉、梳高髻、穿著華麗染衣為日常慣習。做師父的貪圖收徒弟的利益供養，當弟子的懷著偷換形相、逃避賦稅勞役的心思。所以僧團不挑選弟子的賢愚善惡，有利可圖便給予傳授；弟子也不審擇師父的德行是非，苟且求取庇護蔭涼。深思這種道理，連世俗的禮儀尚且無法成立，更何況是超越世間的清淨虛懷佛法，怎能容許成就？因此本律宗派的主旨，一定要出家相貌具足，應當剃除鬚髮、身披袈裟，與出家人完全相同；如果穿著世俗服裝、外道服裝、佩戴世俗莊嚴飾物，或是赤身裸體等，都不算作正式出家受具足戒。如果受戒者不親自稱報姓名，不稱報和尚名號，口說乞戒而心不真正求乞，或者在昏睡、沉醉、發狂、瞋恨暴怒中根本無心受戒，或者是心不在境上、境不契合其心、或者心與境完全不相應，這些都稱為非法，不能算作得受戒體。唯有前後心境相合無違，才能成就受戒大事。現在將兩派的主張都列述出來，取捨任由修行者自己衡量。然而諸部經律都命令必須剃髮同於僧相，出家有別於俗人，若隨便依據論典的開緣，深恐不是正途；而且論典並非宗派的最高依據，應當依循律藏的根本威儀為準。

【582-0012】04_比丘尼鈔/02a_卷上之下#37
【原文】六問有人尼中作本法竟將三兩尼送受戒人往僧寺得否答依此律不得故律云比丘尼僧應將受戒者至大僧中既言是僧云何許別又受戒已由勸言二部僧具足滿僧祇亦云尼受大戒合二十眾又五分彼和尚闍棃須集十尼僧往比丘僧中乞戒故知僧尼各須十人。
【譯文】第六個問題：有人在尼僧中作完本法後，只帶著兩三個尼僧送受戒人前往比丘僧寺，這樣可以嗎？回答：依照本律是不行的。律中說：比丘尼僧應當帶領受戒者前往大僧之中，既然明確說是「尼僧（僧團全體）」，怎能容許個別數人前往？而且受大戒後，大僧會說「在二部僧中具足圓滿」。《僧祇律》也說：尼受大戒，合起來須有二十位大眾僧。《五分律》也說：那和尚尼、阿闍梨尼必須集合十位尼僧，前往比丘僧中乞戒。由此可知，比丘僧與比丘尼僧各需要十人。

【582-0013】04_比丘尼鈔/02a_卷上之下#38
【原文】七問尼僧至僧寺受戒須結界否答此之羯磨二眾所秉非界無以攝人非界無以羯磨各集本部重結穩審又如尼懺僧殘二眾各須結界亦有諸師不立者良恐誤也若欲作法尼僧盡集自然界內令本法尼在自然界外正結作時不得對僧作法須離聞處遙見無妨故律下文不應對尼作羯磨。
【譯文】第七個問題：比丘尼僧前往比丘僧寺受戒，需要結界嗎？回答：這項羯磨是僧尼二部大眾所共同執行的，沒有結界就無法統攝僧眾，沒有結界就無法進行羯磨。因此各自召集本部大眾重新審慎結界，才算穩妥；正如尼僧懺除僧殘罪，二部僧各需要結界一樣。雖然也有法師主張不需結界，恐怕是錯誤的。如果要在比丘寺作法，尼僧應當全部集合在原有的自然界內，讓本法尼留在自然界外。但在正式結界作法之時，不得當著比丘僧的面直接作法，必須離開他們聽得見的距離，遠遠看得到則無妨。所以律下文明文規定：不應當面朝著比丘尼作羯磨。
