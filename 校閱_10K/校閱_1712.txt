# 校閱材料　第1712檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1712-0001】03_業疏/11a_卷二之五#6
【原文】次就機中初科，初明鈍根。「此據」等者，斷上文也。郁伽長者經穢居品云：「居家菩薩當知在家穢汙之事，常念作故，名為居家；斷諸善根本，是名居家；乃至居家如羅網、如毒蛇、如火燒身等。」涅槃云：「居家迫窄，猶如牢獄，一切煩惱由之而生；出家寬曠，猶如虗空，一切善法由之增長。若在居家，不得盡壽淨修梵行，我今應當剃除鬚髮，出家學道。」「有下」次明利根。「心希拔俗」等，謂居塵不染者，固即是定。淨名即維摩經，梵云維摩詰，此翻淨名。彼因諸長者子問云：「我聞佛言父母不聽不得出家。」維摩詰言：「汝等但發阿耨多羅三藐三菩提心，即是出家，即是具足。」爾時三十二長者子即發菩提心等。以佛令剃染受具，本為發大道心；既已發心，何須出受？故云「即是」。此言乃被上達圓機，末俗凡流無宜倚濫
【譯文】其次在就眾生根機論述的第一科中，首先說明鈍根之人。「此據」等語，是承接並劃斷上文。《郁伽長者經》〈穢居品〉說：「居家的菩薩應當知曉在家是污穢染垢之事，因常常起念造作的緣故，所以稱為居家；斷絕一切善法根本，所以稱為居家；乃至說居家好比羅網、好比毒蛇、好比烈火燒身等。」《涅槃經》說：「居家狹隘逼迫，就如同牢獄，一切煩惱都由此而生；出家寬廣無礙，就如同虛空，一切善法都由此增長。如果身在居家，就無法畢生清淨修持梵行，我如今應當剃除鬚髮，出家學道。」「有下」接著說明利根之人。「心希拔俗」等句，是指處於塵俗而不受染著之人；「固」字即是「定」（拘定/固定）的意思（意指心性不為俗塵所拘定）。《淨名經》就是《維摩詰經》，梵語稱「維摩詰」，此方翻譯為「淨名」。經中因為諸位長者子問道：「我聽聞佛陀說過，父母不同意就不得出家。」維摩詰回答說：「你們只要發起阿耨多羅三藐三菩提心，就是出家，就是具足戒法。」當時三十二位長者子立即發菩提心等。因為佛陀令人剃髮染衣、領受具足戒，原本就是為了啟發廣大菩提心；既然已經發起大菩提心，又何須拘泥於形跡的出家與受戒？所以說「即是」。這段話是為了契應上等通達圓融根機之人，末世庸俗凡流切不可依憑此語而混淆濫用。

【1712-0002】03_業疏/11a_卷二之五#7
【原文】就分四句：既出從道，志求解脫，心形俱出也；雖形附道，而心沉世，形出心沒也；如淨名說，心出形沒也；躭滯五欲，縛著居家，俱不出也
【譯文】就此分為四種情況（四句）：既然出家依循佛道，且立志求解脫，這是身與心都出家；雖然形貌依附佛道，但內心卻沉溺於世俗塵勞，這是身出家而心未出家（形出心沒）；正如《淨名經》所說的，這是心出家而身未出家（心出形沒）；沉溺耽著於五欲，被家庭繫縛牽纏，這是身與心都沒有出家（俱不出）。

【1712-0003】03_業疏/11a_卷二之五#8
【原文】次文，初後二俱句，中間二互句。初句「從道」是形出，「求脫」即心出。若以兩根對四句者，初句兼收利鈍，鈍者因形而發心，利者起心而從事；第三句唯利；二、四兩句則非所論
【譯文】第二段文字中，第一句與第四句是身心一致之句（二俱句），中間第二與第三句是身心互違之句（二互句）。第一句「從道」是指形體出家，「求脫」是指內心出家。如果將利根與鈍根兩類人對應這四句：第一句兼收了利根與鈍根，鈍根者藉由外在形體出家而啟發道心，利根者則是先發起道心進而在事相上奉行；第三句（心出形沒）純粹是利根之人；至於第二句（形出心沒）與第四句（俱不出），則不在合宜之列，無足深論。

【1712-0004】03_業疏/11a_卷二之五#9
【原文】然世濁惑深，厭苦求樂，初雖欣出，終墜欲海，不修行業，故徒行也
【譯文】然而世道混濁、眾生惑障深重，往往只是為了厭惡痛苦、希求安樂，最初雖然欣求出家，最終卻墮落於欲海之中，不修持戒行道業，所以只是徒然出家罷了。

【1712-0005】03_業疏/11a_卷二之五#10
【原文】三、引誡中初科，初示時機。謂厭在家營趁之苦，求出家供給之樂，即涅槃云「為衣食而出家」者。「初下」次明退墮。詩云「靡不有初，鮮克有終」，即斯類矣。徒行，謂出家無益也
【譯文】第三、引用戒勉中的第一科，首先指示當下的時勢根機。是指厭惡在居家業謀生求利的勞苦，希求出家後受人供養的安樂，這就是《涅槃經》所說的「為了衣食而出家的人」。「初下」接著說明退失墮落。《詩經》說「靡不有初，鮮克有終」（萬事無不有個開頭，但很少能善始善終），指的就是這類人。「徒行」，就是指如此出家毫無益處。

【1712-0006】03_業疏/11a_卷二之五#11
【原文】如智論云：「六情根完具，智鑒亦明利，而不求道法，唐受身智慧。禽獸皆亦知，欲樂以自恣，而不知方便，為道修善事。既已得人身，宜勉自利益，不知修道行，與彼亦何異？」龍樹引誡為極言也。聞而不行，猶是不聞；今重引告，何得不用
【譯文】正如《大智度論》說：「六種根識皆完好具備，智慧鑑照也明晰敏銳，卻不求取正道佛法，白白承受了這人身與智慧。禽獸也都知道追求欲樂來放縱自己，卻不懂得藉由善巧方便，為了修道而造作善事。既然已經獲得寶貴人身，應當勉勵自己追求真實利益，如果不知道修持道行，與那些禽獸又有何差異？」龍樹菩薩引用此戒勉可以說是言辭痛切至極。聽聞了而不去奉行，就如同沒有聽聞一樣；現在重新引述告誡，怎能不認真遵奉力行呢？

【1712-0007】03_業疏/11a_卷二之五#12
【原文】次科論文三偈：初偈上二句明報勝，下二句嗟不學。六情根者，情即是識，謂根識無缺也；智能鑒物，故云智鑒；唐，虗也；身對初句，智慧對次句。次一偈舉況，畜是癡報，但知欲樂，即經所謂「但念水草，餘無所知」也。後一偈中，上半合初偈，下半合次偈。「龍下」結告勸依。必應此偈出在他經，故云引誡；以畜況人，為誡深切，故云極言
【譯文】第二科論典文字有三首偈頌：第一偈上半兩句說明果報殊勝，下半兩句嗟嘆其不修學佛法。六情根，「情」就是識，是指六根與六識毫無殘缺；智慧能鑑別事物，所以稱為「智鑒」；「唐」，就是虛妄、白白的意思；「身」對應第一句，「智慧」對應第二句。第二首偈頌列舉比況，畜生是愚癡果報，只知道享受欲樂，也就是經中所說的「只知念著水草，其餘一無所知」。最後一偈之中，前半首合於第一偈，後半首合於第二偈。「龍下」總結告誡勸勉依循教奉行。想必這首偈頌出自其他經論，所以說是引用誡勉；用畜生來比況人類，是極為深切痛切的戒誨，所以說是極言。

【1712-0008】03_業疏/11a_卷二之五#13
【原文】道行何耶？一切無染者是也。良由眾生無始封著是此是彼、是得是失，因之起染，纏縛有獄。故世鈍者多著財色，少有利者多貪名見，四科束之，尠不收盡。終歸死去，何事迷乎
【譯文】什麼是修道的戒行呢？對於一切事物不起染著就是了。這實在是因為眾生從無始以來，執著於這是此、那是彼，這是得、那是失，因此生起染污貪著，被繫縛於三有生死牢獄之中。因此世間愚鈍之人大多執著於財富與美色，少數稍有利根聰明之人則大多貪愛名聲與知見見解，以財、色、名、見這四項加以歸納概括，幾乎無不網羅收盡。然而人生終究歸於死亡，為何還要如此執迷不悟呢？
