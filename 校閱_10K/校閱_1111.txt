# 校閱材料　第1111檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1111-0001】資持記/07c_中一下#57
【原文】若佛下，三示不開之意。文敘佛物，法物準同。次科，初句準經。佛下，明不合。若下，示暫開。下引戒文，顯知佛在僧房，可證暫安無妨。三中。前云招提，恐昧其相，故特問之。答中，初引經兩節；前引阿難轉施，名相甚顯。疏云：《中含》：施招提僧房，所謂別房施是也。
【譯文】從「若佛下」開始，第三是顯示不開許互用的用意。文中雖然只敘述佛物，法物也比照相同原則處理。下一科，首句依據經典。從「佛下」開始，說明並不合乎戒律。從「若下」開始，指示暫時開許的情形。下文引述戒相文字，顯明得知佛像安放在僧房之中，可以證明暫時安放是無妨礙的。第三小節中。前面提到了招提物，唯恐有人昏昧不明其相貌，所以特別提出疑問。在回答中，首先引用兩節經典；前半引述阿難尊者轉手布施，名義與相貌十分顯明。戒疏說：《中含》：布施給招提僧房，指的就是將個別獨立的房舍作布施。

【1111-0002】資持記/07c_中一下#58
【原文】謂施主置房，施十方僧，別自供給；不涉眾僧常住，故有和送；而非私房，故名招提常住也。次引菴婆女施。即頻婆娑羅王女，以金瓶行水白佛：毘舍離城，所有園苑最勝，並以奉佛；應是最初園施，故云為首。文下，決判。言不了者，但云園施，相不顯故。
【譯文】這是說施主建造了房舍，布施給十方的僧眾，由施主另外自行供給維護；不牽涉大眾僧人原本的常住物，所以有和合送交之法；然而這又不是屬於僧人私人的房舍，所以稱為招提常住物。其次引用庵婆羅女布施的典故。也就是頻婆娑羅王的女兒，手持金瓶倒水澆手稟告佛陀說：毗舍離城之中，所有最殊勝的園林庭苑，全部奉獻給佛陀；這應當是最初布施園林的開端，所以說以其為首。經文之下，予以判定決斷。所謂「未了」，是指經文中僅僅籠統說是布施園林，具體相貌並不明顯。

【1111-0003】資持記/07c_中一下#59
【原文】準此等者，以園中必有房宇華果等物，故作兩判。僧鬘者，今鈔且取華果結鬘之義；疏云：經中僧鬘物者〔名出《涅槃》〕，此梵本音；據唐言之，對面物也，即是現前對面之施耳；鈔引昔解，謂華果者，隨字顯相，乖事義也。〔疏文〕準此，經中園施言招提者，但是別指房宇耳。四中。
【譯文】依照此類推論，是因為園林之中必定建有房屋房舍、種植花草果樹等物，所以作出兩種判定。所謂「僧鬘」，如今本鈔姑且採取採集花果編結成花鬘的意義；戒疏說：經典中所說的「僧鬘物」〔此名詞出自《大般涅槃經》〕，這是梵語的發音；按照漢語的意思來說，是對面之物，也就是指當面現前對坐受施之物罷了；本鈔引用古時的解釋，將其當成花果，只是隨順文字表面望文生義，違背了事實的真實本義。〔以上為戒疏原文〕依照這個道理，經文中將布施園林稱為招提，只不過是另外專門指涉園中的房屋建築罷了。第四小節中。

【1111-0004】資持記/07c_中一下#60
【原文】此似復示暫安之義，但文不相接。彼論，具問非佛屋，佛像在中，可在前食臥不？答：得食。若佛在世，猶於前食，況像不得；但臥須障，今止引臥文。彼不明罪相，今云不犯者，與佛同處本得小罪故。人畜中。但明僧佛二寶，法亦同之。田園中，初科；《多論》，文有四段；
【譯文】這似乎是再次顯示暫時安放佛像的用意，只是文字前後並沒有緊密銜接。彼論典中，詳細詢問不是專門供佛的屋舍，若是佛像安放在裡面，可以在佛像面前飲食或睡眠嗎？回答說：可以進食。如果佛陀在世時，尚且可以在佛陀面前進食，更何況是佛像，自然沒有不可之理；只是睡眠時必須加以遮障，如今此處僅僅引述了關於睡眠的文字。彼論典並未明述具體的罪名相狀，如今此處說「不犯」，是因為與佛陀同處一室本來只會獲致輕微小罪的緣故。在人道與畜生之中。此處僅僅說明僧、佛二寶，法寶也是同理。在田地園林之中，第一科；《薩婆多論》的文字共有四個段落；

【1111-0005】資持記/07c_中一下#61
【原文】初明僧地不和，不得佛用，和則通得。若僧下，二明僧園花果，得供佛用。言分行得者，別人已分故。言無限者，有餘剩故。若經下，三明園田混雜，開不成互。若屬下，四明用水得否。屬塔水者，或在塔地，或但屬塔用。塔功力者，即治塔人經營而得；彼言：若致功力是塔人者，應賣此水；
【譯文】首先說明僧眾的土地如果未經和合表白，不得挪給佛陀使用，若是作法和合了則通通可以。從「若僧下」開始，第二是說明僧眾園林之中的花果，可以用來供養佛陀。所謂分給各行可以得到，是指已經分配給個別僧人的緣故。所謂沒有限制，是指有多餘剩餘的緣故。從「若經下」開始，第三是說明園林與田地混雜不清時，開許不構成非法互用。從「若屬下」開始，第四是說明用水是否合乎戒律。屬於塔寺的水，或者是水源在塔寺的土地上，或者只是專門供塔寺使用。所謂塔寺功力，是指修治佛塔之人經營開鑿所得；彼論說：若是出力營造的是屬於塔寺的人，就應當將此水出賣；

【1111-0006】資持記/07c_中一下#62
【原文】以錢屬塔，不得餘用，用則計錢；今但略云，僧用得重。〔古云：語到，合云者得，不見彼文故也。〕若由僧下，彼云：若塔無人，致水功力，一由僧人。〔謂無營塔人，即顯功由僧得，故從僧用。〕過限重者，亦據用有制限；約水多少，計直判罪。《十誦》中，初明華通供佛。
【譯文】把賣得的錢歸屬於塔寺，不得作其他用途，若是挪用則按錢財價值論罪；如今此處只是簡略說明，僧人擅自使用便構成重罪。〔古人說：此處是文字倒錯，理應作「者得」，這是因為未曾讀過彼論原文的緣故。〕從「若由僧下」開始，彼論說：若是塔寺沒有人手，引水的勞役功力，全都出自僧人之手。〔意即沒有專門經營佛塔的人，即顯明功力是由僧眾付出得來，所以應順從僧人使用。〕所謂超過限度結重罪，也是依據使用上有其限制；依照用水的多少，折算價值來判定罪行輕重。《十誦律》中，首先說明鮮花通許用來供養佛陀。

【1111-0007】資持記/07c_中一下#63
【原文】如上或已入己，或有餘剩故。若下，明果木供僧。樹皮下，明雜物開別。皮葉等物，理得永用；釜鑊等物，但開暫用。《母論》僧樹，初開私用。不須白者，先已得法，即同白故。下明治塔，即通佛用。作法開故。《僧祇》有三，初明取薪通局。溫室，即今火閤也。取乾枯者，護壞生故。若僧下，次示取樹方便。
【譯文】正如上述所言，或者已經分配給個人所有，或者是有多餘剩餘的緣故。從「若下」開始，說明果實木材可以用來供養僧人。從「樹皮下」開始，說明雜類物品的開許與差別。樹皮、樹葉等雜物，在道理上可以永久使用；釜鑊等炊具鍋具，則僅僅開許暫時借用。《毘尼母論》談到僧眾的樹木，首先開許可以私人取用。所謂不需表白，是因為先前已經依照僧法獲得，就等同於已經表白過了。下文說明用以修治佛塔，就可以通給佛寶使用。因為透過作法予以開許的緣故。《摩訶僧祇律》分為三點，首先說明採取柴薪的通行與局限。所謂溫室，就是如今的浴室暖閣。之所以選取乾枯的樹枝，是為了防護傷害有生命的鮮木。從「若僧下」開始，其次指示砍伐樹木的權巧方便方法。


【1111-0008】資持記/07d_中一下#1
【原文】或僧須用，或在妨處，有此二緣，故開取用。魚骨灰汁，生樹所忌。然使淨人，須作知淨。若僧田下，三開轉易。《四分》中，初引示。故下，準決，初明三寶通塞。若下，次明本通隨用。《善見》。伏藏應在三寶地中，還歸三寶用，故無罪；反明自入取離成盜。若非三寶地；
【譯文】或是僧團需要使用，或是處在阻礙通行的位置，具備這兩種因緣，所以開許伐取使用。然而，魚骨灰汁是活樹所忌諱的催枯之物。如果要讓淨人去處理，必須依照作淨之法進行授意。如果「若是僧田」以下，為第三科開許轉換變賣。《四分律》中，起初引律文告示。接著「所以」以下，是依準決斷，首先說明三寶財物之間的互通與隔絕。接著「如果」以下，其次說明原本通用的物品隨情況使用。《善見論》認為：地底埋藏的寶物如果在三寶地界之中，應當歸還三寶使用，所以沒有罪過；反之，這說明若據為己有而取物離處，便構成盜罪。如果不是三寶的地界；
