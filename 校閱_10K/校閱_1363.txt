# 校閱材料　第1363檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1363-0001】資持記/16a_下四#43
【原文】森然，謂如草木之多。次句明制遍，毘尼事法，依境而制；隨於一境，復有多事；一切境事，不出善惡；對此善惡，以分二持；是則無有一事，而非持奉之處。三明違犯；忽，謂輕忽；不行，言通兩犯。四彰來報。幽責，語含二報。上二句明持，下二句顯犯。故下，次明隨行，上二句明隨事立法。
【譯文】所謂「森然羅列」，是形容如同山林中的草木一般繁多茂密。第二句闡明戒律制定的周遍，毘尼的各項事法，都是依循著這些客觀境界而制定的；隨順在任何一個境界上，又會牽涉許許多多不同的行為舉止；世間一切境界與作為，總括而言不出「善」與「惡」兩端；面對這善與惡，便分立出「作持」與「止持」兩種行門；這樣看來，便沒有任何一件事不是比丘應當謹慎奉持的下手處。第三句說明違犯戒律的情形；所謂「忽」，是指輕慢疏忽；所謂「不行」，文字涵蓋了「該止而不止」與「該作而不作」這兩類犯戒過咎。第四句揭示來世招感的業報。所謂「幽冥的譴責」，文字包含了華報（現世）與果報（地獄惡道）這兩種報應。前兩句闡明如法奉持，後兩句則彰顯毀犯戒律之失。從「故」字以下，接著說明隨順戒體的具體修行，前兩句闡明隨順具體事緣而安立戒法。

【1363-0002】資持記/16a_下四#44
【原文】一一事，謂境事也。種種誡，即律制也。下二句明由解起行。解由教生，故須詮辨，此即通敘一部正教之意。次科，初覆點前篇。諸門，總上二十六篇；以諸篇中，科義相由，事類條貫；顯非雜亂，故云日途相攝。別下，次探示後篇；別類者，沙彌及尼，對大僧為別；諸部，對本宗為別。
【譯文】所謂「一一事」，是指所面對的一切境相事物。所謂「種種嚴誡」，是指律藏中所立下的種種規範禁令。後兩句闡明由明晰的理解進而發起正確的行持。正確的理解必然由研讀教法而產生，所以必須詳加詮釋與辨明，這便是通篇統括敘述一部正律核心意旨的本意。在下一科中，首先回顧指點前面的各篇章。所謂「各門」，是總括前面的二十六篇；因為在那許多的篇章中，科判義理前後相承，事相類別條理井然貫通；藉此彰顯其並非雜亂無章，所以才說「依其門徑途序互相引領攝受」。從「個別」以下，接著預先提示後面的篇章；所謂「個別的類別」，沙彌與比丘尼，相對於大僧比丘而言屬於個別小眾；其餘各部律典，相對於四分律本宗而言屬於個別部派。

【1363-0003】資持記/16a_下四#45
【原文】統收，亦彰不雜。羅，謂包羅。以下，正明本篇。上二句明事雜。繁類，謂無條流。斷，謂義有孤絕；續，謂事或連貫。皆不成科段，故云雜務。紛綸，喻絲之紊亂也。次二句明文雜。瑣，小也。此別，即指當篇；對於上下，故云別也。三中，初顯要。必下，勸修。則下，彰益。怯懦，即畏懼也。
【譯文】統括收納這些內容，同樣是為了彰顯戒相的不雜亂。所謂「羅」，就是包羅無遺的意思。從「以」字以下，正式說明本篇的特色。前兩句說明所涉及的事相極為繁雜。所謂「繁複門類」，是指沒有單一連貫的流派脈絡。所謂「中斷」，是指有些義理看似孤立突兀；所謂「延續」，是指有些事相彼此牽引關聯。這些零散內容都無法各自獨立構成一個完整的章節科段，所以才稱為「繁雜的行務」。所謂「紛紜錯綜」，是比喻如同雜亂無章的絲線一般。隨後的兩句說明文字引述的繁雜。所謂「瑣碎」，就是細小零碎的意思。所謂「這個個別章節」，指的便是當前這一篇；相對於前篇與後篇而言，所以稱之為「別」。第三段中，首先顯明本篇的切要至關重要。從「必定」以下，懇切勸勉大眾勤加修習。從「便能」以下，彰顯修學所帶來的殊勝利益。所謂「怯懦」，就是畏懼害怕的心態。

【1363-0004】資持記/16a_下四#46
【原文】反知不學，動用乖儀；入眾遊方，能無疑懼；寄言學者，幸留意焉。標列十門。一四五，多從化教，非不兼制；餘並制教，時亦兼化。初門，禮敬中。晨午昏為晝三時，初中後為夜三時。三事，如文次列。據餘經論，須行五悔，更加迴向發願；如祖師六時禮文，具載儀式，學者宜依。次科，《多論》。
【譯文】反過來說，如果不知研讀學習，起心動念與舉止動靜必定會乖離戒律儀軌；一旦進入大眾僧團或者遊歷十方行腳參訪，如何能夠不心生疑慮與惶恐畏懼？在此寄語諸位修學戒法的人，萬幸能對此多加留心用意啊。在此標示列出十個門徑：第一、第四、第五門，多數是屬於化教的教化範疇，但並非不兼含制教的戒規；其餘各門則全屬於制教的嚴格規範，有時也兼通於化教的義理。在第一門「禮敬」中，清晨、正午、黃昏為白天的「晝三時」，初夜、中夜、後夜為夜晚的「夜三時」。《智論》所列的三事，正如文中依次羅列。根據其餘經論的教示，在禮敬時必須修持「五悔法」，更應當加上迴向與發願；這正如律宗祖師在六時禮佛懺文中所詳盡記載的儀軌形式，修學者理應當切實遵循。下一科引述《薩婆多論》：

【1363-0005】資持記/16a_下四#47
【原文】華纓，唯得散地；不得散佛僧身，及飲食上，非所宜故。《五百問》。作餘佛事者，雖聽改轉，不換本質，如盜戒引。《多論》。佛臘謂自恣日食，等取餘供養物；雖僧手捉，不成惡觸。三中，《十誦》明知事法，初教勤勞。常下，次令發願。教示餘眾，同此存心，故云亦爾。《善見》，明守寺。
【譯文】編織的花纓華鬘，只允許散灑鋪設在地面上；不得直接散灑在佛陀與僧眾的尊軀上，更不得丟在飲食之上，因為那是極不合宜失敬的舉動。《五百問》記載：如果拿供佛的物品轉作其餘佛事，雖然開許改換用途，但絕不得變更其屬於佛物的本質歸屬，正如在盜戒中所引述的一樣。《薩婆多論》提到：所謂「佛臘」，是指自恣日當天所供養佛陀的食物，以此類推亦包含其餘的各類供養物品；即便僧人親手持拿，也不會構成觸犯惡觸之罪。在第三段中，《十誦律》闡明擔任知事執事僧的法度，首先教導應當精勤辛勞為眾服務。從「常常」以下，接著命令應當發廣大善願。教導其餘的人（沙彌與僕役使人）也要抱持同樣的存心發願，所以鈔文才說「亦爾」。《善見律》則闡明留守常住寺院的法規。

【1363-0006】資持記/16a_下四#48
【原文】《智論》，教差次。請命依臘，須從上起；差役取卑，故從下起。四中，《薩遮、俱舍》，制不得壞。上品治者，同逆罪故。《智論、僧祇》，開壞惡易好。五中。供人即法者，以人解法，法依人故。六中。律令選一能者，知掌眾務；初大僧，二沙彌，三淨人，尋文可見。帥，所類反，領也。七中，初科，《僧祇》明賞給。
【譯文】《大智度論》教導差遣僧差的先後次第。如果是請命供養，應依照戒臘的高低，必須從上座大德開始延請；如果是派遣執役勞務，應先選取戒臘居下的人，所以必須從下座僧人開始差遣。第四段中，《薩遮尼乾子經》與《俱舍論》嚴厲規定，寺院佛法設施絕對不得毀壞。律中判定以最高品階的罪相論處，是因為毀壞僧物等同於犯下五逆重罪的緣故。而《大智度論》與《僧祇律》中，則特別開許若是為了除壞破爛醜惡的設施以換取良好莊嚴的新物，則不在禁止之列。第五段中：供養有德之人便等同於供養正法，這是因為人能通達理解正法，正法也完全依賴人來弘揚住持的緣故。第六段中：戒律命令大眾應當推選出一名具備才幹能力的人，負責總領執掌僧團的大眾事務；第一在大僧中立維那，第二在沙彌中立沙彌首領，第三在淨人中立主帥，細尋下文便可明白。經文中的「帥」字，音讀為率領的「率」，意思便是總領率領。第七段的第一科中，《僧祇律》闡明對於辛勞執事者的賞賜給予。
