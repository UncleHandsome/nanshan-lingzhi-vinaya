# 剩餘 >500 字長段材料

## 合計

```text
26 筆
```

## 分書

```text
行事鈔：14
戒疏：1
業疏：0
尼鈔：1
義鈔：10
```

## 檔案

```text
行事鈔_GAP17、GAP18、GAP20、GAP21、GAP22、GAP23
行事鈔_GAP39、GAP40、GAP41、GAP42、GAP51、GAP53、GAP55、GAP56

義鈔_GAP04、GAP08、GAP09、GAP18、GAP19、GAP20
義鈔_GAP21、GAP22、GAP23、GAP25
```

## 輸出

```text
<書>_<key>_回.md
```

例如：

```text
行事鈔_GAP51_回.md
義鈔_GAP22_回.md
```

## 格式

```text
## GAP51-1
原文起：……
原文迄：……
白話起：……
白話迄：……
```

- 白話起迄必須從【現譯】擷取
- 不可寫「（現譯從缺）」
- 不改字、不增刪

## 注意

行事鈔、義鈔都有 GAP21／GAP22／GAP23／GAP24，檔名已加書名，不可混用。
