整體看，理解方向大體正確，科判、引文歸屬也掌握得不錯；但有幾處**硬傷（錯字、引文失真、詞義誤解）**，以及較普遍的「增譯過度」問題。以下逐則列出。

---

## 一、必改的錯誤

### 1. 錯字重複（0003）
> 「戒師**應當應當**事先傳授給戒子」

衍字，刪一個。

### 2. 引文不可改字（0001）
原文：故云**長益沙門果**也
譯文：所以說是「**增益沙門道果**」

引號內是《律》文原句，不能改寫。應作：所以說「長益沙門果」（增長沙門果）。

### 3. 引文擅加字，且與前文自相矛盾（0005）
原文：世多念云**食僧常食**
譯文：世人大多念誦說「**我今**食僧常食」

前一則（0004）元照才剛說「我今字誤，合作我常」，這裡卻替念辭補上「我今」，等於自己打自己。應照原樣引「食僧常食」，或作「（我常）食僧常食」並加校記。

### 4. 「故略不出」誤解（0001）
「略」是**略去、省略不載**，不是「稍微」。
譯文「所以這裡稍微省略不再全部列出」語意變成「還列了一部分」，與原意相反。
建議：「所以省略而不列出。」

### 5. 「法附中」科名譯錯（0002 末）
下一則開頭即說「既受具戒，即須六念……**因附此篇**」，可知「法附」是指**六念法附於此篇**，不是泛指「附錄律法」。
建議：「在『（六念）法附此篇』的段落中：」

### 6. 「念法」不是「法門」（0003）
原文：初念中，前示**念法**
「念法」＝稱念的方法／念辭文句（念黑白月日之法），譯成「念誦的**法門**」過度拔高。
建議：「先標示稱念的方法（文句）。」

### 7. 譯文循環重複（0004）
原文：通相謂不言黑白
譯文：「所謂『通相』，是指不直說黑月白月，**只說『不言黑白』**」

後半句只是把原文四字再抄一遍，等於沒譯。
建議：「所謂『通相』，是指依一般通行的說法，只說某月某日，不說黑月白月。」

### 8. 臆補引文（0004）
原文：**準下**，教隨方對俗
譯文：「自下文『**準此方土**』以下……」

「準下」是元照慣用的牒文方式（「準」字以下之文），《鈔》文原句是否為「準此方土」並無把握，不宜替古人造引文。
建議：「《鈔》文『準』字以下，是教人隨順此方土俗來應對世人。」

同則「準《羯磨》云：謂不常定者〔有作若無請者〕」（0005）也被整句白話化、引號消失，應保留原文＋夾注：
> 依《羯磨》文作「謂不常定者」（指食處不固定者）〔有本作「若無請者」〕。

### 9. 用詞不當（0001）
「文相具委」譯成「律文**相貌**詳盡周全」——「相貌」一般指形貌，讀來很怪。
建議：「律文的文句內容詳盡委細」。

## 二、可再斟酌之處

| 出處 | 譯文 | 問題／建議 |
|---|---|---|
| 0001 | 「道行雖然**萬殊**」「**精進**修學」「證得**無漏**聖果才算圓滿止境」 | 原文只作「雖多」「當學」「至聖乃已」。「萬殊、精進、無漏」都是加料；「才算圓滿止境」中文也不順。建議：「直到證入聖位才停止」。 |
| 0001 | 「**但云**說相」→「只要提到宣說戒相」 | 「但」＝只。原意是「《鈔》中**只說**『說相』，其實必兼四依」，非條件句「只要……必定……」。 |
| 0001 | 「世俗的**經史**典籍、醫卜**星相**」 | 「經史」「星相」原文所無；且「經」易與佛經混。可作「世間典籍、醫方卜筮、技藝等」。 |
| 0001 | 「宜須隱括，取悟於心」→「撮略總攝、**領悟要義**，求得自心真正的省悟」 | 「領悟要義」與「取悟於心」重複。建議：「應當加以撮要總攝，使心中領悟」。 |
| 0002 | 「不欲**兩繁**」→「不想讓**全書**產生兩處重複繁瑣的弊病」 | 「兩繁」指《鈔》與《羯磨》**兩處**重載，非「全書」；可作「不想兩處都繁複重出」。 |
| 0002 | 「此猶同古」 | 直譯無誤，但宜加譯注：此元照指出《鈔》此處仍沿古師舊說（受戒後才受衣），故下文引《戒壇經》《業疏》加以糾正。否則讀者會誤以為「同古」是肯定語。 |
| 0002 | 「方**事**持衣」→「才去**忙著**受持三衣」 | 「忙著」是情緒性添字，可刪。 |
| 0003 | 「觀行**尤**難」→「難度是相當高的」 | 丟了比較義。應作「觀行**尤其**困難」（與下文六念之「易成」對照）。 |
| 0003 | 「通成今用」→「融通成為我們現在修持的準則」 | 略鬆。可作「通用為現今（受戒後）的念法」。 |
| 0004 | 「非俗法故」→「不是**世俗凡夫**的曆法」 | 「凡夫」是加詞且概念偏離（俗人≠凡夫）。作「不是世俗人的曆法」。 |
| 0004 | 「三並言常」→「三處都說『常』」 | 直譯可通，但宜補注說明「三」所指（不受請的三種念辭），否則讀者無從索解。 |
| 0005 | 「全乖律檢」→「戒律的**檢視繩墨**」 | 「檢」是檢束、規範，非「檢視」。建議「完全違背律制的檢束」。 |
| 0005 | 「妄情憶度」 | 「憶」通「臆」，可逕作「妄情臆測」，比「妄動情識的盲目揣測」乾淨。 |
| 全篇 | 「請」一律譯「請齋」 | 語境雖以食請為主，但「受請」本不限齋供；建議統一作「受請（赴施主之請）」，避免窄化。 |

## 三、總評

1. **忠實度**：義理判讀大致到位（六念緣身、剋念、我常／我今之辨、受衣位次之諍都對）。主要毛病是**形容詞與修辭性增譯偏多**（萬殊、無漏、精進、盲目、忙著、真正的省悟……），律學疏記以簡嚴為體，白話宜「不多一字」。
2. **引文紀律**：凡引號內的原文（長益沙門果、食僧常食、謂不常定者、有作若無請者），一律照錄，需解釋就放在括號或譯注，**不可改字、不可代擬**。這是本批最需要修正的一類。
3. **科判術語**：「法附中」「念法」「牒章」等科文用語要按元照的用法譯，不宜用一般佛教詞彙（法門、附錄律法）頂替。
4. 校勘夾注（〔有作若無請者〕）建議保留原樣並標明是異文，不要混入正文語意。
