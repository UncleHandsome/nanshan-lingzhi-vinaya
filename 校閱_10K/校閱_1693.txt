# 校閱材料　第1693檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1693-0001】03_業疏/10a_卷二之四#8
【原文】初問中，以前四位獨遺式叉，故須問決。重加六法，出過小眾，故云「異持」。答中，初指前通答。「式下」顯同小眾，既云增學，明不發體。《鈔》云「六法是其學宗，戒體更不重發」，還約轉根證同小眾
【譯文】在最初的問難中，因為前面四個位階獨獨遺漏了式叉摩那，所以必須發問予以決斷。式叉摩那額外加上六法，超越了尋常沙彌小眾，所以說是「異持」（特殊的行持）。在回答中，起初指涉前文做普遍回答。自「式」以下顯示其戒體等同於小眾，既然稱為「增長修學」，就表明並未重新發起新的戒體。《事鈔》說「六法是她學習的主旨，戒體並不再重新發起」，也是通過性徵轉變來證明她等同於小眾。

【1693-0002】03_業疏/10a_卷二之四#9
【原文】問：體同沙彌，自有常學，何須增法有違缺戒？答：由於女報性涉虗羸，即授具足，恐有輕犯，故增戒法，加輔靈神，必事陵踐，隨法更學
【譯文】問：如果戒體等同於沙彌，本來就有一貫的學處，何必額外增加六法，使得一旦有所違犯就殘缺了戒法呢？答：由於女性果報體性較為軟弱脆弱，如果直接授予具足戒，恐怕會輕忽犯戒，所以額外增加戒法，用來輔助護衛其心神；如果真的有所踐踏違犯，就要依照法規重新修學兩年。

【1693-0003】03_業疏/10a_卷二之四#10
【原文】次問中，「常學」即十戒也。六法制行二年，中間有犯，還復從初，故云「有違缺戒」。答中，初敘報劣，故下次明制法輔助也。靈神即心識。下云六法練心，恐輕犯故；二年練身，恐有胎故
【譯文】在第二個問難中，「常學」就是指十戒。六法規定必須奉行兩年，其間若有違犯，就要重新從頭算起，所以說是「有違缺戒」。在回答中，起初敘述果報羸劣，自「故」以下說明制定戒法是為了輔助。靈神就是指心識。下文說六法是為了鍛鍊心志，因為恐懼輕易犯戒的緣故；兩年是為了檢驗身體，因為恐懼懷有身孕的緣故。

【1693-0004】03_業疏/10a_卷二之四#11
【原文】所言戒者，謂禁約止善為宗。雖有作用，終須謹攝，有越常規，無非制約，故云止也。有人言防非禁惡為戒者，非無一相，然佛有戒，未必防非，戒通善惡，不可偏解，餘如別顯
【譯文】所謂「戒」，是指以禁約規範、止惡行善（止善）為其主旨。雖然也有起心動念的作為作用（作持），但終究必須謹慎攝受持守；只要有所超越常規威儀，無不需要加以制約管束，所以稱為「止」。有人說「防範過非、禁絕罪惡」就是戒，這並非全無道理，然而佛陀制定的戒法，未必就能防非；而且「戒」的概念通於善與惡（如惡律儀），不能作片面的理解，其餘的道理如其他專文中所闡明。

【1693-0005】03_業疏/10a_卷二之四#12
【原文】次釋戒中，初示今義。禁約言通，止善名局，以局簡通，即知善戒由止成善，故云「止善」。「雖有」等者，會通作持，依法離過，還歸止攝，則知止善通收二持。「有下」斥古解。初引古，「非無一相」，但得止義故。「然下」正斥。上二句斥「防非」，戒必防非，人何有犯？故知須假行人隨中嚴奉，始可離非，故云「未必」也。次二句斥「禁惡」，屠獵所持亦名為戒，今云禁惡，但局善戒，故云「偏解」。下句指廣，即《事鈔》中卷、《戒疏》初卷也
【譯文】其次在解釋「戒」字中，起初展示今家的正義。「禁約」一詞涵義廣泛，「止善」名稱則較為明確局限，用局限來甄別廣泛，便可知善戒是通過止惡而成辦善業，所以稱為「止善」。「雖有」等句，是會通作持，依法去行持而遠離過失，最終仍歸結於止惡防非的攝持，由此可知「止善」通收了止持與作持兩種行持。自「有」以下駁斥古人的解釋。起初引用古說，「非無一相」是指古說僅僅得到了「止」的一層涵義。自「然」以下進行正式駁斥。上面兩句駁斥「防非」：如果戒法必然能夠防非，為何受戒之人還會犯戒呢？由此可知必須依託修行者在隨行中嚴格奉持，才可能遠離過非，所以說「未必」。接下兩句駁斥「禁惡」：屠夫、獵戶所受持的惡誓也稱為「惡戒」，現在若說戒就是禁惡，就僅局限於善戒了，所以說是「片面理解」。最後一句指示詳細發揮處，就是指《事鈔》中卷以及《戒疏》第一卷。

【1693-0006】03_業疏/10a_卷二之四#13
【原文】所言法者，法謂楷模，凡所準酌，咸有緣相故也
【譯文】所謂「法」，法是指楷模軌範，凡是所要依循裁量的標準，全都具備成辦因緣與法度軌相。

【1693-0007】03_業疏/10a_卷二之四#14
【原文】三中，初示義。「凡下」指文。下諸事法，散在教文，今師詳括，布列成儀。緣謂成緣，相即法相
【譯文】在第三科中，起初開示法義。自「凡」以下指涉下文。下面種種作法事相，散見於各處經教律文中，現在祖師詳細統括，排布排列成一套儀軌。「緣」是指成辦作法的因緣條件，「相」就是指具體的法度軌相。

【1693-0008】03_業疏/10a_卷二之四#15
【原文】所言篇者，謂章句分齊之名。自古無紙，用竹編簡，韋連束之，隨章為束，即號為篇，故字體猶存竹也。後漢蔡倫方擣樹皮為紙初也
【譯文】所謂「篇」，是指篇章文句劃分段落範圍的名稱。古代沒有紙張，用竹子編連成簡冊，以熟牛皮繩穿連捆紮起來，隨章節捆成一束，便稱為「篇」，所以這個漢字的字形依然保留著竹字頭。直到後漢蔡倫才開始搗爛樹皮造出紙張。

【1693-0009】03_業疏/10a_卷二之四#16
【原文】四中，初釋名。「自下」指事。簡即竹片，韋即皮繩。擣皮為紙，起自後漢，故云「初」也
【譯文】在第四科中，起初解釋名稱。自「自」以下指陳歷史事實。「簡」就是竹片，「韋」就是皮繩。搗樹皮造紙始於後漢，所以說是「始初」。

【1693-0010】03_業疏/10a_卷二之四#17
【原文】所言第者，謂是居處王侯之宅，從此得名，篇次在此，故云第也
【譯文】所謂「第」，是指王公貴族的府第居所，由此引申得名，篇章次第居處在這裡，所以稱為「第」。

【1693-0011】03_業疏/10a_卷二之四#18
【原文】五中，俗中第宅、第鋪，皆取居處次第之義
【譯文】在第五科中，世俗所說的府第住宅、行第店鋪，都是取居處與次第安頓的意義。

【1693-0012】03_業疏/10a_卷二之四#19
【原文】所言三者，從文其實次二，約義乃是三前
【譯文】所謂「三」，從文字編排來看其實是次於第二篇（故排在第三），但從內涵義理而言乃是在第三篇之前（若從正宗分算起則居第二）。

【1693-0013】03_業疏/10a_卷二之四#20
【原文】六中，「從文次二」謂從初集法來，即當第三；「約義三前」謂從正宗來，即當第二
【譯文】在第六科中，「從文字來看次於第二」是指從最開始結集編排的篇目算起，這正是第三篇；「就義理乃是在第三之前」是指若從正宗分算起，這就應當算作第二篇。

【1693-0014】03_業疏/10a_卷二之四#21
【原文】不覺順世間言，故得勒茲消判，餘前後文可從此例也
【譯文】不知不覺順應了世俗語言的用法，因此得以如此歸納分析判別，其餘前後的經律文章都可以依循這個體例。

【1693-0015】03_業疏/10a_卷二之四#22
【原文】示意中，初點前言。「不覺」者，明非意也。「順世間言」者，隨俗諦也。「勒」，約也。「餘下」指例，前後九篇宜同此釋
【譯文】在展示意圖中，起初點明前面的話。「不知不覺」，說明不是刻意如此。「順應世間語言」，是指隨順世俗諦。「勒」就是統約歸納。自「餘」以下指出通例，前後九篇都應當照此進行解釋。

【1693-0016】03_業疏/10a_卷二之四#23
【原文】所言戒法理通（下釋成俗受也。古來集法，多削在家，便製疏云：「律制內眾，不被外部。」今據律文，通收清信，禁束三業，為道階梯，理須明練是非通塞成敗。何以知耶？如來設教，類同空界，隨立一相，攝修皆盡。五戒被俗之法，五體通道之規，持犯相扶，難遮齊則。由斯弘義，事必書紳，恐涉生常，故前標釋，可通鑒也
【譯文】羯磨文中所謂「戒法理通」以下，是解釋成辦在家人受戒。自古以來編輯羯磨法式的人，大多刪削了在家人的部分，隨即撰寫義疏說：「律法只是制約出家內眾，不覆蓋在外的俗家。」現在依據律文本意，它普遍收攝清信士女，禁束身口意三業，作為趣向菩提聖道的階梯，在法理上必須通達明瞭是非、通塞、成辦與失敗的界限。如何知道這一點呢？如來施設教法，就像虛空一般，隨便安立一相，就能將修行圓滿收攝無遺。五戒是覆蓋在家的戒法，五戒的戒體則是通往聖道的規範；持戒與犯戒的條例相互符合，遮難審問的規矩也完全齊整劃一。由於這種深廣的宏深大義，理當牢記在心（書於衣帶之上），唯恐大家習以為常而生輕忽，所以在前面特別標出並加以解釋，以備全面明察參照。
