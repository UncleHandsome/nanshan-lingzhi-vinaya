# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【495-0006】03_業疏/09b_卷二之三#51
【原文】古師云：七日加法開內宿、煑，此無文也。《僧祇》七日寄僧淨地，則有宿、煑明矣

【495-0007】03_業疏/09b_卷二之三#52
【原文】宿煑中，初引古判，欲彰自任，故責無文。下引《僧祇》，既安淨地，驗知古非。文明七日、非時無宿，內煑同閇
【譯文】「宿煮」之中，首先引用古人的判定，為了彰顯其純屬隨自意臆斷，所以斥責其沒有明文。下文引《僧祇律》，既然安置在淨地，由此驗知古人之說錯誤。律文明言七日藥與非時藥均無內宿，內煮也同樣閉止不許。

【495-0008】03_業疏/09b_卷二之三#53
【原文】自煑一罪，義亦不開。若變生者，則失受不淨，何得後加？若不變生，重煑非犯，猶如淨地無內煑也
【譯文】自煮這一種罪，按義理也是不開許的。如果是轉生為熟，就失去了原先的授受而成為不淨，怎能事後再加法作持？如果不是轉生為熟，重新烹煮並不算違犯，就像淨地之中沒有內煮之過一樣。

【495-0009】03_業疏/09b_卷二之三#54

【譯文】「自煮」之中首先從義理上判定；「若」以下，解釋原因。自煮這種罪，只局限於把生的煮成熟的；若失去授受而成觸摸不淨，義理上不可能再次加法作持。熟的食物重新煮並不犯戒，引用同類事例即可知曉。

【譯文】《四分律》文中，只解釋盡形壽藥開許四罪，七日藥並未列入，顯明其不開許；如果尚未加法作持，一概不允許。所以《僧祇律》說自己烹煮生薑湯便不得飲用，是指生薑有轉生為熟的變化；如果是乾薑，則如律中開許那樣可以飲用。

【495-0018】03_業疏/09b_卷二之三#63
【原文】如《十誦》云：共三種人同食宿，不應食，食得吉羅。初、共比丘，謂與同宿也。二、比丘僧者，謂一具戒者同宿，則通一切皆被染也。如《四分》殘食戒云「今日受已至明日，一切沙門釋子受大戒者皆不清淨」，此通僧也；或釋疑故，如衣不淨犯起別人，謂食同此也，衣有別屬，食味是通，故一切染則通餘也。三、共與學沙彌者，由行違體順、相同故染也。尼中有四，加式叉尼，同宿同罪也
【譯文】如《十誦律》說：與三種人同處留宿飲食，便不應當食用，若吃了便得突吉羅罪。第一、與比丘同宿，指與個別比丘同處過夜。第二、比丘僧，指只要與一位具足戒者同宿，則普遍染污所有僧眾。如同《四分律》宿食戒所說：「今日領受之後放到明日，所有受了大戒的沙門釋子都算不清淨」，這就是通及全體僧眾；或者為了釋疑，比如衣服不清淨只在特定人身上結罪，若以為食物也是這樣，其實衣服各有專屬之人，而飲食美味是大家共通享用的，所以一人受染就會普遍染污其餘大眾。第三、與「與學沙彌」（受處罰而學悔的沙彌）同宿，由於他行為雖有違犯但戒體依然隨順、形相相同的緣故，所以也會受到染污。比丘尼中則有四種人，增加式叉摩那，同處留宿也是同樣結罪。

【495-0027】03_業疏/09b_卷二之三#72
【原文】先以內宿約處明者：不通他物及不周地，由徧坊界俱是開故；餘二淨地，若僧坊無人，亦無宿也；有人不開於淨地，二淨有人不免內宿。就時，要經明相。就人，在三據知故犯，律云遠來持食、狗啣在界內、風吹果墮，皆無人知，是食淨也。就食，二種：長足則犯，未足則無，以生相相連，運運動故，自散種子後生非罪，不可言宿
【譯文】首先將「內宿」依處所來說明：不適用於「他物淨地」及「不周地淨地」，因為全僧坊結界範圍內都被開許的緣故；其餘兩種淨地（處分淨地與白二淨地），如果僧坊內沒有人，也沒有內宿之罪；若淨地內有人居住，則在淨地中亦不開許免罪，此二種淨地若有人留宿同樣不免犯內宿罪。就時間而言，必須經歷黎明破曉（出明相）。就人員而言，在於上述三種人，且依據「知情故犯」才結罪，律中說從遠處攜帶食物前來、狗叼食物進入界內、風吹果實掉落，若都無人知曉，這食物就算清淨。就食物而言，分為兩種：長足成熟了便犯戒，尚未長足便不犯，因為它與生長之相相連、處於持續生長變動之故；自然散落種子而後生長的植物不構成犯罪，不能說成是留宿。
