# 校閱材料　第231檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【231-0001】01_行事鈔/10c_卷下之二#7
【原文】《四分》：老病不堪步涉，聽作步挽車，若輦、若乘；除牸牛、䮬馬。若得輦，聽畜；須輦轅及皮繩、若枕橙，並得。應使寺民、優婆塞、沙彌擔牽。若得車亦爾。應除織皮繩、髮繩。
【譯文】《四分律》說：年老患病不能徒步涉行者，聽許製作徒步拉輓的車子，如手推車（輦）或乘具；但禁止用母牛（牸牛）或母馬（䮬馬）。若獲得輦車，聽許蓄用；需要輦轅、皮繩，或靠枕、坐凳，都可以蓄持。應當讓寺院役民、優婆塞（在家男居士）、沙彌來擔抬或牽拉。若得到大車也是如此。但應當除去以皮革編織的繩子與人髮編織的繩子。

【231-0002】01_行事鈔/10c_卷下之二#8
【原文】《十誦》：比丘無鍼，不得外行。
【譯文】《十誦律》說：比丘身邊若無縫針，不得出外遠行。

【231-0003】01_行事鈔/10c_卷下之二#9
【原文】《五分》：非行來處，若大小便及洗手脚時，聽著屐。《四分》亦爾。《僧祇》：畜塼瓦擬揩脚。
【譯文】《五分律》說：在非尋常走動的特定場所，如大小便溺以及洗手洗腳時，聽許穿著木屐。《四分律》也是如此規定。《僧祇律》說：聽許蓄留磚瓦，用以擦拭腳底。

【231-0004】01_行事鈔/10c_卷下之二#10
【原文】《十誦》：犛牛尾拂，用拂佛塔故受。《僧祇》：自今已去，聽捉線拂、裂㲲、樹皮等；除犛牛尾、馬尾、金銀柄，一切不聽捉；若白色，染壞用；不得如淫女捉作姿作相，是名拂法。《五百問》云：若僧中說法、高座上、不病，不得憑几。捉麈尾，犯墮；非毛者得。《四分》：得尾拂，開畜；不得畜織毛𣭱。
【譯文】《十誦律》說：犛牛尾做成的拂塵，是為了拂拭清掃佛塔才受持蓄用的。《僧祇律》說：自今以後，聽許手持以線繩、撕裂的細棉布（裂㲲）、樹皮等製成的拂子；除了犛牛尾、馬尾以及金銀手柄的拂子一律不聽許拿持；如果是白色的拂子，應當染成壞色後使用；不得像淫女執拂那樣擺弄姿態賣弄風騷，這才是執拂的如法規矩。《五百問》說：如果在僧眾中說法、升於高座之上而並無疾病，不得倚靠几案。若執持麈尾（獸毛拂塵），犯波逸提（單墮罪）；非獸毛製成的則可以拿持。《四分律》說：若得到獸尾拂塵，開許蓄持；但不得蓄持以毛編織的毛扇（或長毛拂）。

【231-0005】01_行事鈔/10c_卷下之二#11
【原文】《十誦》：四人已上坐處，長床所攝。
【譯文】《十誦律》說：可供四人以上坐臥的地方，歸屬於「長床」所攝。

【231-0006】01_行事鈔/10c_卷下之二#12
【原文】《四分》：木師出家，一切作器不應畜。制髮人出家，不得畜剃刀；眾僧得畜剃刀。木作器、角器，聽用盛油。若得衣順浣，開畜浣器及板、剪刀。若不解事數，聽用算子，以帒盛，懸杙上。為治病故，畜㓟刀、若煮藥銚，若銅釜、鐵釜、土釜，及三種瓶、煎餅𨫼、銅杓、銅鐏；眾僧亦得。若鉢不正，作鉢支；塵坌者，作蓋。若須薪、染草、牛屎等，無人處得持之，見白衣下著地；寺內得自移墼石材木等。擣藥須杵、臼、簸箕、篵、掃帚，並開。為治眼故，得畜瑠璃篦，若灌鼻筩。烟筩、吹火筩、若鉗、若椎、火把、煖水瓶、注水筩。并洗脚者供染槃洗脚器，所須應與。若得大小豆、麥、胡麻、粳米，應以鉢器為量，不得畜升斗秤；若穌油等須秤量者，聽刻木作鉢兩，齊四五兩作，準為斤數。《五分》，初如《四分》。後與他物，雖多猶瞋少，佛令僧私畜十解升合及秤。
【譯文】《四分律》說：木匠出家，一切木工器具都不應當私人蓄留。剃頭匠出家，個人不得蓄持剃刀；但僧團大眾（眾僧）得准蓄持剃刀。木製器具、牛角器具，聽許用來盛油。如果得到衣物需要順應清洗，開許蓄留洗衣器具、洗衣板及剪刀。如果不通曉算數法事，聽許使用籌算之子，裝在袋子裡，掛在木橛上。為治病之故，可蓄留割肉放膿的手術刀（㓟刀）、煎煮湯藥的藥銚，以及銅鍋、鐵鍋、陶土鍋，還有三種瓶（瓦瓶、鐵瓶、銅瓶等）、煎餅用的鐵鐺（𨫼）、銅杓、帶尖底的銅鐏；僧團大眾也可蓄持。如果鉢放不端正，可製作鉢座（鉢支）；若怕塵土沾染，可製作鉢蓋。如果需要柴薪、染色草、牛糞等物，在無人處可以自己手持，看見在家人時應當放下置於地上；在寺院之內，可以自己搬移磚坯（墼）、石頭、木材等。搗藥時所需的木杵、石臼、簸箕、盛物竹器（篵）、掃帚，全都開許蓄持。為了治療眼疾，得蓄持琉璃篦子；為了灌藥入鼻，得蓄持灌鼻筒。引煙出屋的煙筒、吹火筒、火鉗、鐵椎、火把、暖水瓶、注水筒。以及染衣用的染盤、洗腳器等，凡是必需之物都應當供給。如果獲得大豆、小豆、麥子、胡麻、粳米，應當以鉢具作為計量標準，不得私人蓄留升、斗、秤等衡器；如果是酥油等需要稱重量之物，聽許刻木製作稱重法碼（木銖兩），以四兩或五兩為限度來製作，依此折算準定為斤數。《五分律》起初規定如同《四分律》。後來因為分發給別人財物時，對方雖然分得多卻仍嫌少而起瞋心，佛陀便准許僧眾個人或寺院蓄置能容納十解（古量名）的升斗量器以及秤具。

【231-0007】01_行事鈔/10c_卷下之二#13
【原文】《四分》：供給和上，聽用銅槃、若案、若几；所食之物，盡持置上，一時授與；得果多，壓取汁飲，開畜壓具。若夜集闇，須燈器，燈炷、鐵著、鐵炷、轉輪燈樹、火爐、燈籠、掃帚、扇；並得別人受。若為護衣故，寺內聽以樹皮、若葉、若竹作蓋；供給蓋具，一切得畜。為補革屣故，開畜錐；得熟皮作革屣，須刀裁、板剗、磨石等，並開。若刀錐、筋毛、縷皮剗迸散，聽作囊盛；若織竹作籠，若樹皮籠，聽以毛囊裹外，亦得趣用十種衣作囊；不得以皮作。若刀生壞，聽以毳劫具、大皮等裹刀。若髮長者，開剃刀及鞘，應以劫貝等，障勿令壞；若刃卷，手上波，石上磨，其石內刀囊中；刀鈍者，開畜刮刀；髮散，畜盛髮器。又開鑷子、剪爪刀、刮舌刀、揥齒物、排耳篦。
【譯文】《四分律》說：供養侍奉和尚（親教師），聽許使用銅盤，或者托盤（案）、几案；將所進用的飲食全都放在上面，一次呈遞授與；若得到的果實很多，壓榨取汁飲用，開許蓄持榨汁用具。如果夜間集會黑暗，需要照明燈器、燈芯（燈炷）、鐵火箸（鐵筷）、持燈燼的鐵器（鐵炷）、旋轉輪形燈樹、火爐、燈籠、掃帚、扇子；這些都可以由個人受持蓄用。如果為了保護衣物不被雨淋，在寺內聽許用樹皮、樹葉或竹子製作雨具傘蓋；供給防護的傘蓋器具，全都可以蓄持。為了修補皮鞋（革屣），開許蓄持錐子；若得到熟皮自製皮鞋，所需的裁皮刀、裁板、鏟刀（板剗）、磨刀石等，都開許蓄留。如果刀、錐、獸筋、獸毛、線縷、皮革、鏟刀等零散散亂，聽許做袋囊裝盛；若編織竹籠或樹皮籠，聽許用毛織袋包裹外層，也可以隨意使用十種如法衣料製作囊袋；但不得用皮革作袋。如果刀刃生鏽損壞，聽許用細毛氈（毳劫具）、厚皮等包裹刀刃。如果頭髮長了，開許蓄持剃刀及刀鞘，應當用細棉布（劫貝）等墊襯包裹，切勿使其損壞；如果刀刃捲口，可在手掌上磨拭（手上波），或在磨刀石上磨利，那塊磨刀石應當放在刀囊中；若刀鈍了，開許蓄持修刃的刮刀；剃下的落髮散亂，開許蓄持盛髮器。此外，又開許蓄持鑷子、剪指甲刀、刮舌刀、剔牙竹籤（揥齒物）、掏耳勺（排耳篦）。
