# 校閱材料　第215檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】第五個問題：給蓄留頭髮的俗衣女子受具足戒，能得戒嗎？回答：有能得戒的，也有不能得戒的。問：什麼情況下能得戒？答：能得戒的情況，是指她立志誓願出家，厭離世俗情感，只是因為遭遇國法王難不准落髮出家；具備這種至誠心意的，無疑能得戒。所以《薩婆多論》問：不剃除頭髮能得戒嗎？答：能得戒，只是不合威儀。《摩得勒伽論》也問：如果白衣居士作和尚，給白衣受具足戒，能得戒嗎？答：受戒者得戒，傳戒之僧犯突吉羅罪。又《十誦律》中優波離問：如果有男子裝扮成女人的威儀、女人的容相、女人的形體，卻依照男子的法度來受戒，得戒嗎？佛陀說：得戒，但與會僧眾犯戒罪。女人裝扮成男子威儀來受戒，也是如此。《五百問事》說：戒壇上的師僧，有的身穿俗服，或者犯了禁戒，受戒人如果明知這是不法，就不得戒；如果不知情，則能得戒。若是弟子身穿俗服，當時若不知情，也能得戒。問：那什麼情況下不得戒呢？答：屢次看見邊遠地區的尼僧妄行戒律，見律文有這些寬容開許之詞，便不論善惡，一律隨波逐流，全都為她們傳授具足戒。這些人對戒事一無所知，專門修習世俗非法，紡紗織布，視世俗勞務為家常便飯，畫長眉、梳高髻、穿著華麗染衣為日常慣習。做師父的貪圖收徒弟的利益供養，當弟子的懷著偷換形相、逃避賦稅勞役的心思。所以僧團不挑選弟子的賢愚善惡，有利可圖便給予傳授；弟子也不審擇師父的德行是非，苟且求取庇護蔭涼。深思這種道理，連世俗的禮儀尚且無法成立，更何況是超越世間的清淨虛懷佛法，怎能容許成就？因此本律宗派的主旨，一定要出家相貌具足，應當剃除鬚髮、身披袈裟，與出家人完全相同；如果穿著世俗服裝、外道服裝、佩戴世俗莊嚴飾物，或是赤身裸體等，都不算作正式出家受具足戒。如果受戒者不親自稱報姓名，不稱報和尚名號，口說乞戒而心不真正求乞，或者在昏睡、沉醉、發狂、瞋恨暴怒中根本無心受戒，或者是心不在境上、境不契合其心、或者心與境完全不相應，這些都稱為非法，不能算作得受戒體。唯有前後心境相合無違，才能成就受戒大事。現在將兩派的主張都列述出來，取捨任由修行者自己衡量。然而諸部經律都命令必須剃髮同於僧相，出家有別於俗人，若隨便依據論典的開緣，深恐不是正途；而且論典並非宗派的最高依據，應當依循律藏的根本威儀為準。

【原文】六問有人尼中作本法竟將三兩尼送受戒人往僧寺得否答依此律不得故律云比丘尼僧應將受戒者至大僧中既言是僧云何許別又受戒已由勸言二部僧具足滿僧祇亦云尼受大戒合二十眾又五分彼和尚闍棃須集十尼僧往比丘僧中乞戒故知僧尼各須十人。
【譯文】第六個問題：有人在尼僧中作完本法後，只帶著兩三個尼僧送受戒人前往比丘僧寺，這樣可以嗎？回答：依照本律是不行的。律中說：比丘尼僧應當帶領受戒者前往大僧之中，既然明確說是「尼僧（僧團全體）」，怎能容許個別數人前往？而且受大戒後，大僧會說「在二部僧中具足圓滿」。《僧祇律》也說：尼受大戒，合起來須有二十位大眾僧。《五分律》也說：那和尚尼、阿闍梨尼必須集合十位尼僧，前往比丘僧中乞戒。由此可知，比丘僧與比丘尼僧各需要十人。

【215-0006】04_比丘尼鈔/02a_卷上之下#38
【原文】七問尼僧至僧寺受戒須結界否答此之羯磨二眾所秉非界無以攝人非界無以羯磨各集本部重結穩審又如尼懺僧殘二眾各須結界亦有諸師不立者良恐誤也若欲作法尼僧盡集自然界內令本法尼在自然界外正結作時不得對僧作法須離聞處遙見無妨故律下文不應對尼作羯磨。
【譯文】第七個問題：比丘尼僧前往比丘僧寺受戒，需要結界嗎？回答：這項羯磨是僧尼二部大眾所共同執行的，沒有結界就無法統攝僧眾，沒有結界就無法進行羯磨。因此各自召集本部大眾重新審慎結界，才算穩妥；正如尼僧懺除僧殘罪，二部僧各需要結界一樣。雖然也有法師主張不需結界，恐怕是錯誤的。如果要在比丘寺作法，尼僧應當全部集合在原有的自然界內，讓本法尼留在自然界外。但在正式結界作法之時，不得當著比丘僧的面直接作法，必須離開他們聽得見的距離，遠遠看得到則無妨。所以律下文明文規定：不應當面朝著比丘尼作羯磨。

【譯文】第六、顏色合乎規定（色如）：本律記載，上等純正鮮豔色彩染成的衣服不可畜存，應當破壞其色澤，染成合乎法度的袈裟色。《十誦律》說：青、黃、赤、白、黑五種純粹的大色衣都不可穿著，補衲衣除外。《薩婆多論》提到：五大色的衣服不能用作三衣；此外，紫草、柰樹皮、地黃、紅緋、黃櫨木等染料染出的顏色，都不合乎法度。若對五大色衣作三點淨，則可以當作其他衣服穿著；所謂紺黑、青、黑色（皁色）、木蘭等色，都可受持為如法衣；純青、淺青、碧綠等色點淨後，只可作衣裡使用；若是赤、白、黃而不屬於純粹的大色，也可以使用。若衣服已經染成不如法的顏色，必須再用如法的顏色覆染，才能受持。《文殊師利問經》說：染色的衣服不能太紅、太黃、太黑、太白，應當是清淨如法的壞色，三件法衣以及其他常服都應如此。律義解釋：作點淨法時，可用前面所提的紺、黑、青三色，在衣服四角任選一角點上一點。《僧祇律》說：點的大小最大如四指，最小如豌豆；《善見論》則說如麻子大。《僧祇律》又說：不可將點連成一片；點的數量可以是一、三、五、七、九點等（取奇數），但不可排列成花朵的形狀；若衣服經過洗滌、穿舊或被泥汙沾染，就自然算作已作淨。若是新縫製的僧伽梨，只需在任一角點淨即可，乃至所有新衣也是如此；若是用許多碎布拼接補綴成的衣，只需在其中一處點淨。「青色」是指銅青色；「黑色」是指用雜泥等染出的黑褐色；「木蘭色」是指用果汁等染出的顏色。律義補充：蜀地有一種木蘭樹皮，其色赤黑而帶有光澤，可用來染色，微有香氣；關東并州也有木蘭樹的果實，既能串成念珠，也可提煉染料，色澤偏黑；京城附近的各山也有這種植物，但採尋者極少。

【譯文】以下其餘二衣的捨法可比照類推理解。《僧祇律》說：如果前往別人家中，忘記隨身攜帶三衣，抵達後才想起來，應當對著遠方心念捨去；捨衣之後，應當暫時借用俗人的衣服或被子作淨法，安上鉤紐暫時受持。律義指出：若知道有其他比丘處存有僧尼多餘的長衣，借來受持更為妥當；想要歸還時應先捨去，回到自己的住所後再重新受持原本的舊衣，這樣就不會犯捨墮罪。《十誦律》說：借用他人衣服離開宿處，只需懺悔波逸提罪，不必再作捨衣法。

【原文】第十四得失者五分云諸比丘不捨先受持衣更受餘衣者成受先三衣說淨者亦成由不捨故但犯小罪此律若失想燒想賊奪想水漂想則失受持得者還須更受以忘失故無捨罪若道逢難緣不得會衣者不失受持婆論云三衣不受持有壞威儀缺衣二罪若本說淨今作三衣即失本淨法又捨此衣更受餘衣前衣即須說淨否者過十日犯長婆論云若三衣破不問孔大小但使緣不斷不失受持尼祇支覆肩衣義準此說。
【譯文】第十四、得失界線（得失）：《五分律》說：各位比丘若不先捨去原先受持的衣，就直接受持別件衣服，則後衣受持成立，先前的三衣若作說淨也成立，但因為未依規定先捨衣，所以犯輕罪（突吉羅）。依本律規定，如果衣服生起「丟失想」、「燒毀想」、「被賊劫奪想」、「被水漂走想」，就失去受持的法效；找回之後必須重新作受法，但因為是遺失的緣故，並不犯未捨之罪。若在路上遇到災難障礙，無法取回衣服，則不失去受持資格。《薩婆多論》說：三衣若不受持，會同時犯下「破壞威儀」與「缺衣」兩項罪過；如果原本作了說淨的衣服，現在拿來作三衣受持，原本的說淨法效即告消失；此外，若捨去原衣改受新衣，原本那件衣服就必須在限期內說淨，否則超過十天就會犯長衣罪。《薩婆多論》又說：如果三衣破裂，無論破洞多大多小，只要邊緣飾帶沒有斷裂，就不失去受持資格；比丘尼的僧祇支與覆肩衣，義理上也依此規定判定。

【215-0069】04_比丘尼鈔/02b_卷上之下#27
【原文】第十五補浣者十誦云以小段物補衣若却刺者不須說淨點淨若直縫者段段須說否者段段得二罪謂不說淨不點淨也見論云若衣欲破未穿壞者或一條二條應先以物補後割却故者不失受三衣背處欲破當轉著兩邊先相連著後以刀破開然後却刺緣不失受持袈裟若大減却若小物裨亦不失受若浣增色亦不失受此律三衣壞隨孔大小方圓補治。
【譯文】第十五、補綴與清洗（補浣）：《十誦律》說：用小塊布料補衣服，如果是用回針倒刺法縫補，就不需要說淨或點淨；如果是用直縫法，則每一塊布段都必須作說淨，否則每一段都會結下兩種罪過，即不說淨罪與不點淨罪。《善見論》說：如果衣服將要破壞而尚未穿孔，無論是一條或兩條，應先用新布貼補，然後再把破損的舊布割除，這樣便不失受持效力；三衣貼靠背部容易磨損的地方將破時，應先移轉縫接於兩邊，先將其連綴固定，再用刀裁割分開，然後回針倒刺包邊，如此亦不失受持資格。袈裟如果過大，裁減之，如果過小，用布料增補之，都不失受持效力；清洗時即使顏色變深，也不失受持效力。本律規定：三衣若破損，應隨破洞的大小方圓進行修補整飭。

【215-0070】04_比丘尼鈔/02b_卷上之下#28
【原文】第十六敬護者十誦云護三衣如自皮鉢如己眼著大衣者不得摙木石土艸掃地敷具等又不得脚躡敷坐臥上及襯身著若不持三衣入聚落俗人處犯吉羅遺教三昧經云比丘行時僧伽棃袈裟衣鉢鍚杖等當與身俱不得去身六尺五百問事云不能著大衣入聚落但持著肩上行無犯僧祇云敬三衣如塔若入聚落必須帶紐行若無紐者用鍼綴無鍼者下至手捉若無紐隨入家家得越心悔有而不著亦越毗尼披時當通肩披齊兩角左手捉時不得手中出角頭如羊耳律中至佛前上座所竝令偏袒經中通肩披衣五百世中入鐵甲地獄五分云得四褺大衣枕之中阿含經多處有文開枕大衣臥七條中三千威儀經云不著泥洹僧不得著僧祇支如是重重乃至最上著僧伽棃故知三衣得上下重著也五分云若出村為艸木鈎衣破裂塵入葉中聽為護衣故聚落外反著衣下數壞聽倒著衣上下安鈎紐及帶雨時不應倒著此律尼不著祇支入白衣舍提毗尼母及此律袈裟不得簾牀及脚躡三千威儀經云三衣在下地身不得高牀處坐決正二部毗尼論云若著大衣入村不得禮拜師僧上座等五百問事云無中衣時得著大衣上講禮拜小衣不近身淨潔無七條者五條亦得著入眾食及禮拜不著三衣食犯罪十誦亦然。
【譯文】第十六、敬重與護持（敬護）：《十誦律》說：愛護三衣應當如同保護自己的皮膚，珍惜缽器應當如同愛護自己的眼睛。穿著大衣時，不可搬運木材、石塊、泥土、割草、掃地、鋪墊坐臥具等，也不可以用腳踩踏、鋪在坐臥之處，更不可貼身肉體直接穿著；如果不帶三衣就進入村落聚落的俗人處所，犯突吉羅罪。《遺教三昧經》說：比丘行走時，僧伽梨袈裟、衣缽、錫杖等，都應當與自身相隨，不可離開身體超過六尺。《五百問事》說：若無法整套穿著大衣進入聚落，只要搭掛在肩上行走，就不算違犯。《僧祇律》說：敬重三衣應當如同敬仰佛塔；進入聚落時，必須扣好帶鈕前行，如果沒有帶鈕，要用針別好，如果連針也沒有，至少要用手握緊衣緣；若無帶鈕而隨意步入各家戶，每進一家便結一次越毗尼罪，需心念懺悔；若是備有帶鈕卻不繫好，也犯越毗尼罪。披衣時應當通肩披著，使兩角齊整；左手握持衣角時，不可讓衣角在手中散露突出如羊耳的形狀。律中規定到佛前或長老上座處，都必須偏袒右肩；而經文提到若通肩披衣禮拜，將有五百世墮入鐵甲地獄的果報。《五分律》說：大衣可以折疊成四層當作枕頭使用；《中阿含經》等多處經文中，均開許將大衣當枕頭、臥在七條衣中。《三千威儀經》說：若不先穿泥洹僧（下裙），就不可穿僧祇支，應當這樣層層內外相套，直到最外層穿上僧伽梨；由此可知三衣是可以上下重疊穿著的。《五分律》說：如果出村時，為了防止草木鉤破衣服、塵土灌入衣條摺葉中，為了護惜衣服，聽許在聚落外把衣服反過來穿；若下緣磨損嚴重，聽許倒過來穿，上下皆安設鉤紐與帶子，但在下雨時不應倒著穿。本律規定：比丘尼若不穿僧祇支便進入俗人家舍，犯波逸提罪。《毗尼母論》與本律皆規定：袈裟不可垂掛遮蔽床沿，也不可用腳踐踏。《三千威儀經》說：三衣若放在低處地上，自身不可坐在高床之上。《決正二部毗尼論》說：如果穿著大衣進入村落，不可在俗舍中向師長僧眾及上座禮拜。《五百問事》說：若缺少中衣，可以穿大衣登座說法或禮拜；五條小衣若未貼身且乾淨整潔，在缺少七條衣時，也可以穿著五條衣進入大眾中應供及禮拜；若完全不穿三衣就去用餐，則構成犯罪，《十誦律》亦同此規定。
