# 校閱材料　第215檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【215-0001】01_行事鈔/09c_卷下之一#34
【原文】次分輕物。律令白二差人。今時行事，但取知僧事者，或臨時口差，不用羯磨，違法通得。持律者，先知不具德者沙彌法等，《多論》云：三衣餘處者，索來此賞；若此德不具，即隨彼分。若三肘五肘外長，隨多少，應白僧令知，和合與者好。《十誦》：沙彌死，所著內、外衣，與看病人；餘輕物僧分。羯磨云：「某甲沙彌死，所有內、外衣及非衣……」餘並同大僧法。今時行法者，命知事人，在僧前胡跪，白二與之。文云：「大德僧聽！比丘某甲命過，所有若衣、若非衣，現前僧應分。若僧時到僧忍聽：僧今持是衣物，與比丘某甲，某甲當還與僧。白如是。」「大德僧聽！比丘某甲命過，所有若衣、若非衣，此現前僧應分；僧今持與比丘某甲，某甲當還與僧。誰諸長老忍：比丘某甲命過，所有衣物，現前僧應分，僧今持此衣物，與比丘某甲，某甲當還與僧者，默然；誰不忍者，說。僧已忍，持此衣物與比丘某甲，某甲當還與僧竟。僧忍，默然故。是事如是持。」作法已，即數僧數，量其衣物相參，擲籌取分。《五分》：若衣少不足者，和僧與一無衣比丘。《善見》云：若一衣極好，眾並有衣，從上座行之，須者直付。若衣物極多，徒眾有法，準聖教分之。此是非時僧得施，功德遍十方僧；不須造像設齋，更生漏過。以出家人修智分業，不以福分為懷，縱設違佛本制。諸部但明分用，凡智不過聖心。若外界不集者，《僧祇》：為病人求衣藥，及為塔、為僧知事，雖當時不在，並應與分。此謂差眾使者得，若私營佛法不合。次明與沙彌，淨人分。四律並云：若僧和合，等與；乃至四中與一、淨人五中與一。若不與者，不合分；若分，得罪。自餘廢立，如《疏》、《鈔》中。如是總計大數，抄名記數，然後品物付之。律無賣物分法，今時分賣，非法非律。至時喧笑，一何顏厚；佛令分付，為息貪情，令各自省；今反樂笑，不惟終始。此習俗生常，乃無悛革；望諸有識，深察斯過。
【譯文】其次是分配輕物。律制命令應當作白二羯磨推差專人。現今寺院行事，往往直接選取寺院知事人，或者臨時以口頭差派，不再舉行羯磨，雖然違背嚴格律法但習俗上通融可行。持律者應當預先知曉照護不具足五德者、或亡者是沙彌等情境的處分法則。《薩婆多論》說：亡者的三衣若存放在別處，應當索取過來此處作為賞物；如果此處看病者德行不具足，就隨同彼處僧眾去分配。如果在三肘、五肘的法定尺寸之外有多餘的長物，不論超出多少，都應當向僧團稟白令大眾知曉，僧團和合同意給予看病者為佳。《十誦律》說：沙彌亡故，身上所穿的內衣、外衣，賞給看病的人；其餘輕物由大眾僧分配。羯磨文說：「某甲沙彌亡故，所有內衣、外衣及非衣服等物……」其餘程序全同大僧之法。現今行此法時，命知事人站在大眾僧前胡跪，以白二羯磨將物品付託給他。羯磨文說：「大德僧聽！比丘某甲命終，所有若是衣服、若是非衣服，現前僧應當分配。若僧時機已到，僧忍可聽許：僧今將此衣物交付給比丘某甲，某甲應當代為歸還分配給僧眾。表白如是。」「大德僧聽！比丘某甲命終，所有若是衣服、若是非衣服，此現前僧應當分配；僧今將此交付給比丘某甲，某甲應當代為歸還分配給僧眾。諸位長老誰忍可同意：比丘某甲命終，所有衣物現前僧應當分配，僧今將此衣物交付給比丘某甲，某甲應當代為歸還分配給僧眾者，請默然；誰不同意者，請說明。僧已忍可同意：將此衣物交付給比丘某甲，某甲應當代為歸還分配給僧眾完畢。因為僧眾忍可默然的緣故。此事就這樣如法受持。」作法完畢之後，隨即清點僧眾人數，衡量衣物數量互相參配，以行籌抽籤的方式領取份額。《五分律》說：如果衣服太少不足以遍分給眾人，應由僧團和合決議，全數給予一位缺少衣服的比丘。《善見律》說：如果有一件衣服極為上好，而大眾僧普遍已有衣服，則從上座起依序詢問行付，誰有需要就直接付給誰。如果遺留的衣物極多，僧眾已有如法定規，就準照聖教予以分配。這是屬於「非時僧得施」（非特定時節僧團意外所得之布施），其分配功德能普遍利益十方僧眾；不需要拿去造像或設齋供僧，以免橫生漏失過患。因為出家人應當以修習智慧之業為本分，不應當一味以經營世俗福德為念，縱使設齋造像也違背了佛陀分配亡僧遺物的本制。各大部派律典只說明分配享用之法，凡夫的心智萬不能超越佛陀聖心。如果結界外有未能集合的僧人，《摩訶僧祇律》說：為了病人求索衣服醫藥，以及為了佛塔、為了僧團公務出差者，雖然當時不在場，都應當分給他一份。這是指受僧團差遣辦公的人才能分得，若是私自外出營辦佛事者則不合資格。其次說明分給沙彌、淨人（寺院雜役僕役）的份額。四部律典都說：如果僧團和合決議，可以均等給予；乃至比丘得四份之中給沙彌一份、淨人在五份之中給一份。如果僧團不同意給予，則不應當分給他們；如果分給了他們，便得罪。其餘各大律典廢立取捨之說，詳載於《戒本疏》與本《行事鈔》其他篇中。像這樣總計出大數，登記姓名與物品數量，然後將物品分付給每個人。律典中根本沒有「變賣亡僧物品分錢」的方法，現今寺院將遺物拍賣分錢，是非法非律的行為。到了拍賣之時眾人喧鬧嬉笑，臉皮何其之厚！佛陀命令分配付予，是為了止息眾人的貪愛之情，令每個人藉此自我省察生死無常；如今反而歡樂嬉笑，絲毫不思及修道的終始。這種世俗惡習已成平常慣例，竟然毫無悔改革新之心；但願諸位有識之士，能深切洞察這種過咎！

【215-0002】01_行事鈔/09c_卷下之一#35
【原文】若五人共住，一人死。衣鉢直三人口和賞勞已；餘諸輕物，依《母論》，四人直作分衣羯磨。文中除「僧今持此衣物與某甲，某甲當還與僧」等字，餘同前法。作此法已，未得分入手來，有客僧入界，並須更共作法分之。
【譯文】如果五人共住，其中一人死亡。衣鉢只需其餘三人以口頭和同表決賞勞完畢；其餘各項輕物，依照《毘尼母經》，剩下的四人直接作「分衣羯磨」。羯磨文中扣除「僧今持此衣物與某甲，某甲當還與僧」等字句，其餘程序全同前面的法規。作完這個羯磨法之後，在物品尚未正式分配到手之前，如果有客比丘進入結界之內，都必須重新共同作羯磨法來進行分配。

【215-0003】01_行事鈔/09c_卷下之一#36
【原文】二明對首法。《毘尼母》云：四人共住，一人死。三人應展轉分。應二人口和，以衣賞看病者；餘物三人彼此相語云：「二大德憶念！此物應屬我等。」餘二人亦如是，三說。若三人中，一人死。先取衣鉢直付；餘物二人展轉如上法。《四分》文中，直明彼此三語受共分，文詞如論說也。
【譯文】第二說明「對首法」。《毘尼母經》說：四人共住一處，一人死亡。其餘三人應當展轉相對作法分配。應當由其中二人口頭和同同意，將衣物賞給看病的人；其餘物品由三人彼此相對陳說道：「二位大德憶念！此物應當屬於我等。」其餘二人也同樣各陳述三遍。如果是三人共住，一人死亡。首先取其衣鉢直接交付給看病者；其餘物品由二人展轉依照上述之法相對作法分配。《四分律》文中，直接說明彼此相對三度陳詞以領受共同分配，文辭正如同論中所說。

【215-0004】01_行事鈔/09c_卷下之一#37
【原文】三明心念法。《毘尼母》云：一相應法者，二人共住一人死，在者作念：「此亡比丘物應屬我。」作此說已，後來人不得分。《四分》：一人受僧施中，應心念口言：「此是我分得也。」
【譯文】第三說明「心念法」。《毘尼母經》說：單獨一人相應之法，即二人共住一處而一人死亡，在生者作念（須口陳）：「這位亡比丘的物品應當屬於我。」作了這樣的念白之後，後來進入結界的人就不得參與分配。《四分律》說：一人接受僧團布施分配時，應當心念口言：「這是我所分得的份額。」

【215-0005】01_行事鈔/09c_卷下之一#38
【原文】問：羯磨文中非衣者，此何衣耶？答：律不顯相。文云：時有將非衣作鉢囊、革屣囊；佛言，不應作之。又云：與比丘尼非衣。亦不知何等衣也？今但通而述之，無妨彼此俱攝。
【譯文】提問：羯磨文當中所說的「非衣」，這是指什麼衣物？回答：律典中並未明確顯現其具體名相。律文中說：當時有人拿非衣去縫製鉢囊、革屣囊；佛陀說，不應當這樣做。律文又說：布施給比丘尼「非衣」。也令人不知究竟是何等衣服？如今只作通泛的論述，不妨將各類非屬正規法衣的衣物布料統攝在其中。
