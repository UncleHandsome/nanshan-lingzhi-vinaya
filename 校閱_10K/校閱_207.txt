# 校閱材料　第207檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【207-0001】01_行事鈔/09b_卷下之一#26
【原文】四明亡五眾物。既財是小人所利，非大士所懷。然出家濟遠，經勞涉樂，俗譽非慕，唯存出道者，則蕭然世表，塵染不拘；而情性未融，素非清潔者，唯利是親，全無道志。然上下二士，並預法流；上達立法以濟器，下達受法而隨懷；俱須兩順佛法，用通一道淨行。然亡僧衣物，處斷多途；並謂指南，俱呈至說。但由教有輕重，機悟淺深；如序所明，其例有六。至論決斷，每有遲疑；臨事詳之，在於輕重。今既事務繁雜，非諸門無以別之；且張十門，用開進不：一制入僧，餘處不得。二對亡者，分法不同。三同活共財不同。四囑授是非。五負債還不。六定物重輕。七具德賞勞。八分物時節。九正加分法。十雜明受物。
【譯文】四明亡五眾物。財物本來是世俗卑小之人所貪圖追逐的，絕非菩薩大德心中的執念。然而出家修道是為了濟度深遠、歷經勤勞安度淨樂，世俗的名譽絲毫不去羨慕，心中唯有出世成道的志向，這樣的人自然瀟灑於世俗表相之外，塵勞染污皆不能拘縛其心；然而那些性情尚未融通法理、平日行止並不清白高潔的人，卻唯獨與財利親近，完全沒有修道的志氣。不過，這上、下兩類出家人，同在佛法的法流之中；上智通達之人創立法規以濟度各類器識，下愚之輩接受法教而隨順各自的心量；雙方都必須隨順佛陀正法，以此融通同一條清淨修行的正道。然而對於亡僧遺留的衣物，律論中處置決斷的途徑極為繁多；各部律論都自稱是指南圭臬，皆提出了極致精微的教說。只是由於戒教開遮有輕重之分，眾生機根領悟有深淺之異；如同本書序文中所說明的，其條例如同六義。到了臨事論斷之際，往往令人產生遲疑不決；臨事必須詳細推究，關鍵在於審酌事相的輕重。如今既然各項事務紛繁龐雜，若不用多個門類就無法條分縷析；姑且開列為十門，用以開示去留進退的原則：第一、規定遺物歸入常住僧團，其餘地方不得分取。第二、針對亡者的不同身分，分配方法各不相同。第三、同處生活、共用財物者的分法不同。第四、生前囑託受授的如法與否。第五、亡者所欠之債是否需要償還。第六、判定遺物屬於重物還是輕物。第七、具備功德勞績者的賞勞之法。第八、分配遺物的具體時節。第九、正式行羯磨的分配儀軌。第十、雜說各類受領遺物之法。

【207-0002】01_行事鈔/09b_卷下之一#27
【原文】初門制意者。所以五眾亡後，皆入僧者。生則依三寶出家，而物不入佛法；以出家六和，同遵出要，身行所為，莫不為僧法所攝。故人施佛法，比丘無分；若施僧者，依位受之。亦不屬俗，非福田故，《僧祇》：阿若憍陳如，空林中入涅槃，牧牛人送衣物與王，王即評直五錢，依法斷還沙門，乃至佛言屬僧。《十誦》：跋難陀死，衣物直四十萬兩金，國王剎利種，及諸親里各欲收取。佛言，王賜諸臣，比丘不得。乃至親里集會，不見喚及。僧家財法並同，俗人不合，此屬僧物。
【譯文】初門制意者。出家五眾身亡之後，遺物之所以全都歸入僧團的原因在於：出家人活著時是依止三寶而出家，而其遺物卻不歸入佛物與法物；因為出家人奉行六和敬，共同遵奉出離生死的大要，其身行所做的一切，無不被僧團大眾之法所統攝包容。所以世人布施給佛與法的財物，比丘個人無權私分；若是布施給僧團的大眾物，則依照戒臘受領一份。這些遺物也絕不能歸屬於世俗之人，因為俗人並非出世福田的緣故。《僧祇律》記載：阿若憍陳如在空曠樹林中入涅槃，放牛人將其遺留的衣物送給國王，國王隨即估定價值五錢，依法判決歸還給沙門，乃至佛陀開示說遺物歸屬於僧團。《十誦律》記載：跋難陀比丘去世，其遺留衣物價值高達四十萬兩黃金，國王、剎帝利貴族階級以及各位親戚眷屬都想要收繳奪取。佛陀說：國王賞賜給大臣，比丘得不到；乃至親族集會，不曾招呼及此。僧家財物與法事皆與亡者完全共同，世俗凡人不應干預分取，此屬於僧團的物資。

【207-0003】01_行事鈔/09b_卷下之一#28
【原文】二對人死分法不同。十種斷別：一者糞掃取。如《五分》，界內水漂死人衣，挂樹枝，隨見者取之。二入當時現前僧。如《十誦》，學悔沙彌死、被擯比丘死、守戒比丘死，隨更互直取。三入同見僧。如《四分》，邪正二部，各執是非；其人中道死、至彼死，皆同見自分。四入功能僧。如《四分》，被舉比丘死，衣物入同羯磨舉僧。五入二部僧。如《五分》獨住比丘死、《薩婆多》二界中間死、《四分》無住處白衣家死，五眾先來者得。六入面所向處僧。如《多論》二界中間，隨面向處僧應取。七入和尚。《僧祇》中沙彌死，衣物入師和尚等。謂令和尚分別財體，以師物自入，沙彌物入僧。八入所親白衣。《薩婆多》滅擯比丘死，將衣鉢付生緣。九隨所在處得。如《十誦》有比丘持衣寄阿難，三處共爭，謂能寄人、所寄者、寄物處。佛言屬阿難處僧，界內現前僧應分，以寄人不寄處故。上來九種，直爾分之。第十，一和清眾死，方入羯磨。
【譯文】二對人死分法不同。共有十種判斷區別：第一種，作為糞掃衣取用。如《五分律》所說，在結界之內被水漂流的死人衣服，掛在樹枝上，凡先看見的人即可直接拾取。第二種，歸入當時現前的僧眾。如《十誦律》所說，在受罰學悔期間的沙彌死、被擯黜驅逐的比丘死、持守禁戒中的比丘死，大眾隨其情況直接相互均分取用。第三種，歸入見解相同的僧團。如《四分律》所說，分裂為邪部與正部二部，各自堅持是非；若某人在路途中死去、或到了對方那裡死去，都由與其見解相同的一方僧眾自行分配。第四種，歸入行使羯磨功能的僧眾。如《四分律》所說，被舉發治罪的比丘死，其衣物歸入共同作羯磨舉發治罪的僧團。第五種，歸入比丘、比丘尼二部僧。如《五分律》說獨自居住的比丘死、《薩婆多論》說在兩界交界中間死、《四分律》說在沒有固定住處的俗人家中死，出家五眾中先到達現場的人即可獲得。第六種，歸入亡者面孔所朝向處的僧眾。如《薩婆多論》說在兩界之間死，隨其臨死時臉部朝向哪一方結界的僧眾，就由該方僧眾取用。第七種，歸入和尚（剃度親教師）。《僧祇律》中說沙彌死，衣物歸入其師長和尚等。意思是讓和尚辨別財產的本質，原本屬於師長之物由師長自己收回，本屬沙彌所有的財物則歸入僧團。第八種，歸入與其親近的俗人。《薩婆多論》說被徹底滅擯（逐出佛門）的比丘死，可以把他的衣鉢交還給其世俗親緣眷屬。第九種，隨（受寄人）所在處的僧眾獲得。如《十誦律》記載有比丘拿衣服寄放在阿難處，有三處僧眾共同爭奪，也就是寄衣者處、受寄託者處、寄放物品處。佛陀裁決說歸屬於阿難所在處的僧團，由該界內現前僧眾分配，因為寄託是託付給人而非託付給住處的緣故。以上九種情況，都可以直接分配。第十種，只有在同一和合的清淨僧眾中如法比丘身死，才正式進入羯磨僧事來行分配。
