# 校閱材料　第796檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【796-0001】02_戒疏/19a_卷四下之一#4
【原文】【記】四十八，制意中。一、比丘觀軍，薄濫佛法；二、招他譏毀；三、習起兇暴。故制此戒，反過成益。
【譯文】【記文】第四十八條，在闡明制定此戒的用意中：第一，比丘前往觀看軍陣，會輕忽鄙薄、混雜染污佛法；第二，容易招致他人的譏笑毀謗；第三，會染習生起兇殘好鬥的心性。所以制定這條戒，轉化過失成為修持的利益。

【796-0002】02_戒疏/19a_卷四下之一#5
【原文】【疏】論犯三緣：一、是軍陣；二、故往觀；三、見便犯。
【譯文】【疏文】論述構成犯戒的三種條件：第一，確實是軍隊列陣；第二，特意刻意前去觀看；第三，眼見軍陣便構成犯戒。

【796-0003】02_戒疏/19a_卷四下之一#6
【原文】【記】犯緣。第二，「故往」者，開非意故。
【譯文】【記文】犯戒條件中。第二點「刻意前去」，是為了開許無意撞見的情況。

【796-0004】02_戒疏/19a_卷四下之一#7
【原文】【註】佛在舍衛。人民反叛，王領六軍征伐，六群觀陣。波斯匿見，不悅，以一褁石蜜奉佛，并持名禮拜。彼至佛所，具陳此緣，因訶制戒也。
【譯文】【註文】佛陀住在舍衛國時。有民眾背叛反抗，國王親自率領六軍出征討伐，六群比丘前去觀看軍陣列隊。波斯匿王看見後，心中非常不高興，便派人持一包石蜜供奉佛陀，並代為稱名禮拜。使者抵達佛陀住處，具體陳述了這個緣由，佛陀因此訶責並制定了戒律。

【796-0005】02_戒疏/19a_卷四下之一#8
【原文】【疏】緣中，始因看軍，王使持名禮佛者，制戒之本也。
【譯文】【疏文】在制戒因緣中，起初是因為比丘觀看軍隊，國王派使者代為稱名禮佛，這是制定此戒的根本緣起。

【796-0006】02_戒疏/19a_卷四下之一#9
【原文】【記】戒緣。匿王遣令奉蜜，意欲請佛制戒。六群不知，往遭訶制。注中，「六軍」，二千五百人為一軍，天子當用六軍，即一萬五千人。
【譯文】【記文】制戒因緣。波斯匿王派遣使者敬奉石蜜，用意在於祈請佛陀制定戒律。六群比丘並不知情，前去觀看便遭到訶責與制戒。隨律註解中的「六軍」，古代以兩千五百人為一軍，天子之尊應統率六軍，總計為一萬五千人。

【796-0007】02_戒疏/19a_卷四下之一#10
【原文】【律】若比丘，往觀軍陣，除時因緣，波逸提。
【譯文】【律文】如果有比丘，前去觀看軍隊陣列，除特定時機與因緣之外，犯波逸提（單墮罪）。

【796-0008】02_戒疏/19a_卷四下之一#11
【原文】【註】若不避者，吉羅。從下至高，道至非道，不見，吉羅；方便不見亦爾；若見，犯墮。不犯者：若有事往；若被請去；勢力將去；若先前行，軍在後至，便下道避。若水陸道斷，惡獸、賊難，水大漲，若為力勢所繫縛，或命、梵等難，不下道，無犯。
【譯文】【註文】如果（在路上遇到軍隊）而不下道避讓，犯突吉羅（輕垢罪）。從低處登向高處，或從正道轉往偏道，雖然沒看見，也犯突吉羅；設法觀看而未看見，也是如此；如果看見了，便犯墮罪。不犯的情況：如果有正當事務前往；如果是受人邀請前去；是被強大勢力強行帶去；如果是比丘先行在路上，軍隊在後方追至，便立即走下道路避開。若是水路或陸路斷絕，遭遇兇惡禽獸、盜賊災厄，江河大水暴漲，或者被外力強行拘禁綑綁，乃至有生命危險或梵行受損等重大災難，因而沒有走下道路避開，均不算犯戒。

【796-0009】02_戒疏/19a_卷四下之一#12
【原文】【疏】戒本四句：一、人；二、觀軍，注中真、戲俱犯；三、除緣，如後；四、結罪，文相可解，不看即是，縱下道避，偷見亦犯。
【譯文】【疏文】戒本條文共有四句：第一，指出違犯的人；第二，前往觀看軍隊，隨律註解指出觀看真實交戰或演習操練均屬違犯；第三，排除特定因緣，詳見後續說明；第四，定罪懲處，文字意義容易理解，只要不去看便算持戒合儀，縱然走下道路迴避，若是暗中偷看也同樣犯戒。

【796-0010】02_戒疏/19a_卷四下之一#13
【原文】【記】戒本。第二句，「真」鬪、「戲」陣，情過同故。三、「除緣，如後」，即次戒也。四中，初指文，「不」下，示意。言「即是」者，謂順教無犯也。《戒本》制觀，偷目竊觀，雖避何益。
【譯文】【記文】戒本條文。第二句指出，觀看「真實」交鬥與「演習」列陣，內心染著與放逸的過咎相同。第三句「排除特定因緣，詳見後續說明」，即指下一條戒所開許的情況。第四句中，起初指引條文，從「只要不去看」以下，是闡明戒行旨趣。所謂「算持戒合儀」，是指順從教法便不犯戒。《戒本》旨在禁制觀賞軍事，如果偷偷窺視，即使形式上走下道路迴避，又有何益處。

【796-0011】02_戒疏/19a_卷四下之一#14
【原文】【疏】此中五兵，不起則已，起必加身，王者不獲已而設。比丘義無輒見。故刀兵之劫，起在此心。違順之間，持犯立見。
【譯文】【疏文】此處所用的五種兵器，不興動則已，一旦興動必定殘害人身，這是國王在不得已的情況下才設置的。比丘在義理上絕不應當隨意觀看。所以刀兵劫的禍患，根本上就生起於好戰喜殺的心念之中。在違背與順從戒律的剎那之間，持戒與犯戒的界限立刻判明。

【796-0012】02_戒疏/19a_卷四下之一#15
【原文】【記】勸持中。初敘兵意。「五兵」者，即軍陣所執五種兵器。《周禮注》曰：「戈、殳、戟、酋矛、夷矛。步卒無夷矛而加弓矢。」、「起必加身」，謂陵害於人身。家國置之以示威，用之以定亂，非所樂之，故云「不獲已」也。
【譯文】【記文】勸勉持戒的文段中。起初敘述設置軍隊的用意。所謂「五兵」，是指軍陣所執持的五種兵器。《周禮注》說：「指戈、殳、戟、酋矛、夷矛。步兵不配備夷矛而改加弓箭。」所謂「一旦興動必定殘害人身」，是指侵凌傷害人命。國家設置兵器是用來昭示威儀，運用兵器是用來平定禍亂，並非樂於使用，所以說「不得已」。

【796-0013】02_戒疏/19a_卷四下之一#16
【原文】【記】「比丘」下，誡往觀。初示非宜。「故」下，明所感。「刀兵劫」者，準《俱舍論》，人年十歲時，人長尺五，短者一尺，有刀兵災起，七日七夜，地多荊棘，皆如鋒刃。手執草木，悉成劍戟，但欲相殺。若人曾持不殺戒，免逢此劫。《長阿含》云「斯由其人常懷嗔忿，害心相向，無慈心故，是為刀兵劫」，故曰「起在心」也。
【譯文】【記文】從「比丘」以下，告誡不可前往觀看。起初指出這與身分極不相宜。從「故」以下，說明心念感召的果報。所謂「刀兵劫」，依據《俱舍論》記載，在人類壽命減至十歲時，人身長度僅有一尺五寸，矮小的只有一尺，屆時刀兵災禍四起，持續七天七夜，遍地布滿荊棘，鋒利皆如刀刃。手中隨便抓取草木，全都會化作利劍長戟，眾人心中只充斥著互相殘殺的念頭。如果有人曾持守不殺生戒，便能免於遭遇此劫難。《長阿含經》說「這全是由於那時的人們常懷嗔恨忿怒，彼此懷抱傷害殘殺的心思，毫無慈悲憐憫之心，因此演變成刀兵劫」，所以說「生起於心念之中」。

【796-0014】02_戒疏/19a_卷四下之一#17
【原文】【記】「違」下，示持犯相。舉心轉眼，即「違」成「犯」，稟制低眸，即「順」成「持」，故云「立見」。
【譯文】【記文】從「在違背與順從」以下，開示持戒與犯戒的行相。起心動念轉頭凝視，就是「違背」教制而構成「犯戒」；遵循戒制低眉垂目，就是「順從」教敕而成就「持戒」，所以說「立刻判明」。

【796-0015】02_戒疏/19a_卷四下之一#18
【原文】【記】結犯，注中二節。初明輕重。「不避吉」者，違制教也。「從下至高」，謂登高處。「道至非道」，謂選要便處。欲見「不見」，緣缺故輕，「見」則是重。不犯中，初開有緣。「若」下，次明順教。「若水陸」等，後開急難。
【譯文】【記文】定罪結過，隨律註解中分為兩節。起初說明罪責的輕重。「不迴避犯突吉羅」，是違背了制戒教敕。「從低處登向高處」，是指登上高聳地形。「從正道轉往偏道」，是指挑選便於窺視的要衝。意圖觀看而「未看見」，因客觀條件不具足所以結罪較輕；若「親眼看見」則結犯重罪。在不犯的情況中，起初開許有正當緣由；從「若是」以下，接著說明順從教法避讓；從「若是水路或陸路」等處，最後開許遭遇急難的情況。

【譯文】【律文】第四十九條：軍隊中留宿過期戒。

【796-0017】02_戒疏/19a_卷四下之一#20
【原文】【疏】在軍過宿戒四十九。
【譯文】【疏文】在軍營中留宿過期戒，為第四十九條。
