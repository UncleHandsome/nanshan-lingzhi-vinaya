# 校閱材料　第1645檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1645-0001】03_業疏/06b_卷一之六#56
【原文】僧祇》：「若僧作非法羯磨，若有力者遮言非法。前人凶惡，能為二難，聽作見不欲，不得趣爾。於同意者說言：『此非法羯磨，我不忍與。』見不欲三說已，不得至四，此即六和中見不同也。餘者與如法欲已捨去。若非法斷事，不遮、不與欲及不欲者，越毗尼。若自念言：『隨其業行，如火燒舍，但自救身。』得護心相應者無犯
【譯文】《僧祇律》說：「如果僧眾作非法羯磨，若有能力之人應當出面阻攔說這是不合法的。如果對方凶頑險惡，能夠製造梵行難與生命難這二種難事，則佛聽許其作『見不欲』（在場表達不同意），但不可隨便草率。應當對意見相同之人說：『這是非法羯磨，我不忍可參與。』見不欲說了三遍之後，不可說到第四遍，這就是六和敬中的見解不同。其餘的人則如法給與欲意後離去。如果是以非法手段斷決僧事，既不阻攔、也不與欲或不欲者，犯越毗尼罪。如果自己心中念道：『任隨他們的業行去受報吧，如同大火燒宅，我只要自救己身即可。』能做到守護內心而心意相稱者，便不犯戒。」

【1645-0002】03_業疏/06b_卷一之六#57
【原文】僧祗中初明訶欲若非下二示開制初中又三初明可遮有力謂具道德者前下二在眾不欲目對心乖名見不欲制不趣爾須擇同意詞須三說即對三人不至四者恐各成眾令僧破別如鈔引云當語傍人言此非法制止得三人是也此下疏家點示餘下三說欲起去彼律具云若作非法制應訶令止不者當說如法欲已捨去此但意乖望前為難故云餘者開制中初明違制不依上三通得吉羅若自下次明開法護他之心稱實言喻故曰相應。
【譯文】在《僧祇律》文的解釋中，起初說明抗議與欲，從「若非」以下第二是指示開許與制止。在最初部分中又分為三小段：首先說明可以阻攔，「有力」是指具備道德名望的人；從「前」字以下第二說明在僧眾中表達不欲，雙目相對而內心相乖違稱為「見不欲」，規定不可草率，必須揀選意見相同之人，言詞必須宣說三遍，即是對三個人說，不到第四人是因為唯恐各自成眾而導致僧團破裂別異，正如《事鈔》所引說應當告訴身旁的人說這是不合法，規定最多只能對三人說；「此」字以下是疏主所作的提點指示；從「餘」字以下第三說明陳說欲意後起身離去，該律典具體記載說若作非法規制應當抗議令其止息，不然就應當陳說如法欲意後捨離而去，這只是心意相違，相對於前面的難緣而言，所以稱為「其餘的人」；在開許與制止之中，起初說明違背規制，若不依照上述三種方式，全都招致突吉羅罪；從「若自」以下接著說明開許之法，護念他人的心與真實道理相稱合，所以說「相應」。

【1645-0003】03_業疏/06b_卷一之六#58
【原文】次就義張
【譯文】其次，依循義理展開鋪陳。

【1645-0004】03_業疏/06b_卷一之六#59
【原文】文云「攝非盡」者，以事則隨相不可窮本，義則依理從歸有途，故又述之，各其致也。云「單白非相義同過別」，「別」謂三十九相各不相有，「同」謂四緣成業不可相無也，下文可解
【譯文】疏文說「收攝過非窮盡」者，是因為就事相而言隨順行相無法窮究根本，就義理而言依照法理歸納則有途徑可循，所以再度敘述，各顯其旨趣。所謂「單白非相義同過別」，「別」是指三十九種行相各自互不包含，「同」是指人、法、處、事四緣成就羯磨業不可彼此或缺，下文即可明白。

【1645-0005】03_業疏/06b_卷一之六#60
【原文】義張總意中初科又二：初釋敘意，事局義通，躡前生後以彰立意；「云」下釋同別，「不可相有」隨法過別也，「不可相無」四緣義同也。指下文者，即餘單白、白二、白四並類此釋，故云可解
【譯文】在依義展開的總體意旨中，初科又分為兩部分：首先解釋敘述的意旨，事相狹隘而義理通達，承接前文引發後文以彰顯立說之意；「云」字以下解釋同與別，「不可相有」是指隨各法所生的過失各別，「不可相無」是指四緣成就羯磨的義理相同。指稱下文，是指其餘單白、白二、白四都比照此例來解釋，所以說可以理解。

【1645-0006】03_業疏/06b_卷一之六#61
【原文】今此七名交絡互現，界非不無，攝在事也。離合適時，不可交定也
【譯文】如今這七種名稱交錯互相顯現，結界的過非並非不存在，而是收攝在「事」之中。離析與合併應當順應時機，不可一概固定。

【1645-0007】03_業疏/06b_卷一之六#62
【原文】次科，前離為四成十四非，此合為三止有七非。前是義門總攝，此欲從文歷句，故云「離合適時」等，交即訓俱
【譯文】下一科中，前面拆開為四法而成十四非，這裡合併為三種而只有七非。前面是義理門徑的總體收攝，這裡是想要順著文句歷數句數，所以說「離合適時」等，「交」字訓詁為「俱」（一概俱全）。

【1645-0008】03_業疏/06b_卷一之六#63
【原文】一人非中，識、疑兩罪須懺露者，以律正約犯者不得聞故，此人亦望能所俱非，律云「不得為犯者說」故。界中有別者，即訶不成也。人非應法者，謂威儀乖越，不順教相故
【譯文】在「一人非」之中，自知與懷疑兩罪必須發露懺悔，是因為律典正是規定犯戒者不得聽聞宣說的緣故，這個人也是從能說者與所聽聞者雙方全屬違律來看，因為律典說「不得向犯戒者宣說」的緣故。「界中有別眾」，是指抗議不能成立。「人非應法」，是指威儀乖謬越軌，不隨順教典行相的緣故。

【1645-0009】03_業疏/06b_卷一之六#64
【原文】次釋非相。人非中初釋不懺露，約行明非，能所俱非，謂能說所聞二俱違律；「界」下次釋別眾、非法，約緣明非，別眾且據口別，餘二準知，非法略舉乖儀，通含足別
【譯文】其次解釋不如法之相狀。在「人非」當中，首先解釋不懺悔、發露，這是從行持上說明其不如法，能作與所作（受對）雙方皆有不如法，即能說者與所聞者兩者都違背了戒律；自「界」字以下，其次解釋「別眾」與「非法」，這是依據因緣環境來說明其非。「別眾」暫且依口頭異議（口別）而言，其餘兩種（身別、界別）依此類推可知；「非法」則是略微舉出違背儀軌的情形，通貫包含了足數與別眾等情況。

【1645-0010】03_業疏/06b_卷一之六#65
【原文】二法非中，「三人單白」者，非法和也；「倒錯不了」，此法非也；「有訶不止」，亦是法非，由不止故
【譯文】在第二「法非」當中，「三人作單白羯磨」這一句，屬於非法而和合（非法和）；「倒錯不了」，這是羯磨法本身不如法（法非）；「有訶不止（有人制止卻不停下來）」，也屬於法非，因為沒有停止下來的緣故。

【原文】法非三節，對文可解
【譯文】法非的三個小節，對照疏文即可明白。

【1645-0012】03_業疏/06b_卷一之六#67
【原文】三事非中，「時非正教」者，非布薩日，制唯在三，餘為非日也；「有緣須略」，略有少多，隨前緣緩急而合作法，並乖緣也；「眾具闕」者，籌、華、燈火不濟時也；「界非聖制」，無難別緣結小界也；既結說已，又不即解，皆非法也
【譯文】在第三「事非」當中，「時非正教（時間不合正確教制）」是指：並非布薩日，佛陀制定只在三種日子（十四日、十五日以及和合日），其餘皆非正日；「有緣須略（有事緣應當簡略）」，簡略有縮減多少的不同，應當隨順面前事緣的緩急而相應作法，此處卻都違背了事緣；「眾具闕（用具缺乏）」是指行籌、散花、燈火等無法周全及時；「界非聖制（界地不合聖教定制）」是指在沒有問難等特殊事緣的情況下結了小界；既然結界說戒完畢，又沒有立即解界，這些全都是不如法的。

【1645-0013】03_業疏/06b_卷一之六#68
【原文】事非中，四時、緣、具、界並事所收。「制唯在三」，黑白兩半各有三日。「有緣略」者，謂八難餘緣，緩則略少，急則略多，今無緣輙略，或雖有緣不隨緩急，故云「並乖」也
【譯文】在「事非」之中，時間、事緣、用具、結界這四項，都屬於「事」所涵攝。「制唯在三」是指黑月（下半月）與白月（上半月）兩半月各有三日（十四、十五以及和合日）。「有緣略」是指若遇到八難等其餘事緣，情勢緩和則略去得少，情勢急迫則略去得多；如今沒有事緣卻擅自簡略，或者雖有事緣卻不依緩急相應而行，所以說「都違背（並乖）」。

【1645-0014】03_業疏/06b_卷一之六#69
【原文】餘有四法，錯互上三，不可頓現，故張網目收羅盡也
【譯文】其餘還有四種句法，是由上述人、法、事三種互相交錯組合而成，無法一時頓現其相，所以羅列如同網孔般予以全數收納囊括。

【1645-0015】03_業疏/06b_卷一之六#70
【原文】次示雙具，雙有三句，具足一句，即用三單相合歷之，總為七句
【譯文】其次指示雙項兼具的情形：雙非有三句（人法俱非、人事俱非、法事俱非），全具（三俱非）有一句，再加上前面的三種單非互相歷經組合，總共為七句。
