# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】眾法中初示總數。「一」下顯通塞：初通論三法。今明事者，須分二途：一就通簡別，如一受戒四法各被；二攝別歸總，如受四緣通成一受，今文約此以分通塞，據本各被，約義明通。「統就眾緣」者，如欲行受地，或自然須先結界，和尚度人須乞畜眾，皆可攬歸受戒，以彰多法成一之義，自恣、捨墮、罰鉢、亡衣竝有斯義，臨文自舉。「白二」下別簡白二，七結不重是塞，餘竝法地為通，故云反上
【譯文】眾法之中起初列示總數。自「一」字以下顯明通塞：起初通論三種法。如今說明辦事，必須區分兩條途徑：一是就整體通相中簡別個別之法，如一場受戒中四種羯磨各自被及不同環節；二是攝受各別之法歸於總體，如受戒的四項法緣通力成就一場受戒，現在文中是依據後者來劃分通塞，按原本而言各有所被及，依義理而言則顯明其相通。「統就眾緣」的意思，例如若要在受戒處行法，若在自然界必須先結界，和尚度人必須乞求蓄眾，這些都可以收攝歸入受戒，用以彰顯多種法成就一事的意義，自恣、懺捨墮、罰乞鉢、分亡僧衣物都具有這種意義，臨到具體律文自會列舉。自「白二」以下特別甄別白二羯磨，七種結界法不可重結是閉塞不通，其餘都以作法界為通，所以說反照上述可知。

【429-0012】03_業疏/03a_卷一之三#4
【原文】初科判中，初敘意總標。準此羯磨，本唯一卷，今分為二，乃後開耳。「法下」就文別判：初敘序分。「由下次」敘正宗。「八篇下」三敘流通。略，即要也。二、三兩篇多是眾法，第四唯是別法，後五竝通眾別，故云「僧私兩成」。末篇首明六念入聚、師資住持等法，故云「靜念」等。毗，即訓助。未葉，即目後世。若據經宗三分判文：序及流通，結集所敘；中間正宗，是佛所說。今此十篇無非佛語，但取作法眾緣為羯磨之序，加法被事是羯磨正宗，修奉弘持為羯磨流通，故與經宗名同義異。又復序中須分證信、發起之別。今以集法廣列聖教，發生物信，故為證信序；次以緣成委示緣相，為法由致，故為發起序
【譯文】在最初科判之中，起初敘述意圖並總括標示。依照這部羯磨，本來只有一卷，現在分為兩卷，是後人展開劃分的。自「法」字以下就課文分別科判：首先敘述序分；自「由」字以下第二敘述正宗分；自「八篇」以下第三敘述流通分。「略」就是綱要的意思。第二篇、第三篇大多是眾法，第四篇唯獨是別法，後五篇都通於眾法與別法，所以說「僧私兩成」。最後一篇開頭闡明六念處、入聚落、師資住持等法，所以說「靜念」等。「毗」就是訓解為輔助。「末葉」就是指後世。若依據經典傳統的三分法科判文句：序分與流通分是結集者所敘述；中間正宗分則是佛所親說。如今這十篇全都是佛陀所言，只是取作法的各項助緣作為羯磨的序分，加持教法被及事相作為羯磨的正宗分，修行奉持弘布住持作為羯磨的流通分，所以與經典的三分名同而義異。再者，序分中必須分出「證信」與「發起」的差別。如今以〈集法〉廣泛列出聖教，啟發眾生敬信，所以是證信序；其次以〈緣成〉詳細開示緣起之相，作為教法的由來因致，所以是發起序。

【譯文】在解釋篇目之中，最初一科前面敘述所憂患的問題，又分為二：首先敘述法相混亂。眾法完全出自本宗律部，別法大多取材於其他部派律典，出處不是一處，所以說「文句分散」；自「至」字以下次敘述對法緣的暗昧；自「故」字以下後說明立篇的用意。法相混亂就必須集錄，法緣暗昧就必須明示，這就是先在前面開示綱領模範，隨後依此加法運用，也就是下述各篇的行事做法。「遲慮」就是疑惑的意思。

【429-0016】03_業疏/03a_卷一之三#8
【原文】注云「事法兼通大小齊降」者，欲明教下所被，無非成業為功，謂羯磨通也。雖隨緣優劣，皆有濟務，謂齊降也。依位數舉，謂綱領也。隨數顯相，各有通塞，若綱目之在綱，如裘毛之依領，故云「末振毛目」也。此明總集三法區分之意
【譯文】注中說「事與法兼通，大與小齊降」的意思，是想說明教法之下所被及的境界，無非是以成就羯磨業性為功效，這就是指羯磨通達；雖然隨著法緣而有優劣之分，但都能成濟事務，這就是所謂齊降；依照僧位與法的數量列舉，這就是所謂綱領；隨著數量顯現名相，各自具有通達與閉塞，如同漁網的目網繫於總綱，如同皮裘的毛依附於衣領，所以說「隨後振舉毛目」。這是說明總括集錄三種羯磨法並加以區分的用意。

【429-0017】03_業疏/03a_卷一之三#9
【原文】釋注中，初科為二：初釋文，「此下」示意。初中，事法即所被中自分三別：房衣等是事，說恣等為法，受懺等即人。今以句局，義必兼人，羯磨聖法通被此三，故曰兼通。大小，即三法下三品之事故，云優劣。文舉大小，亦合收中。降字訓等，謂成濟無殊；或可訓被，謂聖法不揀也。依位舉數，即三法總目，如綱領；隨數顯相，即八品別類，如毛目，對文可解
【譯文】在解釋注釋之中，最初一科分為二：起初解釋文句；自「此」字以下提示用意。在起初之中，「事法」即所被及的境界中自當分為三種：房舍衣服等是非情之「事」，說戒自恣等是教「法」，受戒懺罪等就是有情之「人」。現在因為文句字數受限，義理上必然兼含人，羯磨聖法普遍被及這三種，所以說「兼通」。「大小」就是指三法之下上品、下品等事，所以說有優劣之分。文中列舉大與小，自然也包含中品。「降」字訓解為齊等，是指成濟僧事並無差別；或者可以訓解為加被，是指聖法不加挑揀。依照僧位列舉數量，就是指三種羯磨的總名目，如同綱領；隨著數量顯明事相，就是指八種品類的個別分類，如同裘毛與網目，對照注文即可理解。

【429-0024】03_業疏/03a_卷一之三#16
【原文】有三羯磨攝一切者，隨相顯法，互周事境，不可收盡；以法從緣，不過三法，皆成業行，故以三教攝之，不隨事境定其數也。不同《十誦》恰列百一，終非通被，故此不論。若準此收，但據眾法；若人通於僧別，云三種、五種一切攝盡也
【譯文】所謂「有三種羯磨統攝一切」，是因為隨著事相顯發教法，交錯周遍於一切事境，無法全部收錄窮盡；若以法依從緣起來論，不過就是這三種羯磨法，都能成就律儀業行，所以用三種教法來統攝它，而不隨著外在事境去固定其數量。這不同於《十誦律》恰恰只列出一百零一種，終究不能周遍被及，所以這裡不採用其說。如果依照這種方式來收攝，只是依據眾僧之法；如果按僧人而通論眾法與別法，那麼說三種、五種僧人，就能將一切羯磨收攝窮盡了。

【429-0025】03_業疏/03a_卷一之三#17
【原文】釋注中三：初牒釋。隨相顯法，則數不可限，如上大數略舉而已；以法從緣，則總歸三法，故三羯磨攝盡一切。隨相從緣，竝目事境。互，即是徧。「不下」二、點異部，如前已示。「若下」三、顯通數。通僧別者，兼後對念，合僧為一，故總有三；開僧為五，僧別齊開，則為八、九
【譯文】在解釋注釋之中分為三點：首先標牒並解釋。隨著事相顯發教法，則數量不可限量，如上面大數只是略微列舉而已；以法依從緣起，則總體歸於三種羯磨法，所以三種羯磨能統攝窮盡一切。「隨相」與「從緣」，都是指稱事境。「互」就是周遍的意思。自「不」字以下第二點明其他部派之說，如前面已經指示。自「若」字以下第三顯明通攝之數。通論僧法與別法的，兼含後面的對首與心念，將僧法合為一種，所以總共有三種；若將僧法開展為五種，眾法與別法一同展開，就是八種或九種。
