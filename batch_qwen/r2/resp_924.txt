整體讀來通順，科判與名相大抵掌握得住，但有幾處**會誤導讀者的次第錯位與名相還原問題**，另有明顯的增譯過多。以下按「必改／建議／可商」分級列出。

---

## 一、必改（會造成誤解或義理偏差）

### ★1【0006】九義次第錯位——最嚴重的一處
記文「冷、池、纓、鏡、頭，此五從喻；夢、習、定、勢，此四從法」是**元照的分類歸納，不是鈔文的排列次第**。譯文照抄這個順序後，接著說「又第四項說明能生起禪定」「第一項闡明戒體，第二項是……第三項……」，讀者依前列表對號入座，會得到「第四＝明鏡、第二＝水池、第三＝瓔珞」，全盤錯亂，而且後面「池謂滅惑，纓謂德彰」變成重複解釋。

依文脈可反推鈔文次第應為：**冷、夢、習、定、鏡、頭、池、纓、勢**（故「第四」＝定；「餘六」＝冷夢習池纓勢；六中「初、二、三」＝冷、夢、習，剩下池、纓、勢才另行標名解釋）。

建議改譯並加注：
> 又（鈔文九義次第中的）第四「定」是明能生定，「鏡」「頭」二喻是明發慧，其餘六項當體即是戒。這六項中：初「冷」明戒體，二「夢」是持戒所感（臥安覺安、善夢），三「習」能牽引後行；「池」謂滅惑，「纓」謂德彰，「勢」謂功勝。
> 〔注〕本段「五喻四法」是記主的分類，與鈔文先後次序不同，故「第四」指「定」而非「鏡」。

### ★2【0006】「夢」譯成「夢想」、「定」譯成「定力」
九義是「尸羅言冷、言池、言纓、言鏡、言頭、言夢、言習、言定、言勢」的單字名目。「夢想」在現代漢語是「理想、願望」，與「持戒感得安眠善夢」完全無關；「定力」也把「（戒能生）定」窄化。建議還原為「夢（睡夢安善）」「定（能生禪定）」，「頭顱」亦宜改回「頭」（見下）。

### ★3【0009】十二入的開合講錯
> 譯：「若就十二入而言，意入心法是總相，其餘十一入色法是別相」

十二入中，**法入通心法（心所、不相應行、無為）與少分色（無表色）**，不能說「其餘十一入」都是色法。這是譯者自行補入的內容，且補錯了。
建議：「就十二入說，心法總攝為意入（故心總），色法則開為眼等五根、色等五境十入（故色別）。」

### ★4【0008】「賢善」是呼格，不是形容龍
> 原文：直彈指語言：賢善遠此處去
> 譯：「仁慈賢善的龍啊，請遠離此處！」

「賢善」是對對方的客氣稱呼（猶「賢者／大德」），並非說此龍仁慈賢善——上文才說牠「受性暴惡」，譯文自相矛盾。
建議：「賢者啊！離開這裡，到遠處去！」

### ★5【0009】「故如色也」譯為「所以比喻為色塵」
此句上承六塵、下啟「色陰等者，即餘四陰」，「色」應是**色陰**（以色陰代表三界苦果之相），不是六塵中的色塵；且「如」也不必是譬喻義。
建議保守處理：「苦是三界的果報之相，所以（論中）以『色』來表示。」並加「此『色』所指，或係色陰，待考」的注。

### ★6【0005】《毘婆沙論》逕定為《阿毘曇毘婆沙論》
南山鈔記中「毘婆沙」所指不一（《大毘婆沙論》《阿毘曇毘婆沙論》《薩婆多毘尼毘婆沙》皆有可能），尸羅九義與罽賓龍緣的出處需實查。譯文擅自定名風險高。
建議：保留「《毘婆沙論》」，加注「所指何本待考」。
（相對地，【0004】《解脫論》＝《解脫道論》卷二〈分別戒品〉是正確的。）

## 二、建議修正（不算錯，但語意不到位）

| 出處 | 譯文 | 問題與建議 |
|---|---|---|
| 0005 | 「所以反過來進行訓釋」 | 「故反釋之」語意未譯出。應作：「因梵語『尸羅』含多義，漢譯『戒』字攝不盡，所以（鈔文）反過來就梵語原詞加以解釋。」 |
| 0006 | 「每一種都應當貫穿『尸羅』這兩個字」 | 「貫之」是**冠於每項之上**，即「尸羅言冷」「尸羅言池」……宜明說。 |
| 0007 | 「旁人便無法破壞僧團的和合」 | 「若親在眾，破僧不成」是**提婆達多破僧**的典故，宜補注，否則讀者不知「旁人」為誰。 |
| 0006 / 0008 | 「頭顱」 | 「頭」指六根所聚之首，「頭顱」偏指骷髏，語感不祥且不準。改「頭（首）」；0008 可作「頭是六根聚集處，能同時領納六塵」。 |
| 0007 | 「鏡面明亮影子自然顯現」 | 「像現」是**影像**，非影子。 |
| 0004 | 「必須具足戒體且操行清淨」 | 「具戒」在律典慣指**已受具足戒**，非「具足戒體」。改「須已受具足戒且持戒清淨，方得預（參與）」。 |
| 0003 | 「顯然是指定學」 | 「顯是」＝「顯示這就是」，非推測語氣。 |
| 0003 | 「全都遠離邪妄而回歸純正，能通達涅槃彼岸，所以名為正道」 | 原文是**分別釋「正」與「道」**：「八者皆離邪，故名正；能通至涅槃，故名道。」譯文合併又加「回歸」「彼岸」，宜拆開。 |
| 0002 | 「對望於能摧壞有漏不善法的力量而言」 | 「望」即「就……而言」，不必疊「對望／力量」。改：「就其能摧破有漏不善法而言，故名力。」 |
| 0009 | 「現在這部書只列舉了最初與最後一項」 | 「今」指**鈔文**（道宣），與下文「今引足之」的「今」（元照）不同主語，宜分別標明「鈔文」「記主」。 |
| 0009 | 「『色陰』等項，是指受、想、行、識其餘四陰」 | 是「等」字攝餘四陰。改：「鈔文『色陰等』的『等』字，即指受、想、行、識四陰。」 |
| 0009 | 「總相是指心法與色法」 | 「總即心色」是說**總／別乃就心、色二法的開合而立**，非「總相＝心色」。 |
| 0005 | 「聖所憐愍」→「憐憫愛護」 | 佛教「憐愍」是慈念護念，無「可憐」義。改「為聖者所慈念護愛」。 |
| 0001 | 「規範人事的導師」 | 「軌物」＝為眾生作軌範，「人事」今義偏行政事務。改「能為眾生作軌範（導師）」。 |

## 三、增譯過多（體例問題）

譯文多處加入原文沒有的情態與細節，白話翻譯佛典注疏宜克制：

- 0007「多次**興風作浪**危害**人畜**」——原文僅「數為暴害」。
- 0008「那條龍立刻**乖乖**遠走」「諸位羅漢**驚訝地**詢問」「就像守護根本重戒一樣**毫無違犯**」「**最細微的**輕戒」——原文皆無。
- 0009「寂靜**至極**」「**殊勝**觸感」、0001「境界**層層拔高**」、0003「涅槃**彼岸**」——形容詞皆為添加。
- 0009「出離**無為**」：「無事」直譯即可（或注「無事＝無為、無所作」），不必改字。

另【0007】「『其餘』以下」把「餘下」當成鈔文引文加引號，恐非原文用詞；【0008】「鈔文中的『但以』以下」則合理（鈔確有「但以……」之文），兩者體例宜一致檢查。

## 四、可商／存疑（建議加注而非硬譯）

1. **【0005】「《毘婆沙論》，初中」**：「初中」可解為「初科之中」，亦可解為「初卷之中」（與上文「《解脫論》，第二〈分別戒品〉」的引書體例對照）。譯作「第一段裡」是選擇性判斷，宜存疑。
2. **【0005】「雖死不忘」**：或指「臨終正念不失」，或指「至死戒德不失」，譯文採後者並加「肉身」，可加注並列。
3. **【0005】「成伏解脫樂方便」**：斷句可作「成（就）調伏、解脫樂之方便」，譯文讀法可通，但宜注明異讀。
4. **【0005】「榮顯親友」**：可讀「令親友榮顯」或「為親友所榮顯」，譯文取前者，可注。

## 五、可補的注解（幫助讀者）

- 四念處下宜補「四顛倒」：於不淨執淨、於苦執樂、於無常執常、於無我執我。
- 七覺分「除」＝猗／輕安；四如意足之「欲、精進、心、思惟」體性是四種定；「無學」＝阿羅漢果。
- 0004「《遺教》喻堤塘」可引經文：「譬如惜水之家，善治堤塘；行者亦爾，為智慧水故，善修禪定，令不漏失。」譯文「防護水流的堤防」不如「防止（智慧）水漏失的堤塘」貼切。
- 0006「破戒熱／三惡熱」是解釋「冷」義，譯文未點明，讀者易斷開。

### 一句話總結
最要緊的是 **【0006】九義次第（第四＝定、初二三＝冷夢習）必須還原並加注**、**【0009】十二入「十一入皆色」的錯誤**、**【0008】「賢善」呼格誤讀**，以及 **「夢想／定力／頭顱」等名目還原**；其餘多為增譯與措辭問題，收斂形容詞、把「今」「文中」等指代對象標清楚，品質就會整齊很多。
