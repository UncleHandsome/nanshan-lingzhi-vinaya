整體看下來，譯文流暢、術語掌握大致到位（道共戒／事戒、七支、勝義律儀等都對），主要問題集中在**幾處義理偏差**、**前後譯名不一致**與**標點體例**。以下按輕重分列。

---

## 一、義理需要修正的地方

**1. 【466-0004】「道戒」譯為「與聖道相應的**心體**之戒」——與記文相違**
記文明說「道戒即道俱七支」，即與無漏聖道俱起的**身口七支**（八正道的正語、正業、正命），不是「心體」。此處譯「心體之戒」既無據，又與 #89 的譯文自相矛盾。
建議：「與聖道俱起的（身口七支）道共戒名為『解脫』」。

**2. 【466-0008】「望分所除」譯為「分分除滅」——誤解「分」字**
此段結構是：戒只除「業非」**這一分**，惑須待智方亡；故就「所除僅是一分」而名別脫，智斷惑究竟方名解脫。「分分除滅」帶有「逐步分斷」的意思（那是斷惑的分位義），與此文「只除一部分」的對比不合。
建議：「就戒所除的只是其中一分（業非）而言，所以稱為『別脫』」。

**3. 【466-0007】「故通指之」譯為「總括指歸」——語意失落**「通指」是說疏文只泛稱「論」，因諸論皆同，故**不別指某一部論**（正釋疏文「如論所引」四字）。
建議：「諸論都是這樣說，所以（疏中）通泛地指稱諸論，而不別指某一部」。

**4. 【466-0007】「持此非彼」只譯一半**
譯文「持此戒即遣除與之相應的那一分過非」只講了「持此」，未譯出「非彼」——即**不能兼遣餘境之非**，這才與道戒「類遣（通遣）」構成相反。
建議：「持此戒只能止此境之非，不能兼遣彼境之非，與道戒的『類遣』相反」。

**5. 【466-0006】「餘非未行，不名解脫」譯文含混**
「未曾針對行持的惡行」很容易被讀成「還沒去做的惡行」。原文「行」指**持戒之行**，「非」指過非：其餘過非因尚未持行對治，故不名解脫。
建議：「至於其餘尚未持戒對治的過非，就不名為解脫」。

**6. 【466-0005】「舉法類遣」譯作「通遣一切煩惱」——對象偏了**
記文解釋得很清楚：理觀破惑、業根既除，「豈容**身口更有非、惡**」，故「類遣」所遣的是身口過非（業非），不是直接遣煩惱。且此處把原詞整個化掉，讀者到 #89 看到「故云『舉法類遣』」時無從對應。
建議保留原詞＋註解：「舉起觀智之法即能通遣（身口）一切非惡，故云『舉法類遣』」。

**7. 【466-0005】「空道聖性」為生造語**
原文「道性虛通」，記曰「道即空理，故言虛通」。
建議：「因為道體即是空理，虛融無礙通達」。

## 二、用詞與精確度

| 出處 | 譯文 | 問題／建議 |
|---|---|---|
| 0001 | 「如今我們所學的是善戒」 | 「今是善戒」指**此中所明之戒**屬善戒，非「我們所學」；宜作「今所明者是善戒」 |
| 0001 | 「比以往的定義更為親切切題」 | 「彌親」的比較對象是上文的「**警**」義，不是「以往」；宜明說「較『警』義更為貼切」 |
| 0001 | 「顯發本疏如今確立的正解」 | 「今」＝今家／疏主，「如今」易誤讀為時間副詞 |
| 0001 | 「兩者的功用義理相同」 | 「初引示義同」的「義同」所指（善惡名義同？抑所引與前釋同？）須對照前面疏文才能定，建議回頭核對，勿臆加「功用」二字 |
| 0003 | 「或者有人翻譯為」 | 「有云…或云…」＝「有人說…也有人說…」，「或者＋有人」贅 |
| 0004/0008 | 「別解脫」 | 疏文刻意省稱「**別脫**」以與「解脫」對舉，建議照錄「別脫」，必要時括注 |
| 0005 | 「隨著所證得的部分果位」 | 漏了「得戒」義；宜「隨所證果位之分**而得此戒**，故寄託果位以明之」 |
| 0006 | 「境緣通於世間萬物」 | 「萬境」含情與非情一切所緣境，「世間萬物」偏窄；宜「通於一切境界」 |
| 0006 | 「戰勝了該項犯戒之境」 | 「陵犯」是陵勝**毀犯之非**（記：對治勝也），不是「境」 |
| 0007 | 「初果以上的聖位」 | 「初果以去」含初果，宜作「初果乃至四果」以免歧義 |
| 0007 | 「證得真如之理」 | 記文系統用「空理」，此處「真如」帶大乘唯識色彩，宜統一作「證得真理（空理）」 |
| 0007 | 「『類』含有通同遣除的意思」 | 「類猶通也」是直訓：「『類』猶如『通』」，「遣除」是後文義，不宜混入訓詁 |
| 0007 | 「依從外在緣境所受持的條戒」 | 「條戒」不詞，宜「從受戒因緣所領受的戒」 |
| 0007 | 「才是第一義諦中的真實僧寶」 | 「即」＝「就是」，「才是」多了排他語氣 |
| 0008 | 「外在的業行過失／內在的煩惱迷惑」 | 「內外」是增譯；可作「身口業非／內心煩惑」較貼律家語脈 |

## 三、體例問題

1. **引號與句號位置不一致**：多處作「虛通。」／「舉法類遣。」／「勝義律儀。」——引述的是詞語而非整句，中文體例應作「虛通」。／「舉法類遣」。／「勝義律儀」。
2. **道戒／事戒的釋名前後四處不同**（心體之戒／戒條／身口七支淨戒／條戒），建議統一為「道共戒（與聖道俱起的身口七支）」「事戒（從緣受得之戒）」，首次出現處給定義，後文沿用。
3. 「有力的明證」（0001）、「洗滌清淨」（0008）等形容性增譯，若無特殊需要可略為收斂。

## 四、修訂示例（可直接替換）

**【466-0004】** 如諸論所引述的：與聖道俱起的道共戒名為「解脫」，從緣受得的事戒名為「別脫」。

**【466-0005】** 這是隨所證果位之分而得此戒，故寄託果位來說明它。因為道體即是空理，虛融通達，舉起觀智之法便能通遣一切非惡（「舉法類遣」），不隨境緣而各別，所以只名為「解脫」。

**【466-0006】** 事戒則不然，是隨各別境緣而生起的。所緣通於一切境界，戒行也隨之周遍；持戒之行陵勝毀犯，才名為得解脫。其餘尚未持行對治的過非，就不名為解脫。

**【466-0008】** ……就戒所除的只是其中一分（業非）而言，所以稱為「別脫」；其後以智慧斷除煩惑，才稱究竟，名為「解脫」。
