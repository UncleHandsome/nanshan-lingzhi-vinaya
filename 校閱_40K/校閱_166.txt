# 校閱材料　第166檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【166-0001】02_戒疏/15c_卷三下之三#14
【原文】【記】問答中，初問。答云「如此亦遮」，謂先有妨難，亦處分不成。
【譯文】【記文】在問答之中，這是初次發問。回答說「在這種情況下也是禁止的」，意思是說如果預先就存在妨害與患難，處分羯磨也是不能成立的。

【166-0002】02_戒疏/15c_卷三下之三#15
【原文】【疏】「若爾，何故文云『僧處分有妨難，一殘二吉』者？」
【譯文】【疏文】又問：「如果這樣，為什麼律文中說『（比丘造房）經僧處分，若有妨難（且過量），犯一個僧殘罪與二個突吉羅罪』呢？」

【166-0003】02_戒疏/15c_卷三下之三#16
【原文】【疏】答：「此是處分先成，妨難後起。」
【譯文】【疏文】回答：「這是指處分作法已經先行成立，妨難是在作法之後才產生的。」

【166-0004】02_戒疏/15c_卷三下之三#17
【原文】【記】轉難中。若如上釋，則違《律》文。「一殘」即過量罪，「二吉」即妨難罪。答中，謂先處分已，妨難始生，非先有也。
【譯文】【記文】這是進一步的問難。如果照上面的解釋，就會違背《四分律》的原文。「一個殘罪」就是指超過限量的僧殘罪，「二個吉羅罪」就是處所有妨礙、有禍難（在有妨處、有難處作房）的突吉羅罪。回答的意思是：先前的處分已經作法成立，妨難隨後才發生，而不是事前就存在的。

【166-0005】02_戒疏/15c_卷三下之三#18
【原文】【疏】「若爾，口法簡境，非淨不合，過量三衣，亦不成受？」
【譯文】【疏文】又問：「如果這樣，口受作法需要揀別對象境緣，不清淨就不合律法，那麼超過尺寸限量的三衣，難道也不能成立受持作法嗎？」

【166-0006】02_戒疏/15c_卷三下之三#19
【原文】【疏】答：「衣制故開，藥是聽也。」
【譯文】【疏文】回答：「三衣是佛陀制定必須受持之物，所以開許作法；藥物則是佛陀隨病聽許服用的，情況不同。」

【166-0007】02_戒疏/15c_卷三下之三#20
【原文】【記】次三衣問中。以過量衣得加受法，故舉例難。答中，衣制須開，藥聽必制，二教互立，其致在茲。
【譯文】【記文】這是接著以三衣為例的提問。因為超過尺寸限量的衣服仍舊可以加行受持作法，所以提出來作為難例。回答中說明，三衣是佛制僧人必須具備而開許受持，藥物則是隨病聽許而設有嚴格限制，這兩套教法各自成立，其根本道理就在這裡。

【166-0008】02_戒疏/15c_卷三下之三#21
【原文】【疏】「若爾，白衣亦制，加法應成？」
【譯文】【疏文】又問：「如果這樣，白色三衣也同樣屬於佛制之衣，對它加行受法理應成立（何以加不成受）？」

【166-0009】02_戒疏/15c_卷三下之三#22
【原文】【疏】答：「體相同俗，故非道服。」
【譯文】【疏文】回答：「白衣的形體外相如同世俗凡夫，所以根本不是修道者的法服。」

【166-0010】02_戒疏/15c_卷三下之三#23
【原文】【記】初難中。以白色三衣加不成故。答文，可解。
【譯文】【記文】在初次追問中，是以白色三衣作法不能成立來質疑。回答的文義，非常容易理解。

【166-0011】02_戒疏/15c_卷三下之三#24
【原文】【疏】「若爾，過量非法，亦乖道服，不在加受？」
【譯文】【疏文】又問：「如果這樣，超過限量是不如法的，同樣也違背了修道者的法服規格，難道不應當屬於不能加法受持的範疇嗎？」

【166-0012】02_戒疏/15c_卷三下之三#25
【原文】【疏】答：「過量得者，白色殊乖。」
【譯文】【疏文】回答：「尺寸過量的衣服尚且可以穿著（僅犯突吉羅輕罪），而白色衣物則完全違背了出家僧相（全不許穿）。」

【166-0013】02_戒疏/15c_卷三下之三#26
【原文】【記】次難。以色、量俱非而成不成別。「在」，猶當也。答中，「者」字誤，古本作「吉」，謂過量得著，但犯吉罪。白色外彰，全不許服，故曰「殊乖」。
【譯文】【記文】這是接著問難。提問者認為顏色與尺寸既然都違法，為何加法成立與否卻有差別。「在」字，相當於「當」的意思。回答之中，「者」字是訛誤，古本寫作「吉」，意思是過量的衣服雖然可以穿著，但會犯突吉羅罪。而白色衣服外相顯著，完全不允許僧人穿著，所以說「完全違背僧相」。

【166-0014】02_戒疏/15c_卷三下之三#27
【原文】【疏】六、長短者。手受約時，故名為「短」。口法加延，各有其遠，號之為「長」。
【譯文】【疏文】第六、論述有效期限的長短。手受的時效是依據當時的時間而定，所以稱為「短」。口法作法能延長時限，且每一種藥物各有其長遠的期限，所以稱之為「長」。

【166-0015】02_戒疏/15c_卷三下之三#28
【原文】【記】六中。「手受約時」，謂止齊時中。「各有遠」者，三藥期限，各不同故。
【譯文】【記文】在第六門中。「手受依據當時的時間」，是指僅止於當時的時段之內。「各有其長遠期限」，是因為非時、七日、盡形壽這三種藥的有效期限各自不同。

【166-0016】02_戒疏/15c_卷三下之三#29
【原文】【疏】七、強弱不同。若不手受，口法不成，故手強也。又若無口法加延，手受隨失，故口強也。互說不定義也。
【譯文】【疏文】第七、論述力量強弱的差別。如果不先經過手受，口法就不能成立，因此手受的力量強。另外，如果沒有口法來加持延長，手受的效力隨時就會喪失，因此口法的力量強。這是彼此相對而說、強弱互無定論的道理。

【166-0017】02_戒疏/15c_卷三下之三#30
【原文】【記】七中。若望相假，口必假手，「故手強」。若望相延，口必延手，「故口強」。各據一義，故「互不定」。
【譯文】【記文】在第七門中。如果從彼此依託的層面來看，口法必須依託手受才能成立，「所以手受力強」。如果從延長時限的層面來看，口法必然能延長手受的效力，「所以口法力強」。兩者各依據一種道理來論述，所以說「互相依論而無定論」。

【166-0018】02_戒疏/15c_卷三下之三#31
【原文】【疏】八、手口二受望餘比丘辨通塞者。
【譯文】【疏文】第八、論述手受與口受兩種受法相對於其他比丘，來辨別能否互通共享或阻絕。

【166-0019】02_戒疏/15c_卷三下之三#32
【原文】【疏】有人解云：「手受防盜，一人受竟，通諸比丘。口法不爾，自稱名加，若捨與人，彼則無法，故不合食。」
【譯文】【疏文】有人解釋說：「手受是為了防範盜竊，只要有一人手受完畢，就通於所有比丘共享。口法不是這樣，口法是自己稱念自己的名字來加持，如果把藥捨給別人，對方身上並沒有受法，所以不合適食用。」

【166-0020】02_戒疏/15c_卷三下之三#33
【原文】【記】八、他解中。初科立理，稱名有無，故分通局。
【譯文】【記文】在第八門引述他人見解中。第一小科建立其理論，認為有無自稱名字，是區分能夠通融他人或局限自己的關鍵。

【166-0021】02_戒疏/15c_卷三下之三#34
【原文】【疏】「若爾，作餘法竟，何通餘僧？」
【譯文】【疏文】又問：「如果這樣，行作其餘殘食法完畢後，為什麼可以通於其餘僧人食用呢？」

【166-0022】02_戒疏/15c_卷三下之三#35
【原文】【疏】答：「彼但作法，不自稱名，成殘便止，如病人殘，故是通也。藥法不爾，自題名加，不得例也。」
【譯文】【疏文】回答：「那是因為殘食法只是就事作法，並不自稱個人姓名，法事一旦成立殘食就完成了，就像病人的殘食一樣，所以能互通共享。藥物作法不是這樣，必須題稱自己的名字來加持，不能拿來相提並論。」

【166-0023】02_戒疏/15c_卷三下之三#36
【原文】【記】次釋難中。以餘食法，一人作已，得通多人，違上義故。答中。「不稱名」者，餘食法但云「大德我足食已，知是看是」。又《律》云：「病人殘，不作法，一切得食。」不同「藥法」，牒名稱病，專屬己故。
【譯文】【記文】在接著解答問難中。因為殘食法只要一人作法完畢，就可以通給許多人食用，這與上面的論點相違背，所以提出問難。回答之中：「不稱名」，是指殘食法的詞句只說「大德，我已經吃飽了，請知悉並察看此食」。另外律文說：「病人的殘食，不必另外作法，所有人都能食用。」這不同於「藥物作法」，藥法必須指稱自己的名字、陳述自己的疾病，專門屬於個人所有。

【166-0024】02_戒疏/15c_卷三下之三#37
【原文】【疏】又解：「藥味是通，口法亦通。以其口法加二通藥，舍與前人，不失口法。故《律》文：『藥至七日，與諸比丘。』若不合者，佛不應勸。《僧祇律》中亦同其意，不復繁引。」
【譯文】【疏文】另外一種解釋說：「藥物的性味本來就是互通的，口法也是互通的。以其口法加持兩種皆通的藥物，捨給對方時，並不會失卻口法的效力。所以律文說：『藥物到了第七天，應當給予其餘比丘。』如果不合律法，佛陀就不應該勸勉比丘這麼做。《僧祇律》中也是相同的意旨，不再繁瑣引述。」

【166-0025】02_戒疏/15c_卷三下之三#38
