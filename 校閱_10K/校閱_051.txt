# 校閱材料　第051檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【051-0001】01_行事鈔/03b_卷上之三#33
【原文】二明訶責法。凡欲責他，先自量己內心喜怒。若有嫌恨，但自抑忍；火從內發，先自焚身。若懷慈濟，又量過輕重，又依訶辭進退；前出其過，使知非法；依過順訶，心伏從順。若過淺重訶，罪深輕責；或隨憤怒，任縱醜辭；此乃隨心處斷，未準聖旨；本非相利，師訓不成。宜停俗鄙懷，依出道清過；內懷慈育，外現威嚴；苦言切勒，令其改革。依律五法次罪責之。《四分》云：弟子不承事和尚，佛令五事訶責：一我今訶責汝，汝去。二莫入我房。三莫為我作使。四莫至我所。五不與汝語。自三世佛教，每諸治罰，但有折伏訶責，本無杖打人法。比見大德眾主，內無道分可承；不思無德攝他，專行考楚。或對大眾，或復房中；縛束懸首，非分治打。便引《涅槃》三子之喻。此未達聖教然。彼經由住一子地悲，故心無差降，得行此罰。即《涅槃》云：勿殺勿行杖等。此言何指，不知通解，輒妄引文。縱引嚴師，此乃引喻，不關正文。如《攝論》言：菩薩得淨心地，得無分別智，方便具行殺生等十事，無染濁過失等。今時杖治弟子者，咸起瞋毒，勇憤奮發，自重輕他，故加彼苦；若準《涅槃》恕己為喻，則針刺不能忍之。又有愚師，引《淨度經》三百福罰。此乃偽經人造，智者共非。縱如彼經，不起三毒者，得依而福罰；今順己煩惱，何得妄依？《律》中瞋心訶責，尚自犯罪；乃至畜生不得杖擬，何況杖人？《地持論》中：上犯罰黜，中犯折伏，下犯訶責。亦無杖治。《大集》云：若打罵破戒、無戒袈裟著身剃頭者，罪同出萬億佛身血。若作四重，不聽在寺，不同僧事；若謫罰者，於道退落，必入阿鼻。何以故？此人必速入涅槃，故不應打罵。準此以明，則自知位地；生報冥然，濫自欺枉，可悲之深。廣如彼經。《僧祇》：若師訶責，弟子不受者，當語知事人斷食。若凶惡者，師自遠去。若依止弟子，師應出界一宿還。若弟子有過，和尚為弟子懺謝諸人云：「乃至凡夫愚癡，何能無過？此小兒晚學，實有此罪，當教勅不作。」如是悅眾意。
【譯文】第二、明示訶責之法。凡是想要斥責開導他人，首先應當反躬審視自己內心是否有歡喜或憤怒等情緒。若心存嫌怨惱恨，寧當自我克制忍耐；瞋火若從內心燃發，必將先燒毀自身功德。若是純懷慈悲救濟之心，便當仔細衡量弟子過錯之輕重，並依照合律的斥責辭令進退處置；先明確點出其過咎所在，使其明瞭所為皆屬非法；然後依循過失情節給予合度的訶責，弟子自能心悅誠服、順從悔改。如果過失輕微而施以嚴厲重訶，罪責深重卻予以輕描淡寫之責；或者隨任胸中憤怒爆發，肆無忌憚口出污穢醜惡言辭；這純粹是任憑個人情緒主觀裁斷，完全違背佛陀制戒的聖意；本來就不是為了互利道業，師父的訓育教導自然歸於失敗。應當摒除世俗鄙劣的情懷，依照出家解脫之道指陳罪過；內心懷抱慈憫撫育之德，外表展現肅穆端嚴之威；以苦口良藥切實規勉勒誡，使其洗心革面徹底改過。應當依循律藏所定五種漸進之法依次責罰。《四分律》說：弟子若不肯如法承事和尚，佛陀命令以五件事依次予以訶責：一、「我如今訶責於你，你離去吧！」二、「不要進入我的房間！」三、「不要替我辦理使令差役！」四、「不要前來我的處所！」五、「不再與你交談說話！」自過去、現在、未來三世諸佛的教法以來，每當實施懲處法度時，律中只有降伏慢心與嚴詞訶責之法，根本沒有用杖木打人的肉刑之法。近來屢見一些所謂的大德僧首、寺院大眾綱領，內在毫無道學證量足以令人秉承；不想想自己缺乏德行以攝受感化他人，卻專橫施行考打拷楚之虐。或者當著大眾僧之面，或者關在隱蔽密室房中；將弟子綑綁拘束懸掛頭頸，進行非分的殘酷拷打。隨後便曲解引用《大般涅槃經》（《涅槃》）中「嚴師教治三子」之比喻為藉口。這真是完全不通達如來聖教才會如此妄為！彼經中所說，是因為聖者安住於視一切眾生如親生獨子之平等「一子地」大悲心，其內心毫無親疏偏倚的差降，方能施行這類看似嚴厲的折伏法；即《涅槃經》中明明告誡：「切勿殺戮，切勿動用杖楚打擊」等等。經文這些話是指何境界，不求貫通理解，便輒然妄加斷章取義引為打人的依據。縱使引用經論中的嚴師之說，那也不過是以世俗譬喻作引導，與正法律典根本無涉。正如《攝論》（《攝大乘論》）所說：法身大士菩薩證得清淨心地、證得無分別智，為了慈悲度生的殊勝方便，方能具足行殺生等十種看似違背常道之事而毫無染濁過咎。如今凡夫以木杖鞭笞懲治弟子者，無一不是內心狂起瞋恚惡毒、瞋怒憤激勃發，自尊自大而輕賤他人，因而加諸肉體痛苦於弟子身上；若能依照《涅槃經》所言「將心比心寬恕自律」來推想，自己連一根針扎刺尚且疼痛難忍，又何忍杖打弟子！更有愚頑盲目的師長，引用《淨度經》中的「三百福罰」為據。然而《淨度經》乃是後人偽造的偽經，歷來有智之士皆共同痛斥排斥。縱然退一步依那部偽經所言，也必須是完全不起貪瞋癡三毒煩惱的人，才得以依憑施行福罰；如今分明是順著一己的瞋恨煩惱去洩憤，哪裡能夠妄加依用？在正統律藏之中，若以瞋恚嫉恨之心斥責他人，尚且構成立即犯戒之罪；甚至連畜生動物都不允許用杖棍去比畫作勢威嚇，更何況是用杖打人？《地持論》（《菩薩地持經》）中規定：弟子若犯上等重過則予以懲罰擯黜，犯中等過失則予以折伏屈服，犯下等過失則予以言辭訶責；其中也絕無動用木杖拷打之法。《大集經》（《大方等大集經》）說：如果動手毆打或開口痛罵破犯戒律、或者身無戒體但身披袈裟剃除鬚髮的出家僧人，其所造罪業等同於令萬億尊佛出其身血。出家人縱然造作了四波羅夷重罪，固然不許其繼續留住寺院、不許其同參僧團法事；但若是謫罰他的人，自身將於佛道退轉墮落，命終必入阿鼻地獄。為什麼呢？因為出家剃染之人哪怕犯重罪，也必定會因披袈裟之因緣而於未來迅速得入涅槃，所以絕不應動手打罵。依據這些經文來審視印證，為師者應當清楚明了自己的果位境界安在；來世惡報幽冥深切，濫行非刑自欺欺人，其盲昧可悲至極！詳細情由廣如彼經所載。《僧祇律》說：師父若如法訶責，而弟子頑抗拒不領受者，應當通告寺中知事僧停止供應其飯食。若是弟子性格極度凶暴惡劣，師父應當自行抽身遠離其處。若是依止弟子不受規勸，依止師應當攜帶衣鉢走出結界過宿一晚然後再返回。若是弟子在外犯了過失，和尚應當親自出面代為向大眾僧懺悔謝罪說：「凡夫愚癡迷昧，誰人能全無過失？這名初入佛門的小兒晚輩，確實犯下了這等罪咎，我自當嚴加教誡勒令其永不再作。」應當以這種謙柔辭謝之語來平息大眾的憤懣，使眾人心意歡悅。

【051-0002】01_行事鈔/03b_卷上之三#34
【原文】三明訶責非法。《四分》云：盡形訶責，竟安居訶責，訶責病人，或不喚來現前，不出其過而訶責等，並成非法。若被治，未相懺謝而受供給依止等；或被餘輕訶，而不為和尚、闍梨及餘比丘等執事勞役者；得罪。《僧祇》：若與共行弟子、依止弟子衣已，不可教誡，為折伏故奪；後折伏已，還與無罪。若與衣時言：汝此處住，若適我意，為受經者，與汝；後不順上意，奪者無犯。《十誦》若欲折伏，剝衣裸形可羞。佛言：不應小事折伏沙彌，若折伏留一衣。
【譯文】第三、明示非法訶責。《四分律》說：終身訶責、整期安居訶責、訶責患病之人，或者不召喚到面前來、不指出其過失而予以訶責等，全都構成非法。若是受處分之人，尚未互相懺謝，就接受師長供給的衣食、或去依止其他師長等；或者弟子受到其他輕微訶責，就不肯替和尚、阿闍梨及其他比丘等操持事務勞役者，犯突吉羅罪。《僧祇律》說：如果給予共行弟子、依止弟子僧衣之後，弟子不服教誡，為了折伏他的緣故而奪回僧衣；日後弟子已被折伏，再歸還給他，無罪。如果在給衣時約定說：你在這裡住，若是合我心意、能為我受持經教者，就給你；日後弟子不順從師意，奪回僧衣者不犯戒。《十誦律》說：若有人想要折伏弟子，剝除其衣服致使赤身裸體而招致羞恥；佛說：不應當因小事折伏沙彌，若要折伏應當留下一件衣服（不可全剝使其裸形）。
