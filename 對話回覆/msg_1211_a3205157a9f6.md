對，理論上翻譯材料裡本來就應該是分開的。

現在會合併，是因為我重建 pair 時只做：

```text
同一個單元裡所有【疏】的原文 → 串成一個 .o
同一個單元裡所有【疏】的白話 → 串成一個 .t
```

我把段落邊界洗掉了。

以 D003 為例，現在是：

```text
【疏文】初、教興者。斯乃大聖降臨……
白話：第一，教法興起的原由。這是由於大聖佛陀降臨……
```

但其實白話有兩句：

```text
第一，教法興起的原由。
這是由於大聖佛陀降臨……
```

所以它本來可以切成：

```text
【疏文】初、教興者。
【疏文】第一，教法興起的原由。

【疏文】斯乃大聖降臨……
【疏文】這是由於大聖佛陀降臨……
```

不是翻譯沒分段，是我把它們接起來了。

所以 46 段拆分材料裡，AI 要做的不是重譯，是：

1. 依校正後原文的 `【疏】` 切成 N 段
2. 把現有白話依句義切成同樣 N 段
3. 不改字、不重譯

如果白話真的無法切，才需要重譯該段。
