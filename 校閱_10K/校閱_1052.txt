# 校閱材料　第1052檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1052-0001】資持記/05e_上四#1
【原文】非人不顯，故須之也。律下，明次五德，初列五相。一一相中，是非相對。言知時者，與上何異；上是時節，此即時宜；謂量僧和諍，可舉即舉；疏云：舉過靜諍，無不和順是也。意下，隨釋。初句釋初德，次句釋第二德；欲下三句，釋第三德；故下二句，釋第四德；愍下二句，釋第五德。
【譯文】若非合適之人就無法彰顯其德，所以必須差選。律文接著說明第二種五德，首先列出五種相狀。每一種相狀中，都是正確與錯誤相互對照。說到「知時」，這與上面所說有何不同？上面是指整體的時節，這裡是指當下的時宜；也就是審度僧眾是否和睦或有爭執，可以檢舉時才檢舉；戒疏說：檢舉過失以平息爭端，無不和合順適，就是這個意思。「意」字以下，隨文解釋。第一句解釋第一德，第二句解釋第二德；「欲」字以下三句，解釋第三德；「故」字以下二句，解釋第四德；「愍」字以下二句，解釋第五德。

【1052-0002】資持記/05e_上四#2
【原文】五中，上二是智，能觀量故；次二是悲，皆拔苦故；後一是慈，以與樂故。又第四是口，餘四並心。此謂各人自具二種五德。〔有人行事，差一人為自恣五德，一人為舉罪五德，謬矣。〕問：既具二五，何以不名十德耶？答：罪事別故，通局異故。若爾，今云五德，從何得名？
【譯文】這五德之中，前二種屬於智慧，因為能觀察審量的緣故；中間二種屬於悲心，因為都是為了拔除痛苦的緣故；最後一種屬於慈心，因為能給予安樂的緣故。另外，第四德屬於口業，其餘四德都屬於心意。這是指每個人自身都具備這兩種五德。〔有人在辦事時，差派一人作為自恣五德，差派另一人作為舉罪五德，這是完全錯誤的。〕問：既然具備了兩種五德，為什麼不稱為十德呢？答：因為所涉及的過罪與事由各自不同，通達與局限的範圍也有差異。如果是這樣，現在所說的五德，是依據什麼來命名的？

【1052-0003】資持記/05e_上四#3
【原文】答：用分通局，義有兼正；約事就局，從正為名。次科，初徵。二釋，為三，初點本宗。但令差人，及羯磨中，唯牒一名，故云不了。次示三律並差二人。注釋多人，謂二對三對；作法差已，隨對起復，互相替換；始終二人，非謂齊作。後引三千，正明所以。僧自恣竟者，即同《十誦》，下不用之。
【譯文】答：作用上有通有局，義理上亦有兼帶與正主之分；就具體事相與局限範圍而言，是依據正主的一方來命名的。下一科判，首先徵問。第二段解釋，分為三部分，第一先點出本宗法義。本宗只規定差派人選，而且在羯磨法中，僅僅宣讀一個名字，所以說是不夠明瞭。接著指出有三部律典都規定差派二人。注文解釋「多人」，是指兩對或三對；作羯磨法差派完畢後，隨著各對輪流起立與復座，互相替換；始終維持二人，並不是指全體同時進行。最後引用《三千威儀經》，正是為了說明其中的緣由。至於經中所說「僧眾自恣完畢」，情況與《十誦律》相同，此處暫不採用。

【1052-0004】資持記/05e_上四#4
【原文】此中但取差二之意。三中，初斥專執。謂逐人差也，以見本宗差法，單牒名故。未通諸部者，即上所引也。又下，次斥輕易。今時皆爾。況復庸愚，空無一行，妄充僧命，輒號五德。名存實喪，豈不悲乎！十下，引證。下座來向者，臘高德重，不可勞動故。差法中，初科，前明簡德。
【譯文】這裡只是擷取差派二人的用意。第三部分中，首先斥責執泥不化之人。也就是依著每個人單獨差派，因為見到本宗的差派法中，只宣讀單一名稱的緣故。所謂未通達諸部律典，就是指上面所引用的內容。「又」字以下，接著斥責輕忽隨便的態度。當今之人大多如此。更何況那些庸碌愚昧、毫無絲毫戒行之人，妄自承攬僧團的差命，動輒自稱五德。空有名號而德行喪失，這難道不令人悲嘆嗎！「十」字以下，引律文作證。下座比丘前來趨向，是因為上座戒臘高、德行重，不可使他勞頓奔波的緣故。在差派僧人的羯磨法中，第一科，先說明揀選德行。

【1052-0005】資持記/05e_上四#5
【原文】文令上座差選，或堪能羯磨者，隨作亦得。不下，定處。由世濫行，故須指破。次科中，初明索欲。餘諸羯磨，通傳欲淨；獨此有異，故須別出。此下，示部別。《僧祇》等律，並不開故。問和中。且約通答，後顯別答。指如上者，即〈羯磨篇〉。五德行事，和僧中，初文，前示威儀。今時多在僧前，禮已和白。
【譯文】律文規定由上座比丘差派挑選，或者由具有羯磨能力的人，隨宜主持作法也可以。「不」字以下，限定處所。由於世人普遍浮濫行事，所以必須明確指出糾正。下一科中，首先說明徵索欲事。其他各種羯磨法，通例都可以代傳欲法與清淨；唯獨自恣法有所不同，所以必須特別說明。「此」字以下，指出部派律典的差別。《僧祇律》等律典，全都不開許的緣故。在問訊僧眾是否和合的段落中，先就通例回答，後再顯明特別的回答。指稱「如上所說」之處，就是指〈羯磨篇〉。五德行事中，在和合僧眾的段落裡，第一段經文，先指出應有的威儀。當今之人多半是在大眾面前，頂禮完畢後才作和白宣示。

【1052-0006】資持記/05e_上四#6
【原文】不應下，遮非。次科，初示別答。若下，指通答。行草中，初科為四，初示所出。如前所明。當下，二令預辦。人別一剪者，意使各敷，恐相連布故；當用一握，長二尺許，剪已束之；須令展布，可容一坐，即為準矣。至下，三明次行。上座跪授，餘人不須。各下，四明敷布。
【譯文】「不應」以下，制止錯誤的作法。下一科，首先指出特別的回答。「若」字以下，指明通例的回答。在鋪設草座的段落中，第一科分為四部分，首先說明草座的出處。正如前面所解釋的。「當」字以下，第二是令眾人預先備辦。每人各自剪取一把，用意是讓大家各自鋪設，擔心會連綿散布在一起；應當取用一握的量，長約二尺左右，剪齊後捆成一束；必須使其展開攤平後，足夠容納一人坐下，這就符合標準了。「至」字以下，第三說明依次鋪行。對上座應當跪著奉遞，其餘之人則不需要。「各」字以下，第四說明鋪設排列。

【1052-0007】資持記/05e_上四#7
【原文】於座前者，即所坐席外地上也。注文。有云：重囑預覓。或云：定是預覓，何必重囑？今謂此文。注上敷草；謂若至五德唱已始敷事容倉卒，眾復稽遲；故令受已前敷，待唱即坐；有不依此，特注示之；辨，謂布草備擬坐處也。唱告中。就草座者，告令即時離本座處。偏袒等者，囑後自恣，具儀致敬。
【譯文】「在座前」的意思，就是指所坐席位外面的空地上。注文部分，有人說：這是再次囑咐預先尋覓。也有人說：本來就確定要預先尋覓，何必再次囑咐？現在我認為這段注文，是註解上面鋪草之事；意思是指若等到五德唱白完畢才開始鋪草，事情未免顯得倉促，大眾又會因此延遲耽誤；所以命令接受草料後預先鋪好，等待唱告完畢隨即坐下；有人不依照這套規矩，所以特別註記指明；「辨」，是指鋪設草料以預備坐處。在唱白宣告的段落中。「就草座」這句話，是宣告大眾即刻離開原本的正式座位。「偏袒右肩」等語，是囑咐後續自恣時，必須具足威儀來致敬。

【1052-0008】資持記/05e_上四#8
【原文】注令從之，非謂合眾即皆互跪；下云：見五德來，方從座起；故知爾前，但坐草上。人多錯解，令眾疲極，迷文故也。問：所以須坐草者？答：自恣一法，異餘眾事；由是露過，求他誨示，必現卑遜。褥席坐具，不以𭣋藉；屈身平地，同彼罪囚；恐損身衣，故令布草。
【譯文】注文要求依從此法，並不是說全體大眾就要立即同時單膝互跪；下面說：見到五德前來，才從座位站起；由此可知在此之前，只是坐在草座上。世人大多錯誤理解，導致大眾疲累不堪，這都是因為迷失了經文旨意所致。問：為什麼必須坐在草座上？答：自恣這項法事，有別於其餘僧團眾事；由於這是為了披露過失、求取他人誨導開示，必定要顯現卑下謙遜之態。各類褥席坐具，都不得襯墊鋪借；屈曲身軀坐在平地，就如同那些罪犯囚徒一般；因為擔心損傷身體和衣服，所以命令鋪草。
