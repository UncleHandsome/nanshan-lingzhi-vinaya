# 校閱材料　第895檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【895-0001】03_業疏/19a_卷四之二#41
【原文】四如良藥者，但得支身，以除饑渴，有力無事，令身安穩轉載而已，餘何所求？故經說言是身猶如車，好惡無所擇，香油及臭脂，等同於調滑，是也
【譯文】第四、「正事良藥」：飲食只要能夠支持維持肉身，用以消除飢餓與乾渴，使身體有精力修道而無病事，令肉身安穩像車輛一樣運轉載道罷了，此外還有何所求呢？所以經中說道：這個肉身就像一輛車，好的壞的不用挑揀，無論是香油還是臭動物油脂，用來潤滑車軸使其運轉是一樣的，就是這個道理。

【895-0002】03_業疏/19a_卷四之二#42
【原文】四中，藥以治病，飢渴故病，以飲食治之。「轉載」見下偈。經即《雜藏》，彼因王以麤細二食試外道，外道心起愛憎；及試比丘，比丘說偈答王，因知邪正。謂如塗軸油，豈論香臭？如資持具引
【譯文】在第四項中，良藥是用來治病的，飢渴本是疾病，所以用飲食來醫治它。「轉載」之義見下方的偈頌。經文即是《雜藏經》，那裡記載因國王用粗糲與精細兩種飲食來試探外道，外道心中生起了愛染與瞋憎；待試探比丘時，比丘說偈回答國王，國王因此辨別了正邪。意思就像塗抹車軸的油，哪裡還分香與臭呢？詳細如《資持記》中所具引。

【895-0003】03_業疏/19a_卷四之二#43
【原文】五為成道業者，佛立觀意，食為修道，若行凡福，非出世意。何則？輪王十善福化故也。如《持世》云：若不為除滅我慢諸煩惱者，不許受人一杯之水，何況餘施？文中廣列，至時引用
【譯文】第五、「為成道業」：佛陀施設飲食觀想的本意，進食全都是為了修成道業，如果只是為了修習凡夫的有漏福報，便不合佛陀教化出世的本懷。為什麼呢？因為轉輪聖王的十善道也是以世俗福報化導世間的。如《持世經》說：如果不是為了斷除消滅我慢等一切煩惱，連接受他人的一杯水都不被允許，更何況其餘豐厚的信施呢？律文中廣泛羅列，到用時隨機引用。

【895-0004】03_業疏/19a_卷四之二#44
【原文】五中，初明道業，謂求出離，凡福非道，故所不聽。如下次示不堪，不除我等，即非道行。彼經文廣，故下指之
【譯文】在第五項中，首先說明道業，是指求取解脫出離，凡夫福報並非出世正道，所以不許只為求福而受食。「如《持世》」以下，其次指示不堪消受信施之意，若不斷除我慢等煩惱，就不是修道之行。那部經文內容廣博，所以在下文指示備查。

【895-0005】03_業疏/19a_卷四之二#45
【原文】豈唯口說，必在擎鉢前𮌎，注精觀食，心悶沸涌者知叵耐也。合眼少時，待定方進。鍉鍉預看，然後內口，何心故內？知貪嗜者，須臾吐之，眼不欲見，何況流瀉，臭穢難堪，此不足貪，但癡不覺。若得惡食，待瞋心歇，然後噉之，此《母論》解。若不行觀，羅剎奪去，後充飽竟，乃憶前觀，此業已成，徒悔無益。必須預覺，何事迷耶
【譯文】哪裡只是口頭說說而已，必定要雙手端擎鉢盂在胸前，凝注精神諦觀食物，若感到心煩意亂、貪心如沸水翻湧，便應當知道自己克制不住了。此時應當閉眼片刻，等待心緒平定才進食。每一匙食物都要預先審視，然後再送入口中，要自問以何種心態送入口中？若知道自己起了貪嗜美味之心，應當想到食物吃下片刻如果吐出來，眼睛都不想看它，何況消化之後排泄流瀉出來，臭穢污濁難以忍受，這本來就不值得貪戀，只是愚癡不覺罷了。如果得到粗惡劣食，要等待心中的瞋恨之念平息，然後才去食用，這是《毗尼母論》的解釋。如果不修習這般觀想，食福就會被煩惱羅剎奪去；等到吃飽滿足之後，才回想起前面的觀想，此時惡業已經造成，空自後悔也無濟於事。必須預先覺察警惕，為何還要執迷不悟呢？

【895-0006】03_業疏/19a_卷四之二#46
【原文】結誥中，初科初示法：擎鉢前𮌎，示其儀也；注精觀食，攝心在境也；心悶沸涌者，貪嗜盛也；知叵耐者，治力不加也；合眼待定，漸漸制也；鍉即鉢器，鍉鍉看者，別別觀也；內即入也；何心內者，離三心四過也；知貪嗜者，猶未調也；上吐下流，後可惡也。上對美味，若下對惡食也。此下引文證，羅剎喻三心，食後方觀，不可追也
【譯文】在結尾勸誡中，第一科首先指示修持之法：「端鉢在胸前」，是端正其威儀；「凝注精神觀食」，是攝受心念專注於境界；「心悶沸湧」，是形容貪圖嗜好之盛；「知不可耐」，是對治之力尚且不足；「閉目等待心定」，是逐漸加以克制；「鍉」即是缽器，「每缽每缽審看」，是逐一分別觀照；「內」就是送入口中；「以何種心送入口中」，是為了遠離三種惡心與四種過失；「知道貪嗜」，說明煩惱尚未調伏；「上吐下流」，說明事後極其可厭惡。上面是針對美味而說，「若得」以下是針對惡食而說。此處以下引文印證，「羅剎」比喻貪瞋癡三毒之心，吃飽後才作觀想，已經無法追悔補救了。

【895-0007】03_業疏/19a_卷四之二#47

【譯文】言語雖然簡略而事理極其廣大，關鍵在於親臨飲食之時，才能知道自己的修行功夫是處於何種位階。身為堂堂大丈夫，既然不肯造作滔天大罪去墮地獄，難道要為了一口世俗之食而沉淪陷沒嗎？受長劫劇苦竟以此一口食為因，所作所為實在太怯弱鄙劣了！

【895-0008】03_業疏/19a_卷四之二#48
【原文】次科，初令自省，餘時則高談莫及，對食乃抑制難平，顯是下凡自可知也。大下次示激勵，一等造惡受苦不辭，反為口腹長劫墮獄，所為極弱者，悲其鄙劣也
【譯文】次一科中，首先令人自我反省：其他時候則高談闊論無人能及，面對飲食卻難以克制、內心難平，這顯然是下品凡夫的境界，自己理應心中有數。「大丈夫」以下，其次明示激勵策勉：同樣是造惡受苦在所不惜，如今反而為了口腹之慾導致長劫墮落地獄，所作所為如此懦弱微劣，這是悲憫其行徑的鄙陋低下。

【895-0010】03_業疏/19a_卷四之二#50
【原文】初緣中云：若不醉人，聽非時飲，故知醉者即時藥也。今有用諸草木合釀為酒，具色香味，如酒不異，但不醉者，佛令屏處飲之。非酒色香味，若飲醉者，如法治罪
【譯文】首先在因緣中說：如果不使人沉醉，聽許在非時（午後至明相出前）飲用，因此可知若是醉人的便是時藥。如今有用各種草木配製釀造的飲品，具備酒的色、香、味，與酒毫無二致，但只要不醉人，佛令其在隱蔽處飲用。如果不是酒的色香味，但飲用後會醉人的，則要依法治其犯戒之罪。

【895-0011】03_業疏/19a_卷四之二#51
【原文】二非時釋緣中，初科初定藥體。今下指時事，色香味三具而不醉，開飲非具而醉，犯吉境緣不具，故不至提
【譯文】在第二非時藥解釋因緣中，第一科首先判定藥物的體質。「如今」以下指明當前的事實：色香味三種皆具足但不會醉人的，開許飲用；不具備酒的色香味但會致醉的，犯突吉羅（惡作）罪，因境界與因緣不完全具足，所以不至於結犯波逸提罪。

【895-0012】03_業疏/19a_卷四之二#52
【原文】不應今日受漿至明日飲者，以越非時分故，隨飲殘宿惡觸生也
【譯文】不應當今天受持果漿而留到明天才飲用，因為超越了非時藥的時限部分，若是飲用便隨之生起殘宿與惡觸的罪咎。

【895-0013】03_業疏/19a_卷四之二#53
【原文】二中，過時宿觸，更兼不受非飲不犯
【譯文】在第二項中，超過時限便產生宿食惡觸之過，再加上未曾受持，但若不飲用則不犯。

【895-0014】03_業疏/19a_卷四之二#54
【原文】文列澄如水色者，恐雜滓澱，即時漿也。故諸果中自有清汁，初押漉時，非不雜合；澄久清淨，非時自別
【譯文】經文中列出「澄澈得如同清水之色」，是恐怕混雜渣滓沉澱，若是混濁便成了時漿（時藥）。所以各種果物中自有清純汁液，剛壓榨過濾時，並非沒有混雜濁質；久經沉澱澄清乾淨之後，自然即與時漿有別（而屬非時漿）。
