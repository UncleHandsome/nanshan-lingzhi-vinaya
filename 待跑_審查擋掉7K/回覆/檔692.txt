# 檔692 校閱意見（補跑）

這份譯文整體品質相當優良，對律典科判體裁、行文脈絡的掌握非常深入，特別是【692-0005】中對白衣羅漢與「破結」歸為行濫的辨析，理解十分到位。

針對部分**律學專有名詞、義理精確度及科判指涉**，提出以下幾點校閱意見與修改建議：

---

### 主要問題與建議分析

#### 1. 【692-0001】「受體」譯為「受戒體制」略有失偏
* **原文**：「後三據受體」
* **譯文**：「後三種是就受戒體制而言」
* **分析**：在南山律學中，「受體」是指**「受戒所得之戒體」**（對應前五種僅具虛名或外相之「名相」），並非指現代意義的「制度/體制」。譯為「受戒所得之戒體」或「受戒之體」更為精確，能直指律宗的核心概念。

#### 2. 【692-0002】文句重複「成就」
* **原文**：「白四如法成就得處所」
* **譯文**：「透過白四羯磨如法成就、成就『得處所』……」
* **分析**：譯文中出現了兩次「成就」，語句稍顯重複。此處「白四如法成就」與「得處所」是受戒成立的兩個並列緣（羯磨成就緣、界與僧數成就緣），可潤飾為「透過白四羯磨如法成就、並且得處所（僧數滿足、結界如法成就）……」，讀起來會更為俐落。

#### 3. 【692-0004】「少分、全非」的主語與語意
* **原文**：「上列諸位，不必犯重。或時少分，或復全非，皆非『共比丘』義。」
* **譯文**：「有的人只具備少分資格，有的人則完全不是真正的比丘體，都不符合『共比丘』的定義。」
* **分析**：
  * 此處古德（他解）是論證前面八種為什麼不能直接拿來定義《戒本》中的犯戒比丘：
    * **「不必犯重」**：前面列的名位不一定都會犯波羅夷重罪。
    * **「或時少分」**：如「行」（乞求、破結）與「體」（善來、羯磨），善來、破結皆是聖人（聖人無犯法），羯磨若有緣差或受已證聖者亦不犯，因此這些類別中**只有少部分（凡夫）可能犯重**。
    * **「或復全非」**：如「名」（沙彌、外道）、「相」（相似、割截）、「言說」（自稱），完全沒有具足戒體，**全體都不可能構成比丘犯重**。
  * 譯文譯為「有的人只具備少分資格，有的人則完全不是真正的比丘體」，將焦點偏向了「個人資格」；建議微調為指涉這些類別在犯重罪上**「有的類別只有少部分人可能犯，有的類別則完全不可能犯」**，語意會與後續【692-0005】記文的「『少分』如行體，『全非』如名相等」扣合得更嚴密。

#### 4. 【692-0006】「聖無犯法」的「法」
* **原文**：「聖無犯法，皆不同也」
* **譯文**：「聖者絕無可能犯戒受罰，這些都與凡夫不同」
* **分析**：在小乘阿毘達磨與律宗通義中，初果以上聖者得道共戒，法爾自然不作波羅夷重罪，此即「聖無犯法」（聖人沒有犯重戒之法則/聖者法爾無犯）。譯文增譯了「受罰」，稍微偏離了「聖者本質上就不會作犯戒之事」的法爾教義。建議改為「聖者法爾絕無犯重戒之事」或「聖者絕無犯戒之可能」。
* 此外，「但明三受」同前述，建議將「三種受戒體制」微調為「三種受戒得體之法」或「三種納受戒體之方式」。

#### 5. 【692-0007】科判名稱「顯意」之指涉
* **原文**：「顯意中」
* **譯文**：「在顯明深意的段落中」
* **分析**：此處是律疏科判，前一科是首律師等人的「他解」（引用古德解釋），此科「所以然者……」則是道宣律師自顯立意（疏主自家的正確見解）。因此「顯意」是指**「顯明自家立意」**，而非一般詞彙「顯明深意」。

#### 6. 【692-0010】「結文」是指「結定犯人之文」，非泛指「結尾」
* **原文**：「次解結文」
* **譯文**：「接著解釋結尾的文字」
* **分析**：承接 692-0002 注文科判：一段是「總列眾名」（名字比丘等），一段是「結定犯人」（即「是中比丘者，若受大戒白四……」）。疏文此處的「結文」，即指**「結定犯人的注文」**（下一句便開始逐句消解「若受大戒，簡沙彌也……」）。若譯作「結尾的文字」，讀者容易誤會只是一般文章的收尾結語。建議明確譯為「結定犯人的注文（結文）」。

### 建議修訂對照表

| 編號 | 原譯文修訂建議 |
| :--- | :--- |
| **692-0001** | 「後三種是就**受戒體制**而言」<br>👉 建議修為：「後三種是就**受戒所得之戒體**而言」 |
| **692-0002** | 「透過白四羯磨如法成就、**成就『得處所』**（僧數滿足、結界如法成就）」<br>👉 建議修為：「透過白四羯磨如法成就、**且得處所**（僧數滿足、結界如法成就）」*（避免重複「成就」）* |
| **692-0004** | 「上面所列的各種名位，並不一定都會犯重罪；**有的人只具備少分資格，有的人則完全不是真正的比丘體**，都不符合『共比丘』的定義。」<br>👉 建議修為：「上面所列的各種名位，並不一定都會犯重罪；**有的類別只有少部分人可能犯，有的類別則全體都非犯戒之人（或完全不具戒體）**，都不符合『共比丘』的定義。」 |

| **692-0007** | 「在**顯明深意**的段落中」<br>👉 建議修為：「在**『顯明己意』（疏主自顯立意）**的科文段落中」 |
| **692-0010** | 「接著解釋**結尾的文字**。」<br>👉 建議修為：「接著解釋**結定犯人的注文（結文）**。」 |

（註：【692-0003】、【692-0005】、【692-0008】、【692-0009】義理暢達，翻譯精準，維持原譯即可。）

這批校閱材料出自道宣律師《四分律含注戒本疏》與元照律師《行宗記》，主要解釋《戒本》初波羅夷（大婬戒）戒條之首句「若比丘，共比丘，同戒」。
