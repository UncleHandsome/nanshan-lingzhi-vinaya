# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【447-0001】03_業疏/04b_卷一之四#68
【原文】若作此解，焉有被訶責者得更治人？犯二篇者開餘懺主？審約情事，律文不了，以義糺定，應分二途：若同犯同治，理無預加，律言足數，謂差、結等；若自有犯，必無清過，故有罪人不合解罪，乍可應餘非罪羯磨。若作斯通，始終無妨。故此四人通前數等，三十二也
【譯文】如果作這樣的解釋，哪有自身正被訶責治罰的人反而得以去懲治他人？犯了第二篇罪的人又怎能開許去擔任他人罪愆的懺主？仔細審究情理與事相，律文屬於未了之義；以法理推尋判定，應當分為兩種途徑：如果是同犯同治（自己有同樣罪過又去治罰他人），理應不能參與加罪；律文所說的足數，是指差遣職事、結界等生善法事。如果是自己本身有犯，必定沒有能力去澄清他人的過失，所以有罪之人不合為人解除罪名，至多只能充任其餘非治罪的羯磨。如果作這樣的圓通解釋，前後始終都無妨礙。所以這四種人連通前面的人數，共有三十二人。

【447-0002】03_業疏/04b_卷一之四#69
【原文】次科初躡破。生善可爾，治罰懺罪竝滅惡事，身既有過，如何加彼？「審下」義決。初總標。糺，猶正也。「若下」別列。同犯同治，如犯殘者不足懺殘，被訶責者不足訶責，餘準說之。差、結生善，可通律意；若自有犯，即別犯別治，如犯殘不足捨墮，訶責不足擯出等。犯者不得為人解罪，是律所制；非罪羯磨，亦即生善。若作下結示，用此二途決文不了，於義盡善，故無所妨
【譯文】在下一科中，首先承接上文加以破斥。生善法事尚可如此，而治罰與懺罪都是滅惡之事，自身既然有過，如何能加罰於他人？自「審約」以下，以義理決斷。首先總括標示。「糺」相當於正的意思。自「若同犯」以下分別列舉。同犯同治，例如犯僧殘的人不能充當懺悔僧殘的僧數，被訶責的人不能充當訶責他人的僧數，其餘依此類推。差遣、結界等生善之法，可以貫通律文的深意；若是自己有犯，即指犯相不同而治罰不同，例如犯僧殘者不能充當捨墮懺罪的僧數，受訶責者不能充當擯出羯磨的僧數等。有犯罪過之人不得為他人解除罪過，這是律典所規定的；非罪羯磨，也就是指生善法事。自「若作斯通」以下結算指示，採用這兩種途徑來決斷律文中未盡之義，在義理上最為完善，所以毫無妨礙。

【447-0023】03_業疏/04b_卷一之四#90

【447-0025】03_業疏/04b_卷一之四#92
【原文】誦文合眼，恐有渟延，緣入非違，傍無人覺，此一迷也；或同誦一法，前後無乖，文相能所，不識彼我，此二迷也；或約文謹攝，深練自他，增減乖務，事法錯濫，不召令住，此三迷也；或文句乃明，牒事不濫，人有別緣，是非通默，此四迷也；或人法乃具，事局界境，成不冥然，端拱送忍，此五迷也
【譯文】背誦法文時閉起雙眼，恐有停滯拖延，以致墮入非法違失之中，而身旁竟無人察覺，這是第一種愚迷；或者眾人一同誦讀某一羯磨法，文句前後雖然沒有乖錯，但對於法文名相中的能治與所治、能為與所為，根本分不清彼此主客，這是第二種愚迷；或者依照法文謹慎攝持，深通自他之別，但遇到法事有所增減違背常務、事相與軌法交錯混濫之時，卻不能呼召令其停下，這是第三種愚迷；或者文句十分明瞭，宣示事由也不混濫，但參與之人另有界外等違礙別緣，眾人對於是非卻一概默然不語，這是第四種愚迷；或者人與法都已齊備，而事端局限於界限範圍之內，羯磨究竟成就與否茫然不知，只是一味端坐拱手隨順表決忍可，這是第五種愚迷。
