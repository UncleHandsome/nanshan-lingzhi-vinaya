# 校閱材料　第042檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【042-0001】01_行事鈔/03a_卷上之三#45
【原文】教授師至受者所，正敷坐具，坐已。語令敷坐具，為舒正四角，相對相及申手內。《五分》云：應安慰言：「汝莫恐懼，須臾持汝著高勝處。」
【譯文】教授師走到受戒人站立之處，端正鋪展自己的坐具（尼師壇），坐下之後。吩咐受戒者也鋪展坐具，為他展平撫正四角，兩人相對而坐，距離在彼此伸手可及的範圍之內。《五分律》說：教授師應當安慰他說：「你不要驚慌恐懼，片刻之後我就會引領你登上尊崇殊勝的佛子寶位。」

【042-0002】01_行事鈔/03a_卷上之三#46
【原文】彼應取其衣鉢舒示，寄此以為陶誘。前執五條語言：「此名安陀會衣。」又指身所著者：「此名欝多羅僧。」執大衣已語云：「此衣名僧伽梨。」《薩婆多》云：「此三衣名一切外道所無，今示汝名相。」若依諸部，此處即為受衣鉢者；或在眾中戒師受者。《四分》無文。或受已方持者，亦隨兩存。并執鉢已言：「此器名鉢多羅。」「此衣鉢是汝已有不？」彼答言：「是。」即便襆之。或加受法，如前。
【譯文】教授師應當取過受戒人的衣鉢展開出示，藉由這個契機來陶冶化導受戒者。先手持安陀會（五條衣）對他說：「這件衣名叫安陀會。」又指著他身上所穿的鬱多羅僧說：「這件衣名叫鬱多羅僧（七條衣）。」手持僧伽梨（大衣）之後對他說：「這件衣名叫僧伽梨。」《薩婆多論》說：「這三種袈裟名號是一切外道所絕無僅有的，如今向你開示它們的名稱與行相。」如果依照其餘部派，在此處就應當為他舉行作法加持受衣鉢；或者是由眾僧中的羯磨戒師為其受衣鉢。《四分律》則無明文。或者在受戒完畢之後才正式受持衣鉢，這兩種做法亦隨順並存。接著手持鐵鉢或瓦鉢後說：「這個法器名叫鉢多羅（應量器）。」「這些衣鉢是你自己所擁有的嗎？」受戒者回答說：「是。」教授師隨即將衣鉢重新包袱包裹好。或者在此施加受衣鉢之法，如前篇所述。

【042-0003】01_行事鈔/03a_卷上之三#47
【原文】應語言：「善男子諦聽！今是至誠時，我今當問汝。汝隨我問答，若不實者，當言不實；若實，言實。何以如此？由無始來，欺誑聖賢，沈沒生死；今欲捨虛妄，證真實法故，令汝實答。今問汝遮難，若不實答，徒自浪受。律云：犯遮難人，七佛一時為受，亦不得戒。」
【譯文】教授師應當對他說：「善男子諦聽！現在是必須極盡至誠的時刻，我現在應當審問你。你必須隨順我的詢問如實回答，如果不是實情，就應當說不是實情；如果是實情，就說實情。為何要這樣？因為從無始劫以來，眾生因欺瞞誑騙聖賢，才沉淪淪沒於生死苦海；如今想要捨離虛妄分別、證悟真實妙法，所以必須讓你如實招供回答。現在詢問你各項遮難，如果不如實回答，只不過是徒然虛妄受戒而已。律典說：凡是犯了重遮難之人，縱使過去七佛同時為他授戒，他也得不到戒體。」

【042-0004】01_行事鈔/03a_卷上之三#48
【原文】「汝第一不犯邊罪不？」答言：「無」者。語云：「汝應不識此罪，謂曾受佛戒而犯淫、盜、殺、妄；作此四者，必不得受。今汝無耶？」答言：「無」者。又語云：「汝若不識不解，不得妄答。第二汝不白衣時污淨戒比丘尼不？」答言：「無。」「第三汝不白衣沙彌時，盜聽他說戒羯磨，詐作比丘不？」答言：「無。」「第四汝非曾作外道，來投受戒後，還作外道；今復重來不？」答言：「無。」「第五汝非五種黃門不？」答言：「無」者。「第六汝非殺父不？」「第七汝非殺母不？」「第八汝非殺阿羅漢不？」「第九汝非破僧不？」「第十汝非惡心出佛身血不？」各各答言「無」者。「第十一汝非天子、阿脩羅子，名為非人，變為人形而來受戒不？」答言：「無。」「第十二汝非諸龍畜等能變化者，變為人形而來受不？」答言：「無。」「第十三汝今身中不佩男女二形不？」答：「無」者。應讚言：「善男子！已問難事，十三既無，戒可得受。」
【譯文】教授師問：「你第一、沒有犯過邊罪嗎？」受戒者若回答：「沒有。」教授師應當再說明：「你可能不認識這種罪過，這是指曾經受過佛門禁戒，卻毀犯了淫、盜、殺、大妄語四根本重罪；造了這四種重罪之人，必定不能受戒。如今你確實沒有犯過嗎？」受戒者回答：「沒有。」教授師又告誡：「你若是聽不明白、不理解，絕不得隨意胡亂回答。第二、你沒有在作在家人時染污過持清淨戒的比丘尼嗎？」回答說：「沒有。」「第三、你沒有在作在家人或沙彌時，偷聽大僧說戒布薩與羯磨，詐稱冒充自己是大比丘嗎？」回答說：「沒有。」「第四、你不是曾經作過外道，來投奔佛門受具足戒之後，又反悔回去作外道，如今再度前來嗎？」回答說：「沒有。」「第五、你不是五種黃門嗎？」回答說：「不是（我不是黃門）。」「第六、你不是殺過父親吧？」「第七、你不是殺過母親吧？」「第八、你不是殺過阿羅漢吧？」「第九、你不是破壞過和合僧團吧？」「第十、你不是曾以惡心出過佛身之血吧？」受戒者一一回答：「沒有。」「第十一、你不是天子、阿修羅之子等名為非人之類，幻化成人的形貌前來受戒吧？」回答說：「不是。」「第十二、你不是龍神、畜生等具有變化能力之物，幻化成人形前來受戒吧？」回答說：「不是。」「第十三、你如今身上沒有同時具備男、女二種性器官吧？」回答：「沒有。」教授師應當讚歎說：「善男子！已經審問完十三重難之事，既然這十三難你都沒有，戒法便可以納受了。」

【042-0005】01_行事鈔/03a_卷上之三#49
【原文】「更問十遮：汝今字誰？」答言：「某甲。」「和尚字誰？」答云：「某甲。」「年滿二十不？」答：「滿。」「衣鉢具足不？」答：「具。」「父母聽汝不？」「汝不負債不？」答：「無。」「汝非他賤人佛不許度不？是奴不？」答「無。」「汝非官人不？」答：「無。」「汝是丈夫不？」答：「是丈夫。」「有如是病，癩、癕疽、白癩、乾痟、顛狂，汝今無此諸病不？」答言：「無」者。
【譯文】教授師接著說：「進一步審問十種輕遮：你如今法名叫什麼？」回答說：「某甲。」「和尚尊名叫什麼？」回答說：「某甲。」「年齡滿二十歲了嗎？」回答：「已滿。」「衣鉢具足了嗎？」回答：「具。」「父母允許你出家受戒嗎？」「你沒有身負債務吧？」回答：「沒有。」「你不是佛陀不允許剃度的賤民吧？是奴僕嗎？」回答：「不是。」「你不是身具官役的官員體系之人吧？」回答：「不是。」「你是能承擔道業的大丈夫嗎？」回答：「是丈夫。」「世間有這幾種重病：癩病、癰疽、白癩、乾痟（肺結核等消耗症）、顛狂，你如今沒有這些重病吧？」回答說：「沒有。」

【042-0006】01_行事鈔/03a_卷上之三#50
【原文】應復語云：「汝無遮難，定得受也。如我今問汝，僧中亦當如是問；如汝向者答我，僧中亦當如是答。」
【譯文】教授師應當再次叮囑說：「你既然沒有任何遮難障礙，必定可以如法得戒。如同我現在審問你的各項問題，稍後在大眾僧中羯磨戒師也會這樣審問你；如同你剛才回答我的一樣，稍後在僧眾之中你也應當如實這般回答。」

【042-0007】01_行事鈔/03a_卷上之三#51
【原文】應教起立，為正著七條，令威儀齊正。著履，揲坐具肩上，衣鉢襆置手中。語令：「汝此處立，我至僧中為汝通請；若僧許可，我舉手召汝，汝可即來。」《五分》云：教著衣時，密如法視無重病不，種種隨緣，廣如彼述。或外律中，於此受衣鉢者。
【譯文】應當教導受戒者起立，為他整理端正穿好鬱多羅僧（七條衣），令其儀容威儀整肅齊整。穿上鞋履，將坐具折疊端正搭在左肩上，將包裹好的衣鉢包袱端放在他的雙手中。吩咐他說：「你在這個地方肅立等待，我現在前往僧眾之中為你通報啟請；如果大眾僧應允准許，我向你舉手招引示意，你就可以隨即走進來。」《五分律》說：在教導他穿整衣服之際，教授師應當暗中如法檢視受戒者身上是否有隱蔽重病等，種種隨緣審察，詳細如同彼律所述。或者是其他部派律典中，是在這個步驟為其傳授衣鉢之法。
