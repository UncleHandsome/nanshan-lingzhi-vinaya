# 校閱材料　第279檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【279-0001】02_戒疏/10b_卷三上之一#73
【原文】【疏】此戒與前，名同種別。此假異事，有見根相，即此見根，將以加謗，莫知本犯，故成「假根」。若異事見，向僧道聞，便是無根，落在前戒。乃至餘根類此有無也。解制意，成犯緣，並同前，但假根為別耳。
【譯文】【疏文】這條戒與前一條戒，名稱雖然相同，但罪相種類各別。這是假借另外一件無關的事，而那件事確實有親眼看見的根由之相，毀謗者就拿這個看見的根由，用來加諸對方進行毀謗，對方根本沒有實際犯行，所以構成「假根」。如果是看見了另一件事，卻向僧團宣稱是親耳聽說的，這就成了無根，而落入了前一條戒中。乃至其餘的聞根、疑根，也是比照這種有無情況來推類。解釋制戒的用意、構成犯罪的因緣，都與前一條戒相同，只是以假借根由作為兩者的差別罷了。

【279-0002】02_戒疏/10b_卷三上之一#74
【原文】【記】簡異中。「名同」者，並謗戒故。「種別」者，無、假異故。「此」下，示假根。「若」下，簡無根。「餘根類此」者，謂見言疑。又聞、疑為頭，互歷亦爾。「解」下，指前，不兩繁故。
【譯文】【記文】辨別差異中。「名同」，是指都是毀謗戒。「種別」，是指無根與假根的不同。從「此」往下，指示假根的相狀。從「若」往下，簡別無根。所謂「其餘根由以此類推」，是指看見卻說是起疑，或者以聽聞、起疑為開端，交替推演也是如此。從「解」往下，指示參照前戒，不再重複贅述。

【279-0003】02_戒疏/10b_卷三上之一#75
【原文】【註】佛在羅閱祇。慈地比丘見羊行婬，便言：「此羝羊者，沓婆也；其母羊者，即慈地尼。」便語比丘：「我今親見，非前無根。」比丘詰問，便自臣伏。舉過白佛，而制此戒。
【譯文】【註文】佛陀在羅閱祇城。慈地比丘看見羊在交配，就說：「那隻公羊就是沓婆；那隻母羊就是慈地比丘尼。」隨即對其他比丘說：「我現在親眼所見，不是像之前那樣毫無根由。」比丘們追究訊問他，他便俯首認罪。大家將這件過錯稟告佛陀，佛陀因而制定了這條戒。

【279-0004】02_戒疏/10b_卷三上之一#76

【譯文】【疏文】在制戒因緣中，首先說明羊的交配怎麼能和人類相比，毀謗者便對比丘說「我現在親眼所見」。這是針對前面無根毀謗、已經被判了僧殘罪而言。如今自以為有了根由，自認絕非憑空捏造。

【279-0010】02_戒疏/10b_卷三上之一#82
【原文】【律】於異分事中取片。
【譯文】【律文】在不相干的事物中截取片段相狀。

【279-0011】02_戒疏/10b_卷三上之一#83
【原文】【疏】就第三句，言「異分」者，《善見》云：「以羊當人，是名餘分，事相似故。」《十誦》云：「犯初篇中一一戒，非比丘，失比丘法，故言異分。不異分者，不失比丘法故。片者，諸威儀事也。」約《四分》中，如《論》釋好。所言「片」者，人畜乃殊，欲義非異。故以彼相，用同此犯，「片」非有乖，故曰「取片」。
【譯文】【疏文】就第三句而言，所謂「異分」，《善見論》說：「把羊當作人，這就叫做其餘部分（餘分），因為情狀相似的緣故。」《十誦律》說：「犯了第一篇中的每一條戒，就不再是比丘，失去了比丘的法格，所以稱為異分。不屬於異分的，是因為沒有失去比丘法格的緣故。片段相狀，是指各種威儀事相。」依照《四分律》的意旨，如《善見論》的解釋較好。所謂「片段」，人與畜牲雖然形體不同，但男女交合的淫欲之義並無差別。所以將畜牲的那種相狀，拿來等同於此人的犯罪行為，「片段」在情狀上並無違背，所以稱為「截取片段（取片）」。

【279-0012】02_戒疏/10b_卷三上之一#84
【原文】【記】釋異分中，初科。前引二文。《善見》所釋，頗符《四分》。次引《十誦》，欲彰部異。彼以四夷為「異分」，僧殘已下，並名「不異分」。「諸威儀為片」，謂於四夷中，取少乖威儀事而興謗也。「約」下，次明今釋。初釋異分，指前《見論》，次釋取片。「片非有乖」，「非」猶無也。
【譯文】【記文】解釋「異分」中，第一科。前面引用兩段文獻。《善見論》的解釋，頗為符合《四分律》。其次引用《十誦律》，是為了彰顯部派的差異。彼律將四波羅夷視為「異分」，僧殘罪以下，全都稱為「不異分」。「各種威儀為片段」，是指在四夷罪的範圍中，截取稍微違背威儀的小事來興起毀謗。從「約」往下，其次說明本疏的主張。首先解釋異分，指引前面的《善見論》；其次解釋截取片段。「片非有乖」的「非」，也就是無的意思。

【原文】【疏】注中解「異分者」，並非實犯，假餘相謗，故曰「異分」。約相有五。
【譯文】【疏文】注文中解釋「異分」，都並非對方真正犯下的罪，而是假託其餘無關的事相進行毀謗，所以稱為「異分」。具體情相有五種。

【279-0015】02_戒疏/10b_卷三上之一#87
【原文】【疏】言「假罪」者。見犯六聚，以初聚謗。或七聚通犯，想無故謗。或違想故謗。同犯殘也。
【譯文】【疏文】所謂「假借罪名」。是看見對方犯了六聚中的罪，卻以第一聚重罪進行毀謗。或者對方其實六聚乃至七聚通通都犯了，毀謗者卻誤以為對方清淨而加以毀謗。或者違反自己心中的認定而蓄意毀謗。這些都同樣犯僧殘罪。

【原文】【疏】言「假趣」者，如緣起通之。
【譯文】【疏文】所謂「假借道趣」，如同制戒緣起中以畜生道代指人道那樣來通達理解。

【279-0017】02_戒疏/10b_卷三上之一#89
【原文】【疏】言「異人」者，謂見比丘與所謗者名、姓、相同，以彼人犯，用謗此人也。
【譯文】【疏文】所謂「假借不同之人」，是指看見某個比丘與所要毀謗的人名字、姓氏、容貌相同，就拿那個人的罪犯，用來毀謗這名比丘。

【279-0018】02_戒疏/10b_卷三上之一#90
【原文】【疏】言「若在家」者。以上罪、趣及人，增謗其犯。及論據刻，乃是異身，故非舉謗。便就所謗，緣身搜求，知本在俗有諸重罪，即以加舉。
【譯文】【疏文】所謂「假借原本在家時的事」。是毀謗者藉由前述假借罪名、道趣以及他人（這三種方式），來加重誣謗對方的犯行。到了依據事實審查拷問時，發現所見的原來是別人，因而無法成立舉發毀謗。於是就轉向被毀謗者，從他切身之處搜查索求，得知他原本在俗家時犯過某些重罪，隨即拿來加以舉發。

【279-0019】02_戒疏/10b_卷三上之一#91
【原文】【疏】僧又覆檢，身雖非外，罪是異時，又治其謗。故下又引「假響」，即時俱非本犯，雖聞何益？

【279-0024】02_戒疏/10b_卷三上之一#96
【原文】【記】「言」下，釋異時。初明究勘。三皆非己，故曰「異身」。「便就」等者，出彼轉謗。《律》云：「若見聞本在家時犯婬、盜等，便言『我見彼犯』。」
【譯文】【記文】從「言」往下，解釋「異時（在家時）」。首先說明詳加推究查問。前面三種情況全都不是被謗者本人，所以說是「異身」。「便就」等語，指明毀謗者轉移藉口進行毀謗。《律》中說：「如果看見或聽說對方出家前在俗時犯了邪婬、偷盜等罪，就說『我親眼看見他犯了罪』。」

【279-0025】02_戒疏/10b_卷三上之一#97
【原文】【記】「僧又」下，釋假響。初明再刻。「身雖非外」，非異人也。「罪是異時」，道俗隔也。「又引『假響』」者，示彼重謗。「即時」，非前異時也。《律》云：「比丘自語，聞響聲『犯婬、盜』等，便言『我聞彼犯』。」
【譯文】【記文】從「僧又」往下，解釋「假響」。首先說明僧團再次嚴格審問。「當事人雖然不是別人」，是指並非換了另一個人。「犯罪是在不同時期」，是指在俗與出家有身分時期的阻隔。「又引出『假響』」，展示了毀謗者變本加厲的毀謗行徑。「即時」，不是指前面出家前的不同時期。《律》中說：「比丘自己說，聽到有聲音說某人『犯了婬戒、盜戒』等，就聲稱『我聽見他犯了罪』。」

【279-0036】02_戒疏/10b_卷三上之一#108
【原文】【疏】四、倚傍有濫。前之九相，條然是非。更無有濫，傍倚聖教。過顯群心，何須設諫？後之四戒，皆有倚傍。理行二教，是非交雜，真偽難分。迷情墜惡，事是可愍。故須僧諫，開悟迷途，冀彼棄惡從善，捨邪歸正。
【譯文】【疏文】第四、有所依憑而造成混淆惑亂。前面的九種犯相，是非界限判然分明。再也沒有任何模稜兩可之處，也不會依憑聖教作為託辭。過失既然在眾人眼中昭然若揭，何須設羯磨諫勸？後面的四條戒，都依託假借聖教。義理之教與行持之教，是非交雜在一起，真偽極難分辨。犯者心思迷亂而墮入惡行，情節實在令人憐憫。所以必須透過僧團如法諫勸，開導點醒其迷途，期望他們棄惡從善、捨邪歸正。

【279-0038】02_戒疏/10b_卷三上之一#110
【原文】【疏】就明倚傍，各有所由。如「破僧」者，則傍「四依、八正」；「助破」則傍「有善斯從」；「擯謗」則濫「同犯已悔」；「拒諫」則制「無德不須」。各至本文，重為述也。

【279-0039】02_戒疏/10b_卷三上之一#111
【原文】【記】次科。初二句通示。「如」下，別顯。提婆傍佛四依、八正，立邪五法以勝於佛。「助破」者，謂是從善，反云「此比丘是法語律語比丘」。「擯謗」者，見同犯已悔而不治罰，故云「有愛」等。「拒諫」者，謂《律》中非法、無知不應訶諫，故云「莫向我說」。
【譯文】【記文】下一科。前兩句普遍提示。從「如」往下，分別顯發。提婆達多依憑佛陀的四依法、八正道，建立了更加嚴苛的邪見五法，藉此自命勝過佛陀。「助破」的人，自以為是跟隨善行，反而辯稱「這位比丘是依法發言、依律發言的比丘」。「毀謗依法擯黜」的人，看見同伴犯罪後已經私下懺悔而僧團暫未處治，就毀謗僧團「有愛執偏私」等。「拒諫」的人，假借《律》中提到若是非法之人、無知之人則不應訶諫，因此辯稱「你不要向我說話」。
