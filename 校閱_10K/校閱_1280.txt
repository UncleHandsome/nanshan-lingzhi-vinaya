# 校閱材料　第1280檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1280-0001】資持記/13c_下一#14
【原文】若據通論，但使受持之外，俱名為長。今此且對受持，欲明長衣是餘小物，故約一日可成，非謂不通大小。祇支中。注文翻名，即據下律文，從相為名。前翻掩腋，頗得其實。《四分》下，引示，初引三律明制法。後引《僧祇》示制量。注中，上明本相。下示後改。
【譯文】如果就通則而論，只要在受持的定額之外，都稱作長物。如今這裡暫且對照受持的衣物，想要表明長衣屬於其餘小件物品，所以約定一天可以縫成，並非說它不通於大衣或小衣。在「祇支」中，注文翻譯名稱，就是依據後面的律文，依照形相來命名。前面翻譯為「掩腋」，相當切合它的實況。「《四分》……」以下，引用顯明：最初引述三部律典闡明制度作法，其後引用《僧祇律》說明制定的尺寸。注釋之中，上方說明原始的形式，下方說明後來的演變。

【1280-0002】資持記/13c_下一#15
【原文】後魏即元魏，今時褊衫，又復變也，疏解其文已亡。涅槃僧中，初文。注翻內衣。西國本無裩袴，即以此衣襯體著故。《僧祇》中制戒即眾學初戒。《十誦》。作時，即作務時。《三十》中。三繞即約帶，準被當上有帶字。
【譯文】「後魏」即元魏時代，現今的褊衫，又再次改變了形式，相關註疏文獻已經亡佚。在「涅槃僧」中，最初的文字，注釋翻譯為內衣。西印度原本沒有褲裩，就是用這種衣服貼身穿著。《僧祇律》中所制定的戒律，就是眾學戒的第一條。《十誦律》所說「作時」，就是操作勞務的時候。《三千威儀》之中，「三繞」是指圍繞腰帶；對照彼書原文，鈔文「當」字之上應當有「帶」字（應為「五、帶當三繞」）。

【1280-0003】資持記/13c_下一#16
【原文】餘法後明，露著泥洹僧，上無僧祇支，不得著袈裟，不得上塔至佛像講堂三師上座僧前等。《五百問》。得繫脚者，謂繫裙裾，以閉風故。《四分》。反襵著，謂不用帶繞，反襵抄之。二三四條，以小無力，重加助之。條之謂不使亂。玦如環少缺，即同鉤類；由恐數繫易損，故以玦㺲束勒之。吳即南方，蜀即川界。
【譯文】其餘作法在後面說明，若單獨露出泥洹僧而穿著，上方沒有僧祇支，就不得披著袈裟，不得登上佛塔、前往佛像處、講堂，或是去到三師、上座及大眾僧面前等處。《五百問》說「得繫腳」，是指繫住裙擺的邊緣，用以遮擋風吹。《四分律》所說「反襵著」，是指不用帶子纏繞，而是反向摺疊掖塞住。有兩條、三條、四條，是因為力量微小不夠固定，所以重複添加作為輔助。「條之」是指使其不致紊亂。「玦」如同環狀而帶有缺口，就如同鉤子之類；由於擔心頻繁繫綁容易損壞，所以用玦㺲來束緊固定。「吳」就是指南方，「蜀」就是指四川地區。

【1280-0004】資持記/13c_下一#17
【原文】今時作裙，上施腰帶，即同此土俗女方裙，雖乖本制；而便於著用，少有不齊之過。十、五二律。岐間即兩服之中。左掩上者，謂先以左邊在內，掩向其右；後以右邊於上，掩從其左故也。前云襞頭近左，《章服儀》云：如俗所傳左袵是也；今多右掩，頗乖此法。當後，當即前也。
【譯文】現今製作裙子，上方安設腰帶，就如同這片土地上俗家女子的方裙，雖然乖違原本的制式；但方便於穿著使用，很少有長短不齊的過失。十誦、五分兩部律。「岐間」就是指兩件衣服的中間。「左掩上」，是指先將左側置於內側，向右側掩覆；之後再將右側置於上方，從左側掩覆上去的緣故。前面說「襞頭近左」，《章服儀》說：如同俗人所說的左衽；如今大多向右掩覆，相當違背這個法則。「當後」，「當」就是指身前的意思。

【1280-0005】資持記/13c_下一#18
【原文】三中，《十誦》。俱修羅，《經音義》云：此翻為圖，像其衣形而立名也。〔謂如圖障。〕若準注文，即周圓縫合，而無兩頭，名俱修羅耳。《五分》，俗呵。則知俱修本同俗服，故並權開。貫頭衣，古云南海人開衫竇著之，穿頭先出，次出兩袖，謂之貫頭。注云類女裙者，今時女裙，亦不縫合。餘衣中，初科。
【譯文】第三項中，《十誦律》所稱「俱修羅」，《經音義》說：此處翻譯為「圖」，是仿照其衣服外形而命名的（意思是指形如圖帳）。如果依照注文，就是周圍全縫合在一起，沒有兩個開口，這就稱作俱修羅。《五分律》提到遭受俗人呵責，由此可知俱修原本同於世俗服飾，所以一併權宜開許。「貫頭衣」，古人指南海人開一個套頭領口來穿著，套過頭部先出來，接著伸出兩隻袖子，稱之為貫頭。注文說類似女裙，如今世俗的女裙，也是不予縫合的。在其餘衣物中，最初的科判。

【1280-0006】資持記/13c_下一#19
【原文】偏袒謂止存左袖，袒露右邊，即本祇支。𧝡膊亦即覆肩。此二雖是聽衣，但乖本式。方裙，舊云女人上馬裙；諸裙，自餘裙襜等。《業疏》云：且順律文，非俗非外。〔準方俗所宜，義應得著。〕《十誦》。初即色非，毛氈，體非。餘並製造非。偏袖即偏袒。複謂重袷。兩袖衣，謂但施兩袖，唯覆肩領，而無襟裾。
【譯文】「偏袒」是指僅保留左袖，袒露右邊身體，就是原本的僧祇支。「𧝡膊」也就是覆肩衣。這兩種雖然屬於開聽的衣物，但都乖違了根本的制式。「方裙」，舊說指女子騎馬時穿的裙；「諸裙」，指其餘的裙、襜等。《業疏》說：且順從律文，做到非俗人、非外道的形貌。（依照地方風俗的合宜性，義理上應當可以穿著。）《十誦律》中，最初是指顏色非法，毛氈則是質料非法，其餘全都是製作樣式非法。「偏袖」就是偏袒。「複」是指雙層夾衣。「兩袖衣」，是指只裝設兩隻袖子，僅僅遮覆肩膀領口，而沒有衣襟衣裾。

【1280-0007】資持記/13c_下一#20
【原文】囊衣如帽襪手衣之類。《四分》中，初示別制。前五相非，並是俗衣；餘是體非，並外道衣。褶謂短袴，行縢即行纏。汝等下，引總制。律因六群起過，離隨制斷。復作餘衣，如是煩累；佛因總斷，故云避我制等。如法治即吉羅。開畜中，初科。引經得不兩意，隨宜方便，無非為道。
【譯文】「囊衣」如同帽子、襪子、手套之類。《四分律》中，最初指示個別的限制。前五種外相非法，全都屬於世俗服飾；其餘則是材質非法，全都屬於外道服飾。「褶」是指短褲，「行縢」就是綁腿。「汝等……」以下，引述總括的禁令。律中因為六群比丘滋生過失，隨犯隨即制定禁止；他們又製作其他奇異衣服，造成如此的煩雜累贅，佛陀因而全盤斷絕，所以說「避開我的禁制」等語。依法治處就是結吉羅罪。在「開蓄」之中，最初科判，引用經典表明可行與不可行這兩種意旨，隨順合宜的方便，無非是為了修道。

【1280-0008】資持記/13c_下一#21
【原文】列物中，初科，《四分》中，初示僧物。比丘下，明開借。謂有緣故開。處所壞，即借衣處；移餘處者，謂暫置他處。若著下，明愛護。《五分》。作務開制同之。次明貴物，初示開畜。貴價衣，即同比丘三衣；西土國王，此方古者王臣，亦多著之。𣰽毹即毛褥也。若下，制踐踏。恐損壞故，誡奢逸故。
【譯文】在「列物」中，初科《四分律》裡，最初指明僧眾公物。「比丘……」以下，說明開許借用。是指有因緣事故所以開許。「處所壞」，就是借出衣物之處；「移餘處」，是指暫時移放到其他地方。「若著……」以下，說明愛惜維護。《五分律》在操作勞務時的開許與限制也是相同的。接著說明貴重物品，最初指示開許蓄存。昂貴的衣服，就等同於比丘的三衣；西印度的國王，以及此方古代的王臣，也大多穿著它們。「𣰽毹」就是毛織的地褥。「若……」以下，禁止踐踏。這是擔心遭受損壞的緣故，同時也藉以誡除奢華傲慢的習性。

【1280-0009】資持記/13c_下一#22
【原文】注文決上得坐。以《五分》制犯，故知寺內不開；即下云：唯白衣舍無餘床褥，可坐是也。三中，初科。給住房者，即制舊住待客比丘法，或彼有缺故。房衣即障幕等。複貯如今時給絮衣也。寄俗須染者，有所別故。《五分》。即比丘以衣借俗。次科。初簡皮敷。謂帶毛者。次簡染色。
【譯文】注文判定上面所說的「得坐」。由於《五分律》制定踩踏坐臥為犯戒，所以知道在寺院內並不開許；也就是下文所說：唯獨在居士家中沒有其餘床鋪被褥時，才可以坐下。第三項中，初科「給住房者」，是指制定常住僧招待客比丘的規則，或者因為對方有所缺乏。「房衣」就是遮障帳幕之類。「複貯」如同現今提供填充絲綿的衣服。寄放在俗人家中必須染色，是因為要有所區別。《五分律》是指比丘把衣服借給俗人。下一科判，最初簡擇皮革坐墊，是指帶有毛皮者；接著簡擇染色。
