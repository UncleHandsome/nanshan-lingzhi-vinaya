# 校閱材料　第464檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【464-0001】資持記/02f_上一下#20
【原文】五十法者，據〈足數〉中六十餘人；然第四門十一人猶足生善，故減言之。法非中。八種者，即受法中十種方便；除少分法，及教發戒緣；《隨機羯磨》亦立八耳〔一請師，二安置，三白差，四出問，五召入，六乞戒，七戒師白，八對僧問。〕；上即緣非。及下，正示法非。事非中。
【譯文】所謂「五十種法」，是根據〈足數犍度〉中所列的六十多種不能計入法定人數的人；然而其中第四個門類的十一人仍然足以感發善根，所以扣除之後而作此說明。儀軌過失的段落中。所謂「八種」，就是指受戒法中的十種加行方便；除去了少分受戒之法，以及教導發起戒體的因緣；《隨機羯磨》也只確立了這八種罷了〔一、請師，二、安置，三、白差，四、出外詢問，五、召喚入內，六、乞求受戒，七、戒師表白，八、面對大眾審問〕；上述是指前提緣由的過失。下文「以及（及）」字以下，正式指出羯磨法本身的過失。事項過失的段落中。

【464-0002】資持記/02f_上一下#21
【原文】三位眾法，竝出界非；以局處故。結示中，初正結。離此八條入非之者，故云餘正法也。當下，明法事竝塞。別下，明人別多通。唯除二但，自餘皆有。廣下，顯略。彼文亦亡。曲解羯磨。前通眾別，別法可解，故此一章唯明眾法。敘意中，初三句，顯意。
【譯文】三種品位的大眾僧法，全都列出了結界方面的過失；因為這些法都局限於特定的處所。在總結指示（結示）的段落中，首先作正式總結。排除了上述八條落入非法的過失相狀（而如法成就者），所以稱為「其餘的正法（餘正法）」。下文「應當（當）」字以下，說明儀軌與事項全都處於阻隔不通的狀態。下文「個別（別）」字以下，說明人員處於個別狀態大多可以相通。唯獨除去了但心念與但對首這二種單純的別法，其餘各項全都具有這種情況。下文「廣大（廣）」字以下，顯明文句的簡略。那段文字如今也已經佚失了。委曲詳解羯磨（曲解羯磨）。前面已經通盤說明了大眾法與個別法，個別法原本就容易理解，所以這一章節專門用來闡明大眾僧法。在敘述主旨（敘意）的段落中，最前面的三句顯明了寫作意圖。

【464-0003】資持記/02f_上一下#22
【原文】綱要者，即初釋文，是羯磨大體〔不必強分綱緣〕。通塞者，即後料簡，示文義差別〔不必局指一科〕。若下，示妄謂。然下，明非處。上二句是縱，下二句是奪。言知處者，綱定不成，緣通成否。未可一概，故云不得等。〔禮云無雷同，注云雷之發聲，物無不同時應者。
【譯文】所謂「綱要」，就是最先開始解釋文句的內容，那是羯磨的大體架構〔不一定非要強行分割綱領與緣由〕。所謂「通塞」，就是後面進行甄別分析的內容，用以顯示文字與義理的差別〔不一定局限指定於單一科判〕。下文「倘若（若）」字以下，指出了虛妄錯謬的看法。下文「然而（然）」字以下，說明不合法之處。最上面的兩句是姑且承認縱容，最下面的兩句則是依理破斥奪回。所謂「知道處所（知處）」，綱領若有錯則必定不能成就，細部緣由若有出入則通融於成辦與否之間。不能一概而論，所以才說「不得」等等。〔《禮記》說不要隨聲附和如雷同，注解說：雷聲一發，世間萬物沒有不隨之同時響應的。〕

【464-0004】資持記/02f_上一下#23
【原文】斥執文中，初二句總示。或下，別顯，初斥連誦結略。諸白四法，翻譯省文，故安此語；不當誦之。或下，二斥專執詞句。初句如律覆藏法，但云某甲犯僧殘覆藏，僧今與某甲隨覆藏日羯磨；然前犯有差別，覆日或多少；若依律誦，則不稱前事。〔〈懺篇〉云：依鈔作法得成；若準律文，依古羯磨，即須改張，不可謹誦是也。
【譯文】在斥責偏執文字（斥執文）的段落中，最前面的兩句作了總括提示。下文「或者（或）」字以下，分別加以顯發，首先斥責連續誦讀結尾省略標記的錯誤。在各種白四羯磨法中，翻譯時為了節省篇幅文字，所以安置了「略」這類提示字；在正式作法時絕不應當把它唸出來。下文「或者」字以下，第二點是斥責死板專執固定詞句的錯誤。第一句例如律藏中的覆藏法，原文只說某人犯了僧殘罪而加以隱瞞，僧團現在為某人舉行隨順覆藏日數的羯磨；然而當初所犯的罪名各有差別，掩蓋隱瞞的天數也或多或少；如果完全照著律藏原文死板唸誦，就無法與眼前的事實相稱。〔〈懺罪篇〉說：依照《行事鈔》的方法作法便能成就；若依照律藏原文，遵循古代的羯磨，就必須適度修改變通，絕不可拘謹死誦，指的就是這種情況。〕

【464-0005】資持記/02f_上一下#24
【原文】次句如賞勞法備牒六物，物缺須改；今亦依誦〔下注云隨有言之是也〕。言俱有者，如受日法，牒佛法僧緣，連書半月一月；文事雖備，不合俱牒〔下云不得雙誦半月是也〕。俱無如結有場大界法，律無文事，不復增加〔下云須加內外相內是也〕。亦可如呵責法，文據鬪諍，必有餘犯，不能隨改。
【譯文】下一句例如獎賞勞苦之法，原文完整列載了六種物品，如果當場缺少某些物品就必須加以修改；現在有些人卻依然照本全宣誦讀〔下文註解說應當「隨著實際擁有的物品而宣說」，指的就是這個道理〕。所謂「兼具兩者（俱有）」，例如受日法中，列載了為佛法僧三寶的事緣，文字上連續書寫半個月或一個月；雖然文字與事緣都已備載，但絕不可以在宣白時把兩者全都唸出來〔下文說「不得同時雙誦半個月與一個月」，指的就是這個道理〕。所謂「兩者皆無（俱無）」，例如結集具有戒場的大界之法，律藏原文中沒有相應的事項文字，有些人就不再額外增加詞句〔下文說「必須額外加上內外相標之內」，指的就是這個道理〕。或者也可以比如呵責法，原文的依據是爭吵鬥諍，如果犯人實際上涉及其他罪行，卻不能隨之變更修改。

【464-0007】資持記/02f_上一下#26
【原文】謂人迷足別，事昧虛實。夢中觀海而況逾之，迷可知矣。量下，明法非。雖不守文句，而自裁過甚。照下，總結上非，違教結罪。結誥中，初二句正勸。加事不成，自他兩損；過非輕細，故令極誡。必須親學，方免諸過。若下，明選人。上座者，如《五分》說，即上無人。雖居眾首，必取解法；
