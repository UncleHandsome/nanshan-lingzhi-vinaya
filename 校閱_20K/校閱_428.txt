# 校閱材料　第428檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【428-0001】資持記/01b_上一上#11
【原文】此二句舉喻雖別，所顯義同。結示中。上句躡前智術；既無典據，故云憑虛。下句躡上三事；不能詳評，故曰難為。以即用也。形謂構其相狀，聲即發其言詞。露潔，猶言顯白也。任情虛說，無教照對故易；軌行實事，是非外彰故難。上約虛實相對釋。次就理事釋者。
【譯文】這兩句所舉的譬喻雖然不同，所彰顯的義理卻是一樣的。在結語開示中。上一句承接前面的「智術」；既然毫無經典依據，所以說是「憑虛」。下一句承接上面的三件事；前人無法詳加客觀評斷，所以說是「難為」。「以」就是使用的意思。「形」是勾勒其形相模樣，「聲」就是發出其語言詞彙。「露潔」猶如說顯露明白。順任私情憑空妄說，沒有教典對照印證，所以容易；遵照軌範實行事相，是非對錯完全彰顯於外，所以困難。以上是就虛與實相對立的角度來解釋。接下來是就理與事相對立的角度來解釋。

【428-0002】資持記/01b_上一上#12
【原文】有解云：上句指虛通理性，即經論之學。下句明軌範事相，即毘尼之教。彼引《僧傳》：僧休法師聽洪律師講《四分律》三十餘遍，顧諸徒曰：予聽涉多矣，至於經論，一遍入神；今聽律部，逾增逾暗；豈非理可虛求，事難通會乎！〔又引《戰國策》云：畫鬼魅者易為巧，圖犬馬者難為功。
【譯文】有一種解釋說：上一句是指空泛圓通的理性，也就是經論的學問。下一句是說明建立軌範的事相，也就是毘尼戒律的教門。那位論者引證《高僧傳》：僧休法師聽聞洪律師講解《四分律》三十多次，回頭對門徒們說：「我聽聞涉獵的法門很多了，至於經論奧義，聽過一遍就能心領神會；如今聽講律部，反而越來越困惑、越來越昏暗；這難道不是因為義理可以憑空推求，而事相難以融會貫通嗎！」〔又引證《戰國策》所說：畫鬼怪神魅容易顯得精巧，描摹犬馬真實形象難以成就功力。

【428-0003】資持記/01b_上一上#13
【原文】又云淄州名恪律師親問南山，即以此對，未知何出。〕此謂諸師談經說理，無不精窮；考律行事，未能決白。此釋可取，故兩存焉。次彰講解，斥學解中，初科又二；初至繁濫，正敘執文。上二句標執，下二句顯過。前修即指前代諸師。律藏且據本宗一部。每有行事，必據誠文。
【譯文】又有人說淄州的名恪律師親自向南山祖師請益，祖師便用這個道理回答他，但不知出處究竟為何。〕這段話是說諸位法師談經論理，無不精深究極；但在考證戒律實踐法事上，卻未能徹底判明決斷。這種解釋是可以採取的，所以兩種說法同時保留。接著是彰顯講說與解釋的弊病、斥責學解偏差的段落，其中第一小科又分為兩部分；從開頭到「繁濫」為止，是正式敘述執著於死板文字的缺失。前兩句標示執泥文句，後兩句顯示由此產生的過患。「前修」就是指前代的諸位律師。「律藏」暫且以本宗的一部《四分律》為準。每逢有要推行的法事，必定要根據確鑿的經文。

【428-0004】資持記/01b_上一上#14
【原文】雖是實錄，然由年代渺邈，五師捃拾，翻譯失旨，抄寫錯漏，致有殘缺不了之文。今家則用文義決通，如下所標律文不了是也。寄緣猶附事也。良即訓實。以文害事，故有繁濫。〔如依律羯磨各差五德，有覆不開懺重，夏竟解界，二十八人不足數，四人捨墮之類。
【譯文】雖然律文是佛陀的實錄，然而由於年代久遠，歷經五部律師的采掇輯錄，翻譯時常遺失原旨，傳抄中又多有錯誤遺漏，致使產生殘缺或義理不明的文字。我們宗門則是以文字義理互相貫通決斷，就像下文所標示的「律文不了義」即是此例。「寄緣」猶如依附事相。「良」字訓釋為確實。因為執著於死板文字而損害了事相的推行，所以才產生了繁複雜濫。〔例如依據律文羯磨各派五德之人、有覆藏罪者不開許懺悔重罪、夏安居結束立即解界、將律列二十八種不足數人一概判為不足數、以及主張由四人僧作捨墮羯磨之類。

【428-0005】資持記/01b_上一上#15
【原文】加以下，次明兼生妄計，初句標過濫之源。為學有二：一須研味精詳，二必聞見廣博。既乖此二，故多虛謬。臆下三句，出其過相。臆即胸臆，言其任意。尤即訓甚。〔如手持衣藥、執臥具為越褥之類。〕取類者，或引類例有乖〔如小界立相，引《僧祇》捨衣界一尋為例；無衣鉢得戒，以破戒和尚四句為例等。
【譯文】「加以」以下，接著說明由此兼生妄加揣測的缺失，第一句標示出過失與錯濫的根源。做學問有兩大要點：第一必須精研品味、詳盡探究，第二必須見聞廣博、博採眾長。前人既然違背了這兩點，所以大多流於虛妄謬誤。「臆」字以下的三句，列出他們過失的具體形相。「臆」就是胸臆，意思是任憑己意妄斷。「尤」字訓釋為甚。〔例如規定必須用手拿著衣物與藥物、執持臥具當作多餘被褥之類。〕「取類」的情況，或者是引用的同類條例互有違背〔例如小界建立相界，引《僧祇律》捨衣界一尋作為比照條例；沒有衣缽受戒能得戒，以破戒和尚四句作為比照條例等。

【428-0006】資持記/01b_上一上#16
【原文】或取流類不等〔如用《僧祇》加衣法，及用解大界解小界羯磨而解戒場等。〕。隨聞即用，不究可否，故云寡討論也。愚執畢身，不能遷善，故云生常計也。寡即訓少。集即是聚，言其多也。次科有二，上明辨罪，據別行也；下云眾網，約僧事也。釁戾皆目於罪。
【譯文】或者是比附的流類完全不等同〔例如挪用《僧祇律》的加持三衣之法，以及用解大界、解小界的羯磨來解除戒場等。〕。隨耳聽聞便立刻取用，不探究是否妥當，所以說是「缺乏討論」。愚昧頑執終其一生，不能改過遷善，所以說是「生常計也」。「寡」訓釋為少。「集」就是聚積，意思是極多。下一個小科有兩部分，上面說明辨析罪名，是依據個人個別的行持；下面說「眾網」，是就僧團集體的事務而言。「釁戾」都是用來稱呼罪過。

【428-0007】資持記/01b_上一上#17
【原文】展轉增多，各據一見，故曰倍分。〔如盜僧物得重，而言犯蘭；無知得提，例判為吉。此則以重為輕。盜畜物犯吉，而斷犯夷；捨墮物貿新衣得吉，而云犯提。此謂以輕為重也。〕僧事中。如僧網治罰說戒自恣受日懺罪諸餘眾務，一方行化，立法須通；任情則事派千差，依教則理歸一揆。
【譯文】爭端輾轉增多，各人依憑一套偏見，所以說是「倍分增長」。〔例如偷盜常住僧物應得重罪，卻判為犯偷蘭遮；無知而違犯本應得波逸提，卻一概判為突吉羅。這就是把重罪判為輕罪。偷盜畜生之物只犯突吉羅，卻斷定犯波羅夷；將捨墮之物換取新衣本得突吉羅，卻說成犯波逸提。這就是把輕罪判為重罪。〕在僧團大眾的事務中。例如僧團綱紀治罰、說戒布薩、自恣、受日外出、懺除罪法以及種種其他大眾事務，在一方地域弘揚化導，所立的法規必須圓融通達；任憑己意則事情會分化出千差萬別，依循教理則法則自會歸於一致。

【428-0008】資持記/01b_上一上#18
【原文】既迷教旨，義無所憑；朋黨者則同，憎嫉者故異；世途目擊，今古皆然，故云同異等。區，亦分也。三中。因前異計，執諍紛紜，是非難定，遲疑不決；故推博學深識，方能裁斷。文中，初二句簡其堪能。上句明精窮律藏，教有廢興，偏局之者固執成諍。

【428-0009】資持記/01b_上一上#19
