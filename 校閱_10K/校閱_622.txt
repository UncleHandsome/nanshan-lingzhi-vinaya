# 校閱材料　第622檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【622-0001】02_戒疏/11c_卷三上之二#26
【原文】【記】次七戒中，文分二。初總示。「同」下，別釋。初明五長，同別可解。言「五長」者，即十日、月望、急施，并鉢、藥也。後明奪、浣。受持無共。長物同分，共使共奪，則有同犯。
【譯文】【記文】在接下來的七條戒中，文意分為兩部分。首先作總體提示；從「同住」以下，分別解釋。首先說明五種長物，共同或個別的情況可以理解。所謂「五種長物」，就是十日長衣、月望衣、急施衣，以及長缽、七日藥。後面說明奪衣、浣衣。受持之衣沒有共有之義；如果是長物共同分取，共同使役、共同奪取，就會共同犯戒。

【622-0004】02_戒疏/11c_卷三上之二#29
【原文】【疏】餘有十八，若不同作，為作不犯。如行遇賊，奪衣過受，在者不知，何有同犯？今言「同」者，同行、同失、同計過受。且應「增三」。
【譯文】【疏文】其餘還有十八條戒，如果不是全體共同去作，縱使有人去作了，其餘不知者亦不犯戒。好比行路時遇到強盜，被搶走衣服後過量索受，在寺院留守的人並不知情，哪會有共同犯戒之事？現在所說的「共同」，是指同行、同失衣物、共同謀劃過量領受。這姑且應合於「增三律」的說法。

【622-0005】02_戒疏/11c_卷三上之二#30
【原文】【記】十八中。初明不同。且舉失衣過受，餘準說之。「今」下，示同義。「同計」，謂同謀也。「應增三」者，如前所引「若僧，若眾多，若一人」，即「增三」中文。今明同犯，顯有僧犯之義，故云「且應」也。
【譯文】【記文】在十八條戒當中。起初說明不同犯的情況，暫且舉出失去衣服後過量索受為例，其餘可依此類推。從「今言」以下，指明共同犯戒的涵義。「同計」就是同謀策劃。「應合增三」的意思，如前面所引用的「若僧團，若眾多，若一人」，就是出自本律增三法（增法犍度增三）的經文。現在說明共同犯戒，以顯明有僧團犯戒的道理，所以說「姑且應當」。

【622-0006】02_戒疏/11c_卷三上之二#31
【原文】【疏】有人言：「何須云云？如許多述，終未窮本。今以一義，即定綱宗。若不敘昔言，則不欽後說。何者？三十之中有受持者，則不同犯。餘非受持，同心同犯，異心異犯。如使尼浣，有心使浣，後浣便犯。先本無心，尼輒自浣，佛不制犯。可以例諸。」
【譯文】【疏文】有人主張：「何必說得如此繁瑣？像上面鋪陳了那麼多，終究沒有探尋到根本。現在只要用一條義理，就能定出根本宗旨。如果不敘述前人的說法，就不能顯出後人解釋的可貴。這是為什麼呢？因為三十捨墮當中凡是屬於加法受持的，就不會共同犯戒。其餘不是加法受持的，心思相同就一同犯戒，心思各異就各自犯戒。好比指使比丘尼浣洗衣物，如果起心指使她洗，事後洗了便犯戒；如果當初本無此心，比丘尼擅自去洗，佛陀就不制令犯戒。其餘都可以依此類推。」

【622-0007】02_戒疏/11c_卷三上之二#32
【原文】【記】次師，初斥繁。「今」下，示要。初標示。「一義」，即下約心同異也。「若不敘」等，示前引古之意。「何」下，正明。「受持」，如上五戒。「同心異心」，則應「增三」三位犯也。「如」下，引例。顯知判犯，約心有無。「諸」字語辭。
【譯文】【記文】第二位法師，起初斥責前面解說過於繁複。從「現在」以下，指出綱要。先作標明提示，「一條義理」就是指下文依隨心思的同與異。所謂「如果不敘述」等語，是說明前面引用古說的原由。從「這是為什麼」以下，正式闡明。「受持」就像上述的五條戒。「心同心異」則對應於增三法中所說僧、眾多、一人這三種犯戒位階。從「好比」以下，引用實例，顯明判定犯戒與否完全取決於當初是否有此心念。「諸」字是語尾助詞。

【622-0011】02_戒疏/11c_卷三上之二#36
【原文】【疏】就為己中，有十三戒，教人為己，作事成時，假彼身業異緣無作，成我口業。三性之中，任運成犯。《律》有五敷、奪衣、受寶七戒。《僧祇》使人取尼衣、浣故衣、擗毛、過限索、乞縷驅織五戒。《多》云：「讚織一戒，使人亦犯。」
【譯文】【疏文】在為了自己的情況中，有十三條戒教唆他人為自己辦理，事情辦成時，藉由他人的身業為相異的外緣發起無作戒體之虧損，促成我自己的口業結罪。在善、惡、無記三性之中，自然任運構成犯戒。本律中有五種敷具、奪衣、受寶這七條戒；《僧祇律》中有指使他人取比丘尼衣、浣洗衣物、擘羊毛、過期限索取、乞求織線逼迫織作這五條戒；《薩婆多論》說：「讚美織師一戒，指使他人也犯重罪。」

【622-0012】02_戒疏/11c_卷三上之二#37
【原文】【記】次科，成重中。「十三戒」，本、異合論，如下自別。本律「七戒」可知。《僧祇》「過限索」，即急切索衣。「乞縷驅織」，即使非親織師戒。《多論》「讚織」，即勸織師增價戒。
【譯文】【記文】次科，關於構成重罪的內容。「十三條戒」是將本律與異部律合併論述，下文自會分別。本律的「七條戒」顯而易見。《僧祇律》中的「過限索」，就是急迫逼切地索求衣服；「乞縷驅織」，就是指使非親屬的織師一戒；《多論》中的「讚織」，就是勸說織師增加織價之戒。

【622-0017】02_戒疏/11c_卷三上之二#42
【原文】【記】第四門，初明重中。浣、擗各有三事，擔毛隨過限分，雨衣過前用，隨用結犯。「文」下，引證。且據浣、染，餘三類通。
【譯文】【記文】第四門，最初說明重犯的內容。浣衣、擘羊毛各自包含三種事相，擔羊毛則隨過限的距離分段結罪，雨浴衣過早使用則隨每次使用結罪。從「經文」以下，引用經證，暫且根據浣洗、染色為例，其餘三種可依此相通類推。
