# 校閱材料　第139檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【139-0001】02_戒疏/01a_卷一上之一#75
【原文】【記】三中。初正示聖意。「故律」下，略引三文，證成上義，則前所謂「為道非福」深有據矣。云「三乘」者，通約出世聖道為言。前引《律》、《論》，皆言「為」者，即佛意也。次引後偈，必具三學，文無禪定，義必兼收，非禪不慧，義如上說。「迹」謂蹤迹，即指戒法，前聖後賢，同履踐故。戒德尊勝，出過眾善，故云「增戒」。「泥洹」即涅槃，梵言異耳，同翻「寂滅」。聖證最上，故云「第一道」。「良」，善也。
【譯文】【記文】第三小節中。開頭正式示顯佛陀聖意。「故律」以下，概括引證三段經論原文，用以證成上述法義，那麼先前所主張的「制戒是為了求道而非為了世福」，便有了極為深厚的依據。所說的「三乘」，是通泛就出離世間的聖道而言。前面引據的《律》與《論》，都使用了「為」字，指的便是佛陀的制教本意。接著引述後文偈頌，必定是戒、定、慧三學兼備，文面上雖未明言禪定，義理上必定涵攝在內，缺乏禪定便無從生起真實智慧，其道理正如前文所說。「迹」是指足跡蹤跡，在此指稱戒法，因為前代聖人與後世賢者皆同樣循此踐行的緣故。戒法的德行尊貴殊勝，超越世間一切凡善，因此稱作「增戒」。「泥洹」即是涅槃，僅是梵語譯音不同罷了，同樣翻譯為「寂滅」。聖者所證得的果位最為崇高，因此稱作「第一道」。「良」是美好確鑿的意思。

【139-0002】02_戒疏/01a_卷一上之一#76
【原文】【疏】問：「上通敘致，未知此經，別為誰興？」
【譯文】【疏文】問：「以上通泛敘述了制戒的原由，但不知這部特定的《戒本》，是特別為了哪些對象興起開展的？」

【139-0003】02_戒疏/01a_卷一上之一#77
【原文】【記】次別彰戒本，問中。「上通敘」者，一則機通，但云諸有；二者教通，唯言制戒。機分七眾，教張四位，如向所論，未簡別故。「未知」下，正問今經興意。上句問教，下句問機。
【譯文】【記文】接下來在個別彰顯戒本（別彰戒本）之中，是問答段落。「上通敘」的意思是，一方面是所化的對象太廣泛，僅籠統說是三界諸有情；另一方面是所教的內容太寬泛，僅一般性地說是制定戒律。修學根機劃分為七眾弟子，教法張羅分為四種位階，如同先前所討論的，尚未加以精確簡別。「未知」以下，正式請問眼前這部《戒本》興起的特定用意。上句詢問教法的特殊性，下句詢問對象的特殊性。

【139-0004】02_戒疏/01a_卷一上之一#78
【原文】【疏】答：「大聖垂教，通別乃殊；至於去滯，宗猷莫二。創隨犯制，前後森羅；機教俱開，鮮能舉要。窮神知化，唯佛一人；自餘凡小，卒未明達。故別隨戒，單出本文，依月再說，用清非境。」
【譯文】【疏文】答：「大聖佛陀垂賜教法，整體通規與個別特設雖有不同；至於斷除惑亂滯礙，其根本宗要與法度絕無二致。當初隨順比丘的毀犯而隨緣制定，前後律條森羅繁複；針對各類根機的教法一併鋪展，眾人極少能提綱挈領執持其扼要。能窮盡萬法玄妙、洞悉眾生根性造化者，唯有佛陀一人而已；其餘凡夫與小乘聖者，終究無法在短時間內徹底通達通曉。因此佛陀特別依循各條戒律，單獨提煉出條文核心，命僧團依照每月黑白兩半月重複宣說，用以洗清違犯境界、保持清淨。」

【139-0005】02_戒疏/01a_卷一上之一#79
【原文】【記】正答中，初總示。上二句明教別，次二句明意同。「去滯」即斷惑。「猷」，法也。「創隨」下，次別答，初明通制。「前後」者，通語制廣，非止一時。「森羅」言其多貌，據本制戒，因緣閒起，篇聚不次，後集《戒本》，始成條類耳。「機」差「教」別，故曰「俱開」。然彼時眾，但守廣制，不達歸趣，故「鮮舉要」。「窮」下明別制，初敘教主適機。盡物之性，謂之「窮神」；隨物所宜，謂之「知化」。「凡」通內外，「小」總三乘，等覺已還，未窮業理，不堪制置。「故」下，正彰興意。「別隨戒」者，異廣制故。「單出」者，去緣起、廣解故。「再說」者，黑白兩半故。上二句答教別，下二句答機別。
【譯文】【記文】在正式回答（正答）之中，首先是總體開示。上面兩句說明教法的個別特設，接著兩句說明根本化意完全相同。「去滯」即是斷除煩惱困惑。「猷」是法度的意思。「創隨」以下，接著進行個別回答，首先說明通泛廣制的情況。「前後」這兩個字，通泛指稱制定廣律的過程，絕非發生在一時一刻。「森羅」形容其戒條繁多龐雜的相貌，依據最初制定戒條時，是隨著因緣間雜發生的，篇聚次第並未加以整理，直到後來結集《戒本》時，才歸整成為清晰的條目門類。「根機」參差而「教法」各別，所以稱作「俱開」。然而當時的僧眾，只能死守著廣繁的律制，不能通達其終極歸趨，所以「極少有人能掌握扼要」。「窮」字以下說明特設個別戒本之意，首先敘述教主佛陀契應群機的智慧。能竭盡萬物的本性，稱作「窮神」；能順隨萬物各自適宜的條件，稱作「知化」。「凡」字通貫於佛法內部與外道凡夫，「小」字總括聲聞、緣覺乃至菩薩等三乘人，乃至等覺菩薩以下的聖者，都未曾徹底窮究眾生造業受報的深細法理，不足以制定這項戒律。「故」字以下，正式彰顯特設此經的興起用意。「別隨戒」是為了區別於繁廣的律典制度。「單出」是指去除了每一戒的制戒緣起與廣泛註釋。「再說」是指黑月與白月各半月說戒一次。上面兩句回答了教法的個別性，下面兩句回答了對象的個別性。

【139-0010】02_戒疏/01a_卷一上之一#84
【原文】【疏】斯並如《論》，依大慈門，曲授祕方，偏賜內眾。故《論》云：「三藏為言，律藏勝故、密故，唯佛獨說，制必僧中。」不許餘眾之所讀誦，非所學故。餘如《鈔．序》。
【譯文】【疏文】這一切正如《論》中所說，是依憑大慈悲門，曲盡善巧地傳授祕密法方，特別賞賜給僧團內眾弟子。所以《薩婆多論》說：「在經律論三藏之中，律藏最為殊勝、最為祕密隱微，唯有佛陀一人方能宣說，制定必在和合僧團之中。」絕不允許其餘大眾讀誦研習，因為那不是他們所應修學的範圍。其餘的論述詳見於《行事鈔．序》。

【139-0011】02_戒疏/01a_卷一上之一#85
【原文】【記】引證中。初即《十住婆沙》，彼云「從四無量心中，流出毗尼藏」。彼通說毗尼，不唯戒本，用彼證此，故云「斯並」。言「大慈」者，為濁鈍眾生故。「曲授」證教別，「偏賜」證機別。「曲」謂巧便接引。「內眾」通五，此局大僧，三眾未具，不預同聞。尼據本位，自有別教，不僭上尊，說時亦簡故。次引《薩婆多論》，彼明先集律藏之意。「唯佛說」者，顯勝義也。「制必僧」者，顯密義也。「餘」下，指略，即十門第一「教興意」中。
【譯文】【記文】在引據證成（引證）之中。第一處引自《十住婆沙論》，論中說「從四無量心之中，流露宣化出毗尼律藏」。那部論是通泛論述整部毗尼律藏，不僅限於這部戒本，以此論證成此處之理，所以說「斯並」。所說的「大慈」，是為了救拔五濁惡世愚鈍眾生的緣故。「曲授」證成了教法的特殊性，「偏賜」證成了對象的特殊性。「曲」是指以種種善巧方便接引誘導。「內眾」通泛指稱出家五眾，但此處專指大僧比丘，沙彌等三眾由於尚未受具足戒，不得在場參與一同聽受。比丘尼依其本位，自有專屬的尼戒本教法，不得僭越居於大僧之上，因此半月宣說戒本時也將其簡別排除在外。其次引證《薩婆多論》，該論說明了當初先結集律藏的原委。「唯佛獨說」彰顯了殊勝之義。「制必僧中」彰顯了祕密之義。「餘」字以下，指明略去其餘內容，即《行事鈔》十門中第一門「教興意」裡面。

【139-0024】02_戒疏/01a_卷一上之一#98
【原文】【疏】一者，事證。如戒所禁，緣境思過，警䇿身口，常志憶持，方能遠離。故經云「佛所說禁戒，如猿猴著鏁，亦如利轡勒」，常當制之，無令放逸。由攝持威儀，正離非法也。
【譯文】【疏文】第一種，是具體事相上的持守實證。如同戒律所禁制的規範，每當面對外在境緣便深思過患，警惕策勵自身的言行身口，時刻立志憶持戒法，方能遠離過非。因此經典中說「佛陀所說的禁戒，猶如給散亂的猿猴戴上鐵鎖，又如同給奔馳的烈馬套上銳利的韁繩繮勒」，應當恆常加以制伏約束，絕不令其放縱放逸。這正是藉由嚴謹攝持威儀軌範，端正身心而遠離一切非法過惡。

【139-0025】02_戒疏/01a_卷一上之一#99
【原文】【記】釋二證中，事證為三。初、正明；「故」下，引證；「由」下，結示。「經云」者，他部戒經偈序並同，彼云「繫心不放逸，亦如猿著鎖，日夜常精進，求實智慧故」，又云「心馬馳惡道，放逸難禁制，佛說一切戒，亦如利轡勒」。
【譯文】【記文】在解釋兩種實證之中，事相實證分為三個層次。第一、正式闡明；「故」字以下，引經作證；「由」字以下，結語開示。所引用的「經云」，在其他部派的戒經偈頌序言中內容皆相同，那裡寫道「繫縛心念令不放逸，亦如猿猴套上鐵鎖，晝夜恆常勇猛精進，為了求取真實智慧故」，又說「心念如烈馬奔馳於惡道，放逸難以禁約制伏，佛陀宣說一切戒律，猶如套上銳利的韁繩繮勒」。


【139-0026】02_戒疏/01b_卷一上之一#1
【原文】【疏】二者，理證。聖所說教，同為斷我。我難制故，先以事遮：隨我欣樂，皆約不作；我所不欲，制必行之。故於修捨，漸得調伏。無奈我本，觸境還生。故聖制言：三毒四倒，所不應念；三善四觀，常須依行。窮檢我源，推折不得；知唯妄謂，本來無我。此理明白，由憶念知，還由本說憶念輪故。
【譯文】【疏文】第二種是「理證」（依據義理來印證）。諸聖者所宣說的教法，共同的目的都在於斷除「我執」。然而「我執」極難制伏，所以先用具體事相來加以遮止防範：凡是順應「自我」所貪愛欣樂的事，都予以節制而不去做；凡是「自我」所排斥不願做的事，則制定戒條強令必須去實行。因此在該修作與該捨棄之間，漸漸能夠調伏自心。無奈「我執」的根本，一旦接觸外境還是會隨之萌生。所以聖者又制定規範說：貪瞋癡三毒與常樂我淨四種顛倒妄想，是不應當去憶念的；不貪、不瞋、不癡三善根以及四念處觀，應當恆常依循修持。徹底追究查檢「我執」的源頭，反覆推求剖析都了不可得；由此方知純粹是虛妄的執念，本來就沒有所謂的「我」。這個義理清清楚楚地顯發，是透過憶念觀照才能了知，這仍舊是依憑佛陀最初所宣說的「憶念教化輪」的緣故。
