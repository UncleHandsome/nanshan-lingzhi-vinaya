# 校閱材料　第1735檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】羯磨、破結通三不疑。三語一受八年前興，未擯賓頭，二洲無法，何得通也？故《鼻柰耶》云：「我今擯汝，終身不得涅槃。」便於此沒，出於西洲，夏坐度人，大興佛事。《十誦》大同，加起僧坊。《多論》云：「東洲亦因有佛法教，乃立四部眾等
【譯文】羯磨與破結通於東、西、南三洲，這毫無疑問。三語這一種受戒在成道八年以前興行，當時尚未擯斥賓頭盧尊者，東、西二洲尚無佛法，怎麼可能相通呢？因此《鼻柰耶》說：「我現在擯斥你，讓你終身不得取證涅槃。」賓頭盧尊者便在此洲隱沒，顯現在西洲，結夏安居度化眾生，大興佛事。《十誦律》記載大體相同，只是增加了建造僧坊的內容。《薩婆多論》說：「東洲也是因為他而有了佛法的教化，才得以建立四部大眾等。」

【1735-0002】03_業疏/12a_卷三之一#74
【原文】次科。初明羯磨等但通三者，準下除北洲故。次三語中，賓頭盧為現神足，取竿上旃檀鉢，為佛所擯，往餘三洲，因有佛法；既在八年之後，則三語局南明矣。《鼻柰耶》中但云西洲，又不言起僧坊，故引《十誦》、《多論》續之
【譯文】第二科。首先說明羯磨等受戒只通於三洲，是依準下文排除北洲的緣故。其次在三語受中，賓頭盧尊者因顯現神通，取下高竿上的栴檀木缽，因而被佛擯斥，前往其餘諸洲，那裡才有了佛法；這件事既然發生在八年之後，那麼三語受局限在南洲就很顯然了。《鼻柰耶》中只提到西洲，又未說建造僧坊，所以引用《十誦律》與《薩婆多論》來接續補足。

【1735-0006】03_業疏/12a_卷三之一#78
【原文】初大通小局，如《善戒經》：欲受菩薩戒者，先當淨心受七眾戒，趣菩薩道。欲知大戒唯是漸受，通於小乘；小乘五受當局自通，如後述也
【譯文】第一、大乘相通而小乘偏局。如《菩薩善戒經》所說：想要受菩薩戒的人，應當先以清淨心受持七眾戒，以趣向菩薩道。由此可知大乘戒唯有漸次受持，通於小乘戒；而小乘的五種受戒，就其本位而言是局限的，但自身內部則可相通，如後文所述。

【1735-0007】03_業疏/12a_卷三之一#79
【原文】第五大小通局中初科。初通標大可攝小，故大通；小無兼大，故小局。如下別釋。初釋大通。菩薩戒自有兩宗：若《梵網經》是華嚴部，道俗非畜皆得受之，則通漸頓；若《善戒經》是法華涅槃部，唯比丘得受，唯漸無頓。今此且據《善戒》明之。七眾戒即五、十、具，該七眾故。彼云：欲受菩薩戒，必先受優婆塞五戒、沙彌十戒、比丘具足戒，譬如重樓四級，不由初級至二級，乃至不由三級至四級者，無有是處。小乘五受下次明小局。當局謂小教必無通大之理，自通謂當分具戒通於五、十，指如後述，即次科也
【譯文】在第五大小通局的第一科中。首先總標大乘可以涵攝小乘，所以大乘相通；小乘不能兼攝大乘，所以小乘偏局。如下文分別解釋。首先解釋大乘相通。菩薩戒本有兩大宗系：若是《梵網經》屬於華嚴部，出家、在家乃至非人、畜生皆可受戒，那就通於漸受與頓受；若是《善戒經》屬於法華涅槃部，唯有比丘得以受戒，便純屬漸受而無頓受。此處姑且依據《善戒經》來說明。七眾戒就是五戒、十戒、具足戒，因為涵括了七眾的緣故。該經說：若欲受菩薩戒，必須先受優婆塞五戒、沙彌十戒、比丘具足戒，如同四層重樓，若不經由第一層而登上第二層，乃至不經由第三層而登上第四層，是絕不可能的事。「小乘五受」以下，接著說明小乘偏局。「當局」是指小乘教法絕無通向大乘的道理；「自通」是指就本位來說具足戒可以通攝五戒與十戒，所言「如後述」，即是指下一科。

【1735-0008】03_業疏/12a_卷三之一#80
【原文】問：受菩薩戒必假七眾為前方便乃得大戒，形盡之時，小戒謝不？有人云：前戒局報，與期俱滅；菩薩戒盡於來際，與願俱在。有人言：受大乘戒，引五、八、十、具令長，終於未來，故兩不失也。若爾，經生本戒在者，作惡應犯？答：不知有戒，無違心故
【譯文】問：受持菩薩戒必須藉助七眾戒作為前行方便才能求得大戒，在壽命終盡之時，小乘戒會隨之謝滅嗎？有人說：前面的小乘戒局限於一期身報，隨約定的期限而一併滅除；菩薩戒則窮盡未來際，與誓願常存。有人說：受持了大乘戒，便會將五戒、八戒、十戒、具足戒引申延長，直至未來，所以兩者都不會喪失。若是如此，歷經來生而本有的戒體仍在，造作惡行時是否應當算犯戒？答：因為不知道自己身負戒律，沒有故意違逆之心的緣故。

【1735-0009】03_業疏/12a_卷三之一#81
【原文】問答中。問意謂大戒通至未來，經生不滅；小戒齊一形報，命終須失。然既小戒為大方便，即應小戒亦隨不謝。答有二釋：初釋據誓，兩不相干，故小戒自失，期即要誓；次釋取體，引小歸大，故隨大俱長，至於來際。「若爾」下，釋妨。隔生既在，理應有犯。答文約後不知以明不犯。若爾，必因往迹或有知者，有違犯否？答：大小持犯，並據今報曾受為言，縱使有知，義應無犯。如上二釋，前就教限，後約分通，各有所長，未可去取
【譯文】在問答之中。問意是指大乘戒通達未來，歷經轉生亦不謝滅；小乘戒局限於一期果報，壽終必定喪失。然而既然小乘戒是大乘戒的前行方便，小乘戒就應當隨同而不謝滅。回答有兩種解釋：第一種解釋依據受戒時的誓限，兩者互不相干，所以小乘戒自行喪失，「期」即是指要期誓願；第二種解釋就戒體而言，引導小乘歸入大乘，所以隨同大乘一起延長，直至未來際。「若爾」以下，釋除疑難。隔世戒體既然仍在，理應有所犯。答文是就後世不知有戒來說明不構成違犯。若是如此，必定有人因宿命知見等昔日痕跡而得知自己有戒，是否會構成違犯？答：大小乘的持戒與犯戒，都是就現今身報中曾經受戒而言的，縱使有所知曉，在義理上亦應當不構成犯戒。如上兩種解釋，前一種就教法界限而論，後一種就分通大乘而論，各有其長處，不可妄加取捨。

【1735-0012】03_業疏/12a_卷三之一#84
【原文】故律中不與沙彌戒而受具足者，得戒得罪，故知制漸也。諸部中必先五次十，然後大戒。如《多論》中，不與五、十二戒直受具者，一時得三種戒，羯磨局漸是明文也
【譯文】所以在律藏中規定，若未先給予沙彌戒而直接授與具足戒，受戒者得戒，能授僧眾結罪，由此可知佛陀制定的是漸受。諸部律典中必定先受五戒、次受十戒，然後才受大戒。如《薩婆多論》中所說，不先授與五戒、十戒這兩種戒而直接受具足戒的，同一時刻可獲得三種戒，羯磨受局限於漸受是有明文記載的。

【1735-0013】03_業疏/12a_卷三之一#85
【原文】別釋羯磨漸中初科。初依《四分》，唯約十戒為具足方便。諸部下次據《五分》、《多論》，更加五戒為十方便。若準《尼鈔》，不先五戒直受十戒，亦得戒得罪。《多論》直爾受具，三戒齊得，故知羯磨一受，無有不具五、十戒者。近世有人欲廢五戒，準斯明判，豈非狂簡乎
【譯文】在分別解釋羯磨局限於漸受的第一科中。首先依據《四分律》，僅以十戒作為具足戒的前行方便。自「諸部」以下，接著依據《五分律》、《薩婆多論》，更增加五戒作為十戒的方便。若依據《比丘尼鈔》，不先受五戒而直接受十戒，也是得戒同時得罪。《薩婆多論》認為就這樣直接受具足戒，三種戒同時獲得，因此可知在羯磨這一種受戒中，絕沒有不具足五戒與十戒的。近世有人想要廢除五戒，依據此處明確的判定來看，豈不是志大浮誇的狂妄之徒嗎？
