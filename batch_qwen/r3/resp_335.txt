整體看，這批譯文的**脈絡掌握大致正確**（二部＝上座、大眾；五部＝曇無德等；僧祇＝大眾部；《經》＝《大集經》），白話也算通順。但有幾處**術語誤讀**、**語句不通**與**增譯過度**的問題，以下按輕重分列。

---

## 一、明顯應修正處

**1. 【335-0011】「別目」誤譯**
- 原文：以「戒本」名通，須用**別目**，簡別今宗。
- 現譯：「必須藉由**特殊的部域名稱**，來區分並凸顯本宗的**專屬地位**。」
- 問題：「別目」是相對於「通名」的**別名**（即「四分」），不是「部域名稱」；「專屬地位」為原文所無。
- 建議：「因為『戒本』是各部通用的名稱，必須再加上個別的專名（四分），才能簡別出本宗。」

**2. 【335-0009】「師資」誤解**
- 原文：約義更兼**師資顛倒**。
- 現譯：「師長**教法**與弟子**撰述**次序上的顛倒」。
- 問題：「師資」即師與弟子（佛為師、後人為資），非「教法／撰述」。
- 建議：「就義理說，更兼含師（佛）與資（弟子）前後次第顛倒之意。」

**3. 【335-0010】末句語句不通**
- 原文：故別標「四分」，**用約餘部**。
- 現譯：「用來**限制作為與其餘部派的區隔**」——句法破碎。
- 建議：「用來簡除（排除）其餘部派的戒本。」另，「特別在**前面**冠上」的「前面」原文此處未言（前後問題是下一組問答才處理），宜先譯作「另外標出『四分』」。

**4. 【335-0004】【335-0006】「徧覽」對象譯錯**
- 《大集經》原語是「廣博**遍覽五部經書**」。
- 現譯：「全面閱覽了**五個部派**」——閱覽的是五部的經律文獻，不是「部派」。
- 建議：「遍覽五部的經律典籍」。

**5. 【335-0003】前後自相矛盾＋「本部亦分」含混**
- 現譯先說「經文…**並未直接提及大眾部**」，隨後又說「按照經文本義**只有提到大眾部**」，讀者必然困惑。
- 應加限定：前者指「五部雖異，不妨諸佛法界涅槃」**這一句**只說五部；後者指**整段經文於根本部中只列僧祇，未列上座**，故疏主設問時併稱「二部」。
- 「欲顯**本部亦分**」譯作「根本部派本身後來也發生了分裂」語意游移。依疏問「同是後分」的脈絡，宜作「要顯示根本二部同樣是佛滅後分流所成，所以經中理應一併讚歎」，並加注說明。

**6. 【335-0020】【335-0021】「顯」非「顯揚」**
- 「顯宗目」是**顯示／標示**本宗名目，無「讚揚」義。
- 建議：「是顯示本宗的名目」；記文同改。

**7. 【335-0021】漏譯「法題」**
- 原文科判為「**法題**，別目中，初文」，譯文只留「題目的專屬名稱」。
- 建議：「在法題（正釋名目）中，別名『四分』一節的第一段。」

**8. 【335-0022】「博」≠「龐雜」**
- 「於上座部搜括**博要**」是在**廣博的律文**中撮取精要，「龐雜」帶貶義，與原意相反。
- 建議：「在上座部廣博的律文中搜羅撮取其精要」。
- 又「興斯名教」譯「興起這部**標有名目的教典**」生硬，宜作「這才興起『四分』這一名的教法」。補入的主語「曇無德律師」文意無誤，但屬增補，建議加括號或注標示。

## 二、用語與增譯可斟酌

| 編號 | 現譯 | 建議 |
|---|---|---|
| 0002 | 「根本的兩部是**佛法的大源頭**」 | 「二部是本」只就**相對於五部**而言；佛法源頭是佛。宜作「二部是（五部的）根本」 |
| 0002 | 「義通**五種見解**」 | 宜明作「通貫五部各自的見解」，避免與術語「五見（五惡見）」混淆 |
| 0002 | 「各懷相異的**教條相狀**」 | 「教條」為現代貶義詞，宜作「各執不同的見解、宗相」 |
| 0002 | 「**極容易**激起爭端**競爭**」 | 「多」是往往、多半；「諍競」是諍論競執，非現代義的「競爭」 |
| 0002/0003 | 「不妨礙**共同證入**法界涅槃」／增「平等的」 | 經意是「各部雖異，皆不妨證入諸佛法界涅槃」，「共同」易誤為合體同證，宜作「不妨礙證入諸佛法界涅槃」 |
| 0006 | 「這裡**不再贅述**古說」／「如今的**合理**解釋」 | 「此中不敘」只是此處不敘（無「再」「贅」義）；「今解」＝现在的解释，「合理」為添加 |
| 0006 | 「提出問答加以**裁定**」 | 「問決」宜作「設問決疑」 |
| 0013 | 「**如果一定要區別**，稱作戒本四分」 | 「必云」是「應當題作」，宜作「意思是：題作『戒本四分』，自然就能簡別了」 |
| 0014 | 「一展開**經卷**」 | 此為律典，宜作「一打開卷冊」 |
| 0016 | 「與**通常**不同」 | 宜作「與其餘部派（律本）的標題不同」 |
| 0017 | 「**廣部**律典」 | 宜作「廣律（大本律藏）」，避免被誤讀為部派名 |
| 0018 | 「正式解釋**名稱名目**」 | 疊贅，作「正式解釋題目的名目」 |
| 0001 | 「同樣都屬於**後來的分流**」 | 宜保留「後分」並加注：對佛世一味之教而言二部亦屬後起，但對五部而言二部為根本（此即問答張力所在） |
| 0008 | 「佛陀在世時所**親口宣說**」 | 「所出」較寬（含制戒、結集），可作「佛在世時就已出現」 |

## 三、體例一致性

1. **引文用語要前後一致**：0022 譯「盡所詮相」為「完全交代清楚」，0024 記文引「盡詮相」時未加引號，讀者看不出是在牒舉前文。建議統一譯為「窮盡所詮的事相」並保留引號。
2. **專名首次出現宜加注**：二部（上座部、大眾部）、五部（曇無德、薩婆多、迦葉遺、彌沙塞、犢子）、僧祇＝摩訶僧祇＝大眾部、《經》＝《大集經》、「前三藏所傳」（0006 此語所指不明，譯文含糊帶過，建議保留原語並出注）。
3. **增補成分標示**：如 0022 的「曇無德律師」、0003 的「平等的」、0017 的「節錄」等，屬合理增補，但與原文無對應字，建議以括號或注區隔，避免譯文與原典混同。
