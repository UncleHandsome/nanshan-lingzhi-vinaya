# 校閱材料　第065檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【065-0001】01_行事鈔/04b_卷上之四#14
【原文】二明受日法。夏中有緣，故聽受日；必準聖言，依法加受；妄自誑心，受而破夏；虛損信施，可悲之甚。故委示焉。
【譯文】二明受日法。夏中若有特殊因緣，所以准許受日出界；但必須遵循佛陀聖言，依照戒法加法領受；若虛妄欺誑自心，受法出界而導致破夏；白白虛耗信眾的布施，實在可悲至極。因此在此詳細指示。

【065-0002】01_行事鈔/04b_卷上之四#15
【原文】就中分三：一心念，二對首，三眾法。總分三別：一通料簡，二緣是非，三依位解。
【譯文】這當中分為三類：一是心念法，二是對首法，三是眾僧法。總體分為三項差別：一是通途料簡審辨，二是事緣之是非，三是依各別位次解說。

【065-0003】01_行事鈔/04b_卷上之四#16
【原文】初中，三種受日，有四不同：一對人不同。七日非僧，別人邊成；半月、一月，非別人法，唯僧得成；若互不得。《十誦》問：何處受七日？佛言：界內。從誰受？從五眾受。二對界者。七日通二界，羯磨局作法，可知。三先後者。若用羯磨受，後更受七日，得成，隨緣長短。不同古法唯前七日，後方羯磨。問：先得羯磨，後隨緣七日者，何故羯磨云受過七日？答：此言過者，道羯磨是過七日家法；非謂言已用七日竟，言過也。四明相攝。若受七日用竟，羯磨受者，隨得。若七日未用，或用未盡更有異緣，或是七日過緣；更受半月者，前法即謝。由羯磨法強攝故。不得一身二法相續用也。律云：不及七日還，聽受十五日。今七日法在己，必有餘緣，故知前法壞也。若前羯磨受日，要須用盡，方得受七日。比多有之，謂受一月不足，更請七日相貼，滿三十七日用之，良不可也。
【譯文】初中，三種受日法，有四種不同：第一是所對之人不同。七日法不是向僧團求受，在個人處即能成就；半月、一月的受日法，不是對單個人作法，唯有僧團大眾才能成就；若是相互調換則不能成就。《十誦律》問：在何處請受七日法？佛說：在界內。從何人處受？從出家五眾處領受。第二是所對之界不同。七日法通於自然界與作法界二界，羯磨眾法則局限於作法界，此理顯而易知。第三是先後順序不同。若是先以羯磨法受日，之後因事緣又請受七日法，可以成就，全隨事緣的長短而定。不同於古法主張必須先受七日法，之後方能羯磨。問：若可以先經羯磨受日，之後隨緣受七日法，那為何羯磨白文中說「受過七日」？答：這裡所說的「過」，是說羯磨法是屬於超過七日這類情況的法則；並非是指已經用完了七日，才稱為「過」。第四是說明彼此相攝與消融。若受了七日法而且已經使用完畢，再以羯磨法受日，隨時皆可。如果七日尚未動用，或者尚未用盡而又有其他因緣，或者因緣需要超過七日；進而再以羯磨受半月法者，前一個七日法便告消滅。這是因為羯磨法的力量強大而能涵攝收攝的緣故。不能一人身上同時兩種法相續使用。律中說：來不及在七日內返回者，准許請受十五日法。如今七日法既然還在身上，必定是有了其他因緣，所以知道前法已經壞失了。如果先前是以羯磨法受日，必定要等待期限用盡，方得請受七日法。近來常見有人認為受了一個月尚不足夠，又再請受七日法貼補上去，湊滿三十七天來使用，這實在是萬萬不可的。

【065-0005】01_行事鈔/04b_卷上之四#18
【原文】初定緣是非者。凡受日緣務，要是三寶、請喚、生善滅惡者，聽往。若請喚為利、三寶非法、破戒有難，雖受不成；妄數為夏，計為年德，冐受利養，隨有結罪。《善見》云：自長己夏，受施犯重。若為私己衣鉢藥草，如法悉成；若為治生覓利，販賣生口牛畜等物，縱為三寶，並破夏得罪。《五百問》云：治生破戒得財造佛，得福不？答：尚不免地獄，何況得福？《薩婆多》云：治生造佛，不應禮拜等。廣如後文。
【譯文】初定緣是非者。凡受日的事由因緣，必須是為了三寶之事、他人邀請請喚、能生善滅惡者，才准許前往。如果請喚是為了牟取名利、三寶之非法營謀、有破戒與災難等情事，即使作法受日也不能成就；若妄自將此算作安居夏臘，以此計算戒德年資，冒然領受利養，隨其所犯皆結罪。《善見律論》說：虛妄增長自己的夏臘，領受布施犯重罪。如果是為了自己私人的衣缽醫藥，合乎戒法者皆能成就；如果是為了經營生計謀取利益，販賣奴婢人口、牛馬牲畜等物，縱然是為了三寶，也全都算破夏並得罪。《五百問事》說：經商生計破戒而獲得錢財塑造佛像，能得福報嗎？答：尚且免不了墮地獄，更何況能得福報？《薩婆多論》說：以經營生計之錢財塑造的佛像，不應當向其禮拜等。詳情廣如後文所述。

【065-0007】01_行事鈔/04b_卷上之四#20
【原文】一三寶境界緣。《僧祇》中為塔事，《四分》中佛法僧事，《五分》亦爾。準此，若為大寺諸處緣者，開之。若自受他雇，畫造像寫經，及自經營佛像，或為俗人，縱為僧家佛事，非法乞求；並是邪命破戒，不成，得罪。
【譯文】一三寶境界緣。《僧祇律》中指為了佛塔之事，《四分律》中指為了佛、法、僧事，《五分律》也是如此。準此規定，若是為了大寺院等各處常住的因緣，予以開許。如果自己接受他人雇傭，畫像造像、抄寫經典，以及私自經營佛像買賣，或是為了俗人，縱然名義上是為僧家佛事，而以非法手段乞求募化；全都是邪命破戒之舉，受日法不能成就，並且得罪。

【065-0008】01_行事鈔/04b_卷上之四#21
【原文】二道俗病患、生善滅惡；為益彼，而無為利。《四分》中受戒、懺悔、布施等，聽去。《十誦》問：為誰受七夜？佛言：為七眾興福、設供、懺悔、受戒、問疑、請法、有病、遭難，但使前見，便生善滅惡，應去。若遣使不遣使，俱得受之。若中路聞死、反戒、八難起，不應去。
【譯文】二道俗病患、生善滅惡；為益彼，而無為利。《四分律》中提及如受戒、懺悔、布施等事，准許前往。《十誦律》問：為了何人可以請受七夜出界？佛說：為了七眾弟子興辦福德、設齋供養、求受懺悔、請受戒法、詢問疑難、請轉法輪、身患疾病、遭遇災難，只要前往相見，便能使其生善滅惡，就應當前往。對方無論是否派遣使者來請，都得以受法前往。如果在半路上聽聞對方已死、破戒還俗（反戒）、或是發生了八難等事，就不應當前往。

【065-0009】01_行事鈔/04b_卷上之四#22
【原文】三父母大臣，信樂不信樂，俱聽；律文如此。餘汎俗人，生福信樂，聽去；無信，不聽，必有力生信，義應開往。
【譯文】三父母大臣，信樂不信樂，俱聽；律文如此。其餘一般的俗人，若能生起福德信樂，准許前往；若無信心，則不准前往，但若有能力引導其生起信心者，在義理上應當開許前往。

【065-0010】01_行事鈔/04b_卷上之四#23
【原文】四為求衣鉢乃至藥草，若自病重，不堪受日，聽直去，不須受之，如上安居命難中說。今時有人，為衣藥等，多妄請日。準過知足戒，失三受三，尚結捨墮；今則長財豐足，而缺三衣；此乃捨制取聽，未隨佛化。必長財資具俱乏，準乞衣戒，直爾外乞。藥草等物，亦謂自貧，住處及即日往反處無者，聽；若反上得辨，非緣不成。
【譯文】四為求衣鉢乃至藥草，若自己病重，不堪忍受作法受日，准許直接離去，不需要請受受日法，如前文安居命難中所說。現今有人為了衣服醫藥等，大多虛妄請求受日。比照過度索求不知足的戒條，失去三衣而受取三衣，尚且要結捨墮（尼薩耆波逸提）；如今則是多餘資財豐足，卻唯獨缺乏三衣；這乃是捨棄根本制定（制教）而執取開許條文（聽許），未能隨順佛陀教化。必須是多餘財物與資身器具皆極為匱乏，方可比照乞衣戒的規定，直接向外乞求。醫藥等物，亦是指自己貧困，住處及當日能往返之處都無法取得者，才准許受日前往；如果與上述相反、本可籌措辦理，則不構成為正當因緣，受日不成。

【065-0011】01_行事鈔/04b_卷上之四#24
【原文】五為和僧、護法。《四分》中：有同界安居，因我故鬪；外界僧尼鬪諍，須我和滅，聽直去。然和滅之相難知；約緣而受，不傷大理；律無正斷故。
【譯文】五為和僧、護法。《四分律》中記載：有在同界安居的僧眾，因為我的緣故而發生爭鬥；或是界外的比丘、比丘尼發生爭鬥諍端，必須由我前去調解弭息，准許直接離去。然而調解弭息的具體情狀難以逆料；依據事緣而請受受日法，並不違背總體義理；因為律中對此沒有絕對判斷的明文。
