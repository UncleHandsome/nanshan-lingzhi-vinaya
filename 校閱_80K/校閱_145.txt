# 校閱材料　第145檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【145-0001】資持記/11a_中四上#49
【原文】上約四心，揀去三心。下約三性，揀去二性，以行心通三性故。止作下，次明二犯。亦約四心三性，以揀行體，在文可分。注分善惡者，以行心語通，恐相濫故。三善同時，而不相離。三惡相別，其性相違；作犯多是貪瞋，止犯率由癡慢；一往大判，非不互兼。前後中。
【譯文】上面依照四心，揀別排除了受、想、識三心。下面依照善、惡、無記三性，揀別排除了惡性與無記性，因為行心的思心所本來通貫於三性的緣故。「止作」字以下，接著說明兩種犯戒。同樣依據四心與三性，藉以揀別行心的本體，在文句中可以清楚分明。註文中區分善與惡，是因為行心的語義很寬通，擔心彼此混淆的緣故。三種善根（無貪、無瞋、無癡）是同時生起且不相分離的。三種惡念（貪、瞋、癡）則相貌各別，其自性是彼此相違背的；作犯多半是由於貪心與瞋心而起，止犯通常是由於愚癡與傲慢而致；這只是粗略就大體而作的判斷，並非指兩者完全不會互相兼雜。在「前後門」之中。

【145-0002】資持記/11a_中四上#50
【原文】上文各據二行為言，則持犯不同，止作各異；此明四行，間雜同時；即下自作教人，自業相成二門之義。前後心者，如初教人，及後自作也。別持犯者，一行之中，兼異行也。言可知者，義易見也。後約三業，身口中二，初明二持。次明二犯。言反上者，行殺盜等，名身作犯；不受食，名身止犯；
【譯文】上文是各自依據單純的二行來論述，那麼持戒與犯戒互不相同，止持與作持也各自有別；此處則是說明四種行持，在時間上前後錯雜交替或同時並起；這就是後文「自作教人」以及「自業相成」這兩門的深意。所謂前後心，就像最初教導他人造作，以及後來自己親自造作。「別持犯」（另外的持與犯），是指在單一種行持之中，同時兼具了其他不同的行持。文中說「可知」（理當可知），是因為義理很容易看得出來。後面「約三業」（就身、口、意三業而言），身業與口業之中分為兩部分，首先說明兩種持戒。其次說明兩種犯戒。所謂「反上」（與上文相反），去造作殺生、偷盜等，稱為「身作犯」；不依律受食而逕自取食，稱為「身止犯」；

【145-0003】資持記/11a_中四上#51
【原文】為口四過，名口作犯；不作淨語，名口止犯。竝略舉事配，餘者列說。意業中。意至身口，名身口業；未至身口，則名單意。此明諸篇遠方便，及惡覺、不攝意、默妄、自覆等，果頭罪。初判不成。此通兩宗所計，若彼實宗，定無意業，動色成犯；若約假宗，思心成業；即指瞥爾，名為單意。
【譯文】造作妄語、兩舌等四種口過，稱為「口作犯」；接受淨物而不作如法說淨語，稱為「口止犯」。這些都是粗略舉出具體事相來作配對，其餘的戒相皆可依此類推。在意業之中。意念落實牽動到身業與口業，就稱為身口業；若是尚未牽動到身業與口業，則稱為「單意」（純粹的意念）。此處說明各篇罪條中的遠方便罪，以及生起惡念分別、不攝伏妄念、默然妄語、自心覆藏過失等等，後數種屬於純由意念所構成的果頭正罪。首先判定「不能構成犯戒」。這通貫了兩個宗派的觀點，若是依據主張色心為實有的薩婆多部（實宗），絕對沒有單憑意業犯罪之理，必須引動色身外相才構成犯戒；若是依據主張色心假名的大眾部或成實宗（假宗），思心所一動就能構成業力；這裡指的就是那一剎那生起的輕微念頭，稱為單意。

【145-0004】資持記/11a_中四上#52
【原文】若下，次明通成。籌度所為事，名身口思；雖未動相，即屬身口，不妨上文。若準《戒疏》，上是初解。後復解云：獨頭心念，忽起緣非，不名為犯；重緣向念，可得思覺，而不制約，即入犯科。又云：任情兩取，後為正義。〔順今宗故。〕指後說者，即第七門方便趣果中。四明通塞，標中。四行各立名塞；
【譯文】「若」字以下，接著說明能夠通貫構成犯戒的情形。反覆盤算籌劃所要造作的事，稱為「身口思」；此時雖然尚未牽動外在身口相貌，但本質上已經歸屬於身口業的範疇，這與上文的說法並不妨礙矛盾。若是依照《戒疏》，上面只是第一種解釋。隨後又作了第二種解釋說：孤立自起的個別心念，忽然生起而攀緣非違之事，並不能直接判定為犯戒；但若是重復攀緣、順從該惡念持續發展，明明能夠思惟覺察，卻不去自我制止約束，這就落入了犯戒的科條之中。又說：任憑個人意願兩種解釋皆可選取，但以第二種解釋為正義。（因為這正符合本律宗的宗旨。）文中所指稱「如同後文所述」，就是指第七門「方便趣果」之中的說明。在第四「明通塞」（明瞭通達與阻隔）的「標」（標題提示）之中。四種行持各自孤立並單獨確立名目，稱為「塞」（阻隔不通）；

【145-0005】資持記/11a_中四上#53
【原文】一行中，兼有餘行，或少或多，皆號為通。初門唯塞，第三唯通，二四兩兼。又二中通者，持犯自通；三四中通，持犯互通。如是求之。一心中，初標。唯下，立義。言作業者，此明行心造作，通該四行，非謂作持之作。謂起心對境，各局為言，不約前後相兼之義。
【譯文】在單一種行持之中，若兼具其他行持，無論是少許還是眾多，都稱為「通」。第一門純粹是塞，第三門純粹是通，第二門與第四門則是通與塞兩者兼具。另外，第二門中的通，是指持與犯各自內部相通；第三、第四門中的通，則是持與犯相互通貫。應當如此推求。在「一心」之中，起初是標示。「唯」字以下，確立義理。所謂「作業」，這是說明行陰造作之心通貫涵蓋四行，並非單指作持之「作」。這是說起心面對境界，各自局限於當下一端而言，不涉及前後互相兼涉的義理。

【145-0006】資持記/11a_中四上#54
【原文】若爾，雙持雙犯，如何明之？答：止作緣異，還成不通。以下，釋所以。心竝境頓，無此理故。若爾，不學有頓犯者，豈非境頓。如後明之。第二標中。但由境事，容兼止作；故心隨境，行有雙具。即前所明雙持犯義；但心用教行，二義相參，在文難曉。總分中，上釋塞義。持犯相望，善惡異故。下釋通義。
【譯文】如果是這樣，那麼兼具雙持與兼具雙犯的義理，又該如何說明呢？答：止持與作持所依憑的緣起既然互不相同，到頭來依然屬於互不相通。「以」字以下，解釋其中的緣由。因為內心不能同時並存兩個方向，境界也不可能頓然混為一體，世上絕無這種道理。如果是這樣，那麼不學戒律的人有時會頓然觸犯諸多戒律，這難道不正是境界頓現的情形嗎？這一點如同後文會再作說明。在第二個標題之中。只因為所面對的境界與事相，有可能同時兼具止與作的性質；所以內心順應著境界，行持上就會出現兩者同時具備的情形。這就是前面所闡明的「雙持雙犯」的義理；但由於內心起用與教法行持這兩種涵義相互參雜，在文字上極難明瞭。在「總分」之中，上一句解釋塞的意義。持戒與犯戒相對照，是因為善與惡不同的緣故。下一句解釋通的意義。

【145-0007】資持記/11a_中四上#55
【原文】持犯各局，止作通故。推釋中。止作相濫，無所簡故。通答中，初約互收答。止中有作者，若約教行，止中無作；此據心用，義見下科。作中有止，教行心用，二種皆具。一下，約句以簡，上二句簡二持。初云心別者，止心離過，作心進修。次境別者，止境是惡，作境是善。下二句別簡兩犯。
【譯文】持戒與犯戒各自有所局限，但止與作的行持卻能互相通貫的緣故。在「推釋」（推究解釋）之中。這是因為止與作容易混淆不清，若不推究就無從加以簡別。在「通答」（普遍解答）之中，首先依據相互含攝的道理來回答。所謂止持之中兼具作持，若從戒教的具體行持而言，止持之中是沒有作持的；這純粹是依據內心的對治功用來說明，其義理可見於下一科。所謂作持之中兼具止持，不論是教法行持還是內心功用，這兩種型態都完全具備。「一」字以下，依據句法來加以簡別，上面兩句用來簡別兩種持戒。最初說「心別」（內心不同），是指止持的心在於遠離過患，而作持的心在於進取修善。其次說「境別」（境界不同），是指止持所對的境界是惡法，作持所對的境界是善法。下面兩句特別用來簡別兩種犯戒。

【145-0008】資持記/11a_中四上#56
【原文】上句止犯，下句作犯。次約行中，前明二持。即心用雙持，通一切戒。修觀止緣，通約化業，並非制教。〔準知心用止作，則通化制；教行止作，唯句制教。〕慈悲愍物行，治殺；少欲知足行，治盜；離染淨行，治婬；如實語行，治妄。後明二犯。即約教行雙持。
【譯文】上一句指止犯，下一句指作犯。其次在「約行」（就具體行持而言）之中，前半段說明兩種持戒。這就是指內心起用時的「雙持」，普遍通貫於一切戒律之中。修習止觀以止息外緣，普遍是就化教的修行功德而言，全都不屬於制教戒條。（依此當知，內心起用的止與作，通貫於化教與制教；而教法行持上的止與作，則純粹局限在制教。）慈悲憐憫眾生的行持，用來對治殺生；少欲知足的行持，用來對治偷盜；遠離染污的清淨行持，用來對治淫欲；合乎真實的如實語行持，用來對治妄語。後半段說明兩種犯戒。這就是依據教法行持上的雙持而言。

【原文】若持若犯，皆結二罪。如此格量，粗分途徑矣。問：下開句法，為是學人，為不學人？答：此科正論不學無知，結犯分齊；學人十向無罪，何用句法揀之。古來章記，例以學不學人，相參而說；傳迷來久，見此好為一悟。例開中，初科，上句結前。次句生後。罪相交雜，非句不辨，故云須也。
【譯文】無論是持守還是違犯，全部都要結犯「不學」與「無知」二罪。按照這個標準來衡量，大致就能分清修學的門徑了。有人問：底下所開展出的句法，是指學戒的人，還是不學戒的人？回答：這個科判正是在討論「不學無知」的結犯分寸；學戒之人一概沒有這些罪過，哪裡需要用句法來簡別揀擇。古來的章疏註記，一概把學戒人與不學戒人摻雜在一起論述；錯誤傳承迷誤已久，讀到此處應當好好領悟一番。在條例開展（例開）中，第一科，上一句總結前面。下一句引出後文。罪相交錯雜亂，不用句法就無法辨別，所以說「須要」。

【145-0063】資持記/11b_中四上#48
【原文】今下，示所立。標云今者，簡諸古師，句法異故。此二九句，即能所體狀，相對而論。所體有二，即事與法；事法之下，各帶犯相。能體有三：一識，二疑，三不識；以此三心，歷事歷犯，各有三心；交絡互織，則成九句。〔法中亦爾。〕即上事犯，心容迷倒，復無九句；
【譯文】在「今」字以下，明示所立。標出「今」字，是為了簡別古代諸位法師的說法，因為句法有所不同。這兩個九句，是將能緣心與所緣境的體相狀態，相對而論。所緣之體有二種，也就是「事」與「法」；事與法之下，各自帶有犯相。能緣之體有三種：一、識（明知），二、疑（懷疑），三、不識（不知）；用這三種心念，經歷事與經歷犯，各自形成三種心態；交錯互織，就構成了九句〔法的部分亦同此理〕。這上述的事與犯，心念之中容許產生迷誤顛倒，又形成九句（底本「無」實為「為」字之訛）；

【145-0064】資持記/11b_中四上#49
【原文】此之二九，披括心境，用歷一切塵沙事法，檢察心行，無不通達。事法無量，二九遍該；楷模一定，故云方軌。且下，例通。據一事者，謂舉少出法，非定一事；如下止持作犯，略舉殺盜；作持止犯，但引房長是也。通餘戒者，戒相萬別，句法齊通；以通貫別，無不爾故。
【譯文】這「兩個九句」，徹底剖析了心念與外境，用來經歷一切塵沙般無量的事法，以檢察內心與行為，無不通達明瞭。事法無量無邊，這兩個九句全能普遍涵蓋；標準規格固定不移，所以稱為「方軌（法則）」。在「且」字以下，例示通達。「依據一件事」的意思，是說列舉少數以顯明戒法，並非局限於某一件事；正如底下止持作犯門中，略舉殺戒、盜戒為例；作持止犯門中，僅引房戒、長衣戒二事為例。所謂「通於其餘戒條」，是指戒相雖然千差萬別，但句法的運用完全相通；以通則貫穿個別差別，無不皆是如此。

【145-0066】資持記/11b_中四上#51
【原文】犯不犯等語通事犯，以止作二門，一切事法，隨一事法，必兼於犯。且如婬戒，犯不淨行，共畜生等，即是事也；波羅夷者，即名犯也；乃至眾學齊整著內衣，是事；應當學，即犯，此就總論。若約別說，一婬戒中，自造怨逼，方便重輕，境想差別，種種別相，皆名為事；法亦如之；
【譯文】所謂「犯與不犯」等用語，通於事與犯兩者，因為在止、作兩個門類中，一切事相與法規，隨任一種事法必定都兼帶犯相。暫且以淫戒為例：違犯不淨行、與畜生交媾等，這就是「事」；構成波羅夷罪，這就是「犯」；乃至眾學戒中「齊整穿著內衣」是事，「應當隨學（否則有犯）」即是犯，這是就總體而論。若就個別來說，單單一條淫戒之中：自己造作或被怨家強逼、方便階段的重罪或輕罪、境想的各種差別，這一切個別相狀全都可以稱為「事」，「法」也是如此；

【145-0067】資持記/11b_中四上#52
【原文】是如事法乃有無窮，犯則不出六聚。犯謂不犯者，如墮人胎與殺具等，謂為無犯；此下合有不犯謂犯，如盜無主，謂犯夷等。輕謂重者，如盜鼠物，言犯重等；亦合云迷重謂輕，如盜四方僧物，犯蘭等。疑中有無，即犯不犯，亦應四句；但是遲疑，非全不識；臨文自說，避繁且止。罪數中，初料，又二，初別示。
【譯文】由此可知事相法規乃有無窮，犯則不出六聚。所謂「將犯視為不犯」，例如讓婦女墮胎而給予殺胎器具等，誤以為沒有違犯；在此句之下理應還有「將不犯視為犯」，例如竊取無主之物，誤以為犯了波羅夷重罪等。所謂「將輕罪視為重罪」，例如竊取老鼠之物，說成犯了重罪等；理應也含有「迷惑將重罪視為輕罪」，例如竊取十方僧物，誤以為只犯偷蘭遮罪等。疑心之中的有罪無罪，也就是犯與不犯，也應當各有四句；但這只是心中猶豫遲疑，並非全不知曉；待面對具體文句時自然會講述，為了避免繁複姑且暫停。在「罪數」之中，先作剖析，又分為二：最初分別指示。
