# 校閱材料　第1388檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】這便說明本篇的出現，不僅是為了對比彰顯本宗與他部的差別，而且也能利益那些依其他宗派納受戒體之人。第五科。上兩句展示廣大淵博。通指各大部律，更兼及諸家論典；其中的條貫流布極其繁瑣，由此便可想而知了。「難以翻閱窮盡」，說明其義海深廣不可測度。下兩句彰顯切要核心。也就是下文所分列的七門要則。標名排列之中。第四項說明受日與淨地的開合。受日方面，《四分律》分為三品其義較為嚴狹；《十誦律》開許三十九夜，《僧祇律》開許直到事務辦妥為止，則顯得寬廣；或者也可以說他二宗只有兩種法度故屬嚴狹，本宗具足三位階則屬寬廣；

【1388-0002】資持記/16d_下四#52
【原文】淨地，則《四分》用廢教為寬，他宗制斷為狹。釋中，初文《僧祇》，初明受戒。和尚在外者，彼以羯磨所牒，同所為故。次明懺捨，初標示。以下，釋所以。自不足者，為僧所量故。還財得足者，別有所為故。同自恣者，《四分》：邊受二白，自恣一白，是五人法；《僧祇》，更加諸尼薩耆；
【譯文】淨地方面，則是《四分律》任用廢教之法較為寬大，其他宗派嚴格斷止禁止則顯得狹隘。解釋之中，第一段文句《僧祇律》，起初說明受具足戒。和尚不算在足數僧之內（在十人之外），是因為彼律認為羯磨所讀誦的對象，與所為受戒之人相同的緣故。其次說明懺悔與捨墮，起初標明展示。以下，解釋其中的緣由。自己不能算作足數之僧，是因為他是被僧眾審量處斷的對象。還清財物而得以湊足人數，是因為這時已另有所為之事的緣故。等同自恣之法，《四分律》規定：邊地受戒要二白羯磨，自恣是一白羯磨，都屬於五人作法的範圍；《僧祇律》則另外加上諸尼犯尼薩耆的捨墮懺；

【譯文】若仔細推究所用的人數，唯有宣白召集自恣的法事，才是原本的五人；面對僧眾如法和合捨墮之法，是隨從相合的五人；因為戒師與求懺之主（懺悔者本人），既然是被僧眾審量之人，就是所為的當事人，不能充作僧伽人數之用，其餘如《業疏》中所明。〔過去的注解說：等同自恣之法，這類人只是差派具有五德的比丘，不能計入作法僧數，這種說法是錯誤的。〕《四分律》以下，斥責古德之說，首先列出彼等的見解。四位僧人未明言除外，是指律文沒有明說要排除；律中四位僧人只排除三種作法：受具足戒、自恣、出罪這三事而已。

【1388-0005】資持記/16d_下四#55
【原文】簡犍黃門，有得不得。《五百問》，初明師非法。則約弟子知不知。下明弟子相乖。則據師問不問。《伽論》。賊注，本犯戒，即邊罪，此二屬十三難人；本不和者，受時別眾也；非出家者，即白衣也；並約弟子知不知，以論得否。第三中，《十誦》，先明與欲。四處作法，互相取欲；
【譯文】簡別犍黃門（閹割去勢之黃門），有可以得戒與不可得戒的差別。《五百問》中，起初說明戒師不合法的情況。這是依據弟子知情或不知情來判定。下文說明弟子身相有所違背。則是依據戒師有無詳細盤問來決定。《摩得勒伽論》說：賊住（未受冒充受戒）、本身犯重戒，這就是邊罪，這兩種人都屬於十三難之人；本來僧團不合和者，是指受戒時處於別眾非法的情況；非出家身分者，就是指在家人；這些全都依據弟子自身知曉與否，來論定究竟能否得戒。第三科中，《十誦律》首先說明與欲之法。在四個處所同時作法，彼此互相傳遞收取與欲；

【1388-0006】資持記/16d_下四#56
【原文】若本《四分》，即為破僧。若下，次明足數。謂一比丘，足多僧用。如材木等，舉相以示。《伽論》。同上。八人者，受戒四人、說戒三人，一人身兼兩處也；十三人者，謂兩處受戒，各有四人；一處說戒，有三人，以一人充三處用；十五人者，謂兩處受戒各四，兩處說戒各三用，一人充四處也；
【譯文】若依照本宗《四分律》，這種行徑便構成了破壞僧團。若以下，接著說明湊足僧數之法。也就是指一位比丘，可以同時充當多個僧團羯磨的人數。就像木材一般，舉出具體相狀以作說明。《摩得勒伽論》所說亦同於上文。所謂八人，是指一處受戒需要四人、一處說戒需要三人，其中一人身兼兩處的僧數；所謂十三人，是指在兩處受戒，各有四人；一處說戒，有三人，由一人充作三處的僧數用；十五人，是指兩處受戒各用四人，兩處說戒各用三人，由一人充作四處的僧數；

【1388-0007】資持記/16d_下四#57
【原文】十八人者，兩處受戒各四，三處說戒各三用，一人兼五處。且舉五處，更多應得。第四。初引文，犯重，即邊罪；邊尼並難，約過輕重，故得否兩殊。第二門，羯磨中，初文。廣略開合，具如上卷；《業疏》加小眾悔蘭，為中上，則有九品。參互增減，並判非法。《僧祇、十誦》。制減許增。
【譯文】十八人，是指兩處受戒各四人，三處說戒各用三人，由一人兼充五處的僧數。暫且列舉五處為例，若推廣至更多處所應當也能以此類推。第四科。起初引用律文，犯重戒，就是犯了邊罪；邊罪難與污尼難同為難緣，由於過失的輕重有所不同，所以能否得戒這兩種判定截然相異。第二門羯磨之中，第一段文句。廣略、開合的深意，完全一如上卷所詳載；《業疏》加上小眾悔除偷蘭遮罪，視為中品上品，便形成了九品羯磨。若在法式上參差互見、擅自增減，一律判定為非法羯磨。《僧祇律》、《十誦律》：禁止減少羯磨次數，但允許增加。

【1388-0008】資持記/16d_下四#58
【原文】單白通二，白二通一，極至白四，無所通矣。《僧祇》。加中間，則有四種。求聽，如受日法，從僧求故。《了論》。中間在二間者，唱白一分，羯磨一分，共為一法；唱事問聽，皆不具足，如後所引。加白羯磨，如今打槌白眾之類；直爾白知，故不問聽否。及餘三法，則有五矣。又云下，總簡。
【譯文】單白羯磨可以通向二種，白二羯磨通向一種，到了白四羯磨，就再無可通融增減的餘地了。《僧祇律》說：如果加上「中間羯磨」，便有四種法式。求聽之法，例如受日之法，是必須向僧團祈求聽許的緣故。《律二十二明了論》說：處於中間、介於二者之間的羯磨，唱白佔一部分，羯磨問答佔一部分，共同合為一法；唱導其事與詢問聽許，兩者都不完全具足，正如後文所引述。加白羯磨（直白羯磨），就像如今打槌告白大眾之類；只是單純告知大眾，所以不需要詢問同意與否。連同其餘三種白法，便共有五種羯磨了。又說以下，總括簡別。
