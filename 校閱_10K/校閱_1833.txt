# 校閱材料　第1833檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1833-0001】03_業疏/17b_卷三之六#155
【原文】引勸中，初引傳文，即宋元嘉中，師子國八尼來問䟦摩曰：「宋地未經有尼，何得二眾受戒？」今引䟦摩答詞，律無正斷，謂無不作本法不得之文。以下凖誡，初敘緣成，若下次顯非法。中容非別，謂設二眾滿，須看不足，別眾兩相，眾用界分等者，出須界所以，謂若無界限，不知和別，則無僧用剋獲也。寧下三結斷得否，無體妄持，故曰虗行
【譯文】在援引事例予以勸誡中：起初引述傳記之文，就是宋朝元嘉年間，師子國八位比丘尼前來詢問求那跋摩說：「宋地從來未曾有過如法比丘尼，如何能夠從二部僧中受戒呢？」這裡引用求那跋摩的回答之辭；「律無正斷」，是說律中並沒有「不作本法便不得戒」的明文。 自「以事證知」以下準理誡飭：起初敘明如法前緣方得成就；自「若不能」以下，其次顯明非法之態。「二眾之中容有非數、別眾」，是說縱使二眾人數具足，也須檢視有無不滿數、僧尼別眾之兩相；「僧眾法用以界域劃分等」，是說明需要結界的原因，意思是若無界限劃分，便無從知曉是大眾和合還是別眾犯罪，也就無法獲得僧中如法成辦的功用。 自「寧可」以下，第三結語決斷得戒與否：沒有真正戒體而妄加奉持，所以稱為「虛行」。

【譯文】第四、在正式詢問十三重難與諸遮法中：如同前面所說明關於父母與夫主，先問有無；若有，則問准許與否；若無，則不需發問。「奴隸婢女」乃是犯罪僕役之名，士紳女流皆同所忌諱；僧人既然深通戒法，在義理上必須變換措辭發問。雙根以下諸病，乃是非女五相，為世俗所忌諱，僧尼皆引以為羞恥，不予詢問也是可以的；所以《僧祇律》中僧人詢問遮法，排除了女子的隱處私密疾病，這是因為彼此心懷慚羞，便會失卻宏大化導誘進的莊嚴風貌。

【1833-0011】03_業疏/17b_卷三之六#165
【原文】四中初科，初通指。父下略釋，初釋父母聽否，次釋奴婢，俗禮以有罪者為奴婢，故云罪名。轉勢裁問，如前已明。三釋非女五相難分：二根一也，道合二也，道小三也，常漏便利四也，涕唾常出五也。世下教轉問，仍引僧祇，證知多恥

【1833-0012】03_業疏/17b_卷三之六#166
【原文】問：學戒及清淨相，文列為二，如能長引，一時俱答亦得？乃至遮難長誦長答，前後交亂，但應十三及諸遮者，義竝通也。今時鈍弱，隨問不解，何能引答？不妨鸚鵡逐語而聲，終未解意，還同不語，如是例之
【譯文】問：學戒相與清淨相，文中列為兩項，若能長句引誦、一次性合併回答也可以嗎？乃至於遮難長篇誦問、長篇應答，前後順序交錯紊亂，只要對應了十三重難與各項遮法，在義理上也是皆通的。然而現今之人根機鈍弱，隨問隨答尚且不能領解，如何能夠一口氣引問引答？難保不成為鸚鵡學舌、隨語發聲，終究不解其中深意，這與完全不開口並無差別，其他情況皆依此類推。

【原文】次科初點。文云「列二」者，先問學戒，謂受六法；後問清淨，謂中間無犯。如下示總答，例餘遮難並別牒而問，通用一答，但取相解，無非成法。若不解者，雖復別答，反例不成，故云「今時」等。引答，謂長問而總答也

【原文】言呪咀者呪謂言辭誓約不得違越咀謂結鄙惡言私罵令受由彼過業與妄相應遂令衰弱漸就瘦死也
