# 校閱材料　第135檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【135-0001】資持記/08b_中二#24
【原文】餘五皆善惡相對，初約愛憎慈心損益對；二約根利鈍對；三聞見廣狹對，無補謂不益於人；四求利為法對；六初心久學對，兼人謂倍人之智。不犯中，五事。初即順諫；二非法者，諫不如教故；三無智訶者，不當理故；四實爾者，省己無非故；五錯說者，不作意故。二不定，標指中。
【譯文】其餘五對都是善與惡相對立：第一是貪愛嗔憎與慈悲之心的損益相對；第二是根性利與鈍相對；第三是聽聞見識廣與狹相對，所謂「無補」是指對他人毫無益處；第四是求名利與為佛法相對；第六是初發心與久修學相對，「兼人」是指智慧倍於常人。不犯條款中共有五種情況：第一是順從勸諫；第二是勸諫非法，是指勸諫不符合法度教律；第三是無智慧者苛責，是指呵斥不合事理；第四是確實如此，是指反省自己並無過非；第五是口誤說錯，是指並非故意用心而為。第二部分不定法，標名指示中：

【135-0002】資持記/08b_中二#25
【原文】屏露不同為二，不審實犯為不定。上總戒分，下攝威儀，故當第三。文下二句，指廣。文疏通指古疏，故云久列。疏釋廣律比丘戒本，辨此二戒廣列義門，故云在戒本也。今此但明成犯緣相；自餘義章，並見戒疏義鈔，故云略述大意也。制意中。初二為他，意見戒緣；三是為法，四即為己。
【譯文】因隱蔽處與顯露處的不同而分為二條，因未能審實查明所犯何罪而稱為「不定」。上面總括根本戒律的分野，下面攝受威儀行持，所以位列第三篇。律文下方的兩句，是指引參閱更廣的論述。文中的「疏」通指古代舊疏，所以說「久列」。古代律疏解釋廣律的比丘戒本，辨析這兩條戒時廣泛列出了義理門徑，所以說「在戒本也」。現在這裡只說明構成犯罪的條件相狀；其餘的義理章節，都見於《戒疏》與《義鈔》，所以說「略述大意也」。在制戒意圖中：前兩種是為了他人，用意可見於制戒因緣；第三是為了佛法，第四則是為了自己。

【135-0003】資持記/08b_中二#26
【原文】淫重由成，故云惡業次第也。一屏處不定。〔佛在舍衛，迦留陀夷與優婆夷共屏覆坐，說非法語；毘舍佉母見白佛。因制。〕犯緣中。隨作犯者。若論所犯，各自如篇，此中但制令俗生疑；正篇犯吉，疏云：緣通七聚，犯唯在吉。斯明證也。釋中，本宗文有三，初簡境。
【譯文】淫欲重罪由此而滋生，所以說是「惡業次第也」。第一條屏處不定戒。〔佛在舍衛國時，迦留陀夷與優婆夷在隱蔽覆蓋的處所共坐，談論非法的言語；鹿子母毘舍佉看見後向佛稟告，佛陀因此制戒。〕犯緣之中。「隨作犯者」，如果論述實際所犯的罪名，各自依照相應的篇章來定罪，此處只是限制其行為免得令俗人生疑；屬於本篇的違犯只結突吉羅罪，《戒疏》說：「犯緣雖然通於七聚罪，但本戒違犯只在突吉羅。」這便是明確的證明。在解釋文中，本宗律文分為三段：首先簡別對象境緣。

【135-0004】資持記/08b_中二#27
【原文】人女，簡非畜，有智簡幼小狂睡，未終簡死壞。獨下，二明所造事。望人有二，男女各一，故名為獨。在下，三釋屏處又四，初明二屏。但取他人兩不見聞，不必房室。常語者，聲不大小也。覆處。蓋者，文不指物，隨有皆成。障處。樹等事局，故云及餘，無不收也。可作處者，具上三故。
【譯文】人類女子，是簡別非人與畜生；具有智力，是簡別幼童、瘋狂者與熟睡者；尚未斷氣，是簡別死屍毀壞。在「獨」字以下，第二說明所造作的事相。針對人數而言有兩人，男女各佔一人，所以稱為「單獨」。「在」字以下，第三解釋隱蔽之處又分為四點：首先說明兩種隱蔽，只要能讓他人既看不見又聽不到即可，不一定非要在房屋室內。所謂「平常言語」，是指聲音不大也不小。「覆處」，所謂覆蓋，經文並未限定是何物，只要有覆蓋物遮蔽就算符合。「障處」，樹木等物事體局限，所以說「以及其餘」，便無所不包。「可作處」，就是同時具備上述三種條件。

【135-0005】資持記/08b_中二#28
【原文】他部中，初科；前列諸境，以遮疑濫。設下，明第三人，皆無辨識。縱多非證。《善見》。文釋初緣，義兼第三；以盲聾等非明證故。言多女者，同類喜聞，容相隱覆；雖復聞見，猶非證人。結示中。即指《篇眾》。二露處不定。〔國土犯人竝同前戒，唯露處為別。〕初句標名。
【譯文】在他部律文中，第一科，前面列出各種境緣，是用來防範疑惑與混淆。「設」字以下，說明若是第三者，都缺乏辨別識別的能力，縱使人數再多也不能作證。《善見律》文中解釋最初的犯緣，義理兼及第三項；因為盲人、聾人等無法提供明確證明。所謂「婦女眾多」，因為同類之人喜好窺聽，容易互相隱瞞包庇；即便她們親眼看見或親耳聽見，依然不能充當合格的證人。結語指示中，就是指引參閱〈篇眾〉。第二條露處不定戒。〔國土與犯戒之人皆同前戒，只有處在顯露處有所不同。〕第一句標示名稱。

【135-0006】資持記/08b_中二#29
【原文】次句指同。犯緣亦四，唯改第一為露處，餘三並同。今更辨異：一所在異，即戒兩分；二所作異，謂可淫不可淫；三所說異，前唯說淫，後通麁語；四所疑異，前三後二，並如戒本。三十捨墮，名兼罪懺，律本隨戒並列悔法。故獨此篇指懺；如後，即懺篇也。初戒。〔佛在舍衛，六群畜多長衣；彼常經營莊嚴衣服，積而藏舉，因制。〕制意中。
【譯文】第二句指出與前戒相同。犯緣同樣有四條，只需將第一條改為「顯露之處」，其餘三條完全相同。現在進一步辨別差異：第一是處所不同，也就是戒律劃分為二；第二是所作行為不同，即可能行淫與不可行淫的差別；第三是所說言辭不同，前者僅指談論淫欲，後者通於粗俗言語；第四是所懷疑的罪名不同，前戒有三種罪名可疑，後戒只有二種，都如同戒本所載。三十捨墮，其名稱兼具罪名與懺悔兩重含意，律本在每條戒後都列出懺悔之法。因此唯獨在這一篇中指明懺悔法；所謂「如後」，就是指後文的懺罪篇。第一條戒。〔佛在舍衛國時，六群比丘蓄積過多的長衣；他們常常經營裝飾衣服，積蓄並收藏起來，佛陀因此制戒。〕制戒意圖中：

【135-0007】資持記/08b_中二#30
【原文】功德財者，財喻戒法，能齊貧苦；若貪世利，必喪道財；欲富道財，須遠世利。初是增惑，二即長業，三違教行。第一緣中，初科，上句定所屬。謂下示名體。三衣外者，若受百一，則百一外為長。簡辨中，初科，前引二文定量。若下，次辨犯相，初明應量。下引《多論》，明不應量。
【譯文】所謂「功德財」，是以財寶比喻戒法，能夠救濟資助貧困痛苦；如果貪求世間財利，必定會喪失修道法財；想要道財豐足，必須遠離世俗私利。第一是增長惑業，第二是滋長業障，第三是違背教法行持。在第一個犯緣中，第一科，上一句確定所屬歸宿。「謂」字以下展示名目與實體。在三衣之外的衣物，如果受持了一百一長衣，那麼一百一之外的就屬於長衣。簡別辨析中，第一科，前面引述兩段律文來確定應有的標準尺寸。「若」字以下，其次辨析違犯相狀，首先說明符合標準尺寸的情況。下文引述《薩婆多論》，說明不符合標準尺寸的情況。

【135-0008】資持記/08b_中二#31
【原文】昔人據律，不應非犯；今據聖論，罪分提吉，犯懺不殊。簡濫中。此據正加受者為言；必在受外，通須淨施。三中又三，初不受無犯者，無別長故。缺壞二罪，逐日隨結。若下，用長為受，上明加受失淨。無長防者，以淨本防長，今非長故。下明捨受重說。恐謂已淨，後不須故。
【譯文】過去律師依據律文，認為不符合標準尺寸就不構成違犯；現在依據聖論，罪名雖然區分為單提與吉羅，但犯戒與懺悔的法度並無差別。簡別混淆中，這是依據正式受持的法衣而言；如果是受持之外的衣物，全都需要行作淨施之法。在第三項中又分三點：第一種情況，未正式受持便不犯捨墮，因為並無額外的長衣。但缺少法衣或損壞法衣這兩種罪，會隨著日子逐日結罪。「若」字以下，拿長衣來當作受持的法衣，前文說明正式加受後便失去了原先的說淨效力。沒有防備長衣過犯的功效，是因為作淨施本是為了防範長衣，現在它已不是長衣了。下文說明捨棄此衣另受他衣時，前衣須重新說淨。唯恐有人以為前衣原先已經作過淨施，被捨下後便不需要再作說淨的緣故。

【原文】五即迦提一月五月。釋中，初科。初位十日內，雖滿不犯。若至十日得足，當日須成；不爾，十一日明出便犯。中位十九日同足即犯，後泣一日不足亦犯。得不得者，不同中位得足犯故。同不同，如後解。次科，《僧祇》，且據初位滿足示相。作衣下，明即作。所以爾者，以但三衣人，不說淨故。
【譯文】「五」就是指迦提月的一或五個月期間。在解釋中，第一小節。第一階段的十天之內，即使籌滿衣料也不犯戒。如果到了第十天籌足了，當天就必須縫製完成；若不如此，第十一天天明露出時便構成犯戒。中位階段的十九天內同類布料籌足便構成犯戒，後一位若過限一日仍未籌足亦犯。所謂「得與不得」，與中位階段籌足即犯的情況不同。所謂「相同與不相同」，如後文所作的解釋。下一小節，《摩訶僧祇律》暫且依據第一階段滿足條件來顯示相狀。「作衣……」以下，說明必須立刻裁製。之所以如此，是因為只持三衣的人，是不允許作說淨手續的。

【135-0064】資持記/08c_中二#25
【原文】初明可竟。若下，開急竟。此律下，合上急竟。絣謂疎綴令定。三中，先明同不同者。如營一衣，得多零段，體色相類，名為同衣；餘不類者，不堪共作，即不同衣。皆開一月者，或求三衣同時一月，或復前後各取一月；但得少財，即為初日。若下，明染犯。同足即中位，限滿是後位。
【譯文】首先說明可以縫製完畢的情況。「若……」以下，開許在緊急情況下暫時粗縫完畢。「此律……」以下，契合上述緊急粗縫的意義。「絣」是指粗略綴縫使其定型。第三點中，先說明「布料相同與不相同」的情況：例如經營裁製一件衣物，得到許多零碎布料，材質與顏色互相吻合，就稱為「同衣」；其餘材質色彩不相符、不堪放在一起縫製的，就是「不同衣」。這類情況都「開許一個月寬限」，或者為了求取三衣而在同一個月內求齊，或者前後分別各取一個月的時間；只要獲得些微衣料財物，那一天就算是第一天。「若……」以下，說明連帶沾染犯長的情形。同類布料籌足就是中位階段，時限屆滿就是後位階段。

【135-0065】資持記/08c_中二#26
【原文】由下，釋所以。所下，引證。不犯指前，同是長故。第四。〔佛在羅閱祇，蓮華色尼脫所著貴衣，換比丘弊故納往佛所，因問而制。〕戒名。取即是業，非親簡親，尼別下眾。犯緣，第二中，初句標緣。律下，釋相為三，前明親非親相；本律通示親里，以顯非親。《善見》別簡，初示二親。
【譯文】「由……」以下，解釋箇中原因。「所……」以下，引用經文作證。不犯戒的規定指引前文，因為這些同樣都屬於長衣的範疇。「第四戒（從非親里比丘尼取衣戒）」。〔佛陀在羅閱祇城時，蓮華色比丘尼脫下身上所穿的昂貴衣物，換取比丘破舊的粗劣糞掃衣穿著前往佛所，佛陀因應大眾的疑問而制定此戒。〕戒名。「取」是指行為動作，「非親」是用來揀別親族，「比丘尼」是用來揀別其餘沙彌尼等下眾。犯戒條件，在第二點中，第一句標明因緣。「律……」以下，分三段解釋戒相：首先說明親眷與非親眷的外相；本律是籠統指出內外親戚，藉此彰顯非親眷的範圍。《善見論》作了特別揀別，首先指出父系與母系兩類親族。

【135-0066】資持記/08c_中二#27
【原文】乃至者，略兄弟；兒孫即舅姨家者。皆下，釋親義。唯約父母二姓所屬。又下，簡非親。出家婦者，由姓異故。伯叔之婦，亦是異姓。論中不出，故例同之。《十誦》下，二明開親之意。少尚與者，謂尼貧乏，僧猶愍濟。何況等者，言無此理。律云：若非親里，亦不籌量可否；
【譯文】「乃至」這個詞，省略了堂表兄弟；兒孫是指舅父與阿姨家族的後代。「皆……」以下，解釋「親族」的定義。這僅僅局限於父親與母親兩個姓氏所屬的血脈。「又……」以下，揀別非親眷的情形。出家前曾為妻室的婦女，因為娘家姓氏不同的緣故而屬非親。伯父與叔父的妻子，也屬於異姓姻親。論典中雖未列出，但也比照同例判定。《十誦律》以下，第二段說明開許向親眷索取衣物的用意。連微薄之物尚且願意相贈，這是說比丘尼貧乏時，僧人尚且予以憐憫賑濟；「何況」等語，是說絕沒有在她不足時反而去索取的道理。律文說：如果不是親戚，就不會審慎考量對方的承受能力；

【135-0067】資持記/08c_中二#28
【原文】若是親里，則便籌量，知有無可取不可取等。《五分》下，三簡親尼淨穢。制吉罪者，遮世譏故。第三中，初約緣定境。《僧祇》簡餘輕物。無犯者，望墮為言，非無輕吉。疏云：衣多喜與故重，鉢唯有一故輕。四中。虛心謂專勤一意，無他想故。〔有云揀實心非也。〕
【譯文】如果是親戚，就會反覆考量，清楚其有無能力、可以取或不可取等。《五分律》以下，第三段揀別親族比丘尼本身持戒是清淨還是毀犯。制定突吉羅輕罪，是為了阻絕世俗的譏嫌誹謗。在第三點中，首先依據因緣確定對境。《摩訶僧祇律》揀別其餘輕微物品。所謂「無犯」，是針對免除「捨墮」重罪而言，並不是說完全沒有突吉羅輕罪。《戒本疏》說：衣服大多令人心生歡喜而貪求贈與，所以罪責重；缽只有一個，所以罪責輕。在第四點中。「純淨的心（虛心）」是指專注勤謹於單一意志，毫無其他非分企圖。（有人說是揀擇實質的心，這種說法是錯誤的。）
