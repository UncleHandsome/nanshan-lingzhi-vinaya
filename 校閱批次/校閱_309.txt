# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【309-0028】02_戒疏/16a_卷四上之一#153
【原文】【疏】「妄語」一業，隨人並墮。由是本妄，續流難斷，故聖重制，欲使遮止。

【309-0030】02_戒疏/16a_卷四上之一#155
【原文】【疏】不同「毀」、「兩」即有輕重。若是同類，受惱情重，能礙布薩，故得提罪。餘之六眾，設有毀、破，情微諍薄，不礙於僧，故犯吉罪。
【譯文】【疏文】這不同於「毀謗」與「兩舌」有輕重的分別。如果是同類的僧眾，受到惱害的情緒深重，能夠障礙如法布薩僧事，所以結犯波逸提罪。其餘的六眾人等，縱使對他們毀謗、挑撥，彼此的情緒波動微弱、爭端較小，不致於妨礙整個僧團，所以只結犯吉羅罪。

【309-0031】02_戒疏/16a_卷四上之一#156
【原文】【記】毀兩中。初二句反前。「若」下，正示。初明境重。「礙布薩」者，眾法貴和，違惱多諍，且舉「布薩」統諸羯磨。「餘」下，次明境輕。「毀」即毀呰。「破」即兩舌，壞二邊故。

【309-0032】02_戒疏/16b_卷四上之一#1
【原文】【疏】「綺語」一業，掉戲壞心，過非乖越，未得僧制，通皆小罪。《成實》云：「口之三業，或時離合，綺語一業，必不相離。」如《多論》中，可尋《鈔》也。
【譯文】【疏文】「綺語」這一種口業，會讓人心神散亂放逸而敗壞道心，其過失越軌乖張；在尚未被僧團制定為戒律之前，通通都只結小罪。《成實論》說：「口業的四種之中，有時互為離合；但綺語這一種業，必定與其他三種不相脫離。」這就如同《薩婆多論》中所說，可以去查閱《事鈔》。

【309-0033】02_戒疏/16b_卷四上之一#2
【原文】【記】綺語中。初明輕重。「掉」是心蓋，故云「壞心」。對僧白法，境重故提；若對別人，或對僧未白，並境輕故吉。「成論」下，示離合。令「尋《鈔》」者，彼以三業離合作句，不入綺語，故知餘三通離合，綺語一向合也。
【譯文】【記文】在綺語戒中。首先說明罪過的輕重。「掉」屬於覆蔽心性的煩惱蓋，所以說它「敗壞道心」。若是在僧團正式表決作法（白法）的場合犯，因為對象與情境重大，所以結波逸提罪；若是對單獨的個人，或者對僧眾但尚未正式表決時犯，都因為對境較輕而結突吉羅罪。「成論下」這一段，是開示口業的離合關係。文中指示「去查閱《事鈔》」，是因為該處以口業三種來組成分開與合編的句型，並不把綺語單獨抽出來配對，由此可知其餘三種口業通於分開與合編，而綺語則是一向與其他業相合的。

【309-0034】02_戒疏/16b_卷四上之一#3
【原文】【註】佛在釋翅瘦。釋子象力善能談論，與外道論議不如時，便反前語；若僧中問，復違反語。梵志譏無正法，比丘舉過白佛。因制此戒。
【譯文】【註文】佛陀住在釋翅瘦。釋迦族的象力比丘非常擅長論辯，與外道辯論遇到不利的情況時，就推翻自己先前說過的話；如果在僧團中受到詰問，又再次違背先前的言辭。外道梵志譏嫌佛教中沒有正法，比丘們便將這過失稟告佛陀。佛陀因此制定了這條戒。

【309-0035】02_戒疏/16b_卷四上之一#4
【原文】【疏】就戒緣中，因論善法，便行妄誑，以為因起，況餘雜事而得成信？《五分》亦云：「我實知非，耻墮負處。」是何言也！佛制戒者，為止我倒。今反助我，重加妄習，何由脫免？
【譯文】【疏文】就制戒的緣起而言，因為探討善法，就隨機實行虛妄欺誑，並以此作為因由生起；何況是面對其餘世俗雜事，又哪裡能夠建立起信任？《五分律》也記載他說：「我其實知道自己不對，只是羞恥於落入失敗的境地。」這是什麼話啊！佛陀制定戒律，本來是為了止息執著自我的顛倒心。如今反而助長執我，更加重了虛妄的習氣，又從何能夠解脫出離呢？

【309-0036】02_戒疏/16b_卷四上之一#5
【原文】【記】戒緣中。初牒釋，特舉論法以況餘事。「五分」，亦即象力對僧之語。「是何言」者，疏家躡責以訓後來。「佛」下，敘制勸持。「反助我」者，即順惑也。「何由脫免」者，無出期也。
【譯文】【記文】在緣起之中。首先引述經文加以解釋，特別舉出連論辯善法都會打妄語，以此比況其餘雜事更難以取信。「五分律」的引文，也就是象力比丘對僧團所說的話。「這是什麼話」這句，是撰疏者順著文意加以責備，用以訓誡後世修學者。「佛陀」以下，敘述制戒的本意並勸勉持守。「反而助長執我」，也就是順從了迷惑煩惱。「從何能夠解脫」，意思是將永無出離痛苦的時期。

【309-0038】02_戒疏/16b_卷四上之一#7
【原文】【註】謂見、聞、觸、知，及不見、知八種。見者，眼識能見。乃至意識能知。不見者，除眼識，餘五識是。如是類反也。
【譯文】【註文】意思是「見、聞、觸、知」四種，以及「不見、不聞、不觸、不知」四種，合為八種境況。所謂「見」，是指眼識能夠看見。以此類推，直到「意識能夠了知」。所謂「不見」，是指除了眼識以外，其餘五識所對應的狀況。其他各項也都依此類推、彼此相反。
