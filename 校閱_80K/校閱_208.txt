# 校閱材料　第208檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【208-0001】03_業疏/13a_卷三之二#74
【原文】修敬中：初釋僧中，初出今解，僧、私兩通。預須受者，謂先私請也。「人」下次斥非，彼局僧中，不通先請。畢世師資，豈容心怠？故云似失，其實失也。「次」下次釋徧禮，初令盡敬，意在後持
【譯文】在「修敬」之中：首先解釋在僧眾中請師，先提出當前的見解，認為大眾僧中與私下延請兩皆融通。「預先受師」是指在受戒前私下延請。自「人」字以下斥責錯誤見解，彼說局限於受戒時的僧中，不通融受戒前預先請師。然而終身依止的師徒關係，豈能隨便任由弟子起懈怠之心？所以文中說「似失」，其實就是錯失了正理。自「次」字以下解釋遍禮大眾僧，受戒之初令其竭盡敬意，用意在於受戒之後能謹慎奉持。

【208-0002】03_業疏/13a_卷三之二#75
【原文】就加法中，請可為二
【譯文】就立法加被之法（加法）中，分為「請師」與「答可」兩部分。

【208-0003】03_業疏/13a_卷三之二#76
【原文】初請之法，律制傍教，縱屏令誦，識其文義，後在僧中，如法致請，亦是儀也
【譯文】第一項請師之法，律中規定應由旁人教導其文辭，縱然私下屏退眾人教他熟誦、理解文句義理，隨後在僧眾之中如法懇切致請，這也是合符威儀的。

【208-0004】03_業疏/13a_卷三之二#77
【原文】第二立法請法中初科：文令傍教，義通自誦，觀機利鈍，二竝無在
【譯文】在第二項「立法請法」的第一科中：律文雖命令由旁人教讀，但義理上通於受戒者自行背誦，應當觀察根機的利鈍，兩種做法皆無妨礙。

【208-0005】03_業疏/13a_卷三之二#78
【原文】請文有五：「大德念」者，請專意也；「為和上」者，明所祈也；「願為作」者，慈副本望也；「我依受具」者，三學由生也；五「慈愍故」者，已述所懷，惟聽許也
【譯文】請師之文包含五句：「大德念」一句，是請求師父專注用心地體察；「為和上」一句，是明示自己所祈請的名分；「願為作」一句，是祈請師父慈悲契合自己本來的願望；「我依受具」一句，是指依止和尚戒定慧三學得以生起；第五句「慈愍故」，是既然已陳述心中所願，唯願慈愍聽聞允准。

【208-0006】03_業疏/13a_卷三之二#79
【原文】次科請文五段：「初句」為一，「我某甲」下二句為二，「願」下二句為三，「我依」下二句為四，末一句為五
【譯文】第二科將請辭文句分為五段：「初句（大德念）」為第一段；自「我某甲」以下兩句為第二段；自「願」字以下兩句為第三段；自「我依」以下兩句為第四段；最後一句（慈愍故）為第五段。

【208-0009】03_業疏/13a_卷三之二#82
【原文】告辭有四：初「可爾」者，總領請辭，許為師也；「教授汝」者，非但事攝，有法弘訓也；「清淨」者，宜重戒本，攝持三業也；「莫放逸」者，諸過之源，由行放逸，當攝情根，遠五欲也
【譯文】告知之辭共有四句：第一句「可爾」，是總體領受其請辭，答允作為和尚；「教授汝」，是不僅在生活事務上攝受，更具有佛法正教弘傳訓誨；「清淨」，是應當珍重根本戒法，攝持身口意三業；「莫放逸」，是因為一切過咎的根源，皆由放逸懈怠而起，應當收攝情思根門，遠離世俗五欲。

【208-0010】03_業疏/13a_卷三之二#83
【原文】列釋有四：初答請，二許教，三誡業，四約心
【譯文】列示解釋分為四點：一是應答所請，二是允諾教化，三是告誡三業，四是約束身心。

【208-0011】03_業疏/13a_卷三之二#84
【原文】初答「可爾」中，「可」是答諾下流，「爾」是應酬上位。雙云「可爾」，未善知言，全不可也。至於懺持答中，義兼前二，以所對者有少長故
【譯文】在最初回答「可爾」中，「可」是對下輩的應答認可，「爾」是對上輩長者的承順應酬。如果將兩字合在一起說「可爾」，是未深通言語詞義，全然不可如此。至於在懺罪受持羯磨的答辭中，義理上兼具此二者，是因為所面對的僧眾有年少者亦有尊長者之故。

【208-0012】03_業疏/13a_卷三之二#85
【原文】三中：初釋當文。「可」是允許，「爾」即稟承。未善知言，斥翻傳也。「至」下次會他處，懺法兼二，對少云「可」，對長云「爾」，彼通少長故可兩標，此唯請師，不當雙列故也
【譯文】在第三項中：首先解釋本篇當文。「可」是允許，「爾」是稟命承受。所謂「未善知言」，是斥責翻譯轉述者用辭不當。自「至」字以下會通其他地方的羯磨答辭，懺悔法中兼具二辭，對年少者說「可」，對長老尊者說「爾」，彼處因通涉年少年長兩者所以可以雙列，此處只是弟子單向請師，不應當兩字併用。

【208-0013】03_業疏/13a_卷三之二#86
【原文】有人解云：律雖列四，隨一成答。意以通四，共成一答。如上解文，初是許辭，後三相攝，義聯類也
【譯文】有人解釋說：律文雖然列出四句，隨便說其中一句即可構成答辭。但我意認為應當融通這四句，共同組合成完整的答覆。正如上面解釋文義，第一句是允准之辭，後三句互相關連攝受，在義理上本是一體相續的。

【208-0014】03_業疏/13a_卷三之二#87
【原文】四中：初引他解。「意」下示今釋，義聯類者，言相貫也
【譯文】在第四項中：首先引用他人的解釋。自「意」字以下指示南山宗當前之正解，所謂「義聯類」，是指文辭義理前後貫通相通。

【208-0017】03_業疏/13b_卷三之二#1

【208-0020】03_業疏/13b_卷三之二#4
【原文】云「不得界外」者，此通白四之時；今約事緣，界外無失，如後段緣也。《五分》中，由為不如法人受故，因制戒壇外，十眾在壇上，界外問之。
【譯文】文中說「不得在界外」，這適用於正作白四羯磨之時；現在就準備事緣而言，在界外安排並無過失，正如後文所敘述的因緣。《五分律》中，因為曾為不如法的人受戒，佛陀因此制定受戒者在戒壇之外，十位僧眾在戒壇之上，於界外對其審問遮難。

【208-0021】03_業疏/13b_卷三之二#5
【原文】第二正釋中初科：白四時，謂正受時；不得界外，非謂問難時也。如後段者，即差問中云「將至界外看」等。引《五分》證不如法人，彼因界外借衣鉢故，由本在餘處起過，故制壇外、十眾壇上、對僧前也。界外問者，即壇外也
【譯文】在第二「正釋」的第一科中：「白四時」是指正受具足戒的時刻；「不得在界外」，並不是指差問遮難的時候。所謂「如後段者」，就是指差遣教師問難章節中說「領到界外察看」等語。引用《五分律》來證實不如法之人，該律是因為有人在界外借用他人衣鉢，由於當初在其他地方生起過患，所以制定受戒者立於壇外、十位僧眾坐於壇上、面對僧眾之前。所謂「在界外問」，即是指在戒壇之外問難。
