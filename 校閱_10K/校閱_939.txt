# 校閱材料　第939檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【939-0001】資持記/02c_上一下#44
【原文】然今多據眾法明之；對首心念，同須應法；疏云：一人說戒辦與百千敷教齊等，故可知矣。然下文中多明不足，為顯成足，故約堪能以目篇首。眾相者。有本作僧相，人即解云僧翻眾故。今則不然，四例簡辨，其相非一，故云眾耳。別眾附者，足別相關，以類相從故。
【譯文】然而現今大多依據僧眾大眾法來闡明；對首法與心念法，同樣都必須合乎法度；義疏說：一人秉持說戒，其成辦功德與百千僧眾敷設教化齊等，所以理當明瞭了。然而下文中大多闡明不足數的情形，為了顯明其能成就足數，所以依據具備資格堪能的角度來命名篇首。所謂「眾相」。有的版本作「僧相」，他人便解釋說僧伽翻眾的緣故。現今則不這樣認為，此處是以四個條例來簡別辨析，其相貌並非單一，所以才稱為「眾」罷了。別眾附帶於此的原因，是因為滿足僧數與個別結眾息息相關，依照同類性質相從歸納的緣故。

【939-0002】資持記/02c_上一下#45
【原文】敘來意中，上二句明相生。僧雖已集，真偽相參；法假人弘，人乖法敗；制令簡練，其意可知。若下，示二途；初至僧用，明體非相足。此為一途，即第三例。必下至僧攝，明相乖體淨。此為一途，即初例也。託事於緣，並約三業外相為言。以下，躡前發後。料簡即下四例。是非約所簡。
【譯文】在敘述由來的意旨中，上兩句闡明相伴相生的道理。僧眾雖然已經集會，但真偽彼此參雜；佛法必須假借人來弘揚，若人員不合規範則法事敗壞；制定戒律令僧團審查簡別，其用意極其明顯。「若」字以下，示明兩種途徑；從起初至「僧用」，說明本體不是而相貌充足。這作為一條途徑，也就是第三個條例。從「必」字以下至「僧攝」，說明相貌乖違而本體清淨。這作為一條途徑，也就是第一個條例。藉由僧事依託於因緣，都是就身口意三業的外在相貌而言。「以」字以下，承接前文開啟後論。「料簡」就是指下方的四個條例。「是非」是就所簡別的對象而言。

【939-0003】資持記/02c_上一下#46
【原文】取捨據僧用。就四例中，即前二途開出二例。初句出第四，並體如故。第三出第二，俱體非故。舉要為言，初體是相非故捨；第三體非相是故取；第二俱非故捨；第四俱是，亦取亦捨，對文可知。二云體境者，體謂戒體，境即人境。初例，據文中。
【譯文】「取捨」是依據僧伽的錄用與否而定。就在這四個條例中，就是從前面的兩種途徑開展出二個條例。第一句列出第四條例，兩者本體皆如法故。第三句列出第二條例，兩者本體皆非法故。舉其要旨而言，第一種是本體如法而相貌非法，所以捨棄不用；第三種是本體非法而相貌如法，所以暫且錄用；第二種是體相皆非法，所以捨棄不用；第四種是體相皆如法，也可以錄用也可以捨棄，對照內文便可明瞭。第二例所說的「體境」，「體」是指戒體，「境」就是指人員的境界。第一個條例，依據文中的記載。

【939-0004】資持記/02c_上一下#47
【原文】標《四分》者，即〈瞻波犍度〉，彼作四句：一得滿不應訶〔四羯磨人，見第四例。〕；二不得滿應訶〔欲受大戒人開訶，即下沙彌，唯此一法。〕；三不得滿不應訶〔二十八人。今鈔取六人體如，在初例；二十二人體非，在第二例。〕；四得滿應訶〔善比丘也；篇中所簡，正取此人。
【譯文】標明《四分律》的，就是指〈瞻波犍度〉，該處列出四句：第一是能滿足僧數但不應訶止〔指受四種治罰羯磨處分的人，見第四條例。〕；第二是不能滿足僧數而應當訶止〔想受大戒的人開許訶止羯磨，就是指下文的沙彌，唯獨只有這一部法。〕；第三是不能滿足僧數也不應訶止〔共有二十八人。如今鈔文選取了六位戒體如法人，列在第一條例；二十二位戒體非法人，列在第二條例。〕；第四是能滿足僧數且應當訶止〔指清淨善比丘；篇中所要簡別選取的，正是這種人。

【939-0005】資持記/02c_上一下#48
【原文】今須分二：一體相俱善，二體乖相善，即第三門，並成訶足。〕六人名相，下文自釋。約義中，初科捨戒文有兩出，一出淫戒，二出受法。若受法中，更有醉人，《注羯磨》備引；彼云受戒捨法內云：睡眠醉狂，悉不相領，並不成等。今此且引淫戒中文。或因錯解，妄加改作；或恐寫脫。
【譯文】如今必須分為兩種：一是體相俱皆純善，二是體性乖違而相貌清淨，即第三門，這兩者都能成就訶阻與滿足僧數。〕六人的名稱相貌，下文自會解釋。在「依據義理判定（約義）」中，第一科有關「捨戒」的律文有兩處出現，一處出自淫戒，一處出自受戒之法。如果是在受戒法中，更有醉酒之人的情況，《注羯磨》中已有備載引用；該處說受戒與捨戒的法度中提到：睡眠、醉酒、狂亂者，全都無法領會納受，都不能成就等等。如今此處暫且引用淫戒中的文字。或許是因為錯誤理解，妄自加以改動；或者是抄寫時脫漏。

【939-0006】資持記/02c_上一下#49
【原文】顛狂是一人〔律文次列亂心痛惱二人，今以顛狂總之。〕，瘂聾互具為三人，中邊互望為二人。律文甚廣，取要且列九人。謂下，示義也。《十誦》文見五十四。彼先問云：若眾僧睡眠，擯一比丘，得名擯不？若聞下，引彼答詞。聞白成者，既知所為，情和已彰故。
【譯文】癲狂算作一人〔律文接著列出亂心、痛惱二人，如今以癲狂總括之。〕，啞與聾互相具備算作三人，中原與邊地互相對望算作二人。律文極其浩瀚，截取其綱要暫且列出九人。「謂」字以下，是示明其義理。《十誦律》的文字見於第五十四卷。彼處先提問說：如果僧眾在睡眠之中，擯黜一位比丘，能稱為擯黜成功嗎？「若聞」以下，引用彼處的回答之辭。聽聞宣白羯磨即能成就者，是因為既然已知所作何事，和合之情已經彰顯的緣故。

【939-0007】資持記/02c_上一下#50
【原文】具二者，瘂聾兼也。結文寫誤，合云十一；然彼實有十二，而白衣一人，由體非故，摘歸後科。餘如後解。《伽論》三人。取其異者，同則指前。然彼有轉根人，即落第二尼中，故不重引。《僧祇》。前五如後解。互作者，四中隨舉一儀作法，餘三成別；則一儀有三，歷為十二；
【譯文】具備兩種情況的，是啞與聾兼具之人。結語文字抄寫有誤，應當說是十一人；然而彼處實際上載有十二人，而白衣居士一人，由於戒體非法的緣故，被抽離歸入後面的科判。其餘情況如同後文的解釋。《摩得勒伽論》（伽論）列出三人。選取其中不同之處，相同者則指向前文。然而彼處有轉根之人，那就歸入了第二條例的比丘尼之中，所以不再重複引用。《僧祇律》中所列的，前五種情況如同後文的解釋。所謂互相更替而違犯，就是在四種威儀中隨舉一種威儀來作法，其餘三種便形成別眾；那麼一種威儀就有三種相違，歷遍推算便為十二種；

【939-0008】資持記/02c_上一下#51
【原文】疏云：且從四儀，即合前九。義加二人，初醉人。出受法捨戒中。二自語下四句是一人。即如上引捨戒文也。上二句明自不解，下二句明他不解。是下一句，正彰義斷。餘人並有諸部文證，此二獨無。理非可足，故名義加；非謂祖師自意加之。
【譯文】義疏說：暫且依循四種威儀，就合成了前述的九人。依義理追加了兩人，第一是醉酒之人。出自受法捨戒條文中。第二「自語」以下四句是同一個人。正如上面引用的捨戒律文。上兩句說明自己不理解，下兩句說明他人不理解。「是」字下一句，正式彰顯依義理所作的決斷。其餘的人都有各部律典的明文為證，唯獨這兩人沒有。但在法理上絕不能列入足數，所以稱為「義加」；並不是指祖師隨順己意私自增加。

【939-0009】資持記/02c_上一下#52
【原文】〔《古記》云：義加三人，將不解之人為不解律人，非也；一不識義加，二讀文句破，三不曉癡鈍即不解律人；如下所解，及《業疏》中；已上總三十一人。〕初科別解《四分》，所為中，初標。以下，釋，上明不足所以。文約乞法，據攝多種，今分三別。一乞法〔處分畜眾求懺等陳詞乞，受日無詞乞。〕，二不乞直與〔如諸差人及治諫等。
【譯文】〔《古記》說：義理追加了三人，把不能理解語言的人誤當作不通曉戒律的人，這是錯誤的；一是未能辨識義加的涵義，二是斷句讀破了文句，三是不懂得「癡鈍」正是指不通曉戒律之人；如同下文的解釋，以及《業疏》所載；以上總共有三十一人。〕第一科分別解釋《四分律》中「羯磨所為之人」，起初標明。以下，解釋，前半段說明不足數的原因。文句依據乞求僧法而言，實際上含攝了許多種情形，如今區分為三種差別。第一是陳詞乞法〔如處分、蓄徒眾、求懺悔等陳述言詞請求，請受日法則無言詞請求。〕，第二是不必請求直接給予〔如各種差派人員以及懲處諫勸等。
