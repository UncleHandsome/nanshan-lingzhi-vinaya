# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【491-0001】03_業疏/09a_卷二之三#34
【原文】此之三淨，必是真他，不容倚傍濫託檀越。若道寺是俗造即云他淨，一切僧坊俱非道有，於中盜損望俗推繩，乃至佛法咸無福也。財物無在，隨施成主，何得仍舊為檀越淨
【譯文】這三種淨地，必須是真正屬於他人，絕不容許攀附依傍、混濫假託為施主所有。如果說寺院是俗人建造就稱為「他淨」，那麼全天下所有的僧坊就全都不屬於僧道所有了，若在其中有盜竊損壞僧物，就得對著俗人來推究治罪，乃至於在佛法中布施全都無福可言了。財物無論原本在於何處，一旦布施入僧就隨之轉移業主，怎能依舊執持舊主而當作「檀越淨」呢？

【原文】次科，初明委實。「若」下，次斥妄計。律中盜損僧物，不望俗結；又施入三寶，俗皆獲福。今若屬俗，事皆反之。「財」下，三結責
【譯文】在第二科中，首先說明必須切合實際。自「若」字以下，接著斥責虛妄的計執。律中盜竊損害僧物，並不對著俗人來結罪；而且財物布施歸入三寶，俗人都能獲福。如今若說仍屬於俗人，則這些道理全都反過來了。自「財」字以下，第三是結語責備。

【491-0003】03_業疏/09a_卷二之三#36
【原文】有人言：不結有罪，若結難護；又言：由有倚傍，勝不結者
【譯文】有人說：不結淨地便有犯罪之過，如果結了又難以守護戒律；又有人說：由於有所倚傍託詞（託名他物），總比不結淨地要好。

【491-0004】03_業疏/09a_卷二之三#37
【原文】三中初文，彼謂結與不結，二皆不可；倚傍他物，且得無罪，故勝不結
【譯文】在第三科的第一段文中，古師認為結淨地與不結淨地兩者都不可行；依傍假託他物淨，暫且可以免於獲罪，所以勝過不結淨地。

【491-0005】03_業疏/09a_卷二之三#38
【原文】今解不然。佛制智明，不唯暗塞；親知是非，罔冐聖儀，非唯反增愚暗，更遭不學諸罪。於彼宿煑，終結根本，何有脫也？若言護難，可以難而不結，世中五欲盛啟五情，橫割斷之，得行佛教，豈唯食飲口腹之累，用涉言哉
【譯文】今家的理解則不是這樣。佛陀制戒智慧明晰，絕非愚暗閉塞；明知是非對錯，卻冒犯毀損聖教儀軌，非但反而增長愚癡暗昧，更會遭受不學無知的種種罪過。對於那內宿、內煮之過，終究要結成根本重過，哪裡能夠逃脫免除呢？如果說因為守護困難，就可以因難而不結淨地，那麼世間五欲熾盛發動五情，尚且要強行割捨斷除，才能奉行佛陀教法，難道僅僅為了飲食口腹之拖累，就值得拿來當作托辭嗎？

【491-0006】03_業疏/09a_卷二之三#39
【原文】二中，初、斥倚傍。「佛制智明」，言其制法顯了也；「不唯暗塞」，言其不當罔冐也。然彼自謂倚傍為他物淨，故云「親知是非」等。「反增愚暗」，即癡業也；「不學」更兼無知，故云「諸罪」。此二枝條，并下根本，竝制罪也。「若」下，次斥難護。佛所立教，勉力奉持，豈得畏難，輙自除削？仍舉五欲，責其任情。絕欲則能奉教，畏教即是順欲；況飲食四塵，發欲之甚，過患灼然，不言可見。「啟」，發也；「累」，即是患
【譯文】在第二科中，首先斥責依傍假託。「佛制智明」，是說佛陀制定之法顯豁明了；「不唯暗塞」，是說不應當冒犯毀壞。然而彼師自以為可以依傍假託為他物淨，所以說「親知是非」等等。「反增愚暗」，就是愚癡之業；「不學」更兼具無知之愆，所以說「諸罪」。這兩項枝條之過，加上後文的根本之罪，全都屬於違制之罪。「若」字以下，接著斥責畏難不護。佛陀所建立的教法，應當勉力奉持，哪裡可以因為畏懼困難，就隨便自行削免？進而舉出五欲，責備其放任情欲。斷絕情欲便能奉持教法，畏懼教法實際上就是順從私欲；更何況飲食牽涉色聲香味四塵，最容易引發欲望，過患顯而易見，不說自明。「啟」，就是發動的意思；「累」，就是禍患。

【491-0007】03_業疏/09a_卷二之三#40
【原文】疏者立言：寧結減罪。何以知耶？由結淨地，通無內煑，一有益也；善者懼罪，雖宿有淨，惡者慢犯，雖觸無染，二有益也。結防兩失，俱離無瑕，如何妄指，自貽伊責
【譯文】撰疏者立論主張：寧可結立淨地以減少罪過。何以得知呢？由於結立了淨地，界內通統沒有內煮之過，這是第一種利益；持戒善良之人畏懼犯罪，即使食物在界中過夜也有淨地可宿，破戒造惡之人傲慢犯戒，即便觸碰僧食也不致染犯內宿之罪，這是第二種利益。結立淨地能防範上述兩種過失，使二者皆得遠離罪咎而無瑕疵，怎能妄自非難，自招這番責難呢？

【491-0008】03_業疏/09a_卷二之三#41
【原文】三中，初通示；「何」下別釋。一、無內煑，對下內宿約人不定，故云通無。二、無宿觸，持戒為善，「雖宿有淨」，謂結淨已，大界無內宿也；破戒為惡，「雖觸無染」，亦謂大界無宿觸也。以未結時，善者避犯，不敢與宿，惡者慢犯，與宿成觸；今既結已，二皆成淨。「結」下，雙結。上二句示今益，下二句責古非。「貽」，贈；「伊」，是也
【譯文】在第三科中，首先作總體指示；自「何」字以下分別解釋。第一是沒有內煮之罪，相對下文內宿依人而定不同，所以說普遍皆無。第二是沒有內宿與宿觸之罪。持戒之人稱為善，「雖宿有淨」，是說結立淨地之後，大界之內就沒有內宿之過；破戒之人稱為惡，「雖觸無染」，也是說大界之內沒有宿觸之罪。因為在未結淨地時，善人躲避犯戒，不敢與食物同宿，惡人傲慢犯戒，與食物同宿便構成宿觸；如今既然結了淨地，兩者都轉為清淨。「結」字以下，雙向結語。上兩句顯示今家的利益，下兩句責備古師的謬誤。「貽」，是贈送、招致；「伊」，是「這」的意思。

【491-0011】03_業疏/09a_卷二之三#44
