# 校閱材料　第1619檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1619-0001】03_業疏/04b_卷一之四#106
【原文】文云須知別眾足數四句者，上雖通列，名含是非，但為緣差，濫通淨行，故以法簡，不宜混雜，就分兩對
【譯文】文中說「須知別眾與足數的四句分別」者，上面雖然總體列出，但名稱中包含著合法與非法的不同情況，只是因為因緣差失，以致混濫貫通了清淨行持之人；所以必須用法式加以揀別，不應當混淆雜亂，因此分為兩對四句。

【1619-0002】03_業疏/04b_卷一之四#107
【原文】次足別句中初文敘前列相。或體非而相是，或體淨而緣差，同歸非數，故云名含等。所以淨行之人濫通數內，事雖非足，不妨成別，故以足、別作句簡辨
【譯文】在下一段「足數與別眾句法」中，第一段文敘述前文所列的行相。或者體性是非法而外相是合法，或者體性清淨而因緣差失，兩者同樣歸入不足之數，所以說「名含」等。清淨行持之人之所以會混濫通入僧數之內，是因為事相上雖然不能充任足數，卻不妨礙其構成別眾，所以用「足數」與「別眾」列成四句來揀除辨析。

【1619-0003】03_業疏/04b_卷一之四#108
【原文】初是別眾非足數，如應來不來等二人、隱沒、離見聞、殘行法中七人（亦有通局，如前）、《僧祗》中隔障四別等，實如應法，能礙僧事，故名別眾，身不在僧，非數收也
【譯文】第一句是「構成別眾而非足數」，例如應當前來而不來的兩個人（應來不來、應遣欲而不遣欲）、身形隱沒、脫離見聞範圍、僧殘懲治行法中的七個人（也有通局的分別，如前文所說）、《摩訶僧祇律》中因隔障等構成別眾的四種情況等；這些人本來實在是應法之僧，能對僧事產生障礙，所以稱為別眾；但其身形不在僧中，所以不能算入足數。

【1619-0004】03_業疏/04b_卷一之四#109
【原文】初四句中，第一句收十五人。應來及應欲為二人，本非不足之數，對別作句，故此入之。殘行七人，據行不足，猶通生善，不應滅惡，故有通局。餘八不現，約相不足。足別之言，隨句各異，臨文裁酌，不必一槩
【譯文】在第一個四句中，第一句共收攝十五人。應來不來與應送欲為二人，本來不屬於不足數的範圍，只是為了對應別眾來造句，所以在此納入其中。僧殘行法中的七人，根據其行法而言不足數，但仍然可以通融參與生善法事，只是不應當參與滅惡法事，所以有通與局的分別。其餘八人因身不顯現，是就相狀而言不足數。所謂「足數」與「別眾」的言詞，隨著各句而有所不同，面臨文義時應當細心裁度考量，不必一概而論。

【1619-0005】03_業疏/04b_卷一之四#110
【原文】二是足數非別眾，即律中善比丘同住等。由身參眾侶，行德昭彰，故兼兩位也
【譯文】第二句是「合於足數而非別眾」，也就是律中所說同界共住的清淨善比丘等。由於自身參與到僧眾行列之中，行持品德昭著顯明，所以兼具這兩種身分。

【1619-0006】03_業疏/04b_卷一之四#111
【原文】次句，身參眾侶故是足，行德昭彰故非別
【譯文】在第二句中，自身參與僧眾行列所以是足數，行持品德昭著顯明所以非別眾。

【1619-0007】03_業疏/04b_卷一之四#112
【原文】三亦別眾亦足數者，如現前得訶者訶，身廁僧中，通在數限，口須忍默，乃有訶制，即非同和；乃至僧坐而彼行立、背面僧中等是也
【譯文】第三句是「亦是別眾亦是足數者」，例如現前有權出言訶阻的人出言訶止，其身處在僧眾之中，通計在足數的界限內，口中本須隨順忍默，卻出言發起訶阻裁制，這就不是共同和合了；乃至僧眾坐著而他卻走動或站立、背對僧眾等，也是如此。

【1619-0008】03_業疏/04b_卷一之四#113
【原文】三中六人。應訶外入，義亦同前。此等身現故足，相乖故別
【譯文】在第三句中收有六人。應當訶阻者自外進入，義理也與前面相同。這些人因為身形顯現在前所以是足數，因為行相乖違不和所以是別眾。

【1619-0009】03_業疏/04b_卷一之四#114
【原文】四非別眾非足者，如《四分》尼等四人、邊等十三、二滅、三舉等，或是報別法乖，或是行違治重，體既乖僧，不能為別。《十誦》諸人竝是應法，但為差脫，故不在僧。如睡眠、亂語、憒閙，此三由入無記，不緣善惡，雖在眾中，不成作業也；入定善人，別有靜慮，至於忍默，不同僧和，然身雖在僧，不可為足，見聞又絕，不名別眾；瘂等三人，根壞非證，聽、說二緣，正乖羯磨；狂等三人，由神 Linux 亂故，不了自性，何預兩能？白衣本是無戒，可謂相似比丘同住；樹上須知比丘在界內外，若枝委界外地者，身在界內，是名別眾，界外非別，若不委地，內外俱別，而是不足數收；重病、中邊，及以癡鈍、醉、不解語，竝非二攝也
【譯文】第四句是「非別眾亦非足數者」，例如《四分律》中的比丘尼等四眾、犯邊罪等十三難人、兩種滅擯（已滅擯、應滅擯）、三種舉罪等人，或者由於果報形別、戒法乖違，或者由於行持違犯、治罰深重，本質上既然已與清淨僧團乖違，就不能算作別眾。《十誦律》中所列的諸人本來都是如法之僧，只是因為差失疏脫，所以不能算在僧中。例如睡眠、語無倫次、心神憒亂喧鬧，這三種人由於心識墮入無記之中，不能攀緣善惡之心，雖然身在大眾之中，卻無法成就羯磨作業；入定的善比丘，另有自心專注的靜慮，至於隨眾忍默表決，則不能等同於僧團的和合，然而其身雖然在僧中，卻不可充當足數，對外界見聞又已斷絕，所以也不名為別眾；啞巴等三人，由於根器殘壞不堪作證，羯磨中「聽聞」與「宣說」兩種因緣，正好與其殘缺相乖違；發狂等三人，由於心神昏亂的緣故，不能明了自身心性，哪裡談得上能聽與能說這兩種功用？白衣原本就無具足戒，好比只是形態相似的比丘；同處一界而住在樹上者，必須知道比丘是處於界內還是界外：如果樹枝垂覆於界外的地面，而人身在界內的樹枝上，這稱為別眾，身在界外則不構成別眾；如果樹枝沒有著落於地面，那麼人在界內界外都構成別眾，但都是由不足數所收攝；至於重病、中國與邊地言語不解之人，以及癡鈍、大醉、言語不能領解的人，全都不為這兩類所收攝。

【1619-0010】03_業疏/04b_卷一之四#115
【原文】四中，初《四分》二十二人。報別即尼等三人，法乖即沙彌及十三難，行違即二滅，治重即三舉。《十誦》十二人，次第牒解，一一各顯二非所以。入定中，雖是善行，而非證法，故云別有等。如色、無色定，各有所緣，澄心凝住，故云靜慮。瘂等人中，以羯磨法誡聽勸說，故云乖也。狂中兩能，亦即說、聽。白衣中，如律戒本釋比丘中，有相似比丘，謂剃染形同，本無戒者。非別非足，易知不解。同住樹上，即界內樹也。枝委外地，即涉兩界；若不委地，但從根判。重病下，即《伽論》三人、義加二人，非二可知
【譯文】在第四句中，首先是《四分律》中的二十二人。所謂「果報形別」，就是指比丘尼等三人；所謂「戒法乖違」，就是指沙彌及十三難人；所謂「行持違犯」，就是指兩種滅擯；所謂「治罰深重」，就是指三種舉罪。《十誦律》中的十二人，依次逐一標牒解釋，各自顯明兩者皆非的原因。在入定的人當中，雖然是修持善行，但並非當前作證僧法的心態，所以說「另有」等。如同色界定與無色界定，各有所緣之境，澄清心念凝寂安住，所以稱為靜慮。在啞巴等人當中，因為羯磨法誡飭專心聽受、勸勉如法宣說，所以說「相乖」。發狂等人當中的「兩種功用」，也就是指宣說與聽受。在白衣當中，如同律典戒本解釋比丘時，提到有「相似比丘」，是指剃除鬚髮、身著染衣與比丘外形相同，而本質上沒有具足戒的人。既非別眾亦非足數，道理顯而易見所以不再詳解。一同共住於樹上，是指生長在界內的樹。樹枝若垂覆落在界外地面，就牽涉到兩個結界；如果樹枝不垂落到地面，就只依樹根所在之處來判定。自「重病」以下，即是指《摩德勒伽論》中的三人以及義理增加的二人，兩者皆非的道理是可以得知的。

【1619-0011】03_業疏/04b_卷一之四#116
【原文】上以足數對別為一四句，今以不足數對別又為四句
【譯文】以上是以「足數」對「別眾」構成一個四句，現在以「不足數」對「別眾」又構成一個四句。

【1619-0012】03_業疏/04b_卷一之四#117
【原文】次四句標中，以前四句攝人未盡，故復出之。初、後二句唯收四人，中二同前，如文所指
【譯文】在接下來的第二個四句標示之中，因為前一個四句收攝人數未能窮盡，所以再次列出。第一句與最後一句僅僅收攝四人，中間兩句與前面相同，如同下文所指。
