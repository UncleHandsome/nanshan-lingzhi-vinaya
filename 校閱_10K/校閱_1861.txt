# 校閱材料　第1861檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1861-0001】03_業疏/19b_卷四之二#55
【原文】二就疑罪者，此疑從事生，必對方除也。如旦食粥似於正食，至中還噉，有疑犯足，須待淨人方定罪目。但露無瑕，便應淨法。故雖白露本罪不滅，由未了知，不名懺斷。不同前白，識達無疑，告情及罪事，同對首有斯異也。《十誦》云：一切僧同犯，單白向四方僧，後如法懺。故知不滅矣
【譯文】第二、就「疑罪」而言，這種懷疑是因事而生，必須對著清淨僧人才能遣除。例如早晨喝的粥稠厚得如同正食，到了日中時分又再進食，這時就會懷疑是否犯了足食戒，必須等待淨人判定才能確定罪名。但只要發露而無隱瑕，就符合清淨之法。因此，雖然作了白告發露，但本罪並未消滅；由於尚未明了罪相，所以不名為懺斷除罪。這不同於前面的作白——前面是清楚明了而無疑惑，陳告實情及罪相，其事相功效等同於對首懺悔，兩者有這般差異。《十誦律》說：全體僧眾同犯時，以單白羯磨向四方僧發露，之後仍須如法懺悔。由此可知本罪並未消滅。

【1861-0002】03_業疏/19b_卷四之二#56
【原文】疑罪中，初敘過相，粥似正食，謂稠厚者初出釜時物𦘕成字，即為正食，未問淨人，成否不決，故云疑也。雖露不滅，與前故異。《十》下引證，向四方僧即發露也
【譯文】在疑罪的科文中，首先敘述罪過的事相。「粥似正食」，是指稠厚之粥剛出鍋時，用物劃過能劃出字跡，這就算是正食；由於尚未詢問淨人，罪名是否成立懸而未決，所以稱為「疑」。雖然發露了但罪未消滅，所以與前面的發露有所不同。自「《十》」以下引律文為證，向四方僧白告即是發露。

【1861-0003】03_業疏/19b_卷四之二#57
【原文】今時奉教者云「我不清淨，不合聞聽」，此未了行教也。律不徒然，必為來世，但恐大重，不應單白。縱重學悔，猶稱清淨，豈令身死，總收取乎
【譯文】現今奉持戒教的人說「我身不清淨，不應當聽聞說戒」，這是不明了施行戒教的真意。戒律的制定絕非徒勞無益，必定是為了庇蔭未來世；唯恐犯了極重大罪（波羅夷等），才不許以單白發露。即使犯了重罪而行學悔法，依然稱為清淨，哪有任憑罪垢積存至身亡，最終全數招受惡報的道理呢？

【1861-0004】03_業疏/19b_卷四之二#58
【原文】次科，初敘妄執，耻己不淨，遂不聽戒。此下責愚，教大重即四夷，懺重名學悔。犯不思懺，積累至死，業隨識去，即總收也
【譯文】其次一科，首先敘述妄執：因以自身不清淨為恥，於是不去聽戒。自「此」以下責備其愚癡。戒教中的「大重」即四波羅夷罪，懺除重罪（僧殘）稱為「學悔」。犯了過失不思懺悔，積累直到身死，罪業隨心識而去受報，這就是「總收」。

【1861-0005】03_業疏/19b_卷四之二#59
【原文】問：今諸罪人，意謂不犯，傍人審知，欲舉違教，以律文云「不得逼懺」者？答：兩有其致也。意謂無罪，心淨聞戒，不得嬈之，令生疑負：一不得聽戒，二不得懺悔
【譯文】問：現在有些犯罪的人自以為沒有犯，旁人明審知曉其犯，想要舉發其違背戒教，但律文又說「不得逼迫人懺悔」，這該如何處理？答：這兩方面各有其道理。犯罪者自認為無罪，以清淨的心聽聞說戒，旁人就不得擾亂他，致使他生起疑惑與負擔：一是導致他不能聽戒，二是導致他不能如法懺悔。

【1861-0006】03_業疏/19b_卷四之二#60
【原文】三中，初問罪人謂迷犯者，旁人謂知律者。不舉不合同聞，舉之又違律制不得逼懺，須彼自悔也。答中不舉兩致，即如下例
【譯文】在第三科中，首先提問：「罪人」指迷昧而自認未犯者，「旁人」指通曉戒律的人。不舉發他，則不合乎同座聞戒之法；舉發他，又違背了律制不得逼懺的規定，因為必須由他自願懺悔。答文中說明不舉發有兩種緣由，即如下文所列。

【1861-0007】03_業疏/19b_卷四之二#61
【原文】若爾，何故不知不脫者？答：若語自行，不以不智，隨犯依治也。若據眾法，謂不犯得聞說戒，無違心故；不犯謂犯，不得聞戒，心不淨故。又據自行，實犯謂無、不犯謂有，俱須兩識，不可任情。前言不得強逼者，恐發諍競，故且任之。不同殘中忘謂無覆，雖逼無諍，故戒文中強與覆法。
【譯文】問：既然如此，為什麼又說不知罪就不能脫罪呢？答：如果就個人自修的行持而言，不能因為不知犯戒而免咎，隨其所犯依律治罪。如果依據僧眾大眾法來說，自認為沒犯的人得以聽聞說戒，因為其內心沒有相違背之故；本未犯卻自以為犯的人，則不得聽聞說戒，因為自心不淨之故。再者依據個人自修，確實犯了卻自認未犯、未犯卻自認犯了，這兩種情況都必須辨明了知，不可聽任私情妄執。前面所說的不得強行逼迫，是唯恐引發諍端爭執，所以暫且由他；這不同於僧殘罪中遺忘而自認未覆藏的情形，那時即便逼問也不會引起諍訟，所以戒文中強制給予覆藏治罪之法。

【1861-0008】03_業疏/19b_卷四之二#62
【原文】次問意謂既許聞戒，罪何不脫？答中有二：初約眾自二行對明：自行據體，有犯隨治；眾行取和，不疑許聽，無犯疑有，約心不開。又下次單就自行以辨，實犯謂無，理須舉悔；不犯謂有，義不妄施。前下決上律文，且為護眾，仍簡僧殘次死須救，故逼無諍也
【譯文】接著提問，意在指出既然准許聽聞說戒，罪過為何不能脫免？答文中分為兩層：首先約大眾行與個人自行相對辨明：自行依據戒體，有犯就隨律治罪；大眾行取僧團和合，自無疑惑者准許聽戒，本無犯而起疑為有犯者，依其心態不予開許。自「又」以下，單就個人自行來辨析：確實犯了卻自認未犯，理應舉發懺悔；未犯卻自認有犯，義理上不可隨便施予治罰。自「前」以下決斷前引律文之意，暫時不逼是為了護持僧眾和合，進一步簡別僧殘罪是僅次於四棄之重罪，必須救治，因此縱使逼問也不會有諍訟。

【1861-0009】03_業疏/19b_卷四之二#63
【原文】尼請教法，就文差緣，應白二下，後往僧相。文行略法廣者，闕矣
【譯文】比丘尼請求教誡的儀法，依經文派遣的因緣，應當行白二羯磨差遣，隨後前往僧眾的儀態相狀。經文中實行略法，廣法就付闕省略了。

【1861-0010】03_業疏/19b_卷四之二#64
【原文】尼請法中，初科就文差緣，即前羯磨「應白二下」，即後注文「往僧相」者，尼往僧中之儀式也。廣法即僧中請人作法差往教誡等，法律本具之，當世不行，故但存略。今時廣略俱廢，止可聞知，用為來習耳
【譯文】在比丘尼請法的內容中，第一科依文說明派遣的因緣，即前述羯磨中的「應白二」以下文句；隨後的注文「往僧相」，是比丘尼前往比丘僧中的儀式。廣法是指比丘僧中請人、作法差遣前往教誡等，戒律本來完備具足，但當時已經不施行，所以只保留略法。如今這個時代，廣法與略法都已廢弛，只能聽聞知曉其事，留作未來修習的借鑑罷了。

【1861-0011】03_業疏/19b_卷四之二#65
【原文】云「各滿五人方羯磨差」者，以尼被差，即所為故，非數攝也。僧雖有五，一須具德二十夏者，若無此夏，雖復多人，亦不合受，以德不滿故
【譯文】文中所說「各自滿五人方可行羯磨差遣」，是因為被差遣的比丘尼，就是羯磨所為之人，不計入羯磨法定人數之中。比丘僧雖然有五人，其中一人必須具備德行且滿二十戒臘；如果沒有這個戒臘，即使人數再多，也不符合接受請法（或接受差遣教誡）的資格，因為德行戒臘不圓滿的緣故。

【1861-0012】03_業疏/19b_卷四之二#66
【原文】次科，尼中差使、僧必差師，二竝所為，皆不入數，故須各五方可行之。若但行略，不必僧滿
【譯文】其次一科說明，尼眾僧中差派使者、比丘僧中必定差派教誡師，這兩者都是羯磨的所為之人，都不計入出席法定人數，所以各自都必須有五人方能成辦羯磨。如果只是施行略法，就不必比丘僧人數滿額。

【1861-0013】03_業疏/19b_卷四之二#67
【原文】就兩處教誡，皆列上座者，指本律文，以眾首比丘綱維法務，每有事達，無不承撫，即如前述替補佛也
【譯文】關於在兩處教誡中都列出上座，是指本律的原文；因為身為眾首的比丘統領持維法務，每逢有事情傳達，無不承受撫慰，正如前文所述之代佛行化。

【1861-0014】03_業疏/19b_卷四之二#68
【原文】次座上法教尼中，初文兩處教誡，即注中前云上座作略教法，後云上座有教勑。指本律者，示所據也。以下出所以，達至也，承領撫恤，以應前事
【譯文】其次在座上如法教誡比丘尼的文段中，初文所說「兩處教誡」，即注文中前文所說「上座作略教法」，後文所說「上座有教敕」。指明出自本律，是顯示所依據的教典。自此以下說明緣由：「達」是到達，「承」是承受領受，「撫」是撫恤，用以應對前面的事務。
