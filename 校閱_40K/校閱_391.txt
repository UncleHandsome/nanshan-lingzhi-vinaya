# 校閱材料　第391檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【391-0001】03_業疏/06b_卷一之六#83
【原文】結勸中，初釋條貫諸緣，即百三十四法如葉如物，七非統攝如條如貫，總必攝別，故令尋本。「下」下釋誡勸。本律四十三云：「爾時有住處僧為比丘作法非別眾羯磨，時眾多僧共諍，或言非法別眾，或言非法和合，或言如法別眾，或言法相似別眾，或言法相似和合，或言羯磨成就，或言不成就。」《戒壇經》云：「佛世執法猶行五非，豈是不學無知人耶？臨機心境迷忘故也
【譯文】在結語勸勉中，首先解釋「條貫諸緣」，即一百三十四種羯磨法如同樹葉或器物，七種非相統攝它們就如同枝條或繩串，總綱必定涵攝個別，因此令人探尋根本。自「下」字以下解釋告誡勸勉。本律第四十三卷記載：「那時某個住處的僧眾為比丘作了非法別眾羯磨，當時眾多僧人共同諍論，有的說是『非法別眾』，有的說是『非法和合』，有的說是『如法別眾』，有的說是『法相似別眾』，有的說是『法相似和合』，有的說羯磨成就，有的說不成就。」《戒壇經》說：「佛世時執持戒法的人尚且會行此五種非相，這難道是不學無知之人嗎？這是因為面臨當下境緣時心境迷亂遺忘所致。」

【391-0002】03_業疏/06b_卷一之六#84
【原文】就對首中，初舉位明數，其相可知
【譯文】在「對首法」當中，首先列舉品位並說明數量，其相狀顯而易知。

【391-0003】03_業疏/06b_卷一之六#85
【原文】對首中，「舉位」是標，「明數」即註
【譯文】在對首法中，「舉位」是指標題列出名位，「明數」是指注文中說明其數量。

【391-0004】03_業疏/06b_卷一之六#86
【原文】於緣有異者，以非攝之，義則通也。莫不對人是足、是淨，據法施事，附相乃異。於緣必如，如義通於對法，故須例解；約相持說有殊，故須委練
【譯文】所謂「於事緣有所差異」，若以「非相」來涵攝它，其義理則是相通的。無非都是要求相對之人是足數、是清淨僧，依憑羯磨法來推行其事，只是依附的外相有所不同而已。在事緣上必須合於如法，如法的意義通貫於各個對首法，所以必須依此通例來理解；若就事相上的受持與說淨而言則各有不同，因此必須詳細研習熟練。

【391-0005】03_業疏/06b_卷一之六#87
【原文】但對總標中，初舉通釋別。「於緣異」者，即二十八法是別，七非是通。「莫」下對較通別：初總舉如義；「下」別釋，初釋義通，對法即該二十八也，「約」下次釋相異
【譯文】在僅作對首之總標當中，首先舉出通則以解釋別相。「於緣異」是指二十八種羯磨法為別相，七非為通相。「莫」字以下對比比較通與別：首先總體列舉如法的意義；其下分別解釋，先解釋義理相通，「對法」即涵蓋了這二十八種法；自「約」字以下，其次解釋事相上的差異。

【391-0006】03_業疏/06b_卷一之六#88
【原文】初明人非，即受對者，既有重緣，三根非妄，斯即非數，義無同證
【譯文】首先說明「人非」，即指接受對首作法的人，既然犯了重罪之事緣，且由見、聞、疑三根證明並非虛妄，此人即不再算入清淨僧數之內，在義理上便無法共同作證。

【391-0007】03_業疏/06b_卷一之六#89
【原文】人非犯重中初文，但釋犯重。註云「遮難」，即本受不得人，如小年、不稱名等，雖遮障戒
【譯文】在「人非」因犯重罪的小節中，前文只解釋犯重罪。注文所說的「遮難」，是指根本無法受戒得戒之人，例如年齡不滿二十歲（小年）、不稱名等，雖然只是遮障受戒。

【391-0008】03_業疏/06b_卷一之六#90
【原文】問：自身犯重，合持說不？答：戒從別發，互不相乖。若不受淨，隨相結犯；如學悔流，審知濁境，自犯重者，不合同作，乍可心念。若同學悔，界無淨僧，共對無妨
【譯文】提問：若是自己本身犯了重罪，應不應該為衣藥作受持、說淨法？回答：各條戒法是依個別境緣而發起領納的，彼此之間並不互相妨礙。若是不作說淨，就會隨其事相結罪犯戒；如同正在行學悔羯磨的這類人，若審查知曉對方處於污濁有罪的境地，自己犯了重罪者，就不應當與彼一同作對首法，寧可改作心念法。如果是同處學悔期的同伴，且結界內又沒有清淨僧人，彼此共同相對作法也無妨。

【391-0009】03_業疏/06b_卷一之六#91
【原文】問中，恐謂不堪為他對證，自加受淨亦不成故。答中，初明須說，重雖有犯，餘自成持，本從別發，隨別解說。「如」下次簡對首，自雖犯重，亦須淨境；彼我學悔，無淨方開
【譯文】提問之中，是擔心自己不堪為他人作對首之證明，自己加法受持說淨也會不成就的緣故。回答之中，首先說明必須作說淨，重罪雖然有犯，其餘戒法自可成就持守，因為戒本是從各個個別境緣發起的，隨各別境緣解說作法即可。「如」字以下，其次簡別對首之對象，自己雖然犯重，也必須找清淨境緣；彼此雙方皆在學悔期中，且無清淨僧時，才開許相對作法。

【391-0010】03_業疏/06b_卷一之六#92
【原文】有訶者訶，謂前對證語使文具，不問住止，俱是人非
【譯文】所謂「有訶責者出言制止」，是指面前的作證人出言要求文辭具足，無論作法者是停住還是不顧而繼續，都屬於「人非」。

【391-0011】03_業疏/06b_卷一之六#93
【原文】二中，「不問住止」者，止即法如人別，不止人法俱非
【譯文】在第二段中，所謂「不問住止（不論停住與否）」，若停住下來，即羯磨法如法而人算作別眾；若不停下來，則人與法兩者皆不如法（人法俱非）。

【391-0012】03_業疏/06b_卷一之六#94
【原文】或對僧俗者，僧是別位，俗是下流，必對二人，並人非攝
【譯文】或者「對僧或對俗」，僧伽屬於另一品位（眾法位），在家人則是下流品位，若必定對此二人作對首，都歸屬於「人非」所涵攝。

【391-0013】03_業疏/06b_卷一之六#95
【原文】三中，僧即四人，故云別位。或對二、三，亦名非法
【譯文】在第三段中，「僧」即指四人，所以說是不同的品位。或者對著兩人、三人作法，也稱為非法。

【391-0014】03_業疏/06b_卷一之六#96
【原文】就法非中，持脫錯者，脫謂不牒二名，錯謂不順受體，今誦《僧祗》乖依隨相是也
【譯文】在「法非」當中，持誦脫落或錯亂的情形：「脫」是指沒有牒出本人名與衣名；「錯」是指不順從所受戒體的文旨，例如現今讀誦《摩訶僧祇律》文辭而違背了依從隨順之相，就是如此。

【391-0015】03_業疏/06b_卷一之六#97
【原文】法非中，「不牒二名」即己名、衣名，能所不辨，或俱或互，皆名非法。訛錯義多，特舉乖宗，暗斥時用
【譯文】在法非之中，「不牒二名」即自己的名字與衣物的名稱，能持與所持分辨不清，或兩者皆缺，或互有脫落，都稱為非法。訛謬錯亂的含義很多，此處特意舉出違背宗本的情形，藉以暗中斥責當時僧團的錯誤做法。

【391-0016】03_業疏/06b_卷一之六#98
【原文】就事非中，既是法衣，不容濫染。五色上染，是俗非道，雖持不成，事不應法也
【譯文】在「事非」當中，既然是如法的袈裟，就不容許胡亂染色。使用青、黃、赤、白、黑五正色上色浸染，是在家俗人的做法而非出家修道人之相，即便作了受持也不成就，因為事相不合於教法。

【391-0017】03_業疏/06b_卷一之六#99
【原文】事非中，且舉色相。求財不如，體量乖法，並是事收
【譯文】在事非之中，此處暫且舉出顏色相狀為例。若獲取衣財的手段不如法，或是質地、尺寸違背法度，全都屬於「事非」所涵攝。

【391-0018】03_業疏/06b_卷一之六#100
【原文】餘四交絡，非相互現，可知有無
【譯文】其餘四句交錯組合之相，非相互相顯現，從中即可明白其成就與否。

【391-0019】03_業疏/06b_卷一之六#101
【原文】就眾法對首，言人非者，謂法界內無僧，故開；有人別眾，不成捨也。自然五里，亦須明練，餘界準知
【譯文】在「眾法對首」當中，所謂「人非」，是指作法界內沒有清淨僧伽，所以開許作對首；若界內有人卻成為別眾，則不能成辦捨衣等法。自然界五里的界限，也必須明瞭研習清楚，其餘各界依此類推可知。

【391-0020】03_業疏/06b_卷一之六#102
【原文】眾法對首人非中初科，前明法界，後示自然，且舉蘭若，餘令準知
【譯文】在眾法對首人非的第一科中，前半段說明作法界，後半段指示自然界，暫且舉出阿蘭若為例，其餘各界令依此類推知曉。

【391-0021】03_業疏/06b_卷一之六#103
【原文】人非應法者，所對行穢，體非拔濟
【譯文】所謂「所對之人非應法者」，是指所面對之人的行持污穢，其自身體質並非堪能拔濟罪垢的對象。

【391-0022】03_業疏/06b_卷一之六#104
【原文】二中，行穢語通輕重，但使有過，不合受懺
