# 校閱材料　第262檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【262-0001】資持記/07b_中一下#61
【原文】乃全依本文，一無改易；即戒序云：今依律本，具錄正經；仍隨佛解，即為注述，是也。但以翻傳，詞尚淳質；故仍刪定，專被誦持；對於律解，義同文異；故知注釋，須準古文；若但誦持，可依刪定。今則兩本皆注，殊乖祖心。〔有云：未刪定時已注，故從古本，未知此意。
【譯文】那完全是依憑佛陀宣說的律本本文，毫無任何改動刪削；正如戒序中所說：「如今依照律本全文，完整錄出正經原貌；仍舊隨順佛陀當年的親口解釋，直接作為注釋解說」，指的就是這個。只不過由於最初翻譯傳入時，文字辭句仍保留樸質古風；所以後來才另外有《刪定戒本》，專門用來供出家人登壇誦持；對照佛陀隨後的律法解釋，兩本是法義相同而文字略異；由此可知要注解解釋，必須依循古本文本；如果只是平日誦持，則可以依照刪定本。如今那些注釋家卻把兩種版本胡亂拿來加注，極為違背祖師當初的本心。〔有人說：在尚未刪定時律祖就已經作注，所以才依從古本，這說法完全是不懂得律祖當年的用意。〕

【262-0002】資持記/07b_中一下#62
【原文】況以淺近浮詞，妄參聖語；雜碎科條，浪節真經；瞽論紛紜，焉知自誤，此二非也。又章記至此，且入戒序，科文解釋；至後戒條，例分為二：一戒本，二鈔文。且此科文，為屬戒本，為屬鈔文？是則科段交參，兩無所攝深；非常途撰述之體，此三非也。又復以鈔釋戒，殊不相符；
【譯文】何況那些人還拿淺顯浮泛的鄙俗言辭，胡亂摻入佛陀宣說的聖言之中；把神聖的真經任意科判節段，弄得瑣碎零亂；瞎眼盲目的爭論紛紜雜沓，哪裡知道自己早已深陷謬誤，這是第二種過失。此外，那些章記講解到這裡時，暫且列入戒序，用科判解說經文；到了後面的戒條時，就一律將文段拆成兩截：一是戒本文句，二是本鈔文句。那麼請問此處的科判文句，究竟是屬於戒本，還是屬於本鈔？落得科判段落彼此錯雜參差，兩頭都不著邊際；這完全不符合一般正統著述的體例規矩，這是第三種過失。再者，拿本鈔文句去解說戒本文義，兩者根本就對應不上；

【262-0003】資持記/07b_中一下#63
【原文】且如初戒云：共戒同戒，不捨戒等；今鈔直列境緣，曾無一詞相對；雖強科配，終成乖各，此四非也。又《含注戒本》，全依佛語，注釋精詳；復有義疏，解文委備；當須遍學，方盡始終。今以鈔釋戒，彼成無用；即今律肆，罕見傳通，良由於此；況剽竊疏文，冐為己注；文無起盡，義不周旋；
【譯文】暫且拿第一條重戒來說，戒本文字是：「共戒同戒，不捨戒」等等；而本鈔在此處卻是直接列出境界與犯緣，完全沒有任何隻字片語是在針對戒本文句作訓釋；縱然強行用科條去牽強配屬，終究還是格格不入、乖離背道，這是第四種過失。況且《含注戒本》完全依照佛陀聖言，注解精湛詳盡；此外更有專門的《義疏》，解析文句極其周備；理當通盤研習這整套著作，才能窮盡修學的始終源流。如今卻拿本鈔割裂去解釋戒本，反而讓那部珍貴的《含注戒本》廢置無用；如今律學講席之中，之所以罕見有弘傳流通《含注戒本》的人，正是由於這種惡習所造成的；更何況那些人公然剽竊《戒疏》的文句，冒充為自己的注解；文字沒有起承轉合，義理也無法周全通達；


【262-0004】資持記/07c_中一下#1
【原文】雖欲究尋，終成徒爾；必若鈔文釋戒，後復撰疏何為？此五非也。且略責五非，極多不便。今並刪削，直點鈔文；但摘撮本緣，令知端始。或文略義壅，則引疏決通。或諸部互違，則旁引比對；欲知要旨，妙識犯緣。此乃釋相之綱宗，持犯之樞鍵者矣。婬戒。〔佛在毘舍離國，須提那子出家已；
【譯文】即使想要深入探尋，終究也是徒勞無功；如果《行事鈔》本文已經解釋了戒律，道宣律師後來又何必撰寫《戒本疏》呢？這就是第五種弊端。暫且簡略指責這五種過失，古人做法實有極多不妥與不便之處。如今將這些全數刪削，直接依據《行事鈔》原文來標示；只摘取最初的犯戒因緣，讓學者明瞭事情的開端起因。若是文中過於簡略而義理阻滯不通，就引證《戒本疏》來決斷貫通。若是各部律典互相違背，就旁徵博引以資比對；目的是想讓人通達要旨，精妙地辨識犯戒的緣由。這正是解釋戒相的綱要宗旨，也是持戒犯戒的關鍵所在。淫戒。〔佛陀在毗舍離國時，須提那子出家之後；

【262-0005】資持記/07c_中一下#2
【原文】還本村，與故二共行不淨因制。《僧祇》：婬戒，五年冬分制，餘三戒，並六年冬分制。〕標中。例分三者，義通文別。言義通者，終盡眾學，一一皆然；文或有缺，義必當具；言文別者，隨一一戒，境緣不同。一所犯者，別簡境也；二成犯者，心境合也；三不犯者，心境互缺也。略下，指廣；
【譯文】回到原本的村落，與過去的妻子行不淨行，因此制定此戒。《摩訶僧祇律》說：淫戒是在佛成道後第五年的冬季制定的，其餘三種波羅夷重戒，都是在第六年的冬季制定的。〕在標示戒條之中。按例劃分為三門的原因，是義理相通而文字各有不同。所謂義理相通，是說自始至終窮盡一切學處，每一條戒都是如此；經文中縱使偶有欠缺，義理上也必定應當具備；所謂文字各有不同，是指隨著每一條戒律，所對的境與緣各有差異。第一是所犯的境，用來個別甄別境界；第二是構成犯戒，指內心與外境相合；第三是不犯戒，指內心與外境互相欠缺相應的條件。自「略（知持犯）」字以下，是指示廣本之文；

【262-0006】資持記/07c_中一下#3
【原文】欲彰此處不涉義章。下篇猶略，故復指疏；釋名制意，義門開制，古今別解，釋疑會異，盡在彼文，今多不引；或須相照，時有抄撮，釋通文相，無他意焉。犯境，初科，《僧祇》。上二句示來報，次二句彰現損。言可畏者，《訶欲經》云：女色者，世間之枷鎖；凡夫戀著，不能自拔；女色者，世間之重患；
【譯文】這是為了表明此處不涉及繁冗的義理章節。因為下篇仍然簡略，所以又指示參見《戒本疏》；解釋名稱與制定意圖、義理門中的開遮與制止、古今大德的不同解釋、釋除疑惑與融會異說，全部詳載於彼書之中，此處大多不予引錄；有時若是需要相互參照，才會偶爾節錄抄取，只為了通達解釋文句名相，並無其他的用意。論述所犯的境界，第一科，引用《摩訶僧祇律》。前面兩句開示未來的惡報，後面兩句顯發當世的損害。所謂令人畏懼，《訶欲經》說：女色是世間的枷鎖；凡夫貪戀執著，無法自拔；女色是世間的嚴重禍患；

【262-0007】資持記/07c_中一下#4
【原文】凡夫因之，至死不免。女色者，世間之衰禍；凡夫遭之，無厄不至；行者既得離之，若復顧念，是為從地獄出，還復思入。又云：女人之相，其言如蜜，其心如毒；譬如清淵澄鏡，而蛟龍居之；金山寶窟，而師子處之；當知此害，不可近也。敗正者，立事公正，苟荒女色，則無所成；
【譯文】凡夫因為女色，至死都難以倖免。女色是世間的衰敗禍端；凡夫遭遇了它，種種厄難無不降臨；修行人既然已經脫離了女色，如果又回頭眷戀顧盼，這就如同剛從地獄出來，又想著重新進去。經中又說：女人的相貌，言語甜蜜如蜜，內心陰毒如鴆；好比澄澈如鏡的深淵，卻有蛟龍盤踞其中；又如金山寶窟，卻有猛獅棲息其內；應當知道這種危害，是絕對不可以親近的。所謂敗壞正業，是指處事公正剛立，如果荒廢於女色，就一事無成；

【262-0008】資持記/07c_中一下#5
【原文】即彼經云：室家不和，婦人之由；毀宗敗族，婦人之罪。毀德者，修身立行，或著女色，則皆喪失；即經云：凡夫重色，甘為之僕；終身馳驟，為之辛苦；《淨心觀》云：貪色者憍，貪財者悋；既憍且悋，雖有餘德，亦不足觀。染下，明制急。然心行微細，麁情不覺；縱知違戒，制御猶難；
