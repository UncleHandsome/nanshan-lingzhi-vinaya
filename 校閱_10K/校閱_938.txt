# 校閱材料　第938檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【938-0001】資持記/02c_上一下#36
【原文】對於對首，立眾多人僧〔二三人也〕；對於眾法，立四人僧。又云：莫不弘秉，通號僧焉。〔舊云僧簡別者，謬矣。〕下指《義鈔》文逸。〔舊云檢彼無文，非也。〕《業疏》總義中廣明體相，非可卒示；須學方知；即下〈羯磨篇〉，亦明七位；法事如非，尋之可領。別列中。
【譯文】相對於對首法，安立「眾多人僧」〔指二三人〕；相對於僧眾集體之法，安立「四人僧」。又說：無非都在弘揚秉持佛法，統統都稱為僧伽。〔舊說認為僧伽應當簡別除外個人，這是錯誤的。〕下文指出的《義鈔》文獻已亡佚。〔舊說認為查檢彼處並無此文，也是不正確的。〕《業疏》在總論法義中詳盡闡明了體相，並非片刻能開示完全；必須深入研習方能知曉；也就是下文的〈羯磨篇〉，也闡明了七種位階；法事的是非得失，披尋彼處即可領會。在個別列出之中。

【938-0002】資持記/02c_上一下#37
【原文】別位易解，略而不明。此篇集僧，且據大眾。初四人者。疏云：僧雖有四，體相分二。初一為體，非四不名為僧。後隨事分，故有三別。文中且舉說結；其實百三十四法中，除上五種，餘並四人作之。五人中，初示本宗。
【譯文】個別之位容易理解，故略過不予闡釋。本篇所論聚集僧眾，暫且以大眾僧法為依據。起初的「四人僧」。義疏說：僧伽雖然有四種，其體相分為兩種。第一種四人僧是僧體的本質，不是四人就不能稱之為僧。後續則隨著僧事而劃分，所以有另外三種差別。文中暫且舉出說戒與結界；實際上在一百三十四種羯磨法中，除去了上述五種，其餘都由四人來舉行。在「五人僧」中，起初示明本部宗派的規定。

【938-0003】資持記/02c_上一下#38
【原文】邊受二法，教授白召，戒師對問，自恣白和，唯此三白，是五人用。若約僧體，四人能辦；但由事緣相假，非五不成；故四外加一，為五人僧；邊受白四，還四人攝。若下，次取他部。本宗受懺，亦止四人；今依《祇律》加入五中。彼云：五眾羯磨者，自恣邊受一切尼薩耆是也。十人者。
【譯文】邊地受戒的兩種法事（即教授師單白召請、戒師當面審問），加上自恣時單白和僧，只有這三種單白羯磨，是由五人僧來執行。如果就僧體而言，四個人便能成辦；只因法事因緣需要互相借重，非五人不能成就；所以在四人之外增加一人，成為五人僧；至於邊地受戒的白四羯磨，依然由四人僧含攝。「若」字以下，其次採用其他部派的說法。本宗接受懺悔之法，也只要四人即可；如今依據《僧祇律》將其加入五人僧之中。彼律說：五人僧所作的羯磨，就是自恣、邊地受戒以及一切尼薩耆波逸提的懺罪法。所謂「十人僧」。

【938-0004】資持記/02c_上一下#39
【原文】疏云：中國僧多，前受生慢，故倍前五為十人僧。二十人者。二篇隣重，犯悔情浮，故倍中受，為二十人僧。準疏問曰：受開邊五，例準出罪亦應開十？答：受是生善，開之有益；出罪滅惡，開則增過；餘廣如彼。體用中，初句通括四位。若下，別示僧體，初明體通。今下，明用別。
【譯文】義疏說：中原地區僧人眾多，受戒者容易生起怠慢之心，所以將前面的五人加倍為十人僧。所謂「二十人僧」。二篇僧殘罪業緊鄰根本重罪，犯戒者懺悔之情多有浮躁不專，所以將中原受戒的人數加倍，定為二十人僧。準照義疏提問說：既然受戒能在邊地開許為五人，依例出罪懺悔是否也應開許為十人？回答：受戒是為了生發善法，放寬限制大有助益；出罪是為了滅除惡業，若放寬限制則會助長罪過；其餘詳細論述正如彼處所載。「體性與功用（體用）」這部分，第一句總括了四個位階。「若」字以下，分別開示僧體的本質，起初闡明體性的通相。「今」字以下，說明應用的差別。

【938-0005】資持記/02c_上一下#40
【原文】上即依律略示僧體，律本但有約數明體，謂一人、眾多人、四人也。若取假用，乃準《成論》。詳今文意，雖非正辦，四人實辦，非體而何！則顯古記指前標宗為僧體者誤矣。簡淨穢中，初文。自行取淨，唯約自知；微有所犯，悔已同法；不爾，必約三根檢勘清濁；清可預數，濁必擯治。
【譯文】以上就是依據律典大略開示僧體的本質，律本中只有依據人數來說明體性，也就是一人、眾多人、四人。如果就假合的功用而言，則是準照《成實論》的說法。詳察現在文句的意旨，雖非正位僧事所辦，但四人確實足以成辦僧事，這不是僧體又是什麼呢！這就顯明瞭《古記》將前面標立宗派之處指為僧體的說法是錯誤的。在「簡別清淨與汙穢（簡淨穢）」之中，第一段文句。個人自行修持以求清淨，唯有自己最清楚；若是微小的觸犯，懺悔清淨後便等同如法僧眾；若不是這樣，則必須依據見、聞、疑三根來勘驗其清白與汙濁；清淨者可以列入僧數，汙濁者必須擯除懲罰。

【938-0006】資持記/02c_上一下#41
【原文】根不外彰，亦容參預故也。次科，簡淨中，初三句簡定。文略自恣。以下，釋成，初釋說戒。上句制能說，下句制所聽。後釋懺罪。上句制能懺，下句制所受。問：一切羯磨，生善滅惡二門統收，如何分之？答：如諸悔罪治擯滅諍設諫等法，名為滅惡；已外一切，並號生善；
【譯文】若是罪根尚未外露顯彰，也容許暫時參與僧數之故。下一科「簡別清淨」之中，前三句予以簡別確定。文中省略了自恣。「以」字以下，解釋其成立之由，起初解釋說戒。上句規定能說戒之人，下句規定聽戒之眾。其後解釋懺罪。上句規定能懺罪之人，下句規定接受懺悔的僧眾。提問：一切羯磨法事，由「生發善法」與「滅除惡業」兩門總括收羅，該如何區分？回答：如同各種懺悔罪過、懲治擯治、滅除諍事、設立諫處等僧法，稱為滅除惡業；除此之外的一切法，都稱為生發善法；

【938-0007】資持記/02c_上一下#42
【原文】昔見下云生善，便科此為滅惡；致令後學妄謂說恣同滅惡收。當知文中具明二種，說戒是生善，懺悔屬滅惡；有智考之，幸無混亂。次通穢中，初正明。故下，引例有二。初律開白停僧殘，赴前受戒。二律中有人受戒已，疑和尚犯戒；有四句，三句不知皆得，後句知故不得，如次篇具引。薩下，引證。
【譯文】昔日有人看見下文說到生發善法，便將此處科判為滅除惡業；導致後學之人妄加揣度，認為說戒、自恣也一同被滅除惡業所收攝。應當知道文中具備說明了這兩種，說戒屬於生發善法，懺悔屬於滅除惡業；有智慧之人詳加考證，幸好沒有發生混亂。其次「通於汙穢（通穢）」這部分，起初正面闡述。「故」字以下，引述事例有二。第一是律典開許作白暫停僧殘行法，前去參與受戒法事。第二是律典中有人受戒完畢之後，懷疑和尚犯了戒；文中列出四種情況，前三種不知情的都得戒，最後一種因知情的緣故而不得戒，如在下一篇中詳盡引用。「薩」字以下，引用文獻作證。

【938-0008】資持記/02c_上一下#43
【原文】問：為約所為不知，為能秉互不知？答：且論受戒。所為之人不疑微犯，方得成法。若論能秉，唯據四重；各不相知，亦成法事。下篇具委，故此指之。3 釋足數篇(上一下)釋足數篇題云足數。足，猶滿也。即律中得滿不得滿等，如後具引。數有七位，始自一人，終至二十。
【譯文】提問：這是就羯磨所為之人不知情而言，還是能秉法者之間互不知情？回答：且先論述受戒法事。羯磨所為之人只要不懷疑微小的犯戒，方能成就僧法。若是就主持能秉法的僧眾而言，唯獨依據四重根本大戒來論；只要彼此互不知情，也同樣能成就法事。下一篇有極詳細的論述，所以在此略作指示。第三「解釋足數篇」（卷上一之下）。解釋足數篇的標題稱為「足數」。「足」，如同圓滿具足的意思。也就是律典中所說的「能滿足僧數」、「不能滿足僧數」等規定，如同後文詳盡引用。人數共有七個位階，從一人開始，最終至二十人為止。
