# 校閱材料　第494檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】訶責等七，《律》判不失，而約義有失；所以此二先明，後方通列。問：約前三法，別配九種，同異云何？答：訶責失一，如上可知；遠去兩別，即還失二；越宿失三；餘之七種，約教失三，尋之可見。〔古云死與休道，三法俱失；訶責失一，餘並失下二，非也。安有犯重入場請法仍在耶。
【譯文】受到訶責等七種情況，《律》文判定為不失去，然而從義理上而言卻有失去之處；所以這兩項先提出加以說明，隨後才作總括列舉。問：依據前面所說的三種依止法，分別配對這九種情況，彼此的同異是如何的？回答：受到訶責只失去一種法，就如上述所可知；遠行離去分為兩種情況，當天返回失去兩種法；隔了一夜則三種法全都失去；其餘的七種情況，依照教法規定三種法全都失去，仔細查尋便可明瞭（古人說死亡與還俗，三種法全都失去；受到訶責失去一種法，其餘全都是失去後兩種法，這種說法是不對的。哪裡有犯了根本重罪、進入戒場（另受具戒）之後，依止請法之儀軌依然存在的道理呢）。

【494-0003】資持記/05a_上四#1
【原文】四分律行事鈔資持記上四10 釋說戒篇(上四)釋說戒篇戒即本受法體，量等塵沙，從緣舉要，且列二百五十為持犯蹊徑，使攝修之易。然恐物情懈怠，不自策勤；故黑白兩半，畢集一處，作法宣告；庶使因言省己，治行日新。雖廣略兩殊，僧別三位；一言統攝，無非淨行。故云說戒。

【494-0004】資持記/05a_上四#2
【原文】正儀者。以普照，道安，及當時律肆，立法雖殊，多無典據；此篇所述，皆憑聖量；參詳經律，搜駮是非；題曰正儀，對簡非正。又復上云說戒，克指所說之法；下云正儀，統該能辨之緣。能所兩標，緣法雙顯故也。注文，示正譯中。即下《三千威儀》初義，是今正用，故先舉之。
【譯文】所謂正儀。是因為普照、道安以及當時的律學道場，立下的規矩雖然不同，多數卻沒有聖典依據；本篇所記述的內容，完全依憑聖人的聖言量；參酌詳審經藏與律藏，搜討辨析是非曲直；篇名題為正儀，是為了對照並簡除不正之法。再者，上面說的「說戒」，精準指出所宣說的戒法；下面說的「正儀」，總體涵蓋能辨明這項法事的因緣。能辨與所說兩者皆標明，儀軌與戒法雙雙顯現。注文中，標示正確翻譯的段落。就是下文《三千威儀》最初的義理，是現今正要採用的，所以先舉出來。

【494-0005】資持記/05a_上四#3
【原文】言淨住者，二義釋之：一不失義，聞持無犯，體常存故；下云清淨戒住是也。二依止義，禁制三業，安住戒中；即《廣弘明集》云：淨身口意，如戒而住是也。廣引中，《出要律儀》。但指國語，續引《泥洹》，始是翻名。憍薩羅者，《方志》云：係中印度，周六千餘山，城周四千餘里，大信佛法等。《泥洹》。
【譯文】說到「淨住」，用兩種意義來解釋：第一是不失壞的意義，聽聞並受持而不犯戒，戒體常存的緣故；下文所說的清淨戒住就是這個意思。第二是依止的意義，禁制身口意三業，安住在戒法之中；也就是《廣弘明集》所說：清淨身口意，如戒法而安住。在廣泛引證中，《出要律儀》只是指出外國語言，接著引用《泥洹經》，才算是翻譯名稱。憍薩羅國，《西域方志》記載：屬於中印度，周圍有六千多座山，城周四千餘里，非常崇信佛法等等。《泥洹經》。

【494-0006】資持記/05a_上四#4
【原文】有二本，今云六卷，簡雙卷者。長養即總翻，二義是別釋。初義同上，次義即下《伽論》證得白法等。或可長對次義，養對初義。《雜含》中。梵語雖具猶訛，則知單云布薩，訛而復略。下引正音，二義分配；斷謂止惡，同上戒住；下義相對可知。國語不同，訛上兩字故。亦呼下，上是具翻；
【譯文】有兩種譯本，現在說六卷本，是為了簡別雙卷本。長養是總體的翻譯，兩種意義是分別解釋。第一種意義同於前面，第二種意義就是下文《伽論》（《摩得勒伽論》）所說證得白淨法等。或者可以將「長」對應第二義，「養」對應第一義。《雜阿含經》中。梵語雖然齊備但仍有訛誤，由此可知單單稱布薩，是訛誤而且簡略。下文引出正音，將兩種意義分別配對；「斷」是指止惡，同於上面的戒住；下一個意義相對即可明了。由於各國語言不同，所以訛誤了上面兩個字。自鈔文「亦呼」以下，上面是具足翻譯；

【494-0007】資持記/05a_上四#5
【原文】復含餘義，則有七名。初云集者，戒序云共集一處也。二云知者，即自知犯不犯等；下云從前半月至今半月中間不犯戒耶。三宜者，《戒疏》云晦望兩半折中之宜。四同者，下云十方凡聖所共同遵故。五共住者，奉慎清淨，住二種僧中，有犯者不得聞故。
【譯文】又包含其他意義，則有七種名稱。第一稱為「集」，戒序說共同聚集於一處。第二稱為「知」，就是自己知道犯戒或不犯戒等；下文說從前半月到今天半月之間沒有犯戒嗎。第三稱為「宜」，《戒疏》說這是黑白兩半折衷的合宜之時。第四稱為「同」，下文說這是十方凡夫聖人所共同遵行的緣故。第五稱為「共住」，敬奉謹慎保持清淨，安住在理和與事和二種僧團中，有犯戒者不得聽聞的緣故。

【494-0008】資持記/05a_上四#6
【原文】六云轉者，轉諸業惑，證白法故。七云常者，僧所常行，餘皆稀故。經但出名，今以意詳；引文約義，略如上釋。三千中。三譯，二同上釋。和合者，三體三相，非說不顯故。下二云義言，顯上正翻故。已上多名，總歸四種。淨住、斷、轉，止惡為名；增長、長養，生善為名；集、同、共、和，遵奉為名；
【譯文】第六稱為「轉」，轉變各種業障迷惑，證得白淨善法的緣故。第七稱為「常」，是僧團平常所修行的法事，其他法事都很稀少的緣故。經文只列出名稱，現在用心意詳加推究；引述經文約定意義，大致如上面所解釋。在《三千威儀》中。三種翻譯，其中兩種同於上面的解釋。所謂「和合」，因為六和敬中的三體和（戒、見、利）與三相和（身、口、意），不經宣說就不能顯現的緣故。下文兩處說「意義上稱」，是為了顯明上面是正確翻譯的緣故。以上眾多名稱，總歸為四類。淨住、斷、轉，是以止惡為名；增長、長養，生善為名；集、同、共、和，是以遵奉為名；

【494-0009】資持記/05a_上四#7
【原文】知、宜、及常，從制為名。然雖多出，但準前標，止翻淨住。會通中，《俱舍》。明八戒皆云受布薩護，故云名也。名即是召。次引《了論》。戒護兩分，會同《俱舍》。二論言護，名義頗同；布薩與戒，華梵互舉，事同名異。後引律者。律中二十犍度，第二即〈說戒犍度〉；
【譯文】知、宜、以及常，是順從制戒為名。然而雖然列出很多，只要依照前面標明的，只翻譯為淨住。在會通義理中，《俱舍論》。說明八關齋戒都說是受布薩護，所以稱為名。名就是稱召。接著引用《戒了論》。將戒與護兩者分開，會合贊同《俱舍論》。兩部論典所說的護，名稱與意義相當相同；布薩與戒，是梵語與華語相互交替使用，實質相同而名稱相異。最後引用律藏。律藏二十犍度中，第二個就是〈說戒犍度〉；

【原文】後〈五百結集〉中，迦葉敘波離結集，乃云〈布薩犍度〉；即知前標說戒，後云布薩，前後互舉，故云即也。此句正指同前篇目。問：為布薩翻說戒耶？且布薩自翻淨住，戒乃梵語尸羅；既非對翻，云何律論二名互顯。問：何以不云布薩正儀耶？思之可解。〔學者多昧，故當曲釋。

【494-0011】資持記/05a_上四#9
【原文】敘意中，初顯教益，上二句標歎。下二句釋成，上句約時顯功。正像語略，理須兼末；即下云：云何得知佛法久住等。下句約法明用。以同遵故，清淨和合，餘法可行，下云攝僧根本之教是也。次科，初四句先示情見。滿，猶厭也。希作者，如結界受懺等，數為即半月常行。比下，正斥，初二句斥慢易。
【譯文】在敘述意圖中，首先顯明教法的利益，上面兩句是標示讚歎。下面兩句是解釋成就，上一句就時代而言顯明功效。正法像法是簡略的說法，按理必須兼顧末法；也就是下文說的：如何得知佛法能長久住世等。下一句就戒法而言闡明功用。因為共同遵守的緣故，大眾清淨和合，其餘僧事才能推行，下文所說攝受僧團的根本教法就是這個意思。次一科判，前四句先指出凡情執見。滿，猶如厭倦。稀作者，如結界受戒懺悔等，多次作法就是半月常行的布薩。「比」以下，正式斥責，前兩句斥責怠慢輕忽。

【494-0012】資持記/05a_上四#10
【原文】良下，推所以。日染者，常所習故；屢聞者，一月兩說，故屢數也。以此下，結歎。情即妄緣，逐物流變；愛此惡彼，貴希賤數。寄此一事，足見凡情，故云可知。彼時尚爾，豈況於今！僧寺雖多，行之彌寡。縱有行處，事不獲已。豈非宿業，生值斯時，念道之流，願須珍敬。三中，初敘古，二顯今。
【譯文】「良」以下，推究其原因。日染者，平常所薰習的緣故；屢聞者，一個月說兩次，所以屢次頻繁。「以此」以下，結尾讚歎感慨。情識即是妄緣，逐隨外物境相流轉變異；喜愛這個討厭那個，看重稀罕的而輕賤頻繁的。寄託這一件事，就足以看出凡情，所以說可知。彼時尚且如此，何況是現在！僧寺雖然眾多，行持說戒的卻日益稀少。縱使有推行之處，也是逼不得已應付公事。這難道不是宿業，使我們生逢這個時代？念道之流，願須珍重敬奉。第三段中，初敘古代，二顯現今。

【原文】後二唯出本宗，故下皆標《四分》。別釋中，初文，前引《四分》示同。布薩日，通含三日。問：三日隨用得否？答：世多執諍，未善祖意。若謂通得者，《業疏》那云：十四為俗說法授歸，十六為難開延未可常準。若唯執十五者，疏文那云：三皆通正，隨用開得；必用二日，七非檢勘，何非所收？
【譯文】後二種唯獨出於本宗，所以下文皆標明《四分律》。在個別解釋中，最初一段文字，前面引用《四分律》顯示相同。布薩日，通通包含三日。問：三日隨意採用都可以嗎？答：世人多有執著爭辯，未善明祖師的心意。若認為通通可以，那麼《業疏》為何說：十四日為俗人說法授三皈依，十六日為難緣開許延後未可常準。若唯執著在十五日，疏文為何說：三日皆通於正日，隨用開許皆可；若一定要用十四或十六兩日，用七非來檢視查核，何非所收之列？
