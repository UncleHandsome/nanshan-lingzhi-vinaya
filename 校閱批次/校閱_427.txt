# 校閱材料　第427檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【427-0001】資持記/08c_中二#56
【原文】請考經文，少懷信仰；廣敘利害，《章服儀》備矣。經文，前明能施如法。離殺手者，非蠶家故。不下，明所施可否。初不受應法，大小俱順故。受者非悲，違大順小故。小從大出，望制雖順，約義還違；故知持戒行慈，方符聖旨；縱情受用，全乖道儀。
【譯文】請詳加考證經文，稍微抱持一絲崇敬與信仰之心；關於其中的利害得失，《章服儀》中已經詳細具足地論述了。經文中，前半說明布施者本身合乎法度。所謂「遠離屠殺之手」，是因為對方並非養蠶的人家。「不……」以下，說明施捨之物究竟可否接受。起初不予接受是契合法度的，因為這樣做同時順應了大乘與小乘兩者的教旨。若是接受了便算不上大悲心，因為這違背了大乘的精神而只順應了小乘的枝節。小乘本是從大乘分化而出，就小乘戒律的條文而言雖算順從，但就大乘深意而言實屬違背；故知持戒行慈，方符聖旨；縱情受用，全乖道儀。

【427-0002】資持記/08c_中二#57
【原文】故《章服儀》云：且自非悲之語，終為永斷之言；據此為論，頗彰深切。次引《涅槃》。乃終窮囑累，決了正教；明文制斷，何得遲疑。今下，舉現事。此指唐時。若《僧傳》中敘南岳道休二師不衣綿帛，竝服艾絮。故祖師云：佛法東漸，幾六百載；唯斯衡岳，慈行可歸。
【譯文】所以《章服儀》說：暫且拋開缺乏大悲的責備不談，這終究是佛陀永遠斷除此事的明訓；根據這點來論斷，更能彰顯深切的告誡。接著引用《涅槃經》。這乃是佛陀臨終最透徹的託付，是究竟了義的正確教法；既然明文嚴厲禁止斷絕，哪裡還容得下遲疑不決。現今「今……」以下，列舉當前現世的事例。這是指唐代的情況。在《高僧傳》中記載南嶽慧思與道休兩位大師，生平從不穿著綿帛綢緞，一概只穿艾草搓成的絮衣。所以祖師說：佛法向東傳播，已將近六百年；唯獨這位南嶽衡山的大師，其慈悲行持真正值得依歸。

【427-0003】資持記/08c_中二#58
【原文】今時禪講，自謂大乘，不拘事相；綾羅鬪美，紫碧爭鮮；肆恣貪情，背違聖教。豈不聞衡岳但服艾絮以禦風霜，天台四十餘年唯被一衲；永嘉食不耕鋤，衣不蠶口；荊溪大布而衣，一床而居。良由深解大乘，方乃專崇苦行；請觀祖德，勿染邪風；則稟教修身，真佛子矣。四中。
【譯文】如今的禪宗與講經僧人，自以為通達大乘境界，不受事相戒律拘束；身上的綾羅綢緞爭奇鬥豔，紫色碧色競相鮮麗；肆無忌憚地放縱貪求之念，徹底違背佛陀聖教。難道沒有聽說過南嶽大師只穿艾絮來抵禦風霜，天台智者大師四十多年唯披一件百衲衣；永嘉大師只吃不用鋤頭耕傷蟲害的糧食，只穿不奪蠶兒性命的衣料；荊溪大師一生身穿粗布僧衣，居室內只有一張坐床。良由深解大乘，方乃專崇苦行；請觀祖德，勿染邪風；則稟教修身，真佛子矣。第四小節。

【427-0004】資持記/08c_中二#59
【原文】《五分》不乞自施，尚不自入，意急可見也。結顯中，初示教意。野下，舉文以況。《戒本》云：雜野蠶綿，故兩舉以況之。世有野蠶食桑，就樹作𦼠，破繭為飛峨；取此為綿，不損物命。雜忽見上文。指非中，初示過。此下，決犯。合斬捨者，根本墮也。著著罪，從生吉也。如諸下，引事例顯。
【譯文】《五分律》說，即使不經乞討、由施主主動送來，尚且不准據為己有，戒律意向之嚴急可想而知。在總結彰顯中，首先指示教法的深意。「野……」以下，列舉經文來作比喻。《戒本》說：混雜野蠶的綿絮，所以將這兩者並列比喻。世間有一種野蠶只吃桑葉，在樹上結繭，破繭而出化為飛蛾；拿這種廢繭來抽絲作綿，並不會損傷物命。雜忽的含義見於前文。在指斥非違之處，首先指示過錯。「此……」以下，決斷罪犯。應當用刀斬壞並且捨棄這件衣服，因為犯了根本的捨墮重罪。每次穿著都犯罪，這是從犯戒所生出的突吉羅輕罪。正如「如諸……」以下，列舉事例來彰顯說明。

【427-0005】資持記/08c_中二#60
【原文】犯輕中，《多論》五節，初明自作。無蠶家者，展轉來故。言無罪者，以無蟲故。若是有蟲，出賣尚犯，豈容自作。為下，二明出賣。不為作衣，故彼續云：若無蟲者無罪。若乞下，三明已成。而不犯者，非蠶家故。若蟲下，四明蟲壞。無所損故。論作蠶壞，恐寫誤。作下，五作餘衣。
【譯文】在判輕罪的情況中，《薩婆多論》分為五段，首先說明自己製作。不是養蠶的人家，是因為原料輾轉贈送而來的緣故。所謂判定為無罪，是因為當中沒有殘留活蠶蟲。如果裡面有活蟲，拿去變賣尚且犯戒，哪裡還容許自己拿來製作衣服。「為……」以下，第二段說明賣給他人。不是為了自己做衣服，所以彼論接著說：如果沒有活蟲就無罪。「若乞……」以下，第三段說明乞討已製成的綿衣。之所以不犯戒，是因為對方並非養蠶人家的緣故。「若蟲……」以下，第四段說明被蟲咬壞的廢料。因為這已經沒有殘害殺傷之物了。論典中寫作「蠶壞」，恐怕是傳抄寫錯了。「作……」以下，第五段說明製作成其餘日常衣物。

【427-0006】資持記/08c_中二#61
【原文】竝結吉者，必約蠶家乞得為言。彼云：下至四肘捨墮，反知不應者輕。又云：若合麻衣劫貝褐衣欽婆羅作敷具者吉，故云一切。第三科。教他重者，譏過同故。為他輕者，貪非己故。不犯中。戒制造作，已成不犯。然須斬壞，不壞還墮。指如疏者，彼云已成斧斬，此言切人也，如何可通。
【譯文】這些全都結判為突吉羅罪，這必然是指直接向養蠶人家乞討而得的情況。彼論說：小到四肘長度的敷具都要被判定為捨墮，反過來便知道不符合此標準的其他衣物罪責較輕。又說：如果將麻衣、木棉衣、褐衣、羊毛織物等製成敷具者結突吉羅罪，所以說是「一切皆犯」。第三小節。教唆他人做衣服罪責較重，因為招致外界譏嫌的過失相同。為他人做衣服罪責較輕，因為這份貪念並不是為了滿足自己。在不犯戒條款中。戒律防範的是製造的行為，若是別人已經做好的衣服則不犯重戒。然而必須將其斬截破壞，若是不予毀壞依然算是墮罪。文中所指示如疏文所說，疏文說已經做好的衣服用斧頭斬壞，此處卻說成切人之意（或字誤），如何能講通？

【427-0007】資持記/08c_中二#62
【原文】如《五分》云：施已成，亦犯墮等。十二。〔佛在毘舍離，梨車子多行邪行，披黑毛氈夜行，使人不見，六群學作招譏而制。〕會名中。總決前後四戒，《十誦》並號敷具。昔人疑者，彼謂臥具是被褥故。《僧祇》，彼因諸比丘作氈三衣坐具招幾因制。
【譯文】正如《五分律》所說：別人布施已做好的蠶綿衣服，接受也犯捨墮罪等。「第十二戒（純黑羊毛作敷具戒）」。〔佛陀在毘舍離國時，梨車族的公子多行淫邪放蕩之事，夜間披著黑羊毛織的毛氈出行，使人看不見蹤跡，六群比丘仿效其做法因而招致世俗譏嫌，佛陀於是制定此戒。〕在會通戒名中。總括決斷前後相連的四條戒，《十誦律》中一律稱之為「敷具」。古人產生懷疑，是因為他們誤以為臥具只是專指被褥鋪墊。《摩訶僧祇律》說，該戒起因於諸比丘用黑氈做成三衣及坐具，招致外人譏嫌而制定。

【427-0008】資持記/08c_中二#63
【原文】文舉伽梨，略餘二衣，故云乃至。此證二毛非被褥明矣。犯相中。指如上者，即蠶綿戒。不犯十二相。二三注顯，皆謂本作是心，故作成不犯。儭鉢內者，障塵垢故。攝熱巾者，為儭手故。十三。〔佛在舍衛，六群純以白毛作臥具招譏故制。〕指同異。云因緣同前者，黑白雖異，起過招譏事不別故。

【譯文】制訂這條戒律加以防範約束，是為了熄滅惡念、生長善法的緣故。在解釋戒相、列舉項目的段落中。第六項正屬於本條戒律的規範本體，其餘各項都是附帶加以說明的。在第八項中所說的各類貴重物品，《戒疏》解釋：是指佛陀不允許持有的物品，例如蓄養婦女以及私藏兵器器仗之類。從這裡以下作總結說明，首先說明三藏經典中所記載的內容，只統稱為八種不淨、八種毒蛇、八種污穢等名稱。《涅槃經》雖然列舉了這些物品，但並沒有固定次序，所以說是通括列計。經中彰顯其過患而不應當畜養的文句，如同下文所詳細引用的。從「相承」以下，說明依照古德傳統相承所列出的次第。

【原文】疏云：古來相傳，既有八名，須知八相，故言不出佛經。顯過中二，初明過重，前引制緣。毘尼祕勝，不許外聞。獨此對俗，意如文顯。律云：佛告大臣，若見沙門釋子，以我為師，而受金銀錢寶者，則決定知非釋子。故下，次示四患。酒、婬、錢寶、邪命，此四不唯本律，故通指之。即此戒是者，四患中一也。
【譯文】《戒疏》說：自古相傳以來，既然有八種名稱，就必須明白八種具體相狀，因此說其名稱並非直接出自佛經原文。在彰顯過失的內容中分為兩部分，首先說明過失極為深重，前面引用了制戒的因緣。戒律（毘尼）法門極其深奧尊貴，本來是不允許外行俗人聽聞的。唯獨這條戒律是直接對著在家人宣說，其深意正如經文所顯露的那樣。律中說：佛陀告訴大臣，如果看見沙門釋子，自稱以我為師，卻接受金銀錢寶，那麼就可以斷定他絕對不是釋迦牟尼佛的弟子。因此從下文開始，接著說明出家人的四種大患。飲酒、行淫、貪戀錢寶、營謀邪命，這四種禍患不僅見於本律，所以在此通括指出。本條戒律所規範的，正是四患當中的金錢珍寶。
