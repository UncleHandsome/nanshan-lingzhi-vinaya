# 校閱材料　第785檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【785-0001】02_戒疏/18b_卷四上之三#92
【原文】【疏】凡飲食繁穢，近則長貪，令人不節。又體現交盡，義無貯畜，故置異處，不得輒噉。然今行人，但存省事，隨宜受納，不思遠大，致使教法日就崩離，稱心之過，知何不犯？是以大聖，隨事節約，若衣若食，並有軌儀。緣而不曉，即結無知；可學不涉，又結怠惰。意令割略我倒，專心思道，不令貯畜，用遺愚著，故制斯戒。
【譯文】【疏文】凡是飲食繁雜穢污，靠近它就會增長貪欲，使人不知節制；又食物之體現前受用即盡，義理上不應貯藏積畜，所以要放置在別處，不可隨便就吃。然而現今修行的人，只求省事，隨意受納，不思考長遠的大事，致使教法一天天走向崩壞離散；一味順遂心意的過失，哪有什麼戒是不犯的呢？因此大聖隨事加以節制約束，無論是衣是食，都有軌範儀則。遇到境界而不明白，就結「無知」之罪；可以學而不去學，又結「怠惰」之罪。用意是教人割捨、簡略我執顛倒，專心一意思惟道法，不許貯藏積畜，以此遣除愚癡的執著，所以制定這條戒。

【785-0002】02_戒疏/18b_卷四上之三#93
【原文】【記】三十八，制意為三。初敘食過，文列二過：一、貪染不可近，二、現物不宜畜。「置異處」者，即淨地中。「然」下，次敘違犯。此據緣起坐禪比丘，故言「省事」，今時貪恣，則非所敘。「不思」等者，已雖少欲，凡愚相倣，疾滅法故。「稱心過」者，充其所欲，欲即妄情，必須制故。「是」下，三、彰聖制，又三。初明根本制，文通諸罪，意在今戒。「緣」下，次明重增制。即無知犯提，不學得吉，此二該通止、作兩犯，如前所明。「意」下，顯教益，即生善滅惡也。
【譯文】【記文】三十八戒的制意分為三節。開頭敘述飲食的過失，文中列出兩種過失：一、貪染之心不可親近；二、現前的食物不宜貯畜。「置異處」，就是指放在淨地之中。「然今行人」以下，其次敘述違犯的情況。這裡是根據緣起中坐禪的比丘而說，所以說「省事」；當今之人貪婪放縱，就不是這裡所敘述的了。「不思遠大」等句，是說自己雖然少欲，但凡夫愚人互相仿效，會使教法迅速滅亡的緣故。「稱心之過」，是說充遂其所欲，欲望就是虛妄的情識，所以必須加以制止。「是以大聖」以下，第三是彰明聖人的制教，又分三層：先說明根本的制教，文中通於諸多罪相，用意在於今此一戒；「緣而不曉」以下，其次說明因重增而制的教，就是無知犯波逸提、不學得突吉羅，這兩種通於止犯、作犯兩類，如前所說明；「意令割略」以下，顯示教法的利益，就是生善滅惡。

【785-0003】02_戒疏/18b_卷四上之三#94
【原文】【疏】論犯三緣：一、是殘宿食；二、知是；三、咽，便犯。殘、宿相對，四句分之。殘宿、內宿，亦有四句。可如《鈔》引。
【譯文】【疏文】論犯此戒有三種緣：一、是殘宿食；二、知道是殘宿食；三、一咽便犯。「殘」與「宿」相對，分為四句。殘宿與內宿的對照，也分為四句。可以照《鈔》中所引。

【785-0004】02_戒疏/18b_卷四上之三#95
【原文】【記】犯緣中。初列示。「殘」下，指句。兩重料簡，俱指如《鈔》，今為引之。彼云：「一、殘而非宿，吉；二、宿而非殘，亦吉；三、亦殘亦宿，提；四、非殘非宿，無罪。」次四句者：「一、是殘宿，非內宿，得墮；二、是內非殘，吉；三、四俱句，與前無別。」
【譯文】【記文】這是「犯緣」部分。首先列出顯示。「殘、宿相對」以下，是指示句數。兩重料簡，都指向如《鈔》所說，現在為之引出。那裡說：「一、是殘而非宿，得突吉羅；二、是宿而非殘，也得突吉羅；三、既是殘又是宿，得波逸提；四、非殘非宿，無罪。」第二重四句是：「一、是殘宿而非內宿，得墮；二、是內宿而非殘，得突吉羅；三、四兩句，與前面沒有差別。」

【785-0005】02_戒疏/18b_卷四上之三#96
【原文】【註】佛在羅閱祇。迦羅坐禪，乞食疲苦，食先得者。比丘於小、大食上不見，覓之，具說所由。比丘白佛，佛便訶言：「汝雖少欲，後來眾生相法而行。」因即制戒。
【譯文】【註文】佛在羅閱祇。迦羅坐禪，覺得乞食疲累辛苦，就吃先前所得的食物。比丘們在小食、大食的時候不見他，去尋找他，他詳細說明了原由。比丘們稟白佛陀，佛便訶責說：「你雖然少欲，但後來的眾生會互相仿效（你的做法）而行。」因此就制定了這條戒。

【785-0006】02_戒疏/18b_卷四上之三#97
【原文】【疏】就緣起中，此戒不受，以「坐禪」人為緣起者。約情為論，輕戒而重觀門，故佛言：「後來眾生相法而行。」非法而行，何可妄也？
【譯文】【疏文】在緣起中，這條戒所說的「不受（而食）」，是以「坐禪」的人作為緣起。就人情而論，是輕視戒律而看重觀門，所以佛說：「後來的眾生會互相仿效而行。」不依正法而行，怎麼可以隨便妄為呢？

【785-0007】02_戒疏/18b_卷四上之三#98
【原文】【記】戒緣中。初牒文。「約」下，出意。「非」下，結勸。今時禪、講各尚己宗，頓忘戒律。況加輕弄惑誑後生，謂持戒則徒自拘囚，學道則不勞把捉。豈念壇場立誓，盡壽堅持？非戒無以為僧，非戒將何受施？阿鼻苦楚，本為忘恩；瘖瘂盲冥，良由謗法。金言呵制，明為將來，後學聰明，幸遵慈訓。
【譯文】【記文】在戒緣這一段中，首先牒引疏文；「約」字以下，是顯示用意；「非」字以下，是總結勸誡。當今參禪的人與講經的人，各自崇尚自己的宗派，頓時忘失了戒律。更何況又加以輕慢戲弄，迷惑欺誑後學，說持戒只是白白地自我拘束，學道則不必勞煩把捉。哪裡想到在戒壇上立下的誓願，要盡形壽堅持？沒有戒就不能成為僧伽的一員，沒有戒又憑什麼接受信施？阿鼻地獄的劇烈苦報，本來就是為忘恩而設；成為瘖啞、盲冥的人，實在是由於謗法。佛陀金口呵責制戒，明明是為了將來的人；後學之人若有聰明，但願遵奉這慈悲的教誨。

【785-0018】02_戒疏/18b_卷四上之三#109
【原文】【疏】就第二句，注解中。《十誦》云：「此方殘宿食，餘二方不得食。北方宿食，開三方食，以無我所故。」制不受食，意拔我根，著色味故。餘辨相中可解。《鈔》中大分別也。
【譯文】【疏文】就第二句而言，是在注解中解說的。《十誦》說：「此方（南洲）的殘宿食，其餘二方不得食用；北方的宿食，開許三方食用，因為北方沒有『我所』的緣故。」制立不受食（戒），用意是拔除「我」的根本，因為眾生貪著色味的緣故。其餘辨別行相的部分可以理解，《鈔》中有詳細的分別。
