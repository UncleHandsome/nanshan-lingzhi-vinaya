# 校閱材料　第417檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【417-0001】資持記/07e_中一下#8
【原文】捉物吉者，次方便也。〔準今所判犯蘭。〕動物近方便，可解。次科，別列中，初句。約判斷明犯。以重入輕者，凡判亡物，須差律師，處斷重輕，歷疏告眾；判重為輕，犯夷；判輕為重，得蘭；並望文疏成時，以定犯相。非法判用者，此約常途，妄書簿曆之類。
【譯文】捉持物品犯吉羅，屬於次方便。〔依照現今的判例應當犯偷蘭遮。〕挪動物品屬於近方便，這很容易理解。第二個綱目，在分別列舉中，第一句是依照判定處斷來明示犯相。所謂「以重入輕」，凡是判定亡僧的遺物，必須差派律師，裁斷物品的輕重，寫入文疏向大眾宣告；若將重物故意判為輕物，律師犯波羅夷；將輕物判為重物，律師得偷蘭遮；這些都要看判決文疏寫成宣告之時，來定其犯相。所謂「非法判用」，這是就平常的情況，例如虛妄書寫帳冊簿籍之類。

【417-0002】資持記/07e_中一下#9
【原文】《善見》下，如作契書，分判地界。一頭輕者，如書所從處時，方便蘭也；兩頭重者，復書所至處時，究竟夷也。畫字誤，論作書字，《戒疏》亦依論引。〔或云：畫地作字，不約契書者，恐不合科意。〕次句。但約口斷即犯。《善見》二節，初約盜地。僧皆重者，以同情故。若下，二約斷諍。
【譯文】《善見律》以下所說，就像訂立契據文書，劃分判定田地界線。一頭輕的，比如剛寫出土地起點的處所時，構成方便偷蘭遮罪；兩頭重的，當又寫完土地終點的界線時，便構成究竟波羅夷重罪。「畫字」是傳抄錯誤，原論中作「書字」，《戒疏》也是依據論書引用的。〔有人說：在地上畫出字樣，不涉及契約文書，這恐怕不符合科判的本意。〕第二句，只憑口頭判定就構成犯罪。《善見律》分兩節，第一節是關於盜地，參與的僧眾都得重罪，因為彼此心意相同。從「若」字以下，第二節是關於裁判紛爭。

【417-0003】資持記/07e_中一下#10
【原文】違理判與者，能判犯也；違理判得者，所判犯也。下引《四分》，即約辯說。文如前引。第三句。標者，下注顯相，如今丈尺之類。文中，且引盜二標犯；準論，若盜三標，一舉吉，二舉蘭，三舉重，乃至盜十標；前八並吉，九蘭，十重。〔舊云前九蘭者，不見論文。〕四墮籌者，謂下籌多而令物少。
【譯文】違背法理判給他人的，是能判斷之人犯重罪；違背法理受判而得物的，是被判得之人犯重罪。下文引用《四分律》，就是指憑藉口才辯說奪取財物。文義如同前面所引用。第三句。所謂「標」，下方的注釋顯示了它的形相，就像現今丈量田地的尺標之類。文中暫且引用偷盜兩個標記而構成犯罪；依照論書，如果偷盜三個標記，拔起第一個犯吉羅，拔起第二個犯偷蘭遮，拔起第三個犯重罪，甚至偷盜十個標記；前八個都犯吉羅，第九個犯偷蘭遮，第十個犯重罪。〔舊說前九個都犯偷蘭遮，那是沒有見過論書原文。〕第四「墮籌」，是指藉由多投計算數量的籌碼而使分發的物資減少。

【417-0004】資持記/07e_中一下#11
【原文】或不下籌而取多物，雖非文意，世有其事。五中，初引《十誦律》論，約異色犯。如毛綿杼織，以成華朵鳥獸之物；而牽挽移易，損彼物故。或如下，次準本律，約損色犯。文義可見。六轉齒，如世賭博，多用齒骨，擲采博物；盜心移轉，隨物成犯。摴蒲蒲博，皆賭物之異名，亦名博弈。
【譯文】或者不投籌碼卻取走多份物資，雖然這不是律文原意，但世間確實有這種事情。第五句中，首先引用《十誦律》的論述，是就改變顏色而構成犯罪。比如用毛綿織造，結成花朵鳥獸圖案的物品；卻去拉扯挪移改變，損壞了那件物品。或者如同下文，其次依照本律，是就損壞色相而構成犯罪。文字的義理顯而易見。第六「轉齒」，如同世間的賭博，多用獸齒獸骨，投擲骰子爭奪財物；以盜竊之心暗中移動骰子，隨著牽涉的財物而構成犯罪。摴蒲、蒲博，都是博取財物的不同名稱，也叫做博弈。

【417-0005】資持記/07e_中一下#12
【原文】文中，先引《十誦》示盜相。次引《五分》明賭博。七中。彼明盜四足者，驅向所期，足遍犯重，不隨所向者輕〔雖離，但得蘭罪。〕；本期不定，舉遍即重；本主來逐，心未得者輕〔即文中所謂未作得想也。〕。第八句。《善見》得心已決，微動即犯，不待離處。如下，舉喻。可解。九中。
【譯文】文中，先引用《十誦律》指示盜竊的形相。接著引用《五分律》說明賭博的過失。第七句中，那裡說明偷盜四足牲畜，驅趕牠們朝向預定的地方，牲畜四足全部走過就犯重罪，不遵從驅趕方向的則犯輕罪〔雖然離開原地，但只得偷蘭遮罪。〕；若原本預定的界限不明確，牲畜四足全部抬起走動就犯重罪；原主人前來追趕，盜者心想尚未得手的則犯輕罪〔也就是文中所謂尚未生起得物之想。〕。第八句，《善見律》認為盜心既然已定，物品稍微移動就構成犯罪，不必等脫離原處。如下文所舉的譬喻，容易理解。第九句中。

【417-0006】資持記/07e_中一下#13
【原文】田宅等物，永不可離；不同上句，可離不離。第十。且出空弋水注三相。律中明處，則有十三；疏中次解，今略引示。初地中〔即是伏藏，有主望主結；佛僧𮋭，屬佛僧。〕，二地上〔如今道地得物〕，三乘〔謂象馬等乘，乘盜乘上物，離乘方犯；若兼乘盜，乘離即犯。
【譯文】田地房屋等不動產，永遠不可能搬離原處；這不同於上一句，屬於可以搬離而不去搬離的情況。第十句，暫且列舉出空中、木樁、流水三種相狀。律中說明的處所共有十三種；《戒疏》中依次作了解釋，現在簡略引用說明。第一「地中」〔就是地下埋藏之物，有主的對物主結罪；若是佛物或僧物，則歸屬佛僧。〕，第二「地上」〔如同現今在路上拾得物品〕，第三「乘」〔是指象、馬等騎乘工具，如果偷取乘坐工具上的物品，物品脫離乘具才算犯戒；若是連同乘具一起偷走，乘具一動就犯戒。

【417-0007】資持記/07e_中一下#14
【原文】四擔〔同乘兩分〕，五空〔謂衣物鳥等，從風所吹，而欲盜取；即此空處，以辨離處。《善見》：盜空中鳥，左翅過右翅，尾處至頭，上下亦爾，俱得重罪。〕，六架〔即曲弋也，若盜物者，物離方犯；若連架者，架離即犯。〕，七村〔或盜村物，或盜村體，擊破壞等。〕，八阿練若〔村外空地，同村可知。〕。九田〔《十誦》：若為田故，相言得勝者，重；不如者輕。
【譯文】第四「擔」〔與乘具一樣分為偷物或兼偷擔具兩種情形〕，第五「空」〔是指衣服、鳥雀等，被風吹在空中，而企圖盜取；就在這虛空之中，來判定是否脫離原位。《善見律》說：盜取空中的飛鳥，左翅越過右翅的原位，尾部移到了頭部的原位，上下挪移也是如此，都構成重罪。〕，第六「架」〔就是曲柄的掛木，如果只偷懸掛之物，物品脫離木架才犯；若是連同木架一起偷，木架移位就犯。〕，第七「村」〔或者盜取村裡的財物，或者毀壞村落本身，進行破壞搗毀等。〕，第八「阿練若」〔村莊外的荒野空地，情況如同村莊一樣可以推知。〕。第九「田」〔《十誦律》：如果為了爭奪田地，訴訟而勝訴者犯重罪；敗訴者犯輕罪。

【417-0008】資持記/07e_中一下#15
【原文】若作異相，過分勝者，重。〕，十處所〔如店肆作處，盜物盜體，同上村中。〕，十一船處〔盜物即以船為處；盜船體者，斷繩離處方犯。〕，十二盜水〔即斷水注也，《僧祇》：溉灌水，或一宿，直一文，或至四五；若壞彼渠，得越；水入田蘭，滿五者夷。〕，十三私度關〔如律：比丘無稅，白衣應稅，為彼過物重。

【原文】是以小律結其大過，大教歎其深功。況大小由教，俱是聖言；一抑一揚，豈容乖異。且經明出家菩薩，那云不許比丘〔彼云：捨身非沙門所為。〕；傳列苦行遺身，豈是專存通俗〔彼云：經中所明，事存通俗。〕。荊溪所謂依小不燒則易，依大燒之則難；
【譯文】因此小乘律藏結其為大過失，大乘經典卻讚歎其有深厚功德。何況大乘與小乘都出自佛陀教敕，全都是聖人所說之言；一貶一褒，豈能容許互相乖謬違背？況且大乘經中明明指明是「出家菩薩」，怎能說不允許比丘為之〔彼傳說：捨身並非沙門所應為。〕；高僧傳中陳列的諸多苦行捨身之事，難道只是專門存留在世俗俗人之中嗎〔彼傳說：經中所明示之事，是針對通途俗人。〕？荊溪湛然大師所謂：依照小乘律不燒身指則容易做到，依照大乘經燃燒供養則難能可貴；
