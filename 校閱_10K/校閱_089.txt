# 校閱材料　第089檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【089-0001】01_行事鈔/05b_卷中之一#13
【原文】三明發戒緣境寬狹。上卷受緣，已略明發戒方法，但心隨境起，故今廣論，令知戒德之高廣，亦使持者有勇勵。就中分四：一能緣心，現在相續心中緣。二所緣境。境通三世，如怨家，境雖過去，得起惡心，斬截死尸。現在怨家子，有可壞義；未來諸境，可以準知，故緣三世而發戒也。《成論》問：為但於現在得律儀，從三世眾生得耶？答：三世眾生所得。如人供養過去所尊，亦有福德；律儀亦爾。三發戒，現在相續心中得。四防非者，但防過去未來非，現在無非可防。問：毘尼殄已起，戒防未起，何得言斷過去非耶？答：境雖過去，非非過去，猶是戒防未起非。又解云：一專精不犯，戒防未起非；二犯已能悔，還令戒淨，即除已起非。餘如《戒本疏》解。然則緣境三世，得罪現在，過未二境，唯可起心，說言三世發也；若據得戒，唯在現在一念。《成論》云：慈悲布施，是亦有福；戒亦可爾，以通三世，皆與樂意。又云：慈功備物，但通現在，過未已謝；戒則不爾，要必普周，若作偏局，一向不合。故《多論》云：以惡心隨戒有增減故。問：戒從三世發，唯防二世非者？答：若論受體，獨不能防，但是防具；要須行者秉持，以隨資受，方成防非。不防現在，以無非也。若無持心，便成罪業；若有正念，過則不生故也。然又以隨資受，令未非應起不起，故防未非；若無其受，隨無所生。既起惡業，名曰過非；為護受體，不令塵染；懺除往業，名防過非。若爾，戒必防非，非何故起？答：要須行者，隨中方便，秉持制抗，方名防非。如城池弓刀，擬捍擊賊之譬。餘如《戒本疏》中解之。
【譯文】三明發戒緣境寬狹。上卷受戒緣起中，已簡略說明了發心納受戒體的方法，但心念是隨著所緣境而生起的，故如今在此廣泛論述，為了讓人了知戒德的高妙廣大，同時也使持戒之人產生勇猛勉勵之心。其中分為四個方面：第一、能緣心，是在現在相續的心識之中去攀緣。第二、所緣境。境通於過去、現在、未來三世。例如仇人怨家，其境界雖然已成過去，但人仍可生起惡心去砍斫他的死屍；現在的仇人之子，具有可以被毀損破壞的意義；未來的種種冤家情境，皆可依此類推，故是遍緣三世境界而發起戒體。《成實論》提問：是單單於現在境上得律儀呢？還是從三世眾生境上得律儀呢？回答說：是從三世眾生處所得。就如同有人供養過去已謝世的世尊與長輩尊宿，同樣具有福德；律儀戒法的發起也是如此。第三、發戒，是在現在相續的心念中獲得戒體。第四、防非，只是防禦過去與未來的過非，現在當下一念之中並無過非可防。問：律藏戒律（毘尼）是為了滅除已經生起的過非，戒法是為了防禦尚未生起的過非，如何能說戒是斷除過去的過非呢？回答說：境界雖然過去了，但內心追惡的心非並未過去，戒法防護的依舊是「防護未來未起的過非」。另外又有一種解釋：一是專精持守而不毀犯，戒法便防禦了未起之非；二是毀犯之後能夠如法懺悔，使戒體重獲清淨，這就是除滅已起之非。其餘義理如《戒本疏》中所釋。然而，攀緣境界雖通三世，結罪得罪卻在現在；對過去與未來的境界，只是能生起此心，故說是在三世境上發戒；如果依據得戒的當下而言，則唯在現在的一剎那念中。《成實論》說：慈悲與布施，同樣具有福德；戒法也是如此，因為它遍通三世，都懷抱著給予眾生安樂的善意。論中又說：慈悲的功效利益萬物，只通於現在，過去與未來已經謝滅或未生；戒法卻不是這樣，必須普遍周全於一切境界，如果有所偏私局限，就完全不符合受戒的真諦。故《薩婆多論》說：這是因為防惡之心隨著戒境的廣狹而有增減之故。問：戒既然從三世境上發起，為何說唯防過去與未來二世之非呢？回答說：若單論受戒時所得的戒體，它本身孤立時並不能防禦，只是一件「防惡的器具」；必須依靠修行者切實秉持行持，以隨行的力量來資助受體，方能成就防非止惡的功用。不說防禦現在，是因為現在若具正念便當下無非可防。如果沒有持戒之心，當下便已結成罪業；如果有正念在心，過錯當下便不會生起。此外，以隨行資助受體，使未來本應生起的過非不再生起，故稱為防禦未來之非；如果當初沒有受戒之體，隨行的防護也就無從依托生起。倘若已經生起惡業，便稱為過非；為了護衛受體不使它遭受塵垢染污，進而如法懺除以往的罪業，這就稱為防除過去之非。如果這樣，戒法既然必定防非，過非為何還會生起呢？回答說：必須依靠行者在隨行之中運用種種加行方便，秉持戒念去制伏抗拒惡緣，才叫做防非。這就如同修築城池、備辦弓刀，是用來防衛抵禦擊退賊寇的譬喻一樣。其餘義理如《戒本疏》中詳細解釋。

【089-0002】01_行事鈔/05b_卷中之一#14
【原文】四明發戒多少。略如上明。今又述者，以世俗多迷，故廣銓敘，意存識相知法，自濟兼人故也。然所發戒數，隨境無量。要而言之，不過情與非情，有無二諦，攝相皆盡，任境而彰。略說則地水火風空識等界，及色聲香味觸等五塵；乃至過未三世，法界等法；及六趣眾生，趣外中陰，四生，亦發得戒。
【譯文】四明發戒多少。概要如上文所述。如今再次詳述的原因，是因為世俗之人大多迷茫不解，故廣泛評述鋪敘，用意在於使大家認識戒相、通曉戒法，以達到自度度人的目的。然而受戒所發起的戒法數量，隨其所緣的境界而無量無邊。總要而言，不外乎有情與非情、真有與真無二諦（世俗與勝義二諦），所含攝的萬象完全包攬無遺，任運隨境界而彰顯。簡略來說，則有地、水、火、風、空、識等六界，以及色、聲、香、味、觸等五塵；乃至過去、未來、現在三世，法界等一切萬法；以及六道輪迴的有情眾生、六道之外的中陰身、卵胎濕化四生，在這些境界之上都能發起而得到相應的戒體。

【089-0003】01_行事鈔/05b_卷中之一#15
【原文】上來懸舉。次引文證。
【譯文】以上是預先標舉大綱。接下來引述經論文獻以為證明。
