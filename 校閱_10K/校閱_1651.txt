# 校閱材料　第1651檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1651-0002】03_業疏/07a_卷二之一#35
【原文】答：《四分》云「不得隔駛流水」，此明制也；「除常有橋船梁」，此明開也。如上《多》云「但定岸相」，《僧祇》中「但洲五處標結」，甚明文也
【譯文】回答：《四分律》說「不得橫跨湍急的流水」，這是明文禁止；「除非平時常有橋樑、船筏或木梁相通」，這是明文開許。如同上面《薩婆多論》所說「只要先劃定河岸界相」，《摩訶僧祇律》中說「只要在沙洲五處設立標記結界」，文旨非常明確。

【1651-0003】03_業疏/07a_卷二之一#36
【原文】初答中，《四分》「駛」即急疾，「梁」亦是橋，小大分之。《僧祇》「但洲」，水中孤絕者，彼明五標，兩在水中，三在陸地，如戒塲中具引
【譯文】在第一段回答中，《四分律》所說「駛」就是水流急促迅猛，「梁」也是橋樑，以此區分規模大小。《摩訶僧祇律》所謂「但洲」，是指水中孤立隔絕的沙洲，那裡說明設立五個界標，兩個在水中，三個在陸地上，如在戒場一節中詳細引用的那樣。

【1651-0004】03_業疏/07a_卷二之一#37
【原文】言村得不者，《四分》明文「除村、村外」，攝衣有文，明知攝僧不簡村也。《五分》白衣新作堂舍，為得吉利故，或非人所惱故，佛聽諸比丘於中布薩說戒，準此知界攝也。《多論》云：凡結大界，所以通聚落結者，以界威力故，諸惡不得便，善神所護，為檀越故通結聚落也。準此以言，良由僧德所動，作業圓成，善根所熏，界神護衛，不可輕也
【譯文】說到村落可不可以結界，《四分律》有明確文句說「除村落、村外」，在攝衣界中有此經文，由此明知攝僧界並不排除村落。《五分律》說在家人新蓋堂舍，為了求得吉利吉祥，或是因為遭到非人鬼神侵擾的緣故，佛陀聽許諸比丘在其中舉行布薩說戒，照此可知村舍也在結界統攝之內。《薩婆多論》說：凡是結大界，之所以通貫聚落一同結界，是因為結界的威力緣故，一切惡法惡鬼不得其便，能得善神護持，為了利益施主的緣故才通貫聚落一同結界。照此說來，實因僧眾的德行感召，作法羯磨圓滿成就，善根熏習所致，結界之神威嚴護衛，不可輕率忽視。

【1651-0005】03_業疏/07a_卷二之一#38
【原文】次答有三：初準《四分》攝衣羯磨，由村在界故須牒除。次準《五分》，俗舍既許布薩，理必結界。後據《多論》，即明通攝。所以諸惡，即魔邪變怪等事。「準此」下，疏家顯示神護之意
【譯文】第二部分回答有三點：首先比照《四分律》的攝衣羯磨，正因為村落在結界內，所以必須宣唱排除。其次比照《五分律》，俗人家宅既然允許布薩，按理必定也已結界。最後依據《薩婆多論》，即明確說明通貫包攝村落。所謂諸惡，即是指邪魔、怪異等事。自「準此」以下，是疏主顯示善神護持的用意。

【1651-0006】03_業疏/07a_卷二之一#39
【原文】五百問》云：界內病比丘不能僧中，求結一屋者，僧應先解大界，與結別界，還結大界，不持衣者不得入中。亦除佛地，由佛、僧位殊，不相攝故。中國佛院列異僧表，故有佛地、塔地、僧地，限域各別。此方未行，何得混雜？義須限約
【譯文】《五百問經》說：大界內有患病的比丘不能前往僧眾聚集處，請求單獨結一間房屋之界，僧眾應當先解除大界，為他結出一個別界，然後回頭再結大界，未隨身攜帶三衣的人不得進入其中。同時也要排除佛地，因為佛與僧品位不同，互不相統攝的緣故。中印度佛院排布在僧院之外，所以有佛地、塔地、僧地之分，界限領域各自不同。此地尚未實行此制，怎能混淆雜亂呢？在義理上必須劃定界限予以約束。

【1651-0007】03_業疏/07a_卷二之一#40
【原文】三別界中初科，論文前示緣開，仍教結法。次明護衣，且據作法攝衣為言，若據自然，則通彼此。三簡佛地。「由」下，疏家伸意。西土三寶地別，仍斥此方混濫。表，即外也
【譯文】在第三說明別界的第一科中，論典文字首先開示因事緣而開許，並傳授結界的方法。其次說明護持衣物，暫且是依據作法攝衣界而言，若是依據自然界，則通貫兩處。第三是簡除佛地。自「由」字以下，是疏主申述用意。西天印度三寶的地界各自不同，進而斥責此地混雜混濫。「表」，就是外面的意思。

【1651-0008】03_業疏/07a_卷二之一#41
【原文】又如《明了論》「圍輪別住」者，先結三四小別住訖，周帀安相，四邊開路，即名蘭若地；此外結大別住圍之，如鐵圍山繞四天下。準此誠文，一大界內隨結五三，皆得成也
【譯文】又如《律二十二明了論》所說的「圍輪別住」，是先結好三、四個小別住（小界），周圍安置界標，四邊空出道路，這便稱為阿蘭若地；在這之外再結大別住（大界）圍繞著它們，如同鐵圍山圍繞著四大部洲一樣。依照這一明確文獻，在一個大界之內隨意結三、五個小界，都能成辦。

【1651-0009】03_業疏/07a_卷二之一#42

【譯文】下一科中，首先引用論典「圍輪別住」之說，即是下文所引十七種別住之一。「蘭若」翻譯為空閒處，即是指中間相隔的自然界。下文舉出比喻予以顯明，即彰顯其名稱與含義。「鐵圍」，玄應法師說梵語為「柘迦羅（Cakra-vāḍa）」，此處翻為「輪山」，所以稱為圍輪。參照下文的判決即可明白。

【1651-0010】03_業疏/07a_卷二之一#43
【原文】二、戒場量者。《善見》云：容二十一人，減則不聽。此據極小為言，二十出罪兼所為者，故局此耳。彼論又云：場內不得安僧住處，有慚比丘須折却，唯置佛殿

【1651-0011】03_業疏/07a_卷二之一#44
【原文】戒場中，初明小量。且據一眾行事備足，故不聽減。若兼二眾，須容四十一人。彼下次示廣量。既制僧住，顯知非狹
【譯文】在戒場之中，首先說明最小容量。暫且是依據比丘僧一個僧團行事完備而言，所以不允許減少。如果兼顧僧尼二眾（如尼眾出罪等），就必須能容納四十一人。自「彼」字以下，其次指示廣大的容量。既然禁止僧人在此居住，明顯可知其地界並不狹小。

【1651-0015】03_業疏/07a_卷二之一#48
【原文】就攝僧界，文又分三：初為自然勞倦，眾取濟機，開立大界；界限制約，事雜煩多，又開戒場；上二常途，難濟非務，故開小界。各如文次，當自分別
【譯文】就「攝僧界」而言，文中又分為三部分：首先是因為自然界中奔走勞頓疲憊，為使大眾便於成辦僧事，所以開許設立「大界」；其次因大界範圍寬廣而有所限制制約，且日常雜事繁多紛擾，所以又開許設立「戒場」；以上兩種界是常規之法，難以應對非日常的突發難緣，所以開許設立「小界」。各部分依照文中次第，應當分別辨明。
