# 校閱材料　第290檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【290-0001】資持記/11a_中四上#61
【原文】自作教┐┌自作止持通四行〔作意離過〕　　　止持〔令人漉木〕人四行││自作作持通四行〔說淨畜長〕　　　作持〔持欲僧中〕├┤皆通總││自作作犯通四行〔自作婬事〕　　　作犯〔令人殺主〕十六句┘└自作止犯通四行〔自起不學〕　　　止犯〔不乞造居〕四明相成，總指中。
【譯文】自作教人四行皆通總十六句：自作止持通四行（作意遠離過非）──止持（教令人用濾水囊漉水）；自作作持通四行（說淨畜積長物）──作持（遣他人向僧中陳說與欲）；自作作犯通四行（自己造作淫事）──作犯（教令人去殺害物主）；自作止犯通四行（自己生起不學戒心）──止犯（不乞僧團處分便造僧居）。在第四「明相成」（明瞭業力相互促成）的「總指」（總體指歸）之中。

【290-0002】資持記/11a_中四上#62
【原文】塞謂自起方便，後趣正果，即是自業相成；此如常途，故云易解。通義如前，一中具四，故云無異。自業與教人，事有不同，故云相別；如下可見。示相中。初四句即列四行，當自分之。禁沙彌者，即作持也。律制教沙彌，常須禁閉在房故。此下二句，總示。比四者，是前方便。後修止持，前四同就，一中通四。
【譯文】阻隔不通是指自己先發起前方便的行為，後續直接趣向根本正果，這就是自身的業力相互促成；這就像一般常規的理解，所以說很容易理解。通融相通的意義如同前面所說，在單一一種行持之中具備了四種行持，所以說並沒有差別。自身的業力與教唆他人，在事相上略有不同，所以說兩者互有分別；如同後文即可看清。在「示相」（展示相貌）之中。前四句就是排列出四種行持，應當依照其各自的本位加以區分。所謂「拘禁沙彌」，指的就是作持。律典強制規定管教沙彌時，通常必須將他拘禁防閉在房舍中的緣故。「此」字以下兩句，作總體開示。上述這四件事，屬於前方便。後來修習止持時，前面四件事同時成就，這就是一種行持之中通貫了四種行持。

【290-0003】資持記/11a_中四上#63
【原文】餘三同此。乃下，指餘三行，類準作之，亦為圖相。自業相┐┌後修止持通四行〔作意離過〕　　　止持〔自安漉具〕成通中││後修作持通四行〔乞法造房〕　　　作持〔禁閉沙彌〕├┤四行總││後修作犯通四行〔自盜他物〕　　　作犯〔自安殺具〕十六句┘└後修止犯通四行〔作意斷學〕　　　止犯〔現不與欲〕點示中。前第二門，具通兩種止犯；
【譯文】其餘三種情況與此相同。「乃」字以下，指明其餘三種行持，皆可依此類推準則去推演，同樣也可以繪製成圖表相貌。自業相成通中四行總十六句：後修止持通四行（作意遠離過非）──止持（自己安置濾水器具）；後修作持通四行（如法乞法造房）──作持（將沙彌拘禁房中）；後修作犯通四行（親自偷盜他人財物）──作犯（自己設置殺生器具）；後修止犯通四行（起心作意斷絕學戒）──止犯（現前不肯如法與欲）。在「點示」（點明提示）之中。前面第二門，完整通貫了兩種止犯；


【290-0004】資持記/11b_中四上#1
【原文】後二竝約造作，不論不學止犯。問：如教人事已，自起斷學，何有不得？答：能通可說，文點所通耳。五漸頓門，就心中。此門不約造作成行，但望起心總別，以明頓漸。正明中，初列四頓。若下，次指四漸。但望一境為言。問：遍通諸境，可名為頓；或緣三五，起持犯心，為漸為頓？
【譯文】後兩種持犯完全是就造作行為而論，不討論「不學習戒律而導致的止犯」。有人問：如果是指使他人辦完事後，自己內心生起斷絕學戒的念頭，為何不能算在此類？回答：若就自身造作（能通）而言是可以這樣講的，但鈔文的重點僅在於點明所教唆的四件事（所通）罷了。第五「漸頓門」，是就內心發起狀態而論。這個門類不依據外在造作成業的行為，僅僅看內心生起的總相或別相，以此來說明漸犯或頓犯。在正面說明中，最初列出四種頓犯；緊接著提到「若」字以下，則是指四種漸犯。這只是就面對單一境緣來說的。有人問：普遍緣於一切境，可以稱為「頓」；倘若只是緣於三、五個特定對象，生起持戒或犯戒的心，究竟算漸還是頓？

【290-0005】資持記/11b_中四上#2
【原文】答：但一名漸，自二已去，皆名為頓。顯意中。此論持犯，但望起心，與體違順不同；次科對事造作。應知二持心約，即約通持；望本受體，塵沙事法，發無邊善。兩犯亦爾。若論作犯，對緣正作，自隨前犯；此中止是泛爾起心，可望本受，通犯吉罪。止犯頓漸，如下別解。次對行中。
【譯文】回答：只要只對一個境，就稱為「漸」；從二個境以上開始，全都可以稱為「頓」。在顯明主旨（顯意）的文句中：這裡討論持犯，純粹是看內心的發起，與戒體產生順應或違背的不同；接下來的科判才是對應外在事物而造作。應當知道，「兩種持戒」的發心，是就通攝持戒而言；面對當初所受的戒體，緣於塵沙般無量的事境法相，能引發無邊的善心。作犯與止犯這「兩種犯戒」也是如此。如果論及「作犯」，面對事緣正在造作時，自然隨著前述的犯相結罪；此處僅僅泛指心中生起違逆之念，即可對照原本領受的戒體，普遍結犯突吉羅罪。至於「止犯」的頓與漸，如下文將會個別解釋。接下來在對應實際行為（對行）的說明中。

【290-0006】資持記/11b_中四上#3
【原文】事相各別，心不同時，故唯漸也。但明三行，止犯一行，以涉義門，在下別解。二持可解。修慈是作，收作成止，故是止持。作犯中，初示漸義。且下，舉事以顯，初別舉殺戒。七心，即三不善單複歷之。四下，指餘諸戒。男子五十六，女人六十三；七殺在上明之，故男四十九，女五十六也。
【譯文】外在事相各個不同，心念也無法同一時刻生起，所以完全屬於「漸」。此處只說明了三種行（作持、止持、作犯），至於「止犯」這一行，因為涉及較複雜的義理門類，會在下文個別解釋。兩種持戒的意義容易明白。修習慈心本身是一種造作行為，但將造作收攝於止惡之中，所以屬於「止持」。在「作犯」之中，最初揭示「漸」的涵義。接著在「且」字以下，列舉具體事相來說明，先特別舉出殺戒為例。所謂「七心」，就是指以三種不善心（貪、瞋、癡），經過單獨或複合的心態歷緣而生。在「四」字以下，則是指其餘各條戒律。男子有五十六種情況，女人有六十三種情況；其中殺戒的七種心已在上方說明過，所以除去殺戒後，男子為四十九種，女人為五十六種。

【290-0007】資持記/11b_中四上#4
【原文】指如前者，〈釋相〉初也。止犯中。若據事法止犯，唯漸非頓；合在上科，文略不出，此門唯明不學止犯。四句，即下四科。初門。泛論漸頓，有二不同：一者先後，即是此門；二者一多，即如次門。文中，不學先起者，此望初作斷學心也。準《義鈔》，先起下有故頓二字，文脫。
【譯文】文中指出「如前者」，是指〈釋相〉篇的開頭部分。在「止犯」之中。如果依據具體事法的止犯而言，只有漸犯而非頓犯；這本來應當合在上一個科判，因文字簡略而未列出，此門專門說明「不學習戒律」所產生的止犯。所謂「四句」，就是指底下的四個科判。第一門。大體討論漸頓，有兩種不同角度：第一是依前後時間，也就是本門所談；第二是依數量多寡，也就是下一個門類所談。文中提到「不學的心先起」，這是就最初生起斷除學戒的念頭而言。依照《律學義鈔》的說法，「先起」下方原本有「故頓」二字，此處律文脫漏了。

【290-0008】資持記/11b_中四上#5
【原文】無知後生者，先不斷學，不結無知；必假前成，故是漸義。三根不同，如後所辨。文下，引文證漸。別解，不學中，初總標。如下，別釋，又二，初明頓犯。云下，釋漸犯。無知中，初標。謂下，釋。不學約心，無知隨事。心有總別，故通漸頓；事不竝修，故唯局漸。
【譯文】所謂「無知後生」，如果先前沒有斷除學戒的心，就不會結成無知罪；必定是藉由前者的斷學才成立，所以屬於「漸」的涵義。利、中、鈍三種根性的不同，如後文所辨析。在引律文處，引證律文來證明屬於漸犯。個別解釋中，在「不學」這一項，最初作總體標示。在「如下」一句，個別解釋，又分為兩部分：先說明頓犯，在「云」字以下，解釋漸犯。在「無知」這一項，最初標名，在「謂」字以下進行解釋。不學是就心念而論，無知則是隨著具體事緣而生。心念有總括與個別之分，所以通於漸和頓；具體事緣無法同時並修，所以唯獨局限於漸。

【290-0009】資持記/11b_中四上#6
【原文】又不學罪，凡經兩結；若初起心，漸頓隨犯，如此所明；至後無知，隨事復結，如下句法。示罪中。以古今異判，故問辨之。答中，初出古解。今下，正判，初句明不學一品。無下，明無知重輕。引律證重，即不攝耳戒。疑猶涉解，故罪輕降。問：不學罪為出何處？答：受戒說相，即制依師；
