# 校閱材料　第539檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【539-0001】04_比丘尼鈔/04a_卷中之下#35
【原文】非時食戒具四緣犯一是非時二非時想三時食四咽咽便犯此律云時者明相出乃至日中按此時為法四天下亦爾毗羅三昧經云佛為法慧菩薩說食四種旦起天食時午時法食時暮時畜生食時夜鬼神食時後二種食多生病疾其出家人應作天食法食故曰時食過午已後非上二時故曰非時見論云吐食未出咽喉還咽無犯若出咽者提十誦云阿那律弟子病服吐下藥中後心悶佛言稻稗竹笋汁囊盛米粥絞汁與猶不差佛聽屏處食米粥食殘宿食戒具三緣犯一是殘宿食二知是三咽便犯此律今日受食自貯界內留至明日自煑食者咽咽得七罪謂三提四吉一不受二非時三殘宿四內煑五內宿六自煑七惡觸。
【譯文】非時食用食物戒具備四個條件即構成犯罪：一是處於非規定的時間；二是認定為非規定時間；三是食用正規食物；四是每咽下一口食物便犯本戒。本律說：合法的時間，是從黎明天明破曉開始一直到正午為止，按照這個時段作為規定的正時，四天下皆是如此。《毗羅三昧經》說：佛陀為法慧菩薩解說四種進食時間：早晨是諸天進食之時，正午是三世諸佛法食之時，黃昏是畜生進食之時，夜晚是鬼神進食之時。後兩種時間進食容易滋生各類病痛疾患，因此出家人應當遵循天食與法食的時間，所以稱為『時食』；過了正午之後，就不屬於上述兩種時間，所以稱為『非時』。《善見論》說：食物嘔吐反胃但未吐出喉嚨，隨後又吞嚥下去的，不犯戒；若是已經吐出咽喉之外又吞下的，犯波逸提罪。《十誦律》說：阿那律的弟子生病服下催吐或瀉下的藥劑，到了中午過後心胸煩悶，佛陀說：可以用布袋裝著稻稗或竹筍汁及米粥，絞出汁液給他喝；若依然不見好轉，佛陀開許可以在隱蔽之處喝稀米粥。【食殘宿食戒】具備三個條件即構成犯罪：一是屬於隔夜殘宿之食；二是明知是隔夜食物；三是咽下便犯本戒。本律規定：今天接受的食物，自己儲存在界內留到明天，又親自烹煮來食用者，每咽下一口得七種罪過，也就是三個波逸提罪和四個突吉羅罪：一是不受食戒、二是非時戒、三是殘宿戒、四是內煮戒、五是內宿戒、六是自煮戒、七是惡觸戒。


【539-0002】04_比丘尼鈔/04b_卷中之下#1
【原文】不受食戒具緣可解見論云天人鬼神畜生飛鳥皆成受食婆論云為作證明故非人畜生及無知小兒悉不成受此律除水及楊枝不須受僧祇云若風吹塵午駝振身塵來乃至眾鳥女人行衣曳地塵來如是一切塵坌鉢下草不坌食者成若及食者一切更須受唯畜生振身作意受者得自餘一切不作意受者應更從他受若行麨時抖擻麨器迸落鉢中作意者得名為受不作意者不名為受餘食亦爾五分云眼暗比丘得按萆受食見論云額汗流入鉢更須受臂中汗流入手不須受得食無罪十誦云行食時淨人觸比丘手若特輕故觸比丘手不應受婆論云手不淨受食犯吉僧祇云淨人行果菜時應語云懸空放果墮草上即去不名為受小停者得為受見論云遙擲從地轉來落比丘上成受僧祇云大會時淨人難得比丘受取行之若鎗鑊。
【譯文】（未受而食戒）犯此戒的構成要件容易理解。《善見律毘婆沙》說，天人、鬼神、畜生、飛鳥來授食，都算受食成功；《薩婆多毘尼毘婆沙》則認為，受食必須有人作證明，所以非人、畜生以及不懂事的小孩授食，都不能算受食成功。本律除了水和楊枝之外，一切食物都必須經過受食程序。《摩訶僧祇律》說，如果風吹塵土、牛或駱駝抖身揚塵，乃至群鳥飛過、婦女走動衣袍拖地揚起塵土，這一切塵土飛落，若只落在缽底的草墊上而沒有沾到食物，受食仍然有效；如果塵土沾落到食物上，所有食物就必須重新受食。只有畜生抖身時，比丘若起心作意接受，才算合法受食；其餘各種塵土飛來時若沒有作意受食，都應該重新向他人接受受食。分發炒麥粉時，如果抖動盛粉器具，麥粉濺落缽中，比丘起意接受就名為受食，若沒有起意就不算受食，其他食物也是如此。《五分律》說，視力昏暗的比丘可以撫摸著草蓆來接受食物。《善見律毘婆沙》說，額頭的汗水流進缽中，食物必須重新受食；如果是手臂上的汗水流到手上，就不需要重新受食，吃下去也沒有罪過。《十誦律》說，分發食物時淨人若是觸碰到比丘的手，如果是故意輕慢而觸碰，比丘就不應該接受。《薩婆多毘尼毘婆沙》說，比丘（尼）手不乾淨去接受食物，犯突吉羅罪。《摩訶僧祇律》說，淨人分發瓜果蔬菜時，比丘應當吩咐他：「懸空放手讓果物落在草墊上即可離去。」這樣不算受食；如果淨人稍微停留片刻才放手，就算受食成功。《善見律毘婆沙》說，從遠處扔擲過來，食物從地上滾過來落在比丘身上，就算受食成功。《摩訶僧祇律》說，舉行盛大法會時淨人難得，比丘可以親自接受並端拿搬運。至於像鐵鼎、鐵鑊這類器具，可能沉重得無法直接捧受。

【539-0003】04_比丘尼鈔/04b_卷中之下#2
【原文】不得受者當下以兩木橫置地比丘脚躡上言受受得成此律下文欲受油錯受蘇等不成受必令心境相當得成受此律受食已有三失一任運失謂受得已食時既過故云任運失也二遇緣失謂淨人觸失受也三自變生為熟失也見論云受生薑後生芽不失受火淨已生芽處更淨非生芽處得食鹽變成水得食。
【譯文】遇到這類情形，應當在器具下方橫放兩根木頭在地上，比丘用腳踩踏在木頭上說「受」，受食就算成立。本律後文提到，心裡想接受香油卻誤受了酥油等情況，受食不能成立；必須做到心念與所受物品完全相合，受食才算成功。依照本律規定，受食之後有三種情況會失去受食效力：第一是自然失效，即受食之後已經過了合法的進食時間；第二是遇緣失效，即淨人觸碰到了已經受食的物品；第三是自體轉變失效，即生食變為熟食。《善見律毘婆沙》說，接受生薑之後生薑發芽，受食效力並不喪失；經過火作淨法之後發芽的部位，只要對新發芽處重新作淨即可，未發芽的部位依然可以食用；鹽巴化解成水，依然可以食用。

【539-0004】04_比丘尼鈔/04b_卷中之下#3
【原文】共俗男子屏坐戒具四緣犯一是俗男子二屏處坐三無第三人四伸手不及戶處坐便犯僧祇云若母姉妹淨人等睡眠癡狂心亂嬰兒非人畜生雖有是人亦名為獨竟日坐一提中間更起一一提若淨人作務來往不斷門向道中有人行如食頃不斷若閣上閣下淨人遙見者並不犯此律若舒手及戶坐使乞食尼見若二尼為伴若有識別人在邊及有難緣等並不犯。
【譯文】（與男子在隱密處坐戒）具備四個條件即構成犯罪：一是對方是俗家男子，二是坐在隱蔽有遮障之處，三是身邊沒有第三人在場，四是坐在伸手夠不到門的地方，只要坐下即犯波逸提罪。《摩訶僧祇律》說，如果是母親、姐妹、淨人等在場，但他們處於昏睡、愚癡發狂、心神錯亂、或者只是嬰兒、非人、畜生，雖然有人在身邊，仍然算作獨處。整天連續坐著犯一個波逸提罪；中間如果起身後再坐，每次起身再坐都各犯一個波逸提罪。如果淨人做雜務來來往往未曾中斷，或者房門正對著道路，持續有人走過（維持約一頓飯的時間未曾斷絕），或者樓上樓下的淨人從遠處能看見，這幾種情況都不犯戒。依照本律，如果伸手就能夠到門邊坐著，或者能被行乞的比丘尼看見，或者有兩位比丘尼結伴同在，或者身旁有懂事的人，以及遇到危難險緣等情況，都不犯戒。

【539-0019】04_比丘尼鈔/04b_卷中之下#18
【原文】毀毗尼戒具五緣犯一是毗尼二前比丘尼誦戒時三作滅法意不令久住四發言毀呰五言了便犯僧祇云僧未說戒時訶越說時訶提說已訶越心悔五分云發心作念令人遠離毗尼不誦而毀呰提若作念木叉令不久住蘭此律若毀阿毗曇契經等犯吉不攝耳聽戒具四緣犯一是廣誦戒時二在眾中坐三作不聽意四說過五篇犯一提僧祇云從序至篇吉隨中間戒一一吉一切不聽止一提此提不得向人悔當於眾中持戒威德敬難者前悔前人應訶治同羯磨賞知事後悔謗僧戒此希故不述具緣婆論云凡僧和合若執苦人大德及貧匱人和合賞已訶者提若外來訶者吉。
【譯文】（毀謗毘尼戒）具備五個條件即構成犯罪：一是對象確實是毘尼戒律，二是正當其他比丘尼誦戒之時，三是懷有滅除戒法、不願讓戒法長久住世的念頭，四是開口譏刺毀謗，五是說完話即犯波逸提罪。《摩訶僧祇律》說，僧團尚未開始誦戒時出言呵責，犯越毘尼罪；正在誦戒時出言呵責，犯波逸提罪；誦戒完畢之後出言呵責，犯越毘尼罪並應在心裡悔過。《五分律》說，若是發心作念想讓人遠離毘尼而不願誦讀，進而誹謗毀蔑的，犯波逸提罪；如果存心想讓波羅提木叉戒法無法長久傳世，犯偷蘭遮罪。依照本律，如果毀謗阿毘達磨論典或契經等，犯突吉羅罪。（誦戒時不專心凝聽戒）具備四個條件即構成犯罪：一是僧團廣泛誦讀戒本之時，二是身在僧眾之中坐著，三是存心不想聽聞戒法，四是誦完五篇罪名後即犯一個波逸提罪。《摩訶僧祇律》說，從戒序開始到各篇章不聽，犯突吉羅罪；在各條戒誦讀過程中若不聽，一條戒各犯一個突吉羅罪；如果從頭到尾完全不聽，只犯一個波逸提罪。這個波逸提罪不得隨便向個別一人懺悔，應當在僧眾中具有持戒威德、令人敬畏的尊長面前懺悔，前人應當給予呵責管教。（參與羯磨賞賜知事僧事後反悔謗僧戒）這種情況非常罕見，因此不詳細列述犯緣。《薩婆多毘尼毘婆沙》說，凡是僧眾和合達成共識，對於操勞僧事的執苦人、德高望重的大德，以及貧窮匱乏之人，僧眾和合給予賞賜之後，事後又出言反悔斥責的，犯波逸提罪；如果是外來比丘反悔呵責的，犯突吉羅罪。
