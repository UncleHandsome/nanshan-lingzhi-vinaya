# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【163-0005】02_戒疏/08a_卷二下之一#106
【原文】【疏】就闕緣中，有同有異。闕初境緣，四句俱同，皆異境來替佛本故。雙闕亦爾。若闕想、疑，二句不同。以佛正命，必不斷故，既明出血，本結偷蘭，境雖極尊，約從人制，境強方便故也。
【譯文】【疏文】至於條件不滿足的情況，則有相同與相異之處。若缺少了第一項境緣條件，四種句型都完全相同，都是由別的對象替代了佛陀的本位；雙重缺緣的情況也是如此。若是缺少了認定或懷疑的條件，這兩類句型則與前文不同。因為佛陀的真實壽命，必定不會被斷絕；既然只是導致出血，在律法上原本就只結偷蘭遮罪，受害對象雖然至高無上，但制定戒律時是依循普通人的致傷標準來制裁，這是屬於「對象極強但手段未遂」的偷蘭遮罪。

【163-0006】02_戒疏/08a_卷二下之一#107
【原文】【記】闕緣中。初總標。「闕」下，別釋。初明同，有二。一、境差同：一、人作佛想，二、非人佛想，三、畜，四、杌。四句並蘭。二、示雙闕同。「若」下，次辨異。闕想四句、疑心十句，此二，初句前並犯夷，今同蘭罪。「以」下，出異所以。
【譯文】【記文】在缺少條件的文段中。首先做總體標示。「缺少」以下，進行分別解釋。起初說明相同之處，共有兩項。第一、境緣錯差的情況相同：一、普通人誤作佛想；二、非人誤作佛想；三、畜生誤作佛想；四、木樁誤作佛想。這四句全都結偷蘭遮罪。第二、說明雙重缺緣的情況也相同。「若是」以下，接著辨析相異之處。缺少認定的四句、心存懷疑的十句，這兩大類之中，最初一句在前面殺凡人時都結波羅夷重罪，如今在傷佛的情況下則同樣只結偷蘭遮罪。「因為」以下，點出這種差異之所以發生的緣由。

【163-0010】02_戒疏/08a_卷二下之一#111
【原文】【疏】顯相者。要約親生膝下，故恩養極也。如世律中，惡逆過者，通祖父母、世叔等親，何況假父後母。姑姨之屬，則並非逆。所以經律，據二惟親。
【譯文】【疏文】顯明行相：必須是親生自己、撫育自己於膝下的父母，所以恩養極其深厚。正如世間的法律，所謂惡逆大罪，普遍涵蓋祖父母、伯叔等至親尊長，何況是繼父或後母；至於姑母、姨母這類親屬，則全都不構成惡逆罪。因此佛門經律，依據這兩項逆罪，嚴格限定必須是親生父母。

【163-0011】02_戒疏/08a_卷二下之一#112
【原文】【記】二、顯相中，又二。初簡定。且約二逆，餘同前敘，或可餘三無濫，不須辨相。「膝下」者，語出《孝經》，謂孩幼之時也。「如」下，引俗示濫。「祖父母」即父之父母。世叔及伯，即諸父也。「假父後母」，皆本非親，同名為「逆」。望上「祖」等，此二又親，故云「何況」。「姑姨」非逆，族姓異故。「所」下，結前簡意。
【譯文】【記文】在第二、顯明行相中，又分為兩部分。首先加以甄別判定。此處暫且就父母這前兩重逆罪來談，其餘三項如同前文所敘述，或者說其餘三種逆罪行相明確不致混淆，所以無須另外辨析相貌。「膝下」這個詞出自《孝經》，是指幼童年幼依戀之時。「正如」以下，引用世俗法律來說明混淆之處。「祖父母」是指父親的雙親。世叔與伯父，指的就是諸位叔伯父輩。「繼父後母」本來都非血親，世俗法卻同樣列為「惡逆」。相較於上面的「祖父母」等，這兩者在名分上又更為親近，所以說「何況」。「姑姨」在世俗法不列入惡逆，是因為出嫁後族姓不同的緣故。「因此」以下，總結前面嚴格甄別親生父母的用意。

【163-0012】02_戒疏/08a_卷二下之一#113
【原文】【疏】言釋名者。何故名「逆」？以違恩養福田極故，亦違佛、世兩王化故，名之為「逆」。如《論》所出，云「五無間」，謂常續有，無間隔故。
【譯文】【疏文】探討解釋名稱：為什麼稱為「逆」呢？因為這種罪行極度違背了恩養與福田的倫理，同時也違背了佛法法王與世間人王的教化，所以稱之為「逆」。正如論典中所提出的名稱，稱為「五無間業」，意思是其所感召的苦報恆常相續，沒有絲毫間歇間隔的緣故。

【163-0013】02_戒疏/08a_卷二下之一#114
【原文】【記】釋名中，初科。逆有二義。初「違恩福」，父母違恩，羅漢、破僧違福，出血兼二。次「違王化」，「佛」是法王，「世」即人王，二教齊禁，犯則俱違。華梵雖殊，法律無異。然於五中，唯殺父母，道俗同重，餘三則別。
【譯文】【記文】在解釋名稱的文段中，屬於第一科。逆罪具有兩層含義。首先是「違背恩養與福田」，殺害父母違背了恩養，殺阿羅漢與破僧違背了福田，使佛身出血則兼具違背恩養與福田兩種過失。其次是「違背二王教化」，「佛」是出世間法王，「世」是指世間人王，兩方政教同樣嚴厲禁絕此類惡行，一旦觸犯就是同時違背雙方。中土與印度的風俗雖然不同，但在法律的根本禁戒上是一致的。然而在這五種罪行中，唯獨殺害父母這件事，出家道門與世俗社會同樣視為極重大罪，其餘三種出世間的罪相在世俗法則有所不同。

【163-0014】02_戒疏/08a_卷二下之一#115
【原文】【疏】如《成實》云：「一、趣果無間，捨身生報故；二、受苦無間，中無樂故；三、時無間，定一劫故；四、命無間，中不絕故；五、形無間，如阿鼻相，縱廣八萬由旬，一人多人皆徧滿故，不相障礙，業不可思。」
【譯文】【疏文】正如《成實論》所說：「第一、趣向受果無間，此生命終捨身便立刻受生惡道果報；第二、受苦無間，地獄受苦過程中沒有絲毫快樂間歇；第三、受苦時限無間，必定受滿整整一個大劫；第四、命相無間，在大劫受苦期間壽命絕不斷絕；第五、形相無間，如同阿鼻地獄的景況，縱廣各八萬由旬，一個人墮入也是自身遍滿地獄，眾多人墮入也是各自遍滿地獄，彼此卻互不障礙，這種業力實在不可思議。」

【163-0015】02_戒疏/08a_卷二下之一#116
【原文】【記】次科。「論」即《俱舍》，釋義猶通。「《成論》」五義，示相甚顯。三意束之：第一即間隔也，二及三四謂間絕也，第五即間缺也。然「形無間」，一多不礙，凡情難信，故云「業不可思」。
【譯文】【記文】第二科。「論」是指《俱舍論》，其解釋的含義較為通泛。「《成實論》」所列的五種含義，將罪相顯現得非常透徹。可以用三種概念來總結概括：第一種是指時空的間隔，第二與第三、第四種是指痛苦與壽命的間斷停歇，第五種則是指空間的缺漏與空隙。然而「形體無間」，一人與多人同時遍滿且互不障礙，凡夫的情識極難相信，所以論中驚嘆說「業力實在不可思議」。

【163-0016】02_戒疏/08a_卷二下之一#117
【原文】【疏】問：「三寶皆福田，損佛破僧得論逆者，何故不言破法逆耶？」
【譯文】【疏文】提問：「佛、法、僧三寶全都是福田，傷害佛陀色身與破壞僧團既然都能構成逆罪，為什麼不說破壞佛法也構成逆罪呢？」

【163-0017】02_戒疏/08a_卷二下之一#118
【原文】【記】初問。三寶福田是同，成逆則異，故問釋之。
【譯文】【記文】第一個提問。三寶在作為眾生福田這一點上是相同的，但構成逆罪的情況卻有差異，所以提出問難予以解釋。

【163-0018】02_戒疏/08a_卷二下之一#119
【原文】【疏】答：「謗法重故，不入逆中。如今五逆，不入四重。廣如《智論》及《法華》中。」
【譯文】【疏文】回答：「毀謗佛法的罪業實在太過深重，所以不被收錄在一般的五逆罪之中。好比現行的五逆重罪，根本不被納入比丘戒的四波羅夷重罪一樣。這方面的詳情，廣泛見於《大智度論》以及《妙法蓮華經》之中。」

【163-0019】02_戒疏/08a_卷二下之一#120
【原文】【記】答中。初約業重釋。「如」下，舉例，「廣」下，指證。《智論》云：「聲聞道作五逆，受地獄一劫；菩薩道破佛法，此間劫盡，復至他泥犁中，受無量罪，如是乃至徧於十方地獄等。」《法華．譬喻品》後，廣明謗經獲罪之相，乃至云「其人命終，入阿鼻獄，具足一劫，劫盡更生。如是展轉，至無數劫，從地獄出，當墮畜生」等。
【譯文】【記文】回答中。首先依據業報的極度沉重來解釋。「好比」以下，舉出相應的範例；「這方面的詳情」以下，指引經典作為證處。《大智度論》說：「修持聲聞道者若是造作五逆罪，墮地獄受苦一個大劫；若是修菩薩道者毀破摧殘佛法，此處世間的大劫終盡之時，還要被轉移到其他世界的地獄中，繼續承受無量重罪，如此輾轉受苦，乃至遍及十方世界的地獄等等。」《法華經．譬喻品》的後半段，極為廣泛地說明了誹謗這部經典所獲罪報的相貌，乃至說「此人命終之後，墮入阿鼻地獄，具足受滿一個大劫；劫盡之時，轉生到其他地獄。如此輾轉輪迴，歷經無數大劫；從地獄出來之後，又當墮入畜生道受苦」等等。

【163-0020】02_戒疏/08a_卷二下之一#121
【原文】【疏】有人言：「謗法重者，謂大乘也。對田論逆，即壞法輪，破法逆也。」
【譯文】【疏文】有人提出另一種解釋說：「誹謗佛法的罪業之所以重到超出五逆，那是指大乘佛法而言。若是純粹對應福田的破壞來論斷逆罪，那麼摧毀正法法輪的弘傳，其實就包含在破和合僧這項大逆之中了。」

【163-0021】02_戒疏/08a_卷二下之一#122
【原文】【記】次他解中，初科，又二。初點前義；「對」下，示正解。就小論逆，指歸破僧，則通三寶。
【譯文】【記文】在第二種引述其他解釋的文段中，屬於第一科，又分為兩部分。首先評點前一種說法；「若是純粹」以下，昭示正確客觀的解釋。如果單就小乘教法來討論逆罪，將其指歸於「破和合僧」的範疇，那麼實際上就已經涵蓋了對佛、法、僧三寶整體的全面破壞。

【163-0022】02_戒疏/08b_卷二下之一#1
【原文】【疏】問：「若如此者，何故毀呰修多羅但吉？」
【譯文】【疏文】提問：「如果按照這個道理，為什麼毀謗詆毀契經（修多羅）只結突吉羅罪？」

【163-0023】02_戒疏/08b_卷二下之一#2
【原文】【疏】答：「前言『逆』者，謂破滅故；今言『犯吉』，但毀呰耳。」
【譯文】【疏文】回答：「前面所說的『逆罪』，是指徹底破壞消滅佛法；現在所說的『犯突吉羅』，只是一般的譏諷毀謗而已。」

【163-0024】02_戒疏/08b_卷二下之一#3
【原文】【記】次難中。「毀毗尼戒」，毀餘二藏皆同吉羅，上云「成逆」，義則相違。答釋，可解。
【譯文】【記文】在第二番問難中。提到「毀呰毗尼戒」（毀謗律藏），與毀謗其餘經、論二藏同樣都結突吉羅罪，但前面卻說「構成逆罪」，法義上顯得彼此矛盾。疏文的回答與解釋，意思已經很清楚。

【163-0025】02_戒疏/08b_卷二下之一#4
【原文】【疏】若但破僧，不名為逆，如破羯磨，以損輕故。若殺羅漢，是損真僧，以違福極，故得逆也。
【譯文】【疏文】如果只是破壞羯磨僧團，不能稱為逆罪，就像破壞單一羯磨法事，因為所造成的損害較輕微。若是殺害阿羅漢，則是損害真正的聖僧，因為違背了最極頂的福田，所以構成逆罪。

【163-0026】02_戒疏/08b_卷二下之一#5
【原文】【記】三中。初約破僧反顯。若單破僧既不成逆，則顯逆業，全由破法。「若」下，次引殺聖比例。由殺羅漢，亦望損彼真福田僧，故成逆罪。則知破僧一逆，法在其中，故不別標也。
【譯文】【記文】在第三段中。首先從破壞羯磨僧不構成逆罪來反面顯明。如果單純破僧既不構成逆罪，就顯示出逆罪的根本，完全在於破滅法輪。從「若殺羅漢」往下，接著引用殺害聖人的事例來比照。由於殺阿羅漢，也是著眼於損壞了那位真正具足福田的聖僧，所以構成逆罪。由此可知破法輪僧這一項逆罪，正法就含攝在其中，因此不再另外標立破滅法寶為逆罪。

【163-0027】02_戒疏/08b_卷二下之一#6
【原文】【疏】次明重輕。如前列者，初輕後重。故《成論》云：「破僧最大惡，別離三寶故，離僧、壞佛、毀法寶故。又於佛所，起嫉妬心，違轉正法，復惱大眾，乃至三十界內禪誦不行故。」
【譯文】【疏文】接著說明罪相的輕重。如同前面所列出的次序，排在前面的較輕，排在後面的較重。所以《成實論》說：「破和合僧是最大的惡業，因為它割裂分離了三寶，也就是脫離僧寶、毀壞佛寶、詆毀法寶的緣故。又在佛陀住世之處，生起嫉妒之心，阻礙正法輪的轉動，又惱亂廣大僧眾，甚至使三十界範圍內的禪修與誦經完全無法推行。」
