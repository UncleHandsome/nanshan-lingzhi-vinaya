# 校閱材料　第598檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【598-0001】02_戒疏/10d_卷三上之一#71
【原文】【疏】答：「上『方便義』已論，此何復問？恐迷故耳。然諸部不同。《五分》所明，藉前方便，成後重殘。如《律本》中，作惡修善，有步步罪福。《多論》亦同。如《律》二羯磨竟三蘭，心不息故，若竟結殘。更不云蘭，明知相成。如《僧祇》，攬一切蘭，以成僧殘。又《見》云：前因變滅，以成後果。故知攬四蘭，共成一殘。」
【譯文】【疏文】回答：「上面討論『方便罪義』時已經論述過了，這裡為什麼又提問？是擔心有人迷惑罷了。然而各部律派的說法不同。《五分律》所說的，是藉助前期的方便罪之勢力，來促成後面的僧殘重罪。如同本律《律本》中說，作惡或修善，每走一步都有步步的罪過與福報。《薩婆多論》的觀點也相同。又如同本律說，第二次羯磨完畢結三個偷蘭遮，因為惡心不肯止息的緣故，如果最後羯磨完畢結僧殘罪，經文就不再提及前期的偷蘭遮，由此可知是前後罪相合併相成的。又如《僧祇律》明確說，合併前期的所有偷蘭遮罪，以共同構成一個僧殘罪。此外《善見論》也說：前期的因位罪業轉變滅去，以成就後期的果位重罪。由此可知是合併四個偷蘭遮罪，共同構成一個僧殘罪。」

【598-0002】02_戒疏/10d_卷三上之一#72
【原文】【記】次釋拒諫，初問。答中。初示重意。「然」下，正釋。初句總示。「五分」下，別釋，又二。初至「亦同」，明不相攬。《五分》「藉前方便」，謂藉勢而成，顯非攬故。「如」下，引《律》進趣，反證外部。「步步罪福」，顯是各成，非相攬故。此示本宗非無彼義。《多論》宗《十誦》，故同《五分》。次從「如《律》」下，明相攬。初引本部，即如注中，二羯磨竟，兼前一白，故得「三蘭」。《僧祇》文如上引，及與《善見》，二文並同。
【譯文】【記文】接著解釋抗拒僧諫，首先發問。回答當中。先提示之所以重複說明的深意。「然」字以下，正式解釋。第一句總體開示。「五分」以下，分別解釋，又分為兩部分：從開頭到「亦同」，是說明不互相合併。《五分律》說「藉前方便」，是指藉著方便罪的勢頭來成就果罪，顯然不是把因位罪收攬融合成一果。「如」字以下，引述本律進趣方便之文，反向論證外餘部派的觀點。「步步罪福」，顯示罪業是各自獨立成立的，並非相互融合吸收。這是指出本宗並非沒有那種「不相合併」的義理。《薩婆多論》宗奉《十誦律》，所以觀點與《五分律》相同。接著從「如律」以下，說明前後合併相成。首先引述本部律，就是指注文中所說，第二次羯磨完畢，連同前面的一次單白，所以得「三個偷蘭遮」。《僧祇律》的經文如同上面所引述的，以及《善見論》，這兩部文獻的觀點完全一致。

【598-0004】02_戒疏/10d_卷三上之一#74
【原文】【疏】答：「《僧祇》有之，義不可別。以白未竟因吉，竟即果蘭。三羯磨未竟，因不可吉，以竟果殘，故有四蘭。」
【譯文】【疏文】回答：「《僧祇律》中有這樣的說法，其義理不應有差別。因為單白未完成是因位結突吉羅，單白完成就是果位結偷蘭遮。三次羯磨在未完成時，因位罪不能再結突吉羅，因為一旦全體完成就是果位的僧殘罪，所以在整個推進過程中總共有四個偷蘭遮因位罪。」

【598-0005】02_戒疏/10d_卷三上之一#75
【原文】【記】轉難中，初難。上云「四蘭」，乖《律》文故。答中。初句指出，亦即上文。次句明同。彼明成果，故說四罪。此明中捨，故但有三，據理須四，如下所示。由作法竟，方至果殘。第三法未竟，猶是方便，理須結蘭。
【譯文】【記文】轉入進一步問難中，首先發難。上面說「四個偷蘭遮」，違背了《四分律》原文的緣故。回答當中。第一句指出出處，也就是指前面的引文。第二句說明義理相通。彼論是從成就極果的角度，所以說共有四罪。本律是說明若在中途捨棄邪執，所以只結三個偷蘭遮，但若依常理推究必須算為四個，正如後面所揭示的那樣。因為直到作法全部完畢，才達到最終的果位僧殘罪。第三次羯磨尚未念完時，仍然屬於方便階段，按理應當結偷蘭遮。

【598-0007】02_戒疏/10d_卷三上之一#77
【原文】【記】答：「無也。詳《律》文意，白與羯磨自分兩節，各有因果。白既一法，故以未竟為因，白竟為果。果既是蘭，因故犯吉。後三羯磨，都是殘因，所以三蘭無別因吉也。」
【譯文】【記文】回答：「沒有。詳細體會《四分律》的文義，單白與羯磨本來自然劃分為兩個階段，各自具備因位與果位。單白既然本身自成一法，所以以未念完為因位，以念完為果位。果位既然是偷蘭遮，因位因此便犯突吉羅。後面的三次羯磨，全體都是僧殘重罪的前方便因，所以這三個偷蘭遮沒有另外附帶的因位突吉羅罪。」

【598-0012】02_戒疏/10d_卷三上之一#82
【原文】【疏】答：「蘭下有罪，以小為因。吉下無罪，故因同果。若作異名，名則無窮。然通而為言，因吉成果吉，如『九十』中諫未竟得吉者是。自有多因吉，各不相成，即如白、羯磨未竟者是也。」
【譯文】【疏文】回答：「偷蘭遮罪下面還有更輕的罪名，所以可以用較小的突吉羅作為因位罪。突吉羅罪下面已經沒有更輕的罪名了，所以因位罪只能同稱果位的名字。如果硬要為它安立別的異名，那麼罪名就無窮無盡了。然而通盤來說，因位的突吉羅成就果位的突吉羅，就像『九十單墮』中的規勸尚未完畢時結突吉羅這類情況便是。自然也有許多因位的突吉羅，各自獨立並不互相助成，這就像單白、羯磨未念完時所結的罪便是如此。」

【598-0013】02_戒疏/10d_卷三上之一#83
【原文】【記】次並難中。答文，二。初對蘭釋通。「然」下，別示吉罪。「九十」中諫，亦白四法。初白未竟吉，白竟亦吉，此即「因吉成果吉」也。又白與羯磨未竟三吉，望後提罪，三並是因。隨法別結，各自為果。此即「多因吉，各不相成」也。
【譯文】【記文】接著連類並詰問難當中。回答的文字，分為兩部分。首先是相對於偷蘭遮來通盤解釋。「然」字以下，特別指明突吉羅罪的情況。「九十單墮」當中的規勸，也是使用白四羯磨法。最初的單白未完結突吉羅，單白完成也結突吉羅，這就是所謂的「因位突吉羅成就果位突吉羅」。另外，單白與羯磨在未念完時所得的三個突吉羅，相對於後面的波逸提極果來說，這三個都屬於前方便因。但它們隨作法進程分別結罪，各自成為獨立之果，這就是所謂的「多個因位突吉羅，各自獨立不互相助成」。

【598-0015】02_戒疏/10d_卷三上之一#85
【原文】【記】三、明差別中。初云「因此」者，指上為由也。「通明」者，一則不局此戒，二乃不專吉羅。觀下十中，一一各出二句。前九種中，欲翻下句，故出上句，事並如常，故所不釋。唯後第十，二句並異，故具釋耳。
【譯文】【記文】第三、說明差別當中。開頭說「因此」，是指以上述問題作為討論的發端。「通明」，一來是不局限於這一條戒，二來也不專指突吉羅罪。綜觀下面十種情況，每一種都各自列出兩句。在前九種當中，因為是想用下句來對翻上句，上句的情況都很尋常，所以沒有特別解釋。唯獨最後第十種，上下兩句都是特殊情況，所以才作了詳細解釋。
