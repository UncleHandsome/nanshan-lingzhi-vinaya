# 校閱材料　第091檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【091-0001】01_行事鈔/05b_卷中之一#19
【原文】次對七眾發戒多少。準《薩婆多》云：五戒者，於一切眾生，乃至如來，皆得四戒；以無三毒善根，得十二戒。并一身始終，三千界內，一切酒上，咽咽皆得三戒，以受時一切永斷。設酒滅盡，羅漢入般，戒常成就。準以義推，女人身上淫處有三，男上有二；發由三毒，單配，則女人所得十八戒；男子十五戒；非情一酒，亦得三戒。八戒發者，眾生同上，非情得五。十戒，三眾，情及非情，同大僧發。《四分律》文，俱發七支，戒戒下文，皆結吉羅故。若爾何故列十？此但示根本喜作，說相令其早知，餘則和尚曲教。故三歸羯磨，俱無戒數之文；說相之中，方列十四，兩種類解。若約僧尼，準如《婆論》，一一眾生，身口七支，以貪瞋癡起故，成二十一戒。今義準張，三毒互起，二三等分，應有七門。女人九處，男子八處；七毒歷之，女人身上，得六十三戒；男子身上，以已七毒惱他，得五十六戒；非情戒境，各得七戒。以此例餘，法界之中，情與非情，各得諸戒無量無邊。故《善生》中，五種為量：眾生、大地、草木、大海、及以處空，譬戒德量，如前分雪。
【譯文】次對七眾發戒多少。依循《薩婆多論》所說：受持五戒的人，在一切眾生身上、乃至如來佛陀身上，都能獲得四條戒（不殺、不盜、不邪淫、不妄語）；由於以無三毒之善根發心，便在每一眾生身上獲得十二條戒。再加上就自己一身的終身奉持而言，在三千大千世界以內的一切酒類上，每一咽每一滴上都獲得三種戒德（三善根防一非情境），因為受戒時誓願永斷一切酒。縱使世間的酒全部滅絕、阿羅漢證入涅槃，此戒體依然恆常成就。依照義理推演，在女人的身體上有三處行淫之處（道），在男人身上有二處；發心既然由三毒而起，若以三毒單獨配對（殺、盜、妄三戒各配三毒得三戒，淫戒在女人三處各配三毒得九戒、男子二處各配三毒得六戒），則在女人身上所得為十八戒；在男子身上為十五戒；在非情的一種酒戒上亦得三戒。八關齋戒的發起情況：在眾生身上所得戒數如同上述，在非情境界上則得多出五條戒。十戒，對於出家下三眾而言，在有情與非情境界上所發起的戒體，與大僧（比丘）相同。因為《四分律》中記載，下三眾同樣都發起防護身三口四這「七支」的戒體，在每一條戒的條文之下，毀犯時都同樣結為突吉羅（惡作罪）之故。如果這樣，為什麼十戒只列出十條呢？這只是為了標示出凡夫初入道最容易犯造的根本惡業，為他們宣說戒相讓他們及早明了，其餘微細學處則由其和尚隨機微細教導。所以無論是下三眾受戒的三歸、還是大僧受具戒的羯磨，儀文中都沒有列明戒條數目的文字；只有在後續宣說戒相之時，才分別列出共十四條戒相（沙彌十戒與大僧四重），以兩種類型分別解明。如果就比丘與比丘尼二眾而言，依照《薩婆多論》所載：在一一眾生身上，身三口四這七支過失，因為是由貪、瞋、癡三毒所引發，便相乘而成二十一條戒。如今若依教理推展張皇：三毒互起，有單發、二毒合發、三毒並起等，共可細分成七門毒心。女人身上有九處，男子身上有八處；以七門毒心一一歷練推演，在女人身上可得六十三戒；在男子身上，以自心七門毒心加惱於他，可得五十六戒；在每一種非情戒境上，各得七條戒。以此類推其餘境界，在全法界之中，面對一切有情與非情，各自獲得的戒法都是無量無邊的。故《善生經》中以五種譬喻為標準：眾生、大地、草木、大海以及虛空，用來比喻戒德的宏量，就如同前文所剖析明晰的一樣。

【091-0002】01_行事鈔/05b_卷中之一#20
【原文】問：七支攝戒盡不？答：盡也！設有不盡，攝入七中，如配戒種類所說。又云：攝戒不盡，以罪性不同；如殺打兩別，能防體異。故《善生》云：除善惡戒已，更有業戒，所謂善惡法也！故知，根本七支所收，業戒種類所攝。宜作四句：一者善而非戒，謂十中後三是也！律不制單心犯也！二戒而不善，即惡律儀。三亦善亦戒，十善之中前七支也！以不要期，直爾修行，故名善也！反此策勵，故名戒也！四俱非者，身口無記。問：戒與律儀，行相差別如何？答：通行無涯，是律儀也！對境禁約，是戒儀也！如比丘具緣受已，見生不殺，望此一境，名持殺戒；望餘四生，名持律儀。若殺此生，名犯殺戒；餘生不殺，不犯律儀。若就惡律儀解，望殺一羊，名持惡戒；望餘通類，有生皆罪，是持律儀。
【譯文】問：七支能夠將一切戒法含攝窮盡嗎？回答說：完全能含攝窮盡！縱然有看似未能窮盡的微細戒，也都可以歸攝入七支之中，正如將諸戒配屬於各種類型時所說的一樣。又有一種解釋說：七支不能完全含攝所有戒法，因為罪業的性質各有不同；例如殺生與捶打二者罪業不同，所能防護的自體也有差別。故《善生經》說：「除了善惡戒之外，還有業戒，也就是指世間一般的善法與惡法！」由此可知，根本罪過由七支所收攝，業戒的種類則含攝其餘輕罪與微細學處。在此應當立為四句分別：第一、是善法而不是戒：是指十善業道中的後三種意業（不貪、不瞋、不邪見）！因為律宗不對單純起心動念而未見諸身口者制定犯戒之罪！第二、是戒法而不是善法：也就是殺生、屠戮等世俗的惡律儀。第三、既是善法又是戒法：是指十善業道中的前七支（身三、口四）！若不作長期的立誓要期，只是隨緣直截修善，故稱為善；反於放任而策勵誓願防非止惡，故稱為戒！第四、既非善法又非戒法：是指身業與口業的無記性動作。問：戒與律儀的行相差別究竟如何？回答說：普遍通行於一切境緣而無涯際者，就是律儀；具體面對某一當前特定境界進行禁約防護者，就是戒儀！例如比丘具足一切因緣受戒完畢之後，遇見某一個生命而不起殺心，對著這一個具體境界而言，稱為持守殺戒；對著其餘一切四生眾生而言，稱為持守律儀。如果動手殺害了這個生命，就稱為犯了殺戒；但對其餘未殺害的眾生而言，不犯整體的律儀。如果就惡律儀來解釋：屠夫在屠殺一隻羊時，稱為持守惡戒；對其餘一切有生命的通類而言，只要見到有生命皆欲殺害造罪，這就是持守惡律儀。

【091-0003】01_行事鈔/05b_卷中之一#21
【原文】三者戒行。謂受隨二戒，遮約外非；方便善成，故名戒行。然則，受是要期思願，隨是稱願修行。譬如築營宮宅，先立院牆周匝，即謂壇場受體也；後便隨處營構，盡於一生，謂受後隨行。若但有受無隨，直是空願之院，不免塞露之弊。若但有隨無受，此行或隨生死，又是局狹不周；譬同無院室宇，不免怨賊之穿窬也！必須受隨相資，方有所至。問：今受具戒，招生樂果，為受為隨？答：受是緣助，未有行功；必須因隨，對境防擬，以此隨行，至得聖果，不親受體。故知一受已後，盡壽已來，方便正念，護本所受；流入行心，三善為體，則明戒行，隨相可修。若但有受，無隨行者，反為戒欺，流入苦海，不如不受，無戒可違。是故行者，明須善識，業性灼然，非為濫述。
【譯文】三者戒行。這是指受戒與隨行這兩種戒法，遮止約束外在的過非；善巧的加行方便得以圓滿成就，故稱為戒行。然而，受戒乃是預先立下盡形壽奉持的思願與誓願，隨行則是相稱於此誓願而在日常對境中起修。譬如修建營造宮殿宅第，先在四周確立築造圍牆，這就好比在戒壇壇場上納受戒體；隨後便在圍牆內部隨處營造屋宇，終盡一生的歲月去修葺完善，這就好比受戒之後的隨行修持。如果只有受戒而沒有隨行，那只不過是一座徒有空願圍牆的空地，難免遭受風寒霜露襲擾的弊病。如果只有隨行而沒有受戒，這種行善往往隨逐於生死輪迴之中，而且行持局促狹隘無法周全；這就好比沒有外圍牆垣的房屋，難免遭受仇家盜賊穿牆越郭的侵害！因此必須受戒與隨行互相資助，才能真正有所成就到達彼岸。問：如今受了具足戒，能感召生於善道乃至解脫之安樂果報，這究竟是受戒的功德，還是隨行的功德？回答說：受戒只是一種增上助緣，尚未具備切實的行持功德；必須依憑隨行，在面對境界時切實防禦抗拒，依憑這種隨行的力量，才能最終證得聖果，並非直接由受戒之體單獨感果。由此可知，一旦受戒之後，直到壽命終盡為止，必須常修方便、安住正念，護衛當初所納受的戒體；將戒體流入平日的行持心念之中，以無貪、無瞋、無癡三善根為其自體，如此便明了什麼是戒行，而具體的戒相也就切實可修了。如果只有受戒而沒有隨行的人，反而會被戒法所辜負懲罰，墮落流入惡道苦海之中，這還不如當初不受戒，沒有戒律可資違犯。因此修行的人，務必極其清醒地善加了知，業力果報的體性是昭然若揭的，絕非在此泛泛空談。
