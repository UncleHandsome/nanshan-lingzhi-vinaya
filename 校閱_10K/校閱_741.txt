# 校閱材料　第741檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【741-0001】02_戒疏/16c_卷四上之一#46
【原文】【註】除麤罪，以餘罪說者；自說麤罪、餘人罪——一切吉羅。不犯者，若不知，若眾曾差，若非麤想，若白衣先已聞者，不犯。
【譯文】【註文】除了粗惡重罪之外，如果宣說其他輕罪；或者自己宣說自己所犯的粗惡重罪，以及宣說僧尼之外其餘下眾（如沙彌等）的罪——全部結突吉羅罪。不犯戒的情況：如果是不知情，如果是僧團曾經差派，如果誤以為不是粗惡罪，如果世俗白衣先前早已聽聞知曉者，皆不犯戒。

【741-0002】02_戒疏/16c_卷四上之一#47
【原文】【疏】戒本五句：一、犯人；二、知犯；三、向未具；四、除僧法；五、結罪。
【譯文】【疏文】戒本文句共有五句：第一是能犯戒的人；第二是明知對方犯戒；第三是宣說的對象為未受具足戒者；第四是除去僧團羯磨合法開許的例外；第五是結定罪名。

【741-0003】02_戒疏/16c_卷四上之一#48
【原文】【記】戒本，分文。第四「除僧法」者，《律》因舍利弗為眾所差，於俗眾中說調達過，舍利弗畏慎，佛言「眾僧差，無犯」。
【譯文】【記文】科判戒本分文。第四句「除去僧法」的情況，是指《律》中記載舍利弗曾被僧團差遣，在世俗信眾面前宣揚提婆達多的罪過，舍利弗原本心生畏懼謹慎，佛陀說「若是僧團差遣的，便沒有犯戒」。

【741-0004】02_戒疏/16c_卷四上之一#49
【原文】【疏】就解第二，罪相中，以初二篇同壞眾一，「麤」故犯提。說下諸聚，不能破壞，但犯輕也。所以不列偷蘭罪者，猶名含輕重，若列「蘭」名，謂輕亦提，避濫不出，如《鈔》也。
【譯文】【疏文】在解釋第二句罪相當中，因為初篇波羅夷與第二篇僧殘都會破壞僧團的一致和合，屬於「粗惡」重罪，所以宣說者犯波逸提罪。宣說下位各篇的輕罪，並不足以破壞和合僧，所以只犯輕罪。至於註文之所以沒有列出偷蘭遮罪，是因為偷蘭遮的名目包含重罪與輕罪，若是列出「偷蘭」之名，世人會誤以為犯輕品偷蘭也結波逸提，為了避免混淆失誤所以不列出，正如《行事鈔》所解釋。

【741-0005】02_戒疏/16c_卷四上之一#50
【原文】【記】釋第二，初科。初辨諸篇重輕。「所」下，次明不出偷蘭之意。說上品蘭，同上犯提，中下但吉。若依《多論》，「蘭」同下聚。
【譯文】【記文】科判解釋第二句，初科。先辨析各篇罪相的輕重。「所」字以下，接着說明不列出偷蘭遮罪的用意。宣說上品偷蘭遮罪，同樣犯波逸提，中品與下品則只結吉羅罪。若是依照《薩婆多論》，偷蘭遮罪則一概等同於下位諸篇的罪責。

【741-0006】02_戒疏/16c_卷四上之一#51
【原文】【疏】「自說麤罪」犯輕者，希也。說他數故，自壞壞他，又壞俗信，故重制也。
【譯文】【疏文】宣說「自己所犯的粗惡罪」之所以只結輕罪，是因為這種事極為罕見。而揭發他人的罪過則極為常有，既敗壞自己又傷害他人，更敗壞了世俗的敬信心，所以佛陀才從重制戒加以禁戒。

【741-0007】02_戒疏/16c_卷四上之一#52
【原文】【記】次科。「自說希」者，反下二過。「說他」中，言「壞他」者，即犯過人。
【譯文】【記文】科判第二科。所謂「自說粗罪罕見」，是反襯後兩種過失。在「說他人」的過失中，所謂「傷害他人」，就是指那個犯過失的當事人。

【原文】【律】八、實得道向白衣說戒。
【譯文】【律文】第八條、將自己確實得道向白衣宣說戒。

【原文】【疏】得道向未具說戒八。
【譯文】【疏文】證得道果向未受具足戒者宣說戒第八。

【741-0010】02_戒疏/16c_卷四上之一#55
【原文】【疏】《多論》二義：「大人法者，功德覆藏，諸惡發露。今稱德匿過，是小人法。二、自顯聖德，賢愚各異，若有聞者，偏心專敬，失本平等淨善之心。」
【譯文】【疏文】《薩婆多論》提出兩種義理：「有德行的大人之法，應當隱藏功德，各類惡事則向眾發露；如今自稱功德而隱匿過錯，這是小人之行。第二是自己炫耀聖者德性，使得賢者與愚人的分別彰顯，若有俗人聽聞，就會生起偏頗專注的恭敬心，失去原本對一切僧寶平等清淨的向善之心。」

【741-0011】02_戒疏/16c_卷四上之一#56
【原文】【記】第八，制意中。《多論》二義：初即自失，「匿」即隱也；二是損他，「賢愚異」者，相形比故。
【譯文】【記文】科判第八條，解釋制戒用意。《薩婆多論》的兩種深意：第一種是自身德行的虧損，「匿」就是隱藏的意思；第二種是損害他人，所謂「賢愚各異」，是因為互相比較襯託的緣故。

【741-0012】02_戒疏/16c_卷四上之一#57
【原文】【疏】五緣：一、內實得道，除增上慢人；二、自言已證；三、向未具人說；四、言了；五、聞解。
【譯文】【疏文】具備五種因緣構成犯戒：第一、內在確實證得聖道，排除增上慢未得謂得的人；第二、自己口說已經證悟；第三、對象是未受具足戒的人；第四、言語清晰明瞭；第五、對方聽聞並完全領悟。

【741-0013】02_戒疏/16c_卷四上之一#58
【原文】【記】緣中。第二「自己證」者，此戒局制初果已去證真聖人，內凡已還，無非大妄。
【譯文】【記文】科判犯緣中。第二項「自己說證」，這條戒局限於制定給初果以上證得真理的聖人，凡是內凡位以下的人自稱得道，無一例外皆屬大妄語重罪。

【741-0014】02_戒疏/16c_卷四上之一#59
【原文】【疏】問：「此戒凡夫不犯，聖人一制無染，此教便成無用？」
【譯文】【疏文】有人提問：「這條戒凡夫不會犯，聖人一旦被制戒就不會再染犯，那麼這項教法不就成了擺設而毫無用處嗎？」

【741-0015】02_戒疏/16c_卷四上之一#60
【原文】【疏】答：「制聖，為遮於凡。後更說者，定是凡夫故，為護大妄，不令重犯。」
【譯文】【疏文】回答說：「為聖人立制規範，是為了防遮凡夫。因為日後若有人膽敢再說自己得道，那就必定是凡夫，所以制此戒是為了守護大妄語戒，不讓凡夫犯下波羅夷重罪。」

【741-0016】02_戒疏/16c_卷四上之一#61
【原文】【記】問答中。由制此戒，凡聖顯然，凡不敢說，故云「護大妄」也。
【譯文】【記文】科判問答中。由於制定了這條戒，凡夫與聖人的分野極為明顯，凡夫不敢輕易宣說，所以說是「防護大妄語」。

【741-0017】02_戒疏/16c_卷四上之一#62
【原文】【註】佛在毗舍離，以前「大妄語」緣集僧訶責已，便制此戒。
【譯文】【註文】佛陀住在毗舍離城，先前因「大妄語戒」的緣起召集僧團進行呵責訓勉之後，便隨即制定了這條戒。

【741-0019】02_戒疏/16c_卷四上之一#64

【譯文】【律文】若有比丘，向未受大戒的人宣說超越凡人的聖法，說「我見到了這個境界，我證知了這個真理」，若是實有其事，犯波逸提罪。

【741-0021】02_戒疏/16c_卷四上之一#66
【原文】【疏】戒本五句：一、犯人；二、未具；三、說過人法；四、我見知明證得；五、結罪。餘可解。
【譯文】【疏文】戒本文句共有五句：第一是能犯戒的人；第二是未受具足戒的人；第三是宣說過人之法；第四是說出我見到、明知以證實自己所得；第五是結定罪名。其餘文義皆可理解。

【741-0022】02_戒疏/16c_卷四上之一#67
【原文】【記】釋戒本文。所稱聖法，犯不犯相，大同前戒，故云「可解」。
【譯文】【記文】科判解釋戒本文句。文中所稱的聖法，犯戒與不犯戒的面相，大體上都與前一條大妄語戒相同，所以說「皆可理解」。

【741-0024】02_戒疏/16c_卷四上之一#69
【原文】【疏】獨與女人說法戒九。
【譯文】【疏文】單獨向女人說法戒第九。
