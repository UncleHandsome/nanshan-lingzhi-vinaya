# 校閱材料　第230檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【230-0001】02_戒疏/11b_卷三上之二#120
【原文】【疏】就初門中。「尼薩耆」者，西天梵言，東華人譯，名之為「捨」。如《多論》云有三種：一、捨財，二、捨相續貪心，三、捨罪也。「波逸提」者，如上已翻，此名為「墮」。故曰「三十捨墮」。
【譯文】【疏文】就第一門而言。「尼薩耆」是西方印度的梵語，東土漢人翻譯，稱之為「捨」。如同《薩婆多論》所說具有三種意涵：第一、捨棄非法之財，第二、捨棄相續不斷的貪著之心，第三、捨棄犯戒的罪過。「波逸提」，如上面總論中已經翻譯過的，此處稱之為「墮」。所以合稱為「三十捨墮」。

【230-0002】02_戒疏/11b_卷三上之二#121
【原文】【記】第四篇，釋名中，初科。初釋尼薩耆。約義翻名，引論釋相。次釋波逸提。指「如上」者，即總義中。「故」下，合結。
【譯文】【記文】第四篇，在解釋名稱之中，屬於第一科。首先解釋「尼薩耆」。依循義理翻譯名稱，並引用論典解釋其內涵。接著解釋「波逸提」。指稱「如上所述」，就是指在總綱義理中的說明。「所以」以下，予以合論總結。

【230-0003】02_戒疏/11b_卷三上之二#122
【原文】【疏】問：「『三十』具三，故悉名『捨』；『九十』具二，亦應名『捨』？」
【譯文】【疏文】提問：「『三十條』具備了這三種捨，所以統統名為『捨』；那麼『九十條』既然也具備了後兩種捨，是否也應當稱為『捨』？」

【230-0004】02_戒疏/11b_卷三上之二#123
【原文】【疏】答：「不同。以對捨財，罪猶未捨，而得捨名。當知此捨，非捨罪、捨心。如《明了論》解：尼薩耆者，名為盡捨；如犯長等，犯捨懺時，必無留財還成染犯，故名盡也。『九十』不爾，或因財事，單悔本墮，不可對財。故知此名，唯在『三十』。」
【譯文】【疏文】回答：「這兩者並不相同。因為是相對於必須『捨去財物』，而罪業在此刻尚未解除，因而獲得了『捨』的名號。應當知道這個捨字，並非專指捨罪或捨貪心。正如《律二十二明了論》所解釋的：尼薩耆的意思，是名為『完全棄捨』；就如同蓄積了過量長衣等物，犯下捨墮罪而進行懺悔時，必定不能私自保留任何財物以致於重新落入貪染犯戒的境地，所以稱為『盡捨』。『九十單提』則非如此，有時只是因財物引起的小事，只需單純向僧坦白懺悔本罪的墮落即可，不必對著特定的財物進行捨棄。因此可知這個稱呼，唯獨專屬於『三十條』。」

【230-0005】02_戒疏/11b_卷三上之二#124
【原文】【記】次問中。「『九十』具二」，俱無捨財耳。答中。初正明。凡懺捨墮，先須捨財，後方捨罪。明知「捨」名正因財事，餘二兼帶耳。「如」下，引《論》證。知捨義對財不疑。「九十」下，對簡。「故」下，結示。
【譯文】【記文】在第二個提問中。「『九十條』具備兩種」，是指它們都缺少了「捨棄財物」這一條。在回答之中，首先正式開示。凡是懺悔捨墮罪，都必須先將非法財物捨交給僧團，之後才能正式懺悔除罪。顯然可知「捨」這個名稱正是因為財物本身而立，其餘二種只是附帶具備罷了。「如同」以下，引用論典作證。可知捨的定義毫無疑問是對著財物而言。「九十」以下，進行對比簡別。「所以」以下，結語開示。

【230-0008】02_戒疏/11b_卷三上之二#127
【原文】【疏】良由財事取納乖方，生罪壞道。欲洗心悔，必須上境，方乃絕滅相續貪心。心、事既捨，障業須遣，故次明罪。作法是難，故須前列。「九十」因財，捨懺在別，但斷後犯，即成洗悔。作法是易，故次說之。欲使先識於難，後及於易。行之次第，不足生疑。
【譯文】【疏文】這實在是因為出家人在索取與收受財物之時悖逆了如法之軌則，從而滋生罪過、毀壞修道之行。若想要洗滌身心發露悔過，必須要依憑尊崇的上等境界（清淨僧伽），才能徹底斬斷斷滅那相續不斷的貪婪之心。貪心與非法的財物既已全數捨棄，阻礙聖道的罪障惡業也必須徹底拔除，所以緊接著就要明示其所犯之罪。由於這種滅罪作法極其艱困嚴謹，所以必須排在前面。「九十單提」雖然有些也因財物而起，但其捨棄懺悔純屬個別對首處理，只要從此斷除不再重犯，就算是洗滌悔除完畢。這種作法相對容易，所以放在其後宣說。這是為了讓修行者先認識艱難嚴格的戒軌，接著再學習相對簡易的法則。修行有了先後的次序，便不至於心生猶豫猜忌。

【230-0009】02_戒疏/11b_卷三上之二#128
【原文】【記】釋中。初明捨墮。「上境」，謂僧中。「心、事」，「事」即是財。兼下「障業」是罪，即三捨也。「九十」下，次明單提。「欲」下，合示離分先後之意。
【譯文】【記文】在解釋的文句中。首先說明捨墮戒。「上等境界」，指的就是清淨的僧伽大眾。「貪心與財事」，「事」指的就是財物。連同下文的「障道惡業」指罪過，合起來正是三種捨棄。「九十」以下，接著說明單提罪。「為了」以下，綜合指明將其先後拆分陳述的深意。

【230-0010】02_戒疏/11b_卷三上之二#129
【原文】【疏】第三，依位別解。就初「三十」，八門分之：初明「三十」、「九十」俱因財犯，有捨不捨別；二、同活及僧犯之多少；三、自作教人；四、重犯有無；五、捨懺方法；六、持犯方軌；七、僧尼不同；八、沙彌任運。
【譯文】【疏文】第三、依照位階個別解說。首先針對「三十捨墮」，分為八門來剖析：第一、說明「三十」與「九十」兩者同樣都是因為財物而犯戒，但為何有必須沒收棄捨與不需沒收的差別；第二、同住共財的比丘以及僧團全體犯戒罪相的多少；第三、自己親自造作與指使他人造作的差異；第四、反覆再犯時罪名存在與否；第五、沒收財物與懺悔除罪的具體方法；第六、持戒與犯戒的判定準則規範；第七、比丘與比丘尼規定的差異；第八、沙彌在自然任運中的相關持守。

【230-0011】02_戒疏/11b_卷三上之二#130
【原文】【疏】就初門中。由具三義，得入「三十」。何者為三？一、屬己之財；二、財在生過；三、捨還用得故。「九十」之中二十七戒，雖因財食，不具三義。何者是邪？因食十四，因財十三。
【譯文】【疏文】就第一門而言。由於具備了三種要件，才能被歸入「三十捨墮」之中。是哪三種呢？第一、那必須是屬於自己私有的財物；第二、那份財物只要留在手中就會持續滋生過咎；第三、在捨交給僧團重新作法返還後，自己依然能合法享用受用。在「九十單提」之中有二十七條戒，雖然也同樣是因為財物與飲食而招致違犯，卻未能完整具備這三種條件。是哪二十七條呢？因為飲食起犯的有十四條，因為財物起犯的有十三條。

【230-0012】02_戒疏/11b_卷三上之二#131
【原文】【記】別解八門，初門，初師，通列中。「三義」，上二可見，第三謂捨懺已，僧作法還，得受用故。
【譯文】【記文】個別解說的八門中，第一門，第一位律師的觀點，在通盤列舉之中。「三種要件」，上面兩種顯而易見，第三種是指在沒收懺悔完畢之後，僧伽通過作法將其退還，比丘仍然被允許合法使用。

【230-0030】02_戒疏/11b_卷三上之二#149
【原文】【記】釋疑中，初科。問中，上二句牒前，下二句正難。若三十戒許有說淨，則皆他物，並闕初緣。答云「然」者，承來問也。「何」下，列示。「四戒受持」，不入淨故。長衣、月望、長鉢、長藥四戒，由不說犯。蠶綿、純黑、白毛、減六年、不揲坐具，名為「五敷」，擔毛、擗毛、乞縷線，「未成無量」，「已成有過」，故並不入淨。「自餘」下十四戒，如取非親尼衣、乞衣、過受、勸增等，舉體有過，不應淨法。此明「三十」皆無說淨，即顯屬己也。
【譯文】【記文】在化解疑難的段落中，這是第一科。提問之中，上面兩句承接前文，下面兩句正式展開詰難。如果三十條捨墮戒允許事前透過「說淨」程序，那麼所有的衣物財物在律法上都已託付成為他人的名義之物，那就全都缺少了第一個要件。回答說「是的」，是首肯承認來者的提問。「何以得知」以下，逐一列舉說明。「四條戒已受持」，是不屬於可說淨的範圍。長衣、月望衣、長缽、過期藥物這四條戒，正是因為疏忽沒有進行「說淨法」才導致犯戒。蠶綿、純黑羊毛、白羊毛、未滿六年更換、不拼縫一肘舊布的坐具，這稱為「五種敷具」，再加上運載羊毛、洗擗羊毛、索求線縷，「在未製成時無法衡量尺寸」，「一旦製成便本身即是過錯」，所以全部都不能歸入說淨之列。「其餘」以下十四條戒，例如接受非親屬比丘尼之衣、過分乞衣、過度接受贈衣、勸誘施主增加衣料等，其整件事情本身就是過錯，根本不應當適用說淨的法規。這項論述證實了「三十捨墮」全都未曾進行說淨，由此彰顯出那份非法財物全都是純粹屬於犯戒者自己所私有的。

【230-0038】02_戒疏/11c_卷三上之二#3

【原文】【記】二、七日藥闕亦如上。「三判」者，一正七日捨，與餘比丘食；過七日捨，與守園人；減七日捨，聽自用。謂長藥相染，乃至十二日捨者，猶通三判。若至十四日，一向捨與園人。如後廣明。
【譯文】【記文】第二，七日藥闕失第三條義理也如前面所述。所謂「三種判決」：第一，正好滿七天時捨出，給其他比丘食用；過七天後捨出，給予寺院守園人；未滿七天捨出，聽任自己食用。這是說長存之藥互相沾染，乃至到了第十二天捨出，仍然通於這三種判決；如果到了第十四天，就一律捨給守園人。這在後面會詳細說明。
