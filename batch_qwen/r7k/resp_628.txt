## 一、三個系統性問題

### 1. 科文的「牒文標字」不該翻譯（最嚴重）

記文用「『然』下」「『若由』下」「『是』下」是在**指出疏文的起首字**，作用是定位。譯成「然而以下」「如果從以下」「因此以下」，讀者就無法回查疏文了。

* 【0001】「然」下 → 譯「然而」以下 ❌
* 【0001】「若由」下 → 譯「如果從」以下 ❌（「若由」是疏文兩字，不是一個詞）
* 【0001】「若」下 → 譯「如果」以下 ❌
* 【0001】「是」下 → 譯「因此」以下 ❌
* 【0003】「須」下 → 譯「必須」以下 ❌

**建議一律保留原字**：「『然』字以下」「『若由』以下」……。同理，被解釋的詞也要保留：【0003】「所謂『相互交織』」應作「所謂『交絡』」；「所謂『準則規範』」應作「所謂『方軌』」；【0001】「『戒律規定』這句話」應作「『律制』二字」。否則「牒詞—釋義」的對應關係全失。

### 2. 「法／事法／位法」譯成「法規」不妥

本段的「法」是**戒法、犯法（夷蘭提吉等罪相）**，不是世間法律條文；「事法」＝事相＋犯法。譯文多處作「事相與法規」「事相或法規」，與譯者自己把「犯」譯為「罪相」相矛盾。

**建議全文統一**：事法 →「事相與犯法（罪相）」；可學事法 →「可學的事相與犯法」。

### 3. 增譯（原文沒有的限定語）

「突發的」遺忘、「進過幾天」講堂、「瓦」鉢、「持律大士」、「突吉羅罪／波逸提罪」等，都是譯者添加。方向雖多半合理，但白話譯文宜忠實，補充請放註解。

## 二、逐則核對

### 【628-0001】#107（問題最多）

| 原文 | 現譯 | 問題與建議 |
|---|---|---|
| 初明**學人**開迷 | 有學之人在遇到迷惘時獲得開許 | 「有學」是聲聞前三果的專名，此處「學人」只指**真正修學（律）的人**。又「開迷」是**開許迷忘所犯，不結不學無知罪**。建議：「先說明真正修學的人，遇迷忘時予以開許（不結罪）。」 |
| （科文層次） | 「首先……」／「第一、……」 | 「初明學人開迷」的「初」是「敘結之所以」**之下**的第一節，與前面「首先說明立教之旨」不同層。建議用「其中先明……」以顯層次。 |
| 文中明學，須具**二義** | 兩層意義 | 指兩個**條件**（學教、學行），非「兩層意義」。 |
| 方開**迷忘** | 才開許突發的遺忘迷惘 | 刪「突發的」；作「才開許因迷忘而誤犯之罪」。 |
| 纔過**學肆** | 才稍微進過幾天講堂學肆 | 「幾天」無據；「講堂學肆」重複。建議「才剛到過講學之處」。 |
| 足為**龜鏡** | 足可作為修行的大明鏡 | 龜以卜吉凶、鏡以照妍醜，合指**鑑戒、借鏡**。「大明鏡」只譯一半，「修行的」是增譯。建議「足可作為我們的龜鑑（借鏡）」。 |
| 即諸戒後**境想**中開 | 各條戒後面關於境界想念中所給予的開許 | 「境想」是專名（每戒末「人、人想／疑／不識」等配句），不是泛指「境界想念」。建議「各戒末『境想』句中所開的開緣」。 |
| 次明**昧持** | 對於持戒的盲目 | 語意不清。建議「其次說明於持戒（不犯）之事迷昧無知」。 |
| **持亦成犯** | 即使持戒也仍結**無知罪** | 原文未限定，應作「仍結不學、無知之罪」。 |
| 即「不攝耳聽戒」文 | 〈不攝耳聽戒〉 | 戒名用「」，不宜用篇名號〈〉。 |

另：「泛爾」是**泛泛悠悠、不肯用心**，「泛泛度日」稍偏；「不肯修學」的「不肯」屬增譯（可留，但一致性上宜注意）。

### 【628-0002】#108

* **「須配位法」譯「配對在具體的階位與法規上」有誤。**「位」指下文的**三品品位**（上、中下）／持犯諸位，「法」指**可學事法**；「階位」易誤為修行果位，「法規」如前述。
  建議：「現在略作標舉，還須配合品位與事法來排列。」
* 「兩組九句」可加註：即下文**止持九句、作犯九句**（記文「二九」可證）。

### 【628-0003】#109

* 「在總標題中」❌ → 「總標」是科段名（總體標示），非文章標題。建議「在『總標』這一段中」。
* 「所謂『相互交織』／『準則規範』」→ 還原為「交絡」「方軌」（見上）。
* 「隨便面對任何一項事相或法規」→「隨舉任何一事、一法（事相與犯法）」。
* 「參透」帶禪味，「若解」就是「若能理解」，建議改「若能通解」。
* 「類通法界」譯得可。

### 【628-0004】#110

* 「事相與法規」→「事相與犯法」。
* 可加註：「可學」對「不可學」而言，指可透過學習而知的事與法。
* 「分齊」譯「界限劃分」可。

### 【628-0005】#111

1. **「重」即不識 → 譯「全然不識**教法**」範圍縮小**：本門的「不識」通**事、犯**兩面（不識事、不識犯），非僅不識教法。
2. 「輕謂不學及疑」是**不學之罪與疑心之罪**，現譯「不學與疑惑**所造成的**突吉羅罪」把二者變成「因」，語意略偏。
3. **補出「突吉羅罪／波逸提罪」屬增譯**。雖依律「不攝耳聽戒」有「無知故波逸提」之文，古德判「不學及疑結吉、不識結提」，譯者或有所本；但此處原文只標輕重，且疏記明言「立句之意，如作犯門具明所以」，**建議正文保留「輕罪／重罪」，罪名放註並注明依據**。
4. 「在止持、可學的標示中」建議作「這是牒釋上文『止持』『可學』的標文」。

### 【628-0006】#112

* 「明確明識」贅詞 →「清楚了知」。
* 「這些事相與**法規**」→「這些事相與犯法（罪相）」。
* 「**第一等的上品持律大士**」：「第一等」與「上品」重複；「大士」一般指菩薩，用於「持律之士」過譽。建議「可稱為上品的持律之人」。
* 「夷蘭提吉」展開正確；「三衣一鉢」補「應作之事」與下記相合，很好。

### 【628-0007】#113

* 「制止事／制作事」→「佛制應止（禁止）之事／佛制應作之事」；「強制禁止／強制實行」語感偏硬。
* **「瓦鉢」→「鉢」**（原文未說材質，鉢通鐵、瓦）。
* 「今略示**圖相**」→「現在略示圖表」；「用圖形展示其**行相**」易被讀成心之行相。
* 「提罪對衣鉢」補「的違制」可；可註明「提」通攝**尼薩耆波逸提（捨墮）與單提**（衣鉢多屬捨墮）。

### 【628-0008～0010】#114～116

內容正確，補「中品四句為／下品四句為」很好。僅用詞建議：「完全不識」（#115、#116）與「全然不識」（#111）宜統一。

### 【628-0011】#117

譯文無誤。可加註：此僅舉一邊為例，實亦含「不犯謂犯、迷重謂輕」，且「不識」通於事、犯二種。

### 【628-0012】#118

無問題。

## 三、優先修改順序

1. 還原所有牒文標字（然／若由／若／是／須）與被釋詞（交絡／方軌／律制）。
2. 「法規」→「犯法／戒法」；「位法」重譯；「總標題」→「總標」。
3. #111「不識教法」改為「於事、犯全然不識」；#107「持亦成犯」補「不學、無知」二罪。
4. 刪除或移入註解的增譯：突發、幾天、瓦、大士、突吉羅／波逸提。
5. 「有學之人」「龜鏡」「境想」三處專名重譯。
