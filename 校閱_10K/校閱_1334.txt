# 校閱材料　第1334檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1334-0001】資持記/15c_下三#7
【原文】含蘊無窮，出生無盡，故喻如藏。生身即現在，滅身即舍利。若自下，明營辦。自有功德者，謂富於道行，人所信重者。於己莫輕者，以能供養，獲大福德故。凡下，明用心。若以下，明施物。現在滅後無差別者，謂所得福，存沒正等故。若見下，明供具。次科。
【譯文】其中含藏無窮義理，出生無盡功德，所以譬喻為藏。生身就是佛在世的應化身，滅身就是佛滅度後的舍利。自「若自」以下，說明籌備營建。所謂「自有功德」，是指身懷深厚道行、深為大眾所信服尊崇的人。所謂「於己莫輕」，是因為能親自供養，便能獲得不可思議的大福德。自「凡」以下，說明內心的用心作意。自「若以」以下，說明布施的物品。所謂「現在滅後無差別」，是指所獲得的福報，在佛在世與佛滅度後完全平等相等。自「若見」以下，說明應用的供養器具。接著是下一個科判。

【1334-0002】資持記/15c_下三#8
【原文】修治，自作勸人，隨力所搆。三中，初明造立。若是下，明淨治。任下，嚴飾。畫下，明雜穢。此土多用魚牛等膠；雖復腥鱣，且圖久固。應下，明供養。不下，示非法。酥塗乳洗，皆外道法故。四中。令密藏者，不生善故。令恭敬者，恐生慢故。今時有作涌壁，或畫佛首相，並宜藏之。五中。
【譯文】修葺整治佛塔，無論是自己親手做還是勸導別人做，都要隨順自身的能力去籌措營辦。第三段中，首先說明建造之法。自「若是」以下，說明洗滌淨治的規矩。自「任」以下，說明裝飾的法度。自「畫」以下，說明防範混雜污穢。此地繪畫多半使用魚膠或牛膠等動物膠質；雖然帶有魚肉腥臊之味，但為了畫作能長久堅固，暫且依此施行。自「應」以下，說明供養的儀軌。自「不」以下，指出非法的供養行徑。因為用酥油塗抹、用乳汁沖洗，全部都是外道不合佛法的習氣。第四段中。令其秘密隱藏起來，是因為若隨意顯露反而不能令人生起善心。令其恭敬，是唯恐人隨便見到而生起輕慢心。現今有人在牆壁上浮雕，或隨處彩繪佛頭像，這些都應當遮蓋珍藏起來。第五段中。

【1334-0003】資持記/15c_下三#9
【原文】讚歎，能顯佛德，故勝寶供。六中，初科，《無垢經》中，初即女問三事果報。一問掃塔，二問塗治供養；四相，即方圓半月人形；三問修四法；禪，即色無色定；梵行，即四無量心。上二正用，下一因引。佛告下，如來次答，答初問中。五福：一是內感，二三即外應，四五即來報，四是別報，五即總報。
【譯文】稱揚讚歎能夠顯揚佛陀的無上功德，所以這種法供養遠遠勝過一切珍寶供養。第六段中，第一科引用《無垢經》，一開始便是一位女子向佛請問三種善事的果報。第一問是打掃佛塔，第二問是塗治裝飾供養；其中的「四相」，是指方型、圓型、半月型、人面型四種地相；第三問是修持四種清淨法門；所謂禪，就是色界與無色界的禪定；梵行，是指慈悲喜捨四無量心。上面兩種屬於正行修習，下一種則是旁引的因行。自「佛告」以下，是如來隨後給予的回答，在回答第一個問題中提到五種福報：第一種是內心感應的善報，第二與第三種是外在顯現的善應，第四與第五種是未來的果報，第四種屬於個別的果報，第五種則是總體的總報。

【1334-0004】資持記/15c_下三#10
【原文】若人下，答第二問；四相，四節。初中，若人信佛句絕，此句標心因；圓下，即業行，謂於塔地以泥塗為物像，故有方圓等別；彼下，明獲報，即生後二報。〔餘三節文並爾。〕弗婆提，即東勝身洲，彼人面圓。〔《俱舍》東洲半月，與經不同。〕瞿陀尼，即西州，彼人面如半月；
【譯文】自「若人」以下，是回答第二個問題；其中四相分為四個節段。第一節中，「若人信佛」這句話讀完暫停，這句話標示出發心的因地；自「圓」以下，就是修行的業行，意思是說在塔廟的地基上，用泥土塗抹塑造成各種物體形象，所以才產生了方型、圓型等差異；自「彼」以下，說明所獲得的善報，也就是生報與後報這二種果報（其餘三節的經文結構也都與此相同）。弗婆提，就是東勝身洲，該洲的人面孔圓如滿月（《俱舍論》認為東勝身洲人面孔如半月，這與本經記載不同）。瞿陀尼，就是西牛賀洲，該洲的人面孔形狀如同半月；

【1334-0005】資持記/15c_下三#11
【原文】兜率，此翻知足，欲界第四天。欝單曰，即北州，彼人面方；炎摩，此云妙善，欲界第三天。人面形，即南洲，人面上廣下狹，文脫二報，彼云：後生閻浮提；壽終，生三十三天。所下二句，總結四相。若人入禪下，答第三問，初明修因。四梵行，即慈悲喜捨。彼下，明感報。善根是現報。
【譯文】兜率，此處翻譯為「知足」，是欲界的第四層天。欝單曰，就是北俱盧洲，該洲的人面孔呈方形；炎摩，此處翻譯為「妙善」或「善時」，是欲界的第三層天。人面形，指的是南瞻部洲，此地人的面孔上方寬廣而下方狹長，《鈔》文此處脫落了這兩種果報的經文，彼《無垢經》原文說：「後生閻浮提；壽終，生三十三天。」自「所」開始的兩句，是總結這四種地相的修法果報。自「若人入禪」以下，是回答第三個問題，首先說明修因。所謂四梵行，就是慈、悲、喜、捨四無量心。自「彼」以下，說明感得的果報。成就善根是今生顯現的現報。

【1334-0006】資持記/15c_下三#12
【原文】福報是來果，即人天世果，禪梵定生天，歸戒通人天，涅槃即出世果。《涅槃經》。彼云：東方有佛，世界名不動，佛號滿月光明，無畏菩薩白佛：此土眾生，造何等業，得生彼國？佛以偈答，如《鈔》引。上四句，即四種因，正取中二；下一句，示果。言不犯者，謂不侵損也。二中。
【譯文】福報是來世的善果，也就是人道與天道的世間善果；修習禪定與梵行必定升天，皈依與持戒則通達人間與天界，證得涅槃則是出世間的究竟解脫果。《涅槃經》中記載：東方有佛出世，其佛土名為不動世界，佛號為滿月光明佛。當時無畏菩薩請向佛陀請問：這個世界的眾生，究竟造作了什麼樣的業行，才能往生到那個清淨國度？佛陀便以偈頌回答，正如同《行事鈔》中所引用的內容。偈頌中前面的四句話，標示出四種得生的因地，此處正取其中的中間二句；最後一句，則是明示修因所感的清淨果報。所謂「不犯」，意思是指完全不侵佔毀損常住財物。第二段中。

【1334-0007】資持記/15c_下三#13
【原文】西國多以妙香，塗身供養；十戒制斷，故此問之。答中有二。後解，是今正用。三中。破寺報重，反明造立功深。二造寺法，總示中，初標人法。即露裕法師；稱美道行，故云盛德。《寺誥》，即彼文通題。具下，示其所述。事下，明今所引。次引示中，初文，前敘如法。
【譯文】西域各國大多習慣用極珍貴的妙香塗抹在身上來作為供養；然而沙彌十戒中已明文制訂斷除香油塗身，所以此處特別提出這層疑問。論中的回答有兩種解釋。後面那種解釋，才是我們現今所正應依循採用的。第三段中。拆毀破壞寺院所招感的惡報極其深重，這正好反過來證明了興建寺院的功德無比深廣。第二、造寺之法。在總體提示的段落中，首先標示出所依的人與法。所依的人就是露裕法師；為了稱美其純篤高深的道行，所以尊稱他為「盛德」。《寺誥》，就是該篇文獻的通稱總題。自「具」以下，說明法師著述的完整背景。自「事」以下，說明當前所引用的主旨。接著在引文示導中，前文先敘述合乎戒律規制的如法情況。

【1334-0008】資持記/15c_下三#14
【原文】譏謂譏嫌，涉即干涉，即近尼寺市傍等處。經坊，即今經藏。今下，次明非法。唯有處所，謂但造堂舍。而羯磨結界，時有行之，故云亦有。言限外者，或堂舍之外，或復寺外。故下，引示。木石等者，植樹表其生長，立石表其堅貞；戒壇居東，表發生之義；無常院在西，表傾沒非久；立剎，表迷者知歸；
【譯文】譏是指世人的譏諷嫌棄，涉是指世俗人事牽扯干涉，比如距離比丘尼寺院或市集過於接近的地方。經坊，就是指現今的經藏或藏經閣。自「今」以下，接著說明不如法、違背戒規的情況。所謂「唯有處所」，意思是說只懂得建造堂舍空屋。然而如法透過羯磨法來結立結界，當時也偶爾有人施行，所以說「亦有」。所謂「限外」，是指或者在堂舍界限之外，或者是指在整座寺院之外。自「故」以下，引用文獻加以說明。種植樹木是為了表徵佛法生生不息的長養，樹立磐石是為了表徵道心的堅貞不移；戒壇設置在東方，表徵萬物生發萌芽的涵義；無常院設置在西方，表徵身命終將傾覆殞沒、無法長久；建立高剎，表徵令迷失方向的人懂得皈依歸向；
