# 校閱材料　第001檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【001-0001】01_行事鈔/01a_卷上之一#34
【原文】《四分》文云：當敷座，打楗稚，盡共集一處等。《五分》云：諸比丘布薩時，不時集，妨行道。佛言，當唱時至，若打犍稚，若打鼓、吹螺。使舊住沙彌、淨人打。不得多，應打三通。吹螺亦爾。除漆毒樹、餘木，銅、鐵，凡鳴者聽作。若唱二時至，亦使沙彌淨人唱。住處多，不得遍聞，應高處唱。猶不知集，更相語知。若無沙彌，比丘亦得打。《十誦》中：居士請僧，自於寺內鳴稚。乃至白時至。及送食女人，亦自鳴稚。中食施者亦爾。《增一阿含》云：阿難升講堂，擊犍稚者，此是如來信鼓也。《十誦》中：時僧坊中，無人知時限，唱時至，及打揵稚；又無人灑掃塗治講堂食處；無人相續鋪床；及教人淨果、菜、食中蟲；飲食時，無人行水；眾亂語時，無人彈指等。佛令立維那。《聲論》翻為次第也，謂知事之次第，相傳云悅眾也。若準文中，七種集法：若量影，破竹作聲，作煙，吹貝，打鼓，打犍稚，若唱諸大德布薩說戒時到。亦不言比丘為之。《出要律儀》引《聲論》，翻犍稚，此名磬也，亦名為鐘。
【譯文】《四分律》文中說：應當鋪設座席，敲擊揵稚（犍槌），全體一同集會於一處等。《五分律》說：諸比丘布薩（說戒）之時，不能按時集合，妨礙了修持道業。佛陀說，應當宣唱集會時辰已到，或者敲擊犍稚，或者擊鼓、吹螺。應當差遣常住的沙彌、淨人敲擊。次數不可過多，應當敲打三通。吹螺也是如此。除了漆樹等有毒樹木之外，其餘木料、銅、鐵等，凡是能發出聲響的都准許製作為犍稚。如果宣唱早中二時食時已到，也差遣沙彌、淨人宣唱。若是住處廣大分散，不能普遍聽聞，應當登上高處宣唱。如果仍有人不知前來集合，應互相走告告知。若是沒有沙彌，比丘也可以親自敲擊。《十誦律》中記載：居士迎請僧眾供齋，可親自在寺院內敲擊犍稚，乃至親自告白食時已到；送飯食來的婦女，也可以親自敲擊犍稚；布施中飯午齋的人也是如此。《增一阿含經》說：阿難尊者登上講堂敲擊犍稚，這就是如來的信約法鼓。《十誦律》中記載：當時僧舍中，沒有人通曉時限、宣唱時辰已到以及敲擊犍稚；又沒有人負責灑掃、塗泥修治講堂與用齋處所；沒有人接續鋪設坐臥床座；以及教導他人為瓜果蔬菜作淨、挑出食物中的小蟲；用齋時，沒有人分行淨水；大眾雜亂喧譁交談時，沒有人彈指制止肅靜等。佛陀便命令設立「維那（karmadāna）」一職。《聲論》（梵語文典）翻譯為「次第」，意思是掌管執事之先後秩序，漢地相傳稱為「悅眾」。若是依照律文，共有七種集合的方法：測量日影、破裂竹子發出響聲、生煙發信號、吹法螺貝、擊鼓、敲擊犍稚，或者宣唱「各位大德，布薩說戒的時辰已到」。律中也沒有嚴格限定必須由比丘親自為之。《出要律儀》引用《聲論》說，翻譯「犍稚」之名，此方稱為「磬」，也稱為「鐘」。

【001-0002】01_行事鈔/01a_卷上之一#35
【原文】上具列文，今須義設。凡施法事，先斟量用僧多少，依數鋪設座席，然後準文鳴鐘，具如〈集僧〉法中。雖人並為之，多無楷式；若依《三千威儀經》，則大有科要多少，節解之法；但時所同廢，雖易而難。今通立一法，總成大準；謂約僧多少，就事緩急，量時用之。若尋常所行，生稚之始，必漸發聲，漸希漸大，乃至聲盡，方打一通；如是至三，名為三下。佛在世時，但有三下，故《五分》云打三通也。後因他請，方有長打。其生起長打之初，亦同三下；中間四稚，聲盡方打；如是漸漸斂稚，漸穊漸小，乃至微末，方復生稚，同前三下。此古師以經律參挍，共立此法；亦有清眾畫樣鐘所者。然初欲鳴時，當依經論建心標為，必有感徵。應至鐘所，禮三寶訖，具儀立念：我鳴此鐘者，為召十方僧眾，有得聞者，並皆雲集，共同和利；又諸有惡趣受苦眾生，令得停息。故《付法藏傳》中：罽膩吒王以大殺害故，死入千頭魚中；劍輪繞身，而轉隨斫隨生。若聞鐘聲，劍輪在空。如是因緣，遣信白令長打，使我苦息。即《增一阿含》云：若打鐘時，一切惡道諸苦，並得停止。此並因緣相召，自然之理不亡。余親承有斂念者，被鬼神送物。世有濫用知鐘者，此非聖言。諸經論但云打擊檛等。知淨之語，不通於俗及以自為。早須廢捨。
【譯文】上面具體列舉了律藏原文，現在必須從義理上建立行持軌制。凡是要舉行法事羯磨，首先應當審度考量所需僧眾人數的多寡，依據人數鋪設座位坐席，然後依照律文規定鳴鐘敲擊犍稚，具體細節如〈集僧〉專法中所載。雖然人人都在行做此事，但大多沒有標準的楷模規範；若是依照《大比丘三千威儀經》，則詳細規定了敲擊節奏的多寡、節拍斷續分明的打法；只是當代世人多已共同廢棄不習，看似容易實行起來卻很難合度。現在通論立定一套打法，總體作為大原則標準：即審度僧眾的多寡，切合事情的緩急，斟酌時機而運用。若是尋常行事的打法，在剛開始生起敲擊時，必定是逐漸發聲，節奏由密漸疏、聲浪由弱漸大，直到餘音將絕，才算打完一通；如此重複三次，就稱為「三下（三通）」。佛陀在世時，只有三下的打法，所以《五分律》說敲打三通。後來因為他人請求（如下文罽膩吒王遣信請求），才有了「長打（連續長敲）」的作法。其生起長打的開頭，也與三下的打法相同；中間敲擊四下犍稚，必定要等聲音平息完盡後才敲下一聲；這樣漸漸收斂槌聲，敲擊漸漸密集、聲音漸漸微小，直到細微無聲之際，才又重新發槌生起，如同前面的三下敲法。這是古代律師以經藏與律藏互相參證考訂，共同確立的這套法度；也有清淨僧眾將此敲擊節奏的圖樣張貼畫在鐘樓處的。然而剛要開始敲鳴之時，應當依照經論確立心願目標，如此必有效驗感應。應當走到鐘樓敲鐘處，禮拜三寶完畢，整肅威儀端正立定作念：「我敲鳴這座大鐘，是為了召集十方僧眾，凡是能夠聽聞鐘聲的人，都能雲集於此，共同成就和合與勝妙法利；又令所有在惡道受苦的眾生，聽聞鐘聲都能暫得止息痛苦。」所以《付法藏因緣傳》記載：罽膩吒王（迦膩色迦王）因為生前廣造殺業的緣故，死後轉生為巨大的千頭魚；有無數飛旋的劍輪環繞其身，不斷旋轉隨斬隨生受盡折磨。若是聽聞到佛寺鐘聲，劍輪便會懸停於空中停止斬割。因為這樣的因緣，他託夢遣使告知寺院懇請長打鐘聲，讓他的劇苦得以止息。這正是《增一阿含經》所說：「若是敲鐘之時，一切惡道中的種種苦痛，都能暫時止息停歇。」這些都是感應因緣互相感召，法爾自然的規律絕不泯滅。我親自聽聞有敲鐘時收攝正念祝願的人，受到善神鬼眾送物酬謝。世間有人濫用「知鐘」的說法（比丘差遣人敲鐘時不直說打鐘而妄稱「知鐘」以為是清淨語），這並非佛經聖典的用語。諸部經論只說「打」、「擊」、「撾」等。若是比照「知淨」這類淨語，本來就不通於俗人差遣、更不通於比丘自己去做（比丘自己敲鐘不可能對自己說「知鐘」）。「知鐘」這種虛妄的說法，應當及早予以廢棄。

【001-0005】01_行事鈔/01a_卷上之一#38
【原文】若作法界，則有三別：有戒場者，四處集僧，各得行事；一在戒場，二在空地，三在大界，四在界外。若無戒場，二處各集。若小界者，既不立相，直指坐處，無外可集。
【譯文】如果是「作法界（依如法羯磨作法劃定的結界）」，則有三種分別：如果有設立戒場者，可在四個處所召集僧眾，各自能夠成辦僧事：一是在戒場之內，二是在大界內扣除戒場後的空地上，三是在未隔開的大界內，四是在作法界之外。如果沒有戒場，則在作法界內與作法界外這兩處各自集會行事。如果是臨時設立的「小界」，既然不另外標立標相界標，只是直接指定僧眾當下所坐的處所，便沒有界外可供另一處集會。
