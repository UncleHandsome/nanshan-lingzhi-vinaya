# 校閱材料　第860檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【860-0001】02_戒疏/21a_卷四下之三#106
【原文】【疏】就初文中，佛言：「諍有四種。」
【譯文】【疏文】在第一個章節中，佛陀說：「諍論有四種。」

【860-0002】02_戒疏/21a_卷四下之三#107
【原文】【疏】一、「言諍」者。謂評法相是非，須知邪正，各執己見而生其諍。諍由言起，故曰「言諍」。
【譯文】【疏文】第一種叫做「言諍」。這是指評斷佛法教理名相的對錯是非，必須辨明邪正，結果雙方各執己見而產生諍論。諍執是因言談辯論而引發，所以叫做「言諍」。

【860-0003】02_戒疏/21a_卷四下之三#108
【原文】【疏】二、「覓諍」者。比丘犯過，理須為除，制有三根五德，舉來詣僧，伺覓前罪，令其除殄。因舉評犯，遂生其諍。諍由覓生，故曰「覓諍」。
【譯文】【疏文】第二種叫做「覓諍」。比丘若犯了過失，按理僧團必須為其除去罪障，律制中具備見、聞、疑三種根據（三根）以及五種清淨德行，才能向僧團檢舉，藉由搜查追究其先前罪過，令其懺悔滅罪。因為舉發評議犯戒之事，遂引發爭論。爭吵是因搜查追究而產生，所以叫做「覓諍」。

【860-0004】02_戒疏/21a_卷四下之三#109
【原文】【疏】言「犯諍」者。有過在懷，宜須懺蕩，罪相難識，各議紛紜，遂生諍競。競由犯起，故曰「犯諍」。
【譯文】【疏文】所謂「犯諍」。是指比丘身懷罪過，本應當坦誠懺除滌淨，然而罪名過相難以辨識清楚，大眾各抒己見紛紜莫衷一是，於是產生競爭爭執。爭議是由違犯戒律的判定而引起，所以叫做「犯諍」。

【860-0005】02_戒疏/21a_卷四下之三#110
【原文】【疏】言「事諍」者。羯磨被事，義在順明，片有乖違，未有成遂。然人情易忍，同和理難，各執一見，事法成壞，由斯致諍。諍起由事，故曰「事諍」。
【譯文】【疏文】所謂「事諍」。僧團羯磨所要成辦的事務，其宗旨本在於順應律法而條理分明，只要稍有違背，整件事就無法合法成就。然而人情容易各隨私意而忍可己見，要在理法上達成同心和合卻很困難，大眾各執己見，導致僧事與作法究竟是成就還是敗壞，因此引發爭端。爭論是由於僧團辦事而引起，所以叫做「事諍」。

【860-0006】02_戒疏/21a_卷四下之三#111
【原文】【記】識名中。「言諍者」，因評法相，如《律》諍十八事，餘諍例此。「覓諍」，因他舉罪，諍其成否。「犯諍」，因有懺罪，諍其重輕。「事諍」，唯據羯磨僧事，若非羯磨，並歸上三。「事法成壞」者，「事」即所加，「法」即能被，更兼能秉人及所託界，四法並有如非成壞。
【譯文】【記文】在解釋名相的段落中。所謂「言諍」，是因評斷教法名相而起，例如律藏中記載爭論十八事，其餘諍論以此類推。「覓諍」，是因他人舉發罪過，爭論舉罪程序與事實是否成立。「犯諍」，是因有人要懺悔罪過，大家爭論該罪行的輕重程度。「事諍」，唯獨專指僧團依羯磨辦理的大事，如果不是羯磨法事，全都歸入前三類。「事法成壞」是指，「事」即所要處理的事件對象，「法」即用來處理該事的羯磨規範，更涵蓋了能主持羯磨的人員資格以及所依託的結界範圍，這四種法則只要有如法或非法的差異，便有成辦與毀壞之別。

【原文】【疏】上略釋名相，次明分品。
【譯文】【疏文】以上簡要解釋了諍論的名義行相，接下來說明劃分品位的層次。

【860-0008】02_戒疏/21a_卷四下之三#113
【原文】【疏】用七藥治四諍，諍分十八，則離於藥亦有十八也。
【譯文】【疏文】以七種滅諍的藥方來對治四種諍論的病症，諍論既然可以細分為十八種情況，那麼相對應的藥方剖析起來也有十八種。

【860-0009】02_戒疏/21a_卷四下之三#114
【原文】【記】第二，品量，示數中。七藥四諍各有十八，即是總別開合異耳。
【譯文】【記文】第二部分分析品位，在指示數量之中。七種藥方與四種諍論各自具備十八種情境，這只是大綱分類與個別展開的開合不同而已。

【860-0010】02_戒疏/21a_卷四下之三#115
【原文】【疏】何者是邪？言、覓、犯諍，各分三品，則上中下，故分九種也。「事諍一種」，離為九品，約言、覓、犯，各生事諍。
【譯文】【疏文】具體內容是什麼呢？言諍、覓諍、犯諍三種，各自區分為三品，即上品、中品、下品，所以先分出九種。而「事諍這一種」，又依據所牽涉的言諍、覓諍、犯諍，各自產生相應的事諍，因此自己展開為九品。

【860-0011】02_戒疏/21a_卷四下之三#116
【原文】【記】分品中，初科。初明三諍共為九品。次明事諍，自分「九品」者，即上三諍涉羯磨者，皆歸事攝。
【譯文】【記文】在劃分品位中，屬於第一項。首先說明三種諍論總共構成九品。其次說明事諍自己區分為「九品」，是指前面三種諍論只要牽涉到僧團羯磨程序的，全都收歸事諍的範疇。

【860-0012】02_戒疏/21a_卷四下之三#117
【原文】【疏】如何識邪？謂言諍中，若評教理是非，犯相輕重，是名言諍；若評羯磨是非，迷悟不決，此名言諍中事諍。若評三根清濁，五德通塞，是名覓諍；若評用法治舉，徵覈虗實，則名覓諍中事諍。於五犯聚，懺評有濫，名犯諍；非法羯磨，定罪重輕，是名犯諍中事諍。隨本諍分上中下異，故成九品。
【譯文】【疏文】應當如何辨識呢？也就是說在言諍之中，如果是評議教理的是非、犯戒行相的輕重，這稱為言諍；如果是評議羯磨作法的如法與否、眾人困惑或明了爭執不決（或：對是非迷惑或通曉猶豫不決），這稱為言諍中的事諍。如果是審查舉罪依據的三根是否清白、舉罪者的五德是否具足，這稱為覓諍；如果是評議用以處罰懲戒的羯磨法是否得當、查核事實的虛實，這就稱為覓諍中的事諍。若是對於五種犯戒聚落中，懺悔時的罪名評定有所混淆，稱為犯諍；若是透過非法羯磨來判定罪行輕重，這稱為犯諍中的事諍。隨著原本諍論的根源再劃分為上、中、下品的不同，因此共構成九品。

【860-0013】02_戒疏/21a_卷四下之三#118
【原文】【記】次科。第列三諍，對顯事諍，一一兩分，方見四諍條然無濫。「隨本諍分」者，謂此事諍，同前三諍為九品也。
【譯文】【記文】這是下一項內容。依序排列前面三種諍論，相對顯現事諍的特點，每一種都作雙向劃分，這樣才能看清四種諍論井然有序而毫不雜亂。所謂「隨本諍分」，是指這種事諍如同前三諍一樣，也配合開展為九品。

【860-0016】02_戒疏/21a_卷四下之三#121
【原文】【記】「現前」一種，通三諍該九品。除下品言犯不秉羯磨，但有三法；餘七並加羯磨，皆具五法。「自言」一種，局後犯諍，通治二品；自餘五種，單對一品。上云七藥、四諍各分九品，諍如上分，藥九品者：言諍二藥，覓諍四藥，犯諍三藥，則為九也。
【譯文】【記文】「現前毗尼」這一種藥方，貫通三種諍論並涵蓋全部九品。除了下品言諍與下品犯諍不需要舉行羯磨、只具備三種現前法則之外；其餘七種情況都必須加上羯磨，皆須具備五種現前法則。「承認自白（自言治）」這一種，局限用於後面的犯諍，但通治犯諍中的兩品；其餘五種藥方，各自單獨對應一品。前文提到七種藥方與四種諍論各自細分九品，諍論的劃分如前所述，藥方的九品是：平息言諍有二種藥方，平息覓諍有四種藥方，平息犯諍有三種藥方，合起來也是九種。

【860-0018】02_戒疏/21a_卷四下之三#123
【原文】【疏】下品言諍，以三品現前毗尼滅：一、人現前，兩家同聚，各說教理也；二、法現前，以三藏教判也；三、毗尼現前，教旨明白，疑闇自遣也。
【譯文】【疏文】下品的言諍，用具備三種要素的「現前毗尼」來平息：第一、人員現前，雙方當事人聚集在一起，各自陳述教法義理；第二、法義現前，依據經律論三藏聖教來作評判；第三、戒律精神現前（毗尼現前），聖教的旨趣清晰明瞭，心中的疑惑與無明自然得以化解消除。
