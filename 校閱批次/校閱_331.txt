# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【331-0013】02_戒疏/17b_卷四上之二#95
【原文】【疏】就戒緣中，「作婬像」者，良由染患情重，寄物彰過，約境須斷也。《五分》云：「愛道卷衣舒以示佛，視此所作也。」
【譯文】【疏文】在戒律緣起中，所謂「裁製情欲圖像」，確實是因為愛染煩惱極重，藉由物品彰顯內心的淫欲過失，針對境界必須徹底斷除這種因緣。《五分律》說：「大愛道把衣服卷好帶去展開展示給佛陀看，說請看比丘所做的衣物。」

【譯文】【記文】在緣起中。首先引述解釋。由於替尼眾做衣服，引發了染愛之情，所以說「藉由物品彰顯過失」。由此可知本戒表面上是禁止作衣，實質上完全是為了斷除淫欲。《五分律》以下，引用經律作證。「卷衣展給佛看」，更加顯明此種過失極應制戒防範。

【331-0016】資持記/15a_下三#24
【原文】既知萬劫難逢，勿使一生虛度。請遍尋大藏，深信佛言；竭力奉行，則真佛子矣。次科，論有五意，初謂處眾多惱。以食僧食故。二謂造食多過。言非法者，或買物侵虧，或損傷物命，或宿煮惡觸，故不清淨也。三謂繫屬多患。強顏故色不安，承意故心不安。四順行四依，初示制意。
【譯文】既然知道千萬劫都難以遭遇，就不要讓自己的一生虛度空過。請遍閱大藏經，深深相信佛的教言；竭盡全力奉行，才是真正的佛弟子啊。下一個科判，論書有五種用意：第一是指處在大眾中多有煩惱，因為食用常住僧食的緣故。第二是指烹調造辦飲食過患很多。所謂「非法」，有的是買東西缺斤少兩損害他人，有的是損傷生命，有的是過夜再煮或惡觸不淨，所以食物不乾淨。第三是指攀附牽繫他人患難很多。勉強強顏歡笑所以神色不安，迎合他人心意所以內心不安。第四是隨順奉行四依法，首先顯示制戒的用意。

【331-0017】資持記/15a_下三#25
【原文】受下，彰損益，初敘受請之損。若下，明乞食之益。兼味，兼猶重也。又下，即第五謂即事表法。無盡法者，佛法大海，無源底故。三中，初科，先明出蘭若法。著衣執杖行等，即身業；思惟，即意業；見人問訊等，即口業。打露杖，謂去草上露水，恐濕衣故；或云執錫，驚虫獸故。
【譯文】「受」字以下，彰顯損害與利益，先敘述接受應酬供請的損害。「若」字以下，說明乞食的利益。「兼味」，「兼」就是加倍、厚重的意思。「又」字以下，就是第五種用意，指藉助事相顯發法義。「無盡法」，是指佛法如廣大海，沒有源頭底限。在第三段中，第一科先說明走出阿蘭若的方法。穿衣、拿手杖行走等，屬於身業；思惟法義，屬於意業；見到人互相問候等，屬於口業。「打露杖」，是指打落雜草上的露水，唯恐打濕了僧衣；也有人說是手持錫杖，為了驚走蟲獸。

【331-0018】資持記/15a_下三#26
【原文】若近下，次入聚行乞法，有六，初著衣法。至下，二瞻視法。至第七門相，以律制法，不過七家故。若準《多論》，則有三種次第乞食，一日到一家，得食則食，不足則止；二次第到七家，得食則食，不得亦止；三次第從家至家，食足則止，不限多少；後日乞食，還從先次第；
【譯文】「若近」以下，其次進入村落聚落行乞的方法，共有六項：第一是穿衣之法。「至」字以下，第二是瞻視之法。走到第七家門前，依照戒律制定的法則，不得超過七家。如果依照《薩婆多論》，則有三種次第乞食法：一是每天走到一家，得到飲食就吃，不夠就停止；二是依次走到七家，得到食物就吃，得不到也停止；三是依次挨家挨戶走下去，吃飽了就停止，不限制家數多少；後一天去乞食，再接著先前的次序；
