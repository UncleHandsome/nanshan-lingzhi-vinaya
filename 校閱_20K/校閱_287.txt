# 校閱材料　第287檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【287-0001】02_戒疏/10d_卷三上之一#44
【原文】【疏】初中，「彼比丘」者，如法比丘見行非法，故自陳諫。「諫是比丘」者，是行邪法人也。初「莫壞」者，牒始心於佛不忍，思欲破輪時也。中「莫方便」者，牒共四伴計校時也。後「莫受」下，牒其行化於時，不須破僧，不須受法也。
【譯文】【疏文】第一部分中，「彼比丘」，是指如法的清淨比丘見到對方行持非法，所以主動陳詞規勸。「諫是比丘」，是指那個推行邪法的人。開頭的「莫壞」，是總括他最初在佛陀面前懷有不能忍受之心，心裡盤算著想要破壞法輪的那個時期。中間的「莫方便」，是總括他與四個同黨密謀策劃的那個時期。最後的「莫受」以下，是總括他在世間推行教化的那個時期，告誡他不必去破壞僧團，也不要去接受那種非法。

【譯文】【記文】接著作正面解釋，在總括提撕過錯的段落中。首先解釋比丘，用以揀別邪正的不同。「初」字以下，接著解釋破壞僧團在時間上的三個前後階段。

【譯文】【疏文】第二部分從「大德」以下，因為上面有所勸導告誡不要去做的惡事，下面就必然有所勸導應當去從事的善行。

【287-0004】02_戒疏/10d_卷三上之一#47
【原文】【記】次釋勸同，總分中。「上勸不為」，即前壞僧也。「下有所為」，即後令和合也。
【譯文】【記文】接著解釋勸導回歸同和，在總體劃分當中。「上勸不為」，就是指前面不要破壞僧團。「下有所為」，就是指後面勸令彼此和合。

【287-0005】02_戒疏/10d_卷三上之一#48
【原文】【疏】就勸同中，初舉喻示諫，二、舉有益示諫。就初法中，初「與僧和合」者，成僧義也。俗以和為貴，僧以和為義。必同六相，方成僧體，如何同戒而欲別見？此勸體同也。
【譯文】【疏文】在勸導同和的內容中，首先是舉出比喻來開示規勸，第二是舉出得大助益來開示規勸。在第一種正法內涵中，開頭的「與僧和合」，是成就僧伽的意義。世俗尚且以和為貴，僧團更應當以和為其核心本質。必須具備六和敬之相，才能構成僧團的主體，怎麼可以受持同樣的戒律，內心卻想要存有相左的偏見呢？這是勸導在僧團體性上要同和。

【287-0006】02_戒疏/10d_卷三上之一#49
【原文】【記】次科，勸體同中。「俗以和為貴」，《論語》云：「禮之用，和為貴。先王之道，斯為美。」、「六相」即六和，內外各三也。
【譯文】【記文】下一科段，在勸導僧體同和當中。「俗以和為貴」，《論語》說：「禮的運用，以和為最尊貴。古代先王治理之道，最美妙的地方就在這裡。」「六相」就是指六和敬，內在與外在各具三種。

【287-0007】02_戒疏/10d_卷三上之一#50

【譯文】【疏文】第二、說明「不諍、同一師學」，世間之所以會產生紛諍，都是因為各從其師、修學各異的緣故。如今大家共同以釋迦為姓，導師本來就沒有兩樣，能有什麼個人私見而偏要背離乖異呢？這是勸導在修行實踐上要同和。

【譯文】【記文】在勸導行持同和當中。「異學」是指各隨不同的世俗師長。「同釋姓」，是指大家都不再分彼此不同的宗族了。「師無殊」，是指大家的法脈傳承並無不同。

【287-0009】02_戒疏/10d_卷三上之一#52
【原文】【疏】「如水乳合」者，師乖見異，義則有殊，師同見合，理則無別。如乳合乳，如水合水。不得云「乳合水」，以相合非體，鵝能別故。
【譯文】【疏文】「如水乳合」的意思，如果師承乖違、見解相左，義理上就會產生懸殊；若是導師相同、正見契合，在道理上就不應有分別。就如同把乳汁融入乳汁，把清水融入清水一樣。不能說是「乳融入水」，因為水乳相融畢竟非同一體性，鵝王尚且能把乳汁與水分別開來的緣故。

【287-0010】02_戒疏/10d_卷三上之一#53
【原文】【記】釋喻中。「乳」即水之甘味，與水體別，唯鵝王能別取而食之。既非一體，法喻有乖，必須二物各自論合，故云「不得」等。
【譯文】【記文】在解釋比喻當中。「乳」是水中的甘甜滋味，與水的自體不同，只有鵝王能單獨把它吸取飲用。水乳既然不是徹底一體，在法與比喻上就會有所偏差，所以必須是兩種同質之物各自論其相合，因此疏文才說「不得」等話。

【287-0011】02_戒疏/10d_卷三上之一#54
【原文】【疏】二、「於佛法中增益安樂」者，良由捨除異見，同體行和，如法修道，必除生死，得涅槃樂，故曰也。「增益」者，超凡夫界也。「安樂」者，絕三苦也。
【譯文】【疏文】第二、「在佛法中增益安樂」，確實是由於捨棄消除了異端邪見，體性同和、行持同和，依照正法修行辦道，就必定能夠斷除生死輪迴，證得涅槃之樂，所以經文這樣說。「增益」，是指超越凡夫的界限。「安樂」，是指徹底斷絕三苦（苦苦、壞苦、行苦）。

【287-0012】02_戒疏/10d_卷三上之一#55
【原文】【記】舉益勸中。初通釋。「同體行和」，躡上二勸也。「除生死」者，即增益也。「得涅槃」者，即安樂也。「增」下，別釋。「凡夫界」，即三有也。「三苦」者，一、苦苦，二、壞苦，三、行苦。既超三有，永絕三苦，故「安樂」。
【譯文】【記文】在舉出利益以勸勉的段落中。首先是通盤解釋。「同體行和」，是承接前面兩種同和的勸導。「除生死」，就是增益的意思。「得涅槃」，就是安樂的意思。「增」字以下，分別解釋。「凡夫界」，就是指三界六道。「三苦」，一是指苦苦，二是指壞苦，三是指行苦。既然超越了三有界限，永遠斷絕了三苦，所以稱為「安樂」。

【原文】【疏】「彼比丘」下，明僧諫相。「乃至三諫捨者善」，何等「善」邪？一、以本諫不成殘故，二、以屏諫非提罪故，三、以所犯不成蘭故，曰「善」也。
【譯文】【疏文】「彼比丘」以下，說明僧團公眾規勸的相狀。「乃至三諫捨者善」，是哪一種「善」呢？第一、因為原先發動規勸的事由不再構成僧殘重罪；第二、因為在私下規勸時不至於結成波逸提罪；第三、因為所造的破僧惡事不再構成偷蘭遮果罪，所以稱作「善」。

【287-0021】02_戒疏/10d_卷三上之一#64
【原文】【記】第三雙，初科。釋文。三義釋善，無非離犯。「不成蘭」，即破輪罪也。
【譯文】【記文】第三對句中，第一科段。解釋經文。用三種義理來解釋善，無非都是遠離了犯戒罪過。「不成蘭」，是指不構成破法輪的偷蘭遮重罪。

【287-0023】02_戒疏/10d_卷三上之一#66
【原文】【疏】注中明僧和相。隨其白、羯磨，一一住問者，明諫法也。故約白、羯磨中間住諫，冀彼迴心從善。何得誦過成犯？則非本意也。
【譯文】【疏文】注文中說明僧團如法和合之相。隨著每一次作白、羯磨，都在中間停頓詢問的，是為了闡明規勸之法。所以依據單白、羯磨的中間停頓給予勸誡，是期望對方能夠回心向善。哪裡能夠直接一路念完羯磨讓他成罪呢？那樣就完全違背了規勸的本意了。

【287-0024】02_戒疏/10d_卷三上之一#67
【原文】【記】釋注中。「明諫法」者，以白四羯磨，止是告僧，故須隨法加勸，方名諫法。「中間住」者，謂四法三住，欲彰諫意，不為成罪。
【譯文】【記文】解釋注文當中。「明諫法」，是因為白四羯磨本來只是宣告僧眾，所以必須在羯磨法進行中隨機加以勸勉，才稱得上是真正的規勸之法。「中間住」，是指在四個作法程序之間有三次停頓，是為了彰顯慈悲規勸的意旨，而不是為了要讓他結罪。

【287-0027】02_戒疏/10d_卷三上之一#70
【原文】【疏】問：「此三羯磨竟得僧殘者，為攬因成果不？」
【譯文】【疏文】提問：「在進行完第三次羯磨完畢而得僧殘罪的時候，是合併前期的因位小罪共同構成這一重大極果呢，還是不合併呢？」

【287-0028】02_戒疏/10d_卷三上之一#71
【原文】【疏】答：「上『方便義』已論，此何復問？恐迷故耳。然諸部不同。《五分》所明，藉前方便，成後重殘。如《律本》中，作惡修善，有步步罪福。《多論》亦同。如《律》二羯磨竟三蘭，心不息故，若竟結殘。更不云蘭，明知相成。如《僧祇》，攬一切蘭，以成僧殘。又《見》云：前因變滅，以成後果。故知攬四蘭，共成一殘。」
【譯文】【疏文】回答：「上面討論『方便罪義』時已經論述過了，這裡為什麼又提問？是擔心有人迷惑罷了。然而各部律派的說法不同。《五分律》所說的，是藉助前期的方便罪之勢力，來促成後面的僧殘重罪。如同本律《律本》中說，作惡或修善，每走一步都有步步的罪過與福報。《薩婆多論》的觀點也相同。又如同本律說，第二次羯磨完畢結三個偷蘭遮，因為惡心不肯止息的緣故，如果最後羯磨完畢結僧殘罪，經文就不再提及前期的偷蘭遮，由此可知是前後罪相合併相成的。又如《僧祇律》明確說，合併前期的所有偷蘭遮罪，以共同構成一個僧殘罪。此外《善見論》也說：前期的因位罪業轉變滅去，以成就後期的果位重罪。由此可知是合併四個偷蘭遮罪，共同構成一個僧殘罪。」

【287-0029】02_戒疏/10d_卷三上之一#72
【原文】【記】次釋拒諫，初問。答中。初示重意。「然」下，正釋。初句總示。「五分」下，別釋，又二。初至「亦同」，明不相攬。《五分》「藉前方便」，謂藉勢而成，顯非攬故。「如」下，引《律》進趣，反證外部。「步步罪福」，顯是各成，非相攬故。此示本宗非無彼義。《多論》宗《十誦》，故同《五分》。次從「如《律》」下，明相攬。初引本部，即如注中，二羯磨竟，兼前一白，故得「三蘭」。《僧祇》文如上引，及與《善見》，二文並同。
【譯文】【記文】接著解釋抗拒僧諫，首先發問。回答當中。先提示之所以重複說明的深意。「然」字以下，正式解釋。第一句總體開示。「五分」以下，分別解釋，又分為兩部分：從開頭到「亦同」，是說明不互相合併。《五分律》說「藉前方便」，是指藉著方便罪的勢頭來成就果罪，顯然不是把因位罪收攬融合成一果。「如」字以下，引述本律進趣方便之文，反向論證外餘部派的觀點。「步步罪福」，顯示罪業是各自獨立成立的，並非相互融合吸收。這是指出本宗並非沒有那種「不相合併」的義理。《薩婆多論》宗奉《十誦律》，所以觀點與《五分律》相同。接著從「如律」以下，說明前後合併相成。首先引述本部律，就是指注文中所說，第二次羯磨完畢，連同前面的一次單白，所以得「三個偷蘭遮」。《僧祇律》的經文如同上面所引述的，以及《善見論》，這兩部文獻的觀點完全一致。

【287-0030】02_戒疏/10d_卷三上之一#73
【原文】【疏】問：「《律本》但出二羯磨竟三蘭，何得加四？」
【譯文】【疏文】提問：「《四分律》本來只列出兩次羯磨完畢得三個偷蘭遮，怎麼能夠增加成四個偷蘭遮呢？」

【287-0031】02_戒疏/10d_卷三上之一#74
【原文】【疏】答：「《僧祇》有之，義不可別。以白未竟因吉，竟即果蘭。三羯磨未竟，因不可吉，以竟果殘，故有四蘭。」
【譯文】【疏文】回答：「《僧祇律》中有這樣的說法，其義理不應有差別。因為單白未完成是因位結突吉羅，單白完成就是果位結偷蘭遮。三次羯磨在未完成時，因位罪不能再結突吉羅，因為一旦全體完成就是果位的僧殘罪，所以在整個推進過程中總共有四個偷蘭遮因位罪。」

【287-0032】02_戒疏/10d_卷三上之一#75
【原文】【記】轉難中，初難。上云「四蘭」，乖《律》文故。答中。初句指出，亦即上文。次句明同。彼明成果，故說四罪。此明中捨，故但有三，據理須四，如下所示。由作法竟，方至果殘。第三法未竟，猶是方便，理須結蘭。
【譯文】【記文】轉入進一步問難中，首先發難。上面說「四個偷蘭遮」，違背了《四分律》原文的緣故。回答當中。第一句指出出處，也就是指前面的引文。第二句說明義理相通。彼論是從成就極果的角度，所以說共有四罪。本律是說明若在中途捨棄邪執，所以只結三個偷蘭遮，但若依常理推究必須算為四個，正如後面所揭示的那樣。因為直到作法全部完畢，才達到最終的果位僧殘罪。第三次羯磨尚未念完時，仍然屬於方便階段，按理應當結偷蘭遮。

【287-0033】02_戒疏/10d_卷三上之一#76
