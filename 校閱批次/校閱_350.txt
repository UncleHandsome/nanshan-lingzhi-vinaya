# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【350-0001】資持記/15a_下三#47
【原文】以觀此身，既假骨毛等緣，和合而成；當知我身，畢竟叵得，是為人空；又了諸緣自體亦空，是為法空。如實了知人法俱空，即破二執，故云最空法也。三中，引論，初明上法。在樹下者，謂雨時也。受下，次明中法。雨歸屋下，與上為異。覆處少損故，得用僧物。四中，十利。
【譯文】因為觀照這個身體，既然是假藉骨肉毛髮等因緣和合而成的；應當知道我們這個身體，終究是不可得的，這就是「人空」；又徹底明了這些因緣本身也是空無自性的，這就是「法空」。如實了知人我與諸法兩者皆空，就能破除我執與法執，所以說是「最空法」。第三段中引用論書，首先說明上等法。在樹下坐，是指下雨的時候。「受」字以下，其次說明中等法。下雨時回到屋簷下，這與上等法不同。屋簷覆蓋之處破損很少，所以允許使用常住僧物。第四段中，有十種利益。

【350-0002】資持記/15a_下三#48
【原文】一無求，二無繫，三無他護，四無所愛；七中二利，益反樹下明之，以樹下猶為風聲棘刺故；八不占他處；九不慮他奪。如來下，引聖所行，令忻樂故。大畏林，亦名恐畏林；寒林，即屍陀林，在王舍城西北十里許，彼國人死，多送林中，名為林葬。
【譯文】五是沒有處所名字（也就是沒有住處的稱號），六是沒有鬥毆諍鬥的事情（因為多無守護之物），七是隨順初受戒時的四依法，八是容易獲得且沒有過失，九是隨順修持道業，十是沒有大眾喧鬧聚集的處所（現在《行事鈔》省略了第五、第六、第九條，涵蓋在「等」字之中；舊時的記註將所愛與受用合併為一條，卻把四依法拆算為四條，誤導他人很久了）。在第十種行持（露地坐）中，第一科，前面先敘述樹下坐有許多過患。「便」字以下，說明露天而坐能帶來甚深的利益。下一個科判。引用《增一阿含經》的觀照方法，以成就前文所說的空定。

【350-0003】資持記/15a_下三#49
【原文】為人觸惱不起意者，示行忍辱，垂誡後來；經云：能行忍者，乃可名為有力大人是也。十一隨坐。謂但無人處即坐，不必樹下露地。《解脫道論》，名遇得處坐；解云：不樂人所貪，不惱他令避故。
【譯文】被人觸怒冒犯卻不起瞋恨心，是顯示行持忍辱，為後世留下垂範警誡；佛經說：能夠實行忍辱的人，才可以被稱為有力量的大人，正是此意。第十一種是隨處坐。意思只要是沒有人的地方就坐下，不一定非要在樹下或露天處。《解脫道論》稱為「遇得處坐」；解釋說：不貪戀別人所貪戀的地方，也不惱亂別人逼令其避讓。

【350-0004】02_戒疏/18c_卷四上之三#75
【原文】【疏】凡在俗常習，婚禮無時。出家學慧，須知俯仰。今不思緣，久住不去，妨彼懷求，迭相逼斥，理非所應，故制。

【350-0005】02_戒疏/18c_卷四上之三#76
【原文】【記】四十三，制意中。初敘俗多染習。「出」下，次明僧不知宜，因而起過。言「逼斥」者，如戒緣中，迦留強坐，其夫與食，累遣不去，夫瞋捨棄：「隨汝所作！」
【譯文】【記文】第四十三條，制戒用意中。開頭先敘述世俗多有愛染之習性。「出家人」以下，次一步說明僧人不知合宜避嫌，因而引發過失。文中所說「逼惱斥責」，正如制戒緣起中，迦留陀夷強行坐著不走，其夫雖供與飲食，但累次遣請他離去仍不走，丈夫憤而捨棄離去說：「隨你想幹什麼就幹什麼吧！」

【350-0006】02_戒疏/18c_卷四上之三#77

【350-0007】02_戒疏/18c_卷四上之三#78

【350-0008】02_戒疏/18c_卷四上之三#79

【350-0010】02_戒疏/18c_卷四上之三#81
【原文】【註】若盲、聾互有，吉羅。不犯者：若食家有寶，舒手及戶處坐；若有二比丘為伴；有識別人，或客人在一處，若不盲聾；或從前過，不住；病發倒地；力勢所持；或被繫；命、梵難故——不犯也。

【350-0013】02_戒疏/18c_卷四上之三#84
【原文】【疏】釋「食」，以男女情相領納，故為食。言「有寶」者，如《多論》解，以著寶衣，輕明照內身，現發欲故。《僧祇》中「俱男、俱女亦不犯」，非食家故。
【譯文】【疏文】解釋「食」字，因男女情識互相領納執取，故稱為食。言「有寶」者，如《薩婆多論》解釋，因婦人穿著寶衣，輕薄明徹透顯內身，容易引發貪欲之故。《僧祇律》說「若全都是男子、或全都是女子亦不犯」，因為不是男女貪愛之食家的緣故。

【350-0014】02_戒疏/18c_卷四上之三#85
【原文】【記】釋中。初明食義。「言」下，次釋有寶，即女人嚴身物也。「僧」下，引文簡濫。辨相注中，「盲、聾互有」，即第四人，各缺一根，非全證故。不犯中，「識別人」者，謂舊相知，對下「客人」，即非舊識。
【譯文】【記文】解釋文句中。首先說明「食」的涵義。「言有寶」以下，次一步解釋有寶，即是女人盛裝嚴身之物。「僧祇」以下，引律文簡別濫用。辨相隨文註解中提到「盲、聾互有」，是指在場充當第四人的作伴者，各自存在著感官機能的缺陷（或盲或聾），不能作為合格的見證人，因此比丘仍結犯突吉羅罪。不犯條文中所謂「識別人」，是指舊相識之明理者，與下文的「客人」相對，客人即非舊識。

【350-0022】03_業疏/20a_卷四之三#118
【原文】三中，《多論》明佛安居。初示異。「以」下顯意有二：初明不從他。私釋：佛僧位別，不可以僧為對；小教秪談一佛，無可對故。四無畏者：一一切智無所畏，二漏盡無所畏，三說障道無所畏，四說盡苦道無所畏。「又」下二明不三說。「餘」下雙結，則知凡下竝須依人
【譯文】在第三部分中，《薩婆多毘尼毘婆沙》闡明佛陀的安居。首先指明其特殊不同之處。「以」字以下，顯明其中的用意有二：第一、說明不依從他人作安居。個人私下解釋：佛寶與僧寶位階有別，不能以比丘僧作為對首；且小乘教法只談一位佛出世，沒有其他佛可以作為對首。所謂四無畏是指：一、一切智無所畏；二、漏盡無所畏；三、說障道法無所畏；四、說盡苦道無所畏。「又」字以下，第二、說明不需要說三遍。「餘」字以下，作雙重的結斷，便可知凡夫位及餘人全都必須依附對首之人。

【350-0032】資持記/15d_下三#43
【原文】第十，《母論》五節，初作門師法。五中，第三所應，餘四不應；四中，第二非利他，餘三防媟慢。又下，令他尊敬法。五中，二是下賤；附近權豪，為他走使；四是邪命，餘三並避嫌疑。竊語，謂低聲不公顯也。入下，入俗威儀法。攝諸根者，欲境多故。有下，不宜久住法。
【譯文】第十段內容中，《毘尼母論》分為五個節段，首先是「為世俗人家作門師」的法規。在五件事中，只有第三件是應當做的，其餘四件皆不應為；在不應做的四件事中，第二件（不繫心貪利）並非關乎外在利他，其餘三件則是為了防範輕浮褻慢。「又下」是令他人心生尊敬的法規。五件事中，第二件是自甘下賤；攀附權貴豪門，甘充信差為他人奔走服役；第四件屬於不正當的邪命，其餘三件全都是為了避免招惹世人嫌疑。「竊語」是指交頭接耳、聲音低微不敢公開表露。「入下」是進入俗人家中的威儀規範。之所以要攝受收斂六根，是因為世俗五欲境界繁多混雜。「有下」是不宜在俗人家久留的法規。

【350-0033】資持記/15d_下三#44
【原文】九事，前四輕人，五是慢法，六即無信，餘三慳鄙。如市易者，希還報故。若入下，離過用心法，初示法。如下，喻顯。高山臨淵，喻卑恭攝心；月行動手，喻不著六塵。十一中，《十誦》，初教善說。諸法實相，言通大小；且據小教，即指偏空。此下，令訶止。當觀是非，勿隨好惡。又下，聽演布。
【譯文】九種情境中，前四種是輕蔑慢待出家人，第五種是褻慢正法，第六種是缺乏正信，其餘三種則是慳吝鄙陋。所謂「如同在市場交易」，是指對方供養只希望換取現世的回報利潤。「若入下」是遠離過失時的用心法則，首先提示具體方法。「如下」運用生動的比喻加以彰顯。猶如「身處高山俯臨深淵」，比喻應當謙卑恭敬、嚴格攝伏其心；「明月在空運轉而清風動手」，比喻六根歷經六塵境界而絲毫不生貪愛染著。第十一段中，《十誦律》首先教導應當善於說法。「諸法實相」一詞通貫大乘與小乘；若且就小乘教法而言，指的就是偏真偏空之理。「此下」命令說法者應及時喝止錯誤。應當客觀審察是非對錯，不可隨順個人好惡而行。「又下」聽許可以演繹開布法義。
