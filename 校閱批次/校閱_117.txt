# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【117-0001】02_戒疏/05b_卷二上之一#66
【原文】【記】引教中，《僧祇》，初引文。彼宗戒本，四重戒後，各標時節。四戒間年，俱是「冬分」，即八月十六至十二月十五，共有八箇半月，對數可見。言「人影」者，彼約人身，量日中影，以定早晚。晨朝西影，初長後短，午後東影，從短漸長。即以人身為度，計有幾影；不及全半身者，則步之以脚；不及脚者，即加之以指。文中比對此方日月，並疏家之言，疑本是注。「若」下，示次第。
【譯文】【記文】引用教證的段落中。《僧祇律》的部分，首先引用律文。該宗的戒本在四條根本重戒之後，都分別標明了制戒的時節。四戒制定年份雖然不同，但全都在「冬分」，也就是八月十六日到十二月十五日之間，總共有八個半月，對照數字便可以看清。所謂「人影」，是該律依照人體的身長來測量正午日光照射下的影子，以此來判定時間的早晚。早晨西邊的影子最初極長、隨後漸短；午後東邊的影子則由短漸漸變長。這就是以人身的長度為標準，計算有幾個身高的影長；如果不足整個或半個人身長度的，就用腳步來丈量；不足一腳長度的，就再用手指的寬度來補足。文中將其折算為此土的月日時間，全都是律疏作者的考訂之語，懷疑原本是夾注之文。「如果按照」以下，說明前後次第的結論。

【117-0002】02_戒疏/05b_卷二上之一#67
【原文】【疏】又《智論》云：「婬法不惱眾生，心心繫縛，故為大罪，律中初也。」
【譯文】【疏文】此外《大智度論》說：「行淫之法表面上並不侵惱損害其他眾生，然而卻會使自己的心心念念都被牢牢繫縛，所以是大罪過，在律典中被排在首位。」

【117-0003】02_戒疏/05b_卷二上之一#68
【原文】【記】次《智論》中。彼列十業，殺惱眾生，合標戒首，婬無所惱，不應在初，故《論》釋之，方知有以。又云：「比丘之法，今世取涅槃故。」準前《僧祇》約制緣次第，《智論》據障道重輕，兼前人解，總為四釋。《僧祇》從緣，事雖的實，不妨為表前後諸意，故使緣發次第冥符。
【譯文】【記文】次《智論》中。該論列出十惡業，殺生侵惱損害眾生，理應標立在諸戒之首；行淫並無侵惱對象，按理不該排在最初，所以該《論》特別對此作了解釋，由此才明白其中確實有深厚的緣由。該論又說：「比丘的修行法則，是為了在這一生獲取涅槃解脫的緣故。」依照前文《僧祇律》是根據制定戒律的事緣先後來論述，《大智度論》則是根據阻礙聖道的輕重深淺來立論，再加上前面古德的解釋，總共有四種解釋。《僧祇律》依據事緣由來，事情雖然確鑿真實，但也不妨礙這本身就是為了彰顯前後各種深遠的意旨，從而使事緣發生的先後次第與這些義理暗暗相合。

【117-0004】02_戒疏/05b_卷二上之一#69
【原文】【疏】問：「同是出家，法不異故，有何三眾，與僧不同？」
【譯文】【疏文】問：「同樣都是出家修行，戒法在自性上並無差別，為什麼沙彌等三眾的戒律，排列次序會與比丘僧不同呢？」

【117-0005】02_戒疏/05b_卷二上之一#70
【原文】【疏】解云：「下眾前五，猶本俗戒。後之五者，出家增之。」
【譯文】【疏文】答：「下三眾戒法中的前五條，依然沿襲自原本的世俗五戒；後面的五條，才是出家人所增設的。」

【117-0006】02_戒疏/05b_卷二上之一#71
【原文】【記】問答中。初問。沙彌十戒，以殺戒居初，式叉雖加六法，還即十戒為體，所以問詞通標「三眾」。答中。即約先五次十相由之義，仍依前相，故云「後增」。非謂十戒，道俗兩別。應知增五為十，並是「出家」。增十為具，俱成大戒。
【譯文】【記文】問答的段落中。首先提問。沙彌十戒是以殺生戒排在最初，式叉摩那雖然增加了六法，本體依然還是這十戒，所以問話中通括標指「三眾」。回答中，就是依據先有五戒、後增為十戒的前後因由之義，依然依循原本五戒的相狀，所以說「出家人增設」。這並不是說十戒在出家與世俗兩處有什麼本體上的不同。應當知道由五戒增為十戒，全都是「出家」的法度；由十戒增受具足戒，全都成就了出家的大戒。

【117-0009】02_戒疏/05b_卷二上之一#74
【原文】【疏】答：「出家所為，要斷煩惱，道分所障，勿過於欲，故婬在初。俗不修道，斷婬非分，畜妻行福，不妨世善。或求慈行，有懷殺害，故偏制約，以全斷故。」
【譯文】【疏文】答：「出家的根本宗旨，主要在於徹底斷除煩惱；而對修行證道障礙最大的，莫過於淫欲，所以淫戒排在第一。世俗之人不以修行得道為期許，要他們全斷淫欲並非本分之事；蓄養妻子、修積福德，並不妨礙世間的善法。但世俗人在行慈悲時，往往容易懷有殺害生靈之心，所以特別加以限制約束，要求其徹底斷除殺生。」

【117-0010】02_戒疏/05b_卷二上之一#75
【原文】【記】答中。大約道俗別修，僧修智分，俗修福分。婬欲障智妨道，故僧祇前標；殺害傷慈損福，故俗戒初列。文中，前明僧戒，後明俗戒。又二，初明婬後，「或」下，次明殺先。
【譯文】【記文】回答的段落中。大致上出家與世俗所修習的重點有別：僧眾專修智慧分，世俗專修福德分。淫欲會障礙智慧、妨害聖道，所以僧戒在最初標出；殺害會傷損慈悲、折損福德，所以俗戒在第一位列出。文中前面說明僧戒，後面說明俗戒。後段又分兩層：先說明為什麼把淫戒放在後面，「但世俗人」以下接著說明為什麼把殺戒放在最前。

【117-0014】02_戒疏/05b_卷二上之一#79
【原文】【記】初釋。上句，明同俗。五、十兩戒，竝具戒「方便」故。下明異僧。纔霑有願，故云「少分」。

【117-0015】02_戒疏/05b_卷二上之一#80
【原文】【疏】有人言：「年小惑微，婬惱未發，不妨無慈，故殺在初。」
【譯文】【疏文】有人說：「年紀幼小而煩惱輕微，淫欲與惱亂尚未萌發，但心裡卻不妨礙缺乏慈悲心，所以把殺生戒放在最初。」

【117-0016】02_戒疏/05b_卷二上之一#81
【原文】【記】次釋。以沙彌七歲驅烏，十四應法，年在童稚，故婬未發。癡騃無知，故多好殺。翻名「息慈」，亦由於此。
【譯文】【記文】第二種解釋。因為沙彌七歲就可出家做驅烏沙彌，十四歲即為應法沙彌，年紀還在孩童階段，所以淫欲尚未萌發；但童稚愚癡無知，往往喜好殺生虐物。沙彌翻譯為「息慈」，也就是息滅世俗的惡行並長養慈悲，其名稱也是因這層緣由而來的。

【117-0025】02_戒疏/05b_卷二上之一#90
【原文】【疏】十、明沙彌任運義門。
【譯文】【疏文】第十門、辨明沙彌在不知不覺中自然成犯根本重罪的義理（任運義門）。

【117-0026】02_戒疏/05b_卷二上之一#91
【原文】【記】第十，標中。謂沙彌時，先作破重方便，及後受具，正作法時，前事成遂，三性冥犯，故云「任運」。此即前門教他之義。三戒可犯，婬非所論。
【譯文】【記文】第十門，標題的段落中。是指在做沙彌的時候，預先造作了毀犯重戒的前行方便，等到後來登壇受具足戒、正當羯磨法成就的剎那，先前所造作的惡事恰好圓滿完成，善、惡、無記這三性心都在冥冥不知不覺中觸犯了重戒，所以稱為「任運」。這也就是前面一門中所說教唆他人的情況。殺、盜、妄三戒都可能這樣違犯，淫戒則不在這種情況之列。

【117-0027】02_戒疏/05b_卷二上之一#92
【原文】【疏】言「任運」者，謂自造惡，方便未就，後更造善，由惡障福，不得成就。然經律中出相不定。
【譯文】【疏文】所謂「自然成犯（任運）」，是指自己造作惡業時，前行方便尚未完成，後來轉而造作善業，但由於先前的惡業障礙了善福，導致善業無法圓滿成就。然而經論中對這種相狀的判定並不一致。

【117-0028】02_戒疏/05b_卷二上之一#93
【原文】【記】汎明中，且引經論，通明造業。初科。前釋名義。造善感惡，即是「任運」。「障福」、「不成」者，此中且約前惡強長，立有任運，故云「障福」。至後正義，自有別判。「然」下，示不定，即如下引。
【譯文】【記文】泛論的段落中，暫且引用經論，通泛闡明造業的法則。第一個科判。首先解釋名稱與義理。造善反而感召惡果，這就是「任運」。「障礙善福」、「無法成就」，這裡暫且是依據前面的惡業強大且持久、成立有自然感犯的觀點，所以說是「障礙善福」；等到後文的正統義理中，自然會有另外的判定。「然而」以下，指出經論記載並不一致，正如後文所引用的內容。

【117-0033】02_戒疏/05b_卷二上之一#98
【原文】【疏】解言：「此約貴人常勅殺戮，義同惡戒。以惡強時長，後受齊者雖曰善戒，時短弱故，為惡所障故不得齊。不同前段，暫惡短弱，不能遮齋。以此而推，惡強長者，則有任運，短者則無。」
【譯文】【疏文】解釋說：「這段話是針對位高權貴之人常常下令殺戮而言，這種情況在義理上等同於惡律儀戒。因為惡業勢力強大且時間長久，後來雖然受持了齋戒，即便稱為善戒，但由於時間短暫且勢力微弱，被強大的惡業所障礙，所以得不到齋戒。這不同於前一段所說的，只是暫時起惡、勢力短淺微弱，因此無法阻擋受持齋戒。由此推論，惡業強大持久的，就會有自然障戒成犯的事；惡業短淺微弱的，則沒有這回事。」
