# 校閱材料　第283檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【283-0001】資持記/10a_中三下#56
【原文】《僧祇》、《伽論》約色，《五分》據味。五中。流汗有同鹹水，故亦須受。注中，上句決上臂汗，下句例成額汗。六中，《僧祇》。楊枝分咽不咽，氷雪約人有無。《四分》。楊枝不分兩用，故令準上。明轉變中。下列諸物，雖有變動，不易本質，故皆不失受。
【譯文】《僧祇律》、《薩婆多論》是就顏色而論，《五分律》是依據味道而論。第五部分中。流下的汗水等同於鹹水，所以也必須受取。注文中，上一句決斷了上面所說手臂上的汗，下一句依此類推額頭上的汗。第六部分中，《僧祇律》。楊枝分為吞嚥與不吞嚥兩種情況，冰雪依據身邊有沒有人來決定。《四分律》中。楊枝不分這兩種用途，所以令其依照上面處理。在說明性質轉變中。下列各類物品，雖然形態發生變動，但沒有改變原本的質地，所以都沒有失去受持。

【283-0002】資持記/10a_中三下#57
【原文】《善見》生薑生牙，但須重淨。《僧祇》。注文，即指律中阿難為佛溫飯之緣。酪酥等者，謂中前受酪蔗麻，欲中後作酥蜜油，須加記識法云：此中淨物生，我當作七日藥受。〔非時亦同。〕過中變造，俱不失受。五十。空中不成，謂能受在空；若論所對在空，亦應不成；故知能所俱須在地。
【譯文】《善見律》中生薑發芽，只需要重新作火淨。《僧祇律》。注文就是指律文中阿難為佛熱飯的緣起。酪和酥等，是指在正午前接受了酪、甘蔗、胡麻，想在正午後做成酥、蜜、油，必須加上標記作法說：「這些乾淨物品產生時，我要當作七日藥來受取。」〔非時藥也是如此。〕過午之後轉變製造，都不會失去受持。第五受處中。在空中不能成立受食，是指能接受的人在空中；如果要論所面對的人在空中，也應當不能成立；由此可知接受者和給予者都必須在地上。

【283-0003】資持記/10a_中三下#58
【原文】如前即指第二門。六受法中，初科。《了論》三位可解。今時就盤取食，準至物邊，理應成受。二身心中四句，初句。非心成受者，雖非專緣食境，必須心境分明。一向無心，則不成受。第二句，初示相。毘尼下，引緣。彼因毘舍離穀貴，神足比丘往外國乞；彼嫌比丘等，如鈔所引。若下，顯異。
【譯文】如同前面就是指第二門。在六種受食法則中，第一個段落。《了論》的三個位置容易理解。現在來到盤子前取用食物，依照到達物品邊上的說法，在義理上應當成立受食。第二是身體與心靈的四句分別，第一句。不是用心而成立受食，是指雖然不是專心注視食物之境，但必須心靈與外境分明。如果一味無心，就不能成立受食。第二句，首先指出相狀。從「毘尼」以下，引用緣起。那是因為毘舍離城糧食昂貴，有神通的比丘到外國去乞食；外國人嫌棄比丘等等，如同《行事鈔》所引用的。從「若」以下，顯明不同。

【283-0004】資持記/10a_中三下#59
【原文】口加如後。第三。平等，謂正意仰手而受。上明如法。若下，簡非法。身心雖等，違法不成。第四。先有方便，故開後成。關即涉也。三單心者。即前第二句。前對身心歷句，此中獨約心論。《僧祇》中，初引邪見緣。彼因登瞿國是邊地邪見；嫌比丘故，不親授食。當下應有作字。
【譯文】口中附加作法如同後文所說。第三句。平等，是指心存正念、仰手接受。上面說明合乎戒法。從「若」以下，甄別不合戒法。身體與心靈雖然齊等，但違背戒法則不能成立。第四句。因為先前有了方便作法，所以開許後來成立。「關」就是牽涉。第三種是純粹用心。就是前面的第二句。前面是把身體與心靈結合起來逐句列出，這裡唯獨就心靈來論斷。《僧祇律》中，首先引用邪見的因緣。那是由於登瞿國是邊地邪見之處；嫌棄比丘的緣故，不肯親手遞送食物。「當」字下面應當有一個「作」字。

【283-0005】資持記/10a_中三下#60
【原文】滿茶邏，此云壇規圓也。口云三受，以替手法。前下，指實器緣。畜寶所引，亦《僧祇》文。彼因施主作金椀盛食；比丘以手示器，口加三受等。明下，指略。即彼二部，皆開口受。又中邊不相解語，亦同開之。《五分》。施主送食，未及授與，急緣置地，應加口法。《僧祇》。禪眠，彼云覺者成受；
【譯文】滿茶邏，這裡翻譯為壇場，取其規律圓整。口中說三次「接受」，用來替代手的動作。從「前」以下，指向以實體器皿受取的因緣。在蓄積寶物處所引用的，也是《僧祇律》的文字。那是因為施主造了金碗盛裝食物；比丘用手指給他看器具，口中附加三次「接受」等等。從「明」以下，指出簡略作法。就是指那兩部律，都開許口頭受食。另外中原與邊地言語不通，也同樣開許口受。《五分律》。施主送來食物，還沒來得及授予，因為緊急因緣放在地上，應當附加口頭法事。《僧祇律》。坐禪昏睡，該律說醒著的人算受食成功；

【283-0006】資持記/10a_中三下#61
【原文】若不覺者，覺持欲食，當從淨人更受；若不欲食等，如鈔引。得自捉者，以非自噉，故無惡捉。四中，《僧祇》，初明繩連。彼因蘭若比丘入井抒水，時到，恐水還滿，就井中食，令淨人盛食器中，繩繫懸下；比丘一手挽繩，一手承之，作言受受。非儀犯吉。乃至下，明遙擲。《善見》下，會異。《四分》。
【譯文】如果不省人事，醒來拿著想要吃，應當跟從淨人重新受取；如果不想吃等等，如同《行事鈔》所引用。可以自己拿著，因為不是自己要吃，所以不算犯惡捉（惡觸）之罪。第四部分中，《僧祇律》首先說明繩索相連。那是由於阿蘭若比丘進到井裡汲水，進食時間到了，擔心水又滿上來，就在井中進食，讓淨人把食物盛在器具中，用繩子繫著垂放下去；比丘一手拉著繩子，一手承接，口中說「受、受」。這樣不合威儀要犯突吉羅罪。從「乃至」以下，說明遠處投擲。從「《善見》」以下，調和會通不同說法。《四分律》說。

【283-0007】資持記/10a_中三下#62
【原文】遙擲成受，須約能所同知無礙。三《僧祇》中，初明懸下。即向所引。若下，明引上。捍音汗，護也。《十誦》。雖不絕者，謂初出瓶，未落鉢中者。《僧祇》文四段，初明淨人行受。懸放恐觸器故。即去謂即時迸去者。注文釋上墮草。踞坐謂兩足路地。準〈赴請篇〉，食須踞坐。
【譯文】遠處投擲成立受食，必須約定為給予者和接受者雙方都明白知曉且毫無阻礙。第三《僧祇律》中，首先說明向下懸垂食物，就是剛才所引用的。從「若」以下，說明向上提拉。「捍」字音汗，是防護的意思。《十誦律》中，流柱雖未斷絕仍算成立受食，是指油液剛倒出瓶口、尚未落入缽中的狀態。《僧祇律》文分為四段，首先說明淨人分派食物時的受法。懸空放下是唯恐碰觸到食器具。所謂「即去」，是指掉落後隨即彈跳滾開的食物。注文是解釋上面的果實落在草上。蹲坐（踞坐）是指雙足踩地而蹲。依照〈赴請篇〉的規範，用齋時必須蹲坐。

【283-0008】資持記/10b_中三下#1
【原文】《三千威儀》云：諸佛法皆著淨衣踞坐而食；若有出家弟子，應如是法；以能防眾戒故，為淨衣故，異俗法故，因制踞坐法，廣如後引。此土跏坐受食，隨方所宜，非教所許。若淨人下，明比丘受行，初示緣開。若下，明就地受，又二，初明物重法。稍稍猶言略略。若下，明器熱法。五中。
【譯文】《三千威儀經》說：諸佛的律法都是穿著整齊乾淨的衣服，蹲踞而坐進食；如果有出家弟子，也應當遵循這樣的法則；因為這能防護諸多戒律、能保持法衣潔淨、能有別於世俗習俗，因此制定了蹲踞坐進食之法，詳細內容如後文所引。此方漢地盤腿結跏趺坐受食，只是順應地方風土習俗的權宜，並非佛陀聖教所明文認許。原文「若淨人」以下，說明比丘接受食物與行食的規則，開頭先說明因緣而特許的開緣。「若」字以下，說明就地接受食物，又分為兩部分，首先說明食物過重時的受法。「稍稍」的意思就是略微、稍微。「若」字以下，說明盛器過於燙熱時的受法。在五種情況當中。

【283-0009】資持記/10b_中三下#2
【原文】淨人三法：一火淨，二別藥體，三施心授與。比丘三法：一仰手受，二或加記識，三分體分。七過：一內宿，二內煮，三自煮，四惡觸，五殘宿，六未手受，七受已停過須臾。準下，更有手受已變動，謂之八患。六中。言非心者，由不對境，直爾自取，故無受心。如上，即《僧祇》、《多論》取石上故食。
【譯文】淨人受持食法有三條規則：一是火淨，二是辨識藥物類別，三是以布施之心授與比丘。比丘受食亦有三條規則：一是仰手承接，二是或者加以辨識標記，三是分取各自應得的份額。藏食與受食有七種過失：一是留宿在住處內，二是於住處內自煮，三是親自烹煮，四是惡劣的觸染碰觸，五是隔夜殘食，六是未經親手受納，七是接受之後停留超過須臾片刻。依照後文所說，若再加上親手受納後又有挪移變動，便合稱為八種患過。在第六種情況中。所謂「並非存心」，是因為沒有面對授與的情境，只是徑自拿取，所以沒有領受的心念。如上文所述，就是指《僧祇律》與《薩婆多論》中所載，自取石上陳舊殘食的例子。

【283-0010】資持記/10b_中三下#3
【原文】儉開即本宗八事。七食觀中。一觀外食二事，上句念種作，下句思施意。二觀己行全多缺減。下三並觀現心，三即離過心，上食多貪，下食多瞋，中食多癡；離此三心，乃可進口。四即對治心，言正事者，謂更無宅意；
【譯文】因饑荒而開許的特例，就是本宗所開的八種應急之法。在第七門食觀中。第一是觀想外在食物的兩件事，上句是感念農民耕耘種植的辛勞，下句是思維施主布施的善意。第二是反觀自己修行的德行是圓滿、多備還是有所殘缺短少。以下三種都是觀照當下的心念，第三即是遠離過失的心，面對上等美食容易生起貪心，面對下劣粗食容易生起瞋心，面對中等平常之食容易生起愚癡之心；必須遠離這三種煩惱心，才可以入口進食。第四即是對治疾病的心，所謂「正事」，是指再無其他的居家欲樂雜念；

【譯文】在顯發旨趣（顯意）的科判中，開頭先說明重複宣說的用意。「不爾」以下，是鄭重提出誡勉。「毘尼」以下，是引用經律作為證明。吃每一口、入房每一步（飲食與入房時時作念），受用絕非僅在短暫的片刻；衣食住藥這四事都應當通盤作此觀想，絕非單指飲食一項。所謂「若不如此」，彼處論典說道：接受他人的信施供養，若不能如法受用，放任自己的心念貪逸，荒廢修持道業，將來必墮入三惡道中遭受重大的痛苦；即便現世不受慘烈的苦報，隨意噉食他人信施，食物也會化為破腹而出的鐵丸，衣服則會化為烈火纏身脫離軀體等等。在第八項中，第一科列出《四分律》的十種受食法，前五種。依據手與物體的接觸情況互相組合為四句。
