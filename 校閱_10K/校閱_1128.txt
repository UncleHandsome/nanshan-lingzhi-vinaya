# 校閱材料　第1128檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1128-0001】資持記/08a_中二#29
【原文】三同前者，索而不歎，即屬麁語。不犯中。且列二相。《注戒》更開錯說。第五。〔佛在羅閱祇，迦羅比丘善知俗法，與俗為媒，招譏故制。〕名標人者，簡餘類故。疏云：媒，謀也；計度二姓，用為好合。犯中，釋第六文有五節；一約三時具缺，辨犯差降。具三可知。具二，謂受往而不報。
【譯文】第三種與前戒相同者，如果只索取供養而不讚歎自身，那就屬於前一條的說麁惡語罪。在不犯的狀況中，暫且列出兩種相狀。《注戒》中另外還開許了口誤說錯話的情形。第五條戒（指作媒人戒）。〔佛陀在羅閱祇城時，迦羅比丘精通世俗禮法，替在家人穿針引線做媒，招致社會譏嫌嘲諷，佛陀因此制戒。〕在戒名中特別標明對象是「男女之人」，是為了區別其他的物類。《戒疏》說：所謂媒，就是謀劃的意思；在男女兩家姓氏之間思量計謀，促成雙方的結合成親。在犯相中，解釋第六個犯緣的文字共有五個段落：第一是就「受託、前往、回報」這三個時程的具備與缺損，來辨別結罪的輕重差降。具備三者犯重罪是可以明瞭的。具備兩者，是指接受了委託並前往傳話，但還沒有回報。

【1128-0002】資持記/08a_中二#30
【原文】具一，即受而不往。若受下，二明四種緣差，三輕一重。注顯後一，由女尚存，病容差故。除下，三明非正道。問：女有三道，但除二者？答：口雖通淫，非本媒意；縱有，亦屬餘身分耳。若媒下，四簡異報也。《五分》下，五明事不成也。釋第三中，初文。不能男女，即二種黃門；
【譯文】只具備一者，就是接受了委託卻還沒有前往交涉。「若受」以下，第二段說明四種因緣差錯的狀況，三種情節較輕，一種情節較重。注文中特別顯露出最後一種，是由於女方依然活著，疾病還有痊癒的可能。「除」字以下，第三段說明撮合非男女生殖之正道的情況。有人問：女人有三道，為什麼只排除其中兩道？回答：口腔雖然也能通行淫欲，但根本不是作媒撮合結合的本意；縱然有這種苟合，也屬於觸犯其餘身體部位的範疇。自「若媒」以下文句，第四段是揀選排除了非人類等不同果報的對象。《五分律》「以下」，第五段說明婚事最終沒有撮合成辦的情況。在解釋第三個緣中，第一段文字。所謂「不能男女」，就是指兩種黃門（無性徵或性發育不全者）；

【1128-0003】資持記/08a_中二#31
【原文】或彼此互是，或二俱是，竝同下犯。下列二女，道合一道是一種〔舊分二女，非也。〕；石女者，根不通涶者，羯磨列遮云：二道合、道小，即同此矣。次科，先引律緣。一切殘者，盡界同犯也。今下準斥非法。雖不羯磨，白眾同情故。若下，因責盜用，非此犯相。三中。
【譯文】或者是男女雙方有一方如此，或者雙方都是如此，都同樣依照下文結較輕的罪。下文列出兩種女性缺陷，陰道與便道相通合成一道的算是一種〔過去分成兩種女人，是不對的〕；石女是指生殖通道天生閉塞不通的女人，在羯磨作法中列出的遮難說：「兩道相合、通道過小」，就屬於這類情形。下一段科判，先引用律文中的犯罪因緣。所謂「一切皆犯僧殘」，是指全結界內的所有僧人都共同犯下僧殘重罪。現在「以下」這句話，是依律呵責這種非法作法。雖然沒有進行羯磨白告，但向大眾白告且心意相符容隱。如果「以下」，是順便斥責侵吞挪用僧物，並不是本戒所要論斷的犯相。在第三部分中。

【1128-0004】資持記/08a_中二#32
【原文】好馬勝於餘畜，故罪分二品。今世愚僧多畜猫狗，求合雌雄，一一吉罪。制急過重，知者誡之。第四中。恐後合者，以男女類殊，聚必相染故。五中，《十誦》二相。指腹者未生而媒。古記，準俗算法，預占胎中男女；學者無知，便對俗女輪珠計數，以為己能。且無學射事，尚致俗譏；
【譯文】良馬比其餘的牲畜更加珍貴，所以促其交配的罪名分為兩種品級。當今世上許多愚痴的比丘飼養貓狗，想方設法撮合公母交配，每一次都要結突吉羅罪。戒律制定得如此嚴格，罪過極為沉重，明白道理的人應當深加警惕戒懼。在第四部分中，唯恐日後苟合，是因為男女本質不同，長時間聚集在一處必然會相互染著。在第五部分中，《十誦律》列出兩種相狀。所謂「指腹為婚」，是指小孩還未出生就替其作媒。古代的筆記中，記載有人依照世俗的命理算法，預先推算孕婦腹中的胎兒是男是女；學者如果無知，便在世俗女人面前轉動念珠推算計數，自以為很有能耐。況且無學聖人占測胎兒男女之事，尚且招致世俗人的譏嫌；

【1128-0005】資持記/08a_中二#33
【原文】何況盲愚，復憑世術。高達有恥，聞而革之。《四分》中，初列四法。律有五種，此闕現相；疏云：若使及書，言中自了；指印現相，必假言通等。言指印者，舊云：手墨印紙，約橫竪文以表其意；或云：西人指上貫印，持以為信；然無所據，未知孰是。參互作句者，律以五法，歷於三時，交絡作句；
【譯文】更何況愚昧盲目之人，竟然還憑藉世俗的江湖術數自誇。品行高尚且有知恥之心的人，聽聞這些道理後應當痛加革除。《四分律》中，首先列出四種媒介的方法。律典中本有五種方法，這裡缺少了「現相」（以動作暗示）這一種；《戒疏》說：如果派遣使者以及遞送書信，言詞當中自然表達明瞭；指甲印模和肢體動作，必須藉由言語通達輔助等等。所謂「指印」，過去的說法是：在紙上按上手印，藉由指紋橫豎的走向紋路來表達意思；另一種說法是：西方外國人在手指上套著印章，以此作為憑信；然而這些說法都缺乏確切依據，不知哪一種才是正確的。所謂「交錯搭配作成文句」，是指律典用這五種媒介方法，歷經受託、前往、回報這三個時程，彼此交錯連結而寫成文句；

【1128-0006】資持記/08a_中二#34
【原文】今略引示：〔先以遣使傳語參自作為四句〕一自受語自往自還，二自受語自往遣使報，三自受語遣使往自還報，四自受語遣使往遣使報。〔次以遣使持書參自作為四句〕一自受語自作書往自持書報，二自受語自作書往遣使持書報，三自受語遣使持書往自持書報，四自受語遣使持書往遣使持書報；
【譯文】現在簡略引述如下：〔首先以「派遣使者傳話」與「親自傳話」交錯搭配作成四句〕第一是自己接受囑託、自己前往、自己返回回報；第二是自己接受囑託、自己前往、派遣使者回報；第三是自己接受囑託、派遣使者前往、自己返回回報；第四是自己接受囑託、派遣使者前往、派遣使者回報。〔接著以「派遣使者送信」與「親自送信」交錯搭配作成四句〕第一是自己接受囑託、自己寫信親自送去、自己持信返回回報；第二是自己接受囑託、自己寫信親自送去、派遣使者持信回報；第三是自己接受囑託、派遣使者持信送去、自己持信返回回報；第四是自己接受囑託、派遣使者持信送去、派遣使者持信回報；

【1128-0007】資持記/08a_中二#35
【原文】指印現相各四句亦如是〔竝法上持書參之〕；餘句廣在律文，不復繁引。無問交參，但使三時具者，一切皆殘；具二皆蘭，具一竝吉；則不勞作句，無不通達。若下，因制二事非道所宜。事通一切，不局媒嫁。文制不看，看知可不，容有開持；如不犯所明。六中。雖本夫婦，有同媒故。
【譯文】指印與現相也各自依此法各有四句〔全都是仿照上面持信的方式相互參照〕；其餘的文句廣泛記載在律文之中，這裡不再繁瑣引述。不論如何交錯搭配，只要完整具備了三個時程，一切都犯僧殘重罪；如果只具備兩個時程，全都結偷蘭遮罪；只具備一個時程，全部結突吉羅罪；那麼就不必大費周章地去列出每一句，也能通達所有的罪相了。「若」字以下，是順帶制止兩件不合出家人身分的事情。這些事情通於一切世間事物，並不局限在媒聘婚嫁。律文禁止不看信件內容就代為送往，但若看過信件知道是否如法，便容許開許代持；正如不犯條款中所闡明的。在第六條中，即使原本就是一對夫妻，幫其撮合重聚也等同於做媒。
