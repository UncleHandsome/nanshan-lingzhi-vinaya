# 校閱材料　第511檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【511-0001】02_戒疏/08b_卷二下之一#17
【原文】【記】三中。初示懺業，上二句判定可懺。「大乘」即《佛名》、《方等》，通懺三世十惡五逆。又鴦掘摩羅作五逆，因值佛得滅等。「若」下，引難。「經」即《涅槃》。上據大乘立義，故還引大乘為難。闍王殺父，阿鼻一劫，佛令懺已，於黑繩地獄，七日受盡。既但轉重令微，則顯逆非可懺。答中二意。初引彼經。有無不定，約心明業，雖悔復受，理無所疑。「或」下，示次意。既轉令輕，明開成悔。「餘」下，次明懺制。初判定，「學悔」下，引證。初證懺夷，《律》令「學悔」，開懺不疑。「《十》」下，次證悔蘭。邪正各五，方成破僧，真佛位別，不入僧數，故云「九人」。邪徒破僧，皆犯蘭罪，今既邪正通名「清淨」，故知開悔。「從僧懺」者，上品罪故。
【譯文】【記文】在第三科中。首先揭示懺悔業障之理，前面兩句直接判定是可以懺悔的。「大乘」就是指《佛名經》、《方等陀羅尼經》，普遍開許懺悔三世以來的十惡五逆重罪。又如鴦掘摩羅造作五逆罪，因為值遇佛陀而得以滅罪獲證果位等。從「若爾」往下，引來問難。「經」就是指《大般涅槃經》。上面是依據大乘來立論，所以又引大乘經文作為問難。阿闍世王殺父，本應墮阿鼻地獄受苦一劫，佛陀令其懺悔之後，改在黑繩地獄受苦七日便告了結。既然只是將重罪轉為微薄，就顯明逆罪不是徹底可以完全懺除的。回答中包含兩層意思。首先引用該經經文。罪業的有與無並非固定不變，是依據內心的轉變來明辨業果，雖然懺悔之後仍須承受輕微報應，這在因果法理上沒有什麼值得懷疑的。從「或可」往下，指出第二層意思。既然能將重報轉得極輕，正顯明開許成立懺悔之義。從「餘之三夷」往下，接著說明戒律上制罪的懺悔。首先判定可以滅除，從「學悔」往下，引經據典作為證明。首先證實夷罪的懺除，《四分律》規定要行「學悔」法，可見開許懺悔毫無疑義。從「《十誦》」往下，接著證實偷蘭遮罪的懺悔。邪僧與正僧各五人，破僧的惡事才能成立，真正的佛陀果位特殊，不列入一般僧數之中，所以稱為「九人」。跟隨邪師破僧的同黨，都結犯偷蘭遮罪，現在律文既然將邪派與正派僧人都通稱為「清淨人」，由此可知開許懺悔。「向僧眾懺悔」的意思，是因為這屬於上品重罪的緣故。

【譯文】【疏文】第三科、說明造作逆罪的業相。

【511-0003】02_戒疏/08b_卷二下之一#19
【原文】【疏】破僧是口業，餘四是身業。若互作者，有語助成。若論破僧，身現不得，必須言說，用化前人。能破是口不善業，所破是不和合性。
【譯文】【疏文】破僧屬於口業，其餘四種屬於身業。如果互相造作，也是藉由語言幫助促成。若單論破僧，只在身體上顯現是不能成就的，必須透過語言宣說，用來教化影響對方。能造破僧的是口部不善業，所破（僧破）之體性則是不和合性。

【511-0004】02_戒疏/08b_卷二下之一#20
【原文】【記】業相中，初科，又二。初明各造。《俱舍頌》云：「此五無間中，四身一語業；三殺一誑語，一殺生加行。」「若」下，次明互造。上明口兼身四，「若論」下，次明身不兼口。文中「能」、「所」對明。「所」無別體，即是事、理二種不和，故指為「性」。「性」，即體也。
【譯文】【記文】在業相中，這是第一小科，又分為兩部分。首先說明各自造作。《俱舍論》頌文說：「這五種無間業中，四種屬於身業，一種屬於語業；其中三種是殺害，一種是妄語欺誑，一種是殺生的加行前方便。」從「若互作者」往下，接著說明身口互相資助而造作。上面說明口業能兼涉身業的四種罪，從「若論破僧」往下，接著說明身業不能單獨兼代口業。疏文中「能破」與「所破」相互對照闡明。「所破」並沒有另外獨立的實體，也就是指事相與理體這兩種不和合，所以稱它為「性」。「性」也就是指體性。

【511-0005】02_戒疏/08b_卷二下之一#21
【原文】【疏】破僧瞋嫉心起，餘四分通三性。
【譯文】【疏文】破僧是從瞋恨、嫉妒之心生起的，其餘四種罪則分別通於善、惡、無記三種心性。

【511-0006】02_戒疏/08b_卷二下之一#22
【原文】【記】二中。初明破僧。調達見佛人天奉敬，頻婆國王日給千車，遂起嫉心。結連闍王，以謀害佛。又於佛所，乞請攝眾，為佛所呵，即懷瞋恨。此明破僧，局不善性。「餘」下，示餘四。殺通三性，四逆同之。然本是不善性，旁兼善無記，故示「分通」也。
【譯文】【記文】第二小科中。首先說明破僧之罪。提婆達多看見佛陀受到人天的崇敬供養，頻婆娑羅王每天供應一千輛車的物資，於是生起嫉妒之心。他勾結阿闍世王，密謀殺害佛陀。又在佛陀面前，請求由自己來統領僧眾，遭到佛陀嚴厲喝責，隨即懷恨在心。這說明破僧只局限於不善的心性。從「餘四」往下，指出其餘四種罪。殺生在心性上通於善、惡、無記三性，其餘四種逆罪也是如此。然而根本性質仍是不善，只是旁兼可能帶有善或無記的動機，所以說「分通」。

【511-0007】02_戒疏/08b_卷二下之一#23
【原文】【疏】破僧雖口說，言了未結罪，要待前人忍，方成其破輪也。
【譯文】【疏文】破僧雖然依靠口中宣說，但話語說完時罪名尚未完全結定，必須等待聽聞者信服默許，才算真正成就破壞法輪的重罪。

【譯文】【記文】第三小科中。因為其餘的口業，只要吐露言詞完畢隨即結罪，破僧則極為特殊，所以特別予以闡明。使佛身出血未能致佛於死地，其餘三種與一般殺生相同，對方生命斷絕即構成犯戒，所以不必在此討論。

【511-0012】02_戒疏/08b_卷二下之一#28
【原文】【記】初中。佛在俱通，滅後三通二塞。法輪雖在，無主競化，故二俱闕。
【譯文】【記文】第一點關於時間。佛陀在世時五種逆罪全都會發生；佛陀滅度後，其中三種可能發生（通），兩種不再發生（塞）。雖然法輪遺法猶存，但沒有兩位教主爭相教化，所以出血與破僧這兩種逆罪都不再具備。

【511-0013】02_戒疏/08b_卷二下之一#29
【原文】【疏】二、言處者。南洲具五，東西俱三，出血、破僧須佛身故。北洲俱無，《雜心》云「以命定，無相殺」故。
【譯文】【疏文】第二點論及處所。南瞻部洲五逆罪全都具備，東勝神洲與西牛貨洲都只有三種，因為出佛身血與破僧必須有佛陀真身住世的緣故。北俱盧洲則全無逆罪，《雜阿毘曇心論》說「因為該洲之人壽命固定，沒有互相殺害之事」的緣故。

【511-0014】02_戒疏/08b_卷二下之一#30
【原文】【記】次科。若論有無，則三洲有，北洲無；若約具闕，則南洲具，東西闕。下引《心論》，引證北洲。言「命定」者，《長含》中：「修十善行，生鬱單越，壽命千歲，不壞不滅，是故彼人壽命常定。」
【譯文】【記文】這是第二小科。如果論及有沒有逆罪，那麼三洲都有，北洲完全沒有；如果是就具備或殘缺而言，那麼南洲全備，東西二洲則殘缺不全。下面引用《心論》作為北洲無逆罪的證據。所謂「壽命固定」，《長阿含經》中說：「修持十善業行的人，往生到北俱盧洲，壽命整整千歲，中途不遭夭折毀損，所以那個地方的人壽命始終是固定的。」
