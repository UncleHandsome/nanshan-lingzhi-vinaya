# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【577-0007】資持記/15d_下三#64
【原文】優婆塞，古翻清信士，亦云近事男，女云優婆夷。五如來等，結歸正本也；以三寶名，通九十六種；後須顯正，非同前濫；由此勝號，外道無故；如來者，乘如實道，來成佛也；至真者，體悟無邪也；等正覺者，道同三世也；此實我歸，餘非敬者，故云是我世尊。〔此並撮略，《業疏》釋之，餘廣如彼。

【577-0008】資持記/15e_下三#1
【原文】〕前三歸誓，正發戒緣；三法纔竟，即納戒體；後二歸結，是囑非體。次科，初誡聽。多陀，此云如；阿伽度，此云來；阿羅訶，此云應〔應即應供〕；三藐三佛陀，此云正等正覺；亦舉三號，令生信奉。盡下，列相。邪婬者，犯他妻也；
【譯文】前面三歸依的誓詞，是正發戒體的緣起；這三遍羯磨法才剛結束，就納受了戒體；後面的兩次歸結，只是囑咐教誡而非戒體本身。下一科，首先是誡令諦聽。多陀，在這裡譯為「如」；阿伽度，譯為「來」；阿羅訶，譯為「應」（應即是應供）；三藐三佛陀，譯為「正等正覺」；此處列舉佛的三種名號，是為了令受戒者生起信受敬奉之心。「盡」字以下，是列舉戒相。邪婬，指侵犯他人的妻子；

【577-0009】資持記/15e_下三#2
【原文】《俱舍》有四：一他妻，二自妻非道〔大道、口道〕，三非處〔非房室中〕，四非時〔懷胎、乳子、受八齋時〕。五中，前四性戒，有情境發；後一遮戒，非情境發。飲酒放逸，能作四過，故偏禁之。是下，囑累有四：初囑謹護，二勸作福，三令受齋，四教迴向。
【譯文】《俱舍論》中列有四種邪婬：第一是侵犯他人的妻子，第二是對自己的妻子行非道（即大便道、口道），第三是在非處（不在隱蔽的房室中），第四是在非時（懷孕、哺乳或受持八關齋戒之時）。五戒之中，前四條屬於性戒，是緣對有情境而發起；後一條是遮戒，緣對無情境而發起。飲酒會導致放逸，能夠引發前四種過失，所以特地加以禁戒。「是」字以下，囑累的部分包含四點：一是囑咐謹慎防護，二是勸勉廣修福業，三是令其受持齋戒，四是教導功德迴向。

【577-0010】資持記/15e_下三#3
【原文】年三者，正五九月；冥界業鏡，輪照南洲；若有善惡，鏡中悉現。〔或云：天王巡狩四天下，此三月對南洲；又云：此三月惡鬼得勢之時，故令修善。〕月六，白黑兩半，各有三日；按《智論》：初八天王使者下，十四天王太子下，十五天王自下，觀察眾生善惡；二十三、二十九、三十日亦爾。〔小盡準布薩應用初一。
【譯文】所謂年三齋，是指農曆正月、五月、九月；這時冥界的業鏡輪流映照南瞻部洲，世人若有善惡言行，鏡中都會完全顯現。（或者說：天王巡視四大天下，這三個月正好對著南洲；又有一種說法：這三個月是惡鬼勢力強盛之時，所以教令修善。）所謂月六齋，是每個月的白月與黑月兩半月，各自有三天；依照《大智度論》所說：初八日由天王的使者下界，十四日由天王太子下界，十五日由天王親自下界，觀察眾生的善惡；二十三日、二十九日、三十日也是如此。（若是小月，則準照布薩法應當改用初一日代之。）

【577-0011】資持記/15e_下三#4
【原文】持齋者，或受八戒，或但持齋，中前一食，中後不得妄噉。〔今多蔬菜，不節晚食；此雖非齋，猶勝輩血。又有飲水周時，為清齋者，此乃邪術；一切眾生，仰食而住；但勿過中，是佛正教。〕三料簡中，《成論》。對反有宗，三皆偏局；一須具受，二不重增，三定盡形。《多論》。
【譯文】持齋的人，有的受持八戒，有的只是單純持齋，午前吃一餐，過午之後就不得妄自進食。（現在多數人吃素菜，卻不知節制晚餐；這種做法雖然稱不上是齋，但比起殺生食血還是好一些。又有人二十四小時只喝水當作清齋，這完全是外道邪術；一切眾生都是依賴飲食而生存，只要不過午進食，才是佛陀的正教。）在第三段料簡中，首科為《成實論》。相對地，有宗的主張三點都較為偏狹局限：一是必須具足全受，二是不得重複增受，三是期限必定要盡形壽。次科引《多論》。

【577-0012】資持記/15e_下三#5
【原文】須五眾者，疏云：皆是弘法之人故；俗雖曾受，非故不聽。《智論》，初段。六齋緣起，異上《智論》，蓋所出不同。先雖奉齋，盡日不食，復無善法；佛因誘接，故為加改。次科，問中。若據有部，但發四支；成宗具七，與論頗同，故引示之。答中，初約義釋，上二句正答舉一。又下，轉釋舉妄。
【譯文】必須由出家五眾傳授的原因，疏中解釋說：因為他們都是荷擔弘法之人；在家人雖然曾經受戒，但非出家僧寶故不允許主持傳授。引《智論》的第一段。此處六齋日的起緣，與上面所引《智論》有所不同，大概是因為出處典籍不同。外道原本雖然奉持齋法，整天不吃東西，卻沒有修習相應的善法；佛陀藉此循循善誘接引，所以為其加以改進規範。下一科，在提問中。若依有部的主張，只發動身口七支中的前四支；而成實宗則七支具足，這與《智論》頗為相同，因此引來明示。在回答中，首先是依義理做解釋，前兩句正是在回答為何單舉妄語。自「又」字以下，進一步轉折解釋何以單提妄語。

【577-0013】資持記/15e_下三#6
【原文】恐云：何不於餘三中，趣舉一耶？故此釋之。如下，引例。十善攝無量，妄語攝餘三；相比無異，故云準知。三中。文如〈隨相〉，罵戒具釋。內法即往業，外法即依報。《增一》，意亦同上。內物即正報，以疎況親，必招殃禍。下指諸文，不復煩引，須者尋之。八戒，初科。《多論》開心念者，即自誓受；
【譯文】這是擔心有人會問：為什麼不在其餘三種口業中隨意舉出一種呢？所以在此特別解釋。自「如」字以下，引出實例。十善業道能含攝無量善法，妄語也能含攝其餘三種口過；兩者相比並沒有差別，所以說可以準照而知。第三科中。經文就如〈隨相釋〉裡面的罵戒所具體解釋的。內法指過去世的宿業，外法指依報環境。《增一阿含經》的意旨也與上述相同。內物即指正報，以疏遠的外物尚且如此，來比況親近的正報必當招致殃禍。後面指引的諸多經文，不再繁雜贅引，有需要的人可自行去查尋。八關齋戒，第一科。《多論》開許心念受戒的，就是指自誓受戒；
