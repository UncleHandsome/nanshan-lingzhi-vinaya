# 校閱材料　第609檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【609-0001】資持記/13a_下一#45
【原文】三長垂肘外，有象鼻相，步步吉羅。儻懼因果，請從正教。條數中，初科。條即竪條；五七九至二十五，皆從隻數，故徵所以。如疏、鈔者，《業疏》云：以沙門行慈，仁育為本，同世陽化，故數非偶。〔隻是陽數，能發生故；偶是陰數，能肅發故。〕兼指鈔者，應是《義鈔》逸文。多少中，初科。
【譯文】三是衣角長長垂於手肘之外，現出象鼻一般的拖曳之相，舉手投足步步結犯突吉羅罪。如果對因果心懷畏懼，祈請依順佛陀的正教！在「條數」（衣條的數目）中，第一科。「條」就是豎立的布條；五條、七條、九條乃至二十五條，全都採用單數（隻數），所以探究其中的緣由。針對鈔文所說「如《疏》、《鈔》中」一句，《業疏》解釋說：這是因為沙門奉行慈悲，以仁德撫育眾生為根本，合於世間陽氣生發造化之道，所以條數不能用偶數。〔單數是陽數，具有生發資養之能；偶數是陰數，具有肅殺凋零之意。〕文中兼指鈔文，應當是指《行事鈔義記》的佚文。在條數的多寡之中，第一科：

【609-0002】資持記/13a_下一#46
【原文】《四分》止十九條，中品之極；《十誦》止十五條，中品之初；皆略上品，故並云若過也。然文非顯了，故引《多論》，具列大衣三位九品。《業疏》云：所以極齊二十五條者，欲為二十五有作福田故。次科，先引律文。〈衣犍度〉云：諸比丘不知當作幾條衣，佛言：應五條，不應六條〔下衣〕；應七條，不應八條〔中衣〕；
【譯文】《四分律》只列到十九條為止，這是中品大衣的最高條數；《十誦律》只列到十五條為止，這是中品大衣的最初條數；兩者都略過了上品（即上三品），所以都說「如果超過」等語。然而經文語意不夠明確，所以引述《薩婆多論》，完整列出大衣的三位九品等級。《業疏》說：條數之所以最高限定在二十五條，是為了象徵替三界二十五有的所有眾生作福田的緣故。下一科，首先引述律文。〈衣犍度〉記載：諸比丘不知應當製作幾條的衣，佛陀說：應當做五條，不應做六條〔下衣〕；應當做七條，不應做八條〔中衣〕；

【609-0003】資持記/13a_下一#47
【原文】應九條，不應十條；乃至應十九條，不應二十條〔大衣〕。若能過是條數應畜〔略上三品〕。準律本無不字，後人不曉，妄注於邊；後有知者，不即削除；於下復注，點出前非；至後鏤板，不能刊正故也。今下，正斥。無正教制開者，謂非教制，復非所開，不足承用。三中。《聖跡記》有二卷，靈裕法師撰。
【譯文】應當做九條，不應做十條；乃至應當做十九條，不應做二十條〔大衣〕。如果能力超過這些條數也應當蓄持〔此處省略了上品的三種條數〕。依準律本原文根本沒有「不」字，是後人未能明了義理，妄自注寫在經文旁邊；後來有明事理之人，沒有當即將其塗銷；反而在下方又作附注，點出前面的妄注之錯；及至後代刻鏤木板印刷時，未能及時校勘訂正所導致的。自「今」字以下，正式予以斥責。所謂「無正教制開」，是指這既非佛陀的正教所制訂，又不是特殊因緣所開許，根本不足以承奉信行。在第三部分中，《聖跡記》共有兩卷，是靈裕法師所撰寫的。

【609-0004】資持記/13a_下一#48
【原文】其文但示條相。《智論》明其衣體，故引以成之。〔今有反求細布，有過絹直；放彼拈此，未善教意。〕言大準者，謂九品之衣，隨力所辦，從本須作二十五條；力不足者，次第減降，下至九條；以佛但著下品上衣，故知足以為準。六中。堤謂橫堤，如田之堤岸。
【譯文】該書的文字只是標示條相的規格。《大智度論》則說明了袈裟的布料實質，所以引用來使論說更為完備。〔現今有人反而刻意尋求細軟精緻的布料，其價值甚至超過綢絹；捨棄前者而求取後者，根本未能參透佛陀制教的苦心。〕所謂「大衣的準則」，是指九品大衣應當隨順各人的能力所及去備辦，原本應當發心製作二十五條的大衣；若是資力不足，再順次減少降等，最低降至九條；因為佛陀自己只穿著下品中的上品大衣（十三條），所以知道已足以作為依循的標準。第六部分中，「堤」是指橫向的界堤，就像田地的泥土埂岸一般。

【609-0005】資持記/13a_下一#49
【原文】《章服儀》云：條堤之相，事等田疇，如畦貯水而養嘉苗，譬服此衣生功德也；佛令像此，義不徒然。示數中，初科。《四分》定量文如前引。長短如上略示，五條十隔〔一長一短〕，餘二衣準之，應云七條二十一隔〔兩長一短〕，九條二十七隔等，次第增之。據律定量則出二衣，長短唯據五條；
【譯文】《章服儀》說：條紋與橫堤的形相，事理宛如世間的稻田水疇，如同田埂蓄水而滋養肥美的禾苗，比喻穿著此法衣能滋生功德；佛陀令袈裟描摹田相，其意義絕非徒勞無益的。在指示隔數中，第一科。《四分律》關於尺度的定量經文已如前文所引。長短條數如上面略作標示，五條衣共有十隔〔一長一短〕，其餘兩件衣可依此類推，應當是七條衣二十一隔〔兩長一短〕，九條衣二十七隔等，依此順序逐級遞增。依據律文原本的定量，是載明於二衣，而長短的具體隔數僅就五條衣而言；

【609-0006】資持記/13a_下一#50
【原文】文中通舉，須知兩異。次科，初明如法。所以長增至四，短唯局一者，疏云：法服敬田，為利諸有；表聖增而凡減，喻長多而短少。若下，簡非法。所以成受著用犯者，疏云：著取儀相，用生物善；長短差違，乖慈梵行；隨步越儀，一一結罪。〔今時禪眾多作九條，長短不定；或紗或綾，或絣或碧，自號法衣；體色量相，俱乖正制，何法之有。
【譯文】鈔文中通通列舉，必須明瞭這二者文獻出處的不同。下一科，首先說明如法之制。為什麼長條塊可以增加至四塊、短條塊卻唯獨局限在一塊？《律疏》說：袈裟法服是恭敬福田，旨在利益一切有情；象徵聖人功德增長而凡夫習氣減少，取喻於長塊較多而短塊較少。自「若」字以下，甄別非法的形相。之所以能成就受持、但穿著使用時卻會結罪，是因為《律疏》說：穿著法衣是為了端正儀相，用以引發世人的善心；長短比例若產生差池乖違，便違背了慈悲修行的梵行清規；舉步動止之間便有越軌失儀之過，每一步都要逐一結罪。〔現今禪門大眾多製作九條衣，長短完全毫無定制；或者用生紗，或者用細綾，或者織花，或者染成青碧，自己宣稱為法衣；其實材質、顏色、尺寸與條相，全都乖違佛陀正制，哪裡算得上是什麼法衣！〕

【609-0007】資持記/13a_下一#51
【原文】割截意中，初徵意。二引釋。《四分》不為賊剝者，以無所直故。《十誦》異外道者，彼著全段白㲲故。引律三賤，正取刀賤，人所棄故。已上諸意，皆託外緣，括其所歸，為破貪結，善巧之旨，其在茲乎！第七明多少中，初文。若據諸律重作，或以布通縵，或兩衣縫合；
【譯文】在「割截意」（割斷布料再行縫綴的意圖）中，首先探討其本意。其次引述經論解釋。《四分律》說為了不被賊人強行剝奪，因為碎布拼湊毫無世俗價值之故。《十誦律》說為了區別於外道，因為外道穿著整匹未經裁剪的白㲲布之故。引述律中所說的三種「賤」，此處正是取「刀賤」（剪碎之賤），是世人所遺棄之物。以上各項本意，雖然都是假託外在因緣而設，但總括其終極歸趨，全是為了破除內在的貪愛執著，佛陀運用善巧方便的深意，正是體現在這裡啊！在第七項說明層數多寡（多少）中，第一篇文字。若依據諸部律文重疊縫製的要求，或者用一整幅布在內通體襯托，或者將兩層衣縫合在一起；
