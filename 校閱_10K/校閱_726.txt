# 校閱材料　第726檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【726-0001】02_戒疏/16a_卷四上之一#106
【原文】【記】三、緣異中。「背請、足食」，下《戒本》中並云「尼吉」，《疏》云「作不同戒耳」。尼中二戒合制，故《戒本》云：「先受請，若足食已後食者，提。」「外道」者，尼中白衣男子亦犯，僧則開之。彼戒本云：「自手持食與白衣、外道者，提。」「小年」者，尼中十八童女增二年學法，僧則不爾。《戒本》云：「不與二歲學戒，滿二十，便與受具，提。」「雨浴衣」，過量雖同，用則有別，僧開夏月，尼聽常用。
【譯文】【記文】第三、因緣各異之中。「背請」與「足食」二戒，在下文《戒本》（僧戒本）中都注為「尼犯結吉羅」，《疏》中說是「視為不同的戒條罷了」。比丘尼律中將這兩條戒合併制定，所以《尼戒本》說：「先受請，若是吃飽足食之後又吃者，犯單提。」「外道」，比丘尼若親手給白衣男子食物也成犯，比丘則有開許。彼《尼戒本》說：「親手拿食物給白衣、外道者，犯單提。」「未滿年」，比丘尼對於十八歲童女必須增加兩年的式叉摩那學法，比丘則不然。《尼戒本》說：「不給予兩年學戒，年滿二十便為其受具足戒者，犯單提。」「雨浴衣」，超量違犯雖相同，使用期限卻有差別，比丘只開許在夏季，比丘尼則聽許經常使用。

【726-0002】02_戒疏/16a_卷四上之一#107
【原文】【疏】敢依律例，更有義求。如「牽出房」，春、冬僧尼同犯，若是夏房，尼提僧吉。二、「毀呰」中，尼通兩眾，僧即輕重。三、「覆藏」中，僧罪二階，尼即三品。有此諸異，何得不知？
【譯文】【疏文】我大膽依照律法通例，更作進一步的義理推求。例如「牽出房舍戒」，春季與冬季僧尼同犯，但若是夏安居時的房間，尼犯單提而僧犯吉羅。第二、在「毀謗呵責戒」中，比丘尼犯者普遍通於比丘與比丘尼兩眾，僧犯則依對象不同而分輕重罪。第三、在「覆藏他罪戒」中，僧犯分為兩個階位，尼犯則分為三品。有這些種種差異，如何能不知曉？

【726-0003】02_戒疏/16a_卷四上之一#108
【原文】【記】義求中。前是據文，此出自見，故云「敢依律例」。即上三別，「牽」即緣異，「毀」即輕重，「覆」即有無。「牽出」中，僧有三時分房，夏房入己定，不須避上座，牽稀故輕。「尼提」者，《尼律》云：「安居中受安居已，乃至隨作方便，出門，一一提。」「毀呰」中，尼毀本眾及僧並提，故云「通兩眾」；僧則同類提，四眾吉，故云「輕重」。「覆藏」，僧覆上二篇提，下三吉，故云「二階」；尼加一夷，故云「三品」。「有」下，結告。
【譯文】【記文】義理推求之中。前面是依據律文，此處是出於自己的灼見，所以說「大膽依照律法通例」。這就是上述的三種差別，「牽出房」即是因緣各異，「毀謗」即是輕重不同，「覆藏」即是有無各異。在「牽出房舍」中，比丘有一年三次分房之法，夏安居的房舍一旦歸己即成定局，不須為了上座而避讓，牽出之事實屬罕見所以罪輕。「尼犯單提」，《尼律》說：「在安居中受了安居之後，乃至隨便作方便動作將人逐出門外，一一結犯單提。」在「毀謗呵責」中，比丘尼毀謗本眾及比丘皆結單提，所以說「通於兩眾」；比丘則毀謗同類結單提，毀謗其餘四眾結吉羅，所以說「分輕重」。「覆藏戒」中，比丘覆藏前兩篇罪結單提，覆藏下三篇罪結吉羅，所以說「兩個階位」；比丘尼則多加了一條波羅夷罪的覆藏，所以說「分為三品」。「有這些」以下為結語告誡。

【726-0005】02_戒疏/16a_卷四上之一#110
【原文】【疏】《十誦》九十一墮，無此「不受諫戒」，別立「不敬說法人戒」、「說戒時輕僧浪語戒」。似此「觸惱」，而彼自有「不隨問答戒」。

【726-0006】02_戒疏/16a_卷四上之一#111
【原文】【記】六、諸部中。若論大數，《解脫》、《鼻奈》與《四分》同，《十誦》與《五分》同，《僧祇》獨異。初《十誦》，無一有二異。「浪語」，謂謔浪也。「似」下，簡辨。「不隨問答」即是「觸惱」，明知「浪語」別自立耳。
【譯文】【記文】第六門各部律典之中。若依總數來看，《解脫律》、《鼻奈耶律》與《四分律》相同，《十誦律》與《五分律》相同，《僧祇律》則獨自不同。首先是《十誦律》，缺少一條而多了兩條不同。「放浪言語」是指謔笑放浪之語。「看似」以下作甄別。「不隨問答」即是「觸惱戒」，明知「放浪言語戒」是彼律各自另外建立的。

【726-0010】02_戒疏/16a_卷四上之一#115
【原文】【記】《僧祇》中，無二有四別。上二同前《五分》。「不捨淨」者，彼律凡物說淨已，欲取用者，須作捨法云：「此衣淨施與某甲，某甲於我不計意，今還捨。」不捨，作三衣提，入塔、僧用吉。「又離餘語」者，尋彼《戒本》及以廣律，大同《四分》，止是一戒。若云「離」者，不合大數，則應九十三也。此意末詳，以俟來者。
【譯文】【記文】《僧祇律》中，缺少兩條而多了四條不同。前面兩條同於前面的《五分律》。「不捨淨受持」是指彼律凡是物資作了說淨法之後，若想取來自己使用，必須作捨除說淨的儀軌說：「此衣已淨施給某甲，某甲對我無所吝惜，如今再行捨除。」若不作此法，拿來作三衣結單提，用作佛塔或僧眾常住物結吉羅。「又把異語分開」這點，考查彼部《戒本》以及廣律，大體同於《四分律》，只是一條戒而已。若是說「分開」，便不符合總數的大數，那就應當是九十三條了。這個意涵尚不詳盡，留待後世仁者考證。

【726-0013】02_戒疏/16a_卷四上之一#118
【原文】【疏】《鼻奈耶》九十中，有五不同。因六群共十七群諍，故立戒本：「瞋恚者，提。」六群撓擾，故結戒云：「若擊動使瞋者，提。」因儉請一二人，多往惱亂，戒本云：「不請強去者，提。」下開僧事、病及作衣。「若比丘先至請家，弄小兒者，提。」、「高聲亂人者，提。」
【譯文】【疏文】《鼻奈耶律》的九十條戒中，有五條完全不同。由於六群比丘與十七群比丘起爭執，所以立戒本說：「瞋恚忿恨者，犯單提。」六群比丘騷擾攪亂，所以結戒說：「若挑釁攪動令他人生瞋恚者，犯單提。」由於饑荒年代信眾只供請一二人，多人前往惱亂，戒本說：「不獲邀請而強行前往者，犯單提。」其下開許僧事、疾病以及作衣。「若比丘先到受請的人家，戲弄小兒者，犯單提。」、「高聲喧嘩擾亂他人者，犯單提。」
