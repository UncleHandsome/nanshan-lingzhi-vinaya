# 校閱材料　第1173檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1173-0001】資持記/09b_中三上#24
【原文】恐生輕疑，故特注之。若下，明作務。就葉飲者，以泥作手污，不執餘器故。水下，明損淨萍。水草即萍等。若下，明非久物。朝菌即地蕈，《指歸》云：此生於地，八月有，朝生暮死。準此，例上衣毛，損應得吉。《善見》。以淨人幼小故開。《四分》中。注文指前，即《僧祇》繫草文。釋第四緣，《五分》初明淨語。
【譯文】唯恐大家生起輕忽懷疑的心態，所以特別加以注釋說明。「若」字以下，說明日常勞作事務。湊著樹葉直接飲水，是因為手沾泥土變髒了，不可再去拿持其他器皿。「水」以下，說明損毀經過淨化的浮萍。水草就是指浮萍之類。「若」字以下，說明並非長久存活的物品。朝菌就是地蕈，《指歸》說：這種菌生長在地上，八月間最常見，早晨長出傍晚就枯死。依照這個道理，比照上面的石衣菌毛，損傷它應當只得小罪（吉羅）。《善見律》中，因為淨人年紀幼小不懂事而開許。《四分律》中。注文指示參照前文，也就是《僧祇律》中綁草的那段文句。解釋第四個犯戒條件，《五分律》首先說明清淨言語。

【1173-0002】資持記/09b_中三上#25
【原文】次列四種，解一即止，隨言通得。四皆云是，即指前物。注顯知淨。知屬前人，淨在比丘；由解此義，故號淨人。不合下，應加言字助之。若下，明緣開。開路不犯。文言不故，異上《僧祇》。罪多少中，初對《十誦》明當戒。《十誦》從種，故止五罪；此律約業，故隨多少。乃下，次對《僧祇》辨前戒。
【譯文】其次列出四種情況，只要聽懂其中一種即可停止，隨順口令語音通通可以成立。四種情況都說「是」，就是指眼前的那項物品。注文在於顯發懂得清淨之意。理解屬於在場的俗人，求清淨則在於出家比丘；因為能理解這個法義，所以稱為「淨人」。「不合」字以下，應當補加一個「言」字來輔助文義。「若」字以下，說明開許的因緣。為了開闢通道而不算犯戒。文中強調「並非故意」，這與上面《僧祇律》的標準不同。在結罪多少的問題中，首先對照《十誦律》來闡明本條戒律。《十誦律》是依照種子的種類來結罪，所以頂多只有五種罪名；本部律典則是依據具體毀損行為來結罪，所以罪名隨行為次數多寡而定。「乃」字以下，其次對照《僧祇律》來辨析前一條戒律。

【1173-0003】資持記/09b_中三上#26
【原文】明離地中，引律前明五生。通約就地。柳榴枝種，枝可植故，離地亦犯。榴即石榴。後明非五生。但除枝種，餘離地者。文列三判，尋之可見。槐櫰同類，葉細而青者名槐，大而黑者曰櫰。與地連者，猶屬生故。不犯有十。初作法開，下九皆以若字間讀。墼謂土塊。
【譯文】在說明植物脫離土地的情形中，引用律文前面說明的五種生長形態。這通常是就生長在地面上而言。柳樹與石榴屬於枝種，折下的枝條依然可以種活，所以即便脫離地面折損它也犯戒。榴就是石榴。後面說明不屬於五種可再生植物的情況。只要除開枝種，其餘已經脫離地面的草木。文中列出三種判斷準則，細閱文意便可明瞭。槐樹與櫰樹屬於同類，葉子細小而翠綠的叫作槐，葉子寬大而深黑的叫作櫰。只要根部還與泥土相連，就依然屬於鮮活生長之物。不犯戒的情況有十種。第一是如法作開許程序，下面九種都用「若」字相隔閱讀。「墼」就是指土坯塊。

【1173-0004】資持記/09b_中三上#27
【原文】除經行土者，因損苔草故。十二。〔佛在拘睒彌，闡陀犯罪；餘比丘問，以餘事答；作白制已遂惱僧，喚來不來等；又作白制，違白而作故制。〕身口二業，邪曲惱僧，喻如文綺。此據僧法，故犯提罪；餘非義語，止犯吉羅。《戒本》云：妄作餘語惱他。〔《刪定戒》作異語惱僧。
【譯文】清除經行道路上的泥土，是因為無意間損壞了青苔雜草的緣故。第十二條戒律〔佛陀住在拘睒彌國時，闡陀比丘犯了戒；其他比丘問他，他卻用別的事來搪塞；僧團作白羯磨制止後他反而惱亂大眾，叫他來偏不來等；僧團再次作白羯磨，他依然違抗羯磨而妄作非為，佛陀因此制戒〕。身、口兩種行為，用歪曲邪妄的方式惱亂僧眾，如同雜亂錯綜的文綺。這是針對干擾僧團羯磨如法運作而言，所以犯下嚴重的墮罪（提罪）；其餘世俗無意義的閒聊雜談，只犯輕微的小罪（吉羅）。《戒本》說：妄作其他言語惱亂他人〔《刪定戒本》寫作講異樣的話來惱亂僧團〕。

【1173-0005】資持記/09b_中三上#28
【原文】餘語即口綺，惱他即身綺，即二戒同制也。釋中，本律，先明口綺。諸比丘問言汝自知犯罪不？即作餘語，如文所引。而云等者，律文續云為論何理、為語我為誰、是誰犯罪、罪由何生、我不見罪、云何言我有罪。惱下，明身綺。由制不得餘語，後便觸惱眾僧。等者，律接云：喚來不來，不喚來便來；
【譯文】「餘語」即口業的雜話，「惱他」即身業的惱亂，也就是將這兩種違犯合併制定在一條戒中。解釋的文句中，依據本律，首先說明口業的雜話。諸位比丘問他道：你自己知不知道犯了戒？他隨即講起不相干的言語，如同正文所引用的那樣。文中之所以說「等」，是因為律文接著還寫道：究竟在討論什麼道理、在對誰說話、是誰犯了罪、罪是從哪裡生出來的、我根本沒見到罪、憑什麼說我有罪。「惱」字以下，說明身業的挑釁惱亂。因為被戒律限制不得隨意亂說話，他隨後便用行動來觸惱觸怒僧眾。所謂「等」，律文接著說：叫他來他不來，沒叫他來他偏要來；

【1173-0006】資持記/09b_中三上#29
【原文】應起不起，不應起便起；應語不語，不應語便語。〔此語屬身綺，與上不同。〕不指如前，即結罪相。諸文中。《成論》實語，次第三相，俱有過故；非時者，語不合宜，即名不義；衰惱，謂令他不樂；無本，謂師心也。即下，指律；眾學說法等戒，並非宜故。
【譯文】應該起立他不起立，不該起立他偏要起立；應該發言他不發言，不該發言他偏要發言〔這裡的言語屬於挑釁反抗的身業，與前面的口業雜話不同〕。不指如前，即確定犯罪的行相。在各論典文獻中。《成實論》談到誠實的言語，其次列出的三種狀態，全部都帶有過失：不合時宜的話，就是言談不合時節因緣，就稱作不義；衰損惱亂的話，是指讓別人聽了心生痛苦憂惱；沒有本據的話，是指全憑自己的成見妄自揣測。在「即」字以下，指引律典依據；眾學法中說法等項目的戒律，都因為時間場合不宜的緣故而算違犯。

【1173-0007】資持記/09b_中三上#30
【原文】《善見》下，此開應語不語。律下，此約別人以論。不犯中，初門口綺。重聽謂已疾不聞。參錯謂他言不了。若欲下，次開身綺。初約非法羯磨，明來不來；若一下，次約頭陀病難，明起不起；若惡下，約非問非法，明語不語。如上三位，一一相違；事同非犯，以緣別故。若小下，失口非意。
【譯文】《善見律》以下，這是開許應該發言而保持沉默的特殊情況。律典以下，這是就個別私人的談話情境來論斷。不犯戒的情況中，第一個門類屬於口業雜話。聽力沉重是指自己患有耳疾而聽不清楚。參差錯亂是指對別人說的話理解不透徹。「若欲」以下，其次開許挑釁的身業。首先針對非法的羯磨會議，說明為何可以召之不來；「若一」以下，其次針對頭陀苦行者遭遇病患或危難，說明為何可以該起而不立；「若惡」以下，針對非理詰問與非法要求，說明為何可以該說而不語。如同上面三種情境，每一種看似違背常規；但事相雖然相同卻不算犯戒，這是因為背後的事由完全不同的緣故。「若小」以下，是指一時失口，非出自故意。

【1173-0008】資持記/09b_中三上#31
【原文】如常所開。十三。〔佛在羅閱城，慈地比丘嫌罵沓婆，故制；與僧殘二謗同時。〕名中云僧，簡私請故。疏云嫌罵兩戒，同惱知事不殊，故合制也。緣中。一三六屬知事，餘三屬能犯。初緣中，初科。《五分》通單白，《四分》唯白二。餘人即佐助者。誣謂欺枉。
【譯文】如常所開許的慣例。第十三條戒律〔佛陀住在羅閱祇城時，慈地比丘怨恨毀罵沓婆羅漢，佛陀因而制戒；這與僧殘篇中的兩條誣謗戒是在同一個時期制定的〕。戒名中冠上「僧」字，是為了排除私人的邀請。戒疏說：嫌棄與毀罵這兩條戒，同樣都是無端干擾惱亂執事僧，性質沒有兩樣，所以合併在一起制定。犯戒因緣中。第一、第三、第六項屬於被侵犯的執事僧，其餘三項屬於能犯過的人。第一個條件中，第一科提到：《五分律》通許單白羯磨，《四分律》則嚴格規定必須白二羯磨。其餘人等是指執事僧的輔助差役。誣謗是指欺瞞枉屈。
