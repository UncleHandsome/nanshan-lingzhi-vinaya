# 校閱材料　第107檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【107-0001】01_行事鈔/06a_卷中之二#3
【原文】與女人麁語戒第三。七緣成犯：謂人女，人女想，有染心，麁語，麁語想，六言章了了，七前人知解。《伽論》：比丘性好麁語，偷蘭。律中人女者，要有所了知，解淫欲語也。麁惡語者，非梵行也。未必言聲相有麁醜，號為麁惡；不防涉於善事，而意表於淫欲。故律云：若復作餘語者。如律云：因消蘇著赤衣時，女形露，便言消蘇好不？若女情相領，律結僧殘。若不解者，如《僧祇》云：比丘見女人新染衣著，形露；比丘言，大赤好，女人云，新染故爾。比丘生疑，白佛；佛令一比丘問女，女具如前答；佛言：義味俱解，僧殘。《四分》：解語不解義，偷蘭。此但論染心向女麁語；若準《五分》，具有彼此互向麁語，犯。下歎身戒亦同。律中不犯者，為女說不淨惡露觀，九瘡、九孔、九入、九漏、九流，而彼女謂為說麁語；若說毘尼時，言次及此；若說經受經，若二人同受，若彼問此答，若同誦，若錯說。但無欲心，一切無犯。
【譯文】與女人麁語戒第三。具備七個條件構成違犯：即人道女人、作人道女人想、內懷染污心、說粗惡語、作粗惡語想、言語表達分明清晰、對方領會理解。《鼻奈耶得伽論》說：比丘若生性喜好說粗俗語，結偷蘭遮。律中所說的人道女人，必須是具備理解認知能力，懂得淫欲話語的人。所謂粗惡語，就是非梵行（與淫欲相關）的話語。未必要聲音音相粗鄙醜陋才叫作粗惡語；即使表面上涉及良善之事，但意旨顯露於淫欲，即是粗語。所以律中說：「如果又作其餘的話語。」就像律中記載：有比丘因（名叫）消蘇的女人身著赤衣時，女人的身形曲線顯露，比丘便說：「消蘇好不好啊？」如果女人心領神會其淫意，律典便結犯僧殘。如果對方不解其意，如《摩訶僧祇律》說：比丘看見女人穿著剛染好的衣服，身形顯露；比丘說：「這大紅衣服真好看。」女人回答：「這是剛染好的，所以這樣紅。」比丘心中生疑，向佛陀稟告；佛陀命令一位比丘去問該女人，女人的回答具體如前；佛陀便判定說：「文義情味都已解了，犯僧殘。」《四分律》說：若女人僅理解字面言語而不解淫欲深意，結偷蘭遮。這裡只是論及比丘懷著染污心對女人說粗話；若準照《五分律》，只要具備彼此相互對說粗話，即構成違犯。以下「讚歎自身索求供養戒」也是同樣道理。律中不犯的情況包括：為女人解說不淨惡露觀，講述九瘡、九孔、九入、九漏、九流等法相，而那女人自以為是在說粗話；或者在講解毘尼（戒律）時，話語次序偶爾涉及於此；或者講經、受經，或者兩人共同受學，或者對方提問己方作答，或者共同誦讀，或者口誤說錯。只要內心沒有淫欲之念，一切都不犯。

【107-0002】01_行事鈔/06a_卷中之二#4
【原文】向女歎身索供戒第四。論犯七緣：一人女，二人女想，三內有染心，四歎身說麁語，五麁語想，六、七同前戒。律云：歎身者，端正、好顏色、大姓出家、持戒、修善法、行十二頭陀等。不索淫欲供養者，偷蘭；說欲并自歎者，僧殘；若直說麁語，犯前戒。不犯中，若為女人說法及說毘尼時，言次相及，而女謂自歎身，並無犯。
【譯文】向女歎身索供戒第四。論述成犯具備七個條件：一是人道女人，二是作人道女人想，三是內懷染污心，四是讚歎自身並說粗惡語，五是作粗惡語想，第六、第七個條件與前一戒相同。律中說：所謂讚歎自身，是指自稱相貌端正、膚色容貌姣好、出自名門望族而出家、嚴持戒律、修習善法、實踐十二頭陀苦行等。如果讚歎自身卻不索求淫欲供養者，結偷蘭遮；若既談說淫欲並且讚歎自身索求者，結犯僧殘；若單純直白地說粗惡語，則犯前一條粗語戒。在不犯的情況中，如果為女人宣說佛法以及講授毘尼時，話語次第相涉提及，而女人誤以為是在自我讚歎，皆不構成犯罪。

【107-0003】01_行事鈔/06a_卷中之二#5
【原文】媒人戒第五。六緣成犯：一是人男女，二人想，三為媒嫁事，四媒嫁想，五言辭了了，六受語往還報，便犯。律文要三時具者，方結僧殘：一謂受語，二往彼陳說，三還報知。若具二者結偷蘭遮；具一時者結突吉羅。若受語往彼說，而言已嫁、若死、若賊將去者，偷蘭；若言癩病等，還報者，僧殘。除二道已，媒餘身分者偷蘭；若媒人男畜生等，並吉羅。《五分》：不許而報，偷蘭。《十誦》：不能男女，若道合一道女，石女等，一切偷蘭。此律中，諸比丘白二羯磨，差人媒嫁，一切僧殘。今知事白僧，媒娶淨人，供給婚具，問僧同和，一切僧殘。若用僧物，同俱犯重。《僧祇》：為他求好馬種和合故，偷蘭；餘畜吉羅。《五分》若為男長倩女使，偷蘭；為女倩男亦爾。《十誦》、《伽論》云：若指腹為媒，及自媒者，偷蘭。《四分》：媒法以語書、指印、遣使，但情相領，參互作句，皆犯。若比丘持他書往不看者，及為白衣作餘使，並吉羅。《僧祇》：勸歸婦早還者偷蘭。律不犯中，若男女先已通，後離別，還和合者，開不犯。《十誦》云：作券書言非我婦，猶故未唱出者，偷蘭；若婦禮已斷，不復來往，而和合者，僧殘。律中開持書者，若為父母，及信心精進優婆塞病，若在獄繫，及為佛法僧事，病比丘事等，看書持往不犯。
【譯文】媒人戒第五。具備六個條件構成違犯：一是人道的男女，二是作人道想，三是為了媒合婚嫁之事，四是作媒合婚嫁想，五是言辭清晰分明，六是接受囑託往返傳話通報，便結犯。律文中必須三種時節皆具備，方才結犯僧殘：第一是接受委託之語，第二是前往對方處陳述遊說，第三是返回向委託人回報知會。如果只具備前兩項者結偷蘭遮；只具備第一項者結突吉羅。如果接受委託前往對方處陳說，而對方回覆說已經出嫁、或者已經死亡、或者被盜賊擄走，回報者結偷蘭遮；如果對方回覆患有癩病等殘疾而回報者，結僧殘。除了以行房交合（前道、後道）為目的媒合而犯僧殘之外，若是牽線媒合親撫身體其餘部位，結偷蘭遮；若是媒合人道男子（男男媒合）或畜生等，皆結突吉羅。《五分律》說：對方不應允而回報者，結偷蘭遮。《十誦律》說：為不能男、不能女，或者道合一道女（產道直腸相通者）、石女等作媒，一律結偷蘭遮。本律中規定，若諸比丘透過白二羯磨（一白一羯磨的僧團表決），差遣人員為人作媒婚嫁，所有人皆犯僧殘。如今知事比丘向僧團表白，為淨人（寺院侍者）作媒娶親，提供籌辦婚嫁器具，並徵詢僧團一致和合通過，全體皆犯僧殘。若是挪用僧團常住物資，則同樣犯重罪。《摩訶僧祇律》說：如果為他人尋求良種公馬與母馬交配和合，結偷蘭遮；為其餘畜生作媒合，結突吉羅。《五分律》說：如果為男主人僱用女婢使女，結偷蘭遮；為女主人僱用男僕亦同。《十誦律》、《鼻奈耶得伽論》說：如果指著孕婦之腹預作媒約，以及為自己作媒者，結偷蘭遮。《四分律》說：做媒的方法包括以言語、書信、指印印信、差遣使者，只要彼此心意相通領會，互為參佐成句，全都構成違犯。如果比丘替俗人送信前往而不看信件內容，以及為在家人充當其餘差使，皆結突吉羅。《摩訶僧祇律》說：勸勉回娘家的婦女早日返回夫家者，結偷蘭遮。律中不犯的情況包括：如果男女雙方先前已經私通，後來分離，比丘令其重修舊好者，開許不犯。《十誦律》說：丈夫立下字據契約聲稱「這不再是我妻子」，但尚未在公眾場合唱名宣告休棄者，為之和合結偷蘭遮；如果夫妻禮儀恩義已絕，不再往來，而再去為之撮合者，結犯僧殘。律中開許替人送信的情形：如果是為了父母，以及具備正信精進的優婆塞（男居士）患病，或者身陷囹圄囚禁，以及為了佛、法、僧三寶之事，或為患病比丘之事等，查看信件後替其攜帶前往者，皆不犯。
