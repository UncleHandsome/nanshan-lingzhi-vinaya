# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【202-0001】02_戒疏/09d_卷二下之二#128
【原文】【疏】「多人住」者，以擬多人住故，非謂多人共造也，如畜長例。
【譯文】【疏文】所謂「多人居住的房屋」，是因為預定用來讓大眾僧人共同居住的緣故，並不是指許多比丘共同出資建造一間私房，這就像多蓄長物的法例是一樣的。

【202-0002】02_戒疏/09d_卷二下之二#129
【原文】【記】釋多人中。「非謂共造」者，容同犯故。「如畜長」者，多人未分物，過日不犯，則同「擬多人」也。分屬已定，共處亦犯，如「共造」也。
【譯文】【記文】在解釋多人居住的段落中。所謂「不是指多人共同建造」，是因為共同合建私房仍有可能一同結犯過失。所謂「如同多蓄長物」，是指多人共有尚未分發的物品，就算超過時限也不犯長物罪，這就如同「預定給多人居住」的性質。如果財物歸屬已經確定，卻依然混在一起共同儲存，這就會犯戒，就如同「共同違法建造」一樣。

【202-0003】02_戒疏/09d_卷二下之二#130
【原文】【疏】有人云：「此由造作過量犯，非謂如量貯畜罪。如《見》云：『若沙彌、大僧，多人共作，不犯。段段計分一口，過故亦犯。』」
【譯文】【疏文】有人認為：「這是因為建造房屋超過尺寸才結罪，並不是指如法儲存蓄積的罪過。正如《善見論》所說：『如果沙彌與大僧多數人共同建造大房，並不犯戒。除非各自分段計算，每人所佔的房間空間都超出了規定尺寸，這樣才會犯戒。』」

【202-0004】02_戒疏/09d_卷二下之二#131
【原文】【記】他解中。意謂房、長不可例同，長則共畜有犯，房則共造無過。「如」下，引證無犯。必約段段計過，方有犯義。
【譯文】【記文】在其他學者的解釋中。意思是說房舍與長物不可以生搬硬套當成一類，長物是共同蓄積就會犯戒，而房舍若是大眾共同營造本來就無過犯。從「正如」以下，引用論典證明無犯。必須是在大房中切塊分段計算，每個人所佔有的單位都超過了法定尺寸，才會有結罪的法理。

【202-0005】02_戒疏/09d_卷二下之二#132
【原文】【律】七、有主為己不處分造房戒。
【譯文】【律文】第七、有施主為自己未經指劃處分建造房屋戒。

【202-0007】02_戒疏/09d_卷二下之二#134
【原文】【疏】制意犯緣竝同上，但無制量為別。
【譯文】【疏文】制戒的深意與犯戒的因緣，都與上一條戒完全相同，唯一的區別只是本戒沒有限制房舍的尺寸大小而已。

【202-0008】02_戒疏/09d_卷二下之二#135
【原文】【記】七有主房。指「緣同」者，今須辨異：一、有主；二、為己；三、長佛六磔廣四磔，須乞；四、不乞；五、不乞想；六、房成。對前同別，可知。
【譯文】【記文】第七條有施主房舍戒。文中所指「犯緣相同」，現在必須詳細辨別其相異之處：一、有施主出資；二、純粹為了自己；三、長度在佛的六磔手、寬度在四磔手以上的大房，才必須向僧團乞求處分；四、未經乞求處分；五、心中明知未經乞求而建造；六、房屋正式落成。以此對比前一條戒的同異之處，便一目了然了。

【202-0009】02_戒疏/09d_卷二下之二#136
【原文】【疏】如《見》云：「長佛六磔手，廣四磔手已上者，須處分。」
【譯文】【疏文】正如《善見論》所說：「長度在佛的六磔手、寬度在四磔手以上的房舍，就必須向僧伽乞請指劃處分。」

【202-0010】02_戒疏/09d_卷二下之二#137

【譯文】【記文】關於乞法所適用的建築面積標準，這項尺寸標準貫通前後兩條戒，凡是小於這個尺寸的小屋，就不需要向僧伽乞求處分。

【202-0015】01_行事鈔/10c_卷下之二#1
【原文】四量是非《四分》：大鉢受三斗，小者受斗半，中品可知。此斗升不定。此律姚秦時譯，彼國用姬周之斗。準唐斗，上鉢受一斗，下者五升。《十誦》斗量同《四分》。又彼律云：下鉢受一鉢他飯，半鉢他羹，餘可食半。《薩婆多》云：鉢量，論師種種異說。然以一義為正，謂一鉢他受十五兩飯。秦秤三十兩飯，是天竺粳米釜飯。時人咸共計議，上鉢受三鉢他飯，一鉢他羹，餘可食者半。三鉢他飯可秦斗二斗，一鉢他羹，可食物半，復是秦斗一斗。上鉢受三斗。律師云：無餘可食物，直言上鉢受三鉢他飯，一鉢他羹；留上空處食，指不觸中。中下二鉢，可以準知。見一肆上好鉢，圓正可愛。律師云：佛初出世，眾僧無鉢，佛勅帝釋，令天巧工，作十萬鉢在世間；肆上鉢者，是彼天鉢，非是人造。《毘尼母》云：不滿斗半，若過三斗者，不成受持。然則諸部定量，雖無一指，然多以三斗、斗半為限。但此器名應器，須依教立。律云：量腹而食，度身而衣，趣足而已。言通增減，必準正教。世執小鉢者多，大者全希；豈非狹局貪著，數受多益之相；既號非法，不合說淨受持。
【譯文】四量是非《四分》中說：大鉢可容納三斗，小鉢可容納一斗半，中鉢的容量由此可知。此處所說的斗升容量並不固定。因為這部律是在姚秦時期翻譯的，當時姚秦使用周朝（姬周）的量制。若依照唐代的斗來折算，上等大鉢可容納一斗，下等小鉢容納五升。《十誦律》所定的斗量與《四分律》相同。又該律記載：下鉢可容納一鉢他（prastha，古印度容量名）的飯、半鉢他的羹湯，其餘可食之物（如小菜副食）佔半鉢他。《薩婆多論》說：關於鉢的容量，諸位論師有種種不同說法。但以一種解釋為正當標準，即一鉢他相當於十五兩飯。姚秦秤三十兩飯，相當於天竺粳米煮成的熟飯。當時眾人共同商討計議，認為上等大鉢可容納三鉢他飯、一鉢他羹湯，其餘可食之物半鉢他。三鉢他飯大約折合姚秦斗二斗；一鉢他羹湯加上半鉢他其餘食物，又是姚秦斗一斗。所以上鉢總共可容納三斗。律師說：其實並沒有所謂「其餘可食之物佔半鉢他」，而是直接說上等大鉢容納三鉢他飯、一鉢他羹湯；上方留出空餘之處以供進食，使手指不會觸碰到食物。至於中鉢與下鉢的容量，都可以依此類推得知。曾有人在店鋪市集見到一只精美的鉢，圓潤端正、十分討喜。律師說：佛陀最初出世時，僧眾還沒有鉢，佛陀敕令帝釋天，讓天界的巧匠工師在人間製作了十萬只鉢；店鋪裡見到的那只鉢，就是當時的天鉢，不是凡人所製造的。《毘尼母經》說：若不滿一斗半，或者超過三斗的鉢，都不構成合法的受持。由此可知，各部律典對於鉢容量的定量標準，雖然並非完全一致，但大多是以三斗到一斗半為限制範圍。然而此器物名為「應量器」（應器），必須依循教法規定而設立。律中說：應當估量自己的腹量而進食，度量自己的身材而穿衣，只要充足即可。此話兼通增減，但必須符合正教法度。世間僧人執持小鉢的人很多，執持大鉢的則極為罕見；這難道不是心量偏狹、貪著於頻繁接受他人布施以求多得利養之相嗎？這既然被稱為非法，便不應當作「說淨」（作淨施手續）或「受持」之法。

【202-0016】資持記/14b_下二#59
【原文】鴿色多別，今取青者。次科，先引律制。《四分》令以泥作熏鉢鑪，以灰平地作熏鉢場；安支，以鉢鑪覆上，以灰壅四邊手按令堅，以巨摩〔牛糞〕壅四邊燒。今多安鑪在下，僧圓籠覆上；籠中用鐵條橫架，安鉢在中，以竹烟熏之。而下，斥非。前列五種。棍鋧，古云燒成後入火鋧令牢也。
【譯文】鴿子的顏色有很多差別，這裡取青色的鴿羽顏色。第二科中，先引用律典的制度。《四分律》規定用泥土製作熏鉢的爐子，把泥灰平整鋪在地上作為熏鉢的場地；安放支架，用鉢爐覆蓋在上面，用泥灰填塞四周並用手按壓使它堅固，再用牛糞堆聚在四周燃燒。現今多半把爐子放在下方，用僧用圓籠覆蓋在上面；圓籠中用鐵條橫向架設，把鉢安放在中間，用竹煙來熏染它。「而」字以下，斥責錯誤的做法。前面列出了五種情況。「棍鋧」在古時是指燒成之後再放入火中淬鍊使它堅固。

【202-0017】資持記/14b_下二#60
【原文】但棍不磨者，準須熏已磨退，然後再熏；鐵鉢五遍，瓦鉢二遍；若但一熏掍令牢者，則色落受膩。油塗似今瓷器上油燒者。親下，證非，初引親聞證。此土行用，謂梵僧來此用也。五下，引文證。準下，例通澡瓶，亦熏為色。三中，初引《善見》。二指諸部。三示此方。
【譯文】如果只是混合燒製而不加研磨，依照標準必須熏過之後磨去粗糙部分，然後再次熏燒；鐵鉢要反覆熏五次，瓦鉢要反覆熏兩次；如果只是一次熏燒混合使它堅硬，那麼顏色容易脫落，而且表面容易沾附油膩。塗油的情況就像現今的瓷器表面上油釉燒製一樣。「親」字以下，證實其錯誤，首先引用親自見聞的事例來作證。所謂「此土行用」，是指西域梵僧來到此地所採用的方法。「五」字以下，引用文獻作證。「準」字以下，比照通用於洗手的澡瓶，也是經過熏製呈現出顏色。第三部分中，首先引用《善見律》。第二指引各部律典。第三指示此地的做法。

【202-0018】資持記/14b_下二#61
【原文】《業疏》云：西來鐵熏，由牢固者，解熏法也。量中，初科又三，初示三品。上下之間，即為中品。此下，二定斗不同，初取周斗。注指俗法者，《孫子算經》十粟為圭，十圭為抄，十抄為撮，十撮為勺，十勺為合，十合為升，十升為斗，十斗為斛。相因增法，示可準據。
【譯文】《業疏》中說：從西方傳來的鐵器熏法，是因為具有牢固的特性，這是在解釋熏烤的方法。在「量」這一段中，第一科又分為三部分，首先展示上、中、下三種等級。在上品與下品之間的容量，就屬於中品。「此」字以下，第二部分判定各種斗制的不同，首先採用周朝的斗制。註文中指引世俗的計量法，《孫子算經》記載：十顆粟為一圭，十圭為一抄，十抄為一撮，十撮為一勺，十勺為一合，十合為升，十升為斗，十斗為斛。這種相乘遞增的計量法則，說明是可以作為換算依據的。

【202-0019】01_行事鈔/10c_卷下之二#2
【原文】五加受法。《十誦》云：「大德一心念！我某甲，此鉢多羅應量受，常用故。」《善見》云：若無人時，得獨受持鉢。文準上。《僧祇》云：若十日內，捨故受新，十日一易。
【譯文】五加受法。《十誦律》說：「大德一心專念！我某甲比丘，此鉢多羅（應器）依應量法受持，作為常用之故。」《善見論》說：如果沒有其他比丘在場時，可以自己單獨對境受持此鉢，其白詞準照上述文句。《僧祇律》說：如果十天之內，捨棄舊鉢而受持新鉢，可以每十天更換一次。

【202-0020】資持記/14b_下二#62
【原文】準下，三會唐斗。唐朝雜令用姬周三斗為一斗。今此俗中例用唐斗，宜準為量。次科，初引《十誦》，上二句標同。謂三品大小也。又下，示異。彼明下鉢受兩鉢他，鉢他即梵國量名。準下一鉢他半，為周一斗，即唐三升三合強；
【譯文】「準」字以下，第三部分會通唐朝的斗制。唐朝的雜令規定，以姬周時代的三斗折算為一斗。現今在世俗中一律採用唐斗，應當以此作為衡量的標準。第二科中，首先引用《十誦律》，開頭兩句標明相同之處。這是指三種等級的大與小。「又」字以下，顯示不同之處。那部律說明下品鉢可以裝受兩鉢他，鉢他就是古印度梵國的容量單位名稱。依照下文換算，一鉢他半等於周斗的一斗，也就是唐升的三升三合多；

【202-0021】資持記/14b_下二#63
【原文】餘半鉢他，為周三升三合，即唐一升強，總計唐升四升已上為下品量。故註引《僧祇》合之。應知彼律四升，即據下品鉢他羅；他與多，音之轉耳。《僧祇》在宋朝翻，尺斗並依元魏，大同唐朝，故用四升為下鉢也。次引《婆論》會同《四分》，文為五段，初標示。論師即彼論自指。
【譯文】剩下的半個鉢他，折合為周斗的三升三合，也就是唐升的一升多，總計換算成唐升，四升以上就是下品鉢的容量。所以註文引用《僧祇律》來會通吻合。應當明白那部律所說的四升，就是依據下品鉢的容量鉢他羅來計算的；「他」與「多」只是音譯上的轉化而已。《僧祇律》是在宋朝翻譯的，當時使用的尺量斗制完全依據元魏，與唐朝大體相同，所以把四升作為下品鉢的容量。接著引用《婆沙論》來會同《四分律》，經文分為五個段落，首先予以標明指示。「論師」就是指該論典中自身的指稱。

【202-0022】02_戒疏/09d_卷二下之二#142
【原文】【記】戒緣，答中。去樹為基，明非取樹。「施」字平呼。「多受用」者，《律》云「尼拘律樹，多人往返，象馬車乘，止息其下」等。
【譯文】【記文】在戒緣問答的段落中。砍除樹木是為了整地打地基，說明並不是為了貪取木材。「施」字在此處應讀作平聲（施放鋪設之意）。所謂「多人受用」，正如《律》文記載「那是一棵巨大的尼拘律樹，往返的行人極多，大象、馬匹、車輛，都在樹蔭之下停歇避暑」等等。
