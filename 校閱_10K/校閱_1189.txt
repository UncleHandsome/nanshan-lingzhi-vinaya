# 校閱材料　第1189檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1189-0001】資持記/10a_中三下#27
【原文】通列四時。前後三種，大約不定。日中一種，佛佛常法；以住中道，假事表理故；凡所化儀，無不皆中。佛制下，正顯教意。上有三趣，地獄同鬼類。欲超三界，必斷六因。故制比丘不同彼食，令依極聖，出離可期。嗟彼愚人，多食晚食；肯斆諸佛，而甘同鬼畜，不知何意乎！
【譯文】通盤列出四個時段。前後三種時段，大概來說並不固定。唯獨正午這一種，是過去諸佛與未來諸佛永恆不變的法則；因為安住於中道，藉由世事來表徵真理的緣故；凡是教化的威儀，無一不是契合於中正之道。從「佛制」以下，正式顯明教戒的深意。上面經文列有三種世間趣（天、畜生、鬼神），地獄與餓鬼同類。想要超越三界，必須斷除六道的業因。故制比丘不同於那樣進食，令其依止至極的大聖，解脫出離才指日可待。可歎那些愚癡的人，大多喜歡在晚間進食；不肯效法諸佛，反而甘心等同於餓鬼畜生，真不知心裡是怎麼想的！

【1189-0002】資持記/10a_中三下#28
【原文】三中，《多論》，初釋時非時。四義中，初約日明出沒，餘三約乞食合宜不宜。二三約他事，第四就己行。又下，明時分不定。晝夜各九時〔且約相等〕，《增輝》引古解云：晝夜都十八時，一時有五十臘縛，十八時總九百臘縛，三十臘縛為一須臾。〔三百為十須臾，九百為三十須臾。〕事同者，同下《僧祇》故。〔《俱舍》一百二十剎那為一怛剎那。
【譯文】第三部分中，《多論》首先解釋適當時限與非適當時限。四種義理中，第一種是依據太陽來說明升起與落下，其餘三種是就乞食合不合適來說明。第二和第三種是就他人之事來說，第四種是就自己的行持而言。從「又」字以下，說明時間劃分並不固定。白天和夜晚各分為九個時辰〔暫且依照相等的時間來論〕，《增輝記》引用古人的解釋說：白天夜晚總共十八個時辰，一個時辰有五十臘縛，十八個時辰總共九百臘縛，三十臘縛為一個須臾。〔三百臘縛為十個須臾，九百臘縛為三十個須臾。〕事情相同，是因為與下文的《僧祇律》相同。〔《俱舍論》說一百二十個剎那為一個怛剎那。

【1189-0003】資持記/10a_中三下#29
【原文】六十怛剎那為一臘縛。三十臘縛為一須臾，三十須臾為一日夜。〕日下近地者，準《俱舍》，日月在須彌山半腹，去地四萬由旬；準此則無下義，但日行極南，望之似下；以天上南北相去有一百八十道，日於此中來去，以分八節；
【譯文】六十個怛剎那為一個臘縛。三十個臘縛為一個須臾，三十個須臾為一晝夜。〕太陽落至接近地面的說法，依照《俱舍論》，太陽和月亮在須彌山半腰，距離地面有四萬由旬；依照這個說法就沒有落至地下的意義，只是太陽運行到最南邊時，看起來好像落了下去；因為天上南北相距有一百八十條運行軌道，太陽就在這當中來回運行，以此劃分出八個節氣；

【1189-0004】資持記/10a_中三下#30
【原文】且為夏至日在北第一道，向南行超四十五道是立秋，又越四十五道秋分，又越四十五道是立冬，又越四十五道極南第一道是冬至。〔從北至此熱減寒至甚也，所以寒者，一云南州北闊，日光多故；南狹，日光少故。又云：近須彌山邊氷山故，又云去人遠故。
【譯文】暫且以夏至為例，太陽在最北的第一條軌道，向南運行越過四十五條軌道就是立秋，再越過四十五條軌道就是秋分，再越過四十五條軌道就是立冬，再越過四十五條軌道到達最南的第一條軌道就是冬至。〔從北面運行到這裡炎熱減退而寒冷至極，之所以寒冷，一種說法指南瞻部洲北部寬闊，受日光照耀多；南部狹窄，受日光照耀少。另一種說法：因為接近須彌山邊的冰山；又有一種說法是距離人太遠的緣故。

【1189-0005】資持記/10a_中三下#31
【原文】從北却迴至立春春分立夏夏至，各經四十五道；還至極北，如是終而復始。四十。《時非時經》即《阿含》別品，是以雙標。彼約脚影定一年中日夜長短，須者尋之。準俗者，此方亦以十五日為一氣，一氣有三候，一候有五日，三氣為一節〔四十五日〕，一年有四時八節二十四氣七十二候三十六旬。
【譯文】從北面往回返運行到立春、春分、立夏、夏至，各經過四十五條軌道；又回到了最北邊，就這樣循環往復。第四科。《時非時經》就是《阿含經》的個別篇章，所以並列標示出來。該經依據腳影長短來測定一年之中白天黑夜的長短，需要的人可以去查閱。依照世俗之法，此方也是以十五天為一氣，一氣有三候，一候有五天，三氣為一節〔四十五天〕，一年有四季、八節、二十四氣、七十二候、三十六個十天。

【1189-0006】資持記/10a_中三下#32
【原文】《僧祇》脚影者，立日中以脚步影也。刻漏者，量水為數，隨時增減，滴漏定時，謂之刻漏。釋初緣中，引律定時。云至中者，此明極限，食必中前。四天下者，《俱舍》云：日轉四天下，正照一面，傍照兩面，長背一面，又云：北洲夜半，東洲日沒，南洲日中，西洲日出。
【譯文】《僧祇律》的腳影法，是在正午時分站立，用腳步來測量影子。刻漏，是量度水滴的數量，隨時令增減，靠水滴漏定出時間，這叫做刻漏。在解釋最初因緣中，引用戒律來確定時間。所說「至中」，這是指時間的極限，進食必須在正午前結束。四天下的說法，《俱舍論》說：太陽輪流照耀四天下，正照著一個洲，側照著兩個洲，長久背對著一個洲。又說：北俱盧洲是半夜時，東勝神洲是日落，南瞻部洲是正午，西牛賀洲是日出。

【1189-0007】資持記/10a_中三下#33
【原文】四洲皆約從明至中，故云亦爾。下引《僧祇》。正中犯吉，故知受食必在中前；經中食時，乃當辰已；古德卯齋，護之彌急；有聞諸佛日中食，便謂中前非法，蓋不知教也。又有訛云不過鍾食，便聽鍾奉戒；況打鍾不定，何足為準！瞬即動目少時，髮謂影移少地。
【譯文】四大部洲都是以從天亮到正午為進食時段，所以說「也是如此」。下面引用《僧祇律》。正午時分受食犯突吉羅罪，由此可知接受食物必定要在正午之前；經中所說的進食時間，正相當於辰時和巳時；古德實行卯時用齋，防護得更為急切；有人聽聞諸佛是在正午進食，便認為正午前進食不合教法，這大概是不懂教理吧。又有人訛傳說只要鐘聲未過就可以進食，便完全聽從鐘聲來奉持戒律；何況敲鐘時間本就不確定，哪裡足以作為準則呢！「瞬」就是眼睛眨動的極短時間，「髮」是指影子移動如同一根頭髮般細微的距離。

【1189-0008】資持記/10a_中三下#34
【原文】義淨《內法傳》云：宜於要處安小土臺，圓闊一尺，高五寸；中插細杖，或時食上竪竹箸，可高四指；取正午之影，畫以為記；影過畫處，便不合食；西方在處悉有之，名薜攞斫羯羅，譯為時輪。三中。文列四藥，各有時非時。時藥，約中前，後非時。七日，限中是時，過限非時。
【譯文】義淨法師的《南海寄歸內法傳》說：應當在重要的地方安置一座小土臺，圓形寬一尺，高五寸；中間插上一根細杖，或者有時在食案上豎起竹筷，大約四指高；取正午時的影子，畫一條線作為標記；影子只要超過畫記處，便不合適再進食；西方各處都有這種設施，名字叫做薜攞斫羯羅，翻譯為時輪。第三部分中。文中列出四種藥物，各有其適當時限與非適當時限。時藥，以正午之前為適當時限，過午則為非適當時限；其後的非時藥與七日藥，在各自期限內為適當時限，超過期限則為非適當時限。

【1189-0009】資持記/10a_中三下#35
【原文】盡形者，疏云：有病加服名時，無病輒服名非時。若非口法，從時食論；故下，注云犯有輕重是也。注文分二，初別示盡形。並下，通明三藥。故下，引證，即不受食戒開文。顯知四藥通制也。四中，初科。《五分》開甞者，謂非時中約咽結犯，甞但治舌故。二中。《十誦》六戒，教人同犯。
【譯文】盡形壽藥，戒疏說：有病時作法（加口法）服用稱為適當時限，無病隨便服用稱為非適當時限。如果不作口頭法事，就依照時藥論處；所以在下文中，注文說犯戒有輕重之分就是這個意思。注文分為兩部分：首先分別指出盡形壽藥。從「並」以下，通盤說明其餘三種藥。從「故」以下，引用證據，就是不受食戒中的開許文句。顯然可知這四種藥都是受到戒律普遍限制的。第四部分中，是第一個段落。《五分律》開許品嘗，是指在非適當時限中，是依吞嚥來結罪，品嘗只是舌頭接觸的緣故。第二部分中。《十誦律》有六條戒，教唆他人犯戒與自己犯戒相同。
