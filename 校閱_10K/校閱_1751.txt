# 校閱材料　第1751檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1751-0001】03_業疏/13a_卷三之二#63
【原文】文云「看如父」者，世父疎通學務，道父開授慧明，喻在同也。如俗律名例於其師，如世叔父母者，立差降也。終次連枝，葢非疎越。言敬重瞻視者，正教明告，互相敦遇，微生慢心，不受法化也
【譯文】律文中說「視師如父」，世俗的父親通達疏導世學事務，佛道的法父開示傳授智慧光明，以世父為喻是取其養育引導義同。至於世俗法律的「名例律」中對待師長，比照世間叔父、叔母之禮，是確立等次差降。終究使同氣連枝的兄長居於其下（犯兄之罪次於犯師），足見對師長絕非疏遠輕忽。所謂「敬重瞻視」，是佛陀正教明確告誡，師弟雙方必須互相誠懇禮待，若微細生起傲慢懈怠之心，便不能承受正法教化了。

【1751-0002】03_業疏/13a_卷三之二#64
【原文】三敬攝中：初釋父想。引俗律證者，彼有名例，律犯本師，同叔父母，顯異親生，故云差降也。終次連枝，謂犯兄次之，顯師義重，故云非疎越也。「言」下次釋敬視
【譯文】在第三項「敬重攝受」中：首先解釋視師如父的想法。引證世俗法律，是因為世俗刑律中有名例篇，法律規定若侵害犯及自己的老師，罪責比照侵害叔父、叔母，以此顯明與親生父親有所區隔，所以說是差降。所謂「終次連枝」，是指侵害兄長之罪又次於侵害師長（師長地位高於兄弟），以此顯明對老師的情義深重，所以說並非疏遠放任。自「言」字以下解釋互相敬重瞻視。

【1751-0003】03_業疏/13a_卷三之二#65
【原文】又「病比丘」下，立資弟也。由病致死，緣須待接，損喪道器也
【譯文】又自「病比丘」以下，是確立設立弟子之制。由於有比丘生病無人照料致死，在因緣上必須有人扶持照應，否則將損喪修道之法器。

【1751-0004】03_業疏/13a_卷三之二#66
【原文】立弟子中初科：資即訓取，謂取法於師。因病致死，發起之由
【譯文】在「確立弟子」的第一科中：「資」字訓詁為「取」，是指向師長求取法益。因為比丘生病無人瞻視導致殞命，這是制立師弟相依制度的發起由來。

【1751-0005】03_業疏/13a_卷三之二#67
【原文】言弟子者，學後解生，故得名也。所以師名隨本音者，此土本無，故不可譯。俗中博士，微有相扶，然備束脩，乖則非禮；佛法不爾，導以義方，開示出道，過恒俗訓，若行贈遺，則是邪緣，故從本也。弟子受學，義相似也，故從此方之言
【譯文】所謂「弟子」，是因為隨師學修之後智慧生起，所以獲得此名。之所以對和尚師尊之名保留梵文原音，是因為東土本土本無此種身分，所以不可直接套譯。世俗中的「博士」，雖稍有相近之處，然而世人備辦肉脯束脩為酬，若有違背便被視為失禮；佛法之中絕不如此，師僧以至高義理導引學子，開示出離生死之道，遠遠超越尋常世俗教訓，若行賄賂饋贈等世俗之禮，反倒成了邪命之緣，所以師名保留梵本原音。而「弟子」從師領受教誨修學，其意趣與世俗相類似，所以採用了此方本有的稱謂。

【1751-0006】03_業疏/13a_卷三之二#68
【原文】次科：初釋資名，在後故為弟，從生故為子。「所」下次辨師名。出家之法，始於西梵，故和尚名此土本無。下舉俗禮，明不翻之意。自漢已來，國家多置五經、諸子博士，即學者之師。《禮記》云「君子知至學之難易，而知其美惡，然後能博喻，然後能為師」。束修即肉脯，古者用為見師之禮，今則名通金帛等物，故《論語》云「自行束修已上，吾未嘗無誨焉」。師名恐濫，故不取之；弟子義同，故可比用
【譯文】在第二科中：首先解釋弟子之稱，「居於師長之後」所以稱為「弟」，「由教法化生」所以稱為「子」。自「所」字以下辨析師長之名。出家求道之法源始於西方天竺，所以「和尚」這一名號在此土本來沒有。以下引舉世俗禮儀，說明不直翻的用意。自漢代以來，朝廷多設置五經、諸子「博士」，也就是求學者的師長。《禮記》說「君子懂得進修學業的難易，並知道資質的高下美惡，然後才能廣泛設喻教導，然後才能為人師表」。「束脩」即是成束的肉脯，古代用作初次拜謁師長之禮，後世則通稱金帛禮物，所以《論語》說「只要自行奉上束脩以上的禮物，我未嘗不給予教誨」。佛家師長之名恐與世俗混淆相濫，所以不採用博士等名；而弟子領受教導的意涵與世俗相同，所以可以借用此方之詞。

【1751-0007】03_業疏/13a_卷三之二#69
【原文】師弟相攝云敬重者，以出道在心，形雖在卑，以懷道故，敬而後授，故無虗往也。彼我和敬，正法由生，光大遠世，皆賴開悟，深有致也
【譯文】師徒之間互相關照攝受之所以稱為「敬重」，是因為出離生死之道根源於內心，弟子身分雖然卑下，但因其懷抱道心，師長先存恭敬然後傳授法教，所以不會徒勞無功。彼此和合恭敬，正法才能由此滋長顯現，發揚光大於後世，全都仰賴教導開解省悟，這具有極為深刻的道理。

【1751-0008】03_業疏/13a_卷三之二#70
【原文】三中：初明師敬資意。以文令共相敬重，恐疑反倒，故特示之。尊卑據形，相敬約心，由心懷道，不可輕故。無虗往者，言資必受教也。「彼」下次釋功益，展轉開悟，相生不絕，至於無窮
【譯文】在第三項中：首先說明師父敬重弟子的深意。因律文命令師弟雙方「共相敬重」，恐人懷疑尊卑顛倒，所以特別加以明示。尊卑貴賤是依外在形儀而言，互相敬重是就內在心志而言，由於內心懷抱道法，決不可輕慢。「無虛往」是指弟子必定真誠受教而無虛度。自「彼」字以下解釋其功德利益，如此展轉開示覺悟，燈燈相傳綿延不絕，以至於無窮無盡。

【1751-0009】03_業疏/13a_卷三之二#71
【原文】善見》不請起過者，為束惡緣，制請結之，無輒離也。餘諸法訓，廣如受後及《行事鈔》也
【譯文】《善見論》說若不依禮請師便會生起過咎，這是為了約束惡緣，所以制定必須正式請師建立師徒關係，不得隨意捨離。其餘各項法式訓誨，詳廣內容如受戒之後的章節以及《行事鈔》中所載。

【1751-0010】03_業疏/13a_卷三之二#72
【原文】釋制請中：先無請法，度已起過，和尚呵責，便云「誰請汝耶？」因制請之。束惡緣者，令不作過也；請結之者，結為父子也。指如受後，即〈依止〉中；事鈔，即〈師資篇
【譯文】在解釋「制定請師」中：原先沒有請師之法，度人出家之後弟子生起過咎，和尚呵斥責怪時，弟子便頂撞說「是誰請你當師父的？」佛陀因此制定必須正式請師。「約束惡緣」，是使弟子不致放逸造過；「請師建立關係」，是結合成法身父子的關係。文末指引「如受戒之後」，即指〈依止篇〉；指引「事鈔」，即指〈師資篇〉。

【1751-0011】03_業疏/13a_卷三之二#73
【原文】文列請法在僧中，欲令受者覩相發敬也。必預須受前一年一月，亦無傷也。人云「一席加法，不延久者，恐心怠也」，於義似失。次第隨禮者，以凡多慢習，戒在敬慎，故折伏形骸，希求淨法，後必思犯，非我輒授也
【譯文】文中列明請師法式要在僧眾大眾之中進行，是為了令受戒者親睹僧伽威儀法相而生起恭敬心。若必定要在受戒前一年或一月預先延請，也無妨礙。有人主張「請師加法須局限在受戒同一法席中進行，不得提早延及久前，是恐受者時間一久心生懈怠」，這在義理上似乎有所欠缺。依序隨位禮拜，是因為凡夫大多具有傲慢習氣，受戒的要旨在於敬奉謹慎，所以必須折伏傲慢之形體身軀，一心希求清淨正法，受戒之後每逢想犯戒時便會反思：這不是師長隨便傳授給我的。

【1751-0012】03_業疏/13a_卷三之二#74
【原文】修敬中：初釋僧中，初出今解，僧、私兩通。預須受者，謂先私請也。「人」下次斥非，彼局僧中，不通先請。畢世師資，豈容心怠？故云似失，其實失也。「次」下次釋徧禮，初令盡敬，意在後持
【譯文】在「修敬」之中：首先解釋在僧眾中請師，先提出當前的見解，認為大眾僧中與私下延請兩皆融通。「預先受師」是指在受戒前私下延請。自「人」字以下斥責錯誤見解，彼說局限於受戒時的僧中，不通融受戒前預先請師。然而終身依止的師徒關係，豈能隨便任由弟子起懈怠之心？所以文中說「似失」，其實就是錯失了正理。自「次」字以下解釋遍禮大眾僧，受戒之初令其竭盡敬意，用意在於受戒之後能謹慎奉持。

【1751-0013】03_業疏/13a_卷三之二#75
【原文】就加法中，請可為二
【譯文】就立法加被之法（加法）中，分為「請師」與「答可」兩部分。

【1751-0014】03_業疏/13a_卷三之二#76
【原文】初請之法，律制傍教，縱屏令誦，識其文義，後在僧中，如法致請，亦是儀也
【譯文】第一項請師之法，律中規定應由旁人教導其文辭，縱然私下屏退眾人教他熟誦、理解文句義理，隨後在僧眾之中如法懇切致請，這也是合符威儀的。
