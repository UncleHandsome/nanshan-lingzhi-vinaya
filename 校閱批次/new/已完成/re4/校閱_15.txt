# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【15-0002】03_業疏/17a_卷三之六#143
【原文】問：受體乃在白四，如何方問「能」者？答：計實如問。但機鈍須示，不贊不知。上機善達教旨，不勞示相，如善來三語也；鈍濁有生，更須明示。如不顯然，文中但云受戒，知戒何境？故前止四境，後行四相，分明曉喻，後猶輕陵，何況不語？又不作誓，知誰不犯？故不徒設也。
【譯文】問：納受戒體明明是在白四羯磨之時，為什麼羯磨完畢之後才詢問「能持否」呢？答：若按常理推度確實如你所問。但因為受戒者根機遲鈍必須予以開示，若不輔助點撥他就無法了知。上根之人善於通達教理意旨，不勞費心開示相狀，就像「善來比丘」或受「三歸語」那樣即可得戒；而鈍濁執著的眾生，更必須明確開示。如果不顯明告知，文辭中只說「受戒」，他又哪裡知道所防護的戒是針對什麼境界？所以前面先說明止持的四重境緣，後面闡明作持的四依相狀，如此分明顯白地曉喻開導，事後尚且有人輕慢陵犯，更何況根本不對他說呢？而且如果不立下誓願，又怎能保證日後誰不違犯？所以這絕非徒然設立的。

【15-0003】03_業疏/17a_卷三之六#144
【原文】問中，先受後問，義似倒故。答中，初通敘二機須否，贊即是助。「鈍下」，次別明鈍機須意。有生，謂著有眾生。羯磨言通，非列不顯。若此猶犯，況不爾邪？
【譯文】在提問中，先受戒而後發問，在義理上看似顛倒之故。在回答中，首先通泛敘述兩類根機是否需要，所謂「贊」就是指贊助、扶助。自「鈍下」句起，接著分別說明鈍根眾生之所以需要的用意。「有生」是指執著於有為世間的眾生。羯磨的言辭通泛，若不一一條列便不能顯明其相狀。若是像這樣明確開示猶且還會違犯，更何況不這樣做呢？

【15-0004】03_業疏/17a_卷三之六#145
【原文】就衣開中，云「長利」者，對本制外，餘皆長也。「檀越施衣」者，不問道俗，持來淨施，故任納也。「割壞衣」者，前通俗服，此專道相，故二列也。
【譯文】在衣服開許的文句中，所謂「長利」，是相對於根本制戒之外，其餘的都屬於多餘長物。「檀越施衣」，是不管出家人還是俗人，拿來作為清淨布施，所以聽任受納。「割壞衣」，前一句通指世俗的衣服形式，這一句專指僧道法服的相狀（經過裁割截斷以壞其色相），所以分開並列。

【原文】開中，初云「長利」，即總舉；「檀越施」等，即別相納受也。
【譯文】在開許的文句中，起初說「長利」就是總括標舉；「檀越施衣」等等，就是指各別相狀的受納。

【15-0008】03_業疏/17a_卷三之六#149
【原文】「若僧差」者，即僧次請也。為解脫故出家受戒，得往訃也；反此不合，名盜。「下次」，「若送食」者，至寺設也。「月八日、十五日食」者，謂黑白二月俱有三日，文少十四日，《尼律》具三，此惡日也，故須供齋，如前八戒說之。「月初日食」，彼國重之，至其異設，多陳坊寺，如此方俗正月元日、三月三日、至九月九日，亦須知也。「若僧常食」，隨有少多，準年為量也。「若請食」者，召往俗家，即別請也。
【譯文】「若僧差」，就是指依僧次輪請赴供。為了求得解脫而出家受戒的人，才可以前往應赴；違背這點便不相合，會被稱為盜食。自「下次」句起，「若送食」，是指施主送到寺院中設供。「月八日、十五日食」，是指黑月、白月各自有三天齋日，此處疏文缺少了「十四日」，《比丘尼律》中具備這三天，這些是惡鬼得勢的惡日，所以必須供齋，如同前面八關齋戒中所說。「月初日食」，在印度彼國非常重視，到了這天有特殊的陳設，多在僧坊寺院中供養，如同此方漢地風俗中的正月初一、三月三日、乃至九月九日重陽節，這也是應當知曉的。「若僧常食」，無論多少，是以一年為期定量供給的常住伙食。「若請食」，是指施主招請僧人前往俗家，這就是個別請僧（別請）。

【15-0009】01_行事鈔/12c_卷下之四#44
【原文】《十誦》：無和尚人，受戒得戒，作法僧犯罪。《薩婆多》云：先請和尚，受十戒時，和尚不現前，亦得十戒；若聞死者，不得。受具，不現前不得戒；若僧數滿，設無和尚，亦得戒。《善見》：無和尚受者，得戒，得罪；黃門為和尚，亦爾。《伽論》云：白衣為和尚，與白衣受，得戒，得罪；非出家人，亦爾。《薩婆多》云：不除鬚髮、無衣鉢，受者得戒，得罪。若準《四分》，並不開之；律云：不名受具足戒也。《十誦》：男子作女人威儀，如男子受，得戒，得罪；女想反上。《五分》：若自截男根，若留一卵，得受；全無者，滅擯。《五百問》云：壇上師僧，或著俗服、或犯禁戒，若受戒人知是非法，不得；不知者，得。弟子著俗服，當時不問者，得。《伽論》云：不知和尚是賊住，依彼受戒，得戒；諸比丘犯吉羅。本犯戒人、本不和合人、非出家人為和尚，亦爾。
【譯文】《十誦律》記載：沒有和尚的人，受戒仍能得戒，但為其作法的僧眾犯過失。《薩婆多論》說：事先迎請了和尚，在受沙彌十戒時，和尚不在現場，也能得十戒；但如果聽聞和尚已死，則不得戒。受具足戒時，和尚不在現場則不得戒；但如果作法僧數充足，即使沒有和尚，也能得戒。《善見律毘婆沙》說：沒有和尚而受戒者，能得戒，但與會僧人得罪；以黃門（閹人或性功能障礙者）為和尚，也是如此。《摩得勒伽論》（伽論）說：在家人作為和尚，為在家人受戒，能得戒，但作法者得罪；非出家人作為和尚，也是如此。《薩婆多論》說：不剃除鬚髮、沒有衣鉢而受戒者，能得戒，但得罪。若依照《四分律》，則完全不開許這些情況；律藏說：這不稱為受具足戒。《十誦律》記載：男子現女人威儀，若仍按男子法受戒，能得戒，但得罪；若是女想則反之。《五分律》記載：如果自己截斷男根，若留有一顆睪丸，准許受戒；如果全無睪丸者，予以滅擯。《五百問經》說：戒壇上的戒師僧，有的穿著俗服、有的毀犯禁戒，如果受戒的人明知其為非法，則不得戒；若受戒人不知情，則能得戒。弟子穿著俗服，戒師當時未予盤問指責者，能得戒。《摩得勒伽論》說：不知和尚是賊住（冒充僧人盜法），依止他受戒，能得戒；但參與羯磨的諸比丘犯突吉羅罪。若是根本犯重戒之人、原本破僧不和合之人、非出家人作為和尚，也是如此。

【15-0010】01_行事鈔/12c_卷下之四#45
【原文】《十誦》：一界內，四人一時受具者，得四處展轉與欲。若一比丘一處坐，足四處僧數；一處一人，作羯磨被四眾者，如以材木床榻，連接四界，坐上足四處數；得被四人一切羯磨，皆如法也。《摩得伽》云：頗有比丘，與四處人說戒、受戒、作羯磨，為得不？答：得；乃至五處亦爾；八人、十二人、十五人、十八人，亦爾。
【譯文】《十誦律》記載：在一個結界之內，有四個人同時要受具足戒時，可以分為四個處所輾轉互相與欲（轉達同意）。如果有一位比丘坐在某處，能充實四個處所的僧數；每一個處所各有一人，作羯磨加被這四個壇場的僧眾時，就如同用木材床榻連接四個界區，坐在其上能補足四個處所的僧數；如此能夠對四人進行一切羯磨，全部都合乎戒法。《薩婆多部毘尼摩得伽》說：是否可能有一位比丘，同時為四個處所的人說戒、受戒、作羯磨，這樣可行嗎？回答：可行；乃至五個處所也是如此；八人、十二人、十五人、十八人的處所，也都是如此。

【15-0011】01_行事鈔/12c_卷下之四#46
【原文】《善見》：沙彌犯重，得出家；除壞尼淨行，不得。準此，開學悔也。不得受具。
【譯文】《善見律毘婆沙》說：沙彌犯了重罪（波羅夷），仍開許重新出家作沙彌；但若是毀壞比丘尼的淨行，則不得出家。依照此理，是開許其學悔；但終究不得受具足戒。

【15-0012】01_行事鈔/12c_卷下之四#47
【原文】二聖法通局。《四分》：羯磨略則三種，廣則八品。加減不成，聖印一定；如單白，不得加白二；白二，不得作單白等。《僧祇》、《十誦》：加得成就；應作單白，白二、白四者彌善。減則不成。《僧祇》：加一中間羯磨，亦名求聽羯磨。《明了論》中間亦同。解云：謂在單白、白二之間，又加白羯磨，唱所立事，不問聽許不遮。餘三羯磨同《四分》。又云：中間、直白，此二羯磨，三人等通作；餘三必四人已上。《四分》：羯磨唯加三人，不得僧舉僧；若諫，法通多少。《十誦》中，羯磨得加四人以上受具。《僧祇》：不聽與欲人多，坐僧少者，不成。《五分》：聽多人集，少持欲來。《僧祇》：轉欲即失。
【譯文】二聖法通局。《四分律》中：羯磨法簡略而言有三種，廣泛而言有八品。僧團法印已經固定，增加或減少羯磨層次都不能成就；例如單白羯磨，不得加碼作白二羯磨；應作白二羯磨的，不得減作單白羯磨等。《摩訶僧祇律》與《十誦律》則認為：增加層次仍能成就；原本應當作單白羯磨的，若作成白二、白四羯磨則更加妥善。若減少層次則不能成就。《摩訶僧祇律》中：增加了一種「中間羯磨」，也稱為「求聽羯磨」。《律二十二明了論》中的中間羯磨也是相同的意思。解釋為：是指在單白與白二之間，又加上宣告僧事的白文羯磨，只宣唱所要辦理的事項，而不詢問眾僧是否聽許、有無異議阻攔。其餘三種羯磨則與《四分律》相同。又說：中間羯磨、直白羯磨，這兩種羯磨，三人僧等都可以共通實作；其餘三種羯磨則必須在四人以上僧眾。《四分律》認為：羯磨最多只能同時加被三人受戒，不得由全體僧眾一齊舉發全體僧眾；若是諫斥過惡，其法則不拘人數多少。《十誦律》中，羯磨可以加被四人以上同時受具足戒。《摩訶僧祇律》說：不准許委託與欲的人數過多、而現場就座的比丘太少，否則羯磨不能成就。《五分律》說：准許多人聚集在一起，由少數人代持其與欲前來。《摩訶僧祇律》說：與欲一旦轉託給第三人，該與欲隨即失效。

【15-0013】01_行事鈔/12c_卷下之四#48
【原文】三明重犯。《四分》：戒有重受，亦有重犯。文云：如前，後亦如是。尼摩觸云：隨觸，一一波羅夷。《十誦》：不重犯，由戒不重受故。犯淫戒已，更犯淫者，吉羅；犯盜、殺人、大妄，還得三重。文云：學悔尼犯僧殘，請比丘來，與我摩那埵、出罪等。下篇，隨輕重也；初篇，後犯但吉羅。《僧祇》亦爾。
【譯文】三明重犯。《四分律》認為：戒體有重複納受的情況，也有重複犯戒的情形。律文說：如前面所犯，後面再犯也是如此。比丘尼摩觸戒說：隨每一次觸犯，一一結為波羅夷。《十誦律》則認為：不會重複犯重罪，因為戒體不能重複領受的緣故。犯了淫戒之後，再度犯淫者，只結突吉羅罪；若犯了盜戒、殺人戒、大妄語戒，則依舊各結成重罪（合得三重波羅夷）。律文說：正在學悔的比丘尼又犯僧殘，請求比丘前來，為我行摩那埵、作拔罪出罪等法。在僧殘罪以下的篇章，隨著戒條的輕重結罪；至於初篇（波羅夷重罪），事後再犯就只結突吉羅。《摩訶僧祇律》也是如此規定。

【15-0015】01_行事鈔/12c_卷下之四#50
【原文】《僧祇》有二：初明七日，同於《四分》。後明事訖，便用中間別法；任前緣事未了，法在，不還者得；必非破戒，三寶正緣故。文云：「大德僧聽！某甲比丘，於此處雨安居。若僧時到僧忍聽：某甲比丘於此處雨安居，為塔事、僧事出界行，還此中住。」「諸大德！某甲比丘，為僧事、塔事出界行，還此處安居；僧忍，默然故。是事如是持。」
【譯文】《摩訶僧祇律》有兩種請假法：首先說明七日法，與《四分律》相同。隨後說明事情結束後，就採用中間的特別法規；任憑先前的緣由事務尚未辦妥，只要羯磨法效仍在，不返回安居處也是合法的；因為這絕非為了破戒，而是為了三寶的正當因緣之故。羯磨文說：「大德僧聽！某甲比丘，在此處進行雨期安居。若僧事時機已到，僧眾聽許：某甲比丘在此處進行雨安居，因佛塔之事、僧團之事出界行走，仍回此處中居住。」「諸位大德！某甲比丘，因僧事、佛塔事出界行走，仍回到此處安居；僧眾已經准許，以默然之故。此事當如此受持。」

【15-0016】01_行事鈔/12c_卷下之四#51
