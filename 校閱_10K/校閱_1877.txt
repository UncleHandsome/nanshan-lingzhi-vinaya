# 校閱材料　第1877檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1877-0008】03_業疏/20b_卷四之三#80
【原文】本有前事，可牒緣成；既無實緣，不可虗牒：一則不可倚傍，二則本無實緣，三則不知期限，四則妄受僥倖。一向不合也，如律無事及減年等，皆非法緣，加羯磨不得
【譯文】本來已有先前的事由，才可陳詞事緣而成法；既然沒有真實事緣，便不可虛構陳詞：一是不合借端依附，二是根本無真實事緣，三是無從預知期限，四是妄受法而心存僥倖。這全然不合戒法，如同律中無事空作以及未滿年齡等，皆屬非法之緣，施行羯磨無法成就。

【譯文】解釋的首段文字中，首先敘述非法的過咎。自「一則」以下列舉過失有四點：凡行受日法，一須事緣現前，二須確鑿真實，三須明知日數，四須合乎教法。如下文舉例，律中無事徒具法式則羯磨不成，年歲未滿受戒則不能得戒。

【譯文】第二段中，詰難者以安居時分配房舍若有剩餘、應當為未來僧眾代受為例，比照現在的懸受怎會不成就？答文中「對事進不」，是指僧人來與不來無法確定，以此顯明現在的受日法有法定儀軌開許成就，必須具備真實事緣以相應於法規。

【1877-0012】03_業疏/20b_卷四之三#84
【原文】五百問》中：夏初即受七日、三十九日法好，臨行受者亦得。若無法者，白日出界，夏雖不破，要須懺悔。準此，似是懸受。然彼出界要須受日，不為宿也。若得懸受，何以《十誦》云「無佛所聽緣，受日出界，經明相出破夏」也？以文證前，本非受宿也
【譯文】《五百問》中說：夏初即受七日、三十九日法為好，臨出發時受法亦可。若無受法，白日出界夏雖不破，但必須懺悔。照此看來，似乎容許懸受。然而彼處所指出界必須受日，並非為了留宿。若可懸受，為何《十誦律》說「若無佛陀所聽許的因緣，受日出界，歷經黎明破曉（在界外過夜至天明）便算破夏」呢？以律文印證前義，彼處本非為了留宿而受法。

【1877-0013】03_業疏/20b_卷四之三#85
【原文】三中初引論文。詳彼夏月有緣白日出幹，亦先請法表非專擅；而云「好」者，謂聽許也。不受而出須懺悔者，謂犯吉也。「準」下以義決。初詳其文勢似是而非：一彼宗夜法，今言受日，顯非為宿；二白日出界無法尚犯，顯是制急。「若」下引律反質，驗非懸受，以《五百問》宗《十誦》故
【譯文】第三點中，首先引述論典之文。審究彼論夏月有事緣白日出界辦事，亦須預先請法以表明並非擅專；文中說「好」，是指聽許准行。不受法而出界須懺悔，是指犯了突吉羅罪。自「準此」以下依義理決斷：首先詳察其文勢似是而非：一是彼宗計算法本是夜法，此處言受日，顯然非為留宿；二是白日出界若無作法尚且犯戒，顯明制規嚴格。自「若得懸受」以下引律文反質，驗證並非懸受，因為《五百問》宗承《十誦律》的緣故。

【1877-0022】03_業疏/20b_卷四之三#94
【原文】答：此謂同事暫往即還，恐疑輙往，故白殘夜；非謂異事本無心受，何得白行？若本三寶俱須經營，作法之時文中含攝，是俱有心，法復通也
【譯文】答：這是指同一件事暫時前往即刻返回，唯恐他人疑其擅自前往，所以稟白尚有殘餘夜數；並非是指原本無心受法的別樣事情，怎能白告一下便自行前往？如果原本三寶之事皆須經營，作法之時文辭中已涵蓋兼攝，這是皆有受法之心，法規便相通可用。

【1877-0023】03_業疏/20b_卷四之三#95
【原文】答中初正釋彼文。夜限未竟，故曰殘夜；續用須白，用息眾情。此乃一緣，本法在故；別緣無法，何得輙通？「若」下別出通互。作法通牒，後用皆聽
【譯文】答文中首先正面解釋彼律之文。夜數期限未盡，所以稱為「殘夜」；繼續使用必須白告，是為平息大眾的疑慮。這是一件事緣，本法尚在的緣故；別的事緣並無受法，怎能擅自通用？自「若本三寶」以下，另外指出相通互用的情形：作法時通盤陳牒包攬，日後使用皆獲聽許。

【1877-0024】03_業疏/20b_卷四之三#96
【原文】故《十誦》云：比丘受日到聚落中，七夜未盡，作事未竟，來還白佛。因聽餘殘夜去，云「我受七夜，二夜已過，餘有若干夜往彼出界」。既云「所作事未竟」，明知本事不可雜妄也
【譯文】所以《十誦律》說：比丘受日前往聚落村舍，七夜未滿，事情尚未辦完，回來稟白佛陀。佛因聽許使用殘餘夜數前往，說：「我受了七夜，兩夜已過，尚餘若干夜前往彼處出界。」文中既然說「所作之事尚未辦竟」，明知本來的事緣不可雜亂妄用。

【1877-0025】03_業疏/20b_卷四之三#97
