# 校閱材料　第428檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【428-0001】資持記/05a_上四#38
【原文】準〈釋相〉中，地卑濕處，開床設禮，榰脚八寸，餘則不聽。容有此緣，不可一定，故令隨處。眾具中。令準前者，即上《僧祇》、《四分》。白告中。準下略法，令於小食時白。上座白者，律文正制。今下當時所行，令準用也。
【譯文】依〈釋相〉篇中所說，地勢低窪潮濕的地方，開許設床而禮拜，床腳高八寸，其餘情況則不允許。容許有這種因緣，不可一概而論，所以讓隨處斟酌。「眾具」一段中。教人依準前文，就是上面《僧祇律》、《四分律》所說。「白告」一段中。依準下文略法的內容，讓在早粥（小食）時白告。「上座白」這一句，是律文正式的規定。「今」字以下，是當時所行的做法，讓依準採用。

【428-0002】資持記/05a_上四#39
【原文】今時維那白已，上座依下略法中文，復加勸勉，亦可準行。然策眾之語，當隨機要，激動時情，不必謹誦。指〈僧網〉者，前云每至說晨，令知事點檢僧數，眾主上座親自按行等。集僧中，初科，前明盡集。不局等者，即大小同行法；下約二處集，即是別法；兩明其相，意令通曉。
【譯文】現在的做法是：維那白告之後，上座依下文略法中的文句，再加勸勉，也可以依準實行。不過激勵大眾的話，應當隨順時機的要點，激動當時的人心，不一定要謹慎地背誦。所指的〈僧網〉篇，就是前面所說：每到說戒的早晨，讓知事點檢僧數，眾主、上座親自巡行等。「集僧」一段中，第一科，前半是說明全部集合。「不局」等字，就是指大僧與小眾（沙彌）同行之法；下文就兩處集合，即是別法；兩方面都說明它的相狀，用意是讓人都能通達明白。

【428-0003】資持記/05a_上四#40
【原文】若猶下，明檢校。次科中，初明集處。即在堂外行立。應下，明說偈。即須大眾同聲說之。若云打鐘人說者，合在前明，豈待集至堂前方令說耶！又《業疏》云：律令舊住淨人下位打者，此召僧法制，非具道者所為；必無二人，方聽兼助；必使淨人，令說何益；又文中顯言聞鐘偈，豈是能打耶！
【譯文】「若猶」以下，說明檢校，也就是巡視檢查。第二科中，先說明集合的地點，就是在堂外列隊站立。「應」字以下，說明說偈，就是必須大眾同聲說偈。若說是由打鐘的人說偈，那就應該在前面就說明，豈待大眾集合到堂前才讓他說呢！又《業疏》說：律中令舊住的淨人在下位打鐘，這是召集僧眾的法制，不是具足道行的人所做的事；必定沒有淨人與沙彌這二人，才允許比丘兼代幫助；若一定要用淨人，讓他說偈又有什麼益處；又文中明顯說「聞鐘偈」，哪裡是打鐘的人說的呢！

【428-0004】資持記/05a_上四#41
【原文】〔有人執本緣起是阿難鳴鐘時說，便云此偈是打者說；又輒改聞為鳴，委如別破。〕下諸偈詞，相承不解；人雖誦之，多迷文理，略為科釋。聞鐘二偈，初偈明事用，後偈明所期。初中，上半明功，下半顯用。四魔強盛，能障善道，故有力也；欲相侵害，故如怨也。結即三界見思；
【譯文】〔有人主張這一段的緣起是阿難鳴鐘時所說，就說這首偈是打鐘的人說的；又任意把「聞」改成「鳴」，詳細情形如別處所破斥。〕下面諸首偈詞，前後相承而未能理解；人們雖然誦念，多半迷惑於文理，所以約略加以科判解釋。「聞鐘」二偈：第一偈說明事用，後一偈說明所期望的。第一偈中，上半明功德，下半顯作用。「四魔」強盛，能障礙善道，所以說有力；想要侵害行人，所以說如怨。「結」就是三界的見惑、思惑；

【428-0005】資持記/05a_上四#42
【原文】盡無餘者，即無學極果也。上句修因，下句證果。後偈中，上半明所集之意，下半明能集之願。聞法人者，總凡聖也。雲集者，喻其奔赴也。入堂中，初示儀式有三：初禮敬，次說偈，三就坐。偈中，上半偈明自行成就，次一句明眾行無違，末句自眾兩具方成法事。
【譯文】「盡無餘」，就是無學的極果。上句是修因，下句是證果。後一偈中，上半說明所集大眾的用意，下半說明能集大眾的願。「聞法人」，總括凡與聖。「雲集」，比喻他們奔赴而來。「入堂」中，先顯示儀式有三：初、禮敬；二、說偈；三、就坐。偈中，上半偈說明自行成就，次一句說明眾行無違，末句說明自己與大眾兩方面都具足，才能成就法事。

【428-0006】資持記/05a_上四#43
【原文】自行中，上句受體無缺，下句隨行無犯。〔大眾字，有本作清淨。〕如下，次誡侮慢。如上即〈雜法〉中。極教者，若取制之深極，則指律文；若約教之終極，即指《涅槃》；彼云：我不滅度，半月一來。遺謂佛之遺誡。言根本者，望餘法事，皆是枝條。
【譯文】「自行」一段中，上句是說所受的戒體沒有缺漏，下句是說隨行沒有違犯。〔「大眾」二字，有的版本作「清淨」。〕「如」字以下，其次告誡侮慢的過失。「如上」就是指〈雜法〉篇中所說。「極教」的意思：如果採取制教的深極處，就是指律文；如果就教法的終極而言，就是指《涅槃經》；經中說：我不入滅度，每半月一來。「遺」是說佛的遺誡。所說的「根本」，對望其餘的法事，都只是枝條。

【428-0007】資持記/05a_上四#44
【原文】有人於此妄立歡喜偈者，若言表淨，前偈已具，何勞重述；若是陳過，有犯自當懺露，豈但乞僧歡喜而已；習俗日深，苦諫不捨；知非遷善，未見其人。第五與前第二相濫。以意通之，前約預辨，今此眾集；始將入堂，有同持獻；方合科次，則非重疊。此間不爾，多是預安，故難通曉。後進更詳。
【譯文】有人在這裡妄自安立「歡喜偈」：若說是表達清淨，前面的偈已經具足了，何必再重述；若是陳述過失，有犯就應當自己懺悔發露，豈只是乞求僧眾歡喜而已；習俗日久深入，苦苦勸諫也不肯捨棄；知道錯了而改過向善的人，還沒見到。第五科與前面第二科互相混濫。以文意打通來說，前面是就預先辨定而說，現在這裡是大眾集合；才要入堂，有同於捧持供獻；這樣才符合科判的次第，就不是重疊。此地的實行不是這樣，多半是預先安設，所以難以通曉。後來的學者再詳細考察。

【428-0008】資持記/05a_上四#45
【原文】以物席地，為藉眾器也。僧中設者，明是後安也。六明行事，盥浴中，初明出眾。三五人者，今則一人維那行籌唱告，四人兼助行湯水等。具威儀者，謂安詳恭謹，不必設禮。〔今時出眾各禮三拜，復座展坐具已，還來取物，並非正儀。〕次維那淨手。持下，上座盥掌。準文，維那為之；
【譯文】用物品鋪在地上，是為了墊放眾人的器具。「僧中設者」，說明是後來才安設的。第六，說明行事的次第。「盥浴」中，先說明出眾的人。「三五人」，現在則是一位維那行籌唱告，四位兼助行湯水等。「具威儀」，是說安詳恭謹，不必行設禮。〔現在的人出眾各禮三拜，回到座位展開坐具之後，又回來取物，都不是正當的儀式。〕其次維那淨手。「持」字以下，上座盥掌。依準文意，是由維那來做；

【428-0009】資持記/05a_上四#46
【原文】今多年少，義亦無爽。取下，上座浴籌。各說偈者，合眾同音；今並維那獨唱，事訛變也。偈中，上半聖凡和合，明所集也；下半法事利生，示所為也。維那自浴者，《尼鈔》云：今時多是上座浴籌，此非敬儀；據理年老，代浴無損，今須準用。行水中。
【譯文】現在多是年少的人來做，於義也沒有差失。「取」字以下，上座浴籌。「各說偈」，是合眾同音一起說；現在都是維那獨唱，這是事情訛變走樣了。偈中，上半是聖凡和合，說明所集的大眾；下半是法事利生，顯示所做的目的。「維那自浴」，《尼鈔》說：現在多是上座浴籌，這不合敬儀；按理上座年老，代為浴籌也無妨，現在必須依準此說而行。「行水」中。

【428-0010】資持記/05a_上四#47
【原文】令一年少者，今須二人行湯水，二人行淨巾。偈文，上句歎水德。一清淨，二不臭，三輕，四冷，五軟，六美，七飲時調適，八飲已無患。次句顯事用。外則德水以盥掌垢，內則道水以滌心塵。第三句自行成立，末句化他同己。盥，公玩反。行巾中。左右手者，取其順便。
