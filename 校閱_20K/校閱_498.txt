# 校閱材料　第498檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【498-0001】資持記/05c_上四#14
【原文】住日多少皆不定故。閏月二日結者，百十九日住；乃至閏月三十日結，則九十一日住，故云轉少也。〔前通二十九日結，同至八月一日去。〕越閏過者，釋上漸少所以也。若五下，即第三位。既不涉前閏，故唯三月。五月一日結，八月一日去；乃至十六結，八月十六去。〔結去各十六日。
【譯文】因為安住的天數多少都無法固定。閏月二日結夏的人，要安住一百一十九天；乃至閏月三十日結夏的人，則要安住九十一天，所以說是「轉少（越來越少）」（前面總計二十九天內結夏的人，同樣都在八月一日離去）。「越閏過」這句話，是在解釋上面日數漸漸減少的原因。「若五」以下，就是第三種位次。既然不再涉入先前的閏月，所以只有三個月。五月一日結夏者，八月一日離去；乃至五月十六日結夏者，八月十六日離去（結夏與離去各自都是十六天）。

【498-0002】資持記/05c_上四#15
【原文】準疏此有三句，或有安居隔一月〔四月三十日與五月二日結者，並隔閏月。〕，自恣降一日〔四月三十結，七月盡日去；五月一日結，八月一日去，即降一日。〕；或有安居隔一月〔閏月一日與五月一日結者，亦名隔一月。〕，自恣同日去〔並八月一日去〕，如是漸減〔應云：安居隔二十九日等。
【譯文】依照《業疏》此處有三種句型：或者有安居相隔了一個月（四月三十日與五月二日結夏者，中間都隔了一個閏月），而自恣日則僅相差一天（四月三十日結夏，七月最後一天離去；五月一日結夏，八月一日離去，相距降為僅差一日）；或者有安居相隔了一個月（閏月一日與五月一日結夏者，也稱為相隔一個月），而自恣日卻在同一天離去（都在八月一日離去），像這樣逐漸遞減（應當說：安居相隔二十九天等等）；

【498-0003】資持記/05c_上四#16
【原文】乃至安居隔一日〔閏月三十日與五月一日結，即隔一日。〕，自恣同日去〔亦同八月旦去〕。三閏七月中，初標閏。從下，列釋。初三月住。四月十六結，七月十六去；五月一日結，前七月盡日滿，閏月一日去，故云未至閏也。〔結去各十六日。〕五月下，明第二位。
【譯文】乃至於安居只隔了一天（閏月三十日與五月一日結夏，就是相隔一天），自恣日也是在同一天離去（同樣在八月一日清晨離去）。在第三種閏七月的情況中，開頭先標出閏月。「從」字以下列出並解釋。首先是安住三個月的情形：四月十六日結夏，七月十六日離去；五月一日結夏，在前面的七月最後一日算滿，閏月一日離去，所以說是「未至閏（還沒碰到閏月）」（結夏與離去各自都是十六天）。「五月」以下，說明第二種位次。

【498-0004】資持記/05c_上四#17
【原文】五月二日結，至前七月盡日始得八十九日；故須跨過虛月，取八月旦一日足滿，明旦出界〔即初二去〕，乃至五月十六結去可知〔結通十月五日，去有十五日。〕。疏立二句，或有安居隔一日〔五月一日與二日結，是隔一日。〕，自恣隔一月〔五月一日結，七月盡滿，閏月旦去。二日結者，八月旦滿，二日方去，即隔一月。
【譯文】五月二日結夏的人，到了前面七月最後一日才剛好滿八十九天；所以必須跨越過這個虛設的月份，借取八月一日當天來補足，到了八月二日清晨才能出界離去（也就是初二離去），乃至於五月十六日結夏離去的情形也可以推知（結夏時間可通達十五天，離去時間也有十五天）。《業疏》建立了兩種句型：或者有安居只隔了一天（五月一日與二日結夏，就是相隔一天），而自恣日卻隔了一個月（五月一日結夏者，七月最後一天算滿，閏月一日清晨離去；二日結夏者，八月一日算滿，八月二日才離去，這就是隔了一個月）；

【498-0005】資持記/05c_上四#18
【原文】乃至安居隔十四日〔五月二日乃至十六日結者〕自恣隔一月〔五月二日結，八月二日去；三日已後結者，前退後增；乃至十六結，八月十六去，並隔一月。〕。餘下，指廣。今見《業疏》如上略引。《義鈔》文逸。分房法中。三時分易，西土常儀。將恐保著生常，不思厭世；
【譯文】乃至於安居相隔了十四天（五月二日乃至十六日結夏的人），自恣日則隔了一個月（五月二日結夏，八月二日離去；三日以後結夏者，前面的天數往後退、後面的天數往前增；乃至十六日結夏者，八月十六日離去，全部都隔了一個月）。「餘」字以下，指示參閱更詳盡的論述。現在見到《業疏》大致如上文所引述。《義鈔》的原卷已經佚失了。在「分房法」之中，一年春、夏、冬三時輪流更換分配僧房，是西域印度的常規儀式。這是唯恐大家對常住處所生起耽著眷戀，不再思維厭離塵世；

【498-0006】資持記/05c_上四#19
【原文】薄情遣滯，莫先此法；東華不爾，故所絕聞。或共止一堂，頗符水乳；或別房各住，而不異俗流。且君子安遷，小人懷土。況出世高逸，反更守株！致使聖訓空存，行儀永墜，嗚呼！制緣中。初明主心局狹，簡於客舊，故致嫌責，以為由始。佛下，明制。舊住自知，但令客看；目見好惡，則息諍情。
【譯文】若要淡薄私情、遣除執滯，沒有比這個方法更優先的了；然而東土華夏卻不是這樣，以致於此法完全銷聲匿跡。有的大家混雜共住在一座大堂之中，表面看似水乳交融般親睦；有的則各自佔據獨立房舍，行為與世俗常人無異。況且世間君子尚且能隨遇而安，唯有小人才會死守故土；何況是超越世俗的高雅逸士，反而更加固步自封、守株待兔！以致於佛陀的聖訓形同虛設，修行的威儀規範永遠墜落，真是令人慨嘆！在制定分房的緣由中，開頭說明原住僧人私心偏狹，排斥外來客僧而偏護舊住，因而引發譏嫌責難，這是最初的起因。「佛」字以下說明制定此法。舊住的僧人自己心知肚明，只讓客僧進去察看；親眼看見好壞優劣，便能平息爭執的情緒。

【498-0007】資持記/05c_上四#20
【原文】行法中，初文。具五法者名為五德。上四約心，名為通德，通一切故；第五約事，名為別德，隨事各局故。順己無黨故不愛，違心無憎故不恚，達教無疑故不怖，知機適變故不癡。知可分等者，或約人論，大僧為可，惡比丘及沙彌為不可；或約處者，房舍為可，眾處不可；
【譯文】在實行的方法中，第一段文字。具備五種法條件的人，稱為「具備五德」。前四種是就內心修養而言，稱為「通德（普遍的德行）」，因為它通貫於一切事務；第五種則是就外在事務而言，稱為「別德（個別的德行）」，因為它是隨特定職務而各有局限。順應自己的私意也不結黨偏袒，所以稱為「不愛」；違逆自己心意也不心懷怨恨，所以稱為「不恚」；通達戒律教法而毫無疑慮，所以稱為「不怖」；能看清時機機變應對，所以稱為「不癡」。所謂知道哪些可以分配等等，如果就人而言，大僧比丘為可，惡性比丘及沙彌為不可；如果就處所而言，一般僧房為可，眾人共同的大堂則不可；

【498-0008】資持記/05c_上四#21
【原文】更總為言，必須通解分法始終，方堪差舉。羯磨下，引法。可解。次科，初五德唱告。下明眾僧集物。隨己所有，並持入眾；唯除床榻臥具等。三中，初數知房舍。經營主者，或彼剏造，或復修治，任意選取，以賞勞績；〈鉢器篇〉云：營事比丘房成，與房住九十日一移等，餘廣如彼。
【譯文】若再總體而言，必須通盤理解分房法自始至終的程序，才能勝任並受推選擔任這項差事。「羯磨」以下，引述具體的作法，義理容易理解。下一個科判，首先由具備五德的僧人宣告大眾。下文說明僧眾集中物品的情形。隨自己名下所擁有的一應財物，都要帶出來交給大眾；唯獨除去了床榻與被褥等臥具。「三」字一段中，首先要清點查明房舍數量。所謂「經營主者」，是指或者由他最初開闢建造，或者由他出資整修維護的，可以隨其意願優先挑選，以犒賞其辛勞功績；〈鉢器篇〉記載：負責營造事務的比丘在僧房落成後，給予該房居住九十天然後輪換一次等，其餘詳情正如該處所載。

【原文】後下，二依次分與。若有下，明人少房多，再三分之。故下，明更分無用，故令留置。問：既隨所樂，可取先所住處否？答：必取先住，還因分得，理應無過。然本教意，恐著住處；苟能遷徙，節己稱法，在人為之。若惡下，三明簡人。時下，四示嚴制。問答中，初難者。律制行食不得偏饒上座；
