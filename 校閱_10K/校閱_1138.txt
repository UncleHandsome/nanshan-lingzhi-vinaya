# 校閱材料　第1138檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1138-0001】資持記/08b_中二#45
【原文】燒有餘殘，義亦無爽。注文末句，因點受持；由奪等緣，失本受法；後得重加，義在離衣，緣同因示。次科為三，初牒釋。言取著者，謂有犯捨三衣，由失正衣，即無長過，可取著用，故列不犯。注釋頗詳。《伽論》下，次引證。過十日衣即犯長者。意以有犯必無離宿，故設此問。
【譯文】燒毀而有殘餘剩料，在義理上也是講得通的。注文最後一句，順帶點明受持之事；由於搶奪等緣故，失去了原有的受持法度；後來重新獲得時必須重新加受，箇中義理在於離衣戒中，因為緣由相同所以順帶指出。下一科判分為三部分：首先牒述解釋。所謂「取著」，是指原本有犯捨墮的三衣，由於失去了正法衣，便不再具有長衣之過，可以取來穿著使用，所以列入不犯條款。注文解釋得相當詳盡。《伽論》以下，其次引述證明。超過十天的衣物就犯長衣過失。意思是既然已有犯長過失，離宿時必定不犯離衣宿夜罪，所以設立此問。

【1138-0002】資持記/08b_中二#46
【原文】答中可證加受得成。何下，三釋妨。指前云者，即貿易中；彼言不得，故須通會。答中，初句釋通前文；今下，正顯今意。色猶數也。下引二文，色體不如，並許加受，足為今例。問：為開暫時，為得求作？答：文似暫開，不妨永用。今以義判，或有可別求，卒營未及，暫用彌善；
【譯文】回答中可以證明加持受法是能夠成就的。「何」字以下，第三解答疑難。指稱前文所說的，就是指貿易衣物那一節；那裡說不能穿用，所以必須融會貫通。回答中，第一句解釋通曉前文；「今」字以下，正式顯明現今的意圖。「色」好比數目。下文引述兩段文字，色澤本質縱使不如法，都允許加受，足以作為現在的例證。有人問：究竟是暫時開許，還是允許正式尋求裁製？回答說：經文看似暫時開許，但也不妨礙永久穿用。現在依義理判定，若有別的法衣可尋求，臨時縫製不及時，暫時穿用最為妥當；

【1138-0003】資持記/08b_中二#47
【原文】或守己少欲，趣足被形義通久永。《善見》五大，通收正間。《僧祇》俗衣，彼因借被作淨安紐故。四中。注云重物者，以用重故；準知入淨方有長過，被褥說淨，諸律無文，故云未見等。下引《十誦》，僧別得受；但得受用，不明說淨。五中。付衣者，律作受付囑衣者，即所囑藏舉人也。
【譯文】或者抱持安貧少欲之心，只要能遮蔽身體便心滿意足，在義理上通於長久穿用。《善見律》中的五大衣，通括正色與間色。《僧祇律》中的俗家衣服，那是因為借俗衣披著，作淨施並縫上繫帶紐扣的緣故。第四項中。注中說「重物」，是因為使用上屬於厚重之物；由此可知列入說淨才有長衣過失，對於被褥作說淨，各部律典並無明文，所以說「未曾見過等」。下文引述《十誦律》，僧團公物與個別僧人皆可受用；但只是允許受用，並未說明要作說淨。第五項中。「付衣」者，律文寫作「受囑託衣服的人」，也就是替人收藏保管物品的人。

【1138-0004】資持記/08b_中二#48
【原文】水陸等者，此並人衣隔絕，不及故開；例餘緣阻通入不犯，故云等也。第二。〔佛在舍衛，六群持衣寄親厚，往人間遊行，故制。〕名中。三衣簡餘衣，宿者結犯限分。列緣中。第三通收四礙，如後具釋。第四有緣不及，律開遙捨，或復奔會，二皆無犯；非此則為犯緣。
【譯文】所謂「水陸等」，這些都是因為人與衣服隔絕分離，時間上來不及，所以予以開許；其餘因故受阻的情況依此類推都歸入不犯，所以用「等」字概括。第二條戒。〔佛在舍衛國時，六群比丘把三衣寄放在親近好友處，自己前往人間遊行，佛陀因此制戒。〕戒名中。「三衣」是簡別其餘衣服，「宿」是結罪犯戒的界限時間。列出犯緣中，第三項通體收攝四種阻礙，如後文詳細解釋。第四項因故來不及，律中開許遙遠捨衣，或者奔馳前去會合，這兩種都算不犯；如果不屬於這兩種情況，就構成了犯緣。

【1138-0005】資持記/08b_中二#49
【原文】第五，下列七緣，通入開位。釋第一中，初文，先示罪相。五衣者，附明尼制；祇支，覆肩，皆入制故。非下，釋上餘衣，初正釋。長下，點古。波謂餘衣言通長物，離亦吉故。約根中。前二並受，罪重輕者，制聽別故。後二皆聽，罪有無者，法分受淨，物屬自他故。下指《戒疏》，見離衣戒。二中。
【譯文】第五項，下列七種緣由，都歸入開許的層次。解釋第一項中，第一段文字，先明示罪名相狀。「五衣」是附帶說明比丘尼的戒制；因為僧祇支、覆肩衣，都列入了制戒範圍。「非」字以下，解釋上文的其餘衣服，首先正面解釋。「長」字以下，點評古德之說。彼古德認為其餘衣服言詞通於一切長物，離宿也結吉羅罪。在約根機解釋的一段中：前兩種（三衣與百一衣）都是正式加受的衣物，罪名之所以有重有輕，是因為制衣與聽衣的規定不同。後二種都是聽許蓄積的衣物，罪名的有無，是因為法度上區分為加受與說淨、物權屬於自己還是他人。下文指引參閱《戒疏》，可見於離衣戒。第二項中。

【1138-0006】資持記/08b_中二#50
【原文】本明受持，而指作衣法者；以作如法，方成受故。三中，初科，前指所出。如下釋中具標部號。上下，示通塞，初正示。作法，自然，一一界中，皆具三礙，故云通界並有。界礙不通者，律云：此伽藍非彼伽藍，樹車等皆爾是也。故下，引證通義。古謂伽藍相壞，樹車叢生，故言若干；
【譯文】本應說明如何受持，卻指引製作法衣的法則；這是因為法衣製作如法，受持之法才能成就的緣故。第三項中，第一科，前面指引出處。就如下文解釋中完整標明各部律典的部號。「上」字以下，指示通融與阻隔，首先正面指示。不論是作法結界還是自然結界，每一個結界中都具備這三種阻礙，所以說全界都通有。而「界礙」是不相通的，律中說：這座僧寺並非那座僧寺，樹界、車界等全都是如此，就是這個意思。下文引證通融的含義。古德認為僧寺標誌損壞，樹木車輛叢生密布，所以說是「若干」；

【1138-0007】資持記/08b_中二#51
【原文】今意不爾，故注以示之。別釋中，染礙為二，先引制緣。令除村者，即作法攝衣羯磨所牒。五義出《多論》，文略一三；一聚落散亂不定，衣界是定；三為除鬪諍。即下，次釋制意。女情淫蕩，僧本貞潔，故云乖忤；忤猶違也。縱不為非，亦生疑謗，故云譏迹。佛下，總舉諸戒，類顯今制。
【譯文】現在的見解並非如此，所以用注文予以顯明。分別解釋中，染礙分為兩部分：先引述制戒的因緣。所謂「除村」，就是作法結攝衣界羯磨文中所列的辭句。五種含義出自《薩婆多論》，文中略去了第一和第三項；第一項是聚落散亂不安定，衣界則是固定的；第三項是為了止息爭鬥訴訟。「即」字以下，其次解釋制戒意圖。女人的性情淫蕩，僧人本質應當貞潔，所以說是「違逆」；「忤」就是違逆的意思。縱使未做非禮之事，也容易引起疑心毀謗，所以說是「譏嫌蹤跡」。佛陀以下，總體列舉各項戒律，比類彰顯今時的戒制。

【1138-0008】資持記/08b_中二#52
【原文】宿行各一，坐收屏露及二不定，同住即是除村。若下，結示名相。隔礙中，引律緣。雖無離罪，不妨失受，故得成礙。澁字寫錯，律作嶮難。下引《僧祇》。彼無勢分，捉鑰有梯，並可入故；反此成礙。情礙中三文，並約心想成礙。本律，文見不犯。《僧祇》，如後族界。《多論》。
【譯文】過宿與行走各有一條戒，共坐則收攝了屏處、露處以及兩條不定戒，同住指的就是除村。下文結語指示其名稱與相狀。隔礙之中，引述律典的因緣。雖然沒有離衣過宿的罪名，但並不妨礙喪失受持法，所以得以構成阻礙。「澁」字是寫錯了，律中作「險難」。下文引述《僧祇律》。那裡如果沒有足夠的勢分邊界，拿著鑰匙又有梯子，都可以進入；反過來無法進入就構成了阻礙。情礙之中的三段文字，都是依照心意念想構成阻礙。本宗律典，文字見於不犯條款。《僧祇律》則如後文的「族界」。《薩婆多論》。
