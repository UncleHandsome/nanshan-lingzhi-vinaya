# 校閱材料　第973檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【973-0001】資持記/03b_上二#7
【原文】又《壇經》云：若先結大界，後結戒場，約何法制以分兩界；雖預開空域，終是無法之地。鈔中直破云不讀等。問決中。前雖略斥，未定成否；猶恐妄執，須更明示？答文為二，初明先結得成。文既令捨，即顯結成；所以爾者，唱結無乖故。但下，二明後法不成。所以然者，違制法故。
【譯文】此外《壇經》也說：如果先結大界、後結戒場，究竟要依據什麼法規制度來劃分這兩個界域呢？縱使預先保留一片空地，終究也只是缺乏如法作法的無效之地。《行事鈔》中直接破斥說「沒有讀通」等語。在提問決疑中：前面雖然略加斥責，但尚未斷定究竟算不算結成；仍然擔心有人妄自執著，因此必須進一步說明清楚。回答的文字分為兩部分：第一部分說明先結的界得以成立。經文既然要求「應當捨棄」，就顯明此界本已結成；之所以會成立，是因為唱相結界並無違誤。從「但」字以下，第二部分說明後作之法不能成立；之所以如此，是因為違背了佛制法度的緣故。

【973-0002】資持記/03b_上二#8
【原文】五下，引證復二，初明故違不成。又下，明不知許成。言不知者，謂秉結之人，未闚教故。於後纔知，即不成法。然是愚教，須加二罪。或可後行受者，不知元結，失於次第，約心許成。賴下，示曲開之意。僥倖者，疏云非分遇福也。示非中，初通標。或下，別示，次列四種。
【譯文】從「五」字以下，引用證明又分為兩部分：首先說明如果是故意違背則不能成立。從「又」字以下，說明若是無知而誤作者則開許成立。所謂「無知」，是指主持羯磨的人尚未深入研讀教理；事後一旦知道，這項法事即刻歸於無效。然而這屬於對教法愚昧無知，必須額外承擔兩重罪責。或者也可以說是後來參與受戒的人，並不知道當初結界時失落了次序，依其本無違犯之心，因而開許受戒成就。從「賴」字以下，說明此乃委曲開許的心意。所謂「僥倖」，疏文解釋為非分而獲得利益福報。揭示過錯中，先做通泛標示。從「或」字以下個別列出，接著列舉四種過失。

【973-0003】資持記/03b_上二#9
【原文】初界中不集者，謂自然限內有別眾過，即人非也。總唱者，即就場中遙結大界，謂事非也。二中。界內即大界，不合通唱，及下二種並是事非。第三可知。四中。不唱內相，即兩界錯涉也。此下，總結，上二句示非。故下，明是。當界者，大界戒場，各自局故。結場中。
【譯文】第一種「在界內不集僧」，是指在自然界限定範圍內存在別眾獨立行事的過失，這屬於「人員錯誤」。所謂「總唱」，就是直接在戒場中遙對外圍結成大界，這屬於「事項錯誤」。第二種之中，「界內」指的就是大界，原本就不應當籠統通唱，這與下面兩種情況全都屬於「事項錯誤」。第三種情況其理顯自明。第四種之中，「不唱內相」，就會導致大界與戒場互相牽扯錯亂。從「此」字以下作總結，上兩句揭示其錯誤，從「故」字以下明辨正確做法。所謂「當界」，是指大界與戒場各自局限於自身範圍的緣故。結戒場的段落中：

【973-0004】資持記/03b_上二#10
【原文】相及羯磨，皆云小界者；對外大界，在中名小；與下三小，名同相別。結已中。止將四五人往結大界者，一往且示兩處界別，各不相妨。若準不開說欲，要知界相，理須盡往。次結大界，唱相中，總別唱者。別即內外各唱，總謂逐遍合唱。
【譯文】界相與羯磨文都稱為「小界」，是因為相對於外圍的大界而言，居於其中的便稱為小；這與下文的「三種小界」雖然名稱相同，但體相不同。在結界完畢的段落中，只帶領四、五人前往結大界，只是暫時顯示這兩處界域名分有別，各自互不相礙。若依照結界不開許委託傳達僧欲（說欲）的規定，為了確實明瞭界相，理應全體僧眾都要前往。接著結大界、唱告界相時，有總唱與別唱之分；「別唱」是指內相與外相各自唱告，「總唱」則是指每一遍都將內外相合併唱告。

【973-0005】資持記/03b_上二#11
【原文】若行別唱者，先三唱內相竟，結云此是大界內相三周訖；復次三唱外相竟，結云此是大界外相三周訖，然後通結云：此是大界內外相各三周訖，不須同下云彼此等；以是別唱，無相濫故。雖文出總法，而別唱便易，今宜從別。正明中，初總舉。前下，別唱，初唱內相。
【譯文】如果要採用分別唱相的方法，應當先將內相唱告三遍完畢，結語說「這是大界內相，三遍已唱畢」；接著再將外相唱告三遍完畢，結語說「這是大界外相，三遍已唱畢」；然後再作總結語說：「這是大界內外相，各三遍均已唱畢」，不需要如同下文那樣說「彼此」等詞；因為是分別唱告，彼此不會產生混淆。雖然律文中載有總法，但分別唱告比較便利容易，如今應當依循分別唱相之法。正文說明中，先做總體列舉。從「前」字以下為分別唱相，首先唱告內相。

【973-0006】資持記/03b_上二#12
【原文】次下，二唱外相。並有標唱結三段，標結之詞，通須牒唱。彼下，雙牃總結。如下，唱已通告。羯磨中，牃緣。加減，明加內外二字，而言足一字者，未詳所以；有云外字，義通本有，則非加也。若據下示不須加。以體望相，並是外故。三小中，集僧分三，初敘緣彰異。如下，二正示遠近。
【譯文】從「次」字以下，第二步唱告外相。兩者都包含標示、唱告、結語這三個段落，標示與結語的文詞，全都必須重複提唱。從「彼」字以下，將內外相一併重複提唱作總結。從「如」字以下，說明唱相完畢後須向全體通告。羯磨文中，重提緣由。關於文句加減，說明加上了「內、外」二字，至於說「補足一個字」，原因尚不明確；有人認為「外」這個字在義理上本來就涵蓋其中，所以算不上增加。如果依照下文的指示，其實不需要增加；因為若以界體來對照界相，實質上都屬於外在的界相。三種小界之中，召集僧眾分為三部分：先敘述緣由以彰顯其特殊。從「如」字以下，第二步正式標明距離的遠近。

【973-0007】資持記/03b_上二#13
【原文】七盤陀者，如〈集僧〉中有難蘭若，唯結三小，請無所疑。故下，會同律論，以明可取。論明不同意者，在七盤陀外，得作法事；律云：不同意者未出界〔謂在本界。〕，聽在界外疾疾一處集結小界受戒；名相相符，故云無異。並下，三示結處，上明開閉。由下，釋所以。逈，遠也。逈故來難，露故易見。
【譯文】所謂「七盤陀」，如同〈集僧篇〉中提到的，有災難的阿蘭若處只結三種小界，請不要對此有所疑慮。從「故」字以下，會通律典與論典，以證明此法切實可行。論典中說明「不同意法事者」只要在七盤陀之外，就可以如法作法事；律文說：不同意者如果還未出界〔指仍在原本的界內〕，聽許在界外趕緊於一處集合、結成小界來受戒。兩者名詞與體相完全吻合，所以說並無差異。從「並」字以下，第三步說明結界的地點，前半段說明開許與禁止的界線。從「由」字以下，解釋其中的緣由。「逈」就是遙遠之意；因為遙遠所以容易招來危難，因為露天所以容易被看見。

【973-0008】資持記/03b_上二#14
【原文】聚落反此，不開可會。不竪相中，正義分二，先敘二界須相。此下，正明三小不立，初約緣顯無。有難謂不同意。遮作即來訶止。隨下二句，剋定體量。次科，古義中。彼謂受戒出眾問難，入眾正受，必在界中，故須立相；餘二不爾，故但隨身。
【譯文】聚落的情況正好與此相反，不予開許的道理可以由此領會。在「不樹立界標」的內容中，正義分為兩部分：先敘述二界必須有界標。從「此」字以下，正式說明三種小界不樹立界標，首先根據緣起情況來彰顯無須界標。所謂「有難」，是指出現了不同意法事的人；所謂「遮作」，就是有人前來訶責阻止。從「隨」字以下兩句，明確限定了界體的範圍體量。下一科判關於古師的見解中：古師認為受戒時必須走出僧眾之外詢問遮難，進入僧眾之中正式受戒，身形必定是在界內，因此必須樹立界標；其餘兩種小界則不用如此，所以只要隨身所在即可。
