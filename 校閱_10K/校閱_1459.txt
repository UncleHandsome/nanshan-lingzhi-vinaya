# 校閱材料　第1459檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1459-0001】04_比丘尼鈔/04b_卷中之下#28
【原文】供僧水扇戒具緣可辨僧與尼男女相別供給水扇容生染習迹涉譏醜故犯僧祇水扇互給越水扇俱給提眾多比丘互有兄弟供給水扇無犯十誦云比丘食時尼立侍者提與食已還坐若別處無犯。
【譯文】（為比丘僧倒水打扇戒）犯此戒的構成要件容易明辨。僧眾與尼眾男女有別，在日常中若服侍供水、搖扇，容易滋生染污執著之情，外表行跡也招惹世人譏嫌醜詆，因此制戒禁止。《摩訶僧祇律》說，如果供水或打扇只做其中一樣，犯越毘尼罪；如果供水與搖扇同時侍奉，犯波逸提罪。若有多位比丘與比丘尼彼此是俗家親兄弟姐妹，為其供水打扇則不犯戒。《十誦律》說，比丘用餐時比丘尼若在旁侍立伺候，犯波逸提罪；供送食物之後回到自己座上，或者在另外的地方，則不犯戒。

【1459-0004】04_比丘尼鈔/04b_卷中之下#31
【原文】共男子入屏障處共語戒具緣可解然男子有別體無參涉今入屏處容生染習遠成大過招世譏醜清白難分故所以制若離見聞屏又無染心而非共語但犯吉羅要假共語方犯於提若有染心落在八事戒坐不犯此共男子屏處前離見聞屏復語犯此是露障屏不假語犯不云立住吉者以不行故犯輕遣伴遠去與男子屏處立行耳語此是離見聞屏唯遣伴遠去耳語為異。
【譯文】（與男子進入遮障處交談戒）犯此戒的構成要件容易理解。男女有別，理應沒有私相交涉；如今單獨進入遮障的隱密處，極易滋生染著貪愛，長此以往必釀成重大過患，招致世間譏嫌謗議，清白之身難以自明，所以佛陀制定此戒。如果是在看不見也聽不到的隱密處，又沒有染污之心，而且並沒有共同說話，只犯突吉羅罪；必須是在那裡私下交談，才正式犯波逸提罪。如果有染污貪著之心，罪過就會落入八事戒中。如果只是坐著而不交談則不犯此戒。（辨析與男子同處屏處之戒）：前一條戒是離見聞屏處，須再加上交談才犯提；此戒則是露地遮障之屏處，不需要等到交談，只要共處即犯提。戒文沒有單獨列出「站立」犯突吉羅，是因為既然沒有做出走動交談之事，犯情較輕。若將同伴打發走遠，而與男子在屏障處並排站立、行走並耳語私語，這也屬於脫離眾人視聽的屏障範疇，只是以支開同伴進行耳語為其特徵。

【1459-0007】04_比丘尼鈔/04b_卷中之下#34
【原文】共男子入暗室戒前是覆障屏有窻牖光明無第三人犯今以其暗室故生患處重雖有多人猶犯以此為異故別制也五分云共男子入暗室語語提若恐怖處若卒燈滅不犯義云不問親與非親須有燈明惡心呪詛戒具三緣犯一有瞋心二作惡呪詛三言詞了了便犯此律云立誓者令稱南無佛提謂經云南者歸無者命佛者覺又南者禮無者大佛者壽。
【譯文】（與男子共入暗室戒）前面一條戒律是指有屏障遮擋但有門窗光線透入、因身邊沒有第三人而犯戒；本戒則是因為置身在昏暗無光的房間內，滋生過患之處更為嚴重，所以即便身邊有多人在場，仍然構成犯戒，正是因為這一點差異而另外制戒。《五分律》說，與男子同入暗室內交談，只要一說話就犯波逸提罪；如果是在令人恐懼的處所，或者燈火突然熄滅，則不犯戒。法義上說，無論對方是親戚還是非親戚，都必須點亮燈燭照明方得同處。（以惡毒心咒詛戒）具備三個條件即構成犯罪：一是內心懷有瞋恨，二是口中發出惡毒咒詛之詞，三是言語詞意清楚明白即犯波逸提罪。依照本律，若要發誓，應當令其稱念「南無佛」，《提謂經》說：「南」是歸依，「無」是歸命，「佛」是覺悟；又解釋說，「南」是敬禮，「無」是廣大，「佛」是無量壽。

【1459-0011】04_比丘尼鈔/04b_卷中之下#38
【原文】同活病不看戒具四緣犯一是比丘尼病二是同活三無因緣四不看便犯五分云同學病不看提同學者謂同和尚阿闍棃及常共伴若止住不同無犯。
【譯文】（同住弟子患病不予照看戒）具備四個條件即構成犯罪：一是對方是生病的比丘尼，二是彼此屬於同師共住照料的關係，三是自己沒有特殊正當因緣，四是不去探視照看即犯波逸提罪。《五分律》說，同門同學生病不去照看，犯波逸提罪。所謂同學，是指依止同一位和尚、阿闍梨，或者是經常結伴同修的人；如果平時居住不同處，則不犯戒。
