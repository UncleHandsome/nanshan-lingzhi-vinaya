# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【361-0001】02_戒疏/19b_卷四下之一#46
【原文】【疏】戒本分二。先立法三句：一、比丘；二、得新衣；三、須三壞色成沙門相。正戒本三句：一、犯人；二、不以三色壞；三、結罪。
【譯文】【疏文】戒本分為二部分。先立法的三句：第一、比丘；第二、得到新衣；第三、必須作三種壞色，成就沙門的相狀。正式戒文的三句：第一、犯戒的人；第二、不用三種壞色；第三、結罪。

【361-0002】02_戒疏/19b_卷四下之一#47
【原文】【記】戒本，初科。立法句中，第二句，注約二種示「新衣」相。第三，注中復引「《律》注」，文為二段。初釋作淨，又二：初即染為淨，二、已染揲淨。「自」下，次釋點淨，亦二。初輕，二重，俱須淨故。
【譯文】【記文】戒本，初科中：立法句的第二句，注解就二種情況顯示「新衣」的相狀。第三句，注解中又引用《律》注，文字分為二段：第一段解釋「作淨」，又分二層：第一是染作顏色就是淨，第二是已經染色的則以別色點揲為淨。「自」字以下，其次解釋「點淨」，也分二層：第一是輕衣，第二是重衣，因為兩者都須要淨的緣故。

【361-0003】02_戒疏/19b_卷四下之一#48
【原文】【疏】成犯中，初「不以三色」壞新故重墮。「若輕重衣不作點」以壞色者，吉羅。餘小細物，並須點淨。非謂巾、屣以三色染，更成驚俗，可笑至甚也。
【譯文】【疏文】在成犯這一段中：首先，「不以三色」染壞新衣，所以犯重的墮罪；如果輕衣、重衣不作點淨來作壞色，犯突吉羅。其餘小的細物，都須要點淨。並不是說巾帕、鞋子也要用三種壞色去染，那樣反而驚駭世俗，非常可笑。

【361-0004】02_戒疏/19b_卷四下之一#49
【原文】【記】戒本三句辨相，注中分三。初明正犯。「若重輕」下，二、明點淨。「若以」下，三、明寄俗舍，由濫俗服，無所辨故。
【譯文】【記文】戒本用三句辨明相狀，注文分為三段。第一段說明正犯的情況。「若重輕」以下，是第二段，說明點淨（作壞色點記）。「若以」以下，是第三段，說明寄放在俗人住處，因為容易與世俗衣服相混濫，無法分辨的緣故。

【361-0005】02_戒疏/19b_卷四下之一#50
【原文】【記】疏文，釋上二段。「餘小細」者，即諸囊、巾等。「非謂」下，遮濫。今時有人，聞《律》有言「一切染作袈裟色」，觸衣、襪、履，一槩染之。未見此文，豈知過當？
【譯文】【記文】疏文是解釋上面兩段。「餘小細」是指各種袋囊、巾帕等物。「非謂」以下，是遮止混濫。現在有人聽到《律》中說「一切都染作袈裟色」，就把貼身的觸衣、襪子、鞋子一概染成壞色。若沒看到這段文字，怎麼知道自己做得過分失當呢？

【譯文】【記文】第六十一條，制戒的意義有三。第一義中，「四等」就是慈、悲、喜、捨，普遍對眾生而發，所以都稱為「等」。第二義中，殺業違背慈悲，是諸業之首，眾生因此流轉生死，所以說「生死之本」等。第三義，如緣起所說，是因居士譏嫌而制定的。

【原文】【疏】若就蟲水是同，應合為一，如壞生種，內外合制。為重物命，隨用故內外兩結，離意可見也。
【譯文】【疏文】若就「蟲水」這一點來說，兩戒相同，應該合為一戒，如同壞生種戒，內用、外用合併而制。然而為了重視眾生性命，隨著內用、外用而分作兩處結罪，分開的用意就可以看出來了。

【361-0025】02_戒疏/19b_卷四下之一#70
【原文】【記】次科。對前「用蟲水戒」，以辨離合。初明應合，理如壞生，食、用同制。「內」即內資，「外」即外用。「為」下，次明離意。若單制用，謂飲無過，故須別制，意在存生。生種無情，事輕故合。
【譯文】【記文】下一科。對照前面的「用蟲水戒」，辨明分開與合併的道理。開頭說明本應合併，道理如同壞生種戒，食用與使用同樣制戒。「內」就是內資（自己飲用），「外」就是外用（澆灑等）。「為」以下，其次說明分開的用意。如果只制定「用」的一面，有人會認為飲用沒有過失，所以必須另外制戒，用意在於保全眾生。植物種子沒有情識，事情較輕，所以合併。

【361-0037】02_戒疏/19b_卷四下之一#82
【原文】【疏】論有五緣：一、是大比丘，《多論》「十三難，顛狂比丘，吉羅；學悔、六夜別住、四羯磨、僧尼互疑，並是提，具自性故」；二、作疑惱意；三、六事隨說一相；四、言詞了了；五、前人聞知。
【譯文】【疏文】論犯有五個條件：一、是大比丘，《多論》說：「十三難（之人）和顛狂比丘，犯突吉羅；學悔、六夜別住、四羯磨（之人），以及僧尼互相疑惱，都是波逸提，因為他們具足自性（有戒體）的緣故」；二、有令人生疑惱亂的心意；三、於六件事中隨說其中一相；四、言詞清楚明白；五、對方聽到並了解。

【361-0038】02_戒疏/19b_卷四下之一#83
【原文】【記】犯緣。第一，簡下三眾。《多論》復簡本眾，「十三難人」無受體，「顛狂」人失正念，故此二並輕；「學悔」已下，反上故重。「學悔」即犯重人。「六夜別住」，即懺殘人。「四羯磨」即呵責等人。「具自性」者，有戒體也。顛狂雖具，然由心亂，而不自知是比丘故。
【譯文】【記文】犯緣。第一項，是簡別下三眾（沙彌、沙彌尼、式叉摩那）。《多論》又從本眾中再作簡別：「十三難人」沒有受戒的戒體，「顛狂」的人失掉正念，所以這兩類都輕（犯突吉羅）；「學悔」以下的人，與上面相反，所以犯重（波逸提）。「學悔」就是犯重罪後懺悔的人；「六夜別住」就是懺悔僧殘的人；「四羯磨」就是被呵責等羯磨處分的人。「具自性」的意思是有戒體。顛狂的人雖然有戒體，但因為心智昏亂，不能自知自己是比丘的緣故。
