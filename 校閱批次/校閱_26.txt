# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【26-0001】02_戒疏/01a_卷一上之一#75
【原文】【記】三中。初正示聖意。「故律」下，略引三文，證成上義，則前所謂「為道非福」深有據矣。云「三乘」者，通約出世聖道為言。前引《律》、《論》，皆言「為」者，即佛意也。次引後偈，必具三學，文無禪定，義必兼收，非禪不慧，義如上說。「迹」謂蹤迹，即指戒法，前聖後賢，同履踐故。戒德尊勝，出過眾善，故云「增戒」。「泥洹」即涅槃，梵言異耳，同翻「寂滅」。聖證最上，故云「第一道」。「良」，善也。
【譯文】【記文】第三小節中。開頭正式示顯佛陀聖意。「故律」以下，概括引證三段經論原文，用以證成上述法義，那麼先前所主張的「制戒是為了求道而非為了世福」，便有了極為深厚的依據。所說的「三乘」，是通泛就出離世間的聖道而言。前面引據的《律》與《論》，都使用了「為」字，指的便是佛陀的制教本意。接著引述後文偈頌，必定是戒、定、慧三學兼備，文面上雖未明言禪定，義理上必定涵攝在內，缺乏禪定便無從生起真實智慧，其道理正如前文所說。「迹」是指足跡蹤跡，在此指稱戒法，因為前代聖人與後世賢者皆同樣循此踐行的緣故。戒法的德行尊貴殊勝，超越世間一切凡善，因此稱作「增戒」。「泥洹」即是涅槃，僅是梵語譯音不同罷了，同樣翻譯為「寂滅」。聖者所證得的果位最為崇高，因此稱作「第一道」。「良」是美好確鑿的意思。

【26-0003】02_戒疏/01a_卷一上之一#77
【原文】【記】次別彰戒本，問中。「上通敘」者，一則機通，但云諸有；二者教通，唯言制戒。機分七眾，教張四位，如向所論，未簡別故。「未知」下，正問今經興意。上句問教，下句問機。
【譯文】【記文】接下來在個別彰顯戒本（別彰戒本）之中，是問答段落。「上通敘」的意思是，一方面是所化的對象太廣泛，僅籠統說是三界諸有情；另一方面是所教的內容太寬泛，僅一般性地說是制定戒律。修學根機劃分為七眾弟子，教法張羅分為四種位階，如同先前所討論的，尚未加以精確簡別。「未知」以下，正式請問眼前這部《戒本》興起的特定用意。上句詢問教法的特殊性，下句詢問對象的特殊性。

【26-0005】02_戒疏/01a_卷一上之一#79
【原文】【記】正答中，初總示。上二句明教別，次二句明意同。「去滯」即斷惑。「猷」，法也。「創隨」下，次別答，初明通制。「前後」者，通語制廣，非止一時。「森羅」言其多貌，據本制戒，因緣閒起，篇聚不次，後集《戒本》，始成條類耳。「機」差「教」別，故曰「俱開」。然彼時眾，但守廣制，不達歸趣，故「鮮舉要」。「窮」下明別制，初敘教主適機。盡物之性，謂之「窮神」；隨物所宜，謂之「知化」。「凡」通內外，「小」總三乘，等覺已還，未窮業理，不堪制置。「故」下，正彰興意。「別隨戒」者，異廣制故。「單出」者，去緣起、廣解故。「再說」者，黑白兩半故。上二句答教別，下二句答機別。
【譯文】【記文】在正式回答（正答）之中，首先是總體開示。上面兩句說明教法的個別特設，接著兩句說明根本化意完全相同。「去滯」即是斷除煩惱困惑。「猷」是法度的意思。「創隨」以下，接著進行個別回答，首先說明通泛廣制的情況。「前後」這兩個字，通泛指稱制定廣律的過程，絕非發生在一時一刻。「森羅」形容其戒條繁多龐雜的相貌，依據最初制定戒條時，是隨著因緣間雜發生的，篇聚次第並未加以整理，直到後來結集《戒本》時，才歸整成為清晰的條目門類。「根機」參差而「教法」各別，所以稱作「俱開」。然而當時的僧眾，只能死守著廣繁的律制，不能通達其終極歸趨，所以「極少有人能掌握扼要」。「窮」字以下說明特設個別戒本之意，首先敘述教主佛陀契應群機的智慧。能竭盡萬物的本性，稱作「窮神」；能順隨萬物各自適宜的條件，稱作「知化」。「凡」字通貫於佛法內部與外道凡夫，「小」字總括聲聞、緣覺乃至菩薩等三乘人，乃至等覺菩薩以下的聖者，都未曾徹底窮究眾生造業受報的深細法理，不足以制定這項戒律。「故」字以下，正式彰顯特設此經的興起用意。「別隨戒」是為了區別於繁廣的律典制度。「單出」是指去除了每一戒的制戒緣起與廣泛註釋。「再說」是指黑月與白月各半月說戒一次。上面兩句回答了教法的個別性，下面兩句回答了對象的個別性。

【26-0011】01_行事鈔/07d_卷中之三#2
【原文】疑惱比丘戒六十三。五緣：一大比丘，二故生惱意，三以六事一一說告，四言辭了，五前人聞知。律中，六事惱者：若以生時，若年歲，若受戒，若羯磨，若犯六聚，若犯聖法，隨一一事皆墮。《僧祇》：當受時，應語令知；受後不得，恐疑悔。律不犯者：其事實爾，不故作。彼非爾許時生，恐後有疑悔，無故受他利養，受大比丘禮敬，便語言，汝非爾許時生。若實無爾許歲，恐後悔受利養敬奉，語言，未爾許歲。若實年不滿二十，界內別眾，作白不成，羯磨不成，非法別眾；恐後疑悔受利養禮敬，語彼令知，還本處受戒故。若實犯波羅夷乃至惡說，恐後悔恨受利養，受持戒比丘禮敬；欲令如法懺悔，語知犯六聚者。又為性麁疏，不知言語，便語汝所說者自稱上人法等。若錯、若戲，一切皆開。
【譯文】疑惱比丘戒六十三。構成犯戒有五種因緣：一、對方是具足戒大比丘；二、故意生起使人生起疑念熱惱之心；三、拿六種事之一一對他說告；四、言辭清晰明瞭；五、對方聽聞並且理解。律典中，以六件事使人疑惱，分別是：或者針對出生年月日時、或者針對戒臘年歲、或者針對受戒是否如法、或者針對羯磨程序、或者針對是否犯了六聚罪（波羅夷、僧殘、偷蘭遮、波逸提、提舍尼、突吉羅）、或者針對是否妄稱得聖人法（過人法），隨便拿其中任何一件事去故意挑起疑惱，都結犯墮罪（波逸提）。《摩訶僧祇律》說：在對方即將受戒時，應當說出來讓他知道；受戒之後就不得隨便說，以免引發疑念悔恨。律中規定不犯的情況：事實確實如此，而且並非存心惱亂對方。例如對方確實不是在那個年月日時出生，擔心他日後生起疑悔，平白無故接受別人的利養、接受年長大比丘的禮敬，於是便對他說「你並非在那個時候出生」；如果對方戒臘確實沒有那麼長，擔心他日後悔恨接受利養恭敬，便對他說「你還沒有滿那麼多歲」；如果年齡確實不滿二十歲，或者在結界範圍內僧眾私自分裂成別眾，導致唱白不成、羯磨不成，構成非法別眾受戒；擔心他日後疑悔接受利養禮敬，因而告知讓他明瞭，以便讓他回到原處重新受戒；如果對方確實犯了波羅夷乃至惡說罪，擔心他日後悔恨接受利養、接受持戒比丘的禮敬，為了讓他如法懺悔，而告知他犯了六聚罪；又如果對方性格粗疏，說話不知輕重，便提醒他說「你所說的話屬於自稱得過人法（上人法）」等；或者說錯了、或者是開玩笑，這一切情況都開許不犯。

【26-0012】資持記/10c_中三下#3
【原文】《僧祇》中五，初明漉已看法。厭課謂事不得已，有同課率。象步遲緩，況有所載，迴必延久，故取為限。若施下，明請家漉法。虫不得語者，恐彼知而成犯故。虫水下，明還水法。不消，謂經久不涸。若知下，明知已存護法。顯意中。指同前戒。疏云：若據虫水，應合為一；
【譯文】《僧祇律》中有五點，首先說明過濾後檢視蟲子的方法。「厭課」是指事情迫不得已，如同趕工催促一般。大象步行遲緩，何況背上有負載，折返必定延宕很久，所以取此作為時間限制。「若施」以下，說明受居士迎請到家中濾水的方法。「不得向人說有蟲」，是擔心居士知道後倒掉而造成殺生之犯。「蟲水」以下，說明將蟲水送還原處的方法。「不消」，是指經過很長時間水都不會乾涸。「若知」以下，說明知道有蟲之後保存守護的方法。在顯明制戒意圖中，指出本戒與前戒相同。《戒疏》說：如果依含有蟲的水這點來看，理應合為一條戒；

【26-0013】資持記/10c_中三下#4
【原文】為重物命，故內外兩結。律不犯中。先不知，若無虫想；若虫，麁觸水使去；若漉水飲用，並無犯。六十三。〔佛在舍衛，十七群語五群言：云何入初禪？云何得羅漢果？彼報言汝說者犯波羅夷，佛呵因制。〕初緣者。《多論》：十三難，顛狂比丘，吉羅；學悔，六夜別住，四羯磨，僧尼互疑悔，皆提。釋第三。
【譯文】但為了鄭重愛惜物命，所以在室內濾水飲用與在野外道路飲用兩處分別結罪。律中規定不犯的情況：事先不知情，或者心中作無蟲之想；如果有蟲，只是粗略撥動水使牠們游開；如果是過濾後的水拿來飲用，這些全都算不犯。第六十三條戒。〔佛陀在舍衛國時，十七群比丘對五群比丘說：怎樣能入初禪？怎樣能證得阿羅漢果？五群比丘回報說你們這樣說犯了波羅夷重罪，佛陀呵斥後因而制戒。〕關於最初的犯緣，《薩婆多論》說：十三種難事、癲狂比丘，說此話結突吉羅罪；若是正在學悔、六夜別住、四種羯磨未了、僧尼相互生疑悔罪等情況，說了都結波逸提罪。解釋第三個犯緣。

【26-0014】01_行事鈔/07d_卷中之三#3
【原文】覆他麁罪戒六十四。五緣：一大比丘，二知犯二篇已上，三作覆心，四不發露，五經明相。《善見》：覆他罪，百千共覆一人，俱得提。《僧祇》：向善比丘說，不得輒說。若犯者凶惡，恐有難緣，應念：彼人行業，自有果報；猶如失火，但自救身，焉知餘事？時與護根，相應不犯。《多論》：若疑未了，不須說他。律中：若知他犯麁罪，小食知，至食後說，吉；食後知，初夜說；初夜知，中夜說，一切吉羅。若中夜知，至後夜欲說而未說，明相出，墮。除麁，覆餘罪；自覆罪；除尼，覆餘人罪者，一切吉羅。不犯者：先不知，不麁罪想，若向人說，或無人向說；若發心向說，明相已出；若諸難緣者，並開。
【譯文】覆他麁罪戒六十四。構成犯戒有五種因緣：一、對方是具足戒大比丘；二、知道他犯了前二篇（波羅夷、僧殘）以上的麁罪；三、生起包庇隱瞞之心；四、不向僧眾揭發發露；五、經過黎明天明（明相出）。《善見律毘婆沙》說：包庇隱瞞他人的罪過，縱使有成百上千人共同包庇一人，每個人都同得波逸提罪。《摩訶僧祇律》說：應當向善良持戒的比丘說明，不得隨便宣揚。如果犯戒之人性格兇悍險惡，恐怕揭發後會引來危難災患，此時應當作念默想：「那人造下的行業，自會有其因果報應；這就像失火的時候，自己救護己身尚且不及，哪裡還顧得上其他事？」此時（心念）與防護意根相應，合乎這種情理便不犯。《薩婆多毘尼毘婆沙》說：如果心中尚有疑惑未得查實，不需要宣說他人之過。律典中說：如果知道他人犯了麁罪，早上吃早粥（小食）時得知，拖延到吃完午齋（正食）後才說，結突吉羅罪；午齋後得知，拖延到初夜才說；初夜得知，拖延到中夜才說，這一切拖延情況都結犯突吉羅罪。如果中夜得知，到了後夜本想說卻還沒有說，黎明天明（明相出），就結犯波逸提墮罪。除了二篇麁罪之外，隱瞞其他輕罪；或者自己隱瞞自己的罪過；或者除了比丘尼之外，隱瞞其餘人（如沙彌等）的罪過，這一切都結犯突吉羅罪。不犯的情況：起初並不知道、不認為那是麁罪、已經向人說明、或者沒有適當的人可向其說明；或者已經發心要去說明，而明相恰好升起；或者有各種危難因緣，這些都開許不犯。

【26-0015】資持記/10c_中三下#5
【原文】六事。初生時者，即云汝非爾許時生。二年歲者，云汝非爾許歲，如餘受者。三受戒者，云汝受戒年不滿，又界有別眾。四羯磨者，汝受時羯磨不成。五六聚者，云汝犯夷乃至惡說。六聖法者，云汝所問法則，自稱上人法，犯重，非比丘也。隨下，通結。上引《僧祇》。但開正受。
【譯文】共有六種事。第一是「出生時節」，就是說你並不是在那個時候出生的。第二是「年歲」，說你並不是那個歲數，不像其他受戒者那樣。第三是「受戒情節」，說你受戒時年齡不滿，或者戒場結界中有僧眾別異分開的情況。第四是「羯磨法」，說你受戒時的羯磨沒有如法作成。第五是「六聚罪」，說你犯了波羅夷重罪甚至惡說輕罪。第六是「聖法」，說你所詢問的修行法則，是自稱證得上人法，犯了重罪，已經不再是比丘了。「隨」以下，作總結。上面所引用的《僧祇律》，只開許在正受戒時可以勘問。
