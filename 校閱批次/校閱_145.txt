# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【145-0001】02_戒疏/06c_卷二上之二#89
【原文】【記】三寶中，初科。上三句敘罪、福。二皆「深」者，由境勝故。「如」下，準教簡人。彼經云：「僧物難掌，佛、法無主，我聽二種人掌三寶物。一者阿羅漢，二者須陀洹。復有二種：一、能淨持戒，識知業報；二、畏後世業，有諸慚愧，及以悔心。如是二人，自無瘡疣。」
【譯文】【記文】在三寶的類別中，這是第一段。前三句敘述罪業與福報。兩者都極其「深重」，是因為所對應的境界至尊至勝的緣故。從「如同」往下，依據佛陀教法挑選合適的人選。那部經說：「僧團的物品極難掌管，佛陀與正法又沒有具體形相的物主，我只准許兩種人掌管三寶財物：第一是阿羅漢，第二是須陀洹。另外還有兩種人也可以：第一、能清淨持戒，深切明了業果報應的人；第二、畏懼來世惡業，具備種種慚愧心與悔改過失之心的人。像這樣的兩種人，自然不會產生過犯瑕疵。」

【145-0004】02_戒疏/06c_卷二上之二#92
【原文】【記】次文兩判。初望護主，「佛」下，二、斷施福，並犯夷重。《鼻奈耶》云：「若盜佛塔、聲聞塔等幡蓋，皆望斷施主福邊，得棄捐不受。」若準《鈔》中「佛無我所，例非人結蘭」，今文不出，故指如彼。

【145-0006】02_戒疏/06c_卷二上之二#94
【原文】【疏】初、佛受用物者。如堂宇、衣服，及以金石、泥土，曾為佛像之所受用者，不得差互，常擬供養，生世大福。故《律》云：「若是佛園、坐具等者，一切天、人供養，同塔事故。」所以不許者，莫不即體法身之相，表處是深，不得輕故。
【譯文】【疏文】第一、佛陀親自受用之物。例如殿堂房舍、衣物袈裟，乃至金銀、石材、泥土等，曾經作為佛像受用之物，都不可隨意移作他用或混淆，必須經常準備作為供養之用，以此能令世間眾生生起廣大福德。所以《律》說：「若是屬於佛陀的園林、坐具等，一切天人皆當供養，等同於造塔佛事。」之所以不准挪動移轉，無非是因為這些物品即是體現佛陀法身的表相，其所象徵的深意非同小可，絕不可輕忽對待。

【譯文】【疏文】有人缺乏見識，焚燒損毀殘破的佛經，號稱「我如今用火加以清淨」，自以為「這樣做能得福報」。這真是荒謬妄作的推想！為求佛法半句偈頌而不惜捨棄身命，明明白白記載於經典法典之中；僅僅「常住」二字就能除去惑業，也確切列在正法大乘經中。怎能焚燒除滅，從而失壞了經事常在所生之福（事在福）呢！

【145-0020】02_戒疏/06c_卷二上之二#108
【原文】【記】次科。前出謬見。「此」下，次據文斥。上引「半偈捨身」者，一、彰如來求法之勤，二、示如來重法，三、顯正法難聞。下引經證，「兩字除惑」，顯佛法功深，舉少況多，其過彌甚。儻畏來苦，勿逐魔徒。二緣並出《涅槃經》。彼云「佛告迦葉菩薩言：『過去之世佛日未出，我於爾時，住於雪山，唯食諸果。食已，繫心思惟坐禪。經無數歲，不聞如來大乘經名。修是苦行時，釋提桓因，自變其身作羅剎像，下至雪山，宣過去佛所說半偈云：「諸行無常，是生滅法。」乃至聞此半偈，心生警疑：「汝今幸可說竟此偈？」羅剎答言：「今我實為飢苦所逼，實不能說。」我即問言：「汝食何物？」羅剎言：「惟人煖肉，其所飲者，唯人熱血。」我復語言：「且說半偈。我聞偈已，當以此身，奉施供養。」羅剎即說半偈云：「生滅滅已，寂滅為樂。」菩薩徧於石、壁、樹、道，書寫此偈已，即上高樹，投身樹下。身未至地，虗空之中，出種種聲，乃至阿迦尼吒。爾時羅剎，還復帝釋形，即於空中，接取菩薩，安置平地。』」云云。又《經》云「善男子！若復有人，不知如來甚深境界，乃至輪轉生死，增長諸結，多受苦惱。若有能知如來常住，無有變易。或聞『常住』二字，若一經耳，即生天上。後解脫時，乃能證知如來常住無變易」等。言「事在福」者，如施主作橋、井等事。隨在福生，緣壞則「失」，名「事在無作」。今燒故經，其事亦爾。
【譯文】【記文】接著是第二段（斥責焚經謬見）。前面指出錯誤的見解。從「這真是」往下，接著引據經典駁斥。上面引用「為半偈捨身」，第一是彰顯如來求法的勤奮，第二是顯發如來對正法的尊重，第三是表明正法難值難遇。下面引用經典證明「常住兩字能除惑業」，顯明佛法功德極其深厚，藉由少許功德來襯托更廣泛的妙益，毀經的過失自然更加嚴重。如果懼怕未來的苦報，切莫跟隨魔道之徒的做法。這兩段因緣全都出自《大涅槃經》。該經記載「佛陀告訴迦葉菩薩說：『過去佛陀慧日尚未出世之時，我當時住在雪山中，純粹食用種種野果。吃完之後，專心靜慮坐禪修道。經歷了無數歲月，不曾聽聞如來大乘經典的名號。在修持這種苦行之時，釋提桓因將自己化現為羅剎惡鬼的形象，降臨到雪山，宣說過去佛所說的半首偈頌說：「諸行無常，是生滅法。」我聽到了這半首偈頌，內心驚喜戒惕而問道：「你如今可否好心為我把這偈頌說完？」羅剎回答說：「我現在實在被飢餓痛苦所逼迫，實在無法說法。」我立刻問他說：「你吃的是什麼食物？」羅剎說：「我只吃人的溫熱血肉，所喝的唯有人的熱血。」我又對他說道：「請你暫且說完後半偈。我聽完這偈頌之後，願意將這個身軀奉獻布施給你享用。」羅剎便說出後半偈道：「生滅滅已，寂滅為樂。」菩薩聽聞後，在山石、牆壁、樹木、道路上處處書寫這首偈頌，寫完之後，就爬上高樹，縱身從樹上跳下投身捨命。身體尚未落到地面時，虛空之中發出種種讚歎聲響，一路震響至色究竟天。這時羅剎變回帝釋天原本的形象，立刻在空中接住了菩薩，安穩地放置在平地上。』」等等。經文又說「善男子！如果有人不知道如來甚深法性境界，在生死之中不斷流轉輪迴，增長各種煩惱結縛，承受諸多苦惱。若有人能知道如來是常住不變、無有變遷移異的，甚至只要聽聞『常住』這兩個字，只要一經過耳根，命終即刻生到天上。日後得到解脫之時，就能親自證知如來常住無有變異」等法語。所謂「事在福」，就如同施主修造橋樑、開鑿水井等工事，只要工事完好存在，福報就隨之滋生；設施毀壞了善業果報就跟著「失去」，這稱為「事在無作」之戒福。如今焚燒舊經書，其道理也是一樣的。

【譯文】【疏文】關於僧團的財物，共有四種差別。

【145-0024】02_戒疏/07a_卷二上之三#2
【原文】【記】僧物中。前二屬處永定，通名「常住」。但前無分義，後是可分，故加「常住」、「十方」以簡之。後二俱是即施，通名「現前」。但前局當處，後通內外，故加「現前」、「十方」以別之。
【譯文】【記文】在僧物之中，前兩種財物所屬的處所永遠固定，統稱為「常住物」。但第一種完全沒有分給個人的道理，第二種則是可以分用的，所以分別加上「常住」與「十方」來作揀別。後兩種都是當時現前布施的，統稱為「現前物」。但第三種僅限於當地的僧眾，第四種則通於內外各方僧人，所以分別加上「現前」與「十方」來作區分。

【145-0025】02_戒疏/07a_卷二上之三#3
【原文】【疏】一、常住常住物。如堂宇、田園、人、畜、米麫。屬處已定，不可分割。必欲惠給餘寺，羯磨和與。若直送者，是名「盜損」。或有主掌自盜，不望十方不滿，隨取計五，便與極重。如《僧祇》中，縱集得僧，亦不可分故。
【譯文】【疏文】第一種是「常住常住物」。例如殿堂、房舍、田地、園林、奴僕、牲畜以及米麵等。它們所屬的寺院已經固定，絕對不可以分割。如果一定要贈送給其他寺院，必須透過僧團羯磨作法取得共識才能給予。如果直接送去，就稱為「盜損」。或者有掌管這些財物的人監守自盜，此時不論分算給十方僧每人是否不滿五錢，只要隨手盜取的價值達到五錢，就直接判處最重的波羅夷罪。如同《僧祇律》所說，縱使召集了全體僧眾，這類財物也是不可分給個人的。

【145-0026】02_戒疏/07a_卷二上之三#4
【原文】【記】初中分四。初出物體。「屬」下，示名義。「或」下，明結犯。餘盜望主，此義易知，故文但出「主自盜」耳。「如」下，引證。
【譯文】【記文】這第一部分分為四層。首先列出物品本體。從「屬」字以下，說明名稱的意義。從「或」字以下，說明結罪的判定。其他外人來盜竊，是針對管物主人結罪，這道理容易明白，所以文中只特別提出「主管自盜」的情形。從「如」字以下，引用律典來作證明。
