# 校閱材料　第217檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【217-0001】03_業疏/17b_卷三之六#80
【原文】次學法中正學宗者即今所受正戒摩觸須淨曉者淨謂奉持無犯曉即明達教相
【譯文】在下一項學法之中，所謂「正學宗」，就是指當前所受的正式戒條；所謂摩觸戒必須「淨曉」，「淨」是指奉持而絲毫不犯，「曉」就是指通達明了戒條的教相。

【217-0002】03_業疏/17b_卷三之六#81
【原文】乃至眾中故作妄語戒學別論相天分也五非時食六飲酒者此無可對直舉學本盡形行之
【譯文】乃至於在眾僧中故意說妄語，重戒與學法應當分別論述，兩者的界限相狀如同天地之懸殊一樣涇渭分明。第五條「非時食」、第六條「飲酒」，這兩條在根本十戒中沒有別論的對應相，只是直接舉出修學的根本，盡形壽奉行持守。

【譯文】在解釋其餘戒相中，首先比照說明其餘三種重戒。由於後面三種戒相中，都是先列出根本重戒、後說明具體學法，所以說「戒學別論」。「相天分者」，是說如同天與地的高下差別一樣顯而易見。自「五」以下分別解釋最後兩條戒，因為只有學法本身，所以沒有像前文那樣的重戒與學法相對之文。

【217-0005】03_業疏/17b_卷三之六#84
【原文】大尼所奉戒應學者增本位故學相亦同
【譯文】比丘尼所奉持的戒律中式叉摩那亦應當修學者，是因為提升了原有的沙彌尼位階，所以修學戒相也是相同的。

【217-0006】03_業疏/17b_卷三之六#85
【原文】三簡行同法中初文增本位者過沙彌尼也
【譯文】在第三項「揀別同等隨行法」的初文中，所謂「增本位者」，是指其階位已超過了沙彌尼。

【217-0007】03_業疏/17b_卷三之六#86
【原文】若爾，沙彌亦通萬境，應名學士也？答：學有漸頓，制有緩急。士則隨境能防，雖犯無重加法；女則易為緣壞，增位尊。彼沙彌犯，則隨缺便補。如大僧行高德遠，以所防多故，餘四漸踈，故位隨降，可通照矣
【譯文】如果這樣的話，男眾沙彌的戒行也是通於一切境緣，難道沙彌也應當稱為學士（式叉）嗎？答：修學有漸進與頓得之別，制定戒律有寬緩與急迫之分。男士能夠隨逐境界防護己心，縱使犯戒也沒有重新加受學法的規制；女眾則容易被境界牽引而毀壞戒行，所以增設位階以崇重其行。那沙彌若是犯戒，只要隨缺隨補（懺罪）即可。如同大僧（比丘）戒行高超、道德深遠，因為所防範的戒法最多，其餘四眾所防範圍漸次減少，所以位階隨之降低，這其中的道理是可以通觀照見的。

【217-0008】03_業疏/17b_卷三之六#87
【原文】問中，式叉同尼，故得名學；沙彌同僧，例亦應爾。答中，初二句通示。士下別答：初明沙彌不名所以，由望大戒則為緩，望不增位故為頓，則學頓而制緩也。若準他文，亦名小學，但非本號，故沒不彰；女下次明式叉得名之意，則學漸而制急也。仍舉五眾所防多少，以顯沙彌、式叉二位優劣得名不同
【譯文】在問句中，式叉摩那的行持通於比丘尼，所以得以稱「學」（學法女）；沙彌通於比丘僧，按例也應當如此稱呼。答句中，前兩句通體開示；自「士」字以下分別回答：首先說明沙彌不稱「學法」的緣由，因為相對於具足大戒而言其制較寬緩，相對於不另立新階位而言則屬於頓受，這就是「學頓而制緩」。如果依照其他文獻，沙彌也有稱為「小學」的，但這並非正式本名，所以隱沒不彰；自「女」字以下接著說明式叉摩那得名的深意，這就是「學漸而制急」。接著再列舉出家五眾所防範戒條的多寡，以顯明沙彌與式叉摩那兩者優劣及得名不同的緣由。

【217-0009】03_業疏/17b_卷三之六#88
【原文】除自手取食、授食與他」者，有人解為二緣，今則不然。餘行竝同大尼，唯開不受授尼，不同尼從人受，方與尼有此異耳。若論不受惡觸，何得不無？戒下四眾，罪不虗列，理自從人，方可進耳
【譯文】經文所說的「除自手取食、授食與他」，有人解釋為兩種開許的因緣，如今判定並非如此。其餘隨行全都與大尼相同，唯獨開許她們可以不必親自領受食物即可轉授給大尼，不同於大尼必須先從他人處接受受食法，正是在這一點上與比丘尼有所不同而已。若是論及自手取食而觸犯「不受食惡觸」之戒，哪裡能說沒有過失呢？在「不受食而捉持」的戒條下列出了下四眾，其結罪絕非虛設之文，按理自然應當由他人授與，方可進食。

【217-0010】03_業疏/17b_卷三之六#89
【原文】次釋異中，初出古解為二緣者。彼謂「除自手取」，即開自不受而食也；「授食與他」，開為他作能授人也。今下，次示今解。初約一緣釋通文相。「不受授尼」對簡大尼受已可授，準鈔亦據無人方開。若下次斥古謬說。不受食戒下列四眾，可驗同制，義無輙捉
【譯文】在隨後解釋差異中，首先列出古德解釋為兩種因緣的說法。古師認為「除自手取」就是開許自己不用經過授受程序而直接進食；「授食與他」是開許可以作為能授之人而布施食物給他人。自「今」字以下，接著提出當前的正解：首先依據一種因緣來貫通文句相貌。「不受授尼」，是相對於比丘尼而言——大尼必須先領受然後才能轉授他人，依照《事鈔》也是依據沒有淨人等無人之時才作開許。自「若」字以下接著斥責古代的謬誤之說。「不受食戒」之下列舉了出家下四眾，足以證明同樣受到該戒的規制，在義理上絕不可隨意自行抓取食物。

【217-0011】03_業疏/17b_卷三之六#90
【原文】此二學法女具學三法下文列三品相極曉然以今通誦不識戒學故為分之無所解也
【譯文】這兩種學法女（曾嫁女與童女）應當具足修學三種戒法，下文列出的三種品階相貌極其明了；因為如今大家只是籠統讀誦而不認識戒與學的差別，所以在此為其分列，其實文字本身淺顯並沒有不可解之處。

【217-0012】03_業疏/17b_卷三之六#91
【原文】三法中初科初指文顯以下次示分意無所解者言易見也
【譯文】在「三法」的第一科中，首先指出經文相貌極為顯明；自「以」字以下，接著說明加以區分的用意；所謂「無所解」，是說經文義理顯豁易見。

【217-0015】03_業疏/17b_卷三之六#94
【原文】近人行事，是沙彌者，例著五條；至於六法，還同本服。是則律崩法壞，漸訛替也。為師為匠，俱行諂附，密誘沙彌，不覺滅法。以多論文，沙彌二衣：一當安陀會，擬常務也；二當鬱多羅僧，擬入眾也。若是正衣，不應云「當」，故以位分上下，衣服標異也。律無明斷，故有斯漸
【譯文】近代主持教事的人，凡是沙彌便照例穿著五條衣；至於到了六法學戒女，反而依舊穿著原來的服飾。這真是規律崩毀、法度壞失，日漸訛誤衰替啊！為人師範的大德，全都一味諂媚迎合，暗中放任誘導沙彌僭越，卻不知這是在無形中滅絕佛法。因為依照《薩婆多論》的記載，沙彌只有二衣：第一種相當於（當）安陀會（五條衣），用以應對日常事務；第二種相當於鬱多羅僧（七條衣），用以預備進入大眾集會。如果是正式的條衣，文中就不應當使用「當」（相當於、充當）字，所以應當以僧位區分上下尊卑，在衣服上標示出差異。正因為律文中沒有明確判斷禁止，所以才演變出這樣的漸次訛誤。

【217-0016】03_業疏/17b_卷三之六#95
【原文】斥濫中初科，初敘訛。沙彌著五條，則僭於上；式叉同本服，則屈於下。是下正斥。諂附謂私於己徒，密誘謂容其僭濫。下引多論證知非法。「當」字去呼，代也。故下結上相傳。律下究訛所以。故有斯漸，謂漸訛也
【譯文】在斥責混濫的第一科中，首先敘述其訛謬之處：沙彌若穿著五條衣，就是僭越了上座；式叉摩那若仍穿原本的沙彌尼服，就是屈抑了其位階。自「是」字以下正面斥責：「諂附」是指對自己的徒弟徇私溺愛；「密誘」是指縱容其僭越混濫。後文引用《薩婆多論》證明這種做法是非法的。「當」字讀去聲（讀如「檔」），是充當、替代的意思。自「故」字以下總結上面古代相傳之規矩。自「律」字以下探究訛誤產生的緣由。「故有斯漸」，是指逐漸演變成的訛失。
