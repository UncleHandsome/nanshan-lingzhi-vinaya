# 校閱材料　第145檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【145-0001】01_行事鈔/07b_卷中之三#27
【原文】律中不犯開七緣：一病時者，下至脚跟劈。《善見》云：砂土入中不能行。二作衣時者。自恣竟，無迦絺那衣一月，有則五月是也。三施衣時者。如前背請戒，道船二行為四五二緣者，下至半由旬內來往上下是。六大眾集者。食足四人，長一人為患是；乃至百人，長一人為患。今京輦設供，每有不依疏僧，闐𨶮門首；請家拒閉，不令輒進；大德英達，安然坐食，知外有僧，不思命召。親見其事，過深鄙俗；望諸行者，見聞斂迹。《五分》云：門外有客比丘不得入者，乃至語往本寺取食等。廣如〈訃請法〉中。七者沙門施食時。謂在此沙門釋子外，諸出家者是也。又準論中，僧次不犯；《五分》衣時，都合九緣。《增一》云：師子長者別請五百羅漢，佛言：不如僧次一人，福不可量。因說如飲大海，則飲眾流。師子言：自今已後，當不別請。佛言：我亦不令別施，以無有福。師子便平等施，亦不言此持戒犯戒。佛讚：善哉！平等之施，獲福無量；平等施者，施中第一。《賢愚經》以㲲施佛，佛讓與僧，義意同此。正使將來法垂滅盡，比丘畜妻挾子，四人已上，名字眾僧，漫請供養，應當敬視如舍利弗等。律明開緣，僧次一種，功益自他；病等諸緣，但能自益。律中若無如上諸緣，即起白言：「我於此別眾食中無因緣，今欲出。」餘人無緣者，亦爾。若有別眾食緣欲入者，當白言：「我有別眾緣欲入。」白已，隨次入。若有緣不白者，吉羅。不犯者，如上所開。
【譯文】律中不犯開七緣：第一、患病之時，輕微者乃至腳跟龜裂。《善見律》說：砂土嵌入裂縫疼痛以致無法行走。第二、縫作僧衣之時。結夏自恣完畢後，若無受持迦絺那衣則有一個月作衣期，若受持了功德衣則有五個月的作衣期即是。第三、布施衣物之時，其開緣如前文「背請戒」中所述。第四與第五種因緣，即道路行腳與乘船航行兩種情況，最低限度須在半由旬以上往來奔波或順逆航行即是。第六、大眾雲集之時。原本準備的食物只夠四個人食用，多出一名僧人便會造成匱乏之患即是；乃至多達百人用餐，多出一人便成憂患亦是。如今長安京師設齋供養，經常有未列入受請名冊的僧人，闐𨶮於施主府門之外；設齋的主家緊閉門戶拒絕，不准他們隨意入內；而堂上的名宿大德、英邁之士，卻安然端坐享用齋供，明知門外尚有僧眾，卻根本不考慮傳話招呼迎請入內。貧道親眼目睹這類事情，其過失極為深重，行徑鄙陋低俗；殷切期望各位修道行者，在見聞此事之後應當收斂反省自己的行徑。《五分律》說：門外若有客比丘無法入內受供，乃至應當指派人告知他們返回原寺院領取食物等等。此中詳情正如〈赴請法〉（訃請法）中所廣泛闡述。第七、其他沙門施設飲食之時。這是指在釋迦牟尼佛門下的釋子沙門之外，其他各派外道出家修行者所施設之供養即是。此外，依照論典中的標準，依僧次受請者不犯；加上《五分律》中細分開許的衣時等，總共合計有九種開緣。《增一阿含經》說：師子長者指名別請了五百位阿羅漢應供，佛陀開示說：「這還不如依僧次迎請一位普通僧人，供養後者的福德無可限量。」佛陀因而設譬喻說，這猶如飲用大海的一滴水，便是飽飲了千百條江河的匯流。師子長者聽聞後說：「從今以後，我絕不再指名別請。」佛陀說：「我也並未教你別行布施，因為那樣做福德狹劣。」師子長者於是轉為平等普及布施，也不去分別這位僧人是持戒還是犯戒。佛陀讚歎道：「善哉！平等之施，獲福無量；平等的布施，在所有布施中居於第一位！」《賢愚經》中記載，有施主以細織白布（㲲）布施給佛陀，佛陀卻轉而禮讓並將之布施給常住僧團，其深遠的意趣也是與此相同。縱使到了將來末法即將滅盡之時，出家比丘畜養妻室、攜帶兒女，只要有四人以上聚集，名義上稱作眾僧，施主盲請漫供，內心亦應當像恭敬視奉舍利弗尊者等人一樣來對待。律中所說明的開緣之中，「僧次」這一種方式，其功德利益能廣被自他二利；而生病等其餘各種因緣，則僅能利於自身。在律制中，若是沒有上述各項開許因緣，便應當離席站起稟白說：「我在這次別眾食中並無因緣，現在準備離去。」其餘沒有開緣的比丘也是同樣應當起白離席。如果具備別眾食的開許因緣而想要入席者，應當當面稟白說：「我有別眾的因緣，現在想要入內。」稟白完畢之後，再依照戒臘次序入席。如果具備開緣卻不作稟白就逕自入席者，結突吉羅（吉羅）。不犯的情形，正如上述所開許的各條。

【145-0002】01_行事鈔/07b_卷中之三#28
【原文】取歸婦賈客食戒三十四。五緣：一是上二緣，二知是，三無緣，四取過三鉢，五出門便犯。
【譯文】取歸婦賈客食戒三十四。具備五種緣成犯：一、施主是上述兩類人（返鄉歸寧之婦女，或長途行商之商客）；二、明知對方的身分如此；三、自身並無合理的正當因緣；四、索取接受超過了三滿缽的食物份額；五、跨出門限便結犯。

【145-0003】01_行事鈔/07b_卷中之三#29
【原文】足食戒三十五。五緣：一是可足食，二知境足，三捨威儀，四無緣。五更食犯。律中，若飯麨，乾飯是正食，堪飽足故名足食。五緣：一知是飯。二知持來。三知遮。四知威儀。五知捨威儀。足食已，捨威儀，不作餘食法，得而食之，咽咽墮。《僧祇》：捨威儀者，八種威儀。且如床上坐已，若見師僧塔像在背後者，迴身避坐，曳身不得離床，若離名捨威儀。若正食時，天雨，於上持蓋；無者，合床舁著覆處；舁時倒地，及諸緣而離本處，更食犯墮。《五分》五事：一有食，二授與，三受啖，四不復受益，五身離本處，更得食墮。國土無粥，晨朝開飲麨漿。
【譯文】足食戒三十五。具備五種緣成犯：一、食物是可以使人飽足的正食（可足食）；二、明知自己所對的情境已構成「足食」（即施主勸食而自己已拒絕）；三、捨棄了原先就座用齋的威儀（離座起身）；四、無生病等正當開緣；五、再次進食便結犯。《四分律》中說明：若是米飯、麨粉、乾飯，這些均屬正食，因為能夠使人吃飽果腹，故稱為足食。構成足食具體有五種條件（五緣）：一、明知端來的是正食（如飯）；二、明知是施主親手拿來勸食；三、明知自己已經作口頭或推手之拒絕阻擋（知遮）；四、明知自己正處在進食的威儀之中；五、明知自己已經站起離開原座而捨棄了進食威儀。在構成了足食之後，一旦捨棄了進餐威儀，又未經由其他比丘為其作「餘食法」，若是再次獲得食物而吃下它，每吞咽一口結一個波逸提（單墮罪）。《僧祇律》說：所謂捨棄威儀，涵蓋了八種威儀之變換。姑且例如已經在繩床上坐定，如果見到親教師、阿闍梨僧尊長或佛塔聖像正位於自己的背後，為了避開不敬而轉身換向坐，此時只能拖曳挪動身體而絕對不可離開床座，若是身體離開了床座，就稱作「捨威儀」。如果正在用餐的時候天降大雨，應當在頭頂上撐拿雨傘；若沒有雨傘，應當將人連同床座一起抬到有屋頂遮蔽之處；若在抬移過程中翻倒在地，以及因為其他各種突發因緣而離開了原先的座位處所，之後再吃東西就結犯波逸提（單墮罪）。《五分律》提出五件事相以定犯：第一、有如法的食物；第二、施主親手端呈遞與；第三、比丘領受並已吃了一口；第四、比丘表示不再接受增添加益（不復受益）；第五、身體離開了原來的座位處所，之後若是再次獲得食物進食，便結墮罪。在沒有粥食的邊遠異國，清晨時分開許可以飲用麥粉調製的麨漿。
