# 校閱材料　第322檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【322-0001】資持記/15e_下三#50
【原文】以威儀悟物，故稱威儀第一。身子與目連為友，共結契云：若得甘露，必當同味；後時身子見馬勝，威儀庠序；乃問汝師是誰？為說何法？答云：法從緣生，亦從緣滅；一切諸法，空無有主。〔此依《五分》引，或有出云：諸法從緣生，亦從因緣滅；我佛大沙門，常作如是說。〕身子聞已，便證初果；
【譯文】以威儀化導啟悟物類，所以被稱讚為威儀第一。舍利弗（身子）與目犍連為好友，共同約定立誓說：『若誰先獲得不死甘露妙法，必定要一同分享法味。』後來舍利弗見到馬勝比丘，行止威儀安詳整肅；便詢問他說：『你的師父是誰？為你宣說什麼法？』馬勝比丘回答說：『諸法從因緣而生，亦從因緣而滅；一切諸法，本性皆空、沒有主宰。』〔這是依據《五分律》所引，或者有的典籍記載為：『諸法從緣生，亦從因緣滅；我佛大沙門，常作如是說。』〕舍利弗聽聞之後，當下便證得初果；

【322-0002】資持記/15e_下三#51
【原文】次傳向目連，亦證初果；後同馬勝往佛所出家也。傳法等者，即第五祖優波毱多，威儀肅物，率皆從化，如佛無異；但無相好，時人號為無相好佛。又第二十祖闍夜多，善持威儀，見無不敬；佛曾記之，闍夜多者，最後律師。故知諸祖傳通，並以威儀，令生物善。方冊，即《付法藏傳》。
【譯文】隨後他將這段開示轉傳給目犍連，目犍連也當下證得了初果；後來兩人便一同跟隨馬勝比丘前往佛陀那裡出家求道。所謂傳法之人等等，是指第五代祖師優波毱多尊者，他的行止威儀極其肅穆莊嚴，凡是他所教化教導的眾生無不欣然遵從歸化，如同佛陀在世教化毫無差別；只不過他身上不具備三十二相、八十種好，當時的人都敬稱他為「無相好的活佛」。又有禪宗第二十代祖師闍夜多尊者，平生極善於奉持行止威儀，見到他的人無不肅然起敬；佛陀在世時曾為他授記說：未來的闍夜多，將是最後一位大律師。由此可知歷代諸位祖師傳承宣通大法，全都是憑藉嚴謹的威儀，來令廣大眾生生起清淨善心。所謂「方冊」，是指《付法藏因緣傳》這部典籍。

【322-0003】資持記/15e_下三#52
【原文】故下，結前起後。列示中，初文，《五分》。明威儀，化物功深；闕則二利俱失，故非大明也。《僧祇》。明行法。平視，頭不俯仰也。合身迴，不但轉項也。《中含》，初別示行法，續上《僧祇》。狩王，即師子及象王。若下，通明四儀；初明入聚，即示行法。
【譯文】自「故」字以下，總結前面並生起後文。在分項開示中，第一段文，引《五分律》。闡明行立坐臥具足威儀，教化導引物類的功德極為深廣；若缺乏威儀則自利利他兩皆喪失，所以說不能在世間作為破除昏暗的大光明。引《僧祇律》。闡明行步之法。所謂「平視」，是頭部不向下俯低也不向上昂仰。所謂「合身迴」，是指轉身時必須整個身體一同轉向，而不單單是扭轉頸項脖子。引《中阿含經》，首先個別開示行步的法度，承接上面《僧祇律》的內容。所謂「狩王」，是指百獸之王獅子以及象王。自「若」字以下，通盤闡明四種威儀；首先闡明進入村落聚落，即是開示行步之法。

【322-0004】資持記/15e_下三#53
【原文】無事處，即阿蘭若。合明食法，文見〈頭陀〉。或下，次明住坐二法。於中下，後明臥法。頭面向像，無背違故。係想明相，不著睡眠故。《僧祇》。臥法大途同上，文復詳委，但頭向不同。衣架師長，皆尊處故。合口拄齗，心易定故。念慧，所修觀行，不暫忘故。指如上者，即想明相等。《十誦》。
【譯文】所謂「無事處」，就是指阿蘭若寂靜空處。此處本應合起來說明進食的法度，詳細經文可見於〈頭陀行〉篇。自「或」字以下，接著說明站立與安坐兩種法度。自「於中」以下，最後說明睡眠躺臥的法度。頭部和臉面應當朝向佛像，是為了表達絕不違背相逆的恭敬心。心念繫著想念天明的光相，是為了不讓身心耽著沉溺於睡眠。引《僧祇律》。睡眠躺臥之法大體與上文相同，文字則更為詳實周密，只不過頭朝的方向有所不同。頭朝著衣架與師長的方向，因為這些全都是尊貴的處所。閉合口唇、舌尖抵住上牙齦，是為了讓內心容易得定。保持正念智慧，是為了讓平日所修習的觀行工夫，在一刻之間也不至忘失。指引「如上」所說的，就是指心想光明相之類的法門。引《十誦律》。

【322-0005】資持記/15e_下三#54
【原文】明燈不臥，恐裸露故。出行中，初科，前明摒淨。〈隨相〉，即覆處敷僧物戒。去時下，明白告。後去時下，明觀方量伴。利衰，謂有益無益。時言，謂當言即言。若有下，明暫住復去法。下座得病下，明遇病料理法。上座有病，理合看視；故但明下座，恐捨棄故。得脫，謂差損。次科，初示行法。
【譯文】在明亮燈光下不可睡眠躺臥，是擔心身體會在無意中裸露失儀的緣故。出行篇中，第一小科，前半部分說明出行前將住處打掃收拾乾淨。〈隨相釋〉中，就是指在能遮雨的覆處鋪設僧物之戒。自「去時」以下，說明必須如法明白告稟長老。自「後去時」以下，說明應當審慎觀察前往的方向並妥善選擇同行的同伴。所謂「利衰」，是指此行到底是有法益還是無益受損。所謂「時言」，是指該說話的時機就說話。自「若有」以下，說明暫時借住隨後又離開的法式。自「下座得病」以下，說明同行者遇到生病時的照料護理之法。上座若生病，下座理所當然應該精心看護；所以此處只強調說明下座生病的情況，是擔心同行上座會心生厭倦隨意將其捨棄離去。所謂「得脫」，是指病體痊癒康復。下一小科，首先開示行步之法。

【322-0006】資持記/15e_下三#55
【原文】先指後跟，是賤下相。在下，明覓處。前食即小食，後食即中齋。當白入者，由覓宿食，必入俗舍故。三中。安詳，離卒暴故。一心，離雜念故。觀地二意，即止作也。不退菩薩，舊云初地已去。坐臥中，初科；《僧祇》，前明坐法。駱駝，謂兩膝拄地。次明臥法。仰是慢相，伏即飢相，左脇婬相；
【譯文】走路時若是腳趾先著地、腳跟後著地，這是低賤下流之相。自「在」字以下，說明尋找宿處的規範。所謂「前食」是指早晨的小食（朝粥），「後食」是指正午的午齋。之所以應當先行白告而後進入，是因為為了尋找住宿與飲食，勢必會走入世俗人家的宅院。第三小科中。神態安詳從容，是為了遠離魯莽急躁的粗暴心態。一心專注，是為了遠離紛飛雜亂的妄念。行走時觀看地面具有兩種用意，就是止惡與作善的止作二持。所謂不退轉菩薩，古德多解釋為初地以上的證果菩薩。在坐臥法的第一小科中；《僧祇律》前半部分闡明坐法。所謂「駱駝坐」，是指雙膝直接跪柱在地上。後半部分闡明睡姿臥法。仰臥是驕傲怠慢之相，伏臥是飢餓困頓之相，左脇臥是貪著婬欲之相；

【322-0007】資持記/15e_下三#56
【原文】如法，即右脇臥。指三十五者，彼云：應如師子獸王順身臥，若右脇有癰瘡，無罪，不者越威儀。《增一》。手按，彼因外道抽除床攊，故制。〔攊音曆，今謂床桄〕。《十誦》。制晝臥者，有病應開。喜眠令經行者，除昏思故。《善見》，初制繫想。三寶、戒、施、天，為六念。
【譯文】合乎佛法的如法臥姿，就是必須保持右脇著地而臥。所指的第三十五卷，彼律文中說：應當如獸王獅子般順著身體右脇而臥，如果右脇長了癰疽瘡痛，開許左臥無罪，若非如此則違越了威儀之戒。引《增一阿含經》。用手按摸檢視床具，彼處是因為外道曾故意抽掉床板的橫木床桄，想要陷害僧人摔倒，所以佛制定此防護規範。（「攊」字讀作曆，現在俗稱床桄。）引《十誦律》。戒律禁止在白天躺臥，若有疾病則應當開許。對貪嗜睡眠者命令他去經行，是為了消除昏沉睡眠的思緒。引《善見律》，首先規定應當繫念正法。心念三寶（佛、法、僧）、戒法、布施、諸天，合稱為「六念」法門。

【322-0033】資持記/16a_下四#23
【原文】作惡生善道者，準天台《十疑論》，三義通之：一者約心，以造罪時，從虛妄顛倒心生，是虛；今因知識勸導，改心是實故。二者造罪時，由癡暗虛妄為緣，是偽；今遇知識，得聞佛名，發菩提心是真故。三決定者，前造罪時，心有間斷；今臨終時，心猛利故；
【譯文】一生造作惡業卻能在臨終轉生善道者，依照天台智者大師《淨土十疑論》的說法，可以從三個義理層面來貫通融會：第一是就「心念的真偽」而言，造作罪業之時，是從虛妄顛倒的攀緣心所生起，本質是虛妄的；如今臨終因善知識的開導勸誘，洗心革面，這種悔悟之心是真實的緣故。第二是就「境界的真偽」而言，過去造作罪業，是因愚癡暗昧的妄想作為助緣，其境是偽造的；如今值遇大善知識，得以親聞諸佛名號，所發出的菩提心是真實不虛的緣故。第三是就「心力的強弱決定」而言，先前造作罪業時，其心念時斷時續；如今面臨死亡關頭，心念猛烈專注無比的緣故；
