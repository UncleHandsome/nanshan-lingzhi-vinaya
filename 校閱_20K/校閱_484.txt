# 校閱材料　第484檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【484-0001】資持記/04b_上三#20
【原文】觸八二戒尼通夷重，恐謂俱障，故引簡之。文中若摩觸為一句。下二句明八事，上句約八人共成，下句約一人獨作。準《疏》八尼合作八人，傳寫誤也。彼律問云：頗有污尼，未受戒者應受，已受不應滅擯耶？佛言：有，若以身相觸污尼是。又問：頗有污尼人得與受戒耶？
【譯文】身觸與行八事這兩條戒，在尼戒中都通於波羅夷重罪，唯恐有人認為全都障礙受戒，所以引文加以揀別。文中「如果摩觸」算作一句。下面兩句說明八事，上一句是指八人共同做成，下一句是指一人獨自作八事。比照《戒疏》，「八尼」應當作「八人」，這是傳抄時的錯誤。該律提問說：是否有污損比丘尼，未受戒者應該准許受戒，已受戒者不應滅擯驅逐的？佛回答說：有，如果是以身體互相摩觸而污尼者就是。又提問說：是否有污損比丘尼之人，仍得以給予受戒的？

【484-0002】資持記/04b_上三#21
【原文】答：有，若八人以八事污尼，尼名污，八人不名污；又復一人以八事污尼，尼名污，是人不名污。令下二句，總結二戒。八事具如〈尼篇〉。雜相中，論文三段，初簡下眾。若下，明通三道。據本成婬，不勞此示；為遮疑濫，謂餘非障故。若下，辨形服。義決中，初正決。
【譯文】回答說：有，如果是八個人以八事來污損比丘尼，比丘尼算被污，這八個人不算犯污難；又如果是一個人對尼行八事，比丘尼算被污，這人也不算犯污難。從「令」字以下的兩句，總結這兩條戒。八事的具體內容全都如同〈尼篇〉所說。在「雜染相狀（雜相）」中，論典的文字有三段，首先揀除下位眾生。從「若」字以下，說明通於大便道、小便道、口道這三道。按照根本戒成立婬罪的標準，本不需要在此明示；這是為了排除懷疑混濫，免得誤以為其餘二道不算障礙受戒。從「若」字以下，辨析身形與服飾。在「義理決斷（義決）」中，首先正式決斷。

【484-0003】資持記/04b_上三#22
【原文】上言自著不障，不約知與不知，故須兩判。但下，遮濫。恐謂前境淨穢，亦同形服約知不知，故特簡之。下文指廣。《義鈔》第一，《業疏》第三。《疏》云：有師言但是具戒，何論淨穢；陵辱慢重，故障出家；乃至祖師云：宜用《僧祇》明判淨穢是也。壞比丘中。
【譯文】上面說（尼）自己穿著白衣俗服不構成障礙，沒有論及知道或不知道，所以必須作兩種判斷。從「但」字以下，是排除混淆。唯恐有人以為前境之人的清淨或受染，也如同形體服飾一樣要依知與不知來劃分，所以特地加以揀擇澄清。下文指示廣博的文義。在《四分律拾毘尼義鈔》（義鈔）第一卷、《業疏》第三卷。《戒疏》說：有律師認為只要是具足戒尼，何必談論清淨與否；凌辱輕慢的罪過極重，理應障礙出家受戒；乃至南山祖師說：應當採用《僧祇律》明確判斷其淨與不淨，就是指此而言。在「破壞比丘（壞比丘）」中。

【484-0004】資持記/04b_上三#23
【原文】答文，初句判定。尼下，例決。彼問云：汝不犯淨行比丘耶。言事希者，出僧中略意。故下，引文決。彼具問云：汝不盜現前僧物不？於六親所、比丘比丘尼所，行不淨行不？父母師長有病棄去不？不殺發菩提心眾生不？總示中。俗人，須約未受五八者。三明賊心。
【譯文】回答的文句，第一句就作了判定。從「尼」字以下，依例比照決斷。彼律問道：「你沒有侵害犯染修清淨行的比丘嗎？」說「事蹟罕見」，道出了僧律中略去不問的緣由。從「故」字以下，引用經文來裁決。該經具體審問說：「你沒有盜取現前僧物嗎？在六親的處所，以及在比丘、比丘尼的處所，行過不淨行嗎？父母師長生病時曾棄離不顧嗎？沒有殺害發菩提心的眾生嗎？」在「總體標示（總示）」中。在家人，必須限定是尚未受過五戒、八戒的人。第三說明「起盜賊之心（賊心）」。

【484-0005】資持記/04b_上三#24
【原文】法財非分，詐竊歸己，故以為名。引示中，初引本緣。律因波羅柰國穀貴，有一年少外道，見佛及僧多得供養，即自剃髮，著衣持鉢，入眾中食；諸比丘窮問，彼乃自言，佛因制斷。若下，判成不，初明偷形。未出家者，謂十戒也。未受者，即具戒也。不應受者，約前知也。已受得者，據後知也。
【譯文】以不正當的方式取得法與財，用欺詐盜竊的手段據為己有，所以立「賊住」這個名稱。「引示」中，先引根本緣起。律中說：因為波羅奈國穀物昂貴，有一個年輕外道，看見佛與僧眾得到很多供養，就自己剃髮、穿僧衣、持鉢，混入僧眾中吃飯；諸比丘追根究底地問他，他才自己說出實情，佛陀因此制戒斷除。「若」字以下，判定成與不成，先說明「偷形」。「未出家者」，指連十戒都未受；「未受者」，即指具足戒；「不應受者」，是就先前已知情而說；「已受得者」，是據後來才知情而說。

【484-0006】資持記/04b_上三#25
【原文】律具云：若至一比丘，乃至僧所，不共羯磨說戒；若未出家受具戒，不得與出家受具戒；若已與出家受具戒，聽即名出家受具戒。文剩者字，去之即義顯。曾下，明偷法。正是難位，故令滅擯。前但同遮，縱僧預知，違制得戒。決通中，前引律文。下示義決。
【譯文】律文完整說道：如果去到一位比丘、乃至大僧處所，沒有共同作羯磨說戒；如果尚未出家受具足戒，不得為他舉行出家受具足戒儀式；如果已經為他舉行出家受具足戒儀式，聽許這就名為出家受具足戒。文中多出一個「者」字，刪去之後義理便很明顯。從「曾」字以下，說明「偷竊佛法（偷法）」。這正是難位，所以應令其滅擯驅逐。前面僅等同於遮戒，縱使僧眾預先知曉，也只是違制而受者依然得戒。在「決斷會通（決通）」中，前面引用律文。下文指示義理的決斷。

【484-0007】資持記/04b_上三#26
【原文】上文但云一二三人，不明眾但，須以義定；餘和合者，如說恣告眾和僧立制等。他部中，《善見》。三種並號偷形，若據第二，正是盜法，所以《疏》中但言三種。〔或恐寫誤，一字合在偷形字上，則同《義鈔》。〕或可稱夏受禮，濫大僧形，故通標耳。初明偷形。言利養者，須約二種現前僧物。
【譯文】上文只說「一、二、三人」，沒有辨明是作眾法還是作但對首等法，必須以法義來判定；其餘的「和合事」，例如說戒、自恣、向眾宣告、僧眾和合訂立規約等。在其他部派中，引用《善見論》。三種都稱為偷形，如果依據第二種，正屬於偷法，所以《戒疏》中只說三種。（或者恐怕是傳抄寫錯，應將「一」字放在「偷形」二字之上，那就與《義鈔》相合了。）或者可以說自稱戒臘、受人禮拜，冒充大僧的形象，所以通泛地標示。首先說明偷形。所謂「利養」，必須限定為兩種現前僧物。

【484-0008】資持記/04b_上三#27
【原文】飲食供設，是彼所希，義無不受，所以下云為饑餓故是也。二偷和合者。律唯約法。論通四種，加臘禮利，並成障戒。故《疏》問云：偷和合者，應在羯磨，何以文中具列夏等？答：夏次禮儀及信施等，並是僧家六和表相；由有戒故，便有夏次等；以盜戒相，令他信之故也。若偷下，判斷得不。
【譯文】飲食與種種供養的施設，正是他們所希求的，按理沒有不受的道理，所以下文說「為饑餓故」（因為饑餓的緣故），就是這個意思。第二是「偷和合」：律中只就「法」也就是羯磨方面說，論中則通於四種，加上戒臘、禮儀、利養，都構成障戒。所以《疏》中問：偷和合應當是就羯磨而說，為什麼文中卻一併列出夏等呢？答：夏次、禮儀以及信施等，都是僧家「六和」的表相；由於有戒的緣故，才有夏次等差別；這是因為盜戒的相狀，是要讓他人信受自己是真僧的緣故。「若偷」以下，判定得戒不得戒。

【原文】同前《四分》。引《五百問》，別證受禮。料簡中，初科為二，前示本律言通。依下，次引《僧祇》決正，初明偷法。彼云沙彌潛身床下，盜聽初中後語者，即攝羯磨言相始終，俱記成障，不具不成。文雖約記，義須明解。〔古記云：作白為初，五篇為中，略教為後，此釋甚謬，說戒可爾；
