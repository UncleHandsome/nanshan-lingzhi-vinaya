# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【538-0005】03_業疏/13b_卷三之二#22
【原文】問：既未白四，義是沙彌，何得加者？答：既云受具，正法有儀，章服被於外容，戒業充於內報，事義相假，何得不持？如僧、尼二眾，體不同法，及論受戒，聞說皆開，故知持竟，從僧乞受。如和上例，可以通鑒，豈同古人雷同受後？須曉之也

【538-0006】03_業疏/13b_卷三之二#23
【原文】問意假設他疑，引起後義。答中：初立理，謂正受時，時具儀相，故須先持。如「下」引例有二：初引尼眾受戒同法，以例未具得加三衣；次引和尚先請後受，可例受前加法無過。「聞說皆開」，聞即開聽，說謂開訶。「豈」下彰異，古來例皆受後加持，《事鈔》兩存，義猶未決。雷同，言無異識也。問：若加受法，誰為對首？答：按《壇經》云，教授師於此為受衣，準此即對大僧也。若謂沙彌不合與僧對首者，即應難曰：沙彌那得受大僧衣耶？既許沙彌受僧衣，何妨大僧為對首？今時有用沙彌為對者，止可本眾對加縵衣；沙彌既無三衣，豈得對彼加受？請以理求，無事氷執
【譯文】問意是假設他人的疑惑，以此引出後續的義理。答文之中：首先樹立正理，是指正式受戒時，當下即應具足威儀容相，所以必須預先受持衣缽。「如」字以下引述例子有二：首先引述尼眾受戒時與僧同法之例，以此比照未受具足戒者可以預先加持三衣；其次引述和尚是先迎請而後受戒，可以比照在受戒前作加持法並無過失。「聞說皆開」，「聞」即開許聽聞，「說」是指開許呵責。「豈」字以下彰顯與舊說的不同，自古以來通例都是在受戒後才加持，《事鈔》中將兩說並存，義理尚未決斷。「雷同」，是說沒有分別辨析的見識。問：如果作加持受法，應以誰為對首？答：按照《壇經》所說，教授師在此處為其受衣，依照這個道理就是面對大僧。如果說沙彌不應當與大僧作對首，那就應當詰難說：沙彌又怎麼能受大僧衣呢？既然開許沙彌受僧衣，又有何妨由大僧作為對首？如今有人用沙彌作為對首，這只可以在本眾之間相對加持縵衣；沙彌既然沒有三衣，哪裡能夠對著沙彌加持受持呢？請依正理尋求，不要無端固執己見。

【538-0011】03_業疏/13b_卷三之二#28
【原文】初來意者，光師云：夫欲遠希玄果，非戒不剋；然戒法清虗，乃出道津濟。法既精玅，致受非易。論其受也，非身淨不剋。是以身為受道之器，心為納法之主，身心圓淨，得戒亡言。若內懷遮難，於道非淨，雖備眾緣，徒勞無益，一生絕分，障不發戒，名之為難。由難障故，因撿稽留，故制問之。意在此也
【譯文】第一制定的來意，光律師說：想要在久遠之後希求玄妙的聖果，若不是依靠戒律就無法獲得；然而戒法清淨虛寂，乃是出離生死之道的津梁舟楫。戒法既然極為精妙，使得領受它並不容易。論及受戒，若不是自身清淨就不能成辦。因此身體是領受佛道的器皿，心性是納受戒法的主宰，身心圓滿清淨，得戒便無庸贅言。如果內心懷有遮障與難事，在佛道上就不算清淨，縱使具備種種外緣，也是徒勞無益，一生之中與道絕分，障礙戒體不得生發，所以稱之為「難」。由於有難障的緣故，必須因此檢驗留難，所以制定在受戒時詢問它。其用意就在於此。

【譯文】在列舉詢問義門的制定用意中，引述光律師的文字分為四段：首先敘述持戒的功德，「玄果」通指三乘聖果，「剋」就是獲得的意思。「然」字以下，其次說明簡擇清淨。「是」字以下，第三說明有難與無難的得戒與否，「亡」就是沒有的意思。「由」字以下，第四結尾顯明詢問的用意。

【538-0014】03_業疏/13b_卷三之二#31
【原文】二中初科：染即是情，以十三難不出三道，三道皆情，情生非一，故難亦無量
【譯文】在第二部分第一科中：染污就是情識妄執，因為十三難都不出於煩惱、業、苦這三道，三道都源於妄情，妄情的生起並非只有一種，所以難障也是無量的。

【538-0015】03_業疏/13b_卷三之二#32
【原文】初邊罪難者，曾受佛戒，理宜謹奉，捉心不固，具緣犯重。為過不輕，業果生報，不思捨悔，反戒更受，義無再攝。分在眾外，名之為邊；一生永障，名之為難。難由邊罪障戒而生，故曰邊罪
【譯文】第一、邊罪難：受戒者曾經受過佛戒，理應謹慎奉持，但因把持自心不堅固，具備因緣犯了重戒。所造罪過非輕，必招感業果生報，事先不想著捨戒或懺悔，反而毀犯戒法卻又重新前來受戒，在義理上僧眾不再攝受。其名分被棄置於僧眾之外，稱為「邊」；一生之中永遠障礙得戒，稱為「難」。難障是由於邊罪障礙戒體而生起，所以稱為邊罪難。

【538-0016】03_業疏/13b_卷三之二#33
【原文】釋名中初科：曾受佛戒，總該道俗。不思捨悔，謂將犯時不捨戒，戒羸不悔也。反戒，即犯重也。破前為邊，障後為難。分在眾外，謂不入二種僧中
【譯文】在解釋名稱的第一科中：「曾受佛戒」，總體涵蓋出家與在家。「不思捨悔」，是指將要犯戒時不捨戒，戒力羸弱時也不自悔。「反戒」，就是毀犯重罪。「破前為邊」，毀壞先前的戒體而成為邊外；「障後為難」，障礙後來的發戒而成為難障。「分在眾外」，是指不得列入比丘、比丘尼這二種僧眾之中。

【538-0017】03_業疏/13b_卷三之二#34
【原文】自餘十二，例如下述。諸說云云，終是犯重，義無攝受也
【譯文】其餘的十二種難，依此體例如同下文所述。雖然諸家說法紛紜，但終究屬於犯重罪，在義理上僧眾絕不予攝受。

【538-0018】03_業疏/13b_卷三之二#35
【原文】次科：初指例已後諸難，標、釋、結三，竝同初釋。「諸」下斥異，云云多說，如第三門
【譯文】次科中：首先指出後續諸難的體例，其標名、解釋、結名三部分，都與初難的解釋相同。「諸」字以下斥責異說，眾說紛紜的說法，如第三門中所辨析。

【538-0019】03_業疏/13b_卷三之二#36
【原文】二壞尼難者，淨具尊境，是世福田，理宜䖍敬，生出世福，反加慢辱，毀壞梵行。業深罪重，雖受無益，名之為難。難由壞尼淨行而生，故曰也。尼中反之，可如後說
【譯文】第二、壞比丘尼難：清淨具足戒的比丘尼是尊貴的境緣，是世間的福田，理應虔誠恭敬，以此生長出世間的福德，反而橫加輕慢羞辱，毀壞其清淨梵行。造業深重、罪報沉重，即使前來受戒也沒有利益，稱為「難」。難障是由於毀壞比丘尼的淨行而生起的，所以如此命名。在比丘尼戒中則反過來論，正如後文所說。

【538-0020】03_業疏/13b_卷三之二#37
【原文】二中，言淨具者，淨簡穢境，具簡沙彌。陵犯勝境，必無奉信，故受無益。尼中反者，即壞淨具大比丘也
【譯文】第二難中，所說的「淨具」：「淨」是簡別非清淨的污穢境緣，「具」是簡別沙彌尼。陵辱冒犯此殊勝境緣，心中必定毫無敬奉信仰，所以前來受戒也無益處。在比丘尼中反過來論，就是指毀壞清淨具足戒的大比丘。

【538-0021】03_業疏/13b_卷三之二#38
【原文】三賊心受戒難者，沙彌、俗人，法非本位，形濫僭上，又盜聖財，非分妄謂，故號為賊，障不發戒。世財是共，雖盜非難；法財不共，具緣方感。此難由賊妄謂而生，故曰也
【譯文】第三、賊心受戒難：沙彌或俗人，在佛法位階上並非屬於大僧本位，形相混雜僭越上位，又偷盜聖道法財，在不屬於自己的名分上妄自宣稱，所以號稱為「賊」，以此障礙而不得發戒。世間財物是共通之物，雖然偷盜但不成戒難；佛法之財不與外人共有，必須具備相應因緣才能感得戒體。此難障是由於賊心妄自作態而生起，所以如此命名。

【538-0022】03_業疏/13b_卷三之二#39
【原文】三中，形濫即偷形，盜聖財即偷法。盜世財非難者，據本白衣為言；若受五、十，滿五成重，即入邊收
【譯文】第三難中，「形相混濫」就是盜取僧形，「偷盜聖財」就是盜取作法。偷盜世間財物不構成戒難，是依據本來是白衣的情況來說的；如果已經受了五戒、十戒，偷盜滿五錢構成重罪，那就歸入邊罪難中收攝。

【538-0023】03_業疏/13b_卷三之二#40
【原文】四破內外道難，正取破內，兼實破外，志性無恒，內外無取，鬬亂彼此，俱不成辦，故文云「汝不破二道耶」是也。《五分》云「捨內法外道人者，不應受戒」，此直取破內也。由信心未著，捨正歸邪，破於內法，即名為難
【譯文】第四、破內外道難：正取破壞佛門內道，兼帶實際上破壞外道；其志向心性沒有恆常操守，在內道外道中皆無所獲取，挑唆擾亂彼此，兩邊的修學都不能成辦，所以律文說「你不破二道嗎？」就是指此。《五分律》說「捨棄內法而入外道的人，不應受戒」，這是直接取破壞內法而言。由於其信心尚未堅定，捨棄正法歸向邪道，破壞了佛門內法，所以名之為難。

【538-0024】03_業疏/13b_卷三之二#41
【原文】四中初科：初引本宗，明破二道俱不成辦，謂於所業兩無成故。次引《五分》，但明破內。著猶定也，陟慮反之
【譯文】在第四難的第一科中：首先引述本宗《四分律》，說明破壞二道都不能成辦，是指對各自的學業兩無所成。其次引述《五分律》，只說明破壞內法。「著」猶如定（堅定），音為陟慮反。

【538-0025】03_業疏/13b_卷三之二#42
【原文】問：沙彌雖破而不成難，何故毀重同為邊障？答：具、分乃殊，同壞本也
【譯文】問：沙彌雖然破壞內外道卻不成難，為什麼毀犯重戒卻同樣成為邊罪之障呢？答：具足戒與少分戒雖然有別，但在毀壞根本戒體上是相同的。

【538-0026】03_業疏/13b_卷三之二#43
【原文】問答中：以破局大僧，邊通小眾，故問決之。具、分，即目大小二戒
【譯文】在問答之中：因為破內外道局限於大僧，而邊罪通於小眾（沙彌等），所以提出問題來決斷。「具、分」，就是指大僧具足戒與小眾分受之戒。

【538-0027】03_業疏/13b_卷三之二#44
【原文】若爾，尼中兩眾犯後四重，應是障也？答：前四限分，故違；後四枝條，深制
【譯文】如果是這樣的話，比丘尼僧團中的式叉摩那與沙彌尼這兩眾，犯了比丘尼後四條重戒，也應當構成得戒之障嗎？答：前四條是少分戒的基本界限，所以是故意毀犯根本；後四條則是枝條之戒，屬於對大僧的深重制定。

【538-0028】03_業疏/13b_卷三之二#45
【原文】轉難中：尼有八重，犯皆成障；尼下二眾，前四成邊，後四非障。因引為難，欲顯不同
【譯文】在輾轉詰難之中：比丘尼有八波羅夷重戒，犯了都構成難障；而比丘尼階下的兩眾，犯前四條構成邊罪，犯後四條則不構成難障。因此引來作為詰難，目的是為了顯明兩者的不同。
