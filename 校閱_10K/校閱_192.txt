# 校閱材料　第192檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【192-0001】01_行事鈔/09a_卷下之一#25
【原文】一求財如法。謂非四邪五邪、興利販易，得者不成。律云：不以邪命得、激發得、相得，犯捨墮衣不得作等。
【譯文】第一、籌求布料財物必須合乎戒法。這指的是不能透過四種邪命、五種邪命、放貸取利、經商買賣等不正當手段，以這類方式取得的布料製作法衣便不合法。律藏中說：不用邪命求得、不以激發言語索求而得（如故意稱讚他人衣服以求布施）、不以形相暗示而得，凡是犯尼薩耆波逸提（捨墮，須捨物並懺悔之罪）的衣料，都不得用來製作法衣等等。

【192-0002】01_行事鈔/09a_卷下之一#26
【原文】二財體如。必須厚重熟緻者。若細薄生疎綾羅、錦綺、紗縠、細絹等，並非法物。律云：文繡衣不成受持故。《僧祇》：一切生疎毛髮、樹皮衣、草衣、皮衣，並不成。《五百問》云：生絹不得作，必不現身者得，以作成如法故。《僧祇》：龍著袈裟，免金翅鳥難；必不順教，則所被無力故。
【譯文】第二、衣料的質地必須合如法度。必須是厚重、熟練且質地密緻的布料。如果是纖細輕薄、質地生硬稀疏的綾羅、錦綺、紗縠、細絹等，全都是不合法的物品。律藏說：織有花紋刺繡的衣服不能成就如法的受持體。《摩訶僧祇律》說：一切未經熟治且粗疏的毛髮編織物、樹皮衣、草衣、獸皮衣，全都不合法。《五百問》說：生絹不得製作三衣，但如果穿上後必定不會隱約顯露身體肌膚的則可以，因為做成的法衣合乎法規。《摩訶僧祇律》說：龍披著如法袈裟，便能免除金翅鳥啄食之難；如果不遵順佛陀教法製作，那麼所披著的袈裟就沒有神力庇護了。

【192-0003】01_行事鈔/09a_卷下之一#27
【原文】三色如法。《四分》云：上色染衣不得畜，當壞作袈裟色；若作五納衣者得。上色碎段者，裁作五納亦得。《涅槃》云：聽受衣服皮革等。雖聽畜種種衣，要是壞色。《十誦》云：一切青黃赤白黑，五種純色衣，不得著，除納衣。《戒本》三色，青、泥、棧也。《薩婆多》云：五大色衣，不成受作三衣，得作餘衣著。三點淨，用紺、黑、青。除三衣，餘衣三點淨。得皂木蘭，一切得受。純青淺青碧等點淨，得作衣裏用；若赤白黃不純大色者，亦得。若以不如法色染訖，更以如法色染覆，成受持。袈裟者，秦云染也；如結愛等，亦名染。真紫色、蘇方、地黃、柰黃、花黃色，並是非法。《僧祇》云：真緋、欝金染、紅藍染、皂色、青染、花色，不聽用；聽用根、葉、花、樹皮，下至巨摩汁等。《戒本》青、黑、木蘭。下文廣有染法。青謂銅青，黑謂雜泥等，木蘭者謂諸果汁等。予於蜀郡，親見木蘭樹皮，赤黑色鮮明，可以為染；微有香氣，亦有用作香者，如《善見》所說。遺教法律經中五色者，此非正錄，無知者用之。《四分》云：若青、若黑、若木蘭，一一色中隨意壞。《善見》云：善來比丘，瓦鉢貫左肩，青色袈裟，赤色鮮明。若見著五大色衣比丘，有智慧者當言：此是遭賊失衣比丘。準上律論及經，並不得純色，必有須壞；不壞不成受持著，著得罪如〈隨相〉中。
【譯文】第三、顏色必須合乎戒法。《四分律》說：上等鮮明純色染成的衣服不得蓄持，應當破壞其純色而染成如法的袈裟色（壞色）；如果是做成補納衣（百納衣）的則可以。若是上等純色的破碎布片，剪裁做成補納衣也可以。《大般涅槃經》說：聽許接受衣服、皮革等物。雖然聽許蓄持各種衣料，但必定要是壞色（非純正鮮豔之色）。《十誦律》說：一切青、黃、赤、白、黑五種純正色彩的衣服，都不得穿著，補納衣除外。《戒本》所規定的三種壞色，即青色、泥色、棧色（赤黑色）。《薩婆多論》說：五種大純正色彩的衣服，不能加法受持為三衣，但可以當作其他日常衣服穿著。點淨（在衣角點染以破壞純色）的三種顏色，用紺色、黑色、青色。除了三衣之外，其餘衣服應以這三種壞色之一點淨破色。若染成黑色或木蘭色，一切衣服都可以受持。以純青、淺青、碧綠等色點淨的布，可以用來作衣服的內裡；如果是赤、白、黃色但非純正大色的布料，也可以使用。如果先染了不如法的顏色，後來再用如法的壞色重新染色覆蓋，便能成就如法受持。梵語「袈裟」，秦地（漢語）翻譯為「染」；就像結縛貪愛等煩惱也稱為「染」一樣。真正的純紫色、蘇芳木染、地黃染、柰黃染、花黃色，全都是非法的顏色。《摩訶僧祇律》說：純正深紅（真緋）、鬱金香染、紅藍花染、濃黑色、正青染、花俏雜色，都不准許使用；聽許使用植物的根、葉、花、樹皮，乃至巨摩（牛糞）汁等來染色。《戒本》規定的是青色、黑色、木蘭色。下文會詳細說明染色之法。青色指的是銅青（銅綠色），黑色指的是摻雜泥土等所染之色，木蘭色則是指各種果實汁液等染成的顏色。我（道宣）在蜀郡時，親眼見過木蘭樹皮，呈鮮明的赤黑色，可以用來染色；略帶有香氣，也有人將它用作香料，正如《善見律毘婆沙》所說的。偽託《遺教法律經》中所說的五色，這不是正統佛教的經典記錄，無知之人隨意採用它。《四分律》說：或者青色、或者黑色、或者木蘭色，每一種顏色中隨心意用來破壞正色即可。《善見律毘婆沙》說：佛陀以「善來比丘」度化的比丘，瓦鉢掛在左肩上，披著青色且赤黑鮮明的袈裟。若是看見穿著五大純色衣服的比丘，有智慧的人應當說：這必定是遭遇賊人搶劫而遺失了如法法衣的比丘。依據上述各部律典、論典及經典，都規定不能使用純色，必定需要破壞純色；不加以破壞顏色就不能成就合法的受持穿著，若執意穿著所獲得的罪過，正如〈隨相釋罪篇〉中所說。

【192-0004】01_行事鈔/09a_卷下之一#28
【原文】四量是非。《四分》云：安陀會，長四肘廣二肘；欝多羅僧，長五肘廣三肘；僧伽梨亦爾。然此下衣極成窄小，當取通文。律言：量腹而食，度身而衣，取足而已。準此無定量，任時進不。雖爾，亦須楷準，故《十》、《祇》中，各立三品之量。今準《薩婆多》：中三衣長五肘廣三肘，若極大者長六肘廣三肘半，若極小者長四肘廣二肘半者，並如法。若過、若減，成受持，以可截續故。鉢若過、減，不成受，不可截續故。若過量外應說淨，不者犯捨墮。《五分》：肘量長短不定，佛令隨身分量，不必依肘。
【譯文】第四、尺寸度量的是非標準。《四分律》說：安陀會（下衣），長四肘、寬二肘；欝多羅僧（中衣），長五肘、寬三肘；僧伽梨（大衣）也是長五肘、寬三肘。然而這樣規定安陀會顯得極其窄小，應當採取律藏的通融經文。律中說：衡量自己的食量而進食，度量自己的身材而穿衣，以足夠遮身蔽體為度而已。依照這段話，法衣並沒有固定死板的尺寸，聽憑時代與身材而有所增減。雖然如此，還是必須有一個標準楷模，故《十誦律》、《摩訶僧祇律》中，各自訂立了上、中、下三品尺寸的規格。如今依照《薩婆多論》：中品的三衣長五肘、寬三肘；如果是極大尺寸（上品），長六肘、寬三肘半；如果是極小尺寸（下品），長四肘、寬二肘半，這些都算合如法度。如果尺寸超過或不足，仍可成就加法受持，因為布料可以裁截或拼接續接的緣故。（相較之下，鐵瓦鉢如果尺寸過大或不足，就不能成就受持，因為鉢器無法隨意裁截拼接的緣故。）如果超過了規定的度量，多出的部分應當作「說淨」（透過對首宣告解除貪著執念），否則便犯尼薩耆波逸提（捨墮）。《五分律》說：一肘的長度各地標準不一，佛陀敕令隨順個人的身體尺寸來裁製衣服，不一定非要死板依照肘量。
