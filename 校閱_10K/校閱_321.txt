# 校閱材料　第321檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【321-0001】02_戒疏/01c_卷一上之一#76
【原文】【疏】若據緣本，其流「上座」，何以知耶？大迦葉波初秉宗教，將事集法，簡練通德故。五百無學，《智論》千人，並是釋門達化之士，故號斯侶名為「上座」。如《律》中說：「結後召眾重述前法。時大眾曰：『佛是智人，立法須定，何得開制？』迦葉告曰：『由是智人，制已更開，開已還制。』」自非達化，何以明斯？故得任持三藏御世。如《部執》解，於佛滅後夏竟涅槃。《大悲》、《智論》咸陳滅相。如《付法藏傳》說，付法與阿難等。
【譯文】【疏文】如果追溯這一脈派系的源頭本底，它正是流傳自「上座部」，憑什麼知道呢？大迦葉尊者起初執掌佛陀的宗教大法，將要著手結集經律之時，極其嚴格地甄別挑選了通達六通且戒德圓滿的聖僧。這五百名無學阿羅漢（《大智度論》則說是千人），全都是釋迦教門中深達佛陀化導機宜的傑出人物，因此尊稱這群長老聖侶為「上座」。正如《四分律》中記載：「結集圓滿之後大迦葉召集大眾，重新重述宣講剛結集的法規。當時有大眾長老提出質疑：『佛陀是具足大智慧的人，創立法規必須恆常確定，怎能開許之後又禁止、制定之後又開許呢？』大迦葉回答說：『正因為佛陀是具足大智慧的人，才會在制定戒律之後又依緣開許，開許之後又依緣重新禁止。』」若非親身體認達通佛陀深邃化導的智者，怎能闡明這個道理？因此大迦葉能夠主持護持三藏教法以統理化導世間。如同《異部宗輪論（十八部執論）》所解釋，尊者在佛滅度後的首個結夏安居結束便示寂入滅。《大悲經》、《大智度論》都詳細陳述了他入滅入定時的神異景象。又如同《付法藏因緣傳》所載，大迦葉臨入滅前將正法眼藏交付付囑給了阿難尊者等人。

【321-0002】02_戒疏/01c_卷一上之一#77
【原文】【記】次明五部。先敘異世五師者，欲顯派分有所因故。初師中，初二句示本部。「何」下，明緣相。又四，初敘選眾。「摩訶迦葉波」，此云大飲光氏。「秉」即是持。「通」謂六通，「德」即學行。「《智論》千人」者，示不同故。言「達化」者，體佛意故。「如」下，次引緣釋上達化。雖歎迦葉，意通大眾。即五百結集中，迦葉結集三藏畢，有長老富那奢，與五百比丘，至王舍城詰問，迦葉再條所集一一答之，故云「結後」等。「時大眾」者，即富那奢問儉開八事，迦葉答以豐時還制，乃發是問。「自非」等語，結歎智能。「任持」謂力行正教，「御世」謂攝化群生。「如《部執》」下，三、示滅相，即《十八部執論》。「佛滅夏竟涅槃」者，準《義鈔》，五師住世各二十年，此即所見不同也。《大悲經》，彼云「迦葉入涅槃時而作誓曰：願我滅後，以神力加，令身衣不變，諸根亦然，乃至彌勒出世，令我見彼共作三會，乃至彌勒將所度眾皆到其所。眾念迦葉身卑，遂踊身虗空而作神變，現為大形充滿世界。眾見神力，除去憍慢，成阿羅漢。尊者以己身火闍維其身」等，《智論》大同。「如付」下，四、明傳法。彼明迦葉結集三藏弘持法已，尋禮佛四塔，次入娑伽羅宮禮佛牙塔。忉利天禮佛髮已，往別闍王。遇王晝𮄊，告閽者畢，向雞足山。王與阿難追之，山自開闢，迦葉在中，全身不散。王哭投地𧂐香欲焚，阿難曰：「迦葉以定力持身，待於彌勒，不可闍維。」王遂迴駕，其山復合。先「以法付阿難」等。
【譯文】【記文】其次說明五大部派。先敘述不同時代傳承正法的五位宗師，是為了彰顯後來的分門別派都是有其傳承因緣的。在第一位宗師大迦葉的文段中，前兩句指出其源出於本部。「何」字以下，說明其傳承的因緣相狀。又分為四部分，首先敘述甄選大眾。「摩訶迦葉波」，華語翻譯為大飲光氏。「秉」就是執持。「通」是指六種神通，「德」就是修學戒行。「《智論》千人」，是為了指明經典記載的數量差異。說「達化」，是指能徹體佛陀設教的深意。「如」字以下，其次引用事緣來解釋上文的深達化道。這雖是讚歎大迦葉，但意旨在於通讚全體結集的聖眾。也就是在五百結集完成時，有位長老富那奢（富蘭那），帶領五百位比丘來到王舍城提出質疑，大迦葉將所結集的內容逐條條分縷析地一一回答，所以說「結後」等。「時大眾」，是指富那奢詰問佛陀在饑荒時曾開許過八種食物儲存處，為何後來又禁止？大迦葉回答說豐收之時佛陀便依時重新制斷，富那奢於是提出了這番疑問。「自非」等文句，是總結讚歎大迦葉與上座長老的大智慧能力。「任持」是指竭力推行正教，「御世」是指攝受化導無量群生。「如《部執》」以下，第三、展示入滅示寂的相狀，出自《十八部執論》。「佛滅度後夏竟涅槃」的說法，若依準《義鈔》，五位祖師各自駐世傳法二十年，此處則是各家記載所見的不同。《大悲經》記載說：大迦葉尊者臨入涅槃之時發下誓願：「願我入滅之後，以神通力加持護念，令我的法體與袈裟長久不壞不爛，眼耳身等諸根亦完好如初，一直等到當來下生彌勒尊佛出世，讓我能親見彌勒如來共赴龍華三會，直到彌勒尊佛引領所度化的信眾都來到我入定之處。」眾人見到迦葉尊者身形枯小，尊者便湧身飛升虛空顯現大神通變現，化現為巍峨偉岸的巨大身形充塞虛空世界。大眾目睹此等神力，徹底除滅了內心的憍慢，當下證得阿羅漢果。隨後尊者以自體內自發的三昧真火闍維火化自己的遺身等，《大智度論》的記載大體相同。「如付」字以下，第四、說明付囑傳承正法。該傳記載大迦葉結集三藏並弘揚護持正法之後，隨即前往禮拜佛陀生平四大聖跡寶塔（出家、成道、轉法輪、涅槃四塔），隨後進入娑竭羅龍宮禮拜佛牙塔。又升到忉利天禮拜佛髮舍利之後，前往向阿闍世王辭別告別。恰逢阿闍世王日間正在晝寢（午睡），大迦葉告知宮門衛士之後，便隻身前往雞足山。國王醒後與阿難尊者隨後急追，雞足山峰自然開裂為二，大迦葉身坐其中，全身端坐不壞。國王痛哭伏地，堆積香柴想要將其火化焚化，阿難阻止說：「迦葉尊者是以甚深禪定願力護持肉身，以等待彌勒佛降誕，絕不可擅自闍維焚化。」國王於是悲泣回駕，雞足山山崖隨即重新合攏。大迦葉在入定之前「已先將正法藏交付囑託給了阿難尊者」等。

【原文】【疏】二師阿難，受法化世。如《付法藏傳》，恒水中流而取滅度，分身四分，廣相如彼。

【321-0004】02_戒疏/01d_卷一上之一#1
【原文】【記】第二阿難。指彼「《傳》」者，彼明阿難聞竹林比丘誦法句偈云：「若人生百歲，不見水老鶴，不如生一日，而得覩見之。」阿難慘然云：「此非佛偈。佛偈云：『若人生百歲，不解生滅法，不如生一日，而得解了之。』」阿難還聞誦於前偈，歎曰：「我於世無用。」遂別闍王，亦值王𮄊，即度恒河。王覺追之，半河方及。王請住世，阿難默然。復度雪山五百仙人已。河變金地，即於此處入風奮迅三昧。分身四分：一與闍王，二與毗舍離王，三與婆竭龍王，四與帝釋。四處建塔。先以法付商那。
【譯文】【記文】第二位是阿難尊者。這裡所指的《付法藏傳》，記載阿難曾聽到竹林精舍的比丘誦念〈法句偈〉說：「如果人活到一百歲，卻看不見水老鶴，還不如只活一天，能夠親眼看見它。」阿難神情悲戚地說：「這不是佛陀所說的偈頌。佛陀的偈頌是說：『如果人活到一百歲，卻不明白生滅變異的真理，還不如只活一天，而能徹底了悟它。』」後來阿難又聽到那個比丘仍在誦念先前的錯偈，便感嘆道：「我在世間已經沒有用處了。」於是向阿闍世王辭別，正巧遇上國王正在睡覺，便直接前往橫渡恆河。國王醒來後急忙追趕，追到河中央才追上。國王懇請他常住世間，阿難默然不許。接著又在河中度化了雪山的五百位仙人。此時河水化為黃金寶地，阿難便在此處進入風奮迅三昧。將遺身分成四份：一份給阿闍世王，一份給毗舍離王，一份給娑竭羅龍王，一份給帝釋天。讓四處各自建造寶塔供養。在此之前，他已先將佛法付囑給商那和修。

【321-0005】02_戒疏/01d_卷一上之一#2
【原文】【疏】三師末田提，四師商那和修，並是阿難親承資奉。阿難將滅，以法通付二人。田提道洽罽賓，和修化在中國，是則同時分地而王也。
【譯文】【疏文】第三位祖師末田提，第四位祖師商那和修，兩人都是親自承事奉養阿難的弟子。阿難即將圓寂時，將正法同時付囑給他們二人。末田提的教化普遍推行於罽賓國，商那和修的弘化則在中印度，這就如同在同一個時代劃分疆域而各自稱治一般。
