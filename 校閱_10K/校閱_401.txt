# 校閱材料　第401檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【401-0001】02_戒疏/04a_卷一下之二#94
【原文】【疏】彼疏釋云：「此間為『篇』，今依本義，立名『部』也。」故知梵本各有所由，翻經之家，以意商度，以「篇」譯之。何事紜紜，浪諍字也？故彼解云：「何故名『部』？有二義故：一、成就根本義；二、隨順根本義。」
【譯文】【疏文】義理疏文說：該論的註疏解釋道：「在此土通常稱為『篇』，現在依照根本罪的義理（二種根本義），安立名稱為『部』。」由此可知梵文原典各有其字源由來，翻譯經典的譯師，憑著自心意圖斟酌商討，才翻譯為「篇」字。後人何必紛紛擾擾，白白地為文字徒生爭執呢？所以該論疏解釋說：「為什麼稱為『部』？因為具備兩種義理：第一、具有能成就根本果罪的意義；第二、具有隨順根本果罪的意義。」

【401-0002】02_戒疏/04a_卷一下之二#95
【原文】【記】引《疏》解中，初文分三。初引疏標文。言「本義」者，即下二種根本。「故知」下，因斥古非。以《疏》標「五部」，顯是隨義為名，不必三均，獨得名「篇」。「紜紜」，雜亂之貌。「浪」，虗也。「故彼」下，引釋「部」義。二種「根本」，如後結合。
【譯文】【記文】在「引用明了論疏解釋」中，前半段文字分為三點：首先引用論疏標示正文。所說「本義」，指的就是下文所說的兩種根本。「故知」以下，趁機斥責古人的非論：因為該論疏標名「五部」，顯然是隨義立名，並非一定要具備三種均齊才能單獨稱為「篇」。「紜紜」是紛亂雜亂的樣子。「浪」是虛妄之意。「故彼解云」以下，引用解釋「部」的意義；這兩種「根本」，如同後文的結語所歸納。

【401-0011】02_戒疏/04a_卷一下之二#104
【原文】【疏】若準《十誦》、《多論》，此則初篇遠方便「偷蘭」。名雖有異，對人不殊也。故彼文中，初二兩篇，各有遠近方便，位分三階。初篇近者，界內僧懺；初篇遠者，二篇近者，合為一階，界外四人邊悔；二篇遠者為第三階，一人前悔。俱號偷蘭，懺同墮罪。
【譯文】【疏文】義理疏文說：若是依據《十誦律》與《薩婆多論》，這屬於第一篇遠方便的「偷蘭遮」。名稱雖然不同，但必須對著他人發露這一點則是相同的。所以在那兩部文典之中，前兩篇各自都具備遠、近兩種方便，品位劃分為三個階次：第一篇的近方便，必須在界內僧伽大眾前懺悔；第一篇的遠方便，與第二篇的近方便，合併為一個階次，在界外四位僧人面前悔過；第二篇的遠方便則為第三個階次，只需在一人面前悔過即可。這些罪都稱為偷蘭遮，懺悔方式與波逸提墮罪相同。

【401-0012】02_戒疏/04a_卷一下之二#105
【原文】【記】次科，會通中分二。初準文會異。言「遠方便」者，彼宗但立兩方便。動色為始，故云「遠」也。中蘭與吉，並對首懺，故云「名異」等。若論詞句，三、一實異，且就所對，故云「同」耳。「故」下，正引彼文。偷蘭三品，分對兩篇，上下各局，中品兩通。
【譯文】【記文】在第二小科「融會貫通」中分為兩部分。首先依循文典融會名相差異。所說的「遠方便」，是因為該宗只立兩種方便：以發動色身為起點，所以稱之為「遠」。中品偷蘭與突吉羅，都屬於對首懺悔，所以說「名雖有異，對人不殊」。若論懺悔的言詞文句，三語或一語其實有別，此處暫且就懺悔所對的對象而言，所以說「相同」。「故彼文中」以下，正式引述彼律文句：偷蘭遮三品分別對應於前兩篇，上品與下品各自侷限在一處，中品則通於兩篇。

【401-0013】02_戒疏/04a_卷一下之二#106
【原文】【疏】若依本律，初二兩篇不成之罪，同號偷蘭。至於定罪，不分輕重。可依上律，如法治之。廣如《刪補羯磨》、《疏》、《鈔》。
【譯文】【疏文】義理疏文說：若是依照本部《四分律》，前兩篇未能成辦究竟的罪行，一概稱為「偷蘭遮」。至於判定罪責時，並未細分輕重品位。可以依照上述諸部律典，依如法原則來處置對治。詳細內容正如《刪補羯磨》以及《羯磨疏》、《事鈔》中所記載。

【401-0014】02_戒疏/04a_卷一下之二#107
【原文】【記】取舍中。初示《律》文。初篇廣解，皆云「成者波羅夷，不成者偷蘭遮」，僧殘亦爾。「可」下，取用《十誦》兩蘭，以替《了論》次吉，頗合今宗不成偷蘭之義。「廣」下，指略。《羯磨》及《疏》，即《懺法篇》。《事鈔》，即在《篇聚》及《持犯》中。
【譯文】【記文】在「取捨」之中。首先指出《四分律》的文義：第一篇廣解中都說「成辦者為波羅夷，不成者為偷蘭遮」，僧殘戒也是如此。「可依」以下，取用《十誦律》的兩種偷蘭遮，用來替代《明了論》的次吉羅，這十分契合本宗「不成究竟即為偷蘭遮」的宗旨。「廣如」以下，指引省略的文句。《羯磨》與《羯磨疏》指的是〈懺法篇〉；《事鈔》則指在〈篇聚名相〉與〈持犯方軌〉各門之中。

【401-0015】02_戒疏/04a_卷一下之二#108
【原文】【疏】三者，近方便。至彼人邊，或欲摩觸，身未交前，是偷蘭遮。為行婬故觸，不為戲樂故觸，所以不成僧殘。故此偷蘭，對僧懺也。
【譯文】【疏文】義理疏文說：第三種、近方便。已經走到對方身邊，或者企圖撫摩碰觸，在身體尚未實際交合之前，結為「偷蘭遮」。因為是為了行淫才去觸摸，並非純粹為了嬉戲取樂而觸摸，所以不構成僧殘罪。因此這個偷蘭遮罪，必須在大眾僧伽面前發露懺悔。
