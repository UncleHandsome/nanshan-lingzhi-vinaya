# 校閱材料　第189檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【189-0001】資持記/11d_中四上#28
【原文】準如罪中，竝通此說。法中，初示理無。言下，辨略無，初列諸戒。二妄即自稱法〔大妄但出人非人句，不出法句。〕，諫是他作法，隨舉即治法。如下，例證；初引《僧祇》，別證隨舉。彼文，隨舉比丘戒有四句：一舉作不舉想，無罪；二不舉作舉想，吉；三舉作舉想，提；
【譯文】比照罪法之中的情形，都可以通用這種說法。在法軌之中，首先指出法理上根本無境想（理無）。從「言」字以下，辨析文字省略（略無），首先列舉各條戒律。兩種妄語戒是指自稱證得過人法〔大妄語戒只列出是人非人的句法，並未列出合不合法度的句法〕；勸諫是他人所舉行的羯磨法度；隨順被舉罪者則屬於僧團處罰懲治的法度。從「如」字以下，引證各項通例；首先引用《僧祇律》，專門用來證實隨順被舉罪比丘戒。該律文指出，隨順被舉罪比丘戒共有四句：一是被舉罪者作未被舉罪想，不犯戒；二是未被舉罪者作已被舉罪想，犯突吉羅；三是被舉罪者作已被舉罪想，犯波逸提；

【189-0002】資持記/11d_中四上#29
【原文】四不舉不舉想，無罪。隨順沙彌，四句門上。次引媒麁，反例二妄。由同有語法，而二妄皆無，媒麁獨有，故云反此。後引發諍，別例諸諫。由僧斷諍，類同設諫；斷諍既具，諫亦須有。非法等示諫作句也；以諫通如非，交絡互歷；
【譯文】四是未被舉罪者作未被舉罪想，不犯戒。隨順被驅逐沙彌戒的四句法門也是同樣的道理。接著引用媒嫁戒與粗語戒，從反面推例兩種妄語戒。因為彼此同樣都涉及言詞話語的法度，然而兩種妄語戒全都沒有列出法想句法，唯獨媒嫁戒與粗語戒單獨具備，所以說「反此」。最後引用挑起諍端（發諍）戒，專門用來推例各條涉及僧團勸諫的戒律。因為僧團裁斷諍論，在性質上等同於設立諫正；裁斷諍論既然具足境想句法，那麼勸諫戒也必須具備。所謂「非法」等詞，是標明勸諫戒設立句法的具體方式；因為勸諫通於如法與非法，彼此交錯對應歷緣；

【189-0003】資持記/11d_中四上#30
【原文】應云：如法如法想殘，如法如法疑蘭，如法非法想蘭，下二可知。時中。洗浴，即半月浴過也。罪中。上明略無，以戒本中，唯覆說二戒，對罪為境；僧戒皆有，故取尼覆明無。第四門，敘由中三，初敘立門意。即前圖中，四五不定；須辨所以，使通教意。且下，列示句法。且約一戒，示其相狀。
【譯文】應當表述為：面對如法勸諫作如法想犯僧殘，面對如法勸諫懷疑是如法犯偷蘭遮，面對如法勸諫作非法想犯偷蘭遮，其餘兩句可以依此類推。在時間之中：洗浴戒，即是指半個月內洗浴次數超過限度。在罪法之中：上面說明律文的省略，因為在戒本之中，唯獨覆藏粗罪與說粗罪這兩條戒，是以他人所犯之罪為所對之境；比丘戒中都具備，所以取比丘尼戒中的覆藏罪來闡明文字的省略。在「第四門」敘述緣由之中分為三部分，首先敘述創立這一門的意圖。也就是前述圖表中，四句或五句的數量並不固定；必須辨明其中的緣由，才能通達佛陀立教制戒的深意。從「且」字以下，列舉說明句法。暫且依據一條戒，來展示其相狀。

【189-0004】資持記/11d_中四上#31
【原文】比前律句，小有不同；前第二云：人作人疑，第五非人非人疑；或恐疑涉兩境，故此易之；或不見律，傳誤寫錯；請以諸戒句法比之，皆無異轍；雖通上釋，從律為正。第五注云雙闕者，非人是境闕，疑即心闕。所下，示多少所以。次簡辨中。徵意乃推第三不定所以，不可濫上。
【譯文】這與前面的根本律文語句略有不同；前面第二句說：是人而懷疑是人，第五句說是非人而懷疑是非人；或許是擔心懷疑的心態牽涉到兩種境界，所以在此處作了變動；也可能是抄寫者未見根本律文，流傳過程中所造成的抄寫錯誤；請拿它與各條戒律的句法相互對照，道理上並無任何差別；雖然可以通融上面的解釋，但仍以遵從律文為準繩。第五句註解說「雙闕」的意思，是指面對非人屬於所對境的缺損（境闕），心存懷疑則屬於能緣心的缺損（心闕）。從「所」字以下，說明句法多少的緣由。接著在「簡別辨析」之中：發問的用意在於推求第三句數量不固定的緣由，不能與上面的通例相混淆。

【189-0005】資持記/11d_中四上#32
【原文】故下古今兩解，皆為評此第三一句；自餘四句，一向永定，故不在言。昔解中。彼立二義，總判諸戒；初約轉想本迷，俱有罪者，名輕重相對；重謂轉想，輕即本迷；二取轉想有罪，本迷無罪者，名犯不犯相對；犯謂轉想，不犯即本迷。初輕重中，初標二門。如下，收諸戒。
【譯文】所以下文列出的古今兩種解釋，都是為了評斷審定這第三句；至於其餘四句，向來是永遠固定的，因此不在討論之列。在古代的解釋中：該說立下兩種義理，用來總括判定所有戒律：首先是依據心意轉變（轉想）與始終迷執（本迷）兩者都有罪的情況，稱為「輕重相對」；重罪是指心意轉變的罪，輕罪就是始終迷執的罪；第二種是取心意轉變有罪、始終迷執則無罪的情況，稱為「犯與不犯相對」；犯是指心意轉變的情況，不犯就是始終迷執的情況。在第一種「輕重」之中，首先標出這兩種法門。從「如」字以下，收錄各條戒律。

【189-0006】資持記/11d_中四上#33
【原文】婬戒轉迷竝夷蘭者，從境制故俱夷，非道想邊俱蘭。〔準婬無輕重，酒戒亦爾，轉迷俱提。〕二麁即麁語歎身，等取媒嫁。〔媒麁竝人想五句。〕殺等六戒，竝緣非人，皆有輕重；轉想蘭吉是重〔前心蘭，後心吉。〕，本迷唯吉即輕。故下，結示定五。此門兼上婬酒，總收八戒。犯不犯中，初標示。
【譯文】婬戒在心意轉變與始終迷執時同樣犯波羅夷或偷蘭遮，這是因為順從所犯之境而制戒的緣故，面對正道同樣犯波羅夷，在非道想這一邊同樣犯偷蘭遮。〔依照準則，婬戒沒有輕重的差別，飲酒戒也是如此，心意轉變與始終迷執同樣都犯波逸提。〕兩種粗語是指宣說粗語戒與歎身戒，用「等」字涵蓋媒嫁戒。〔媒嫁戒與粗語戒都具備人想的五句。〕殺生等六條戒，都是攀緣非人之境，全都有輕與重的差別；心意轉變犯偷蘭遮與突吉羅屬於重罪〔前心犯偷蘭遮，後心犯突吉羅〕，始終迷執僅犯突吉羅則屬於輕罪。所以下文總結判定為必定具備五句。這個法門連同上面的婬戒與酒戒，總共收錄了八條戒律。在「犯與不犯」之中，首先標明指示。

【189-0007】資持記/11d_中四上#34
【原文】不處等者，二房七重、掘地、壞生二重、日暮、非時、媒嫁法想；此等諸戒，律中並約轉想前心有罪，故有五句，則名為犯；若約本迷，始終無罪，止有四句，則為不犯。盜戒二重、麁語法想、迴僧物、二麁罪、二虫水、尼讚食、足、勸、殘宿、不受、發諍，此等律據本迷無罪，止出四句，名不犯；
【譯文】所謂「不處分」等戒，是指兩座房舍戒中的七重、掘地戒、破壞生草木戒中的二重、日暮說法戒、非時食戒、媒嫁戒中的法想；這幾條戒律，律中都是就心意轉變時的前心有罪而言，所以具備五句，這就稱為「犯」；如果依照始終迷執來看，則始終無罪，僅有四句，這就屬於「不犯」。盜戒的二重、粗語戒中的法想、挪用僧物戒、兩條粗罪戒、兩條含蟲水戒、食尼讚食戒、足食戒、勸足食戒、食宿食戒、未受授食戒、挑起諍端戒，這些戒在律中是依據始終迷執無罪而僅僅列出四句，稱為「不犯」；

【原文】若據轉想，須有五句。盜下顯相。略舉二戒，餘皆例準。初盜戒注中，即示律文不出之句；以非罪緣，本迷無罪，故無此句。次不處分注，顯律本現有之句；轉想前心，有方便罪，故立此句。五下，釋成。可解。二境者，本主無心，無主無過。此門總收二十戒。〔媒麁通二門。〕結示中。

【189-0048】資持記/12a_中四下#15
【原文】《方等陀羅尼經．三卷》，《虛空藏經》、《占察經》等，並明悔法。若準《業疏》，須具五緣：一請佛菩薩為證〔即奉請眾聖也〕，二誦經呪〔即誦經諷呪〕，三說己罪名〔即說懺悔〕，四立誓言〔即今發願〕，五如教明證〔即今求相簡擇邪正〕。重廣中，初示所修觀相。無性即空理。以下，明罪滅所以。
【譯文】《方等陀羅尼經》三卷、《虛空藏經》、《占察經》等，全都闡明了悔罪之法。若依據《業疏》所說，必須具備五種因緣：一是恭請佛菩薩作為證明（即奉請諸位聖者），二是誦念經典與神咒（即誦經諷咒），三是自說己罪之名稱（即如實陳白懺悔），四是立下誓願（即如今之發願），五是如教法明示獲致瑞相驗證（即如今求取瑞相以簡別邪正）。在重新廣泛發揮中，首先開示所修觀行的境相。無性，就是諸法本空的實理。「以」字以下，闡明罪業得以消除的原由。

【189-0049】資持記/12a_中四下#16
【原文】諸世間業，皆從我生，我為業主；我既無託，故所造善惡，不從我倒而生；妄業無依，故得除滅。見謂達理，思謂起修，除謂能觀智，滅即所觀業。破妄顯真，而非頓證，故皆云分。若約位判，分見分思，即內凡人；分除分滅，即初果已去。如下，喻顯。眠醉喻迷，醒覺喻悟；
【譯文】世間一切善惡業，都是從自我執著而生起，「我執」即是造業的主宰；既然「我」已無處寄託寄附，那麼所造的善惡之業，便不會從我見的顛倒中滋長；虛妄罪業失去了依託，所以能夠得以斷除消滅。「見」是指通達實理，「思」是指發起修持，「除」是指能觀的智慧，「滅」就是所觀的罪業。破除虛妄而顯發真實，並非一蹴即成，所以都稱為「分」（部分逐步）。若依修行果位來判定，分見、分思，即是內凡位的修行人；分除、分滅，則是證得初果以上的聖者。如同下文，以比喻來顯明。昏睡與沉醉比喻沉淪迷妄，睡醒與酒醒比喻開悟覺知；

【189-0050】資持記/12a_中四下#17
【原文】眠覺醉醒，相似法故。次列三觀，標中。理本是一，何有三者？若權實往分，前二是權，後一是實；若大小相對，前一是小，後二屬大。若約開權會小，終歸一理；若對三宗，性空局小，唯識局大，相空通小大，如是分之。性空中分三，初示所觀境，即諸法二字。諸法之言，總包一切；
【譯文】睡眠與沉醉、睡醒與酒醒，在情狀上都是各自相似的法相。接著列出三種觀法，在標題中。實相之理本來唯一，為何會有三種觀法？若從權教與實教來區分，前二種是權教，最後一種是實教；若從小乘與大乘相對而言，第一種屬於小乘，後兩種屬於大乘。若就開權顯實、會通小乘歸於一實而言，終究回歸於同一實相之理；若對應於三宗，性空觀局限於小乘宗，唯識觀局限於大乘宗，相空觀則通於小乘與大乘，應當如此區分。在性空觀中分為三部分，首先開示所觀之境，即「諸法」這兩個字。諸法這個詞，總括包羅一切事物；

【189-0051】資持記/12a_中四下#18
【原文】諸經論中，或約依正因果，或世出世間，或有漏無漏，或色心非色心，或善惡無記，或陰界入等。若據通論，總觀諸法；今就懺悔，且指罪業而為觀境。性空無我一句，即能觀智。罪從緣有，本無自性；緣即心境，虛妄心境和合成業，業性自空，非使之空。由存妄計，故受輪轉；
【譯文】在諸多經論之中，或者就依報正報與善惡因果而言，或者就世間出世間、有漏無漏、色法心法非色心法、善惡無記，或者五陰十八界十二入等來論述。若是通泛論述，則是總觀一切諸法；如今就懺悔法而言，且專指罪業來作為所觀之境。「性空無我」這一句，就是能觀的智慧。罪業是依憑因緣而生起，本來就沒有自性；所謂因緣就是內心與外境，虛妄的心與境和合而形成罪業，罪業的本性自身本空，並非修行者刻意使它變成空。由於存有虛妄的計執，所以才遭受生死輪迴；

【189-0052】資持記/12a_中四下#19
【原文】但破妄計，覓罪叵得；叵得之處，強名空理。言性空者，小機智劣，不能即法見空；必待推析窮法體性，然後方空；其中須分利鈍，利者體法即空；鈍者析法見空；或云：有宗唯證人空，假宗人法二空。此下判位。小乘通收聲聞緣覺；據所乘法，諦緣雖殊；若論斷證，同見空理。
【譯文】只要破除了虛妄執著，尋求罪業的自性了不可得；這了不可得的實相，勉強稱它為空理。稱為「性空」的緣由，是小乘根機智慧低劣，不能當下就萬法徹見其體性本空；必須等待推求析破以窮究諸法的實體，然後才能見到空性；在小乘根機中又必須區分利根與鈍根，利根者體達當下萬法即是空；鈍根者必須逐步分析萬法才見到空；又或者說：阿毗達磨有宗只證悟人我空，成實假宗則兼證人我、法我二空。「此下」判定果位。小乘法總括收攝聲聞與緣覺；若據其所依乘的法門而言，四諦與十二因緣雖有不同；但若論及斷惑證真，則同樣親見此一空理。
