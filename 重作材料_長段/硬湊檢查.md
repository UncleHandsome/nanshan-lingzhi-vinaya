# 定稿硬湊檢查

## 方法

逐筆比對：

```text
定稿 source（純漢字）
vs
TXT raw[raw_start:raw_end]（純漢字）
```

不相等就是區間與原文不一致。

## 結果

| 書 | 單位 | source ≠ raw | 比例 |
|:--|--:|--:|--:|
| 行事鈔 | 1,574 | 8 | 0.5% |
| 戒疏 | 4,659 | **4,462** | **95.8%** |
| 業疏 | 2,616 | 76 | 2.9% |
| 尼鈔 | 804 | 0 | 0% |
| 義鈔 | 215 | 0 | 0% |

## 戒疏

幾乎整本書的 `source` 和 `raw_start:raw_end` 不一致。

例：

```text
00_卷首_0020
source：凡例題中四分律戒本出曇無德部……
raw   ：凡例題中四分律戒本出曇無德部……
```

看起來很像，但邊界有偏移。

```text
00_卷首_0021
source：凡例戒本之注古本並分行細書……
raw   ：置也戒本之注古本並分行細書……
```

`raw_start` 早了約 2 字。

## 判定

```text
戒疏不是少量硬湊
是系統性邊界偏移
```

原因是對齊時用前綴定位後，沒有逐筆驗證整個 `source` 是否等於 raw 切片。

## 其他書

- 行事鈔 8 筆：多為底本異字（屍／戶、以／已）
- 業疏 76 筆：多為異體字（羣／群、獨／局）
- 尼鈔、義鈔：0

## 結論

```text
有硬湊，主要在戒疏
不能說戒疏已對齊完成
```

## 修正方向

1. 不再用前綴直接定區間
2. 對每筆用完整 source 在目前位置附近重新找
3. 驗證 `source == raw[start:end]`
4. 找不到就標未定位，不硬拉
5. 全部歸零後才可說對齊完成
