# 校閱材料　第207檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【207-0001】資持記/16a_下四#12
【原文】請尋大小《彌陀經、十六觀經、往生論、十疑論》等諸文，詳究聖言，必生深信矣。像面向西，病者在後；謂將終之時已前，常須瞻像，令其繫心。忍土者，梵語娑婆，此云堪忍；《大悲經》云：此界眾生，忍受三毒，及諸煩惱故。人間臭穢者，《感通傳》，天人云：人中臭氣，上熏於空四十萬里；
【譯文】請研讀查閱大本與小本《阿彌陀經》、《十六觀經》、《往生論》、《淨土十疑論》等各部文典，仔細窮究佛陀聖者的教言，必然能生起深切的信心。佛像應當面向西方，病人則安置在佛像後方；是指在即將命終之時以及在此之前，必須常常能瞻仰佛像，使病人的心念緊緊繫念不散。所謂「忍土」，梵語稱為娑婆，在此翻譯為「堪忍」；《大悲經》說：這個世界的眾生，能夠忍受貪瞋癡三毒以及種種煩惱的緣故。所謂「人間臭穢」，《感通傳》中天人曾說：人間的濁惡臭氣，向上熏染空界達四十萬里之遠；

【207-0002】資持記/16a_下四#13
【原文】諸天清淨，無不厭之；但以受佛付囑，令護於法；佛尚與人同止，諸天不敢不來。恒在佛所者，恐心無繫，念世事故。四中，初科。《十誦》文中，但是通制；下諸詞句，皆出祖師。深法，但是佛教，通得云深。是道謂出世法，非道即世間法。練若中。汎話，謂問疾安慰，以為勸誘之端。
【譯文】諸天的身心清淨純潔，無不對此感到厭惡嫌棄；只是因為承受了佛陀的囑託，命令他們護持佛法；佛陀尚且與世間凡人同住一處，天人們這才不敢不降臨護持。所謂「始終安置在佛像所在之處」，是唯恐病患的心神無所繫掛，轉而憶念世間俗事的緣故。第四部分的第一科中，《十誦律》的經文只是一般的通規戒律；其後的種種遣詞用句，全都是出自律宗祖師的闡發。所謂「甚深之法」，只要是佛陀的教法，通通都可以稱為甚深。所謂「是道」是指解脫出世的法門，「非道」則是指世間法。在「阿蘭若」這一節中，所謂「泛話」，是指探問病情與安慰的話語，以此作為勸誘引導的起點。

【207-0003】資持記/16a_下四#14
【原文】捨座，即分半座與迦葉坐；捨衣，謂脫所著衣，易彼糞掃衣披之。誦經中。鸚鵡緣出《賢愚經》中，彼云：須達家有二鸚鵡，能知人語；阿難往其家，授四諦法；聞已，喜悅誦習；飛向樹上，次第上下，經於七反；其暮宿樹，野狸所食，即生四天王天；阿難聞已，問佛生處；
【譯文】所謂「捨座」，就是將半個座席讓給迦葉尊者同坐；所謂「捨衣」，就是脫下自己所穿的袈裟，換穿迦葉的糞掃衣。「誦經」這一節中，鸚鵡得度的因緣出自《賢愚經》，該經記載：須達長者家中有兩隻鸚鵡，能夠懂得人語；阿難尊者前往長者家，為牠們傳授了四聖諦法；鸚鵡聽聞之後，法喜充滿地複誦修習；牠們飛到樹上，順次由上而下、由下而上，來回飛動了七趟；當天傍晚在樹上歇息，不幸被野狸捕食，命終之後立即投生在四天王天；阿難聽聞此事，便向佛陀請教牠們投生的去處；

【207-0004】資持記/16a_下四#15
【原文】佛告阿難：緣汝授法，命終之後，初生四天王天，壽五百歲；二生忉利天，壽一千歲；三生焰摩天，壽二千歲；四生兜率天，壽四千歲；五生無憍樂天，壽八千歲；六生化應聲天，壽萬六千歲；七還生第五天，次第還至四天王天，上下七反，天壽終已，下生閻浮提；於人中，出家學道；
【譯文】佛陀告訴阿難：「由於你為牠們傳授正法的因緣，牠們命終之後，最初投生在四天王天，壽命五百歲；第二次投生在忉利天，壽命一千歲；第三次投生在夜摩天，壽命二千歲；第四次投生在兜率天，壽命四千歲；第五次投生在化樂天，壽命八千歲；第六次投生在他化自在天，壽命一萬六千歲；第七次再投生回到第五天，這樣次第往返乃至四天王天，上下往返共七個回合，天界的壽命享盡之後，轉生降生在閻浮提人間；在人道之中，得以出家修學佛道；

【207-0005】資持記/16a_下四#16
【原文】緣前四諦，心自開解，成辟支佛，故云後得道迹。《大品》，即《般若》；〈經耳品〉，出第三十卷，彼云：釋提桓因作念，若人聞般若名一經耳者，是人先世，佛所作諸功德，與善知識相隨，何況受持讀誦。常住二字，六卷《泥洹》云：善男子，善女人，當持如來常住二字，歷劫修習；
【譯文】因為過去聽聞四聖諦的善根，內心自然開解悟道，證成了辟支佛果，因此才說『後來證得道跡』。《大品》就是指《大品般若經》；〈聞持品（經耳品）〉出自第三十卷，經中記載：釋提桓因心中思忖，如果有人能讓般若波羅蜜的經名僅僅聽聞於耳中一次，這個人前世必定曾在諸佛處所修造種種功德，並有善知識時常相隨，更何況是受持讀誦這部經典。至於『常住』這兩個字，六卷本《大般泥洹經》說道：善男子、善女人，應當受持如來常住這兩個字，經歷曠劫精勤修習；

【207-0006】資持記/16a_下四#17
【原文】是等眾生，不久當成等正覺道。二經並明勝報，故云不生惡道也。律師中。毘尼主於住持，故讚興隆等。自持攝他，即是二利。諸佛讚者，如諸經論，讚持戒功深，如〈標宗〉具引。法師中。迷倒如盲，妄想如病。禪師中。梵云禪那，此云思惟修；故知禪者，唯是修心，故貶多說。今之參禪，亦務多說；
【譯文】這類眾生，在不久的將來必定當成就無上正等正覺的佛道。這兩部經典都闡明了聽聞受持能獲殊勝的果報，所以才說『不墮入惡道』。在『律師』這一節中，毘尼戒律主旨在於住持正法，所以稱讚能興隆僧團等德行。自行持戒並攝受他人，這便是自利利他的二利之行。所謂諸佛稱讚，正如各部經論之中，盛讚持戒功德無比深廣，這在〈標宗篇〉中已經完整引述。在『法師』這一節中，沉迷顛倒好比雙目失明，妄想紛飛好比重病在身。在『禪師』這一節中，梵語稱為禪那，此處翻譯為『思惟修』；因此可知修禪者純粹是在於收攝修心，所以貶抑過多的言說談論。如今參禪之人，也競相追求誇誇其談；

【207-0007】資持記/16a_下四#18
【原文】事持言句，忘本久矣。眾事中，初引五聖為比。沓婆，即《四分》沓婆羅漢；捨羅漢者，厭無學也；求堅固者，修大行也；《善見》云：此人是王子出家，故云王種。迦葉緣者，《薩婆多傳》云：迦葉於耆山，自經營五寺，通為一界，自作泥塗壁。祇夜，具云祇夜多；
【譯文】只知在字句言詞上記持玩弄，忘失了參究自心的根本已經很久了。在『僧團事務』這一節中，首先引述五位大聖者作為行持的榜樣。所謂『沓婆』，就是《四分律》中所說的沓婆羅漢；『捨棄羅漢果位』，是指厭離自了的無學境界；『求取堅固妙果』，是指發心修持自利利他的大乘行願；《善見律》說：這個人原本是王子出家，所以稱他為『出身王室尊貴種姓』。迦葉尊者的因緣，《薩婆多部傳》記載：迦葉尊者在耆闍崛山，親自操辦營造了五處寺院，統合為一個結界範圍，並親自動手用泥土塗抹牆壁。所謂『祇夜』，全名為祇夜多；

【207-0008】資持記/16a_下四#19
【原文】《雜寶藏》云：南天竺有二比丘，聞夜多有大威德，到其住處；見一比丘，形容憔悴，竈前然火；問言：識夜多否？答云：在第三窟，即至窟中，但見向來然火比丘；禮已，問云：既有威德，何為自勞？答曰：我念昔時生死之苦，若我頭手可以然者，尚不惜之，況勞身也。身子，即舍利弗；

【原文】能書寫則稱為草聖，通俗典則自號文章，擇地則名為山水，卜術則呼為三命；豈意捨家事佛，隨順俗流之名；本圖厭世超昇，翻習生死之業。故《智論》云：習外典，如以刀割泥；泥無所成，而刀自損；又如視日光，令人眼暗。然往古高僧，亦多異學；或精草隷，或善篇章，或醫術馳名，或陰陽顯譽；
【譯文】稍微擅長書法書寫的便自誇自封為「草聖」，稍微通曉世俗文史典籍的便自命為「文章巨擘」，懂得堪輿選地的便自居為「山水地理宗師」，通曉占卜算命之術的便自吹為「三命精微大師」；哪裡想得到自己當初辭親出家原本是為了求事於佛，如今卻反過來隨逐附和世俗凡流的虛名；原本圖謀的是厭離五濁世間以求超昇解脫，如今反倒全力修習流轉生死的有漏之業。所以《大智度論》說道：出家人修習外道世俗典籍，好比「拿鋒利的寶刀去切割爛泥」；爛泥固然絲毫無法塑造成功，而寶刀的鋒刃自己卻已經受損變鈍了；又好比「直視烈日強光，反倒使人的眼睛當場盲黑」。然而縱觀古代的諸位高僧大德，也往往兼通許多世間異學；他們有的精研草書隸書，有的擅長詩文篇章，有的以精湛醫術揚名當世，有的以精通陰陽曆數顯赫一時；

【原文】皆謂精窮本業，傍涉餘宗；無非志在護持，助通佛化。故《善戒經》云：若為論義，破於邪見；若二分經，一分外書，不犯；《四分》開誦，皆此意耳。今或沽名邀利，附勢矜能；形廁方袍，心染浮俗；畢身虛度，良可哀哉。《母論》。一句一偈，通指三藏教詮；

【207-0047】資持記/16a_下四#58
【原文】雖是聖教，令觀時用舍，不可專固，故云應行即行等。後世比丘，即佛滅後，傳法祖師；凡有言教，亦須隨宜，故云亦爾。四中，《五分》，示開制。無人，謂無剃髮者。難緣，謂遭世難。論家，即《多論》。彼明次第，即約多人，同時剃故。《母論》，簡剃處。餘毛，即身腋等處，律制偷蘭。
【譯文】這縱然是至高無上的聖者教法，但也要求修學者必須審察時機來決定取捨運用，絕不可固執一端僵化不變，所以才說「應該行持的時候便如實推行」等等。所謂「後世的比丘」，是指佛陀滅度之後，歷代承續弘揚正法的祖師大德；凡是所立下的言教法規，也必須隨順時機因緣而靈活運用，所以才說「也是如此」。在第四小段中，《五分律》明示了開許與禁制的界限。所謂「無人」，是指身邊沒有可以代為剃髮的人。所謂「遇上險難因緣」，是指遭遇世間戰亂流離等危急苦難。所謂「論家」，指的便是《薩婆多論》的論師。該論闡明剃髮的先後次第，是針對有多數人同時聚在一起剃髮的情況而言。《毘尼母論》則嚴格揀別可以剃除毛髮的部位。至於其餘各處的體毛，也就是腋下、隱私部位等處，戒律明文規定若任意剃除便結偷蘭遮罪。
