# 校閱材料　第1455檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1455-0001】04_比丘尼鈔/04b_卷中之下#3
【原文】共俗男子屏坐戒具四緣犯一是俗男子二屏處坐三無第三人四伸手不及戶處坐便犯僧祇云若母姉妹淨人等睡眠癡狂心亂嬰兒非人畜生雖有是人亦名為獨竟日坐一提中間更起一一提若淨人作務來往不斷門向道中有人行如食頃不斷若閣上閣下淨人遙見者並不犯此律若舒手及戶坐使乞食尼見若二尼為伴若有識別人在邊及有難緣等並不犯。
【譯文】（與男子在隱密處坐戒）具備四個條件即構成犯罪：一是對方是俗家男子，二是坐在隱蔽有遮障之處，三是身邊沒有第三人在場，四是坐在伸手夠不到門的地方，只要坐下即犯波逸提罪。《摩訶僧祇律》說，如果是母親、姐妹、淨人等在場，但他們處於昏睡、愚癡發狂、心神錯亂、或者只是嬰兒、非人、畜生，雖然有人在身邊，仍然算作獨處。整天連續坐著犯一個波逸提罪；中間如果起身後再坐，每次起身再坐都各犯一個波逸提罪。如果淨人做雜務來來往往未曾中斷，或者房門正對著道路，持續有人走過（維持約一頓飯的時間未曾斷絕），或者樓上樓下的淨人從遠處能看見，這幾種情況都不犯戒。依照本律，如果伸手就能夠到門邊坐著，或者能被行乞的比丘尼看見，或者有兩位比丘尼結伴同在，或者身旁有懂事的人，以及遇到危難險緣等情況，都不犯戒。

【原文】共男子露坐戒具四緣犯一是俗男子二露處坐三無第三人四伸手內共坐便犯十誦云與男子露地坐隨起還坐隨得爾數提相去半尋提相去一尋半吉二尋若過無犯。
【譯文】（與男子在露天處坐戒）具備四個條件即構成犯罪：一是對方是俗家男子，二是坐在露天無遮蔽之處，三是身邊沒有第三人在場，四是坐在伸手可及的距離內，只要一同坐下即犯波逸提罪。《十誦律》說，與男子在露天處坐著，每次起身再坐下，就隨坐下的次數犯相等數量的波逸提罪；彼此相距半尋（約四尺）犯波逸提罪，相距一尋半犯突吉羅罪，距離達到二尋或超過二尋則不犯戒。

【1455-0003】04_比丘尼鈔/04b_卷中之下#5
【原文】觀軍陣戒具四緣犯一是軍陣二故往三無因緣四往見使犯僧祇云若入聚落城邑道中逢軍陣不作意見無犯若作意舉頭下頭窺望欲使見者提十誦云若軍陣發行為鬬彼賊殺死因觀無常故不犯婆論云道由中過無犯若立住看犯左右反顧壞威儀故吉羅。
【譯文】（觀看軍陣戒）具備四個條件即構成犯罪：一是對象確實是軍陣，二是故意前往，三是沒有正當因緣，四是親自前往觀看，只要前去看軍陣即犯波逸提罪。《摩訶僧祇律》說，如果在進入村落、城邑的途中偶然遇到軍隊陣列，並非存心觀看，則不犯戒；若是存心抬頭、低頭窺視張望，想看清軍隊的，犯波逸提罪。《十誦律》說，如果軍隊出發作戰是為了討伐盜賊，比丘尼前往是藉由傷亡來觀察無常之理，則不犯戒。《薩婆多毘尼毘婆沙》說，道路必須從軍隊中穿過而不犯戒；如果停下腳步站著觀看便算犯戒；東張西望破壞威儀的，犯突吉羅罪。

【1455-0004】04_比丘尼鈔/04b_卷中之下#6
【原文】飲酒戒具三緣犯一是酒二無重病緣三飲便犯此律體雖是酒而非酒色非酒香非酒味不應飲體非是酒然有酒色酒香酒味得飲若飲甜味酒若飲酸味酒若食酒糟若食麴等並吉羅自今已去以我為師者乃至不得以草木頭內酒中滴入口餘藥治不差以酒為藥者不犯五百問事云若醫師言必差得和藥服不得空服強勸人不飲吉飲提婆論云此戒極重能作四逆唯除破僧又能破一切戒及餘眾惡故。
【譯文】（飲酒戒）具備三個條件即構成犯罪：一是所飲確實是酒，二是沒有重大疾病的特殊因緣，三是飲用下去即犯波逸提罪。依照本律，本質雖然是酒，但看起來沒有酒的顏色、聞起來沒有酒香、嚐起來沒有酒味，也不應該飲用；本質不是酒，但具備酒的顏色、酒香、酒味，則可以飲用。如果飲用甜味酒、酸味酒，或者食用酒糟、酒麴等，都犯突吉羅罪。佛陀教誡：「從今以後，凡是以我為導師的弟子，甚至不能用草木的末端蘸酒滴入口中。」若用其餘藥物治療都無法痊癒，必須以酒為藥引的，則不犯戒。《五百問事》說，如果醫生診斷說必須用酒才能治好，可以將酒調和在藥物中服用，不得未調和藥物而單獨飲酒（不得單飲純酒）。強勸他人飲酒，若對方不喝，勸酒者犯突吉羅罪；若對方喝了，勸酒者犯波逸提罪。《薩婆多毘尼毘婆沙》說，這條戒極為重大，因為飲酒能引發四種逆罪（除了破和合僧之外），而且能毀破一切戒律並引生種種惡行。

【1455-0005】04_比丘尼鈔/04b_卷中之下#7
【原文】水中嬉戲戒具三緣犯一是水二無因緣三入水便犯此律戲者放意自恣或以手畵水相澆乃至以鉢盛水弄一切皆提除水弄餘苦酒等吉僧祇云水陸互澆灒越俱水中者提五分持雪乃至草頭露弄者吉此律若道行渡水者不犯。
【譯文】（水中嬉戲戒）具備三個條件即構成犯罪：一是場所確實是水，二是沒有正當因緣，三是進入水中嬉戲即犯波逸提罪。本律所說的嬉戲，是指放縱心思、自我任性，或者用手劃水互相澆潑，乃至用缽盛水玩耍，這些行為全都犯波逸提罪；除了水以外，若是拿苦酒等液體玩耍，犯突吉羅罪。《摩訶僧祇律》說，一人在水中一人在陸地互相澆潑濺水，犯越毘尼罪；兩人都在水中嬉戲澆潑，犯波逸提罪。《五分律》說，拿雪甚至拿草頭上的露水來玩耍嬉戲的，犯突吉羅罪。依照本律，如果是在路上行走需要涉水過河的，不犯戒。

【1455-0007】04_比丘尼鈔/04b_卷中之下#9
【原文】不受諫戒具五緣犯一自作非法事二他如法諫三知己所作非前人諫者是四拒諫不受五隨所作犯根本違諫得提此諫作犯雖發言拒諫未是作犯要待作事違諫義成故得提罪此戒最益制欲犯者恐有業行之過不可一一集僧而諫故令一人處處行諫違便得罪婆論云前諫人有六種不應從一心有愛憎二若鈍根無智三若少聞見四為利養名聞五為現法樂但欲自攝六若新出家愛戀妻子如是六人諫則有損。
【譯文】（不受規諫戒）具備五個條件即構成犯罪：一是自己做了違背戒律法度的事，二是他人依法予以規勸諫阻，三是知道自己所作是不對的且對方所諫是正確的，四是抗拒諫勸拒不接受，五是隨著後續所造之業犯根本罪，違背諫勸犯波逸提罪。這種因違諫而犯戒的情況，雖然開口拒絕規諫時還不算正式犯戒，必須等到真正把事情做下去、違諫的實質成立之後，才正式獲犯波逸提罪。這條戒律最具利益，是用來遏制想要犯戒的人；因為擔心造下惡業罪過，不可能每次都召集僧團進行諫勸，所以允許個人隨處隨事進行規諫，只要違背諫勸便得罪。《薩婆多毘尼毘婆沙》說，前來諫勸的人如果有以下六種情況，可以不用聽從：一是心存偏袒喜怒；二是根性遲鈍毫無智慧；三是少聞淺見；四是為了爭奪名聞利養；五是只耽著現生禪修法樂，只想自我收攝（獨善己身而不求化導）；六是剛出家不久，心中仍戀戀不捨妻子兒女。這六種人前來諫勸，往往只會帶來損害。

【1455-0008】04_比丘尼鈔/04b_卷中之下#10
【原文】恐怖尼戒具五緣犯一是比丘尼二作恐彼意三以六塵等事示說四現相言了五見聞便犯不待前怖與不怖。
【譯文】（恐怖比丘尼戒）具備五個條件即構成犯罪：一是對象是比丘尼，二是存心想要恐嚇對方，三是藉由色聲香味觸法等六塵事物進行示現解說，四是顯露驚悚形相且言辭表達清楚，五是對方一經看見或聽聞即犯波逸提罪；無論對方最後到底有沒有受到驚嚇，只要做了就成立犯罪。
