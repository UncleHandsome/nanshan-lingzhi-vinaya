# 校閱材料　第1165檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1165-0001】資持記/09a_中三上#22
【原文】然彼正作應云，明是答詞；若準注意，義又非便；以在胡正為妄語，在漢復是異音，二皆不可。《指歸》云：指甲乃是脚跡，令彼自看獸跡，則免上過；又斥《僧祇》注文是後人妄加。未詳孰是，疑故並存。《十誦》。三種語他。初是虛誑，正犯此戒。次兼妄惱，則犯二戒。
【譯文】然而該律正文中寫作「應當說」，顯然是作為回答的言詞；如果依照注文的意思，在義理上又不太妥當；因為在胡地這分明就是妄語，在漢地這又變成了奇異不明的方言，兩者都是不可以的。《指歸》說：指甲其實是指腳印足跡，讓對方自己去看野獸的足跡，就能免除上述的過失；並且斥責《僧祇律》的注文是後代人妄自添加的。目前尚不清楚哪一種說法才正確，因為心中存疑所以兩說並存。《十誦律》中列出三種對他人說話的情況。第一種是虛誑不實，正是犯了本條戒。第二種是既虛妄又惱亂他人，就犯了兩條戒。

【1165-0002】資持記/09a_中三上#23
【原文】後即稱實，止犯後戒，即下六十三疑惱戒也。不犯中。指注戒者，彼云不見言不見，乃至知言知等。今云稱想，在言雖略，無不攝矣。第二。〔佛在舍衛，六群毀罵斷事人因制。〕戒名。有云惡口，然據律中亦通善法。今云罵者，但是辱他，通收善惡。引勸中，《智論》。
【譯文】第三種則是據實陳說，只犯後面那一條戒，就是下面第六十三條的疑惱戒。不犯戒的條款中。指出《注戒》所說的，該處說沒看見就說沒看見，乃至知道就說知道等。如今說「契合心中所想」，言詞上雖然簡略，但已經無所不包了。第二條戒。〔佛陀在舍衛國時，六群比丘毀辱辱罵裁斷是非的訴訟執事僧，佛陀因此制定此戒。〕在戒名方面。有人稱作惡口，然而依據戒律來看，也可以通向宣說善法時借題發揮。如今稱為毀罵，只要是侮辱他人，通通收攝了以善法或惡法來罵詈。引用勸戒文句中，出自《大智度論》。

【1165-0003】資持記/09a_中三上#24
【原文】彼九十二云：一切菩薩道，皆淨此三業；初淨身口意，後為淨佛土；自身若淨，亦淨他人，何以故？非但一人生國中，皆共作因緣。〔同處受生，共業所感；此明菩薩欲取淨土，必須化他令淨三業，乃可同感故也。〕今引下二句，以謂一人受生所依報土，悉是多人共業所感；今止取意，不必泥文。謂下，是論自釋。
【譯文】該論第九十二卷說：一切菩薩之道，都要清淨這三種身口意業；最初是清淨自己的身口意，最後是為了清淨佛國淨土；自身如果清淨，也能夠使他人清淨，這是為什麼呢？因為並非只有一人受生在國土中，而是大家共同造作因緣所招感的。〔在同一處所受生，是共同業力所感召；這是說明菩薩想要求取清淨佛土，必須教化他人讓大眾的身口意三業都清淨，才能夠共同感召淨土的緣故。〕如今引用下面兩句，是認為一個人受生所依止的依報國土，全都是多數人共業所感召的；如今只取其核心意涵，不必拘泥於字面文句。所謂「謂」以下，是論典自己的解釋。

【1165-0004】資持記/09a_中三上#25
【原文】內法是業，即善不善；外法是報，即所依器界；報由業感，故云與也。如惡下，先示三惡因緣，以配三報；且據口意，略不明身；因果相對，尋文可了。不作下，次明三善；反上三報，故云平正也。下舉彌勒為證，彼佛當來人壽八萬歲時出世。
【譯文】內在的精神法是業，也就是善業與不善業；外在的物質法是果報，也就是生命所依託的器世間；果報是由業力感召而來的，所以說是隨業而給予。如同惡法以下，首先指出三種惡業因緣，用來配對三種不善的果報；這只是暫且依據口業與意業來說，簡略沒有說明身業；因與果相對應，詳讀文句就能明了。從「不作」以下，接著說明三種善業；與上面的三種惡報相反，所以說是平正吉祥。下面舉出彌勒佛作為證明，那位佛陀將在未來人壽八萬歲的時候降生出世。

【1165-0005】資持記/09a_中三上#26
【原文】引此文者，意彰惡口過重，感報不淨，令自勉也。次本律中。彼云善語者善〔樂因果故〕，惡語者自熱惱〔苦因果故〕乃下，舉況。束彼廣文，故云乃至。彼具云：剎尸羅國婆羅門有牛，與一長者牛鬪力；共駕百車，賭金千兩，婆羅門於眾前作毀呰〔音紫〕云：一角可牽。
【譯文】引用這段經文，用意在於彰顯惡口罵人的過失極其嚴重，會感召不淨的依報環境，好讓人自我策勵勉勉修持。接著引用本律經文。該律說口出善言的人就獲得善果〔因為這是安樂的因果〕，口出惡言的人就自身煩悶熱惱〔因為這是痛苦的因果〕，從「乃」以下，是列舉事例來作比況。這是概括了那段冗長的經文，所以說「乃至」。該處完整地說：剎尸羅國有個婆羅門養了一頭牛，與一位長者的牛比賽力氣；兩頭牛各自拉動一百輛車，以黃金千兩作為賭注，婆羅門卻在大眾面前毀謗侮辱自家的牛說：一隻角的畜生可以拉車了。

【1165-0006】資持記/09a_中三上#27
【原文】時牛慚愧，不肯出力，遂即輸金；乃至牛語婆羅門言：汝於眾前毀呰故爾。又令主倍賭二千兩，當於眾前讚言端正好角；主依牛語，乃得勝彼。〔《多論》云：劫初未有三惡道眾生，盡從人天中墮；以宿習近，是以能語，具如疏引。〕緣中。二引《伽論》，證須自語；
【譯文】當時那頭牛感到羞慚難堪，不肯出力拉車，婆羅門於是輸掉了黃金；隨後牛對婆羅門說：你只因為在大眾面前毀謗侮辱我，我才這樣的。牛又讓主人加倍下賭兩千兩黃金，並交代應當在大眾面前讚美牠長相端正、牛角美麗；主人依照牛的話去讚賞，這才贏了長者。〔《薩婆多論》說：劫初時代還沒有三惡道的眾生，全都是從人道與天道中墮落下來的；因為過去世身為人類的習性尚近，所以動物還能夠說話，詳情正如律疏所引用。〕在犯戒條件中。第二條引用《摩得勒伽論》（伽論），證明必須親口說出才算；

【1165-0007】資持記/09a_中三上#28
【原文】傳為並輕，故言皆吉。釋中，初科。六諍本者，不出三毒；上二是瞋，次一即貪，下三並癡。一切諍起，不越此六，故云本也；能治此六，則無諍矣。罵相中，本律分二；初明惡法又二，先出語相。種類者，六品是種，隨一品下多相為類。一卑姓家生者，即旃陀羅、除糞種、竹師種、車師種等。
【譯文】傳達別人的罵詈之詞罪責較輕，所以說都結吉羅罪。解釋之中，第一科。六種爭執的根本，全都不出貪瞋痴三毒；上面兩種是瞋，中間一種就是貪，下面三種全都是痴。世間一切爭端生起，都不超越這六種根本，所以稱為本；若能對治這六種心，就不會有爭端了。在毀罵的具體相狀中，本律分為兩大部分；首先說明以惡法罵人，又分為二，先列出口說的相狀。所謂「種類」，六品是種，在任何一品之下繁衍的眾多相狀稱為類。第一是出身低賤種姓家，就是旃陀羅、挑糞種姓、竹編篾匠種姓、車伕種姓等。

【1165-0008】資持記/09a_中三上#29
【原文】二行業者，即屠獵漁捕作賊守城等。三伎術卑者，鍛〔丁貫反〕作，木作，瓦陶〔音󱌲〕作，皮革作等。四犯過者，作七聚罪也。注中。若據餘五，依實亦同。恐謂實犯，呵毀無過，故特注之。問：不實成謗，為犯何戒？答：前謗戒中，引《僧祇》云對所謗人前罵謗語語僧殘，不言罵罪。
【譯文】第二是賤業，就是屠夫、獵戶、漁民、盜賊、城門守卒等。第三是卑微的工藝技術，打鐵、木工、陶器瓦器製作、皮革加工等。第四是毀犯戒律過失，造作了七聚罪過。在注文中。如果對照其餘五種，即便依照事實罵人也同樣犯戒。唯恐有人以為對方確實犯戒，出言呵斥毀辱就沒有罪過，所以特別加以注釋說明。問：如果不合事實而罵就構成了誹謗，究竟該犯哪一條戒？回答：前面誹謗戒中，引用《僧祇律》說在被毀謗的人面前口出罵詈誹謗之語，每一句話都犯僧殘罪，並沒有另外結惡口罵人罪。
