# 剩餘長段／GAP 材料

## 內容

```text
剩餘 >1000 字長段：12
GAP17：1
```

檔案：

```text
重作材料_長段/剩餘_長段GAP_材料/
GAP06.md
GAP07.md
GAP12.md
GAP13.md
GAP14.md
GAP17.md
GAP24.md
GAP44.md
GAP50.md
GAP66.md
GAP90.md
YE-G01.md
```

## 輸出

```text
<key>_回.md
```

例如：

```text
GAP66_回.md
YE-G01_回.md
```

## 格式

```text
## GAP66-1
原文起：……
原文迄：……
白話起：……
白話迄：……
```

- 白話起迄必須從【現譯】擷取
- 不可寫「（現譯從缺）」

## 完成後

放回：

```text
測試/重譯/_長段_送千問/回覆/
測試/重譯/_義鈔GAP_送千問/回覆/
```
