# 校閱材料　第1307檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1307-0001】資持記/14b_下二#29
【原文】非畜成者，必約知解。三中。止即不須。手眼現相，口即語示。四中，敘意為三，初示法。心境者，心即能緣，境謂前食。仰手是色，相領即心。上注引非顯正，下注釋成相領。一事即食境。除下，明開。眼雖不覩，亦可聞聲；有緣置地，彼雖無心，自須起意。
【譯文】非人和畜生能夠成就證明，必然是針對具有理解能力者而言。在第三部分中，「止」就是不需要的意思。手勢與眼色呈現外相，口中則用言語示意。在第四部分中，敘述其意圖分為三點，首先說明受法。「心境」這兩個字，心是指能緣的心念，境是指眼前的食物。雙手向上攤開屬於色法，彼此心意領受屬於心法。上面的註文引用錯誤的做法以顯現正確的做法，下面的註文則解釋促成彼此心意領受的道理。「一事」就是指食物這個對境。「除」字以下，說明開許的情況。眼睛雖然看不見，也可以透過耳朵聽見聲音；有特殊因緣而放在地上時，對方雖然沒有特別作意，自己心裡必須生起受持的意念。

【1307-0002】資持記/14b_下二#30
【原文】不喜即外道相嫌，驚急即火燒馬屋，具引如〈釋相〉。既下，教通受。謂先須起念是食皆受；後或心差，亦得成法。受法，標中，初指略時藥。此下，次標三藥。分位以明，故曰別論。非時四位，初中。八患，謂八種過。前五染觸，通自他犯；後三約受，唯據自論。
【譯文】「不喜」是指遭到外道嫌棄，「驚急」是指失火燒了馬棚，詳細引述就如同〈釋相篇〉所載。「既」字以下，教導通用的受法。意思是說事先必須生起意念：凡是食物我全都接受；事後就算心念出現偏差，受法也一樣能夠成立。在「受法」標題這一段中，開頭先略過時藥不談。「此」字以下，接著標示出其餘三種藥。因為必須分出不同的階段時位來說明，所以稱為「分別論述」。非時藥有四個階段，在第一階段中，「八患」是指八種過失。前面五種屬於沾染污觸，自己或他人犯戒都會受影響；後面三種針對受持來說，唯獨就自己這方面來論斷。

【1307-0003】資持記/14b_下二#31
【原文】六是不受，七八即失受。第七且據中後為言，中前無過，如注所簡。第八注文，即前轉變體中中論所說；謂果漿變為甜醋，即失受法。二中。須煮沸者，謂生果汁；必是熟者，則不須之。三中。前漿類別者，如上體中果蜜等漿，有差別故。三記識者，或須不須，故注示之。四中。
【譯文】第六種是未曾受持，第七和第八種是失去受持。第七種暫且是針對正午之後的時間來說的，如果在正午之前則沒有過失，就如同註文中所簡別的那樣。第八種的註文，就是指前面「轉變體」中依照中論所說的內容；也就是果汁發酵變成了酸醋，就失去了原本受持的效力。在第二階段中，必須煮沸的，是指生鮮的水果汁；如果本來就是熟的，就不需要再煮沸。在第三階段中，前面所說各類果漿的區別，就如同上面在藥體中所說的水果漿、蜜漿等，彼此存在差異。第三種「記識」，有時需要、有時不需要，所以註文特別予以說明。在第四階段中。

【1307-0004】資持記/14b_下二#32
【原文】諸律無文有事，故須義立。詞中六句。初令專審，恐異緣故。二稱己名，簡非他故；準下科中，病重不堪，得代加之，應稱病者名字。三稱病緣，明非濫託。四云薑湯，別指藥體。五云夜分，期定時限。六於他受，求前對證。〔下二法分句同此。〕注云無遺不須加者，由加口法，本為延時；
【譯文】各大律典中沒有明文記載卻有實際行事，所以必須依義理來訂立。唱詞中共有六句：第一句是令對方（對首大德）專心審察，唯恐夾雜了其他因緣。第二句是稱呼自己的名字，簡別這不是別人；依照下文的科別，如果病情嚴重無法親自作法，可以由他人代為加受，這時就應當稱呼病患的名字。第三句是說出生病的因緣，表明並非隨意託詞。第四句說「薑湯」，是特別指出該藥物的本體。第五句說「夜分」，是明確限定時間的期限。第六句是向他人請求受持，尋求對方作為當面的證人。（下面兩種受法的分句也是比照這個格式。）註文說如果沒有剩餘就不需要加受，這是因為增加口頭唱詞的受法，本來就是為了延長存放的時間；

【1307-0005】資持記/14b_下二#33
【原文】必無所留，但直手受七日中，初明八患。改第八者，以酥油等無變動故。犯竟殘藥，異上殘宿；但是受已經夜，非犯竟者。〔昔約自他分異，非非。〕能授四法，大同於前。三中五過，初過分二，初正明，二問答。正明又三，初句標過。若下，示相。僧下，引證。
【譯文】如果必定沒有剩餘的藥物，只要直接用手接受即可。在「七日藥」中，首先說明八種禍患。之所以改動第八種，是因為酥油等物不會變質腐壞的緣故。已經犯過戒的殘餘藥物，與上面所說的「殘宿」不同；殘宿只是接受之後經過了一夜，並非犯過戒的藥物。（過去有人從自己或他人來區分差別，這是不對的。）能授藥者的四種法則，大致與前面相同。在第三部分所列的五種過失中，第一種過失分為兩段，首先正式說明，其次進行問答。正式說明又分為三部分，第一句標示出過失。「若」字以下，指出其相貌。「僧」字以下，引用文獻作證。

【1307-0006】資持記/14b_下二#34
【原文】問答中，由未犯長，制受不成，故須問決；答中，前釋不成，後簡異藥。第二。長染不成，可會。三中。藥味通者，義同共畜故。《僧祇》如此者，若據本宗，理應自成。四中，初引制法。一日即第八日。謂下，顯意。上句示間日，下句明非犯。據本不服，理應成受；制須間日，為抑貪情。
【譯文】問答之中，因為還沒有構成「犯長」的過失，戒律規定受持不能成功，所以必須提出問答來決斷；回答之中，前半段解釋受法不成立的原因，後半段簡別其他種類的藥物。第二種過失，因為染著犯長而不成立，這個道理可以融會貫通。在第三種過失中，藥物的味道如果相通，在義理上就等同於共同儲蓄。《僧祇律》雖然是這樣說，但如果依照本宗的義理，在法理上應該能自然成立。在第四種過失中，首先引用戒律規定的作法。「一日」就是指第八天。「謂」字以下，顯露其深意。上一句指出必須間隔一天，下一句說明這並不算犯戒。按照原本沒有服用的情況，理應能夠受持成功；但戒律規定必須間隔一天，是為了壓制貪婪的心情。

【1307-0007】資持記/14b_下二#35
【原文】又心曾服食，八日成犯，後受相染；今由不服，故得間受。立法有以，故令準用。五中。正可者，藥恰盡也。雖無染犯，不許續加。結中。決上相續，須約同藥。下引《僧祇》，一體轉易；可證異味，不妨續受。自作中。第二然燈塗足，由非服食，義無加受。
【譯文】再者，若是曾經服食過，到了第八天該藥就會構成犯長之罪，其後新受的藥也會受到相染（而法不成）；現在由於並未服食，所以得以間隔一日後重新受持。立法的背後有其深意，所以才要求依準施行。在第五種過失中，「正可」的意思，是指藥物剛好用完。這時雖然沒有染污犯戒的情形，但律法不允許連續加受。在結尾這段中，決斷上面的連續受持，必須針對同一種藥物而言。下面引用《僧祇律》，藥物一旦本體改變；就可以證明換成不同的味道，並無礙於接續受持。在「自作」這一段中，第二種用來點燈或塗腳的情況，因為不是拿來服用的，在道理上就不需要加受。

【1307-0008】資持記/14b_下二#36
【原文】〔古云油以除風，塗足能履水，西竺多用。〕下指所出，義須依準。第三記識，用舍不定，故注示之。四中注釋展轉之義。油蜜不轉經煮不失，是以文中唯簡二酥。得自煮者，以生酥先熟，非變生故。二煮即上自他。
【譯文】（古代說用油塗腳可以祛除風寒，還能夠踏水行走，西印度地區經常使用。）下面指引其出處，在道理上必須依據奉行。第三種「記識」，採用或捨棄並不固定，所以註文特別予以說明。在自作四法中的第四法中，註文解釋了「展轉」的涵義。油和蜜不會變質，經過烹煮也不會失去受持力，所以鈔文中唯獨挑出生酥和熟酥這二酥（來說明展轉烹煮）。自己可以烹煮的原因，是因為生酥本來就是熟物，並不是把生食煮成熟食。所謂「二煮」，就是指上面提到的自己煮或請他人煮。
