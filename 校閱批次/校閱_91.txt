# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【91-0008】02_戒疏/04a_卷一下之二#94
【原文】【疏】彼疏釋云：「此間為『篇』，今依本義，立名『部』也。」故知梵本各有所由，翻經之家，以意商度，以「篇」譯之。何事紜紜，浪諍字也？故彼解云：「何故名『部』？有二義故：一、成就根本義；二、隨順根本義。」
【譯文】【疏文】義理疏文說：該論的註疏解釋道：「在此土通常稱為『篇』，現在依照梵文原本的意趣，安立名稱為『部』。」由此可知梵文原典各有其字源由來，翻譯經典的譯師，憑著自心意圖斟酌商討，才翻譯為「篇」字。後人何必紛紛擾擾，白白地為文字徒生爭執呢？所以該論疏解釋說：「為什麼稱為『部』？因為具備兩種義理：第一、具有能成就根本果罪的意義；第二、具有隨順根本果罪的意義。」

【91-0019】02_戒疏/04a_卷一下之二#105
【原文】【記】次科，會通中分二。初準文會異。言「遠方便」者，彼宗但立兩方便。動色為始，故云「遠」也。中蘭與吉，並對首懺，故云「名異」等。若論詞句，三、一實異，且就所對，故云「同」耳。「故」下，正引彼文。偷蘭三品，分對兩篇，上下各局，中品兩通。
【譯文】【記文】在第二小科「融會貫通」中分為兩部分。首先依循文典融會名相差異。所說的「遠方便」，是因為該宗只立兩種方便：以發動色身為起點，所以稱之為「遠」。中品偷蘭與突吉羅，都屬於對首懺悔，所以說「名雖有異，對人不殊」。若論懺悔的言詞文句，三語或一語其實有別，此處暫且就懺悔所對的對象而言，所以說「相同」。「故彼文中」以下，正式引述彼律文句：偷蘭遮三品分別對應於前兩篇，上品與下品各自侷限在一處，中品則通於兩篇。

【譯文】【疏文】義理疏文說：若是依照本部《四分律》，前兩篇未能成辦究竟的罪行，一概稱為「偷蘭遮」。至於判定罪責時，並未細分輕重品位。可以依照上述諸部律典，依如法原則來處置對治。詳細內容正如《刪補羯磨》以及相關《戒疏》、《事鈔》中所記載。

【91-0021】02_戒疏/04a_卷一下之二#107
【原文】【記】取舍中。初示《律》文。初篇廣解，皆云「成者波羅夷，不成者偷蘭遮」，僧殘亦爾。「可」下，取用《十誦》兩蘭，以替《了論》次吉，頗合今宗不成偷蘭之義。「廣」下，指略。《羯磨》及《疏》，即《懺法篇》。《事鈔》，即在《篇聚》及《持犯》中。
【譯文】【記文】在「取捨」之中。首先指出《四分律》的文義：第一篇廣解中都說「成辦者為波羅夷，不成者為偷蘭遮」，僧殘戒也是如此。「可依」以下，取用《十誦律》的兩種偷蘭遮，用來替代《明了論》的次吉羅，這十分契合本宗「不成究竟即為偷蘭遮」的宗旨。「廣如」以下，指引省略的文句。《羯磨》與《羯磨疏》指的是〈懺法篇〉；《事鈔》則指在〈篇聚名相〉與〈持犯方軌〉各門之中。

【91-0022】02_戒疏/04a_卷一下之二#108
【原文】【疏】三者，近方便。至彼人邊，或欲摩觸，身未交前，是偷蘭遮。為行婬故觸，不為戲樂故觸，所以不成僧殘。故此偷蘭，對僧懺也。
【譯文】【疏文】義理疏文說：第三種、近方便。已經走到對方身邊，或者企圖撫摩碰觸，在身體尚未實際交合之前，結為「偷蘭遮」。因為是為了行淫才去觸摸，並非純粹為了嬉戲取樂而觸摸，所以不構成僧殘罪。因此這個偷蘭遮罪，必須在大眾僧伽面前發露懺悔。

【91-0026】02_戒疏/04a_卷一下之二#112
【原文】【疏】前三方便，皆為成犯，故名「部」也。若根本未成，前三可懺；若已成就，則隨根本，悉不可懺。
【譯文】【疏文】義理疏文說：前三種方便罪，都是為了成辦最後的犯罪，所以名之為「部」。如果根本果罪尚未成辦，前三種方便罪都還可以懺悔消除；如果根本罪已經成就，則一切方便罪都隨順歸納入根本罪之中，全都無法懺悔出罪了。

【91-0027】02_戒疏/04a_卷一下之二#113
【原文】【記】結部義中。果由因克，是「成就」義；攬因歸果，即「隨順」義。以蘭、吉別聚，由此二義總歸初篇，同一部類。
【譯文】【記文】在「總結部義」中：究竟果罪是藉由前因克制而成辦，這就是「成就」的意思；攬取前因歸入果罪之中，這就是「隨順」的意思。因為偷蘭遮與突吉羅本屬於個別的罪聚，經由這兩層意義全都歸入第一篇，成為同一部類。

【91-0030】02_戒疏/04a_卷一下之二#116
【原文】【疏】若講至此，可引《鈔》、《疏》，相潤成宗。必觀時宜，廣略機變，不事誦文，彼此同惱。有人不解道理者，云：「為我盡底道。」余云：「底何可盡，至佛方知。」今且大略，識相奉持，勿乖正行，是則可矣。
【譯文】【疏文】義理疏文說：若是講述到了這裡，可以援引《事鈔》與《戒疏》的義理，相互潤澤滋益以成就本宗宗旨。講解時務必觀察時節因緣，或廣演或簡略隨機應變，切不可死板地背誦文字，致使彼此徒增煩惱苦悶。有人不明曉其中深理，便說：「請替我毫無保留、探究到底地講解。」我便回答說：「深底哪裡能探究得盡，這唯有證悟成佛時才能窮盡徹知。」如今姑且提綱挈領，只要能認識戒相並如法奉持，不背離清淨正行，這樣就可以了。

【91-0031】02_戒疏/04a_卷一下之二#117
【原文】【記】結告中。初令援引；「必」下，教隨宜；「有」下，杜非議。彼意嫌略，故持遮之。答云「至佛方知」者，即《智論》云：「智度大海，唯佛窮底。」、「今」下，示略意。

【91-0034】02_戒疏/04a_卷一下之二#120
【原文】【疏】所言「遠」者，遠資前境，借勢成犯，事絕情殊，名體全隔，故名為「遠」。及論成果，非不別因，即以此罪，名為「方便」。今於此過，位分有五。
【譯文】【疏文】義理疏文說：所謂「遠方便」，是指遠遠地資助牽引前面的事境，藉其情勢以成就後面的犯罪；兩件事截然不同、起心動念亦有差別，名稱與自體完全隔閡分離，所以稱之為「遠」。然而談到其最終成辦果罪，並非沒有這別異的起因，因此便將這前緣的罪過，也稱之為「方便」。現在就這類過失而言，品位劃分為五種。

【91-0035】02_戒疏/04a_卷一下之二#121
【原文】【記】遠方便中，通示「遠」義。彼謂果罪次第相因，名為「方便」。「非不別因」者，即下「近」中自有方便也。
【譯文】【記文】在「遠方便」中，通盤說明「遠」的定義。彼師認為前罪與後來的果罪次第相因，所以稱為「方便」。「非不別因」，指的是下文「近方便」中自然有其各自的方便罪。
