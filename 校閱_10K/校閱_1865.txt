# 校閱材料　第1865檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1865-0001】03_業疏/20a_卷四之三#9
【原文】就文分二：初明住法，後出界法
【譯文】就科文分為兩部分：首先說明安居的住法，隨後開出安居的結界之法。

【1865-0002】03_業疏/20a_卷四之三#10
【原文】初為五：初作法不同，二結時前後，三夏閏延促，四解結成不，五背前結後
【譯文】第一部分分為五門：一是作法不同，二是結夏時節的前後，三是夏期遇閏月的延長與縮減，四是解界與結界之成否（夏中解界結界對安居成否之影響），五是違背前面而結夏於後。

【1865-0003】03_業疏/20a_卷四之三#11
【原文】就初門中，住法有四，謂對首、心念、忘成及界也。相在文中，至彼消釋。又分為七，前三不分，就界為四，以園界兩所足有雙隻故也
【譯文】在第一門中，安居的住法有四種，即是對首、心念、忘成以及及界。其詳細事相載於律文中，到後文再作消解闡釋。又細分為七種：前三種不再細分，就「及界」細分為四種，因為僧園與結界兩處各有單獨或兼具的緣故。

【1865-0004】03_業疏/20a_卷四之三#12
【原文】安居五門初門列法中，初分四法，又下次開七法。及界中，園與界各有雙隻，故為四也
【譯文】在安居五門的第一門列述作法中，首先分為四種法，自「又」以下進一步開展為七種法。在「及界」之中，僧園與自然結界各有單屬與合屬，所以成為四種。

【1865-0005】03_業疏/20a_卷四之三#13
【原文】用前七法，下約三時，則二十一種。將此數法以約兩界（自然、作法），合四十二種。將此約人，人有五眾，則合二百一十種也
【譯文】運用前面這七種法，配對以下三時（前、中、後安居），就是二十一種。將這二十一種法配對兩處結界（自然界、作法界），合為四十二種。將這四十二種配對人物，人有出家五眾，總共便合為二百一十種。

【1865-0006】03_業疏/20a_卷四之三#14
【原文】配數中初科，約人五眾，一眾具四十二種，總合可知
【譯文】在配對數量計算的第一科中，按照出家五眾推算，每一眾各具四十二種，總合之數即可推知。

【1865-0007】03_業疏/20a_卷四之三#15
【原文】有人言：前之二法，既有聖教，可通三時。忘成及界，此之五法，作法開成，本無言說，故中安居所不開也。恐不及前，故損五利；恐不及後，一夏虗坐。有斯兩意，開於二日，中間不開。如此約數，則一百六十種。以前二法歷三時兩處及以五眾，則六十種；以後五法依前二時，則一百也
【譯文】有人說：前面的對首與心念二法，既然有聖教明文，可以通於三時。忘成以及及界這五種法，是透過特定因緣開許而成就，本來沒有宣告之言辭，所以中安居時並不開許。因為唯恐趕不上前安居，所以會受損失去五種利益；唯恐趕不上後安居，導致一夏虛度而坐。基於這兩種考慮，只開許在前安居與後安居的二日，中間時段並不開許。如果依此推算數量，就是一百六十種：以前面二法經歷三時、兩處結界以及五眾，就是六十種；以後面五法依據前後二時、兩處與五眾，就是一百種。

【1865-0008】03_業疏/20a_卷四之三#16
【原文】他義中初科，初示制開通局。如下歷數：二法歷三時成六，兩處每處有六為十二，一眾十二，故有六十；五法歷二時為十，兩界為二十，五眾成一百
【譯文】在引述他人之義的第一科中，首先指出制止與開許的通達與局限。如後文逐一推算數目：二種法經歷三時成為六種，配對自然與作法兩處結界，每處有六種合為十二種，一眾有十二種，所以五眾共有六十種；後五種法經歷前後二時成為十種，配對兩界為二十種，五眾合為一百種。

【1865-0009】03_業疏/20a_卷四之三#17
【原文】如此分相，據一人經多夏，一夏有多人故也
【譯文】像這樣分析事相，是依據一個人經歷多次夏季，以及一個夏季之中有多個不同情況之人的緣故。

【1865-0010】03_業疏/20a_卷四之三#18
【原文】總示中兩義，以顯歷數所以。一人多法不可同時，故約多夏多人始能具耳
【譯文】總括開示中包含兩種涵義，以顯明推算數目的因由：一個人所行的多種法不可能在同一時間具足，所以只有就多個夏期或多個人而言，才能全部具足這些數量。

【1865-0011】03_業疏/20a_卷四之三#19
【原文】因此前後，泛解有六
【譯文】因著前後結夏的意義，廣泛通釋有六門。

【1865-0012】03_業疏/20a_卷四之三#20
【原文】三泛解六門。準下初門即前次師之義，而下諸門今家所取，故因引之
【譯文】第三、泛解六門。準照下文的第一門，即是前面第二位法師的見解；而其餘各門是南山宗今家所採取的觀點，所以順便引述說明。

【1865-0013】03_業疏/20a_卷四之三#21
【原文】初開制前後者：對首、心念，此二制法，始終一月一日結之，兼閏得兩月一日。後之五法，如上是開，唯是前後兩夏各十六日，中間二十九日所不開也
【譯文】第一、開許與制止的前後：對首與心念這兩種教制常法，自始至終在一個月零一日之間皆可結夏，若逢閏月則有兩個月零一日。其餘五法，如前所述乃是因緣開許之法，只在前夏十六日與後夏十六日這兩天開許，中間的二十九天則不予開許。

【1865-0014】03_業疏/20a_卷四之三#22
【原文】初門且出彼解。準如初釋，則通三位
【譯文】第一門暫且列出那位論師的見解；若依照最初的解釋，則能通達於前、中、後三種時位。

【1865-0015】03_業疏/20a_卷四之三#23
【原文】二結罪前後者：從四月十六日至五月十五日為前，以不結者隨日不結吉羅；後五月十六日為後，若不結者尼提僧吉也
【譯文】第二、結罪的前後：從四月十六日起至五月十五日為前安居期，凡不結夏者，每過一日不結便犯一個突吉羅罪；隨後的五月十六日為後安居期，如果仍舊不結夏，則比丘尼犯波逸提罪，比丘僧犯突吉羅罪。

【1865-0016】03_業疏/20a_卷四之三#24
【原文】二中，尼提即單提中制，僧吉即隨結也
【譯文】在第二門中，「尼提」是指比丘尼犯波逸提，乃尼戒本單墮篇中的定制；「僧吉」是指比丘僧犯突吉羅，乃律中隨事所結之罪。

【1865-0017】03_業疏/20a_卷四之三#25
【原文】三有難前後者：《五百問》云：從夏初日至五月十五日，可日日結坐。若夏初有難不得結者，或五日、三日乃至一月，雖不結之，不失前坐。以難不結，非是故心。此名三十日坐，一日受歲。後坐夏人，唯得一日結；過七月十五日已有難者，可日日受歲，盡八月十五日。此名一日坐結，三十日受歲也
【譯文】第三、因難緣而分前後：《五百問經》說：從安居初日（四月十六日）起至五月十五日，每天都可以作法結夏安居。如果夏初遇到災難阻礙而不得結夏，或者耽擱了五天、三天乃至一個月，雖然未能及時結夏，但並不失去前安居的資格；因為是因災難阻隔而未能結夏，並非存心故意。這稱為「三十日安居，一日受歲」。後安居的人，只有一天可以結夏（五月十六日）；過了七月十五日之後如果遭遇災難，可以在其後的每一天受歲自恣，直到八月十五日為止。這稱為「一日結夏安居，三十日受歲」。

【1865-0018】03_業疏/20a_卷四之三#26
【原文】三中，《五百問》初明前難。以難緣故未暇加法，要心已定，故不失前坐。「一日受歲」，同是七月十五自恣故。「後」下次明後難，謂結後安居者，七月十五夏雖未滿，可隨前坐先自恣故
【譯文】在第三門中，《五百問經》首先說明前期的難緣：因為災難緣故無暇加行作法，但修道安居的志願期約已定，所以不失前安居的資格。「一日受歲」，是因為同樣都在七月十五日自恣受歲。自「後」以下說明後期的難緣，是指結後安居的人，七月十五日夏期雖然未滿，但可以隨順前安居者先受自恣的緣故。

【1865-0019】03_業疏/20a_卷四之三#27
【原文】四位約前後者初後兩夏各十六日中間安居二十九日僧祗云若在道行至安居日即於路側若於中道應受安居然後往趣所住之處應更安居道中不前安居一越至住不後安居二越據此前結安居若是不應後制但依教法知不成也往住後結可依受歲。
【譯文】第四、依時位約分前後：前夏與後夏各在十六日這一天，中間安居為二十九日。《摩訶僧祇律》說：如果行走在路上到了安居之日，應當在路旁或半途受持安居，然後再前往所要住的地方重新安居；在半途中不行前安居，是一重越法之過；到了住處又不行後安居，是二重越法之過。依此可知，前面的結夏安居如果不符合後文的教制，只要依照戒教之法，便知其安居不能成就；到了住處後依教結夏，才可依此受歲自恣。

【1865-0020】03_業疏/20a_卷四之三#28
【原文】四中，即三位結法，前後各一日，餘並名中。《僧祇》道行未至前所，至期必說，且為免過，不當結法
【譯文】在第四門中，即是指三種時位的結夏作法，前後各只有一日，其餘時間都稱為「中安居」。《摩訶僧祇律》中行路尚未到達預定住處，期限到了必須宣說表態，這暫且是為了免除犯過，並非正式的結夏作法。
