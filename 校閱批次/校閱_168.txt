# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【168-0006】資持記/14b_下二#38
【原文】二與餘別，必約藥分相雜。三中。體謂正藥，分即餘助。二法者，即手口二受。〔有云即體分二藥，屬法所收，故云二法。〕別來謂不同時買，別受謂隨得隨加。第四，總受中。注牒諸藥，此約藥味未和合者。必是成現丸散，單牒藥君；如云黃芪散阿魏丸等。若下，指例。
【譯文】第二點要與其他藥物區分，必定是針對不同藥物的成分互相雜揉的情況。在第三部分中，「體」是指主要藥物，「分」就是其餘的輔助藥物。「二法」的意思，就是指手受與口受兩種受法。（有人說是指藥體與藥分這兩種藥物，都屬於作法所含攝，故云二法。）「別來」是指不在同一個時間買來，「別受」是指隨得隨加。第四部分，在「總受」這一段中，註文詳細列舉各味藥物，這是針對藥味尚未調和在一起的情況。如果已經調配成現成的藥丸或藥散，就只要單純列出主要藥物的名稱；例如稱作「黃芪散」或「阿魏丸」等。「若」字以下，指引類推的標準。

【168-0009】02_戒疏/08b_卷二下之一#104
【原文】【記】第三句釋人中。初訓字。「俗」下，示所出。《釋名》，即劉熙撰，彼云「仁，忍也，好生惡殺，善惡含忍也」。「謂」下，釋義。天陽之氣，資始萬物，人有推愛及物，博施濟眾，合天之道，得人之正，故云「存育」等。「若」下，明「重言」之意。

【168-0010】02_戒疏/08b_卷二下之一#105
【原文】【疏】所言「命」者，謂此身報，假之維持，終於一形，壽所因本，故謂命根，以命持識，令依住故。如《雜心》中：「命根體者，非色非心。」良由眾生往業所剋，期在此形，連持不絕。故今死者，氣雖斷絕，隨有暖處，識在其中，即識住處，為命根攝。
【譯文】【疏文】所說的「命」，是指眾生這個果報的身軀，全憑藉著一股內在的力量加以維持牽繫，從出生一直延續到一生形體終結為止，這是一期壽命得以依託的根本因由，所以稱它為命根；正因為這股命根維繫著神識，使神識能夠安住停留在肉體之中。就像《雜阿毘曇心論》中所說：「命根的自體，既不屬於色法（物質），也不屬於心法（精神）。」這確實是由於眾生往昔所造的業力所感得的果報，限定在這一具肉身形體上，相續牽引執持而不斷絕。所以現在剛死的人，呼吸氣息雖然已經斷絕，但只要身體某處仍保有餘溫（暖氣），神識就依然停留在該處，那神識停留的地方，就依然屬於命根所含攝的範圍。

【168-0011】02_戒疏/08b_卷二下之一#106
【原文】【記】釋命中，初科為三。初釋名。壽無別體，即命短長，以為人壽，故云「因本」。能持於識，為壽之本，故得名「根」。「如」下，示體。以無形段，復與識異，故二「非」攝。「良」下，顯相，先敘業感，「故」下，正示命相。由煖、識、息三種相依，故有煖處，息識未捨，生分未絕，即為命矣。
【譯文】【記文】在解釋「命」字的一段中，第一小段分為三點。首先解釋名稱。人的壽命並沒有另外獨立的實體，只是依據命根維持的時間長短，來算作人的壽命，所以說是「因本」。命根能夠執持神識，作為整期壽命的根本依託，所以得以稱為「根」。從「如《雜心》」往下，指出其自體本質。因為命根既沒有形體物質（非色），又不同於知覺神識（非心），所以被判定在「色法、心法兩者皆非」（不相應行法）所攝受。從「良由」往下，顯露其生命相狀，先敘述這是由過去業力所感召；從「故今死者」往下，具體指出生命的相狀。由於體溫（暖）、神識（識）、呼吸（息）這三者是互相依存的，所以只要還有體溫的地方，呼吸與神識就尚未完全捨離，生命的成分就尚未斷絕，這就依然算是有命。

【168-0021】02_戒疏/08c_卷二下之一#5
【原文】【疏】所以言此二識者，亦為遮惡比丘念也：「若殺人者，可得重罪，如胎分中迦羅邏者，即既非人，故不名犯。」所以張網，通收初後。若有胎人，識所依止，隨有損害，無非極刑。即如《五分》，若人、似人，意亦可見。《四分》下文墮胎等相。
【譯文】【疏文】之所以要同時標明初識與後識這兩端，也是為了防堵惡意比丘生起投機的念頭，以為：「如果殺害活人，自當判處重罪；但若是胎兒階段的迦羅羅，既然還不算成形的人，殺了應當不算犯根本重罪。」因此律法如同布下羅網，將生命最初至最後的階段全面涵蓋。只要是有生命托胎的實體，作為神識依止之處，隨意予以損傷戕害，無一例外皆處以極刑。這就如同《五分律》中所說，無論是已成形的人或像人的胎形，立法本意由此可知。這也正是《四分律》下文所列舉墮胎等罪相的依據。
