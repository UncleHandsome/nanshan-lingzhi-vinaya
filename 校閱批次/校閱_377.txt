# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【377-0001】02_戒疏/20a_卷四下之二#57
【原文】【註】除杖、手、石，若以戶鑰、曲鈎、拂柄、香驢柄挃者，一切吉羅。尼同犯。不犯者，有病須椎打，若食咽須椎脊，若共語不聞而觸令聞。若睡時以身委他上，若來往經行時共相觸，若掃地時杖頭誤觸者，開。
【譯文】【註文】除了用杖、用手、用石頭之外，如果用門鑰、彎鈎、拂塵柄、香爐柄撞擊觸打他人者，全都犯突吉羅罪。比丘尼同犯此罪。不犯戒的情況：對方有病需要捶打醫治；或是進食哽噎需要拍捶脊背；或是共同談話對方聽不見而觸碰使其注意；或是睡眠時無意將身體倚靠在他人身上；或是來回經行時互相碰撞；或是掃地時掃帚手杖前端不慎誤觸者，皆開許不犯。

【377-0002】02_戒疏/20a_卷四下之二#58
【原文】【記】戒文，三句：一、人；二、瞋；三、打，結罪。辨相中，「挃」字，陟栗反，撞也。不犯諸相，並非嗔惱故也。
【譯文】【記文】戒本文句，共有三句：第一、能犯的人；第二、瞋恨的心態；第三、毆打的動作，判定結罪。辨析戒相之中，「挃」字，讀陟栗切，意思是撞擊。不犯戒的種種情形，全都是因為沒有瞋恨惱害之心的緣故。

【譯文】【疏文】揮手擊向比丘戒，為第七十九條。

【377-0005】02_戒疏/20a_卷四下之二#61
【原文】【記】七十九。戒名云「搏」，即俗所謂斫手也。下引《僧祇》，示相甚顯。
【譯文】【記文】第七十九條。戒名所說的「搏」，就是俗話所說的側手作刀砍擊的動作。後文引用《僧祇律》，所顯示的行相非常明顯。

【377-0006】02_戒疏/20a_卷四下之二#62
【原文】【疏】前是限分中制，打著方犯；此是深防中制，手擬便犯。
【譯文】【疏文】前一條戒是在有限範圍內制定，必須打著接觸身體才構成犯戒；這一條戒則是為了深層防微杜漸而制定，只要舉手比擬揮向對方，就構成犯戒。

【377-0007】02_戒疏/20a_卷四下之二#63
【原文】【記】釋中，初科。言「深防」者，為防前打，使無犯故。
【譯文】【記文】解釋之中，第一段科文。所謂「深層防範」，是為了防範前面那一條毆打之罪，讓人不敢犯戒的緣故。

【377-0008】02_戒疏/20a_卷四下之二#64
【原文】【疏】須定犯相。本為打非搏，搏但打家方便，吉羅。本為搏非打，動心即搏方便。
【譯文】【疏文】必須判定其犯相的本質。原本意圖是毆打而非僅僅比劃虛擊，那麼揮手比劃就只是毆打的前方便，結突吉羅罪。如果原本意圖就是揮手比劃虛擊而非真打，那麼動心舉手就是揮手虛擊的前方便。

【377-0009】02_戒疏/20a_卷四下之二#65
【原文】【記】次科。為打則搏為方便，打是根本。為搏則舉心為方便，搏是根本。
【譯文】【記文】第二段科文。若是為了毆打，則揮手比劃屬於方便，毆打著身才是根本罪。若是純粹為了揮手比劃，則起心動念屬於方便，舉手揮向對方就是根本罪。

【377-0010】02_戒疏/20a_卷四下之二#66
【原文】【疏】《僧祇》云：「以側掌為刀相，用擬於人，故號為搏。」《伽》云：「若舉手刀向眾多比丘，一一皆提。」
【譯文】【疏文】《僧祇律》說：「以手掌側邊作成刀的樣子，用來朝向他人比擬砍擊，所以稱為搏。」《毘尼摩得勒伽》說：「如果舉手作成手刀向眾多比丘揮擊，面對每一個人都要結一個波逸提罪。」

【377-0011】02_戒疏/20a_卷四下之二#67

【譯文】【記文】第三段科文。《僧祇律》的名稱與行相可以清楚看見。《毘尼摩得勒伽》（《伽論》）所說的「手刀」，就是以側掌當作刀。「面對每人皆結提罪」，是隨著所對的境緣各自結罪。

【377-0022】02_戒疏/20a_卷四下之二#78
【原文】【記】八十。大同殘中，唯所謗所犯為別，故但略指而已。今引釋之。制意者，《多論》云：「一、為護自行，令法久住；二、為止誹謗，令梵行者安樂修道，不妨正業，故制。」犯緣亦八：一、是比丘；二、作大比丘想；三、有瞋心；四、無根；五、乃至對一比丘前；六、以殘罪加謗；七、言了；八、聞知。戒本五句：二犯人；二、瞋恚；三、無根，注文指前殘中；四、謗相；五、結罪。辨相，比前可解。
【譯文】【記文】第八十條。大致上與僧殘篇中的誣謗戒相同，唯獨所誣謗的罪名與本條所犯的罪名較輕有所區別，所以此處只是略微提示而已。現在引申解釋如下。制戒意圖，《薩婆多論》說：「第一、為了保護自己的清淨修行，使正法長久住世；第二、為了止息誹謗，讓清淨修道者能安樂修行，不致妨礙道業，所以制定此戒。」犯戒條件也是八個：第一、能犯的是比丘；第二、認定對方是大比丘；第三、懷有瞋恨心；第四、毫無見、聞、疑的事實根據；第五、哪怕只是面對一位比丘宣說；第六、以僧殘罪強加誹謗；第七、言詞表達清晰明白；第八、對方聽聞且理解。戒本共有五句：第一、犯罪的人；第二、瞋恚的心態；第三、毫無根據，注文指示參照前面僧殘篇；第四、誣謗的行為態樣；第五、判定結罪。辨析戒相，比照前戒即可理解。

【原文】【疏】突入王宮戒八十一。
【譯文】【疏文】闖入王宮戒，為第八十一條。

【377-0025】02_戒疏/20a_卷四下之二#81
【原文】【疏】王者自在，情多奢縱，染樂不期，義須觀撿。今此比丘輙便突入，既相逼斥，彼此懷愧，深非所宜。又王宮豔逸，動亂凡心，容生染著，自壞亂道，過深故制。
【譯文】【疏文】國王握有至高權柄隨心所欲，心性大多驕奢放縱，在未預期的時刻沉浸於私密享樂，按理出家人必須審慎觀察檢點。現在這比丘隨意擅自闖入，既然造成雙方逼近喝斥，彼此都心懷慚愧尷尬，這極為不合適。再加上王宮中奢華艷麗，容易動搖凡夫的心意，極可能產生貪愛染著，從而損壞道心擾亂修行，過患極為深重，所以制定此戒。

【377-0026】02_戒疏/20a_卷四下之二#82
【原文】【記】八十一。「突入」，謂不告而入。制意有二。初約妨他釋。「義須觀撿」，謂比丘欲入，先須審察。「逼斥」，「斥」即訓逐，如緣起也。「又」下，次約損己釋。「豔」即華豔，「逸」即奢逸。凡愚所貴，故多「生著」。
【譯文】【記文】第八十一條。「闖入」，是指未經稟告通傳就擅自進入。制戒意圖有兩個層面。首先從妨礙他人的角度來解釋。「理應審慎觀察檢點」，是說比丘想要進入時，必須先詳加審視觀察。「逼近喝斥」，「斥」就是驅逐斥退的意思，如同戒律緣起所描述的情形。「又」以下，接著從損害自身的角度來解釋。「艷」就是華麗艷美，「逸」就是驕奢安逸。這是凡夫愚人所看重的，所以極容易「生起貪著」。

【377-0027】02_戒疏/20a_卷四下之二#83

【377-0037】02_戒疏/20a_卷四下之二#93
【原文】【疏】戒本六句：一、人；二、剎利；三、王未出；四、寶未藏，《律》中列寶而不顯相，如《多論》云「進御采女，令著寶衣，內身外現」，今此比丘突至此處；五、入宮門，深防而制，初入已結，何況見寶；六、結罪。
【譯文】【疏文】戒本文句共有六句：第一、能犯的人；第二、剎帝利階級；第三、國王尚未出寢殿；第四、珍寶尚未收藏妥善，《律藏》中雖列舉了種種珍寶卻未明言其實質意義，如同《薩婆多論》所說「侍奉進御的宮女，讓她們穿著薄透的寶物衣裳，使得肌體若隱若現」，現在這比丘卻驟然闖入此處；第五、跨入宮門，此處是為了深層防範而制定，剛一入門就已經結罪，更何況是親眼見到了珍寶與裸露；第六、判定結罪。

【377-0038】02_戒疏/20a_卷四下之二#94
【原文】【記】戒本。第二句，「剎利」王種，四姓之一。「水澆頭」者，譯語頗質，即灌頂王，如注所引。注中「婆羅門」等，雖非王姓，灌頂不殊，入亦同犯。三、「王未出」，謂未出寢宮。「女未還本處」，猶在王宮故。準本緣起，乃約寢宮，今但是王內庭，入門即結。四中，初點文暗，注中但列「眾寶」，不明未藏之意。「如」下，引示，謂采女侍寢，皆著輕踈寶衣，猶未收藏，以彰逼惱成犯過意。辨相中，除四輪王，餘諸小國之主，名「粟散王」，言其眾多不計數也。
【譯文】【記文】戒本。第二句，「剎帝利」王族階級，為古印度四種種姓之一。「水澆頭」，翻譯用語較為質樸直白，也就是灌頂加冕的國王，如同注文所引述。注文中說「婆羅門」等，雖然不是王族種姓，但灌頂立王的性質並無不同，擅入也是同樣犯戒。第三句「國王尚未出」，是指尚未走出寢宮。「宮女尚未返回原處」，也就是仍在寢宮內部之故。依照原始緣起，原本是指寢宮內殿，現在只要是國王的內庭，跨入門檻即結罪。第四句中，首先指出原文文意稍顯隱晦，注文中只列出「種種珍寶」，卻沒有闡明未收藏的真正意涵。「如」以下，引證說明，是指宮女侍寢時，都穿著輕薄透光的寶衣，尚未退下收藏，以此來彰顯闖入造成雙方窘迫驚擾而構成過失的深意。辨析戒相之中，除了四大轉輪聖王之外，其餘各個小國的君主，稱為「散粟王」，是形容其數量極多、無法計算。
