# 校閱材料　第460檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【460-0001】02_戒疏/05d_卷二上之一#102
【原文】【疏】五、心境者。有戒斯是。無有單心而犯戒者。有人云：「如不學等，可有境邪？」今解不然。同此學境，何得無邪？故光師云：「緣無定據，心相易流，境有美惡，心有濃淡。」或約心從境，如婬、酒戒；或制境從心，如盜、殺等；或以心境相應，方始成業。
【譯文】【疏文】第五、心念與境界的關係（心境）。每一條戒都是如此，絕對沒有單單憑藉一個心念就能構成犯戒的。有人說：「好比不學等罪，難道也有外在境界嗎？」現在解釋並非如此。面對這個應當修學的境界，怎麼會沒有境界呢？所以慧光律師說：「外緣沒有固定的標準，心的相貌容易隨緣流轉；境界有美好與醜惡，心念也有強烈與淡薄。」或者以心念順從境界來結罪，好比淫戒與酒戒；或者依境界順從心念來結罪，好比偷盜戒與殺生戒等；或者必須心念與境界完全相應，才算真正形成業道。

【460-0002】02_戒疏/05d_卷二上之一#103
【原文】【記】心境中，初明通義。「無單心犯」者，即如《母論》：「犯必託境，關心成業。」心不孤起，境無獨立，未有一法不由心、境，故言「通」也。下斥古解，彼謂不學之罪，起心即犯，不待造境。然不學有二：初起斷心，若頓若漸，竝對前境；又隨事無知，別結不學，亦即對境，但於學境，心有背耳。「故光師」下，次明別相。初總示差別。「緣」即是「境」。四句隔對，尋之可見。「或」下，別配戒相。文列三句。初句唯局淫、酒。二、三兩句，則通諸戒。上二即境想後四句，下一即是初句。
【譯文】【記文】在「心境」的科判中，首先說明通相的義理。「沒有單憑心念就能犯戒」，就如同《毘尼母論》所說：「犯戒必定要依託境界，結合心念才能成就罪業。」心不會無端孤立生起，境界也不會獨自成立，從來沒有一法不是由心念與境界共同構建的，所以稱為「通」。下文駁斥古德的見解：古人認為不學無知之罪，只要一起心動念就算違犯，不需等待接觸境界。然而不學有兩種情況：一是起初生起了拒絕修學的心，無論是一時頓起還是漸次生起，全都是面對著眼前的教戒境界；二是隨著具體事務而茫然無知，個別結判定為不學之罪，這同樣是面對具體境界，只是對於該學的境界，內心產生了違背罷了。自「故光師」以下，接著說明別相。首先總體揭示其差別，「緣」就是「境界」。四句境界與心念的交互對照，仔細尋索便可明瞭。自「或」以下，個別配對各項戒相，文中列出三句：第一句僅局限於淫戒與酒戒；第二與第三兩句則通於一切戒條；上面兩句即是境想句法中的後四句，下一句即是境想句法中的第一句。

【460-0006】02_戒疏/05d_卷二上之一#107
【原文】【疏】犯不自成，成由緣集。因藉萬差，要唯內外。如情道等為內，非情道等為外。就情中，食飲為內，衣服為外。如是例準。
【譯文】【疏文】犯戒的行為不會憑空自發形成，其形成完全是由於各種條件因緣匯聚。所依託的因緣千差萬別，綱領扼要來說不外乎內與外。例如有情眾生的身體器官等屬於「內」，非情眾生的器物環境等屬於「外」。若就在情識之中細分，飲食屬於「內」，衣服屬於「外」。其餘一切事物都可以此為例進行推定。

【460-0007】02_戒疏/05d_卷二上之一#108
【原文】【記】內外中，標釋可解。初明通者，一切諸戒，無出二境：性戒竝情，如七支等；遮多非情，掘地、房、酒等。「就」下，明別相。「衣」、「食」二種，計是非情，但隨身用，故判屬情。而約資用，以分內外，如「三十」、「九十」別相可知。
【譯文】【記文】在「內外」的科判中，標題與解釋很容易理解。首先說明通相的道理，一切戒條不出這兩種境界：性戒所緣的全部屬於有情，好比身三口四等罪；遮戒所緣的則多數屬於非情，好比掘地、造房、飲酒等。自「就」字以下說明別相。「衣服」與「飲食」這兩種，按本質來說雖是非情之物，但因為緊隨身體所用，所以判歸於有情一類；進而依據生活資助的用途來區分內外，如「三十捨墮」與「九十單墮」中的個別戒相便可由此了知。

【460-0008】02_戒疏/05d_卷二上之一#109

【460-0017】02_戒疏/05d_卷二上之一#118
【原文】【記】僧利中。初攝僧者。制戒治別，別聚名僧，即是以戒攝別入僧。次釋歡喜。云「半月」者，以說戒檢行，淨穢兩明，能令眾喜。三、釋安樂。舉後聖果，以顯因心。「適」即是悅，「神」即識心。
【譯文】【記文】在僧團利益的部分：首先「攝取於僧」，是指制定戒律來對治個別修行者，個別修行者匯聚起來就稱為僧團，這就是以戒法攝受個別僧眾融入僧團之中。其次解釋「歡喜」，之所以說是「半個月」，是因為透過誦戒來檢驗行持，使清淨者與染污者兩皆顯露，從而令僧眾心生歡喜。第三解釋「安樂」，是以未來的殊勝聖果，來顯發此時因地的心境。「適」就是愉悅，「神」就是指內在的神識心靈。

【460-0018】02_戒疏/05d_卷二上之一#119
【原文】【記】問：「與第二何異？」
【譯文】【記文】有人問：「這與第二個『歡喜』有什麼不同？」
