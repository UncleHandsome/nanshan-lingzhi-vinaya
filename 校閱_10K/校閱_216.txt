# 校閱材料　第216檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【216-0001】01_行事鈔/09c_卷下之一#39
【原文】十明雜分物法。若在私莊寺致死，或作僧使，在莊檢校而死。若有家人及比丘守者，重物入亡者本寺，輕物隨現分之；亦不得尼眾分也；縱令近僧來攝重物，亦不須與，以非佛正制。若亡者無住處，而隨有常住處，隨近通攝。若無比丘守掌，同白衣家法。《四分》：若比丘在無住處，白衣家死，彼有信心檀越，應掌錄此物；若有五眾，先來者應與；若無來者，應送與近處僧伽藍僧。準此文者，若比丘共尼同至，隨所同眾死，各自取之，不得共分此物；當部亦不須加法，直爾攝取，不同共住，閑豫加法也。重物如上量之，隨情遠近。若至白衣家，知有亡物，必須捉執，作屬己意，方成；雖見，不得。縱捉入手，而俗人自攝入己，此則屬俗已定，盜僧成就，亦不得反奪；當勸示之與僧，令無業道。《僧祇》：比丘持他衣行，衣主命過，便將衣別受，不與同界比丘，越。若作羯磨已，量影；恐客比丘來，應知在羯磨前後。律中：有比丘，無想，別眾分衣，不成。
【譯文】第十項「說明各類雜處死歿時的分配遺物之法（雜分物法）」。如果是在私家莊園或所屬支院中亡故，或者是充當僧團差使，在莊園巡視檢校之時亡故。若現場有莊園家丁僕從以及僧人留守掌管，重物歸入亡者原本所屬的本寺，輕物則隨同現場現前的僧眾分配；但絕不得讓比丘尼眾參與分配；縱使附近寺院的僧人前來收取重物，也不須給予，因為這不符合佛陀的正式律制。如果亡者居無定所，但隨其死處附近若有常住僧寺，則由距離最近的寺院一併統攝其遺物。如果現場沒有比丘留守掌管，則等同於在俗人（白衣）家中亡故的處置法則。《四分律》說：如果比丘居無定所，死在俗人家中，該處若有具足信心的施主檀越，應當代為保管並登記這批遺物；若有出家五眾，最先到來的就應當給予他；如果沒有出家人到來，應當送交給附近寺院的僧眾。依據這段律文，如果比丘與比丘尼同時到達該處，隨同亡者所屬之眾別（僧隨僧、尼隨尼）各自取得遺物，不得男女僧眾共同分配此物；當部所屬僧眾也不需要另行作羯磨加法，直接收取即可，這不同於平日寺院共住、從容安閒時須作加法的規定。重物的歸屬如前文衡量，隨情理判歸相應之寺院。出家人如果到了俗人家中，得知有亡僧遺物，必須親手執持掌管，心中生起「此物歸僧（或歸己）」的意念，法方告成立；如果只是眼睛看見而未親手執持，則不算取得。縱使已經親手拿到，但俗人強行奪回納入私囊，這就已經確定被俗人侵奪，世俗人盜取僧物之罪業即告成立，僧人也不得強行反奪；應當好言勸導開示他歸還給僧團，以免他造下深重的惡業道。《摩訶僧祇律》說：比丘攜帶他人的衣服出行，衣主在別處命終，持衣者便將該衣自行納受持用，不拿出來與同結界內的比丘分配，犯突吉羅（越濟）罪。如果作完羯磨法之後丈量日影；擔心會有外來客比丘到來，應當明察其到來是在羯磨法完成之前還是之後。律中記載：有比丘在不知界內另有僧眾聚集（無別眾之意圖）的情況下脫離大眾另自分衣，其分衣法亦不能成就。

【216-0002】01_行事鈔/09c_卷下之一#40
【原文】問：將亡人物出界分，成不？答：《四分》：若衣物難分，當唱令來某處某時分，若遣人來，若自來，應與分者得。諸部結犯，不云得成。《十誦》云：比丘寄衣鉢與尼者，應索取，比丘分之；尼寄比丘物亦爾。問：將亡人物入界，其內比丘不知，還將出界，得先見者分不？答：得受。由當界不知，分時同法故。
【譯文】提問：將亡僧遺物攜帶到結界之外去分配，分衣法能夠成就嗎？回答：《四分律》說：如果衣物在當地難以分配，應當向大眾唱告通知「請於某時到某處來分配」，若是派遣代表前來，或者親自前來，應當由前來參與分配的人獲得。其餘各部派律典對擅自攜出界外分衣者皆判定犯戒，不承認其分配能夠合法成就。《十誦律》說：比丘生前將衣鉢寄存在比丘尼處者，應當索取回來，由比丘僧眾分配；比丘尼寄存在比丘處的物品也是如此。提問：將亡僧遺物攜入某個結界之內，界內的比丘並不知情，隨後又將遺物帶出結界，最先見到的僧人能分得（受分）嗎？回答：可以接受分配。因為該界內的僧人並不知情，在界外分配時其法式仍然相符同法的緣故。

【216-0005】01_行事鈔/10a_卷下之二#3
【原文】報命支持，勿過於藥。藥名乃通，要分為四：言時藥者，從旦至中，聖教聽服，事順法應，不生罪累。言非時藥者，諸雜槳等，對病而設，時外開服，限分無違。七日藥者，約能就法，盡其分齊，從以日限，用療深益。盡壽藥者，勢力既微，故聽久服，方能除患；形有三種：一盡藥形，二盡病形，三盡報形。《明了論》云：有身必有病，雖少差損，後必重發，加其口法，任終而受。就此四中，五分明之：一明藥體，二明淨地處所，三護淨不同，四淨法差別，五二受有別。
【譯文】支持果報身之性命，沒有比藥物更切要的了。「藥」的名稱雖然通泛，但綱要分為四種：所謂「時藥」，從清晨到正午，聖教聽許服用；事相順理、教法相應，不生罪累。所謂「非時藥」，指各類雜槳〔註：原文作「槳」，疑為「漿」之訛字〕等，是針對疾病而設，正午之外開許服用，只要不違背限定的時間與分量即可。「七日藥」，是依據藥物效能而依法制定，窮盡其藥力期限，順應以七日為限，用以治療重病而獲深益。「盡壽藥」〔盡形壽藥〕，因其藥力較微弱，所以聽許長久服用，才能消除病患；其期限之「形」有三種：一是盡藥形（藥物未壞前），二是盡病形（疾病未癒前），三是盡報形（生命果報未盡前）。《律二十二明了論》說：只要有肉身就必定有疾病，雖然暫時稍有減損好轉，日後必定復發；只要施加對首受持的口法，便任隨壽命終盡皆可受用。在這四種藥物之中，分作五部分來闡明：第一、明藥體；第二、明淨地處所；第三、護淨不同；第四、淨法差別；第五、二受有別。
