# 校閱材料　第192檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【192-0001】02_戒疏/19a_卷四下之一#130
【原文】【記】戒本，辨相。犯中分二。初六塵示人者，《律》云：「色怖者，或作象、馬、鬼形等；聲怖者，或貝、鼓、啼聲等；香怖者，樹、葉、花、果香及臭氣等；味怖者，醋、甜、苦、澁令彼甞怖；觸怖者，熱、冷、重、輕、麤、細、滑、澁令觸怖；法怖者，語云『夢汝死』、『罷道』等。」、「結輕重」者，即知、不知也。次說六塵語人，即上六相，但說為別，「輕重」亦同。
【譯文】【記文】戒本條文，辨析行相。犯罪行相分為兩部分。起初用六塵外境示人嚇人者，《四分律》說：「用色境恐嚇，或是裝扮成大象、烈馬、厲鬼等恐怖形貌；用聲境恐嚇，或是吹海螺、擊戰鼓、發出淒厲哭嚎聲等；用香境恐嚇，是採集特定樹木、枝葉、花果的異香或是令人作嘔的惡臭等；用味境恐嚇，是用酸、甜、苦、澀等怪味讓對方嚐試而受驚恐；用觸境恐嚇，是以過度燥熱、冰冷、沉重、微輕、粗糙、細滑、滯澀的物件強加觸碰使人驚嚇；用法境恐嚇，是恫嚇對方說『我昨晚夢見你橫死』、『夢見你還俗破戒』等。」所謂「判定罪行輕重」，就是以對方是否知情受驚來論罪。其次（第二種）是用言語宣說六塵告知對方，也就是上述六種內容，只是改為純言語恐嚇，「輕重判準」也是依照知與不知來分別。

【192-0007】02_戒疏/19a_卷四下之一#136
【原文】【疏】欲界摶食，身多不淨，事須澡浴，增道生善。但皎潔過常，身形光澤，翫著色相，無心厭背，正違出離。故須限約半月一洗，減則致犯。
【譯文】【疏文】欲界眾生依靠分段固體食物維生，身體容易排泄積聚種種不淨，理應需要洗滌沐浴，以維持身心清爽進而增進道業、生長善法。然而沐浴過度頻繁求取潔白光淨，使身形呈現光滑潤澤，容易貪玩愛著自他色相肉體，內心將不再存有厭離背棄生死的心念，這正好徹底違背了求取解脫出離的初衷。所以必須限定約束半個月洗浴一次，若不足此期限而頻繁洗澡便會構成犯戒。

【192-0008】02_戒疏/19a_卷四下之一#137
【原文】【記】制意中。初敘開意。「摶食」亦名段食，由食此食，脂膩外流，積聚塵垢，故成「不淨」。「澡」、「沐」者，並洗濯之異言，如俗字書「濯頭曰沐」，今取通意，不局身、首。清身去患，故能「增道」；外無垢染，故能「生善」。「但」下，二、明制意。數洗有二過：一、「翫著色相」，即樂世也；二、「無心厭背」，即違道也。
【譯文】【記文】制戒用意中。起初敘述開許沐浴的深意。「摶食」也稱為段食，由於攝取這種粗重食物，體內油脂膏汗不斷向外滲流，積聚在體表成為塵垢，所以導致身體「多不淨」。「澡」與「沐」，都是清洗濯除的不同用語，如同世俗字書所言「洗頭稱為沐」，如今律宗取其廣義通指，並不局限在洗頭或洗身。洗淨身軀祛除疾病隱患，所以能夠「增長修道」；外表去除垢濁染污，所以能夠「生長善法」。從「然而」以下，第二步說明制戒設限的用意。頻繁洗浴有兩種深重過患：第一、「貪玩愛著色相肉體」，這是貪戀世俗享樂的表現；第二、「內心無意厭離背棄生死」，這是完全違背解脫正道的。

【192-0015】02_戒疏/19a_卷四下之一#144
【原文】【疏】戒本四句。一、人。二、半月一洗，不得過。若著文相，出半月外是犯。今據減犯，何意言「過」？以佛制戒，半月一浴，今減數受，過於聖制，故云「過」。「過」是違越教相之言也。三、結罪。四、開緣。

【譯文】【疏文】五個條件具足便成犯：一、對象是畜生；二、心中作畜生的想法；三、有殺害的心；四、生起殺害的行動（方便）；五、性命斷絕。
