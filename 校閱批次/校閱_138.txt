# 校閱材料　第138檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【138-0001】02_戒疏/03a_卷一下之一#102
【原文】【疏】注中「行根、面首」，此歎木叉生善相也。由戒能生成萬「行」，喻若於「根」；如《經》云「若無戒者，諸善不生」，即其證也。又如《論》云「戒為眾善之根，生善中勝，無過斯法」，喻同「面首」也。
【譯文】【疏文】注釋中所說的「行根、面首」，這是讚歎波羅提木叉能夠滋生善法的功德相貌。由於戒律能夠滋潤生成萬種德行，所以用「樹根」來作比喻；如同經中說「如果不持戒，一切善法皆不能生長」，這就是明證。又如同論典所說「戒律是一切善法的根本，在一切滋生善法的功能中最為殊勝，沒有任何法門能超過它」，所以用「面首頭面」來作尊貴的比喻。

【138-0002】02_戒疏/03a_卷一下之一#103
【原文】【記】生善中二喻，「根」喻出生，「面首」喻尊勝。初總判，「由」下，別釋。初據《遺教》，但合「根」喻。「又」下，次引《多論》，雙合二喻。「根」義同上。「首」居五體之尊，戒為萬善中勝故也。
【譯文】【記文】在滋生善法中包含兩個比喻，「根」比喻能夠滋生萬行，「面首」比喻最為尊貴殊勝。首先是整體判定，「由於」以下是逐一解釋。起初依據《佛遺教經》，只吻合了「根」的比喻。「又如同」以下進一步引證《薩婆多論》，同時融會貫通了這兩個比喻。「根」的涵義與上文相同。「首」位居全身五體的最上方最尊榮之處，象徵戒律是一切善法中最為殊勝無比的緣故。

【138-0003】02_戒疏/03a_卷一下之一#104
【原文】【註】「集眾善法，三昧成就。」
【譯文】【註文】「匯集一切眾善之法，成就三昧正定。」

【138-0004】02_戒疏/03a_卷一下之一#105
【原文】【疏】注中「集眾善法」者，能會正慧也；「三昧成就」者，能明正定也。此之兩行，並藉戒因，成上「根」義。如《經》云「依因此戒，得生定慧」也。
【譯文】【疏文】注釋中所說「集眾善法」，是指能契合開發真實正慧；「三昧成就」，是指能夠顯發成就真實正定。定慧這兩種修行，完全要憑藉持戒為前因，才能圓滿成就上面所說的「樹根」涵義。正如經中說「依賴並憑藉這項淨戒，才能生長禪定與智慧」。

【138-0005】02_戒疏/03a_卷一下之一#106
【原文】【記】三中。初別釋二學。「集善配慧」者，歷諸道品，無非觀慧。「三昧」者，亦言三摩提，此云「等持」，亦云「正定」。「此」下，總顯戒功，釋上「能會」、「能明」之語。已上三引經文，並是《遺教》。
【譯文】【記文】在第三項說明中。首先個別解釋定慧二學。「集善對配智慧」，是因為歷涉各種三十七道品，無一不是清淨觀照的智慧。「三昧」也稱作三摩提，漢語翻譯為「等持」，也翻譯為「正定」。「這兩種」以下總括顯耀戒律的強大功效，以解釋上面的「能契合」與「能顯發」的文句。以上三度引用的經文，全都是出自《佛遺教經》。

【138-0006】02_戒疏/03a_卷一下之一#107
【原文】【疏】上來歎木叉惡滅善生，深有殊功。次歎木叉發引群心，能成法軌。
【譯文】【疏文】上面是讚歎波羅提木叉能使惡業滅除、善法增長，具有極其深厚殊勝的功德。接下來讚歎波羅提木叉能啟發導引大眾的修道真心，建立起行持的準則法軌。

【138-0007】02_戒疏/03a_卷一下之一#108
【原文】【記】四中，初科。上是歎行，即結前也。「次」下歎教，即生後也。以教相條別，持犯揩定，能使行人舉動有儀，故云「能成」等。
【譯文】【記文】在第四項說明中，這是第一小節。上面是讚歎修行的行持，屬於總結前文。「接下來」以下讚歎教法，屬於引導後文。因為教法儀相條理分明，持戒與犯戒規範界定清晰，能使修行人一舉一動皆有莊嚴法度，所以說「能建立」等語。

【138-0008】02_戒疏/03a_卷一下之一#109
【原文】【註】「當結，當說，當發起，演布開現，反覆分別故也。」
【譯文】【註文】「應當結治，應當宣說，應當發起，廣泛演說陳布顯現，反覆周詳地區別辨明。」

【138-0009】02_戒疏/03a_卷一下之一#110
【原文】【疏】言「當結」者，若於法有違，覆過顯淨，當如法治。治在說後，故言「當」也。交今未唱，望後許陳，言「當說」也。八段序分，與正宗為興致之由，言「發起」也。
【譯文】【疏文】所謂「應當結治」，是指如果對戒法有所違犯，隱匿過失而假稱清淨，就應當依法加以懲處治罪。但治罪是在宣說戒文之後，所以說「應當」。當下尚未正式宣唱，指望稍後才能陳述，所以說「應當宣說」。八段序分，是開啟正宗本分戒文的起端緣由，所以說「發起」。

【138-0010】02_戒疏/03a_卷一下之一#111
【原文】【記】三分解中。初釋「當結」，即默妄罪。「當」，猶將也。次釋「當說」，即下序文召令懺露。「交」，猶對也。三釋「當發起」。「八段」即序八章。
【譯文】【記文】在三分科解中。首先解釋「應當制立」，就是指默然妄語的罪責。「當」就像將要的意思。其次解釋「應當宣說」，就是指下文序文中召喚眾人出面發露懺悔。「交」如同當面、眼前的意思。第三是解釋「應當發起」。「八段」就是指戒序中的八個章節。

【138-0015】02_戒疏/03a_卷一下之一#116
【原文】【疏】廣教流通，篇別重舉。恐有理墜，罔冐將來，故云「反覆分別」也。
【譯文】【疏文】廣博的教法為了流布傳承，每一篇各自分門別類重複提問宣告。唯恐義理沉沒遺失，蒙蔽誤導了未來的行者，所以說「反覆周詳地區別辨明」。

【138-0016】02_戒疏/03a_卷一下之一#117
【原文】【記】流通中。初二句指文。「篇別重舉」，謂牒前已說，即是反覆也。「恐」下，示意。誦有遺漏，則是「沉墜」。誤於後傳，故言「罔冐」。
【譯文】【記文】在流通分中。前面兩句指示經文。「每一篇重複提問宣告」，是指再次提說前面已說過的戒相，這就是反覆叮嚀。「唯恐」以下顯露其用意。誦持若有遺漏，就是戒法「沉沒廢墜」。若是誤導了後世的傳承，所以稱作「蒙蔽誤導」。

【138-0017】02_戒疏/03a_卷一下之一#118
【原文】【疏】有人云：「八篇正宗，各有三致，何得通收廣教？如初篇中『諸大德四棄』即『當發起』；中開四相，列坐齊聞，即『布現』；後結三問，重條前章，即『反覆分別』。並是聖言引用，何得不依！」
【譯文】【疏文】有人說：「八篇正宗分各自具有這三種起承轉合，怎能通用來總括整部廣博教法呢？好比初篇中『諸大德四棄法』就是『應當發起』；中間開展四條罪相、列坐齊聽，就是『陳布顯現』；最後結尾三度審問、重新覆述前章，就是『反覆區別』。這些全都是聖人言教所明文引用的，怎能不予遵循！」

【138-0018】02_戒疏/03a_卷一下之一#119
【原文】【記】他解中。初立義指斥。「如」下，舉初篇別配。此則唯就正宗明之。然前列三當，此師但舉發起一義，餘二文略，義必通含。「並」下二句，似是他師結責之詞，又如疏家取用之語。上文配釋，全據本經，故云「並是聖言」也。

【138-0025】02_戒疏/03a_卷一下之一#126
【原文】【疏】又解云：「『同羯磨』者，明說正戒，行淨者同。自餘過犯不足數者，不同羯磨，不須集也。言『應與欲』者，謂此行教，不可自輕。大急要緣，事不獲已，方開與欲；自餘輕小，則不須也。且如病緣，重者輿來，少者僧就，可以知也。言『應訶』者，謂四羯磨、諸雜治人，行法在身，無容秉法，身雖足數，口不陳非故也。若斯陶練，方得實人，可不然也！」

【138-0026】02_戒疏/03a_卷一下之一#127
【原文】【記】佗解中三節，並約揀眾。一、簡足數。「過犯」謂三舉二滅人，更兼尼等四眾，瘂、聾、睡、狂等人。二、簡欲緣。「大急」即三寶、疾病等。三、簡合訶。「四羯磨」：一、訶責，二、擯出，三、依止，四、遮不至白衣家。此四，《律》名「得滿不得訶」。「諸雜治」者，即收行覆藏等人。竝由奪其智能，不得訶法；必非此等，方名「應訶」。「若」下，總結。「陶練」，即是揀擇。「實人」，謂合教者。

【138-0045】02_戒疏/03a_卷一下之一#146
【原文】【疏】注中正心思擇，名「端意」也；一心無倒，名「專聽」也。
【譯文】【疏文】注釋中所說端正心意並詳細思辨抉擇，稱為「端意」；一心不亂毫無顛倒散亂，稱為「專聽」。

【138-0046】02_戒疏/03a_卷一下之一#147
【原文】【記】釋注中。上簡邪思，下簡亂想。
【譯文】【記文】在解釋注釋中。上面是簡別去除偏邪的思緒，下面是簡別去除雜亂的妄想。

【138-0047】02_戒疏/03a_卷一下之一#148
【原文】【律】若自知有犯者，即應自懺悔。
【譯文】【律文】如果自己知道犯了戒，就應當自行懺悔。

【138-0048】02_戒疏/03a_卷一下之一#149
【原文】【疏】四、「自知有犯」者，以說戒本意，唯在除犯；聞而即行，便同上起，故文云「即應懺悔」者是也。
【譯文】【疏文】第四段「自己知道有違犯」，是因為宣說戒律的本來意圖，完全在於消除罪犯；一聽聞戒相就應當立即付諸實行，便如同罪業翻轉、善法向上生起，所以經文中說「就應當立即懺悔」。
