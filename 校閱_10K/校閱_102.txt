# 校閱材料　第102檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【102-0001】01_行事鈔/05c_卷中之一#20
【原文】三明有盜心。然此一門，實德之人未免。但世盜由心結，不望境之是非。故《僧祇》：寺主好心互用三寶物，是盜波羅夷，謂愚癡犯也。《四分》亦云：我說此人愚癡波羅夷。理既難知，故具抄示。《十誦》六種盜心：謂苦切取，輕慢取，以他名字取，觝突取，受寄取，出息取；除出息一種，餘並結重。《摩得伽》三種劫心：強奪取，耎語取，施已還取也。《五分》有四：一以諂心，曲心，瞋心，恐怖心而取他物，即是盜心。《四分》十種賊心：一黑闇心。謂癡心愚教，生可學迷，隨作結重；《僧祇》寺主即是其事。二邪心者。謂貪心規利，邪命說法，以財自壅。三曲戾心者，即瞋心也。與少嫌恨，假瞋得財；或虛示威怒，意存財利，得物犯重。四恐怯心。或以迫喝，或說法怖取，或自懷疑怖，而取財也。五常有盜他物心，恒懷規奪也。六者決定取。內心籌慮，方便已成，因必克果，動物成犯。七寄物取。或全觝突，或以少還他。八恐怯取。謂示身口相，畏敬故與物也。九見便取。伺求他慢，因利求利也。十倚託取。或倚名聞威德，或以名字方便也；或依親友強力者，謂假他威勢而取也；或以言辭辯說者，託於論端，浮華引接，令前異望，而取財利。言誑惑而取者，非法言法，法言非法；但規前利，幻惑群情。以此諸文，證知心業，其相略顯，足得垣牆，防擬妄境。
【譯文】三明有盜心。然而這一門，即使是有真實德行的人有時也未能免除。只因世間的盜罪是由內心造作結成的，而不單單看外在境界的對錯。所以《僧祇律》說：寺主出於好心相互調用三寶之物，即構成盜戒的波羅夷，這稱作愚癡犯戒。《四分律》也說：我說這種人是愚癡波羅夷。義理既然如此難以明了，所以具體抄錄明示。《十誦律》列出六種盜心：即苦切逼迫而取、輕慢強奪而取、假冒他人名字而取、抵賴蠻橫而取、接受寄託侵吞而取、放貸生息而取；除了放貸取息這一種之外，其餘五種皆結為重罪。《摩得伽論》列出三種搶劫之心：強力強奪而取、軟言誘哄而取、布施之後反悔強行索回。《五分律》列出四種：以諂媚心、歪曲心、瞋恚心、恐怖威脅心而取他人之物，即是盜心。《四分律》列出十種賊心：第一是黑闇心。是指愚癡之心對教理昏昧，於應當修學的戒律生起迷執，隨其所作結重罪；《僧祇律》中的寺主即是此類事情。第二是邪心。是指貪心謀求名利，以邪命說法，用不義資財充塞自我。第三是曲戾心，即瞋恚心。對方給得微薄便心生嫌恨，藉瞋怒索取錢財；或者虛張聲勢示現威怒，意圖謀取財利，取得物品即犯重罪。第四是恐怯心。或者以言語逼迫威嚇，或者藉說法恐嚇取財，或者自己懷抱疑懼恐懼而奪取資財。第五是常懷盜取他人財物之心，恆常心懷謀奪。第六是決定取。內心審思籌劃，作案手段（方便）已經完成，其因必定克取其果，動搖他人財物即構成犯戒。第七是寄物取。或者完全賴帳抵賴，或者以少數歸還他人而侵吞大半。第八是恐怯取。是指現出身相、口相，令對方因畏懼敬畏而獻出物品。第九是見便取。伺察他人的疏忽懈怠，趁火打劫因利求利。第十是倚託取。或者倚仗名聞威德，或者假藉他人名字施設方便；或者依附親友的強大勢力，假託他人威勢而取財；或者憑藉言辭辯才，託辭於議論端緒，浮華引誘接引，令對方產生錯誤指望，從而謀取財利。所謂欺誑迷惑而取物者，將非正法說成正法，將正法說成非正法；只是一心圖謀眼前的財利，迷惑擾亂大眾的情思。以此諸部經律文句，可以證知內心的造業，其相狀大略顯明，足可作為堅固的圍牆，以防範對治虛妄境界的造罪。

【102-0002】01_行事鈔/05c_卷中之一#21
【原文】四重物。謂五錢，若直五錢，即餘雜物。《薩婆多》問曰：盜五錢成重，是何等之錢？答有三解：初云，依彼王舍國法用何等錢，準彼錢為限。二云，隨有佛法處用何等錢，即以為限。三又云，佛依王舍國盜五錢得死罪，依而結戒；今隨有佛法處，依國盜幾物斷死，即以為限。雖有三釋，論師以後義應是。然五錢之義，律論互釋不同；判罪宜通，攝護須急；故律云：下至草葉不盜。今諸師盛行，多依《十誦》。彼云：盜五錢者，古大銅錢得重；若盜小錢，八十文。隨其盜處，所用五錢，入重。《僧祇》：王無定法，斷盜不定；當取瓶沙古法，四錢三角結重。《四分》但云五錢，準此，廢上律論，以後為勝；縱四錢三角，《善見》解之，亦同五錢。《善見》云：若堈中盜寶，內手取已，出離堈口，得夷。又解：但離處得夷，未出堈口。法師曰：於戒律中，宜應從急。又觀五事，處時新故等，是名律師。以此文證，五錢為允。
【譯文】四重物。是指滿五錢，或者價值滿五錢的其餘各色雜物。《薩婆多毘尼毘婆沙》問道：盜取五錢構成重罪，究竟是指何種錢幣？答有三種解釋：第一種說，依據當年王舍國的法律使用何種錢幣，即依準該錢幣為限度。第二種說，隨佛法流傳的所在地使用何種錢幣，即以此地的錢幣為限度。第三種又說，佛陀是依據王舍國法令盜滿五錢即處死罪，依循世法而制定戒律；如今隨著佛法流傳的處所，依據該國法律盜取多少財物判處死刑，即以此數額為限度。雖然有此三種解釋，論師認為應當以後一種義理為正確。然而五錢的義理，各部律論互相解釋並不相同；判決罪名應當通達圓融，但攝受防護戒體必須急切謹慎；所以律中說：下至微細草葉亦不可偷盜。如今諸師廣為盛行的見解，大多依循《十誦律》。該律說：盜滿五錢者，是指古代的大銅錢即得重罪；若是盜取小錢，須滿八十文。［今正判定：］隨其盜取之地所通用的五錢，即可入重罪。《僧祇律》說：國王的法令沒有固定之規，判斷盜罪數額不定；應當依取頻婆娑羅王古代的舊法，盜滿四錢三角即結為重罪。《四分律》中僅說滿五錢，依此而言，應當廢除上述雜說律論，而以後出的明文為優勝；縱使是四錢三角，《善見論》解釋它，也是同於五錢。《善見論》說：若在甕中盜取寶物，伸手入甕取寶之後，拿出手離開甕口，即得波羅夷重罪。另一種解釋說：只要移動寶物離開原地即得波羅夷，不必拿出甕口。律師說：在戒律行持中，應當從嚴從急。又應當觀察處所、時節、新品或舊品等五事，這才能稱得上是律師。以此文句為證明，以五錢為判定標準最為允當。
