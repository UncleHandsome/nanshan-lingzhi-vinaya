# 校閱材料　第960檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【960-0001】資持記/02f_上一下#22
【原文】綱要者，即初釋文，是羯磨大體〔不必強分綱緣〕。通塞者，即後料簡，示文義差別〔不必局指一科〕。若下，示妄謂。然下，明非處。上二句是縱，下二句是奪。言知處者，綱定不成，緣通成否。未可一概，故云不得等。〔禮云無雷同，注云雷之發聲，物無不同時應者。
【譯文】所謂「綱要」，就是最先開始解釋文句的內容，那是羯磨的大體架構〔不一定非要強行分割綱領與緣由〕。所謂「通塞」，就是後面進行甄別分析的內容，用以顯示文字與義理的差別〔不一定局限指定於單一科判〕。下文「倘若（若）」字以下，指出了虛妄錯謬的看法。下文「然而（然）」字以下，說明不合法之處。最上面的兩句是姑且承認縱容，最下面的兩句則是依理破斥奪回。所謂「知道處所（知處）」，綱領若有錯則必定不能成就，細部緣由若有出入則通融於成辦與否之間。不能一概而論，所以才說「不得」等等。〔《禮記》說不要隨聲附和如雷同，注解說：雷聲一發，世間萬物沒有不隨之同時響應的。〕

【960-0002】資持記/02f_上一下#23
【原文】斥執文中，初二句總示。或下，別顯，初斥連誦結略。諸白四法，翻譯省文，故安此語；不當誦之。或下，二斥專執詞句。初句如律覆藏法，但云某甲犯僧殘覆藏，僧今與某甲隨覆藏日羯磨；然前犯有差別，覆日或多少；若依律誦，則不稱前事。〔〈懺篇〉云：依鈔作法得成；若準律文，依古羯磨，即須改張，不可謹誦是也。
【譯文】在斥責偏執文字（斥執文）的段落中，最前面的兩句作了總括提示。下文「或者（或）」字以下，分別加以顯發，首先斥責連續誦讀結尾省略標記的錯誤。在各種白四羯磨法中，翻譯時為了節省篇幅文字，所以安置了「略」這類提示字；在正式作法時絕不應當把它唸出來。下文「或者」字以下，第二點是斥責死板專執固定詞句的錯誤。第一句例如律藏中的覆藏法，原文只說某人犯了僧殘罪而加以隱瞞，僧團現在為某人舉行隨順覆藏日數的羯磨；然而當初所犯的罪名各有差別，掩蓋隱瞞的天數也或多或少；如果完全照著律藏原文死板唸誦，就無法與眼前的事實相稱。〔〈懺罪篇〉說：依照《行事鈔》的方法作法便能成就；若依照律藏原文，遵循古代的羯磨，就必須適度修改變通，絕不可拘謹死誦，指的就是這種情況。〕

【960-0003】資持記/02f_上一下#24
【原文】次句如賞勞法備牒六物，物缺須改；今亦依誦〔下注云隨有言之是也〕。言俱有者，如受日法，牒佛法僧緣，連書半月一月；文事雖備，不合俱牒〔下云不得雙誦半月是也〕。俱無如結有場大界法，律無文事，不復增加〔下云須加內外相內是也〕。亦可如呵責法，文據鬪諍，必有餘犯，不能隨改。
【譯文】下一句例如獎賞勞苦之法，原文完整列載了六種物品，如果當場缺少某些物品就必須加以修改；現在有些人卻依然照本全宣誦讀〔下文註解說應當「隨著實際擁有的物品而宣說」，指的就是這個道理〕。所謂「兼具兩者（俱有）」，例如受日法中，列載了為佛法僧三寶的事緣，文字上連續書寫半個月或一個月；雖然文字與事緣都已備載，但絕不可以在宣白時把兩者全都唸出來〔下文說「不得同時雙誦半個月與一個月」，指的就是這個道理〕。所謂「兩者皆無（俱無）」，例如結集具有戒場的大界之法，律藏原文中沒有相應的事項文字，有些人就不再額外增加詞句〔下文說「必須額外加上內外相標之內」，指的就是這個道理〕。或者也可以比如呵責法，原文的依據是爭吵鬥諍，如果犯人實際上涉及其他罪行，卻不能隨之變更修改。

【960-0004】資持記/02f_上一下#25
【原文】〔下云及論當時，未必如文。〕致下，明知法者呵，莫知所措。白讀中，如後問決。初敘非法。豈下，彰過。伊即訓是，責即是罪。不學無知，非法罪外加之。斥師心中，初句示人。轉弄謂非智強智，雖非愚塞，復是狂簡。觀下，示彼行事，初句明乍觀似是。而下，示再考還非，初明人事兩非。
【譯文】〔下文說「等到真正論及當時的情境，未必完全如同書面文字」。〕下文「致使（致）」字以下，當深知戒法的人出言呵責時，主事者竟然不知所措。在看著本子宣讀（白讀）的段落中，就如同後面的問答決斷一樣。首先敘述其非法的狀況。下文「難道（豈）」字以下，彰顯其過失所在。「伊」字的意思就是指「這」，「責」字指的就是獲罪。因為不肯學習而盲目無知，這是在行事非法罪名之外額外增加的罪過。在斥責主事者自以為是（斥師心）的段落中，第一句指出了這種人。所謂「轉弄」，是指本非明智之人卻硬要賣弄聰明，雖然算不上極度愚笨閉塞，卻也是狂妄自大且失之粗疏。下文「觀察（觀）」字以下，指出了他們的具體行事，第一句說明猛然一看似乎合乎規矩。下文「然而（而）」字以下，說明若是再次審查考驗，終究還是屬於非法，首先說明了人員與事項這兩方面的過失。

【960-0005】資持記/02f_上一下#26
【原文】謂人迷足別，事昧虛實。夢中觀海而況逾之，迷可知矣。量下，明法非。雖不守文句，而自裁過甚。照下，總結上非，違教結罪。結誥中，初二句正勸。加事不成，自他兩損；過非輕細，故令極誡。必須親學，方免諸過。若下，明選人。上座者，如《五分》說，即上無人。雖居眾首，必取解法；
【譯文】這意思是說主事者在人員上分不清足數還是別眾，在事項上辨不明虛妄還是真實。就像在夢境之中觀看大海，何況現實情況比這還要嚴重，其昏沉迷惑便可想而知了。下文「衡量（量）」字以下，說明儀軌本身的非法。他們雖然沒有死板守著既有文句，自己任意裁奪修改卻過於嚴重。下文「鑑照（照）」字以下，總結上述所有的非法過失，凡是違背佛教規制的都要結獲罪名。在總結告誡（結誥）的段落中，最前面的兩句作了正式勸誡。施加法事（羯磨）不能成就，對自己和對他人都是嚴重的損害；這類過失絕非輕微細小，所以令人必須極為警惕戒懼。必須親自依止明師認真學習，才能免除各種過失。下文「倘若（若）」字以下，說明挑選主持人員的標準。所謂上座，如同《五分律》中所說，就是指僧團中地位最高、其上已無他人之人。雖然位居僧團的首座，也必定要選取通達戒法的人；

【960-0006】資持記/02f_上一下#27
【原文】高臘無知，何足算也。故下，引證。律列四人；上座次座，約位簡人；誦律不誦，約法簡人。文闕第四。言持律者，即是第三；疏云：非謂誦文，必兼識義。四不誦者，疏云：雖不連文累紙，而曉達成否。又云：《四分》總列，竝據有能；應預未閑，亦開學悔。已下，遮濫。可知。正釋中。所以唯約受說者。
【譯文】若是只有戒臘年歲很高卻無知昏昧，又有什麼值得依憑選取的呢？因此下文引證律典為據。律藏中列出了四種人：上座與次座，是根據位階身分來挑選人員；通誦律藏與不誦律藏，則是根據對戒法的熟悉度來挑選人員。《行事鈔》文中欠缺了第四種人。文中所說「持律者」，指的就是第三種人；《羯磨疏》說：這並不是單指死背文句，還必定要同時深刻領會其中的義理。第四種「不誦律者」，《羯磨疏》說：雖然沒有連篇累牘地背誦大量經卷，卻非常清楚明白羯磨能否順利成就。又說：《四分律》總括列出這些人，全都是根據具有實際能力者而言；對於理應預先知曉卻尚未熟練的人，也開許讓他們學習並懺悔補過。下文「已」字以下，是用來防範冒名濫竽充數。其餘內容可以明白。在正式解釋（正釋）的段落中。之所以只拿受戒法與說戒法作為範例。

【960-0007】資持記/02f_上一下#28
【原文】由此二法，世中數用故。又人常誦，亦易解故。白中五句。初後中間三句，相傳為綱者；總該諸務，揩式軌定故。二四兩句名緣本者，即法所被事，隨機不同。如〈說戒〉云白月十五日，即是緣也；布薩說戒，即本事也。又〈受戒〉云某甲從和尚，乃至三衣鉢具等，竝名緣也；今從僧乞戒，即本事也。
【譯文】是因為這兩種法在世間極為頻繁使用。而且大眾平時經常背誦，也最容易理解明白。宣白（白）的內容共有五句話。最初、最後以及中間這三句話，歷來相傳被視為整個儀軌的骨架核心（綱）；因為它們總括涵蓋了各項僧事事務，具有固定標準且不可動搖的軌範之故。第二句與第四句被稱為細部事由的根本（緣本），也就是戒法所施加的具體事項，會隨著不同的對象與機緣而有所不同。例如〈說戒犍度〉中說「白月十五日」，指的就是當時的事緣；「布薩說戒」，指的就是本來要辦的事務。又如〈受戒犍度〉中說「某甲依託某和尚」，乃至於「三衣一鉢器具齊備」等，全都被稱為事緣；而「現在懇求大眾僧傳授戒法」，指的就是本來要辦的事務。
