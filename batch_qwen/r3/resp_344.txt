整體看，七段譯文的骨架都對，科判對應（「若」下、「大」下、「此」下等）也都沒有錯位。主要毛病集中在三類：**增詞過度**（形容詞、四字堆疊）、**少數術語理解偏移**（儀／進退／非法不知／一方），以及**該註未註**（拘鄰、白㲲、五分）。以下逐段列出，並標明輕重。

---

## 【344-0001】疏

1. **【誤譯】「如理體三寶」的「如」**：不是「例如」。記文明說「初二句指前眾相」，可見此處是承前論次第，「如」＝「至於／如同前面所說的」。
 → 建議：「至於理體三寶，其次第與前面所列相同。」
2. **【用詞】「故先五分」譯「先推崇五分法身」**：「先」是次第在前（先列），不是「推崇」。
 → 「所以先列五分法身，佛寶因而居首。」並宜補註：五分＝戒、定、慧、解脫、解脫知見，即佛寶。
3. **【增譯】「證理方具」→「必定是證得真理之後三寶功德才得以具足」**：「三寶功德」「必定是」都是加的，語氣也偏重。
 → 「須證得理體，三寶方才具足。」
4. **【贅】「因此在理體上法寶應當居於最先」**：本段即論理體，「在理體上」可刪。

## 【344-0002】記

1. **【誤譯】「進退以釋」→「從進一步與退一步的角度來互為解釋」**：兩處失準。
 (a)「以釋」＝「加以解釋」，不是「互為解釋」；
 (b)「進退」是科文用語，指就「約證／從行」兩面反覆推論，不宜直譯成口語的「進一步退一步」。
 → 「是就『約證』與『從行』兩面反覆推論解釋。」
2. **【用詞】「約證」→「證悟實體」**：應作「證悟理體」；「的先後」為贅詞。
 → 「若約證理而言，法寶理當居先。」
3. **【增譯】「比例化相」→「比照化相三寶的規律」**：「比例」＝比類、比照其例，「規律」多餘。
 → 「比照化相三寶之例。」

## 【344-0003】疏

1. **【增譯過重】「唯佛獨尊」→「全宇宙唯有佛一人最為獨尊」**：「全宇宙」是現代宇宙觀語彙，與文脈不合。
 → 「唯獨佛陀一人至尊。」
2. **【用詞】「止得動其耳目」→「頂多只能震撼引動眾生的耳目聽聞」**：「震撼」太強（原文重點是「只能觸及感官見聞，未能斷惑」）；「耳目聽聞」疊義。
 → 「也只能觸動眾生的耳目見聞。」
3. **【增譯】「煩惑」→「內在幽深的煩惱惑業」**：原文無「業」，「內在幽深」也是加的。
 → 「至於煩惱惑染。」
4. **【待補註】「拘鄰會正」**：「拘鄰」若不註，讀者不會知道是人名。
 → 註：拘鄰即憍陳如（五比丘之一）；「會正」＝會入正理、見諦證果。譯文可作「直到拘鄰（憍陳如）見諦證果，僧寶才出現」。
5. **【可改】「教之所及，行是所歸」** 現譯稍含糊 → 「教法所及之處，最終以起行實證為歸趣。」
6. **【可改】「化儀次第」→「化相示現教儀的先後秩序」** 略繞 → 「這就是佛陀教化眾生的次第儀軌，不可違亂。」

## 【344-0004】記

無實質問題。「隨順文義逐一解釋」「總括結語指示」可簡為「隨文解釋」「總結指示」，與記文簡峭的體性較合。

## 【344-0005】疏（本段問題最多）

1. **【誤譯】「世途法爾」→「世間大道的常態本來就是如此」**：「世途」指世間常規、世情之常，不是「大道」（「大道」是上句「道假人弘」的道，兩者混同）。
 → 「這是世間常規，本來自然如此。」
2. **【誤譯／不一致】三個「儀」字**：此處「儀」是「儀相／形儀」（三寶住持於世的相狀），不是「威儀」（行住坐臥舉止），也不是「儀軌」（修法軌式）。
 - 僧儀→「剃染僧寶的威儀」✗ →「僧寶的形儀（僧相）」（「剃染」為增詞）
 - 法儀→「法寶的教規儀制」✗ →「法寶的儀相（經教言說）」
 - 佛儀→「佛寶的形像儀軌」✗ →「佛寶的儀相（畫像）」
3. **【語意打轉】「故表畫像於涼臺，推其所說」→「為了表彰法源……推究其所說法源」**：「法源」出現兩次、句子繞回原點。「推其所說」是**由法推人**——推尋說此法者是誰（即佛），故畫佛像。
4. **【增譯】「非凡小之所開」→「凡夫小乘的心量所能開示」**：「心量」可刪。
5. **【待補註】** 迦＝迦葉摩騰（攝摩騰）、竺＝竺法蘭（已譯出，很好）；五乘＝人、天、聲聞、緣覺、菩薩；三途＝地獄、餓鬼、畜生。「漢明帝」是依記文補入，宜加括號或註腳標示。

**參考修訂：**
> 第三、住持三寶中，僧寶居初、法寶次之、佛寶在後的理由。因為大道須憑人弘傳，這是世間常規，本來如此。所以迦葉摩騰、竺法蘭最初來到中土，先顯現了僧寶的形儀；接著讲述五乘是善因、三途是惡果，這就顯現了法寶的儀相；而此法深遠廣大，不是凡夫小乘所能開演，於是（漢明帝）在清涼臺圖畫佛像以表彰法之所自——推尋說此法者即是佛陀，這就顯現了佛寶的儀相。

## 【344-0006】記

1. **【用詞】「初通列」→「最初是通體列明」**：「通體」不詞，且與下文「別釋」相對，應作「先總列（次第）」。
2. **【疊詞】「法委於僧」→「正法完全付囑託付給僧寶」**：「付囑託付」重複，「完全」為增詞 → 「正法付託於僧寶」。
3. **【待補註】「白㲲」未註**：宜註「白㲲（ㄉㄧㄝˊ，亦作氎）＝白色細棉布；此指繪於白棉布上的釋迦像」。
4. **【一致性】「騰蘭」**：前段已用全名，此處宜作「攝摩騰與竺法蘭二人」。
5. **【可改】** 「是約此方以論前後」→「這是就中土而論先後」即可，「佛教初傳的歷史」屬補釋，可移至註。

## 【344-0007】疏

1. **【誤譯】「非法不知」→「如果沒有透澈的心法本體，根本無從生起覺悟」**：原文是「若無（所覺之）法，便無從覺知」，重點在**法為所證之境，故在先**，不在「透澈」。加了「透澈」會與下句「非佛不曉」的能覺義混淆。
 → 「若無法（所覺之理），便無從覺知，所以法寶在初。」
2. **【漏譯】「一方行化」的「一方」未譯出**：或指「一方（一處）世界」，或指「各就一方面」，宜譯出並存疑註。另「隨相用分」譯「隨順**外**相功用」的「外」易誤導（一體三寶正就心體說），建議刪。
 → 「只是隨其相狀與作用分為三，各就一方（一面）施設教化。」
3. **【疊詞】「至理無滯」→「通融圓融、毫無滯礙隔閡」**：「通融圓融」疊、「滯礙隔閡」疊 → 「至理圓融無礙（無有乖諍），即『和合僧』義」。
4. **【增譯】「體離名言」→「心體本自寂滅、脫離一切名言思維」**：「本自寂滅」「思維」皆加詞 → 「心體離於名言（不可言說）」。
5. **【增譯】「體是心體」→「眾生現前的一念心體」**：「現前一念」雖合南山圓教義，仍屬補釋，宜括註或簡作「眾生心體」。
6. **【用詞】「一體者」→「一體自性三寶」**：建議保留「一體（同體）三寶」，「自性」作括註，避免與他處「自性三寶」混用。
7. **【可改】「分有所遣」→「仍有所殘留與逐步除遣」** 稍鬆 → 「（惑染）只除遣了一部分，尚未斷盡」。
8. **【贅】「豈喻醍醐」→「純熟的醍醐」**：「純熟」多餘；「非佛不曉」的「究竟圓滿通曉」也可簡。宜補註：雜血乳／醍醐出《涅槃經》五味喻，前者喻因位未淨，後者喻究竟佛果。
9. **【可補】**「法」義譯「法則」可，宜補「軌則（軌生物解）」之義。

## 通則建議

- **節制形容詞堆疊**：究竟圓滿、內在幽深、全宇宙、純熟、通融圓融……這類增詞會稀釋原文判斷句的力度；記文（科判）尤其宜簡峭。
- **補釋與正文分離**：人名、朝代、典故（漢明帝、拘鄰、白㲲、五味喻）統一用括號或註腳，不要混入正文，讀者才分得清「疏文本義」與「譯者補充」。
- **術語統一**：儀＝儀相／形儀（✗威儀、✗儀軌、✗教規儀制）；理體（✗實體）；五分法身；會正；通列／別釋；進退（兩面推論）。
- 「在○○的科判中」是加詞套語，可簡為「論理體三寶中」「釋化相三寶中」。

七段中 **0005、0007 建議修訂後再定稿**，0001、0002 屬小幅修正，0003、0006 主要是補註與去贅詞，0004 可原樣保留。
