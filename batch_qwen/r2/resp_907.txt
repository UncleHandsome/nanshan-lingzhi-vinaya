整體讀來文氣通順、科判层次也掌握得不錯（例如把「二文義具闕」判讀為「文具義闕」，與下文「三義具文闕」相對，是正確的）。但有幾處**名相誤譯**與**增譯過度**會影響法義，另有術語前後不一致的問題。以下逐條列出。

---

## 一、實質性錯誤（建議必改）

**1.「雨衣」≠「雨安居衣」（0001、0006）**
原文「以《多論》受雨衣為例」「以雨衣為例」，指的是**雨浴衣**（尼薩耆第24條「春末一月應求雨浴衣，半月應用浴」），《薩婆多論》討論其受持時限如何計算閏月，故拿來類比「安居依閏」。譯成「雨安居衣」憑空造出一個不存在的衣名。
→ 建議：「受持**雨浴衣**（的時限規定）」。

**2.「邊罪等二十二人」不是「不得受戒之人」（0006）**
此段屬**足數**問題（下文「自言不足數」「體既非僧」「成足」可證），指羯磨時不充僧數的二十二種人，不是能否受戒。
→ 建議：「《四分律》所列邊罪等二十二種**不足僧數**之人」。

**3.「三寶病緣」應拆為二事（0002）**
「為別處三寶病緣」＝為他處的**三寶事緣**與**病（人）緣**，皆是受日的開緣。譯成「三寶病患因緣」變成「三寶生病了」。
→ 建議：「為了其他處所的**三寶事、病人（看病）等緣**」。

**4.「僧次請」方向顛倒（0002）**
僧次請是**施主依僧中次第依次請僧供齋**（相對於「別請」），不是僧團自己去「輪流請齋」。
→ 建議：「以及**施主依僧次（次第）的請供**」。

**5.「十六遮」不是「障難」；「得戒」不是「可以求受」（0002）**
難（十三難）與遮（十六遮）判然有別：遮不障戒體，故負債人「準理**得戒**」——重點在**真的得戒體**，不在「可以求受」。
→ 建議：「十六**遮**中負債之人，依理仍**得戒（獲得戒體）**」。

**6.「對首」不限於懺悔（0003）**
「此約眾法對首為言」是說賊住難的成立，就**眾法羯磨**與**對首法**（三法之一）而言。縮成「對首懺悔」範圍過窄。
→ 建議：「這是就**眾法（僧法）與對首法**而說」。

**7.「憶即悔者得」的「得」被譯丟了（0004）**
「得」指**得夏、不破安居**，譯成「即屬合法有效」語意空泛。
→ 建議：「想起來就立即懺悔者，**仍得夏（不破安居）**」。

**8.「自有」≠「自然有」（0006×2、0007×2、0008×2）**
「自有…者」是「（其中）有…的情形」，是列舉用語，無「自然」義。全篇六處同誤。
→ 建議：「**其中有**屬於…的」「**另有**…的情形」。

**9.「復有兼文例二種者」易生歧義（0007）**
這是義決三句中的第三句：義決**同時兼帶文、例二者**，不是「有兩種情況」。
→ 建議：「又有**同時兼帶文決與例決二者**的」。

**10.「古記」不是「古代筆記」（0004）**
古記指古德對《行事鈔》的**注疏**（如《會正記》一類）。又「尋文未獲」是**元照自己**去查《善見》而未得，譯文主語不清，且《善見》是論不是經，「經文」宜作「論文」。
→ 建議：「**古德注疏**說即是《善見論》，（我）**遍查論文仍未找到**」。

**11.「今師」宜作「今師（道宣）」，非「本師」（0006、0008）**
資持記中「今師」指鈔主南山道宣；「本師」一般指釋尊或剃度本師。另0008原文「引《僧祇》云」並無「本師」二字，屬增譯。

---

## 二、術語概念偏差

**12.「例」＝可類比的**事例 **，不是「條例」（0002、0005、0006、0007）**
原文自釋「**無文引事相比**，名為例決」，明說是引事作類比。譯文「毫無現成**條例**可循」「相似條例」「以…為條例」，會讓讀者誤以為在講法規條文，與「文決」混淆。
→ 建議統一作「**類例／可資類比的事例**」；「為例」＝「作為類比之例」。

**13.「受日」宜作「受日法／受持出界日限」**
「接受請假日法」讀來像收受別人的請假單。受日是比丘**從僧受取出界的日限**（七日、半月、一月法）。

**14.「持衣」的持是「攜帶」（0001）**
「忘不持衣」＝忘記**沒帶衣**，非「未能持守衣物」。

**15.「界」譯作「地界」略嫌含混**
律中「界」是結界（sīmā）所成的僧界範圍，建議作「**（結）界**」，避免與四大之「地界」混同。

## 三、增譯、誇飾與用詞可議

| 出處 | 譯文 | 問題 |
|---|---|---|
| 0002、0005 | 「**深密**法義」「**深密**義理與**普遍**法理」 | 原文只作「義」「理」，「深密／普遍」是憑空加上的形容，反而模糊了兩者對舉的本意 |
| 0005 | 「以**整體**法義來裁定條文」 | 「以意定文」的「意」是義意、己意，非「整體」 |
| 0002 | 「上座誡勅」→「警誡**斥責**」 | 勅＝教敕、囑咐，無斥責義 |
| 0002 | 「開示境心、威儀安慰」→「境心**觀想**」「威儀舉止的安撫關照」 | 「境心」是所緣境與能緣心（發戒體處）；「威儀」「安慰」是兩件事，不宜揉成一句 |
| 0004 | 「恐謂師心」→「律師**自出心裁**」 | 「師心」是師心自用、任己臆斷，帶貶義；「自出心裁」偏褒 |

## 四、可再斟酌／建議加注處

- **（0001）「忘不持衣往會不及」**：譯文用「導致」把兩事串成因果，恐非原意。較稳妥的讀法是「（因）忘而未攜衣前往僧會，（明相出前）趕不及」，建議譯得貼近原文並加注。另「長物衣」宜作「**長衣**（三衣以外的多餘衣）」。
- **（0002）「當日出界遇難」**：「當天」所指不明（受日當日？夏滿當日？），建議保留字面並加註，勿逕行斷定。
- **（0003）「準須付他」**：「準」是依準義理而判（此段正屬義決），譯「比照**規定**」與「無明文」的前提相牴；「他」宜註明指淨人。
- **（0004、0007）《摩夷經》**：摩夷即本母，一般指《毘尼母論》，建議保留《摩夷》並加注，不宜逕加「經」字；同段《五百問》稱「論著」亦稍寬泛。
- **（0008）「三由旬界合角量取」**：譯為「拼接邊角量取」讀者幾乎無法理解，建議加註說明《明了論》的量界法。
- **（0008）「一一說欲」**：宜補出「為每位缺席者**各別傳達其欲（同意）**」，「向人陳述欲法」語意太浮。

## 五、建議統一的術語表

| 原文 | 建議譯法 |
|---|---|
| 例決（通） | 例決——引類例以決通 |
| 理決 | 理決——依道理決斷 |
| 義決通 | 義決——以義意裁定律文 |
| 文決通 | 文決——引他部明文成事 |
| 為例 | 作為類比之例 |
| 受日 | 受日法（受持出界日限） |
| 雨衣 | 雨浴衣 |
| 古記／今師 | 古德注疏／今師（道宣） |

**小結**：最需優先修訂的是「雨衣」「二十二人」「三寶病緣」「僧次請」「十六遮得戒」「對首」「憶即悔者得」這七處法義性錯誤，以及「自有→自然有」六處、「例→條例」的系統性偏差；其餘多屬增譯與措辭問題，酌減形容詞、貼回原文即可。
