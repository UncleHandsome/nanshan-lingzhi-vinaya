# 校閱材料　第191檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【191-0001】03_業疏/04a_卷一之四#79
【原文】若爾，小界無內可如前言，身界之外可不須集？答：元制簡人，雖有不集，不同大界制內外集
【譯文】如果這樣，小界沒有界內就像前面所說的那樣，那麼在圍繞人身之界的外圍難道就不需要集會了嗎？回答：原本制定的用意在於簡別隔絕他人，雖然界外有人也不去召集，這不同於大界強制規定界內、界外都必須召集。

【191-0002】03_業疏/04a_卷一之四#80
【原文】釋妨中，恐謂說恣小界可以類同，故須簡別。答中，制簡人者，為遮訶故。若須外集，開無所濟；大界非難，故曰不同
【譯文】在解答疑難中，因唯恐有人認為說戒、自恣的小界也可以同類等同看待，所以必須加以簡別。在回答中，規定簡別隔絕他人，是為了遮止他人來訶止羯磨。如果還必須召集外圍之人，那麼開許結小界就無濟於事了；大界並非處於急難之時，所以說體制不同。

【原文】若有戒場，則四處各集：一是界外，二是界內，三是內相外、戒場外中間空地，四是戒場體
【譯文】如果設有戒場，則在四處各自集會：一是大界之外，二是大界之內，三是大界內界標之外、戒場標界之外的中間空地，四是戒場本體之上。

【191-0004】03_業疏/04a_卷一之四#82

【譯文】在第三設有戒場之界中，各處當位自行召集，事理上容易理解。特意著眼於共同集會，來顯示其殊異的法相。

【譯文】問：羯磨法的施設，只要結界之中沒有未集之僧人（別無他人）就能成就，為什麼還要召集其他外處界限的人呢？

【191-0006】03_業疏/04a_卷一之四#84
【原文】初問大界外集之意
【譯文】首先詢問大界之外也須召集集會的意圖。

【191-0007】03_業疏/04a_卷一之四#85
【原文】答：行法不同。若作羯磨，則隨界分局，人不相集；若作說恣，則內外通收。以是攝僧綱紀，使內外同崇，不許逃避。乃至外界、戒場見相便求，多有句數，即其事也
【譯文】回答：所施行的律法有所不同。如果是舉行羯磨，就隨各個界限劃分局限，彼此之人互不參與集會；如果是舉行說戒或自恣，則界內界外通通收攝。因為這是統攝僧團的綱紀，旨在使內外界限的僧眾共同尊崇教法，不允許有任何人藉故逃避。乃至於對界外、戒場若見到僧相身影，便須前往尋訪呼喚同集，其中有許多種句數情況，正是指這件事。

【191-0008】03_業疏/04a_卷一之四#86
【原文】答文今釋中，初句總示。「若下」別釋，即僧私二緣通局兩集。「乃至下」別證通集。本律說戒犍度云：時有一住處，說戒日，客比丘來，見舊比丘在戒塲上，見而不求，便作羯磨。諸比丘白佛，佛言成羯磨，說戒有罪。若見已便求，求已不喚，成羯磨，說戒有罪。若見已求，求已喚，成羯磨，說戒無罪。聞、疑亦如是。又有住處，說戒日，舊比丘見客比丘在戒場上，三句并聞疑三句，竝同上。餘廣如彼，故云有多句數也
【譯文】在回答的疏文今釋中，第一句作總體指示。自「若（作羯磨）」以下，作個別解釋，即僧眾公務（說恣）與私人因緣（羯磨）的通攝與局限這兩類集會。自「乃至」以下，特別引證普遍通收集會之例。本律〈說戒犍度〉記載：當時有一處僧住處，在說戒的日子，客比丘來到，看見舊住比丘在戒場上，客比丘看見卻不去尋訪探問，便直接作羯磨。眾比丘向佛陀稟告，佛陀說：羯磨雖然成就，但說戒犯過有罪。如果看見之後便去尋訪，尋訪之後卻不喚他同來，羯磨成就，說戒有罪。如果看見之後前往尋訪，尋訪之後喚他同來，羯磨成就，說戒無罪。聽聞音聲、心中生疑的情況也是如此。又有一處僧住處，說戒之日，舊住比丘看見客比丘在戒場上，其看見的三句以及聽聞、生疑各三句，都與上述相同。其餘詳情廣如律文所述，所以說具有許多種句數。

【191-0009】03_業疏/04a_卷一之四#87
【原文】有說云：縱作羯磨，亦須通知。以年歲逾遠，界相莫知，或主客改轉，虗傳制限，故須通集，先委問緣。脫有漠落，徒生疑惑；必本非法，實濫後緣。若經受戒，空傳聖法，喪他一生，自他同陷，深可鏡之。此言易耳，臨時難改
【譯文】有一種說法認為：縱使只是作羯磨，也必須通報告知。因為年代久遠，原本結界的標相已不可知，或者由於舊住僧與客比丘遷替流轉，徒然口耳相傳不實的界限範圍，所以必須全面召集，預先詳細詢問原委。倘若有疏忽遺漏之處，只會徒然產生疑惑；如果當初的結界根本不合法，確實就會延誤敗壞後續的一切如法因緣。如果經歷傳受具足戒，徒然虛傳聖法而實未得戒，將喪送他人一生的法身慧命，自己與他人一同陷入罪過之中，這非常值得引以為鏡戒！這件事說起來雖然容易，但到了臨事之際卻難以臨時補改。

【191-0010】03_業疏/04a_卷一之四#88
【原文】次古解中，此就私緣，約界不明，可有通集；必無疑濫，則不須之。初敘須集所以。「脫下」彰不問之非。初謂標相不分，「必下次」即本結乖法，於界生疑，不出此二。必有此緣，解已重結，不同今世，無問曾結不結，一概妨疑，請考此文，足知傳謬。濫後緣者，通諸眾法，作竝不成，受法尤重，故別舉耳。「此言易者」，秉結不難故；「臨時難改」，再受非易故
【譯文】在次一段古德解釋中，這是針對單個私人因緣、在結界界相不明確時，才可能進行全面召集；若是必定沒有任何疑惑混濫，則不需要如此。起初敘述必須全面召集的緣由。自「脫（有漠落）」以下，彰顯不預先詢問的過失。前者是指標相不能分清，自「必（本非法）」以下其二是指當初結界時就違背法度，對於界限產生懷疑，不出這兩種情況。若必定存在這種疑緣，應當解界之後重新再結，這不同於當今世人，不論曾經結界還是未曾結界，一概橫加質疑阻礙，請考察這段文義，便足以明白世俗相傳的訛謬。「混濫後緣」是指通於各種僧眾羯磨法，作了都不能成就，其中傳受具足戒之法尤為重大，所以特別舉出來講。「這話說起來容易」，是因為主持結界並不困難；「臨事之際難以補改」，是因為重新受戒並非易事。

【191-0017】03_業疏/04a_卷一之四#95
【原文】初不可分別者，或約僧之來去難可知者，或約處所散落不知際域。故《僧祇》云：若城邑聚落，界分散亂不可知者，以五肘為弓，七弓種一樹，齊七樹為量。相去作法，雖有異眾，各不犯別。約相步之，則有六間六十三步

【191-0081】03_業疏/04b_卷一之四#45
【原文】又解人雖體非，相有僧用，各不相知，理開成足。故《十誦》云：犯重罪人、賊住、邊等，若先言有是過，作法不成，反上得也。故律論竝云「同住之法，肉眼三根淨，不用天眼見他犯過」，廣如《鈔》中。是以文中「若言犯罪」與彼不殊，故知自言自述，使人聞也。又《四分》中，於不持戒和尚受具足，前三句者由不知不得，故開；第四句知不得故方閉，廣文如欲法中
【譯文】又有一種解釋：此人雖然本質並非如法，但外相上具備僧人的功用，若彼此互相不知情，按理開許算作足數。所以《十誦律》說：犯重罪之人、賊住、犯邊罪等，如果在作法前先說出有這等過咎，作法便不成；反之若不說，羯磨便得成。所以律與論都說「共住之法，只要肉眼所見的三根（眼見、耳聞、疑心）清淨即可，無須用天眼去觀照他人是否有犯過」，詳細如《事鈔》中所明。因此律文中的「若言犯罪」，與那裡的說法並無不同，由此可知是指自己口頭陳述、讓人聽聞。又如《四分律》中，在不持戒的和尚座下受具足戒，前三句由於不知道會不得戒，因而開許得戒；第四句因為知道會不得戒，所以才閉塞不開許，詳細律文如同說欲法中所載。

【191-0123】03_業疏/04b_卷一之四#87
【原文】斥非中，初引非。「今下」正斥。為緣即有難，如《十誦》中，和尚師僧著俗服得戒是也。《善見》比丘為賊所剝，聽著五大色衣，即是俗服，脫臨法席，豈不足數
【譯文】在破斥非議之中，首先引述不合理的見解。自「今不同之」以下正式破斥。所謂「為緣」就是指遇有危難，例如《十誦律》中，和尚師僧因故身著俗服而授戒成功，就是此例。《善見律》記載比丘被盜賊剝光衣服，佛陀開許著用五大色之衣，這就是俗服，倘若面臨僧事法席，難道就不能充當僧數嗎？

【191-0126】03_業疏/04b_卷一之四#90
【原文】今約癡鈍，事義須知。夫羯磨者，為通和忍，隨文解意，則非愚限。故即世行事，秖論身足，及問是非，渺同河漢。今出愚相，略有五焉
【譯文】如今就癡鈍而言，其中的事理必須明瞭。所謂羯磨，是為了使僧團和合忍可的通表，能夠隨順文辭理解義旨，這才不屬於愚癡的範疇。然而當世僧團行事，只論人身到場湊足人數，等到詢問法事的合法與非法時，卻茫然無知如同銀河般遼遠摸不著邊。現在指出愚癡的行相，大體上有五種。

【191-0127】03_業疏/04b_卷一之四#91
【原文】次別釋中初科。文敘羯磨取解為功，世多愚暗，故須歷辨。渺同河漢，言其浮漫無涯畔也
【譯文】在隨後個別解釋的第一科中。文中敘述羯磨以通達理解文意為功效，當世僧人大多愚昧暗昧，所以必須逐一辨析。「渺同河漢」，是形容其漫無邊際、無有涯岸。

【191-0128】03_業疏/04b_卷一之四#92
【原文】誦文合眼，恐有渟延，緣入非違，傍無人覺，此一迷也；或同誦一法，前後無乖，文相能所，不識彼我，此二迷也；或約文謹攝，深練自他，增減乖務，事法錯濫，不召令住，此三迷也；或文句乃明，牒事不濫，人有別緣，是非通默，此四迷也；或人法乃具，事局界境，成不冥然，端拱送忍，此五迷也
【譯文】背誦法文時閉起雙眼，恐有停滯拖延，以致墮入非法違失之中，而身旁竟無人察覺，這是第一種愚迷；或者眾人一同誦讀某一羯磨法，文句前後雖然沒有乖錯，但對於法文名相中的能治與所治、能為與所為，根本分不清彼此主客，這是第二種愚迷；或者依照法文謹慎攝持，深通自他之別，但遇到法事有所增減違背常務、事相與軌法交錯混濫之時，卻不能呼召令其停下，這是第三種愚迷；或者文句十分明瞭，宣示事由也不混濫，但參與之人另有界外等違礙別緣，眾人對於是非卻一概默然不語，這是第四種愚迷；或者人與法都已齊備，而事端局限於界限範圍之內，羯磨究竟成就與否茫然不知，只是一味端坐拱手隨順表決忍可，這是第五種愚迷。

【191-0132】03_業疏/04b_卷一之四#96
【原文】如《僧祇》中有九：一者與欲人堂中作法，通收欲者以入現數；二若隔障，即同在覆，別有遮斷，不見身也；三半覆露，中間隔障；四半覆露，申手不相及；五同在露地，申手不相及。此上五種，是善比丘當時乖相，故非數限
【譯文】如《摩訶僧祇律》中有九種人：第一是給予欲法的人，在堂中作法時，卻將這出具欲法者算入現前人數之內；第二是如果有屏障隔開，即雖然同在屋覆之下，但另有遮斷障礙，看不見其身形；第三是半覆半露（部分在屋簷下、部分在露地），中間又有屏障阻隔；第四是半覆半露，彼此伸手搆不著；第五是同在露地之中，彼此伸手搆不著。以上這五種情況，都是如法的善比丘在當時行相有所乖違，所以不合列在足數的界限內。
