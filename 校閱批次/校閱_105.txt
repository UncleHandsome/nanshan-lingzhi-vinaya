# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【105-0007】03_業疏/18a_卷四之一#16
【原文】次科初敘難。「仙苑」即鹿野苑。《婆沙》云「施鹿林」，梵摩達王以樹林施眾鹿故，亦號「仙人論處」，羅勝仙人始於彼轉法輪故。意云：初時已具，後衣法中何以復制耶？「由下」，釋通。初敘年賖事變。「教下」，出變所以。急於修證，趣得覆形，不暇如法，遂致訛濫
【譯文】在下一科中，起初陳述問難。「仙苑」即是鹿野苑。《大毘婆沙論》稱之為「施鹿林」，因為梵摩達王將森林布施給鹿群的緣故；又名「仙人論處」，因為羅勝仙人最初在該處轉法輪的緣故。問難之意是說：當初善來受戒時法衣已經具足，為何後來在〈衣法〉中又要再次制定呢？自「由聖制」以下，給予通暢的解釋。起初敘述年代久遠導致事態變遷。自「教網」以下，指出演變的原因：當初大家急於修證解脫，只要能遮蔽身體即可，無暇顧及是否完全如法，遂導致訛誤濫造。

【105-0009】03_業疏/18a_卷四之一#18
【原文】僧祇中，初文引四分偈，顯非凡服。上二句云：「懷抱於結使，不應被袈裟。」結使即見思惑，體是三毒。次《賢愚經》云：佛告阿難，古昔無量阿僧祇劫，此閻浮提於山林中有一師子名𨃓迦羅毗，軀體金色，光相明顯。時獵師剃頭著袈裟，內佩弓箭，以毒箭射之。師子驚覺，即欲馳害，見著袈裟，念言：「此人不久必得解脫。所以者何？此染衣者，三世聖人標相。我若害之，則為惡心向三世賢聖。」便說偈曰：「耶羅羅，婆奢沙，娑訶。」乃至獵師剝皮奉王，王求仙人解說上語。云：「耶羅羅」者，云剃頭著染衣人，當於生死疾得解脫；「婆奢沙」者，云如上人皆是賢聖之相，近於涅槃；「娑訶」者，云如上人當為諸天世人所見敬仰等
【譯文】在引用《僧祇律》的段落中，起初經文引用《四分律》的偈頌，顯明袈裟並非凡俗之服。其前兩句說：「若心中懷抱著煩惱結使，就不應當披上袈裟。」「結使」就是見惑與思惑，其自體即是貪瞋癡三毒。 其次《賢愚經》說：佛告阿難，在古昔無量阿僧祇劫以前，這閻浮提的山林中有一隻獅子名叫契迦羅毘（𨃓迦羅毗），身軀呈金色，光芒顯著。當時有獵人剃除鬚髮、身披袈裟，內藏弓箭，用毒箭射中牠。獅子驚覺後，立刻想要奔馳上前加害獵人，但見到他身披袈裟，便心想：「此人不久必定獲得解脫。為什麼呢？這染色法衣乃是三世聖人的標幟相貌。我若傷害他，就是懷有惡心對向三世賢聖。」於是說偈道：「耶羅羅，婆奢沙，娑訶。」乃至後來獵人剝了獅子皮奉獻給國王，國王尋求仙人解說上述話語。仙人說：「『耶羅羅』的意思是，剃頭身著染色衣之人，應當於生死輪迴中速得解脫；『婆奢沙』的意思是，上述之人都具有賢聖的相貌，已臨近於涅槃；『娑訶』的意思是，上述之人應當為諸天與世間眾人所共同瞻仰恭敬等。」

【105-0011】03_業疏/18a_卷四之一#20
【原文】次科初指廣，見〈二衣篇〉。「至」下勸引，牽挽猶援引也。「但」下破執，上二句破所執，次二句破能遣。執是病，遣如藥，病去藥存，藥還成病，復是法見，微密難除，故云「最」也。下句誡觀察。學者至此，慎勿強會。汝今惰學，尚未有執，將何為遣？况令遣遣，必非己分。自非定慧照達名相一切緣生，則終日談玄未說一句，終日執卷未始看文，猶如揮手於空，可謂如如不動。若斯傅演，何往不通！

【105-0019】03_業疏/18a_卷四之一#28
【原文】次科初示名通，三衣同名故云總號。《增一》云「如來所著衣名曰袈裟」，《華嚴·淨行品》云「著袈裟時當願眾生」等。「俗無字」者，梵語借音，但作加沙，後謂之衣，故篇韻中例添衣字。「梁下」，又二：初引人語，應是襄陽道安法師，然安出晉朝而云梁者，未詳所以，或恐梁朝別有安師。「然下」，評量。「道服」之言，殊非對譯。「袈裟」染色，名體全乖。引四分彰非，舉六味反質。準《涅槃經》，甘、苦、辛、酸、醎、淡，是為六味，不云有袈裟味，不知何出。「如下」，次引教文。二律並取方相以翻，《多論》所釋止定其名，未知袈裟從何為目。仍指戒疏，見捨墮中，彼云「但以三衣總號，此土先無，不知何物，而廣長之相同此被敷，故即相翻云臥具等」，餘廣如彼
【譯文】在次一科中，首先顯示名稱的通稱，三衣具有共同名稱，所以說是「總號」。《增一阿含經》說「如來所著的衣服名為袈裟」，《華嚴經·淨行品》說「著袈裟時，當願眾生」等。「俗無字」這句話，是指借梵語之音，原本只寫作「加沙」，後來指衣服，所以在字書韻書中便依例加上「衣」字旁。「梁下」自此以下又分兩部分：首先引用前人說法，應當是襄陽的道安法師，然而道安法師是東晉時期的人，此處卻說是「梁代」，未能詳知原因，或許是梁朝另有一位安法師。「然下」自此以下是評斷辨析。「道服」的說法，絕非對譯。「袈裟」意為染色，名與體完全不相干。引《四分律》彰顯其非，列舉六味來反詰質疑。依據《涅槃經》，甘、苦、辛、酸、鹹、淡稱為六味，並沒有提到有袈裟味，不知出自何處。「如下」自此以下是其次引述教典教文。兩種律典都取衣形方整的相狀來翻譯，《薩婆多論》的解釋也只是確定其名稱，依然不知袈裟究竟從何命名。疏中仍指引參考《戒疏》，見於〈捨墮〉篇中，那裡說「只因三衣是總號，此土原先沒有，不知是何物，而寬廣長大的形相如同此土的被褥席具，因此便隨其形相翻譯為臥具等」，其餘詳細如彼處所說。
