# 校閱材料　第208檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【208-0001】01_行事鈔/09c_卷下之一#1
【原文】三同活共財不同。若師本意，正與弟子衣食，不共同活；已與者得，未與者師亡已後，悉皆入僧。實非同生，假冐取僧物者，犯重。若師本契，所有財物決心同分，看如兒想，終無分隔；此若互死，任情多少，隨身服用，一切入僧。若師徒共契，財物共有，各別當分。且在一處，別活反道，悉共半分，是名共活。若分其物，準俗制道；已著之衣服，已用之器物，各屬隨身，並未須分；餘有長財，依式分半。若不同活，又非共財，妄言取分，能所俱犯；重則犯重，輕則偷蘭。《善生經》中，亦有兩斷，並據輕物。
【譯文】三「同活」與「共財」之不同情形。若是師父原本的心意，只是供給弟子衣食，並未打算與他共同生活（共活）；那麼已經給予的就歸弟子所得，尚未給予的，師父亡故之後，全部歸入常住僧物。若實質上不是如同父子般的同活關係，卻冒名妄取僧物的人，犯重罪（波羅夷）。若是師父原本就立下契約約定，決心所有財物共同分配，看待弟子如同親生兒子，始終不予分隔；這種情況下，若任一方亡故，在生者可以隨其意願收取剩餘財物（不拘多少），唯獨死者的個人隨身服用衣物，則一律歸入僧團。若是師徒共同立契，約定財物共有，各自應得一份。暫且同住一處，若有一方另外立戶謀生或還俗（反道），全部財物雙方各分一半，這就稱為「共活」。如果要分割這類財物，應當準照世俗禮法來制定僧道之規：已經穿在身上的衣服、已經使用的器物，各自歸屬於隨身之用，都不需要分割；其餘剩餘的多餘財物（長財），則依照定式對半平分。如果既非同活，又非共財，妄言冒稱而前來分取財物者，擅自裁斷給與的眾主（能）與妄取財物者（所）雙方皆犯戒；情節重的犯重罪（波羅夷），情節輕的犯偷蘭遮（粗惡罪）。《善生經》中，也有兩種判斷標準，都是依輕物來立論的。

【208-0002】01_行事鈔/09c_卷下之一#2
【原文】四囑授是非，四句分之：一囑授善惡，二人物差別，三重單囑授，四成不之相。
【譯文】第四、囑託交付的合法與非法，分為四個項目：第一、囑授的善與不善；第二、受囑人與財物的差別；第三、重疊與單純囑授之相狀；第四、囑授成就與否的相狀。

【208-0003】01_行事鈔/09c_卷下之一#3
【原文】初中，有四：一囑授善者。自知昔來非法儲積，唯結不善，今若命終，無一隨者；不如破著捨貪，順本初受；便決誓願，以財付他，生福上處，故是善也。二不善者。恐此財物死後僧得，慳貪俗態，妄授白衣，謂言勝善，此囑非善。三不囑善者。若病篤之時，唯存出道；於此身中，空無無漏，以此恨歎，常知偽財，本非真要，縱有勸囑，便在愛增；但論前業福道，此財佛已誠斷；如此而終，不囑亦善。四不囑不善。謂前心欲捨，後便慳覆，展轉互生，不能自決，遂便捨命，是不善也。《五百問》中，比丘愛銅盌事，及慳衣事，如〈隨相〉說。
【譯文】第一項（囑授善惡）中，分為四種情況：第一是「囑授為善」。自己明知過去非法積蓄財物，只會結下不善業，如今若是命終，沒有任何一件財物能帶得走；不如破除執著、捨離貪心，順應最初受戒的出家本懷；於是決心立下誓願，將財物交付他人，用於能生廣大福德的殊勝之處，因此這是善。第二是「囑授不善」。害怕這些財物死後被僧團所得，出於慳吝貪著的世俗心態，胡亂囑授給在家人（白衣），還自稱是殊勝的善行，這樣的囑授是不善的。第三是「不囑授為善」。如果在病重垂危之時，心中唯念出離之道；感念自身之中，尚未證得無漏聖道，以此深自遺憾嘆息，深知世俗虛偽之財，本非修道真要，縱使有人勸他囑託交代，心念也容易偏墮於愛憎私情；此時只論隨順前業與修福正道，這筆財產佛陀早已明確裁斷歸僧；像這樣而命終，不作囑託也是善。第四是「不囑授為不善」。這是指先前起心想要捨棄，隨後又被慳貪覆蔽，兩種念頭輾轉交替生起，無法自我決斷，於是就這樣命終捨報，這是不善。《五百問》中記載的比丘貪愛銅碗之事，以及慳吝僧衣之事，正如本卷〈隨相〉篇中所說明。

【208-0004】01_行事鈔/09c_卷下之一#4
【原文】二差別者。一人物俱現，是囑是授。奴婢、田宅、車牛、莊園等重物，及輕物不可轉者，名囑。二可付與，如絹匹、衣服、寶物等，是授。三人物互現，或俱不現，是囑非授；以人在他邦，餘物別處等。四非囑授者，任僧準式，如前說也。
【譯文】第二項「人物差別（受囑人與財物的差別）」。第一種情況是「受囑人與財物俱現前」，此即既是囑託又是交付（是囑是授）：其中奴婢、田宅、車牛、莊園等重物，以及不可搬移轉運的輕物，稱為「囑」；其二，可以當面交付給予的匹絹、衣服、寶物等，稱為「授」。第三種情況是人與物僅有一方現前，或者雙方都不現前，這只能算是「囑」而非「授」；因為受託之人身在他鄉，或者財物留存在別處等。第四種情況是「非囑授者」，則聽任僧團依照律制軌式來處理，正如前面所說。

【208-0005】01_行事鈔/09c_卷下之一#5
【原文】三重囑授相。《僧祇》：囑與眾多人，最後人得；授與眾多人，在前者得。準此決犯。如決心與他，自言先出，或對人陳；隨一許竟，後便差損。理是他財，因不付他，或轉餘施，財主犯重。《善生》云：先許他一衣，後便餘大德來，轉以施之，是得偷罪。《明了論》：決心捨已，不犯長。
【譯文】第三項「重疊與單純囑授之相狀（重單囑授相）」。《摩訶僧祇律》說：如果將財物囑託給許多人，由最後受囑的人獲得；如果是當面交付給許多人，由最先受給的人獲得。應當依此準則來判決犯戒之相。例如已經下定決心給予他人，口中已經先說出口，或者對著人陳述說明；只要上述三種許諾方式中任一種成立之後，物主事後卻發生乖違變卦、減損不給。從道理上說，那已是他人的財物，如果因此不交付給他，或者轉而布施給其他人，財主（原物主）犯重罪。《善生經》說：先答應給予他人一件衣服，後來有其他大德到來，便轉而布施給這位大德，這是犯了偷盜罪。《明了論》說：決心捨棄之後，就不犯蓄長財罪。

【208-0006】01_行事鈔/09c_卷下之一#6
【原文】四成不相者。凡言囑授，正是捨財相應心，要必決與，生福勝處；定無變悔，皆悉成就。若云，此物死後與我作墓、買棺槨碑碣、作像寫經、供僧等事，並不成就。以未死是物主，定不自分；死後更有主來，處斷不依前法。若犯王法，知明日晚間必死，今日中前，隨時並成；由未死前，心決成主。若以財物令人造像、施僧、齋供，使我眼見，因即命終者成；若言死後，同前浮漫。故諸部明示。《四分》云：若臨終時，囑物與佛法僧，若我死後與等。佛言：一切屬僧。《十誦》大同；唯三衣六物，不應自處分。《僧祇》：若未付財，或得已不作淨，還置病人邊，並不成；若作淨已，置邊者得。若言我死當與，若差即不捨，並不成。《五分》：若生時已與人，而未持去，僧應白二與之。
【譯文】第四項「成與不成之相狀（成不相）」。凡是說到囑授，正是與捨棄財物相應的心念，必定要堅決給予、用於能生勝福之處；而且必定不再變易反悔，這樣囑授才能全部成就。如果說：「這批財物在我死後替我修建墳墓、購買棺槨碑碣、塑造佛像、抄寫經卷、設齋供僧」等事，這些囑託全都不成立。因為生前自己是物主，一定不能自己任意處分死後的僧物；死後則更有新的主事人（看病五德比丘）來接管，後來的處斷不能依隨他先前的說法。如果是觸犯國法，明知明天晚間必定處死，在今天中午之前，隨時囑授都能成就；因為在死前心意已決，已確定移交了物權。如果拿出財物讓人造像、布施僧眾、供養齋僧，並說「要讓我在生前親眼看見」，因此隨即命終的，囑授便算成就；如果說是「死後才做」，就同前述一樣流於虛浮泛慢而不成立。因此各部律典都明確指示：《四分律》說：若是臨命終時，將財物囑託給佛、法、僧，或者說「等我死後再給」等，佛陀說：一切歸屬於僧團。《十誦律》大致相同；唯獨三衣等六物，死者生前不得自行處分。《摩訶僧祇律》說：若是尚未交付財物，或者受囑人獲得之後未作說淨（對首加持），又放回病人身邊，都不能成就；若是已經作了說淨，再放在病人身邊的，則囑授成立。如果說「等我死了應當給予，如果病好痊癒（差）就不捨」，這全都不成立。《五分律》說：如果生前已經給予他人，但受囑人尚未拿走，僧團應當作白二羯磨（一白一羯磨）將財物給予該人。
