# 校閱材料　第993檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【993-0001】資持記/04a_上三#20
【原文】所以五人獨言持律者，邊地僧少，恐不簡練，故特標之，非謂中國便容濫預；古師錯解，如《疏》委斥。此土邊陲，本是開位。僧既漸多，還遵中制。末世浮薄，德學全虧；必準本開，理亦無過；是知律制五人持律，經開千里無師；非謂無僧，但實行者不易得耳。若下，決上邊開。
【譯文】之所以在邊地五人中特別言明「持律」，是因為邊地僧人稀少，恐怕不加審慎簡選，所以特地標明，並非表示在中國就可以容許濫竽充數；古代律師理解錯誤，正如《業疏》中詳細斥責的那樣。此土在初期屬於邊陲，本來屬於開許之位。後來僧人既然漸漸增多，就應當還歸遵循中國之制。末世風氣浮薄，德行與學問完全虧損；此時若必定遵照當初的開許，按理也沒有過錯；由此可知律制要求五人中須有持律者，經典中開許千里之內無師即可，並非說那裡完全沒有僧人，只是具備真實行持的人難得遇到罷了。從「若」字以下，決斷上述邊地的開許。

【993-0002】資持記/04a_上三#21
【原文】得戒謂僧法無缺，得罪即本制有乖。若爾，中國五人，可同此否？答：中本無開，不可相例。此下，指所出，《伽論》亦然。第四和集。文據可解。五中。則下二句，且括四非。或昧綱緣，白讀謹誦，皆不成法，故云等也。六中。疏云：內欣勝法，外假勝儀；身心相依，如魚有水。
【譯文】「得戒」是指僧團法事沒有缺陷，「得罪」則是違背了本來的戒制。如果這樣的話，中國五人受戒也可以比照這個例子嗎？回答：中國本來就沒有開許，不能互相比照。從「此」字以下，指明法義的出處，《摩得勒伽論》（《伽論》）也是這樣說。第四項「大眾和合聚集」。文句依據很明顯，可以理解。第五項之中，從「則」字往下的兩句，暫且概括了四種非法的羯磨。或者昏昧於法綱因緣，或者單純照本宣讀、拘謹背誦，都無法成就如法羯磨，所以說「等等」。第六項之中，《業疏》說：內心欣慕殊勝戒法，外在假借殊勝威儀；身相與心念相互依存，猶如魚在水中一樣。

【993-0003】資持記/04a_上三#22
【原文】問：與能受中第四何異？答：前約小眾容儀，此據大僧道具，能所內外，豈不明乎！統上六緣，還歸四種；人法事處，單複配之。又前五不具，定不成受。第六有闕，容多諍論；若準祖意，例亦不成，如後委辨。又準《羯磨》，復加一種，謂佛法時中。
【譯文】問：這與受戒者自身條件中的第四條有何差異？回答：前面是指初出家小眾的形儀容貌，此處是依據大僧應具備的道具器物，能受戒與所對受、內心與外相，難道還不明顯嗎！總括上述六種緣，終究回歸為四種要素：人、法、事、處，以單一或複合來相配對。此外，前五條如果不具備，必定無法成就受戒。第六條如果有欠缺，可能會引起諸多爭論；但如果依照祖師的旨意，照例也是不能成就的，如同後文詳細辨析。再者依照《羯磨》的說法，又另外增加了一種條件，即「處於佛法住世之時」。

【993-0004】資持記/04a_上三#23
【原文】《毘曇論》云：若至法滅，一切結界受戒，皆失沒故。第三緣者。上並旁助，此正因本。必須開悟，方堪進受。若論發乞，合是兩緣；心口雖殊，希求義一，故合之耳。文下，引示。律中佛言教乞戒而不乞，不得受具足。
【譯文】《阿毘曇論》說：如果到了佛法滅盡之時，一切結界與受戒的法效，都會徹底喪失泯滅。第三條緣「發起請求的心願」（第三緣者）。上面那些都是從旁資助，此心才是正因本質。受戒者必須心開意解領悟，才能夠進一步領受戒體。若分開論述發心與乞戒，本該是兩種緣；但心念與口述雖然不同，希求戒法的意涵卻是一致的，所以合併為一條。鈔文下方，是引用律文說明。律中佛陀說：教導乞戒而不肯乞求的人，不得給予受具足戒。

【993-0005】資持記/04a_上三#24
【原文】又云：時有強與授戒，後便逃走還家，佛言不得強授人具足戒，即無心也。四心境者。無別緣相，即合二三相對以論，計有四句。標即俱如，是今正取；俱非，易解；止明二互。初句，先引律緣，眠醉狂三，皆因受已後覺返道，佛並制斷；心俱無記，正缺戒因；無心同上。
【譯文】律中又說：當時有人被強迫授予戒法，事後便逃跑回家，佛陀說不得強迫他人受具足戒，這就是因為受者無心求戒。第四項「心境相應」（四心境者）。沒有特殊的緣相，就是將第二項所對之境與第三項發心相對來討論，總計有四種情況。標題所立的「兩者皆如法」，是現在所要選取的正軌；「兩者皆非法」，很容易理解；此處只說明兩者互有出入的兩種情況。第一句，先引用律典記載的因緣，睡眠、沉醉、發狂三種人，都是因為受戒清醒之後反悔還俗，佛陀全部制止斷絕為其受戒；因為其心處於無記狀態，正恰缺乏了納受戒體的正因；「無心受戒」的情況如同上面所述。

【993-0006】資持記/04a_上三#25
【原文】若準《多論》，通列四心，善惡無記及以無心；文收二種，善惡準之。復下，次句；文中略引人法二非，事處亦爾。薩下，引證。文但明心，義必兼境。重心者即上相應。輕心者即眠醉等。教無教者，即是成宗作與無作，會釋名義，委在中卷。五中。通括前後具緣正加，一一無違，方成究竟。初約正受釋。
【譯文】若依據《薩婆多論》，通泛列出了四種心：善心、惡心、無記心以及無心受戒；此處鈔文只收錄了無記心與無心兩種，善心與惡心可以依此推知。從「復」字以下，是第二句；鈔文中簡略引述了能授之人與所用法式兩方面的非法，事相與處所非法也是同樣的道理。從「薩」字以下，引用經論作證明。論文明面上雖然只說明能緣之心，但義理上必定兼顧所緣之境。「重心」就是指上面所說的心境相應。「輕心」則是指睡眠、酒醉等狀態。所謂「教與無教」，就是成實宗所說的作戒與無作戒，融會解釋其名義，詳細內容記錄在中卷。第五項「事成究竟」（五中）。總體概括受戒前置具緣與正加羯磨的整個過程，每一項都毫無違背，才算成就圓滿究竟。首先約定就正受戒時來解釋。

【993-0007】資持記/04a_上三#26
【原文】言始從者，總攝八緣；終至者，正納法體，共為九法。下列十緣，除初及三，但取八種，如下明之。言往來者，行事出入施造之相。界下，二約具緣釋。略舉心境以明成否。引證中。上列諸緣，皆依律本。此但通證立緣簡辨非無所據，至論列相，不必全同。初《母論》中。
【譯文】所謂「始從」，總括了八種緣；「終至」，是指當下正納受無作戒體之時，總共構成了九種法事。下文所列的十種緣中，除去第一種與第三種，只取其餘八種，如同後文說明。所謂「往來」，是指行事過程中出入進退、施作造作的相貌。從「界」字以下，第二部分約定就具緣方面來解釋。簡略舉出受戒者的心念與外境，用以說明受戒能否成就。在引用教證的文段中，上面所列舉的種種緣，都是依據律藏原本。此處只是通泛證明建立受戒條件、簡別是非並非毫無依據，真要論及各家所列的相貌，倒不一定完全相同。首先在《毘尼母論》之中。

【993-0008】資持記/04a_上三#27
【原文】總束五緣，不過人法，略證所對三四五也。次引《多論》。唯明邊難，略證能受第三一緣。然其邊罪，律據具戒；論通白衣，故約三戒次第明相。初列三受。隨下，顯難。文出破五，即障餘三；中間省略受十不得，故云乃至。破八障二，破十障一，第論可知。然五八戒相，不分輕重；
【譯文】總括歸納為五條緣，不出人與法兩個範疇，簡要證明了前述所對之境中的第三、第四、第五項。接著引用《薩婆多論》，單純說明邊罪之難，簡要證明受戒者自身的第三條緣。然而所謂邊罪，律藏是依據受具足戒之後來論斷；論典則通及白衣居士，所以依照五戒、八戒、十戒三種戒法次第來說明其相貌。首先列出三種受戒身分。從「隨」字以下，顯露其罪難所在。論文明言破犯五戒中的重罪，就會障礙受持其餘三種戒法；中間省略了受持十戒而不可得的文句，所以說「乃至」。破犯八戒則障礙其餘兩種，破犯十戒則障礙受具足戒一種，依此類推可知。然而五戒與八戒的戒相，本身並不分輕罪重罪；
