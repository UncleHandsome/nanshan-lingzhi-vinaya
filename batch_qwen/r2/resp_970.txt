整體看下來，譯文對科判（「某字以下」「初…次…」）的處理清楚，大方向也多能掌握；主要問題集中在三類：**（1）「濫」「通」「別眾」等術語訓解偏差**、**（2）無據的增譯推測（水波形、個別處所、大門內相之外等）**、**（3）加「罪」字與過度潤飾造成的語意走樣**。以下逐則列出。

---

## 970-0001

1. **「此門上科」→「此門的第一科」**
 「上科」指本門**前面那一科**（即上文列舉諸種界形之文），不必是「第一科」。建議：「此門前面一科，即是『標』」。
2. **「界形與相」→「界形與標相」**
 下文答文明白把「標／體／相」三分，問句的「相」正是三相中的「相」，加一「標」字反而與答文衝突。建議照譯「界形與（界）相」。
3. **「不論形相」→「不論外在地形相貌」**
 「形相」宜作「界形界相（形狀相狀）」，「地形」是添義。
4. **「約人別居」**：譯「人員個別居住」用語偏行政化，可作「就『人』各別居住而立（不從形狀上分）」。
5. **「時所多行」→「當前世人最常行事的地方」**
 「多行」是「多數通行、多被採用」，非「最常行事」。建議：「是當時多數採行的兩種處所」。
6. **「唱相，離過，敘由中」**是三重科判，建議斷開：「『唱相離過』中，先明『敘由』（敘述緣由）……」，比現在串成一句清楚。
7. 「空有兩處」保留術語較好：「空（空野、蘭若）、有（聚落）兩處」。

## 970-0002

1. **「出濫相」→「浮濫的具體相貌」**（關鍵）
 此處「濫」是**混濫、訛濫**（界相混淆不清），不是「浮濫（過多）」。建議：「指出混濫（錯誤）的情形」。
2. **「寺門當垣牆之間」→「正好建在圍牆中間」**
 易被讀成「牆的中段」。原意是**門設在牆身厚度的中間，門面未與牆內外齊平**，故下句才說「必若寺門齊牆內外，亦無此患」。建議明寫此意。
3. **「無別眾患」→「破壞和合別眾的過患」**
 「別眾」是羯磨時**僧不全集（有人在界外未與欲）致作法不成**，與「破和合僧」不同，不宜用「破壞和合」釋之（0004 更譯成「分黨別眾」，問題更大）。建議：「沒有（僧）別眾的過患」。
4. 「外唱／內唱」譯作「唱告外側／內側界相」偏含糊，建議統一為「沿牆外緣唱相／沿牆內緣唱相」（此點請對照鈔文與下圖再確認）。

## 970-0003

1. **「遮濫」→「遮止瑣碎浮濫」**
 同上，「濫」是混濫；此段正是要**防止「隨屈曲」一語被濫用**（曲折深遠者仍須立標相）。建議：「遮止混濫（防其濫用）」。
2. **「曲折深遠」→「曲折幽深遼遠」**：「幽深」屬文學性添飾，宜作「曲折多而長遠」。
3. **「分齊分明」→「極為分明」**：「極為」是加程度；「分齊」即分際界限，照譯即可。
4. **「恐成繁累，略云隨屈曲者，亦無有過」**
 現在「唯恐……只要……」的句法鬆掉了因果。建議：「（若一一唱出）恐成繁瑣累贅，那麼簡略說『隨其屈曲』，也無過失」。
5. **「牒入相中」→「一一宣讀寫入界相之中」**：「牒入」是列入（唱相文中），「宣讀」為添義；「計其尺寸」也不必限定為「圍牆長度」。
6. 「初出彼唱」的「彼」承上是指**他人不如法的唱法**，建議補「（錯誤的）」以免中性化。

## 970-0004（本則問題最多）

1. **「以與欲出界，失法成別」→「若與欲委託後走出大門內相之外，就喪失了作法效力，構成分黨別眾」**
 三處可議：①原文無「大門內相之外」，此為推測性限定；②「與欲後走出」暗示時序，原意重點是**已與欲而身在界外，欲法失效**；③「分黨別眾」嚴重誤導。
 建議：「因為已與欲而人在界外，（與）欲之法失效，便成別眾。」
2. **「別眾罪」「破夏罪」**：別眾是作法不成之過、破夏是安居被破，皆非罪名，「罪」字宜刪（「離衣」補「宿」字則可，屬合理注釋）。
3. **「遙指暗唱」→「遙遙虛指、暗中默唱」**
 「唱相」必出聲令眾聞，「默唱」自相矛盾。「暗唱」是**含糊籠統、不明示地唱**。建議：「遠遠指點、含糊而唱」。
4. **「突吉羅（輕垢罪）」**：「輕垢罪」一般用於菩薩戒；突吉羅宜注「惡作（輕罪）」。
5. 「蘭若」首次出現宜加註（空野寂靜處），與 0007「空野」譯法統一。

## 970-0005

1. **「水波形標石」**（關鍵）
 原文只作「水波一丈五尺」，「水波形」是譯者添加的形狀描述，無文獻依據。建議保留原詞：「《明了論》說『水波一丈五尺』，是指標石與標石相隔的距離，不是說石頭的長短高下。」（「水波」為《了論》所列界相之語，可另加註待考。）
2. **「通舉兩損」→「通體指出兩種損害」**：「通體」不成詞，應作「先**總**舉兩種損害」。
3. **「損中尤甚故」→「諸多損害之中」**：上文既言「兩損」，應作「在這兩種損害中，此者尤為嚴重」。
4. **「陷他／自陷」→「陷害他人／自己陷害自己」**：「陷害」含惡意構陷義，此處是**陷誤他人、自身陷墮罪業**。建議：「上二句解釋陷誤他人，『自』字以下二句說明自身陷墮」。
5. **「違教雖輕，結業彌重」**：「彌」是**更加**，「極其深重」失了比較；「看似」也是添加。建議：「違背佛制，罪相雖輕，結成的業卻更重」。

## 970-0006

1. **「舊住」→「久住的老比丘」**：「舊住」只表久住該寺，不表年臘高，「老」字宜刪。
2. **「斯為通論」→「通達圓融的定論」**
 「通論」與上句「豈局主客」的「局」相對，意為**通泛不限之說**，非「通達圓融」。建議：「這是通泛（不限主客）的論斷，確實可以依循」（「依循遵循」亦嫌重複）。
3. **「相當者」→引號作「彼此相當」**：鈔文只作「相當」，引號內不宜增字。釋義本身可，但「終究要與原點相合」宜作「首尾回還相合」。
4. **「律下，遮濫」→「遮止雜亂執著」**：仍應統一為「遮止混濫（恐人誤執）」，與下則「恐執律文」正好呼應。

## 970-0007

1. **「恐濫為別故」→「唯恐稱名混淆而被誤認為是個別處所」**（關鍵）
 「個別處所」純屬推測。此「別」應與羯磨法之「別（眾／別人法）」相關，且下引《業疏》「莫非成僧」正是就**僧法成立**而說。建議保守處理：「怕混濫而成『別』」並加註待考，勿逕譯為處所。
2. **「以羯磨牒唱」→「羯磨文中既然要一一宣告唱出」**：語意含混，宜作「因羯磨文中已牒舉而唱」。
3. **「莫非成僧」→「成就如法僧團」**：應是「成就僧法（作法）」，非成立僧團。
4. **「故知不局」→「並非死板拘束」**：宜明說「可知並不局限（稱名、不稱名皆得）」。
5. 「四維」建議加註「四隅（東南、東北、西南、西北）」，與「方（四正）」對顯，讀者才懂「起方／起維」之別。
6. 「紕謬，猶錯亂也」→「錯亂顛倒」：「顛倒」為添義，作「錯亂」即可。

## 970-0008

1. **「雖非鈔意」→「雖然不完全符合鈔文原意」**：原文是直判「非鈔意」，「不完全」淡化了語氣。建議：「這雖不是《鈔》文本意」。
2. **「義須準用」→「在法理上應當推準採用」**：「推準」生硬，可作「依理應可準此採用」。
3. **「禮僧等相」**：「問訊」為增譯（雖合情理），若要嚴謹可作「禮拜僧眾等事相」；「相（事相）」未譯出。
4. 「起角處，則云從此」引號作「從此處起」亦屬增字；「餘處不著」加「平直」二字為推測，可刪。
5. 「城邑市區」用語偏現代，可作「城邑（聚落）」。

## 建議統一的術語

| 原文 | 現譯（不一致） | 建議 |
|---|---|---|
| 濫／遮濫 | 浮濫／瑣碎浮濫／雜亂執著 | 混濫；遮止混濫 |
| 通（通論、通舉） | 通達圓融／通體 | 通泛不限；總舉 |
| 別眾 | 破壞和合／分黨別眾／別眾罪 | 別眾（僧不全集，作法不成） |
| 破夏 | 破夏罪 | 破夏（安居被破） |
| 陷他／自陷 | 陷害他人／自己陷害自己 | 陷誤他人／自身陷墮 |
| 唱相／外唱／內唱 | 唱告界相／唱告外側界相 | 唱（界）相；沿牆外緣／內緣唱相 |
| 空處／空野／蘭若 | 空處／荒野空地／蘭若 | 一律加註「空野（蘭若）」 |

**需回查鈔文、《業疏》再定案的三處**：①「水波一丈五尺」的「水波」何義；②「恐濫為別」的「別」所指；③「外唱／內唱」究指唱牆外緣／內緣，或唱文中「出／入」之別（0008「望前為出，至後為入」可為線索）。這三處 presently 的譯文都属「猜測性落實」，建議先保留原詞加註，比逕行具體化安全。
