整體讀來通順，科判用語也大致掌握住了。但有幾處**實質誤譯**和**原文無據的增字**，建議修改。以下按嚴重程度與段落分別列出。

---

## 一、明顯需要改的三處

### 1. 【0006】「得心已決」譯成「盜心既然已定」——誤譯

> 原文：《善見》**得心已決**，微動即犯，不待離處。
> 譯文：《善見律》認為**盜心既然已定**，物品稍微移動就構成犯罪。

「得心」＝「得物之想（認為已到手）」，不是「盜心」。同段上文才剛說「本主來逐，**心未得**者輕〔即文中所謂**未作得想**也〕」，正是與此相對：未作得想→輕；得想已決→微動即重。盜心從一開始就有，不能作為此處「微動即犯」的判準。

建議：**「《善見》說：若『已得（到手）』之想已經確定，稍微移動就成犯，不必等到離處。」**

### 2. 【0005】「或如下」是科文用語，不是「或者如同下文」

> 原文：**或如下**，次準本律，約損色犯。
> 譯文：**或者如同下文**，其次依照本律……

資持記慣用「Ｘ下」標舉鈔文（同段有「《善見》下」「若下」「如下，舉喻」）。此處指鈔文「**或如……**」以下那一段，故應譯：

**「（鈔文）『或如』以下，其次依本律（《四分》），就損色而結犯。」**

### 3. 【0001】「不足五錢」原文無據

> 原文：一偷蘭者，**自作犯也**。自下，釋結蘭義；恐疑**共盜**，應須犯夷故。
> 譯文：得一個偷蘭遮罪，是因為自己親手偷盜**不足五錢**而犯。

原文給的理由只有「自作」，下一句的對比是「**共盜**（應犯夷）」，可見重點在「自作／共盜」之別，不在錢數。「不足五錢」是譯者自行補入，且與文理不合，建議刪除。

另兩點：
* 「一偷蘭者」的「一」應是列項序號（第一項明偷蘭），不是「一個」罪。
* 「自下」很可能也是科文＝「『自』字以下」（與「若下」「或如下」同例），譯「從此往下」宜再斟酌。
* 括注「重大未遂」太窄，偷蘭遮通於方便與果頭，建議注為「粗惡罪，次於波羅夷」。

## 二、斷句／指稱可疑

### 【0005】「初引《十誦律》論」

譯成「引用《十誦律》**的論述**」，把「論」附屬於律名，很可疑。資持記中「論」多指《善見論》（0003「論作書字」、0004「準論」皆然）。較可能的讀法是：

* 「初引《十誦律》、論」＝先引《十誦律》與《善見論》；或
* 「論」作動詞＝「先引《十誦律》，論約異色而犯」。

建議核對鈔文所引來源後再定，不要逕譯為「十誦律的論述」。

### 【0003】《善見》的名稱前後不一致

《善見》＝《善見律毘婆沙》，是**論**。譯文一會兒稱「《善見律》」，一會兒又說「**原論**中作書字」，讀者會混淆。建議統一作「《善見論》」或首見處加注。

## 三、增字與語意含糊（建議修）

| 段落 | 譯文 | 問題 |
|---|---|---|
| 0002 | 「依照現今的**判例**」 | 「今所判」指**今家（南山道宣）所作的判定**，「判例」是現代法律術語，易誤導。 |
| 0002 | 「若將重物**故意**判為輕物」 | 「故意」原文無，雖合意仍屬添加。 |
| 0002 | 「**律師**」 | 指通達戒律的比丘，非現代律師，宜加注。 |
| 0002 | 「裁斷物品的**輕重**」 | 宜注明：重物＝不可分（屬四方僧）、輕物＝可分（屬現前僧）。否則「判重為輕犯夷」會被誤讀成罪刑輕重。 |
| 0002 | 「**歷**疏告眾」 | 漏了「歷」＝逐一、遍列。可作「逐項列入疏文，通告大眾」。 |
| 0003 | 「因為彼此**心意相同**」 | 「同情」＝**同有盜心**，宜明說。 |
| 0003 | 「一頭輕的／兩頭重的」 | 直譯太隱晦，可補：只寫起點一端→蘭；兩端都寫→夷。 |
| 0004 | 「能判之人**犯重罪**」「被判得之人**犯重罪**」 | 原文只作「犯」，未標罪相。若無鈔文明文依據，建議只譯「犯（盜罪）」。 |
| 0004 | 「**甚至**偷盜十個標記」 | 「乃至」＝以至、推及，非「甚至」。 |
| 0004 | 「使**分發的物資減少**」 | 「令物少」應指**他人（或僧）分得之物減少而己多得**，譯文未點出關鍵。 |
| 0005 | 「以盜竊之心**暗中**移動骰子」 | 「暗中」為添加。 |
| 0005 | 「隨著**牽涉的財物**而構成犯罪」 | 「隨物成犯」＝隨所賭得之物的價值（滿五錢等）而結罪，宜譯明確。 |
| 0006 | 「四足全部**走過**就犯重罪」 | 應是「四足都跨過（到達）所預期的處所」，與下文「本期不定，舉遍即重」（四足皆舉離本處）才成對比。 |
| 0006 | 「原本預定的界限**不明確**」 | 「本期不定」＝本來的預期目標**未確定**，非「不明確」。 |
| 0006 | 「說明賭博的**過失**」 | 「明賭博」只是說明賭博（為盜相之一），「過失」可省。 |

## 四、小結

* **必改**：0006「得心已決」、0005「或如下」、0001「不足五錢」。
* **待核**：0005「《十誦律》論」的斷句、0001「自下」的所指、0004「犯重罪」的依據。
* **通則**：
 1. 嚴守「者…也」判斷句與科文「Ｘ下」的讀法，不要把科判標記當白話連接詞。
 2. 少補原文沒有的限定語（不足五錢、故意、暗中、過失、重罪）。
 3. 律學名相（律師、重物輕物、生地、同情、隨物成犯）寧可加短注，不要用含混的白話帶過。
