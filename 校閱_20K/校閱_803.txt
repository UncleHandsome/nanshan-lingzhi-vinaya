# 校閱材料　第803檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】三者，文云「疾疾結之，恐遮人出界也」，立相容遮，終非結意，餘如文解
【譯文】第三、律文說「應當急速結界，唯恐前來遮難之人走出界外」，樹立標相容易容留遮難，終究不是結小界的本意，其餘的如文中所解釋。

【803-0002】03_業疏/08b_卷二之二#17
【原文】三中，準文立義。若立標相，事容遲緩，遮人即至，結法不成。下指文解，即第五門
【譯文】在第三段中，是依照律文建立義理。如果樹立標相，作法過程就容有遲緩，阻礙之人隨即來到，結界之法便不能成就。下文指示參照正文的解釋，即是第五門。

【803-0003】03_業疏/08b_卷二之二#18
【原文】四、結解同異者，又上總門第四義也。大界結時竪相，解時牒二捨之，則解不類結。如上三小，結解相應者：一、現作非未來，二、暫時非久固，三、無相為遮訶，故小界與人處相相應也。結者成解，餘人不得，若起迷方，無由重捨，故佛制「不應不解而去」，誠有深致
【譯文】第四、「結與解的同異」，這又是前面總門中的第四個義理。大界在結界時樹立標相，在解界時宣讀「二同」而捨棄之，那麼解界與結界的形式並不完全雷同。而如前述的三種小界，結與解是相互呼應的：第一、現前作法而非留待未來，第二、暫時一用而非長久穩固，第三、不立標相以阻絕訶止，所以小界與人、處、相都是相應的。結界的人才能成辦解界，其餘的人不能解；如果離開後迷失了方位界域，就無法重新解除，所以佛陀制定「不應當不解界就離去」，確實含有深遠的旨趣。

【803-0004】03_業疏/08b_卷二之二#19
【原文】四結解中，初標指。前後諸界皆有結解一科，屬前第四義門，故一一提示。「大」下，對明同異，初敘異。前以大界結解皆牒二同，故云相類；此望解時不牒標相，且云不類，欲彰小界無相所以，故躡以問之。「一」下釋通，初列示三義，反前大界；「故」下，結顯異相。「人處相」者，處即界體。下引制解，益彰無相
【譯文】在第四「結解」中，首先標示指出。前後各界都有結與解這一科，屬於前面第四義門，所以一一提示。自「大」以下，相對說明同異，首先敘述相異之處。前面以大界在結與解時都宣讀二同，所以說彼此相類；此處考量到解界時不宣讀標相，姑且說互不相類，是為了彰顯小界不立標相的原因，所以藉此發問。自「一」以下解釋會通，首先列出三種意義，以反襯前面的大界；自「故」以下，總結顯示相異之相。「人處相」中，「處」就是界體。下文引用制令解界之文，更加彰顯不立標相之義。

【803-0006】03_業疏/08b_卷二之二#21
【原文】初緣分三界，在文可知
【譯文】第一、起緣分為三種小界，在正文中即可明白。

【803-0007】03_業疏/08b_卷二之二#22
【原文】第五初指三緣。注中受戒一種，界內不和，潛出界外，文不顯處，義必空野；說、恣二種，並因道路無村曠野，非村蘭若，語少異耳。注云「類諸難開」，謂如諸戒命、梵緣開，非難擅行，無非正犯
【譯文】第五門最初指明三種起緣。註解中受戒這一種，是界內僧眾不和，暗中走出界外，文中沒有明言處所，但義理上必然是空曠野外；說戒與自恣這兩種，都是因為行在道路且在無村曠野中，即非村落的蘭若，只是文詞稍有差異罷了。註解所說的「比類各種難緣之開許」，是指如同諸條戒律在命難或梵行難時開許，若非遇到難緣而擅自行持，無一不是實際犯戒。

【803-0011】03_業疏/08b_卷二之二#26
【原文】大小二界，緣難有無，標相寬狹，終不徒立。文中「羯磨不成」者，以法事相違也。界以標相為體，大界無難，作法具儀，先唱標域，後依加結，乖不成也；小界怱急，不明立相，恐訶人至，納在相中，隨集約身，一時唱結，有乖斯法，理是壞緣
【譯文】大界與小界這二種界域，難緣之有無、標相之寬狹，終究不是徒然設立的。文中說「羯磨不成」，是因為作法與事相相違背。界域是以標相為其體性，大界沒有難緣，作法具足威儀規範，先宣唱標界地域，然後依之加法結界，若有乖違便不能成就；小界因情勢倉卒緊急，不明確樹立標相，唯恐訶止之人來到而被收納在標相界內，只能隨集合之眾約身為界，一時宣唱結成，如果有乖於此法，在理上便是敗壞了成辦的因緣。

【803-0012】03_業疏/08b_卷二之二#27
【原文】三明非法通明中，初標示二界不同，如注對顯。「文」下牒釋，初通示。「界」下別釋，前明大界須相，不立則非；後示小界無相，立則乖法
【譯文】在第三「明非法」的通明中，首先標示二界的不同，如註解相對顯明。自「文」以下引文解釋，首先通途指示。自「界」以下分別解釋，前面說明大界必須有標相，不立標相則是非法；後面指示小界沒有標相，若立標相就乖違法式。

【原文】下明四過者
【譯文】以下說明四種過失。

【803-0014】03_業疏/08b_卷二之二#29
【原文】初非開緣，專權結小，違佛教也。如諸難緣，界外持欲；儉開八事；離衣道斷，持通九等之流，雖是曲被，未可常行。依法用之，則一切智，故文云「制已更開，開已還制」，義須憑準，何得自矜
【譯文】第一、若非開許的難緣，擅專結小界，這是違背佛陀的教法。正如各種難緣之下，因難緣經由界外傳持欲意（持欲出界）；饑饉時開許八事；離衣遇道路阻斷，持守之制普通於三根九品之類，雖然是委曲拔濟，但不可常行。依照教法合時運用，才體現佛陀是一切智人，所以文中說「制定之後又予開許，開許之後復又禁止」，在義理上必須有所依憑準則，豈能自我矜誇擅作主張。

【803-0015】03_業疏/08b_卷二之二#30
【原文】次四過中初過為二：初明違教，權猶擅也。「如」下引類，為他持欲，難緣出界，開不失法；儉開八事：內宿、內煑、惡觸、殘宿、僧俗二食、水陸兩果、不作餘食法，由有儉緣，不作不犯；忘不持衣，歸護不及，或水陸道斷，並開無罪；九等，即三根中各分三品，上根守制，專持不犯，中下不堪，故須曲被。「依法用」者，緣至則開，緣盡還制，開制隨時，則彰如來是一切智人也。故下引證，即迦葉答富那羅之語，如《鈔》、《記》引。「義」下，誡斥，自賢曰矜
【譯文】在接下來的四種過失中，第一種過失分為兩部分：首先說明違背教敕，「權」就是擅專的意思。自「如」以下引述同類情況：為他人持欲意時因難緣而出界，開許不失作法；饑饉時開許八事：內宿、內煮、惡觸、殘宿、僧俗二食、水陸兩果、不作餘食法，由於有饑饉難緣，不作殘食法等也不算犯戒；遺忘未帶衣物，回去守護已來不及，或者水路陸路斷絕，都開許無罪；「九等」即是上中下三根各分為三品，上根持守制定，專心持戒不犯，中下根不堪忍受，所以必須委曲拔濟。「依法用」是指難緣到來時便開許，難緣結束時復歸禁制，開許與禁制隨順時機，就彰顯了如來是一切智人。所以下文引證，即迦葉尊者回答富那羅的話，如同《行事鈔》與《資持記》所引用。自「義」以下是誡勉斥責，自以為賢能就叫做「矜」。

【803-0016】03_業疏/08b_卷二之二#31
【原文】言輒立相者，古師傳用：自恣圓坐，五德在中；說戒直立，開無眾具，故《僧祇》云「行住坐臥悉成布薩」，《十誦》亦然；及作受戒，相如熨斗柄，是中問遮
【譯文】談到擅自樹立標相，古德相傳的做法是：自恣時僧眾圍繞圓坐，五德比丘在中間；說戒時直立，開許沒有眾多坐臥用具，所以《僧祇律》說「行、住、坐、臥都能成就布薩」，《十誦律》也是如此；等到作受戒時，標相就像熨斗柄的形狀，在柄中訊問遮難。

【803-0017】03_業疏/08b_卷二之二#32
【原文】二中初科，自恣對跪須坐，說戒隨聞故立，二律所明，四儀通得。古謂說、恣宜不立相，受戒問難事須立相，故云「如熨斗柄」也
