# 校閱材料　第598檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【598-0001】資持記/12a_中四下#2
【原文】然懺通化制及以理事，今此且據制教事行以為篇目。敘來意中，初科為二，初敘懺意，上句明造業。且約篇聚所制二犯之罪；結業成因，必招來果，故如種焉。次句明須懺。以犯從妄起，罪假緣生；妄體本空，緣生無性；了知妄本，則犯相何依！識達緣生，則罪根叵得。是以忽追所犯，深恨前非；
【譯文】然而懺悔通於化教與制教，也兼具理懺與事懺，如今本篇姑且依據制教的事相行持來立為篇目。在敘述開展此篇的意圖中，第一科分為兩部分：首先敘述懺悔的意旨，上一句說明造業。此處姑且就篇聚戒相所制定的「由作而犯」與「由止而犯」這二種罪行而言；造業凝聚成因，必定會招感未來的苦果，所以如同播下種子一般。下一句說明必須懺悔。因為犯戒是從妄念生起，罪過是憑藉因緣而生；妄念的本體本來是空寂的，因緣所生之法也沒有固定不變的自性；既然徹底明瞭妄念的根本為空，那麼所犯之罪相又要依託何處！如實照見因緣生法無有自性，罪業的根源便不可尋得。因此忽然追悔所犯之過，深深痛恨先前的非行；

【598-0002】資持記/12a_中四下#3
【原文】仰對勝緣，盡披肝膽。罪從心起，還逐心亡；既伏現因，不牽後果。犯而不悔，業苦何窮。有智識非，義無隱覆故也。則下二句彰益。上句自行無瑕，下句眾法有用。故下，引勸；前引論文勸速改，初引論；不下，申勸。彼論問曰：何法重於地？何法高於空？何法多於草？何法疾於風？
【譯文】恭敬仰對殊勝的境界與對象，毫無保留地剖露肺腑、徹底發露。罪業是從心念生起，自當還隨著自心止息而消亡；既然伏斷了現前的惡因，便不再牽引未來的苦果。如果犯了戒卻不求懺悔，所感召的業苦何時才能窮盡。有智慧的人認清了過非，在義理上本就毫無隱蔽覆藏的道理。接續下來的兩句彰顯懺悔的利益。上一句說明自身行持清淨無瑕，下一句說明在僧團各項羯磨作法中皆具備合格資格。因此在下文引據加以勸導；前半段引用論典之文勸勉應當迅速改過，先引論典；自「不」字以下，申述勸誡。那部論典問道：什麼法比大地更重？什麼法比虛空更高？什麼法比草木更多？什麼法比疾風更快？

【598-0003】資持記/12a_中四下#4
【原文】答曰：戒德重於地，我慢高於空，煩惱多於草，心念疾於風。今略引後句以明昔心造惡，今忽追悔，剎那翻善，不待終日。意令有犯速須求懺。次引經文彰佛勸。經明如來訶責示惡之意，欲令行者有過尋悔。上訶毀禁，令成止行；下說惡道，令成作行。斥古中，初示非。
【譯文】回答說：戒德比大地更重，我慢比虛空更高，煩惱比草木更多，心念比疾風更快。如今大略引用最後一句，用以說明往昔之心造作了惡業，現今一旦追悔，剎那間便能翻轉為善念，用不著等待整日。用意在於令有犯戒者必須儘速求懺悔。接著引用經典之文彰顯佛陀的勸勉。經文中說明如來呵責並開示惡行之意圖，是想令修行人有了過失隨即悔改。前半段呵斥毀犯戒禁，是為了促成止持之行；後半段宣說墮入惡道之苦，是為了促成作持之行。在斥責古師說法中，首先指出其謬誤。

【598-0004】資持記/12a_中四下#5
【原文】遂，往也。古師即指諸家集羯磨者。如僧鎧羯磨：初出懺殘；二懺偷蘭，白二法懺，不分重輕；三懺捨墮，不簡單提；四懺餘罪，不顯罪相；提舍吉羅，並不出法。又曇諦羯磨：初亦懺殘；二懺捨墮；三懺餘罪，謂單提、提舍、蘭吉，同一法懺，詞句並同捨墮。事儀加改，謂之增減；
【譯文】「遂」是過去的意思。古師就是指歷來編集羯磨儀軌的諸家學者。例如僧鎧律師的羯磨：最初列出懺僧殘；第二列懺偷蘭遮，採用白二羯磨法來懺，卻不區分罪相的輕重；第三列懺捨墮，卻未將它與單提（單墮）分開；第四列懺其餘之罪，卻不標顯罪相；至於提舍尼與突吉羅，則完全沒有列出懺法。又如曇諦律師的羯磨：起初也是懺僧殘；第二列懺捨墮；第三列懺其餘之罪，也就是將單提、提舍、偷蘭遮與吉羅，全都併入同一種懺法，其詞句完全與懺捨墮相同。在儀軌作法上任意增補改動，稱為「增減」；

【598-0005】資持記/12a_中四下#6
【原文】立法出沒，謂之隱顯。若準下文，則古謂夷罪必須都無覆心，方開懺悔；又唯婬開懺，餘三不開；又僧殘中覆藏別住，或云盡行，或俱不行；又提舍中同懺提法，又眾學罪同皆責心；增減隱顯，尋之可見。臆課多者，責其師心。課猶說也。照教無文，謂事無所據；
【譯文】在立法上隨意隱沒或顯露，稱為「隱顯」。如果依照下文所辨，那麼古師認為波羅夷罪必須在犯後完全沒有覆藏之心，才能開許懺悔；又認為只有犯淫戒才開許懺悔，其餘三條重罪則不開許；又在僧殘罪中對於覆藏後的別住法，有的主張應完全依律行持，有的卻主張一概不行；又在提舍尼中混同單提之法來懺，又將眾學罪全都等同於責心懺；種種隨意增減與隱沒顯露，尋究其文便可看清。至於責備「私自度量揣測過多」，是斥責他們全憑個人成見。課，就如同解說。對照聖教卻查無明文，是指行事毫無聖教依據；

【598-0006】資持記/12a_中四下#7
【原文】撿行違律，謂行用非法。故下，引斥。即律〈增二〉中，明二種愚人。初人抱過不悔，次人悔不依教；今取次人，證上非法。律文又出二種智人，與愚相反，如下科引。聖下二句，示師心所以。上句示後悔法，皆見律文；下句顯前諸師不能依用。顯今中分二，初敘撰述，上一句正示。
【譯文】檢視行持卻違背律制，是指行儀運用全屬非法。因此在下文引律斥責。即是律典〈增二〉之中，說明了二種愚癡之人。第一種人抱守過失不肯悔改，第二種人悔改卻不依循聖教；如今選取第二種人，用以印證上述古師之法屬於非法。律文中又提出二種有智慧的人，恰好與愚人相反，將在後面的科判中引用。「聖下」這兩句，揭示了古師全憑個人成見的緣由。上一句指出後續悔罪的法則，在律典明文中全都能見到；下一句彰顯前面的諸位大師不能依律採用。在闡明今時正見中分為兩部分，首先敘述撰述的意旨，上一句是正面開示。

【598-0007】資持記/12a_中四下#8
【原文】定綱位者，六懺差別，不相濫故。格心境者，各顯緣法，無所昧故。隨一懺中，緣法雖多，不出心境。如下所示，慨過陳露，即能懺心也；託處對人用法等事，皆屬所對境也。格即訓正。下二句顯意。上句明立法有準。今古相形，是非鏡矣。下句示行事無疑。心境相照，得失彰矣，能所即心境也。
【譯文】「定綱位」的意思，是使六聚懺法各自的位次井然有別，不致互相混淆。「格心境」的意思，是使各篇緣起與作法各自彰顯，毫無模糊曖昧。在任何一個懺法之中，因緣作法雖然繁多，終究不出能懺之心與所對之境。如同下文所示，為自身過非感慨並陳白發露，就是能懺之心；依託處所、對向僧人、採用如法之羯磨等事，都屬於所對之境。格，訓詁為匡正。下兩句彰顯立法的意旨。上一句說明立法必須有所遵循。將今正與古謬互相對照，是非對錯便如明鏡般清楚了。下一句指出實際行事毫無疑惑。心與境相互映照，得失自然顯露，能與所指的就是心與境。

【598-0008】資持記/12a_中四下#9
【原文】此下二句，隔句對釋上文二句，尋之可見。則何下，次彰功益。明今依法，罪必可除，心有所寄；翻前違律，悔罪不出，臆課無憑，故云何患等。為聖歎者，順佛語故。故下，引律示歎。以命能懺為智人故。次明懺法，總分中，化教。具兼兩懺，通被二眾，如文所敘；又復二懺通大小乘；
【譯文】此處緊接的兩句，是隔句對應解釋上文的兩句，細尋便可明瞭。「則何下」接著彰顯其功德利益。說明如今依循正法，罪業必定得以消除，內心有所依憑寄託；翻轉了先前違背律制、悔罪無法出罪、隨意揣度毫無憑據的困局，所以說「何必擔憂」等語。「為聖人所稱歎」，是因為順應佛陀言教的緣故。因此在下文引律以明示稱歎之意。因為律中稱讚能懺悔者為有智慧的人。接著說明懺法，在總體分類中，化教。具足兼備事理兩懺，普遍涵蓋出家在家兩眾，如同文中所敘述；再者事理兩懺通於大乘與小乘；

【原文】又所犯罪，通悔三世，總牒十業。制中。反成五局：言律懺者，局小宗也，如文自述局道眾也；託受生者，局事行也；依初受者，局現犯也；次第治者，局名體也。上且分對，次釋文相，初二句標局。言道眾者，總收出家五位。由下，釋局所以。文敘犯懺，皆依本受；受是稟制；

【原文】此約觀慧推窮業性，明見真理；罪得伏滅，故云懺也。文中初標根性。且望修事，通名利根；若對三觀智用淺深，自分利鈍，如後可見。觀下，示觀行，初句示所觀境。由下，明能觀智，上四句明達妄見理。下二句明行成罪滅。分謂分辨，即觀照也。此中通示理觀；

【原文】無生之言，總下大小三種之理。次事懺中，初標機宜。由下，示懺法又二，初敘不堪理觀。止下，正明事懺，初明事行。不出三業，禮拜旋繞是身業，稱歎誦持即口業，虔仰竭誠等即意業。勝境不出三寶。則下，明成益，上二句示先業。言輕重者，就過為言，五逆謗法用僧物等為重，餘則為輕；
【譯文】「無生」這個詞，總括涵蓋了下文大乘與小乘的三種法理。其次在事懺之中，首先標明所應對的機宜。「由下」指出懺法又分為兩部分，首先敘述根機低劣無法修持理觀。「止下」正式說明事相懺悔，首先說明事相的行持。不出於身口意三業，禮拜與圍繞是身業，稱揚讚歎與誦持是口業，虔誠仰慕與竭盡真誠等就是意業。所依託的殊勝境界不出於三寶。「則下」說明懺罪成滿的效益，前兩句揭示過往的業力。說「輕重」，是就過失本身而言，五逆、謗正法、侵用僧物等屬於重罪，其餘則屬於輕罪；

【原文】諸世間業，皆從我生，我為業主；我既無託，故所造善惡，不從我倒而生；妄業無依，故得除滅。見謂達理，思謂起修，除謂能觀智，滅即所觀業。破妄顯真，而非頓證，故皆云分。若約位判，分見分思，即內凡人；分除分滅，即初果已去。如下，喻顯。眠醉喻迷，醒覺喻悟；
【譯文】世間一切善惡業，都是從自我執著而生起，「我執」即是造業的主宰；既然「我」已無處寄託寄附，那麼所造的善惡之業，便不會從我見的顛倒中滋長；虛妄罪業失去了依託，所以能夠得以斷除消滅。「見」是指通達實理，「思」是指發起修持，「除」是指能觀的智慧，「滅」就是所觀的罪業。破除虛妄而顯發真實，並非一蹴即成，所以都稱為「分」（部分逐步）。若依修行果位來判定，分見、分思，即是內凡位的修行人；分除、分滅，則是證得初果以上的聖者。如同下文，以比喻來顯明。昏睡與沉醉比喻沉淪迷妄，睡醒與酒醒比喻開悟覺知；

【598-0017】資持記/12a_中四下#18
【原文】諸經論中，或約依正因果，或世出世間，或有漏無漏，或色心非色心，或善惡無記，或陰界入等。若據通論，總觀諸法；今就懺悔，且指罪業而為觀境。性空無我一句，即能觀智。罪從緣有，本無自性；緣即心境，虛妄心境和合成業，業性自空，非使之空。由存妄計，故受輪轉；
【譯文】在諸多經論之中，或者就依報正報與善惡因果而言，或者就世間出世間、有漏無漏、色法心法非色心法、善惡無記，或者五陰十八界十二入等來論述。若是通泛論述，則是總觀一切諸法；如今就懺悔法而言，且專指罪業來作為所觀之境。「性空無我」這一句，就是能觀的智慧。罪業是依憑因緣而生起，本來就沒有自性；所謂因緣就是內心與外境，虛妄的心與境和合而形成罪業，罪業的本性自身本空，並非修行者刻意使它變成空。由於存有虛妄的計執，所以才遭受生死輪迴；
