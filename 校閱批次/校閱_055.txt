# 校閱材料　第055檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【055-0001】02_戒疏/03a_卷一下之一#67
【原文】【記】六中云「別緣」者，即自行。「二答」者，下釋云「有犯露答，無犯默答」。
【譯文】【記文】第六段中所說的「各自個人的私自行持」，就是指自己的身心行持。「兩種應對」在下文解釋為「有犯過者如實發露回答，無過犯者安住沈默作答」。

【055-0002】02_戒疏/03a_卷一下之一#68
【原文】【疏】若內實犯，而外表淨，令僧妄解，罪障尤深。是以第七「如是比丘」下，明隱覆之瑕，不實之損，行穢自纏，特由抱過，勸發露也。
【譯文】【疏文】如果內心確實有犯戒，表面上卻裝作清淨無染，讓僧眾產生錯誤的理解，這樣的罪業障礙最為深重。因此第七段「如是比丘」以下，揭示隱瞞覆藏過失的瑕疵，以及不老實面對的巨大損害，行為汙穢作繭自縛，完全是由於懷抱過失不肯放捨，以此勸勉眾人應當坦誠發露。

【055-0003】02_戒疏/03a_卷一下之一#69
【原文】【疏】若順教修，理有深益。是以第八「若彼比丘」下，知犯識懺，還淨上起，三學增明，克成道業，不虗之益也。
【譯文】【疏文】若是順從佛法教導來修持，在義理上具有極深廣的利益。因此第八段「若彼比丘」以下，說明知曉犯戒且懂得依法懺悔，就能重回清淨並使戒行向上生起，戒定慧三學益發光明，必定能成就解脫道業，這是真實不虛的殊勝利益。

【055-0004】02_戒疏/03a_卷一下之一#70
【原文】【記】八中。「上起」即懺悔，名出《了論》，謂翻前犯時居下，故名為「上」；戒法續生，稱之為「起」。「克」，能也。
【譯文】【記文】第八段中。「向上生起」就是指懺悔，名詞出自《二十二明了論》（《了論》），意思是翻轉先前犯戒時身處低劣下墮的境況，所以稱為「上」；戒律善法相續生起，所以稱為「起」。「克」就是能夠的意思。

【055-0005】02_戒疏/03a_卷一下之一#71
【原文】【疏】生起此文，非教本意，講說之家，務傳言相。西梵諸師凡欲敷演，但依文義，廣說所由；至於科約，蓋闕如也。縱有分判，大通無局，如龍樹解《大品》以為二道，天親釋《涅槃》以為七分，須知意也。不可浪事悠悠，費於紙墨，大破正功，無任法利。顧諸學者，可不思哉！今欲消文，就義分之。更有科約，終非大濟，故削略也。
【譯文】【疏文】梳理生起此文的層次，原本並非佛陀立教的根本意圖，而是講經說法的法師為了傳承文義名相所作的施設。印度西方的論師們凡是要講經說法，多半只依循經文義理，廣泛闡述其源由背景；至於科判章節的分割約束，向來大多是缺漏不設的。縱然有所劃分判定，也多是大體貫通而不拘泥細節，例如龍樹菩薩解釋《大品般若經》只統攝為兩道，天親菩薩註解《涅槃經》只區分為七分，我們必須明白這個宗旨。切不可漫無邊際地隨意鋪張，空耗紙墨，嚴重破壞了真實修行的功用，對求取佛法實益毫無幫助。回顧各位參學之人，豈能不深加反思！如今為了消解文句，姑且順著義理加以區分。若再立更多的繁瑣科判，終究對修行沒有實質助益，所以全部予以刪削省減。

【055-0006】02_戒疏/03a_卷一下之一#72
【原文】【記】結略中三，初示意。教本資行，非圖多說，今此敘致，但利講解，故「非本」也。「西梵」下，二、舉中梵例顯，初敘本無。如今藏中大小乘論，止是長途散釋而已。「縱」下，遮妨。其間亦有科判之者，故須此示。「大通」者，謂以義總分；「無局」者，非隨文細碎。「龍樹」下，即《智度論》，釋《大品般若》，彼分二道判盡一經：一、聲聞道，二、菩提薩埵道。「天親」造《涅槃論》，分經為七：一、不思議通達示分，二、成就種性遣執分，三、正法實義分，四、方便修成分，五、離諸放逸入證分，六、慈光善巧住持分，七、顯相分。據彼西梵敷演之式，則知科判本非急要，故云「須知意」也。「不可」下，三、顯略。「浪」，橫也。「費」，損也。「破正功」者，妨自行也。「無法利」者，無益他也。
【譯文】【記文】在總結省略的三個層次中，首先是表明用意。佛教本是為了資助實修，並非貪圖講說得再多，如今這番敘述，只是為了利益講經解說，所以說「並非立教根本」。「印度西方」以下，第二、舉出古印度的先例來顯明道理，首先敘述原本沒有細碎科判。如今大藏經中的大小乘論典，大多只是通篇散文式的隨文解說而已。「縱然」以下是防範疑惑。論典中間也偶有作科判劃分的人，所以必須加以說明。「大體貫通」是指依據義理作總體劃分；「不拘泥細節」是指不隨逐細微文句碎割經文。「龍樹」以下是指《大智度論》解釋《大品般若經》，論中僅劃分兩道就判析整部經：第一是聲聞道，第二是菩薩道。「天親菩薩」撰造《大般涅槃經論》，將全經分為七部分：一、不思議通達示分，二、成就種性遣執分，三、正法實義分，四、方便修成分，五、離諸放逸入證分，六、慈光善巧住持分，七、顯相分。從西域先哲宣講敷演的體式來看，就知道繁細科判本來不是要緊的急務，所以說「必須明白這個宗旨」。「切不可」以下，第三、說明刪削省略的原因。「浪」就是隨便妄作。「費」就是損耗。「破壞真實修行」是指妨礙了自己的修持。「毫無佛法實益」是指無法實質利益他人。

【055-0011】02_戒疏/03a_卷一下之一#77
【原文】【疏】問：「廣說戒法，其必在僧，如何今告，乃言別也？」
【譯文】【疏文】有人問：「廣泛宣說戒法，必定是要面對全體僧團，為什麼現在的宣告稱呼，卻用了稱呼個別對象的用詞呢？」

【055-0012】02_戒疏/03a_卷一下之一#78
【原文】【疏】答：「戒法通收，何隔僧別。望法是僧，望機是別，法被在人，故須問別，不足怪也。」
【譯文】【疏文】回答說：「戒法全面統攝一切，哪裡有僧團與個別成員的隔閡？從法事的角度來看面對的是整個僧團，從教化對象的個人反省來看面對的是各個成員；因為戒法是加被落在每個人身上，所以必須向個別人員發問，這一點不足為奇。」

【055-0013】02_戒疏/03a_卷一下之一#79
【原文】【記】問中。如羯磨告眾，則云「大德僧聽」；單對一人，則云「大德心念」。今此對僧，反彰別號，故須問釋。答文，初二句通示戒法。以制總十方，法分三位，故曰「通收」。「望」下，正答來問。「望法是僧」者，單白廣說故。「望機別」者，檢問自行故。私釋：若準羯磨，初令同聽，乃是告僧；後責同忍，云「諸長老」，亦是問別。今此說戒，前陳單白，已是告僧，後文勅聽，例皆召別。據斯比擬，義無異也。
【譯文】【記文】提問中。好比羯磨法宣告大眾時，就說「大德僧聽」；若是單獨面對一個人，就說「大德心念」。如今此處明明是對著僧團，反而顯現出個別稱呼，所以需要提問辨析。回答的文字中，前兩句通論說明戒法。因為戒律的制定總攝十方，法制分為心念、對首、眾法三種層次，所以說「全面統攝」。「從」以下正式回答提問。「從法事來看是僧團」，是因為這是透過單白通告而廣泛宣說的緣故。「從教化對象來看是個人」，是因為需要大家檢點審問自己行持的緣故。私下補充解釋：如果比照羯磨法，起初讓大家一同聽聞，那是向全僧團宣告；隨後要求大家默許同意，說「諸位長老」，那也是轉向詢問個人。如今這項說戒儀軌，前面陳述單白表白，已經是對僧團的宣告，後文誡敕大眾傾聽，例行都是呼召個別個人。依據這種體例相互對照，義理上並沒有差別。

【055-0061】02_戒疏/03a_卷一下之一#127
【原文】【記】佗解中三節，並約揀眾。一、簡足數。「過犯」謂三舉二滅人，更兼尼等四眾，瘂、聾、睡、狂等人。二、簡欲緣。「大急」即三寶、疾病等。三、簡合訶。「四羯磨」：一、訶責，二、擯出，三、依止，四、遮不至白衣家。此四，《律》名「得滿不得訶」。「諸雜治」者，即收行覆藏等人。竝由奪其智能，不得訶法；必非此等，方名「應訶」。「若」下，總結。「陶練」，即是揀擇。「實人」，謂合教者。

【055-0090】02_戒疏/03b_卷一下之一#2
【原文】【疏】注中「犯事未悔」者，釋成有罪相也。但以無始無明想倒為本，動念緣境，何得蕭然？唯有智人，能見能懺；自餘惑重，何由開悟？故《律》文云「無學果人不故犯戒」，三果同凡，未免緣縛，可不思哉！

【譯文】【記文】在探究制教意趣的章節中，此為第一科。首句提出徵問。「以」字以下展開解釋。「集諦」是世間流轉的苦因。「見道」即指證得初果。此處說明唯有極致的聖人才能徹底斷除集諦業惑，凡夫僅憑口陳懺悔，豈能立刻滅盡業道？此文意在闡明律宗的懺悔並不著眼於深層業理的消滅，而是著重於清淨遮障，因此可以判定為得清淨。

【055-0098】02_戒疏/03b_卷一下之一#10
【原文】【疏】今諸戒首令懺已聞者，既悔前罪，斷後相續，露過現前，於心無隱，便同淨用，得預聞持。不論往業招生增惑。

【055-0099】02_戒疏/03b_卷一下之一#11

【譯文】【記文】第二科。前半段說明懺悔得以清淨的緣由。律宗懺悔的核心宗旨，在此段文字中表露無遺。「不」字以下，劃定教理的界限分齊。「業」是指善惡業道，「招生」是指引發受生的苦報果道，「增惑」是指煩惱障道。這三種心念與行業的清淨，在判教上歸屬於化教；律宗則是依據是否違背佛制來裁定，所以不屬於此處所論範圍。

【055-0100】02_戒疏/03b_卷一下之一#12
【原文】【疏】此但事悔，伏業而已。終須行淨，深見我倒。知我倒本，相等虗空，但有妄緣，故纏三有。審見此理，明白無疑，分得正見，方傾苦趣。若此之悔，名為滅業。業何可滅？障不招生，故名滅矣。乃至無學尚酬往因，如身子嬰病，目連遭苦。可以類通，想不迷矣！
【譯文】【疏文】這僅僅是事相上的懺悔，暫時伏滅惡業而已。終究必須透過行持清淨，深徹照見「我執」的顛倒本相。體悟到我執顛倒的本質，原本就如虛空般了不可得，只因妄念攀緣，才受縛於三界輪迴。若能審諦徹見此理、明了透徹毫無疑慮，由此分證正見，才能徹底推翻輪迴苦道。若是這般懺悔，才稱為徹底滅除罪業。然而業性豈能憑空滅除？只因阻斷了障礙使其不再感召後世受生，所以稱之為滅。乃至阿羅漢等無學聖人尚且須償還宿世宿業，如同舍利弗罹患風疾、目犍連慘遭撲打。以此類推便可貫通領會，想必不會產生迷茫了！

【055-0101】02_戒疏/03b_卷一下之一#13
【原文】【記】三中。初二句躡上律懺。「終」下，發後理懺。初示理觀。且據小宗，性空觀析，見無我理；相空、唯識，具在《事鈔》。「我倒本」者，即是無我，故舉「虗空」為喻。「審」下，判位。言「分得」者，即內凡以上不生惡道。「若此」下，結示，初明行勝。前但事伏，此理滅故。「業」下，轉釋滅義。「不招生」者，但無總報，不無別報，定業不轉，至佛猶償。是故學人好自觀察，常以善緣熏練心識，勿謂無罪，業理灼然。《華嚴》偈云：「假使百千劫，所作業不忘，因緣遇會時，果報還自受。」佛言真實，無得自欺。「乃」下，引示。《大論》舍利弗患風疾，《增一》目連乞食，為梵士所打，骨肉爛盡，皆謂醻往業。據此可知，理懺不滅，故云「可以」等也。
【譯文】【記文】第三科中。前兩句承接上文律宗的事相懺悔。「終」字以下，開展後續的理觀懺悔。首先開示理性觀照。暫且依據小乘宗派，透過性空觀之分析，照見無我真理；至於相空觀與唯識觀，則完整記載於《事鈔》之中。「我倒本」就是指無我之體，因此引用「虛空」作為比喻。「審」字以下，判定修行果位。所謂「分得」，是指達到內凡位以上便不再墮入惡道。「若此」以下進行總結指示，先說明這種行持的殊勝之處。前面律懺僅是事相壓伏，此地理觀方為真實息滅。「業」字以下，轉向解釋「滅」的真實意涵。「不招生」是指不再感召引導投胎的總報，但仍難逃個別的別報，決定性業報無法轉移，乃至成佛尚須償還。因此修道之人應當善自審視反省，恆常以善緣熏習歷練心識，切莫自認無罪，因果業理昭然若揭。《華嚴經》偈云：「假使百千劫，所作業不忘，因緣遇會時，果報還自受。」佛語真實不虛，切勿自我欺瞞。「乃」字以下，引用聖蹟以示明證。《大智度論》載舍利弗患風疾，《增一阿含經》記目犍連乞食時遭梵士痛打致骨肉糜爛，皆是償還過去宿業。由此可知，縱經理懺亦不能抹滅定業，所以說「以此類推」等語。
