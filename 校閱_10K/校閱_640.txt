# 校閱材料　第640檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【640-0001】02_戒疏/12b_卷三上之三#75
【原文】【記】次除疑中。初牒釋，「昔」下，指古解。「今」下，出正解。初二句標。「有」下，釋。初敘疑；「故」下，次決破。「非衣法」者，佛制犯衣捨懺後用，今不捨輙貿，故云「非」也。「罪由心生」者，出制捨意。上明前衣不合。「新」下，次明後衣無犯。初正判。次引《多論》，文證甚明。「上」下，揀濫。恐謂前引《論》云衣捨罪悔，畜心不斷，有相染犯，此何不爾，故特分之。前明捨財物在，此說貿易物去，不可混同，故云「反上」。
【譯文】【記文】其次在除斷疑惑中。首先提引經文作解釋，從「古代」以下，指示古人的說法。從「現在」以下，提出正確的解釋。前兩句是標示大綱。從「有人」以下，進行詳細解釋。首先敘述一般人的疑慮；從「所以」以下，接著加以破斥糾正。「不合法度」，是因為佛陀規定犯戒的長衣必須在僧團中捨棄並懺悔罪過之後才能重新使用，現在不經捨懺就擅自拿去交換，所以說是「非法的」。所謂「罪過是從心中產生」，道出了佛陀制定捨衣的深意。前半段說明前一件衣服處置得不合戒法。從「新換得」以下，進一步說明後一件新衣服其實本身沒有罪過。首先給出正面判定，接著引證《薩婆多論》，經文的證據極其明白。從「前面」以下，簡別容易混淆之處。唯恐有人以為前面《薩婆多論》提到捨棄衣物時罪過若未懺淨、蓄存的貪心未斷，後面的衣料也會受到牽連染污犯戒，為什麼這裡卻不算犯戒？所以特別加以區分。前文說的是捨棄時物品本身還在自己手上，這裡說的是物品已經透過交易給了別人，兩者絕不可混為一談，所以說「與前面相反就可以明白」。

【640-0002】02_戒疏/12b_卷三上之三#76
【原文】【疏】「一尼薩耆一突吉羅」，如上已判。昔人以為著不捨衣，如《見論》云：「得吉羅罪。若無比丘，得著無罪。若見比丘不捨悔故，亦一一吉。」三衣戒明不開餘者，如《僧祇》云：「受用不淨衣，隨一一越。」
【譯文】【疏文】「構成一個尼薩耆波逸提、一個突吉羅」，這在前面已經判定過了。古人以為穿著了沒有依法捨懺的衣服，如同《善見論》說：「犯突吉羅罪。如果身邊沒有其他比丘可以對面懺悔，准許暫時穿著而不算犯戒。如果看見了比丘卻不肯前去捨衣懺悔，每穿一次也都會構成一個突吉羅。」三衣戒中明確規定不開許其餘不淨之物（充作三衣），如同《摩訶僧祇律》說：「受用不清淨的衣物，每一次受用就犯一個越毗尼罪。」

【640-0003】02_戒疏/12b_卷三上之三#77
【原文】【記】釋二罪中，初科。初指前判。「昔」下，次示昔解。《見論》無人對懺，故開暫著。有人須懺，不懺故犯。「三衣戒不開餘」者，謂犯捨物不得作三衣，著用有罪。故《僧祇》「隨一一」者，謂著著犯也。因循昔解，乃引諸文。然文中吉羅，自犯輙貿違教之罪。新衣無過，豈有著用犯耶？
【譯文】【記文】在解釋雙重罪名時，這是第一科。首先提示前文的判定。從「古人」以下，接著列出古人的解釋。《善見論》認為沒有人可以面對面懺悔時，開許暫時穿著。如果有人在場就必須懺悔，不肯懺悔而穿著就犯戒。「三衣戒不開許其餘物」，是說犯捨墮的布料不能拿來製作三衣，穿著使用就有罪。所以《僧祇律》所說的「每一次受用就犯」，是指每穿一次就犯一次罪。後人沿襲了古代的註解，便胡亂引用各家律文。然而律文中所說的突吉羅罪，純粹是比丘擅自拿長衣去交易而違背佛陀教誡所犯的罪。新換來的衣服本來就沒有罪過，哪裡會有每穿用一次就犯一次罪的道理呢？

【640-0004】02_戒疏/12b_卷三上之三#78
【原文】【疏】問：「何故衣中畜重著輕，食中畜輕食重？」
【譯文】【疏文】問道：「為什麼在衣法之中，蓄存長衣的罪重，穿著的罪輕；在飲食法之中，蓄存過宿食物的罪輕，吃下去的罪反而重呢？」

【640-0005】02_戒疏/12b_卷三上之三#79
【原文】【記】問中。衣食二制相反，故問通之。如食內宿、殘宿，經宿但吉，食用方提。
【譯文】【記文】提問的內容。衣法與食法的兩部制戒規定恰好相反，所以提出問題要求通達解答。例如食物隔夜存放，存放過夜只犯突吉羅罪，真的吃下去才會犯波逸提罪。

【640-0006】02_戒疏/12b_卷三上之三#80
【原文】【疏】答：「衣有淨法，不施長貪，故隨畜犯；隨著非制，故但是輕。食中非制，無違畜輕；制不許服，故違得重。」
【譯文】【疏文】回答說：「衣物原本就有說淨的開許法門，如果不作說淨就是放任長養貪心，所以只要隨意蓄存就直接犯重罪；隨意穿著這件不合規定的衣服並非正戒所嚴禁的焦點，所以只是輕微的突吉羅罪。飲食方面，存放本身並非正戒所要防範的焦點，在沒有明確違背正戒之前蓄存的罪很輕；但正戒嚴格禁止食用隔夜殘食，所以一旦違背禁令吃下去，罪過就很重。」

【640-0007】02_戒疏/12b_卷三上之三#81
【原文】【記】釋中，初解。衣有淨法，制不妄畜，與食制不服同也。「不施」謂不淨施。「隨著非制」者，由是犯衣不應故吉，而非正制，則與畜食同也。
【譯文】【記文】在解釋之中，這是第一種說法。衣物本來有說淨法，佛制不許隨意蓄存，這與食法禁止食用是同樣關鍵的重點。「不作說淨」，就是指不肯依教作法。「穿著並非正戒禁令」，是因為那是穿著了違犯規定的衣服，所以只論突吉羅罪，這並非制戒的本體重心，因而與單純存放食物的情形是一樣的。

【640-0008】02_戒疏/12b_卷三上之三#82
【原文】【疏】又解：「衣有別屬，畜則在己，是以罪重，著用罪輕。食是味通體在，不局故輕。若食交盡，無有所結，故隨咽結。」
【譯文】【疏文】另一種解釋說：「衣物具有專屬佔有的特性，一旦蓄存就完全歸屬於自己，因此蓄存的罪重，穿著使用的罪輕。食物的滋味與利益具有共通性，物資體性擺在那裡，並未被單獨個人長久獨占，所以存放的罪輕。但是食物一旦吞下肚就徹底消耗殆盡，就無所依託以結罪，所以罪過是隨著每一次吞嚥而結罪。」

【640-0009】02_戒疏/12b_卷三上之三#83
【原文】【記】次解中。衣則畜重用輕，食則畜輕食重。酌情以論，理自可見。
【譯文】【記文】第二種解釋中。衣物是蓄存罪重而使用罪輕，食物是儲藏罪輕而吃下罪重。依據人情物性來推敲評斷，其中的道理自然一目了然。

【640-0010】02_戒疏/12b_卷三上之三#84
【原文】【疏】「此捨墮衣」下，正明治罪捨懺相。其儀法用，具在《羯磨疏》及《鈔》中，此但依文句解耳。不須復列，非宗本故不明也。
【譯文】【疏文】註文從「這種捨墮衣」以下，是正式說明治罪以及捨衣懺悔的法相規範。其具體的儀軌作法，完整收錄在《羯磨疏》以及《事鈔》之中，這裡只是依循《戒本》的字句加以消解罷了。不需要在這裡重複鋪陳列舉，因為這不是戒本的核心宗旨，所以不多作說明。

【640-0011】02_戒疏/12b_卷三上之三#85
【原文】【記】正治罪中。初牒釋。「其」下，指廣。《鈔》與《羯磨》，並有《懺篇》，在彼合明。今釋《戒本》，識相持奉，捨懺儀式，不當廣述，故云「非宗」。
【譯文】【記文】在正式治罪的說明中。首先標示出所要解釋的條文。從「具體」以下，指示詳情另有出處。《事鈔》與《羯磨疏》中都專門設有〈懺罪篇〉，在那裡作了完整的說明。現在這部書是在解釋《戒本》，目的是為了讓比丘認清戒相並切實持守奉行，至於僧團集體捨衣懺悔的繁瑣儀式，不應當在此詳細鋪敘，所以說「非本宗旨趣所在」。

【640-0012】02_戒疏/12b_卷三上之三#86
【原文】【疏】「不犯」中，「十日內」者，反前過限。「淨施」、「遣人」，亦反「不淨施」故，所以有犯。
【譯文】【疏文】在「不犯」的項目中，「十天之內」這一句，是相對於前面所說超過期限的規定。「說淨」、「送人」，也是相對於前面的「不作說淨」，所以才會有犯戒與不犯的區隔。

【640-0013】02_戒疏/12b_卷三上之三#87
【原文】【記】不犯中，初科。謂限內作淨與人故無犯。
【譯文】【記文】在不犯的條文中，這是第一科。意思是說在規定的十天期限之內作了說淨或者送給了他人，所以不構成犯罪。

【640-0014】02_戒疏/12b_卷三上之三#88
【原文】【疏】言「奪想」者，財在想去，無畜心故，不犯長罪。如《十誦》中「後見本財，更得十日」。餘失例爾。
【譯文】【疏文】註文所說「強盜搶奪的誤想」，是指財物實際上還在，但主觀上誤以為已經被搶走了，由於心中沒有蓄長衣的貪念，所以不犯長衣罪。如同《十誦律》中記載「後來又找回了原本的財物，重新再獲得十天的寬限」。其餘遺失、燒毀等情況也都依此類推。
