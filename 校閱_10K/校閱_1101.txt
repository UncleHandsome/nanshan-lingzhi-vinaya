# 校閱材料　第1101檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1101-0001】資持記/07b_中一下#39
【原文】〔舊記以《四分》戒配數，非也。〕次解中。以僧尼轉根，即互入眾，更不重受。故知比丘一體具二眾戒，尼亦例爾。次七眾多少，五戒；引論中，先明有情。竝下，示無情。始終者，彼宗五戒，局盡形故。設下，通示。五法不隨緣境，有減失故。
【譯文】〔過去的記疏用《四分律》的戒數來配算，這是錯誤的。〕在第二種解答中：因為比丘或比丘尼如果發生生理轉變（轉根），就能直接互換加入對方的僧團，不需要重新受戒。由此可知比丘一身在戒體上實質具備了二眾的戒法，比丘尼也是依此類推。接著說明「七眾戒法的多少」，在「五戒」當中：引用的論典中，首先說明有情眾生境。在「竝」字以下，說明無情境。所謂「始終」，是因為該宗派主張五戒必須以盡形壽為受持期限。在「設」字以下，普遍說明：五戒之法不會隨著所緣境界的滅失而有所減失。

【1101-0002】資持記/07b_中一下#40
【原文】此中情無情共論，三善別配，總十五戒。義準中，初明情境，先離婬境。則對女六戒，對男五戒。發下，配心毒。下示非情。若情非情合數，則對女二十一，對男十八，此約單配。準開七毒，則女四十九，男四十二。八戒中。指情同上，亦約依論義準，二數不同。
【譯文】這裡將有情境與無情境合併討論，再分別配屬無貪、無瞋、無癡三善根，總共成為十五種戒。在「義準」推論當中，首先說明有情境，先分析遠離淫欲的境界：那麼面對女性就有六條戒，面對男性就有五條戒。在「發」字以下，配屬內心的煩惱毒害。下方說明無情境。如果將有情與無情合併計算，那麼面對女性就是二十一條戒，面對男性就是十八條戒，這是就三毒單獨配屬而言。若是進一步開展為七種毒心，則面對女性是四十九條戒，面對男性是四十二條戒。在「八戒」當中，指明有情境與上述五戒相同，同樣是依照論典本文與義理推準兩種計算，因而有兩種不同的數量。

【1101-0003】資持記/07b_中一下#41
【原文】非情五者：一酒，二花纓，三高床，四歌伎，五不過中食。一一三戒。若情非情合數，依論則得二十七戒，義準則對女三十三，對男三十。私約七毒，對女七十七，對男七十，可知。〔上且依彼論四支示數。〕十戒，初中，上示境同僧。下準文以證。律文，即大小持犍度。戒戒下者，即二部戒本。
【譯文】無情境的五項是：第一是不飲酒，第二是不著花鬘瓔珞，第三是不坐高廣大床，第四是不歌舞倡伎，第五是不非時食。每一項各含三善根而成三條戒。如果將有情與無情合併計算，依照論典則得到二十七條戒，依照義理推準則面對女性是三十三條，面對男性是三十條。若私下推演為七種毒心，則面對女性是七十七條戒，面對男性是七十條戒，道理可以想見。〔以上暫且依照該論典以四支業來顯示數目。〕十戒當中，起初上方標示所面對的境界與比丘僧相同。下方依循律文來印證：律文是指〈大小持犍度〉。「每條戒」以下，是指比丘與比丘尼兩部的戒本。

【1101-0004】資持記/07b_中一下#42
【原文】標《四分》者，簡餘宗不爾；《多論》四支，同前五八故也。釋妨中。說相列十，而云同僧，正相違故。此下，釋通，初出列相之意。故下，以具戒白四比類。方列十四者，十即十戒，對上三歸；四即四重，對一羯磨。具戒中。論文，且約單犯。一一眾生，所對境也；身口七支，即所造業，戒所禁也。
【譯文】特別標明出自《四分律》，是為了簡別其餘宗派並非如此；例如《薩婆多論》主張只發四支，與前面的五戒、八戒相同。在解釋疑難中：說戒相時明明只列出十條，卻又說與比丘戒相同，這顯然互相矛盾。在「此」字以下解釋通達，起初指出條列相狀的用意。「故」字以下，以具足戒的白四羯磨來比況類推：所謂「才條列出十四條」，十是指十戒，對應前面的三歸受體；四是指四波羅夷，對應最後的那一次羯磨宣白。在「具足戒」當中，論典的文字暫且是就單一造犯的狀況而言。每一個眾生，都是所面對的境緣；身三口四這七支，就是所造作的惡業，也就是戒法所要禁戒的。

【1101-0005】資持記/07b_中一下#43
【原文】三毒，即能造心，業之本也。論舉有情，非情三戒，一一亦爾也。義準中，初離毒心。三單如論。互起中二三者，謂複有三也：一貪瞋，二貪癡，三瞋癡；等分，即具足一也。通上三單，共為七毒。女人下，離過境也。於七業中，唯婬可離；所以爾者，如婬一道，餘道無污；
【譯文】三毒就是能夠造業的心念，是惡業的根本。論典舉出有情境，而無情的三條戒，每一條也都是依此道理類推。在「義準」推論中，首先分析心念中的毒害。三種單獨的毒心如同論典所說。互為夾雜生起的「二或三種」，是指複合的心態有三種：一是貪瞋，二是貪癡，三是瞋癡；所謂「等分」，就是貪瞋癡三者具足合為一種。加上前面的三種單純毒心，共計形成七種毒心。在「女人」以下，分析所防過失的境界。在七種惡業中，唯獨淫業可以進一步區分處所；之所以如此，是因為如淫欲只需犯於一道，其餘各道並沒有被污染；

【1101-0006】資持記/07b_中一下#44
【原文】殺有四處，隨一即死，故不須分〔腦喉心腰。〕七下，以毒歷支，以支對境；一一支中，各有七毒；對男女境，合數可見。後二句，歷非情境，則不可數。結指中。《善生》五種，統攝戒境；但舉境比法，故云譬耳，非譬喻也。雪，猶理也。問攝戒中。以佛制戒，其相非二；
【譯文】殺生則有四個要害部位，隨便傷及一處就會致死，所以不需要再細分部位〔即腦袋、喉嚨、心臟、腰部〕。在「七」字以下，用七種毒心歷緣身口七支，再以七支去面對一切境界；在每一支當中，各自具備七種毒心；對照男女境界，合算的數目便顯而易見。最後兩句，歷遍無情境界，數量就多到無法計數了。在總結指引中：《善生經》的五種分別，統攝了所有持戒的境界；這只是舉出具體境界來比擬戒法，所以才說「譬如」，並不是真正的譬喻。「雪」，在此是條理、明辨析理的意思。在提問攝持戒法中：因為佛陀制定的戒律，其本質體性並沒有二樣；

【1101-0007】資持記/07b_中一下#45
【原文】而前對情境，但說七支；疑其未盡，故申此問。初答盡中。配戒種類，文出多宗；《戒疏》、《義鈔》竝引；止以四重，攝一切戒。種名乃通，諸篇條相各自為種；類名則局，唯據殘下諸聚，是種之類。今明種類，且約偏對；種即四重，根本異故；類即餘篇，枝條生故；
【譯文】但前面面對有情境界，卻只談論身口七支；令人疑惑戒法是否涵蓋未盡，所以提出這個疑問。最初在「攝持已盡」的回答中：把戒律分類配屬為「種」與「類」，文獻出自薩婆多宗；《戒疏》與《拾毘尼義鈔》全都引用了這段；純粹是用四波羅夷重罪，來統攝一切戒律。「種」的名義本來較寬廣，各篇聚的條文行相各自都可以稱為種；「類」的名義則較狹隘，唯獨是指僧殘以下的各個聚罪，都是根本重罪的流類分支。如今說明種類，暫且偏向相對待來論：種就是四重罪，因為是不同的根本罪；類就是其餘各篇聚，因為是從根本枝條衍生而來的；

【1101-0008】資持記/07b_中一下#46
【原文】縱有無量，不出此四。次不盡中，初句立義。以下，釋所以。殺打別者，所防過異也。〔疏作輕重不同。〕能防異者，對治行別也。故下，引證。彼具云：除十善業，及十惡業〔化教業道〕；善戒〔制教七支〕惡戒已〔即不律儀〕，更有業戒所不攝者，謂善惡法〔此依古記所引〕；今鈔略舉善惡戒耳。
【譯文】縱然戒條有無量之多，也絕對超不出這四重罪的範圍。其次在「攝持未盡」的回答中，第一句先確立論點。在「以」字以下，解釋其中的原由。殺生與責打之所以有別，是因為所防範的過失不同。〔《戒疏》寫作輕重程度不同。〕能防護的功能不同，是因為對治的行持互異。在「故」字以下，引用經文作證。那部經具足的文句是：除了十善業道以及十惡業道〔屬於化教業道〕；善戒〔屬於制教身口七支〕與惡戒之外〔即不律儀〕，還有業道與制戒所不能含攝的，稱為善法與惡法〔這是依照古代記疏所引用的內容〕；如今行事鈔只是簡略舉出善戒與惡戒罷了。
