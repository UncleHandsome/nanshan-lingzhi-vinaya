# 校閱材料　第1033檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1033-0001】資持記/05b_上四#36
【原文】準此明據，豈復疑乎。《四分》下，指所出，初點本律。不題篇首，故云不了。今下，取他文。即指上法有誠據也。本律〈說戒犍度〉，初明先廣後略次第八段；彼云：比丘作是念，今以難緣聽略說戒，難來猶遠，我等得廣說；彼比丘應廣說，不說如法治。〔下七例此作之。〕又云：我曹不得廣說，可說至九十；
【譯文】依照這樣明白確鑿的證據，哪裡還需要懷疑呢！從「四分」以下，是指明出處來源，首先點評本宗的《四分律》。由於它沒有在篇首單列題綱，所以才說文意「不了（不夠清晰）」。從「今」字以下，是採納其他論典的文字。也就是指明上述這套作法具有真實可靠的依據。本律〈說戒犍度〉中，先是說明先廣後略的連續八個段落；那裡說：比丘心中這樣想，如今因為危難事緣雖然聽許簡略說戒，但危難距離尚遠，我們還可以詳盡廣說；那位比丘就應當詳盡廣說，若不廣說就依照戒法加以處分。〔後面七個段落比照這條體例進行。〕又說：我們不能全部廣說，可以廣說到九十單墮戒為止；

【1033-0002】資持記/05b_上四#37
【原文】又云：不得說九十，可說至三十；又云：不得說三十，可說至二不定；又云：不得說二不定，可說十三；又云：不得說十三，可說四事；又云：不得說四事，可說戒序；又云：不得說序，即從座起去。〔次第八段，前一是廣，後七是略，古人妄傳為七略一直者，非也。
【譯文】又說：如果不能說到九十，可以說到三十捨墮戒為止；又說：如果不能說到三十，可以說到二不定法為止；又說：如果不能說到二不定，可以說到十三僧殘法為止；又說：如果不能說到十三，可以說到四波羅夷法為止；又說：如果不能說到四波羅夷，可以說到戒經序文為止；又說：如果連戒序都來不及說，就應當立即從座上起立離去。〔這井然有序的八個段落，前一個是廣法，後面七個是略法，古人妄加流傳說是七種略法加一種直說法，那是錯誤的。〕

【1033-0003】資持記/05b_上四#38
【原文】後明先略後廣三五說戒，彼云：有五種說戒：一說序已，餘者應言僧常聞〔已下並從說序去，一一皆以餘者等結之。〕；二至四事；三至十三；四至二不定；五廣說〔三十已後〕。復有五種：一說序四事已，餘者略之；二至十三；三至不定；四至三十；五廣說〔九十已下〕。
【譯文】後來又說明先略後廣的三組五種說戒之法，那裡說：有五種說戒方法：第一是說完戒序之後，其餘篇章應當說「僧眾平日所常聞」〔從宣說序文開始，每一條都用「其餘的等等」這句話來作結尾〕；第二是說到四波羅夷法；第三是說到十三僧殘法；第四是說到二不定法；第五是全部廣說〔即三十捨墮戒以後全部誦出〕。復有五種：第一是說完戒序四事已，其餘的加以簡略；第二是說到十三；第三是說到二不定；第四是說到三十；第五是全部廣說〔即九十單墮戒以下全部誦出〕。

【1033-0004】資持記/05b_上四#39
【原文】復有五種：一說序至十三；二至不定；三至三十；四至九十；五廣說〔提舍已下〕。律本甚廣，今云不了，明非正用；恐人未曉，略引令知。二中。且約說序竟，舉初例後。故《羯磨》云，應隨到處云：已說至某處，餘者僧常聞；
【譯文】復有五種：第一是說完戒序直至十三僧殘；第二是說到二不定；第三是說到三十；第四是說到九十；第五是全部廣說〔即提舍尼戒以下全部誦出〕。律藏原本文字極其浩繁，現在說它「不了（不明了）」，是為了挑明它並非眼下正用的法度；唯恐後人懵懂不解，所以簡略引述出來使大家明白。在第二段中，暫且是以宣說戒序完畢為例，舉出最初的例子來比照後面的情況。所以《羯磨》中說，應當隨著誦讀所到的段落說道：「已經說到某個篇章，其餘的篇目僧眾平日所常聞」；

【1033-0005】資持記/05b_上四#40
【原文】又疏釋云：誦至隨戒，難卒排門，不可轉誦，故知通後也。三中。此出《僧祇》。〔古記將此為本律一直者，非。〕未說序者，謂作白纔竟也。問：必未作白，難至如何？答：不成略法，理須再說。或待難靜，或出界外；或眾或別，隨緣作之。結斷中，初結勸。
【譯文】戒疏又解釋說：背誦到了隨意某條戒時，危難突然破門而入，不可能再掉頭轉讀其他，由此可知這條規矩普遍適用於各篇之後。在第三段中，這出自《僧祇律》。〔古記把這個當作本宗《四分律》的直說法，那是錯的。〕所謂「尚未說序文」，是指說戒的羯磨白文才剛剛作完的時候。問：如果連羯磨白文都尚未作完，危難就降臨了，該怎麼辦？答：這就不能構成簡略之法，在道理上必須重新說戒。或者等待危難平息，或者遷移到界限之外；或者由大眾作法，或者由個別行持，全都隨著事緣來處置。在「結尾斷定（結斷）」中，首先是作結並勸勉。

【1033-0006】資持記/05b_上四#41
【原文】言就緣者，示略法之本也。並結正者，即前七略中，若可廣說不廣說，乃至可說序不說序，並如法治。比下，斥非，初斥略法乖儀。或下，斥託緣不說。次明別法說戒中，初文。律因佛制眾僧說戒，一比丘住處，不知云何，白佛，故制。調度者，律云：敷坐具、具水瓶、洗足瓶、然燈火、具舍羅等。
【譯文】說「就緣（依循事緣）」，是指出簡略之法的根本依憑。所謂「全都判定結犯正罪（並結正）」，就是指前面七種略法之中，如果本可以廣說卻不去廣說，甚至本可以說序卻連序都不說，全部都要依照戒法予以處分。從「比」字以下，是痛斥非理作法，首先斥責簡略之法違背威儀軌則。從「或」字以下，是斥責借託事緣而乾脆不去說戒。其次在說明「以別行法說戒（別法說戒）」中，第一段文字。律藏記載因為佛陀制定大眾僧必須集體說戒，但只有一位比丘獨自居住時，不知該如何處置，便向佛稟告，佛陀因此制定了獨自說戒之法。所謂「調度」，律藏記載：要陳設坐具、備齊淨水瓶、洗足瓶、點亮燈火、備好算籌（舍羅）等等。

【1033-0007】資持記/05b_上四#42
【原文】待客來者，疏云：出家之人，漂泊無侶；何有定住，是我所也；遊化觀方，縱任自在；隨所弘道，不局坊寺；望剎為居，四海為食故也。次科，眾法中。此明別法，而列四人者；由本獨住，待擬外客；來不可期，因而明之；不同初位常途僧法。至於行事，還復同前。對首中。文約三人。
【譯文】所謂「等待客僧前來」，戒疏中說：出家之人漂泊四海而無固定伴侶；哪裡有固定的處所能夠執著為我所有？遊行教化觀覽十方，任運自在無拘無束；隨著能夠宏揚聖道的地方便去，絕不局限在某個特定的寺院；遙望佛剎就作為歸宿寄居，面對四海就隨處乞食為生，所以才要等待外客。在次一科大眾法中。這裡本是說明特別的獨住之法，卻列出了四個人；這是由於起初本是一人獨居，為了等待擬議中的外來客僧；而客僧前來沒有固定的預期，所以才順帶加以闡明；這不同於最初地位中常規的大眾僧法。但至於具體的事項運作，終究還是與前面相同。在對面作法（對首）中，文字是針對三個人而設立的。

【1033-0008】資持記/05b_上四#43
【原文】後指二人，作法詞中，但除二字。疏問：僧說戒者，一人秉說，餘皆默坐；下至對首，皆各表淨者？答：僧法位強，成辦力大，故白說戒，通四方故；別人力弱，但表內淨，應上教也。心念，說戒中，初出法。若下，示餘緣。上依律文，且據蘭若；山行聚落無人義同，故準開之。露罪中，初文。
【譯文】後面指示二個人的時候，在作法的詞句中，只除去「二」字即可。戒疏中問道：大眾僧說戒時，只要一人秉持宣說，其餘大眾都是默然端坐；為何到了最少二人對面作法時，卻各自都要表白自己的清淨呢？答：大眾僧法的位格極其威強，成辦大事的力量無比宏大，所以只要宣告一次說戒，法力便貫通十方；個別私人的法力微弱，只能各自表白內心的清淨，以順應佛陀的教敕。在心中默念（心念）說戒中，首先標出作法。從「若」字以下，是開示其餘的事緣。上面依照律文，暫且是依據阿蘭若空寂處而言；但在山間行路、或者在沒有出家人的村落聚落中，情理完全相同，所以比照予以開許。在發露罪過（露罪）中，第一篇文字。
