# 校閱材料　第240檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【240-0001】01_行事鈔/11a_卷下之三#19
【原文】十二常坐不臥者。《薩婆多》云：加趺坐者，將正心故。然始正身，異外道故，生人信心；故三乘人，皆以此坐悟道。《解脫道論》云：夜常不臥也。如《決定王經》中有四法：一乃至彈指頃，於眾生中，不生瞋心。二不應與一時頃，使睡眠覆心。三引導眾生，使得阿練若功德。四晝夜不離念佛。餘如論說。《十住論》說十利：一不貪身樂。二不貪睡眠樂。三不貪臥具樂。四無臥時脇著席苦。五不隨身欲。六易得坐禪。七易讀誦經。八少睡眠。九身輕易起。十求坐臥具衣服心薄。《四分》中：蘭若比丘，敷好臥具安眠。佛言：不應爾！應初夜後夜，警意思惟。所為出家，為存出要，觀行法如後說。《智論》云：身四威儀，坐為第一；食易消化，氣息調和。求道者大事未辨，煩惱賊常伺其便，不宜安臥。若欲睡時，脇不著席。
【譯文】第十二、「常坐不臥」。《薩婆多毘尼毘婆沙》說：結跏趺坐，是為了端正自心的緣故。先從端正身儀開始，能有別於邪門外道，從而令人生起敬信之心；因此三乘聖賢之人，全都是以此坐法而開悟成道的。《解脫道論》說：夜晚常坐而不躺臥。如同《決定王經》中所列的四種法門：一是在彈指那麼短暫的片刻間，對眾生都不生起瞋恚心。二是不得在須臾片刻間，放任睡眠覆蔽自心。三是引導化導眾生，使他們成就阿練若的功德。四是白天黑夜都不離念佛。其餘細節如論中所載。《十住毘婆沙論》說有十種利益：一是不貪圖肉身的舒適快樂。二是不貪戀睡眠的享樂。三是不貪戀安適臥具的快樂。四是沒有橫臥時脅肋沾席的重濁懈怠之苦。五是不隨順肉身的欲望牽引。六是容易成就坐禪定境。七是容易讀誦經典。八是能夠減少睡眠昏沉。九是身體輕靈容易起立行動。十是渴求坐臥具與精美衣服的心思淡泊。《四分律》中記載：住在阿蘭若的比丘鋪設了美好的臥具安穩酣睡。佛陀訶責說：不應當這樣！應當在初夜與後夜時分，警醒心志、端正思惟。之所以出家，是為了掌握出離生死的大要，其觀行之法如後文所詳說。《大智度論》說：在行、住、坐、臥這四種威儀之中，端坐是居於第一位的；坐姿使食物容易消化，內在氣息調順平和。追求正道的人大事未明，煩惱之賊常伺機窺探伺隙而入，絕不適宜安穩躺臥。若是睏倦想要打瞌睡時，肋脅也絕不著席躺臥。

【240-0002】01_行事鈔/11a_卷下之三#20
【原文】三諸部異行。《毘尼母》中云：若瞋心不止，我則不食；待瞋滅方食。《智論》：中後不飲漿。由此緣故，心生樂著，不一其心修習善法。《寶雲經》云：四分之一食。凡乞得食，分為四分：一分與同梵行者，第二分與窮下乞匃之者，第三分與諸鬼神，第四分自供身食。但念修道，於食中不生貪染心。若乞食時，繫念威儀，終不輕躁。諦視目前，不過一尋。次第乞之，除惡狗、惡牛，先破禁戒；隨有人畜能擾惱者，皆悉不往；可譏嫌處，亦不往彼。餘如彼〈十二頭陀〉中說。《十住婆沙》有著毳衣、食後不受非時飲食；各有十利，如彼說。《解脫道》中有十三頭陀：衣二、食五、處五，十三是常坐勇猛之分。《十誦》：多雨國土，四月在露地，八月在覆處；少雨國，反前。上列十二，依《四分》而言。統明經論所述，並不及《解脫道論》次第詳悉。正行既成，定慧斯立。彼論廣有次第法，略不述之。
【譯文】第三、諸部派（或各部經論）記載的不同行持。《毘尼母論》中說：如果瞋恨心不能止息，我就不進食；一定要等到瞋心泯滅之後才吃飯。《大智度論》說：過午之後不飲用米湯果漿等飲品。因為如果飲漿，內心會產生貪戀執著，就無法專一其心修習善法。《寶雲經》說：「四分之一食」。凡是乞食得來的食物，均分為四份：一份布施給同修的清淨梵行人，第二份施捨給貧窮下賤的行乞者，第三份施予一切鬼神，第四份才留給自己滋養色身。心中唯念精進修道，在飲食之中絕不生起貪愛染著。乞食的時候，端正繫念於身行威儀，始終不輕浮急躁。凝視前方地面，目光不超過一尋（八尺）。依次第挨門挨戶乞食，但要避開有惡狗、惡牛的地方，以及原本就破壞禁戒之家；凡是有能擾亂惱害身心的人或牲畜之處，全都不去；容易引起世俗譏嫌詬病的地方，也絕不前往。其餘細節正如該經〈十二頭陀品〉中所述。《十住毘婆沙論》還有穿著毳衣（毛織粗衣）、食後不接受非時飲食等行持；各有十種利益，正如該論所說。《解脫道論》中則列有十三種頭陀行：衣服兩種、飲食五種、處所五種，第十三項「常坐不臥」是屬於勇猛精進之分支。《十誦律》記載：在多雨的國土，四個月露天而坐，八個月在有遮蔽的屋下；少雨的國土，則與此相反。上述所列的十二種頭陀行，是依據《四分律》系統而言的。總括統覽經論中所述，其實都比不上《解脫道論》的編排次第那麼詳盡周密。頭陀正行既然成就，禪定與智慧自然確立。那部論中有極為廣泛的修持階次之法，此處略過不加贅述。

【240-0003】01_行事鈔/11a_卷下之三#21
【原文】四雜法。《四分》：蘭若比丘，乞食至蘭若中，往常食處，淨掃灑，具水器、殘食器、床座、洗脚石、盛水器、拭脚巾。若見餘蘭若來，應遠迎，為取鉢、取衣，舒張有污者，應拭揉、抖擻、浣暴；等令其坐訖，與彼水器及水、洗足石、拭脚巾，持革屣安左邊，勿令水漬；彼洗足已，洗足諸器物復本處，將澡豆，淨洗手。別留賊食。便授水，與彼比丘已；次授食，供給所須苦酒鹽菜等；若熱應扇。若日時欲過，應俱食；不爾者待彼食已，取鉢自食已。有餘食者，應與人、若非人；若淨地無草處，無蟲水中。餘諸食具淨洗，復本處，淨掃食地。有賊來者，語言：此是水，此是食，為汝等故，別留淨潔，若欲食便食之。須善知夜時節，及以方相星名，恐賊來問答有失。《十誦》開練若讀星經。若見人來，先共語，和悅顏色，不應垂頭，應正憶念。餘如《四分》。《四分》開用鑽木出火，在屏處亦開用火珠。《善見》：若頭陀比丘，雖住寺中，不住僧房，不食眾食，施主自為起房，僧不得差為知事。若比丘有能讀誦、教化、說法，能利僧者，亦不得差為知事；好房舍衣鉢先與之，飲食果木得加分與。《五分》：若不捨十二頭陀法，在人間受請，一一吉羅；若不能者，皆應捨頭陀法。
【譯文】第四、雜法。《四分律》說：住在蘭若（寂靜的林中住處）的比丘，入村乞食之後回到蘭若之中，先到自己往常進食的處所，把它打掃乾淨並且灑上清水，預先備妥水器、殘食器（裝盛殘餘食物的器皿）、床座、洗脚石、盛水器以及拭脚巾。倘若看見別的蘭若比丘到來，應當遠遠地出去迎接，替他接過鉢、接過衣；把他的衣舒展開來，若有污漬沾著，就擦拭揉洗、抖擻乾淨、洗淨曬乾。這些事辦妥了，請他坐下，然後把水器連水、洗足石、拭脚巾一一遞交給他，再把革屣（皮製的鞋子）安放在左邊，不要讓水浸濕。等他洗完了脚，就把洗足石等各種器具放回原處，再取澡豆（豆粉製成的洗滌用品）把雙手洗淨。此外，還要特地留下一份食物，預備給盜賊。接著先遞上水，等那位比丘飲用之後，再遞上食物，凡是他所需要的苦酒（酸醋）、鹽、菜蔬等物，都要一一供給；天氣若炎熱，應當在旁邊為他搧風。如果日中的時限快要過去，就應當一同進食；若不是這樣，就等對方用畢，再取自己的鉢來進食。若有剩下的食物，應當施給人，或者施給非人（鬼神之類）；也可以倒在沒有草的淨地上，或是倒進沒有蟲的水中。其餘各種食具都要洗淨，放回原處，並且把進食的場地打掃乾淨。若有盜賊前來，便對他們說：這裡是水，這裡是食物，這都是特地為你們另外留下的潔淨飲食，你們若要吃，便拿去吃吧。必須善於了知夜晚的時節分限，以及方相星名（指示方位的星宿名稱），恐怕盜賊來時，問答之間有所失誤。《十誦律》開許練若（蘭若）比丘讀誦星象之書。若是看見有人前來，應當先與他交談，面色和悅，不應低垂著頭，應當端正憶念。其餘如《四分律》所說。《四分律》開許用鑽木的方法取火，在隱蔽之處也開許使用火珠（聚光取火的晶珠）。《善見律》說：若是頭陀比丘，雖然住在寺院之中，卻不住在僧房裡面、不吃僧團的飲食，施主又自行為他營建房舍，僧團不得差派他擔任知事（僧團的事務職掌）。若有比丘能夠讀誦經典、教化眾生、宣說法義，能對僧團有所饒益，也不得差派他擔任知事；上好的房舍、衣鉢應當先分給他，飲食、果木也可以額外多分給他。《五分律》說：若是還未捨離十二頭陀法，卻在人間接受他人的邀請供食，每接受一次邀請便犯一次突吉羅（惡作罪）；若是持守不住的，就都應當把頭陀法捨去。
