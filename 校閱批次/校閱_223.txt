# 校閱材料　第223檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【223-0001】02_戒疏/10d_卷三上之一#106
【原文】【註】若僧諫時，白二竟捨，犯三偷蘭；乃至白竟捨者，犯一偷蘭；白未竟捨，但一吉羅。若未白前，受破僧法，堅持不捨，並犯吉羅。尼同僧殘。
【譯文】【註文】如果僧團進行規勸時，在單白與兩次羯磨念完時肯捨棄的，犯三個偷蘭遮；乃至在單白念完時肯捨棄的，犯一個偷蘭遮；在單白尚未念完時肯捨棄的，只犯一個突吉羅。如果尚未進行單白之前，就接受破僧的非法，並且堅持不肯捨棄，全都犯突吉羅罪。比丘尼如果犯此罪，與比丘僧殘罪同等。

【223-0002】02_戒疏/10d_卷三上之一#107
【原文】【疏】就注辨相中，初明違諫輕重。二、「若未白」下，就諫所為事明輕重者，根本以論，初行五法輕吉，後終外化時重蘭也。就尼同犯中，雖無破輪體，得立主伴，堅持五法以誘於人也。
【譯文】【疏文】在依照注文辨識犯相的內容中，首先說明違抗僧諫罪過的輕重。第二、「若未白」以下，是針對所規勸的那件事情本身來明辨罪過輕重；從根本發展過程來論，最初推行五法結輕微的突吉羅，最後向外行化大肆破僧時則結重罪偷蘭遮。至於比丘尼同犯此條，比丘尼雖然不能單獨構成破法輪僧的自體，但可以充當主謀與同黨，固執堅持五法用以誘惑別人。

【223-0003】02_戒疏/10d_卷三上之一#108
【原文】【記】釋注，犯中。違諫輕重，注云「白二竟」者，謂一白二羯磨。以第三羯磨未竟無犯。竟則至果，故所不明。「所為事」，即是破僧。「根本論」者，決文中吉罪，據從始也。「尼中無破輪體」，謂不能自立法故。「得主伴」者，倣同僧故。
【譯文】【記文】解釋注文的犯相部分。違抗僧諫的輕重，注文說「白二竟」，是指一次單白加兩次羯磨。因為第三次羯磨尚未念完時並不另結罪（無犯），全念完就直接達到僧殘果罪，所以這裡不作說明。「所為事」，就是指破僧這件事。「根本論」，是判定經文中的突吉羅罪，是依據最初起始階段而言。「比丘尼不能破法輪」，是指她們不能自立教法僧團的緣故。「得立主伴」，是指她們仿效追隨比丘而行的緣故。

【223-0004】02_戒疏/10d_卷三上之一#109
【原文】【註】不犯者：初諫便捨；若立非羯磨作訶諫者；若非法、非律、非佛所教；若破惡友、知識。若欲破僧者，若作非法者，若為僧、塔、和尚、闍黎、知識作損減，破者，不犯。
【譯文】【註文】不犯的情況：在最初規勸時立刻捨棄；如果僧團是用非法的羯磨來作呵責規勸；如果規勸本身不合正法、不合戒律、不合佛陀的教導；如果所破壞的是惡友、惡知識；如果是想去破壞即將破僧的非法者、如果對方所作全是非法之事、如果對方對僧眾、佛塔、和尚、阿闍黎、善知識造成損害削弱，而予以破斥的，全都不犯。

【223-0005】02_戒疏/10d_卷三上之一#110
【原文】【疏】「不犯」中，「初諫便捨」，一切不犯。若作五非，無成諫義，此不犯僧諫，非不違屏諫也。言「非法」者，作無軌要也。言「非律」者，無調業也。「非佛教」者，不是聖說也。「破惡友」下，以前立邪，欲毀正故。今以正法破邪非法事緣，皆不犯也。
【譯文】【疏文】「不犯」的條文中，「最初規勸時立刻捨棄」，這一切罪名都不犯。如果僧團作了五種非法羯磨，就不能構成合法的規勸之義，這種情況下不犯違抗僧諫罪，但並非不構成違抗私下規勸罪。所說的「非法」，是指作法缺乏正確的準則體制。所說的「非律」，是指沒有調伏煩惱惡業的作用。「非佛所教」，是指不是聖者佛陀的金口親宣。「破惡友」以下，是因為對方之前樹立邪法，企圖毀滅正法；如今運用正法去破除邪法與非法的人事因緣，全都不犯。

【223-0006】02_戒疏/10d_卷三上之一#111
【原文】【記】不犯中。初「五非」者，《律》有五非羯磨：一、非法別眾羯磨，二、非法和合眾羯磨，三、如法別眾羯磨，四、法相似別眾羯磨，五、法相似和合羯磨。「非法」、「非律」，並據秉法設諫為言。法雖不非，事乖軌度，故云「非法」。又非理折伏而非調攝，故云「非律」也。「不是聖說」者，出胸臆也。「破惡友」下，注中四節。初句指所破人，下三並彼所作事。言「破邪非法」，對注易見。「事緣」即僧、塔、和尚等作損減也。
【譯文】【記文】不犯的內容中。開頭所說的「五非」，是指《律》中所列的五種非法羯磨：一是非法別眾羯磨，二是非法和合眾羯磨，三是如法別眾羯磨，四是法相似別眾羯磨，五是法相似和合羯磨。「非法」、「非律」，都是針對秉法作羯磨進行規勸這件事來說的。作法程序雖然沒有違背，但所針對的事由違背了戒律準則，所以稱為「非法」。又如果是無端折伏而非為了調攝教化，所以稱為「非律」。「不是聖說」，是指全憑自己私心臆造出來的妄說。「破惡友」以下，注文包含四個分節。第一句是指被破壞的人，下面三句都是指那個人所做的事。說「破邪非法」，對照注文很容易明白。「事緣」就是指使僧眾、佛塔、和尚等受到損減破壞的事端。

【223-0009】02_戒疏/10d_卷三上之一#114
【原文】【疏】眾僧作法諫主之時，四伴影響助成破僧。僧尋設諫，拒而不受。故曰「助破違諫戒」也。
【譯文】【疏文】大眾僧依法作羯磨規勸主謀提婆達多之時，四位同黨像影子隨形、聲音相應一般協助促成破壞僧團。僧團隨即對其發起規勸，他們卻拒絕而不肯接受。所以稱作「幫助破僧違抗僧諫戒」。

【223-0010】02_戒疏/10d_卷三上之一#115
【原文】【記】十一，釋名，初科。「四伴」：一曰三聞達，二名騫茶達婆，三名拘婆離，四名迦留羅鞮舍。「影響」謂如形之影，如聲之響，言其相副應。
【譯文】【記文】第十一條，解釋戒名，第一科段。「四伴」：一名叫三聞達多，二名叫騫荼達婆，三名叫拘婆離，四名叫迦留羅鞮舍。「影響」的意思是如同形體之有影子、聲音之有回響，形容彼此緊密策應。

【223-0011】02_戒疏/10d_卷三上之一#116
【原文】【疏】有人言：「此名助惡遮僧不聽諫違諫戒。何以知然？故文云『諸大德，莫訶調達』，此遮僧也；乃至『我忍可』等，此助惡也。」
【譯文】【疏文】有人主張說：「這條戒的名稱應當叫作『助惡阻擋僧團不聽規勸違諫戒』。憑什麼知道是這樣呢？因為經文說『各位大德，請不要呵責提婆達多』，這就是阻擋僧團；乃至說『我們欣然認可』等語，這就是幫助行惡。」

【223-0012】02_戒疏/10d_卷三上之一#117
【原文】【記】古解中，初科。古謂此戒無破僧義，故以「惡」字替之。又闕「遮僧諫」義，故復加之。兩引文據，明非妄謂。
【譯文】【記文】古人見解中，第一科段。古人認為這條戒沒有直接破僧的內涵，所以用「惡」字來取代它。又因為缺少了「阻擋僧團規勸」的意義，所以又額外加上。接連引用經文作為依據，以證明不是自己妄加判定。

【223-0015】02_戒疏/10d_卷三上之一#120
【原文】【記】遮妨中，初問。戒文諫破，故須通之。答中。以前戒正諫破僧，此戒正諫遮諫。但由遮諫，意在壞僧，故文列之，非正諫事。
【譯文】【記文】消除疑難中，首先發問。戒文中明明是規勸其不要破僧，所以必須加以通融解釋。回答當中。因為前一條戒是直接規勸破僧，這條戒則是直接規勸其阻擋僧諫。只是由於他們阻擋規勸，其根本目的還是在於破壞僧團，所以經文中才順帶列出，這並非此處正受規勸的實體。

【原文】【疏】就戒緣中。初、明調達執五法相，二、明伴黨比丘助破為緣。
【譯文】【疏文】在制戒緣起中。第一、說明提婆達多執持五法的相狀；第二、說明同黨比丘協助破僧來作為發起制戒的因緣。

【223-0026】02_戒疏/10d_卷三上之一#131
【原文】【疏】就前五法，「乞食、糞衣、露坐」，似佛四依，為相似語故。然不同四依開制託緣，此三調達說必盡形故。後二妄語者，調云「蘇鹽味重，魚、肉損生」，故立二斷也。調達云：「以此五法，為人說時，年少比丘，必多信受，上座長老，則不允從。」於王舍城創說之時，五百年少，一時信受。六十長老及阿難云：「此是非法，非毗尼，非佛教。」脫鬱多羅僧於一面。前已設諫，今猶復行。四伴順從，故又設諫。緣相如此。
【譯文】【疏文】就前面所說的五法而言，「乞食、穿糞掃衣、露天而坐」，表面上看很像佛陀教導的「四依法」，屬於相似的語言。然而這不同於佛陀的四依法有開許、有依託緣起的彈性制戒，提婆達多這三條宣稱必須終生貫徹奉行。後面兩條則是純屬妄語，提婆達多說「酥鹽味道濃重增加貪愛，魚肉殘損生靈生命」，所以自立要徹底斷絕這兩樣。提婆達多說：「如果用這五法去向人們宣說，年輕的比丘一定會大多信從接受，上座長老則不會聽從答應。」在王舍城最初倡導此說的時候，有五百位年輕比丘，一時之間全信受採納。六十位長老以及阿難說：「這是非法、非毘尼、非佛陀教導。」（阿難與六十位長老）將上衣（鬱多羅僧）脫下置於一旁（以示反對）。之前僧團已經對其進行過規勸，現在提婆達多依然繼續推行。四個同黨也盲目順從，所以大眾僧又對同黨設立規勸。發起制戒的緣由相狀就是如此。

【223-0027】02_戒疏/10d_卷三上之一#132
【原文】【記】戒緣，牒釋中，二。初明五法，邪正對明。但四依中易其第三，除去後一，復加餘二。欲強佛制，令人受行，一制盡形，更無開許。教雖嚴峻，人不可依，不濟機緣，但成虗設。判歸邪法，其致在茲。前三傍佛，故云「相似」。後二自立，故云「妄語」。「酥鹽味重」者，謂以酥鹽煑肉等為膏。如《多論》酥肉汁、《僧祇》五脂為七藥之類也。
【譯文】【記文】戒律緣起，在提撕解釋當中，分為兩部分。首先說明五法，將邪法與正法對照辨析。提婆達多只是在佛陀的四依法中置換了第三條，去掉了最後一條，又額外增加了其餘兩條。他是想藉此凌駕於佛制之上，強迫別人遵行，一律規定為終生不改，絕無任何開緣通融。這種說法表面雖然嚴苛極端，但一般人根本無法持久依止，既不契合眾生根機，終究只是一紙虛談。將其判歸為邪法，原因全在於此。前三條依傍佛法，故云「相似」。後二自立，故云「妄語」。「酥鹽味重」，是指用酥鹽熬煮肉類等製成膏油之類。就像《薩婆多論》說的酥肉汁、《僧祇律》說的五種動物脂膏作為七日藥之類。
