# 校閱材料　第180檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【180-0001】01_行事鈔/08b_卷中之四#41
【原文】五知懺儀置設。即第五方，宿住差異。
【譯文】第五、明了懺悔儀軌的施設安立。也就是第五種方法中，關於宿住（別住）與否的階位差異。

【180-0002】01_行事鈔/08b_卷中之四#42
【原文】六覆日長短相從。律中，犯眾多殘罪，雖憶數、不憶數；但憶日數長短者，總依日數長日治之。若不憶日數者，從清淨已來治，謂壇場受時已來治也。《十誦》：不憶日月數，應從受大戒已來治。要須云：「乞清淨已來，五年、十年覆藏」；不得直言「乞清淨已來。」以知滿分齊故。《僧祇》云：不憶夜者，當問，無歲時犯耶？若默然者，隨年與。若言不爾者，更問一歲、二、三、四歲時犯耶？隨默然處與之。《十誦》，眾中三諫犯殘已，即於僧中自唱，犯僧殘罪；若不即說，是名覆藏。故知，多人雖知犯，終須發露也。
【譯文】第六、覆藏日數的長短應從長判定。律中說，犯了眾多僧殘罪，無論是記得犯戒次數、還是不記得次數；只要記得覆藏日數長短的，一律依照覆藏日數最長的那一罪來定日治罪。如果完全記不得日數者，則必須從清淨已來開始治罪，也就是從當初在戒壇受具足戒之日起算。《十誦律》說：記不得日月天數的，應當從受大戒以來開始治罪。言詞中一定要說：「乞求自清淨以來，五年或十年的覆藏」；不得單單說「乞求清淨以來」。因為必須確知圓滿屆滿的分限故。《摩訶僧祇律》說：記不得過夜日數的，僧團應當問他：「是在無戒臘（剛受戒時）犯的嗎？」如果他默然承認，就隨他的年數給與別住。如果說不是，就進一步問：「是一歲、二歲、三歲、四歲臘時犯的嗎？」隨他默然承認之處而給與相應的日數。《十誦律》說，在大眾中被三次諫勸而犯僧殘罪後，應當隨即在僧中自己高聲發露說犯了僧殘罪；如果不立即宣說，這就叫做覆藏。由此可知，即使眾人皆已知曉其犯戒，最終仍然必須依律發露懺悔。

【180-0003】01_行事鈔/08b_卷中之四#43
【原文】七明總別懺法。律中知數、不知數等，覆、不覆等，一名多種等，同用一羯磨懺之。又云：有比丘犯眾多僧殘罪，或有覆一日乃至十日者，佛令從十日總懺。《僧祇》：總別各得。如月一日犯一罪覆藏，乃至十日犯一罪覆；或有覆一夜，乃至十夜者；應作十番別住，乃至一番覆藏者，其六夜出罪等，例同。《十誦》：懺僧殘中，具明犯數，及若干日覆等。
【譯文】第七、說明總別合併或個別的懺法。律中說，知曉犯戒次數、不知次數等，有覆藏、無覆藏等，同一個名目下的多種罪相，都可以合併使用同一道羯磨來懺除。又說：有比丘犯了多種僧殘罪，有的覆藏一日、乃至有的覆藏十日，佛陀敕令他從最長的十日作總相合併懺悔。《摩訶僧祇律》說：總相合併或個別分開進行，二者皆可。例如初一日犯一罪而覆藏，乃至初十日犯一罪而覆藏；或者有的覆藏一夜、乃至覆藏十夜；應當作十番別住，乃至作一番總覆藏別住，隨後的六夜摩那埵及出罪羯磨等，例此相同。《十誦律》說：在懺悔僧殘罪的文詞中，必須具體說清犯戒次數，以及覆藏了若干日數等等。

【180-0004】01_行事鈔/08b_卷中之四#44
【原文】八明正加羯磨。分二：先明懺者威儀，教授乞詞。二明羯磨所被。
【譯文】第八、說明正式施加羯磨。分為兩部分：一是說明懺悔者的威儀禮貌，以及教授他祈請的詞句；二是說明羯磨所施加的具體法事。

【180-0005】01_行事鈔/08b_卷中之四#45
【原文】初中，先脫却新淨餘衣，著安陀會及餘麁服，上著欝多羅僧，偏露右肩，脫革屣，合掌曲身低頭，來至僧中。自慨此罪，將入重處，如上論云：殘有咽喉未死，賴蒙如來曲垂慈憫，開立懺法。又我自慶，預發怖心，得生慚愧；不知此懺者，則五十億六十千歲，唐受地獄。如是等緣，以為悲喜方便；深自慨責，恥己罪累，塵坌清眾。如是鞭心已，四面禮僧足訖。至羯磨者前，互跪合掌，若自乞陳，旁人授之亦得：「大德僧聽！某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜；今從僧乞百夜覆藏羯磨，願僧與我百夜覆藏羯磨。慈憫故！」三乞已。
【譯文】在第一部分中，懺悔者應當先脫下嶄新潔淨的多餘衣物，穿上安陀會（五條下衣）及其他粗糙布服，外上身披著欝多羅僧（七條中衣），偏袒右肩，脫去皮鞋，合掌屈身低頭，來到僧眾之中。自我慨嘆所犯此罪，幾乎快要墮入極重之處（波羅夷），如同上述論書所說：犯僧殘罪就如同咽喉尚存一息而未徹底斷氣，全賴蒙受如來曲垂慈悲愍念，開闢創立了出罪懺法。又自我慶幸，預先發起了怖畏惡道之心，得以生起大慚愧；如果不知此懺法者，則將在五十億六萬歲的漫長歲月中，徒然在地獄中受盡折磨。以這諸般思維，作為悲泣與慶幸的修持前導；深深自責自省，深恥自己的罪愆牽累、染污了清淨大眾。如此策勵鞭策自心之後，向四面頂禮眾僧之足完畢。來到羯磨師座前，右膝著地互跪合掌，或者自己陳詞乞求，由旁人教授文句亦可：「大德僧聽！某甲比丘，犯了故意漏失不淨、摩觸女人、向女人說麁惡語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜；如今向僧團乞求一百夜的覆藏羯磨，願僧團給與我一百夜覆藏羯磨。慈愍我的緣故！」如此乞求三次完畢。

【180-0006】01_行事鈔/08b_卷中之四#46
【原文】次明與法。索欲、問和、答已，作云：「大德僧聽！某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜；今從僧乞百夜覆藏羯磨。若僧時到僧忍聽：僧與某甲比丘，百夜覆藏羯磨。白如是。」「大德僧聽！某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜；今從僧乞百夜覆藏羯磨；僧今與某甲比丘，百夜覆藏羯磨。誰諸長老忍僧與某甲比丘百夜覆藏羯磨者，默然；誰不忍者，說。是初羯磨。」「僧已忍，與某甲比丘百夜覆藏羯磨竟。僧忍，默然故。是事如是持。」
【譯文】其次說明授與懺法。索取與欲、詢問和合、回答完畢之後，羯磨師作法宣白：「大德僧聽！某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜；如今向僧團乞求一百夜覆藏羯磨。若僧團時機已到，僧團聽許：僧團給與某甲比丘一百夜覆藏羯磨。單白如是。」「大德僧聽！某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜；如今向僧團乞求一百夜覆藏羯磨；僧團如今給與某甲比丘一百夜覆藏羯磨。各位長老凡是贊同僧團給與某甲比丘一百夜覆藏羯磨的，請默然；有不贊同的，請說話。這是初番羯磨。」「僧團已經贊同，給與某甲比丘一百夜覆藏羯磨完畢。因為大眾贊同而默然故。這件事就這樣遵行受持。」

【180-0007】01_行事鈔/08b_卷中之四#47
【原文】九明奪行誡勅行護法。
【譯文】第九、說明剝奪權利行法、誡敕以及行持護戒的方法。

【180-0008】01_行事鈔/08b_卷中之四#48
【原文】羯磨者告云：「此白四羯磨，聖教良藥，遵之在心。奪三十五事，是折伏法，勿得有違；執眾勞苦，奉清淨比丘，是調伏法，每事順行；白等八事，是發露法，宜加愧恥，深自剋責，依法而白，不得有失。失者，失宿，自慢慢他。」
【譯文】羯磨師告誡他說：「這白四羯磨，乃是聖教中治罪的殊勝良藥，應當銘記遵行於心。剝奪你的三十五種權利僧事，這是折伏你慢心的方法，切不可有所違背；操勞大眾苦役之役，承事供奉清淨比丘，這是調伏自性的方法，事事皆須順從奉行；對客比丘等發露稟白的八種事，這是發露罪垢的方法，應當倍加慚愧恥辱，深深自責克己，依法一一稟白，不得有絲毫遺失差池。若有所闕失，便會失去當夜的修行天數（失宿），不僅自己放逸怠慢，也欺慢了他人。」

【180-0009】01_行事鈔/08b_卷中之四#49
【原文】示語已，即因僧集，白僧令知。應教云：「大德僧聽！某甲比丘，犯故漏失僧殘罪，不憶數，覆藏一夜乃至百夜；已從僧乞覆藏百夜羯磨，僧已與我百夜覆藏羯磨；我某甲比丘，從今日行，白大德僧知，我行覆藏。」
【譯文】開示訓勉完畢之後，便趁著僧眾集會之時，向僧團發露稟白令眾人知曉。應當教導他說：「大德僧聽！某甲比丘，犯了故意漏失僧殘罪，記不得次數，覆藏了一夜乃至一百夜；已經向僧團乞求覆藏一百夜羯磨，僧團已經給與我一百夜覆藏羯磨；我某甲比丘，從今天起開始奉行別住，稟白大德僧知曉，我正在行覆藏。」
