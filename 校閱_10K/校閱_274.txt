# 校閱材料　第274檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【274-0001】01_行事鈔/12b_卷下之四#13
【原文】初中，《華嚴》云：「若有不識出家法，樂著生死不求脫，是故菩薩捨國財，為之出家求寂靜。五欲所縛不離家，欲令眾生解脫故，示現不樂處五欲，是故出家求解脫。」以此文證，故知出家，功由菩薩。《郁伽長者經》、《涅槃經》等，並有出家之法。
【譯文】在第一門中，《華嚴經》說：「如果有人不認識出家之法，耽著於生死而不求脫離，因此菩薩捨棄國土財寶，為了他們而出家求取寂靜。世人被五欲繫縛而不能出離家庭，菩薩為了讓眾生獲得解脫的緣故，示現不樂於貪著五欲，所以出家求得解脫。」以此經文為證明，可知出家的大功德是由菩薩所倡導開顯的。《郁伽長者經》、《大般涅槃經》等經中，也都有出家之法。

【274-0002】01_行事鈔/12b_卷下之四#14
【原文】二明勸出有益者。《華手經》：菩薩有四法，轉身當作善來比丘，蓮華化生，現增壽命：一自樂出家，亦勸助他人，令其出家；二求於佛法，無有懈倦，亦勸他人；三自行和忍，亦勸他人；四習行方便，深發大願。《出家功德經》云：若放男女奴婢人民出家，功德無量。譬四天下，滿中羅漢，百歲供養；不如有人，為涅槃故，一日一夜，出家受戒，功德無邊。又如起七寶塔，至三十三天，不如出家功德。《智論》云：出家人雖破戒，破戒墮罪，罪畢得解脫。如《蓮華色尼本生經》說。如佛度醉婆羅門，以無量世來，無出家心，因醉發心，後當得道，因說出家偈。《本緣經》云：一日一夜出家故，二十劫不墮三惡。《祇律》：一日一夜出家修梵行，離六百六千六十歲三塗苦。
【譯文】第二、說明勸導出家有大益處。《華手經》記載：菩薩若具足四種法，轉生後應當成為「善來比丘」（以佛喚善來而自然具足戒），於蓮華中化生，現世增長壽命：一是自己樂於出家，也勸勉協助他人令其出家；二是精求佛法無有懈怠疲倦，也勸勉他人如此；三是自己奉行調和忍辱，也勸勉他人如此；四是修習實踐善巧方便，深發大誓願。《出家功德經》說：如果放任兒女、奴婢、百姓出家，功德無量無邊。好比四大天下滿是阿羅漢，以百年時間供養他們，還不如有人為了證得涅槃，一日一夜出家受戒的功德廣大無邊。又如同建造七寶佛塔高聳到達三十三天（忉利天），其福報也不如出家的功德。《大智度論》說：出家人即使破了戒，雖然破戒會墮落受罪，但罪報受畢仍能獲得解脫，正如《蓮華色尼本生經》中所說的那樣。又如佛陀度化醉酒的婆羅門，他於無量世以來從無出家之心，只因酒醉而發心出家，佛便給他剃度，預言他未來定能成道，佛陀因而說了讚歎出家的偈頌。《菩薩本緣經》說：只因一日一夜出家的緣故，便能在二十劫中不墮入三惡道。《摩訶僧祇律》記載：一日一夜出家修持清淨梵行，便能遠離六百六千六十年的三塗惡道之苦。

【274-0003】01_行事鈔/12b_卷下之四#15
【原文】三障出有損。《出家功德》云：若為出家者，作留礙抑制，此人斷佛種，諸惡集身，猶如大海；現得癩病，死入黑闇地獄，無有出期。
【譯文】第三、說明障礙出家具有大損害。《出家功德經》說：如果對想要出家的人設置阻礙、橫加壓制，這個人便斷絕了成佛的種子，一切惡報聚集在其身上，廣大如同大海；現世會罹患痲瘋重病，死後將墮入黑闇地獄，永無出離之期。

【274-0004】01_行事鈔/12b_卷下之四#16
【原文】四明既出家已，行凡罪行。《大寶積經》云：出家有二種縛：一見縛，二利養縛。有二癰瘡：一者求見他過，二者自覆己罪。經中又言，有二毒箭，雙射其心：一邪命為利，二樂好衣鉢。《涅槃》云：我涅槃後，濁惡世時，多有為飢餓故，發心出家，名為禿人；見有持戒、威儀具足，清淨比丘，護持正法；驅逐令出，若殺若害。若論罪行，且列五種：所謂貪欲、瞋恚、愛親、求利、慳嫉等五。並如《別鈔》，隨事引文。
【譯文】第四、說明已經出家之後，卻行持凡夫罪惡之行。《大寶積經》說：出家人有兩種繫縛：一是邪見縛，二是利養縛。有兩種癰瘡：一是專門尋求挑剔他人的過失，二是掩蓋隱瞞自己的罪咎。經中又說，有兩支毒箭同時射中其心：一是依邪命謀取私利，二是貪愛喜好名貴的衣物鉢具。《大般涅槃經》說：我滅度之後，在五濁惡世之時，會有許多人因飢餓困頓的緣故發心出家，這些人被稱為「禿人」；他們見到有持守戒律、威儀具足的清淨比丘護持正法，反而將其驅逐驅趕出去，甚至加以殺害。如果要論述罪行，暫且列舉五種：即貪欲、瞋恚、貪戀親眷、追求名利、慳貪嫉妒等五種。這些都如《別鈔》中隨事引證經律之文所載。

【274-0005】01_行事鈔/12b_卷下之四#17
【原文】五明出家行凡福行。謂有比丘，出家已後，但知持戒，不志尚道；以戒為上，餘悉不為，用為非道；內多瞋怒，自污淨心，情無勝進。此戒取見，見取煩惱，欲界下業，非上界行；若修世禪，是上界業，終退生死，未有出期；乃至多聞、布施、講經、誦習，並是欲有，未成無漏。《智論》云：世間法者，孝順父母、供養沙門、布施持戒、四禪四無色定、念佛法僧、九想等是。《成論》云：於持戒、多聞、禪定等少利事中，自以為足；以貪著此少利事故，忘失大利。智者不應貪著小利，忘失大利。
【譯文】第五、說明出家後只行持凡俗的人天福報之行。這指的是有的比丘出家之後，只知道拘泥持戒，卻沒有慕求聖道的心志；自以為持戒最為崇高，其餘種種行門一概不做，甚至視其為非道；內心常多瞋怒，自己染污了清淨心，志向上毫無殊勝的精進。這屬於「戒禁取見」與「見取見」的煩惱，純屬欲界的低下善業，並非色界、無色界的上界之行；若是修持世間禪定，雖然屬於上界的善業，但終究還會退墮於生死輪迴之中，難有出離之期；乃至博學多聞、行布施、講說經論、諷誦修習，也全都是欲界的有漏之因，未能成就無漏解脫。《大智度論》說：所謂世間法，包括孝順父母、供養沙門、布施持戒、四禪四無色定、念佛法僧、九想觀等都是。《成實論》說：在持戒、多聞、禪定等小利益的事項中，自己便感到滿足；因為貪著於這些微小的利益，反而忘失了成佛解脫的大利益。有智慧的人絕不應當貪著眼前微利而忘失終極的大利。

【274-0006】01_行事鈔/12b_卷下之四#18
【原文】六明出家行聖道行。但出聖道，無始未曾，皆由著世慣習難捨。今既拔俗，必行聖業。經中乃多，要分三位：一者小乘人行。觀事生滅，知無我人善惡等性。二小菩薩行。觀事生滅，知無我人善惡等相。三大菩薩行。觀事是心，意言分別。故《攝論》云：從願樂位，至究竟位，名觀中，緣意言分別為境。離此無別餘法。上二別行，如餘所明。若入道方便，除疑捨障；要拔諸行，常志行者；如別行門二十卷中，具廣分別。
【譯文】第六、說明出家應當行持出世聖道之行。然而修出世聖道，是無始以來未曾實踐過的，皆因執著世俗的習氣根深蒂固而難以割捨。如今既然脫離世俗，就必須奉行出世聖業。經典中論述雖多，概要可劃分為三個位階：第一是小乘人行。觀察一切事相的生滅變化，通達沒有我、人以及善惡等實體自性。第二是小菩薩（初發心菩薩）行。觀察事相的生滅，通達沒有我相、人相及善惡等分別假相。第三是大菩薩行。觀察一切事相皆是唯心所現，純為意識言語之虛妄分別。因此《攝大乘論》說：從勝解行位（願樂位）直到究竟佛果位，在此觀照之中，皆以意言分別為所緣之境。離開了意言分別，再無其他外在諸法。上述大小菩薩兩類分別之行門，如其他論卷所闡明。至於悟入聖道的方便、斷除疑惑、捨離障礙；提綱挈領超拔一切諸行，使修行者恆常立志實踐之法，正如《別行門》（二十卷）中詳細廣泛的辨析。

【274-0007】01_行事鈔/12b_卷下之四#19
【原文】七明大小乘相決同異。三乘道行，如上已明。今通決正，不出三學；一切聖人，無不行此。
【譯文】第七、說明大小二乘相互決斷同異。三乘的修道行法，如上面已經說明。現在通盤考訂辨正，都不超出戒、定、慧三學；一切聖賢，沒有不實踐三學的。
