# 校閱材料　第617檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【617-0001】資持記/13c_下一#57
【原文】言成分者，由身出界，不妨作法故。又下，次明心念受者，應云此是我物，三說。若時下，次明時定。律因舊住時中不分，意令客去人少物多。佛罰之者，以非時人多，得物反少，故知此施必在時中。既轉同非時，則須羯磨，義復明矣。次科。隨意與者，或等或分也。三中。住日若等，即二處受；
【譯文】說「算有一份」，是因為他雖然身體出了結界，卻不妨礙羯磨作法的成立。「又……」以下，接著說明心念受法，應當說「這是我應得之物」，說三遍。「若時……」以下，接著說明時間的固定。律中因為舊住僧人在規定時間內不予分配，存心想讓外來客僧離開，好讓僧人少而物品多分。佛陀懲罰他們，是因為在非時的狀態下人數眾多，所分得的物品反而減少，由此可知這種布施必定要在規定時間內分完。既然轉變等同於非時施，就必須透過羯磨作法，這項義理便再次明朗了。下一科判，「隨意與」，或者均等給予，或者按比例分配。第三項中，如果居住的天數均等，就在兩處都領取；

【617-0002】資持記/13c_下一#58
【原文】以是難緣，不成破故。據此，時現前施，亦應得受。非時現前中，初示名相。下引律緣。因事而施，顯是非時。又下，次引分法。次科，初明與三眾法。本出二種僧得，今欲例同二種現前，故此引之。初明檀越自分。若檀越下，次明比丘為分。後引二律會同。可解。然諸文通泛，故注以決之。
【譯文】因為這屬於危難的緣故，並不構成破除安居。根據這一點，此時現前的布施，也應當可以分受。在「非時現前施」中，最初指明名稱與相貌。下方引述律中的因緣，因為特定事件而布施，顯明這屬於非時施。「又……」以下，接著引述分配的方法。下一科判，最初說明分給下三眾的作法。原本出於兩種僧得施，如今想要比照同於兩種現前施，所以在此處引用。起初說明檀越自己來分配；「若檀越……」以下，接著說明比丘代為分配；其後引用兩部律典進行融通比對，文義容易理解。然而各處文字都較為寬泛，所以加註注文予以裁決。

【617-0003】資持記/13c_下一#59
【原文】四下，後分淨人。注指如後。非時僧得中，初示名相。三時總指一歲，以釋非時。不局一界，通攝十方，即明僧得也。將下，次明分法。斷字上呼，止也。次科。白二同下分亡物法，但改緣云，此住處僧大得可分衣，現前僧應分等。二部，標中。謂檀越通施僧尼，隨來者得，故云互正。
【譯文】「四……」以下，最後分給寺院淨人，注文指引詳見後文。在「非時僧得施」中，最初指明名稱與相貌。「三時」總括指稱一年，用來解釋「非時」；不受一個結界的局限，普遍攝納十方僧眾，就是說明「僧得」。「將……」以下，接著說明分配之法。「斷」字讀作上聲，是停止的意思。下一科判，白二羯磨同於下方分配亡僧遺物的作法，只是更改緣起為「這處住處的僧眾獲得大量可供分配的衣物，現前的僧眾應當進行分配」等語。在「二部僧」的標目中，是指檀越普遍布施給僧尼二眾，隨何者先來何者即獲得，所以說是「互為正主」。

【617-0004】資持記/13c_下一#60
【原文】言四種者，謂二部僧得二部現前，各有時非時故。二部互中，初別示互正。律云：時有住處二部僧，多得可分衣物，僧多尼少，佛言：分作二分；若無尼，純式叉純沙彌尼，亦分作二；分若無尼三眾，比丘僧應分〔此僧為正〕。若尼多僧少，若無僧，乃至沙彌亦為二分；
【譯文】所說的「四種」，是指二部僧得施與二部現前施，各自有時施與非時施的緣故。在「二部互相通融」中，最初個別指出誰為主體。律中說：當時有一處住處的二部僧，獲得了大量可分配的衣物，僧多而尼少，佛陀說：分成兩份；如果沒有比丘尼，只有式叉摩那或只有沙彌尼，也分成兩份；如果沒有女眾三眾，比丘僧就應當全分（這時僧為主體）。如果尼多而僧少，如果沒有比丘，乃至只有沙彌也分成兩份；

【617-0005】資持記/13c_下一#61
【原文】俱無二眾，比丘尼應分〔此尼為正〕。如下，總示分法，初明本部各分。《注羯磨》云：至當部中，皆須作羯磨分。不下，顯互取之意。非謂五眾得同作法。當部互中，初明受施作相。及在座者，謂就本座而施者。若有下，次明取他遺物。謂比丘受請，在白衣舍，去後遺物；
【譯文】如果男眾完全沒有，比丘尼就應當全分（這時尼為主體）。「如……」以下，總括說明分配的方法，最初說明本部各自進行分配。《注羯磨》說：到了自己當部之中，都必須作羯磨來分配。「不……」以下，顯明相互取用的意圖，並非說五眾可以共同舉行羯磨作法。在「當部互相通融」中，最初說明接受布施時鳴椎集僧的作相；「及在座」，是指就著原來的座位而行布施。「若有……」以下，接著說明取用他人遺留的物品。是指比丘應供，在居士家中，離開之後遺漏了衣物；

【617-0006】資持記/13c_下一#62
【原文】後來比丘，或因俗施；受取進否，故須明之。知來犯墮，由是他物，不合取故；但俗所施，不成盜重。知死犯棄者，縱是他施，亦合僧分。亡物，敘意中，初科，上二句示財物。利，宜也。然下，敘人根，初明上士慕道。濟遠謂越二死海；濟，度也。經勞，謂歷於苦事。
【譯文】後來的比丘，或者藉由居士施捨，接受取用算不算違犯，所以必須說明。明知原物主會回來卻拿取則犯墮罪，因為這是別人的物品，不應當拿取的緣故；但既然是居士所施捨，便不構成重罪的偷盜罪。明知原物主已死卻拿取則犯波羅夷（犯棄）罪，縱使是居士施捨，也應當收歸大眾僧共同分配。在「亡物」的「敘意」中，初科上兩句指示財物。「利」是合宜的意思。「然……」以下，敘述人的根機，最初說明高尚之士嚮慕道業。「濟遠」是指橫渡分段與變易這兩種生死苦海；「濟」是度化的意思。「經勞」是指經歷辛勞辛苦的事務；

【617-0007】資持記/13c_下一#63
【原文】涉樂，謂趣於無為。俗譽，即世間名聞。蕭然，即脫離之貌。上四句敘其志，下二句明其行。次明下士希利；融，通也。然下，明相濟。《論語》云：君子上達〔達仁義也〕，小人下達〔達財利也〕；今借彼語，用目二機。謂上士雖輕於利，當行法以利人，故云濟器；
【譯文】「涉樂」是指趨向清淨無為的涅槃。「俗譽」就是世間的名聲榮譽；「蕭然」就是灑脫出離的樣貌。上四句敘述其志向，下兩句顯明其行持。接著說明低下之士貪求財利；「融」是通達的意思。「然……」以下，說明彼此相互救助扶持。《論語》說：「君子上達（通達仁義），小人下達（通達財利）」；如今借用那些世俗詞語，用來指稱這兩種根機。意思是高尚之士雖然輕視利益，卻應當推行教法來利益他人，所以說是要濟度群器（利濟他人）；


【617-0008】資持記/13d_下一#1
【原文】下根雖重於財，當依法而稟行，故云隨懷。然上士不可以輕利而棄法，下流不可以重財而任情，故云俱須等。通謂流通。一道淨行，即分衣法；三世同遵，故云一道；離塵遣著，故曰淨行。次科，初敘諸師處斷。指南者，古有作指南車，亦名司南，以示迷方者。但下，示各執所以。
【譯文】根基較淺的人雖然重視財物，仍應當依照戒律來奉行，所以說要「隨順其心懷」。然而，有德的上士不能因為輕視利益就廢棄戒法，底層的劣修者也不能因為看重財物就任憑私情，因此說兩者「都必須」依教奉行。流通，指的是讓法義流傳開通。純一無雜的清淨行業，指的就是分配亡僧遺衣的法規；過去、現在、未來三世諸佛都共同遵行，所以稱為「一道」；遠離塵俗貪染、遣除執著，所以稱為「清淨行業」。下一段科判，首先敘述歷代諸位律師所作的處斷裁決。「指南」，古人曾製造指南車，也稱作司南，用來為迷失方向的人指示方位。「但」字以下，說明各家堅持己見的原因。

【617-0009】資持記/13d_下一#2
【原文】六師持律，尋序可見。至下，點古未詳。臨下，示今要旨。三中十門。初二及十，各局一門；三下七科，次第行事。制意中，初意，上二句徵問。生下，釋通又二，初約義定。以下，出所以。故下，引決。次意中，初義判。僧下，引示，《僧祇》。具云阿若多，此翻解本際，又云知無，知空無故。
