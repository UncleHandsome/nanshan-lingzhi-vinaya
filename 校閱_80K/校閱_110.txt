# 校閱材料　第110檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【110-0001】資持記/02a_上一下#45
【原文】阿難悲惱，三請世尊住壽一劫。佛說偈云：我所說諸法，即是汝等師；又云：汝等勤精進，如我在無異。今取經意，文有少異。《遺教》。文見卷首。論釋云：示現波羅提木叉是修行大師故，示現人法住持相似故。等者，如諸經佛臨滅時，阿難請問四事。第二問云：佛滅度後，以誰為師？
【譯文】阿難尊者悲傷憂惱，三次懇請世尊住世一劫；佛陀於是說偈言道：「我所宣說的一切法，就是你們的導師」；又說：「你們應當勤奮精進，這與我親自住世毫無差別」；現在鈔文採納經文的大意，文字稍微有些出入。《遺教經》的這段文字出現在經文卷首；論疏解釋說：示現波羅提木叉（戒經）就是大眾修行的導師，也是示現出佛陀住世（人住持）與戒法住持（法住持）是同等無異的；經文所說的「等等」，好比各大經典記載佛陀即將滅度時，阿難請問了四件事，第二個問題問：「佛滅度之後，我們以誰為師？」

【110-0002】資持記/02a_上一下#46
【原文】佛言：以戒為師。〔初問依何而住？令依四念處住。三問經首安何語？令安如是我聞等。四問治惡性比丘，令默擯治之。〕二中。發趣者，發謂起行，趣謂所期。萬行舉其大數。宗是尊義主義。萬行之中，戒為尊主。所以然者，有多義故。一由資始故，二有期誓故，三有本體故，四攝境遍故，五止作統故。
【譯文】佛陀回答說：「以戒為師」（第一個問題是依憑什麼而住？佛令依四念處而住；第三個問題是經文開頭應安立什麼話語？佛令安立『如是我聞』等字；第四個問題是如何處置惡性比丘？佛令採取默擯的方式懲處他）。第二點：所謂「發趣」，「發」是發起行持，「趣」是所期盼的歸宿；「萬行」是列舉行持的大略多數；「宗」是至尊之義、主導之義；在萬種行持之中，戒律是最為尊貴的主導者；之所以如此，是因為具有多重意涵：第一是它是修行的開端，第二是受戒時發有誓願，第三是有無作戒體作為根本，第四是戒法所攝受的境界最為周遍，第五是戒法統攝了一切止持與作持；

【110-0003】資持記/02a_上一下#47
【原文】餘行無此，故為卑為賓耳。故下，引證。《古記》云：即《善生經》，然與戒本序語意相涉。上句總彼兩句，故云等也。戒以足喻，頗符發趣之義。然從權意，且指人天；須知所趣實通五乘，如前已辨。三中，初舉喻。地有二義：一能生，二能持。兩引《遺教》，止得初義。
【譯文】其他行持都不具備這些特性，所以相對居於從屬與賓客的地位。「故」字以下，引用經文作證，《古記》記載：這出自《善生經》，然而這段文字與戒本序的文意彼此相通；上一句總括了經文的兩句話，所以用了「等」字；將戒律比喻作雙足，極為貼合「發趣啟程」的含意；然而若順從權巧的教意，姑且只指向生於人天善道；但必須明白戒足所要奔赴的歸宿，實質上貫通五乘聖果，這在前面已經辨析過了。第三點中，首先提出譬喻；大地有兩種特性：第一能生長萬物，第二能承載住持萬物；兩次引用《遺教經》，都只取了第一種「能生長」的意涵；

【110-0004】資持記/02a_上一下#48
【原文】上云諸善，通漏無漏及動不動。下云定慧須約聖道，唯在無漏及不動耳。又下，次引律文，雙示二義。即本律〈說戒揵度〉中文。而言經者，名通三藏，皆佛語故。〔舊云：《善生經》者，檢彼無文。〕先引文。即下，喻合。經云行根，即能生故。上三約喻，則初師、二足、三地。
【譯文】上面所說的「一切善法」，通於有漏善、無漏善，以及動亂心態與不動定境中的善；下面所說的「定慧」，則必須依聖道來論斷，唯獨局限在無漏善法與不動禪定而已。「又」字以下，其次引用律典的文字，同時展示能生與能持這兩種特性；這出自本律〈說戒揵度〉的內容；之所以引律而稱為「經」，是因為「經」通名於經律論三藏，全都是佛陀教說的緣故（舊說認為出自《善生經》，但查檢該經並沒有這段文字）；先引用律文，接著「即」字以下將譬喻與法義結合；經文所說的「行持根基」，就是具備能生長的涵義；以上三種譬喻，第一是導師，第二是雙足，第三是大地；

【110-0005】資持記/02a_上一下#49
【原文】合法者，初是軌物，二即攝行，三能生功德。小乘論中，《成實》三喻。柱喻依持，郭喻防禦，印喻為人所信。初言道品，即是慧學。次第增深，隨有所見，故如樓觀，即三十七品。四念處〔一身不淨，二受是苦，三心無常，四法無我。破四顛倒，即是念處。
【譯文】在法義的配合上：第一項戒法是規範人事的導師，第二項戒法是統攝一切行持的雙足，第三項戒法是能生長一切功德的大地。在小乘論典中，《成實論》提出了三種譬喻：柱子比喻依憑護持，外城郭比喻防禦外敵，印鑑比喻為人所信任；最初說的「三十七道品」，指的就是智慧之學；由淺入深次第增進，隨其所見境界層層拔高，所以比喻為樓觀樓台，也就是三十七菩提分法：四念處（第一觀身不淨，第二觀受是苦，第三觀心無常，第四觀法無我；破除四種顛倒，就是四念處）；

【110-0006】資持記/02a_上一下#50
【原文】四正勤〔一已生惡令斷，二未生惡不生，三未生善令生，四已生善令增長，於正道中勤行故也。〕、四如意足〔一欲，二精進，三心，四思惟。所願皆得，故名如意。〕、五根〔一信，二精進，三念，四定，五慧。竝取能生，故名為根。〕、五力〔即上五根，望能壞有漏不善故名力。
【譯文】四正勤（第一已生惡令斷除，第二未生惡令不生，第三未生善令生起，第四已生善令增長；在正道之中勤勉精進的緣故）；四如意足（第一欲，第二精進，第三心，第四思惟；所祈求的心願皆能圓滿，所以名為如意）；五根（第一信根，第二精進根，第三念根，第四定根，第五慧根；都取其能生長善法的力量，所以名為根）；五力（也就是上述五根，對望於能摧壞有漏不善法的力量而言，所以名為力）；

【110-0007】資持記/02a_上一下#51
【原文】七覺分〔一擇法，二精進，三喜，四除，五捨，六定，七念。無學實覺，七事能到，故名覺分。〕、八正道〔一見，二思惟，三語，四業，五命，六精進，七念，八定。八竝離邪為正，能通涅槃名道。〕。二禪定者，顯是定學。定以防心，抑制妄動，故喻如城。
【譯文】七覺分（第一擇法，第二精進，第三喜，第四除，第五捨，第六定，第七念；無學位的真實覺悟，憑藉這七件事能夠達成，所以名為覺分）；八正道（第一正見，第二正思惟，第三正語，第四正業，第五正命，第六正精進，第七正念，第八正定；這八項全都遠離邪妄而回歸純正，能通達涅槃彼岸，所以名為正道）。第二項談到「禪定」，顯然是指定學；禪定用以防護自心、抑制妄念妄動，所以比喻為城堡；

【110-0008】資持記/02a_上一下#52
【原文】即同《遺教》喻堤塘也，謂四禪四空定及餘無漏諸禪三昧。戒為郭者，郭謂外城。三入眾者，即屬戒學；謂羯磨說戒二種僧中，具戒清淨方可預故。下二句結勸。《解脫論》，第二〈分別戒品〉。指令尋之，今為略引。彼云：若人有戒。為有戒故，成就無畏；
【譯文】這就如同《遺教經》把禪定比喻為防護水流的堤防一樣，是指四禪、四空定以及其餘一切無漏諸禪定三昧；以戒律作為「郭」，「郭」是指外城的防禦城牆。第三項談到「進入大眾」，這屬於戒學的範疇；也就是在舉行羯磨法與說戒這兩種僧團集會中，必須具足戒體且操行清淨，才可以參與；下面兩句是總結勸勉。《解脫道論》第二卷〈分別戒品〉，鈔文中指示讀者自行查尋，現在為大家簡略摘引；那部論說：如果人能具足戒律，因為有戒律的緣故，便能成就無所畏懼的德能；

【110-0009】資持記/02a_上一下#53
【原文】榮顯親友，聖所憐愍，是親友依，是善莊嚴，是領諸行，是功德處，是供養處，是可貴同學處，於諸善法不畏不退，成就一切意願清淨，雖死不忘，成伏解脫樂方便，如是無邊戒功德。《毘婆沙論》，初中。初句牒所受，下列四義。尸羅，梵言，此翻為戒。今以梵語，猶含多義，故反釋之。

【110-0010】資持記/02a_上一下#54

【原文】和者有六：戒見利三，名體和；身口意三，名相和。又初果已去名理和，所證同故；內凡已還名事和，即六和也。若下，反明須集之意。上二句明人非。乖離者，總三種別。御下法非。被下事非。法事縱如，由人非故，二並不成。故下，文含三意：一釋首題，二結篇意，三即分章。示前後中。
【譯文】所謂和合有六種層面：戒和同行、見和同解、利和同均這三項，稱為體性上的和合；身和同住、口和無諍、意和同悅這三項，稱為事相上的和合。另外證得初果須陀洹以上的聖人稱為理和，因為所證得的無為真理完全相同；內凡位以下的凡夫修行者則稱為事和，指的就是六和敬的法門。從「若」字以下，反面說明必須召集大眾的用意。上面兩句說明人的身分不如法。所謂違背乖離，總體涵蓋了三種別眾離異的過失。從「御」字以下說明所施行的羯磨法不如法。從「被」字以下說明所處理的執事法不如法。即便羯磨法與所辦之事都合乎律制，但只要出家人數或身分不如法，這兩者便完全不能成就。因此「故」字以下，文句包含了三重用意：第一是解釋章節首題，第二是總結本篇旨趣，第三就是劃分章節段落。在指示先後次序中。
