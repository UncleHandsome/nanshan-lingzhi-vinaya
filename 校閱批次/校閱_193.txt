# 校閱材料　第193檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【193-0001】資持記/13a_下一#35
【原文】《業疏》云：諸部極小唯《四分》文，出家貧乏，故是常也。餘二衣長九尺，廣五尺四寸。然下，出通量。但云下衣極小，準餘二衣非小明矣。然恐身量短長不定，是故三衣俱準通量。言度身者，此有二法。一準《多論》。佛身丈六，衣長丈八，廣丈二。常人半之，衣長九尺，廣六尺。
【譯文】《業疏》說：各部律中最小的尺寸唯有《四分律》的記載，這是考慮到出家人生活貧乏簡樸，所以將其立為常規。其餘兩件衣（七條與大衣）長九尺，寬五尺四寸。自「然」字以下，引出通用的彈性尺寸。文中只說下衣極小，由此推知其餘二衣並非極小，這是很明白的。然而唯恐每個人的身軀身材長短不一，因此三衣都准許參照通用的尺寸來裁製。所謂「依照身材裁度」，這裡有兩種方法。第一種依準《薩婆多論》：佛的身軀長一丈六尺，衣服長一丈八尺，寬一丈二尺。普通人的身材折半計算，衣服長九尺，寬六尺。

【193-0002】資持記/13a_下一#36
【原文】〔與《四分》小異。〕據此以算，人身長一尺，則長邊得一尺一寸二分半，廣邊得七寸五分。如是增之，則八尺之人，可著長九廣六之衣也。更增至佛量亦無差。設或身相長短不稱，減成儉約，過須說淨。二準《業疏》。就身裁度。疏云：從肩下地踝上四指以為衣身，餘分葉相，足可相稱。
【譯文】〔這與《四分律》的尺寸略有差異。〕依據這個比例計算，人身長若為一尺，衣服長邊應得一尺一寸二分半，寬邊應得七寸五分。照此等比例增加，那麼身高八尺之人，便可以穿著長九尺、寬六尺的衣服。若再依此增加至符合佛陀身量的比例也不會有差錯。設若身材長短比例不勻稱，尺寸減小則合乎簡約之德，但若超過限制便必須行「說淨」之法。第二種依準《業疏》所說，直接就著身體來裁剪量度。《業疏》說：從肩膀向下垂至腳踝上四指之處作為衣身長度，剩餘分割縫綴的葉相條塊，自然能相稱合度。

【193-0003】資持記/13a_下一#37
【原文】此謂人身多是長短不定，尠有肥羸；縱有肥羸，不妨服用；是故但出廣量，不明長法。〔有云餘分葉相，即是長量；今謂葉相廣長齊有，何獨長邊。〕且今時人少至八尺，但取九尺已內，足可相稱；良由袈裟右角，本在左肩；或垂腋下，是故九尺之服，頗宜八尺之身。
【譯文】這是說人的身形大多是長短高矮不定，很少有單純肥胖或消瘦的極端；縱然體型肥瘦有別，也不妨礙穿著使用；因此律中只定出寬度的標準量法，沒有死板規定長度的標準。〔有人說「剩餘分割的葉相」就是長度的量法；如今我認為葉相的寬度與長度同樣具備，豈能單指長邊呢。〕況且現今之人身高很少能達到八尺，只要取九尺之內，便足以相稱合度；這全是因為袈裟的右角原本是收搭在左肩上，或者垂在左腋之下，所以九尺長度的衣服，極為適宜八尺高的人穿著。

【193-0004】資持記/13a_下一#38
【原文】今則右角前垂，著用乖法；遂使長邊何啻丈二，廣邊不滿五尺。長拕象鼻，動越威儀；習久迷深，何由諫諭。必懷奉法，夫復何言。文中節量等語，本是誡節貪求，令知止足，故云取足而已。今此引用，意顯隨宜，故云準此等。度字入呼，謂裁度也。取字去呼，謂粗略也。
【譯文】現今有些人卻把袈裟的右角向前垂垂掛落，穿用方式完全違背戒法；以致使衣服長邊何止一丈二尺，而寬邊卻連五尺都不到。多餘的部分像長長的象鼻子一樣拖曳著，動輒超越律儀威範；這種習氣由來已久、執迷極深，又從何去勸諭諫正呢！倘若是存心奉持戒法之人，又何須我多言！文中「節量」等言詞，原本是告誡節制貪求之念，令知止足，所以說「取足而已」。如今此處引用，意在顯明隨機便宜制宜，所以說「準此」等語。「度」字讀入聲，是指裁剪量度。「取」字讀去聲，是指大概推求。

【193-0005】資持記/13a_下一#39
【原文】引諸文中，初二字躡上通文。亦下一句，生後引用。然《四分》下衣雖云窄小，而諸部中三衣或等，足可準繩。恐見度身，便即任意廣長無法，故云雖爾等。〔今執丈二長衣，便云《律》有通文者，正墮此過。〕故下，引示諸文，初指二律。《十誦》。上衣長五肘，廣三肘〔同上《四分》〕；
【譯文】在引證諸經律文句中，前兩個字承接上面的通融律文。「亦」字下一句，引導引生後文的引證。然而《四分律》的下衣雖然說極其窄小，而在其餘各部律中三衣的尺寸或者均等，足以作為立規的繩墨規範。唯恐有些人一看到依隨身量，便隨心所欲使廣狹長短全無章法，所以說「雖然如此」等語。〔現今執持一丈二尺長衣的人，便聲稱「律中有相通的條文」，這正是墮入了這種過失。〕自「故」字以下，引述並昭示諸部律文：首先指明兩部律藏。《十誦律》規定：上衣長五肘，寬三肘〔與上述《四分律》相同〕；

【193-0006】資持記/13a_下一#40
【原文】下衣長四肘，廣二肘半〔長同《四分》，廣加九寸，則四尺五寸。〕；七條量在上下之間。《僧祇》。三衣各有三品。上者長五肘，廣三肘〔亦同《四分》〕；中者長五肘一不舒手〔謂五中一肘不舒手量，不滿五肘，準彼論肘舒手量之。〕，廣三肘一不舒手；
【譯文】下衣長四肘，寬二肘半〔長度同於《四分律》，寬度增加九寸，即四尺五寸〕；七條衣的尺寸介於上衣與下衣之間。《僧祇律》規定：三衣各有上、中、下三種品位。上品的長五肘，寬三肘〔這也與《四分律》相同〕；中品的長五肘但其中一肘手指不伸展〔這是說在五肘中有一肘是以握拳不舒展手指的手肘量度，不足標準的五肘長，是依照該論舒手與屈手的量法計算〕，寬三肘其中一肘不伸展手指；

【193-0007】資持記/13a_下一#41
【原文】下衣長四肘半〔八尺一寸〕，廣三肘一不舒手。中下二衣亦各三品，並如上。《婆論》中。三事通有三品。長五廣三〔中衣同《四分》〕；若極大者，長六肘〔一丈八寸〕，廣三肘半〔六尺三寸〕；若極小者，長四肘，廣二肘半。上出三品如法。下明過減非法，初判成受。過者可截，減則可續。
【譯文】下品衣長四肘半〔即八尺一寸〕，寬三肘其中一肘不伸展手指。中衣與下衣也各有三品，標準都如同上述。《薩婆多論》中規定：三衣通用皆有三種品位。標準的是長五肘、寬三肘〔中衣同於《四分律》〕；若是極大的尺寸，長六肘〔一丈八寸〕，寬三肘半〔六尺三寸〕；若是極小的尺寸，長四肘，寬二肘半。以上說明如法合度的三品尺寸。自「下」字以下說明超越或減損尺寸的非法之相：首先判定是否能成就受持之法。超過尺寸的可以截除，縮減不足的可以拼接補續。

【193-0008】資持記/13a_下一#42
【原文】鉢無此義，故受不成。若過下，判犯。準知今時丈二長衣，既不說淨，皆犯長罪。注出受淨前後，以受持外者，屬長物故。〔故知法衣之上，連帶長物；今按《尼鈔》，祖師明斷，若過量外，必須淨施。〕《五分》初緣亦依肘量。但隨人用，不能一準，故云不定。佛令隨身，須依《業疏》肩踝為度。
【譯文】鐵鉢則沒有這種補救的道理，所以規格不合格便無法成就受持。自「若過」以下，判定其犯戒過失。由此可知現今穿著丈二長衣之人，既然沒有依法說淨，便全都犯了蓄長物罪。注釋指明了行說淨法與受持法的前後順序，因為在受持法定額度之外的布料，都屬於長物範圍。〔所以應當知道法衣上面，連帶繫著非法蓄長之物；如今考查《尼鈔》，道宣祖師已明確判定，若是超過規定尺寸之外，必須先行淨施。〕《五分律》最初的制戒因緣也是依隨肘量。但由於每個人體型不同，不能全憑同一尺度，所以說「不定」。佛陀令依隨各自身軀量度，必須依照《業疏》以肩膀至腳踝四指的長度為準。

【譯文】第三項中，《善見律》開頭先說明因緣而開許心念法。從「諸」字以下，接著辨別受持法是否喪失。所謂「八指之內」，是指在八指長度的限度界線以內；（長邊的）一搩手與（安陀會廣邊的）四指，也同樣是指在該限度界線之內。所謂「有橫縷」，是指還有少許絲線相互連接綴合。這是依照破損穿孔來判定失法，下文引述《薩婆多論》則是根據衣緣斷裂來判定失法；兩部論典都引述了，可隨意選用；但若依照《業疏》，則唯獨採用後一種解釋。律疏說：因為周圍的衣緣還在，受持的界限就依然具備。雖然中間破損了，卻開許加以修補整理。

【193-0048】資持記/13b_下一#20
【原文】若又失受，破非意故，煩累則多。但約緣存，攝緣即足。〔此出不取《善見》之意。〕四中，初引《善見》。文列七緣，兼上成八。《四分》，初別舉清隔。具下，通示四礙。恒懷守護，不失無罪；忽爾遇緣，失法無罪，先慢不攝失法得罪。三斷並見離衣戒，故指如上。
【譯文】如果破損就又喪失了受持法，而破損又非出自本意，那麼帶來的麻煩擾累就太多了。只要衣緣還存在，維持住整體的邊界就足夠了（這是說明不採用《善見律》的緣由）。第四項中，開頭先引述《善見律》。文中列出了七種因緣，加上前文合為八種。《四分律》中，開頭分別列出情礙與隔礙（底本作「清隔」，實為「情隔」之訛）。從「具」字以下，通盤顯示四種障礙。常懷守護之心，未曾失法則無罪過；忽然遭遇障礙因緣而失去受持法，也沒有罪過；如果原先怠慢不用心攝持而失去受持法，就要結犯過罪。這三種判決都見於離衣戒中，所以指稱如上所述。

【193-0049】資持記/13b_下一#21
【原文】《義鈔》無文。疏即二疏。五中，《多論》，初明不受無離〔亦復非長〕。《善見》離亦犯提，故注顯異。若下，次明加受失淨。補治中，初科，《十誦》。乃約刺縫以分持犯。二罪者，不說淨提，不點淨吉。《母論》中，初以未淨，縫已淨者。所依有法，攝能依故。
【譯文】《義鈔》中沒有此段文字。「疏」即是指兩部疏文。第五項中，《薩婆多論》開頭先說明未曾受持就不構成離衣之犯（同樣也不構成蓄長衣之過）。《善見律》則認為離開也要犯波逸提，所以夾註指出了差異。從「若」字以下，接著說明重新加受會使原先的說淨失效。在修補整理的章節中，第一科引述《十誦律》，乃是依照縫刺的行為來劃分持戒與犯戒。所謂「兩種罪」，是不作說淨犯波逸提，不作點淨犯突吉羅。在《薩婆多毘尼母論》中，開頭先以未說淨的布，縫合在已經說淨的衣上；這是因為所依託的主體具備法效，能攝受附著在上的客體之故。

【193-0050】資持記/13b_下一#22
【原文】若下，次以已淨縫未淨者。能依有法，染所依故。上明衣和合淨，彼論更有色和合淨，故云通二種也。《羯磨》引云：若色非法，縫著如法者，是名色和合淨，更不須別淨〔謂不更點淨也〕。論文但云縫著，注令準上《十誦》通之。次科，《善見》中二，初明補治不失。欲破即補者，彼論穿破即失受故。
【譯文】從「若」字以下，接著以已經說淨的布縫在未說淨的衣上；這是因為附著的客體具備法效，會沾染所依託的主體之故。上面說明的是衣質的和合淨，那部論典還有色相的和合淨，所以說通於這兩種。《羯磨》引述說：如果顏色不合法，縫在合法的衣服上，這稱為「色和合淨」，就不需要另外點淨（意思是不用再重新點淨染壞）。論典文字只說到「縫著」，夾註令其比照上面的《十誦律》來通達理解。下一科中，《善見律》分為兩節，開頭先說明修補整理不失受持法。所謂「快要破損就立即修補」，是因為那部論典認為一旦穿孔破損就會立即失去受持法之故。

【原文】注中，若準《多論》，義須重加；言隨情者，任便取用。準前疏意，須從《多論》。若浣下，次約色明不失。增色，謂洗已鮮澤也；脫，退也；上，加也。《五分》中。複線謂雙索者，下云重線亦同。文開直縫，於義非便，故須注顯。《四分》中，初引示。

【193-0052】資持記/13b_下一#24
【原文】律下，準決，初示律意。言律令者，即躡上文，但非明顯。故令同論，即前所引欲破未穿文也。多下，次定失否，初舉論。此下，決判。上句點《多論》，下句存《善見》。三中。赭音者，赤土也。絣，此萌反，振繩墨也。四中。幽顯俱訶者，乖威儀故。
【譯文】從「律」字以下，依照法理來裁決，首先指示出律典的本意。所謂「律令」，是承接前文而來，只是表達得不夠明顯。所以應當讓它與論典保持一致，也就是前面所引述「快要破損尚未穿透」的那段文字。從「多」字以下，接著斷定是否失法，開頭先列出論典的觀點。從「此」字以下，做出斷決評判。上一句點出《薩婆多論》的意涵，下一句則存留了《善見律》的主張。第三項中，「赭」讀音為者，是指紅土。「絣」音同此萌反，是指拉彈墨繩劃線。第四項中，所謂「幽隱與顯現皆受訶責」，是因為違背了威儀之故。
