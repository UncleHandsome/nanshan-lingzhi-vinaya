# 校閱材料　第872檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【872-0001】02_戒疏/21c_卷四下之三#47
【原文】【記】次科，初問答中。「事」謂行業，「時」即三世，正徧知海，無不明練。「碎首苦」者，《五分》云：「五百金剛，常隨佛後，三問不答，競舉金剛杵擊碎其頭。」如《涅槃》說，此亦化現，非實爾也。
【譯文】【記文】在下一科判的最初問答中。「事」是指造作的行業，「時」就是指三世，佛陀的正遍知覺性廣大如海，沒有不明白熟稔的。「頭顱碎裂之苦」，《五分律》說：「五百位金剛神，常隨侍在佛陀身後，如果三次詢問不作答覆，便競相舉起金剛杵擊碎他的腦袋。」如同《涅槃經》所說，這也是密跡化現警勵，並非真會如此打碎。

【872-0003】02_戒疏/21c_卷四下之三#49
【原文】【疏】答：「佛眼無不觀了，唯行淨者，方同。僧制取報，三根現淨，得陳說戒。」
【譯文】【疏文】答：「佛眼沒有不能完全觀照了達的，唯獨行持真正清淨的人，才能同住聽戒。僧團的制度是依據當事人的陳報，只要無見、聞、疑三種根由而呈現清淨，就可以陳白並舉行說戒。」

【872-0004】02_戒疏/21c_卷四下之三#50
【原文】【記】次問。僧中通穢是「一開」，佛唯淨境是「一閉」。答文，可解。「報」，告也。
【譯文】【記文】在第二個提問中。僧團中容許濁穢之人是「一者開放」，佛陀唯獨面向純淨之境是「一者禁閉」。回答的文句，容易理解。「報」，就是陳告白告的意思。

【譯文】【疏文】問：「兩者都具備宣說戒法的能力，開放與禁閉的原則仍然令人困惑，請陳述其中的深意？」

【872-0006】02_戒疏/21c_卷四下之三#52
【原文】【疏】答：「佛說不應，則神杵壞之，僧說不應，則無神可損。故知末法，淨穢同居。但說對淨士，會機入正。穢雖在眾，不壞僧法，但自壞行，遠有出期也。」
【譯文】【疏文】答：「佛陀親自說戒時若有犯人不相應，就有神杵擊碎毀壞其首；僧眾自行說戒時若有犯人不相應，則沒有神祇會予以降損。因此可知在末法時期，清淨與垢穢之人雜居混處。但說戒是針對清淨的行者，讓合乎根機的人契入正道。垢穢之人雖然身在大眾中，並不破壞僧團的清淨羯磨法，只是自行敗壞自己的修持，久遠以後仍有出離解脫之期。」

【872-0007】02_戒疏/21c_卷四下之三#53
【原文】【記】三問。以前義未盡，故復徵之。答中，還用初義，兩以釋通。「故」下，顯益。「會機入正」，「會」，合也，「正」，即正道。「遠有出期」者，謂無近益，《業疏》云「自為來習」是也。
【譯文】【記文】在第三個提問中。因為先前的義理尚未窮盡，所以再次提出詰問。在回答中，依舊採用最初的義理，從兩方面來解釋會通。「故」字以下，顯明其中的益處。「會合根機契入正道」，「會」，是契合合致，「正」，就是無上正道。「久遠以後仍有出離解脫之期」，是說眼前沒有立即的利益，如同《業疏》所說「自行種下未來的修習之因」就是這個意思。

【872-0008】02_戒疏/21c_卷四下之三#54
【原文】【律】諸比丘，自有樂法、樂沙門者，有慚、有愧、樂戒者，當於中學。
【譯文】【律文】各位比丘，若有能自求出離、喜愛正法、樂於作沙門者，有羞恥慚愧之心、喜愛戒律者，應當在其中精進研學。

【872-0009】02_戒疏/21c_卷四下之三#55
【原文】【疏】第三，「諸比丘」下，明略教流通也。「自為」者，獨拔厭世也。「樂法」者，修善教也。「樂沙門」者，息惡士也。「有慚」者，隱不起過也。「有愧」者，外無非違也。「樂學戒」者，總攝上五，成斯行本也。「當於中學」者，明上略教，為行者所依，可受而從，必有成濟也。
【譯文】【疏文】第三部分，「諸比丘」以下，說明簡略教法的流布傳通。「自求出離（自為身）」，是指超凡拔俗而厭離世間。「喜愛正法」，是指修持善妙的教導。「喜愛沙門」，是指作為止息諸惡的人。「有慚」，是指在隱密之處不起過失。「有愧」，是指在顯露外在時沒有違非踰矩。「喜愛修學戒律」，是總括涵蓋以上五種功德，成為這項修行的根本。「應當在其中修學」，是說明上述簡略的教導，是修行者所依止的依歸，應當納受而跟從，必定會有所成辦與獲益。

【872-0010】02_戒疏/21c_卷四下之三#56
【原文】【記】三、略教流通中。初總示。「自」下，牒釋。列釋簡人。「隱不起過」，即屏處；「外無非違」，謂露處也。「總攝上五」者，由具上五，方能奉戒，故云「成行本」。「當」下，釋勸學。「可受而從」者，教非虗授也。「必有成濟」者，行不徒為也。
【譯文】【記文】在第三、簡略教法流布傳通的段落中。最初是總體指示。「自」字以下，重提並解釋。依序排列解釋以挑選合格之人。「在隱密處不起過失」，是指獨處的幽蔽之處；「顯露外在沒有違非踰矩」，是指身處廣眾之處。「總括涵蓋以上五種功德」，是由於具備了上述五項，才能真正奉持戒律，所以說是「成就修行的根本」。「當」字以下，解釋勸勉修學。「應當納受而跟從」，表示教法並非虛妄傳授。「必定會有所成辦獲益」，表示修行不會白費心力。

【872-0011】02_戒疏/21c_卷四下之三#57
【原文】【疏】大段第三，明廣略二教總流通，文分為五：初從「明人」下，至「諸佛法」來，明廣教行益，勸信流通；第二，「若有自為身」下，至「入寂滅涅槃」來，明略教行益，開演信順流通；第三，從「世尊涅槃時」下，至「得入涅槃」來，明戒為眾行之師，善護行淨之士，明付囑久住，以辨流通；第四，「若不持此戒」下二偈，明違佛遺囑，必有陷墜之咎，勸信奉順流通；第五，「我已說《戒經》」下，結前迴向以辨流通。
【譯文】【疏文】大段落的第三部分，說明廣泛與簡略二種教法整體的流布傳通，文意分為五部分：最初從「明人」以下，直到「諸佛法」為止，說明廣泛教法的修行利益，勸勉起信並流布傳通；第二、「若有自為身」以下，直到「入寂滅涅槃」為止，說明簡略教法的修行利益，藉由開展演說而起信順從以流布傳通；第三、從「世尊涅槃時」以下，直到「得入涅槃」為止，說明戒律是大眾修行的導師，善加護持行持清淨的修道者，說明付囑咐託使其久住，藉此辨析流布傳通；第四、「若不持此戒」以下兩首偈頌，說明違背佛陀遺囑，必定會有沉淪墮落的過患，勸勉信奉順從以流布傳通；第五、「我已說戒經」以下，總結前面並作迴向，藉此辨析流布傳通。
