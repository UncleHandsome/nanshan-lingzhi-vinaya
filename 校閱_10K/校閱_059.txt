# 校閱材料　第059檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【059-0001】01_行事鈔/04a_卷上之四#23
【原文】就中雜相。若界外來者，徑至說處，若未誦序清淨已來，依次而坐，不告清淨。若已說清淨已，後方來者，戒師見來即須止住；不肯住者，訶令住之。待坐，互跪，一人告云：「大德僧聽！某甲比丘若干人等，並是清淨。」若有犯過，依過陳之；為偪說戒，後如法懺。便依次為說。若外界比丘，若多若等，縱說戒竟，皆令重說；不者，如法治。《毘尼母》云：若犯七聚不淨人前，應止不說戒。即律文云：犯者不得聞戒，不得向犯者說等。若三寺五寺尼請教授，隨意受之；總前各列寺號尼名，後便總結請意。若誦中，恐誤，當告比近人示令；不得大眾同教，致增混亂也。《四分》：若說戒日無能誦者，當如布薩法，行籌告白；差一人說法誦經餘諸教誡，誦遺教亦得。若全不解者，律云，下至一偈：「諸惡莫作，諸善奉行，自淨其意，是諸佛教。」如是作已，不得不說。若不解者，云：「謹慎莫放逸！」便散。並是佛之囑累，深有來致，令正法久住。而世有住寺，輕此教網，故違不說。染污淨識，漸於大法，無有滋味；是則出家，無有利益。口言佛是我師；師教拒違故，是外道弟子也。若有犯重罪，不預聞戒，縱在寺內，別眾則無；若經懺悔，來不隨意。僧殘已下，依教懺訖，得聞，如律所顯。若座上憶得，莫問疑識，對眾發露；恐大眾鬧亂者，但心念口言，自陳云：「我某甲犯某罪，為偪說戒，待竟當懺。」便得聞戒。若於罪有疑，亦準此陳露。
【譯文】此中還有各類雜項情況。如果是有界外的比丘前來，直接到達說戒處所，如果在尚未誦完戒序中「清淨」之問以前趕到，就依序就座，不用特別宣告其清淨。如果是在已經宣說清淨之後才到來，戒師見到有人前來，就必須立即停頓止住；戒師若不肯停頓，他人應訶責令其停住。等候來人就座、互跪之後，由一人宣告說：「大德僧聽！某甲等若干比丘，全都是身心清淨。」如果有違犯過失，應依其過失陳明發露；因為迫近（逼）說戒之時，容許事後如法懺悔。隨後便依序為其宣說。如果結界外來的比丘人數，多於本界僧眾或與之相當，縱然此間已經說戒完畢，都必須全部重新宣說；若不重說，依法予以治罰。《毘尼母論》說：如果在違犯七聚罪過的不清淨人面前，應當中止而不說戒。即如律文所載：有犯戒者不得聽聞說戒，不得向有犯戒者說戒等。如果有三個寺院、五個寺院的比丘尼前來請求教授教誡，比丘可隨意接受（不限於一寺）；總括在前面各自列出寺名與比丘尼名，隨後便總體總結其請法之意。如果在誦戒之中，恐怕有差錯訛誤，應當告知鄰座靠近的人予以提示；不得全體大眾一同發聲指教，致使徒增紛擾混亂。《四分律》說：如果到了說戒日，僧中無人能誦戒本，應當如同布薩法那樣，行籌告白；差派一人宣說佛法、諷誦經典或其餘各類教誡，讀誦《佛垂般涅槃略說教誡經》（《遺教經》）也可以。如果全都不會讀解，律典說，最低限度也要誦一首偈：「諸惡莫作，諸善奉行，自淨其意，是諸佛教。」如此作法之後，便得免除不說戒之罪（不可算作未說戒）。如果連一偈都不解，就說一聲：「謹慎莫放逸！」隨後便解散。這些全都是佛陀的叮囑寄託，具有深遠的旨趣由來，目的在於令正法長久住世。然而世間有些主持寺院之人，輕蔑忽視這項教制網領，故意違背而不舉行說戒。這將染污清淨的識心，漸漸地對於大乘佛法毫無修持法味；這樣出家，就沒有任何實質利益。口中說「佛陀是我的導師」；卻抗拒違背導師的教敕，這實質上是外道的弟子！如果有人犯了波羅夷重罪，便不得參與聽聞說戒，縱然人仍在寺內，也不算作違背僧團常規的「別眾」；縱然經過如法治罰懺悔，想前來聽戒亦不得隨其個人心意。僧殘罪以下，只要依教法懺悔完畢，便得以聽聞，如律典所明文開示。如果是在說戒座上突然憶念起自己有罪，無論是心中生疑還是明確認知，都應當對眾發露；如果擔心引發大眾擾亂喧鬧，只要心念口言，自行陳白說：「我某甲犯了某罪，因迫近說戒之期，等待說戒完畢應當如法懺悔。」便可以聽聞說戒。如果對罪過有所懷疑，也準照此法陳白發露。

【059-0002】01_行事鈔/04a_卷上之四#24
【原文】四明略說雜法者。《四分》云：若有八難：王、賊、水、火、病人、非人、惡蟲、人難者。《明了論》云：有人欲執縛比丘也。餘緣者，若大眾集床座少、若眾多病、若座上覆蓋不周、或天雨；若布薩多夜已久、或鬪諍事、或論毘曇毘尼、或說法夜已久，聽一切眾未起，明相未出，應略說戒。《十誦》云：共伴行，若住，廣說；小住，略說；不住，三語說。在白衣前不得口言，心念云：「今日布薩說戒！」乃至宿處有命梵等難，龍鬼之怖，皆不得出聲，心念口言：「今日說戒！」《五分》：貴人、惡獸、地有生草棘刺、蛇窟、闇夜、地有泥、坐迮。《僧祇》：若偪暮、天陰、風雨、老病不堪久坐、住處遠，皆開略說。《十誦》：聽在諸王前說，令心清淨；除大臣兵吏遣去。《五分》：說戒時賊來，應連聲誦經，莫令有絕。若有一方眾主，綱維徒眾者，每至盛夏嚴冬，準前略說。至時、小食上，應告僧云：「今說戒日，十方賢聖所共同遵，並願眾僧同時集會。」乃知冬熱，當為略說；勿事他緣，自生厭法。《僧祇律》第三十四卷，廣立布薩上座法。《五分》云：不應以小事囑授，應在顯露處說。
【譯文】四、說明略說戒等雜法。《四分律》說：如果有八種難事：國王難、盜賊難、水災、火災、病患、非人（鬼神）難、惡蟲難、人難（惡人逼害）。《律二十二明了論》說：人難是指有人想要拘捕捆縛比丘。其餘緣由，例如：大眾集合而床座缺少、或者僧眾多有生病、或者坐處上方棚頂遮蓋不嚴密、或者下雨；或者布薩佔用了大半夜且為時已久、或者有鬥諍之事、或者討論阿毘曇（論藏）與毘尼（律藏）、或者說法已至深夜，聽許在大眾全體尚未起座、黎明天色明相尚未顯露之前，應當略說戒。《十誦律》說：與同伴同行時，如果停住駐留，就廣說戒；若是短暫停留，就略說戒；若是不停留而前行，就以三句話略說。在在家人面前不得口中說出，應當在心念中說：「今日布薩說戒！」乃至投宿之處有生命危難或梵行危難等，有惡龍鬼神之恐怖威脅時，都不得出聲，只需心念口言：「今日說戒！」《五分律》列出：貴人（官宦權貴）、惡獸、地面生有青草荊棘、毒蛇之窟穴、黑夜昏暗、地面泥濘、坐處狹窄壅塞等情況。《摩訶僧祇律》說：如果逼近傍晚（日色將暮）、陰天、風雨、年老病弱不堪久坐、住處路途遙遠，都開許略說戒。《十誦律》說：聽許在諸位國王面前說戒，令其心意清淨；應當遣退排除大臣與官吏士兵，待其離去後方可說戒。《五分律》說：說戒時若有盜賊前來，應當聲音相續不斷地誦讀經文，切莫令聲音斷絕。如果有一方的僧團主事者（眾主）、統攝維繫徒眾者，每到盛夏炎暑或嚴冬酷寒之時，可準照上述規定略說戒。到了時刻、早齋（小食）之時，應當告白僧眾說：『今日是說戒之日，是十方賢聖所共同遵奉之法，懇願大眾僧同時集會。我深知冬寒夏熱之苦，屆時當為大眾略說戒；大家切莫經營其他事緣，而對佛法自生厭倦懈怠之心。』《摩訶僧祇律》第三十四卷中，廣泛設立了布薩之上座法規。《五分律》說：不應當為了微小之事就囑託他人代為與欲（囑授），且受囑說欲應當在顯露處宣說。
