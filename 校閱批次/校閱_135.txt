# 校閱材料　第135檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【135-0001】資持記/01b_上一上#24
【原文】咨爾來學，勿負祖恩。言世事者，謂是世中合行之事，非世俗之事也。準下撰述一十六師，今云百無一者，汎舉至多，以明至少，猶不可得，言都無所取也。次義集者，即諸本羯磨。以羯磨文散在廣律，並以義類集結成篇，故云文在義集。如今《隨機羯磨》，亦稱撰集；
【譯文】嘆惜你們後來的學人，千萬不要辜負了祖師的恩德。所謂「世事」，是指世間僧團合該舉行的法事，而不是指世俗的雜事。準照下文所列撰述的十六位律師，如今說「百本中無一本可用」，是用極多的概稱，來顯明能用的極少，甚至根本無法得到，意思是說全都無可取之處。接著提到「義集」，就是指各本羯磨儀軌。因為羯磨文句散落在廣大的廣律之中，都是按照義理類別集結成篇章，所以說「文字見於義集」。如今這本《隨機羯磨》，也稱為撰集；

【135-0002】資持記/01b_上一上#25
【原文】又《業疏》中召出羯磨人為集法者，皆可證矣。此科文意，為遮後疑。恐云上斥疏鈔繁費乖宗；且諸本羯磨，直顯行事，如何上云百無一本，無乃誣彼先賢耶。今雖許有，還成無用。言時有者，明其不多也。銳懷者，美其敏利也。即目鎧諦光願四師。上標人法。或下，指過。初二句即光願二本。
【譯文】又如《業疏》中稱呼撰出羯磨的人為「集法者」，這些全都可以作為明證。這個小科的文意，是為了防範後人的疑難。唯恐有人說：上面斥責各家疏鈔繁瑣徒勞且違背宗旨；但各本羯磨儀軌，分明是直接顯明實踐行事的，為什麼上面說百本中無一本可用，這豈不是誣衊了前代賢哲嗎？如今即便承認有這些羯磨，到頭來依舊是毫無實用價值。說「時有」，是說明其數量並不多。「銳懷」是讚美其才思敏捷銳利。這就是指鎧、諦、光、願四位律師。上面標示出作者與著作。從「或」字以下，是指出其過失。前兩句就是指光、願兩位律師的著作。

【135-0003】資持記/01b_上一上#26
【原文】光本多以義求，願本廣引緣據；詞繁事隱，不濟時用，故云多列等。閑緩非要，謂之游詞。好廣者樂從，尚簡者不顧，故云逗機未足。逗猶濟也。次單題下，即鎧諦二本。上二句斥文略。題即書寫。彼唯出法，不辨緣成，故云莫宣，猶言不述也。下二句明無用。
【譯文】光律師的本子多半以義理推求，願律師的本子廣泛引用事緣依據；文字繁瑣而事相隱晦，無法救濟當時之實用，所以說「大多陳列」等語。閒緩而不切要的話，稱為「游詞」。喜好廣博的人樂意遵從，崇尚簡要的人則不屑一顧，所以說「無法契合眾人根機」。「逗」猶如濟度契合之意。接著「單題」以下，就是指鎧、諦兩位律師的著作。上兩句斥責其文字過於簡略。「題」就是書寫。他們只列出法式，不辨明成就與否的因緣條件，所以說「莫宣」，猶如說不曾敘述。「下兩句」說明其無實用價值。

【135-0004】資持記/01b_上一上#27
【原文】既不曉成敗，加被無功，故云依文等。故《業疏》序中總斥四本云：增減繁略，互見得失等。〔昔來所釋，都無所曉。〕總斥中。通前疏鈔及以義集，故云並也。碎謂文無章節，亂謂義非倫序。所以下二句，對上文碎故難尋求，次二句對上義亂故難領會。
【譯文】既然不能明曉成敗的關鍵，施加羯磨也是徒勞無功，所以說「依文」等語。因此《業疏》的序言中總結斥責這四部本子說：「增減繁簡各異，互見其得失」等。〔自古以來的種種解釋，全都毫無所曉。〕在總括斥責的段落中。普遍涵蓋了前面的疏鈔以及義集，所以說「並皆」。「碎」是指文字毫無章節段落，「亂」是指義理毫無倫常次序。在鈔文「所以」以下的兩句，對應上文的文字破碎因而難以尋求；接下來的兩句，對應上文的義理混亂因而難以領會。

【135-0005】資持記/01b_上一上#28
【原文】第二明今述作，初文為二，初明覽古。聽采暇者，在首師講席習學之時。顧眄者，明非正學也。〔迴觀曰顧，斜視曰󱌁，音麵。〕群篇，通指前代所流也。撰集雖眾，一無可取，故曰通非等。屬音燭，訓當。非當意者，不契祖心也。上句示無取，下句出所以。問：劣則可爾，優何不契？
【譯文】第二部分是說明如今這部著作的緣起，最初一段分為兩層，第一層說明遍覽古籍。「聽采暇」是指在智首律師的講席下研習學戒的空閒時間。「顧眄」是說明並非正式正軌的研習。〔回頭看叫做「顧」，斜眼看叫做「眄」，音讀作面。〕「群篇」是通稱前代所流傳下來的著述。撰述集錄雖然眾多，卻沒有一本值得採取，所以說「通非」等語。「屬」音讀作燭，訓釋為恰當。「非屬意」是指不合祖師的心意。上句顯示毫無可取，下句指出其中的緣由。有人問：劣等的著作固然不可取，優良的又為何不契合心意呢？

【135-0006】資持記/01b_上一上#29
【原文】答：以群篇中優劣互見，優雖有取，劣不可存；欲得全優，未之有也。云非屬意，其義如斯。慈訓所興，良由於此。斐然下，次明撰述。斐然者，文章駁雜之貌，文出《論語》。〔孔子在陳思魯，乃云：吾黨之小子狂簡，斐然成章。
【譯文】回答說：因為各篇著作中優點與缺點交相參見，優點雖然可以攝取，缺點卻萬萬不可存留；若想尋得一部全盡優善的著作，那是從未有過的。說「不合心意」，其道理就在於此。慈悲的訓誨之所以興起，確實就是由於這個緣故。「斐然」以下，接著說明正式撰述。「斐然」是文章錯雜成章的樣子，文句出自《論語》。〔孔子在陳國時思念魯國，便說：「我同鄉的年輕人志向狂放而行事簡略，斐然成章。」〕

【135-0007】資持記/01b_上一上#30
【原文】作命即撰文，命謂典章之異號，即目今鈔也。〔《論語》云：為命，裨諶草創之等。正義曰命，謂政令之詞，為即作也。〕直筆者，即後批云不事虬文。此有三意：一顯行事故，二被新學故，三彰謙意故。具謂委陳行相，舒謂演布文詞，一部之文，盡於此句。〔有科此為刪四分繁，包下為引他文補，非也。
【譯文】「作命」就是撰寫篇章，「命」是典籍規章的別名，就是指如今這部《行事鈔》。〔《論語》說：「撰作政令，裨諶草創之」等。孔穎達正義說「命」是指政令之辭，「為」就是製作。〕「直筆」就是後文批註所說的「不追求典雅華麗的文辭」。這有三層深意：第一是為了顯現實踐行事的緣故，第二是為了攝受初心後學的緣故，第三是彰顯自謙心意的緣故。「具」是指委細陳述法事的行持相貌，「舒」是指敷陳鋪排語言文字，一部《行事鈔》的文字體裁，完全盡在這一句之中。〔有人把這句科判為刪除《四分律》的繁雜，把下句科判為引用其他文獻補足，那是錯誤的。〕

【135-0008】資持記/01b_上一上#31
【原文】次科，引用中為二，先列所引文。有四句。初句統収諸律，即五十祇等。次句收大小乘經。經中談律，名為隨經之律，故云隨說。第三收大小乘論。第四總諸師疏鈔，及《布薩儀》、《高僧傳》、《師資傳》、《寺誥》等。此之四句，括盡一部引用之文，是則貫攝兩乘，囊包三藏；
【譯文】接下來的科判，在論述引用的內容中分為兩層，先列出所引用的文獻。共有四句。第一句總括收錄諸部律藏，也就是《十誦律》、《五分律》、《僧祇律》等。第二句收錄大乘與小乘的經典。經中談及戒律的，稱為「隨經之律」，所以說「隨說」。第三句收錄大乘與小乘的論典。第四句總結諸位律師的疏鈔，以及《布薩儀》、《高僧傳》、《師資傳》、《寺誥》等。這四句話，概括了一部書中所引用的所有文獻，這便是貫穿攝受了大小兩乘，囊括包容了經律論三藏；

【原文】良由眾生根器不同，樂聞有異，故令聖制輕重不等，緩急有殊；諸部輕重乃有無量，雖復不同，各稱根性；皆有奉行之益，以是義故，聖制本有五名。又引《付法藏傳》，佛現在世，分為五部等。〔大集夢㲲亦同此意。〕若爾，《義鈔》下文復云無五意者？
【譯文】這確實是因為眾生的根器資質不同，所喜好聽聞的教法有差異，所以使得聖人制定的戒規有輕有重，緩急各有所別；諸部派律典的輕重差別多至無量，雖然規定互不相同，卻各自切合該部眾生的根性；只要遵行都能獲得解脫的實益，正因為這個緣故，聖人所立之法原本就有五種部派之名。又引《付法藏傳》說，佛陀在世之時，便已懸記分作五部等等。〔《大集經》夢見氎布碎裂的事蹟，也表達相同的意旨。〕如果這樣，為何《義鈔》後文又說佛在世時並無五部的意圖呢？

【原文】答：此明佛在不分之意，謂隨機立制，豈有五意！故使現在但有五名，不分五別；不妨輕重緣急，即是懸被將來。故彼云聖者之制，現無五意，但有懸記之言；佛去世後，始有諸部分張等。次句彰異。言多別者，統論分部。初則二部剏初各集；
【譯文】回答：那是說明佛在世時僧團尚未分化為五部的深意，意思是佛陀只是隨順機緣制戒，哪裡預先存有分割出五個宗派的企圖！因此佛在世時戒律只有五種名稱的區分，並沒有真正分立出五個獨立部派；但這並不妨礙佛隨緣制訂的輕重緩急，正是為了在冥冥之中預先護佑未來的學人。因此那部書說，聖者的制度在佛世時並無分立五部之意，僅有預作懸記的預言；直到佛陀去世之後，各部派才真正分道揚鑣。次句是用來彰顯宗派的差異。所謂「多別」，是總括論述部派的分化。最初是上座部與大眾部兩部開端各自結集；

【原文】次一百年後，上座部中分出五部；又云：二百年後分十二部；四百年後分十八部〔通根本為二十〕；乃至復分五百部。〔備如《義鈔》，此不煩引。〕相傳云：本作宗則有其十八，後修時改為多別。故知此語通含，非唯五部。引證中。既云多別，不可備陳；略引二部，以明異相，故云且如等。
【譯文】接著佛滅百年之後，從上座部中分化出五個部派；又有說法認為佛滅二百年後分化為十二部；佛滅四百年後進一步分化為十八部〔若算上根本二部則總為二十部〕；乃至最後細分至五百部之多。〔詳細內容如《義鈔》所載，此處不再繁複引用。〕依古德相傳：此處原文原本寫作「宗派則有十八」，後來重修時改為「多別」。因此可知這句話涵蓋廣泛，並非僅僅侷限在五部而已。在「引證」的段落中。既然說部派差異甚多，無法全部列舉；只能略引其中兩部，用以說明互異之相，所以說「暫且以某某為例」等等。

【原文】所以特引此二部者，此方盛弘。假實二解，敵對相反，於義易見。或可部計雖多，不出空有。是以下明戒體，亦出兩宗耳。兩部勝劣，略列四種，今合釋之。初戒本繁略，對下立教顯約。
【譯文】之所以特別引用這兩部律，是因為它們在漢地弘傳最盛。假名宗與實法宗這兩種見解互相對立相反，在義理上最容易辨明。又或者說部派的主張雖然極多，卻不外乎「空」、「有」兩端。因此下文在闡明戒體時，也同樣列出這兩個宗派。這兩部律典的殊勝與平庸之處，略可列出四種對比，現在一併解釋。第一項是「戒本的繁瑣與簡略」，這正對照著下文所說「立教的顯著與精要」。

【135-0056】資持記/01c_上一上#14
【原文】《十誦》著三衣有六戒〔一太高、二太下、三象鼻、四多羅葉、五參差、六攝縐〕，內衣同上，共十二戒，則為繁也。大小便利，止有一戒；敬塔都無，此為略也。《四分》敬塔便唾，各隨別相，具列多戒，故云顯也。著衣立二，義無不收，故名約也。
【譯文】《十誦律》中關於穿著三衣的威儀有六條戒〔一是太高、二是太低、三是象鼻形、四是多羅葉形、五是長短參差、六是摺疊不整齊〕，穿著內衣的規定也與上面相同，合起來共有十二條戒，這就屬於「繁瑣」。但對於大小便利的威儀卻只有一條戒，敬拜佛塔的規矩全無記載，這就屬於「簡略」。《四分律》對於禮敬佛塔與隨處便溺吐痰等事，各自依照不同的事相詳細列出許多戒條，所以說「條理顯著」；而對於穿衣的威儀只立了兩條大綱，在義理上卻無所不包，所以稱為「精要」。
