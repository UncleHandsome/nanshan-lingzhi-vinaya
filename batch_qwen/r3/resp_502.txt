整體看，這批譯文對科判、罪相（重／蘭／吉）的掌握大致正確，讀來也順。主要問題集中在**幾處詞義誤讀**、**引文體例不一致**、**「共分」一律譯成「平分」**，以及**科判層級與罪名稱法不統一**。以下逐則列出。

---

## 一、逐則問題與建議

### 【502-0001】#96
1. **「前示犯意」譯成「前面說明犯罪的意圖」——語義偏差。**
 此處「犯意」是「成犯之所以（成盜的道理）」，觀下文「本無有犯／有成盜義」即知，不是在講犯罪心理（mens rea）。
 建議：「前面先說明成犯的道理。」
2. **《律》文整段未譯**，與 #101、#1（0012）譯出引文的作法不一致。
 建議：「共同經營事業所得的財物應當共有，若以盜心取走五錢或超過五錢，就犯重罪。」
3. 「以同財業，本無有犯」→ 建議「因為財物、事業本是共有，取用本來不犯盜」，比「合夥共同經營的財產，本來不構成盜罪」貼切。
4. 「資生同」「同活生」是疏文用語，建議保留原詞再加括注；「故取十成重」可補一句理由：**因各得一半，須取滿十錢，對方損失才達五錢**，讀者才懂五／十之別。
5. 「故云在『此引也』」→「所以說『在此引述』」；「提出來」不如「引述」。

### 【502-0004】#99
- 「先要共分」譯「事先約定得手後**平分**」：「共分」只是約定分享，**平分是下文「分半」的特例**。建議改「約定共分」。
- 「《律》中列舉前去行竊」→「《律》中舉出行盜之例」（「前去」是添加）。
- 其餘（誤得己衣仍須分半、不問自他）譯得準確。

### 【502-0005】#100
- **同樣《律》文未譯**。建議：「與他人立約，教他說：某時去、某時回來，或穿牆取物，或在路上劫取，或放火（趁亂取財），從那裡得到財物回來共分。」
- 「若燒」語意略含糊，宜加譯注（放火趁亂取物），不要留白。

### 【502-0006】#101
1. **「咒願」譯成「念咒祝願」——術語錯誤。** 律中「呪願」指受施後為施主說祝願偈、吉祥祝語，與持咒無關。
 建議：「得到衣服並已為施主祝願之後……」
2. 「**自私地**心想」「**私下**共同約定」是添加語。「自念」＝自己心想；「自共制」＝二人共同立約。建議刪去修飾。
3. 「半滿結夷」建議點明：**「同伴應得的那一半，價值滿五錢，即結波羅夷」**，比「該衣物半數價值滿五錢」清楚。
4. 「各任相祿」可作「各隨自己的福分」，與 #104 記文「福相／祿分」呼應（「好運」稍俗）。
5. 原文引號跨段未閉，譯文自行閉合可接受，但宜與下一則統一處理方式。

### 【502-0007】#102
1. **第二句漏掉「解約」，破壞三句平行。** 三句都是「解約」而犯，只是入手／隱藏／未取之別。
 建議：「二、拾得好衣，先用草覆蓋（藏起來）之後解約；三、不取也不覆蓋就解約。」
2. 記文（#105）明說疏文略去「摶覆」「不取」；譯文**補了「不取」卻未處理「摶覆」**，處理不一致。建議一律用〔 〕補字或一律出注。
3. 「約定共同尋找碎布作衣」可簡作「約定共同尋覓（糞掃）衣」。

### 【502-0008】#103
- 無實質錯誤。「三階」可括注（重／偷蘭遮／突吉羅），呼應下文。

### 【502-0009】#104
1. **「貪好故解」譯「貪圖好處而解約」過泛**：應是「貪著（已得的）好衣而解約」，正對應上文「後得不必及是」。
2. 「犯吉羅」→ **「犯突吉羅」**（與 #101 統一）。
3. 「入已」當為「入己」之訛，譯文理解正確，可出一條校勘注。
4. 「如後所決」→「如後文（疏）所判定」，明示所指為 #103 疏文。

### 【502-0010】#105
1. **「明各解，又三」譯成「疏文又分為三節」——層級誤判。**
 下文「初句重，次句蘭，後句吉」可證「三」是**三句／三種情形**。
 建議：「從『一』字以下，說明各別解約，又分三句（三種情形）。首先列出文句。」
2. **「摶覆」括注「以磚石覆蓋」缺乏依據。** 「摶」本義為摶土成團；佛典中「摶」又常是「塼（磚）」的訛字，兩解皆有可能。建議**保留原詞並注「未詳」**，或查《摩訶僧祇律》原文後再定，不宜逕斷為磚石。
3. 「次句下／第三句上」→「第二句末／第三句開頭」，更明确。

### 【502-0011】#106
1. **「相要不絕」譯「彼此約定的心意連綿不絕」——偏離。** 指**約定尚未解除、效力仍在**（這正是結罪的前提）。
 建議：「彼此的約定一直有效、未曾解除。」
2. 「相當者重」宜依下記文補足主體：「（行事與所約）相符的，**教者與取者俱結重罪**」。
3. 「不如要者輕」建議加譯注：**此「輕」只就教者說，取者仍犯波羅夷**（見下則），否則讀者極易誤解為兩人都輕。
4. 書名《善見論》與下則《善見律毘婆沙》宜統一。

### 【502-0012】07b#1
1. **「三中」層級混淆。** 此處是「共要」之下的**第三科（引《善見》）**；而 07b#3 記文的「三中」是**外層第三類（伺候）**。兩處都譯「第三種情況」會攪亂科判。
 建議：「（共要中）第三科引《善見律毘婆沙》。」
2. **「含泛籠統」是錯字**（無「含泛」一詞）→「含糊籠統／泛泛籠統」。
3. 「專剋」→「專意剋定時間」，比「特定限定條件」明確。
4. 「不可悔的**棄損**重罪」——「棄損」罕見。建議「波羅夷（不可悔的重罪，義譯『棄』『斷頭』）」。
5. 初夜／後夜譯「前半夜／後半夜」尚可，但律中三夜為初／中／後，作「初夜（前夜时分）／後夜（近凌晨）」更精確。

### 【502-0013】07b#2
1. 「得財必共」→「所得財物必定**共分**」（同前，非必然平分）。
2. 「相期進不」→「彼此約定進止（要不要動手）」，「進退動向」稍空。
3. **「為候亦犯」譯「也同樣構成犯戒」過泛**：記文明言「能所同重」，應作「擔任探查把風者也同犯重罪」。
4. 格式：`【疏文】：` 多一個冒號（0015 同）。

### 【502-0014】07b#3
1. **《律》擅自譯為《四分律》**：判斷雖合理，但 #96 保留「《律》」，體例不一。建議統一為「《律》」或「《律》（《四分律》）」。
2. 「於彼得物一切共」→「一切**共分**」。
3. 「能所同重」→「能教者與所教者同犯重罪」，並把結論接回疏文「為候亦犯」，論證才完整。
4. 「勑豔反」改寫為「敕艷反」可，但建議存原字並附今音，避免讀者以為訛字。

### 【502-0015】07b#4
1. **「守護」譯「看守接應」——添了原文沒有的「接應」義。** 依疏文「為其掌錄」，此處是替同伴**掌管、守護（財物）**。建議「守護（保管）」。
2. **「隨得共之」譯「隨後偷得財物便一同平分」——「隨」誤讀為「隨後」。** 「隨得」是「隨所得、不論所得為何」。
 建議：「隨所得到的財物，都與他共分。」
3. 「所在追求」譯「搜刮追求」語氣過重且偏義，宜作「（同伴）在各處尋求財物」。
4. 「故言此也」→「所以（疏中）列出這一類」。
5. 後半「若先不要……義亦非犯」譯得正確。

## 二、跨段一致性建議

| 項目 | 現況 | 建議 |
|---|---|---|
| 共分／平分 | 多處一律作「平分」 | 原文「共」「共分」用「共分」；只有「二人共分」「分半」才是平分 |
| 罪名 | 吉羅／突吉羅混用；夷／波羅夷；越／突吉羅 | 統一「突吉羅（越毘尼）」「偷蘭遮」「波羅夷」 |
| 科判 | 小科／種情況混用，層級不明 | 一律「第○科」，並標明是外層類別還是段內小科 |
| 引文 | 有的整段文言、有的全譯 | 一律白話（必要时原文＋譯文對照） |
| 書名 | 《善見論》／《善見律毘婆沙》；《律》／《四分律》 | 首次出現給全名＋簡稱，之後統一 |
| 增譯語 | 私下、自私地、搜刮、接應、前去 | 節制形容與推測性添加，尤其涉及判罪語意者 |

## 三、值得稱許之處
- 「誤得己衣仍須分半，以立約但云得衣、不問自他」的推理譯得清楚。
- 「半滿結夷」掌握到「以同伴應得之半計值滿五錢」，方向正確。
- 「此二並未入手故輕」與「入手共分」的判罪關鍵抓得準，這是本段最容易譯錯的地方。
- 0012 「隨違成重」理解為「不限時日則教者亦成重」，正確。

**最需優先修的三處**：#105「又三」的層級與「摶覆」的臆斷、07b#4「隨得共之」、#106「相要不絕／相當者重／不如要者輕」的主體與輕罪歸屬。
