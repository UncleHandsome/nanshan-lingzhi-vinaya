# 校閱材料　第1152檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1152-0001】資持記/08d_中二#28
【原文】縱為護法，不淨亦制；必具四緣，方開受畜。如是四法下，結勸。我為等者，此即法四依；後文肉眼不辨邪正，須說四依；慧眼了法，故不為說。經云：是諸比丘當依四法，何等為四？一依法不依人〔法即法性，人即聲間；法性即如來，聲聞即有為。
【譯文】縱然口稱是為了護法，若是採用不合淨法的手段也同樣受到制止；出家人必須同時具備上述四種因緣，才能開許接受與蓄存。從「如是四法」以下，作結語勉勵勸勉。經中說「我為……」等文，這就是大乘的「四依法」；後文提到因為肉眼凡夫無法辨別邪正，所以必須宣說四依法；若是具備慧眼能透達諸法實相者，就不需要再對他宣說了。經中說：諸位比丘應當依止四種正法，是哪四種呢？第一是依法不依人【法是指諸法法性，人是指聲聞個體；法性就是如來實相，聲聞則屬於生滅有為】；

【1152-0002】資持記/08d_中二#29
【原文】二依義不依語〔義即常性語謂綺飾文詞。〕，三依智不依識〔智即如來，識謂聲聞不能善知如來功德。〕，四依了義經不依不了義經〔了義即菩薩乘，不了義即聲聞乘。〕。謂前開四緣，乃是大乘了教，勸令依止；若下，決前不了教。又下，指禁斷文。多出第六。
【譯文】第二是依義不依語【義是指常住真如的法性，語則是指華麗裝飾的文詞】；第三是依智不依識【智是指如來的圓滿圓融智慧，識則是指聲聞心識無法真正明了如來的甚深功德】；第四是依了義經不依不了義經【了義是指大乘菩薩法門，不了義則是指聲聞緣覺乘的小法】。這段話說明前面所開許的四種因緣，乃是大乘了義的教法，佛陀勸勉大眾應當依此修行止惡；從「若」字以下，決斷排除前面所說的小乘不了義教法。從「又」字以下，指出經中禁止斷絕八不淨財的經文，大多出自《大般涅槃經》卷第六。

【1152-0003】資持記/08d_中二#30
【原文】又云下，引誡道俗文，初誡俗眾。若下，誡道眾。餘如後引。會相違中，初指《十輪》。如〈僧網〉云：乃至畜妻挾子，恭敬如舍利弗，不聽責罰等。又下，決破。《涅槃》了義，廢前不了，故云不用。以下出廢所以。《涅槃》護法事重，《十輪》為存俗信，故云小小。
【譯文】經文又說，以下引用告誡出家與在家的文句，首先告誡在家信眾。從「若」字以下，告誡出家僧眾。其餘詳情正如後文所引述的。在會通教理相互矛盾的段落中，首先指出《十輪經》的內容。正如〈僧網品〉中所說：即使比丘娶妻蓄養子女，在家人對他恭敬禮拜仍應如同對待舍利弗尊者一樣，不許肆意加以責罰等。從「又」字以下，進行破除糾正。《大般涅槃經》屬於究極的了義教法，早已廢止了前面階段未究竟的不了義教，所以說不可採用。從「以」字以下說明廢除的理由。《涅槃經》著重在守護正法，事關體大極其重大，《十輪經》只是為了留存世俗信眾對三寶的信心，所以才將這些過患看作是微小之事。

【1152-0004】資持記/08d_中二#31
【原文】三結罪中，初明二重。綿不入淨，此據成衣相者；褥同重物，亦不入淨，應是小者。餘下，明六輕。言畜少者，謂事稀故。四交貿中有五，初二句以八易衣。犯販賣故。以下四句，以衣易八。得寶即犯貿寶。綿毺俗邊犯販賣。若以下四句，上明二自相貿。
【譯文】在第三項結算罪名的段落中，首先說明兩種重犯情況。絲綿本不入說淨之例，此處判違淨施得墮是據已經製成衣服樣式者而言；墊褥等同重物本亦不入說淨，此處應當是指尺寸較小的坐褥。從「餘」字以下，說明六種情節較輕的罪相。說它蓄存罪較輕，是因為這類雜事發生的機率較為稀少。在第四項物資相互交易的行為中分為五種，前兩句說明用八種不淨物去換取僧衣。這犯了販賣罪。從「以」字以下四句，說明用僧衣去換取八種不淨物。換得了金銀珍寶就犯以物換寶罪。換得絲綿或毛毯，若是在俗人處換得則犯販賣罪。從「若以」以下四句，前半段說明前面兩種物品私自相互交易。

【1152-0005】資持記/08d_中二#32
【原文】衣易衣犯販賣，寶易寶犯貿寶。下明以二貿六，得輕，可知。六下四句，六種自貿。或對貿，或互易，並吉。又以六易二，販貿二墮，準上可明。此下，點上販賣，對人輕重。上云犯捨，且據俗論。明說淨中，初明淨財易物。衣鉢百一，入受持故。
【譯文】用衣服換衣服犯販賣罪，用金寶換金寶犯換寶罪。後半段說明用這兩種物品去換取其餘六種輕物，結得輕罪（突吉羅），其理可知。從「六」字以下四句，是指六種物品內部相互交易。無論是同類對換，還是互換種類，全都犯突吉羅罪。如果用六種輕物去換取前兩種重物，則會觸犯販賣或換寶的兩種墮罪，依照上面的原則即可明白。從這裡以下，特別點出上述販賣行為，面對出家人與在家人所結罪名的輕重差異。上面所說要受到捨財處罰，暫時只是針對面對在家人時而論的。在說明「說淨」的法度中，首先說明用合法的淨資財物去換取其他物品。僧衣、缽具等百一資身用品，因為已經納入個人受持的法規之中。

【1152-0006】資持記/08d_中二#33
【原文】已外說者，若準《業疏》，並不須說，即入淨故。若下，明犯長錢寶，未懺，先用易物。後但悔罪，物不須捨；準有輒用，吉羅；悔於僧中，句絕。已外須說者，既已入淨，則應淨法。解本戒中，初科。以舊戒本云：若自手捉錢，若金銀等，語濫後戒，故須簡之。
【譯文】超出百一之外需要作說淨的物品，如果依照《業疏》的觀點，全都不需要再做說淨，因為它們本來就已經合法納入淨物之中了。從「若」字以下，說明非法蓄存超額的錢寶，尚未懺悔罪過，就先拿去換取生活物資。事後只要懺悔私蓄之罪，換得的物資不需要沒收捨棄；但是依照規定擅自挪用，要犯突吉羅罪；鈔文到『悔於僧中』處句讀斷斷（句絕）。超出範圍之外必須作說淨法，是因為既然已經納入清淨資財，就應當依法履行說淨的軌範程序。在解釋本條戒律的內文中，第一個科判。因為舊版戒本經文寫道：「若自手捉錢，若金銀等」，在文詞上容易與後面一條戒律混淆不清，所以必須加以辨析揀別。

【1152-0007】資持記/08d_中二#34
【原文】《刪定戒》中，改捉為受，則無濫矣。別時意者，畜中言捉，犯後戒故。準作四句：一是畜非捉，唯犯前戒〔教人口受〕；二是捉非畜，但犯後戒〔觸自淨寶及他人寶，捉金像等。〕；三亦畜亦捉，前後俱犯〔手受而畜〕；四二非無犯〔如法受淨〕。次科，斥濫中，先敘貪畜之意。內即是志，外謂為行。
【譯文】在《刪定戒本》之中，將「捉持」改為「接受」，這樣就不會與後面的戒條互相混雜了。所謂「別時意語」，是因為在蓄存戒中若提到用手捉持，就會同時犯了後面的捉持寶物戒。依照戒律可以推演出四種情況：第一種是蓄存而非捉持，只觸犯前面這條蓄寶戒【例如口頭指使人接受】；第二種是捉持而非蓄存，只觸犯後面這條捉持戒【例如觸碰自己已經說淨的寶物、他人的寶物，或者捉持金屬佛像等】；第三種是既蓄存又捉持，前後兩條戒律同時觸犯【例如親手收受並加以私藏】；第四種是既不蓄存也不捉持，完全沒有違犯【例如依照法度辦理說淨手續】。第二個科判，在斥責虛妄濫用的段落中，先陳述貪圖私蓄的內心動機。內心存著貪求的名利志向，外表表現出奔逐的造作行為。

【1152-0008】資持記/08d_中二#35
【原文】不思聖誡即慢法，縱貪癡是自任。故下，引證；初引本律，準明失戒。非弟子者，不稟師教故；非沙門者，不修淨行故；非釋子者，不係聖族故；今多受畜，為教所揀。雖自剃染，即魔外之徒。又云下，佛告珠髻大臣之詞。次引《雜含》。以五欲法，非善功德，復非清淨。
【譯文】不顧念佛陀神聖的遺誡就是輕慢戒法，縱容自己的貪欲與愚癡就是放任自流。從「故」字以下，引述經教證明；首先引用本宗《四分律》，明確指出這樣做會徹底喪失戒體。所謂「非我弟子」，是因為不遵從根本恩師的教誨；所謂「非沙門」，是因為不再修習清淨的梵行；所謂「非釋子」，是因為不再歸屬於釋迦如來的神聖家族；如今僧眾大多貪圖接受蓄積財物，早已被佛陀聖教所擯除淘汰。即便私下剃髮身披染衣，本質上也只不過是魔王與外道的黨徒罷了。經文又說，下文是佛陀親自告誡珠髻大臣的沉痛法語。接著引用《雜阿含經》。經中指出世間的五欲之法，根本不是良善的功德，更談不上絲毫的清淨。
