# 校閱材料　第1867檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1867-0001】03_業疏/20a_卷四之三#45
【原文】若據《多論》，似攝閏取。故彼文云：若閏四月者，則取前四月受雨衣，滿一百二十日。此衣開物，尚制依閏；安居修道，理制收閏。即彼《伽論》，前安居已，王作閏月，本知有故，則依閏不合受衣；本不知有，數日成夏。有斯兩文，須通兩致。如何從開而越本制？義不可也
【譯文】如果依據《薩婆多論》，似乎應當將閏月包攝在內。所以該論說：如果閏四月，則取前面的四月領受雨安居衣，滿一百二十天。這種雨衣不過是開許受用的物品，尚且規定必須依隨閏月算滿；安居精進修道的大事，理當教制將閏月納入在內。就連那部《薩婆多毘尼摩得勒伽》也說，在結了安居之後，國王設立閏月，如果本來就知曉有閏月，那就應當依隨閏月，不應提早受衣；如果原本不知有閏月，數滿日數即可成夏。既然有這兩處文獻，必須貫通兩種緣由。怎能盲從隨緣開許，進而逾越根本教制呢？這在義理上是絕不可行的。

【1867-0002】03_業疏/20a_卷四之三#46
【原文】次科詳定中，初引《多論》準開況制。雨衣即用澡浴，夏月多垢，故聽畜之。「即」下通前《伽論》，彼文通依不依，乃據知不知耳。先知後結，定須依閏；先結後知，則開數滿。「有」下結責，可知
【譯文】在其次一科詳細考定中，首先引用《薩婆多論》，以開緣之物來比況正式教制。「雨衣」就是用來沐浴洗澡的衣服，因夏季多有垢穢，所以聽許蓄持。自「即」以下通會前面的《薩婆多毘尼摩得勒伽》，該論之文之所以通許依循與不依循，純粹是依據知情或不知情而定：先已知曉有閏月隨後結夏者，必定要依隨閏月；先結了夏隨後才知有閏月者，則開許數滿日數即可。自「有」以下結語責難，其意顯而易知。

【1867-0003】03_業疏/20a_卷四之三#47
【原文】問：且如閏四月者，前四月二十日受一月出界，亦應攝閏在法內不？答：不得也。本閏正月，故曰閏餘，何得攝閏兩月出界？安居是制，受日是聽，故無開也。五事賞勞，其益亦爾。以利是奢，酬前功故，縱兼有閏，但止數滿，不同修道慕急通攝也
【譯文】問：姑且以閏四月為例，若在前面的四月二十日受請外出一個月，是否也應當將閏月包含在受日法限之內？答：不可以。閏月本來是附於正（常之）月，所以稱為閏餘，哪能將閏月也包含進去而成兩個月出界呢？結夏安居是強制性的制定（制法），外出受日是開許的聽法（聽法），所以不開許通攝閏月。功德衣五事賞勞大眾辛勞的利益也是如此。因為利養屬於寬縱之事，只是為了酬謝先前的功德，所以縱使適逢閏月，也只要滿常規的日數即可，不同於修道因求切急迫而通攝閏月。

【1867-0004】03_業疏/20a_卷四之三#48
【原文】例難問中，前四月受，後五月滿，中間含閏，共六十日。答中初正明受日。「五」下因決迦提。制是攝修，故宜長；開是奢縱，故宜短。閏法，每日餘分積成其月，還閏正月，名為閏餘，如《鈔》減年戒中細明
【譯文】在引例發難的提問中，前四月受日，後五月期滿，中間包含一個閏月，共計六十天。在回答中，首先正式說明受日出界。「五」字以下，順便決斷迦絺那衣（五事功德）的規定。制定（制法）是為了約束策厲修道，所以時間宜長；開許（聽法）屬於放寬縱容，所以時間宜短。依照閏法，每日的餘分累積而成一個閏月，歸結還是閏正月，因此稱為閏餘，這在《四分律行事鈔》的「減年受戒」戒條中有詳細說明。

【原文】若閏七月者，有二品坐法：從四月十六日至五月一日結者，皆三月住，莫不數滿，不及後閏故；五月二日結至七月末，止得八十九日，明旦是閏，含虗增故，不得充數，安坐本界，盡閏月未至八月旦滿九十日，明旦方去也。如是日日至後夏初，莫不收閏，皆四月住
