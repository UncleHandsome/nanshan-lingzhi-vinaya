# 校閱材料　第044檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【044-0001】01_行事鈔/03b_卷上之三#3
【原文】應語言：「善男子！汝遮難並無，眾僧同慶，當與汝戒。但深戒上善，廣周法界，當發上心，可得上法，如前緣中。今受此戒，為趣泥洹果，向三解脫門，成就三聚戒，令正法久住等，此名上品心。次為開廣汝懷者。由塵沙戒法注汝身中，終不以報得身心而得容受；應發心作虛空器量身，方得受法界善法。故《論》云：若此戒法有形色者，當入汝身作天崩地裂之聲；由是非色法故，令汝不覺。汝當發驚悚意，發上品殷重心。今為汝作羯磨聖法，此是如來所制，發得塵沙法界善法，注汝身心，汝須知之。」
【譯文】應當對受戒者說：「善男子！你的遮障與難事全都沒有，大眾僧同感欣慶，應當為你授戒。然而戒法深微，是至高無上的善法，周遍廣大於一切法界，必須發起上品之心，方能獲得上品戒法，如同前面緣起中所說。今日受持此戒，是為了趨向泥洹（涅槃）聖果，趣入三解脫門，成就攝律儀、攝善法、饒益有情之三聚淨戒，令正法長久住世等，這就稱為上品心。其次為你開拓廣大胸襟器量：因為如塵沙般無量的戒法將注入你的身心之中，絕非僅憑業報所感的血肉身心便能容受得下；必須發心使身心猶如虛空般無邊器量，方能容受法界的一切善法。因此《論》（《薩婆多論》）說：如果這戒法是有具體形相色質的，那麼當它注入你身中時，將會發出如天崩地裂般的巨響；正因為它是非色非相之法，才讓你毫無覺知。你應當生起驚悚惕勵之意，發起上品極殷重之心。如今正為你作羯磨聖法，這是如來所親自制定的，能發起塵沙法界的善法注入你的身心，你必須深刻體認明了。」

【044-0002】01_行事鈔/03b_卷上之三#4
【原文】應告僧言：「大眾慈悲，布施其戒。同心共秉，願勿異緣，令他不得。」應四顧望之，不令非別之相；有者喚令如法。告言眾僧聽作羯磨：「大德僧聽！此某甲，從和尚某甲，求受具足戒；此某甲今從眾僧乞受具足戒，某甲為和尚；某甲自說清淨，無諸難事，年滿二十，三衣鉢具。若僧時到僧忍聽：授某甲具足戒，某甲為和尚。白如是。」作白已，問僧成就不？乃至羯磨中第一、第二、第三，亦如是問。此《僧祇》文。準此，僧中知法者，答言成就。《十誦》：因為他受戒，或睡、入定、鬧語、闠亂等，佛言：不成受戒。羯磨時當一心聽，莫餘覺餘思惟；應敬重法；當思惟，心心相續憶念；應分別言，是第一羯磨，乃至第三，不說得罪。又應語受者言，已作白已，僧皆隨喜。今作羯磨動彼戒法，莫令心沈舉，當用心承仰。又白僧言，當聽羯磨：「大德僧聽！此某甲，從和尚某甲，求受具足戒；此某甲今從眾僧乞受具足戒，某甲為和尚；某甲自說清淨，無諸難事，年滿二十，三衣鉢具；僧今授某甲具足戒，某甲為和尚。誰諸長老忍僧與某甲受具足戒，某甲為和尚者，默然；誰不忍者，說。此是初羯磨。」問僧成就不？告受者言：「已作初羯磨，僧皆默可。今十方法界善法，並皆動轉；當起欣心，勿縱怠意。」次作二羯磨，如上問已，告受者言：「已作二羯磨法，僧並和合。今十方法界善法，並舉集空中；至第三羯磨竟時，當法界功德，入汝身心。餘一羯磨在，汝當發身總虛空界，心緣救攝三有眾生，并欲護持三世佛法。」直依此語，不同上廣。仍白僧言：「願僧同時慈濟前生，同共合掌佐助，舉此羯磨。」便即作之，乃至是事如是持已。
【譯文】應當告知大眾僧說：「請大眾慈悲，布施給他戒法。同心協力共同秉持作法，但願切莫分心旁騖於其他外緣，致使受戒者不得戒體。」應當環顧四周，不容許有非法或僧眾別異不和合的相貌；若有不合律制的，應喚其使其如法合儀。宣告大眾僧諦聽以作羯磨：「大德僧聽！此某甲，從和尚某甲，求受具足戒；此某甲如今從大眾僧乞求受具足戒，由某甲為和尚；某甲自陳清淨，沒有各項難事，年齡已滿二十歲，三衣一鉢皆已齊備。若大眾僧辦事時機已成熟，僧眾忍可聽許：授與某甲具足戒，由某甲為和尚。單白（告白）如此。」作完單白告白之後，詢問僧眾：「成就不？」乃至羯磨中的第一番、第二番、第三番，也都如此詢問。這是《僧祇律》的經文。依此律制，僧中通達律法者應回答說：「成就。」《十誦律》中說：若因替他人授戒作法時，有人瞌睡、入定、喧鬧言語、昏亂等，佛說：受戒便不成就。作羯磨時應當一心諦聽，切莫生起其他覺受或旁騖思惟；應當敬重戒法；應當深切思惟，心心相續專注憶念；應當清楚分別並口稱：這是第一番羯磨，乃至第三番羯磨，若不稱說則得罪。又應當對受戒者說：已經作完單白告白，大眾僧都已隨喜忍可。現在作羯磨以震動感發彼法界戒法，切莫讓自心陷入昏沈或浮躁高舉，應當用心虔敬承迎仰求。接著再向僧眾白言，應當諦聽羯磨：「大德僧聽！此某甲，從和尚某甲，求受具足戒；此某甲如今從眾僧乞求受具足戒，由某甲為和尚；某甲自陳清淨，無各項難事，年滿二十，三衣一鉢齊備；大眾僧如今授與某甲具足戒，某甲為和尚。若諸位長老忍可聽許大眾僧授與某甲具足戒、某甲為和尚者，請默然；誰不忍可聽許者，請發言說明。這是第一羯磨。」問僧眾成就不？隨後告知受戒者說：「已作完第一羯磨，僧眾皆已默然忍可。如今十方法界的善法，都已開始震動轉移；應當生起欣喜慶幸之心，切莫放縱懈怠之意。」接著進行第二羯磨，如同上面問詢僧眾之後，告知受戒者說：「已作完第二羯磨法，大眾僧皆和合無異。如今十方法界的善法，都已騰舉雲集於虛空中；到了第三羯磨結束時，此法界一切功德，將注入你的身心。尚餘最後一羯磨在，你應當發起自身量等同於整個虛空界，內心攀緣誓欲救度攝化三界六道一切眾生，並願護持三世一切諸佛法脈之弘願。」此處直接依此話語簡要提撕，不再像前面那樣廣說。仍須向僧眾告白說：「願大眾僧同時慈悲救濟眼前的發心眾生，共同合掌襄助，秉持唱誦這番羯磨。」隨即便作第三羯磨，乃至宣說「此件事情就這樣受持」完畢。

【044-0003】01_行事鈔/03b_卷上之三#5
【原文】若多人一人，即須隨竟，記其時節。《四分》云：有新受戒者，不及後安居，便數為歲，佛言不爾。有者，應和尚闍梨教授時節云，若冬若春若夏，若干日月；若食前食後，乃至量影。應預將一尺木，至受訖日中竪之，記其影頭，臥尺量之，計為尺寸，以為常法。《善見》云：受戒已，立取脚隨身量影，示春冬時。眾數多少。後說四依四重等。若受人多者，但有受竟，在僧下坐。乃至一切作已，方總集上座前，同時為說隨相。不必戒師。問：此新受戒人，相同界外來者，何不重和？答：非是外來，當處新起。
【譯文】不論受戒者是多人還是一人，羯磨完畢之後，就必須隨即記錄下受戒的時節時刻。《四分律》中記載：有新受戒者，未趕上後安居，便擅自計為一歲夏臘，佛陀訶責說不可如此。若有受戒者，和尚與阿闍梨應當教導其時節說：是冬、是春、還是夏，第幾個月、第幾天；是午前食前還是午後食後，乃至量度日影。應當預先備好一尺長的木條，到了受戒完畢時，在日光中將木條豎立起來，標記其日影尖端，再把尺平放倒地量度其長度，計算出確切的尺與寸，以此作為通行的常規法度。《善見論》（《善見律毘婆沙》）說：受戒完畢之後，令受戒者站立，以其腳長為單位量度其隨身日影，並標示春季或冬季時節，以及在場參與的大眾人數。其後再為其宣說「四依法」與「四波羅夷重戒」等。如果受戒的人多，凡是受戒完畢的，便依次坐在僧團的下座；直到所有人全部作法完畢，才總集在大眾上座面前，同時為他們宣說隨相（持犯戒相）。宣說者未必限定是戒師。有人問：這位新受戒的人，其情況如同從界外新來的人一樣，為什麼不再度舉眾重新和合呢？回答：他並不是從結界之外進來的人，而是在本界道場當處新成就戒體的。
