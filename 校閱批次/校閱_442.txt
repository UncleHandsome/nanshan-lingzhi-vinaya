# 校閱材料　第442檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【442-0001】資持記/10a_中三下#24
【原文】以化就蕩相，制是建立，故云不應求等。論具云：諸佛世尊結諸戒，是中不應求有何實〔體之虛實〕，有何名字〔名之有無。〕，何者相應，何者不相應〔義之違順〕；何者是法，如是相；何者是法，不如是相〔相之是非〕，以是故是事不應難。〔化教詮理，必須四義求之。〕次難中。
【譯文】因為化教側重於破除執相，制教側重於建立事相，所以說不應當追求等等。論中完整說：諸佛世尊制定各項戒律，在這當中不應當追求有何等真實體性〔本體的虛妄或真實〕，有何等名字〔名稱的存在或沒有〕，什麼是相應的，什麼是不相應的〔義理的順從或違逆〕；什麼是法，符合這樣的相狀；什麼是法，不符合這樣的相狀〔法相的是與非〕，正因如此，這件事是不應當詰難的。〔化教詮釋真理，必須依據這四種義理去探求。〕在第二個詰難中。

【442-0002】資持記/10a_中三下#25
【原文】論文前云如來為除邪見，不言迦羅，說三摩耶。謂餘經中多說假時；如上引律，乃說實時；義有相違，故以為難。答中為二，初明毘尼說實意，上句正示。〔不字誤，論文正作中字。〕以下，顯意。謂毘尼不許白衣外道聞故，可說實時；以道眾自知非實，不生邪執故。〔文中下聞字，論作而字。〕說下，次明餘經說假意。
【譯文】論典文字先前說如來為了破除邪見，不言迦羅，而說三摩耶。意思是其餘經典中多數說假時；但像上面引用的戒律，卻說的是實時；義理上存在矛盾，所以拿來詰難。回答中分為兩部分：首先說明戒律中說實時的意圖，上一句正式指出。〔「不」字是傳抄錯誤，論文原本正是「中」字。〕從「以」以下，顯明其用意。這是說戒律不允許在家人和外道聽聞，所以可以說實時；因為出家修道的大眾自己明白並非真實體性，不會生起邪妄執著的緣故。〔文中下面的「聞」字，論文原本寫作「而」字。〕從「說」以下，其次說明其餘經典說假時的意圖。

【442-0003】資持記/10a_中三下#26
【原文】通多分者，道俗俱可聞故。〔古多錯解，妄改文字；學者難曉，不免繁文。〕顯意中。以學語者恥已貪嗜，濫謂大乘無時非時；故今還引《大論》以誡邪執；近世學大學小，噉食無時，不畏佛戒。銅漿鐵丸，焦爛喉腹，病徹心髓，誰當代之？悲夫！次科。經即《毘羅三昧經》。

【442-0004】資持記/10a_中三下#27
【原文】通列四時。前後三種，大約不定。日中一種，佛佛常法；以住中道，假事表理故；凡所化儀，無不皆中。佛制下，正顯教意。上有三趣，地獄同鬼類。欲超三界，必斷六因。故制比丘不同彼食，令依極聖，出離可期。嗟彼愚人，多食晚食；肯斆諸佛，而甘同鬼畜，不知何意乎！
【譯文】通盤列出四個時段。前後三種時段，大概來說並不固定。唯獨正午這一種，是過去諸佛與未來諸佛永恆不變的法則；因為安住於中道，藉由世事來表徵真理的緣故；凡是教化的威儀，無一不是契合於中正之道。從「佛制」以下，正式顯明教戒的深意。上面經文列有三種世間趣（天、畜生、鬼神），地獄與餓鬼同類。想要超越三界，必須斷除六道的業因。故制比丘不同於那樣進食，令其依止至極的大聖，解脫出離才指日可待。可歎那些愚癡的人，大多喜歡在晚間進食；不肯效法諸佛，反而甘心等同於餓鬼畜生，真不知心裡是怎麼想的！

【442-0005】資持記/10a_中三下#28
【原文】三中，《多論》，初釋時非時。四義中，初約日明出沒，餘三約乞食合宜不宜。二三約他事，第四就己行。又下，明時分不定。晝夜各九時〔且約相等〕，《增輝》引古解云：晝夜都十八時，一時有五十臘縛，十八時總九百臘縛，三十臘縛為一須臾。〔三百為十須臾，九百為三十須臾。〕事同者，同下《僧祇》故。〔《俱舍》一百二十剎那為一怛剎那。
【譯文】第三部分中，《多論》首先解釋適當時限與非適當時限。四種義理中，第一種是依據太陽來說明升起與落下，其餘三種是就乞食合不合適來說明。第二和第三種是就他人之事來說，第四種是就自己的行持而言。從「又」字以下，說明時間劃分並不固定。白天和夜晚各分為九個時辰〔暫且依照相等的時間來論〕，《增輝記》引用古人的解釋說：白天夜晚總共十八個時辰，一個時辰有五十臘縛，十八個時辰總共九百臘縛，三十臘縛為一個須臾。〔三百臘縛為十個須臾，九百臘縛為三十個須臾。〕事情相同，是因為與下文的《僧祇律》相同。〔《俱舍論》說一百二十個剎那為一個怛剎那。

【譯文】六十個怛剎那為一個臘縛。三十個臘縛為一個須臾，三十個須臾為一晝夜。〕太陽落至接近地面的說法，依照《俱舍論》，太陽和月亮在須彌山半腰，距離地面有四萬由旬；依照這個說法就沒有落至地下的意義，只是太陽運行到最南邊時，看起來好像落了下去；因為天上南北相距有一百八十條運行軌道，太陽就在這當中來回運行，以此劃分出八個節氣；

【442-0008】資持記/10a_中三下#31
【原文】從北却迴至立春春分立夏夏至，各經四十五道；還至極北，如是終而復始。四十。《時非時經》即《阿含》別品，是以雙標。彼約脚影定一年中日夜長短，須者尋之。準俗者，此方亦以十五日為一氣，一氣有三候，一候有五日，三氣為一節〔四十五日〕，一年有四時八節二十四氣七十二候三十六旬。
【譯文】從北面往回返運行到立春、春分、立夏、夏至，各經過四十五條軌道；又回到了最北邊，就這樣循環往復。第四科。《時非時經》就是《阿含經》的個別篇章，所以並列標示出來。該經依據腳影長短來測定一年之中白天黑夜的長短，需要的人可以去查閱。依照世俗之法，此方也是以十五天為一氣，一氣有三候，一候有五天，三氣為一節〔四十五天〕，一年有四季、八節、二十四氣、七十二候、三十六個十天。

【原文】風塵落鉢不受相雜，捨受聽食，方便免過。文約沙彌，餘眾淨人，理應通許。〔諸文所明，不唯當戒不受惡觸；事犯相涉，文中可見；臨文辨之，勿使參濫。〕不犯四節。初不自食。二與作人，還從乞得，義同新故。三鉢中所餘，無由淨故。四為治病，非欲食故。西土患眼，多以酥油灌鼻。
【譯文】風揚塵土落在鉢中，未經受授的塵土與食物相混雜，律中開許捨去先前的受法重新由沙彌授與比丘而允許食用，透過這種方便免除過失。文中雖以沙彌為例，其餘大眾和淨人，照理都應當通融准許。〔各部律文所說明的，不只是當前這條戒的不受而食或惡觸碰；事相與犯行互相關涉，在文中處處可見；閱讀經文時應當明辨，不要讓它們互相混淆。〕不犯戒的情況有四節。第一是不自己吃。第二是交給作事人，再回過頭向他乞得，在義理上等同於新食物。第三是鉢中所剩餘的，無法再行作法清淨。第四是為了治病，並不是想要進食。西域治療眼病，大多用酥油灌入鼻腔。
