# 校閱材料　第061檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【061-0001】01_行事鈔/04b_卷上之四#1
【原文】初中，《四分》不得在樹上。若樹下，起不礙頭，枝葉足蔭一坐；如是乃至小屋、山窟中，坐趣容膝，足障水雨。若依牧牛人、壓油人、船上人、斫材人、依聚落等，並成。若依牧牛人已下五處者，若安居中移徙，隨所去處，應去。文中不了。《五分》云：諸依如上人者，先謂作住意，得依安居；中間忽去，隨信樂衣食豐足處去。若在無護處，劫賊、塚間、鬼神處、毒蟲窟、露地，若有命梵二難，並不成安居。《明了論》五種成安：一處所有覆。二夏初十六日，謂為成前後安居日故。三若東方已赤，謂十五日夜分盡，則東方赤者，是十六日限；為破《十誦》疏家，要令十五日及界宿故。四若在別住，起安居心。《疏》云：別住是布薩界。安居心三種：一為自行；二為利他；三為料理三寶，修治房舍。一脚蹋界，起安居心即成。五在處無五過：一太遠聚落，求須難得。二太近城市，妨修道業。三多蚊螘難，或噆齧人，踐傷彼命。四無可依人，其人具五德：謂未聞令聞、已聞令清淨、能為決疑、能令通達、除邪見得正見。五無施主施飲食湯藥。無此五過，乃可安居。《四分》、《摩得伽》中，大同此論。《十誦》云：無人深山，可畏處，不須住。《五分》云：若在無救處，必知無妨害，亦開。欲安居時，先思量有難無難，無難應住。《毘尼母》第六卷中，大明安居方便法用，文廣不錄。乃至安居上座，於一切僧集時、食時、粥時、漿時，應白言：「爾許時已過，餘有爾許時在。」若行此等行法者，是名僧父母，亦名僧師。
【譯文】初中，《四分律》規定不得在樹上安居。若在樹下，起立時不礙著頭，枝葉足以遮蔭一個坐處；如此乃至小屋、山窟之中，坐下僅能容膝，足以遮蔽風雨。若依止牧牛人、榨油人、船上人、伐木人、依止聚落等處，都算成就。若依止牧牛人以下五處，如果在安居期間遷移，隨其所去之處，應當跟隨而去。律文中對此未作明確交代。《五分律》說：凡依止上述等人者，起初若抱持安住之意，便得依之安居；中途他們若是突然離去，隨其信樂且衣食豐足之處跟隨而去。若在無人救護之處，如劫匪出沒處、墓地塚間、鬼神聚居處、毒蟲洞窟、露地，或者有危及生命與梵行（命梵二難）者，皆不能成就安居。《明了論》提出五種成就安居的條件：一是處所有遮覆。二是夏初十六日，這是為了成就前、後安居日期的緣故。三是若東方已泛紅，指十五日夜分已盡，東方破曉泛紅，這便是十六日的界限；這是為了破除《十誦律》的義疏家認為必定要令比丘在十五日當天及時趕到僧界內投宿的說法。四是若在別住處，生起安居之心。《疏》說：別住是指布薩（說戒）界。安居之心有三種：一是為了自修德行；二是為了利益他人；三是為了照料三寶產業、修繕房舍。只要一隻腳踏入界內，生起安居之心即告成就。五是所住之處無五種過患：一是距離聚落太遠，所需物資難以取得。二是距離城市太近，妨礙修習道業。三是多蚊蟻之患，或叮咬人，或行走踐踏傷害牠們的生命。四是沒有可依止之人，此人應具備五德：即未聽聞的佛法能令聽聞、已聽聞的能令理解清淨、能為其決斷疑難、能令其通達法義、能破除邪見而得正見。五是沒有施主布施飲食與醫藥。沒有這五種過患，方可安居。《四分律》、《薩婆多部摩得伽》的說法，與此論大致相同。《十誦律》說：無人的深山等令人怖畏之處，不需要住。《五分律》說：若在無人救護之處，但確知無所妨害，也開許安居。想要安居時，應當先思量是否有災難，沒有災難就應當安住。《毘尼母經》第六卷中，詳細闡明安居的方便法度與運用，文篇幅繁廣故不抄錄。乃至安居上座，在一切僧眾集合時、正餐時、食粥時、漿時，都應宣告說：「已經過了這麼多時間，還剩下這麼多時間在。」若能奉行這等行法者，稱為僧中的父母，也稱為僧中的導師。

【061-0002】01_行事鈔/04b_卷上之四#2
【原文】二結時前後。由夏中壞行義多，招譏復重，故文云：自今已去，聽三月夏安居。春冬過少，必無事不依，同結吉羅。問：何為但結三月者？一生死待形，必假資養；故結前三月，開後一月，為成供身衣服故。二若四月盡結，則四月十六日得成；若有差脫，便不得結；教法太急，用難常準。故如來順物，始從十六日，至後十六日；開其一月，續結令成。上總三時分別。今但就夏，亦有三時：初四月十六日是前安居；十七日已去，至五月十五日，名中安居；五月十六日名後安居。故律中有三種安居，謂前中後也。前安居者住前三月，後安居者住後三月；雖不云中三月，然文中具明前後日數，中間不辨，於理自明。結文各別，如後法中。因汎明前後：一賞罰前後。四月十六日是前；十七日已去結者，並不得五利，故名罰也。二得罪前後。五月十五日已前，名前；以有緣如法，不結無犯；無緣，吉羅。十六日者，緣與無緣，皆結一罪，唯除難事。尼同僧犯，唯有墮別。三難事先後。《五百問》云：從夏初日，有難事不得結，而不出本界；至後夏來，並名前坐；是名三十日安居，同至七月十五日受歲。若五月十六日安居，唯得一日結；後七月半已，有難者，可隨無難日自恣；是名一日安居，三十日受歲。
【譯文】二結時前後。由於夏季中敗壞行門的因緣甚多，招致譏嫌又極為嚴重，故律文說：從今以後，准許三個月夏安居。春冬二季過失較少，若無事而不依制安居（禁足），同樣結突吉羅罪。問：為何只結夏安居三個月？答：第一，生死之身有待形骸，必定要憑藉資具滋養；因此結夏前三個月，放開最後一個月，是為了成就供養色身的衣服（迦絺那衣）之緣故。第二，若四個月全部結夏安居，則四月十六日即可成就；若稍有差錯疏失，便不得結夏安居；教法過於急促嚴苛，在運用上難以作為常規標準。所以如來隨順眾生根機，從四月十六日起，至五月十六日止；放開這一個月的時間，使之得以相續作法受安居而得成就。以上是就春夏冬三時總體分別。現在單就夏季而言，亦有三時：起初四月十六日是前安居；十七日以後，至五月十五日，稱為中安居；五月十六日稱為後安居。因此律中有三種安居，即前、中、後安居。前安居者安住於前三個月，後安居者安住於後三個月；雖然未明言中三個月，然而律文中具體載明前後的日數，中間這段時間縱未辨析，在義理上自然明白。受安居的誓詞（結文）各有差別，如後面的行法所述。順此廣泛說明前後的分別：第一、賞罰前後。四月十六日是前安居；十七日以後結夏者，皆不得享受五利（五種利益），所以稱為罰。第二、得罪前後。五月十五日以前，稱為前安居期間；若有正當因緣且合乎戒法，不結夏無犯；若無正當因緣，結突吉羅罪。十六日這一天，無論有緣或無緣而不結夏，皆結同一罪過，唯除遭遇災難阻礙之事。比丘尼與比丘所犯相同，唯有結罪屬於波逸提（單墮罪）的差別。第三、難事先後。《五百問事》說：從夏初之日起，有災難阻礙而不得結夏，但並未走出本界；到了後夏安居之時，皆稱為前坐；這稱為三十日安居，同樣到七月十五日受歲（結束安居結算戒臘）。若是五月十六日安居，僅得一日結夏；之後到了七月十五日以後，若有災難，可隨無災難之日舉行自恣；這稱為一日安居，三十日受歲。

【061-0003】01_行事鈔/04b_卷上之四#3
【原文】三夏閏延促者。依閏安居，無有正文。比於《薩婆多》云：夏中有閏，受雨衣得百二十日。彼衣開法，尚依夏閏而受；夏是制教，理宜通護。又本結安居，要心三月不出；今夏未滿，閏中出界，即非相續而滿，是以破也。若不依閏者，數滿九十日便自恣。《摩得伽》云：安居已，王作閏月；數安居日滿，自恣已，受迦絺那衣。即此衣成受不成受，謂依閏不依閏。既二文兼具，至時隨緣。夏初要心取閏，不得依《伽論》；若反前者，通二論兩文。
【譯文】三夏閏延促者。依照閏月安居，律中沒有正文規定。比照《薩婆多論》所說：夏中有閏月，受雨安居衣可得一百二十天。彼處衣法的開許，尚且依照夏中的閏月而領受；夏安居是佛陀的制定之教（制教），於理更應當通融守護。再者，當初結界安居時，誓願期約（要心）三個月不出界；如今夏期未滿，在閏月中出界，即非相續圓滿，因此算是破夏。如果不依閏月，日數滿九十天便舉行自恣。《摩得伽》說：安居之後，國王設立閏月；算滿安居日數，自恣之後，領受迦絺那衣。這件衣服成就受領或不成就受領，取決於依閏月或不依閏月。既然兩部論典的文義兼具，屆時應隨順因緣。夏初立誓時若決意算入閏月，便不得依循《摩得伽論》；若與前者相反，則通於兩部論典的兩種文義。
