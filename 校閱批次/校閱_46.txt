# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【記】今用四種三寶，對此六義。
【譯文】【記文】現在運用四種三寶的分類，來對應這六種意涵。

【46-0002】02_戒疏/02a_卷一上之二#44
【原文】【記】初義通四。住持，無信不遇；化相，無緣不遇，舍衛三億，可以明之；理體局聖，凡愚不遇；一體，二乘不遇。
【譯文】【記文】第一種稀有義，貫通於四種三寶。對於住持三寶，沒有純淨信仰的人無從得遇；對於化相三寶，沒有成熟善緣的人無從得見，例如舍衛城三億人不知不聞佛陀，便足以證明這點；理體三寶唯局限於出世聖者，凡夫愚夫無法得見；一體自性三寶，則是滯留二乘之人未能徹證得見。

【46-0003】02_戒疏/02a_卷一上之二#45
【原文】【記】第二義中，唯約理寶。《歸敬儀》云：「住持三寶，體是有為，具足漏染。」又云：「化相體是無常，四相所遷，滅過千載，但可追遠，用增翹敬。」據後一體，在迷隨染。故此三種，皆無此義。
【譯文】【記文】第二種離垢義，唯獨就理體三寶而言。《歸敬儀》中說：「住持三寶的本體屬於有為生滅法，仍然具足有漏與雜染之相。」又說：「化相三寶的本體具有無常之性，被生老病死四相所遷流推移，佛滅度至今已過千載，今日只能追憶遙念，用以倍增虔敬仰慕之心。」若論及後面的自性一體三寶，在凡夫迷執時依然隨順著雜染而沉淪。所以這其餘三種，都不具備離垢義。

【46-0004】02_戒疏/02a_卷一上之二#46
【原文】【記】第三喻中，六通在人，唯對化相。神境、他心、天眼、天耳、宿命、漏盡，六皆明徹，總號為「通」。「毒」謂苦惱，下云寶能現除貧苦，與此頗同。
【譯文】【記文】第三種勢力譬喻中，六種神通依止於人身，唯有對應於化相三寶。神境通、他心通、天眼通、天耳通、宿命通、漏盡通，這六種都透澈明朗，總括統稱為「神通」。「毒」是指眾生的種種苦惱，下文說世間珍寶能現世拔除貧窮苦難，與此處頗為相符。

【46-0005】02_戒疏/02a_卷一上之二#47
【原文】【記】第四通四。住持、化相，能發信仰；理體、一體，可以修證：皆是「嚴身」。
【譯文】【記文】第四種莊嚴義，貫通於四種三寶。住持三寶與化相三寶，能啟發引導世人內心的正信；理體三寶與一體三寶，則能作為行者親自修習證悟的依歸：這些全都能夠用來「莊嚴法身」。

【46-0006】02_戒疏/02a_卷一上之二#48
【原文】【記】第五亦通四。餘三易解。住持佛法，雖是世物，莫不表示法身功用無極。《儀》云：「金木石土，體是非情，以造像故，敬毀之人，自獲罪福。」故知此寶，得名「無上」。法亦準同。剃染之僧，為世福田，人天中勝。破戒惡行，猶過外俗，況餘持奉，其勝可知。
【譯文】【記文】第五種最勝義，同樣貫通於四種三寶。其餘三種容易理解。住持佛寶與法寶雖然屬於世間物質形相，但無一不是象徵表露法身功德妙用的無窮無盡。《歸敬儀》說：「金屬、木頭、石頭、泥土，本體雖然屬於無知無情之物，但因為被塑造為佛像的緣故，前來禮敬或加以毀損的人，自身便會獲得無量福德或罪障。」由此可知連這住持佛寶，都能獲得「至高無上」之名。住持法寶也是同樣的道理。剃髮染衣的僧寶，作為世間的大福田，在人道天道之中最為尊貴殊勝。即便是有破戒惡行的比丘，其出世身分依然超越世俗常人，何況其餘精嚴持戒奉持律儀的僧眾，其殊勝無上更是不言而喻。

【46-0007】02_戒疏/02a_卷一上之二#49
【原文】【記】第六唯局理寶。《儀》云：「此之三寶，常住於世，不為世法之所陵慢。」一體雖常，然就迷邊，隨緣流變；餘二無常，非所論矣。「八法」者，《智論》云：衰利毀譽，稱譏苦樂，四違四順，能動物情，名為「八風」。理寶人法，皆是出世無漏聖道，不為八法之所動故。
【譯文】【記文】第六種不改義，唯獨局限於理體三寶。《歸敬儀》說：「這理體三寶常住於世間，絕不為一切世俗生滅法所凌辱侵害。」一體三寶本性雖然常住，然而就迷執的層面而言，仍隨緣產生遷流變異；其餘兩種本體無常，更非此處所論。「八法」，《大智度論》說：衰落、利益、毀損、名譽、稱讚、譏諷、痛苦、快樂，這四種違逆、四種順應之境，最能牽動凡夫的心情，所以名為「八風」。理體三寶中的行者與正法，全都是超越世間的無漏聖道，絕不會被世間八風所動搖。

【46-0018】02_戒疏/02a_卷一上之二#60
【原文】【記】初明理寶，文出《多論》。「五分」者，戒、定、慧，從因受名，解脫、解脫知見，從果彰號。由慧斷惑，惑無之處，名解脫。出纏破障，反照觀心，名解脫知見。「滅理」，四諦、滅諦、涅槃。「學、無學」者，初果已去，同見真諦，名理和僧。然此理寶，亦即同體，但望佛、僧證理邊為別。故《多論》云：「佛亦是法，法亦是佛，僧亦是法。止是一法，相有差別，故分三寶。」
【譯文】【記文】首先說明理體三寶，經文出自《薩婆多論》。「五分」法身，戒、定、慧是從修行的因位而獲得名稱，解脫與解脫知見則是從證悟的果位而彰顯名號。由於智慧能斷除煩惱惑業，煩惱不復存在之處，就稱為解脫。跳脫纏縛、破除障礙，迴光反照審觀自心體性，就稱為解脫知見。「滅理」，是指苦、集、滅、道四聖諦中的滅諦涅槃。「學、無學」，是指從初果須陀洹以上，同修共見真空真諦之理，稱為理和同體僧。然而這種理體三寶，本質上也即是同體三寶，只是對照佛陀與僧伽證悟真理的角度而有所區別。所以《薩婆多論》說：「佛也就是法，法也就是佛，僧也就是法。其實只是一部妙法，由於顯現的相狀有所差別，因此劃分為三寶。」

【46-0019】02_戒疏/02a_卷一上之二#61

【46-0024】02_戒疏/02a_卷一上之二#66
【原文】【疏】四種之中，初「理」為本，餘三從相，故為末也。如毀佛出血，據相無罪，化佛無心，非情無惱也；以損法身所依，故結重逆。法僧損益，本末例然。故《大集》云「若打破戒、無戒比丘，罪重出萬億佛身血」者，豈不以形服出世，為聖道標，若加輕毀，則三寶通壞故也。
【譯文】【疏文】在這四種三寶之中，最初的「理體」是根本，其餘三種都是從外相而衍生顯現的，所以是枝末。例如毀壞佛身導致出血，單純就外在色相而言原本無罪，因為應化佛身沒有凡夫血肉的心識，無情之物受損不會產生惱害；然而因為損壞了無漏法身所依託的器質，所以結成最重的逆罪。法寶與僧寶的受損與增益，本末的道理也是如此。因此《大集經》說「如果毆打破戒、無戒的比丘，其罪更重於使萬億尊佛的身軀出血」，這難道不是因為其形相與法服代表了超脫世俗的表徵，作為出世聖道的標誌旗幟，如果對其施加輕賤侮辱，那麼就等於將整個三寶的尊嚴全都毀壞殆盡的緣故嗎？

【46-0025】02_戒疏/02a_卷一上之二#67
【原文】【記】總明中。初正示。「如」下，舉事以顯，先明佛寶。此明化相，以理為本，化相應身，故云「化佛」。《多論》：「問：『何以出色身血，得逆罪耶？』答：『以色身是法身器故，法身所依故。』」、「法」下，例餘二寶。如破法輪，正望真諦無證入故；如殺羅漢，亦望證理，福田極故。是則化相，皆望理寶以論罪福。「故」下，別證僧寶，即約住持以證化相。初引經文，破戒無戒，打業極重，故知不取儀相論僧。「豈」下，推經意。「形服」是住持僧。「聖道」即理寶僧。住持佛、法，由僧弘顯，是故毀僧則兼佛、法，故云「通壞」。又《智論》云：如泥銅等，體是無記，非感罪福，以成法身相，隨前敬慢有罪福也。一體在迷，迷從理起，悟還復理，本末可知。
【譯文】【記文】在總體說明的科判中。首先正面提示。「如」字以下，列舉具體事例來顯明，先說明佛寶。這是指化相三寶是依據理體為根本，化現的應身，所以稱為「化佛」。《薩婆多論》：「提問：『為什麼使佛陀的色身出血，會獲致無間重逆的大罪呢？』回答：『因為色身是法身的器皿寄託，是法身所依持顯現之處的緣故。』」「法」字以下，比照其餘兩種寶。例如破壞轉正法輪，主要是因為它障礙了眾生證入真諦的可能；又如殺害阿羅漢，也是因為阿羅漢已徹證真理，作為最極致的福田。由此可知化相三寶，都是以理體三寶為根本基準來評斷罪過與福報的。「故」字以下，特地用引證來確立僧寶，也就是透過住持僧寶來佐證化相僧寶的道理。首先引用佛經原文，指出毆打即便破戒或無戒的僧人，其惡業罪報都極為沉重，由此可知不能單純以個人戒行儀態來輕慢僧寶整體。「豈」字以下，推敲經文深義。「形服」代表的是世間住持僧。「聖道」代表的則是理體聖僧。住持世間的佛寶與法寶，全賴僧寶加以弘揚顯發，因此毀損僧寶就連帶損害了佛與法，所以說「通通毀壞」。又《大智度論》說：例如泥塑銅鑄的佛像，本身實質是無知無記的材質，原本不會招感罪障或福德，但因為它成就了法身莊嚴之相，隨著瞻仰者內心的敬奉或怠慢輕視，而分別獲得福報或招致罪衍。一體自性三寶在迷妄之時，迷妄也是依託理體而生起，一旦覺悟又回歸理體本源，本末的層次自然清楚可知。

【46-0028】02_戒疏/02a_卷一上之二#70
