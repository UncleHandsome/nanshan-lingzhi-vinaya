# 校閱材料　第410檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【410-0001】03_業疏/11a_卷二之五#66
【原文】次定學中初示定相。名色即是所觀五陰，四陰屬心，心無形相，但有名字，故云名色。故智論云：「一切諸法中，但有名與色。若欲如實觀，但當觀名色。」準此，竝通大小觀境，今文且就小教為言。謂觀此五陰，緣會故生，緣散即滅，生滅從緣，了無自體，無體故空，空即是理，故云「緣修生滅為理」也。故下引證論，明大小兩乘真如差別，文見第四。如疏略引，彼又續云：「此虗妄觀，唯因中有，果地則無。是故此如，因中則成，果地則壞。菩薩如者，離於虗妄，約真性以觀真故，如此如於因果中二處無異，故唯成不壞。是故二乘如者，逐其定滅，去而不來；菩薩如者，因果恒有，去來不異，捨因到果，故稱如去，從果出用，故曰如來。」故下結示。了達五蘊，專緣行心，隨見起滅，住於寂滅，故無諦用；不同大士證真起用故也
【譯文】次定學中，首先開示禪定的相狀。「名色」就是所觀照的五陰（五蘊），受、想、行、識四陰屬於心法，心識沒有實體形相，只有假立的名字，所以稱為名色。因此《大智度論》說：「一切諸法中，只有名與色。若想作如實的觀照，只應當觀著名色。」依此而言，這本來通於大乘與小乘的觀境，如今文中暫且就小乘教法來說。意思是觀照這五陰，因緣和合所以生起，因緣離散隨即謝滅，生滅都順從因緣，全然沒有獨立的自體，沒有自體所以本性為空，空就是真理，所以說「攀緣修行以生滅為真理」。自「故下」以下引用論典印證，闡明大、小兩乘所證真如的差別，經文見於《佛性論》第四卷。如業疏中所簡略引用的，該論後面接著說：「這種虛妄的修觀，只存在於因地之中，到了果地便不復存在。因此這種真如，在因地時得以成立，在果地時就會毀壞。菩薩所體證的真如，遠離了一切虛妄，依照真實自性而觀照實相，所以這種真如在因位與果位二處沒有差別，只有圓成而不毀壞。因此二乘人所見的真如，隨逐著入定寂滅，去了就不再來；菩薩所體證的真如，在因果二位恆常存在，去與來沒有差別，捨離因位到達果位，所以稱為『如去』，從果位中顯發妙用，所以稱為『如來』。」自「故下」以下結示其意。小乘了達五蘊，專注攀緣行陰之心，隨其所見皆是生起與謝滅，最後住於灰身滅智的寂滅，所以沒有依真諦而起的大用；這不同於大乘菩薩證得真如實相之後能生起妙用。

【410-0002】03_業疏/11a_卷二之五#67
【原文】今學語者，謂以四諦八正為道，得其語也。行心須緣，故語、業、命是其道戒，念、定、方便義約禪靜，正思及見此為慧觀。四儀緣籌，唯在慧解；慧心一動，隨念追覺，初思後見，見是道明
【譯文】如今只學得口頭話語的學者，說以四諦、八正道為修道之法，這只不過得到名相言說罷了。實踐之心必須藉事攀緣，所以正語、正業、正命是聖道之戒；正念、正定、正方便（正精進），義理上配屬於禪定寂靜；正思惟與正見，則是智慧觀照。在行住坐臥四威儀中籌謀因應，全在於智慧的理解；智慧之心一旦發動，隨即隨順正念追隨覺悟，起初由思惟破除惑執，而後由正見印證真理，這正見即是照破無明的聖道光明。

【410-0003】03_業疏/11a_卷二之五#68
【原文】三慧學中初科，初斥其逐語而不知修，故下示其道相。即以八正配屬三學：口語、身業、活命，此三屬戒；攝念入定，由於方便，方便即是正精進，此三屬定，念與方便非正禪定，今以意收，故云義約；思是思擇，即破惑之智，故曰初思；見是見解，即證理之慧，故云後見。四儀等者，謂隨事觀察，推功歸慧
【譯文】第三慧學中的初科，首先斥責那種追逐言說文字而不知實修的偏弊，所以自「故下」以下開示聖道的行相。也就是將八正道配屬於戒、定、慧三學：口中言語（正語）、身體行業（正業）、生活謀生（正命），這三者屬於戒學；攝斂念頭趣入禪定，必須憑藉方便，方便也就是正精進，正念、正定、正精進這三者屬於定學，念與精進方便並非純粹的禪定本體，如今以意旨相通而加以收攝，所以說是「義約」（義理上權且配約）；「思」是思惟審擇，也就是破除惑障的智慧，所以稱為「初思」；「見」是真實見解，也就是證悟真理的實慧，所以稱為「後見」。「四儀」等語，是說隨順一切事相進行觀察，其成道之功全都歸結於智慧。

【410-0004】03_業疏/11a_卷二之五#69
【原文】斯據法忍，故非凡地；然分有解，亦稱見也。故成實云：「得世上正見，不生惡道」者，即相似無漏分斷三塗，通說得也
【譯文】這八正道的見解是依據見道位（法忍）而說，所以已不是凡夫地境界；然而凡夫若部分產生了理解，也可以稱為見。所以《成實論》說：「得到世間第一之正見，就不墮落惡道」，這就是指相似無漏的智慧，部分斷除了墮落三惡道的因緣，通貫而言也是說得通的。

【410-0005】03_業疏/11a_卷二之五#70
【原文】次科，初結前所配。法忍即初果，即知入聖可名正道。「然下」次正顯通凡。分有解者，謂內凡四善根中世第一人，分見空理。下引成論證成分見。世上，謂將入聖位，凡中最上，謂世第一也；望真無漏，故云相似；望盡見障，故云分斷
【譯文】次科中，首先總結前面所配屬的位次。「法忍」就是指初果見道位，由此可知唯有證入聖位才可稱為真正的正道。自「然下」以下，其次正式闡明這也能通於凡夫位。所謂「分有解」，是指內凡位四善根中處於「世第一法」階位的人，部分照見了偏空真理。下文引用《成實論》來證成凡夫也能部分見理。「世上」，是指即將登入聖位，在凡夫位中居於最上位，也就是「世第一法」；相對於真正的無漏慧而言，所以稱為「相似」；相對於完全斷盡見惑的障礙而言，所以稱為「分斷」。

【410-0006】03_業疏/11a_卷二之五#71
【原文】據其戒定，義約為言。正斂身心，但緣慧理，無心緣罪，身口不起，故道戒三從此得名；緣理觀度，凝想無漏，約心不散，義名為禪，故道定三從此有也。本唯慧觀，滯漏是障，思擇障本，畢竟無依，由斯行起，發生無作，即名此業為道有也
【譯文】依據八正道中的戒與定，是從義理融攝的角度來說的。當如法收斂身心、一心攀緣智慧真理時，沒有起心去造罪，身、口惡業自然不起，因此「道共戒」的三個項目（正語、正業、正命）便由此建立名稱；心緣真理而觀照出離，專凝思慮於無漏法，約束心念不使散亂散逸，在義理上稱為禪定，因此「道共定」的三個項目（正念、正定、正精進）便由此得以安立。修道根本全在於智慧觀照，滯著於有漏煩惱即是障礙，審察思擇這障礙的根本，實是畢竟虛妄而無所依托；由此觀行生起，引發了無作戒體（無表業），就稱這種業力為依聖道而有的業。

【410-0007】03_業疏/11a_卷二之五#72
【原文】三中前敘戒定。初二句通標，以斷證之時正用慧學，相兼非正，故云義約。「正下」別釋。心既緣理，則攝斂身口，自然無惡；澄凝念慮，任運不散；約此二義，以為戒定。「本下」後正顯慧學。滯漏是惑，思擇即慧，畢竟無依即真空理，發生無作即無漏功德，道分所獲，故云道有
【譯文】第三科中，前面先敘述戒與定。開頭兩句為通標，因為在斷除煩惱、印證真理之時，主要起作用的是慧學，兼帶並非正體，所以說是「義約」。自「正下」以下進行分別解釋。心既然攀緣真理，便收斂身口，自然不作惡事；澄清凝聚念慮，任運不散亂；依據這兩種義理，安立為戒學與定學。自「本下」以下，後面正式顯明慧學。「滯漏」是指煩惱惑業；「思擇」就是指智慧；「畢竟無依」就是指真空實理；「發生無作」就是引發無漏的功德；這是在聖道分位中所獲得的，所以稱為「道有」。

【410-0008】03_業疏/11a_卷二之五#73
【原文】若據大乘，戒分三品，約義收緣，不異諸律。何以明之？如殺一戒，具兼三位：息諸殺緣，攝律儀也；常行慧命，即攝善法也；護前命故，即攝眾生。此一既爾，餘者例然。非無一二遮戒，如地持等，寶璧開制，戒異凡小
【譯文】若依據大乘佛教，戒律分為三品（三聚淨戒），依義理統攝各條制戒因緣，與小乘諸部律藏並無不同。如何說明這一點呢？例如不殺生這一條戒，就同時具備三種品位：止息一切殺生的因緣，這就是「攝律儀戒」；常行正慧以長養法身慧命，這就是「攝善法戒」；護持對方的生命，這就是「攝眾生戒」。這一條戒既然如此，其餘各戒也可以依此類推。當然也不是沒有一兩條遮戒，例如《菩薩地持經》等所規定的，關於收受珍寶璧玉等事相上的開許與制定，這些戒條才與凡夫和小乘有所不同。

【410-0009】03_業疏/11a_卷二之五#74

【410-0040】03_業疏/11a_卷二之五#105
【原文】一、偏袒右肩，示執作之務，明謙敬也。俗中短右袂，便於事是也。袒謂肉袒，如袒裼銜絏者。今此末俗著偏袖衣，謂名偏袒者，非也。西梵全無此衣，但有方服耳
【譯文】第一、偏袒右肩，是示現承擔執持作務之意，以顯明謙遜恭敬。在世俗中縮短右邊衣袖，以便於操作事務，就是這個意思。袒是指袒露肉體，如同世俗所說肉袒、脫去上衣拿著繮繩牽馬（袒裼銜絏）的儀制。如今末法世俗之人穿著單偏袖的衣服，稱之為「偏袒」，這是錯誤的。西方印度根本沒有這種偏袖衣服，只有方幅的袈裟法服罷了。

【410-0041】03_業疏/11a_卷二之五#106
【原文】乞法具儀釋偏袒中初顯意。示執作者，卑己敬他，如僕侍故。短右袂，出論語，彼云「褻裘長，短右袂」，謂私居之裘，當裾長而袂短。袒裼銜絏，出孟子。裼，音錫，衣也；絏，謂馬韁；言袒衣而執韁，亦僕從之儀也。「今下」斥非。以偏袒本是袒露，而非衣名，彼時偏袖輒號偏袒，今時兩袖亦名褊衫，又復訛矣。西梵祇支、覆肩，竝同袈裟之相，故云但有方服
【譯文】在乞度之法具足威儀解釋「偏袒」之中，首先顯發其用意。示現承擔執作，是謙卑自己而敬奉他人，如同僕人侍從的緣故。「短右袂」出自《論語》，彼書說「褻裘長，短右袂」，意思是日常私下穿著的皮裘，衣身長而右袖短。「袒裼銜絏」出自《孟子》。「裼」，音錫，指脫去外衣露出身體；「絏」，是指馬韁繩；這是說脫衣露身而手執馬韁，也是僕從之人的禮儀。自「今下」以下斥責錯誤之說。因為「偏袒」本來是指袒露肉體，而不是衣服的名稱；當時人將單偏袖的衣服動輒稱作偏袒，如今世人將兩袖的僧服也稱為「褊衫」，這又是錯訛的了。天竺印度的僧祇支、覆肩衣，都如同袈裟那樣是方幅之相，所以說只有方服。
