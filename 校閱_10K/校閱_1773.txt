# 校閱材料　第1773檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1773-0001】03_業疏/14b_卷三之三#115
【原文】制列遮相，諸律竝同。及論難體，《十誦》、《五分》但問「曾為比丘，如法持、捨不？」此邊相也，餘悉不問；及至僧中，亦爾。《四分》亦同。如律中制十三難已，若不問者，不名得戒，故諸結者引之集坐，在遮前問。《僧祇》有二，所言略者：「今僧中當問，汝有無當答。」僧中一一問之，大如《四分》及諸遮相，不可抄盡，須者觀之。乃至問「曾為比丘，四重、十三事」，一一隨問；若有犯者，重則令去，殘令後悔
【譯文】規定列出遮相，諸部律典大體相同。至於論及十三難的本體，《十誦律》、《五分律》只問「是否曾作過比丘，是否如法持戒、如法捨戒？」這屬於邊罪之相，其餘的難一概不問；到了僧眾之中也是如此。《四分律》也是一樣。如律中制定了十三難之後，若不詢問，就不算得戒，所以各位編撰集錄羯磨之人將難引錄並集於一處，放在問遮之前詢問。《僧祇律》則有廣略兩種，所謂略法是說：「如今在僧中將會詢問，你有或沒有應當據實回答。」到了僧中則一一詳細詢問，大致與《四分律》相同，以及諸多遮相，無法全部抄錄，需要的人可自行閱覽。乃至問「是否曾作過比丘，犯過四波羅夷、十三僧殘事」，一一隨即詢問；若有犯者，犯重罪的就令其離去，犯殘罪的令其受戒後懺悔。

【1773-0002】03_業疏/14b_卷三之三#116
【原文】次科，初、示遮同。「及」下，次、明難別。初、《十》、《五》二律屏處、僧中，止問邊相。次、《四分》亦同，謂差問、正問亦不列難。言諸結者，即集羯磨人，引難冠遮，依律具問。坐，猶著也。三、《僧祇》有二，謂廣、略也。廣則具問；略即如文，謂屏問時，但囑累而已。「下」指遮相，如《事鈔》備引。仍問篇聚，重是邊罪故令去，「殘」下非難故令悔，受已方悔，故云後悔也
【譯文】在次一科中，首先明示諸律問遮相同。「及」字以下，其次說明問難各異。第一、《十誦律》、《五分律》兩部律在屏處與僧中，都只問邊罪之相。第二、《四分律》也是如此，即差使問與僧中正問原本都不列出諸難。所說的「諸結者」，就是集錄羯磨之人，將諸難引出放在問遮之首，依照律文具體詢問。「坐」如同附著之意。第三、《僧祇律》有廣、略兩種，廣法則完全具足詢問；略法則如文中所說，指在屏處詢問時，只是囑咐交代而已。疏文下文是指各項遮相，如同《事鈔》中詳細引述的那樣。仍然要問及篇聚罪相，犯重罪屬於邊罪所以令其離去，「殘」字以下因為不是十三難所以令其懺悔，受戒之後才懺悔，所以說是「後悔」。

【原文】汝字何等？」依俗中法：子生三月，孩而名之；年至二十，冠而字之，隨義別立。僧中識者，立名異字，如《僧傳》中；自餘者多，名字通忍，愚謂名、字猶如眼、目，字義無別也。當隨機轉問，並改云「名」，得實錄也

【1773-0008】03_業疏/14b_卷三之三#122
【原文】上以是事，俱是戒緣，有闕一相，即非受法。十三難者，名義須分。諸遮之中，師資、名字及丈夫三，此定須有，缺非戒緣；衣鉢餘者，具須依文，至時增減，通人情也。如《僧祇》中遮多，《四分》猶有開略，況復《四分》定判遮不得戒處，並通消息也

【1773-0009】03_業疏/14b_卷三之三#123
【原文】三、結斷中，初通結八緣必須圓具。「十」下別點遮難，初明重難，「諸」下次簡輕遮。三種須具，餘通增減。「丈夫」即年滿。若準《鈔》文「名字、年歲、衣鉢」，今此衣鉢在增減中，必應問前累示已曾加法，略之無損；通人情者，臨事自裁也。「如」下引況，《僧祇》遮多，開略如上所示。《四分》列遮，並云「未受不應受，已受得戒」，故知除前三外，改轉廣略，一切皆通。
【譯文】在第三、結語判斷中，首先通結八緣必須圓滿具備。「十」字以下分別點出遮與難，先說明嚴重的十三難，「諸」字以下其次揀別輕遮。有三種必須具備，其餘則通融增減。「丈夫」就是指年齡已滿二十歲。如果依照《事鈔》的文句所列是「名字、年歲、衣鉢」，現在這裡把衣鉢歸在可增減之列，必定是在問遮之前已再三指示受持衣鉢並加法完畢，所以省略了也不妨礙；所謂「通人情者」，是指臨事時自行裁量裁決。「如」字以下引用情況作比況，《僧祇律》遮難繁多，但開許省略如上文所揭示。《四分律》列出遮難時，都說「未受戒者不應給受，若已受戒則得戒」，由此可知除前述三種之外，改換措辭、或廣或略，一切都可以變通。


【1773-0010】03_業疏/15a_卷三之四#1
【原文】初緣標指中，「廣如鈔」者，彼明三品發心并示緣境。發心則終依上品，緣境則徧該十界，如《資持》委釋。「有師出戒方便」者，未詳何人，《鈔》文亦云別抄有三十餘紙。「末代如來」者，以其知法，替補佛處故。「同十誦」者，彼云知布薩法者盡應供養，以無佛時，是人補處是也
【譯文】在第一項標示指明受戒之緣中，所謂「廣如鈔所說」，是指《事鈔》中闡明了三品發心並指示發心所緣的境界。發心則最終須依據上品心，所緣境界則普遍涵蓋十法界，如同《資持記》中所詳細解釋的。所謂「有位法師撰出受戒方便」，不知具體是哪一位法師，《事鈔》的文中也提到另外抄錄有三十多紙。所謂「末代如來」，是因為他通達戒法，替代並補處於佛位之故。所謂「與《十誦律》相同」，是指《十誦律》中說通達布薩之法的人都應當受到供養，因為在無佛之時，此人就是補處之位。

【1773-0011】03_業疏/15a_卷三之四#2
【原文】引《多論》證者，是正量也。凡愚智淺，何能生知？自非久學，卒誨猶暗。此之戒法，出家本務，素非懷大，定難容納，深有由矣
