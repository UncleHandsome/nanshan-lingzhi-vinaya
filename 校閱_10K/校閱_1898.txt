# 校閱材料　第1898檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1898-0001】03_業疏/22a_卷四之五#72
【原文】四、心境相應者，彼此言義迭相領會也
【譯文】第四、所謂「心境相應」，是指懺罪者與受懺者雙方的言說與義理，能夠彼此輾轉完全領悟體會。

【1898-0002】03_業疏/22a_卷四之五#73
【原文】五者，事成有三，謂教具足及訶責立誓故，自責心生厭離是也；三、領受無違，即答言「爾」也。
【譯文】第五、所謂懺罪法事究竟成就包含三點：第一是指教法儀軌具足；第二是由於受懺者的呵斥策責而使能懺者立誓悔過，內心深自苛責而生起厭離惡業之心；第三是受懺者印可領受而毫無違逆，也就是回答說「爾（是的、善哉）」之語。

【1898-0003】03_業疏/22a_卷四之五#74
【原文】五事成有三：教具足為一，謂作法無非；訶誓為二，謂前對誨勗也
【譯文】在第五項法事究竟包含三點中：教法具足為第一點，是指作法羯磨儀式毫無違失；呵責與立誓為第二點，是指所面對的尊長給予教誨與勉勵。

【1898-0004】03_業疏/22a_卷四之五#75
【原文】四、大小所明滅不相者
【譯文】第四、大乘與小乘所闡明的罪業滅與不滅的行相。

【1898-0005】03_業疏/22a_卷四之五#76
【原文】有人言：大乘懺者得滅業也。一者理深藥玅，二發悟悔過起治行勝，三多身修業非一形證故也
【譯文】有人說：大乘的懺悔法門能夠徹底滅除惡業。其原因有三點：第一是所依理體幽深而對治法藥神妙；第二是能發心開悟悔改過非，所發起對治的行持極為殊勝；第三是歷經多生多劫修行聖業，並非僅依一期身形證得道果的緣故。

【1898-0006】03_業疏/22a_卷四之五#77
【原文】四他解中，一謂法勝，二是行勝，三即報勝。雖有三勝，不分事理
【譯文】在第四門其他師家的解說中：第一種是說對治之法殊勝，第二種是說對治之行殊勝，第三種就是說果報殊勝。這雖然說了三種殊勝，但並沒有區分事懺與理懺的不同。

【1898-0007】03_業疏/22a_卷四之五#78
【原文】今解云：經雖說滅，不了義也。望後理觀，遠通說耳。但地前故業，分段所攝，用以招生。若據小乘增上忍中，相似無漏，惡道女業方得不受，故《成實》云「得世上見，雖來往生死乃至百千世，終不墮惡道」。若論別報，無學未免，故有貫腦之苦、碎身之痛、地獄燒身、飢餓切體，復何可論
【譯文】現在解釋道：經中雖然說到「滅」，但這是不了義的說法。這是對照後文的理觀，從長遠貫通的層面來說的。然而大乘地前的舊業，仍屬於分段生死所攝，還會用來招感來生。如果依據小乘的增上忍位，具有相似無漏智，惡道與受女身的業報才得以不再受生，所以《成實論》說「證得世第一法，雖然還在生死中來往乃至百千世，也終究不會墮落惡道」。如果談到別報，連無學果位（阿羅漢）都未能免除，因此有如鐵杖貫腦之苦、粉身碎骨之痛、墮入地獄燒身、飢餓切骨入體等報應，這又哪裡能說已經徹底消滅呢？

【1898-0008】03_業疏/22a_卷四之五#79
【原文】今解初科正明中，初決經文。如注所引《未曾有經》，或通諸經說滅之文，事但抑伏，理觀能滅。「但」下，又二：初明大乘地前三賢，尚有分段生死，則知不滅。「若」下，次示小乘忍位方免惡道，則知爾前業亦非滅。《成論》「世上見」即世第一，又過忍位，則知內凡已上，將隣聖位，無漏慧勝，方能滅業。惡道是總報，餘苦即別報。故下四句並果人償債之緣：初如《婆沙》中差摩比丘病重，諸比丘問之，自言「我病不差，猶如壯士繫縛其頭，兩手急絞，我之頭痛亦復如是」；次如《增一》目連乞食，為梵志所打，骨肉爛盡；三如《雜寶藏經》離越羅漢山中坐禪，為人誣盜牛，十二年在獄，自言過去誣他盜牛經一日夜，後墮三惡道受苦無量，餘殃不盡，故受此報；四如《百緣經》黎軍支過去餓母七日，後成羅漢，七日乞食不得，吞沙而死。委如《資持
【譯文】在「今解」初科「正明」之中，首先判決經文。如同注文所引用的《未曾有經》，或是貫通諸經中說「滅罪」的經文，事懺僅能抑止伏住，理觀才能真正消滅。自「但」字以下，又分為兩部分：首先說明大乘地前的三賢位，尚且具有分段生死，由此便知罪業並未消滅。自「若」字以下，其次明示小乘要到忍位才能免除惡道，由此便知在忍位之前業力也並未消滅。《成實論》所說的「世上見」即是「世第一法」，比忍位又更高一層，由此可知到了內凡位以上，將近臨聖位之時，無漏慧力強勝，才能消滅罪業。惡道是總報，其餘的苦楚即是別報。所以下文四句都是證果聖人償還宿債的因緣：第一句如《大毗婆沙論》中差摩比丘病重，諸比丘問候他，他自己說「我的病不見好轉，就像有大力壯士緊緊綁住他的頭，用雙手急速絞緊，我的頭痛也是如此」；第二句如《增一阿含經》中目犍連尊者去乞食，被外道梵志打擊，骨肉俱爛；第三句如《雜寶藏經》中離越羅漢在山中坐禪，被人誣陷偷牛，在牢獄中關了十二年，他自己說過去曾誣陷他人偷牛經過一日一夜，死後墮入三惡道受無量苦，餘殃未盡，所以今生受此別報；第四句如《百緣經》中黎軍支比丘過去曾令母親挨餓七天，後來證得羅漢果，仍七天乞食不得，最後吞沙而死。詳細內容如同《資持記》中所述。

【1898-0009】03_業疏/22a_卷四之五#80
【原文】一思至此，業之善惡俱不可作。古人有言：「慎莫作善。」斯有遠旨。如造世善，生極有頂，娑婆三界，更增苦諦，如燒金丸不可觸也
【譯文】一想到這裡，罪業與福業（無論善惡）都不應當去造作。古人曾說：「千萬謹慎不要去作善業。」這具有深遠的旨趣。例如造作世間的有漏善法，最高受生到非想非非想處的有頂天，在娑婆三界之中，反而更增添苦諦的束縛，如同燒紅的金丸一樣不可觸摸。

【1898-0010】03_業疏/22a_卷四之五#81
【原文】結誥中，初示業理可畏：一能引後習，二歷劫不亡，三牽生感報，不由於人。「古」下，引證。以作惡則墮三惡趣，作善則墮三善道，皆不出輪迴。善雖是福，能障聖道，甚於作惡。後生聞此，慎勿錯會。「如」下，顯意。有頂即非非想天，壽八萬大劫，是為難地。燒金丸者，即喻凡福反為害也
【譯文】在結語告誡中，首先顯示業理的令人敬畏：第一、能引發後續的習氣；第二、歷經多劫也不會消亡；第三、牽引受生感召果報，絲毫由不得人。自「古」字以下，引用古語作證明。因為作惡就會墮落三惡趣，作善就會生到三善道，都出不了輪迴。世間善業雖然是福報，但障礙聖道的力量比作惡還要嚴重。後學之人聽聞此言，千萬慎重切勿誤解。自「如」字以下，顯明其深意。有頂即是非想非非想天，壽命長達八萬大劫，屬於難以修道脫離的「八難」之一。比喻為「燒金丸」者，就是比喻凡夫的有漏福報反而會成為禍害。

【1898-0011】03_業疏/22a_卷四之五#82
【原文】又就律中懺重之相，雖非即數，有可收理，盡形行學，障地獄故，餘至文解
【譯文】再就律部中懺除重罪的相狀而言，雖然不能列入僧數（不得入於僧數），但有可以收攝容受的道理，命其終身奉行學悔法，以阻擋地獄之業的緣故，其餘細節留到後文再解釋。

【1898-0012】03_業疏/22a_卷四之五#83
【原文】次科小乘事懺中，「非即數」者，即猶入也；「有可收」者，來否隨意也；「盡形行」者，不復本淨也。此所謂小乘無懺重文也
【譯文】在下一科「小乘事懺」中，「非即數」的意思，「即」猶如「入」，指不能重入僧數；「有可收」的意思，是指此人來不來求懺悔隨其意願，僧團得為收攝；「盡形行」的意思，是指終身行持學悔法，不能回復原本的比丘清淨位。這就是所謂小乘律中沒有徹底滅除重罪文句的道理。

【原文】上略義述，須通融心。不爾，晨夕直在佛前，低頭妄懺，心多無記，更增慢習，不如不作。至時觀之，作何物在
【譯文】以上大略從義理進行闡述，必須具備圓融通達的心性。否則，早晚只是在佛像前低頭虛妄地懺悔，內心多處於無記昏沉的狀態，反而更加滋長傲慢的習氣，倒不如不做。到了臨終受報之時回頭看看，究竟造就了什麼呢？

【1898-0014】03_業疏/22a_卷四之五#85
【原文】結示中，初勸明心。「不」下，顯過患。「至」下，責愚暗。「至時觀」者，令自省也；「作何物」者，必墮惡趣也
【譯文】在結語示導中，首先勸勉要明了自心。自「不」字以下，顯發其過失與禍患。自「至」字以下，責備其愚癡昏暗。「至時觀」這句話，是令其自我反省；「作何物」這句話，指其必定會墮入惡趣。

【譯文】現在必須解釋律文，先說明緣起，後說明儀法。因為修懺悔法的人往往一併誦讀，多數人並不明白通曉，所以引用律文予以明示。
