以下按原文順序逐條核對，分「**須修正的實質問題**」「**增譯／推測過多**」「**用語可再斟酌**」三類，並附建議改法。

## 一、須修正的實質問題

**1.〈隨相〉篇名寫錯**
- 原文：「別請法如〈隨相〉中。」
- 譯文：「見於〈隨相顯過〉之中。」
- 問題：《行事鈔》並無「隨相顯過」篇。「隨相」是〈**隨戒釋相篇**〉的簡稱（「顯」字疑與〈標宗顯德篇〉混用）。
- 建議：「別請的相關作法，如〈隨戒釋相篇〉（隨相）中所說。」

**2.「今俗有執名邀請者」誤解為「別請名單」**
- 譯文：「如今世俗施主常有執持特定名單邀請某些僧人的情況。」
- 問題：此句以下整段都在談**書寫用字**（「必須筆註」→「赴」字之訛→應作「訃」字），與上文「別請」是兩個話題。這裡的「執名」應指世俗人**執持名帖（寫上僧名的請柬）來邀請**、或執意要形諸文字名字，不是「指定名單別請」。譯文把它接續別請義，導致後文「赴／訃」之辨變得突兀無著。
- 建議：「現今世俗之人，有執持名帖（書寫僧名）前來邀請的。」

**3.「借念時還，貸念時償」的「貸」方向反了**
- 譯文：「借人之物時常念著及時歸還，**貸人財貨**時常記著按期償清。」
- 問題：「貸人財貨」讀來像「借給別人」，但「按期償清」顯然是**自己向人借貸**才須償。兩句是互文，皆指借入。
- 建議：「向人借物，要念著按時歸還；向人貸財，要念著按時償還。」

**4.「唯不得與女人共輿」宜作「共同抬舉」**
- 譯文：「唯獨不得與女人同乘一輿。」
- 問題：上句是「為俗家設會張幔及諸供具」，屬**布置搬運**的语境；「輿」在此取「抬舉、扛抬」義（律中「共輿」多指男女共抬一物，因身體相觸生過），譯成「同乘轎」與上下文不合。
- 建議：「唯不得與女人共同抬舉（搬運）物品。」（若要保守，可加註「一說同乘」，但不宜只取乘轎義。）

**5.「四方僧物」不宜加「大德常住」**
- 譯文：「即等同於盜取四方**大德常住**僧物。」
- 問題：律學「四種僧物」中，「四方（十方）僧物」與「常住僧物」是不同範疇，混加「常住」會造成術語錯亂；「大德」更是無據的敬詞。
- 建議：「就等同盜取四方僧眾（十方僧）共有之物。」

**6.「僧次」的定義不準**
- 譯文：「僧次請（依僧團**名冊**次第**普請**）」。
- 問題：僧次請是**不揀擇、依僧中（戒臘）次第輪差受請**，未必是「名冊」制度，也不是「普請全體」。「普請」易與「別請一人」的對比失焦。
- 建議：「僧次請（不指定人選，依僧團次第依次差請）」；「別請（指名邀請特定比丘）」（「指名單請」四字亦拗口）。

**7.「食未嚫」的「大嚫（財施回向）」用詞含混**
- 譯文：「主人尚未施予**大嚫（財施回向）** 便擅自離席」。
- 問題：「嚫」即「嚫施／達嚫」，指食後施主行施、比丘為作咒願，並無「大嚫」此一定稱；「財施回向」把施主行施與比丘咒願混為一事。
- 建議：「齋食已畢、尚未行嚫施（施主行施、比丘咒願）便離去者，亦犯墮。」

**8.「吉羅」不宜釋為「輕垢罪」**
- 譯文：「犯突吉羅罪（**輕垢罪**）」。
- 問題：「輕垢」是《梵網》菩薩戒系統的說法；此處是聲聞律的突吉羅，應作「**惡作（惡說）**」。
- 建議：「犯突吉羅（惡作）罪。」

**9.「若問不問」不是「來不來得及」**
- 原文（第二段）：「必於中有命梵難者，若問不問，聽去。」
- 譯文：「無論**是否來得及**稟白上座，皆開許立刻離去避難。」
- 問題：原文是「不論有無稟問（上座），皆聽許離去」，重點在**不問亦無犯**，不是時間急迫與否。
- 建議：「不論是否曾稟白上座，都開許離去。」

## 二、增譯／推測過多（建議刪除或改為加注）

| 原文 | 譯文添加處 | 建議 |
|---|---|---|
| 此云次第 | 「意譯為**知次第者**」 | 直譯「意為『次第』」 |
| 從於階陛布衣 | 「鋪設**華麗**衣物」 | 原文只作「布衣」，刪「華麗」 |
| 為未來比丘故 | 「為了**防範警示**未來世比丘」 | 原意是**護念**將來的比丘（免得居士也如此鋪衣、比丘蹈過招譏損福），語氣不宜負面 |
| 後作一會 | 「後來**合併**為一次舉行」 | 原文僅「後作一會」，未言合併 |
| 恐僧失食 | 「落空**挨餓**而錯失飯食」 | 「挨餓」可刪 |
| 制者不少 | 「**嚴厲**制止……規定**極多**」 | 「不少」≠「極多」，宜作「制止別請的說法也不少」 |
| 如飲海水，即飲眾流 | 「飲得**一口**海水……飲**盡**百川……亦是如此**圓滿**」 | 比喻可簡潔：「如飲海水即飲眾流，依僧次請僧亦同此理」 |
| 於僧中請一似像極惡比丘 | 「**依次第**迎請」 | 「於僧中」不必補「依次第」；「無量果報」不必加成「無量無邊」 |
| 當持一日戒 | 「受持一日**八關齋**戒」 | 「一日戒」通常即指八戒，可保留但宜加「（即八關齋戒）」表示是注釋 |
| 沽酒家門 | 「賣酒人家的**正門**」 | 「正門」是由「更有餘門」推得，可作「（賣酒的）門面」並加注 |
| 必須筆註 | 「**知事僧**也必須在**簿冊**上落筆記錄」 | 原文未指執行者與載體，宜作「仍必須用筆註記（於名帖上註明）」 |
| 有人書為赴字 | 「在**冊籍**上寫作」 | 同上，刪「冊籍」 |
| 餘人私行 | 「其餘（**未受請的**）僧人」 | 「未受請」是猜測，宜只作「其餘人」或加「一說」 |
| 應往……處住 | 「**殿堂**中集合等候」 | 作「處所（食堂）」較穩 |
| 病比丘事者 | 「等**緊急**要務」 | 「緊急」可刪 |

## 三、用語可再斟酌

1. **「若共師並坐」的「師」**：譯「親教師」過窄，宜作「師長（和尚、阿闍梨）」。
2. **「應借僧臥具」**：譯「比丘所用的座褥臥具」→ 宜作「僧團所有的臥具（坐褥床席）」；借給白衣的方向是對的。
3. **「此未知字學耳」**：「字學」是文字之學（正訛、六書），譯「文字**訓詁**」偏於詁訓一門，宜作「不通文字之學」。
4. **「必有斯舉，可註為訃字」**：譯「若記此事」語意鬆散，宜「若一定要這樣書寫，就應註作『訃』字」。
5. **「甚補高望」**：「補」是增益，譯「維護」略弱，可作「大大有助於成就（僧人的）清高德望」。
6. **「主人意無在者，得」**：譯「便可前往」主語模糊（易讀成比丘自己去），宜「即可（派人代往）」。
7. **「作佛得物」**：譯「造佛像所得的錢物」語意含糊，宜「原為造佛像而施捨／募得的財物（挪作齋僧之用）」，較能顯出「不得挪用」的重點。
8. **「儼頭」**：譯「微點其首」可通，但此詞諸本或作「頷頭」，建議加註存異。
9. **「打楗椎本為集僧故」**：譯加「共食」二字可，然原文只作「集僧」，直譯更貼。
10. **「《善見律》」**：可註明即《善見律毘婆沙》，與《四分》等廣律有別。

## 四、關鍵兩句改譯示例

> **原文**：既僧次福大……別請法如〈隨相〉中。今俗有執名邀請者。然口雖許往，必須筆註；有人書為「赴」字者，此未知字學耳！必有斯舉，可註為「訃」字。
>
> **建議譯**：既然依僧次請僧福德廣大，若有施主前來託請僧眾，知事者應為他宣說僧次請的功德作用，開導俗人之心，不使他指名別請。別請的作法，如〈隨戒釋相篇〉中所說。現今世俗有執持名帖（書寫僧名）前來邀請的；雖然口頭已答應前往，仍必須以筆註記。有人寫作「赴」字，這是不通文字之學！若一定要這樣寫，應當註作「訃」字。

> **原文**：故諺云：借念時還，貸念時償。事雖鄙陋，廉恥之本。
>
> **建議譯**：所以俗諺說：「向人借物，念著按時歸還；向人貸財，念著按時償清。」事情雖瑣細鄙俗，卻是廉恥的根本。

---

**總結**：第二段（往訃法）大體忠實，主要只有「若問不問」一處釋義偏差與「殿堂／緊急」等輕微增譯；第一段問題較集中，其中**篇名誤植、「執名邀請」誤解、「貸」字方向、「共輿」、「四方僧物」** 五處屬必改，其餘多為增譯與術語精度問題。
