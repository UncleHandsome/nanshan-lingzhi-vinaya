# 校閱材料　第1304檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1304-0001】資持記/14b_下二#5
【原文】若下，次開佐助，同前《十誦》。坂〔音反〕，岥也。《十誦》。負謂抱負。自觸吉者，示制過也。有過藥，即曾犯觸宿者，病故開之。〔或云五辛者，非。〕《鼻奈耶》。下，注決所開，義非自畜。自煮中。初科開者，非自食故。注中，引前沙彌擔食例決。次科，初煮飯法。
【譯文】「若」字以下，接著開許可以從旁協助，這與前面的《十誦律》相同。「坂（音反）」，就是山坡、斜坡的意思。《十誦律》中，「負」是指抱在懷中或揹負。自己觸碰而結吉羅罪，是為了顯示這是佛所制止的過失。「有過藥」，就是指曾經犯了污觸或內宿的藥物，因為生病的緣故而開許服用。（有人說是五辛之類，這是不對的。）《鼻奈耶律》以下，註文判定所開許的範圍，其道理並不是允許自己蓄存。在「自煮」這一段中，第一科之所以開許，是因為並非為了自己食用。註文中引用前面沙彌擔運食物的例子來作決斷。第二科中，首先說明煮飯的方法。

【1304-0002】資持記/14b_下二#6
【原文】得洗器等，由體淨故。使淨人煮，非變生故。須橫木者，表身受故。受已自煮，同溫食故。與病人者，通餘人故；亦得自食，由無過故。次明煮菜。三制薑湯。四開溫食。五開指教。抒，謂以箸攪動。內宿中。二律不犯，皆非意故。本律復開不知不犯，如通塞引。內煮中。開為他者，即是淨人。
【譯文】可以清洗器具等物，是因為物品本身原本清淨。指使淨人烹煮，是因為比丘自己並沒有將生食煮成熟食。必須使用橫木，是為了表示身體有親自承受。接受之後自己去煮，就等同於溫熱食物一樣。拿給病人食用，可以通於其他病人；自己也可以吃，因為並沒有犯過的緣故。接著說明煮菜。第三說明禁止自煮薑湯（制止薑湯）。第四開許溫熱食物。第五開許給予指導與指點。「抒」，是指用筷子攪拌翻動。在「內宿」這一段中，兩部律都判定不犯，全都是因為並非出於本意的緣故。本律又開許在不知情的情況下不犯，就如同通塞門中所引用的內容。在「內煮」這一段中，開許為他人烹煮，那他人就是指淨人。

【1304-0003】資持記/14b_下二#7
【原文】有餘開食，事同自煮。通塞二門，並約有罪為通，無罪名塞。初門。時藥唯通，文舉宿煮，具足四過；餘三藥並望限中名局，過限名通。又非時七日，限中唯開惡觸；盡形方開三罪，則通塞可見矣。七日指後，即生罪中。盡形中，初示所開。僧下，決前相違。薑是盡形，不開自煮故。
【譯文】有剩餘而開許食用，事情的性質就如同自己烹煮一樣。「通」與「塞」這兩門，都是以有罪的情況稱為「通」，無罪的情況稱為「塞」。在第一門中，時藥只有通門，經文中列舉了內宿和內煮，具備了四種過失；其餘三種藥在限定的時間內都屬於局部限制（塞），超過時限就屬於通門（通）。另外，非時藥與七日藥在限期之內只開許防止惡觸；到了盡形壽藥才全面開許三種罪過，這樣通與塞的差別就很明顯了。七日藥指稱在後面，就是在產生罪相的那一段中。在「盡形」這一段中，首先指示所開許的內容。「僧」字以下，用來決斷前面互相違背的說法。生薑屬於盡形壽藥，並不開許自己烹煮。

【1304-0004】資持記/14b_下二#8
【原文】注文，破古。疏云：古師云：七日加法，開內宿煮，此無文也。〔非時亦然。〕獨盡形藥，律開三罪，故云唯也。觸通三藥，故所不云。下引二律，斥古所執。《十誦》開飲，恐彼妾引，故注決之。《四分》即殘宿食戒，開文唯許外用。然彼但云宿受蘇油，義亦通收加法之者。餘下，次通簡藥體。
【譯文】註文是用來反駁古代律師的觀點。註疏說：古時的律師認為，七日藥經過作法加持後，可以開許內宿與內煮，這在律文中是找不到依據的。（非時藥也是如此。）唯獨盡形壽藥，律中開許了三種罪過，所以才說「唯」。惡觸這條過失通於三種藥，所以這裡沒有特別說明。下面引用了兩部律，用來斥責古代律師所執持的見解。《十誦律》開許飲用，恐懼有人會錯誤引用，所以註文特別加以決斷。《四分律》也就是殘宿食戒，開許的經文只允許在體外塗抹使用。然而那裡只說隔夜受持的酥油，在道理上也通攝了經過作法加持的藥物。「餘」字以下，接著通論簡別藥物的本體。

【1304-0005】資持記/14b_下二#9
【原文】下指《十誦》，如後受法中第二科引；彼明非時等三藥，故云餘也。次門明過中，《十誦》為二，初示犯人。比丘即別人，僧即眾僧。尼加式又，二眾共七人。注中，以式叉過食，非常開故。次明四過。內宿中，但云僧坊，致有計云淨地中共宿無過；而文不了，故注點之。內熟自熟，熟即煮也。
【譯文】下面指引《十誦律》的內容，就像後面「受法」中的第二科所引用的那樣；那裡說明了非時等三種藥，所以才說是「其餘」。第二門「明過」這一段中，《十誦律》分為兩部分，首先指出犯戒的人。「比丘」是指個別的人，「僧」是指大眾僧團。「比丘尼」再加上式叉摩那，這兩眾總共有七種人。註文中認為式叉尼授食給大尼，並非常規的開許。接著說明四種過失。在「內宿」中，只說是僧房，導致有人認為在淨地中一同住宿沒有過失；但經文說得不夠明白，所以註文特別予以點明。「內熟」與「自熟」，熟就是烹煮的意思。

【1304-0006】資持記/14b_下二#10
【原文】惡捉多種，且據一相。注中顯示，必須決捨，再受無過。《多論》三種：初受，二捉，三不受不捉。文中共宿經夜吉者，即內宿罪。初不共宿亦吉者，疏云：以心貯畜故犯。《四分》無文，義豈通許。對顯中，內宿，對處。三處有犯。人中三人，唯據大僧；知有犯者，不知不犯。下引文示，可見。
【譯文】「惡捉」有很多種類型，這裡暫且根據其中一種相貌來說明。註文顯示，必須堅決捨棄，重新受持才沒有過失。《多論》列出三種情況：第一是已受持，第二是抓捉，第三是未受持也未抓捉。經文中所說的共同住宿經過一夜結吉羅罪，這就是內宿的罪過。第一種情況不共同住宿也結吉羅罪，註疏解釋說：這是因為存心儲蓄積存所以犯戒。《四分律》沒有明文記載，在義理上哪裡能夠隨便准許。在「對顯」這一段中，內宿是針對處所而言。在三種處所中會犯戒。「人」門的三種人中，唯獨以大僧（具足戒者）為準；知情的會犯戒，不知情的不犯。下面引用經文來顯示，這一點顯而易見。

【1304-0007】資持記/14b_下二#11
【原文】狗持風吹，皆謂食在大界。律字誤，合作佛言。食中有三，初明離地不論長足。二未離地須簡長足。如果菜等，生分未絕，皆無內宿。三簡四藥。唯除盡形是塞，三藥皆犯為通。內煮中。對處唯大界中犯，故淨地並塞；人通七眾，此據能造；若論食犯，唯局三人。
【譯文】狗咬叼或者風吹，都是指食物原本在僧團大界之內。律文中的「律」字是錯誤的，應該改為「佛言」。食物方面有三種情況：第一，說明脫離土地的，不論其是否已經長成完足。第二，未脫離土地的，必須區分是否長成完足。如果是果實蔬菜之類，生長之氣還沒有斷絕，都不算內宿。第三，簡別四種藥物。唯獨除去盡形壽藥屬於塞門，其餘三種藥犯戒都屬於通門。在「內煮」這一段中，針對處所來說，只有在大界之內才會犯戒，所以淨地都屬於塞門；人物方面通於七眾，這是就動手製作的人而言；如果就食用犯戒來說，則只局限於三人。

【1304-0008】資持記/14b_下二#12
【原文】四藥唯開盡形，自煮亦爾。自煮中。約食，變生成犯。《五百問》被淨言通，應是火淨生物。惡觸，就人中，初科又二，前明自觸具五。決意不食，即失受法；若欲再噉，理須重受。若下，次明他觸唯一。次科。初句注云故食亦爾，謂一心度與淨人；雖經兩捉，亦不成觸，如前所明。
【譯文】四種藥物唯獨開許盡形壽藥，自己烹煮也是同樣的道理。在「自煮」這一段中，就食物來說，把生食煮成熟食就構成犯戒。《五百問》中「被淨」一詞涵蓋較寬泛，應當是指經過火淨的生鮮物。在「惡觸」就人論處的段落中，第一科又分為二，前半部分說明自己觸碰具備五種條件。只要打定主意不再吃，就失去了受持的法則；如果還想再吃，在道理上必須重新受持。「若」字以下，接著說明他人觸碰只有一種情況。第二科中，第一句的註文說本來的食物也是如此，這是指一心想要交給淨人；雖然經過兩次抓拿，也不構成污觸，就如同前面所說明的那樣。
