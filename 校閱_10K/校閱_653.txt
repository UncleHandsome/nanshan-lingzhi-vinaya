# 校閱材料　第653檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【653-0001】02_戒疏/13b_卷三下之一#75
【原文】【疏】一、解開緣。如文「得痟病人間遊」。《多論》云：「所以爾者？四意：一、有緣眾生應受化故；二、宜遊病損故；三、求行道處故；四、降伏信悟故。」、「是舍利弗病故，何者？亦四義：一、先世惱人故；二、智深思法故；三、勤業不臥故；四、此後邊身先業已盡。」、「若以神力轉三千界，大悲心中請聖制故。」
【譯文】【疏文】第一、解釋開許的緣由。如同注文所載「患了消渴症在人間遊化」。《薩婆多論》說：「之所以要遊化，有四種深意：第一、有緣的眾生應當接受化度；第二、適度遊行有助於病體康復；第三、為了尋求安心修道的處所；第四、為了降伏外道並令其信受開悟。」又說：「這是在舍利弗生病時所制，原因為何？同樣有四種意義：第一、過去世曾有惱害他人的業報；第二、智慧深廣經常思惟妙法；第三、精勤修業從不隨意躺臥；第四、這是最後的輪迴之身，往昔惡業在此完全消盡。」「舍利弗若以神通之力足以迴轉三千大千世界，是在大悲心中為了利益後人而請佛陀制定此開緣。」

【653-0002】02_戒疏/13b_卷三下之一#76
【原文】【疏】二、法成不相者。要須人病衣重者成，餘人病互有，一向不成。所言「老」者，《多論》「七十已上，名為老者」。有前四益，乃至三寶求覓，亦得。
【譯文】【疏文】第二、辨別羯磨能否成立的相狀。必須同時具備「人患重病」且「衣物沉重」這兩個條件，羯磨才能成立；其餘情況若僅有人病或僅有衣重，一概不能成立。至於所說的「年老」，《薩婆多論》認為「七十歲以上，才稱為老人」。老人若具備前面的四種利益，乃至為了三寶事務外出尋求物資，也可以開許作法離衣。

【653-0003】02_戒疏/13b_卷三下之一#77
【原文】【疏】三、離多少相。此中唯是大衣。《五分》云：「留一並離，非羯磨故，皆犯離罪。得留中衣，上下不得留。有賊難處，隨留好者。」《十誦》、《多論》，留一義同。
【譯文】【疏文】第三、開許分離衣物數量的相狀。在此處僅限於僧伽梨大衣。《五分律》說：「准許留下一件衣；若三衣一併脫離，因非羯磨所開許之故，皆犯離衣罪。律中准許羯磨留下中衣，大衣與下衣則不得留下。若在有盜賊危難的地方，則任憑留下一件較好的衣物。」《十誦律》與《薩婆多論》關於留置一件衣物的義理也是相同的。

【653-0004】02_戒疏/13b_卷三下之一#78
【原文】【疏】四、約日多少。《十誦》夏分不開，《五分》聽前安居九月，後安居八月。《見論》云：「隨病未差，若差即還，遇難不失。不作還意，失衣。」《多》云：「若得羯磨已，病重不行，後行，即先羯磨。若化未盡，衣藥營求，三寶未辨，而月已盡，以事難故，緣訖無罪。若死，此衣得與看病人。」
【譯文】【疏文】第四、依據離衣日數的多寡。《十誦律》規定夏安居期間不開許離衣，《五分律》則准許前安居者可離衣九個月，後安居者可離衣八個月。《善見論》說：「隨順病患只要未痊癒即可離衣，若病好了就應當立即返回，中途遭遇險難則不失去衣物。若心中沒有返回的意思，即算失去衣物。」《薩婆多論》說：「如果已經通過羯磨開許離衣，但病情加重未能成行，日後再度成行時，仍可沿用先前的羯磨。如果教化眾生的任務尚未結束，或者為僧團營求衣物藥品、三寶設施尚未辦妥，而開許的月份已經屆滿，由於事務艱難的緣故，因緣結束之前並不算犯戒。如果比丘不幸身亡，這件留置的衣物可以贈送給照料病患的人。」

【653-0005】02_戒疏/13b_卷三下之一#79
【原文】【疏】五、得重加不？《多論》云：「本衣若施三寶，更求得衣，不問輕重，應加羯磨，乃至九月亦如是。」
【譯文】【疏文】第五、是否可以重新加作羯磨？《薩婆多論》說：「原本的大衣如果布施給了三寶，另外尋求得到新衣，無論質地輕或重，都應當重新為其作羯磨法開許，乃至長達九個月的時間也是如此。」

【653-0006】02_戒疏/13b_卷三下之一#80
【原文】【記】第六，釋注五意，初意又二。初牒文。次引釋。初釋遊行。初四利他。初即可化，四是難化，故須降伏令生信悟；二、三皆自利。「病損」，即減損也。「是」下，次釋得病。緣因身子，故須顯意。初後約往業，中二據現修。彼論問曰：「舍利弗神通如意，能以三千世界手中迴轉，何以言僧伽黎重耶？」、「大悲」下，即彼答辭，為未來老病而作發起，故云「大悲」。
【譯文】【記文】第六點在解釋注文的五種深意中，第一種深意又分為兩部分。首先引述注文，接著引證解釋。先解釋遊化出行，第一點與第四點屬於利他：第一點是容易受化的人，第四點是難以化度的人，所以必須降伏並令其生起信悟；第二與第三點都是自利。「病損」，就是病情減輕的意思。從「這是在」以下，接著解釋生病的原因。因為因緣起源於舍利弗，所以必須顯明其深意。第一與第四點是依據過去世的業力，中間兩點是依據現世的修持。該論提問道：「舍利弗神通自在，能將三千大千世界在手中迴旋運轉，為什麼還會說大衣沉重呢？」從「大悲心中」以下，就是該論的回答之辭，說明他是為了未來後世年老患病的人作為發起因緣，所以稱為「大悲」。

【653-0007】02_戒疏/13b_卷三下之一#81
【原文】【記】二中，初示成不。「人病衣重」，二緣具者，方堪與法。「所」下，釋老相。《論》中正作「七十」，有本作「三十」者，誤也。「四益」同前遊行。「乃」下，示別緣。此開營事，不必老病也。
【譯文】【記文】第二點中，首先指出羯磨成立與否。「人病衣重」這兩個因緣具備，才能為其作法開許。從「至於」以下，解釋老人的相狀。論典中正文作「七十歲」，有的版本作「三十歲」，那是傳抄錯誤。「四種利益」與前面遊化相同。從「乃至」以下，指示特別的因緣。這是開許為了營辦僧事，不一定非得年老生病不可。

【653-0009】02_戒疏/13b_卷三下之一#83
【原文】【記】答：「老、病兩緣，自不相涉。」
【譯文】【記文】回答：「年老與生病這兩種因緣，本來就互不相干。」

【653-0010】02_戒疏/13b_卷三下之一#84
【原文】【記】有云：「病而不老，此猶可開；老而不病，義必不許。」今意不然，老據力衰，不必在病。
【譯文】【記文】有人說：「病而不老，這還可以開許；老而不病，按義理絕不允許。」現在看來並非如此，年老是依據體力衰弱來認定，不一定非得患病不可。

【653-0011】02_戒疏/13b_卷三下之一#85
【原文】【記】三中。「此中大衣」，即是本律，如注緣起。《五分》，初示數。「並離皆犯」者，彼云「盡離三衣」。「非羯磨」者，以非所開而妄加法，即是「事非」，法不成故。「得」下，定體。「上」即大衣，為入聚生善；「下」即五條，謂不許單著。故二「不得留」。「有」下，明難則無所拘，下指二文，同故不引。
【譯文】【記文】第三點中。「在此處僅限於僧伽梨大衣」，就是本宗的《四分律》，正如注文中的緣起所示。《五分律》首先指出數量。「一併脫離皆犯離罪」，是指該律說「完全離開三衣」。「不合乎羯磨規定」，是因為對於本非開許的範圍妄加作法，屬於「事相違背」，羯磨法不能成立的緣故。從「准許」以下，確定所留衣物的性質。「上衣」就是大衣，是為了進入村聚使人生起善心而穿；「下衣」就是五條衣，律中不許單穿下衣。所以這兩種「不得留置不帶」。從「若在」以下，說明遇到險難時則不受拘束，下文指出另外兩部律文，內容相同所以不再引述。
