整體讀來通順、大方向忠實，但有幾處**義理／判罪要件**與**科判文讀法**的問題必須改，另有一批增譯與用語可以再收斂。以下按轻重分列。

---

## 一、必須修正（會影響意思或成罪判斷）

**1. #1213-0001「甚至與其同宿」──把成罪要件寫成附帶情節**
原文「而誘將畜養，**共止宿者**，波逸提」，「共止宿」正是本戒結罪之處（#2 疏文六句把「四、誘將畜養」「五、共宿」分列，可證）。譯作「甚至」，語氣變成可有可無的加重情節，讀者會誤以為單憑誘引畜養即犯波逸提。
建議：「卻仍誘引帶領、收留供給，**並與他共同止宿**，即犯波逸提。」

**2. #1213-0001「非障道法」譯法有歧義**
「如果行淫欲，並不是障礙修道的方法」——中文自然會讀成「不是『障礙修道的方法』」，語意扭曲。
建議：「行淫欲**並不會障礙修道**」；下文對應作「淫欲**是會障礙修道**之法」。

**3. #1213-0001「不得隨逐餘比丘」過度字面化**
「跟隨在其他比丘身後」只譯出物理動作。律意指滅擯後不得再依附、追隨比丘為伴（不得受其依止、供給）。
建議：「不得再追隨、依附其他比丘（不得與比丘為伴依止）」。

**4. #1213-0004「戒本，釋第三中」主客顛倒**
這是科判標語，意為「（此段）解釋**戒本第三句**之中」，不是「戒本正文在解釋第三句」。戒本是被解釋的對象。
建議：「〔科判：〕解釋戒本第三句的部分。」

**5. #1213-0003 引文擅增字＋「擯出法」誤譯**
- 疏作「**彼比丘語**」下，譯文引號內寫成「彼比丘**應**語」。引號內應照疏文原字（律文作「彼比丘應語此沙彌言」，可另注）。
- 「明擯出法」＝說明**擯出的作法（程序軌則）**，譯成「法定宣白」不妥；且《記》明說戒文「但出呵黜之詞」，白四羯磨文並不在戒文中，譯作「法定宣白」正好與下段《記》相衝。

**6. #1213-0009「故違聖教」──「故」是故意，不是公然**
「故違」為律疏常語，指明知而故意違背。譯「公然違抗」改動了犯罪心態的描述。
建議：「**故意**違背聖教」。

**7. #1213-0009「為存俗習」因果關係漏譯**
原文是解釋下根為何勸亦難從：「**因為**仍存留世俗習氣」。譯文「始終執著世俗習氣」既丟了「為（因為）」，又擅加「始終」。

**8. #1213-0002「沙彌諫舉事」譯語不成話**
「沙彌被勸諫舉處的事由」——「勸諫舉處」非中文。「諫舉」＝勸諫（不從）而擯舉。
建議：「沙彌受諫不從、乃至被擯舉的事緣」。另「六、結罪」譯「裁定罪名」偏司法量刑語感，宜作「結成罪相（波逸提）」；「一、隨擯比丘」宜點明即戒文「若比丘」句，並作「隨順**被擯沙彌**的比丘」，六句與戒文的對應才清楚。

**9. #1213-0004「闕後一隻」的「對／隻」關係被抹掉**
「但有三對，闕後一隻」是說：依前戒諫法的配對次第，此處只三對，尚缺後面對句中的一句。譯「缺少了最後一句」籠統。另「準上次第」宜作「**比照前面（違諫）戒的次第**」，非泛指「先前的順序」。

## 二、宜潤飾（增譯、術語未白話化、語病）

| 出處 | 原譯 | 問題／建議 |
|---|---|---|
| #1 | 「世尊曾以無數的方便」 | 「方便」未白話化，宜「以無數種善巧方式（因緣譬喻）」 |
| #1 | 「他若堅持邪見不肯捨棄」 | 「他」承上易誤讀為比丘，宜明寫「該沙彌」 |
| #1 | 「應至再三諫」→「再三前去勸諫」 | 「至再三」＝乃至三次，非泛指多次；「前去」為增字。下句「乃至三諫而捨」宜作「三次勸諫之中（任一次）能捨」 |
| #1 | 「滅去」→「徹底離開」 | 可補「（除名）離去」以存滅擯之意 |
| #4 | 「前後文句中大多寫作『殯』」 | 「多作」＝多處寫作，「大多」語意過強 |
| #4 | 「相關條文在《事鈔》中有徵引」 | 「文」指滅擯白四的羯磨文，宜「其羯磨文如《行事鈔》所引」；「滅擯」可加短注 |
| #5 | 「不須再作繁雜的引述」 | 「不勞廣」＝不必費心廣解，非「引述」 |
| #6 | 「也是因為此類事相極為罕見」 | 漏譯「**同上**」（同前戒之稀有）；「極為」為增字 |
| #9 | 「善知識是……最關鍵因緣」 | 「梵行正緣」＝成就梵行的正要助緣，「最關鍵」是加譯 |
| #9 | 「唯有中等根器……最需要」 | 原文「中品之徒，事須友接」無「唯有／最」 |
| #9 | 「趣向菩提聖道」 | 「菩提」為增譯，聲聞律作「趣向聖道」即可 |
| #9 | 「任之鄙吝」→「墮入下劣慳吝」 | 「鄙吝」古語多指鄙陋庸劣、心志狹劣，非專指財物慳吝，建議「鄙陋庸劣」 |
| #9 | 「內心缺乏自我求進取的意願」 | 「自我求進取」不成詞，改「自我上進之心」；「無」譯「缺乏」稍弱 |
| #9 | 「外在毫無順從善道的心志」 | 「從善」指聽從善友勸導，宜「毫無聽從勸善的志向」 |
| #9 | 「如今有頑迷之人懷抱痴心」 | 「頑迷之人」為增譯，可簡作「如今（此人）痴心懈怠」 |

## 三、一點提醒（不一定錯，但建議加注）

**#3「僧屏諫法」**：譯「僧中與屏處勸諫」是通解，但本戒實際只有**一比丘屏處私諫**，僧中作法（滅擯白四）在下一段「擯出」。《記》說「但有三對，闕後一隻」，正是套用前面違諫戒「僧屏諫」的科判通名而缺句。白話若不加一句說明，讀者容易誤以為本戒也有僧中諫法的完整六句。

## 四、處理得當、可保留者

- 「二三宿」譯「二至三夜」、「汝出去，滅去」的語氣、「字合從手」辨「擯／殯」的字形說明，都準確。
- 「滅𢷤」還原為「滅擯」、《鈔》補為《事鈔》，符合體例。
- #7、#8 戒題翻譯無問題；#9「上達／下流／中品」譯為三根之說、「堪為物軌」譯「足以作為大眾儀範」，皆貼切。

**最優先要改的三處**：#1 的「甚至」（成罪要件）、#4 的「戒本在解釋第三句」（主客顛倒）、#9 的「公然違抗」（故意→公然）。其餘多屬潤飾層級。
