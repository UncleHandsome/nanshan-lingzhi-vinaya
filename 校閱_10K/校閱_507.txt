# 校閱材料　第507檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【507-0001】02_戒疏/08a_卷二下之一#80
【原文】【記】制意中。初示句。「欲」下，正敘。初敘境勝合敬。四果、四向為「八輩」。「俯」，猶下也。「反」下，次明損害制罪。自不加敬，是失自利；斷他勝田，即失他利。「餘」下，簡去餘聖。上四句正簡。下二句釋疑。上云「同凡」，且據制罪，凡聖位別，業必重輕。
【譯文】【記文】在制戒用意中。首先標示出句義。「此處旨在」以下，正式鋪陳敘述。起初敘述對象極為尊貴而理當恭敬。四果與四向合稱為「八輩」。「俯」是屈尊放下的意思。「如今反而」以下，接著說明摧殘損毀而制定罪責。自身不知加崇敬重，是喪失了自利；毀壞了眾生的殊勝福田，就是摧毀了他利。「其餘」以下，剔除其餘七種聖者階位。上面四句是正式剔除。下兩句是解釋可能的疑慮。上面說「等同凡夫」，純粹是就戒律所制定的罪名而言；凡夫與聖人的果位本質有別，業報必然有輕重的巨大差異。

【507-0002】02_戒疏/08a_卷二下之一#81
【原文】【疏】問：「如《十輪經》，殺辟支佛，不同羅漢者？」
【譯文】【疏文】提問：「正如《大乘大集地藏十輪經》所說，殺害辟支佛，罪過並不等同於殺阿羅漢，這該如何解釋？」

【507-0003】02_戒疏/08a_卷二下之一#82
【原文】【疏】答：「以聲聞人，因聲入道，一、能說法，二、能現通，三、令他得道。益深利廣，故結夷逆。辟支不爾，故殺同人。如《涅槃》云：『緣覺之人，志樂獨處。若化眾生，但現神通，終日默然，無所宣說，不能說法，令人得果。』以此文證，福田狹故。」
【譯文】【疏文】回答：「這是因為聲聞乘聖者是依循佛陀音聲言教而悟入聖道，具備三大能力：第一、能宣說妙法；第二、能展現神通；第三、能令他人隨之證悟得道。給予眾生的恩惠極其深厚、利益無比廣大，所以殺害聲聞羅漢結波羅夷重罪與逆罪。辟支佛則不具備這些，所以殺害辟支佛的制戒罪名等同於殺凡人，同結波羅夷重罪，而不另結逆罪。正如《涅槃經》所說：『緣覺聖人，志向喜好獨自隱居。如果要化導眾生，只會示現神通，整日保持緘默，沒有任何言辭宣說，無法講經說法讓人證得果位。』以此經文為證明，是因為他所提供的福田利益較為狹窄的緣故。」

【507-0004】02_戒疏/08a_卷二下之一#83
【原文】【記】初問中。彼明「殺支佛」不障戒，今以斷證是同，福田亦等，故須問決。答中。先明聲聞具三能故重，下明支佛不具故輕。後引大經，證闕二能。然「支佛」有二：一者，出無佛世，則名「獨覺」；二者，觀十二因緣得道，則名「緣覺」。如上所釋，且據大途，不妨緣覺善能化物，自有聲聞不堪說法。
【譯文】【記文】第一個提問中。那部經表明「殺辟支佛」不會構成障礙受戒的逆罪，如今考量兩者在斷除煩惱與證悟聖果上是一樣的，所成就的福田也相等，所以必須提問以求裁決。回答中，先說明聲聞聖者具備三種殊勝能力所以罪責極重，接著說明辟支佛不具備這些能力所以罪名較輕。最後引用大乘《涅槃經》，證明他缺乏講法與令人得果這兩種能力。然而「辟支佛」有兩種：第一種是生於無佛之世自悟，稱為「獨覺」；第二種是觀察十二因緣而悟道，稱為「緣覺」。如上文所解釋的，只是依據普遍概況而言，並不妨礙某些緣覺聖者善於化導眾生，也有些聲聞聖者天生無法講經說法。

【507-0009】02_戒疏/08a_卷二下之一#88
【原文】【疏】答：「殺望福田，故逆不逆異。犯尼，事通凡聖，壞淨境故。」
【譯文】【疏文】回答：「殺害罪是針對福田的圓滿程度來論斷，所以才有一者構成逆罪、一者不構成的分別。而侵犯比丘尼這件事，普遍牽涉到凡夫與聖者，重點在於摧毀了行者清淨梵行的境緣。」

【507-0010】02_戒疏/08a_卷二下之一#89
【原文】【記】轉難中。汙尼障戒，事實不同，欲辨殺、汙兩別，故立此難。但殺損福田，故不通下位；汙取境淨，而不局聖人。
【譯文】【記文】轉進追問的文句中。玷污比丘尼構成障礙受戒，與殺生在事理上有所不同；提問者為了辨明殺害與玷污兩者的差異，所以設立了這個詰難。殺生只會損及福田的大小，所以逆罪不通於三果以下的聖者；玷污則是著眼於摧毀了清淨的梵行境緣，因而並不局限於聖人（凡夫比丘尼亦同）。

【507-0011】02_戒疏/08a_卷二下之一#90
【原文】【疏】問：「若殺辟支不入逆者，何故《涅槃》知殺有三：蟻子、畜生為下，凡夫、三果為中，羅漢、辟支、菩薩為上？」
【譯文】【疏文】提問：「如果殺害辟支佛不算列入逆罪，為什麼《涅槃經》將了知殺業劃分為三個等級：殺蟻子與畜生屬於下品，殺凡夫與前三果聖者屬於中品，殺阿羅漢、辟支佛與菩薩則列為上品？」

【507-0012】02_戒疏/08a_卷二下之一#91
【原文】【疏】答：「彼以約境分心，故分三位，不明逆夷輕重等相。若不爾者，即彼文云『闡提不墮三種殺』中，可無罪耶？約律中，從境，闡提人夷；約經論，闡提無性也。」
【譯文】【疏文】回答：「那部經是依照所面對境緣的尊卑來衡量內心殺意的大小，所以劃分出三個等級，並不是在說明律法中逆罪與波羅夷罪的輕重相狀。如果不這樣理解的話，同一段經文接著說『一闡提不墮入這三種殺業中』，難道殺一闡提就毫無罪過了嗎？若依照律典，是依循眾生形體境緣來判定，殺一闡提依然構成殺人的波羅夷重罪；若依照經論，則是就一闡提沒有佛性而言（故經說不入三種殺）。」

【507-0013】02_戒疏/08a_卷二下之一#92
【原文】【記】三難中。即據《涅槃》，轉難初答。《經》明佛及菩薩，皆了知殺法，故云「知殺」。「羅漢」上，準《經》有「父母」二字，今此正問辟支，故略之耳。《經》文既以三乘同為上品，則知緣覺罪無差降。答中。初出《經》意。《經》分心業，不揀夷逆。準此，若殺辟支，雖非逆重，由境尊勝，業異常流。「若不」下，就經反質。初引示《經》文。梵云「一闡提」，此云「信不具」。「不墮三殺」者，由殺無罪，不入三品，故《經》云「譬如刈草、掘地等，無有罪報」。「約」下，比對律制。言「無性」者，準《經》，前明闡提無佛性。據後決前，此名「隨他語」。一切有性，名「隨自語」。
【譯文】【記文】第三個詰難中。是直接根據《涅槃經》的說法，轉過來駁難前面的第一個回答。經中說明佛陀與菩薩都能如實了知殺生的法相，所以稱為「知殺」。「阿羅漢」之上，依照經文本來有「父母」二字，此處因為正是在質問辟支佛的問題，所以省略了這兩個字。經文既然將三乘聖者同列為上品殺業，就表示殺害緣覺的罪責並不亞於羅漢。回答中，首先點出《涅槃經》的本旨。經文純粹是劃分起心動念的業行，並非在甄別律制中的波羅夷與逆罪。照此看來，如果殺害辟支佛，雖然不構成律制中的五逆重罪，但由於對象尊貴殊勝，所招感的惡業絕非尋常之流。「如果不」以下，引導經文反詰質疑。首先引述經文的記載。梵語稱為「一闡提」，中文翻譯為「信根不具」。「不墮三種殺業」的意思，是由於經中方便宣說殺之無罪，不列入三品之中，所以經文說「好比割草、掘地一樣，沒有罪業果報」。「依照」以下，比對律宗的制度。所謂「無性」，依照經文前段，是指一闡提斷盡善根無佛性。但根據後文的判決，這只是佛陀隨順眾生根機的「隨他意語」；一切眾生皆有佛性，才是佛陀徹底的「隨自意語」。

【507-0014】02_戒疏/08a_卷二下之一#93
【原文】【疏】問：「若殺羅漢，為知得逆，為不知耶？」
【譯文】【疏文】提問：「如果殺害阿羅漢，究竟必須是在知情他是聖者時才構成逆罪，還是不知情也會構成呢？」
