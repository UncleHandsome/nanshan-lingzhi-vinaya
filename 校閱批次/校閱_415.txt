# 校閱材料　第415檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【415-0001】資持記/03d_上二#19
【原文】律中，阿難徒眾非法，為迦葉所訶。眾欲失者，失猶壞也。汝年少者，命阿難也。俱下二句，斥放逸。初下二句，斥懈怠。遍下二句，斥虛食信施，故言破穀。又解，穀即訓善，言壞他淨信。〔《論語》云：三年學，不至於穀，注云穀善也。〕以下，準文誡約。
【譯文】律藏記載，阿難的徒眾行事不合法度，因而遭到大迦葉的呵斥。說「僧眾將會毀滅」，「失」就是壞的意思。說「你這年輕人」，是在呼喚阿難。從「俱」字以下的兩句，是斥責其放逸。從「初」字以下的兩句，是斥責其懈怠。從「遍」字以下的兩句，是斥責其虛耗吞食信徒的布施，所以說是「破壞糧穀」。另一種解釋，是將「穀」訓讀為「善」，意思是毀壞了他人清淨的信仰。〔《論語》說：「學習了三年，心思還不在求取善道上」，註解說穀就是善的意思。〕從「以」字以下，依照經文進行告誡與約束。

【415-0002】資持記/03d_上二#20
【原文】善知法相者，以多聞故。若據佛在，阿難猶是學人；今云無學者，從後為言。自輕，謂不以攝眾為重故。簡人中，初標示。須下六句，列示五德。初行潔，二志堅，三學廣〔中間二句〕，四識高，五智深。可下二句，示堪能。今時昏鄙，無有一德，輒居僧首；
【譯文】所謂「善於了知法相」，是因為聽聞佛法極為廣博的緣故。若依佛陀在世時的情形來看，阿難當時還只是個「有學」之人；現在說他是「無學」，是順從後來的果位而說的。所謂「自輕」，是指不把統領大眾當作一件重大的事。在「甄選人才」（簡人）這一科中，開頭標明指示。從「須」字以下的六句，列出並開示五種德行：第一是德行純潔，第二是志向堅定，第三是學識廣博〔即中間的兩句〕，第四是見識高超，第五是智慧深邃。從「可」字以下的兩句，指出其所具備的堪能。現今時代的人昏聵鄙陋，毫無一德，卻動輒佔據僧團首領之位；

【原文】群愚共聚，造作非法；但謀利養，餘無所知。悲夫！四分律行事鈔資持記上二
【譯文】一群愚痴的人聚集在一起，造作種種不如法的事；只圖謀利養，其餘一概無知。可悲啊！——《四分律行事鈔資持記》卷上之二。

【415-0004】資持記/04a_上三#1
【原文】四分律行事鈔資持記上三8 釋受戒篇(上三)釋受戒篇受即能領心，戒謂所納法。受通五種〔一善來，二三語，三破結，四八敬，五羯磨。〕，戒分四位〔五、八、十、具〕。今此所標，受據羯磨，戒指具足。就羯磨中，自分六位〔僧中十人、五人，尼中二十人，義立十人；
【譯文】《四分律行事鈔資持記》卷上三之八，解釋〈受戒篇〉：能領受的心稱為「受」，所納受的法稱為「戒」。「受」通於五種方式（第一善來，第二三語，第三破結，第四八敬，第五羯磨），「戒」則分為四個位階（五戒、八戒、十戒、具足戒）。現在此處所標示的，受是依據羯磨法，戒則是指具足戒。在羯磨受戒之中，本身又分六種位階（僧中十人受、五人受；尼中二十人受，義理上亦立有十人受；

【415-0005】資持記/04a_上三#2
【原文】小年曾嫁、遣信，兼前共成十受。〕；今此據文，正明大僧中國十人，羯磨行事。義兼邊五，眾異事同，故不別顯。緣即文中五種，就別離為十四。眾緣會聚，作業方成，故云集也。《疏》云：佛世利機，契動便感；末時澆薄，聖制從緣；緣集則作業功成，緣散則戒德無立。文意頗同。
【譯文】年少曾出嫁者受、遣信受，連同前面所說合為十種受戒法）。現在此處依據鈔文，正是闡明大僧在中國地區由十位僧人以羯磨來行事受戒。義理上同時兼顧邊地的五人受戒，兩者只是大眾人數不同，但行事本質一致，所以不再另外顯現。所謂的「緣」，即是指鈔文中所說的五種條件，若依細目分別開來共有十四種。種種條件聚合，法事造作才能成就，所以稱為「集」。《業疏》說：佛陀在世時眾生根機敏利，只要心念相契感動便能蒙受戒體；末法時期風氣澆薄，聖人制戒必須依憑條件；條件具足聚集則造作功成，條件離散則戒德無從確立。經疏與此處鈔文的意思大體相同。

【415-0006】資持記/04a_上三#3
【原文】所以不言因者，若據相籍成業，則因緣義通；若論功有親疎，則內外體別。今云緣集，且就通論；餘處兩分，乃從別意。標歎中。凡鄙者，通目六道。煩惱業苦，垢染不淨，故云穢流。聖眾，則總召三乘。無漏聖道，人天所尊，故云寶位。上明所捨，下明所獲。敘緣中。六句三意，次第相生。初明心廣緣多。
【譯文】之所以不說「因」，是因為如果依據彼此憑藉成就戒業來說，因與緣的含義是可以相通的；若是論及引發功能的親疏遠近，則內在動機與外在條件本體自有分別。現在說「緣集」，是暫且就通泛的義理來談；在其他地方將因與緣分開說明，則是順從各自特殊的用意。在標題讚歎的文段中，「凡鄙」通指六道眾生。被煩惱、惡業、痛苦所垢染而不清淨，所以稱為「穢流」。「聖眾」則是總體稱呼聲聞、緣覺、菩薩三乘。無漏的聖道為人道與天道所尊崇，所以稱為「寶位」。前半段說明所捨離的境界，後半段說明所獲得的果位。在陳述緣由的文段中，包含六句話、三層意思，依序相續而生。首先說明受戒之心極其廣大、所對之境緣極其繁多。

【415-0007】資持記/04a_上三#4
【原文】上句躡上超入。下云緣多者，即下五位總別諸相。〔有云緣多即法界境者，甚非文意。〕次二句明緣多事難。法事者，目下正加。攸即語詞，或可作尤。下二句明事難須審。通斥中，初二句斥無知秉御。每，猶多也。師匠義一，文家疊舉。學教知法，舉事成益，故云實易。不學昏教，自他俱損，故曰實難。
【譯文】第一句承接上文而超越凡俗證入聖位。下面所說的「緣多」，就是指下文五個位階中所包含的總相與別相種種條件。（有人認為緣多是指法界之境，這非常不符合鈔文的原意。）接下來兩句說明因境緣繁多而使受戒法事變得艱難。所謂「法事」，是指稱下文的「正加教法」。「攸」是語助詞，或者也可以作「尤」字解。再下面兩句說明法事既然艱難就必須審慎進行。在總體斥責的文段中，前兩句斥責那些毫無知見卻主持羯磨受戒的人。「每」就是多的意思。「師」與「匠」意義相同，撰文者將其重疊並舉。通達教理通曉戒法，舉辦事相就能成就利益，所以說「確實容易」。不肯學習而對教理昏昧，讓自己與他人都蒙受損害，所以說「確實艱難」。

【415-0008】資持記/04a_上三#5
【原文】意云：為師本易，在彼反難也。但下，推妄行所由。㳂謂從舊，革乃更新。事雖古傳，容有訛正；彼唯執舊，故曰不思。真教即律。列非中。五句即括四緣，二五事非，餘三可見。執文即白讀。障即是難，遮通得否，難則永閉。薄謂中邊不滿，惡謂體相非數；文略別眾，義必兼含。
【譯文】意思是說：擔任戒師本來是容易的事，在那些無知者身上反而變得艱難了。從「但」字以下，推究盲目妄行產生的原因。「㳂」是指沿襲舊規，「革」是指更新變革。事情雖然是自古相傳，但其中難免會有訛誤與端正；那些人只是一味執守舊規，所以說「不思量」。所謂「真教」就是指律藏。在列舉非法的文段中，五句話就概括了四種緣，第二句與第五句是屬於事相上的非違，其餘三句則顯而易見。「執文」是指照本宣讀白文。「障」就是難，遮難通於能否開許受戒，而難法則永遠閉塞受戒之路。「薄」是指中印度或邊地的僧數不滿，「惡」是指僧人的體質品相不合僧數；鈔文雖然簡略未提別眾，但義理上必定涵蓋在內。

【原文】假借衣鉢，過在能受，故云自也。結損中，上二句指斥。虛下，明損他。唐亦虛也。後下，彰自損。引勸中，初引經。此下，準經勸慎，不可誤他。若據本律，得更重受；今望事難，故云不宜耳。故下，正彰篇意。具緣中。舊記並科此為古五緣，謂正加中十種方便，為今師十緣。毀祖師教，盲後學眼；

【譯文】問：這與受戒者自身條件中的第四條有何差異？回答：前面是指初出家小眾的形儀容貌，此處是依據大僧應具備的道具器物，能受戒與所對受、內心與外相，難道還不明顯嗎！總括上述六種緣，終究回歸為四種要素：人、法、事、處，以單一或複合來相配對。此外，前五條如果不具備，必定無法成就受戒。第六條如果有欠缺，可能會引起諸多爭論；但如果依照祖師的旨意，照例也是不能成就的，如同後文詳細辨析。再者依照《羯磨》的說法，又另外增加了一種條件，即「處於佛法住世之時」。

【原文】《毘曇論》云：若至法滅，一切結界受戒，皆失沒故。第三緣者。上並旁助，此正因本。必須開悟，方堪進受。若論發乞，合是兩緣；心口雖殊，希求義一，故合之耳。文下，引示。律中佛言教乞戒而不乞，不得受具足。
【譯文】《阿毘曇論》說：如果到了佛法滅盡之時，一切結界與受戒的法效，都會徹底喪失泯滅。第三條緣「發起請求的心願」（第三緣者）。上面那些都是從旁資助，此心才是正因本質。受戒者必須心開意解領悟，才能夠進一步領受戒體。若分開論述發心與乞戒，本該是兩種緣；但心念與口述雖然不同，希求戒法的意涵卻是一致的，所以合併為一條。鈔文下方，是引用律文說明。律中佛陀說：教導乞戒而不肯乞求的人，不得給予受具足戒。
