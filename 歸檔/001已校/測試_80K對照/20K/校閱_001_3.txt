# 校閱材料　第001檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【001-0059】01_行事鈔/00_卷首#59
【原文】若《四分》判文有限，則事不可通行，還用他部之文，以成他部之事。或二律之內，文義雙明，則無由取捨，便俱出正法，隨意采用。然行用正教，親自披閱，恐傳聞濫真故也！
【譯文】如果《四分律》判定事相的文句有限，事情不能普遍通行，就回過頭來用其他部派的文句，以成辦其他部派所說的事。或者兩部律之中，文與義都明白，那就無從取捨，便一併列出正法，隨自己的意思採用。然而在實行運用正教時，要親自披閱原典，這是恐怕傳聞會混濫真理的緣故！

【001-0060】01_行事鈔/00_卷首#60
【原文】又世中持律，略有六焉。一唯執《四分》一部，不用外宗。二當部缺文，取外引用。三當宗有義，文非明了。四此部文義具明，而是異宗所廢。五兼取五藏，通會律宗。六終窮所歸，大乘至極。
【譯文】又，世間持律的人，大略有六種：一、只執守《四分》一部，不用外宗的說法。二、本部缺文時，取外宗引用。三、本宗有義理，但文字並不明了。四、此部文義都具足明白，卻是異宗所廢棄的。五、兼取五藏，通達會歸於律宗。六、最終窮究所歸，則是大乘的至極。

【001-0061】01_行事鈔/00_卷首#61
【原文】此等六師，各執正言，無非聖旨；但由通局兩見，故有用解參差。此鈔所宗，意存第三、第六；餘亦參取，得失隨機，知時故也！
【譯文】這六類律師，各執正確的言論，無非都是聖人的意旨；只是由於通達與局限兩種見解，所以運用理解有參差不同。這部鈔所尊崇的，用意在於第三與第六；其餘也參酌取用，得失隨機而定，因為要知時宜的緣故！

【001-0062】01_行事鈔/00_卷首#62
【原文】第五文義決通意。夫理本絕名，故立名標其宗極；名隨事顯，故對事而備斯文。然考斯律藏，言事並周，但為年代渺邈，聲彩靡追；法為時移，事多殘缺；加以五師捃拾，情見不同；重由翻譯失旨，妄生構立；又為抄寫錯漏，相承傳濫。所以至於尋究，紛慮良多。今總會之，以通其大見。
【譯文】第五，文義決斷貫通的用意。理本來是絕於名言的，所以安立名稱來標示其宗旨極致；名稱隨事相而顯現，所以對事相而具備這些文字。然而考核這律藏，言語與事相都周備，只因為年代久遠渺茫，音聲光彩已無法追尋；法隨時代而轉移，事相多有殘缺；加上五師收集拾取，情見各有不同；更由於翻譯失去原旨，妄自生起構立；又因為抄寫錯誤脫漏，師資相承而傳成濫誤。所以到了尋求探究的時候，紛雜的疑慮很多。現在總會貫通它們，以通達其大體見解。

【001-0063】01_行事鈔/00_卷首#63
【原文】若文義俱闕，則可舉一以例諸；或就理有，而成前事；或在文雖具，而於義有闕，便以義定之。故論言以理為正故也！或義雖必立，當部無文，則統關諸部，以息餘謗。
【譯文】如果文與義都欠缺，就可以舉一例來類推其餘；或者就義理上應有的，來成立前面所說的事；或者文字雖然具足，但在義理上有欠缺，便以義理來判定。所以論中說「以理為正」的緣故！或者義理雖然一定應成立，而本部沒有文字，就統攝關涉諸部，以止息其餘的謗議。

【001-0064】01_行事鈔/00_卷首#64
【原文】然文義決通，誠難廢立；自非深明律相，善達開遮；不然，便有累於自心，固無益於他境。故律云：文義俱同、文同義異、文異義同、文義俱異，具舒進止，不勞敘釋。
【譯文】然而文義的決斷貫通，實在難以取捨建立；如果不是深深明了律相、善於通達開與遮，不然的話，就會有累於自己的心，固然也無益於他人的境界。所以律中說：文義俱同、文同義異、文異義同、文義俱異，都詳細舒展其進止取捨，不必勞煩敘述解釋。

【001-0065】01_行事鈔/00_卷首#65
【原文】然決判是非者，必總通律藏之旨，并識隨經之文；如上六師所明，乃可究斯教迹。故《十誦》云：比丘有三事決定知毘尼相：一本起，二結戒，三隨結。應思惟觀察二部戒律，并及義解、毘尼、增一，開遮輕重。如五大色，是不淨，遮；非色，淨，不遮。如是等，籌量本末已用也！《明了論》亦云：比丘能知五相，名解毘尼，不看他面。文略同上，廣如彼說。
【譯文】然而要決斷判定是非的人，一定要總體通達律藏的宗旨，並且熟知隨經律中的文句；像上面六類律師所闡明的，才可以探究這教法的蹤跡。所以《十誦律》說：比丘有三件事能決定知道毘尼的相狀：一是本起（制戒的起因），二是結戒（制立戒條），三是隨結（隨事增結）。應當思惟觀察僧、尼二部的戒律，以及義解、毘尼、增一，開遮輕重。譬如五大色是不淨的，就遮止；非色是清淨的，就不遮。像這樣等，籌量其本末之後再運用！《明了論》也說：比丘能知道五相，名為解毘尼，不必看他人臉色。文字大略同上，詳細如那部論所說。

【001-0066】01_行事鈔/00_卷首#66
【原文】第六教所詮意。詮教之文，文雖浩博，撮其大趣，止明持犯。然持犯之境，境通內外；內謂行心之結業，外謂情事之順違。但令教行相循，始終無犯，則為持也。若生來不學，於法無聞，修造善惡，義兼福罰。今欲科罪，但使與教相應，不問事情虛實，並名犯也。此通名持犯也！
【譯文】第六，教法所詮釋的用意。詮釋教法的文字，文字雖然浩瀚廣博，撮取其主要旨趣，只在於說明持與犯。然而持犯的境界，境界通於內外；內是指行心所結成的業，外是指情事上的順與違。只要使教法與行持互相依循，從始至終沒有違犯，那就是「持」。如果生來不學，對法沒有聽聞，所修造的善惡，其義兼有福與罰。現在要判科其罪，只要與教法相應，不問事情的虛實，都名為「犯」。這是通稱的持犯！

【001-0067】01_行事鈔/00_卷首#67
【原文】若結篇正罪，窮諸治罰，必令束其方便，攬成業果；使量據覈其實情，輕重得於理教；則斷割皎然，更何蕪濫。此別名持犯也！
【譯文】如果是結成篇聚的正罪，窮究各種治罰，一定要收束其前方便，總攬結成業果；使衡量的依據能考核其實情，輕重都能符合義理與教法；那麼判斷就清楚明白，還有什麼雜亂氾濫呢。這是別稱的持犯！

【001-0068】01_行事鈔/00_卷首#68
【原文】第七道俗七部立教通局意。顯理之教，乃有多途，而可以情求，大分為二。
【譯文】第七，說明道俗七眾（七部）建立教法的通與局之意。顯明義理的教法，有許多途徑，而可以用情識去推求的，大致分為兩種。

【001-0069】01_行事鈔/00_卷首#69
【原文】一謂化教。此則通於道俗。但汎明因果，識達邪正。科其行業，沈密而難知；顯其來報，明了而易述。
【譯文】第一是化教。這通於出家與在家。只是泛泛說明因果，使人認識通達邪正。至於判別其行業的品類，則深沈隱密而難以了知；顯示其未來的果報，則清楚明白而容易敘述。

【001-0070】01_行事鈔/00_卷首#70
【原文】二謂行教。唯局於內眾。定其取捨，立其網致，顯於持犯，決於疑滯；指事曲宣，文無重覽之義；結罪明斷，事有再科之愆。
【譯文】第二是行教。只局限於內眾（出家眾）。確定其取捨，建立其綱要，顯示持犯，決斷疑滯；指對事相而委曲宣說，文字沒有需要反覆再看才能明白的情形；結罪判決明確，事有再科（重複判罪）便有過失。

【001-0071】01_行事鈔/00_卷首#71
【原文】然則，二教循環，非無相濫；舉宗以判，理自彰矣。謂內心違順，託理為宗，則準化教；外用施為，必護身口，便依行教。然犯化教者，但受業道一報；違行教者，重增聖制之罪。故經云：受戒者罪重，不受者罪輕，文廣自明。所以更分者，恐迷二教之宗體，妄述業行之是非；故立一門，永用蠲別。
【譯文】然而這兩種教法循環相關，並非沒有互相混濫；舉出宗旨來判定，道理自然彰顯。就是說：內心的違與順，寄託於義理為宗，就依準化教；外用的施為，必須守護身口，便依行教。然而違犯化教的人，只承受業道的一種果報；違犯行教的人，更加上聖人所制之罪。所以經中說：受戒的人罪重，不受戒的人罪輕，文字廣說自然明白。之所以再加以分別，是恐怕人迷惑於二教的宗體，妄自敘述業行的是非；所以建立這一門，永遠用來區別。

【001-0072】01_行事鈔/00_卷首#72
【原文】第八僧尼二部行事通塞意。然二部同戒同制，則事法相同；行用儀式，類準僧法；具在諸門，隨事詳用。若辨成犯相者，戒本自分。隱而難知者，具在隨相。餘有約位之戒，謂輕重不同，有無互缺，犯同緣異，而是當世盛行，種相難知者；及別行、眾行等法，方列尼別行法中。此但分其宗類，猶未顯其來詮；諸有不同之意，具在大疏。

【原文】後明鈔興本意。夫鈔者，固令撮略正文，包括諸意也！余智同螢曜，量實疎庸；何敢輕侮猷言，動成戲論。雖然，學有所承，承必知本；每所引用，先加覆撿。於一事之下，廢立意多；諸師所存，情見繁廣。今並刪略，止存文證。及教通餘論，理相難知；自非通解，焉能究盡？具如集《義鈔》所顯。而抄略證文，多不具委，但取文義堪來入宗者。自外不盡之文，必欲尋討，知其始末，則非鈔者之意。故文云：諸比丘欲不具說文句，佛言聽之。《毘尼母論》云：佛令引要言妙辭，直顯其義。庶令臨機有用，無待訪於他人；即事即行，豈復疑於罪福？猶恐後代加諸不急之務，增益其中，使真宗蕪穢，行者致迷；鳥鼠之喻，復存於茲日矣！
【譯文】最後說明這部鈔興起的本意。所謂「鈔」，本來就是要撮取正文的精要、包括諸家的意旨！我的智慧如同螢火之光，才量實在疏淺平庸；怎麼敢輕慢聖人的言教，動輒成為戲論。雖然如此，所學有所傳承，傳承就必須知道根本；每次有所引用，都先加以覆核檢查。在每一件事之下，取捨建立的用意很多；諸位律師所保存的，情見繁雜廣博。現在一概刪略，只保存文證。至於教法通於其餘論典，義理相狀難以了知；若非通達理解，怎能究盡？詳細如所集的《義鈔》中所顯示。而抄錄節略的證文，大多不夠完備詳委，只取其中文義足以收入本宗的部分。除此之外未盡的文字，若一定要尋求探討、知其始末，那就不是作鈔者的本意了。所以文說：諸比丘想要不具說文句，佛說可以。《毘尼母論》說：佛令引用要言妙辭，直接顯示其義。希望能使面對機境時有所用，不必等待去問他人；即事即行，哪裡還會對罪福有所疑惑？但仍恐怕後代加上一些不急要的事務，在其中增益，使真正的宗旨荒蕪污穢，行道的人因此迷惑；那麼「鳥鼠」的比喻，又要出現在今日了！
