# 資持記 裁決重跑

## 材料

```text
測試/重譯/資持記/_裁決_重跑/
```

19 份：

```text
24、64、202、1000、1205、1500、1770
```

## 執行

```powershell
$env:QWEN_SHUJI_SRC='重譯/資持記/_裁決_重跑'
$env:QWEN_KEY_FILE='qwk.txt'
$env:QWEN_WORKERS='19'
$env:QWEN_LOCAL='1'
$env:QWEN_NO_WEB='0'
$env:QWEN_MAX_SEARCH='3'
$env:QWEN_RAW_SAVE='1'
$env:QWEN_NO_CITE='0'
$env:QWEN_EFFORT='xhigh'
$env:QWEN_KEEP_THINKING='1'
python -X utf8 _src/qwen_local.py
```

## 檢查

回覆到：

```text
測試/重譯/資持記/_裁決_重跑/回覆/
```

每份必須有：

```text
【結論】
【分歧與裁決】
【修正後的譯文】
```

若只有研究筆記、沒有這三欄，仍是失敗。

## 完成後

把 19 份回覆覆蓋回：

```text
測試/重譯/資持記/_裁決/回覆/
```

再重新打包審核這 19 個 key 所屬 pack。
