**可以合併，但要看你擔心的是哪一種「改壞」。**

這個做法（**Turn 1 跑完審核 → 僅對 `FIX` 在同一個 `messages` 對話追問 Turn 2 輸出修訂版**）會**減少「漏改／斷裂型」改壞**，卻會**提高「誤殺型」改壞**的機率。

### 一、為什麼你會覺得「同對話加一輪比較不會改壞」？（確實擊中現況的 3 個斷點）

目前 `audit` 和 `revise` 是拆成兩支獨立腳本重開對話，中間確實有資訊斷鏈：

1. **檢索證據在 `revise` 階段全丟光了**
   - `audit` 開著 `NO_WEB=0`，一組常跑 3–5 次 `local_search`（每次回傳前後 240 字）＋ 1–2 次 `web_search`／`web_fetch`（1800 字）。
   - 但 `mk_revise_materials.py` 只把 `【必改硬傷】` 傳給 `revise`（而且 `revise` 被設為 `QWEN_NO_WEB=1` 斷網）。若硬傷是靠 `web_search` 查出來的，`revise` 根本複查不到原證據，只能看濃縮後的 `依據：` 重猜或重搜。
2. **`【逐句簡核】` 被丟掉，獨立 `revise` 容易誤刪或誤改**
   - `fixes_block()` 只抓 `【必改硬傷】`，丟掉了 Turn 1 的 `【逐句簡核】`。
   - 獨立重開的 `revise` 得用 `xhigh` 重新讀懂整段原文與譯文，才會出現你們之前修補過的狀況——例如 `REVISE_PROMPT` 被迫加了一堆護欄（「不得刪去原譯正確之主詞、出處限定或條件」、「問題欄成立而修正方向過粗或錯置者，應自擬精確修法」）。
   - 若在同一對話接 Turn 2，哪些句「字面相符」、哪個字為什麼錯、平行文原文是什麼都在上下文裡，要求它「只替換剛才列出的硬傷，其餘逐字照抄」，**確實較不會改壞其他無辜的句子**。
3. **省掉 `FIX` 組（約 18–20%）重搜的輪數與排程步驟**
   - 依你們 L7（2/11）與 20 組實測（4/20），只有約兩成會進 `revise`。同對話 Turn 2 若直接鎖 `tool_choice='none'`（證據 Turn 1 剛查完了），只需多送 1 輪 API，也不用另外維護 `mk_revise_materials.py` 的長段／打包對接。

### 二、但它為什麼「反而可能改壞」？（這套系統原本的 3 道安全閥）

1. **最大風險：失去獨立「駁回（`駁回該項`）」的雙眼覆核（自我合理化）**
   - 你們在 7.3 節與 `REVISE_PROMPT` 第 3 條特別保留了**駁回權**（「審核誤判『水與水該刪』」、「修訂盲從錯誤建議 → 加『應駁回該項、維持原譯』」）。
   - `qwen_local.py` 預設開啟 `KEEP_THINKING=1`（`preserve_thinking: True`）。如果讓**同一個對話裡的同一個模型**緊接著做 Turn 2，它一秒前才用 `xhigh` 思考推論說服自己「這裡有錯」，下一輪幾乎不可能自我否定去「駁回」，結果就是**只要 Turn 1 誤報，Turn 2 就會乖乖把原本譯對的句子改壞**。
   - 獨立重開 `revise` 沒有 Turn 1 的思考包袱，是這條管線裡唯一能攔截審核誤殺的機制。
2. **`mk_audit` 故意隱藏的「裁決理由」，`mk_revise` 卻要看**
   - 看程式碼會發現一個刻意設計的不對稱：
     - `mk_audit_materials.py`（第 169–185 行）把裁決第 2 欄的理由 `_why` **刻意剃掉**，只留 `採甲／採乙／重修（線索：《…》）`，避免審核被裁決帶偏。
     - `mk_revise_materials.py`（第 166–170 行）卻附上完整的 `divergence(_r1t)`（最多 2000 字），讓修訂能執行「若係裁決推翻甲／乙所致，得參照【裁決分歧參考】採回更準譯法」。
   - 若直接接在 `audit` 的 Turn 2，模型看不到甲乙取捨的完整依據，這條「採回」護欄會失效。
3. **重檢索組的上下文已經很肥，接尾容易不穩**
   - 依 7.6 節，用滿 5 次本地檢索的檔案平均輸入已達 **46,398 tokens**（接近 `MAX_LAST_IN_TOK = 45000`）。
   - 在塞滿 5 輪 KWIC 片段、`xhigh` 思考歷史與 `AUDIT_PROMPT`（「勿改寫整段」「要附書名卷次依據」）的對話尾巴硬轉成 Turn 2（「完整輸出」「禁附出處與括號按語」「遵守 `[1][2]` 與 `STYLE_SPEC`」），容易出現**角色殘留**（夾帶說明／書名）、輸出截斷（`length`）或超過 600 秒 timeout。
   - （順帶一提：千萬不要改成「**單輪**同時輸出審核＋修訂」，模型為省輸出會明顯傾向判 `PASS` 放水；你們想的「先審核、確定 FIX 才追問一輪」已經好非常多。）

```python
        r'(?:【逐句簡核】|(?m)^[#*\s\d.、]*逐句簡核[*：:\s]*)\s*(.+?)'
        r'(?=\n\s*[#*\s\d.、]*【?結論】?|\Z)',
        rt or '', re.S)
    if not m:
        return ''
    txt = re.sub(r'\n{3,}', '\n\n', m.group(1)).strip()
    txt = re.sub(r'(?m)^(\s*)(?=\[\d+\])', r'\1• ', txt)
    if len(txt) > max_chars:
        txt = txt[:max_chars].rsplit('\n', 1)[0] + '\n…（以下省略）'
    return txt


def _evid_plain(s):
    return re.sub(r'[^\u4e00-\u9fffA-Za-z0-9]', '', s or '')


def evidence_block(aud_rep, key, fixes_txt, max_chars=2200):
    ep = os.path.join(aud_rep, key + '_evid.json')
    if not os.path.exists(ep):
        return ''
    try:
        items = json.load(io.open(ep, encoding='utf-8'))
    except Exception:
        return ''
    if not isinstance(items, list) or not items:
        return ''

    quotes = [_evid_plain(q) for q in re.findall(r'[「『]([^」』]{2,40})[」』]', fixes_txt or '')]
    quotes = [q for q in quotes if len(q) >= 2]
    fix_plain = _evid_plain(fixes_txt)

    scored = []
    for idx, it in enumerate(items):
        raw_txt = re.sub(r'https?://\S+', '', (it.get('text') or '')).strip()
        if not raw_txt:
            continue
        bk = (it.get('book') or '').strip()
        src = it.get('src') or 'local'
        tp = _evid_plain(raw_txt)
        sc = 0
        if src in ('web_search', 'web_fetch'):
            sc += 3  # 修訂階段為 NO_WEB=1，優先保留網搜證據
        if bk and (_evid_plain(bk) in fix_plain or (len(bk) >= 2 and bk[:2] in (fixes_txt or ''))):
            sc += 5
        for q in quotes:
            if q in tp:
                sc += 10
            elif len(q) >= 4:
                grams = {q[i:i + 3] for i in range(len(q) - 2)}
                sc += sum(1 for g in grams if g in tp)
        scored.append((sc, -idx, it, raw_txt))

    scored.sort(reverse=True)
    # 若完全沒有任何片段命中硬傷關鍵詞（代表初審只在核對無誤句），最多僅附前 2 筆（900 字內）備查
    has_hit = any(sc >= 5 for sc, _, _, _ in scored)
    budget = max_chars if has_hit else min(max_chars, 900)
    limit_n = len(scored) if has_hit else 2

    lines, acc = [], 0
    for sc, _, it, raw_txt in scored[:limit_n]:
        src = it.get('src') or 'local'
        bk = (it.get('book') or '').strip()
        jn = (it.get('juan') or '').strip()
        q = (it.get('q') or '').strip()
        if src == 'local':
            tag = '本地｜《%s》%s｜查「%s」' % (bk or '未名', jn, q)
            cap = 480
        else:
            tag = '網搜｜%s｜查「%s」' % (bk or '白名單', q)
            cap = 650
        body = raw_txt if len(raw_txt) <= cap else (raw_txt[:cap] + '…')
        row = '- [%s] %s' % (tag, body.replace('\n', ' '))
        if acc + len(row) > budget and lines:
            break
        lines.append(row)
        acc += len(row) + 1
    return '\n'.join(lines)
```
