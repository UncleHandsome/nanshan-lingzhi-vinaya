# 校閱材料　第138檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【138-0001】資持記/01d_上一上#48
【原文】言即能詮，事謂所詮。但下，正明遺缺有四意，初示正意。上二句明去聖時遙，次二句顯法隨時變。此約《四分》結集之時，即當佛滅一百年後，故云渺邈，即遙遠也。聲謂言音，彩謂好相，靡追猶言莫及也。五師相付，百年已來，如來在日親宣之事，莫能反追。教逐時訛，故有遺缺；
【譯文】「言語」就是指能詮顯的教條文句，「事相」是指所詮顯的戒相行持。從「但是」往下，正式說明律法遺漏殘缺的四種緣由，起初揭示核心原委。前兩句說明距離聖人佛陀的時代已經十分遙遠，接下來兩句彰顯戒法隨著時代更迭而產生變遷。這是就《四分律》在印度正式結集的時間來說，正值佛陀滅度百年之後，所以說「渺邈」，也就是悠遠漫長的意思。「聲」是指佛陀的金口聖音，「彩」是指佛陀的三十二相好容顏，「無從追尋」猶如說人力已無法追及。由五位尊者代代傳承囑託，百年以來，佛陀在世時親自宣告的事相，已經無人能夠重返追尋。教典跟隨時代傳揚產生了訛誤訛傳，因此才有了脫漏欠缺；

【138-0002】資持記/01d_上一上#49
【原文】如優波毱多問尼佛在日事，及令魔現佛，斯可證也。加以下三種，並是兼意，故例標重增之語。捃，居運反，採掇也。前云隨其樂欲，成立己宗；故不樂者，則捨而不存，故有缺矣。上二並是西土結集之差；下二即明此方翻傳之失。《業疏》云：覺明論主誦本東傳；至於翻時，隨出便寫；
【譯文】例如優波毱多尊者向年邁的比丘尼詢問佛在世時的行持遺風，以及命令魔王變現出佛陀的身相，這些都可以作為印證。加上以下三種情況，全都是兼帶造成的因緣，所以一律冠上「雪上加霜」的評語。「捃」音居運反，意思是採集摘取。前面說過隨順傳承者各自的心念好樂，分別建立屬於自己的宗派；所以凡是不合心意好樂的，就予以捨棄而不留存，因此就造成了缺漏。上面這兩種情況都屬於在西方印度結集時所產生的偏差；下面這兩種情況則是說明在此方東土翻譯流傳時所發生的訛失。《羯磨疏》說：佛陀耶舍尊者將背誦在心中的律本流傳到東土；等到臨場翻譯時，往往邊口述便隨即寫下；

【138-0003】資持記/01d_上一上#50
【原文】貴在一本，無暇覆疎，尋復返西；此土行用，故多缺耳。又結淨地四句成白，疏云：此是結集缺文〔同上二意〕；或是覺明漏誦，又可竺念遺筆〔同後二意〕。此中欲顯決通，先明殘闕；殘闕之由，不必一致；故以此四詳而求之，然亦不須舉事強配。顯今中，初文。紛慮，謂心想之亂。
【譯文】當時重在先確立出一本漢譯，沒有閒暇來回核對詳細草稿，不久尊者又返回西方；因此在東土行持應用時，遺留了諸多缺漏。又如劃定淨地的作法僅有四句就作成白告羯磨，註疏中說：這或許是在印度結集時就已經脫漏了文句〔等同於前述兩種原由〕；或者可能是佛陀耶舍尊者背誦時產生疏漏，也可能是竺佛念法師在筆錄時遺漏筆墨〔同後兩種原由〕。這裡為了要彰顯決疑開通的重要，先闡明律文殘缺的狀況；然而殘缺的緣由，未必全出於同一種情況；因此依據這四種緣由詳加探求，但也不需要硬拿具體事相生搬硬套。在彰顯當前處理準則的文句中，起初的文段。所謂「心思煩亂」，是指心意念頭紛亂不定。

【138-0004】資持記/01d_上一上#51
【原文】總會者，以三種條例，收一部遺缺。後學披覽，不滯一端，故云通大見也。別示中，初至前事，即第一俱闕例。能決有二，一例二理。例中。如律無解戒場法，例三小界翻結成解；諸律無受七日法，例半月眾法白文立之；又無請二師文，例準請和尚法。此據作法釋也。又如破白讀羯磨，舉誦戒為例；
【譯文】「總體會通」，是指運用三種條例準則，統攝收納整部律典的遺漏欠缺。使後代的修學者在翻閱閱覽時，不再滯留在單一枝節上，所以說「通達廣大高遠的見識」。在分別列示的文段中，從最初到「成辦前事」為止，就是指第一種「條文與義理全皆欠缺」的示例。能夠予以決疑開通的方法有兩種，一是「借例引證」，二是「依理決斷」。在「借例引證」中。例如律典中沒有解除戒場的專門儀軌，便比照三種作法小界翻轉結界作法而成就解界；各部律典中都沒有受七日出界法的具體作法，便比照半月大眾僧事的白文格式來確立；又如沒有迎請羯磨師、教授師二師的明文，便比照迎請得戒和尚的法式。這是依據羯磨作法的角度來解釋。又如宣告破白之後讀誦羯磨文，便拿誦戒的作法作為借例；

【138-0005】資持記/01d_上一上#52
【原文】忘不持衣往會不及，以長衣開忘為例；牒多緣受日，以懺殘多罪同法為例；惡心解界不成、疑界不得重結，並以淨地為例；三種安居，以三品鉢為例〔上是本宗，下引他部。〕；明相會夏，以《僧祇》護衣為例；安居依閏，以《多論》受雨衣為例。此約行事釋也〔餘更尋之〕。理決中。
【譯文】比丘遺忘未能持守衣物導致前往集會不及，便拿長物衣開許遺忘的規定作為借例；具體陳述多種緣由以接受請假外出的日法，便拿懺悔僧殘罪多種過犯採用同一作法作為借例；以瞋惡之心解除地界無法成就、對地界心生疑惑時不得重複劃定，這些都拿結定淨地的法規作為借例；安居的三種時節，拿受持三品缽的法規作為借例〔上面都是依據本宗，下面引用其他部派。〕；守候天邊破曉明相以完成安居，拿《僧祇律》守護衣物的準則作為借例；安居時依照閏月調整，拿《多論》受持雨安居衣的準則作為借例。這是依據僧事行持的角度來解釋〔其餘請自行探求尋找〕。在「依理決斷」中。

【138-0006】資持記/01d_上一上#53
【原文】言理有者，此謂無例，道理合然。如此界僧為別處三寶病緣及僧次請，皆開受日；又當日出界遇難，義判得夏；又十六遮中負債人準理得戒。此等並無文義及例，故云理也。又說恣中前後梵唄偈詞唱告、上座誡勅，不出教文者；及受戒中開示境心、威儀安慰；
【譯文】所謂「法理上具足」，是指毫無現成條例可循，但在道理上理當如此。例如此界僧眾為了其他處所的三寶病患因緣以及僧團輪流請齋，都開許准予接受請假日法；又如當天走出界外途中遭遇災難障礙，在法理上即判定仍算圓滿完成夏安居；又如十六種障難中負債的人依據正理依然可以求受具足戒。這些在律典中完全沒有明文規定、深密法義或相似條例，所以稱之為「依理」。又如說戒自恣儀式中前後的梵唄詠唱、偈文唱誦宣告、上座長老的警誡斥責，這些未見於教典明文之處；以及受戒過程中對境心觀想的開示、威儀舉止的安撫關照；

【138-0007】資持記/01d_上一上#54
【原文】正羯磨時白告警策等，亦名理有而成前事也。二文義具闕。如律盜四方僧物犯蘭，決云此約暫礙僧用故輕，理須犯重。又云：至二三人所共作法，成賊住難，決云：此約眾法對首為言。又得受布薩錢，決云準須付他。《四分》夏中和諍開直去，不須受日；決云約緣而受，不傷大理等。如是尋之。
【譯文】在正式舉行羯磨時的宣告、警策等環節，也都稱為在法理上具足而能成辦前面的律儀僧事。第二種是「條文具備而義理缺漏」（文具義闕）。例如律中規定偷盜十方僧物結偷蘭遮罪，決疑開通時指出：這是針對暫時妨礙僧團日常使用所以處分較輕，若論真實法理則必須結犯重罪（波羅夷）。又如律中說：前往二至三位比丘處共同舉行羯磨作法，構成賊住障難，決疑開通時指出：這是針對僧團大眾行法或對首懺悔而言。又如得到並收受布薩布施的錢財，決疑開通時指出：比照規定必須交託給他人保管。《四分律》中規定夏安居中為了調和紛爭開許比丘直接離去，不需要接受日法請假；決疑開通時指出：應當隨順因緣而受持請假，才不致有傷根本大理等。諸如此類皆應探尋深究。

【138-0008】資持記/01d_上一上#55
【原文】論言者，古記云，即是《善見》，尋文未獲，此所謂不以文害意也。三義具文闕。如有難移夏，準《摩夷》不破安居；遇緣出界忘不受日，引《五百問》憶即悔者得；又《四分》不明重受日法，引《五百》、《明了》二文決之。據義雖當，恐謂師心，故云息謗也。問：如上所引，非無相濫，更請分之？

【譯文】所謂「是非」，是指化教與行教混淆濫雜。世人聽聞《維摩詰經》說發心就是具足戒，就妄自判定戒體的有無。或者迷昧於三性觸犯制教，便認為業力全都是同一個等級；或者說為了營造福報而違背戒律是沒有過咎的；或者執著於唯心觀想，隨即毀棄律儀威儀；或者認為只要堅定持戒，用不著智慧觀照；或者依據《方等經》的事、理二種懺法，就聲稱制教之罪全都消滅；或者依憑篇聚的六種治罰法，就認為性罪業道全都滅除。所以才有人依據大乘教法懺悔波羅夷罪，便企圖湊足小乘僧眾作法之數。像這類的迷誤混亂，從古至今屢見不鮮。

【譯文】到了下文的〈懺篇〉，會再做更廣泛的解說。「故」字以下，說明今天確立此說的意義。普遍通行並普及於後世，不再有謬誤濫用，所以說「永遠用作……」等。「蠲」就是簡別剔除的意思。在〈標宗〉、〈僧網〉、〈懺法〉、〈沙彌〉等各篇中，都會辨明這兩種教法，讀到具體文句時應當詳細體察。第八門。前一門中人員與法門全都是通達的，而這一門則全都是局限的；因為在人方面唯獨局限於二眾，在教法方面局限於行教戒條。然而由於男女果報相貌各有不同，所以致使教法分成了共同與個別；因此必須加以辨析顯示，才能看清各篇的意旨。在說明通塞的文段中，最初的文段。

【原文】同戒即止持戒本，初篇四重，二篇七戒，三十中十八，九十中六十九，眾學一百，七滅諍也。同制謂作持諸法。具諸門者，同戒在中卷，同制則上下二卷。其全同者，則無別舉，如〈集僧〉、〈與欲〉、〈羯磨〉、〈僧網〉之類。少有異者，隨事點示，如〈結界〉中，尼界二里，有難同僧；
【譯文】「同戒」是指止持的戒本，初篇的四波羅夷，第二篇的七個僧殘，三十捨墮中的十八條，九十單提中的六十九條，眾學法中的一百條，以及七滅諍法。「同制」是指作持的各項法門。具備在各個門類中的，同戒是在中卷，同制則分布於上、下兩卷。至於完全相同的法門，就不再特別列出，例如〈集僧〉、〈與欲〉、〈羯磨〉、〈僧網〉這一類。稍微有所不同的，隨具體事相點出，例如〈結界〉中，比丘尼的結界範圍是兩里，若有災難則同於比丘；
