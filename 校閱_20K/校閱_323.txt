# 校閱材料　第323檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【疏】五、「波逸提」，犯法也。
【譯文】【疏文】第五、「波逸提」，是指所犯的罪名法條。

【323-0002】02_戒疏/14b_卷三下之二#97
【原文】【疏】不犯中。「若得已成」，亦須「斧斬」。此言切人也，如何可通？
【譯文】【疏文】在不犯的例外規定中。「如果得到別人已經做好的」，也必須「用斧頭斬碎」。這句話措辭極為嚴峻切厲，怎麼可以隨便予以通融開許呢？

【323-0003】02_戒疏/14b_卷三下之二#98
【原文】【記】第五，釋注中，初文。「此言切人」，謂誡勒甚切。「如何可通」，言必無開許也。
【譯文】【記文】第五、在解釋注釋中，這是第一段。「這句話措辭嚴峻」，是指告誡約束得非常嚴厲。「怎麼可以通融」，是強調絕對沒有任意開許的餘地。

【323-0004】02_戒疏/14b_卷三下之二#99
【原文】【疏】如《五分》云：「他施已成，亦犯捨墮。」《十誦》：「若得已成者，受用不犯。」
【譯文】【疏文】就像《五分律》說的：「即使是別人布施已經做好的成品，也同樣犯捨墮罪。」《十誦律》則說：「如果得到已經做好的成品，受用並不犯戒。」

【323-0005】02_戒疏/14b_卷三下之二#100
【原文】【記】二中，《五分》、《十誦》，二文不同，致有他解。
【譯文】【記文】第二部分中，說明《五分律》與《十誦律》這兩部律文的說法不一致，才導致後來產生了其他不同的見解。

【323-0006】02_戒疏/14b_卷三下之二#101
【原文】【疏】有人解云：「《四分》同《十誦》，不同《五分》。」而《律》文中，「若得已成」者下無開文，但道「斬壞」，如何舍制而用他開？所不同也。
【譯文】【疏文】有人解釋說：「《四分律》的立場與《十誦律》相同，不同於《五分律》。」然而在《四分律》的原文中，在「若得已成」這句話下面根本沒有開許受用的文句，只是交代要「斬壞」，怎麼可以捨棄嚴格的禁制而反過來採用別人的開許呢？這就是我所不能苟同的地方。

【323-0007】02_戒疏/14b_卷三下之二#102
【原文】【記】三中，初科。古謂《四分》文列不犯，故云「同《十誦》」。「而」下，斥非。注中引《律》，明云斧斬，正符《五分》，那云不同？則知《十誦》文緩，不可依也。
【譯文】【記文】在第三點中，第一科。古人認為《四分律》注文列在不犯條款，所以說「與《十誦律》相同」。自『而律文中』以下，斥責其非。注文中引述《律》文，明確說明應當用斧頭砍碎，正好契合《五分律》，怎能說不相同呢？由此可知《十誦律》的規定較為寬緩，不可依從。

【323-0008】02_戒疏/14b_卷三下之二#103
【原文】【疏】余因參譯，親見梵僧。自唐國已西已南，至于大海，百餘國僧，現今所披，並非綿帛。非氈非布，無成法衣。問何所以，為斷殺故。斯成現量，何用謾言？止可知披而謂非，不可迷非而謂是。
【譯文】【疏文】我因為參與翻譯經論的機緣，親眼見到來自印度的梵僧。從大唐國土向西、向南，一直遠到大海邊，上百個國家的出家僧眾，如今身上所披搭的僧衣，絕沒有一件是用蠶綿絲帛製作的。如果不是羊毛氈、就是植物麻布，除此以外不能用來做如法法衣。詢問他們為什麼要這樣，回答都是「為了徹底斷除殺生之罪」。這是親眼目睹的現量事實，何須空發狂妄之言呢？我們充其量只能承認自己穿著絲綿是違背戒律的，絕不可以在迷惘中把錯誤的行徑指稱為合乎戒律。

【323-0009】02_戒疏/14b_卷三下之二#104
【原文】【記】二中。初敘親聞，玄奘西歸，於慈恩寺選十僧翻譯，祖師預焉，故云「參譯」。「已西已南」，皆唐國外境。「氈」是獸毛，亦即生分，然是剪剃，非害命故，如下所明。「斯」下，責謬解。現行之事，故云「現量」。「謾」，猶妄也。「披而謂非」，此猶可恕，「迷非謂是」，豈免無知？
【譯文】【記文】第二段中。首先敘述親身的見聞。玄奘法師從西方歸國後，在慈恩寺選拔了十位大德僧人協助翻譯，道宣律祖也名列其中，所以說「參與翻譯」。「向西向南」，全都是大唐疆土之外的廣大西域與印度各國。「毛氈」雖然是用獸毛製成，也屬於眾生身體的一部分，但因為是剪剃毛髮，並非傷害性命，就如同下文所說的那樣。「這是親眼目睹」以下，責備錯誤的曲解。這是眼前正在推行實踐的事實，所以稱為「現量」。「謾」就是虛妄之意。明知身披絲綿法衣是不合戒法的，這種人尚且還有得救的自知之明；若冥頑不靈、把非法的行為堅稱合乎戒法，又怎能免於愚昧無知的過失呢？

【323-0010】02_戒疏/14b_卷三下之二#105
【原文】【疏】問：「既云非法，受持成不？」
【譯文】【疏文】提問：「既然說是屬於非法的衣物，那麼作法加持受持到底能否成立？」

【323-0011】02_戒疏/14b_卷三下之二#106
【原文】【疏】答：「如律通制，但云五大上色，不成受持，至於財體，無文得不。若準《央掘》：『繒綿轉來，施持戒人，不應受。若受，非悲，不破戒。』據此斟酌也。」
【譯文】【疏文】答：「依律的通則來說，只說五種大上色不能算作如法的受持；至於財物的材質本身，律文並沒有明文說可以或不可以受持。若依《央掘摩羅經》所說：『繒帛絲綿若是轉手得來，布施給持戒的人，不應該接受。若接受了，只是欠缺悲心，並不破戒。』要依這個標準來斟酌。」

【323-0012】02_戒疏/14b_卷三下之二#107
【原文】【記】初問答中。初據律無斷，「若」下，準經斟酌。《央掘摩羅》，即大乘經。「轉來」，非蠶家者。「不應受」者，《經》中斷也。「若受非悲」者，違化教也。「不破戒」者，不犯制教也。大乘菩薩悲行為先，若著蠶衣，沾殺生分，故是「非悲」。小教聲聞，離過為本，但離殺手，犯緣不具，故「不破戒」。準此據律，如法得成，深取經意，終非應法，故令「斟酌」也。《章服儀》云：「且自『非悲』之語，終為永斷之言。」祖師之意，自可見矣。
【譯文】【記文】開頭的問答之中，前半是依據律文沒有斷然禁止；「若」字以下，是依經文來斟酌。《央掘摩羅》，就是大乘經典。「轉來」，是指並非從養蠶人家直接得來。「不應受」，是經典中的禁斷。「若受非悲」，是違背化教。「不破戒」，是不觸犯制教。大乘菩薩以悲行為先，若穿著蠶絲衣服，便沾上殺生的成分，所以說是「非悲」。小乘聲聞以離過為根本，只要遠離親手殺害，犯戒的條件不具足，所以說「不破戒」。依此看來，若依據律典，如法可以得成受持；但深深體取經意，終究不算合乎正法，所以令學人「斟酌」。《章服儀》說：「單從『非悲』這句話來看，終究是永遠斷除的教誡。」祖師的用意，自然可以看得出來。

【323-0013】02_戒疏/14b_卷三下之二#108
【原文】【疏】問：「綿衣、黑、白，同是犯緣。如何入捨全壞不等？」
【譯文】【疏文】提問：「蠶綿衣物、黑毛衣物、白毛衣物，這三者同樣都是犯戒的境緣。為什麼到了捨棄財物時，一個要徹底砍碎毀壞，其餘的卻不這樣處置？」

【323-0014】02_戒疏/14b_卷三下之二#109
【原文】【疏】答：「綿本損命，偏乖聖心，故斬絕源，永除後犯。黑、白不爾，身分餘毛，過淺障微，還聽服用。」
【譯文】【疏文】回答：「蠶綿原本就涉及損害物命，特別違背佛陀的慈悲聖心，所以必須砍碎以斷絕惡緣，永遠斷除日後重犯的可能。黑毛、白毛則不是這樣，它們只是取自動物身上的殘餘毛髮，過失較淺，障蔽道業的力量輕微，所以在捨棄懺悔後，依然准許返還本人受用。」

【323-0015】02_戒疏/14b_卷三下之二#110
【原文】【記】次問。綿令斬壞，黑白二毛捨已還主，故問決之。答中，毛不損命，與綿不同，故分兩捨。
【譯文】【記文】第二個提問。蠶綿要求徹底斬剁碎裂，黑白二毛在捨棄懺悔後卻可以還給物主，所以提出問題要求判定解決。回答中說明：獸毛不涉及戕害性命，本質與蠶綿截然不同，所以分成兩種完全不同的捨棄處置方式。

【323-0016】02_戒疏/14b_卷三下之二#111
【原文】【疏】「若爾，今有作綿，待蟲飛出，計非損命，應無損也？」
【譯文】【疏文】提問：「如果是這樣的話，現在有人製作蠶綿，是等待飛蛾完全破繭飛出之後才採繭取絲，照理說並沒有損害性命，這樣應當就不算損害了吧？」

【323-0021】02_戒疏/14b_卷三下之二#116
【原文】【記】三問。四戒「不犯」，並牒捨法，餘戒不爾，故問通之。答中。初二句答餘戒不辨。下二句答四戒須牒。言「反前」者，捨還差別如上具明，開通所牒如下各辨，且就此戒，如注所引「得已成者斧」。
【譯文】【記文】第三個提問。這四條戒的「不犯」項目中，全都重申了捨棄的作法，其他戒條卻不是如此，所以提問以求通達其理。回答之中：前兩句回答了其他戒條為什麼不重複辨析；後兩句回答了這四條戒為什麼必須重新標明。所謂「與前面的通則相反」，是指捨棄之後究竟能否退還本人的差別，如同上面已經詳細辨析的那樣；而本戒開許條文中所重複提及的內容，在下文也會各自辨明，單就本戒而言，正如注釋中所引述的「如果得到已經做好的成品，必須用斧頭砍碎」。

【323-0026】02_戒疏/14b_卷三下之二#121
【原文】【記】制意。總括有六：一、虗費，二、長貪，三、經營，四、招譏，五、障道，六、妨業。對文可見。言「體貴」者，如下《僧祇》明之。
【譯文】【記文】制戒意旨。總括起來有六點：第一、平白浪費；第二、助長貪念；第三、經營造作；第四、招致譏嫌；第五、遮障聖道；第六、妨礙本業。對照原文便一目了然。所謂「材質昂貴」，在下文引述的《摩訶僧祇律》中有詳細說明。

【323-0027】02_戒疏/14b_卷三下之二#122
【原文】【疏】四緣成：一、純黑羊毛；二、作三衣，除作氈被、臥具，罪非此戒；三、為己；四、自作成犯。《僧祇》云：「諸比丘並作氈三衣、坐具，唯除漉水囊。乞毛眾多，為人所厭。又毛大貴，一兩須二三金錢。毛細輭，觸人眼睛不淚出。為人求故，或還或死，破人家業。故捨入僧。」
【譯文】【疏文】具備四種因緣構成犯戒：一、使用純黑色的羊毛；二、用來製作三衣袈裟，若是拿來做毛氈被子、寢具鋪墊，罪過則不屬於本戒所管；三、是為了自己使用；四、自己製作完成便構成犯戒。《摩訶僧祇律》說：「當時諸位比丘全都用羊毛氈來製作三衣法衣和坐具，唯獨過濾水囊除外。他們向俗人乞求大量的羊毛，令大眾感到非常厭煩。而且這種黑羊毛極其昂貴，一兩重就要兩三個金錢。毛質細緻柔軟，即使不小心觸碰到人的眼珠子，眼睛也不會痛得流淚。為了替比丘尋求這種珍貴毛料，俗人有時出遠門輾轉才能返家，有的甚至客死他鄉，導致許多家庭傾家蕩產。因此佛陀下令必須將所造之衣捨棄交給僧團。」

【323-0028】02_戒疏/14b_卷三下之二#123
【原文】【記】犯緣。第二點古迷名，故簡「氈被」。「非此戒」者，體是重物，理應得吉。《僧祇》下，引示制意，有二。初是自求，令俗生厭。「又」下，次倩他求，令彼破業。初明體貴，顯其難得。「為人求」等者，彼律估客婦告舍利弗言「我夫主及諸親屬，為求是毛故，或時還家，或死不還」等。此彰過重，故佛制之。
【譯文】【記文】在犯戒因緣中。第二點是針對古人混淆名詞而作的辨正，所以特別排除了「毛氈被褥」。「不屬於本戒」是指這類物品本質上也是重物，按理應當屬於突吉羅罪。《僧祇律》以下，引證以展示佛陀制戒的深意，共有兩層原因。首先是比丘親自乞求，引起俗人強烈的厭棄反感。「而且」以下，第二是央求他人尋覓，導致他人家庭破敗破產。前一段先說明材質極度珍貴，以凸顯其取得之艱難。「為了替比丘尋求」等語，是該部律中記載一位商人的妻子向舍利弗訴苦說「我的丈夫和各位親屬，為了解決比丘對這種黑毛的需求，有時歷盡艱辛才能回到家，有時甚至死在外地再也回不來了」等等。這充分彰顯了過失的嚴重性，所以佛陀才制定了嚴規。

【323-0037】02_戒疏/14b_卷三下之二#132
【原文】【疏】三、「作臥具」，正犯境也。即是法衣，若作餘衣，如上不犯。如戒緣中，衣用上披，擬夜行故，比丘効之。知非下裳，何況作褥，是犯戒也？故下開通，褥非是犯。
【譯文】【疏文】第三、「作臥具」，是正犯之境（或：是正要構成犯戒的對象境緣）。指的就是如法僧衣袈裟，如果拿去做其餘世俗衣服，就如同上面所說是不犯本戒的。正如戒律緣起所載，這種毛氈是用來披在身上、打算在夜晚潛行行動的，比丘正是仿效這種做法。由此可知它絕不是下身穿的裙裳，何況是拿來做地下的褥子，又怎麼會犯戒呢？所以下文的開許條例中，做成褥子明白判定為不犯戒。
