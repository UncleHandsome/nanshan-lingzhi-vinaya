# 校閱材料　第313檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【313-0001】02_戒疏/01b_卷一上之一#100
【原文】【記】三中。名雖多別，大約不出教行及果。但果是正名，餘並隨義，故云「不妨」等。
【譯文】【記文】在第三科之中。名稱雖然有諸多差別，但大抵不出教相、行持與極果這三種範疇。只不過「解脫之果」才是木叉的正宗定義，其餘的稱呼全都是隨順義理而借用，所以說「不妨據本」等等。

【313-0002】02_戒疏/01b_卷一上之一#101
【原文】【疏】三、云「毗尼」，亦「毗那邪」、「鼻奈邪」等，皆是傳梵之訛替耳。
【譯文】【疏文】第三、所謂「毗尼」，也稱作「毗那邪」、「鼻奈邪」等等，這些全都是翻譯梵語時所產生的音訛傳衍罷了。

【313-0003】02_戒疏/01b_卷一上之一#102
【原文】【記】「毗尼」中，初文。且列三名。或云「毗尼斯」、「鞞尼迦」、「鼻那耶」、「比泥」，竝見經、律，故云「等」也。
【譯文】【記文】在解釋「毗尼」的段落中，此為首段之文。在此暫且列出三個名號。有時稱為「毗尼斯」、或稱「鞞尼迦」、或稱「鼻那耶」、或稱「比泥」，全都可以在經藏與律藏中見到，所以說「等」。

【313-0004】02_戒疏/01b_卷一上之一#103
【原文】【疏】自古綴疏，至翻名中，並云「胡音為彼，漢譯為此」。智士立言，義不徒發，如斯釋判，沉罔祖宗，全不可也。
【譯文】【疏文】自古以來撰寫疏註的人，凡是談到翻譯外來名稱時，往往都說「胡語發音為彼，漢語翻譯為此」。有智慧的賢士確立言論，義理絕不會毫無根據地隨意發抒，像這樣混為一談地解釋判定，實在是埋沒誣蔑了正法的祖宗源頭，是絕對不可以採用的。

【313-0005】02_戒疏/01b_卷一上之一#104
【原文】【記】次辨胡梵，初科。按祖師《內典錄》，晉道安法師稱「梵」為「胡」，如彼所破。後世述疏，承彼之風，故有斯濫。「智士」等者，責其不當也。「沉罔」者，反屈佛教出於邊鄙也。
【譯文】【記文】其次在辨別「胡語」與「梵語」的段落中，此為第一科。查考祖師所撰的《大唐內典錄》，東晉道安法師習慣將「梵文」稱為「胡語」，正如那部書中所破斥的那樣。後世撰寫疏註之人，承襲了他的習氣風尚，所以才產生了這種混淆濫用。「智士」這句話，是責怪其用語大為不妥當。「沉罔」的意思，反而是委屈誣衊佛法出自邊陲鄙陋的蠻荒之地。

【313-0006】02_戒疏/01b_卷一上之一#105
【原文】【疏】何者？胡本雜戎之地，梵唯真聖之都。雪山已南，三方距海，周輪九萬，厥名「大夏」。金剛輪者，地之中心，凡聖大王，同居此土。若處邊鄙，地為之傾。
【譯文】【疏文】為什麼這樣說呢？胡地本來是各類雜居戎狄之處，而梵國則是真正聖賢出世之都城。大雪山以南，三面環繞著大海，周圍廣達九萬里，那個地方的名號稱為「大夏」。大地之中的金剛寶座，是整個南瞻部洲的正中心，凡夫的轉輪聖王與出世的法王佛陀，共同安居在這一片土地上。如果佛陀降生在邊陲鄙陋之地，大地就會為之失衡傾斜。

【313-0007】02_戒疏/01b_卷一上之一#106
【原文】【記】次科，定梵國中。初二字徵問。「胡」下，正釋，分二。上二句對明勝劣。「雜戎」者，若取《禮記》，東夷、西戒、南蠻、北狄；今此通指蕃胡邊鄙，人物兇頑，以為「戎」耳。「真聖都」者，佛及聖賢弟子，皆出彼故。「雪山」下，二、別示梵土，初明境廣。「雪山南」者，以山抵北，梵國背山面海，故但云「三方」。山後北際，亦臨大海，今明國境，故所不論。「周九萬」者，通指五印。《西域記》云：「五印度境周九萬餘里，北廣南狹，形如半月，𦘕野區分七十餘國。」今以總屬中梵，故通舉之。大國曰「夏」。「金剛」下，約事定中。一約輪座定，二約二王所居定。《釋迦方誌》云：「中天竺國如來成道樹下有金剛座，用承佛焉。」「凡王」即輪王，「聖王」即如來。《方誌》云「佛之威神，不生邊地，為傾斜故」，文意同此。
【譯文】【記文】下一個科判，在考定梵國的段落中。起初兩個字詰問發端。從「胡」以下，正式展開解釋，分為兩個部分。最前兩句相對辨明兩地的優劣。「雜戎」如果依據《禮記》所載，指的是東夷、西戎、南蠻、北狄；如今此處是通泛指稱各個蕃胡等邊鄙之地，風俗人物兇殘頑劣，所以統稱為「戎」。「真聖都」的意思，是說佛陀以及具足正信的聖賢弟子，全都在那裡出生的緣故。從「雪山」以下，第二部分是個別指出梵土邊界，起初闡明幅員廣大。「雪山南」的意思，是因為雪山橫亙在北邊，梵國背靠著雪山、面朝著大海，所以只說「三方」。雪山背後的北邊極處，同樣瀕臨大海，如今是要指明國境範圍，所以不在討論之內。「周九萬」這句話，是通指整個五印度境內。《大唐西域記》說：「五印度的國境周圍廣達九萬餘里，北方開闊、南方狹窄，形狀宛如半月，劃分分布為七十多個國家。」如今總括屬於中梵之地，所以予以統括列舉。廣大的國家便稱為「夏」。從「金剛」以下，是依憑具體事跡來判定何處是中心。第一是依據金剛寶座來判定，第二是依據輪王與法王二王所居之處來判定。《釋迦方誌》說：「中天竺國如來成道的那棵菩提樹下設有金剛寶座，用來承載托負佛身。」「凡王」指的是轉輪聖王，「聖王」指的就是如來。《方誌》說「佛陀的大威神力，絕不誕生在邊緣下劣之地，因為大地會為之傾斜歪倒」，其文義與此處相同。

【313-0008】02_戒疏/01b_卷一上之一#107
【原文】【疏】此方中岳，亦號「中華」，且據軒轅，局談中表。故《河圖》云：「崐崘東南方五千里，號曰神州，亦稱赤縣。」
【譯文】【疏文】我們漢地的中嶽嵩山，雖然也稱為「中華」，但這只是依據軒轅黃帝的時代，局促地在自我疆域內自談內外中心而已。所以《河圖》說：「崑崙山的東南方五千里處，名號稱為神州，也稱為赤縣。」

【313-0009】02_戒疏/01b_卷一上之一#108
【原文】【記】顯此方中。此有五嶽：東嶽泰山、南嶽衡山、西嶽華山、北嶽恒山、中嶽嵩山。「軒轅」即古黃帝之號。《史記》云：「居軒轅之丘，故以名焉。」、「有土德之瑞，名黃帝。」舊云軒轅以中嶽嵩山為此國之中，或云且據軒轅所統為言耳。此說震旦一國言「中」，若望梵國還成邊土，故云「且據」等。「中表」，「表」邊也。「故」下，引證。在山「東南」，非中明矣。「神州」者，《物理論》云「地神曰祇。大曰黃地祇，小曰神州」，是則神主其地，故得名也。「赤縣」者，或云帝王南面，南方赤故；或云取中心之處，縣即境邑之通名。然上所釋，並據王者居處為言。今此通解，但是震旦異名，總目一國耳。
【譯文】【記文】在顯明此方漢地真實地理位置的段落中。漢地有五大名山：東嶽泰山、南嶽衡山、西嶽華山、北嶽恆山、中嶽嵩山。「軒轅」就是古代黃帝的名號。《史記》記載：「他居住在軒轅之丘，所以以此為名。」、「因具有土德應和的祥瑞，所以名為黃帝。」自古相傳軒轅氏以中嶽嵩山作為漢地的中心，或者說是暫且依據軒轅氏所統轄的疆域來立論而已。這只是在震旦一國之內自稱「中心」，如果相望於中天竺梵國而言，漢地依然屬於邊陲偏土，所以說「且據」等等。「中表」之中，「表」是外邊的意思。從「故」以下，引證古代緯書說明。位在崑崙山的「東南方」，顯然不是世界的中心，這就很清楚了。所謂「神州」，《物理論》說「地神稱為祇。廣大的稱為黃地祇，細小的稱為神州」，這說明是有神明主宰該處土地，因此而得名。所謂「赤縣」，或者有人說是帝王坐北朝南稱尊，南方屬火為赤色之故；或者有人說是取天下的中心地帶之意，「縣」就是疆域城邑的通稱。然而上述種種解釋，都是依據人王所居之處來談論的。如今此處予以通盤理解，這些都只是震旦漢地的不同異名，用來總括稱呼我們這一國土罷了。
