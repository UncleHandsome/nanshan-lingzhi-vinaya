# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】釋中初文，初敘非。「一」下列過有四：凡行受日，一須緣現，二是的實，三知日數，四即稱法。如下舉例，律中無事有法羯磨不成，年歲不滿受戒不得
【譯文】解釋的首段文字中，首先敘述非法的過咎。自「一則」以下列舉過失有四點：凡行受日法，一須事緣現前，二須確鑿真實，三須明知日數，四須合乎教法。如下文舉例，律中無事徒具法式則羯磨不成，年歲未滿受戒則不能得戒。

【譯文】第二段中，詰難者以安居時分配房舍若有剩餘、應當為未來僧眾代受為例，比照現在的懸受怎會不成就？答文中「對事進不」，是指僧人來與不來無法確定，以此顯明現在的受日法有法定儀軌開許成就，必須具備真實事緣以相應於法規。

【375-0004】02_戒疏/19d_卷四下之一#120
【原文】【疏】凡眾物共有，眾情非一。既同和作法，賞他知事。輒便悔反，謗僧隨愛。駭動群心，喜生鬬諍，迭相苦惱，不得安樂修道。《多論》三意如此，故制。
【譯文】【疏文】凡是僧團的物資皆為大眾所共有，而大眾的心意往往各不相同。既然當初大眾和合共同作法，決定賞賜給辛勞負責事務的人，事後卻又擅自反悔翻異，毀謗僧團是徇私偏袒。這必將驚擾擾動大眾的道心，極易滋生是非爭端，使得彼此相互痛苦煩惱，再也無法安樂修持正道。《薩婆多論》所指出的三種制戒用意正是如此，因此佛陀制定本戒。

【375-0005】02_戒疏/19d_卷四下之一#121
【原文】【記】七十四，制意中。初敘同法。「輒」下，次明反謗。「駭」下，示過惡：一、生諍，二、相惱，三、廢道業。「《多論》三意如此」者，彼云：「為滅鬪諍故，為滅苦惱故，為得安樂行道故。」
【譯文】【記文】第七十四條制戒用意之中。首先敘述共同如法行事。「輒」字以下，其次說明事後反悔毀謗。「駭」字以下，指陳由此引發的重大過患：一是滋生爭執，二是彼此惱害，三是荒廢修道。「《薩婆多論》三意正是如此」，論中說道：「一為了息滅鬥諍，二為了平息痛苦煩惱，三為了大眾能安樂行道。」

【375-0006】02_戒疏/19d_卷四下之一#122
【原文】【疏】論犯四緣：一、是僧物，《十誦》、《五分》、《僧祇》云「施現前僧應分物」，故知非是常住物；二、同法賞知事已，《多》云「凡僧和合，不問羯磨不羯磨，若執苦人、大德、貧匱，和與物已，訶者亦提」；三、輒便悔反；四、言詞了，犯。
【譯文】【疏文】論述構成犯戒的四個條件：一、賞賜之物屬於僧團公物，《十誦律》、《五分律》、《僧祇律》均指出「施現前僧應分物」，由此可知並非屬於不可分割的常住公物；二、大眾已依法一致賞賜給辦事有勞之人，《薩婆多論》說「凡僧眾和合，不論是否經過白二羯磨作法，只要針對承擔勞役辛勞之人、長老高德、或貧困匱乏之人，經大眾和合商定賜予物品之後，再行呵斥反悔者，一概判犯波逸提」；三、事後擅自反悔翻異；四、反悔指責的言詞表達完畢，即構成犯罪。

【譯文】【疏文】第二、十方現前僧物。例如已故比丘所遺留下來的遺物，上自最崇高的羅漢聖僧，下至剛出家的沙彌，人人皆有一份均分權利。但必須依法舉行羯磨作法，正式宣告隔斷其他十方未至之僧，僅以當時集會的在場大眾作為分配對象。

【375-0020】02_戒疏/19d_卷四下之一#136
【原文】【疏】三、常住者。以當局淨住，通於三世，局定不動，亦不可分也。
【譯文】【疏文】第三、常住僧物。這是指定專屬於某一特定寺院道場，貫通過去、現在、未來三世，性質永久固定不得轉移變動，也絕對不可私自變賣分攤。

【375-0021】02_戒疏/19d_卷四下之一#137
【原文】【疏】四、現前常住。如造熟食，本擬寺僧，情通主客，不許出外故也。
【譯文】【疏文】第四、現前常住僧物。例如寺院每日烹調好的熟食供飯，本來就是為了供養本寺僧眾，但此飲食之情兼通款待往來的各方主客僧人，絕對不准私自攜帶運出寺外。

【375-0022】02_戒疏/19d_卷四下之一#138
【原文】【記】列釋中。初物得將賞人，故指「此戒」。「施池井」者，《律》云為造池造井等，因而施物。「就」下，示名義。二中，初明十方義。「極聖」即無學。「下至沙彌」，總收聖凡、大小之眾。「作法」下，即現前義。三中，上三句局處定，下一句不同分。或處雙疊為名，餘處亦名「四方僧物」。「淨住」，即伽藍之異名。四中，亦名「十方常住」。「不許出外」，即示名也。
【譯文】【記文】列出解釋之中。第一種現前僧物可以用來賞賜給有功辦事者，所以此處特別指明「本戒所指」。「施水池水井」，是指律文記載信眾為了建造水池、水井等因緣，特意布施給負責僧人的物品。「就」字以下，揭示其名稱涵義。第二種中，首先說明屬於「十方」的義理。「極聖」指無學阿羅漢。「下至沙彌」，全體涵括了聖者與凡夫、大僧與小眾。「作法」以下，即是轉化為「現前」的義理。第三種中，前三句說明處所永遠固定，最後一句說明不得予以私分。有的地方將處所名稱疊用，在其他文獻中亦稱為「四方僧物」。「淨住」，是僧院伽藍的另一種別名。第四種中，在其他地方亦稱為「十方常住僧物」。「不許攜出寺外」，正是點明其名稱實質。

【375-0023】02_戒疏/19d_卷四下之一#139
【原文】【疏】四種之中，初物是和，可以賞也，第二義通，後兩全閉。
【譯文】【疏文】在這四種僧物之中，第一種物品已經過大眾和合共議，可以用來酬謝賞賜；第二種物品在義理上經作法後亦能通融賞賜；至於後兩種，則完全封閉絕對不可拿來私相賞賜。

【375-0024】02_戒疏/19d_卷四下之一#140
【原文】【記】簡判中。前二並通，是可分故。後二全閉，是常住故。
【譯文】【記文】分析裁決之中。前兩種物品都能通融動用，因為它們本來就屬於可以分割分發的資財。後兩種物資則完全嚴加封閉不可動用，因為它們純粹屬於寺院永久所有的不可分常住物。

【375-0027】02_戒疏/20a_卷四下之二#3
【原文】【疏】凡如法事，理宜同遵，許無乖競。今停僧作法，輒便捨者，心不和同，障礙僧事，惱眾不輕，故制。
【譯文】【疏文】大凡符合戒律的僧團事務，按理應當共同遵從，以期沒有違逆與抗爭。現在若暫停僧團行作羯磨，隨意擅自捨離離去，便是內心不和合協同，障礙了僧團事務，擾惱大眾的情節非輕，因此制定此戒。

【375-0028】02_戒疏/20a_卷四下之二#4
【原文】【記】七十五，制意。初敘僧法。「今」下，明起過。「停」，止也。
【譯文】【記文】第七十五條，制戒意圖。首先敘述僧團如法之事的常理。「現在」以下，說明過失的生起。「停」，是止息暫停的意思。

【375-0029】02_戒疏/20a_卷四下之二#5
【原文】【疏】論犯五緣：一、是如法僧事；二、知如法；三、不與欲；四、輒起去；五、雙足出門犯。
【譯文】【疏文】論及其犯戒的五個條件（五緣）：第一、是合乎戒律的僧團事務；第二、明知是合法的；第三、沒有給予同意權（不與欲）；第四、擅自起身離去；第五、雙腳跨出門檻即構成犯戒。

【375-0030】02_戒疏/20a_卷四下之二#6
【原文】【記】犯緣。第一，「如法」，簡非法無犯，準下又局斷諍，簡餘法但輕。
【譯文】【記文】犯戒條件（犯緣）。第一點，「合乎戒律」，是為了排除非法的羯磨則不犯戒；依據後文來看，此戒又特別局限於裁斷諍事的羯磨，排除其餘的僧事，若擅離則僅犯輕微過失。

【375-0031】02_戒疏/20a_卷四下之二#7
【原文】【註】佛在舍衛。多比丘集，論法毗尼。六群相謂「看諸比丘，似為我等作羯磨」，從座起去。比丘喚住而故去。以事白佛，便訶而制戒。
【譯文】【註文】佛陀住在舍衛國。許多比丘聚集，討論佛法與毗尼。六群比丘彼此私語說：「看那些比丘的樣子，好像要為我們作處分的羯磨」，便從座位起身離去。其他比丘出聲呼喚挽留，他們仍故意離去。比丘們將此事稟告佛陀，佛陀便喝責他們並制定此戒。

【375-0032】02_戒疏/20a_卷四下之二#8
【原文】【律】若比丘，眾僧斷事未竟，不與欲而起去，波逸提。
【譯文】【律文】若有比丘，在僧團裁斷爭議尚未結束時，不給予同意權便起座離去，犯波逸提罪。

【375-0033】02_戒疏/20a_卷四下之二#9
【原文】【註】若斷事未竟，動足出戶外者，犯墮。一足在戶內，方便欲去而不去，吉羅。尼波逸提。不犯者，若與欲，若口噤。若非法羯磨，若為僧、塔、寺、和尚、闍棃、同學作損減，不與欲而去者，得。
【譯文】【註文】如果裁斷諍事尚未結束，動步邁出門戶之外者，犯墮罪（波逸提）。一隻腳在門戶之內，起意想要離去卻未真正離去，犯突吉羅罪。比丘尼亦犯波逸提。不犯戒的情況：如果已經給予同意權，或者因病口不能言（口噤）；如果是違法的羯磨；若是為了避免僧團、佛塔、寺院、和尚、阿闍梨、同學遭受損害，不給予同意權而離去者，是可以開許的。

【375-0034】02_戒疏/20a_卷四下之二#10
【原文】【疏】此唯斷四諍事，不與欲者提。餘者吉羅。如《戒本》、《鈔》說。
【譯文】【疏文】這裏唯獨局限於裁斷四種諍事的場合，不給予同意權而離去者才結波逸提罪。其餘的僧務羯磨則僅結突吉羅罪。詳如《戒本》與《事鈔》中所說。
