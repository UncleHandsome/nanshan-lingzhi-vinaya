== PROBLEM ==
將《業疏》誤譯為《含注戒本疏》。南山三大部中，《四分律刪補隨機羯磨疏》簡稱《羯磨疏》或《業疏》；而《含注戒本疏》簡稱《戒疏》或《戒本疏》。此處引文出自《羯磨疏》，譯文張冠李戴。 段027開頭的記文（「好往婬女家……成八五也」）被提前塞入段026譯文末尾，導致段026增譯、段027段首漏譯。 段043開頭「樂住〔有食有法，雖遣不應去。〕」被提前翻譯在段042末尾，導致段043段首漏譯。

== SUGGESTION ==
改為「如果依照祖師的《隨機羯磨疏》（業疏），則必定是以《五分律》為準則……」 將段026末尾「、喜好前往婬女家中（後面的六組五事中……構成了八組五事）」移回段027譯文開頭。 將段042末尾「，歡喜安樂留住（有飲食也有佛法，縱使師長遣趕也不應離去）」移至段043譯文開頭。

== ORIG ==
若準《業疏》，定依《五分》，彼云：豈同古人雷同受後。

== CURRENT ==
文中採取「兩者並存」的說法，顯示這裡還沒有下定論。如果依照祖師的《含注戒本疏》，則必定是以《五分律》為準則，疏中說：哪能像古人那樣隨便盲從，把加持放在受戒之後呢！現今有些地方另外設立一位「持衣阿闍梨」，在別的處所預先給受戒者受衣缽，這在義理上雖然沒有大錯，但並不是祖師的原意。下文「并……」，是展示缽盂的儀軌。第三科中，「不實」，是指受戒者身上帶有遮難；「實」，就是身心清淨無染。「浪」，就是虛妄。下文引用律文開示，是藉由舉出聖者的例子來警戒凡夫，勉勵受戒者一定要說實話。然而對於輕微的遮難，有時也能通融通納，此處是專就嚴重的遮難而言的。第四科中：
