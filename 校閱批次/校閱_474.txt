# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】若是上座，正如《五分律》所說，就是座中之上更無長者。《毘尼母論》依僧夏戒臘將上座局限於具德長老，這是不宜依準的。所以《十誦律》說：上座一人是代表補缺如來之位。如果上座有所衰朽缺損，次座也可以秉法，如同身子（舍利弗）作為轉法輪大將，有時也參與替佛說法。如果上座與次座兩人皆不堪任，能誦律者列為第三位，這並非僅指會背誦經文，必定要同時通曉義理。如果是不會背誦律文的人，雖然不能連綴字句、連篇累牘地背誦，但通曉明達羯磨的成與敗，所以律文說「能堪能者作」。不誦讀律本的人尚且要挑選具備堪能者，何況謹慎誦文的人，豈能不揀擇其義理的通達與窒礙！

【474-0007】03_業疏/07b_卷二之一#20

【譯文】下一科中，首先解釋「上座」。《五分律》與《十誦律》之文通於老少，只要座中無更長者即是上座，這是如今所採取的觀點。《毘尼母論》之所以局限，是因為彼論說「從無戒臘至九夏為下座，十夏至十九夏為中座，二十夏至四十九夏為上座」。《十誦律》中上座身為僧首替補佛位，末世庸碌鄙陋之人怎可濫竽充數？「必有」以下解釋「次座」。「有所壞」是指前述上座精神昏憒、戒德有所缺失而不能勝任。《大智度論》說舍利弗是第二位轉法輪的大將，有時替佛說法說戒。《彌勒下生經》說：「大智舍利弗能隨佛轉法輪，是佛法中的大將。」「身子」是華語翻譯，因其母親身材端好，兒子隨母親之名稱呼，所以稱為身子。「上二」以下解釋「能誦律者」。「上二不堪」為一句，句意已盡。「若不」以下解釋「不誦律者」。此處依據挑選堪能者的標準，判定前面誦文者必定兼具解義之能。地位雖然分為四種差別，但通曉堪能的要求必定相同。「通塞」就是指對律義的明達與昏昧。

【譯文】就前一部分又分為兩段：首先是「單白」，是提呈申明其事而告白僧眾；這既然不是輕微簡約之事，義理上必須詳細陳述，所以還要再通過羯磨問答和合同議才能最後裁定。

【474-0016】03_業疏/07b_卷二之一#29
【原文】初白分五
【譯文】最初的單白文分為五句。

【474-0017】03_業疏/07b_卷二之一#30
【原文】一、「大德僧聽」者，恐妄緣事，無情同秉，故初總告，誡耳識也
【譯文】第一句「大德僧聽」，是恐怕僧眾胡思亂想緣涉他事、心不在焉地共同秉法，所以在最初作總體宣告，以誡敕大家的耳識專注諦聽。

【474-0018】03_業疏/07b_卷二之一#31
【原文】二、「此住處」下，牒緣告眾，擬成本業也
【譯文】第二句從「此住處」以下，是提呈申明相關因緣以告白大眾，旨在成就根本的羯磨僧業。

【474-0019】03_業疏/07b_卷二之一#32
【原文】三、「若僧時到僧忍聽」者，法事契會謂時到也，詳集同舉謂忍聽也。今約心和，勸聽可也；前約身和，勸聽聞也。兩聲別召，事義亦乖，不解兩緣，名非數也
【譯文】第三句「若僧時到僧忍聽」，各項法事因緣契合齊備稱為「時到」，審慎集會共同舉事稱為「忍聽」（容忍聽許）。此處是就「心和」而言，勸請大家表示認可同意；前面的第一句是就「身和」而言，勸請大家側耳聽聞。這兩種讀音分別召請不同的含義，事相與義理也各不相同，如果不理解這兩種因緣，就不能稱作合格的僧數。

【474-0020】03_業疏/07b_卷二之一#33
【原文】初解文相。單白第三句初通釋「法事契會」等者，謂能所相應，稱可眾心故。「今」下別點，「聽」字平、去兩音，前後須別
【譯文】首先解釋文句相貌。單白第三句中，最初通解「法事契會」等語，是指能秉與所秉互相相應，符合大眾的心意。「今約」以下特別點明，「聽」字有平聲（聽聞）與去聲（聽許）兩種讀音，前後兩處必須有所區別。

【474-0021】03_業疏/07b_卷二之一#34
【原文】四、「僧今於此相內結」下，單牒根本，勸僧同決，不可遲疑也
【譯文】第四句從「僧今於此相內結」以下，是單獨提呈根本要務，勸請僧眾共同裁決，不可遲疑不決。

【474-0022】03_業疏/07b_卷二之一#35
【原文】第四句初科可解
【譯文】第四句的第一科淺顯易解。

【474-0023】03_業疏/07b_卷二之一#36
【原文】前第二句緣本雙陳者，「住處比丘」緣也，「唱大界相」本也。及至第四，緣是傍疎，本是親正，故直舉示，決通和相也
【譯文】前面的第二句之所以因緣與根本雙雙陳述，是因為「住處比丘」是因緣，「宣唱大界相」是根本。到了第四句，因緣屬於次要疏遠之端，根本才是親切核心之旨，所以直接提呈昭示，以裁定通達和合的相貌。

【474-0024】03_業疏/07b_卷二之一#37
【原文】二中，躡前第二，對辨雙單。緣謂先敘因由，本即正陳所為。前是告眾，義必雙標；後決成和，文須單舉
【譯文】在第二段中，承接前面的第二句，對比辨析雙陳與單舉的差別。「緣」是指先敘述起事的因由，「本」就是正式陳述當前所作的要務。前面是宣告大眾，義理上必須將因緣與根本雙雙標明；後面是裁決成就和合，文詞上則只需單獨舉出根本要務。

【474-0025】03_業疏/07b_卷二之一#38
【原文】列二同者，結界所為，非正結事，當時為說戒故，便結此界，因牒入法。律本多然，戒相竝是，不可怪也
【譯文】列出「二同」，是結界的目的，並不是正要結界的核心法事本身；當時是因為要說戒的緣故，才結這個界，因此順便牒入羯磨法中。律本大多是如此，戒相也全都是這樣，不足為奇。

【474-0026】03_業疏/07b_卷二之一#39
【原文】三中，初示意。結界本出〈布薩犍度〉，因集說戒奔馳疲頓，故聽別結，即以二同牒入羯磨。如下文云「不著亦得」，明非羯磨所被正緣。「律」下舉例，律本羯磨多用緣起牒入法中，如冶諫等，故曰「多然」；又諸戒相，竝用前緣牒入戒本，如盜、殺等，舉之可知，故云「竝是」。
【譯文】第三項中，首先說明用意。結界本來出自〈布薩犍度〉，因為大眾聚集說戒奔波勞頓，所以聽許另外結界，也就是把「二同」牒入羯磨之中。如同下文所說「不寫也可以」，說明這並非羯磨所針對的正緣。自「律」字以下是舉例說明：律本中的羯磨大多採用緣起牒入法中，例如冶諫等，所以說「大多如此」；又如各條戒相，全都用先前的因緣牒入戒本，例如盜戒、殺戒等，列舉便能明白，所以說「全都是這樣」。

【474-0027】03_業疏/07b_卷二之一#40
【原文】五、「白如是」者，事已達僧，更無餘慮，故結上務，知作業也
【譯文】第五、「所宣告的如同上述」這句話，是指事情已經通達僧眾，再沒有其他疑慮，所以總結上面的事務，使眾人知曉正要造作羯磨業事。

【474-0028】03_業疏/07b_卷二之一#41
【原文】第五句，「如是」二字，指示之辭，謂所白事如是而已，即結上也
【譯文】第五句中的「如是」二字，是指示之詞，意思是宣告的事項就像這樣而已，也就是總結上面所說的內容。

【474-0029】03_業疏/07b_卷二之一#42
【原文】就後羯磨又分為三：初從「大德僧聽」下至「誰諸長老忍」，明作業將決，情事須和，還牒白中第二緣本雙牒以告情也。二「今僧於此相內」下至「不忍者說」，還牒白中第四單本重告大眾，勸僧和決，語默表情，不可久也。三「僧已忍」下，眾情陳露，默顯通和，故牒本情持之在事也
【譯文】就後面的羯磨又分為三：第一、從「大德僧聽」以下至「誰諸長老忍」，說明作業即將表決，心意與事由必須和諧，便回扣白文中第二句，將緣起與事本雙牒，以宣告情實。第二、從「今僧於此相內」以下至「不忍者說」，回扣白文中第四句單牒事本，再次宣告大眾，勸請僧眾和合表決，以言語或默然來表達心意，不可拖延太久。第三、從「僧已忍」以下，大眾的心意已經表露，以默然顯現全體和合，所以牒出原本的心意，並在法事上切實受持。
