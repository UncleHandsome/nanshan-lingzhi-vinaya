# 校閱材料　第686檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【686-0001】03_業疏/18b_卷四之一#101
【原文】長周尺量者，律云長佛二搩手，廣一搩手。佛在人倍，人長八尺，佛則丈六，並依周尺以定律呂也。更增半搩者，謂截竟加半搩耳，非謂相連說增也。故佛滅度後一百年之時，毗舍離國擅行十事，「不割縷淨」是其一擅。今世盛有，即䟦闍風，妄情難信，但準聖言，自無咎也
【譯文】以周朝長尺來度量坐具，律中說長度為佛的二搩手，寬度為一搩手。佛的身量是常人的兩倍，常人身長八尺，佛的身長則是一丈六尺，這都是依周尺來配合律呂（法定準則）而制定的。「更增半搩」是指裁剪完成後另外加上半搩手的緣邊，並不是指連同布料主體直接說加大。所以佛滅度一百年時，毗舍離國跋闍子比丘擅自推行十事非法，其中妄執「坐具不裁截邊緣亦屬合律之淨法（不割縷淨）」便是其擅自行事之一。如今世間盛行這種作法，正是跋闍之遺風，凡夫妄情難以憑信，只要遵照聖人的教言，自然就沒有過咎。

【686-0002】03_業疏/18b_卷四之一#102
【原文】二中初明初量。佛一搩手長二尺，人止一尺。律呂猶準則也，六律六呂，氣候不差故。「更下」，次明增量。初示增法。「故下」，引斥妄行。䟦闍十事，《資持》具引。「擅」謂專輙。「不割縷淨」，謂統同增量，如法無過
【譯文】在第二部分中，首先說明最初的應量。佛的一搩手長二尺，常人只有一尺。「律呂」猶如準則，因為六律、六呂與天地節氣時候絲毫不差。自「更增」以下，其次說明增量的規定。先指示增量之法。自「故佛滅度」以下，引古例斥責妄行。跋闍十事，《資持記》中有詳細引述。「擅」是指專擅妄為。「不割縷淨」，是指彼等妄執將坐具統同一體加大尺寸，是合於戒律而無過錯的淨法。

【686-0005】03_業疏/18b_卷四之一#105
【原文】如《僧祇》可教誡者，情多樂廣，喜受偽法，故遮惡緣，預設防禁。今不披律，至廣長作，正法滅身也；除依教行，正法生身也。執此兩途，增漏障道也
【譯文】如《摩訶僧祇律》所說應受教誡之人，凡情往往喜好寬大，樂於接受偽妄之法，所以佛陀遮止惡緣，預先施設防範禁制。如今若不展閱律典，乃至將坐具作得極其寬長，這是正法在自身滅沒；若能依教奉行，正法便在自身生起。若偏執於這兩種途徑，便會增長煩惱漏疾而障蔽道果。

【686-0006】03_業疏/18b_卷四之一#106
【原文】四中初示律意。「今」下斥非，法之興廢在於一身，可不慎乎！違教則如病須藥，依教則病差藥有，二俱障道，情不可留也。注中諸相，並見《鈔》、《記》。
【譯文】在第四項中，首先開示律文的本意。「今」字以下斥責非理，佛法的興盛與廢墜全在於個人一身，怎能不謹慎呢！違背教法就像生了病必須用藥，依從教法則病已痊癒卻仍執著藥物不捨，這兩者都障礙道業，凡情執著絕不可存留。註文中的各種行相，都見於《事鈔》與《資持記》。

【686-0007】03_業疏/18b_卷四之一#107
【原文】言不得淨施者，以宅所履，本制須之，必受持也。自餘聽畜，方開淨施。今多說淨，無有受者，不可怪也。說淨猶次，但無準的
【譯文】所說坐具「不得作淨施」，是因為它是安居鋪墊、坐臥所履踐之物，本律規定必須具備，所以必須加法受持。其餘聽許蓄留之衣物，才開許作說淨施。如今大多只是行說淨法，卻沒有依法受持者，不足為怪（因其不知教法）。說淨法尚屬次等，只是沒有切實的依準。

【686-0008】03_業疏/18b_卷四之一#108
【原文】五中初明制受，非長故不聽淨。「宅」，居也。「今下」，斥非。「不可怪」者，不知教故。「說淨次」者，次於受持，勝不受故
【譯文】在第五項中，首先說明制定應當受持，因為它不是長物，所以不聽許作說淨。「宅」即安居之意。「今」字以下，斥責非理。「不可怪」這句話，是因為彼等不知教法之故。「說淨次」是指，說淨之法次於受持法，但還是勝過全不受持。

【686-0017】03_業疏/18b_卷四之一#117
【原文】初中，以出家務道，本不謀食，然有待形假資方就。俗則餚膳方丈，無思厭背；道則不雜種食，一鉢知足。然古佛道法以為標幟，非聖自制，餘無知者。如《五分》引，誠為後式
【譯文】在第一項制意中，出家人專務修道，本來不謀求飲食，然而有所待託的色身，必須借助資糧才能修成道業。世俗之人則菜餚膳食羅列滿案，毫無厭離背棄之心；出家之道則不混雜多種食物，一鉢即生知足之心。然而這也是過去諸佛的道法，以此作為標幟，若非大聖佛陀親自制定，其餘之人無從得知。如《五分律》所引之文，確實是後世的典範法則。

【原文】緣中初科，指鈔四藥皆以時限為名：五正不正為時，清漿為非時，酥蜜等為七日，不任食者為盡形
【譯文】在因緣中的第一科，指明《行事鈔》中四藥都是以服用的時限來命名的：五種正食與非正食名為「時藥」，澄清果漿名為「非時藥」，酥油石蜜等名為「七日藥」，不堪充當常食的藥物名為「盡形壽藥」。

【譯文】就經文中的「手受」而言，《薩婆多論》說明手受有五種意旨，以防範盜取之相為根本，其餘如《戒疏》所說。第二引述「口受」，是為了施加法式延長時限，使其能夠度過規定的服藥時限。《十誦律》說：「這三種藥，若是留置過夜不淨，無病之人全都不合受持。」反觀上述規定，若無過失則可施加口法受持。

【686-0046】03_業疏/19a_卷四之二#5
【原文】次科，手受五意：一斷盜緣，二求證，三止謗，四少欲知足，五令他生信。口受延時為對病故。《十誦》舉宿收二（宿、不淨收二，煑、惡觸等），此謂藥有過也；無病非開緣也。藥穢則雖病不開，無病則藥淨亦閉
【譯文】次一科中，手受有五種意旨：一是斷絕偷盜的因緣，二是尋求見證，三是止息世人譏謗，四是彰顯少欲知足，五是令他人心生信敬。口受法用以延長時限，則是針對疾病的緣故。《十誦律》說藏宿包含兩種（宿食、不淨包含煮食與惡觸等過患），這是指藥物本身有過失；而沒有疾病則不是開許的因緣。藥物若有污穢，即使有病也不得開許；若沒有疾病，即使藥物清淨也同樣閉塞不開許。
