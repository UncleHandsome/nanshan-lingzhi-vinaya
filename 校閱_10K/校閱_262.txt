# 校閱材料　第262檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【262-0001】01_行事鈔/11c_卷下之三#32
【原文】二明四儀法。夫成善有由，憑教相而心發；冥因顯果，藉儀形而立宗。是以阿說身子，具列昔經；傳法軌模，亦題方冊。故直敘一致，別引諸說云云。《五分》：若四威儀不如法者，非為於世而作大明。《僧祇》：若行時，平視；迴時，合身迴。《中含》：佛告比丘，依於狩王法。若平旦，著衣持鉢，入村乞食，善護持身，守攝諸根。乞食已，收舉衣鉢，澡洗手足，以尼師壇著於肩上，至無事處，或經行、坐禪。復於初夜，經行坐禪，淨心中障已。於中夜時入室欲臥，四牒憂多羅，敷床上，襞僧伽梨作枕，右脇而臥；當頭面向佛像處，足足相累，意係想明相。彼後夜時，速起，如初夜法。《僧祇》：頭向衣架，及和尚、長老比丘。初夜，思惟自業。至中夜，右脇著下，累兩脚，合口，舌拄上齗，枕右手，舒左手順身上；不捨念慧，思惟起想。餘如上。《十誦》：燈明中不得臥。
【譯文】第二、說明行住坐臥四威儀之法。成就一切善法皆有其根由路徑，依憑戒相教化而使菩提善心萌發；冥冥之中的修因顯發昭著的果報，正是藉由外在端正的威儀形貌來樹立根本綱宗。因此阿說示（馬勝比丘）以威儀折服度化舍利弗（身子）的公案，具體載錄於往昔的經典中；流傳佛法的法度典範，也始終銘刻於竹簡典籍之中。所以先直接敘述其一貫的宗趣，再分別引述諸部律論之說等等。《五分律》說：如果行住坐臥四威儀不如法，便不能在世間作為照破黑暗的大光明。《摩訶僧祇律》說：行走的時候，應當目光平視前方；轉身轉向的時候，應當整個身軀一同轉動（不可只扭動頸項）。《中阿含經》說：佛陀告訴比丘，應當依循如獅子獸王般安詳威嚴的法則。清晨黎明時，穿著袈裟僧衣，托著瓦鉢，進入村落乞食，善加護持自心色身，嚴格守護收攝諸根。乞食完畢之後，收拾收好衣鉢，洗滌手足，將坐具（尼師壇）搭在肩膀上，前往寂靜無雜務的林野空處，或者經行漫步、或者坐禪。又在初夜時分，經行坐禪，清淨化除自心之中的煩惱障礙。到了中夜時分，進入室內準備就寢，將鬱多羅僧（上衣、七衣）摺疊成四層鋪在床上，將僧伽梨（大衣、九條衣）摺好充當枕頭，身體朝右脇而臥（吉祥臥）；頭部應當面朝佛像的方位，雙腳上下相疊，心念專注繫念於光明之相。到了後夜時分，應當迅速起身，如同初夜時的方法一樣坐禪經行。《摩訶僧祇律》說：睡眠時頭部應當朝向掛衣架，以及和尚、長老比丘僧房的方向。初夜時，專意思惟自己的善惡行業。到了中夜，右脇在下貼席而臥，雙腳相疊，嘴唇閉合，舌尖抵住上牙齦，右手充當枕頭枕於頭下，左手伸直順沿貼在身體上；不捨棄正念與正慧，心念時刻思惟預備清晨醒轉而起之念。其餘規矩如同上述。《十誦律》說：在明晃晃的燈光之中不得直接睡臥。

【262-0002】01_行事鈔/11c_卷下之三#33
【原文】《毘尼母》：比丘欲行時，先掃除房內；衣服床褥，如法安置，在〈隨相〉中。去時，白和尚阿闍梨。若過十臘，有法事，必能利益者，雖師不聽，自往無過。去時，出寺外，望去處方，應思量行伴何似？正見不？有病相料理不？如我心所作不？其人威儀常攝不？非懈怠不？為利為衰？若必好者共去。復問同伴：「汝等衣鉢，乃至一切自隨之物，無所忘不？」兼復誡勅：「今當共行，汝等時言少語，守攝諸根；路中處處見者，皆令歡喜，發其善心。」諸下座皆合掌互跪，對曰：「如教歡喜奉行！」若有住止，發時，上座應遍看，無遺落物不。下座常在前，上座在後；語諸下座，各自攝心，莫令散亂。下座得病，上座應為說法，令善心相續。雖有急難，不得捨去，盡其筋力，令其得脫；乃至自力不能，應至郡縣檀越所重比丘，大臣、國王門前營理；使得解脫，莫使受苦。《僧祇》：行時先下脚跟，後下脚指。在道行欲宿，遣二年少比丘前覓宿處，索前食後食；當白非時入聚落；得已還報，應展轉相白入。《智論》：出入來去，安詳一心；舉足下足，觀地而行；為避亂心，為護眾生故。是不退菩薩相。
【譯文】《毘尼母經》說：比丘若要遠行啟程時，必須先將僧房內部打掃乾淨；各項衣服、床鋪、被褥，應當按照如法的方式收拾妥當安置好，詳見〈隨相〉篇中。動身離開時，應當向和尚（親教師）、阿闍梨（軌範師）稟白辭行。如果戒臘已經超過十夏，外出若有弘法佛事，且確信必定能夠利益佛法眾生的，縱使師父不准許，自己前往也沒有過失。出發時，走出寺門之外，遙望所要前往的方位，應當審慎思量同行的旅伴為人究竟如何：是否具足佛法正見？同伴生病時能否互相照料看護？行事是否能與我同心協力？那人的行住威儀是否能時常收攝整肅？是否不是懈怠放逸之流？同行究竟是有益於修道還是會導致道業衰退？如果是確切良善之伴侶，方可共同上路。出發前還要詢問同伴說：「你們的衣鉢、乃至一切隨身攜帶的物品，沒有遺忘什麼吧？」並且還要嚴肅誡勉告誡說：「如今我們共同行路，你們應當合乎時宜而說話，盡量少說話，嚴格守護收攝各部根門；沿途無論何處見到世人，都要令他們見到威儀心生歡喜，啟發其歸向三寶的善心。」諸位戒臘較淺的下座比丘都應當合掌胡跪，回答說：「謹遵教誨，歡喜依教奉行！」如果途中有停留寄宿之處，每次啟程時，上座比丘應當巡視各處看遍，檢查是否有遺失遺落的物品。行走時，下座比丘應當常在前面走，上座比丘在後面隨行；上座應當隨時告誡諸下座說：各自收攝身心，切莫令心念散亂放縱。下座比丘如果患病，上座應當為他宣說佛法，令其菩提善心相續不斷。途中縱使遭遇危急災難，上座絕不得拋棄患病弟子離去，必須竭盡自己的筋骨體力，令患病者得以脫離險境；乃至自己個人力量無法解決時，應當前往當地的州郡縣官、施主所敬重的德高長老比丘、以及王公大臣、國王的門前求助奔走經理；務必使其脫離危難，莫讓他獨自遭受苦楚。《摩訶僧祇律》說：行走邁步時，應當腳後跟先著地，隨後腳趾再著地。在路上行進如果打算投宿，應當預先派遣兩位年輕比丘先行前往尋找借宿之地，並尋訪次日的早齋（前食）與午齋（後食）；進村前應當先作「非時入聚落」的稟白作法；覓得住處與飲食後返回稟報，眾人應當輾轉互相稟白之後再共同入村。《大智度論》說：進出往來行走之際，步履安詳端莊、內心專注一心；舉足抬腳、下足踏地之時，目光常觀注地面而行；這樣做既是為了避免自心散亂，也是為了愛護地面微細眾生不加傷害。這就是行持不退轉的菩薩之相。
