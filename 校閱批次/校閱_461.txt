# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【461-0001】03_業疏/06a_卷一之六#42
【原文】三中，初結非法。據前但收善惡二性，然皆出昏情，無非無記，故通三也。業是集因，故能感果。「反」下示如法。集是世間因，通含善惡，如雖是善，不了成滯，非出離因，故亦須離。此言離者，非謂捨棄兀爾不為，執捨為離，離還成執。若乃達名字性離，了諸行緣生，祇此有為，無非實際，豈唯作法，奉戒亦然！豈唯奉戒，萬行亦然！故《淨名》云：「能如此者，是名奉律。」故知能持無慧，但是集因；有慧不持，終歸魔業。此勉持者更加勝進，非謂抑善使不為也，思之
【譯文】在第三部分中，首先總結非法。依據前面論述，原本只收攝善與惡二性，然而既然全都出自昏昧情識，無非也是無記，所以通於三性。業是集諦之因，所以能招感果報。自「反」字以下指示如法。集是世間的成因，通通包含善與惡，如法雖然是善，若不了達空性而執著成滯礙，就不是出離之因，所以也必須遠離。這裡所說的遠離，並不是指全盤捨棄、茫然無所作為，若將捨棄執著為遠離，遠離反而成了執著。若是能夠通達名字自性本空遠離，了知一切諸行皆是緣生，就在這有為法上，無一不是真如實際，豈止秉作羯磨是如此，奉持戒律也是如此！豈止奉持戒律是如此，菩薩六度萬行也是如此！所以《維摩詰經》（《淨名經》）說：「能夠做到這樣的，才稱為真正奉持戒律。」由此可知，能夠持戒而缺乏智慧，終究只是集諦之因；具備智慧而不持戒律，終究歸入魔道之業。這是勉勵持戒之人更進一步向上精進，並非壓抑善行讓人不去作為，應當深入深思。

【461-0003】03_業疏/06a_卷一之六#44

【461-0004】03_業疏/06a_卷一之六#45
【原文】二分總別據名體中，初以義定。「名」即文標七名，「體」即名下註釋。「何」下引示，初非註中列人法事，與下六種列相全別，故知各立，不可相收
【譯文】在第二「區分總別」的「依據名體」之中，首先從義理上判定。「名」就是文中標示的七種名稱，「體」就是名稱之下的注文解釋。自「何」字以下引證說明，第一非的注釋中羅列人、法、事，與下面六種所列行相完全有別，所以知道它們是各自獨立並立的，不能互相包含收攝。

【461-0005】03_業疏/06a_卷一之六#46

【譯文】若是單純從名稱來收攝，則第一個非是總相，下面六個非是別相。因為非法的行相不出人、法、事這三種因緣，第一非之中收攝了人與事的非法，所以律文中說「或者法不稱合於事，事不相應於法，或者事與法彼此互違」，都統稱為非法非毗尼，由此可知第一非是總相。後面的六種非，只是單獨舉出人與法，在一種位次上交錯交織，彼此是非局限於某一局部，由此可知怎能不是別相呢？

【461-0006】03_業疏/06a_卷一之六#47

【461-0015】03_業疏/06a_卷一之六#56
【原文】有人言：前六有非，應訶不訶，皆六收之；或有訶者，即第七攝。如非法別、非法和，約法非同，莫不白此事為彼事作，故但配人和別，即分二非；此亦爾也。故知訶時通含是非，自六非外，但不應法，訶止即如，不止為非
【譯文】有人說：前六種羯磨有過失，應當抗議卻不抗議的，都由前六非所收攝；若有人提出抗議，即屬於第七非所攝。就如同非法別眾、非法和合眾，就「法是非法」而言是相同的，無非都是把宣告此事誤作宣說彼事，因此只配對僧人的「和合」與「別眾」，便分出兩種非；這裡也是如此。所以可知在抗議之時，通達含攝了如法與非法，在六非之外，只要不合教法，抗議而止息便成如法，不止息便成為非。

【461-0016】03_業疏/06a_卷一之六#57
【原文】四中初科，初立義。「如」下舉例，二、三兩種非法是同，人分兩異，例今前後有非是同，呵不呵別。「故」下結示體相如非不定
【譯文】第四種解釋的初科中，首先確立義理。「如」字以下舉例說明，第二種與第三種兩者的「非法」是相同的，只在僧人方面區分為和、別兩種差異，以此例照此處前後皆有過非相同，差別只在於抗議與不抗議。「故」字以下總結說明其體相在如法與非法之間是不固定的。

【461-0017】03_業疏/06a_卷一之六#58
【原文】問：訶不止非與得訶人訶，有何別耶？答：約人明訶，情不同故成別眾也；約法不止，欲同詳秉故入法非。又云：別眾訶者訶於事，故訶法不止，謂人法處等
【譯文】問：第七「抗議不止非」與前述「有資格抗議者提出抗議」，有什麼差別呢？答：就僧人而言說明抗議，因心意不和同而構成別眾；就法式而言不停息，是為了共同審詳秉持，所以歸入法非。又有人說：別眾的抗議是針對事相而抗議，所以抗議羯磨法不停息，是指涉及人、法、處等過失。

【譯文】在揀除混濫的提問中，前面的「非法別眾」等都有合乎資格的人抗議，所以必須加以甄別。回答中有兩種解釋：第一種就人與法來劃分，前者構成別眾，後者構成非法，想要共同審詳秉持，顯示僧人是如法的；「又」字以下，第二種依據四種緣（人、法、處、事）來判定。

【461-0019】03_業疏/06a_卷一之六#60
【原文】上諸解者，但分為二，疑未當也。今解：無問情涉違順，緣通是非，德人吐辭，義須依住。住則是別，法不可非；不住乖法，人法俱非。餘就文重解
【譯文】以上諸家的解釋，只是將它劃分為兩種，恐怕並不妥當。現在我的解釋是：無論情志是相違還是相順，因緣通於如法或非法，只要有德之人發言抗議，依義理就必須依從而止住。止住了就屬於別眾，但羯磨法不能判為非法；如果不住手便違乖法式，人與法就全都成非。其餘的隨後就經文再次解釋。

【461-0020】03_業疏/06a_卷一之六#61
【原文】今義中，初斥諸解。然此七非體相各立，那得相對但分二耶？誠為未當，不足疑矣。次示今義。「情」即屬人，「緣」收事處。「住」即是止，由是得訶人訶，故止、不止皆成別眾。然止順呵故法不非，即如法別；不止違呵故兼法非，同非法別。此之兩相，即非體矣
【譯文】在今家所立正義中，首先駁斥諸家的解釋。這七非的體相各自獨立確立，哪裡能互相對照而僅僅劃分為兩種呢？確實是不妥當的，不值得懷疑。接著闡明今家的義理。「情」就屬於人，「緣」則收攝事與處。「住」就是停止，由於是有資格抗議的人提出異議，所以無論停止或不停止，都構成別眾。然而停止是順從了抗議，所以法不算過非，即成為如法別眾；不停止則是違抗了抗議，所以兼帶法非，等同於非法別眾。這兩種行相，就是第七非的自體。
