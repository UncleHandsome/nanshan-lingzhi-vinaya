# 校閱材料　第414檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【414-0001】02_戒疏/21b_卷四下之三#21
【原文】【記】第六，初科。前敘緣起，即象力也。「故重」下，示制法。注文「有本」下，示異名。「而」下，示次第。由前名濫，恐倒亂故，仍定品位，決無相濫矣。
【譯文】【記文】第六段，第一科。前面敘述緣起，也就是象力比丘之事。「故重」以下，指示制定作法。註文中「有本」以下，指明不同的名稱。「而」以下，指示先後次序。由於前面的名稱容易混淆，擔心產生倒錯紊亂，因此確定其品位次序，便絕對不會相混了。

【414-0002】02_戒疏/21b_卷四下之三#22
【原文】【疏】《律本》此名，或名「覓罪相」者，或「以多人為覓罪相」者。今誦戒人，不釋藥之上下，對病治滅，應先誦「多滅」，後誦「覓相」，此是好也。
【譯文】【疏文】《律本》中這個名稱，有的稱為「覓罪相」，有的稱為「以多人為覓罪相」。現在誦戒的人，不明白這兩種法藥的上下層級，在對應病症進行治罰平息時，應當先誦「多人語（多滅）」，隨後誦「罪處所（覓相）」，這樣才是妥當的。

【414-0003】02_戒疏/21b_卷四下之三#23
【原文】【記】次科。「或名覓罪相」，據《律本》也，今《刪定戒》依《律》易之。「或以多人為覓罪」者，錯用後名，召前法也，由《律》名同，致令濫用。「今」下，教依次誦。今《刪定戒》，多覓是「多人語」，單覓即「罪處所」。名相既正，藥病不差，故云「好」也。
【譯文】【記文】第二科。「或名覓罪相」，是依據原本律文的翻譯；現在《刪定戒本》依照律義進行了更正。「或以多人為覓罪」，是錯誤地使用了後面的名稱去稱呼前面的法規，正因為律典譯名相同，才導致浮濫混用。「今」以下，教導大眾依照正確次序誦讀。現在的《刪定戒本》，「多人覓罪相」（多覓）是指「多人語」，單稱「覓罪相」（單覓）即指「罪處所」。名稱和名相既然已經匡正，法藥與病情便不會差錯，所以說是「好」的。

【414-0005】02_戒疏/21b_卷四下之三#25
【原文】【註】佛在舍衛國。比丘共諍，經年難滅。以事白佛，聽彼此二眾相對共滅。應一眾中上座作白言：「我等行來出入，多犯諸罪，除『遮不至白衣家』，餘罪共長老作草覆地滅。」彼一眾中上座亦如上作白已，彼此和合，罪諍俱滅，更不相問，如草覆地。
【譯文】【註文】佛陀住在舍衛國。比丘們共同諍論，長年難以平息。將此事稟白佛陀，佛陀允許讓爭議的雙方大眾面對面共同消解。應當由其中一方的大眾中推派上座宣告說：「我等行動出入，多犯諸罪，除『遮不至白衣家』之外，其餘罪過都與長老們如同以草覆蓋大地一般共同消滅。」另一方大眾中的上座也依照上述儀軌宣告完畢後，雙方和合一致，罪過與諍論全都止息，不再互相追究，就像以草覆地遮掩塵土一樣。

【414-0006】02_戒疏/21b_卷四下之三#26
【原文】【疏】七、明「草覆地」者。兩朋相諍，經年難滅，勘撿罪事，不知首尾，無由以教，取斷是非。故直面對，各陳咎失，不須後說彼我是非，罪諍於此一時俱淨。如草掩泥，事淨便止，故曰也。
【譯文】【疏文】第七科、說明「草覆地毗尼」。雙方朋黨互相爭論，歷經經年都難以平息，勘查檢驗犯罪情事，不知首尾原委，無由依據戒律來斷定是非。所以直接面對面，各自陳述自己的過失，事後不需要再去議論彼此的是非，罪過與諍論在此時一概消除清淨。就像用草掩蓋爛泥，事情清淨就此為止，所以稱為草覆地。

【414-0007】02_戒疏/21b_卷四下之三#27
【原文】【記】第七。初敘緣起，即拘睒彌諍，經涉六年。「故」下，示制法。「面對」、「各陳」等，即法儀也。「如」下，結名。法藥如「草」，久諍如「泥」，從喻為名。注中，兩眾各一上座，先令彼眾伏地，上座白懺，此眾受之，然後此眾對懺亦爾。「遮不至白衣家」，由對俗犯，所以除之。
【譯文】【記文】第七段。起初敘述緣起，就是拘睒彌比丘的諍論，時間長達六年。「故」以下，指示制定作法。「面對」、「各陳」等語，就是指行法的儀軌。「如」以下，總結名稱。法藥好比「草」，長久的諍論好比「泥」，是依據比喻來命名的。註文中，兩眾各推一位上座，先讓那一眾伏首在地，上座宣告懺悔，這一眾接受懺悔；接著這一眾對那一方懺悔也是如此。「遮不至白衣家」，因為這是針對俗人家而犯的戒，所以排除在外（須另外單獨懺除）。

【414-0030】02_戒疏/21b_卷四下之三#50
【原文】【記】問中。云「前解」者，即上卷明二教中，對前廣教，七佛略偈並合為「餘」，文中「偏指」，故須問決。答中，釋迦一偈，止明三業，總前廣教更無別法。前六佛偈，各明一行，如「忍辱」等，廣文不攝，故曰「義寬」。前可包後，後不攝前，故曰「從多」也。
【譯文】【記文】在問答中。所說「前解」，就是上卷在闡明兩種教法中，相較於前面的廣教，七佛的略偈都應合稱為「餘」，但經文中「偏偏只指六佛」，所以必須提問決疑。回答中，釋迦牟尼佛的一偈，僅僅闡明身口意三業，總攝前面的廣教而沒有別法。前六尊佛的偈頌，各自闡明一種德行，如同「忍辱」等，是廣教戒文中沒有直接涵蓋的，所以稱為「義寬」。前面可以涵括後面，後面不能涵括前面，所以說「從多」來稱呼。

【414-0042】02_戒疏/21b_卷四下之三#62
【原文】【疏】就初忍法有三：一、法思惟；二、他不益；三、安苦也。於辱生忍，故曰「忍辱」；行功既彊，入道最勝，故曰「第一道」。此明因行也。因不虗設，必能感果。是以次句明涅槃體寂，不為諸相所遷，故曰「無為」。出離中勝，故曰「最」也。
【譯文】【疏文】就前半段而言，忍辱之法有三種：第一是法思惟忍；第二是他不利益忍；第三是安受苦忍。對於屈辱能生起忍耐心，所以稱為「忍辱」；修行的功力既然強固，趣入道果最為勝越，所以稱為「第一道」。這是闡明因地修行。修行之因絕不虛設，必定能夠感得善果。因此下一句闡明涅槃的本體寂滅，不被一切生滅相狀所變易牽引，所以稱為「無為」。在一切出離解脫之道中居於首位，所以稱為「最」。
