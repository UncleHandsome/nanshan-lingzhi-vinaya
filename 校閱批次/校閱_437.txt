# 校閱材料　第437檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【437-0001】資持記/09b_中三上#37
【原文】必約露處。手觸即同受用，故犯。若下，明囑他。不舉亦開。文標春月，不慮損故；餘時義應不許。若行下，明別制。此非僧物，但是乖儀，有違應吉。《多論》。遊房吉者，非捨去故。《四分》有四，初明捨去方便。次第四種，並以若字分之。初囑知事，二舉屏處，三好蓋覆，四作意還。上句明即還。
【譯文】必定是指在露天的環境。只要用手觸碰移動，就等同於自己在使用，所以犯戒。「若」字以下，說明囑託別人照看。即使自己不收起來也予以開許。文中標明是春暖之月，不必擔心會受風雨損壞；其餘時節在法理上應當不允許這樣做。「若行」以下，說明附帶的特別規定。這雖然不是僧團公物，但行為有失僧人威儀，有所違犯應當判為小罪（吉羅）。《薩婆多論》提到。在各房間走動串門子判為小罪，是因為這不算是徹底捨棄離去。《四分律》有四點，首先說明想要捨棄離去時的處置方法。接著有四種程序，都用「若」字區分。第一是囑託給執事僧，第二是收納放置到有遮蔽隱蔽的處所，第三是用物品妥善蓋好覆蓋住，第四是動念預計馬上就會返回。上一句是指立刻就回來的打算。

【437-0002】資持記/09b_中三上#38
【原文】應下脫去字，律云便應去；又疑便字寫倒，今將連下讀之。言雨中者，律云若疾雨疾還，不壞坐具者應往；若中雨中行，及得還者，應往；若少雨少行，及得還者，應往〔皆謂去時作如是意〕；今但云隨雨及時，通收義足。彼下，總結，初明順法。若不下，明違犯。正罪方便，如文所列。
【譯文】「應」字下面脫漏了一個「去」字，律文中寫作「便應去」；又懷疑是「便」字抄寫顛倒了，現在應當把它連貫著往下閱讀。所謂「在雨中」，律文說如果遇上下急雨而能趕緊返回，不致於損壞坐臥用具者，應當可以去；如果遇上下中雨而在雨中行走，能夠趕得回來者，應當可以去；如果遇上下小雨而在雨中行走，能夠趕得回來者，應當可以去〔這都是指動身離去時內心有這樣的預期計算〕；現在文字只簡括地說「隨雨及時」，這在法義上就已經完全包含足夠了。「彼」字以下，做通盤總結，首先闡明合乎法規的做法。「若不」以下，說明違犯的行相。根本正罪與預備的方便罪，正如文中所排列的那樣。

【437-0003】資持記/09b_中三上#39
【原文】言還悔者，律云：一足門外，一足門內，欲去而不去也。若二下，次明同犯。律云：下座意謂上座當收，而上座竟不收，故犯二罪；不收故提，復以非威儀故吉。〔輒使上座，故犯二罪。〕又上座意謂下座當收，而不收，上座犯提。俱不收者，律云：二人不前不後也〔謂同臘者〕。餘下，三明餘物。空床非所用臥者。
【譯文】所謂「回頭懊悔」，律文說：一隻腳邁在門外，一隻腳留在門內，想要離去卻又猶豫不走的情形。「若二」以下，其次說明共同違犯的判定。律文說：下座比丘心想上座比丘應該會收，然而上座比丘最終卻沒有收，因此下座比丘犯了雙重罪；因為沒收好公物而犯提罪，又因為失卻恭敬威儀而犯小罪（吉羅）〔自作主張使喚上座，所以犯兩項罪〕。又若是上座比丘心想下座比丘會收，下座卻沒收，此時上座比丘犯提罪。若是兩個人都不收，律文說：兩個人戒臘不前不後不相上下〔是指戒臘相同的人〕。「餘」字以下，第三說明其餘的用具。空置的床鋪並非平時用來躺臥睡覺的。

【437-0004】資持記/09b_中三上#40
【原文】表裏即內外，謂摘開各處，非全物也。若下，四明別務。思惟，即禪定。不犯中。但明囑付二人。律文更列力勢所持命梵二難，不作次第而去不犯。十五。〔佛在舍衛，客比丘在邊房宿，不語便去，臥具壞爛，故制。〕僧物制意同前。緣中。第五犯相有二，如後釋中。
【譯文】「表裏」是指內部與外表，是指將用具拆散開來放在各處，不是一件完整的器物。「若」字以下，第四說明處理別的事務。思惟，就是指修習禪定。不犯戒的情況中。只提到了鄭重囑託給兩個人。律文中還另外列出了受到強大勢力脅迫牽制，以及面臨危及生命、危及梵行這兩大急難，此時若來不及按程序逐一收拾就離開，不算犯戒。第十五條戒律〔佛陀住在舍衛城時，有客比丘在僧房偏僻角落的房間借宿，未告知主人就逕自離開，導致臥具受潮腐爛，佛陀因而制戒〕。僧團公物的制戒用意與前面那一條相同。條件中。第五個犯戒相狀有兩種，正如後面的解釋所述。

【437-0005】資持記/09b_中三上#41
【原文】疏云：所以分二戒者，一屏露異。二得罪異，露則出門，屏則出界；又決去出界，暫往三宿。三開緣異，露則兩相緩急〔緩則如上方便，急謂勢力命梵等緣，不作次第。〕，屏則開於二夜〔屏是房室，故有斯開。〕。釋中，初明出界犯，前示方便。若不下，結犯。若即下，次明三宿犯，初示方便。
【譯文】《戒疏》說：之所以把這件事分開制定為兩條戒，第一是室內遮蔽處與室外露天處環境不同。第二是結罪的判準界限不同，露天處只要一走出房門即成罪，室內遮蔽處則要走出寺院結界才成罪；而且抱定主意離開必須走出結界，若是暫時出外則以留宿達三夜為限。第三是開許的因緣條件不同，露天處有緩急兩種情況〔緩慢情況就如上述如法善後，緊急情況是指遇上勢力脅迫、生命危難、梵行危難等特殊緣由，可以不必走完收拾程序〕，室內遮蔽處則直接寬限開許可以外宿兩夜〔因為室內是遮風蔽雨的房室，所以才有這項放寬〕。解釋的文句中，首先說明走出結界即構成犯戒，前面先列出預備階段的方便罪。「若不」以下，做出正式結罪的結論。「若即」以下，其次說明外宿滿三夜構成犯戒，前面先列出方便罪。

【437-0006】資持記/09b_中三上#42
【原文】不下，結犯。不犯者，如上方便，已在界外，水陸命梵等緣皆開。十六。〔佛在舍衛，六群十七群同道行，至無住處，十七群求得住處；六群知，強於中間敷臥具宿，故制。〕釋中，律文分三，初釋中間。約身四邊者，明其迫窄不相容也；以間寬不妨，開無犯故。次釋臥具。且列四種，餘物準知。若下，三約心明犯。
【譯文】「不」字以下，做出正式結罪的結論。不犯戒的情況，是指完全做到了上述善後的處置方法，或者人已經走出結界之外，遇到水災、陸路阻斷、生命危難、梵行危難等突發事故，全部都在開許之列。第十六條戒律〔佛陀住在舍衛城時，六群比丘與十七群比丘在路上同行，走到一處沒有客舍可住的荒野，十七群比丘好不容易求得一處落腳安宿的屋舍；六群比丘得知後，硬是在兩人的鋪位中間強行鋪設臥具擠著睡覺，佛陀因而制戒〕。解釋的文句中，律文分為三段，首先解釋何謂「中間」。從身體的四周邊界來界定，這是為了說明空間過於逼仄狹窄、彼此不能相容的窘態；因為如果中間間隔寬敞、互不妨礙，就開許不成立犯戒。其次解釋何謂「臥具」。此處暫且列舉四種，其餘用具可以依此推知。「若」字以下，第三是從動機心態來界定犯戒。

【437-0007】資持記/09b_中三上#43
【原文】開不知故。《十誦》。於中敷已，又作多事惱他意令避去，故隨事結。且列八種，不出聲色。隨他之語，總收一切。不犯中。初句不知，次五並以若字分之；下明難緣，共成七也。語已住者，彼許容也。親舊教者，彼自召也。倒地、轉側，皆非意也。命梵等者，文略力勢所持，及繫閉也。
【譯文】這開許給不知情者。《十誦律》說：在兩人中間鋪設好之後，又蓄意製造許多雜事惱亂對方，企圖逼迫他人主動避開離開，所以伴隨著這些惱人的舉動一一結罪。此處姑且列出八種，都離不開出聲與作態色相。而鈔文中「隨他（不樂事作）」這句話，則總括收攬了一切惱害騷擾的行徑。不犯戒的情況中。第一句是指不知情無心之過，接下來五種都用「若」字相間分列；最下方說明遭遇急難的因緣，總共合成了七種免責情況。說話之後才留宿的，是指對方已經明確答應接納包容。受熟識的老朋友指引的，是指對方自己主動邀請召喚的。跌倒在地、翻轉側身，這些都完全不是出於故意。遇到生命與梵行等急難的，文中略過了受到強暴勢力牽制，以及遭到關押囚禁等情形。

【原文】疏云：何故看覆，無自覆者？答：不看房成，有受用義；自覆招譏重，故不許。或可從緣起說，由使人作，因即制戒。第三緣，若去見聞互離吉羅；俱離不犯，得房受用。言三節者，若約緣起，則是三重；覆已更覆，故致摧倒；若據律文，即約苫草以分節段，從橫皆犯。
【譯文】《戒疏》問道：為什麼只禁制「監督覆蓋」，卻沒有提到「親自覆蓋」呢？回答：如果不加以監督卻能使房舍落成，這具有供大眾合理受用的意義；若是身為比丘親自爬上去覆蓋屋頂，招惹世人譏嫌的程度極為嚴重，所以在根本戒中原本就不允許。或者也可以從本戒最初的制戒緣起而言，正是因為闡陀比丘指使工人去做，佛陀因而順著此一緣由制定了這條戒。第三個條件是，如果遠離了現場，見與聞只要有一項未脫離，就犯小罪（吉羅）；若是眼不見、耳不聞兩者完全脫離，就不犯戒，僧團可以安然接受這所房舍並加以受用。所謂「三節」，若是依照制戒的起因來說，是指覆蓋了三重屋頂；蓋了一層又再加蓋一層，所以才導致房舍被壓垮倒塌；若是依照律文本意，就是依照鋪蓋茅草的工序來劃分節段，無論是橫向鋪還是縱向鋪，超過了規定的三道節段都算犯戒。
