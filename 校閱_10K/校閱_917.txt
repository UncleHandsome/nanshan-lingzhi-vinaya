# 校閱材料　第917檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【917-0001】資持記/01f_上一上#10
【原文】因筆斯文，益增哽痛；自非聖鑒，孰見余心。悲夫！總結中，上三句結前。言總束者，則驗十門非別序明矣。諸門者，即下諸篇；則顯教興中指諸門，非九門明矣。析，辨也。若下，指廣。可知。別論者，則三十篇望序為別，又復明矣。大段第三，示所詮行相，初總示中。宅，居也。
【譯文】藉著書寫這些文字的機會，心中倍感哽咽悲痛；若非聖者心靈明鑑，誰又能看清我的心聲。真是令人悲傷啊！在總結的段落中，前三句總結前文。提到「總束」，便顯然證知十門並非別序。所謂「諸門」，就是指後文的各篇；這便清楚顯明在〈教興〉中所指的諸門，並非指〈教興〉等九門。所謂「析」，就是辨析。從「若……」以下，指出廣泛的內容，讀者自可理解。所謂「別論」，是指三十篇相對於序文來說屬於分別論述，這一點又再次顯明了。大段落之三，標示所闡釋的行法體相（示所詮行相），首先在總括標示之中。所謂「宅」，就是居住。

【917-0002】資持記/01f_上一上#11
【原文】佛門廣大，包納清澄，喻之如海；僧稟佛化，即居其中；如犯重禁，名為邊罪，謂漂出佛海邊外，即其義也。流即是水，法能滋物，故比於水。廁，預也。伍，眾也。此明比丘身具三寶，所修法行，雖乃萬途；以眾自共，攝無不盡。然據行體，止是二持；但就作中，別簡一色；羯磨僧法以為眾行；
【譯文】佛門廣大無邊，包容攝受一切而清澈澄明，比喻如同大海；僧眾秉持佛陀的教化，就居住在其中；如果犯下重罪，稱為「邊罪」，意思是漂流出佛海的邊界之外，就是這個意涵。「流」就是流水，佛法能夠滋潤萬物，所以比喻為水。「廁」是參與、列名。「伍」是隊伍、僧眾。這是說明比丘自身具足三寶，所修持的法門行持雖然千差萬別；但以眾行、自行、共行來涵蓋，就無不收攝殆盡。然而根據行持的本質，只不過是止持與作持兩種；只是在「作持」之中，另外揀選出一種；將羯磨等僧法歸為眾行；

【917-0003】資持記/01f_上一上#12
【原文】自餘雜法，總歸共行。欲使綱目兩分，眾別無濫，故云唯三位也。別對中，初明自行。上句明建志攝修，次句示學知教相。出離聖道，不類邪術，故云正戒。文指體相，必具法行；體附釋相，相總四篇；故此二字，統於中卷。自下，次明眾行。上句躡前，次句正示。凡行僧事，必先簡眾；
【譯文】其餘雜項法門，全部歸入共行。為了使大綱與細目各自劃分，團體之法與個別之法不相混淆，所以說「只有三個類別」。在逐一對照的段落中，首先說明「自行」。上句說明建立志向、收攝修持，下句提示學習而明了教法名相。這是出離生死的聖道，不同於邪魔妖術，所以稱為「正戒」。鈔文指出戒體與戒相，必定具足戒法與戒行；戒體附於〈隨戒釋相篇〉，戒相則總括了中卷四篇；所以「體、相」這兩個字，統攝了整部中卷。自此以下，接著說明「眾行」。上句承接前文，下句正式提示。凡是要推行僧團事務，必須先檢驗大眾僧的資格；

【917-0004】資持記/01f_上一上#13
【原文】故須體淨，方應秉宣。言綱領者，對下毛目也。匡攝住持，存乎眾法；隨事奉修，在乎別行；眾法存則別行修，綱領舉則毛目正；上下作持，離分在此。自他下，明共行。上句示行相。凡為道眾，彼我同須，即是共義，故云兩德。德亦行也。下句顯繁多。
【譯文】所以必須自身清淨，才應當秉持宣唱。所謂「綱領」，是相對於下文的細目（毛目）而言。匡正主持、住持佛法，繫於僧團的眾法；隨順事情奉持修習，在於個人的別行；僧團眾法得以保存，個人的別行才能修治，大綱綱領提得起，微細條目就能端正；上卷與下卷的作持之法，其區別就建立在此。從「自他……」以下，說明「共行」。上句提示行持的相貌。凡是出家修道大眾，彼此都需要奉行，這就是「共」的含義，所以說是「兩德」。「德」也就是行持。下句顯示其繁多雜碎。

【917-0005】資持記/01f_上一上#14
【原文】除僧法羯磨已外，一切作行，皆歸共收。唯此共行，攝相最廣，故曰多途。或可上句躡前兩行；次句正示行相，謂必須共行輔成自眾，故云成相多途。問：自眾兩行，亦制同遵，豈非相濫？答：自行則護體防心，義非他共；止作體別，此不在言。就論眾行，作業辦事，多是為他；義非常行，有緣方舉。
【譯文】除了僧法羯磨之外，一切所應運作的行持，都歸屬於共行收攝。唯有這種共行，所涵蓋的面相最為廣泛，所以說「多途」。或者可以解釋為：上句承接前述兩種行持；下句正式提示行持的面相，意思是必須依靠共行來輔助成就自行與眾行，所以說「成相多途」。有人發問：自行與眾行這兩種行持，同樣是戒律制定大家必須共同遵守的，難道不會相互混淆嗎？回答說：自行是守護戒體、防範心念，在意義上並非與他人共同進行；止持與作持的體性各別，這點自不必說。若單就眾行來討論，舉凡羯磨辦事，大多是為了利益他人；在意義上並非日常恆常進行之事，而是遇到因緣才會舉行。

【917-0006】資持記/01f_上一上#15
【原文】共行不爾，日用恒須，是僧俱稟，獨彰斯目；如衣藥鉢器訃請導俗等類。比論二行，別相可知。然三行之目，古德所傳。若取今文，明標自行；又復前云上卷則攝於眾務，則自眾二行名義灼然。唯斯共行，雖復無文；兩德之言，義取無爽。古多妄解，不免繁詞。〔古云：四人羯磨為眾行，一人心念為自行，二人對首為共行者，誤矣。
【譯文】共行則不是這樣，是日常生活中恆常需要的，凡是僧眾都必須秉持遵行，所以才單獨彰顯這個名稱；例如衣物、醫藥、鉢器、赴受請召、導化俗人等類。拿這些來與前兩種行相比，個別的相貌便很清楚了。然而「三行」的名稱，是古德所流傳下來的。如果依據本鈔當前文句，明確標示了「自行」；而且前面又提到「上卷則涵蓋僧眾事務」，那麼自行與眾行這兩行的名稱與意義就極為清楚明瞭了。唯有這個「共行」，雖然文中沒有直接標名；但從「自他兩德」的文句來看，取其義理絕無偏差。古人大多有錯誤的解釋，不免說了許多繁複冗長的話。［古人說：四人共同作羯磨是眾行，一人在心中默念是自行，二人面對面宣說是共行，這是錯誤的說法。］

【917-0007】資持記/01f_上一上#16
【原文】問：前文已分，何意重迷？答：前判能詮，則以文攝行；此明所詮，則指行在文。雖文行俱明，而正意兩別。問：前以上卷在初，此則中卷為首，何以不同：答：意如上解。若爾，何不依行次第，以自行為上卷耶？答：此有二意。一約行次第，則先止後作，自行合初。
【譯文】問：前面文句已經區分過了，為什麼此處又重復開陳標示？回答：前面是在判定「能詮表」的文句，是以文句來統攝行持；此處是說明「所詮表」的實質行相，是指明行持體現在文句之中。雖然文句與行持兩處都有說明，但是核心用意各有不同。問：前面將上卷放在最先，這裡卻以中卷為開端，為什麼有所不同？回答：用意正如上面所解釋。如果真是這樣，為什麼不依照行持的先後順序，把自行列為上卷呢？回答：這有兩種用意。第一是依照行持的先後次第，應當先修止持、後修作持，自行理當列在最前。

【917-0008】資持記/01f_上一上#17
【原文】二約事勝劣，則住持功大，眾須在首；故律序云：以眾和合故，佛法得久住。今取後意，如文所列。雙結中。教行兩備，攝機斯盡。次科，初二句標難。謂事隨篇類，則使三行互有投寄。如上卷〈標宗〉亦明法體行相，及捨戒、六念、別人說恣、識疑發露之類，則眾行兼自共也。
【譯文】第二是依照事相的尊勝與微劣來看，住持佛法的功德最為廣大，大眾僧法必須居於首位；所以律序中說：「因為大眾和合的緣故，佛法才能長久住世。」現在採取後一種用意，如同鈔文所排列的順序。在雙重總結的段落中。教法與行持兩皆具備，化導收攝根機就毫無遺漏了。下一個科判，前兩句點出難處（標難）。這是說各項事相隨著所屬篇章歸類，導致這三種行持彼此互有交織寄託。例如上卷的〈標宗〉也闡明了法體與行相，以及捨戒、六念、個別向人說戒與自恣、知疑發露等事，這便是眾行之中兼帶了自行與共行。
