# 校閱材料　第342檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【342-0001】02_戒疏/15c_卷三下之三#105
【原文】【記】戒緣中。因開致濫，招譏故制。「畢陵伽婆蹉」，即佛上首弟子，人所知識，致令徒眾多得多畜。故知信施生過之本，存心向道，慎勿近之。「有」下，斥妄判。「今解」引據，如前具引。言「同說」者，謂彼二律同今《四分》。
【譯文】【記文】在制戒緣起之中。因為開許而導致泛濫，招致譏嫌所以制戒。「畢陵伽婆蹉」，是佛陀的上首弟子，深受眾人敬重熟知，以致於他的徒眾得到極多供養而大量蓄積。由此可知信眾的布施乃是滋生罪過的淵藪，存心向道的人，務必要謹慎切勿貪近。「有」字以下，駁斥錯誤的判斷。「今解」所引用的依據，如同前面已經詳細引述過的。所謂「同樣說」，是指那兩部律典與本《四分律》的看法完全一致。

【342-0002】02_戒疏/15c_卷三下之三#106
【原文】【律】若比丘有病，殘藥酥、油、生酥、蜜、石蜜，齊七日得服。若過七日服者，尼薩耆。
【譯文】【律文】如果比丘患有疾病，殘餘的藥物如酥、油、生酥、蜜、石蜜，最多只能在七天之內服用。如果超過七天還服用的，犯尼薩耆波逸提罪。

【342-0003】02_戒疏/15c_卷三下之三#107
【原文】【註】此應捨藥與僧已，白治罪竟，還彼藥法：至第七日，捨與比丘，彼應取食；若過七日，酥、油塗戶嚮，蜜、石蜜與守園人；減七日者，白二還之，比丘當取塗脚、然燈用。
【譯文】【註文】這應當先將藥物捨給僧團，在僧中宣白表白治罪完畢後，歸還該藥物的使用法則：如果是剛好到了第七天的藥，應當捨給其餘比丘，那位比丘應當拿去食用；如果超過七天的藥，酥和油只能用來塗抹門窗樞紐，蜜與石蜜則送給看守寺院的淨人；如果還不足七天的藥，透過白二羯磨還給原主，比丘應當拿來塗腳或點燈使用。

【342-0006】02_戒疏/15c_卷三下之三#110
【原文】【疏】戒本七句。一、人。二、病緣。《僧祇》云「病有四百四也，水、火、風、雜，各有百一。風病用油，熱病用蘇，水病用蜜，雜病用三」，故云「醫教服」也。三、「殘藥」者，列名相也。四、「齊七日服」，給其限也。五、「過七日服」，明乖法也。下二，可知。
【譯文】【疏文】戒本共有七句。第一句是行為人（比丘）。第二句是疾病因緣。《僧祇律》說「疾病有四百零四種，水大、火大、風大以及四大交雜之病，各有百零一種。風病用油治療，熱病用酥治療，水病用蜜治療，雜病則同時使用這三種」，所以說「依照醫師的教導來服用」。第三句「殘藥」，是列舉藥物的名目形態。第四句「齊七日服」，是給定服用的期限。第五句「過七日服」，是說明違背了法規。下面兩句，容易明瞭。

【342-0007】02_戒疏/15c_卷三下之三#111
【原文】【記】戒本，分句中。第二引《僧祇》。初示病，「雜」病即三種互發。「風病」下，明對治。「醫教」即醫師知病，教令須服。四中，「給」猶與也。
【譯文】【記文】在戒本劃分語句之中。第二句引用《僧祇律》。起初顯示疾病種類，「雜病」是指三種病相交互引發。「風病」以下，說明對治的方法。「醫教」，是指合格的醫師明了病情，教導比丘必須服用。第四句中，「給」相當於給予的意思。

【342-0012】02_戒疏/15c_卷三下之三#116

【342-0013】02_戒疏/15c_卷三下之三#117
【原文】【記】次問。意謂何不受「迦絺藥」。答中，上三句明衣須受，下二句明藥不開。止能治疾，故言「資狹」。
【譯文】【記文】這是第二個問難。意思是為什麼不能受持「迦絺藥」。回答之中，前三句說明衣服必須受持迦絺那迦絺那，後兩句說明藥物不能開許。藥物僅僅只能用來治病，所以說「資補範圍狹小」。

【342-0018】02_戒疏/15c_卷三下之三#122
【原文】【疏】答：「三衣制畜非長限，故對非長明『長衣』。藥唯開畜無可對，所以文中不明長。」
【譯文】【疏文】回答：「三衣是佛制規定蓄持的必備法服，不屬於多餘蓄長的範疇，所以對照非長限的法衣而標明『長衣』。七日藥本來就完全是因病開許蓄存的，沒有本具的常制法藥可以相對照，所以律文中不標明『長』字。」

【342-0019】02_戒疏/15c_卷三下之三#123
【原文】【疏】又解云：「雖無『長』字有殘藥，故知義一而文異。」
【譯文】【疏文】另一種解釋說：「雖然律文中沒有『長』字，但有『殘藥』二字，由此可知意義相同而文字不同罷了。」

【342-0020】02_戒疏/15c_卷三下之三#124
【原文】【記】四問。答中二義。初約不同釋，謂衣可有長，藥不名長。「又」下，次約義同釋。「殘」，即「長」義故。
【譯文】【記文】這是第四個問難。回答中有兩種意旨。起初是依據不同之處來解釋，認為衣服可以有多餘蓄長，藥物則不稱為長藥。「又」字以下，接著依據意旨相同來解釋。「殘」字，本來就是「多餘長蓄」的意思。
