整體看，譯文對律典術語掌握得不錯（如「手搏＝舉手作勢未打著」「不受食」「背請」「別眾食」等注都到位），可用度高。問題主要集中在三類：**幾處釋義偏差**、**白話化不徹底（半譯半抄）**、**條目切分與校勘注記**。以下按輕重列出。

---

## 一、須修正（義理／語意有誤或可疑）

**1.「壞生種」→「破壞植物種子」（#38）— 釋義過窄，屬錯譯**
「壞生種」即「壞鬼神村」，指損壞能生長的草木（律分根種、莖種、節種、枝種、子種五類），不是單指「種子」。
建議：**「損壞生長中的草木植物（根、莖、節、枝、子等能再生長者）」**。

**2.「草繫比丘」注「寧不動身而壞草」（#40）— 語意講反／不通**
典故是比丘被賊以**生草**繫縛，為不犯壞生草之戒，寧受困不動、**不壞草**。現注讀來變成「寧可不動身而去壞草」。
建議：**「（賊以生草繫縛，寧受困不動，以免傷斷生草）」**。

**3.「泉渠水中露身洗浴（泉、溝渠，非池）」（#38）— 「非池」無據**
此注未見律據，疑為臆增。
建議刪去，或作 **「於露天的泉水、溝渠中裸身洗浴」**，若要保留區別須附出處。

**4.「強敷僧臥具。惱他比丘尼。」被合併為一條（#38）— 疑漏一條**
原文此處有句讀隔開，且譯文對「擊攊他不受諫」是**拆成兩條**處理的，體例不一致。建議查《四分比丘尼戒本》確認「強敷臥具」與「惱他」是否各別成條；若是，須分列。

**5.「受戒已離和尚出去」→「離開戒和尚」（#38）— 性別易誤**
尼律中的「和尚」是**和尚尼（尼和尚，女性親教師）**，且此戒本意是受具後應二年隨和尚尼住、不得擅離。
建議：**「受具足戒後（未滿二年）即離開和尚尼他往」**。

**6.「僧／眾」宜標明是「大僧」（#38）**
「不半月請教誡」「不詣僧自恣」「不依僧安居」「不白僧入寺」四條的「僧」皆指**比丘僧（大僧）**；譯文一會兒「僧團」、一會兒「比丘僧」，讀者易誤為尼僧。建議統一標明；「不白眾使男子治癰」的「眾」則須確認是尼眾或大僧，不宜含糊作「大眾」。

**7.「輒」譯為「隨意」不準（#38，三處）**
「輒坐白衣牀」「輒著他衣」「輒問大僧義」的「輒」是**未經允許／不問主／不白僧而擅自**，非「隨意」。
建議：**「未經主人同意擅坐在家人床上」「未經衣主同意擅穿他衣」「未經許可擅自向比丘請問法義」**（現注只寫「未經允許擅自請問」，漏了「向大僧」）。

## 二、白話化不徹底（照抄原文，讀者仍看不懂）

以下各條幾乎原樣照錄，建議一律語譯或補注：

| 原文 | 建議 |
|---|---|
| 兩舌語 | 挑撥離間語 |
| 露處敷僧臥具不舉／屏處敷僧臥具 | 在露天（或遮蔽處）鋪用僧團臥具，離去時不收舉 |
| 水中戲 | 在水中嬉戲玩樂 |
| 著白色三衣 | 穿未染成壞色（青、黑、木蘭）的白色三衣 |
| 剃三處毛 | 剃大小便道及腋下三處毛（宜注明） |
| 洗淨過分 | 便後清洗下身超過律制分齊（宜注明） |
| 瞋心呪詛 | 以瞋恨心咒詛他人（如咒人墮惡趣、早死） |
| 共尼同牀 | 與另一比丘尼同牀**而臥**（非只同坐） |
| 度諸遮童女 | 剃度有遮法、不應受具的童女 |
| 百夏尼不禮小比丘 | 戒臘一百夏的老比丘尼，不禮拜新受戒的比丘（依八敬法應禮） |
| 乘乘（無病而乘坐車乘）出行 | 「乘乘…出行」贅語，改「無病卻乘坐車乘行路」 |
| 此門先請懺悔主云（#41） | 這一門也先禮請懺悔主，說： |
| 並如前說（#45） | 都如同前面所說 |

**最關鍵的是两处定型句（#38、#44 同）：**
- 「憶念犯發露。知而不覆藏。」→ 建議 **「一憶起所犯便即發露，明知有罪也不隱藏。」**
- 「願大姉憶我清淨。戒身具足。清淨布薩。」→ 建議 **「願大姊憶念證知我已清淨，戒體完具無缺，得以清淨參加布薩。」**
（這是懺法的核心句，照抄等於沒譯。）

## 三、須查證／出校的地方

**1.「不以二事輒授弟子」（#38）**
譯文作「不用二法即隨意收授弟子」——既改字（事→法）又未釋「二事」所指，等於沒交代。此處可能指授具前應辦的兩事（如「與二歲學六法」＋「白僧聽許」），亦有解為「法、衣食」二事攝受者。**建議查《四分律》尼戒本對應條文後補注，或直接標「二事所指待考」**，不宜含混帶過。

**2.「一槌𮌎露身」（#38）**
譯者標〔待核〕的態度是對的，但注記宜寫成正式校勘：
- 「𮌎」疑為「胸」之異體／訛字，「槌」當作「搥（椎）」，宜注明底本字形；
- 「一」字可疑（究屬上條衍文，或與下合讀「一搥胸」）；
- 究竟為「搥胸」＋「露身」二條，或「瞋恚搥胸露身」一條，須對戒本核。
建議改注為：**「〔校：『𮌎』疑『胸』之訛；『一搥胸露身』或分二條，待依尼戒本核〕」**。

**3.「露處敷僧臥具。不舉屏處敷僧臥具。」**
原文「不舉」位置明顯錯亂（當屬上句，或涉下而衍）。譯文已順讀為兩條，處理正確，但**應出校注說明**，否則讀者比對原文會困惑。同理「擊攊他不受諫」拆為二條，也宜一併注明。

**4.「三時無事遊行」**
注「春夏冬三時」可再補：印度一年分三際，此指無正當因緣而終年遊行人間；「無事」＝無三寶、病等因緣。若不敢定，可標待考。

**5.「經居士家」（#43）**
「經」是「往至／經過」，譯「進入居士家中」稍重，可作「到居士家」；「自乞」宜點出「**為自己**（無病緣）乞求」。八事注（酥、油、蜜、石蜜、乳、酪、魚、肉）正確，是很好的補注，可再加「石蜜＝粗製糖塊」。

## 四、句式問題（#40）

原譯：「從今以後，絕不可再度重犯，如護鵝珠比丘（…）、草繫比丘（…）無異。」
——「如…無異」在中文裡懸空，讀來斷裂。建議重組：

> 「妳應當自責其心，生起厭離罪業之意。從今以後，更不可重犯，**要像護鵝珠的比丘（鵝吞寶珠，寧受拷打也不說出，以護鵝命）、草繫的比丘（被賊以生草繫縛，寧受困不動，以免傷斷生草）那樣護持淨戒，與他們沒有兩樣。**」答說：「弟子頂戴受持，不敢重犯。」

另外 #39「汝識是罪否／答識」，主語是譯者補的（懺悔主問、犯者答），建議加括號标明「（懺悔主）問／（懺悔者）答」，與 #45「（懺悔主的）誡責」體例一致。

## 五、小結

- **必改**：壞生種、草繫注、「非池」、和尚尼、「輒」字三處、大僧標明。
- **必補**：結尾定型句白話化、上表未譯諸條、「二事」釋義。
- **必注**：「強敷／惱他」是否兩條、「一搥胸露身」校勘、「不舉」錯簡。
- 其餘（別眾食、背請、手搏、不受食、減半月洗浴等）釋義無誤，可保留。
