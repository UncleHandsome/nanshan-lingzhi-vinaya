# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【136-0001】02_戒疏/06a_卷二上之二#103
【原文】【記】次科，初敘機劣。內凡已上，不羸不捨，已前皆容有退，故云「退位」，即外凡也。「故」下，顯開意。「往」謂開捨，「來」謂再受。善、惡兩通，故云「無障」。「即」下，結歎權巧。「王」者，得其自在。於法自在，故稱「法王」。
【譯文】【記文】在第二段中，首先敘述凡夫根機的劣弱。內凡位以上的心性堅固，不致羸弱也不會捨戒；在此之前的位階都有退轉的可能，所以稱為「退位」，也就是指外凡夫。「故」字以下，顯明開許捨戒的意圖。「往」是指開許捨戒還俗，「來」是指回心再次受戒。無論向善或向惡都不加死板阻絕，所以說「無障」。「即」字以下，結語讚歎佛陀的權巧方便。「王」是指能夠通達自在毫無阻礙。對法門得大自在，所以尊稱為「法王」。

【136-0002】02_戒疏/06a_卷二上之二#104
【原文】【疏】《增一》云：「僧伽摩比丘，七反降魔，後更受戒，得成羅漢。自今捨戒，聽齊七反；若過，非法。」《十誦》云：「尼若捨戒，轉為男者，亦得出家。」
【譯文】【疏文】《增一阿含經》說：「僧伽摩比丘，七次被欲魔逼降（捨戒還俗），後來再次受戒，最終依然證得了阿羅漢果。從此之後捨戒的規定，聽憑最多可以達到七次；如果超過七次，就是不如法的非法之行。」《十誦律》說：「比丘尼如果捨戒之後，生理轉變為男性，也可以再次被度化出家。」

【136-0003】02_戒疏/06a_卷二上之二#105
【原文】【記】三中。初引比丘開限。降魔不免破戒，故先捨之，極齊七反，已外不開，開中制也。次引《十誦》，明尼不開。轉根方得，反知不轉，即障出家。又《伽論》中「尼捨再受，即成賊住」是也。
【譯文】【記文】在第三段中，首先引用比丘捨戒次數的上限。被欲魔降伏而不免破戒，故先捨戒，極限以七次為準，七次之外不再開許，這是開許規定中的嚴格限制。接著引用《十誦律》，說明比丘尼原則上不開許捨戒後再受戒。只有在生理轉變成男根時才被允許，反之如果沒有轉變男根，就成為出家的絕對障礙。此外在《摩訶僧祇律論》中也規定「比丘尼若捨戒後又再次受戒，就直接視為賊住身分」，指的就是這個道理。

【136-0004】02_戒疏/06a_卷二上之二#106
【原文】【註】佛言：「若有比丘不樂梵行，聽捨戒還家。復欲出家，於佛法中修梵行者，應度出家，得受大戒。云何不名捨戒？若自顛狂、心亂、痛惱、瘂、聾，又向如是人前，及中、邊人等互捨，不成。若戲，若眠，若無知人，若自不語，若前人不解，並不成捨。若言『我捨佛，捨法，捨僧、和尚、戒律』、『我受家法』等，是名『捨戒』也。」
【譯文】【註文】佛陀說：「若有比丘不樂於修持清淨梵行，聽許他捨戒返回家中。日後若又想出家，在佛法之中修持梵行，僧團應當度他出家，得以再次受大戒。怎樣的情況不算是捨戒？如果自己處於癲狂、神智混亂、重病痛苦煩惱逼迫、或是啞巴、聾子，又或者向這種癲狂昏亂的人面前，以及中印度人與邊地外國人言語不通互相捨戒，都不能成就捨戒。如果純屬開玩笑、或是在熟睡中、或是面對完全無知聽不懂話的人、或是自己並未開口說話、或是對方根本沒有聽懂領受，全都不算成就捨戒。如果親口說出『我捨棄佛、捨棄法、捨棄僧、捨棄和尚、捨棄戒律』、『我現在願意領受在家的俗法』等語，這才叫做真正的『捨戒』。」

【136-0005】02_戒疏/06a_卷二上之二#107
【原文】【疏】注中，「云何不名捨戒」下，分二：初、「自顛狂」下，心境不了，雖捨不成；「若言捨佛」下，對境彰成，文相可解。
【譯文】【疏文】注解之中，從「怎樣的情況不算是捨戒」以下，分為兩部分：第一、從「自顛狂」以下，是指如果心神錯亂或是所對的境緣無法理解溝通，雖然做了捨戒動作也不能成就；從「若言捨佛」以下，是指心意明瞭且對著合格的對象如法宣告，捨戒便告成立，文句表相很容易理解。

【原文】【記】注文。前段即敘佛開，上科已示。故從「云何」下，分其文耳。
【譯文】【記文】注解部分。前面一段是敘述佛陀開許捨戒的慈悲，在上一個科判中已經說明過了。所以此處直接從「云何」以下，切分其經文層次。

【136-0007】02_戒疏/06a_卷二上之二#109
【原文】【疏】就捨戒中，義分四門：一、汎列經論捨相不同；二、漸頓異；三、捨善已未；四、具捨緣。
【譯文】【疏文】關於捨戒的內涵，在義理上分為四門來探討：第一、普遍列出各部經論中捨戒相貌的不同；第二、辨析漸次捨與頓時捨的差異；第三、辨明所捨的善業是已生起還是未生起；第四、具備捨戒的必備因緣。

【136-0008】02_戒疏/06a_卷二上之二#110
【原文】【疏】言「汎列」者。如《雜心》說：「若捨、命終、斷善、二形生也。」《善生經》加「受惡戒時捨善戒。」《俱舍論》：「八戒期心，盡夜分終，故捨。」且列如此。
【譯文】【疏文】談到「普遍列出」：例如《雜阿毘曇心論》中說：「透過作法宣誓而捨、壽命終結而捨、斷絕善根起大邪見而捨、身體轉變為雙性二形而捨。」《優婆塞戒經（善生經）》則增加了「在領受惡律儀惡戒時，自會捨去善戒」。《俱舍論》說：「八關齋戒的誓願是以夜晚結束（至次日天明）為期，所以期限一到便自然捨戒。」姑且在此羅列這幾種。

【136-0009】02_戒疏/06a_卷二上之二#111
【原文】【記】捨戒中，初科。若準注文，但明作法，統括諸文，則有六種，故云「汎列」。「《雜心》」四捨，言「若捨」者即「作法」，「斷善」即起邪見。「《善生》惡戒」，即惡律儀。上五通五、八、十、具。《俱舍》「期心」唯局八戒，義兼五戒。言「且列」者，示未盡故。
【譯文】【記文】在捨戒的第一個科判中。如果依照戒本的注解，純粹只是說明透過言語作法的捨戒；但如果統括歸納所有的經論文獻，則共有六種捨戒途徑，所以說是「普遍羅列」。《雜心論》的四種捨戒，所說的「若捨」就是指「宣告作法捨戒」，「斷善」是指生起否定因果的極端邪見。《善生經》的「受惡戒」，是指領受了屠宰、打獵等惡律儀。上面五種通於五戒、八戒、十戒以及具足戒。《俱舍論》的「期心」則局限在八關齋戒，義理上也兼通五戒。文中說「且列」，是表明種種異說尚未完全窮盡。

【136-0010】02_戒疏/06a_卷二上之二#112
【原文】【疏】二、漸頓者，即作法捨中。如《律》「我作沙彌、五戒」等，是漸也；「我作白衣、外道」等，為頓也。
【譯文】【疏文】第二、辨析「漸捨與頓捨」，這屬於透過言詞作法捨戒的範疇。例如依照《律藏》宣告「我現在轉作沙彌、轉受五戒」等，這是漸次捨戒；宣告「我現在轉作在家人、轉作外道」等，這就是頓時徹底捨戒。

【136-0013】02_戒疏/06a_卷二上之二#115
【原文】【疏】問：「今捨戒者，為捨已生隨行為因之業？為捨初願本受無作體邪？」
【譯文】【疏文】有人提問：「現在捨戒的人，所捨掉的究竟是過去已經生起、作為未來感果之因的隨行善業呢？還是捨棄了最初發願時本來所領受的無作戒體呢？」

【136-0014】02_戒疏/06a_卷二上之二#116
【原文】【疏】答：「已生為因，不可捨也。得聖無漏，方傾善習。今所捨者，止是本體，更不相續。故《雜心》云：『言捨戒者，戒身種類滅也。』」
【譯文】【疏文】回答：「過去已經造作生起、成為感果之因的善業，是絕對不可能捨掉的。必須一直修行證得聖者無漏智慧時，才能徹底傾覆拔除這種有漏善業的習氣牽引。現在捨戒所捨掉的，只不過是當初所納受的無作戒體本體，使其在未來不再相續延續罷了。所以《雜心論》說：『所謂捨戒，是指防非止惡的戒身相續種類消滅了。』」

【136-0015】02_戒疏/06a_卷二上之二#117
【原文】【記】三中。初標科。「善」，謂隨中二持之行。未捨之前，所有持行，名「已生善」；後未修者，名「未生善」。今明捨戒，為捨何者？
【譯文】【記文】在第三門中，首先標明科判名稱。「善」是指隨中二持之行。在捨戒之前，所有實踐過的持戒行為稱為「已生善」；日後尚未修持的善行稱為「未生善」。現在探討捨戒，究竟是捨掉哪一個？
