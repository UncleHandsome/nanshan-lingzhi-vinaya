# 校閱材料　第1160檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1160-0001】資持記/08e_中二#24
【原文】犯相既異，故須各列。過用中，第二時中者，準此；若犯過前求，則不犯過前用。〔《多論》止犯吉羅。〕三中或但受畜，或同眾受，如下注顯。廣辨中，初科。初示衣體；彼下，明兩限。十種衣如〈二衣〉中。受用中。《僧祇》文列六制：一不得當三衣者，本非法衣故。〔急緣應得。
【譯文】犯相既然不同，所以必須分別列出。在「過用」中，第二項「時中」，依照這項規定；如果觸犯了提前求取，就不會再犯提前使用。〔《多論》只判定輕罪（吉羅）。〕第三項中或者只是個人接受蓄積，或者與僧眾一同接受，如下面的注文所表明。在詳細辨析中，第一個條目。首先顯示衣服的形質；從「彼」以下，說明求與用的兩個期限。十種衣服就像〈二衣〉中所說。在受持使用中。《僧祇律》列出六條禁制：第一不能充當三衣，因為原本就不是法衣。〔遇到緊急緣由應當可以。

【1160-0002】資持記/08e_中二#25
【原文】不淨施者，復非長故。〔上二並約時內，如下《五分》，過時須受說。〕不入河者，恐易壞故。〔下云垢液亦開。〕小雨不用者，不成浴故。不裸身著者，恐污觸故；舍勒，梵語；舊記云短裙之類，《鼻柰耶》云：泥洹僧也。餘故衣，如襯內圍巾之類。不著作事者，非本開故；
【譯文】不作淨施，因為它並不算長物。〔上面兩項都是指在應當使用的期限之內，如同下面《五分律》所說，過了期限就必須受持說淨。〕不穿著跳入河中，恐怕容易損壞。〔下面說有污垢油脂時也開許。〕下小雨不用，因為無法構成沐浴。不裸體穿著，恐怕會產生污穢觸碰；「舍勒」是梵語；舊傳的註記說是短裙之類，《鼻柰耶》說是泥洹僧（內衣）。其餘的舊衣服，就像穿在裡面的圍巾一類。不穿著去勞動勞作，因為這不是原本開許的用意；

【1160-0003】資持記/08e_中二#26
【原文】聽作障者，無所損故。衣相中，指古。云傀儡子者，木戲人也。今下，顯非。引文中。《僧祇》披浴，彌彰上義。液謂津膩。《多論》中，初明求作。彼云從三月半至三月盡應作；若得成衣，四月一日應畜〔畜，即用也。〕；
【譯文】允許用來作遮蔽，因為這沒有損害。衣服的外相中，指出古代的說法。說像「傀儡子」的，就是木偶戲人。從「今」以下，指明其錯誤。引用文中。《僧祇律》說披著沐浴，更能突顯上面的含義。「液」是指身上的油脂分泌。《多論》中，首先說明求取與製作。那裡說從三月十五日到三月底應當製作；如果做成了衣服，四月一日應當蓄積〔畜，也就是使用。〕；

【1160-0004】資持記/08e_中二#27
【原文】若不成衣，乃至四月半聽求聽作，故云乃至亦爾等。又云：設三月十六日得，一二日即成者，亦得畜用；約準今宗，正犯後戒；部計之異，不可和會；須知求通一月，用限半月，不可濫也。次明畜法，初明本開。長下，明衣量。《四分》長六搩手，則同彼論；廣二磔手半，則廣五尺。
【譯文】如果沒有做成衣服，乃至到四月十五日都允許求取、允許製作，所以說「乃至亦爾」等。又說：假設三月十六日得到，一兩天就做成功的話，也可以蓄積使用；若比照本宗的規定，正好觸犯了後面那一條戒；部派見解的差異，無法強行調和；必須知道求取的期限通貫一個月，使用的期限僅限半個月，絕對不能混淆。接著說明蓄積的法則，先說明最初的開許。從「長」以下，說明衣服的尺寸。《四分律》長六搩手，就和該論相同；寬二磔手半，就是寬五尺。

【1160-0005】資持記/08e_中二#28
【原文】以夏下，明開意。既為護衣，故得覆雨，不唯著浴也。此浴下，釋妨。恐謂浴衣那將覆雨，故此釋之。若據今戒，名雨浴衣，謂著雨中浴。是則戒本名兼用局，《多論》名局用通也。《僧祇》不通餘用，與論小異。若著下，以不用正衣，方便免過也。捨法中，前引二律明制捨。下引《僧祇》出捨法。
【譯文】從「以夏」以下，說明開許的本意。既然是為了保護衣物，所以可以用來遮擋雨水，不單單是穿著來沐浴。從「此浴」以下，解釋疑問。恐怕有人會認為浴衣怎麼能拿來遮雨，所以在這裡作了解釋。如果根據現在這條戒，名稱叫做「雨浴衣」，是指在雨中穿著沐浴。這樣看來戒本的名稱兼含而用途狹窄，《多論》則名稱狹窄而用途廣泛。《僧祇律》不允許兼通其他用途，與該論稍有出入。從「若著」以下，說明因洗浴時未穿用正衣（雨浴衣），故以此權巧方便來免除過失。在捨棄的方法中，前面引用兩部律典說明規定必須捨棄。下面引用《僧祇律》提出捨棄的作法。

【1160-0006】資持記/08e_中二#29
【原文】文無受法，故注準之；但改受字為異。不得十六者，以入冬分故。不犯有四。初開限滿不捨吉。二著浴者，此約無犯明不犯。浣舉二緣，開不用吉。二十八。〔佛在毘蘭若，聽受夏衣，六群多受；後於舍衛安居中，大臣為安居施，因開而制。〕戒名中。施主本為安居故施；
【譯文】文中沒有受持的作法，所以注文中比照辦理；只將「受」字改換作為區別。不能超過十六日，因為已經進入冬天的時節。不犯戒的情況有四種。首先開許期限已滿卻不捨棄的輕罪（吉羅）。第二穿著沐浴，這是從沒有犯戒的本體來說明不犯戒。清洗與收存這兩種緣由，開許免除不使用的輕罪（吉羅）。第二十八條戒。〔佛陀在毘蘭若時，聽許接受夏衣，六群比丘過度接受；後來在舍衛國安居期間，大臣為了安居而行布施，因而由開許轉為制戒。〕戒名中。施主原本是為了安居而布施；

【1160-0007】資持記/08e_中二#30
【原文】忽有急緣，不及夏竟，預先持施；佛開安居未竟，十日內受，故有二過，如緣所解。注文簡濫。疏云：不同雨衣一事生二；以受用雖異，同是雨衣。此戒過前犯由受施，過後罪據畜長，故云不同也。列緣有二，過前中。初緣，引律釋急施開意。三中，自恣十日在，即七月初六已後得受；
【譯文】忽然有了緊急變故，來不及等到結夏圓滿，便預先拿來布施；佛陀開許在安居尚未結束前，十天之內可以接受，所以會產生兩種過失，如同犯戒條件所解釋的。注文用來分辨混淆。《戒疏》說：不同於雨衣是一件事生出兩種過犯；因為雨衣接受與使用雖然不同，本質都是同一件雨衣。而這條戒提前違犯是由於接受布施，延後結罪則是根據蓄積長物，所以說情況不同。列出的犯戒條件有兩部分，在「過前」之中。第一個條件，引用律文解釋急施開許的用意。第三項中，自恣還有十天在，也就是七月初六以後就可以接受；

【1160-0008】資持記/08e_中二#31
【原文】爾前輒受，名過前。四無緣者，律不犯中，若奪衣失衣過前取無犯。過後中。第三緣者，準知前後無互犯也。四中。律云：若寄衣比丘遠行、水陸道斷，過後不犯。第五若七月六日受，至八月十五即說；不說十六日犯。〔若受德衣至十二月十五說淨，下增準說。
【譯文】在那之前擅自接受，就叫做「過前」。第四項沒有特殊緣由，律文不犯戒中，如果衣服被奪走、遺失而提前拿取，不算犯戒。在「過後」之中。第三個條件，依此推知前後兩種犯戒不會相互混淆。第四項中。律中說：如果是寄託衣服的比丘遠行、水陸交通阻斷，過了期限不犯戒。第五項如果在七月六日接受，到八月十五日就應當說淨；不說淨的話，十六日就犯戒。〔如果受持了迦絺那衣，則到十二月十五日說淨，下面遞增的情況比照這項推說。

【1160-0009】資持記/08e_中二#32
【原文】初七受者，前減一日，後增一日。〔八月十六說淨，不說十七犯。〕如是乃至十五日受，前減九日，後增九日。〔八月二十四說淨，不說明日犯。〕是名次第潧也。次科指廣。今且撮示時非時相。夏竟一月五月名時，餘則非時。初明本是時衣，非時而受，故於時外更開十日〔即急施也〕。
【譯文】初七日接受的，前面減一天，後面增一天。〔八月十六日說淨，不說淨十七日犯戒。〕像這樣一直到十五日接受，前面減九天，後面增九天。〔八月二十四日說淨，不說淨次日犯戒。〕這就叫做「次第增長」。下一個條目指引詳博之處。現在姑且提綱挈領說明時衣與非時衣的分界。結夏圓滿的一個月或五個月叫做「時」，其餘時間則叫做「非時」。首先說明本來屬於時衣，卻在非時的情況下接受，所以在此時段之外另外開許十天〔也就是急施衣〕。
