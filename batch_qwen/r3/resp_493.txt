整體看下來，這批譯文水準不錯，術語（波羅夷、偷蘭遮、棄捐不受、常住、白衣等）處理大致到位。但有幾處**判讀錯誤或漏譯**，另有若干增譯、指代不明的地方。按輕重分列如下。

---

## 一、必須修正（意思錯了或漏了結論）

**1. 【493-0004】「佛物無護，如《鼻柰邪》斷施主故」— 漏結論＋因果錯接**

譯文：「若是佛陀物品而無人照管，如同《鼻奈耶律》所說，**這是因為斷絕了施主供佛福報的緣故**。」

- 疏意是：有守護主 → 望護主結重；**佛物沒有守護主 → 改從「斷施主福」這一面結罪，同樣犯極重**。下一條【記】「初望護主……二、斷施福，**並犯夷重**」正是明證。
- 譯文把「斷施福」寫成「佛物無人照管的原因」，因果顛倒，且最重要的「亦犯極重」不見了。
- 建議：「佛物若沒有守護的人，則如《鼻奈耶》所說，從斷絕施主福報這一方面結罪（同樣犯極重罪）。」

**2. 【493-0007】「同塔事故」≠「造塔佛事」**

- 律意是：佛園、坐具等，一切天人應供養，**因為它們與佛塔同等**（故不得移用）。不是「等同於造塔的功德」。
- 建議：「……一切天人都應供養，因為等同於佛塔的緣故。」

**3. 【493-0014】「引例」譯成「引用法義作為類比」**

- 「引例」是**引用同類事例（《薩婆多論》施法之例）作比況**，不是「引用法義」。
- 建議：「從『如』字以下，引用同類事例作比況。」

**4. 【493-0011】「事同屬佛」未點出所指**

- 「屬佛」是專指**第二類「屬佛物」**，不是泛指「屬於佛陀的財產」。
- 建議：「因為情況與第二類『屬佛物』相同，依義理類推即可明白。」

**5. 【493-0013】「義同佛家之所攝故」主語不明**

- 被「佛家所攝」的是**侍佛之人**（侍佛者義同佛的家人眷屬，故得受用供佛之物），不是「物品」。譯文「在法義上**這**是屬於佛家所收攝眷顧的緣故」，讀者會誤以為指物。
- 建議：「因為在義理上，侍奉佛陀的人如同佛家眷屬一般被攝受的緣故。」

**6. 【493-0018】「書經像」譯為「書寫經典畫像」語意含混**

- 「經像」＝經卷與佛像，動作是「書經、畫像」。
- 建議：「在紙、白絹、竹、木上書寫經典、繪製佛像」。
- 同段「曾經盛貯」宜補受詞：「曾經用來盛裝貯存經像」。

**7. 【493-0002】「佛、法無主」增譯失真**

- 譯文「佛陀與正法又**沒有具體形相的物主**」，讀來像「沒有長相的主人」。原意是：僧物有守護主而難掌，**佛物、法物則沒有（守護的）主人**。
- 建議：「僧團的物品極難掌管，佛物、法物又沒有守護的主人。」

**8. 【493-0014】「若施法者」譯「布施正法的人」易生歧義**

- 「施法」是**布施供養「法（法寶）」之物**，不是「布施佛法／為人說法」。且與【493-0013】譯作「布施法物」不一致。
- 建議兩處統一：「若有人布施供養法寶之物，應分作兩分……」

## 二、意思略偏／增譯過多（建議調整）

| 出處 | 問題 | 建議 |
|---|---|---|
| 0007 | 「佛陀**親自**受用之物」 | 疏文明說「曾為**佛像**之所受用」，「親自」易誤為釋尊在世親用。作「佛（像）所受用之物」 |
| 0007 | 「金石」→「**金銀**、石材」 | 金＝金屬（造像材料），無「銀」。作「金屬、石材」 |
| 0007 | 「常擬供養」→「經常準備作為供養」 | 是「恆常擬定（保留）作供養之用」，非「時常準備」 |
| 0007 | 「生世大福」→「令**世間眾生**生起廣大福德」 | 增譯了「眾生」；宜作「能生世間大福報」（此語亦可再核《鈔》記） |
| 0009 | 「通擬佛用」→「**通盤**意在供給佛事使用」 | 重點在「通泛、未限定用途」，與前類「曾為勝相、剋定」相對。作「原本施主只是泛泛指定供佛使用」 |
| 0009 | 「故唯一定」→「**唯獨**永久固定」 | 「唯」是語助，非「唯獨」。作「所以決定不可改轉」 |
| 0012 | 「物別」→「物品**性質**雖然不同」 | 指種類不同（幡華 vs 錢寶人畜）。作「物品種類雖與前類有別」 |
| 0013 | 「獻佛物」→「食品**雜物**」 | 【記】明說「飲食、果實等」，「雜物」無據 |
| 0016 | 「後還入常住」→「歸還回常住僧眾**庫房**」 | 「庫房」為增添；作「事後仍應歸入常住（僧物）」 |
| 0005 | 「佛無我所」→「佛陀並無**自我所有權的概念**」 | 現代法律語感太強；宜作「佛沒有『我所』的攝護（占有）之心」 |
| 0002 | 「畏後世業」→「畏懼來世**惡業**」 | 所畏是後世的**業報苦果**，作「畏懼後世的業報」 |
| 0002 | 「三寶中，初科」→「在三寶的**類別**中」 | 是「（盜）三寶物這一科中的第一科（總敘）」，非三寶的分類 |

## 三、行文與一致性建議

1. **「餘廣如《鈔》」**（0004、0013）譯「其餘詳情**正如**《行事鈔》所載」，語氣變成斷言；這是指示參閱語，宜作「其餘廣說，詳見《行事鈔》」。
2. **「物相」「物體」**（0008「具體樣貌」、0019「物品的本體」）：科判用語的「相／體」指**物品的體相、種類**，非哲學義的「本體」，建議統一作「標示物品的種類（體相）」。
3. **「白衣」**（0014）譯「白衣居士」略窄，白衣泛指在家人（未必受戒），作「在家人／白衣」較穩。
4. **0001「擔任寺院掌管執事僧務的人」** 疊床架屋，可簡作「寺院中掌管事務的知事人」；「罪福……極其深重」的「深重」多用於罪，福報宜作「罪與福的果報都極為深大」。
5. **0017「也有四種情況」** →「也有四類」，與下文四類物體一致。
6. **0015** 補「這些侍者」與答文「後還入常住」相合，判讀正確，可保留；「事後」屬增譯，但無害。

## 四、判讀無誤、可放心者

- 0002 引《大集》二種人（阿羅漢／須陀洹、淨持戒識業報／畏後世有慚愧悔心）、「自無瘡疣」的處理。
- 0005「棄捐不受」保留原譯語並加括注「即波羅夷重罪」，作法很好；「今文不出，故指如彼」的疏通也正確。
- 0008「法身無相，隨物以彰」、0018「滅理之所依持……望涅槃而生罪福」、0019「止是世物，但望所詮，至真無價」的義理掌握都到位。
- 0014「義通道俗」、《善見》道俗皆得食，以及「例今侍佛，得食無疑」的推論層次清楚。
