# 校閱材料　第1094檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1094-0001】資持記/07a_中一下#45
【原文】彼謂小機力劣，不約心論；善惡二業，皆由色造；能造是色，所發亦色；故作無作，竝色為體。彼部宗師，雖多解判，未善權意；故至《業疏》，的指體相，方為盡理。故疏文云：如律明業，天眼所見；善色惡色，善趣惡趣，隨所造行，如實知之；以斯文證，正明業體是色法也。
【譯文】彼宗認為小乘根機力量劣弱，不能從唯心層面去談；善惡二種業力，全都是由色身動轉所造作；能造的工具是色法，所引發的業體自然也是色法；所以作戒與無作戒，全都以色法為體。彼部的宗師們雖然做出許多解釋與判斷，但未能體會佛陀隨機設教的權巧本意；所以到了《業疏》中，確切指陳出體相，這才算窮盡了至理。因此疏文說：如同律中說明業力，能被天眼通所看見；造善業者現善色、造惡業者現惡色，往生善趣或墮入惡趣，隨所造的行業，天眼都能如實了知；以此文為證，正顯明業體的本質就是色法。

【1094-0002】資持記/07a_中一下#46
【原文】又云：然此色體，與中陰同，微細難知，唯天眼見；見有相貌，善惡歷然；豈約塵對，用通色性；諸師橫判分別所由，考其業量，意言如此。〔故知彼論，但計無對法入假色。指為細色，獨出今疏。〕二明本宗《成論》，過分小乘；教雖是小，義乖小道；雖通大乘，非全大教；
【譯文】又說：然而這個業色之體，與中陰身的性質相同，微細極難了知，唯有清淨天眼才能看見；看見它具備相貌，善業與惡業歷歷分明；哪裡只是藉由法處無對假色，來勉強通稱為色性呢？諸位法師橫加評判分別戒體的由來，真正考察有宗的業體實相，本意就是如此。（由此可知，那部論典表面上只計執無對法處假色。直指它是細微色質，唯獨出自南山《業疏》的深見。）第二，說明本宗《成實論》（假名宗），屬於超過分量的小乘。教義雖然名義上屬於小乘，但義理卻違背了小乘的淺道；雖然通向大乘，卻還不是純全的大乘教法；

【1094-0003】資持記/07a_中一下#47
【原文】比前為勝，望後還劣，是故立體兩楹之間。初明作戒，色心能造；色是本教，心即過分；及論所發非色非心，非色過分，非心本教。《大集》所謂曇無德師，覆隱法藏；《戒疏》亦云：包括權實，其義在茲。若論作戒，猶可循文；獨茲無作，歷代沈喪，故須顯示。
【譯文】比前面的有宗殊勝，但望向後面的大乘依然劣弱，所以它建立戒體是介於兩大支柱的中間地帶。首先闡明作戒，是由色法與心法共同造作；色法是小乘本教的意涵，心法則是超拔小乘的分位；等到論及所引發的無作戒體是非色非心：非色是超拔小乘的分位，非心則是停留於小乘本教。《大集經》所謂曇無德律師隱覆遮藏法藏；《戒疏》也說：這部律涵蓋包括了權教與實教，其深意就在這裡。如果談論作戒，還可以依循經文去理解；唯獨這個無作戒體，歷代都被沉淪埋沒喪失真義，所以必須明確開示。

【1094-0004】資持記/07a_中一下#48
【原文】非色非心，得名多別；二對作釋，如上成宗。二翻作釋，疏云：由作初起，必假色心；無作後發，異於前緣，故強目之非色心耳。三簡教釋，非色簡小，非心讓大。四迭廢釋，作戒，云身口是具，無作名非色，即對廢有宗二戒；又言：非心，自廢本宗作戒。
【譯文】「非色非心」得名的因緣有很多種不同分別：一、對照作戒作解釋，就如同上述成宗的論述。二、翻轉作戒作解釋，《業疏》說：由於作戒最初發起時，必定假藉色身與心思；無作戒在隨後發起，性質迥異於前面的生滅外緣，故勉強號名為非色心耳。三、簡別教門作解釋：非色是簡別排除小乘有宗，非心則是謙讓推崇給大乘圓教。四、重疊廢除作解釋：作戒說身口只是工具，無作戒稱為「非色」，這就是針對廢除了有宗主張二戒皆色的說法；又說「非心」，則是自我廢除本宗把作戒說成是思心所的執著。

【1094-0005】資持記/07a_中一下#49
【原文】五遣疑釋，初疑作既假具，必應是色，故言非色；及解無作，乃云心起；又疑是心，故云非心。若論其體，既是心成，體豈他物；但由教限，不可濫通；教既是權，體寧從實。且如《成論》，言色則無記頑色，談心則六識妄心；是以非色，則云非塵大所成；
【譯文】五、遣除疑惑作解釋：初學者疑慮作戒既然假藉身口工具，那戒體必定應當是色法，所以說是「非色」；等到解釋無作戒，卻又說是從心生起；初學者又疑慮無作戒是心法，所以說是「非心」。如果要討論它的體性，它既然是由心所成就，本體難道還會是其他外在事物嗎？只是由於教化時節的界限，不能混亂混雜地宣通；教門既然屬於隨機權巧，法體又豈能完全依據究竟實理來顯露呢？且如《成實論》，一談到色法，就指無記頑鈍的質礙色；一談到心法，就指六識的虛妄意識；因此說它非色，是指它並非微塵四大所組成；

【1094-0006】資持記/07a_中一下#50
【原文】非心，乃謂體非緣慮；良由善性記業，比色全乖；業體無知，與心實異。究論體貌，實唯心業；但不談種子，故名非色；不說梨耶，故言非心。故《業疏》云：考其業體，本由心主〔從作起故〕；還熏本心〔本心即六識，望作云還。〕，有能有用〔能謂牽後，用即對防。〕；心道冥昧，止可名通；
【譯文】說它非心，是指它的本體沒有攀緣思慮的功能；全因具有善性的感應業力，與物質色法全然違背；而業體本身缺乏靈知覺受，又與認知的心王確實不同。若究極探討它的體貌，本質上純粹就是心識造業之氣分；只因為小教不談種子之名，所以名為非色；不談阿賴耶識之體，所以名為非心。因此《業疏》說：考察那個業體，根本是由心念所主導（因為從作戒生起故）；隨後還熏返照自心（本心即是前六識，相對於作戒的造作所以稱還熏），具有功能與防非止惡的妙用（能是指牽引後報，用是指對境防非）；心性之理幽深冥暗難辨，只能借用名相通達其意；

【1094-0007】資持記/07a_中一下#51
【原文】故約色心，窮出體性〔兼緣義也〕；各以五義，求之不得〔不相應也〕；不知何目，強號非二〔兩求不得，不可名而名，故云強號。若在彼宗，但計非二；纔云強號，即顯教權。須知強號之言，始見今疏。〕。三圓教者，即大乘義。前之二釋，俱不了教；故《涅槃》中，或色非色，俱為諍論；
【譯文】因此從色法與心法兩端，竭盡推求它的體性（這正是兼帶外緣的義理）；各用五種義理去求索，都不可得（因為與色心兩者皆不相應）；不知道該用什麼名字去稱呼它，只好勉強號稱為「非色非心」這二非。（兩方求索皆不可得，無法命名而勉強命名，所以說「勉強號稱」。如果依據該宗原本見解，只會死執它是非色非心；只要一說出「勉強號稱」，當下就顯發出這個教法只是權巧施設。必須知道「強號」這兩個字，最初正是見於道宣祖師的《業疏》。）第三，圓教宗，這就是大乘的究竟了義。前兩種解釋，全都是不究竟了義的教門；所以《涅槃經》中，或者說是色法、或者說是非色法，學者各執一端互相諍論；

【1094-0008】資持記/07a_中一下#52
【原文】如來明判，不解我意；是以祖師，深取大乘圓實了義；決開權教，顯示我等壇場受體；意使修持，投心有處。今分為二，初示圓體。即明梨耶隨緣變造，含藏種子。初明能造，還即六識；但依八起，即異小乘；縱有兼色，此色亦心，不同小宗心色體別。二明所發，即心所造；
【譯文】佛陀明確判定：這全都是不理解我的真意！因此南山祖師，深刻採取大乘圓滿實相的了義；剖析開啟了權教的遮蔽，徹底顯示出我們在戒壇受戒時真正所得的本體；目的是讓修行者在持戒修持時，心靈有個安頓歸宿之處。如今分為兩部分，首先開示圓教戒體。這就是闡明阿賴耶識隨緣變現造作，含藏萬法種子。最初說明能造之因，歸根究底還是前六識；然而依託第八阿賴耶識而生起，這就完全不同於小乘；縱使兼帶有身口色法，這個色法當體也是唯心所現，不同於小乘宗派將心法與色法視為體性各別。第二，說明所發起的戒體，正是由心所變造；
