# 校閱材料　第204檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【記】言諍，下品中。三法現前，與後五法相濫。初簡人者。三中能所合論，俱別人故；五中人者，但收所諍，能斷屬後「僧」中。二、簡法者。前是教文，後即羯磨。三、簡毗尼。前約開迷殄息，五據選德同評。是則此三，名通事局；僧、界二種，名體俱局。

【204-0041】02_戒疏/21b_卷四下之三#14
【原文】【疏】五、「多人語」者。由評法相，取解不同。故召兩朋，同處面決。行籌五德具八法者，三種量度，詳審眾情，又知義理，邪正明決，依法行之。非法者多，且令散去，後當更斷，待法語人。事希法隱，故略不述。

【204-0042】02_戒疏/21b_卷四下之三#15
【原文】【記】第五，初科。先敘緣，即注從初至「不了」也。「故」下，次示制法，即注「以事白佛」已下文也。「八法」者，《律》云：「不愛、不恚、不怖、不癡、知已行不行，有如是五法，應差行舍羅。」并解三種行籌法，共為「八」也。「三種」，如注所列。「舍羅」，即籌。籌有二別，一完，二破。從正者捉完籌，隨邪者捉破籌，多者為是。細尋可解。注中，「此律」下，示別名。「事希」下，三、顯略。

【204-0043】02_戒疏/21b_卷四下之三#16
【原文】【疏】今亦有師共諍佛性，或道理有，或執行成，俱有俱無，不能自決。十住羅縠，凡下絕思。義須三藏，據理取斷。是名事露法隱，誰有行之？
【譯文】【疏文】如今也有法師共同爭論佛性，有的主張道理上本具，不假修證；有的堅持由修行功力方能成就；有的主張兩者皆有，有的主張兩者皆無，自己無法裁決。連十地菩薩看佛性都如隔著輕紗薄紈，凡夫更斷絕了妄加思度的可能。按義理必須依憑三藏聖典，根據正理來加以裁斷。這就叫做「事情顯著而行法晦沒」，現在又有誰能施行呢？

【204-0044】02_戒疏/21b_卷四下之三#17
【原文】【記】次科。「或理有」，謂理性本具，不假修證，此執有也。「或行成」者，謂行功所成，非性本有，此計無也。「俱有」，謂亦理具亦修成，此計兩亦。「俱無」，如定性聲聞、闡提無等，此執雙非也。然彼佛性，不墮四句，凡計一竭，俱為戲論。「十住」字誤，合云「十地」，或通指十聖，或但第十地及等覺人。彼見佛性，如隔羅縠觀月，喻其末明。《涅槃經》云：「菩薩位階十地，尚不了了知見佛性，何況聲聞緣覺之人能得見耶？」文況下凡，非彼所測，則可知矣。「義」下，明合用此法。由是言諍，須教殄滅。「是」下，傷時不用。「露」，顯也。法何所隱，由人不行耳。
【譯文】【記文】第二科。「或理有」，是指理性本來具足，不假借後天修證，這是執著於「有」。「或行成」，是指靠修持功力所成就，並非自性本來具有，這是執著於「無」。「俱有」，是指既在理體上具足也在修持上成就，這是執著於「兩者皆是」。「俱無」，如同認為定性聲聞、闡提沒有佛性等，這是執著於「兩者皆非」。然而那佛性，根本不墮入這「四句」的分別中，凡是執計一端，全都是戲論。疏文中的「十住」字有誤，應當作「十地」，或者通指十聖位，或者單指第十地與等覺菩薩。他們見佛性，如同隔著輕紗觀月，比喻尚未徹見圓明。《涅槃經》說：「菩薩果位高達十地，尚且不能清清楚楚地見到佛性，何況聲聞、緣覺之人哪裡能得見呢？」經文以此況顯下位凡夫，更非凡夫所能測度，理當可知。「義」以下，說明理當採用這種羯磨法。正因為這是言語的諍論，必須以聖教來平息消滅。「是」以下，感傷當前時代已無人施行。「露」，就是顯露。羯磨法哪裡會自我隱蔽，全是因為沒有人去推行罷了。
