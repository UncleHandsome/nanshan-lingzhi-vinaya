# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【292-0001】02_戒疏/15b_卷三下之三#111
【原文】【記】二、轉變中。《十誦》「甘蔗」轉成四藥，且據時藥一物具四為言。自餘諸物，或三或二，轉變不定。又復七日可轉非時、盡形，如蜜為漿，石蜜燒灰之類；盡形可轉為時，如前杏人、薯芋之類；唯非時漿體無轉變。西土石蜜有二：黑石蜜似此砂糖，白石蜜如此米糖。
【譯文】【記文】第二、藥物轉變中。《十誦律》說「甘蔗」可以轉變成四種藥，這只是依據時藥的一種物品具備四種轉變而說的。至於其他各種物品，有的能轉成三種，有的能轉成兩種，轉變情況並不固定。再者，七日藥也可以轉變為非時藥與盡形壽藥，例如蜂蜜調水成為非時漿，石蜜燒成炭灰成為盡形壽藥這類情況；盡形壽藥也可以轉變為時藥，例如前面所說的杏仁、山藥一類；只有非時果漿其本體無法再作其他轉變。西印度地區的石蜜有兩種：黑石蜜類似此地的紅砂糖，白石蜜則類似此地的麥芽糖或白糖。

【292-0002】02_戒疏/15b_卷三下之三#112
【原文】【疏】三、明相和門。《律》中，時藥含四，作時服之，盡形唯一。不許非時隨名而服。此則義乖。如《多論》云：「四藥相和，從強而服。如蘇煑肉汁，為七日藥。蘇、乳如葶藶子，作終身服。」亦如《鈔》說。
【譯文】【疏文】第三門、說明調和門。《四分律》規定，時藥可以包含後三種藥，當作時藥來服用；盡形壽藥只能單獨服用一種。不允許在非時的時段隨意依據所混入的藥名而服用。這種說法在義理上有些違背。如同《薩婆多論》所說：「四種藥互相調和時，順從藥力強大的一方來受持服用。例如用酥熬煮肉汁，整體作為七日藥受持；酥與乳酪中混入葶藶子，整體作為終身盡形壽藥受持。」這也詳見於《事鈔》的說明。

【292-0003】02_戒疏/15b_卷三下之三#113
【原文】【記】三、相和中。初引本律《藥犍度》中：「初約時藥，用下三藥相和，作時藥受；二、非時藥，用下二藥相和，作非時受；三、七日用下一藥相和，作七日受；四、盡形用盡形相和，作盡形受。」盡形下無可兼，故云「唯一」。文舉初後，中二準知。「不」下，決文不了。謂初時藥得兼下三，時中而服，下之三藥不得兼時，非時中服，故云「不許」等。「如」下，引證。則明四藥並許相和，隨名而服。「酥煑肉汁」，則七日兼時，「酥、乳和葶藶」，則七日與時和盡形，豈非互通耶？下指四藥，須者尋之。
【譯文】【記文】第三、調和配伍中。首先引用本律《藥犍度》的記載：「第一、關於時藥，拿後面三種藥與之調和，作為時藥受持；第二、非時藥，拿後面兩種藥與之調和，作為非時藥受持；第三、七日藥，拿後面一種藥與之調和，作為七日藥受持；第四、盡形壽藥，只拿盡形壽藥互相調和，作為盡形壽藥受持。」盡形壽藥底下沒有其他藥物可以兼納了，所以說「唯一」。經文只列出了開頭與結尾，中間兩種可以依此準知。「不」字往下，判定律文在表述上尚未圓融通達。意思是第一種時藥能夠兼納後面三種，在應食的時間內服用，但後面的三種藥卻被認為不得兼帶時藥而在非時服用，所以說「不許」等語。「如」字往下，引用論典作證。這證明四種藥完全開許互相調和，隨順藥力較強者的名稱來受持服用。「酥煮肉汁」，就是七日藥兼帶了時藥；「酥、乳和葶藶」，就是七日藥與時藥混入了盡形壽藥，這難道不證明藥物是可以互相融通的嗎？下文指示詳見四藥篇，需要的人應當去查尋研讀。

【292-0005】02_戒疏/15b_卷三下之三#115
【原文】【疏】初、二受意者。手受五意，如下戒說。口受多意。防護手受，過時不失，又防不受、殘宿、惡觸、內宿二提兩吉，罪不得生。廣說其相，不可誦也。
【譯文】【疏文】第一、兩種受持法的本意。手受的五種意圖，如同在後面的「不受食戒」中所說。口受則有多種意圖。一方面是為了守護手受的效力，使得藥物過了時間其受法不致失落；另一方面也是防範未經手受、食殘宿食、惡觸食、內宿食等兩條波逸提與兩條突吉羅罪，使這些罪名無從產生。若要廣泛宣說其中的相狀，無法全部口誦說盡。

【292-0006】02_戒疏/15b_卷三下之三#116
【原文】【記】第二受法十門，初門二。初明手受五意。「如下」，即指不受食戒，下引《多論》云：「一、斷盜竊因緣；二、為他證明；三、為止誹謗；四、為成少欲知足；五、為生他信敬心故。」次明口受，有二意：一、防手受；二、防諸罪，略分四罪，如後自明。「廣下」二句，囑令講者引下說之。
【譯文】【記文】第二受持方法十門中的第一門，分為兩節。首先說明手受的五種本意。「如下」，就是指不受食戒，下文引用《薩婆多論》說：「第一、斷絕偷盜的因緣；第二、為他人作證明；第三、為了平息誹謗；第四、為了成就少欲知足；第五、為了令旁人生起信敬心。」接著說明口受，有兩層意義：第一、守護手受的效用；第二、防範各類罪過，大略分為四種罪，後文自然會明瞭。「廣說」以下兩句，是囑咐講經律師應當引導聽眾參照下文予以宣說。

【292-0008】02_戒疏/15c_卷三下之三#1
【原文】【記】二中，初科又二。初明手受。「若」下，次明口受。時藥不為延時，但有手受，若有因緣，口加三受，為代手受，故云「互不通」也。「如」下，引示口受。「如諸律」者，《僧祇》「邪見人與食」，并「俗人寶器盛食」，竝口加三受。《十誦》，不相解人。《五分》「火燒馬屋」，送食置地竝口受。「即此律」者。《律》因神足比丘往外道國乞食，彼嫌比丘，以食置地捨去。佛言：「離手已，成與竟。」下明三藥，並須口受，必先手受，則二受互通也。
【譯文】【記文】第二大段之中，第一小科又分為兩部分。起初先說明手受。「若」字以下，接著說明口受。時藥並非為了延長食用期限，平常只要手受即可；如果有特殊因緣，口中加念三遍受法，是用來代替手受，所以說「兩種受法互不相通」。「如」字以下，引用諸部律典來指示口受的實例。所謂「如諸部律所說」：《僧祇律》記載「邪見外道給予食物」，以及「在家人用珍貴寶器盛放食物」，都必須口中加念三遍受法。《十誦律》中，則是針對語言不通的人。《五分律》記載「大火焚燒馬房」時，送來的食物直接放在地上，也是口受。所謂「即本律所說」：本律記載因為一位具備神通的比丘前往外道國家托缽乞食，外道嫌惡比丘，把食物丟在地上就走開。佛陀說：「只要食物一離開他的手，就已經成立給予了。」下面說明其餘三種藥，都必須口受，而且此前一定先經過手受，這樣手受與口受兩種受法就互相貫通了。

【292-0009】02_戒疏/15c_卷三下之三#2
【原文】【疏】如昔解云：時、非時藥不須口法，時非近遠故也。
【譯文】【疏文】如同古德的解釋說：時藥與非時藥不需要口受作法，因為時藥與非時藥並非為了延展時限（古本作近遠）的緣故。

【292-0010】02_戒疏/15c_卷三下之三#3
【原文】【記】次科。昔判「時藥」可爾，「非時」不然，故須點破。「近」合作「延」，傳寫錯也。彼謂非時不為延日，故不須加。
【譯文】【記文】這是第二小科。古德判定「時藥」不需要口受作法還可以說得通，「非時藥」卻非如此，所以必須指出其錯誤。疏文中的「近」字應當作「延」字，是抄寫時傳抄錯誤。古德認為非時藥並非為了延長到隔天，所以不需要口加受法。

【292-0011】02_戒疏/15c_卷三下之三#4
【原文】【疏】今解無文，不足依據。今所明者，時藥分局，止在午前，無可加延，不勞口法。非時一藥，若不加法，過午須臾，時時失受，故須立法加被，方得久延。故文云：「不應今日受漿，留置明日。」以受法有限，既具非時，不通時也。後之二藥，患非卒除，功由漸降，故約藥勢遠、近兩緣加法被物，服用無咎。如《十誦》云：「是三種藥，舉宿、惡捉、不病，不手受、口受，並不得服。反上者得。」此良證也。
【譯文】【疏文】現在看來古德的解釋缺乏律文依據，不足以作為憑據。現在所要說明的道理是：時藥的時限非常局限，僅止於正午前，沒有辦法再作法延長，所以不必勞煩口受作法。而非時藥這一種，如果不用口法加持，過午片刻，即於時藥時限中失去受法，所以必須制定作法加持護持，方得長久延續。因此律文說：「不應當今天接受飲漿，卻留置到明天。」因為受法的期限有限，既然具備了非時法，就不能通到時藥的時間服用。後面的兩種藥（七日藥與盡形壽藥），疾病不是立刻就能消除，藥效也是逐漸減退，因此依據藥力延續的遠、近兩種因緣，以口法加持護持藥物，服用才不會有過失。正如《十誦律》說：「這三種藥，若是隔夜存放、不如法捉持、無病而蓄、未經手受或口受，全都不得服用；反之合乎以上規矩的，才可以服用。」這就是極好的明證。

【292-0012】02_戒疏/15c_卷三下之三#5
【原文】【記】三中。初斥妄。「今」下，正明。初明時藥不須。次明三藥須加。初明非時。雖不延日，而須延時。「故」下，引證。初引文。「以」下，出文意。「既具非時」，謂加非時法故，不許明日時中服也。「後」下，次明七日、盡形。「功漸降」者，謂治病有強弱也。「藥勢」有「遠近」者，七日勢強故近，盡形勢降故遠。「咎」即是罪。「如」下，引文。通明三藥，有過無過，則知非時須加明矣。「舉宿」即殘宿，并「惡捉」，並有過故。「不病」，非所開故。「不手口受」，以無法故。
【譯文】【記文】在第三小科中。起初先駁斥錯誤的說法。「今」字以下，正式說明正理。首先說明時藥不需要口法。接著說明其餘三種藥必須加持口法。先說明非時藥：雖然不能延長到隔天，卻必須延長到正午之後的時間。「故」字以下，引證說明。起初引用律文。「以」字以下，闡述律文的深意。「既然具備非時法」，意思是說既然加持了非時法，就不允許在明天的時藥時間內服用。「後」字以下，接著說明七日藥與盡形壽藥。「藥效逐漸減退」，是指治療疾病的力量有強有弱。「藥力」有「遠近」之別：七日藥的藥力強，所以期限近；盡形壽藥的藥效更為平緩，所以期限長遠。「咎」就是罪過。「如」字以下，引用律文。通貫說明這三種藥有過失與無過失的情況，由此就能明白非時藥必須加持口法是毫無疑問的。「舉宿」就是隔夜宿食，以及「惡捉」（不如法捉持），這兩者都是有罪過的。「無病」，不是開許服用的情況。「未經手受口受」，是因為沒有合法的受持儀軌。

【292-0013】02_戒疏/15c_卷三下之三#6
【原文】【疏】三、論授人者，手受五義，除自同類，餘有六眾三趣，皆成授也。口法不爾，必是同類，先手受訖，對法六和，方得加也。
【譯文】【疏文】第三、論述授藥之人的身分：手受具備五種涵義，除了自己的同類（比丘）之外，其餘六眾弟子以及能解人語的異趣（天、鬼、畜等）三趣，全都能成立授藥。口法則不是這樣，對方必須是自己的同類比丘，並且自己先已經手受完畢，對著具備六和敬僧相的同修，才能加行口受之法。

【292-0014】02_戒疏/15c_卷三下之三#7

【譯文】【記文】在第三門中。起初先說明手受。七眾弟子之中「除去同類比丘」，「三趣」之中揀別除開不能理解者，其餘皆可相通成立手受。接著說明口受：口受嚴格局限於「同類比丘」，其餘身分全都不能對之作法。必須彼此身分本質相同，才可以相對加持，所以說「六和敬」等。

【292-0015】02_戒疏/15c_卷三下之三#8
【原文】【疏】四、作法中。說藥雖四，若作法時，須相領當。彼此錯互，皆不成受。又如《羯磨疏》及《鈔》中廣引。

【292-0016】02_戒疏/15c_卷三下之三#9

【292-0017】02_戒疏/15c_卷三下之三#10
