# 校閱材料　第724檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【724-0001】02_戒疏/16a_卷四上之一#75
【原文】【疏】上品一句，識法識犯。如德衣加受，功用須知，名識法也。如有違越，或吉或提，開合衣、藥，定罪多少，名識犯也。餘相例解，不能具出。由本戒無失，復不愚學，識達皎然，名為上品持律。
【譯文】【疏文】上品有一句，即通曉法式亦通曉犯相。例如受持功德衣，必須明瞭其功德作用，這叫做通曉法式。若有違背超越，或結吉羅或結單提，在衣物、藥品開許與禁止之際，能判定罪過之多寡，這叫做通曉犯相。其餘的行相依此例推理解，不能全數列出。由於根本戒無所過失，又不對學戒愚昧昏聵，了達分明如日照空，所以稱為上品的持律者。

【724-0002】02_戒疏/16a_卷四上之一#76
【原文】【記】上品中。初標句。「如德衣」下，舉前「背」、「別」開法，委釋其相。言「加受」者，謂作羯磨，人別三受。「功用須知」者，《鈔》云：「能感多衣，衣無敗壞。」又云：「以眾僧同受此衣，便招五利功德。」、「如有違越」者，謂受德衣有多制法：一、應時節，須安居竟；二、簡衣體，製造合法；三、簡受人，唯須當界前安居具三衣人；四、簡持人，須具五德等。一事乖法，受則不成。既不成受，妄開背、別，一一戒下，各有「提、吉」之罪。重輕不定，故云「或」也。「開合衣、藥」，謂背請戒，或單衣食請為開，或兼衣食請為合，有背不背，如後自明。「定罪多少」，謂二戒下有方便、根本、重輕等相，亦如後說。「餘」下，指十一戒。「由」下，結位。
【譯文】【記文】上品之中。先標示詞句。「例如受持功德衣」以下，舉出前述「背請」、「別眾食」的開緣法，詳細解說其行相。所謂「受持」，是指作羯磨法，每個人各自三遍受法。所謂「必須明瞭功德作用」，《行事鈔》說：「能感得諸多衣物，衣物不至毀壞。」又說：「因為全體僧眾共同受持此衣，便招感五種利益的功德。」「若有違背」是指受功德衣有許多戒條法度：第一、順應時節，必須結夏安居結束；第二、揀擇衣體，製造須合法律；第三、揀擇受衣之人，必須是當界內作前安居且具備三衣之人；第四、揀擇持衣之人，必須具備五種德行等。只要有一件事違背法式，受衣便不能成就。既然受衣不成就，妄自開許背請、別眾食，在每一條戒下，各自都有「波逸提、突吉羅」之罪。輕重不一，所以說「或」。「衣物藥品的開閉」，是指背請戒中，或者單純請衣物飲食為開，或者兼具衣食為合，有違背與不違背的差別，後文自會明晰。「判定罪之多寡」，是指這兩條戒下有方便罪、根本罪、輕罪重罪等相，也如同後文所說。「其餘」以下指其餘十一條戒。「由於」以下結出其品位。

【724-0003】02_戒疏/16a_卷四上之一#77
【原文】【疏】中位有四：初識法疑犯；二、識法不識犯；三、疑法識犯；四、不識法識犯。識同前解。言疑法者，謂受德衣用法有四，疑一、二、三，不能通決。言不識法者，迷昏不學，任物牽行，是非由他，自無尺寸。於犯疑闇，例此可知。然於一事由帶一識，故判以為中品持律。
【譯文】【疏文】中位有四句：第一、通曉法式而疑惑犯相；第二、通曉法式而不通曉犯相；第三、疑惑法式而通曉犯相；第四、不通曉法式而通曉犯相。通曉的涵義同於前面的解釋。所謂疑惑法式，是指受功德衣的方法共有四種，對其中第一、二、三項心存疑惑，無法徹底決斷通達。所謂不通曉法式，是指昏昧而不修學，任憑外物牽引盲行，是非全由他人擺布，自己胸無點墨、全無尺度。對於違犯起疑或昏昧，依此例推便可知曉。然而在同一件事上，由於尚帶有一項明瞭，所以判定為中品的持律者。

【724-0004】02_戒疏/16a_卷四上之一#78
【原文】【記】中品，分三。初列句。「識同」下，牒解有三。初識指前。疑中，言「四法」者：一、和僧單白法；二、差持衣人白二法；三、正受衣法；四、出德衣單白法。不識中，「任物牽行」，如盲人也。「自無尺寸」，不能度量也。學者明教，教即目、尺。有目則能見險夷，有尺則不迷長短。後生聞此，猶不省耶？「於」下，次例迷犯。謂於犯上有「疑、不識」，準上釋之。「闇」即不識。「然」下，三、結位。「一事」合云「一法」，或可事名是通，存亦無失。
【譯文】【記文】中品分為三段。先列出各句。「通曉同於」以下牒釋其義，分為三點：首先「通曉」指前文。在疑惑中，所說的「四種法式」為：一、僧眾和合的單白法；二、差派持衣人的白二法；三、正式受衣法；四、捨除功德衣的單白法。在不通曉中，「任憑外物牽引盲行」，如同盲人摸索。「自己全無尺度」，是無法衡量度量。學者若通達教法，教法即是雙眼與度尺。有了雙眼便能看清險路與平地，有了度尺便不致混淆長度與短缺。後世之人聽聞此理，難道還不反省嗎？「對於」以下，接著比照對於違犯的昏昧，是指在犯相上有「起疑、不識」，準照上面來解釋。「闇」即是不識。「然而」以下，第三結出其品位。「一件事」照理應當說「一法」，或者因為「事」這個名詞涵蓋較廣，保留下來也沒有過失。

【724-0013】02_戒疏/16a_卷四上之一#87
【原文】【記】示罪中。兩指「如上」，即前諸篇。上品，無罪。中品四句，不學四吉，無知二疑吉，二不識提，共八罪也。下品不學八吉，無知四疑吉，四不識提，即十六罪。此門總二十四罪，十八吉六提也。
【譯文】【記文】指明罪過之中。兩處指稱「如同前面」，即前述諸篇。上品者無罪。中品四句，有四個不學吉羅罪，兩個無知起疑吉羅罪，兩個不識單提罪，共八個罪。下品有八個不學吉羅罪，四個無知起疑吉羅罪，四個不識單提罪，即十六個罪。這一門總共有二十四個罪，計有十八個吉羅罪、六個單提罪。
