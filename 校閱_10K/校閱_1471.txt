# 校閱材料　第1471檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1471-0001】04_比丘尼鈔/05a_卷下之上#30
【原文】第三受法初受時食者未受已前要須識知食體兼作普受之意方得成受故律云欲受油錯受蘇等並不成受皆須心境相當方得名受唯除眼暗及不喜見沙門得置地受　二受非時漿口法者諸律雖制受服而無受法自下受法及說淨等並準文義出依行彌善手執湯漿至一比丘尼前云。
【譯文】第三「受持之法」（受法）：
首先「受持時食」：在接受之前，必須清楚識別食物的本質，同時心懷平等普受大眾的心念，方能成就受法。所以戒律說：本想受油卻誤受為酥，皆不能成立受法；必須心念與外境相符，才稱得上是手受；唯獨除了雙眼失明、以及不喜見僧人的情況，才開許將食物置於地上受取。
第二「受持非時漿的口說作法」：各部戒律雖然規定受持服用，卻未寫明具體的受持詞句；以下所列的受法與說淨等詞，皆依據律文義理引申而出，如法依循實踐最為完善。手捧熱湯或果漿，走到一位比丘尼面前說道：

【1471-0002】04_比丘尼鈔/05a_卷下之上#31
【原文】大姉一心念。我比丘尼某甲。今為渴病因緣故。此是薑蜜湯。為欲夜分已來服故。今於大姉邊受。
【譯文】「大姊一心念，我比丘尼某甲，如今為了渴病因緣故，這是薑蜜湯，為了要在夜分已來服用故，如今在大姊處受持。」

【1471-0003】04_比丘尼鈔/05a_卷下之上#32
【原文】若蒱桃棃奈諸。果漿等隨其病緣類牒說之若頓受不過須臾飲盡者不勞加法　三受七日藥者。
【譯文】若是葡萄、梨、奈等諸果漿，隨其病緣類比陳說即可；若是一次受用、片刻間即可飲盡者，不勞加法。第三「受持七日藥的作法」：

【1471-0004】04_比丘尼鈔/05a_卷下之上#33
【原文】大姉一心念。我比丘尼某甲。今為熱病因緣故。此是酥七日藥分。為欲七日共宿服故。今於大姉邊受如是風病服油冷病服蜜雜病服石蜜等類牒可知　四受盡形藥者。
【譯文】「大姊一心念，我比丘尼某甲，如今為了熱病因緣故，這是酥七日藥分，為了要在七天之內共宿服用故，如今在大姊處受持。」
像這樣風病服油、冷病服蜜、雜病服石蜜等，類比陳說即可知曉。
第四「受持盡形壽藥的作法」：

【1471-0005】04_比丘尼鈔/05a_卷下之上#34
【原文】大姉一心念。我比丘尼某甲。今為氣病因緣故。此是薯蕷丸盡形壽藥。為欲共宿長服故。今於大姉邊受。
【譯文】「大姊一心念，我比丘尼某甲，如今為了氣病因緣故，這是薯蕷丸盡形壽藥，為了要共宿常服故，如今在大姊處受持。」

【1471-0006】04_比丘尼鈔/05a_卷下之上#35
【原文】如是薑桂及餘丸散等隨病因緣類牒可解若買藥令俗人斷價定已比丘尼自選今多於本分買竟然後遣稱已受取不得置地即須對同伴尼加其口法如其不爾停過須臾失受惡觸罪生不能如是之時令俗人受取持歸和搗竟然後口受最善。
【譯文】像這樣生薑、肉桂以及其他丸散等，隨病情因緣類比陳說即可明解。若買藥令在家人議定價格確定之後，比丘尼自己挑選；如今多是在原處買妥之後，遣人秤妥受取，不得置於地上，必須立即對同伴比丘尼施加其口法；若不這樣做，停頓片刻便會失受，生起惡觸之罪。若不能做到這樣，在買藥時令在家人受取持歸，調和搗碎完畢之後然後口受，最為妥善。

【1471-0007】04_比丘尼鈔/05a_卷下之上#36
【原文】第四說淨者此七日藥一種作口法竟偏心屬己故須說淨以藥體是貴資身力強過畜延時無變動義若不說淨越過七日便犯捨墮餘之三藥不具前意不須說淨說淨方法如長衣法唯云長藥為異若初受藥忘不說淨者不成惡觸故律下文云受得生薑忘不說淨佛言應放地使淨人作淨已自應洗手更受故知忘受不成惡觸。
【譯文】第四「說淨之法」（說淨）：這種七日藥，作完口受作法之後，由於偏心專屬於自己一人，所以必須「說淨」（透過對首說法打破私有執念）。因為藥物本身珍貴，資助身體的力量很強，蓄存延時既無變質腐壞之憂，若不作說淨，一旦超過七天就會觸犯捨墮罪；其餘三種藥不具備上述情狀，所以不須說淨。說淨的方法與長衣說淨法相同，只是將「長衣」改稱為「長藥」即可。如果當初受藥時忘記說淨，並不會構成惡觸罪。所以本律下文說：受得生薑而忘記作淨（去種生相），佛說應當放置地上讓淨人作淨之後，自己再洗手重新手受；由此可知，忘記作淨並不構成惡觸。

【1471-0008】04_比丘尼鈔/05a_卷下之上#37
【原文】第五通塞者手受為防其盜一人受竟通餘尼共食無罪論其口法亦通餘人由其口法加他二通之藥一者味通二者手通故捨與前人受法不失。
【譯文】第五「通達與阻隔」（通塞）：手受是為了防範偷盜，一人受持完畢，轉給其他比丘尼共同食用並無罪過；論及口受之法，也能通及他人，因為口受作法加持了其他兩項相通的藥物特性：一是味道相通，二是手受相通；所以轉送給眼前之人，原有的受法效力並不會喪失。

【1471-0009】04_比丘尼鈔/05a_卷下之上#38
【原文】第六重受者義云論其手受觸失本受即須更受雖重無過若論口法依婆論云五日已還淨人來觸更餘不受藥來雜更加七日法不作二日法正從法論不從藥勢六日已去不得重加以藥物入淨故便隨藥勢更不加法若藥眾多不知何者是本藥應手口二受然後服之若病重尼不得口受傍人直爾為受與服亦得設看病尼為手口二受稱病人名亦得成受盡形壽藥若淨人來觸直爾手受不須作法以口法不失若餘藥來雜更口法受之。
【譯文】第六「重新受持」（重受）：《義釋》指出：論及手受，若經外力觸碰而失去原本的受法效力，就必須重新受取，即使重複受持也沒有過失。若論及口受，依照《薩婆多論》說：如果在五天之內，有淨人前來碰觸，或者混雜了其他未受持的藥物，應當重新追加作七日法，而不必作剩下兩天的法，這是完全依從受持律法來判定，而非依藥力的強弱來算；若是到了第六天之後，則不得重新追加，因為藥物已屆清淨效期，便隨藥力告終，不再追加作法。如果藥物數量繁多，分不清哪一份是原先的本藥，應當重新履行手受與口受兩種程序，然後再服用。如果是重病比丘尼無法親自口受，旁人直接代為受取給予服用亦可；假使照護病患的比丘尼代為行使手受與口受，口中稱呼病患的名字，也能成就受持之法。至於盡形壽藥，如果淨人前來碰觸，直接用手重新受取即可，不必再作口受程序，因為終身口受的效力並未喪失；如果混雜了其他藥物，才需要重新施以口受作法。

【1471-0011】04_比丘尼鈔/05a_卷下之上#40
【原文】此篇大門有十一一簡請二釋非三訃會四至家五就座六淨食七香願八受食九食儀十噠嚫十一還法。
【譯文】這一篇的大綱分為十一門：第一是揀擇請僧的性質，第二是解釋過失，第三是赴會集結，第四是抵達施主家，第五是就座儀軌，第六是使食物清淨，第七是行香祈願，第八是接受飲食，第九是受食儀規，第十是達嚫祝願，第十一是歸返僧坊之法。
