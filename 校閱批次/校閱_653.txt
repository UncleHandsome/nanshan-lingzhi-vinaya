# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】問浣染打實是三戒總制者何答皆是使尼處同復是始終由一衣生故問既制令尼洗衣何故不制熏鉢答染浣義易尼多閑解為洗義數熏治是難尼多不閑作之義稀故聖不制問令洗新衣何以輕耶答使洗義稀且不生過故制輕之又下二眾無有師義為洗即稀是以犯輕式叉尼是下眾使上尊浣衣義稀故犯輕罪。
【譯文】問：洗、染、打實是三戒，何以總相制戒？答：皆是使尼處所相同，復是始終由一衣而生故。問：既制令尼洗衣，何故不制燻缽？答：染洗之義容易，尼多通曉，為洗之義數多；燻治是難，尼多不曉，作之義稀，故聖不制。問：令洗新衣何以輕？答：使洗之義稀，且不生情染過失，故制輕之。又下二眾無師長之尊，為其洗即稀，是以犯輕；式叉摩那為下眾，使上尊洗衣義稀，故犯輕罪。

【653-0003】05_拾毗尼義鈔/03b_卷中之一#23
【原文】問衣中既立勸增價鉢無增者答衣資身義寬喜增故制鉢資身狹義稀所以不竝問若勸鉢增輕者乞鉢如何制同衣耶答實以鉢無多用然彼全乞一鉢惱處深故犯捨墮勸增非一故犯小罪問勸增縷何故乃至一縷亦犯乞衣一條與此相違答乞本施主先無心捨乃至乞時任彼籌量施與多少惱義是微故得一條方犯其勸增中虗心自施分限已定不荷其恩嫌少更索長貪惱彼情過最深故勿問多少隨增皆犯。
【譯文】問：衣中既立勸增價，缽何以無增？答：衣資身之義寬廣，喜勸增故制；缽資身狹隘，勸增義稀，所以不相並。問：若勸缽增價罪輕，乞缽何以制同於衣？答：實以缽無多用，然而彼全乞一缽，惱亂之處深重，故犯捨墮；勸增非全乞，故犯小罪。問：勸增縷何故乃至一縷亦犯，乞衣一條與此相違？答：乞衣本施主先無捨心，乃至乞時任彼籌量施與多少，惱義微弱，故得一條方犯；其勸增中，虛心自施，分限已定，不荷其恩，嫌少更索，長貪惱彼，情過最深，故勿問多少，隨增皆犯。

【653-0004】05_拾毗尼義鈔/03b_卷中之一#24
【原文】問若勸二居士增價一增一不增為犯前後答犯後戒唯增者犯不增者不犯猶是二人合作故問所以但勸二居士不勸三者答二合作一衣勸增損惱是多所以須制三合作多損惱是微是以不制問若三居士各為己作一布衣今勸三人合作紬衣豈可非損何以不制答此戒要本施衣體上增方犯今勸作紬落前乞衣戒中首解本為買絹今勸增買紬落在乞戒此戒要本施衣體上方犯下求縷亦爾。
【譯文】問：若勸二居士增價，一增一不增，為犯前戒犯後戒？答：犯後戒，唯增者犯，不增者不犯，猶是二人合作故。問：所以但勸二居士，不勸三者何？答：二人合出一衣，勸增損惱多，所以須制；三人合作損惱微，是以不制。問：若三居士各為己作一布衣，今勸三人合作紬衣，豈非損惱，何以不制？答：此戒要於本施衣體上增方犯；今勸作紬衣，落入前乞衣戒中。首解：本為買絹，今勸增買紬，落在乞衣戒；此戒要於本施衣體上方犯，下求縷亦爾。

【653-0009】05_拾毗尼義鈔/03b_卷中之一#29
【原文】問臥具制年限不制其揲坐具反前者何答臥具為取煖氣資身受用年多已去久故陳朽無資身義故制年限不制其揲坐具不取資身煖氣但恐汙僧臥具障身便罷但使體在不限年數既有坐具常得受用貪好更作是以制揲息著好心問若不揲者揲已便懺復何須捨答不揲舉體有過今雖更揲猶有本過體在故須捨其過量量內無咎先割量外然後懺罪故不須捨又可捨已便歸主無受用義故須割却不須捨也問若爾不揲捨已還主猶好亦應須揲答不揲為好捨已還我義同新得非我情過過量他與猶亦是犯母論云不揲坐具得羯磨已無不揲過。
【譯文】問：臥具制年限不制揲，坐具反前者何？答：臥具為取暖氣資身受用，年多已後陳朽無資身之義，故制年限不制揲；坐具不取資身暖氣，但恐污僧臥具，障身便罷，只要體在不限年數；既有坐具常得受用，貪好更作，是以制揲以息著好之心。問：若不揲者，揲已便懺，復何須捨？答：不揲舉體有過，今雖更揲，猶有本過體在，故須捨；其過量者，量內無咎，先割量外然後懺罪，故不須捨。又可捨已便歸主無受用之義，故須割卻不須捨也。問：若如此，不揲捨已還主猶好，亦應須揲？答：不揲為貪好，捨已還我義同新得，非我情過；過量他人與之受用猶亦是犯。《毘尼母論》云：不揲坐具得羯磨已，無不揲之過。

【653-0010】05_拾毗尼義鈔/03b_卷中之一#30
【原文】問八不淨物中展轉相易犯何罪耶答以金綿褥等二相易者提得餘六互者吉六六相易得小罪得餘二者犯捨此中若以八不淨物貿得十種衣皆得犯捨以十種衣貿得金銀錢綿褥氍毹轉得尼薩耆得餘六者吉多論云說淨錢寶得易衣外財作三衣鉢器入百一物數不須說淨已外須說若捨墮錢寶者易得衣財作百一物數先畜錢邊吉對首懺先畜寶邊僧中捨墮懺已貿衣財作百一物不須捨已入淨故。
【譯文】問：八不淨物中展轉相易，犯何罪？答：以金銀、綿褥等二物相易者，尼薩耆波逸提（捨墮）；得其餘六物互易者，吉羅；六六相易得小罪；換得前二物者犯捨墮。此中若以八不淨物貿得十種衣，皆得犯捨墮；以十種衣貿得金銀錢、綿褥、母毹，轉得尼薩耆；換得其餘六者，吉羅。《薩婆多論》云：說淨錢寶得換易衣外之財，作三衣缽器入百一物數，不須說淨，此外須說；若捨墮錢寶者，易得衣財作百一物數，先蓄錢邊犯吉對首懺，先蓄寶邊於僧中捨墮懺，懺已貿衣財作百一物不須捨，因已入淨法故。

【653-0012】05_拾毗尼義鈔/03b_卷中之一#32
【原文】問長衣戒本得有迦絺衣開鉢何故無答衣鉢體別益不及鉢有過不相損有利不相及所以無也問衣不利鉢何不受迦絺鉢答衣有三領為伽棃重故開功德衣雖離無罪兼益長故鉢唯有一常隨身受用何得受功德鉢既不開受不益長鉢故不言已出。
【譯文】問：長衣戒本得有迦絺那衣開許，缽何故無？答：衣缽體別，益不及缽，有過不相損，有利不相及，所以無也。問：衣不利缽，何不受迦絺那缽？答：衣有三領，為僧伽梨重故開功德衣，雖離宿無罪兼益於長衣；缽唯有一，常隨身受用，何得受功德缽？既不開受，不益長缽，故不言已出。

【653-0013】05_拾毗尼義鈔/03b_卷中之一#33
【原文】問何故不問迦提一月答鉢若未成本自無長何假開也其鉢若成已開十日足得說淨故無一月又餘衣有四時不同令洗浣故開有時限鉢即不爾故不相竝伽論問頗有一鉢即尼薩耆不答有謂不受持十誦問頗有比丘過十日畜長鉢不得捨不答有得鉢已轉根作尼者是也尼畜十日轉亦爾婆論問白色衣畜過十日犯白色鉢畜過十日何故不犯答衣可染令如意必成壞色更無增損儲畜義強故犯長過鉢若燒熏或令損壞難可如意是故不犯。
【譯文】問：何故不問迦提一月？答：缽若未成，本自無長，何假開許？其缽若成，已開十日足得說淨，故無一月。又餘衣有四時不同，令洗浣故開有時限；缽即不爾，故不相並。《摩得伽論》問：頗有一缽即尼薩耆否？答：有，謂不受持。《十誦律》問：頗有比丘過十日蓄長缽不得捨墮否？答：有，得缽已轉根作比丘尼者是也；尼蓄十日轉根亦爾。《薩婆多論》問：白色衣蓄過十日犯，白色缽蓄過十日何故不犯？答：衣可染令如意，必成壞色，更無增損，儲蓄義強，故犯長過；缽若燒燻或令損壞，難可如意，是故不犯。

【653-0014】05_拾毗尼義鈔/03b_卷中之一#34
【原文】問衣若過減皆成受持鉢何無此答衣者過可截減可續是以成受鉢無此事故不成受問乞鉢鉢無多用好者留置奪入僧庫為本寺故者乞得多衣亦惱施主兼損寺舍何不如鉢答衣本資身用寬故歸主鉢無多用資身義狹故須入僧問若爾長鉢過日亦無多用何不一鉢還主餘者入僧答畜長鉢或自己物易得或施主虗心捨施無損他義雖無多用生患處少故悉還主其乞鉢者一長貪求二惱施主三損寺舍四無多用如是生患義非一故須入僧。
【譯文】問：衣若過量、減量皆成受持，缽何無此？答：衣過長可截、減短可續，是以成受；缽無此事故不成受。問：乞缽，缽無多用，好者留置、奪入僧庫為本寺故者，乞得多衣亦惱施主兼損寺舍，何不如缽？答：衣本資身，用途寬廣，故歸主；缽無多用，資身義狹，故須入僧。問：若如此，長缽過日亦無多用，何不一缽還主、餘者入僧？答：蓄長缽或自己物易得、或施主虛心捨施，無損他義，雖無多用，生患之處少，故悉還主；其乞缽者，一張貪求，二惱施主，三損寺舍，四無多用，如是生患之義非一，故須入僧。

【653-0015】05_拾毗尼義鈔/03b_卷中之一#35
【原文】乞縷令織中何故但制俗非親里不制尼耶答俗屬官故尼即不爾又尼無自織法大僧知法使尼義稀假令為織但得小罪問若爾亦可但制使俗人浣衣不制尼耶答聖教聽尼自浣染衣是故大僧喜令尼浣妨彼修道又浣染義易更無多損故不犯也。
【譯文】乞縷令織中，何故但制俗人非親里，不制尼耶？答：俗人屬官役故，尼即不爾；又尼無自織之法，大僧知法，使尼之義稀，假令為織，但得小罪。問：若如此，亦可但制使俗人洗衣、不制尼耶？答：聖教聽尼自浣染衣，是故大僧喜令尼浣，妨彼修道；又浣染之義容易，更無多損，故不犯重罪。

【653-0016】05_拾毗尼義鈔/03b_卷中之一#36
【原文】問勸織師戒損居士縷與前勸一二居士問縷何異而別制之答前對縷主面勸此屏處勸織師所以有異問前戒有勸二居士合作衣戒此中何故無勸二織師合作衣戒答前對二居士面勸皆是縷主得有合衣義故制此中若二居士各遣一織師織衣比丘屏處勸二織師合作一衣既非縷主何有合義所以不制問此中亦與織師犯由前縷師何異答前戒損織師不損縷主以自得縷故此戒損縷主不損織師以與價故又前非親犯親即無犯此戒不問親不親皆有損縷主義故又前織成犯此領受犯所以別制問若奪沙彌衣不犯者下九十中隨沙彌不應與大僧同犯亦應犯輕答本與衣為欲共行沙彌非己同類與之義稀奪亦不數是故犯輕下僧作法擯舉竟皆不聽隨順同遵僧法損惱無殊是以同犯問奪沙彌衣及犯重比丘同得小罪者何故打即輕重不同答與衣本欲共行沙彌及犯重俱不得共行共宿義齊故同犯輕罪打本取惱犯重比丘與己同位損惱義深沙彌位別是其下眾受惱義微故輕重不同。
【譯文】問：勸織師戒損居士縷，與前勸一、二居士增縷何異而別制？答：前對縷主面勸，此於屏處勸織師，所以有異。問：前戒有勸二居士合作衣戒，此中何故無勸二織師合作衣戒？答：前對二居士面勸，皆是縷主，得有合作衣之義故制；此中若二居士各遣一織師織衣，比丘屏處勸二織師合作一衣，織師既非縷主，何有合作之義，所以不制。問：此中對織師結罪，由前縷師何異？答：前戒損織師不損縷主，以自得縷故；此戒損縷主不損織師，以給予價錢故。又前非親犯、親即無犯，此戒不問親與不親，皆有損縷主義故。又前織成犯，此領受犯，所以別制。問：若奪沙彌衣不犯，下九十單墮中隨順沙彌不應與大僧同犯，亦應犯輕？答：本與衣為欲共行修道，沙彌非己同類，與之義稀，奪亦不常數，是故犯輕；下文僧作法擯舉已，皆不聽隨順，同遵僧法，損惱無殊，是以同犯。問：奪沙彌衣及犯重比丘同得小罪者，何故打擊即輕重不同？答：與衣本欲共行，沙彌及犯重比丘俱不得共行共宿，義齊故同犯輕罪；打擊本取惱亂，犯重比丘與己同位，損惱義深；沙彌位別是下眾，受惱義微，故輕重不同。
