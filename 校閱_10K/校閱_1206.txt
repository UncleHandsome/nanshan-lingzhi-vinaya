# 校閱材料　第1206檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1206-0001】資持記/10c_中三下#38
【原文】三是護法。毘尼禁惡，毀則惡法熾然。又下，釋雜碎義。若據律緣，指下三篇威儀為雜，論約廣略對明純雜。緣中。二誦戒時者，不必在眾。五緣列三，疑是寫脫；準疏加之，而發言毀，五言詞了。釋中，初引《五分》。今時新戒，欲誦戒本，師多苦障，或加毀呰，正犯此戒。
【譯文】第三是為了護持正法。毘尼是用來禁絕惡事的，一旦毀謗，則惡法必然猖獗熾盛。「又」字以下，解釋「雜碎」的含義。如果依據律文的制戒因緣，是指下三篇微細威儀稱為雜碎；若依據各論典，則是以廣本與略本相對而言，區分出根本與枝末雜碎。犯緣中。第二項「誦戒之時」，不一定指在大眾集會之時。五個犯緣中只列出三種，懷疑是抄寫脫漏；依據《戒疏》補足的話，就是第四項「開口發言毀謗」，第五項「言詞明確清楚」。在解釋中，首先引用《五分律》。如今的新戒比丘，如果想要讀誦戒本，戒師往往苦苦阻礙，或者加以毀謗責難，這正是違犯了本條戒律。

【1206-0002】資持記/10c_中三下#39
【原文】《十誦》，初出毀詞。恐犯故疑惱，有犯則熱惱。若下，斷犯。《多論》，初呵戒本，通別兩犯。下明戒序通得一罪。引律。契經吉者，《多論》，四義故，毀毘尼重：一、能生萬善，二、一切佛弟子依住，三、趣涅槃初門，四、是佛法纓絡；餘經無故輕。
【譯文】《十誦律》首先列出毀謗之詞。因為擔心犯戒所以心生疑惑煩惱，如果有了犯戒行為則內心熱惱痛苦。「若」字以下，斷定所犯之罪。《薩婆多論》首先說呵斥毀謗戒本，通貫整部與單篇各得一罪。下文說明毀謗戒經序文通結一個罪。引用律文。毀謗佛陀親宣的契經結突吉羅罪，《薩婆多論》說基於四種含義，毀謗毘尼律藏罪過極重：第一、能生起一切善法，第二、一切佛弟子皆依止律儀而住，第三、是趣向涅槃的最初門徑，第四、是佛法的瓔珞莊嚴；其餘契經不完全具備此義所以結罪較輕。

【1206-0003】資持記/10c_中三下#40
【原文】又疏云：此據小乘為言；毀大乘罪重，非校量所辨。私謂：約制教邊，大小同吉；就業道邊，重輕須分。《智論》云：此間劫火起，其罪未盡，故轉至十方世界大地獄中；若彼火劫起，復展轉至他方；他方火劫起，復生此間阿鼻地獄，展轉如前；是破般若波羅蜜罪，又如《法華．譬喻品》偈廣明惡報。
【譯文】又《戒疏》說：這是依據小乘教法而言；毀謗大乘經教的罪過極為沉重，絕不是世間比較較量所能形容的。私下認為：從制教戒律層面來看，毀謗大乘小乘經律同樣結突吉羅罪；但就業道因果層面而言，輕重就必須嚴格區分了。《大智度論》說：此世界的劫火燃起時，那毀謗者的罪業尚未受盡，所以轉生到十方世界的大地獄中；如果那個世界的大火劫燃起，又輾轉受生到其他世界；其他世界的大火劫燃起，又重新受生回此間的阿鼻地獄，像這樣輾轉受苦如同前面所說；這就是破毀般若波羅蜜的重罪，又如同《法華經．譬喻品》中的偈頌廣泛闡明這類惡報。

【1206-0004】資持記/10c_中三下#41
【原文】不犯中。並謂期心後誦，非毀滅故。初開先習經論。雖無所犯，乖學次第，非本教意；《淨心觀》云：越學空宗，佛不隨喜是也。次開病緣，後開進行。謂直修三學，破惑取果，擬後誦之。故知至聖不違此制。七十三。
【譯文】不犯的情況中。都是指打定主意以後再去讀誦，並不是存心毀滅廢棄戒法。首先開許先修習經藏與論藏。雖然這樣做在戒律上沒有違犯，但違背了修學的先後次序，並非本教的原意；《淨心誡觀法》說：越次躐等去修學空宗，佛陀不會讚歎隨喜，說的就是這種情形。其次開許因病苦的因緣，最後開許致力於道業精進之人。這是指直接修習戒定慧三學，斷除惑障求取果位，打算證果後再來讀誦戒本。由此可知至高無上的聖人也不會違背這項規定。第七十三條戒。

【1206-0005】資持記/10c_中三下#42
【原文】〔佛在舍衛，六群中一人自知有罪恐舉，故先詣清淨比丘所言：我始知此法戒經所載耳，佛因制戒。〕戒名恐舉，據彼情也；疏作不攝耳戒，推其本也；古師云：詐驚張戒，與今語別意同。釋中，《僧祇》，初明結犯。彼律但據不聽判犯輕重，不必如緣待言方結。
【譯文】〔佛陀在舍衛國時，六群比丘中有一人明知自己有罪唯恐被僧眾舉發，所以先前往清淨比丘處說：我如今才知道戒經中記載了這條戒律呀，佛陀因而制戒。〕戒名取為「恐舉」，是依據他內心的動機；《戒疏》命名為「不攝耳戒」，是推求其犯過根本；古代律師稱之為「詐驚張戒」，與現今的語詞不同但用意一致。在解釋中，《僧祇律》首先說明結犯標準。該部律典只依據不聽聞說戒來判定罪過輕重，不一定像本緣起那樣必須等待口中說出才結罪。

【1206-0006】資持記/10c_中三下#43
【原文】疏云：若曾聞戒，即是久知，而言始知，結妄語提；若無知解，但有不攝罪。受下，次明制學。二部一部，並約廣律。又下，即是戒本。如初句者，文中略牒三篇；應準上云；又不能，當誦四眾戒等及偈，即諸惡莫作等。若下，三明制說，初制能說。餘下，制聽眾。餘業謂誦經等。
【譯文】《戒疏》說：如果曾經聽聞過戒律，那就是早已知曉，卻謊稱剛剛才知道，結妄語波逸提罪；如果確實毫無知見理解，則只得不攝耳聽戒的罪過。「受」字以下，接著說明規定應當研習的內容。兩部律與一部律，都是依據廣律而言。「又」字以下，就是指戒本。如同首句所說，律文中簡略提到了三篇罪名；應當依照前文所說補足：「又不能，當誦四眾戒」等；下文所說的「及偈」，也就是「諸惡莫作」等偈頌。「若」字以下，第三項說明規定宣說戒法，首先規定有能力宣說的戒師。「餘」字以下，規定聽戒的僧眾。其餘的學業是指讀誦經典等等。

【1206-0007】資持記/10c_中三下#44
【原文】戒是行本，攝修之要，故須正制，不許餘事。不犯中，若實未聞廣說，今始聞，若戲錯等。七十四。〔佛在羅閱祇，沓婆摩羅子為知事，僧得貴衣白二與之，六群後悔故制。〕初緣，僧物四種，如盜戒說；二種現前，可以和賞；二種常住，一切不開；
【譯文】戒律是行持的根本，是收攝身心修行的要務，所以必須作正式的制約規定，不許兼顧其餘雜事。不犯的情況中，如果確實未曾聽聞廣律宣說，如今才是第一次聽聞，或者開玩笑、說錯話等。第七十四條戒。〔佛陀在羅閱祇城時，沓婆摩羅子擔任僧團知事，僧眾獲得珍貴的衣物以白二羯磨獎賞贈送給他，六群比丘事後心生後悔，佛陀因而制戒。〕最初的犯緣，僧團的物產有四種，如同在盜戒中所說；其中兩種「現前僧物」，可以透過和睦決議來賞賜；另外兩種「常住僧物」，一切情況下都不得開許；

【1206-0008】資持記/10c_中三下#45
【原文】即衣鉢針筒尼師壇，下至飲水器，隨用賞之。三中反謗者，即《戒本》云：諸比丘隨親友以僧物與也。不犯者，其事實爾，隨親與之；若戲錯說。七十五。〔佛在舍衛多比丘論法毘尼，六群相謂諸比丘似為我作羯磨，從座起去，比丘喚住而故去，因制。
【譯文】也就是衣服、缽盂、針筒、尼師壇，下至喝水的器具，都可以隨其功用加以賞賜。第三項「反過來毀謗」，就是《戒本》所說：諸位比丘隨順自己的親近好友而將僧物私自給予。不犯的情況：事實確實如此，確實是隨順私親而給予；或者是開玩笑、口誤而言。第七十五條戒。〔佛陀在舍衛國時，多位比丘在研討法義與毘尼，六群比丘彼此私語說這些比丘似乎要為我作舉罪羯磨，於是從座位起身離去，比丘們呼喚叫他留下他卻故意離開，佛陀因而制戒。

【1206-0009】資持記/10c_中三下#46
【原文】初緣，疏云：此唯斷四諍事，不與欲者犯提，餘者吉羅。第五緣，律云：一足在戶內，方便欲去而不去，吉。釋中，初科《五分》，初明正犯。三羯磨謂單白白二白四。下約覆露明犯分齊。若下，次明輕過。次科，《僧祇》，初說毘尼。但非斷諍，故犯小罪。白即說欲。
【譯文】最初的犯緣，《戒疏》說：這只限於決斷四種諍事時，不託付同意權（不與欲）而逕自離座者犯波逸提罪，其餘情況結突吉羅罪。第五個犯緣，律中說：一隻腳尚在門內，採取了想離去的方便手段卻未真正離去，結突吉羅罪。在解釋中，第一科《五分律》，首先說明正犯的界限。三種羯磨是指單白羯磨、白二羯磨、白四羯磨。下文依據室內覆處與露天地界來界定犯罪的限度。「若」字以下，接著說明較輕的過失。下一科，《僧祇律》，首先說明宣說毘尼之時。只要不是正在評決斷定諍事，所以只犯微小之罪。「白」就是指陳託付同意權（說欲）。
