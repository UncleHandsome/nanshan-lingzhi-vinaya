# 校閱材料　第1257檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1257-0001】資持記/12b_中四下#36
【原文】見物作念，意欲不染。此下，斷犯。謂纔見忘物，即有屬己之念，故曰前生。前心已染，方起施心，故判不成。文下，引證。捨謂捨懺，遣即與人。反明不懺不成施故。三中，簡其所忘。餘戒本非貪畜，但是受納乖方，故不相染。三長反此，故有染也。四中。謂捨財者恐有所忘，決心預捨。
【譯文】一看到物品時便動了念頭，原本是希望能不被染污。從「此」字以下，判定為犯罪。這是指才剛看見遺忘的物品，心中立刻就生起了屬於自己的執著念頭，所以說是「先念先生」。先前這念貪心既然已經染污了物品，隨後才生起布施的心意，因此判定不能成立捨財。從「文」字以下，引述經律為證。所謂「捨」是指捨財懺悔，「遣」是指給予他人。這反過來證明如果不先懺悔，贈與他人的行為便不能成立。在第三點中，揀別所遺忘的物品性質。其餘戒條原本就不是出於貪心而蓄積，只不過是在接受納取時違反了規則，所以不會互相染污。三種長物則剛好相反，因此才會產生互相染污。在第四點中，是指捨財的人唯恐自己有所遺忘，預先決心將其全部捨棄。

【1257-0002】資持記/12b_中四下#37
【原文】後見無染，即須付彼。威儀中，初明處置衣物；彼下，後示捨衣儀相。初中前明別幞。若下，示離合，初明得合。謂三幞中別段同束也。又下，示須離。為分忘染故。長本有染，由貪積故；離定無染，受持物故；雜捨通者，據本無染；但為捨還入淨故染，故云通也。
【譯文】日後看見該物品時便不會產生染污，就應當直接將它交付給對方。在威儀的段落中，首先說明如何放置衣物；從「彼」字以下，接著示範捨衣時的具體行相。在前一部分中，首先說明要分別用包袱包裹。從「若」字以下，說明可以合併還是必須分開，首先說明可以合併的情形。這是指長衣、離衣、雜捨這三種包袱各自內部若有多段衣料，可分別捆成一束。從「又」字以下，說明必須分開的理由。這是為了區分遺忘與染污的界限。長物本來就具有染污的性質，是由於貪求蓄積所導致的；離宿衣則必定沒有染污，因為那是本分受持的資生物品；雜亂捨出的衣物之所以通融，是依據其本質上並無染污；只是因為在捨納還回時必須重新說淨才會產生染污，所以說它是通融的。

【1257-0003】資持記/12b_中四下#38
【原文】然據捨財，未必有忘；但欲表示三品不同，故須各襆。私釋。又為還財有隔日即座之異，故須各處。離衣雖同即座，受淨法異，故復兩分。正說中，初明和僧。雖不秉法，須問表和，成僧法故。以下，引證。雖通僧別，必約盡界。制不別眾，彌彰僧法，故必先和。文相等者，準文囑累。然下，次正陳詞。
【譯文】然而就捨財的常態而言，並不一定都會發生遺忘的情況；只是為了彰顯這三品罪相的差異，所以必須各自包裹。這是私下的註解說明。另外也是因為歸還財物有隔天處理與當場歸還的差別，所以必須分處放置。離宿衣雖然同樣是在當場歸還，但重新受持與說淨的作法不同，所以又分為兩種情況。在正式陳說（正說）的內容中，首先說明必須向僧眾宣導和合。雖然不正式秉持羯磨，但也必須詢問大眾以表顯和諧，這樣才能成就僧法。從「以」字以下，引述經教為證。雖然通融於全體僧眾或個別比丘，但必定要在全界範圍內進行。規定不得在僧團之外私自作法，這更能彰顯僧法的崇高，所以必定要先求得和諧。鈔文說「文相如是」等句，是指依照律文加以囑咐叮嚀。從「然」字以下，接著正式陳述詞句。

【1257-0004】資持記/12b_中四下#39
【原文】具列三物。出法如是，未必齊具。次明捨心，標中。財為犯境，故是罪緣；罪是結業，故能感報；心為業本，故是罪因。今行悔法，三種俱捨，故並云除。正明中，初文又三，初敘相續。此下，顯異。若下，示要。下指文者，即律明捨已僧不還者，犯吉。而不成盜，決意可知矣。
【譯文】完整列出三樣東西。所出的作法雖然如此，實際上卻未必樣樣齊備。其次說明「捨心」，這是在標題之中。財物是造罪的對象，所以是罪的助緣；罪是所結的業，所以能招感果報；心是業的根本，所以是罪的因。現在修持悔罪之法，這三樣都要捨，所以一併說「除」。在正式說明中，第一段又分三節：第一是敘述相續；「此」字以下是顯示差別；「若」字以下是指示要點。下文所指的文據，就是律中所說：已經捨了之後，僧眾若不把衣物還給他，便犯突吉羅；但這並不構成偷盜，其存心如何是可以斷定的。

【1257-0005】資持記/12b_中四下#40
【原文】顯宗中，初敘本宗。宗大乘者，分通義也；虛通無係者，因果推心也，即《業疏》云：捨財用非重，知心虛通；故發言誠者，即對僧捨也。言表於誠，既陳捨詞，則無貪畜，故云無滯結也。若下，次明他部諸捨不同。如《十誦》，二寶，少者永捨，多付淨人作四方僧臥具。
【譯文】在彰顯部派宗旨（顯宗）的內容中，首先敘述本宗的宗旨。本宗歸趣於大乘，具有分通大乘的深意；所謂通達無礙、無所繫縛，是指因果皆由心造的道理，這就如同《業疏》所說：捨財在物質功用上並不是最重大的，最重要的是通達內心的空靈無礙；因此發言懇切誠懇，就是指當著僧眾面前捨棄財物。言語表達了真誠的心意，既然已經陳述了捨財的言辭，內心就沒有貪著蓄積的情執，所以說是「沒有窒礙結縛」。從「若」字以下，接著說明其他部派各種捨財規定的不同。例如《十誦律》規定，對於金銀二寶，數量少的永遠捨棄，數量多的則交付淨人充作四方僧臥具。

【1257-0006】資持記/12b_中四下#41
【原文】《五分》，二寶入僧永棄，五敷永入常住。《僧祇》，二寶入僧無盡財中，五臥具捨入僧，隨僧用。《善見》，金銀擲去。《了論》，長衣、長鉢、雨衣、急施，捨與僧已，僧問須者應還。僧廣如諸部別行中。文中。常住通二種，四方局常住常住。棄山水者，即諸律二寶永棄也。
【譯文】《五分律》說：二寶歸入僧團便永遠棄捨，五種敷具永遠歸入常住。《僧祇律》說：二寶歸入僧團的無盡財中，五種臥具捨入僧團，隨僧眾受用。《善見律》說：金銀擲棄而去。《了論》說：長衣、長鉢、雨衣、急施衣，捨給僧團之後，僧團詢問需要的人，應當歸還。僧團的廣說如諸部別行中所述。文中所說的「常住」，通於「常住常住」與「十方常住」兩種；「四方」則局限於「常住常住」物。所謂「棄山水」，就是諸律所說二寶永遠棄捨的意思。

【1257-0007】資持記/12b_中四下#42
【原文】即同此律者，本宗亦有永捨之義；蠶綿違慈過重，故須斬壞；乞鉢損處事深，故罰入厨。七日藥以味重故，齊七日者施僧；過七日者與守園人。問：既同他律，豈是虛通，則與上文一何相反？答：酌情之教，隨緣緩急；知機而設，故非一概。誡告中，初科為五，初直勸。
【譯文】文中說「與本律相同」，是因為本宗同樣也具有永遠捨棄的意涵；用蠶絲製作的綿衣因嚴重違背慈悲心，所以必須剪碎損壞；非時求乞過量而得的缽器損害信眾極深，所以罰令繳入僧廚充公。七日藥由於滋味濃厚，儲滿七天的必須施捨給僧眾；超過七天的則轉送給守護園林的人。若問：既然與其他部派相同，又怎能說是通融無滯呢？這豈不是與上文互相矛盾？回答說：依情理斟酌而立的教法，會隨著因緣的輕重緩急而有不同；這是鑑察眾生根機而施設的，因此絕非千篇一律。在告誡叮嚀（誡告）的內容中，第一科分為五點，首先是直接勸誡。

【1257-0008】資持記/12b_中四下#43
【原文】兩相勞擾者，能懺所對，皆徒為故。但下，出不捨所以。見即識見，性謂心性。口說解脫，故云世表。行縛塵事，故云庸陋。今下，舉死事激勸。要必歸死者，意謂必待至死而將去耶！太事即出家所為，經生猶言度世。但下，舉勝行深勉。豈下，引生下文。次科。
【譯文】所謂「兩相勞擾」，是說能懺悔的人與所受懺的對象，都只是白費氣力。「但」字以下，說明不肯捨的原因。「見」就是識見，「性」是指心性。口頭上說解脫，所以稱為「世表」。行為被塵俗之事綁住，所以稱為「庸陋」。「今」字以下，舉出死亡之事來激勵勸勉。「要必歸死」的意思是：難道一定要等到死到臨頭才帶著走嗎！「大事」就是出家所為之事，「經生」就像是說「度世」。「但」字以下，舉出殊勝的行持來深切勉勵。「豈」字以下，引出下文。以下是其次的一科。
