# 校閱材料　第148檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【148-0001】資持記/12a_中四下#2
【原文】然懺通化制及以理事，今此且據制教事行以為篇目。敘來意中，初科為二，初敘懺意，上句明造業。且約篇聚所制二犯之罪；結業成因，必招來果，故如種焉。次句明須懺。以犯從妄起，罪假緣生；妄體本空，緣生無性；了知妄本，則犯相何依！識達緣生，則罪根叵得。是以忽追所犯，深恨前非；
【譯文】然而懺悔通於化教與制教，也兼具理懺與事懺，如今本篇姑且依據制教的事相行持來立為篇目。在敘述開展此篇的意圖中，第一科分為兩部分：首先敘述懺悔的意旨，上一句說明造業。此處姑且就篇聚戒相所制定的「由作而犯」與「由止而犯」這二種罪行而言；造業凝聚成因，必定會招感未來的苦果，所以如同播下種子一般。下一句說明必須懺悔。因為犯戒是從妄念生起，罪過是憑藉因緣而生；妄念的本體本來是空寂的，因緣所生之法也沒有固定不變的自性；既然徹底明瞭妄念的根本為空，那麼所犯之罪相又要依託何處！如實照見因緣生法無有自性，罪業的根源便不可尋得。因此忽然追悔所犯之過，深深痛恨先前的非行；

【148-0002】資持記/12a_中四下#3
【原文】仰對勝緣，盡披肝膽。罪從心起，還逐心亡；既伏現因，不牽後果。犯而不悔，業苦何窮。有智識非，義無隱覆故也。則下二句彰益。上句自行無瑕，下句眾法有用。故下，引勸；前引論文勸速改，初引論；不下，申勸。彼論問曰：何法重於地？何法高於空？何法多於草？何法疾於風？
【譯文】恭敬仰對殊勝的境界與對象，毫無保留地剖露肺腑、徹底發露。罪業是從心念生起，自當還隨著自心止息而消亡；既然伏斷了現前的惡因，便不再牽引未來的苦果。如果犯了戒卻不求懺悔，所感召的業苦何時才能窮盡。有智慧的人認清了過非，在義理上本就毫無隱蔽覆藏的道理。接續下來的兩句彰顯懺悔的利益。上一句說明自身行持清淨無瑕，下一句說明在僧團各項羯磨作法中皆具備合格資格。因此在下文引據加以勸導；前半段引用論典之文勸勉應當迅速改過，先引論典；自「不」字以下，申述勸誡。那部論典問道：什麼法比大地更重？什麼法比虛空更高？什麼法比草木更多？什麼法比疾風更快？

【148-0003】資持記/12a_中四下#4
【原文】答曰：戒德重於地，我慢高於空，煩惱多於草，心念疾於風。今略引後句以明昔心造惡，今忽追悔，剎那翻善，不待終日。意令有犯速須求懺。次引經文彰佛勸。經明如來訶責示惡之意，欲令行者有過尋悔。上訶毀禁，令成止行；下說惡道，令成作行。斥古中，初示非。
【譯文】回答說：戒德比大地更重，我慢比虛空更高，煩惱比草木更多，心念比疾風更快。如今大略引用最後一句，用以說明往昔之心造作了惡業，現今一旦追悔，剎那間便能翻轉為善念，用不著等待整日。用意在於令有犯戒者必須儘速求懺悔。接著引用經典之文彰顯佛陀的勸勉。經文中說明如來呵責並開示惡行之意圖，是想令修行人有了過失隨即悔改。前半段呵斥毀犯戒禁，是為了促成止持之行；後半段宣說墮入惡道之苦，是為了促成作持之行。在斥責古師說法中，首先指出其謬誤。

【148-0004】資持記/12a_中四下#5
【原文】遂，往也。古師即指諸家集羯磨者。如僧鎧羯磨：初出懺殘；二懺偷蘭，白二法懺，不分重輕；三懺捨墮，不簡單提；四懺餘罪，不顯罪相；提舍吉羅，並不出法。又曇諦羯磨：初亦懺殘；二懺捨墮；三懺餘罪，謂單提、提舍、蘭吉，同一法懺，詞句並同捨墮。事儀加改，謂之增減；
【譯文】「遂」是過去的意思。古師就是指歷來編集羯磨儀軌的諸家學者。例如僧鎧律師的羯磨：最初列出懺僧殘；第二列懺偷蘭遮，採用白二羯磨法來懺，卻不區分罪相的輕重；第三列懺捨墮，卻未將它與單提（單墮）分開；第四列懺其餘之罪，卻不標顯罪相；至於提舍尼與突吉羅，則完全沒有列出懺法。又如曇諦律師的羯磨：起初也是懺僧殘；第二列懺捨墮；第三列懺其餘之罪，也就是將單提、提舍、偷蘭遮與吉羅，全都併入同一種懺法，其詞句完全與懺捨墮相同。在儀軌作法上任意增補改動，稱為「增減」；

【148-0005】資持記/12a_中四下#6
【原文】立法出沒，謂之隱顯。若準下文，則古謂夷罪必須都無覆心，方開懺悔；又唯婬開懺，餘三不開；又僧殘中覆藏別住，或云盡行，或俱不行；又提舍中同懺提法，又眾學罪同皆責心；增減隱顯，尋之可見。臆課多者，責其師心。課猶說也。照教無文，謂事無所據；
【譯文】在立法上隨意隱沒或顯露，稱為「隱顯」。如果依照下文所辨，那麼古師認為波羅夷罪必須在犯後完全沒有覆藏之心，才能開許懺悔；又認為只有犯淫戒才開許懺悔，其餘三條重罪則不開許；又在僧殘罪中對於覆藏後的別住法，有的主張應完全依律行持，有的卻主張一概不行；又在提舍尼中混同單提之法來懺，又將眾學罪全都等同於責心懺；種種隨意增減與隱沒顯露，尋究其文便可看清。至於責備「私自度量揣測過多」，是斥責他們全憑個人成見。課，就如同解說。對照聖教卻查無明文，是指行事毫無聖教依據；

【148-0006】資持記/12a_中四下#7
【原文】撿行違律，謂行用非法。故下，引斥。即律〈增二〉中，明二種愚人。初人抱過不悔，次人悔不依教；今取次人，證上非法。律文又出二種智人，與愚相反，如下科引。聖下二句，示師心所以。上句示後悔法，皆見律文；下句顯前諸師不能依用。顯今中分二，初敘撰述，上一句正示。
【譯文】檢視行持卻違背律制，是指行儀運用全屬非法。因此在下文引律斥責。即是律典〈增二〉之中，說明了二種愚癡之人。第一種人抱守過失不肯悔改，第二種人悔改卻不依循聖教；如今選取第二種人，用以印證上述古師之法屬於非法。律文中又提出二種有智慧的人，恰好與愚人相反，將在後面的科判中引用。「聖下」這兩句，揭示了古師全憑個人成見的緣由。上一句指出後續悔罪的法則，在律典明文中全都能見到；下一句彰顯前面的諸位大師不能依律採用。在闡明今時正見中分為兩部分，首先敘述撰述的意旨，上一句是正面開示。

【148-0007】資持記/12a_中四下#8
【原文】定綱位者，六懺差別，不相濫故。格心境者，各顯緣法，無所昧故。隨一懺中，緣法雖多，不出心境。如下所示，慨過陳露，即能懺心也；託處對人用法等事，皆屬所對境也。格即訓正。下二句顯意。上句明立法有準。今古相形，是非鏡矣。下句示行事無疑。心境相照，得失彰矣，能所即心境也。
【譯文】「定綱位」的意思，是使六聚懺法各自的位次井然有別，不致互相混淆。「格心境」的意思，是使各篇緣起與作法各自彰顯，毫無模糊曖昧。在任何一個懺法之中，因緣作法雖然繁多，終究不出能懺之心與所對之境。如同下文所示，為自身過非感慨並陳白發露，就是能懺之心；依託處所、對向僧人、採用如法之羯磨等事，都屬於所對之境。格，訓詁為匡正。下兩句彰顯立法的意旨。上一句說明立法必須有所遵循。將今正與古謬互相對照，是非對錯便如明鏡般清楚了。下一句指出實際行事毫無疑惑。心與境相互映照，得失自然顯露，能與所指的就是心與境。

【148-0008】資持記/12a_中四下#9
【原文】此下二句，隔句對釋上文二句，尋之可見。則何下，次彰功益。明今依法，罪必可除，心有所寄；翻前違律，悔罪不出，臆課無憑，故云何患等。為聖歎者，順佛語故。故下，引律示歎。以命能懺為智人故。次明懺法，總分中，化教。具兼兩懺，通被二眾，如文所敘；又復二懺通大小乘；
【譯文】此處緊接的兩句，是隔句對應解釋上文的兩句，細尋便可明瞭。「則何下」接著彰顯其功德利益。說明如今依循正法，罪業必定得以消除，內心有所依憑寄託；翻轉了先前違背律制、悔罪無法出罪、隨意揣度毫無憑據的困局，所以說「何必擔憂」等語。「為聖人所稱歎」，是因為順應佛陀言教的緣故。因此在下文引律以明示稱歎之意。因為律中稱讚能懺悔者為有智慧的人。接著說明懺法，在總體分類中，化教。具足兼備事理兩懺，普遍涵蓋出家在家兩眾，如同文中所敘述；再者事理兩懺通於大乘與小乘；

【譯文】（有人認為這裡是指正式作羯磨的時候，此說應當詳細考量。）第二是規定凡是犯同樣罪過的人必須分開坐，這是擔心如果有了同伴，內心就會失去慚愧之意。第三是規定必須坐在顯眼之處，律文中自己說明了用意。在第五點中，引述《善見律》，首先說明有了特殊緣故，可以透過白告暫停修別住法。從「若」字以下，說明白天捨去別住法、傍晚再重新行法。說明在天亮前必須白告的原因，是因為這就算作一整天了。在《十誦律》的引文中，行六夜出罪法時也開許白告暫停，但仍然設有日期的限制；本宗的白告暫停，無論時間長短都可以。《四分律》中，首先說明如何透過白告來捨法，前面已經開示了開許捨法的情況。

【148-0069】資持記/12b_中四下#7
【原文】若下，明白行。彼下，明受禮作使。上明同類，下明下眾。六中。八事，一三並出外，寺非寺分；二四對客比丘，入出以分；六七約處，人無人分；五八各為一事。徐行謂緩步，簡疾行者，不白不犯。多人同屋，非別住故。又八事中，前五及八，並不白故失；六七事非故失。
【譯文】從「若」字以下，說明如何透過白告來重新行法。從「彼」字以下，說明接受頂禮與差遣作使的規定。前半段說明同為別住者的同類人之間，後半段說明對待下位的大眾。在第六點中列出了八種過失：第一與第三項都是外出，以寺院內外來作區分；第二與第四項是針對客比丘，以進入或離開來作區分；第六與第七項是依處所劃分，以有人或無人來區分；第五與第八項則各自獨立為一事。緩步行走是指放慢步伐，用以揀別快步行走的人，快步走若未白告則不犯過失。很多人同住在一間屋內，就不屬於單獨別住。此外在這八事中，前五項以及第八項，都是因為沒有白告而喪失行日；第六與第七項則是因為所做的事情不合體制而喪失行日。

【148-0070】資持記/12b_中四下#8
【原文】注云已得，謂前已行日；未得，謂所失之日。若後重行，但續已得，足滿前數。七中，初白一比丘法。往餘寺、客比丘等，皆準此。白詞中大德僧聽者，傳寫之誤，合云大德一心念，由是白別人故。若五人下，白眾多人法。若據對僧，合云僧聽；而云諸大德者，由非僧法；但不能別白，從省故耳；
【譯文】注文所說的「已得」，是指先前已經如法修行的日數；「未得」，是指違規而喪失的日數。如果日後重新起行，只需要接續已經修得的日數，補足原先所規定的總數即可。在第七點中，首先說明向單一比丘白告的方法。前往其他寺院、接待客比丘等情況，都比照這個規則。白告詞中出現「大德僧聽」的字眼，那是傳抄過程中的錯誤，應當作「大德一心念」，因為這只是向個別一人白告的緣故。從「若五人」以下，是向多位大眾白告的方法。如果依據面對僧團的通則，理應稱作「僧聽」；這裡卻稱「諸大德」，是因為這並非全體僧團的正式羯磨僧法；只是由於無法一一分別白告，為了求簡便而如此稱呼罷了；

【148-0071】資持記/12b_中四下#9
【原文】後說戒白，方可稱僧。有下，白客僧法。比丘中有德望者，須異常人。其下，指白僧法。說戒等者，謂一切眾集時。八中，《十誦》明往餘寺。若到便往者，恐違白法失宿故也。《五分》明出界。九中，《四分》。欲白不及，非意故開。《十誦》，初明見客執儀。若下，次明有病遣白。
【譯文】必須等到誦戒時的白告，才可以正式稱作「僧」。從「有」字以下，是向客僧白告的方法。比丘當中具有德行威望的人，待遇必須不同於常人。從「其」字以下，指明向僧眾集體白告的方法。所謂「說戒等」，是指所有大眾齊聚一處的時候。在第八點中，《十誦律》說明前往其他寺院的規定。之所以規定能到達才前往，是因為害怕途中無人可白而違反白告之法、喪失安宿日數的緣故。《五分律》則說明走出界外的情形。在第九點中，《四分律》指出，想要白告卻來不及，因為並非故意所以開許不犯過。《十誦律》首先說明遇見客僧時應執持的禮儀。從「若」字以下，接著說明若有疾病可以派遣別人代為白告。

【148-0072】資持記/12b_中四下#10
【原文】詞句闕略，故指《四分》，即前所引。《五分》。明行時對境，指第五方；五字錯，合作三字。評量中，初科為四，初嗟悔法不行。當隋唐之世，僧英極眾，佛法大興，尚云亦少；況今末法，焉可言哉！六聚懺法，墜地久矣。僧徒造惡，穢迹叵言；或臨布薩，則安坐默然；
【譯文】其詞句有所欠缺簡略，所以指引參照《四分律》，也就是前面所引用的內容。《五分律》說明行法時所面對的對象，鈔文中指稱是在「第五方」中說；這裡的「五」字是錯誤的，應當改為「三」字。在評核裁量（評量）的段落中，第一科分為四個部分，首先感歎悔過之法無法推行。在隋唐那個時代，僧中的英才極為眾多，佛法大為興盛，律祖尚且感歎依律悔罪的人太少；更何況是現在的末法時期，那裡還談得上呢！六聚懺罪的教法，被棄置荒廢已經很久了。僧眾徒眾造作惡業，污穢的行徑難以盡言；或者逢臨半月布薩說戒之時，便安然端坐、默不作聲；

【148-0073】資持記/12b_中四下#11
【原文】抱過畢生，死猶無悔。豈非妙藥雖留，毒氣深入，不肯服耶！悲夫！縱下二責棄制從化，初出過。余下，斥非，上三句責其取捨。真誠為道，義必兼行，不當厭小忻大。但下，三示其懺別。皆下，出其情狀。以制懺指定犯相，對眾折辱；況行別住，奪行苦役，羞愧不為；
【譯文】終生抱持著過失，直到死亡都還毫無悔改之意。這難道不是靈丹妙藥雖然留存在世，但毒氣已經深入腑臟，人們卻不肯服藥嗎！真是令人悲歎啊！從「縱」字以下，第二點責備捨棄律制懺悔而追隨化教懺悔，首先指陳其過失。從「余」字以下，痛斥錯誤的做法，上面三句責備其取捨不當。若是真心誠意為了求道，在道理上必定要兩者兼行，不應當厭棄小乘而欣求大乘。從「但」字以下，第三點指出兩種懺法的差異。從「皆」字以下，揭露其內心的真實情狀。因為律制懺法必須明確指定所犯的罪相，在眾人面前遭受折服羞辱；更何況要修行別住，被剝奪僧倫權益而從事辛苦勞役，修士往往心懷羞愧而不肯去行；
