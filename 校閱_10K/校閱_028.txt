# 校閱材料　第028檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【028-0001】01_行事鈔/02b_卷上之二#18
【原文】言默擯者。《五分》云：梵壇法者，一切七眾不來往交言。《智論》云：若心強獷，如梵天法治之。以欲界語地，亦通色有，不語為惱，故違情故，不語治之。此法最要。亦有經中加羯磨者。尋本未得。《雜含》云：三種調伏法謂，柔耎、剛彊也，猶不調者殺之。謂不與語、教授、教誡也。言滅擯者，謂犯重比丘，心無慚愧，不肯學悔，妄入清眾，濫居僧限。當三根五德舉來，詣僧憶念示罪，令自言已，與白四法。《五分》文云：「大德僧聽！此比丘某甲，犯某波羅夷罪。若僧時到僧忍聽：僧今與比丘某甲某波羅夷滅擯羯磨，不得共住，不得共事。白如是。」「大德僧聽！比丘某甲犯某波羅夷罪，僧今與比丘某甲波羅夷罪滅擯羯磨，不得共住，不得共事。誰諸長老忍，僧與比丘某甲波羅夷罪滅擯羯磨，不得共住共事者，默然；誰不忍者，說。是初羯磨。」「僧已忍，與比丘某甲波羅夷罪滅擯羯磨，不得共住共事竟。僧忍，默然故。是事如是持。」《薩婆多》云：但實犯重，大眾有知，不須自言及現前，直爾滅擯驅出。若準律文，必須自言，如目連被訶中說。即世多有，大眾容之，自他同穢。
【譯文】談到「默擯」的方法。《五分律》說：所謂「梵壇法（梵罰）」，就是所有七眾弟子皆不與他來往、不與他交談交涉。《大智度論》說：如果有人性情剛強粗獷，便以梵天之法（默擯）懲治他。因為欲界是以語言為交流境地，色界亦有尋伺語言之用，以「不與他說話」使其感到苦惱，以此違逆其情意，所以用不言語來懲治他。這項方法最為切要。也有些佛經中記載對此須附加羯磨儀軌。但尋查其根本出處尚未找到。《雜阿含經》說：有三種調伏之法，即是柔和、剛強，若依然無法調伏者就「殺」了他。所謂「殺」，就是指完全不與他說話、不給予教授、不進行教誡。再談到「滅擯（徹底驅逐開除僧籍）」，是指違犯了重罪（波羅夷）的比丘，內心毫無慚愧，不肯依法學悔，狂妄混入清淨大眾之中，僭居於僧團編制之列。應當由具備見聞疑「三根」與「五德」的比丘出面檢舉召喚前來，來到僧眾面前為他作憶念、指出其罪狀，令其坦白自陳之後，僧團以白四羯磨（一白三羯磨）對其處分。《五分律》文載白文說：「大德僧聽！此比丘某甲，違犯了某某波羅夷罪。若僧團時機成熟，僧眾忍可聽許：僧團現在給予比丘某甲某某波羅夷滅擯羯磨，不得與僧共住，不得與僧共同參與法事。白告如是。」羯磨文說：「大德僧聽！比丘某甲犯了某某波羅夷罪，僧團現在給予比丘某甲波羅夷罪滅擯羯磨，不得與僧共住，不得與僧共事。哪位長老贊同僧團給予比丘某甲波羅夷罪滅擯羯磨、不得共住共事者，請保持默然；哪位不贊同的，請說出來。這是第一遍羯磨。」結白說：「僧團已經贊同，給予比丘某甲波羅夷罪滅擯羯磨、不得共住共事完畢。因僧眾贊同而默然之故。這件事就這樣遵行受持。」《薩婆多部毘尼摩得伽》說：只要確實違犯了重罪，大眾皆已知悉，就不需要由他親自坦白自言以及到場現前，直接就可以進行滅擯並驅逐出寺。然而若是準照律本正文，則必須由本人親自認罪自陳，如同目犍連尊者被訶責的典故中所說的那樣。當今世間常有犯重之人，大眾卻姑息容忍，導致自己與他人都一同遭受垢穢污染。

【028-0002】01_行事鈔/02b_卷上之二#19
【原文】二約僧制眾食以論。先明世立非法，後引正制證成。
【譯文】第二項就僧團規約與大眾飲食來論述。首先說明世俗所立的非法清規，其後引證如來的如法正制予以證實確立。

【028-0003】01_行事鈔/02b_卷上之二#20
【原文】初中，寺別立制，多不依教。飲酒醉亂，輕欺上下者。罰錢及米，或餘貨賕；當時同和，後便違拒，不肯輸送；因茲犯重。或行杖罰枷禁鉗鎖。或奪財帛以用供眾。或苦役治地、斬伐草木、鉏禾、收刈；或周年苦役。或因遇失奪，便令倍償。或作破戒之制，季別依次鉏禾刈穀，若分僧食及以僧物，科索酒肉，媒嫁淨人，賣買奴婢及餘畜產。或造順俗之制，犯重囚禁，遭赦得免；或自貨賕，方便得脫；或奪賊物，因利求利。或非法之制，有過罪者，露立僧中，伏地吹灰，對僧杖罰。如是眾例，皆非聖旨。良由綱維不依法網，同和而作；惡業深纏，永無改悔。眾主有力，非法伴多；如法比丘，像末又少；縱有三五，伴勢無施。故佛預知有，不令同法，如後引之。《僧祇》云：若作非法制者，應訶令止；不者，當說如法欲已，起去。若眾中有力者不聽，當語旁人言：此非法制。止得三人，不得趣爾而作，應知識邊作。若不得者。說見不欲，與護心相，應云：彼自有業行，何關我事；如失火燒舍，脫身便罷。《毘尼母》云：見眾非法事，獨不須諫，應作默然，如上說。問：非法制中，罰取財物，犯重罪不？答：不犯重罪。由當時僧眾，同和共作，後依制罰，得不犯。非不犯作非法制罪。
【譯文】首先說明世俗所立的非法清規。各寺院各自訂立的規章制度，多數並不依循佛教戒律。對於飲酒醉亂、輕慢欺凌上座與下座之人，寺中往往罰其出錢、出米，或者罰以其他財物；受罰者當時雖然表面附和同意，事後便違抗抗拒，不肯繳納輸送；甚至因此引發爭端而犯下重罪。或者濫用杖刑拷打、枷鎖禁錮與鉗夾鐵鎖。或者強行奪取其個人財帛用來供養大眾僧。或者罰其從事繁重苦役如整頓田地、砍伐草木、鋤草禾田、收割莊稼；甚至罰以長達一整年的苦役。或者因為意外遺失或被奪走寺物，便強令他加倍賠償。或者制定破戒之章規，每季按順序輪流去鋤地收穀，或者私自分配常住僧食與僧物，攤派索討酒肉，替淨人（寺院僕役）作媒婚嫁，買賣奴婢以及其餘牲畜家畜。或者制定隨順俗世法令的規章，犯了重罪被囚禁者，一旦朝廷大赦便予以免罪；或者自己行賄送禮，透過各種手段得以逃脫處分；或者強奪盜賊之物，藉此謀求利益。或者設立非法之罰則，令有過失之人，在露天中罰站於僧眾面前，趴伏在地上吹灰受辱，當著全體僧眾施加杖刑拷打。像這類種種事例，全都不合如來聖意。這都是因為寺院綱維管理層不依循佛門法網，私自和合共同制定；導致惡業深重糾纏，永遠沒有悔改之期。寺院主事者大權在握，違法之同黨極多；而如法持戒的比丘，在像法末法時期本就稀少；縱使有三五位正直僧人，其微弱勢力也無從施展。因此佛陀早就預知會有此類亂象，不允許真比丘隨同參與其法事，如後文所引用的那樣。《摩訶僧祇律》說：如果有人制定非法的清規，應當予以喝止令其停罷；若勸阻無效，應當在宣白自己堅持如法之欲意（不同意非法制）之後，起身離去。如果僧團中握有實權的人不許反對，應當私下告訴身旁的人說：「這是非法的清規。」最多只能有三人（不可滿四人結成別眾），不得隨便草率行事，應當在明理的知友善知識身旁商議舉措。如果身旁找不到善知識，對方索欲時，應當面陳白表示不同意（說見不欲，口稱「我不欲」），並抱持護持自心正念的心態，應當自想：「那是他們自己的業行，與我何干？就如同房屋失火燃燒，自己能抽身逃出便罷了。」《毘尼母論》說：看見大眾在做非法之事，若只有自己單獨一人便不須出面規勸，應當保持默然，如同上面所說。有人發問：在非法的規章中，罰沒收取他人財物，是否會犯偷盜之重罪？回答：不犯偷盜重罪。這是由於當時僧眾是共同和合訂下規約，事後是依照規約執行罰沒，所以得免犯偷盜重罪。但這並不是說他不犯「制定非法規約」之罪。
