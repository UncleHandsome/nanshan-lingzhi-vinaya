# 校閱材料　第285檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【285-0001】02_戒疏/17c_卷四上之二#33
【原文】【記】次《成論》中。初句立義。「乃」下，釋成。初約佛與弟子對校。彼論問云：「為智福勝，為斷福勝？」答：「智能達法相，謂畢竟空，此則勝斷。何者？如佛以智故，於弟子中勝，不以斷故。」、「供」下，次唯就弟子比校，文為三段。初示勝劣。「前言」下，《論》自釋難。彼論前引《雜藏經》「供百初果，不如一二果」，與此相違故。「從」下，釋通，有二。初云「從多說」者，謂前經且據多少相望，初果多故劣，二果少故勝，今此約智，與彼不同。「亦」下，次約不了釋，謂彼經赴機一往權說，非究竟故。「還」下，還據彼經會同前義。初引畜生勝人道。「又」下，次引因人勝果人。彼云「彌勒菩薩雖未得佛，為羅漢所禮，由智大故」，又云「乃至沙彌發無上心，羅漢自取衣鉢，擔隨後行，故知智慧福田為勝」。
【譯文】【記文】接下來是引述《成實論》的段落。第一句立下義理主張。從「乃至」以下，解釋論證。首先以佛陀與弟子的關係作比校：該論提問道「究竟是智慧的福報殊勝，還是斷惑的福報殊勝？」回答說「智慧能通達法相，也就是了達畢竟空，這便勝過單純的斷惑。為什麼呢？因為佛陀是以智慧的緣故，在諸弟子中尊貴超勝，而不是單憑斷盡煩惱的功德。」從「供利根」以下，接著單就弟子之間進行比較，內文分為三段。第一段指出勝劣差別。從「前言」以下，是該論自行解釋疑難：因為該論前面曾引《雜藏經》說「供養一百位初果不如供養一位二果」，與這裡的主張相違背。從「從多說」以下，進行會通解釋，共有兩種：第一種說「從多說」，是指前面的經典暫且從人數多寡來對比，初果人多故算劣，二果人少故算勝，而現在此處則是就智慧利鈍來論，與那裡不同；從「亦不了」以下，第二種依非了義來解釋，是指那部經是為了適應某些眾生的根機而暫作權巧說法，並非最究竟之談。從「還即」以下，依舊引用那部經文來會合相同的義理：首先引用畜生勝過人道的例子；從「又如」以下，接著引用因地菩薩勝過果位羅漢的例子：論中說「彌勒菩薩雖然尚未成佛，卻受到阿羅漢的頂禮，這是因為他智慧廣大的緣故」；論中又說「乃至於沙彌發了無上菩提心，阿羅漢便親自為他拿取衣缽、背在後面跟隨，由此可知以智慧為福田是最為殊勝的」。

【285-0002】02_戒疏/17c_卷四上之二#34

【285-0003】02_戒疏/17c_卷四上之二#35
【原文】【記】次尼贊中。律文少略，故引示之。「謦」去挺反，彼作「謦欬」，謂𠻳聲也。「尼翻問」者，既為尊者所聞，故作他辭，欲混前語。迦葉答者，準此行乞，因入施家，不為別請，斯為明證。
【譯文】【記文】接著是比丘尼讚歎獲食的段落。由於律文敘述較為簡略，所以引述此段加以說明。「謦」字讀音同「挺」去聲，該律寫作「謦欬」，就是咳嗽的聲音。「比丘尼反問」，是因為她的胡言亂語被尊者聽見了，所以故意用別的話題反問，想要掩蓋混淆剛才說過的話。迦葉尊者的回答，證明修頭陀乞食者隨緣進入施主家，並不屬於私自答應的個別迎請，這就是極為明確的證據。

【285-0010】02_戒疏/17c_卷四上之二#42
【原文】【疏】就辨相中，「除飲食」，然「燈」已，明知大、小兩食皆犯，即文云「從旦至中得」也。所以「衣」輕者，財重難捨也。又財別屬，義非通用，食無獨噉，勸辦是易，故制重也。尼輕僧者，歎尼是希也。
【譯文】【疏文】在辨別犯戒相狀中，提到「除了日常飲食之外」，然而「燈油」一項所得的則是輕罪；至於大食（正食）與小食（不正食），都包含在飲食的犯相之中，吃了都會結重罪，正如律文所說「從早晨到正午所得的飲食」都包含在內。為什麼獲得「衣服」的情節較輕呢？因為財物價值重，施主難以割捨。而且財物屬於個別專用，義理上無法大眾通用；而食物不能一人獨吞，勸化促成也比較容易，所以律法對受食的處罰制訂得較重。比丘尼受讚而食處罰比大僧為輕的原因，是因為世人讚歎比丘尼而供食的情況比較少見罷了。

【285-0011】02_戒疏/17c_卷四上之二#43
【原文】【記】釋第五中，三段。初明燈油。「已」字合作「犯」，復缺「輕」字。油既得輕，顯上飲食通收「大小」，即正、不正也。「即」下，引證，文見注中。「所」下，次釋衣財兩意。「尼」下，三、顯尼輕，希數異耳。
【譯文】【記文】解釋第五句的段落中，分為三段。首先說明燈油部分：原文「已」字應當修正為「犯」字，而且還缺少了一個「輕」字。燈油既然只是輕罪，顯示前面所說的飲食是全面涵括「大食」與「小食」，也就是正食與不正食。從「即」以下，引述律文作證，文字見於戒本註中。從「所以」以下，接著解釋衣服財物兩項處罰較輕的兩種用意。從「尼」以下，第三、說明比丘尼處罰較輕的原因，只是因為發生次數多寡不同而已。

【285-0041】02_戒疏/17c_卷四上之二#73

【285-0046】02_戒疏/17c_卷四上之二#78
【原文】【記】三十二，制意中。初敘施意。「今」下，明過制。「無信」即是自失，「無用」即損供施。若據戒緣，應兼長貪、招譏之過。文從別相，又易知，略不明耳。
【譯文】【記文】第三十二戒，在說明制戒用意中。首先敘述施主的發心；從「今」以下，指明過失而立制：「無信」就是比丘自己失德，「無用」就是損害了施主的供養布施。如果依照制戒緣起，還應當兼具助長貪心、招致譏嫌的過失；此處是順著個別的行相來說，而且顯而易見，所以略過不明說罷了。

【285-0047】02_戒疏/17c_卷四上之二#79
【原文】【疏】釋此戒名，諸部各異。《四分》，展前家食，轉就後家，故名也。《僧祇》云「數數食」，亦言「處處食」。《十誦》、《五分》、《多》、《伽》，並同「數數食」。《注戒本》名「背請」者，隨俗取解，亦無過也。
【譯文】【疏文】解釋這條戒的名稱，各大部派各不相同。《四分律》稱為「展轉食」，意思是指移轉了前一家的飲食，轉而奔赴後一家的飲食，因此得名。《摩訶僧祇律》稱為「數數食」（頻繁受食），也稱為「處處食」。《十誦律》、《五分律》、《薩婆多論》、《毘尼摩得勒伽》（《伽論》），都同樣稱為「數數食」。《戒本註》稱之為「背請」，這是順應世俗容易理解的話來命名，也沒有過失。
