整體看，這批譯文對「闕緣／境差方便／小漫・剋心」的骨架掌握得不錯，但有**幾處實質誤譯**和**一批術語、體例不一致**的問題，以下逐則列出（✗＝建議必改，△＝可斟酌）。

---

## 一、逐則檢視

### 【713-0001】
1. ✗ **「學者皆能，故云『通誦』」被譯反了。**
 記文體例是「先出疏詞、後作解釋」或「先釋理由、後出疏詞」；此處「學者皆能」是**解釋**，「通誦」是**疏文原詞**。譯文写成「修學者都能通誦，所以說『皆能背誦』」，把被釋詞與釋義對調了。
 建議：「修學的人都能（通曉），所以疏文說『通誦』。」
2. ✗ **「時可惜」不是「時光可惜（惋惜）」。古漢語「可惜」＝值得珍惜。** 記文「恐虛度也」正是「怕虛度，故應珍惜」。
 建議：「『時可惜』是說時光應當珍惜，因為恐怕虛度光陰。」
3. △ **「『如』下」譯成「從『如果』往下」可疑。** 此處「如」多半是疏文「如後／如下所出」的「如」（如同、如下），不是假設連詞。請核對上一則疏文原句再定。
4. △ 「『世』下」譯成「從『人生世事』往下」：記文只標舉「世」字，建議保留原字＋補釋，如「從『世（世事）』字以下」。
5. △ 「反具成闕」譯得繞口。可作：「與『具緣成犯』相反，就是『闕緣』」。
6. △ 「示不廣所以」→「不廣泛引申」宜作「不廣為鋪陳（列述）的原因」。

### 【713-0002】
1. ✗ **「非人」≠「非人類」。** 律中「人／非人／畜生」是三趣，「非人」專指天、鬼神等；譯成「非人類的財物」會與下面「畜生物、無主物」重疊，三趣分類就垮了。
 建議：「第一、實際上是『非人』（天、鬼神等）之物，替代了人物之處，卻仍作人物之想而取。」（0007、0008 同此問題）
2. △ 「得三偷蘭」宜與後文「九句」體例一致：「得三句偷蘭遮」。
3. △ 「境差方便」→「境界有偏差的著手**行徑**」：「行徑」今語帶貶義，且「方便」是律學定譯，建議統一作「境差（對象錯誤）的方便罪（未遂、加行）」。
4. △ 「達持犯者」→「通達持犯戒律之人」稍生硬，可作「通達持犯（持戒與犯戒之相）的人」。

### 【713-0003】
1. ✗ **「對上小漫，人趣無闕，故云『還立』」的邏輯關係譯錯。**
 原意是**轉折**：小漫所對三異境皆非人趣（故闕境）；剋心中王物、張物同屬人趣，**人趣雖無欠缺，「闕境」之義卻仍然成立**，故云「還立」。譯文用「**所以**……依舊成立」，把讓步關係寫成因果，讀者會覺得不通。
 建議：「相對於上面的小漫（三異境皆非人趣）而言，此處剋心雖同屬人趣、人趣並無欠缺，但『闕境』之義仍然成立，所以說『還立』。」
2. △ 「大漫隨犯」→「隨遇隨犯」語意含糊（易讀成「隨便遇到就犯戒」）。宜補：「大漫心通於三趣，隨對何境皆成犯，無闕境可論」。
3. △ **人名不一致**：「張三」／「王某」混用，請統一（張某／王某，或張三／王四）。
4. △ 「『俱』下」譯作「從『全都作』往下」：記文是在標舉疏詞，建議保留原字，如「從『俱（作人想）』以下」，讀者才對得上疏文。
5. △ 「指廣」→「指引詳廣的文義」可作「指出詳說之處，即前文『境差方便』中」。

### 【713-0004】
1. ✗（體例） **「九句」譯成「九種句型」不妥。**「句」在律疏指「情況、類型（句相）」，「句型」是现代語法術語。建議一律作「九句（九種情況）」，0005、0007、0008、0009 同改。
2. △ 「亦不勞出」→「本來也不勞煩列出」主語不明，可作「本也不須（費事）列出」。
3. △ 「恐未達者」→「恐怕有人未能**透達**」用詞生僻，作「未能通達（此義）的人」。
4. △ 「雙闕」此處譯「心境雙缺」，0005 譯「心境俱差」，宜統一為「心境俱闕（俱差）」。

### 【713-0005】
1. ✗ **「各歷三境」譯成「各自歷經三種替換境界」與前句自相矛盾。** 前文才說轉想、疑心是「**境定**心差」（境未替換，仍是本境人物），此處「三境」是指**非人、畜生、無主**三種（作想或作疑的對象），不是「替換境」。
 建議：「用這三種（轉想、疑心、雙闕），各歷非人、畜生、無主三境，所以成九句。」
2. △ 「『想、疑』」譯成「心想與懷疑」丟了「轉」義，應承上文作「『（轉）想』與『疑（心）』」。
3. △ 「境定心差」可再明確：「境是決定的（仍是本境人物），只是心的想、疑有偏差」。

### 【713-0006】
△ **增字**：原文只標舉科目「言『轉想』者」，譯文加「的相狀」屬無據增添。建議：「所謂『轉想』（轉變心想）者：」。

### 【713-0007】
1. ✗ 「非人」同 0002 問題（「非人財物」易讀成「不是人的財物」）。
2. △ **「取」不宜譯「奪取」**：盜戒是偷取、不與而取，「奪取」偏搶奪；且 0002 用「拿取」，此處用「奪取」，前後不一致。建議統一「取／拿取」。
3. △ 「俱得吉羅」的「俱」宜點明所指：「（三句）都只得突吉羅」。
4. △ 「盜人方便」譯「屬於偷盜人類財物的著手罪」，可補因果：「因为是盜人的方便（未遂），故結偷蘭」。
5. △ 「後不言也」→「後文就不再一一贅述」略籠統，易誤解為後文完全不提；記文（0008）明說只是「不敘前後心相結罪之義」。建議：「後文不再重複說明（前後心結罪之義）」。

### 【713-0008】
1. ✗ **「心境相當，故云『同』也」又是引號錯位**（同 0001「通誦」）。「同」是疏詞（可得同境），「心境相當」是解釋。
 建議：「心與境相當，所以疏文說『同』（契合）。」
2. △ 「但不敘……」譯成「不**贅**述」語意偏移（贅述＝多說重複的），應作「只是不敘述前後心相結罪之義」。
3. △ 「『據』下」→「從『如果單就』往下」：同 0003，建議保留原字「據（後心時）以下」。

### 【713-0009】
△ 標點與句法：「第二句、是人類財物作畜生財物想。」建議「第二、（本是）人物，卻作畜生物之想（而取）。」或「第二句：於人物作畜生物想。」

## 二、通則性問題（建議全域統一）

| 項目 | 現況 | 建議 |
|---|---|---|
| 標點 | 「非常容易。」「皆能背誦。」「契合。」「不再贅述。」 | 引語作句子成分時，句號置引號**外**：「非常容易」。 |
| 記文釋詞體例 | 有時把「疏文原詞」譯成白話再放進引號（通誦、同、俱、據…） | 一律「保留原字＋（白話解釋）」，否則記文的「釋詞」功能消失、對不上疏文 |
| 「句」 | 句型 | 句／句相（情況、類型） |
| 「非人」 | 非人類 | 非人（天、鬼神等），與畜生、無主並列為三類境 |
| 「方便」 | 著手行徑／預備著手／著手罪 | 方便罪（加行、未遂），首次出現加註 |
| 「闕／缺」 | 闕緣、缺境界之緣、境界有缺、心境雙缺 | 統一用「闕」，白話補「欠缺」 |
| 「境差」 | 境界有偏差／境界偏差／境界有差 | 統一「境差（對象錯誤）」 |
| 人名 | 張三／王某 | 統一張某／王某 |
| 「取」 | 拿取／奪取 | 統一「取（拿取）」 |
| 小漫／大漫／剋心 | 小漫註「範圍較狹的泛泛之心」 | 建議明確：小漫＝局於人趣而普遍通取；大漫＝通三趣皆取；剋心＝剋定專指某物 |

## 三、優先處理清單

**必改**：0001（通誦倒置、「時可惜」誤義、「如果」待核）→ 0003（「人趣無闕，故云還立」邏輯）→ 0005（「三種替換境界」自相矛盾）→ 0008（「同」引號錯位）→ 0002/0007（非人術語）→ 全域「句型」。

**建議改**：0006 增字、0007「奪取」、0003 人名、標點與術語統一。
