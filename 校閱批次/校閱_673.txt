# 校閱材料　第673檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【673-0001】03_業疏/17a_卷三之六#10
【原文】三問，五中口業但列妄語，故有是問。答中初略示，「故」下引證。《善生》中初斥非，「十戒」上合有沙彌字。「無義語」，言不合義，即綺語也。「我」下顯理，若但禁妄，通餘三種口業非淨，故《智論》以重攝輕，故知通制。
【譯文】第三段問，是因為五戒中口業只列出了不妄語，所以有此問難。在回答中，開頭先作簡要示明，自「故」以下引經論為證。《善生經》中開頭先斥責其非，「十戒」之上應當有「沙彌」二字。「無義語」，是指言語不合乎正義，也就是綺語。自「我」以下顯明法理，如果只是禁止妄語，通於其餘三種口業就不能算作清淨，所以《大智度論》是以重戒統攝輕戒，由此可知是通通予以制止的。

【673-0002】03_業疏/17a_卷三之六#11
【原文】今以義推，貪等諸毒間雜不定，三單、三雙、一合為七。用歷過境，約文為五，對境為七，就業非情為八、為十。且以七毒就文歷之，隨一一境得三十五戒，徧生有四，非情有一，如是類推。
【譯文】現在以義理來推求，貪、瞋、癡等諸毒煩惱交雜起伏不定，有三種單發、三種雙發、一種合發，共成七種。用這七種心毒來歷對所防之過失境界：依文字列相而言為五種戒，對境開拓而言為七種戒，就業道與非情境而言則為八種、十種戒。暫且用七毒就文字列相來歷算，隨順每一種境都可得三十五條戒，普遍緣於眾生有四種境，非情境有一種，照此依此推類。

【673-0003】03_業疏/17a_卷三之六#12
【原文】義推中初離七毒，三單可解。三雙者：一、貪瞋，二、貪癡，三、瞋癡；一合，即三毒並起。「用」下歷戒，初列位。「約文五」者，據列相文；「對境七」者，五中開婬三境；「就業非情」，七支外加酒為八，開婬則為十。「且」下正歷，合數可見。
【譯文】在義理推演中，開頭先析分七毒，三單發心容易理解。三雙發心是：第一、貪與瞋，第二、貪與癡，第三、瞋與癡；一合，就是三毒同時並起。自「用」以下依毒歷戒，開頭先列出位次。「約文五」，是依據列舉戒相的經文；「對境七」，是在五戒中將淫戒開為三道行淫之境；「就業非情」，是在身口七支之外加上飲酒戒而成八戒，若開出淫戒三境則成十戒。自「且」以下正式歷算，合算出來的數目清楚可見。

【673-0004】03_業疏/17a_卷三之六#13
【原文】二、明八戒，有情同四，非情得五。以七毒歷緣，一一境上六十三戒。
【譯文】第二、說明八戒，在有情境上與前面同為四支，在非情境上得五種。以七種心毒歷緣各境，在每一境上都各發起六十三條戒。

【673-0005】03_業疏/17a_卷三之六#14
【原文】八戒中，「有情同四」，同上五中前四支也；「非情五」者，八戒實九，合數如文。準前對境為十一，就業非情則十二、十四。
【譯文】在八戒中，「有情同四」，是指與上面五戒中的前四支相同；「非情五」，八戒實質上有九條，合計的數目正如文中所說。若依照前面的對境來開拓則為十一，就業道與非情境而言則為十二、十四。

【673-0006】03_業疏/17a_卷三之六#15
【原文】三、明十戒，眾生同上，非情得六，則有十也。以毒通歷，可以準知。此律文中同僧七支學，是有願皆吉羅故。
【譯文】第三、說明十戒，在眾生境上與上面相同，非情境得六種，合起來就有十種。用諸毒普遍歷算，可以照此準則得知。在此部律文中，沙彌如同僧人一樣在身口七支上修學，是因為但凡有違誓願皆結為突吉羅罪的緣故。

【673-0007】03_業疏/17a_卷三之六#16
【原文】十戒中初示數，即上九中更加捉寶，歷之共為七十；對境十二，就業非情則十三、十五。「此」下辨犯，「此律文」者，簡異多宗，即〈大小持犍度〉。
【譯文】在十戒中，開頭先示明戒數，就是在上面九戒中再加上捉持金銀寶物戒，依七毒歷算共為七十條；對境而言為十二，就業道與非情境而言則為十三、十五。自「此」以下辨明犯相，「此律文」，是區別於薩婆多部等他宗，即出自〈大小持犍度〉。

【673-0008】03_業疏/17a_卷三之六#17
【原文】四、明大戒。如《多論》云：「一一眾生身口七支，若不受戒，皆因起惡；由受戒約，同翻為善。」三種善根歷於七支成二十一，餘則例知。
【譯文】第四、說明具足大戒。正如《薩婆多論》說：「對於每一個眾生，其身口七支若不受戒，都會依之而造作惡業；由於受戒的約束，全都翻轉而成為善。」以三種善根經歷身口七支，就成為二十一條戒，其餘情況依此類推可知。

【673-0009】03_業疏/17a_卷三之六#18
【原文】大戒示量有情中，初文初敘徧發所以，「三」下歷示戒數。「餘例知」者，七支外諸篇聚制也。
【譯文】在說明大戒所對有情境的數量中，第一段文字開頭先敘述普遍發起戒體的緣由，自「三」以下經歷並示明戒數。「餘例知」，是指身口七支之外所制定的各篇各聚戒法。

【673-0010】03_業疏/17a_卷三之六#19
【原文】若以互起，則列七門。婬境士女隨分二、三，女人身九，六十三戒；男子身八，五十六戒。
【譯文】如果以心毒交互並起來論，就列出七門。淫境在男女身上隨處劃分為二處、三處，在女人身上有九處，成六十三戒；在男子身上有八處，成五十六戒。

【673-0011】03_業疏/17a_卷三之六#20
【原文】次科，初示心毒，「婬」下開境對歷，男女數異。
【譯文】在第二科中，開頭先示明心毒，自「婬」以下開展境界進行對比歷算，男女身上的數目各不相同。

【673-0012】03_業疏/17a_卷三之六#21
【原文】自餘非情地、水、火、風、虗空、草木、凡聖教理，隨有一境起過塵沙；今反從善成塵沙戒，則無量矣。
【譯文】其餘非情的地、水、火、風、虛空、草木，以及凡聖所說的教法義理，隨順任何一境都可生起如塵沙般無量的過失；現在翻轉歸向於善而成就如塵沙般的戒體，其數量就是無量無邊的了。

【673-0013】03_業疏/17a_卷三之六#22
【原文】非情中，初示境量。「凡聖理教」，謂凡聖所說者，並非情攝。「隨」下歷數，隨一一境七毒歷之，境尚無量，以毒歷戒，數則叵知矣。
【譯文】在非情境中，開頭先示明所緣境的數量。「凡聖理教」，是指凡夫與聖人所說的法，都屬於非情境所攝。自「隨」以下經歷戒數，隨順每一種境用七毒去經歷，境界尚且無量無邊，若用諸毒來歷算戒數，數量就不可限量、無法盡知了。

【673-0014】03_業疏/17a_卷三之六#23
【原文】如《善生》云：「眾生無量，大海無邊，虗空無際，艸木無數，戒善同爾，亦無分齊。」
【譯文】正如《善生經》說：「眾生無量，大海無邊，虛空無際，草木無數，戒善也是這樣，同樣沒有限度邊際。」

【673-0015】03_業疏/17a_卷三之六#24
【原文】引證中，《善生》五量括盡諸境，眾生有情，餘四無情。大地摘在後科。
【譯文】在引經作證中，《善生經》以五種無量概括了一切境界，眾生屬於有情，其餘四種屬於無情。大地則摘取在後面的段落中。

【673-0016】03_業疏/17a_卷三之六#25
【原文】故《多論》云：「於非眾生，亦得無量戒善功德。如十方世界所有大地，下至金輪，傷如微塵，皆得其罪；一一塵處，今翻戒善，復無量也。如壞一艸，萌、芽、葉、華，一一得罪；反罪成福，又無量也。」故《善生》云：「大地無邊，戒亦如是。」
【譯文】所以《薩婆多論》說：「對於非眾生之境，也能得到無量的戒善功德。就像十方世界所有的大地，下至金輪，只要毀傷如微塵許，都會獲罪；在每一微塵之處，現在翻轉而成就戒善，福德又是無量無邊的。就像損壞一株草，於萌動、抽芽、生葉、開花等處，處處都結罪；翻轉罪業而成就福德，又是無量無邊的。」所以《善生經》說：「大地無邊，戒善也是這樣。」

【673-0017】03_業疏/17a_卷三之六#26
【原文】《多論》有二：初舉地塵，土輪至金輪皆屬地大故；「如」下次明草木，仍引《善生》覆證前段。
【譯文】《薩婆多論》的引文有兩層意思：開頭先列舉大地微塵，因為從土輪直到金輪都屬於地大的緣故；自「如」以下其次說明草木，並且再次引用《善生經》來反覆印證前一段。

【673-0018】03_業疏/17a_卷三之六#27
【原文】問：約情七支攝戒盡不？
【譯文】問：就依有情境所發的身口七支而言，是否能把一切戒法統攝窮盡呢？

【673-0019】03_業疏/17a_卷三之六#28
【原文】問攝戒中，「約情」謂有情也。
【譯文】在問戒法是否統攝窮盡中，「約情」是指有情眾生。

【673-0020】03_業疏/17a_卷三之六#29
【原文】答：盡。通收故，如打搏等落殺戒中。

【673-0022】03_業疏/17a_卷三之六#31
【原文】又解：不盡。何得相攝？一、輕重不同，二、能防體別。殺、打二戒，因果條別。故《善生》云：「除十葉外，更有業戒，謂善惡法。」故知不盡。

【673-0023】03_業疏/17a_卷三之六#32
【原文】攝不盡中初科，初立義。輕重即所防過，能防謂對治行。如殺犯重，打但得提，所防既殊，能防亦別；方便果本，彼此不同，既非相攝，故知不盡。「故」下引例，十業前七即是七支，彼經十外更有業戒，例今七支不攝明矣。「善惡法」，法即是業。
【譯文】在不能統攝窮盡的第一科中，開頭先確立觀點。「輕重」就是所防範的過失，「能防」是指對治之修行。比如殺人犯重罪，打人只結波逸提罪，所防範的罪過既然不同，能防範的對治也就有別；前方便與根本結果彼此不同，既然不能互相統攝，所以知道不能攝盡。自「故」以下引用經例，十業道的前七種就是身口七支，該經在十業之外更有業戒，比照現在七支不能統攝一切戒法就很清楚了。「善惡法」，「法」也就是業。

【673-0040】03_業疏/17a_卷三之六#49
【原文】別釋初文，初示梵言。二皆訛略，《涅槃》為正。「或下」，明翻譯。謂貧乏道德，故云「謙虗」等。收，謂收斂。自稱所能，謂之「伐德」。若準《涅槃》釋義則別，彼云「沙門名乏，那名道，斷一切乏，斷一切道，以是義故，名沙門那」。上依古翻。「今下」，次引今譯。「元拔俗」者，謂離父母之家；「入非家」者，即造空寂之道。

【673-0041】03_業疏/17a_卷三之六#50
【原文】釋子者，如《阿含》中及律八喻：四河入海，無復餘名；四姓出家，同稱釋種。如律複召云「釋迦子」者是也，上單召之，故云「釋」也。中梵如此，唐言譯之為「能仁」也。以四子被斥於雪山南，人民歸之，奄成大國，父後得聞，便曰：「吾子仁育，故有多能。」因從姓也。廣如僧祐《釋氏譜》十卷明之。所言「子」者，男子之通稱，即有孳育之緣，謂紹先聖之後也。餘者何由說盡，且削也。
【譯文】「釋子」，正如《阿含經》中以及律藏的八種比喻所說：四條河流匯入大海，就不再保有原來的名字；四個種姓的人出家，通通稱為釋迦種姓。正如律中具足稱呼時叫作「釋迦子」，上面只是單字稱呼，所以稱作「釋」。在中印度梵語是這樣，漢語翻譯為「能仁」。因為當初四位王子被驅逐流放到雪山以南，人民前來歸附，迅速形成一個強大的國家，父親後來聽說此事，便說：「我的兒子仁厚撫育人民，所以具有許多才能。」因此就以「釋迦」為姓氏。詳細情況正如僧祐律師所撰《釋氏譜》十卷中所明示。所說的「子」，是男子的通稱，即具有生養培育的因緣，意指繼承先聖的道統之後。其餘的因緣哪裡能在此說盡，暫且予以省略。
