# 校閱材料　第610檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【610-0001】02_戒疏/11a_卷三上之二#117
【原文】【記】次難。謂尼殘篇結文不問。然今尼戒同僧有之，未詳何意？闕疑不釋，以俟後賢。
【譯文】【記文】其次提出詰難。意思是比丘尼的僧殘篇結尾經文並未詢問此點。然而現今比丘尼戒本與比丘戒本同樣列有此問，究竟是何用意？此處姑且存疑而不做武斷解釋，留待後世賢德之士考證。

【610-0002】02_戒疏/11a_卷三上之二#118
【原文】【疏】問：「如《律》中不得強逼令悔，而此云『強』者？」
【譯文】【疏文】提問：「如同《律藏》中所載，不得強行逼迫犯過者發露求悔，但這裡為何說『應當強制給予（強與）』？」

【610-0003】02_戒疏/11a_卷三上之二#119
【原文】【疏】答：「此望別人治令行淨，故須強與。彼不逼者，眾法心淨，即堪說戒。若就強問，有所廢故。待說戒竟，依法治之。」
【譯文】【疏文】回答：「這是從針對個別犯戒之人、懲治並令其行持恢復清淨的角度來說，所以必須強制交付別住法。至於律中說不可強行逼迫，那是因為大眾作羯磨時只要內心自認清淨，就可以直接說戒；若是在說戒當場強行逼問，會廢止耽誤說戒大典之故。應當等待說戒完畢之後，再依法對其進行治罰。」

【610-0004】02_戒疏/11a_卷三上之二#120
【原文】【記】次釋治罸，初問中。《律》因佛不說戒，目連牽犯者出，佛言「須彼自言」，因制自言毗尼。今云「強與」，則違彼文。答中。初釋此文。「彼」下，次通彼意。言「心淨」者，開迷想故。若準《鈔》中，二篇鄰重，理宜早救，故須強與，不容緩也。
【譯文】【記文】其次解釋治罰處分，初問中。《律藏》記載因佛陀不開口說戒，目犍連便將犯戒者拉出大眾，佛陀開示說「必須等他自己主動陳白」，因而制定了「自言治罰（由犯者自承其罪的毗尼）」。如今此處卻說「強行給予」，顯然與那段經文相違背。回答中，先解釋此處的戒文。「彼」字以下，接著通達律文的原意。所謂「內心清淨」，是開許犯者一時生起迷妄執想的情況。如果依照《事鈔》中的說法，第二篇僧殘緊鄰波羅夷重罪，戒理上應當儘早予以挽救，所以必須強制賦予處分，不容許絲毫拖延怠慢。

【610-0005】02_戒疏/11a_卷三上之二#121
【原文】【疏】問：「初、二篇下安治罸法，下三不安，其義何邪？」
【譯文】【疏文】提問：「第一篇與第二篇戒文結尾都安立了治罰悔罪之法，下面的其餘三篇（捨墮、波逸提、提舍尼等）為何都不安立，其義理何在？」

【610-0006】02_戒疏/11a_卷三上之二#122
【原文】【疏】答：「上篇須者，一則壞眾，二則悔必待眾，故須安之。下三闕此，故不安也。如《律》偈『餘者不須救』，明非僧務也。」
【譯文】【疏文】回答：「上面的兩篇之所以需要，一是因為違犯會破壞僧團僧數的合法性，二是因為求懺悔必須依賴清淨僧團才能成就，所以必須特別安立。下面的三篇欠缺這兩項條件，所以不必安立。如同《律藏》偈頌所言『其餘的罪法不須僧團救度』，表明那些並非屬於全體僧團的公共事務。」

【610-0007】02_戒疏/11a_卷三上之二#123
【原文】【記】次問，以八篇戒本，唯初、二兩篇後結治故。答中。犯夷永不足，犯殘少分不足，不成僧務，故云「壞眾」。「悔必待眾」，別人不成故。然重蘭、捨墮亦制僧悔，但正出罪，皆別法故。「如」下，引證。即「律序」偈，彼云「四事不可治，可救有十三，餘者不須救」。此謂下三從別人悔，不假僧法，故下釋云「明非僧務」也。
【譯文】【記文】第二個提問，因為在八篇戒本之中，唯獨在第一篇與第二篇之後總結安立了治罪之法。回答中指出：犯波羅夷者永遠無法列入僧數，犯僧殘者暫時失去清淨資格而少分不足以充當僧數，兩者都無法成就僧團羯磨法務，所以稱為「破壞僧團」。「懺悔必須依賴僧眾」，是因為僅對單一比丘懺悔無法消除僧殘罪之故。雖然嚴重的偷蘭遮罪與捨墮罪也規定要在僧團中懺悔，但到了真正出罪時，全都是依對首（別人）之法，而非僧羯磨法之故。「如」字以下，引用文獻作證。即《律藏序文》中的偈頌，那裡說「有四種重罪不可救療，可以救度的僧殘罪有十三條，其餘的輕罪無須全體僧眾出面救度」。這是說明下三篇罪法只要對著個別比丘懺悔即可，不假藉全體僧團的羯磨法，所以下文解釋說「表明這不是全體僧團的法務」。

【610-0008】02_戒疏/11a_卷三上之二#124
【原文】【疏】問：「初篇下云『後亦如是』，第二篇後，何故無邪？」
【譯文】【疏文】提問：「第一篇結尾說『以後所說各戒也是如此受持』，第二篇結尾為何沒有這句話呢？」

【610-0009】02_戒疏/11a_卷三上之二#125
【原文】【疏】答：「如解同上。彼有不足疑，有斷頭疑。此非極罪，理有重犯，無疑可釋。」
【譯文】【疏文】回答：「解釋如同前述。第一篇結尾時，大家會懷疑到底算不算入僧數，也會懷疑犯者是否如同斬首斷頭永遠逐出。而僧殘並非極端死罪，在義理上允許再次違犯後重新受治，沒有任何疑難需要解釋。」

【610-0010】02_戒疏/11a_卷三上之二#126
【原文】【記】三問，答中。彼有二疑，此無疑故。「不足疑」，謂不足數。
【譯文】【記文】第三個提問的回答中。說明第一篇後有那兩種疑惑，而本篇並無疑惑。「僧數不足的疑惑」，是指懷疑犯戒者是否還能列入作法的人數計算中。

【610-0011】02_戒疏/11a_卷三上之二#127
【原文】【疏】文中「應與波利婆沙」者，西梵天音。東華人言，名為「覆藏」，或云「別住」。《母論》云：「何名別住？別在一房，不得與僧同處，雖入僧中，不得談論，亦不得答，故曰也。」
【譯文】【疏文】經文中「應與波利婆沙」一句，是古印度的梵音。在震旦東土漢語中，翻譯為「覆藏」，或者稱為「別住」。《毘尼母論》說：「什麼叫做別住？就是單獨住在另一間房舍內，不得與正常清淨僧眾共同起居，即使進入僧眾集會中，也不得與人交談，也不得回答他人問話，所以稱作別住。」

【610-0012】02_戒疏/11a_卷三上之二#128
【原文】【疏】若欲作法，隨其覆日，從僧三乞，白四加法，奪行奪能，合三十五事，八緣失宿。行法滿已，方名此法治覆情過。
【譯文】【疏文】如果要做羯磨法，依照他覆藏罪過的天數，向僧團請求三次，由僧團執行白四羯磨加予別住法處分，剝奪其日常行儀特權與執事能力，共有三十五件事遭到限制，並且有八種緣由會導致夜宿中斷而失去修行天數。必須依法行持期滿之後，才算以此法懲治了覆藏不報的情態罪過。

【610-0013】02_戒疏/11a_卷三上之二#129
【原文】【疏】二、犯覆藏罪。謂吉羅也。次對治懺。有人立在前懺，以後證前，不應爾也。
【譯文】【疏文】第二項、違犯覆藏罪。指的是突吉羅（輕垢）罪。接著應當進行對治懺悔。有人主張應在別住之前先行懺悔；但若以後文僧殘先治後懺的次第來證明前文覆藏，古人的主張是不合理的。

【610-0014】02_戒疏/11a_卷三上之二#130
【原文】【疏】三、治僧殘情過，須「與六夜摩那埵」法。此亦西語，《論》云「意喜」。前雖自意歡喜，亦生慚愧；又使眾僧歡喜，與少日故。作此法者，前須三乞，白四與法。奪行、失宿，大同於前。六夜之中，界中有僧，不同覆藏，一人行法。
【譯文】【疏文】第三項、懲治僧殘本身的罪行情態，必須「給予六夜摩那埵」法。這同樣是梵語，《毘尼母論》翻譯為「意喜（折伏其心令僧歡喜）」。犯戒者自己雖然心意歡喜，但也生起慚愧；又能使大眾僧歡喜，因為僧團只給與六夜少日之故。作此行法之人，事前必須向僧團三度乞求，僧團以白四羯磨賦予此法。其被剝奪的權利與失去夜宿期限的規則，大致與前述別住法相同。在這六夜期間，同一結界內必須有清淨僧人同在，不同於別住時可以一人獨處行法。

【610-0015】02_戒疏/11a_卷三上之二#131
【原文】【疏】四、治僧殘罪者，即如戒本「與出罪」是也。如《律本》名「阿浮訶那」，此名「喚入眾」，或名「拔除罪根」也。若欲行悔，廣如《鈔》中。
【譯文】【疏文】第四項、消除僧殘本罪，就是如同戒本所說的「與其出罪羯磨」。依照《律本》梵名稱作「阿浮訶那」，此處翻譯為「召喚重返大眾」，或者翻譯為「拔除罪惡根株」。如果想要具體遵行懺悔程序，詳細內容如同《事鈔》中所記載。

【610-0016】02_戒疏/11a_卷三上之二#132
【原文】【記】次通釋中，初文，三段。初翻名釋義。「覆藏」是約過。「別住」即從治。
【譯文】【記文】在接下來的通論解釋中，第一段包含三個層次。首先翻譯名稱並解釋字義。「覆藏」是從所犯的過失來立名，「別住」則是從受罰的行持來立名。
