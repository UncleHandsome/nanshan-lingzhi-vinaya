# 校閱材料　第1089檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1089-0001】資持記/07a_中一下#3
【原文】幾種者，通論諸教，所說不定；約境，從制，就位〔五八十具〕，剋體〔作及無作〕，或對七支，或總三業，或分遮性，或據受隨；有斯多異，通而問之。答中，初約境示量。今下，舉要統收。今正明體，此二為要，故偏舉之。通收盡者，由此二戒懸防，總發體中含攝故。
【譯文】所謂「幾種」，若通論各派教法，所說並沒有定論：有依所緣境來分的，有順著制戒因緣分的，有就受戒位階（五戒、八戒、十戒、具足戒）來分的，有直接限定實體（作戒與無作戒）來分的；或對應身口七支，或總括身口意三業，或區分遮戒與性戒，或根據受體與隨行來分。正因為有如此多的歧異，所以通括起來發問。回答之中，起初是依照戒境來顯示其數量。從「今」字以下，是舉出綱要來總括統攝。如今正要顯明戒體，作與無作這二戒最為關鍵扼要，所以特別舉出它們。說能夠通統收攝無遺，是因為這二戒具有防非止惡的廣大功效，在受戒總發戒體之中就已全部含攝的緣故。

【1089-0002】資持記/07a_中一下#4
【原文】此收法體，而言境者，欲明偏境之法，皆歸二戒故。第二科中。前但通立，次申所以。理趣既顯，引據復明；所立已定，即須顯示二種名義；故以解名，寄之於後。初科，問中。言不一者，欲顯相須，故約互廢以問。及以三者，《業疏》作何不三合；謂有作俱無作，二法同時；
【譯文】這裡本是在收攝法體，卻提及「境」，是為了說明即便周遍於一切境的法，最終全都要歸結到這二戒之中。在第二科裡，前面只是總體安立名稱，接下來申述這樣立名的緣由。理路旨趣既然已經顯露，引用的教證又已明朗；所安立的範疇既然底定，就必須顯發這兩種名相的深義；因此將解釋名義，寄託在後文之中。第一科的提問中，說「不一」，是為了彰顯二者互相依賴，所以假定偏廢其中一種來發問。至於問及「及以三者」，《業疏》中寫作「為何不三合」；這是指有「與作俱時而起的無作」，二法同時存在；

【1089-0003】資持記/07a_中一下#5
【原文】直應更立一合，次前為三。初答為二，先明作須無作。作休不防者，以作短故；不可常作者，心或餘用故。次若單下，明無作須作。二下，結示。次答中。作無作別者，動靜異故；心非心別者，體相違故。《業疏》三句：一作是色心，無作非色心；二作者初緣，無作後業；三作是運動，無作非故。〔鈔無第二，餘二比對大同。
【譯文】理應順理成章再立一個合和的類別，接在前面兩者之後成為三種。最初回答分為兩部分，先說明作戒必須仰賴無作戒。作戒止息就不能再防非止惡，是因為作戒的作用短暫；不可能恆常保持作戒狀態，是因為心念有時會轉作其他用途。接著從「若單」以下，說明無作戒必須仰賴作戒而起。從「二」以下，予以總結開示。接著回答作與無作不能合為第三類：作戒與無作戒之所以不同，是因為運動與靜止的相貌相異；心法與非心法之所以不同，是因為二者體質互相違背。《業疏》提出了三句辨析：第一，作戒屬於色心，無作戒並非色心；第二，作戒是最初造作的因緣，無作戒是隨後相續的業力；第三，作戒具有動轉造作，無作戒則無造作。（鈔中略去了第二句，其餘兩句互相對照大體相同。）

【1089-0004】資持記/07a_中一下#6
【原文】若下，釋疑。以不許立三，恐謂戒法唯局此二，故持釋之；顯上且據能防，故唯二也。引證中，《多論》，初二句，明從因感發。初下，明成就分齊。注中示名，初句會同，下句釋義。《業疏》云：此明業體，一發續現，不假緣辨；無由教示，方有成用；即體任運，能酬來世，故云無教；
【譯文】從「若」字以下，是釋除疑慮。因為不允許建立第三種戒，唯恐有人以為戒法僅僅侷限在這兩種，所以特地解釋；這是顯發上面暫且依憑「能防非止惡」的功能，所以只立兩種。在引用教證中，引用《薩婆多論》，前兩句說明戒體是從行者的心因而感應發起。從「初」字以下，說明戒體成就的限度與界分。註文之中指示名稱，第一句是會通名詞相同，下一句是解釋字義。《業疏》說：這是闡明業體一旦發起便相續顯現，不再假借外緣造作；不需要他人教導指點，當下就具備成就的功用；即是戒體任運自然，能夠酬引未來果報，所以稱為「無教」；

【1089-0005】資持記/07a_中一下#7
【原文】今時經論，多云無作，義例同也。〔準此，注中他字，乃指業體，非屬人也。〕《俱舍》名無表，亦同此釋。二中，初示二戒。是下，明緣具因闕。下復指論，以顯經意。三中。彼明化教十不善道，然二色義同，故可為證。《業疏》作是十種法，則通善惡，頗應下喻。
【譯文】如今的經論之中，大多稱為「無作」，其法義與體例是相同的。（依照這個道理，註文中的「他」字，是指戒體本身任運，並非指他人。）《俱舍論》稱它為「無表」，也是相同的解釋。第二段引文中，先指示這兩種戒。從「是」字以下，說明作戒之緣雖具備、但受體之因卻闕漏的情況。後面又指出論義，以彰顯經文的旨趣。第三段引文中，那部經闡明的是化教中的十不善業道，然而其中作色與無作色這二種色法的義理相同，所以可以作為引證。《業疏》寫作「這是十種法」，那就通於善業與惡業，正好與底下的比喻相呼應。

【1089-0006】資持記/07a_中一下#8
【原文】由心重輕，有發不發，故云或有無等。如下，喻顯。極喻重心，香臭喻善惡，瓦木喻輕爾無記，手執喻作；除去物已，餘氣有無，用配三心，可見。〔舊云此經與《俱舍》同宗，非也。安有佛經與論同宗耶？宜云：《俱舍》等，宗此經可也。〕結中。
【譯文】由於心力的重或輕，而有引發或不引發無作的分別，所以說「或者有、或者無」等等。從「如」字以下，以比喻來顯發義理。「極」比喻極重之心，「香與臭」比喻善與惡，「瓦石木塊」比喻微輕的無記心，「手執持」比喻作戒的造作；把物品拿開之後，殘餘氣味的有或無，用來配對這三種心，其理自明。（過去有人說這部經與《俱舍論》同屬一個部派宗義，這是不對的。哪有佛經去宗奉論典的道理呢？應當說：《俱舍論》等是宗奉這部經，這樣才對。）在結語之中：

【1089-0007】資持記/07a_中一下#9
【原文】問曰：今宗二戒，名體竝異，那引《多論》、《善生》而為證者？答：今此不論名體，但證二數是同；請觀結文，幸無遲慮。次解名義，問中。結前生後，總問三名。答中。作即方便搆造為義。陶家，謂土作家；輪，即範土為坏器之車；運之則轉，故以喻焉。四大質體名報色，從緣動作名方便；
【譯文】有人問：我們這一部宗派的二戒，名稱與實體都與有部不同，為何要引用《多論》與《善生經》來作證明呢？回答：現在這裡不討論名相與體性，純粹只是證明「分為兩種」的數目是相同的；請細看結語的文字，但願不要猶豫疑慮。接下來解釋名相與義理，提問之中，是總結前文並引出後文，總體詢問這三個名稱。回答之中，所謂「作」，就是以加行造作、搆畫運作作為它的意義。「陶家」是指製作陶土器的工人；「輪」就是轉動泥土做成胚器的旋轉車具；加以運轉它就會轉動，所以用它來比喻。四大假合的質體稱為「報色」，順應外緣而動轉造作稱為「方便」；

【1089-0008】資持記/07a_中一下#10
【原文】報起方便，方便依報；二法相假，不一不異；但言報未必是方便，言方便其必具報。今以輪水喻報質，輪動作喻方便，即名其動以為作耳。故下，引證。身及動身，對喻可解。〔《心論》，即有部，計作戒是方便色，故但云身。〕無作中。一發者，一，猶始也。
【譯文】由真報之身生起加行方便，加行方便又依託於真報之身；這兩種法相互借資，既不是截然為一，也不是完全相異；單單說果報之身未必就是方便動轉，但只要談方便動轉就必定具備果報身。如今以轉輪與水比喻果報的質體，以轉輪的動轉比喻方便造作，就是把這個動轉造作命名為「作」罷了。從「故」字以下，是引用教證。身體以及運動其身，對照比喻即可理解。（《雜心論》即屬於有部，主張作戒是方便動轉之色，所以單單說「身」。）在無作戒的解釋中：所謂「一發」，「一」就相當於「始」。
