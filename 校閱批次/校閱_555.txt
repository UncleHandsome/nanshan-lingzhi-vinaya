# 校閱材料　第555檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【555-0001】資持記/16b_下四#35
【原文】一解脫，二精進，三忍辱，四饒益，一一皆具自行化他；此中正用第一，餘三相因而引。《功德經》中，初正明。二喻顯，有二。為道出家，無漏功德；供聖起塔，皆有為福，故所不及。一日一夜舉少況多。彼經，阿難問佛：若有人放人出家，若自出家，得幾所福？
【譯文】一是解脫，二是精進，三是忍辱，四是饒益，每一種都具足自行與化他；此處主要使用的是第一種，其餘三種是因緣相連而順帶引出。《出家功德經》中，首先正面說明。第二以比喻顯發，包含兩層意涵。為了求道而出家，具有無漏的真實功德；供養聖人、建造寶塔，都屬於有為的世間福德，所以比不上出家。以一日一夜極少的時間，來比況更長時出家的廣多功德（舉少況多）。該經中，阿難問佛：如果有人准許（成全）他人出家，或者自己出家，能得多少福報？

【555-0002】資持記/16b_下四#36
【原文】若人毀破他人出家，受何罪報？佛告阿難：若滿百歲中問我，我以無盡智慧，除飲食時；滿百歲中，為汝說此人功德，猶不能盡。若人毀破出家因緣者，是人於三惡道中，常受生盲；若為人時，在母腹中，受胎便盲；汝於百歲常問是義，我於百歲，以無盡智，說是罪報，亦不可盡。
【譯文】如果有人破壞他人出家，會受何種罪報？佛告訴阿難：如果在整整百歲之中你來問我，我以無盡的智慧，除了飲食時間之外；在整整一百年裡為你演說這人的功德，依然不能說盡。如果有人破壞阻礙出家的因緣，這人在地獄、餓鬼、畜生三惡道中，常受生盲之苦；如果轉生為人，在母親腹中受胎之時就雙目失明；你若在百歲中經常詢問這個義理，我於百歲之中以無盡智慧說此人的罪報，也是說不盡的。

【555-0003】資持記/16b_下四#37
【原文】次科，《智論》二緣，初尼緣者。彼云：如優鉢羅華〔即蓮華也〕。《比丘尼本生經》說：佛在世時，此尼得羅漢果，化諸婦女出家；彼言：我等持戒為難，恐破戒墮獄；尼云：墮者從墮，久有出期；我念昔時，曾為戲女；因著袈裟，至迦葉佛時，乃得出家；
【譯文】下一個科判，《大智度論》列舉兩種因緣，第一是比丘尼的因緣。論中說：正如《優鉢羅華〔即蓮華也〕比丘尼本生經》所說：佛在世時，這位比丘尼證得阿羅漢果，度化許多婦女出家；她們說：我們持守戒律太難了，恐怕破戒墮入地獄；比丘尼說：要墮落就隨它墮落，久遠之後終有出離之期；我回憶過去世，曾做過戲女；因為穿戲服披著袈裟的因緣，到了迦葉佛時才得以出家；

【555-0004】資持記/16b_下四#38
【原文】由破戒故墮獄，今值釋迦，却得出家解脫。次引婆羅門緣。彼云：佛在祇園，彼因醉故，來至佛所求度，佛勅阿難度之；彼既醉醒，乃却歸家；比丘問佛，佛答如鈔。出家偈曰：孔雀雖有色嚴身，不如鴻鵠能遠飛，白衣雖有富貴力，不如出家功德勝。後引經律。以少時善根，障多生惡報。
【譯文】後來因為破戒的緣故墮入地獄，如今遇到釋迦牟尼佛，反而得以出家獲得解脫。接著引用婆羅門的因緣。論中說：佛在祇樹給孤獨園，那位婆羅門因為酒醉的緣故，來到佛的住處求度出家，佛敕令阿難度化他；他酒醒之後，就又返回家中；比丘們問佛，佛的回答如戒鈔所引。出家偈頌說：孔雀雖然有美麗色澤裝嚴身軀，卻比不上鴻鵠能夠高飛遠翔；在家人雖然有富貴勢力，卻比不上出家功德殊勝。最後引用經論戒律。用短時間的微少善根，能障蔽多生的惡劣果報。

【555-0005】資持記/16b_下四#39
【原文】年劫多少，隨緣赴機，不必一定。第三中。出既有功，障則損大。經中留礙，如親里不聽；仰制，如王臣禁斷。惡集如海者，示業重也。癩病即現報，入獄即生後二報。餘如上引。四中，初科，《寶積經》。二縛，喻不自在；二癰喻不清淨，二箭喻有所損。此三竝喻自心，智者幸宜自照；
【譯文】年劫時間的多少，隨順因緣對應根機，不一定有固定的定數。第三段中。出家既然有大功德，阻障出家則損害極大。經典中所說的留難阻礙，例如親戚不允許；朝廷的抑止制約，例如國王大臣下令禁斷。惡報積集如海，顯示罪業深重。罹患癩病是現世受報，墮入地獄即是來生與後世兩種果報。其餘如前文所引述。第四段中，第一個科判引述《大寶積經》。兩種繫縛，比喻不得自在；兩處癰瘡，比喻不清淨；兩支毒箭，比喻有所損傷。這三種都是比喻自己的內心，有智之人切須自我對照反省；

【555-0006】資持記/16b_下四#40
【原文】慎勿自謾，謂是他也。見，謂執見，義兼於名，此利根也；利養，即財物，更兼欲色，此鈍根也；《業疏》云：鈍貪財色，利著名見；四科收之，尠無不盡。《涅槃》。為飢餓者，以出家人，衣食易得故。見有持戒，驅逐殺害者，自無戒德；恐相形比，失於利養，生嫉忌故。次科。
【譯文】千萬切勿自己欺瞞自己，以為是在說別人。「見」，是指偏執之見解，義理兼含名聲，這是利根之人；「利養」，就是財物，更兼含貪慾色相，這是鈍根之人；《業疏》說：鈍根者貪著財物美色，利根者執著虛名偏見；用這四個類別來收攝，極少有不被涵蓋殆盡的。《涅槃經》。為了飢餓而出家者，是因為出家人衣食容易獲得的緣故。見到有持戒之人而驅逐殺害者，是因為自己沒有戒德；害怕彼此相形見絀而失去利養，因而生起忌妒之心的緣故。下一個科判。

【555-0007】資持記/16b_下四#41
【原文】罪相繁多，約心總攝，且列五種，故云等也。愛親求利屬貪，嫉即屬瞋，慳即是癡；還即三毒，為惡業本。〔不必將此色上三俞。〕下指《別鈔》，未詳何文，今見《業疏》。五中，初科，即修世間三學；初至界行，是持戒。戒取見，見即執見；以專持戒，名戒取；又以戒為上勝，名見取；
【譯文】罪惡相狀極為繁多，若就內心而言加以總括收攝，暫且列出五種，所以說「等」字。愛念親族、追求利養屬於貪心，嫉妒即屬於瞋心，慳吝即屬於痴心；歸根結底就是這三毒，作為惡業的根本。（不必把這五種配入前述的三種譬喻。）下文指示《別鈔》，尚未詳知是指哪篇文章，現今可見於《業疏》中。第五段中，第一個科判，就是修習世間的三學；從開頭至「非上界行」一句，是說明持戒。戒禁取見，「見」就是偏執之見；因為專門執取戒條，稱為戒取；又執著戒律為最上最殊勝，稱為見取；

【555-0008】資持記/16b_下四#42
【原文】此即五利使中二使，故云煩惱。欲界下業，即是人道；縱得生天，止在六欲。若下，明修定。即四禪四空定。多聞講誦，即習慧。準知修道，事行難分；自非達人，何由可識。次科，《智論》。所列，對上可見。總名世間法者，即人天善。然世出世，據心不同；至論事行，亦無有別。《成論》。
【譯文】這就是五利使煩惱中的兩種，所以稱為煩惱。欲界下品的世間善業，所感即是人道；縱然修善得以生天，也止步在六欲天。若字以下，說明修習禪定，也就是四禪四空定。博學多聞、講說誦讀，就是修習智慧。由此可知修道過程中，事相行持極難分辨；自身若非通達之人，憑何能夠識得？下一個科判，《大智度論》。論中所列內容，比對上述即可明了。總體稱為世間法者，就是人天的善法。然而世間與出世間，是依據發心之不同而區分；若論及事相行持，也沒有差別。《成實論》。

【555-0009】資持記/16b_下四#43
【原文】世樂為少利，出世聖道為大利。心別事同，義亦如上。六中，初科，初敘難行；今下，示頊行；經下，總標。無始未曾者，顯聖行難成也。著世慣習者，示難成所以也。經中，通指三藏。列示中。三觀竝云觀事者，事即是境，心依境起，隨境立觀；

【555-0024】資持記/16b_下四#58
【原文】既無持破，則無有戒；既無有戒，則應任意施為，不須守戒；世多邪見，故問決之。答中。以福況罪。不作福者，不取福相，故云不作。種種因緣，謂方便化導；隨所動用，皆離過故。釋疑中，初文。《地持論、佛藏經》，斷常二見取捨不同，故須通會，則明菩薩隨機立教，言乖趣合。
【譯文】既然沒有持戒破戒，就沒有戒律的存在；既然沒有戒律，那就應當任憑自意有所作為，不需要守戒；世間多有抱持這種邪見的人，所以提出問題來決斷澄清。回答之中，用福德來比況罪業。所謂「不作福」，是不執著福德之相，所以稱為「不作」。所謂「種種因緣」，是指以方便法門教化引導；隨順所動用行持的一切，都能遠離過失。解釋疑難中，第一段文字。《地持論》與《佛藏經》，對於斷滅見與常見的取捨立場不同，所以必須融會貫通，才能顯明菩薩隨順眾生根機安立教化，表面言詞相違而實質意趣完全契合。
