|:--|:--|

## 二、操作流程

1. 打開 `篇NN_bounds.md` → 全選複製 → 貼給 AI
2. AI 回傳 JSON（`{"bounds":[...]}`）→ 存成
   `AI語譯/_work/pian_bounds/bounds_篇NN.json`
3. 打開 `篇NN_splits.md` → 複製 → 貼給 AI
4. AI 回傳 JSON（`{"splits":[...]}`）→ 存成
   `AI語譯/_work/pian_splits/split_篇NN.json`
5. 告訴我「篇NN 好了」，我會跑：
   ```
   mk_pian_split.py NN      # 產生會本 docx
   chk_pian_docs.py         # 檢查逆序／無記鈔
   ```
   然後轉 PDF 給你驗。

## 四、給 AI 的 JSON 格式（複習）

**bounds**（每條鈔從哪個記段開始）
```json
{"bounds": [{"c": 2, "n": 5}, {"c": 3, "n": 13}]}
```

**splits**（跨鈔記段的切點）
```json
{"splits": [{"n": 16, "base": 4, "markers": ["大界中"], "targets": [4, 5]}]}
```

規則：
- `markers` 必須在該記段原文中**逐字出現**
- `targets` 必須是 `base, base+1, base+2…`
- 不確定就不要列，寧缺勿濫

## 六、我這邊會做的檢查

收到你的 JSON 後，我會先驗證：

1. c 是否連續、n 是否遞增
2. 每個 marker 是否逐字存在
3. targets 是否連續
4. 產出後：記號逆序＝0、無記鈔＝0

有問題我會直接告訴你是哪一條，不會硬套。
