# 校閱材料　第109檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【109-0001】01_行事鈔/06a_卷中之二#8
【原文】若男若女，在家出家，皆為房主；無此等主，故言無主。難處者，《四分》中，虎狼乃至蟻子也。《善見》：下至若有蟻子窟，不得作；若蟻行覓食，逐令去，得作。何以故？如來為慈愍眾生及比丘故。《五分》：四衢道中，多人聚戲，淫女、市肆、放牧、惡獸、隱險處、園田、社樹、墳墓、偪村近道等，是難處。妨處者，律云：乃至不容草車迴轉處。《善見》云：是人田園，或怨家、賊處、尸陀林處、王誌護處，四周不通十二輄梯，間有拳一肘者。《十誦》：是舍四邊一尋地內，有塔地，官地，居士、外道、比丘尼地，若大石、流水、大樹、深坑等，是妨處。《明了論》：或樹空、山巖、石陰等，得行住坐臥，如作房舍所攝。解云：如上處等，欲於中住，必須隔斷；須將比丘羯磨治地。所以爾者，若不依量，用功則多；若有妨難，自損惱他。故知僧私二地，並須乞作。《僧祇》：若僧中無能羯磨者，一切僧就彼作處，一人唱言：「一切僧為某比丘指授房。」三說亦得。若處遠、隔水，寒、暑、雨、雪、多病，不得並往者，應差二三人，不得羯磨四人。往彼指授，有四種人：一越年，二異界僧，三作私房者多，四妨難二處，悉皆不成；即此律云，使可信者看；故知簡別。《薩婆多》云：處分處得作，餘處不得。餘人就此房上作重屋；房主聽，得；無不處分罪。《善見》云：長中減一磔手，廣中長一磔手，互減過，皆僧殘。若房未成而行，客為成者，無罪。以人無一口房分，若段段計人分滿過量亦犯。問：何不同長衣，必俱過成犯？答：此房為造作故犯，長衣貯畜故犯。《四分》若教他作，受教者過量，犯；若是房主，得僧殘；巧師得偷蘭。妨、難，各突吉羅；過量、不乞，二僧殘罪。律不犯中，減量、無妨難，為佛圖、講堂、為僧、多人住屋，草菴、小容身屋者。
【譯文】無論男人或女人，在家人或出家人，只要出資興造，皆稱為房主；沒有這些施主出資，所以稱為「無主」。所謂有「難處」，《四分律》中列舉從虎狼侵害乃至有蟻穴蟲蟻等。《善見律毘婆沙》說：低微至如果有螞蟻窟穴的地方，便不得建造；如果是螞蟻爬行覓食之處，將牠們驅趕離開後，便可以建造。為什麼呢？因為如來是出於慈悲憫念一切眾生以及護持比丘的緣故。《五分律》說：在四通八達的十字路口中、眾人聚會遊戲之處、妓女所居之所、市集商鋪、放牧牲畜之地、猛獸出沒之處、險峻隱蔽處、果園農田、社廟神樹、墳墓墓地、逼近村落或緊鄰大路等，都屬於難處。所謂有「妨處」，律中說：乃至無法容納一輛載草的柴車迴轉的地方。《善見律毘婆沙》說：那是別人的田園土地，或是冤家仇敵之地、強盜出沒處、尸陀林（棄屍火葬場）、官府標記保護之處，以及四周無法容納架設十二檔階梯（十二輄梯，梯級間距約一拳一肘寬）的地方。《十誦律》說：在這座房舍四周一尋（約八尺）土地範圍之內，如果有佛塔所屬地、官府用地、居士用地、外道用地、比丘尼用地，或者有巨大的岩石、流動的活水、巨大的樹木、幽深的坑坎等，都屬於妨處。《律二十二明了論》說：或者在空心樹洞、山崖洞窟、岩石陰涼處等，只要可以在其中經行、居住、坐臥，皆等同於建造房舍所攝受的範圍。文義解釋說：像上述等處所，若打算在其中居住，必須加以隔斷築造；就必須請比丘僧團以羯磨法治地指授。之所以如此，是因為若不依照標準尺寸，耗費的功力必然過多；若建造在有妨害災難之處，既損害自己又惱亂他人。由此可知，無論是僧團公地還是私人土地，都必須向僧團乞求處分方可建造。《摩訶僧祇律》說：如果僧團中沒有通曉羯磨作法的人，全體僧眾可以一同前往該建造地點，由一人唱白說：「全體僧眾為某某比丘指授指派此處營造房舍。」如此說三遍也可以成就。如果建地地處偏遠、被江河隔斷，或者適逢酷寒、盛暑、連綿陰雨、大雪，或者僧眾多病，無法全體同往者，應當派遣兩三人前往，但不得派遣能主持羯磨的四人法規人數。前往該地指授處分時，有四種情形不能成就：一是跨越前一年預先指授，二是差遣了界外非同住僧，三是差遣了自己也建造諸多私房的貪求者，四是指授的建地處於有妨礙或有危難之處；這四種情況皆不能成就合法的處分。這正符合本律所說「派遣可信賴者前去查看」，所以得知必須經過嚴格甄別挑選。《薩婆多部》說：在僧團處分指授的地點可以建造，其餘未經處分的地點不得建造。如果其他人要在此房舍上方加蓋樓層重屋，只要房主聽許便可以；這樣不會犯未經僧團處分罪。《善見律毘婆沙》說：長度減少一磔手，寬度卻增加一磔手，互相增減而超過定量者，皆結犯僧殘。如果房屋尚未建成而比丘遠行離去，由過路客僧將其完成者，客僧無罪。因為各人皆無獨造滿一間房之份額；但若是分段計算個人的承造份額，若有某人所造之份額已達到過量標準者，該人亦犯。問：為什麼不同於長衣戒必須全體超過才犯？答：建造此房是因為動手營造之行為而犯，長衣則是因為蓄意貯藏蓄積而犯。《四分律》說：如果指使他人建造，受指使者建造超過定量，即構成違犯；若是房主本人，得僧殘罪；從事建造的工匠巧師，得偷蘭遮罪。若有妨礙處、危難處而建造，各得一個突吉羅罪；建造超過限量、未乞請僧團處分，則各得一個僧殘罪。律中不犯的情況包括：縮減尺寸未超量、建造處無妨礙無危難，或是為佛塔、講堂、僧團公眾、多人共住之房舍，以及建造草庵、僅能容納己身的小屋者，皆不犯。

【109-0002】01_行事鈔/06a_卷中之二#9
【原文】有主僧不處分房戒第七。制意同前。成犯具六緣：一有主；二為己作；三長佛六搩手，廣四搩手已上房；四不處分；五不處分想；六作成便犯。此房屬於己身，若死，遠去不還，隨意分處；若與三寶親友白衣，自賣取錢，隨心自在；唯不得賣地，地是僧物，僧不許賣，房僧得罪。若房主不自處分者，屬四方僧，次第住之。律中，妨、難，二吉羅；不乞邊，一僧殘罪。開通中：若處分；作草菴、葉菴、小容身屋，以小故不須乞處分；若作多人住處等，並得。
【譯文】有主僧不處分房戒第七。制戒意旨與前一戒相同。構成犯罪具備六個條件：一是有施主出資建造；二是為自己建造；三是建造長度在佛的六搩手、寬度在四搩手以上的房舍；四是未經僧團羯磨處分；五是作未經處分想；六是房屋建造完畢便結犯。這座房舍產權屬於比丘個人，若比丘去世，或遠走不再返回，隨其意願處分分配；若贈與三寶、親朋好友或在家人，或是自己賣掉換取錢財，皆可隨心自在處理；唯獨不得將地基土地變賣，因為土地是僧團常住物，僧團不允許變賣，房僧得罪。如果房主離去時自己未作處分吩咐者，房舍歸屬十方常住僧，由僧眾依戒臘次第居住。律中規定，若有妨礙處、危難處而造，得兩個突吉羅罪；就未向僧團乞求處分這一面而言，得一個僧殘罪。開許通融的情況：如果已向僧團乞求處分；或是建造草庵、樹葉庵，以及僅容己身的小屋，因為建築狹小所以無須乞求處分；若是建造供大眾居住的多人處所等，都屬合法律制。
