# 校閱材料　第178檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【178-0001】資持記/09a_中三上#50
【原文】三位九別，初三句覆遍障缺，次三句障周覆欽，後三覆障俱缺。言此室者，總前九種。開行坐者，據成室相，有伴方開；此諸非室，無伴亦許；準約同臥，亦應犯輕。若病下，難緣不犯。第五。〔佛在曠野城，六群與俗人共處宿形露因制；後於拘睒彌開二三宿，重結此戒。〕列緣中。
【譯文】共分為三類九種差別，前三句是屋頂遮蓋完整而四周遮障殘缺，中間三句是遮障周全而屋頂遮蓋不足，後三句是屋頂與牆壁兩者都殘缺。所謂「此室」，是總括前面這九種情況。開許在其中行走坐立，是依據構成正式房室的相貌而言，必須有同伴才能開許；而在這幾種不算房室的處所，即使沒有同伴也是被允許的；依照同臥的標準來看，就算躺臥也應當只結輕罪。從「若病」以下，遇到危難事緣而不算犯戒。第五條戒。〔佛陀在曠野城時，六群比丘與世俗人同處過夜而身體裸露，佛陀因此制定此戒；後來在拘睒彌國開許可以住兩夜到三夜，進而重新修訂結成此戒。〕在排列犯戒條件中。

【178-0002】資持記/09a_中三上#51
【原文】等一指餘義者，疏云：昔云男犯非女犯；以制隨宿，義無三夜。今此不引，直取論證。釋中，初科。戒本，廣解，宿限不同，不可和會；此引廣解，故至四夜。疏云：約戒本犯至三宿者墮；剋相為言，入第三夜，臥即是犯。故《十誦》戒本過二夜提，致使解者有緩急。〔準疏定奪，應從戒本。
【譯文】「等一」而指陳其餘義理，律疏說：古人曾說男犯非女犯；以制戒隨同留宿而定，義理上沒有允許過三夜的說法。現在這裡不引用古說，直接採取論典的依據來證實。解釋之中，第一科。戒本的條文與廣解的內容，對於留宿期限的限制並不相同，無法強行調和融會；這裡引用的是廣解，所以放寬算到第四夜。律疏說：依照戒本的規定，只要住滿到第三夜就墮入犯戒；精確指陳罪相來說，只要進入了第三夜，躺下睡眠當下就算犯戒。故《十誦律》戒本規定超過兩夜就犯波逸提罪，以致於後世解釋的人有了寬鬆與嚴格的分歧。〔依照律疏的裁決評定，應當依從戒本的標準為準。

【178-0003】資持記/09a_中三上#52
【原文】下引諸文，見母二論及《僧祇》，則同廣解；《十誦》、《伽論》，頗符戒本。二中。《十誦》兩開；通夜坐者，同下《五分》。《母論》兩宿，由無去處，開坐免過。注中初夜，即第四夜初。此戒初夜，本合犯提；論家開坐，故不即犯；及至將明，還制互去；
【譯文】下面引用各部文獻，《善見論》、《母論》這兩部論以及《僧祇律》，論調就如同廣解的說法；《十誦律》與《僧伽論》（伽論），則相當契合戒本的嚴格精神。第二部分中。《十誦律》有兩種開許；整夜坐著不睡的情況，與下面《五分律》的說法相同。《母論》開許住兩夜，是因為沒有別處可去，所以開許用靜坐來免除犯戒過失。注文中的「初夜」，是指第四夜的最初階段。這條戒在第四夜的剛開始，本來就該結犯波逸提罪；論師們開許整夜打坐，所以暫時不立刻結罪；可是等到了天色將明之際，還是硬性規定彼此必須有一方離去；

【178-0004】資持記/09a_中三上#53
【原文】若一向開，何須令去。準下注中，必須四夜通坐方開。此兩節注，似斥古非；有謂等四夜坐，開無犯故；雖不明指，語意可見。三中，《僧祇》，初明緣開。不下，示犯。過三夜者，即第四夜初。犯竟下，明未懺疊犯。轉長罪，謂展轉增犯。夜犯別結，故不開二夜。
【譯文】如果是一味完全開許，又何必勒令其中一人離開呢。依照下面注文的意思，必須在第四夜整夜端坐才能開許。這兩節注文，似乎是在斥責古人的錯誤見解；因為有人認為只要挨到第四夜打坐，就徹底開許而毫無犯戒之虞；這裡雖然沒有指名道姓，但語氣意思已經顯露無遺。第三部分中，《僧祇律》，首先說明因特殊事緣而開許。從「不」以下，指出犯戒情況。所謂「過三夜」，就是指第四夜的開始。從「犯竟」以下，說明尚未懺悔而重疊犯戒。所謂「轉長罪」，是指輾轉相乘增加犯戒次數。每一夜的犯戒各自單獨結罪，所以不開許可以連住兩夜。

【178-0005】資持記/09a_中三上#54
【原文】據開三夜，但第三夜將入犯位，不為開故。四中。《多論》四句，故知結犯不問入室同異，但取過夜耳。不犯指前，但過三為異。第六戒。〔佛在曠野城，六群與俗誦經，聲高亂坐禪者，因制。〕所以制此戒者，《多論》四意：初為異外道；二師資位別；三分別言章；四依實義，不在音聲。
【譯文】按理既然開許住三夜，只因第三夜即將邁入犯戒的臨界點，所以不屬於開許的範圍。第四部分中。《薩婆多論》列出四句分別，因此可知結罪與否並不在乎進入房間是同是異，完全只取決於是否逾越了規定的夜數。不犯戒的條款指陳同前，只是以超過三夜作為相異之處。第六條戒。〔佛陀在曠野城時，六群比丘與世俗人一同誦讀經文，聲音高亢吵鬧擾亂了坐禪的人，佛陀因此制定此戒。〕之所以要制定這條戒，《薩婆多論》提出了四種意旨：一是為了有別於外道的作風；二是為了顯現師徒尊卑的位階有別；三是為了字句言語的分明條理；四是為了依循真實義理，而不在於浮誇的音聲。

【178-0006】資持記/09a_中三上#55
【原文】具斯四益，所以一制。列緣。二中，三種不同，隨一成犯。注戒云：句義、句味、字義。釋云：句義者，同誦不前不後也。〔疏云同誦偈也，此通長行，文盡見義，故云句義。〕句味者，眼無常等〔一句之下，理味自足。〕；字義者同，誦阿字也〔誦呪之類〕。
【譯文】具備了這四種利益，所以統攝制定此戒。列舉犯戒條件。第二條中，有三種不同的情況，只要符合其中一種就構成犯戒。《注戒》說：句義、句味、字義。解釋說：所謂句義，是指一同誦讀時聲音不前不後齊聲並進。〔律疏說是合誦偈頌，這通於散文長行，文字讀完能顯露義理，所以稱為句義。〕所謂句味，是指念誦「眼無常」等語句〔在一句話之下，法理旨味自然具足。〕；字義，是指一同誦念「阿」等字音〔誦咒之類〕。

【178-0007】資持記/09a_中三上#56
【原文】用此三種配緣中三字，小有差倒。第四謂授法時抄前合誦也。釋初緣中，初科，前簡所誦。二聖二凡，則通四人。《智論》更加化人。若口下，示犯相，初結同誦犯。口授即同誦。書授謂已誦他書。若師下，結不教犯。凡欲授法，必先誡之；縱不同聲，不教亦犯。決通中，初決所誦之法，《僧祇》。
【譯文】用這三種名目去配對犯緣中的三個字，稍微有一點次序上的錯位顛倒。第四謂授法時搶先或隨同合誦。在解釋第一條犯緣中，第一科，前面先行甄別所誦讀的對象。二種聖人與二種凡夫，總共通涉四種人。《大智度論》則額外增加了化現之人。從「若口」以下，指出犯戒相狀，首先判定合誦犯戒。口頭傳授就等同於合誦。書寫傳授是指自己念誦而令對方抄寫記錄。從「若師」以下，判定沒有事先告誡的犯戒責任。凡是打算傳授佛法，必須預先戒勉對方；縱使沒有齊聲合誦，若事前未加告誡也同樣犯戒。在裁決融通中，首先裁決所誦讀的教法，《僧祇律》。

【178-0008】資持記/09a_中三上#57
【原文】餘人，即天仙。佛印可者，還同佛說。本宗但通四人，故注以示之。《善見》，初明佛說。若下，簡餘人說；《十誦》下，次決結犯分齊。品及章段，名異義同；隨經所立，故具列之。一部多品，隨得多罪。此下，點律通漫。釋第四中，初開俱利。非始授故。若下，次開從下受法。則通同誦。
【譯文】其餘的人，就是指天人與仙人。只要受到佛陀印可認同的，就等同於佛陀親自所說。本宗戒律只通涉四種人，所以特別加注加以指明。《善見論》，首先說明佛陀宣說的範疇。從「若」以下，簡別其他人所說的法；從《十誦律》以下，接著裁決結罪的界限與分齊。所謂「品」以及「章段」，名稱雖然不同但實質意義相同；都是隨著各部經典所建立的段落，所以完全予以列出。一部經典如果有許多品，就會隨著章段的多寡而獲得多次罪過。從此以下，點出戒律文義通泛散漫之處。在解釋第四條犯緣中，首先開許對雙方都有利益的情形。因為這並不是初次啟蒙傳授的緣故。從「若」以下，接著開許向地位低下的人請教受法。這時就通融可以齊聲合誦。

【譯文】「因」字以下，引用相關因緣故事。那裡提到：當時有捕魚人網到一條具有上百個頭的大魚，每個頭的形貌都各不相同；世尊看見後，呼叫它的名字，它便即刻應聲；佛陀問它：你的母親現在何處？它回答在廁所之中；佛陀說：這條魚在迦葉佛的時代，曾是精通三藏的比丘；因為惡口罵人的緣故，感召墮落受生為雜類百頭的果報；它的母親貪戀其獲得的供養利養，所以墮落為廁所中的糞蛆。引用這段因緣，是為了深切警惕後世的修學者。然而世間許多的講經法師親身登上法座，卻常常彼此非議謾罵；請好好深思未來的果報，實在應當加倍畏懼謹慎啊！

【178-0048】資持記/09b_中三上#34
【原文】釋第四中。注文傳誤，合作大書。反上者，聞聲不見面，如隔障處。疏云：此與罵戒有四別：一、前是泛僧，此僧知事；二、前戒不問虛實，此說實不犯；三、罵詞不同〔前列多種毀呰，此戒但言愛恚。〕；四、前非知事，見聞互離輕；此敬護重，互離犯提。
【譯文】解釋第四個犯戒條件中。注文傳抄有誤，應當修正為大字正文。與上述情況相反者，是指只聽見聲音卻看不見人臉，如同隔著牆壁阻障的處所。《戒疏》說：這條戒與毀罵僧人戒有四點不同：第一，前一條是泛指一般僧眾，此戒專指僧團執事人員；第二，前一條戒不論所罵是虛是實都犯，此戒若說的是實情則不犯；第三，毀罵的言詞不同〔前戒列舉了多種惡毒的詆毀譏刺，本戒則僅指責其出於私愛或瞋恚〕；第四，前戒所辱對象並非執事僧，見面與聞聲只要缺一即可減為輕罪；本戒為了恭敬維護執事職責，即使見面與聞聲相互分離也依然結犯提罪。

【178-0049】資持記/09b_中三上#35
【原文】若下，相因而制。不犯中。明同友相利，故無有過。十四。〔佛在舍衛，長者請僧；十七群取僧坐具露敷往食不收，風塵虫鳥壞污，因制。〕《多論》。三義故制：一須掌護，使資身行道，得安樂故；二同心愛惜，長彼信敬故；三令受用，福反資施主，善根成就故。列緣中。
【譯文】「若」字以下，是順帶連帶制定的情況。不犯戒的情況中。說明志同道合的同參道友彼此規勸互利，所以沒有罪過。第十四條戒律〔佛陀住在舍衛城時，有長者供請僧眾；十七群比丘把僧團的坐臥用具鋪在露天處，逕自前去應供而不收納，導致用具被風吹沙染、蟲咬鳥便毀損弄髒，佛陀因而制戒〕。《薩婆多論》提到。由於三種用意而制定此戒：第一是必須細心保管護持，讓僧具能資助行者安心修道，獲得安穩快樂；第二是大家同心協力愛惜公物，能夠增長施主的信敬之心；第三是讓大眾妥善受用，這份福報才能反過來資助施主，成就施主的善根。列舉條件中。

【178-0050】資持記/09b_中三上#36
【原文】僧物有三，如迴僧物戒；今取已捨與僧犯墮，餘二結輕。床即繩床木床，敷謂臥具坐褥。釋五中，《五分》，初明犯墮。並以事異而犯同，故三皆言亦。初見不舉，雖非自敷，不惜護故；尼寺犯者，皆僧物故；借俗犯者，恐損失故。若下，明犯輕。二緣，俱非心過，但情慢故吉。《僧祇》中，初明安像。
【譯文】僧團的公物有三種，如同隨意挪移僧物戒中所述；這裡專指已經明確布施交付給僧團的物品，違犯者結犯墮罪，其餘兩種僧物則結輕罪。「床」是指繩床或木床，「敷」是指睡臥的被褥與坐墊。解釋第五個條件中，《五分律》首先說明結犯墮罪的情況。這些都屬於行為情境不同但犯罪本質相同，所以三種情況都寫「亦同」。第一種是看見別人放置而不收起，雖然不是自己鋪設的，但放任不管缺乏愛護之心；在比丘尼寺院中犯戒，是因為這些全是僧團公物；借給世俗之人而犯戒，是擔心器物會遭到損失毀壞。「若」字以下，說明結犯輕罪的情況。這兩種因緣，都並非內心故意要破壞，只是態度怠慢疏忽，所以判為小罪（吉羅）。《僧祇律》中，首先說明安放佛像的狀況。

【178-0051】資持記/09b_中三上#37
【原文】必約露處。手觸即同受用，故犯。若下，明囑他。不舉亦開。文標春月，不慮損故；餘時義應不許。若行下，明別制。此非僧物，但是乖儀，有違應吉。《多論》。遊房吉者，非捨去故。《四分》有四，初明捨去方便。次第四種，並以若字分之。初囑知事，二舉屏處，三好蓋覆，四作意還。上句明即還。
【譯文】必定是指在露天的環境。只要用手觸碰移動，就等同於自己在使用，所以犯戒。「若」字以下，說明囑託別人照看。即使自己不收起來也予以開許。文中標明是春暖之月，不必擔心會受風雨損壞；其餘時節在法理上應當不允許這樣做。「若行」以下，說明附帶的特別規定。這雖然不是僧團公物，但行為有失僧人威儀，有所違犯應當判為小罪（吉羅）。《薩婆多論》提到。在各房間走動串門子判為小罪，是因為這不算是徹底捨棄離去。《四分律》有四點，首先說明想要捨棄離去時的處置方法。接著有四種程序，都用「若」字區分。第一是囑託給執事僧，第二是收納放置到有遮蔽隱蔽的處所，第三是用物品妥善蓋好覆蓋住，第四是動念預計馬上就會返回。上一句是指立刻就回來的打算。
