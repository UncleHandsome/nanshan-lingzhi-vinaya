# 校閱材料　第322檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【322-0001】資持記/15d_下三#49
【原文】〔上是論文，今但取受羹少物，以證上耳。〕《善見》。受使善事，不犯，以非使故。十三中，《地持》，初相見慰問。又下，隨緣呪願。《四分》，初明待遇病人。方便遣者，可遣即遣，為益彼故。稱譽聽作，謂有信俗人，無所歸者。若下，隨俗呪願。嚏，丁計反，噴鼻也。
【譯文】（上述是論典的原意，此處引用只是為了截取佛陀接受羹湯微少之物這件事，用來印證前面的義理罷了。）《善見律毘婆沙》指出：接受指派去辦理善法事宜，不構成犯戒，因為這並不屬於世俗私事的差遣役使。第十三段中，《菩薩地持經》首先教導相見時的慰問關心之禮。「又下」說明隨順因緣進行祝願祈禱。《四分律》首先說明照顧接待病人的規矩。「方便遣」是指若是合適遣送回鄉者即可遣送，這是為了讓病人獲得更好的照料益處。「稱譽聽作」是指若病患稱揚讚歎三寶，則聽許為其照料治病，這是指具有信心的在家人且無所投靠者。「若下」是隨順世俗習俗予以祝願。「嚏」字的讀音是「丁計反」，指鼻子噴氣打噴嚏。

【322-0002】資持記/15d_下三#50
【原文】律因比丘不呪願，招譏，故制。十四《僧祇》三段，初入王眾法，初制非宜。應下，教善語。二家，即剎帝利、婆羅門，諸佛巧便利物，人尚德行，則於婆羅門姓中生；若尚威勢，則於剎帝利姓中生。法輪，即佛法；力輪，是王臣。又下，誡觸犯。形相，謂以形相人。欲下，聽陳意。俗下，示應答。
【譯文】律藏是因為當時有比丘在他人打噴嚏時不作祝願，招致了世人的譏嫌非議，佛陀因此制定了相應儀軌。第十四段《摩訶僧祇律》分為三段，首先是進入國王宮殿或王臣大眾中的法則，第一點禁止不合宜的舉止。「應下」教導應當運用善巧合宜的言語。「二家」是指剎帝利（王族）與婆羅門（祭司貴族），諸佛運用巧妙方便利益眾生，若當代世人崇尚道德修行，佛陀便投生在婆羅門貴族之中；若當代世人崇尚權勢威嚴，佛陀便投生在剎帝利王族之中。「法輪」指佛法教化；「力輪」是指國王與大臣的權威體系。「又下」告誡不可觸犯忌諱。「形相」是指妄自憑藉外貌體相去評論他人。「欲下」聽許陳述自心本意。「俗下」指示如何得體應對回答。

【322-0003】資持記/15d_下三#51
【原文】恐有遺忘緣阻，故言皆不定。次明入居士舍，初制不應。令他慚恥，失敬信故。應下，示慰諭。方便引接，發彼善故。三入外道眾，二節同上。形訾，謂形言毀辱。此門所明，說法儀式；然事相交雜，不唯說法；或作門師，或是接對，或令教導。又復說法之式，不專導俗；
【譯文】這是擔心日後若有遺忘或遭遇事緣阻礙，所以回答時語氣皆不可說得絕對肯定。次一段說明進入在家居士住宅的法規，首先禁止不應有的舉止。這是為了避免令對方心生羞慚恥辱，因而喪失了原有的恭敬與信仰之心。「應下」指示如何進行慈悲慰勉開導。以權巧方便引導接引，以此激發啟迪對方的善根。第三部分說明進入外道信眾之中的法規，其兩個節段與前文相同。「形訾」是指以言語形象當面加以毀謗羞辱。這一門所闡明宣說的，表面上是說法的儀軌程序；然而具體事相交織繁雜，其實並不僅限於登座說法；有的教導如何擔任世俗門師，有的教導如何接人待物，有的指令如何引導教化。再者，說法的規範程序，也不僅僅專用於導化世俗；

【322-0004】資持記/15d_下三#52
【原文】為師訓道，義亦同然。事類相投，寄此明耳。第二，三歸中，制意引經。初正明受意。即《多論》云：如人獲罪於王，投向他國，以求救護；眾生亦爾，繫屬於魔，有生死過；歸向三寶，魔無如之何；故知若受三歸，得脫生死。煩惱魔者，三毒劫善故；五陰魔者，遷謝不停故；死魔者，逼切報命故；
【譯文】作為師長在寺院訓誡教導僧眾，其法度理義也是完全相通的。因為事理類別相同相符，所以寄託在這一門中一併予以明示。第二部分「三歸」中，說明制戒用意並引經為證。首先正面闡明受持三歸的真實用意。正如《薩婆多毘尼毘婆沙》所說：就像有人在國王那裡犯了死罪，不得不逃亡投奔到鄰國，以尋求該國君王的拯救庇護；一切苦難眾生也是如此，繫縛隸屬於魔王魔網之下，隨時有沉淪生死的罪過凶險；只要一心歸向奉持三寶，魔王便拿他無可奈何；由此可知如果真誠受持三歸，便能徹底超越脫離生死輪迴。「煩惱魔」是因為貪瞋癡三毒會劫奪內心的善根種子；「五陰魔」是因為色受想行識五蘊遷流謝滅永無停息；「死魔」是因為無常殘酷逼迫奪取眾生報命；

【322-0005】資持記/15d_下三#53
【原文】天魔者，撓令退道故；四皆惱害，不能自由，故名魔也。名下，次彰法勝。名一義異者，彼經第五自解云：佛常，法常，比丘僧常，此明如來欲示眾生常住真心，一體二寶，故於方便教中，隨宜離合，故云諸佛境界等；既知方便，本為引實；今受三歸，無非顯性；機雖未達，可使由之；
【譯文】「天魔」是因為第六天魔王經常惱亂障礙修行人、令其退失修道初心；這四種魔都會殘害自性，使眾生無法自在做主，所以稱為「魔」。自鈔文「名一義異」句以下，接著彰顯三寶法門的尊貴殊勝。所謂「名稱為一但法義有別」，那部經的第五卷自己解釋說：佛陀是常住的，法寶是常住的，比丘僧寶也是常住的，這說明如來想要為眾生開示常住不滅的真心、以及一體二寶的真實實相，所以在隨緣方便的教法之中，隨應機宜而作拆分或合併，所以經中說這完全屬於「諸佛極深的智慧境界」等等；既然明了方便教法，本意全都是為了引導回歸真實義理；那麼今日受持三歸，無非是為了顯發本具的真如自性；眾生的根機雖然尚未完全通達明了，但可以引導他們依循這條道路實踐前行；

【322-0006】資持記/15d_下三#54
【原文】而授者用教，不可不知之。說一為三者，經云：云何為一？佛告摩訶波闍波提憍曇彌：莫供養我，當供養僧；若供養僧，即得具足；汝隨我語，則供養佛；為解脫故，則供養法；為受用故，則供養僧。說三為一者，如《多論》，問：佛亦是法，法亦是佛，僧亦是法，正是一法，有何差別？
【譯文】而作為傳授三歸的師長在運用教法時，心中則絕對不可不知曉這層深意。所謂「說一法而開顯為三寶」，經中說：什麼叫作歸為一體？佛陀告訴姨母摩訶波闍波提憍曇彌：「妳不要單獨供養我一人，應當以平等心供養清淨僧團；如果能供養僧團，一切功德即得圓滿具足；妳隨順聽從我的教誨，這就是至誠供養佛；為求了生脫死的緣故，這就是至誠供養法；為了僧團的修持受用，這就是至誠供養僧。」所謂「說三寶而合歸為一法」，如同《薩婆多毘尼毘婆沙》所問：佛本來就是法，法也就是佛，僧團同樣不離於法，三者根本就是同一法性，究竟有何差別？

【322-0007】資持記/15d_下三#55
【原文】答：雖有一義，相有差別；無師大智，一切功德，是佛寶；盡諦涅槃，是法寶；聲聞學無學功德，是僧寶是也。又下，顯功能。故知三寶加護，不為他害；龍畜尚爾，況於人乎！《義鈔》，即受戒法中；《業疏》委備，此不煩引。二中，初敘意。但使未歸三寶，皆名信邪。隨順生死，皆名邪業。

【原文】毀三寶及戒為四，五不利優婆塞住處〔遮部彼所受戒〕；六作他惡名稱；七欲辱彼住處；八以非法為正法，欺誑於人。〔或可此三，通以不利改之，故不別舉。〕若有此八，許令不敬，以無德故。若下，次教道不往俗。聚落亦爾者，上約一家；合聚皆嗔，比丘不往彼聚。《雜含》。示名實。
【譯文】毀謗佛、法、僧三寶以及毀犯戒法合為四項，第五項是不利於優婆塞的住處（遮止阻礙其所受之戒法）；第六是造作各種惡名聲；第七是企圖羞辱他們的住處；第八是以邪偽的非法冒充為正法來欺騙誑惑世人。（或者這後三項，都可以通融歸納為「不利」來概括改換，所以文中沒有單獨列出。）如果有這八種過失，佛陀就允許信徒不予恭敬，因為其人已無德行的緣故。自「若」字以下，接著教導道人不往俗家去之法。聚落也是如此的意思，上面是就一個家庭而言；若整個村落的人都對僧人懷有嗔怒，比丘就不要前往那個村落。《雜阿含經》。開示名分與實質相符的道理。
