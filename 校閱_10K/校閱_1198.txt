# 校閱材料　第1198檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1198-0001】資持記/10b_中三下#38
【原文】論云：以麥及藥草，以酒和之，後乾持行，和水飲，令人醉也。次科，初引律。境想事同婬戒。注中初句示律文，次句明今釋。謂先有方便欲飲，至後飲時，乃生非酒想疑；後心無犯，成前方便，故須結重。必先無意迷忘須開。疏云：諸師約心從境制，余意不同；
【譯文】該論說道：用大麥以及各類藥草，加入酒液調和混拌，之後烘乾隨身攜帶，路上只要加水沖飲，就能讓人大醉酩酊。次一科，首先引述律文。境想的心理辨識過程，其事理行相與犯婬戒完全相同。附註中第一句是指明律典的原意，第二句則是說明當前的註解看法。這是指修行人起初本來就有想要喝酒的意圖方便，到了真正要喝的時候，才突然生起這不是酒的猜想或是懷疑；雖然臨下肚時後念的心沒有犯戒故意，但卻成就了先前的飲酒動機方便，所以必須判定結犯重罪。如果從一開始就完全沒有飲酒的意圖，只是單純昏迷遺忘而誤飲者，則必須開許不犯。《戒疏》說道：歷代諸位律師都是主張依據心念隨順外境來判定結戒，我個人的看法與他們不同；

【1198-0002】資持記/10b_中三下#39
【原文】聖制有以，文少不了；豈有智人由來不嗅，須漿誤飲，可結提耶！《十誦》。彼約不看，同今取境。看則非意，可證迷心無方便者。不犯中，初文。兩緣可解。次科。以律語漫，引論決之。《五百問》中，必取醫語以定可不。強下，即教他犯。次引《善見》，必無香味。兩準論意，須知制急，不可濫託。三中。
【譯文】聖人的制戒自有其深刻因由，原文字句稍微有些不夠詳盡；哪裡有具備智慧的人從來不去嗅聞氣味，需要喝漿湯時誤飲了酒，就可以給他結犯波逸提罪的道理呢！《十誦律》中，彼律是依據沒有審慎查看看視而飲用，這與如今依照客觀外境來定罪的觀點相同。如果看視了卻未認出，那純屬無心之過，正好可以用來證明心中迷昧且毫無預謀方便者應當不犯。在不犯的條文中，開頭第一段。兩條開許因緣容易理解。次一科。因為律典的用語過於寬泛廣漫，所以必須引用論典來加以決斷。《五百問》中規定，必須完全依憑合格醫生的醫囑，才能決定到底可否服用。隨後是指教唆他人犯戒的行相。接著引用《善見論》，強調所用的藥引酒必須毫無酒的香氣與味道。這兩處都依照論典的深意，必須明白戒律的制定極為嚴格緊急，萬萬不可隨意濫用託詞而破戒。第三項中。

【1198-0003】資持記/10b_中三下#40
【原文】《僧祇》果漿，同上甜酒。麴知飯提，亦約能醉。蘖即米牙，謂糟粕也。此方多有糟藏之物，氣味全在，猶能醉人；世多貪噉，最難節約；想西竺本無，故教所不制；準前糟麴，足為明例；有道高士，幸宜從急。五十二。
【譯文】《僧祇律》所說的各類果漿，等同於前述的甜酒。酒麴與酒釀飯結提罪，也是依據其能否讓人發醉來評定的。「蘖」就是指發芽的米麥，也就是酒糟粕物。我們漢地到處都有用酒糟醃藏封存的各類食物，其酒的氣味完全留存，依然能夠令人吃醉；世俗之人大多貪圖這種口腹滋味，最是難以自制節約；想來古天竺西方原本沒有這種醃製法，所以聖教律典中未曾明文禁止；但依照前面有關酒糟、酒麴的判例，已足以作為明晰的依據條例；志在求道的高尚志士，萬望在此處從嚴、從緊要求自己。第五十二條戒。

【1198-0004】資持記/10b_中三下#41
【原文】〔佛在舍衛，十七群在阿耆羅婆提河中嬉戲澆潛，匿王與未利夫人在樓上見，夫人令以石蜜奉佛，便呵責而制。〕制意中。初是壞法，二即損他，三四損己。佛慈制戒，反損成益。犯緣。第二謂道行渡水等，皆不犯故。釋中。第引四文，攝相斯盡；罪有輕重，隨事不同；莫非皆約戲弄之意。
【譯文】〔佛陀在舍衛國時，十七群幼小比丘在阿耆羅婆提河中嬉戲玩水、互相澆潑潛游，波斯匿王與末利夫人在高樓上看見，夫人派人拿著石蜜供奉給佛陀，佛陀因而嚴厲呵責比丘並制定此戒。〕制戒的用意中。第一是敗壞佛教威儀法度，第二是損害他人的敬信，第三與第四是損害自身的德行與性命安全。佛陀慈悲制定戒律，正是為了反轉損害使之成為無上的法益。犯戒因緣。第二項是指凡是為了趕路行道而涉水渡河等情形，全都屬於不犯的範圍。在解釋條文中。依序引用了四處文獻，將嬉戲之相收攝無遺；罪名有輕有重，都是隨著所涉及的事態情境而有所不同；無一不是依據內心是否存在戲謔玩弄的心態來論定的。

【1198-0005】資持記/10b_中三下#42
【原文】不犯三緣。皆非戲意。道行渡水，一也；沈水取物，二也；學浮防難，三也。準《注戒》，而下多浮字。掉臂畫水，浮法須爾，因而潛故。五十三。〔佛在舍衛，六群中一人擊櫪十七群中一人幾死，因制。〕戒名者。古謂以手於腋下捵弄令痒，若準犯緣必具惱意，故知成犯非唯戲劇。釋中，《僧祇》。
【譯文】不犯的開許因緣共有三條。全都必須是不存戲弄之心。為了行路趕道而涉水渡河，這是第一條；沉入水中打撈取回落水之物，這是第二條；學習游泳技能以防備日後的溺水災難，這是第三條。依照《注戒本》，在「而」字下方多出了一個「浮」字。擺動手臂劃撥水面，這是游泳時必須採取的動作法式，因而不得不暫時潛入水中。第五十三條戒。〔佛陀在舍衛國時，六群比丘中有一人去抓搔戳擊十七群比丘中一人的腋下，致使對方大笑氣喘幾乎窒息喪命，因而制定此戒。〕戒律的名稱。古德認為是指用手指在對方的雙腋之下挑逗抓搔使人發癢，但如果依照犯戒的客觀因緣，內心必定要具備惱亂對方的意圖，由此可知構成犯罪絕非僅僅是因為好玩嬉鬧而已。在解釋文句中，《僧祇律》。

【1198-0006】資持記/10b_中三下#43
【原文】指觸，須論惱意。言挽衣者，深防意也。若準《四分》，眠觸皆開。《五分》。簡異類。《四分》。簡餘物。不犯中。略行來，掃地，誤以杖頭觸他。五十四。〔佛在拘睒毘，闡陀欲犯戒，比丘諫言莫作，不從他諫，即犯諸罪，故制。〕緣中，初通列五緣。此下，點上四五。
【譯文】用手指觸碰抓搔，必須審究其是否有惱亂對方的惡意。所謂「拉扯衣服」，是為了深刻防範引發觸癢的意圖。如果依照《四分律》，在睡眠狀態中無意識的觸碰全都予以開許。《五分律》簡別了非同類的有情眾生。《四分律》簡別了手指以外的其餘各類器物。在不犯的條文中。簡要列出如行走往來、打掃庭院地面時，不慎誤用拐杖的杖頭觸碰到他人。第五十四條戒。〔佛陀在拘睒毘國時，闡陀比丘企圖毀犯戒律，其餘比丘好言勸諫說請勿這樣做，闡陀傲慢不肯聽從他人的勸阻諫言，隨即違犯了種種戒罪，佛陀因而制定此戒。〕犯戒因緣中，開頭先總體列舉出五條因緣。隨後點明辨析前面的第四與第五條。

【1198-0007】資持記/10b_中三下#44
【原文】前僧殘中，違僧命重，隨諫即結；此別人諫，要待作成；若不作事，便成受勸故也。又不同下拒勸學戒；諫於止犯，出言即止；此諫作犯，待作成違。〔上並疏意。〕不犯指上者。若無智人諫，報言可問汝師和尚更學問等，若戲笑獨語夢中語錯亂。五十五。〔佛在波羅梨毘國，迦波羅比丘為佛侍者，於輕行處反披拘執怖佛，明旦制此戒。
【譯文】在前面僧殘重戒中，違抗僧團如法作出的羯磨命令罪責極重，隨著大眾三番羯磨勸諫完畢隨即結罪；而此處只是個別同修私下的勸諫，必須等到對方真正去做出違犯之事才成立結罪；如果聽諫之後沒有去做出惡事，那就變成了接受同修勸戒的善行了。這又不同於下文那條抗拒他人規勸學戒的戒條；彼處是諫阻他停止正在犯的罪，只要對方口出傲拒之言隨即結罪；此處是諫阻他不要去作即將犯的事，必須等到他真正作成了惡事才構成違背勸諫的罪責。〔以上全都是《戒疏》的深刻意旨。〕不犯指涉前文者。如果遇到沒有智慧常識之人胡亂勸諫，比丘回答說你可以去向你的法師和尚進一步請教學問等，或者是以戲笑之心、自言自語、夢中囈語以及神智錯亂時所說的話。第五十五條戒。〔佛陀在波羅梨毘國時，迦波羅比丘擔任佛陀的侍者，在佛陀經行放鬆的去處反披著皮衣、手持器械跳出來驚嚇恐嚇佛陀，佛陀於次日清晨制定了這條戒。
