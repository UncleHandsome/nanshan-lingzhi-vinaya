# 校閱材料　第615檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【615-0001】02_戒疏/11b_卷三上之二#61
【原文】【疏】三、犯處俱通者。如《十誦》中「趣說一事」，故犯不出二處。又云「隨所一犯，與覓羯磨」故。
【譯文】【疏文】第三、所犯之罪與處所兩者皆通的情形。如同《十誦律》中所說的「隨便指稱一事」，所以實犯之罪不出這兩處。又說「隨其所真正觸犯的其中一種罪，便為其作『覓罪相羯磨（實覓羯磨）』」之故。

【原文】【疏】四、對舉亦通諸篇。
【譯文】【疏文】第四、對證舉發的罪名也廣泛通於諸篇。

【615-0003】02_戒疏/11b_卷三上之二#63
【原文】【疏】五、僧別通塞。此問別人以舉罪故，下「毗尼」中舉藥問僧，以非別秉。此中有三毗尼：如比丘語治，自言毗尼也；如可信語治，罪處所也；要三法五法現故，即現前也。此無諍殄，與下不同。餘四毗尼，無義不有。
【譯文】【疏文】第五、僧團作法與個別審問的通達與閉塞。這裡之所以只單向詢問受嫌比丘個人來舉發其罪，是因為情節閉塞局限在個人身上；下文「滅諍毘尼」中推舉羯磨藥問及僧眾，則是因為滅諍羯磨並非由個別比丘私下秉持（而是由全體僧團共秉）。本處包含了三種滅諍毘尼：依照被舉發比丘自己的坦白而處治，這屬於「自言毘尼」；依照具足信心的優婆夷所言來處治，這屬於「罪處所毘尼」；必須在三種法度或五種法度現前審判，這就是「現前毘尼」。此處並沒有消除重大爭訟的議決，與下文的滅諍法有所不同。至於其餘四種滅諍毘尼，在義理上本就不可能適用於此處。

【615-0004】02_戒疏/11b_卷三上之二#64
【原文】【記】四、通塞中。
【譯文】【記文】在第四門論通塞的段落中。

【615-0005】02_戒疏/11b_卷三上之二#65
【原文】【記】初科。「同異」，即是通塞。「緣」即所疑事，謂事通犯局也。
【譯文】【記文】第一科。「同異」就是指通達與局限。「因緣」指引起懷疑的事由，也就是說懷疑的內容涉及各篇（通），而此處所結的罪行則局限於突吉羅（局）。

【615-0006】02_戒疏/11b_卷三上之二#66
【原文】【記】二中。初明通者，以造作七聚，不離二處故。「論」下，明局。「疑取染謗」，如戒所列，《義鈔》作「染機」。「結罪就處」，「唯」得二吉。
【譯文】【記文】在第二點中。首先說明通達的一面，因為造作七聚的罪行，都不外乎在這兩種處所發生。「若論」以下，說明局限的一面。「懷疑鎖定在染污與毀謗」，如同戒本所列舉的，《義鈔》寫作「男女染機」。「依處所結罪」，就「只能」得到屏、露兩種突吉羅。

【615-0007】02_戒疏/11b_卷三上之二#67
【原文】【記】三中，《十誦》二段。初「趣說一事」，不局篇聚故；「不出二處」，總歸屏、露。故二皆通。「又」下，次段。但示犯通，義同上釋。「與覓羯磨」，即下「罪處所毗尼」也。
【譯文】【記文】在第三點中，《十誦律》有兩段話。第一段是「隨便指陳一事」，因為不局限在特定篇聚；「不出兩種處所」，是指全歸結於屏處與露處。所以兩者都屬共通。「又說」以下是第二段文字。只是顯示犯戒事實是相通的，義理與上面的解釋相同。「為其作覓罪相羯磨」，指的就是下文的「罪處所毘尼」。

【615-0008】02_戒疏/11b_卷三上之二#68
【原文】【記】四中，舉通。前云「就壞僧論，亦通篇聚，且約過重收淫觸」等是也。
【譯文】【記文】在第四點中，說明舉發的相通。前面說過「就毀損僧眾而言，亦通於各篇聚，且先針對重罪收攝淫觸」等語，指的就是這個意思。

【615-0009】02_戒疏/11b_卷三上之二#69
【原文】【記】五中。初明舉罪通塞。此問「別人」是「塞」，下問「眾僧」是「通」。「此中」下，明用治同異。「三毗尼」如文次列。「此無」下，顯異。「餘」下，明無。七毗尼中，但有上三，不涉餘四。
【譯文】【記文】在第五點中。首先說明舉罪程序的通塞。這裡單獨審問「個人」屬於局限之「塞」，下文普問「全體僧眾」則屬於開放之「通」。「在此之中」以下，說明採用治罪法規的同異。「三種滅諍法」依照經文次序排列。「此處沒有」以下，顯明不同之處。「其餘」以下，說明不會出現。在七滅諍法中，這裡僅適用上述三種，完全不牽涉其餘四種。

【原文】【疏】五、僧尼不同。
【譯文】【疏文】第五、比丘與比丘尼規定的不同。

【615-0011】02_戒疏/11b_卷三上之二#71
【原文】【疏】昔云：「僧屏犯三，露則有二，故有不定。尼屏有二，露則犯一，一則是定，故無不定。」
【譯文】【疏文】古德曾說：「比丘在屏處可能觸犯三種重罪（夷、殘、提），在露處則可能觸犯兩種（殘、提），所以有不定法。比丘尼在屏處只有兩種罪（夷、提），在露處則只會觸犯一種（提），只有一種罪就是確定無疑的，所以比丘尼沒有不定法。」

【615-0012】02_戒疏/11b_卷三上之二#72
【原文】【記】五中，古解，初釋。尼觸同夷，故屏處但有夷提，露處唯有提罪耳。
【譯文】【記文】在第五點中，古德的解說，這是第一種解釋。比丘尼身受觸摸就直接等同於波羅夷，所以她在屏處只有波羅夷與波逸提兩種可能，在露處則只會觸犯波逸提罪而已。

【615-0013】02_戒疏/11b_卷三上之二#73
【原文】【疏】又云：「佛制舉罪，要僧尼兩眾。尼舉違敬，故取信女替尼舉罪，不識名種，故僧有之。尼犯須舉，二眾識相，不須俗男，故舉是定，所以無也。」今言尼舉，如「浣擗戒」。言「僧識犯」，亦有不識。何得輒言尼無不定？
【譯文】【疏文】古德又說：「佛陀規定舉發罪過，要求應由出家僧、尼二眾來擔任（舉罪者須是出家二眾）。比丘尼舉發比丘會違背尊卑敬重之禮，所以才選取清信女代替比丘尼舉罪，婦女不識得具體罪名與種類，因此比丘戒中設有不定法。而比丘尼若有犯戒需要舉發，僧尼二眾都懂得戒律相狀，不需要世俗男子出面，所以其舉發是確定明確的，因此比丘尼沒有不定戒。」如果照此而言，比丘尼舉發比丘，就如「浣擗羊毛戒」一樣由尼眾舉發。再者，若說「僧眾皆懂得犯相」，僧中也有許多不懂戒律的人。哪能輕易斷言比丘尼就絕無不定戒？

【615-0014】02_戒疏/11b_卷三上之二#74
【原文】【記】次釋，初敘僧有。「尼犯」下，次明尼無。「二眾」即僧中二位。「今」下，躡破。「三十」中「使非親尼浣羊毛戒」，即愛道尼舉過因制。上云「二眾識相」，然有末學或復不學，豈容皆識？
【譯文】【記文】第二種解釋中，首先敘述比丘戒之所以設有不定戒的理由。「比丘尼犯戒」以下，接著說明尼戒中沒有的緣由。「二眾」指的是僧團中的兩類成員（比丘、比丘尼二眾）。「如今」以下，緊追著予以駁斥破除。三十捨墮中的「差遣非親眷比丘尼洗滌羊毛戒」，正是大愛道比丘尼舉發比丘過失因而制定的。前面宣稱「僧尼二眾皆通曉罪相」，但僧中亦有剛入門的晚學、甚至是根本不學戒律之人，豈能人人全都知道？

【615-0015】02_戒疏/11b_卷三上之二#75
【原文】【疏】又云：「尼無獨行，行必有伴，故無屏露。」若爾，亦應二處不結坐戒。
【譯文】【疏文】古德又說：「比丘尼不能單獨行走，外出必定有同伴相隨，所以不會有獨處屏處或露處的機會。」如果是這樣，那比丘尼戒中也就不該為這兩個處所制定「同坐戒」了。

【615-0016】02_戒疏/11b_卷三上之二#76
【原文】【記】三釋。初引古，「若爾」下，難破。
【譯文】【記文】第三種解釋。首先引述古德的觀點，「如果是這樣」以下，提出詰難予以攻破。

【615-0017】02_戒疏/11b_卷三上之二#77
【原文】【疏】今云尼所以無者。由比丘與女生譏處坐，夫主不信，或時驅出，為患處深，故制僧有。尼雖與男獨坐生譏，夫無屬婦之義，過微不結。
【譯文】【疏文】我們現在解釋比丘尼之所以沒有這兩條戒的原因是：比丘若是與婦女在容易引發譏嫌的地方共坐，女子的丈夫便會心生懷疑不信任，甚至可能將婦女驅逐出家門，這所造成的禍患極其深重，所以特別為比丘制定此戒。比丘尼雖然若是與男子獨坐也會引來譏嫌，但世俗禮法中並沒有男子從屬於女子的道理，過失相對微輕，所以未予以結戒。

【615-0018】02_戒疏/11b_卷三上之二#78
【原文】【記】今解中。亦即首師義。初文。初明僧有。「或驅出」者，謂夫有驅婦之義。「尼雖」下，次明尼無。反上可知。
【譯文】【記文】在今師的解釋中，這也是智首律師的觀點。首先是第一段文字。前半段說明比丘戒具備此戒的原因。「甚至驅逐出門」，是指丈夫在宗法上有權休棄妻子。「比丘尼雖然」以下，接著說明尼眾無此戒的理由。與上方相比即可了然。
