# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【671-0001】資持記/16a_下四#44
【原文】一一事，謂境事也。種種誡，即律制也。下二句明由解起行。解由教生，故須詮辨，此即通敘一部正教之意。次科，初覆點前篇。諸門，總上二十六篇；以諸篇中，科義相由，事類條貫；顯非雜亂，故云日途相攝。別下，次探示後篇；別類者，沙彌及尼，對大僧為別；諸部，對本宗為別。
【譯文】所謂「一一事」，是指所面對的一切境相事物。所謂「種種嚴誡」，是指律藏中所立下的種種規範禁令。後兩句闡明由明晰的理解進而發起正確的行持。正確的理解必然由研讀教法而產生，所以必須詳加詮釋與辨明，這便是通篇統括敘述一部正律核心意旨的本意。在下一科中，首先回顧指點前面的各篇章。所謂「各門」，是總括前面的二十六篇；因為在那許多的篇章中，科判義理前後相承，事相類別條理井然貫通；藉此彰顯其並非雜亂無章，所以才說「依其門徑途序互相引領攝受」。從「個別」以下，接著預先提示後面的篇章；所謂「個別的類別」，沙彌與比丘尼，相對於大僧比丘而言屬於個別小眾；其餘各部律典，相對於四分律本宗而言屬於個別部派。

【671-0002】資持記/16a_下四#45
【原文】統收，亦彰不雜。羅，謂包羅。以下，正明本篇。上二句明事雜。繁類，謂無條流。斷，謂義有孤絕；續，謂事或連貫。皆不成科段，故云雜務。紛綸，喻絲之紊亂也。次二句明文雜。瑣，小也。此別，即指當篇；對於上下，故云別也。三中，初顯要。必下，勸修。則下，彰益。怯懦，即畏懼也。
【譯文】統括收納這些內容，同樣是為了彰顯戒相的不雜亂。所謂「羅」，就是包羅無遺的意思。從「以」字以下，正式說明本篇的特色。前兩句說明所涉及的事相極為繁雜。所謂「繁複門類」，是指沒有單一連貫的流派脈絡。所謂「中斷」，是指有些義理看似孤立突兀；所謂「延續」，是指有些事相彼此牽引關聯。這些零散內容都無法各自獨立構成一個完整的章節科段，所以才稱為「繁雜的行務」。所謂「紛紜錯綜」，是比喻如同雜亂無章的絲線一般。隨後的兩句說明文字引述的繁雜。所謂「瑣碎」，就是細小零碎的意思。所謂「這個個別章節」，指的便是當前這一篇；相對於前篇與後篇而言，所以稱之為「別」。第三段中，首先顯明本篇的切要至關重要。從「必定」以下，懇切勸勉大眾勤加修習。從「便能」以下，彰顯修學所帶來的殊勝利益。所謂「怯懦」，就是畏懼害怕的心態。

【671-0003】資持記/16a_下四#46
【原文】反知不學，動用乖儀；入眾遊方，能無疑懼；寄言學者，幸留意焉。標列十門。一四五，多從化教，非不兼制；餘並制教，時亦兼化。初門，禮敬中。晨午昏為晝三時，初中後為夜三時。三事，如文次列。據餘經論，須行五悔，更加迴向發願；如祖師六時禮文，具載儀式，學者宜依。次科，《多論》。
【譯文】反過來說，如果不知研讀學習，起心動念與舉止動靜必定會乖離戒律儀軌；一旦進入大眾僧團或者遊歷十方行腳參訪，如何能夠不心生疑慮與惶恐畏懼？在此寄語諸位修學戒法的人，萬幸能對此多加留心用意啊。在此標示列出十個門徑：第一、第四、第五門，多數是屬於化教的教化範疇，但並非不兼含制教的戒規；其餘各門則全屬於制教的嚴格規範，有時也兼通於化教的義理。在第一門「禮敬」中，清晨、正午、黃昏為白天的「晝三時」，初夜、中夜、後夜為夜晚的「夜三時」。《智論》所列的三事，正如文中依次羅列。根據其餘經論的教示，在禮敬時必須修持「五悔法」，更應當加上迴向與發願；這正如律宗祖師在六時禮佛懺文中所詳盡記載的儀軌形式，修學者理應當切實遵循。下一科引述《薩婆多論》：

【671-0004】01_行事鈔/12a_卷下之四#20
【原文】十種分之：一佛法僧，二眾中雜事，三別人自行，四共行同法，五出家要業，六遇賊法，七大小便法，八慈濟畜生法，九避惡眾生法，十雜治病法。
【譯文】本篇內容分為十類：第一是事奉三寶（佛法僧）之法，第二是僧眾之中的雜務規範，第三是各人私下自修的操持，第四是同修共住的同行之法，第五是出家人的本要正業，第六是遭遇賊寇強盜時的對處法，第七是大小便利的律儀，第八是慈悲救濟畜生之法，第九是避開惡人惡獸等惡眾生之法，第十是各種對治調治疾病之法。

【671-0005】01_行事鈔/12a_卷下之四#21
【原文】《智論》：菩薩晝三夜三，常行三事：一者清旦偏袒右肩，合掌禮十方諸佛，言：「我某甲，三世三業罪，願令除滅，更不復作！」二者十方三世諸佛功德，願隨喜勸助。三者勸請十方諸佛，初轉法輪，及久住於世。行此三行，功德無量。
【譯文】《大智度論》記載：菩薩在白天三時、夜間三時（晝夜六時），恆常行持三件事：第一、在清晨偏袒右肩，合掌頂禮十方諸佛，祈請說：「我某某，過去、現在、未來三世身口意三業所造之一切罪障，願皆消除滅盡，從今以後誓不再造！」第二、對於十方三世一切諸佛所成就的功德，發願悉皆歡喜讚歎、隨喜勸助。第三、至誠勸請十方諸佛最初轉大法輪，以及長久住世度化眾生。能依此修行這三種法門，功德不可限量。

【671-0006】01_行事鈔/12a_卷下之四#22
【原文】《薩婆多》：不得以華香瓔珞莊嚴具，著佛身上，得散地；供養僧亦爾。不得以香華，著漿飲食上，供養僧。《五百問》：先上佛幡，得取作餘佛事；若施主不聽，不得。《薩婆多》：若食是佛臘等，雖先受捉，後買得食，以捉時無已想故。
【譯文】《薩婆多論》說：不得將花朵、塗香、瓔珞等莊嚴裝飾之物，直接披戴在佛像之身，只可散布在地上供養；供養僧眾時也是如此。不得將香花直接放在飲料與飲食之上來供養僧眾。《五百問》說：原先用以供奉佛陀的綵幡，可以取來轉作其他的佛事之用；如果原施主不同意，則不可轉用。《薩婆多論》說：若食物是自恣日供佛的節慶齋食等（佛臘），比丘雖然在先前已經親手觸碰持拿，後來出錢買下後仍然可以食用，因為最初拿取時並沒有當作自己所有物之念頭的緣故。

【671-0007】資持記/16a_下四#47
【原文】華纓，唯得散地；不得散佛僧身，及飲食上，非所宜故。《五百問》。作餘佛事者，雖聽改轉，不換本質，如盜戒引。《多論》。佛臘謂自恣日食，等取餘供養物；雖僧手捉，不成惡觸。三中，《十誦》明知事法，初教勤勞。常下，次令發願。教示餘眾，同此存心，故云亦爾。《善見》，明守寺。
【譯文】編織的花纓華鬘，只允許散灑鋪設在地面上；不得直接散灑在佛陀與僧眾的尊軀上，更不得丟在飲食之上，因為那是極不合宜失敬的舉動。《五百問》記載：如果拿供佛的物品轉作其餘佛事，雖然開許改換用途，但絕不得變更其原有的常住質地，正如在盜戒中所引述的一樣。《薩婆多論》提到：所謂「佛臘」，是指自恣日當天所供養佛陀的食物，以此類推亦包含其餘的各類供養物品；即便僧人親手持拿，也不會構成觸犯惡觸之罪。在第三段中，《十誦律》闡明擔任知事執事僧的法度，首先教導應當精勤辛勞為眾服務。從「常常」以下，接著命令應當發廣大善願。藉此教化昭示其餘的大眾，也應當抱持同樣的存心，所以才說「其他僧眾亦復如是」。《善見律》則闡明留守常住寺院的法規。

【671-0008】01_行事鈔/12a_卷下之四#23
【原文】《十誦》：知僧事人，應巡行僧坊；先修治塔，次四方僧事。常作是念：願諸比丘，未來者來；已來者，供給四事，不令有乏。教沙彌使人亦爾。《善見》：佛常使一比丘，食時守寺。《智論》：差僧使，從下起。
【譯文】《十誦律》說：主管僧團事務的知事人（僧知事），應當巡行查察整個僧坊；應當先修繕維護佛塔，其次操辦四方僧團的公務。心中常生起這樣的意念：「願十方諸位比丘，未來的皆能前來；已經到來的，隨時供給衣服、飲食、臥具、醫藥四事，不讓他們有所匱乏。」教導沙彌與差役僕從時也是如此。《善見律》說：佛陀經常差遣一名比丘，在眾人用餐的時刻負責留守看顧寺院。《大智度論》說：差遣僧團公役差事，應當從戒臘最低的下座開始輪派。

【671-0009】01_行事鈔/12a_卷下之四#24

【原文】《智論》，教差次。請命依臘，須從上起；差役取卑，故從下起。四中，《薩遮、俱舍》，制不得壞。上品治者，同逆罪故。《智論、僧祇》，開壞惡易好。五中。供人即法者，以人解法，法依人故。六中。律令選一能者，知掌眾務；初大僧，二沙彌，三淨人，尋文可見。帥，所類反，領也。七中，初科，《僧祇》明賞給。
【譯文】《大智度論》教導差遣僧差的先後次第。如果是請命供養，應依照戒臘的高低，必須從上座大德開始延請；如果是派遣執役勞務，應先選取戒臘居下的人，所以必須從下座僧人開始差遣。第四段中，《薩遮尼乾子經》與《俱舍論》嚴厲規定，寺院佛法設施絕對不得毀壞。律中判定以最高品階的罪相論處，是因為毀壞僧物等同於犯下五逆重罪的緣故。而《大智度論》與《僧祇律》中，則特別開許若是為了除壞破爛醜惡的設施以換取良好莊嚴的新物，則不在禁止之列。第五段中：供養有德之人便等同於供養正法，這是因為人能通達理解正法，正法也完全依賴人來弘揚住持的緣故。第六段中：戒律命令大眾應當推選出一名具備才幹能力的人，負責總領執掌僧團的大眾事務；這人選首先應當由大僧比丘擔任，其次由沙彌擔任，第三才由淨人承擔，細尋律文便可明白。經文中的「帥」字，音讀為率領的「率」，意思便是總領率領。第七段的第一科中，《僧祇律》闡明對於辛勞執事者的賞賜給予。

【671-0013】01_行事鈔/12a_卷下之四#27
【原文】《僧祇》：若僧地種果樹有功者，若一樹一園，聽與一熟，不能併取，年取一枝，枝遍則止；若種瓜菜，與一剪。《五分》：若月直監食，欲知生熟鹹酢，得掌中舌舐甞之。若白衣入寺，應借僧臥具受用。僧有五種物不可賣、不可分：一地，二房舍，三須用物，四果樹，五華果。《僧祇》：眾僧田地，正使一切僧集，亦不得賣、不得借人；若私受用，越毘尼。若園田好，惡人侵者，語本施主，任其轉易；僧床臥具，亦爾。《四分》：僧物不應賣分入己，偷蘭遮。
【譯文】《僧祇律》說：如果有人在僧團土地上栽種果樹建有功勞，無論是一棵樹還是一整座果園，聽許將成熟的一季果實給予他作為酬謝，但不能一次全部收取，而是每年准許採取一枝的果實，等到各枝都採過一遍之後便終止；如果栽種的是瓜果蔬菜，則給予收割一茬（一剪）作為酬勞。《五分律》說：若是輪值按月監理大眾飲食（月直）的比丘，為了查知菜餚的生熟鹹酸，可以倒在自己手掌心中用舌頭舐嘗調味。如果有世俗白衣居士留宿寺院，應當借調僧團的臥具供其暫時使用。僧團有五種物品絕對不可出賣、不可瓜分私用：一是常住土地，二是常住房舍，三是僧眾生活所必需的用具，四是果樹，五是樹上所產的花果。《僧祇律》說：僧團大眾的田地，縱然聚集全體僧眾議決，也不得擅自出賣、不得借貸給世俗私人；若是私自擅用，犯越毘尼（違背戒律之罪）。如果僧團的園林田地肥美良好，招致惡人強橫侵奪，應當轉告原先捐贈的施主，聽憑施主出面調換抵易；僧團的床榻臥具，處理原則也是如此。《四分律》記載：僧物不應當擅自變賣分取歸為己有，違者結犯偷蘭遮（大障善道罪）。

【671-0014】01_行事鈔/12a_卷下之四#28
【原文】《僧祇》：若佛生日、轉法輪日、若大會，多出幡蓋，供養支提；若卒風雨，一切共收；不得云：我是行人大德等；應隨近房安置，不得護房；應抖擻牒舉。何以故？汝等依是得活。若治床褥，打楗稚時，不得徐行，當共治補；又不得云有德行。

【671-0015】資持記/16a_下四#49
【原文】言有功者，是彼經營故。一熟，謂一番採熟留生也。一剪，謂一番剪也。《五分》三段。初明知事嘗食，開舌舐吉；次明僧物暫借俗用，相依住故；三明五種僧物不分賣者，是常住故。《僧祇》同上，初制永定。次開轉易。《四分》。結蘭。暫礙僧用，必侵入己，如上犯重。次科。
【譯文】所謂「有功勞的人」，是指此處的果木等物產全由那人辛苦經營培植的緣故。所謂「成熟一輪」，是指第一批採摘已成熟的果實，而留下尚未成熟的。所謂「一剪」，是指收割一茬瓜菜。《五分律》包含三段內容：第一說明知事僧人在調味時若要品嘗食物，開許將食物放於掌中以舌舐嘗調味，如此則合乎如法（吉）；第二說明僧團的常住器具可以暫時借給俗人使用，這是因為彼此相互依存居住的緣故；第三說明有五種僧團常住物資是絕對不得私自瓜分販賣的，因為這是屬於十方大眾常住所有的緣故。《僧祇律》與上述意旨相同，首先規定常住物應永遠固定保有。其次開許在必要時得以物易物以求其合宜。《四分律》規定：若違犯便結下偷蘭遮罪。如果只是暫時障礙僧團的使用，必定是為了侵占據為己有，其過咎正如前面所說應依重罪論處。在下一科中：
