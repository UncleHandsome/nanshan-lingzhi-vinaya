# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【326-0001】02_戒疏/17a_卷四上之二#139
【原文】【記】三、意中。初示如法合往。「自非」下，四句，總後十德。初句攝二、三、四，次句攝初及九，第三句攝五及八，第四句攝六、七與十。「有」下，次簡非法。初至「導物」，反上初句，即無解也。「或」下，至「濟拔」，反前次句，謂無行也。既無解行，豈能說法備德者乎？文中不反，義可見矣。「由」下，三、結示。
【譯文】【記文】第三種用意中。首先開示在如法規範下應當差派前往的資格。「若不是」以下四句，總結涵蓋了後文所載的十種德行。第一句總括了第二、三、四德，第二句總括了第一與第九德，第三句總括了第五與第八德，第四句總括了第六、七與第十德。「若有人」以下，接著淘汰不合法的劣等人員。從「若有人」到「導引眾生」，正與上述第一句相反，指的是沒有真實知見正解。「或者」以下到「濟拔他人」，正與上述第二句相反，指的是缺乏身心威儀戒行。既然缺乏真知又無行持，哪裡談得上說法度人且備足德行？文中雖未一一完全反向列舉，但其文義已十分分明了。「正是由於」以下，第三總結開示。

【326-0002】02_戒疏/17a_卷四上之二#140
【原文】【記】四、制差中，二意。初為能教有濫。「藉」下，二、為所教易化。傳訓無壅，故曰「通行」。如風偃草，故云「風化」。
【譯文】【記文】第四、規定僧差的用意中，包含兩層意涵。首先是為了防範能施教的比丘私下前往產生弊端流弊。「藉由」以下，第二是為了使被施教的尼眾容易受到正法化育。法音宣導訓誨暢行無礙，所以稱「通行」；猶如狂風吹伏雜草令其順從倒伏，所以稱「風化」。

【326-0003】02_戒疏/17a_卷四上之二#141
【原文】【記】五中。「專」下四句，反前初意。「乖」下二句，反前次意。「靡」即順也。「輕」下，結過顯制。不取僧命，故云「輕法」。輒為師訓，即是「自尊」。
【譯文】【記文】第五種用意中。「放任自專」以下四句，正反照前文第一種用意。「違背法度」以下二句，反照前文第二種用意。「靡」就是順從的意思。「輕慢」以下，總結其過失以彰顯制戒必要。不聽從僧團的大眾命令，所以叫「輕法」；擅自充當比丘尼的心靈導師，這就是「自尊自大」。

【326-0004】02_戒疏/17a_卷四上之二#142
【原文】【疏】論犯五緣：一、佛開說法、八教；二、制白二差；三、不蒙僧命往集尼眾，即簡別房別說不犯；四、說法、八敬；五、隨說，墮。
【譯文】【疏文】論定犯戒的五種條件：第一、佛陀開許只准宣講佛法與八敬法教誡；第二、規定必須經由羯磨白二差派方可成行；第三、未奉僧團差命便逕自前往聚集尼眾施教，此處特別簡別：若在個別房間私下個別交談則不犯本正罪；第四、對大眾宣說佛法或八敬法；第五、隨著宣講語音完畢，即結犯波逸提墮罪。

【326-0005】02_戒疏/17a_卷四上之二#143

【譯文】【記文】列出犯戒條件。第二點「規定經白二羯磨」，其羯磨文如下：「大德僧聽！若僧時到，僧忍聽。差某甲比丘教授比丘尼。白如是。」

【326-0006】02_戒疏/17b_卷四上之二#1
【原文】【註】佛在舍衛。大愛道尼來請教授，佛令差往，僧次般陀往彼說法，六群次往，向說世論。愛道白佛，便羯磨差而制戒也。
【譯文】【註文】佛陀在舍衛國時。大愛道比丘尼前來懇請佛陀教授佛法。佛陀吩咐僧團輪流差派比丘前往，剛好輪到周利槃陀前往教誡說法。接著輪到六群比丘前往，他們卻對尼眾高談闊論世俗的雜談。大愛道便將此事稟告佛陀，佛陀於是制定以僧團羯磨如法差派教授師，並隨之制定本戒。

【326-0007】02_戒疏/17b_卷四上之二#2
【原文】【疏】就緣起中：初明尼請；二、令僧次差往；三、六群為說世論，過起之由；四、「白佛」下，羯磨備德。
【譯文】【疏文】在戒條的緣起中：第一、說明比丘尼前來祈請；第二、佛陀吩咐由僧團依序輪派前往；第三、六群比丘向尼眾宣說世俗雜論，這是引發過失的起因；第四、從「稟白佛陀」之後，說明必須經由羯磨差派具備完整德行之人。

【譯文】【記文】在戒律緣起中，所謂「宣說世俗雜論」，《四分律》明確指出就是「僅僅談論帝王之論、人民之論、軍陣戰馬等雜論」的情況。

【326-0009】02_戒疏/17b_卷四上之二#4
【原文】【疏】問：「愛道來請，止論比丘，何不請佛？」
【譯文】【疏文】提問：「大愛道前來祈請，只請求比丘前來，為何不直接請求佛陀？」

【326-0010】02_戒疏/17b_卷四上之二#5
【原文】【疏】答：「請佛教授，有二種過：一、違八敬教，教中令問僧故；二、違誓受心。若請僧者，翻前兩失。」
【譯文】【疏文】回答：「祈請佛陀親自教授，有兩種過失：第一、違背八敬法的教敕，因為八敬法中規定應當請問僧團；第二、違背當初立誓納受戒體時的心願。如果請求僧團差派，正好能免除上述兩種過失。」

【326-0011】02_戒疏/17b_卷四上之二#6
【原文】【記】初問答中。初明請佛二過，並是違敬，但上違敬法下違受心，以本從八敬而獲體故。「若」下，次明請僧兩得。有本作「請佛者」，文誤。
【譯文】【記文】在第一個問答中。首先說明請佛的兩種過失，都屬於違背恭敬，只是前者違背了恭敬僧眾的法則，後者違背了自己當初誓願納受的心，因為尼眾本來就是依順八敬法才得以獲得戒體。從「如果」以下，接著說明請求僧眾所獲得的兩項利益。有版本寫作「請佛者」，那是文字傳抄錯誤。

【326-0017】02_戒疏/17b_卷四上之二#12
【原文】【記】次問。答中，初明佛教之過，後明僧教之益。「翻三益」者，廣、多、長也。
【譯文】【記文】接著是第二個問答。在回答中，首先說明若由佛陀親自教導會有的過失，隨後說明由僧團教導所帶來的益處。所謂「轉成三種利益」，即是普及廣大、人數眾多、流傳長遠。

【326-0018】02_戒疏/17b_卷四上之二#13
【原文】【疏】就「羯磨差」中，須具十德：一、具持戒行；二者，多聞；三、誦二部戒本利；四、決斷無疑；五、善能說法；六、族姓出家；七、顏貌端正；八、堪為尼說法，令尼歡喜；九、非為佛出家被三法衣而犯重法；十、二十夏若過。不具斯十，皆不成差，故略分別也。
【譯文】【疏文】在「以僧團羯磨差派」的規定中，受差派者必須具備十種德行：一、具足護持清淨戒行；二、廣學多聞；三、能流利背誦僧、尼兩部戒本；四、決斷戒律疑難毫無疑惑；五、善於為大眾說法；六、出身尊貴家族而出家；七、顏貌端正；八、堪能為比丘尼說法，使尼眾生起法喜；九、並非為佛出家披著三衣卻犯下重罪之人；十、出家戒臘滿二十夏以上。若不具備這十種德行，都不能算作差派成立，因此在此作簡略的分別。

【326-0019】02_戒疏/17b_卷四上之二#14
【原文】【記】差人中。初列十德。「一」、「九」，「五」、「八」，名似相濫，並前通後別，分之可解。又「八」及「十」，局在教尼，名為別德，餘皆通德。「不」下，簡非。此但依《律》單列名數，未暇廣釋，故云「略」也。
【譯文】【記文】在差派人員的段落中。首先列出十種德行。「第一」與「第九」、「第五」與「第八」，名稱看似容易混淆，但都是前者通泛、後者別指，辨析之後便能明了。另外「第八」與「第十」，專門局限於教化尼眾的職責，稱為別相之德，其餘各項則屬於通泛之德。從「若不具備」以下，是剔除不合格者。這裡只是依照《四分律》單純列出項目名稱，尚未詳細解釋，所以說「簡略」。

【譯文】【律文】如果有比丘，未經僧團差派，教授比丘尼者，犯波逸提（單墮罪）。

【326-0021】02_戒疏/17b_卷四上之二#16
【原文】【註】若於說戒時，座上問答已，若僧差，若隨尼請，彼比丘剋時到，尼亦剋時迎；若違，俱犯吉羅。若聞來者，當出半由旬迎，供給所須，不者吉羅。若僧不差，非教授日，與說八不違法，吉羅；若不差，與說法者，墮。若僧病、不和合、眾不滿，應遣人禮拜問訊；尼眾病等，亦遣禮拜問訊——若不，吉羅。比丘尼等二眾吉羅。不犯者，比丘尼眾如上方便已，而為水陸道斷諸難不容禮拜問訊者，並開。
【譯文】【註文】若在誦戒之時，法座上問答完畢，若是僧團所差派，或是隨順尼眾祈請，該比丘應當準時抵達，尼眾也應當準時迎接；若有違背，雙方都犯突吉羅罪。如果聽聞比丘前來，尼眾應當出迎半由旬，並供養所需物品，不迎接供養的犯突吉羅。如果未經僧團差派，又不是規定的教授日，卻為尼眾宣說八不違法（即八敬法），犯突吉羅；若未受差派而為尼眾說其餘佛法的，犯波逸提。如果僧團有僧人患病、僧眾不和合、人數不足，應派遣他人前往禮拜問訊；尼眾有疾病等情況，也應派遣他人前往禮拜問訊——若不派遣，犯突吉羅。比丘尼等兩種出家女眾犯突吉羅。不犯的情況：比丘尼眾已經做好了上述迎接問訊的準備，但因為水陸道路斷絕等種種災難，實在無法前往禮拜問訊者，皆開許不犯。

【326-0023】02_戒疏/17b_卷四上之二#18
【原文】【疏】就解第四「八敬」之文，指於《律本》。恐好事者未見前後故，略為三門：初制意列相；二、敬之次第；三、得罪輕重。
【譯文】【疏文】解釋第四句「八敬法」的文字時，註解指向了《四分律》原本。唯恐好學佛法之人未能通覽前後文意，所以簡略分為三門：第一是制定戒律的旨意與各相列舉；第二是八敬法的順序次第；第三是得罪輕重。

【326-0024】02_戒疏/17b_卷四上之二#19
【原文】【記】戒本，第四，初標中。云「指《律本》」者，點注略也。「恐好事」者，樂法人也。
【譯文】【記文】在戒本第四句、最初標示的內容中。所謂「指向《律本》」，是指出註解文字簡略。「唯恐好學佛法之人」，是指樂於追求正法的人。

【326-0025】02_戒疏/17b_卷四上之二#20
【原文】【疏】就初制者。凡體無貴賤，有道則尊，法式軌要，非僧不具。敬法重人，事須致敬。敬而為言，觸途皆是。但此八種，攝尼偏要，故別制之，審能修行，戒淨法住。故《善見》云：「由度尼故，正法減半；若行八敬，還滿千年。」法由人弘，其義不昧矣。
【譯文】【疏文】探討最初制定義理。大凡人的本體並沒有尊卑貴賤之分，有道德智慧便值得尊崇，而威儀軌範的要旨，非僧團就無法具足完備。為了敬重正法、尊重賢人，理所當然應當致以敬意。就恭敬的道理而言，處處都應奉行。然而這八種戒法，在攝受約束尼眾上格外關鍵要緊，所以佛陀特別制定，若能切實依教修行，戒行就能清淨，正法得以常住。因此《善見律論》說：「由於度化尼眾出家，正法縮短了五百年；如果依教遵行八敬法，正法便能重新圓滿維持千年。」正法全仰賴人來弘揚，其中的深意絕非晦昧不明的。

【326-0026】02_戒疏/17b_卷四上之二#21
【原文】【記】制意中二。初通敘僧德，有道具法，故須致敬。「敬而」下，二、正顯八敬，又為三節。初正明。「故」下，引證。此即阿難初請度尼，如來許度之語。「法」下，結告。
【譯文】【記文】在制戒旨意中分為二部分。首先通泛敘述僧寶的德行，具有道德修為並具足戒法，所以應當致以敬意。從「就恭敬」以下，第二是正式闡明八敬法，又細分為三小節。首先正式說明。從「因此」以下，引用經教作證。這就是阿難最初請求度化尼眾、如來答應准許時所說的話。從「正法」以下，總結叮嚀。

【326-0029】02_戒疏/17b_卷四上之二#24
【原文】【疏】二、明次第者。法不自顯，開導在人，是以初三明遵僧也。人尊由法，故次四、五明所遵法。法由請得，是故下三明稟悔也。
【譯文】【疏文】第二、說明順序次第。正法不能自行顯現，發揚引導全在於人，所以前三條旨在說明尊奉敬順僧寶。然而僧人之所以尊貴是因具備正法，所以第四、第五條說明所應尊奉的戒法。正法必須透過祈請才能獲得，因此後三條說明稟承教授與懺悔。

【326-0030】02_戒疏/17b_卷四上之二#25
【原文】【記】明次第中，初科。三位次第相生，且約總分。隨一位中，復有次第，如下別論。「悔」字誤，合作「誨」，下同。
【譯文】【記文】在說明順序次第中，此為第一科。三種層次依序相生，暫且依大綱區分。在每一種層次中，又各自具有細部的順序，如下文分別討論。「悔」字有誤，應當作「誨（稟受教誨）」，下文相同。

【326-0031】02_戒疏/17b_卷四上之二#26
【原文】【疏】就初位中，身業慢麤，所以先明；口業過微，故須後說。說語二中，違法惱深，順法舉微，故列前後，或可希數而言也。
【譯文】【疏文】在前三條中，身業的傲慢較為粗顯，所以最先說明；口業的過失較為微細，所以隨後宣說。在口語的兩條之中，違背正法而生辱罵惱害較深，順應正法而檢舉過失惱害較輕，所以排列有先後，或者也可以依照發生的頻率少數來解釋。
