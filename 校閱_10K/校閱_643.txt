# 校閱材料　第643檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【643-0001】02_戒疏/13a_卷三下之一#29
【原文】【記】次列名中。三種各二者，大約分也。攝僧二者：作法有三，大界、戒場、小界；自然有四，聚、蘭、道、水。攝衣中二，如下廣辨。攝食二者，四種淨中，白二淨是作法，處分、不周、檀越三種即自然也。
【譯文】【記文】在第二部分列出名稱中，三種各分兩種，是大略的分類。攝僧界的兩種中：作法界有三種，即大界、戒場、小界；自然界有四種，即聚落、蘭若、道路、水域。攝衣界的兩種，如後文詳細辨析。攝食界的兩種中，四種淨地裡，「白二淨（作法淨地）」屬於作法界，「處分淨」、「不周淨」、「檀越淨」三種則屬於自然界。

【643-0002】02_戒疏/13a_卷三下之一#30
【原文】【疏】二、制意者。制攝僧界，攝人以同處，令無別眾罪，必有乖別，不名為僧，僧具六和也；二、制攝衣界，攝衣以屬人，令無離宿罪；三、制攝食界，攝食以障僧，令免宿煑罪。所言「界」者，彼此差別，互不相通，故曰「界」也。如文云「此僧伽藍界，非彼僧伽藍」也。
【譯文】【疏文】第二、制定意圖：制定攝僧界，是為了攝聚僧眾同處一界，使大眾不犯別眾集會的罪過，如果有所違逆分離，就不能稱為僧團，因為僧團必須具備六和敬；第二、制定攝衣界，是為了將衣服攝屬於比丘名下，使人不犯離衣過夜的罪過；第三、制定攝食界，是為了規範食物與僧眾隔開，使僧人免於觸犯宿食煮食的罪過。所謂「界」，是指彼此有所差別，互相不能混通，所以稱為「界」。如同註文所說（或：如同律文所說）「這個僧伽藍界，不是那個僧伽藍界」。

【643-0003】02_戒疏/13a_卷三下之一#31
【原文】【記】制意中。初別列三意，「所」下，總示界名。
【譯文】【記文】在制定意圖中，首先分別列出三種意圖；「所言界者」以下，則是總體指示界域的名稱含義。

【643-0004】02_戒疏/13a_卷三下之一#32
【原文】【疏】三、就宗分別者。僧、食二界，作法分隔，行用羯磨，如彼宗明。
【譯文】【疏文】第三、依據宗旨加以辨別：攝僧與攝食這兩種界域，是依靠作法來分隔，必須舉行羯磨法來運作，如同彼二界各自所宗的篇章中所闡明的那樣（或：如同彼處本法中所闡明的那樣）。

【643-0005】02_戒疏/13a_卷三下之一#33
【原文】【疏】此中明衣，計須作法，然衣離相，自然界多。故從多論，戒本須引。若論作法攝衣界者，《羯磨疏》中具之。
【譯文】【疏文】此處說明衣界，照理也應當作法，然而在離開衣服的相狀上，屬於自然界的狀況居多。所以依從多數的情況來討論，戒本中必須加以引用。若要討論作法攝衣界，《羯磨疏》中已有完整具備的說明。

【643-0006】02_戒疏/13a_卷三下之一#34
【原文】【記】三、就宗者。謂三種界各有所宗。若三界相望，則衣是今宗。又就衣中，二界相對，則自然為今宗矣。是以先以三科簡之。
【譯文】【記文】第三「依據宗旨」，是指三種界域各自有其歸屬的宗要。若是三種界域互相對照，那麼衣界就是當前的主題；若單就衣界之中，兩種界域相對而言，自然界就是當前的主題了。因此先以這三科來加以簡擇分別。

【643-0007】02_戒疏/13a_卷三下之一#35
【原文】【疏】今論自然衣界相狀。下諸義中特論「僧界」者，以衣須隨身，身是僧界所屬，若不並明，則彼此相亂，故須合論大小，敘其得不。如斯識緣種者，可謂如鳥知其雌雄矣。
【譯文】【疏文】現在討論自然衣界的相狀。在以下各項義理中特別討論「僧界」，是因為法衣必須隨逐僧身，而僧身是屬於僧界所管轄的，如果不一併說明，彼此的界限就會互相混淆，因此必須合起來討論界域的大小，敘述其成立與否。像這樣能夠認識各種因緣差別的人，真可謂如同能辨別烏鳥的雌雄一樣敏銳了。

【643-0014】02_戒疏/13a_卷三下之一#42
【原文】【疏】聚落有二：可分別者，如《十誦》盡聚落集之；不可分者，如《僧祇》七弓之量，七樹中間則六十三步。廣如《羯磨疏》中。
【譯文】【疏文】聚落有兩種：能夠劃分邊界的，依照《十誦律》，應當召集整個聚落的僧眾；不能劃分邊界的，依照《僧祇律》，以七張弓的長度為準，七棵樹之間就是六十三步的距離。詳細內容如同《羯磨疏》所述。

【643-0015】02_戒疏/13a_卷三下之一#43
【原文】【記】聚落中。「可分別」者，處有分齊，人有限量。反此二種，名「不可分別」。由無限齊，故依「樹量」合數。並如《鈔記》。
【譯文】【記文】聚落之中，「可分別」的，是處所有明顯界限，人數也有限量。反於這兩種情況的，稱為「不可分別」。由於沒有界限，所以依照「樹木的間距」來折算步數。這些都詳見於《行事鈔》及《資持記》。

【643-0016】02_戒疏/13a_卷三下之一#44
【原文】【疏】二者，蘭若，亦有兩種：無難空地，可用《十誦》面俱廬舍五里集之；有難蘭若，則如《善見》七槃陀量五十八步四尺八寸。所以有難、無難者。僧法同遵，義無乖競，必有見異，多恐破僧，故須局狹。必若情通，自然廣攝。
【譯文】【疏文】第二種是阿蘭若，也有兩種：沒有危難的荒野空地，可以採用《十誦律》所說以一個俱盧舍（方圓五里）的範圍來召集僧眾；有危難的阿蘭若，則依照《善見律》以七個槃陀的距離，即五十八步四尺八寸為準。之所以區分有危難與無危難，是因為僧法應當共同遵守，在義理上不容許有違逆爭端，一旦意見不同，很可能導致破僧，所以界域必須收緊局限；如果僧情通達無礙，自然就可以廣泛包容攝受。
