# 校閱材料　第1644檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1644-0001】03_業疏/06b_卷一之六#36
【原文】白此為彼」者，白牒戒場，羯磨牒攝衣也。若牒白四中事，則初非攝。若就單白作者，僧時到前牒說戒，忍聽後牒自恣也。未必常有，立法例知。如今行世刈草掘地集眾同作，亦名僧事，望非是同
【譯文】所謂「白此為彼」，是在白文（白二羯磨之前白）中牒陳戒場，而在羯磨中卻牒陳攝受衣物。如果牒陳的是白四羯磨中的事，就歸屬於第一種非所收攝。如果就單白羯磨來作，是在「僧時到」前面牒陳說戒，而在「忍聽」後面牒陳自恣。這種情況未必經常發生，但確立此法以供例推明知。例如如今世間所行的割草掘地等召集大眾共同勞作，也稱為僧事，相照於非法而言，兩者是相同的（同屬非法）。

【1644-0002】03_業疏/06b_卷一之六#37
【原文】第二釋非法中初牒釋，此約三法當位自互；若三法交互，即屬初非。「未」下示非相不定。「下」舉世事，即今禪眾用為僧法，此顯非相隨情訛變，不可收盡
【譯文】在第二解釋「非法」的文字中，起初牒引並解釋，這是就三種羯磨法在當前本位中自行錯亂而言；如果三種法彼此跨類交互錯亂，就屬於第一非。「未」字以下顯示過非之相並不固定。「下」舉出世俗事務，即如今禪宗徒眾將日常勞作當作僧事法度，這是顯明非相隨順人情訛謬轉變，無法窮盡收攝。

【1644-0003】03_業疏/06b_卷一之六#38
【原文】應來者不來」下，三別眾相也
【譯文】「應來者不來」以下，是三種別眾之相。

【1644-0004】03_業疏/06b_卷一之六#39
【原文】別眾中初文，三業不和，故分三別
【譯文】在「別眾」的最初文句中，因三業不和合，所以分為三種別眾。

【1644-0005】03_業疏/06b_卷一之六#40
【原文】昔解云：「所言訶者，訶前兩別。」此非正解，不應增三。故《五分》中，上二並同，此第三云：「羯磨時，得訶人不同而強作者，是名別眾。」《十誦》上二亦同，第三云：「現前比丘遮成遮。」此文義俱同，不煩妄解
【譯文】古德解釋說：「這裡所說的抗議，是抗議前面的兩種別眾。」這不是正解，不合於律本〈增三法〉之明文（古德只立兩種，不符律本增三之說）。所以《五分律》中，前兩種都相同，這第三種說：「作羯磨時，有資格抗議的人不同意而僧眾強行作法的，這就稱為別眾。」《十誦律》前兩種也相同，第三種說：「現前比丘若提出阻攔則成為合法阻攔。」這幾部律文義全都相同，毋須多作妄加的解釋。

【1644-0006】03_業疏/06b_卷一之六#41
【原文】次科，古謂訶法在眾非別，但訶前二，故列別中。此下正斥。本律增三云：「佛言有三種和合，謂應來者來等。」反此別眾具三明矣。故下引證，《五分》、《十誦》但云遮訶，明判別眾，可證妄解
【譯文】下一科中，古德認為在僧眾中抗議羯磨法不算別眾，只是抗議前兩種別眾，所以列在別眾之中。此處以下正是嚴加駁斥。本律〈增一犍度〉（增三法）中說：「佛言有三種和合，即應當來的人前來等。」反過來說，別眾具足三種行相就很明確了。所以隨後引用文證，《五分律》、《十誦律》只說阻礙抗議，明確判定為別眾，正可以印證古德是妄加解釋。

【1644-0007】03_業疏/06b_卷一之六#42
【原文】第三「非法和合眾」、第四「如法別眾」，更互相翻，文相可知
【譯文】第三「非法和合眾」與第四「如法別眾」，兩者恰好互相談對翻轉，文句行相容易明了。

【1644-0008】03_業疏/06b_卷一之六#43
【原文】三、四相翻，易故不釋
【譯文】第三與第四種互相翻對，因顯明易懂所以不再解釋。

【1644-0009】03_業疏/06b_卷一之六#44
【原文】第五「法相似」者，誦文無差，但倒作故。若白二、白四互倒，則初非所收。第六「法相似和合」，反上亦同
【譯文】第五「法相似（別眾）」，是指念誦文句沒有差錯，只是顛倒作法的緣故。如果是白二與白四彼此互倒，則由第一非所收攝。第六「法相似和合」，反過來對照上文也是同樣道理。

【1644-0010】03_業疏/06b_卷一之六#45
【原文】五、六二似，亦據當法自倒，又不通單白
【譯文】第五與第六這兩種相似法，也是依據當前法式自身前後顛倒而言，而且不通於單白羯磨。

【1644-0011】03_業疏/06b_卷一之六#46
【原文】第七「訶不止」者，律出其人，不明非體，如法為相，如上明之，註中人解取律意耳
【譯文】第七「訶不止」，律典只指出抗議之人，並未說明過非的自體，它是以如法為行相，如同上文所闡明的那樣；夾注中的諸家解釋，只是擷取律典的深意罷了。

【1644-0012】03_業疏/06b_卷一之六#47
【原文】第七標中，「律出其人」者，但云得訶人訶，故前之六種並依律註，後既闕文，故引人解，即相傳也
【譯文】在第七非的標題中，「律出其人」是指律文只說有資格抗議的人提出抗議，所以前面的六種都依照律文夾注，此處既然闕乏原文，所以引用前人的解釋，這就是歷代相承之說。

【1644-0013】03_業疏/06b_卷一之六#48
【原文】今解此非，位分三別：初、就人辨訶，能訶之人唯是非非；二、就法辨訶，所訶之法通是通非；後、人法合明者，若非人來訶，去即是是，住即是非；如人來訶，住即是是，去即是非。其相並如上有人得滿訶中所說
【譯文】如今我解釋這種過非，品位分為三種差別：第一、就人來辨明抗議，能抗議之人唯獨是如法之人而非過非之人；第二、就法來辨明抗議，所抗議的法通於如法與非法；最後、人與法合併說明：如果是不合格的人前來抗議，僧眾繼續進行羯磨便是如法，止住不作便是過非；如果是如法之人前來抗議，僧眾止住不作便是如法，繼續進行便是過非。這些行相全都如同上文在「有人得滿訶」中所說的一樣。

【1644-0014】03_業疏/06b_卷一之六#49
【原文】釋中初科三位：初人唯是，即善比丘；二法通是非；三合明中，「非人」者，即前所簡不得訶人，「去、住」即約秉法止、不止也。「如人訶」者，準前四句，二人得訶，然今且據後善比丘，故下但指第四句耳
【譯文】解釋中的初科分為三位：第一、僧人唯獨如法，即指良善比丘；第二、法通於如法與非法；第三、合併說明中，所謂「非人」，就是前面所揀除無資格抗議之人，「去、住」就是指秉持羯磨的停止與不停止。所謂「如法人抗議」，依照前面的四句分別，有兩類人有資格抗議，然而現在暫且依據後面的善比丘，所以下文只指涉第四句而已。

【1644-0015】03_業疏/06b_卷一之六#50
【原文】母論》云：「應止羯磨者，比丘皆集，但所作非法，眾中持律行淨者說言：『此非法非律，是不應作。』即止不作，是名止羯磨。不應止者，所作如法，無說嫌者，不應止也
【譯文】《毗尼母論》說：「應當停止羯磨的情況：比丘全都到齊和集，但所作之法違背教法，大眾中持律且梵行清淨之人發言說：『這不是正法、不是戒律，這是不應當作的。』僧眾隨即停止不作，這就稱為停止羯磨。不應當停止的情況：所作之法合乎教法，無人提出嫌責，就不應當停止。」

【1644-0016】03_業疏/06b_卷一之六#51
【原文】次引文中，《母論》有二：前明應止，持律行淨即得訶人，「說言」等者即訶止之訶；後明不應止，即如法也
【譯文】在隨後引用的文中，《毗尼母論》分為兩段：前半段說明應當停止，持律行淨就是有資格抗議的人，「說言」等句就是抗議使其止息的抗議之詞；後半段說明不應當停止，就是指羯磨如法的情形。

【1644-0017】03_業疏/06b_卷一之六#52
【原文】五分》云：「若羯磨時，得訶人不同者不成，強作犯吉。隔障訶者不成訶
【譯文】《五分律》說：「如果在作羯磨時，有資格抗議的人不同意，羯磨便不能成就，強行作法者犯突吉羅。有屏障隔開而抗議者，不能構成有效的抗議。」

【1644-0018】03_業疏/06b_卷一之六#53
【原文】五分》「不同」即心不和，「強作犯吉」即訶不止，「隔障不成」以非數故
【譯文】《五分律》中的「不同」就是指心意不和合，「強作犯吉」就是指遭到抗議依然不停息，「隔障不成」是因為身在僧數之外的緣故。

【1644-0019】03_業疏/06b_卷一之六#54
【原文】四分》中，約身坐處結小界，為遮訶人，界外不成故
【譯文】《四分律》中，依照身體所坐之處結定小界，是為了隔開抗議之人，因為在界外抗議不能成立的緣故。

【1644-0020】03_業疏/06b_卷一之六#55
【原文】四分》即準小界反顯同界成訶
【譯文】《四分律》即是依準小界反面顯明：若在同一結界內，抗議便告成立。
