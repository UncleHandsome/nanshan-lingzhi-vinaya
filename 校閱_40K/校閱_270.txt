# 校閱材料　第270檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【270-0001】資持記/08b_中二#42
【原文】〔作句竝同前具出如別。〕四即奪失。五謂燒漂，故注顯之。灼即燒也。六中轉作㡌袜，不入長故。第八。注中，初句總標；次二句別釋，後句例開。貿易中，初文。以律言通，容彼異解，故須決正。次科，初二句出古解。彼謂貿得新衣，為前衣染犯，故尼薩耆。不合箸用，故突吉羅。論下，引斥；
【譯文】〔造句的方式全都與前面相同，完整內容另有詳文。〕第四門就是被搶奪或遺失。第五門是指燒毀或漂沒，所以用注文予以顯明。「灼」就是燒灼的意思。第六門中改製為帽子、襪子，不再算入長衣之列。第八門。注文中，第一句為總括標明；接下來兩句為分別解釋，最後一句為例行開許。在貿易衣物中，第一段文字：因為律文措辭較寬泛，容易產生不同的理解，所以必須決斷端正。下一科判，前兩句引出古德的解釋。他們認為換得的新衣，會被先前的長衣染污而犯戒，所以犯尼薩耆罪。因為不合規矩穿用，所以犯突吉羅罪。「論」字以下，引述論部予以斥責；

【270-0002】資持記/08b_中二#43
【原文】文有二段，初明捨懺。後雖更改，皆從本犯。應及不應，二種相別。〔上是因引，下文正用。〕二衣即應量不應量，下同。二若下，正明貿易。文明後衣不懺不捨，頗見昔非。已入淨者，新衣無染，應淨法故。三中，初明一提。準上論云：懺先罪故。次判一吉。下引律證，文制不應，違教結吉明矣。
【譯文】文中有兩個段落：首先說明捨衣懺悔。事後雖然變更更換，都要依循最初的違犯定罪。應量與不應量，兩者相貌有所不同。〔上面是順帶引述，下文才是正式應用。〕「二衣」就是指應量衣與不應量衣，下文同此。第二「若」字以下，正式說明貿易之事。文中說明後來的衣服不需懺悔也不需捨棄，很能看出古德說法的謬誤。已經作過說淨的，新衣不會被染污，因為符合清淨法度的緣故。第三段中，首先說明犯一個單提罪。依照上文論部所說：是為了懺悔先前的罪過。其次判定犯一個吉羅罪。下文引述律文證明，文中限制不合規定，違背教法而結吉羅罪便非常明瞭了。

【270-0003】資持記/08b_中二#44
【原文】不犯中，初科。即前八門二三兩位。下明奪失燒漂，同前四五；餘略不出。次異想中。言奪等者，律列四想；此但明奪，餘三下指同。本律但開不犯，不明更開，故引《十誦》決之。三中，初文。四緣開者，前據虛想，此約實失，故注以簡之。問：若實奪失，何容後得耶？答：奪失水漂，皆可再獲；
【譯文】不犯條款中，第一科。就是前面八門中的第二、第三兩種層次。下文說明奪失、燒毀、漂沒，同於前面的第四、第五門；其餘的省略未列出。接下來「作其他想」中，所謂「奪等」，律中列出四種心想；這裡只列出奪想，其餘三種下文指出與此相同。本宗律典只開許不犯本罪，並未說明是否進一步開許，所以引述《十誦律》來作決斷。第三項中，第一段文字。這四種緣由得以開許，前面是依據虛妄的懸想，這裡是依據實際的損失，所以用注文加以簡別。有人問：如果實際被搶奪或遺失，怎麼可能日後重新獲得呢？回答說：被搶奪、遺失或被水漂走，都有可能重新尋回；

【270-0004】資持記/08b_中二#45
【原文】燒有餘殘，義亦無爽。注文末句，因點受持；由奪等緣，失本受法；後得重加，義在離衣，緣同因示。次科為三，初牒釋。言取著者，謂有犯捨三衣，由失正衣，即無長過，可取著用，故列不犯。注釋頗詳。《伽論》下，次引證。過十日衣即犯長者。意以有犯必無離宿，故設此問。
【譯文】燒毀而有殘餘剩料，在義理上也是講得通的。注文最後一句，順帶點明受持之事；由於搶奪等緣故，失去了原有的受持法度；後來重新獲得時必須重新加受，箇中義理在於離衣戒中，因為緣由相同所以順帶指出。下一科判分為三部分：首先牒述解釋。所謂「取著」，是指原本有犯捨墮的三衣，由於失去了正法衣，便不再具有長衣之過，可以取來穿著使用，所以列入不犯條款。注文解釋得相當詳盡。《伽論》以下，其次引述證明。超過十天的衣物就犯長衣過失。意思是既然已有犯長過失，離宿時必定不犯離衣宿夜罪，所以設立此問。

【270-0005】資持記/08b_中二#46
【原文】答中可證加受得成。何下，三釋妨。指前云者，即貿易中；彼言不得，故須通會。答中，初句釋通前文；今下，正顯今意。色猶數也。下引二文，色體不如，並許加受，足為今例。問：為開暫時，為得求作？答：文似暫開，不妨永用。今以義判，或有可別求，卒營未及，暫用彌善；
【譯文】回答中可以證明加持受法是能夠成就的。「何」字以下，第三解答疑難。指稱前文所說的，就是指貿易衣物那一節；那裡說不能穿用，所以必須融會貫通。回答中，第一句解釋通曉前文；「今」字以下，正式顯明現今的意圖。「色」好比數目。下文引述兩段文字，色澤本質縱使不如法，都允許加受，足以作為現在的例證。有人問：究竟是暫時開許，還是允許正式尋求裁製？回答說：經文看似暫時開許，但也不妨礙永久穿用。現在依義理判定，若有別的法衣可尋求，臨時縫製不及時，暫時穿用最為妥當；

【270-0006】資持記/08b_中二#47
【原文】或守己少欲，趣足被形義通久永。《善見》五大，通收正間。《僧祇》俗衣，彼因借被作淨安紐故。四中。注云重物者，以用重故；準知入淨方有長過，被褥說淨，諸律無文，故云未見等。下引《十誦》，僧別得受；但得受用，不明說淨。五中。付衣者，律作受付囑衣者，即所囑藏舉人也。
【譯文】或者抱持安貧少欲之心，只要能遮蔽身體便心滿意足，在義理上通於長久穿用。《善見律》中的五大衣，通括正色與間色。《僧祇律》中的俗家衣服，那是因為借俗衣披著，作淨施並縫上繫帶紐扣的緣故。第四項中。注中說「重物」，是因為使用上屬於厚重之物；由此可知列入說淨才有長衣過失，對於被褥作說淨，各部律典並無明文，所以說「未曾見過等」。下文引述《十誦律》，僧團公物與個別僧人皆可受用；但只是允許受用，並未說明要作說淨。第五項中。「付衣」者，律文寫作「受囑託衣服的人」，也就是替人收藏保管物品的人。

【270-0007】資持記/08b_中二#48
【原文】水陸等者，此並人衣隔絕，不及故開；例餘緣阻通入不犯，故云等也。第二。〔佛在舍衛，六群持衣寄親厚，往人間遊行，故制。〕名中。三衣簡餘衣，宿者結犯限分。列緣中。第三通收四礙，如後具釋。第四有緣不及，律開遙捨，或復奔會，二皆無犯；非此則為犯緣。
【譯文】所謂「水陸等」，這些都是因為人與衣服隔絕分離，時間上來不及，所以予以開許；其餘因故受阻的情況依此類推都歸入不犯，所以用「等」字概括。第二條戒。〔佛在舍衛國時，六群比丘把三衣寄放在親近好友處，自己前往人間遊行，佛陀因此制戒。〕戒名中。「三衣」是簡別其餘衣服，「宿」是結罪犯戒的界限時間。列出犯緣中，第三項通體收攝四種阻礙，如後文詳細解釋。第四項因故來不及，律中開許遙遠捨衣，或者奔馳前去會合，這兩種都算不犯；如果不屬於這兩種情況，就構成了犯緣。

【270-0008】資持記/08b_中二#49
【原文】第五，下列七緣，通入開位。釋第一中，初文，先示罪相。五衣者，附明尼制；祇支，覆肩，皆入制故。非下，釋上餘衣，初正釋。長下，點古。波謂餘衣言通長物，離亦吉故。約根中。前二並受，罪重輕者，制聽別故。後二皆聽，罪有無者，法分受淨，物屬自他故。下指《戒疏》，見離衣戒。二中。
【譯文】第五項，下列七種緣由，都歸入開許的層次。解釋第一項中，第一段文字，先明示罪名相狀。「五衣」是附帶說明比丘尼的戒制；因為僧祇支、覆肩衣，都列入了制戒範圍。「非」字以下，解釋上文的其餘衣服，首先正面解釋。「長」字以下，點評古德之說。彼古德認為其餘衣服言詞通於一切長物，離宿也結吉羅罪。在約根機解釋的一段中：前兩種（三衣與百一衣）都是正式加受的衣物，罪名之所以有重有輕，是因為制衣與聽衣的規定不同。後二種都是聽許蓄積的衣物，罪名的有無，是因為法度上區分為加受與說淨、物權屬於自己還是他人。下文指引參閱《戒疏》，可見於離衣戒。第二項中。

【270-0032】資持記/08c_中二#11
【原文】答：《戒疏》有三釋：一有法故無，無法故有。二自然內外俱是無法，作法內是有法，外則無法。三自然是本制故開，作法是開，故不復開。《僧祇》中，初科，文有六開，初開借道眾長衣加受。準應遙捨本衣。無下，次開借俗物。作淨，謂點壞也。又下，三開奔還門外。
【譯文】答：《戒本疏》有三種解釋：第一，已有羯磨作法之界，便無需自然勢分；沒有作法界限的，才有自然勢分。第二，自然界的外內兩側都不依作法；而作法界的內部已有作法力量，外部則完全沒有法力相及。第三，自然界是本律原始制定的基礎，所以開許勢分；作法界本身就已經是一種開許變通，所以不再額外開許。《摩訶僧祇律》中，第一段科文共有六項開許：第一項，開許向僧眾借取多餘的長衣加入受持。依照常理，應當在遠處捨棄自己原本的衣服。「沒有……」以下，第二項開許借用俗人的器物。所謂「作淨」，是指在衣物上作點記以破壞其完好完整性。「又……」以下，第三項開許奔逃回到寺院大門之外。
