# 校閱材料　第1133檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1133-0001】資持記/08b_中二#4
【原文】望父違恩養，望羅漢損福田故。次例，即《多論》，將口三過互織辨犯，如小妄中委引，彼云：傳他此語向彼說，以不實故是妄語，作分離心故名兩舌。此並一境兩犯，足為前例。餘下，指廣。彼問云：元謗望僧治，何因言了，結？答：能謗意在治，治擯唯僧力；遂瞋暢思決，言了便成犯。列緣中。第二緣。
【譯文】這是因為對父親違背了撫育之恩，對阿羅漢則損壞了世間福田。第二個例子，出自《薩婆多論》，將口業四過中的三種交織辨析犯相，正如在小妄語戒中詳細引用的那樣。論中說：輾轉將此人的話向那人述說，因話不真實所以是妄語，心存離間之意所以又叫兩舌。這都是屬於面對同一境遇而兼犯兩罪的情況，足可作為前文的例證。其餘文字是指引參閱更廣的論述。那裡發問說：原本誣謗是期望僧團予以處罰，為什麼說完這句話就算結罪？回答說：誣謗者的意圖在於借僧團治罪，但處罰擯黜全憑僧團之力；既然嗔恨之心宣洩已畢，話音剛落便已構成犯罪。在列出犯緣中，第二個犯緣：

【1133-0002】資持記/08b_中二#5
【原文】準疏古解有二。初約體淨，彼據戒本非波羅夷為證。次師約想淨，即如鈔引；文中，初出彼所立；故下，準疏是今師引破；彼云：無餘是重，作是曾犯。是則明知有犯，亦成謗罪，豈須想淨耶！今師但據自無三根，不論彼境淨穢；循古引示，而非所取，故別立第二。
【譯文】依照律疏，古德的解釋有兩種：第一種是從對象本體清淨來論，依據是戒本中明言「非波羅夷罪」作為證明。第二位律師則從主觀認定其清淨來論，就如《行事鈔》所引用的；文中首先列出該師的主張；「故」字以下，依照律疏是今師引述來予以駁斥；《戒本疏》中說：無餘罪是重罪，這樣做就是曾有犯戒行為。由此可知明知對方有犯，說出來也構成誣謗罪，哪裡需要主觀認定其清淨呢！今師只依據自己並無見、聞、疑三根作為依據，不論對象境緣是否清淨；引述古說只是順帶展示，並非所採納的觀點，所以另外確立了第二個犯緣。

【1133-0003】資持記/08b_中二#6
【原文】八前人知者，但取所對，不必所謗。釋中。論明謗者強戾，僧折伏法。初教僧詳緩。若下，出彼請判。論具云：若言眾僧為我判此罪莫停；若是者，我當受持；若不是，我不受。〔受即執也，此是兩向求斷之語。〕僧下，示折伏法有三，初教遷延。暝即暗也。猶下，次令出界。如是覓寺下，後明為斷。懦，柔弱也。
【譯文】第八項「對方知曉」，只針對說話的對象而言，不一定是被誣謗的人。解釋文中，論部說明誣謗者態度強橫暴戾時，僧團用以折伏的方法。首先教導僧眾要審慎寬緩。「若」字以下，說明對方請求裁斷的話語。論中完整說道：如果對方說「請大眾僧為我判斷這項罪名，不要拖延；如果是真的，我應當承受；如果不是，我就不接受。」〔接受就是堅持認同，這是兩頭逼迫求斷的話語。〕「僧」字以下，指示折伏的方法有三種：首先教導拖延時間。「暝」就是天色昏暗。「猶」字以下，其次是命令他移出結界。「如是覓寺」以下，最後說明為他裁斷。「懦」是指性格柔弱。

【1133-0004】資持記/08b_中二#7
【原文】不犯中，初通示。實有下，別簡五實。具五成開，闕一成犯。第二約心，餘皆約境。真實者，字誤；準疏作真境實，謂所對不謬也。想實者，想心謂不淨也。若下，總結。論開須具五實，反犯止在一虛。後引二律。別證第五，縱知實犯，互亦成謗。第九。〔慈地因見羊行淫，便言羝羊如沓婆，母羊如慈地尼；向諸比丘，我今親見，非前無根，因此而制也。〕
【譯文】不犯條款中，首先作普遍說明。「實有」以下，分別挑選出五種真實情況。具備這五種便構成開緣，缺少一種便構成犯戒。第二項是依據內心，其餘各項都是依據境緣。「真實」二字有傳抄錯誤，依據律疏應作「真境實」，意思是所面對的對象並無錯誤。「想實」是指心裡認定對方並不清淨。「若」字以下作總結。依論而言開緣必須具備五種真實，反過來說犯戒只要在一項上虛妄即可。後面引述兩部律典，特別證明第五項，即使明知對方確實犯戒，彼此互換情節舉發也同樣構成誣謗。第九條戒。〔慈地比丘因為看見公羊與母羊行淫，便說這隻公羊好比沓婆，母羊好比慈地比丘尼；他向諸位比丘說，我現在親眼看見，絕非先前那樣無憑無據，佛陀因此而制定此戒。〕

【1133-0005】資持記/08b_中二#8
【原文】辨異中，初示相。異事即見羊淫，此事謂比同人犯。疏云：若異事見，向僧道聞；便是無根，落在前戒；餘根準此。事不下顯名。假謂詐託別事，意表有根；如下五異，俱名假也。釋中，指緣如上。須知第四假根有別。次科中。初如緣起說；二謂見犯下聚，以初聚謗；
【譯文】在辨析差異中，首先指示相狀。「異事」是指看見羊行淫，「此事」是指附會為人犯淫。律疏說：如果看見其他事件，卻向僧眾聲稱是聽來的，這就是無根，落入前一條戒中；其餘見聞疑三根依此類推。「事不」以下彰顯戒名。「假」是指詐偽託詞於別的事情，表面上表示有所依據；如同下文列出的五種相異情況，都稱之為假。解釋文中，指出犯緣如同前文。必須知道第四種假根有所不同。下一科判中：第一種就如緣起所說；第二種是指看見對方犯了下篇之罪，卻用初篇的重罪去誣謗；

【1133-0006】資持記/08b_中二#9
【原文】三謂餘人與所謗者名姓相同，以彼所犯用謗此人；四即本在俗時曾作重過，今用加舉；五謂自語聞彼響聲，言作淫盜等。上四義通三根，後一唯局聞疑。言下，論釋甚顯。三指略者。《注戒》云：辨相開通，並同前故。第十。〔佛在羅閱祇，提婆教人害佛，惡名流布，利養斷絕，便別眾食，為佛訶責；因即破僧，舉過設諫，因制。〕
【譯文】第三種是指別人與被謗者同名同姓，拿那人的罪過來誣謗這個人；第四種是指本來在俗家時曾犯過重罪，現在拿來加諸其身舉發；第五種是指自己說話時聽到對方的迴聲，便聲稱對方在行淫、偷盜等。前面四種情況在義理上通於見、聞、疑三根，最後一種只局限於聞根與疑根。「言」字以下，論中的解釋非常明顯。第三項省略說明的內容，《戒本注》說：辨析相狀與開遮通融之處，都和前面相同。第十條戒。〔佛在羅閱祇城時，提婆達多教唆他人謀害佛陀，惡名流傳四方，利養斷絕，便在僧團之外別眾受食，受到佛陀呵責；隨後便破壞僧團，佛陀舉出過失設法勸諫，因此制戒。〕

【1133-0007】資持記/08b_中二#10
【原文】戒名中。破僧有二，一立五法化世，破四依八正，名破法輪僧。二同界各作眾法，名破羯磨僧。僧作白四法諫，三諫不捨，犯殘；餘三戒竝爾。總示中，初科，前列五諫，初二句總舉。此違諫者，即當篇四戒。逮下篇者，即單提中有一，寄此預明。或下，別釋，初明三戒。
【譯文】在戒名中，破僧有兩種情況：一是設立五種苦行法度化世人，破壞四依止與八正道，稱為「破法輪僧」；二是在同一結界內各自舉行僧團法事，稱為「破羯磨僧」。僧團行白四羯磨進行勸諫，經三次勸諫仍不捨棄，便犯僧殘罪；其餘三條諫戒也是如此。總體說明中，第一科先前列出五種諫戒，前兩句是總體提出。這裡的「違諫者」是指本篇中的四條戒。「逮下篇者」是指單墮篇中有一條，寄託在此處預先說明。「或」字以下進行分別解釋，首先說明三條戒。

【1133-0008】資持記/08b_中二#11
【原文】如注所列。謗僧即污家，拒僧即惡性。事希謂過非常有，法隱即羯磨不行。或但下，明二戒。有二意：因不辦果者，閻浮一化，唯提婆一人破僧究竟；餘但方便故；局佛在者，以佛滅後，無可競化故。若破羯磨僧，容有至果，復通滅後；然今論犯，須具二破；正取法輪為所諫耳。
【譯文】如同注文中所列出的：誣謗僧眾就是「污家」，抗拒僧眾就是「惡性」。「事希」是指這種過失非尋常所有，「法隱」是指羯磨法不能推行。「或但」以下，說明兩條戒的情況。這有兩種含意：從因位不能成就果位來說，閻浮提一期的教化中，只有提婆達多一人究竟完成了破僧；其他人只算方便未遂罷了；局限於佛在世之時，是因為佛滅度之後，再無人可以與佛競相宣化。如果是破羯磨僧，則有可能達成結果，並且通於佛滅度之後；然而現在論斷犯戒，必須具備這兩種破僧；此處正取破法輪僧作為勸諫的對象。
