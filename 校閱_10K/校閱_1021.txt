# 校閱材料　第1021檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1021-0001】資持記/04d_上三#45
【原文】依師本意，檢過策勤。五並不知，師義安在；去非就道，固其宜矣。釋難中。前七法中，弟子於師訶責犯殘，並須經理；有疑惡見，復須諫正。此明捨去，故須和會。正答，可解。引示中，前明受諫。若師下，明拒諫。依前二師者，和尚遠去，依止出界。七失師法，列示中，初明和尚無失。
【譯文】依止師長的本意，是為了檢察過失並策勉精進。五種法意全然不知，為師的道義又體現在哪裡；離棄非道而趨向正道，本來就是理所應當的。在「解答難題」（釋難）中，前面七法之中，弟子對於師長若受訶責或犯僧殘罪，都必須代為照料打理；師長有疑惑或惡見，又必須諫正使其回歸正軌。此處說明捨棄離去，所以必須加以調解融通。正面回答文意容易明白。在「引證指示」（引示）中，前半段說明接受規諫。「若師」以下，說明師長拒絕規諫。「依照前文二師之法」，是指和尚遠去，依止阿闍梨出界。第七「失去師資關係之法」（失師法），在「列舉明示」（列示）中，開頭說明和尚不會失去師徒實質關係。

【1021-0002】資持記/04d_上三#46
【原文】無德依他者，但可捨去，相依仍在。以下，示無失所以。初受期心，盡壽親附；不同依止，容有再請故也。二明依止有失。若論依止，但有請法；義分三種，故云詳正。若失請法，則須重加；若失下二，起心而已，如後所明。互治中二，前明師被治中復二，初定失法。
【譯文】「無德而依止他人」，弟子只不過可以捨離而去，彼此互為依怙的名分依然存在。「以」字以下，說明不失去的緣由。最初受戒時結下依止期約的心念，是一生都要親近依附的；這不同於依止阿闍梨，容許有再次請受的可能。第二部分說明依止師會失去師徒法相。若單論依止，原本只有請受戒法這一項；在義理上劃分為三種法，所以說是「詳加審定考正」。如果失去了請受依止的根本法，就必須重新舉行請受儀式；若是失去了後面的兩種心念，只要重新發起相依之心即可，如同後文所說明的那樣。在「彼此受懲治」（互治）中分為兩部分，前半段說明師長被僧團懲治，其中又分為兩小節，開頭判定所失之依止法。

【1021-0003】資持記/04d_上三#47
【原文】《律》云：和尚闍梨，僧與作訶責擯出依止遮不至白衣家作舉，佛言不失依止〔弟子亦同〕。今以義約，即不失上二也。〔舊云三舉失下二者，非也。〕以師下，釋失所以。言得罪者，若輒教誡，則違行法，一一吉羅。以奪下，轉釋得罪。不得依止，即奪眷屬也。若下，次明弟子被治，三皆不失。
【譯文】《律》中說：和尚阿闍梨，僧團為其作訶責、擯出、依止、遮不至白衣家、作舉等懲治羯磨時，佛陀說不失去依止關係（弟子受懲治時也是如此）。如今依據義理加以限定，就是指不失去上述前兩種法（請法與心依）（古人說三種舉罪會失去後兩種法，是不對的）。「以師」以下，解釋失去的緣由。所謂「招致得罪」，是指若擅自進行教導誡勉，就違背了懲治的行法，每一項皆犯突吉羅罪。「以奪」以下，進一步解釋得罪的原因。「不得受人依止」，就是剝奪其受徒眾眷屬依附的權利。「若」字以下，次一步說明弟子受到懲治時，三種法全都不會失去。

【1021-0004】資持記/04d_上三#48
【原文】開無隨順者，合眾同治，餘人隨順，並制吉羅，師獨開之。〔不同隨舉，彼局惡見犯提故。〕互出界中，初牒文。《律》云：和尚闍梨決意出界去不還，而即日還；佛言，此失依止〔弟子亦同〕。失下，次義決。不失請者，不越宿故。言但生者，謂起意也。請法謂求教授。
【譯文】開許不必斷絕隨順往來，是因為全體大眾共同予以治罪，其餘僧人若是隨順親近，全都依律判定犯突吉羅罪，唯獨開許其師長不必斷絕隨順（這不同於隨順被舉罪者，那是侷限於執持惡見者，犯波逸提罪）。在「彼此出界」（互出界）中，開頭引用經文。《律》中說：和尚阿闍梨下定決心越過界外離去不再回來，然而當天就返回；佛陀說，這便失去了依止關係（弟子也是如此）。「失」字以下，次一步從義理判定。不失去請法依止，是因為未曾經過一夜。「但生起」，是指內心起意。「請法」，是指祈求教授佛法。

【1021-0005】資持記/04d_上三#49
【原文】《律》約即還，故云決意；若論隔宿，不問決與不決，三法俱失。指《大疏》者，古記引云：師徒決意出界心隔，雖即日還，便失依止者〔謂失下二〕；若爾，離衣破夏，何待經宿？答：師徒各有兩捨之心故失，人有離衣處心，衣處無離人意，故須經宿；
【譯文】《律》是就當天返回而言，所以才說「下定決心」；若是就隔了一夜來說，不論決心離去還是沒有決心，三種法全都失去。指引《大疏》之處，古代注記引述說：師徒下定決心越界離去而心生隔閡，即使當天就返回，便失去了依止關係（這是指失去了後兩種心）；如果是這樣，離開戒衣與破壞夏安居，為何一定要經過一夜？回答：師徒雙方各自抱持著互相捨離之心，所以才失去；人雖有離開衣物所在處所的心念，但存放衣物之處並沒有離開人的心意，所以必須經過一夜；

【1021-0006】資持記/04d_上三#50
【原文】又衣夏約明相論失，依止約心約界明失，故不同也。通列中。《律》文前後總括有九。第四犯重者，《律》云：和尚闍梨，僧為作滅擯，佛言失依止〔弟子亦同〕。五如上引，通七羯磨，且舉訶責。餘七種，即出〈受戒犍度〉八五句中，對文可見。
【譯文】再者，離衣與破夏是依據黎明破曉的天色（明相）來論定失去，依止法則是依據內心意念與地理界線來明示失去，所以兩者並不相同。在「通括列舉」（通列）中。《律》文的前前後後總括歸納共有九種情況。第四種「犯重罪」，《律》中說：和尚阿闍梨，僧團為其作滅擯羯磨驅逐，佛陀說失去依止關係（弟子被滅擯也是如此）。第五種如同上文所引，通貫於七種羯磨處分，暫且列舉訶責羯磨為例。其餘七種，就是出自〈受戒犍度〉的八組「五句」之中，比對經文即可明瞭。

【1021-0007】資持記/04d_上三#51
【原文】彼云有五法失依止〔一師訶責，二去，三休道，四不與依止，五入戒場上。〕，復有五事〔一死，二去，三休道，四不與依止，五若五歲若過五歲。〕，復有五事〔五見本和上，四句同前，唯第五別，自下並爾。
【譯文】那裡說有五種法會失去依止（一是師長訶責，二是離去，三是捨道還俗，四是不給予依止，五是進入戒場內）。又有五件事（一是死亡，二是離去，三是捨道還俗，四是不給予依止，五是滿五歲或超過五歲）。又有五件事（第五句是見到本受和尚，前面四句與前文相同，唯獨第五句不同，自此以下全都是這樣）。

【1021-0008】資持記/04d_上三#52
【原文】復有五事〔五和上闍梨休道〕，復有五事〔五弟子休道〕，復有五事〔五和上闍梨命終〕，復有五事〔五弟子命終〕，復有五事〔五還在和上目下住〕。第二第六，必約經宿；若即日還，如上所判；第八謂師先遠去，弟子別求依止；後見本師，還復依學，彼法即失。
【譯文】又有五件事（第五句是和尚阿闍梨捨道還俗）。又有五件事（第五句是弟子捨道還俗）。又有五件事（第五句是和尚阿闍梨命終）。又有五件事（第五句是弟子命終）。又有五件事（第五句是重新回到和尚眼下同住）。第二種與第六種情況，必定是以經過一夜為準；若是當天返回，就如上文所判定的那樣；第八種是指師長先前遠行離去，弟子另行尋求他人依止；後來又見到了本師，重新回歸依止修學，後請受的依止之法隨即失效。

【1021-0009】資持記/04d_上三#53
【原文】第九亦爾，但約弟子離師後還為異。準《律》上六通於師資，下三唯局弟子。言約教失者，別點第七；且約教限，若就行論，法身成立，方離依止，如上所明。問：訶責約教，明言不失？答：上準奪行，亦即是教。問：遠去訶責，即上二門，何須重示？答：遠去即還，《律》文判失，而義有不失；
【譯文】第九種也是如此，只是換成弟子離開師長之後又重新返回為差別。依照《律》文，上面六種通於師長與弟子雙方，下面三種則唯獨侷限在弟子身上。所謂「依從戒法規定而失去」（約教失），特別點出第七種；暫且是就教法的年限規範而言，若就個人的實際行持來論，必須等到戒法之身成熟確立，才能真正脫離依止，就如前文所說明的那樣。問：訶責懲處依據教法規定，明言說「不失去依止」？回答：上文比照剝奪行持權利來論，其實這也就是教法的規定。問：遠行離去與受到訶責，就是上面探討過的兩門，何必在此重新提示？回答：遠行離去而當天返回，《律》文明定判定為失去，然而在義理上卻有不失去的層面；
