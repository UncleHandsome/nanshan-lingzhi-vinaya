# 校閱材料　第680檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】有人問：傳授學戒六法時，是在眾僧面前當面傳授，還是遙隔一段距離傳授？回答是：各大律部規定不同，現今依照《四分律》，應當讓這位沙彌尼步入眾僧之中，向大眾僧誠懇乞請三次，乞戒完成後，她應當走到「肉眼看得見、耳朵聽不到」的規定位置站立，然後比丘尼僧團正式作羯磨傳授；依照這部《四分律》的規矩，隔開距離遙相授戒是可以成立的；若是依照《十誦律》，則要求必須留在僧眾之中當面受戒；這純屬各部派制度不同，絕對不可雜亂混用，既然宗奉本律自行修行，就不能捨棄本部的規範去盲從他宗。有人問：學戒若不滿兩整年，受比丘尼戒時能得到戒體嗎？回答是：絕對得不到戒體。從何處得知呢？例如受持六法眼看將滿兩年，只要隨便毀犯了一條戒，就必須重頭再給予兩年學戒，由此嚴格規定便確知不滿兩年是絕不可能得戒的。而且《僧祇律》明文記載：如果比丘尼為學戒未滿兩年者傳授具足戒，戒師要結犯波逸提罪，可見學戒必須徹底滿兩整年才行；《十誦律》解釋說：設立六法是為了陶冶磨礪內在心地，試驗觀察她是否堪能承受比丘尼大戒的崇高緣起，規定兩年時間是為了考察磨礪其肉身外相，試驗觀察她是否在俗世懷有身孕，所以臨近受具足戒時，大眾必須當面審查詢問：「是否已經學滿兩年六法？」《五分律》等各派羯磨文中，也都明確標明「二年學戒期滿」。義理上沉痛指出：現今時代有許多毫無見識的盲昧之人，公然答應那些學戒不滿兩年的女眾，草率為她們傳授比丘尼大戒！如果不滿年限也能得戒，為什麼《僧祇律》、《十誦律》、《五分律》等都一致判定傳戒師長要結犯大罪呢？又為什麼《五分律》等所有羯磨文中都明載「年限已滿」的定句？如今傳戒師長與在場大眾明明都知道未滿年限，卻公然違背佛陀聖教，在法會上公然妄稱說「已經期滿」，這種僧事原本就違背戒法，所秉羯磨怎麼可能成就？若是嚴格依律令其學滿兩年，便可確鑿無疑斷定其必得戒體；如果任憑凡夫情執妄自傳授，萬一根本無法感得戒體，豈不是耽誤了他人一生的出家道業、白白虛度光陰，乃至招致累劫受罪的可怕後果？既然沒有國難等急難逼迫，有什麼好慌亂急迫的，非要強行違背佛陀聖意，硬逼著她們提前受戒？有的人甚至妄引其他律文曲解說：經中說連十戒都未曾受過的人有時尚能開許受具成立，比照這個道理，不滿兩年又何嘗不可開許？這種狡辯完全是錯誤的：那些未受十戒而成的特例，是屬於佛陀因特殊因緣而宣說的「開許通則」，律中有明確聖文為據；而此處兩年學戒，則是佛陀嚴格制定的「禁止死法」，聖教明令禁止違犯；「開許」與「禁止」是完全相反的兩回事，如何能夠混為一談、胡亂比附？六法屬於硬性制令，絕對不可不遵行；十戒在特定因緣下的開許，則無違順逆法理。這類拿開制相反的教條強詞奪理，其法義高低懸殊如同天壤之別；這不僅僅是妄自判斷法理的過錯、徹底暴露出自身的愚昧無知，更是草率盲目授戒的大罪過，禍患必將殃及自己與受戒者雙方啊！本律明確警示：如果戒師不知如法得戒的真正標準，盲目造作非法之舉而傳授學戒，屬於違犯佛制之罪。如果這個女子以前曾經結過婚，只要年滿十歲以上，便可以為她傳授為期兩年的學法，而不必等到滿十八歲。有人問：為什麼年紀幼小而曾結過婚的童女，就可以提早傳授六法？回答是：《薩婆多論》解釋說：已婚女子到了十二歲便可以受具足戒，因為她們長期在夫家被使喚勞動，飽經滄桑，經歷並忍受了世間的種種辛酸苦楚，更加厭離世俗凡情，心智與意志早已經堅定成熟；《僧祇律》也是持同樣的看法。義理上指出：式叉摩那平時不能單獨與大比丘尼結伴而行，因為她的大戒尚未圓滿；自然也不能單獨與沙彌結伴，因為彼此性別不同、非屬同類。如果是一位大比丘尼帶同一位式叉摩那，或者是兩位式叉摩那帶同一位沙彌尼，就可以互相作為同伴共同行走，除此之外其餘搭配都是不合法的。《沙彌尼雜戒文》說：不能與在家優婆夷互相比量觀看裸露的身體或放聲大笑；又不可在僻靜幽暗之處赤裸身軀、撫弄自己的身體；也不得照鏡子梳妝、塗抹面容、畫眉描眼。跟隨師長學習經典時，應當隨同長老尼一起前往；距離講席六尺之外長跪合掌，請教經義時應當清楚明白文句語調的起承轉合；如果遭到師長嚴肅呵責，應當立刻至誠認錯悔改，絕對不可隱瞞罪咎，不可自尋藉口強詞奪理，更不可用凶惡的眼神怒視師長等等。

【680-0009】04_比丘尼鈔/01b_卷上之上#90
【原文】此篇大門有二一畜意二制乞。
【譯文】本篇大綱分為兩個部分：第一是蓄收徒眾的心態與限制，第二是制令必須向僧團乞求。

【680-0010】04_比丘尼鈔/01b_卷上之上#91
【原文】第一畜意者此律云尼十二歲欲度人受具足戒者應白二羯磨請僧聽許已然後得度否者犯提若受他依止式叉尼等犯吉羅若和尚尼無德僧止其度人捨畜眾羯磨若得羯磨已一年中得一大尼一六法尼一沙彌尼一依止人更不得多隔一年已更欲度者還如前法與衣食及法更不須重與羯磨。
【譯文】第一部分「蓄收徒眾的心態與限制」：本律規定：比丘尼受具足戒滿十二夏以上，若想要度化他人受具足戒，應當先在僧團中作「白二羯磨」，請求全體大眾僧聽許，獲得許可後才可以度人受戒；如果不經僧團許可擅自度人，結犯波逸提罪；如果私自收受他人的弟子為依止門徒、或私度式叉摩那等，要結犯突吉羅罪。如果當得戒和尚的比丘尼缺乏德行戒行，僧團應當制止她度人，並作羯磨撤銷收徒的資格；如果已經合法通過羯磨取得收徒資格，一年之中也只允許度一位大比丘尼、一位六法式叉摩那、一位沙彌尼、收受一位依止弟子，絕對不可以過量多收。隔了一年之後如果又想度人，依然要按照上述法規在衣食與戒法上如法引導傳授，但不必重新再向僧團作一次畜徒羯磨了。

【680-0011】04_比丘尼鈔/01b_卷上之上#92
【原文】第二制乞者其度沙彌尼式叉尼大尼戒竝須乞以年年度弟子犯罪故捨畜眾法等乞比丘尼度尼應具修威儀禮僧足長跪合掌乞云。
【譯文】第二部分「制令必須向僧團乞求」：度化沙彌尼、式叉摩那以及傳授大比丘尼戒，全部都必須事先向僧團正式乞求；因為佛制規定比丘尼若是年年盲目度收弟子，屬於犯戒罪過；或是先前曾被僧團撤銷（或捨去）收徒資格者，也都必須向僧團乞求。比丘尼若想度人，應當整肅威儀，頂禮大眾僧足，長跪合掌，向僧團乞求說：

【680-0015】04_比丘尼鈔/01b_卷上之上#96
【原文】大姉僧聽。此比丘尼某甲。今從眾僧。乞授人具足戒。僧今與比丘尼某甲。授人具足戒。誰諸大姉忍。僧與比丘尼某甲。授人具足戒者默然。誰不忍者說。僧已忍與比丘尼某甲。授人具足戒竟。僧忍默然故。是事如是持。
【譯文】（白二羯磨羯磨詞）：「大姊僧團請聽。這位比丘尼某甲，如今向大眾僧乞求允許傳授他人具足戒。僧團如今正式准許比丘尼某甲傳授他人具足戒。在場各位大姊，有誰贊同僧團准許比丘尼某甲傳授他人具足戒的，請保持默然；如果有誰不贊同的，請現在發言。僧團已默然贊同，准許比丘尼某甲傳授他人具足戒之事已經圓滿。因為大眾僧默然贊同的緣故，這件事情就這樣如法認定與奉行。」


【680-0016】04_比丘尼鈔/02a_卷上之下#1

【譯文】（具足戒篇第十）

【680-0017】04_比丘尼鈔/02a_卷上之下#2
【原文】此篇大門有五一由藉二本法三至僧四戒相五退捨。
【譯文】本篇共有五大項目：第一、受戒的因由與憑藉；第二、受戒的本法；第三、前往比丘僧團求戒；第四、戒相的內容；第五、退還捨戒。

【680-0018】04_比丘尼鈔/02a_卷上之下#3
【原文】第一由藉者義云若欲受具先受十戒六法然後受具故律云若不受十戒得戒而眾僧得罪故十誦云若未度出家便與受大戒得戒不佛答言得戒而眾僧得罪婆論云所以佛制受十戒者為染習佛法故六法制意如別。
【譯文】第一項「受戒的因由與憑藉」，義理上說：如果想要受具足戒，必須先受十戒與式叉摩那六法，然後才能受具足戒。因此律中說：如果不受十戒，雖然能得戒，但僧眾犯戒罪。所以《十誦律》說：如果未度出家，就直接為他受大戒，到底得不得戒？佛陀回答說：可以得戒，但僧眾犯戒罪。《薩婆多論》說：佛陀之所以制定先受十戒，是為了染習佛法的緣故。制立六法的用意，則另有專門說明。

【680-0019】04_比丘尼鈔/02a_卷上之下#4

【譯文】第二項「受戒的本法」，這裡面包含十種程序：第一請師、第二明發戒之緣、第三安置處所、第四單白差師、第五出眾問難、第六單白喚入、第七正乞受戒、第八單白和僧、第九對眾問難、第十正受具戒。
