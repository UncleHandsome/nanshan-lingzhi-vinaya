== PROBLEM ==


== SUGGESTION ==
改為：「此處是就依附作法大界安居的人而言；若是對照未曾作法結界、純粹依託僧伽藍（寺院）自然界安居的人，則沒有這種過失。」

== ORIG ==
若下，次釋破夏。依界者，對無界依藍，則無此過。言下，三釋離衣。

== CURRENT ==
「如」字以下，分別解釋為三種過失，首先解釋破壞和合的「別眾罪」。因為若與欲委託後走出大門內相之外，就喪失了作法效力，構成分黨別眾。在「若」字以下，其次解釋「破夏罪」。此處指依附作法大界安居的人而言；若是對照未曾結界的無界處依蘭若安居，則沒有這種過失。在「言」字以下，第三點解釋「離衣宿罪」。因為若在自然界中有護衣的自然效力，也不會有這種過失，所以是針對作法衣界來闡明的。在「故」字以下，做總結提示。在蘭若處唱界相中：現今的人樹立標相，標誌物之間相隔遙遠，中間毫無可依附指認之物；只是遙遙虛指、暗中默唱，非常切中此處所責備的過失。「自負」是指自己背負罪咎，也就是犯了不如法結界的突吉羅（輕垢罪）。
