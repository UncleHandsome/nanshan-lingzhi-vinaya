# 校閱材料　第489檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【489-0001】資持記/04c_上三#38
【原文】準《羯磨》云：我今不別眾食。然別眾唯約受請為言；若常住食，則無別過；可準此文，但云依眾。必下，有緣開別。九緣別眾，戒中委出，故指如後。六中。康謂安健，羸即有病。文出二法，隨時兩用。已上六事，總束為三。一三是戒；二四及五，內外兩資；第六即身。身是道器，衣食道緣，戒即道基。
【譯文】依照《羯磨》應當念誦說：「我從今日起不單獨接受別眾請齋。」然而「別眾」這條戒律，純粹是專就接受信眾請齋而言；如果是吃常住大眾的普請飲食，就根本沒有「別眾」的過失；可以依照這裡的律文，只要稱念「依止僧眾而食」即可。下文「若……」，是指遇有特殊因緣而開許別眾食的情況。律中開許了九種特殊因緣可以別眾受食，在隨後的戒相篇中會詳細列出，所以這裡指引參看後文。在「第六念」中：「康」是指身體安適康健，「羸」就是指患病羸弱。律文中開出了兩種念誦的方法，行者可以隨著自己當下的身體狀況靈活選用。以上這六件事，總括收攝起來不外乎三大門類：第一念與第三念屬於「戒律」門；第二、第四及第五念，屬於調攝身心的「內外道糧資助」門；第六念則屬於「身相」門。身體是載道的器具，衣食是修道的助緣，戒律則是修道的基石。

【489-0002】資持記/04c_上三#39
【原文】三皆助道，故制常念。晨朝不作，止犯六吉。此是羯磨，須合四緣；法須口說，言章無濫；事即六緣，無非詣實；人唯獨作，處通兩界；緣乖法敗，隨有結犯。〔古記云防二十七罪，又印行六念云：晨朝不作，得三十二罪；此無所出，妄穿鑿耳。〕雜相，初科。應法澡罐，謂一斗已下小者。
【譯文】這三者全都是資助成辦菩提大道的殊勝因緣，所以佛陀規定行者清晨必須常常繫念。早晨如果不作六念觀想，只會結成六個突吉羅的小罪。這本身也是一種羯磨作法，必須具備四種緣起才能成就：在作法上必須親口宣說，言辭章句不得含糊濫套；在事相上就是這六種境界，無一不是真實懇切的事實；在人員上只能由自己單獨作法，在處所上則通於自然界與作法界兩界；如果緣起相違、作法失敗，隨著各別的過失都會結罪。（古代的記注說六念可以防範二十七種罪過，又有坊間印行的《六念法》說：早晨若不作六念，會招致三十二種罪；這些在律藏中都毫無出處，純粹是後人胡亂穿鑿附會罷了。）在「雜相」的第一科中：所謂「合乎律法的洗滌澡罐」，是指容量在一斗以下的小水罐。

【489-0003】資持記/04c_上三#40
【原文】指〈隨相〉者，漉袋如飲虫水，澡罐即畜寶；彼云鐵瓦瓶銅盆銅盋等器，別人得受。〔彼律雨衣入六物，漉囊為眾具。〕二中。言心退者，鈍根未堪，故開後誦，不過五夏；《四分》先誦經論，及病，亦開。三中。佛度比丘，即善來受者；隨身制物，自然所感。
【譯文】指引參看〈隨戒釋相篇〉的內容：漉水袋的規定見於「飲蟲水戒」，澡罐的規定見於「畜寶戒」；彼律說鐵瓶、瓦瓶、銅盆、銅缽等器物，個別僧人是可以開許受持的。（在那部律中，雨浴衣被列入出家人的「六物」之中，漉水囊則被歸為「僧團公用器具」。）第二科中：所謂「心志退怯」，是指根性鈍拙的人心力不堪負荷，所以開許他延後背誦戒本，但最長不能超過五個夏臘；《四分律》中對於先去讀誦經藏、論藏的人，以及身患疾病的人，也同樣開許通融。第三科中：佛陀當初度化比丘，也就是那些應聲「善來」便自然得戒的聖弟子；他們隨身所用的制約法物，都是往昔善根自然感得而現前的。

【489-0004】資持記/04c_上三#41
【原文】引聖況凡，理須恒具。針斧二物，補衣須用；據論為制，在《律》歸聽。四中。即賊住緣起。此明時緣，為別邪正，故須常憶，用擬他問。五中。年有三時，月分黑白者；《戒疏》云：道俗位殊，時數亦改故也；俗則年有四時，道則歲唯三位，略於秋分也；故三時之始，冬分在初，表無常也；
【譯文】藉由舉出昔日聖者的清淨法相來比況今日凡夫，在義理上本來就應當恆常具足法物。縫衣針和斧頭這兩件物品，是修補百衲僧衣必須用到的器具；依據論典的解釋是規定必須攜帶，在《律藏》中則歸為聽許隨身之物。第四科中，這正是「賊住」偽作沙門的緣起歷史。這裡說明時間曆法的因緣，是為了辨別外道邪說與如來正教的差異，所以必須時常牢記在心，用來準備回答世人或官府的盤問。第五科中，一年分為三個季節，每個月劃分為黑月和白月；《戒疏》說：這是因為出家人與世俗人的地位身分懸殊，計算時間歲數的方法也隨之改變；世俗人將一年分為春夏秋冬四季，佛門正道則一年只有三個時節，把秋季略過併入了；因此三個時節的開端，是以冬分作為起首，藉此表徵世間萬法的苦空無常；

【489-0005】資持記/04c_上三#42
【原文】令有慧者觀時入道，不容非逸也。〔彼以八月十六冬分為始，此中隨俗列春在初，準《疏》為正。〕又先黑後白者，三時之始，必十六日為初也。捨戒中。總有四捨。一作法捨，二命終捨，三二形生，四斷善根。此明作法一種。又捨通漸頓，若直作白衣，則三戒齊失，名為頓捨。〔五十具也。
【譯文】這是為了讓具有智慧的修道人觀察時節變遷而速入聖道，不容許有絲毫的放逸懈怠。（彼論是以八月十六日作為冬分的開端，此處隨順世俗習慣把春季排在最前面，應當以《戒疏》的說法為準繩。）此外，先稱黑月後稱白月的規矩，是因為三個季節的開始，必定是以每月十六日作為初首的緣故。在「捨戒」的段落中，總共有四種捨戒的因緣：第一是如法作法捨戒，第二是此生命終自然捨戒，第三是生理突生男女雙根（二形），第四是徹底斷絕世間與出世間善根。這裡所說的，是第一種「作法捨戒」。此外，捨戒的行相又分為漸捨與頓捨：如果直接表明退作白衣在家人，那麼五戒、十戒、具足戒三種戒體同時退失，稱為「頓捨」。（也就是退失五戒、十戒與具足戒。）

【489-0006】資持記/04c_上三#43
【原文】若捨具作沙彌，或捨具十作優婆塞，則名漸捨。略知如此，餘廣如《疏》。僧捨中，初引開法。《律》因跋闍子比丘不樂淨行，還家與故二行不淨，佛因開捨。文引佛語，不出捨法；《律》云：我捨佛、捨法、捨比丘僧、捨和尚、捨阿闍梨、捨諸梵行、捨戒、捨律、捨學事，受居家法，我作淨人外道等。〔即頓捨也。
【譯文】如果捨去具足戒而作沙彌，或者捨去具足戒與十戒而作優婆塞，就稱為漸捨。簡略了解大概如此，其餘詳盡內容如同《戒疏》所說。在比丘捨戒這部分中，首先引用開許捨戒之法。《律》中因為跋闍子比丘不樂修清淨梵行，回到家中與原先的妻子行不淨行，佛陀因此開許捨戒之法。鈔文中引用了佛陀的言教，但未列出具體的捨戒言詞；而《律》中說：「我捨佛、捨法、捨比丘僧、捨和尚、捨阿闍梨、捨諸梵行、捨戒、捨律、捨學事，接受居家之法，我作淨人、外道等。」〔這就是頓捨。〕

【489-0007】資持記/04c_上三#44
【原文】我作優婆塞，我作沙彌〔此漸捨也。〕；須對比丘捨之，一說即成。《多論》所謂受如採寶，亦如登山，必假多緣多力；捨如失財，如從高墜，不假多緣，故唯一說。《增一》下，明分齊。彼經因僧伽摩比丘七反降魔，後更受具得阿羅漢，因開七反，已外不聽。尼捨中，引示。
【譯文】（若說：）「我作優婆塞」、「我作沙彌」〔這就是漸捨〕；捨戒必須面對比丘而捨，只要宣說一遍即可成就。《薩婆多論》所謂受戒如同採集珍寶，又如同攀登高山，必定需要依憑眾多因緣與諸多力量；捨戒則如同喪失財物，如同從高處墜落，不需要依憑眾多因緣，因此只要宣說一遍。《行事鈔》引《增一阿含經》以下，是說明捨戒再受的限度界限。該經記載因為僧伽摩比丘七次降魔，後來再次受具足戒而證得阿羅漢果，佛陀因此開許最多可以七次，七次之外便不再聽許。在比丘尼捨戒這部分中，則是引用律文來指示說明。

【原文】云無更受者，女流報弱，多無志操；佛初許度，尚是曲開；何況再受，理非容納。釋疑。答中，初列二義。比丘下，示開制。僧兼二種，尼但初義；各顯所以，在文可見。注文義決，唯障具戒。
