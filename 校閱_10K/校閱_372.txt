# 校閱材料　第372檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【372-0001】02_戒疏/03a_卷一下之一#71
【原文】【疏】生起此文，非教本意，講說之家，務傳言相。西梵諸師凡欲敷演，但依文義，廣說所由；至於科約，蓋闕如也。縱有分判，大通無局，如龍樹解《大品》以為二道，天親釋《涅槃》以為七分，須知意也。不可浪事悠悠，費於紙墨，大破正功，無任法利。顧諸學者，可不思哉！今欲消文，就義分之。更有科約，終非大濟，故削略也。
【譯文】【疏文】梳理生起此文的層次，原本並非佛陀立教的根本意圖，而是講經說法的法師為了傳承文義名相所作的施設。印度西方的論師們凡是要講經說法，多半只依循經文義理，廣泛闡述其源由背景；至於科判章節的分割約束，向來大多是缺漏不設的。縱然有所劃分判定，也多是大體貫通而不拘泥細節，例如龍樹菩薩解釋《大品般若經》只統攝為兩道，天親菩薩註解《涅槃經》只區分為七分，我們必須明白這個宗旨。切不可漫無邊際地隨意鋪張，空耗紙墨，嚴重破壞了真實修行的功用，對求取佛法實益毫無幫助。回顧各位參學之人，豈能不深加反思！如今為了消解文句，姑且順著義理加以區分。若再立更多的繁瑣科判，終究對修行沒有實質助益，所以全部予以刪削省減。

【372-0002】02_戒疏/03a_卷一下之一#72
【原文】【記】結略中三，初示意。教本資行，非圖多說，今此敘致，但利講解，故「非本」也。「西梵」下，二、舉中梵例顯，初敘本無。如今藏中大小乘論，止是長途散釋而已。「縱」下，遮妨。其間亦有科判之者，故須此示。「大通」者，謂以義總分；「無局」者，非隨文細碎。「龍樹」下，即《智度論》，釋《大品般若》，彼分二道判盡一經：一、聲聞道，二、菩提薩埵道。「天親」造《涅槃論》，分經為七：一、不思議通達示分，二、成就種性遣執分，三、正法實義分，四、方便修成分，五、離諸放逸入證分，六、慈光善巧住持分，七、顯相分。據彼西梵敷演之式，則知科判本非急要，故云「須知意」也。「不可」下，三、顯略。「浪」，橫也。「費」，損也。「破正功」者，妨自行也。「無法利」者，無益他也。
【譯文】【記文】在總結省略的三個層次中，首先是表明用意。佛教本是為了資助實修，並非貪圖講說得再多，如今這番敘述，只是為了利益講經解說，所以說「並非立教根本」。「印度西方」以下，第二、舉出古印度的先例來顯明道理，首先敘述原本沒有細碎科判。如今大藏經中的大小乘論典，大多只是通篇散文式的隨文解說而已。「縱然」以下是防範疑惑。論典中間也偶有作科判劃分的人，所以必須加以說明。「大體貫通」是指依據義理作總體劃分；「不拘泥細節」是指不隨逐細微文句碎割經文。「龍樹」以下是指《大智度論》解釋《大品般若經》，論中僅劃分兩道就判析整部經：第一是聲聞道，第二是菩薩道。「天親菩薩」撰造《大般涅槃經論》，將全經分為七部分：一、不思議通達示分，二、成就種性遣執分，三、正法實義分，四、方便修成分，五、離諸放逸入證分，六、慈光善巧住持分，七、顯相分。從西域先哲宣講敷演的體式來看，就知道繁細科判本來不是要緊的急務，所以說「必須明白這個宗旨」。「切不可」以下，第三、說明刪削省略的原因。「浪」就是隨便妄作。「費」就是損耗。「破壞真實修行」是指妨礙了自己的修持。「毫無佛法實益」是指無法實質利益他人。

【譯文】【疏文】有人問：「廣泛宣說戒法，必定是要面對全體僧團，為什麼現在的宣告稱呼，卻用了稱呼個別對象的用詞呢？」

【372-0008】02_戒疏/03a_卷一下之一#78
【原文】【疏】答：「戒法通收，何隔僧別。望法是僧，望機是別，法被在人，故須問別，不足怪也。」
【譯文】【疏文】回答說：「戒法全面統攝一切，哪裡有僧團與個別成員的隔閡？從法事的角度來看面對的是整個僧團，從教化對象的個人反省來看面對的是各個成員；因為戒法是加被落在每個人身上，所以必須向個別人員發問，這一點不足為奇。」

【372-0009】02_戒疏/03a_卷一下之一#79
【原文】【記】問中。如羯磨告眾，則云「大德僧聽」；單對一人，則云「大德心念」。今此對僧，反彰別號，故須問釋。答文，初二句通示戒法。以制總十方，法分三位，故曰「通收」。「望」下，正答來問。「望法是僧」者，單白廣說故。「望機別」者，檢問自行故。私釋：若準羯磨，初令同聽，乃是告僧；後責同忍，云「諸長老」，亦是問別。今此說戒，前陳單白，已是告僧，後文勅聽，例皆召別。據斯比擬，義無異也。
【譯文】【記文】提問中。好比羯磨法宣告大眾時，就說「大德僧聽」；若是單獨面對一個人，就說「大德心念」。如今此處明明是對著僧團，反而顯現出個別稱呼，所以需要提問辨析。回答的文字中，前兩句通論說明戒法。因為戒律的制定總攝十方，法制分為心念、對首、眾法三種層次，所以說「全面統攝」。「從」以下正式回答提問。「從法事來看是僧團」，是因為這是透過單白通告而廣泛宣說的緣故。「從教化對象來看是個人」，是因為需要大家檢點審問自己行持的緣故。私下補充解釋：如果比照羯磨法，起初讓大家一同聽聞，那是向全僧團宣告；隨後要求大家默許同意，說「諸位長老」，那也是轉向詢問個人。如今這項說戒儀軌，前面陳述單白表白，已經是對僧團的宣告，後文誡敕大眾傾聽，例行都是呼召個別個人。依據這種體例相互對照，義理上並沒有差別。

【372-0012】02_戒疏/03a_卷一下之一#82
【原文】【疏】光師《戒本》云「我今說戒」者，以名顯時心，略隱果號。而今所引，乃是《律》文，不可全蔽，故須出也。
【譯文】【疏文】慧光律師的《戒本》寫作「我今欲說戒」，是藉由當下通俗的名稱來彰顯當時大眾的心思，略微隱去了果位的梵音稱號。然而現在所引用的完全是《四分律》的正文，不可隨意全部遮蔽掩蓋，所以必須如實引出。

【372-0013】02_戒疏/03a_卷一下之一#83
【原文】【記】次科。先示古意。彼謂果號乍聞難曉，以文舉梵言，義非現行，故云「以名」等。「而」下，指非。恐乖聖旨，不可改作。則古今兩別，是非可見。「蔽」，覆也。
【譯文】【記文】第二小節。首先展示古人的用意。光師認為果位梵音名號初次聽聞難以通曉，既然文句引用的是梵語，其意涵並非當下通俗流行之語，所以說「藉由通俗名稱」等語。「然而」以下指出其不妥之處。擔心違背了佛陀的聖旨，不可隨意更改經文。那麼古今兩種譯本各有取捨，是非得失便顯而易見。「蔽」就是遮掩。

【372-0014】02_戒疏/03a_卷一下之一#84
【原文】【註】佛言：「新受者未聞戒，不知何學，聽集一處，和合說之。」
【譯文】【註文】佛說：「剛受具足戒的人未曾聽聞戒法，不知如何學習，允許聚集在一處，和睦合力地宣說戒本。」
