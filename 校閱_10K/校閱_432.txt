# 校閱材料　第432檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【432-0001】02_戒疏/05a_卷二上之一#119
【原文】【記】引緣難中。「龍珠」者，昔有螺髻梵志，居恒水邊，為龍所撓，佛令從彼乞頸下珠瓔，龍即不來。「鳥翅」者，昔有比丘住林間，正患夜半眾鳥悲鳴，佛教乞鳥兩翅，即飛出林，不復還矣。引此二緣，則顯畜類於財亦重，則違上義。答中。此出「房戒」，因諸比丘乞求多故，人皆逃避。佛將制戒，因說此喻。彼云：「佛告比丘，鳥獸尚不喜乞，況於人乎？」故云「借喻」等也。
【譯文】【記文】引述緣起發難中。「龍珠」，指往昔有螺髻梵志居住在恆河邊，常被毒龍擾惱，佛陀教他向龍索求頸下所戴的神珠瓔珞，龍因惜珠便不再前來。「鳥翅」，指昔日有比丘住於山林，深受半夜群鳥悲鳴之苦，佛陀教他向鳥索取雙翼，群鳥隨即飛出森林不再返回。引用這兩個因緣，顯示畜生對自身之物也非常看重，這就違背了上面所說的道理。解答之中，此語出自「作房戒」，因當時比丘們索求供養過多，導致施主紛紛逃避。佛陀將要制戒時，便宣說了這個譬喻。彼律云：「佛告諸比丘，鳥獸尚且不歡喜別人索求，何況是人呢？」所以說是「借喻反襯」等。

【432-0002】02_戒疏/05a_卷二上之一#120
【原文】【疏】問：「妄語論趣，人重餘輕者？」
【譯文】【疏文】問：「大妄語戒就所向趣別來論，何以在人道為重，其餘諸趣為輕呢？」

【432-0003】02_戒疏/05a_卷二上之一#121
【原文】【疏】「凡欲顯招名利，人趣是長。發言誑彼，彼多信奉，故制與重。餘趣不爾，報別非解，縱有潤微，故但輕罪。」
【譯文】【疏文】解答：「大凡想要顯揚自身以招納名利，人道是最佳場所。發出言辭欺誑對方，人類大多能信受崇奉，所以立制給予極重之罪。其餘非人、畜生二趣則不是這樣，果報隔閡根本不能真正領解，縱使有所利養滋潤亦極其微薄，所以只結輕罪。」

【432-0004】02_戒疏/05a_卷二上之一#122
【原文】【記】妄中，初解。人重二義，釋文，上二句明招利義。偏在人中，故云「長」也。「發」下，即信奉義。人多識別，非人邪諂，畜類愚癡故。「餘」下，簡非畜。言「非解」者，反「信奉」故。言「潤微」者，反「名利」故。
【譯文】【記文】妄語戒之中，初解。對人道結重有兩層意思，解釋文句時，前兩句說明招求利益之義，名利偏盛於人間，故說是「長」；「發」字以下，即信奉之義。人類多能辨識分別，非人則邪諂多疑，畜類則愚昧無知。「餘」字以下，簡別非人與畜生。說「不能解」，是相對於「信奉」；說「滋潤微」，是相對於「名利」。

【432-0005】02_戒疏/05a_卷二上之一#123
【原文】【疏】有人解云：「道之修成，會在人趣。容有修成，剋在己用。今故誑他，自敗其志，失利處深，豈不制重？餘道不爾，反前故輕。天趣雖勝，不能修善，又報得通心，誑無信義，但制輕罪。」
【譯文】【疏文】有人解釋說：「聖道之修成，唯有在人趣才有機會。人道容有修行成道、確實獲得實證為己所用之可能。如今故意去欺誑他人，自毀修道志向，喪失法利之處極深，難道還不應制定重罪嗎？其餘各道並非如此，反於前述條件所以結輕罪。天道雖然殊勝，但不能修習出世善法，而且以果報得他心神通，對其欺誑根本無人相信，所以只制輕罪。」

【432-0006】02_戒疏/05a_卷二上之一#124
【原文】【記】修道解中，初文亦二。先敘人重。以真實聖道，自他並有修成之義，若用誑人，反成兩損。「自敗」是損己，無正信故。「失利」即損他，令虗解故。「餘」下，簡二趣。上二句通簡非畜。言「反前」者，皆障道故。「天」下，別簡天趣，二義釋之。「通心」謂他心通。言「通」有二：聖人修道得，天、鬼業報得。
【譯文】【記文】就修道法義來解釋之中，第一段亦分為兩節。先敘述在人趣結重之由。因為真實的聖道，無論自己或他人都有修證成功的可能，如果用來欺瞞他人，反倒成了自他兩損。「自敗」是損傷自己，斷失正信；「失利」是損害他人，令彼生起虛妄解會。「餘」字以下，簡別二趣。前兩句通簡非人與畜生，說「反於前」，是指彼等皆屬障道之處。「天」字以下，個別簡別天趣，從兩層意義來解釋。「通心」即指他心通。神通有兩種：聖人透過修行而得，天人、鬼神則依業報而得。

【432-0007】02_戒疏/05a_卷二上之一#125
【原文】【疏】問：「天得通心，誑無信義得輕罪者，將佛以例，誑佛應輕？」
【譯文】【疏文】問：「天人具有他心通，欺誑彼者因彼不信而只得輕罪；若是將佛陀拿來為例，欺誑佛陀也應當結輕罪嗎？」

【432-0008】02_戒疏/05a_卷二上之一#126
【原文】【記】釋難中。佛具神通，誑亦無信，合同天趣，不當重輕。
【譯文】【記文】在釋難之中。佛陀具足一切神通，對佛誑說佛亦絕不會相信，照理應同於天人，不應結重罪，而應當結輕罪。

【432-0009】02_戒疏/05a_卷二上之一#127
【原文】【疏】答：「天是異趣，不信故輕。佛雖無信，佛亦無怖，約制從人，言了即結。又且誑怖為義，不取元情，但使言了相現，不問信與不信，怖與不怖，皆結正罪。不同殺佛，命不可斷。無學同人，義不待言。」
【譯文】【疏文】答：「天人屬於異類趣道，因不信受誑言所以結罪從輕。佛陀雖然不會被欺誑而生信，佛陀也毫無被恐嚇而生的怖畏，但戒律之制定依循人道之法，只要大妄語之言辭表達完畢當下即結重罪。況且誑惑與恐嚇之為義，根本不取決於受話者最初的心境，只要說妄語者語言分明、相貌顯現，無論對方是信與不信、怖與不怖，通通結成正犯之根本罪。這不同於殺佛，佛身金剛不壞其命根不可斷絕。無學阿羅漢同屬人道，其理顯然不必多費唇舌。」

【432-0010】02_戒疏/05a_卷二上之一#128
【原文】【記】答中。初約所誑釋，以顯不同。不信雖同，準「恐怖比丘戒」，怖佛亦提。然佛無怖，制罪同人，可為今例。「又」下，次約能誑釋。初正釋。「不同」下，簡異殺戒。「無學」下，例同羅漢。準佛可知，故云「不待言」也。
【譯文】【記文】答覆之中。首先就受誑對象來解釋，以顯其不同。不信雖然相同，但準照「恐嚇比丘戒」，嚇唬佛陀同樣犯波逸提。然而佛陀並無恐怖，律制結罪仍同對常人，正可作為此處的依據。「又」字以下，其次就能說妄語者的角度來解釋。先作正面的解釋。「不同」以下，簡別與殺戒的差異。「無學」以下，例同阿羅漢。比照佛陀即可明了，故說「不必言」。

【432-0018】02_戒疏/05a_卷二上之一#136
【原文】【疏】「若爾，自盜言無罪者，何故《律》中盜得己衣，犯偷蘭邪？」
【譯文】【疏文】「若是如此，說自盜自己之物不算犯罪，那為何《律》中記載偷盜卻錯拿到自己的衣服，被判犯偷蘭遮罪呢？」
