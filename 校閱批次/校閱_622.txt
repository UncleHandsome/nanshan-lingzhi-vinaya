# 校閱材料　第622檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【622-0001】03_業疏/08b_卷二之二#88
【原文】問：結淨亦假僧界，義非自然，何不稱者？答：僧、衣兩攝，雖不相可，莫不用攝人衣同處。若論淨地，元結攝食障人，故不稱於本住；又若稱者，恐成相可，徧有內宿，不如不結
【譯文】問：結立淨地同樣也是依託於僧界，其義理並非自然界，為什麼它不與僧界相稱（不遍同僧界）呢？答：僧界與衣界這兩種統攝範圍，雖然在事緣上未必彼此遍滿相稱，但無一不是用來統攝僧人與衣物在同一處所。如果談到淨地，原本結立的目的就是為了統攝儲存食物並防隔障礙僧人（防止僧食混雜），因此並不與原本的僧同住界相稱（不遍覆僧界）；再者，如果相稱的話，恐怕就會形成全面相合，導致全界之內普遍都有「內宿」之過，那還不如不結淨地。

【622-0002】03_業疏/08b_卷二之二#89
【原文】次問，衣、食兩界，能依義同，稱、不稱別，故問分之。答中，初明衣界須稱。「雖不相可」者，約緣為言。「若」下，次明淨地不稱，有二釋：一、攝食障人，二、恐徧界有過。世人見此，便謂通結淨地須除二同，然不知前牒二同，正彰通結，下除堂殿，別簡分齊，明非相可，豈得妄除？今此所通，自明本宗別結不須稱耳。聞聲即用，曾不考尋，恐後妄傳，寄此點示
【譯文】第二項提問中，衣界與食界（淨地）作為能依之界的義理相同，但與僧界相稱或不相稱卻有差別，所以發問來加以分別。回答當中，首先說明衣界必須相稱；「雖不相可」這句話，是就事緣有村落等阻礙而言。自「若」字以下，接著說明淨地不相稱，共有兩種解釋：第一是為了統攝食物並障隔僧人，第二是恐怕遍及全界會產生過失。世人見到這段文，就以為通結大界為淨地時必須除去二同（同住、同說戒），然而他們不知道前面標舉二同，正是為了彰顯通結大界，而後面排除堂殿等處，則是另外甄別界限分齊，以此表明並非完全相稱，哪裡可以妄自除去二同？如今這裡所會通的，自然是闡明本宗在別結淨地時不須與大界相稱罷了。世人往往聽聞隻字片語就盲目採用，不曾考究尋求原意，恐怕後人妄加傳播，所以借此處予以指明點破。

【622-0003】03_業疏/08b_卷二之二#90
【原文】若依《僧祇》，聚落、蘭若通結。後因舍衛失火，蘭若畏燒衣故，急奔赴城中，為人所訶，因制蘭若不通聚落。《四分》所結城外僧坊，若聚落內，是彼廢教，或是兩通；既除村界，明非廢也
【譯文】如果依據《摩訶僧祇律》，聚落與阿蘭若原本是可以互通結界的。後來因為舍衛城失火，住阿蘭若的比丘害怕失火燒了寄放的衣物，急忙奔赴城中，遭到世人訶責，佛陀因此制定阿蘭若不准與聚落互通結界。《四分律》中所結的城外僧坊，如果包含了聚落之內，這或者是《僧祇律》所廢止的教法，或者兩者原可相通；但本律既然在羯磨中除去了村界，顯然就不是施行廢教。

【622-0004】03_業疏/08b_卷二之二#91
【原文】四會異宗中初引《僧祇》。「聚蘭通結」者，即前九精舍涉聚蘭故。「蘭若畏燒衣」者，謂蘭若比丘也。彼云：時舍衛城中失火，城中諸人運物出城，諸比丘多於城中寄衣，畏火燒故，急走向城。為人訶者，彼言：「諸不信佛者呵言：『我等火逼出城避難，是沙門等向城而走，如蛾趣火，有何急事？』等。」「因制」等者，彼云：「佛言：從今已去，不聽練若通結聚落，應練若處通結練若，聚落處通結聚落，乃至如前互結得越毗尼罪。」次引《四分》會通兩部：初約相廢釋。「城外僧坊」者，律因比丘見蘭若好窟，聽結衣界，故羯磨除村，即通聚落，乃是《僧祇》廢教。「或」下，次約兩通釋。既制除簡，即不相通，正合彼宗，故非所廢。《僧祇》後結，亦制除村，如前可見
【譯文】在第四「會通異宗」中，首先引述《摩訶僧祇律》。「聚蘭通結」，就是指前面九座精舍牽涉聚落與阿蘭若兩者。「蘭若畏燒衣」，是指住阿蘭若的比丘。該律說：當時舍衛城中失火，城中百姓將財物運出城外，許多比丘多把衣物寄存在城中，害怕大火燒毀，急忙跑向城內。所謂被世人訶責，該律說：「那些不信佛的人訶斥說：『我們被大火所逼出城避難，這些沙門等人卻朝城中奔跑，就像飛蛾撲火一樣，有什麼急事呢？』等等。」「因制」等語，該律說：「佛說：從今以後，不准阿蘭若與聚落通融結界，應當在阿蘭若處只結阿蘭若，聚落處只結聚落，乃至如果像以前那樣相互通結，得越毗尼罪（突吉羅）。」接著引述《四分律》來會通這兩部律：第一是就相互廢立來解釋。「城外僧坊」，是指律中因比丘見到阿蘭若有好的洞窟，佛聽許結衣界，所以在羯磨中除去村落，如果這樣即通於聚落，那就是《僧祇律》所廢止的教法。自「或」字以下，接著就兩部皆通來解釋：既然制法中除去了村落、作了甄別，那就不算相互通結，正好符合彼宗後來的規定，所以並非採用廢教。《摩訶僧祇律》後來的結界規定，也同樣制定除去村落，如同前面所述可以明見。

【622-0007】03_業疏/08b_卷二之二#94
【原文】五分》云：若本無村結不失衣界竟，村後入者，不須更結，先已結故；若本有村結衣界已，村移出界，即此空處有不失衣界；若聚落小後轉大者，隨村及處皆非衣界；若村先大結衣界已，後漸小者，隨有空地盡是衣界。準此通前，約緣不徧，據法從本，說名為徧
【譯文】《五分律》說：如果原本沒有村落而結成不失衣界完畢，後來有村落遷入界內，不需要重新再結，因為先前已經結過的緣故；如果原本有村落，在結成衣界之後，村落遷移出界外，則這個空出來的地方就具有不失衣界；如果聚落原本很小，後來擴大，那麼隨著村落擴展所及之處，都不是衣界；如果村落原本很大，在結成衣界之後，後來漸漸縮小，那麼隨之空出的土地便全都是衣界。依照此理來會通前面所說：就事緣而言是沒有遍及，若依結法追溯其本體，則稱之為遍及。

【622-0008】03_業疏/08b_卷二之二#95
【原文】二中初引文。前明無村現結懸除；「若本」下，次明有村現除懸結，復分三相：初、移村出界，二、展小為大，三、縮大為小。有無廣狹，隨緣不定，驗知除村但除緣礙耳。「準」下，次準決前義，皆有誠據
【譯文】第二科當中，首先引述文句。前半部分說明原本無村時在當前結界而懸空排除後來的村落；「若本」字以下，接著說明原本有村時在當前排除而懸空結於村落騰空之時，這又分為三種相狀：第一是村落遷出界外，第二是村落由小變大，第三是村落由大縮小。有無與廣狹，完全隨事緣而定，由此驗知羯磨除村，只不過是排除了事緣的阻礙而已。「準」字以下，接著依此決斷前面的義理，都有切實可靠的依據。

【622-0010】03_業疏/08b_卷二之二#97
【原文】初緣言「厭離」者，即頭陀比丘厭於世間，不樂想也。「除駛流水」者，由漂蕩鼓怒，會護是難。僧界雖攝，尚通梁濟，文乃無橋，義亦通許
【譯文】最初因緣中所說的「厭離」，就是指修頭陀行的比丘厭離世間，生起不樂居世的意想。「除駛流水（排除奔騰的急流）」，是因為水流漂蕩奔騰凶猛，集會僧眾或守護衣物都很困難。僧界雖然統攝水流，尚且通融以橋梁接濟；文中雖然沒有提及橋梁，義理上也是通融允許的。

【原文】《僧祇》云：「院內潘汁流巷，人訶僧住與俗無別，因制不許。」《十誦》云：「初聽白二結地已，外道譏言：『禿居士舍，倉庫食厨，白衣無別。』因令僧坊外作。既在露地，乞多食少，因制不作淨地，作者吉羅，先結捨之。」
【譯文】《摩訶僧祇律》說：「僧院內的淘米水流到街巷中，世人訶責僧人住處與俗人毫無差別，佛陀因此制定不許在院內作淨地。」《十誦律》說：「當初聽許作白二羯磨結立淨地之後，外道譏諷說：『這哪是出家人，簡直是光頭居士的宅舍，有倉庫和廚房，與在家人毫無分別。』佛陀因此命令在僧坊外作淨地。既然設在露天之地，求乞者多而食物不足，佛陀因此制定不作淨地，若有作者犯突吉羅（吉羅），先前所結的淨地應予捨除。」
