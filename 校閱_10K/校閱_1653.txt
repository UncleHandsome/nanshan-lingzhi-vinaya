# 校閱材料　第1653檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1653-0001】03_業疏/07a_卷二之一#59
【原文】四分》十餘，委如鈔記。且舉四種以明非固，更有荊棘、汪水、糞聚等，皆非久固之物。「一」下約義通之。如空、露等，止可暫用，故云「得準律也」。然律列樹林、山巖等，與論大同，故云「可通律論」。即如論中小樹、蟻封，豈是久固？草竹、窮途等，何妨暫時？今以意定：若論暫用，諸物皆通；若取久永，必須別選
【譯文】《四分律》列出的十多種界相，詳細內容見於《事鈔》及《資持記》。此處姑且舉出四種來說明其不穩固，此外還有荊棘、積水、糞堆等，全都是不長久穩固之物。「一時」以下從義理上加以融通。例如空處、露天等，僅可供暫時使用，所以說「可依準律文施行」。然而律中所列的樹林、山岩等，與論藏大體相同，所以說「可以會通律論」。正如論藏中所說的幼樹、蟻封，難道就是長久穩固的嗎？草竹、絕路等，又何妨在暫時結界中使用？如今依義理判定：若是論及暫時使用，各種物體皆可通用；若是求取長久永久的界標，則必須另外審慎挑選。

【1653-0005】03_業疏/07a_卷二之一#63

【1653-0006】03_業疏/07a_卷二之一#64
【原文】《了論》長圓或一丈、或五尺，趣舉遠近以彰立相。言「水波」者，標相屈曲，狀如波焉。自性，即蘭若空處。二繩，謂兩處繩圍，中間連續。四廂，即四向有屋，中有空庭。且列十種，餘即一門、方土、比丘尼、優波塞、垣墻、滿圓、顛狂，竝如《鈔》、《記》具解。「皆」下疏家總示，結略指廣。
【譯文】《明了論》說長圓形中每隔或一丈、或五尺立石，只是大略舉出距離遠近以說明立標之相。所謂「水波」，是指標相曲折起伏，形狀如水波一般。「自性」，就是指阿蘭若空曠無人之處。「二繩」，是指兩處各自用繩索圍繞，中間互相連接。「四廂」，是指四面都有房屋，中間有空曠庭院。此處姑且列出十種，其餘七種即是一門、方土、比丘尼、優婆塞、垣牆、滿圓、顛狂，全都如《事鈔》與《資持記》中所詳細解釋。「皆」字以下是疏主總括提示，總結略述並指向廣博的文義。

【1653-0009】03_業疏/07a_卷二之一#67
【原文】若欲竪者，前識三量：一者界標，即唱者之所據；二者界相，即羯磨之所牒；三者界體，即作法之依地。或標即體，相在標外；或標異體，相在標內。若論其相，必在體外。引此附事，何有不成？欲知和別、夏限、衣藥，但曉此三便有界也。不識標體，虗指山林，或約城邑，不緣其事，得其語矣，奈無義何
【譯文】若要豎立標記，必須先明了三種量度：第一是「界標」，即宣唱界相者所依據的物體；第二是「界相」，即羯磨文中所列舉申明的標界；第三是「界體」，即羯磨作法所依止的土地。有時界標即是界體本身，而界相在界標之外；有時界標與界體不同，界相在界標之內。若就界相本身而言，必定處於界體之外。拿這三量附合於具體事相，哪有結界不成的道理？若想知道僧眾的和合同聚與離群別眾、安居結夏的界限、受持離宿衣與藥物等事，只要通曉這三量，界限就自然分明了。如果不辨識標與體，虛妄地籠統指稱山林，或泛指整個城邑，心裡並未緣取實際界事，即使口中念出言詞，又怎奈毫無實際意義呢！

【1653-0010】03_業疏/07a_卷二之一#68
【原文】示量中初科。前分三量：初是周回標物，二謂四圍外表，羯磨牒云「四方相內」是也，三即所圍內地。循外為相，則標下即體；就裏為相，則標與體異。標體容有異同，體相必不相離，故云「相必體外」也。「引」下次示成否在於明暗
【譯文】在開示三量中的第一科。前面區分了三種量度：第一是周圍環繞的標記物體；第二是指四周圍繞的外在邊界，也就是羯磨文中列舉所說「在四方界相之內」；第三就是所圍繞的內部土地。若是沿著標記的外緣作為界相，那麼標記底下就是界體；若是沿著標記的內緣作為界相，那麼標記與界體就截然有別。界標與界體容或相同或相異，但界體與界相必定互不相離，所以說「界相必定在界體之外」。「引此」以下，其次指出結界的成敗在於對此三量是明了還是昏昧。

【1653-0014】03_業疏/07a_卷二之一#72
【原文】有人云：一肘已上，大者得成。如《明了論疏》：一山一石，東西各結。又如《十誦》：有問者言「得竝結不」，佛答「周帀說為內外相者是也
【譯文】有人說：標記有一肘以上的寬度，體量較大的就能成立。例如《律二十二明了論疏》所說：以同一座山或同一塊巨石，其東側與西側各自結界。又如《十誦律》中有人問「能否並排結界」，佛陀回答「周圍宣說作為內外界相的就可以」。

【1653-0015】03_業疏/07a_卷二之一#73
【原文】問答中，古解局量，不許減小。仍引《了論》山石東西，證知標廣；下引《十誦》周帀分相，驗須相遠
【譯文】在此問答中，古人的解釋拘泥於具體尺寸，不允許小於一肘。並且引用《明了論疏》中以山石之東側與西側結界，來證知界標必須寬大；下文引用《十誦律》周圍區分界相之說，以驗證兩界必須有所間隔相遠。
