# 校閱材料　第249檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【249-0001】資持記/05c_上四#34
【原文】言為事者，別有所務，明非要故。及界中。疏云：界者入攝僧界，園者僧伽藍園。〔藍是梵語，園即華言，即院相也。〕此須料簡，若藍狹界寬，及藍界俱等，並約界論；或藍寬界狹，或復無界，則約園說。律據僧坊，準通俗舍。此收四種，疏云：園界兩所，足有雙隻。
【譯文】所謂「為事而來」，是指另有私事勞務在身，這就表明其並非抱著專誠安居的期約而來。在「跨入界內（及界）」之中，《業疏》說：所謂「界」，是指進入了統攝僧眾的大界；所謂「園」，是指僧伽藍的庭園（「藍」是梵語，而「園」是華語，指的就是整個寺院的外廓）。此處必須詳細分析：如果是僧園狹小而結界寬大，或者是僧園與結界範圍相等，全部都要依照結界來判定；如果是僧園寬大而結界狹小，或者該處根本沒有結界，那就必須依照僧園來論定。律文雖然是依據寺院僧坊而言，準照此理也可通用於俗家舍宅。此中總共收攝了四種情況，《業疏》說：僧園與結界這兩個處所，腳有雙足與單足之分。

【249-0002】資持記/05c_上四#35
【原文】〔謂園與界各有雙隻二種，故為四也。〕問：隻足尚成，何須雙足？答：律因緣起隨機緩急，先雙後隻，次第開之。既約隻成，雙則無用，所以文中但言一脚耳。下指廣者，疏云：所以一脚入界，明相出成者；以怱切不暇，開不結成。又問：雙足入出，成敗相對〔敗即破夏〕；
【譯文】（也就是僧園與結界各有雙足踏入與單足踏入兩種，所以合計為四種情況）。有人問：既然一隻腳踏入尚且能成夏，何必還要說雙足踏入呢？回答說：律文是依照事情發生的因緣，隨著根機情況的緊迫與寬緩，先開許雙足、後開許單足，循序漸進地予以開許。既然單足踏入就已經能成夏，雙足踏入自然就不成問題，所以後來的文字中只強調「一腳跨入」罷了。下文指示參閱更詳盡論述處，《業疏》說：之所以只要一腳踏入界內、天明看見明相就算成夏，是因為當時情況倉促急迫、無暇作法，所以特別開許不必作法結夏也能成辦。又有人問：雙足踏出與踏入界內，分別對應著成夏與失敗（敗就是破夏）；

【249-0003】資持記/05c_上四#36
【原文】未知一足入出，得例前不？答：要須兩足出界辨破，以利勝故；若一出破，一入不成，皆損行人，不名開制，大有理也。次明分齊。即前四法，約時處人法四位總收，使無通濫故也。初約時者。謂上四法通前中後，一時有四，成十二也。次約處中。自然作法，並通安居；
【譯文】不知道一隻腳踏出或踏入，是否也能比照前面的雙足之例呢？回答說：必須要兩隻腳都走出界外，才算判定為破夏，因為戒律是以盡量維護利益為優先考量；如果一隻腳踏出就算破夏、一隻腳踏入又不算成夏，處處都會損害修行人，這就稱不上是通權達明的「開遮制定」了，這個道理是極為深刻圓滿的。其次是說明範疇分界。也就是將前面的四種法，依照時間、地點、人物、作法這四個範疇加以統括歸納，使它們條理井然而不致相互混淆。首先是依照時間來劃分：上面所說的四種法通貫於前安居、中安居、後安居，一個時節各有四種，便構成了十二種。其次是依照地點來劃分：無論是自然界或作法界，全都通達可以安居；

【249-0004】資持記/05c_上四#37
【原文】各有十二，成二十四。又約人者，五眾各有二十四，則成一百二十種安居。〔疏中又分及界為四，成七種法，用歷三位，成二百一十種，倣上作之。〕約法中。上文四法，既通三時，不勞此位；然對異說通局不同，故須重簡。初明對念。通三可知。後明忘及，初引異解，初解局開前後。
【譯文】各有十二種，便構成了二十四種。若是再依照人物來劃分：五眾弟子各自擁有這二十四種，便構成了整整一百二十種安居。（《業疏》中又將「跨入界內」細分為四種情況，合計為七種作法，用以歷經時、處、人三位來推算，便構成了二百一十種，仿照上述方法推演即可）。在依照作法劃分之中：上面所說的四種法，既然已經通貫於三個時段，本來不需要在此再立科位；然而為了對應古來各種異說在通融與局限上的分歧，所以必須重新加以甄別剖析。首先說明面對面與心念作法：這兩者通貫於三個時段，容易明白。接著說明遺忘而成夏與跨入界內：開頭引述不同的解釋，第一種解釋局限於只開許在前安居與後安居。

【249-0005】資持記/05c_上四#38
【原文】注羯磨中亦標此義。又下，次解局開後夏。並下，結斷。今準祖意，並通三時；隨日結成，隨滿受歲，義無抑塞。乍觀兩解，從急似善。然律本中但明四法，不簡初後，故云並非等也。問：忘及二法，為加法否？答：準疏亦須陳詞，但夏成在前，加法在後，不以加法為結之始。
【譯文】《注羯磨》之中也標示了這個觀點。「又」字以下，是第二種解釋，認為僅局限於開許給後安居。「並」字以下進行總結判定：現在準照祖師道宣律師的意旨，這兩者應當全部通貫於前、中、後三個時段；隨著結夏之日成辦，便隨著期滿受歲自恣，在義理上本無所抑塞阻礙。初看這兩種古解，從嚴從緊似乎顯得很妥善；然而律本原文中只是列出這四種法，並未區分初夏還是後夏，所以判定說那些說法全非正解。有人問：遺忘與跨入界內這兩種法，事後到底還需不需要補作加法？回答說：依照《業疏》，事後仍然需要陳述詞白，只是成夏在前面就已算成立，補作加法在後，絕不能將後來的加法當作安居的起始日。

【249-0006】資持記/05c_上四#39
【原文】疏云忘等直得，後用加法何為？答：制開義立，何得不有。〔直得是開，加法依制。〕四遇緣中，二科。據論受日，合在法附；但出界逢難，失不義同，故此明耳。初引律開，即開二難；初總標。梵下，別釋；初釋梵難。略舉婬盜，餘事準知。地有伏藏，容生盜取。二下，釋命難。
【譯文】《業疏》說遺忘等情形當下直接就能成夏，那麼事後再補作加法又有什麼用呢？回答說：開許是特例，制定是常規，兩者各具義理，怎能不予補行呢！（直接成立是通權開許，補行作法是依循根本制法）。在第四項「遇緣（外出遇阻）」之中，包含兩科。就道理而言，受日外出法理應附屬於具體作法之後；然而此處是指走出界外遇到災難阻礙，其喪失夏臘與否的意義與前文相同，所以才在此處說明。首先引述律文的開許，也就是開許兩種災難；開頭是總標。「梵」字以下，分別解釋：首先解釋梵行難。此處只簡略列舉淫戒與盜戒，其餘各戒可以依此推知。例如地下有埋藏的寶物，容易引發他人起心盜取。第二小節解釋生命難。

【249-0007】資持記/05c_上四#40
【原文】佛下，示開。次詳定中，初科，初句牒前。從下，正斷為二；初明求處，約心以明成破。若得下，二明得處，約緣以辨通塞。法隨身者，處有前後，法仍相續故。出界便破者，亦據越宿。結成後去者，法既隨身，不必作法；但望所至之處，立心止住，名為結耳。
【譯文】「佛」字以下，宣示開許之法。接著在詳細考定之中，第一科的開頭一句是承接前文。「從」字以下，正式決斷為兩點：首先說明尋求避難處所，是就其內心意圖來明辨成夏與破夏。「若得」以下，第二點說明已經尋得安居之處，是就所遇之因緣來辨別通融與阻隔。所謂「法隨身（安居之法隨身相續）」，是因為處所雖然有先後更換，但安居的戒法依然相續不斷。所謂「出界便破夏」，也是依據在外過夜（越宿）而論定的。在結夏成辦之後離去的人，戒法既然已經隨身而行，到了新地方就不必重新作法；只要朝向所抵達的處所，立定決心長住下來，就稱之為結夏成了。

【原文】須緣及法者，緣即難事，法謂受日；反無緣法，破夏何疑。文義證中，初科引文有五；《五分》：食不足者，道緣闕故。親戚苦樂者，苦生憂惱，樂恐染著，皆妨道故。《十誦》下，合示三文。《四分》亦爾者，即如上引牧牛人等五處隨去也。《了論》中，初通舉八難。同說戒中。
