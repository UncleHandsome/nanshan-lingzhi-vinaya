# 校閱材料　第335檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【335-0001】02_戒疏/15b_卷三下之三#11
【原文】【疏】答：「不同有四：一、前損織師，自得縷故，此損縷主；二、前損織師，不與價犯，此損縷主，與價便犯；三、前戒開親，後戒俱犯，損義通也；四、前是己物，織成即犯，此本屬他，要受方犯。」
【譯文】【疏文】回答說：「不同之處有四點：第一、前戒損害的是織師，因為比丘自己提供了絲線；本戒損害的是絲線的主人。第二、前戒損害織師，不給工錢才犯戒；本戒損害絲線主人，給了織師工資反而犯戒。第三、前戒開許由親屬織造不犯，後戒無論親疏全都犯戒，因為損害他人利益的實質是一樣的。第四、前戒本是自己的物料，織成之時便結犯；本戒物料原屬於他人，必須等到正式接受衣物時才結犯。」

【335-0002】02_戒疏/15b_卷三下之三#12
【原文】【記】次問。二戒不同，緣相可見，欲生料簡，故發此問。答中。第三「後戒」親、非親「俱犯」者，謂織師也。上列緣中，明簡親者，據縷主也。
【譯文】【記文】第二個提問。兩條戒律的情形不同，事緣行相顯而易見，為了進一步辨析簡別，所以提出這個問題。答語中提到第三點「後戒」無論是親是疏「全都犯戒」，指的是對織師而言；上文所列的犯緣中，明確簡別親疏的，則是就絲線主人來說的。

【335-0003】02_戒疏/15b_卷三下之三#13
【原文】【註】佛在舍衛國。居士出線與織師為跋難陀作衣，彼後至家，擇取好線與織師織，又許與價。居士譏嫌，比丘舉過。佛因訶制。
【譯文】【註文】佛陀住在舍衛國時。有位居士拿出絲線交給織師為跋難陀比丘縫製僧衣，跋難陀後來到了織師家裡，挑選取用了上好的絲線交給織師織造，並且許諾增加工錢。居士為此生起譏嫌，其他比丘舉發了他的過失。佛陀因此呵責並制定了戒律。

【335-0012】02_戒疏/15b_卷三下之三#22
【原文】【疏】注解「自恣請」者，謂許好取惡耳，非長貪壞信而索好也。《僧祇》云「若俗家兄弟令自往營，疾成，得好」，是自恣相。
【譯文】【疏文】註文中所解釋的「自恣請」，意思是施主原本許諾給好的，自己卻選取粗劣的，並不是放縱貪心、破壞施主信心反而索取更好的。《僧祇律》說「如果俗家的兄弟讓比丘自己去督造操辦，以便早日織成、織得更好」，這便是屬於隨意請供的行相。

【335-0013】02_戒疏/15b_卷三下之三#23
【原文】【記】釋注中。初牒釋。言「自恣」者，任比丘意也。「僧祇」下，引示。彼文約親，本無所犯，且欲顯示「自恣相」耳。
【譯文】【記文】解釋注文的內容。首先摘錄註文加以解釋。所謂「自恣」，就是完全聽憑比丘的心意。「僧祇」以下，引用律文來指示說明。該條文是針對親屬而言，本來就沒有犯戒的嫌疑，此處引用只是為了顯示「自恣請的行相」罷了。

【335-0016】02_戒疏/15b_卷三下之三#26
【原文】【疏】與衣規伴，已是邪源。後既不行，和取無犯。今瞋心強奪，逼惱情深，特乖儀節，故聖制止。光律師云「先與衣不分強奪戒」。
【譯文】【疏文】以贈送僧衣為條件去圖謀同行的伴侶，這本身就已經是邪曲的源頭。後來對方既然不願同行，平和地討回本不犯戒。如今卻以瞋恨心強行奪回，逼迫惱亂他人情態嚴重，極其違背威儀行節，因此聖者佛陀立法加以禁止。慧光律師稱此戒為「先與衣不分明強奪戒」。

【335-0017】02_戒疏/15b_卷三下之三#27
【原文】【記】二十五，制意中。初二句，敘先與之由。「規」，求也。次二句，明理須和取。「今」下，顯過興故制。「乖儀節」者，「儀」即威儀，「節」謂節行。後引光師立名，以合制意。「不分明」者，與否未決故。
【譯文】【記文】第二十五條，制戒本意。前兩句敘述起初贈送衣服的原由。「規」，就是圖謀、求取的意思。接下來兩句說明理應以和氣的方式收回。「今」字往下，彰顯出過咎生起所以需要立戒制止。「乖儀節」的「儀」就是威儀，「節」是指節操操行。最後引用慧光律師所立的戒名，以契合制戒的本意。所謂「不分明」，是指給予還是借用並未明確決斷。

【335-0023】02_戒疏/15b_卷三下之三#33
【原文】【疏】三、不定與、決定取，生諍故犯。義加四句：初如向列；二、不定與、不定取，奪但犯吉；三、決定與、不定取，四、二俱決定與、取，若奪此二，則犯重罪。由初決捨，屬他已定。故文云「施已還取，是重攝」也。
【譯文】【疏文】第三、當初給予時心意不定、後來索回時心意決定，因為引發紛爭所以結罪。依義理可引申為四種情況：第一種就如剛才所列；第二種是給予時不確定、索回時也不確定，強奪僅犯突吉羅；第三種是決定給予、索回時心意不確定；第四種是決定給予、也決定索回，如果強奪這後兩種情況的衣服，就犯了盜戒重罪。因為最初已決意布施捨棄，物資所有權確定已屬於他人。所以經文說「布施之後又強行取回，這屬於盜戒重罪所收攝」。

【335-0024】02_戒疏/15b_卷三下之三#34
【原文】【疏】四、自奪使人。《祇》中，自與使奪，四句皆墮。衣謂三衣。若奪減量衣等，但犯吉羅。
【譯文】【疏文】第四、自己強奪或是指使他人強奪。《僧祇律》中說，自己給予或是差人強奪，四種交錯情況皆結墮罪。此處的衣是指三衣。如果強奪的是不足尺寸的減量衣物等，只犯突吉羅罪。

【335-0025】02_戒疏/15b_卷三下之三#35
【原文】【疏】五、得衣屬己。《僧祇》四句，初「合與別奪者，一時與三衣，後隨衣奪，犯三提罪」，餘句準知。
【譯文】【疏文】第五、奪得衣服並占為己有。《僧祇律》區分四種情況，第一種是「一併給予而分別強奪，也就是同時給了三衣，事後一件一件搶奪，結犯三個波逸提罪」，其餘句的情況可以準此類推。

【335-0026】02_戒疏/15b_卷三下之三#36
【原文】【記】列緣。第一，唯局大僧。「若爾」下，例難。下「九十」中隨順被舉，大小同墮故。答中，彼違僧法，故不簡位。
【譯文】【記文】列舉犯緣。第一項僅局限於大僧。「若爾」以下，是拿其他戒律作為通例來詰難。因為在後文「九十單墮」中，比丘隨順被舉的大僧與隨順被擯的小眾沙彌，皆同犯墮罪。答語指出，那是因為同樣違抗了僧團的白黑法羯磨，所以不分位次。

【335-0027】02_戒疏/15b_卷三下之三#37
【原文】【記】三中。初示當戒犯緣。「義」下，立句簡辨。次句取既不定，奪則惱微，故罪輕降。後二「犯重」，屬前盜戒。「由」下，出犯重所以。由捨已決，非己物故。引證可知。
【譯文】【記文】第三項中。首先指出本戒的正犯因緣。「義」字以下，設立四句分別簡要辨析。第二句因為取回的心意並不堅決，強奪造成的惱亂較輕微，所以罪名降輕。後兩種「犯重罪」，歸屬於前面的盜戒。「由」字往下，點出犯重罪的原因。因為當初布施已經決絕捨棄，不再是自己的物品了。引證文句顯而易見。

【335-0028】02_戒疏/15b_卷三下之三#38
【原文】【記】四中。引《僧祇》，初明自他四句：一、自與使人奪；二、使人與自奪；三、使人與使人奪；四、自與自奪。「衣」下，次簡體。「減量吉」者，非三衣故。五中，《僧祇》與取離合，亦作四句：初句如文；二、別與合奪，三、合與合奪，此二並一罪；四、別與別奪，同上三罪。
【譯文】【記文】第四項中。引用《僧祇律》，首先說明自奪或遣人的四句：第一、自己給予而差使他人奪；第二、差人給予而自己去奪；第三、差人給予而差人去奪；第四、自己給予而自己去奪。「衣」字以下，接著簡別衣服本體。「減量吉」的意思，是因為不屬於正統三衣的緣故。第五項中，《僧祇律》對於給予和奪取的合在一處或分開來，也作了四句辨析：第一句如疏文所寫；第二句是分開給予而一次奪回，第三句是一次給予而一次奪回，這兩種情況都只結一個罪；第四句是分開給予也分開奪回，與第一句同樣結三個罪。

【335-0029】02_戒疏/15b_卷三下之三#39
【原文】【註】佛在舍衛國。難陀弟子善能勸化。跋難陀意欲共遊行，便先與衣。餘比丘言：「彼癡，不知誦戒、說戒、布薩、羯磨。」後去不隨，彼即奪衣。比丘訶舉，佛因制戒。
【譯文】【註文】佛陀住在舍衛國時。難陀有一位弟子非常擅長勸勉教化。跋難陀比丘心想與他一同遊行結伴，就預先給了他一件僧衣。其他比丘說：「那個人愚癡遲鈍，不懂得背誦戒本、宣說戒法，也不懂布薩和羯磨作法。」後來那位弟子沒有跟隨同行，跋難陀立刻強行奪回僧衣。比丘們呵責舉發其過失，佛陀因此制定了戒律。

【335-0030】02_戒疏/15b_卷三下之三#40
【原文】【疏】就戒緣中。所列「癡」相有四位者，初二防未起非，後二除已起罪也。就初中「不知誦戒」者，自行未閑也；不知「說戒」者，眾法儀則迷也。就後中，不知「布薩」者，不識念對治罪也；不知「羯磨」者，不識從僧乞滅也。皆冥不知，故言「癡」矣。
【譯文】【疏文】在制戒因緣當中。所列出的「愚癡」相狀共有四個位階，前兩項是防止尚未生起的罪過，後兩項是消除已經產生的罪業。在前兩項中，「不懂誦戒」，是指自身的修行尚未熟練；「不懂說戒」，是指對僧團共事的法則軌範茫然不知。在後兩項中，「不懂布薩」，是指不知道如何心念發露（或依心念法懺悔）來對治罪過；「不懂羯磨」，是指不知道如何向僧團請求懺除罪障。這幾項全都不知曉，所以稱作「愚癡」。

【335-0031】02_戒疏/15b_卷三下之三#41
【原文】【記】戒緣中。顯示癡相。初總分。「就」下，別釋。「布薩」翻淨住，故約懺罪釋之。「布薩」對別人，悔下諸聚；「羯磨」對僧，悔上二篇。「皆」下，通結。
【譯文】【記文】制戒緣起中，顯示愚癡的相狀。起初先作總體劃分。「就」字以下，分別詳細解釋。「布薩」翻譯為淨住，所以依照懺悔罪業來解釋。「布薩」是對著個人，用來懺悔下位各聚的輕罪；「羯磨」是對著整個僧團，用來懺悔僧殘等上位二篇的重罪。「皆」字以下，作整體結語。

【335-0032】02_戒疏/15b_卷三下之三#42
【原文】【律】若比丘，先與比丘衣，後瞋恚，若自奪，若教人奪，「還我衣來，不與汝」。
【譯文】【律文】若有比丘，起初給了其他比丘衣服，事後生起瞋恚心，無論是自己搶奪，還是指使他人搶奪，說「把我的衣服還來，不給你了」。

【335-0033】02_戒疏/15b_卷三下之三#43

【335-0035】02_戒疏/15b_卷三下之三#45
【原文】【註】尼同僧犯。不犯者：不瞋恚，言「我悔，不與汝，還我衣來」，彼知心悔，可即還衣；若餘人言「此比丘欲悔」，還他衣。若借他衣，著無道理，還奪，不犯。恐失，恐壞，若彼人破戒、破見、破威儀，若被舉、滅擯、應擯，若為此事命、梵難，一切奪取不藏舉者，皆不犯。
【譯文】【註文】比丘尼與比丘犯同樣的罪。不犯的情況是：沒有瞋恚心，只是說「我後悔了，不打算給你了，把衣服還給我吧」，對方明知自己心生反悔，可以隨即歸還衣服；或者由第三人從中調解說「這位比丘想要反悔了」，而將衣服歸還給他。如果是借給別人衣服，對方穿著毫無章法規矩，因而奪回的，不犯。害怕衣服遺失、損壞，或者對方破了淨戒、破了正見、壞了威儀，或者對方被舉發、被滅擯、應當被擯除，或者為了防止發生危及性命及梵行的危難，在這種情況下一切奪取而不私自藏匿據為己有的，全都不犯。

【335-0037】02_戒疏/15b_卷三下之三#47
【原文】【疏】注中，「奪而藏」者，謂對面奪也。「未藏」情疑，屬己不顯，故約藏相結成墮罪。又云「若著樹上」者，謂非對面，隨舉「離處」，則犯正罪，以無人可諍故結也，後時更藏，但犯吉耳。
【譯文】【疏文】註文中所謂「奪而藏」，是指當著對方的面奪取。「未藏」代表心存猶豫，占為己有的意圖尚不明顯，所以必須藉由藏匿這一行相來結定墮罪。又說「若著樹上」，是指背著對方的面拿取，只要一拿起並「離開原處」，就犯了正罪，因為當時沒有對面的人可以產生爭執，故以此結罪，事後如果再藏匿，只不過另犯突吉羅罷了。

【335-0038】02_戒疏/15b_卷三下之三#48
【原文】【記】戒本，牒釋中。注明此戒成犯有二，故須通之。初釋奪藏成犯。「又」下，次釋舉離成犯。各出所以，以彰兩別。「後藏吉」者，前已結提，猶慮彼取，更藏故吉。
【譯文】【記文】解釋戒本注文的段落。注文說明本戒結成犯罪有兩種情況，所以必須融會貫通。起初先解釋當面強奪且藏匿而結罪。「又」字往下，接著解釋背地拿取離開原位而結罪。各自闡明其中的緣由，以彰顯兩者的分別。「後時更藏犯吉羅」，是因為先前移動離處時已經結了波逸提正罪，後來依然擔心對方找尋取回，於是進一步藏匿，所以另結突吉羅。
