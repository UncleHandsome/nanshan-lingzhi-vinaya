# 校閱材料　第235檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【235-0001】資持記/03c_上二#21
【原文】上明餘過，罵是正過。須下，明立治。名相兩顯。言作法者，白云：大德僧聽！此善法比丘，質多居士信樂檀越常好布施供給眾僧，而以下賤惡罵罵之；若僧時到僧忍聽，今為善法作遮不至白衣家羯磨，白如是。〔羯磨準作。〕奪行並同。僧下，示別過。雖非罵謗，損惱同故。遣謝中，初明選差。
【譯文】前面說明其他過失，辱罵才是最主要的過咎。在「須」字以下，說明建立這項治罰。名稱與行相兩者都很明晰。說到具體作法，單白說道：大德僧請聽！這善法比丘，對於質多居士這位樂善好施、常喜布施供養眾僧的信心檀越，竟然用下賤粗鄙的惡語辱罵他；若僧團時機已到且僧團同意聽許，僧團現在為善法比丘作遮止不得前往白衣家的羯磨。這就是單白。〔羯磨亦依照此法推演辦理。〕剝奪權利等規定完全相同。在「僧」字以下，指示其餘的過失。雖然並非辱罵誹謗，但造成的損害煩惱是相同的。在派遣致歉的段落中，起初說明挑選差派的人選。

【235-0002】資持記/03c_上二#22
【原文】八法中第五受人語者，不妄拒也。七約行業，餘並解能。八中議字，律本不從言，單作為正。將下，明往懺。初令語告檀越懺悔者，召令受也。若下，次教觀量。具有等者，律云：若不受，應至眼見耳不聞處，安羯磨比丘著眼見〔令彼目覩，心柔受懺。
【譯文】在八項資格條件中，第五項「能受人語」，是指不會妄自抗拒他人的規勸。第七項是就戒行行持而言，其餘各項則屬於理解與應對能力。第八項中的「議」字，律本中並不帶有言字旁，單純作「義」字才是正確的字形。在「將」字以下，說明前往懺悔的過程。起初令其告知檀越前來接受懺悔，這是召請居士出面接納。在「若」字以下，接著教導如何觀察局勢。說到「具有」等語句，律中說：如果居士不肯接納，應當前往眼睛看得見而耳朵聽不見的地方，將受羯磨處罰的比丘安置在看得見之處〔好讓居士看見他，心生柔和而接受懺悔〕。

【235-0003】資持記/03c_上二#23
【原文】耳不聞處〔恐聞作法〕，教令如法懺悔，復來語言：居士懺悔，彼比丘先犯罪，已為懺悔，罪已除；彼若受者善，若不受者，犯罪比丘應自往懺悔。若俗下，後示開解。懺竟俗喜，足顯從順故。總簡中。以前後七法，過相相涉；治法乃殊，故約信行大分二類；〈隨相〉細簡，各別如文。前四中。
【譯文】「耳不聞處」〔這是怕他聽到作法的緣故〕：教他依正當的方式懺悔，然後再回來對他說：「居士請寬恕（接受懺悔）！」，那位比丘先前所犯的罪，已代他懺悔，罪已除滅；對方若接受便好，若不接受，犯罪的比丘應親自前往懺悔。「若俗」以下，是隨後指示開許解除羯磨的規定。懺悔完畢後俗人歡喜，正足以顯示比丘順從教導的緣故。在總體簡別的部分中：因為前後七種治法，所治的過失相狀互相牽涉，而對治的方法卻有不同，所以依「信」與「行」大致分為兩類；〈隨相〉中再詳細簡別，各各不同，如文所說。前四項之中。

【235-0004】資持記/03c_上二#24
【原文】律足數者，前篇具明。後三中。同犯重者，財法亡故。引《涅槃經》，初示正意。謗法者，通前七過；降伏者，總目七法。若準經中，通明七種；今此引之，且證三舉。又下，明別意。果在當來，愚多不信；輕撥聖教，公然作惡。故立治法，使知因果，驅歸正信故也。斥濫中三，初三句標人。
【譯文】律中認為足以計入僧數的標準，在前面的篇章中已經完整說明。在後面三種法中，與犯重罪者相同，是因為在財利與佛法上都已被徹底斷絕的緣故。引用《涅槃經》時，起初顯示這項教法的主要意旨。所謂「謗法」，通盤貫穿了前面的七種過失；所謂「降伏」，則是對這七種懲處法門的總括稱呼。如果依照經中的義理，通盤說明了七種懲處；如今引用此文，暫且用來作為三種舉罪法的佐證。在「又」字以下，說明另一層特殊用意。惡果報應在未來世，愚昧之人多半不肯相信；輕率排斥聖人教誨，公然造作惡行。所以建立懲治之法，使眾人深知因果歷然，強制促使其回歸正信。在斥責濫用之處包含三部分，前三句標示所針對的人群。

【235-0005】資持記/03c_上二#25
【原文】上句示所學，下二句明心行。未涉道者，隨塵染故。違大小者，不稟教故。口下，二示濫。上二句即明學語。罪福性空，出《普賢行》法；婬欲是道，出《無行經》。乃大乘之通說，非止一經。
【譯文】上一句指出其所學習的內容，下兩句明示其內心的行持。之所以說「未涉道境」，是因為心念隨著外塵塵垢染著的緣故。說「違背大小乘」，是因為未曾敬承教法規範的緣故。在「口」字以下，第二部分揭示其狂妄濫用的言論。上面兩句正是說明其模仿學習口頭言語。所謂「罪福自性本空」，出自《普賢行法》；所謂「婬欲即是道」，出自《無行經》。這原本是大乘經教中相通的說法，並不僅限於一部經典。

【235-0006】資持記/03c_上二#26
【原文】為顯業相皆如幻故，復示業性不可得故，復示染淨同一源故，復示諸法唯一心故，復令眾生於諸惡中得解脫故。非謂使汝作不淨行。今身為惡，傍倚此語，用飾己非；取適愚情，實乖聖意。即《楞嚴》云：先斷淫心，是名如來先佛世尊第一決定清淨明誨；
【譯文】這是為了顯明一切業相皆如幻化，同時顯示造業之自性了不可得，並進一步揭示染污與清淨原本同出一源，顯發萬法皆唯心所造，從而令眾生能於一切惡境中獲得解脫。這並不是教你去肆無忌憚地行持不淨業。如今自身縱容作惡，反而借用這些深奧話語來掩飾自己的罪過；這只是迎合了愚蠢的情執，實際上徹底違背了聖人的本意。這正如《楞嚴經》所說：先斷除淫欲之心，這名為過去無量如來諸佛世尊的第一道決定清淨明白的教誨；

【235-0007】資持記/03c_上二#27
【原文】若不斷淫修禪定者，如蒸砂石，欲成其飯；經百千劫，終名熱砂等。又《梵網經》云：菩薩應生孝順心，救度一切眾生，淨法與人；而反更起一切人婬，乃至無慈悲心，是菩薩波羅夷罪。汝謂《楞嚴》、《梵網》是大乘乎？若專彼語，此復云何！悲夫悲夫！身下，顯上心行。上句示行，下二句明心。
【譯文】如果不斷除淫心而修習禪定，就如同蒸煮砂石卻想讓它變成米飯；縱使經歷百千劫數，終究只能稱作滾燙的砂子而已。又如《梵網經》所說：菩薩應當生起孝順之心，救度一切眾生，將清淨的正法傳授給人；如果反而引發一切人的淫欲，乃至喪失了慈悲之心，這就是菩薩的波羅夷重罪。你認為《楞嚴經》與《梵網經》難道不屬於大乘教法嗎？如果一味執著那些撥無因果的言論，面對這些戒規又該如何交代！實在令人悲嘆！實在令人悲嘆！在「身」字以下，顯露前面所說的心念與行為。上一句指出具體行徑，下兩句明示其內心動機。

【235-0008】資持記/03c_上二#28
【原文】隨即是順，謂愚叢從化；違謂智者所非，愛惡熾然，去道甚遠。並下，三勸罰。不見舉中。佛在拘睒彌國，闡陀比丘犯罪，餘比丘語言汝犯罪見不？答言不見，比丘舉過，佛因訶制。出過有二，初即倒亂。或下，二明信壞。但是作惡不畏來報，即為邪見；非同斷善，頓棄三寶而失戒矣。
【譯文】所謂「隨」，就是盲從順遂，是指愚癡的人盲目附和隨順其教化；所謂「違」，是指遭到有智之人的非難痛斥，貪愛與瞋惡之火熾盛燃燒，距離解脫道極其遙遠。在「並」字以下，第三部分勸勉必須施以嚴懲。在不見罪舉羯磨中。佛陀在拘睒彌國時，闡陀比丘違犯了罪過，其餘比丘對他說你見到自己犯罪了嗎？他回答說沒看見，比丘們舉發其過失，佛陀因而呵斥並制定了這項舉罪法。所列出的過失有兩項，第一是顛倒混亂。在「或」字以下，第二是說明其信仰破壞。只要是放肆作惡而不畏懼未來惡報，這就屬於邪見；這不同於徹底斷絕善根、完全拋棄三寶而當即失去戒體的情形。

【235-0009】資持記/03c_上二#29
【原文】或由下二句，推上過源。僧下，示其拒逆。邪見在懷，非言不顯；故假問答，為舉本緣。僧即下，次加治法；初明加法。白云：大德僧聽！此闡陀比丘犯罪，餘比丘語言汝犯罪見不？答言不見；若僧時到僧忍聽，今為闡陀比丘作不見罪舉羯磨，白如是。〔羯磨例準。〕奪行等並同。為下，二明舉意。
