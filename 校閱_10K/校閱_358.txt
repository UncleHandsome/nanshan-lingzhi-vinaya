# 校閱材料　第358檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【358-0001】02_戒疏/02c_卷一上之二#129
【原文】【疏】一、以時機須爾：末代鈍根，聞廣如睡，故聖前演，望有欽承；若為說略，則用全疎，微被少機，不可不用。二、隱顯故爾：廣教相彰，化用形勝，故前；略題三業，義通須後。三、功強故爾：略教既壞，制廣還興，從興攝護，功成先說；略教不爾，無補廣之能，且順別機，故須後說。
【譯文】【疏文】第一、因為時代根機必須如此：末法時代的鈍根之人，聽聞詳細的廣教條文尚且昏昏欲睡，所以聖人必須先宣演詳細的廣教，期望眾人能生起欽受奉行的敬畏心；如果一開始就只對他們宣說簡略的教法，那麼對於整體的戒律防護就會完全疏失，略教只能極其微細地利益極少數利根之人，但也不能完全棄置不用。第二、因為教相有隱蔽與顯露的緣故：廣教的法相分明顯露，其教化功用相形之下更為顯著殊勝，所以應當擺在前面；略教只概括性地提出三業防護，其義理涵融深邃，理應放在後面。第三、因為功用強弱不同的緣故：略教的綱領一旦毀壞，制定廣教就能讓戒律重新興盛，順應這種振興而產生的攝受防護功能，既然功德宏大就應當先說；略教則不具備這種力量，它沒有回頭補救廣教虧缺的能耐，而且只能隨順極少數特殊根機，所以必須放在後面宣說。

【358-0002】02_戒疏/02c_卷一上之二#130
【原文】【記】初約時機。則明佛世唯可用略。「聞廣如睡」者，以廣況略也。「若」下，明略不稱機。「微」下，釋兼略所以。次約教相。「隱」謂言通，「顯」即相別。「形」謂相形。「故前」，句絕。後約功能。取其能補，唯廣「功強」。「順別機」者，不兼鈍故。上云「少機」，末世稀故。
【譯文】【記文】首先是依據時代根機來論述。這就說明佛陀在世時，一開始確實只要使用略教即可。「聽廣教如入睡」是用廣教的詳細來反襯略教的難以受持。「如果」以下，說明略教無法契合當前眾生的根機。「極其微細」以下，解釋為什麼後面還要兼說略教的緣故。第二是依據教法的相貌。「隱蔽」是指語言通泛概括，「顯露」是指條文具體分明。「形」是指相形，即兩相比較而顯現。「所以放在前頭」，此處文意告一段落。最後是依據發揮的功能。取其具有補救防護的強大能耐，唯有廣教具有「強大功用」。「隨順少數根機」是指它無法普遍兼顧鈍根之人。前文所說的「少數根機」，是指末法時代利根之人極其稀少的緣故。

【358-0005】02_戒疏/02c_卷一上之二#133

【358-0006】02_戒疏/02c_卷一上之二#134
【原文】【疏】答：「元制略教，雖為利機，言略義通，非不收鈍。由鈍不解，違略起非，是教行俱缺也。後遂制廣，用充前略。何以知然？但略有包通之理，廣無異略之能。鈍士當機，先作無犯，廣名雖異，還同略教之功。是名教行俱補。斯則兩教相成，通無廢立。約緣利鈍，據實兼之。」
【譯文】【疏文】回答：「佛陀最初制定略教，雖然本意是為了利根之人，但文字簡約而義理貫通，並非不能涵蓋收攝鈍根之人。只是由於鈍根之人無法深刻領解，違背了略教而生起過失，這就造成了佛陀的教法與個人的行持同時出現缺憾。後來佛陀隨之制定廣教，正是用來填補充實先前的略教。怎麼知道是這樣呢？因為略教本來就具備了包羅貫通的法理，而廣教也沒有任何超脫略教之外的異能。鈍根之人作為引發制教的當機者，在制戒前所作的過失並不結犯，廣教的名相雖然繁複殊異，其本質仍是發揮與略教完全相同的調伏功能。這就稱作教法與行持兩方面都被彌補完備了。這樣一來，這兩種教法是相輔相成的，全盤貫通而不需要廢除任何一方。若就外在機緣而言有利根與鈍根的分別，若就實質內容來說則是兩者兼融完備的。」

【358-0007】02_戒疏/02c_卷一上之二#135
【原文】【記】答中。初明違略制廣。「言略」者，唯一偈半故。「義通」有二：一者，教通，三業明行，無不收故；二者，機通，利鈍二根，無不被故。此明利根，了知所造本於三業，故能奉略；鈍者不識能造，隨緣壞行，故須示相以為廣教。「充」，猶補也。「何」下，正顯相成。初句徵。「但」下，釋。上二句明補教。「略」中具廣，故曰「包通」。廣即略相，故不「異略」。「鈍」下，明補行。違略無犯，開廣續制，全彼行故。篇聚差別，故言「名異」。無非三業，故云「同略」。「斯」下，結顯。上二句明不可去留，即彰《戒本》兩存之意。下二句明所被通局。上句明二機局對兩教，下句示兩教各具二機。
【譯文】【記文】在回答的段落中。首先說明由於違背略教才引發了廣教的制定。「文字簡約」是因為只有一首半的偈頌。「義理貫通」包含兩層意思：第一是教法相通，藉由身口意三業來說明行持，沒有任何一項善惡行法無法包攬；第二是受教根機相通，利根與鈍根兩種根器，沒有一人不在其涵蓋範圍之內。這說明利根之人深刻了知一切造作全都源於身口意三業，所以能嚴格恪守略教；鈍根之人不認識造業的根源，隨順外緣就敗壞了戒行，所以佛陀必須詳列具體罪相以作為廣教。「充實」如同補足填滿的意思。「怎麼知道」以下，正式顯明兩者相輔相成。第一句提出徵問。「因為」以下，進行解釋。上兩句說明教法的互補。「略教」之中本來就具足了廣教的內涵，所以說「包羅貫通」。廣教其實就是略教的具體相貌，所以說並未「超脫於略教」。「鈍根的人」以下，說明行持的互補。在違背略教時不論處犯戒罪名，透過開啟廣教接續制定具體規範，以此保全他們的戒行。篇章聚類的罪名各有差別，所以說「名相殊異」。但其本質無非都在防護三業，所以說「等同略教之功」。「這樣一來」以下，作結尾彰顯。上兩句說明兩種教法不可任意取捨，這正是彰顯《戒本》之中同時保留這二者的深意所在。下兩句說明所對應的受教對象在普遍與局限之間的關係。上一句說明利鈍二機分別局限對應兩教，下一句則指明這兩種教法實質上各自完整涵蓋了利鈍兩種根機。

【358-0011】02_戒疏/02c_卷一上之二#139
【原文】【記】引示中。《善見》「二十年前說略」，今引三部皆「十二年」。《義鈔》云：「隨根所見異故。」
【譯文】【記文】在引用經論開示的段落中。《善見論》說「最初二十年之前佛陀宣說略教」，如今此處所引用的三部典籍都記載為「十二年」。《義鈔》解釋說：「這是由於弟子隨順各自根機，所見到的佛陀化導年數有所不同罷了。」
