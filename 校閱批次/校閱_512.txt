# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【512-0002】03_業疏/11a_卷二之五#18
【原文】如華手經：有四法轉身，即在善來比丘蓮華化生，現增壽命。一者、自樂出家，亦勸助人令欣出家；二、求法無倦，亦勸他人；三、自行和忍，亦勸他行；四、習行方便，深發大願，隨有功利，至時付引
【譯文】正如《華手經》說：有四種法門能夠轉變來世的身報，也就是能在善來比丘身邊於蓮花中化生，並且在現世增長壽命。第一、自己樂於出家，也勸勉助成他人令其欣求出家；第二、勤求佛法不知疲倦，也以此勸勉他人；第三、自己奉行和睦忍辱，也勸勉他人奉行；第四、修習推行善巧方便，深切發起廣大誓願，隨其所具有的功德利益，到機緣成熟時引導並付囑於他人。

【512-0003】03_業疏/11a_卷二之五#19
【原文】次科華手經，轉身即生報也。善來比丘，謂值佛得戒者。蓮華化生，即生佛淨土者。現增壽命，即現報也。下列四法：前三並自行勸他，後一即化他行願；正取初法，餘三連引。「隨下」囑令廣述。引付，謂引以付他
【譯文】第二科《華手經》，「轉身」就是指來世的生報。「善來比丘」，是指值遇佛陀而得受戒之人。「蓮華化生」，就是往生佛陀淨土之人。「現增壽命」，就是指現世的果報。下面列出四種法門：前三項都是既自己奉行又勸導他人，最後一項則是化導他人的願行；這裡正要取用的是第一法，其餘三法是連帶引用的。「隨下」是囑咐應當廣為宣述。「引付」，是指引導並付囑傳給他人。

【512-0004】03_業疏/11a_卷二之五#20
【原文】又如出家功德經：若能放人出家受戒，功德無邊。譬如四天下滿中羅漢，百年供養，不如有人為涅槃故，於一日夜出家受戒。謂猶前施雖多有竭，是欲界繫；為法出家，非三界業，故說過前。又云：縱起寶塔至忉利天，亦劣出家功德者。一時欣出，雖未可數，然其積微，是高勝本。前供無學，功德未多；後以供佛，情謂大勝；然終事供，淪歷下地，判非靜業，何有相勝
【譯文】又如《出家功德經》說：若能放任許可他人出家受戒，所獲功德無量無邊。好比四大天下之中遍滿了阿羅漢，以飲食供養他們百年之久，還不如有人為了證得涅槃的緣故，在一日一夜之中出家受戒。這是因為前者的布施功德雖然極多但終有窮竭之時，仍屬於欲界所繫縛；而為了求法而出家，則不屬於三界的有漏業，所以說超過前者。經中又說：縱使建造寶塔高達忉利天，其功德也比不上出家的功德。一時間欣求出家，其時間雖然微不足道，然而積聚微小之因，正是成就崇高殊勝果報的根本。前面供養阿羅漢無學聖人，功德尚且算不上最多；後面建造寶塔以供養佛陀，常情往往自認為極其殊勝；然而這終究只是事相上的供養，仍流轉沉淪於欲界下地，判定並非出離的清淨之業，又哪裡談得上勝過出家呢？

【512-0013】03_業疏/11a_卷二之五#29
【原文】第四示罪本中，初正示。言事縛者，即上四科，因之生罪，故為罪本。如下引示寶積，諸見即人、法兩執，利養謂所須四事。律緣，即舍利弗請佛制戒，佛言我自知時，未得利養，過漏未起；後須提那等，皆由利養豐盈，向道心薄，遂生過漏。故知名利，毀戒之緣；欲脫死生，深須遠離
【譯文】第四門開示罪業根本中，初段為正示罪本。所說的「事縛」，就是指上述四科，順著這些事相生起罪過，所以稱為罪本。如同下文引用《大寶積經》所開示的，諸見就是人我執與法我執這兩執，利養是指生活所必需的四事供養。律中制戒因緣，就是舍利弗曾請佛制戒，佛說我自知時機，在僧團未得利養之前，過失漏失尚未生起；後來須提那等人犯戒，都是由於利養豐盈，求道之心日漸淡薄，於是生起了過患漏失。所以得知，名利是毀犯戒律的助緣；若想解脫生死，深切必須徹底遠離。

【512-0014】03_業疏/11a_卷二之五#30
【原文】今世出家，翻種苦本，不畏沉溺，多起下業。故彼文云：又有三癕，謂求見他過、自覆己罪、向諸行者。知來實苦，決定現世不造苦因，如知火燒、湯爛，無有內手足者。佛說罪事，深宜遠離；以不信所燒，隨心造罪，更增俗人
【譯文】現在世上的出家人，反而種下了痛苦的根本，不怕沉淪溺陷，大多造作下劣的惡業。所以該經文說：又有三種癰瘡，就是求見他人過失、自己覆藏自己的罪過、以此向各位修行人發難（或求過覆罪以告知諸修行人）。若深知未來的果報確實痛苦，就應堅決在現世不造作痛苦之因，猶如明知烈火會焚燒、滾湯能燙爛，便沒有人會把手腳伸進去一樣。佛陀所說的犯罪之事，深應當徹底遠離；如今出家人若被不信之心所焚燒，隨心所欲造作罪業，罪惡反而比俗人更為增長。

【512-0015】03_業疏/11a_卷二之五#31
【原文】次造惡中初科，初傷時眾。業能生苦，故云苦本；出家脫苦，今既造業，故云翻種；下業即三途因。「故下」次引文示，即是寶積，前已標名故此略之。求他、覆己，於心為患，故喻癕瘡。「向下」三、正垂誡。初勸知果斷因。向，謂語告；內，猶入也。「佛下」次明違教造業。不信能喪善根功德，故如燒焉
【譯文】次造惡中的初科，首先哀傷當時的僧眾。惡業能生起痛苦，所以稱為「苦本」；出家本為脫離痛苦，如今既然造作業障，所以說是「翻種」（反倒種下）；「下業」就是墮入三途的惡因。自「故下」以下，其次引文開示，也就是《大寶積經》，前面已經標出經名，所以此處予以省略。求覓他人過失、覆藏自己的罪過，在內心成為禍患，所以比喻為癰瘡。自「向下」以下，第三為正式垂示誡勉。初段勸勉應當了知苦果而斷除苦因。「向」，是指告知；「內」，如同納入、伸入。自「佛下」以下，其次說明違背教誨而造罪。不信之惡能喪失善根功德，所以比喻為火燒。

【512-0016】03_業疏/11a_卷二之五#32
【原文】故十誦云：未來世中，出家人入地獄，白衣生天者，以俗人無法在身，但專信故得生天也；出家有法，為世福田，乃反毀犯，妄受信施，開諸惡門，令多眾生習學放逸故
【譯文】所以《十誦律》說：未來世中，出家人墮入地獄，在家人反而生天，這是因為俗人身上沒有受持戒法，只憑著專一的信心而得以生天；出家人身受戒法，作為世間的福田，卻反而毀犯戒律，虛妄受用信眾的布施，開啟種種惡門，使得許多眾生跟著習學放逸的緣故。

【512-0017】03_業疏/11a_卷二之五#33
【原文】次科十誦中，初引文；「以下」顯意。前明白衣生天，後明出家入獄。一、反道法，二、妄受施，三、令他習學；白衣無此，故昇沉異焉
【譯文】次科《十誦律》引文中，初段引用經律之文；自「以下」以下顯明其意旨。前面說明在家人升天，後面說明出家人墮地獄。出家人有三種過失：第一、違背道法；第二、虛妄受用布施；第三、引令他人習學放逸；在家人沒有這些過失，所以上升與沉淪截然不同。

【512-0018】03_業疏/11a_卷二之五#34
【原文】四分中，為說利養難消，六十比丘得無學也，六十比丘熱血從面孔而出，六十比丘畏佛語故便退還俗
【譯文】《四分律》中，佛陀為大眾宣說利養難以消受，致使六十位比丘證得無學果，六十位比丘熱血從面孔中流出，六十位比丘因為畏懼佛陀的話語而退道還俗。

【512-0019】03_業疏/11a_卷二之五#35
【原文】四分六十得果，即清淨者；六十流血，謂毀犯者；六十退道，即初入者
【譯文】《四分律》中六十人證得果位，就是戒行清淨的人；六十人面孔流血，是指毀犯戒律的人；六十人退還俗道，就是剛出家初入門的人。

【512-0020】03_業疏/11a_卷二之五#36
【原文】餘如涅槃「為利出家，驅逐淨行」等，廣亦如鈔
【譯文】其餘如《大般涅槃經》所說「為了利養而出家，驅逐修持淨行的人」等經文，詳細內容也如同《行事鈔》所載。

【512-0021】03_業疏/11a_卷二之五#37
【原文】涅槃中彼云：「我涅槃後，濁惡世時，多有為飢餓故發心出家，名為禿人。見有持戒威儀具足清淨比丘護持正法，驅逐令出，若殺若害。」若論罪行，且列五種，所謂貪欲、瞋恚、愛親、求利、慳嫉也。下指如鈔，並沙彌篇
【譯文】《大般涅槃經》中佛說：「我涅槃之後，在五濁惡世之時，會有許多人因為飢餓貧困的緣故發心出家，稱為禿頭之人。他們看見有持守戒律、威儀具足的清淨比丘護持正法，就將其驅逐令其離開，甚至予以殘殺戕害。」如果論述他們的罪惡行徑，暫且列舉五種，即所謂的貪欲、瞋恚、貪愛親故、追求利養、慳吝嫉妒。下文所指的「如鈔」，也是指《行事鈔》的〈沙彌別行篇〉。

【512-0022】03_業疏/11a_卷二之五#38
【原文】五、明出已乃行凡福
【譯文】第五門、說明出家之後卻修持凡夫的福業。

【512-0023】03_業疏/11a_卷二之五#39
【原文】凡出家者，出有為家；為解脫者，謂脫纏縛；此為本也。如五分說，不為解脫出家，不得名僧，次不受供
【譯文】凡是出家的人，是要脫離有為三界的牢家；所謂為了求取解脫，是指解脫種種煩惱的纏縛，這才是出家的根本。如《五分律》說，如果不是為了求得解脫而出家，就不能稱名為僧人，其次也不應當接受供養。

【512-0024】03_業疏/11a_卷二之五#40
【原文】第五釋中初文。出家求脫，經律通言，牒以釋之，示其行本。有為，總目三界；纏縛，且論二惑。下引五分，證知求脫乃名出家
【譯文】第五門解釋中的初段經文。出家追求解脫，是經藏與律藏共通的說法，此處引錄來作解釋，開示修行的根本。「有為」，是三界的總稱；「纏縛」，暫且指見思二惑。下文引用《五分律》，是為了證知唯有追求解脫才稱得上是出家。

【512-0025】03_業疏/11a_卷二之五#41
【原文】今有行者，但知持戒，無心在道。道在虗通，達累為本，此而不思，但持戒善，自餘講解、修習觀務，悉為非道，內多瞋忿，久汙淨心。此戒取結，謂為最勝；又是見取，體是欲界，增生下業
【譯文】如今有的修行人，只知道執守戒律，而無心專注於聖道。聖道的體性在於虛曠通達，以通達消除繫累為根本；修行人不思考這個道理，只知固守戒律善行，對於戒律之外的義理講解、修習禪觀等事務，全部認為不是正道，內心多生瞋恨憤怒，長久污染清淨自心。這屬於戒禁取見的結使，自以為最為殊勝；同時也是見取見，其本質仍局限於欲界，反而增長滋生下劣的生死惡業。

【512-0026】03_業疏/11a_卷二之五#42
【原文】次行相中初科，初敘持戒昧道。言虗通者，道之體也；言達累者，道之用也。餘為非道者，是此非彼也。內多瞋者，怒他不從己欲也。「此下」結示行果。凡夫具十使：貪、瞋、癡、慢、疑，五鈍使也；身見、邊見、邪見、戒取、見取，五利使也。今此執戒為勝，即二種結使煩惱耳。既無禪觀，未脫欲有，故是下業
【譯文】次行相中的初科，首先敘述持戒而蒙昧於聖道。所說的「虛通」，是聖道的本體；所說的「達累」，是聖道的作用。認為其餘皆為非道，就是自以為是而排斥非難他人。內心多生瞋恨，是因為憤怒別人不順從自己的意願。自「此下」以下，結示其行徑與果報。凡夫具足十種結使：貪、瞋、癡、慢、疑，是五種鈍使；身見、邊見、邪見、戒禁取見、見取見，是五種利使。如今執持戒律為最勝，正是這兩種結使煩惱。既然缺乏禪定觀照，未能脫離欲界的生存繫縛，所以屬於下劣之業。
