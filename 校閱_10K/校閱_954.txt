# 校閱材料　第954檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】用何羯磨，為是何事〔事復有三，即如鈔列。〕；復在何界。今此止明事中三耳，慎勿相濫。地約結界，衣謂攝衣。言具單者，此約一事容有相兼。準疏分七：三單如鈔。三複有三，一人法〔差比丘問法差受自恣等〕，二人事〔離衣杖囊差人行籌之類〕，三法事〔滅諍說戒修道自恣之類〕，具足一句〔滅諍行籌白云如是語者捉籌，唯此具三。〕。
【譯文】應當採用哪種羯磨，這究竟是屬於哪一類事〔事又分為三種，就如同鈔文所排列的。〕；又是在哪一個界限範圍之內。現在這裡只是說明「事」當中的三種情況而已，千萬不要相互混淆。「地」是指結界，「衣」是指加持攝受衣物。所謂「具單（具足或單純）」，這是就單一事務中是否容許兼帶其他法事來說的。準照律疏細分為七種：三種單獨的如同鈔文所列。三種重複的又分三種：一是人與法兼具〔例如差派比丘詢問遮法、差派接受自恣等〕；二是人與事兼具〔例如離衣杖囊、差人行籌之類〕；三是法與事兼具〔例如滅諍、說戒、修道自恣之類〕；具足一切的一句〔滅諍行籌時白告說『持有此等話語的人請拿籌』，唯獨這一種具足三者。〕。

【原文】差別之言，須通人處；文但明人；人分四位，隨事用舍，故云進止。選取堪能，秉御證正；已外隨喜，多少從之，故云優劣。然須更知處之差別。作法三種，自然六相；各攝分齊，竝如前篇。五中有二，初約上座勸勉。須下，約三業從順。如前即別眾中。六中二，初簡小眾。尼三同遣。

【原文】作舉謂僧中德人舉罪告僧。憶念謂指定時處，令伏首自言。證正謂能秉勘實。知法即所犯伏罪，法即是罪。〈僧網〉云：證正其罪，得伏方與是也。三竪標者，不應在八，疏云：若行事時，竪標第三；由竪標訖，然後集僧。今此相從唱相列之。第四可解。九中，初出問法。謂下，示問者。
【譯文】「作舉」，是指僧中有德之人舉發罪過並宣告僧眾。「憶念」，是指指定具體的時間與處所，令犯過者低頭自我招認。「證正」，是指秉法者核實勘查。「知法」，是指所犯之人承認屈伏於罪名之下，「法」就是指罪名。〈僧網〉中說「核實確定他的罪行，伏罪之後方可施行羯磨」，正是這個意思。第三種豎立標誌，本來不應當排在第八項，律疏說：如果是臨事行法之時，豎立標誌應該排在第三位；因為豎立完標誌之後，然後才召集僧眾。現在此處只是順隨宣唱界相而把它列於此。第四種容易理解。第九項之中，首先提出提問之法。「謂」字以下，開示提問之人。

【954-0007】資持記/02e_上一下#44
【原文】答雖多別，問無異辭。十中，上出答相。某即別事，羯磨是法。謂下，遮濫。然復須知總別兩答；言總答者，如受戒三單白、一白四，差教授時，總云受戒羯磨；餘之三法，竝不須問；捨墮自恣，類此可知。言別答者，四法別提，如云差教授師、單白羯磨等。結指中，上三句示通。若下，揀別。
【譯文】回答的內容雖然有很多差別，但提問卻沒有兩樣的文辭。第十項之中，上面提出回答的行相。「某」是指具體的事務，「羯磨」是指法度。「謂」字以下，用來遮止混淆濫用。然而又必須知道有「總答」與「別答」兩種形式：所謂總答，比如傳授具足戒時，包含了三個單白、一個白四羯磨，差派教授師時，總體上只回答「授戒羯磨」；其餘的三項法，全都不必逐一詢問；捨墮法、自恣法，以此類推便可知道。所謂別答，是將四種法分別提出，例如回答說「差教授師單白羯磨」等。在「結指（總結指歸）」之中，上面三句顯示共通的通則。「若」字以下，作特殊的揀別。

【954-0008】資持記/02e_上一下#45
【原文】結界無第七，受差無第八，此存古解，疏中則標有人言。又云結淨地不唱相，故云等也。疏云：今解竝須具之；結界無欲，立緣顯之；受差無乞，豈不須告；結淨不唱，此不尋文；律云：應唱房名，其事極顯等。又云對首心念，亦須具十；如受衣法：一、五大上色，義加不成；
【譯文】結界時沒有第七項（受欲法），受差派時沒有第八項（乞白法），這是保存古代舊有的解釋，律疏中則標註為「有人這樣說」。又說結淨地時不宣告四至界相，所以說是「等」。律疏說：現在的解釋是這十項全都需要具備；結界時雖然沒有受欲，但需設立事緣來彰顯它；接受差派雖然不必乞請，但難道不需要向僧眾告白嗎；結淨地不宣告界相，這是沒有深入研讀律文所致；律典說「應當唱出各房屋的名字」，那事情已經極為明顯了。又說面對面的對首法和心中默念的心念法，也必須具備十種緣；例如受持衣物之法：第一、不可使用五種正色與上色之衣，這是律疏依義理追加的規定，若違犯則法不成就；
