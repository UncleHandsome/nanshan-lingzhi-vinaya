以下按「明確該改」→「術語／漏譯」→「待考」→「參考修訂」四層來看。整體方向是對的，专名（婆論＝薩婆多論、見論＝善見論、母論＝毘尼母論）都認對了，但有幾處硬傷。

---

## 一、明確要改的地方

**1.「（贏為羸之誤）」——校勘注寫錯了**
原文作「不**徤**不**羸**人」，本來就是「羸」，沒有「贏」字。需要出注的是「**徤**」＝「健」的異體。這個括注方向反了，應刪改為「（徤，同健）」，並把「不健不羸」白話化為「體力不強壯也不瘦弱」。

**2.「與師持衣」——不是「和師父一起持衣」**
《十誦律》原意是**弟子為和尚（師）持衣**在道上走，師與持衣弟子前後相距四十九尋內，**師**不失衣。
原譯「與師父持衣在道路中行走」語意含混，建議：「（弟子）為師父持衣在路上行走，（師父與衣）前後四十九尋之內不失衣」。

**3.「以無勢分故（此界本就不加勢分）」——括注解釋失準**
前文才說「十一界各加勢分十三步」，這裡忽然說「本就不加勢分」，讀者會覺得自相矛盾。真正的理由是**扣回第一段的「染礙」**：村界因有男子而不攝衣，所以**沒有十三步的勢分可言**，衣必須貼身。
建議：「因為（村界有染礙、不攝衣）沒有勢分的緣故」。另「若界內有男子」宜補為「若（村）界內有男子」。

**4.「大小行在近處」——幾乎照抄，未白話化，且主語不明**
原譯「國王前來界內留宿，大小行（大小便）在近處，並非衣界」——讀者不知是誰在大小便、為何如此就非衣界。此句是「情礙」的例子，重點在**畏懼王勢、心不得自在，故雖同界亦成隔礙**。建議譯出因果並加「（）」補語，或注明待考（見第三節）。

**5.「四相」的譯法與下文「四相不圓」打架**
原譯「各有四種外相成就者」容易讀成「四個條件都要具備」；但四相中第二、第三明說「**不周**」，若四者須同時具足，「不周」本身就是相，邏輯不通。
「四相」應是**四種「圍相」（界定範圍的形態）**，「成／不圓」指界相是否成立、範圍是否確定。建議譯為「各有四種界相，界相成立（範圍確定）者……若四種界相都不成立（範圍不確定），則諸界各自生起」，並核對《資持記》《行宗記》再定。

**6.「一一犯捨墮」漏譯「一一」**
原譯只作「一一犯捨墮」照抄。須點明是「一一（各別情形／每件衣）各結一罪」。此處「一一」承上十一界，也可能指一一衣，宜出注說明。

**7.「便歸併成一個大界」——用詞易混**
「大界」是羯磨作法界的專名，此處講的是**自然界**，用「大界」會誤導。改「便合成一界」即可。

**8. 文言殘留，未真正白話化**
「若未捨會」「不至擲石所及處」「以情隔故」「不爾」「皆犯」「以無勢分故」等，都還是原文句子。至少要展開：
- 不捨會 → 未作法捨衣、也未（在明相出前）到衣處與衣相會
- 不至擲石所及處 → 人不在擲石所及的勢分範圍內
- 皆犯 → 都犯（失衣、捨墮）

## 二、術語與可補的注解

| 項目 | 建議 |
|---|---|
| 捨墮 | 首次出現應釋名：尼薩耆波逸提，須先捨衣再懺悔 |
| 五衣 | 補列比丘尼五衣：僧伽梨、鬱多羅僧、安陀會、僧祇支、厥修羅 |
| 受法 | 「已作法受持（成為受持衣）」 |
| 失想、奪想 | 「以為衣已遺失、以為衣被奪（心已不作己衣想）」 |
| 命難、梵行難 | 「危及生命的災難、危及清淨梵行的災難」 |
| 勢分 | 「界的勢力所及、向外延伸的範圍」——首次出現即釋，後文才好讀 |
| 尋／肘 | 一尋約八尺（張臂之長）、一肘約一尺半，宜加注 |
| 中人 | 「中等人」易誤讀，改「體力中等的人」 |
| 此律 | 首次標「本律（《四分律》）」 |
| 若干界 | 補「（表示界數不定）」 |
| 井界二十五肘 | 應說明是「以井欄為中心二十五肘的範圍內」，原譯「在二十五肘之內」無所依 |
| 脫衣服人家形露 | 「把衣脫下（留在）人家，以致赤身露體」語意較順 |
| 一腳在岸一腳入水 | 可補「（身與岸相連，衣在岸上）」說明何以不失 |
| 「即構成犯罪」 | 佛律語境宜作「即結罪／即犯戒」 |

另：六緣第六「明相出（天亮）時即犯」，「犯」是六緣具足後的結論，宜移到六條之後；編號「四、未作法捨衣」與其餘「一是／二是」體例不一致。

## 三、待考（建議查證後再定，不要硬譯）

1. **「王來入界住宿，大小行在近處」**：可讀作「（比丘畏王，）連到近處大小便都不敢，何況取衣」，也可讀作「（王的）大小便處設在近處，故該處不成衣界」。請核《薩婆多毘尼毘婆沙》原文，譯文暫加「（疑）」或出注。
2. **四相的「二籬柵不周、三籬牆不周」**：兩句句式重複可疑，宜核《行事鈔》《資持記》相關段落，確認是否文字有訛，或「不周」是「雖不周匝亦成相」之意。
3. **「一一犯捨墮」** 的「一一」指界或指衣。

## 四、參考修訂譯文（可直接對照修改）

> 離衣宿戒，須具足六緣才結罪：一是自己（受持）的五衣；二是此衣已作法受持；三是人與衣各在異處（不同界）；四是既未作法捨衣，也未在明相出前與衣相會；五是沒有律中所開的特殊因緣；六是明相出（天亮）。六緣具足，即犯捨墮（尼薩耆波逸提，須先捨衣再懺悔）。
>
> 「人衣異處」有四種差別：
>
> 第一是**染礙**：同一界內有男子，名為染礙。所以律中說：諸比丘把衣脫下留在人家，以致赤身露體；佛因此說：（結不失衣界時）應除去村及村外界。可見村界不攝衣，故名染礙。
>
> 第二是**隔礙**：本律（《四分律》）說，若因水路、陸路斷絕等無法前往取衣，雖離衣也不犯。
>
> 第三是**情礙**：本律說，若作遺失想、被奪想，或遇惡獸、命難、梵行難等因緣而離衣，不犯。《薩婆多論》說：國王進入界內住宿時，（比丘畏懼王勢、不得自在，）即使只是到近處大小便（也無法趨近衣處），該處都不算衣界——這是因為心有所忌憚而被隔絕的緣故。
>
> 第四是**界礙**：本律說自然衣界有十一種：僧伽藍界、村界、樹界、場界、車界、船界、舍界、堂界、庫界、倉界、阿蘭若界。其中僧伽藍界與村界各有四種界相；界相成立、範圍確定的，就不名為多界，因為僧伽藍界與村界界義強，能收攝其餘九界，合成一界。若這四種界相都不成立（範圍不確定），則諸界各自生起，便有十一界並存，所以律中說「若干界」（界數不定）。四相是：一、四周有完整垣牆；二、籬柵（雖）不周匝；三、籬牆（雖）不周匝；四、四周有房屋圍繞。
>
> 本律說：這十一界之外各加「勢分」（界力所及的延伸範圍），另有十三步。所以律中說：以體力中等的人擲石所及之處為準。《善見論》說：所謂「中人」，取不強壯也不瘦弱（徤，同健）的人，盡力擲石，以石頭落地處為準，不取滾動後到達之處。
>
> 若把衣放在這十一界內，自己卻在界外過夜，既未作法捨衣、未與衣相會，人又不在擲石所及的勢分範圍內，明相一出，一一（各別情形）都犯捨墮。
>
> 若（村）界內有男子，所持的衣必須貼近身邊，否則明相出即犯捨墮——因為（有染礙故村界不攝衣）沒有勢分的緣故。
>
> 又，其他部派所說衣界另有四種：
> 一、**道行界**：《十誦律》說，（弟子）為師父持衣在道上行走，前後四十九尋（一尋約八尺）之內不失衣；《薩婆多論》說縱橫四十九尋之內不失衣。
> 二、**洲上界**：《善見論》說，水中沙洲上十四肘（一肘約一尺半）之內不失衣；若洲上有人來往，衣須貼身，否則失衣。
> 三、**水界**：《善見論》說，比丘在阿蘭若處夜入池洗浴，未洗完明相已出（衣留岸上，人衣異界），犯捨墮；《毘尼母論》說，一腳在岸、一腳入水（身仍與岸相連），雖經明相出也不失衣。
> 四、**井界**：《僧祇律》說，行路時在露地井欄旁過夜，衣放在井欄周圍二十五肘之內，而身在此範圍外過夜，即失衣；或把衣放在井內、自己在井上過夜，既不以繩與衣相連，也不垂下手腳相接，明相出時都犯（捨墮）。
>
> 《明了論》說：行路夜宿時誤拿他人的衣離去，他人的衣（受持）不失，自己的衣（留在原處、人衣相離）則失。
