# 校閱材料　第141檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【141-0001】02_戒疏/10d_卷三上之一#111
【原文】【記】不犯中。初「五非」者，《律》有五非羯磨：一、非法別眾羯磨，二、非法和合眾羯磨，三、如法別眾羯磨，四、法相似別眾羯磨，五、法相似和合羯磨。「非法」、「非律」，並據秉法設諫為言。法雖不非，事乖軌度，故云「非法」。又非理折伏而非調攝，故云「非律」也。「不是聖說」者，出胸臆也。「破惡友」下，注中四節。初句指所破人，下三並彼所作事。言「破邪非法」，對注易見。「事緣」即僧、塔、和尚等作損減也。
【譯文】【記文】不犯的內容中。開頭所說的「五非」，是指《律》中所列的五種非法羯磨：一是非法別眾羯磨，二是非法和合眾羯磨，三是如法別眾羯磨，四是法相似別眾羯磨，五是法相似和合羯磨。「非法」、「非律」，都是針對秉法作羯磨進行規勸這件事來說的。作法程序雖然沒有違背，但所針對的事由違背了戒律準則，所以稱為「非法」。又如果是無端折伏而非為了調攝教化，所以稱為「非律」。「不是聖說」，是指全憑自己私心臆造出來的妄說。「破惡友」以下，注文包含四個分節。第一句是指被破壞的人，下面三句都是指那個人所做的事。說「破邪非法」，對照注文很容易明白。「事緣」就是指使僧眾、佛塔、和尚等受到損減破壞的事端。

【141-0004】02_戒疏/10d_卷三上之一#114
【原文】【疏】眾僧作法諫主之時，四伴影響助成破僧。僧尋設諫，拒而不受。故曰「助破違諫戒」也。
【譯文】【疏文】大眾僧依法作羯磨規勸主謀提婆達多之時，四位同黨像影子隨形、聲音相應一般協助促成破壞僧團。僧團隨即對其發起規勸，他們卻拒絕而不肯接受。所以稱作「幫助破僧違抗僧諫戒」。

【141-0005】02_戒疏/10d_卷三上之一#115
【原文】【記】十一，釋名，初科。「四伴」：一曰三聞達，二名騫茶達婆，三名拘婆離，四名迦留羅鞮舍。「影響」謂如形之影，如聲之響，言其相副應。
【譯文】【記文】第十一條，解釋戒名，第一科段。「四伴」：一名叫三聞達多，二名叫騫荼達婆，三名叫拘婆離，四名叫迦留羅鞮舍。「影響」的意思是如同形體之有影子、聲音之有回響，形容彼此緊密策應。

【141-0006】02_戒疏/10d_卷三上之一#116
【原文】【疏】有人言：「此名助惡遮僧不聽諫違諫戒。何以知然？故文云『諸大德，莫訶調達』，此遮僧也；乃至『我忍可』等，此助惡也。」
【譯文】【疏文】有人主張說：「這條戒的名稱應當叫作『助惡阻擋僧團不聽規勸違諫戒』。憑什麼知道是這樣呢？因為經文說『各位大德，請不要呵責提婆達多』，這就是阻擋僧團；乃至說『我們欣然認可』等語，這就是幫助行惡。」

【141-0007】02_戒疏/10d_卷三上之一#117
【原文】【記】古解中，初科。古謂此戒無破僧義，故以「惡」字替之。又闕「遮僧諫」義，故復加之。兩引文據，明非妄謂。
【譯文】【記文】古人見解中，第一科段。古人認為這條戒沒有直接破僧的內涵，所以用「惡」字來取代它。又因為缺少了「阻擋僧團規勸」的意義，所以又額外加上。接連引用經文作為依據，以證明不是自己妄加判定。

【141-0010】02_戒疏/10d_卷三上之一#120
【原文】【記】遮妨中，初問。戒文諫破，故須通之。答中。以前戒正諫破僧，此戒正諫遮諫。但由遮諫，意在壞僧，故文列之，非正諫事。
【譯文】【記文】消除疑難中，首先發問。戒文中明明是規勸其不要破僧，所以必須加以通融解釋。回答當中。因為前一條戒是直接規勸破僧，這條戒則是直接規勸其阻擋僧諫。只是由於他們阻擋規勸，其根本目的還是在於破壞僧團，所以經文中才順帶列出，這並非此處正受規勸的實體。

【141-0013】02_戒疏/10d_卷三上之一#123
【原文】【記】轉難中。前教不捨，亦是助惡，必如所立，亦應須諫。答約具闕，即彰兩異。
【譯文】【記文】轉入進一步問難中。前面教唆不捨棄，也同樣是幫助行惡，如果按照你所立的道理，那時也應當給予規勸。回答中以具備條件與缺少條件作對比，立刻彰顯了兩者的差別。

【141-0019】02_戒疏/10d_卷三上之一#129
【原文】【註】佛在羅閱祇。時，提婆達故執五法：盡形乞食，著糞掃衣，常受露坐，不食穌鹽、魚及肉。以教比丘。眾僧諫時，伴黨比丘助破諫僧。比丘舉過，佛訶責已，因制此戒。
【譯文】【註文】佛陀住在羅閱祇城。當時，提婆達多故意堅守五法：終生乞食、身穿糞掃衣、常常露天而坐、不吃酥酪與鹽、不吃魚與肉。以此來教導比丘。當大眾僧規勸提婆達多時，同黨比丘卻幫助破僧而反過來勸阻大眾僧。有比丘舉出這項過失，佛陀呵責之後，便因此制定了這條戒。

【141-0020】02_戒疏/10d_卷三上之一#130
【原文】【疏】就戒緣中。初、明調達執五法相，二、明伴黨比丘助破為緣。
【譯文】【疏文】在制戒緣起中。第一、說明提婆達多執持五法的相狀；第二、說明同黨比丘協助破僧來作為發起制戒的因緣。

【141-0021】02_戒疏/10d_卷三上之一#131
【原文】【疏】就前五法，「乞食、糞衣、露坐」，似佛四依，為相似語故。然不同四依開制託緣，此三調達說必盡形故。後二妄語者，調云「蘇鹽味重，魚、肉損生」，故立二斷也。調達云：「以此五法，為人說時，年少比丘，必多信受，上座長老，則不允從。」於王舍城創說之時，五百年少，一時信受。六十長老及阿難云：「此是非法，非毗尼，非佛教。」脫鬱多羅僧於一面。前已設諫，今猶復行。四伴順從，故又設諫。緣相如此。
