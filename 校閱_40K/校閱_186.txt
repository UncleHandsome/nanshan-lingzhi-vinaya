# 校閱材料　第186檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【186-0001】02_戒疏/18a_卷四上之三#103
【原文】【疏】凡食以充軀為用，多則長貪，少則廢道，事須量節。是以大聖審知凡報強弱不同，致有將補，五種位異：一、四分之一；二、一摶；三、一坐食；四、受小食；五、作餘食法。通須裁節，過則有損。今此比丘受正食已，須慎威儀，一坐飽足。為性輕懆，輙便後噉，長患廢業，又違教戒，故制。
【譯文】【疏文】大凡飲食是以充實滋養色身為功用，吃得過多就會滋長貪欲，吃得太少就會荒廢道業，凡事必須衡量節制。因此大聖佛陀審慎明察凡夫果報身體的強弱各有不同，因而有了調養色身與補救修持的規矩，共有五種不同的進食層次：第一、乞得食物只吃四分之一；第二、只吃手中能拿的一摶食物；第三、一坐吃完不再起食；第四、接受少許清淡點心（受小食）；第五、依照佛法行殘食作法（作餘食法）。這一切全都需要加以裁斷節制，過度了就會產生損害。如今這名比丘既然已經接受了正餐，就必須嚴謹維持威儀，在同一席位上吃飽滿足。卻因為生性輕躁，隨便又在飯後吃別的東西，滋長了貪患、荒廢了道業，這又違背了教導與戒律，所以制定本戒。

【186-0002】02_戒疏/18a_卷四上之三#104
【原文】【記】三十五，制意中三。初敘食利害。「是」下，二、汎敘開制。「將」謂開食使得資身，「補」謂制法令無缺行。「五」中，上三頭陀報強，下二中下報弱。又三、二中，各自相望，前強後弱，次列可尋。初即乞食，四依本制。《寶雲經》中，凡乞得食，分為四分：一、與同梵行，二、與乞人，三、與諸鬼，四、自供身。「一摶」不益，「一坐」不再，「小食」即粥及餘不正。上四汎明，五即當戒。「今」下，三、正顯今意，先明所應。「為」下，次顯不應。「長患」謂多貪，「廢業」由多事。「違教」因開法。
【譯文】【記文】第三十五條，在制戒意趣（制意）之中分為三點。首先敘述飲食的利害關係。從「因此（是）」字以下，第二是通盤敘述開許與制止的規矩。「將」是指開許進食使色身獲得資養，「補」是指制定法則使修行沒有缺損。在「五種」之中，前面三種適合修頭陀行、果報色身強健的人，後面兩種適合中等與下等、身體較弱的人。再者，在前三與後二之中，各自互相比對，也是前者強而後者弱，依序排列即可明瞭。第一種就是乞食，四依止法本來的定制。《寶雲經》中說，凡是乞食得到的食物，要分成四份：一份給同修梵行者，一份給乞丐，一份給鬼神，一份供養自己色身。「一摶」是指不再添加，「一坐」是指不再吃第二輪，「小食」是指吃粥以及其餘非正餐的流質食物。上面四種是通泛說明，第五種正是本條戒的焦點。從「如今（今）」字以下，第三是正式顯露當前的制戒意趣，先說明應當具備的規範。從「卻因為（為）」字以下，接著指出不應有的行為。「滋長禍患」是指過度貪婪，「荒廢道業」是由於事務紛雜。「違背教誡」是因為佛陀已經開立了餘食法卻不遵守。

【186-0005】02_戒疏/18a_卷四上之三#107
【原文】【註】佛在舍衛，說一食法。五種食中令飽足。後猶憔悴，佛言「聽瞻病者又食病人殘食」。又開「作餘食法」。有貪餮者，不知食法，因制此戒。
【譯文】【註文】佛陀駐錫在舍衛城，宣說了日中一食之法。要求在五種正食之中吃飽滿足。後來比丘們身體依然枯瘦憔悴，佛陀說「准許照料病人的人，也可以吃病僧吃剩的殘食」。後來又開許「行作餘食之法」。有貪吃嗜食的比丘，不懂得如法受食的法則，佛陀因而制定了這條戒。

【186-0006】02_戒疏/18a_卷四上之三#108
【原文】【疏】就戒緣中，從初至「作餘食法」來，明佛開諸比丘食緣。二、「貪餮」下，明起過也。「不知食法」者，隨不知足不足、正不正，具幾成、餘不成等也。
【譯文】【疏文】在戒律的緣起之中，從開頭到「作餘食法」為止，是說明佛陀為諸位比丘開許受食的各階段因緣。第二、「貪吃嗜食（貪餮）」以下，說明過失的產生。「不懂得如法受食」的意思，是指無論是不知道何為足食與不足食、何為正食與非正食，或者是不知道具備多少條件作法才算成功、欠缺什麼條件則作法不成等事。

【186-0007】02_戒疏/18a_卷四上之三#109
【原文】【記】釋戒緣中，分二。初段，注文少暗，疑是脫字。今依《律》示，凡有七節：初說「一食法」；二、由比丘形枯燥，聽一坐食；三、猶枯燥故，聽一坐食、五正食；四、病比丘不堪一坐，猶枯燥，聽數數食；五、開「瞻病食病人殘」；六、比丘以所舉食與餘人，從此始開餘食法食；七、比丘以所餘食與餘人，亦聽「作餘食法」食。第二段中，初總示。「餮」，音鐵，貪食也。「不」下，牒釋。「足正」二句，謂不知食境是非。「具幾」等者，謂不知作法成否。法有十五，故云「幾」也。
【譯文】【記文】解釋戒律緣起（釋戒緣）中，分為兩段。第一段，註文稍微晦暗，懷疑有脫漏的字句。現在依照《四分律》文指出，一共有七個演變節奏：起初宣說「一食之法」；第二、由於比丘形體乾枯消瘦，准許同一席位吃飽（一坐食）；第三、身體依然乾枯，准許一坐吃飽並受用五種正食；第四、生病比丘無法忍受一坐食，身體依然消瘦，准許一日之內分多次進食；第五、開許「看護病僧者吃病人吃剩的殘食」；第六、比丘將自己留存的食物給予其他人，從這裡開始開許行作餘食法而受食；第七、比丘將自己吃剩的殘食給予其他人，也准許「行作餘食法」之後受食。在第二段中，首先作總體提示。「餮」音同鐵，意思是貪吃。從「不懂得（不）」字以下，照錄並解釋經意。「足食與正食」兩句，是指不知道所食對象是非標準。「具備多少條件」等語，是指不知道作法的成敗標準。作法有十五種條件，所以說「多少（幾）」。

【186-0013】02_戒疏/18a_卷四上之三#115
【原文】【註】是中行、住、坐、臥，各作句數，犯足如《律》。佉闍尼食，有根、枝、葉、華、果、油、胡麻、黑石蜜、磨細末食。彼比丘足已，不作餘食法，得而食之，咽咽墮。若食已，為他作；若知他足食已，作；自手捉食作；持食置地作；使淨人作；淨人前作；以不好食覆上作；若持去——並不成餘食法，吉羅。尼等四眾吉羅。不犯者：食作非食想；不受餘食法；並反上制文；若病不作法；病人殘食不作餘食法；若已作餘食法，無犯。
【譯文】【註文】這當中無論是走著、站著、坐著、躺著，各有句數的組合，構成違犯的條件詳如《四分律》。雜食（佉闍尼食），包括植物的根、莖、葉、花、果實、油脂、胡麻、黑石蜜、研磨細末的食物等。那位比丘吃飽之後，不作餘食法，拿來吃的話，每咽下一口就結一次墮罪（波逸提）。若是自己已經吃飽，卻替別人作法；或是明知對方已經吃飽，還向他作法（以他為對象作法）；自己親手拿著食物作法；拿著食物放在地上作法；指使未受戒的淨人去作法；在淨人面前作法；用不好的劣質食物覆蓋在上面作法；或者拿著食物走開——這些都不能成就合法的餘食法，犯突吉羅罪。比丘尼等其餘四眾犯突吉羅罪。不犯的情況：把食物當作不是食物想；無須接受餘食法者（受持頭陀行而不受餘食法之人）；一切與上述違制條文相反的清淨情況；若是生病不作法也可以吃；吃病人吃剩的殘食不需要作餘食法；若是已經依法行作了餘食之法，皆不犯戒。

【原文】【記】釋作法中。初點示文意。「就」下，牒釋。八相四對，並以兩字分之。初為他所對，不能自知，即是「愚」也。二、求他為對，不知簡境，故云「暗」也。三、手持不放，故「恭」。四、懶持置地，故「慢」。五、使淨人，即遣「俗」作。六、淨人前，即對「道」作，但在俗前，故不合耳。七、以惡覆好，能作「慳」也。八、與彼持去，所對「貪」也。「就」下，總簡，即《律》自判。「非儀吉」者，據論作法，眾、別羯磨，通須遠俗。所以俗聽眾法對、念，則成障戒，別法方開，制不使聞，於義明矣。況此餘法，事非少欲，若對俗前，必生忽易，故特別制，違則乖儀。
