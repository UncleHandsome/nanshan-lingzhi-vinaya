# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【53-0006】01_行事鈔/07d_卷中之三#23
【原文】過量床足戒八十四。五緣：一是床，二僧床及已，三過量，四自作使人，五作成便犯。本為截者，不截方犯。律云：高如來八指。《多論》：木床高大悉犯，俗人八戒亦同。八指者，一指二寸，姬周尺一尺六寸，唐尺一尺三寸彊。《五分》：得高床施，先作念截却，得受；不爾者墮。《僧祇》：僧床亦犯。恐施主嫌者，木筩盛脚埋之。乃至截脚木還搘床脚亦犯，隨坐起一一墮。若下濕處，用八指木搘脚得。若俗家高床不犯。《十誦》云：截竟，僧中懺罪。八指者，用我指量，第三分入梐。準此，《十誦》疏家以八寸為量，四等分之。又云：長床極小容四比丘坐處；臥床過三肘。降四歲共坐，若減不得坐。床長一肘半，得二人共坐。床搘不得過八指。《四分》不犯者：去地八指，若減，若脫脚，無犯。
【譯文】過量床足戒八十四。構成犯戒有五種因緣：一、物品是坐臥之床；二、屬於僧團公有之床或自己的私床；三、床腳超過法定尺寸；四、親自製作或指使他人製作；五、製作完工便結犯墮罪。如果原本就是打算做好後截除超長部分的，則在不截斷而直接使用時才算犯戒。律中說：床腳高度不得超過佛陀的「如來八指」。《薩婆多毘尼毘婆沙》說：木床過於高大全都犯戒，在家人受持八關齋戒時也是如此。所謂「八指」，按如來一指相當於常人二寸計算，折合周朝姬周尺為一尺六寸，折合唐尺為一尺三寸強。《五分律》說：得到施主布施的高床，必須先在心中作念打算截短它，方可接受；如果不作截短之念而直接接受使用，結犯墮罪。《摩訶僧祇律》說：僧團常住的床若過量也同樣犯戒。如果擔心截短床腳會引起施主不悅譏嫌，可以用木筒套住床腳將其埋入地下以降低高度。乃至如果把截下來的床腳木塊又拿來墊在床腳下墊高，也是犯戒，每次坐起都一一結犯墮罪。如果是地勢潮濕低窪之處，用不超過八指高的木塊墊在床腳下是可以的。如果在俗人居士家裡坐高床則不犯此戒。《十誦律》說：截短床腳完畢之後，應在僧眾中懺悔罪過。所謂「八指」，是以佛陀自身手指為準，其中第三等分（最上一分）是嵌入床梐（床框卯榫）之內的。依照這個說法，《十誦律》的義疏註家以八寸為總度量，並將其四等分折算。又說：長床的最小規格應能容納四位比丘同坐；臥床則是長度超過三肘；這兩類大床開許戒臘相差在四歲以內的比丘同坐；若年資差距超過四歲（長幼尊卑懸殊），則不得同坐。床若長一肘半，可以容納兩人同坐。墊床腳的支撐物高度不得超過八指。《四分律》規定不犯的情況：床底距離地面正好八指高、或者低於八指、或者卸去床腳直接鋪在地上，都不犯戒。

【53-0007】資持記/10d_中三下#1
【原文】第二啟白喚召兩緣，不白非犯。釋第四。《十誦》三處不白，初即聚落中僧坊。注簡尼寺，同俗舍故。本住處謂所居寺。初緣《四分》中，初釋非時。不下，示犯相。若下，明白緣。第三，初科。《十誦》開四衢者，住處無人，出街求也。發心去者，衢中復無，擬道逢也。
【譯文】第二科說明啟白與呼喚兩項條件，如果不需稟白的情形則不構成犯戒。以下解釋第四條。《十誦律》指出有三種處所不須啟白，第一種就是村落中的僧坊。夾注中特別排除比丘尼寺，因為尼寺與在家人房舍性質相同。所稱本住處，是指自己平時居住的寺院。在第一項條件中引《四分律》，首先解釋何謂非時。從「不」字以下，展示犯戒的具體相狀。從「若」字以下，明列稟白的相關條件。第三條，第一小科。《十誦律》開許在十字街頭啟白，是因為原住處沒有僧人，所以出門到街市尋覓。發心前去啟白，是指街市中也沒有人，打算在路上巧遇時稟白。

【53-0008】資持記/10d_中三下#2
【原文】白三眾者，道中又無，開別類也。疏云：淨人亦得。知其去處，有可尋求。次科《僧祇》，初明非時。不必中後，時內亦犯。急於本宗。作下，引示白法。準《羯磨》云：長老！我非時入聚落，至某城邑聚落某甲舍。〔依此誦之。〕若下，制其遲迴。道從聚過者，如今通街店也。中有塔廟，不得旋迴，開中制也。三中。
【譯文】向沙彌等三眾啟白，是指連路上都沒有比丘，因而開許轉向其他同類眾人啟白。《戒疏》說：向淨人稟白也可以。只要知道對方的去向，有跡可循即可。下一小科引《僧祇律》，首先說明非時的界定。不一定要到中午過後，只要在正時之內也有可能犯戒。這比本宗的規定更為嚴格。從「作」字以下，引文展示啟白的方法。依據《羯磨疏》說：大德！我於非時進入聚落，前往某座城邑聚落的某人住宅。〔應依此文誦白。〕從「若」字以下，制止在途中拖延徘徊。道路穿過聚落，就像現今貫穿街市的店家。途中若有塔廟，不得流連盤桓，這是於開許之中所作的限制。以下是第三項。

【53-0009】02_戒疏/02b_卷一上之二#91
【原文】【記】三中，二義。初句標喻，「顯」下，法合。初除現生貧苦，止惡積善故「不貧」，人天聖道故「無苦」。「交」，俱也。次義中，標喻法合，亦如上分。凡聖兩報，由戒資成，世出世別，故分「近遠」。「斯」下，雙結。
【譯文】【記文】在第三個層次中，包含兩種含義。首句標出譬喻，「顯」字以下，以法來會合譬喻。第一種功能是拔除現世的貧窮困苦，止惡積善所以「不貧」，獲得人天尊榮乃至解脫聖道所以「無苦」。「交」，就是都、俱備的意思。在第二種含義中，標出譬喻並以法會合，劃分方法也如同上面所述。凡夫的善報與聖人的道果，全都依賴戒律來資養成就，世間與出世間既然有別，所以劃分為「近果與遠果」。「斯」字以下，對這兩種功用進行雙重總結。

【53-0010】02_戒疏/02b_卷一上之二#92
【原文】【疏】問：「如經論說，海喻多種，今此偈中止列二者？」
【譯文】【疏文】提問：「正如經論中所說的，大海的譬喻有多種，如今這首偈頌中為何僅僅列出這兩種？」

【53-0011】02_戒疏/02b_卷一上之二#93
【原文】【記】問中。「多種」者，海有八德：一、漸深漸入；二、潮不過限；三、不宿死屍；四、百川來會，無復本名；五、萬派悉歸，而無增減；六、出眾珍寶；七、大身眾生所居；八、同一醎味。《戒本》上句可配初德，次句對第六，旁兼「清澄」，即是第三。欲顯戒文出二之意，故問申之。
【譯文】【記文】在提問的設問中。「多種」的意思，是指大海具備八種功德德行：第一、海水漸次深邃；第二、潮水漲落不逾越界限；第三、海中不住留死屍；第四、百川百河匯聚而來，不再保留原本的名字；第五、萬條江河悉數歸入，海水卻不增不減；第六、孕育出眾多奇珍異寶；第七、極大體型的巨海眾生所棲居；第八、海水皆具備同一種鹹味。《戒本》偈頌的第一句可以配屬第一種德行，第二句對應第六種德行，旁側兼具的「清澄」含義，就是第三種德行。為了顯發《戒本》偈文單單列出這兩項的深意，所以設立問答來加以申述。

【53-0012】02_戒疏/02b_卷一上之二#94
【原文】【疏】答：「作者知時，明喻舉要。初明深廣清澄喻，顯說戒儀專被行淨，如有纖過，非聽說之儀也。是以今初開宗，即明簡眾喻。眾成由行，能懷聖寶，故次辨求無厭喻。此二攝化始終，餘非要務，故略不敘。」
【譯文】【疏文】回答：「造論者通達時機，明智的譬喻當擷取精要。首先闡明深廣澄清的譬喻，是為了顯明宣說戒律的儀軌，專門是為了加被身心行持清淨的僧眾，如果有絲毫的過失，就不得參與聽說戒律的儀軌。因此如今開宗明義，一開始就以大海譬喻來簡別淘汰僧眾。僧團的成就仰賴於戒行的清淨，能懷抱如上的聖道珍寶，所以緊接著辨明如求寶無厭的譬喻。這兩種譬喻已經將化導攝受的始終完全包攬，其餘的並非當務之急，所以省略而不贅述。」

【53-0013】02_戒疏/02b_卷一上之二#95
【原文】【記】答中。初歎美部主。「初」下，次正申所以。前明「無涯」喻，「深廣」、「清澄」，兼含兩義。「眾成」下，次示「求寶」喻。「此二」下，正通來問。前喻眾行，後喻自行；說戒攝僧，要唯此二故也。
【譯文】【記文】在回答的文句中。首先讚歎部派教主之宏才。「初」字以下，接著正面申明其緣由。前面闡述「無涯」的譬喻，「深廣」與「清澄」兼含了這兩層含義。「眾成」以下，接著開示「求寶」的譬喻。「此二」以下，正面解答來問。前面的譬喻對應大眾的集體行持，後面的譬喻對應自身的個別修行；說戒法事用以攝持僧團，其要點僅僅在於這兩方面而已。

【53-0014】02_戒疏/02b_卷一上之二#96
【原文】【疏】就法說中。初舉喻益，勸護聖財；後明體不虗圓，必假說聽之力。方便攝持，名之為「欲」；對治行成，非緣不起，名之為「護」。戒德內充，資神養聖，目之為「財」。「財」即道品，恐濫於世，故云「聖法」。合上「寶」也。
【譯文】【疏文】在以法義直說的文句中。首先舉出譬喻所帶來的利益，勸勉眾人應當護持這殊勝的法財；其後闡明戒體不會憑空圓滿，必須假借宣說與聆聽的力量。以方便善巧攝持戒心，稱之為「欲（願求）」；對治煩惱的行持得以成就、非適宜之緣境不起現行，稱之為「護」。戒律的功德充滿內在，資養心神並長養聖道，稱之為「財」。「財」就是指三十七道品，因恐懼與世間財物相混淆，所以稱為「聖法」。這正對應了上面的「珍寶」譬喻。

【53-0015】02_戒疏/02b_卷一上之二#97
【原文】【記】次法說，勸護中，初文。「欲」、「護」二字，即是能持始終二心。「神」即心神，「聖」謂聖道。
【譯文】【記文】接著以法說勸勉護持的文句中，這是第一段。「欲」與「護」這兩個字，就是指能夠持戒的發端與持續這二種初心。「神」就是指心神，「聖」就是指聖道。

【53-0016】02_戒疏/02b_卷一上之二#98
【原文】【疏】所以不合初喻者，前顯戒體，量周無際；後顯多寶，充足所求。求在無限，終從戒海，故所出之寶無窮，則知能生之海無際。是則聖財通於三道，欲護聽眾，亦被三乘。若作此解，具兼兩喻。
【譯文】【疏文】之所以不單獨去會合最初的大海譬喻，是因為前面已經顯發了戒體的廣大、周遍無際；後面則顯發了戒寶的多樣，能充分滿足一切祈求。既然求索無限，終究是源於這座戒海，所以由它出產的珍寶無窮無盡，由此便可知曉那能孕育珍寶的大海是多麼浩瀚無際。這就說明聖道法財通貫諦、緣、度三道，想要護持法財的聽戒大眾，同樣也涵蓋了三乘行者。如果做這樣的理解，就能完全兼顧這兩種譬喻了。
