# 校閱材料　第127檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【127-0001】02_戒疏/20a_卷四下之二#151
【原文】【記】定量中。「俗人八戒」，亦同僧制。「周尺」一尺六寸，「當今一尺三寸」，即唐尺也。以一尺二寸為唐一尺，以三寸六分為三寸，更餘四分，故云「許」也。下指《僧祇》，雖是「僧床」，亦兼己分，造者犯提，餘人應吉。
【譯文】【記文】訂定尺度規格之中。「在家人八戒」，也是等同於僧人的規矩。「周尺」的一尺六寸，「折合現在的一尺三寸」，指的就是唐尺。因為以周尺一尺二寸折為唐尺一尺，周尺三寸六分折為三寸，還剩下四分，所以說是「一尺三寸許」。下文指出《僧祇律》的說法，雖然是「僧團公有床」，但也包含了自己受用的份額，親手製造者犯波逸提罪，僧中其餘大眾應當結突吉羅罪。

【127-0002】02_戒疏/20a_卷四下之二#152
【原文】【註】佛在舍衛。迦留陀夷預知佛從此道來，即於道中敷高好牀，白言：「看我牀座！」佛言：「當知癡人內懷弊惡。」集僧訶責，因制此戒。
【譯文】【註文】佛陀住在舍衛國。迦留陀夷比丘預先知道佛陀會從這條路經過，便在道路中央鋪設了高大精美的床鋪，稟白說：「請看我的床鋪坐具！」佛陀說：「當知這個愚癡之人，內心懷抱著卑劣與罪惡。」佛陀召集僧眾喝責他，因而制定了此戒。

【127-0005】02_戒疏/20a_卷四下之二#155
【原文】【註】若自作、教他作，成，過，犯墮；若不成，若為他作，一切吉羅。尼同犯。不犯者：若作足高八指，若減；若他施，截而用之；若脫脚者。
【譯文】【註文】如果自己動手做、指使他人做，做成了且尺寸超標，犯墮罪（波逸提）；如果未做成，或者是替他人製作，全都犯突吉羅罪。比丘尼同犯此罪。不犯戒的情況：如果製作的床腳高度正好八指，或者低於八指；如果是他人布施的，將床腳鋸斷截短後再使用；或者是床腳已經脫落者。

【127-0007】02_戒疏/20a_卷四下之二#157
【原文】【記】戒本。第二句，注「五種如上」，即前露敷戒中。「除入梐孔上」，謂入孔栒頭，不在數也。「截竟」者，究竟成也。
【譯文】【記文】戒本。第二句，注文所說的「五種如同上述」，就是指先前露天鋪設臥具戒中所說的內容。「除去卡入孔洞的上端部分」，是指插入榫孔的木榫頭，不計算在八指的限度之內。「截切完成」，是指床腳徹底完工製成。

【127-0008】02_戒疏/20a_卷四下之二#158
【原文】【疏】所以不得約人用尺者，諸國法各不同，俗情又異。但準佛為定，以此定量，則之永無乖異。餘如「房戒」中。
【譯文】【疏文】之所以不能依照一般常人的手指作為尺規標準，是因為各國的制度尺度各自不同，世俗民眾的身材長短也有差異。唯有以佛陀的身量作為定則準繩，以此來規定尺寸標準，依此為依據就永遠不會產生歧異與爭端。其餘詳情如同「造房戒」中所解釋。

【127-0009】02_戒疏/20a_卷四下之二#159
【原文】【記】釋佛指中。「諸國不同」，謂尺寸有長短也。「俗情異」者，各執一端，容生諍也。「但準佛」者，佛唯有一，身量常定，可準的故。所以前後諸戒「搩指」並取佛也。
【譯文】【記文】解釋依佛手為標準的深意。「各國不同」，是指尺寸長短各異。「俗情各異」，是指每個人執持自己的標準，容易引發爭論。「唯有以佛為準」，是因為佛陀的身量常住標準、獨一無二，足可作為精確的依歸。因此前後各條戒律中所說的「搩手、指量」，全都是以佛陀的身量為準。

【127-0096】02_戒疏/20b_卷四下之二#43
【原文】【記】次難。答中，初以義分。衣體既同，量容有濫，鉢體既別，義無濫故。私釋：衣不制體故制量，鉢不制量故制體，比丘不得畜石鉢，當知衣鉢二並無濫。「智」下，引示體別。以佛畜石鉢故。初明佛畜意。彼云四天王四山頭自然生石故，石細不受膩。《本起經》云：「四王各取上佛，佛總受累左手中，右手按之，四際分明。」次明比丘不得意，有三：一、石麤；二、無感；三、體重。「不同」下，釋疑。既云體重，佛何以持？假令佛有力者，阿難為佛侍者，亦能持之？故此釋通，方顯比丘不得畜意。「那羅延」，此云金剛，亦云鉤鏁力士。
【譯文】【記文】第二個問難。答覆中，先以義理分析。衣服的質地既然相同，尺寸就容易混濫；缽的材質既然根本不同，義理上就沒有混淆的可能。私下解釋：衣服不限制材質所以限制尺寸，缽不限制尺寸所以限制材質，比丘不能蓄持石缽，可知衣與缽兩者都不會有混濫之虞。「智」字以下，引經證示材質差別。因為佛陀蓄持石缽。先說明佛陀蓄持的意旨。經中說那是四大天王各從山頭取自然之石，所以石質細潤不沾油脂。《修行本起經》說：「四天王各取石缽獻佛，佛陀總合置於左掌中，右手一壓，四缽合成一缽而四道外緣分明。」次說明比丘不得持石缽的意旨，有三個原因：一、石質粗糙；二、無福感應；三、質地沉重。「不同」以下，釋除疑難。既然說石缽沉重，佛陀何以能持？即便佛陀有神力，阿難身為佛的侍者，何以能持？所以此處予以通釋，方能顯出不准比丘蓄持的真正用心。「那羅延」，譯為金剛，也稱為鉤鎖力士。

【127-0111】02_戒疏/20b_卷四下之二#58
【原文】【疏】先就內中，不過私、眾兩所。初戒在屏者，比丘與尼，法服是同，男女位別，理須離染，躬在聚落，自手取食，容生染譏，對離此過，故在初制。又在眾中，偏心指授，迹涉曲私，默受不訶，於眾不顯，對離此過，故制第二。
【譯文】【疏文】先從僧尼內部來說，不外乎私下與眾中兩種場合。第一條戒之所以屬於屏處（私下）的情形：比丘與比丘尼同樣穿著法服，但男女身分有別，理應遠離染污；如今親身進入聚落，親手從尼手中取食，容易生起染污的譏嫌，為了對治、遠離這種過失，所以列為第一條戒。又在眾人之中偏私地指示分配，行迹涉及曲私，大眾默然接受而不訶責，在眾人面前不能表明清白，為了對治、遠離這種過失，所以列為第二條戒。

【127-0113】02_戒疏/20b_卷四下之二#60
【原文】【疏】託外起非，不過聚落、蘭若。聚落起者，學家過受，令他竭盡，招致譏過，故制第三。蘭若起者，比丘懈惰，在於逈險，安坐受食，使賊嬈觸送食婦人，招致譏過，對離此失，故制第四。
【譯文】【疏文】依託外境所生起的過失，不外乎聚落與蘭若（寂靜處）。在聚落中生起的：對「學家」（已見諦的在家弟子）過度受食，使他財物竭盡，招致譏嫌過失，所以列為第三條戒。在蘭若中生起的：比丘懈怠懶惰，身處遙遠險僻之處，安坐而受食，致使盜賊騷擾、侵犯送食的婦人，招致譏嫌過失，為了對治、遠離這種過失，所以列為第四條戒。

【127-0124】02_戒疏/20b_卷四下之二#71
【原文】【疏】言二持者。見尼指授，止而不食，身止持也；見過訶責，後食無罪，身作持也。此之名體各別，所以如上。又解：見尼指授，依法而訶，不越教約，語止持也；訶而不止，後食無過，身口作持。
【譯文】【疏文】所謂二持：看見比丘尼偏私指授，停下來不吃，這是身止持；看見過失而訶責，之後再吃沒有罪，這是身作持。這些名稱與體相各有不同，其所以然如上所說。另一種解釋：看見尼指授，依法訶責，不超越佛陀的教誡約束，這是語止持；訶責之後尼仍不停止，之後再吃沒有過失，這是身口作持。

【127-0125】02_戒疏/20b_卷四下之二#72
【原文】【記】第四門，初雙持犯，二持中又二。初身二持。食屬身業，呵屬口業，故兩分之。止、作是「名別」，食、不食即「體別」。言「如上」者，前諸篇中一一破古，故通指之。「又」下，次口二持，易解。
【譯文】【記文】第四門，先論雙重持犯，其中二持又分二段。第一種是身體的二持。進食屬於身業，訶止屬於口業，所以將兩者分開。止持與作持是「名稱不同」，食與不食即是「體質不同」。說「如上」者，指前面諸篇中一一破斥古人誤解之處，因此通括指之。「又」以下，次論言語口業的二持，容易理解。
