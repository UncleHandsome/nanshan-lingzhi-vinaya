# 校閱材料　第195檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【195-0001】02_戒疏/08c_卷二下之一#95
【原文】【記】牒釋，制意中。敘過有四：初至「已證」，明竊法過；「惑」下，即誑人過；「希」下，邪求過；「曀」下，滅法過。「冐」，覆也，覆其所無，妄云已有。「曀」即昏暗。「罔」謂誣罔。「過」下，總結。
【譯文】【記文】在開示提調、解釋「制戒意圖」的文句中：敘述其罪過共有四點：從開頭至「已證」，指明其盜竊冒充佛法之過；從「惑」字以下，即是指其欺瞞大眾之過；從「希」字以下，指明其心懷邪念貪求名利之過；從「曀」字以下，指明其滅壞障蔽正法之過。「冐」是掩蓋覆蓋之意，掩蓋自己一無所有的實情，反過來虛妄自稱早已證得。「曀」就是昏暗幽蔽之意。「罔」就是誣陷欺瞞。「過」字以下，總括作結。

【195-0003】02_戒疏/08c_卷二下之一#97
【原文】【記】答：「四戒皆重，何有優降？但各專一義，互望為劣。如淫障道之極，餘三則輕。盜則違惱，殺損道器，妄取罔時。準上相比，義亦可解。」
【譯文】【記文】回答：「四條重罪皆屬極刑，哪裡有孰優孰劣的等差？只是每一條戒各自偏重於一個層面的極端過患，相互比照時便各見輕重。好比淫戒是障礙修道之至極，其餘三戒在此點上則較輕；盜戒是嚴重侵犯惱害他人財產；殺戒是殘害毀滅修道的清淨身心之器；妄語戒則是自欺欺人、欺蒙世間障蔽正法。依照上述原則互相參照比對，其義理自然便能冰釋了。」

【195-0006】02_戒疏/08c_卷二下之一#100
【原文】【疏】如昔解云：「言非稱實，名之為妄。妄說聖德，事超凡境，故云『過人法』。言『過』有二：過凡至聖，過欲至色。以此二法，同誑於人。故曰『妄說過人法戒』。」
【譯文】【疏文】正如古德舊解所說：「言語不能如實相稱，稱之為妄。虛妄宣稱自己證得超凡聖德，這項事態已超越了凡夫境界，所以稱為『過人法（超凡人之法）』。所謂『超越』包含兩種意涵：一是超越凡夫階位而證達聖者果位，二是超越欲界粗濁而證得色界禪定。若以此二種殊勝之法來欺騙大眾，便犯此戒。所以古代將本戒命名為『妄說過人法戒』。」

【195-0007】02_戒疏/08c_卷二下之一#101
【原文】【記】引古中。彼立戒名，云「妄說過人法戒」，故作此釋。二義釋過：上即據位，如說初、二果等；下乃約界，如說四禪、四空等。
【譯文】【記文】在引用古說的文句中：古代律師建立這條戒名時，直接命名為「妄說過人法戒」，因此作出了這種解釋。此處以兩種義理來解釋「過（超越）」：前半段是依據修證果位來論，好比宣稱證得初果、二果等；後半段則是依據三界層級來論，好比宣稱證得四禪天、四無色界定等。

【195-0008】02_戒疏/08c_卷二下之一#102
【原文】【疏】問：「何以但言『過人法』，不云『過天』者？」
【譯文】【疏文】提問：「為什麼戒文中只稱『過人法（超越凡人的法）』，而不稱『過天法（超越天人的法）』呢？」

【195-0009】02_戒疏/08c_卷二下之一#103
【原文】【疏】答：「如《多論》解，佛在人中結戒，故人中有木叉。多修善法，入道勝天。但云勝人，已過天故。又勝人以罪重，天故無所論。」
【譯文】【疏文】回答：「如同《薩婆多論》的解釋，佛陀是在人道之中示現成道並制定戒律的，所以人道之中才有別解脫波羅提木叉。人類勇猛修習善法，其悟道入道的潛力遠遠勝過貪戀天樂的諸天。因此只要宣稱超越人類，其層次本就已經凌駕於諸天之上了。再者，自稱超越凡人所招致的欺騙之罪已至重至極，超越諸天之說自然更不在話下，無需贅述。」

【195-0010】02_戒疏/08c_卷二下之一#104
【原文】【記】問答中，《多論》三義釋之。初約制戒釋。「多」下，次約人勝釋。諸天著樂，多不修善，劣於人故，但言「過人」。「又」下，三、約比況釋。謂過人已重，何況過天？理必可知，故云「無所論」也。
【譯文】【記文】在問答的文句中，《薩婆多論》共運用了三層義理來解答。第一是依循佛陀制戒的處所來解釋。從「多」字以下，第二是依據人類修道的殊勝來解釋；諸天耽溺著於世俗禪樂，大多不肯精進修習出世善法，在入道解脫上遠遜於人類，所以戒條只明言「超越人類」。從「又」字以下，第三是以比喻況顯來解釋；意思是宣稱超越人類罪過尚且已極重無比，更何況是宣稱超越天人？其常理自然必然可知，所以說「無所論（無需再論）」。

【195-0011】02_戒疏/08c_卷二下之一#105
【原文】【疏】三、釋成犯緣，具九：一、前境是人；二、作人想；三、誑境是虗；四、知已境虗；五、誑他心；六、說過人法；七、自言已證；八、言章明了；九、前人知解。

【195-0015】02_戒疏/08c_卷二下之一#109

【譯文】【疏文】如果缺乏第二項條件（失去是人的正確認知）：隨意泛泛而說（漫心）的轉念想像有三種句型，鎖定特定目標（剋心）的轉念想像有四種句型，因為另外加入了對特定對象之人（或王、人境想）之轉想的緣故。泛泛而說辨析心中存疑有六種句型，鎖定對象辨析心中存疑有十種句型。若是「前境非人」與「想心偏差」兩項條件同時缺乏，可衍生出四十種句型。推演立句的方法全與前文相同，易於通達明瞭。

【原文】【疏】「人法」者，下列「陰界入」也。古翻經者，謂「積聚」是「陰」義。撿諸字書，無此訓故。今世所翻，改「陰」為「蘊」，不可怪也。如古改「陰」為「眾」，可以通之。
【譯文】【疏文】所謂「人法」，下面列出「陰、界、入」。古代翻譯經典的人，認為「積聚」是「陰」的字義。查閱各種字典字書，並沒有這種訓詁。現今時代所翻譯的，把「陰」改為「蘊」，不足為怪。就像古代把「陰」改為「眾」，也是可以通融的。
