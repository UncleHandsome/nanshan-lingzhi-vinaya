# 校閱材料　第1015檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1015-0001】資持記/04c_上三#60
【原文】必希進趣，當復從師；此則無簡愚智，皆須盡壽也。律下，引證。可知。通諸教者，即《涅槃》文。又《成論》云：佛初成道，觀一切人無勝己者；念言：我所得法，因此成佛，還當依法為師。多出經論，故令廣說。次正行中。初七共行，謂師資互須故；後三別行，唯在弟子故。本宗中，初。治罰者，謂七羯磨。
【譯文】如果戒子有志於在佛道上百尺竿頭更進一步，理應當重新依止大德善知識；若就這個高標準來看，那麼無論愚拙或聰慧，出家人終其一生都是必須依止明師以修道的。下文引律為證，義理顯而易見。所謂「通通貫徹各部經教」，是指引用《大般涅槃經》的聖文。此外《成實論》中也記載：佛陀當初剛剛於菩提樹下成道時，觀察世間一切眾生，沒有任何一人的德行勝過自己；佛陀心中沉思：「我今天所證得的無上妙法，正是因為依託了此法才得以成佛，所以我依舊應當以我自己所證的『正法』作為依止的老師。」這種深意廣泛出現在各大乘經論之中，所以祖師在此策勵法師們臨場要廣泛宣說。在「正行」的科判中：前面七條是「師弟共行」，也就是師徒之間彼此都必須遵行的雙向義務；後面三條是「弟子別行」，是專屬於弟子侍奉師長單方面的日常行持。在本宗《四分律》中，第一條：所謂「治罰」，是指律中所制定的「七種羯磨」僧團懲罰。

【1015-0002】資持記/04c_上三#61
【原文】弟子下，分二，上明不令僧罰。設下，明已罰令解。二中，初勸發露。為下，次為求懺。三中。差及命終，看視功畢，不可中止。四中。本明弟子移處，下引《僧祇》，師送弟子；由是共行，不妨互顯。《僧祇》中，初制不得離。若欲下，明開暫離。上二句明師不遮；若下，明弟子憂念；當下，明師安慰。
【譯文】下文「弟子……」分為兩層：上面說明要想方設法使僧團不對師長施加治罰；下文「設……」，說明若僧團已經對師長施加了懲處，弟子應當竭力奔走設法讓僧團為師長解除懲罰。第二條中，首先是勸導師長向僧團發露懺悔過失；下文「為……」，其次是弟子為師長奔走四方尋求清淨僧眾來主持懺悔儀軌。第三條中：師長患病直到痊癒或者不幸命終，弟子的看照守護之責才算圓滿終止，中途絕對不可半途而廢、置之不理。第四條中：律文本意是說明弟子要遷徙遷移到別的處所，下文引述《僧祇律》則是說明師父為弟子送行；因為這屬於師徒雙向的共行之道，所以不妨礙在行文上互為顯發補充。《僧祇律》中，首先嚴格禁止弟子無故脫離師長。下文「若欲……」，是說明開許暫時離開的情況。上面兩句話說明此時師父不應無理阻攔；下文「若……」，說明弟子臨行前內心難免憂傷牽掛；下文「當……」，說明做師父的應當慈悲予以溫暖安慰。

【1015-0003】資持記/04c_上三#62
【原文】第五。與下法護何異？此謂事有過失，容生疑悔，以教解之；下令修學，故非相涉。六。惡見，謂著邪背正。七中。出家學道，以法為本，故先明法以資慧命。次列衣食，用攝形累。須知二護義有親疎。引諸部中，初標示。僧下，正引；初《僧祇》，文同五六，前明諫勸可不。
【譯文】第五條中：這與下文的「以佛法護念」有何不同呢？此處是指當師長在事相上出現過失時，心中容易萌生疑惑悔恨，弟子應當以正知正見的教理為師長化解疑雲；而下文是弟子教令師長勤修三學，所以兩者旨趣截然不同，並非互相混淆。第六條中：所謂「惡見」，是指（師長）執著邪見、違背正法、背棄佛門正法。第七條中：出家修學佛道，完全以佛法作為立身處世的根本，所以首先必須闡明以「正法護念」來滋養法身慧命；接著才列出世間的衣食生活資糧，用來調攝安撫血肉身軀的負擔拖累。學人必須清楚明白，這兩種護念在義理上是有主次親疏之別的。在引用各部律典的段落中，首先標明指示。下文「僧……」是正式引證；最初引述《僧祇律》，其內容與前面的第五、第六條大致相同，前半段是說明當面進諫勸告是否合乎律制。

【1015-0004】資持記/04c_上三#63
【原文】言軟語者，師兼父德，不許犯顏。依止出界者，隔明失法，得別依人。若和尚下，明有益不離。醍醐味中最勝，可喻明師。下相攝中廣引，故此指之。次引《五分》，同上第二。次明別行，白事中，《四分》，前明弟子白師。事通一切。若下，明師當量可。且約外行。八事者，三事互歷為八：一伴是，處事非；
【譯文】所謂「以柔軟慈和的言語勸諫」，是因為師長兼具如同世間嚴父般的崇高恩德，弟子絕對不被允許以粗暴言語冒犯師長顏面。所謂「依止出界者」，是指若出界隔宿（明相出），依止法便自然失壞，可以另外依止他人。下文「若和尚……」，是說明若隨侍在師長身邊能獲得殊勝法益，縱然遭受訶責也不應輕言離去。在世間各種甘美滋味之中以「醍醐」最為尊貴殊勝，這最適合用來比喻能夠救人慧命的大德明師。在下文論述師資相互攝受中會有廣泛引證，所以在此只是略微點出。接著引用《五分律》，內容與上述本宗的第二條行儀相同。接下來說明「弟子的各別行持」，在「凡事皆須白告師長」的科判中，《四分律》前半段先說明弟子凡事都應向師長如實稟白。這裏的「事」通徹涵蓋修行與日常生活的一切大小事務。下文「若……」，是說明師長應當仔細考量客觀條件是否合適。這暫且是就外出遠行一事而言。所謂「八種情況」，是將同行伴侶、所往處所、所辦事務三者互相交叉比對，總共衍生為八種句型：第一是同行者對，處所與事務不對；

【1015-0005】資持記/04c_上三#64
【原文】二處是，伴事非；三事是，伴處非〔一是二非三句〕；四伴處是，事非；五伴事是，處非；六事處是，伴非〔二是一非三句〕；七三種俱是；八三種俱非。三種交絡者，總指八句。唯下，簡上七句，皆不令去，獨取俱是一句聽去。《五分》中，初別示他行。唯下，通明一切。
【譯文】第二是處所對，同行者與事務不對；第三是事務對，同行者與處所不對（這三句是「一對二錯」）；第四是同行者與處所對，事務不對；第五是同行者與事務對，處所不對；第六是事務與處所對，同行者不對（這三句是「二對一錯」）；第七是同行者、處所、事務三種條件全都正確無誤；第八是三種條件全都錯誤違法。所謂「三種條件交織羅網」，就是統括上述的這八種情況。下文「唯……」，是甄別淘汰前面的七種情況，師長全都不得放行批准弟子離去，唯獨單單選取「三者全都正確合適」這一種情況，才准許弟子前往。《五分律》中，前半段特別指出涉及外出遠行的行事準則。下文「唯……」，則是普遍申明日常生活中的一切言行舉止，全都必須依循此法稟白師長。


【1015-0006】資持記/04d_上三#1
【原文】文除不白，顯餘須白。《十誦》，初通明諸白。同《五分》者，並除大小便等。若下，別顯出行，前明白法。非時亦爾者，非時入聚，對餘人作牒處同上。當量下，明師可不。布薩名清淨，謂對治止過也。羯磨名業，謂如緣作善也。法事會坐者，說法誦戒兩集也〔座合作坐。
【譯文】律文除去了不需稟白的情形，即顯示其餘事情皆須稟白。《十誦律》開頭總括說明各種稟白之法。與《五分律》相同之處，是都除去了大小便等事。律文「若」字以下，特別說明外出之法，前面則已說明日常稟白之法。「非時入聚落也是如此」，是指在非規定時間進入村落聚落，應當對同住的其他比丘作白告，而在言辭中列明所前往的處所，則與上述規則相同。「應當衡量」以下，說明師長是否准許。布薩的意思是清淨，指對治並止息過非。羯磨的意思是造業（辦事），指順應緣法成就善業。「法事集會」，是指說法與誦戒這兩種集會（「座」字應作「坐」字）。

【1015-0007】資持記/04d_上三#2
【原文】不受語者，謂師不許而故違之。《僧祇》文為四節，初白師須不，上明少物不白。若下，明作務須白。紉，女隣反，索線也。有下，明師出轉白。師後來者，謂歸本處也。說前緣者，述前已白也。餘準此者，例通多事也。若弟子下，二誡資行施。亦由來白，故有斯誡。
【譯文】「不聽受教誡」，是指師長不准許，而弟子卻故意違背。《僧祇律》的經文分為四個段落，開頭說明稟白師長是否必要，前文已說明微小事物不用稟白。「若」字以下，說明從事勞作必須稟白。「紉」，音女隣反，即搓搓繩線。「有」字以下，說明師長外出時的轉白之法。「師長後來」，是指師長回到原處。「敘述先前的因緣」，是指說明先前已經稟白過。「其餘比照此例」，是比照適用於多種事務。「若弟子」以下，第二段告誡弟子行布施之事。也是由於弟子前來稟白，所以師長才給予這番告誡。
