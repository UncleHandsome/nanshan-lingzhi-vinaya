# 校閱材料　第441檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【441-0001】02_戒疏/05b_卷二上之一#94
【原文】【疏】有立無者。如《善生》云：「先遣戮人，信遲未至。後受齋時，信至即殺。以戒力故，不得殺罪。」以此文證，知無任運。
【譯文】【疏文】有主張根本沒有「自然成犯」這回事的。例如《善生經》中說：「預先派遣使者去殺戮某人，使者走得遲緩尚未抵達。後來此人受持八關齋戒時，使者剛好到達並立即將人殺死。由於受持齋戒的功德力，此人並不得犯殺生罪。」依據這段經文的證明，可知並沒有自然感犯罪業的事。

【441-0002】02_戒疏/05b_卷二上之一#95
【原文】【記】引示中，初科。上句標計。「如」下，引據《善生》。初明起殺方便。「戮人」，即殺者。「後」下，明造善事成。「受齋」，即八戒。「以」下，結示。
【譯文】【記文】引用說明的段落中，第一個科判。上一句標立觀點。「例如」以下引用《善生經》作為依據。首先說明發起殺人的前行方便。「戮人」就是指行刑殺戮者。「後來」以下說明造善與惡事同時成就。「受齋」就是指八關齋戒。「由於」以下作結尾說明。

【441-0003】02_戒疏/05b_卷二上之一#96
【原文】【疏】若如此者，即《善生》云：「欲受戒者，先止諸惡；若不遮者，不名得戒。」
【譯文】【疏文】如果是這樣的話，那麼《善生經》又說：「想要受戒的人，必須先止息一切惡行；如果不能遮止惡行，就不能稱作得戒。」

【441-0004】02_戒疏/05b_卷二上之一#97
【原文】【記】難中，還即彼經，不應相違。
【譯文】【記文】質難的段落中，同樣依據這部經典自身，經文前後不應當互相矛盾相違。

【441-0005】02_戒疏/05b_卷二上之一#98
【原文】【疏】解言：「此約貴人常勅殺戮，義同惡戒。以惡強時長，後受齊者雖曰善戒，時短弱故，為惡所障故不得齊。不同前段，暫惡短弱，不能遮齋。以此而推，惡強長者，則有任運，短者則無。」
【譯文】【疏文】解釋說：「這段話是針對位高權貴之人常常下令殺戮而言，這種情況在義理上等同於惡律儀戒。因為惡業勢力強大且時間長久，後來雖然受持了齋戒，即便稱為善戒，但由於時間短暫且勢力微弱，被強大的惡業所障礙，所以得不到齋戒。這不同於前一段所說的，只是暫時起惡、勢力短淺微弱，因此無法阻擋受持齋戒。由此推論，惡業強大持久的，就會有自然障戒成犯的事；惡業短淺微弱的，則沒有這回事。」

【441-0006】02_戒疏/05b_卷二上之一#99
【原文】【記】釋中，初義。先釋通經意。「貴人」，謂國王、大臣。「惡戒」，即屠、獵者惡律儀戒。「不同」下，簡前所引。「以」下，準經雙立。
【譯文】【記文】解釋的段落中，第一種義理。首先解釋融通經文的意旨。「貴人」是指國王、大臣。「惡戒」就是指屠夫、獵戶所受持的惡律儀戒。「這不同於」以下，揀別前面所引用的情況。「由此」以下，遵照經文將兩種情況同時確立。

【441-0007】02_戒疏/05b_卷二上之一#100
【原文】【疏】問：「若惡律儀強長障戒者，今善律儀形俱亦強，何故斷善便失戒邪？」
【譯文】【疏文】問：「如果惡律儀勢力強大持久能夠障礙善戒，那麼現在善律儀是一生受持（形俱戒），其勢力也同樣強大持久，為什麼一旦生起斷善根的邪見，就會立即失掉善戒呢？」

【441-0008】02_戒疏/05b_卷二上之一#101
【原文】【記】轉難中。「斷善失戒」，四捨之一，即生邪見，遠捨三寶。「善」、「惡」翻對，相違可知。
【譯文】【記文】轉進一步質難的段落。「斷善根失戒」，這是四種失戒因緣之一，也就是生起了極大邪見，徹底捨棄了三寶。「善」與「惡」互為對立翻轉，彼此相違的道理自然可知。

【441-0009】02_戒疏/05b_卷二上之一#102
【原文】【疏】答：「障戒不成，已如上解。生大邪見，正是斷善，與戒相違，惡強善故。依如《成論》、《善生經》說：『受惡律儀，即失善戒。』如《薩婆多》云：『善惡二戒，互受捨得。』」
【譯文】【疏文】答：「惡業障礙使得戒體不能成就，前面已經解釋過了。生起大邪見，這正是徹底斷除善根，與戒法完全相違背，這是惡法強過善法的緣故。依據《成實論》與《善生經》的說法：『一旦受了惡律儀，就會立即失去善戒。』正如《薩婆多論》中所說：『善戒與惡戒這兩者，會隨著彼此的受持而互相捨棄或獲得。』」

【441-0010】02_戒疏/05b_卷二上之一#103
【原文】【記】答中。初指前義。「生」下，釋來難。初正釋。上二句示斷善之相，下二句明失戒所以。私釋：惡是順惑，發必強盛，是以先惡能禁後善，後惡能斷前戒。「依」下，引證。「受惡失善」者，若《義鈔》中，準《心論》四捨，無惡戒捨，不取上文。彼云：「得形俱戒後，雖受惡律儀，必不失戒，非斷善故。」故知斷善惡戒，重輕自別。今引取例，於義不妨。次引《多論》，彼問曰：「善戒人作惡戒人，何時捨善戒得惡戒？」答：「若一說言『我即屠兒』，捨善戒；第二、三說，即得惡戒。」又云：「隨時捨善，即得惡戒。」又問：「惡戒自得，從他受得？」答：「自誓便得。以順生死，隨心即得。」《論》中但明受惡捨善，受善捨惡翻對亦同，故云「互」也。
【譯文】【記文】回答的段落中。首先指出前文的義理。「生起」以下解釋後面的質難。首先正面解釋，上兩句顯示斷善根的相狀，下兩句說明失戒的原因。私下解釋：惡法是順應凡夫煩惱惑障的，發作起來必定非常強烈熾盛，因此前面的惡法能夠阻禁後來的善法，後面的惡法也能夠斷除前面的戒體。「依據」以下引用經論證明。「受持惡戒而失去善戒」，如果在《義鈔》中，依據《阿毘曇心論》（《心論》）的四種失戒因緣，並沒有「因受惡戒而捨善戒」的說法，所以不採取上面的文意。那裡說：「得到盡形壽的戒體之後，縱然受持了惡律儀，也必定不會失去善戒，因為這並非斷絕善根的緣故。」由此可知斷善根與惡律儀，在輕重上自有其差別。現在引用作為同類相比，在義理上並無妨礙。接著引用《薩婆多論》，該論問道：「持善戒的人轉做持惡戒的人，在什麼時候捨去善戒而得到惡戒？」回答說：「如果第一次開口宣稱『我就是屠夫』，就捨去了善戒；等到說了第二遍、第三遍，就立即得到了惡戒。」又說：「隨時捨棄善戒，就立即得到了惡戒。」又問：「惡戒是自然獲得的，還是從他人處受得的？」回答說：「自己立誓便能獲得。因為這順應了生死的流轉，順著妄心當下就能成就。」該《論》中雖然只說明了受惡戒捨善戒，但受善戒捨惡戒反過來也完全相同，所以說「互相」。

【441-0011】02_戒疏/05b_卷二上之一#104
【原文】【疏】今正依門，明小學人任運義者。
【譯文】【疏文】現在正式依照本科門，來闡明初學沙彌自然感犯重罪的義理。

【441-0012】02_戒疏/05b_卷二上之一#105
【原文】【疏】有人不立。所以然者？若沙彌時，作罪成，名「吉羅」；若比丘時，作罪成，名「波羅夷」。今則不爾。本沙彌時，教人往盜殺，未離未命斷。能教是沙彌，未得究竟罪。及受戒後，彼所教人，離處斷命。我是比丘，而未教人，云何得重？
【譯文】【疏文】有人不主張成立這種自然成犯之說。為什麼會這樣呢？如果在沙彌階段造罪圓滿，其罪名叫做「突吉羅」；如果在比丘階段造罪圓滿，其罪名叫做「波羅夷」。現在的情況卻不是這樣：原本在做沙彌時，教唆他人前去偷盜、殺生，財物尚未移離原處、對方的性命也尚未斷絕，此時能教唆的人還是沙彌，並未得到究竟圓滿的罪名；等到登壇受戒之後，那個被教唆的人，才把財物移開原處或斷絕了他人性命，此時我已經是比丘了，卻並沒有在此時教唆他人，怎麼會突然被判定犯下重罪呢？

【441-0013】02_戒疏/05b_卷二上之一#106
【原文】【記】正釋中，初師立理。初句標示，「所」下，引釋。前明罪聚各異，「今」下，明因果俱差。上明沙彌因不至果，下明比丘事遂無因，人同位隔，故無有罪。
【譯文】【記文】在正式解釋的段落中，第一位律師立論的理由。第一句標明觀點，「為什麼」以下引導解釋。前面說明不同階位的罪名種類各異，「現在」以下說明其前因與後果全都對不上號。上面說明沙彌時的前因沒有延續到結果，下面說明比丘時的事態圓滿卻沒有前因，雖然是同一個人但位階已經隔斷，所以不應當判有根本重罪。
