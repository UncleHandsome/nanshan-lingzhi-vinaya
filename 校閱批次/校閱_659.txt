# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【659-0001】05_拾毗尼義鈔/04a_卷中之二#44
【原文】問準十誦勸人非時食殺生艸木然火掘地噉殘宿食等勸他為己不為己前人作者二俱得提與此不例何答此戒有四義故離一足食身業犯勸足口業犯二足食病開勸足無病開三足食貪心犯勸足通三性四足食咽犯勸足己身不食犯故不得合。
【譯文】問：依照《十誦律》，勸人非時食、殺生、伐草木、燃火、掘地、吃殘宿食等，勸他人是為了自己或不為了自己，只要前人造作了，兩人都同樣得單墮罪；為什麼足食戒與勸足食戒不比照這個例則？答：因為這兩條戒有四種意義上的分離：一、足食是身業犯，勸足食是口業犯。二、足食有生病的開許，勸足食沒有生病的開許。三、足食純粹是貪心犯，勸足食則通於善、惡、無記三性。四、足食是自己吞嚥犯，勸足食是自身不吃但也犯；所以不能合併為一例。

【659-0002】05_拾毗尼義鈔/04a_卷中之二#45
【原文】問南浮提比丘至餘三方以何時食耶答如十誦云南閻浮比丘到俱耶尼用閻浮提時俱耶尼食三方亦如是乃至天食過中無犯伽論問頗有比丘非時食佉闍尼不犯耶答有若往北單越用彼時食不犯若在單越以閻浮時至彼中夜一切三方亦似閻浮提十誦云餘三方殘宿食三方人不得互食北方宿食彼無我心所隨意食無犯乃至受法不受法比丘得更互受食得食無犯明了論云能受者具戒比丘住於自性伽論云以北鬱單法不受食不犯。
【譯文】問：南閻浮提的比丘到了其餘三方天下，應當依據什麼時間吃飯？答：如同《十誦律》說：南閻浮提比丘到了俱耶尼，應當依照閻浮提的時間在俱耶尼吃飯；其餘三方也是如此。乃至到了天上，吃天人食物超過中午也不犯戒。《伽論》問：難道有比丘非時吃佉闍尼（嚼食）而不犯戒的情況嗎？答：有的，如果前往北俱盧洲，依照當地的時間吃飯就不犯戒；如果人在北俱盧洲，卻依照閻浮提的時間，到了當地半夜才吃，這也是不犯的；其餘三方也類似閻浮提。《十誦律》說：其餘三方的殘宿食，三方的人不能互相食用；北方的宿食，那裡的人沒有「我所有」的執著心，隨意吃也不犯戒；乃至受持口法與不受持口法的比丘，得以互相交換受食，吃下去也不犯戒。《律二十二明了論》說：能夠受食的人，必須是具足戒比丘安住於自性（本性）。《伽論》說：依照北俱盧洲的法則，縱然不受法而吃食也不犯戒。

【659-0003】05_拾毗尼義鈔/04a_卷中之二#46

【譯文】問：既然知道給予在家的外道食物犯輕罪，不知道為什麼給予出家的外道食物犯重罪（單墮）？答：出家外道名稱與佛門僧眾相同，真偽難以分辨，容易使世人生起迷惑顛倒，所以制定重罪；在家的白衣外道，出家與世俗的地位界限分明，不會使人生起疑惑倒錯，所以結罪較輕。《薩婆多論》說：外道的男女如果生病，或者請求出家，給予他們食物不犯戒；求出家的人應當給予四個月的觀察試驗，《四分律》也是如此。問：佛法究竟是在九十六種外道之外，還是在其之內？答：《摩訶僧祇律》販賣戒中說，似乎是在其內，所以該律說：向一切九十六種出家人身邊購買物品沒有罪過，並沒有說「除佛教七眾」，由此可知是包含在內。《薩婆多論》三衣戒中說：顯現未曾有法，九十六種道中都沒有這「三衣」的名號。該論正式解釋這條戒說：親手給予九十六種異見之人食物，不問在家出家、有衣無衣，一律犯單墮罪。販賣戒中說：外道根本由六大師發端，教導十五名弟子，各自受持奉行不同的異見；六師各自有法，與弟子不同，師徒相通共計九十六種；像這樣師師相傳，長久存在不斷絕。佛道是在這九十六種之外，這是毫無疑問的。比丘尼也應當犯單墮罪，現在結小罪（突吉羅），是因為其作法方便有所不同。

【659-0008】05_拾毗尼義鈔/04a_卷中之二#51
【原文】問疑惱戒中不問前人惱不惱若聞知得罪者戒本何言少時不樂者答非待前人少時不樂方犯就惱他者意故與咎。
【譯文】問：疑惱他人戒中，不問對方到底苦惱還是不苦惱，只要聽聞知曉了就得罪，那麼戒本中為什麼說「令他片刻不高興」呢？答：並不是要等待對方真的產生了片刻不高興才構成犯罪，而是純粹針對蓄意惱亂他人者的心意，所以判定其罪過。

【659-0009】05_拾毗尼義鈔/04a_卷中之二#52
【原文】問覆初二同謗何有輕重答謗以重事誣訕於人眾僧擯棄損惱處深故初篇重以二篇謗人既是可懺不永配眾外損微故輕此直覆藏不經眾首露無治罰義同是麤罪壞眾義齊故結一品與謗不例問覆他重自覆輕何答自覆名輕而治重又解覆他有本重制令發露自覆本壞不須重制婆論云覆罪有三覆夷殘得提覆二逆得對首蘭首云依四分若覆二逆理應犯殘。
【譯文】問：覆藏初篇（波羅夷）與二篇（僧殘）同樣是單墮罪，為什麼誹謗初篇與二篇卻有輕重不同？答：誹謗是用重大重罪去誣衊陷害他人，會導致僧團將其擯棄，損害惱亂之處極深，所以誣謗初篇罪重；用二篇罪去誹謗他人，既然二篇是可以悔除的罪，不會永遠被逐出僧團之外，損害較微，所以罪輕。這條戒只是知情隱瞞覆藏，沒有經過在僧眾面前揭露，不牽涉僧團治罰的意義；兩者同屬於粗重之罪，隱瞞後毀壞僧眾的過患是相等的，所以結成同一等級的單墮罪，與誹謗戒並不是同一例則。問：覆藏他人的重罪犯單墮罪，覆藏自己的重罪為什麼結罪反而輕（突吉羅）？答：覆藏自己的罪名相上雖然較輕，但治罰卻很重（必須如數補修覆藏日期的苦行）。另一種解釋：覆藏他人之罪，（覆他）自己根本戒體仍在（有本），故佛重制令其發露；覆藏自己的罪，其人根本戒體已經毀壞，不需再加重制止。《薩婆多論》說：覆藏罪有三種：覆藏波羅夷和僧殘得單墮罪；覆藏二逆罪（如出佛身血、破僧）得對首懺悔的偷蘭遮罪。首律師說：依照《四分律》，如果覆藏二逆罪，在法理上應當觸犯僧殘罪。

【659-0010】05_拾毗尼義鈔/04a_卷中之二#53
【原文】問何故如來不聽減二十出家受具答如大集云佛告頻婆娑羅王太子幾年不聽入宮世尊過二十不聽入宮佛告我亦如是沙彌未二十乃至得道不聽入眾。
【譯文】問：為什麼如來不准許年未滿二十歲的人出家受具足戒？答：如同《大集經》中所說：佛陀告訴頻婆娑羅王，太子要滿幾歲才准許進入宮殿？國王回答：世尊，要超過二十歲才准許入宮。佛陀告訴國王：我也是如此，沙彌年齡未滿二十歲，縱使已經得道，也不准許進入大僧眾中領受具足戒。
