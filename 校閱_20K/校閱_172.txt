# 校閱材料　第172檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【172-0001】02_戒疏/03a_卷一下之一#33
【原文】【疏】此「聽」，心用和忍之聽，異上初句耳識所得也。不解此二，「聽」、「聽」同聲者，則言表不通，不成羯磨。前「聽」即在去聲，他徑反；後「聽」即是平聲，他丁反。恐不解此，違損事多。自說戒時，罪福猶可；脫臨受戒，惱害尤深。故須極誡也。
【譯文】【疏文】此處的「聽」字，是指內心和合容許、准許的意思，不同於上面第一句耳根聽聞聲音的「聽」。如果不懂得這兩種區別，把「聽」與「聽」混讀為同一個讀音，那麼言詞所表達的意義就無法通達，羯磨法便無法成立。前面的「聽」是去聲（發音如「他徑切」），後面的「聽」則是平聲（發音如「他丁切」）。擔心有人不懂這層道理，會導致許多違犯虧損。自己誦戒的時候，罪福的損害還算有限；若是面臨受具足戒的莊嚴時刻，所造成的障礙禍害就極其深重了。因此必須極力告誡警惕。

【172-0016】02_戒疏/03a_卷一下之一#48
【原文】【疏】言「黑白」者，以道俗位殊，時數亦改故也。俗則年有四時，道則歲唯三位，略於秋分也。故三時之始，冬分在初，表無常也，令有慧者觀時入道，不容非逸也。故冬四月，以八月十六日為初；春四月，以十二月十六日為初；夏四月者，以四月十六日為初也。
【譯文】【疏文】提到「黑月與白月」，是因為出家與世俗的規範位階不同，時間的劃分與計算也隨之改變。世俗將一年分為四季，出家修行則將一年只分為三個階段，簡略省略了秋季。因此三時的起始，是以冬季為最初，象徵世間無常，令有智慧的人觀察時節變化而精進修道，不容許懈怠放逸。所以冬天的四個月，是以八月十六日為第一天；春天的四個月，是以十二月十六日為第一天；夏天的四個月，則是以四月十六日為第一天。

【譯文】【記文】在說明黑月與白月的第一節中。前面闡明異於世俗，「因此」以下推究教法的用意。世俗以春天為歲首，是取萬物萌發生長之意；佛門以冬季為開端，則是取萬物凋零零落之象。出家人旨在厭離世間，並非追求世俗榮華。「所以冬天」以下，列出時間位階的具體劃分。

【172-0019】02_戒疏/03a_卷一下之一#51
【原文】【記】次餘國中。「五月十六為前夏」，則九月十六為冬初，正月十六為春首，即《善見》中「六月十六為後安居」是也。「覩貨羅」者，《西域記》云「此國地南北千餘里，東西三千餘里，東阨葱嶺，西接波斯，南至雪山，北據鐵門。其國冬末春初，霖雨相繼，加以風土，率多瘟疾。而諸僧徒以十二月十六日入安居，三月十五日自恣」等。《業疏》云「余參傳譯，親問來人」是也。「此」下，會通。
【譯文】【記文】接著談到其他國家的情況。「五月十六日為前安居」，那麼九月十六日就是冬季開端，正月十六日就是春季首日，這就是《善見律毗婆沙》中所說的「六月十六日為後安居」。所謂「覩貨羅國」，《大唐西域記》記載「該國土地南北一千餘里，東西三千餘里，東邊緊鄰蔥嶺，西邊連接波斯，南面直抵雪山，北面依據鐵門關。該國冬末春初之際，連綿大雨接續不斷，加上當地的風土氣候，極常流行各類瘟疫。因此僧眾多在十二月十六日進入安居，三月十五日舉行自恣」等。《業疏》中說「我曾參與經典翻譯，親自向西域來人詢問」即是此意。「這都是」以下是融會融通之語。

【172-0022】02_戒疏/03a_卷一下之一#54
【原文】【疏】先黑後白者，舉三時三始，必十六日為初也。又云：「十六日已去，白虧黑生；月一日已去，白生黑虧。約相取分，故有斯召。」
【譯文】【疏文】之所以先算黑月後算白月，是列舉一年三時的三個開端，必定都是以十六日為最初一天。又有一種說法：「從十六日開始，月光虧損而黑暗漸生；從初一日開始，光明漸生而黑暗退損。依據天象特徵來區分時段，所以有了這樣的稱呼。」

【172-0023】02_戒疏/03a_卷一下之一#55
【原文】【記】先後中，初正示。文中不顯所表，亦以「白虧黑生」表無常敗壞，使觀厭也。「又」下，示得名所以。
【譯文】【記文】在辨析前後次序中，首先是正式說明。疏文中雖然沒有明言所象徵的法義，但同樣是藉由「白月虧損黑暗滋生」來象徵世間的無常破敗，使人觀照而生厭離之心。「又有一說」以下指出得名的由來。

【172-0026】02_戒疏/03a_卷一下之一#58
【原文】【律】諸大德！我今欲說波羅提木叉。

【172-0027】02_戒疏/03a_卷一下之一#59
【原文】【疏】次解第二發起序中。文分八段，《律》文具解。今且生起，後方釋文。
【譯文】【疏文】接下來解釋第二部分發起序文。經文共分為八段，《律》典中有詳盡解釋。現在先梳理這八段文章生起次第的脈絡，隨後再逐字解釋經文。

【172-0028】02_戒疏/03a_卷一下之一#60
【原文】【記】次釋誡勅，初分示中。「《律》具解」者，即注所引也。生起八段，次第相由，在文可見。
【譯文】【記文】接著解釋誡敕警策，在最初劃分段落的說明中。「《律》典中有詳盡解釋」，就是注釋中所引述的內容。生起這八段文句，彼此順序相承，在經文中清晰可見。

【172-0029】02_戒疏/03a_卷一下之一#61
【原文】【疏】從初至「說木叉」已來，標舉說宗，歎功勸信，有生善滅惡之義。
【譯文】【疏文】從最開頭直到「說波羅提木叉」為止，是標明並提出宣說戒律的主旨，讚歎戒律的功德以勸勉大眾深信，具有生起善法、滅除惡業的深義。

【172-0030】02_戒疏/03a_卷一下之一#62
【原文】【疏】但斯正戒，乃是眾同所聞，理宜崇遵，必無乖別。是以第二令「集一處」，顯形心無異。
【譯文】【疏文】然而這部清淨正戒，本是僧眾全體應當共同聽聞的，理應尊崇恪守，絕不容有任何違逆脫節。因此第二段要求大家「齊聚在一處」，彰顯大眾形體與心意的一致無別。

【172-0031】02_戒疏/03a_卷一下之一#63
【原文】【疏】形心既和，事須詳審，聽若異聞，則乖說意。是以第三「諦聽善思」，正明警勅，有開解之用。
【譯文】【疏文】身形與心意既然已經和睦，辦理法事就必須詳細審慎，傾聽時如果心不在焉另有所想，就違背了宣說戒律的本意。因此第三段「諦聽善思」，正是明確地給予警惕誡飭，具有開啟明了正解的作用。

【172-0032】02_戒疏/03a_卷一下之一#64
【原文】【疏】凡欲聞戒，為被行淨之人，必有違犯，便乖說聽之法。是以第四「若自知有犯」已下，正勸時眾，省己之違，見過尋悔，應法成行。
【譯文】【疏文】大凡想要聽聞戒律，是為了加被於行為清淨的人；如果有了違犯，便與說戒聽戒的法規相違背。因此第四段「若自知有犯」以下，正是勸勉在座大眾，省察自己的違犯過失，一旦見到過錯就隨即懺悔，合乎法度地成就道行。

【172-0033】02_戒疏/03a_卷一下之一#65
【原文】【疏】染者既誡，無過當機。自表已淨，世號「伐德」。但止默然，聞成義顯，即名答對，應上問意。是以第五「不犯者」下，省己之順，默表已淨。
【譯文】【疏文】有染犯過失的人既然已經告誡，毫無過咎的人就成為當機之眾。如果自己宣告自己已經清淨，世俗常稱這是「自我誇耀德行」。只要安住於靜默，聽聞成立而法義顯發，這就是一種具體的應對作答，回應了上面的審問之意。因此第五段「不犯者」以下，是省察自己的隨順合戒，以沈默表達自身清淨。

【172-0034】02_戒疏/03a_卷一下之一#66
【原文】【疏】上五通告，止在別緣。三根外彰，眾網須正。必有他舉，理須對實。是以第六「若有他問」下，誡勸時座，犯持之士，深懷二答。
【譯文】【疏文】上面五段是通同告誡，僅止於各自個人的私自行持。但如果見、聞、疑三根過犯跡象已經外顯彰露，僧團的綱紀就必須匡正。若是有人出面舉發檢舉，理當依據實情對質答覆。因此第六段「若有他問」以下，誡勉勸導在座大眾中，無論是犯戒還是持戒之人，內心都應深深明白兩種應對答話的道理。

【172-0035】02_戒疏/03a_卷一下之一#67
【原文】【記】六中云「別緣」者，即自行。「二答」者，下釋云「有犯露答，無犯默答」。
【譯文】【記文】第六段中所說的「各自個人的私自行持」，就是指自己的身心行持。「兩種應對」在下文解釋為「有犯過者如實發露回答，無過犯者安住沈默作答」。

【172-0036】02_戒疏/03a_卷一下之一#68
【原文】【疏】若內實犯，而外表淨，令僧妄解，罪障尤深。是以第七「如是比丘」下，明隱覆之瑕，不實之損，行穢自纏，特由抱過，勸發露也。
【譯文】【疏文】如果內心確實有犯戒，表面上卻裝作清淨無染，讓僧眾產生錯誤的理解，這樣的罪業障礙最為深重。因此第七段「如是比丘」以下，揭示隱瞞覆藏過失的瑕疵，以及不老實面對的巨大損害，行為汙穢作繭自縛，完全是由於懷抱過失不肯放捨，以此勸勉眾人應當坦誠發露。

【172-0037】02_戒疏/03a_卷一下之一#69
【原文】【疏】若順教修，理有深益。是以第八「若彼比丘」下，知犯識懺，還淨上起，三學增明，克成道業，不虗之益也。
【譯文】【疏文】若是順從佛法教導來修持，在義理上具有極深廣的利益。因此第八段「若彼比丘」以下，說明知曉犯戒且懂得依法懺悔，就能重回清淨並使戒行向上生起，戒定慧三學益發光明，必定能成就解脫道業，這是真實不虛的殊勝利益。

【172-0038】02_戒疏/03a_卷一下之一#70
【原文】【記】八中。「上起」即懺悔，名出《了論》，謂翻前犯時居下，故名為「上」；戒法續生，稱之為「起」。「克」，能也。
【譯文】【記文】第八段中。「向上生起」就是指懺悔，名詞出自《二十二明了論》（《了論》），意思是翻轉先前犯戒時身處低劣下墮的境況，所以稱為「上」；戒律善法相續生起，所以稱為「起」。「克」就是能夠的意思。

【172-0039】02_戒疏/03a_卷一下之一#71
【原文】【疏】生起此文，非教本意，講說之家，務傳言相。西梵諸師凡欲敷演，但依文義，廣說所由；至於科約，蓋闕如也。縱有分判，大通無局，如龍樹解《大品》以為二道，天親釋《涅槃》以為七分，須知意也。不可浪事悠悠，費於紙墨，大破正功，無任法利。顧諸學者，可不思哉！今欲消文，就義分之。更有科約，終非大濟，故削略也。
【譯文】【疏文】梳理生起此文的層次，原本並非佛陀立教的根本意圖，而是講經說法的法師為了傳承文義名相所作的施設。印度西方的論師們凡是要講經說法，多半只依循經文義理，廣泛闡述其源由背景；至於科判章節的分割約束，向來大多是缺漏不設的。縱然有所劃分判定，也多是大體貫通而不拘泥細節，例如龍樹菩薩解釋《大品般若經》只統攝為兩道，天親菩薩註解《涅槃經》只區分為七分，我們必須明白這個宗旨。切不可漫無邊際地隨意鋪張，空耗紙墨，嚴重破壞了真實修行的功用，對求取佛法實益毫無幫助。回顧各位參學之人，豈能不深加反思！如今為了消解文句，姑且順著義理加以區分。若再立更多的繁瑣科判，終究對修行沒有實質助益，所以全部予以刪削省減。
