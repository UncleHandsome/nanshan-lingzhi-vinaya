# 校閱材料　第101檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【101-0001】02_戒疏/14b_卷三下之二#39
【原文】【註】彼執事人若在家、在市、作處，到彼前默然立。執事人問：「何緣此立？」比丘報言：「汝自知之。」若彼人言：「今我不知。」餘人知者，比丘當語：「彼人知之。」是默然相也。
【譯文】【註文】那位執事人無論是在家裡、在市場、在工坊，比丘到了他面前只是默默站立。如果執事人問：「為了什麼緣故站在這裡？」比丘應當回答：「你自己心裡明白。」如果那人說：「我現在不知道。」若是旁邊有人知情，比丘應當說：「那個人知道這件事。」這就是靜默站立的相貌。

【101-0002】02_戒疏/14b_卷三下之二#40
【原文】【律】若四反、五反、六反，在前默然住，得衣者善。
【譯文】【律文】如果去了四次、五次、六次，在他面前默默站立而能得到衣服，那很好。

【101-0003】02_戒疏/14b_卷三下之二#41
【原文】【註】若作一反語，破二反默然，乃至三反語破六反默然也。
【譯文】【註文】如果每講過一次話，就抵消了兩次默默站立的額度，乃至三次開口講話，就抵消了六次默默站立的額度。

【101-0004】02_戒疏/14b_卷三下之二#42
【原文】【律】若不得衣，過是求得衣者，尼薩耆波逸提。
【譯文】【律文】如果還是得不到衣服，超過了這個限度強行索求而得到衣服者，犯尼薩耆波逸提（捨墮罪）。

【101-0005】02_戒疏/14b_卷三下之二#43
【原文】【疏】若不得衣，從所得衣價處，若自往，若遣使往，語言：「汝先遣使持衣價與某甲比丘，是比丘竟不得衣。汝還取，莫使失。」此是時。
【譯文】【疏文】如果最終還是得不到衣服，應當親自前往、或派遣使者前往最初出資提供衣價的主人那裡，告訴他說：「您先前派使者送買衣錢給某甲比丘，那位比丘自始至終都沒有拿到衣服。您去把它收回去吧，不要讓財物白白損失了。」這才是合乎戒律時機的做法。

【101-0006】02_戒疏/14b_卷三下之二#44
【原文】【註】不犯者：若遣使告知，若彼言「我今不須，即相布施」，是比丘以時、輭語、方便索衣；若為作波利迦羅故與，以時、輭語索，若方便索得者。
【譯文】【註文】不犯戒的情況：如果派遣使者告知財主，對方回答說「我現在不需要這筆錢了，就直接布施給你們」，這時比丘在合宜的時間、用柔和的言語、以適當方便的方式去索求衣服；或者施主當初是為了給比丘製作助身衣（波利迦羅）而給予衣價，而能合時、柔和索求，或以方便索取而得到衣服的情況。

【101-0007】02_戒疏/14b_卷三下之二#45
【原文】【疏】戒本六句：一、犯人；二、「若王」以下，明寶主緣由；三、若過索成業結犯；四、捨；五、結罪；六、不得進不相。

【101-0017】02_戒疏/14b_卷三下之二#55
【原文】【記】戒本，釋第二中，初科。「五位」，即王臣等五位人。「執事」者，即掌寶者。文云「若僧伽藍民」，即守園人。「優婆塞」即在家俗士。「世信使」等者，言能往復，為使當然。
【譯文】【記文】戒本中，解釋第二部分的初科。「五種身分」，就是指國王、大臣等五種人。「執事」也就是替僧人掌管寶物的人。經文說「或者是寺院工人」，就是看守園林的人。「優婆塞」也就是在家的男居士。「世間信使」等語，是說能夠有始有終、來回稟告，做一個使者本當如此。

【101-0018】02_戒疏/14b_卷三下之二#56
【原文】【疏】就索法度中。初明語索三反相；二、「若不得衣，四反五反」下，默然相。
【譯文】【疏文】在索求衣服的法度限額中。首先說明開口索求三次的規矩相貌；第二、「若不得衣，四反五反」以下，說明靜默站立的規矩相貌。

【101-0019】02_戒疏/14b_卷三下之二#57
【原文】【疏】《僧祇》云：「一反語索，淨主一月來，即一月來，乃至三月，不得過。如是十日，四三二一日，乃至須臾，不得過三。」若一反默索，例上可知。
【譯文】【疏文】《摩訶僧祇律》說：「一次開口索求之後，如果淨人說一個月後來，就必須等滿一個月再去，乃至最多只能等三次一個月，不得超過這個次數。如果是約定十天、四天、三天、兩天、一天，乃至片刻須臾，去索求的次數也都不得超過三次。」如果是一次靜默索求，比照上面的原則可以類推而知。

【101-0020】02_戒疏/14b_卷三下之二#58
【原文】【記】索法中。《僧祇》，彼具云：「若比丘至檀越所索衣時，語言『長壽！與我衣直』，若彼答言『尊者更一月來』，比丘滿一月來，往復索。若彼言『尊者更一月來』，比丘滿一月復往索。過三月不與，不得復索。若言『半月來』、『十日』乃至『須臾』，但使過三，不得復索。默索例上日月，但不語耳。」
【譯文】【記文】索求法度中。《僧祇律》原文具體說：「如果比丘到施主那裡索求衣服時，開口說『仁者！請把我的衣服錢給我』，對方如果回答『尊者請一個月後再來』，比丘等滿一個月後，才可以再去索求。對方如果又說『尊者請一個月後再來』，比丘滿了一個月後又可以再去索求。如果超過了三個月對方還是不給，就不得再去索求了。如果對方說『半個月後來』、『十天後』乃至『片刻後』，只要前去的次數超過了三次，就不得再去索求。靜默索求也比照上面的時間間隔，只是不開口講話罷了。」

【101-0021】02_戒疏/14b_卷三下之二#59
【原文】【疏】《善見》云：「默然者，口不語，喚坐不坐，與食不受，說法、呪願一切不得。若言：『何因至此？』答言：『居士自知。』」
【譯文】【疏文】《善見律毘婆沙》說：「所謂默然站立，就是嘴裡不講話，對方叫你坐也不坐，給飲食也不接受，說法、念誦咒願一切都不可以做。如果對方問：『為什麼到這裡來？』只能回答：『居士你自己心裡明白。』」

【原文】【疏】純語往索，齊六不犯；純默往索，十二反；語參默故，則九反。《律》文「四反」、「五反」者，承前語勢接次四五。若行事時，始心一二，故成六默。

【101-0069】02_戒疏/14b_卷三下之二#107
【原文】【記】初問答中。初據律無斷，「若」下，準經斟酌。《央掘摩羅》，即大乘經。「轉來」，非蠶家者。「不應受」者，《經》中斷也。「若受非悲」者，違化教也。「不破戒」者，不犯制教也。大乘菩薩悲行為先，若著蠶衣，沾殺生分，故是「非悲」。小教聲聞，離過為本，但離殺手，犯緣不具，故「不破戒」。準此據律，如法得成，深取經意，終非應法，故令「斟酌」也。《章服儀》云：「且自『非悲』之語，終為永斷之言。」祖師之意，自可見矣。
【譯文】【記文】開頭的問答之中，前半是依據律文沒有斷然禁止；「若」字以下，是依經文來斟酌。《央掘摩羅》，就是大乘經典。「轉來」，是指並非從養蠶人家直接得來。「不應受」，是經典中的禁斷。「若受非悲」，是違背化教。「不破戒」，是不觸犯制教。大乘菩薩以悲行為先，若穿著蠶絲衣服，便沾上殺生的成分，所以說是「非悲」。小乘聲聞以離過為根本，只要遠離親手殺害，犯戒的條件不具足，所以說「不破戒」。依此看來，若依據律典，如法可以得成受持；但深深體取經意，終究不算合乎正法，所以令學人「斟酌」。《章服儀》說：「單從『非悲』這句話來看，終究是永遠斷除的教誡。」祖師的用意，自然可以看得出來。

【101-0105】02_戒疏/14b_卷三下之二#143
【原文】【記】十三，制意中。初句指同。體雖非貴，長貪營造，妨業不殊，故須制約。「五」下，示異。本宗緣於純白，乃制相參，二律因彼微參，故制分齊。「小小白尨」，謂不多也。「尨」，莫江反，若依字書，則犬多毛。有云合作「牻」，訓雜者，此乃雜色牛名，非訓雜也。今準注中，頭脚等處即是「麤毛」，倉黃色者謂之「尨毛」。
【譯文】【記文】第十三條，在制戒意旨中。第一句是指涉意旨相同。白毛材質雖然沒有純黑毛那麼昂貴，但貪心滋長、營造營求、妨害修道本業的情形是完全相同的，所以必須加以約束限制。「《五分》」以下，展示各部律典的差別。本宗《四分律》是針對比丘使用「純白毛」而引發譏嫌，才制定相雜配比的限制；《五分》、《十誦》二部律典則是因為比丘稍微摻入一點點雜毛來規避前戒，所以才制定嚴格的比例分寸。「微量的一點點白毛與雜毛」，是指數量極少。「尨」字讀作「莫江反」，如果依照字書字典的解釋，是指長著很多長毛的狗。有人說這個字應當寫成「牻」，解釋為雜色，但那其實是雜色牛的名稱，並不是解釋為顏色龐雜。現在依照律注中的定義，羊頭部、腳部等處的粗糙毛髮就是「粗毛」，顏色呈灰黃蒼黃色的就稱為「尨毛（雜色毛）」。

【101-0106】02_戒疏/14b_卷三下之二#144
【原文】【疏】犯緣五成：一、三毛參作；二、為擬作三衣；三、為己；四、增好減惡，下至一兩；五、成便犯。
【譯文】【疏文】犯戒因緣具備五項構成犯戒：第一、摻雜三種羊毛製作；第二、意圖用來製作三衣袈裟；第三、是為了自己使用；第四、增加了精美好毛、減少了粗劣毛，乃至只要多了一兩；第五、製作完成便構成犯戒。

【101-0107】02_戒疏/14b_卷三下之二#145
【原文】【記】犯緣。第四，「增好」即增黑毛，「減惡」即白尨毛。
【譯文】【記文】在犯戒因緣中。第四項「增加了精美的好毛」是指增加了黑毛的分量，「減少了粗劣毛」是指減少了白毛與雜色毛的分量。

【101-0108】02_戒疏/14b_卷三下之二#146
【原文】【疏】問：「黑白同犯，何故前黑不制參邪？」
【譯文】【疏文】提問：「黑毛與白毛同樣都是犯戒的境緣，為什麼前面黑毛戒中不規定按比例混合製作呢？」

【101-0109】02_戒疏/14b_卷三下之二#147
【原文】【疏】答：「兩戒明參，文則繁複，以後例前，黑參非犯。」
【譯文】【疏文】回答：「如果兩條戒都反覆申明混合比例，文字就會顯得繁瑣重復；只要拿後面的戒條來比照前面的戒條，就可以知道黑毛若照比例混合製作，就不算犯戒了。」

【101-0110】02_戒疏/14b_卷三下之二#148
【原文】【記】初問。答中，白既減好成開，黑必參尨無過，故云「以後例前」也。
【譯文】【記文】第一個提問。回答中說明：白毛既然在減少精美好毛、依比例混雜的情況下能得到開許，黑毛必然在摻雜了雜色毛後也不構成過失，所以才說「用後面的規定來類推前面的條文」。

【101-0111】02_戒疏/14b_卷三下之二#149
【原文】【疏】問：「三毛俱參，何故黑多而尨少？」
【譯文】【疏文】提問：「三種毛料都要混合摻雜，為什麼黑毛用得多，而雜色毛反而用得少呢？」

【101-0112】02_戒疏/14b_卷三下之二#150
【原文】【疏】答：「就白制戒，故黑多耳；約前黑戒，白亦須多。」
【譯文】【疏文】回答：「這是針對防範純白毛所制定的戒律，所以黑毛相對較多；若是站在前面防範黑毛的角度來看，白毛所佔的比例也必須增加。」

【101-0113】02_戒疏/14b_卷三下之二#151
【原文】【疏】又云：「黑色雖貴，順法衣相；白是俗服，是以少也。」
【譯文】【疏文】另一種解釋說：「黑毛的顏色雖然貴重，但染成壞色後符合出家法衣的樸素相貌；白色是世俗人的服飾常色，所以使用的比例必須減少。」

【101-0114】02_戒疏/14b_卷三下之二#152
【原文】【記】次問。以戒文中黑毛二分，白、尨二毛各一分故。文中但云「尨少」，義必兼白。答中。初約制戒相翻釋。「又」下，次約毛色順違釋。
【譯文】【記文】第二個提問。因為戒律經文中規定黑毛佔兩份，白毛與雜色毛各佔一份。經文提問時雖然只問「雜色毛為什麼用得少」，但按道理必然也涵蓋了白毛。回答之中：首先是從制戒所防範對象的互換翻轉來作解釋。「另一種解釋」以下，則是從毛料顏色究竟順應法衣還是違背法規的角度來解釋。

【101-0115】02_戒疏/14b_卷三下之二#153
【原文】【註】佛在舍衛國。六群比丘純以白毛作新臥具，居士譏嫌「如王、大臣」。比丘舉過，佛因訶制。
【譯文】【註文】佛陀在舍衛國時，六群比丘完全用白毛製作新的臥具，居士們譏嫌他們「像國王、大臣一樣」。比丘們舉發此事，佛陀因此訶責並制定戒條。

【101-0116】02_戒疏/14b_卷三下之二#154
【原文】【疏】就戒緣中，由比丘著行，致有譏訶，故知上服。
【譯文】【疏文】在這條戒的起因緣起中，由於比丘是把這件衣服穿戴在身上走動，才引來世俗的譏嫌呵責，由此確切知道它是穿在上身的外衣法衣。

【101-0117】02_戒疏/14b_卷三下之二#155
【原文】【記】戒緣中，「知上服」者，反古非也。
【譯文】【記文】在戒律緣起中，「確切知道是穿在上身的外衣」，是徹底推翻古人認為是鋪地被褥的錯誤見解。

【101-0118】02_戒疏/14b_卷三下之二#156
【原文】【律】若比丘，作新臥具，應用二分純黑羊毛、三分白、四分尨。
【譯文】【律文】若比丘，作新臥具，應當使用二份純黑羊毛、一份白羊毛（第三份）、一份雜色毛（第四份）。

【101-0119】02_戒疏/14b_卷三下之二#157
【原文】【註】頭上毛，耳上毛，若脚上毛，若餘尨色毛也。欲作四十鉢羅臥具者，二十鉢羅黑，十鉢羅白，十鉢羅尨。乃至作二十鉢羅臥具，準上可知也。
【譯文】【註文】所說的「尨」，是指頭上的毛、耳上的毛，或是腳上的毛，或是其餘雜色的毛。若要做四十鉢羅重的臥具，就用二十鉢羅黑毛、十鉢羅白毛、十鉢羅雜色毛。乃至做二十鉢羅的臥具，依上述比例類推就可以知道。
