# 校閱材料　第087檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【087-0001】01_行事鈔/08b_卷中之四#60
【原文】上座如前作法安慰之訖。白言：「大德僧聽！某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜，已從僧乞百夜覆藏羯磨，僧已與彼百夜覆藏羯磨；彼已行覆藏日，今從僧乞六夜摩那埵。若僧時到僧忍聽：僧今與彼六夜摩那埵。白如是。」「大德僧聽！此某甲比丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜已，從僧乞百夜覆藏羯磨，僧已與某甲比丘百夜覆藏羯磨。此某甲比丘，已行覆藏日，今從僧乞六夜摩那埵；僧今與某甲比丘，六夜摩那埵。誰諸長老忍，僧與某甲比丘六夜摩那埵者，默然；誰不忍者，說。是初羯磨。」「僧已忍，與某甲比丘六夜摩那埵竟。僧忍，默然故。是事如是持。」
【譯文】上座如同前面一樣如法勉勵安慰他完畢。隨後作白宣示：「大德僧聽！某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜，先前已向僧團乞求一百夜覆藏羯磨，僧團已經給與他一百夜覆藏羯磨；他如今已經行完覆藏日數，如今向僧團乞求六夜摩那埵。若僧團適宜的時間已到，僧團也贊同許可：僧團如今給與他六夜摩那埵。這是所白告之事。」「大德僧聽！此某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜，先前已向僧團乞求一百夜覆藏羯磨，僧團已給與某甲比丘一百夜覆藏羯磨。此某甲比丘，如今已經行完覆藏日數，如今向僧團乞求六夜摩那埵；僧團如今給與某甲比丘六夜摩那埵。各位長老凡是贊同僧團給與某甲比丘六夜摩那埵的，請默然；有不贊同的，請說話。這是初番羯磨。」「僧團已經贊同，給與某甲比丘六夜摩那埵完畢。因為大眾贊同而默然故。這件事就這樣遵行受持。」

【087-0002】01_行事鈔/08b_卷中之四#61
【原文】彼得羯磨已，即於僧中白言：「大德僧聽！我某甲丘丘，犯故漏失、摩觸、麁語三僧殘罪，各不憶數，或覆藏一夜乃至百夜，已從僧乞百夜覆藏羯磨，僧已與我百夜覆藏羯磨。我比丘某甲，已行覆藏日，已從僧乞六夜摩那埵，僧已與我六夜摩那埵；我某甲比丘，從今日行，白大德僧知，我行摩那埵。」若行經一夜者，餘詞同上。乃至「僧已與我六夜摩那埵；我某甲比丘，已行一夜，未行五夜，白大德僧知，我行摩那埵。」若客比丘來，唯改大德僧為異，餘詞並同。
【譯文】該比丘領受羯磨完畢之後，隨即在僧眾之中稟白說：「大德僧聽！我某甲比丘，犯了故意漏失、摩觸、麁語三種僧殘罪，各記不得次數，或者覆藏了一夜乃至一百夜，先前已向僧團乞求一百夜覆藏羯磨，僧團已經給與我一百夜覆藏羯磨。我比丘某甲，如今已經奉行完覆藏日數，已經向僧團乞求六夜摩那埵，僧團已經給與我六夜摩那埵；我某甲比丘，從今天起開始奉行，稟白大德僧知曉，我正在行摩那埵。」如果奉行經過了一夜，其餘文詞如同上面所述。乃至說到「僧已與我六夜摩那埵；我某甲比丘，已行一夜，未行五夜，白大德僧知，我行摩那埵。」如果有外來客比丘抵達，只將大德僧改換稱謂為異，其餘文詞全都相同。

【087-0003】01_行事鈔/08b_卷中之四#62
【原文】律云：行六夜比丘，亦同行別住覆藏法；唯常在僧中宿、日日白，為異。《僧祇》：因數數犯僧殘，如波逸提乃至越毘尼悔，故便制六夜懺悔，二十人中出罪。此上二行中，若覆，與前法；不覆，與後法；同俱出罪。若二法中重犯者，各壞二法，皆重與本日治之。餘如別述。
【譯文】律中說：奉行六夜摩那埵的比丘，其行持儀軌與奉行別住覆藏法大致相同；唯一不同之處，在於他平時常在清淨僧大眾之處住宿、且每日必須向大眾稟白發露。《摩訶僧祇律》說：因為有人頻頻毀犯僧殘罪，卻輕慢地像悔波逸提乃至越毘尼（惡說罪）那樣隨意求悔，所以佛陀便制定了六夜專精懺悔之法，並規定必須在二十位清淨大僧之中才能作成出罪羯磨。在這兩種行法之中：若有覆藏，便給與前法（別住）；若無覆藏，便給與後法（摩那埵）；最後同樣都需經過羯磨出罪。若在遵行這兩種懺法期間再度犯下僧殘罪，則各自破壞了這兩種行法，都必須重新依本日治之。其餘的細則如別處章疏中所詳細論述。

【087-0006】01_行事鈔/08c_卷中之四#3
【原文】與出罪已，依《僧祇律》，當教示言：「善男子！佛在世比丘，能受戒、能持戒、能得聖果；滅後比丘，能受戒、能破戒、能入惡道。行者既內無護心，外縱身口，今犯此罪，垂至死處；猶有勝因，改心懺悔，大眾隨喜，汝幸自慶！故文云：自今已去，形心清淨，如無憂花，更勿復犯。縱更續犯，怖心難生；縱怖心生，懺罪無處。故論云：若二十清淨比丘，出僧殘罪，我法不滅。今時惡世，尚不喜聞犯名，豈當聽汝懺者！」如是種種因緣，為說割斷之意。并引《涅槃經》：以貪欲習故，死入地獄畜生餓鬼；從彼得出，還為鳩鴿雞雀等。
【譯文】給予出罪完畢後，依照《僧祇律》（《摩訶僧祇律》），應當教誡開示說：「善男子！佛陀在世時的比丘，能夠受戒、能夠持戒、能夠證得聖果；佛陀滅度後的比丘，能夠受戒、能夠破戒、能夠墮入惡道。修道者既然內心沒有守護戒律之心，外在放縱身口造業，如今犯了這種重罪，幾乎臨近法命斷絕的死地；所幸還有殊勝的善因，能悔改其心發露懺悔，僧眾都為你隨喜，你應當為自己慶幸！所以經文說：自今以後，身形與心靈皆得清淨，宛如無憂花般無瑕，切莫再次重犯。縱使日後又接續再犯，恐怕就很難再生起怖畏之心；縱使怖畏之心生起了，也找不到清淨僧團為你懺罪之處。所以論書說：若有二十位清淨比丘為犯者出僧殘罪，我的佛法就不會滅亡。現今是末法惡世，人們連聽到犯戒之名都不高興，哪裡還會願意聽你懺悔呢！」以此類種種因緣，為他宣說徹底斷除惡習的深意。並引用《涅槃經》（《大般涅槃經》）之意：由於貪欲習氣的緣故，死後墮入地獄、畜生、餓鬼三惡道；從惡道中脫出後，轉世仍舊做鳩、鴿、雞、雀等貪淫的飛禽。

【087-0009】01_行事鈔/08c_卷中之四#6
【原文】一者從生偷蘭，謂初、二篇下方便。若依《十誦》：初篇生重，此是近方便，謂身口相加，未得暢遂者，應一切僧中悔；若初篇生輕，二篇生重，應界外四比丘眾中悔；若僧殘生輕，應一比丘前悔，其懺法與波逸提同。
【譯文】一者從生偷蘭，也就是初篇（波羅夷）、二篇（僧殘）的前方便罪。如果依《十誦律》的說法：由初篇波羅夷生起的重偷蘭遮，這是近方便，指身與口已施加動作，但尚未達到究竟暢遂的人，應當在一切僧眾（界內全體僧團）中懺悔；如果是初篇生起的輕偷蘭遮，以及二篇僧殘生起的重偷蘭遮，應當在結界外的四位比丘僧眾中懺悔；如果是僧殘生起的輕偷蘭遮，應當在一比丘面前對首懺悔，其懺悔法與波逸提（單墮）相同。

【087-0010】01_行事鈔/08c_卷中之四#7
【原文】二者自性偷蘭，亦名獨頭，亦分三品：云何名重？謂盜僧食具、十方現前物，偷四錢、及非人重物等，須大眾懺。云何名中？破羯磨僧；盜三錢已下僧私之物；一有衣一無衣相觸，作僧殘境界；如是等類，對小眾懺。云何名下？如律云：畜用人髮，剃三處毛、灌下部、露身行，著外道衣、畜石鉢、食生肉血等。《僧祇》：瞋心裂破三衣鉢、破塔等，並偷蘭，用一人懺。律中：初二篇下，教人犯偷蘭者，並是究竟，輕重同上懺之。
【譯文】二者自性偷蘭，亦名獨頭，亦分三品：什麼叫作重品？指盜取僧團的飲食器具、十方現前僧物，偷竊四錢以及非人的貴重財物等，必須向大眾僧（五人以上僧團）懺悔。什麼叫作中品？破羯磨僧（破壞僧事作法）；盜取三錢以下屬於僧眾或個人的財物；一人穿衣、一人裸露而相互摩觸，構成僧殘的境界；像這一類的，對小眾僧（四人或二三人）懺悔。什麼叫作下品？如同律中所說：蓄積使用人的頭髮，剃除三處（腋下、陰部等）毛髮、灌洗下部、裸露身體行走，穿著外道衣服、蓄存石鉢、吃生肉生血等。《僧祇律》說：以瞋恨心撕裂撕破三衣及鉢、破壞佛塔等，都屬於偷蘭遮，只需對一人懺悔。律藏中：在初篇、二篇之下，教唆他人而使自己結犯偷蘭遮罪的人，此偷蘭遮即是教唆者的究竟罪，其罪的輕重比照前述方式懺悔。

【087-0012】01_行事鈔/08c_卷中之四#9
【原文】初明大眾者。就中分七：初乞。《多論》中，莫問輕重，悉隨僧三乞，然後請懺悔主。其受懺者單白已，對首三悔，文如波逸提法。今明立大眾，要具五人以上，方得行之。並界中僧集已，具修威儀，至僧中，禮足已，先陳過於僧，然後乞云：「大德僧聽！我某甲比丘，犯淫方便重偷蘭遮罪，不憶數。今從眾僧乞懺悔，願僧聽我某甲懺悔。慈慜故！」二明請懺悔主。應至清淨比丘所，合掌互跪，請云：「大德一心念！我某甲比丘，今請大德為偷蘭遮懺悔主，願大德為我作偷蘭遮懺悔主。慈慜故！」三懺主單白，索欲問和，答云：「犯重罪偷蘭遮，單白受懺羯磨！」應白言：「大德僧聽！此某甲比丘，犯淫方便重偷蘭遮罪，不憶數，今從眾僧乞懺悔。若僧時到僧忍聽：我某甲比丘，受某甲比丘懺悔。白如是。」四當為說罪名、罪種、罪相、破戒餘習，如前後懺中。五正明捨罪，文云：「大德一心念！我某甲犯淫方便重偷蘭遮罪，不憶數，今向大德發露懺悔，不敢覆藏……」餘詞如後捨墮中說。六呵責云：「自責汝心生厭離！」答言：「爾！」第七，上之七相，律論各題；及論附事，皆不整頓。今通引誠用，想無紊亂。且據一罪，餘者準之。
【譯文】初明大眾者。就中分七：初乞。《多論》（《薩婆多毗尼毗婆沙》）中說，無論罪過輕重，全都隨順僧團作三次祈乞，然後延請懺悔主。那位受懺悔的比丘作單白羯磨之後，犯者對首三次悔過，其文句如同波逸提法。如今說明設立大眾懺法，必須具備五人以上，才得以施行。等到結界中的全體僧眾集會之後，犯者整飭具足威儀，來到僧眾之中，頂禮僧足完畢，先向僧團陳述過失，然後祈乞道：「大德僧伽請聽！我某甲比丘，犯了淫戒方便重偷蘭遮罪，不記得犯了多少次。現在向眾僧祈求准予懺悔，祈願僧團許可我某甲懺悔。請慈悲愍念！」二明請懺悔主。應當前往清淨比丘的處所，合掌互跪（胡跪，右膝著地），延請道：「大德一心念！我某甲比丘，如今恭請大德作偷蘭遮的懺悔主，祈願大德為我作偷蘭遮的懺悔主。請慈悲愍念！」三懺主單白，索取欲令並詢問大眾和合，回答說：「這是為犯重罪偷蘭遮，作單白受懺羯磨！」應當作白告白說：「大德僧伽請聽！這位某甲比丘，犯了淫戒方便重偷蘭遮罪，不記得次數，現在向眾僧祈求准予懺悔。若僧團適宜的時間已到，僧團也贊同許可：我某甲比丘，接受某甲比丘的懺悔。這是所白告之事。」四當為說罪名、罪種、罪相、破戒餘習，如同前後懺法中所述。五正明捨罪，其文句說：「大德一心念！我某甲犯了淫戒方便重偷蘭遮罪，不記得次數，如今向大德發露懺悔，不敢覆藏……」其餘文詞如同後文捨墮懺中所說。六呵責云：「汝當自責己心，生起厭離！」七立誓答言：「是！」上述七相，律論各題各異；以及《多論》所附載的事相，都未曾整飭完備。如今通盤引證而切實應用，想來不會紊亂。且姑且根據一條罪名為例，其餘各罪皆依此類推。

【087-0013】01_行事鈔/08c_卷中之四#10
【原文】第二小眾者。《十誦》：四人為小眾，若受他懺，則無單白，止得口問邊人。《四分》〈滅諍〉中，小眾者，二三人也。縱有四人，止同小法；以《僧祇》正斷五人為捨墮故，如上卷所明。立法有七，須乞懺法：初明請懺主，一如大眾。二受懺者問邊人取和，比捨墮中。三為說罪名、種、相。四正捨罪，其詞曰：「大德一心念！我某甲比丘，犯摩觸女人身上衣偷蘭遮，不憶數，今向大德發露，不敢覆藏……」餘詞如常所述。五呵責。六立誓。並同上。
【譯文】第二小眾者。《十誦律》說：四人為小眾，如果接受他人懺悔，則不需要作單白羯磨，只需口頭詢問身旁同行之人。《四分律》〈滅諍犍度〉中說，所謂小眾，是指二三人。縱然有四人，也只等同於小法；因為《僧祇律》明確判斷五人僧方能作捨墮羯磨，如同上卷所闡明。設立法度有七條，必須祈求懺悔法：初明請懺主，完全如同大眾法。二受懺者問邊人取和，比照捨墮法中所述。三為說罪名、種、相。四正捨罪，其文詞說：「大德一心念！我某甲比丘，犯了摩觸女人身上衣裳的偷蘭遮罪，不記得次數，如今向大德發露，不敢覆藏……」其餘文詞如同通常所述。五呵責。六立誓。全都與大眾法相同。

【087-0015】01_行事鈔/08c_卷中之四#12
【原文】上來三懺，事既是稀；非謂事稀，罪多懺少故也！然智人犯過，思悔必多；脫隱而不出，即成疎略。文已繁廣，事實遺漏；必若懺滌，足為準量。
【譯文】以上三種懺悔法，在日常事相上既然極為少見；這並不是說所犯之事稀少，而是因為犯罪者多而懺悔者太少的緣故！然而有智慧的人犯了過失，思量懺悔的必然很多；倘若將這些法規隱沒而不撰出，就會造成律法疏漏欠缺。律文固然已經繁瑣廣博，事相行持上卻多有遺漏；若真要依律懺悔洗滌罪障，此處所立已足夠作為遵循的標準。
