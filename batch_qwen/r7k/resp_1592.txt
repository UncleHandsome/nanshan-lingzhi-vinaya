整體讀來通順、義理方向大致無誤，但有幾處**實質誤讀**、幾處**增譯過度**，以及科判語（「故下」「即下」「或下」）處理方式不一致的問題。分項列出：

---

## 一、明顯要改的錯誤

**1. 【0005】「皆稱為滅」→ 譯成「大多」（量詞錯誤）**
原文「古譯毘尼，**皆**稱為滅」，譯文作「**大多**把它翻譯成『滅』」。這是把全稱判斷降為部分判斷，且正好削弱了下文疏主破斥的對象。應作「古來譯師翻『毘尼』，**都**稱之為『滅』」。

**2. 【0004】「故引疏注出」→ 譯文丢了「注」的意思**
譯文：「所以特別引述註疏將其**詳盡列出**」。
「引疏注出」應是「引（道宣）疏文，**於注中列出**」——即緊接其前的〔 〕夾注正是元照自己所加的注。譯成「詳盡列出」既無「詳盡」之據，也看不出「注」與「疏」的層次。
建議：「常見有人妄解，所以引疏文，在注中列出（其正解）。」

**3. 【0005】「前後兩處」重複＋「經文」應作「律文」**
譯文：「**這兩處經文前後兩處**，梵語與華語分別舉出」。除了同義重複，前句才說「律藏的〈拘睒彌犍度〉」，此處卻改稱「經文」，前後不一致；所引《四分律》兩處都是**律文**。
另：「**至**〈拘睒彌犍度〉」是「至於／另據」，不是時間上的「到了」；「**出第二**云」是指十八法中的**第二對**（即「律非律」）在該犍度作「毘尼、非毘尼」，譯成「列出了第二項」容易誤讀。
建議：「這是依〈破僧戒〉所列；至於〈拘睒彌犍度〉所列，第二對則作『毘尼、非毘尼』。前後兩處，一舉華名、一舉梵名，所以說二名不同時並舉。」

**4. 【0001】「聖通事理二和」的解讀偏了**
譯文：「『聖』**通指**事和與理和兩種和合」。原文是說**人**：聖僧兼具事和、理和；凡夫僧只有事和。「聖」不是「兩種和合」的代稱。
建議：「『聖眾』之『聖』通於事、理二和（聖僧兼有事和與理和），凡夫僧唯有事相上的和合。」（可加註：事和即六和敬，理和即同證真理。）

**5. 【0002】「軌生物解」不宜加「規範身心」**
「法」取「軌生物解」（作軌範令人生解），「律」取「調身口、離七非」——這是元照分判二名的關鍵。譯文在「法」下加「能規範身心」，正好把「律」的內涵混進來，兩名的對顯就模糊了。
建議：「八正道能作為軌範、令眾生於法生起理解，這就是『法』。」

**6. 【0003】「壞葉墮龍」的處理**
- 「**公案**」是宗門用語，用在律記譯文中不宜，改「事例／因緣」。
- 「調**見**」是「見到（經律所載）」，不是親眼「看見」。
- 此指伊羅鉢龍本緣（迦葉佛時比丘壞生樹葉，後墮龍身），宜加短註，否則讀者不知「壞葉」何以「墮龍」。

---

## 二、需要查證的疑點

**1. 【0004】「餘是經約」**
譯文作「其餘是**經教中**的常規約束」。這句可疑：上句「四是重禁」、下句「四輕餘重」，文勢明顯是**重／輕**相對，「經」很可能是「**輕**」之訛（輕約）。建議核 CBETA（T40, no.1805）原文與校勘。即使照現字讀，「經」也只能作「常」解（常規制約），添「經教中」會誤導為經藏所說，與「佛制律」的語境不合。

**2. 【0004】「疏」所指**
「故引疏注出」之「疏」，一般指道宣《四分律含註戒本疏》（或《業疏》），宜查明後在譯注中標出，不要泛稱「註疏」。

**3. 【0002】「注顯異號」**
若所指是**音譯用字之異**（毘尼／毗尼／鞞尼之類），譯文「各種不同異名……全是輾轉流傳的訛誤」宜補一句「此指音譯用字之別，非另有別義」；若指義譯異名，則說法不同。建議回到鈔文確認。

**4. 【0005】「破僧戒」**
譯作「破和合僧戒」可通，但「破僧」有破法輪僧／破羯磨僧之別，此處屬調達破法輪僧，宜保留「破僧戒」並略註，避免與「破羯磨僧」混同。

## 三、增譯與用語（建議清理）

以下字詞原文無據，屬譯者自行添飾，累積起來會讓注文語氣失真：

| 譯文 | 問題 |
|---|---|
| 資助長養的「**妙用**」 | 「用」即可 |
| 世尊「**必定會由衷地**」稱譽 | 「所稱譽」是被動式，無「必定」「由衷」 |
| 「**稱讚稱譽**」 | 同義疊用，取一即可 |
| 「**極大地**」契合愉悅聖心 | 「悅可聖心」無程度副詞 |
| 「五種**極端**苦行」 | 「五邪／五法」即可，「極端」是評價 |
| 「**妄言**／**揚言**／**堅持**」 | 原文只是「便謂」「便言」「說」 |
| 「**詳盡**列出／更加彰顯**確鑿**」 | 「注出」「益顯」無此強調 |
| 「不被**我們**採用」 | 「故所不取」宜作「所以不取此譯」 |
| 「各種**不同異名**」 | 「異名」已含「不同」 |
| 「道業法身即無由存立」 | 「人亡」的引申，可簡化為「人（能弘者）無由成立」 |

另：「遮惡為輕」宜作「遮罪（相對於性罪）為輕」，「微細」可刪；「五篇是佛制」譯成「五篇**罪相**」偏窄，宜作「五篇戒法」。

## 四、術語與可讀性建議

1. **科判語統一格式**。目前「所以接下『故下』引文作證」「接下『即下』引述……」「接下『或下』指出……」既冗贅（「所以」與「故」重複），又把標舉語當正文讀。建議一律作：
 「（鈔文）『故』字以下，是引證」「『即』字以下，引出所據」「『或』字以下，指斥古譯之非」「『故』字以下，顯示正義」。
2. 【0001】「又四，初二句翻名」：譯成「又細分為四點，前兩句……」，「點」與「句」混用易誤解。宜作「又分四節，第一節中最初兩句是翻名」。
3. 【0005】「故云不並」未白話化，宜補「（梵華二名）不並舉」。
4. 【0005】「名不附體」理路可補一句：**「滅」只是作用而非體性，以用為名，故名不附體**——否則讀者不易看出「水滅火而水不名滅」的類比要點。
5. 可加短註處：七非（身三口四）、四諍（言、覓、犯、事）、有殘／無殘（尚有餘殘可懺／永障無餘）、調達五法內容。另「九邪九正」與注中「八正道／五法」數目不相應（八正、五法是就內容舉示），建議加一譯注說明，免得讀者以為算錯。

## 五、示例改寫（【0005】前半）

> 這是依〈破僧戒〉所列的名目；至於〈拘睒彌犍度〉，第二對則作「毘尼、非毘尼」。前後兩處律文，一舉華名、一舉梵名，所以說二名不並舉；由此可知「律」這個譯名，是律藏自身所翻。以下又引經文，稱七滅諍為「七律」，譯「律」所據就更明顯了。「或」字以下，是指斥古譯之非，文見《毘尼母論》。疏中說：古來譯「毘尼」都稱為「滅」，是因為七毘尼能殄息四諍；但如水能滅火，水本身並不叫「滅」——滅只是用，不是體，名不附體，所以不取此譯。「故」字以下，是顯示正義。
