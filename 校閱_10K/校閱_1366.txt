# 校閱材料　第1366檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1366-0001】資持記/16a_下四#64
【原文】律下，次教呪誓。謂有屈抑之事，發誓以雪之，意是求佛為證，故云南無佛等。十中。恐怖，謂暗黑險難等處；存想三寶，必蒙加被，即得安隱。十一。律論所制，皆謂避世譏疑，遠防欲染故也。十二，前明嚼楊枝，初出不嚼之過。癊，即痰癊。引，猶進也。《五分》，教洗棄。《四分》須屏處。
【譯文】從「律」字以下，接著教導如何如法發願詛誓。這是指僧人遇上蒙受委屈冤抑難以申雪的事情時，發出誓願以洗刷自己的冤屈，其本意是祈求佛陀降臨作證，所以才稱念「南無佛」等等。在第十小段中：所謂「恐怖」，是指走入黑暗荒野、險峻危難等令人怖畏的處所；此時只要一心專注存想三寶功德，必定能蒙受佛力加被護佑，當下便能獲得安穩與平靜。在第十一小段中：各部律論所立下的禁制規範，全都是為了迴避世俗之人的譏嫌疑慮，從深處預先防範情欲染著的生起。在第十二小段中，前面先說明嚼咬楊枝淨齒的法度，首先指出不嚼楊枝所招感的種種過咎。所謂「癊」，就是胸膈所積聚的痰癊之疾。文中的「引」字，意思等同於「進」，指進食（能進飲食）。《五分律》教導嚼完楊枝後應當洗淨隨後丟棄。《四分律》則規定嚼楊枝必須在隱蔽處進行。


【1366-0002】資持記/16b_下四#1
【原文】大小二事，因而連引。次明經行，初顯益。一謂慣熟，二即專一，三謂血氣均和，四五可解。《十誦》示行相。晝地，謂作直道，不使斜曲故；或用磚石，為之。《寄歸傳》云：五天之地，道俗多作經行，直去直來，唯遵一路。〔謂以磚石累為直道，狹而且長，人之往來，有同經緯，故以名焉。
【譯文】大小二便之事，因而相連引申。接著說明經行，首先顯明益處：一是習慣熟練，二是心神專一，三是血氣調和均勻，第四、第五點則容易理解。《十誦律》開示經行的行持相狀。「畫地」，是指開闢一條筆直的小路，不讓它斜曲；或者用磚石來鋪設。《南海寄歸內法傳》記載：五印度的地域，僧俗大眾大多作經行，直直走去、直直折返，只循著一條道路。（這是說用磚石堆砌成筆直的步道，狹窄而且長，人的來來往往就像織布的經線與緯線，所以用「經行」來稱呼它。）

【1366-0003】資持記/16b_下四#2
【原文】又云：佛經行之基，闊二肘，長十四五肘。〔闊三尺六，長二文六七許。〕上以石作蓮華開勢，高二寸，闊一尺有十四五，表聖足迹也。《三千》中，明作處。隨處所宜，不可局故。十三，《僧祇》明眾處燈，初教上燈。乃下，次示息燈。亦爾者，同上告僧。
【譯文】《寄歸傳》又說：佛陀經行之基址，寬二肘，長十四至十五肘。（大約寬三尺六寸，長二丈六七尺左右。）上面用石頭雕刻出蓮花綻開的形勢，高二寸，寬一尺，共有十四、五朵，象徵聖者的足跡。《三千威儀》中說明經行的處所，應當隨順各處所合宜的情形，不可執著拘泥。第十三段，《僧祇律》說明大眾共聚處的燈火，首先教導點燈。「乃」字以下，接著指示熄燈。「亦爾」是指如同前面一樣告知大眾僧。

【1366-0004】資持記/16b_下四#3
【原文】䩭，《尼鈔》作欹，以箸取物也。下文指廣，彼云：然燈時，當先照舍利，及形像前燈；禮拜已，當出滅之；乃至若多油者，廁屋中，當竟夜然；若油少者，人行斷，當滅之。次明供佛燈。今時所謂長明燈也；若佛有明暗，則當夜點晝滅；以無明暗，故不間晝夜。本無言念，謂施主期心；
【譯文】「䩭」字，《比丘尼鈔》作「欹」，是用筷子夾取物品的意思。下文指示詳細內容，那裡說：點燈的時候，應當先照耀舍利以及形像前之燈；禮拜完畢後，應當退出熄滅它；乃至如果燈油充裕，廁所屋內應當整夜燃燒；如果燈油較少，行人往來斷絕時，就應當熄滅它。接著說明供佛的燈，就是現今所說的長明燈；如果佛陀有明暗的分別，那就應當夜間點燃、白天熄滅；因為佛沒有明暗的分別，所以不間斷白天與黑夜。「本無言念」，是指施主當初發願的心期；

【1366-0005】資持記/16b_下四#4
【原文】必有齊限，滅應無過。次引經證。彼十一云：佛在舍衛，有女名難陀，乞匃自活；見諸國王臣民，供養佛僧；自心思惟：我之宿罪，生處貧賤；雖遭福田，無有種子；便行乞丐，以俟微供；唯得一錢，指詣油家，具語所懷；油主憐愍，增倍與油；得已歡喜，足作一燈，奉上世尊；
【譯文】施主若必定有期約限度，熄滅就應當沒有過失。接著引用經典為證。《賢愚經》第十一卷說：佛陀在舍衛國時，有一位名叫難陀的女子，靠乞討維生；她見到各位國王、大臣與人民供養佛陀與僧眾，自心思維：我前世宿業之罪，出生在貧窮卑賤之處；雖然遇到了福田，卻沒有播種的種子；於是四處行乞，以備辦微薄的供養；好不容易只討得一枚錢，便直奔油坊，詳細說明自己的心願；油坊主人憐憫她，加倍給予油量；得到之後非常歡喜，剛好足夠做一盞燈奉獻給世尊；

【1366-0006】資持記/16b_下四#5
【原文】自立誓願：我令貧窮，用是小燈，供養於佛；以此功德，令戒來世，得智慧照，滅除一切眾生垢暗。作是誓已，禮佛而去；乃至竟夜，諸燈盡滅，唯此獨然；是時目連當次直日，欲取滅之；即舉手扇，復以衣扇；
【譯文】難陀女自己立下誓願：我如今貧窮，用這盞小燈供養於佛；願以此功德，令我於來世備受智慧光明之照耀，滅除一切眾生的垢染昏暗。立下這個誓願後，禮拜佛陀便離去；乃至到了天明整夜過去，所有的燈都已熄滅，唯獨這盞燈依然獨自燃燒著；當時目犍連尊者正值輪班值日，想要取來熄滅它；隨即舉手去搧，又用僧衣去搧；

【1366-0007】資持記/16b_下四#6
【原文】燈明不損，佛語目連：今此燈者，非汝聲聞所能傾動，正使四大海水以用灌之，毘嵐風吹之，亦不能滅；此是發大心人所施，佛說是已；難陀女復來，頭面作禮；佛即授記，於來世二阿僧祇劫，當得作佛，號曰燈光，十號具足。十四，《五分》。乞狗乞鳥減乞，三乞字並去呼。分外，謂多受而施。《四分》。人，即乞人等；
【譯文】燈火光明絲毫未損，佛陀對目犍連說：現在這盞燈，不是你們聲聞乘人的力量所能傾動熄滅的，就算用四大海水來澆灌它，用毗嵐狂風來吹它，也不能熄滅；這是發大菩提心的人所布施的。佛陀說完這話，難陀女又前來，以頭面頂禮佛足；佛陀隨即為她授記，在未來世過二阿僧祇劫，當得成佛，佛號名為「燈光」，十種通號具足圓滿。第十四段，《五分律》。施食給狗、施食給鳥以及減少自己所食以施與，此處三個「乞」字都讀去聲（作「給與」解）。「分外」，是指多接受了施物而轉施出去。《四分律》。「人」，就是乞討之人等；

【1366-0008】資持記/16b_下四#7
【原文】非人，即鬼神禽畜。《母論》。人中別類。無過，謂非污家。十五。壞色，謂面無神色。生犯戒緣，即露地然火掘壞等戒，因而成犯。十六。初二自他心淨，三執勞作務，四挫折自高，五現當兩報。第四門。前諸雜事，並是隨人各行，故名別人自行；
【譯文】「非人」，就是鬼神、禽獸、畜生。《毘尼母論》。「人中別類」，是指一般人以外的特殊階層。「無過」，是指並非俗事污家。第十五段。「壞色」，是指面容沒有光采神色。「生犯戒緣」，就是露天燃火、掘壞土地等戒律，因而構成違犯。第十六段。前二種是自心與他心清淨，第三是承擔勞務差使，第四是挫折傲慢自高之心，第五是現世與來生兩種福報。第四門。前面各項雜事，都是隨順個人各自奉行，所以稱為個別人的個人修行；

【1366-0009】資持記/16b_下四#8
【原文】此門所明誦持經戒，無論利鈍新舊之殊，但預道門，義當依奉，故云共行同法。正明中，初科，前敘誦持之要。而下，顯根性不同。神用即心智。互強弱者，謂聞多解少，或聞少解多；有下，即初人；故下，即次人。次科為四，初教誦綱要。古德未詳何人。
【譯文】本門所說明的誦持經文與戒律，無論利根、鈍根、新進、久修的分別，只要進入了佛門道途，義理上都應當依教奉行，所以稱為「共同修行的同等法則」。正文說明中，第一個科判，前面先敘述誦持的要旨。「而」字以下，顯發根性的不同。「神用」就是心智。「互有強弱」，是指聽聞得多而理解得少，或者是聽聞得少而理解得多；「有」字以下就是指前一種人；「故」字以下就是指後一種人。第二個科判分為四部分，首先教導誦持的綱領要點。「古德」尚未詳知是指何人。
