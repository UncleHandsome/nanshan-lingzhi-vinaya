# 句級合編規劃（行事鈔 ＋ 資持記）

## 目標
把《行事鈔》與《資持記》從「篇級合編」推進到「句級合編」：每個鈔文段落後面緊接元照針對該段的記文，而不是整篇末尾才放全部記文。

## 現況
- 鈔：34 塊、5,358 段原文，每段有白話，段號固定。
- 記：77 塊（資持記_細分）、4,291 段，「釋XX篇」可切出 34 個篇級區塊。
- 已有 30 篇對照表，產出三冊篇級合編。

## 三種對位法（依可靠度排序）

### A. 引文錨定（最可靠）
資持記常整句引用鈔文（「鈔云」「文中」之後）。
1. 從記段抽出引號或「鈔云」後的片段（連續 12 字以上）。
2. 在該篇鈔段中模糊比對（容異體字、脫字）。
3. 命中者建立「記段 → 鈔段」邊。
4. 預估命中率：篇內 30–50%。

### B. 科判對位（次可靠）
記文科判序（初、二、三…）與鈔文分科一一對應。
1. 抽記段開頭科判字，建序列表。
2. 抽鈔段科判標記（初、第二…）。
3. 序數相同則配對；不齊時最近未配對遞補。

### C. 篇幅比例分配（後備）
同篇內 A、B 都無法配對時：
1. 算鈔段與記段累計字數。
2. 按比例單調分配（不回頭）。
3. 標記為「推定」，不與 A/B 混用。

## 輸出格式
每個鈔段：
　【鈔】原文（淺褐底）
　　　　白話
　【記】原文（淺藍底）
　　　　白話
一個鈔段可掛多個記段；無法配對的記段集中放篇末，標「【記・篇末】」。

## 驗證
1. 配對率：A+B 應達 60% 以上，其餘標 C。
2. 長度比：記白話／鈔白話 應在 0.3–4 倍，超出抽樣檢查。
3. 抽讀：每篇抽 3 組確認語意連貫。
4. 段數不變：鈔 5,358 段、記 4,291 段，合編後不得遺漏。

## 執行順序
1. 等 fix 批次（part3/4）套用完成、段數檢查通過。
2. 先做「標宗顯德篇」原型，人工看 3 頁。
3. 通過後跑全書，輸出三冊 PDF。
4. 網站加「合編」入口。

## 風險
- 記文常「總釋」整篇而非逐句，大量段落掛不上去 → 篇末集中處理。
- 引文比對可能誤配 → 要求引文 ≥12 字且唯一。
- 鈔、記白話出自不同批次，語體略異 → 可接受，不重譯。
