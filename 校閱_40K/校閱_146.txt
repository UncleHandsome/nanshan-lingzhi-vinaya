# 校閱材料　第146檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【146-0001】02_戒疏/11b_卷三上之二#19
【原文】【疏】初名者。昔云屏、露兩殊，名之為「二」。四法無準，故曰「不定」，謂犯、舉、言、治各非定故。
【譯文】【疏文】首先是解釋名稱。古德曾說：屏處與露處兩種情境不同，所以名為「二」。由於涉及四種法都沒有固定標準，所以稱為「不定」，意思是犯戒、舉發、自陳與治罪四個方面各自都不是固定唯一的。

【146-0002】02_戒疏/11b_卷三上之二#20
【原文】【記】釋名中，昔解。「四法」，《義鈔》引云：「一、犯不定，以夷、殘、提，或單或竝，犯不定故。二、舉不定，俗女舉罪，不識罪名，稱非法事，一二三舉，如犯不定故。三、自言不定，舉罪既多，自言何一？四、治不定，隨犯三罪，三法治故。」
【譯文】【記文】在解釋名稱中，引用了古德的解說。「四種法」在《戒疏義鈔》中引用說明：「第一、所犯不定，因為在波羅夷、僧殘、波逸提之中，可能是單犯某一條，也可能兼犯數條，所犯之罪不定。第二、舉發不定，在家婦女舉發罪過時，不懂得具體罪名，只是陳述非法的舉動，可能舉發一罪、二罪或三罪，就像所犯之罪一樣不確定。第三、自我陳白不定，既然被舉發的罪嫌眾多，僧人自己承認的又是哪一條？第四、懲治處分不定，隨著承認犯了哪一種罪，就依照相應的三種法度來治罰。」

【146-0003】02_戒疏/11b_卷三上之二#21
【原文】【疏】今言「不定」者，本無三四之名，浪立治舉。但於二中，未定實犯。《律》云：「是中無定法，故云『不定』。」故《十誦》云：「於三篇中，趣說一事。可信女人不知犯，不知起，不知名字，但云『我見女人來去坐立。比丘亦爾，不見作婬相』等。不決定故，名『不定』也。」
【譯文】【疏文】我們現在所說的「不定」：原本並沒有所謂三種或四種的分類名稱，古人隨意安立了「治罪不定」、「舉發不定」等說法。其實只是在兩種情境之中，尚未能判定到底實際觸犯了什麼罪。《律本》說：「因為這當中沒有固定的罪法，所以稱為『不定』。」因此《十誦律》說：「在三篇之中，姑且隨意指稱一件事。可信賴的女子不知道具體犯了什麼罪，不知道罪緣從何生起，也不知道具體罪名，只是說『我看到女人走來走去相坐或相對站立。比丘也是這樣，但我並沒有親眼見到行淫的舉動』等等。由於情況無法確定，所以命名為『不定』。」

【146-0004】02_戒疏/11b_卷三上之二#22
【原文】【記】今解中。初斥非。言「本無」者，非典據也。言「浪立」者，任𦙄臆也。此但略斥，餘如《義鈔》。「但」下，顯正。「二」字同前，故但釋「不定」。謂俗女心疑，故云「若波羅夷」等。犯未定實，故云「不定」。次引《律》證。「無定法」，即目犯也。次《十誦》中，彼云「不知犯」，「不知何處起」，「不知犯名字」，餘同所引。
【譯文】【記文】在今師的新解中。首先斥責古德的錯誤觀點。說「原本沒有」，是指沒有正統經律作為依據。說「隨意安立」，是指僅憑個人的主觀臆想。這裡只是簡略批評，其餘詳盡辨析如同《戒疏義鈔》所述。「只是」以下，顯發正確的觀點。「二」這個字的定義與前面相同，所以此處只單獨解釋「不定」。意思是可信賴的女人心中起疑，所以說「若是犯了波羅夷」等等。所犯的實情尚未確定，所以稱為「不定」。接著引用《律本》為證。「沒有定法」，指的就是犯戒之相。接下來是《十誦律》的記載，那裡說「不知道所犯何罪」、「不知道從何處生起」、「不知道罪過名稱」，其餘文義與此處所引用相同。

【譯文】【記文】「如果是這樣，這與古德所說的『所犯不定』有何不同？」

【146-0008】02_戒疏/11b_卷三上之二#26
【原文】【疏】有人言：「如法自言能治行，非法自言所防罪。」
【譯文】【疏文】有人主張：「如法地自我坦白發露是能治的善行，違法的自我陳白則是此戒所防堵的罪過。」

【146-0009】02_戒疏/11b_卷三上之二#27
【原文】【記】次出體中，古解。彼謂《戒本》中比丘言「我犯是罪」，二三不定，即「非法自言」，此即戒家「所防過」。制令「如法自言」，即「能治行」。
【譯文】【記文】在接下來標明戒體的段落中，先列出古德的見解。那位法師認為《戒本》中比丘說「我犯了此罪」，在二罪三罪之間游移不定，這就是「違法的陳白」，正是戒法所要「防範的過失」。佛陀規定僧人必須「如法地坦白陳說」，這就是「能治罰的善行戒體」。

【146-0010】02_戒疏/11b_卷三上之二#28
【原文】【疏】有人云：「屏錄三罪，露收兩罪，此即是罪為不定體。」
【譯文】【疏文】又有人說：「屏處涵蓋三種罪嫌，露處則涵蓋兩種罪嫌，這幾種罪名本身就是不定的戒體。」

【146-0011】02_戒疏/11b_卷三上之二#29
【原文】【記】次師中。準《義鈔》，先難初師云：「若爾，我亦七聚罪，皆有非法自言，何獨此三，餘四不彰？又復尼亦有非法自言，何無不定？」次師乃以《戒》文所疑之罪即「不定體」。《義鈔》甚廣，且直示耳。
【譯文】【記文】在第二位律師的觀點中。參照《戒疏義鈔》，古人先詰難第一位律師說：「如果是這樣，我們佛門的七聚罪過之中，都有可能存在非法的陳白，為何偏偏只挑這三篇，其餘四聚卻不彰顯？再者，比丘尼也有非法陳白的情況，為何比丘尼戒中就沒有不定法？」第二位律師於是將《戒經》經文所懷疑涉嫌的罪名直接當作「不定的戒體」。《義鈔》的論述非常寬廣，此處僅直接指陳其要旨。

【146-0012】02_戒疏/11b_卷三上之二#30
【原文】【疏】今解不然。二三罪體，名種各別，如何束之以為一戒？今云房室私禮，俗所常行。而比丘無侶，獨一女人同處麤語，於三罪中令他疑怪，犯相難分，故言「不定」。
【譯文】【疏文】我們現在的理解並非如此。二罪或三罪的罪體，其名稱與種類各自有別，怎麼能勉強包裹在一起當成同一條戒？現在應當解釋為：房室之內的私密行徑，是在家俗人日常習以為常的事。然而比丘身邊毫無同伴，獨自與一名婦女在同一處所說麤惡淫穢的言語，在三種罪嫌之中引發了他人的懷疑怪罪，犯戒的真實相狀極難分清，因此稱為「不定」。

【146-0013】02_戒疏/11b_卷三上之二#31
【原文】【記】今解，初科，又二。初斥非。初師已如次師所破，今略不引，但斥次師耳。「今云」下，立義。準《義鈔》，即首解也。
【譯文】【記文】在今師的解釋中，這是第一科，又分為兩層。首先駁斥前人的錯誤。第一位律師的觀點已經如第二位律師所破除的那樣，現在略過不再引述，只駁斥第二位律師的看法。「如今應當說明」以下，樹立正確的義理。依照《義鈔》，這正是智首律師的解釋。

【146-0014】02_戒疏/11b_卷三上之二#32
【原文】【疏】何須禁者？出家遊棲，或入聚落，因事交涉，汙辱彼此。所損非輕，故宜須制。
【譯文】【疏文】為什麼必須制定此戒來禁制？出家人遊化棲息，有時會進入村落聚落，因世事往來交涉，極易招致彼此的污損與羞辱。這所造成的毀損非同小可，所以極有必要立法禁制。

【146-0015】02_戒疏/11b_卷三上之二#33
【原文】【記】次科，「入聚交涉」者，則知此篇犯在俗舍，如戒緣說。
【譯文】【記文】下一科中，「進入村落往來交涉」，便可知曉本篇所犯的戒境多是在俗人的房舍之中，就如同制定本戒的緣起所記載的一樣。

【146-0016】02_戒疏/11b_卷三上之二#34
【原文】【疏】所以須取三罪疑事者，此之疑心，由來未制，故得從疑，以為戒本。若取三罪，諸篇已結，何假此中方言「最初」？
【譯文】【疏文】之所以必須以牽涉三罪的起疑之事為本戒，是因為這種引起懷疑的心思，自古以來未曾立法禁止過，因此可以順應這種嫌疑，將它立為本戒的戒條。如果直接取三種罪作為戒體，其他各篇早已制定結罪，何須假借在此處才說是「最初制定」呢？

【146-0017】02_戒疏/11b_卷三上之二#35

【譯文】【記文】第三、說明最初犯戒的情形，在古德的解說中。首先立下論點。「因為」以下，解釋其成立的原因，經文既然「列出治罪之條」，就表示並非沒有犯過罪。「雖然」以下，化解可能面臨的質疑。因為《四分律本》中兩條戒都並列著「最初未制戒者不犯」，所以古德曲折地加以解釋。他們認為前面制定的五篇罪名稱為「個別廣說」，這兩條不定戒則稱為「總括廣說」，因為《戒本》在此總括了前面的諸多戒條。當初制定五篇時，是制定廣義戒律以彌補略教的不足，所以最初犯戒者不算有罪。如今制定不定戒，則是「制定總括的廣戒」以「補足個別廣戒」。相對於觸犯個別廣戒而言，所以《律本》才列出「最初」；但此時並非完全不犯，所以將其判定為「第二起犯戒才結罪」。參照《戒疏義鈔》，原文中「總制」兩字刻寫顛倒，應調轉過來閱讀。

【146-0070】02_戒疏/11b_卷三上之二#88
【原文】【疏】就戒緣中。言「毗舍佉母」者，《多》云：「此人聰明，已入道迹。常聞佛說聽法五利：一、得未聞法；二、清淨堅固；三、除邪見；四、得正見；五、解深法。故來屏聽，不以嫌疑。」《見》云：「毗舍佉母有十男十女，各有二十兒孫，合四百二十人，國中稱之婚法準則。」

【146-0071】02_戒疏/11b_卷三上之二#89
【原文】【記】戒緣中。初引《多論》明彼聽意。《論》先問云：「毗舍佉母聰明利根，大德重人，何故往聽也？」《疏》引答詞。「道跡」謂初果。「聽法五利」：一、解，二、行，三、識非，四、達是，五、資深。彼持佛說，故來聽法，不謂惡語故也。次引《見論》示其族望。一男一女，各生二十子，即有四百孫。「婚法準則」，謂有家豐，為人所法也。
