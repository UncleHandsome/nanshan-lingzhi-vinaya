# 校閱材料　第1290檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1290-0001】資持記/13d_下一#35
【原文】著得墮罪，故須入重。今不具引，直牒彼計，引類難破。絹布不出黃白二色，同是五大，亦不許著，而判在輕。故知不可但據佛制不著，便謂入重。若爾下，例難。𣰽毹前有兩斷，彼謂入輕，乃是約量；入重正是約色，故有此難。答中。初明入輕，但離綺錯；縱純上色，亦判入輕。
【譯文】穿了會得波逸提罪，所以必須歸入重物。如今不全面引述，直接提出對方的見解，藉由同類事相來質難反破。絹布不過是黃、白兩種顏色，同樣屬於五種大色，律中也不允許穿著，然而卻判定屬於輕物。由此可知，不能單單根據佛陀禁止穿著，便認定屬於重物。從「若爾」往下，舉例質難。前面對於毛毯有兩種斷決，對方認為歸入輕物是就尺寸而言；歸入重物才是專就顏色而論，所以有此質難。在回答中。首先說明歸入輕物，只要遠離文采錯雜；縱使純是上位正色，也可以判定歸入輕物。

【1290-0002】資持記/13d_下一#36
【原文】故知但分文之純雜，不論色之如非。故引《五分》為證，彼云：錦綺毛𣯊等不應分，若純色者應分。四中。含，包也。儀云：有蟲之繭，著稈之麻。竝謂未成縷者。稭音皆，麻稈也。五中，初判輕。注約串於肩上，取兩頭以為齊限，即非大者。準《五分》者，上明數量，即出《五分》。下三入重，竝謂大者。
【譯文】由此可知只要分辨花紋的純淨或雜亂，不論顏色是否合乎法度。所以引述《五分律》作為佐證，該律說：錦繡、彩綺、毛布等不應當分配，如果是純色無紋的，則應當分配。在第四項中。「含」即是包裹的意思。《輕重儀》說：有蠶蟲在內的蠶繭，連帶著麻稈的麻料。都是指尚未紡成紗縷的原料。「稭」，音同「皆」，就是麻稈。在第五項中，首先判定輕物。註解是就斜搭在肩頭，以雙手兩端為齊限標準，這就不是大件物袋。所謂「依照《五分律》」，上面闡明的數量尺度，就是出自《五分律》。後面三種歸入重物，都是指大件的袋子。

【1290-0003】資持記/13d_下一#37
【原文】被袋隨被判也。連袋，古云：兩頭縫合，中間開口也。儀云：以綺錯所成，同俗被袋，不入分限。六中，壞色異俗，折破非衣，故竝入輕。猶是下，反上二種故重。儀云：為絕懷俗之心故。襦，短衣也。七中。綵線靴鞋者，儀云：時有作三臺龍鳳〔得頭有三層者〕，及錯綵線綺繡刺成者入重。
【譯文】被袋是跟隨著被褥來判定的。「連袋」，古德說：兩頭縫合閉鎖，中間開口的袋子。《輕重儀》說：因為是由彩繡錯雜製成，如同世俗的被袋，不納入分配之限。在第六項中，壞色衣與世俗不同，剪破折損的布料不成完整衣服，所以全都歸入輕物。從「猶是」往下，與上述兩種相反所以屬於重物。《輕重儀》說：這是為了斷絕貪著世俗的心念。「襦」，指的是短襖上衣。在第七項中。所謂彩線靴鞋，《輕重儀》說：當時有人製作三台龍鳳紋飾〔靴頭有三層構造者〕，以及用雜彩線、綺繡刺繡而成的鞋子，這些都歸入重物。

【1290-0004】資持記/13d_下一#38
【原文】男女衣服，即童男稚女花綵之衣。補方，舊云：即裁五彩畟方補合成者。儀云：繡纈結絡，綺錯綵袋，俱從重收；純色氈袋等，竝入分也。繡綺鉢袋輕者，隨鉢判故。若準儀文云：繡綵裝飾者，可單抽重收，事同繡錦之服故。第二標中。五體總收五物。石鐵二種，總諸金寶。《四分》，初科，前總列諸物。
【譯文】男女衣服，指的就是童男童女所穿的花彩衣物。「補方」，舊說認為：就是裁剪五彩布料拼成正方形補綴縫合之物。《輕重儀》說：刺繡、扎染、編結瓔珞、紋理繁複的彩袋，全都歸從重物收納；純色的氈袋等物，則全都納入分配。刺繡彩飾的缽袋算作輕物，是因為隨著缽體判定的緣故。但若依照《輕重儀》的文意說：飾有刺繡彩料點綴的缽袋，可以單獨抽出來作為重物收納，因為其性質如同錦繡衣物一樣。在第二類器物的標題中，五類材質總括了五種物品。石與鐵這兩類，總括了各種金銀珠寶。在《四分律》中，第一科，前面總體列舉各類物品。

【1290-0005】資持記/13d_下一#39
【原文】即十三章門六章之物。瓶盆及下斧鑿燈臺，在第五；二床在第七，水瓶等在十一；車輿等在十，鐵皮等作器在十二；下明染色，針線，即第六成衣眾具〔共前為八〕。律竝判重，下引諸部，則有科酌。此下，別簡作具。儀云：古德謂不問能所皆重。故此決之。初正示。故下，引證。
【譯文】這指的就是十三章門中六章的物品。瓶、盆以及後面的斧、鑿、燈台，位列第五章；兩種床位列第七章；水瓶等物位列第十一章；車輿等物位列第十章；鐵、皮等工巧器具位列第十二章；下文闡明的染色原料、針線，就是第六章的製衣眾具〔與前合為八項〕。律中全都判定為重物，下文引述各部律，則有衡量通融的判斷。從「此」字往下，個別辨析工巧器具。《輕重儀》說：古德認為不論是能造之具還是所造之物，全都屬於重物。所以此處加以決斷。首先作正面指示。從「故」字往下，引文作證。

【1290-0006】資持記/13d_下一#40
【原文】注簡所造差別，不可一判；則明上云入重，定是能造。儀云：鐵作器者，鑪治鉗碪錯等器，陶作器謂輪繩袋簿鍬钁等具，皮作器謂盆瓮床桄刀剗熨鐵等，竹作器謂刀鋸等，木作器謂斧鋸斤剗等。此皆妨道，不合畜故。次科。剃刀入輕，從用輕故。三中。
【譯文】註解中簡別所造之物的種種差別，不可一概而論；這就說明了上文所說歸入重物者，必定是指「能製造」的工具。《輕重儀》說：鐵作器，指的是熔爐、冶鍊用鉗、鐵砧、銼刀等工具；陶作器，指的是陶輪、繩索、泥袋、竹簾、鍬、钁等用具；皮作器，指的是水盆、瓮、床側桄木、刮刀、鏟刀、熨斗等物；竹作器，指的是竹刀、竹鋸等物；木作器，指的是斧頭、鋸子、斤斧、木鏟等物。這些器具都會妨礙修道，不合宜蓄存。下一科。剃刀歸入輕物，是因為從用途上看屬於輕之故。在第三項中。

【1290-0007】資持記/13d_下一#41
【原文】錢通入種〔金、銀、銅、鍮、鐵、木皮、胡膠〕，寶總真似〔金銀真珠摩尼珊瑚車磲碼碯及諸璧玉為真寶，鍮銅鐵錫偽珠等為似寶。〕。錢及真寶皆重，不淨物故。似寶若本塊段入重，入百一數者皆輕。下文，即律衣法中，拾糞掃者取之，因開。此證錢寶是不得畜。
【譯文】「錢」通指八種幣材〔金、銀、銅、鍮石、鐵、木皮、胡膠〕，「寶」總括真寶與假似之寶〔金、銀、珍珠、摩尼寶珠、珊瑚、硨磲、瑪瑙及各種美玉為真寶，鍮石、銅、鐵、錫及假珠等為假似之寶〕。錢幣與真寶都屬於重物，因為這是不清淨之物。假似之寶如果原本是整塊粗段則歸入重物，如果已製作納入百一供身物之數的則全都算作輕物。下文，即是律中衣法所言，拾取糞掃衣料者可取用，因之而開許。這證明錢財珍寶是不得私自蓄存的。

【1290-0008】資持記/13d_下一#42
【原文】諸部中，初科，前通列諸物。皆是小者。半鉢，即淺鉢；戶牌，標戶鉤者。若下，別簡諸器。貝即海虫殼，齒即獸牙。作器謂上四物所作者。如前即指上諸鉢。注，姬周半斗，即今一升半許。上明器物。一切下，判染色。儀云：紫草黃蘗梔子乾陀等，此皆木類。次科，《僧祇》三節，初判二寶。次判床器。
【譯文】在諸部律中，第一科，前面通體列舉各種器具物品，這些全都是小型的器具。「半缽」就是較淺的缽；「戶牌」是標記門鉤的牌子。從「若」字往下，個別簡擇各類器具。「貝」就是海中貝殼，「齒」即是獸牙。「作器」指的是以上述四種材質所製作的器物。「如前」指的就是前述的各種缽。註解中，周朝的半斗，大約等於現在的一升半左右。以上是說明器物。從「一切」往下，判定染色之物。《輕重儀》說：紫草、黃蘗、梔子、乾陀等，這些都屬於木本植物之類。下一科，《僧祇律》分為三節，首先判定金銀真偽二寶。其次判定床座器具。
