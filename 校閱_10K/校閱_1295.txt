# 校閱材料　第1295檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1295-0001】資持記/13e_下一#11
【原文】若下，示制。《疏》即《業疏》，《鈔》即《義鈔》，文逸。二中。記數，謂知僧多少。品即量也。三中，初示教所不許。今下，斥世非法，初正斥。顏厚，謂無羞色也。佛下，示意。今下，重責。惟即思惟。始終，謂生死。悛，改也。望下，深勉。四人法中，初示僧位。
【譯文】在「若下」的部分，出示相關戒律制度。所謂《疏》即是指《羯磨疏》（業疏），《鈔》即是指《義鈔》，該段原文如今已佚失。在第二個小段落中。所謂記數，是指知曉僧眾確切的人數多寡。所謂品，就是衡量的意思。在第三個小段落中，首先指出這是佛教教法所不容許的行徑。在「今下」的部分，痛斥當世違反戒律的非法作為，起初予以嚴正斥責。所謂顏厚，就是指毫無慚愧羞恥的神色。在「佛下」的部分，指明佛陀制戒的深意。在「今下」的部分，給予嚴重的斥責誡厲。所謂惟，就是思惟反省。所謂始終，是指整個生死輪迴的過程。所謂悛，就是悔改的意思。在「望下」的部分，寄予深切的勉勵期許。在四人同修的法式中，首先出示參與僧眾的位階人數。

【1295-0002】資持記/13e_下一#12
【原文】衣下，明賞勞。口和者，準《羯磨》云：諸大德憶念！今持此亡比丘某甲衣鉢〔坐具等物〕與某甲看病比丘。〔三說。〕餘下，正分衣。準《注羯磨》四句成。白云：大德僧聽！若僧時到僧忍聽，某甲比丘命過，所有衣物現前僧應分，白如是。〔準或合須牒本云僧今分是衣物。
【譯文】在「衣下」的部分，說明犒勞看護的辦法。所謂口頭和合，依照《羯磨》的規範應當說：「諸位大德請注意聆聽！僧眾現在持這件亡故比丘某甲的衣缽（乃至坐具等物品），致贈給某甲照料病人的比丘。」（這段話重複宣說三次。）在「餘下」的部分，正式進行分衣程序。依照《注羯磨》的規定，說完四句話便告成立。白告詞為：「大德僧聽！如果僧眾時機已成熟，僧眾聽許，某甲比丘已經捨報命終，他所遺留的一切衣物，現前僧眾應當予以分配，白告程序就是這樣。」（依照常例，或許應當按照原文本增補說明「僧眾現在分配這些衣物」。

【1295-0003】資持記/13e_下一#13
【原文】《羯磨》云：大德僧聽！比丘某甲命過所有衣物現前僧應分。〔準前牒本。〕誰諸長老忍僧分是衣物者默然等；結詞云，僧已忍分是衣物竟等。〔此依《母論》出法，改正不妨。〕作此下，示改法。未入手者，明入手已，則不須改。更共作法者，改從五人法也。注中引類顯上須改。
【譯文】）《羯磨》的詞句說道：「大德僧聽！比丘某甲已經捨報命終，他所遺留的一切衣物，現前僧眾應當予以分配。（比照前文增補原文本內容。）哪位長老贊同僧眾分配這些衣物，請保持沉默……」結尾的定詞說：「僧眾已經同意分配這些衣物完畢……」（這是依據《毘尼母論》（母論）所列出的法式，加以修正調整並無妨礙。）在「作此下」的部分，說明變更法式的規定。所謂未曾入手，是指物品如果已經分發交到手上，就不需要再變更法式。所謂更共同行作法，是指變更程序而依從五人僧團的法式。注文中引用類似的事例，來彰顯上述情況確實必須變更。

【1295-0004】資持記/13e_下一#14
【原文】準非時施中，本亦直分；因客比丘數數來分衣疲極，佛言，應差一人令分。今無人故，依論直分；後有人來，類彼須改。有下，證成。對首有二，初三人法。彼此相語，故云展轉。二人口和，但除諸字。次二人法。不出詞句，應云：大德！此亡比丘衣鉢〔坐具等物〕，與大德看病賞勞。
【譯文】比照「非時施」的戒規，原本也是直接分發；後來因為外來客僧接二連三地前來領取，導致負責分衣的僧人疲憊不堪，佛陀才指示應當推派一人專門負責分配。現在是因為當下人數不足，所以依照論典直接均分；假若事後又有僧人到來，比照那個例子便必須變更法式。在「有下」的部分，引出依據以證明成立。面對面作法（對首法）包含兩種情況，首先是三人法。彼此互相對答言說，所以稱為展轉。在場另外二人作口頭和合時，只須刪除「諸」這個字。接著是二人法。經文並未明列具體詞句，應當說：「大德！這位亡故比丘的衣缽（乃至坐具等物品），致贈給大德以作為看護病人的犒勞。」

【1295-0005】資持記/13e_下一#15
【原文】指分法如上，但除上二字。《四分》下，會同本律。但出對首之法，不論賞勞，故云直明等。文如論者，即同上引。心念中，初示緣。此下，出法。即須口陳，非謂默然。作下，明重分須不。若三說已，決作己想，或手執捉，即為入己，如注所顯。若不爾者，有來須分。《四分》下，引類。
【譯文】至於分衣的法式則如同前述，僅須刪去前述的兩個字。在「四分下」的部分，將義理會通於本門《四分律》。此處僅僅列出面對面作法的程序，並未論及犒賞看護的環節，因此才說是直接說明等等。其文字表述如同論典所載，即與前文所引用的完全相同。在僅憑心念作法的章節中，首先標明適用的特殊因緣。在「此下」的部分，出示具體的作法。這時必須親口念出聲來，並不是在心中默默無聲。在「作下」的部分，說明事後究竟需不需要重新分配。如果三次口述完畢，已明確生起屬於自己的念頭，或者已經用手實際拿取，這件物品就算是歸入自己名下，就如注文中所闡明的那樣。如果不符合這些條件，一旦有其他僧人到來，就必須重新分配。《四分下》的部分，引用類似的戒規條文。

【1295-0006】資持記/13e_下一#16
【原文】律文續云：更有餘比丘來，不應分與。同上通之。問非衣中。《戒疏》云：昔云如幡蓋等，有云如革屣鉢囊等，此亦非也；又相傳云：帽袜之類。古多局解，故問通之。答中，初句通標。文下，引示。今下，正答。通而述者，即上所牒；或未成衣財，或僧尼互望皆可收之，故云彼比俱攝也。
【譯文】律典的文字接著寫道：假若還有其他比丘前來，便不應當分給他。這與前面的道理相通。在詢問非衣物類的章節中。《戒疏》記載：從前有人認為是指幡蓋這類物品，也有人認為是指皮鞋、缽袋這類物件，這些說法都是不對的；坊間又相傳是說：帽子、襪子之類的衣著。古人多半將其作狹隘局限的理解，因此才透過提問來加以貫通辨析。在回答之中，第一句先作全面的標示概括。在「文下」的部分，引證律文加以說明。在「今下」的部分，給出正式的解答。如果通達而論，就是指前面所列舉的事物；或者是指尚未縫製成衣服的布料，或者是無論大僧比丘、比丘尼雙方相對而言皆可納入收取的物品，因此才說兩方都能涵蓋在內。

【1295-0007】資持記/13e_下一#17
【原文】十中，初科，前明有守掌又二，初明有住處。若亡下，次明無住處。家人即俗侍者。不得尼者，顯是僧物故。不與近寺者，明有本處故。注云僧法，即眾行羯磨。若無下，後明無守掌。白衣家中，初文可解。次科，前明本眾各取。不同得施二部共分。當下，次明當部不行羯磨。
【譯文】在第十個章節中，第一個小段落先前說明有人看守掌管的情況，這又分為兩類，首先說明有固定住處的情況。在「若亡下」的部分，接著說明沒有固定住處的情況。所謂家人，就是指世俗身分的侍奉僕役。之所以不能交給比丘尼，是為了彰顯這屬於大僧僧團共有物品的緣故。之所以不交給鄰近的寺院，是表明該物品本來就具有所屬的原有住處。注文所說的「僧法」，是指僧眾共同如法舉行羯磨。在「若無下」的部分，隨後說明無人看守掌管的情況。在俗人家中的情況，前面的文義很容易理解。第二個小段落，先前說明本所屬的僧團部類各自收取。這不同於信徒布施時，比丘、比丘尼兩部僧團共同均分的情況。在「當下」的部分，接著說明所屬部類不舉行羯磨程序。

【1295-0008】資持記/13e_下一#18
【原文】重物隨遠近者，近有伽藍，則攝入常住；無則隨彼五眾攝歸本寺。三中，初明五眾取法。必約執捉作意以為得限。縱下，次明俗人不還。盜僧成就，即彼俗人已成盜業故。若彼俗士從勸還僧，即同得施，故注示之。同界集中，初明持出別受。
【譯文】至於沉重的大件物品，則依照距離遠近來決定處置方式：若鄰近有僧院伽藍，就直接收歸該處作為常住僧物；若附近沒有，就由隨行的五眾弟子將其收攝帶回所屬的寺院。在第三個小段落中，首先說明五眾弟子的收取法式。這必定要以用手拿取並在心中生起據為常住之意，作為取得該物的界限標準。在「縱下」的部分，接著說明世俗之人拒絕歸還的情況。此時已構成盜取僧物之罪，是指那位俗人已經造就了偷盜的惡業。假若那位世俗士人聽從勸導將物品歸還給僧團，性質就等同於重新獲得信徒布施，所以注文特別對此加以開示說明。在同處於一個結界範圍集會的章節中，首先說明私自將物品帶出界外而個別領受的情況。
