# 校閱材料　第314檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【314-0001】02_戒疏/13b_卷三下之一#65
【原文】【疏】就《四分》中，衣、食、夏等，必約明出，人宿等戒，日光沒後。準此定時，看西明相，一更已後，方始沒滅。諸師行事，合瞑即犯，意不同也。與「同室宿」，必夜分齊。
【譯文】【疏文】就《四分律》而言，衣物、食物、夏安居等事項，必定以破曉天明為準；至於人同室過夜等戒律，則是依據太陽落山之後為準。依照這個標準來定時，觀察西方殘餘的日光天色，通常要到一更以後才會完全消失滅盡。許多律師在行事時，認為黃昏天黑即刻構成犯戒，這與律意是不相同的。「與未受具戒人同室過夜」，則必定以進入夜間為界限。

【314-0002】02_戒疏/13b_卷三下之一#66
【原文】【記】《四分》中。初示異。前引《僧祇》三位差別。今此《四分》一向約明，文略覆罪，故云「夏等」。二同宿戒，並據初夜。「準」下，定夜分。「諸師」下，斥非。「合瞑」即昏黃時，未入夜分，乖彼制限。今須據夜，故云「意不同」等。
【譯文】【記文】在《四分律》的說明中，首先指出差異。前面引述《僧祇律》有三種判定標準的差別。如今本宗《四分律》則一概以天明為準，文字中略去了隱覆罪過，所以說「夏等」。兩種同室過夜的戒律，都依據初夜來判定。從「依照」以下，確立夜間的時間界定。從「許多律師」以下，斥責錯誤做法。「黃昏天黑」就是傍晚日落時分，此時尚未真正進入夜間，違背了該戒的時限。現在必須以正式入夜為準，所以說「這與律意是不相同的」等等。

【314-0003】02_戒疏/13b_卷三下之一#67
【原文】【疏】《僧祇》「初夜明內宿」者，亦是其理，謂夜與宿，貪附情多。約同《四分》，一夜與宿，明相暫離，名為不犯。此約情過則深，有犯事同《僧祇》。《律》據通緣，且依明相。餘且略之。
【譯文】【疏文】《僧祇律》規定「初夜時分食物在界內過夜即犯」，這也是有道理的，因為夜晚與食物同宿，容易生起過多的貪著依附之心。如果比照《四分律》的規定，整夜與食物同宿，天明之前暫時移出界外，便不算犯戒。以貪著情過較深的角度來看，若有犯意實質上就如同《僧祇律》所說。但《四分律》是依據通行的通緣，暫且以天明破曉為準。其餘細節暫且略過。

【314-0004】02_戒疏/13b_卷三下之一#68
【原文】【記】三中。但明內宿，彼此不同。初示《僧祇》，出彼制意。「約」下，次校《四分》。初明情過，則宜同《僧祇》。「明相暫離」，謂天欲明時，出外避之，則不違制。「律」下，示律緩急。食非別屬，故云「通緣」。
【譯文】【記文】第三部分專門說明食物在界內過夜，各部律派規定不同。首先說明《僧祇律》，點出該律制戒的用意。從「如果比照」以下，接著比對《四分律》。首先說明如果就情理上的過失而言，理應與《僧祇律》相同。「天明之前暫時移出」，是指天快亮時將食物搬到外面避開，就不算違背制約。從「但《四分律》」以下，顯示律法規定的寬緩與緊迫。食物並非僧人專屬的私物，所以說是「通行的通緣」。

【314-0005】02_戒疏/13b_卷三下之一#69
【原文】【疏】四、明所離結罪相者。《律》下注中「除三，餘者吉羅」。今解：「如百一供具，有持可離，故結小罪。餘說淨者，既指別主，何有離罪？如《五分》中：『應受持三衣、襯身衣、被衣、雨浴、覆瘡、蚊厨、敷行、障蝨、單敷，護髀、踝、頭，拭身、手、面巾及諸囊，若似衣，皆受持之。』餘畜廣相，亦如《鈔》說。」
【譯文】【疏文】第四、說明離開所受持之物時的結罪相狀。律文下方的注釋說「除了三衣之外，若離開其餘衣物，犯突吉羅罪」。現在解釋認為：「如同百一供具等物，既有受持儀軌就可能發生分離，所以結成輕罪。至於其餘已經作說淨法的衣物，既然已經指稱歸屬其他主人，哪裡還會有離衣之罪？正如《五分律》中所說：『應當受持三衣、貼身內衣、蓋被之衣、雨浴衣、覆瘡衣、蚊帳、坐臥敷具、防蝨布、單敷，以及護腿布、護腳踝布、裹頭巾、擦身巾、擦手巾、洗面巾和各種囊袋，凡是類似衣物之類，皆應當受持。』其餘蓄積衣物的詳細相狀，也正如《事鈔》中所說。」

【314-0006】02_戒疏/13b_卷三下之一#70
【原文】【記】犯相中。初牒注。「今」下，正釋。古謂百一、諸長，離皆犯吉。此但直伸正解，以顯古非。「如」下，引證。所列諸衣，皆是百一。下指「如《鈔》」，見《二衣》中。
【譯文】【記文】在犯戒相狀之中，首先引述律文注釋。從「現在解釋」以下，提出正面解釋。古人認為百一供具與諸多長衣，一旦分離皆犯突吉羅罪。此處直接陳述正確見解，以彰顯古說之非。從「正如」以下，引用律文作證。所列舉的諸多衣物，全都屬於百一供具的範圍。下文指示「正如《事鈔》」，可參見該書《二衣》篇章之中。

【314-0009】02_戒疏/13b_卷三下之一#73
【原文】【註】時，比丘得乾痟病，糞掃僧伽棃極重，有因緣事人間遊行，不堪持行，以事白佛。佛令三乞已，白二離。
【譯文】【註文】當時有比丘患了消渴症（糖尿病等消耗性疾病），所穿的糞掃大衣極其沉重，適逢有因緣事務必須在人間遊化出行，身體不堪承受攜帶大衣行走的負擔，便將此事稟告佛陀。佛陀吩咐比丘經過三次乞請之後，僧眾以白二羯磨法開許其可以離衣。

【314-0010】02_戒疏/13b_卷三下之一#74
【原文】【疏】注列病緣，後明乞法，總有五意。
【譯文】【疏文】注文中先列出患病的因緣，接著說明乞請羯磨之法，總括起來共有五種深意。

【314-0011】02_戒疏/13b_卷三下之一#75
【原文】【疏】一、解開緣。如文「得痟病人間遊」。《多論》云：「所以爾者？四意：一、有緣眾生應受化故；二、宜遊病損故；三、求行道處故；四、降伏信悟故。」、「是舍利弗病故，何者？亦四義：一、先世惱人故；二、智深思法故；三、勤業不臥故；四、此後邊身先業已盡。」、「若以神力轉三千界，大悲心中請聖制故。」
【譯文】【疏文】第一、解釋開許的緣由。如同注文所載「患了消渴症在人間遊化」。《薩婆多論》說：「之所以要遊化，有四種深意：第一、有緣的眾生應當接受化度；第二、適度遊行有助於病體康復；第三、為了尋求安心修道的處所；第四、為了降伏外道並令其信受開悟。」又說：「這是在舍利弗生病時所制，原因為何？同樣有四種意義：第一、過去世曾有惱害他人的業報；第二、智慧深廣經常思惟妙法；第三、精勤修業從不隨意躺臥；第四、這是最後的輪迴之身，往昔惡業在此完全消盡。」「舍利弗若以神通之力足以迴轉三千大千世界，是在大悲心中為了利益後人而請佛陀制定此開緣。」

【314-0012】02_戒疏/13b_卷三下之一#76
【原文】【疏】二、法成不相者。要須人病衣重者成，餘人病互有，一向不成。所言「老」者，《多論》「七十已上，名為老者」。有前四益，乃至三寶求覓，亦得。
【譯文】【疏文】第二、辨別羯磨能否成立的相狀。必須同時具備「人患重病」且「衣物沉重」這兩個條件，羯磨才能成立；其餘情況若僅有人病或僅有衣重，一概不能成立。至於所說的「年老」，《薩婆多論》認為「七十歲以上，才稱為老人」。老人若具備前面的四種利益，乃至為了三寶事務外出尋求物資，也可以開許作法離衣。

【314-0013】02_戒疏/13b_卷三下之一#77
【原文】【疏】三、離多少相。此中唯是大衣。《五分》云：「留一並離，非羯磨故，皆犯離罪。得留中衣，上下不得留。有賊難處，隨留好者。」《十誦》、《多論》，留一義同。
【譯文】【疏文】第三、開許分離衣物數量的相狀。在此處僅限於僧伽梨大衣。《五分律》說：「准許留下一件衣；若三衣一併脫離，因非羯磨所開許之故，皆犯離衣罪。律中准許羯磨留下中衣，大衣與下衣則不得留下。若在有盜賊危難的地方，則任憑留下一件較好的衣物。」《十誦律》與《薩婆多論》關於留置一件衣物的義理也是相同的。

【314-0014】02_戒疏/13b_卷三下之一#78

【譯文】【疏文】第四、依據離衣日數的多寡。《十誦律》規定夏安居期間不開許離衣，《五分律》則准許前安居者可離衣九個月，後安居者可離衣八個月。《善見論》說：「隨順病患只要未痊癒即可離衣，若病好了就應當立即返回，中途遭遇險難則不失去衣物。若心中沒有返回的意思，即算失去衣物。」《薩婆多論》說：「如果已經通過羯磨開許離衣，但病情加重未能成行，日後再度成行時，仍可沿用先前的羯磨。如果教化眾生的任務尚未結束，或者為僧團營求衣物藥品、三寶設施尚未辦妥，而開許的月份已經屆滿，由於事務艱難的緣故，因緣結束之前並不算犯戒。如果比丘不幸身亡，這件留置的衣物可以贈送給照料病患的人。」

【314-0016】02_戒疏/13b_卷三下之一#80

【譯文】【記文】第六點在解釋注文的五種深意中，第一種深意又分為兩部分。首先引述注文，接著引證解釋。先解釋遊化出行，第一點與第四點屬於利他：第一點是容易受化的人，第四點是難以化度的人，所以必須降伏並令其生起信悟；第二與第三點都是自利。「病損」，就是病情減輕的意思。從「這是在」以下，接著解釋生病的原因。因為因緣起源於舍利弗，所以必須顯明其深意。第一與第四點是依據過去世的業力，中間兩點是依據現世的修持。該論提問道：「舍利弗神通自在，能將三千大千世界在手中迴旋運轉，為什麼還會說大衣沉重呢？」從「大悲心中」以下，就是該論的回答之辭，說明他是為了未來後世年老患病的人作為發起因緣，所以稱為「大悲」。

【314-0017】02_戒疏/13b_卷三下之一#81

【314-0021】02_戒疏/13b_卷三下之一#85
【原文】【記】三中。「此中大衣」，即是本律，如注緣起。《五分》，初示數。「並離皆犯」者，彼云「盡離三衣」。「非羯磨」者，以非所開而妄加法，即是「事非」，法不成故。「得」下，定體。「上」即大衣，為入聚生善；「下」即五條，謂不許單著。故二「不得留」。「有」下，明難則無所拘，下指二文，同故不引。
【譯文】【記文】第三點中。「在此處僅限於僧伽梨大衣」，就是本宗的《四分律》，正如注文中的緣起所示。《五分律》首先指出數量。「一併脫離皆犯離罪」，是指該律說「完全離開三衣」。「不合乎羯磨規定」，是因為對於本非開許的範圍妄加作法，屬於「事相違背」，羯磨法不能成立的緣故。從「准許」以下，確定所留衣物的性質。「上衣」就是大衣，是為了進入村聚使人生起善心而穿；「下衣」就是五條衣，律中不許單穿下衣。所以這兩種「不得留置不帶」。從「若在」以下，說明遇到險難時則不受拘束，下文指出另外兩部律文，內容相同所以不再引述。

【314-0022】02_戒疏/13b_卷三下之一#86
【原文】【記】四中，《十誦》、《五分》，同明不開時節。前安居人除三月，後安居人除四月。義準中安居隨滿即開，除則不定。次引《見論》，明開中病差未差。「遇難不失」者，彼云：「路險不得還，恒作還意，雖差不失。」後引《多論》，明餘雜相，有三。初明後用前法，不須再乞。「若化」下，次明事難不犯。「化未盡」者，往彼教化，或是人多，或約處遠，故有「未盡」。「而月盡」者，九月八月滿也。「緣訖」，謂取事辦，出於月外，以事緣故，亦開夏限也。「若死」下，明亡過所屬。隨在外死，有看病者，索往賞之。
【譯文】【記文】第四點中，《十誦律》與《五分律》同樣說明了不開許離衣的時節。前安居的人扣除三個月，後安居的人扣除四個月。依義理推論中安居的人則是安居期滿隨即開許，扣除的月份則不固定。接著引用《善見論》，說明開許期間疾病痊癒與否。「遭遇險難不失衣」，是指該論說：「道路險阻無法返回，只要心中常存返回之意，即使病好了也不失衣。」最後引用《薩婆多論》，說明其餘雜項規定，共有三點。首先說明後續可以沿用先前的羯磨法，不需再次乞請。從「如果教化」以下，說明因事務艱難而不算犯戒。「教化未盡」，是指前往彼處教化眾生，或者因為人數眾多，或者因為路途遙遠，所以有「尚未結束」的情況。「而月份已滿」，是指九個月或八個月期限已滿。「因緣結束」，是指把事情辦妥為止，即使超出了月份期限，因為是公事的緣故，也開許突破安居期限。從「如果身亡」以下，說明亡僧遺物的歸屬。隨身在外身亡，若有照料病人的人，應索取這件大衣來賞賜給他。
