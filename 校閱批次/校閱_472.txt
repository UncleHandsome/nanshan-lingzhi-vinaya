# 校閱材料　第472檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【472-0001】資持記/13a_下一#54
【原文】疏云：得成受持，著用得罪。相參中，唯大衣可說，餘非所論。初引論示數。餘下，引律顯制。以新衣止得二重，今多一重，故有犯長也。三中。糞掃棄物，不限多重。摘分中，初明急緣開許。謂衣厚重，不可持行。摘分，謂拆開也。若下，次明死後所屬。論出二解。本界內者，即留寄處分之；
【譯文】《律疏》說：可以成就受持，但穿著使用時會結犯突吉羅罪。在「相參」（新舊布料夾雜）中，唯有大衣才需論及此事，其餘二衣不在此限。首先引述論典說明層數。自「餘」字以下，引述律文彰顯制教規定。因為用新布製作至多只能做兩層，如今多加了一層，所以會構成犯蓄長物罪。第三小節中，糞掃衣是世人遺棄的碎布，不受製作層數多寡的限制。在「摘分」（拆開持行）中，首先說明在緊急因緣下開許拆分。這是指衣服過於厚重，不便隨身攜帶長行。摘分，就是拆開縫線的意思。自「若」字以下，次一節說明死後的歸屬。論中提出了兩種解釋：歸屬於原本戒界之內的，就是留在寄放衣服之處加以分發處置；

【472-0002】資持記/13a_下一#55
【原文】賞看病者，索往死處與之。八中，初科。律中，上二衣，本要割截；若少揲葉〔各得一種。〕，下衣復得襵葉。〔更加此一，為三種。謂作小襵，略分葉相。〕二中，初《僧祇》勸助。恐犯缺衣，故須急竟。續引經示。在聖尚爾，況餘人乎！今時多用女工者。《章服儀》云：今有不肖之夫，倩纏嗜好。
【譯文】若是賞給看病比丘的，則索取並送到其圓寂之處給予看病僧人。在第八項中，第一科。律中規定，上二衣（大衣與七條）原本必須割截碎塊製作；若布料不足只得以疊布壓葉〔這兩種衣各得一種變通做法〕，下衣（五條）則還可以打褶顯葉。〔下衣再加上這一種，共有三種做法。也就是捏出小褶子，大略分出葉相即可。〕第二科中，首先引用《僧祇律》勸勉僧眾互相協助縫衣。唯恐因衣服未成而犯下缺少法衣之過，所以必須緊急縫製完成。接續引用經文昭示。連佛陀聖人尚且親自為僧縫衣，何況其餘凡夫之人呢！針對現今許多出家人多僱用女工縫衣的現象，《章服儀》批判說：現今有些不肖之輩，順從自身的嗜好慾望。

【472-0003】資持記/13a_下一#56
【原文】自迷針縷，動必資人。但論刺作之纖媚，不計功價之高下。或有雇縫之直，倍於衣財。履歷孀荒，譏過斯負。通觀誠教，衣唯自縫；今則反之，罪由此起。〔準此比丘男子為之彌善。〕《四分》下，次明結犯。針工是尼本習，故重於僧。此中且約人衣為言。準《鼻奈耶》，七條四日成，五條二日成。三中。
【譯文】自己對針線之事一竅不通，動輒依賴他人代勞。只是一味計較刺繡縫製是否纖巧嫵媚，卻不顧及工價的昂貴低賤。甚至有人支付的縫工報酬，比衣服布料本身的價值還要高出一倍。頻繁出入寡婦獨居之室，招致外界的譏嫌與罪過。通觀佛陀懇切的教誡，法衣原本唯有自己親手縫製；如今卻反其道而行，罪過正是由此而生。〔依準此理，由同道比丘或在家的男子代為縫製，都要妥善得多。〕自《四分》以下，次一節說明結罪犯戒之處。縫紉針工本是比丘尼的本門勞作，所以尼僧受託縫衣其結罪比男僧更重。此處暫且就著為他人縫製衣物而言。依準《鼻奈耶律》，七條衣應當在四天內縫成，五條衣應當在兩天內縫成。在第三小節中：

【472-0004】資持記/13a_下一#57
【原文】一端，此間謂之一疋。指作謂指擬欲作而未作也。五肘，謂取長五廣三肘體，是法衣量，不須說淨；已外須說。〔引此證前，定量彌顯。〕四中，初科，前明轉作三衣。若下，次明製作納衣。《五分》中，初出非法。前四犯吉，後一結蘭。言染作者，謂以別色染為條葉。縫著謂不却刺，故注以斥之。
【譯文】「一端」，在我們漢地稱為「一疋」。所謂「指作」，是指心中打算要作法衣而尚未真正動手裁作。所謂「五肘」，是指截取長五肘、寬三肘的整幅布體，這已是法衣的規定尺寸，不需要行說淨之法；超出這個尺寸以外的多餘布料，則必須行說淨法。〔引用這點印證前文，衣服的定量規定更加明確昭著。〕第四項中，第一科，前半段說明將舊衣改製為三衣的方法。自「若」字以下，次一節說明製作百衲衣的方法。在《五分律》中，首先列出非法的做法。前四種情況犯突吉羅罪，後一種情況結犯偷蘭遮罪。所謂「染作」，是指用不同的顏色在布上染出條葉的形狀。「縫著」是指不採用倒針縫刺，所以注釋中予以斥責。

【472-0005】資持記/13a_下一#58
【原文】襵葉，準彼三衣，俱為非法；《四分》開下衣，餘二亦非襵。半向上下者，謂開葉相俱須順下，不得逆上。阿難下，次明如法，初教安條葉。靡猶順也，謂條葉相壓，須順左右。且如七條，兩邊三條，各順左右一向，中間一條，兩壓左右之上，故云兩向順。若下，次明隨物裁製，初引文。
【譯文】至於「打褶作葉」，依準該律的規定，三衣全部屬於非法；《四分律》僅開許下衣可以打褶，其餘二衣同樣不可打褶。「半向上下」是指翻開的葉相全都必須順向朝下，不得倒逆朝上。自「阿難」以下，次一節說明如法製作之軌則，首先教導如何安立條與葉。「靡」就是順隨的意思，是指條與葉互相疊壓時，必須順應左右的方向。例如七條衣，兩旁的各三條，各自朝著左向或右向順平疊壓，正中間的一條，則同時壓在左右兩條之上，所以稱為「兩向順隨」。自「若」字以下，次一節說明隨順布料多寡裁製法衣，首先引述律文。

【472-0006】資持記/13a_下一#59
【原文】若得衣者，或衣財，或已成者。不足，謂作二十五條大衣，財猶少也。次第減降，故兩云乃至。準下，義決。初決文相，二示受法，三引文證。《僧祇》，初示非法。彼云：有比丘對頭縫，佛言：不應對頭縫，應作葉。謂彩畫條葉，直爾縫之；邊緣相屬，故言對頭。應下，教如法有六，初制割截。
【譯文】所謂「若得衣」，或者是指得到做衣的布料，或者是指得到已經縫好的衣服。所謂「不足」，是指想要製作二十五條的大衣，但布料資財依然不夠。因而依序縮減降等，所以文中有兩處說到「乃至」。自「準」字以下，依循義理作出裁決：第一是判定律文的文相，第二是提示受持之法，第三是引述文獻為證。《僧祇律》中，首先標明非法的做法。該律說：有比丘將布對頭平縫，佛陀說：不應當對頭平縫，應當做出葉相。這是指僅用彩色畫出條葉之相，直接將布邊對綴縫合；兩邊布緣緊密相連，所以稱為「對頭縫」。自「應」字以下，教導如法縫製的六個要點：第一，規定必須割截碎塊。

【472-0007】資持記/13a_下一#60
【原文】極下，二示條葉大小。《業疏》云：今多廣大，澆風扇也。《章服儀》云：如小獷麥，得分畦畔，為世福田；今則過其正度，故非法服。準須依教，不應廣闊。不下，三明長短相差。縫下，四明縫刺。宣謂散解。馬齒縫，舊云偷針刺，若馬齒闊。或作鳥足縫，疏云：押葉丁字有三叉相，是也。
【譯文】自「極」字以下，第二點，標示條與葉的寬窄大小。《業疏》說：如今世人多把條葉做得極為寬大，這是澆薄奢靡的風氣吹拂煽動所致。《章服儀》說：條葉應當如同小麥粒般微凸，恰好分出田疇水畦的邊界，以此為世間作福田；現今之人卻遠遠超過了正常的度數，所以這根本不是法衣。應當嚴格依準教法，不該做得過於寬闊。自「不」字以下，第三點，說明長短條塊必須交錯參差。自「縫」字以下，第四點，說明針線縫刺的法度。「宣」是指布線鬆散解脫。「馬齒縫」，舊稱「偷針刺」，針腳有如馬齒那般疏闊。或者作「鳥足縫」，《律疏》說：壓在葉相上的「丁」字形有三叉的相貌，就是這種縫法。

【原文】故《業疏》云：尼受二衣，覆肩肘量，薄有所承；祇支全改，文雖約量，漸訛變也。準《羯磨》改云：大姉一心念！我比丘尼某甲，此僧祇支如法作，我受持。〔覆肩同此。〕問：此是尼衣，僧開畜不？答：準尼戒中，尼離五衣俱提。僧離二衣犯吉，明知得作百一受持。但尼是制物，僧入聽衣。
【譯文】因此《業疏》說：比丘尼受持這兩件衣，覆肩衣的肘量尚且稍微有一點承傳的依據；僧祇支則完全被改樣了，雖然文句上限定了尺寸，實際上卻漸漸訛誤變形了。依照《羯磨》應當改為：「大姊一心念！我比丘尼某甲，這件僧祇支如法縫製，我現在受持它。」（覆肩衣也比照這個格式。）有人問：這是比丘尼的衣服，比丘開許蓄積嗎？回答：依照尼戒的規定，比丘尼離開五衣都要結波逸提罪；比丘離開這兩件衣只犯突吉羅，由此明白可知比丘可以將它們作為百一物來受持。只是比丘尼屬於規定必須具備之物，比丘則是列入聽許蓄積的衣物之中。
