# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【222-0001】02_戒疏/10d_卷三上之一#53
【原文】【記】釋喻中。「乳」即水之甘味，與水體別，唯鵝王能別取而食之。既非一體，法喻有乖，必須二物各自論合，故云「不得」等。
【譯文】【記文】在解釋比喻當中。「乳」是水中的甘甜滋味，與水的自體不同，只有鵝王能單獨把它吸取飲用。水乳既然不是徹底一體，在法與比喻上就會有所偏差，所以必須是兩種同質之物各自論其相合，因此疏文才說「不得」等話。

【222-0002】02_戒疏/10d_卷三上之一#54
【原文】【疏】二、「於佛法中增益安樂」者，良由捨除異見，同體行和，如法修道，必除生死，得涅槃樂，故曰也。「增益」者，超凡夫界也。「安樂」者，絕三苦也。
【譯文】【疏文】第二、「在佛法中有增益安樂住」，確實是由於捨棄消除了異端邪見，體性同和、行持同和，依照正法修行辦道，就必定能夠斷除生死輪迴，證得涅槃之樂，所以經文這樣說。「增益」，是指超越凡夫的界限。「安樂」，是指徹底斷絕三界之苦。

【222-0003】02_戒疏/10d_卷三上之一#55
【原文】【記】舉益勸中。初通釋。「同體行和」，躡上二勸也。「除生死」者，即增益也。「得涅槃」者，即安樂也。「增」下，別釋。「凡夫界」，即三有也。「三苦」者，一、苦苦，二、壞苦，三、行苦。既超三有，永絕三苦，故「安樂」。
【譯文】【記文】在舉出利益以勸勉的段落中。首先是通盤解釋。「同體行和」，是承接前面兩種同和的勸導。「除生死」，就是增益的意思。「得涅槃」，就是安樂的意思。「增」字以下，分別解釋。「凡夫界」，就是指三界六道。「三苦」，一是指苦苦，二是指壞苦，三是指行苦。既然超越了三有界限，永遠斷絕了三苦，所以稱為「安樂」。

【222-0011】02_戒疏/10d_卷三上之一#63

【譯文】【疏文】「彼比丘」以下，說明僧團公眾規勸的相狀。「乃至三諫捨者善」，是哪一種「善」呢？第一、因為原先發動規勸的事由不再構成僧殘重罪；第二、因為在私下規勸時不至於結成波逸提罪；第三、因為所造的破僧惡事不再構成偷蘭遮果罪，所以稱作「善」。

【222-0016】資持記/14c_下二#6
【原文】先師後己者，尊人重法，隨事表心故。串，古患反，穿也。後明洗衣，相因而引。漬，浸也。若下，明用破鉢法。行護中，初科三段，雜明敬護，誠絕非用。《十誦》。一心，謂專意也。日炙津出，為損色故。《母論》。一切處者，唯除中齋，遮斷餘用。目睛為比，誡令極護。
【譯文】先為師長洗而後為自己洗，是為了尊崇前輩、敬重法道，隨著具體事務表達內心敬意。「串」字讀作「患」（古患反），是穿插的意思。後面說明洗衣的方法，是因事情相連而順帶引出。「漬」字就是浸泡的意思。從「若」字以下，說明使用破缽的方法（用破鉢法）。在日常守護（行護）中，第一科分為三段，雜亂列出敬重護持之法，誠懇告誡斷絕非法的用法。《十誦律》說的「一心」，是指心意專注。被太陽曝曬會滲出油脂，是因為會損壞缽的色澤。《母論》說的「一切處」，只除去中午齋食之時，禁止一切多餘的使用。以眼睛作為比喻，告誡必須極力愛護。

【原文】《五分》，初示護法。若下，避非。煖湯，謂沸湯，亦損色故；或是將燒湯洗物，即非用故。得罪，並制吉羅。次科，《四分》，前列十三種安處非法。不得下，次明將持非法。《僧祇》。六事並蘭，謂壞三寶，同外道故。今取壞鉢，餘皆因引。三中，《四分》六節，初制別用。若下，次制雕刻。
【譯文】《五分律》中，首先展示護持之法。從「若」字以下，是避開非法的行為（避非）。「煖湯」是指滾燙的熱水，也是因為會損毀顏色；或者是指打算燒熱水來洗滌其他東西，這就不合於規定的用途。所招致的罪過，都制定為突吉羅罪。下一小科引《四分律》，前面列出了十三種安放處所屬於非法（安處非法）。從「不得」以下，其次說明攜帶拿持屬於非法（將持非法）。《摩訶僧祇律》中，六種事項都結偷蘭遮罪，是因為毀壞三寶器具，等同於外道行徑的緣故。這裡只取毀壞缽的罪過，其餘都是順帶引述。第三段中，《四分律》分為六節，首先禁止用作其他用途（制別用）。從「若」字以下，其次禁止刻雕花紋（制雕刻）。

【原文】萬字梵體作卍，佛胸前德，人多濫用。今或刺於衣角，是教所開。破下，三明補治。墁兩分者，凡鉢上下中分三分故。不得著下，四明安處。熏即熏色。言故壞者，用上四物藉之。猶故色壞，方令以鑞墁其鉢底。不得雜下，五明洗法。牛屎西國所貴，此方不用。若手下，六明帶持。

【原文】火母，所鑽物，如竹木等。火子，取火物，如乾艾等。鑽即火鑽，亦用竹木為之。若下，七明諸鉢。初因得藥令置四種鉢中，故知得畜。文中通云不作淨施，然大鉢應量，理必須說，故注決之。〔據律應是不應量者。〕龍牙杙者，杙頭雙出，像龍牙故。不得下，簡非。故知上四並據泥鐵為體者。
