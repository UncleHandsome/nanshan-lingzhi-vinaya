# 校閱材料　第138檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【138-0001】02_戒疏/10c_卷三上之一#24
【原文】【疏】初破僧時，倣佛二法，用擬邪化：一、立五邪以為行法，替正四依；二、立非法羯磨以為眾法，替正羯磨。所以王舍城時忍五法者，止是破行。後至伽邪，羯磨說戒，方破眾法，始是究竟破法輪僧。
【譯文】【疏文】最初發起破僧之時，提婆達多仿造了佛陀的兩種法制，用來推行其邪惡教化：第一、創立五種邪法作為修行之法，用以取代正統的四依止法；第二、創立非法的羯磨法作為大眾規矩，用以取代正統的羯磨法。因此在王舍城時眾人認可五法，還僅僅是破壞行持。直到後來抵達伽耶山，正式作羯磨並說戒，才徹底破壞了大眾法制，自此才算真正究竟成就了法輪破僧。

【138-0002】02_戒疏/10c_卷三上之一#25
【原文】【記】第三，時處，正明中。初明立法。行法被自行，眾法為軌眾，且依《律》示。《論》中八正道，亦行所收。「所以」下，示時處。「王舍城」即遊化之境。「伽耶」山乃住止之處。《方志》云「伽耶，世謂靈岳」，亦云「象頭山」。提婆始於王舍行化，有五百新學比丘信受五法，隨往伽耶布薩，二法俱破，方成破僧。
【譯文】【記文】在第三大項說明時機處所的正面闡述中。首先說明立法的內容。行法是用於規範自身修行，眾法是用作僧眾的共同軌制，姑且依據《律》來開示。《論》中所提及的八正道，也是收攝在行法的範疇。「所以」以下，指出具體的時間與處所。「王舍城」是遊化宣教的環境。「伽耶山」則是長期安居的處所。《西域方志》記載「伽耶山，世人稱之為靈嶽」，也稱為「象頭山」。提婆達多最初在王舍城推行教化，有五百名初學比丘盲信接受了五法，隨後跟隨他前往伽耶山舉行布薩，至此修行法與大眾法兩者全被破壞，才真正構成了破僧。

【138-0003】02_戒疏/10c_卷三上之一#26
【原文】【疏】故《僧祇》云：「調達向伽邪山，佛喚不得。便作羯磨，為後世名譽。乃至三喚，云『我已說戒竟』。佛言：『非法人已作竟，如法人自作布薩。』便說『清淨如滿月』偈等。」以此文證，破在伽邪。
【譯文】【疏文】所以《僧祇律》說：「提婆達多前往伽耶山，佛陀派人傳喚他卻喚不回。他為了在後世博取名聲，便自行舉行羯磨。乃至佛使召喚三次，他回答說『我已經說戒完畢了』。佛陀說道：『非法之人已經作法完畢，如法之人應當自行舉行布薩。』隨即說了『清淨如滿月』等偈頌。」以此經文為憑證，可知破僧的處所是在伽耶山。

【譯文】【記文】引經作證的文字中，所謂「佛喚」，是指如來派遣阿難尊者前去傳喚提婆達多。

【138-0005】02_戒疏/10c_卷三上之一#28
【原文】【疏】問：「調達說戒，如來僧等同界，何得成者？」
【譯文】【疏文】問：「提婆達多說戒時，與如來僧團同在一個結界之內，他的法事怎麼能夠成立？」

【138-0006】02_戒疏/10c_卷三上之一#29
【原文】【疏】答：「一破已後，兩不相足。如《拘睒彌》說。」
【譯文】【疏文】回答：「一旦僧團徹底破裂之後，雙方便不再互算僧數。正如《拘睒彌犍度》中所說。」

【138-0007】02_戒疏/10c_卷三上之一#30
【原文】【記】問答中。由「不相足」，不妨同界各自成法。「如」下，引例。「《拘睒彌》說」，即《律》犍度。彼明拘睒彌國比丘鬪諍，破為二部，各自說戒，佛判成法。彼是非異見，猶不相足，況今邪正兩分，不復疑矣。
【譯文】【記文】在問答之中。正因為「不再互算僧數」，所以不妨礙在同一結界之內各自成辦僧事。「如」字以下，引用先例。「《拘睒彌》說」，是指《律》中的拘睒彌犍度。那裡記載了拘睒彌國的比丘發生爭執，分裂為兩個部派，雙方各自說戒，佛陀判定各自的羯磨都能成立。彼處只是因觀點是非不同而產生異見，尚且互不算數，何況如今邪與正涇渭分明，當然更無需懷疑了。

【138-0008】02_戒疏/10c_卷三上之一#31
【原文】【疏】第四，明二逆偷蘭因果者。
【譯文】【疏文】第四、說明破僧與出血兩項逆罪中偷蘭遮罪的因位與果位。

【138-0009】02_戒疏/10c_卷三上之一#32
【原文】【疏】如昔解云：「出血偷蘭是方便，以殺佛不成故。而是最初，以《智論》云『多聞、持戒九清淨人得破僧』者，若是第二，何名淨也？」
【譯文】【疏文】正如古代的解釋說：「出佛身血的偷蘭遮罪屬於預備階段的方便罪，因為殺害佛陀並沒有得逞。然而這算是最初犯，因為《智度論》說『具備多聞、持戒的九位清淨人才能破僧』，如果是第二度犯戒，怎麼能稱得上清淨呢？」

【138-0010】02_戒疏/10c_卷三上之一#33
【原文】【記】第四，出血中。「昔解方便」，則與今同。判為「最初」，則與今異。彼據《智論》，既云「清淨」，豈非無犯？
【譯文】【記文】在第四大項關於出佛身血的辨析中。古德認為出血是「方便罪」，這一點與現今見解相同。但判定為「最初犯」，則與現今見解不同。彼方依據《智度論》，既然說提婆達多破僧時是「清淨」的，難道不意味著他此前沒有實質犯重戒嗎？

【138-0011】02_戒疏/10c_卷三上之一#34
【原文】【疏】今解不爾。五逆之罪，犯則無初。外道犯逆，即滅擯也。
【譯文】【疏文】如今的見解並非如此。五逆重罪，一旦違犯就絕無最初犯免罰之說。外道若犯了五逆罪，即便受了戒也必須永遠驅逐淘汰。

【138-0012】02_戒疏/10c_卷三上之一#35
【原文】【記】今解中。初判定。「外」下，引例。緣出《受戒》十三難中。制教開初，業道無初。外道犯逆，受已滅擯，顯是業道，何得有初？
【譯文】【記文】在如今的見解中。首先確立判定。「外」字以下，引用事例作證。此條緣由出自《受戒》篇的十三難事之中。僧團制教才開許最初犯無罪，但業道重罪則絕無最初犯之說。外道只要犯過五逆，受戒之後查出也必須驅擯，這顯然是指業道重罪，怎麼可能有免責的最初犯呢？

【譯文】【疏文】「如果真的沒有最初犯，為什麼出佛身血之後才開始破僧，經論中還稱他為『清淨』呢？」

【138-0014】02_戒疏/10c_卷三上之一#37

【譯文】【疏文】回答：「這是指他在受驅擯的極重戒上沒有違犯，所以稱作『清淨』。」

【138-0015】02_戒疏/10c_卷三上之一#38
【原文】【記】初難中。通前《智論》。業道雖成逆，制教是方便，故不違擯法，而得名「清淨」。
【譯文】【記文】第一道難問中。今解藉此會通前述《智論》的說法。業道上雖然已經構成逆罪，但在戒律制教上尚屬方便預備罪，因此並未觸犯被逐出僧團的波羅夷罪，所以仍得以被稱為「清淨」。

【譯文】【疏文】「既然如此，為什麼《雜心論》說『如果犯了其餘的無間罪，就不能再破僧』呢？」

【138-0017】02_戒疏/10c_卷三上之一#40
【原文】【疏】答：「謂未受前而犯三逆，以受不得，非比丘故。出血偷蘭，可懺淨故。」
【譯文】【疏文】回答：「這是指在出家受戒之前就犯了三種逆罪，由於連戒都受不成，根本不是正式比丘的緣故。出佛身血所結的偷蘭遮罪，是還可以經由懺悔而清淨的。」

【138-0018】02_戒疏/10c_卷三上之一#41
【原文】【記】次難。以無初成逆，違《心論》故。答中。「三逆」即殺父、殺母、羅漢，釋上「餘無間」也。逆業障戒，無破僧理。蘭罪可懺，故稱清淨。
【譯文】【記文】第二道難問。這是以若無最初犯即構成逆罪為由，質疑與《雜心論》相違。回答之中。「三逆」是指弒父、弒母、殺阿羅漢，用以解釋上文的「其餘無間」。逆罪惡業會阻障得戒，連比丘都不是，自然談不上破僧。出佛身血在律制上屬偷蘭遮罪，尚可求懺悔，所以仍可稱為清淨比丘。

【138-0019】02_戒疏/10c_卷三上之一#42
【原文】【疏】破僧偷蘭，是究竟，非方便故。以本心規奪徒眾，壞僧斷法，歸從己見，暢滿心腑，更無進趣，故果蘭罪。
【譯文】【疏文】破僧所結的偷蘭遮罪，屬於事情徹底完成的究竟罪，並非預備階段的方便罪。因為提婆達多本心就是要奪取徒眾、毀滅僧團斷絕正法，使大眾歸附自己的見解，如今心願徹底滿足，再也沒有後續企圖，所以結成究竟果位的偷蘭遮罪。

【138-0020】02_戒疏/10c_卷三上之一#43
【原文】【記】次破僧罪，初科。初判定。「以」下，釋所以。偷蘭因果各有三品，此中二罪並是上品。

【138-0025】02_戒疏/10c_卷三上之一#48
【原文】【記】次難中。破僧逆蘭，則無最初。違諫犯殘，即開最初，故引為難。僧諫、佛諫既同，有初、無初何異？答中，佛諫、破僧，則諫、犯不別。僧諫、違諫，則諫、犯不同。僧亦諫破僧，彼犯由違諫故也。後句稱美，必引他文。

【138-0044】02_戒疏/10c_卷三上之一#67
【原文】【疏】昔解云云，何由披出？今直據理，隨事重輕，故分輕重。如殺、盜、媒、長乃至眾學，豈非事之大小邪？
【譯文】【疏文】古人的解釋紛紜龐雜，哪裡能夠逐一辨析得清？如今直接依據客觀法理，隨著所犯事情的輕重程度，來劃分罪名的輕重。就像殺生、偷盜、做媒、蓄長衣乃至眾學戒，難道不正是依照事情性質的大小來定罪的嗎？

【138-0045】02_戒疏/10c_卷三上之一#68
【原文】【記】釋輕重中，初科。初斥古。《義鈔》引云「一解，今此四戒，皆倚傍行教，言說相濫，朋黨相助，事成破僧。前二壞法輪，後二壞羯磨」等，「說欲不障，於理教有違，僧法無濫。又復口說未犯根本。所以事微，故結提罪」。此所謂「云云」也。「披」，分也。今解中。初立義，「如」下，引例。隨事重輕，義通一切，故總舉諸戒也。
【譯文】【記文】在解釋罪名輕重的第一小段。首先駁斥古說。《義鈔》引述說：「有一種解釋認為，如今這四條戒，都是依傍偽造教法而行，言論互相混淆，朋黨相互勾結，事情已演變成實質破僧。前兩條破壞法輪，後兩條破壞羯磨」等等，「至於說欲受染不障道，只是在教理上有所違背，對僧團法制作業並沒有造成混淆。再者口頭言說也還沒觸犯到根本性罪。因此事情性質較為輕微，所以只結波逸提罪（單墮罪）」。這就是所謂的「紛紜龐雜」。「披」是剖析分明的意思。在如今的新解之中。首先確立論點，「如」字以下，引用事例作證。隨事態輕重而定罪，這個法則通於一切戒律，所以概括列舉各項戒品。

【原文】【疏】答：「『九十』諫竟，便即出舉者，為明能隨舉人有同犯故。若不出舉，無由得結能隨之過。此四諫竟，若有不見，亦合作舉。以隨不見，但得吉故。既不同犯，不勞須出。」
【譯文】【疏文】回答：「九十單提中的規勸完畢後，隨即宣告舉法處分，是為了表明隨順受舉之人也有同犯之罪的緣故。若不宣告舉法，就無從判定隨順者之罪過。而此處這四條戒在勸諫完畢之後，如果犯僧仍不承認自身有罪（不見罪），理應也要對其作不見舉處分。但因為盲從隨順此不見罪者，僅僅只得突吉羅罪。既然隨順者與受舉者並非同犯一罪，律文中就不必多此一舉列出舉法（另制隨舉戒）了。」

【138-0054】02_戒疏/10c_卷三上之一#77
【原文】【記】次舉不舉。問意，可解。答中。初明後戒有舉，以隨舉戒相連次故。次明四諫無舉。論舉有三：一、不見舉，二、不懺舉，隨順此二犯吉；三、惡邪不捨舉，即說欲不障也，隨順犯提。今此四諫，舉唯上二，隨但輕吉。能所各篇，故不同上。
【譯文】【記文】其次是關於有無「舉法」處分的辨析。提問的用意很清楚。回答之中。首先說明後面的單墮戒之所以要有舉法處分，是因為與盲從隨順受舉者的戒條是前後緊密相連的。接著說明四條僧殘戒之後律文之所以未列出舉法（另制隨舉戒）。論及舉法處分共有三種：第一是不見罪舉，第二是不懺悔舉，盲從隨順這兩者的人都犯突吉羅輕罪；第三是堅持惡見不捨舉，即宣稱淫欲不障道這一類，盲從隨順這種舉法的人會犯波逸提罪。如今這四條違諫戒，所能構成的舉法只有前兩種，盲從者只得輕微的突吉羅罪。能隨順者與所隨受舉者的罪名屬於不同篇聚，所以不同於上述單墮戒的情況。

【138-0061】02_戒疏/10c_卷三上之一#84
【原文】【疏】二、須諫意。然彼邪人，倚傍佛教。乞食等四，生聖之緣，趣道遠因，說緣為種。正語等八，生聖之因，趣道近法，正為聖體。稱法而談，名為正見。邪人反說，顛倒教理，是非兩濫，言同意異，真偽難分。迷情墜惡，實可憐愍。須僧設諫，開示是非。冀彼改迷從正，棄惡就善。是以須諫，意在於此。
【譯文】【疏文】第二、必須設立勸諫的用意。提婆達多那樣的邪人，往往依託附會佛教教義。乞食等四依法，本來只是生起聖道的輔助資緣、是趨向佛道的遠程助緣，他卻將助緣誇大為根本種子。正語等八正道，才是生起聖道的真正內因、是趨向聖道的核心正法，也是聖者人格的實體所在。完全契合正法來談論，才稱為正見。邪見之人卻反其道而說，完全顛倒了佛教的義理，使是非正邪兩相混淆，言詞表面雷同而實質意涵完全相違，真偽極難分辨。無知的僧眾被蒙蔽情志而墮入惡道，實在令人哀憐悲痛。所以必須由僧團出面設立嚴正的勸諫，向其剖析開示是非對錯。無非是希望他能改迷成悟、歸向正道，改惡向善。這就是必須設立三諫程序的深意所在。
