# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【196-0001】02_戒疏/09c_卷二下之二#84
【原文】【記】次意中三。初雙徵事法。「然」下，二、正明制意。初敘少欲順教。「今」下，明違法多過。上二句，總標，「一」下，別列。五中，前三過量過，後二不乞過。前中，初過，多事長業，則反正行。第二，多貪增惑，則反少欲。第三，多乞惱他，則反自滅法。「二趣」者，如戒緣中人、非人也。四中，不乞處分，眾法不行，故礙僧事。第五，若在難處，則有命、梵二難。「自損」即命難，「違慈」即梵難。「以」下，通結。
【譯文】【記文】在第二個制戒用意中分為三段。首先雙重質詢建造的事相與法則。從「然」字以下，第二、正式說明制戒用意。首先敘述少欲知足順應聖教。從「今」字以下，說明違背戒律將產生諸多過患。上面兩句是總括標出，從「一」字以下逐一列出。五種過失中，前三種是建造過量所致，後二種是未經僧團審查處分所致。在前三種中，第一種過失是雜事太多滋長世俗業累，違背了正行。第二種是貪念太多增長煩惱惑業，違背了少欲。第三種是過度乞求惱亂他人，反而自我毀滅正法。「二趣」是指戒律緣起當中所說的世人與非人鬼神。在後二種過失中，不向僧團請求審查處分，僧團法事無法如法推行，所以妨礙了僧務。第五種，如果在險難之處造房，就會帶來生命與梵行二種危難。「自損」就是威脅生命，「違慈」就是障礙梵行。從「以」字以下，全面總結。

【196-0002】02_戒疏/09c_卷二下之二#85

【196-0003】02_戒疏/09c_卷二下之二#86
【原文】【疏】答：「四在少欲，依成上品，若使不行，便當中下。是故依而不行，聖不結犯。四開非勝，稱緣而設，而於自分不行，故有輕重別制。但為房是疎緣，義不交急，營搆過多，具前五種，是故制殘。餘三依開，資身正要，事不獲已，必須服用，約情敘過，微故制墮。」
【譯文】【疏文】回答：「四依止法重在少欲，遵依奉行就是上品功德，假使無法做到，便退居中品與下品。因此對於依教奉行卻無法做到的人，聖者不給他結犯戒罪。而四種開許之法並非殊勝之道，只是順應根機因緣而設立的方便，如果連在自己的分位上都不守規矩，所以才根據情節制定不同的輕重罪罰。只因為建造房屋屬於較為疏離的外在因緣，在修道義理上並不是極度緊迫之事，如果營造過度擴大，就具足了前面所說的五種過患，所以制定為僧殘重罪。其餘三種依止法中的開許（衣、食、藥），是資養身軀最直接緊要的事物，實屬不得已而必須服用受用，若論及情理過失相對較輕微，所以只制定為波逸提（單墮罪）。」

【196-0004】02_戒疏/09c_卷二下之二#87
【原文】【記】問中，含二意：一問違依無過，違開有罪；二問違開制罪，房重餘輕。答中，先答初意，前明違依。但由機劣，力所不堪，而非故違，故無所犯。下明違開，食依房藥，四依之後，隨列開法，故云「四開」。言「非勝」者，開對下機，教則緩故。「自分不行」，謂不守開中制法故。「但」下，次答後意。初明房重。「交」，猶至也，《義鈔》作「要急」，或恐傳誤。下明餘輕，「三依開」者，糞衣中開畜長、取衣等，乞食中開受請，即有別眾、展轉、足食等，腐樂中開長藥、請藥等，並見墮中。
【譯文】【記文】問話中包含兩層意思：一是詢問為何違背了「四依止」沒有罪過，違背了「四開許」反而有罪；二是詢問既然都是違犯開許之法而定罪，為何房舍戒判重罪，其餘三種卻判輕罪。答覆當中，先回答第一個問題，前面說明違背依止法的情況。只是因為根機羸弱，力量不堪負荷，並非存心違背，所以不犯戒罪。後面說明違犯開許法，在衣服、飲食、房舍、醫藥四種依止之後，隨即列出了開許的方便法，所以稱為「四開」。說它們「並非殊勝」，是因為開許法是針對下等根機而設，戒律的要求相對放寬。「在自己的分位上不能奉行」，是指不遵守開許條款中所制定的規範。從「但」字以下，接著回答第二個問題。首先說明房舍罪重的緣故。「交」同於「至」，《事鈔》寫作「要急」，恐怕是傳抄錯誤。下文說明其餘三種罪輕的緣故，「三依開許」是指：在糞掃衣中開許蓄存長物衣、接受施衣等；在乞食中開許接受請齋，於是便有了別眾食、輾轉食、足食等戒規；在腐爛藥物中開許儲存長藥、請求特定藥品等，這些全都見於波逸提篇中。

【196-0009】01_行事鈔/10b_卷下之二#55
【原文】二體者。律云：大要有二：泥及鐵也。《五分》有用白銅鉢者。佛言：此外道法，若畜得罪。佛自作鉢坏，以為後式。《十誦》：畜金、銀、瑠璃、銅、鑞、木、石等鉢，非法，得罪。《五分》：畜木鉢，偷蘭。《僧祇》云：是外道標故，又受垢膩。今世中有麥紵鉢、棍瓦鉢、漆鉢、瓷鉢；並是非法，義須毀之。

【196-0010】資持記/14b_下二#56
【原文】《五分、十誦》，並簡非法。鉢坯即未燒者。佛自作者，彼律云：佛在蘇摩國作鉢坯，令窑師燒成金鉢，次成銀鉢；皆言王若知者，謂我能作金銀寶；乃令埋之；後燒作鐵鉢，佛令用之，曰蘇摩鉢，從國為名。則知制度非出凡謀，如前篇云：佛教阿難裁製三衣。
【譯文】第二、鉢的體質。律中說：主要有兩種：瓦泥與鐵。《五分律》中記載有比丘使用白銅鉢。佛陀說：這是外道之法，如果蓄持便得罪。佛陀親自製作泥鉢陶坏，作為後世的範式。《十誦律》說：蓄持金、銀、琉璃、銅、鑞（錫鉛合金）、木、石等材質的鉢，皆屬非法，得罪。《五分律》說：蓄持木鉢，犯偷蘭遮（重罪）。《僧祇律》說：因為木鉢是外道的標誌，而且容易吸收油垢污膩。現今世俗之中有麥紵鉢（麥秸麻布漆胎鉢）、棍瓦鉢（抹粉塗泥瓦鉢）、漆鉢、瓷鉢，全都屬於非法器具，按義理應當予以毀棄。

【196-0011】01_行事鈔/10b_卷下之二#56
【原文】三色是非。《四分》云：應熏作黑色、赤色。《僧祇》：熏鉢作孔雀咽色、鴿色者，如法。若準律文，並須熏治。律文廣具熏法。而世有素瓦、白鐵，掍鋧為色者；或先熏鐵鉢，而剝落者；先熏瓦鉢，但棍不磨；色淺落受膩者；有用麻油塗者。並為非法。親問翻經三藏云：中國無用油鉢者，若此土行用，一度訖，即打破，不許再用。《五百問》中，不許受畜。準此，瓦澡鑵，義同油鉢。《善見》云：鐵鉢五熏已用，土鉢二熏已用受持。諸部律並明熏法。此方用熏二遍入籠，猶未變色，但用法不同。
【譯文】第三、鉢顏色的如法與非法。《四分律》說：應當熏染成黑色或赤色。《僧祇律》說：將鉢熏成孔雀咽喉的青綠色或鴿子羽毛的灰色，合乎律法。如果依照律文，都必須經過煙熏加工。律文中廣泛具備熏鉢之法。然而世間有人使用未熏的原色素陶瓦鉢、白鐵鉢，或者以掍鋧（塗抹拋光）造出色澤；或者先前熏過鐵鉢，但熏層剝落；或者先前熏過瓦鉢，卻只塗抹而不加打磨；或是顏色淺淡剝落而沾染油膩；還有人用麻油塗抹。這些全都是非法的做法。我曾親自詢問翻譯經典的三藏法師（玄奘），法師說：中天竺沒有使用塗油鉢的，如果梵僧來到此土（中國）使用油鉢，用過一次之後，就打破丟棄，不准許再次使用。《五百問》中，也不准許受持蓄用。依照這個道理，陶瓦水罐（澡罐）的用法，義理上與油鉢相同。《善見律》說：鐵鉢經過五次熏治之後才能受用，泥土陶鉢經過兩次熏治之後才能受用受持。各部廣律都載明了熏鉢之法。此方漢地熏了兩次放入烤籠，顏色往往尚未改變，這只是使用的方法不同罷了。

【196-0012】資持記/14b_下二#57
【原文】良以古佛道法，非佛親示，餘無知者；凡在奉持，深須自慶。《十誦》中。《業疏》云：雜寶為器濫在家人，木鉢外道，石鉢唯佛；比丘俱離，但用泥鐵；由離諸濫，省事易得故也。後引《五分》，決上罪相。仍引《僧祇》，彰犯所以。總判諸鉢。白銅及木，可結偷蘭。
【譯文】這實在是因為古佛相傳的正法，若非佛陀親自開示，其餘的人是無從知曉的；凡是能奉持此法的人，內心深處應當深感慶幸。在《十誦律》的內容中，《業疏》說：使用各種珍寶製作器具容易混同於在家人，木鉢是外道所用，石鉢唯有佛陀才能使用；比丘於此三者全部遠離，只能使用泥鉢或鐵鉢；這是為了遠離各種混淆，並且省事容易取得的緣故。後面引用《五分律》，來決斷上面的罪相。進而引用《僧祇律》，彰顯犯戒的緣由。總體判定各種鉢具：白銅與木質的，可以結偷蘭遮罪。

【196-0014】02_戒疏/09c_卷二下之二#89
【原文】【疏】初中。專任在己，故稱「自為」。身獨運造，故云「無主」。大非法限，故曰「過量」。餘同上也。
【譯文】【疏文】在第一部分中。完全由自己做主營造，所以稱為「自為」。獨自一人操辦營建而無施主資助，所以稱為「無主」。尺寸過大超越了法定的界限，所以稱為「過量」。其餘名詞與上面相同。

【196-0015】02_戒疏/09c_卷二下之二#90
【原文】【記】釋名中。言「自為」者，《戒本》標名，則無此語，比下「有主」，亦云「為己」。況疏文牒釋，犯緣明列，理必有之，但恐寫脫耳。指「同上」者，亦應分對所防、能治，諸戒皆爾。
【譯文】【記文】在解釋戒名中。說到「自為」，《戒本》的標題名稱中雖然沒有這兩個字，但比對下面「有主房戒」也標明「為己」。何況疏文引述解釋時，犯戒條件中明白列出，義理上必定是有此一詞，只是恐怕在傳抄中脫漏罷了。指稱「同上」者，也應當分別對應防範的過非與能治的戒法，所有戒律都是如此。

【196-0016】02_戒疏/09c_卷二下之二#91
【原文】【疏】言離合者。
【譯文】【疏文】談到兩條房舍戒的離合。

【196-0017】02_戒疏/09c_卷二下之二#92
【原文】【疏】問：「初後皆房，何故分者？」
【譯文】【疏文】問：「前面和後面這兩條戒都是談房舍，為什麼要分成兩條戒呢？」

【196-0018】02_戒疏/09c_卷二下之二#93
【原文】【疏】答：「同少異多，故不可合。何者？有主無主異，有量無量異，羯磨法中相翻是異。有三別故，所以分之。」
【譯文】【疏文】回答：「因為相同之處少而相異之處多，所以不能合併。為什麼呢？有施主與無施主不同，有尺寸限制與無尺寸限制不同，在僧團羯磨法中兩者的對白詞句正好相反。因為有這三種差異，所以分立為兩條戒。」

【196-0019】02_戒疏/09c_卷二下之二#94
【原文】【記】離合中，初問。答中，三異。上二易知。「羯磨相翻」者，前戒則牒「自乞無主」，後戒乃云「有主為己」。
【譯文】【記文】在離合問題中，首先提問。答覆當中列出三種相異。前面兩種容易明白。「羯磨詞句相反」是指：前一條戒要稟白「自乞無主房」，後一條戒則說「有主為己房」。

【196-0020】02_戒疏/09c_卷二下之二#95
【原文】【疏】「若爾，前房亦有不乞、過量，何為復合？」
【譯文】【疏文】「如果是這樣，前一條房舍戒中也同時包含了『不乞求審查處分』與『過量』兩種過失，為什麼反而合為一條戒呢？」

【196-0021】02_戒疏/09c_卷二下之二#96
【原文】【疏】答：「欲明房雖一口，罪則四含，過濫是多，懼非輒造故也。又顯過量不過量，俱有不乞罪；處分不處分，俱有過量罪。」
【譯文】【疏文】回答：「這是要說明房舍雖然只有一間，罪名卻包含了四種，其中的過失繁雜眾多，令人心生戒懼而不敢擅自建造的緣故。同時也是為了顯示：無論過量還是不過量，只要不向僧團請求審查處分都有罪；無論僧團審查處分了還是沒處分，只要過量建造就都有罪。」
