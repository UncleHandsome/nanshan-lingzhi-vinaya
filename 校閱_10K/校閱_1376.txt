# 校閱材料　第1376檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1376-0001】資持記/16c_下四#23
【原文】無相福田者，出世無漏之福，離有為相故。〔有云：無相即縵衣者，非也。〕下二句勸勵。上句自行。如，依也。下句利他行。九中。令禮佛者，喜形於身也。復說偈者，形於言也。偈詞，上半是能喜。上句自喜，下句他喜。下半即所喜。上句喜緣會，下句喜得法。福願，竝宿因；時，即今緣。十中。
【譯文】稱為「無相福田」，是因為蘊含了出世間無漏的福德，遠離了一切世間有為的事相。〔有人主張「無相」就是指沒有條理的縵衣，這種說法是錯誤的。〕後兩句是用以勸勉與惕勵。上面一句指自己的修行行持。「如」是依循的意思。下面一句則是指利益他人的宏大願行。第九段中。令他禮拜佛陀，是喜悅之情直接流露在身體肢體上的表現。再次宣說偈頌，則是喜悅透過言語表達出來。偈詞的前半段是能生歡喜的心志。第一句是自己深感慶幸歡喜，第二句是令周遭他人同感喜悅。後半段則是所歡喜的殊勝事相。上一句欣喜宿世良緣於今聚會，下一句欣喜今生得以獲持妙法。福德與誓願都是宿世的善因；而「時」指的就是現前的殊勝得度之緣。第十段中。

【1376-0002】資持記/16c_下四#24
【原文】初設禮者，謝證明也。在下坐者，即令預眾，令忻躍也。受親拜者，形貌纔殊，尊卑即別也。出下，示堪受之意。據文，坐已方賀；似令坐受，理亦無損；今或立者，亦是其儀。十一。須中前者，取陽生也。十二。剃髮已，受歸戒者。據論五戒，本在家所受。今雖出家，形同體俗，故得受之；
【譯文】首先向眾僧設拜禮謝，是為了酬謝大眾為其作證。隨後被安排坐在末位下座，是讓其正式列入僧眾行列之中，使其內心充滿法喜躍進。接受親族親友的頂禮跪拜，是因為身形服飾才剛剛轉變，僧俗尊卑的位次隨即分明劃分。在「出」字以下，闡明其之所以有資格接受頂禮敬奉的緣由。依據律文來看，是坐定之後親友才上前祝賀；似乎應當坐著接受禮拜，在法理上也並沒有不妥；如今若有人選擇站著受拜，同樣也符合儀軌規範。第十一段。必須在日中正午之前完成，是為了順應朝陽生氣蓬勃之意。第十二段。剃髮完成之後，接著傳受三皈依與五戒。依據諸論主張，五戒原本是世俗在家之人所受持。如今此人雖然形貌已經出家，但身心本質上仍屬世俗之體，所以可以受持五戒；

【1376-0003】資持記/16c_下四#25
【原文】若不受者，失漸次故，此乃明文。世有不曉，輒欲廢者，便謂《母論》是他部耳。且前云：應以諸部會明，立出家儀式，何獨不用此文耶？豈非情之所蔽乎？問：剃髮披衣已，那名優婆塞耶？答：形同出家，體是婆塞；如〈足數〉中，本受不得者；雖復剃染，尚名白衣。今名婆塞，有何不可？
【譯文】如果此時不受五戒，就會喪失循序漸進的次第，這在經論中有極其明確的記載。世間有些不明白法理的人，動不動就想要廢除這道程序，甚至藉口說《毘尼母論》只是其他宗派的論著罷了。然而前面已經明確指出：應當會集各部律典共同參照明斷，藉以確立出家儀軌，為何唯獨刻意不用這段文獻呢？這難道不是被個人主觀的情見所遮蔽了嗎？有人問：既然已經剃髮並且披上袈裟，怎麼還能稱呼他為「優婆塞」呢？回答說：外在形貌雖然如同出家，內在本質依然還是優婆塞；正如〈足數篇〉中所說，原本受戒未成者；縱使已經剃光頭髮、穿上染衣，在名義上依舊稱為白衣。如今稱呼他為優婆塞，又有什麼不可以呢？

【1376-0004】資持記/16c_下四#26
【原文】疏云：以法分俗，方絕彼此。〔謂受十戒已，方是出家。〕豈以形服而為妨乎！應分二種：一者形同出家，體猶是俗，不妨俗戒；二者法同，既納十戒，已是出家，則不可受在家戒也。問：縱廢不受，為有戒否？答：縱不受十，直爾受具，亦獲三戒。以頓得故。則知五戒，無由廢之。若爾頓得，今廢不受，為有何過？
【譯文】註疏中說：以佛法的戒體劃分僧俗界線，彼此的區隔才能徹底斷定。〔意思是唯有領受十戒之後，才算真正成為出家人。〕哪裡單憑外在的形貌與服飾就造成阻礙呢！這應當區分為兩種層次：第一種是外形與出家人無異，但本質依然是俗人，因此無礙於受持世俗戒法；第二種是法理體性相同，既然已經正式納受十戒，體質就已經是出家人，自然就不可以再回頭受持在家戒法。有人問：假使縱容廢除而不受五戒，究竟能不能得到戒體？回答說：縱使未曾受持十戒，直接受持具足大戒，也能頓時獲取這三層戒體。因為這屬於頓得戒體的特殊情況。由此可知五戒這道次第，根本沒有理由隨意予以廢除。既然可以直接頓時獲取，如今廢除不受，究竟又有什麼過患呢？

【1376-0005】資持記/16c_下四#27
【原文】答：失漸次故。疏引《婆論》云：染習佛法，必須次第；得佛法味，好樂堅固；難可退敗，不破威儀。一時受者，反上失次，又破威儀等。又準《尼鈔》，不受五戒，直受十戒，得戒，得罪。餘如《業疏》受法，廣為辨之。第三受法，作白中。指同前者，即剃髮中。二法竝闍梨秉。彼某甲，即受者；
【譯文】回答說：這樣做會失卻修持的先後次第。註疏中引述《薩婆多論》的話說：熏染修習佛法，必須遵循嚴格的次第；逐步品嚐佛法的法味，內心的好樂向道才能堅定穩固；如此一來道心便極難退轉敗退，也不會輕易毀壞僧團的行儀法度。如果貪快在一時之間頓受，就會違反上述原則而喪失次第，同時也容易破壞威儀規矩等。再依據《比丘尼鈔》的規範，不先受五戒而直接受十戒者，雖然能夠得到戒體，但傳戒之師卻要獲結罪過。其餘更詳細的義理，如同《隨機羯磨疏》（《業疏》）的受法中，已經做了非常詳盡的辨析。第三受戒法中，在作單白的段落。指明如同前面的程序，指的就是剃髮程序中所行的作白法。這兩種羯磨法都由阿闍梨主持宣秉。文中的「彼某甲」，指的就是受戒者本人；

【1376-0006】資持記/16c_下四#28
【原文】從某甲，謂和尚。二中。以出家人必依和尚，不同五八，唯一人故。三中。以五為十緣，十為具緣，故必先五後十。《智論》云：因五戒生十戒，因十戒生具戒。《善戒經》云：先五，次十，三具，四菩薩。譬如重樓四級，不由初級至二級者，無有是處；乃至不由三級至四級者，無有是處等。
【譯文】「從某甲」，指的就是主持的和尚。在第二項中。因為出家人一生必須終身依止和尚，這與受持五戒、八戒時只需要一位傳戒師長的情況完全不同。在第三項中。因為五戒是受持十戒的增上緣由，十戒又是受持具足大戒的增上緣由，所以必定要先受五戒、再受十戒。《大智度論》說：依循五戒而生起十戒，依循十戒而生起具足戒。《善戒經》中也說：先受五戒，次受十戒，第三受具足戒，第四受菩薩戒。這就好比建造四層樓閣，若不想通過第一層就妄想直接登上第二層，是絕不可能的事；乃至不通過第三層就想直接跨上第四層，同樣絕不可能的事等。

【1376-0007】資持記/16c_下四#29
【原文】如此明詰，豈得懷疑。四中，初示正儀。次斥非法。律文但制五法，偏袒、脫屣、互跪、合掌、禮足，本無捉衣之式，復非尊敬之意；故特點之，絕後濫用。五中，初示處。既作單白，義是對僧。理下，次示問緣。立勝緣者，為說法開導，委示心境，及問遮等。舊云：五逆中，但不問破僧。
【譯文】經文這般明辨詰問，學者哪裡還能心存絲毫懷疑呢。在第四項中，首先展示正規的禮儀。接著嚴厲斥責不合法的弊病。律文中僅僅制定了五項敬法：袒露右肩、脫除鞋履、互跪、合掌、頂禮雙足，本來就沒有拉扯師長袈裟衣角作為敬禮的規矩儀式，這樣做也絲毫談不上是真正尊敬的心意；因此特別加以點破糾正，徹底斷絕後人盲目濫用。在第五項中，首先指明受戒的地點。既然已經向僧團宣告作了單白，在法理上就等同於是在僧團大眾面前受戒。「理」字以下，接著說明詢問阻難緣由的規定。設立殊勝緣起，是為了為其開導說法，詳細指示心境如何納受戒體，並且詢問是否有受戒的遮難。古德相傳說：在詢問五逆罪中，唯獨不必詢問是否破僧。
