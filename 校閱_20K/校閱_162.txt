# 校閱材料　第162檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【162-0001】02_戒疏/02b_卷一上之二#46
【原文】【記】引證中。《論》出五法，初是約教，後四從人。二、五相濫，約義兩別。但二取知法之能，五約延時之久。三、四二種，受隨分之。
【譯文】【記文】在引證的文句中。《論》中列出了五種法，第一項是就教法而言，後四項則是就持法之人而言。第二項與第五項看似雷同，但在含義上有別。第二項僅著眼於具備通曉戒法的能力，第五項則著眼於延續住世時間的久遠。第三項與第四項這兩種法事，是以「受戒」與「隨行出罪」來作區分的。

【162-0002】02_戒疏/02b_卷一上之二#47
【原文】【記】問：「所以住法須『五人』者？」
【譯文】【記文】提問：「為什麼住持正法必須要有『五人』？」

【162-0003】02_戒疏/02b_卷一上之二#48
【原文】【記】答：「除出僧殘，餘皆可秉。四人雖體，不辨邊受。受法不行，僧寶永絕。道假人弘，由僧絕故，佛法無託。苟闕斯人，法皆覆墜。」
【譯文】【記文】回答：「除了為僧殘罪者出罪之外，其餘的一切僧事羯磨五人皆可秉持作法。四人雖然已具備成僧之體（羯磨法體），但不能成辦邊地五人受具足戒的法事。受戒法事如果無法推行，僧寶便會永遠斷絕。佛道必須假託人來弘傳，由於僧寶斷絕的緣故，佛法就無處寄託。如果缺乏了這五位持律人，所有的正法都將傾覆崩墜。」

【162-0004】02_戒疏/02b_卷一上之二#49
【原文】【記】「五千年」者，有二：初五千年中，一千年得三達智，二千年得四果，三千年得三果，四千年得二果，五千年得初果；第二五千年，學不得道。萬年經書滅盡，但剃髮披袈裟而已。願諸後學，竭力護持。但得五人，是名「法住」。末世雖多，但知剃染，戒德不修，律範安識？豈能令法光顯於時？況二千年，尚得四果，去聖未遠，但不䇿勤；必有勇進，何患不及？請觀聖論，退而省之。
【譯文】【記文】所謂「五千年」共有兩個階段（前後兩期五千年）：在最初的五千年中，第一個千年有人能證得三達智，第二個千年能證得四果阿羅漢，第三個千年能證得三果阿那含，第四個千年能證得二果斯陀含，第五個千年能證得初果須陀洹；在第二個五千年中，雖然修行卻不再能證得道果。一萬年之後，佛經律書全部滅盡，只剩下剃除鬚髮、身披袈裟的徒具形式而已。希望各位後世學人，竭盡全力守護護持。只要能有五位持律僧人，就叫做「正法住世」。末世之人雖然眾多，卻只知道剃髮染衣，戒德完全不去修持，戒律的風範哪裡還認得？又怎麼能讓佛法在當代光顯燦爛？何況在兩千年內，尚且能證得四果，距離聖人時代還不算太遠，只是眾人不肯策勉勤修罷了；如果有勇猛精進之人，又何必憂慮達不到呢？請仔細審視聖賢的論典，退而反省自警吧。

【162-0005】02_戒疏/02b_卷一上之二#50
【原文】【疏】良由一聞行教，信而奉遵，業非外傾，定慧內發，遠近兩果，無不思懷。引生後進，永隆萬載，故為久住也。

【162-0006】02_戒疏/02b_卷一上之二#51
【原文】【記】出所以中。初明修因慕果。下云「近獲人天，遠成五分」，此為「兩果」。「引」下，明相傳不絕，顯「久住」義。
【譯文】【記文】在顯發緣由的文句中。首先說明修持善因以欣求勝果。下文明言「近則獲得人天福報，遠則成就五分法身」，這就叫做「兩種果報」。「引」字以下，說明代代相傳永不斷絕，顯發「長久住世」的含義。

【162-0007】02_戒疏/02b_卷一上之二#52
【原文】【疏】然此歸敬一行偈文，戒本或無者，但是後人妄減，非是梵本略之。通撿諸部戒心卷首，皆明歸敬。考文約義，理必具之。豈得徑歎戒功，前沒三寶？輒增勸信，誰能奉行？故知引者是也。昔人謂「同大律」，或且標異前弘，刪略傷甚，為過久矣！
【譯文】【疏文】然而，這首表達歸依敬奉的一行偈文，有些戒本中可能沒有，這純粹是後人盲目刪削，並不是梵文原本有所簡略。普遍查閱各宗派戒本卷首，全都明文記載了歸敬之辭。考證文詞、衡量義理，理應完整具備。哪有一開頭就徑直稱歎戒律功德，反而將前面的皈依三寶完全隱沒的道理？貿然陳說勸勉信受之辭，又有誰能夠真正奉持實踐呢？所以知道引用歸敬偈的戒本才是正確的。古時有人認為此本應「等同廣律」，或者為了標榜異於先前的弘揚版本，結果刪減過甚反而造成了極大的損害，這種過失已經持續很久了！

【162-0008】02_戒疏/02b_卷一上之二#53
【原文】【記】斥略中。即願師集本。文相有四。初、明減略。「通」下，二、取他宗，例決《十誦》、《僧祇》、《五分》、《解脫》，四本皆然。「考」下，三、約義斥非。彼本卷首便云「戒如海無涯」，故云「豈得」等。不列三寶，無所稟承，故云「輒增」。「故知引是」者，取覺明、慧光二本也。「昔」下，四、出古除意。上句明簡廣律，下句明異他本。「前弘」即上二本。「刪」下，結責。
【譯文】【記文】在斥責刪略的文句中。這是針對願法師所集結的戒本而言。文義分為四層。第一、說明盲目刪減。「通」字以下，第二、借用其他宗派為例進行裁決，《十誦律》、《僧祇律》、《五分律》、《解脫戒經》，這四部戒本全都具備歸敬偈。「考」字以下，第三、從義理角度斥責其非。彼版戒本在卷首便直接寫「戒如海無涯」，所以斥責說「豈得」等等。如果不排列歸敬三寶，大眾就失去了受持稟受的源頭，所以說「輒增」。「故知引是」這一句，是肯定了覺明、慧光兩位律師所傳的戒本。「昔」字以下，第四、指出古人刪除的意圖。上半句說明其想與廣律保持一致，下半句說明其想標新立異、有別於其他戒本。「前弘」就是指上述兩位律師的戒本。「刪」字以下，作出結語嚴加斥責。

【162-0028】02_戒疏/02b_卷一上之二#73
【原文】【記】科文中，初段。云「宗體」者，宗即戒法，體謂受體。此據已受之人，納法成體，故云「聖道基」也。「弘廣」即指海喻，「引生」即如寶喻。「雖」下，敘次段。初句躡上，「業」下發後。「業」即戒體，造作成故，號為「無作」。非色心相，道理難見，故言「微隱」。「略舉篇聚」，即「欲除」下一偈。「結說有人」者，即「毗婆」下一偈半。「有承寄」者，即「我今」下半偈。「上」下，敘第三節。初二句躡前，「縱」下，起後。「四喻五行」，前二行是一喻，後三行各一喻。又前二別行，後二眾行，如下委釋。「此」下，總示。初明「法」、「體」，次即「戒相」，後是「戒行」，則知此段備敘四戒。「宗體」是教行之本，故曰「所歸」。「戒相」所列成犯「緣境」，為成二持，故云「生行」。「戒用」即目戒行。「用」謂功用，非行不彰，從功表行，故云「用」也。「結成」謂行心造作。「本業」即二持善因。因能感果，故云「本」也。或通持犯、善惡二業，彰戒功深，持益毀損。
【譯文】【記文】在科判的文句中，這是第一段。所謂「宗體」，宗是指戒法，體是指所領受的戒體。這是就已經受戒的人而言，領納教法化為自身的戒體，所以說「是聖道的基礎」。「弘廣」就是指如大海的譬喻，「引生」就是指如珍寶的譬喻。「雖」字以下，敘述第二階段。首句承接上文，「業」字以下啟發後文。「業」就是戒體，由造作修持所成就的緣故，稱為「無作戒體」。既非物質色法亦非心識之相，其道理極難洞見，所以說是「微隱」。「略舉篇聚」，就是指「欲除」以下的一首偈頌。「結說有人」，就是指「毗婆」以下的一偈半。「有承寄」，就是指「我今」以下的半偈。「上」字以下，敘述第三個小節。前兩句承接前文，「縱」字以下引發後文。「四喻五行」，前兩行偈頌合為一個譬喻，後面三行偈頌各自構成一個譬喻。又前兩個譬喻屬於個別修行，後兩個譬喻屬於大眾羯磨，如後文詳細解釋。「此」字以下，作總體開示。最初闡明「戒法」與「戒體」，接著就是「戒相」，最後是「戒行」，由此可知這段文句完整敘述了「法、體、行、相」四戒。「宗體」是教法與行持的根本，所以稱為「所歸」。「戒相」所列出的是構成犯罪的「緣境」，為了成就止持與作持二種行持，所以稱為「生行」。「戒用」就是指戒行。「用」是指功用，若非透過修行則無法彰顯，藉由功用來表現修行，所以稱為「用」。「結成」是指修持之心所造作的業行。「本業」就是止作二持的善因。因行能夠感得善果，所以稱為「本」。或者通指持戒與犯戒、善與惡這兩種業行，用以彰顯戒律功德深厚，持戒有利益而毀犯有損傷。
