# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【203-0021】02_戒疏/10a_卷三上之一#14
【原文】【疏】次釋名者。內無三實，故曰「無根」，以重加誣，名之為「謗」。「無根謗」非是戒，乃是戒家所防。「戒」者，能治之行。能所通舉，故曰也。
【譯文】【疏文】其次是解釋名義。由於內心毫無見、聞、疑三種事實依據，所以稱作「無根」；拿重罪橫加誣衊，稱之為「謗」。「無根謗」並非戒律本身，而是戒法所要防範的過失。「戒」，則是能對治調伏的行持。將能治與所治通融並提，所以如此命名。

【203-0022】02_戒疏/10a_卷三上之一#15

【譯文】【記文】在解釋名義中，首先照錄名目來解說。「三實」，就是親見、親聞、生疑這三種實事。說到「以重」，是為了簡別排除其餘各聚罪法，因為那些罪較輕且層次遞降。「無」字以下，其次是總體開示。說到「所防」，是顯明這是所要防範的過失之相。

【203-0032】02_戒疏/10a_卷三上之一#25
【原文】【記】次難中。初舉二文，彼云：「若草木於寶藏上生，若斫伐者，得突吉羅。」、「受寄」文如盜戒引。「殺草」即壞生，「觝言」是妄語，並不犯提，則與上文損主及畜雙結義乖，故引為難。「皆」下，正難。「相似」，謂與前事同。「無別罪」，謂無別果罪也。答中，上句領前難詞。「相成」即盜家方便。下句反成單犯，正符前義。
【譯文】【記文】在第二層反難中。首先舉出兩段引文，那部論說：「如果草木生長在寶藏之上，如果將它砍伐，得突吉羅罪。」「受寄」這段文字如盜戒中所引用。「殺草」就是破壞生類，「抵賴」就是說妄語，這兩者都不另犯波逸提罪，那麼就與上文損害主人及畜生雙重結罪的義理相違背，所以引來作為質難。「皆」字以下，正式提出反詰。「相似」，是指與前述事件性質相同。「無別罪」，指的是沒有另外的根本果罪。回答之中，上一句領受對方剛才的反難言辭。「相成」是指所引之論文正好相互印證無墮罪之義。下一句則反過來證成只是單犯，恰好符合我先前的觀點。

【203-0033】02_戒疏/10a_卷三上之一#26
【原文】【疏】今準別論，單雙俱得。元情專謗無妄心，約心唯可結一罪；若兼誑謗兩種心，僧誑人謗結二罪。如前殺父兼羅漢，兩舌相對互說相也。
【譯文】【疏文】現在依照另一種論述來看，判為單罪或雙罪都可以說得通。如果起初的心思專注在誣謗而沒有特意欺誑的心，依照心念來看就只能結犯一種罪；如果同時兼具欺誑僧眾與誣謗他人這兩種心，那麼對僧眾是欺誑、對那個人是誣謗，便結犯兩種罪。這就如同先前所說殺害父親而父親又是阿羅漢，以及離間語（兩舌）相對互為句型的相狀一樣。

【203-0034】02_戒疏/10a_卷三上之一#27
【原文】【記】次約義中。初總標。下約兩意，故曰「別論」。「元」下，別示。約心單複，釋通兩解。以業隨心結，故罪有雙單，善達持犯，於茲見矣。「如」下，舉例，有二。初舉殺戒，故指「如前」。謂父成羅漢而行殺者，若但殺父，不知成聖，止得一逆；若知是聖，則兼二逆。次引兩舌戒，即《多論》中以口三過互歷為句，故云「相對」。一、是兩舌，非妄語、惡口；二、是兩舌，非妄語，是惡口；三、是兩舌，是妄語，非惡口；四、三種俱是。餘二為頭，互歷亦爾。並由心緣兼獨，故使犯有雙單。證今謗、妄，不可偏判矣。
【譯文】【記文】其次是依理抉擇分析。首先是總體標明。下面依據兩種心意來判別，所以稱為「別論」。「元」字以下，個別指明。依照心念的單純或兼帶，通暢地解釋了兩種看法。由於造業是隨著發心而結罪，所以罪名有雙犯與單犯之別，能夠善於通達持犯之理，在此處就能看出來了。「如」字以下，舉出兩個例子。首先舉出殺戒為例，所以指稱「如前」。意思是如果父親成就了阿羅漢而行殺害，如果只知道是殺父，不知道父親已成聖人，只得一重逆罪；如果明知是聖人，就兼犯兩重逆罪。其次引述兩舌戒，即《薩婆多論》中將口業的三種過失互相歷經配置成句型，所以說是「相對」。第一種，是兩舌，但不是妄語、惡口；第二種，是兩舌，不是妄語，而是惡口；第三種，是兩舌，也是妄語，但不是惡口；第四種，是三種過失全都具備。以其餘二者作為開頭，相互歷對也是如此。這全都是由於心念所緣境是兼帶或是單一，因而使得犯戒有雙犯與單犯之別。由此證實如今討論誣謗與妄語，不可偏頗地執定一種判法。

【原文】【記】四、分齊中。以謗本為治，言了未遂故。答中。上二句明不待治，由出「僧力」，不由我故。下二句顯從言了，「遂瞋暢思」，顯示業成故。
