# 校閱材料　第154檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【154-0001】02_戒疏/01d_卷一上之一#44
【原文】【記】已上五師，得名有三：初從解為名，下云「明慧卓朗，除邪倒」故；二從計得名；後三從觀行為名。又小乘宗計不出四門：初是空門，二、五即有門，第三雙亦，四即雙非。或可總歸二宗：一、四皆空宗，二、三、五並有宗。
【譯文】【記文】以上這五位大師，名稱的由來有三種：第一是從其理解教理的角度來命名，下文說「明利智慧卓越朗照，能破除偏邪倒見」就是這個意思；第二是從其所堅持的主張見解來命名；後三位則是從其觀修實踐的行持來命名。此外，小乘宗派的見解都不超出四門：第一是空門，第二與第五屬於有門，第三是亦有亦空門，第四則是雙非的非有非空門。或者也可以總歸為兩大宗：第一與第四都屬於空宗，第二、第三與第五則全屬於有宗。

【154-0002】02_戒疏/01d_卷一上之一#45
【原文】【疏】又云：「廣博徧覧五部經典，是故名曰『摩訶僧祇』。」此云大眾，此有其律。
【譯文】【疏文】經中又說：「廣博而且全面閱覽了五個部派的經籍教典，因此名稱叫作『摩訶僧祇』。」這裡翻譯為大眾，該派存有其傳世的律典。

【154-0003】02_戒疏/01d_卷一上之一#46
【原文】【記】六、僧祇中。不偏一見，攝機斯足，故云「廣博」。懸觀五計，集法無遺，故云「徧覽」。
【譯文】【記文】第六位、大眾部這部分。該派不偏執於單一的見解，化導攝受各類根機極為周全充分，所以稱為「廣博」。預先全面觀照五個部派的見解，匯集佛法毫無遺漏，所以稱為「全面閱覽」。

【154-0004】02_戒疏/01d_卷一上之一#47
【原文】【疏】問：「古師多謂『僧祇本律即婆麤富羅所執』，今如何分？」
【譯文】【疏文】有人提問：「古代的法師多半認為『僧祇部原創的律本，就是婆麤富羅部所受持的經典』，如今又該如何進行區分呢？」

【154-0005】02_戒疏/01d_卷一上之一#48
【原文】【疏】答：「非敢苟分，《大集》明異。若合『婆麤』，文不應云『徧覽五部』。」
【譯文】【疏文】回答說：「並非我們敢隨便妄加劃分，而是《大集經》已明確指出了兩者的差異。如果大眾部等同於『婆麤部』，經文中就不應該說它『全面閱覽了五個部派』。」

【154-0006】02_戒疏/01d_卷一上之一#49
【原文】【記】初問中。「古師謂」者，如前已示。答中，初示所據。「若」下，顯古違文。
【譯文】【記文】在第一個提問中。「古代法師認為」的說法，前面已經揭示過了。在回答中，首先指出劃分的依據。「如果」以下，指出古代法師的說法違背了經文的原意。

【154-0007】02_戒疏/01d_卷一上之一#50
【原文】【疏】問：「二部、五部同是後分，如何經讚唯在五部？」
【譯文】【疏文】有人提問：「根本的兩部與後出的五部，同樣都屬於後來的分流，為什麼經文唯獨偏重讚歎五個部派呢？」

【154-0008】02_戒疏/01d_卷一上之一#51
【原文】【疏】答：「二部是本，義通五見，不慮後疑。五部支生，各懷異相，多起諍競，恐不傳持，故偏牒五『不妨法界』。」
【譯文】【疏文】回答說：「根本的兩部是佛法的大源頭，義理完全能融通後出的五種見解，用不著擔憂後世產生疑惑。而五個部派則是後起的枝末，各自心懷相異的教條相狀，極容易激起爭端競爭，深恐因此無法代代傳承住持，所以經文中才特別指明這五部『並不妨礙共同證入法界涅槃』。」

【154-0009】02_戒疏/01d_卷一上之一#52
【原文】【記】次問。經中但云「五部雖異，不妨諸佛法界涅槃」，不言僧祇，故有此問。據經止有僧祇，而言「二部」者，欲顯本部亦分，經中合讚故也。答中。上明本部不須意，下示五部須意。
【譯文】【記文】在第二個提問中。經文中只說「五部雖然相異，卻不妨礙共同證入諸佛平等的法界大涅槃」，並未直接提及大眾部，因此產生了這個疑問。按照經文本義只有提到大眾部，而提問中卻稱作「根本兩部」的原因，是想彰顯根本部派本身後來也發生了分裂，經文中理應一併讚歎才對。在回答中，前段說明根本部派不需要特別讚歎的緣由，後段則指出五部之所以必須特別讚歎的用意。

【154-0010】02_戒疏/01d_卷一上之一#53
【原文】【疏】問：「如上所列，五部在初，僧祇應後，以徧覽故。」
【譯文】【疏文】有人提問：「按照上面所列出的順序，五個部派排在前面，大眾部理應排在最後，因為它是『全面閱覽了五個部派』的緣故。」

【154-0011】02_戒疏/01d_卷一上之一#54
【原文】【疏】今解云：「僧祇實先，滅後便有，以廣博故，通含五意，故是總也。如上《經》說。」
【譯文】【疏文】如今解釋說：「大眾部在實質上確實起源在先，佛滅度後隨即產生，正因為它包羅廣博，能通泛含攝五派的要旨，所以它代表著總體。正如上述《大集經》所說明的那樣。」

【154-0012】02_戒疏/01d_卷一上之一#55
【原文】【記】第三問。以僧祇根本，理合在前，而《經》云「徧覽」，則顯居後，故須通之。答中。古師執前三藏所傳，以僧祇為五部，恐據「徧覽」之語謂是後分，故須問決。此中不敘，故直標「今解」。初示次第。既云「廣博」，顯是根本。「通含」總攝，故是徧覽。
【譯文】【記文】第三個提問。由於大眾部身為根本部派，按常理應當排在最前面，然而《經》中卻說它「全面閱覽」，這就顯示它似乎居於後位，所以必須予以融通解釋。在回答中，古代法師執持先前三藏法師所傳的說法，將大眾部當作五部之一，恐怕會有人依據「全面閱覽」這句話便認定它是後起的部派，所以必須提出問答加以裁定。這裡不再贅述古說，而是直接標出「如今的合理解釋」。首先指明先後次序。既然稱作「廣博」，顯然它是最根本的宗源。「通泛含攝」而總體收羅，這就是所謂的「全面閱覽」。

【譯文】【疏文】第二部分，說明題名次序先後的問題。

【154-0031】02_戒疏/01d_卷一上之一#74
【原文】【記】答：「二意通之：一據自宗已盡，二梵本元備，傳度致缺，如《業疏》云『于闐有本，約可百卷』是也。」

【154-0032】02_戒疏/01d_卷一上之一#75
【原文】【疏】此據說之所至，非義判也。故二十犍度離分三分，可是義開邪？
【譯文】【疏文】這個劃分是依據宣說時的段落進度而定，並非刻意按照義理類別所作的科判。所以律中的二十個犍度被拆散分置在三個部分中，這難道會是出於義理邏輯的開合劃分嗎？

【154-0033】02_戒疏/01d_卷一上之一#76
【原文】【記】次科。恐謂同世章疏科釋為四，故此遮之。由結集時，隨至一節未終而罷，如是四番，一部方畢，故云「此據」等也。「故」下，引據。律中二十犍度，《受戒》、《說戒》二犍度，在第二分尼律後；《安居》下十六犍度，自為第三分；《房舍》、《雜法》二犍度，在第四分初。據此散落，無有分齊，驗非義判，故云「可是」等。
【譯文】【記文】這是第二科。深恐有人誤以為如同世間人作章疏註解般刻意科判劃分成四段，所以在此予以澄清阻絕。因為結集之時，隨著進度說到某個段落尚未完結便暫且告一段落，像這樣經過了四輪進程，整部大律才告圓滿，所以說「依據宣說時的段落進度」等等。「所以」以下，引用客觀事證為憑據。律藏中的二十個犍度，《受戒》與《說戒》這兩個犍度被編排在第二分比丘尼律的後面；《安居》以下的十六個犍度，則自成第三分；《房舍》與《雜法》這兩個犍度，又落在了第四分的開頭。由此可見這些內容散落分置，在章節段落上毫無整齊的界線，充分印證了這並非依照義理來劃分科別，所以說「這難道會是」等等。

【154-0038】02_戒疏/01d_卷一上之一#81
【原文】【疏】戒者，禁也，警也，即眾行之所因；本者，根也，從也，能生成於道務，此「戒為道本」也。又云「戒為行本」，世出世行並依承之。又云「戒為教本」，一部廣律，止解戒行之文，計應名「律本」，今舉行目教也。又云「戒為說本」，在座誡勸，有所依承，文云「半月說，戒經中來」也，豈不以所說為傳者之本也？又云「聽者以說為本」，耳聽心納，尋說生行。如是廣之。
【譯文】【疏文】所謂的「戒」，具有禁止、警策的意思，它是一切善行得以生起的根本因由；所謂的「本」，具有根本、依從的意思，能夠培育生成一切修道的事業，這就是「戒是道業的根本」。又有一種說法是「戒是善行的根本」，不論是世間還是出世間的善行，全都必須依仗承接它而立。又有一種說法是「戒是教法的根本」，一整部浩瀚的廣部律藏，只不過是用來解釋戒行條文的文句，按理原本應當稱作「律本」，如今是以所詮的戒行來命名能詮的教法。又有一種說法是「戒是宣說的根本」，在法座上進行警戒與勸勉時，內心有所依憑遵從，文獻上說「每半個月所宣說的法，皆出自這部戒經之中」，這豈不是說明了所宣說的戒文就是傳法者的根本嗎？又有一種說法是「聽聞的人以宣說為根本」，耳朵聽聞而內心納受，依循著所宣說的條規而落實出實際行動。照這樣可以廣泛地演繹發揮。

【154-0039】02_戒疏/01d_卷一上之一#82
【原文】【記】廣釋中。五義：前二約所詮法，後三就能詮文。初義以因望果，故言「道本」；次義唯就因論，故云「行本」；三約能詮對所詮；四即能說望所說；五即能聽望能說。對文可見。「如」下結指。
【譯文】【記文】在詳細解釋的內容中。共包含了五種意涵：前兩種意涵是就文字所詮顯的實踐法則而言，後三種意涵則是就具備詮釋功能的文獻本體而言。第一種意涵是從修因仰望所證之極果，所以說是「道業之本」；第二種意涵則是單純就因地修持來論述，所以說是「善行之本」；第三種意涵是拿能詮釋的文教對應所詮釋的行法；第四種意涵是能宣說的法師仰仗於所宣說的條文；第五種意涵則是聽受教法的弟子依憑於能宣說的教誨。對照著疏文便清楚可見。「照這樣」以下，總結並指明可多方體悟。
