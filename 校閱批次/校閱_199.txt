# 校閱材料　第199檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【199-0001】資持記/14b_下二#26
【原文】次答，前示生相。七種者，青黃赤白黑紫縹〔青黃之色〕。所下，次明生種。離地得生，如柳榴類，其枝可栽者。從緣，即水土也。指律五種，即根枝節子雜種也。第五，標中，初敘須廣之意。略下，列章。初科，前引《多論》五意。第五即外道見比丘不自取果，發心出家等。次引《五分》，因呵而制。
【譯文】接著回答，前面先說明生長的面貌。七種顏色是指：青、黃、赤、白、黑、紫、縹（青黃交錯的顏色）。「所」字以下，接著說明能夠生長的種子。脫離土地仍然能夠生長，例如柳樹或石榴之類，它們的枝條可以直接插枝栽種。所謂順從外緣，就是指水分和土壤。指引律中的五種，就是指根、枝、節、種子以及雜類種子。在第五門標題這一段中，首先敘述必須廣泛說明的用意。「略」字以下，列出各個章節。第一科中，前面引用了《多論》的五種立教意圖。第五種意圖就是外道看見比丘不自己摘取果實，因而發心出家等。接著引用《五分律》，是因為受到譏嫌而制定戒條。

【199-0002】資持記/14b_下二#27
【原文】故知立法意為遮譏，即同《多論》第三意也。不與取即盜異名。口受二意，防法防罪，如文可分。後指如下，即防罪中。二中，初標問。手下，釋通，義分為三，初明手通。次明口局。時藥亦有口者，即有緣口加三受也。時藥有二局：一手口互局，二並局中前。餘三可見。《十誦》中，初示緣開。
【譯文】由此可知，制定戒法的意圖是為了防範世人的譏嫌，這與《多論》的第三個意圖相同。「不與取」就是偷盜的另一種名稱。口受有兩種意圖：防止違背戒法與防止產生罪過，這就如同經文中所能區別的那樣。後面指引「如下」，就是指防止罪過這一段。在第二部分中，開頭先標出提問。「手」字以下，進行解釋與會通，義理上分為三個部分，首先說明手受普遍通用。接著說明口受具有局限性。時藥也有用到口受的，那就是遇到特殊因緣時，以口受之法加唱三次受持。時藥有兩種局限：一是手受與口受互相局限，二是兩者都局限在正午前使用。其餘三種藥的情況可以想見。《十誦律》中，首先說明因特殊因緣而開許。

【199-0003】資持記/14b_下二#28
【原文】由非正時，故云時分。非下，簡藥體。舉宿者，語含殘內。三中。所授，即過食者。初科。五義者，指上《多論》。由有五義，故須餘眾，不許自類。六眾，道四俗二也。三趣，更兼非畜也。口受二局，眾局比丘，趣唯人道。次科。作證明者，即上五中第二義也。論中約人有無以明成不；
【譯文】因為不是正午之前合法的用餐時間，所以稱為「時分」。「非」字以下，簡別藥物的本體。所謂「舉宿」一詞，語中含攝殘宿、內宿二義。在第三部分中，所謂「所授」，就是指遞交食物的人。第一科中，所謂「五義」，是指上面《多論》所說的五種意圖。因為具備這五種意圖，所以必須由其他眾人來授與，不允許由同類比丘自行授與。「六眾」是指佛教出家的四眾加上在家的二眾。「三趣」則是再包含了非人與畜生。口受有兩種局限：在眾別上局限於比丘，在道趣上唯獨限於人道。第二科中，充當證明的人，也就是上述五種意圖中的第二個。論典中依照身邊有沒有人來判定受法是否成功；

【199-0004】資持記/14b_下二#29
【原文】非畜成者，必約知解。三中。止即不須。手眼現相，口即語示。四中，敘意為三，初示法。心境者，心即能緣，境謂前食。仰手是色，相領即心。上注引非顯正，下注釋成相領。一事即食境。除下，明開。眼雖不覩，亦可聞聲；有緣置地，彼雖無心，自須起意。
【譯文】非人和畜生能夠成就證明，必然是針對具有理解能力者而言。在第三部分中，「止」就是不需要的意思。手勢與眼色呈現外相，口中則用言語示意。在第四部分中，敘述其意圖分為三點，首先說明受法。「心境」這兩個字，心是指能緣的心念，境是指眼前的食物。雙手向上攤開屬於色法，彼此心意領受屬於心法。上面的註文引用錯誤的做法以顯現正確的做法，下面的註文則解釋促成彼此心意領受的道理。「一事」就是指食物這個對境。「除」字以下，說明開許的情況。眼睛雖然看不見，也可以透過耳朵聽見聲音；有特殊因緣而放在地上時，對方雖然沒有特別作意，自己心裡必須生起受持的意念。

【199-0005】資持記/14b_下二#30
【原文】不喜即外道相嫌，驚急即火燒馬屋，具引如〈釋相〉。既下，教通受。謂先須起念是食皆受；後或心差，亦得成法。受法，標中，初指略時藥。此下，次標三藥。分位以明，故曰別論。非時四位，初中。八患，謂八種過。前五染觸，通自他犯；後三約受，唯據自論。
【譯文】「不喜」是指遭到外道嫌棄，「驚急」是指失火燒了馬棚，詳細引述就如同〈釋相篇〉所載。「既」字以下，教導通用的受法。意思是說事先必須生起意念：凡是食物我全都接受；事後就算心念出現偏差，受法也一樣能夠成立。在「受法」標題這一段中，開頭先略過時藥不談。「此」字以下，接著標示出其餘三種藥。因為必須分出不同的階段時位來說明，所以稱為「分別論述」。非時藥有四個階段，在第一階段中，「八患」是指八種過失。前面五種屬於沾染污觸，自己或他人犯戒都會受影響；後面三種針對受持來說，唯獨就自己這方面來論斷。

【199-0006】資持記/14b_下二#31
【原文】六是不受，七八即失受。第七且據中後為言，中前無過，如注所簡。第八注文，即前轉變體中中論所說；謂果漿變為甜醋，即失受法。二中。須煮沸者，謂生果汁；必是熟者，則不須之。三中。前漿類別者，如上體中果蜜等漿，有差別故。三記識者，或須不須，故注示之。四中。
【譯文】第六種是未曾受持，第七和第八種是失去受持。第七種暫且是針對正午之後的時間來說的，如果在正午之前則沒有過失，就如同註文中所簡別的那樣。第八種的註文，就是指前面「轉變體」中依照中論所說的內容；也就是果汁發酵變成了酸醋，就失去了原本受持的效力。在第二階段中，必須煮沸的，是指生鮮的水果汁；如果本來就是熟的，就不需要再煮沸。在第三階段中，前面所說各類果漿的區別，就如同上面在藥體中所說的水果漿、蜜漿等，彼此存在差異。第三種「記識」，有時需要、有時不需要，所以註文特別予以說明。在第四階段中。

【199-0007】資持記/14b_下二#32
【原文】諸律無文有事，故須義立。詞中六句。初令專審，恐異緣故。二稱己名，簡非他故；準下科中，病重不堪，得代加之，應稱病者名字。三稱病緣，明非濫託。四云薑湯，別指藥體。五云夜分，期定時限。六於他受，求前對證。〔下二法分句同此。〕注云無遺不須加者，由加口法，本為延時；
【譯文】各大律典中沒有明文記載卻有實際行事，所以必須依義理來訂立。唱詞中共有六句：第一句是令對方（對首大德）專心審察，唯恐夾雜了其他因緣。第二句是稱呼自己的名字，簡別這不是別人；依照下文的科別，如果病情嚴重無法親自作法，可以由他人代為加受，這時就應當稱呼病患的名字。第三句是說出生病的因緣，表明並非隨意託詞。第四句說「薑湯」，是特別指出該藥物的本體。第五句說「夜分」，是明確限定時間的期限。第六句是向他人請求受持，尋求對方作為當面的證人。（下面兩種受法的分句也是比照這個格式。）註文說如果沒有剩餘就不需要加受，這是因為增加口頭唱詞的受法，本來就是為了延長存放的時間；

【199-0008】資持記/14b_下二#33
【原文】必無所留，但直手受七日中，初明八患。改第八者，以酥油等無變動故。犯竟殘藥，異上殘宿；但是受已經夜，非犯竟者。〔昔約自他分異，非非。〕能授四法，大同於前。三中五過，初過分二，初正明，二問答。正明又三，初句標過。若下，示相。僧下，引證。
【譯文】如果必定沒有剩餘的藥物，只要直接用手接受即可。在「七日藥」中，首先說明八種禍患。之所以改動第八種，是因為酥油等物不會變質腐壞的緣故。已經犯過戒的殘餘藥物，與上面所說的「殘宿」不同；殘宿只是接受之後經過了一夜，並非犯過戒的藥物。（過去有人從自己或他人來區分差別，這是不對的。）能授藥者的四種法則，大致與前面相同。在第三部分所列的五種過失中，第一種過失分為兩段，首先正式說明，其次進行問答。正式說明又分為三部分，第一句標示出過失。「若」字以下，指出其相貌。「僧」字以下，引用文獻作證。

【譯文】就是二釜二瓶各有四物。「則」以下，合計數目，可以明白。「又」以下，其次說明鐵作具。韛，讀薄拜反，是皮囊吹風入爐。錯就是鑪。鏇音旋，古作去聲，是轉軸用來裁器。〔像現今錯木塑車。〕「亦」以下，第三說明熏鉢之物，就是熏爐、熏籠等。「若」以下，第四說明作衣之具。絣線，是彈墨取直。「治」以下，第五說明補鉢之具。鑽，讀子算反，就是錐。鍱，音葉。「蘭若」以下，第六，說明火具。

【199-0050】資持記/14c_下二#11
【原文】火母，所鑽物，如竹木等。火子，取火物，如乾艾等。鑽即火鑽，亦用竹木為之。若下，七明諸鉢。初因得藥令置四種鉢中，故知得畜。文中通云不作淨施，然大鉢應量，理必須說，故注決之。〔據律應是不應量者。〕龍牙杙者，杙頭雙出，像龍牙故。不得下，簡非。故知上四並據泥鐵為體者。
【譯文】火母，是被鑽之物，如竹木等。火子，是取火之物，如乾艾等。鑽就是火鑽，也用竹木做成。「若」以下，第七說明各種鉢。起初因為得藥，令放在四種鉢中，所以知道可以畜。文中通說不作淨施，然而大鉢應量，理上必須說淨，所以加注決斷。〔據律應是指不應量的。〕龍牙杙，是杙頭雙出，像龍牙的緣故。「不得」以下，簡別非法。所以知道上面四種都是就泥、鐵為體而說的。

【199-0051】資持記/14c_下二#12
【原文】出下，別示鍵𨩲。上文示異名，下文顯體相。二中，初老病開作。挽即牽也。輦謂小車，或用畜駕，或是人荷。牸牛𮪏馬，皆謂雌者之異名；深防觸染，故簡除之。若得下，次明他施得畜。轅音袁，即車前兩木，引而舉前以駕軛〔音厄。〕皮繩用以束輦。枕橙並輦上所須。應下，明駕輦人。
【譯文】「出」以下，別示鍵𨩲。上文示異名，下文顯體相。第二中，先開許老病者作。挽就是牽。輦是小車，或用畜力駕，或由人擔荷。牸牛、𮪏馬，都是雌者的異名；深防觸染，所以簡除。「若得」以下，其次說明他人布施可以畜。轅音袁，就是車前兩木，引而舉前以駕軛（音厄）。皮繩用來束輦。枕與凳都是輦上所需。「應」以下，說明駕輦的人。

【199-0052】資持記/14c_下二#13
【原文】簡比丘故。若下，指例。車即大者。應下，簡非。織皮，有華文故。髮繩，同外道故。三中。彼以針綴衣，無故衣解形露，因制帶行。今用鉤紐，則不須之。此中但明聽畜耳。四中。非行來處，即僻隱處也。五中，《十誦》。尾拂得受，非己用故。犛牛莫交反，多出西方，鬃尾皆赤，多用為拂。《僧祇》中。
【譯文】這是簡別比丘的緣故。「若」以下，指例。車就是大的。「應」以下，簡別非法。織皮，因為有華文。髮繩，因為同於外道。第三中。他們用針綴衣，若沒有針，衣服散解便會導致身體顯露，因此制令帶行。現在用鉤紐，就不需要了。這裡只是說明聽許畜而已。第四中。非行來之處，就是偏僻隱密的地方。第五中，《十誦》。尾拂可以受，因為不是自己用的。犛牛，莫交反，多出西方，鬃尾都是赤色，多用來作拂。《僧祇》中。

【199-0053】資持記/14c_下二#14
【原文】初明自畜，則簡畜尾。裂㲲謂剪絹布為條。樹皮即麻苧楊樹等，今多用椶櫚為之。今時後生持扇執拂，多作女態；教名婬女，豈不懷慚。《五百問》中。几即几案，麈謂鹿之大者，群鹿行時，看尾指處，即隨所往；講者持拂指授聽眾，故以為名；但不得畜毛為之，故制犯罪。《四分》。
【譯文】首先說明自己蓄存的規定，就排除了動物尾巴製成者。「裂㲲」是指剪裁細絹棉布成為布條。「樹皮」就是指大麻、苧麻、楊樹等樹皮，現在多用棕櫚樹皮製作。現代的年輕出家人拿扇持拂，多半裝模作樣像女人的體態；戒教中稱為如淫女之態，難道不感到慚愧嗎？在《五百問經》中：「几」就是几案。「麈」是指鹿群中體型較大者，鹿群奔跑時，看麈尾所指的方向便隨之跑去；講經者持麈尾拂指授聽眾，所以取名為麈尾；但不得蓄存獸毛所製成的麈尾，故制定結罪。引《四分律》中：
