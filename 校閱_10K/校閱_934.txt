# 校閱材料　第934檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】現今初學之人，常將鳴鐘輕視為微小瑣事，大多不存至誠懇切之心；請詳察以上諸文，希望能因此有所省悟；或者輪到執掌維那時，當依循上述的威儀，仍須發下殷重誓願；如此便能拔苦與樂，成就廣大行持。「斥責浮濫」這部分，前兩句引出浮濫之說以斥責其虛妄。彼方認為比丘差遣他人打鐘，必須說「知鐘」，這才算是清淨語；如果直接說「打鐘」，就名為不淨語。「諸」字以下兩句，依據教理顯明其錯誤。文中舉出經論，文字上對律典有所略過。言「打」如前面引用的四分、五分等律，言「擊」出自《阿含經》，言「檛」則出自《大智度論》。

【934-0007】資持記/02c_上一下#7
【原文】知下，以理難破。前明打鐘，能教所教，俱通道俗；然知淨語，能不通俗，所不通道；事非相例，故用難之。知淨不通俗者，能教局道也；鐘則不爾，通彼俗士，使人打故。及自為者，所教局俗也；鐘亦不爾，通彼比丘，受教自打故。早下，勸勉。
【譯文】「知」字以下，依循法理進行詰難攻破。前面說明打鐘，無論是能教者或受教者，都通於道俗二人；然而所謂「知」的清淨語，能教者不通於俗人，所教者不通於道人；兩件事性質不同無法並論，所以用這點來詰難他。知淨語不通於俗人，是因為能教者局限於道人；打鐘則不是如此，能通於俗人，可以差遣他人去打。鈔文說「及以自為」，是因為受教者局限於俗人（比丘不得自為，只能教俗人淨人去做）；打鐘也不是如此，通於比丘，可以接受教敕自己去打。鈔文中自『早』字以下，為勸勉之辭。

【934-0008】資持記/02c_上一下#8
【原文】疏云：知鐘之言，雖非巨害，然是知法者之大忌。〔《古記》妄解，以疏對照，曲而釋之。〕第二辨來處。總標通局，分科云分齊者何耶？答：通謂體同，局謂相別。同則略分，別須委示。從局標名，故言分齊。下科用人，例亦同此。問：通局何相？答：一處，二人。言處者，作法自然二界是通；
【譯文】義疏說：「知鐘」這種說法，雖然不是什麼嚴重的禍害，然而卻是通曉如法之人的大忌。〔《古記》妄加解釋，拿義疏相對照，便曲意牽強地穿鑿附會。〕第二部分「辨明界限來處」。總體標示通相與局相，分科稱為「界限範圍（分齊）」是何原因？回答：通相是指體性相同，局相是指事相有別。相同者則略加區分，有別者則須詳細開示。依照局相來安立名稱，所以稱為界限範圍。下一科指明用人，例子也同於此。提問：通相與局相是何種相貌？回答：一是指處所，二是指人員。所謂處所，作法界與自然界兩者屬於通相；

【934-0009】資持記/02c_上一下#9
【原文】作法有三，自然分六，則為局也。人中，別人及僧二位為通；別有三階，僧分四種，故為局也。語冠首題，一篇綱要；略知條目，始可尋文。標示中。制意開緣，下篇既顯，不可兩繁；故指如後。以類相從，此之謂矣。作法三者，場及大小。然有場四集，雖兼大界，正意明場。
【譯文】作法界有三種，自然界分為六種，這就屬於局相。在人員中，個別之人與僧伽兩個位階屬於通相；個別之人有三個等階，僧伽分為四種，所以屬於局相。這些話冠於篇首題目之中，是一整篇的綱要；大略通曉了條目，才可以進而披尋內文。「標明指示」這部分。制戒的本意與開許的因緣，在下一篇既然已有顯明闡述，就不可以重複繁複；所以指示如後文所載。按照同類性質相互歸納，指的就是這個意思。作法界的三種，是指戒場以及大小界。然而有戒場時可在四處集僧，雖然兼明了大界，但其主要用意是在說明戒場。
