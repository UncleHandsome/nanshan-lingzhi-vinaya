# 校閱材料　第473檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【473-0001】02_戒疏/06b_卷二上之二#57
【原文】【記】隨釋中，初科。「問何罪」者，若據注中，明結偷蘭，由兼殘境，欲分兩犯，故發是問。答中，初句總示，「若」下，別釋。又二：初約心分相，「此」下，結示今犯。
【譯文】【記文】在隨文逐條解釋的第一個科判中。「問犯何罪」這句話，如果依照小註所說，明明白白結判為偷蘭遮，但因為這種行為同時牽涉到僧殘罪的犯境，問者想要釐清這兩條戒的界限，所以才發出這個提問。回答中，第一句先總括提示，「若」字以下則分別詳細解釋。這又分為兩層：第一層是依照動機心念來劃分罪相，「此」字以下則是結語指明現在這一戒所要結罰的標準。

【473-0002】02_戒疏/06b_卷二上之二#58
【原文】【疏】就境想中，前之三句，本境為言。後之兩句，境差想也。
【譯文】【疏文】在心念與外境相對應的文句中，前面的三個句子，是以本來的真實客觀境界為基準；後面的兩個句子，則是指客觀境界產生了偏差、非原本所設想的情況。

【473-0003】02_戒疏/06b_卷二上之二#59

【譯文】【記文】在分析心境想念的段落中，梳理出各個句子。前三句全都結判為極重罪，因為戒律絕不通融開許行淫時的愚癡迷糊；後兩句全都結判為較輕之罪，因為所侵入的客觀部位根本不成立大淫戒的根本犯境。

【譯文】【疏文】若要從法理層面詳細劃分境想句法，在《事鈔》中有非常詳盡的論述，現在只在此提綱挈領地簡略列出。

【473-0006】02_戒疏/06b_卷二上之二#62
【原文】【記】義門中，制意。以心有是非，境有錯誤。「婬、酒」，前三句重，後二句輕。餘戒，初句相應故重，後四句乖差故輕。
【譯文】【記文】在法理層面中，說明制戒的用意。因為內心的認知有正確與錯誤，外在的境界也有對應與偏差。「淫戒與飲酒戒」，前三句結重罪，後兩句結輕罪。其餘各條戒律，第一句心境相符所以結重罪，後四句產生乖離差錯所以結輕罪。

【473-0007】02_戒疏/06b_卷二上之二#63
【原文】【疏】二、明有無者。準《律》約戒，不必具有。今解「無」者，是略也，無別所以。
【譯文】【疏文】第二、說明各條戒律中是否有境想句法。依照《四分律》的戒條來看，並不是每條戒都必須具備這套句法。現在我們的見解認為，律文「沒有列出」的地方，純粹只是文字省略罷了，並沒有什麼特殊的深奧緣由。

【473-0008】02_戒疏/06b_卷二上之二#64
【原文】【記】次門，正釋中。據《律》戒本，二十六戒，具出境想句，餘並不出，故須辨之。
【譯文】【記文】在第二門正式解釋的內容中。依照《四分律》的戒本，只有二十六條戒完整列出了境想句法，其餘戒條全都沒有列出，所以必須加以辨析明白。

【473-0009】02_戒疏/06b_卷二上之二#65
【原文】【疏】有人云：「一切過境皆重，則無境想，如漏失者。」今解不然。境雖通犯，染起由心。如《律．調部》，精出，約心明有、無想，即輕、重也。故知無者，但是略耳。
【譯文】【疏文】有人主張說：「凡是侵犯一切客觀過失境界全都算重罪的戒律，就不存在境想句法，例如故意洩精的漏失戒。」現在我們判定這種說法是不對的。客觀境界雖然只要觸碰都算犯戒，但染污煩惱的生起畢竟是由心念所主導。正如《律藏．調部》中所記載，關於排洩精液的判定，也是依照當事人的心念到底是有想還是無想，來區分情節的輕罪與重罪。由此可知，沒有列出句法的地方，純粹只是文筆省略罷了。

【473-0010】02_戒疏/06b_卷二上之二#66
【原文】【記】斥非中。初引彼解。以「漏失戒」，內色，外色水、風、空等，皆是犯境，隨境犯殘，不須簡辨，故無句法。「今」下，正斥。初立理，「如」下，引據。彼云：「非道想不疑，殘。」則明漏失，文略不出，非理無也。
【譯文】【記文】在駁斥錯誤觀點的段落中。首先引述對方的錯誤見解。對方認為「漏失戒」無論是自身的內色器官，或是外在的水、風、虛空等一切境界，全都是觸犯的對象，只要隨境洩精就犯僧殘罪，不需要特別簡別分辨，所以沒有句法規則。「今」字以下，是展開嚴正駁斥。首先確立正理，「如」字以下則是引用文獻依據。律文中說：「非道想不疑，殘」，這就證明漏失戒只是文字省略未列，絕不是法理上不存在這套分析。

【原文】【疏】三、定四、五句者。
【譯文】【疏文】第三、判定究竟是適用四句法還是五句法。

【473-0012】02_戒疏/06b_卷二上之二#68
【原文】【記】三中。以《律》中列句，四、五不定。且如初篇，婬、殺、妄三戒並五句，盜戒四句。殺五句者：一、人作人想，夷；二、人作人疑，蘭；三、人非人想，蘭；四、非人人想，蘭；五、非人非人疑，蘭。盜四句者：一、有主有主想，夷；二、有主有主疑，蘭；三、無主有主想，蘭；四、無主無主疑，蘭。餘如《鈔記》具引。但由第三一句，結罪有、無，故句法不定。如「殺戒」，人非人想，轉想蘭，本迷吉。盜戒無第三句者，以有主無主想，想轉亦蘭，本迷無罪。若準《鈔》中，則約「本迷」、「轉想」對明。今此一門，唯約本迷，罪之有無，於義易解。
【譯文】【記文】在第三個環節中。因為《律藏》中所列出的句法，在四句或五句上並不固定。就以第一篇極重罪來說，淫戒、殺生戒、大妄語戒三條戒都是五句法，而偷盜戒卻是四句法。殺生戒的五句法是：一、是人而作人想，犯波羅夷；二、是人而心存懷疑，犯偷蘭遮；三、是人而誤作非人想，犯偷蘭遮；四、是非人而誤作人想，犯偷蘭遮；五、是非人而心中懷疑，犯偷蘭遮。偷盜戒的四句法是：一、有主之物而作有主物想，犯波羅夷；二、有主之物而心存懷疑，犯偷蘭遮；三、無主之物而作有主物想，犯偷蘭遮；四、無主之物而心存懷疑，犯偷蘭遮。其餘內容如《事鈔記》中所詳盡引述。這完全是由於第三句到底有沒有結罪，才導致句法數量不固定。例如「殺生戒」中，把人誤當成非人，如果是念頭轉變則犯偷蘭遮，若自始本來就認錯則犯突吉羅。偷盜戒之所以沒有第三句，是因為把有主物誤當作無主物時，即使念頭轉變也是偷蘭遮，但若自始徹底認錯則完全無罪。如果依照《事鈔》的說法，則是拿「原本認錯（本迷）」與「中途轉念（轉想）」互相對照說明。現在此處的法理，純粹只就「原本認錯」的情況來判定罪過之有無，在義理上比較容易理解。

【473-0013】02_戒疏/06b_卷二上之二#69
【原文】【疏】若輕、重相望，境是可學，生不可學迷，同是五句。如覆重謂輕等。
【譯文】【疏文】如果從情節輕重互相對照來看，客觀境界本是應當修學明瞭的重罪境，臨事卻生起了不可學的事差之迷（迷重為輕），這種情況一律適用五句法。例如隱匿重大罪過卻誤以為是輕微過失等情況。

【473-0014】02_戒疏/06b_卷二上之二#70
【原文】【記】輕、重中。迷重為輕，如人作非、畜殺，有主作非、畜盜等，皆緣罪境，定有第三句，故同五句。「覆重」者，即「覆麤戒」。《律》出四句，今約罪緣，入五句中。謂覆藏初、二兩篇麤罪，犯提；迷夷作提，迷殘謂吉，覆則犯吉。此雖本迷，不妨結犯。《律》中不出，謂一向無罪而覆藏者。
【譯文】【記文】在輕與重的分析中。將重罪誤認是輕罪，例如殺人卻誤當作非人或畜生來殺，盜取有主物卻誤當作非人或畜生物品來偷，這都是緣取了罪惡境界，必定存在第三句，所以同樣具備五句。「覆重」是指「覆藏粗罪戒」。律文中列出四句，現在依照造罪緣由，將其歸入五句法中。也就是隱匿第一篇或第二篇的粗重罪過，本犯波逸提；若將波羅夷誤以為是波逸提，或將僧殘誤認為突吉羅，一旦隱匿仍舊犯突吉羅。這雖然是屬於原本認錯的情況，但並不妨礙結判犯罪。《律藏》中之所以不列出，是指那些自始至終認定對方完全無罪而予以隱匿的情形。
