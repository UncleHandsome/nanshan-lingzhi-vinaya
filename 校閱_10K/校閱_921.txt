# 校閱材料　第921檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【921-0001】資持記/02a_上一下#25
【原文】方克一句，即收第四五。克猶遂也。若下，次明失，初三句明緣乖不得。即反五緣。不待全差，少乖即失，故云毫微。徒虛也。將下，彰無戒之過。上一句失自利，下二句失利他。結誥中，初二句指所誥人。清身謂志樂建修。圓果即心期極證。無下一句，誡輕易。必下，教用意。
【譯文】「方得克成」一句，就收攝了第四與第五緣；「克」是遂願之意。「若」字以下，其次說明喪失戒體的情形，前三句說明緣法乖違而不得戒，這正是與上述五緣相違背。不待五緣全盤出錯，只要稍有違背便會喪失，所以說「毫髮之微」；「徒」是空無之意。「將」字以下，揭示沒有戒體的過患：上一句指喪失了自利的功德，下兩句指喪失了利他的功用。在結語告示中，前兩句指明所要告示的對象：「潔淨己身」是指志向樂於建立修持，「圓滿果德」是心意期盼能獲致極致的證悟。「無」字開頭的一句，是告誡不可等閒輕忽；「必」字以下，教導大眾應如何用心：

【921-0002】資持記/02a_上一下#26
【原文】專志者，有所詣也。攝慮者，無異想也。契謂心會前法，入即納法歸心。滯，礙也。故下，引證。即《涅槃》十八卷，彼云：云何念戒？菩薩思惟有戒不破不漏不壞不雜〔不破即四重，不壞即餘戒；不漏不雜，即重輕方便，此依北遠疏。〕，雖無形色而可護持〔非色〕；雖非觸對，善修方便，可得具足〔非心〕；
【譯文】「專心一志」是指有所歸趨，「收攝散慮」是指不起任何雜念；「契」是心神契會當前的戒法，「入」就是納受法教歸於自心；「滯」是滯塞障礙。「故」字以下，引用經文作為明證，即是出自《涅槃經》第十八卷，經文說：如何繫念戒律？菩薩思惟這戒法是不破、不漏、不壞、不雜的（不破是指未犯四根本重戒，不壞是指未犯其餘輕戒，不漏與不雜是指遠離重輕戒的起心動念與方便罪，這依據隋代淨影寺慧遠法師的疏解），雖然沒有形質色相卻可以如法護持（非色法）；雖然不是感官可以觸摸相對的，只要善巧修習方便法門，便能夠具足成就（非心法）；

【921-0003】資持記/02a_上一下#27
【原文】諸佛菩薩之所讚歎，是大方等大涅槃因。此證重心領納，有戒何疑。徵釋中，初科；上二字，徵上所受，發下開章。但下，釋意。初敘廣；且下，示要。初中，上二句據法明廣。五、八、十、具，四位不同；或約業者，七支種類也；或從制者，重輕篇聚也。軼〔徒結反，又音逸。〕，車相交過，喻其多貌。
【譯文】這為諸佛菩薩所共同讚歎，是大乘方等大涅槃的因緣。這段經文證明了以至誠莊嚴之心領受納取，必定能獲得戒體，還有什麼好懷疑的。在徵問與解釋的段落中，第一科的前兩個字，是徵問上文所領納的內容；並藉此發起下文以開立章門。「但」字以下，解釋其意旨：先陳述法義的寬廣，而「且」字以下，則標示其中的樞要。前半部分中，上兩句是依據戒法來說明寬廣：五戒、八戒、十戒、具足戒，這四個位階各有不同；或者就業性分類，包含身口七支各種類型；或者順應制定分類，包含輕重各個篇聚。「軼」字（徒結反，又音逸），是車輛交錯奔馳的樣子，以此比喻其數量繁多浩博；

【921-0004】資持記/02a_上一下#28
【原文】次二句約心明廣。即上四位各有三品。若下二句，就境明廣。情及非情，不可數故。示要中。樞即門樞，亦取要義。欲達四科，先須略示。聖人制教名法，納法成業名體，依體起護名行，為行有儀名相。有云未受名法，受已名體；今謂不然。法之為義，貫徹始終，安有受已不得名法。
【譯文】接下來兩句是就發心來說明寬廣，也就是上述四個位階的戒法，都各自有上品、中品、下品三種發心。「若」字開頭的兩句，是依據所緣的境界來說明寬廣，包括有情世間與非情器世間，浩瀚不可計數。在標示樞要中，「樞」是門戶的軸心，也是取其關鍵要領之意。想要通達這四個科條，必須先做簡略的開示：聖人所制定的教導名為「戒法」，將戒法納入身心並凝結成業力名為「戒體」，依託戒體生起防非止惡的守護名為「戒行」，落實於操行而顯現儀表軌度名為「戒相」。有人說尚未受戒之前叫作法，領受之後才叫作體，現在看來並非如此；「法」的涵義，貫穿了始終，哪有受戒之後就不能稱之為法的道理？

【921-0005】資持記/02a_上一下#29
【原文】須知下三從初得號，是故一一皆得稱戒。或可竝以法字貫之，方顯體及行相，非餘泛善。問：所以唯四，不多少者？答：攝修始終，無缺剩故。隨成一行，四義整足；言有次第，行不前後。問：法之與體，同異云何？答：《業疏》云：體者戒法所依之本。
【譯文】必須知道下面三者（體、行、相）都是從最初的「戒法」而得名，因此每一個都可以冠上「戒」的名稱；或者都可以貫穿一個「法」字（如法體、法行、法相），這樣才能彰顯體性以及行持的外相，並非一般的泛泛善行。問：為什麼只有這四項，不能增多也不能減少？答：因為它完整涵蓋了修持的始末，沒有欠缺也沒有多餘。隨順成就任何一項行持，這四種義理都完整具足；說法雖有先後次第，但落實在行持上是沒有前後分別的。問：戒法與戒體，究竟是同還是異？答：《業疏》說：戒體是戒法所依憑的根本；

【921-0006】資持記/02a_上一下#30
【原文】是則法為能依，體是所依，不可云同。又云：戒體者，所謂納聖法於心胸，即法是所納之戒體。據此不可云異。應知言法未必是體，言體其必是法。不即不離，非同非異。問：行相何異？答：三業分之。戒法中，初文二，初標示。語猶敘也。直下，正明。法雖兩通，不能委辨；
【譯文】這樣看來，法是能依，體是所依，不能說是相同；該疏又說：所謂戒體，就是將神聖的法教納受在自己的心胸之中，也就是說法本身就是所納受的戒體；根據這點，又不能說是相異。應當明白：稱之為「法」未必就是戒體，但稱之為「戒體」其本質必然是法；兩者不即不離，非同非異。問：戒行與戒相有什麼差別？答：可以用身、口、意三業來作區分。在「戒法」的章段中，第一段包含兩個部分，先標明並提示，文中的「語」就像是敘述；「直」字以下，正式說明：法雖然通達於凡夫與聖人，但無法在此逐一詳辨；

【921-0007】資持記/02a_上一下#31
【原文】但從聖論，故云直也。必，定也。軌成者，示法義也。出離道者，聖所證也；〈釋相〉科為聖道本基，即同此意。要下，出從聖所以。然此但示法之功力，文不明指何者是法，意令學者思而得之。次科，初二句躡前。今下，正示。已成者，初果已上所修三學，名聖道故。
【譯文】此處只單純順著聖人的境界來論述，所以說是「直（直接）」。「必」是必定。「軌成」是展示「法」的軌範定義。「出離之要道」是聖人所證悟的境界；〈釋相篇〉的科判立為「聖道根本基址」，也就是同一個意思。「要」字以下，說明為何順從聖人來立論的緣故。然而此處只是揭示戒法的功用力量，文字上並未直接指明究竟什麼是法，用意是讓研習者深思而自得。第二科的前兩句承接前文；「今」字以下，正式指出：所謂「已成就者」，是指初果以上的聖者所修習的戒定慧三學，名為聖道；

【921-0008】資持記/02a_上一下#32
【原文】今雖在凡，亦名聖法，因中果號也。三中，初明立志，上二句明慕近事。背俗向道，得事解脫，在凡因故。下二句明希遠果。斷惑證理，即理解脫，是聖果故。累即三界結使，外謂二種涅槃。又可上約身儀異世，下據心行清昇。必下，勸令早學。言必預者，不得臨時故。此心者，即上近遠二心。
【譯文】現在我們雖然仍處於凡夫位，但也稱為領受聖法，這是在因地預先冠上果位的名稱。第三節中，先說明立定志向：前兩句說明仰慕切近的行事，背棄世俗邁向聖道，能夠獲得事相上的解脫，這是居於凡夫因地的緣故；後兩句說明希冀長遠的聖果，斷除煩惱契證真理，就是證得理體上的解脫，這是聖人的極果；「累」是指三界的結縛煩惱，「外」是指有餘依與無餘依兩種涅槃。又或者上一句是指身體威儀有別於世俗，下一句是指內心行持清淨超拔昇華。「必」字以下，勸勉學者應當及早修習。說「必定要預先準備」，是因為無法臨渴掘井；「這份心志」是指上述切近與長遠的兩種心願；
