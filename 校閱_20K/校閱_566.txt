# 校閱材料　第566檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【566-0001】資持記/09b_中三上#7
【原文】欲明佛是勝緣，復非為己，而被呵制；以況餘事深非所宜，注中破戒獲罪，妄謂得福，是為儌倖矣。〔此注合是大字。〕釋中，初文為三，初示地相。律云若未掘，即是生地，易知故略。但明已掘，文中二相；初約四月，謂經時故；二約被雨，由滋潤故；由此二緣還成生地，故不可掘。
【譯文】旨在說明佛陀是至高無上的勝妙福田，而且掘地又不是為了自己，卻依然遭到佛陀呵斥並制戒；以此類推其餘瑣事，更深知極不適宜去做。注文中提到破戒反倒獲罪，卻妄想能求得福報，這完全是心存僥倖的妄念〔這段注文按體例應當是正文的大字〕。解釋的文句中，第一段分為三層，首先指出土地的性相狀態。律中說若是從未挖掘過的，那就是生地，因為容易辨識所以略過不談。這裡只說明已經挖掘過的土地，文中有兩種情況相貌：第一是歷經四個月，指時間已經過了很久；第二是被雨水淋過，由於受到水分滋潤的緣故；由於這兩種緣由，土質又還原成為生地，所以不可挖掘。

【566-0002】資持記/09b_中三上#8
【原文】四月不論被雨，被雨不待四月。〔有以四月被雨為一事，此未見律文。〕若用下，明掘傷。钁即鍫類，耒謂手耕之具。扴古黠反，謂以手物揩動。作地想者，結過由心。若不下，明使人不教，先犯此罪。別釋中，《十誦》，初明似地。發生力薄，故並犯輕。頹，崩也。石底，即石所壓地。
【譯文】滿四個月不必考慮是否被雨淋，被雨淋過則不用等待四個月滿〔有人把滿四個月又被雨淋當作同一件事，這在律文中未曾見過〕。「若用」以下，說明挖掘與損傷土地的行為。钁是指大鋤頭之類，耒是指用手操作的耕地農具。「扴」的讀音為刮，指用手或器物去磨擦翻動。內心存有土地的想法，罪過的成立完全由動念決定。「若不」以下，說明使喚他人時不使用合法說詞，教唆者自己先犯下此罪。在分別解釋中，《十誦律》首先說明看似土地的類別。由於滋生萬物的能力薄弱，所以挖動都算輕罪。「頹」就是崩落的意思。石底，就是被大石壓在底下的土地。

【566-0003】資持記/09b_中三上#9
【原文】泥字去呼，謂泥塗處。恐深至地，故制沒膝，已下無犯。除下，明緣開。作模，謂規地作相。此開生地，若準前注，未可從寬。若下，明非地不犯。赭即赤土〔不生物者〕。墡即白土。生石，天生石地。《多論》。言蜀本者，簡關中本；文多闕漏，止有八卷；首師從蜀僧求得第九，即今藏中見傳者是。
【譯文】「泥」這個字讀去聲，是指爛泥塗抹的地方。唯恐泥層太深會觸及真實土地，所以規定深陷過膝才算犯戒，在膝蓋以下不算違犯。「除」字以下，說明因特定緣由而開許的狀況。製作模具，是指在地上劃定範圍做出形相。這雖開許動到生地，但若依照前面的注文來看，不應該輕易放寬處理。「若」字以下，說明非屬土地的物質，動之不犯戒。「赭」就是紅土〔不能生長植物的土〕。「墡」就是白土。天生石是指天然生成的整塊石質地面。《薩婆多論》中。提到所謂蜀地版本，是為了與關中版本區別；關中本缺漏甚多，只有八卷；首律師從蜀地僧人那裡求得第九卷，也就是現在大藏經中所見流傳的版本。

【566-0004】資持記/09b_中三上#10
【原文】文釋二地，初句通標。生地者下，牒釋，初釋生地。罪相可知，故文不出。餘下，釋不生地，初示名。地無不生，從緣彰號，故云義名。若下，顯相有三，初明觸地。乾土吉者，與濕連故，不連無犯。次明牆土。濕字誤，論作齊築處，即指牆體，故云異於地也。雖字上，論有地字，謂牆根邊地。
【譯文】論文明釋兩種土地，第一句是通泛標出。「生地者」以下，承接並作解釋，首先解釋何謂生地。其罪相大家皆知，所以文中未特別寫出。「餘」字以下，解釋非生地，首先指出名稱。大地沒有不能滋生萬物的，只是順應特定情緣才立出名稱，所以說是假借意涵而立的名。「若」字以下，顯發其相貌共有三種，第一說明接觸地面。乾燥的泥土動了算小罪（吉羅），是因為它與下方的濕土相連，若不相連則不犯戒。其次說明牆壁上的泥土。「濕」字是傳抄錯誤，論典中作「齊築處」，就是指牆壁本身，所以說它不同於一般土地。「雖」字之上，論典中有個「地」字，是指牆根旁邊的地面。

【566-0005】資持記/09b_中三上#11
【原文】濕淹犯墮，不濕應吉。發起即掘動。三明牆屋上土。傷草是後戒。下文或明草木，皆相因而引，非此中意，知之。《僧祇》中，初作務毀傷。轉石謂翻轉也。搭地謂以物按搭令平。二明上塊大小。三明損壁。打合作釘。損成功者，示犯義也。若外下，四明重生地。
【譯文】泥土濕潤浸染時挖動犯墮罪（波逸提），不濕潤則應算小罪。發起就是掘動的意思。第三說明牆壁與屋頂上的泥土。損傷青草是後面那一條戒的內容。下文中若有提到草木，都是順帶引述對照，並非本戒的核心旨意，應當明白這一點。《僧祇律》中，第一說明勞作事務中的毀損。翻轉石頭就是將它翻動。搭地是指用物品向下按壓敲打使之平整。第二說明土塊的大小標準。第三說明損壞牆壁。「打」字理應作「釘」字（指釘杙房壁）。損毀了已經造好的建物，這是用以點明犯戒的法義。「若外」以下，第四說明重新變回生地。

【566-0006】資持記/09b_中三上#12
【原文】土末祭謂地極盡際，雨不沾處。若撤下，五明摘壞。此謂地上疊累為壁，如今土牆。初約有泥。令人除已，自得摘。若下，次明無泥被雨。令除潤際，自摘中間。行字戶綱反。〔或去呼，北地俗語。〕井下，六明治水。瀆即是溝。汪水，謂雨暫停處。抒，常呂反，洩水也。
【譯文】「土末祭」是指土地極深或偏僻的邊界、雨水淋不到的處所。「若撤」以下，第五說明拆除破壞。這是指在地上層層堆疊泥土築成的牆壁，就如同現在的土牆。起初以塗有濕泥的情況來說。指使他人清除表泥之後，自己才可以拆除。「若」字以下，其次說明未塗泥但被雨淋過的情況。應使人除去濕潤的表層邊緣，自己再拆除中間乾燥的部分。「行」字讀作杭，平聲〔或者讀作去聲，這是北方民間俗語〕。「井」字以下，第六說明治理水患。溝瀆就是水溝。汪水，是指雨水暫時積聚停滯的地方。「抒」讀作捨，是排洩積水的意思。

【566-0007】資持記/09b_中三上#13
【原文】大下，七明扴傷。謂在生地。若瓶下，八明動物。九明砂土。十明死土。次緣開中，《四分》火難，上開壞生。若下，開掘地。土滅者，以土撲也。逆燒，燒字去呼，謂迎前野火也。除即去土，不使旁延。《善見》，前明非地。文列三相。砂地土少無犯，《僧祇》半砂吉；義準砂少，即同生地。
【譯文】「大」字以下，第七說明擦動損傷。這是指在生地上的情況。「若瓶」以下，第八說明搬動器物。第九說明沙質土。第十說明死土。其次在開許的緣由中，《四分律》提到遭受火災時，前面開許毀損植物；「若」字以下，開許挖掘土地。以土滅火，是指用泥土覆蓋撲滅。逆燒的「燒」字讀去聲，是指迎著前方野火蔓延的方向預先點火燒除。去除雜物就是挖走泥土，防止火勢向旁延燒。《善見律》前面說明非屬土地的類型。文中列出三種樣貌。沙地中泥土極少者動之不犯戒，《僧祇律》則認為半土半沙算小罪；依此義理推敲，若沙少土多，就等同於生地處理。

【566-0008】資持記/09b_中三上#14
【原文】若野火下，示緣開。《五分》中。但引作相召眾。下指諸部，同開掘壞，重故不引。釋第四緣，論文前明僧犯。僧尼作淨語者，法不對人，作不成故。餘眾不作者，有人無法，違佛制吉；掘即犯提。下明三眾。無緣犯者，有緣開故。《五分》緣開，有淨人則犯。剉草，斬乾草以和泥也。《僧祇》下注文。
【譯文】「若野火」以下，指出開許的因緣。《五分律》中。僅僅引用在地上劃出記號召集僧眾。下文指出其餘各部派律典，同樣開許掘地破壞，因為文意重複所以不再引出。解釋第四個犯戒條件，論典文字前面先說明僧人犯戒。僧人與尼僧若對彼此說清淨口令，在法理上對象不合，口令無法成立。若指使未受具戒的其餘人等而不說清淨口令，是有合格受話人卻未依法說淨語，比丘違背佛制結吉羅；受使者若動手挖掘，比丘即犯提罪（波逸提）。以下說明沙彌等三眾。無正當事由而掘地算犯戒，有正當事由則開許。《五分律》開許的因緣是，若現場有淨人指使而不指使，自己動手就犯戒。剉草，是指把乾草斬碎來攪拌泥土。《僧祇律》底下的注文。
