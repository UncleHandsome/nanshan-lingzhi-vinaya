# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【114-0001】02_戒疏/05b_卷二上之一#14
【原文】【記】第七門，釋名中。初通示，「遂」下，別釋。初略分，上二句明隨事尋名，名則有濫。如下諸部，互出不同。「隨」下，次明以名定事，事則可分。如文所示。「所」下，委釋。初釋錯義，「若」下，釋誤義。準文顯相，不出境心。論境有二：一、現不現別；二、多與少別。心亦有二：一、忙亂迷謬；二、臨機前後。如是尋之，不更繁釋。
【譯文】【記文】第七門，解釋名稱的段落中。首先是通泛開示，「如果順著」以下是分別解釋。先作粗略的劃分，前兩句說明如果隨事尋求名稱，名稱就容易產生混淆，就像後文諸部律典互有不同的記載一樣。「若是依循名稱」以下，接著說明依據名稱來判定事實，事相就能條理分明，正如律疏本文所展示的那樣。「為什麼」以下是詳細解釋，先解釋「錯」的含義，「若要論述」以下是解釋「誤」的含義。依照律文顯發的相狀，始終不脫離「境」與「心」兩個層面。就境來說有兩種：一是顯現與不顯現的分別，二是多與少的分別；就心來說也有兩種：一是慌亂迷謬，二是臨機的前後心念不同。循著這個脈絡去探討即可，不再作繁雜的解釋。

【114-0007】02_戒疏/05b_卷二上之一#20
【原文】【疏】若先剋定，要取人物，不盜餘趣。及往盜時，境交想轉，雖舉離處，不成罪攝。不稱本心，猶屬本主，以於此物，元無盜心。心境既非，何過之有？故錯與誤俱不名犯。後知錯、誤，即應還主，不還起盜，後方成重。

【114-0008】02_戒疏/05b_卷二上之一#21
【原文】【記】小漫中。初示起心。「及」下，明造境，初判非犯。「境交」是錯，「想轉」即誤。若得人物，犯重無疑；若非、畜物，則開無犯。「不稱」下，次釋所以，初句示心非。言「不稱」者，本期在人故。「猶」下三句明境非。「屬本主」者，猶是非、畜物故。「心」等四句雙結。「後」下，明後犯。前開離處，「後知」「起盜」，則非所開。非畜蘭吉，望盜云「重」。
【譯文】【記文】特定程度較淺的普遍心（小漫心）段落中。首先說明發起的心意。「等到」以下說明造作對境，首先判定為不犯根本罪。「境界交錯」就是錯，「意想轉變」就是誤。如果錯得的是人類的財物，犯重罪自無可疑；但若錯得的是非人或畜生的財物，則予以開許不犯重。「因為這不符合」以下接著解釋原因，第一句說明心意違背，說「不符合」是因為原本只鎖定在人身上。「財物依舊」以下三句說明對境違背，說「屬於原本主人」是因為物主是非人或畜生。「心意與客觀對境」等四句同時作總結。「如果事後」以下說明後續結犯的情況。前面開許剛移離原處時不犯重，但「事後知曉」而「生起盜心」，就不是開許的範圍了。對於非人或畜生財物雖然只結偷蘭遮或吉羅罪，但相較於前面全不犯來說，這裡稱為結「重」。

【114-0011】02_戒疏/05b_卷二上之一#24
【原文】【疏】三、對同主辨錯誤者，俱非犯也，故《善生》云「盜金得銀，還置本處，不得盜罪」。如《律》男想盜女物者犯，據漫心也。
【譯文】【疏文】第三、針對同一個物主來辨明錯與誤，兩者也同樣不犯重罪。所以《善生經》中說：「本想偷金子卻錯拿了銀子，若放回原來的地方，就不構成偷盜罪。」至於《律》文中說「心裡想著是男人的財物而實際偷了女人的財物要結犯重罪」，那是依據普遍心而判定的。

【114-0012】02_戒疏/05b_卷二上之一#25
【原文】【記】同主中。初通標。「故」下，引示。得銀許還，則知離處，不即成犯。知銀不還，後心自結。「如」下，點異。《律》文「結夷」，似不開誤，故須引決，與上無違。「據漫心」者，謂小漫也。前之三門，初是漫心，兼含大小，後二剋心，別開自他。又前對異趣，二對異人，三約異物。
【譯文】【記文】針對同一物主的段落中。首先總括標明原則。「所以」以下引用經文證明。既然拿了銀子許諾歸還，可知剛挪移開原處時並不立即構成根本重罪。如果明知是銀子卻不歸還，後起的心念自然會單獨結罪。「至於」以下點出異例。律文中「結犯波羅夷重罪」，看似不開許誤拿，所以必須引用來加以決斷會通，使其與上述義理不相違背。所謂「依據普遍心」，指的是特定程度較淺的普遍心。前面這三個層面，第一個是普遍心，同時兼含大普遍心與小普遍心；後兩個是特定心，分別開許了自他對境的差異。又或者說，第一個是針對不同趣的眾生，第二個是針對不同的人，第三個是針對不同的物品。
