# 校閱材料　第1319檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1319-0001】資持記/15a_下三#7
【原文】不取不捨，謂於法離有無二執；不修，謂不取所修行；不者，謂不取所證道。彼云：無有少法可取，既無所取，則無所捨；又無自他兩修，則無所證著故。〔不見自修，不見他修。〕顯德中，初科，引文有五，《增一》中。毀讚同佛者，欲明損益重故。由下，串重所以。《十輪》中。
【譯文】「不取不捨」，是指對於諸法遠離了「有」與「無」兩種偏執；「不修」，是指不執取自己所修的行持；「不」字（即指不證），是指不執取自己所證得的聖道。那部經說：沒有絲毫法可以執取，既然沒有可取的，也就沒有可捨棄的；而且沒有自修、他修的分別，所以不會對所證之理產生執著（看不見自己有修，看不見他人在修）。在顯明德行（顯德）中，第一科引用的文獻有五處，在《增一阿含經》中。毀謗或讚歎等同於對佛一樣，是想說明損益極其深重。「由」字以下，貫穿解釋嚴重的緣由。在《十輪經》中。

【1319-0002】資持記/15a_下三#8
【原文】準彼乃是七字偈，今鈔第四句下，多數字，恐是後人妄加。彼文但訶破戒，由破戒故，失頭陀行，則彰破戒過重也。初句示過。次句明過重。謂同五逆，佛所不救。下二句引證。不入眾者，即二種僧中。此據犯初篇為言。《華手經》中。言辭讓者，彼云：我見聖王，尚以為難，況復得與分床共坐；
【譯文】依照那部經典原本是七字偈頌，現在《行事鈔》第四句下面多出幾個字，恐怕是後人胡亂添加的。那段文字只是訶斥破戒，由於破戒的緣故，喪失了頭陀行，這就彰顯出破戒的過失極其嚴重。第一句指明過失。第二句說明過失深重，意思是如同五逆罪一樣，連佛都無法救度。下面兩句引用經文證明。「不入眾」，就是指不入於勝義僧和世俗僧兩種僧團之中。這是依據犯下第一篇（波羅夷罪）而言。《華手經》中。說到辭謝退讓，那部經說：我見到轉輪聖王，尚且覺得很難遇到，何況能夠與佛分坐同一個座位；

【1319-0003】資持記/15a_下三#9
【原文】我今得見，親近咨請，已為大利；況乃見命分床共坐，甚為希有；如來深具慈悲喜捨等。《雜含》。緣同，但加易衣稱讚為異。彼明佛在祇桓，諸比丘見迦葉著麁衣來，起於慢心；佛即易衣，以息彼慢。由行苦行，佛尚尊敬，則知功勝矣。《四分》。
【譯文】我如今得以見佛，親近請教，已經是莫大的利益；何況竟然承蒙召喚與佛平分座位而坐，實在是太稀有難得了；如來深具大慈、大悲、大喜、大捨等功德。《雜阿含經》的因緣相同，只是增加了換穿僧衣、予以稱讚這一點不同。那裏說明佛在祇桓精舍時，各位比丘看見大迦葉穿著粗糙破爛的衣服前來，生起了輕慢之心；佛立即與他調換衣服，以平息他們的輕慢。由於修持苦行，連佛尚且予以尊敬，便可知其功德殊勝了。《四分律》中。

【1319-0004】資持記/15a_下三#10
【原文】即〈衣犍度〉文，彼明佛在舍衛，告諸比丘：我欲三月靜坐思惟，無使外人入，唯除一供養人；諸比丘立制，若有入者，作波逸提懺；時長老和先跋闍陀子，與波羅國六十頭陀，不用諸比丘制，俱詣佛所；佛讚善哉善哉！和先，汝等盡是阿蘭若等，得隨意問訊；
【譯文】也就是〈衣犍度〉的經文，那裏說明佛在舍衛國時，告訴諸位比丘：我想三個月靜坐思惟，不要讓外人進來，唯獨留一位送飲食供養的人；各位比丘立下規約，如果有進去的人，就要作波逸提懺悔；當時長老和先跋闍陀之子，與波羅國的六十位頭陀行者，沒有理會比丘們的規約，一同前往佛的住處；佛稱讚說：太好了，太好了！和先，你們全都是住阿蘭若的行者等，可以隨意問訊；

【1319-0005】資持記/15a_下三#11
【原文】諸比丘聞已，多習頭陀行，乃至捨長衣成大𧂐。則知少欲離染，隨順佛語，即為供養佛人。彰利中。論明十二頭陀，各具十利；且引練若一種，以彰多利；故至下文列相，不復引也。初標示。言略說者，明不盡故。言盡形者，明要期故。次列相。初謂身無所屬，二謂無物所繫，三即不為他阻；
【譯文】諸位比丘聽聞之後，大多修習頭陀行，甚至捨棄多餘的長衣堆成了大堆。由此可知，少欲知足、遠離染著、順從佛的教導，就是真正供養佛的人。在彰顯利益（彰利）中，論書說明十二頭陀行各具備十種利益；這裏暫且引用阿蘭若一種，用來彰顯多種利益；所以到了下文羅列行相時，就不再重複引用了。起初進行標示說明。所謂「略說」，是說明無法完全窮盡。「盡形」，是說明終身發願的期限。其次羅列行相：第一是指身體無所拘屬，第二是指沒有物品牽繫，第三就是不受他人阻礙；

【1319-0006】資持記/15a_下三#12
【原文】四中，論云：心轉樂習阿練若住處，謂樂靜之心，轉增勝故；五謂無所營求；六謂空處無畏，以彰本志；七離喧潰；八以獨處閑靜，無所為故；九凡修禪定，必託靜緣故；十無礙想者，謂空三昧，論作無障礙想者。若下，三示緣開。
【譯文】第四項中，論書說：心中愈發喜愛修習阿蘭若住處，意思是喜愛清靜的心念更加增長殊勝；第五是指沒有任何經營求取；第六是指身處空曠無畏懼，以此彰顯本來志向；第七是遠離喧鬧混亂；第八是因為獨處清閒安靜，無事可作；第九是凡修習禪定，必定要依託寂靜的外緣；第十「無礙想」，是指空三昧，論書中寫作「無障礙想」。「若」字以下，第三部分顯示因緣開許。

【1319-0007】資持記/15a_下三#13
【原文】有因緣者，論云：一供給病人，二為病人求醫藥，三為求看病人，四為病人說法，五為餘人說法，六聽法教化，七為供養大德，八為供給聖眾，九為讀誦深經，十教他令讀深經。有通局者，給緣有無也；外道一制無開，故不同之。下指彼品，文見十三十四。料簡中，初示名通濫。
【譯文】所謂「有因緣者」，論書說：一是供養照顧病人，二是為病人求取醫藥，三是為了尋找看照病人的人，四是為病人說法，五是為其他人說法，六是聽聞佛法教化，七是為了供養大德，八是為了供應聖僧大眾，九是為了讀誦甚深經典，十是教導他人讀誦甚深經典。有普遍與局限的分別，是指供應緣由的有無；外道一律制定不得開許，所以與此不同。下面指示該論的品目，經文見於第十三、十四卷。在辨析簡別（料簡）中，首先指出頭陀之名通於喧靜（聚落與空野）以防混濫。

【1319-0008】資持記/15a_下三#14
【原文】籣下，簡行通局。謂二局十通也。喧靜，即目聚蘭。列數，標中。總括十二，不出四位；先出相生，但據總數；後科列行，乃約別數。相生中，初文，先敘生起；故下，後列行相；初中，前明在初之意。資道濟身，衣食皆爾；但食有時限，衣必常須；故云最要，明合居先。若於下，顯須立所以。
【譯文】「籣」字以下，簡別行持的局限與相通。意思是兩種局限、十種相通。「喧靜」，就是指聚落與阿蘭若。在羅列數量（列數）的標題中，總括十二頭陀行，不出四個位次；先說明相互生起的次第，只是依據總數；後面的科判羅列具體行持，則是依據個別的數量。在相互生起（相生）中，第一段文字先敘述生起的緣由；「故」字以下，後面羅列行持相貌；在第一部分中，前面說明排在最初的用意。資助道業、救濟身體，衣服與飲食都是如此；但飲食有時間限制，衣服則是必須常年具備；所以說最為要緊，說明應當排在最前面。「若於」以下，顯明必須建立頭陀行的原因。

【1319-0009】資持記/15a_下三#15
【原文】初敘過非。是下，示教立。少欲知足者，離貪求也。受取有方者，合制法也；制法如下所示。下之三科，一一竝有躡前生起，列相二段，尋文可分。三中。蕩即蕩逸，節謂節行。露坐隨坐，以儀目處，與下異也。四中。前三望坐，坐是正修，故名助緣；若望心觀，坐亦緣耳。
【譯文】首先敘述過失與非理。「是」字以下，指示教法的建立。「少欲知足」，是遠離貪求。「受取有方」，是符合制定的法則；制定的法則如下文所示。下面的三個科判，全都有承接前文生起次第、羅列行相這兩個段落，循著文字便可區分開來。在第三項中，「蕩」就是放蕩放逸，「節」就是節制德行。「露地坐」與「隨處坐」，是以儀表威儀來標示處所，與下文有所不同。在第四項中，前三種相對於端坐而言，端坐是正修，所以前三種稱為助緣；若是相對於心性觀照而言，端坐也只是一種助緣罷了。
