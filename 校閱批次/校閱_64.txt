# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【64-0001】02_戒疏/02d_卷一上之二#6
【原文】【記】問中。《僧祇》五年制婬，自後隨制，顯有不淨之機。而十二年前佛猶說略，即對犯說，故曰「義乖」也。
【譯文】【記文】在發問的文句中。《僧祇律》記載成道五年時開始制定婬戒，從此以後隨事隨犯而制定，這顯示當時就已經有了身心不淨的犯過根機。然而在十二年之前佛依然宣說略教，那就等於是面對犯戒之人說戒了，所以發問說這在「道理上互相違背」。

【64-0002】02_戒疏/02d_卷一上之二#7
【原文】【疏】答：「《律》中所列重犯故耳。自此已前，先作無罪，猶同無事。至於說戒儀軌，前說略已，及至廣制，說不難知。故《增一》云：『因重犯戒，佛止不說，命上座持律能通利者說之。』故毗婆尸佛一百年前說『忍辱偈』，後付僧說；乃至尸棄、釋迦，八十、十二，可以情求。」
【譯文】【疏文】回答：「那是因為《四分律》中所記載的是再次重犯的緣故。在此之前，起初所作的犯戒行為在未制戒前算作無罪，情況還等同於無事的清淨僧。至於說戒的儀軌，先前既然宣說過略戒，等到後來有了廣制，廣說的儀軌也就不難理解了。所以《增一阿含經》說：『因為有僧人再次重犯戒律，佛便停止不再親自說戒，命令通達利落的持律上座去宣說。』因此，毘婆尸佛在成道最初的一百年間宣說『忍辱偈』（略戒），此後才付囑僧眾宣說廣戒；乃至尸棄佛的八十年間、釋迦牟尼佛的十二年間，皆可依此情理推求，這些道理都可以依據情理去推知求索。」

【64-0003】02_戒疏/02d_卷一上之二#8
【原文】【記】答中，初釋相違。「《律》所列」者，指前證文。以目連牽出犯者，因盜金蓮花葉，望檀尼是第二犯，故云「重」也。「此前無罪」，以須提那等皆最初故，則顯如來已前說略，皆非犯者。「同無事」者，略教云「為無事僧」，即清淨僧也。「至」下，詳究說廣。初敘難定。前引諸文，但云十二年後付弟子說，不明爾前說不說故。若據如來，定不說廣；此疑弟子，故須決之。「故」下，引示。《經》明如來因犯不說，始命弟子。可驗爾前，定不說廣。以文非顯，故曰「可以情求」。七佛年次，如前委引。
【譯文】【記文】在回答的文段中，首先解釋表面看似相違之處。所謂「《律》所列」，是指前面引用的經律證文。因為目犍連尊者拉出去的犯戒者，是因為盜取了金蓮花葉，比起最初犯盜戒的檀尼迦是屬於再次重犯，所以稱為「重」。所謂「此前無罪」，是因為須提那等人都是最初首犯，在制戒前不算獲罪，這就顯明如來在十二年之前說略戒時，大眾中並沒有知情故犯的犯戒者。所謂「等同於無事」，略教中說「為無事僧說戒」，「無事」指的就是清淨僧。「至」字以下，是詳細探討宣說廣教的情況。先敘述難以確定的疑點。前面所引用的各文獻，只提到十二年之後付囑弟子宣說，並沒有明確說明在那之前到底有沒有宣說廣戒。如果依如來而言，必定是不親自說廣戒的；但這裡令人懷疑的是弟子們是否宣說，因此必須加以決斷。「故」字以下，引用教典予以指示。《經》中明確記載如來因為僧眾再次重犯而不說戒，才開始命令弟子代宣。由此可以驗證，在那之前弟子必定也不說廣戒。因為文獻記載不夠顯著，所以說「可以依情理推求」。七尊佛各自說戒的年限次第，正如前文已詳細引用過的。

【64-0009】02_戒疏/02d_卷一上之二#14

【64-0010】02_戒疏/02d_卷一上之二#15
【原文】【疏】答：「法利所先，務在通洽。有染聞戒，於道莫行。說必被機，非人不授。故《母論》云：『設僧百千，但一毀戒，則不合說。』明知聖制不欲徒然。」
【譯文】【疏文】回答：「戒法利益的首要之處，務必在於普遍霑溉潤澤。心有染污犯戒者前來聽戒，對於修道並不會真正依教奉行。說戒必須能契合根機，若不是堪受此法之人就不能傳授。所以《毘尼母論》說：『即便有成百上千位僧眾，只要有一個人毀犯了戒律，就不應當宣說。』由此明知聖者的制戒，是不希望讓戒法徒勞無功地宣說的。」

【64-0011】02_戒疏/02d_卷一上之二#16
【原文】【記】問中。初二句示佛說唯須淨，次二句明弟子通淨穢。「目覩」謂肉眼也。「如」下，正難。以序文始末，無非簡淨，欲彰序意，故此問之。答中。初敘教意。教被兩機，故云「通洽」。「洽」，猶徧也。「有」下，明序意。初正示。上二句明簡穢，次二句明取淨。「故」下，引證。初正引。「明」下，顯意。持者於道有進，犯者聞之不行，意令說聽成益，故云「不欲徒然」，則知序文深符佛意矣。
【譯文】【記文】在發問的文句中。前兩句指出佛親自說戒時唯一要求大眾清淨，後兩句說明弟子肉眼所見本來就通含清淨與染污之人。「目覩」指的就是肉眼。「如」字以下，是正式提出問難。因為戒本序文從頭到尾無非都是在簡別清淨，為了彰顯序文的深意，所以在此提出這項問難。在回答中，首先敘述立教的意旨。戒法本要普被染淨兩類根機，所以說「通洽」。「洽」就是普遍的意思。「有」字以下，闡明序文的宗旨。首先是正面的指示。上兩句說明淘汰染污者，下兩句說明選取清淨者。「故」字以下，引用文獻作證。首先是正式引文。「明」字以下，彰顯制戒深意。持戒者聽戒能於道業有所進步，犯戒者聽了卻不會依教奉行，因此制戒的用意是要讓宣說與聽受都能成就實質利益，所以說「不欲徒然」，由此可知序文的意旨是深深契合佛陀心意的。
