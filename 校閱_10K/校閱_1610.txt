# 校閱材料　第1610檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1610-0006】03_業疏/04a_卷一之四#77

【1610-0007】03_業疏/04a_卷一之四#78

【譯文】在其次無戒場界中，這是就說戒與自恣需要界內、界外兩處集會而言，所以說「分別集會」。不允許私自逃避隱匿，這就是所謂的約束。下文所說的四處集會，義理也是相同的。

【1610-0008】03_業疏/04a_卷一之四#79

【譯文】如果這樣，小界沒有界內就像前面所說的那樣，那麼在圍繞人身之界的外圍難道就不需要集會了嗎？回答：原本制定的用意在於簡別隔絕他人，雖然界外有人也不去召集，這不同於大界強制規定界內、界外都必須召集。

【1610-0009】03_業疏/04a_卷一之四#80

【譯文】在解答疑難中，因唯恐有人認為說戒、自恣的小界也可以同類等同看待，所以必須加以簡別。在回答中，規定簡別隔絕他人，是為了遮止他人來訶止羯磨。如果還必須召集外圍之人，那麼開許結小界就無濟於事了；大界並非處於急難之時，所以說體制不同。

【1610-0014】03_業疏/04a_卷一之四#85
【原文】答：行法不同。若作羯磨，則隨界分局，人不相集；若作說恣，則內外通收。以是攝僧綱紀，使內外同崇，不許逃避。乃至外界、戒場見相便求，多有句數，即其事也
【譯文】回答：所施行的律法有所不同。如果是舉行羯磨，就隨各個界限劃分局限，彼此之人互不參與集會；如果是舉行說戒或自恣，則界內界外通通收攝。因為這是統攝僧團的綱紀，旨在使內外界限的僧眾共同尊崇教法，不允許有任何人藉故逃避。乃至於對界外、戒場若見到僧相身影，便須前往尋訪呼喚同集，其中有許多種句數情況，正是指這件事。

【1610-0015】03_業疏/04a_卷一之四#86
【原文】答文今釋中，初句總示。「若下」別釋，即僧私二緣通局兩集。「乃至下」別證通集。本律說戒犍度云：時有一住處，說戒日，客比丘來，見舊比丘在戒塲上，見而不求，便作羯磨。諸比丘白佛，佛言成羯磨，說戒有罪。若見已便求，求已不喚，成羯磨，說戒有罪。若見已求，求已喚，成羯磨，說戒無罪。聞、疑亦如是。又有住處，說戒日，舊比丘見客比丘在戒場上，三句并聞疑三句，竝同上。餘廣如彼，故云有多句數也
【譯文】在回答的疏文今釋中，第一句作總體指示。自「若（作羯磨）」以下，作個別解釋，即僧眾公務（說恣）與私人因緣（羯磨）的通攝與局限這兩類集會。自「乃至」以下，特別引證普遍通收集會之例。本律〈說戒犍度〉記載：當時有一處僧住處，在說戒的日子，客比丘來到，看見舊住比丘在戒場上，客比丘看見卻不去尋訪探問，便直接作羯磨。眾比丘向佛陀稟告，佛陀說：羯磨雖然成就，但說戒犯過有罪。如果看見之後便去尋訪，尋訪之後卻不喚他同來，羯磨成就，說戒有罪。如果看見之後前往尋訪，尋訪之後喚他同來，羯磨成就，說戒無罪。聽聞音聲、心中生疑的情況也是如此。又有一處僧住處，說戒之日，舊住比丘看見客比丘在戒場上，其看見的三句以及聽聞、生疑各三句，都與上述相同。其餘詳情廣如律文所述，所以說具有許多種句數。

【1610-0016】03_業疏/04a_卷一之四#87
【原文】有說云：縱作羯磨，亦須通知。以年歲逾遠，界相莫知，或主客改轉，虗傳制限，故須通集，先委問緣。脫有漠落，徒生疑惑；必本非法，實濫後緣。若經受戒，空傳聖法，喪他一生，自他同陷，深可鏡之。此言易耳，臨時難改
【譯文】有一種說法認為：縱使只是作羯磨，也必須通報告知。因為年代久遠，原本結界的標相已不可知，或者由於舊住僧與客比丘遷替流轉，徒然口耳相傳不實的界限範圍，所以必須全面召集，預先詳細詢問原委。倘若有疏忽遺漏之處，只會徒然產生疑惑；如果當初的結界根本不合法，確實就會延誤敗壞後續的一切如法因緣。如果經歷傳受具足戒，徒然虛傳聖法而實未得戒，將喪送他人一生的法身慧命，自己與他人一同陷入罪過之中，這非常值得引以為鏡戒！這件事說起來雖然容易，但到了臨事之際卻難以臨時補改。

【1610-0017】03_業疏/04a_卷一之四#88
【原文】次古解中，此就私緣，約界不明，可有通集；必無疑濫，則不須之。初敘須集所以。「脫下」彰不問之非。初謂標相不分，「必下次」即本結乖法，於界生疑，不出此二。必有此緣，解已重結，不同今世，無問曾結不結，一概妨疑，請考此文，足知傳謬。濫後緣者，通諸眾法，作竝不成，受法尤重，故別舉耳。「此言易者」，秉結不難故；「臨時難改」，再受非易故
【譯文】在次一段古德解釋中，這是針對單個私人因緣、在結界界相不明確時，才可能進行全面召集；若是必定沒有任何疑惑混濫，則不需要如此。起初敘述必須全面召集的緣由。自「脫（有漠落）」以下，彰顯不預先詢問的過失。前者是指標相不能分清，自「必（本非法）」以下其二是指當初結界時就違背法度，對於界限產生懷疑，不出這兩種情況。若必定存在這種疑緣，應當解界之後重新再結，這不同於當今世人，不論曾經結界還是未曾結界，一概橫加質疑阻礙，請考察這段文義，便足以明白世俗相傳的訛謬。「混濫後緣」是指通於各種僧眾羯磨法，作了都不能成就，其中傳受具足戒之法尤為重大，所以特別舉出來講。「這話說起來容易」，是因為主持結界並不困難；「臨事之際難以補改」，是因為重新受戒並非易事。

【1610-0018】03_業疏/04a_卷一之四#89
【原文】問：大界四集，可如前言；戒場之中，亦有集不？答：場中兩集，亦為說恣，如難緣開之，餘如結界法中說
【譯文】問：大界劃分為四處集會，誠如前面所說；那麼在戒場之中，也有這樣的集會嗎？回答：戒場之中劃為兩處集會，也是為了說戒與自恣，如同遭遇急難因緣時開許的那樣，其餘內容如同結界法中所述。

【1610-0019】03_業疏/04a_卷一之四#90
【原文】次問戒場比前大界，例有四集？答云兩集，即是通局二集。或可字誤，「兩」合作「四
【譯文】其次詢問戒場比照前面的大界，是否照例也有四處集會？回答說「兩集」，即是指通攝與分局這兩種集會。或者可能是文字有誤，「兩」字應當作「四」字。
