# 校閱材料　第713檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】我比丘尼某甲。敬白十方諸佛。證知弟子某甲。不慎威儀。坐起不如法。著衣不齊整。或犯戲笑妄語等。識知是罪。經夜覆藏。得突吉羅罪。不憶數。第二夜已去。乃至多夜。隨展轉覆藏。得突吉羅罪。不憶數。又犯根本。壞非威儀。得突吉羅罪。不憶數。今向十方諸佛。發露懺悔。不敢覆藏。懺悔則安樂。不懺不安樂。憶念犯發露。知而不敢覆。願十方諸佛。憶我清淨。戒身具足。清淨布薩。
【譯文】「弟子比丘尼某甲，恭敬啟白十方諸佛，祈願證明了知弟子某甲，威儀未能審慎，起臥舉止不合戒法，穿衣不端莊齊整，或嬉笑中犯了虛妄言語等。明知是罪而經夜覆藏，得突吉羅罪，次數記不清。第二夜起乃至許多夜，隨著輾轉覆藏，得突吉羅罪，次數記不清。又犯了根本毀壞威儀的過失，得突吉羅罪，次數記不清。如今向十方諸佛發露懺悔，不敢覆藏。懺悔了就能安樂，不懺悔就不得安樂。憶念起所犯即刻發露，自知而不敢隱匿。願十方諸佛憶念我已得清淨，戒體具足，能一同參與清淨的布薩。」

【713-0008】04_比丘尼鈔/06a_卷下之下#58
【原文】第一制看者夫人之形多諸嬰累四大互反六腑難調若不互看命無所寄是故律云汝曹不相看視誰當應為乃至世尊為病人說法洗除大小便已便立制云自今已去應看病比丘應作瞻病人若供養我者應供養病人世尊是極果之人猶親自看病況同法義重如何相棄。
【譯文】第一項制定看病制度：人的肉身有極多重擔牽累，體內四大相互衝突違逆，五臟六腑難以調順。如果僧眾彼此不相互照料，生命將無所依靠。因此戒律中說：你們若不互相看護照料，誰來照應你們呢？乃至世尊親自為患病的僧人說法，為他清洗排泄的大小便，隨後建立戒制說：從今以後，應當照料患病的比丘，應當擔任照護病患的人；如果有想要供養我的人，就應當供養生病之人。世尊是證得極致聖果的人，尚且親自照料病患，何況同處佛門、法義深重的同修，怎能彼此拋棄不顧呢？

【譯文】第二項挑選看病人員：本律說：如果有人患病，應由受戒和尚、阿闍梨，乃至同一個和尚、同一個阿闍梨的同修，或是弟子等人，從關係最親近者到疏遠者依序前來照護。如果這些人都沒有，僧團大眾應當為他指派照護之人；如果被指派者不肯照護，僧團應依序差遣他人；如果依舊抗拒不從，就依照僧法治處。如果連同參道友都沒有，乃至七眾中的優婆夷等女居士也可以前來照護，但不可直接接觸比丘的身體。《僧祇律》說：應當隨病患人數多寡指派相應人員前去，如果不肯照料，全體僧眾都要結罪。如果在路上遇見比丘乃至患病者，應當找來車輛乘具駝運載送回去，如法供養照護；乃至去世的時候，應當為其火化荼毘或殯殮埋葬，不得丟棄不管。下二眾沙彌、沙彌尼患病時也是如此。

【原文】第三供侍者僧祇云若病人衣鉢外有醫藥直者取之供給無者眾僧應與若僧無者彼有貴價衣鉢當貿賤者受持餘者供給若病人惜者應白僧云此病人不知無常慳惜衣鉢不肯貨易白僧已輭語說使得開解然後為貨易若復無者應外求覓與之若僧中取好食與看病人不得愛惜自業而不瞻視五分云無淨人處聽比丘自洗燒器看水令淨人淘米著中比丘然火使熟更從淨人受取持與病人不犯五分云每僧行粥時應問別有病人粥否若無應先與病人然後行與僧十誦云當隨病所須問病因緣覓師求藥日別到僧厨問有病人食否若無取僧所供給庫中物無者當為外求應從善好名聞福德比丘索又病人得藥差者但是僧中不淨殘宿惡捉不受內宿並得服之善生云瞻病人不應生厭若自無物出外求之不得者貸三寶物差已依法十倍償之五百問事云看病人將病人物為病人所須供給不問病者或問起嫌並不得用若已取應償不還者犯重比丘病困不得闕衣鉢而作功德若不即有故弊衣鉢受持者犯墮此律當問病人持何等衣彼病人又受不好衣鉢及送與他恐看病人得佛言不應爾。
