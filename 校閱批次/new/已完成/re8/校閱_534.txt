# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【534-0001】03_業疏/13a_卷三之二#9
【原文】初唯是人簡四趣者：天實報勝，但著樂多，無求修道故也；修羅懷疑，道在會正；非人鬼神，諂誑不實；畜生報局，愚騃所收，道在質直、慧心遐舉，戒受為道，非道故障；地獄常苦，亂惱衝心，故論說言「如鎔鐵聚，何能懷道而受戒也？」唯斯人者，苦輕下趣，樂劣上天，強識念力，能崇道業，如《多論》引歸戒所投，誠有致也
【譯文】第一項「唯獨人道能受戒」而簡別淘汰其餘四道者：天道果報確實殊勝，但貪著享樂太多，沒有修求道業之心；阿修羅心懷猜疑，而道法貴在契會正理；非人、鬼神諂媚誑詐而不真實；畜生果報侷限，為愚蠢癡呆所拘縛，而道法貴在質樸正直、智慧高遠超拔，受戒是為了成道，非道之障礙便阻礙了發心；地獄長受劇苦，擾亂煩惱衝擊其心，所以論中說「如同融化的鐵汁聚結，哪裡能懷抱道心而受戒呢？」只有人道眾生，痛苦比下三道輕微，享樂不及諸天，具有強大的辨識力與意志力（念力），能夠尊崇建立道業，正如《薩婆多論》所引三皈依與戒法所寄託付予之處，確實深具道理。

【534-0002】03_業疏/13a_卷三之二#10
【原文】初人道中：初總標。「天」下別釋，初簡餘趣，列示五道。文標四趣，則合修羅通諸趣故。天著樂者，《多論》云：如目連勸帝釋云「佛世難值，何不數數相近聽受正法？」乃至帝釋云「天上種種宮觀，無數天女，天須陀食，自然百味，百千伎樂，以自娛樂。雖知佛世難遇，正法難聞，以染樂所縛，不得自在」等。阿修羅或翻疑神，疑是信障，故不能入道。「非人」下合明鬼畜，上四句列二趣，下四句明違道。質直反鬼神，慧心反畜類，遐舉謂高遠也。地獄引偈即《智論》也，具云「地獄中陰身，猶如鎔鐵聚，熱惱燒然苦，不可為譬喻」。「唯」下次顯人道，「苦輕下趣」，無常苦也；「樂劣上天」，無勝境也，此二句異於天獄；「強識」異畜生，「念力」異修鬼。下指《多論》，彼云「五道而言，唯人得戒，餘四道不得」是也
【譯文】在第一項「唯人道」中：首先總體標出。自「天」字以下分別解釋，先簡別其餘惡趣，列示五道。文中雖標四趣，是將阿修羅合並通攝於諸趣之故。關於天人貪著享樂，《薩婆多論》記載：如目犍連勸帝釋天說「佛出世極難值遇，為何不常來親近聽受正法？」乃至帝釋回答說「天上有種種宮殿樓觀、無數天女，有甘露天食、自然顯現的百味珍饈，以及成千上萬的伎樂用來自娛。雖然明知佛出世難遇、正法難得聽聞，但被耽染享樂所束縛，不得自在」等。阿修羅有時翻譯為「疑神」，懷疑是正信的障礙，所以無法入道。自「非人」以下合並說明鬼道與畜生道，前四句列出此二趣，後四句說明與道相違。「質直」反於鬼神的諂誑，「慧心」反於畜類的愚鈍，「遐舉」是指高遠。地獄所引用的偈頌即出自《大智度論》，完整文句為「地獄中陰身，猶如鎔鐵聚，熱惱燒然苦，不可為譬喻」。自「唯」字以下進一步顯明人道：「苦輕下趣」，是指沒有惡道恆常的劇苦；「樂劣上天」，是指沒有天界耽溺的勝境，這兩句說明人道不同於天道與地獄；「強識」不同於畜生，「念力」不同於修羅與鬼神。以下指引《薩婆多論》，該論說「就五道而言，唯獨人道得受戒，其餘四道都不得受」，正是此意。

【534-0007】資持記/15c_下三#47
【原文】雖可罔於無知，實取笑於有識。亦下，次開不起。縱是尊長，非所宜故。若下，三明留位。此謂知彼有緣而未至者。五中，《僧祇》，初上座訶止。聖毘尼，即佛戒；以眾學制，入白衣舍，不得戲笑，須靜默故。齗，語斤反，齒根肉也。無常等，即四念處；死想等，即九想。由下，次教餘人自制。
【譯文】這雖然可以暫時欺瞞矇騙那些無知愚民，但實際上只會讓真正有見識的明眼人笑掉大牙罷了。自「亦」以下，接著開許可以不必起立迎接的情況。縱使來者是尊長長老，在用齋這種場合隨意起立迎接也絕非合宜的舉動。自「若」以下，第三是說明可以為他人保留席位的情況。這是指明知對方遇到了正當的法務因緣而暫時尚未趕到的特殊狀況。第五段中引用《僧祇律》，首先說明首座上座應當出聲呵斥制止喧嘩。所謂「聖毘尼」，就是指佛陀的無上戒律；因為眾學戒中制有此條，進入白衣居士家中，絕對不得嬉笑打鬧，必須保持寂靜肅穆的威儀。所謂「齗」，讀音為「語斤反」，是指牙齒根部的牙肉。所謂「無常等」，就是指觀身不淨、觀受是苦、觀心無常、觀法無我的四念處修法；所謂「死想等」，就是指膨脹、青瘀、壞爛等九種不淨觀想。自「由」以下，接著教導其餘清眾應當如何自我節制收攝。

【譯文】在第四項中：首先引牒解釋「形同」，是指斷除世俗因緣的外相。自「下列」等句，是解釋簡別非道之相。世俗之人講究服飾莊嚴，是執著於「有」的極端；外道赤身裸體，是執著於「無」的極端；這也稱為斷、常二邊。《大智度論》說：佛陀聖弟子安住於中道，所以身著三衣。自「今」字以下決斷當時代之所用。首先說明三衣相同於原本規制，是指與天竺梵本無異。自「自」字以下指明其餘附屬衣物：「正背」在《行事鈔》中稱為「褡膊」；「方裙」類似今日的圍裙；「倚支（裿支）」是搭在左肩上、繫於右腋下，用來掩映袈裟的內衣，名稱雖出自本律，只是後世縫製方法違背了律法。這些衣物雖然不合經律古制，然而其形制顏色依然存有修道之相，可以隨順律文。正如律中所說「從今以後，凡一切世俗人與外道的服裝，一概不得穿著」即是此意。
