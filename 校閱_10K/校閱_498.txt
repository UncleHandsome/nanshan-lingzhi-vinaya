# 校閱材料　第498檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【498-0001】02_戒疏/07b_卷二上之三#96
【原文】【記】顯意中。初句徵問。「欲」下，引釋。初約誡後釋。「弊」，惡也。皆有此惡，故云「同弊」。「輕仁」，謂無濟惠之心。「薄義」，謂非義而取。「懲」，音澄，誡也。
【譯文】【記文】在顯發立意這一科判中。第一句提出徵問。「欲明」以下，引申解釋。先就告誡後人來解釋。「弊」就是惡劣。世俗佛門都有這等惡行，所以說「同弊」。「輕仁」是指毫無救濟周濟他人的仁愛之心。「薄義」是指以不合道義的手段強取。「懲」的讀音是「澄」，意思是警戒懲戒。

【498-0002】02_戒疏/07b_卷二上之三#97
【原文】【疏】又人解云：「初篇四夷，餘三自犯，無多過失。顯盜是公白，尚盜王材，況餘凡庶，而得免者？故舉貴類賤，舉難況易，意可見也。」
【譯文】【疏文】：又有人解釋說：「戒律第一篇的四條根本重罪中，其餘三條都是自己暗中違犯，在世俗看來沒有引發太大的擾動過失。而列舉這條是為了突顯盜竊是在光天化日之下公然損害他人，連國王的資財都敢偷盜，更何況一般平民百姓，又怎麼可能倖免呢？因此列出尊貴的國王來比類卑微的小民，列出難以下手的國王資財來比況容易盜取的庶民財物，佛陀的深意由此便可以看出了。」

【498-0003】02_戒疏/07b_卷二上之三#98
【原文】【記】次科，約彰過釋。「貴」則無過國王，「難」則無過王物，故舉其極，以況其餘。
【譯文】【記文】在第二小科中，是就彰顯罪過的角度來解釋。「尊貴」莫過於國王，「難以盜取」莫過於王家財物，所以舉出極端的例子，以此比況其餘尋常事物。

【498-0004】02_戒疏/07b_卷二上之三#99
【原文】【疏】捉殺四相，輕重文亂。若欲糾正，應言捉、縛、驅、殺也。
【譯文】【疏文】：捉拿、處死這四種處罰相，律文中的輕重順序有所錯亂。如果要糾正順序，理應當說是：捉拿、綑綁、驅逐、處死。

【498-0005】02_戒疏/07b_卷二上之三#100
【原文】【記】牒釋中，初科。以殺第二，治法不次，義須後列。「糾」，定也。
【譯文】【記文】在逐句解釋中，這是第一小科。因為處死排在第二位，處罰的先後次序並不合理，在法理上必須排在最後。「糾」是定奪校正的意思。

【498-0006】02_戒疏/07b_卷二上之三#101
【原文】【疏】所言「捉」者，《僧祇》云：「瓶沙王遠祖治賊，但令栴陀羅拍頭捉手，便自愧恥，永不行盜。」所言「縛」者，世濁情澆，雖捉猶作，乃於多人之處，祖王使人以灰圍之。及至父時，止故灰圍，行「驅出」法。至瓶沙登位，七反驅出，還入為盜。乃截一指，愁悔無極。佛為王說過去為養千愚事。至阿闍世，乃行殺戮也。
【譯文】【疏文】：所說的「捉拿」，《僧祇律》記載：「頻婆娑羅王的遠祖治理處罰盜賊時，只要命令旃陀羅（下賤階級的行刑者）拍拍盜賊的頭、捉捉他的手，盜賊便深感慚愧羞恥，永遠不再行盜。」所說的「綑綁」，是因為後來世風日下、人情澆薄，盜賊即便被捉拿訓誡依然照常作案，於是祖王便在聚集眾人的處所，派人撒石灰畫圈將盜賊圍在中間。等到其父王即位時，停止了撒石灰圍困的作法，改為施行「驅逐出國境」的刑罰。等到頻婆娑羅王登基時，曾將一個盜賊七次驅逐出境，那盜賊卻一再折返回來偷盜作亂。國王於是下令斬斷他的一根手指，事後國王憂愁悔恨到了極點。佛陀為國王講述了他過去世曾收養一千個愚人的因緣故事。到了阿闍世王的時候，世風更壞，就真正開始施行殺戮死刑了。

【498-0007】02_戒疏/07b_卷二上之三#102
【原文】【記】釋四相中，並引《僧祇》文。「旃陀羅」，此翻殺者。「澆」，薄也。「灰圍」，即同「縛」也。「及」下，釋第三。「驅出」，似今之配流。「至」下，釋第四。「七反」者，彼云：「時有一賊，七反驅出，還來劫殺村城。爾時有人，捉縛與王，乞令苦治，王令將截去小指。王尋生悔念言：『夫為王者，愛念民物。何有人王，傷截人指？』即往問佛。佛言：『過去世時，有城名波羅奈，國名迦尸，王號名稱。國民皆工巧伎，以自生活。若無伎術，及作賊者，皆付名愚癡。時有作賊，送至王所。王言：「始有一愚，若滿千數，用作大會，方苦治之。」勅付大臣，令著無憂國，與五欲樂。後愚聞王賜樂，不久滿千。臣即白王。王乃與食施寶。勅愚人言：「汝等還家，供養父母，勤修家業，勿復作賊。」爾時愚人，聞勅奉行。王即以位授太子，入山學仙人法。而說偈言：「本求千愚人，作會謂難得。如何未幾時，千數忽已滿。惡法日夜增，大會於是止。欲離世惡人，宜時當出家。」』佛言：『諸比丘，爾時國王，即瓶沙是。先世已來常畏罪報。今既為王，續亦畏罪，故生疑問佛也。』」準有五法。今既「截指」，合歸後「殺」。
【譯文】【記文】在解釋四種處罰相時，全部引用《僧祇律》的文字。「旃陀羅」在漢語中翻譯為殺者或屠夫。「澆」是指輕薄浮薄。「石灰圍繞」在意義上就等同於「綑綁拘禁」。「及」以下，解釋第三種處罰。「驅逐出境」類似現今的流放配軍。「至」以下，解釋第四種處罰。「七次驅逐」的典故，彼律記載：「當時有一個盜賊，被驅逐出境七次，每次都折返回來劫掠殺戮村莊城鎮。當時有人捉拿並綁縛了盜賊押送給國王，請求嚴厲處罰，國王下令將盜賊的小指斬斷。國王隨後心生悔意想道：『作為君王，理應當愛護眷顧天下百姓與萬物。哪有為人君王，卻傷害殘斷他人手指的？』於是親自前往向佛陀請教。佛陀說：『在過去久遠世時，有一座城池名叫波羅奈，國家名叫迦尸，國王稱號叫作名稱王。國民都憑藉精巧的技藝工藝來謀生自活。如果沒有謀生技能、或是去當盜賊的人，統統歸入愚癡之人名冊。當時有人作賊被捕，押送到國王處。國王說：「現在才抓到一個愚人，如果湊滿一千個人，我要設一場盛大聚會，再來嚴厲懲處他們。」於是下令交給大臣，將這盜賊安置在無憂國中，供給五欲娛樂。後來的愚人聽說國王賜予享樂，不久人數就滿了一千。大臣隨即稟報國王。國王便賜給他們飲食並施贈珍寶。隨後訓誡這批愚人說：「你們各自回家，奉養孝順父母，勤奮經營家業，萬萬不可再做盜賊了。」當時那些愚人聽從訓誡依教奉行。國王隨後把王位傳給太子，自己入深山修學仙人修道之法。並且說了一首偈頌道：「原本想搜集一千個愚人，設大會時還以為難以湊齊。怎麼沒過多久，千人之數忽然就已經滿了。世間的惡法日夜都在增長，這懲處大會自此應當終止。若想要遠離世間的惡人，正應當在此時剃度出家。」』佛陀說：『諸位比丘，當時的那位國王，就是現在的頻婆娑羅王。從過去世以來就常常畏懼造罪的惡報。如今既然身為一國之君，自然繼續畏懼罪報，所以才心生疑悔前來問佛。』」按照這個脈絡本有五種處罰方法。現在既然出現了「截斷手指」，在性質上應當歸入最後一項「處死」這類重刑中。

【498-0008】02_戒疏/07b_卷二上之三#103
【原文】【疏】問：「如戒緣中，若盜五錢，罪應死者，云何乃指其後殺邪？」
【譯文】【疏文】：發問：「如果按照這條戒律的緣起，若是盜取滿五個錢，罪責應當判處死刑，為什麼這裡卻偏偏指稱是排在最後的處死呢？」

【498-0009】02_戒疏/07b_卷二上之三#104
【原文】【疏】答：「滿五合死，古法常然。王欲輕刑，減死從𢷤。如今此國，竊滿絞刑，政緩刑寬，減從加伇也。」
【譯文】【疏文】回答：「盜竊滿五錢應當處死，這是自古以來的通例常法。國王如果想要減輕刑罰，可以把死刑減等，改為驅逐流放。好比現今這個國家，行竊滿一定數額原本要判處絞刑，若遇政風寬緩、法網開恩，也可以減刑改為加役流放。」

【498-0010】02_戒疏/07b_卷二上之三#105
【原文】【記】問中。意謂既有四治，不合戒緣獨指後一。答中。初二句釋戒緣明死。「王」下，示文列四治。
【譯文】【記文】在發問之中。意思是既然有四種處罰層級，不應當在戒律的發起因緣中單單只指稱最後一種死刑。在回答之中。前兩句解釋戒律緣起中說明死罪的原因。「國王」以下，明示律文之所以並列四種處罰的原因。

【498-0011】02_戒疏/07b_卷二上之三#106
【原文】【疏】餘三罵辭，及後結罪，文相易解。
【譯文】【疏文】：其餘三句呵罵斥責的言辭，以及後面結斷罪名的文句，文意很明白，容易理解。

【譯文】【記文】在指點其餘文句的一科中。第一句指稱當前的責罵之語。「及」以下，指稱其後結斷罪名等兩句。
