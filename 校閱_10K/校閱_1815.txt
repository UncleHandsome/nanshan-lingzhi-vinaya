# 校閱材料　第1815檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1815-0001】03_業疏/17a_卷三之六#37
【原文】就餘三戒，十中前四俱善戒也，後六善而非戒。如上《四分》、《善生經》說，四人所受通七支也。
【譯文】就其餘三種戒（五戒、八戒、十戒）而言，十業中的前四種都兼具善與戒，後六種是善而不是戒。如果按照上面《四分律》及《善生經》所說，四類受戒之人所受之戒都是通於身口七支的。

【1815-0002】03_業疏/17a_卷三之六#38
【原文】次科，初依多宗，餘三即五、八、十，前四並通戒善，後六三戒不制，故云「非戒」。「如」下次示今宗，四人即婆塞、淨行、沙彌、大僧，所對四戒通制七支。
【譯文】在第二科中，開頭先依據薩婆多部宗義，其餘三種戒就是五戒、八戒、十戒，前四種都通於戒與善，後六種在此三戒中不予制定，所以說「非戒」。自「如」以下其次指示今宗（四分律宗）的主張，四類人就是優婆塞、受八戒的淨行人、沙彌、大僧（比丘），所對應的四種戒法都是通通制定身口七支的。

【1815-0003】03_業疏/17a_卷三之六#39
【原文】若據菩薩，十善俱戒。如下《四分》，心念故犯，亦同相也。
【譯文】如果依據菩薩戒，十善業全都是戒。正如本篇後面所引《四分律》中，心生念頭故意觸犯也同樣結犯，也是同一種行相。

【1815-0004】03_業疏/17a_卷三之六#40
【原文】三中，初對菩薩戒。由制單意，故通後三，俱是戒攝。「如下」，次對本律。言如下者，即諸犍度，律制發心作、心念作並吉；又一切時中，常爾一心，違皆結犯。此宗制教，義同菩薩，但瞥爾、重緣以分大小耳。
【譯文】在第三段中，開頭先對比菩薩戒。由於菩薩戒制止單純的起心動念，所以通於後三種意業，全都在戒法所攝之列。自「如下」以下，其次對比本律（《四分律》）。所說「如下」，就是各個犍度，律中規定「發心作」、「心念作」都結為突吉羅罪；又要求在一切時中，常常保持一心專注，若有違背都結罪犯戒。本宗的制教，在法義上與菩薩戒相同，只是以「微細瞥爾生心」與「重念相續緣境」來區分大乘與小乘而已。

【1815-0005】03_業疏/17a_卷三之六#41
【原文】第三隨相，分文為三：初、四重者，止持行相；二、授四依，作持行相；三、「汝已受」下，總結前二，勸以學方。
【譯文】第三、隨順戒相，將此處受相之文分為三部分：第一、宣說四波羅夷重戒，這是止持的行相；第二、傳授四依法，這是作持的行相；第三、自「汝已受」以下，總結前面兩部分，勉勵其修學的方法。

【1815-0006】03_業疏/17a_卷三之六#42
【原文】就初止持前緣中，由不即說，羯磨通昧，謂犯非過；須前即示，恐進無緣。故略明四重，聖行根源；餘所未知，律制修學。如《十誦》中，乃至十三殘法。
【譯文】在第一部分止持受戒後的說相因緣中，由於受戒時若不隨即宣說，羯磨文詞概括深隱，受戒者會以為觸犯並非過失；必須在受戒之後立即宣示，恐怕他再往前造次就斷絕了戒法因緣。所以簡略明示四波羅夷重戒，作為聖道修行的根源；其餘尚未通達知曉的戒法，律中規定應當精勤修學。正如《十誦律》中，說相甚至宣說到十三僧殘之法。

【1815-0007】03_業疏/17a_卷三之六#43
【原文】第三戒相止持中，初文初敘不說之損。羯磨詞中，但標受具，故云「通昧」。「須下」，次明即說之益。恐進無緣，謂後受成障。本宗四重，由是行根；《十誦》兩篇，葢取戒分。
【譯文】在第三科戒相止持之中，第一段文字開頭先敘述不及時宣說的損害。羯磨文詞中，只標明受具足戒，所以說「通昧」。自「須」以下，其次說明隨即宣說的益處。「恐進無緣」，是指受戒之後若犯重戒就會成為進修道業的障礙。本宗只宣說四重戒，是因為這是修行的根本；《十誦律》宣說波羅夷與僧殘這前兩篇，大概是為了選取主要的戒法部分。

【1815-0008】03_業疏/17a_卷三之六#44
【原文】四重初篇，如《戒本疏》，今略消文。
【譯文】四波羅夷重戒這第一篇，詳見《戒本疏》，現在只是簡略消釋文義。

【1815-0009】03_業疏/17a_卷三之六#45
【原文】次分釋中，初科上二句指廣，「今下」標分。
【譯文】在隨後的分別解釋中，第一科前兩句指引廣說所在，自「今」以下標示本處科分。

【1815-0010】03_業疏/17a_卷三之六#46
【原文】就分為二：初標舉總相，後隨四問結之。就前「善男子聽」者，誡其身心也。且舉三號說四重者，明人尊教切，不得輕陵隨也。「犯非沙門釋子」者，簡絕門人，不在我族也。尼受相中云「族姓女」，大同此也。
【譯文】就科分而言分為兩部分：開頭先標明列舉總相，其後隨著四個問答來作結尾。就前面「善男子聽」這句話而言，是告誡其身心要專注端正。暫且舉出佛的三種尊號來宣說四重戒，是表明說法人尊貴、所說教法懇切嚴厲，不得輕蔑毀犯、隨順放逸。「犯非沙門釋子」，是除名斷絕為門徒弟子，不再屬於佛門家族之列。在比丘尼受相戒文中稱作「族姓女」，與此大體相同。

【1815-0011】03_業疏/17a_卷三之六#47
【原文】總相中，初科四節。耳聽心思，故誡身心。三號：一、如來，二、至真，三、等正覺。簡絕門人對「非沙門」，不在我族對「非釋子」，以稱釋子同佛族故。引尼說相，預點後文同此釋故。
【譯文】在總相中，第一科分為四個節段。耳朵聽受、心思專注，所以告誡其身心。三號是：第一、如來，第二、至真（應供），第三、等正覺。除名斷絕門人是對應「非沙門」，不再屬於我佛種族是對應「非釋子」，因為稱為釋子即等同於佛陀家族的緣故。引用比丘尼的說相戒文，是預先點明後面的文字與此處解釋相同。

【1815-0012】03_業疏/17a_卷三之六#48
【原文】沙門者，舊翻為桑門，音之互也。《涅槃》云「沙門那」者，是本音也。或云「乏道」、「貧道」以譯之，皆謙虗自收，不伐德也。今譯為「息惡」者，取其意也。元拔俗來入非家者，決誓斷惡，息本習也。
【譯文】「沙門」，舊時翻譯為桑門，是梵音的互傳差異。《涅槃經》中稱作「沙門那」，才是原本的梵音。有的人用「乏道」、「貧道」來翻譯它，都是謙虛收斂自己、不自我誇耀德行之意。現在翻譯為「息惡」，是選取了它的義理。原本脫離世俗、進入非家修道之人，是決心誓願斷除惡行、止息原有的習氣。

【1815-0013】03_業疏/17a_卷三之六#49
【原文】別釋初文，初示梵言。二皆訛略，《涅槃》為正。「或下」，明翻譯。謂貧乏道德，故云「謙虗」等。收，謂收斂。自稱所能，謂之「伐德」。若準《涅槃》釋義則別，彼云「沙門名乏，那名道，斷一切乏，斷一切道，以是義故，名沙門那」。上依古翻。「今下」，次引今譯。「元拔俗」者，謂離父母之家；「入非家」者，即造空寂之道。
【譯文】在分別解釋的第一段文字中，開頭先示明梵語原詞。沙門、桑門二者都是訛誤或省略，《涅槃經》的稱法才是正確的音。自「或」以下說明漢語翻譯。意思是自己缺乏道德，所以說「謙虛」等。「收」，就是收斂。自稱自己有某種能力，稱為「伐德（自誇功德）」。如果依照《涅槃經》的解釋，法義則有所不同，那裡說：「沙門名叫作乏，那名叫作道，斷除一切匱乏，斷除一切邪道，以這個義理的緣故，稱作沙門那。」以上是依從古代的舊譯。自「今」以下其次引述新譯。「元拔俗」，是指離開父母生養的世俗之家；「入非家」，就是趨向空寂解脫之道。

【1815-0014】03_業疏/17a_卷三之六#50
【原文】釋子者，如《阿含》中及律八喻：四河入海，無復餘名；四姓出家，同稱釋種。如律複召云「釋迦子」者是也，上單召之，故云「釋」也。中梵如此，唐言譯之為「能仁」也。以四子被斥於雪山南，人民歸之，奄成大國，父後得聞，便曰：「吾子仁育，故有多能。」因從姓也。廣如僧祐《釋氏譜》十卷明之。所言「子」者，男子之通稱，即有孳育之緣，謂紹先聖之後也。餘者何由說盡，且削也。
【譯文】「釋子」，正如《阿含經》中以及律藏的八種比喻所說：四條河流匯入大海，就不再保有原來的名字；四個種姓的人出家，通通稱為釋迦種姓。正如律中具足稱呼時叫作「釋迦子」，上面只是單字稱呼，所以稱作「釋」。在中印度梵語是這樣，漢語翻譯為「能仁」。因為當初四位王子被驅逐流放到雪山以南，人民前來歸附，迅速形成一個強大的國家，父親後來聽說此事，便說：「我的兒子仁厚撫育人民，所以具有許多才能。」因此就以「釋迦」為姓氏。詳細情況正如僧祐律師所撰《釋氏譜》十卷中所明示。所說的「子」，是男子的通稱，即具有生養培育的因緣，意指繼承先聖的道統之後。其餘的因緣哪裡能在此說盡，暫且予以省略。
