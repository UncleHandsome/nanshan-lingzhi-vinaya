# 校閱材料　第153檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【153-0001】資持記/13d_下一#17
【原文】第三加保任處，謂比丘為彼保掌出息也。四加質物處，謂以財物在異處質與人也。五加執券書者，即為財主掌計簿籍也。次科，初句指破。若下，次顯理非。如下，三明別斷，上明入僧。若負下，次明在俗，前約直取。若下，後斷互爭。《十誦》五中，準後三斷。
【譯文】第三句增加了擔任保證人的處所，也就是指比丘為他擔保掌管放貸取息之處。第四句增加了抵押物品的處所，也就是指以財物在別處向人抵押之地。第五句增加了執掌借據券書者，也就是為財主掌管帳簿戶籍之人。下一科，第一句指出並破斥其非。從「若」字往下，接著顯明其在理法上的不合。從「如」字往下，第三項闡明個別的裁斷，前文闡明財物歸入僧團。從「若負」往下，接著闡明在俗人處，先前是就直接索取而言。從「若」字往下，最後裁決彼此互爭。《十誦律》的五種情況中，可比照後三種判定。

【153-0002】資持記/13d_下一#18
【原文】人處二寄，即分法中寄人不寄處，寄處不寄人，二斷也。《母論》：生息在外，即俗人處。《五百問》。借人物者，謂以物借他。言得罪者，彼云：一切不得自取犯吉。白眾，眾還得取，眾不還犯吉〔結僧罪也〕。若眾不與，強取犯墮。故云自他俱犯也。《僧祇》索債，謂有比丘死，餘人來索；事客同濫，故制觀量。
【譯文】「寄人」與「寄處」兩者，就是分配法中所說的「寄放於人而不限處所」、「寄放於處所而不限特定之人」這兩種判別。《毘尼母論》說：在外面放貸生息，指的就是在俗人處。《五百問論》中，所說借用他人財物，指的是將物品借給別人。所說「得罪」者，該論說：一概不得自行擅取，否則犯突吉羅罪。應當秉白大眾，大眾答應歸還方可取得，大眾不歸還若擅取則犯突吉羅〔這是結犯僧團之罪〕。若大眾不給與而強行索取，則犯波逸提罪。所以說「自他雙方皆獲罪犯」。《僧祇律》索討債務，指的是有比丘去世，其餘的人前來索債；事情與外來客僧交涉容易產生混亂，所以制定應當審慎衡量。

【153-0003】資持記/13d_下一#19
【原文】定輕重中，初科為二，初正判；不下，遮非。初中，前明據體。受隨相應故。後約隨處。現僧同見故。遮非中，初遮其妄情。實下，示其濫用。如下所引，《四分》衣鉢等外，多判入重；《十誦》餘物多是歸輕。今欲多得衣分，乃背受隨，輒用《十誦》。
【譯文】在「定輕重」中，第一科分為兩部分，首先是正面判定；從「不」字往下，遮止非理的偏執。在第一部分中，前面闡明根據受戒戒體。這是因為受戒之體與隨順戒行必須相應的緣故。後文就「隨處」而言，是因為現前僧眾皆持同一部派見解的緣故。在遮止非理中，首先遮止其妄生私情。從「實」字往下，指出濫用律法的弊端。正如後面所引述，《四分律》除了衣缽等隨身物之外，大多判定歸入重物；《十誦律》其餘物資大多歸入輕物。現在有些人想要多分配衣物，竟然違背自身的受隨戒律，擅自套用《十誦律》。

【153-0004】資持記/13d_下一#20
【原文】由貪等者，推過歸心，以判重為輕，皆犯夷重。《輕重儀》云：然以人情忌狹，擁結非無；知事則親常住，引輕入重；別僧則私自利，引重從輕是也。次科。豫合作預。總撮六見，不出三階。別釋中，第一師，初科。十三章者，一是僧伽藍；二屬僧伽藍園田果樹；三多有別房；
【譯文】所謂「由於貪求等」，是將過失推究歸於內心，若私自將重物判定為輕物，皆構成波羅夷重罪。《輕重儀》說：然而由於世人情執狹隘忌刻，阻礙結怨並非沒有；擔任知事者便偏袒常住，把輕物牽引歸入重物；個別僧人則圖謀私利，把重物牽引依從輕物，指的就是這種情況。下一科。「豫」字應當作「預」。總結歸納六家之見解，都不出這三個層次階梯。在「分別解釋」中，第一位律師，第一科。「十三章」指的是：第一是僧伽藍寺院建築；第二是附屬於僧伽藍的園田果樹；第三是僧團所擁有的許多個別房舍；

【153-0005】資持記/13d_下一#21
【原文】四屬別房物；五瓶盆斧鑿燈臺；六多諸重物〔即成衣眾具等，如文所列。〕；七繩床木床臥具坐褥；八伊梨延陀〔此鹿王名謂鹿皮類〕，耄羅、耄耄羅〔此二皆獸名，儀云：狀如虎兕豹獏之類，皮厚毛軟可坐。〕；九守伽藍人；十車輿；十一水瓶澡鑵錫杖扇；十二諸雜作器〔竹木等作具〕；十三衣鉢等，如文所引。
【譯文】第四是附屬於個別房舍的物資；第五是瓶、盆、斧、鑿、燈台；第六是諸多重物〔也就是做衣服的各類器具，如律文所列。〕；第七是繩床、木床、被褥臥具、坐墊坐褥；第八是伊梨延陀皮〔這是鹿王的名稱，指各類鹿皮〕，以及耄羅、耄耄羅〔這兩種都是獸名，《輕重儀》說：形狀像虎、犀牛、豹、貘之類，皮厚毛軟可以坐臥。〕；第九是看守僧伽藍的人僕；第十是車輛車乘；第十一是水瓶、洗滌罐、錫杖、扇子；第十二是各類工巧作具〔竹木等製作工具〕；第十三是衣缽等隨身物，如文中所引述。

【153-0006】資持記/13d_下一#22
【原文】律斷前十二皆重，後一屬輕，故云唯有重輕二別也。次科，初明輕物。即第十三一章門也。俱夜羅，儀云：此翻隨鉢器。餘下，次明重物。即總前十二門也。若下，別簡衣服。結中。此一家者，即指上判。無與二者，謂與今同也。但彼不用外宗，未為盡善；
【譯文】律法判定前十二項全都屬於重物，最後一項屬於輕物，所以說「唯有重物與輕物兩類差別」。下一科，首先闡明輕物，指的就是第十三這一個章門。「俱夜羅」，《輕重儀》說：此處翻譯為「隨缽器具」。從「餘」字往下，接著闡明重物，也就是總括前面的十二門。從「若」字往下，個別簡擇辨別衣服。在結語中，「這一家」指的就是上面的判定。「沒有能與之相左者」，意思是與如今的看法相同。只是那位法師不採用其餘外宗各部，尚未算得上盡善盡美；

【153-0007】資持記/13d_下一#23
【原文】不可抑之為非，奪之不存，故云也。次師，初科，三義。據體立宗，故《四分》先準。本宗既闕，取外相成，故取諸部。本異俱無，仍加義決。下之二種，對上本宗，故云旁出；旁即兼也。略分中，三科各出所以。前二輕重各定，諸部皆同；後一反之，故須列判。
【譯文】但也不能直接貶抑它為不對、抹煞它使其不存，所以有這樣的說法。第二位律師，第一科，包含三種理義。根據根本體制確立宗旨，所以《四分律》排在最前作為準則。本宗律文既然有所欠缺，便吸取其餘部派相輔相成，所以引取各部律。本宗與異部都闕漏不載者，便進一步加諸義理以作決斷。後面的兩種方式，相對於前面的本宗，所以稱為「旁出」；「旁」就是兼具取用的意思。在「粗略分別」中，三科各自指明其原因。前兩項輕重已經各自確定，各部派全都相同；最後一項則相反，所以必須列出判定。

【153-0008】資持記/13d_下一#24
【原文】簡去異說，故云鈔者一意。三位。性重，謂金石等物。性輕謂布帛等。從用二句，應具四句，俱重俱輕，舉事配之可解。事重，事即物體。用輕謂資身助道，用重謂恣情廢業。廣分中，初科，上二句示引用。然下，明科判。注中，取例。《十誦》器物，不從體判，但隨事用以分重輕。
【譯文】為了排除各種異說，所以說是「《鈔》之作者的一家之意」。分為三個等級。自性為重，指的是金石等金屬礦物。自性為輕，指的是布帛絲綢等。從用途而分的兩句，應當具足四句，體用俱重、體用俱輕，列舉事相加以配對即可明瞭。物事本身之重，「事」指的就是物品本體。用途之輕指的是滋養色身以助益辦道，用途之重指的是放縱情欲而荒廢道業。在「廣泛分別」中，第一科，上兩句指示引用的依據。從「然」字往下，闡明科判的分別。註解中，取引同類例子。《十誦律》對於器物，不依物質本身判定，只是隨著事相用途來劃分重物與輕物。

【153-0009】資持記/13d_下一#25
【原文】今此諸門，準彼為例；亦隨事判，故云附事廣明也。次科。《十誦》，明持物入眾。《母論》明遣差五德。彼廣示分法，故指云云。下釋重名，義含體用。輕物名義，可以準知。正判中。絲麻毛綿，從體標名，四種攝盡一切衣物，即十三章中十三第八二章也。古來科節連環合雜，物類不分，重輕混亂。

【譯文】比照「非時施」的戒規，原本也是直接分發；後來因為外來客僧接二連三地前來領取，導致負責分衣的僧人疲憊不堪，佛陀才指示應當推派一人專門負責分配。現在是因為當下人數不足，所以依照論典直接均分；假若事後又有僧人到來，比照那個例子便必須變更法式。在「有下」的部分，引出依據以證明成立。面對面作法（對首法）包含兩種情況，首先是三人法。彼此互相對答言說，所以稱為展轉。在場另外二人作口頭和合時，只須刪除「諸」這個字。接著是二人法。經文並未明列具體詞句，應當說：「大德！這位亡故比丘的衣缽（乃至坐具等物品），致贈給大德以作為看護病人的犒勞。」

【原文】指分法如上，但除上二字。《四分》下，會同本律。但出對首之法，不論賞勞，故云直明等。文如論者，即同上引。心念中，初示緣。此下，出法。即須口陳，非謂默然。作下，明重分須不。若三說已，決作己想，或手執捉，即為入己，如注所顯。若不爾者，有來須分。《四分》下，引類。
【譯文】至於分衣的法式則如同前述，僅須刪去前述的兩個字。在「四分下」的部分，將義理會通於本門《四分律》。此處僅僅列出面對面作法的程序，並未論及犒賞看護的環節，因此才說是直接說明等等。其文字表述如同論典所載，即與前文所引用的完全相同。在僅憑心念作法的章節中，首先標明適用的特殊因緣。在「此下」的部分，出示具體的作法。這時必須親口念出聲來，並不是在心中默默無聲。在「作下」的部分，說明事後究竟需不需要重新分配。如果三次口述完畢，已明確生起屬於自己的念頭，或者已經用手實際拿取，這件物品就算是歸入自己名下，就如注文中所闡明的那樣。如果不符合這些條件，一旦有其他僧人到來，就必須重新分配。《四分下》的部分，引用類似的戒規條文。

【原文】十中，初科，前明有守掌又二，初明有住處。若亡下，次明無住處。家人即俗侍者。不得尼者，顯是僧物故。不與近寺者，明有本處故。注云僧法，即眾行羯磨。若無下，後明無守掌。白衣家中，初文可解。次科，前明本眾各取。不同得施二部共分。當下，次明當部不行羯磨。

【原文】準似界外受之，但犯越者，即成分衣，但乖法故。注引《四分》例決不成，即盜僧物。若下，次明羯磨限約。在前入界，作法重分；已後入者，不須與分。下引律證。可知。釋疑中，初問。以物屬當界，不合出外；教文互見，故問通之。答中，初正答。
【譯文】依照標準這類似在界外私自領受，雖然只結犯突吉羅（輕微過失）罪，分衣的效力依然算成立，但行為本身已違背正法。注文中引用《四分律》同類的條文斷定此舉不能成立，否則即等同於盜取僧物。在「若下」的部分，接著說明羯磨法所設定的時間界限。在作法之前就已進入結界者，必須重新作法為其分配；如果是在法式完成之後才進入者，便不需要再分給他。下方引用律典作為明證，義理清晰可知。在解釋疑難的章節中，首先是提出詰問。因為物品屬於該結界所有，依法不允許帶出界外；各部教典的文字各有不同，因此提出問題來加以通達辨正。在回答之中，首先做出正式的解答。

【原文】言難分者，或在本處，多人往還，叢雜難辨。別擇靜處，故須唱令白僧令知，此即許出界外。《十誦》將僧得施物出界犯吉；亡物準同，故云結犯。注中，和會上科出界別受犯越之文。《十誦》下，明僧尼互索。亦顯攝歸本界。注中所簡，比上諸文。次問。
【譯文】所謂難以分配，有時是因為物品在原處時，往來閒雜人等過多，環境紛雜難以辨識查驗。為了另外挑選安靜之處，所以必須預先唱告秉白僧眾讓眾人知曉，這種情況就准許帶出結界之外。《十誦律》規定把僧團獲贈的布施物品私自帶出結界犯吉羅罪；亡者的遺物也比照這項規定辦理，所以才說要論處結罪。注文之中，調和融會了上一段關於私自帶出結界個別領受因而犯越的律文。在「十誦下」的部分，說明僧人與尼僧互相索要物品的情況。這同樣彰顯了應當收攝歸還至原本所屬結界的規範。注文中所作的甄別排除，可以拿來與前述各段經文對照參照。接著提出第二個詰問。

【153-0069】資持記/13e_下一#21
【原文】以物入界，即屬此處，意疑外人不可受故。答中，二意。一以不知，知則不許。二以同法，歸界同分，非私屬故。四分律行事鈔資持記下一
【譯文】既然物品一進入結界範圍，就理當歸屬於這個地方，因此心中疑惑界外之人應當無法受領分配。在回答之中，包含兩種層面的意涵。第一種是基於不知情的前提，若事先知情則絕不允許分給他。第二種是基於同屬正法同修的立場，物品既然回歸僧界就應當共同均分，因為這不是屬於任何個人的私有物品。《四分律行事鈔資持記》卷下一結束。
