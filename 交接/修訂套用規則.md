# 修訂套用規則（2026-11-10 起）

## 原則

**不再由程式自動套用修訂。** 每一批校閱結果都由 AI subagent 判斷後產出最終段落，程式只負責解析、分派、寫入已判定的結果。

## 流程

1. 解析報告 → `report_*.tsv`（含 gid / book / chunk / seg / problem / suggestion / current）。
2. 依書分派 subagent，指示明確：
   - 以 `current` 為底，只改問題指出的地方
   - 問題句已不在 current 就跳過
   - **若建議與該段原文不對應（疑似貼錯段），不得採用，標為「錯位」交回**
   - 輸出完整段落，不確定就跳過
3. 套用 subagent 產出的 `fix_*.tsv`（已是判斷後的結果）。

## 為什麼

程式無法判斷「新譯文是否對應這段原文」：
- 全書譯文與原文的漢字重合度中位數約 80%，錯位段落也有 60–70%，門檻分不開。
- 過去四次錯位（`10a#7`、`11a#21`、`01c#10`、`17a#80`）都是程式照段號覆蓋造成。

## 例外

純機械替換（`「A」改為「B」` 且 A 在 current 中恰好出現一次）仍可自動處理，但僅限單詞層級、不改整段。
