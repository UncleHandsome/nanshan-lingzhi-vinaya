# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【332-0005】02_戒疏/17b_卷四上之二#110
【原文】【疏】論犯四緣：一、是尼三眾，《五分》、《多論》「尼眾俱犯提罪」，道、船行戒亦爾，除去俗女不犯此戒；二、是隱、露處；三、無第三人，人相如《鈔》中；四、共坐便犯，《多論》：「比丘坐住，隨尼起坐，一一結提。尼坐亦爾。兩人同一坐，通日但一墮。」
【譯文】【疏文】論述構成犯戒的四個條件：第一、對方是尼眾三眾，《五分律》與《薩婆多論》都主張「尼三眾在此戒中同樣結犯波逸提」，後面的「同道行戒」與「同船行戒」也是如此，除了世俗女子不在此戒結犯（另有俗女戒）；第二、處所屬於隱蔽處或露天處；第三、現場沒有具備見證資格的第三人在場，合適的見證人行相如《行事鈔》中所載；第四、雙方一同坐下即構成犯戒，《多論》指出：「比丘坐著不動，尼眾隨之起立又坐下，每一次坐下都各自結犯一次波逸提。比丘尼坐著不動比丘起坐也是如此。若兩人同坐在一張長座上，整日相續不起只結犯一次墮罪。」

【332-0006】02_戒疏/17b_卷四上之二#111
【原文】【記】犯緣。第一，《四分戒本》唯據大尼，故引他部。既云「尼眾」，通三不疑，及後「道、船」例同此判。「除俗女」者，下有別制，故云「不犯此」也。第三，指《鈔》，彼「與女坐戒」引《僧祇》云「若母、姉妹，若大小淨人、睡眠、癡狂、嬰兒，並非證人」。
【譯文】【記文】在犯戒條件中。第一項，《四分戒本》雖然表面只依大比丘尼立名，所以引用其他部派律典作證。既然通稱「尼眾」，毫無疑問通指三眾，後文的「道行戒」、「船行戒」也都依此類推判定。「除世俗女子」，因為下文另有單獨制定的戒律，所以說「不犯此戒」。第三項，指向《行事鈔》，該書在「與女人共坐戒」中引用《僧祇律》說「如果是母親、姊妹，如果是未成年的大小淨人、正在熟睡者、癡狂者、嬰兒，都不具備第三見證人的資格」。

【原文】【疏】過制同前。
【譯文】【疏文】過失與制戒旨意皆同前戒。

【332-0026】02_戒疏/17b_卷四上之二#131
【原文】【記】二十七。「制同前」者，事別意通，故不重舉。宿、坐、船、行，離染無別，隨境造作，事相不同。文多略指，其意若此。
【譯文】【記文】第二十七條。「制意同前」，是因為事情雖然不同但防患之意完全相通，所以不再重複舉述。同宿、共坐、共船、同行，遠離情染的本意毫無二致，只是隨著境界造作的不同，事相才有所區分。文中大多簡略指出，用意就在於此。

【332-0027】02_戒疏/17b_卷四上之二#132
【原文】【疏】六緣犯。《多論》云：一、尼家三眾；二、共期，除偶相值，或期不許，不離聞處；三、同一道；四、不離見聞處；五、無緣；六、隨度界犯。
【譯文】【疏文】具備六個條件即構成犯戒。《多論》說：第一、對方是尼家三眾；第二、事先共同約定同行，除非是偶然相遇，或者是約定而對方未答應，彼此未脫離能聽聞的範圍；第三、走在同一條道路上；第四、彼此未脫離眼見與耳聞的距離；第五、沒有正當開許的因緣；第六、隨跨越界限即構成犯戒。

【332-0028】02_戒疏/17b_卷四上之二#133
【原文】【記】犯緣。第二，「除偶值」者，即《多論》文。彼具云：「若不期而偶共道，當使相去語言不相聞處，若相聞者，吉。若彼此相期互不許者，若相聞語聲者，吉。」文中「不離聞處」，總上兩句，皆有吉罪，但不犯提，故簡除也。
【譯文】【記文】在犯戒條件中。第二項「除非是偶然相遇」，這是引用《多論》的文字。論中詳細說：「如果不曾相約而偶然同走一條路，應當保持距離直到彼此說話互不相聞的地方；如果說話仍能互相聽見，犯突吉羅。如果彼此邀約但其中一方不同意，若同行時仍能互相聽聞說話聲，犯突吉羅。」經文中所說「未離開聽聞範圍」，總結了上述兩種情況，都有突吉羅罪，只是不犯波逸提，所以在此作了揀別排除。

【332-0031】02_戒疏/17b_卷四上之二#136
【原文】【註】隨分齊眾多界，一一墮。非村，若空處行，乃至十里，墮。若減一村，減十里，多村間同一界行，及方便共期，一切突吉羅。
【譯文】【註文】隨其所劃分的多數村界，每跨越一界，就一一結犯波逸提。若不在村莊，在荒野空曠處行走，乃至每滿十里，結犯波逸提。若不滿一個村莊、不滿十里，或在多個村莊之間同一交界處行走，以及事先共謀約定同行的方便階段，一切都犯突吉羅罪。

【332-0032】02_戒疏/17b_卷四上之二#137

【原文】【註】尼等吉羅。不犯者，不共期，大伴行，疑恐怖處，若往彼得安穩，若力勢所持，命、梵等難者，並開。

【332-0034】02_戒疏/17b_卷四上之二#139
【原文】【疏】戒本五句：一、犯人；二、與尼期；三、同道行；四、除異時；五、結罪辨相。重釋可知。

【332-0035】02_戒疏/17b_卷四上之二#140
【原文】【記】戒本，分文中。「重釋」者，即指釋「異時」文。《律》因僧尼皆欲往毗舍國，尼求僧伴，僧既不許，尼遂前往，為賊所劫，因開援護。文中兩相：「估客」男伴，無難亦開；「疑怖」難緣，無伴亦許。
【譯文】【記文】在戒本劃分條文中。所謂「重覆解釋」，是指解釋「特殊時節」的那段文字。《四分律》記載因為比丘與比丘尼都要前往毗舍離國，尼眾祈求能與比丘結伴，比丘不答應，尼眾於是自己先走，結果在路上遭到盜賊搶劫，佛陀因此開許讓比丘予以護援。經文中開許有兩種情況：「商旅」屬於男性結伴，即使沒有危難也開許同行；「疑慮恐怖」屬於危難因緣，即便沒有大商隊陪伴也允許同行。
