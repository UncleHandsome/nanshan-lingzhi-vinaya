整體讀來通順，但有幾類問題會誤導讀者：**術語被當成普通話語譯（例、相、境、取捨、僧用、別眾）**、**文化專名錯置（中國／邊地）**、**動詞讀錯（互作、合、出）**，以及**若干加譯**。以下分「系統性」與「逐則」說明。

---

## 一、系統性術語問題（各則都出現）

| 原文 | 現譯 | 問題／建議 |
|---|---|---|
| 四例、初例、第三例 | 四「條例」、第一「條例」 | 「例」是**類／句例**（體相四句料簡），不是法規條文。應作「四例／四類」「第一例」。 |
| 相（相足、相非、相乖、相善） | 相貌 | 指**三業外相、相狀**（可見可聞的表面狀態），與長相無關。宜作「外相」。 |
| 體 | 本體／體性／戒體（三種混用） | 記文自釋「體謂戒體」，宜統一作「體（戒體、身分）」，首次加註。 |
| 取／捨 | 錄用／捨棄不用 | 是**取（列入足數）／捨（不列入足數）**，不是人事任用。 |
| 僧用 | 「僧伽的錄用與否」 | 是「**供僧（作法）之用**」——能否充數供僧作羯磨。語意主客顛倒。 |
| 訶 | 訶止／訶阻（前後不一） | 應統一作「訶（在羯磨中提出異議、遮止）」。尤其「不應訶」是**不許他訶**，「開訶」是**開許他訶**；現譯「不應訶止」看不出是誰訶誰。 |
| 別眾 | 「個別結眾」 | **別眾是專有名詞**（與和合眾相對，同界不齊集、不與欲而致法不成），不可意譯。 |
| 眾相之「眾」 | （承「僧翻眾」而來） | 元照此處正主張「眾＝**眾多**」（其相非一），不是僧眾。譯文未點出，讀者會誤會。 |
| 白衣 | 白衣「居士」 | 白衣＝在家人（體非），「居士」多了褒義。 |
| 唯此一法 | 「這一部法」 | 「法」指這一種情形／這一人，不是典籍。 |

## 二、逐則問題

### 939-0001
1. **「一人說戒辦與百千敷教齊等」**：譯成「其成辦**功德**與百千僧眾**敷設教化**齊等」——「功德」是加譯；此句重點在**法事之成辦相等**（故心念、對首亦須應法），不在功德。「敷教」＝敷演教誡（說戒）。
 建議：「一人（心念）說戒所成辦的法事，與百千人（眾法）說戒敷演教誡相等。」
2. **「故可知矣」** → 「所以理當明瞭了」：贅字且語意偏。宜「由此可知（對首、心念也須應法）」。
3. **「故約堪能以目篇首」**：「堪能」宜補足為「堪能**足數**」，並點明即篇名「足數眾相」。
4. **「人即解云僧翻眾故」** → 「他人便解釋說僧伽翻眾的緣故」：不成句。宜「有人便解釋說：『僧』譯為『眾』，故二者相同」。
5. **「足別相關」**：應作「足數與別眾二事相關」。

### 939-0002
1. **「上二句明相生」** → 「相伴相生」：相生指**前後文相因而起**（承前篇僧集，故有此篇簡辨）。宜「上二句說明（與前文）相承而起的緣由」。
2. **「明體非相足」／「明相乖體淨」** → 「本體不是而相貌充足」／「相貌乖違而本體清淨」：前者中文不通。
 建議：「體雖非（不具戒體）而外相可充足數」／「外相乖違（不足數）而戒體清淨」。
3. 「其意可知」→「極其明顯」稍過；「制令簡練」宜作「（佛）制令簡別揀練」。
4. 「託事於緣」譯「藉由僧事依託於因緣」偏 vague，宜「都是就著事相因緣（外在可見者）而說，故皆約三業外相」。

### 939-0003
1. **「取捨據僧用」**：如上表，應作「取捨是就**能否供僧作法之用**而定」。
2. **「初句出第四」「第三出第二」**：「出」是**開出／開展出**，不是「列出」；且「初句」「第三」即前二途之初例、第三例，譯文一會「句」一會「條例」宜統一。
3. 「故取」→「所以**暫且**錄用」：「暫且」是加譯，宜「所以取（列入足數）」。
4. **「第四俱是，亦取亦捨」** → 「也可以錄用也可以捨棄」：讀來像任憑處置。此處應是**分別而言有取有捨**（善比丘則取；受四羯磨者得滿而不應訶）。建議核對鈔文後譯為「有取有捨（就足數則取，就訶法則捨）」之類。
5. **「境即人境」** → 「人員的**境界**」：明確誤譯。「人境」是**以「人」為所對之境**。宜「境即指人（作為羯磨所對之境）」。
6. 「初例，據文中」宜點明是「初例六人**依律文而出**」，與後文「義加」相對，語意才顯。

### 939-0004
1. 「得滿／不得滿」譯「能／不能滿足僧數」可，但「訶」須依上表統一。
2. 「唯此一法」→「唯獨只有這一部法」：改「只有這一種（此一人）」。
3. 「四羯磨人」譯得對，可加註（呵責、擯、依止、遮不至白衣家四種羯磨）。

### 939-0005
1. **「悉不相領」** → 「全都無法領會納受」：應是「**彼此不能領解（言語）**」，故受戒、捨戒皆不成。
2. 「六人名相」→「名稱相貌」：宜「六人的名字與相狀」。
3. 「並成訶足」宜作「都得訶（異議）與足數」。

### 939-0006
1. **「瘂聾互具為三人」** → 「互相具備算作三人」含糊。宜明列：「啞、聾、啞聾兼具，共三人」（與下則「具二者，瘂聾兼也」相呼應）。
2. **「中邊互望為二人」** → 「**中原**與邊地」：**文化錯置**。律中「中國」指佛法中心之地（中印度一帶），「邊地」指佛法邊遠、律不盛行處，與中國／中原無關。宜「中（中國，佛法中心之地）與邊（邊地）相對而望為二人」。
3. 「情和已彰」→「和合之情已經彰顯」：「情和」指**內心已聽許（同意）**，非和合。宜「其內心聽許之意已顯」。

### 939-0007
1. **「互作者」** → 「所謂**互相更替而違犯**」：誤譯。「互作」指四威儀**彼此不同而作法**，結果是**成別眾（法不成）**，不是「違犯（犯罪）」。
 建議：「所謂『互作』，是四儀中隨舉一儀作法，其餘三儀便成別眾；一儀對三儀有三，四儀歷計共十二。」
2. 「第二尼中」宜作「第二例中『尼』的一類」。
3. 「餘如後解」宜作「其餘如後文所解（後文再釋）」。

### 939-0008
1. **「且從四儀，即合前九」** → 「就**合成了**前述的九人」：「合」應是**合計／加上**（十二與前九相合），不是「合成為九人」。此處涉及下文「總三十一人」的算法，建議核對《業疏》原文後改譯為「（十二）與前面九人合計」。
2. 「是下一句」宜作「『是』字以下那一句」。
3. 「義加」的說明譯得不錯，可保留。

### 939-0009
1. **科判被併入正文**：「初科別解《四分》，所為中，初標」宜斷開：「初科別解《四分》。就『所為（人）』中，先標舉；『以』字以下解釋。」
2. 「處分」「受日」直接照搬，讀者難解，建議簡注：處分（乞處分羯磨）、受日（安居中受日出界之法）。
3. 「《古記》三失」譯得準確，「癡鈍即不解律人」一句處理得好。

## 三、最需優先修的三處
1. **「人境」→「人員的境界」**（0003）：意思全錯。
2. **「中邊」→「中原與邊地」**（0006）：文化專名錯置。
3. **「互作」→「互相更替而違犯」**（0007）＋ **「即合前九」→「合成了九人」**（0008）：把「成別眾」誤作「犯戒」，並把合計算錯。

其餘如「例→條例」「相→相貌」「取捨→錄用」雖不算大錯，但全篇一致偏移，建議統一術語表後回改，讀者才不會把「體相四句」讀成行政法规。
