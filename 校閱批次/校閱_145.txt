# 校閱材料　第145檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【145-0001】02_戒疏/03c_卷一下之一#86
【原文】【疏】答：「藥有二種，殺、活同名。如初則滅棄，其猶殺人藥也。既犯極刑，無任僧務，隨事不成，彼我負罪。今則加擯復無斯咎。彼則永絕財法，濫坌無緣；此則僧倫清穆，立法成濟。若斯行事，藥義存乎！」
【譯文】【疏文】回答：「藥有兩種，殺人之藥（毒藥）與救活人之藥，同樣都冠以藥的名稱。例如第一篇予以徹底滅擯棄絕，就如同能致人於死的毒藥一樣。既然違犯了世出世間的極刑大罪，就再也不堪勝任僧團的法務職責，隨他參與任何法事都不能如法成就，反而會使彼此雙方都蒙受罪咎。現在給予擯黜驅逐，就不會再產生這種過咎。對犯重者個人而言，從此永遠斷絕分受僧團財產與同霑法事的權利，免去混亂污染僧團的因緣；對僧團大眾而言，僧眾倫理得以保持清淨肅穆，建立起如法維繫教團的濟世功用。像這樣嚴肅地推行法事，難道不正是藥法的深刻用意所在嗎！」

【145-0002】02_戒疏/03c_卷一下之一#87
【原文】【記】初問中。悔法除罪，可得名「藥」；滅擯不爾，故問通之。答中，初定藥名。「既」下，釋藥義。初敘病。「今」下，示用藥。謂藥則殺惡存善，擯則除穢成淨，故得名「藥」。
【譯文】【記文】在第一個問答中。能以悔罪法門消除罪障，自然可以稱作「藥」；而徹底驅逐擯黜卻不是這樣，所以發問以求通達。回答之中，首先確定藥的定義。「既然違犯」往後，解釋發揮藥的深義。先敘述罪病情況；從「現在給予」往後，展示用藥的功用。意思是說良藥能除殺惡疾以留存善體，擯黜則是清除穢污以保全清淨，所以完全有資格稱之為「藥」。

【145-0003】02_戒疏/03c_卷一下之一#88
【原文】【疏】問：「對藥立刑，似有其致。今疑其藥，不攝刑科。偷蘭一法，何藥所治？初篇覆、露，則兼二藥。乃至第五，同上須多。如何對藥以立篇目？故知非也。」
【譯文】【疏文】有人問：「對照五種藥法來設立罪刑科條，看似很有道理。但現在我懷疑這些藥法，並不能完全統攝所有的刑罰科條。例如偷蘭遮這一種罪法，究竟要用什麼藥法來對治？第一篇中若隱瞞罪過或發露坦白，就兼跨了兩種藥法。乃至到第五篇，也同樣如上面所說需要多種藥法。怎麼能硬說是一對一對應著藥法來安立篇章名目呢？因此可知之前的說法是不對的。」

【145-0004】02_戒疏/03c_卷一下之一#89
【原文】【記】次難中。初二句許前義。「今」下，申疑。偷蘭無藥，夷、吉復多。「如」下，難破。
【譯文】【記文】在第二道質難之中。前兩句先肯定前面的解釋。「現在我懷疑」往後，陳述自己的疑惑。偷蘭遮罪沒有專屬的五藥可對應，而波羅夷與突吉羅罪又有多種懺法對應。從「怎麼能」往後，以此為據駁斥前面的觀點。

【145-0005】02_戒疏/03c_卷一下之一#90
【原文】【疏】今重解云：「藥病相對，大途為言；至於定罪，不無通塞。用藥或通，皆不出五。偷蘭聚攝，輕重不倫，至於用藥，非無對首。初重兩治，覆從初藥，露從第二。第五兩懺，故作第四，悞則第五。如斯處藥，通別何疑？」
【譯文】【疏文】現在我們重新解釋說：「藥方與病症一對一相對應，只是就總體大略的綱領而言；若論及具體判定罪名，自然免不了有寬通或限縮之別。具體用藥的方法雖然有通融兼用的情況，但總歸都不超出這五種藥法。偷蘭遮罪雖然統攝在七聚之中，輕重品位參差不齊，但若論及其對治的用藥法門，並非沒有對首懺悔的法門。第一篇重罪有兩種處治方法，隱瞞不報的適用第一種滅擯之藥，發露坦白的則適用第二種僧法之藥。第五篇的兩種悔法，故意違犯的適用第四種對首之藥，無心誤犯的則適用第五種責心之藥。像這樣開立處方用藥，各篇之間普遍涵蓋與個別專屬的分際又有何好懷疑的呢？」

【145-0006】02_戒疏/03c_卷一下之一#91
【原文】【記】重解中，初科為三。初通示，「用」下，別收。「偷蘭」三品，對眾多少，通皆對首，攝屬第三。夷、吉分對，在文可解。「如」下，結顯。言「通別」者，一、「滅擯藥」，局收初重；二、「僧懺藥」，通二；三、「對首三說藥」，通二；四、「對首一說藥」，通二；五、「責心藥」，唯局輕吉。初後皆局，中三並通。
【譯文】【記文】在重新解釋的段落中，第一個綱目包含三層意思。首先通體說明；從「具體用藥」往後分別統攝。「偷蘭遮」分為上中下三品，面對懺悔的大眾人數雖有多寡，但全都屬於對首懺悔的性質，在體系上收歸於第三種藥法。波羅夷罪與突吉羅罪的各自分配，在文字中已可清楚明瞭。從「像這樣」往後總結彰顯。所謂「普遍涵蓋與個別專屬（通別）」，是指：第一、「滅擯之藥」，唯獨局限收攝於第一篇重罪；第二、「僧團懺悔之藥」，通於前二篇；第三、「對首三說之藥」，通於二篇；第四、「對首一說之藥」，通於二篇；第五、「自心責備之藥」，唯獨局限於輕微的突吉羅罪。最初與最後這兩藥都是專門局限的，中間三種藥法則具備共通的適應性。

【145-0007】02_戒疏/03c_卷一下之一#92
【原文】【疏】如七滅藥，「現前」則通，「憶念」唯局。三法、五法，通局又多。尚得名藥，以殄四諍。
【譯文】【疏文】就如同七種滅諍藥法一樣，「現前毗尼」普遍通治一切諍論，而「憶念毗尼」則局限於特定事項。三種法與五種法，在適用上的寬通與局限情況更為繁多。即便如此，它們依然能統稱為藥法，用以平息四種諍論。

【145-0008】02_戒疏/03c_卷一下之一#93
【原文】【疏】此亦同彼，病雖位五，藥亦名同，至於對治，不無通局。故五藥中或有捨墮，此僧中懺，但據乞鉢為言，可即總對墮也。餘如《羯磨疏》中。
【譯文】【疏文】這裡的情況也和彼處完全相同，病症雖然劃分為五個位次，藥法也依此確立相同的名稱，至於具體的對治應用，自然不免有寬通與專門的差別。所以在五種藥法的對治中，或許有捨墮罪要在僧團大眾中懺悔的情況，這，只是就請求發還鉢盂這件事而言，自然就可以總體對應到波逸提（墮罪篇）之中。其餘詳細義理，如同《羯磨疏》中所記載。

【145-0009】02_戒疏/03c_卷一下之一#94
【原文】【記】次科。初正引。「現前毗尼」，通治四諍，兼下六藥。「憶念局」者，并不癡、罪處，唯滅覓諍，不通餘者；又「多人語」局言諍；自言、草覆局犯諍。又事諍中具上三諍，用藥並同，則知六藥兼通事諍。「三、五通局」者，重示「現前」也。四諍中，言、覓、犯各有三品，共為九品；事諍自有九品，共十八品。不秉羯磨，則三種現前，通治四品；若作羯磨，五法現前，通十四品。上舉現前麤對四諍，則一向俱通；下分三五細配諸品，則有通局，故云「又多」。餘廣如後。
【譯文】【記文】這是第二個層次。首先正式引用為例。「現前毗尼」普遍能治四種諍論，並且兼帶下文的其餘六種藥法。說「憶念毗尼是局限的」，是因為它以及不癡毗尼、罪處所毗尼，只能用來止息「覓諍（查究過失的諍論）」，不能通於其餘諍論；又「多人語毗尼」局限於「言諍（言語見解的諍論）」；自言治與草覆地局限於「犯諍（判定犯戒的諍論）」。又在「事諍（僧團法事的諍論）」之中具備上述三種諍論，用藥法門完全相同，由此可知六種藥法也兼通於事諍。所謂「三種法與五種法的寬通與局限」，是再次說明「現前」之義。四種諍論中，言諍、覓諍、犯諍各有上中下三品，合為九品；事諍本身也有九品，總計十八品。如果不舉行羯磨法會，則三種現前能夠普遍救治四品；如果舉行羯磨法會，五法現前則能普遍通達十四品。上面舉出現前毗尼粗略對應四種諍論，是全面普遍通達的；下面剖析三法、五法細緻配屬各個品位，則有通有局，所以說「情況更為繁多」。其餘詳細內容在後文廣泛說明。

【原文】【疏】答：「義有多途，不可一槩。若就根條以判，初則行之所依，餘四枝條故劣。若就進趣修成，初篇過重易離，不假勝進修治，故名為劣。乃至第五，過微難護，必須專意，無由識相。是以《戒本》舉『應當學』者，勸能治行也。若就純淨無染，名為最勝。」
【譯文】【疏文】回答說：「義理的角度有多種途徑，不可以一概而論。如果單從『根本與枝條』的角度來評判，第一篇是所有行持的依止所在，其餘四篇只是枝條，所以相對顯得淺劣。如果就『修行進趣與修持成就』的難易來說，第一篇過患極其粗重而容易遠離，不需要假借高深的修為去特別對治，所以在這層意義上稱為淺劣。乃至到了第五篇，過失極其微細而極難防護，必須全神貫注，稍一不慎就無法察覺罪相。因此《戒本》中特別標明『應當如法修學』，就是為了勉勵修行者建立起高度的對治行持。若就防護微細而達到純淨無染而言，則名為最為殊勝。」
