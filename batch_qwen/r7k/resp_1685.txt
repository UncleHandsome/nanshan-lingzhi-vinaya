以下按「明顯誤譯 → 可疑／增譯 → 體例問題」分則列出。整體讀來通順，但有幾處實詞誤讀會影響義理判斷，另有整段未譯與序號脫漏，建議優先處理。

---

## 一、跨則的系統性問題（先講，因為每則都出現）

1. **科文標記處理不一致**：資持記的「戒名／名中／犯緣／三中／簡濫中／釋中／律不犯中」都是元照的科段提示。譯文有時照抄（「戒名。」），有時譯出（「在犯戒條件中。」），有時把「名中」譯成「戒名。」。建議一律改成固定格式，如 **【戒名】（此下解釋戒名）**、**【犯緣】**、**【簡濫】**，或統一譯「以下解釋戒名：」。
2. **「緣」多處誤作「因緣」**：本組文字的「緣」绝大多数指**犯緣（成犯條件）**，不是制戒因緣故事（#43 兩處）。
3. **「衣」宜統一譯「衣（袈裟／三衣）」**，避免「衣物、衣服」的泛稱；律中「失衣」「乞衣」都是三衣。
4. **部分原文整段照抄未譯**（#44 不犯六緣、#47 問句、#42「更受」），這在「白話譯文」中屬體例缺失。

## 二、逐則檢查

### 【1685-0001】#42

| 問題 | 說明／建議 |
|---|---|
| ❌「下一句則**通達**道俗兩眾」 | 「通」是「通及、兼通、適用於」，非「通達」。改：**「下一句則兼通出家、在家二眾」**。 |
| ❌戒名「過量索衣戒」 | 此戒通稱 **「過知足戒」（過受衣戒）**，下一則開頭即釋「失三受二是為知足，失三受三故名過分」可證。「過量索衣」易與第六乞衣戒、第八勸增衣價戒混淆。 |
| ❌「六群比丘卻唆使他拿下來取來交給我（更受）」 | 「拿下來取來」重複；人稱在「他／我」間跳動；「更受」未譯。建議：**「六群比丘卻對他說：『你（多）取下來，拿來給我，我再受取。』」**（「更受」的確切所指建議再核律文，先加括注存疑）。 |
| ⚠️「正是本戒的**正犯**」 | 「正犯」易讀成現代刑法名詞。改：**「正是違犯此戒（的情形）」**。 |
| ⚠️「不加揀擇受者的**品行**」 | 「前境」只指受施對象（是否如法、淨不淨），「品行」是增譯，可保留但宜置括注。 |
| ⚠️「受與施雙方一同墮落」 | 「二俱為施所墮」是律家成語，宜**保留原詞＋注釋**，並與上文「為施所墮」的括注一致。 |
| ✏️「〈興治篇〉」 | 首次出現宜作 **〈對施興治篇〉**（《行事鈔》篇名）。 |
| ✏️「道應輕罪」 | 宜補注：指**比丘以外的出家眾結輕罪（突吉羅）**，否則與「上局比丘」的關係讀者不易明白。 |

### 【1685-0002】#43

| 問題 | 說明／建議 |
|---|---|
| ❌「下文所列**因緣**說『超過知足的界限』」 | 「下列緣」＝**下面所列的犯緣**（緊接著就是科文「犯緣」）。改：**「下文所列犯緣中說『過知足』，就是指此」**；「過知足」是術語，宜保留原詞。 |
| ❌「從反面來解釋前述**因緣**」 | 「反釋上緣」＝**反過來解釋上面那一條犯緣（第三緣）**。 |
| ❌「失去一件卻**不索取**」 | 「不取」是**律制不許取（受）**，不是比丘自願不索。改：**「失一衣而（應）不取者」**。 |
| ⚠️「重衣尚可**拆改改制**」 | 「摘」是**抽取、分出**：二三重衣可摘出一重充數。「改制」屬增譯。建議：**「（餘下的）二三重衣可以摘出一重（充一件）」**。 |
| ⚠️「或者是**考慮**另處可以求得」 | 「容」＝可、容許。改：**「或可另處求得」**。 |
| ⚠️「不可全數索要**耗盡其善心**」 | 疏文只作「不可全取」，後半句是譯者推衍，宜刪或加括注標示為補說。 |
| ⚠️「在**失去衣服的地方**」 | 「失衣處」也可能指「在失衣這種情況下」，非實指地點。建議譯「就失衣一事而言」並存疑。 |
| ✏️「自恣（隨意索取）」 | 應注為 **「施主自恣請（任比丘隨意索求）」**，主語是施主；現注讀來像比丘自行隨意索取。 |
| ✏️「在第三點中。」重複出現 | 與前文「在第三點中」撞車，建議統一為「（犯緣）第三中」。 |

### 【1685-0003】#44

| 問題 | 說明／建議 |
|---|---|
| ❌「（**戒本注文**中，「欲受」二字之上並無「彼」字。）」 | **「注戒」是書名**，即元照《四分律含註戒本》。改：**「《含註戒本》中，『欲受』之上沒有『彼』字。」** |
| ⚠️「對於**剩餘物品**的詢問」 | 「餘殘問」承上「自恣／為失故與」的討論而來，較可能是 **「其餘（未盡）的問答」**（或與律文「餘殘衣」相關的問答），譯成「剩餘物品」缺乏依據。建議保留原詞＋存疑注。 |
| ⚠️「比丘就不應當接受」 | 語境是 **「（超過知足的部分）不應取」**；與「自恣請」可多受相對。宜補此意。 |
| ⚠️「『曹』就是同輩、同類的**群體**」 | 「曹＝輩」是人稱複數詞尾（汝曹＝你們這些人）。建議：**「『曹』就是『輩』，猶言『你們（這些人）』」**。 |
| ⚠️「只是**秉公為人**」 | 「直為他」＝**單純為了他人**，「秉公」多了公正義。改：「若只是單純為他，沒有私情偏好」。 |
| ✏️「現在的文本是傳抄錯誤」 | 可作「今（鈔）文是傳寫之誤」，明示所指為《行事鈔》本文。 |

### 【1685-0004】#45（本則問題最多）

| 問題 | 說明／建議 |
|---|---|
| ❌**不犯六緣整段未譯** | 「若知足，若減知足，若多與衣〔謂自恣請〕，若細薄不牢，若二三重作，有餘如上語知」原文照抄。建議：**「若（依律）知足而受、若比知足更少受、若施主多給衣（指施主自恣請）、若所給的衣細薄不牢固、若是二三重（多層）作的衣，其餘情形如上文所說可知——都不犯。」** |
| ❌**「五」字脫漏** | 「五增價縷二物」的「五」是**第五犯緣**（與上句「第二有限者」同例）。應作：**「第五（緣）中，增價、增縷二事，隨增其一即成犯。」** |
| ⚠️「增加**絲**線」 | 「縷」泛指線（麻、棉皆可），逕譯「增線」較穩。 |
| ⚠️「用來購買衣物的**金錢價值**」 | 「價直（值）」＝價錢、財物，律中通錢與絹布等，「金錢」偏窄。改：**「買衣的價錢（財物）」**。 |
| ⚠️「更大、**更新**、更美觀堅實」 | 「新好」是「新而好」，「更新」易誤讀為動詞。建議「寬大、新、好、堅密」。 |
| ⚠️「只要**隨便涉及**一種」 | 「隨一成犯」＝**隨增其中任何一項即犯**，「隨便涉及」語意鬆散且帶輕率語感。 |
| ✏️「名中」→「戒名。」 | 未白話化，且與 #42 的處理撞名。 |
| ✏️戒名「勸居士增價衣戒」 | 慣稱 **「勸增衣價戒」**，建議統一。 |

### 【1685-0005】#46

| 問題 | 說明／建議 |
|---|---|
| ❌「**古代筆記**說」 | **「舊記」指古德舊有的《行事鈔》註記**（前人鈔記），不是現代「筆記」。改：**「古德舊記（前人《鈔》註）說」**。 |
| ⚠️「**彼國**古代的大銅錢」 | 「彼國」宜明譯為**印度（天竺）**；又「即今一小錢」的「今」是作者當時，非今日，可作「即當時的一枚小錢」。 |
| ⚠️「最極微少的**份額**」 | 「一分一線」宜點明：**一分（極小的錢）、一線（一根線）**，作為犯戒的最低界限。 |
| ⚠️「都屬於尺寸與價格的**範疇**」 | 「即是量價」是**對應關係**：廣、長、堅緻即相當於（十誦的）增量、增價。建議直譯「就是（增）量與（增）價」。 |
| ⚠️「三種**增改相**」 | 屬合理增譯（十誦：色、量、價），但宜加括注標示為譯者補說。 |
| ⚠️「闡明開許的**真意**」 | 「釋成開意」＝**解釋成立開緣之意**，「真意」多餘。 |
| ⚠️「五種相狀可以**清楚分辨**」 | 「五相可分」是**科分**：「（律文）『若從……』以下，可分為五相（其餘五種不犯）」。 |

### 【1685-0006】#47

| 問題 | 說明／建議 |
|---|---|
| ❌「所以要滿**一條布**才犯戒」 | 「乞衣一條方犯」的「條」是**衣**的量詞（四肘量的衣），不是布；此處顯然是被上文「買布」帶偏。改：**「要（乞得）一件衣（四肘量）才犯」**。 |
| ❌「原本施主心中**並無定額**」 | 「乞本施主無心」＝**施主本來沒有（施衣的）心意**，正與下文「（勸增）限約已定」相對。譯成「無定額」把兩者的對比邏輯弄丟了。 |
| ❌「**前一條**的乞衣戒」 | 「前乞戒」指**前面（第六）的乞衣戒**；本文正在第八戒，「前一條」會被讀成第七過知足戒。 |
| ❌問句整段未譯 | 「勸增一縷即犯，乞衣一條方犯……」照抄。建議：**「勸（施主）增價乃至一縷就犯；乞衣卻要乞得一件才犯（即上引《十誦》《僧祇》的四肘量），二者為何不同？」** |
| ❌「文中所指示如疏文所說者」 | 句子不通。改：**「（鈔文）說『如疏』，所指的是：疏中說……」**。 |
| ⚠️「對施主的惱害**意義**較微薄」 | 「惱義是微」＝**惱亂施主的情形輕微**；「意義」是誤讀「義」。 |
| ⚠️「貪婪引發施主懊惱的**情節**最為嚴重」 | 「貪惱最重」＝**貪求、惱他的過失最重**，「情節」用語不宜，因果鋪陳也是增譯。 |
| ⚠️「施主**純淨心意**所定的限額」 | 「虛心」的確解待考（與上句「無心」相對，應指施主先已發心、限定衣價）。建議保留「虛心」原詞＋注，不要逕定為「純淨心意」。 |
| ✅「不荷嫌少索多」譯「不但不感恩，反嫌少而索多」 | 準確，可保留。 |

## 三、建議再查證的疑點（不宜逕下斷語）

1. **#44「餘殘問」**：所指為「其餘問答」或律文「餘殘衣」之問，需比對《戒本疏》上下文。
2. **#43「失衣處」**：地點義 or 情況義。
3. **#47「虛心」**：與「無心」對舉的確切用法。
4. **#42「更受」**：是六群自稱「我再受取」，抑或另有律文用語背景，宜核《四分律》捨墮第七緣起。

## 四、修訂優先順序

1. **改義理關鍵詞**：#47「無心／一條（衣）／前乞戒」、#43「緣＝犯緣」、#42「通」、#44「注戒」、#46「舊記」。
2. **補齊未譯與脫漏**：#45 不犯六緣、「五」字；#47 問句；#42「更受」。
3. **統一體例**：科文標記、戒名（第七＝過知足戒、第八＝勸增衣價戒）、書名簡稱、「衣」的譯法。
4. **清理增譯**：「耗盡其善心」「秉公為人」「金錢」「真意」「情節」等，凡屬推衍一律加括注或刪除。
