整體看，這份譯文方向正確、沒有大的義理顛倒，但 **「白話化」做得不徹底且不均勻**：有的句子譯得很口語，有的整句照抄原文；另有幾處斷句／主語／科判語的處理會误导讀者。以下分「逐則問題」與「通則問題」說明。

---

## 一、逐則問題

### 0001

1. **「若下，明不犯」譯作「若以下，明不犯」——體例不一致且未譯。**
   前面「謂下，示相」已譯成「謂字以下，示相」，此處應同例：
   → 「**『若』字以下，說明不犯的情形。**」
   （這是元照在科分《行事鈔》文句，不是「如果以下」的意思，現在的寫法讀者极易誤讀。）
2. **「得抄右邊不見肘也」**譯為「得抄右邊而不見手肘」語意含混。原意是抄衣的**限度**：
   → 「通肩披衣的，可以抄起右邊，**但不可露出手肘**。」
3. 「初標名」「示相」仍是文言。可作：「（鈔文）先標出戒名；『謂』字以下，顯示（犯相）樣態。」
4. 「無有**斬**愧」→「慚愧」屬校改，宜加校註（詳見通則）。

### 0002

1. **「禮佛侍上，皆為媟慢」缺主語**，現在讀來像「禮佛侍奉長上本身就是褻慢」。
   → 「**（覆頭）**禮佛、侍奉尊長，都是輕慢不敬。」
2. **「又坐戒，妨比座故」未譯開**，且「妨礙比鄰之座之故」句式疊「之」拗口。
   → 「**另有『叉腰坐戒』，因為會妨礙鄰座比丘的緣故。**」
   注意：**比座＝鄰座的人（比丘），不是「座位」**，譯成「比鄰之座」略偏。
3. 「匡器」照抄未釋。宜加注：「匡（筐）狀器具，喻兩肘外撐如筐架。」
4. 「蹲坐**失衡**跌倒」的「失衡」是增字引申，可保留但宜作「蹲坐不穩而跌倒，衣開露形，招致譏嫌」。
5. 「尻音苦刀反」處理得好（保留反切＋释义），可再加今音ㄎㄠ。

### 0003

1. **「戾，曲也」「前卻，卻即後也」完全未譯**，與 0002「尻……即臀部」的處理不一致。
   → 「戾，就是身體歪曲。」「前卻，『卻』就是後退。」
2. 「或擔刺」拆成「挑擔／棘刺」**是對的**（正好凑「三事」），但「貫通上文三事」仍模糊。
   → 「『舉手遮』一項，**通貫上面惡獸、擔、刺三種情況**。」
3. **「靜點」→「靜默」是校改**（黑部形近而訛），此處默改、0004 又照抄「靜點戒」，前後打架。應統一並出校。
4. 「此以正行列為戒本」可再說清楚：
   → 「**此戒在戒本中是用正面表述立文**（如『好覆身』），同類的還有齊整著衣、靜默、用意受食、平缽受食等。」

### 0004

1. 「牀」→「狀」的判斷**很有道理**（爿旁，木／犬形近），但語氣宜存疑：「疑為『狀』之訛」，不要逕斷。
2. **「不生世善」譯「不生世間善心」語意含糊**——這批威儀戒的制意是「令世人（白衣）生善生信」。
   → 「**不能令世人生起善心（信心）**」。
3. 「若在伽藍，豈得不爾」→「豈得放肆」意思雖合下文，但字面「不爾（不如此）」被改掉了。
   → 「若在寺院中，**難道就可以不這樣（不守威儀）嗎**！」
4. **「時開寺內，非是常途」**譯「有時開許在寺內」易誤讀成「寺內偶爾可以開許」。
   → 「（戒文）雖有開許寺內的情形，但那是**特例，不是常規**。」（「常途常規」亦嫌重複）
5. 「施食者，如供聖呪願等」是解釋**靜默戒的開緣**（為施主咒願而出聲不犯），譯文只羅列詞面，讀者看不出關聯。
   → 「所謂『施食』，指供僧（供聖）時為施主咒願說法之類（故出聲不犯）。」

### 0005

1. 「棄撒羹飯」用詞生造。→ 「**灑落、糟蹋羹飯**」。
2. 「平鉢二戒」宜加注：即「平缽受食」「平缽受羹」兩條。
3. 「故云非溢」把引文改寫成「不使漫溢」， losing 引文痕跡。
   → 「今師就**食物**說，所以說『**非溢**』（食與缽口齊平，不堆高溢出）。」
4. 《教誡律儀》可注全名（道宣《教誡新學比丘行護律儀》）。
5. 「義理推準……一體適用」譯得好。

### 0006（**問題最集中的一則**）

原文是「居士／比丘」主語交替的敘事，譯文一律省略主語，讀者會分不清誰吃誰添：

> 建議改寫：
> 「居士先把飯盛入缽後，進屋去取羹；回來時，**比丘已把飯吃光**。居士給了他羹，又轉身去添飯；回來時，**比丘又把羹吃光了**。（居士）於是譏嫌說：像個餓漢。」

另外：

1. **「更須受益」譯成「更須增添益受」几乎等於沒譯**。受益＝受取添益。
   → 「所謂『正須』，是指隨食吃完後，**確實還需要再接受添食**，並非貪求快吃（搶食）之故。」
2. 「棑鉢中戒」照抄。宜作「排（挑）缽中食戒」並加注：即挑挖缽中央而食。
3. 「烏鳥」可徑譯「烏鴉」。

### 0007

1. 「見比座所分多」仍拗口 → 「**見鄰座比丘分得的食物較多**」。
2. 「被比座取缽藏之」補「被」字很好，但可再白話：「鄰座比丘把他的缽拿走藏起來」。
3. **「大揣」「擲口」「頰食」「噏飯」四個戒名全未釋**，是這則最大缺口：
   - 大揣＝大摶，飯團捏得過大
   - 擲口＝遠處把飯團拋投入口
   - 頰食＝把食物塞在腮頰裡（如獼猴）
   - 噏飯＝吸吮作聲而食
4. 「鳥鳥」→「烏鳥」是校改，應出校。
5. 原文末缺「〕」，譯文補上是对的，可註明「原闕，今補」。

## 二、通則性問題（建議統一體例）

1. **白話程度不一致**：科判語（初標名／謂下／不犯中／開緣指上）與夾註，有的譯有的抄（「覆頭如同盜賊」譯了，「不慚入室，如似鳥雀」沒譯）。建議明訂：**夾註一律白話**，或**一律保留原文**，不要混用。
2. **校改要透明**：目前「斬→慚」「點→默」「鳥鳥→烏鳥」是默改，只有「牀→狀」出注。應統一：凡改字一律加〔校：疑作○〕，並統一存疑語氣。
3. **術語統一**：
   - 「比座」時譯「比鄰之座」、時留原詞；且宜正名為「**鄰座比丘**」。
   - 缽／鉢：原文用「鉢」，譯文用「缽」，全篇統一即可，但勿混用。
   - 戒名（跳行、蹲坐、繫鉢、棑鉢中、頰食……）建議**首見處加短注**，後文沿用。
4. **增字引申宜可辨識**：如「失衡」「饑荒」「向外張開」都是合理補足，但屬解釋而非原文，最好用括號或注明，避免與原文字面混淆。

## 三、值得肯定之處

- 「或擔刺」正確析為二事，與「貫上三事」吻合（此處最容易錯）。
- 「匡肘」理解為兩肘外張，方向正確。
- 「義準，諸戒內外通犯」「安有處寺而容縱放」譯得乾淨有力。
- 「尻，苦刀反，臀也」保留反切並释义，處理得當，可作為其他字詞注釋的範式。
