### 1. `qwen_local.py` 的兩個嚴重執行期 Bug

* **`UnboundLocalError` 讓「查無改搜全庫」幾乎必敗**
  看 `local_search` 第 207–227 行：
  ```python
  if _own and hits:
      _wins = [...]  # ← 只有在 hits 非空時才會定義 _wins
  ...
  if not hits and work:
      hits = _LC.find(query, None, rows)  # 改搜全庫
      if _own and hits:
          if any(w and w in _ht for w in _wins):  # ← 💥 直接報 UnboundLocalError！
  ```
  只要模型填了錯誤的 `work` 導致第一次 `_LC.find` 回傳 `0` 筆，`_wins` 就**根本沒被定義**；接著程式貼心地改搜全庫並命中結果時，第 227 行一讀 `_wins` 就會立刻噴出變數未定義錯誤，被外層攔截回傳「工具執行錯誤」。這很可能也是 7.8 節出現高達 28% 查無的隱藏元兇之一。

* **撞過 400 審查的檔案，續跑時會「無止境重跑花錢」**
  `_save_blocked()` 的註解寫著「`內容審查未通過：不重跑，只把錯誤與用量存檔`」，但 `run(f)` 開頭的跳過判斷（第 433 行）**只檢查 `_回.txt` 和 `_usage.json`**，沒有檢查 `_400審查.txt`。只要你重跑同一批指令來續跑未完成工作，所有曾撞 400 的檔案都會重新再搜一次、再撞一次 400。

### 2. `local_corpus.py` 的三個檢索盲點

* **27 部主庫遇到含「卷X」的短正文會整行被吞掉**
  南山 6 部書用的 `_add_file()` 有寫條件避開含標點或以「`如`/`見`/`若`」開頭的句子；但 27 部律藏與辭典用的 `load()`（第 199 行）**直接呼叫 `_juan_label` 卻沒加這個過濾**。
  結果只要《四分律》或《南山律學辭典》裡有一行 ≤40 字、剛好出現「卷上」「卷一」的引文（例如 `見卷三僧殘法。`），就會被誤認為卷名標題直接 `continue` 跳過，永遠搜尋不到這行，順便把後面的行都標錯卷次。

* **指定 `work` 查單書時，最多永遠只給 2 筆**
  `find()` 預設 `per_book=2`，而 `qwen_local.py` 呼叫 `_LC.find(query, work, rows)` 時沒有覆寫 `per_book`。所以就算模型明確指定 `work='資持記'` 並要求 `rows=5`，程式還是只回傳 2 筆就截斷。

* **書名別名表 `startswith` 誤配**
  `_norm_book` 按順序用 `startswith` 比對 `ALIASES`。清單裡有 `含注戒本疏 → 戒疏` 和 `隨機羯磨疏 → 業疏`，卻漏了不帶「四分律」前綴的 **`含注戒本疏行宗記`** 與 **`隨機羯磨疏濟緣記`**。若模型這兩部記文填了這種常見簡稱，會被截胡配對到《戒疏》和《業疏》裡去。

### 3. `pack_judge.py` 依賴「檔名尾數」判相鄰，遇混合切法會誤打包
* 4.10 節的「混合切法」會把舊組漏掉的段落重新命名為 `n0001`、`n0002`……但這批補建的組別彼此之間在原卷裡可能隔了幾十段。
* `pack_judge.py` 靠 `key` 結尾數字相減是否為 `1`（修好雙斜線後）來判斷相鄰，遇到 `n0001`、`n0002` 會誤判成相鄰而硬包在一起，造成「前一段」跟「後一段」共用錯置的後文背景。直接比對 `.json` 裡的 `cur[-1]['md']['g1'] == it['md']['s0']` 才真正可靠。

### 4. `mk_review_materials.py` 讓「盲翻」不必要地受制於舊譯 (`AI語譯/out`)
* `load_pair()` 只要發現某一卷的原文行數與舊現譯（`AI語譯/out`）段落數不合（`len(a) != len(o)`），就會整卷略過不建材料。
* 但因為 `mk_blind_materials.py` 是從它的輸出轉材料，這代表**只要舊譯某一卷缺檔或少換了一個空行，連完全不用舊譯的「盲翻」也會跟著整卷漏翻**（而且 `mk_split_blind.py` 不會略過該卷，會變成該卷只有 >500 字的長段有翻、一般段全失蹤）。

### 5. `build_a2.py` 在審核缺檔時會靜默把「未審核稿」放進定稿
* 若終審階段偶發缺檔（`ap_` 不存在），`build_a2.py` 雖然會把它記進 `_未審核清單.log`，但**同時照常把未經終審的裁決稿寫進 `_定稿/*.txt`**。如果後續自動化合併全書時沒先檢查 `_未審核清單.log` 是否為空，未審核的譯文就會混進成品。

### 6. `qc_scan.py` 的三個盲區（會回傳 ✅ 放行異常檔）
目前的質檢腳本遇到以下三種明確壞檔時，都會全數顯示 **`✅`**：
1. 譯文完全是空的或被截斷到剩幾個字（`oh == 0` 不在 `10 <= sh <= 75` 檢查範圍內）。
2. `pack_judge.py` 拆回失敗寫進檔案的 **`（拆回失敗：缺標籤）`**／**`（拆回失敗：缺段）`** 字樣。
3. 原本是雙欄（【疏文】＋【記文】）的單元，在某關漏掉整段【記文】沒輸出，或者只剩單欄，也沒有與材料的 `units` 數量核對。
