# 校閱材料　第211檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【211-0001】資持記/16d_下四#27
【原文】應償者，是俗物故。《五分》。聽求援。《十誦》，初制呵罵。次簡所詣。餘人，謂非官及斷事人也。第七，四獨戒。〔佛在舍衛，有凡褰衣渡水，為賊觸嬈，人譏故制；尺有尼多諸弟子，捨眾，獨行入村；又於村中獨宿，人皆譏云：欲得男子。
【譯文】應當賠償者，因為那原本是俗人的財產。《五分律》聽許比丘尼尋求救援。《十誦律》最初制止喝斥辱罵。其次簡別所前往的人。其餘人，是指非官府及非斷案主事之人。第七條四獨戒。〔佛在舍衛國，有凡夫尼撩起衣服渡水，被盜賊觸碰騷擾，遭到世人譏嫌因此制戒；又有比丘尼擁有許多弟子，卻捨棄大眾，單獨行走進入村落；又在村落中獨自留宿，世人都譏笑說：想要得到男子。

【211-0002】資持記/16d_下四#28
【原文】又六群尼，與眾尼於拘薩羅曠野中行，而常在後，人問，答云：欲得男子，訶已因制；四戒合制，隨一成犯。〕若比丘尼，獨渡水，獨入村，獨宿〔隨脇著地〕，獨後行〔離伴見聞〕，犯初法應捨僧伽婆尸沙。獨渡河中，初緣又二，初定犯相。道行戒，即尼制邊方，有疑怖處，人間遊行，皆犯提罪。
【譯文】又有六群尼，與大眾尼在拘薩羅國曠野中行走，卻常常落在後頭，別人問她，回答說：想要得到男子，被訶責之後佛因而制戒；這四條戒合併制定，隨犯其中一事即成罪。〕若比丘尼，獨自渡水，獨自入村，獨自留宿〔只要一側脅肋著地即算〕，獨自落在後方行走〔離開同伴的目見耳聞範圍〕，犯初法應捨僧伽婆尸沙。在獨自渡河之中，第一個因緣又分兩段，首先判定犯相。「道行戒」是指比丘尼戒中規定邊方有疑慮恐怖之處，人間遊歷行走，都犯波逸提罪。

【211-0003】資持記/16d_下四#29
【原文】彼明行相，通界外內，可決今犯。次明開緣。有橋而渡，不涉水故。車船亦爾，如次所明。第二緣，初示犯相。入水方便，上岸至果。文據兩尼，以示輕重。律下，次教正儀。三四可知。獨入村中，初文。《四分》：示村野分齊。注示吉罪；坊，即是村，謂村中人家也。《僧祇》，明離伴分齊。
【譯文】那條戒明示行止的相狀，通於結界之外與結界之內，可以用來決斷眼前的違犯。其次說明開許之緣。有橋梁而渡過，因為不踩涉水流之故。乘車或坐船也是如此，正如其次文句所明示。第二個因緣，首先昭示犯相。踏入水中的方便罪，直到登岸便成究竟罪。文句依據兩位比丘尼同行，以此說明罪名輕重。律文以下，接著教導端正的儀軌。第三、第四個因緣可以由此類推而知。獨自進入村落之中，第一段文句。《四分律》昭示村落與曠野的分限。注解中標示犯突吉羅罪；「坊」就是村，是指村落之中的民宅家戶。《僧祇律》說明離開同伴的判定分限。

【211-0004】資持記/16d_下四#30
【原文】三無緣，亦謂命梵。次科。據本成犯，須約村門。古解越界，乃約村中橫道成殘；不唯太過，抑亦昧文。下引律證。明約村門，足知非解。出村亦犯，即知入出，皆名越界。獨宿中。初緣。初句明犯分齊。次句示犯處，不問僧俗，通一切故。兩處下，明持。若下，示開。故下，證犯。
【譯文】第三是無特殊因緣，其中的因緣也是指命難與梵行難。次一科。依據根本成犯而言，必須以跨越村門為準。古代的解說認為越過分界，竟是指在村落中的橫道穿行即成僧殘；不僅太過嚴苛，而且也昧於律文原本的真意。下文引述律文作證。明定是以村門為界，足以明白古解是不正確的。走出村落也算違犯，即可知進入與走出，都稱為跨越界限。獨自留宿之中。第一個因緣。第一句明示犯戒的分寸界線。第二句指示犯戒的處所，不問是出家或世俗之地，通攝一切處所。兩處以下，說明持守之法。若以下，指示開許因緣。故以下，證實結罪情況。

【211-0005】資持記/16d_下四#31
【原文】《僧祇》明相檢法。《五分》示犯相。獨行中，同上三緣；初至處行，即第一緣。根本，即發足時。又下，即第二緣。《四分》下，第三緣。不犯四節，初獨度中。言共伴者，非犯緣也。乘船等者，不涉水也。伴死等者，非本意也。《五分》水淺，無觸嬈也。次入村中。指如前者，即第三無緣也。三獨宿中。
【譯文】《僧祇律》說明互相檢校探尋的方法。《五分律》指示犯戒相貌。獨自落後行走之中，同於上述三種因緣；從開頭到「處行」這一段，就是第一因緣。根本成犯，就是舉足出發之時。又以下，就是第二因緣。《四分律》以下，是第三因緣。不犯戒的四節文句中，首先獨自渡水之內。所說的「伴侶同行」，並非犯戒的因緣。乘船等等情況，是因為沒有涉水涉足。同伴死亡等狀況，並非出於本意。《五分律》說水淺之處，沒有遭到觸碰騷擾的危險。其次獨自入村之中。「指如前」的意思，就是第三種缺乏正常因緣。第三獨自留宿之中。

【211-0006】資持記/16d_下四#32
【原文】初約守戒明不犯。若下，伴有緣也。乃下，已有難也。獨行中。伴緣己難，並同上開。《僧祇、五分》，並據緣開，可解。邂逅，不期也。單提一百二十。與僧同者，如前〈釋相〉。異但出一，現行數犯；餘尋《尼鈔》，自可委明。第一百十四紡績戒。〔佛在舍衛，六群尼自手紡績，居士笑言，如我婦無異，白佛因制。
【譯文】首先依據謹守戒律說明不犯。若以下，是同伴遇到了因緣事故。乃至以下，是自己遇到了危難。獨自落後行走之中。同伴的因緣與自己的危難，都同於前文的開許。《僧祇律》、《五分律》，都是依據因緣而開許，理可想知。邂逅，是指未曾預期而偶遇。波逸提（單提）共有一百二十條。與比丘僧相同的戒條，如前面〈釋相篇〉中所述。相異的戒條此處僅提出一條，是因現今經常有所違犯；其餘若查尋《尼鈔》，自然可以詳盡明了。第一百一十四條紡績戒。〔佛在舍衛國，六群尼親手紡線織布，居士笑著說，跟我家婦人沒有兩樣，白佛因而制戒。〕

【211-0007】資持記/16d_下四#33
【原文】若比丘尼自手紡績者，波逸提。擗，謂分擗；引即牽引；縈，謂卷絡；織則可會；四事隨作，皆犯墮。恐謂懺竟得著，故制不合；隨著，吉羅。今時尼女，機織刺繡，以為事業。棄親入道，本圖何事？若此出家，何如在俗！避溺投火，即斯人矣。結中。上下，即戒本前後也。
【譯文】若比丘尼親手紡線織布者，犯波逸提。「擗」，是指分剖撕扯；「引」就是牽引拉線；「縈」，是指卷繞絲絡；「織」則自然明白；這四種事隨便作哪一種，都犯墮罪。唯恐有人以為懺悔完畢後衣服就可以穿著，所以制定不合理；隨其穿著，得突吉羅罪。現今的比丘尼女子，以織布刺繡作為生活事業。捨棄父母親人出家入道，究竟是為了圖謀何事？如果像這樣出家，又跟身處世俗有何差別！所謂想要躲避溺水卻反而投身烈火，正是說的這類人。結語之中。「上下」就是指戒本的前前後後。

【211-0008】資持記/16d_下四#34
