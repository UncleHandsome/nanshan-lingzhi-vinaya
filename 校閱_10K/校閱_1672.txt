# 校閱材料　第1672檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1672-0001】03_業疏/08b_卷二之二#32
【原文】二中初科，自恣對跪須坐，說戒隨聞故立，二律所明，四儀通得。古謂說、恣宜不立相，受戒問難事須立相，故云「如熨斗柄」也
【譯文】在第二過失的第一科中，自恣需要對跪就坐，說戒隨處聽聞故而站立，兩部律典所說明的，四種威儀皆可行辦。古師認為說戒與自恣適宜不立標相，受戒問遮難之事則必須立標相，所以說「像熨斗柄」。

【1672-0002】03_業疏/08b_卷二之二#33
【原文】今有人結，隨在何處，臨時指擬方隅為相，然後誦結，義則不然。三小相同，體以身集為界，如何於外更立標相？必其擅置，故引訶人，令訶法壞，大乖律文，終非開意，誠不可也
【譯文】如今有人結界，無論身在何處，臨時比畫指點四方角落作為標相，然後誦念結界文，在義理上絕非如此。三種小界性質相同，本質都是以身相集合之處作為界限，怎能在外邊另外樹立標相？如果擅自設立標相，因而招引來訶止之人，導致訶止而使羯磨法敗壞，這大大乖違了律文，終究不是開許結小界的本意，實在是不可行的。

【1672-0003】03_業疏/08b_卷二之二#34
【原文】次科初牒非。「義」下躡斥，初責其妄判三小同為遮訶，不當有異，那得小受獨立相耶？「必」下顯過，一則法壞，二乃違文
【譯文】下一科中首先列舉其錯誤。自「義」以下接續斥責，首先責難其妄加判斷，三種小界同樣是為了阻絕訶止，不應當有所差異，怎能唯獨受戒小界單獨樹立標相呢？自「必」以下彰顯其過失：一則導致羯磨法敗壞，二則是違背律文。

【1672-0004】03_業疏/08b_卷二之二#35
【原文】故受戒文云「疾疾一處集，知無異外」，一是也；說戒文云「爾許比丘集，知數人外無界」，二是也；自恣文云「齊坐結之，知坐處外非界」，三是也；受中又云「界外不訶」，四是。飜是成非，數可知矣
【譯文】所以受戒文中說「急速在一處集合，當知沒有其餘的界外」，這是第一點；說戒文中說「聚集這許多比丘，當知在此數人之外沒有界域」，這是第二點；自恣文中說「齊同就坐之處結界，當知坐處之外不是界域」，這是第三點；受戒文中又說「在界外不能訶止」，這是第四點。若反轉這四點正確之義而成非法，其過失之數便可得知了。

【1672-0005】03_業疏/08b_卷二之二#36
【原文】三中初別引四段，並彰無外，如注所引。「飜」下總結，若立外相，違上諸文，則成四非
【譯文】在第三段中，首先分別引用四段律文，都彰顯界外無別有界，正如註解所引。自「飜」以下總結，如果樹立外在標相，違背了以上各段律文，就構成了四種非法過失。

【1672-0006】03_業疏/08b_卷二之二#37
【原文】問：以身為標，外無界內，問難受法如何得成？文云「界外不成受」故。答：義須殷鑒，不可氷情。問難前緣，可自依律界外問也；及論請師乞受，必須呼來入界，十人融通，開間納取，一足入內，尚預法儀，何況俱也！如斯行事，內準佛教，外約凡訶，僧有授法之功，前無虗受之願，可也
【譯文】問：如果以身體為標相，身體之外就沒有界內空間，那麼訊問遮難與受戒之法如何能夠成就？因為律文說「在界外受戒不成」的緣故。答：義理上必須深切鑑察，不可滯礙情見。訊問遮難的前行因緣，自可依照律文在界外訊問；至於請師與乞受戒法，必須喚受戒者進入界內，十位僧人通融，中間讓出空隙予以接納，只要有一隻腳跨入界內，就尚且算是參與法事儀軌，何況雙腳都進來呢！如此行事，內在合乎佛陀教制，外在約束凡情訶止，僧眾具備傳授戒法的功德，受戒者也沒有落空的發願，這樣就可以成了。

【1672-0007】03_業疏/08b_卷二之二#38
【原文】初問中，律云受戒人不得在空、隱沒、離見聞處及在界外，古師執此以立外相，故引為難。答中初斥執計。「問」下教行事。律云有受戒者，將至界外，脫衣看稽留受戒，因制問難，此即明在界外。上引「不成」文者，準下決云，此通白四之時耳。「一」下舉類，即如《十誦》一人中間木上坐，足四邊作法，故云「尚預法儀」。「如」下結益
【譯文】在第一問中，律文說受戒的人不得在虛空、隱蔽、脫離見聞之處以及在界外，古師執著此文而樹立外在標相，所以引用來作為問難。回答中首先斥責其偏執計度。自「問」以下指示具體行事。律文說有受戒的人，被帶到界外脫衣檢視而耽擱了受戒，佛陀因而制定問遮難，這就明示是在界外進行。上面所引的「不成」之文，依準下文決斷說明，這通指作白四羯磨之時罷了。自「一」以下舉出同類情況，就如同《十誦律》中一人坐在中間木頭上，僧眾在其腳的四周作法，所以說「尚且參與法式儀軌」。自「如」以下總結其利益。

【1672-0008】03_業疏/08b_卷二之二#39
【原文】問：訶人若來，倚我身界，豈不別耶
【譯文】問：訶止的人如果前來，挨靠著我等身界，難道不構成別眾嗎？

【1672-0009】03_業疏/08b_卷二之二#40
【原文】次問，若據今師，已無身外之界，欲破古解，故假設為問
【譯文】第二個提問，如果根據今師的觀點，本已沒有身外的界域，為了破除古師的見解，所以設為問難。

【1672-0010】03_業疏/08b_卷二之二#41
【原文】答：有人言：初結不成，以同自然，有別住故；既結界已，雖訶不成，界立為難，開無訶也，如惡心觸不成觸等
【譯文】答：有人說：起初結界不能成辦，因為等同於處在自然界中，有比丘在界內別眾而住的緣故；既然已經結界完畢，即使來訶止也不能成立，因為界已立下是為了避難，開許不被訶止，如同以惡心觸犯不算有效觸犯等等。

【1672-0011】03_業疏/08b_卷二之二#42
【原文】古解中，彼由立相，故作兩通：初結若來，即成訶別；結已或至，縱訶不成，引例可見
【譯文】在古師的解釋中，他們由於主張樹立標相，所以作了兩種會通：初結界時若有人來，就構成訶止與別眾；結界之後倘若到來，縱使訶止也不能成立，所引用的事例可以明白看出。

【1672-0012】03_業疏/08b_卷二之二#43
【原文】今解：前後皆成。結齊身坐，正為絕訶，豈得前閉後開？義不可也。律無開語，何得輒通？如所開遮，不勞身界，既結無外，明不容訶，故文云「得訶人者，謂善比丘在同住地」，餘無有文，不可用也
【譯文】今師解釋：前後兩種情況羯磨都能成就。結界齊同於身坐之處，正是為了阻絕訶止，豈能前面閉塞而後面開許？在義理上是不通的。律文中沒有開許之語，怎能擅自會通？如同所開許與遮止的，無須勞費結此身界，既然結界之外沒有界域，顯然就不容許訶止，所以律文說「能夠訶止的人，是指善比丘在同一住地之內」，其餘並無明文，不可採用古說。

【1672-0013】03_業疏/08b_卷二之二#44
【原文】今斥中，初斥非理。若依立相，初結、結後並成訶別，何得輒判？「律」下，次斥違文。「既」下，示今意。既不立相，了無倚身來訶之義，故下引文證，可驗古師妄判無取
【譯文】在今師的斥責中，首先斥責其不合道理。如果依照樹立標相的主張，初結與結後都應當構成訶止與別眾，怎能擅自如此判定？自「律」以下，其次斥責其違背律文。自「既」以下，顯示今師本意。既然不立標相，全無挨靠著身體前來訶止的道理，所以下文引律文作證，可以驗知古師是妄加判定而不可採信。

【1672-0014】03_業疏/08b_卷二之二#45
【原文】三、處留久固者，以因難生權，開加結，難非常，有結寧永固？必又開久，用大界為？故文中「即解而去」者：一、為餘人迷相，雖解不成；二、為恐後結界，能遮作法；三、為臨機一教，非為重集。違斯專制，故乖正法也
【譯文】第三、處所保留久遠穩固的過失。因為是因難緣而生起權變，才開許另加結界，難緣不是常態，所結之界豈能永遠穩固？如果必定又開許留存長久，那要大界做什麼呢？所以律文中說「立即解除界限而離去」，原因有三：第一、唯恐其餘的人迷失標相，即使作法解界也不能成辦；第二、唯恐阻礙後來的結界，能夠遮障後來的作法；第三、因為這是臨機應變的一時教法，不是為了重複集合之用。違背上述佛制而擅自專行保留小界，所以在道理上乖違了正法。

【1672-0015】03_業疏/08b_卷二之二#46
【原文】三中初敘非久所以。「用大界為」，言無所濟也。故下準制解責非，次列三義。二中以界不重結，留則遮後。「違」下，結斥專制，謂擅行也
【譯文】在第三段中，首先敘述不應持久的原因。「用大界為」是說小界若長留，大界就毫無用處了。自「故」以下依照制定解界之文責難其錯誤，其次列出三種意義。第二義中由於界域不能重疊結立，若保留小界就會阻礙後來的作法。自「違」以下，總結斥責其擅專制定，就是指擅自行事。
