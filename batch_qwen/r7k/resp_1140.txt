以下按「實質誤譯 → 用语／科判不當 → 術語不一致 → 建議加註」分層整理，並附修訂示例。整體而言譯文流暢、科判掌握大致無誤，但有幾處**義理方向性錯誤**與**主語混淆**需要改。

---

## 一、實質性問題（建議必改）

### 1. 【0001】「亦表法、食有隔」——方向譯錯了
譯文：「這也象徵著**如法羯磨之法事與受用飲食產生了隔閡**」。

依【0003】《記》自身的解釋：「『不共同味』是食別，即**利不和**；以事表法，法亦有乖，即**戒、見不和**，故云『法食隔』。」
可見「法食隔」是說**法（戒和、見和）與食（利和）兩邊都乖隔**（六和敬中三項失和），不是「法事」與「飲食」彼此之間產生隔閡。

建議改：「同時也表顯在『法』（戒和、見和）與『食』（利和）兩方面都有所乖隔。」

另：【0003】句末譯成「法與食產生隔閡」，雖較接近，但與【0001】講法不一致，兩處應統一。

### 2. 【0001】「眾別食」不宜譯為「個別受食」
譯文：「應該稱作『私組之眾**個別受食**（眾別食）』」。

《記》明說「『從語論』者，**能所便也**」——這是語法上「能／所」的順暢問題：既然《律》據能別之人立名，「眾」就是**能別的主語**，故應作「眾別（他）食」。譯成「個別受食」會誤導成「各人各自吃」，與「四人以上同處共食」正相違反。

建議改：「應稱作『（能別之）眾別離大眾而食（眾別食）』」。

### 3. 【0005】第二緣「別請、別乞」——主語混淆
譯文：「施主特別個別指定邀請、**個別乞求**」。

「別請」是**施主**別別請四人以上（不依僧次）；「別乞」是**比丘**各別乞得食，然後共集一處同食。譯文把兩者都歸給施主，且「個別乞求」語意不明。

建議改：「二、別請（施主個別指定邀請四人以上）或別乞（比丘各別乞食後，共聚一處同食）」。

### 4. 【0006】「犯下四篇，亦成別眾」語意含混
譯文：「若是觸犯下四篇罪的比丘，**依然會構成別眾**」——容易讀成「他自己犯別眾食」。

原意是：此戒所簡之「境」只取「清淨一色」（未犯重／波羅夷者），犯僧殘以下四篇者**仍算入僧數、仍成其別眾之境**。

建議改：「即使是犯了下四篇（僧殘以下）罪的比丘，仍計入『眾』數而構成別眾（之境）」。
同段「法、食罪異」宜點明「法」指**別眾羯磨（法事）**：「別眾法事與別眾食所結之罪雖不同，但簡別對象（境）的標準大體相同。」

### 5. 【0007】「廣分蹊徑」被譯成假設句
譯文：「**若**詳細剖析其微細的途徑，非常有其源由與意趣」。

原文是陳述：《鈔》中於七緣廣開細分門徑，各有缘由意趣，故「可如《鈔》中依緣點（示）」。加「若」使語氣轉為條件，且與下句「若又列來」的「若」重複混淆。

建議改：「解釋此戒七緣，（《鈔》中）廣為細分門徑，各有其缘由與意趣，可參照《行事鈔》中逐緣所作的點示。」

### 6. 「文云」一律譯作「經文」（【0001】【0003】【0004】【0008】）
此處所引皆《四分律》律文／戒本之文，非「經」。【0001】已把《律》譯為《律藏》，卻又把「文云」譯成「經文」，前後矛盾。請一律改為「律文」；【0008】「今此附文」宜作「此疏依附戒本之文而釋」。

## 二、用語與科判可再斟酌

| 出處 | 譯文 | 問題／建議 |
|---|---|---|
| 0001 | 「不與大眾共同享用**同等滋味**」 | 偏字面。「同味」即同食、同其食味，重點在**利養不共（利不和）**。宜「不與大眾同食共味（利不和）」。 |
| 0001 | 「所以**在形成小團體之處**便構成犯戒之罪」 | 「故眾處得罪」是說**罪結在能別之眾這一邊**（與下句「所別之處」對舉）。宜「故於能別之眾這一邊結罪」。 |
| 0001 | 「只要邀請三個人受食，我們就不會構成脫離大眾聚食**的緣故**」 | 句尾硬留「故」不成白話。宜：「（施主）但請三人來食，我等便不成別眾（故不犯）。」 |
| 0001 | 「私自分組」「小團體」 | 帶貶義且與【0005】【0009】的「結成僧眾」不一致；「成眾」是術語（四人以上），宜統一作「成眾（四人以上同處共食）」。 |
| 0003 | 「第一點到『得罪』為止」 | 「初至得罪」指**疏文從開頭至「得罪」**，非「第一點」。 |
| 0003 | 「**經文的義理**十分顯著」 | 「文理顯然」＝**文字與義理**都明顯，漏了「文」。 |
| 0003 | 「會通語句表達的**文相**」 | 「會言相」是會通**名稱用語**（何以名「別眾」而不名「眾別」）。 |
| 0003 | 「提婆達多**結夥的原由**，是為了脫離原本的正法僧團」 | 「本緣」指**制戒本緣**；「別正眾」是別離如法大眾。宜「就制戒本緣——調達別離如法大眾（正眾）——而立名」。 |
| 0008 | 「**標示指南**（標指）」 | 「標指」＝標舉指示（指廣、示要），非「指南」。宜「標舉指示（標指）」。 |
| 0008 | 「**暫且適宜**簡要解釋」 | 「且宜略釋」＝姑且只宜略釋。 |
| 0009 | 「就此區分為**三種情況**」 | 「就分為三」多指下文的**三門／三段科判**，宜先看下文再定；若為科分，作「就此分為三門（三段）」。 |

## 三、建議補註（不補也不算錯，但讀者不易懂）

1. 【0005】「五正」＝五種正食（飯、麨、乾飯、魚、肉）；「時中」＝明相出至正午之「時」。
2. 【0005】第五緣宜補足關鍵語意：明知同一界內**另有未受請、未同食的清淨比丘**——這才是成犯之要。
3. 【0005】「七、咽食犯」宜註「咽咽結罪（每吞一口結一罪）」。
4. 【0005】「僧食」譯作「僧團**常住**食」略嫌窄（常住只是僧食之一類），依【0006】「十方共分」宜作「僧食（十方僧共有之食）」。
5. 【0006】「不作相」語意較隱晦（作白告知大眾／囑授之相），建議加註並標「待考」，不宜逕譯為「未作相告知」而不說明。
6. 【0003】原文「不共同**殊**」與疏文「不共同**味**」不合，係訛字；譯文已逕改「味」，宜出校注說明「殊，疑當作味，今據疏文改」，以免讀者誤以為原文如此。

## 四、修訂示例（【0001】）

> 【疏文】第二、解釋名稱（釋名）。只就能別離（大眾）之人而言：其在受食之處四人以上同處共食而成眾，以此「眾」別離於其餘比丘，不與大眾同食共味（即利不和）；同時亦表顯「法」（戒和、見和）與「食」（利和）兩方面皆有乖隔，所以罪結在能別之眾這一邊。被別離的一方，難道不也是「眾」嗎？然而《四分律》是就能別之人立論，故律文說：「別眾食者，四人，若過（四人或四人以上）。」若純就語句上能別、所別的順暢來說，應稱「眾別食」（能別之眾別離大眾而食）；只是為取制戒本意（調達別離正眾之本緣），故仍稱「別眾」罷了。若是三人以下，則無上述「法乖、食別」兩種損害。故律文說：「（施主）但請三人食，我等便不成別眾。」

## 五、術語統一表（供全篇比照）

- 別眾食 → 保留原詞，注「四人以上於同一界內別離大眾而共食」
- 能別／所別 → 「能別（主動別離者）／所別（被別離之大眾）」，勿交替使用「能私自分組／能脫離／能分組」
- 成眾 → 「成眾（四人以上）」，勿用「小團體」
- 善比丘 → 「善比丘（未犯重罪、清淨一色者）」
- 文云 → 「律文說」；《鈔》→《行事鈔》；《律》→《四分律》
