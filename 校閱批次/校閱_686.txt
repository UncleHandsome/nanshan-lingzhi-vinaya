# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【686-0001】01_行事鈔/07c_卷中之三#5
【原文】初中，《五分》云：佛未制前，比丘各不受食。白衣訶言，我不喜見著割截壞色衣人，不受食食，是為不與取。《多論》五義故：一為斷盜竊因緣，二為作證明，三為止誹謗，四為成少欲知足，五為物生信令外道得益。昔有比丘，與外道共行，止果樹下。比丘不上樹，不搖果，又不肯就地取，並答言佛不許作。外道知佛法清淨，即隨佛出家，尋得漏盡。
【譯文】第一部分（制受意），《五分律》說：佛陀尚未制定此戒之前，比丘們各自都不經受食就自行拿取食物。在家人（白衣）呵責說：「我很不喜歡看到穿著割截碎布染成壞色衣的人，不經別人給予就自取食物來吃，這是不與而取（偷盜）。」《薩婆多論》提出五種意義：第一是為了斷除偷盜的嫌疑和因緣；第二是為了有人作為給予的證明；第三是為了平息外界的毀謗；第四是為了成就少欲知足的德行；第五是為了讓眾生生起信心、使外道獲得法益。從前有一位比丘，與外道同行，停宿在果樹下。比丘不爬上樹，也不搖動果樹，更不肯從地上撿取，並回答說佛陀不允許這樣做。外道得知佛法如此清淨嚴整，隨即跟隨佛陀出家，不久便證得漏盡通（阿羅漢果）。

【686-0002】資持記/10a_中三下#47
【原文】三十九。〔佛在舍衛，人為父母等，於四衢道乃至廟中祭祀供養；糞掃衣乞食比丘自取食之，俗譏因制。〕名中。比丘凡食，必從人受；故違此教，名不受食。然受兼手口，食通四藥，如後具明。制意中，初引《五分》。白衣訶詞，義分三過。他不喜者，招譏謗也。著割截衣者，不生物善也。
【譯文】第三十九條。〔佛在舍衛國時，有人為了父母等過世親人，在十字路口乃至神廟中設祭供養；穿糞掃衣乞食的比丘自己拿來吃了，世俗譏嫌，佛因此制戒。〕在戒名中。比丘凡是要進食，必須由別人授予；故意違背這項教誡，就叫做不受食。然而受食兼具手受和口受，進食通於四種藥物，後面會詳細說明。在制戒意圖中，首先引用《五分律》。在家人呵責的話語，在義理上分為三種過失。令他人不高興，是招致譏諷毀謗。穿著割截的袈裟而妄取，是無法在眾生中生起善心。

【686-0003】01_行事鈔/07c_卷中之三#6
【原文】二能受者，是比丘。《了論》：能令受者，具戒比丘，住於自性，求得在此處。解云：能受者，清淨持戒無毀，故言住自性；欲求飲食，名為求得；此處受食，即度與餘比丘，不須更受，即名此比丘為能受。若破戒、被擯、別住、十三難、三舉、滅擯、應滅擯、學悔等人，不成受故。
【譯文】第二、能受食的人，是指比丘。《律二十二明了論》說：能夠使受食成立的人，是具足戒比丘，安住在清淨自性中，在此處求得食物。解釋說：所謂「能受者」，是指清淨持守戒律、沒有毀犯，所以稱為「住自性」；想要乞求飲食，稱為「求得」；在此處接受了食物，隨即轉遞給其他比丘，其他比丘就不需要再次接受授予，因此稱這位比丘為能受者。如果是破戒者、被驅擯者、行別住者、具十三難（出家十三遮難）者、被作三種舉罰（三舉）者、被滅擯（終身逐出僧團）者、應當被滅擯者、行學悔（行摩那埵）等人，他們受食是不能成立的。

【686-0004】資持記/10a_中三下#48
【原文】不與取者，同盜竊也。後制此戒，即反三過以為三益。《多論》，五義。初為防重盜。二假彼能授，證非竊盜。三四易會。五中引緣，顯示生信。初外道令比丘上樹，比丘言我法樹過人頭不應上；又令搖樹取果，比丘言我法不得搖落果〔不壞生故〕；
【譯文】不給予而自取，等同於盜竊。後來制定這條戒，就是反轉這三種過失而成為三種利益。《多論》列出五種用意。第一是為了防範重大的偷盜。第二是藉由對方的授予，證實自己不是偷盜。第三和第四條容易理解。第五條中引用因緣，顯示令人生起信心。起初外道讓比丘爬到樹上，比丘說「我的戒法規定樹木超過人頭高就不應當上去」；外道又讓他搖動樹木取下果實，比丘說「我的戒法規定不可以搖落果實〔因為不能損壞生長的草木〕」；

【686-0005】資持記/16c_下四#38
【原文】沙彌生法二年以分上下，故須雙念。十數中。第一但出外計。《業疏》續云：佛法不爾，身假食資。食取濟形，道取濟神。故假形食，緣修道行。至論道也，要修離著為本；不識道元，乃以斷食為道，故須破之。二中。疏云：佛法不爾。內報外報，皆有本因。諸眾生有，皆因名色。〔名，即心也。
【譯文】沙彌則需要依據肉身出生的歲數與受法的年限，兩者兼看以區分僧團中的長幼次序，因此必須兩者同時繫念。在十數之中。第一數外道的主張完全是凡夫邪計。《業疏》接著闡述道：佛法完全不是外道所說的那樣，人的色身必須假借食物來滋養維持。食物是用來保全生命形體，正道則是用來長養心性神識。因此暫時假借飲食滋養形體，作為因緣以修持正道之行。若真要探究正道本體，必定以修持遠離一切貪愛執著為根本；外道不識正道的源頭本質，竟然把斷絕飲食當作得道，所以必須予以痛斥破除。在第二數中。註疏中說：佛法並非如此。無論是正報的身心還是依報的世界，都有其根本因緣。一切眾生之所以流轉三有，都是源於「名色」。〔名，指的就是心識。

【686-0006】01_行事鈔/12b_卷下之四#37
【原文】四明隨戒相。沙彌行事，法用同僧；羯磨一法，不在數例；自餘眾行，並制同修。如說戒自恣，既是常行，不得別眾；約盡界集，自然遠近，亦同僧法。《明了論》中，乃至優婆塞，亦有別界別施。所對之人，昔用比丘。今解不然。各別有法，兩不足數，不可通用，還以沙彌為對；無者，同僧心念也。《五百問》中，無沙彌，大比丘亦同作法。亦隨所存。
【譯文】第四、說明隨順戒相的行持。沙彌的日常行事規範，其行持法則大體與比丘僧相同；唯有參與僧伽羯磨表決一法，沙彌不列入僧數的法定資格中；至於其餘一切僧團大眾行持，佛制都要求共同修持。例如每半月的說戒與安居結束時的自恣，既然是僧團的常規行事，沙彌就不得隨意私自分別立眾；以結界劃定的全界內必須全體集會，隨自然界的遠近範圍，這一點也完全與比丘僧法相同。《律二十二明了論》中記載，甚至連優婆塞（在家男居士），也各有住處、各有施主標意布施之法。關於沙彌說戒等所面對秉白懺悔的對首之人，過去的古德主張借用比丘為對象。現在我的理解並非如此。因為比丘與沙彌各別有其戒法軌則，彼此都不能計入對方的僧數，不可通用互代，沙彌還是應當以其他清淨沙彌作為對首之人；如果找不到其他沙彌，就同比丘僧法一樣以「心念法」來自陳作法。《五百問事》中則說，若是沒有其他沙彌在場，大比丘也可以共同陪同作法。這可以隨各人所依循的見解行持。

【686-0007】資持記/16c_下四#39
【原文】心不可見，止可名談。初始識支，故轉為名；假染持識，即染為色。託彼胎藏，展轉增長；月滿便生，何得自然也。三中。前標云：痛痒想者，古翻語質，即三受也；痛即苦受，痒即樂受，想即捨受。文出外計。疏云：佛法不爾。生憎愛者，實由陰本，何干天也。
【譯文】心是無形無相看不見的，只能藉由名稱加以指涉宣說。投胎最初一念的識支，轉化立名為「名」；假借父精母血的染愛以受持心識，這血肉體質就稱為「色」。寄託在母體的胎藏之中，隨著時日輾轉長大增厚；懷胎十月圓滿便降生人間，哪裡是外道胡說的「自然而生」呢。在第三數中。前面標示說「痛痒想」，這是古代翻譯的古樸名詞，指的就是苦、樂、捨三受；「痛」就是苦受，「痒」就是樂受，「想」在此處即代表不苦不樂的捨受。文句是引述外道的錯誤見解。註疏中說：佛法完全不是這樣。眾生之所以生起憎惡與貪愛，根本是由於五陰業因所致，跟大梵天或天神有什麼關係呢！

【686-0008】資持記/16c_下四#40
【原文】初念緣色名識，了達染淨為想，領納違順曰受。由三想〔苦、樂、捨也〕，便生三受；由三受故，便有三行。故長淪歷，無解脫也。四中。疏云：佛法不爾。苦集世俗因果，滅道出世因果。眾生知苦無諦，聖人解苦有諦。凡聖皆由因果，那云無也！五中。
【譯文】最初一念緣取色境攀緣稱為「識」，明了通達境界是染是淨稱為「想」，領納逆境或順境稱為「受」。由苦、樂、捨三種分別之想，隨即生起苦、樂、捨三種受領納於心；因為有了三種受，便引發貪、瞋、癡三種造作之行。因此眾生長劫沉淪於生死巨浪之中，永遠找不到解脫的出路。在第四數中。註疏中說：佛法完全不是這樣。苦諦與集諦是世俗生死的流轉因果，滅諦與道諦則是出世間涅槃的還滅因果。凡夫眾生縱然身受無量痛苦卻不能明了苦諦的真實，出世聖人體解苦相因此具足通達真諦。無論凡夫還是聖人，都離不開因果業報的法則，外道怎能妄稱因果皆空無所有呢！

【原文】疏云：佛法廣破，我在何處？為在色中？為在識中？計此身中，但有五陰；隨陰計我，則有五種。如是離合〔為復五陰，各有一我，則是離也；若惟一我，則在色時，餘四應無，即是合也。〕，次第求之。覓我無從，便悟妄執；得無我理，分成無漏相似聖人。六中。扃，即門戶，疏作六窓。佛法不爾。
【譯文】在第五數中。註疏中說：佛法以廣大智慧全面破斥這種謬論，所謂的「我」究竟存在於何處？是在色身之中嗎？還是在心識之中？審視反觀這具身心，不過就只是五陰假和合而已；若執著於五陰之中有我，就會衍生出五種我見。像這樣透過「分開獨立」與「混合同一」〔究竟是五陰每一陰各自擁有一個獨立的我，這就是分開尋求；若只有唯一一個我，那麼當我在色身時，其餘受想行識四陰就該沒有我，這就是混合同一。〕，依次層層追究尋找。找尋自我根本了不可得，便能當下覺悟那純粹是虛妄的執著；一旦證悟「諸法無我」的真理，就能證入無漏解脫，分證相似位聖人的境界。在第六數中。「扃」就是指門戶，註疏中則寫作「六個窗戶」。佛法完全不是這樣主張。

【原文】識隨根起，若是一識，豈眼根中而聞聲耶！七中。却，即逆也。觀前為逆，觀後即順。疏云：由得五通，逆順觀中，八萬劫外，冥然不委，計為冥諦。轉縷丸者，舉喻顯也；謂以縷繫丸，高山放下；縷盡丸止，以喻無修。疏破云：佛法不爾。要須方便增修乃剋。
【譯文】眼、耳等心識是隨順各自的根門而生起的，如果六根裡面只有唯一同一個心識，難道眼睛能夠代替耳朵聽聞到聲音嗎！在第七數中。「却」就是逆向反觀的意思。向前逆推過去生稱為逆觀，向後順看未來世稱為順觀。註疏中說：外道因為修得了五種世俗神通，在逆推與順看的極限中，對於八萬大劫之外的幽遠境界，茫然無知無法徹底探究，於是便妄自執著該處為原始的「冥諦」。以「滾動絲線線團」為例，是舉出譬喻來彰顯其謬執；意思是把絲線繫在線團上，從萬仞高山向下丟擲；絲線放盡之時線團自然停止，以此比喻不需要修行、業盡自然解脫。註疏破斥道：佛法完全不是這樣。必須依賴方便善巧不斷精勤增上修持才能剋期證果。

【原文】如七覺支，簡擇正理，方能至詣，何有不修耶！八中。外道三學皆邪。烏雞等者，以見禽畜，今報已盡，遠業將起，生彼色天；不思遠因，謂即報是；便効彼畜，噉草不淨等。八禪，謂修世禪，謂為涅槃。邪慧，即彼所見；邪進，如投嵓臥灰棘等。佛法不爾。四依為聖道緣。

【686-0013】資持記/16c_下四#45
【原文】疏云：彼增修定，緣色住心；以色滅欲有，以空滅色有。今下，正破，上二句點非。十處，即是定相；謂地水火風、青黃赤白、空識，趣道初門，故名十入，亦名十遍處。如觀青色，初以少分青色觀之，使遍一切處皆青，乃至空識亦爾，故云自心運用。實下，顯正法。續引《智論》。示不得出離所以。
【譯文】註疏中說：外道努力增強修習定力，心念專注依附在物質色相上；企圖用物質色定來滅除欲界貪有，用虛空定境來滅除色界質礙。在「今」字以下，正式予以駁斥破除，前兩句直陳其非。所謂「十處」，就是十種禪定的相狀；指修持地、水、火、風四大，青、黃、赤、白四色，以及虛空與心識，這是趣向定境的初門，所以稱為「十入」，也稱作「十遍處」。比如修觀青色，最初先以極少部分的青色作為所緣境觀想，逐步擴大使其周遍一切處所全都化為青色，乃至觀想空與識也是如此，所以說這純粹是「自己心念刻意運轉作意」罷了。「實」字以下，顯露真正正法的實義。接著引用《大智度論》的教證。揭示出外道修定終究不得出離生死的真實緣由。
