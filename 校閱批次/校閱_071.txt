# 校閱材料　第071檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【071-0001】01_行事鈔/08c_卷中之四#29
【原文】四為說罪名種相、破戒餘習。先為說持破之相，後分別輕重悔法。當量前事告之。若是犯長者，云：比丘之法，本無積聚；《涅槃》文證，不名為僧；今以凡心違於佛教，甚可恥等。若離衣者，告云：佛言：我為諸弟子結戒，寧死不犯。比丘止有三衣鉢器，行必隨身，猶如飛鳥，無所顧戀。今慢佛正法，不制隨身，制者留著，豈成佛子。若離此衣，生名破戒之人；妄食信施，所執鉢盂，即洋銅器；所著衣者，是熱鐵鍱；出在《大論》，豈是凡言。乃至破戒餘習，破戒衣食故，入畜生中，別受無毛蟲鳥，噉糞眾生等。如是隨機，約略斬斫五三句要害事，以示語之。但犯罪長時，心智頑鈍，雖聞苦語，末足動心者；亦不必誡示，亦不勞為受，以相續故也。次為說罪名。名有三種：一者根本波逸提，此最後懺。二者從生根本三突吉羅，在根本前懺。三者從生覆藏六品吉羅，最在前懺。云何六品？一者根本覆吉羅，經初夜一品，第二夜一品，例餘著用、默妄，各有二品，通前六品。並據犯者言之。必無此九品，亦不得謹誦。大見誦者，故重言之。猶恐有誦者，知復柰何，當復柰何。今正初懺六品覆藏。律文在前，不得合墮。應請一比丘，即向所請者亦得，口言：「大德一心念！我某甲比丘，請大德為突吉羅懺悔主，願大德為我作突吉羅懺悔主。慈憫故！」三請已。二正悔罪，應言：「大德一心念！我某甲比丘，故畜眾多長衣不說淨，犯捨墮；離僧伽梨宿，犯一捨墮；並不發露犯突吉羅，經夜覆藏，隨夜展轉覆藏；并著用前犯捨衣突吉羅，經夜覆藏，隨夜展轉覆藏；經僧說戒，九處三問默妄突吉羅罪，經夜覆藏，隨夜展轉覆藏。如是六品，各是突吉羅，各不憶數。今向大德懺悔，不敢覆藏，願大德憶我！」告言：「自責心，生厭離！」答言「爾！」二次懺三小罪。根本、著用捨墮，律中，《善見》俱結罪名；說戒默妄，文亦同此。如前請訖，更不重言。但正懺本罪，應言：「大德一心念！我某甲比丘，故畜長財眾多不說淨，犯眾多波逸提罪；離僧伽梨，犯一波逸提罪；各經夜覆藏，犯突吉羅罪，如上多少；又經僧說戒，九處三問默妄突吉羅罪，不憶數；又著用不如法衣，犯眾多突吉羅罪。今向大德懺悔，願大德憶我！」呵責立誓如前。然懺法繁重，生善致難。恐停勞僧眾，當於捨衣前，別處悔九品小罪；臨至僧中，單題根本者，最是機要。
【譯文】四為說罪名種相、破戒餘習。首先為他解說持戒與破戒的事相，然後分別說明輕重不同的懺悔之法。應當考量他所犯的前事而教誡他。如果是犯蓄長物的人，便對他說：比丘的清淨法規，本來就沒有積聚財物之事；《涅槃經》有文為證，積聚財物者不得稱為僧寶；如今你以凡夫貪心違背佛陀的教誡，實在是非常可恥等等。如果是離衣宿的人，則教誡他說：佛陀說過，我為諸位弟子制定禁戒，寧可捨命也決不違犯。比丘身邊只有三衣與鉢器，行住起居必定隨身攜帶，如同飛鳥雙翼隨身，無所留戀顧盼。如今你輕慢佛陀正法，佛未制令隨身攜帶的物品反而隨身攜帶，佛制令隨身攜帶的衣鉢反而留置住處，這哪裡算得上佛子？如果離開了這三衣過夜，活著就背負破戒之人的惡名；虛妄受食信眾的布施，手中所端持的鉢盂，就等於是熔化的銅汁鐵器；身上所穿著的衣服，就如同燃燒的熱鐵鍱片；這都出自《大論》（《大智度論》），難道是凡夫的妄語嗎？乃至破戒所招感的殘餘習氣惡報，因為破戒而受用衣服飲食的緣故，死後墮入畜生道中，受生為沒有羽毛的蟲鳥、噉食糞便的骯髒眾生等。像這樣順應對方的根機，扼要切中要害地講說三五句切膚痛切的話，來告誡開示他。然而如果犯罪日久，心智已變得頑固魯鈍，雖然聽到了切責的苦口良言，仍舊不足以打動其心的人；那也就不必再費辭誡勉開示，也無須勞費心思為他受懺，因為他的惡心相續未斷的緣故。其次為他宣說罪名。罪名有三種：第一是根本波逸提罪，這要留到最後懺除。第二是從此衍生出的三種根本突吉羅罪，在懺悔根本罪之前懺除。第三是因隱瞞掩蓋而衍生的六品突吉羅罪，必須在最先懺除。什麼是六品呢？第一是根本罪隱瞞掩蓋的突吉羅，經過第一夜算一品，經過第二夜又算一品；其餘穿著使用該衣、以及說戒時沈默妄語所犯之罪，也都各經過兩夜而成二品，連同前述合為六品。這都是據實有犯的情況而言的。如果確實沒有這九品罪，也絕不能刻板死誦文句。我常看見許多盲目照誦的人，所以在此鄭重叮嚀。即便如此，恐怕還是有人照本宣讀，真是讓人無可奈何，又能拿他怎麼樣呢？現在首先正式懺悔這六品覆藏罪。律文中規定在前，不得與捨墮本罪合併懺悔。應當延請一位比丘，即使是向剛才所請的那位懺悔主也可以，口中說道：「大德一心念！我某甲比丘，恭請大德作突吉羅罪的懺悔主，祈願大德為我作突吉羅懺悔主。請慈悲愍念！」三請完畢。第二是正式悔罪，應當說：「大德一心念！我某甲比丘，故意蓄存眾多長衣未作說淨，犯捨墮；故意離僧伽梨過夜，犯一捨墮；並且不發露而犯了突吉羅罪，經夜隱瞞掩蓋，隨每夜輾轉隱瞞；以及穿著使用前述應捨之衣犯突吉羅罪，經夜隱瞞掩蓋，隨每夜輾轉隱瞞；經歷僧團說戒，在九處三番詢問時沈默妄語犯突吉羅罪，經夜隱瞞掩蓋，隨每夜輾轉隱瞞。像這六品，每一品都是突吉羅罪，各自不記得次數。如今向大德發露懺悔，不敢隱瞞掩蓋，祈願大德憶念我已清淨！」懺主告誡說：「汝當自責己心，生起厭離！」犯者答道：「是！」第二次懺悔三種小罪。最初覆藏（根本覆藏）與穿著使用應捨之衣，在律藏本集與《善見》（《善見律毗婆沙》）中都判結為突吉羅罪名；說戒時沈默妄語，文獻中亦同此定罪。如前述延請完畢，不再重複請詞。只需正式懺悔本罪，應當說道：「大德一心念！我某甲比丘，故意蓄存長財眾多未作說淨，犯了眾多波逸提罪；離僧伽梨過夜，犯了一波逸提罪；各自經夜隱瞞掩蓋，犯突吉羅罪，如上述的數量；又經歷僧團說戒，在九處三番詢問時沈默妄語犯突吉羅罪，不記得次數；又穿著使用不如法的衣物，犯了眾多突吉羅罪。如今向大德發露懺悔，祈願大德憶念我已清淨！」其呵責與立誓的儀式同前。然而這種懺法極其繁瑣沉重，想要由此生起善法實在很難。唯恐久停而勞擾僧眾，應當在前往僧中捨衣之前，先在別處懺悔完這九品小罪；等到來到僧團之中，單純提出根本罪來懺悔，這才是最為契機緊要的做法。

【071-0002】01_行事鈔/08c_卷中之四#30
【原文】五正悔本罪法。應在受悔人前，具儀，口云：「大德一心念！我某甲比丘，故畜長衣眾多，不說淨，犯捨墮；故離僧伽梨，犯捨墮。此衣物已捨與僧。各犯波逸提罪，如上犯數；又犯長捨財，已用壞盡；各犯根本波逸提罪，不憶數。今向大德發露懺悔，不敢覆藏；懺悔則安樂，不懺悔不安樂，憶念犯發露，知而不敢覆藏。願大德憶我清淨，戒身具足，清淨布薩！」
【譯文】五正悔本罪法。應在受悔人前，具儀，口中說道：「大德一心念！我某甲比丘，故意蓄存長衣眾多，未作說淨，犯了捨墮罪；故意離開僧伽梨過夜，犯了捨墮罪。這些衣物已經捨給僧團。各自違犯了波逸提罪，數量如同上述所犯之數；又犯蓄長應捨之財物，已經使用損壞耗盡；各自犯了根本波逸提罪，不記得犯了多少次。如今向大德發露懺悔，不敢覆藏；懺悔則身心安樂，不懺悔則不安樂，憶念所犯即行發露，明知犯戒不敢覆藏。祈願大德憶念我身心已得清淨，戒身具足完滿，得以清淨布薩！」

【071-0004】01_行事鈔/08c_卷中之四#32

【譯文】第七是立誓，犯者應當回答說：「是！」

【原文】六懺突吉羅法。此篇懺儀，亦有多別；先出方軌，後立條例。突吉羅罪，依律文中二種不同：一故作故犯，應懺突吉羅，又犯非威儀突吉羅；二若不故作，犯非威儀突吉羅。亦不分二懺之法。若依《摩夷論》說，故作者，對人一說悔；誤作者，責心悔。《明了論》、《薩婆多》亦同如此。此則兩懺灼然，通衢自顯。比來諸師，相㳂舊解，依文謹誦，同皆責心；又引律文，小罪不從人懺；此文未了，須論解之。當律明故誤二法，諸論明兩懺不同；正理自明，何得固執；人言易毀，聖論難違。今立論律二種懺法，先出罪種，後明懺儀。
【譯文】第六、懺除突吉羅罪的方法。此篇的懺悔儀式也有很多差別；以下先列出常規儀軌，隨後確立具體條例。突吉羅罪依據律文有兩種不同的情形：第一是故意造作、故意違犯的，結「應懺突吉羅」，同時又結「非威儀突吉羅」；第二若不是故意造作（誤犯），則結「非威儀突吉羅」；但律文中並未分開說明這兩種罪各用何種懺法。如果依據《摩夷論》所說：故意造作者，須對一人說一遍而懺悔（對首懺）；誤犯者，則於自心自責而懺悔（責心懺）。《明了論》與《薩婆多論》也同樣是這樣主張的。如此一來，兩種懺法涇渭分明，通達的正道自然顯露。近來的諸位律師，相沿襲用舊有解釋，僅拘泥於文句誦持，一概都判為責心懺；又引用律文說「小罪不向人懺悔」；其實律文此處說得未夠詳盡，必須依據論典來加以解釋。本律明文區分了「故犯」與「誤犯」兩種情況，而各部論典又明確指出了這兩種情況的懺法不同；正理昭然若揭，怎能頑固執著舊見呢？前人的個人說法容易破除，但聖賢的論典不可違背。因此，現在結合論典與律文確立這兩種懺法：先列出罪相種類，隨後說明懺悔儀軌。
