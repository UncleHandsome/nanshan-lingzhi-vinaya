# 校閱材料　第1208檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1208-0001】資持記/10c_中三下#55
【原文】恐忘前戒，略引緣成有八：一是大比丘，二作大比丘想，三內有瞋心，四無三根，五下至對一人說，六以殘罪加誣，七言詞了了，八前人知犯。八十一。〔佛在舍衛，未利夫人奉信，聽比丘入宮無障，迦留陀夷入宮，夫人拂床形露因制。〕初緣，剎利即四姓之長；
【譯文】擔心遺忘前面的戒條，所以簡要列出構成犯戒的八項犯緣：第一對方是大比丘，第二自己心中認同他是大比丘，第三內心懷有瞋恨誹謗之意，第四毫無見、聞、疑三根由據，第五至少對著一個人宣說，第六用僧殘重罪橫加誣陷，第七言詞明確表達清晰，第八所對之人聽懂領解，即構成犯戒。第八十一條戒。〔佛陀在舍衛國時，末利夫人虔敬奉信，准許比丘入宮毫無阻礙，迦留陀夷比丘進入王宮，夫人拂床形露因制。〕初緣，剎利即四姓之長；

【1208-0002】資持記/10c_中三下#56
【原文】律約灌頂受位，即《戒本》中水澆頭也。餘三姓如是立者，亦名灌頂。次緣同處，準下王未出，須約寢宮方犯；已外應輕。此土王庭不許輒入，事亦希也。四入門限者，疏云：深防而制，初入已結，何況見寶。釋中。粟散言餘小王如粟之多。不犯中，若有奏白，請喚，若命梵難。
【譯文】律中依據行灌頂禮而登基掌位，就是《戒本》中所說用水澆淋頭頂。其餘三種階級若同樣這樣冊立繼位，也稱為灌頂之王。第二個犯緣在同一處所，依照下文國王尚未離出的情況，必須嚴格界定在寢宮才會犯戒；寢宮之外的地方處罰應當較輕。在東土中原君王的朝廷是不許擅自闖入的，這種事情本來就極為罕見。第四項「跨入門檻」，《戒疏》說：這是為了深加防患而制戒，剛跨入時就已經結罪，更何況是親眼見到宮中女寶（后妃）。在解釋中。「粟散」是說其餘的小國君王如同散落的粟粒那麼多。不犯的情況：如果有國事奏稟陳白、受到國王傳喚邀請、或者是為了逃避危及生命或毀壞梵行的危難等。

【1208-0003】資持記/10c_中三下#57
【原文】八十二。〔佛在舍衛，外道路中止息，忘千兩金，比丘見之持還，便言金少，王斷罰謫入宮，因制。〕正名中，初示名有據。論如下引。因下，廢古所立。彼執緣起，謂拾遺犯提，手捉但吉，故召為拾遺。戒緣中。此戒犯相有二：若但捉寶，唯有三緣，初二及五；若於聚落，拾他遺寶，方具五緣；
【譯文】第八十二條戒。〔佛陀在舍衛國時，有外道在路途中間歇息，遺忘了千兩黃金，比丘看見了替他收存送還，外道竟然反咬誣陷說金子短少了，國王查核後對其施以罰責送入宮中，佛陀因而制戒。〕在確立戒名中，首先表明戒名是有經論根據的。論典的依據如下文所引。「因」字以下，廢棄古代大德所立的名目。彼等拘泥於制戒的由來起因，認為拾取遺失物犯波逸提罪，親手觸摸只是結突吉羅罪，所以稱之為「拾遺戒」。在戒條犯緣中。這條戒的犯戒相狀有兩種：如果單純是觸摸捉持寶物，只有三種犯緣，也就是第一、第二及第五項；如果是在村莊聚落之中，拾取他人遺失的寶物，才需要具備全部五種犯緣；

【1208-0004】資持記/10c_中三下#58
【原文】共拾遺衣，但應得吉；伽灆宿處，有寶無寶，一切開拾。如下引明。三非住處，即非伽灆；及宿處者，謂非俗舍。釋第一中，《多論》，初明真寶。七名即金、銀、摩尼、真殊、珊瑚、硨礛、碼碯，律中又有琥珀、琉璃、具玉。〔彼論錢入似寶。〕若下，次明似寶。取得吉者，論云為畜故取也。
【譯文】若是撿拾遺落的衣服，只應當結突吉羅罪；在僧寺僧伽藍以及寄宿處，無論遺失的是不是寶物，一切都開許撿拾保管。正如文後引用闡明。第三項「非住處及宿處」，非住處是指並非僧伽藍，非宿處是指並非俗人居舍。在解釋第一項中，《薩婆多論》首先說明真正的寶物。七種名稱就是金、銀、摩尼寶珠、真珠、珊瑚、硨磲、瑪瑙，律中另外還有琥珀、琉璃、美玉。〔彼論將銅錢列入似寶之中。〕「若」字以下，接著說明似寶。拿取結突吉羅罪，是論中說因為想蓄積佔有而拿取。

【1208-0005】資持記/10c_中三下#59
【原文】不取者，論作不應自取，如法說淨。〔準不為畜，捉應無過。〕上文通論畜捉。若捉下，單明捉犯。金薄謂裹貼之物，金像或貼或鑄者。似寶入百一，捉畜皆開，已外俱吉。《僧祇》中，初通明制意。知事當開，教亦不許，而況餘人，故云乃至。若下，別示供具又三，初通列供會。供養具下，明鋪設供興。
【譯文】「不自取」，在論中寫作不應當自己拿取，應當如法說淨轉移。〔照此推論如果不為了蓄積，單純觸摸應當沒有罪過。〕上文是通貫討論蓄積與觸摸。「若捉」以下，單獨說明觸摸的結罪。金箔是指包裹張貼之物，金像有的是貼金箔有的是鑄金造成的。似寶如果屬於百一長物之內，觸摸與蓄積都開許不犯，在此之外的情況全都要結突吉羅罪。《僧祇律》中，首先全面闡述制戒的意圖。僧團知事原本應當開許，教法中尚且不許他觸碰，更何況是其餘尋常人，所以說「乃至」。「若」字以下，分別開示各類供具又有三項，首先通列種種供養法會。「供養具」以下，說明鋪設陳列供品法器。

【1208-0006】資持記/10c_中三下#60
【原文】裹手捉者，恐損壞故，暫開佐助；世有持戒者，裹手捉錢，愚教之甚。若浴下，正明浴像。不得後放者，必須先放，意表助他故。釋第二中，《多論》，初明女飾。下簡男物。兵樂二器，捉亦犯吉，所以除之。矟所角反，矛之長者。若下，明使同類，能所俱重。律下，次引本律。即不犯中文。
【譯文】以布裹手觸拿，是擔心器物損壞，所以暫時開許從旁輔助協助；世間有些自命持戒的人，用布包裹著手去拿錢幣，這真是愚昧不解教理到了極點。「若浴」以下，正式說明浴佛像的規定。「不得後放」，是必須（比淨人）先放手，用意在於表明自己只是輔助他人洗沐。在解釋第二項中，《薩婆多論》首先說明婦女的飾品。下文簡別男子的用品。兵器與樂器這兩種器具，觸摸了也犯突吉羅罪，所以將其排除。矟，音所角反，指的是長矛。「若」字以下，說明若是差使同類比丘（捉寶），能使者與被使者罪過同樣沉重（皆犯墮罪）。在「律」字以下，接著引用本律。就是指不犯條文中的文字。

【1208-0007】資持記/10c_中三下#61
【原文】與上相違，故注決之。下引論證。顯非常開。釋第三緣，《四分》，先明方便還他。言自捉者，據此拾遺明開自捉。二人同取，謂二人各來識認。語同謂二皆相應，無由辨故。若餘下，明無緣結犯。《僧祇》五節，初明拾衣。以物輕故，停三月；下是貴寶，故待三年。若貴下，次明拾寶。
【譯文】這與上文互相矛盾，所以特別作註解判定。下文引論證說明，彰顯這並不是尋常普遍的開許。解釋第三個犯緣，《四分律》首先說明想方設法歸還失主的權巧。所謂「自己捉持」，依據本條拾取遺物戒，是明確開許可以親手拿取的。兩個人一同來認領，是指兩個人分別前來指認。口說相符是指兩個人的說法都對得上，無從查驗辨別。「若餘」以下，說明沒有正當因緣而結犯。《僧祇律》分為五節，首先說明拾取衣服。因為衣服價值較輕，所以保管三個月；下文是指珍貴的寶物，所以必須保管三年。「若貴」以下，接著說明拾取貴重寶物。

【1208-0008】資持記/10c_中三下#62
【原文】由此貴物，多容妄認，故但屏看；異前衣也。受三歸者，因而接引。眼看不得者，明非汝分也。如上處所者，即隨佛僧用也。比丘下，三明失物作念。若心捨棄，後取成盜。客下，四明移他遺物。徙即訓移。言犯重者，此約盜心，恐彼還取故重；若為收藏，雖移無過。
【譯文】由於這種珍貴物品，最容易容許他人虛妄冒領，所以只能暗中私下查看；這點與前面撿到衣服不同。給失主受三歸依，是為了藉此機緣接引他入佛門。「用眼看不得」，是向他闡明這並不是你該得的那一份。「如上處所」，就是指隨順佛塔或僧團的用度來處置。「比丘」以下，第三項說明失主對失物生起的心念。如果失主內心已經徹底捨棄，後來再去取回便構成了盜戒。「客」字以下，第四項說明移動他人遺失的物品。「徙」字就是訓詁為遷移、移動。所謂「犯重罪」，這是依據心懷盜取之意而言，擔心失主返回取回所以判罪沉重；如果是為了代為收藏保管，雖然移動了也沒有過失。
