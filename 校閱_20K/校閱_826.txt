# 校閱材料　第826檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【826-0001】03_業疏/11a_卷二之五#76
【原文】次科，初通標。「出下」次別釋。前明出家菩薩有三：初、明形位同。他方諸佛多有聲聞、菩薩二種僧，不相參混；其菩薩僧不局形體。唯釋迦佛但有聲聞僧，不立菩薩僧，故諸大菩薩影響施化，皆須剃染稟戒，所以形位同聲聞也。此據一類機緣所見，然菩薩作用，不必常爾。故下二、明受隨同。「息世譏嫌」即諸遮戒，「性重無別」謂性遮等持也。浮囊多少者，彼明人欲渡海而須浮囊，有羅剎問乞，初全乞不與，次乞一半，三乞掌許，四乞指許，五乞微塵許，喻三毒欲犯五篇而皆不與，即喻堅持也。又下三、明急護同。無分別智，謂觀諸法如實平等故無分別，唯一真體，外塵本無故塵不顯現，亦名如理智，初地已上始得用之。方便即權巧。殺生等者，即十惡也。有利益者，謂利他也；自無染者，謂自利也；具此二利，雖行無犯；互有所缺，亦不行之，故云「縱有」等。今時愚人不量位地，不知權行，作惡無耻，妄引為例，自誤誤他，難可救也。後明在家菩薩，指淨名經。彼云：「雖為白衣，奉持沙門清淨戒行；雖處居家，不著三界；示有妻子，常修梵行；現有眷屬，常樂遠離；乃至入諸婬舍，示欲過等
【譯文】次科中，首先作總相標明。自「出下」以下，其次分別解釋。前段說明出家菩薩有三點：第一、說明形象與地位相同。他方世界諸佛大多有聲聞僧與菩薩僧兩種僧團，彼此不相混雜；菩薩僧團並不局限於出家形貌。唯獨釋迦牟尼佛的娑婆世界只有聲聞僧團，不另外設立菩薩僧團，所以各大菩薩作為影響眾施行教化時，都必須剃除鬚髮、身著染衣而稟受戒律，因此形象與地位和聲聞相同。這是依據一類眾生的機緣所見而論，然而菩薩的示現作用，未必恆常如此。自「故下」以下，第二說明受戒與隨行相同。「息世譏嫌」就是指各條遮戒，「性重無別」是指性戒與遮戒同等堅持。所謂「浮囊多少」，是彼經說明有人想要渡過大海必須依賴浮囊，途中有羅剎前來乞討浮囊，起初乞討整個浮囊，人不給；次而乞討一半，也不給；第三次乞討手掌大小的一塊，不給；第四次乞討手指大小的一點，不給；第五次乞討微塵般大小的一點，依然不給；這比喻三毒煩惱引誘去違犯五篇戒相，而修行者絲毫也不違犯，即是比喻堅決持戒。自「又下」以下，第三說明緊要急迫護持相同。所謂「無分別智」，是指觀察一切諸法如實平等，因而沒有凡夫分別，唯有一真法界本體，外在妄塵本來虛妄，所以塵境不顯現，也稱為「如理智」，初地以上的菩薩才開始能夠運用。方便就是指權巧智慧。「殺生等」，就是指十惡業。「有利益」，是指能利益他人；「自無染」，是指自己無有貪染過失；具備這兩種利益，雖然行作也無有犯戒過咎；如果互相缺少了一項，也是絕不施行的，所以說「縱有利益」等。如今世上的愚昧之人，不自量自己的修行果位，不懂得權巧方便的深意，作惡無恥，胡亂引證這段話作為自己的藉口，自誤誤他，實在難以救藥！最後說明在家菩薩，指引《維摩詰經》（淨名經）。該經說：「雖然是在家人身分，卻嚴謹奉持沙門的清淨戒行；雖然生活在居家環境，卻不貪著三界凡塵；示現娶妻生子，卻常修清淨梵行；示現擁有眷屬，內心卻常樂遠離；乃至走入各處淫舍妓院，只為示現愛欲的過患」等。

【826-0003】03_業疏/11a_卷二之五#78
【原文】次定慧中，謂眾生心體本來明靜，妄起昏動，遂致流浪。若達唯心，無別餘法，當知昏動體即明靜，定慧寂照，同出異名。此理幽遠，末世機劣，非彼所聞，縱聞不行，言之何益？故略不明，但悲歎而已。如淨心觀、歸敬儀等，亦略明之，自可尋也
【譯文】次定慧之中，是說眾生的心體本來就是光明沉靜的，只因妄念生起昏沉與動亂，才導致輪迴流浪。如果能了達萬法唯心、心外別無他法，就應當知道昏沉動亂的本體當下就是光明澄靜，定與慧的寂靜與照察，源自同一個自性本體而立不同的名稱。這個道理深奧幽微遠大，末法時代眾生根機微劣，不是他們所能理解聽聞的，縱使聽聞了也不會躬行實踐，說了又有何益處呢？所以簡略而不加明說，只是發出悲傷慨嘆罷了。如同《淨心誡觀法》、《釋門歸敬儀》等著作中，也曾簡略闡明此理，讀者自己可以去查閱尋求。

【826-0019】03_業疏/11a_卷二之五#94
【原文】乞食非法者，謂擇富去貧、離難從易、棄惡取好，皆非次第，越威儀也。五分佛未立二師，故威儀改常，自手取食，不從人受，就他手中抄撥而取，手捻鉢緣，不擎受食。斯之妄法，往往盛行，可通改也
【譯文】所謂乞食不合法度，是指挑選富貴人家而避開貧窮人家、避開艱難處所而專走容易之處、拋棄粗惡食物而選取美好飲食，這些都不合乎次第乞食的規矩，違越了威儀法則。《五分律》中記載，佛陀尚未設立和尚、阿闍梨二師之時，僧眾的威儀失去了常軌，自己伸手拿取食物而不由施主授與，直接在施主手中抓扒取食，或者用手指捏拿缽緣而不雙手端擎缽具接受布施。像這樣的荒妄非法的行徑，在世間往往盛行，理應全面加以糾正改革。

【826-0020】03_業疏/11a_卷二之五#95
【原文】四中初牒釋。擇富去貧是分別過，離難從易是懈怠過，棄惡取好即貪嗜過。「五下」引緣。自手取食，一向不受也；就手抄取，受而乖法也；捻緣不擎，非受儀也。「斯下」誡勸
【譯文】第四科中首先引文解釋。挑選富戶避開貧戶屬於分別心之過失，避難就易屬於懈怠懶惰之過失，棄粗取精即屬於貪愛美食之過失。自「五下」以下引證制戒因緣。自己伸手取食，是完全不遵從受食之法；在別人手中抓取，是雖受食而違背軌則；捏著缽緣而不端擎，是不合乎受食的威儀。自「斯下」以下為誡勉與勸告。

【826-0021】03_業疏/11a_卷二之五#96
【原文】處處受不淨鉢食者，謂起諸邪命、不淨殘宿、穢染不洗器也。皆不信鎔銅灌咽之苦，故其相多也
【譯文】所謂到處接受不潔淨的缽中之食，是指生起種種邪命求食、食用不淨殘食與過夜殘宿之食、使用污穢染垢而不清洗的食器。這些人都是不相信將來會遭受熔銅灌注咽喉的劇苦，所以這種違犯的行相才如此多見。

【826-0022】03_業疏/11a_卷二之五#97
【原文】五中初牒釋不淨鉢食。律云「處處受不淨食，或受不淨鉢食」。邪命是體不淨；不淨殘宿，更收內宿、惡觸，竝緣不淨，此釋上不淨食也；穢染不洗，即器具不淨，此釋上不淨鉢也。「皆下」示意。不信來苦，故噉不淨。鎔銅灌咽，略舉一相，鐵丸火炭，獄報何窮
【譯文】第五科中首先引文解釋不淨缽食。律藏說「處處受不淨食，或受不淨鉢食」。依邪命而得的食物是自體不淨；不淨的殘食宿食，更包含在宿內之食（內宿）、被惡觸染污之食（惡觸），都屬於因緣不淨，這是解釋上面的「不淨食」；污穢染垢而不清洗，也就是飲食器具的不淨，這是解釋上面的「不淨鉢」。自「皆」字以下說明其意旨。因為不信未來的果報之苦，所以才敢吞食不淨之物。熔化之銅汁灌注咽喉，只是簡略舉出地獄的一種受苦之相，吞食熱鐵丸、臥於烈火炭，地獄的果報又哪有窮盡呢！

【826-0023】03_業疏/11a_卷二之五#98

【826-0024】03_業疏/11a_卷二之五#99
【原文】六中，初出起過之由。不奉法等，推其內心也；假食發者，形於外事也。「俗下」舉儒況釋，竝曲禮文。戒寢食時不當言語。「儼然若有所思」，身不妄動也；「安定詞」，口不妄言也；傲長則禍，欲縱則失，志滿則溢，戒令自節，然後為君子也。道高俗表，超世人也；如何反者，責其不當也
【譯文】第六科中，首先指出生起過失的原由。「不奉法」等句，是推求其內心的根源；「假食發者」，是顯現於外在的事相。自「俗」字以下，引用儒家典籍作比況解釋，都是《禮記·曲禮》中的文句。戒示在就寢與飲食之時不應當說話。「儼然若有所思」，是指身體不輕易妄動；「安定辭」，是指口舌不輕易妄言；傲慢滋長就會招致禍患，欲望放縱就會造成迷失，志得意滿就會溢滿招損，誡勉應當自我約束節制，如此然後才能成為君子。修道之德高邁於世俗之表，應當超越世俗凡人；「如何反者」，是斥責其行為極不相稱合宜。

【826-0025】03_業疏/11a_卷二之五#100
【原文】問：諸過之長，勿高十惡，如何不述，乃舉衣食兩緣者？答：十不善業，外惡易除；身口內貪，儀相難顯。要託衣食，其過方明，故因制也。又十惡文制，道俗知非；貪染乖儀，初未言過。然口腹之累，沈溺者多；形骸之重，在生為急。制戒為道，義須橫割；反此悠悠，未成其相也
【譯文】問：在一切罪過之中，沒有超過十惡業更嚴重的了，為什麼不先陳述十惡，反而單單舉出衣服、飲食這兩種因緣呢？答：十種不善之業，屬於顯露於外的大惡，容易予以斷除；而身口之中的內在貪染，在威儀相貌上難以明顯察覺。必須寄託於衣服和飲食這兩件事，其貪染的過失才昭然若明，所以藉此因緣而制定戒規。再者，十惡業在經典中明文禁止，出家人和在家人都知道那是過錯；而貪染違背威儀的小節，當初尚未被明確指責為過失。然而受累於口腹之欲，沉淪溺陷的人極多；關乎身軀體膚的保養，在生存中又是最為迫切的需求。制定戒律是為了修道，依理必須堅決截斷割捨；如果反此而悠忽放任，就根本無法成辦出家修道的戒德相貌了。

【826-0026】03_業疏/11a_卷二之五#101
【原文】問答中，初問可見。答中有二：初、約內外難易釋，制內以治外，先難而後易；「又下」次約麤細釋。道俗知非，此明麤顯，故通制二眾；初未言過，此彰微細，故偏制道眾。「然下」出須制所以。沈溺多者，偏生過故；在生急者，常受用故。若不割斷，入道徒為，故云未成相也
【譯文】在問答之中，前面的提問顯而易見。回答中分為兩層：第一、從內外與難易的角度來解釋，約束內心以治理外在，先攻難處而後克易處；自「又」字以下，其次從粗顯與微細的角度來解釋。「道俗知非」，這是說明十惡粗顯昭著，所以共通制定於僧俗二眾；「初未言過」，這是彰顯衣食貪著極其微細，所以偏重制定於出家道眾。自「然」字以下，指出必須制定戒規的原因所在。所謂「沉溺多者」，是因為特別容易在衣食上生起過失之故；所謂「在生急者」，是因為活在世間恆常受用衣食之故。如果不堅決割斷這份貪戀，趣入修道只不過是白費工夫，所以說「未成其相也」。

【826-0027】03_業疏/11a_卷二之五#102
【原文】二就制中，託犯為緣，因白制者，覩壞方補，聖說非虗；事假僧量，理當告白也
【譯文】第二、就制定度人法而言，佛託比丘犯過為因緣，因而制定須向僧團告白之法（制白）；這是看到規矩損壞才加以匡補（如同修補破衣），聖人的教導絕非虛設；度人事相必須藉助僧團的考量評斷，在道理上理應當向僧團白告陳述。
