# 校閱材料　第180檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【180-0001】02_戒疏/17a_卷四上之二#112
【原文】【疏】四緣成犯：一、自為己；二、使人覆；三、至三節未竟，不離見聞處；四、三節竟，犯。
【譯文】【疏文】構成犯戒的四種條件：第一、自己為自己蓋房；第二、指使工人施作覆蓋；第三、工序達到第三重鋪設尚未完工時，比丘未曾離開可見可聞的監工現場；第四、第三重鋪設全部完工，即結正罪。

【180-0002】02_戒疏/17a_卷四上之二#113
【原文】【記】列緣。第三，言「三節」者，或云「三重」，如世茆庵；或云「三行」，如蓋瓦屋。未詳西土覆屋之相，不可定約。
【譯文】【記文】列出犯戒條件。第三點，說到「三節」，有人說是「三重覆蓋」，如同世間蓋茅草棚屋重疊三層；有人說是「三排瓦槽」，如同蓋瓦房屋。由於古印度的覆頂技術究竟如何尚不明確，所以不能硬性以此方概念死板規定。

【180-0003】02_戒疏/17a_卷四上之二#114
【原文】【疏】問：「何故有看覆，無自覆者？」
【譯文】【疏文】提問：「為何只處罰在場督工監造，而沒有處罰親自手動覆蓋屋頂的情況呢？」

【180-0004】02_戒疏/17a_卷四上之二#115
【原文】【疏】答：「不看房成，有受用義；自覆招譏重，故不許用也。或可從緣起說，由使人作，因即制戒。」
【譯文】【疏文】回答：「比丘不親自監督使房屋順利告成，將來有實際受用安居的利益；但若是親自爬上去動手蓋屋，容易招致世俗深重的譏嫌，所以房屋蓋成之後，律法不允許比丘受用此房。或者也可以順著緣起事實來說，因為當初正是因為指使他人拼命加重鋪蓋，佛陀便順應此因緣而制定了戒律。」

【180-0005】02_戒疏/17a_卷四上之二#116
【原文】【記】問中。此制指授，看覆成犯；不制自覆，故問通之。答有二意，文相可解。
【譯文】【記文】提問中。本戒是制止比丘在旁指揮指授、督工看著過度覆蓋而結成正犯；卻沒有明文制止比丘親自覆蓋，所以提出問題來會通。回答中包含了兩種深意，文句行相易於明瞭。

【180-0006】02_戒疏/17a_卷四上之二#117
【原文】【疏】《多論》：「此房是十三中大房，三十萬錢作成即崩。施主生惱。比丘為說：『房雖崩壞，功德已成。未壞之時，佛到此房，即是無上福田之所受用。尋後有一新受戒比丘入中，若起房閣，嚴若須彌，持戒暫用，已畢施恩。以戒背世俗法，房舍四事是世間法故。』」
【譯文】【疏文】《薩婆多論》記載：「這間大房是僧殘第十三條中所說的大房舍，花費了三十萬錢的大代價剛修好便立刻坍塌。施主對此深生煩惱悔恨。比丘便為施主開示說：『房屋雖然倒塌損壞了，但您布施造屋的真實功德已經圓滿成就。在這房舍尚未毀壞之時，佛陀曾親自踏入此房安歇，這就已經被無上的大福田受用過了。緊接著，曾有一位剛受具足戒的清淨比丘走入其中，即使有人建造房舍樓閣，高廣莊嚴猶如須彌山一般，只要持戒清淨者暫時在此受用片刻，就已經徹底酬報並圓滿了施主的深恩。因為戒律是背離、超越世俗虛妄法的出世解脫因，而房舍等四事供養畢竟只是生滅無常的世間法罷了。』」

【180-0007】02_戒疏/17a_卷四上之二#118
【原文】【記】引緣中。初指本緣，房崩主惱。「十三中大房」，即有主房，若據《四分》，因斫神樹為緣，與此不同。「三十萬」者，十千為萬，即三百千。「比丘」下，次明比丘開解之詞。前明佛曾受用。「尋」下，後明新戒受用。「戒背世俗」者，無漏勝法，聖道本基，勝世法故。
【譯文】【記文】引用戒律因緣中。首先指明本緣起，是房倒屋塌令施主生起煩惱。「僧殘第十三條之大房」，是指有大施主主辦建造的僧房，如果依照《四分律》，該條是因擅自砍伐神樹為緣起，與論中所說略有不同。「三十萬錢」，在古代以十千為一萬，三十萬即是三百千文錢。「比丘」以下，接著說明比丘開導寬慰施主的話語。前半段說明佛陀曾親身受用。「緊接著」以下，後半段說明新受戒的清淨僧人受用。「戒律超越世俗」的意思，是指清淨戒法是無漏殊勝法，是成就聖道的根本基石，遠非世俗生滅有為的功德所能比擬。

【180-0008】02_戒疏/17a_卷四上之二#119
【原文】【註】佛在拘睒毗。闡陀起房，重覆不止，屋便摧破，居士嫌言：「檀越雖與，受者應知足。」比丘舉過，佛因制戒。
【譯文】【註文】佛陀住在拘睒彌國。闡陀比丘修造房屋，重疊鋪蓋屋頂不知節制，屋頂過重便轟然坍塌損壞，居士譏嫌批評說：「施主雖然樂意布施，領受的人也應當知足適度才是。」比丘們向佛舉報其過失，佛陀因而制定此戒。

【180-0012】02_戒疏/17a_卷四上之二#123
【原文】【註】若互捨見、聞處，吉羅。不犯者，如上指授，離遠者開。
【譯文】【註文】如果只是離開了能看見的地方但仍能聽見，或者離開了能聽見處但仍能看見，兩者未能完全脫離，犯突吉羅罪。不犯的情況：如同上述在指揮鋪設時，及時遠離到看不見也聽不見的地方，則屬開許不犯。

【譯文】【記文】戒本經文。第三句中，「苫」這個字，讀音為失廉反，意思是覆蓋屋頂的茅草。

【180-0015】02_戒疏/17a_卷四上之二#126
【原文】【疏】然「三節」相，律、論互談，至於事實，亦可披據。故《多論》云：「作房三品，上、中、下覆各自有限。若中、下房，用上法覆，以鎮重故，隨用草作，一一皆提。」《五分》：「若以草、瓦、版覆。」《母論》：「泥故崩。」《伽論》「若以草、版、鳥翅覆者，過限不犯」，亦以輕耳。及作房時，商度基陛材具，方可覆之，如《多論》也。
【譯文】【疏文】然而關於「三節」的具體工法相狀，各部律藏與諸部論典各有其說法，至於實際的施作，也可以有所考據印證。所以《薩婆多論》說：「建造房屋分為上、中、下三等品級，其屋頂覆蓋各自有限度。若是中等、下等房屋，卻採用了上等房屋的厚度法度去覆頂，因為屋頂受到重壓的緣故，此時無論是隨意用茅草層層鋪排，每一動作皆結犯波逸提墮罪。」《五分律》說：「若是用茅草、陶瓦、木板來覆頂。」《毗尼母論》說：「是因為泥灰塗抹過重而導致崩塌。」《摩得勒伽論》則說「如果只是用輕軟的茅草、薄木板、鳥禽羽毛來覆蓋屋頂，即便超過了三重限量也不犯」，這也是因為材料輕巧無壓力的緣故。因此在建造房屋時，必須仔細估量地基、台階與梁柱建材的承重強度，然後才可以施加覆蓋，這正如《薩婆多論》所詳述的原則。

【180-0016】02_戒疏/17a_卷四上之二#127
【原文】【記】三中。初生起。「故」下，引示。「《多論》三品」，隨其房屋費用、厚薄以分階位。「中、下上覆」，即為過限。「五分」已下，並出物體不同之相。《伽論》「草板不犯」，與上諸文相違，故以物「輕」通之。「及」下，次明籌量用與方便。下指《多論》，如「二房」中。

【180-0052】02_戒疏/17b_卷四上之二#20
【原文】【疏】就初制者。凡體無貴賤，有道則尊，法式軌要，非僧不具。敬法重人，事須致敬。敬而為言，觸途皆是。但此八種，攝尼偏要，故別制之，審能修行，戒淨法住。故《善見》云：「由度尼故，正法減半；若行八敬，還滿千年。」法由人弘，其義不昧矣。
【譯文】【疏文】探討最初制定義理。大凡人的本體並沒有尊卑貴賤之分，有道德智慧便值得尊崇，而威儀軌範的要旨，非僧團就無法具足完備。為了敬重正法、尊重賢人，理所當然應當致以敬意。就恭敬的道理而言，處處都應奉行。然而這八種戒法，在攝受約束尼眾上格外關鍵要緊，所以佛陀特別制定，若能切實依教修行，戒行就能清淨，正法得以常住。因此《善見律論》說：「由於度化尼眾出家，正法縮短了五百年；如果依教遵行八敬法，正法便能重新圓滿維持千年。」正法全仰賴人來弘揚，其中的深意絕非晦昧不明的。

【180-0053】02_戒疏/17b_卷四上之二#21

【180-0065】02_戒疏/17b_卷四上之二#33

【譯文】【記文】在第三門說明罪名中。首先說明有三種法犯波逸提。第二條中，「辱罵」與「誹謗」義理相通，所以參照說明。《四分律》說「不得辱罵比丘，不得誹謗」等。文中標出三種罪名，誹謗通於僧殘、波逸提、突吉羅三篇，如先前所配屬；辱罵只包含兩種，以惡法辱罵得波逸提，以善法諷刺辱罵只得突吉羅。第三條「舉罪」中，所謂「說過失犯提」，《四分律》列出舉過的形態如說「你所做的是這樣」、「你所做的不是這樣」以及「不得作自言告白」。「阻止舉罪犯吉羅」，《四分律》說「遮止比丘尋求過罪」以及「遮止比丘說戒、自恣」。第五條結「吉羅」的原因，應當是此事較為少見。從「其餘」以下，就是指安居和自恣，這兩者違犯都得波逸提罪。
