# 校閱材料　第541檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【541-0001】資持記/08a_中二#25
【原文】義，謂言義；味，即意趣。二具，方殘；則顯上緣解義不解味，理應輕降。故引《四分》明之；此中語義，即上義味。互向中。比丘向女，如前可知；女向比丘麁語，比丘領意，亦同前犯。歎身同故，探前點之。不犯中，初別舉七事。竝以若字分之。前六皆據說法受經，因而言及，故開無犯。
【譯文】「義」是指字面上的言詞意義；「味」是指話中暗藏的意趣。字義與意趣兩者都理解，才結僧殘罪；這就說明了在上面的條件中，如果只理解字義而不理解隱含意趣，理應減輕罪責。所以引用《四分律》來做說明；這裡所說的語句和字義，就是指上面的字義與意趣。在彼此互說的情況中，比丘對女人說粗惡語，如前文所述可以明瞭；女人對比丘說粗惡語，比丘心領神會其淫意，也同樣構成前面的犯罪。這與讚歎自身索取供養的情況相同，所以預先探取引出後戒於此處提點。在不犯的情況中，首先分別列舉了七種事情，全部都用「若」字來分段區隔。前六種都是基於說法和傳授經典的需要，順帶牽涉提到，所以開許不算犯戒。

【541-0002】資持記/08a_中二#26
【原文】初說法中，九瘡眼耳鼻各二，口及大小道。破肉如瘡，竅穴為孔；外通物入，內出流漏，故列多名。四中，比丘與女同受，則同聲故。六但同誦，非從人受，與上為異。但無下，此語通攝，不唯前事。第四。〔迦留陀夷聞佛制前三戒，故將女入房，歎身索供，因制。〕名中。
【譯文】在第一種說法的情況中，所謂「九瘡」是指眼、耳、鼻各兩個，加上嘴巴以及大小便道。皮肉破裂就像瘡口，孔穴凹陷形成孔洞；外在能容許物體進入，內在能流出液體分泌，所以列舉了許多名稱。在第四種情況中，比丘與女人一起受經，因為是同時同聲朗誦。第六種情況只是共同誦讀，並不是向他人學習領受，與上一條有所不同。「但無」以下，這句話具有廣泛的涵攝力，不僅僅局限於前述的幾件事情。第四條戒（指歎身索供戒）。〔迦留陀夷比丘聽聞佛陀制定了前三條戒，於是將女人帶入房內，讚歎自身有德行而向她索取淫欲供養，佛陀因而制戒。〕戒名中。

【541-0003】資持記/08a_中二#27
【原文】境過一一須分。索供者，誘調前女，令以欲供也。疏問：既修梵行〔牒戒本文。〕，義無行非，何以索欲供者？答：必實行欲，索者偷蘭，大淫方便也；今本不行，口言其相，妄開淫門，擬通適耳。犯中，列緣。六言章了了，七前人解知，近故指之。釋四中，先出歎相，有三。初端正等，歎報色。
【譯文】對象境界與所犯罪過，每一項都必須詳細劃分清楚。所謂「索供」，是指引誘挑逗眼前的女人，讓她以行淫來供養自己。《戒疏》提問：既然出家修持清淨梵行〔這是戒本的原話〕，理應不可能有行淫非禮的行為，為什麼還要索取淫欲供養呢？回答：如果真的要行淫，向女人索求便結偷蘭遮罪，因為這是根本大淫戒的前行方便；現在原本並不想真行淫，只是口中訴說那些相狀，妄圖打開淫樂之門，準備藉此獲得快感罷了。在判犯中列舉犯戒條件：第六是言語句意表達清清楚楚，第七是對方完全理解通曉，因為前文剛說過，所以在此只是提點。在解釋第四個條件中，先列出讚歎的相狀，共有三種：首先說「端正」等等，是讚歎果報帶來的殊勝容貌身色。

【541-0004】資持記/08a_中二#28
【原文】二大姓者，歎種族；剎帝利婆羅門名大姓，毘舍首陀為下姓。三出家下，歎德行；是中出家是遠離行，持戒即止作行，修善是少欲行；下舉頭陀，釋成修善；律中更列唄𠽋多聞說法持律坐禪，故云等也。不下，結犯差別。有三句：初結蘭者，歎而不索故。次犯殘者，索歎兩兼故。
【譯文】第二是讚歎大姓，是讚歎種姓門第；剎帝利與婆羅門稱為高貴大姓，吠舍與首陀羅屬於低賤下姓。第三，「出家」以下，是讚歎道德操守與修持；在這些德行中，出家是遠離世俗之行，持戒就是止惡作善之行，修善則是少欲知足之行；下文列舉頭陀苦行，是用來解釋修善的具體內容；律文中還另外列出了歌詠梵唄、博學多聞、講經說法、嚴持戒律、坐禪修定，所以用一個「等」字涵蓋。「不」字以下，是總結犯戒的層次差別。共有三種情況：第一種結偷蘭遮罪，是因為只讚歎自身而不索取行淫供養。第二種犯僧殘者，是因為索取供養與讚歎自身兩者兼備。

【541-0005】資持記/08a_中二#29
【原文】三同前者，索而不歎，即屬麁語。不犯中。且列二相。《注戒》更開錯說。第五。〔佛在羅閱祇，迦羅比丘善知俗法，與俗為媒，招譏故制。〕名標人者，簡餘類故。疏云：媒，謀也；計度二姓，用為好合。犯中，釋第六文有五節；一約三時具缺，辨犯差降。具三可知。具二，謂受往而不報。
【譯文】第三種與前戒相同者，如果只索取供養而不讚歎自身，那就屬於前一條的說麁惡語罪。在不犯的狀況中，暫且列出兩種相狀。《注戒》中另外還開許了口誤說錯話的情形。第五條戒（指作媒人戒）。〔佛陀在羅閱祇城時，迦羅比丘精通世俗禮法，替在家人穿針引線做媒，招致社會譏嫌嘲諷，佛陀因此制戒。〕在戒名中特別標明對象是「男女之人」，是為了區別其他的物類。《戒疏》說：所謂媒，就是謀劃的意思；在男女兩家姓氏之間思量計謀，促成雙方的結合成親。在犯相中，解釋第六個犯緣的文字共有五個段落：第一是就「受託、前往、回報」這三個時程的具備與缺損，來辨別結罪的輕重差降。具備三者犯重罪是可以明瞭的。具備兩者，是指接受了委託並前往傳話，但還沒有回報。

【541-0006】資持記/08a_中二#30
【原文】具一，即受而不往。若受下，二明四種緣差，三輕一重。注顯後一，由女尚存，病容差故。除下，三明非正道。問：女有三道，但除二者？答：口雖通淫，非本媒意；縱有，亦屬餘身分耳。若媒下，四簡異報也。《五分》下，五明事不成也。釋第三中，初文。不能男女，即二種黃門；
【譯文】只具備一者，就是接受了委託卻還沒有前往交涉。「若受」以下，第二段說明四種因緣差錯的狀況，三種情節較輕，一種情節較重。注文中特別顯露出最後一種，是由於女方依然活著，疾病還有痊癒的可能。「除」字以下，第三段說明撮合非男女生殖之正道的情況。有人問：女人有三道，為什麼只排除其中兩道？回答：口腔雖然也能通行淫欲，但根本不是作媒撮合結合的本意；縱然有這種苟合，也屬於觸犯其餘身體部位的範疇。自「若媒」以下文句，第四段是揀選排除了非人類等不同果報的對象。《五分律》「以下」，第五段說明婚事最終沒有撮合成辦的情況。在解釋第三個緣中，第一段文字。所謂「不能男女」，就是指兩種黃門（無性徵或性發育不全者）；

【541-0007】資持記/08a_中二#31
【原文】或彼此互是，或二俱是，竝同下犯。下列二女，道合一道是一種〔舊分二女，非也。〕；石女者，根不通涶者，羯磨列遮云：二道合、道小，即同此矣。次科，先引律緣。一切殘者，盡界同犯也。今下準斥非法。雖不羯磨，白眾同情故。若下，因責盜用，非此犯相。三中。
【譯文】或者是男女雙方有一方如此，或者雙方都是如此，都同樣依照下文結較輕的罪。下文列出兩種女性缺陷，陰道與便道相通合成一道的算是一種〔過去分成兩種女人，是不對的〕；石女是指生殖通道天生閉塞不通的女人，在羯磨作法中列出的遮難說：「兩道相合、通道過小」，就屬於這類情形。下一段科判，先引用律文中的犯罪因緣。所謂「一切皆犯僧殘」，是指全結界內的所有僧人都共同犯下僧殘重罪。現在「以下」這句話，是依律呵責這種非法作法。雖然沒有進行羯磨白告，但向大眾白告且心意相符容隱。如果「以下」，是順便斥責侵吞挪用僧物，並不是本戒所要論斷的犯相。在第三部分中。

【541-0008】資持記/08a_中二#32
【原文】好馬勝於餘畜，故罪分二品。今世愚僧多畜猫狗，求合雌雄，一一吉罪。制急過重，知者誡之。第四中。恐後合者，以男女類殊，聚必相染故。五中，《十誦》二相。指腹者未生而媒。古記，準俗算法，預占胎中男女；學者無知，便對俗女輪珠計數，以為己能。且無學射事，尚致俗譏；

【541-0009】資持記/08a_中二#33
