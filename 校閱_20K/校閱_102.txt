# 校閱材料　第102檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【102-0001】01_行事鈔/10a_卷下之二#6
【原文】時藥有二：《四分》中，有五種蒲闍尼，謂麨、飯、乾飯、魚、肉也；五種佉闍尼，謂枝、葉、華、果、細末磨食。《僧祇》：時食者，蔓菁根、葱根、藕根、蘿蔔根、治毒草根；時漿者，一切米汁、粉汁、乳酪漿是。諸律並明魚、肉為時食，此是廢前教。《涅槃》云：從今日後不聽弟子食肉，觀察如子肉想；夫食肉者，斷大慈種，水、陸、空行，有命者怨，故不令食。廣如彼說。經云：前令食肉，謂非四生之肉，但現化耳，為度眾生。《稜伽》云：有無量因緣不應食肉，略說十種：一者一切眾生無始已來，常為六親，以親想故不應食肉。二狐狗人馬，屠者雜賣故。三不淨氣分所生長故。四眾生聞氣悉生怖故。五令修行者慈心不生故。六凡愚所習，臭穢不淨，無善名稱故。七令呪術不成就故。八以食肉，見形起識，以染味著故。九諸天所棄、多惡夢、虎狼聞香故。十由食種種肉，遂噉人肉故，如《班足王經》說。今有凡愚，多嗜諸肉，罪中之大，勿過於此。故屠者販賣，但為食肉之人；必無食者，亦不屠殺；故知食者，同屠造業，沾殺生分，可不誡乎！《僧祇》云：若為比丘殺者，一切七眾不應食；乃至為優婆夷殺，七眾不食亦爾。今學戒者，多不食之，與中國大乘僧同例。有學大乘語者，用酒肉為行解；則大小二教不收，自入屠兒行內；天魔外道尚不食酒肉，此乃閻羅之將吏耳。《四分》云：若此殺者，行十惡業，為我故殺，乃至大祀處肉，不得食之；以辨具來者，心無定主故。今屠者通殺，則依教無肉可食，正斷食肉也。《毘尼母》大同。律云：若持十善，彼終不為我故斷眾生命，如此應食。準此，何由得肉而噉？唯自死者。鳥殘猶獲罪也！《稜伽》云：酒、肉、葱䔉、韮薤之屬，悉不嘗之。俗中尚云，沽酒市脯不食；況出道高僧，以酒肉為意旨，所懷亦可見也！《摩得伽》云：若以酒煮時、非時、七日藥得服者，謂無酒性得服。今時藥酒，令昏醉悶，氣味具足，為貪服之；必加苦毒，亦不附口。以此二途，驗知情性，去道全遠。
【譯文】時藥有兩種：《四分律》中，有五種蒲闍尼（正食），即麨（炒麥粉）、飯、乾飯、魚、肉；五種佉闍尼（嚼食），即樹枝、葉、花、果實、研磨細粉作成之食物。《摩訶僧祇律》說：時食包括蔓菁根、蔥根、藕根、蘿蔔根、治毒草根；時漿則是一切米汁、麵粉汁、乳酪漿等。各部律典雖然皆載明魚、肉為時食，但此教法已被後設之教令所廢止。《大般涅槃經》說：從今日起不聽許弟子食肉，應當作如同自己親生兒子之肉來觀察；凡食肉者，斷絕大慈悲種子，水、陸、空行一切有命眾生皆生怨恨，所以不令食用。詳細如該經所說。經中又說：先前令食肉，所開許的並非卵胎濕化四生之肉，只是神力顯現之幻化罷了，是為了度化眾生。《楞伽經》說：有無量因緣不應食肉，略說有十種：第一、一切眾生無始以來常為六親眷屬，以眷屬想之故不應食肉。第二、狐、狗、人、馬等肉，屠夫常雜賣之故。第三、是由不淨氣分精血所生長之故。第四、眾生聞到肉氣皆生怖畏之故。第五、令修行者慈悲心不生之故。第六、是凡夫愚人所習染，臭穢不淨，沒有善美名聲之故。第七、令呪術不能成就之故。第八、因食肉者見其形體即起貪識、染著滋味之故。第九、諸天善神所棄捨、常做惡夢、虎狼聞其香氣而追隨之故。第十、因食用各類肉，最終演至噉食人肉之故，如《班足王經》所說。如今有些凡夫愚人，極為嗜好各類肉食，罪過之中最為重大者，莫過於此。屠夫宰殺販賣，只是為了食肉之人；若必定無人食肉，自然也就不會屠殺；由此可知食肉之人與屠夫共同造作惡業，分擔了殺生的罪分，難道能不戒懼嗎！《摩訶僧祇律》說：若是為比丘而殺的，出家在家一切七眾皆不應食；乃至為優婆夷而殺，七眾不得食用也是如此。如今學戒之人多不食肉，與中印度（西天竺）大乘僧侶同例。有些人學了幾句大乘言論，便將嗜酒肉視為契合行解；這為大小二乘教法所不收容，自甘墮入屠夫劊子手之列；連天魔外道尚且不食酒肉，這等人不過是閻羅王座下的將吏罷了。《四分律》說：如果這名宰殺者平生行十惡業、或是為我而殺，乃至大祭祀場所的肉，都不得食用；以及置辦祭祀筵饌而送來的肉，宰殺時心無特定目標（普為眾人而殺）之故。如今屠夫普遍殺生，依教理便無肉可食，這正是要徹底斷絕食肉。《毘尼母經》說法大體相同。律中說：如果對方受持十善業，他終究不會為我之故斷絕眾生命，這樣的肉才可以吃。準此而言，哪裡還能得到肉來吃呢？除非是自然死亡之獸類。然而連鳥獸吃殘的剩肉，吃了尚且獲罪！《楞伽經》說：酒、肉、蔥、蒜、韭菜、薤菜之類，一概不去品嘗。世俗之中尚且說「從市集買來的酒和肉乾不吃」，何況出家修道的高僧，若反以酒肉為修道宗旨，其胸懷意趣也就可想而知了！《摩得伽論》說：若用酒來煮時藥、非時藥、七日藥而得以服用的，是指完全失去酒性（無酒氣酒味）才得服用。現今之藥酒，令人昏醉悶亂，酒的氣味具足，僧人卻因貪圖而服用；若在其中加入苦澀有毒之藥，他們便不沾口。從這兩種情況檢驗，即可深知其情性貪著，距離聖道極為遙遠。

【102-0002】01_行事鈔/10a_卷下之二#7
【原文】非時漿者。《僧祇》：一切豆、穀、麥，煮之頭不卓破者之汁；若穌、油、蜜、石蜜、十四種果漿、生果汁，要以水作淨。若器底殘水，被雨濺等，亦名淨。《十誦》若蒲萄不以火淨，汁中不以水淨，及互不淨，不應飲；俱淨得飲。準此，通四藥，為壞味除貪故。《善見》：舍樓伽漿、一切木果；一切葉，除菜；一切華；一切草果，除甜瓠子、冬瓜、甜瓜、椰子果已外，得非時服。《毘尼母》：得種種果，多食不盡者，破取汁飲。若不至初夜，變成苦酒者，不得飲，以酒兩已成故。《明了論》：炒米令焦黑，餘藥投中，釀以為漿，亦名非時漿。《四分》：八種漿，古昔無欲仙人所飲，梨、酸棗、甘蔗、𮒂果、蒲萄、舍樓伽等漿也。若醉人不應飲，飲則如法治。《伽論》要須漉除滓，澄清如水；若有濁汁，與時食雜，若咽咽飲，隨犯波逸提。
【譯文】所謂非時漿：《摩訶僧祇律》說：一切豆類、穀類、麥類，熬煮時表皮未裂破時濾出之汁液；若是熟酥、油、蜂蜜、石蜜、十四種果漿、生鮮果汁，必須用水作淨（加水破壞純味）。若是器皿底部殘留之水，或被雨水濺入等，也算作淨。《十誦律》說：若葡萄不用火作淨，葡萄汁中不用水作淨，以及兩者互有未作淨，皆不應飲用；二者俱作淨了才得飲用。準此而言，這通於四種藥物，是為了壞其純美滋味以除貪心之故。《善見律》說：舍樓伽（藕根）漿、一切木本果實；一切樹葉，蔬菜除外；一切花朵；一切草本果實，除了甜瓠子、冬瓜、甜瓜、椰子果以外，皆得以在非時服用。《毘尼母經》說：得到各類果實，過多吃不完的，壓破榨取汁液來飲用。如果尚未至初夜，就已經變成苦酒（醋）的，則不得飲用，因為酒兩〔註：原文作「酒兩」，《毘尼母經》作「酒性」或「酒氣」，「兩」疑為形訛〕已經形成之故。《律二十二明了論》說：將米炒至焦黑，把其餘藥材投入其中，浸泡釀製成漿，也稱為非時漿。《四分律》說：有八種漿，是古代無欲仙人所飲用的，即梨、酸棗、甘蔗、𮒂果〔註：原文作「𮒂」，罕見字，諸律常作「柑果」或「樝果」〕、葡萄、舍樓伽等漿。若是會令人醉亂的則不應飲用，飲用了就依照律法治罪。《摩得伽論》說：必須過濾除盡渣滓，澄清如水；若有渾濁汁液，與時食成分相雜，若一口一口吞飲，每一咽便隨之犯波逸提（單墮罪）。

【102-0003】01_行事鈔/10a_卷下之二#8

【原文】次二，六味定者。《明了論》云：五種量，乃至大開，攝一切物皆盡。《疏》云：藥有五種：甘味物中，除甘草、蜜、沙糖、穌、油，餘甘味是時量；酸味除阿摩勒果汁等，餘酸味是時量；辛味中除薑、椒、萆茇、呵梨勒，餘辛味是時量；一切苦澁物非食，作終身藥。七日藥外，一切可食物，名依時量食；從平旦至正中，為時；過此，不得食。一切漿、甘蔗等，名依更量；日夜各分五時，從平旦受至二更，過則不得服，如是輪轉，乃至五更；此間漬飯為漿，屬時量。穌、油、蜜、沙糖等，名依七日量。甘草等，名依一期量；從受戒後，臨一期報終，名一期也；於此時中，無問晝夜，恒得服之。灰、土、水、屎、尿此五，名依大開量；不須受，隨意取服，是世間所棄，非所惜故。《四分》：須受灰、土等。
【譯文】第二、依六味決定藥量：《律二十二明了論》說：有五種限度（量），乃至大開許，將一切物品攝盡無餘。《律二十二明了論疏》說：藥物分為五種：在甜味物品中，除甘草、蜂蜜、砂糖、熟酥、油之外，其餘甜味皆屬依時量；酸味物品中，除阿摩勒果汁等之外，其餘酸味皆屬依時量；辛辣味中，除生薑、胡椒、蓽茇、呵梨勒之外，其餘辛味皆屬依時量；一切苦澀之物不是食物，皆作為終身藥。除了七日藥之外，一切可充飢食用之物，稱為「依時量食」；從平旦至正午，稱為「時」；過了此時限，便不得食用。一切果漿、甘蔗等，稱為「依更量」；一日一夜各分為五更（五時），從平旦受持至第二更，過時便不得服用，如此輾轉輪替，乃至第五更；中土浸泡米飯所成的米漿，則屬於依時量。熟酥、油、蜂蜜、砂糖等，稱為「依七日量」。甘草等，稱為「依一期量」；從受具足戒之後，直至一期生命果報終結，稱為「一期」；在此時間之中，不論白天黑夜，恆常得以服用。草木灰、土、水、屎、尿這五種，稱為「依大開量」；不需要作受持法，隨意取來服用，因為這是世間所拋棄之物，並非世人所顧惜之故。《四分律》則規定：必須作法受持灰、土等。
