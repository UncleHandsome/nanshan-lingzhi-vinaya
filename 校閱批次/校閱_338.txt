# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【338-0001】02_戒疏/18a_卷四上之三#6
【原文】【記】初明損俗，復有二意。上四句明損財。由食處成眾，費用則多，據此明意，欲令人少，即如下引「汝等但請三人，我等不得別眾」是也。言「段食」者，色香味觸，有形段故。「又」下，二、明損福。能別乖和，所別失利，故云「損重」；施心不普，獲福非勝，故云「利輕」。
【譯文】【記文】最初說明損害世俗（損俗），這裡又有兩層意思。前面的四句話說明損耗財物。由於聚集受食之處形成了小僧團（成眾），花費就會增多，根據這一點來闡明制戒意圖，是希望讓受供人數減少，也就是如同下文所引用的「你們只要邀請三個人，我們就不能脫離大眾結夥受食」這句話。所謂「有形質的飲食（段食）」，是指具備色、香、味、觸，帶有形狀分段特質的食物。從「再者（又）」字以下，第二點說明損害福報。能私自分組者違背了僧團和合，被排除在外者失去了利養，所以說「損害重大」；施主的布施心不普遍，所獲的福德就不殊勝，所以說「利益輕微」。

【338-0002】02_戒疏/18a_卷四上之三#7
【原文】【記】二、明損道。即正戒緣，如注所引。提婆達等與佛競化，性難調伏，故號「難調」。今制別眾，令同僧海，即攝彼也。
【譯文】【記文】第二點，說明損害道業（損道）。這正是制戒的正緣，如同注文所引述的內容。提婆達多等人與佛陀爭奪教化權，性格難以調伏，所以被稱為「難調伏者」。如今制定不得私自聚食的戒律，令他們與僧團大眾的大海同歸一體，這就是為了攝受調伏他們。

【338-0003】02_戒疏/18a_卷四上之三#8
【原文】【記】「有」下，三、總結。由制此戒，翻損成盛，一者濟俗，二謂僧和，即下所謂「慈愍白衣，攝難調人」也。
【譯文】【記文】從「由於有（有）」字以下，第三部分是總結。由於制定了這條戒律，反轉了損害而成為興盛，一者是救濟世俗，二者是僧團和合，也就是下文所說的「慈愍俗人白衣，攝受難調伏之人」。

【338-0004】02_戒疏/18a_卷四上之三#9
【原文】【疏】二、釋名中。但以能別之人，食處成眾，以眾別他，不共同味，亦表法、食有隔，故眾處得罪。所別之處，豈可非眾？然《律》據能別之人，故文云「別眾食者，四人，若過」也。若從語論，應云「眾別食」也，取本意故云「別眾」耳。三人已下，無上兩損。故文云：「但請三人食，我等不得別眾故。」
【譯文】【疏文】第二、在解釋名稱（釋名）中。只因為能私自分組的人，在受食之處達到了四人以上而結成小團體（成眾），以這個小團體脫離了其他僧眾，不與大眾共同享用同等滋味，這也象徵著如法羯磨之法事與受用飲食產生了隔閡，所以在形成小團體之處便構成犯戒之罪。被脫離的大眾之處，難道可以不是僧團大眾嗎？然而《律藏》是根據能脫離的這批人來立論，所以經文說「脫離大眾受食的人，達四人或四人以上」。若是從語言表達的邏輯來論，應該稱作「私組之眾個別受食（眾別食）」，只是為了採取原本的制戒意趣，所以稱作「脫離大眾受食（別眾）」罷了。若是三個人以下，就不會造成上述的兩種損害。所以經文說：「只要邀請三個人受食，我們就不會構成脫離大眾聚食的緣故。」

【338-0006】02_戒疏/18a_卷四上之三#11
【原文】【記】初中，有三。初至「得罪」，從能別釋名判犯。「不共同殊」是食別，即利不和。以事表法，法亦有乖，即戒、見不和，故云「法食隔」也。「所別」下，二、辨能所相濫，引證能別，文理顯然。「若從」下，三、會言相。「從語論」者，能所便也。「取本意」者，調達本緣，別正眾故。
【譯文】【記文】在最初的正釋中，包含三點。第一點到「得罪」為止，是從能私自分組的人來解釋名稱並判斷犯相。「不共同味」屬於飲食上的差別，也就是利益上的不和合。以具體事相表徵如法原則，法事上也隨之產生乖離，也就是戒律與見解的不和合，所以說是「法事與飲食產生隔閡」。從「被脫離（所別）」以下，第二點是辨析主動脫離者與被脫離者之間容易混淆的關係，並引用經文證實是以能脫離者為主，經文的義理十分顯著。從「若是從（若從）」以下，第三點是會通語句表達的文相。所謂「從語論」，是指在能分組與所脫離的文詞使用上求其順暢。「取本意」，是指提婆達多結夥的原由，是為了脫離原本的正法僧團。

【338-0009】02_戒疏/18a_卷四上之三#14
【原文】【記】列緣。第一，「簡僧食」者，以十方共分，有人不集或不作相，並在盜收，不犯此戒。第三，合示兩緣。五、「善比丘」，即不犯重人。下云「唯除惡戒」，《鈔》云「別眾，唯據清淨一色」，又云「犯下四篇，亦成別眾」。法、食罪異，簡境大同。六、「無緣」者，即下九開。
【譯文】【記文】列出犯戒諸緣（列緣）。第一點，「簡別僧團常住食（簡僧食）」，因為那是十方僧眾共同持有的份額，如果有人未集會、或者沒有作法通知，都屬於盜戒所收攝的範疇，不犯這條戒。第三點，合併標示了受食時間與食物種類這兩種緣。第五點，「善比丘」，是指沒有觸犯重戒的人。下文說「唯獨除開惡戒之人」，《戒疏行事鈔》說「別眾的界定，完全以清淨無瑕的同類僧眾為準」，又說「若是觸犯下四篇罪的比丘，依然會構成別眾」。作法事與受飲食的罪相雖然不同，但簡別對象的標準大體相同。第六點，「沒有因緣（無緣）」，就是指後面所列的九種開許情況。

【338-0013】02_戒疏/18a_卷四上之三#18
【原文】【疏】若僧次請來，家內不集故犯。初雖僧法，及至食時，界內有僧，別不同食，即此僧次還名別請也。若本別請，食時僧來，既無遮約，即此別請名僧次也。
【譯文】【疏文】如果是按照僧團長幼次序輪流接受邀請前來（僧次請），但施主家內沒有集合眾僧同食，所以犯戒。起初雖然符合僧團受供之法，但等到吃東西時，界內還有其他僧人，卻私自不與其共同受食，那麼這個原本的僧次邀請，就轉變為私自個別受請了。如果原本是個別被邀請，受食時有其他僧人前來，既然沒有加以阻擋排拒，那麼這個個別邀請就視同為僧團次序的普請了。

【338-0014】02_戒疏/18a_卷四上之三#19
【原文】【疏】自餘別請別眾，別乞別眾，不問界內有僧無僧，但使食處成眾故犯。若鳴稚作相，若唱召一人，即非犯過。
【譯文】【疏文】至於其餘的私自個別受請而成眾受食、私自個別乞食而成眾受食，無論結界之內有沒有其他僧人，只要在受食之處達到了四人以上而結成僧眾，就會構成犯戒。如果鳴打木揵椎發出作法信號，或者唱名召請了一位僧人同食，就不構成違犯之過。

【338-0015】02_戒疏/18a_卷四上之三#20
【原文】【疏】必明此三緣，即當如鏡也。
【譯文】【疏文】如果徹底明瞭這三種因緣，在持犯的理解上就會像明鏡一般清晰。

【338-0016】02_戒疏/18a_卷四上之三#21
【原文】【記】約三位中，分三。初總示。言「分三」者，即僧次、別請、別乞也。「若」下，別釋。初明僧次，又二。先明初僧後別，則有別眾；後明翻別成僧，則無別眾。「自」下，次明二別，可解。言「無僧犯」者，由先遮他，及至食時，遠去亦犯，如《鈔》所明。言「唱召」者，以僧多食少，從六十臘以至沙彌，但得一人，即免別眾。「必」下，三、結告。
【譯文】【記文】在約定三種情況（約三位）的說明中，分為三部分。首先是總體提示。所謂「分為三種」，就是指僧次請、個別受請、個別乞食。從「如果是（若）」字以下，進行分別解釋。先說明僧次請，這裡又有兩層：先說明起初是僧團普請但後來私自結夥，這就會構成別眾；後說明將個別邀請轉變為普請同食，這就不構成別眾。從「至於其餘（自）」字以下，接著說明另外兩種個別情況，文義容易理解。所謂「界內無僧也犯」，是因為事先阻擋拒絕他人，等到受食時，即使其他僧人遠去了也構成犯戒，如同《行事鈔》所闡明的。所謂「唱名召請」，是因為僧多而食物少，從戒臘六十歲的上座一直到沙彌，只要召請到其中一人同食，就能免去別眾的罪過。從「如果徹底（必）」字以下，第三部分是總結告誡。

【338-0017】02_戒疏/18a_卷四上之三#22
【原文】【疏】據論法、食，妙約人論，人有精麤，教亦通塞。
【譯文】【疏文】根據論典所探討的如法羯磨與飲食受用，其精妙之處在於依據人的品質來衡量，人有精純與粗糙之分，戒律的開遮通塞也隨之不同。

【338-0018】02_戒疏/18a_卷四上之三#23
【原文】【記】法食簡中。「法」即羯磨。由境通淨穢，犯有成不。作法足數，受施來集，但無三根，通取相淨。若判別眾，必須勘覈，不可枉濫，所以簡之。
【譯文】【記文】簡別羯磨之法與飲食（法食簡）中。「法」就是指羯磨。由於對象境地通於清淨與污穢，結罪與成法便有成與不成的差別。如果是作如法羯磨湊足法定人數、或者接受布施前來集會，只要沒有見、聞、疑三種破戒跡象，通常一律採取表面相狀清淨的標準。但若要判定是否構成別眾食，則必須嚴格勘驗考覈，不可冤屈濫判，所以必須加以簡別。

【338-0019】02_戒疏/18a_卷四上之三#24
【原文】【疏】且如僧次一種，必以淨戒為先。微犯憲章，不令受利。故文云：「犯吉羅故語令知，恐受信施、持戒禮拜。」又云：「為解脫生死出家，得受僧次，唯除惡戒。」故破戒者，不合受僧俗兩供。若此簡人，名為「精」也。
【譯文】【疏文】且如按照僧團次序輪流受請（僧次）這一種，必定要以戒律清淨為優先考量。哪怕是些微觸犯了法規篇聚，也不讓其承受此種利養。所以經文說：「觸犯突吉羅小罪，所以要告知讓他知曉，唯恐他接受信徒布施、承受持戒比丘的禮拜。」又說：「若是為了解脫生死而發心出家，就能接受僧團次序的普請受供，唯獨除開破壞惡戒的人。」所以破戒者，依法不應當接受僧團與俗人兩方的供養。如果按照這種標準來挑選簡別人員，就稱為「精純（精）」。

【338-0020】02_戒疏/18a_卷四上之三#25
【原文】【記】精簡中三。初正明。「憲章」，即是篇聚。下至吉羅，故云「微犯」。「故」下，二、引證。初是本簡疑惱戒文，則該六聚。「又」下，《五分》唯簡初篇。「故破」下，三、結示。
【譯文】【記文】在精純簡別（精簡）中分為三點。首先是正面說明。「憲章」就是指戒律的篇聚。甚至微細到突吉羅罪，所以說是「微細違犯」。從「所以（故）」字以下，第二是引用經文證明。第一處是本律中簡別疑惱戒的經文，通該了全部六聚罪相。從「又說（又）」字以下，《五分律》則僅簡別觸犯第一篇波羅夷重罪者。從「所以破戒（故破）」字以下，第三是結語指示。

【338-0021】02_戒疏/18a_卷四上之三#26
【原文】【疏】又《賢愚》云：「正使將來為利出家、畜妻狹子，名字比丘，若有僧中請得此者，宜應供養，其福難量，如舍利弗、大目乾連等，勝別請得五百羅漢。」如此取人，名為「麤」也。故《多論》云「如僧海中，持戒破戒，若邪若正，一切無遮」故也。
【譯文】【疏文】又《賢愚經》說：「縱使未來世有人純粹為了名利而出家、娶妻生子，僅具有出家人名字的比丘，若是在僧團普請中請到了這樣的人，依然應當恭敬供養，所得的福報難以估量，其功德如同供養舍利弗、大目犍連等人，勝過私自個別邀請五百位阿羅漢。」像這樣不加苛求地選取人員，就稱為「寬泛粗略（麤）」。所以《薩婆多論》說「就如同在僧眾大海之中，無論持戒、破戒，無論是邪是正，一切無遮」故也。

【338-0023】02_戒疏/18a_卷四上之三#28
【原文】【疏】佛在人專，故又行實。末代人濫，形服為上，外生物信，於諸僧海，自感僧福。非謂行缺而消信施。故經云「橋度物」也。破戒之人，雖入地獄，口說善法，令生信故。
【譯文】【疏文】佛陀在世時修道之人專注純粹，所以其修行與德行非常踏實。到了末法時代人員雜濫，唯有以出家僧相僧服為最首要的標準，外在能令眾生生起信敬，在廣大的僧海福田中，信徒自然感得供僧的福報。這並非是說修行有所殘缺的人自己能夠消受信眾的布施。所以經典上說是「如橋梁般度脫人物」。破戒的人，雖然自己將來會墮入地獄，但口中宣說善法，依然能使眾生生起信心。
