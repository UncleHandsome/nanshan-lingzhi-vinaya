# 校閱材料　第1857檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1857-0001】03_業疏/19a_卷四之二#101
【原文】釋中初科，初簡非法，求得即邪命不淨，謂興販等，此已先犯，皆不入淨。金下示如法，兩引開文，無非濟道。衣價即錢寶，引經律論，竝令施他，明非自畜。《涅槃》護法，為存僧寶，佛法在世故
【譯文】在解釋的初科中，首先甄別非法所得：自求所得即屬於邪命不淨，例如經商販賣等，這在事先就已經犯戒，都不能納入說淨。「金」字以下示明如法之物，兩度引述開許之文，無非是為了資助修道。衣價就是指錢寶，引述經、律、論三藏，都令比丘施給他人，顯明不能自己私蓄。《涅槃經》所言護法，是為了保全僧寶，令佛法常住於世。

【1857-0002】03_業疏/19a_卷四之二#102
【原文】如《多論》中求可信人，《四分》亦爾，不許比丘親自執掌，壞心行故，餘如鈔顯。引《多論》文所以五眾不得為錢寶施主者，竝為戒制，不應行故
【譯文】如同《薩婆多論》中所說要尋求可信任的俗人，《四分律》也是如此，不允許比丘親自掌管，因為會敗壞心性操守，其餘內容如《事鈔》所彰顯。引用《多論》之文，說明出家五眾之所以不能充當錢寶的施主，是因為大家都受到戒律制止，不應當經手蓄持的緣故。

【1857-0003】03_業疏/19a_卷四之二#103
【原文】二簡主中，以捉畜二戒，五眾同制，故注云錢寶外長財即衣財耳
【譯文】在第二「甄簡施主」中，因為捉持金銀戒與蓄積金銀戒這兩條戒，五眾同受制約，所以夾注中說錢寶之外的多餘財物，就只是指衣料布匹等財物而已。

【1857-0004】03_業疏/19a_卷四之二#104

【譯文】所說「用淨施的錢寶換取衣物，不必再作說淨」，是由於當初所得的錢財已經作過說淨了。現在既然是換得衣服，並不是意料之外的長物，本來就沒有貪婪依附之心，也就是本來就沒有染著之故。

【1857-0008】03_業疏/19a_卷四之二#108
【原文】問：《多論》淨寶得財入淨不說者，寶主若死，財衣說不？答：衣寶兩主，道俗位分，既易淨財，理須展轉，但非外得，故開不說。必寶主無，還須依淨，由無所指，儲積還多
【譯文】問：《多論》說用說淨的錢寶換得財物已入淨法而不必說淨，那麼如果錢寶的施主死了，換得的衣服要不要說淨？答：衣物與錢寶的施主，出家與世俗的位分不同；既然換成了合法的衣物，按理必須作展轉淨，只是因為並非額外所得，所以才開許不必說淨。如果錢寶的施主亡故了，就必須重新依法說淨；因為施主既無所指，便又成了蓄積多餘之物。

【1857-0009】03_業疏/19a_卷四之二#109

【譯文】接著提問：用淨施的錢財換得衣服，施主死了該如何？回答中首先說明與前一樣不必說淨；「必」字以下正式裁決所產生的疑問。

【1857-0010】03_業疏/19a_卷四之二#110
【原文】如《母論》中和合淨者，謂說點染三種通淨，開無一墮及二吉羅。如《十誦》中，縫者非法，必須刺著，方無三過
【譯文】如同《毘尼母論》中所說的「和合淨」，是指說淨、點淨、染淨三種通通清淨，開許免除一個波逸提罪及兩個突吉羅罪。如同《十誦律》中所說，單純縫合在一起是非法的，必須用針刺透縫定，才沒有這三種過失。

【1857-0011】03_業疏/19a_卷四之二#111

【譯文】在第五段中，不說淨犯一個波逸提墮罪，不點淨、不染淨犯兩個突吉羅罪，這是指衣服尚未作後兩種淨化，就縫在已經清淨的衣物上面。又將五正色或五間色所染的布料縫在如法色的衣服上，以所依從的主體合成一體，所以稱為和合。其下引用《十誦律》來決斷《母論》關於「縫」的文字義理。

【1857-0017】03_業疏/19b_卷四之二#1
【原文】然以教法初開，事必有漸。古佛道法，何法不無？但為教迹乃在餘道，故因收集，共成一化。外道得其事末，隨相而行；佛隨後制，乃窮理本，令清心形，應道業故。
【譯文】然而因為教法開端之初，事相必定循序漸進。過去古佛的道法，又有哪種法門不曾具備？只因教化的形跡正流行在其他外道之中，所以因緣收集採用，共同成就一代的教化。外道只得到事相的末節，盲目執著於外相而行；佛陀隨後制定戒制，則是窮盡法理之根本，令心神與身形皆得清淨，以契應修道之業。

【1857-0018】03_業疏/19b_卷四之二#2
【原文】次科，初敘託緣，《十誦》外譏，《四分》王教，起教之端。當知說、恣，古佛常法，教有形迹，故名「教迹」。「因收集」者，謂取彼所行成我法則，欲收邪眾歸心正法，權巧之意凡小莫知。「外」下次明意別，事末則暫爾和同，理本則終令出離，似同而別，天地相懸。
【譯文】在次科中，首先敘述托附的因緣，《十誦律》中是因外道譏嫌，《四分律》中是因瓶沙王請示，這些都是興起說戒教法的開端。應當知道說戒與自恣，乃是過去諸佛的常規之法；教化顯現於外在形相痕跡，所以稱為「教迹」。「因收集」的意思，是說攝取外道所行的儀節而化成我佛門的法則，藉此招攬邪道眾生歸心於正法，這種權巧方便的深意非凡夫二乘所能測知。「外」字以下進一步闡明旨趣的差別：事相末節只是暫時順應雷同，法理根本則是最終令其出離生死，看似相同實則大異，有如天地相隔。

【1857-0019】03_業疏/19b_卷四之二#3
【原文】文中引論，言「布薩」者，乃梵本音，此以義翻，捨惡證善法也，大途如此。
【譯文】文中引用論典，說「布薩」是梵語原音，在此依義理翻譯，是「捨惡證善」的法門，大體上便是如此。
