# 校閱材料　第705檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【705-0001】04_比丘尼鈔/05a_卷下之上#28
【原文】第一藥體者此有四一時藥者此律有十謂餅麨乾飯魚及肉枝葉華果細末磨食等　二非時漿者僧祇云謂一切穀豆麥煑不破者取汁而飲諸生果汁等要以水作淨若器底殘水被雨濺等亦為淨十誦云若蒲桃不以火淨汁中不以水淨及互不淨不應飲俱淨得飲見論云舍樓伽漿者謂藕根漿澄汁使清淨得飲母論種種果多食不盡聽破汁飲若不至初夜變成苦酒者不得飲以酒勢欲成故義云若作漿法要須汁滓相分漉澄水清其狀如水方得飲之若有濁汁與時食和咽咽犯提　三七日藥者此律蘇油生酥蜜等五種世人所識當食當藥如食飯乾飯不令麤現有病因緣得非時服伽論云沙糖漿亦得七日受僧祇云此藥清淨無時食氣一時受取得七日服人有四百四病風病百一用油脂治火大熱病用酥治之水病用蜜治之雜病用上三藥治之十誦云石蜜不得輙噉除五種人得食謂遠行人病人食少人不得食人若施水處和水得噉五分飢渴二時以水和飲　四盡形藥者僧祇云胡椒蓽茇薑呵梨勒等此藥無時食和者頓受病比丘尼盡形服之此律云一切苦辛鹹甘等不任為食者聽盡形服見論云一切樹木及草根莖枝葉不任為食並得盡形受服義云今時多有僧尼非時分中食於時食何者是耶乾棗汁生棗汁乳酪清漿生藕根或諸生果搗破不以水和澄清稠濁飲之或食餲糖清飯漿等如是之類非時而食咽咽犯提。
【譯文】第一「藥物的體質」（藥體）：這裡分為四類：第一是「時藥」（按時受用的食物）：本律列出十種，即餅、炒麵、乾飯、魚、肉、枝葉花果、研磨成細粉的細末食品等。第二是「非時漿」（過午可飲用的清汁果漿）：《僧祇律》說，指一切穀豆麥類煮而不煮破皮者，濾取其汁液而飲用；各種生果汁等，務必要用水作淨；器皿底部若有殘水被雨水濺濕等，也算清淨。《十誦律》說：如果葡萄汁未經火淨、汁中未經水作淨，或者其中一項不淨，皆不應飲用；兩者都清淨方可飲用。《善見論》說：所謂舍樓伽漿，是指藕根磨搗澄淨後的清汁，清澈即可飲用。《薩婆多論》說：種種果子太多吃不完，聽許壓破取汁飲用；若是尚未到初夜時分就已轉變成苦酒（發酵酒味），則不得飲用，因為已具備酒的氣勢。《義釋》指出：熬調果漿的方法，務必要將渣滓與汁液分開，濾得澄清之水，其清澈狀如清水，方可飲用；若有混濁汁液混雜了時食，每吞下一口就犯一個波逸提罪。第三是「七日藥」（可保存七天的滋補脂藥）：本律指酥、油、生酥、蜜等五種世人所共知的油膏滋養之物；既可當作食物，亦可當作藥物；如同吃一般飯食或乾飯一樣，但不得如吃大碗飯食般顯露粗重貪相（應少少服用）。如果有病苦因緣，聽許在過午非時服用。《摩得伽論》說：砂糖漿也可以作七日藥受持。《僧祇律》說：此藥必須純淨，不含任何時食雜質，一次受持取用，可供七天內服用。人體有四百零四種疾病：風病有一百零一種，用油與脂膏醫治；火大熱病用酥油醫治；水大冷病用蜂蜜醫治；雜病則用上述三種藥調和醫治。《十誦律》說：石蜜不得任意輒食，除了五種人得以食用，即遠行之人、生病之人、食量稀少之人、不得飲食之人；若在施水之處調和水飲用亦可。《五分律》說：飢渴之時，可以調水飲用。第四是「盡形壽藥」（終身常備的治病草藥）：《僧祇律》說：胡椒、蓽茇、乾薑、訶梨勒等；這類藥品如果不混雜時食，可以整批受持，患病比丘尼可終身服用。本律說：一切苦、辛、鹹、甘等味道，不適合作為日常主食充飢之物，皆聽許終身受持服用。《善見論》說：一切樹木與草類的根、莖、枝、葉，不適合作為日常飯食的，都可以作為盡形壽藥受持服用。《義釋》指出：如今許多僧尼在非時（午後至翌晨）食用非規定的日常食物，究竟是哪些呢？例如乾棗汁、生棗汁、乳酪清漿、生藕根，或者是各種生果搗碎、未用水調和澄清的濃稠濁汁飲品，或者是食用微發酵的甜黏濁米汁等；像這類東西在過午非時食用，每吞嚥一口便犯一個波逸提罪。

【705-0002】04_比丘尼鈔/05a_卷下之上#29
【原文】第二受意者此門有二一手受二口受初手受意婆論云有五義故制一為斷盜竊因緣故二為作證明故三為止誹謗故四為成少欲知足故五為生他信敬心故次口受意為防手受故若無口受過牛便失手受由有此法乃至限滿方始法謝又為防非時不受殘宿惡觸內煑自煑等七罪手受但防不受惡觸二罪也。
【譯文】第二「接受的心意」（受意）：這一門分為二種：一手受（親手接受），二口受（口宣作法）。
首先「手受的意旨」：《毘尼母論》說：基於五個原因而制定此法：一是為了斷絕偷盜的因緣，二是為了留下清楚的證明，三是為了止息外人的誹謗，四是為了成就少欲知足的美德，五是為了生起他人的信敬心。
其次「口受的意旨」：是為了防止手受時效失效；如果沒有作口說受持之法，一過中午手受的效力便隨之喪失；正因為有口受之法，才能在期限屆滿之時受法才告終結。此外，也是為了防備非時食、不受而食、留宿殘食、惡觸、內煮、自煮等七種罪愆；單純手受只能防範「不受而食」與「惡觸」這兩種罪而已。

【705-0003】04_比丘尼鈔/05a_卷下之上#30
【原文】第三受法初受時食者未受已前要須識知食體兼作普受之意方得成受故律云欲受油錯受蘇等並不成受皆須心境相當方得名受唯除眼暗及不喜見沙門得置地受　二受非時漿口法者諸律雖制受服而無受法自下受法及說淨等並準文義出依行彌善手執湯漿至一比丘尼前云。
【譯文】第三「受持之法」（受法）：
首先「受持時食」：在接受之前，必須清楚識別食物的本質，同時心懷平等普受大眾的心念，方能成就受法。所以戒律說：本想受油卻誤受為酥，皆不能成立受法；必須心念與外境相符，才稱得上是手受；唯獨除了雙眼失明、以及不喜見僧人的情況，才開許將食物置於地上受取。
第二「受持非時漿的口說作法」：各部戒律雖然規定受持服用，卻未寫明具體的受持詞句；以下所列的受法與說淨等詞，皆依據律文義理引申而出，如法依循實踐最為完善。手捧熱湯或果漿，走到一位比丘尼面前說道：

【譯文】像這樣生薑、肉桂以及其他丸散等，隨病情因緣類比陳說即可明解。若買藥令在家人議定價格確定之後，比丘尼自己挑選；如今多是在原處買妥之後，遣人秤妥受取，不得置於地上，必須立即對同伴比丘尼施加其口法；若不這樣做，停頓片刻便會失受，生起惡觸之罪。若不能做到這樣，在買藥時令在家人受取持歸，調和搗碎完畢之後然後口受，最為妥善。

【705-0009】04_比丘尼鈔/05a_卷下之上#36
【原文】第四說淨者此七日藥一種作口法竟偏心屬己故須說淨以藥體是貴資身力強過畜延時無變動義若不說淨越過七日便犯捨墮餘之三藥不具前意不須說淨說淨方法如長衣法唯云長藥為異若初受藥忘不說淨者不成惡觸故律下文云受得生薑忘不說淨佛言應放地使淨人作淨已自應洗手更受故知忘受不成惡觸。
【譯文】第四「說淨之法」（說淨）：這種七日藥，作完口受作法之後，由於偏心專屬於自己一人，所以必須「說淨」（透過對首說法打破私有執念）。因為藥物本身珍貴，資助身體的力量很強，蓄存延時既無變質腐壞之憂，若不作說淨，一旦超過七天就會觸犯捨墮罪；其餘三種藥不具備上述情狀，所以不須說淨。說淨的方法與長衣說淨法相同，只是將「長衣」改稱為「長藥」即可。如果當初受藥時忘記說淨，並不會構成惡觸罪。所以本律下文說：受得生薑而忘記作淨（去種生相），佛說應當放置地上讓淨人作淨之後，自己再洗手重新手受；由此可知，忘記作淨並不構成惡觸。

【705-0010】04_比丘尼鈔/05a_卷下之上#37
【原文】第五通塞者手受為防其盜一人受竟通餘尼共食無罪論其口法亦通餘人由其口法加他二通之藥一者味通二者手通故捨與前人受法不失。
【譯文】第五「通達與阻隔」（通塞）：手受是為了防範偷盜，一人受持完畢，轉給其他比丘尼共同食用並無罪過；論及口受之法，也能通及他人，因為口受作法加持了其他兩項相通的藥物特性：一是味道相通，二是手受相通；所以轉送給眼前之人，原有的受法效力並不會喪失。

【705-0011】04_比丘尼鈔/05a_卷下之上#38
【原文】第六重受者義云論其手受觸失本受即須更受雖重無過若論口法依婆論云五日已還淨人來觸更餘不受藥來雜更加七日法不作二日法正從法論不從藥勢六日已去不得重加以藥物入淨故便隨藥勢更不加法若藥眾多不知何者是本藥應手口二受然後服之若病重尼不得口受傍人直爾為受與服亦得設看病尼為手口二受稱病人名亦得成受盡形壽藥若淨人來觸直爾手受不須作法以口法不失若餘藥來雜更口法受之。
【譯文】第六「重新受持」（重受）：《義釋》指出：論及手受，若經外力觸碰而失去原本的受法效力，就必須重新受取，即使重複受持也沒有過失。若論及口受，依照《薩婆多論》說：如果在五天之內，有淨人前來碰觸，或者混雜了其他未受持的藥物，應當重新追加作七日法，而不必作剩下兩天的法，這是完全依從受持律法來判定，而非依藥力的強弱來算；若是到了第六天之後，則不得重新追加，因為藥物已屆清淨效期，便隨藥力告終，不再追加作法。如果藥物數量繁多，分不清哪一份是原先的本藥，應當重新履行手受與口受兩種程序，然後再服用。如果是重病比丘尼無法親自口受，旁人直接代為受取給予服用亦可；假使照護病患的比丘尼代為行使手受與口受，口中稱呼病患的名字，也能成就受持之法。至於盡形壽藥，如果淨人前來碰觸，直接用手重新受取即可，不必再作口受程序，因為終身口受的效力並未喪失；如果混雜了其他藥物，才需要重新施以口受作法。
