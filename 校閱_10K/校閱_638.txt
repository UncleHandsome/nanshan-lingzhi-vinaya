# 校閱材料　第638檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【638-0001】02_戒疏/12b_卷三上之三#52
【原文】【疏】注解所由，因「迦葉」故。《多》云：「迦葉為營五大精舍，時治竹林，身不在故。問：『羅漢已辦，福業何為？』答：『有五義：一、為報佛恩；二、為長養法；三、為滅少脩自高者；四、為折伏弟子憍心；五、起來世福業故。』」
【譯文】【疏文】註解指明這項規定的起因，是為了「迦葉尊者」的緣故。《薩婆多論》說：「迦葉尊者為了主持營建五大精舍，當時正在修治竹林精舍，本人不在佛身邊。有人問：『阿羅漢修行大事已辦，何必還做這些求福的事業？』回答說：『有五個道理：第一、為了報答佛恩；第二、為了長養佛法；第三、為了破除那些修行微少卻自命清高者的傲慢；第四、為了折服年輕弟子的驕矜之心；第五、為了為未來世眾生樹立修福修行的榜樣。』」

【638-0002】02_戒疏/12b_卷三上之三#53
【原文】【記】注中，初科。引《論》。「迦葉」，同名者多，此即大迦葉也。「五大精舍」，「竹林」即其一焉，往營精舍，不在佛所。次問答中，五義：一、「報佛恩」者，並是如來棲止處故；二、「長養法」者，「法」上脫「佛」字；三、「少修」，謂不樂福業者；四、師猶營福，資不憍恣；五、「起來世」者，為導未來，令修福故。
【譯文】【記文】註文中的第一科，引用《論》文。「迦葉」這個名字同名的人很多，這裡指的大迦葉尊者。「五大精舍」之中，「竹林精舍」就是其中之一，尊者前去營造精舍，所以不在佛身邊。接下來的問答中列出五個意義：第一、「報答佛恩」，因為精舍都是如來安住棲止之所；第二、「長養佛法」，「法」字上面脫漏了一個「佛」字；第三、「修行微少者」，指那些不樂意廣修福業的人；第四、連大宗師都在營造福業，弟子自然不敢驕慢放肆；第五、「為未來世興起福業」，是為了引導未來的修行人，讓大家知道修福的必要。

【638-0003】02_戒疏/12b_卷三上之三#54
【原文】【疏】何以開於「十日」？以佛知法相，不緩不急，止開十日。使籌量布施，縫治作衣及說淨。故《毗尼母》云：「若放逸不說淨者，以惡心故，不滿十日，皆犯捨墮。」
【譯文】【疏文】為什麼期限只開許「十天」？因為佛陀洞徹一切事物的條理法相，規定的標準不寬也不緊，剛好只開許十天。目的是讓比丘有足夠的時間籌劃布施、縫製修改僧衣以及進行說淨。所以《毗尼母論》說：「如果有放逸懈怠不肯作說淨的人，因為心存惡意的緣故，哪怕還不滿十天，就已經構成捨墮罪了。」

【638-0004】02_戒疏/12b_卷三上之三#55
【原文】【記】次科。初敘開限得所。「緩」則心有縱慢，「急」則事容廢缺。「故」下，引證慢教無開。
【譯文】【記文】第二科。首先說明開許期限訂得恰到好處。「期限太寬」人心就會放逸怠慢，「期限太緊」事情可能來不及辦理而有所缺漏。從「所以」以下，引用律論證明：蓄意輕慢戒律的人，是不享有這十天寬限的。

【638-0005】02_戒疏/12b_卷三上之三#56
【原文】【律】尼薩耆波逸提。
【譯文】【律文】犯尼薩耆波逸提（捨墮）。

【638-0006】02_戒疏/12b_卷三上之三#57
【原文】【疏】「尼薩耆」者，制須捨也。「波逸提」者，所犯墮也。
【譯文】【疏文】「尼薩耆」，是規定必須將物品捨棄給僧團。「波逸提」，是指所犯下的墮落惡道之罪。

【638-0007】02_戒疏/12b_卷三上之三#58
【原文】【註】不犯有八：若不得衣，若淨施，若遣與人，若失衣，若故壞，若作非衣，若親友意，若忘去。反上並是尼薩耆。若捨墮衣不捨，更貿餘衣，一尼薩耆波逸提，一突吉羅。此捨墮衣應捨與僧，乃至一人，不得別眾捨——不捨，突吉羅。比丘尼同犯。下三眾，乃至下戒，並犯吉羅。不犯者，十日內，若轉淨施，若遣與人。若賊奪想；若失想；若燒想；漂想；若奪衣、失衣，取著；若他與作被；若付衣者遠行，水陸道斷——如是不淨施，不與人，皆不犯。
【譯文】【註文】不構成犯戒的情況有八種：若未實際獲得衣物，若已作說淨布施，若已託人轉送他人，若遺失了衣物，若故意毀壞了衣物，若改作成了非衣的物品，若是作親友想（認定為親友所有），若遺忘了此事。與上述相反的情況，全都屬於捨墮罪。如果應當捨棄的墮罪長衣不肯捨棄，反而拿去換取其他衣物，則構成一個尼薩耆波逸提、一個突吉羅罪。這種捨墮的衣料應當捨給僧團，乃至捨給一位清淨比丘，絕不能在別眾之中捨棄——如果不肯捨棄，犯突吉羅罪。比丘尼同樣犯此罪。下三眾（式叉摩那、沙彌、沙彌尼），乃至其餘較輕戒律，都犯突吉羅。另外不犯的情況包括：在十天之內，如果轉作說淨布施，如果派人轉送給他人。或者誤以為已經被強盜搶走；或者誤以為已經遺失；或者誤以為已經被火燒毀；被水漂走；如果是原本的三衣被奪、遺失，而拿這件長衣充作三衣穿著；如果是別人拿這塊布料替自己縫製被褥；如果是受託付衣物的人出遠門，水路陸路交通阻斷——像上述這些情況，即使沒有作說淨，也沒有送給別人，全都不算犯戒。

【638-0008】02_戒疏/12b_卷三上之三#59
【原文】【疏】就辨相中。初列八門，明持犯相。「若捨墮衣」，明除疑執。「此捨墮」下，正治罪也。
【譯文】【疏文】在辨析條文法相中。首先列出八種門類，說明持戒與犯戒的判定界限。「如果不捨棄墮罪衣料」以下，是為了解除疑難偏執。「這種捨墮衣」以下，則是正式說明治罪與懺罪的儀軌。

【638-0009】02_戒疏/12b_卷三上之三#60
【原文】【疏】初中，得衣、不得衣以分相者。如何得衣？謂手領受，或心屬己也。
【譯文】【疏文】在第一科中，以「得到衣物」或「未得到衣物」來判定法相。什麼情況才叫得到衣物？是指親手接納領受，或者在心中認定這已經屬於自己所有。

【638-0010】02_戒疏/12b_卷三上之三#61
【原文】【記】第四，辨注，初明持犯有四，初科，正釋中。但出「得相」，即「身」、「心」二受，異此則不得相也。
【譯文】【記文】第四部分辨明註文，首先說明持犯界限，共分為四科，這是第一科，進行正面的解釋。文中只指出了「得到的形相」，也就是包括「身體接觸」與「心念認領」這兩種受納，不符合這兩種情況的就不算真正得到。

【638-0011】02_戒疏/12b_卷三上之三#62
【原文】【疏】故《伽論》云：「若入手、膝上、肩上，作想我物，從是數十日也。」
【譯文】【疏文】所以《摩得勒伽論》說：「如果衣物拿到手中、放在膝上、披在肩上，心中認定這是我的東西，就從這時候起開始計算十天。」

【638-0012】02_戒疏/12b_卷三上之三#63
【原文】【記】引示中，《伽論》四相，上三是身，下一即心。
【譯文】【記文】在引證說明中，《摩得勒伽論》提出了四種情形，前三種屬於身體上的接觸領受，後一種屬於心理上的認領。

【638-0013】02_戒疏/12b_卷三上之三#64
【原文】【疏】《四分》開文，邊方入手，故數限滿。若見比丘，未須捉也。
【譯文】【疏文】《四分律》開許條文中提到，在偏遠地區衣物只要一入手，就必須計算期限。如果是看見有清淨比丘在場，就不必非要等到親手執持才算獲得。

【638-0014】02_戒疏/12b_卷三上之三#65
【原文】【記】《四分》。「邊方」開五事，長衣「入手」方犯，謂少僧處，但未手捉，容待人故。「若見比丘」者，以開未捉本為待人，今既有人，即須說淨，不說即犯，故云「未須手捉」。
【譯文】【記文】《四分律》在提到「邊遠地區」開許五事時規定，長衣必須「到了手中」才開始算犯戒天數，這是因為僧人稀少的地方，只要還沒親手拿取，就還可以寬容等待同修前來。至於「如果看見有比丘在場」，那是因為先前開許未親手拿取不算犯，本來是為了等待其他比丘來作證說淨；現在既然眼前已經有比丘在，就應當立即作說淨，不說淨就立刻犯戒，所以說「不必非要親手拿取」。
