# 校閱材料　第1884檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1884-0001】03_業疏/21a_卷四之四#66
【原文】次略點中，彼文不了，以理廢之。指如前解，謂各眾自對，見上義門
【譯文】在接下來的簡略點評中，彼律的文意不夠徹底圓通，因此依義理予以廢止不用。指稱「如前解」，是指各個階層的僧眾應當各自對同眾作法，這已見於前面的義理門徑。

【1884-0002】03_業疏/21a_卷四之四#67
【原文】有人云：但告四眾，知我行往，何如不告，故猶勝也。今解不然。立法須定，安有比丘對尼為證，義即敗也。若欲通消，但得心念；必欲令知，口告處所，終不以此為受日法也
【譯文】有人說：只要稟告其餘四眾，讓他們知道我的行蹤去向，這總比完全不稟告要好，所以還是勝過不告。我們現在的解釋並非如此。建立戒律法式必須嚴格確定，哪有堂堂大僧比丘對著比丘尼求作證明之理，若如此在律義上便已敗壞了。如果想融通排解，只可作心念法；如果一定要讓對方知曉，口頭告知去向即可，終究不能將此當作正式的受日羯磨法。

【1884-0003】03_業疏/21a_卷四之四#68
【原文】斥非中，初引他解。「今」下示今義。初正斥，律中尼及下眾可得對僧，如尼白入寺、沙彌對僧自恣之類；若論大僧，必無餘眾作證之理。「若」下釋通，先作心念，後囑而去
【譯文】在斥責非義的內容中，起初引述他人的解釋。從「今」字以下開示本宗的義理：首先嚴正斥責，律中尼眾以及下屬小眾可以對大僧作法，如同尼僧白告進入大僧寺院、沙彌對大僧自恣之類；但若論及大僧比丘，絕無讓其餘下眾作為證人的道理。從「若」字以下進行融通解釋：先作心念受法，然後口頭囑託告知便出行。

【1884-0004】03_業疏/21a_卷四之四#69
【原文】次解命、梵二難出界法
【譯文】接下來解釋遭遇命難與梵難這兩種災難時出界的法式。

【1884-0005】03_業疏/21a_卷四之四#70
【原文】緣列本二、婬女來誘調者，淨行難也。凡心染愛，無始纏懷，今暫割削，遇緣還起，故有境來，知非是淨，或因斯次有犯重障。說為難者，因中彰果；若已犯者，不名難故。惡鬼、毒蟲、不得如意醫藥，斯命難也
【譯文】事緣中列出昔日的妻子、淫女前來誘惑挑逗等，這屬於淨戒危難。凡夫之心染著貪愛，自無始劫以來纏繞心懷，如今雖然暫時割捨剃除，但一遇對境便又重新生起，所以每當誘惑之境現前，便自知難保清淨，甚至可能因此犯下破除重戒的障道之罪。之所以稱為「難」，是在起因之中顯示其可能導致的惡果；如果已經犯了戒，就不能再叫做「難」了。至於惡鬼作祟、毒蟲侵害、無法獲得合適對症的醫藥，這些都屬於生命危難。

【1884-0006】03_業疏/21a_卷四之四#71
【原文】第二命、梵移夏，釋中初科為二：初釋梵難。注列三女即婬境，伏藏是盜境。「本二」即在俗時妻，二謂匹偶也。「凡心」等者，即示難相，恐因此境汙我戒行，懼犯未犯，則名為難；已犯成罪，故不名難。「惡」下次釋命難，注列五種，皆可致命
【譯文】在第二項因命難與梵難而遷移安居的內容中，解釋的初科分為兩部分：首先解釋梵行難。注文中列出的三種女性就是引發淫欲之境，地下伏藏則是引發偷盜之境。「本二」就是指在俗時的妻子，「二」是指匹偶伴侶。「凡心」等語句，即是展示災難的相貌，唯恐因這些境界玷污了自己的戒行，懼怕犯戒而尚未犯戒之時，才稱之為「難」；如果已經犯了戒而結成重罪，就不叫做「難」了。從「惡」字以下接著解釋生命危難，注文中列出的五種情形，都是足以致命的危難。

【1884-0007】03_業疏/21a_卷四之四#72
【原文】律中但云「即應以此事去」，不言得歲
【譯文】律文中只說「即應以此事去」，並沒有明言是否算得夏歲。

【1884-0008】03_業疏/21a_卷四之四#73
【原文】次科牒示中，據云「應去」，理是得歲
【譯文】在下一科提引示明之中，依據律文說「應去」，在義理上應當算作成就夏歲。

【1884-0009】03_業疏/21a_卷四之四#74
【原文】有師解云：既開無罪，用夏何為？如《明了論》中，有難、隨意行，俱不得歲也
【譯文】有律師解釋說：既然已經開許離去而不算有罪，又何必要算得夏歲呢？如同《明了論》中所說，遇到災難以及隨意遊行，全都算不得夏歲。

【1884-0010】03_業疏/21a_卷四之四#75
【原文】次引諸解，初解中初科。彼據《了論》有難、隨意二種，竝云經宿破安居，有因緣故不得罪，如前具引
【譯文】接下來引用各家解釋，在第一種解釋的初科中。那是依據《明了論》所說的有難與隨意這兩種情形，都說過了一夜就破了安居，只是因為有特殊因緣所以不得罪，如同前文所具體引述的那樣。

【1884-0011】03_業疏/21a_卷四之四#76
【原文】若依律中「二處安居、二處受衣」，準此無夏不得受衣，今得受衣，明知有夏
【譯文】如果依照律文所規定的「二處安居、二處受衣」，比照這一點，沒有夏歲的人是不能分受迦提衣的，如今既然准許他受衣，由此明確可知他是算有夏歲的。

【1884-0012】03_業疏/21a_卷四之四#77
【原文】次準律中。「二處安居」，即移夏者。夏竟受衣，破夏不預，今既許受，有夏可知
【譯文】在第二依準律文的內容中。「二處安居」，指的就是遷移安居處所的人。安居結束受功德衣，破夏的人是不能參與分配的，如今既然准許他分受衣服，其擁有夏歲便顯而易知了。

【1884-0013】03_業疏/21a_卷四之四#78
【原文】又《五分》云：「食麤不足、父母親戚苦樂等緣，我若住者，恐失道意及命、梵、和僧，聽破安居去，無有罪也。」《十誦》云：「命、梵者，此無罪，不言得夏。和僧復云破夏去也。」《僧祇》中有二難者，接界通收，此應得夏，直去不得，以無界隔。《毗尼母》中如文所開者，大如《四分》前所解也。《明了論》中「安居有難者，住處多有博易來往，見此生貧，致犯大重，即以為難」，餘可例知
【譯文】又《五分律》說：「飲食粗劣難以下嚥、資具不足、父母親戚有痛苦歡樂等各類事緣，我如果繼續住下去，恐怕會喪失修道之心；以及遇到命難、梵行難、或為了和合僧眾，律中准許破安居離去，沒有罪過。」《十誦律》說：「遇到命難與梵難而離去的人，這沒有罪過，但未明言算不算得夏。遇到和合僧的緣由，又說是破夏離去。」《僧祇律》中遇到這兩種災難的人，可以連接界線通融兼收，這應當算得夏歲，若直接離去則不算得夏，因為並未以結界相隔。《毗尼母論》中如同經文所開許的，大體與《四分律》前面所解釋的相同。《明了論》中說「安居時遇到災難，是指住處頻繁有貿易交易來往，看見這些引發貪貧之心，甚至導致犯下大重罪，這就稱之為難」，其餘情形皆可依此類推。

【1884-0014】03_業疏/21a_卷四之四#79
【原文】三引證中大有五段。《五分》中，食麤謂有病不如意，不足謂供須有缺，親戚苦樂謂俗舍凶喜事，此三約義亦命、梵所收。《十誦》和僧破夏，亦如前引。《僧祇》夏中有難，結三由旬界於中往來。《母論》如文，即指注中「大如《四分》」，即上二處受衣文。《了論》博易，亦犯盜緣。前引三律，竝非明斷；後引《了論》，但出難相；中間《母論》，乃為明決，顯知得夏
【譯文】在第三引證之中大體包含五段。《五分律》中，飲食粗劣是指生病時飲食不合調養，不足是指日常供養所需匱乏，親戚苦樂是指俗家有凶喪喜慶等事，這三種從義理上看也都屬於命難與梵難所統攝。《十誦律》說為了和僧而破夏，也如同前文所引用。《僧祇律》規定安居中遇到災難，可以結三由旬的大界在界中來往。《毗尼母論》如同經文所載，就是指注文中所說的「大如《四分》」，也就是上面所說的在兩處受衣的經文。《明了論》說的貿易買賣，也是引發犯盜戒的因緣。前面所引的三部律典，都不是明確的判定；後面所引的《明了論》，只是列出災難的相貌；唯有中間的《毗尼母論》，才是明確的決斷，由此顯然可知算得夏歲。

【1884-0015】03_業疏/21a_卷四之四#80
【原文】又云：但破安居，不失夏。夏計行功，不虧法故；安居在處，出故名破也
【譯文】又解釋說：只是破了原本處所的安居，卻不失掉整體的夏歲。因為夏歲計算的是修行的功德，並未虧損修道之法；而安居本指固定居於某一處所，離開了原處所以才稱之為破。

【1884-0016】03_業疏/21a_卷四之四#81
【原文】次解。既移其處，故破安居；隨處修道，故不失夏
【譯文】下一種解釋。既然遷移了原本的處所，所以叫做破安居；但隨其所到之處繼續精進修道，所以不失掉夏歲。
