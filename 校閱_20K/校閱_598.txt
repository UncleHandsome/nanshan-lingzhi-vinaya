# 校閱材料　第598檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【598-0001】資持記/11d_中四上#2
【原文】且舉一條，諸餘例顯；用前三句，照會諸戒，通局之相，如指諸掌。初四境中。初句示境，即是六趣，或總三趣。若下，且對初篇，四境無論男女，人中不簡道俗大小內外，初戒齊犯可知；餘三戒，人境同夷，非人竝蘭，畜則殺提，盜妄俱吉，故云昇降也。又如摩觸、媒、麁、對趣差別，尋前〈隨相〉。
【譯文】這裡姑且列舉一條為例，其餘戒律都可依此類推而顯明；運用前面所說的三種對照關係，去核對審視各條戒律，其普遍適用與局部限定（通局）的具體情況，便如看手掌中的紋理一樣清楚分明。在第一種「四境」之中：初句標明所對之境，即是六道眾生，或總括為三道。從「若」字以下，是暫且對應第一篇（波羅夷法）來談：四境之中無論男女，在人類中也不分僧俗、尊卑老幼、佛門內外，觸犯第一條婬戒同樣都成重罪，這是不言而喻的；至於其餘三戒，面對人類之境同樣犯波羅夷罪，面對非人之境則同犯偷蘭遮罪；若面對畜生之境，殺人戒對應殺畜生犯波逸提，盜戒與妄語戒則都犯突吉羅，因此說罪報有輕重的升降差別。又如同觸摩戒、媒嫁戒、麁語戒，對應六道眾生各有差別，請參閱前面的〈隨相篇〉。

【598-0005】資持記/11d_中四上#6
【原文】此中所明，在文不貫。漏失同者，亦色為境；婬唯內色，漏總六境，內外中間水風空處；今就內色，以論，四境多分壞白骨間，皆漏失境，故云仍寬。若據摩觸，亦通四女；觸屍亦殘，理同婬判。自下，次明心中。觀即發諍戒，望僧能觀心成犯。許即迴僧物，望施心成犯。
【譯文】此處所說明的，在文義脈絡上並無相互貫通。漏失戒與此相同之處，也在於以物質色身為境；行淫唯局限於體內之色，漏失戒則總括六種境，包括體內、體外、體內外中間、水、風、虛空等處；現在僅就體內色身來論，四境之中多數在體壞甚至化為白骨的階段，都是漏失戒的結罪之境，因此說其範圍依然更寬。若按照摩觸戒來看，也通於四種女性之境；觸撫屍體同樣結僧殘罪，法理上與婬戒的判斷相同。自此以下，接著說明屬於心識（心）的部分：觀察，即是指挑起諍端（發諍）戒，是針對僧團能夠審察自心而構成犯戒。應許，即是指挪用僧團公物（迴僧物）戒，是針對施主原本的施心而構成犯戒。

【598-0006】資持記/11d_中四上#7
【原文】染心衣食，即尼受染心男子衣食，犯殘，取彼染心為境。結示中。上句結前，下句示略。外事中。草木即壞生，及草上便唾。入錢寶等物、畜、貿、盜、捉，成犯；又水為境，如水中戲、大小便；火謂然火；又水風空，盜漏皆犯。不受等，九十及眾學等諸食戒，竝食為境。又食局正食者，如足、別、背，餘通正不正。
【譯文】染著之心接受衣食戒，即是比丘尼接受懷有貪染之心的男子所供給的衣食而結犯僧殘，這是以彼男子的染著之心作為所對之境。在「結尾明示」（結示）之中：上句總結前面的內容，下句標明省略的意旨。在「外界事物」（外事）之中：草木即是摧毀植物生長（壞生）戒，以及在草木上大小便或吐唾液戒。牽涉到金錢珍寶等物品的蓄積、買賣交易、盜取、捉持，都會構成犯戒；又有以水為境的，例如在水中嬉戲、向水中大小便；火是指故意點火戒；又如水、風、虛空，犯盜戒與漏失戒時都會涉及。未經受授等戒律，在九十波逸提以及眾學法等各項飲食戒中，都是以食物為所對之境。此外，食物又有局限於正餐主食（正食）的情況，例如食足再食、別眾食、受請背席等戒，其餘飲食戒則通於正食與不正食。

【譯文】或者有局限於「時藥」的，如過量受食、索求美食等戒便是；局限於「七日藥」的，如蓄積多餘藥品戒便是；局限於「盡形壽藥」的，如受用四月藥戒便是；通於「四種藥」的，即是未經受授而食、非時而食等戒。蓄積多餘衣缽、離衣宿（二離）、等待月望月晦（月望）、受急施衣等戒律，都是依據具體事緣兼及時間，但姑且依所依物品來論定，因此說「亦可」。此處還應當進一步收錄求取羊毛、棉線等各項乞求戒律。若依照「四事供養」來分，衣服與醫藥如同前面所說；房舍則如自作無主房與有主房兩戒、覆蓋屋頂戒、強行牽出僧房戒、安放佛像等；臥具則如兩重敷設、兜羅綿墊之類。以上說明的是純粹的外在事物之境（單外境）。
