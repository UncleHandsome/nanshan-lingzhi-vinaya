# 校閱材料　第805檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【805-0007】02_戒疏/19b_卷四下之一#16
【原文】【註】不犯者：若知彼物，相體而舉；若在露地風雨漂漬，舉之；若物主慢藏，衣物狼籍，為誡敕故藏之；若借他衣，而彼不收襵，恐失故舉之；或以此衣鉢諸物故，有命、梵等難故藏——一切無犯也。
【譯文】【註文】不犯的情形：如果知道那是對方的東西，認清形體後代他收起；如果在露地遇到風雨浸壞，替他收起；如果物主輕忽收藏，衣物散亂狼藉，為了告誡教敕而替他收藏；如果是將自己的衣服借給別人，而對方沒有摺疊收好，自己怕遺失所以代為收起；或者因為這些衣鉢等物的緣故，有命難、梵行難等災難而收藏——這些全都無犯。

【805-0008】02_戒疏/19b_卷四下之一#17
【原文】【疏】戒本三句。二、出所藏物。言「下至戲笑」，上至生怖失意。三、結罪。餘如《鈔》中所引。
【譯文】【疏文】戒本有三句。第二句，是列出所藏的物品。所說「下至戲笑」，是就最低的程度說；往上則到令對方生起恐怖、失魂落魄。第三句，是結罪。其餘的如同《鈔》中所引。

【805-0009】02_戒疏/19b_卷四下之一#18
【原文】【記】戒本。初句犯人，易故不列。下指「如《鈔》」，須者尋之。注不犯中，五別，前四並以「若」字分之。初、相體悉，二、恐損壞，三、為驚他，四、恐失脫。上三並他物，四即己物。「或」下，第五難緣，對文可見。
【譯文】【記文】戒本。第一句是犯人，因為容易了解所以不列出來。下文指出「如《鈔》」，需要的人可以去查尋。注解的不犯中，有五種分別，前四種都用「若」字來區分：第一、認清物相形體；第二、怕被損壞；第三、為了警誡對方；第四、怕遺失散落。前面三種都是他人的物品，第四種是屬於自己的物品。「或」字以下，是第五種災難的因緣，對照注文就可以明白。

【805-0012】02_戒疏/19b_卷四下之一#21
【原文】【疏】凡淨施之法，為遣封著，事雖漸約，遠同大行。衣既付彼，時取須問，不問輒須，還同不施，現違聖禁，未能割略。又物不在主，失相惱深，故結。
【譯文】【疏文】凡是淨施的做法，是為了遣除慳吝執著；事情雖然只是漸次地約束，長遠說來同於大行。衣服既然已經交付給對方，到時候要取用就必須先問；不問就擅自索取，就等於沒有施出去一樣，現在就違犯了聖教禁戒，因為還不能割捨。又，物品既然不在物主那裡，對方失去它，惱害很深，所以結罪。

【805-0013】02_戒疏/19b_卷四下之一#22
【原文】【記】五十九，制意有二。初乖於淨法。前敘施意。漸捨「封著」，終成檀度，故云「遠同大行」。「衣」下，明輒取。取用自任，還同屬己，故云「未能割略」，謂畜心不斷也。「又」下，二、惱彼淨主。由不語知，彼謂失故。
【譯文】【記文】五十九，制戒的用意有二：第一、違乖淨施之法。前面先敘述施與的用意：漸次捨棄慳吝執著，最終成就檀度，所以說「遠同大行」。「衣」字以下，說明擅自取用：任意自行取用，就等於還屬於自己，所以說「未能割略」，意思是貯畜之心沒有斷除。「又」字以下，是第二、惱害那位淨主，由於不告訴他，他會以為東西遺失了。

【805-0021】02_戒疏/19b_卷四下之一#30
【原文】【疏】問：「如解義中，真淨施法，兩部不合更互而作，何以戒本通列者？」
【譯文】【疏文】問：如「解義」中所說，真實淨施的作法，僧、尼兩部不應互相對作，為什麼戒本卻通列五眾呢？

【805-0022】02_戒疏/19b_卷四下之一#31
【原文】【疏】答：「為明五眾俱有犯相，雖輕重異，淨施義同，故通列名。至於淨法，自從律法。」
【譯文】【疏文】答：是為了說明五眾都有犯戒的相狀，雖然罪有輕重不同，但淨施的道理相同，所以通列五眾的名字。至於淨施的作法，自然依從律的規定。
