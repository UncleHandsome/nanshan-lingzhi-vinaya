# 校閱材料　第1270檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1270-0001】資持記/13a_下一#57
【原文】一端，此間謂之一疋。指作謂指擬欲作而未作也。五肘，謂取長五廣三肘體，是法衣量，不須說淨；已外須說。〔引此證前，定量彌顯。〕四中，初科，前明轉作三衣。若下，次明製作納衣。《五分》中，初出非法。前四犯吉，後一結蘭。言染作者，謂以別色染為條葉。縫著謂不却刺，故注以斥之。
【譯文】「一端」，在我們漢地稱為「一疋」。所謂「指作」，是指心中打算要作法衣而尚未真正動手裁作。所謂「五肘」，是指截取長五肘、寬三肘的整幅布體，這已是法衣的規定尺寸，不需要行說淨之法；超出這個尺寸以外的多餘布料，則必須行說淨法。〔引用這點印證前文，衣服的定量規定更加明確昭著。〕第四項中，第一科，前半段說明將舊衣改製為三衣的方法。自「若」字以下，次一節說明製作百衲衣的方法。在《五分律》中，首先列出非法的做法。前四種情況犯突吉羅罪，後一種情況結犯偷蘭遮罪。所謂「染作」，是指用不同的顏色在布上染出條葉的形狀。「縫著」是指不採用倒針縫刺，所以注釋中予以斥責。

【1270-0002】資持記/13a_下一#58
【原文】襵葉，準彼三衣，俱為非法；《四分》開下衣，餘二亦非襵。半向上下者，謂開葉相俱須順下，不得逆上。阿難下，次明如法，初教安條葉。靡猶順也，謂條葉相壓，須順左右。且如七條，兩邊三條，各順左右一向，中間一條，兩壓左右之上，故云兩向順。若下，次明隨物裁製，初引文。
【譯文】至於「打褶作葉」，依準該律的規定，三衣全部屬於非法；《四分律》僅開許下衣可以打褶，其餘二衣同樣不可打褶。「半向上下」是指翻開的葉相全都必須順向朝下，不得倒逆朝上。自「阿難」以下，次一節說明如法製作之軌則，首先教導如何安立條與葉。「靡」就是順隨的意思，是指條與葉互相疊壓時，必須順應左右的方向。例如七條衣，兩旁的各三條，各自朝著左向或右向順平疊壓，正中間的一條，則同時壓在左右兩條之上，所以稱為「兩向順隨」。自「若」字以下，次一節說明隨順布料多寡裁製法衣，首先引述律文。

【1270-0003】資持記/13a_下一#59
【原文】若得衣者，或衣財，或已成者。不足，謂作二十五條大衣，財猶少也。次第減降，故兩云乃至。準下，義決。初決文相，二示受法，三引文證。《僧祇》，初示非法。彼云：有比丘對頭縫，佛言：不應對頭縫，應作葉。謂彩畫條葉，直爾縫之；邊緣相屬，故言對頭。應下，教如法有六，初制割截。
【譯文】所謂「若得衣」，或者是指得到做衣的布料，或者是指得到已經縫好的衣服。所謂「不足」，是指想要製作二十五條的大衣，但布料資財依然不夠。因而依序縮減降等，所以文中有兩處說到「乃至」。自「準」字以下，依循義理作出裁決：第一是判定律文的文相，第二是提示受持之法，第三是引述文獻為證。《僧祇律》中，首先標明非法的做法。該律說：有比丘將布對頭平縫，佛陀說：不應當對頭平縫，應當做出葉相。這是指僅用彩色畫出條葉之相，直接將布邊對綴縫合；兩邊布緣緊密相連，所以稱為「對頭縫」。自「應」字以下，教導如法縫製的六個要點：第一，規定必須割截碎塊。

【1270-0004】資持記/13a_下一#60
【原文】極下，二示條葉大小。《業疏》云：今多廣大，澆風扇也。《章服儀》云：如小獷麥，得分畦畔，為世福田；今則過其正度，故非法服。準須依教，不應廣闊。不下，三明長短相差。縫下，四明縫刺。宣謂散解。馬齒縫，舊云偷針刺，若馬齒闊。或作鳥足縫，疏云：押葉丁字有三叉相，是也。
【譯文】自「極」字以下，第二點，標示條與葉的寬窄大小。《業疏》說：如今世人多把條葉做得極為寬大，這是澆薄奢靡的風氣吹拂煽動所致。《章服儀》說：條葉應當如同小麥粒般微凸，恰好分出田疇水畦的邊界，以此為世間作福田；現今之人卻遠遠超過了正常的度數，所以這根本不是法衣。應當嚴格依準教法，不該做得過於寬闊。自「不」字以下，第三點，說明長短條塊必須交錯參差。自「縫」字以下，第四點，說明針線縫刺的法度。「宣」是指布線鬆散解脫。「馬齒縫」，舊稱「偷針刺」，針腳有如馬齒那般疏闊。或者作「鳥足縫」，《律疏》說：壓在葉相上的「丁」字形有三叉的相貌，就是這種縫法。

【1270-0005】資持記/13a_下一#61
【原文】衣下，五明施緣。疏云：以周緣故，持無速壞。急時如前，謂麁行急竟，後更刺也。借下，六明安紐。即指離衣戒。彼明比丘有緣至他處留宿，暫借俗被受持，作淨安紐等。第五中，初引律示法。䩙，胡犬反，鉤也。準下，顯示文意。《業疏》云：逼邊緣四指安鉤，擬反向後八指取紐；
【譯文】自「衣」字以下，第五點，說明在四周安施緣邊的道理。《律疏》說：因為有四周圍繞的緣邊，穿持受用才不會過快破壞損壞。緊急時的做法如同前文所述，是指先以粗針大線緊急縫成就行，日後再行細密縫刺。自「借」字以下，第六點，說明安裝鉤紐的法度。這正是指離衣戒中的規定。那裡說明比丘若有要事到他處借宿，暫時借用俗人的被子行受持法，必須先作說淨並安上鉤紐等。在第五小節中，首先引述律文昭示法式。「䩙」字音為胡犬反，是指衣鉤。自「準」字以下，顯發律文的深意。《業疏》說：緊貼衣服邊緣四指處安設衣鉤，以便反折向後八指處去扣取衣紐；

【1270-0006】資持記/13a_下一#62
【原文】以覆左肩，故有遠近也。《章服儀》云：良以用衣右角掩覆左肩；前鉤後紐，收束便易；所以西來聖像，東土靈儀，衣在左肩，無垂肘膝等。〔今時垂肘象鼻非法。〕六中，初明制刺。却即是倒，謂倒針刺。異俗者，彼唯直縫故。防外道者，有比丘直縫衣，為彼抽線使零脫故。又下，明補衣亦刺。四下，準決本宗。
【譯文】用來覆蓋遮掩左肩，所以鉤紐之間有距離遠近的差別。《章服儀》說：這實在是因為要用衣服的右角遮掩覆蓋左肩；前方安鉤、後方安紐，收束整頓起來極為便利省事；所以西方傳來的尊者聖像、東土留存的神靈儀相，法衣皆妥貼在左肩之上，絕沒有拖垂到手肘與膝蓋之下的情況。〔現今有些人把法衣垂在肘外形同象鼻，這完全是非法的。〕第六小節中，首先說明規定倒針縫刺的緣由。「却」就是倒退，是指倒針縫刺之法。為了區別於世俗，是因為世俗之人只會順向前進直縫。為了防範外道破壞，是因為曾有比丘直縫衣服，被外道暗中抽去縫線使整件衣服散落脫節的緣故。自「又」字以下，說明補綴衣服時也應當採用倒針刺法。自「四分」以下，依準《十誦律》來決斷本宗的行事規範。


【1270-0007】資持記/13b_下一#1
【原文】七中，初明揲角。疏云：相助為力故。又下，次明安紐揲肩。然須揲者，為障垢膩。疏云：數浣本衣，恐速壞故。八中，初引緣。聚落下，應加犯吉字助釋方顯。鉤欄即條葉。當字去呼。十下，例開貧乏，上句躡上開文。下二句準例。貧無餘服，糞掃五納安揲分相，入聚無過。
【譯文】第七項中，開頭先說明補綴四角。律疏說：這是為了讓四角相互支撐、增加牢度。從「又」字以下，接著說明安設鈕扣與在肩部加綴補布。之所以必須加補布，是為了阻擋汗垢油脂。律疏說：若頻繁洗滌本衣，唯恐它太快損壞。第八項中，開頭先引述制戒緣起。從「聚落」以下，應當加上「犯吉羅」這幾個字來輔助解釋，文義才會彰顯。「鉤欄」就是指衣上的條葉。「當」字讀作去聲。從「十」字以下，例行開許貧窮匱乏的情況，上一句是承接前文的開許規定，後兩句則依照通例推展。若貧窮而沒有多餘的衣物，使用糞掃衣或雜碎布料拼綴出條條的分相，穿著進入村落聚落，是沒有過失的。

【1270-0008】資持記/13b_下一#2
【原文】三明受持，對首中，用法分二，前示《四分》缺文，初句立制。若下，明再受。疑謂先受後忘，或復失否未了，並令捨已更受明白。昔下，次明古今用別，初引古。注顯不同之相。彼律約夜分三，內宿初夜成犯；覆罪護夏，約明相犯；離衣犯雖明相，持通夜分。
【譯文】第三，說明受持。在對首法中，行持方法分為兩部分：前面先指明《四分律》原文的缺漏，第一句確立了制戒規範。從「若」字以下，說明重新受持的情況。「疑」是指先前受持過後來遺忘，或是無法確定是否已經失法，這時都應當先捨棄舊受，然後再重新如法受持，使之明白確立。從「昔」字以下，接著說明古今用法的差別，先引述古時的說法，夾註中顯示了不同的形態。彼律就夜分（判定持犯）共有三種情況，關於食物內宿，過了初夜便構成違犯（食物不可在僧舍內宿過夜）；覆藏罪過與護持結夏安居，則是依照破曉時的明相來判定犯相；而離衣之犯雖然也以明相為準，但受持的效力卻貫穿整個夜分。
