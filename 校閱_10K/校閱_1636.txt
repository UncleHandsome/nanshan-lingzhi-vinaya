# 校閱材料　第1636檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1636-0001】03_業疏/05b_卷一之五#113
【原文】次今立中為二：初明同異，「古」下二斥餘本。初中，前明四異。「非苟異」者，苟猶強也。「何」下徵示：初緣出《母論》、本律，故云「佛制」等；二兩界者，次師假界唯取作法，不通自然，法有通塞，總義已明；三、四兩緣，初師集僧但據問集，不分作相、約界之異。故前四種，竝今剏立，咸準誠文，如前注顯。「至」下次明六同：和相與問答同初師，簡人、欲淨同初後二師，緣緒即正陳意，此同後師，據理合爾，故非苟同。斥餘本中，「古本曹魏」者，鎧本竝不立緣；諦本首云：「凡諸羯磨，應先白：『未受具戒者出，不來比丘說欲清淨。僧今和合，何所作為？』答：『某羯磨。』」止有簡眾、說欲、問答四緣，故云「太簡」也。光本已亡，不知所立。故下結示今備
【譯文】在隨後「明今所立」中分為兩部分：首先辨明同異，自「古」字以下，第二駁斥其餘版本。在第一部分中，前面說明四種相異之處。「非苟異」，「苟」相當於勉強。自「何」字以下徵引說明：第一緣出自《毗尼母論》與本律，所以說「佛制」等；第二緣兩界，相部師的「假界」只取作法界，不能通於自然界，法有通塞之別，總括的義理前面已經闡明；第三、第四兩緣，初師（愿律師）集僧只依據詢問僧集，不區分敲槌作相與依界聚集的差異。因此前四種因緣都是現今所創立，全依準真實經律之文，正如前面注釋所顯明。自「至」字以下，接著說明六種相同之處：和相與問答同於初師，簡人、欲淨同於初師與後師，緣緒即正式陳述本意，此同於後師（礪律師），依照理則理當如此，所以不是隨意附和。在駁斥其餘版本中，「古本曹魏」，康僧鎧的譯本並未確立各緣；曇諦的譯本卷首說：「凡各種羯磨，應當先宣告白文：『未受具足戒者請出去，未能前來的比丘請傳達與欲清淨。僧眾如今和合，要作何事？』回答：『作某某羯磨。』」彼本只有簡眾、說欲、問答這四緣，所以說是「太簡」。光師之本已經失傳，不知其所立因緣為何。因此下文總結顯示現今所立已完備無缺。

【1636-0003】03_業疏/06a_卷一之六#2

【譯文】在「眾法對首」中，人若不如法則有過失，事情雖然可能繁多，但歸結起來只是屬於別眾，或者被歸入不入僧數。如果論及法事，則隨不同因緣而各自有異。例如五人同住在一處作捨墮衣懺悔法，隨事有一人是所為之人（出罪者），不計入僧數之中；其餘四人起初作為僧眾所用，姑且能夠受理捨衣；若由一人接受其懺悔，則其餘二人便不再成僧，被破除簡別無餘了。其餘行相如上所述。四人自恣、三人說戒，乃至下至二人，全都沒有與欲之法，都稱為對首，依照人數則各有不同，羯磨文詞必須相應改換，不必拘泥死誦。

【譯文】在「眾法對首」中，首先說明「人之非」，無非是被別眾、不入僧數所收攝。自「若」字以下，接著說明法事。在最初的捨墮法中，六人同住則全行僧法，四人同住則純屬別法，現今這五人同住，所以貫通於僧法與別法。最初捨衣與最後還衣都是僧法，口頭和合問對這一邊就是別法；「破」相當於甄簡。其次在說戒與自恣中，所謂「依照人數必須改換」，是指說戒自恣面對二人時則稱「二大德」，自恣面對三人時則稱「諸大德」，面對一人則如平常慣例。

【原文】但心念者，人事可知。下二心念，界同人別者，以本是對人眾法，既獨在界，故開作之。今若有人，還是本法，不合別作，前集法中具分其位
【譯文】所謂純粹心念（但心念），其人與事之相狀顯而易見。至於下文的兩種心念，之所以「界同而人別」，是因為這兩種心念原本分別是對人法（對首法）與眾法（僧法），既然單獨一人在界內，所以才開許作心念法。如今如果界內有人，就還是應依本法辦理，不應當另外作心念法，在前面的集法之中已詳細分別其位次。
