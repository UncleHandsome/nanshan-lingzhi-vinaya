# 校閱材料　第401檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【401-0001】資持記/02e_上一下#27
【原文】有執成別，故問通之。答中，初句直斷。以下，申所以。上句示欲意，下二句顯非所為。反顯若以欲緣為羯磨事，則容有別。疏云欲本不稱〔謂不牒緣，意在下答。〕，僧為又別〔正同此意〕，但知通意，故兩無違；義須應往，故結小犯。文下，引決。如法治者，吉羅異名。轉難中。
【譯文】有人執著這會構成別眾，所以藉由提問來融通說明。回答之中，第一句直接判定。「以」字以下，陳述箇中原因。上一句指出給欲的本意，下兩句顯明這不是當時僧眾所要辦的事。反過來顯明如果把託欲的原由作為當前僧眾羯磨的事由，就可能產生別眾的問題。《業疏》說給欲原本就未稱述事由〔意思是沒有陳列事由，意旨留在下文回答中。〕，僧團所辦的事又是另一回事〔正是同於這個意思〕，只要明白通達這層深意，兩者就互不相違背；但按義理他應當前往僧中，所以判定犯輕微的罪過。文句以下，引用律文來決斷。「如法治」，就是突吉羅罪的另一種名稱。在「轉難（進一步詰難）」之中：

【401-0002】資持記/02e_上一下#28
【原文】事休是同，而法謝不謝有別，故引相並。答文，易解。5 釋羯磨篇(上一下)釋羯磨篇律中羯磨，大有三位，別開八品；隨事細歷，則有一百八十四種；今此篇中，總明緣法是非成敗；望下諸篇，隨事各別，故云通辨。羯磨梵言。或云劍暮，音之訛轉。注中，初引文示。
【譯文】事情停歇這一點相同，而作法是否謝落終止則有差別，所以引來互相對照比並。回答的文義容易理解。5 「釋羯磨篇（上篇之一的下半部）」「釋羯磨篇」：律典中的羯磨，大致有三個位階，分別開演為八個品類；如果隨順具體事務詳細考究，則有一百八十四種之多；現在這一篇之中，總括說明事緣與作法的是非、成敗；對照後面各篇，則是隨順具體事務而各有不同，所以說是「通辨（通盤辨明）」。羯磨是梵語，或者稱作「劍暮」，那是讀音的訛誤轉音。在注釋之中，首先引用經文來開示。

【401-0003】資持記/02e_上一下#29
【原文】《了疏》兩翻，大體無異。前則名作為業；後直指作，無復異名。業謂行心鼓動身口，假緣搆造，則有勝功，能遂前事；疏云：業謂成濟前務，必有達遂之功是也。《百論》云事，亦業之異名，無非造作，即體為目。次義求中。此從昔義，疏中不取；
【譯文】《了論疏》有兩種翻譯，大體上沒有不同。前一種是把「作」稱為「業」；後一種則是直接指稱「作」，不再有別的名稱。「業」是指發動造作的心念（行心、思心所）驅策身業與口業，憑藉著各種助緣構作造辦，就會產生殊勝的功用，能夠成辦眼前的事務；《業疏》說：業是指成就救濟眼前的事務，必然具有通達圓滿的功用，正是指此而言。《百論》把這稱為「事」，也是「業」的另一種名稱，無非都是造作的意思，直接以本體作為名稱。接著在「義求（探求義理）」之中：這是順從古代的舊說，律疏中並不採用；

【401-0004】資持記/02e_上一下#30
【原文】彼云：自古至今翻為辦事者，非無此義，但用功能往翻。謂下，釋義。疏出彼解，謂成辦生善滅惡之事。問：此與《百論》何異？答：彼論直召能造，不從所辦。問：疏家所以不取者？答：凡立名定體，從用則疎；如燈能照暗，燈不名照。水能滅火，水不名滅。但分體用，名亦無在。
【譯文】古人說：從古至今把羯磨翻譯為「辦事」，並非沒有這個含義，只是用它的功能來作翻譯罷了。「謂」字以下，解釋其含義。律疏列出他們的解釋，是指成辦「生善滅惡」的事業。有人問：這與《百論》有什麼不同？回答說：那部論是直接稱呼能造作的主體，而不是從所成辦的事業來說的。有人問：律疏作者為什麼不採用舊說？回答說：凡是確立名相、判定體性，若是從功用方面著手就會顯得疏遠不貼切；就像燈能夠照破黑暗，但燈不能就叫作「照」。水能夠熄滅火焰，水不能就叫作「滅」。只要分清本體與功用，用什麼名稱也無傷大雅。

【401-0005】資持記/02e_上一下#31
【原文】所以疏家旁通舊解。敘意中，初科，初句示能秉人。即前三篇。次句明所秉法。即是此篇。統即是總。僧位所立，止存秉御，無他所為，故曰其唯。方下二句顯功。亦即所被事，即後諸篇。僧獨無能，假法彰勝，故曰方能。群迷重累，謂三不善業；界分深根，即五住煩惱。
【譯文】所以律疏作者只是順道融通舊有的見解而已。在「敘意（敘述宗旨）」之中，是第一科。第一句標示出能夠主持羯磨的人，也就是指前面的三篇。下一句說明所主持的法度，也就是指現在這一篇。「統」就是總括的意思。僧伽階位之所以確立，完全只在於主持統御法事，並沒有其他多餘的目的，所以才說「其唯」。方字下面的兩句顯明其功用，也是指羯磨所施加的事務，也就是後面的各篇。僧眾如果單憑自己則無所作為，必須憑藉教法才能彰顯殊勝，所以說「方能」。群迷的重累，是指身口意三種不善業；界分中的深根，就是指五住煩惱。

【401-0006】資持記/02e_上一下#32
【原文】業縛自心，縛之彌固，故云重累；惑生業苦，生之無窮，故曰深根。群迷指六道正報，界分即三有依報。此明超凡趣聖，功由羯磨矣。又有解云：上句滅惡，下句生善；非無此義，即如疏云：生善之大，勿過受體；滅惡之大，勿過懺重等。德下二句正歎。上句歎體，成濟之廣；下句歎用，諸法中最。
【譯文】惡業繫縛自己的心靈，而且越縛越牢固，所以稱為「重累」；惑障引生造業受苦，而且無窮無盡地滋生，所以稱為「深根」。群迷是指六道輪迴的正報眾生，界分是指三界的依報環境。這說明超越凡夫趣向聖道，全憑羯磨的功勳了。另外還有一種解釋說：上一句是滅惡，下一句是生善；這並非沒有道理，正如律疏所說：生善的極致，沒有大於受戒得戒體的；滅惡的極致，沒有大於懺除重罪的。德字下面的兩句是正式讚歎：上一句讚歎羯磨的體性，其成濟救拔的範圍何等廣大；下一句讚歎羯磨的功用，在一切法門之中居於至尊之位。

【401-0007】資持記/02e_上一下#33
【原文】敘訛中，初敘正教可聞。如來滅度，常光隨息，故曰棲光。但下，次明因人訛替，初六句敘人非。上二句明無志，次二句明無言，下二句明無行。無此三者，未足稱僧；況為師首，輒秉聖法，寧無愧乎；陶，化也。俗風謂世事。由心染世，故情鄙薄；鄙謂下劣，薄即輕浮。礫謂礫石；
【譯文】在「敘訛（敘述訛傳）」之中，首先敘述正統教法原本是可以聽聞的。自從如來入滅之後，常寂的光芒便隨之歇息，所以說「棲光」。但字以下，接著說明因為人事的衰敗而導致訛替傳承，前面六句先敘述僧人的過失。上面兩句說明心中無志向，中間兩句說明言談無標準，下面兩句說明舉止無德行。缺乏這三樣條件，根本不足以稱為僧寶；更何況還忝居師位領袖，隨意主持神聖教法，難道內心能不感到慚愧嗎！「陶」，是教化的意思。「俗風」，是指世俗的事務。由於心靈沾染了世俗，所以情操變得鄙陋淺薄；「鄙」是低劣，「薄」就是輕浮。「礫」，是指瓦礫碎石；

【401-0008】資持記/02e_上一下#34
【原文】言喻瓦石，不足貴也。真淨文即羯磨。參即是雜，或約參預秉御，或可增減文句。在三者，謂君父師是人倫之大本，君則義重，父則恩重，師即君父之間；《弘明集》云：君親之義，在三之訓是也。致下一句明法非。事下，明事非。納，入也。竝下，推過，還結三非。雖行眾事，莫知得失，故曰混同。
