# 校閱材料　第586檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【586-0001】02_戒疏/10c_卷三上之一#3
【原文】【記】三中，羯磨「八人」者，兩處各成眾故。「彼此不成」者，互望別眾故。法輪中，初標徵。「故」下，列示。初出能破。主及四伴，通為「五人」，由非真佛，故在僧數。「一佛」下，示所破。法寶可知，文中不列。師徒五人而言「四」者，佛寶位別，故不在數。故能、所十人，但云「九」耳。「所以」下，徵示真佛不入之意。《俱舍》「破在別處」者，以對能立所，故云五人，及論正破，不在佛會。如下文說，破在伽耶。「輕」謂輕陵，「逼」謂逼惱。「言教可信」者，若在佛所，必受佛化，破不成故。下引《雜心》，共成三意。
【譯文】【記文】在第三項中。羯磨破僧所謂的「八人」，是指分裂的兩方各自達到成辦僧事的法定人數。「彼此不成」是指雙方相互視為非法異眾。法輪破僧的段落中，開頭先標出徵問。「故」字以下，逐一列舉說明。先點出能破的一方。邪師主首加上四名同伴，合稱為「五人」，因為他不是真佛，實質上仍算在僧數之中。「一佛」以下，指出所破的一方。法寶的對立不言而喻，所以文中省略未列。正方師徒五人卻只說「四人」的緣故，是因為佛寶的尊位有別，所以不納入僧數計算。因此能破與所破雙方合計十人，經中卻只說「九人」而已。「所以」以下，追問並說明真佛不計入人數的緣由。《俱舍論》說「破在別處」，是將能立與所立雙方相對而言，故稱五人，但若論及正式宣告破僧，則不在佛陀所在的集會中。正如後文所述，破僧之事是發生在伽耶山。「輕」是指輕蔑侮慢，「逼」是指逼迫惱害。「言教可信」的意思是，如果當著佛陀的面，眾人必然會依止佛的教化，分裂便無法得逞。下文引證《雜心論》，總共構成了上述三層涵義。

【586-0002】02_戒疏/10c_卷三上之一#4
【原文】【疏】四、就界內外明者。羯磨僧破，要在加法界內，兩眾別行，不通界外。法輪僧破，初秉法時，唯在界內，後破行法，通界內外。
【譯文】【疏文】第四、依結界內外來說明破僧。羯磨破僧，必須在同一個作法結界之內，兩群僧眾各自進行法事，範圍不通於界外。法輪破僧，在最初宣秉法事時，僅限於界內，後來傳播破法教義時，則通於界內界外。

【586-0003】02_戒疏/10c_卷三上之一#5
【原文】【記】四中。羯磨，一須加結，二局界內。法輪中。「初秉法時」者，以提婆先自布薩，破羯磨僧，故須局界，後方行化，則不定處。準下先在王舍破行，後於伽耶壞眾，與此不同。今詳破眾已後，行化未息，故云「後」耳。準知前後皆通內外。
【譯文】【記文】在第四項中。羯磨破僧，一是必須經由僧團如法結界，二是範圍局限在界內。法輪破僧的段落中。所謂「初秉法時」，是因為提婆達多先私自舉行布薩，破壞了羯磨僧團，所以必須局限在界內；之後四處推行教化，就沒有固定處所了。對照下文先在王舍城破壞修行，隨後在伽耶山分裂僧眾，與此處略有不同。現在詳細推敲，在分裂僧眾之後，其傳播教化的舉動並未止息，所以才稱為「後」。由此可知前後階段都通於界內界外。

【586-0004】02_戒疏/10c_卷三上之一#6
【原文】【疏】五、就凡聖二僧明破。羯磨破者，真俗俱能，聖人事迷，容生別眾非法故也。法輪僧破，唯俗諦僧，聖人識達，必不從化。故《成實》云：「凡夫輕躁，易可破壞。若得世間空無我心，尚不可破，況無漏也？」
【譯文】【疏文】第五、依凡夫與聖者兩類僧人來說明破僧。羯磨破僧，聖者與凡夫都能參與破壞，因為聖者對於僧事細節可能不察，也有可能因此產生分立非法集會的情況。法輪破僧，只有世俗凡夫僧才會參與，聖者智慧通達，絕不會盲從邪化。所以《成實論》說：「凡夫性情浮躁輕率，容易被破壞。如果已經證得世間的空無我心，尚且無法被動搖破壞，更何況是無漏聖者呢？」

【586-0005】02_戒疏/10c_卷三上之一#7
【原文】【記】五中。「真」即四聖，證真諦故。「俗」即兩凡，具煩惱故。法輪中。初正明，「故」下，引證。「世間空無我心」，即內凡世第一人分見空理者，則知爾前猶可破也。「無漏」即初果。
【譯文】【記文】在第五項中。「真」是指四果聖人，因為他們體證了真諦。「俗」是指內外兩位階的凡夫，因為他們煩惱具足。法輪破僧的段落中。開頭先作正面的說明，「故」字以下，引用論典作證。「世間空無我心」，是指內凡夫中的世第一位階、部分體見空性之理的人，由此可知在此位階之前的人都還可能被誘惑動搖而破壞。「無漏」即是指初果以上的聖人。

【586-0006】02_戒疏/10c_卷三上之一#8
【原文】【疏】六、就方明破者。羯磨所破，通三天下；破法輪僧，局在南洲。故《雜心》云「三方有八羯磨壞，閻浮有九法輪壞」也。
【譯文】【疏文】第六、依地理方位來說明破僧。羯磨破僧所通達的地域，遍及三大部洲；破法輪僧，則局限在南瞻部洲。所以《雜心論》說「三方天下有八人便可成羯磨破，閻浮提洲則須九人方成法輪破」。

【586-0007】02_戒疏/10c_卷三上之一#9
【原文】【記】六中。羯磨不對化主，故通三州，不通北州。法輪對主，唯局南州，不通三州。下引《雜心》，證上通塞。「八」、「九」並約人數，如上可知。
【譯文】【記文】在第六項中。羯磨破僧並不需要直接面對化主如來，所以通於三大洲，但北俱盧洲則不適用。法輪破僧必須直接對立教主，所以只限於南洲，不能通於其他三洲。下文引證《雜心論》，用以證明上述地域的通與不通。「八人」、「九人」都是就人數而言，如前文所述可以明瞭。

【586-0008】02_戒疏/10c_卷三上之一#10
【原文】【疏】七、就時明破者。羯磨通於二世，法輪唯佛世故。彼論云：「牟尼般涅槃，未結界前後，息肉未出時，又無第一雙。如是六時中，不名破法輪。」
【譯文】【疏文】第七、依時機來說明破僧。羯磨破僧通於佛在世及佛滅後二世，法輪破僧則唯獨局限在佛陀住世之時。該論說道：「如來滅度後，未結界前後，息肉未生時，又無第一雙。在這樣的六種時節中，都不能稱作破法輪。」

【586-0009】02_戒疏/10c_卷三上之一#11
【原文】【記】七中，初科。羯磨通現、未，法輪局現在。「彼論」，亦即《雜心》。偈中通明六時。正用初句，證成上義。真佛既滅，無可競化，故不通滅。後「未結界」者，以破法輪，必兼羯磨，非結界地，羯磨不行。故未立結界，則無破僧。「前後」，如《疏》自釋。「息肉未出」者，準《俱舍》解，於正戒、見，未生破毀時也，即以息肉以喻毀破。「息」合作「瘜」，謂臭肉也。「第一雙」者，《雜心》云「未建立第一雙」。準《阿毗達磨》解，「未立止觀第一時」。謂止觀二法名「雙」，超諸法門，故云「第一」。由立止觀，令眾修習，識別邪正，必無破僧。初後三句，各明一時。第二句含三時，故結云「六時」。
【譯文】【記文】在第七項的第一小段。羯磨破僧通於現在佛世與未來滅後，法輪破僧則局限在佛陀住世之時。「彼論」指的也是《雜心論》。偈頌中總共說明了六個時段。此處正引用首句，來證成上述的論點。真佛既然已經滅度，就不再有爭奪教化的對象，所以不通於滅後。其後「未結界」的意思，是因為破法輪僧必然連帶破羯磨僧，如果不是如法結界之地，羯磨法事便無法運作。因此在僧團未建立結界之前，就談不上破僧。「前後」的含義，如同《疏》後文自作的解釋。「息肉未出」的意思，依照《俱舍論》的解釋，是指僧眾對於正戒與正見，尚未生起毀破之時，此處即以息肉來比喻毀犯破壞。「息」字應當作「瘜」，指的是發臭的贅肉。「第一雙」者，《雜心論》寫作「未建立第一雙」。依照《阿毗達磨》的解釋，是指「未建立以止觀為首要的時期」。意思是止與觀這兩種修行合稱為「雙」，超越一切法門，所以稱為「第一」。由於建立了止觀法門，使僧眾得以修習，進而辨別邪正，就必定不會發生破僧之事。偈頌的首句與後二句（合為三句），各自說明了一個時段。第二句則包含了三個時段，所以總結稱為「六時」。

【586-0010】02_戒疏/10c_卷三上之一#12
【原文】【疏】所言「前後」者。昔人約破僧以分前後，無第二破故。
【譯文】【疏文】所說的「前後」一詞。古德是依據破僧這件事來劃分前後，因為不可能發生第二次法輪破僧。

【586-0012】02_戒疏/10c_卷三上之一#14
【原文】【疏】答：「唯可方便，終非究竟。」
【譯文】【疏文】回答說：「末代只能算作企圖破僧的方便作為，終究無法構成破僧的究竟罪。」
