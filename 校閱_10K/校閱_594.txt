# 校閱材料　第594檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【594-0001】02_戒疏/10c_卷三上之一#131
【原文】【記】釋疑中。以下諸聚總歸四重，種類相通，可有破義，理無通該異種之戒。答文，亦出《多論》。「四處」謂腦、咽、心、腰也。
【譯文】【記文】在釋疑的段落中。既然下位各聚最終歸屬於四大重戒，在同種類的性質上相通，還可以說具有連帶破壞的含義，但法理上不可能跨越不同種類的戒條而連帶破除。回答的文字，也是出自《多論》。「四處」是指人的腦袋、咽喉、心臟以及腰部。

【594-0002】02_戒疏/10c_卷三上之一#132
【原文】【疏】言「麤惡」者，如《母論》云：「初、二篇方便，若身若口，無慚心故，犯濁重偷蘭，名『麤惡』也。『非麤惡』者，波逸提下，及餘偷蘭也。」彼皆反說。
【譯文】【疏文】「粗惡罪與非粗惡罪」這一對，如同《毗尼母論》所說：「違犯第一篇與第二篇戒條的預備方便階段，無論是透過身體還是言語，只要是以徹底無慚無愧的放肆心態去造作，犯下污濁沉重的上品偷蘭遮罪，這就稱為『粗惡罪』。所謂『非粗惡罪』，是指波逸提以下，以及其餘情節較輕的偷蘭遮罪。」提婆達多對於這些正統標準也全都反過來胡亂顛倒。

【594-0003】02_戒疏/10c_卷三上之一#133
【原文】【記】六中，初科。《母論》除前二篇，就後五聚以分兩別。
【譯文】【記文】在第六對之中，此為第一小段。《毗尼母論》除去了前兩篇波羅夷與僧殘本身，專門針對後五聚戒律來劃分粗惡與非粗惡的差別。

【594-0004】02_戒疏/10c_卷三上之一#134
【原文】【疏】《了論》解云：「言麤有二：一、意，二、罪。翻此罪麤。」意麤有四：一、邪見撥無因果；二、不信苦樂等報；三、放逸不愛惜所受戒，縱意造惡；四、濁重貪瞋癡也。次用四句分別：一、由意麤，不由罪麤，若由四意殺草木等；二、由罪麤，不由意麤，非前四意，輕爾殺畜；三、由意麤，亦由罪麤，用前四意行殺等罪；四、不由意麤，不由罪麤，離四意殺草木也。非麤亦四：一、由意非麤，不由罪非麤；二、由罪非麤，不由意非麤；三、由意非麤，亦由罪非麤，輕爾損草木；四、不由意非麤，亦不由罪非麤，重心殺生者。
【譯文】【疏文】《了論》解釋說：「所謂粗惡有兩種：第一是意念粗惡，第二是罪行粗惡。翻對此（意粗與）罪粗，即為非粗惡。」意念上的粗惡有四種情況：第一是固執邪見而撥無善惡因果；第二是不相信苦報與樂報等業力感應；第三是放逸不知愛惜所受的清淨戒律，任由心意造作惡業；第四是深沉濁重的貪欲、瞋恚與愚癡。接下來用四句分別來判定：第一、由於起心動念粗惡，而不是由於罪行本身粗惡，例如基於上述四種粗惡意念去砍伐草木等；第二、由於罪行本身粗惡，而不是由於起心動念粗惡，例如並非出於上述四種惡念，僅是輕忽漫不經心就殺害了畜生；第三、既由於起心動念粗惡，也由於罪行本身粗惡，例如懷抱著上述四種惡念去造作殺生等重大罪行；第四、既不是由於起心動念粗惡，也不是由於罪行本身粗惡，例如遠離上述四種惡念去砍伐草木。至於「非粗惡」也有四句：第一、由於意念非粗惡，而不是由於罪行非粗惡；第二、由於罪行非粗惡，而不是由於意念非粗惡；第三、既由於意念非粗惡，也由於罪行非粗惡，如漫不經心輕忽折損了草木；第四、既非由於意念非粗惡，亦非由於罪行非粗惡，如以深重惡心造作殺害生靈的大罪。


【594-0005】02_戒疏/10d_卷三上之一#1
【原文】【記】次科。初總示二麤。「翻」謂翻對。「意麤四」中。初二相濫，但第二者未必邪見，止「不信」耳。行者觀此四心，用省己行，汙戒墮惡，孰不由斯？次互織為句，又二。初麤四句，後非麤四句。相翻互歷，配對大同。非麤四中，初即前二，二即前一，三對前四，四對前三。
【譯文】【記文】接續上一科段。首先總體提示兩種粗惡（意念粗惡與罪行粗惡）。「翻」指的是反面相對。「意地粗重有四種」當中，前兩種情況容易混淆，但第二種未必是邪見，只是「不信」罷了。修行者應當觀察這四種心態，用來反省自己的行為，戒行受到玷汙而墮入惡道，哪一個不是由此而起的呢？接著是兩兩交織組成句型，又分為兩部分：先是粗重的四句，後是非粗重的四句。彼此反轉互為經歷，配對情況大致相同。非粗重的四句中，第一句對應前面的第二句，第二句對應前面的第一句，第三句對應前面的第四句，第四句對應前面的第三句。

【594-0006】02_戒疏/10d_卷三上之一#2
【原文】【疏】「常所行、非常所行」者。《多》云：「八正道常所用法，調說非常。五法非常用法，調說常所用。」《了論》云：「非常行者，非佛所作所習也。彼即說是常所行者，是佛所作。入定說法，受現法樂，是佛所習，彼又反說。」
【譯文】【疏文】「常所修習、非常所修習」的意思。《薩婆多論》說：「八正道是佛陀常教導修習的法，提婆達多卻說成非常所用。五法本不是佛常教導的法，提婆達多卻說成是常修之法。」《律二十二明了論》說：「非常修習的法，是指不是佛陀所作、所修習的。提婆達多卻說這才是常修習之法；而入定說法、受用現法樂等真正佛陀所作、所修習的法，他反而反過來說成不是。」

【594-0007】02_戒疏/10d_卷三上之一#3
【原文】【記】七中。《多論》可解。次《了論》中，「非佛作習」，即邪見諸惡。
【譯文】【記文】第七條當中。《薩婆多論》的意旨容易明白。接著《明了論》中所說的「不是佛陀所作所習」，就是指邪見等種種惡法。

【594-0008】02_戒疏/10d_卷三上之一#4
【原文】【疏】「制、非制」者，《多》云：「五篇戒，佛金口制，調說非制。五法非佛所吐，名為非制，調說為制。」
【譯文】【疏文】「所制、非所制」的意思，《薩婆多論》說：「五篇戒律，是佛親口所制定的，提婆達多卻說不是佛所制。五法並非佛陀親口宣說，本屬於非所制，提婆達多卻宣稱是佛所制。」

【594-0009】02_戒疏/10d_卷三上之一#5
【原文】【記】第八，易解。
【譯文】【記文】第八條，容易理解。

【594-0010】02_戒疏/10d_卷三上之一#6
【原文】【疏】「說、非說」者，四是重禁，餘是輕約，此名正說，調說為非。四禁為輕，餘篇為重，是名非說，調為是說。
【譯文】【疏文】「所說、非所說」的意思，四波羅夷是極重禁戒，其餘篇章是較輕的約束，這叫作佛的正說，提婆達多卻說這是不對的說法。他反而把四重戒說成輕罪，把其餘輕篇說成重罪，這本是非佛所說，提婆達多卻宣稱這才是佛的真正教說。

【594-0011】02_戒疏/10d_卷三上之一#7
【原文】【疏】《了論》云：「非如來說，非如來教。彼即說是如來所說。」五陰、十二入、十八界，乃至八萬法門，對治眾生八萬煩惱，令其觀察，是如來教。十二部經名句文，是如來說。彼皆反之。
【譯文】【疏文】《明了論》說：「不是如來所說、不是如來所教導的，彼提婆達多就宣稱這是如來所說。」五陰、十二處、十八界，乃至八萬四千法門，用來對治眾生的八萬四千煩惱並令其修習觀察，這才是如來的教導；十二部經的名相句義文句，才是如來所說。彼提婆達多把這一切全都顛倒反說了。

【594-0012】02_戒疏/10d_卷三上之一#8
【原文】【記】九中，《了論》。初明說非為是。「非如來說」及「非教」者，如五邪、世典之類。名言為「說」，法門為「教」。「五陰」下，次明說是為非。
【譯文】【記文】第九條中引用《明了論》。首先說明將非佛說的執為是佛說。「非如來所說」以及「非如來所教」的，就像調達五邪法、世間俗典之類。語言名相稱為「說」，修持法門稱為「教」。「五陰」以下，接著說明把真正的佛說執為非佛說。

【594-0013】02_戒疏/10d_卷三上之一#9
【原文】【疏】即以此法，心懷知是，口說言非，異見異忍，為他人說，是名邪佛之法寶也。
【譯文】【疏文】彼提婆達多就用這種方法，心裡明明知道是對的，口中偏偏說是不對，懷抱著異樣的見解與認同，去向他人宣說，這便稱作邪佛的法寶。

【594-0014】02_戒疏/10d_卷三上之一#10
【原文】【記】總結中。「心知是」者，心不應口也。「口言非」者，語不副心也。「異見異忍」是自損，「為他人說」即害他。「邪佛法寶」，總前半九法也。
【譯文】【記文】總結當中。「心知是」的意思，是內心與口頭所言不相呼應。「口言非」的意思，是言語違背了自己的本心。「異見異忍」是損害了自己，「為他人說」就是去危害別人。「邪佛法寶」，是總括前面所說的九種非法。

【594-0015】02_戒疏/10d_卷三上之一#11
【原文】【律】和合僧。
【譯文】【律文】和合僧團。
