# 校閱材料　第203檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【註】佛言：「諍有四種：言諍、覓諍、犯諍、事諍。」言諍者，以現前毗尼、多人語二種滅滅也。覓諍以現前、憶念、不癡、罪處所四滅滅也。犯諍以現前、自言治、草覆地三滅滅也。事諍者，以一切滅滅。其三種諍，各分上、中、下三品，合明九種。事諍一種，歷上三諍，隨分九品。應隨現前中三種、五種，滅上、中、下品。對病說藥，應善觀、解也。
【譯文】【註文】佛陀說：「諍論有四種：諍論法相名義的言諍、追查過失違犯的覓諍、評斷罪過輕重的犯諍、僧團辦事爭議的事諍。」言諍是運用「面對面解決（現前毗尼）」、「採納多數意見（多人語）」這二種滅諍法來平息的。覓諍是運用「現前毗尼」、「憶念過去清淨無犯（憶念）」、「心智瘋狂失常時所作不罰（不癡）」、「處治隱瞞相違之本罪（罪處所）」這四種滅諍法來平息的。犯諍是運用「現前毗尼」、「本人親口坦承處置（自言治）」、「以青草覆地雙方互捨小過（草覆地）」這三種滅諍法來平息的。事諍則是貫通運用全部滅諍法來平息。前三種諍論各自細分上、中、下三品，合起來共有九種。事諍這單一種，經歷貫通前面三種諍論，隨其情節也細分為九品。應當依據現前法中的三種法或五種法，分別平息上、中、下品之爭。面對不同的病症施予相應的藥石，應當審慎觀察、善加理解。

【原文】【疏】一、「言諍」者。謂評法相是非，須知邪正，各執己見而生其諍。諍由言起，故曰「言諍」。
【譯文】【疏文】第一種叫做「言諍」。這是指評斷佛法教理名相的對錯是非，必須辨明邪正，結果雙方各執己見而產生諍論。諍執是因言談辯論而引發，所以叫做「言諍」。

【原文】【疏】二、「覓諍」者。比丘犯過，理須為除，制有三根五德，舉來詣僧，伺覓前罪，令其除殄。因舉評犯，遂生其諍。諍由覓生，故曰「覓諍」。
【譯文】【疏文】第二種叫做「覓諍」。比丘若犯了過失，按理僧團必須為其除去罪障，律制中具備見、聞、疑三種根據（三根）以及五種清淨德行，才能向僧團檢舉，藉由搜查追究其先前罪過，令其懺悔滅罪。因為舉發評議犯戒之事，遂引發爭論。爭吵是因搜查追究而產生，所以叫做「覓諍」。

【203-0094】02_戒疏/21a_卷四下之三#117
【原文】【疏】如何識邪？謂言諍中，若評教理是非，犯相輕重，是名言諍；若評羯磨是非，迷悟不決，此名言諍中事諍。若評三根清濁，五德通塞，是名覓諍；若評用法治舉，徵覈虗實，則名覓諍中事諍。於五犯聚，懺評有濫，名犯諍；非法羯磨，定罪重輕，是名犯諍中事諍。隨本諍分上中下異，故成九品。
【譯文】【疏文】應當如何辨識呢？也就是說在言諍之中，如果是評議教理的是非、犯戒行相的輕重，這稱為言諍；如果是評議羯磨作法的如法與否、眾人困惑或明了爭執不決（或：對是非迷惑或通曉猶豫不決），這稱為言諍中的事諍。如果是審查舉罪依據的三根是否清白、舉罪者的五德是否具足，這稱為覓諍；如果是評議用以處罰懲戒的羯磨法是否得當、查核事實的虛實，這就稱為覓諍中的事諍。若是對於五種犯戒聚落中，懺悔時的罪名評定有所混淆，稱為犯諍；若是透過非法羯磨來判定罪行輕重，這稱為犯諍中的事諍。隨著原本諍論的根源再劃分為上、中、下品的不同，因此共構成九品。

【203-0095】02_戒疏/21a_卷四下之三#118
【原文】【記】次科。第列三諍，對顯事諍，一一兩分，方見四諍條然無濫。「隨本諍分」者，謂此事諍，同前三諍為九品也。
【譯文】【記文】這是下一項內容。依序排列前面三種諍論，相對顯現事諍的特點，每一種都作雙向劃分，這樣才能看清四種諍論井然有序而毫不雜亂。所謂「隨本諍分」，是指這種事諍如同前三諍一樣，也配合開展為九品。
