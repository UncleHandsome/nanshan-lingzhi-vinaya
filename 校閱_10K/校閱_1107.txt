# 校閱材料　第1107檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1107-0001】資持記/07c_中一下#24
【原文】故下總云：唯有本心方便，驗非偏判也。方便即偷蘭，廣如下篇明之。別問，答中，示相有四，初《見論》約人家以明。西天可爾；此土屬官，則非無主。《婆論》二種。初即可用。第二須約國亂；無主物處，亦無官典守護，取則無過。封相，即封土作疆界處。
【譯文】所以下文總括說道：只有原本發心的方便罪，這證明並非偏頗的判斷。方便罪就是偷蘭遮，詳細內容如同下篇所明示。特別提問的回答中，顯示相狀共有四種，首先《善見律毗婆沙》依據一般民家來進行說明。在印度可以如此認定；但在這片土地一切歸官府所有，那就不是無主之物。《薩婆多論》列出兩種。第一種即可取用。第二種必須在國家混亂時；在無主之物的地方，也沒有官吏典掌守護，取走就沒有過錯。所謂封相，就是堆土標示作為邊界劃分之處。

【1107-0002】資持記/07c_中一下#25
【原文】即下，一種，據俗令者，恐是唐令。既不令占，即無所屬，故是無主。若下，今判加功占據，還成有主。犯相中，初文。準疏但有五緣，無今第五。彼問云：今此盜緣無方便者？答：損財明盜，便成重罪；有盜成重罪，不假方便，恐涉濫故；縱有方便，亦俱不明；但知未離已前，並方便攝。今鈔不釋，意亦可見。
【譯文】自鈔文「即」字以下的一種，依據世俗律令而言，恐是唐朝的律令。既然朝廷不准私自占有，那就沒有所有權人，所以是無主物。自鈔文「若」字以下，如今判定若是耗費人工占據，就又變成了有主之物。在犯相之中，第一篇文字。依照《戒本疏》只有五個犯緣，並沒有如今的第五個。那裡提問說：如今這條盜戒的犯緣中沒有列出「方便」嗎？回答說：損害財物以顯明盜行，便立即構成重罪；有些盜行構成重罪，不需要假借方便之階段，唯恐涉及混濫；縱然有方便前行，也全都不予標明；只要知道財物未離原處之前，全都屬於方便罪所收攝。如今本鈔不作解釋，用意也是顯而易見的。

【1107-0003】資持記/07c_中一下#26
【原文】總括犯緣，不出心境；一四即境，二三及五是心；六中兼二，心境合故。初緣，三寶物中，先簡知事。初科，上句徵覈何故先明。若下，示意。如後者，即互用及瞻待中。次科。兩經合引，文理同故。初示難護。僧物有主，用與多過，是故難掌；佛法無主，用與由人，又復難矣。
【譯文】總體概括犯緣，不出妄心與外境；第一與第四就是境，第二、第三及第五就是心；第六之中兼具兩者，是因為心與境相合的緣故。第一個犯緣，在三寶財物之中，首先簡別知事僧人。第一科，上句追究考察為何要先說明此事。自鈔文「若」字以下，指示其用意。所謂如後文所說，就是指相互借用挪用以及瞻視照料之中。下一科。將兩部經典合併引用，是因為文意與道理完全相同。首先指出極難守護。僧物是有明確主人的，挪用與給予極容易產生過錯，因此難以掌管；佛法（二）物沒有具體的主人，用度與賜予全憑人為決斷，這就更加困難了。

【1107-0004】資持記/07c_中一下#27
【原文】我下，簡人，初簡聖人。文舉初後，二三兩果，何以不明？或可知故，或約二惑究盡處故。更下，次簡凡夫。初人知因，後人懼果；或可上簡精持，下容犯悔。無瘡疣者，喻能離過故。申誡中，初指前經。因下，示制罪。今時學律，侵損僧物，如已所有；不識業因，不畏來苦；覩此慈訓，不知慎護；
【譯文】從「我下」開始，簡別適用之人，首先簡別聖人。文中列舉初果與後果，二果與三果為何不明示？或者因為道理顯而易見，或者依據見思二惑徹底斷盡的界限而言。自鈔文「更」字以下，其次簡別凡夫。前一種人知曉因果，後一種人畏懼惡果；或者也可以說，上面的第一種人簡拔精純持戒之人，下面的第二種人寬容犯戒後能懺悔者。所謂沒有瘡疣傷痕，是比喻能夠遠離過錯。在重申戒誡之中，首先指涉前述經文。自鈔文「因」字以下，指示制罪的標準。當今學習戒律的人，侵占損害僧眾物品，如同己有；既不認識造業的起因，也不畏懼未來的苦果；看到這些慈悲的教訓，依然不知道謹慎防護；

【1107-0005】資持記/07c_中一下#28
【原文】斯地獄人，不可拔也。盜用中，標分四門。上三通論三寶，後一唯明僧物。初門，佛物中，初科，正明。言同非人者，若據非人擲卜而取，非無我所；但望惱微，與人相降；今殿塔靈儀，有同神像，故得例同。引證中，初舉例證。文如後引。次引文證。言不問取者，即盜相也。
【譯文】這些人都是未來的地獄中人，實在是無可救拔。在盜用之中，標示分為四個門類。上面三門通論三寶之物，最後一門單獨說明僧眾之物。第一門，在佛物之中，第一科，正式明示。所謂如同非人，若是依據非人擲卜問卦而取物，並非沒有執持物主；只是若論對其所生的惱怒相對微小，與人類相比稍有降次；如今殿堂塔寺的靈異儀相，有些等同於神像，所以得以依例比照。引文證明中，首先舉出同類事例為證。經文如同後文所引。其次引述經文為證。所謂不過問就逕自取走，這就是偷盜的相狀。

【1107-0006】資持記/07c_中一下#29
【原文】知，即識法故違；不知，謂愚教迷犯。〔古云：大乘約境判者，非也；此即愚癡波羅夷之類耳。〕言犯蘭者，正望佛結；縱有主掌，經家不論；然罪名雖輕，據業則重。望主中，初文。兩判可解。施主，即本主也。結罪者，準下犯夷；《尼鈔》，亦直云結重。〔有云犯吉，非也。〕引證中，初文。
【譯文】所謂知曉，是指明知教法卻故意違犯；所謂不知曉，是指愚昧於教理盲目犯戒。〔古人說：大乘戒依據境界來判定，這是不對的；這屬於愚癡波羅夷之類罷了。〕所謂犯偷蘭遮罪，是純粹對著佛陀來結罪；縱然有僧人主管照看，經論作者也不予論述；然而罪名雖然看似較輕，若是依據所造業力來說則極其沉重。在對待物主方面，第一篇文字。兩種判定是可以理解的。所謂施主，就是原本的主人。所謂結罪，依照下文應犯波羅夷重罪；《比丘尼鈔》也直接說結成重罪。〔有人說是犯突吉羅，是不對的。〕引文證明中，第一篇文字。

【1107-0007】資持記/07c_中一下#30
【原文】彼因波離問佛，鈔引佛答；彼云：謂檀越施與塔寺，斷彼施主福，成棄捐不受。〔波羅夷，翻為棄捐；捐亦棄也。不受，即不共住也。〕引《五百問》。彼云：佛塔上掃得土，棄之有罪不？答：得棄，不得餘用。引此似證損福。次證中，初例證者。則知非人罪通兩結，佛亦同之。
【譯文】那是因為波離尊者向佛請教，本鈔引用佛陀的答覆；那裡說：如果施主布施給塔寺，斷絕了那位施主的福德，成棄捐不共住之罪（即波羅夷罪）。〔波羅夷，翻譯為棄捐；捐也就是拋棄。不受，就是不再共同止住。〕引用《五百問》。那裡說：在佛塔上面掃得塵土，拋棄它有罪嗎？回答說：可以拋棄，但不得作其他用途。引用這段話似乎是為了證明損毀福報。在接下來的引證中，首先是同類比照證明。由此可知非人財物的罪過通貫兩方面結罪，佛物也是如此。

【1107-0008】資持記/07c_中一下#31
【原文】次《十誦》及下《善生》，並是顯文。佛圖，即全梵語；或召塔者，亦以藏佛遺身，從人為目。所以中。指如後者，下明不勒掌錄，有填償義故。盜供養中，初中。二文不異，故合引之。云淨心者，即非盜業。自下，示淨心相。次文。初《伽論》結犯，與上相違；下引《婆論》決之；既為轉賣，明非淨心供養故犯。
【譯文】接下來的《十誦律》以及下文的《善生經》，全都是明確的經文。所謂「佛圖」，就是完整的梵語發音；或者稱之為「塔」，也是因為內部供藏著佛陀的遺體舍利，順著佛陀本身來立名的。在原委之中。指出如同後文所述，是因為下文說明了不強制主管僧官登錄賠償，具有必須予以填補償還的義務。在偷盜供養物之中，第一部分。兩部文獻並無差異，所以合併引用。所謂「清淨心」，就是指並非出於偷盜的造業意圖。從「自下」開始，顯示出清淨心的相貌。下一段文字。首先《摩得勒伽論》判定犯戒，與上述說法相違背；下文引用《薩婆多論》來決斷；既然是為了轉手販賣，顯然不是出於清淨心供養，所以構成犯戒。
