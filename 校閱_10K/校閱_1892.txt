# 校閱材料　第1892檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1892-0001】03_業疏/21b_卷四之四#91
【原文】守寺淨人應等與，乃至《五分》中與一分者，體非福田，以供僧勞，望僧故合。不與、不應分者，以制在僧，僧須周給，今但繼於上尊，不兼及下，失於僧和無礙，即非僧義，雖分不合，又是盜攝也
【譯文】守護寺院的淨人應當均等分給，乃至在《五分律》中分給一份的情況，是因為其本質雖然不是福田，但由於為僧團服勞供役，對待僧團的勞苦而言是合宜的。至於說「不給予」、「不應分配」的說法，是因為權限制定在於僧團，僧團必須周遍施給，如今如果只接濟上座尊者，而不兼顧下位之人，就喪失了僧團和合無礙的意義，便不符合僧伽的精神；這樣即使分配了也不合律制，而且屬於盜戒所攝之罪。

【1892-0002】03_業疏/21b_卷四之四#92
【原文】五中初敘得分之意，非福田故少與，供僧勞故須與。「不」下次釋不與之過，恐謂俗眾不預施故。「不合」是吉，「盜收」犯重
【譯文】第五段中，起初敘述淨人得以分獲利養的意旨：因為不是福田，所以少分給予；因為服侍僧團有勞苦，所以必須給予。自「不」字以下接著解釋不給予的過失，這是恐怕有人認為俗人眾等不應當參與施與的緣故。「不合」是指犯突吉羅（輕垢罪），「盜收（盜取收執）」則違犯重罪。

【1892-0003】03_業疏/21b_卷四之四#93
【原文】三、明時現前法中，以安居故，為福故施，隨其勞限，各取分也
【譯文】第三、說明「時現前」之法，是指因為安居的緣故，施主為了修福而行布施，隨同各人安居勞苦的期限，各自取得其應得的份額。

【1892-0004】03_業疏/21b_卷四之四#94
【原文】第三安居施者，即是時也；隨勞限者，謂現前也
【譯文】第三科中，所謂因安居而施與，就是指「時」；所謂隨安居勞苦的期限，就是指「現前」。

【1892-0005】03_業疏/21b_卷四之四#95
【原文】四、非時現前者，如上二部，此據一眾隨人故也
【譯文】第四、「非時現前」，相較於上面的僧尼二部，此處則是依據單一部眾、隨在場之人而分的緣故。

【1892-0006】03_業疏/21b_卷四之四#96
【原文】第四不為夏勞，故曰非時；人物限定，故名現前。注文可見
【譯文】第四科中，不是為了結夏安居的勞苦，所以稱為「非時」；人和物都有特定的限定，所以稱為「現前」。這在注文中清楚可見。

【1892-0007】03_業疏/21b_卷四之四#97
【原文】五、分時僧得者，夏勞開受，施通一化，若不作法，何以約之
【譯文】第五、分劃「時僧得」之物，是因為夏安居勞苦而開許接受，施主的布施通於一化（全界僧眾），如果不通過作羯磨法，又憑什麼來約束限制分配呢？

【1892-0008】03_業疏/21b_卷四之四#98
【原文】第五須作法者，即破古解
【譯文】第五科中說明必須作羯磨法，這正是為了破斥古代律師的舊解。

【1892-0009】03_業疏/21b_卷四之四#99
【原文】六、非時僧得，就文為二，極分明也
【譯文】第六、「非時僧得」，依據文意分為兩部分，界限極其分明。

【1892-0010】03_業疏/21b_卷四之四#100
【原文】第六初科分二，即如注中，前檀越施，後亡人物
【譯文】第六項的第一科分為兩部分，就如同注文中所說，前半部分是施主（檀越）所布施之物，後半部分是亡僧遺物。

【1892-0011】03_業疏/21b_卷四之四#101
【原文】其亡物重輕作法制約，在文雖具，終須開示，廣如鈔中及《輕重儀》之所解也。至時兩引，同歸一致，竝須當法量斷，不容臨事遲疑
【譯文】至於亡僧遺物的輕物、重物以及作法約束規程，在律文中雖然具足，但終究需要加以開顯釋明，詳細內容正如《事鈔》以及《量處輕重儀》當中所解釋的那樣。到了臨事之時兩相引證，歸結為一致的道理，都必須依據相應的法則來裁量決斷，不允許臨時猶豫遲疑。

【1892-0012】03_業疏/21b_卷四之四#102
【原文】次科初指廣。亡物重輕即處判也；作法制約即攝僧、別賞勞、付分等也。鈔及儀文，開釋甚廣。「至」下勸引，仍誡曉達。今更略分：二亡物中，大分為二，初敘所屬，「又」下次示分法，十門明之，大同儀、鈔，文亦自顯，有疑尋對。第九門中有四，前二是僧，後二即別。初僧即五人已上，行事備故。付分羯磨中「諸長老」下，秖合單牒根本，多牒緣十五字，秉時削去
【譯文】下一科起初指示詳盡的廣文。亡僧遺物的輕重即是指處置判斷；作法制約即是指召集僧眾、特別賞賜勞苦、交付分派份額等。在《事鈔》與《輕重儀》文中，開示解釋得極為詳盡。自「至」字以下勉勵予以引證，並誡飭必須通曉明達。如今再略作劃分：在第二科亡物之中，大體分為兩部分，起初敘述遺物的歸屬，自「又」字以下接著指示分配之法，以十門來加以說明，大致與《輕重儀》及《事鈔》相同，文意也自然顯明，若有疑問可對照查尋。第九門中包含四種情形，前兩種屬於僧團公有，後兩種即屬於個人私屬。起初僧團的情形是指五人以上，因為羯磨行事具備的緣故。付分羯磨文中在「諸長老」之下，只應當單獨宣讀根本語句，若多讀了事緣的十五個字，在秉持作法時應當刪去。


【1892-0013】03_業疏/22a_卷四之五#1
【原文】釋懺六聚篇。
【譯文】解釋懺悔六聚罪篇。

【1892-0014】03_業疏/22a_卷四之五#2
【原文】篇目。懺是能悔心，六聚即所犯過。法通理事，化制不同，局題就宗，即指諸羯磨耳。
【譯文】這是本篇的題目。「懺」是能夠悔改的心，「六聚」就是所違犯的罪過。行法通於理懺與事懺，教化（化教）與制戒（制教）各有不同，若局限於篇題並依從本宗（律宗）而言，就是指各種滅罪的羯磨法。

【1892-0015】03_業疏/22a_卷四之五#3
【原文】上諸門中，被於行淨專精之人。但以五濁澆風，鼓扇塵境，不能制割，遂與犯同。若不清蕩，未曰智人；覆藏瑕疵，終歸顯露。故當及時早懺，不可後世悔之。
【譯文】上面各門之中，是加被於行業清淨、專精修持的人。然而由於五濁惡世的澆薄之風，煽動塵勞境界，行者若不能克制斷割，於是就如同犯戒一般。如果不加以洗滌清蕩，就算不上是智慧之人；若隱瞞遮蓋自身的瑕疵罪咎，終究會顯露出來。所以應當及時早早懺悔，不可等到來世才後悔。

【1892-0016】03_業疏/22a_卷四之五#4
【原文】敘意中初科，初二句結前七篇正宗行相；「但」下，生起當篇須立之意。初敘成犯之由，五濁：時數漸減為劫濁，邪執堅固為見濁，催年促壽為命濁，三毒猛盛為煩惱濁，分別妄計為眾生濁，皆非清淨，故並名濁，亦名五滓，即是有情、無情二種世間。劫減情浮，逐境造業，與犯同者入篇聚也。「若」下明須懺所以，注引律二種愚人、二種智人：一、堅持不犯，二、犯已能懺。「終歸顯露」，即現、當、後三報。
【譯文】敘述大意中的第一科，前兩句總結前面七篇正宗的行持相狀；自「但」字以下，生起本篇必須建立的意旨。起初敘述構成犯戒的緣由，所謂五濁：年月壽數漸減為「劫濁」，邪倒妄執堅固為「見濁」，摧折年歲促短壽命為「命濁」，貪瞋癡三毒熾盛為「煩惱濁」，分別妄加計度為「眾生濁」，全都不是清淨之法，所以一併稱為「濁」，也稱為「五滓」，這就涵蓋了有情世間與器（無情）世間二種世間。在減劫中凡情浮躁，隨逐塵境造作惡業，與犯戒相同者便墮入相應的篇聚之中。自「若」字以下說明必須懺悔的原因，注文引述律典中所說的二種愚人與二種智人：智人一是堅持不犯，二是犯了之後能夠悔改。「終歸顯露」，就是指現報、生報、後報這三報必定受報。

【1892-0017】03_業疏/22a_卷四之五#5
【原文】今多憍伐自矝，謂能拒抗前惡。深須量度是何位人，然後自高，可得度世？不然，縱毒知何不經？生後苦楚，孰難遭遇！
【譯文】如今多有人驕縱誇耀、自我尊大，自稱能夠抵禦對抗先前的惡業。深切需要自己審度衡量一下自己究竟是處於什麼果位的人，然後才能自視甚高，難道這樣就能度脫生死嗎？如果不是這樣，放縱三毒惡心，又有什麼惡罪未曾經歷造作？來生及後世的痛苦，又有誰能免於遭遇呢！

【譯文】第二段中，「驕伐自矜」是愚昧，「謂能拒抗」是愚癡，既然愚昧而且愚癡，不知自己的斤兩分量，等到禍患臨頭才後悔，便追悔莫及了。下文引用《攝大乘論》說初地與八地菩薩：一是自無過失，二是有利他之能，才可示現造行殺生等過惡，其餘凡夫則不可如此，所以說「不然」等等。「縱毒」就是一切罪惡全都造作，所以說「知何不經（什麼罪惡未曾造作歷經）」；惡業既成則地獄之苦隨即降臨，所以說「孰難遭遇（誰能不遭遇此苦）」。
