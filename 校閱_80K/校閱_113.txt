# 校閱材料　第113檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【113-0001】資持記/02d_上一下#63
【原文】引病例健，於義難成。所以斷語猶進退者，由無明文，且據義決；況略是律開，欲取通意，未可一向，故云難定。然今行事不可從緩；有病堪能，亦須廣說，方契聖心。問現相者。本律有名無相，欲引外部明之，故設此問。答中，初示五相。隨病者所為，亦非止此。律下，次誡令詳審。
【譯文】引述生病的事例來比照健康人，在道理上是難以成辦的。之所以斷定時的語詞還有進退留有餘地，是因為沒有明確的白紙黑字律文，暫且依憑義理來決斷；何況略說是戒律所開許的，若要取其融通的意旨，尚不可一概全然抹煞，所以說是「難以定奪」。然而現在推行法事絕不可流於寬緩放任；若有疾病而體力尚堪能者，也必須廣說欲詞，才契合佛陀聖心。在詢問顯現身體動作行相的項目中。本律只列出名稱而沒有具體行相，想要引述外部律典來闡明，所以設立這個問答。在回答中，起初列出五種行相。隨順病患所能作出的動作，但也並不僅限於這幾種。從「律」以下，其次告誡必須詳細審查。


【113-0002】資持記/02e_上一下#1
【原文】律即《五分》。由無名句，色相難辨，故在取者默識趣向。說欲中，初為他分二，前儀，後法。若為他傳，待索方說。兼他自說，不必待索；由緣來不時，不可定約；如便利卒患，可待問耶！具威儀者，如下所決。法中。初句告眾同聽，次句牒彼人名；我下一句，傳初受辭；彼下二句，牒應僧也。
【譯文】律文就是指《五分律》。因為沒有特定的名相文句，心態相貌難以分辨，所以全在於受持者心中默默領會其旨趣意向。說欲之中，一開始為別人代傳分為兩部分：前面是威儀，後面是作法。如果是為別人代傳，必須等僧中索取時才能說。若是兼為他人並連同自己一起說，就不必等僧中索取；因為事情突然發生不限時宜，不能作固定的約定；就像突然患了大小便急病，難道還能等待僧中詢問嗎！具足威儀的情形，如後文所決斷。作法文辭中：第一句是告知大眾一同審聽，第二句是列舉那個人的名字；「我」下面的一句，是轉達最初受託時的辭句；「彼」下面的兩句，是列舉以呈報給僧團。

【113-0003】資持記/02e_上一下#2
【原文】若下，示總說。《僧祇》不得至四，本宗唯多無在，但於次句總牒諸名。若不記者，當云我受眾多比丘欲清淨。疏云：此據迷忘，必思審者，不得籠通。合說中。出法詞句，大同轉欲，唯初告僧為異。而依古牒緣者，一暫借別緣，簡異彼此。二恐後學不曉牒緣之相，故特示之。
【譯文】「若」字以下，是開示總合宣告之法。《僧祇律》規定代傳人數不得多至四人，本宗則即便人數再多也無妨，只要在第二句中總括列出眾人的名字。如果不記得名字，應當說「我受眾多比丘的欲與清淨」。《業疏》說：這是針對迷惘忘失的情況，如果還能思惟審察清楚的人，就不得含混籠統。合說之法中：所出的作法詞句，大體與轉移欲法相同，只有最初告白僧眾的文辭有差別。而依照古法列舉事緣的原因：第一是暫時借用特定的事由，用來分辨彼此的差異；第二是擔心後學者不明白列陳事緣的具體行相，所以特地指出來告知。

【113-0004】資持記/02e_上一下#3
【原文】臨事正說，必須削去，故《尼鈔》但云我某甲彼某甲等。自說中，初示法。與前與欲文同，但初句別。今時後生不識僧別，多於眾中而云大德一心念，或云大德憶念；愚癡迷法，法恐難成。《四分》下，指所出。此行他部事，引緣可解。彼但云我某甲清淨，僧憶念持；今不用彼詞。
【譯文】臨事正式作法時，必須把這些多餘的文句刪削去掉，所以《尼鈔》中只說「我某甲、彼某甲等」。自己說欲之中，首先開示作法。這與前面給予他人欲法的文辭相同，只有第一句有差別。現在的後生晚輩不識得僧中作法與個人對首的差別，大多在大眾之中說「大德一心念」，或者說「大德憶念」；愚癡而不通曉教法，僧事恐怕難以成就。《四分》以下，指出其出處。這是施行他部律的做法，引述這段事緣便可理解。那部律中只說「我某甲清淨，僧憶念持」，現在本宗並不採用那樣的言詞。

【113-0005】資持記/02e_上一下#4
【原文】善作者，歎其能也。如法者，釋其疑也。不受得罪者，彼云越毘尼。通明五法。初二屏與，後三對眾。又前三正出本宗，後二兼行他部。故《注羯磨》中止列三法，顯知後二準前裁出。次決通中。以當時諸家行事多別，義須指定，故問決之。答中，初文四相。二是合說，二是各說。
【譯文】「善作」，是讚歎他的辦事能力。「如法」，是解釋大眾心中的疑慮。「不受得罪」，在彼律中是說犯突吉羅（越毘尼）。這總共說明了五種受欲之法。前兩種是屏處個別給予，後三種是面對大眾給予。又前三種正是出自本宗，後兩種則是兼行其他宗派之法。所以《注羯磨》中只列出三種法，顯然可知後兩種是依據前面的原則裁定出來的。接著在「決通（決斷通貫）」科判中：因為當時諸家行事多有差別，在道理上必須指定正途，所以藉由問答來決斷。回答之中，最初的文句顯示了四種行相：兩種是合說，兩種是各自個別說。

【113-0006】資持記/02e_上一下#5
【原文】又前二對僧禮不禮別，後二就位下不下異。取舍中，初科為二，初至皆成來，一往暫許。據文有二。一據忘名，律中若不憶姓相，但云眾多比丘與欲清淨；次準不說，並如後引。若下，二取義奪破。律中等者，釋上文意。忘誤得罪，對上兩文。無緣不得，顯非常開。上來釋通本部。
【譯文】而且前兩種是以對僧團禮拜與不禮拜來作分別，後兩種是以就在座位上或是離席走下來作差異。在「取舍」之中，第一科分為兩部分：最初到「皆成」以來，是依表面文義暫且認可。依據文獻有兩種情況：一是依據忘記姓名，律中說如果不記得同伴的姓名形貌，只須說「眾多比丘給予欲和清淨」；其次是準照不說名字的規定，都如後文所引用的那樣。「若」字以下，是第二部分，以義理奪破前說。律中這類話，是用來解釋上文的用意。「忘誤」與「得罪」，分別對應上面的兩段文句。沒有特殊事故就不得隨便這樣做，顯見這不是尋常開許的做法。以上是解釋通達本部的教意。

【113-0007】資持記/02e_上一下#6
【原文】約下，勸準他宗。文見次科。引文中，初《五分》。明與欲人囑彼傳者。〔準此為他傳欲至僧中，隨多少須為捉籌。今多不知。〕次引《僧祇》二節，初明與者，揀境堪能。其下，次明受者自量可否。〔準此受欲必選精明，據《業疏》中戒具解昏，不聽持欲。〕觀此二文，亦不明各說；
【譯文】「約」字以下，是勸勉應當準照其他宗派的規定。文意詳見下一科。在引用的文獻中，首先是《五分律》，說明給欲之人囑咐那位傳欲者。〔依照這個原則，為別人傳欲到僧中，隨同代傳人數的多少，必須替他們捉相應數量的籌碼。現在多數人都不懂這個道理。〕接著引用《僧祇律》的兩節文：最初說明給欲的人，必須揀選對象是否具有代傳的能力；「其」字以下，接著說明受欲之人應當自我衡量是否可以承擔。〔依照這個規定，接受託欲必須挑選精明審慎的人，依據《業疏》所說，戒相雖具備但見解昏昧者，不聽許為人持欲。〕細看這兩處引文，也沒有明確說必須各自個別宣說；

【譯文】律疏說如果依據《薩婆多毘尼毘婆沙論》，恰好列出了一百零一種；所以那部論中排列的名目，單白有二十四種，白二有四十七種，白四有三十種；古代的人讀誦其他異部宗派的論著，反而忽略了自己本宗的規定〔《摩得勒伽論》就是宗承《十誦律》的〕。在「指非相（指出非法行相）」之中，是第一科。上面兩句說明之所以需要說明的用意：上面既然闡明了法度的界限準則，依循運用時都應當符合規範；如果稍有偏差違背，是成是敗就難以分辨了，所以義理上應當在這裡詳細指陳非法的相狀。但字以下，說明省略說明的用意。「進不」，就是成辦與不成辦。必字以下，指示詳廣之處，那篇文獻也已經亡佚了。

【113-0064】資持記/02f_上一下#1
【原文】一非法非毘尼羯磨，二非法別眾羯磨，三非法和合羯磨，四如法別眾羯磨，五法相似別眾羯磨，六法相似和合羯磨，七訶不止羯磨。略示中二，初正示是非。謂下三句，明是。別相，即法所攝事。若下四句，明非。如但心念，止齊三事；若加餘事，即是非攝。
【譯文】第一、非法非毘尼羯磨；第二、非法別眾羯磨；第三、非法和合羯磨；第四、如法別眾羯磨；第五、法相似別眾羯磨；第六、法相似和合羯磨；第七、訶不止羯磨。在略要說明的文字中分為兩部分，首先是正面指出正確與錯誤。鈔文「謂」字以下的三句，是說明正確的情況；其中的「個別名目（別相）」，就是該僧事儀軌所包含的特定事項。鈔文「若」字以下的四句，則是說明錯誤的情況；比如單純的心念羯磨，範圍只限於三件事，如果加入其他事項，就屬於錯誤的範圍。

【原文】乃至白四唯被三十八事，若加說恣差結等事，即名非法。如是八位，例之可知。此謂約法加事，交互彰非，欲使初學略識其相。若欲下，指義七非。言通知者，上文但明法非；未顯下三皆有非故。此門者，總指相攝一科。上下，即前後四位。各有非相，隨位總收，故云橫括；
【譯文】乃至於白四羯磨只能用於三十八種僧事，如果擅自加入說戒、自恣、差派人員或結界等事，就稱為非法。像這八個範疇，以此類推便能明白。這是指根據僧事儀軌擅自添加事項，彼此交錯而顯出過失，目的是要讓初學者大致認識其形式。下文說到「若欲」之處，是指七種非法的義理。之所以說「通通必須了解（通知者）」，是因為上文只說明了儀軌本身的過失，尚未顯明儀軌之外的其餘三種條件也各自存在過失。這裡所說的「這個門類（此門者）」，是總括指稱互相關聯相涉的這一科判。上下兩方，也就是指前後的四個範疇。它們各自具有非法的表現，隨著各個範疇全部收攝，所以說是「全面涵括（橫括）」；

【原文】說戒〔即五戒相。〕，說法；佛言此是上座應作。以三語五戒兩竝對人，且證對首。下引《十誦》雙證二法。彼明疑問，佛為決之。羯磨下，續云後來比丘不與分。第二明事有三：一情事，二非情事，三二合事。百八十四，此三攝盡。標指中，由前八法各出別相，故云不重。
【譯文】說戒〔也就是宣說五戒的具體行相〕、說法；佛陀說這些事情應當由上座來做。因為三皈依受戒與傳授五戒這兩者，都是單獨面對一個人進行的，以此暫且證明有對首羯磨的存在。下文又引用《十誦律》同時證明這兩種法。那裡記載了生起疑問的情況，佛陀親自為大眾決斷。在羯磨的文句下方，接著記載說後來的比丘不再分給僧物。第二部分說明羯磨所針對的事由，共有三種：第一是涉及有情眾生的事（情事），第二是不涉及有情的事（非情事），第三是兩者混合的事（二合事）。一百八十四種僧事，全部被這三種涵蓋窮盡。在提綱標示的文字中，由於前面八種法已經各自列出個別形態，所以說「不再重複」。
