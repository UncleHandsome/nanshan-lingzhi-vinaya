# 校閱材料　第695檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第七八敬者五分云瞿曇彌白佛言願聽女人出家受戒佛言止止莫作是語所以者何往古諸佛皆不聽女人出家諸人皆自依於佛在家剃髮著袈裟勤行精進獲得果證未來諸佛亦復如是我今聽汝以此為法如是三請佛亦不聽瞿曇彌便大啼哭自剃髮等乃至佛為說八敬方聽出家母論云阿難為女人求出家迦葉謫罰阿難十事一者若女人不出家者諸檀越等常應各各器盛食在道側互跪授與沙門二者常應與衣服臥具於道中求沙門受用三者常應乘象馬車乘在於道側以五體投地求沙門而蹈過四者常於路中以髮布地求沙門蹈上而過五者常應恭敬心請諸沙門到舍供養六者常應生恭敬心淨掃其地脫身衣服布地命沙門坐七者乃至脫體上衣掃比丘足上塵八者乃至常應舒髮拂比丘足上塵九者乃至沙門威德過於日月況諸外道豈能正視於沙門乎十者女人不出家者佛之正法應住千年今減五百一百年中得堅固解脫一百年中得堅固定一百年得堅固持戒一百年得堅固多聞一百年得堅固布施見論云所以不聽女人出家者為敬法故若度女人出家正法五百歲不住由世尊制比丘尼行八敬故正法還得千年摩耶經云千一百歲已諸比丘等如世俗人嫁娶行媒於大眾中毀謗毗尼義云今時尼眾順教行媒受俗馳使街衢路首輕突大僧不避尊儀陵辱上下或獨行無侶孤遊聚落出入行來類同賤俗滅法之原特由於此然法眾多不能具述今但逐要不過八敬今列八名幸願依行冀正法長存千齡弗墜耳此律云一者百歲比丘尼見初受戒比丘僧當迎逆禮拜問訊請令坐二者比丘尼不得罵謗比丘三者不得與比丘罪說比丘過失比丘得說尼過失四者式叉摩那已學於戒應從眾僧求受大戒五者尼犯僧殘應半月在二部僧中行摩那埵六者尼於半月從僧中求請教授人七者不應在無比丘處住八者夏安居訖當詣僧中求自恣人如是八法並應尊重恭敬讚歎盡形壽不應違之中含經云若比丘聽尼問經律毗曇然後得問不聽者犯第五尊師法僧祇云尼入大僧寺中應頭面一一禮一切比丘足若老病不堪隨力多少恐不徧者得就總禮應云我尼某甲頭面禮一切僧足若比丘入尼寺應須禮不得罵云是犯戒是醫師是摩訶羅無所知乃至實罪皆不得說比丘得說尼實罪尼若憍慢不恭敬迎逆禮足者犯越敬法大愛道尼經云若比丘舉比丘尼過尼應自省不得高聲大語又比丘尼敬比丘僧視之如佛此律云比丘尼式叉摩那沙彌尼等觸犯諸比丘者佛言應喚來謫罰若不改悔應作捨教授羯磨僧祇云若比丘犯過親里尼得輭語語不得訶責十誦云尼見大僧不起提此律若一比丘喚一比丘尼乃至眾多比丘尼應往若不往如法治問何故制尼依僧耶答愛道尼經云女人但欲惑色益壽畜弟子亦不欲學問但知須臾之事故依僧也。
【譯文】第七、敬重大僧之八種法則（八敬法）：《五分律》說：大愛道瞿曇彌稟白佛陀說：「請求世尊允許女人出家受具足戒。」佛陀說：「止住，止住！切莫說這種話。為什麼呢？過去諸佛皆不允許女人出家，眾人都是各自歸依於佛，在家剃除鬚髮、身著袈裟，精勤修行精進，證得果位；未來諸佛也是如此，我如今答應妳以此種方式修行。」像這樣三次懇求，佛陀皆不答應。瞿曇彌便痛哭流涕，自己剃除鬚髮等等；乃至佛陀為她宣說了「八敬法」，才允許女人出家。《母論》說：阿難為女人代求出家，尊者迦葉為此懲治責備阿難十件事：第一、如果女人不出家，各位檀越施主常會各自用器具盛裝飲食，跪在路旁雙膝著地，親自奉授奉給沙門。第二、施主常會在道中供給衣服臥具，懇求沙門受用。第三、施主常會乘著象馬車乘停在道旁，五體投地伏在地上，懇求沙門踐踏而過。第四、施主常在道路中將自己的頭髮鋪在地上，求沙門踩在上面走過。第五、施主常會以極恭敬之心，迎請諸沙門到舍宅中供養。第六、施主常會生起恭敬之心，將地面打掃得乾乾淨淨，脫下身上的衣服鋪在地上，請沙門入座。第七、乃至脫下身上所穿之衣，用來擦拭比丘腳上的塵土。第八、乃至常會散開頭髮，用來拂去比丘足上的灰塵。第九、乃至沙門的威德尊貴將超越日月，何況那些外道，哪裡敢正視沙門一眼呢？第十、如果女人不出家，佛陀正法應住世一千年；如今減少了五百年：前一百年中得堅固解脫，第二個一百年中得堅固禪定，第三個一百年中得堅固持戒，第四個一百年中得堅固多聞，第五個一百年中得堅固布施。《善見律》說：之所以起初不答應女人出家，是為了敬重佛法之故；如果直接度化女人出家，正法連五百年都無法住世；正由於世尊制定比丘尼必須奉行「八敬法」，正法才得以重回一千年之期。《摩耶經》說：一千一百年之後，諸比丘將混同於世俗之人，行婚配嫁娶、充當媒婆，並在大眾之中毀謗誹謗毗尼戒律。依義理來說：如今有些尼眾不知順應教規，反而充當媒妁、接受俗人驅馳役使，在市井街頭肆意衝撞大僧，不顧尊嚴禮儀，陵慢侮辱上下長幼；或者孤身獨行無有伴侶，獨自遊走於村落聚集之處，出入往來等同於卑賤世俗之人。佛法毀滅的根源，尤其正是由這些弊端引起的。然而相關法規極其繁多，無法詳細具述，如今只切中要旨，關鍵不出「八敬法」。在此列出八條名稱，唯願依教奉行，期望正法常存世間，千載歲月不致墜落傾覆。本律說：第一、百歲戒臘的比丘尼，見到剛受戒的比丘僧，也應當起立相迎、禮拜問訊、請其入座；第二、比丘尼不得辱罵誹謗比丘；第三、比丘尼不得舉發比丘之罪、宣說比丘過失，而比丘則可以宣說比丘尼的過失；第四、式叉摩那學完戒法後，應當前往大僧僧團中求受具足大戒；第五、比丘尼若犯僧殘罪，應當於比丘、比丘尼二部僧中行半個月的摩那埵（折伏傲慢之行）；第六、比丘尼應當每半個月向比丘僧團求請教誡教授之人；第七、比丘尼不應當在沒有比丘駐錫之處安居度夏；第八、夏安居結束後，應當前往比丘僧中求覓自恣之人（請大僧檢舉其見、聞、疑罪）。這八種法則，都應當竭誠尊重、恭敬、讚歎，盡形壽終身不得違背犯染。《中阿含經》說：如果比丘允許比丘尼請問經文、戒律、毗曇論義，然後才可以發問；如果未經許可擅自發問，犯第五條不尊奉師長法。《僧祇律》說：比丘尼進入大僧寺院中，應當頭面著地、一一禮拜每一位比丘的雙足；如果年老多病不堪勞累，隨體力能拜多少拜多少；若是擔心無法逐一拜遍，可以集中行總禮，應當說：「我比丘尼某某，頭面頂禮一切僧眾雙足。」如果比丘進入尼寺，比丘尼必須行禮迎奉，不得辱罵說「這是犯戒僧、這是醫師、這是摩訶羅無所知之人」，乃至比丘的真實罪過，皆不得私自宣揚；而比丘則可以如實說出比丘尼的真實罪過。比丘尼若是驕慢怠慢、不恭敬迎接禮足，犯違越敬法之罪。《大愛道尼經》說：如果比丘舉發檢舉比丘尼的過失，尼僧應當自加反省，不得高聲大語爭辯反駁；又比丘尼恭敬比丘僧，應當敬之如同敬佛。本律說：比丘尼、式叉摩那、沙彌尼等若有觸犯諸比丘者，佛說應當喚來懲罰責問；如果拒不悔改，應當對她作「捨教授羯磨」（斷絕大僧教誡資格）。《僧祇律》說：如果比丘犯了過失，有親戚關係的比丘尼得以溫和言語相勸，不得嚴詞訶責。《十誦律》說：比丘尼見到大僧不起立相迎，犯波逸提罪。本律說：如果一位比丘召喚一位比丘尼乃至眾多比丘尼，比丘尼皆應當前往；若不肯前往，依法治罪。有人問：為什麼要規定比丘尼依附於比丘僧呢？回答：《愛道尼經》說：女人心性往往容易迷惑於容色、貪求延年益壽，蓄養弟子也不圖學習經教問道，只貪顧眼前短暫之事，因此必須依附於僧團。

【695-0007】04_比丘尼鈔/03b_卷中之上#16
【原文】婬戒具四緣犯一是正道大小便及口是二有染心三興方便四與境合但使正道三處入如毛頭皆犯此律有將小兒根內口中弄雖本無婬心但使入時受樂便犯十誦口中要過齒犯此律若為怨家賊等緣強持男根令入三處自無婬心但使始入入已出時無有一念受樂心者皆不犯若隨有一時受樂便犯若比丘及尼互教前人作者偷蘭前人不作教者吉羅下三眾相教作及不作俱吉仍作滅擯不犯者若睡眠無所覺知不受樂一切無有婬意。
【譯文】淫戒（婬戒）：具備四種條件即構成破戒犯重：一是正道（大便道、小便道以及口道即是）；二是有染污之心；三是發起方便企圖；四是受行器官與境界相合。只要在三處正道之中，進入即便小如毫毛之端，皆算犯戒。本律記載：有人將小兒的生殖器放入口中玩弄，雖然本意並無淫欲心，但只要伸入時感受到了快感淫樂，便算犯戒。《十誦律》規定：口道中一定要深入過齒才算犯戒。本律又說：如果是被仇家、強盜等惡緣強迫，強行將男根塞入三道之中，自身本無淫念，只要在剛進入、進入後、拔出時，沒有生起絲毫享受淫樂的心念，皆不算犯戒；倘若隨同其中任何一個時刻生起受樂之心，便構成犯戒。如果比丘與比丘尼彼此唆使對方去造作淫行，教唆者犯偷蘭遮罪；對方若沒有去做，教唆者犯突吉羅罪。若是下三眾（式叉摩那、沙彌、沙彌尼）互相教唆去作，無論對方作與不作，教唆者均犯突吉羅罪，並且仍要對犯淫者施行滅擯驅逐。不構成犯戒的情況是：如果在熟睡之中毫無知覺、未受淫樂，從始至終完全沒有淫欲心念者，不犯。

【695-0008】04_比丘尼鈔/03b_卷中之上#17
【原文】盜戒具六緣一有主物二有主想三有盜心四重物五興方便六離本處犯此中約境判盜開為十三重一佛二法三僧四三寶互用五當體互六像共寶互七即物自互八出貸九賓客十人物十一非人物十二畜生物十三雜明盜業。
【譯文】盜戒：具備六種條件即構成犯戒：一是有所屬主人的物品；二明知是有主之物並作此想；三生起偷盜之心；四盜取的物品值重價（滿五錢）；五發起偷盜的方便企圖；六將物品搬離原處，即成犯戒。此中依據所偷盜的境界面向，開列為十三個層面（十三重門）：一佛物、二法物、三僧物、四三寶互用、五當體互用、六佛像與寶物互換、七同物自身互換、八出借放貸、九款待賓客、十偷盜人物、十一偷盜非人物、十二偷盜畜生物、十三雜項說明盜業。
