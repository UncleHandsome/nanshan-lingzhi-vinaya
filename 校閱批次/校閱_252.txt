# 校閱材料　第252檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【252-0001】02_戒疏/14c_卷三下之二#22
【原文】【疏】所以如來不受請者，《多論》五意：「一、為入寂室故；二、為諸天說法故；三、看病比丘故；四、為結戒故；五、為看房舍臥具故。比丘行後，知佛行房，必自肅慎，不令非法。又欲斷盜賊，知佛行房，不起惡故。」
【譯文】【疏文】探究如來之所以不接受迎請的原因，《薩婆多論》列出五種意圖：「第一、為了能進入寂靜精舍坐禪；第二、為了給諸天神說法；第三、為了探視生病的比丘；第四、為了制定戒律；第五、為了巡視僧房舍宅與臥具器物。比丘們出外之後，知道佛陀會巡視房間，必然會自我整肅謹慎，不讓房間出現非法的雜亂。此外也是為了斷絕盜賊的覬覦，賊人知道佛陀仍在寺內巡房，便不敢生起作惡的心念。」

【252-0002】02_戒疏/14c_卷三下之二#23
【原文】【記】戒緣中，佛不受請中。《多論》「五意」，且據大分為言，然經律中，如來亦多受請。「寂室」，即坐禪處，比丘俱出，宜入禪故。二中，比丘在寺，諸天不下故。三、佛親看病，以福勝故。四、五二意，即今戒緣。五中復有兩意：初令弟子肅慎，謂諸比丘知出行後，佛必行房，先自摒淨故；「又」下，二令竊盜息念，以佛在寺，躬自巡行故。
【譯文】【記文】戒緣之中，佛陀不接受迎請的部分。《多論》所說的「五種意圖」，只是就大體概況而言，然而在經律之中，如來也經常接受迎請。「寂室」就是坐禪之處，比丘們都出去了，正好適合入定禪修。第二點中，比丘若留在寺內，諸天便不會降臨。第三點，佛陀親自探視病人，是因為其福德最為殊勝。第四與第五兩種意圖，正是此戒制定的緣起。第五點中又含有兩層用意：首先讓弟子們整肅嚴謹，即比丘們知道出門後佛陀必定巡房，出發前便會自行收拾乾淨；「又」字以下，其次是讓盜賊息滅偷竊的企圖，因為佛陀留在寺院並親自巡查的緣故。

【252-0003】02_戒疏/14c_卷三下之二#24
【原文】【疏】《僧祇》云：「佛以五利，五日一行諸房：一、我諸弟子不著有為事不；二、不著世俗言論不；三、不著睡眠妨行道不；四、看諸病人不；五、為年少出家者，見佛威儀庠序，起歡喜心故。」
【譯文】【疏文】《僧祇律》說：「佛陀基於五種利益，每五天巡視一次各僧房：第一、察看我的眾弟子是否執著於世俗的有為雜務；第二、是否沉溺於世俗的言談議論；第三、是否貪著睡眠而妨礙了修道；第四、察看弟子是否照看病患比丘（或：察看僧中是否有病患比丘）；第五、為了讓年少初出家的人，見到佛陀安詳和緩的威儀，能生起歡喜向道之心。」

【252-0004】02_戒疏/14c_卷三下之二#25
【原文】【記】次科。《僧祇》五利，前四撿校徒眾，並滅惡利也；後一令他歡喜，生善利也。初云「有為事」，即世間俗事。
【譯文】【記文】下一科。《僧祇律》的五種利益，前四項是查核約束徒眾，全都屬於息滅惡法的利益；最後一項是令他人生起歡喜，屬於生起善法的利益。第一條所說的「有為事」，就是指世間的凡俗雜事。

【252-0005】02_戒疏/14c_卷三下之二#26
【原文】【疏】二、明制揲者，以新故狼藉，受用致虧。以故揲新，息貪受用，俱有益故。
【譯文】【疏文】第二、說明制定縫綴補貼的用意，是因為新舊坐具隨意拋擲一片狼藉，使資具的妥善受用受到虧損。透過用舊布補綴新坐具，既能止息貪心，又能兼顧物資的受用，兩方面都有益處。

【252-0006】02_戒疏/14c_卷三下之二#27
【原文】【記】二、制揲中。初明因過。狼性躁急，食多遺籍，故云「狼藉」。「受用虧」者，不專持故。「以」下，次明立制。「息貪」即清心，「受用」即資身，故云「俱有益」也。
【譯文】【記文】第二、在制定縫綴的段落中。首先說明引發過失的緣由。狼的性情躁急，吃東西常常遺落滿地雜亂，所以稱為「狼藉」。「受用致虧」，是指沒有專一受持愛護資具。「以故」以下，接著說明確立定制的用意。「息貪」就是澄淨內心，「受用」就是資助身體，所以說「兩者都有益處」。

【252-0007】02_戒疏/14c_卷三下之二#28
【原文】【疏】問：「此中明揲，『九十』制量，同是坐具，何不合明？」
【譯文】【疏文】提問：「此處說明縫綴舊布，後面的『九十單墮』中又限制坐具的尺寸長寬，同樣都是針對坐具，為什麼不在一處合併說明？」

【252-0008】02_戒疏/14c_卷三下之二#29
【原文】【疏】答：「不同有四，故分二戒：一作新如量，不揲犯前；作故過量，犯後；作故如量，俱持；作新過量，俱犯。對此二戒，明其捨悔，先悔量外，然後捨悔。」
【譯文】【疏文】回答：「因為有四種不同的情況，所以分為兩條戒：第一、製作新坐具符合尺寸，但不縫綴舊布，犯前一條捨墮戒；以舊料製作坐具但尺寸超量，犯後一條單墮戒；以舊料製作坐具且符合尺寸，兩條戒都受持未犯；作新坐具不縫舊料且尺寸超量，兩條戒同時違犯。針對這兩條戒說明捨物與懺悔的法則，必須先懺除尺寸超量的罪，然後再行捨衣並懺除不縫綴的罪。」

【252-0009】02_戒疏/14c_卷三下之二#30
【原文】【記】初問中。欲彰二戒不同之意，故發斯問。答中。初立句料簡。「對」下，示俱犯悔法：不揲過量，罪兼二悔；初悔過量，截去量外，單悔提罪；次悔不揲，須將入捨，然後悔罪。
【譯文】【記文】在第一個提問中。提問者想要彰顯這兩條戒律立意不同的深意，所以提出這個問題。回答之中。首先建立四句邏輯來加以辨析。「對此」以下，指示同時違犯時的懺悔作法：不縫貼舊布且尺寸超量，罪責兼具兩種懺悔法；起先懺悔超量的部分，將超出限制的布料裁截除掉，單獨懺悔波逸提罪；接著懺悔不縫貼的過失，必須把這整件新坐具拿入僧中行捨財法，然後再懺悔罪愆。

【252-0010】02_戒疏/14c_卷三下之二#31
【原文】【疏】問：「準下『九十』，揲已同截，後何須捨？」
【譯文】【疏文】提問：「如果依照後面『九十單墮』的作法，補縫舊布就如同裁截超量一樣，完成後何必還要把坐具捨棄？」

【252-0011】02_戒疏/14c_卷三下之二#32
【原文】【疏】答：「不揲則舉體有過，過在須捨，故不勞揲。過量則量內無過，無則非捨。亦可過量捨已，主無用義，故須截之。」
【譯文】【疏文】回答：「不縫綴舊布，是整件坐具的本體都構成過失，其過失嚴重在於必須全物捨棄，因此犯後無須再勞煩補貼。如果是尺寸超量，在限度之內的範圍本身並無過失，既然無過就不是應當捨棄的對象。或者也可以說，超量的坐具即便依捨法捨給僧團再歸還，對於原主而言依然沒有合法受用的意義，因此（不須行捨法，）只要直接將超量部分裁截去除即可。」

【252-0012】02_戒疏/14c_卷三下之二#33
【原文】【記】次問。意謂過量截己，單悔本罪；不揲揲已，與截不異，何須復捨？答中，有二。初答不揲須捨，次明過量不捨。「無則非捨」，謂內既無過，無可捨故。「亦」下，次答。過量不截，始終非法，故「主無用」，反明不揲還主有用，故須捨之。
【譯文】【記文】第二個提問。意思是說尺寸超量只要裁截之後，單純懺悔原本的罪名即可；不縫貼的人補縫之後，跟裁截的意思沒有兩樣，為何還要再捨棄？回答之中，包含兩層意涵。首先回答不縫貼必須全物捨棄，接著說明尺寸超量無須全物捨棄。「無過就不是捨棄的對象」，是指尺寸限度之內既然合法，就沒有需要捨棄的道理。「亦可」以下，是第二種回答。超量的部分如果不裁截，自始至終都是非法的物品，因此「原主無法合法受用」，反過來說明不縫綴的坐具經捨懺還給原主後仍可合法受用，所以必須先經由僧伽行捨法。

【252-0013】02_戒疏/14c_卷三下之二#34
【原文】【疏】「若爾，不揲捨已，還主猶好，亦應須揲？」
【譯文】【疏文】「既然如此，不縫貼舊布的坐具在行捨法之後，歸還給原主時依然完好，是否也應該再行縫綴補貼？」

【252-0014】02_戒疏/14c_卷三下之二#35
【原文】【疏】答：「不揲為好。今捨還我，義同新得，好非我過。過量他與，量非制故，猶是本業。故不須捨，但截即得。」

【252-0024】02_戒疏/14c_卷三下之二#45
