# 校閱材料　第423檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【423-0001】資持記/04c_上三#43
【原文】若捨具作沙彌，或捨具十作優婆塞，則名漸捨。略知如此，餘廣如《疏》。僧捨中，初引開法。《律》因跋闍子比丘不樂淨行，還家與故二行不淨，佛因開捨。文引佛語，不出捨法；《律》云：我捨佛、捨法、捨比丘僧、捨和尚、捨阿闍梨、捨諸梵行、捨戒、捨律、捨學事，受居家法，我作淨人外道等。〔即頓捨也。
【譯文】如果捨去具足戒而作沙彌，或者捨去具足戒與十戒而作優婆塞，就稱為漸捨。簡略了解大概如此，其餘詳盡內容如同《戒疏》所說。在比丘捨戒這部分中，首先引用開許捨戒之法。《律》中因為跋闍子比丘不樂修清淨梵行，回到家中與原先的妻子行不淨行，佛陀因此開許捨戒之法。鈔文中引用了佛陀的言教，但未列出具體的捨戒言詞；而《律》中說：「我捨佛、捨法、捨比丘僧、捨和尚、捨阿闍梨、捨諸梵行、捨戒、捨律、捨學事，接受居家之法，我作淨人、外道等。」〔這就是頓捨。〕

【423-0002】資持記/04c_上三#44
【原文】我作優婆塞，我作沙彌〔此漸捨也。〕；須對比丘捨之，一說即成。《多論》所謂受如採寶，亦如登山，必假多緣多力；捨如失財，如從高墜，不假多緣，故唯一說。《增一》下，明分齊。彼經因僧伽摩比丘七反降魔，後更受具得阿羅漢，因開七反，已外不聽。尼捨中，引示。
【譯文】（若說：）「我作優婆塞」、「我作沙彌」〔這就是漸捨〕；捨戒必須面對比丘而捨，只要宣說一遍即可成就。《薩婆多論》所謂受戒如同採集珍寶，又如同攀登高山，必定需要依憑眾多因緣與諸多力量；捨戒則如同喪失財物，如同從高處墜落，不需要依憑眾多因緣，因此只要宣說一遍。《行事鈔》引《增一阿含經》以下，是說明捨戒再受的限度界限。該經記載因為僧伽摩比丘七次降魔，後來再次受具足戒而證得阿羅漢果，佛陀因此開許最多可以七次，七次之外便不再聽許。在比丘尼捨戒這部分中，則是引用律文來指示說明。

【423-0003】資持記/04c_上三#45
【原文】云無更受者，女流報弱，多無志操；佛初許度，尚是曲開；何況再受，理非容納。釋疑。答中，初列二義。比丘下，示開制。僧兼二種，尼但初義；各顯所以，在文可見。注文義決，唯障具戒。9 釋師資篇(上三)釋師資篇師通多種，今局二位，一得戒和尚，二依止闍梨；餘並一席作法，不論相攝。資，取也。
【譯文】律說比丘尼一旦捨戒就再也不能重新受戒，這是因為女人的身心果報較為羸弱，大多缺乏堅毅不拔的志向與節操；當初佛陀初次答應度化女人出家，就已經是勉為其難的委曲開許了；何況是一旦退心捨戒還要再受，在義理上絕對是不能容納接納的。在「釋疑」的段落中，回答包含了兩層義理。在下文「比丘……」中，展示了開許與禁制的規定：比丘兼具上述二種意義（不成波羅夷與來去無障，故開七反），比丘尼則僅具第一種意義（只為不成波羅夷而在俗無過，無來去無障之義，故制不得再受）；各自顯現其深層原因，在律文中看得很清楚。注文中在義理上作了裁決：這項禁令僅僅是阻礙她再次領受「具足戒」而已。第9篇〈釋師資篇〉（卷上之三）：在〈釋師資篇〉中，「師」通指多種身分，此處局限於兩位：一是得戒和尚，二是依止阿闍梨；其餘戒師都只是一座法會上的作法戒師，不論師資相攝。「資」是取的意思。

【423-0004】資持記/04c_上三#46
【原文】即目弟子取學於師。若據沙彌，亦依二師；行法大同，相攝無異，然此所明專約具戒；縱容相涉，非是正意。言相攝者，括下一篇，不出三種；一約心者，謂父子想；二法三財，互相濟故。問：此無羯磨，那屬上卷。答。計此合入〈受戒篇〉中，所以《律》文合為一聚；約前所攝，故同眾行。
【譯文】所謂「資」，即是指弟子向師長汲取教法學習。如果就沙彌而言，身邊同樣必須依止這兩位師長；其具體修持行儀大體相同，師徒相互攝受也沒什麼差別；然而本篇所闡明的法度，純粹是專就受了具足戒的比丘而言；縱然偶爾牽涉到沙彌，也並非本篇的正旨所在。所謂「相互攝受」，總括這整個篇章的內容，不出三種核心範疇：第一是就「心念」而言，彼此要抱持如父如子的骨肉深想；第二是「佛法正道」、第三是「世間衣食資財」，彼此互相關懷濟度。有人問：這一篇並沒有羯磨作法，為什麼要歸入上卷之中呢？回答說：按理這一篇本來應當編入〈受戒篇〉之中，正因為如此，《律藏》本文把受戒與師資合為一大聚合；就前文所收攝的內涵而言，師徒相處同樣屬於「眾人共行」的範圍；

【423-0005】資持記/04c_上三#47
【原文】但事繁行廣，故兩分之。來意中，初科，上二句明立教之意。住持三寶，全賴人弘；師徒相攝，僧寶不斷，則佛法增廣也。增益謂從微至著，廣大即遍布流通。互下，示相攝之益，上二句通舉三攝。敦遇即心相攝，謂厚顧也。日下，示解行二益。業謂所學，文通師資，義在弟子。
【譯文】只是因為這方面牽涉的事相繁複、實踐行持極其廣大，所以才分拆為兩個篇章來論述。在「本篇由來意趣」的第一科中，上面兩句闡明了佛陀立教的深遠本意。護持正法、令三寶常住於世間，完全依賴於後人的弘揚開拓；師長與弟子之間能夠以道相契、緊密攝受，清淨的僧寶才能燈燈相續永不斷絕，佛法也才能日益增長廣大。「增益」是指德業由微小逐漸顯著，「廣大」是指正法法脈周遍流布暢通。下文「互……」，是揭示師徒相互攝受的殊勝利益，上面兩句話統括列舉了三種相攝法門。「敦遇」就是心意上的互相攝受，是指深厚懇切的照料與顧念。下文「日……」，是展示在教理理解與實際行持兩方面的長足利益。「業」是指所修學的戒定慧道業，文字雖然貫通師徒二人，但核心用意主要在於成就弟子。

【423-0006】資持記/04c_上三#48
【原文】彰非中，上四句敘非法。初句明教壞，次句明人愚，三即俗輕，四謂道妄。並下，推所因。率，猶引也。二下，示所損，上明損自他。欲下，損佛法。篇意中，上句示悲懷。拯急即拔苦故。次句明慈行。安危即與樂故。愚教任情，動成惡業；墮在苦處，喻如倒懸。〔《孟子》云：當今之時，萬乘之國行仁政，民之悅之，猶解倒懸。
【譯文】在「彰顯過非」的段落中，上面四句話是在敘述那些不合律法的混亂亂象：第一句說明神聖教法遭受破壞，第二句說明出家人心智愚昧無知，第三句是指引起世俗之人的輕賤鄙視，第四句是指修道者動輒妄念紛飛、道風敗壞。下文「並……」，是追究這種敗壞現象的根本起因。「率」是引導、率領的意思。下文「二……」，是展示這種做法所造成的雙重損害，上面說明這對自己和他人都有嚴重的損害。下文「欲……」，是說明這將徹底損毀如來正法。在「闡明作篇用意」中，上一句顯露出祖師無比慈悲的本懷。「拯急」就是拔除沉淪苦難的意思。下一句表明慈愛利他的深廣行持。「安危」就是給予安穩快樂的意思。若是師長以愚鈍的觀念隨順私情去教育弟子，一舉一動全都會造下無邊惡業；師徒一同墮入三惡道苦境之中，那種慘痛就如同被倒懸在虛空一樣難受。（《孟子》說過：「在當今這時代，萬乘之尊的大國若是能施行仁政，人民的欣喜雀躍，就像是被解開了倒懸之苦一般。」）

【423-0007】資持記/04c_上三#49
【原文】下二句勸修彰益。師名中，問標三名。師是華言，義通二師，文指和尚。答中初句略答。非此本有，故無正翻。顯下諸文，皆義翻耳。善下，引示，初引《見論》。師即和尚。彼因瞿陀沙彌為育王說法，王以八分食供養；沙彌云：迴與我師及闍梨；王問二名，沙彌隨答。文引答詞。
【譯文】下面兩句話是勸導大家依律修持，以彰顯殊勝的功德利益。在「解釋師長名義」中，提問中標指了三個名稱。「師」是此方震旦的漢語，義理上通稱和尚與阿闍梨兩位大師，在律文中則專指和尚。回答中第一句是扼要的總答。因為這個概念並非震旦本土原本就有的，所以沒有完全對等的正統翻譯。這也表明下文引用的種種經文，全都是依照義理所作的靈活翻譯罷了。下文「善……」以下是引經據論予以開示，首先引用《善見論》。「師」就是指和尚。那是起因於瞿陀沙彌為阿育王宣講妙法，阿育王拿出八份上等美食供養沙彌；沙彌推辭說：「請將這些美食轉供養給我的和尚及依止阿闍梨」；國王便詢問這兩個名稱的意涵，沙彌隨即作了解答。律文引述的就是當時沙彌回答的話。

【原文】弟子下，分二，上明不令僧罰。設下，明已罰令解。二中，初勸發露。為下，次為求懺。三中。差及命終，看視功畢，不可中止。四中。本明弟子移處，下引《僧祇》，師送弟子；由是共行，不妨互顯。《僧祇》中，初制不得離。若欲下，明開暫離。上二句明師不遮；若下，明弟子憂念；當下，明師安慰。
【譯文】下文「弟子……」分為兩層：上面說明要想方設法使僧團不對師長施加治罰；下文「設……」，說明若僧團已經對師長施加了懲處，弟子應當竭力奔走設法讓僧團為師長解除懲罰。第二條中，首先是勸導師長向僧團發露懺悔過失；下文「為……」，其次是弟子為師長奔走四方尋求清淨僧眾來主持懺悔儀軌。第三條中：師長患病直到痊癒或者不幸命終，弟子的看照守護之責才算圓滿終止，中途絕對不可半途而廢、置之不理。第四條中：律文本意是說明弟子要遷徙遷移到別的處所，下文引述《僧祇律》則是說明師父為弟子送行；因為這屬於師徒雙向的共行之道，所以不妨礙在行文上互為顯發補充。《僧祇律》中，首先嚴格禁止弟子無故脫離師長。下文「若欲……」，是說明開許暫時離開的情況。上面兩句話說明此時師父不應無理阻攔；下文「若……」，說明弟子臨行前內心難免憂傷牽掛；下文「當……」，說明做師父的應當慈悲予以溫暖安慰。
