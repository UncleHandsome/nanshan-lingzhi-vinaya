# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【原文】此篇大門有八一僧物二乞食三陞坐四就法五淨地六遇賊七濟生八雜事。
【譯文】本篇大項目共有八門：第一是僧團財物（僧物），第二是乞食，第三是陞座，第四是說法（就法），第五是清掃地面（淨地），第六是遭遇盜賊（遇賊），第七是救濟眾生（濟生），第八是雜項事物（雜事）。

【629-0003】04_比丘尼鈔/06b_卷下之下#44
【原文】第一僧物者此門有五一四方僧物謂一切重物上至羅漢下至沙彌盡皆有分無有和合賣買供給私用此約方為名也二常住僧物謂常在此處不可移動四方僧來即此處受用此從用為名也三柘鬬提奢物謂俗人地別為現前僧各造私房四方僧來起立房舍供給所須此以處為名也五僧鬘物謂園中華果貨得物來此從鬘為名也五分云僧有五種物不可賣不可分一地二房舍三須用物四果樹五華果僧祇云若僧地種果者有功若一樹一園聽與一熟不能併取者年取一枝枝徧即止若種瓜菜聽與一剪有比丘僧地作屋上座來不與持草木餘處去。
【譯文】第一門僧團財物（僧物），此門包含五種：第一是四方僧物，指一切重物，上至阿羅漢、下至沙彌全都有份，不得和合買賣以供私用，這是依方位來命名的；第二是常住僧物，指長久固定在此處不可搬移，四方僧人前來即在此處受用，這是隨用途來命名的；第三是柘鬬提奢物（即招提僧物，梵語四方僧物之意），指俗人在特定土地上為現前僧各自建造私房，四方僧人前來則建立房舍供給所需，這是依處所來命名的；（原文脫漏第四項現前僧物）；第四是現前僧物（原文脫漏，據律制補）；第五是僧鬘物，指僧園中的花果販賣所得之物，這是從華鬘來命名的；《五分律》說僧團有五種財物不可出賣、不可分發：一是土地，二是房舍，三是日常器用之物，四是果樹，五是花果；《僧祇律》說如果在僧地種植果樹是有功勞的，若是一樹或一園，准許給予一熟果實；若不能一次全取，每年可摘取一枝，採遍各枝即告終止；若種植瓜菜，准許給予收割一次；曾有比丘在僧地上建房屋，上座比丘來時不肯讓與，反而拆毀草木攜往他處。

【629-0004】04_比丘尼鈔/06b_卷下之下#45
【原文】第二乞食者見論云分衛者乞食也三乘聖人並皆乞食此律若比丘入村乞食者清旦洗手著七條已𧜼大衣著肩上手執打露杖在道行時常思惟善法若見人先問訊言善來若近聚落便著大衣至於村門應看巷陌第一門第七門相右手捉杖左手持鉢道側而行次第乞食若俗人送食不得迎取除喚往取不得強乞知得立待若得食已乃出村安鉢著地採大衣如前進否而去僧祇若乞食時不得語云與我食得大富當在現處默然而立十誦云乞食時入三重門至中庭三彈指不得便去僧祇云迦葉發願乞食初得施與僧尼後得自食寶梁經云凡乞得食分為四分一分與同梵行一分與窮不乞匃之者第三分與諸鬼神第四分自供身命但念修道於其食中不生貪染心若乞食時繫念威儀終不輕躁諦視目前不過一尋次第乞之。
【譯文】第二門乞食，《善見論》說「分衛」即是乞食之意，三乘聖人都實行乞食；本律規定，比丘若入村乞食，清晨洗手、穿好七條衣後，應將大衣（僧伽梨）疊置肩上，手拿防露杖；行走於道路時，心中常思惟善法；若見到人，先致意問訊說「善來」；若接近聚落，便穿上大衣；走到村門時，應當觀察街巷，從第一家到第七家依相循序；右手持杖，左手托缽，沿著道路一側前行，順次乞食；若俗人送食前來，不得迎上前去領取，除非對方呼喚才前往領取；不得勉強乞求，知道有施與便站立等待；得到食物後便走出村外，將缽安放地上，如同先前那樣收疊大衣，然後整裝離去；《僧祇律》說乞食時不得說「給我食物可得大富貴」，應當在當處默然而立；《十誦律》說乞食時若進入三重門，走到中庭彈指三下，若無人應對不得立刻離去；《僧祇律》說大迦葉發願乞食，最初得到的布施給僧尼，其後得到的才自己食用；《寶梁經》說凡是乞討所得的食物應當分成四份：一份給予同修梵行者，一份給予貧窮不乞討之人，第三份施給鬼神，第四份供養自己生命；只要心念修道，對於食物不生貪染心；乞食之時應當攝受威儀，始終不可輕浮急躁，端正視線看著前方不過一尋（八尺）遠，依序乞討。

【629-0005】04_比丘尼鈔/06b_卷下之下#46
【原文】第三陞座者三千威儀經云上座讀經先禮佛次禮經法及上座後在座正坐向上座犍稚聲絕先讚偈唄如法而說此律不得二人同一高座說法以相諍互求長短故五百問事云若僧中說法高座上無病不得凭机捉麈尾犯墮非毛者得此律得麈尾拂開畜不云得捉十誦云𤛆牛尾拂用拂佛塔故得受僧祇云自今已去聽捉線拂裂㲲樹皮等作之除𤛆牛尾馬尾金銀柄等一切不聽捉若白色應染壞用不得如婬女捉作姿作相是名非法若為律師法師敷師子座散華著上不拂却不得坐婆論云不得以華香瓔珞莊嚴具著佛身上得散地供養眾僧亦爾不得華香著漿飲食上供養眾僧。
【譯文】第三門陞座，《三千威儀經》說：上座讀經時，先禮拜佛陀，次禮敬經法及大眾上座，然後在座位上端正坐好，面向大眾上座；等犍稚鐘聲停息後，先讚誦唱唄，如法宣說；本律規定：不得二人同坐一個高座說法，以免互相爭論、互尋缺失；《五百問事》說：若在僧眾中說法，身在高座上若無病痛，不得倚靠几案、手拿塵尾扇，違者犯墮罪，若非毛製品則可；本律中准許蓄持塵尾拂塵，但未說准許手執說法；《十誦律》說髦牛尾拂塵是用來拂拭佛塔的，因此得以受用；《僧祇律》說自今以後，聽許手持以線繩、撕裂的細布、樹皮等製成的拂塵，除髦牛尾、馬尾、金銀手柄等之外，其餘一律不聽許執持；若是白色拂塵，應染壞其色後使用；不得像倡妓女子那般拿著做出妖嬌姿態，那樣是非法的；若為律師、法師鋪設獅子座並在座上散花，如果不先拂拭去除花瓣，便不得入座；《毘尼母論》說：不得將花香瓔珞等莊嚴用具戴在佛像身上，可以散在地上供養，對待眾僧也是如此；不得把花香放在漿水飲料、食物之上來供養眾僧。

【629-0006】04_比丘尼鈔/06b_卷下之下#47
【原文】第四說法者此律為檀越說法聽說契經及分別義得不具說文句母論云若大眾集文多恐生疲厭者聽諸比丘引經中要言妙詞直顯其義不犯又佛法中不貴浮華之言語雖質朴不失其義令人易解者是立意也五分云若眾樂淺不樂深不益前人名惡說反此名善說又應除貪心不自輕心不輕大眾心應慈心喜心利益心不動心立此等心乃至一四句令前人如實解者長夜安樂又諸比丘請破戒根不具者說法因此惡人得勢又辱眾僧佛言聽請法師三藏者說涅槃經云若比丘為利養故說法所有徒眾亦傚是師是人便自壞眾五百問事云若希望心為讀經說法得物犯捨墮無貪心不犯無衣得取雜阿含經云一比丘得受六十新學比丘教誡說法涅槃經云若有受持讀誦書寫宣說莫非時非國不請而說輕心輕他自歎隨處而說及滅佛法乃至令無量人死墮地獄則是眾生惡知識也十誦云有五種人問不應為說毗尼謂試問無疑問不為悔所犯故問不受語問詰故問並不得答寶梁經云不教施主佛性毗尼此比丘賊行賊住著衣噉食坐臥等皆是賊也。
【譯文】第四門說法（就法），本律規定為檀越居士說法時，聽許宣說契經與分別法義，可以不必逐句念誦全文；《毘尼母論》說若大眾聚集，經文太長恐怕聽眾生起疲倦厭煩，聽許諸比丘摘引經中要領言詞，直接闡明法義，不犯戒；而且佛法中不崇尚浮華詞藻，言語縱然質樸，只要不失法義，能使人容易理解，這就是說法本意；《五分律》說若大眾樂聽淺義而不樂深法，不能利益對方，名為惡說，反之名為善說；說法時應除去貪利之心、不自輕蔑之心、不輕慢大眾之心，應抱持慈心、悲喜心、利益心、不動心；樹立這些善心，乃至只說一首四句偈，只要令對方如實理解，即得長夜安樂；又有比丘迎請破戒、根基不具全的人說法，因此讓惡人得勢，又羞辱了僧眾，佛說聽許迎請通達經律論的三藏法師宣說；《涅槃經》說若比丘為了名聞利養而說法，所有門徒也會效仿這個師父，這人就是自毀僧團；《五百問事》說若懷著貪圖回報之心為人讀經說法而獲得財物，犯捨墮罪，若無貪心則不犯，無衣之人可以收取；《雜阿含經》說一位比丘可以接受六十名新學比丘對其教誡說法；《涅槃經》說若有人受持、讀誦、書寫、宣說佛法，若非適當時機、非適當國度，在未獲迎請下即說，以輕慢自他之心、自我讚歎、隨處濫說以致敗滅佛法，乃至令無量人死後墮入地獄，這人就是眾生的惡知識；《十誦律》說有五種人發問時不應為其說毘尼律：一是試探發問，二是漫無疑惑而問，三不是為了懺悔所犯而問，四是不接受教誡而問，五是為了詰難質詢而問，皆不得回答；《寶梁經》說若不教導施主佛性與毘尼戒律，這個比丘所行、所住如同盜賊，其穿衣、進食、坐臥等，全都是盜賊行為。

【629-0007】04_比丘尼鈔/06b_卷下之下#48
【原文】第五淨地者成實論云若掃僧房一閻浮不如掃佛塔一手掌撰集百緣經云掃地得五功德一自除心垢二去憍慢三調伏心四增長功德五得生善處沙彌威儀經云掃地有五法一不得背人二不得逆掃三即當令淨四不得有跡五當即棄却無垢清淨女問經云掃佛地得五福一自心清淨他人見亦生淨心二為他愛三天心歡喜四集端正業五命終生善道天中。
【譯文】第五門清掃地面（淨地），《成實論》說清掃僧房一整個閻浮提那麼大，不如清掃佛塔一手掌大小之地；《撰集百緣經》說掃地可獲得五種功德：一是消除自心垢染，二是除去憍慢，三是調伏自心，四是增長功德，五是得以轉生善處；《沙彌威儀經》說掃地有五種法則：一是不准背對著人，二是不准逆風橫掃，三是應當徹底掃乾淨，四是不准留下掃帚痕跡，五是應當立即把垃圾倒掉；《無垢清淨女問經》說清掃佛地可得五種福報：一是自心清淨且他人見了也生起清淨心，二是受他人喜愛，三是天神心中歡喜，四是集聚相貌端正的善業，五是命終轉生善道天界之中。

【629-0008】04_比丘尼鈔/06b_卷下之下#49
【原文】第六遇賊者此律比丘被剝不得露身行得罪當以輭草樹葉覆形應取長衣著知友僧中覓衣著乞衣得已應還本處否者犯罪母論云令虗發己聲使賊去僧祇云若賊言僧物何處不得示實處又不得妄語應示房舍牀等佛物指塔邊供具等若道中行有露令年少在前若有賊獸難老僧在中央欲令賊起慈心者老僧前行。
【譯文】第六門遭遇盜賊（遇賊），本律規定比丘被盜賊剝光衣服後，不得裸露身體行走，違者得罪；應當用柔軟的草葉遮蔽身體，取用多餘衣物穿上，或在知友僧眾中尋找衣服穿著；乞討得衣物後，應當返回原處，否則即是犯罪；《毘尼母論》說可以虛張聲勢發出聲音以使盜賊退去；《僧祇律》說若盜賊問僧團財物放在何處，不得指出真實位置，又不得說謊，應當指著房舍、床榻等物說是僧物，指著佛塔旁的供具等物說是佛物；如果在道路上行走遇到露宿處，應讓年輕僧人走在前面；若有盜賊、猛獸之險難，年老僧人應走在中間；若想讓盜賊生起慈悲心，則由老僧走在前面。

【629-0009】04_比丘尼鈔/06b_卷下之下#50
【原文】第七濟畜生者律中慈心解他被繫狗子被溺豚子解蘭若處賊繫牛等不犯僧祗云有神力奪賊劫人放諸禽獸皆慈心作者不犯十誦云若悲壞羅網及獄但犯吉羅五百問事云行路寄鬼神屋宿不得有觸擾意違者犯墮。
【譯文】第七門救濟眾生（濟生），律中規定出於慈悲心解救他人被拴縛的狗、將要被溺斃的小豬，或解救阿蘭若處被盜賊拴綁的牛等，都不犯戒；《僧祇律》說有神通力奪回盜賊劫持之人、放走各類禽獸，凡是出於慈悲心所作者，皆不犯戒；《十誦律》說若因悲憫心而破壞捕獸羅網及牢獄，只犯突吉羅罪；《五百問事》說趕路時借宿在鬼神祠廟中，不得有觸動侵擾之意，違犯者犯墮罪。
