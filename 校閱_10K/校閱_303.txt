# 校閱材料　第303檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【303-0001】02_戒疏/01a_卷一上之一#70
【原文】【疏】答：「須知遠意。原佛降世，豈為增生？天主、人王，咸興有教，佛還說有，則與凡同。以此測量，故懸殊異。」
【譯文】【疏文】回答說：「應當體會這其中深遠的聖意。追溯佛陀降生於世的本懷，難道是為了讓眾生在生死中輾轉增長受生嗎？色界梵天王與欲界帝釋天主，乃至世間轉輪聖王，全都宣說興辦滯留於三界『有』境之教，倘若佛陀也只開示流轉有情之教，那便與凡夫世俗毫無二致。以此層深意加以度量，佛陀的立教與世間福法實有天壤之別。」

【303-0002】02_戒疏/01a_卷一上之一#71
【原文】【記】答中，初科。上一句反責來難，次二句略示佛意。佛所立教，增道損生；若修世福，受人天報，輪轉不息，是謂「增生」，非佛意也。「天」下，引凡比況。梵王色天主，說四無量化人，令生色界。帝釋欲天主，說十善化人，令生欲界。「人王」即四輪王，亦以十善化人，令生人天。不能出離，故云「有教」。佛若同彼，即非「大聖」。
【譯文】【記文】回答之中，是第一小節。第一句話反躬責問提問者的淺見，接著兩句簡要示明佛陀的深意。佛陀所創立的教法，是為了增長聖道、損滅輪迴受生；倘若只修持世間福報，享受人天勝果，在生死中輾轉不息，這便稱為「增生」，絕非佛陀本意。「天」字以下，引述凡間教法來作比喻對照。大梵天王是色界天主，宣說慈悲喜捨四無量心化導世人，使眾生生於色界。帝釋天是欲界天主，宣說十善法化導世人，使眾生生於欲界。「人王」指統治世間的四種轉輪聖王，也是以十善法化導黎民，使眾生投生人天善趣。這些皆無法出離三界輪迴，所以稱作「有教」。佛陀若與他們相同，便不足以被尊稱為「大聖」了。

【303-0003】02_戒疏/01a_卷一上之一#72
【原文】【疏】「任戒集業，但事亂收；體沈下界，判非色有。故《伽論》云：『戒是有為有漏世間法也。』」
【譯文】【疏文】「如果單憑戒行本身去招集業果，只不過是被欲界散亂之境所收攝罷了；戒體本質沈落於下界欲界之中，判定它絕不屬於色界與無色界之法。因此《摩得勒伽論》說：『戒律乃是有為法、有漏法，屬於世間法的範疇。』」

【303-0004】02_戒疏/01a_卷一上之一#73
【原文】【記】次科，行體。已如上釋。心無觀智，隨業牽生，故云「任戒」。是世間因，故云「集業」。
【譯文】【記文】下一小節，闡明行持之體（行體）。義理已如上文所解釋。心中如果沒有相應的觀照智慧，單純隨著業力牽引受生，因此說「任戒」。這終究只是世間的因位，因此說「集業」。

【303-0005】02_戒疏/01a_卷一上之一#74
【原文】【疏】「若元制意，為道方便，三乘學人，必由斯迹。故《律》云『為調三毒令盡故，制增戒學』，又《多論》云『為開泥洹門故制戒』，下文云『戒淨有智慧，便得第一道』，斯良證也。」
【譯文】【疏文】「若是探究佛陀當初制戒的真正本意，乃是作為趣入聖道的善巧方便，三乘一切修道之人，必定都要沿著這條軌跡起步。因此《四分律》中說『為了調伏貪嗔癡三毒令其斷盡的緣故，所以制定了增上戒學』，又《薩婆多論》說『為了開啟泥洹解脫之門的緣故所以制定戒律』，下文偈頌亦說『戒行清淨且具足真實智慧，便能獲證最勝無上的第一聖道』，這些都是確鑿美好的明證。」

【303-0006】02_戒疏/01a_卷一上之一#75
【原文】【記】三中。初正示聖意。「故律」下，略引三文，證成上義，則前所謂「為道非福」深有據矣。云「三乘」者，通約出世聖道為言。前引《律》、《論》，皆言「為」者，即佛意也。次引後偈，必具三學，文無禪定，義必兼收，非禪不慧，義如上說。「迹」謂蹤迹，即指戒法，前聖後賢，同履踐故。戒德尊勝，出過眾善，故云「增戒」。「泥洹」即涅槃，梵言異耳，同翻「寂滅」。聖證最上，故云「第一道」。「良」，善也。
【譯文】【記文】第三小節中。開頭正式示顯佛陀聖意。「故律」以下，概括引證三段經論原文，用以證成上述法義，那麼先前所主張的「制戒是為了求道而非為了世福」，便有了極為深厚的依據。所說的「三乘」，是通泛就出離世間的聖道而言。前面引據的《律》與《論》，都使用了「為」字，指的便是佛陀的制教本意。接著引述後文偈頌，必定是戒、定、慧三學兼備，文面上雖未明言禪定，義理上必定涵攝在內，缺乏禪定便無從生起真實智慧，其道理正如前文所說。「迹」是指足跡蹤跡，在此指稱戒法，因為前代聖人與後世賢者皆同樣循此踐行的緣故。戒法的德行尊貴殊勝，超越世間一切凡善，因此稱作「增戒」。「泥洹」即是涅槃，僅是梵語譯音不同罷了，同樣翻譯為「寂滅」。聖者所證得的果位最為崇高，因此稱作「第一道」。「良」是美好確鑿的意思。

【303-0007】02_戒疏/01a_卷一上之一#76
【原文】【疏】問：「上通敘致，未知此經，別為誰興？」
【譯文】【疏文】問：「以上通泛敘述了制戒的原由，但不知這部特定的《戒本》，是特別為了哪些對象興起開展的？」

【303-0008】02_戒疏/01a_卷一上之一#77
【原文】【記】次別彰戒本，問中。「上通敘」者，一則機通，但云諸有；二者教通，唯言制戒。機分七眾，教張四位，如向所論，未簡別故。「未知」下，正問今經興意。上句問教，下句問機。
【譯文】【記文】接下來在個別彰顯戒本（別彰戒本）之中，是問答段落。「上通敘」的意思是，一方面是所化的對象太廣泛，僅籠統說是三界諸有情；另一方面是所教的內容太寬泛，僅一般性地說是制定戒律。修學根機劃分為七眾弟子，教法張羅分為四種位階，如同先前所討論的，尚未加以精確簡別。「未知」以下，正式請問眼前這部《戒本》興起的特定用意。上句詢問教法的特殊性，下句詢問對象的特殊性。

【303-0009】02_戒疏/01a_卷一上之一#78
【原文】【疏】答：「大聖垂教，通別乃殊；至於去滯，宗猷莫二。創隨犯制，前後森羅；機教俱開，鮮能舉要。窮神知化，唯佛一人；自餘凡小，卒未明達。故別隨戒，單出本文，依月再說，用清非境。」
【譯文】【疏文】答：「大聖佛陀垂賜教法，整體通規與個別特設雖有不同；至於斷除惑亂滯礙，其根本宗要與法度絕無二致。當初隨順比丘的毀犯而隨緣制定，前後律條森羅繁複；針對各類根機的教法一併鋪展，眾人極少能提綱挈領執持其扼要。能窮盡萬法玄妙、洞悉眾生根性造化者，唯有佛陀一人而已；其餘凡夫與小乘聖者，終究無法在短時間內徹底通達通曉。因此佛陀特別依循各條戒律，單獨提煉出條文核心，命僧團依照每月黑白兩半月重複宣說，用以洗清違犯境界、保持清淨。」
