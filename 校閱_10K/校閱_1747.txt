# 校閱材料　第1747檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1747-0001】03_業疏/13a_卷三之二#10
【原文】初人道中：初總標。「天」下別釋，初簡餘趣，列示五道。文標四趣，則合修羅通諸趣故。天著樂者，《多論》云：如目連勸帝釋云「佛世難值，何不數數相近聽受正法？」乃至帝釋云「天上種種宮觀，無數天女，天須陀食，自然百味，百千伎樂，以自娛樂。雖知佛世難遇，正法難聞，以染樂所縛，不得自在」等。阿修羅或翻疑神，疑是信障，故不能入道。「非人」下合明鬼畜，上四句列二趣，下四句明違道。質直反鬼神，慧心反畜類，遐舉謂高遠也。地獄引偈即《智論》也，具云「地獄中陰身，猶如鎔鐵聚，熱惱燒然苦，不可為譬喻」。「唯」下次顯人道，「苦輕下趣」，無常苦也；「樂劣上天」，無勝境也，此二句異於天獄；「強識」異畜生，「念力」異修鬼。下指《多論》，彼云「五道而言，唯人得戒，餘四道不得」是也
【譯文】在第一項「唯人道」中：首先總體標出。自「天」字以下分別解釋，先簡別其餘惡趣，列示五道。文中雖標四趣，是將阿修羅合並通攝於諸趣之故。關於天人貪著享樂，《薩婆多論》記載：如目犍連勸帝釋天說「佛出世極難值遇，為何不常來親近聽受正法？」乃至帝釋回答說「天上有種種宮殿樓觀、無數天女，有甘露天食、自然顯現的百味珍饈，以及成千上萬的伎樂用來自娛。雖然明知佛出世難遇、正法難得聽聞，但被耽染享樂所束縛，不得自在」等。阿修羅有時翻譯為「疑神」，懷疑是正信的障礙，所以無法入道。自「非人」以下合並說明鬼道與畜生道，前四句列出此二趣，後四句說明與道相違。「質直」反於鬼神的諂誑，「慧心」反於畜類的愚鈍，「遐舉」是指高遠。地獄所引用的偈頌即出自《大智度論》，完整文句為「地獄中陰身，猶如鎔鐵聚，熱惱燒然苦，不可為譬喻」。自「唯」字以下進一步顯明人道：「苦輕下趣」，是指沒有惡道恆常的劇苦；「樂劣上天」，是指沒有天界耽溺的勝境，這兩句說明人道不同於天道與地獄；「強識」不同於畜生，「念力」不同於修羅與鬼神。以下指引《薩婆多論》，該論說「就五道而言，唯獨人道得受戒，其餘四道都不得受」，正是此意。

【1747-0006】03_業疏/13a_卷三之二#15
【原文】至如根緣，耳、舌、意三，助道勝也。由耳聽法，意緣邪正，有疑通決，非舌不明，必具此三，定為戒本。故狂、聾、瘂，通及自他，俱非數收，意可見也。眼及鼻、身，少缺通許，約戒受法，能乞能持，雖通在遮，得在開例。如《鈔》廣引《五分》、《僧祇》，斟酌量機，不可輕度
【譯文】至於諸根的因緣，耳、舌、意這三根，對助道的功用最為殊勝。由於耳根能聽聞正法，意根能辨緣邪正，若有疑難需要通達決斷，非藉舌根言語便無法明瞭，所以必須具足這三根，定為得戒的根本。因此狂亂、耳聾、瘖啞之人，通論受戒者與傳戒師（自與他），都不能列入合格之數，其用意顯而易見。眼、鼻、身這三根，若稍有殘缺則通融開許，只要就戒律的受法而言，能夠親自乞戒、能夠依教受持，雖然通常列在遮難之中，但也得以屬於開許之例。正如《行事鈔》中廣泛引用《五分律》、《僧祇律》，必須審慎斟酌度量根機，萬不可輕率度人出家受戒。

【譯文】在第三科中：首先說明耳、舌、意三根若有殘缺則不可開許。以下引述僧數足否之例，證知殘缺者不可任用。「通自他」是指能秉法作羯磨之師與所受戒之弟子。自「眼」字以下說明眼、鼻、身三根若有殘缺則通融開許。如文末指引廣論，見於《行事鈔·受戒篇》，因文字繁廣不再錄出，閱讀時自行查閱。懇切敕令審慎斟量，用意在於精嚴擇選。

【1747-0010】03_業疏/13a_卷三之二#19
【原文】文列《多論》者，以五、八、十戒是具者基，基既先頹，無所加也，何況毀具，反道重受，不可接也。下引諸業者，如汙尼、逆罪，雖無戒犯，然業在生報，戒障三途，正與相違，故成難攝
【譯文】文中列引《薩婆多論》的說法，是因為五戒、八戒、十戒是具足戒的基礎，基礎既然先行崩壞毀塌，就無法再加受具足戒，更何況毀犯具足戒後還俗、如今又想重新受戒，更不可接引。以下引用各類造惡業者，例如淫污比丘尼（污尼）、造作五逆罪等，此時雖然沒有戒律可犯，然而惡業感得來世必受三途生報，而受戒是能阻障三途之法，兩者正好根本相違，所以納入遮難所攝。

【1747-0011】03_業疏/13a_卷三之二#20
【原文】次科：初釋邊罪。《四分》但論具戒，故引《多論》以通餘戒。然據成難，須約四重。雖五、八、十不分重輕，可準大僧篇聚為例。頹，毀也。「下」下次釋重業，文中且據全未受戒白衣為言。注列沙彌汙尼、殺逆，還歸邊攝；但有賊住，如後自明。生報三途，戒所不障，故與相違
【譯文】在第二科中：首先解釋「邊罪」。《四分律》僅討論犯具足戒的邊罪，所以引用《薩婆多論》以通涉其餘各戒。然而依據構成遮難的條件，必須限於四重罪。雖然五戒、八戒、十戒不分篇聚輕重，但可以比照大僧的篇聚為例。「頹」就是毀壞的意思。自「下」字以下解釋極重之惡業，文中暫且依完全未曾受戒的白衣來說。注中所列沙彌污尼、犯殺父弒母等逆罪，仍歸於邊罪所攝；但若有賊住，如後文自會說明。造下此等重業者，次生必墮三途惡道，戒法無法障阻其惡報，所以與戒體互為相違。
