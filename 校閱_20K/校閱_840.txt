# 校閱材料　第840檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【840-0001】03_業疏/13a_卷三之二#14
【原文】次科：初敘時澆報劣，學行謂修持也。「教」下次明教通開制，防譏則護於外化，成道則接彼下根
【譯文】在第二科中：首先敘述時代澆薄、果報低劣，「學行」是指修持。自「教」字以下說明戒教通於開許與制止，防譏是為了維護對外的化導，成道則是為了接引那些下根之人。

【840-0002】03_業疏/13a_卷三之二#15
【原文】至如根緣，耳、舌、意三，助道勝也。由耳聽法，意緣邪正，有疑通決，非舌不明，必具此三，定為戒本。故狂、聾、瘂，通及自他，俱非數收，意可見也。眼及鼻、身，少缺通許，約戒受法，能乞能持，雖通在遮，得在開例。如《鈔》廣引《五分》、《僧祇》，斟酌量機，不可輕度
【譯文】至於諸根的因緣，耳、舌、意這三根，對助道的功用最為殊勝。由於耳根能聽聞正法，意根能辨緣邪正，若有疑難需要通達決斷，非藉舌根言語便無法明瞭，所以必須具足這三根，定為得戒的根本。因此狂亂、耳聾、瘖啞之人，通論受戒者與傳戒師（自與他），都不能列入合格之數，其用意顯而易見。眼、鼻、身這三根，若稍有殘缺則通融開許，只要就戒律的受法而言，能夠親自乞戒、能夠依教受持，雖然通常列在遮難之中，但也得以屬於開許之例。正如《行事鈔》中廣泛引用《五分律》、《僧祇律》，必須審慎斟酌度量根機，萬不可輕率度人出家受戒。

【840-0003】03_業疏/13a_卷三之二#16
【原文】三中：初明三根有缺不開。下引足數，證知非用。通自他者，即能秉、所為也。「眼」下次明三根有缺通許。如下指廣，如《鈔》竝見〈受戒篇〉，文廣不錄，臨文自尋。誠令斟量，意在精擇
【譯文】在第三科中：首先說明耳、舌、意三根若有殘缺則不可開許。以下引述僧數足否之例，證知殘缺者不可任用。「通自他」是指能秉法作羯磨之師與所受戒之弟子。自「眼」字以下說明眼、鼻、身三根若有殘缺則通融開許。如文末指引廣論，見於《行事鈔·受戒篇》，因文字繁廣不再錄出，閱讀時自行查閱。懇切敕令審慎斟量，用意在於精嚴擇選。

【840-0004】03_業疏/13a_卷三之二#17
【原文】三身心清淨者，既為道器，純淨方堪，如淨舍宅，可以為例；又如淨衣，易染為色，故先染汙，不成後受。律中所列十三種人，皆為戒難，如後相解
【譯文】第三項「身心清淨」，受戒者既然作為載道之器，必須純潔清淨方能堪任，如同潔淨的舍宅，可以用來作為譬例；又如同潔淨的白衣，容易染成如法的色澤，所以若先已被染污，便不能成就後來的受戒。律中所列舉的十三種人，都構成受戒的難事，如後文分別解釋。

【840-0005】03_業疏/13a_卷三之二#18
【原文】三中初科：初以喻顯，舍宅則先法後喻，淨衣則先喻後法。「律」下次指所簡，下文委解
【譯文】在第三項的第一科中：首先以譬喻顯明義理，舍宅的比喻是先立法說後出喻說，淨衣的比喻則是先出喻說後立法說。自「律」字以下指出所要簡別淘汰之人，下文將詳細解釋。

【840-0006】03_業疏/13a_卷三之二#19
【原文】文列《多論》者，以五、八、十戒是具者基，基既先頹，無所加也，何況毀具，反道重受，不可接也。下引諸業者，如汙尼、逆罪，雖無戒犯，然業在生報，戒障三途，正與相違，故成難攝
【譯文】文中列引《薩婆多論》的說法，是因為五戒、八戒、十戒是具足戒的基礎，基礎既然先行崩壞毀塌，就無法再加受具足戒，更何況毀犯具足戒後還俗、如今又想重新受戒，更不可接引。以下引用各類造惡業者，例如淫污比丘尼（污尼）、造作五逆罪等，此時雖然沒有戒律可犯，然而惡業感得來世必受三途生報，而受戒是能阻障三途之法，兩者正好根本相違，所以納入遮難所攝。

【840-0007】03_業疏/13a_卷三之二#20
【原文】次科：初釋邊罪。《四分》但論具戒，故引《多論》以通餘戒。然據成難，須約四重。雖五、八、十不分重輕，可準大僧篇聚為例。頹，毀也。「下」下次釋重業，文中且據全未受戒白衣為言。注列沙彌汙尼、殺逆，還歸邊攝；但有賊住，如後自明。生報三途，戒所不障，故與相違
【譯文】在第二科中：首先解釋「邊罪」。《四分律》僅討論犯具足戒的邊罪，所以引用《薩婆多論》以通涉其餘各戒。然而依據構成遮難的條件，必須限於四重罪。雖然五戒、八戒、十戒不分篇聚輕重，但可以比照大僧的篇聚為例。「頹」就是毀壞的意思。自「下」字以下解釋極重之惡業，文中暫且依完全未曾受戒的白衣來說。注中所列沙彌污尼、犯殺父弒母等逆罪，仍歸於邊罪所攝；但若有賊住，如後文自會說明。造下此等重業者，次生必墮三途惡道，戒法無法障阻其惡報，所以與戒體互為相違。

【840-0008】03_業疏/13a_卷三之二#21
【原文】四相具者，即形同也。下列覆、露兩儀，俱非道相，離於二邊也。今時三衣實相同本，自褊衫、正背、方裙、裿支，皆非經律也，然且順律文，非俗非外耳
【譯文】第四項「法相具足」，也就是外形體貌與僧伽相同。下文列出覆蓋嚴密與裸露身軀兩種儀表，都不是佛道之相，應當遠離這兩種極端。當今的三衣，其實質形相與梵本規制相同，至於褊衫、正背、方裙、裿支（衵衣）等，都不是經律中所規定的服制，然而姑且依順律文精神，做到既非世俗裝飾亦非外道形相罷了。

【840-0009】03_業疏/13a_卷三之二#22
【原文】四中：初牒釋云形同者，斷緣相也。「下列」等者，釋簡非也。俗人莊嚴，著有邊也；外道裸形，著無邊也；亦名斷常二邊。《智論》云：佛聖弟子住於中道，故著三衣。「今」下次決時用。初明三衣相同本者，不異西梵也。「自」下次示餘衣：正背，《鈔》作褡膊；方裙，似今幃裙；倚支，搭左肩上，繫右腋下，以𭣋袈裟，名出本律，但製造乖法耳。此等諸衣，雖非經律，然其體色猶存道相，可順律文。律云「自今已去，一切俗人、外道服，竝不得著」是也
【譯文】在第四項中：首先引牒解釋「形同」，是指斷除世俗因緣的外相。自「下列」等句，是解釋簡別非道之相。世俗之人講究服飾莊嚴，是執著於「有」的極端；外道赤身裸體，是執著於「無」的極端；這也稱為斷、常二邊。《大智度論》說：佛陀聖弟子安住於中道，所以身著三衣。自「今」字以下決斷當時代之所用。首先說明三衣相同於原本規制，是指與天竺梵本無異。自「自」字以下指明其餘附屬衣物：「正背」在《行事鈔》中稱為「褡膊」；「方裙」類似今日的圍裙；「倚支（裿支）」是搭在左肩上、繫於右腋下，用來掩映袈裟的內衣，名稱雖出自本律，只是後世縫製方法違背了律法。這些衣物雖然不合經律古制，然而其形制顏色依然存有修道之相，可以隨順律文。正如律中所說「從今以後，凡一切世俗人與外道的服裝，一概不得穿著」即是此意。

【840-0012】03_業疏/13a_卷三之二#25

【840-0015】03_業疏/13a_卷三之二#28
【原文】一結界須成者，以教法所由，非界不立，深須通練，方應受緣。今世行事，聞受便誦，都不觀緣，非但誦得不須界也。縱知有界，須曉結人，迷濫多雜，致虧界本，即須窮問初結體標離合。後人不知，即是虗指。如上文中，捨結極易，何得自輕？拈得徑作，約事驗人，心不實後生還爾，何慮不然
【譯文】第一項「結界必須成就」，因為僧團教法的施行，若無結界便不能成立，必須極為通達熟練，方能堪應受戒因緣。當世辦理法事之人，一聽說要受戒就隨口唱誦羯磨文，完全不觀察界緣是否成就，難道只要口誦羯磨就能得戒、而不需要結界嗎？！縱使知道有結界之事，也必須明瞭當初結界之人的持犯學行，若昏亂混雜，導致虧損了結界的根本法則，就必須徹底追究當初結界時的體性、標相及離合情況。後人若全不知曉，那就是虛妄指稱有界而已。正如上文所言，捨界與重新結界極為容易，怎能自輕草率？隨手拿來就徑直作羯磨，依據事實檢驗其為人，若存心不誠實，來生轉世也會同樣愚昧受報，這又何必擔憂因果不會如此呢？

【840-0016】03_業疏/13a_卷三之二#29
【原文】第二所對結界中：初敘緣。「今」下斥非，初斥不立界緣。「非但誦得」，言不唯直誦羯磨而得戒也。「縱」下次斥立而乖謬：一須尋界相分齊分明，二須考結人學行明昧。指上文者，即〈結界篇〉。「約」下總責二過，「心不實」者，非為度人故；「後生還爾」，相似果報故
【譯文】在第二項所對之「結界」中：首先敘述結界的緣起。自「今」字以下斥責錯誤，先斥責不建立結界之緣。「非但誦得」，是說並不能單憑口誦羯磨就得以獲戒。自「縱」字以下斥責雖結界卻出現乖謬：一是必須尋查界相分界是否清晰分明，二是必須考證結界之人的學識德行是明達還是愚昧。所指的上文，即指〈結界篇〉。自「約」字以下總體責備這兩種過失：「心不實」，是指並非真心為了度人；「後生還爾」，是指將感召同等愚癡的相似果報。

【840-0019】03_業疏/13a_卷三之二#32
【原文】三僧數須滿，中邊二受，雖列五、十不同，非數不可妄預。如論簡人，乃云清淨。清淨之言，何所不在，豈在戒也？戒淨由於智明，必於事法開遮曉通如鏡，方得受體清淨無染
【譯文】第三項「僧眾人數必須圓滿」，在中國與邊地兩種受戒法中，雖然規定有五人與十人的不同，不合入僧數之人決不可妄自預入充數。正如論中甄別戒師資質時所說，必須是「清淨」之人。所謂清淨，哪裡有不包含的修德，難道僅僅限於不犯戒條嗎？持戒清淨是由於智慧明達，必須對於僧事羯磨法則的開遮持犯通達明白如同明鏡，才能令受戒者的戒體清淨毫無染污。

【840-0020】03_業疏/13a_卷三之二#33
【原文】三中，別約受具，必須數滿。兩緣相濫，通別分之。初科：初釋數滿，正明中受，兼示邊開。「如」下次釋《母論》，若唯守戒，無智暗教，持犯不明，終非清淨
【譯文】在第三項中，特別就受具足戒而言，人數必須圓滿。因「僧數」與前項「秉法僧」兩緣容易混淆，所以用通相與別相加以區分。第一科：首先解釋僧數圓滿，正明中國受戒需十人，兼示邊地開許五人。自「如」字以下解釋《毘尼母論》，若只是死守戒相，沒有智慧而蒙昧於戒教，對持犯開遮糊塗不明，終究算不上真正清淨。

【840-0021】03_業疏/13a_卷三之二#34
【原文】今有人言：但不破戒，即堪足數。此言濫也。通不破戒，無著猶染；別不破戒，時逢非數，如睡、定、癡、鈍、聾、狂之類，雖有若無，忍默空據，不名僧滿。今此邊隅，用本開五，必叵具者，雖行無罪，可通曉也
【譯文】如今有人說：只要不破戒，就可以算作湊足僧數。這種說法太過籠統混濫了。就通途不破戒而言，即使是阿羅漢（無著）尚有不知而犯的染污；就個別不破戒而言，有時遇上不合僧數之人，例如睡眠、入定、愚癡、遲鈍、耳聾、狂亂之類，這些人雖在座中卻如同不存在，即使默認也只是徒佔座位，不能稱為僧數圓滿。如今身處此方邊陲之地，依據佛本制開許五人即可，若確實無從湊足合格之人，雖然如法推行而無罪過，這一點應當通達明曉。

【840-0022】03_業疏/13a_卷三之二#35
【原文】次科：初引非。「此」下躡斥。無學結惑永盡，名究竟解脫，一切無犯，故云通不破也，然有誤犯，故云尚染。若云但不破戒，聖人誤破，即應非數。凡夫惑業尚存，名別別解脫，有犯不犯，故云別不破也。若云但不破戒，凡僧不破睡定等緣，即應足數。「今」下決此土用僧，據本僧多，須依中國；知法難得，可用五人，理應無罪。《十誦》、《伽論》「得戒得罪」，乃約易得處為言
【譯文】在第二科中：首先引用錯誤觀點。自「此」字以下接著斥責。無學聖人煩惱惑業永盡，稱為究竟解脫，一切粗重戒律無所違犯，所以說「通不破戒」，然而偶有不知誤犯，所以說「尚有染污」。如果說只要不破戒即可足數，那麼聖人即便微細誤破，豈不就不能入數了？凡夫煩惱惡業尚存，所持名為別別解脫戒，有犯與不犯之別，所以說「個別不破戒」。如果說只要不破重戒即可，那麼凡夫僧人即便處於睡眠、入定等不合格因緣中，豈非也能算作足數？自「今」字以下決斷此土僧人的任用，若依據律制原本要求僧人眾多，必須依循天竺「中國」之法（十人）；但若明達戒法之人難得，也可通融採用五人，在理上應當無罪。《十誦律》、《摩得勒伽論》所說的「得戒但得違制之罪」，是針對容易尋得合格僧人的地方而言的。
