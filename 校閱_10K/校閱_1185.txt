# 校閱材料　第1185檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1185-0001】資持記/09c_中三上#47
【原文】律緣瓶沙王妹有子，於外道出家，詣僧坊設食故佛開之。疏云：將化入道，故開受供。他部緣中。疏問：律明作衣，已是開限，何用衣時？答：據本受意，有長短也；文云下至一縫者，極短也。〔短即《四分》作衣，長謂《五分》衣時。〕次別證中，前引《增一》。
【譯文】律典中的起因緣起是頻婆娑羅王的妹妹生了一個兒子，在邪命外道中出家，後來特地來到僧寺設齋供養，佛陀因此特予開許。義疏說：這是為了教化他導入正法佛道，所以破例開許接受這份供養。在引用其餘部派的開緣中，義疏提出詰問：本律既然指明縫製衣服就是開許的期限，為何還要另立一個「衣時」的名目？回答：依照最初領受衣物時的心念，有時間長短的分別；文中提到「下至縫合一處縫線」，指的是極短的期限。〔時間短的即是指《四分律》中親手縫製衣服的期間，時間長的則是指《五分律》中整個通用的受衣時節。〕接著在別立見證中，前段先引用了《增一阿含經》。

【1185-0002】資持記/09c_中三上#48
【原文】彼云：佛在羅閱城，長者請舍利弗目連等五百人，佛呵如鈔。飲大海者，由心通僧寶，無所簡擇；雖得一人，則為供養十方凡聖故。師子下，受教奉行。佛讚下，為聖所讚。《賢愚》中。姨母自紡績作一端金色㲲上佛；佛言：可以施僧，得福無量；若於十六具足〔《增輝》云：僧尼各有四果四向。
【譯文】經中說：佛陀在王舍城時，有長者迎請舍利弗、目犍連等五百位大阿羅漢，佛陀呵斥的情形正如鈔文所載。所謂「痛飲大海之水」，是因為心量全面涵括了整個僧寶，沒有絲毫的分別挑揀；哪怕只迎請到一位凡夫僧人，就等於實質供養了十方一切凡夫與聖僧大眾。在「師子」以下，說明信徒接受佛陀教誡並如法奉行。在「佛讚」以下，說明這種平等施心受到了佛陀聖眾的讚歎。在《賢愚經》中提到，佛陀的姨母大愛道瞿曇彌親自紡紗織布，製成一匹金色的細毛氈獻給佛陀；佛陀告訴她：應當將這端布匹布施給大眾僧，這樣能獲得無量無邊的功德福祉；如果只是布施給十六位具足戒德的僧眾〔《增輝記》解釋：是指比丘與比丘尼中各自具備的四果四向等聖賢位。

【1185-0003】資持記/09c_中三上#49
【原文】未足為多；餘如鈔中。挾，抱也。名字僧，無實德者。問：前引《五分》除惡戒者，此何相違？答：疏云：《五分》簡人，精也；賢愚取人，麁也。破戒受施，且取外生物信，令於僧海自感施福，非謂行缺能消信施。〔疏中意也。
【譯文】所得的福報根本稱不上廣大；其餘文義正如鈔文中所引。挾，意思就是抱持。所謂「名字僧」，是指徒有僧人虛名而無實質戒德之人。有人問：前文引用的《五分律》要求必須剔除惡戒之人，這豈不是與此處互相矛盾？回答：義疏指出，《五分律》著重在挑選受請者，採取的是嚴格精純的標準；《賢愚經》著眼於施主攝受對象，採取的是寬廣博大的標準。破戒僧人受納布施，只是暫且藉由僧相在外表上引發世人的信心，讓施主在浩瀚的僧海中自然感得布施的大福報，絕不是說持戒殘缺有虧之人自己真能消受得了信徒的布施供養。〔這正是義疏的本意。

【1185-0004】資持記/09c_中三上#50
【原文】私謂：《五分》除惡戒，《佛藏》不消杯水，《母論》腹裂；律中畜寶，對俗呵制；對施興治，能所俱墮；如是等類，並謂極誡內眾，使自策勤；《增一》、《賢愚》、《十誦》、《善生》，皆據導俗；恐忽慢僧徒，自招枉墜。是知受須戒淨，不淨則自陷無疑；施必普周，不周則所施無福。
【譯文】我私下認為：《五分律》嚴厲剔除破戒僧徒，《佛藏經》警示破戒者連一杯清水都無法消受消融，《毘尼母論》指出破戒受施會招致肚腹爆裂的劇報；律典中對於私自蓄積珍寶的行徑，是當著世俗大眾的面嚴厲呵責制約；對於濫受布施而興起的對治懲處，讓施受雙方通通墮入惡道；像這一類的嚴格教誡，全都是極力訓誡僧團內部的大眾，促使僧人時時刻刻自勉精進策勵身心；至於《增一阿含經》、《賢愚經》、《十誦律》、《善生經》的教導，全都是著眼於引導化育世俗檀越；唯恐在家人輕忽慢待出家僧徒，給自己平白招來枉墮惡道的奇禍。由這點可知：受請者必須保證戒行清淨，若是戒德不淨自己必將墮落無疑；施主發心則必須普周平等，若是不周不平等則所布施之物將無福可言。

【1185-0005】資持記/09c_中三上#51
【原文】用斯往判，諒無所違。總判中，初明功益。通揀九種。注顯八緣，其相可解。次告白中，初無緣者。疏云：無上九中前六也；有緣之者，且能自益；無緣之人，故須白出。若下，有上六緣，制令白入。後三統眾，故但云六。若據大眾，亦是通眾；以非儉時，則分為二部，互白出入。
【譯文】用這層道理前去融通評判，相信各部經論之間就毫無矛盾牴觸之處了。在總結評判中，首先闡明所獲得的功德法益。總體料簡了九種開緣。注文中具體揭示了八種特殊事緣，其犯戒相貌極為顯明易懂。接著在「稟白告知」中，首先說明沒有特殊事緣的情況。義疏說：是指不具備上述九種情況中的前六種緣由；有特殊事緣的人，暫且能夠獨自獲得法益開許；完全沒有事緣的人，所以必須正式向大眾宣白之後方能外出。在「若」字以下，說明若具備上述六種事緣，便規定必須先向大眾宣白之後才能進入別處受食。後三種情況是統轄全體大眾的通規，所以此處僅僅提到前六種。如果就全體僧眾的角度而言，這同樣屬於共通的大眾法規；因為在非饑饉荒年的平常時期，僧團就必須分為兩個部別，彼此互相宣白告知外出與進入。

【1185-0006】資持記/09c_中三上#52
【原文】疏云：所以白出者，護施主意故；白入者，護內比丘意故。言隨次者，律云：隨上座次入；疏云：身是有緣，入須儀式。不白吉者，違教故也。問：無緣白出，不白犯不？答：望同違教，理應準結。或可不白而出，無損於眾；入則反之，故制與罪。不犯指前本異九種。
【譯文】義疏說：之所以規定必須宣白後才能外出，是為了維護施主原本供僧的至誠心意；規定必須宣白後才能進入，則是為了顧全內部僧團比丘們的和合心意。文中所說「依照倫次」，律典記載：必須依照上座長老的戒臘次序魚貫進入；義疏說：自身雖然具備特別事緣，進入現場時仍必須恪守威儀規矩。若不向大眾宣白就私自行動便結突吉羅輕罪，因為違背了佛陀的教誡之故。有人問：沒有特殊事緣而宣白外出，若是不向大眾宣白就私自跑出去，到底算不算犯戒？回答：以同樣違背佛陀制定的教規來看，在法理上理應比照標準予以結罪。或者也可以說：不宣白就逕自離開，對常住大眾並未造成實質損害；若不宣白就擅自闖入接受供養則恰恰相反，嚴重破壞了僧倫秩序，所以才特別制定戒律予以科處罪刑。不犯戒的情況，請直接參照前文所列本律與各部律典所載的九種開緣。

【1185-0007】資持記/09c_中三上#53
【原文】四分律行事鈔資持記中三上
【譯文】四分律行事鈔資持記卷中之三第一部分終

【1185-0008】資持記/10a_中三下#1
【原文】四分律行事鈔資持記中三下三十四。〔佛在舍衛，婦人將還夫家；辨食頻施，經時不還，夫別取婦；又取商客食分路中數施，為賊所劫，因此二緣，合制一戒。〕列緣。第一指上標名。第三疏云即《戒本》中無病過受，則知開有病也。第四疏云：《多論》上鉢取一無罪，二鉢是犯；
【譯文】《四分律行事鈔資持記》卷中三之下第三十四條。〔佛在舍衛國時，有一位婦人準備返回夫家；她準備了食物頻頻布施僧眾，經過許久都未回去，丈夫便另娶了妻子；婦人又拿了客商的食物在路途中多次布施，結果客商被盜賊劫掠。因為這兩種緣起，佛陀合併制定了一條戒律。〕這是列出制戒緣起。第一點是指向上文標示的戒名。第三點戒疏說，這就是《戒本》中所說的無病而過量受取，由此便知有病是可以開許的。第四點戒疏說：《薩婆多論》認為大鉢取一鉢無罪，取兩鉢就犯戒；
