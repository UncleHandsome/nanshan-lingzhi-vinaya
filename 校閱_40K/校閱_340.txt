# 校閱材料　第340檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】第二依止意者尸迦羅越六方禮經弟子事師當具五意一當敬難之二當念其恩三所有言教隨之四報恩不厭五從後稱譽師教弟子亦有五意一當令疾知二令勝他人弟子三令知不忘四有諸疑難悉為開解五欲令弟子智慧勝師正法念經云若畏師持戒名下持戒僧祇師度弟子者不得為供給自己故度人出家得罪當使彼人因我度故修諸善法得成道果佛藏經云五夏已前於人受學律藏五夏已後具知應學無我人法見論云云何學律謂讀誦解義也此律云和尚畜弟子當如兒想弟子看和尚當如父想義云如兒想看者須具四意一匠成訓誨二慈念三矜愛四攝受以衣食如父看者還具四心一親愛二敬順三畏難四尊重敬養如臣子之事君父也故律云如是展轉相敬相重瞻待令正法便得久住增益。
【譯文】第二門「依止本意」：《尸迦羅越六方禮經》說：弟子侍奉師長應當具備五種心意：一是要敬畏尊重大師，二是要常念大師的恩德，三是所有言教都要隨順遵行，四是報答師恩永不厭倦，五是要在背後讚美稱頌師德。師長教導弟子也有五種心意：一是要讓弟子迅速通達，二是要讓弟子超越其他人的門徒，三是要讓弟子領會後永不遺忘，四是遇到所有疑難都替他開解消除，五是希望弟子的智慧能超越師長自己。《正法念處經》說：如果只是因為畏懼師長而持戒，稱為下等的持戒。《僧祇律》說：師長度化弟子，不得為了替自己提供勞役使喚而度人出家，否則得罪；應當使那個人因為我的度化，而能修持各項善法，得以成就道果。《佛藏經》說：出家五夏以前，應當向他人求教學習律藏；五夏以後，具足通達了，就應當學習無我無人的大乘正法。《善見論》說：怎樣才算學習戒律？是指能夠讀誦並通解其義理。本律說：和尚對待弟子，應當如同對待自己的親生兒女；弟子看待和尚，應當如同看待自己的親生父親。義理上分析：視如兒女的心態，必須具備四種心意：一是培育教誨，二是慈悲顧念，三是憐憫疼愛，四是用衣食加以照顧攝受。看待和尚如同父親，也必須具備四種心意：一是親切敬愛，二是恭敬順從，三是敬畏謹慎，四是尊重供養；就像臣民與兒子侍奉君王與父親一樣。所以戒律說：像這樣彼此輾轉敬重尊崇、相互照顧護持，正法才能夠長久住世並日益昌盛增長。

【原文】第二敬佛者惟今道俗虔誠寡薄慢怠逾強輕懱聖容傲物自廣遂令故像豐多盈堂滿室趺光墮落手足縱橫泥木雜汙糞土狼藉於是青蓮之座數傾白毫之相屢危寶塔自摧嚴容聳峙設有與心造作鎔鑄不圓相好尊儀至多疎漏或爭價高下增減靈相逐賤省功將為稱意致使形儀換改不類西華隨情造作乃同糞土遂使國君有破壞之心臣民存不敬之意善惡無徵羣邪競起至聖不加反招自辱靜思己過豈不然乎阿含經云無恭敬心於佛法中當墮龍蛇中以過去從中來今猶無敬故多睡也又佛昇忉利天優填王請目連為我等將巧師看世尊形下來造之三上三審三下始得真相世尊下來此像迎佛佛為摩頂記當來利益於我敬福經云經像主莫論道雇經像之匠莫云客作造佛布施二人獲福不可度量欲說其福窮劫不盡受吾約制是佛真子如是精誠造少福多問居士之中作經像師合取直否答不得取價直如賣父母取財者逆過三千直是天魔離吾佛法非我眷屬飲酒食肉五辛之徒不依聖教雖造經像數如微塵其福甚少蓋不足言劫燒之時不入海龍王藏勞而少功不敬之罪死入地獄主匠無益諸天不祐不如不造直心禮拜得福無量如向所列造多福少像師作像不具足相五百世諸根不具第一盡心為上妙果先昇。
【譯文】第二、恭敬佛像（敬佛）：觀想當今出家與在俗之人，虔誠之心極其淺薄，懈怠傲慢之氣反倒越來越重；輕視蔑視佛陀聖容，傲慢待人、自我膨脹，以致於破舊的佛像充斥各處，堆滿殿堂房屋。背光跌落損壞，殘肢斷臂橫七豎八，泥塑木雕雜處汙穢之中，泥土糞穢狼藉不堪。於是青蓮華的佛座頻頻傾倒，白毫相的佛顏屢屢遇險，珍寶裝飾的佛塔自行倒塌，原本莊嚴聳立的容貌蕩然無存。縱使有人發心造作，熔鑄卻不圓滿，相好莊嚴的儀容大多粗疏漏失；或者為了造像工價爭論高低，隨意增減聖像的尺度，貪圖便宜、省工減料，自以為十分合意；以致造成聖像儀軌變樣，完全不像西方天竺傳來的法相，隨順私情隨意造作，簡直等同於泥土糞塊。這就致使國君產生破壞毀棄之心，臣民心存不敬之意，善惡昭彰無憑無據，種種邪說競相興起；無上至聖之像得不到尊崇，反而招致世人侮慢褻瀆。靜下心來反省自己的過失，難道不正是如此嗎？《阿含經》說：在佛法中若是缺乏恭敬心，將來應當墮入龍蛇之中；因為過去世是從這類畜生轉生而來，如今依然沒有恭敬心，所以常常昏沉多睡。又如佛陀升到忉利天時，優填王請求目犍連尊者：「請為我們帶領能工巧匠，去瞻仰世尊的形貌，回到人間來塑造。」巧匠三次上升天界、三次審視聖容、三次返回人間，才得以塑出真實的相貌。世尊從天上下降時，這尊木像主動前來迎接佛陀，佛陀為它摩頂，並授記它未來將在佛法中廣作利益。《敬福經》說：經書與佛像的主人，切莫與工匠討價還價；受雇雕造經像的工匠，也不要自稱是在打短工。造佛像與行布施這兩個人，所獲得的福報廣大得不可限量；要想說盡他們的福德，歷經窮盡大劫也說不完；能遵從我的告誡約束，才是佛陀真正的弟子；如此精誠專注，即使造像微小，獲福也極多。有人問：在居士之中，以製作經卷佛像為業的工匠，應不應當收取酬勞工錢？回答說：不得收取工錢身價；如果像販賣父母一樣以此謀取財利，其忤逆之罪超過三千條大罪，這簡直就是天魔外道，脫離了我的佛法，不是我的眷屬。那些飲酒、吃肉、食用五辛的人，不依從聖教修行，雖然建造的經書佛像多如微塵，但所得的福報極其微少，根本微不足道；等到大劫之火焚燒之時，所造的經像也不能被收入海龍王宮的經藏之中，勞心費力而鮮有成效。因不敬之罪，死後必定墮入地獄，造像之主與工匠都毫無益處，諸天善神也不會庇佑；與其如此，倒不如不造，只要以質直之心禮拜佛陀，就能獲得無量福德。正如方才所列舉的，造得雖多而福報極少，工匠若是造像相貌殘缺不圓滿，五百世中諸根殘缺不全。唯有全心全意極盡至誠才是上等，其殊勝妙果必定最先顯現提升。
