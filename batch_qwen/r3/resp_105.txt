整體讀來通順，多數判罪術語（波羅夷、偷蘭遮、羯磨、五眾）處理得當。以下按「意思有出入」→「用語可再精準」→「體例」→「第二段互用」分列，標★者是建議一定要改的。

---

## 一、意思有出入（需改）

**★1.「隨約所與人邊結罪」→「隨即依所贈與的人那邊來結罪」**
「隨約」是「隨／約」同義連用，都是「依、就」的意思，不是「隨即」。譯文憑空生出時間義。
建議：**「就依受囑授（受贈）的那個人這邊結罪。」**

**★2.「此未見諸部明文」→「這未見諸部律典有明文開許」**
加了「開許」，把意思改反了方向。文脈是：有人看到《四分》說「皆犯偷蘭」，就宣稱「盜僧物不成盜（重）」，於是放膽奪取；鈔主斥責這種人**沒讀到諸部律的明文**（前引《僧祇》《善見》皆判重）。「未見」是「他沒看見」，不是「律中沒有開許」。
建議：**「這是因為沒有看到諸部律的明文（才有的誤解）；若強行奪取入己，即結重罪。」**

**★3.「若奪成重」→「若強奪則僧人自己構成重罪」**
「僧人自己」是譯者添加的限定，原文並無；盜僧物成重通於道俗。
建議：**「若強奪據為己有，便結重罪（波羅夷）。」**

**★4.「亡五眾輕物」→「所遺留的輕便物件」**
「輕物」是律中专術，與「重物」相對：**重物**（房舍、田園、床榻等）屬四方僧、不可分；**輕物**（衣缽、資身用品等）可羯磨分與現前僧。不是「輕便／重量輕」的意思。
建議：**「例如亡故五眾所遺留的『輕物』（衣缽等可分與現前僧的資具；房舍田園等重物則屬四方僧，不可分）。」**

**★5.「隨損一毫」→「隨便損壞一絲一毫」**
「隨」是「任隨、哪怕只要」，不是白話的「隨便」；「損」是侵損、盜損，未必是「損壞」。
建議：**「哪怕只侵損一絲一毫，也要望十方凡夫僧、聖者僧一一結罪。」**

**★6.「同共盜損，應得輕罪」→「若是大眾共同盜損，應得輕罪」**
「大眾」易被讀成一般信眾。此句指**僧眾自己**共同私取、耗用：因十方常住物人人有分，取自己也有分之物，故結輕。
建議：**「若是（本處）僧眾共同私自取用或耗損，因各人於僧物中本来有分，應得輕罪。」**

**7.「《四分》：暫礙僧用，故結輕」→「《四分律》說」**
這句是**鈔主的會通之語**（解釋《四分》為何只結偷蘭），並非《四分律》原文。與前面真正的引文用同一句式「《四分律》說」，會誤導讀者。
建議：**「（會通）《四分律》之意：是就暫時妨礙僧眾使用而說，所以結輕罪；若永久入己，則同《善見論》判重。」**

## 二、用語可再精準（小修即可）

| 原文 | 譯文 | 建議 |
|---|---|---|
| 有護主者 | 守護的主人 | 「護主」是**看管人**（知事、守護者），非物主；後文已譯對，宜統一作「守護主（看管人）」 |
| 不可分用 | 不可分割使用 | 「不可分割、分給個人受用」 |
| 行用與人 | 拿去使用**並**贈與他人 | 「自己受用**或**給與他人」（非二者兼備） |
| 偷蘭遮（重大罪） | — | 宜作「粗罪（次於波羅夷、僧殘的重罪）」，與前面「波羅夷＝極重罪」拉開層級 |
| 一錢已上犯偷蘭 | 一錢以上 | 補「（未滿五錢）一錢以上」，避免與五錢重罪重疊 |
| 若僧、若眾多人、若一人 | 照譯 | 可加註：僧＝四人以上、眾多人＝二至三人、一人 |
| 若未羯磨…得罪輕 | 由於歸屬十方僧 | 可補理由：「十方僧人數無量，各人分薄，故所損輕」；已羯磨則人少分厚，故重 |
| 多有人施佛物者 | **常**有人布施 | 「**許多**人拿物品供施於佛」（多有＝數量，非頻率） |
| 入阿鼻而得早出 | 也要墮入阿鼻地獄而得以早出 | 語意轉折不順：「仍要墮阿鼻（無間）地獄，只是能較早出離；何況不償還的，永無出期」 |
| 五逆四重 | 四重罪 | 可註「四重＝四波羅夷（淫、盜、殺、妄）」 |
| 如僧家供僧常食／如亡五眾輕物 | 如同… | 此處「如」＝例如 |
| 書名 | 《僧祇律》《五百問經》等 | 首次出現可補全名：《摩訶僧祇律》（已補）、《五百問事經》、《大集經·日藏分》、《因緣僧護經》 |

另可考慮在四種僧物名稱下各加一句「體（所有權）／用（受用範圍）」的說明（常住常住：體通十方、用局本處且不可分；十方常住：體通十方、用局本處但可食；現前現前：體用俱局現前；十方現前：未羯磨體通十方，羯磨後用局現前），讀者較能掌握命名的由來。

## 三、體例

1. 開頭 **「盜僧物者。」照抄未譯**，與全篇白話體例不一致（可作「盜取僧眾之物者」）。
2. 「十方常住物。」／「十方現前物。」——**句號應在引號外**：「十方常住物」，…。
3. 「四方僧物」譯成「十方僧物」意思雖同，但與前文專名宜統一（或保留「四方僧物」並註即十方僧物）。

## 四、【105-0002】互用四科

1. **「二明互用」未譯**，宜作「第二、說明（三寶物的）互用」。
2. **「互用」譯為「相互調用」偏中性**；本科是判「挪用三寶物是否成盜」，建議作「互相挪用（流用）」。
3. ★ **「像共寶互」的解釋最需要覆核。** 譯文斷定為「住持三寶（像）與理體三寶（寶）」，但理體三寶（五分法身、滅諦理、證理聖僧）本身並無財物，何來互用？此科緊承「三寶互」而別開，一般律家是就**佛像（形像）之物與舍利塔（真身、寶）之物**互用而言。建議查對元照《資持記》此處釋文後再定，不宜逕下斷語；若一時無法確認，可先直錄「像共寶互」並存疑。
4. 「當分互」宜點明：**同一寶自類之內**的挪用（如佛物與佛物之間）。
5. 「一一物互」譯「個別物品相互調用」太籠統，宜作：**就一一物各別論互用**（如佛物中受用物、施屬物、供養物、獻物彼此不得挪用）。

**小結**：真正要改的是第 1～6 條（尤其「隨即」「開許」「僧人自己」「輕便物件」「隨便損壞」五處），第 7 條與「像共寶互」屬判讀層次，建議查《資持記》確認；其餘多為潤飾與體例問題。
