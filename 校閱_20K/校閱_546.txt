# 校閱材料　第546檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【546-0001】資持記/08a_中二#40
【原文】次科，長廣中。出量有二：前《善見》是乞法量，後《四分》即作房量。一磔二尺，計數可會。〔磔字當從石，張也；謂母指中指相去為磔。〕若不滿六磔，過乞俱無〔應有妨難〕；若十二磔已內，有乞無過，已外過乞俱有；若已得法，但有過量，如是知之。
【譯文】在下一段科判中，討論房舍的長度與寬度。指出尺寸規定有兩種：前面《善見律》所說的是向僧團乞法的標準規格，後面《四分律》所說的則是實際動手蓋房的限量尺寸。一磔手等於兩尺，推算數目就可以吻合相通。〔「磔」字應當從「石」字旁，是張開的意思；也就是大拇指到中指張開時兩端之間的距離叫做一磔手。〕如果不滿六磔手，過量與不乞法兩種罪名都不成立〔但可能會有其他妨礙修行的難處〕；如果在十二磔手以內，只有不乞法之罪而沒有過量之罪，若超過這尺寸則過量與不乞法兩罪同時成立；如果事先已經得到僧團如法批准，建造時就只有超量之罪，應當依此準則來理解判定。

【546-0002】資持記/08a_中二#41
【原文】勘尺量中，初文為三，初通標。僧下，二正引。《僧祇》、《了論》數同。《善見》即三尺。《多論》肘半，二尺七寸也。《五分》是今所取。已下，三出所以。有二：一譯處異，二譯人異。聞見不同，各據所見故。南即楊都，北指京洛；
【譯文】在查考尺寸長度中，第一段文字分為三個部分，首先作通盤標示。「僧」字以下，第二是正式引證文獻。《摩訶僧祇律》與《律二十二明了論》的數目相同。《善見律》則定為三尺。《薩婆多論》定為一肘半，也就是兩尺七寸。《五分律》的標準是當今所採納的。「已」字以下，第三說明出現分歧的原因。主要有兩點：一是翻譯的地理處所不同，二是翻譯的譯者不同。所聽聞見到的尺度各有不同，各自根據自己所見的制度來記錄罷了。南方是指建康楊都，北方是指長安京城洛陽；

【546-0003】資持記/08a_中二#42
【原文】又東晉宋齊梁陳相繼為南朝，後魏後周隋謂之北朝。《僧祇》，東晉佛陀羅與法顯譯；《了論》，陳真諦譯；《善見》，南齊僧伽跋陀羅譯；《多論》失譯，獲本西蜀；《五分》，宋佛陀什共竺道生譯；其間生顯是華人，餘並梵僧；故云生處不同也。矛即鏘戈，盾謂旁牌。〔《韓子》云：宋人有賣矛盾於市，有買矛者云：此矛甚利，所刺皆陷；
【譯文】此外，東晉、劉宋、南齊、蕭梁、南陳相繼統治南方，後魏、後周、隋朝則稱為北朝。《摩訶僧祇律》是東晉時佛陀跋陀羅與法顯大師共同翻譯的；《明了論》是陳朝真諦三藏翻譯的；《善見律》是南齊僧伽跋陀羅翻譯的；《薩婆多論》失落了譯者姓名，是從西蜀之地獲得的梵本；《五分律》是劉宋時佛陀什與竺道生大師共同翻譯的；這幾位譯師當中，道生和法顯是漢地華人，其餘全都是天竺梵僧；所以說譯師出生之處各有不同。矛就是長槍戈器，盾就是防護盾牌。〔《韓非子》記載：宋國有人在市集上賣矛和盾，誇讚自己的矛說：我的矛非常鋒利，什麼東西都能刺穿；

【546-0004】資持記/08a_中二#43
【原文】有買盾者云：此盾極堅，無能陷者；或人謂云：用子之矛，刺子之盾，如之何？因而絕對，今喻語之互違耳。〕次科，判定中，初標示佛量。文見《了論》，《多論》亦同。此下定尺寸，初二句通示不同。疏云：元魏撥亂，文籍焚除，無可依據，故隨世立，是也。
【譯文】又有買盾的人說：這個盾非常堅固，沒有東西能刺穿它。有人對他說：拿你的矛刺你的盾，會怎麼樣呢？賣者因此無言以對。這裡用來比喻諸部律論說法互相違背矛盾。〕下一段科判判定中，起初標示佛陀的尺量標準。文字見於《明了論》，《薩婆多論》也相同。「此」字以下確定尺寸，前兩句通體說明古今不同的緣由。《戒疏》說：元魏平定戰亂之後，典籍毀棄焚燒，度量沒有可依據的標準，所以隨順世俗而建立，就是這個意思。

【546-0005】資持記/08a_中二#44
【原文】而下，明周法可準。律曆即俗中陰陽數歷，定星辰纏度分抄無差故。姬即周姓，周乃國號。故隋下，引兩朝以證。煬帝隋第二主。準古即姬周也。唐朝即神堯受隋禪改號唐國。御宇謂君臨宇宙也。兩用謂周唐並行，至今亦爾。然唐尺但加周尺二寸，故云不違古也。
【譯文】而「以下」，說明周朝的制度最具權威、可作為標準。所謂律曆，是指世俗中推算陰陽節氣的歷法，推算星辰運行度數分毫不差。姬是周朝天子的姓氏，周則是國號。「故隋」以下，引用隋唐兩朝來印證。隋煬帝是隋朝第二任皇帝。依循古制就是指姬周的古法。唐朝就是唐高祖神堯皇帝接受隋朝禪讓改國號為唐。御宇是指君臨天下統治宇宙。兩用是指周制與唐制並行，直到今天依然是如此。然而唐尺只是比周尺增加了兩寸，所以說這並沒有違背古代標準。

【546-0006】資持記/08a_中二#45
【原文】唐令即唐朝律令，魏徵撰，二十卷。周十寸為尺，五斤為秤，三升三合等為斗。尺加二寸，斗秤例增兩倍。準下，示所取。論即多了二論。此方據南洲也。八尺之人，可張一尺；佛身既倍，明知二尺；方彰《五分》所譯無差，故為今取矣。率字，《戒疏》音律，率猶算也。斥濫中，初文，上二句指人。
【譯文】所謂唐令，就是唐朝頒布的國家律令，由魏徵編撰，共二十卷。周朝規定十寸為一尺，五斤為一秤，三升三合等為一斗。唐尺比周尺增加兩寸，斗和秤的計量標準也照比例增加了兩倍。「準」字以下，指明現在所選取的標準。「論」是指《薩婆多論》和《明了論》這兩部論典。這裡所說的身量是依據南瞻部洲的人民而言。身高八尺的常人，手掌張開可達一尺；佛陀的身量既然是一般人的兩倍，由此明顯可知佛的一磔手就是兩尺；這樣才能彰顯《五分律》所翻譯的數值完全無誤，所以現在才將其採納為依據。「率」這個字，在《戒疏》中讀如律法的「律」，率在此就是計算推算的意思。在斥責混亂訛誤的第一段文字中，上兩句是指特定的人。

【546-0007】資持記/08a_中二#46
【原文】未知，謂學之未及。昧教，謂雖學不通。既下，顯濫。道謂諸教異同，俗則朝代差互。未能通會，故二俱不達。次科舉證有四，初據時用；上二句敘國法大同。文謂文章，軌即制度。及下明尺秤多別。五種者，舊云：南吳尺〔短周二寸〕，姬周尺〔十寸為定〕，唐尺〔加周二寸，尺二為尺。〕，山東尺〔加唐二寸，尺四為尺。
【譯文】「未知」，是指學問功夫還沒下到那裡。「昧教」，是指雖然學過卻無法通達明瞭。「既」字以下，顯露其錯亂的根本原因。「道」是指佛教各部派經教之間的同異，「俗」則是指歷代朝廷制度的交替更迭。由於無法融會貫通，所以對佛法和世俗典章制度都無法透徹通達。下一段科判中舉出四項證據：第一是依據當時通行的制度；上兩句敘述國家法度大致相同統一。「文」是指法令文書，「軌」是指車同軌等典章制度。「及」字以下說明度量衡的尺秤存在許多差別。所謂五種尺，過去的說法是：南吳尺〔比周尺短兩寸〕、姬周尺〔以十寸為定準〕、唐尺〔比周尺多兩寸，以一尺兩寸為一尺〕、山東尺〔比唐尺多兩寸，以一尺四寸為一尺〕、

【546-0008】資持記/08a_中二#47
【原文】潞州羅柯尺〔加山東二寸，尺六為尺。〕；國家不禁，致此多別。至於公用，還準周尺。故云必以等。衡謂秤之斤兩，量即尺之分寸。〔今朝私用周尺，公用唐尺。〕此下，推其本始。通閻浮者，顯是輪王之舊法耳。乃下，準鉢量，以律。斗量，正用姬周；
【譯文】潞州羅柯尺〔比山東尺多兩寸，以一尺六寸為一尺〕；因為國家沒有嚴格禁絕，才造成了這許多雜亂的差別。但是到了官方法定的公用場合，一律還是以周尺為準則。所以說「必定以……為準」等等。「衡」是指秤的斤兩輕重，「量」是指尺的長短分寸。〔現今朝廷私下多用周尺，官方公事則採用唐尺。〕「此」字以下，追溯這些度量衡的原始由來。通行於整個閻浮提世界，顯然是轉輪聖王所留下來的古老法則。「乃」字以下，依據僧缽的容量標準，對照律典的記載。律中計量缽的大小的斗量，正巧採用姬周的周制；

【546-0009】資持記/08a_中二#48
