# 義鈔缺口與長段定稿

## 結論

義鈔 25 個缺口，不是沒有翻譯；大部分在 `_長段/_定稿` 裡。

## 直接證據

缺口 G01 原文：

```text
此鈔傳世，其來久矣。或為之訓解，或口以傳授……
```

對應長段定稿：

```text
測試/重譯/義鈔/_長段/_定稿/00_卷首_0004.txt
```

開頭：

```text
這部鈔書流傳於世，由來已經很久了。有人為它作文字訓解，有人以口頭講授相傳……
```

所以 G01 不是缺譯，是長段定稿沒有接回 `定稿/yichao.jsonl`。

## 為什麼對不上

`_長段/_定稿` 是**整段長段的譯文**，不是按 25 個缺口切好的。

例如：

```text
00_卷首_0004.txt
```

是一整段長段譯文，包含 G01，也可能包含前後文；不能直接當 G01 一個 pair 插入。

## 目前狀態

```text
義鈔缺口：25
長段定稿：56 檔
```

長段定稿有譯文，但：

- 沒有按 G 缺口切
- 沒有寫進 `定稿/yichao.jsonl`
- 直接套會造成大段覆蓋小缺口
