# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【423-0012】03_業疏/02a_卷一之二#70
【原文】問：如說恣等眾法通下，人位分三，據緣應異，何者是耶？答：有多異。一人有少多；二對法三別；三約界通局，謂僧局別通也；四欲無欲異，僧秉不開，唯在結界，別人俱閉故；五別相異，僧中具三別，若對眾多人則無不與欲別，若對一人但有應來不來別，所以可知
【譯文】問：例如說戒、自恣等大眾法通融降下行辦，人數的位階分為三種，依據所具的因緣應當有所差異，具體有哪些呢？ 答：有許多差異。第一是人數有多寡的差別；第二是對應的法有三種差別；第三是依結界而言有局限與通融的差別，也就是僧眾大眾法局限於當界，個別之人作法則通於兩界；第四是有無「說欲」的差別，大眾僧秉法時原則上不開許免除說欲（唯有結界羯磨絕對不開許與欲），個別之人作法時則完全閉塞不開許與欲；第五是個別相狀的差別，在大眾僧中具備三種個別差別相，若面對眾多人則沒有「不與欲」的差別，若面對一人則只有「應來而不來」的差別，其原由由此可知。

【423-0013】03_業疏/02a_卷一之二#71
【原文】三中，問意欲簡前通，使無濫故，通下對念，更兼本位，故云分三。答中五異：初二可解；三中僧局作法，別通兩界；四中說欲，僧唯不開結界，則顯餘法通開；五中僧具可知，眾多人中對首無欲，故但有二，心念無訶，故唯有一，將別對人以明有無，故兩云「若對
【譯文】在第三項中，提問的用意是想簡別前面的相通之處，使法相不致混淆失當，大眾法通融降至對首與心念，再加上原本的大眾位階，所以說分為三種。回答當中有五種相異：前兩種容易理解；第三種是僧團大眾局限在當界作法，個別之人則通於界內界外兩界；第四種是說欲受欲，大眾僧只有在結界時絕對不開許與欲，這就顯明其餘大眾法皆普遍開許與欲；第五種是大眾僧具足三種差別相顯而易見，在眾多人當中的對首法沒有與欲這回事，所以只有兩種差別相，心念法沒有口言反對（訶阻）這回事，所以只有一種差別相，這是將個別之人對照大眾以說明有無，所以兩次說到「若對……」。

【423-0015】03_業疏/02a_卷一之二#73
【原文】僧得被尼事，但有三：受戒、半月、出罪也。約法分齊，則一白問難、三番白四，自餘不行。其教授、自恣，非無互差互往，然是各行眾法，至彼此部，無面對作，不同前三兩部通秉，故文云「二十眾受」也。《五分》云：「四十人出罪，減一不成」等。然上局僧唱，故約一相為言耳。律云：「僧不得為尼作羯磨令受，誦已，當部作之
【譯文】比丘僧得以加被比丘尼的僧事，只有三種：受具足戒、半月摩那埵（懺殘罪）、以及出罪。就法的範圍界限而言，只有一次單白問難、三次白四羯磨，其餘的法則不能由比丘僧直接為尼舉行。至於派遣教授、自恣，並非沒有彼此互差、互往來之事，然而那是在各部僧中分別舉行大眾法，前往對方所屬部派時，並不是面對面直接作法羯磨，不同於前面那三種是兩部僧共同主持秉持，所以律文說「二十眾（僧十人、尼十人）前受具足戒」。《五分律》說：「四十人（僧二十人、尼二十人）為尼出罪，少一人都不能成就」等。然而上面是局限於比丘僧作唱導宣告而言，所以只是就單一相狀來說罷了。律文說：「大僧不得為尼僧作羯磨（指說戒等），若尼不解誦戒，開許令其至大僧中受學誦習，誦習通達之後，回歸尼寺由尼僧本部自行作法。」

【423-0016】03_業疏/02a_卷一之二#74
【原文】僧尼中初僧被尼為三：初正明尼從僧受戒，對問一白，正受白四；又依僧悔殘，不行覆藏，但有半月摩那埵并正出罪兩番白四，共四法耳。「其」下簡異說戒、教授、自恣、請悔，尼眾差尼來請，僧眾差僧往教，竝用白二，恐謂同前，故須簡別。下引二文證前同秉，《五分》但明出罪，若論半月即須八人。「然」下重示，謂上四法制須僧秉，據此一相言得對尼，非謂餘法得同尼秉，文證可知。當部即本眾
【譯文】在僧尼互作中，首先比丘僧加被比丘尼分為三個部分：第一、正式說明比丘尼依從比丘僧受具足戒，面對面詢問遮難是一次單白，正式授戒是一次白四羯磨；又比丘尼依從比丘僧懺悔僧殘罪，不行覆藏法，只有半月行摩那埵以及正式出罪這兩次白四羯磨，總共只有這四種法。「其」字以下，簡別有別於說戒、教授、自恣、請悔等法，比丘尼眾差派尼僧前來迎請，比丘僧眾差派僧人前往教誡，都是採用白二羯磨，唯恐人們以為與前面相同，所以必須加以簡別。下文引述兩段律文證明前面是由兩部僧共同秉持，《五分律》只說明出罪，若論及半月摩那埵則需要八人。「然」字以下重新提示，是指上面四種法規定必須由比丘僧主持秉持，依據這一個相狀而說可以面對比丘尼作法，並不是說其餘僧法也可以與尼眾共同秉持，律文證據顯而易見。「當部」指的就是比丘尼原本的自眾。

【423-0017】03_業疏/02a_卷一之二#75
【原文】十誦》云：「如受戒等三僧對尼作，不禮、不語、不敬此三，尼遙為僧作。」又約《四分》捨教授法，僧為尼作不禮羯磨，尼為僧作
【譯文】《十誦律》說：「如同受戒等三種法是由比丘僧對比丘尼作，不禮敬、不交談、不恭敬這三種法，則是比丘尼遙對比丘僧而作。」又依照《四分律》，捨教授法是由比丘僧對比丘尼作，不禮羯磨則是由比丘尼對比丘僧作。

【423-0018】03_業疏/02a_卷一之二#76
【原文】次互作中，《十誦》僧對尼三同上所列。尼為僧中，由僧乖行，尼不禮等，則違八敬作法遙被，不禮無過。《四分》中尼眾非法，僧不往教，作法遙捨，《十誦》無此；又此律但有不禮，則無餘二
【譯文】其次在互作當中，《十誦律》比丘僧對比丘尼的三種法與上面所列相同。在比丘尼為比丘僧作法當中，由於僧人行為乖違，比丘尼施加不予禮拜等羯磨，便是在違背八敬法的情形下作法遙相加被，此時不予禮拜便沒有過失。《四分律》中比丘尼眾若有非法之行，比丘僧便不再前往教誡，作法遙相捨棄，在《十誦律》中則沒有這項規定；又本《四分律》中只有「不禮」一項，沒有其餘兩項（不語、不敬）。

【原文】解云：但據四人，尚通秉法，何況餘三？又人解云：四人作務，通秉眾法，以體成僧故也。如說戒、滅諍、形法二同、觸惱諸制，謂單白也；差人被緣、受日處分，謂秉日（）二也；七法治人、諫證等法，謂秉白四也。故法雖多，以二攝盡，謂說戒、羯磨，四人通持，意可見也
