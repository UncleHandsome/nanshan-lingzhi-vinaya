# 校閱材料　第578檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【578-0001】資持記/10b_中三下#22
【原文】若不盲聾〔互闕吉羅，俱闕非證。〕，或從前過不住〔多人行處〕，或病發到地，力勢所持，命梵難緣等並開。四十四。〔迦留陀夷念前戒開手及戶處坐，即與女人在戶扉後坐，共語招譏故制。〕若準《戒本》，亦標食家，乃是因前而制。至於論犯，不必假夫，故略之耳。緣中。
【譯文】或者作伴者並非眼盲耳聾〔缺少其中一樣結突吉羅罪，兩樣都缺失則不具備作證防嫌的資格〕，或者有人從門前走過而不作停留〔指眾人頻繁行走的過道通道〕，或者比丘突發重病倒地、被強大勢力所拘禁威逼、面臨生命危難或梵行危機等不可抗力的因緣，全都予以開許。第四十四條戒。〔迦留陀夷比丘想到前一條戒開許伸手可及門扉之處可以共坐，便與婦人坐在門扉後方，共同私語招來譏嫌，因而制定此戒。〕如果依照《戒本》，此處也標明是「食家（有男女欲樂之家）」，這純粹是承接前一戒的因緣而制定。至於論斷實質犯戒，則不一定非要有丈夫在場不可，所以文句予以省略。在犯緣中。

【578-0002】資持記/10b_中三下#23
【原文】屏處者，律云若樹牆壁籬柵，若衣及餘物障。釋第三，《多論》。約戶內外，次列三相。今時入聚，須帶淨人；或對女坐，勿使離身，可得免過；不爾，如論結犯。《僧祇》，初簡非證。七人三類，初三親囑；小淨人嬰兒無解，睡狂無知，皆非可畏。大字讀為太。二不定及強坐中已釋，故注顯重重之意。
【譯文】所謂「隱蔽之處（屏處）」，律典記載是指樹木、牆壁、籬笆、柵欄，或者是布簾以及其餘器物之遮蔽。解釋第三項，《多論》是依據門戶的室內與室外來區分，接著列出了三種相狀。如今這個時代比丘入於聚落村坊，必須帶領淨人相隨；或者面對女人而坐時，切勿讓淨人離身，如此才可以免除過咎；否則的話，就會如論典所定而結犯戒罪。《僧祇律》，開頭先簡別不具備作證資格的人。七種人分為三類，前三種是親自囑託；幼小的淨人與嬰兒毫無是非理解力，沉睡者與狂病者心智昏蒙無知，這些都不是令人有所忌憚的人。文中的「大」字應讀為「太」字。在二不定法以及強行共坐的戒文中已經作過解釋，所以注文特別標明此處是重疊防範的深刻用意。

【578-0003】資持記/10b_中三下#24
【原文】若淨人下，明假緣成證。三相可分。不犯並同前引。四十五。〔亦因迦留陀夷與女露坐招譏故制。〕列緣。第二，注釋露處；由此二屏，皆無障故。前云塵霧暗黑名見屏，常語不聞聲名聞屏。犯相中，《十誦》初約身動止。相去下，二就處近遠。罪相遞減，譏過淺深故。一尋八尺，即伸手內。點前中。
【譯文】「若淨人」以下，說明憑藉外在因緣而成立作證除嫌。這三種相狀可以清楚分辨。不犯的各條開緣，全都與前面所引用的規定相同。第四十五條戒。〔這也是因為迦留陀夷比丘與女人在露天無遮之處共坐招致譏嫌，因而制定此戒。〕列舉犯緣。第二項，注文解釋何謂「露天之處」；這是由於這兩種屏障，全都沒有阻隔之故。前文所說的塵霧瀰漫暗黑看不清楚稱為「見屏」，正常說話卻聽不見聲音稱為「聞屏」。在判定犯戒相狀中，《十誦律》開頭是依據身體的動態與停留來判定。「相去」以下，第二是依據距離的遠近來論斷。罪責相狀依次減輕，是因為招致世人譏嫌過失的深淺程度不同。一尋為八尺，也就是指手臂向外伸展的距離之內。在點勘前文處。

【578-0004】資持記/10b_中三下#25
【原文】前引《十誦》，但云不犯，恐前遺筆，寄之點之；或別有意，來者更詳。注戒指不犯同前。四十六。〔佛在舍衛，跋難陀與比丘鬪，結恨在心；便誘至城中無食處，知還寺時過，便驅出，令彼不得食疲乏因制。〕犯緣。第三，無諸緣者，即下不犯破戒見命梵等也。不犯為三。初先與後遣；
【譯文】前文引用《十誦律》，僅僅說道「不犯」，恐怕是前面傳抄時遺漏了字句，故而寄託於此點出備查；或者其中另有深意，有待後來的學者進一步詳加考究。注文所指的戒律，其不犯的開緣與前述完全相同。第四十六條戒。〔佛陀在舍衛國時，跋難陀比丘與另一位比丘爭鬥，心中懷恨結怨；便誘騙那人到城中沒有飲食的地方，算準了返回寺院的用餐時間已過，便將他驅逐出門，使那人無法進食、疲困匱乏，因而制定此戒。〕犯戒因緣。第三項，所謂「沒有種種特殊因緣」，就是指下文不犯條例中所說的破戒、起邪見、危及生命與梵行等事故。不犯的情況分為三類。首先是先給予食物然後才遣送離開；

【578-0005】資持記/10b_中三下#26
【原文】若病下二緣，先遣後送；若破戒等，不與而遣。文令方便，反明嫌心非無小過。四十七。〔佛在釋翅瘦，施主請僧給藥；六群求難得藥，彼為市求，便呵罵之，因制。〕戒名。四月，且從緣說，準下《僧祇》一月半月。犯緣。
【譯文】「若病」以下的兩種開緣，是先遣走後續再派人送去飲食；如果是因為對方破戒等嚴重過患，則可以直接不給食物而驅逐離開。經文中要求應當善巧方便，反向說明如果出於嫌惡懷恨之心驅趕他人，也並非完全沒有微細的小過。第四十七條戒。〔佛陀在釋翅瘦國時，施主請僧團供給醫藥；六群比丘索求難得的珍罕藥物，施主四處入市求購，比丘反倒呵斥斥罵他，因而制定此戒。〕戒律名稱。所謂「四個月」，暫且是順隨當前的起因因緣來說，若依照下文《僧祇律》所載，亦有一個月或半個月的期限。犯戒因緣。

【578-0006】資持記/10b_中三下#27
【原文】第一，《十誦》四藥通犯，過受四月時食者提，索餘事吉〔謂非四藥〕；四月過已，求七日終身〔即盡形也〕，亦提；非時藥吉。五無緣者，即下四緣。釋中。《僧祇》三時，各有四月，通有過限。不犯中。
【譯文】第一項，《十誦律》規定受持四種藥物都通於犯戒，如果超過期限而受取四個月日常當食的時藥者結提罪，索取藥物以外的其餘物品結吉羅罪〔指非屬四種藥物之物〕；四個月期限過後，若再去索求七日藥或終身藥〔也就是盡形壽藥〕，同樣結提罪；索求非時藥則結吉羅罪。第五項所謂無特殊因緣，就是指下文列出的四種開許因緣。在解釋條文中。《僧祇律》指出一年有三時，每一時各有四個月，全部都有可能發生超過受藥期限的情形。在不犯的條文中。

【578-0007】資持記/10b_中三下#28
【原文】四緣者，一常請〔彼言我常與藥也〕，二更請〔斷已後復更請與之〕，三分請〔持至僧伽藍分與之〕，四盡形請〔我當盡形與藥〕。疏云：常與盡形有何別者？就能所以分也。〔常請約能施，盡形約所施。〕示犯中。猶同昔義，準疏反之。彼云：此戒索輕，過限重也；
【譯文】四種特許因緣為：第一是「常請」〔施主明言我將長年固定供給醫藥〕，第二是「更請」〔供給中斷之後施主又重新再次邀請供給〕，第三是「分請」〔施主將藥物直接送到僧團寺院中平均分配分給眾人〕，第四是「盡形請」〔施主發願說我將盡形壽終身供給醫藥〕。《戒疏》說道：長請與盡形請究竟有何差別？這是從施予者的主動能動性與被動受用性來作區分的。〔常請著重在能布施之人的常態發心，盡形請著重在受施之人的身命終盡。〕在標示犯戒的情節中。如今的看法仍然依循往昔的舊義，若依照《戒疏》的評判則剛好相反。彼疏說道：這條戒本來是索求藥物結罪較輕，但如果超逾了施主承諾的期限，結罪反而加重；

【578-0008】資持記/10b_中三下#29
【原文】所以然者：先有好心，四月與藥；期限已滿，供養心息；過受置惱，敗損處深；又承前受請，人喜過日故重。餘不具引。四十八。〔佛在舍衛，人民反叛，王領軍征伐，六軍觀陣，匿王不悅，故制。〕制意中。初明住持；二是化他；三成自行，由觀兵鬪，凶暴無慈，失諸善利。

【578-0009】資持記/10b_中三下#30
【原文】初緣，律中下至一馬一車一步卒皆犯。第三，即下被請道斷等開。釋中，初科，《四分》初明犯。上二句釋軍陳。戲謂遊驛教習之時，真謂正鬪。律作若戲若鬪，其相可解。若軍下，次明相值。方便謂雖下道，偷目顧眄。若被下，明不犯。律列多種，謂若有事往；若下道避，惡獸賊難，大水漲，命梵等，不下道無犯。
【譯文】第一條犯緣，律典中規定哪怕低微至僅看一匹戰馬、一輛戰車、一名步卒，全都算犯戒。第三項，就是指下文提到的被國王差遣請託、道路阻斷受阻等開許之緣。在解釋文句中，第一科《四分律》開頭先說明犯戒的行為。上面兩句解釋何謂「軍陣」。「戲」是指平常巡行操演、教習戰陣的時候，「真」是指雙方兩軍真正交戰搏鬥之際。律典原文寫作「若戲若鬥」，其行相十分淺顯易懂。「若軍」以下，次一步說明在路途上與軍隊相遇的情形。「方便」是指雖然走下道路迴避，卻依然偷眼斜視瞻顧。隨後說明不犯的情形。律典列舉了許多種，例如若有公務要事前去；或者若要走下道路避讓，卻遇上凶惡野獸、盜賊劫難、江河大水暴漲，或是危及生命與梵行等災難時，不離開道路直接穿行不算犯戒。

【578-0010】資持記/10b_中三下#31
【原文】釋二中，《僧祇》，初明逢軍。準意斷犯。若天下，明非陣。三相皆輕。天王即國君儀伏。畜鬪人爭，皆相因而制。《十誦》。由覩相殘，易生厭離。雖有此文，世多濫倚；自非實行，往觀皆犯。四十九。〔六群有緣至軍中宿，招譏因制。〕初緣，《多論》四意，上三利他，四即相利。
【譯文】在解釋第二科中，《僧祇律》開頭說明路遇軍陣的情節。這是依照內心的動機來裁斷是否犯戒。「若天」以下，說明並非實戰軍陣的情況。這三種相狀所結的罪都較輕。「天王」是指一國之君出巡時的儀仗護衛。觀看牲畜相鬥或眾人爭鬥，全都是以此戒的意旨為因由而比照制戒。《十誦律》說：由於目睹生靈自相殘殺，內心容易生起厭離生死之意。雖然律典有這段文句，但世間修行人大多以此為藉口而浮濫依傍；如果自己並非真正具備純熟的道行，前去觀看搏殺就全屬犯戒。第四十九條戒。〔六群比丘因為有特定因緣而前往軍隊營地中留宿，招致世人譏嫌，因而制定此戒。〕第一條犯緣，《多論》列出了四種原由，前面三種是為了利益他人，第四種是為了彼此互利。

【原文】《五分》。緣同《四分》，彼云娑竭陀比丘，梵音少異。初緣起。舁音餘，對舉也。佛集下，立制，初示過，上二句無恭敬。下二句無威德。因下，正制。《多論》，初句通標制重。能下，舉事別釋有三。初成逆業，破僧立佛，醉者人必不信，所以除之。二能破戒。一切者，總收五八十具；
【譯文】《五分律》的緣起情節與《四分律》相同，彼處稱為娑竭陀比丘，只是梵文音譯稍有差異罷了。開頭說明事件的發端。「舁」字音同「餘」，意思是兩人對抬擔架。佛陀召集大眾以下，正式確立戒法，開頭先指示其過失，上兩句指其毫無對聖教的恭敬之心，下兩句指其徹底喪失了沙門應有的威儀德望。「因」字以下，正式制定戒條。《多論》中，第一句通體標明這條戒律制定得極為嚴格重大。「能」字以下，列舉具體事例分別解釋，共有三項。第一是能成就五逆重罪，如破僧立佛等，但醉酒之人的狂言他人必定不會相信，所以把破僧這一逆除外。第二是能毀破清淨戒律。所謂「一切」，是總體收納了五戒、八戒、十戒以及具足戒；

【原文】具三同酒，必不具者，如下甜酢，但犯吉羅。若酒下，明和食。準《注戒》，煮字下多酒字。上明犯重。若甜下，明結輕。律作甜味酒、錯味酒，今文合之。《十誦》。五種皆墮，並取能醉；《四分》結吉，應非醉者。𮡆即酒滓。食麴能醉，於義難顯，故引《多論》決之。
