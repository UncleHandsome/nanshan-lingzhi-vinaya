# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【195-0001】03_業疏/18b_卷四之一#120
【原文】二體中初簡濫。「貞」謂志堅，「素」謂行潔。寶、木、石三，皆不聽用。按《本起經》：佛念往佛以鉢受食時，四天王往頗那山取石為鉢，各以奉佛，佛累於左手，以右手按之，合為一鉢，四際分明。所以比丘不聽者，恐濫上故。又準《智論》，石鉢體重，慈愍諸比丘故；又云細石難得，麤者受膩故。問：比丘三衣許濫佛者？答：鉢但體殊，衣唯量別。「但下」，顯體離濫易得，具二義故
【譯文】在第二項體質中，首先簡別混濫。「貞」是指志向堅定，「素」是指操行純潔。寶器、木質、石質這三種，都禁止使用。按《修行本起經》所說：佛陀憶念過去諸佛用鉢受食之時，四大天王便前往頗那山取石化作石鉢，各自奉獻給佛，佛陀將四鉢重疊在左手上，以右手一按，合成了一鉢，四個邊際痕跡分明。比丘之所以不許使用石鉢，是唯恐混濫於佛陀之尊。又依《大智度論》，石鉢體質沉重，佛慈愍諸比丘體力之故；又說細緻的石頭難以尋得，粗石又容易吸納油膩。有人問：比丘的三衣允許與佛相同，為何鉢不可？回答說：鉢是體質質地不同，而三衣只是尺寸度量有別。「但用泥鐵」以下，彰顯泥鐵二鉢之體能遠離混濫且容易求得，具足這兩種義理。

【195-0002】03_業疏/18b_卷四之一#121
【原文】三明色中，應熏作色者，以諸餘色並同俗故，受膩易脫，數有經營，妨道亂業。制用熏持，唯被道眾。佛廣說之，唯熏鉢法非俗常也。今依律用，隨作竝成，但鐵熏一者多剝落耳。西來鐵熏由牢固者，解熏法也。世有掍油諸鉢，體相乃同，無奈色別，不成受也
【譯文】在第三說明顏色中，應當熏染成色，是因為其餘種種顏色都同於世俗之物，且易吸附油膩、容易脫色，頻繁清洗打理，會妨礙修道、荒亂課業。制定用熏色來加持，唯獨行於出家道眾。佛陀對此詳加宣說，唯獨這熏鉢之法不是世俗尋常所有的。如今依照律典使用，隨作都能成就，只是鐵鉢熏染一次的多半容易剝落。西域傳來的鐵鉢熏色之所以堅固，是因為他們懂得熏治之法。世間有塗油燒釉的各種鉢（瓷器等），外形體相雖然相似，無奈顏色有別，不能加法成就受持。

【195-0003】03_業疏/18b_卷四之一#122
【原文】三色中初敘制意，有三：一異俗，二不受膩，三不廢業。「佛廣說」者，見本律雜犍度。彼云：時瓶沙王布施比丘鐵鉢，比丘不受。佛言聽畜，乃至云畜鉢不熏生垢患臭，佛言應熏。彼不知云何熏，聽作爐若釜若瓨，種種泥塗，以杏子、麻子泥裹，以灰平地作熏鉢場，安支以鉢置上，鉢爐覆上，以灰壅四邊，手按令堅，若以新牛屎壅四邊燒之，當作如是熏。「今下」，示熏法。依律即黑、赤兩色。《僧祇》孔雀咽、鴿色，即青翠色。《善見》瓦鉢貫左肩青色是也。鐵堅不入，故色易剝。準《善見》，鐵鉢五熏，土鉢二熏，則知西竺解熏法也。「世下」，斥濫。「掍油」似今磁器
【譯文】在第三項顏色中，首先敘述制定義意，共有三點：一是不同於世俗，二是不吸受油膩，三是不荒廢修業。「佛廣說」這句話，見於本律〈雜犍度〉。那裡說：當時頻婆娑羅王布施比丘鐵鉢，比丘不敢接受。佛說聽許蓄持，乃至說蓄鉢若不熏製就會生垢生臭，佛說應當熏製。比丘不知該如何熏製，佛聽許造作爐具、或釜、或陶罐，塗抹各種泥料，用杏仁、胡麻的果泥塗裹，用草木灰平整地面作為熏鉢場地，安置支架把鉢放在上面，用鉢爐反覆覆蓋在上面，用草木灰壅塞四邊，用手按壓使其堅實，或者用新鮮乾牛糞壅蓋四邊進行燒烤，應當如此進行熏製。「今依律」以下，指示熏色之法。依照本律就是黑、赤兩種顏色。《摩訶僧祇律》說是孔雀咽喉色、鴿色，也就是青翠深青之色。《善見論》說瓦鉢染作如貫穿左肩的青色，即是此類。鐵質堅硬藥汁不易滲入，所以顏色容易剝落。依準《善見論》，鐵鉢要熏五次，土瓦鉢熏兩次，由此可知天竺僧人通達熏鉢之法。「世有」以下，斥責混濫。「掍油」類似現在的瓷器釉彩。

【原文】四鉢量中，如《多論》解，種種不定，或以稱飯斤兩為法。《四分》、他部多說：上鉢受三斗，下者斗半

【195-0005】03_業疏/18b_卷四之一#124
【原文】四明量引教中初文。《多論》自云：論師種種異說，以一義為正，謂一鉢他受十五兩飯，上鉢受三鉢他飯、一鉢他羮、餘可食者半，即秦三斗。諸部多說，如鈔廣引
【譯文】在第四說明容量引證教典中，這是第一段文。《薩婆多論》自己說：論師們有種種不同的說法，而以其中一種義理為正解，即一個「鉢他」（容量單位）盛受十五兩米飯，大鉢能受三鉢他的飯、一鉢他的羹湯、其餘可食之物半鉢他，相當於秦制的三斗。諸部律論的多數說法，如《行事鈔》中詳細引述。

【195-0006】03_業疏/18b_卷四之一#125
【原文】律是姚秦時翻，猶行晉法，故唐《雜令》云：斗者，三斗為之。故知姬周本制，圭、抄為本，如是乘之
