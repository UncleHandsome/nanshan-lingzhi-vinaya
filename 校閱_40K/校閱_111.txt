# 校閱材料　第111檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【111-0001】02_戒疏/06a_卷二上之二#114
【原文】【疏】三、明捨善已未者。
【譯文】【疏文】第三、辨明捨棄的善法究竟是已生還是未生。

【111-0002】02_戒疏/06a_卷二上之二#115
【原文】【疏】問：「今捨戒者，為捨已生隨行為因之業？為捨初願本受無作體邪？」
【譯文】【疏文】有人提問：「現在捨戒的人，所捨掉的究竟是過去已經生起、作為未來感果之因的隨行善業呢？還是捨棄了最初發願時本來所領受的無作戒體呢？」

【111-0003】02_戒疏/06a_卷二上之二#116
【原文】【疏】答：「已生為因，不可捨也。得聖無漏，方傾善習。今所捨者，止是本體，更不相續。故《雜心》云：『言捨戒者，戒身種類滅也。』」
【譯文】【疏文】回答：「過去已經造作生起、成為感果之因的善業，是絕對不可能捨掉的。必須一直修行證得聖者無漏智慧時，才能徹底傾覆拔除這種有漏善業的習氣牽引。現在捨戒所捨掉的，只不過是當初所納受的無作戒體本體，使其在未來不再相續延續罷了。所以《雜心論》說：『所謂捨戒，是指防非止惡的戒身相續種類消滅了。』」

【111-0004】02_戒疏/06a_卷二上之二#117
【原文】【記】三中。初標科。「善」，謂隨中二持之行。未捨之前，所有持行，名「已生善」；後未修者，名「未生善」。今明捨戒，為捨何者？
【譯文】【記文】在第三門中，首先標明科判名稱。「善」是指隨中二持之行。在捨戒之前，所有實踐過的持戒行為稱為「已生善」；日後尚未修持的善行稱為「未生善」。現在探討捨戒，究竟是捨掉哪一個？

【111-0005】02_戒疏/06a_卷二上之二#118
【原文】【記】問中乃約「行」、「願」兩審。答文方見「已」、「未」存亡。
【譯文】【記文】在提問的段落中，是分別從「隨行」與「受願」兩個面向來審查反問。透過回答的文字，才能看清「已生善」與「未生善」究竟是保存還是喪失。

【111-0006】02_戒疏/06a_卷二上之二#119
【原文】【記】答中。初答因業不失。結業在心，行功不滅，故不可捨。及證初果，無漏智力，達罪福性，漏業方傾。「今」下，次明無作體失。「本體」，即無作。「不相續」者，失未生善也。「故」下，引證。「戒身」，即受體無作。「種類」，即相續善行。二皆云「滅」，證上可知。
【譯文】【記文】在回答的段落中，首先回答善因之業絕不喪失。過去造作的業力銘刻在心識中，修行的功德不會消滅，所以不能捨棄。直到證得初果以上，憑藉著無漏智慧的力量通達罪福的虛妄空性，有漏的業習才能徹底被拔除。「今」字以下，接著說明無作戒體徹底喪失。「本體」就是指無作戒體。「不相續」是指喪失了未生起的善法。「故」字以下引經論為證。「戒身」就是指受戒時所得的無作體；「種類」就是指依體而起、相續不斷的善行。經論都宣告這兩者「滅」，用以證明上面的論點是確鑿無疑的。

【111-0007】02_戒疏/06a_卷二上之二#120
【原文】【疏】四、明具緣明捨，有五。
【譯文】【疏文】第四、說明具備捨戒的緣起條件，共有五項。

【111-0008】02_戒疏/06a_卷二上之二#121
【原文】【記】四中。戒假緣成，還從緣謝。受、捨各五，相反可尋。
【譯文】【記文】在第四門中。戒體既然是憑藉因緣而成就，自然也是順著因緣而謝滅散失。受戒與捨戒各需要五種緣起，彼此相反相對，可以相互對照尋思。

【111-0009】02_戒疏/06a_卷二上之二#122
【原文】【疏】初、體是比丘住自性者。
【譯文】【疏文】第一、本人身分必須是比丘，且具足本來所受的戒體（住自性者）。

【111-0010】02_戒疏/06a_卷二上之二#123
【原文】【記】初、云「住自性」者，即具本受體也。
【譯文】【記文】第一項說「住自性」，就是指依然具備當初所領受的本來戒體。

【111-0011】02_戒疏/06a_卷二上之二#124
【原文】【疏】二、所對人境。如《多論》云：「若無出家人，隨得白衣、外道，相解者成。」
【譯文】【疏文】第二、所面對的人境。如《薩婆多論》說：「如果身邊沒有出家人，只要隨緣找到任何在家人、外道，只要對方能完全聽懂你的話，捨戒就算成就。」

【111-0012】02_戒疏/06a_卷二上之二#125
【原文】【記】二、明所對，開教從緩，不必本眾。
【譯文】【記文】第二項說明所面對的對象，由於開許教法採取寬鬆原則，所以不一定非要是僧團內部的人。

【111-0013】02_戒疏/06a_卷二上之二#126
【原文】【疏】三、有捨心。謂有欣猒心、作捨心、決定心、住自性心、久思心、歡喜心、自有心、寂靜心。反上八心，則不成捨。
【譯文】【疏文】第三、具備真正的捨戒之心。也就是必須具備欣厭心、作意捨戒心、決定心、安住自性心、長久思量心、歡喜心、自主心、寂靜專一心。若違背這八種心態，捨戒就不能成立。

【111-0014】02_戒疏/06a_卷二上之二#127
【原文】【記】三中。「八心」，注云「意欲在家、念父母」等，又云「不樂梵行，猒比丘法」，即忻俗猒道。「作捨心」，謂欲棄捨也。「決定」者，非進退也。「住自性」者，自知是比丘，非狂亂也。「久思」者，非朝夕也。「歡喜」者，無所悔也。「自有」，非他逼也。「寂靜」者，心專一也。
【譯文】【記文】在第三項中。所謂「八種心」，戒本注解說「心中想要返家、掛念父母」等，又說「不樂於清淨梵行，厭倦比丘戒法」，這就是欣慕世俗而厭離道法。「作捨心」是指主動想要放棄捨離。「決定心」是指心志堅定不再猶豫退縮。「住自性」是指心智自知是比丘身分，並非處於瘋狂昏亂。「久思」是指經過長期審慎思量，並非一時衝動。「歡喜」是指徹底自願毫無悔恨。「自有」是指全憑自願而非遭受外力逼迫。「寂靜」是指精神專注意志純一。

【111-0015】02_戒疏/06a_卷二上之二#128
【原文】【疏】四、心境相當。如《律》：「中邊不領，前人不解，並不成捨。」
【譯文】【疏文】第四、心意與外在對境互相契合相通。正如《律藏》所規定：「中印度人與邊地人言語不通而無法領會、對方沒有聽懂你說什麼，全都不算成就捨戒。」

【111-0016】02_戒疏/06a_卷二上之二#129
【原文】【記】四中。指《律》，即如注引。
【譯文】【記文】在第四項中，所指涉的《律藏》內容，就如同戒本注解中所引用的文句。

【111-0017】02_戒疏/06a_卷二上之二#130
【原文】【疏】五、一說便成。《多》云：「『受捨相對，理宜相準。何故難易不同者？』答：『相違對故。一、求增上法，如上高山，多緣多力；捨戒退道，如高墜下，故不須多。二、不生前惱，若制緣多，便言「佛多緣惱，受須多人，捨何須也？」三、受如入海採寶，捨如失財，王、賊、水、火，須臾蕩盡。四、受容預心，捨對境情逼。喜帶戒行非，一語開成捨，尚不依行，況多緣也？』」
【譯文】【疏文】第五、只要開口宣告一次就算成就。《薩婆多論》問道：「『受戒與捨戒是相對應的事，理應在規矩上相互比照一致。為什麼受戒那麼難，捨戒卻那麼容易呢？』回答：『因為這兩者的性質是完全背道而馳的：第一、受戒是為了求取殊勝增上的戒法，就像攀登高山一樣，必須仰賴許多因緣與極大力量；捨戒則是道心退墮，就像從萬丈高處跌落下來，所以根本不需要繁多的因緣。第二、為了不讓眾生生起障礙與煩惱，如果把捨戒的因緣規定得繁複嚴苛，人們就會抱怨說「佛陀訂的規矩真是煩人，受戒需要那麼多人作法，連捨戒也要搞得這麼麻煩嗎？」第三、受戒就像冒險入海採集珍寶，捨戒則像破產喪失財富，國王搶奪、盜賊偷竊、大水淹沒、烈火焚燒，只要一瞬間就能蕩然無存。第四、受戒時內心是從容安詳的，捨戒時往往是面臨欲望境界而情急難耐。世人往往容易帶著戒體去造作惡行，如今只用一句話就寬大開許成就捨戒，眾人都尚且不願如法照辦，更何況是設立繁複的因緣限制呢？』」

【111-0018】02_戒疏/06a_卷二上之二#131
【原文】【記】五中。初標緣，「多」下，引示。初引問受捨緣相難易，可知。且取作法，受須白四，捨唯一說。答中。初句通答。善惡天別，故云「相違」。立法難易，故云「對」也。「一」下，別顯四義相對。初、三約喻，二約立教，四就機宜。

【111-0069】02_戒疏/06b_卷二上之二#48
【原文】【疏】就初所以將罪以況「斷頭」者，過之重也。如俗極刑，勿過「大辟」，謂斬首也。約刑制戒，兩以通之。故《鈔》引云，如人有頭，受諸塵也，若不毀重，能有見諦，反此毀壞，永不能見，故以類也。
【譯文】【疏文】首先在第一部分，之所以拿「斷頭」來比喻這種重罪，是因為這項過失極為嚴重。好比世俗人間最極端的重刑，沒有大過於「死刑大辟」的，也就是斬首示眾。戒律依照世俗的刑罰精神來建立規範，兩者在義理上是相通相融的。因此《事鈔》中引用說明：好比人只要有了頭部，才能完整接納六塵的感知；修道者如果不毀犯重戒，才能具備見到四聖諦真理的能力；反過來說一旦毀壞了根本大戒，就永遠不能洞見真理，因此才用斷頭來做比喻。

【111-0070】02_戒疏/06b_卷二上之二#49
【原文】【記】釋注，罪名中，初文。前明舉喻所以。「如」下，引俗刑比釋。準俗制道，事義相類，故云「兩通」。「故」下，引示。即《標宗篇》引《婆沙》文「人之頭首，具納六塵，戒法亦爾，能通諸法」，故以比之。故彼論云：「戒名為『頭』，能見苦諦等色，聞名身等義，嗅覺意花，嘗出離三菩提味，覺禪定解脫等觸，知色陰等法。」廣如《鈔記》委釋。
【譯文】【記文】在解釋小註罪名的開頭文句中。前面說明舉出比喻的緣由。「如」字以下，是引用世俗的刑罰來對比解釋。依照世俗之法來制定僧團道規，在法義事相上非常相似，所以說「兩相通融」。「故」字以下，是引用文證說明。也就是在《標宗篇》中引用了《大毘婆沙論》的文句：「人的頭部具足容納六塵，戒法也是如此，能通達一切善法」，所以才以此做比喻。因此那部論典說：「戒律被稱為『頭部』，有了它才能看到苦諦等無漏色法，聽聞名身、句身等正法義理，嗅聞到七覺支的心靈妙花，品嘗超脫三界的無上菩提滋味，覺受到禪定解脫等殊勝觸感，澈見五蘊等諸法實相。」詳細情形如《事鈔記》所作的精細解釋。
