# 校閱材料　第502檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【502-0001】02_戒疏/08a_卷二下之一#7
【原文】【記】答：「化教明於業行，業中身殺居先。又復殺惱乖慈，大士特須偏禁，淫無違惱，故列于後。制教不爾，為道而制，障道中深，勿過淫欲，小機自利，不慮違慈，故與前反，各有其致。」
【譯文】【記文】回答：「化導教法旨在闡明業行的善惡，在諸種惡業中，身業的殺生居於首位。再者，殺戮逼惱完全違背慈悲心，大乘菩薩尤其必須著重禁絕；而淫欲並未帶來侵逼惱害，所以排在殺業之後。制定戒律的教法則不是這樣，律法是為了修道解脫而制定，在一切阻礙修道的過患中，沒有比淫欲更深重的；小乘根機的人以自身得解脫為目標，起初並未顧慮是否違背普濟慈心，所以律教的排序與經教相反，兩者各具深意。」

【502-0002】02_戒疏/08a_卷二下之一#8
【原文】【記】諸經皆爾，不可一指，是故文中但云「經明」。「豈」下，出意。三業之中，口、意二業，依身而成。身居其初，故云「先」也。又身三業中，殺為最重，如上所明。由此義故，經標在初，故云「因首」。次「言」下，轉釋重名。「性」名通含，對經云「重」。心無輕重，隨境分差，教依心制，故罪亦別。
【譯文】【記文】各部經典都是這個道理，無法一一列舉，所以疏文只概括說「經中闡明」。「難道不是」以下，揭示其深意。在身、口、意三業之中，口業與意業皆依託身體而得以成辦。身業居於首位，所以稱為「在先」。此外，在身業的三種過惡中，殺業最為嚴重，如同前文所闡明的那樣。由於這個道理，經教便將殺業標示在最前頭，所以說是「因首」。接著「所謂」以下，轉而解釋「性重」的名稱。「自性」這一概念涵蓋廣泛，是相對於經教所說的「重罪」而言。心念本無自帶的輕重，是隨著所面對的境緣而產生差異；戒律依據心態與對象來制訂處罰，因此罪報等級也有所不同。

【502-0003】02_戒疏/08a_卷二下之一#9
【原文】【疏】今就人趣，四句分業：一、非恩養，非福田；二、是恩養，非福田；三、是福田，非恩養；四、亦福田，亦恩養。
【譯文】【疏文】現在就人類這一範疇，以四句來劃分不同的業報：第一、既非恩養之親，亦非福田；第二、是恩養之親，但非福田；第三、是福田，但非恩養之親；第四、既是福田，又是恩養之親。

【502-0004】02_戒疏/08a_卷二下之一#10
【原文】【記】分句釋中。即對常人、父母、無學、及佛，以為四句。雖同人道，業道、制教、重輕、單複、因果竝殊，故須標別，方無通濫。大約而分：前一唯凡，後二唯聖，第二父母，則通凡聖。廣如後釋。
【譯文】【記文】在劃分句義並進行解釋的文句中。這四句分別對應了普通凡人、生身父母、阿羅漢聖者以及佛陀。受害者雖然同屬人道，但就業道本質、戒律制裁、罪過輕重、單純或重複犯戒，以及因果業報而言都各不相同，所以必須加以標明區分，才不會含混錯亂。大體劃分來說：第一句純粹是凡夫，後兩句純粹是聖者，第二句的父母則兼通凡夫與聖人。詳細情況如後文所解釋。

【502-0007】02_戒疏/08a_卷二下之一#13
【原文】【疏】以非父母，故非恩養；又非無學，故非福田。既非此二，則餘人道。所以不許加害者，人趣報勝，善因所招，形心俱是受道之器。出家之士，理應四等為懷，慈濟物命。今反內懷瞋忿，斷彼相續，違慈惱他，損害道器，過中之甚，故聖徧禁。
【譯文】【疏文】因為受害者並非父母，所以不屬於恩養之境；又不是無學道聖者，所以不屬於福田之境。既然不屬於這兩種，那就是指其餘的普通人類。之所以不允許加以殺害，是因為生於人道所獲得的果報極為殊勝，是由宿世善因感召而來，無論身體還是心智，都是堪以領受佛道的器量。出家修道之人，本應當以四無量心為懷抱，以慈悲之心救濟一切生命。如今反而內心懷抱忿恨瞋怒，斷絕他人生命的相續，違背慈悲並逼惱眾生，損壞了堪能載道的器量，這是過失中最為嚴重的，所以聖者制戒全面予以禁絕。

【502-0008】02_戒疏/08a_卷二下之一#14
【原文】【記】初句制意中。初對句揀境，「所以」下，正示制意。又二，初明所害境勝。文中三義：初、是現報勝，二、謂宿因勝，三、堪受道。六道之中，唯人一道，有緣可化，故云「道器」。「出家」下，次明能殺過深。初明順行。「四等」，即慈、悲、喜、捨，於物無偏，故四皆名「等」。「今」下，明違行。上二句明結業，次二句顯情過。色心報命，堪貯聖道，喻若「器」焉。下二句示制教。
【譯文】【記文】在闡釋第一句制戒用意這部分。開頭先對照句義甄別所面對的境緣，「之所以」以下，正式宣示制戒用意。其中又分為兩部分，首先說明所殺害對象的境緣殊勝。疏文中包含三層含意：第一、現世所得的果報殊勝；第二、宿世修積的善因殊勝；第三、堪能領受聖道。在六道輪迴之中，唯有人道具有善緣可以教化，所以稱為「道器」。「出家」以下，接著說明行殺者過患深重。起初說明順應佛道的修行。「四等」就是慈、悲、喜、捨四無量心，對待一切眾生平等無偏，所以四種都稱為「等」。「如今」以下，說明違背佛道的惡行。前兩句說明造下罪業，接著兩句顯露情緒的過患。身心報得的性命，能夠承載聖道，就如同容器一樣。最後兩句指出制定戒相的律制本旨。

【502-0010】02_戒疏/08a_卷二下之一#16
【原文】【疏】古人云：「殺生戒者，無論人畜，約命是同。」今言「大殺」，對後小害；大則重夷，小則輕墮，故名也。
【譯文】【疏文】古德曾說：「殺生戒的本質，無論殺的是人還是畜生，就傷害生命這一點而言是相同的。」如今稱為「大殺」，是為了對應後面傷害較輕的罪相；大的殺業直接構成極重的波羅夷罪，小的殺害則結較輕的波逸提罪，所以如此命名。

【502-0011】02_戒疏/08a_卷二下之一#17
【原文】【記】釋大殺中，初科。又二，初標古通濫，「今」下，明今列意。據標「大殺」，亦簡非人，但文見廣解，無別戒條，且對「九十」，揀異畜趣。
【譯文】【記文】在解釋「大殺」的文段中，屬於第一科。其中又分兩層，首先標示古德之說容易產生混淆，「如今」以下，說明現在立名的用意。依據標名為「大殺」，也是為了簡別殺害非人的情況；只是相關文意廣見於其他解釋，此處沒有另設戒條，暫且用來對應「九十單墮」中殺畜生的戒條，以簡別畜生道這類對象。

【502-0012】02_戒疏/08a_卷二下之一#18
【原文】【疏】故《善見》云：「生有二種，一者色生，二者無色生。色生可壞，無色生不可壞。然無色生，依於色生。色心相依行者，資稟成一假命。今以刀輪，壞彼色生，無色生者相與俱壞。使前不感後，後不赴前，斷報相續，名之為『殺』。」
【譯文】【疏文】因此《善見律毘婆沙》說：「生命有兩種：第一種是有物質形體的色生，第二種是無物質形體的心識無色生。色生是可以毀壞的，無色生則無法直接毀壞。然而無色生依託於色生而存在。色身與心識相互依託而運作，稟受資生條件而構成一期虛妄的生命。如今若以刀刃之輪毀壞對方的色生，依附的無色生便與之一同毀壞。使得前一剎那的心色無法感召後一剎那，後一剎那無法銜接前一剎那，徹底斬斷果報生命的相續，這就稱為『殺』。」

【502-0013】02_戒疏/08a_卷二下之一#19
【原文】【記】次科為二。初引示。「色」、「無色」者，即是五陰，四陰皆心，故言無色。「色」即凝滑，「心」謂業識，此二相依，乃成假命，故竝名「生」。「然」下，正釋。初釋生義。上二句，明心依於色。「色心」下二句，六字為句讀之，此顯相依而成報命。「今」下，釋壞義。以刀為輪，趣舉殺具，如罽膩吒王，為千頭魚，劒輪遶身之類。
【譯文】【記文】第二科分為兩部分。首先引證說明。「色」與「無色」，指的就是色、受、想、行、識五蘊，除了色蘊之外的四蘊都屬於心法，所以稱為無色。「色」就是受胎初期的凝滑物質，「心」是指業識，這兩者相互依託，才成就了暫時和合的假名生命，所以都統稱為「生」。「然而」以下，正式解釋。先解釋「生」的含義。前兩句說明心識依託於色身。「色身與心識」以下兩句，以六字為一句來讀誦，這是顯明兩者相互依託而成就果報的生命。「如今」以下，解釋毀壞的含義。以刀刃組成輪形，泛指各種殺戮的器具，例如罽膩吒王化為千頭大魚，劍輪繞身斬斫之類的公案。
