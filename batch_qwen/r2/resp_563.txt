以下逐則核對，先列**較嚴重的語義問題**，再列**精確度／增譯／用語一致性**的建議。

## 一、明顯錯誤（建議必改）

### 1. 【563-0005】「狂妄免責法」——誤解「狂」字
原文「狂病既止」的「狂」是**癲狂、精神失常**（律中「與癲狂人作羯磨」，狂亂期間所作不犯，故俗稱免責法），不是「狂妄」（驕縱自大）。譯文前句已作「癲狂病」，後句卻作「狂妄」，前後自相矛盾。
**建議**：「為什麼還須另作羯磨，解除先前為癲狂者所作的（不犯）羯磨法呢？」

### 2. 【563-0001】「破內」不是「損破男根」，且句構切錯
- 「破內」應是十三難中「**破內外道**」的省稱（與下文「邊、黃、五逆」同樣是省稱筆法），指入佛法後又歸外道者；譯成「損破男根」無據。
- 原文是兩組對照：
 **「二形、破內，永變非、畜」→ 戒有失**
 **「邊、黃、五逆，暫變二趣」→ 無失**
 關鍵在「**永變**非、畜」與「**暫變**二趣（非人、畜生二趣）」的對比。譯文把「永遠退墮非人畜生」寫成二形、破內的結果，又把「暫變二趣」拆成另一個獨立項目（「或暫時轉化為異類」），對照關係全失。
**建議改寫**：
> 「就已受具戒者而言，汙尼、賊住二難必不會在受戒後才生起；若是二形生、破內外道，或**永久**變為非人、畜生之身，戒體也會喪失；至於邊罪、黃門、五逆，以及只是**暫時**變為非人、畜生二趣之身者，戒體則不失。今說『不失』，即據此類而言。」

### 3. 【563-0010】「同難」應依《記》解為「同妨難」
《記》明言：「言『同難』者，謂同妨難。」譯文卻作「與**十三難**同樣是障礙」，與#12譯文（「如同危難妨礙一樣」）不一致，也違背元照的界定。
**建議**：「百種遮法既同於（房舍的）妨難一樣是障礙，難道也使受戒不成？」

### 4. 【563-0006】「本不由心」的「心」指「要期心」
疏文整段論證是：離衣法「**要心有期**」→病差違前法故失；狂羯磨「**得法本不由心**」→無期限故法存須解。「心」是**要期（期約）之心**，非「狂亂時的心識」。譯文「不取決於他狂亂時的心識」把重點移到精神狀態，論證線索斷了。
**建議**：「此法是由僧作法而得，本不由當事人的要期之心（而得），所以病癒後法仍存續，必須另作羯磨解除。」

## 二、術語與精確度

| 出處 | 問題 | 建議 |
|---|---|---|
| 0001 | 「惡獸才**搬遷過來**」 | 「始來」只是「才來／才出現」，不必加搬遷 |
| 0001 | 「釋**開成**之意」→「羯磨得以成立的**深層意趣**」 | 「開成」＝開許而（法）得成；「深層」為添加語 |
| 0001 | 「『法』下」譯成「**既然作法**以下」、「『此』下」譯成「**這是因為**以下」 | 這是對前面疏文的猜測引文；若無法定案，宜作「『法』字以下」「『此』字以下」 |
| 0001 | 「引此為據」→「引用**這段律文**」 | 「此」所指未明，不宜擅自坐實為律文 |
| 0003 | 「受戒後捨」→「**自願**捨戒」 | 《記》說「通指四捨」（含命終等），不宜限縮為自願 |
| 0004 | 「故引為並」→「**古師**引此作為對比質難」 | 此處是疏主假設問難，「古師」為增譯 |
| 0004 | 「**生病加持**的法效」 | 「加持」用語不當，應作「因病開許的離衣法」 |
| 0009 | 「初例可解」→「第一個**譬喻**」 | 「例」是引例／例證（受戒重難之實例），非譬喻；0001「作為比喻」同此 |
| 0011 | 「即身自有」→「自身**生來**就有」 | 重點是「就在自身上，無法像房舍那樣換處」，非強調先天 |
| 0011 | 「永乖出期」→「永遠違背出家解脫的期盼」 | 主語宜點明：「使此人永遠失去出離生死之期」 |
| 0012 | 「一百五十餘遮」→「一百五十多種**輕遮之難**」 | 此段正辨遮／難之別，宜作「遮法（輕遮）」，避免混稱 |
| 0012 | 「餘通得不」→「有得戒與不得戒的**通融空間**」 | 宜直譯「其餘則通於得戒與不得戒」，較貼原文 |
| 0012 | 「文據一往為語」→「就其大體主要義理而言」 | 「一往」＝約一方面、大略而說（非決定之說），可補「並非究盡之論」 |
| 0014 | 「必有所被」→「所**加被**施行的對象」 | 「加被」易誤讀為加持；宜「必定有所針對（所加及）的對象」 |
| 0014 | 「義須定指」→「必須具體明確指定」 | 應是「義理上須判定此法究竟歸屬於人或處」，故下文才有「與處相應」之答 |
| 0002 | 「因病而衣物沈重」 | 原文「人病、衣重」是兩項條件（病＋三衣沉重無力持），非「因病致衣重」 |
| 0020 | 「結界法」→「結**大**界」 | 疏文泛說結界，可不必限定大界 |

## 三、可保留但略可斟酌者

- **0007**「例難自失」：譯為「反難前文所立『病好法便自然消失』之說」，理解合理（以此例為難，則前義自失），可保留。
- **0008**「同受重難」補「十三難」是恰当注解；但「根本障礙戒體無法發起生起」稍嫌冗贅，可作「障礙戒體，令不發」。
- **0018**「應得作不」的「作」：譯為「建造」符合處分房舍的脈絡（下一難以結界作羯磨相並），可保留；必要時可加注「作屋」。
- **0019**「意在後通」→「其深意將在後面通達說明」：「通達」宜改「會通」（0001「故問通之」同此，作「設問加以會通」較準）。
- **0011**「青黃三角」：《記》判為三事（太青、太黃、眼三角），譯文0011合併為「膚色過於青黃」，與0012「列舉這三項」略有落差，可統一為三事。

## 四、總結

整體理解方向正確（三番問難的比並、遮難與重難之別、法與處相應），主要需修正的是：
1. **「狂」誤作狂妄**（0005）；
2. **「破內」誤釋＋永變／暫變對照錯置**（0001）；
3. **「同難」未依《記》解為妨難**（0010）；
4. **「不由心」的心未點出「要期心」**（0006）；
5. **「例／譬喻」「所被／定指」等術語精確化**，並刪去「古師」「自願」「加持」「深層」等無據增譯。
