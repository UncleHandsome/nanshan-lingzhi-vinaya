# 校閱材料　第424檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【424-0001】03_業疏/15a_卷三之四#23
【原文】若爾，既睡雖作不聞，今俱不作，何妨感戒？答：前雖無記，白是和本；後作教圓，緣非乖相，故不作不成
【譯文】如果這樣的話，既然睡著了即使僧眾作法他也聽不見，那麼現在僧眾都不作法，又有何妨礙於感發戒體？答：受戒者後面雖然處於無記睡眠狀態，但前面的單白是僧眾和合的根本；後面宣讀羯磨教法圓滿，因緣並沒有相違違悖，所以僧眾如果不作法是絕不能成就的。

【424-0002】03_業疏/15a_卷三之四#24
【原文】次科難意：彼既不聞，不作應得？答中初示聞白，「後」下次明羯磨。「緣非乖相」，謂能成之緣須滿足故
【譯文】次一科詰難的用意在於：受戒者既然睡著聽不見，僧眾不作羯磨應該也能得戒吧？答文中首先指出受戒者已聽聞白文，「後」字以下其次說明羯磨作法。「緣非乖相」，是說能成就戒體的因緣必須圓滿具足。

【424-0003】03_業疏/15a_卷三之四#25
【原文】有人言：戒是善本，善心相續，思心暢滿；若初善後惡，皆不發戒，以種類不續故。律云：與瞋恚、睡眠人不名受具。此豈始終惡、無記耶？中間暫起，即乖心思，何有成耶？如人起殺，臨到境所，心亂等生，前事不犯，戒亦同爾
【譯文】有人說：戒法是善法的根本，必須善心相續不斷，造作的心思通暢圓滿；如果起初是善心而後轉為惡心，都不能發起戒體，因為心念的種類不能相續的緣故。律中說：給處於瞋恚、睡眠中的人受戒，不能稱為得受具足戒。這難道是指他自始至終都處於惡或無記心嗎？中途暫時生起惡心或睡著，就違背了受戒的心念，怎麼能夠成就呢？好比有人生起殺心，將要走到所殺對象的處所時，忽然生起心亂等障礙，前面的殺業便不能構成犯罪，受戒也是同樣的道理。

【424-0004】03_業疏/15a_卷三之四#26
【原文】斥異中初科初立義。種類不續，三性相間故。「律」下引證，即受戒犍度文。彼約暫起，今取始終，如「下舉例」。「心亂生」者，或疑想心差，或癡狂失念。「戒同爾」者，比之可知
【譯文】在斥責異說的第一科中，首先建立其論點。所謂「種類不續」，是指善、惡、無記三性互相間隔之故。「律」字以下引律作證，即〈受戒犍度〉的律文。那段律文是就中途暫時生起而言，如今此處取的是通貫始終，如同「下文舉例」。「心亂生」，或者由於生起疑念想念偏差，或者由於癡狂喪失正念。「戒同爾」，拿它作比喻即可明了。

【424-0005】03_業疏/15a_卷三之四#27
【原文】解云：不同。受是緣成法，殺盜自造境。自造須作成，作成感無作，故前心異，作無有業也。受則不爾，自作在前，及論無作，假緣方感，已聞白竟，故是業起
【譯文】解釋說：這兩者並不相同。受戒是依憑外緣而成就的法，殺生與偷盜則是自己造作境業。自己造作必須作意行為成就，作相成就才能感得無作業體，所以前念心意如果發生變異，作相就無法構成業果。受戒則不是這樣，自己的作戒表業在聽白時已於前成就，至於論及無作戒體，則是假借僧眾等外緣才得以感發，既然先前已經聽聞白文完畢，所以戒業自然能夠生起。

【424-0006】03_業疏/15a_卷三之四#28
【原文】次正破中初科初總分。戒假他成，故云緣成法；殺盜反之，故云自造境。「自造須作」下別釋，初明殺盜不犯，「受」下次顯受戒須成
【譯文】在次段正式破斥的第一科中，首先總體區分。戒法假借他力而成就，所以稱為「緣成法」；殺盜則恰恰相反，所以稱為「自造境」。「自造須作」以下作分別解釋，先說明殺盜中途變心則不構成根本犯罪，「受」字以下其次顯明受戒必定能夠成就。

【424-0007】03_業疏/15a_卷三之四#29
【原文】又復解云：今受戒者，如教人殺盜。所教起狂心，但令前會，能教成重，不坐所教，以無有作無作故；若能教起狂心，但使遂本意，能教得無作。今例受者，如彼能教，以從僧乞，願僧與戒，僧隨其意，依法加被，似所教也
【譯文】又進一步解釋說：現在受戒的人，好比教唆他人去行殺生偷盜一樣。被教唆的人中途發狂心，只要所教的事項在前境會合，發起教唆的人便構成重罪，被教唆的人則不獲罪，因為他沒有作戒作罪與無作罪業之故；如果發起教唆的人中途發狂心，但只要被教唆的人遂順完成了原本的意圖，發起教唆的人也能感得無作罪業。如今拿來比照受戒者，受戒者如同那個發起教唆的人，因為他向僧眾乞戒，願僧眾賜予戒法，僧眾順從其心願，依照戒法加持秉作，僧眾就像被教唆的人一樣。

【424-0008】03_業疏/15a_卷三之四#30
【原文】次科正明中，殺盜兩戒，自作教他，二俱成重，故舉為例。初明所狂唯能教成犯。「不坐」謂不坐罪。「若」下次明能狂則能所俱犯。「今例」下但合後半，前半不同，如後問決。今以受者比能教，十師同所教
【譯文】在次一科正式說明中，殺與盜這兩條戒，無論是自己造作還是教唆他人，兩者都構成重罪，所以列舉出來作為比喻。首先說明被教唆者發狂時只有教唆者構成犯罪。「不坐」是指不獲罪受罰。「若」字以下其次說明教唆者發狂時則教唆與被教唆者都構成犯罪。「今例」以下只是契合後半部分的比喻，前半部分則不相同，如同後文問答所決斷的。現在把受戒者比作能教唆的人，十位戒師如同被教唆的人。

【424-0009】03_業疏/15a_卷三之四#31
【原文】問：若如前例，但受有心，前緣不具，亦同感業？答：譬取後半，前半則不同所教也。受是緣中須具，殺盜損境相應也
【譯文】問：如果依照前面的比喻，只要受戒者有受戒之心，前面的外緣縱然不具足，也能同樣感得戒業嗎？答：比喻只取後半部分的義理，前半部分則不同於被教唆的例子。受戒是在眾緣之中必須圓滿具足，殺盜則是只要損害前境便與罪相相應，所以兩者不同。

【424-0010】03_業疏/15a_卷三之四#32
【原文】釋妨中，問引前半以難受心。如能教起殺，前緣即十師；如所教起狂，彼既能教成重，此應受者得戒。答中初判不同。「受」下次申所以。受須緣具，所狂則非具；殺取損境，所狂則亦損，故不同也
【譯文】在解釋疑難中，詰難者引述前半段比喻來質難受戒之心。好比能教唆者發起殺心，此處的外緣就是十位戒師；好比被教唆者發狂，那裡既然能教唆者構成重罪，這裡受戒者也應該得戒。答文中首先判定兩者不同。「受」字以下進一步陳述原因。受戒必須外緣具足，若戒師發狂則緣不具足；殺業著重在損傷前境，被教唆者縱然發狂但境亦受損害，所以並不相同。

【424-0011】03_業疏/15a_卷三之四#33
【原文】故《多論》云：先以善心禮僧合掌，白四起業，相續成就，是名善心發善心得；若先以善心乃至起業，羯磨未竟，起不善念，藉前善心力故，發業任運而起，與不善俱，是名善心發惡心得，亦以前善心力教作故得，非不善心得；無記睡心入滅盡定者，是無心得，亦由前善心力故，與滅定俱，故云無心得，非無心而得也
【譯文】所以《薩婆多論》說：起初以善心頂禮僧眾、合掌恭敬，白四羯磨發起戒業，心念相續成就，這叫做以善心發心而在善心中得戒；如果起初以善心乃至羯磨發起戒業，羯磨尚未念完，心中生起了不善的惡念，憑藉前面善心的力量，發動的戒業自然任運而起，與不善心同時並存，這叫做以善心發心而在惡心中得戒，這也是因為前面善心之力請僧作法所以得戒，並非憑借不善心而得戒；至於處於無記睡眠心或者進入滅盡定的人，屬於在無心中得戒，這也是由於前面善心的力量，使戒體與滅盡定同時俱存，所以說是「在無心中得戒」，並不是說毫無前心就憑空得戒。

【424-0012】03_業疏/15a_卷三之四#34
【原文】引證中三句，發並善心得，通三性。初明善性得。「若」下次明惡性得。「起業」謂聞白竟，羯磨已去，轉惡亦成。「亦以業」者，遮疑，恐謂惡心而發善戒故。「無」下三明無心得。此有二種：睡是無記心，滅定心想不行即是無心
【譯文】在引文作證中有三種句式，戒體的發起都是憑借最初的善心而獲得，在得戒的剎那則通於善、惡、無記三性。第一說明在善性中得戒。「若」字以下其次說明在惡性中得戒。「起業」是指聽聞白文完畢，羯磨開始之後，轉生惡念也能成辦戒體。「亦以業」這句話是為了排除疑慮，唯恐有人誤以為是惡心感發了善戒。「無」字以下第三說明在無心中得戒。這有兩種情況：睡眠是無記心，滅盡定則是心念與想念不起行作即屬於無心。

【譯文】戒的共通名稱實際上兼通於善戒與惡戒，暫且依照《優婆塞戒經》（善生經）簡約歸納為五種義理：第一稱為「制」，是因為能斷除一切惡法之故；第二稱為「窄隘」，是因為其自性容不得惡法之故；第三稱為「清涼」，是因為能遮除煩惱之熱惱之故；第四稱為「上」，是因為能通達無上菩提之道之故；第五稱為「學」，是因為能調伏諸根智慧之故。雖然有這五種解釋，但全部都是從其義理功用來立名的。《大般涅槃經》的解釋如同上述的第一種通義，所以說：戒只不過是遮止遏制惡法，如果不造作惡事就稱為持戒。如同上文受戒之緣中，已經大略作了解釋。又如《阿毘曇心論》中所說，最初一念的無作戒體有七種名稱，此後的各念無作戒體有五種名稱，詳細內容如通常所解說的一樣。
