# 校閱材料　第200檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【200-0001】02_戒疏/09a_卷二下之二#78
【原文】【記】今破中。初通示持犯之本。「法」即是教，未立教法，無持犯故。「據」下，別示房戒。初立正義，反古三失。「事」、「法」各具「止」、「作」，「名體」如下所顯。「安」下，次斥古非。初舉重戒例破。「禦」謂正念離非，即能治之行。「識達」謂明辨行相，即解教之智。必須此二，方得成持，自餘悠悠，但名泛善，學者臨文，細意詳究。「戒隨」下，次約隨戒飜破。指「前立義」者，即「持犯成就」中。今師必據造房以明，與古全異，故此斥之。
【譯文】【記文】現在進行破斥。起初通貫說明持犯的根本根源。「法」就是佛陀的教法，未制立教法之前，本無持犯可言。「拿建造房屋」以下，個別說明造房戒。首先樹立正確義理，反破古人的三項缺失。「事相」與「教法」各自具備「止」與「作」，其「名目與體性」就如下文所彰顯。「哪裡有」以下，接著斥責古人的謬誤。起初列舉根本重戒為例來破斥。「克制抵禦」是指以正念遠離過失，這是能對治惡業的行持；「清楚了達」是指明晰辨別業行相貌，這是通達教法的智慧。必須這兩者兼備，才能成就真正的持戒，其餘悠忽漫不經心之態，只不過是泛泛浮善，修學者讀到此處，必須細密推究。「隨行戒體」以下，接著就隨戒生起的法義翻破古說。所指稱的「先前立論」，就是「持犯成就」那一章節。如今祖師必定依據實際造房的動作來闡明，與古說截然不同，所以在此加以痛斥。

【200-0004】02_戒疏/09a_卷二下之二#81
【原文】【疏】就房事明持犯者，依教不越名「止持」，驗教知量名「作持」，出於教量名「作犯」，不順教故名「止犯」。此則約其度量，顯其違順，止作持犯，名體各別。

【200-0005】02_戒疏/09a_卷二下之二#82

【200-0006】02_戒疏/09a_卷二下之二#83
【原文】【疏】次就法論，恐犯教制，如法無違名「止持」，從僧乞法名「作持」，故違不乞名「作犯」，即此違教名「止犯」。此亦名體各別。「止」據無違，「作」據順教，極分明也。若有昧者，翻犯可知。
【譯文】【疏文】其次就求法的羯磨程序來談：唯恐觸犯教法禁令、如法而無違背稱為「止持」；主動向僧團如法乞求作法稱為「作持」；故意違背戒法而不乞求處分稱為「作犯」；當下這份荒廢教法的怠慢稱為「止犯」。這同樣是名相與實體各自獨立分明。「止」是基於沒有違背，「作」是基於順從教法，界限極其明朗。如果還有人茫然不解，只要將犯戒相狀反轉對照，便能了然於胸。

【200-0007】02_戒疏/09a_卷二下之二#84
【原文】【記】後法中，先列四行。「止據」下，重示二持。令「翻犯」者，古謂乞法，但有作持及以兩犯。既存兩犯，必具二持，以翻「作犯」即「止持」故。
【譯文】【記文】後半部探討法度，先列出四種行持。「止是基於」以下，重新提示兩種持戒。文中所說「反轉對照」，是因為古人認為向僧團乞法只有作持以及止作二犯。既然承認有二犯，其背後必定對應具備二持，因為只要反轉「作犯」的本質，即是「止持」的安立。

【200-0009】02_戒疏/09a_卷二下之二#86
【原文】【疏】答：「此之過量及以不乞，緣雖兩望，果由房結。對相思事，隨有四違，纔一舉手，營搆土木，即有偷、吉四罪隨生。安有過量，偏屬作犯？若如此問，後戒無過，無作犯矣。準此成例，身業是過，約緣分罪，隨多少也。」

【200-0010】02_戒疏/09a_卷二下之二#87
【原文】【記】問中意者，以不乞法，但是不為，何有作犯？故躡前事，相比徵之。答中。初正答。「兩望」，即過重、處分，此謂不乞，還望造房，得有作義。「對」下，次斥偏局，又二。初約多罪難。「對相」即房境。「思事」即行心籌度。事、法，各有止、作兩犯，故云「四違」。「偷、吉」，此約方便，二作犯兩蘭，二止犯兩吉。「若」下，次引後戒例難。此二重難，雖釋前問，乃是對破古師耳。「準」下，結顯。後戒無過，而有作犯，可例此戒，具二作犯。既有二作，則兼兩止，並望身業造作過量，具兼四犯。又復乞、過有無不定，故云「約緣」等也。
【譯文】【記文】提問的深意是：不向僧團乞法，表面上只是單純的不作為，何來動態的「作犯」？所以攀附前述的事相，兩相對比來提出詰難。回答中，起初作正面答覆。「分屬兩端」是指過度超量與未經處分，這是說不乞請法度，終究還是要歸結到實際動工造房上，從而具備了「造作」的意義。「當面對」以下，接著破斥片面狹隘的執著，又分為兩節。首先就同時引發多種罪過來駁難。「對相」就是房舍的境界，「思事」就是造作之心審慎籌劃。事相與法度各自有止犯與作犯，所以稱為「四種違背」。「偷蘭遮與突吉羅」，這是就加行階段而言，兩個作犯結兩個偷蘭遮，兩個止犯結兩個突吉羅。「若是」以下，接著引用後續的無主大房戒作為例證反難。這兩重駁難，表面上是回答前面的提問，實質上是用來徹底擊破古代法師的偏頗見解。「依照這個常例」以下，總結顯明。大房戒沒有超出尺寸的過咎，卻同樣成立作犯，這即可作為此戒兼具兩種作犯的例證。既然具備二作，就同時兼具二止，全都是依託著身業逾矩造作這同一實體，同時具足了四種犯相。況且乞法與超量在具體個案中存廢不一，所以說「依據因緣來分配」等。

【200-0032】02_戒疏/09a_卷二下之二#109
【原文】【疏】摩觸一戒，尼重僧輕。所以然者？尼則煩惑情重，既受摩捉必為陵逼，成大過故，方便之內，制與重名。丈夫摩捉必無陵壞，不假深防，但就限分，故制輕也。又女人貪觸情重，《律》有背夫從觸之相，如彼《賢愚》，試蛇以㲲，女住男去，情有著故。
【譯文】【疏文】摩觸這一條戒，比丘尼犯之極重而比丘犯之較輕。何以如此呢？因為女人煩惱迷惑的習性沉重，一旦接受撫摩抓捉必定會遭進一步凌辱逼迫，從而促成破戒的大過失，因此在加行方便階段，就直接安立重罪之名。而成年男子施作摩捉，通常不會隨即被侵犯破壞淨行，不需防範得如此深嚴，只需就碰觸的部位與界限來論，所以制罪較輕。再者，女人貪著撫觸的情執更為濃厚，《律藏》中記載有背棄丈夫而順從他人撫觸的記載，就像《賢愚經》中以細軟毛毯試驗兩條蛇的公案，雌蛇靜臥不動而雄蛇游移離去，正因為女人的情感對此更為執著。

【譯文】【疏文】兩條造房戒也是如此。之所以不同，是因為比丘僧往往獲得較多利養且經常獨來獨往，造房的事務繁多頻繁所以罰重；比丘尼則恰恰相反所以罰輕。又如《薩婆多論》所說：「比丘尼通常是兩人共同建造，不得單獨住宿，所以個人不構成單獨房屋的法定限量。縱使建造有些許逾越，過失也是偏輕而不致判重。」

【200-0043】02_戒疏/09a_卷二下之二#120
【原文】【記】二房中。尼蘭同上，故云「亦爾」。「所」下，徵示。初約稀數釋。「尼反前」者，化緣微寡，則非「多利」，出處須伴，則非「孤遊」。「又」下，次約共不共釋。「人無房量」者，由是共造，各不滿量也。
【譯文】【記文】造房戒中。比丘尼犯此同上述二語只結偷蘭遮，所以說「也是如此」。「之所以」以下探問並解釋。首先從造房次數多寡來解釋。「尼眾相反」是指比丘尼化緣的能力較為微薄，算不上「多獲利養」；外出起居都必須結伴，稱不上「獨來獨往」。「又如」以下，接著從共有或獨有的角度來分析。「個人不構成房量」是指因為是共同營建，分攤到每個人頭上都不滿法定超量。
