# 校閱材料　第013檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【013-0001】01_行事鈔/01b_卷上之一#64
【原文】二對首心念，亦具七非，數同於上。隨事對法，各有別相。且舉安居一法，餘則例之。一者人非，謂界中有人，別眾而作，自不依他等。二者法非，口說錯脫，文非明了等。三者事非，時非夏限，處有難緣，不依佛制。四非已下，類前可知。
【譯文】第二、對首轉心念法，也具足七非，數目與上述相同。隨著所辦的事項對應其法式，各自有其個別的相狀。暫且舉單獨「受安居」這一項法為例，其餘的皆可照此推知：
第一是「人非」，也就是結界之內明明還有其他比丘，卻避開大眾私自心念安居，自己不依止他人受法等。
第二是「法非」，口中所說的辭句錯漏脫落，文句含混不明了等。
第三是「事非」，時間不在夏季安居的期限之內，處所有危難障礙的因緣，不依照佛陀的制度。
第四非以下（人法非、人事非、事法非、具三非），比照前面的模式即可明白。

【013-0002】01_行事鈔/01b_卷上之一#65
【原文】三眾法心念，如說戒等，亦具七非。一者人非，界內別眾，自犯六聚。二者法非，不陳三說，或有漏忘。三者事非，眾具有闕，時非正法。四非已下，如前例之。
【譯文】第三、眾法轉心念法，例如一人心念說戒等，也具足七非：
第一是「人非」，界內明明有其他僧眾卻獨自別眾作法，或者自己身犯六聚罪過而未懺淨。
第二是「法非」，不陳白宣說三遍，或者有脫漏遺忘。
第三是「事非」，應當具備的事項有所殘缺，或者時間不是如法的布薩之日。
第四非以下，如同前面的通例類推。

【013-0003】01_行事鈔/01b_卷上之一#66
【原文】四但對首，如持衣法。一者人非，所對之人，犯戒非法，有訶者訶。二者法非，陳受非正，或訶不止。三者事非，五大色衣及以上染，財是不淨之例。四非至七，如前例知。
【譯文】第四、純粹對首法，例如受持三衣之法：
第一是「人非」，所面對的那個人，犯戒身染非法，或者身邊有權訶責的人出聲訶責。
第二是「法非」，陳述領受的辭句不正確，或者有人訶責時卻不停下來。
第三是「事非」，衣物染上了青、黃、赤、白、黑五種正色或上等名貴染色，或者衣料財物來源是不清淨等類別。
第四非至第七非，如同前面的通例類推可知。

【013-0004】01_行事鈔/01b_卷上之一#67
【原文】五眾法對首，如自恣等。一者人非，四人秉法，第五受欲，或非淨戒，知而同法。二者法非，互不相陳，說不明了等。三者事非，時非夏末，眾難不具等。四非已下，亦如前例。
【譯文】第五、眾法轉對首法，例如二、三人對首自恣等：第一是「人非」，界內已有五人本應作僧法，卻由四人秉持對首法、第五人託受欲意（界滿五人不開對首且對首法不開受欲，故成別眾非法），或者參與者並非戒律清淨，明知其破戒卻仍與他共同作法。第二是「法非」，彼此互不陳白發露，言語說得不明了等。第三是「事非」，時間不在夏安居結尾之日，或者面臨的危難因緣並不具足等。第四非以下，也如同前面一樣比照例推。

【013-0005】01_行事鈔/01b_卷上之一#68
【原文】六者單白，如捨墮法，餘例取解，而各不同。一者人非，界內別眾，人非清淨等。二者法非，輕重同法，持犯不分，妄陳言說。三者事非，財非合捨，有過不陳，界非作法，衣物不集，妄輒託人之類。四人法非已下可解。
【譯文】第六是單白羯磨，例如捨墮法事，其餘單白皆可照此理解，而具體相狀各有不同：第一是「人非」，結界之內有人別眾不來集會，與會的人不是清淨比丘等。第二是「法非」，輕罪與重罪混用相同的法軌，持戒與犯戒的界限不分，胡亂陳述言辭。第三是「事非」，財物本不該捨卻予以捨除，有過失卻不陳白發露，所處界地不是如法的作法界，應當呈繳的衣物沒有集中在大眾前，或者妄自推託說衣物寄在某人處之類。第四項人法非以下，皆可依此理解。

【013-0006】01_行事鈔/01b_卷上之一#69
【原文】七白二中，如結界法。一者人非，不盡標盡相而集，界內別眾，得訶人訶。二者法非，唱相不明，作法闇託，又訶不止等。三者事非，標相及體三種分齊，混然一亂，不知彼此；二界錯涉，重結交互；遙唱遙結之類。並不成就。餘非例知。
【譯文】第七在白二羯磨中，例如結界法事：
第一是「人非」，沒有沿著所有界標、所有界相的範圍完全集會，結界之內有比丘別眾不集，在場有權訶責的人出聲訶責。
第二是「法非」，宣告界相不明確，作法時暗中含糊寄託，或者有人出言訶責卻不停下來等。
第三是「事非」，界標、界相以及界體這三種分齊界限，混雜成一團混亂，分不清彼此；兩種結界彼此交錯牽涉，重複結立、互相關涉；或者遠遠地宣告唱相、隔空遙遠結界之類。這些全都不能成就。其餘的非相照此例推可知。

【013-0007】01_行事鈔/01b_卷上之一#70
【原文】八者白四，如受戒法等。一者人非，受者遮難，界中不集，僧數有缺；人雖五百，一一人中，五十餘法，簡之不中，通非正數。二者法非，受前進止八種調理，及論正受執文無差等。三者事非，界相不明，衣鉢非己之類。餘非例前。
【譯文】第八是白四羯磨，例如受具足戒法等：第一是「人非」，受戒者有十三難或十六遮等障礙；界內比丘未能全部到齊集會；參與羯磨的僧人數目有所欠缺；與會僧人即使多達五百人，若對其中每一個人，未以五十餘種不合僧數之法徹底簡別審查，只要有一人不合僧數，便導致全體僧人皆不能算作法定正數。第二是「法非」，受戒前引導求戒者進退禮儀的八種調試整理有所違背，以及論及正式受戒羯磨時拘執文句不敢改動（死守文面不知隨事變更）等。第三是「事非」，界相不明確，衣物與鉢具不是求戒者自己所有之類。其餘各非比照前面例推。

【013-0008】01_行事鈔/01b_卷上之一#71
【原文】餘之正法，乃至心念，當法自成，不相通練。別眾一法，多或通之，廣張非相，如《義鈔》也。
【譯文】其餘的如法法事，乃至心念法，都是依其本法自身而成就，彼此法軌不可互相雜亂混用。唯有「別眾」這一項過失，往往會普遍貫通並破壞各類羯磨法事；關於其廣泛鋪敘展開的非法相狀，詳見《四分律拾毗尼義鈔》。

【013-0009】01_行事鈔/01b_卷上之一#72
【原文】次釋羯磨正文，令知綱要，識解通塞；若不具明見，增減一字，謂為法非。然其非相，唯在一字；然須知處所，不得雷同。或依文謹誦，曾不改張有無；或第二第三，亦隨略說；或無文稱事、有文無事、俱有俱無、未能增減，致使旁人加改，重增昏亂；或復闇誦，不入心府，臨事致有乖違，於即對眾之中，執文高唱。如斯等事，呈露久聞，豈不以愚癡不學，自受伊責。亦有轉弄精神，觀事乃同於法，而人事兩緣，冥逾夢海；量時取法，全是師心。照教，教稱不成；結罪，罪當深罰。是以同法之儔，幸宜極誡。若作羯磨人，要須上座。故律云：應作羯磨者，若上座次座；若上座不能，當出言語，持律者作。已外不合。今正釋文，且就說戒單白及受戒羯磨，具解二文。餘則例解。
【譯文】接下來解釋羯磨的正文，目的是讓人了知其綱領要目，辨識理解文句的開通與局限；如果不具透徹明瞭的見解，看見別人增減了一個字，便妄以為是羯磨法非。然而這非法之相，往往就在關鍵的一字之差；但必須明白該改與不該改的處所，不能一概而論、盲目雷同。有的人只知拘泥律文謹慎背誦，面對實際情況的有無卻從不知靈活變更；或者看到律文標註「第二第三亦如是說」，便照著省略字句直接念出（未能如法重宣羯磨三遍）；或者律文沒有相應字句卻胡亂稱說事端、或者律文有字句卻沒有相應的實事、或者兩者俱有俱無，作法者都無能審度予以增減，以致於需要旁人當場出言糾正修改，更加增添了現場的昏聵混亂；或者背誦不熟，沒有真正銘記於心，臨到行事時產生脫落違誤，只得在僧團大眾之中，手捧文本大聲朗讀。像這一類荒腔走板的事，早已屢見不鮮，這豈不是因為愚癡怠學，才招致律法的責難！也有的人賣弄才智小聰明，看待具體事緣竟隨意混同於固定法式，對於人與事這兩大因緣，昏聵懵懂如同置身夢海；臨時揣度取用作法，完全出於自以為是的師心自用。對照聖教律文，聖教判定其法事根本不能成就；審定罪過，當事人應當遭受嚴厲的罪罰。因此同修道友們，實在應當引以為極大戒惕！如果擔任主持羯磨的人，必須要是上座。所以律藏說：「應當作羯磨的人，或是上座，或是第二座；如果上座能力不及，應當出言囑託，由通達戒律的持律者代為進行。」除此之外的人都不合規格。如今正式解釋文句，暫且就說戒的「單白文」以及受戒的「羯磨文」，具體剖析這兩篇文句。其餘的文句皆可比照理解。
