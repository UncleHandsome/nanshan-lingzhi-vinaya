# 校閱材料　第1176檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1176-0001】資持記/09b_中三上#47
【原文】不犯有四，初開非意。無恚者，謂後至人。隨次出者，即前住者，謂見上座來自避去也。共下，次開護戒。若下，三開簡穢。以此九人非同儔故。四破中，闕正命。因下，四開難緣。若不牽出，必致損已，故云因此。辨異中。強敷不開穢境，故須明之。俗處不簡，寄他舍故；
【譯文】不犯戒的情況有四種，首先開許無心之失。沒有瞋恚惡念的人，是指後到的人。按照長幼次序依次退出的人，是指原先住在裡面的僧人，看見上座長老進來，自己主動避讓離開。「共」字以下，其次開許為了維護戒律威儀。「若」字以下，第三開許清理驅逐污穢之徒。因為這九種惡人不配與清淨大眾同列為伴。在四種破戒壞行者中，此處缺漏了破正命這一項。「因」字以下，第四開許逃避災難的因緣。如果不把對方拉出去，必定會直接導致自己受到傷害危險，所以說是「因此」。在辨析差異的段落中。前面強占中間鋪位戒並未開許針對污穢之人強鋪，所以此處必須嚴加辨明。在世俗人家裡不必細加篩選驅趕，因為那是寄居借住在別人家裡；

【1176-0002】資持記/09b_中三上#48
【原文】僧處須簡，非同住故。十八。〔佛在舍衛，有比丘在重屋上住，坐脫脚床，脚脫墮比丘身，壞身出血；仰面恚罵，因制。〕但標名列緣而不釋者，末世事稀；若復委明，不濟時要；前後諸戒有略皆爾；不知此旨，全迷鈔宗。然恐初學臨文致壅，故略引釋，餘廣如疏。初緣重屋，平地非犯。〔疏有四緣，第二云薄覆，明易陷也。
【譯文】在僧團常住的處所就必須嚴格篩選清理，因為他們根本不具備同住清修的資格。第十八條戒律〔佛陀住在舍衛城時，有比丘住在樓房的上層，坐在一張床腳已經脫落鬆動的床上，床腳突然脫落砸在下層比丘身上，砸傷身體流血；受傷比丘仰面瞋恚咒罵，佛陀因而制戒〕。此處只標明戒名、列舉犯戒條件而不做詳細解釋的原因，是因為末世這種事情極為少見；如果再詳細說明，無濟於當前的迫切需要；前後各戒凡有簡略之處全都是這個道理；不明白這個用意，就會完全迷失《行事鈔》的宗旨。然而唯恐初學者閱讀至此產生壅塞阻礙，所以簡略引用解釋，其餘詳情正如《戒疏》所說。第一緣樓閣房屋，若在平地上坐則不犯〔《戒疏》列有四個條件，第二個條件說是樓板覆蓋薄弱，說明容易塌陷〕。

【1176-0003】資持記/09b_中三上#49
【原文】二脫脚，律云脚入髀〔疏云明將脫不久也〕。三坐臥犯者，廣解唯臥犯；今從戒本，坐臥齊犯。律中若獨坐床一板床浴床，坐者皆吉。不犯者。若坐鏇脚直脚曲脚無脚床〔皆謂不脫〕，若床支大〔雖脫有所承故〕，若脫脚安細腰〔謂有釘鈕〕，若重屋板覆厚覆等，若板床坐〔謂以板藉〕，若脫脚坐〔除去脚也〕，並開。
【譯文】第二個條件是床腳脫落，律文中說床腳只是虛插在床框的榫孔中〔《戒疏》說這代表即將鬆脫不久了〕。第三個條件是坐臥時皆犯，詳細解說的文獻只認為躺臥時才犯；現在依循戒本正文，坐或臥同樣都算犯戒。律文中如果是一個人獨坐的單人床、單塊木板床、洗澡用的矮床，坐了都算輕罪（吉羅）。不犯戒的情況是：如果是坐在旋轉榫接、直腳、曲腳、無腳的固定矮床上〔都是指床腳堅固不脫落的〕，如果是床腳底部的支撐極為寬大〔即使脫榫也另有依托支撐〕，如果是脫腳處用細腰榫卯鎖固〔指有釘子或金屬搭扣扣住〕，如果是樓房樓板以木板鋪覆或厚實鋪覆等情況，如果是在厚木板床上安坐〔指以整塊厚板作為墊底〕，如果是直接卸除床腳坐在地上〔就是乾脆把床腳拆除〕，這些全都予以開許。

【1176-0004】資持記/09b_中三上#50
【原文】十九。〔佛在俱睒毘，闡陀起屋，虫水和尼招譏故制。〕此中大意，過在違慈。疏引光師云：重已所輕〔房屋〕，輕他所重〔虫命〕，深乖慈惻，故須急制。釋第四中，初明虫水。若下，次明諸漿。律云除水已，若有虫酪漿等；則知餘物皆制，不獨虫水也。酪分清濁，餘二可解。
【譯文】第十九條戒律〔佛陀住在拘睒彌國時，闡陀比丘起造房屋，用含有小蟲的水去和泥塗牆招來世人譏嫌，佛陀因而制戒〕。這條戒律的核心大意，過失完全在於違背了慈悲心。《戒疏》引用智光律師的話說：過度看重自己所看輕的俗物〔房屋建築〕，卻極度輕視他人所看重的珍寶〔微蟲的生命〕，這深深違背了慈悲惻隱之心，所以必須緊急制戒防範。解釋第四個犯戒條件中，首先說明含有微蟲的生水。「若」字以下，其次說明各類植物漿汁與飲品。律文說除了水以外，如果是有蟲的酪漿、果汁等物；則知其餘各種液體皆受禁制，絕非僅限於有蟲的水而已。酪漿有清稀與濃稠之分，其餘兩類容易理解，不必多說。

【1176-0005】資持記/09b_中三上#51
【原文】《戒本》但明用澆泥草，今就廣文互投皆墮。一切下，總結罪相。下引《五分》用水澆物，本律以物擲水，並計虫魚多少為量，故云一一墮也。問：此戒為約用水，為約虫死？答：《戒疏》云：此不就損命中制，是深防制；若彼命斷，自依畜戒；是知虫雖不死，計數成犯。
【譯文】《戒本》中只說明拿水去澆灌泥土和青草，如今按照詳盡的廣律記載，將蟲拋入泥草，或者把泥草投入蟲水，兩者同樣都結犯墮罪。在「一切」以下，總括歸結所犯的罪相。下文引用《五分律》說用水潑灑澆灌物品，本部《四分律》則說拿物品拋擲入水中，都是計算其中所害微蟲或魚苗的具體數量來定罪，所以說每害一命便一一結犯一項墮罪。有人問：這條戒到底是針對用水的動作來結罪，還是針對微蟲死亡的結果來結罪？回答：《戒疏》說：這並非直接依據殺害眾生生命的實質結果來制戒，而是一條深遠防微杜漸的嚴防性戒律；假使微蟲真的喪命斷氣，自當依照殺畜生戒來另外判罪；由此可知哪怕微蟲僥倖未死，只要按水中微蟲的數量推算，便已經構成犯戒。

【1176-0006】資持記/09b_中三上#52
【原文】問：虫不可知，罪寧有數？答：此據漫心，不論知數；隨用隨擲，冥獲多罪。宿云轉轉，食云咽咽，衣云著著，例皆爾也。若爾，懺悔如何陳相？答：罪必可知，隨數牒入；不可知者，但云不憶，如後自顯。釋第三中，初引經明麁細二類；意顯細虫，明須漉用。十分之一，明其極細。千萬由延，示其極麁；
【譯文】有人問：水中的微蟲肉眼根本無法全知，罪名數量怎麼可能算得清楚？回答：這是就粗疏放任的心態而言，不論當事人是否精準知道實際數字；只要你隨手取用隨手潑擲，冥冥之中就已經犯下了多重罪過。如同過去律師所說「宿夜則念念輾轉成罪，進食則咽咽吞下獲罪，穿衣則件件披身得罪」，全都是依照這個通例來處理的。若是這樣的話，事後懺悔時該如何陳述發露罪相？回答：罪數如果必定可以查明算清，就隨著查出的數字逐條列名呈報懺悔；若實在無從查清知曉，只要在佛前陳述說「我不復記憶確數」即可，這在後文自然會詳細顯明。解釋第三個條件中，首先引用經典來說明粗大與細微這兩大類眾生；其用意是在顯發極其細微的蟲類，明確強調必須經過濾水囊過濾後才能取用。小到一粒微塵的十分之一，這是形容其微小到了極致。大到千萬由旬之廣，這是形容其龐大到了極致；

【1176-0007】資持記/09b_中三上#53
【原文】如摩竭魚金翅鳥蟒蛇之類。次科，《僧祇》，初護梵行。不可居也。若下，明漉用。或是元無，或曾漉竟。春夏朝中並應諦視。《五分》，初示虫水。虫取可見，即入制限。《多論》：身子天眼觀空中虫，如水邊砂，器中粟，遂斷食；佛因制云：但肉眼所見，漉囊所得，文與此同。
【譯文】例如摩竭大魚、金翅大鳥、巨型蟒蛇這一類的眾生。在下一科中，《僧祇律》首先提到要護衛清淨梵行。這樣的水不可隨意放置在起居處。「若」字以下，說明濾過之後方可取用。或者本來就沒有蟲，或者是先前已經完全過濾過了。在春季與夏季的早晨和中午，都應當仔細端詳察看。《五分律》中，首先指出何謂有蟲之水。這裡的蟲是指肉眼可見的，才列入戒律規範的限制。《薩婆多論》記載：舍利弗尊者用天眼觀看虛空中的微蟲，密密麻麻如同水邊的細沙、器皿裡的粟米，因而驚駭得絕食不敢飲水；佛陀隨即制定戒律說：只要以肉眼所能看見、濾水囊所能攔截過濾的為準，其文意與本部律典完全吻合。
