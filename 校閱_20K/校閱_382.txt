# 校閱材料　第382檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【382-0001】02_戒疏/18c_卷四上之三#66
【原文】【記】戒本，釋第二中。文云「前食後食」，合云「食前食後」。「依《時經》」者，彼從明旦至中已前，中半折之，故云「時中」，謂時之中間也。若約此方，正當辰時，即如《經》云「食時著衣持鉢」是也。
【譯文】【記文】在戒本解釋的第二部分中。戒本原文寫著「前食後食」，依文法語序應當理解為「食前與食後」。「依照《時經》的標準」這句話，是指經典中從清晨拂曉開始計算到日正當中為止，將這半天時間的中間點加以折半切分，因此稱為「時中」，也就是整個時段的正中點。若是對應於漢地的十二時辰計算法，大約正好落在辰時（早晨七點至九點），正如諸多大乘《經典》中所記載的「到了食時，著衣持缽」的那個時段。

【382-0002】02_戒疏/18c_卷四上之三#67
【原文】【疏】《律》「囑授」中，文列「同界共住」。若無易覔，不得白非同受請者及容展轉也。異非時白，取知而已。
【譯文】【疏文】《四分律》在說明「告知囑託」的具體作法時，條文明確限定為「同在一個僧界之內共同居住的比丘」。如果身邊一時難以找到同伴，絕不可以隨便向那些「沒有共同接受同一份請齋」的比丘進行告知，也絕對不允許請託他人輾轉代為傳話。這與後續另一條「非時進入聚落」只需讓人知曉即可的性質截然不同。

【382-0003】02_戒疏/18c_卷四上之三#68
【原文】【記】第三中。初釋當戒，定須同界。「若無易覔」，謂覔同請難得，則非同請者不得白之，亦不得囑他展轉白也。若獨受請，無可對白，即落開通。「異」下，簡後戒。非時入眾聚，但取白知，無問界之內外、請之同別，隨白得成。此局彼通，持犯兩異。
【譯文】【記文】在第三部分中。首先解釋本戒的根本規範，囑託的對象一定必須是同界共住的人。「如果身邊難以找到」，意思是如果尋找共同受請的人非常困難，那麼絕對不能退而求其次去向那些沒有受請的人告白，也不能託人輾轉代為轉告。但如果從頭到尾只有自己一個人接受請託獨自赴會，周遭完全沒有同伴可以對白告託，這就直接落入無人可囑的開許免責情況。「這與後續」以下，將本戒與後面的戒條進行簡別辨異。後文的非時入聚落戒，其精神純粹只是讓僧團有人知道自己的行蹤即可，無論那人是界內還是界外、無論是否共同受請，只要隨意向一位比丘告知便算如法成就。本戒的規範非常嚴苛侷限，而後戒則極為寬廣通融，兩者在持戒與犯戒的界線上存在著極大的差異。

【382-0004】02_戒疏/18c_卷四上之三#69
【原文】【疏】就開緣中，列三加白為四。「衣時」文，明時外開故。若非時分，先有好心施衣及食，已是開訖。必未起心，比丘勸化作食、施衣，為僧者開，以利多故。自為不開，長貪敗道，邪命所攝。
【譯文】【疏文】在免責的開許因緣中，條文明列了三種時節開緣，若加上向比丘告白囑託則共有四種。「施衣時節」的條文，明確展現了這是在常規時令之外的一種特殊放寬。如果不在法定的結夏時分之內，只要居士原本就預先懷抱著純良的善心想要主動布施衣服與飲食，比丘前往便已經是合法開許的了。倘若居士本來尚未發起這份布施之心，比丘為了大眾僧的生計而主動前往勸化對方修善、提供飲食與僧衣，只要純粹是為了整個僧團的利益，也是在准許開緣之列，因為這能為大眾帶來廣大的利益。但如果是為了滿足個人的私欲而去化緣，則絕對不得開許，這會滋長一己貪欲、敗壞修道品格，在佛法中屬於邪命自活的惡劣行徑。

【382-0005】02_戒疏/18c_卷四上之三#70
【原文】【記】第六句中。初總示四開。「衣」下，別釋施衣。初明檀越自施。「必」下，次明比丘勸化。開僧制別，在文可分。
【譯文】【記文】在第六句的解釋中。開頭先總體指出四種開許的因緣。「衣時」以下，個別深入解釋布施僧衣的各項情況。首先說明居士出於自發心的主動布施。「倘若居士」以下，次一步說明比丘主動前往勸化募化。為了整個僧團而開許、為了個人私利而嚴加禁止，這兩者的界線在條文中界定得非常分明。

【382-0006】02_戒疏/18c_卷四上之三#71
【原文】【疏】不犯中，「多家敷具」者，謂多家同會處，處處待僧，隨至何家，皆是請處。
【譯文】【疏文】在不犯條件中，所謂「多戶人家共同敷設坐具」的情況，是指有多戶居士共同在一處廣場或大廳聯合聚會，各家各自設席等待僧眾前來應供，這時比丘無論走到哪一家的席位，該處都屬於正當接受請齋的合法場所。

【382-0007】02_戒疏/18c_卷四上之三#72
【原文】【記】不犯中。釋多家請，但約「同會」，不同亦犯。注中，庫藏、邊房、尼寺，並非家故。《律》中，作囑授已，至此等處，即失前法，再白聽往。此不犯中，約無可囑，家既非犯，餘開可知。
【譯文】【記文】在不犯條款的分析中。解釋多戶人家聯合設請，前提必須是他們「共在同一聚會場合」，如果各居士分散在不同宅邸，隨意亂走依然構成犯戒。隨文註解中所列舉的寺院庫房、邊陲僧舍、比丘尼寺，這些在本質上都不是世俗的「白衣家宅」。《四分律》規定，比丘如果已經作了外出囑託，但中途若先到了這些非世俗住家的場所，先前所作的告白法效便立即失效，若要再進入村落住家，必須重新向人告白方得前往。而在上述的不犯條款中，是指在完全沒有其他比丘可以囑託的情況下，前往住家既然都不算犯戒，那麼前往這類附屬處所自然更在開許免責之列，這是顯而易見的。

【382-0010】02_戒疏/18c_卷四上之三#75
【原文】【疏】凡在俗常習，婚禮無時。出家學慧，須知俯仰。今不思緣，久住不去，妨彼懷求，迭相逼斥，理非所應，故制。

【382-0011】02_戒疏/18c_卷四上之三#76
【原文】【記】四十三，制意中。初敘俗多染習。「出」下，次明僧不知宜，因而起過。言「逼斥」者，如戒緣中，迦留強坐，其夫與食，累遣不去，夫瞋捨棄：「隨汝所作！」
【譯文】【記文】第四十三條，制戒用意中。開頭先敘述世俗多有愛染之習性。「出家人」以下，次一步說明僧人不知合宜避嫌，因而引發過失。文中所說「逼惱斥責」，正如制戒緣起中，迦留陀夷強行坐著不走，其夫雖供與飲食，但累次遣請他離去仍不走，丈夫憤而捨棄離去說：「隨你想幹什麼就幹什麼吧！」

【382-0012】02_戒疏/18c_卷四上之三#77

【382-0014】02_戒疏/18c_卷四上之三#79
【原文】【註】佛在舍衛。迦留陀夷本俗友婦齋優婆私，各端正，俱繫意。後至其家，彼婦嚴身，夫主極愛。比丘食已坐住，其夫便瞋捨去。比丘以事白佛，佛因制戒。

【382-0019】02_戒疏/18c_卷四上之三#84
【原文】【疏】釋「食」，以男女情相領納，故為食。言「有寶」者，如《多論》解，以著寶衣，輕明照內身，現發欲故。《僧祇》中「俱男、俱女亦不犯」，非食家故。
【譯文】【疏文】解釋「食」字，因男女情識互相領納執取，故稱為食。言「有寶」者，如《薩婆多論》解釋，因婦人穿著寶衣，輕薄明徹透顯內身，容易引發貪欲之故。《僧祇律》說「若全都是男子、或全都是女子亦不犯」，因為不是男女貪愛之食家的緣故。

【382-0020】02_戒疏/18c_卷四上之三#85
【原文】【記】釋中。初明食義。「言」下，次釋有寶，即女人嚴身物也。「僧」下，引文簡濫。辨相注中，「盲、聾互有」，即第四人，各缺一根，非全證故。不犯中，「識別人」者，謂舊相知，對下「客人」，即非舊識。
【譯文】【記文】解釋文句中。首先說明「食」的涵義。「言有寶」以下，次一步解釋有寶，即是女人盛裝嚴身之物。「僧祇」以下，引律文簡別濫用。辨相隨文註解中提到「盲、聾互有」，是指在場充當第四人的作伴者，各自存在著感官機能的缺陷（或盲或聾），不能作為合格的見證人，因此比丘仍結犯突吉羅罪。不犯條文中所謂「識別人」，是指舊相識之明理者，與下文的「客人」相對，客人即非舊識。
