整體看下來，這五則譯文的**大方向與判教理解是對的**（四心分二止、三心非業望受體說持、三性揀二性、四行間雜等），白話也算通順。但有幾處**義理誤譯**、幾處**術語失準**，以及**校勘字未加注**的問題。以下逐則列出，並附建議改法。

---

## 一、貫穿全篇的三個通則問題

**1.「四行」不宜譯成「四種行持」**
「四行」＝止持、作持、止犯、作犯，其中兩個是「犯」。譯成「四種行持」（0002、0004）等於把犯也說成「持」，語義自相矛盾。
→ 建議統一作「四行（止持、作持、止犯、作犯）」或「四種行」，首次出現時加括注即可。

**2. 科判文與釋文混在同一段流水白話中**
如「三成就門，約心中，初二句標示」「一下，正明，初立義」「田下，示立所以」「前後中」「後約三業，身口中二」——這些是元照的**科判**，不是論文。目前譯成敘述句（「在第三成就門之中……前兩句標明提示。」）讀來突兀。
→ 建議另立一行、加【科判】標記，或用「〔科〕」區隔，並保持句式一致（「某字以下」）。

**3. 原文疑訛字被「默默改掉」，未加校注**
0001「緣本述魚」、0003「田下」、0003「上持」三處，譯文都直接改成通行讀法。改得合理，但讀者無從得知原刊本作何字。
→ 建議加校注（可核《大正藏》T40, No.1805 及《行事鈔》T1804），例如：「原文作『緣本述魚』，疑為『緣木求魚』之訛，今依義改譯。」

## 二、逐則檢視

### 【1794-0001】

| 原譯 | 問題 | 建議 |
|---|---|---|
| 攝受修持 | 「攝受」在佛典多指佛攝化眾生，與此處「攝修」不合 | 「攝心修行」／「收攝身心依教修持」 |
| 捨棄鈔文而妄自推求**本體** | 「本體」帶近代哲學味；此處「體」是「持犯之體（體狀）」 | 「棄捨鈔文而自行推敲持犯之體」 |
| 硬生生建立標新立異的**端緒** | 「異端」＝異說、別解，不是「端緒」 | 「硬要另立異說」 |
| 一切萬行的根本基石 | 「一切」＋「萬」語義重複；「基石」為增譯 | 「萬行的根本」 |
| 我們律宗祖師的**真正道風** | 「道」指教法令脈，「真正」「風」皆增字 | 「我們祖師的法道」 |
| 明決裁斷其中的合理與否 | 「明決裁斷」生硬 | 「抉擇判定其是非可否」 |

* 校勘：「緣本述魚」→ 應注明為「緣木求魚」之訛。
* 「幸負反隅之識」譯「希望諸位懷有舉一反三的見識」可以，建議加注出處（《論語》「舉一隅不以三隅反」）。
* 「三成就門」建議補全名為「第三、成就（處所）門」，與後文十門科名一致。

### 【1794-0002】

1. **「唯止持通二」譯「通貫這兩種心態」——太含糊。**
 「二」明指「三心中止／行心中止」，也就是三心與行心。
 → 「唯獨止持通於『三心』與『行心』二者」。
2. **「想謂取所領之相」譯「獲取領納境界的相貌」——句法歧義。**
 讀起來像「獲取＋領納境界的相貌」。原意是：於「受」所領納之境上取像。
 → 「想，是取著所領受境界之相（於境取像）」。
3. 「四心」首次出現宜补注：**受、想、行、識**（即四無色蘊），否則讀者要到下一則才拼得出來。
4. 「顯示分二所以」譯「分成兩種的緣由」宜補實：「分為『三心』與『行心』二類的緣由」。
5. 「善惡尚未**著落**」用詞偏口語且易誤解 → 「善惡之相尚未彰著（未成業）」。
6. 小註來源建議分層：〔通指六識〕是**記的夾註**，「注簡四心」的「注」是**鈔的小註**，兩者都用圓括號會混淆，可用不同標記或加「鈔註／記註」。

### 【1794-0003】

1. **「田下」→ 譯為「『由』字以下」：這是校勘判斷，必須注明。**
 「田」與「由」「因」「四」形近皆可能，請核大正藏原刊；若無他本可據，宜作「『田』字以下（『田』疑為『由』之訛）」並存疑。
2. **「即名上持」→ 譯「就稱為止持」：同上，「上」疑為「止」之訛，應加注。**
3. 「能取於果」譯「能夠**招感招致**果報」——疊詞冗贅 → 「能招感果報」。
4. 「以持是記業」譯「有記的善業」可，但宜補一句：「『記』指善惡可記別者，與『無記』相對」，否則「有記／無記」讀者難解。
5. 「但望受體」譯「對照受戒所得的防非戒體」——很好（受體／隨行之分掌握到了），保留。

### 【1794-0004】

1. **⚠ 主要義理誤譯：「三惡相別」譯成「三種惡念……則相貌各別」。**
 此句與上句「三善**同時**，而不相離」對文，「相別」是說**三不善根各別而起、不能同時並生**（下句「其性相違」正是理由），不是「長相不同」。
 → 「三種不善根（貪、瞋、癡）則各別而起、不能俱時，因為它們的體性彼此相違。」
2. 「四種行持」→ 同通則，改「四行」。
3. 「因為行心的**語義很寬通**」→ 更貼切：「因為『行心』一詞通於善、惡、無記三性，怕彼此混淆」。
4. 「『止作』字以下」→ 「『止作』二字以下」（引兩字時不宜用「字」單稱）。
5. 「止犯通常是由於愚癡與傲慢」——「率」＝大率、多半，譯「通常」略強，可作「多半」。
6. 「前後中」譯「在『前後門』之中」：加「門」字須與全篇十門科名一致；又 0005 說「即**下**自作教人、自業相成二門」，涉及門次先後，建議核對整篇科判表後再統一命名（避免此處稱門、彼處稱節）。

### 【1794-0005】

1. **「別持犯」括注「（另外的持與犯）」——不當。**
 「別」是「各別」，指於一行中兼帶異行，故持犯各別，不是「另外的」。
 → 或刪去括注，或作「（各別的持犯相）」。
2. 「上文各據二行為言」譯「各自依據**單純的**二行」——「單純的」是無據增譯且語意不明。
 → 「上文是各就二行（二持、二犯）分別而說」。
3. 「即下……二門之**義**」譯「二門的**深意**」→ 「二門所要說的義理」即可，不必加深。
4. **「不受食」建議加注。** 這是律中「不受食戒」：食前須從人依法領受（受食作法），應作而不作，故判為「身止犯」。
 原譯「不依律受食而**逕自取食**」屬增字解釋，方向沒錯，但重點在「**不作受食之法**」，宜改為：「不依法從人受食（應作而不作），稱為『身止犯』」，並加簡注。
5. 「言可知者」譯「文中說『可知』（**理當可知**）」——括注多餘，可刪。
6. 「間雜同時」譯「前後錯雜交替或同時並起」可以，但「前後」是增字；若保留，宜與下文「前後心」呼应說明。

## 三、建議的優先處理順序

1. **必改（義理）**：0004「三惡相別」；0002「唯止持通二」；0005「別持犯」括注。
2. **必補（校勘）**：0001「緣本述魚」、0003「田下」、0003「上持」三處加校注。
3. **術語統一**：四行／三心／行心／受體／記業·無記／止持·作持·止犯·作犯，建議建一份對照表，全書一致。
4. **文體**：科判獨立成行；节制增字（「真正」「深意」「單純的」「妄自」等），必要的解釋改放括注或腳注，不要混入正文。
