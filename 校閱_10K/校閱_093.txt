# 校閱材料　第093檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【093-0001】01_行事鈔/05b_卷中之一#27
【原文】第二盜戒。性戒，含輕重也。性重之中，盜是難護。故諸部明述，餘戒約略總述而已；及論此戒，各並三卷五卷述之。必善加披括，方能免患。有人別摽此盜，用入私鈔，抑亦勸誡之意也。終須遍覽，故銓次列之。
【譯文】第二是盜戒。它屬於性戒，包含輕與重。在性重戒之中，盜戒最難守護。所以各部律的解說，對其餘的戒只是約略地總述而已；至於討論到這條戒，各部都用三卷、五卷的篇幅來敘述。必須好好地披閱括究，才能免除過患。有人特別標出這條盜戒，收入私人的鈔記之中，這也含有勸誡的用意。終究必須普遍閱覽，所以按次序編列在這裡。

【093-0002】01_行事鈔/05b_卷中之一#28
【原文】初犯境之中。謂六塵六大，有主之物，他所吝護，非理致損，斯成犯法。若無主物，及以己物，或為緣差、境奪、心想、疑轉，雖有盜取之心，而前非盜境，並不結犯，唯有本心方便。問：何名無主物？答：《善見》云：子作惡事，父母逐去，後時父母死者，是物無主，用則無罪。《薩婆多》云：二國中間，兩邊封相，其間空地有物，是名無主。又云：若國破王走，後王未統，此中有物，又是無主。即如俗令，山澤林藪，不令占護；若先加功力，不得盜損。
【譯文】初犯境之中。是指色等六塵、地等六大，凡是有主人所有的財物，為他人所珍惜守護的，若以非正理的方式造成其損害損失，便構成了犯戒之法。如果是無主之物，或者是自己的物品，或者是因為外緣陰錯陽差、境界奪變轉移、內心認知顛倒錯想、疑念轉換，此時雖然動了偷盜竊取的心念，但眼前所取的並非真正的盜戒境界，並不結成根本重罪，唯獨結有本心動念時的加行方便罪。問：什麼叫做無主之物？回答說：《善見律毘婆沙》說：兒子作了惡事，父母將他驅逐出家門，日後父母過世，遺留下來的物品就屬於無主之物，取用它則沒有偷盜之罪。《薩婆多論》說：在兩國國境之間，兩邊皆設立了邊界封域標記（封相〔註：「封相」，指封界標識、界標〕），其間夾峙的荒置空地上若有物品，這稱為無主之物。又說：如果國家破滅、國王逃亡，後繼的新王尚未接管統治，此時國中留存的物品，也是無主之物。正如世俗法令所規定的，山林沼澤荒野，官府若明令不准任何人私自占據守護，則屬無主；但若有人已先對其施加人工力氣予以開墾守護，他人就不得擅自偷盜損壞。

【093-0003】01_行事鈔/05b_卷中之一#29
【原文】二成犯相中，總緣具六種：一有主物，二有主想，三有盜心，四重物，五興方便，六舉離本處。必具成犯。今依犯緣，次第解釋。就初緣中，大分三位：一盜三寶物，二盜人物，三盜非畜物。
【譯文】二成犯相中，總括的犯戒因緣具備六種：一是有主之物，二是心中作有主物想，三是生起偷盜之心，四是所盜財物達到重罪價值（滿五錢），五是發起偷盜的加行方便，六是將財物挪移搬舉離開了原來的位置。必須六緣完全具足才構成犯重罪。如今依照犯戒的因緣，依序逐一解釋。在第一個因緣「所盜之物」中，大致分為三個類別：一是偷盜三寶物，二是偷盜人類的物品，三是偷盜非人與畜生的物品。

【093-0004】01_行事鈔/05b_卷中之一#30
【原文】初中，先明知事人是非，然後解盜用差別。所以然者，若不精識律藏，善通用與者，並師心處分，多成盜損。相如後說。故《寶梁》、《大集》等經云：僧物難掌，佛法無主，我聽二種人掌三寶物：一阿羅漢，二須陀洹。所以爾者，諸餘比丘，戒不具足，心不平等，不令是人為知事也。更復二種：一能淨持戒，識知業報；二畏後世罪，有諸慚愧，及以悔心。如是二人，自無瘡疣，護他人意，此事甚難等。聖教如此，即為大誡。因即犯者，愚癡慢故。所以律云：我說此人，愚癡波羅夷等。
【譯文】第一部分之中，先要明白知事人的是非對錯，然後再解釋盜用僧物的差別。為什麼這樣呢？如果不能精確地認識律藏，善於通達「與」和「用」的分寸，都憑自己的主觀見解來處分，大多會造成盜損。其相狀如後面所說。所以《寶梁經》、《大集經》等經中說：僧物難以掌管，佛法沒有主人，我允許兩種人掌管三寶物：一是阿羅漢，二是須陀洹。為什麼這樣呢？其餘的比丘，戒不具足，心不平等，所以不讓這種人作知事。另外還有兩種：一是能清淨持戒、認識了知業報；二是畏懼後世的罪報，有慚愧心，以及悔過之心。這樣兩種人，自己沒有瘡疣，又能護念他人的心意，這件事非常困難等等。聖教既然如此，就是極大的告誡。因此犯戒的人，是由於愚癡、憍慢的緣故。所以律中說：我說這種人，是愚癡波羅夷等等。

【093-0005】01_行事鈔/05b_卷中之一#31
【原文】今料簡三寶物，四門分別：一盜用，二互用，三出貸，四將三寶物瞻待道俗法。
【譯文】現在簡別三寶物，分四門來說明：一、盜用；二、互用；三、出貸；四、將三寶物用來供給、招待道俗的方法。

【093-0006】01_行事鈔/05b_卷中之一#32
【原文】初中，盜佛物者。正望佛邊，無盜罪。由佛於物無我所，心無惱害故。但得偷蘭，以同非人物攝故。《十誦》：盜天神像衣，結偷蘭。《涅槃》亦云：造立佛寺，用珠華鬘供養，不問輒取，若知不知，皆犯偷蘭。若有守護主者，三寶物邊，皆結重罪；無守護主，望斷施主福邊結罪。故《鼻奈耶》云：若盜佛塔、聲聞塔等幡蓋，皆望斷本施主福邊結罪。故《五百問》中，塔上掃土，淨地棄之，不得惡用。《摩得勒伽》云：盜非人廟中物，有守護者犯重。《十誦》：盜佛圖物，精舍中供養具，若有守護，計直成犯。《善生》中，亦從守塔人得重罪，不望佛邊結之。所以約守物人結者，如盜人物中分別。必盜而供養，無犯：《薩婆多論》盜佛像，《十誦》中偷舍利；並淨心供養，自作念言，彼亦是師，我亦是師，如是意者，無犯。《摩得伽》中，盜佛像舍利，不滿五故，偷蘭；滿五犯重。《薩婆多》云：謂轉賣者，若佛塔中鳥死，及得餘物，但供塔用，餘用犯盜。
【譯文】第一部分中，先說盜佛物。若正對佛而言，並沒有盜罪；因為佛對物品沒有「我所」的執著，心中沒有惱害的緣故。只結偷蘭遮，因為它與非人的物品同類所攝的緣故。《十誦律》說：盜取天神像的衣服，結偷蘭遮。《涅槃經》也說：建造佛寺，用珠華鬘供養，不問而擅自取走，不論知道或不知道，都犯偷蘭遮。如果有守護的主人，在這種三寶物的情形下，都結重罪；沒有守護的主人，則就斷絕施主福德這一方面來結罪。所以《鼻奈耶》說：如果盜取佛塔、聲聞塔等的幡蓋，都就斷絕本施主福德這一方面結罪。因此《五百問》中說：塔上的掃土，要在乾淨的地方丟棄，不可以惡心使用。《摩得勒伽》說：盜取非人廟中的物品，有守護者的犯重。《十誦律》說：盜取佛圖之物、精舍中的供養具，如果有守護的人，計算價值而成犯。《善生經》中，也是從守塔人邊得重罪，不就佛邊結罪。之所以就守護物品的人結罪，如同盜人物中的分別一樣。如果是盜取而作供養，則沒有犯：《薩婆多論》說盜佛像，《十誦律》說偷舍利；只要是清淨心供養，自己作念說：他也是師，我也是師，有這樣的心意，就沒有犯。《摩得勒伽》中說：盜取佛像、舍利，價值不滿五錢的緣故，結偷蘭遮罪；滿五錢則犯根本重罪。《薩婆多》說：這是指轉賣的人而言；如果在佛塔中的鳥死了，以及得到其他物品，只供塔使用，用作其餘用途就犯盜。
