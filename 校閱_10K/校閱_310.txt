# 校閱材料　第310檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【310-0001】02_戒疏/01b_卷一上之一#59
【原文】【疏】答：「須得宗意，不有斯疑。一部律文，知何不說！制局篇聚，出世所行；旁兼心觀，徧被四部；時明餘戒，唯俗二眾。以義判文，初是當宗；餘二隨律，非本意也。如《涅槃》中『八穢』、『七治』、『十篇』、『五戒』，如《阿含》中『七滅』、『六報』、『犯聚』等相，豈是俗行？故名斯文『隨經之律』。」
【譯文】【疏文】回答道：「必須體得本宗的立意，就不會生起這樣的疑慮。一整部廣大的律文，有什麼內容是不能宣說的呢！然而其制定條規以防過失，是專門局限在律篇與律聚之中，這是出世僧眾所踐行的正軌；至於從旁兼帶宣說心性觀照，是普遍覆蓋到道俗四眾弟子的；其間有時闡明其餘戒法，則唯獨針對在俗的優婆塞、優婆夷二眾。如果依照法義來判斷律文，第一種才是本律的正宗核心；其餘兩種只是隨順律文而兼帶宣說，並非律藏最初安立的本意。這正如《大般涅槃經》中也談論了『八種不淨物』、『七種治罪羯磨』、『十篇戒』以及『在俗五戒』，又如同《阿含經》中也談論了『七滅諍法』、『六聚犯戒果報』與『犯戒聚相』等等，這些難道是世俗人的行持嗎？因此我們將經典中的這些律制文字稱為『隨順經藏而兼說的律相』。」

【310-0002】02_戒疏/01b_卷一上之一#60
【原文】【記】答中，初二句略止來問。「一」下，委釋。初明道教兼餘二教。「篇聚」即本道教。「旁兼心觀」即通道俗教。謂「五停」、「四念」、「五陰」等觀，竝見律文。道俗各二眾，是為「四部」。五八戒即唯制俗教。「以」下，總判兼正。律中說經名「隨律之經」。「如」下，次明通道俗教，亦兼二教。「《涅槃》『八穢』」即八不淨財，「七治」即七羯磨，「十篇」舊云即十戒，止是道教，「五戒」即俗教。「《阿含》中『七滅』」即七毗尼，「六報」謂六聚犯報，「犯聚」即六聚罪相。
【譯文】【記文】在回答的段落中，最前兩句簡要止息來者的發問。從「一」以下，予以詳細剖析。起初說明出家道教兼帶了其餘兩種教法。「篇聚」指的就是原本的出家道教。「旁兼心觀」指的就是兼通道俗二眾的教法。所謂「五停心觀」、「四念處觀」、「五陰觀」等觀法，都可以在律文中見到。出家男女與在家男女各有二眾，合稱為「四部」。五戒八戒指的就是唯獨制約俗人的教法。從「以」以下，總體判斷何者為兼帶、何者為正宗。律藏中兼說經教的稱為「隨律之經」。從「如」以下，其次說明兼通道俗的經藏教法，同樣兼帶了其餘二教。《涅槃經》中的「八穢」指的就是八種不淨財物，「七治」指的就是七種羯磨僧事，「十篇」古德相傳指的就是十戒，這純粹是出家道教，「五戒」則是在家俗教。《阿含經》中的「七滅」指的就是七滅諍法，「六報」指的是六聚罪相的犯戒果報，「犯聚」指的就是六聚罪的具體相狀。

【310-0013】02_戒疏/01b_卷一上之一#71
【原文】【疏】「戒」有何義？義訓「警」也。由警䇿三業，遠離緣非，明其因也。
【譯文】【疏文】「戒」具有什麼意涵呢？在字義訓詁上是「警惕」的意思。由於它能夠警策行者的身口意三業，使之遠離造作過失的緣境，這說明的是修行因地上的功用。

【310-0014】02_戒疏/01b_卷一上之一#72
【原文】【記】釋義中，初科。以理裁酌，故云「義訓」。「戒」為能警，「三業」即所警。「警䇿」是作，「離非」即止。此約心用一持以顯戒義，對下「木叉」，故言「因」也。
【譯文】【記文】在解釋義理的第一個科判中。依據理體來加以裁斷斟酌，所以說是「義訓」。「戒法」是能發揮警策作用的，「三業」就是被警策的對象。「警策」屬於積極修善的作持，「離非」屬於止息惡業的止持。這是依據心念運作於一念持守，來顯揚戒的內涵，相對應於下文的「木叉（果）」，所以說是「因」。

【310-0015】02_戒疏/01b_卷一上之一#73
【原文】【疏】如古所傳「防非禁惡」以解於「戒」。然「戒」通善惡，「律儀」亦然，不可偏舉以釋「戒」義。
【譯文】【疏文】如同古德所相傳的，都是以「防制非理、禁絕惡行」來解釋「戒」字。然而「戒」一詞本來就貫通善與惡兩方面，「律儀」一詞也是如此，不能單單偏執一端來解釋「戒」的定義。

【310-0016】02_戒疏/01b_卷一上之一#74
【原文】【記】斥古中。先出古解。「然」下，斥局。如屠殺者，受「惡律儀」，以殺為「戒」。但對境名「戒」，通禁名「律儀」，故云「亦然」。戒既通惡，古解局善，即是「偏舉」。
【譯文】【記文】在斥責古德見解的段落中。先列出古代論師的解釋。從「然」以下，斥責其定義過於狹隘。例如從事屠宰殺生的人，領受了「惡律儀」，就是以殺生為其誓受之「戒」。只要是面對外境所立的誓約都可稱為「戒」，普遍性的禁令誓願都稱為「律儀」，所以說「亦然」。戒既然通於惡戒，古代的解釋卻僅僅局限在善戒，這就是「偏執一端」。

【310-0017】02_戒疏/01b_卷一上之一#75
【原文】【疏】如經論中，多從善戒約義得名。試為舉之。如《智論》云「尸羅者，此云性善」，此從體說；如《心論》、《善生》云「別解脫調伏」及「學調諸根」，此就心說；如諸論中「作」、「無作戒」，此就業說；或名「清涼」、「迮隘」、「上天」，此舉喻明，就能說也；或云「以戒自觀，說是戒經」，此就教說也。諸如此相，其例不一，但偏善行，不通惡性。
【譯文】【疏文】在經論之中，大多是順著善戒的方向來界定義理以獲得其名稱。我們試著來列舉看看：如同《大智度論》說「尸羅，在漢語中譯為性善」，這是從戒的本體來立論；如同《阿毗曇心論》、《善生經》所說的「別解脫調伏」以及「修學以調伏諸根」，這是從心性的克制來立論；如同各部論典中所說的「作戒」與「無作戒」，這是從業力的運作來立論；或者將戒稱為「清涼」、稱為「迮隘（狹窄無容隙）」、稱為「上天」，這是列舉譬喻來說明，是就戒的功能來立論；或者有的經論說「以戒自觀，說是戒經」，這是依據能詮的教法來立論。諸如此類的法相，其例證各不相同，但全都是偏向於善法行持來立說，並不貫通惡的自性。
