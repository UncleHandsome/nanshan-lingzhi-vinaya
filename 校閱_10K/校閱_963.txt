# 校閱材料　第963檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【963-0001】資持記/02f_上一下#43
【原文】至下，二引翻譯證。疏云：翻三衣為臥具敷具，略得其相，失其本體等〔如減六年羯磨〕。三詁訓證。字訓義同，故云兩得。故下一句，結上三例。初問白讀。謂對眾公白而讀，明非暗誦也。如前所斥，恐生異計，故此決破。答中，初句判定。雖下，申理。無明決者，非正教所斷。以義求者，生下所明。
【譯文】下文「至於（至）」字以下，第二點是引用翻譯文獻作為明證。《羯磨疏》說：將三衣翻譯成「臥具」或「敷具」，僅僅大致抓住了它的外在形象，卻失去了原本的體性本質等〔例如未滿六年另作新臥具的羯磨文便是如此〕。第三點是字詞訓詁的明證。文字訓詁的義理完全相通，所以說兩者都可以採用。因此最下面的一句話，總結了上述三類引例。首先針對看著文獻宣讀（白讀）提出發問。這意思是說當著大眾公開看著本子讀出來，顯然不是背誦。正如前面所痛斥的那樣，深怕後人產生怪異偏差的見解，所以在此予以決斷破除。在解答的內容中，第一句作了斬釘截鐵的判定。下文「雖然（雖）」字以下，申述其中的道理。之所以說「沒有明確決斷」，是因為根本沒有正統教法直接明文判定此事。若是「依照義理來推求」，就會引生出下文所要闡明的論述。

【963-0002】資持記/02f_上一下#44
【原文】戒本例中。言相似者，告眾義同故。故下，引示。不得重說者，此明多人共往學誦，故不令重。準下，推制意。呪術例中，初明俗呪。越謂言乖，散謂心亂，反上專正也。故下，明道呪。羯磨下，合例。況，比也。律序顯者，彼云：神仙五通人，造設於呪術；如來立禁戒，半月半月說。〔上喻下法。
【譯文】在以戒本為例的段落中。所謂「性質相似」，是因為兩者面向大眾宣告的意義完全相同的緣故。因此下文引述說明。所謂「不得重複宣說」，是指多個人共同前往學習背誦時，為了維持專注所以不允許重疊雜亂宣說。下文「準照（準）」字以下，推究佛陀立制的意圖。在以世俗咒術為例的段落中，首先說明世俗咒術。所謂「越」，是指言詞乖謬；所謂「散」，是指心念散亂，這與前面所要求的專注端正恰恰相反。因此下文說明佛門出世間的咒術。下文「羯磨」字以下，將兩者加以比照相合。所謂「況」，就是比喻對照的意思。律藏序文說得非常明白，那裡說道：具有五種神通的世間仙人，創造設計了世俗的咒術；如來世尊則創立了戒律禁戒，每半個月每半個月向大眾宣說。〔上面是以仙人咒術為比喻，下面是以如來戒律為法體。〕

【963-0006】資持記/02f_上一下#48
【原文】至下，顯局。治舉違惱，或致破僧；僧不舉僧，律文明制。治舉可爾。乞為受懺，竝是順情，何以同禁不得至四。學者尋之。引證中，《四分》證上乞為。《五分》下，彰部別。和諫亦制，故云通也。《母論》及下《四分》，竝證治舉。文中四五伴可諫，不慮擯治；則知不得加眾明矣。
【譯文】下文「至於（至）」字以下，顯明受局限不得通融的情況。治罰與舉發罪過會引起違逆與惱怒，甚至可能導致僧團分裂破僧；僧團不得舉治僧團（被舉治者人數不得達四人），這是律文中的明確規定。治罰與檢舉固然是如此。然而乞求他人為自己受戒、為自己懺罪，全都是順應人情的好事，為什麼同樣被嚴格禁止不得達到四人？這需要後世學者深入探究尋思。在引用證據的段落中，《四分律》證明了上面所說的「乞求為其作法」一事。下文「《五分》（五分）」字以下，彰顯出不同部派律典的規定。調和諍論與規諫時也同樣受到限制，所以說是「通貫於各項羯磨（通也）」。《毘尼母論》以及下文引用的《四分律》，全部都是用來證實舉治罪過的規定。經文中說有四、五個同伴尚且可以從旁勸諫，不用擔心遭到僧團擯除治罰；由此便能清楚明白，羯磨治罰絕不可施加於四人僧眾，其理至為顯明。

【963-0007】資持記/02f_上一下#49
【原文】十五種默者，〈雜犍度〉中，舍利弗見作非法，佛聽默然；因說五法不應默，若作如法羯磨〔事雖如法，緣有差違，須訶令止。〕，若得同意伴〔不慮眾治，此同《母論》。〕，若見小罪〔眾有犯輕，僧體不失。〕，為作別住〔謂在界外〕，在戒場上〔界中別界，此二處非。〕；
【譯文】關於十五種保持沉默（十五種默）的行相。在〈雜犍度〉中，舍利弗尊者看見有人施行非法羯磨，佛陀聽許他可以保持沉默；佛陀隨即宣說了有五種情況「不應當保持沉默」：如果僧團正在舉行合乎戒法的羯磨〔事情雖然如法，但緣由若有差錯違背，就必須出言呵責使其終止〕；如果找到了意見相同的同伴〔不用擔心會遭到僧團治罰，這一點與《毘尼母論》相同〕；如果發現的是輕微的小罪〔大眾中有人犯了輕罪，僧團的本體並未喪失〕；在別處結界外作羯磨〔是指在結界之外進行〕；在戒場之上舉行〔在結界之中另立小界，這兩種處所都是不合法的〕；
