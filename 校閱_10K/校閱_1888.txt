# 校閱材料　第1888檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1888-0001】03_業疏/21b_卷四之四#23
【原文】次科《增一阿含經》。初敘如來自恣，示同凡法故，垂範後世故，令眾省己故，使折我慢故。「舍利」下，身子稱歎三業無過，具三不護故。「不度者度」，明其慈愍也；「作眼目」者，明其示法也；「作醫王」者，明其濟物也。且就教限，故云大千
【譯文】下一科引用《增一阿含經》。起初敘述如來行自恣，是為了示現同於凡夫之法故，為了垂示模範於後世故，為了令大眾反省自己故，為了使其折服我慢故。自「舍利」以下，舍利弗稱讚如來三業沒有過咎，具足三不護的緣故。「度化未度者」，說明其慈悲愍念；「作眼目」，說明其開示正法；「作醫王」，說明其救濟萬物。且就教化化境的界限而言，所以說是三千大千世界。

【1888-0002】03_業疏/21b_卷四之四#24
【原文】就文分五：「大德」者，正告五德，求聽說也；小者言「長老」；「眾僧今日自恣」者，牒僧恣時也；「我某甲亦自恣」者，下應上法，縱陳過咎，恣僧舉也；「若見聞疑罪」下，我有三根，慈誨賜示；五、「我若見罪」下，從聞悔過，成我清美。所以三說者，表仰囑之勤，非是濫託也
【譯文】就文詞而言分為五部分：「大德」，是正式告知五德比丘，請求允許陳說；年少者則稱呼「長老」；「眾僧今日自恣」，是提起僧團自恣的時刻；「我某甲亦自恣」，是以自身下位呼應大眾上位之法，坦率陳述過失，任憑僧眾舉發；「若見聞疑罪」以下，是說若我有依見、聞、疑三根所見的罪過，祈求慈悲教誨賜予指示；第五、「我若見罪」以下，是表示順從聽聞而悔改罪過，成就我清淨美德。之所以要說三遍，是為了表達懇切仰賴囑託的誠意，並非隨便濫託。

【1888-0003】03_業疏/21b_卷四之四#25
【原文】釋法陳詞中初文。初釋文句有五，牒文顯意，能所自別。後示偏數，少略多繁，故止三說
【譯文】在解釋作法陳詞的第一段文字中。起初解釋文句分為五節，照錄文句顯發意義，能自恣與所自恣自然區分開來。最後說明遍數，太少則顯得簡略，太多則顯得繁冗，所以止於說三遍。

【1888-0004】03_業疏/21b_卷四之四#26
【原文】上且一途釋其大小。更通論之，長老乃大，故經中「長老舍利弗」、「賢者阿難」等。律中不定，今略釋之：行解具故，名為大德；年臘高遠，名為長老，如俗中云長老之言也
【譯文】上面姑且按照一種說法來解釋尊長與後學的稱呼。若再通泛論述，長老其實是指尊長，所以經典中有「長老舍利弗」、「賢者阿難」等稱謂。律典中稱呼並不固定，如今略作解釋：德行與解悟俱全的緣故，稱為「大德」；年歲戒臘高遠的，稱為「長老」，如同世俗中所說的長老一詞。

【1888-0005】03_業疏/21b_卷四之四#27
【原文】次正明中，初科又三：初點前局；「更」下次示名通，經召尊上，非專少小；律但隨稱，亦不以此而分尊卑，故曰不定。「今」下二釋名義，反明大德名通，長老名局。俗禮召鄉中父宿為長者、鄉老，皆尊敬之言
【譯文】在接下來的正明內容中，第一科又分為三：起初指出前面的解釋有所局限。自「更」以下接著說明名稱互通，經典中用來稱呼尊長，並非專指少年後進；律典中只是隨順稱呼，也不以此來截然區分尊卑，所以說不定。自「今」以下第二解釋名詞義理，反過來顯明「大德」名稱意涵較廣，「長老」名稱意涵較局限。世俗禮儀稱呼鄉里中具德望的父執宿老為長者、鄉老，都是尊敬之辭。

【1888-0006】03_業疏/21b_卷四之四#28
【原文】前單牒者，但告五德；後雙牒者，勤重之志在僧故也。何以知然？律中「不得疾疾竊語」，故是對僧，令知名目，理須清朗，擬眾通淨也。《僧祇》亦云「長老及僧自恣說」，又知通告也
【譯文】先前單獨提起（稱呼大德）的，只是告知五德比丘；後來雙重提起（兼稱大眾）的，是因為殷勤鄭重的心志在於整個僧團的緣故。何以得知是這樣呢？律典中說「不得匆忙急促、低聲竊語」，所以是對著全體僧眾，令大眾明白名目事項，理應音聲清亮明朗，以便使全體大眾普遍清淨。《摩訶僧祇律》也說「長老及僧自恣說」，由此可知也是通告全體大眾的。

【1888-0007】03_業疏/21b_卷四之四#29
【原文】次科，初示前後單複。「何」下推釋所以。先準本律，「疾疾」急語，「竊語」聲低，竝犯吉罪。後引《僧祇》，「長老」局五德，「及僧」通大眾。準今詞中，「大德」召五德，「長老」對告僧而不云僧者，意以下至別人知我三根，亦求舉過，如羯磨云「誰諸長老忍」，即僧中召別也
【譯文】下一科，起初說明前後文辭的單稱與雙稱。自「何」以下推尋解釋其緣故。首先依據本律，「疾疾」是指言語急促，「竊語」是指音聲低沉微弱，都犯突吉羅罪。隨後引用《摩訶僧祇律》，「長老」局限於五德比丘，「及僧」通於全體大眾。依照現今的詞句，「大德」用以稱呼五德比丘，「長老」用以對告僧眾卻不直接稱「僧」者，用意是下至個別僧人若知道我的三根罪過，也請求其舉發，如同羯磨中所說「哪位長老贊同」，就是在僧眾之中稱呼個別僧人。

【1888-0008】03_業疏/21b_卷四之四#30
【原文】問：前對小已得，如文中云「大德」不？答：具德差遣，咸所推敬，何得不稱？《善見》云：「大為大德，小為長老。」且分二人，義通上下，餘不可盡也
【譯文】問：前面若是面對戒臘較少者，可以如文中所說稱之為「大德」嗎？回答：既是具足德行而受僧差遣的人，都是大眾所推崇尊敬的，怎能不稱大德？《善見律毗婆沙》說：「年長者為大德，年幼者為長老。」這姑且是區分兩類人，法義實際上通於上位與下位，其餘不可以偏概全。

【原文】問答中，相美之稱，不論大小。《善見》所解，一往揀別
【譯文】在問答之中，讚美尊崇的稱呼，無論年長年幼都可以使用。《善見律毗婆沙》所作的解釋，只是就大體而言所作的初步分別。

【1888-0010】03_業疏/21b_卷四之四#32
【原文】其小五德在第二上座前立，待眾首竟，方互跪對作；大五德者下至第三前立。如是展轉，廣如鈔中所出文也。餘有如文，至時口解
【譯文】那位資歷較淺的小五德在第二位上座面前站立，等待首座自恣完畢，才互跪（胡跪）相對作法；大五德則走下到第三位面前站立。像這樣展轉進行，詳情正如《事鈔》中所引述的條文。其餘事相正如律文，臨事時再口頭解說。

【1888-0011】03_業疏/21b_卷四之四#33
【原文】次行事中，從上至下次第對說。一跪一立，不容竝跪，令眾委悉，揀別無濫。今有竝跪令說，非法獲罪。下指如鈔，見自恣篇，彼文具出事儀成否，尋以對之，避繁不錄
【譯文】在接下來的行事內容中，是從上座到下座依序相對陳說。一人長跪、一人站立，不容許兩人同時長跪，這是為了讓大眾詳審明白，嚴加簡別而不致紊亂。如今有人讓兩人同時長跪陳說，這是非法的並結罪。底下指示如《事鈔》，詳見〈自恣篇〉，該文具體列出了法事儀軌的成與否，可尋求對照，為免繁冗在此不予抄錄。

【1888-0012】03_業疏/21b_卷四之四#34
【原文】就略恣中，對五德者有二略：二說、一說也。親對五德，緩念自知，任時量事，不須和白。不對五德有三略者，則百人為五十對，一時彼此三說、再說、一說。所以須白者，既不對五德，成和在僧，故須先和，後方如作也
【譯文】在略法自恣中，面對五德比丘的略法有兩種：說兩遍或說一遍。親自面對五德比丘，事情緩急自己心中清楚，隨任當時情況衡量事務，不需要作白和僧。不面對五德比丘的略法有三種，就是百人分成五十對，同時彼此相對說三遍、說兩遍或說一遍。之所以必須作白，是因為既然不面對五德比丘，成就和合在於僧眾，所以必須先作白和僧，然後才如法作自恣。

【1888-0013】03_業疏/21b_卷四之四#35
【原文】次略法中，八難餘緣，行廣不及，故開略說。初對五德略有二：本廣三說，緣緩減一，緣急減二。次不對五德有三，先須作白告僧令知。通前五略，廣略共有六種自恣
【譯文】在接下來的略法內容中，若遇八難等其餘因緣，來不及推行廣法，所以開許略說自恣。起初面對五德比丘的略法有兩種：原本廣法是說三遍，因緣較緩則減為兩遍，因緣緊急則減為一遍。其次不面對五德比丘的略法有三種，必須先作白告知僧眾令大家知曉。通計前面五種略法，廣法與略法共有六種自恣。

【1888-0014】03_業疏/21b_卷四之四#36
【原文】對首恣中，四人不受第五人欲者，通須盡集，則展轉得成僧法。若有四人，不得如僧，以所差人不足數故，但彼此三說也
【譯文】在對首自恣中，四個人不能接受第五人的受欲，必須全體到齊聚集，這樣才能展轉成就僧法。如果只有四人，則不能像僧團廣法那樣行事，因為所差派的人不足法定人數的緣故，只能彼此相對說三遍。
