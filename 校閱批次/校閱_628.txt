# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【628-0003】04_比丘尼鈔/06b_卷下之下#16
【原文】第一羯磨中五人得作賞勞分衣羯磨若四人者止得分衣不成賞勞以僧不滿故寧可羯磨後將衣物口和賞勞母論云由四人中牒一人入羯磨餘三不成僧故今立法者令瞻病人將亡人輕重二物並集僧中重物不可勝舉多者知數已直付僧庫亦得晝日作法彌善不得閉門限約客尼以通十方理無私背故婆論云白日閉門已不打鐘打鼓食者名盜僧食罪又此分衣不成而此物者人人各有分而有心限約客者各犯微塵數偷蘭遮故善生經云盜亡比丘衣物者若未羯磨望十方僧得罪若羯磨已望同羯磨僧滿五得夷不滿偷蘭看病人應近物邊長跪執物捨之若無看病尼維那捨之亦得。

【628-0028】04_比丘尼鈔/06b_卷下之下#41
【原文】第十雜法者若尼在莊園及私伽藍死者應如寺法分之云何名私伽藍如在村坊聚落俗人共造一院唯三寶受用白衣不通居止兼有周帀籬牆等即名伽藍不要結界方號伽藍者若有看病尼重物入尼本寺輕物入現在寺若有四人已上見亡人物者則須羯磨分若先無界結已作法分三人已下對首分以不同白衣家死故十誦比丘衣鉢寄在尼寺者還比丘索取分尼寄比丘衣鉢僧寺亦爾若無人守掌者事同白衣家法故此律云若比丘尼無住處白衣家死有信心檀越應掌錄此物若有五眾出家人先來者應與若無來者應送與近僧伽藍義云雖知白衣家有亡物要須手捉目覩作屬己之意方得此物反此不成後來尼應共分若俗人已攝屬己者盜財義成不得反奪若白衣畏罪還尼者得取若僧尼一時共見亡物者若是尼亡屬尼僧亡屬僧不得共攝以各是知法人故不須作法直爾攝屬己意則得不比莊寺以彼閑預要須作法若僧尼前後來見者屬先見者得互攝取也。
【譯文】第十項為雜法，若尼僧在莊園及私設伽藍中死亡，應當依照僧寺之法進行分配；何謂私設伽藍？例如在村坊聚落中，俗人共同建造一處院舍，純粹由三寶受用，不許白衣隨意居留，且周圍建有籬笆牆垣等，即稱為伽藍，不一定要結大界才叫伽藍；若有看病尼，重物歸入該尼僧原屬寺院，輕物歸入現在所在地之寺院；若有四人以上見到亡人物品，則必須作羯磨分配；若原先無界，結界後依法羯磨分發；若是三人以下，依對首法分發，因為此處不同於白衣家中死亡之故；《十誦律》說比丘衣缽寄存在尼寺中，仍歸比丘僧索取分配，尼僧寄存在比丘僧寺的衣缽亦然；若無人看管守護，情況如同白衣家法；因此本律說，若比丘尼在無常住處的白衣家中死亡，有信心的施主應當掌管記錄該物，若有五眾出家人最先到來者應當給予，若無人前來，應當送交鄰近的僧伽藍；教理認為：雖然明知白衣家中有亡人物品，必須親手拿取、親眼目睹，並生起歸屬自己的心念，才能得到此物，反之則不能成立，後來的尼僧應當共同分配；如果俗人已經將物品收歸己有，偷盜僧財之罪即已成立，出家人不得反向強奪；若白衣畏懼罪業主動還給尼僧，則可以收取；若僧、尼同時見到亡人物品，如果是尼僧死亡歸屬尼僧，比丘死亡歸屬比丘，不得共同佔有，因為彼此都是知法之人；不須另作羯磨法，只要直接生起歸屬自己之意即可獲得，這不同於莊園寺院，因為在莊園寺院等安閒處所必須依法作羯磨；若是僧尼先後前來見到者，歸最先見到之人所有，互相皆可這樣獲取。
