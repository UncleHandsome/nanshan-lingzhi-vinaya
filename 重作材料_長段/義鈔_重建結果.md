# 義鈔重建結果（只用小單位）

## 做法

- 只用 `義鈔/_終審` 的小單位
- 不用 `_長段` 大單位
- FIX 用 `_終修/回覆`，PASS 用 `_終審`

## 結果

```text
單位：207
有位置：188
未定位：19
缺口：14
重疊：164
```

## 缺口

```text
只用小單位：14
```

## 重疊 164

不是長段造成，因為已經沒有長段。

這代表 207 個「小單位」本身區間就重疊。

可能原因：

- `■ 鈔文（原文）` 區塊含前後文
- 同一段被拆進多個終審單位
- source 截斷位置不準

## 判定

```text
長段大單位：已移除
小單位：仍有 164 重疊
```

所以問題不在長段，是終審小單位自己的區間不乾淨。
