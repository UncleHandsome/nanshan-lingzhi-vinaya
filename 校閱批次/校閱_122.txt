# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【122-0001】02_戒疏/05c_卷二上之一#54
【原文】【註】佛在毗舍離國。時，須提那子，持信出家，後還本村，與其故二共行不淨。諸比丘察知已，言：「當於如來清淨法中，於欲無欲，能斷渴愛，破壞巢窟，除眾結縛，愛盡涅槃。云何乃作如是惡事？」以過白佛。即集眾僧，知時義合，取自言已，佛訶責云：「汝所為非，非威儀，非沙門，非淨行，非隨順行，所不應為。」告諸比丘：「我無數方便，說斷欲法，越度愛結。」又說此欲如火如炬，乃至如刀如戟。如是訶已，「此為癡人，多種有漏，最初犯戒。今當結戒，集十句義：一、攝取於僧；二、令僧歡喜；三、令僧安樂；四、未信者令信；五、已信令增長；六、難調者調順；七、慚愧者安樂；八、斷現在有漏；九、斷未來有漏；十、正法久住。」諸戒例爾，下並略之。欲說戒者，當如是說。
【譯文】【註文】佛陀住在毗舍離國。當時，迦蘭陀村長者須提那的兒子，出於正信出家修道，後來回到原籍村落，與過去的妻子行了不淨法。諸位比丘察知這件事之後，責備他說：「你應當在如來的清淨教法中，於愛欲中心無愛欲，能夠斷除飢渴般的貪愛，破除輪迴的巢穴，消除一切煩惱纏縛，達到貪愛永盡的涅槃境界。為什麼竟然做出這種惡事？」於是將他的罪過向佛稟白。佛陀隨即召集僧眾，在時間與法義都合適的情況下，審問取得他自己的供詞後，佛便嚴厲呵責道：「你的所作所為完全不對，不合僧伽威儀，不是出家沙門的行徑，不是清淨戒行，不是隨順聖道的行為，全是你絕不應當做的事。」隨後佛告誡大眾：「我用無數的善巧方便，宣說斷除貪欲的法門，教大家超越貪愛結縛。」佛又宣說這種愛欲如同猛火、如同火炬，甚至如同刀劍戟戈般殘害身心。如此呵責之後，佛說：「這真是愚癡之人，種下了極多流轉生死的有漏罪因，是僧團中最初犯戒的人。如今應當制定戒律，這聚合了十種利益：一、為了整肅攝受僧團；二、使僧團歡喜；三、使僧團安樂；四、使未生起信心的人產生信心；五、使已有信心的人信念增長；六、使難以調伏的剛強者得以調伏順服；七、使知慚愧的人身心安穩；八、斷除現在世的有漏煩惱；九、斷除未來世的墮落因緣；十、令如來正法能夠長久住世。」其餘各條戒都是以此類推，以下皆省略不提。若要宣說這條戒法，應當這樣宣說。

【122-0005】02_戒疏/05c_卷二上之一#58
【原文】【記】戒緣，初文，敘前段中。託緣制立，故云「結戒」。呵過立治，名為「行法」。對後說戒，即是眾法。「行」下，明次段。「緣依」，即目說由，說戒警行故為緣，以行憑教故為依。前制治過，名「行益」；後說弘傳，名「教益」。
【譯文】【記文】在因緣的第一部分、敘述前半段之中。藉由事緣而制定戒規，所以稱為「結戒」。呵責過失而確立對治法則，稱為「行法」。與後面說戒相比，這屬於全體僧團的羯磨共法。「行雖成顯」以下說明第二部分。「緣依」是指宣說戒相的由來，透過定期說戒來警惕戒行，所以說是「緣」；修行必須憑藉教條規範，所以說是「依」。前半段制戒以對治過失，稱為「行門利益」；後半段定期宣說傳布，稱為「教化利益」。

【122-0016】02_戒疏/05c_卷二上之一#69
【原文】【疏】如《律．結集》中，犯有戒相，恐涉妄列，必須三處審同所由。若乖其本，雖佛所說，亦不依用。故彼文云：「何處制？因誰制？何因故制？」如是諸戒，例此三徵。末代持律，亦準三責，如四廣說，可以求之。
【譯文】【疏文】如同《律典．五百結集》中，凡是要認定犯戒的戒相，唯恐涉入虛妄不實的陳述，必須在三種具體處所審核查驗其原委。如果違背了原本的事實，即使傳說是佛陀所說的，也不能依信採用。所以該文中記載：「是在何處制定的？是因為誰而制定的？是因為什麼緣故而制定的？」所有的戒條，都依照這三種方式來盤問。後世持律的人，也應當準照這三種要點來責問審定，就如同「四大廣說」中所指示的原則，可以從中尋求審判的依據。

【122-0017】02_戒疏/05c_卷二上之一#70
【原文】【記】緣起中，初科。初分文。「如」下，引示。初敘本集意。言「三處」者，初即住處，二、三即目人、犯為處。「故」下，次引彼文，即《五百結集》中，始自初戒，終至眾學。迦葉一一舉此三事為問，波離隨問答之，集成《律藏》。「末」下，明今準用。「四廣說」，如別所引。《律》明四說，正為末世辦定是非。舉彼例此，令依處判。
【譯文】【記文】因緣科判中的第一科。首先劃分經文。「如律」以下引用律文予以說明。首先敘述當初結集律藏的本意。所謂「三處」，第一是指住處，第二、第三是指將涉案的人與犯戒的事當作關鍵之處。「故彼文云」以下接著引用五百結集的律文，也就是《五百結集》中從第一條波羅夷戒開始，一直到眾學法為止，大迦葉尊者一一提出這三件事作為提問，優波離尊者隨著提問一一回答，最後結集成這部《律藏》。「末代」以下說明現在也應準照使用。「四大廣說」如其他律典文獻所引用的那樣。律中說明四廣說，正是為了讓末世僧團判定是非真偽。引用那個例子來對照此處，是為了讓人在判斷犯相時必須依據具體事證。

【122-0019】02_戒疏/05c_卷二上之一#72
【原文】【記】住處中。云「廣嚴城」者，「廣」謂土境之大，「嚴」即風物之美。昔波羅奈國王夫人，生一肉團，羞媿不已，封之金函，棄於江內。有一道人，見而取之。後生一兒一女，有大人相，乃立為王。子孫漸多，三展其國，故曰「廣嚴」。
【譯文】【記文】在駐留處所的解釋中。稱作「廣嚴城」的理由，「廣」是指國土疆域廣大，「嚴」是指風土景物莊嚴美好。相傳往昔波羅奈國王的夫人，生下了一個肉團，心中感到無比羞愧，便將它封在金盒子裡，丟棄在江水之中。有一位修道人看見並收留了它。後來裡面誕生了一男一女，相貌具有偉人的特徵，眾人便立那男孩為王。後來子孫繁衍日增，三次擴展王國的城郭，所以稱之為「廣嚴」。

【122-0025】02_戒疏/05c_卷二上之一#78
【原文】【疏】就訶責中，初明比丘，後明佛者？欲顯比丘同徒同住，過犯先知，故前列也。如來三達，知見常圓，示同化儀，位尊殊隔，義無先知，故在後列。又解，理越常情，絕於鑽仰。今為同徒所訶，分當己位，容可勵己，剋意不為。後明佛訶者，玄軌之教，出於高軌，切磋之益，義存我友。亦彰比丘言無虗設，互相敦崇，用成同濟之道。餘語略之，下更不解。
【譯文】【疏文】在呵斥譴責之中，為何先敘述比丘同修的呵責，其後才敘述佛陀的呵責呢？這是為了顯明比丘們同屬同一個道場、同住在一起，過失必定是同儕先察覺知道，所以列在前面。至於如來的智慧通達三世，知見永遠圓滿無礙，只是為了示現符合教化的儀軌，且佛的尊位殊勝超絕，在世俗情理上不應表現為私下搶先察知，所以列在後面。另一種解釋是，佛陀的境界超越凡常之情，高深到無法揣摩仰望。如今先受到同修同伴的呵責，身分地位彼此相當，反而容易激勵自己，下定決心不再違犯。隨後才寫佛陀的呵斥，是因為根本大法的戒律教導，必須由至高無上的聖者確立規範，但同儕間切磋砥礪的助益，則寄託在道友身上。這也彰顯了比丘們的規勸並非虛設，彼此互相敦勉尊重，以成就共同修行解脫的道業。其餘的文句從略，以下各戒不再重複解釋。
