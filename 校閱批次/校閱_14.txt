# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【14-0001】03_業疏/17a_卷三之六#116
【原文】是知聖說具四種義：一、慈心益物；二、稱機設藥；三、善達開遮，非但開於中下服諸好衣，亦開上士有病及無糞衣聽受施服，由本通道，故有斯開，故《雜心》云「若僧和合，令超昇離生，得果漏盡，坐禪、學問、思惟業生」，餘之三依，例此可比；四者、佛說乞食等四能生道緣，正語等八能生道因，稱法而談，無謬濫過。
【譯文】由此可知佛聖的宣說具備四種深義：第一、以慈悲之心利益眾生；第二、契稱根機施設藥方；第三、善巧通達開許與遮止，不僅開許中下根器穿著各種美好衣服，也開許上等修道之士在患病及沒有糞掃衣時聽許受用施主衣服，由於其根本目的是為了通達聖道，所以才有這樣的開許，因此《雜阿毗曇心論》說「如果僧團和合，能令行者超昇出離生老病死，證得道果、斷盡煩惱漏失，從而引生坐禪、研學、思惟等功德業」，其餘三種四依，照此類推即可比知；第四、佛說常乞食等四種法能成為引生修道的助緣，正語等八正道能成為引生聖道的正因，稱合法理而宣談，毫無謬誤混濫之過失。

【14-0002】03_業疏/17a_卷三之六#117
【原文】次科初總舉。「一下」，別列。初是本誓，二即鑒機，三能達教。一開已後，通被三根；仍引《雜心》，顯示開聽必須存道。僧和無諍，容可進道；得果對超昇，漏盡對離生。上舉施衣，餘三有開，意不殊此。四即彰益，四依資道，故得名緣；八正修心，故云道因。
【譯文】次科起初總括標舉。自「一下」句起，分別羅列。第一項是如來的根本誓願，第二項是審鑒根機，第三項是通達教法。開許一經確立之後，便普遍普被三種根機；文中仍舊引用《雜阿毗曇心論》，顯示准聽開許的前提是內心必須存有求道之念。僧團和合而無諍論，才能進修道業；「得果」對應於「超昇」，「漏盡」對應於「離生」。上面舉出接受施衣，其餘三種四依也有開許，其意旨與此並無不同。第四項是彰顯利益，四依法資助修道，所以稱為道緣；八正道用於修治心神，所以稱為道因。

【14-0003】03_業疏/17a_卷三之六#118
【原文】調達效佛，乃說五法，唯制不開，謂納衣、乞食、樹下、不食酥鹽等也。一則不具四義，如上反說；二則顛倒說法，令墮邪見，謂語業八為道緣，乞食等五說為道因，逾於八正，廣說相似，惑亂正依，致令愚叢猶學此道，即調達部也。
【譯文】提婆達多仿效佛陀，竟然創立五種行法，只有遮制而沒有開許，也就是穿著補納衣、常乞食、樹下坐、不吃酥油與鹽等。一方面他不具備前述四種深義，正如上面反面所言；另一方面則顛倒說法，使人墮入邪見，把八正道（語業等八法）說成是修道的助緣，把乞食等五種法說成是得道的正因，凌駕於八正道之上，廣泛宣說似是而非的道理，惑亂了正法所依，致使愚痴的僧眾仍去修學這套教法，這便是提婆達多部派。

【14-0004】03_業疏/17a_卷三之六#119
【原文】邪法中，初敘立法。調達，具云提婆達多，此云天熱，生時諸天心熱惱故。立邪三寶，破佛正法；五法即法寶也。酥鹽，以酥脂煑鹽，彼為珍味故；而言「等」者，等取魚肉。「一下」，次顯過。不具四義：一、無慈心，二、不識機，三、不曉教，四、無利益。二、顛倒說法，以因為緣，以緣為因，即用五法以貶八正也。逾，過也。相似者，五中前三名相似語，後二為妄語。愚叢猶學，至今西竺尚有遺風。
【譯文】在論述邪法的段落中，起初敘述立法的緣由。調達，具體音譯為提婆達多，漢譯為「天熱」，因為他出生時令諸天心中感到熱惱之故。他創立邪三寶以破壞佛陀的正法；五法就是他所立的法寶。所謂酥鹽，是指用酥油油脂煎煮鹽，在彼處被視作珍貴美味；說「等」字，是指等同包括魚肉在內。自「一下」句起，接著顯明其過失。不具備四義：第一、沒有慈悲心；第二、不能識別根機；第三、不通曉教理開遮；第四、沒有真實利益。第二、顛倒說法，把因當成緣，把緣當成因，也就是用五法來貶低八正道。「逾」就是超越、凌駕。「相似」是指五法之中前三種稱為相似之語（似是而非），後兩種純屬妄語。愚昧之眾仍去學它，直到現今天竺那裡仍有此派的遺留風氣。

【14-0005】03_業疏/17a_卷三之六#120
【原文】故《雜心》中：若言五法是、八正非者，則地神唱生，乃至三千世界，盡佛化境，禪誦不行。餘如《戒本疏》說。
【譯文】所以《雜阿毗曇心論》說：如果有人宣稱五法是正確的、八正道是不對的，那麼地神就會發聲呼喊，乃至遍及三千大千世界，凡是佛陀教化所及的境域，坐禪與誦經修行全部廢止不行。其餘內容如《戒本疏》中所說。

【14-0006】03_業疏/17a_卷三之六#121
【原文】次科，初明破正已成，人所信故。「則下」，次明法輪不轉。禪誦即觀法。《鼻柰耶》云：諸佛常法，食時僧破，至暮還復，中間人天無悟道者，故云「不行」。餘下指略，即破僧戒，宜自尋之。
【譯文】次科，起初說明破壞正法已經得逞，因為為人所信奉的緣故。自「則下」句起，接著說明法輪不再運轉。「禪誦」就是指修觀之法。《鼻柰耶》說：諸佛的常規法則是，齋食之時僧團破裂，到了黃昏便又復合，在這期間人天之中沒有一人能悟道，所以說「不行」。自「餘下」以下指示省略之處，就是指破僧戒，應當自行去尋閱。

【原文】就文為二：初緣，後相。
【譯文】就疏文結構而言分為兩部分：先是緣起，後是戒相。

【14-0008】03_業疏/17a_卷三之六#123
【原文】緣中，初先與依，由厭本習故；開後授，據此依理，本存道業，庸疎未委故；前誨約，恐後退沒，知初戒故，不徒然也。
【譯文】在緣起之中，起初先傳授四依，是因為要厭離原先外道的習氣；後來開許在受戒之後傳授，是依據這四依的義理，根本在於保有道業，庸劣粗疏之人尚未完全了達的緣故；在受戒前先加告誡約束，是唯恐日後退墮沉淪，令其知曉最初受持戒律之本分，所以絕非徒勞無益的。

【14-0009】03_業疏/17a_卷三之六#124
【原文】二、就文釋緣中，注文兩段。初先與依，釋初制緣由；下二句釋後授緣由。厭本習，欲令外道不反道故。「據下」，示制意。依理，謂立四依之理；道庸疎，即鈍機；退後知初，追本不捨故。
【譯文】第二、就疏文解釋緣起的段落中，注文分為兩段。起初「先與依」，是解釋最初制定的緣由；隨後兩句是解釋後來改在受戒之後傳授的緣由。「厭本習」，是想要讓外道不再返回邪道。自「據下」句起，顯示制戒的用意。「依理」，是指確立四依的道理；「道庸疎」，就是指鈍根之人；「退後知初」，是指日後追念根本而不捨棄戒法之故。

【14-0011】03_業疏/17a_卷三之六#126
【原文】所以止、作二持，竝前標如來三號者，略示非邪，大聖親誡，故同舉之；令重教依行，必無怠縱故也。
【譯文】之所以在止持、作持這兩類持犯之前，都標明如來的三種名號（如來、應供、正遍知），是為了簡要顯示這不是邪道，而是大聖佛陀親自的誡敕，所以同樣列舉出來；這是為了讓人尊重教法、依教奉行，必定不敢懈怠放縱之故。

【14-0012】03_業疏/17a_卷三之六#127
【原文】次體相標舉中，初文微意，兼通前後。「略下」，總釋。示非邪者，外道、調達皆立依法故；無怠縱者，不輕犯故。
【譯文】在次段標舉體相的段落中，初文的深微意旨，兼通前後各段。自「略下」句起，作總體解釋。「示非邪」，是因為外道和提婆達多都各自設立了依止之法；「無怠縱」，是為了讓人不輕易違犯。

【14-0013】03_業疏/17a_卷三之六#128
【原文】文云「依此得出家」者，離有為也；「受具戒」者，登無願也；「成比丘法」，同聖儀也。
【譯文】經文中說「依此得出家」，是指遠離有為世間；說「受具戒」，是指登上無願解脫門；說「成比丘法」，是指等同於聖者的威儀軌範。

【14-0014】03_業疏/17a_卷三之六#129
【原文】次科，三有之中，皆有為法，超拔有為，故名出家。言無願者，無所求故。同聖儀者，三乘皆爾故。
【譯文】次科，三界之中全都是有為之法，超拔於有為之外，所以稱為出家。所謂「無願」，是因為對世間無所希求之故。所謂「同聖儀」，是因為三乘聖者皆是如此的緣故。

【14-0021】03_業疏/17a_卷三之六#136
【原文】「依糞掃衣」者，舉名顯示也。依律中列十種，竝世所同棄，如糞掃喻耳。故俗所賤者，道所貴也。此據常人，故有言耳。故《論語》云：「君子不耻惡衣惡食，若耻則未可與議也。」《劉子》云：「食足充虗接氣，衣足葢形御寒。」斯言是也。至如冠章甫，衣縫掖，嘉肴溢目，芳音盈耳，一時之榮，故不足尚也。《書》云「高位厚味，俱不可久」，是以君子存謙光之道。忍人不忍，謂憎愛也；割人不割，即情欲也；行人不行，即仁義也。欲尚爾，況懷道乎？知是繁文，末俗多昧故也。
【譯文】「依糞掃衣」，是舉出名稱加以顯示。依照律中所列共有十種，全都是世人共同遺棄之物，就如同掃除的糞穢塵垢一般作比喻罷了。所以世俗所鄙賤的，正是修道所珍貴的。這是就普通人而言，所以才作這番議論。因此《論語》說：「君子不耻惡衣惡食，若耻則未可與議也。」《劉子》說：「食足充虗接氣，衣足葢形御寒。」這話確實很對。至於頭戴章甫冠，身著寬袖衣（縫掖），美味佳餚滿目琳瑯，美妙絲竹充盈於耳，這只是一時的虛榮，本來就不值得推崇。《尚書》說「高位厚味，俱不可久」，因此君子心存謙遜光大之道。忍受常人所不能忍受的，是指憎恨與貪愛；割捨常人所不能割捨的，就是指情執與欲望；踐行常人所不能踐行的，就是指仁義之道。在世俗欲望上尚且應當如此，更何況心懷至高聖道呢？明知這是繁複的文字，只因末世凡俗多有愚昧暗昧的緣故。

【14-0022】03_業疏/17a_卷三之六#137
【原文】「依律下」，委釋為三：初示名體。律十種者：一、牛嚼，二、鼠嚙，三、火燒，四、月水，五、產婦，六、神廟，七、塚間，八、求願，九、往還，十、王軄。俗賤道貴，示相反也。「此下」，次議其名。常人謂淺識者，若卓拔君子，豈以衣為糞掃耶？「故下」，三引況。初《論語》，「未可與議」，言此庸人不足語道。《劉子》即劉晝也，著書二卷五十五篇，窮悴無由自達，乃負其書候沈約於車前獻之，約覽而異之，遂呼登車定交，時人號此書為《劉子》。今引〈防欲篇〉，彼云「明者刳情以遣累，約欲以守貞」，方接「食足」等語。「斯言是」者，美其有理也。「至下」，敘厭榮。冠、衣二字去呼。章甫，殷時冠也；縫掖，大袖衣也。《家語》孔子對哀公曰：「丘少居魯，衣縫掖之衣；長居宋，冠章甫之冠。」嘉肴謂品饌，非穀而食曰肴；芳音謂歌樂之聲。高位是貴，厚味是富，未詳何書。「俱不可久」，勢有退也。「是以」下，明向道。《易·謙卦》云：「人道惡盈而好謙，謙尊而光，卑而不可踰，君子之終也。」「忍人」等者，謂眾人所不能者，我則勉力為之。文出《淨住子》，本唯三句，疏加配釋，助顯其文。以俗況道，俗淺道深，理必過之，況不及乎？況相反乎？「知下」，三結意。
【譯文】自「依律下」句起，詳細解釋分為三部分：第一、顯示名稱與體相。律中所列十種糞掃衣是：一、被牛嚼破之衣，二、被老鼠咬破之衣，三、被火燒殘之衣，四、沾染月經之衣，五、產婦用過之衣，六、神廟祭祀之衣，七、墳墓塚間死人之衣，八、祈願祭神後捨棄之衣，九、從遠途往返廢棄之衣，十、王職（受刑死者或王官廢棄）之衣。世俗所賤而道人所貴，顯示二者正相反對。自「此下」句起，第二評議其名稱。「常人」是指見識淺陋之輩，若是超卓拔萃的君子，哪會把這衣物看作糞土塵芥呢？自「故下」句起，第三引用世間典籍作比況。首先引用《論語》，「未可與議」是說這種庸俗之人不值得同他論道。《劉子》即劉晝，著書兩卷五十五篇，因貧困潦倒無由自我顯達，便背著自己的書在沈約的車前等候並進獻，沈約展讀後深感其奇異，於是呼喚他登車結為好友，當時人便稱這部書為《劉子》。此處引用其〈防欲篇〉，該篇說「明智之士剖除情執以排遣牽累，節約欲望以堅守貞節」，隨後才接上「食足」等語。「斯言是」一句，是讚賞這話極有道理。自「至下」句起，敘述厭離榮華。「冠」、「衣」二字讀去聲（作動詞用）。章甫是殷商時期的冠帽；縫掖是大袖之儒服。《孔子家語》載孔子回答魯哀公說：「我丘年少時住在魯國，身穿縫掖之衣；年長後住在宋國，頭戴章甫之冠。」「嘉肴」指各類美味菜餚，非五穀主食的菜味稱為肴；「芳音」是指歌舞音樂之聲。「高位」代表顯貴，「厚味」代表富有，具體出自何書尚不詳備。「俱不可久」，是說權勢與富貴終有退失之時。自「是以」以下，明示心向於道。《易經·謙卦》說：「人道惡盈而好謙，謙尊而光，卑而不可踰，君子之終也。」「忍人」等句，是指眾人所不能做到的，我則盡勉力去踐行。文句出自《淨住子》，原文只有三句，疏文加上了對應配釋，以助顯其深意。以世俗之事比況修道，世俗尚淺而聖道至深，其義理必定超越世俗，又怎會及不上呢？又怎會反其道而行呢？自「知下」句起，第三總結其立意。
