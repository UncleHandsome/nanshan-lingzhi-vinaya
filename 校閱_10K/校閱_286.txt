# 校閱材料　第286檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【286-0001】01_行事鈔/12c_卷下之四#30
【原文】次明諸要行，勿過八敬。《善見》：佛初不度女人出家，為滅正法五百年；後為說八敬，聽出家，依教行故，還得千年；今時不行，隨處法滅；故須勵意。今列其名：一者百歲比丘尼，見初受戒比丘，當起迎逆、禮拜、問訊、請令坐。二比丘尼不得罵謗比丘。三不得舉比丘罪，說其過失；比丘得說尼過。四式叉摩那，已學於戒，應從眾僧求受大戒。五尼犯僧殘，應半月在二部僧中行摩那埵。六尼半月內，當於僧中求教授人。七不應在無比丘處夏安居。八夏訖，當詣僧中求自恣人。如此八法，應尊重恭敬讚歎，盡形不應違。
【譯文】次明諸要行，勿過八敬。《善見律毘婆沙》說：佛陀起初不度女人出家，是為了避免正法提早五百年滅亡；後來為她們宣說八敬法，才准許出家，因依教奉行的緣故，正法住世依然可得千年；現今之人若不遵行，隨所到之處佛法便隨之衰滅；所以必須勉勵留心。現今列出其名稱：第一、即使是百歲戒臘的比丘尼，見到剛受戒的比丘，也應當起立迎迓、頂禮拜伏、問訊起居、恭請其就坐。第二、比丘尼不得辱罵毀謗比丘。第三、比丘尼不得舉發比丘罪過、宣說其過失；比丘則得宣說尼眾之過失。第四、式叉摩那（正學女）完成學戒之後，應當向二部僧眾乞求傳受具足戒。第五、比丘尼犯僧殘罪，應當於二部僧中行半個月（半月期）的摩那埵（悅眾意悔過法）。第六、比丘尼每半月之內，應當向比丘僧中求請教誡教授之人。第七、比丘尼不應在沒有比丘居住的處所進行夏安居。第八、夏安居結束後，應當前往比丘僧中求請自恣之人。這八種法則，應當尊重、恭敬、讚歎，終身（盡形壽）不得違背。

【286-0002】01_行事鈔/12c_卷下之四#31
【原文】《五分》：應遣三尼，來僧中自恣。《中含》：八尊師法中，若比丘聽尼問經律毘曇，然後得問；不聽者，犯第五尊師法。《僧祇》：尼入僧寺，應頭面一一禮比丘足；若老病不堪，隨力多少；不遍者，總禮，口云：「我尼某甲，頭面禮一切僧足。」若比丘入尼寺，尼禮亦爾。不得云：是犯戒、是醫師、是摩呵羅、無所知，及虛實罪。比丘得說尼實罪。尼若憍慢，不敬起迎禮足者，越敬法。《十誦》：見大僧不起者，墮。《五分》亦爾。
【譯文】《五分律》說：應當派遣三位比丘尼，前來比丘僧中說自恣。《中阿含經》記載：在八尊師法之中，若比丘准許比丘尼請問經、律、阿毘曇（論藏），然後才可以發問；若未得准許便問，犯第五尊師法。《摩訶僧祇律》記載：比丘尼進入比丘寺院，應當頭面頂禮，逐一頂禮每位比丘之足；如果年老病弱不堪勞頓，隨力量所及禮拜若干；若無法禮拜周全，則總體頂禮，口中陳白說：「我比丘尼某甲，頭面頂禮一切僧眾之足。」如果比丘進入比丘尼寺，尼僧行禮也是如此。尼僧不得說：這位比丘是破戒者、是醫生、是摩訶羅（愚昧無知之老僧）、一無所知，以及宣說其或虛或實的罪過。比丘則可以宣說尼僧的真實罪過。比丘尼如果生起憍慢之心，不行敬意起身迎逆禮拜比丘足者，違犯八敬法。《十誦律》說：見到大僧不起立相迎者，犯波逸提（單墮罪）。《五分律》也是這樣規定的。

【286-0003】01_行事鈔/12c_卷下之四#32
【原文】《僧祇》：若親里尼，得軟語語，不得呵責。若年少者，語云：汝今不學待老耶？汝後當教弟子，弟子亦學汝，是故應隨順受經、誦經。《四分》：尼輒入僧寺，墮。《五分》：若立不見比丘，不得不白而入；白時，比丘籌量，可聽以不。如上明之。
【譯文】《摩訶僧祇律》記載：如果是親屬關係的比丘尼，應以柔軟言辭好言相勸，不得嚴加呵責。如果是年輕的尼僧，應對她說：「妳現在不努力學戒學法，難道要等到年老嗎？妳以後還要教導弟子，弟子也會模仿妳，因此應當隨順教導受持經典、誦讀經典。」《四分律》記載：比丘尼擅自進入比丘寺院，犯波逸提。《五分律》記載：如果站在門外看不到比丘，不得未經通報就擅自進入；通報時，比丘應當思量，是否可以准許她們進入。這如同上文所說明的那樣。

【286-0004】01_行事鈔/12c_卷下之四#33
【原文】二明式叉摩那法。《四分》：十八童女，應二歲學戒。又云：小年曾嫁，年十歲者，與六法。《薩婆多》：年十二，得受具者，為夫家所使，任忍眾苦，加厭本事。《僧祇》亦同。《十誦》中，六法者，練心也，試看大戒受緣；二年者，練身也，可知有胎無胎。廣文如彼。故文中，盡形，為法故；二歲堪受，無胎故。
【譯文】二明式叉摩那法。《四分律》記載：年滿十八歲的童女，應當學習戒法二年。又說：幼年曾經出嫁、年滿十歲的人，授予六法學戒。《薩婆多論》說：童女年滿十二歲（曾嫁者）即可受具足戒，是因為長期在夫家操持勞役，能堪忍受各種勞苦，更加厭離世俗之事。《摩訶僧祇律》也持相同說法。《十誦律》中說：修學六法，是為了歷練其心性，試驗其納受具足大戒的因緣；為期二年，是為了考驗身形，以便查知是否懷有身孕。詳細內容如該律所述。所以律文說，誓願終身持守，是為了戒法的緣故；修學二年即堪能受戒，是因為確認並無懷孕的緣故。

【286-0005】01_行事鈔/12c_卷下之四#34
【原文】應立離聞處，著見處，白四受法後，召來與說六法名字。乃至答言能持，如常說。
【譯文】應當讓她站立在聽不見話語、但能看得到身影的處所，經由白四羯磨（一白三羯磨）授予學戒法之後，將她召喚過來，為她宣說六法的名稱。乃至讓她回答「能持」，其程序如常規所述。

【286-0006】01_行事鈔/12c_卷下之四#35
【原文】此式叉尼，具學三法：一學根本，謂四重是。二學六法，即羯磨所為。謂染心相觸，盜人四錢，斷畜生命，小妄語，非時食，飲酒也。文中列淫、盜、殺、妄者，隨十戒而言，沙彌已學。三學行法，謂一切大尼戒行，並須學之。若學法中犯者，更與二年羯磨；若犯根本者，滅擯；犯餘行法，但名缺行，直令改悔。若滿二年已犯者，更與二年。
【譯文】此式叉尼，具學三法：第一、修學根本重戒，即是前四重波羅夷。第二、修學六法，即是羯磨所特別授與的法條。也就是染污心相摩觸、盜取他人四錢（錢財未滿五錢不犯重者）、斷絕畜生命、小妄語、非時食（過午飲食）、飲酒。律文中列舉淫、盜、殺、妄者，是隨順沙彌十戒而言，沙彌階段已修學過了。第三、修學威儀行法，也就是大尼的一切戒律威儀行法，全都要修學。如果在這學法的兩年之中犯了六法，應當重新作羯磨再給予兩年學戒；如果犯了根本四重戒，直接滅擯（驅逐逐出僧團）；如果犯了其餘的威儀行法，只稱為「缺行」（操行有虧），直接命其悔過即可。如果滿了兩年之後又違犯六法，必須重新再給予兩年。

【286-0007】01_行事鈔/12c_卷下之四#36
【原文】律云：式叉尼，一切大尼戒應學。除自手取食，授食與他；若自取食食，律亦制犯。無沙彌尼者，開之；有者，得授與尼，自須受取。
【譯文】律藏說：式叉尼應當修學大尼的一切戒律。但除自手拿取食物、親手授食給他人這兩點有所不同；如果自己拿取食物食用，律藏同樣制定為犯戒。如果沒有沙彌尼在場，則開許自取；若有沙彌尼在，式叉尼可以把食物授與比丘尼，自己食用時則必須由他人授與而後納受。
