# 校閱材料　第415檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【415-0001】資持記/07d_中一下#25
【原文】斷重歸輕，夷；斷輕歸重，蘭；一一各兼非法吉羅，故云雙結也。〔有云：不學無知，非也。〕三出貸者，謂暫借也。釋中，初文。且約塔僧，法物亦爾。券即契書。讀疏者，歷帳告僧。違結罪者，一違此教，理須得吉；一不還三寶，隨物結犯。次科。以錢出利，如母生子，故名息也。西竺，三寶各有無盡財；
【譯文】判定重大財物歸於輕物，犯波羅夷；判定輕微財物歸於重物，犯偷蘭遮；每一項都各自兼帶非法的突吉羅罪，所以說是「雙重結罪」。〔有人說是無知未學，這種說法是錯的。〕第三「出貸」，是指暫時借用。在解釋中，起初的文句，暫且就塔物與僧物而論，法物也是如此。「券」就是借契文書。「讀疏」是宣讀帳目通告僧眾。違規而結罪的情況：一是違背了佛陀這項教制，理應得突吉羅罪；二是不償還三寶，隨所欠物品結犯相應之罪。下一科中，用本錢生出利息，如同母親生下孩子，所以稱為「息」。在西印度，三寶各自設有「無盡財」；

【415-0002】資持記/07d_中一下#26
【原文】謂常存供養，滋生不竭故。干雜，謂相亂，此句通結上文。別人貸中，初科。兩文並許。二中，初引經。餘下，準判。以彼病者，尚須倍還；況不病者，不開明矣。與下，和會。經律開制，極成相反；於義可疑，在文有妨。彼經云：出家菩薩，若畜出家弟子，先當教告，令不放逸；
【譯文】這是指永久留存供養，滋生利潤取之不盡。所謂「干雜」，是指互相混亂，這句話總結了上文。在「他人借貸」中，起初一科。兩處文獻都予以允許。第二點中，起初引用經文。接著「其餘」以下，依準判決。因為生病的人尚且需要加倍償還；何況沒有生病的人，顯然絕不開許。接著「與」以下，進行融會調和。經文與戒律的開許與制止完全相反；在義理上令人懷疑，在文句上有窒礙難通之處。那部經說：出家菩薩如果蓄養出家弟子，首先應當教誡勸告，使他們不放逸；

【415-0003】資持記/07d_中一下#27
【原文】若闕所須，病時當為求覓；若自無，應貸三寶物；若差，十倍還之；以出家弟子，猶通道俗，故云文似也。三中，引論有二節。初自用者，論云：與佛物同，復犯重罪。壞法身者，同逆業故。若有下，即次段。論作得受使用，言為佛受用也；今變其語云不得者，遮餘人也。
【譯文】如果缺乏日常所需，生病時應當替他尋求；如果自己沒有，應當借貸三寶之物；如果病癒，應十倍償還；因為出家弟子也兼通僧俗，所以說「文字表象相似」。第三點中，引證論典分為兩個段落。起初是私自受用，論中說：與私用佛物同，再次結犯重罪。毀壞法身，是因為此罪等同五逆之業。接著「如果有」以下，就是次一段。論中原文作「可以接受並使用」，意思是為了佛事而受用；現在改換其詞句說「不得借使」，是為了防範其他人。

【415-0004】資持記/07d_中一下#28
【原文】下指後戒者，彼云：施軍器應打壞，樂器許賣等。四明瞻待，初文為三，前引制。亦下，定物。初點文通漫。準下，例決。律中，沓婆為僧知事，僧以十方現前所得衣賞之。《十誦》下，顯意。此人，即上知法等。二中，初引文。此下，義決；初指前文，且據無信。
【譯文】下文明指後面的戒條，那裡說：布施軍用武器應當砸爛，樂器則允許變賣等。第四「說明照顧款待」（四明瞻待），起初的文句分為三段，前面引用限制規定。接著「亦」以下，判定物品。起初指出文意過於廣泛籠統。接著「依準」以下，依循事例決斷。戒律中，沓婆為僧團擔任執事，僧眾用「十方現前物」所得的衣服犒勞他。接著「十誦」以下，顯示其深意。所謂「這個人」，就是指上面通曉佛法等條件的人。第二點中，起初引用文句。接著「這」以下，作義理決斷；起初指出前文，暫且是依據毫無信仰的人來說。

【415-0005】資持記/07d_中一下#29
【原文】悠悠，謂遠離三寶，無所歸者。若下，次明有信。福食，謂檀越求福，施眾僧故。三中，初引《十誦》明用分齊。初給王臣。十九錢者，彼土大銅錢，一當十六，當今三百也。下明賊難。不可約數。次《僧祇》中，通列五人。上三可解。下示王臣，須論勢力；必無力者，應非所開。多下，引決。
【譯文】「悠悠」，是指遠離三寶、無所依歸的人。接著「如果」以下，其次說明有信仰的人。「福食」，是指檀越施主為了求福，而布施給大眾僧侶的食物。第三點中，起初引證《十誦律》說明使用的界限份額。起初是給予國王大臣。所謂「十九錢」，是西印的大銅錢，一枚抵得上十六枚，相當於現在的三百文錢。下文說明防備盜賊患難。不能限定數量。其次在《僧祇律》中，通列了五種人。前三種容易理解。下文說明國王大臣，必須審核其權勢力量；如果完全沒有權勢，應當不在開許之列。接著「多」以下，引文決斷。

【415-0006】資持記/07d_中一下#30
【原文】由上律云：損益皆與，既是有益，理不當與；在文不了，故續決之。若下，通上律意。俗知僧物難消，必無虛受；僧知污家非法，必無妄與；但有緣須給，微亦通之；《十誦》通開，諒在於此。指二篇者，即下僧殘污家戒也。彼云：父母病人牢獄繫閉等，不犯。四病人中。兩錢半，即今四十。
【譯文】由於上述戒律說：無論有損或有益都給予，既然有益，在道理上就不應當給予；文字上不夠明晰，所以接著加以判決。接著「如果」以下，通達上述戒律的原意。世俗之人知道僧物難以消化，絕不會平白無故接受；僧人知道污家非法，絕不會妄自給予；只要有因緣需要接濟，即使微薄之物也能通融；《十誦律》通盤開許，原因大概就在於此。指稱「第二篇」，就是指下文僧殘篇中的「污家戒」。那裡說：若給予父母、病人、監獄囚犯等，不犯戒。第四「病人」中，兩錢半，也就是現在的四十文。

【415-0007】資持記/07d_中一下#31
【原文】準前，應是齊此不須白僧耳。五淨人中。二短作分番，長使通結。六中，初引文。契，即約也。準下義決，又二；初準俗法，約中前後。又下，準上律文，量功勤墮。三結指中。指上卷者，即〈僧網篇〉。二盜人中。通收道俗。總分中。正主，即是物主，損彼物故。護主，即看守人；
【譯文】依照前面原則，應當是指達到這個金額就不需要向僧團報告宣告而已。第五「淨人」中，分為兩類：短期作工者分班輪值，長期僕役則通盤結算。第六點中，起初引述文句。「契」，就是約定。接著「依準」以下做義理決斷，又分兩點；起初依準世俗法律，以日中前後為準。接著「又」以下，依準上述戒律，衡量勞作之勤勞或懈怠。第三結語指引中，指明見於上卷，也就是〈僧網篇〉。第二「盜取人身物」（二盜人）中，通盤涵蓋僧眾與世俗。總括分門中，「正主」就是物主，因為損壞了對方的財物。「護主」就是看守保管之人；

【415-0008】資持記/07d_中一下#32
【原文】雖非彼物，失必填償，還成損護故。句法中，初三句。第二云：無守護者，非無人守，謂此物不可藏貯故。三言無我無守者，此望不知，心不繫故。據此，合有無我所心，有守護，此句見下文。若下，總判犯相。後二句中。上句僧物，各有己分，故有我所。下句官物，不屬於己，故無我所。
【譯文】雖然物品並非他所有，但失竊必須照價賠償，因此依然構成損害守護之人。在句法結構中，首先有三句。第二句說：無人守護，不是指沒有人看守，而是指這件物品無法儲藏封閉。第三句說沒有「我所心」也沒有守護者，這是針對不知情而言，心念沒有繫著於物。據此推論，應該還有「無我所心而有守護」的情況，這一句見於下文。接著「如果」以下，總結判定犯罪相狀。後兩句中，上一句是指僧團之物，每個人都有自己的一份，所以有「我所心」。下一句是官方財物，並不歸屬於自己，所以沒有「我所心」。
