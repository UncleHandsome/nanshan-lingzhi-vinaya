# 校閱材料　第567檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【567-0001】資持記/09c_中三上#20
【原文】不白請家者，犯後四十二戒。釋第三，初科有三，初釋病緣。律因病比丘不得隨病食故。次釋施衣緣。律中一家單食請，一家衣食請，佛開背前；又律云：自恣竟，無衣一月，有衣五月〔此通開背，不約兼衣。〕；又云：若復有餘施食及衣等，此明兼施，不限時與非時，故云十二月也。若一日下，明捨請，初示捨法。
【譯文】如果事先不稟告前一位請客的施主，便會觸犯後文的第四十二條戒。在解釋第三項時，第一科包含三個層面，首先解釋患病的緣由。律中是因為生病的比丘無法隨意挑選適合病情的食物之故。接著解釋布施衣物的緣由。律典中記載，如果一家單純請吃素齋，另一家同時布施衣服與飲食，佛陀開許可以捨棄前一家；律中又說：解夏自恣結束之後，沒有得到僧衣者有一個月開緣，得到衣物者有五個月開緣〔這是通盤開許違背前請，並不限於兼施衣物的情況。〕；律中又說：如果還有其他施主供養食物與衣服等，這指兩者兼施，不論是應時或非應時的時段，所以說是整整「十二個月」。在「若一日」以下，說明捨棄先前受請的方法，首先指示捨請的儀軌。

【567-0002】資持記/09c_中三上#21
【原文】若不下，明犯相。引《五百問》決上可否，主嫌不捨，亦應成背；準前六念，開心念捨。次科，彼宗開病，限至三家，但開背二；若容更背，恃開無節，教緩機慢，故不得四也。不犯中，七；前三如上，第四注中，粥謂出釜稀者，餘則枝葉細末等。五中，注云少者，犯取境足故。
【譯文】如果「不」字以下，說明成犯的情狀。引用《五百問》來裁決上述做法是否得當，如果施主心生怨嫌而不肯答應捨去，按理也應當構成違背受請；比照前文的「六念法」，此處開許可以在心中作意默許捨去。在下一科中，該部派開許生病時的受請，上限為三家施主，但只開許違背前兩家；如果允許繼續違背受請，比丘便會仗著開緣毫無節制，導致教規鬆弛、行者懈怠，所以絕不能通融到第四家。在不犯的項目中共有七種；前三種如上所述，第四種注文中提到，粥是指剛起鍋時質地稀薄的粥，其餘食物則是樹枝、綠葉、細碎粉末等雜食。第五項中注文提到「微少」，是因為要滿足犯戒條件必須達到標準的份量。

【567-0003】資持記/09c_中三上#22
【原文】第六無請，豈得有犯；七謂前後重食，乃可犯足，而不犯背；必不壞儀，足亦非犯。律又云：一處前後食，謂同主異食，非背可知；文中不出，故云等也。三十三。〔佛在羅閱祇，提婆教人害佛，教闍王殺父；惡名流布，利養斷絕；乃與五人別乞，因制。〕釋戒名者，謂能別之人，食處成眾；
【譯文】第六項是根本沒有接受先前的邀請，哪裡會構成犯戒；第七項是指前後兩餐都吃得極飽，雖然可能觸犯「足食戒」，但並不觸犯「背請戒」；只要不損壞威儀體統，吃飽本身也不算犯戒。律典又說：在同一個處所先後進食，是指由同一位施主提供不同的食物，這顯然不屬於背請的範疇；條文中未一一列出，所以用「等」字概括。第三十三條波逸提法。〔佛陀在王舍城時，提婆達多教唆旁人謀害佛陀，教唆阿闍世王弒父篡位；惡名遠播之後，供養利養全斷絕了；他於是帶著五位徒眾另行單獨化緣乞食，佛陀因此制戒。〕解釋戒名時，是指能夠發起別立行為的人，在用餐處所聚合成了僧眾；

【567-0004】資持記/09c_中三上#23
【原文】以眾別他，不共同味；若取語便，應云眾別；然據所別，非不通眾；但犯由能別，故獨彰名。又能唯約眾，所通眾別。委如《本疏》。約相中，初科，本律有二，初約廣解明別請。即開緣文。佛初未開，比丘凡有他請，皆用此言對之，如鈔所引。至後白佛，故有七開。若依下，次約緣起明別乞。
【譯文】他們以自己的小眾脫離了其他大眾，不肯與大眾共同享用同一樣食物；若是順應語法便利，理應稱作「別離大眾」；然而就其所脫離的對象而言，也未嘗不能通稱大眾；只是犯戒責任在於這群自行別立的人，所以單獨以此立名。又或者「能別」單指這群小眾，「所別」則通指全體大眾或個別僧眾。詳細內容正如《行事鈔本疏》所載。在分析犯戒相狀中，第一科提到，本律有兩種面向：首先是透過廣泛解釋來闡明個別受請。這正是屬於開緣的經文。佛陀最初尚未開許時，比丘只要遇到其他外來迎請，都用這套說辭回絕對方，正如鈔文所引用的那樣。直到後來向佛陀稟白，才有了七種特別開許。在「若依」以下，接著藉由起因緣起來說明個別乞食。

【567-0005】資持記/09c_中三上#24
【原文】難調人即召提婆，明佛制戒，為攝彼故。〔本宗止有此二。〕《多論》具三，皆論不集，初句總標。亦下，別列。上云亦明者，亦前律文；下云亦有者，亦上二種。分相解中，總標。云各明緣者，三位各具七緣，如下所列。引據證別者，即下多見二論辨三相不同。僧次中，初科。
【譯文】「剛強難調伏之人」就是指提婆達多，這說明佛陀制定此戒，是為了收攝防範那幫惡人的緣故。〔本宗四分律僅有這兩種面向。〕《薩婆多論》具備三種面向，都是探討眾僧未能集會的情況，第一句是總括標明。「亦」字以下，分項列舉。上文說「亦明者」，是同樣闡明前面的律文；下文說「亦有者」，是兼具上述兩種情況。在逐一分析相狀的解釋中，先作總括標明。所謂「各自辨明成犯事緣」，是指這三種情境各自具備七項條件，正如後文所羅列的。引用文獻佐證其差異，即指後文多處引用兩部論典來辨析這三種情狀的不同。在依僧倫次受請的科判中，進入第一科。

【567-0006】資持記/09c_中三上#25
【原文】且據僧次，餘二例同，但改第二為異。次科有二，初明僧界開法。須布薩處，即知法者所居，以布薩是攝眾之法；請彼一人，則表眾集。自處不須者，即彼二處不相請送，與下俗舍不同。若下，次明聚落，初明作法。加打犍槌。僧界人多，不可作相，但有二法。更下，明重作。以後來者，復成別故。或下，明互轉。
【譯文】此處姑且根據「依僧倫次受請」為準，其餘兩種情況均可比照辦理，只是將第二項條件改換為其特有的相狀。下一科分為兩部分，首先說明僧團結界處所的開許作法。必須在「布薩場所」，也就是通達戒法的主事者所居住之處，因為布薩是統攝全體僧眾的法事；迎請那裡的一位僧人，就象徵著全體僧眾齊集。在自己原處則不需要另行作法，因為那兩處之間互不迎請送達，這與後文世俗房舍的作法不同。在「若」字以下，接著說明村落聚落的情況，首先說明進行羯磨法事。增加了敲擊犍槌的儀式。僧團界內人數眾多，不可能一一當面作意宣白，所以只有這兩種法事。在「更」字以下，說明重新作法。因為對於後來才抵達的僧人，又會再次構成個別隔離的過咎。或者「或」字以下，說明彼此身分的互相轉換。

【567-0007】資持記/09c_中三上#26
【原文】如後廣之。如下，結示。別乞中，《見論》。四句，且引初句，餘三如後。《多論》。各乞同處，反明同乞異處成別。別請中。作法即鳴鐘，唱令召夏臘等。遮食罪準理是吉。若下，約集明犯。準上界內無人之文。下引文證，同坐異味，亦即集犯。準決中。總斷三位，不集皆同，集犯有別。
【譯文】這如後文所詳細闡述。在「如」字以下，結語指示。在「個別乞食」中，引用《善見論》。列出四種情況，此處暫且引述第一句，其餘三句如後文所述。《薩婆多論》提到：各自乞食卻聚集在同一處所受用，反過來證明：共同乞食卻分開在不同處所受用，便構成了別眾。在「個別受請」中。其法事即是鳴響鐘聲、唱導號令並依照戒臘長幼唱名等。阻擋他人進食的罪過，依照常理推斷應屬於突吉羅輕罪。在「若」字以下，針對齊集僧眾來辨明是否犯戒。比照前文僧團結界內無人的文句。下文引用經文為證，同處就坐卻享用不同的飲食，這同樣構成了齊集時犯戒。在權衡裁決中，總結判斷三種情境，在未曾齊集大眾這一點上完全相同，但在齊集時是否成犯則有所差異。

【原文】先無別請者，謂長請之外，一切普設，無別召者；則二日已去，縱遮無過。不能下，次明有遮免過。不能無遮者，食不足供也。勸化比丘，即是門師。言六十臘者，趣舉多者為言；乃至者，五十九下，次第減唱。言都無者，虛唱成法，為免後患。若不下，明違教結犯。
