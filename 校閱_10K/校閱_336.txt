# 校閱材料　第336檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【336-0001】02_戒疏/02a_卷一上之二#86
【原文】【記】四、一體中。初標列。「體」下，隨釋又二。初示三相，前敘迷。「今」下，明悟。上二句悟實，體本一故；下二句悟權，知方便故。《涅槃》云：「善男子，汝今不應如諸聲聞、凡夫之人，分別三寶。於此大乘，無有三歸分別之相。所以者何？於佛性中，即有法僧。為欲化度聲聞、凡夫，故分別說三歸異相。」故知分三，暫被凡小，故云「一方行化」，即娑婆機宜也。「故」下，顯一體義。「照」即能覺智，「理」謂所覺常住佛性。「離名言」者，體寂滅故。「理無滯」者，隨染淨緣故。「非法」下，二、顯次第。初二句明法初。「知」即是悟。法體常住，隨悟得入，故必居初。次二句明佛後。逮至極果，方究盡故。下明僧中。此據初心至於等覺，皆是「中」間。《涅槃．迦葉問品》云：「眾生佛性，如雜血乳。『血』者，即是無明行等一切煩惱。『乳』者，即是善五陰也。乃至須陀洹人、斯陀含人，斷少煩惱，佛性如乳；阿那含人，佛性如酪；阿羅漢人，猶如生酥；從辟支佛至十住菩薩，猶如熟酥；如來佛性，猶如醍醐。」上列三乘，皆是「分遣」，未及果佛，故云「豈喻」等也。《疏》據四位，別論次第；今總四位，可例明之。理體、一體，二皆常住，則通三世；化相現在；住持滅後。此約如來從凡至聖，出世入滅，則一體居初。若從佛出，開演化導，則化相應初，理、一居次，住持最末。義可知也。
【譯文】【記文】在第四種一體三寶的科判中。首先標示排列。「體」字以下，隨順文義解釋，又分為兩部分。首先指示三種相狀，前面先敘述凡夫的迷失。「今」字以下，說明覺悟的狀態。上面兩句悟入真實實相，因為心體原本為一的緣故；下面兩句悟入權巧方便，深知應機施設的道理。《大般涅槃經》說：「善男子，你現在不應當像那些聲聞人與凡夫一般，妄自將三寶切分為截然不同的個體。在這一乘大乘妙法之中，根本沒有三歸依彼此各別分立的行相。為什麼呢？因為在佛性之中，本自圓滿具足了法寶與僧寶。只是為了要化導救度聲聞與凡夫，所以才在方便中分別演說三歸依的不同形相。」由此可知劃分出三寶，只是暫時用來化導凡夫與小乘根機，所以說「在一方世間推行化導」，指的就是娑婆世界應機的權巧方便。「故」字以下，顯明自性一體的深義。「照」就是指能覺照的妙智，「理」是指所覺照的常住佛性。「脫離名言」，是指自性本體寂滅無為。「理體無滯」，是指自性能隨順染淨種種因緣而無礙展現。「非法」這句以下，第二、顯明先後次第。前面兩句說明法寶居首。「知」就是指體悟證入。法體原本常住，行者隨其體悟即可契入，所以必定排列在最前。接下來兩句說明佛寶排在最後。因為直到證得至高無上的究極佛果，才能將此心源徹底開顯窮盡的緣故。下面說明僧寶居於中間的理由。這是依據從初發心一直到等覺菩薩的位階，都屬於中途進修的「中間」階段。《大般涅槃經．迦葉菩薩品》說：「眾生本具的佛性，猶如參雜了血液的牛奶。『血』，就是指無明、行等一切煩惱。『乳』，就是指本具的清淨善五陰。以至於須陀洹人、斯陀含人，斷除了少分煩惱，其佛性就像已轉為純乳；阿那含人，佛性猶如凝酪；阿羅漢人，佛性猶如生酥；從辟支佛一直到圓教十住位菩薩，其佛性猶如熟酥；唯有如來的究竟佛性，才真正稱得上是極致的醍醐。」上面所列舉的三乘行者，全都屬於「隨分除遣」，尚未圓滿證得究竟果佛的法界心體，所以說「哪能比喻為醍醐」等語。《戒本疏》是依據四種三寶的各自位階，分別論述其先後順序；現在若是總括這四種三寶的大綱，也可以依此規律推演明了。理體三寶與一體自性三寶，這兩者本質都是常住不滅，所以貫通過去、現在、未來三世；化相三寶唯局限於佛在世的現在；住持三寶則專屬於佛滅度後的末世。如果依照如來從凡夫修至成聖、出興於世乃至示現入滅的整個過程來看，則應當以一體自性三寶居於最初。如果從佛陀降誕出世、開演佛法以化導眾生的化儀來看，則應當以化相三寶居於最先，理體與一體三寶居於中間，住持三寶排列在最後。箇中的義理自然可以推知明瞭。

【336-0003】02_戒疏/02a_卷一上之二#88
【原文】【疏】四寶為言，理寶為勝，由常住故，為世所歸；餘三隨設，體是有法。
【譯文】【疏文】若就四種三寶來論定高下，理體三寶最為殊勝，因為它是常住不滅的實體，作為一切世間真正的究竟依歸；其餘三種三寶都是隨順世間因緣而權巧施設的，其體質都屬於生滅有為的法度。

【336-0004】02_戒疏/02a_卷一上之二#89
【原文】【記】功用，正明中。云「理寶勝」者，理通大小：生空真如，是小乘理；清淨心本，即大乘理。今須約大，以論勝劣。《歸敬儀》云：「理謂至理，天真常住，還是心體。」
【譯文】【記文】在功用效能的正面說明科判中。疏文說「理體三寶最殊勝」，此處的「理」通貫大乘與小乘：我空真如，是小乘所證的理體；自性清淨心本，則是純粹的大乘理體。現在必須依據大乘圓融之義，來論定其高下勝劣。《歸敬儀》說：「所謂理，是指無上至理，天然真性永恆常住，歸根究底還是眾生的自性心體。」

【336-0010】02_戒疏/02a_卷一上之二#95
【原文】【疏】答：「就理為言，誠如所問。語相為論，穢雜非現，何得同佛所證心源？故《涅槃》云『或有佛性，二人俱無』，明知行果，異俱有也。」
【譯文】【疏文】回答：「單就本具的理性本體而言，確實如同你所問的那樣無二無別。但如果就顯現的相狀功用來論述，凡夫當前污穢雜染、煩惱覆障，清淨佛性根本無法顯現，哪裡能夠等同於佛陀所親證的圓滿心源？所以《大般涅槃經》說『或者有一種佛性，是闡提與善根人兩者都不具備的』，由此可知修持證悟的究竟果位，與凡夫全體本具的理體，是存在著本質性差異的。」
