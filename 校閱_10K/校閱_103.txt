# 校閱材料　第103檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【103-0001】01_行事鈔/05c_卷中之一#22
【原文】二以義門六句不同。一《十誦》、《伽論》云：錢有貴賤時，不妨錢貴盜一入重，遇值賤時百千犯輕。二《四分》、《五分》、《善見》云：貴處盜物，賤處賣，還依本盜處估價。三《善見》云：貴時盜得，賤時賣，若定罪者，還依本時。上三句互反，皆同得輕降也。四《摩得伽》中：取五千不犯重——數數取四錢，數數作斷心。或不得物而入重，如《四分》，燒薶壞色教他等。五不滿五犯重，如《四分》：眾多人遣一人盜五錢，多人共分；或多人共盜，通作一分，但使滿五，一切同盜，結重。或盜過五結輕，如《十誦》：盜眾多人未分物者是，即如亡人輕物之類。六盜五人各一錢結重，如《僧祇》：五人各以一錢遣一人守掌，若盜，望守護人結。《善見》云：欲知盜相，如師徒四人互相教，共盜一人六錢，各得一波羅夷，一偷蘭。自業不合教他業，但得一偷蘭。此義應知。
【譯文】二以義門六句不同。第一句，《十誦律》、《薩婆多毘尼勒伽》說：錢幣有物價昂貴與低賤之時，不妨在錢幣貴重時盜取一錢即入重罪，遇上物價低賤時盜取百千錢亦僅犯輕罪。第二句，《四分律》、《五分律》、《善見論》說：在物價高貴之處盜取物品，拿到物價低賤之處變賣，仍應依照原本盜取處的估價判定。第三句，《善見論》說：在物價高貴之時盜得物品，在物價低賤之時變賣，若要定罪，仍應依據偷盜當個時節的價格為準。上述三句若是情況相反，也都同理可降為輕罪。第四句，在《摩得伽論》中：取了五千錢卻不犯重罪——因為他是多次盜取四錢，每次盜取時都作了就此了結斷除的心念。或者是未曾真正得到物品卻已入重罪，如同《四分律》所說，以焚燒、埋藏、破壞顏色、教唆他人行盜等手段。第五句，不滿五錢而犯重罪，如同《四分律》所說：眾多人共同派遣一人去盜取五錢，眾人共同瓜分；或者是眾多人共同前去行盜，所得合併作一份，只要滿了五錢，所有共同行盜之人皆結波羅夷重罪。或者盜取超過五錢卻結輕罪，如同《十誦律》所說：盜取眾多人尚未均分的共有物品即是如此，這就像過世僧人遺留的輕便衣物之類。第六句，盜取五人各一錢而結重罪，如同《僧祇律》所說：五個人各拿一錢委託一人保管守護，若是盜取，對著該守護人結重罪。《善見論》說：想要知道盜罪的相狀，例如師徒四人互相教唆，共同盜取一人六錢，各得一個波羅夷重罪、一個偷蘭遮。自己下手的盜業不能與教唆他人的盜業合併計算，故自業部分各僅得一個偷蘭遮（而教唆他人盜得六錢的部分則各得一個波羅夷）。此中義理應當通曉。

【103-0002】01_行事鈔/05c_卷中之一#23
【原文】五離本處。《四分》云：若牽挽埋藏，隨為一事，方便不成，並結偷蘭。《五分》：物在地中，作盜心得吉羅，掘地得提；捉物吉羅，動物偷蘭，離處方重。離處義，十句分之。一文書成辨離處。如律師疏判，以重入輕，非法判用僧物之類。《善見》云：畫地作字，一頭時輕，畫兩頭時重。二言教立者。《善見》：若盜心唱云，定是我地。地主生疑，偷蘭；決定失心者，重；若來問僧，答同皆重。若共爭園田，違理判與，違理判得；乃至口斷多端，偷夏唱大得物，皆重。即如《四分》：若以言辭辯說，誑惑而取，皆重。三移標相者。《善見》：標一舉時偷蘭，舉二標時重，乃至得一髮一麥皆重；地深無價，繩彈亦爾。四墮籌者。《四分》：盜隱記數籌，分物籌，致令缺少也。五異色者。《十誦》、《薩婆多》云：氈褥氍毹上，有樹枝葉華；今從樹葉上，盜牽至樹華上，犯重，謂異本色故。或如借他衣鉢，非理用損，減他五錢，亦結重罪。律云，若壞色故。六轉齒者。如《十誦》；樗蒲，移棋子等。《五分》：蒲博賭物，犯吉羅。七離處明不離處。如《僧祇》：盜他牛馬，未作得想，雖舉四足，不成重罪。八不離處明離處。如《善見》：空靜處盜，決得無疑，如擲杖空中，必無不下，故動即成重。九無離處辨離處。如《四分》：盜他田宅，攻擊破村，燒薶壞色，皆犯重等。十雜明離處。如空中吹物盜鳥，曲弋，斷流水注等。並不具述，廣如本疏。
【譯文】五離本處。《四分律》說：若是拉扯牽引、埋藏隱蔽，隨便施行了一種手段，若是未達目的偷盜未遂，都結偷蘭遮。《五分律》說：物品埋在地中，心中生起盜心即得突吉羅；動手掘地得波逸提；觸摸捉持物品得突吉羅；晃動物品得偷蘭遮；使物品徹底離開原地才結波羅夷重罪。離開原處（離處）的義理，分為十句來說明：第一是文書成立具辦而離處。如同律師書寫疏文判決，將重物判定為輕物，非法判決挪用僧物之類。《善見論》說：在地上畫字立契，剛畫完一端時得輕罪，畫完兩端契約成立時得重罪。第二是言辭教令確立者。《善見論》說：若以盜心宣唱說「這塊地一定是我的」。地主心中生起懷疑，結偷蘭遮；地主若徹底絕望決定放棄者，結重罪；若地主前來詢問僧團，僧團隨聲附和判定者皆結重罪。若雙方共同爭奪園林田地，違背法理而判給對方，或者違背法理而判定自得；乃至口頭斷決造出諸多是非端緒，偷報虛假戒臘自稱大德而冒領物資者，都結重罪。正如同《四分律》所說：若以言辭辯才欺誑迷惑而取財物者，都結重罪。第三是移動地界標界者。《善見論》說：拔起一個地界標記時得偷蘭遮，拔起第二個標記時得重罪，乃至由此多得一髮、一麥之寬的土地都得重罪；因為土地向下深邃價值無量，以墨繩彈線劃界也是如此。第四是隱匿分物算籌者。《四分律》說：偷盜隱藏記數籌、均分物品的籌碼，致使大眾所得缺少份額。第五是移動變異顏色者。《十誦律》、《薩婆多毘尼毘婆沙》說：毛氈地毯上織有樹枝、樹葉與花朵圖案；如今從樹葉圖案處，暗中將地毯牽拉移至樹花圖案處，即犯重罪，因為移離了原本色彩位置的緣故。或者如同借用他人的衣鉢，不如法使用致使受損，折損了他人五錢的價值，也結重罪。這是律中所說「若破壞其原色」的緣故。第六是轉動棋子者。如同《十誦律》所說：擲骰樗蒲、移動棋子作弊等。《五分律》說：以博戲賭博爭奪財物，犯突吉羅。第七是看似已離處而實明未離處。如同《僧祇律》說：盜取他人的牛馬，但心中尚未生起「確定奪得」的念頭，牛馬雖然四足皆已走動移位，仍不構成重罪。第八是看似未離處而實明已離處。如同《善見論》說：在空曠幽靜無人處行盜，決心奪得毫無疑慮，如同將手杖擲向空中，必定沒有不落下的道理，所以物品一經挪動當下即成重罪。第九是無處可離而辨明離處。如同《四分律》說：強占盜取他人的田園宅舍、攻打摧毀村落、焚燒埋藏毀損他人衣色等，都犯重罪。第十是雜說各種離處。如同盜取空中隨風吹動之物與飛鳥、曲柄掛架（曲弋）上的懸掛物、截斷他人引水流注等。此處不一一具體敘述，詳細內容如同本疏中所說。

【103-0003】01_行事鈔/05c_卷中之一#24
【原文】然盜戒相隱，極難分了；若廣張體貌，徒盈卷軸；至於披撿，取悟必繁；故略列犯緣，粗知梗概，意存省事知足。憂心念道者，緣境既局，少應清潔；若多眾務，而欲高升者，必羅盜網，終無有出。何者？由心懷勝劣，倒想未傾；初果無學，方可營事。有心懷道者，細讀附事，深思乃知。故《善見》云：戒律宜從急護；此第二重戒，事相難解，不得不曲碎解釋；其義理分別，汝當善思。論文如此，以準上列。猶恐不肖者謂繁，余心寔未言盡；約略如前，故且削也。
【譯文】然盜戒的行相極其隱蔽，極為難以分辨明白；若是過於廣泛鋪展其全貌，只會徒然充塞卷軸篇幅；至於翻閱檢索，要領悟也必定繁難勞形；所以僅簡略列舉犯戒之因緣，讓人粗略得知其大體梗概，用意在於簡省事端、知足止足。那些憂心念道、專意修行之人，所攀緣的境界既然狹隘局限，稍加謹慎便應當能保持清淨；若是包攬眾多僧務、企圖追求名位高升之人，必定會身陷盜戒羅網，終究無有出離之期。為什麼呢？因為內心還懷有勝劣高下之見，顛倒妄想尚未徹底傾伏除滅；唯有初果（須陀洹）乃至無學果（阿羅漢）的聖人，方才可以出來營辦大眾僧事。有心懷抱道業的行者，應當細細閱讀這些附隨事相，深沉省思才能通曉明白。所以《善見論》說：受持戒律應當從嚴從急守護；這第二條根本重戒，事相極難理解，不得不委曲委細地碎析解釋；其中的義理差別，你應當善加思維。論典的文字便是如此，用來依準印證上面所列諸條。我依然深恐根器不敏者嫌其煩瑣，其實我的內心實未將千言萬語盡情言盡；僅粗略概括如同前文，所以暫且刪削停筆了。
