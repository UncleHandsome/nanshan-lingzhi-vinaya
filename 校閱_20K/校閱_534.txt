# 校閱材料　第534檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【534-0001】資持記/07c_中一下#4
【原文】凡夫因之，至死不免。女色者，世間之衰禍；凡夫遭之，無厄不至；行者既得離之，若復顧念，是為從地獄出，還復思入。又云：女人之相，其言如蜜，其心如毒；譬如清淵澄鏡，而蛟龍居之；金山寶窟，而師子處之；當知此害，不可近也。敗正者，立事公正，苟荒女色，則無所成；
【譯文】凡夫因為女色，至死都難以倖免。女色是世間的衰敗禍端；凡夫遭遇了它，種種厄難無不降臨；修行人既然已經脫離了女色，如果又回頭眷戀顧盼，這就如同剛從地獄出來，又想著重新進去。經中又說：女人的相貌，言語甜蜜如蜜，內心陰毒如鴆；好比澄澈如鏡的深淵，卻有蛟龍盤踞其中；又如金山寶窟，卻有猛獅棲息其內；應當知道這種危害，是絕對不可以親近的。所謂敗壞正業，是指處事公正剛立，如果荒廢於女色，就一事無成；

【534-0002】資持記/07c_中一下#5
【原文】即彼經云：室家不和，婦人之由；毀宗敗族，婦人之罪。毀德者，修身立行，或著女色，則皆喪失；即經云：凡夫重色，甘為之僕；終身馳驟，為之辛苦；《淨心觀》云：貪色者憍，貪財者悋；既憍且悋，雖有餘德，亦不足觀。染下，明制急。然心行微細，麁情不覺；縱知違戒，制御猶難；
【譯文】正如該經所說：家庭不和睦，都是因為婦人的緣故；毀滅宗族敗壞家族，也是婦人的罪過。所謂毀壞德行，是指修身確立品行，一旦執著女色，就全都喪失；正如經中所說：凡夫看重女色，甘願作為它的奴僕；終其一生奔馳勞役，為它受盡辛苦；《淨心誡觀法》說：貪愛女色的人驕慢，貪愛財物的人慳吝；既然既驕慢又慳吝，即使還有其餘的德行，也不足稱道了。從「染心」以下，說明制戒的嚴急切要。然而內心的微細妄動，粗淺的心思根本覺察不到；縱然明知違犯戒律，想要克制約束依然十分困難；

【534-0003】資持記/07c_中一下#6
【原文】豈況悠悠，終無清脫。請臨現境，自審狂心；或宛轉迴頭，或殷勤舉眼，或聞聲對語，或吸氣緣根；雖未交身，已成穢業。大聖深制，信不徒然；諒是眾苦之源，障道之本。是以托腥臊而為體，全欲染以為心；漂流於生死海中，焉能知返；交結於根塵網裏，實謂難逃。
【譯文】更何況漫不經心之人，終究無法清淨解脫。請在面臨當前境界時，自我審視狂亂妄動的內心；或者展轉回頭回望，或者殷勤抬眼凝視，或者聽聞聲音相對說話，或者吸取氣息攀緣六根；雖然尚未交合身體，卻已經構成了污穢的罪業。大聖佛陀深深予以禁制，確實絕非徒勞無益；這著實是眾多痛苦的根源，障礙修道的根本。因此，修行者若是托身於腥臊之軀，通體全以欲念染著為本心；漂流在生死的大海之中，又如何能夠知道回頭；交織盤結在根塵的羅網之內，實在可以說是難以逃脫。

【534-0004】資持記/07c_中一下#7
【原文】當自悲嗟，深須勉強。或觀身不淨，即是屎囊；或諦彼婬根，實唯便道；或緣聖像，或念佛名，或誦真經，或持神呪，或專憶受體，或攝念在心，或見起滅無常，或知唯識所變。隨心所到，著力治之；任性隨流，難可救也。《智論》中，彼謂殺戒違惱過重，何以律中婬戒在初？故此通之。
【譯文】應當自感悲傷嘆息，極力勉勵自我克制。或者觀想自身不淨，只不過是裝糞的皮囊；或者審視對方的淫根，實際上僅僅是排泄的通道；或者攀緣觀想佛菩薩聖相，或者稱念佛陀名號，或者誦讀真實經典，或者受持神咒，或者專心憶念受戒的戒體，或者攝受心念安住於正念，或者照見念頭生滅無常，或者了知一切唯是心識所變現。隨著心念所到達之處，奮力施加對治；若是任由習性順隨慾流，那就很難拯救了。《大智度論》中提到，有人認為殺戒違逆惱害眾生的過失最重，為何律典中卻將淫戒排在第一？因此此處予以通融解釋。

【534-0005】資持記/07c_中一下#8
【原文】文有二義：初約染著義。若望違惱，則殺重婬輕；若論染著，則殺輕婬重。又下，次約障道義。以障道中，貪欲重故。比丘法者，對簡菩薩歷劫度生，不專自利；故大乘戒，殺初婬後；比丘不爾，所以反之。然今所引，但彰過重耳。次科中四，初列境相，又三：一以趣攝。
【譯文】經文含有兩種義理：首先是依據染著的程度來論。如果對比違害惱亂，那麼殺生罪重而淫欲罪輕；如果論及染著深重，那麼殺生罪輕而淫欲罪重。從「又」字以下，其次是依據障道的程度來論。因為在障礙佛道的因素中，貪欲最為嚴重。比丘的修法，是為了簡別菩薩歷經百劫救度眾生、不專求自利；所以大乘戒律將殺戒放在首位而將淫戒置於其後；比丘戒則不是這樣，所以排序正好相反。然而如今所引用的內容，只不過是為了彰顯其過患極其嚴重罷了。下一科分為四部分，首先列出犯戒的境相，又分為三小點：第一是依道趣來攝歸。

【534-0006】資持記/07c_中一下#9
【原文】注云等者，即修羅地獄，四合為一。二約報有三，該上六趣。三約處亦三，須通三報。此下，二定犯分齊。文列四相，二生二死，相別可見。如毛頭者，斷犯處也。律下，三明不開疑想。律云：若道作道想、若疑、若非道想，並波羅夷；文舉畜趣，餘趣同然。餘下，四示異。彼約根節，論犯分齊；
【譯文】注文中說「等」字，就是指阿修羅與地獄，四種合成一類。第二依據果報分為三種，涵蓋了上述的六趣。第三依據行淫處所亦分為三種，必須通貫於三種果報。從「此下」開始，第二是判定犯戒的界限範圍。文中列出了四種相狀，兩種生者兩種死者，相貌差異顯而易見。所謂如毛髮之頭，是判定犯戒之處。從「律下」開始，第三是說明不開許懷疑或錯想。戒律說：若是正道作正道想、若是懷疑、若是非道想，全都構成波羅夷罪；經文中雖列舉畜生道，其他各道也是同樣如此。從「餘下」開始，第四是顯示各部派的差異。彼部派是依據生殖器官的節度，來論定犯戒的界限；

【534-0007】資持記/07c_中一下#10
【原文】口要過齒，二道過皮。此律毛頭微入即犯，性重宜急，不必待過。《戒疏》云：極微尚犯，何況餘者是也。三中，初敘情見。上二句，縱其所知。及下，示其制重。問犯，謂究問教法也。約下，述其愚暗。此有四過：一生厭惡，不欲問故；二無尊重，生輕笑故；三無深信，疑非佛說故；
【譯文】口道必須深入過齒，大小便二道必須深入過皮。本律則是毛頭稍微進入即構成犯戒，由於性質嚴重應當嚴急制止，不必等待完全深入過限。《戒本疏》說：極其微小的進入尚且構成犯戒，更何況是其餘深入的情形呢，指的就是這個意思。第三門中，首先敘述凡情偏見。前面兩句，寬容其所已知的知見。自鈔文「及」字以下（及論問犯），開示其制戒的嚴重。所謂問犯，是指追究探問教法。自鈔文「約」字以下（約相示過），敘述其愚蠢冥暗。這裡面有四種過失：第一是生起厭惡，不想詢問；第二是毫無尊重，輕浮譏笑；第三是沒有深切信心，懷疑非佛說；

【534-0008】資持記/07c_中一下#11
【原文】四不正見，怪作是說故。故下，引誡。法師，即論主；將集此戒，故先約勒。文中三，初遮眾情。生下，教觀察。生慚愧者，克己自責也。世間愚人，誰能反照；身行鄙穢，殊不省非；及聞教說，反生驚怪。汝必惡聞，何如不作；汝既自作，何得惡聞。
【譯文】第四是抱持不正之見，驚怪佛陀為何作這種宣說。自鈔文「故」字以下（故善見云），引用訓誡。所謂法師，就是論主；即將彙集此戒，所以事先予以約束告誡。文中分為三部分，首先遮止大眾的凡情妄見。自鈔文「生」字以下（生慚愧心），教導應當自我觀察。所謂生起慚愧，是指克制己心、深自責備。世間的愚昧之人，有誰能夠反觀自省；身體力行卑鄙污穢之事，卻絲毫不反省自己的過非；等到聽聞教法宣說，反而生起驚訝怪罪之心。你若是厭惡聽聞，何不乾脆不要做；你既然自己做了，又怎能厭惡聽聞呢？

【534-0010】資持記/07c_中一下#13
【原文】後約境合辨緣，既開身交，故就心明犯。初緣，先示犯相，次正列緣。裹隔者，用物裹根以隔之；律文，四句皆犯。一有隔有隔〔彼此俱有。〕，二有隔無隔〔此有彼無。〕，三無隔有隔〔此無彼有。〕，四無隔無隔〔彼此俱無。〕；《善見》云：於女三道，或以樹葉、或衣、或熟皮等，隨得物而用隔也。
【譯文】後一段依照與境相合來辨別犯緣，既然已經開許身體被迫交接，所以純粹就內心動念來辨明犯戒。第一種犯緣，先開示犯相，其次正式列出犯緣。所謂裹隔，是用物件包裹生殖器官以作間隔；律文中說，四種句型皆構成犯戒。第一是雙方皆有隔礙〔彼此都有包裹。〕，第二是己方有隔礙對方無隔礙〔此方有而彼方無。〕，第三是己方無隔礙對方有隔礙〔此方無而彼方有。〕，第四是雙方皆無隔礙〔彼此都沒有包裹。〕；《善見律毗婆沙》說：對於女子的三道，或者使用樹葉、或者使用衣布、或者使用熟皮等物，隨手取得物品用作隔礙。

【原文】彼因比丘以根刺它口中，生疑白佛，佛斷如文。刺者，即毛頭，相同今宗也；非戲者，即有欲心，同上所判。受刺亦爾，約比丘言之。次《十誦》中，上論戲笑，皆約口道；觀其引意，似決上犯；復似顯別，學者詳之。口道同《伽論》，二道同四五二律。

【原文】以境通兩戒，犯隨心別，故須辨之。文又分三：初示當戒分齊。若下，二約心簡濫。前簡漏失；由下，後顯今戒。指《戒疏》者，彼問死屍半壞，行染得何罪？答：有二緣，若唯重淫意，入便偷蘭；縱出不淨，不犯僧殘；若欲喜樂意者，如《十誦》、《五分》；
