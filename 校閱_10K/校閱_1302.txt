# 校閱材料　第1302檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1302-0001】資持記/14a_下二#52
【原文】答中。內煮準據大界中煮，不論人之有無。內宿俱隨人物共處，不問界是僧食。第三護淨，翻淨中，初文為三，初敘益。一方別住，謂眾同之處。維持佛法者，即弘讚之人。通僧路者，隨處可食故。順佛懷者，不違聖制故。今下，二斥非，前斥貪噉乖儀。叵猶不可也。
【譯文】回答之中，內煮是依據在大界之中煮食來論處，不論該處有無人員。內宿則是食物與人共處一處，不問該界是僧界還是食界。第三「護淨」與「翻淨」之中，第一段分為三個部分，首先敘述利益。所謂「一方別住」，是指大眾共聚之處。所謂維持佛法的人，就是弘揚讚歎戒法之人。所謂「通僧路」，是因為隨處都可以食用的緣故。所謂「順佛懷」，是因為不違背聖者制戒之意。從「今」字以下，第二部分斥責過非，前面斥責貪戀噉食而乖違僧儀。「叵」猶如不可。

【1302-0002】資持記/14a_下二#53
【原文】俗中所恥者，儒宗君子尚遠庖厨，故舉以況之。脫下，次斥倚濫開教。因染污者，開宿觸也。若緣無者，謂時豐也。初猶都也。此心即觸宿之心；妄心無準，以教範之；即佛所謂當為心師而勿師心；彼不信之，故多自任。欲下，三生起。反穢謂曾染污，以法翻之令淨。緣淨中。
【譯文】世俗中所感到恥辱的，即儒家君子尚且遠離庖廚，所以舉此為例來作比況。從「脫」字以下，接著斥責藉口依託開許之教。因染污而起者，是開許宿食與惡觸。若是因緣不存在，是指豐衣足食之時。「初」猶如全然。所謂「此心」，就是觸污與宿食的心念；妄心沒有準則，必須用教法來規範約束；也就是佛所說的應當作自心的導師，而不要以妄心為師；那些人不信奉這個道理，所以多憑藉己意任意妄為。從「欲」字以下，第三部分發起後文。所謂「反穢」，是指曾經被染污過，必須依法加以翻改使其潔淨。在「緣淨」之中。

【1302-0003】資持記/14a_下二#54
【原文】得佐助者，如下《十誦》開惡觸也。體淨中。自安水等者，即下《僧祇》開惡觸自煮，諸僧器等開觸宿。體不淨中，即引《多論》。穢財造佛，持戒人不得禮。供僧不得受，食亦犯提，至死方淨。言心惡者，如〈隨相〉引；收販之人，常願荒儉王路隔塞等。上下，總示。正經即諸律論。
【譯文】得以佐助，就如下文《十誦律》中開許惡觸一樣。在「體淨」之中，自行安放清水等，就是下文《僧祇律》開許惡觸與自煮，諸僧器等則開許觸摸與過宿。在「體不淨」之中，即引用《多論》。用不淨財物造佛像，持戒的人不得禮拜；用來供僧則不得接受，若吃了也犯波逸提罪，直到命終才算清淨。所謂「心惡」，如同〈隨相篇〉所引用的；從事販賣囤積的人，常常期盼發生饑荒、官道阻隔閉塞等等。從「上」以下，總體提示。「正經」就是指諸部律論。

【1302-0004】資持記/14a_下二#55
【原文】初二不須翻，第三不可翻。緣不淨中。須臾者，但取少時。刨音炮，正作鉋，去呼，刃治木也。《十誦》。餘不盡者，謂洗器不淨，污染於物，故令轉易。《業疏》云：隨用少許，於六眾中展轉博之〔準此不必盡易〕，或可類準轉易，令易穢器。《善見》，初明易食。若下，明翻器。
【譯文】前兩種不須翻改，第三種則不可翻改。在「緣不淨」之中，「須臾」只是指短暫的片刻。刨音同炮，正字寫作「鉋」，讀去聲，是用刃削治木材。在鈔文引《十誦律》處，所謂「餘不盡者」，是指洗刷器皿不徹底乾淨而污染了物品，所以令其轉移更換。《業疏》說：隨意取用少許，在六眾之中輾轉交換（依此看來不必全部更換），或者可以類推轉移更換，令其換去受污穢的器皿。《善見律》首先說明換除食物。從「若」字以下，說明翻洗器皿。

【1302-0005】資持記/14a_下二#56
【原文】《四分》中。注文，點上七杓；若是常用，亦不得觸。非常用者，即體淨也。問中。欲彰聖意，故特問之。答中，初科。但制宿觸，則免六過。三聖即三乘。《楞伽》證大乘，彼云寺舍烟不斷常作種種食；依實修行者，不應食此食。
【譯文】《四分律》中，夾注文中提到點上七杓之法；若是平常經常使用的器皿，也不得觸碰。不是平常經常使用的器皿，就屬於實體潔淨。問答之中，為了彰顯聖人的本意，所以特別提出質問。回答之中，這是第一科。只要防制過宿與惡觸，就能免除六種過失。「三聖」就是指三乘。《楞伽經》證成大乘，該經說寺舍中炊煙不斷、經常烹煮種種食物；依真實法修行的人，不應當吃這種食物。

【1302-0006】資持記/14a_下二#57
【原文】《十誦》證小乘，彼初聽結淨已，外道譏言禿居士舍倉庫食厨，白衣無別，因令僧坊外作。引文中，《護淨經》。彼云佛往昔共阿難行，遇值一池，深廣各四十里；池中有蟲，形如蝌蚪；佛語阿難：此池中蟲者，十方世界本是眾僧食不淨食，墮此臭穢糞屎池中，常食不淨等，餘同鈔引。
【譯文】《十誦律》證成小乘，該律中記載當初准許結淨地之後，外道譏嫌說這是禿頭居士的房舍，有倉庫與廚房，與在家人毫無分別，佛因此下令在僧坊之外操作。引用的經文中，有《護淨經》。該經說佛陀過去曾與阿難同行，遇到一個大池，深廣各四十里；池中有蟲，形狀像蝌蚪；佛告訴阿難：這池中的蟲，原本是十方世界的出家眾僧，因吃了不淨之食，才墮落到這臭穢的糞屎池中，長年吃不淨之物等，其餘內容如同鈔中所引。

【1302-0007】資持記/14a_下二#58
【原文】經中墮蟲猪狗蜣蜋，並五百萬世，故云各也。因說知事者，彼云：昔有羅漢，向暗上廁；見一比丘在邊呻吟，羅漢問云：汝本好人，云何墮餓鬼中？答言：我飢渴來久等，餘如鈔。又云：憶念曾作比丘，知僧淨事；觸僧淨食，以不淨食食眾僧故，故致此殃；羅漢為呪願，得免餓鬼，還復人道等。
【譯文】經中說墮落為蟲、豬、狗、蜣螂，各受五百萬世之苦，所以說「各也」。順帶提及知事僧人的因緣，經中說：過去有一位羅漢，天黑時去上廁所；看見一個比丘在旁邊呻吟，羅漢問道：你本是個好人，為何墮落到餓鬼之中？答道：我飢渴已久等，其餘如鈔文所述。又說：回憶起過去曾作比丘，掌管僧中淨食事務；觸污了僧中淨食，以不淨之食給大眾僧吃，所以招致這個災禍；羅漢為他咒願，才得以免除餓鬼之身，轉還人間等等。

【1302-0008】資持記/14a_下二#59
【原文】蜣蜋，噉糞蟲也。《智論》：淨信檀越施僧求福，名福田食。下文指廣，須者檢看。《大集．濟龍品》。彼云：時有一盲龍舉聲大哭，作如是言：大聖世尊願救濟我，我今身中受大苦惱，日夜常為諸蟲咂食，居熱水中，無時暫樂。
【譯文】蜣螂就是吃糞的蟲。《大智度論》說：具足清淨信心的檀越布施給僧眾求取福報，這稱為福田食。下文指示詳盡之處，需要的人請去查閱。《大集經．濟龍品》中說：當時有一條瞎眼的龍放聲痛哭，說道：大聖世尊，願您救濟我，我現在身中遭受極大的苦惱，日夜常被各種蟲吸食，處在沸水之中，片刻沒有安樂。

【1302-0009】資持記/14a_下二#60
【原文】佛言：汝過去世時曾為比丘，毀破禁戒，內懷欺詐，外現善相，廣貪眷屬，弟子眾多，名聲四遠；以是因緣，多得供養，獨受用之。見持戒人，反加惡說；彼人懊惱，如是念言：世世生中食汝身肉；如是惡業，死生龍中。又過去無量劫中，在融赤銅地獄中，常為諸蟲食噉；
【譯文】佛說：你在過去世曾作比丘，毀壞禁戒，內懷欺詐，外現善相，廣泛貪戀眷屬，弟子眾多，名聲遠播；以這種因緣，得到很多供養，卻獨自受用。看見持戒的人，反而加以惡語誹謗；那人心懷懊惱，便發念道：世世代代生生世世我要吃你的身肉；因為這樣的惡業，死後墮入龍族之中。又在過去無量劫中，在熔銅地獄之中，常常被諸蟲啃咬吞食；

【1302-0010】資持記/14a_下二#61
【原文】乃至眾中二十六億諸餓龍等，悉皆雨淚；念過去身，雖得出家，備造惡業，經無量身，在三惡道；以餘報故，猶在龍中受極大苦。佛語諸龍：汝可持水洗如來足，令汝殃罪漸得除滅。諸龍以手掬水，水皆成火，變作大石，滿於手中，如是至七，亦復如是；
【譯文】乃至大眾之中二十六億餓龍等，全都淚如雨下；回想起過去之身，雖然得以出家，卻造盡了惡業，經歷了無量身形，墮於三惡道中；因殘餘業報的緣故，如今仍在龍族中受極大痛苦。佛告訴諸龍：你們可以捧水洗如來的足，讓你們的罪殃漸漸得以除滅。諸龍用手掬水，水都化成了火，變成了大石滿握手中，如此反覆到第七次，依然如此；
