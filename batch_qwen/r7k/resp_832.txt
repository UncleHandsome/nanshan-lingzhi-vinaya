以下按「重大語意問題 → 次要用詞 → 體例一致性 → 原文校勘／史實（宜加註不改譯）」四層來看。整體譯筆流暢、科判對應清楚，主要毛病集中在 **832-0003 的兩處硬傷**，以及幾處「未依《記》文而自創新解」的地方。

---

## 一、必須修正（重大）

### 1.【832-0003】「用古尺一，今魏一尺」譯反了 ★最嚴重

- 原文：「故隨世立，用古尺一，今魏一尺。」
- 譯文：「所以隨著世俗設立新制，**將原本的一尺定為新魏尺的一尺**。」

問題：全篇的論證前提就是「魏尺大、古（宋）尺小」——【0001】「元魏所用一尺當於宋家一尺二」、【0004】引《雜令》「以一尺二寸為尺」。此處若作「古尺一尺＝魏一尺」，等於說兩者相同，**與上下文直接矛盾**。

原文此句顯有脫文，應作「故隨世立〔尺〕，用古尺一〔尺二為〕今魏一尺」。

建議改譯：
> 於是隨當時世情另立尺度，**以古尺的一尺二寸作為魏的一尺**。（原文此處疑有脫字，據上下文及《唐雜令》補。）

### 2.【832-0003】「律量衡平」誤拆為「律呂／容量／權衡」

- 譯文：「至於推算恆星宿次的分度、**律呂度數、斗斛容量、權衡輕重等度量衡標準**、醫藥的分銖、宗廟祭祀的升斗容量……」

問題：《記》【0004】已明界定義：
> 「律量」，謂俗律決犯，並準丈尺。「衡」，猶準也。**上二辨尺**。「藥」下，明秤……「祠」下，明升斗……**已上四事**。

即四事＝①星次（尺）②律量衡平（尺，刑律依丈尺量刑）③藥石（秤）④祠祭（升斗）。譯文把「律量衡平」讀成律呂＋量＋衡，**既違《記》解，又把「四事」變成六、七項**，與下文「已上四事」牴觸。

建議改譯：
> 至於星辰躔度宿次的劃分、**刑律量刑判定（皆依丈尺）的準則**、藥物的分銖劑量、祭祀的升合容量，無不是以古制為準。

### 3.【832-0004】「通明物理」主語錯置

- 原文：「煬帝，隋第二主，撰《博物志》，通明物理。」
- 譯文：「煬帝是隋朝第二代君主，撰寫了《博物志》，**通達明曉物理制度**。」

「通明物理」是說**該書**通曉闡明萬物之理（故下句才說它「還依古行」可為據），不是說煬帝本人；且「物理」＝事物之理，非「物理制度」。

建議：
> 「煬帝」是隋朝第二代君主，他撰有《博物志》，**此書通達闡明萬物之理**。

### 4.【832-0004】「合和兩分」漏譯「分」

- 譯文：「二十四銖為一兩，**調配藥物各取若干兩**，是絲毫不能增減的。」

「兩分」是重量單位「兩」與「分」，非「若干兩」。

建議：
> 二十四銖為一兩，**合藥時所用的兩、分劑量**，絲毫不能增減。

### 5.【832-0001】「通於東西」把兩解併成一解

- 《記》：「東西，即南北二朝，**或可**花梵兩土。」（二說並存）
- 【0001】譯文：「所以能貫通**南北與梵漢**」→ 變成兼指，且與【0002】「或者可以指……」自相矛盾。

建議【0001】改：
> 所以能會通南北二朝（一說指華、梵兩地）的度量，判定尺秤的標準，確實是有其緣由的。

## 二、次要用詞／語意

| 編號 | 譯文 | 問題與建議 |
|---|---|---|
| 0001 | 「本律中沒有**明確的折算尺寸**文字可供依循」 | 增譯過多。宜：「本律沒有（磔手尺寸的）明文可依。」 |
| 0001 | 「應以魏朝的**兩尺**作為佛的一磔手」 | 「兩尺」是推算所加，宜與後面折算一併放在括注內，避免混入正文。 |
| 0002 | 「上一句說明《本律》**有所欠缺**」 | 「缺」指缺文，宜：「本律缺（尺寸之）文」。 |
| 0002 | 「**翻譯者未能詳查**」 | 「不詳」是不清楚實情，非未去查考。宜：「譯者不明（此地尺度實情）」。 |
| 0002 | 「不熟悉**此地**的時局制度」 | 「此方」宜作「漢地／中國」，較貼原意。 |
| 0002 | 「就像把『果汁』**誤譯**為『木蘭』」 | 「誤」字是 added judgment；原文只作「以……為……」。宜：「例如把『果汁』譯作『木蘭』之類」，另加註說明此典故（涉染衣壞色用藥，宜查《僧祇》原文再定是否為誤譯）。 |
| 0002 | 「華夏與天竺**兩國**」 | 「兩土」宜作「兩地」（天竺非一國，華夏亦非國名）。 |
| 0003 | 「都**未曾改變沿用**」 | 語病。宜：「都相沿未改」。 |
| 0003 | 「**升斗**容量」（祠祭升合） | 「合」是十分之一升，非斗。宜：「升、合等容量」。 |
| 0003 | 「以求**通達世俗習慣**」 | 「以通時俗」＝順應／通行於當世習俗。宜改。 |
| 0003 | 「《律本》」 | 宜註明即《四分律》（姚秦佛陀耶舍譯），讀者才知為何接「姚秦時政」。 |
| 0004 | 「記述唐朝**沿襲使用了這種變革**」 | 「承用」指承襲沿用魏尺。宜：「敘述唐代承襲沿用（魏尺）」。 |
| 0004 | 「來明確其行度的**軌跡**」 | 「行度」是運行度數，非軌跡；「必約分數」宜作「必須依一定的度數劃分」。 |
| 0004 | 「『衡』，就是**平準尺度**的意思」 | 宜：「『衡』就是『準』（依準、標準）的意思」。 |
| 0004 | 「以上兩種是辨明**尺規**」 | 「尺規」易誤解為工具。宜：「以上兩項是辨明用尺（的場合）」。 |
| 0004 | 「鎮守建業，在建康建立國家政權」 | 建業＝建康（同城改名），宜加短註，否則讀者以為兩地。 |

## 三、體例一致性（建議統一）

1. **《記》文標舉字詞，應保留疏文原字**，不宜換成白話詞，否則失去「某字以下」的對應：
 - 【0002】「從『**聽聞**』以下」→ 疏文作「聞」，宜「『聞』下（即『聞傳佛教』以下）」。
 - 【0004】「『**習慣**』以下」→ 疏文作「習俗生常」，**應作「習俗」**（現譯與疏文不符）。
 - 【0002】「『五分律』以下」「『僧祇律』以下」→ 原標「五分」下、「僧」下，可寫「『五分』下」。
2. 【0001】與【0002】對「東西」的處理要一致（見上第5點）。
3. 「宋朝」宜一律作「南朝劉宋」，並在首見處註明《僧祇律》實際譯於東晉末（見下）。

## 四、原文疑誤／史實：建議「加譯註」而非改動譯文

譯文這幾處都忠實照譯，處理方向正確，但讀者容易被誤導，建議補註：

1. **校勘**
 - 【0002】「元魏都長安為**朝**」——疑脫「北」字（譯文已補「北朝」，可出校）。
 - 【0002】「明星辰**纏**度」——當作「躔度」；「地里書」即「地理書」。
 - 【0003】「用古尺一，今魏一尺」——脫文（見上第1點），**務必出校**。
2. **史實**
 - 元魏都**平城、洛陽**，長安是西魏／北周都——元照原文如此，宜註不改。
 - 《摩訶僧祇律》為佛陀跋陀羅與法顯譯於**東晉義熙十四年（418）**，劉宋尚未建國；疏、記稱「宋朝」是南朝泛稱。
 - 佛陀跋陀羅為**迦毗羅衛（北天竺）** 人，《記》作「中天竺」。
 - 《五分律》譯人為佛陀什、竺道生、**慧嚴**；疏作「智嚴」，疑誤（智嚴是迎請佛陀跋陀羅者）。
 - 《博物志》舊題張華撰，此處云煬帝撰，宜註「元照所據待考」。
 - 「俗律決犯並準丈尺」可加一例說明（如唐律對杖長、絹布計贓以尺計），讀者較易理解「律量」為何屬「尺」。

## 五、【832-0003】建議整段改譯（供參）

> 【疏文】南方的尺本是姬姓周朝所用之尺，歷經秦、漢、曹魏，都相沿未改；晉室南渡以後，這套尺法便固定下來。元魏平定北方亂世時，典籍焚毀散失，沒有可資依循的標準，於是隨當時世情另立尺度，**以古尺一尺二寸作為魏的一尺**（原文此處疑有脫字）。唐代《雜令》所述，也還是如此（以一尺二寸為一尺）。隋煬帝所撰《博物志》，則仍依古尺而行。習俗既久便成常軌，所以古尺不被採用，現今（唐代）仍用魏尺，以順應當世習俗。至於**星辰躔度宿次的劃分、刑律量刑（依丈尺）的準則、藥物的分銖劑量、祭祀的升合容量**，無不是以古制為準。所以《四分律》本說「大鉢受三斗，小鉢一斗半」——姚秦當時的制度，使用古量尚未訛變，因此所譯的律文，頗為通行允當。
