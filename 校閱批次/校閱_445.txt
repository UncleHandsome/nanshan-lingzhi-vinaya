# 校閱材料　第445檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【445-0001】資持記/10b_中三下#28
【原文】四緣者，一常請〔彼言我常與藥也〕，二更請〔斷已後復更請與之〕，三分請〔持至僧伽藍分與之〕，四盡形請〔我當盡形與藥〕。疏云：常與盡形有何別者？就能所以分也。〔常請約能施，盡形約所施。〕示犯中。猶同昔義，準疏反之。彼云：此戒索輕，過限重也；
【譯文】四種特許因緣為：第一是「常請」〔施主明言我將長年固定供給醫藥〕，第二是「更請」〔供給中斷之後施主又重新再次邀請供給〕，第三是「分請」〔施主將藥物直接送到僧團寺院中平均分配分給眾人〕，第四是「盡形請」〔施主發願說我將盡形壽終身供給醫藥〕。《戒疏》說道：長請與盡形請究竟有何差別？這是從施予者的主動能動性與被動受用性來作區分的。〔常請著重在能布施之人的常態發心，盡形請著重在受施之人的身命終盡。〕在標示犯戒的情節中。如今的看法仍然依循往昔的舊義，若依照《戒疏》的評判則剛好相反。彼疏說道：這條戒本來是索求藥物結罪較輕，但如果超逾了施主承諾的期限，結罪反而加重；

【445-0002】資持記/10b_中三下#29
【原文】所以然者：先有好心，四月與藥；期限已滿，供養心息；過受置惱，敗損處深；又承前受請，人喜過日故重。餘不具引。四十八。〔佛在舍衛，人民反叛，王領軍征伐，六軍觀陣，匿王不悅，故制。〕制意中。初明住持；二是化他；三成自行，由觀兵鬪，凶暴無慈，失諸善利。
【譯文】之所以會如此，原因在於：施主最初存有純善的好心，答應四個月供養醫藥；如今約定的期限已經屆滿，其發心供養的意願已經止息；出家人若強行索求過度接受，會給施主帶來惱亂困惑，對僧伽聲譽與道心的敗壞損害極為嚴重；再加上貪戀先前的受請供養，修行人容易貪圖安逸而度日，所以結罪深重。其餘的文句在此不再一一俱引。第四十八條戒。〔佛陀在舍衛國時，境內人民叛亂，國王率領軍隊前往征伐，六群比丘前去觀看軍陣，波斯匿王感到不悅，因而制定此戒。〕制戒的用意中。第一是為了護持正法久住世間；第二是為了教化導引他人；第三是為了成就自身的修行，因為觀看兵刃相鬥，會增長凶暴殘忍而喪失慈悲心，進而喪失種種善法功德利益。

【445-0003】資持記/10b_中三下#30
【原文】初緣，律中下至一馬一車一步卒皆犯。第三，即下被請道斷等開。釋中，初科，《四分》初明犯。上二句釋軍陳。戲謂遊驛教習之時，真謂正鬪。律作若戲若鬪，其相可解。若軍下，次明相值。方便謂雖下道，偷目顧眄。若被下，明不犯。律列多種，謂若有事往；若下道避，惡獸賊難，大水漲，命梵等，不下道無犯。
【譯文】第一條犯緣，律典中規定哪怕低微至僅看一匹戰馬、一輛戰車、一名步卒，全都算犯戒。第三項，就是指下文提到的被國王差遣請託、道路阻斷受阻等開許之緣。在解釋文句中，第一科《四分律》開頭先說明犯戒的行為。上面兩句解釋何謂「軍陣」。「戲」是指平常巡行操演、教習戰陣的時候，「真」是指雙方兩軍真正交戰搏鬥之際。律典原文寫作「若戲若鬥」，其行相十分淺顯易懂。「若軍」以下，次一步說明在路途上與軍隊相遇的情形。「方便」是指雖然走下道路迴避，卻依然偷眼斜視瞻顧。隨後說明不犯的情形。律典列舉了許多種，例如若有公務要事前去；或者若要走下道路避讓，卻遇上凶惡野獸、盜賊劫難、江河大水暴漲，或是危及生命與梵行等災難時，不離開道路直接穿行不算犯戒。

【445-0004】資持記/10b_中三下#31
【原文】釋二中，《僧祇》，初明逢軍。準意斷犯。若天下，明非陣。三相皆輕。天王即國君儀伏。畜鬪人爭，皆相因而制。《十誦》。由覩相殘，易生厭離。雖有此文，世多濫倚；自非實行，往觀皆犯。四十九。〔六群有緣至軍中宿，招譏因制。〕初緣，《多論》四意，上三利他，四即相利。
【譯文】在解釋第二科中，《僧祇律》開頭說明路遇軍陣的情節。這是依照內心的動機來裁斷是否犯戒。「若天」以下，說明並非實戰軍陣的情況。這三種相狀所結的罪都較輕。「天王」是指一國之君出巡時的儀仗護衛。觀看牲畜相鬥或眾人爭鬥，全都是以此戒的意旨為因由而比照制戒。《十誦律》說：由於目睹生靈自相殘殺，內心容易生起厭離生死之意。雖然律典有這段文句，但世間修行人大多以此為藉口而浮濫依傍；如果自己並非真正具備純熟的道行，前去觀看搏殺就全屬犯戒。第四十九條戒。〔六群比丘因為有特定因緣而前往軍隊營地中留宿，招致世人譏嫌，因而制定此戒。〕第一條犯緣，《多論》列出了四種原由，前面三種是為了利益他人，第四種是為了彼此互利。

【445-0005】資持記/10b_中三下#32
【原文】彼又云：若不開往，便謗云：比丘有求不喚自來，無求時雖喚不來；若往說法令悟道果，故開往也。律不犯者。第三宿明相未出離見聞處，水陸道斷命梵等不往，皆開。五十。〔六群有緣在軍中觀鬪力，一人彼箭射舁歸招譏故制。〕此戒因前而制。疏云：既有緣至，應坐說法；後看合戰，為刃所中；
【譯文】彼論又說：如果不開許前往，世人便會毀謗說：比丘凡是有所貪求時不用呼喚自己就跑來，沒有索求時即使再三呼請也不肯來；比丘如果前往營中宣說佛法，能令軍士覺悟證得道果，所以特許開緣前往。律典中不犯的規定為：到了第三夜黎明曙光尚未出現前就必須離開軍營可見可聞的範圍，若遇水陸交通阻斷、危及生命與梵行等事故而無法離去，全部予以開許。第五十條戒。〔六群比丘因為有緣由滯留軍營中觀看將士搏鬥角力，其中一人被飛箭射中，由他人用擔架抬回寺院，招致世人譏嫌，因而制定此戒。〕這條戒是依託前一條戒的因緣而進一步制定的。《戒疏》說道：既然已有正當因緣抵達軍中，理應端坐為眾人講經說法；後來卻跑去看兩軍交戰搏殺，結果被兵刃箭矢射中；

【445-0006】資持記/10b_中三下#33
【原文】犯同於初。〔即觀陣戒。〕不犯亦同前戒，故文不列。五十一。〔佛在支陀國，娑伽陀比丘降龍示俱睒彌王，得酒飲醉，臥路因制。〕制意中，本律，初示嚴勅。以為資者必稟師教，不可違故。乃下，明急制也。今時學法，率多嗜酒。臨此慈訓，那不自慚！因下，顯過。
【譯文】其所犯的罪過與最初的戒律相同。〔也就是指觀看軍陣戒。〕不犯的各項開緣也完全與前一戒相同，所以戒文不再重複列舉。第五十一條戒。〔佛陀在支陀國時，娑伽陀比丘降伏了惡龍顯現威德給俱睒彌王看，後來得到民眾供養的酒飲喝得酩酊大醉，倒臥在路旁，因而制定此戒。〕制戒的用意中，依照本律，開頭先宣示了極為嚴厲的訓誡。因為作為依止佛陀的佛子，必定要稟承導師的教誨，絕對不可以違逆背棄。「乃」字以下，說明這是十萬火急、刻不容緩的重戒。如今這個時代的學律修道之人，大半都極度嗜好飲酒。面對佛陀這般慈悲嚴厲的訓誡，內心怎能不深感慚愧！「因」字以下，明白揭示飲酒的過失。

【445-0007】資持記/10b_中三下#34
【原文】一顏色惡，二少力，三眼視不明〔此三及六損色〕，四現瞋恚相〔此一與九亂神〕，五壞業資生〔破家〕，六增疾病，七益鬪訟〔長業〕，八無名相〔喪德〕，九智慧少，十命終墮三惡道。〔上九現惡，十即來苦。〕觀斯十過，現事灼然。世愚反云益力治病者，不亦謬哉！

【原文】法怖者，語云夢汝死罷道等。五見聞者，對上兩緣。不下，示犯。不問前人者，以怖就能犯作意為言，不取所怖。不犯中，初開色聲。謦欬，謂嗽聲也。若以下，開非意。則通六塵。若實下，點法塵。下開戲誤，可知。五十六。
【譯文】「法恐怖」，是指用語言恐嚇說我夢見你即將暴斃身亡、必定會破戒還俗退道等等。第五項以眼見或耳聞來恐嚇，是對應前面的兩種因緣。隨後說明犯戒的相狀。不論被恐嚇的對方（前人）是否真的受驚害怕，因為這條戒的恐嚇罪責完全是依據能恐嚇者主觀上存有故意嚇人的惡意來判定的，並不以受恐嚇者實際產生的恐懼程度為標準。在不犯的條文中，開頭先開許了無意間發出色相與聲音的情形。「謦欬」是指咳嗽、清嗓子的聲音。隨後開許並非存心嚇人的情形。這便廣泛通於色聲香味觸法六塵。隨後點明了法塵的不犯相狀。至於下文開許純粹開玩笑或是無心之誤，文義顯明容易明瞭。第五十六條戒。
