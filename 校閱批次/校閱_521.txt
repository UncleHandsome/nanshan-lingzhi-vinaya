# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【521-0001】03_業疏/11b_卷二之五#103
【原文】五中初標示。「如下」出計。或有計云我大色小、色在我中，或計色大我小、我在色中，受、想、行、識竝有二計，歷之可見。「佛下」對破。「為在」等者，且舉二陰，略受想行，此即離求；應云「為總在五陰中」，此名合求。得無我理，即是我空，亦名人空、生空真如也。分成相似，即是內凡世第一人
【譯文】第五段中，起初標明指示。自「如彼」以下，指出外道妄計。或者有人執計說「我大色小，色在我之中」，或者執計「色大我小，我在色之中」，對於受、想、行、識也同樣各有這兩種執計，依序歷算便可明了。自「佛法」以下，針對破斥。所謂「為在色中」等語，是暫且舉出色、識二陰，省略了受、想、行三陰，這就是分別推求（離求）；還應當說「或者總在五陰之中」，這稱為總合推求（合求）。證得無我之理，也就是我空，亦稱為人空、生空真如。所謂「部分成就相似」，就是指內凡位中的世第一法之人。

【譯文】第六、從「識」來論述，是為了破除「單一神識」的外道理論。就像有一間屋子而設有六扇窗戶，一隻獼猴在各個窗戶處隨處顯現，無知之人便以為有六隻猴子，其實只有一隻。人也是這樣，根門雖然有六個，卻只有一個神識在其中周流貫通。佛法並非如此，識是隨順各自的根門與境相應而生起，如果真是一個神識，難道會在閉目睡眠（眠根）之時還能聽聞聲音嗎？由此可知彼論是錯誤的。

【521-0010】03_業疏/11b_卷二之五#112
【原文】十、約諸入者，破色空為道也。彼增修定，緣色住心，以色滅欲有，以空滅色有，謂空至極，更不重修。佛法不爾，須尋本際，但是自心運用多少，實唯一識，本無前境，但是妄倒自立是非，我見不除，還受生死。故智論云：「外道能生禪定船，度欲色界海，無色界海深廣，難可得度，由不破我心故
【譯文】第十、從「諸入」（定境處所）來論述，是為了破除以色與空為究竟之道的見解。他們輾轉增進修習禪定，攀緣色相而安住心念，以色界定業滅除欲界之有，以空無邊處定滅除色界之有，認為空就是至極之道，便不再進一步修習。佛法並非如此，必須推求萬法的本原實相，這只不過是自己心識運轉運用的範圍廣狹多少而已，實質上唯有一識，本來就沒有心外現前之境，只是妄想顛倒而妄自建立是非取捨；如果我見不除，終究還是要遭受生死輪迴。所以《大智度論》說：「外道能生禪定船，度欲色界海，無色界海深廣，難可得度，由不破我心故。」

【521-0011】03_業疏/11b_卷二之五#113
【原文】十中，初標。「彼」下出計。增修定者，初則緣色住心，即以定業以滅欲有亂業；此定既成，次又觀空，即用無色定業以滅色有定業；至此為極，謂為涅槃。「佛」下顯正，彼既緣色、緣空以為至極，此即用十一切處定以破之。此之十境，亦緣色、空，但是發定之處，非至極也：一、青一切處，二、黃一切處，三、赤一切處，四、白一切處，五、地一切處，六、水一切處，七、火一切處，八、風一切處，九、空一切處，十、識一切處。十皆言「一切處」者，即從所觀境徧滿為名。今名「入」者，謂從此以發定也。「尋本際」者，推於心也。「多少」，謂初觀少色，後使多偏，實唯一識，攝境歸心也。「但是」等者，彰外計之過，引證可知。
【譯文】第十段中，起初標示。自「彼」以下，指出外道妄計。所謂「增修定」，起初是攀緣色相安住心念，也就是用色界定業來滅除欲界諸有的散亂雜業；這種禪定修成之後，其次又觀修虛空，也就是用無色界定業來滅除色界諸有的定業；達到此處便以為是至極，稱之為涅槃。自「佛法」以下，顯明正理。彼外道既然攀緣色、攀緣空而當作至極，此處就用「十一切處定」來加以破斥。這十種定境雖然也是攀緣色與空，但只不過是引發禪定的處所，並非至極之道：一、青一切處，二、黃一切處，三、赤一切處，四、白一切處，五、地一切處，六、水一切處，七、火一切處，八、風一切處，九、空一切處，十、識一切處。十種都稱為「一切處」，是因為所觀照的境界周遍圓滿而得名。現在稱之為「入」，是指從此處發起禪定。所謂「尋本際」，是推求於自心。所謂「多少」，是指起初觀想少量的色相，後來使其廣大周遍，實質上唯有一識，將外境攝歸於自心。所謂「但是妄倒」等語，是彰顯外道執計的過失，所引用的經論文證顯而易知。

【521-0018】03_業疏/12a_卷三之一#3
【原文】言「比丘」者，中梵天音，此方無譯，可以陳相。如水火等，彼此同體，以名目之，得其實也。比丘不爾，元出中方，此土本無，不知何目，且用義例，得詮便止。因此四句：以義翻名、以名翻義，餘二俱句，可以例知。
【譯文】所謂「比丘」，是中印度梵天之音，此方漢地沒有相應的直接翻譯，但可以陳述其體相特徵。就像水、火等物，兩地本體相同，用名稱來稱呼它，就能切合其實質。比丘則不是這樣，他原本出自中印度，此方土地本來就沒有這種身分，不知該用何詞命名，姑且借用義理譬例，只要能夠顯明其意便止。由此形成四句分別：以義理翻譯名稱、以名稱翻譯義理，其餘兩句俱句（以名翻名、以義翻義），可以依此類推而知。
