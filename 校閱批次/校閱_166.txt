# 校閱材料　第166檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【166-0001】資持記/07a_中一下#8
【原文】由心重輕，有發不發，故云或有無等。如下，喻顯。極喻重心，香臭喻善惡，瓦木喻輕爾無記，手執喻作；除去物已，餘氣有無，用配三心，可見。〔舊云此經與《俱舍》同宗，非也。安有佛經與論同宗耶？宜云：《俱舍》等，宗此經可也。〕結中。
【譯文】由於心力的重或輕，而有引發或不引發無作的分別，所以說「或者有、或者無」等等。從「如」字以下，以比喻來顯發義理。「極」比喻極重之心，「香與臭」比喻善與惡，「瓦石木塊」比喻微輕的無記心，「手執持」比喻作戒的造作；把物品拿開之後，殘餘氣味的有或無，用來配對這三種心，其理自明。（過去有人說這部經與《俱舍論》同屬一個部派宗義，這是不對的。哪有佛經去宗奉論典的道理呢？應當說：《俱舍論》等是宗奉這部經，這樣才對。）在結語之中：

【166-0002】資持記/07a_中一下#9
【原文】問曰：今宗二戒，名體竝異，那引《多論》、《善生》而為證者？答：今此不論名體，但證二數是同；請觀結文，幸無遲慮。次解名義，問中。結前生後，總問三名。答中。作即方便搆造為義。陶家，謂土作家；輪，即範土為坏器之車；運之則轉，故以喻焉。四大質體名報色，從緣動作名方便；
【譯文】有人問：我們這一部宗派的二戒，名稱與實體都與有部不同，為何要引用《多論》與《善生經》來作證明呢？回答：現在這裡不討論名相與體性，純粹只是證明「分為兩種」的數目是相同的；請細看結語的文字，但願不要猶豫疑慮。接下來解釋名相與義理，提問之中，是總結前文並引出後文，總體詢問這三個名稱。回答之中，所謂「作」，就是以加行造作、搆畫運作作為它的意義。「陶家」是指製作陶土器的工人；「輪」就是轉動泥土做成胚器的旋轉車具；加以運轉它就會轉動，所以用它來比喻。四大假合的質體稱為「報色」，順應外緣而動轉造作稱為「方便」；

【166-0003】資持記/07a_中一下#10
【原文】報起方便，方便依報；二法相假，不一不異；但言報未必是方便，言方便其必具報。今以輪水喻報質，輪動作喻方便，即名其動以為作耳。故下，引證。身及動身，對喻可解。〔《心論》，即有部，計作戒是方便色，故但云身。〕無作中。一發者，一，猶始也。
【譯文】由真報之身生起加行方便，加行方便又依託於真報之身；這兩種法相互借資，既不是截然為一，也不是完全相異；單單說果報之身未必就是方便動轉，但只要談方便動轉就必定具備果報身。如今以轉輪與水比喻果報的質體，以轉輪的動轉比喻方便造作，就是把這個動轉造作命名為「作」罷了。從「故」字以下，是引用教證。身體以及運動其身，對照比喻即可理解。（《雜心論》即屬於有部，主張作戒是方便動轉之色，所以單單說「身」。）在無作戒的解釋中：所謂「一發」，「一」就相當於「始」。

【166-0004】資持記/07a_中一下#11
【原文】此句明業體初成，即第三羯磨竟，第一剎那，與作俱圓，是體發也。作戒既謝，無作獨存；相繼不絕，故云續現。〔舊云：一發者，作戒落謝，無作續起。此解非也。〕始，即上句一發之時；末，即終，謂命終捨也。雖通四捨，且約常途，故餘三不舉，此句明業體久長也。四心者，通舉四陰；
【譯文】這句話說明業體最初成就的時刻，也就是第三次羯磨完畢的第一剎那，與作戒同時圓滿，這就是戒體的引發。作戒隨後謝滅，無作戒獨自留存；相繼不斷絕，所以說「續現」。（舊有的註解說：「一發」，是指作戒謝落，無作戒相續生起。這種解釋是錯誤的。）「始」，就是上一句最初發起之時；「末」，就是終結，指的是生命終盡而捨戒。雖然捨戒通於四種情形，但這裡姑且依照通常的情況而言，所以其餘三種暫不列舉，這句話說明業體相續的長久。所謂「四心」，是通括受、想、行、識四陰；

【166-0005】資持記/07a_中一下#12
【原文】三性者，別示行陰；三陰，唯無記；行陰，通三性故，此句顯非心也。下句正示無作義也。若翻對作解，初句反前即謝也，次句反一念也，第三句反善行心也，第四句反緣搆也。故下，引證有二，《雜心》中。初句躡前作謝，生起無作。〔本論與上釋作戒，文相連故。〕餘識，即四心；後心望前作心，故云餘也。
【譯文】所謂「三性」，是特別指示行陰；其餘三陰在無作時唯獨是無記性；唯有行陰能通於善、惡、無記三性，這句話顯發它「非心」的特質。下一句則是正式開示無作的定義。如果反過來與作戒相對照作解：第一句反對前面作戒的隨即謝滅，第二句反對作戒僅存於一念，第三句反對作戒必須是造作善行的心，第四句反對作戒的隨緣運作造構。從「故」字以下，引證有兩處。在《雜心論》中，第一句承接前面作戒謝滅，而引生發起無作戒。（因為原本論典的這段話與上面解釋作戒的文字是相連的。）「餘識」就是指四心；隨後生起的心相望於先前造作戒法的心，所以稱為「餘」。

【166-0006】資持記/07a_中一下#13
【原文】俱即同時。是法，即無作；隨生，謂任運起也。《成論》中。通明業理，非局戒也。因心者，示現從作發也；因，是相假之義；心，即簡別有宗。生罪福，生即是發，罪福即善惡無作。文舉無記，等取餘心。通名中，初二句直示正義。由此二戒俱斷惡故。故下，引證，《涅槃》。遮制，即禁斷義。
【譯文】「俱」就是指同時。「是法」就是指無作戒；「隨生」指的是任運自然生起。在《成實論》中，是通泛說明業力的真理，並不侷限在戒法上。所謂「因心」，是顯示它是從作戒發起的；「因」是相互依憑借資的意思；「心」則是為了簡別排除有宗的色法主張。所謂「生罪福」，「生」就是發起，「罪福」就是惡性或善性的無作。經文中列舉了無記心，以此類推等同於其餘的心識。在通名（共同名稱）中，前兩句直接顯示正確的法義，這是由於這二戒都能夠斷除惡業的緣故。從「故」字以下，引用教證，出自《大般涅槃經》。「遮制」就是禁戒斷絕的意思。

【166-0007】資持記/07a_中一下#14
【原文】直是者，一言盡理，更無餘論故。《善生》。如前，即戒法第三門。制等五字，即括五義，對前可見。三出體中。法體幽微，頗涉言論；但鈔為新學，直申正理；文義簡略，致多謬妄。此既律教之源，復是修行之本；事須廣釋，少資心用。標云體狀，謂體之相狀，無別所以。
【譯文】「直是」這兩個字，是一句話道盡了至理，再也沒有其他多餘爭論的緣故。《善生經》所說的「如前」，就是指戒法中的第三門。以「制」字為首的五個字，就總括了五種義理，對照前文即可明白。在第三項「出體（顯明體性）」中：戒法本體幽深微妙，相當牽涉義理名言的辯論；只因為行事鈔是為了初學者而寫，直接陳述根本正理；以致文句與法義相當簡要，導致後人產生許多謬誤妄解。這既然是律宗整座教法的根源，又是修持實踐的根本；事情必須詳細解說，以稍微資助修心行持。標題稱為「體狀」，指的是戒體的相狀，並沒有其他的含義。

【166-0008】資持記/07a_中一下#15
【原文】示宗中，初句通示異計；今下，別示本宗。二論，即指多成。言不同者，統括部計，不出四門；所謂空、有、雙非、兩亦；雙非入空，兩亦歸有；故此四計，還即二門。此土飜傳，雖有四律；《十誦》、《四分》，時所盛弘，故今但對多宗辨異。
【譯文】在宣示宗派的部分，第一句普遍指出各派不同的計執；從「今」字以下，分別指示本宗的立場。所謂「二論」，就是指《多論》與《成實論》。說各部主張不同，總括所有部派的計執，不出四門：也就是空、有、非空非有（雙非）、亦空亦有（兩亦）；非空非有歸入空門，亦空亦有歸入有門；所以這四種主張，歸結起來依然就是空、有二門。此土翻譯傳布的律典，雖然有四部律；但《十誦律》與《四分律》在當時弘傳最為興盛，所以如今只針對多宗（薩婆多部）來辨別差異。

【原文】標中云依《多論》者，若順多宗，應云無教；但名通彼此，趣爾舉之。列釋中。問：作俱既與方便齊生，何名無作？答：雖與作俱，不妨彼體不假緣搆；以二法相違，性不可合故。疏云：不由心起，任運相感，故即號曰作俱無作是也。二形俱者，期盡壽故。形滅失者，據論受體，實通四捨，且據本期一相為言。
