# 校閱材料　第323檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【323-0001】02_戒疏/14c_卷三下之二#46
【原文】【記】次科。初示須加法。「不言氈布」，謂不論其體之精麤，但取常所用者加法持之，餘則說淨而畜。「今」下，斥非。「意」下，顯正。「意謂」即祖師所懷。初責多畜，「如衣鉢」者，以六物中坐具為一數故，既同衣鉢，豈容多畜？「若如」下，次辨如非。初示成否。「事」下，次明受用。「同三衣畜服」者，謂制隨身也。「犯持同鉢」者，離宿亦吉，而不失法。「餘」下，指廣，《事鈔．二衣》、《業疏．衣藥》，「九十」即過量戒。
【譯文】【記文】第二科。起初指示必須經過加持之法。「不論氈布」，意思是不用去爭論質料是細緻還是粗糙，只取平日經常使用者作法加持受持，其餘多餘的就必須作說淨法後才可蓄存。「如今」以下，斥責錯誤現象。「意謂」以下，彰顯正確法義。「意謂」二字代表了道宣祖師心中的探討與開示。起先責備過度多蓄，「如同衣缽」這句，是因為在比丘六物之中坐具佔其一數，既然地位等同於衣缽，豈能容許隨意大量蓄存？「若是如法」以下，接著辨別合法與非法。先說明加持受持能否成立。「事情」以下，接著說明日常受用的規矩。「如同三衣蓄存穿著」，是指戒律規定必須隨身攜帶。「違犯與受持如同瓦缽」，是指夜間若離開身邊寄宿也只結突吉羅輕罪，但並不會失去原本受持的效力。「其餘」以下，指示詳閱其他典籍，即《事鈔·二衣篇》、《業疏·衣藥篇》，而「九十」就是指其中的過量坐具戒。

【323-0007】02_戒疏/14c_卷三下之二#52
【原文】【疏】一、是貴羊毛。文除「賤」者，以開緣中「頭脚毛」故。今若生譏，何論貴賤，擔於毳等，亦越威儀。但緣在於毛，故制開外耳。《僧祇》云「成器者不犯」，「器」謂衣相也。此是通名，如今刀斧衣物通號。
【譯文】【疏文】第一、所持的是珍貴的好羊毛。條文中排除「粗賤羊毛」，是因為在開緣條款中提到「頭毛與腳毛」等賤毛之故。現在若以招致世人譏嫌的角度來看，何須論其貴賤，只要挑擔細軟短毛等物，同樣也失卻了威儀。只不過這條戒律起犯的緣由在於羊毛本身，所以這項行為便落在制罪與開緣的規範之外罷了。《摩訶僧祇律》說「已經製成器具的不犯」，所謂「器」，是指已做成了衣物的形相。這是通泛的名稱，就像現今把刀斧器物與衣飾物件統稱為器具一樣。

【原文】【疏】四、至三由旬。故《僧祇》云：「乃至羊毛著衣囊中，經行繞塔。或持一由旬半已，忘物返來。計過三由旬，故犯墮也。」

【323-0011】02_戒疏/14c_卷三下之二#56
【原文】【記】犯緣中。初緣簡「賤」，據後開通。「今」下，義判。初約譏同判犯。「擔毳」等者，總牒開文。「越威儀」者，即吉罪也，由是小賤，故不同重。「但」下，次明文列不犯之意。上敘本犯，具兼制開，故指不犯，在「制開」之外。次引《僧祇》。初決文相。「此」下，次釋「器」名。如「刀斧」等諸餘受用，皆得名「器」，欲顯「器」名不局，得目衣物也。「至三由旬」下，即第四緣，文脫標數。下引《僧祇》顯示異相。初明經行繞塔，雖非道行，亦計里數。「或」下，次約在道。「一由旬半，忘物返來」，成三由旬，再行即犯。「一由旬」，計四十里。
【譯文】【記文】犯戒條件之中。第一個條件簡別排除「粗賤羊毛」，是依據後面條文開許的通則。「如今」以下，依義理進行法官式的判定。首先依據招致譏嫌相同這一點來判斷其過失。「擔負短毛」等語，是總結提引開緣的條文。「失卻威儀」，就是指犯突吉羅輕罪，因為這是微小卑賤之物，所以不比重大罪相。「但」以下，接著說明經文列出不犯的用意。上面陳述本犯的條件，已經兼具了正制與開許，所以指出不犯的情形，是在這「正制與開許」的界線之外。接著引用《僧祇律》。首先判定文字相貌。「此」字以下，接著解釋「器」這個名稱。如同「刀斧」等其餘日常受用物品都可以稱為「器」，這是為了顯示「器」這個名詞涵蓋廣泛，也可以用來指稱衣物。「達到三由旬」以下，即是第四個條件，原文中脫漏了標號數目。後面引用《僧祇律》來顯示特殊的犯相。起初說明在經行繞塔時，雖然不是在官道上趕路，但同樣要計算行走的里程步數。「或者」以下，接著以在道路上行進為例。「走了一由旬半，因忘記帶東西而走回原地」，來回加總就達到了三由旬，如果再往前走一步就構成犯戒。「一由旬」，古代計算相當於四十里路。

【323-0029】02_戒疏/14c_卷三下之二#74
【原文】【疏】就戒緣中，「姨母為染」至「佛所禮足而立」者。《多論》云：「所以制者。與諸比丘增上法故，若諸尼眾執作浣染，廢修正業，則無威儀，破增上法。又止惡法次第因緣，各令清淨故。」所以不坐者，女人敬難情多，又佛不廣為女眾說法，又尼至佛所，一切皆立，為止外道誹謗故，又女人鄙陋，多致譏疑，所以不坐。
【譯文】【疏文】在戒律制定的因緣中，「姨母為其染毛」以至「前往佛所禮足肅立」的記載。《多論》說：「之所以要制定此戒，是為了給予諸比丘長養增上善法的緣故，如果眾比丘尼全去操持粗重的洗滌染織雜務，荒廢了自己修道的正業，就會喪失出家人的威儀，從而破壞了增上善法（或：這等同是比丘在破壞增上法）。此外也是為了在最初便止息惡行相續蔓延的因緣，讓僧尼各自保持清淨。」而比丘尼禮佛後之所以站著而不坐下的原因，其一是女人對佛的敬畏與難為之情較多；其二是佛陀通常不為女眾作長篇繁複的說法；其三是尼眾到了佛陀面前，一律保持站立，是為了止息外道誣衊譏諷的誹謗；其四是世俗看待女人較為低賤鄙陋，坐著容易引發世人譏評猜疑，所以站著不坐。

【323-0030】02_戒疏/14c_卷三下之二#75
【原文】【記】戒緣中。初牒文徵意。《多論》下，引釋，有二。初釋制戒，有二意：初意「與比丘增上法」者，由尼執作廢業乖儀，則是比丘破增上法；次意「止惡法次第」者，禁輕防重故。「所以」下，次明不坐，四意釋之。第二說聽非久，故不須坐，餘三可解。注中「姨母」，即大愛道尼。「汙手見佛」，發請制戒也。
【譯文】【記文】在戒緣之中。起初引提經文並推究深意。《多論》以下引導解釋，分為兩個部分。首先解釋制定戒律的原因，有兩層意圖：第一層「給予比丘增上法」，是因為尼眾若忙於勞務而荒廢道業、威儀失序，這等同是比丘在破壞增上法；第二層「止息惡法次第蔓延」，是為了從小事禁防以防止嚴重大過。「所以」以下，接著說明尼眾不就坐的原由，共用四個觀點加以解釋。第二點提到因為說法與聽法時間不會很久，所以不必坐著，其餘三點容易明白。注文中所說的「姨母」，就是大愛道瞿曇彌比丘尼。「雙手染汙面見佛陀」，這正是觸發並請求佛陀制定戒律的機緣。
