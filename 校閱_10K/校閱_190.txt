# 校閱材料　第190檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【190-0001】01_行事鈔/08c_卷中之四#41
【原文】先對故作。分二：前悔吉羅，如捨法中。不得以同名吉羅故，共根本合懺；律文自分六聚，不可抑之。次懺根本。且約淫戒方便，餘則例之。先請一懺主，其詞如捨墮中，三請已；便為說罪名種相已；三正捨罪，文云：「大德一心念！我某甲比丘，犯淫戒遠方便突吉羅，不憶數。今向大德發露懺悔，願大德憶我！」一說便止，餘詞同上。此文《四分》無有。今約提舍，波逸二懺，已多少不同；吉羅最微，不可廣誦墮法。不同《僧祇》，彼合墮罪故也。
【譯文】先對故作。分二：第一是先懺悔隨生的突吉羅罪，方法如同捨墮法中。不得因為同樣名叫突吉羅，就把它與根本罪合併在一起懺悔；律文明確將罪過劃分為六聚，絕不可含混壓抑抹煞。次懺根本。姑且以淫戒的方便罪為例，其餘各戒依此類推。首先延請一位懺悔主，其請詞如同捨墮法中，三次祈請完畢；懺悔主便為他解說罪名、罪種、罪相完畢；第三是正式捨罪，其文句說：「大德一心念！我某甲比丘，犯淫戒遠方便突吉羅，不憶數。今向大德發露懺悔，願大德憶我！」說一遍即告終止，其餘文詞與前述相同。這段文詞在《四分律》本中並不存在。如今審酌提舍尼與波逸提這兩種懺法，其詞句詳略已各有不同；突吉羅罪最為輕微，不可繁冗廣誦波逸提墮罪那套長文。這也不同於《僧祇律》，因為該律是將突吉羅與波逸提墮罪合併懺悔的緣故。

【190-0002】01_行事鈔/08c_卷中之四#42
【原文】次明誤作。先出其相。謂心不正念，遇緣起非；外越威儀，理須改懺。如著三衣，必迴顧看視，諸相齊整，方乃進路；戲笑妄語，諸非法相，並先不攝念，故起斯過。律云：佛制攝持威儀，比丘若入若出，屈申俯仰，攝持衣鉢，若衣若食，若服藥，大小便利，若眠若睡若覺，若來若去，若坐若臥，若語若默，常爾一心。若違此制，具結其犯。次明作法。先悔從生，後明根本。應具儀至佛廟所，致敬已，互跪合掌云：「我某甲比丘，犯誤不齊整著欝多羅僧突吉羅罪，不憶數。今發露懺悔，更不敢作。」餘並準此。
【譯文】次明誤作。先出其相。這是指內心未能安住於正念，遇到境界外緣而生起非違；外在行止違越了威儀法度，理當痛加改過懺悔。例如穿著三衣，必定要回頭審視檢視，確保各處齊整端正，然後才能舉步前進；至於嬉戲嘲笑、虛妄言語等種種非法相狀，都是因為事先未能收攝心念，所以才生起這種過失。律中說：佛陀制定了收攝護持威儀之法，比丘若入若出、屈伸俯仰、攝持衣鉢，無論穿衣、進食、服用湯藥、大小便利，無論睡眠、打盹、清醒，無論來往行走、坐止臥息，無論言語、靜默，皆應當常爾一心。如果違背了這項禁制，全都判定結罪。次明作法。先悔從生，後明根本。應當威儀具足來到佛廟處所，致敬頂禮之後，互跪合掌說道：「我某甲比丘，犯誤不齊整著欝多羅僧突吉羅罪，不憶數。今發露懺悔，更不敢作。」其餘誤犯之罪皆依此準則辦理。

【190-0003】01_行事鈔/08c_卷中之四#43
【原文】識罪發露。至一清淨比丘所，具儀云：「大德憶念！我某甲，犯某罪，今向大德發露，後如法懺。」此謂犯已未經明相者，得行斯法。若已經覆，後隨露日，即罪不藏。若雖經說訖，後還覆者，還成覆藏，更須露罪。若犯僧殘，未經明相即首露者，免吉羅罪，不成覆藏；餘之五聚，同免懺吉。疑罪露法，餘同如上，應告言：「大德憶念，我某甲比丘，於某犯生疑；今向大德發露，須後無疑時，如法懺悔。」
【譯文】識罪發露。前往一位清淨比丘的住處，具足威儀說道：「大德憶念！我某甲，犯某罪，今向大德發露，後如法懺。」這指的是犯戒之後尚未經過翌晨天明微白（明相出）的人，得以施行這項法度。如果已經隱瞞過夜，後來隨著發露的那一天起，罪過便不再算是繼續覆藏。如果雖然曾經發露說畢，後來又重新覆藏掩飾的，依然構成覆藏罪，必須再度發露罪過。如果犯了僧殘罪，尚未經過明相出就立即主動發露首白的，可以免去覆藏的突吉羅罪，不構成覆藏；其餘五聚之罪，同樣免於懺悔覆藏突吉羅罪。對疑似犯戒的發露之法，其餘程序皆如同上述，應當告知說道：「大德憶念，我某甲比丘，於某犯生疑；今向大德發露，須後無疑時，如法懺悔。」

【190-0004】01_行事鈔/08c_卷中之四#44
【原文】《大論》云：戒律雖微細，懺則清淨。犯十善戒，雖懺，三惡道罪不除。如比丘殺畜，罪報猶在。前已具出。恐慢性戒，謂言懺已無業。餘如行法所述。
【譯文】《大論》說：戒律雖然微細，懺則清淨。犯十善戒（性罪業道），雖懺，三惡道罪不除。例如比丘殺害畜生，雖然懺了破戒罪，罪報猶在。這在前面篇章中已經詳細引出。這是唯恐有人心生怠慢而輕視戒律，妄以為懺悔之後就沒有任何業報牽纏了。其餘事理如同行法中所述。

【190-0005】01_行事鈔/08c_卷中之四#45
【原文】《善見》云：於大者懺，云大德；小者懺，云長老。《四分》：於上座懺者，具五法；小者懺，具四法，除禮足。《十誦》：應具五法：偏袒、脫革屣、右膝著地、兩手捉上座足。如悔過法。與欲清淨、受歲、出罪等法，威儀亦爾。有四種人，數數犯罪，數數悔過：一無羞，二輕戒，三無怖畏，四愚癡。
【譯文】《善見》說：對戒臘長於己者懺悔，稱呼對方為「大德」；對戒臘少於己者懺悔，稱呼對方為「長老」。《四分律》中記載：對上座比丘懺悔者，應具備五種禮儀；對戒臘小於己者懺悔，具備四種禮儀，除去頂禮雙足這一項。《十誦律》說：應具五法：偏袒右肩、脫去皮鞋、右膝著地、兩手捉扶上座雙足。如同悔過之法。至於委託與欲說清淨、受自恣歲、出僧殘罪等各項羯磨法，其威儀也是如此。有四種人，數數犯罪，數數悔過：一是無恥無羞，二是輕慢戒律，三是毫無怖畏，四是愚癡無知。
