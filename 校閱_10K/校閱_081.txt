# 校閱材料　第081檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【081-0001】01_行事鈔/05a_卷中之一#28
【原文】三無記心犯者。謂元非攝護，隨流任性；意非善惡，汎爾而造。如比丘方坐，高談虛論，費時損業，縱放身口；或手足損傷草木地土，和僧媒娶，妄用僧物，長衣過限，非時入俗，手觸僧器，壞身口儀。如是眾例，並通攝犯。唯除恒懷護持，誤忘而造；此非心使，不感來業。非即如上。前為方便，後眠醉狂，遂成業果；通前結正，並如論中無記感報。問：無記無業，云何有報？答：解有二。初言感報者，謂先有方便，後入無記；業成在無記心中，故言感報，而實無記非記果也。二者不感總報，非不別受。如經中頭陀比丘，不覺殺生，彼生命過，墮野猪中，山上舉石，即因崩下，還殺比丘。又如《五百問》中：知事誤觸淨器，作啖糞鬼等。如《成論》中：睡眠成業，是無記業。問：如前無記，有不犯者，其相如何？答：前已略明，今更廣示。謂學知戒相，善達持犯，心常兢厲；偶爾忘迷，由非意緣，故開不犯。如長衣過日，忘不說淨；善攝根門，便睡漏失；扶持木石，失手殺人。如是等緣，並非結限。反上所懷，並結正犯。然則業苦綿積，生報莫窮；虛縱身口，污染塵境；既無三善可附，唯加三惡苦輪；以此經生，可為歎息。
【譯文】第三是「無記心（非善非惡之平常心）犯戒」。是指原本就不懂得收攝防護，隨順流俗任性妄為；心意並非故意作惡也非為善，只是泛泛隨便造作。例如比丘正在坐席時，高談闊論虛妄之語，荒廢時光折損道業，放縱身業與口業；或者手腳不經意損傷草木泥土，附和僧眾為人作媒婚娶（如附同知事為淨人媒娶），隨意取用僧團物資，蓄留長衣超過十日限期，不在規定時間進入世俗村落，雙手隨意觸摸僧團公用器具，毀壞身口的威儀。像這一類的眾多事例，全都通盤收攝於犯罪之中。除非平日恆常懷抱護持戒律之心，只因一時疏忽遺忘而造作；這不是由故意的心思所驅使，不會感招未來的惡業果報。這不同於上述的情形。若先前起意作為方便，後來陷入睡眠、沉醉、發狂，最終成就了罪業之果；這必須連同先前的動機而判定為根本正犯，皆如同各部論典中所說的無記心感招惡報。問：無記心不招感業道，為什麼會有果報呢？答：有兩種解釋。第一、所謂感招果報，是指先前已有犯戒的方便企圖，隨後陷入無記心；罪業是在無記心之中達成完畢的，所以稱為感報，而實際上純粹的無記心本身並不能感招異熟果報。第二、無記造罪雖不感招引導一生投胎的「總報」，但並非不遭受個別的「別報」。例如佛經中有一位修頭陀行的比丘，無意間踩踏殺生，那隻眾生壽命結束後，投生為野豬，在山上拱動石頭，石頭隨即崩落滾下，回頭砸死了這位比丘。又如《五百問事經》中說：執事僧人無意中用污手碰觸清淨器皿，死後化作噉糞鬼等。又如《成實論》中說：在睡眠之中成就了損他之業，這屬於無記業。問：如前面所說無記心中，有開許為不犯的情況，其具體相狀為何？答：前面已經略為說明，現在更廣泛地開示。這是指平時認真學習知曉戒相，通達明瞭持戒與犯戒的界限，內心時常戰戰兢兢、警惕勉勵；偶爾遺忘迷失，由於並非出於本心的意圖攀緣，所以律法開許為不犯。例如蓄留長衣過了十天，純粹是忘記了作說淨儀式；或是平時妥善收攝諸根，卻在熟睡中夢遺失精；或在搬動扶持木石之時，一時失手滑落砸死了人。像這樣的因緣，全都不在結罪的界限之內。反之，若無上述嚴謹防護的心懷，隨意致過，全都判定為正式犯戒。既然如此，造業受苦綿延累積，受生果報無窮無盡；虛妄放縱身業口業，染污於塵勞境界之中；既然沒有三種善根可以依附，只會平白增加三惡道的苦痛輪迴；若以這種態度度過一生，實在令人深感嘆息。

【081-0002】01_行事鈔/05a_卷中之一#29
【原文】二引證誠報。如《目連問罪報經》云：若比丘、比丘尼，無慚愧心，輕慢佛語，犯突吉羅眾學戒罪；如四天王壽五百歲，墮泥犁中；於人間數九百千歲。第二波羅提提舍尼，如三十三天壽命千歲；於人間數三億六十千歲，墮地獄中。第三波逸提者，如夜摩天壽二千歲；於人間數二十一億四十千歲。第四偷蘭遮，如兜率天壽四千歲；於人間數五十億六十千歲。第五僧伽婆尸沙罪，如不憍樂天壽八千歲；於人間數二百三十億四十千歲。第六犯波羅夷罪，如他化自在天壽十六千歲墮泥犁中；於人間數九百二十一億六十千歲。《涅槃》中：犯突吉羅罪，如忉利天日月歲數八百萬歲，墮地獄中。與上經文不同者，此謂數有大小，即萬萬為億之量也。
【譯文】第二、引述經文來證實確切的果報。如同《目連問罪報經》說：若比丘、比丘尼，無慚愧心，輕慢佛語，犯突吉羅眾學戒罪；如四天王壽五百歲，墮泥犁中；於人間數九百千歲。第二波羅提提舍尼，如三十三天壽命千歲；於人間數三億六十千歲，墮地獄中。第三波逸提者，如夜摩天壽二千歲；於人間數二十一億四十千歲。第四偷蘭遮，如兜率天壽四千歲；於人間數五十億六十千歲。第五僧伽婆尸沙罪，如不憍樂天壽八千歲；於人間數二百三十億四十千歲。第六犯波羅夷罪，如他化自在天壽十六千歲墮泥犁中；於人間數九百二十一億六十千歲。《大般涅槃經》中說：犯突吉羅罪，如忉利天日月歲數八百萬歲，墮地獄中。這與上面經文所算數額有所不同，這是因為計算單位的進位法有大數與小數的分別，此處是採用以萬萬為一億的計算量級。

【081-0003】01_行事鈔/05a_卷中之一#30
【原文】自上引經，並是佛說正翻，非謂失譯疑偽。勿得縱心罪境，曾不反知。一犯尚入刑科，多犯理須長劫。
【譯文】從以上所引證的經文，全都是佛陀所親口宣說且經由正統翻譯傳入的，絕非譯者失傳或可疑偽造之書。切莫放縱心性於罪惡境界之中，卻從不知反省覺察。違犯一條輕罪尚且要受到如此酷烈刑科的制裁，若毀犯多條，在理法上必定要歷經長遠劫數受苦。
