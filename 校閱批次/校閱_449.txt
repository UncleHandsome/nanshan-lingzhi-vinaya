# 校閱材料　第449檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【449-0001】資持記/06c_中一上#39
【原文】犯中復二，即輕與重；四義，攝盡毘尼大藏。就輕重中，復有因果缺緣開制之異，故云等也。顯示律名從教而立，故云並律等。問中。以聖人之教，皆修行之法，而修多羅取貫攝為目，阿毘曇以析理彰名，故申此問，意顯今宗獨專此號。答中。引論示意，還約三學引生次第；
【譯文】在犯相之中又細分為兩種，也就是輕罪與重罪的不同；這四項核心義理，就徹底統攝了整個浩瀚的毘尼律藏大部。在討論輕重罪相之中，又含有因位、果位、欠缺成罪因緣、開許、制約等等的種種差別，所以用一個「等」字來涵括。這顯示了「律」這個名稱是依據整個教法所承載的規範而確立的，所以才說「都是律」等等。在「提問」當中，發問者認為：聖人的所有言教，本來全都是修行的法則，然而修多羅（經藏）取「貫通攝持」作為其名稱，阿毘曇（論藏）則以「分析法相真理」來彰顯其名號，所以提出這個疑問，目的是要凸顯為什麼我們律宗唯獨專門享有「法」這個專號。在「回答」中，引述論典來說明宗旨意趣，依然是圍繞著戒、定、慧三學引導生起的前後次第；

【449-0002】資持記/06c_中一上#40
【原文】戒範在先，故獨名法。若爾，經亦訓法，論翻對法無比法等，是則餘藏亦得名法，豈獨律耶？答：修多翻線，西竺本名；此土《字書》，訓經為法。又論稱法者，或從法相，如陰界入等；或即法門，諦緣度等；或就法體，涅槃理等。毘尼不爾，中梵本名；復是教詮，名相楷定；
【譯文】戒的規範最為優先，所以單獨稱為「法」。若這樣，經也能解釋為「法」，論則譯為「對法」「無比法」等，如此一來其餘二藏也都可以名為「法」，哪裡只是律呢？答：「修多羅」譯為「線」，是西方天竺的本名；此土《字書》把「經」解釋為「法」。又論被稱為「法」，有的是從法相上說，如陰、界、入等；有的是就法門說，如諦、緣、度等；有的是就法體說，如涅槃之理等。毘尼則不是這樣，它是中天竺梵語的本名；又是教法的詮表，名相確定不移；

【449-0003】資持記/06c_中一上#41
【原文】是非可不，必從文斷，故與餘藏法義天別。問：彼法門義，亦即從教？答：若就通論，三藏教詮，竝名為法；但戒引生軌物義勝，先據斯目；餘雖號法，弱故不彰；若約別論，三名各異，如上所列。前後中，初徵。若據世傳云經律論，此從語便；若對三學，律必當先，故申其意。由下釋。
【譯文】什麼是對、什麼是錯、可以做還是不可以做，全部都必須嚴格依據律文來判定決斷，因此它與其餘兩藏在「法」的義理層面上，有著天壤之別。有人問：那些經論中的法門義理，難道不也是順從教法而來的嗎？回答道：如果就廣泛通泛的角度來論述，三藏教典所詮釋的內容，確實全部都可以統稱為「法」；但唯有戒律在引領生發修行、規範眾生身口威儀上的功能最為殊勝強烈，所以最先佔據了這個崇高的稱號；其餘二藏雖然也有法的涵義，但相較之下這個功能微弱而不顯著；如果從各自獨特專屬的角度來論述，三藏各自的梵名涵義完全不同，就如同上面所詳細列舉的那樣。在論述「前後次第」中，首先提出詰問。如果按照世間一般的俗稱，大多習慣順口說成「經、律、論」，這是順著語音念誦的便利習慣；但如果對應到戒、定、慧三學的修持次第，律學必然應當位居最首位，所以在此特別申述這個深意。接下「由下」提出解釋。

【449-0004】資持記/06c_中一上#42
【原文】以定慧幽隱，邪正難分；簡別雜濫，必用律法；用既在首，義必先標。內法，謂八正道。外俗濫同，謂偷形者。以法除者，如律中，時世飢饉，有外道偷形，隨眾僧後；僧以受戒時分、和尚闍梨等詰之；竝云不知，因即陳首。妙，要也。故下，結示。創，初也。餘下，指略。
【譯文】這是因為禪定與智慧的境界極其幽隱玄微，其中的邪正偏頗往往極難分辨；要簡擇辨別混雜濫泛的真偽，必定要藉助律法作為照鑑的尺規；它的運用既然位居最前端，其義理的排序自然必須首先標明。所謂「內法」，是指八正道等出世正法。所謂「外俗混濫相同」，是指那些未曾如法受戒卻偷穿僧服、盜竊出家僧相的人。所謂「依憑律法予以驅除剔除」，就如同廣律中所記載的：在過去飢荒災荒的年代，有外道偷偷剃髮穿上僧服，混雜在大眾僧團之後蹭食；僧團長老便以受戒的具體年月時辰、戒和尚與阿闍梨的法號等等細節加以詰問；那些人全都答稱不知道，因而只得如實坦白伏罪發露。所謂「妙」，就是極為精要神妙的意思。接下「故下」結語開示。所謂「創」，就是開端最先的意思。接下「餘下」省略指示。

【449-0005】資持記/06c_中一上#43
【原文】或約三學次第，或是佛法壽命，故合居先；此即常聞，故所不釋。〔或指戒及木叉，或指《戒疏》，皆非。〕次釋戒義，初科。引《雜心》者，顯示戒義，類通周遍，無境不發，無惡不禁；簡餘世善，局狹不周；禪無漏戒，唯情境發，皆非類通也。指廣如後，即戒體中。廣列中，初科，《智論》。
【譯文】這或者是依照戒定慧三學的修持次第，或者是因為戒律是維繫佛法慧命的壽命所在，所以理應位居最首要的地位；這些道理都是平素耳熟能詳的常識，所以在此不再贅述繁釋〔有人把這段話指為戒相與木叉，或者指稱是《戒疏》，這些都是錯誤的理解〕。接下來是「解釋戒的義理」，第一科中，引述《雜阿毘曇心論》的原因，是為了顯示戒的本義是隨順一切善惡境界而普遍生發的，沒有任何一個境界不生起防護誓願，沒有任何一種惡法不去加以禁止；以此簡擇區隔其餘世間的世俗善法，世善往往狹隘局限而無法周遍；至於定共戒與無漏道共戒，則唯獨面對有情眾生境界才能生發，這些全都不屬於能「類通周遍」的戒法。至於廣泛的論述就如後文所載，也就是指戒體篇章當中的論述。在「廣泛列舉」的內容中，第一科引述了《大智度論》。

【449-0006】資持記/06c_中一上#44
【原文】言性善者，彼云：好行善道，不自放逸；謂性是善，不使從惡故。《善生》。五釋學義，摘在次科。二從心中。此就所治為名。身口五根，通須調伏；不唯在心，故云等也。三中，初示召體之名。如下，引論示體，初句舉名。此與從心語濫。以下，示體即約三性簡體，是善無作。問：此與上性善何異？
【譯文】論中所說的「性善」，該論解釋說：樂於奉行善道，使自己不致流於放逸自墮；這是指其本性原本向善，能約束自身不順從惡業的緣故。《優婆塞戒經》中將「學」的義理分為五種解釋，我們摘錄並列在下一科當中。第二「從心靈調伏的角度命名」，這是從所要對治滅除的對象來命名的。身、口以及五根，全部都需要予以調伏克制；防非止惡並非僅僅在於內心，所以用了「等」字來概括其餘身口各根。在第三點中，首先揭示用來稱呼戒體本質的名稱。接下「如下」引述論典來彰顯戒體的本質，第一句舉出名稱。這個名稱在文字上容易與前面「從心」的說法混淆不清。以下說明戒體是藉由三性（善、惡、無記）來簡擇判定其體性，它純粹屬於善的「無作戒體」。有人問：這個體性與上面所說的「性善」有什麼不同？

【449-0007】資持記/06c_中一上#45
【原文】答：準前論釋，望遮惡為言，故判屬功能也。四中。前引諸殺，而局善釋，於義未盡；是故鈔主以義繼之，故曰因明。名義兩通，故曰正義。初句示名不局；戒言性者，借訓顯義，勿滯《字書》。惡律儀，亦名惡戒；屠兒獵師旃陀羅輩，常行殺害，名受惡戒，持惡律儀。問：如何受耶？

【原文】答云通者，彼云：先以善心，禮僧合掌，白四起業；相續成就，是名善心發，善心得。若先以善心，乃至起業；羯磨未竟，起不善念；藉前善心力故，發業任運而起，與不善俱；是名善心發，惡心得；無記睡心，入滅盡定者，亦爾。次立難中。即前〈受戒犍度〉中文。瞋是不善，睡狂是無記。答中，初示得不。
【譯文】回答說各性通達的深義是：該疏解釋說，如果行者最初先發起至誠的善心，頂禮僧眾、恭敬合掌，一直到白四羯磨的儀軌正式發起行法；心念相續不斷地成就，這就稱為「善心發起，最終以善心得戒」。如果一開始先發起至誠善心，乃至展開了羯磨法務；但在羯磨儀軌尚未徹底結束之前，行者心中忽然轉念生起了不善的惡念；但因為藉由最初那份深厚善心之力的維繫，所引發的發業力量仍能自然任運生起，並與當下的不善念並存；這就稱為「善心發起，最終於惡心中得戒」；至於在無記心、睡眠沉睡心、或者深入滅盡定的狀態下得戒，其因緣道理也是完全相同的。接下來設立詰難的文句，就是引自前面〈受戒犍度〉當中的文段。瞋恚屬於不善的惡心，睡眠與瘋狂則屬於無記心。在「回答」中，首先揭示究竟能得戒還是不能得戒。
