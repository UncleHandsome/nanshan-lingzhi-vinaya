以下按「必須改」→「宜斟酌」→「譯例／注釋」三層來看。整體說，這份譯文對律學名相（篇聚、毗尼、七滅、聖女舉罪等）掌握得不錯，行文也順；問題集中在**一處否定詞被譯反**、**幾處斷句與指代未交代**，以及 **「通名／別名」等術語的譯法**。

## 一、必須修正

### 1. 「不即是總舉處別問」——否定被譯成肯定（最嚴重）

* 原文：「今不定中，若總舉二處有犯者，**不即是**總舉處別問，是知總別不同。」
* 譯文：「……**這就是**總括處所而分別審問，所以得知總與別是不同的。」

原文是「不即是」，譯文卻作「這就是」，語意正好翻轉。此句斷句雖有歧義（㈠「不即是總舉，處別問」；㈡「不」讀為「否」，屬上句作問詞），但**無論哪一讀都不宜逕作肯定並把「不」消化掉**，至少要出注。

建議譯法（並加注異讀）：

> 今不定法中，雖總舉屏、露二處而問有無犯，卻不等於七滅那樣的「總舉而通問」，而是隨處各別限定罪名而問；由此可知總問與別問不同。

### 2. 同段「答」的理路沒有譯出來

問：既然只就所問之罪結默罪，何以七滅中「七藥之外」有過不發露皆成默過？
答的關鍵是：**七滅是「總問僧」（七藥通治一切諍，故無所不攝）；不定是「別問人」（唯限二三罪，故二三之外無默罪）。** 譯文逐字直譯「總舉處別問／是知總別不同」，讀者看不出這是在回答問題。建議以括號或腳注補足上述對比。

### 3. 「不序名問」的「序」誤解為「說戒序」

前文「又**序**二三者」譯作「陳述」（正確，序＝敘列）；此處「不**序**名問」卻譯成「（說戒）**序中總問**時」，前後不一致，且憑空添了「戒序（序分）」之義。
建議：「（戒本）並不別列該罪名而問，此時有默妄罪否？」

## 二、宜斟酌（指代、詞義、校勘）

| 原文 | 譯文 | 問題與建議 |
|---|---|---|
| 舉唯犯吉羅 | 「僅就遭人舉疑的這件事來說」 | 「舉」所指浮動（能舉之舉罪？所舉之戒相？）。宜作「若只就所舉的不定戒相（屏露獨坐被舉）而言，唯結突吉羅」，並注明「吉羅＝突吉羅（惡作、惡說）」及此判罪之依據 |
| 犯通五七 | 「通貫於五篇**或**七聚」 | 五篇、七聚是同一罪體的兩種開合，非二擇一。去掉「或」，作「通於五篇七聚」 |
| 以染譏極故 | 「招引貪染譏嫌最為嚴重」 | 「染」「譏」宜分說：染＝淫染重罪（夷、殘），譏＝世人譏嫌之罪（波逸提）。故只就最重者列三罪、二罪 |
| 護犯無默 | 逕改「餘犯」並夾注 | 校改不宜入正文。除「餘」外，「**諸**」與「護」形近亦極可能（諸犯＝其餘諸犯）。建議保留原字，注：「『護』疑為『諸』或『餘』之訛」 |
| 同外有犯 | 「二罪三罪之外」 | 「同」字可疑（或涉上句），譯文默默理順，宜出校注 |
| 設不過者 | 「假使有過而不說出（不發露）」 | 「不過」語意不明，補「發露」屬推測，宜標注存疑 |
| 逐彼諍訟 | 「追究紛爭時」 | 「逐」是隨／因義：「因彼諍訟而起」，非「追究」 |
| 而定人情 | 「平定人心」 | 「人情」多指其人之情實。宜「判定其人（清淨與否）的實情」 |
| 不與物違 | 「不與他人相違逆」 | 物＝眾人。宜「不與眾情相違（人所共信，無有異議）」 |
| 今從能治故問異也 | 「順應能對治的功能」 | 宜點明：能治＝藥，所治＝罪諍；七滅從能治而問，不定從所治而問 |
| 毗尼之興，為殄於諍 | 「戒律的興起」 | 此處毗尼偏指滅諍之法，非泛指整個戒律 |
| 上三／下二、下三／上二 | 「上面的三罪／下面的二罪」 | **最需要補注**：既然結云「理皆通五」，上三應指五篇前三（夷、殘、波逸提），下二指後二（提舍尼、突吉羅）；七滅「下三」指後三篇、「上二」指夷、殘。照字面直譯，讀者极易與不定戒本身的「三罪、二罪」混淆 |
| 亦不當宗 | 「不合本宗宗旨」 | 「宗」指此處論題（不定章／滅諍章各自所宗），不是「宗派宗旨」。宜「不契此處論題」 |
| 通名毗尼／別名毗尼 | 「通稱」／「專屬名稱的毗尼」 | 「別名」是**別義（狹義）**，非「專屬名稱」。建議統一作「就通義（廣義）名毗尼」／「就別義（狹義、專指滅諍）名毗尼」，末句「通別兩異」才好讀 |

## 三、譯例與注釋建議

1. **增譯宜標示**：「以行籌從多數決」（原文無）、「徹底」滅罪、「現成的」諍端、「伏認」等，屬解釋性補語，建議一律用括號或移入注腳，避免與原文混淆。
2. **首見名相補注**：五篇七聚（含偷蘭遮、惡作惡說之開合）、默妄（說戒時有罪默然不答之突吉羅）、聖女＝可信優婆夷（見諦語可信者）、婆私＝優婆夷音譯略稱、罪處所＝覓罪相毗尼、草覆地、三現前／五現前（宜依《行事鈔》滅諍篇列其人、法、毗尼等條件）。目前「聖女」首次出現即無注，讀者會不知其何指。
3. **層次宜分段編號**：第五門下實有兩重問答，其後又有三個「又此中……」的比較段，建議分項排列（如「五之二」「又一／又二／又三」），長段落會清楚很多。
4. **校勘與譯文分离**：凡疑訛、疑衍、異讀，統一放腳注；正文只出一個選定讀法。

## 四、示例修訂（第三門答段）

> 答：有犯而被問者，隱默不答即有過失；但除屏處三罪、露處二罪之外，其餘諸犯（原文作「護犯」，「護」疑「諸」或「餘」之訛）不說並無默罪，因為並未就該罪發問，無「違問不答」之可言。
> 問：若如此，何以七滅諍中，七藥之外凡有過不發露，皆成默過？
> 答：那是比丘舉此七藥而問「能秉法之僧」，僧即用此七藥為他人滅諍，所問通攝一切諍事，故是「總問」。今不定法中，雖總舉屏、露二處而問有無犯，卻不等於那樣的總問，而是隨處各別限定罪名而問（此句原文「不即是總舉處別問」，斷句有異讀，詳注）。由此可知總問與別問不同〔故默罪之有無亦異〕。
