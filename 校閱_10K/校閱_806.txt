# 校閱材料　第806檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【806-0001】02_戒疏/19b_卷四下之一#32
【原文】【記】釋疑，問中。「解義」中，即指廣解。「兩部」即僧、尼二眾。《律》云：「真實，五眾不得更互作，以非同類故。」答中，以淨施法通制五眾，但罪有別，故云「輕重異」也。及至淨施各眾相對，故云「自從律法」也。注不犯中，具列兩淨。「真實語主」，於教無違；「展轉隨意」，本無有犯。
【譯文】【記文】這是解釋疑惑，屬於問答中的問。「解義」中，就是指廣解的部分。「兩部」就是僧、尼二眾。《律》中說：「真實淨施，五眾不得互相對作，因為不是同類的緣故。」回答中，因為淨施之法通制五眾，只是罪有差別，所以說「輕重異」。至於淨施要各眾相對而作，所以說「自從律法」。注解的不犯中，完整列出兩種淨施：「真實淨施要告訴物主」，於教法沒有違背；「展轉淨施可隨意取用」，本來就沒有犯。

【806-0005】02_戒疏/19b_卷四下之一#36

【譯文】【記文】六十，在制意這一段中：最初敘述色的相狀。「內遣著」，是因為不貪好色的緣故；「外長信敬」，是因為讓人知道這是求解脫的人。「今」字以下，顯示過失。比丘這個身體，是聖法所聚之處，外面披著法服，內外相應，這就是「聖道幢」。外在的表相既然相違，所以說「非」。

【806-0012】02_戒疏/19b_卷四下之一#43
【原文】【註】《律》注云：「此言『淨』者：若染作色言『淨』；若已成色淨衣，應以餘物異色趣揲一處，作標識故言『淨』。自下若衣、非衣，是不用物，盡應點標幟淨畜。言『重』者，氍氀毾㲪，謂是衣中之重者。」
【譯文】【註文】《律》的注解說：「這裡所說的『淨』：如果是染成顏色，就說『淨』；如果已經是成色的淨衣，就應該用其他顏色的物料隨意補綴在一處，作為標識，所以說『淨』。從這以下，不論是衣或非衣，這些不須通體染壞的物品，都應點上標幟，以淨法貯畜。所說的『重』，指氍氀、毾㲪，這是衣物中厚重的。」

【806-0014】02_戒疏/19b_卷四下之一#45
【原文】【註】彼不作三種色便著者，墮。若重、輕衣不作點淨而著者，吉羅。若非衣——鉢囊、革屣囊、針線囊、禪帶、腰帶、帽韈、攝熱巾、褁革屣巾，不作淨畜者，吉羅。若以未染衣寄白衣家，吉羅。不犯者，得白衣染作三種色，餘輕、重乃至巾作淨畜也。
【譯文】【註文】不作三種壞色就穿上身的，犯墮。如果是重衣、輕衣不作點淨就穿著的，犯突吉羅。如果是非衣類——鉢囊、皮鞋袋、針線袋、禪帶、腰帶、帽子襪子、拭汗巾、包裹皮鞋的巾，不作淨而貯畜的，犯突吉羅。如果把未染的衣服寄放在在家人家中，犯突吉羅。不犯的情形：得到未經染色的素白布衣，先染成三種壞色再穿；其餘輕衣、重衣乃至巾帕，作淨而貯畜。

【806-0016】02_戒疏/19b_卷四下之一#47
【原文】【記】戒本，初科。立法句中，第二句，注約二種示「新衣」相。第三，注中復引「《律》注」，文為二段。初釋作淨，又二：初即染為淨，二、已染揲淨。「自」下，次釋點淨，亦二。初輕，二重，俱須淨故。
【譯文】【記文】戒本，初科中：立法句的第二句，注解就二種情況顯示「新衣」的相狀。第三句，注解中又引用《律》注，文字分為二段：第一段解釋「作淨」，又分二層：第一是染作顏色就是淨，第二是已經染色的則以別色點揲為淨。「自」字以下，其次解釋「點淨」，也分二層：第一是輕衣，第二是重衣，因為兩者都須要淨的緣故。

【806-0017】02_戒疏/19b_卷四下之一#48
【原文】【疏】成犯中，初「不以三色」壞新故重墮。「若輕重衣不作點」以壞色者，吉羅。餘小細物，並須點淨。非謂巾、屣以三色染，更成驚俗，可笑至甚也。
【譯文】【疏文】在成犯這一段中：首先，「不以三色」染壞新衣，所以犯重的墮罪；如果輕衣、重衣不作點淨來作壞色，犯突吉羅。其餘小的細物，都須要點淨。並不是說巾帕、鞋子也要用三種壞色去染，那樣反而驚駭世俗，非常可笑。
