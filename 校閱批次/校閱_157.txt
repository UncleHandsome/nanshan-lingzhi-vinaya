# 校閱材料　第157檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【譯文】【記文】在第三科中，首先標示劃分。「順」以下分別顯露，第一先說明持戒的真意。「愚」以下，展示犯戒的相貌。這依然是指向止持門的判定，所以說「如同前面的範例」。

【157-0003】02_戒疏/04c_卷一下之二#178
【原文】【疏】就不可學法，亦有九句，如前段後九句三品。法雖可學，迷倒忽生，佛開不犯。不同昔解。是以《律》中，不處分想疑，皆非殘故。
【譯文】【疏文】就不可修學的法規而言，同樣開展出九句，如同前一段文後面所列的九句三品。法規雖然在客觀上是可以修學的，但臨時突發迷惘顛倒，佛陀慈悲開許不判根本大罪。這與過去古德的見解完全不同。因此《律》文明載，對於未經處分的僧房若心生誤想或疑惑，全都不會判定結成僧殘重罪。

【157-0004】02_戒疏/04c_卷一下之二#179

【譯文】【記文】在不可修學當中包含三層意思。首先標明指示；「法」以下，確立理論基礎。「不同」以下，斥責破除古德的舊說。前面止持門中問答時所說「指引參照後面的作持」，指的就是現在這段文字。

【157-0007】02_戒疏/04c_卷一下之二#182
【原文】【疏】如昔解云：「止犯法中，無不可學。」今言迷倒，隨位皆有。如不說淨，見罪不露，即是可學；若迷若忘，即不可學。如是例知，通諸戒相。
【譯文】【疏文】例如過去有解釋說：「止犯的法規當中，絕對沒有不可修學的範疇。」本疏現在主張心念的迷惘顛倒，在任何行持位階中都可能存在。例如蓄留長物不作宣告說淨、自己見到犯了戒卻故意覆藏不發露懺悔，這原本都是可以透過修學而做好的事；但若是因為臨時迷亂或突發遺忘，這就屬於不可修學的開許範疇。依此類推，就可以通達應用到所有的戒律行相中了。

【157-0008】02_戒疏/04c_卷一下之二#183
【原文】【記】引古中。初科為二：初，牒古；二，立今。說淨覆藏，二俱開忘，故引為據。「如」下，例通一切。文言「諸戒」，舉其大槩。須論戒下若事若法，皆具二九。「類通法界」，即其義焉。
【譯文】【記文】在引用古德的討論中。第一科分為兩部分：第一、引述古說；第二、確立本疏的新義。宣告說淨與覆藏戒罪，律文中對於遺忘都明文開許不犯重罪，所以引用這兩條作為鐵證。「依此」以下，以此為範例通達貫穿一切戒律。文中說「所有的戒律」，是列舉其大綱。必須深究每一條戒律之下的具體事相與僧事法規，全都各自完備兩組九句。「能夠類推貫通法界一切事」，指的就是這層無比廣大的深義。

【157-0009】02_戒疏/04c_卷一下之二#184
【原文】【疏】有人解云：「止犯位中，對教不學，則唯八句，除法事俱識也。對事不學，九句通有。如造房舍衣鉢，雖達相了知，何妨不乞處分受持加淨，皆獲殘提等罪是也。」
【譯文】【疏文】有人解釋說：「在止犯這一個位階中，若是針對教理不去修學，那就只有八句，必須剔除法規與事相兩者全都明識的第一句。若是針對具體事相不去修學，那麼九句全都通達存在。例如自己興建房舍、或者蓄備三衣與瓦鉢，雖然對外在規格行相全都了了分明，但這哪裡能妨礙他不肯主動向僧團乞求處分、或者不作法受持加持與宣告說淨呢？這樣一來，自然全都要招致觸犯僧殘罪或波逸提罪了，這就是明證。」

【157-0010】02_戒疏/04c_卷一下之二#185
【原文】【記】次科。止犯一位，須分三種：一、不學止犯，即不學無知也；二、事法止犯，即於制聽善事善法，故違不作也。如文兩別。初止犯中除初句者，二種並識，非無知故。
【譯文】【記文】在第二科中。止犯這個位階，必須細分為三種：第一、不學止犯，也就是不學無知罪；第二、事法止犯，也就是對於強制或開許的善事善法，故意違抗不去修作。正如文中所區別的這兩種。在第一種不學止犯中之所以剔除第一句，是因為這第一句對於事相與法規全都明識清楚，完全不屬於「無知」的範疇。

【157-0047】02_戒疏/05a_卷二上之一#31
【原文】【疏】婬之一戒，無始染本，起因三毒，成必在貪。故《善生》云：「若為自樂，是名從貪；婬怨眷屬，是名從瞋；於所生母行非梵行，是名從癡。」境交內順，非貪不辨。以癡不遂，瞋是相違，故兩不成。
【譯文】【疏文】淫欲這一條戒，是無始以來生死染著的根本，發起的根由雖然通於貪、瞋、癡三毒，但成辦之業必定在於貪愛。所以《善生經》說：「如果是為了自身受樂而行淫，這稱為從貪心生起；若是為了報復而淫亂怨家眷屬，這稱為從瞋心生起；若是對於親生母親行非梵行，這稱為從癡心生起。」境界交會而內心順從受樂，若非貪愛就無法成辦淫事。由於愚癡心難以遂行歡樂，瞋恚心更是與歡喜相違背，所以依純粹的瞋、癡兩者無法單獨成辦究竟淫罪。

【157-0048】02_戒疏/05a_卷二上之一#32
【原文】【記】配毒中，婬戒分三。初明起成。「起」即據始，「成」即取終。「故」下，引經證起；「境」下，約義辨成。
【譯文】【記文】在配屬三毒的文段中，淫戒分為三部分。首先說明罪業的起因與成辦。「起」是指造作之初，「成」是指結罪之終。「故」字以下，引用經文來印證起因；「境」字以下，依照法理來辨析成辦。

【157-0051】02_戒疏/05a_卷二上之一#35
【原文】【疏】何以明之？即《善生》云：「若為己身，及諸眷屬，而取他物，是名從貪；若盜怨物，是名從瞋；劫奪下姓，是名從癡。」如《律本》中「燒、埋、壞色」，不益己故，名瞋起成。如《僧祇》中「摩摩帝互用佛、僧之物，皆犯夷」者，癡心起成。三毒互成，可以顯也。
【譯文】【疏文】何以明了這一點？《善生經》說：「如果為了自身及諸親眷屬而奪取他人物品，這稱為從貪心生起；如果偷盜仇怨之人的財物，這稱為從瞋心生起；如果是劫奪下賤種姓的財物，這稱為從癡心生起。」又如《律本》中所說「燒毀、埋沒、敗壞他人財物之顏色」，因不能利益自己，故稱為瞋心發起且由瞋心破壞而成；如《僧祇律》中說「執事人（摩摩帝）將佛物與僧物互相混用，皆犯波羅夷罪」，這是愚癡心發起並由癡心而成辦。由此可見，三毒相互資助而成業的道理便很顯明了。

【157-0052】02_戒疏/05a_卷二上之一#36
【原文】【記】盜中。初句徵起，「即」下引示。初引《善生》，備明三事。「下姓」，即簡大姓，如婢僕之類。賤故不貪，非怨故不瞋，故是「癡」也。「如」下，引二律盜相，義判二毒。「摩摩帝」，即經營人，彼以塔無物，僧有物，即持僧物治塔，得重罪。「三毒」下，結示。盜本貪犯，餘亦能成，故云「互」也。或可上據三單始終為言，此示兼具，故云「互成」。應云：貪起瞋成，貪起癡成。餘二為頭，亦各有二，則為六句。或復具三，如取怨美物，謂無因果之類。文不委出，故云「可顯」。
【譯文】【記文】在盜戒之中。首句提問引發，下文「即」字起引用經文開示。先引《善生經》，具備闡明了三種因由。「下姓」，即簡別非大貴種姓，指奴婢僕役一類。因其身分微賤所以不貪其利，非仇怨所以不起瞋心，故純屬「愚癡」。「如」字以下，引用兩部律典的偷盜行相，以法理判歸二毒。「摩摩帝」，即寺院經營事務的執事人，彼人見佛塔無供養物，而僧團有餘物，便拿僧物來修治佛塔，因此結得重罪。「三毒」以下，結示要旨。偷盜本是由貪心而犯，但其餘二毒也能成辦，所以說「互」。或者上面是就單一三毒從始至終造業而談，此處則是開示二毒兼具，故說「互成」。應當解釋為：貪心發起而瞋心成辦、貪心發起而癡心成辦；以其餘二毒為首，亦各自有兩種可能，合為六句；或者三毒具足，例如奪取仇家的美物，且自認毫無因果報應之類。疏文沒有詳細全列，所以說「可以顯明」。

【157-0053】02_戒疏/05a_卷二上之一#37
【原文】【疏】因解殺戒論心。如《善生》云：「貪利害命，瞋殺怨家，癡謂有福殺老父母。」又《雜心》云：「如毒蛇等，於人有害；父母老病，謂殺無罪。皆是癡攝。」又《成論》中：「依王舊法，約罪殺人，自謂無罪，但是癡成。何以故？具足殺緣。」心依惑故，互起相成。
【譯文】【疏文】順著前面之意來解釋殺戒的動機心態。如《善生經》所說：「貪圖利益而殺害生命，因瞋恨而殺害仇怨冤家，愚癡者誤以為有福報而殺害年老生病的父母。」又《雜阿毗曇心論》說：「如遇毒蛇等物，因其對人有害；或對父母年老病苦，以為殺了令其脫離痛苦並無罪過，這些全屬於愚癡所攝。」又《成實論》中說：「依照國家舊有法律，依罪判決殺死罪人，執法者自以為無罪，這全是由愚癡所成辦。何以故？因為已具足了殺生的各項條件。」心念既然依著煩惱起伏，所以三毒交互發起而成辦殺業。
