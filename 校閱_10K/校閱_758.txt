# 校閱材料　第758檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【758-0001】02_戒疏/17b_卷四上之二#41
【原文】【記】今解中。初定兩相無別。「戒本教授」，即是八敬。「廣解說法」，如注自引。「結吉」下，釋通注中結犯之意。故知差已日非，則說法、八敬竝吉；不差輒往，二竝犯提。《律》文但結日非、不差二罪，因而互列，故令妄解。「文無言」者，謂《戒本》中不明說法、八敬故。「結成相」者，謂《戒本》結犯，承上「不差」而結，則知犯墮止由不差。今更作句以定罪相：一、不差，日如，單犯一提；二、受差，日非，唯犯一吉；不差，日非，雙結提、吉。說法、八敬，教示不殊，有何義故而分輕重？決知非矣。
【譯文】【記文】在當前義理的解釋中。首先確定兩種法相並無輕重差別。《戒本》中的「教授」，實質指的就是八敬法。詳細解釋中的「說法」，如註文自行引用的那樣。從「之所以結判」以下，解釋通達註解中結罪的本意。由此可知若是受了差派卻在非教授日前往，那麼無論是說法還是講八敬法都只得吉羅；如果是未經差派而擅自前往，兩者都構成波逸提。《四分律》只是針對「日子不對」與「未經差派」這兩種過失結罪，因而在文中交錯陳述，以致引發後人的錯誤解讀。所謂「經文中並未言及」，是指《戒本》正文並沒有將說法與八敬法拆開獨立科罪。所謂「罪名成立的行相」，是指《戒本》結罪是承接前句的「不差」而作結定，由此便知犯波逸提墮罪完全是由於未受差派所致。現在進一步以句型來釐定罪相：第一、未受差派，但日子合法，單犯一個波逸提；第二、領受差派，但日子非法，唯犯一個突吉羅；第三、未受差派，日子又非法，則同時結判波逸提與突吉羅。說法與八敬，同為開導啟示，有什麼道理硬要拆分輕重？由此斷定古師的說法是錯誤的。

【758-0002】02_戒疏/17b_卷四上之二#42
【原文】【疏】「尼結吉」者，非輙教僧罪也，蓋是不被尼差輙教授耳。尼「二眾」亦不蒙大尼差遣，輙往僧寺禮拜問訊故也。
【譯文】【疏文】註文中「比丘尼結犯吉羅」，並不是指比丘尼擅自教導比丘的罪名，而是指尼眾未經自己僧團差派，擅自前往請受教授罷了。比丘尼下屬的式叉摩那與沙彌尼「兩眾」，也是因為未蒙大比丘尼僧團差遣，擅自前往比丘僧寺禮拜問訊故也。

【758-0003】02_戒疏/17b_卷四上之二#43

【譯文】【記文】在解釋比丘尼犯戒的段落中。首先說明大比丘尼。所謂「擅自教授」，是指擅自私自前去祈請。其次說明下屬兩眾。在義理上她們本就沒有不經差派擅自去請法的資格，所以只會發生「擅自前去禮拜」等罪過。在不犯的情況中，只是開許免除尼眾不去請法時所招致的罪過。

【758-0012】02_戒疏/17b_卷四上之二#52
【原文】【記】緣起中。以西國僧居城外，尼依城內，日暮城閉，奔還不及，故宿壍中，諸俗譏云「沙門釋子無有慚耻，無清淨行，竟夜與尼共宿，晝便放還」等。指「諸部」者，即《善見》云：「初為女人根鈍故，盡聽往僧寺教授；為人譏故，次開五人往；猶譏，始聽僧往尼寺。」若作此釋，甚有相妨。前「輙教」中，備明差往，若是初開，不應後列，若在前者，復曾被差。進退難定，來學請詳。下示遺忘，以警後來。
【譯文】【記文】在緣起之中。因為古代西域的比丘僧多居住在城外，比丘尼則依附城內居住，日暮城門關閉，尼眾奔走不及回城，所以只能露宿城壕之中，世俗之人便譏刺說「釋迦沙門毫無慚愧恥辱之心，沒有清淨品行，整夜與尼眾共宿，白天便放她們回去」等語。指向「其餘各部律典」，即是《善見論》所說：「起初因為女人根機較為遲鈍，完全允許她們前往僧寺聽受教授；後來因遭人譏嫌，其次開許每次限五人前往；依然有人譏嫌，這才開始允許比丘前往尼寺說法。」如果按照這個解釋，前後文義頗有互相矛盾之處。在前一條「擅自教授戒」中，已經完備說明差派比丘前往尼寺，若本戒是初次開許，就不應當列在後面（輒教戒之後）；若本戒是發生在前面（輒教戒之前），難陀又怎會已被僧團差派教授（當時尚未制僧差之法）。前後順序進退兩難難以斷定，請後來的學者仔細詳考。下文表示自己遺忘，是藉此警惕後學當精進不怠。

【758-0016】02_戒疏/17b_卷四上之二#56
【原文】【註】尼等吉羅。不犯者：教授尼至日未暮便休；除婦女已，為餘人；若船濟處說法，尼自聽者；若與估客夜說法；若尼寺中；若因人請，值說便聽者，開。
【譯文】【註文】比丘尼等犯突吉羅。不犯的情況：教授比丘尼到了太陽尚未下山便適時停止；除了婦女之外，只專為其餘男子說法；若在渡船碼頭處說法，比丘尼自己在旁聽聞；若是夜間為商旅商人說法；若在比丘尼寺院中說法；若是因為他人祈請，比丘尼恰巧遇到說法便在旁隨聽的，皆開許不犯。
