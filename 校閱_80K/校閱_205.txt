# 校閱材料　第205檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【205-0001】03_業疏/11b_卷二之五#92
【原文】一者、眾生依食者，為破自餓為道者，或䬸風服氣，餌藥存生，是邪道也。佛法不爾，身假食資：欲有段食，根塵觸食，卵生多思食，上界識食；或有兼者，如別所陳。食取濟形，道取濟神，故假形食，緣修道行；至論道也，要修離著為本，不識道元，乃以斷食為道
【譯文】第一、「一切眾生皆依飲食而住」：這是為了破斥以自我飢餓絕食作為修道途徑的人，外道或者餐風吸氣，或者服食丹藥以保全生命，這些都是邪道。佛法並非如此，肉身必須假藉飲食來資養：在欲界有分段物質的「段食」，有根境相對生起領納的「觸食」，卵生眾生多有以企盼希望資養的「思食」，上界（無色界）則有心識維持壽命的「識食」；或者有的生命兼具多種食，正如其他經論所陳述。飲食的作用在於救濟色身，正道的作用在於救濟精神慧命，所以假藉滋養色身的飲食，作為修持正道道行的增上助緣；若深論道法本體，必須以修習遠離貪著為根本，外道不知曉正道的根源，竟然把斷絕飲食當作修道。

【205-0002】03_業疏/11b_卷二之五#93
【原文】依食中初科，初標示。「或下」出外計。餌，仍吏反，食也。「佛下」示正法。初示三界皆依食住。段食，謂四塵所成，有形段故；起世經云閻浮提人以飯、麨、豆、肉等名麤段食，亦名摶食，即取摶聚，亦段義也。觸食，謂根塵相觸，資益諸根，如戒本中「食家有寶」即觸食家是也。卵生多思食者，起世經云若有眾生意思資潤諸根增長，如魚、鼈、蝦蟆等。上界識食，謂無色天資益延久，唯識持報；起世、成論竝云無色眾生皆識所持。或有兼者，謂欲有諸趣亦有識食；起世、成論竝云中陰、地獄、入滅盡定皆名識食；又瑜伽論謂第八識因餘三食勢力所資，便能任持諸根大造令不滅壞，有長益義，即以第八梨耶為體；若經部中取前五識、獨頭意識為體；準此以論，則識食一種通該三界六道，不唯上界也。又思食卵生且取一相，須知欲、色兩界通有四食，唯無色界局有識食耳。不可廣示，故指如別。「食下」次明須食所以。離著即道元也
【譯文】在依食住的第一科中，起初標明開示。自「或」字以下列出外道邪計。「餌」，音仍吏反，吃的意思。自「佛」字以下開示佛法正道。起初說明三界眾生皆依飲食而安住。「段食」，是指色香味觸四塵所造，具有分段形質之故；《起世經》說閻浮提洲的人類以米飯、炒麪、豆類、肉類等稱為粗段食，也稱為「摶食」，也就是取其搓摶凝聚之義，也是分段的意思。「觸食」，是指諸根與塵境相觸接觸，從而資益滋養諸根，如同比丘戒本中「食家有寶」中的「食家」即指觸食之處。「卵生多思食」，《起世經》說若有眾生以意念希求思戀來資潤諸根令其增長，如同魚類、鱉類、蝦蟆等。「上界識食」，是指無色界天資養益壽長久，全憑心識住持果報；《起世經》、《成實論》皆說無色界眾生全由心識任持。「或有兼者」，是指欲界諸道趣中也有識食；《起世經》、《成實論》皆說中陰身、地獄眾生、入滅盡定者皆以心識為食；又《瑜伽師地論》認為第八阿賴耶識因其他三種食的勢力資助，便能任持眼等諸根與四大造色令其不毀滅敗壞，具有長養饒益之義，即以第八阿賴耶識為識食之體；若依經部宗所論，則取前五識與獨頭意識為識食之體；照此推論，那麼「識食」這一種實際上通達涵蓋三界六道，並非僅局限於上界無色天。再者，「思食」舉卵生為例只是暫取一種特相，必須明了欲界、色界兩界共通具有四種食，唯獨無色界才局限於只有識食罷了。此處無法詳盡廣泛宣示，所以指示參照其他經論。自「食」字以下接著說明必須進食的原因。遠離執著，正是解脫之道的源頭根基。

【205-0003】03_業疏/11b_卷二之五#94
【原文】彼賊住者，本非正師，偷形入法，謂無願為，故以識之，餘九例爾
【譯文】那些賊住之人，本非正信之師，偷盜出家之形貌混入佛法之中，對佛法根本毫無願樂實踐之心，所以用這十數問答來識別考驗他，其餘九種法數也都以此類推。

【205-0004】03_業疏/11b_卷二之五#95
【原文】次科，本非正師即邪徒也。謂無願為，言偷形者，但為飲食，而於正法無心願樂。以法推求，可驗邪正；律令為說，其意若此。識，猶別也
【譯文】在第二科中，「本非正師」指的就是外道邪徒。「謂無願為」，是說偷盜僧貌出家的人，只為了謀求飲食供養，而對於真正的佛法全無願樂修持之心。以十數法義推問求證，即可驗知是邪是正；律典命令為他宣說，用意就在於此。「識」，就是辨別的意思。

【205-0005】03_業疏/11b_卷二之五#96
【原文】二、名色者，為破自然為道。彼計如犢生已自然飲乳，棘尖、烏黑、火上、水下、風輕、地重，皆無其因。佛法不然，內報外報皆有本因，諸眾生有皆因名色。心不可見，止可名談，初始識支，故轉為名；假染持識，即染為色；故哥羅邏時凝滑不淨，中含心故，展轉增長，三十八轉，九月便生，託彼胎藏，何得自然也
【譯文】第二、「名色」：這是為了破斥將「自然無因」視為修道真理的外道。外道妄計如同牛犢出生後自然就會吮飲母乳，荊棘天生就尖銳、烏鴉天生就羽黑、火性自然向上、水性自然流下、風性輕飄、地性沉重，全都沒有前因。佛法並非如此，內在身心果報與外在器世間果報皆有其根本原因，一切眾生的存在全都因於名色。心念無形不可得見，只能用名稱來詮表談論，最初投胎之識支，所以轉化稱為「名」；假藉父母交合的染濁物質來持受此識，那染濁之質即是「色」；所以受胎最初的羯羅藍階段，如凝脂滑膏般的赤白不淨之物中涵含著心識，輾轉生長發育，經過三十八個七天的轉變，九個月便行誕生，乃是依託彼母胎藏而生，哪裡會是自然而然的呢？

【205-0006】03_業疏/11b_卷二之五#97
【原文】二中初標示。「彼下」出外計，且列數端，例餘皆爾。「佛下」正破。彼計無因，故以十二因緣破之，亦名十二支：無明、行，過去因也；識、名色、六入、觸、受，現在果也；愛、取、有，未來因也；生與老死，未來果也。內外即是依正。初通示。「心下」委釋。識支投染，遂為名色支；染，即男女赤白不淨。哥羅邏時，謂初受胎時，亦名羯邏藍，此云雜穢。七日一轉，三十八箇七日，成二百六十六日，五大四小，故成九月；已前與母同氣，已後四日與母別氣，故至十月然後趣生
【譯文】在第二項中，起初標明開示。自「彼」字以下指出外道的邪執妄計，暫且列舉數項事例，其餘各項亦皆以此類推。自「佛」字以下正式破斥。外道妄計諸法無因，所以用十二因緣法來破斥其執著，十二因緣亦稱為十二支：無明與行，是過去世之二因；識、名色、六入、觸、受，是現在世之五果；愛、取、有，是未來世之三因；生與老死，是未來世之二果。內報與外報，就是正報與依報。起初通體說明。自「心」字以下詳細解釋。識支投入於男女交合的染質之中，便轉成名色支；「染」，就是男女交合的赤白不淨物。「哥羅邏時」，指最初受胎之時，也稱羯邏藍，此處翻譯為「雜穢」。七天為一轉變，三十八個七天，共成二百六十六天，依五個大月（三十天）四個小月（二十九天）計算，所以滿九個月；此前與母親同體呼吸氣息，此後四天與母親氣息分別，所以到了第十個月然後趣向出生。

【205-0007】03_業疏/11b_卷二之五#98
【原文】三、痛痒想，即受異名。古人翻經未通字義，假事為目：痛者苦受，痒者樂受，想者捨受。此破為計梵天因者。以劫初成，梵天創下，因有人物；諸眾生等，便計彼天以為父母，此生瞋喜，還因彼天。佛法不爾，生憎愛者，實由本陰，何于天也？以初一念緣色心名之為識，了達染淨名之為想，領納違順名之為受。由三想故，便生三受；由三受故，便有三行；故長淪歷，無有解脫也
【譯文】第三、「痛痒想」，即是「受」的異名。古人翻譯經典時尚未通曉字義，便藉用具體事相來命名：痛是指苦受，痒是指樂受，想是指捨受。這是為了破除執著大梵天為萬物之因的外道。因為劫初生成之時，大梵天最初下降，隨後便有了人類與萬物；各類眾生便執計彼梵天為自己的父母，以為自身所生起的瞋怒與歡喜，也全都是由於彼梵天所致。佛法並非如此，眾生生起憎惡與喜愛，實在是由於自身的本陰（受陰），何嘗與梵天有關？因為最初一念攀緣色身與心相名為「識」，明了通達染污與清淨相名為「想」，領受接納違逆與隨順之境名為「受」。由於三種想的緣故，便生起三種受；由於三種受的緣故，便產生三種行（善、惡、無記之業行）；因此長期沉淪流轉於生死之中，無有解脫。

【205-0008】03_業疏/11b_卷二之五#99

【205-0084】03_業疏/12a_卷三之一#58
【原文】如《多論》中，佛不度尼，為止謗故。若善來度，外道當言：本在王宮婇女自娛，出家還度以自樂故。如《撰集百緣》、《賢愚》等經，如來自唱善來度者，皆得羅漢，何以相違？如《明了論》，是聖人者佛唱善來，非聖人者則不度也。《多論》止謗，義在凡夫；必是聖人，能遣邪執，則非教限
【譯文】如《薩婆多論》中所說，佛陀不用善來度化比丘尼，是為了止息譏謗。若用善來度化，外道便會說：原本在王宮中以采女自我娛樂，出家後又度她們來讓自己享樂。然而如《撰集百緣經》、《賢愚經》等經中所載，如來親自宣唱善來而度化的比丘尼，都證得了阿羅漢果，為何會彼此相違？如同《律二十二明了論》所說，如果是聖人，佛陀便宣唱善來，若非聖人則不用此法度化。《薩婆多論》所說的止謗，意在凡夫；若是聖人，自能破除邪妄執著，便不在此教誡限制之內。

【譯文】第三、就時代辨析通局：善來、三語、八敬這三種受戒，局限在佛陀在世之時，原因不言而喻；破結得戒則通於佛滅度之後，因為依《善見律》的文句，佛滅後五千年之內能證得三達智，由此可知道果成就時戒體便圓滿具足；羯磨法通於在世與滅後兩個時代，這是顯而易知的。然而善來受戒，如《付法藏因緣傳》中所說，阿難後來主持宣唱而度化仙人，這是特殊的別緣，不能視為常規慣例。

【205-0095】03_業疏/12a_卷三之一#69
【原文】三中言就時者，即在世、滅後也。三局二通，如文。五千年前，謂第一千年也。通達三世，名三達智。然下會異。《付法藏傳》說阿難臨滅，於恒河水中度五百仙人，皆善來得戒，恐引為妨，故特通之。言別緣者：一則機在阿難，非通他故；二則一時之用，非通後故
【譯文】在第三科中說「就時代」者，即指佛在世與佛滅度之後。三種偏局、兩種相通，如文中所述。「五千年之前」，是指（正法）五個一千年中的第一個一千年。通達過去、現在、未來三世，稱為三達智。自「然」字以下會通相異的記載。《付法藏因緣傳》說阿難臨近入滅時，在恆河水中度化五百位仙人，都是以善來而得戒，恐有人以此提出難破，所以特地予以會通。所謂特別的因緣：一是因為此感應之機在於阿難，並不能通於他人；二是因為這只是一時的權用，並不能通於後世。

【205-0097】03_業疏/12a_卷三之一#71
【原文】善來、八敬局在南洲，由中成道，佛自秉故。問：何故一代不遊三天？答：南洲有四別緣，謂見佛、聞法、出家、悟道，餘三洲無見佛緣，且據一相如此判也。至如舍衛九億有不見聞，不妨餘洲有具四者，從多為言，非不如上
【譯文】善來與八敬局限在南洲（南閻浮提），因為佛在此洲成道，由佛親自主持的緣故。問：為何佛陀一代教化不遊行於其餘三天下？答：南洲具有四種殊勝的別緣，即見佛、聞法、出家、悟道，其餘三洲缺乏親見佛陀的機緣，這且是依據一種共通的相狀來作如此判定。至於像舍衛國九億人口中也有未見未聞者，不妨礙其餘洲中也有具足此四種緣者，但這只是就多數情況而言，並非不如上所述。
