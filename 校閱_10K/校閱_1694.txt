# 校閱材料　第1694檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1694-0001】03_業疏/10a_卷二之四#24
【原文】釋注中，初略判。「古下」二委釋。初引古，「今下」敘今，又三：初明所據。三歸、五、八，竝見受戒犍度，為道階梯，十、具漸次，故律被內眾，兼明導俗，故今集法據此為量。「何下次」推教意。「同空界」者，虗空有二義：一無邊義，喻周徧也；二包含義，喻攝機也。且舉五戒顯上一相廣攝之義。「被俗法」者，約相局也；「通道規」者，據體通也。《善生經》云：「此戒甚難，能為沙彌、大比丘、菩薩戒而作根本」是也。但婬分邪正，罪無篇聚，至於大重小輕，方便趣果，義則不別，故云「持犯相扶」，字或作「符」。注引《善生》，具問遮難，與道不異，故云「齊則」。「由下」三明須立。「弘」即訓大。「書紳」出《論語》，彼云「子張書諸紳」。「恐涉」等者，出注意也
【譯文】在解釋注釋的文字中，起初作簡略判定。自「古」以下，第二作詳細解釋。起初引用古說，自「今」以下敘述今家正見，又分為三層：第一、說明所依憑的根據。三皈依、五戒、八齋戒，全都見於律典的〈受戒犍度〉中，都是通向聖道的階梯，是邁向十戒、具足戒的循序漸進階位；因此律法主要雖覆蓋出家內眾，同時也兼明導引世俗在家人，所以現在結集儀軌以此為準繩標準。自「何以」以下，第二推究教化意圖。「如同虛空界」，虛空具有兩種意義：一是無邊無際義，比喻周遍；二是含容一切義，比喻包容攝受一切根機。這裡暫且舉出五戒來彰顯上面所說一相廣博收攝的深意。「覆蓋世俗之法」，是就戒相的外在局限而言；「通達聖道的軌範」，是就戒體貫通聖道而言。《優婆塞戒經》（《善生經》）說：「此戒非常難，能作為沙彌戒、大比丘戒以及菩薩戒的根本」，就是這個意思。只是在家人的淫戒區分邪淫與正淫，罪相未列入出家律的五篇七聚之中，至於重罪與輕罪的分別、方便發起到達成犯果，道理上並無二致，所以說「持犯相扶」（扶字有時寫作「符」，即相符合之意）。注中引用《善生經》，全面審問遮障與難事，與出家求道毫無差異，所以說是「法度齊整」。自「由」以下，第三說明必須確立此法。「弘」就是解釋為大。「書紳」典出《論語》，其中說「子張將教誨記在衣帶上」。「恐涉」等語，是說明作這段夾注的用意。

【1694-0004】03_業疏/10a_卷二之四#27
【原文】初三歸中，諸師冥目誦習授之，討論經論，大有弘致。既為師匠，義須通博，使受成濟，彼我無虗。背此師心，多符妄習，故為分途，啟疎戶牖，披文見意，是為得也
【譯文】在第一項受三皈依中，許多戒師閉著眼睛全憑習慣背誦傳授，然而若深入探討經論，其中實有非常宏遠深刻的旨趣。既然為人師表做傳戒師範，在義理上就必須通達廣博，使得受戒能夠真正成辦濟度，彼此雙方都不虛度荒廢。如果違背這一點而任憑一己私心自用，大多只會附和盲目虛妄的流俗習慣；因此我為之分門別類開闢途徑，啟開門窗以透光明，使人閱讀文字就能洞見深意，這才是正確的收穫。

【1694-0005】03_業疏/10a_卷二之四#28
【原文】次科俗法三歸敘引中，初文初指非。心無所曉，冥目誦文，恐遺忘故。「討下」次責昧教。經論即下引《多論》等。既背聖教，每事師心，心即妄習，符猶順也。「故下」示文意。分途即下諸門，戶牖即門下之義
【譯文】在下一科「俗法三歸」的敘述與引證中，第一段文字起初指出錯誤：戒師心中毫無所曉，只是閉著眼睛背誦文句，唯恐遺忘而已。自「討」字以下，其次是責備其昧於教理；「經論」即指下文引用的《薩婆多論》等。既然違背了聖教，凡事都師心自用，「心」就是妄想習氣，「符」就是順從。自「故」字以下，開示文意；「分途」即指下文各個門類，「戶牖」即指各門之下的義理要旨。

【1694-0006】03_業疏/10a_卷二之四#29
【原文】古人有言，文疏之作當從三易：一、章句易讀，二、文字易識，三、辭義易達，則為尚也。今世筆者反成三難：章句蹇澀，牽引梗舌，一難也；多專俗習，不涉本文，《蒼》、《雅》、《篇》、《統》，目所未矚，弁、辨、甄、蠲，文理全別，不羞多列，令人心惑，二難也；援引事義，翳文略指，相似餘辭，未能顯別，自非對讀，更須解出，三難也。故摘瑕累，意存通教，豈事藏密方稱能也？餘如常引，經即其倫
【譯文】古人曾說，著述文疏應當遵循「三易」：第一、章句容易朗讀，第二、文字容易辨識，第三、文辭義理容易通達，這樣才是值得推崇的。然而現今的撰述者反而造成了「三難」：章句艱澀生硬，語脈拖沓牽強而拗口礙舌，這是第一難；大多只依憑世俗陋習，不研閱字書本文，對於《蒼頡篇》、《爾雅》、《玉篇》、《字統》從未親眼過目，像「弁」、「辨」、「甄」、「蠲」等字，字義文理全然不同，卻毫不知羞地混雜羅列，使人心生困惑，這是第二難；援引事相義理時，遮蔽原文而語焉不詳，用看似相似的其他文辭，未能明確區別，若非對照原典閱讀，就必須另加註解才能讀懂，這是第三難。因此，此處摘錄指出這些缺失毛病，心意在於通達弘傳聖教，難道只有故意隱藏深奧才稱得上能幹嗎？其餘的毛病就如尋常所指出批駁的那樣（不再廣破），經典才是我們效法直顯其義的同類榜樣。

【1694-0007】03_業疏/10a_卷二之四#30
【原文】次科，初引古三易。沈隱候云：「文章當從三易：易見事，一也；易識字，二也；易讀誦，三也。」「今」下斥世三難。牽引謂句長；梗，猶礙也；俗習，謂世俗相傳無典據也。《蒼頡篇》、《爾雅》、《玉篇》、《字統》，四皆古賢字書，彼皆未見；「并」，皮變反，乃古製皮冠；辨與辨同，謂罪人相訟，古疏竝作「辨」字用之；「甄」字訓簡，「蠲」字訓除，彼亦一混而用。翳文，謂不顯所出；略指，謂引詞不備；相似餘詞等，謂隱而難見。若欲解者，須用本文對讀，不然又須注解。「故」下顯示今意，初二句示離過，次二句明異古，後二句顯從要；上句明不廣破，下句標今所法，謂同經論直顯其義也。
【譯文】就下一科而言，首先引用古人所說的三易。沈隱侯（沈約）說：「寫作文章應當遵循三易：第一、用典敘事容易理解；第二、字體容易辨識；第三、容易朗誦讀誦。」自「今」字以下，斥責當世文章的三難。「牽引」指文句冗長；「梗」如同窒礙；「俗習」指世俗流傳卻毫無典籍依據。《蒼頡篇》、《爾雅》、《玉篇》、《字統》，這四部都是古代賢人所著的字書，那些人都不曾見過；「弁」，音皮變切（biàn），是古代製作的皮帽；「辡」與「辨」同義，指罪人互相爭訟，古時義疏都寫作「辨」字來用；「甄」字解釋為甄選簡別，「蠲」字解釋為免除清除，那些人也混淆在一起使用。「翳文」指不指明引文出處；「略指」指所引用的文詞不完整；「相似餘詞」等，指文意隱晦而難以明辨。如果想要理解，就必須對照原文閱讀，否則又必須另作註解。自「故」字以下，顯示當前著作的旨趣：前兩句表示遠離過失，次兩句說明不同於舊說，後兩句顯示依從要義；上句說明不作廣泛破斥，下句標示如今所效法的方式，也就是如同經論那樣直接顯發其義理。
