# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 原文請直接複製材料中的【原文】，不要重新打字或改寫。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文：
- 譯文：
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【281-0001】02_戒疏/15a_卷三下之三#33
【原文】【記】第四中。初文為三。初開五眾，即對貿人。「餘人約」者，即俗人也。「如衣」下，次開自貿。既「不增減」，故無有過。《衣法》，即本律《衣犍度》，彼云「有貴價衣，令淨人貿，無淨人者，乃至遣比丘貿」。「他律」者，《僧祇》云「若估客物直五十而索百錢，比丘以五十，知之如是求者，不名為下」，《十誦》「比丘三度語，索不得，覔淨人使買」等。廣如《鈔》引。「律」下，三、釋上制開之意。
【譯文】【記文】在第四個科判中。第一部分文句分為三點。第一點是開許出家五眾互相交易，也就是交易的對象。「對於其他人加以約束」這句話，是指世俗之人。「正如衣法」以下，第二點是開許親自交易。既然「不增減價格」，所以就沒有過失。《衣法》就是指本律的《衣犍度》，那裡說「如果得到昂貴的衣服，應當差遣淨人去換取日用品，若沒有淨人，乃至可以派遣比丘代為換取」。「其他律典」方面，《僧祇律》說「如果商客的貨物價值五十錢卻索價一百錢，比丘知道後若只照原本的五十錢去買求，這不叫做壓低價格」；《十誦律》說「比丘三次說明索要不得，便尋找淨人代為購買」等。詳細內容正如《事鈔》所引。「四分律」以下，第三點是解釋上述禁止與開許的意圖。

【281-0002】02_戒疏/15a_卷三下之三#34
【原文】【疏】「若悔聽還」者，《十誦》：「七日者聽，過則不應。」、「僧中買者，悔則不可。」
【譯文】【疏文】「如果對方反悔，准許退還」這句話，《十誦律》規定：「如果在七天之內反悔，准許退還；若是超過七天，就不應當退還。」以及「若是在僧團內部公開購買的物品，反悔則不可以退還。」

【281-0003】02_戒疏/15a_卷三下之三#35
【原文】【記】次科。「若悔聽還」，《四分》文漫，故引《十誦》決之：一、有日限，二、簡僧別。
【譯文】【記文】在下一段科判中。「如果反悔准許退還」一句在《四分律》中文字較為寬泛，所以引用《十誦律》來作裁決：第一是設有七天的期限，第二是區分了個別交易與僧團內部的不同。

【281-0004】02_戒疏/15a_卷三下之三#36
【原文】【疏】又云「蘇油相易是不犯」者，外用也。前言「七日是犯」者，據內資也。
【譯文】【疏文】註釋又說「酥與油互相調換不算犯戒」，這是指用在外部照明塗抹等用途而言。前面說過「交換七日藥是犯戒的」，那是針對內服滋補身體的情況而言。

【譯文】【記文】在第三點中。前面說過四種藥物互相交易屬於犯戒，此處卻予以開許，所以用外用與內服的不同來調和疏通前後看似相違的說法。

【281-0008】02_戒疏/15a_卷三下之三#40
【原文】【疏】然鉢為應供之器，得一資身長道便罷。今過畜盈長而非少欲，常又經營，廢修正業，招機自壞。過是不輕，故所以制。所以開十日者，然物變無恒，容有失奪，身資要用，事不可廢，施時不受，後須難得。所以開限十日，作法而畜，過則致犯故也。
【譯文】【疏文】然而鉢是接受供養的器物，只要得到一個用來資助身命、增長道業就足夠了。如今過量蓄留多餘的鉢，這就稱不上少欲知足，平常又要去打點經管，耽誤了修習正業，更會招來世人譏嫌而敗壞自己的德行。這項過失非同小可，所以必須制戒防範。之所以開許十天的寬限期，是因為外物變遷無常，難免會有遺失或被搶奪的可能，而維持身命的重要器物，在生活上是不可或缺的，信眾布施時如果不接受，日後需要時就難以獲得了。因此放寬期限為十天，允許作說淨法後蓄留，超過期限就會構成犯罪。

【281-0009】02_戒疏/15a_卷三下之三#41
【原文】【記】二十一，制意中二。初明制意。敘過有三，「非少欲」，即乖行、廢業、招譏；翻此三過，即成三益。「所以」下，次示開意。則知開畜用擬失壞，非為貪積。「開十日」者，即同長衣，從容處置，緩急得所。
【譯文】【記文】在第二十一條戒中，解釋制戒意圖的部分分為兩點。第一點說明制戒的意圖。陳述其過失有三項：「稱不上少欲」，也就是違背道行、荒廢道業、招致譏嫌；反過來排除這三種過失，就能成就三種利益。「之所以」以下，接著說明開許的意圖。由此可知，開許蓄留是為了預備將來遺失毀損時使用，並不是為了貪求積蓄。「放寬十天期限」這點，就如同多餘的衣服一樣，讓人可以從容處置，在緩急之間拿捏得宜。

【原文】【疏】六緣成犯。
【譯文】【疏文】具備六種條件即構成犯罪。

【281-0011】02_戒疏/15a_卷三下之三#43
【原文】【疏】一、先有受持鉢。二、更得鉢，若是如法，可得其罪。三、是如法鉢，要具三如：一、體如，唯泥、鐵二種，餘木等並非法故；二、色如，要須熏令堅固，若油若掍磨等，並非佛教；三、量如，諸部言雖有多，準《母論》「大鉢受三斗，小者斗半，若過若減，不成受」說，餘如《鈔》中。
【譯文】【疏文】第一、先前已經有了受持的專用鉢。第二、又得到了別的鉢，如果是合乎戒規的鉢，才會構成這項罪名。第三、必須是合法的鉢，必須具備三種如法條件：一是質料如法，只能是陶土泥鉢或鐵鉢這兩種，其餘如木質等全都不合戒規；二是顏色如法，必須經過煙熏使之堅固，若是塗油或用石研磨打亮等，都不是佛陀所教導的合法作法；三是容量如法，各部派律典的說法雖然很多，但準照《毘尼母論》的記載，「大鉢能容納三斗，小鉢能容納一斗半，如果過大或過小，都不能算作受持的合法鉢」，其餘規定如同《事鈔》所載。

【281-0012】02_戒疏/15a_卷三下之三#44
【原文】【疏】四、不作淨。五、無因緣，《多》云：「得鉢五日，披擯、顛狂、心亂等，雖經多日無罪。後得止，取後五日續滿者犯。」
【譯文】【疏文】第四、沒有做說淨法。第五、沒有合法的特殊事故，《薩婆多論》說：「得到鉢五天之後，如果遭遇被擯除出境、癲狂、心智錯亂等事，即使經過了許多天也不算犯罪。後來這些事故止息之後，要接續計算剩下的五天，滿期仍不處理才算犯戒。」

【281-0013】02_戒疏/15a_卷三下之三#45
【原文】【疏】六、過十日，便犯。《見》云：「若買他鉢未還直，不成受。若主言『但受』，雖有此語，亦不成，過日非長。若度價竟，為熏報知，比丘不取，過日犯捨。餘人知報，非鉢主者，不犯。」《僧祇》：「鉢知友邊作淨。若十日內捨故受新，十日一易。」
【譯文】【疏文】第六、超過了十天，便構成犯罪。《善見律》說：「如果是向他人買鉢而尚未付清價錢，便不構成受持。就算原主人說『你儘管拿去受持』，雖然說了這話，仍然不算正式屬於自己，超過期限也不算長鉢。如果已經算清價錢，由陶師熏好告知比丘，比丘卻不去取回，超過十天就犯捨墮罪。如果是其他人知道而告知，而非鉢的原主人告知的，則不犯罪。」《僧祇律》記載：「鉢應當在知心朋友那裡作說淨法。若在十天之內捨棄舊的而受持新的，應當每十天輪換一次。」

【281-0014】02_戒疏/15a_卷三下之三#46
【原文】【記】犯緣，第二。「是如法」者，簡販搏得者，則無長過。
【譯文】【記文】在犯罪條件的第二點中。「是合乎戒法之物」，是為了排除透過非法的販運買賣所得到的鉢，那種情況下就不會構成蓄留長鉢的過失。

【281-0015】02_戒疏/15a_卷三下之三#47
【原文】【記】第三。體如中，木鉢同外道，寶鉢同俗流，石鉢僭如來，皆不應法。色如中。「油」字去呼，謂以桐荏油塗已燒之。「掍」合作璭，謂揩磨出光也。量如中。「諸部言多」，謂出量不一而無分齊，唯《母論》同今《四分》，故引示之。「三斗」、「斗半」，並準姬周為定。五中，「披擯」即法隔，「顛狂、心亂」，即病緣。準例，長衣亦應同此。
【譯文】【記文】第三點。在質料如法中，使用木鉢等同於外道，使用金銀寶鉢等同於世俗凡流，使用石鉢則是僭越了如來的器皿，全都與法度不合。在顏色如法中，「油」字讀作去聲，是指塗上桐油或荏油之後拿去火燒。「掍」字應當作「璭」，是指擦拭研磨出光澤。在容量如法中，「各部派說法眾多」，是指提出的容量標準不一且缺乏統一尺度，唯獨《毘尼母論》與現今這部《四分律》相同，所以引來作為說明。「三斗」與「一斗半」，都是以姬周時期的斗秤度量為準定奪。在第五點中，「被擯除」就是指僧法上的隔絕隔離，「癲狂、心亂」則屬於疾病事故。按照這條規則推衍，長衣戒也應當適用同樣的規定。

【281-0016】02_戒疏/15a_卷三下之三#48
【原文】【記】六中。《善見》約直明犯。初據未還，由未屬已，縱語非長。「若」下，次據已還，主報即犯，餘報不犯，未委實故。《僧祇》，「知友邊」者，即淨主也。「十日一易」，此據不畜長人，一受一捨，更互加用。今引此文，但取不得過十日耳。
【譯文】【記文】在第六點中。《善見律》是以價金是否付清來界定是否犯戒。一開始是依據未付清而言，因為物品尚未正式屬於自己，縱使主人開口應允也不算自己的長鉢。「如果」以下，接著是依據已經付清的情況而言，主人親自通知就開始算期限犯戒，若是其他人通知則不算犯戒，因為情況尚未證實明確。《僧祇律》中說「在知心朋友處」，就是指說淨的對象。「十天輪換一次」，這是針對不蓄留多餘物品的人而言，一個受持、一個捨去，互相輪流替代使用。現在引用這段文字，只是取其不得超過十天的規定罷了。

【281-0019】02_戒疏/15a_卷三下之三#51
【原文】【疏】問：「衣若過減，皆成受持，鉢反上者？」
【譯文】【疏文】又問：「衣服如果過長或過短，都還可以折衷截補而受持，鉢為什麼反而與此不同呢？」

【281-0020】02_戒疏/15a_卷三下之三#52
【原文】【疏】《論》答云：「衣可截續，是以成受。鉢無此義，成量成持。」
【譯文】【疏文】論典解答說：「衣服可以截短或拼接，所以能作成合乎標準的受持物。鉢則沒有這種改製的可能，唯有本身容量符合法度才能成立受持。」

【281-0021】02_戒疏/15a_卷三下之三#53
【原文】【記】次料簡中。《多論》，初問答中，衣染必成色，鉢熏不必成。次問答中，衣過可截，衣減可續，鉢則不爾，故成不成別。
【譯文】【記文】在接下來的辨析討論中。《薩婆多論》的第一個問答中，衣服染色一定能成功變色，鉢熏烤卻不一定能成功保持完好。第二個問答中，衣服過大可以裁剪，衣服過小可以拼接，鉢卻無法這樣做，所以兩者能否成立受持的規定有所不同。
