# 校閱材料　第273檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【273-0001】資持記/08c_中二#13
【原文】以校本宗，雖開勢分，必約無礙，有則同彼。故下，引示，初明不犯。三事緩急，初明無礙有勢分，下二顯有礙無勢分。注云界外事者，雖非內礙，在外有緣，亦開捨故，寄此明之。若不下，次明離犯。強弱中，初文一一者，律中十一界，皆有此語故。相攝中，初文，前明僧村可攝餘界。
【譯文】若用來對校本宗律法，雖然開許了勢分，但也必定要以沿途無障礙為前提；如果有障礙，就應如同前述部派的嚴格處置。因此「故……」以下，引文說明，先說明不犯戒的情況。三種事情的緩急次序：第一項說明無障礙時擁有勢分，後兩項顯示有障礙時便失去勢分。注文所說「界外之事」，雖然不是內部的障礙，但如果人在外有特殊事故因緣，也開許在遠處捨衣，因而寄託於此處說明。「若不……」以下，其次說明因分離而構成犯戒。在「強弱」比較中，第一段文中所說的「一一」，是因為律文在說明十一種自然界時，每一條都有這句話的緣故。在「彼此相攝（涵蓋）」中，第一段，前半說明僧團界與村落界可以涵蓋其餘各界。

【273-0002】資持記/08c_中二#14
【原文】藍中有村，則不相攝，二皆強故。樹舍者，舍即堂庫等。諸下，明餘界自不相攝。互相通涉，故無別勢分。二中，初明僧村相外有別界。言中分者，各取半故；隨處遠近，不必十三步。如下，指例。三中，堂及庫倉，三皆有相，故別簡之。初明堂庫攝餘界。文略倉界。不下，次明餘界不相攝，初正明。
【譯文】如果伽藍內有村落，則互不涵蓋，因為這兩者的力量都極為強大。所謂「樹舍」，「舍」就是指堂屋、倉庫等。「諸……」以下，說明其餘界彼此之間不能相互涵蓋。因為界線互相融通交錯，所以沒有額外獨立劃定的勢分。第二段中，首先說明僧村外部界相之外另有獨立界線。所說的「中分」，是雙方各取一半的距離；隨著處所距離的遠近為準，不一定局限在十三步。正如「如下……」處所舉的例子。第三段中，堂屋以及庫房、糧倉，這三種建築都有明確的外部形相，所以特別加以揀別。首先說明堂屋與庫房可以涵蓋其餘各界。文字中省略了糧倉界。「不……」以下，其次說明其餘界不能互相涵蓋，首先作正式說明。

【273-0003】資持記/08c_中二#15
【原文】如下，舉例。不周淨者，籬牆不匝，四淨之一，下卷具明。類即是例，舉彼例此，可明不攝。若下，明各立。如樹下有車，依樹則樹界，依車則車界，故云各別。如疏者，彼云樹下生樹及車場等，既無別院，異界叢起等。釋第五中，標云泛列者。律明無緣，止約迦提一月五月。
【譯文】正如「如下……」處列舉事例。所謂「不周淨」，是指籬笆圍牆不周密完整，這是四種淨地規定之一，在下卷有詳細說明。「類」就是指同類例證，列舉彼處的例子來比對此處，便可明瞭為何不能涵蓋。「若……」以下，說明各自獨立建立界限。例如樹下有車輛，依憑樹木就是樹木之界，依憑車輛就是車輛之界，所以說是「各別獨立」。如同疏文所說：疏文提到樹木下又生長小樹以及停放車場等情況，既然沒有獨立的院落，各種不同的界線便叢雜並起。在「解釋第五點」中，標題說「泛列（廣泛列舉）」。律文在說明「無因緣」這一條時，（其所認定的開緣）僅局限於受迦絺那衣的一個月或五個月期間。

【273-0004】資持記/08c_中二#16
【原文】今通括諸開，於此廣示故也。別釋中，初謂有緣界外令捨受法。不同對僧作法開離，故注簡之。二中，分二，初乞法中。注云三十者，即開乞分齊。舊記云：《多論》作七十，然律文《戒疏》並作三十，未詳孰是。如疏即《戒疏》離衣戒中，廣明緣相；必約人病衣重，方成作法，互有不成。
【譯文】如今通盤總括各種開緣，在此處作全面的開示說明。在個別解釋中，第一種情況是指有因緣在界外令其捨棄受持之法。這不同於在僧眾面前作法開許離衣，所以注文特別予以揀選區分。在第二點中，分為兩部分：首先在「乞求受法」中。注文說「三十」，就是指開許乞求法離衣的天數極限。古代的筆記說：《薩婆多論》作「七十」，然而律文與《戒疏》都作「三十」，尚未詳知何者正確。如同疏文，即是指《戒本疏》在「離衣戒」中，詳細闡明開緣的相狀；必須依據人員患病、衣服沈重這兩項條件，才能成就作法，否則便互有不能成立之處。

【273-0005】資持記/08c_中二#17
【原文】次作迦絺者。羯磨受已開五月離，亦同對僧作法故，如自恣中。三對處中。非謂開離，結攝衣已，藍外界內，同不失故。四如後戒。五即當戒開通。六謂夏竟通開一月。七亦出蘭若離衣戒。但約賊難別緣為異耳。料簡中，初科。蘭若通有無者，無法是本位，有法歸初開。
【譯文】其次是「作迦絺那衣法」。僧團完成羯磨受持迦絺那衣之後，比丘便開許享有五個月離衣的特權，這也是等同於對僧團作法而得的，就如同在自恣法中所說。第三種是「對處（結界處所）」。這並不是指開許離衣，而是因為已經結下「攝衣界」，因此即使處在伽藍之外但在結界之內，同樣都算不失衣。第四種情況就如後文的戒相所明。第五種情況就是當前這條戒所開許的融通條件。第六種情況是指雨安居結束後，普遍開許有一個月的緩衝。第七種情況也是出自「阿蘭若處離衣戒」。只不過是以遭遇盜賊劫難等特殊因緣而有所差別罷了。在「考核簡別（料簡）」中，第一小節。阿蘭若處通融「有作法界與無法界」：自然無作法界是本然界位，有作法界則歸屬最初的開緣。

【273-0006】資持記/08c_中二#18
【原文】〔準此賊難別緣，同開六宿；有人錯解後戒，請以比證。〕次科，但列五緣無罪，則顯餘二有罪。第一以輕易重，有罪可知。第三對處，何得有罪。此謂三礙後生，或容離犯，非一向無故。三中。第五望斷失者，由遭隔塞，不知衣之在，無意謂失故。
【譯文】（依照這個道理，遭遇賊難的特殊因緣，同樣開許六夜離衣；有人誤解了後面的戒相，請以此處作為比照參證。）在下一小節中，僅僅列出五種因緣可以免除罪責，這就反顯出其餘兩種因緣是有罪的。第一種因緣是「以輕罪換取免除重罪」，本來就有輕罪，這是顯而易見的。第三種因緣是「對處結界」，為什麼會有罪呢？這是指三種障礙在結界之後產生，有時仍可能構成離衣犯戒，並非絕對毫無罪責。在第三點中。第五種因緣「因阻隔而絕望斷念失衣者」，是由於遭遇阻隔障塞，不知衣服是否安好，心無寄託便認為已經失去。

【273-0007】資持記/08c_中二#19
【原文】不失如後，即不犯中勤守護者。第二有緣謂病未差，時在謂未滿五月。餘一一者，第四有難不失，難靜應失；第六迦提未出不失，限滿即失；第七六宿不失，過此即失；唯第一緣，捨之永失。不已中，初明五想。壞想者，謂故爛等。注中初釋不犯。決下二句，釋失受意。無下二句，釋無罪意。
【譯文】「不失衣」的情況就如後文所說，正是指「不犯」項目中那些勤於守護之人。第二種「有因緣」是指疾病尚未痊癒，「時間尚在」是指五個月期限未滿。其餘各條逐一而言：第四條「有災難時不失衣」，災難平息後就應當算作失衣；第六條「迦提月尚未撤除時不失衣」，期限一滿便算失衣；第七條「六宿之內不失衣」，超過此期限便算失衣；唯獨第一種因緣，只要一經捨棄便是永久失去。在「不犯」項目中，首先說明五種念頭。所謂「壞想」，是指認為衣服已經陳舊腐爛等。注文中首先解釋為何不犯重罪。從「決」字往下的兩句（「決心謂失，即是捨心」），是用來解釋失去受持的意思；從「無」字往下的兩句（「無情過故，不犯捨也」），是用來解釋沒有罪過的意思。

【原文】次引《善見》和會相違，初句指論。即前道行界文；師下，出論意。但疑在外，隔明失法，不慮失體故。此下，出今律意，異上可知。若下，次列諸緣。並是難開。此下，總斷。五想賊獸等是情礙，水陸道斷是隔礙。勤慢中，義判有三，初明先慢失法得罪。若下，次明勤護法在無罪；

【273-0030】資持記/08c_中二#42
【原文】上句明受施者，謂行邪諂乞求他施，正犯此戒。下句即能施人，謂不擇前境而故與之，為施所墮。上局比丘；下通道俗，道應輕罪，俗必成業。即〈興治〉中二俱為施所墮是也。第七。〔佛在舍衛，比丘失衣；有信居士多送衣與比丘，言不須；六群令取持與我更受，因制。〕戒名。

【原文】失三受二，是為知足；失三受三，故名過分。下列緣云過知足是也。犯緣。第三，約彼施心以定犯相。釋第五云。失一不取者，或重衣可摘，或容別求。都失取二者，疏云：以失衣處施主厚心，不可全取也。三中。言自恣者，明非為失故施，反釋上緣。
