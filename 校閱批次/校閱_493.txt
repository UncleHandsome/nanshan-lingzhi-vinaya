# 校閱材料　第493檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【493-0001】資持記/10c_中三下#3
【原文】《僧祇》中五，初明漉已看法。厭課謂事不得已，有同課率。象步遲緩，況有所載，迴必延久，故取為限。若施下，明請家漉法。虫不得語者，恐彼知而成犯故。虫水下，明還水法。不消，謂經久不涸。若知下，明知已存護法。顯意中。指同前戒。疏云：若據虫水，應合為一；
【譯文】《僧祇律》中有五點，首先說明過濾後檢視蟲子的方法。「厭課」是指事情迫不得已，如同趕工催促一般。大象步行遲緩，何況背上有負載，折返必定延宕很久，所以取此作為時間限制。「若施」以下，說明受居士迎請到家中濾水的方法。「不得向人說有蟲」，是擔心居士知道後倒掉而造成殺生之犯。「蟲水」以下，說明將蟲水送還原處的方法。「不消」，是指經過很長時間水都不會乾涸。「若知」以下，說明知道有蟲之後保存守護的方法。在顯明制戒意圖中，指出本戒與前戒相同。《戒疏》說：如果依含有蟲的水這點來看，理應合為一條戒；

【493-0002】資持記/10c_中三下#4
【原文】為重物命，故內外兩結。律不犯中。先不知，若無虫想；若虫，麁觸水使去；若漉水飲用，並無犯。六十三。〔佛在舍衛，十七群語五群言：云何入初禪？云何得羅漢果？彼報言汝說者犯波羅夷，佛呵因制。〕初緣者。《多論》：十三難，顛狂比丘，吉羅；學悔，六夜別住，四羯磨，僧尼互疑悔，皆提。釋第三。
【譯文】但為了鄭重愛惜物命，所以隨身內飲用與身外澆用兩戒分別結罪。律中規定不犯的情況：事先不知情，或者心中作無蟲之想；如果有蟲，只是粗略撥動水使牠們游開；如果是過濾後的水拿來飲用，這些全都算不犯。第六十三條戒。〔佛陀在舍衛國時，十七群比丘對五群比丘說：怎樣能入初禪？怎樣能證得阿羅漢果？五群比丘回報說你們這樣說犯了波羅夷重罪，佛陀呵斥後因而制戒。〕關於最初的犯緣，《薩婆多論》說：十三種難事、癲狂比丘，說此話結突吉羅罪；若是正在學悔、六夜別住、四種羯磨未了、或者僧尼相互生起疑惱，說了都結波逸提罪。解釋第三個犯緣。

【493-0003】資持記/10c_中三下#5
【原文】六事。初生時者，即云汝非爾許時生。二年歲者，云汝非爾許歲，如餘受者。三受戒者，云汝受戒年不滿，又界有別眾。四羯磨者，汝受時羯磨不成。五六聚者，云汝犯夷乃至惡說。六聖法者，云汝所問法則，自稱上人法，犯重，非比丘也。隨下，通結。上引《僧祇》。但開正受。
【譯文】共有六種事。第一是「出生時節」，就是說你並不是在那個時候出生的。第二是「年歲」，說你並不是那個歲數，如同其他受戒者所知那樣。第三是「受戒情節」，說你受戒時年齡不滿，或者戒場結界中有僧眾別異分開的情況。第四是「羯磨法」，說你受戒時的羯磨沒有如法作成。第五是「六聚罪」，說你犯了波羅夷重罪甚至惡說輕罪。第六是「聖法」，說你所問的法，就是自稱證得上人法，犯了重罪，已經不再是比丘了。「隨」以下，作總結。上面所引用的《僧祇律》，只開許在正受戒時可以勘問。

【493-0004】資持記/10c_中三下#6
【原文】注準不犯，亦開受後。不犯中，初二句通標。彼下，別列。還對前六事以明開相。初至時生，開第一也。若實無下，即第二也。若實年下，合明三四也。注決重受，先須究勘。今時受者，年多不滿；十師愚教，不能提誨；下檀已後，輒同僧事，冐受信施，真可怜愍；若實犯下，即第五也。
【譯文】註文依照不犯的條文，也開許在受戒之後詢問。不犯的條文中，前兩句是總括標明。「彼」字以下，分別列出。再對照前面的六種事來闡明開許的相狀。「初至時生」，是開許第一種情況。「若實無」以下，就是第二種情況。「若實年」以下，是合併說明第三與第四種情況。註文中判定重新受戒者，必須先詳加審問核查。如今受戒的人，年齡大多不足；十位戒師對律教愚昧無知，不能提攜教誨受戒者；下壇之後，動輒一同參與僧事，冒然接受信徒布施，實在太可憐憫了；「若實犯」以下，就是第五種情況。

【493-0005】資持記/10c_中三下#7
【原文】又下，即第六也。上六並謂心懷慈濟。餘戲錯等皆非惱意，故並開之。六十四。〔佛在舍衛，跋難陀與親友比丘數犯，向說不語人知；後與共鬪便相說，因制。〕名標麁罪，對簡下篇。釋中，初科。《善見》所覆雖一，能覆情同，多人皆犯一覆，多人多罪可知。注引《十誦》，示發露相。
【譯文】「又」字以下，就是第六種情況。上面這六種情況都是指內心懷有慈悲濟助之意。其餘如開玩笑、說錯話等，都不是出於惱害的意圖，所以全部開許不犯。第六十四條戒。〔佛陀在舍衛國時，跋難陀有一位親友比丘多次犯戒，向跋難陀訴說並囑咐不可讓他人知曉；後來兩人爭鬥，跋難陀便揭發其犯罪，佛陀因而制戒。〕戒名標明是「粗罪」，是為了對比並簡別下三篇的輕罪。在解釋中，第一科。《善見律》認為所覆藏的罪人雖然只有一人，但能覆藏者的心態情狀相同，多數人都各自結罪；反之，若一人覆藏多人，結犯多個罪也是顯而易見的。註文引用《十誦律》，說明發露懺悔的相狀。

【493-0006】資持記/10c_中三下#8
【原文】但為表己心無私曲，復恐相惱，故不須多。次科，《僧祇》初簡對露。若下，次明難開。護根謂意根也。三中。《多論》開疑，由未審決，不成覆故。四十，引律明犯，初約晝夜各分時限，遞明知說。故知露罪制在半日之內。問：小食時知，食後不說，復有罪不？
【譯文】只是為了表明自己心中毫無自私偏曲，又擔心造成對方的苦惱，所以不必向太多人說。下一科，《僧祇律》首先簡別相對發露的情形。「若」字以下，其次說明遇到困難時的開許。「護根」是指防護意根。第三項中，《薩婆多論》開許心懷疑慮的情況，因為尚未審慎判定，所以構不成覆藏罪。第四科，引用律文說明結犯，首先以白晝與黑夜各自劃分時限，遞次說明知道之後發露的規定期限。由此可知發露罪過規定在半天之內。有人問：在吃早粥時知道，吃完午齋（正食）後仍不說，這樣到底有罪沒有？

【493-0007】資持記/10c_中三下#9
【原文】答：約義以求，初夜中夜不說皆吉，並是方便；若論犯墮，須約明相；文中結墮，因前次第，且據中後夜耳。除下，次明所覆輕重。餘罪即下三篇。自下，三簡自他不同。疏云：覆他名重而治輕〔但悔本罪〕，自覆名輕而治重〔覆殘行別住，餘篇並先悔。〕。
【譯文】回答：從法義來探求，初夜、中夜不說都結突吉羅罪，這都屬於方便未成之罪；如果論及結犯墮罪（波逸提），必須以天亮顯現明相為準；律文中結墮罪，是順著前面的先後順序，暫且依據中夜與後夜來說罷了。「除」以下，接著說明所隱瞞罪過的輕重。其餘的罪過就是指下三篇輕罪。「自」以下，第三項簡別自覆與覆他的不同。《戒疏》說：隱瞞他人的罪名義上較重，但處罰較輕〔只須懺悔當下的覆藏本罪〕；隱瞞自己的罪名義上較輕，但處罰較重〔隱瞞僧殘罪必須行別住，其餘各篇也都必須先懺悔覆藏罪〕。

【493-0008】資持記/10c_中三下#10
【原文】又云：覆他有本，故重制令露，以戒淨故〔釋上有本。〕；自覆本壞，不須重制等。除尼下，四簡餘眾。覆尼同僧，此論輕罪，故簡除之。餘人即三眾也。不犯中。初不知者，無心覆故。不麁想者，由心差故。若向說者，已發露故。無人向者，闕所對故。若發心者，非覆意故。
【譯文】又說：隱瞞他人是因為他人本體有戒，所以從嚴規定令其發露，以維護戒律清淨〔這是在解釋上面所說的「有本」〕；自己隱瞞罪過則戒體本已毀壞，所以不須加重規定等等。「除尼」以下，第四項簡別其餘大眾。隱瞞比丘尼的粗罪與隱瞞比丘相同，此處是在討論輕罪，所以予以剔除。其餘的人就是指另外三眾。不犯的情況中。最初的「不知」，是因為沒有覆藏的心意。「不粗想」，是因為辨識心產生偏差。「若向說」，是因為已經向人發露了。「無人向」，是因為缺乏可以發露的對象。「若發心」，是因為心中本無覆藏之意。

【原文】約二十八日為月，則少二日在。《戒疏》至十二日方得，則於今鈔十日外更加二日，恰成一月，方得滿足二十年也。今則以疏為定。然此算法，連代共迷；講師至此，謬妄最甚；學者聽之，但增昏悶。故特委曲，勿謂繁長。至於詳細，卒書何盡，故且削之。三中，初指俗曆。
【譯文】若以二十八天折算為一個月，那麼還缺少兩天。《戒疏》認為要推算到十二日才可以，那麼就是在如今《行事鈔》的十日之外再增加兩天，恰好滿一個月，這樣才能滿足二十歲。現在就以《戒疏》的說法為準定論。然而這種推算法，歷代以來大家都感到困惑；講經法師講到這裡，所犯的荒謬錯誤最為嚴重；學者聽聞之後，只會徒增昏沉煩悶。所以特地委婉曲折地詳細說明，請不要認為這是繁瑣冗長。至於最詳細的演算，又豈是一時書寫得盡的，所以暫且刪除略過。第三項中，首先指明世俗曆法。
