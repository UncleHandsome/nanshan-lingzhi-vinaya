# 校閱材料　第214檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【214-0001】01_行事鈔/09c_卷下之一#33
【原文】前集財已，後鳴鍾遍召，一同僧式。不得閉門限客，假託昏夜，意遮十方，並非眾法；非上緣者，自淨其心。僧徒集已，彼瞻病人，在衣物所，具儀捨之：「大德僧聽！比丘某甲命過，所有若衣、若非衣，此住處現前僧應分。」眾中持律上座，即處判之。先問僧中，誰知亡者負三寶、別人物；又誰知三寶、別人，負亡者物？一一撿問，有者，如上處分。次明囑授雜相，同活、共財二別，並準上斷已。次定輕重訖，如上分之，重者一處，依名抄記；輕物一處，依名抄之。并問看病者，不將亡者輕重財物送喪不？有者，索替入法已，三唱和還；若無者，先當作賞勞法。但五德難具，不具不合依賞。今時行事，對眾問具德以不？若答具者，此乃自伐其功，俗人所恥；若不答具，有功無賞，違佛正制。與奪得所，出自僧中。故律云：僧得自在，若結不結，隨意也！今亦未須問德，律無正文。若知辛苦有功者，上座告云：「長老看病有功，佛令優賞。」當胡跪受羯磨也。看病者謙退陳訴：「無德有愧，不堪重賞。」僧當抑伏令受，然後索欲問和，答：「作賞看病人六物羯磨。」即白二與之：「大德僧聽！比丘某甲命過，所有三衣、鉢、坐具、針筩、盛衣、貯器，此現前僧應分。若僧時到僧忍聽：僧今與看病比丘某甲。白如是。」「大德僧聽！某甲比丘命過，所有大衣、七條、坐具，此現前僧應分，僧今與某甲看病比丘。誰諸長老忍：僧與某甲看病比丘七條、五條、鉢及袋、衣襆者默然；誰不忍者，說。僧已忍：與某甲看病比丘衣、鉢、坐具、鉢筩、盛衣、貯器竟。僧忍，默然故。是事如是持。」
【譯文】前面將財物聚集完畢之後，接著鳴敲大鐘普遍召集僧眾，一切依照僧團法式進行。絕不得緊閉寺門排斥外來客僧，或者假借天黑昏夜，存心防範遮蔽十方客比丘入內，這些都違背了大眾僧法；若非因上述不良緣由，大眾應當各自澄清自心。僧眾集合完畢之後，那位看護病人者，站在衣物停放處，具足威儀將財物捨給僧團，白言：「大德僧聽！比丘某甲命終，所有若是衣服、若是非衣服等遺物，此住處現前僧應當分配。」大眾之中的持律上座，隨即主持裁斷處分。首先詢問大眾僧：「有誰知道亡者生前積欠三寶或個別人的財物？又有誰知道三寶或個別人積欠亡者的財物？」一一查證檢問，若有債務，即如前述規定處分清償。其次查明囑授的各種相狀，以及同活、共財兩種差別，皆準照前述準則斷決完畢。接著判定輕物與重物完畢，如前法分列開來，重物堆放一處，依品名登記抄寫；輕物堆放一處，依品名登記抄寫。並且詢問看病者：「有沒有拿亡人的輕重財物充作送喪料理之用？」若有的話，索取其自備物品代換、納入僧團分物羯磨之法後，向大眾三度唱告和同歸還；若是沒有，首先應當作「賞勞法」。然而照護者的五德極難完全具備，如果不具備，按嚴格法理不合規定受賞。現今寺院行事，往往當眾質問他是否具備五德？如果照護者回答「具備」，這是在自我誇耀功勞，連世俗人都引以為恥；如果回答「不具備」，辛勞有功卻得不到賞賜，又違背了佛陀優恤的定制。給予或剝奪只要合宜得當，權柄本就出自僧團。因此律中說：僧團擁有自主之權，作法結成或不結成，聽隨僧意！如今其實不需當眾詢問是否具德，律典中本無當面查問的明文。如果僧團明知其照護辛苦、確實有功，上座便告諭說：「長老看護病人有功勞，佛陀制戒令大眾給予優厚獎賞。」看病者應當胡跪準備接受羯磨。看病者應當謙遜退讓陳述：「末僧無德，深感有愧，不敢當此重賞。」僧團應當壓服勸勉令其接受，然後徵索與會者意願（索欲）、詢問大眾是否和合同意（問和），大眾回答：「作獎賞看病人六物的羯磨。」隨即作白二羯磨將物品授予給他：「大德僧聽！比丘某甲命終，所有三衣、鉢、坐具、針筒、盛衣、貯器，此現前僧應當分配。若僧時機已到，僧忍可聽許：僧今將此物給予看病比丘某甲。表白如是。」「大德僧聽！某甲比丘命終，所有大衣（僧伽梨）、七條衣（鬱多羅僧）、坐具，此現前僧應當分配，僧今將此給予某甲看病比丘。諸位長老誰忍可同意：僧給予某甲看病比丘七條衣、五條衣（安陀會）、鉢及袋、衣襆者，請默然；誰不同意者，請說明。僧已忍可同意：給予某甲看病比丘衣、鉢、坐具、鉢筩、盛衣、貯器完畢。因為僧眾忍可默然的緣故。此事就這樣如法受持。」
