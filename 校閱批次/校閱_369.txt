# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【369-0001】02_戒疏/19d_卷四下之一#19
【原文】【記】戒本，初科。第三句「如法」字誤，合云「如是」。七、「供給」中，注文，初總示，「法」下，別釋。「意、智」即「心、慧」也。八、「同法」中，注云「說戒等」者，「等」餘一切羯磨眾法。九、「止宿」中，注列四室：一、障覆俱徧；二、覆徧障不徧；三、障徧覆不徧；四、障覆俱不徧，如三邊墻壁，上開明處。此言「不一切」、「不盡」等，「障」則唯缺一邊，「覆」則唯開少許，室相成就，故有犯也。後不犯中，但據一半已下為言，兩處列相，顯然自別。但此中語少不明，故下點云「與開何別」耳。經中「言語」下，注顯前後入室宿相，必有彼此往返言論。
【譯文】【記文】戒本正文的第一科判。第三句中的「如法」兩字有誤，應當修正為「如是」。第七句「供給」之中，注文首先作總體說明，「法」字以下則分別詳細解釋。「意、智」指的就是定心與智慧。第八句「同法」之中，注文提到「說戒等」，那個「等」字包含其餘一切僧團的羯磨共聚之法。第九句「止宿」之中，注文列出了四種屋室型態：第一、四面遮蔽與上方覆蓋皆完全齊備；第二、上方覆蓋完整但四面遮蔽不全；第三、四面遮蔽完整但上方覆蓋不全；第四、遮蔽與覆蓋皆不完全，例如三面有牆壁，上方留有採光的天窗。此處所說的「不一切」、「不盡」等詞，指四面遮障僅缺了一面，或是上方覆蓋僅留有些許開口，但整體房舍格局依然形成，所以在此同宿即構成犯戒。後文不犯的開緣中，則是針對牆面遮蔽或頂部覆蓋不到一半以下的情形來說，這兩處列舉的房舍相狀顯然有所差別。只不過此處文句稍有不明確之處，因此後文才特別點出「這與開緣究竟有何分別」。戒經中「言語」以下，注文揭示了前後進入室內同宿的狀況，期間彼此必定有言語往來的討論。

【369-0008】02_戒疏/19d_卷四下之一#26
【原文】【疏】入道已來，要由有信。然此沙彌，既未具戒，說欲非障，違僧三諫，邪見心成，於後受戒，事容難剋，故加重法，作彼𢷤名，怖以入道。大僧有戒，故直舉之，何須重法改作擯也？此但口說，未作重事。若實犯重，即在滅擯，何須諫後方作擯名？故知非重。
【譯文】【疏文】出家入道以來，根本關鍵在於具足正信。然而這位沙彌既然尚未受具足戒，竟口出行欲不障蔽聖道的惡見，違抗僧團的三次勸諫，邪見之心已然堅固，日後想要順利受具足戒，恐極難克成；所以特別施加嚴厲的處分，給予他「擯出」的重罰之名，藉此讓他心生畏懼而重新回向正道。大僧原本就具足大戒，所以直接用白四羯磨舉罰即可，何須動用更重的名目改為擯除呢？況且沙彌這時僅是口頭妄說，尚未真正做出根本重罪。如果他真的犯了重罪，直接就屬於永遠逐出的滅擯，哪裡還需要經過三次勸諫才安上擯除之名？因此可知此時所犯並非根本重罪。

【369-0009】02_戒疏/19d_卷四下之一#27
【原文】【記】初意，正明中，又三。初敘須擯。此滅擯法，十三難人、犯重不懺人故加此法，永棄海外，更無收錄，諸治罰中此法極重。沙彌口說，便加此罰，欲使迴心，成彼受戒故也。「大僧」下，二、對簡前戒，以示不同。「此」下，三、釋除疑濫。「若實犯重」，即邊罪難，永無入道，直爾擯棄，不在先諫也。
【譯文】【記文】第一點用意，在正文闡明之中又分作三層。首先敘述必須予以擯除的緣由。這種滅擯之法，本是針對十三種難人、以及犯了根本重罪而不肯悔改者所施加的處分，將其永遠驅逐到僧團境外，再也不得收錄，在各種懲治處分中以此法最為嚴厲。如今沙彌只是口頭妄說，就對他施加如此重罰，目的是想讓他回心轉意，以便將來能順利受戒。「大僧」以下，第二層是與前一條戒相對比檢驗，以顯示彼此處罰的不同。「此」字以下，第三層是解釋並消除疑慮與混淆。「如果真的犯了重罪」，就成了邊罪難人，永無入道受戒的機會，直接予以逐出即可，根本不須在事前加以勸諫。

【369-0020】02_戒疏/19d_卷四下之一#38
【原文】【註】佛在舍衛。跋難陀二沙彌共行不淨，自謂：「從佛聞法：行婬欲非障道。」比丘舉過，佛令白四設諫，不捨，滅擯。六群誘將畜養。比丘舉過，佛訶，因制戒。
【譯文】【註文】佛陀在舍衛城時。跋難陀的兩位沙彌私下做不淨行，還自稱說：「我們親從佛陀那裡聽聞佛法，說行淫欲並不會障蔽修道。」眾比丘揭發此過失，佛陀命令以白四羯磨進行勸諫，若不肯捨棄則予以滅擯。六群比丘卻暗中誘引並收留蓄養他們。比丘向佛陀揭發過失，佛陀予以呵斥，並因而制定了這條戒。

【369-0021】02_戒疏/19d_卷四下之一#39
【原文】【律】若比丘，知沙彌作如是語：「我從佛聞如是法：若行婬欲，非障道法。」彼比丘諫此沙彌如是言：「汝莫誹謗世尊，誹謗世尊者不善；世尊不作是語。沙彌！世尊無數方便說婬欲是障道法。」彼比丘諫此沙彌時，堅持不捨，彼比丘應至再三諫，令捨此事故。乃至三諫而捨者，善。不捨者，彼比丘應語此沙彌言：「汝自今已去，不得言『佛是我世尊』，不得隨逐餘比丘。如諸沙彌得與比丘二三宿，汝今無是事。汝出去，滅去，不應住此。」若比丘，知如是眾中被擯沙彌，而誘將畜養，共止宿者，波逸提。
【譯文】【律文】如果比丘明知沙彌發表這樣的言論：「我親從佛陀聽聞這樣的教法：如果行淫欲，並不是障礙修道的方法。」其他比丘前去勸諫該沙彌說：「你不要誹謗世尊，誹謗世尊是極不善的行為；世尊從未說過這樣的話。沙彌啊！世尊曾以無數的權巧善巧，說明淫欲是障礙修道之法。」那比丘勸諫該沙彌時，他若堅持邪見不肯捨棄，那比丘應當再三前去勸諫，務必使他放棄這種事。如果勸諫至三次他肯捨棄，那便很好；如果堅持不捨棄，比丘應當對這名沙彌宣布說：「你從今以後，不得再稱『佛陀是我的世尊』，也不得跟隨在其他比丘身後。其他沙彌本來可以與比丘同住二至三夜，你如今再無這項權利。你出去吧，徹底離開，不應當住在此處。」如果比丘明知該沙彌是在僧團中被擯除的人，卻仍誘引並收留蓄養他，甚至與其同宿者，判犯波逸提罪。

【369-0022】02_戒疏/19d_卷四下之一#40
【原文】【疏】戒本六句：一、隨擯比丘；二、知；三、沙彌諫舉事；四、「若比丘」下，明誘將畜養；五、共宿；六、結罪。
【譯文】【疏文】戒本正文可分為六個分句：一、隨順受擯者的比丘；二、明知其情；三、沙彌被勸諫舉處的事由；四、「若比丘」以下，說明誘引並收留蓄養的行為；五、與其同宿；六、裁定罪名。

【369-0023】02_戒疏/19d_卷四下之一#41
【原文】【疏】就第三中，分二：初明僧屏諫法六句；二、「彼比丘語」下，明擯出法。
【譯文】【疏文】在第三句之中又分為兩部分：前半部分說明僧團當面私下勸諫的法則，共有六句；後半部分從「彼比丘應語」以下，說明正式擯除驅逐的法定宣白。

【369-0024】02_戒疏/19d_卷四下之一#42
【原文】【記】戒本，釋第三中。「初僧屏諫六句」者，但有三對，闕後一隻，準上次第，對文可見。二、「擯出」中，但出呵黜之詞，準須先作滅𢷤白四，文如《鈔》引。《疏》文前後多作「殯」字，非，字合從手。
【譯文】【記文】戒本正文在解釋第三句之中。「前半部僧團當面勸諫的六句」，實際上只有三對對應句，缺少了最後一句，依照先前的順序對照文句便能明瞭。第二部分「擯除」之中，戒文僅列出了嚴加斥退驅逐的辭句；但按照律制規矩，必須先作滅擯的「白四羯磨」，相關條文在《事鈔》中有徵引。《戒本疏》在前後文句中大多寫作「殯」字，這是不正確的，字形應當從「手」部作「擯」。

【369-0029】02_戒疏/19d_卷四下之一#47
【原文】【疏】凡行不自成，必須訓導，方能䇿進修善，有趣道之益。善知識者，梵行正緣，若不依仰，無由自勵。然含識有心，略分三位。上達不假緣成，堪為物軌；下流勸亦難從，為存俗習；中品之徒，事須友接，率則清昇，任之鄙吝。然今癡心懶惰，不肯修學，聞他諫勸，拒而不受，內無自進之心，外無從善之志，故違聖教，過重故制。
【譯文】【疏文】凡修道之行絕非憑空自成，必須依賴良師益友的教導訓示，才能策勵精進修善，獲得趣向菩提聖道的利益。善知識是修持清淨梵行的最關鍵因緣，若不依止崇敬，便無從自我惕勵。然而具有心識的含靈眾生，大致可分為三個等級：上根利智者不需假借外緣即可自成，足以作為大眾的儀表風範；下劣愚鈍者即便勸勉也極難遵從，始終執著世俗習氣；唯有中等根器之流，最需要良友的接引提攜，引導得當則能德行昇華，放任不管則墮入下劣慳吝。如今有頑迷之人懷抱痴心懈怠懶惰，不肯認真修學，聽到別人的勸諫，又抗拒而不肯接受，內心缺乏自我求進取的意願，外在毫無順從善道的心志，如此公然違抗聖者教誨，過咎極重，所以制定本戒。
