# 校閱材料　第167檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【原文】【記】二中，初斥釋義。「即」下，斥反切。《字林》，作丘竭反；《毛詩》音義，去謁反；《漢書》音義，其逝反。故知音「竭」殊無所據。「撿」下，總責。
【譯文】【記文】在第二段中，首先駁斥錯誤的字義解釋。「即」字以下，駁斥反切讀音的錯誤。《字林》作「丘竭反」；《毛詩音義》作「去謁反」；《漢書音義》作「其逝反」。由此可知將其讀作「竭」音是完全沒有根據的。「查檢」以下，進行總體的指責。

【167-0002】02_戒疏/02c_卷一上之二#39
【原文】【疏】又尋翻經，古譯則云「偈他頌」，今云「伽陀頌」。斯則「伽」「偈」兩聲相近，省略本故，後所出者，但云「偈言」。故知「偈他」翻為「頌」也。故今所翻無序之頌，則云「伽陀」，有序之文，便為「頌曰」，可以分也。
【譯文】【疏文】進一步探尋翻譯經典的歷史，古代的翻譯稱作「偈他頌」，現在則稱作「伽陀頌」。這說明「伽」與「偈」兩個字音非常相近，由於省去了原本詞尾的緣故，後來出產的譯本，往往只寫成「偈言」。由此可知，「偈他」翻譯為漢語就是「頌」。所以現在所翻譯的、前面沒有散文長行的孤起偈頌，就稱為「伽陀」，若前面有長行散文的重複重頌之文，就翻譯為「頌曰」，這兩者是可以清楚劃分的。

【167-0003】02_戒疏/02c_卷一上之二#40
【原文】【記】三中，先出古今不同。應法師云：「『偈』者，梵言也，正云『伽陀』，或云『室廬迦』，謂三十二字，此方當『頌』、『攝』。」、「斯」下，究存略所以。「故知」下，示華梵。「故今」下，明兩分。「今翻」謂唐翻也。「無序」即孤起偈，「有序」謂牒前重頌。此約華梵以分，義無別也。
【譯文】【記文】在第三段中，首先指出古今翻譯名稱的不同。玄應法師說：「所謂的『偈』，是梵語音譯，正音應作『伽陀』，或者稱作『室廬迦』，意思是三十二個字，在我們這裡相當於『頌』或『攝』。」「這說明」以下，探究留存與簡略的緣由。「由此可知」以下，對照漢語與梵語。「所以現在」以下，說明兩者的劃分。「現在所翻譯」指的是唐代的最新翻譯。「無序」指的就是孤起頌，「有序」則是指承接前文再次重述的重頌。這是依據梵漢兩種體例來作劃分，義理上其實沒有差別。

【167-0006】02_戒疏/02c_卷一上之二#43
【原文】【記】次眾法喻，初科。由偈文云「好醜」、「勇怯」，通含持、毀，故以兩喻各對二人。據後從文，合云「兵戰喻」，今取𩰖戰必用智謀，故言「神解」耳。「又」下，復伸一判。「戒體」即五篇根本。「毀」約究竟，「護」取行成，故云「果」也。「戒緣」即「蘭」、「吉」方便。「縱」謂起心，「防」據警察，故言「因」也。「故」下，雙結如上。
【譯文】【記文】在接下來的「眾法喻」中，這是第一科。由於偈頌經文說「好與醜」、「勇與怯」，這全面涵蓋了持戒與毀戒，所以用這兩個比喻各自對應持與犯這兩種人。如果依照後文順應經文脈絡，應當稱作「兵陣作戰的比喻」，如今取其在戰場交戰中必定要運用智謀之意，所以稱之為「神解」（神妙明智）。「另一種」以下，又提出了另一種判定標準。「戒體」指的就是五篇戒律的根本究竟（根本戒法）。「毀損」著眼於造罪至究竟，「防護」著眼於戒行得以圓成，所以稱作「果」。「戒法的緣起行持」指的是偷蘭遮、惡作等前方便犯罪行為。「放縱」是指動念起心，「防範」是指警覺察省，所以稱作「因」。「所以」以下，如同上面所作的雙向結語。

【167-0014】02_戒疏/02c_卷一上之二#51
【原文】【記】次科，喻中。「約止」即能持心，「非緣」是所防過。能持、所防，則為「兩陣」。「正智」等者，謂心強過弱，持心勝也。「癡墮」等者，過強心弱，非境勝也。

【167-0015】02_戒疏/02c_卷一上之二#52
【原文】【疏】下法合中，「說戒亦如是」合初句。何以知耶？由說、聽交對，愚智、勤怠彼此相違，如陣合戰也。下句中，覩己行淨，由持故成名「淨」，是則戒淨心「安」趣道，合上「勇進」也。怠惰不學，心昏境慢，止犯「穢」心，將鄰苦趣，故常「畏」，合上「怯退」也。
【譯文】【疏文】在下面「落實法理」的段落中，「宣說戒律也是這個道理」這句話對應了前文的第一句。怎麼知道是這樣呢？因為說戒者與聽戒者相互問答交對，愚昧與智慧、精進與懈怠彼此衝突抗衡，如同兩軍合陣交戰一般。在下一句中，看見自己的戒行清淨，由於堅持持守而成就的德行稱作「淨」，如此一來戒行清淨、內心「安穩」而能趣向聖道，這對應了前文的「勇往邁進」。若懈怠懶惰而不肯學習戒律，心思昏昧而對外境漫不經心，因止犯而導致內心「汙穢」，眼看即將鄰近三惡道的痛苦果報，因此常常心懷「畏懼」，這對應了前文的「膽怯退縮」。

【167-0016】02_戒疏/02c_卷一上之二#53
【原文】【記】法合中，初句。以說戒師提示過境，同集聽眾，隨事觀緣，故如合戰。「愚智」約性，「勤怠」據行，即淨穢二機，淨勇穢怯，故曰「相違」。下句，對喻可見。「心安」是成因，「趣道」即慕果。「止犯」即不學無知罪。
【譯文】【記文】在落實法理的段落中，這是第一句。因為說戒師提示各種可能犯戒的情境，同聚一處的聽戒大眾，隨著每一項戒條審視自己的行持因緣，所以如同合陣交戰。「愚昧與智慧」著眼於天性資質，「精進與懈怠」著眼於行持造作，也就是具備清淨與垢穢這兩種根機的人，清淨者勇敢、垢穢者膽怯，所以說「彼此相違」。下一句經文，對照比喻即可明白。「內心安穩」是成就修行的正因，「趣向聖道」就是欣慕道果。「止犯」指的就是不肯修學戒律所招致的無知罪愆。

【167-0017】02_戒疏/02c_卷一上之二#54

【167-0025】02_戒疏/02c_卷一上之二#62
【原文】【疏】「王」者尊勝，威德超眾，喻戒住持，功高萬善故也。然「世間」之王有三種異，謂梵、魔、輪。恐濫法王，故云「世」也。大「海」弘廣，包括「眾流」；戒善周通，德收眾行也。朗「月」明空，除煩識妄；戒除業惱，見道知歸。「佛」是法王，「眾聖」師仰；戒是正行，九道崇之。

【167-0026】02_戒疏/02c_卷一上之二#63
【原文】【記】釋喻中，列示有四。初、王喻又二。初、對合。「然」下，明簡濫。「梵」王即色界初禪天主。「魔」王即六欲天主。「輪」王有四，金、銀、銅、鐵，金輪統四州，餘三第減可知。海取二喻，「弘廣」、「包含」，即前所引八德中二。月喻亦二。《涅槃》云「能除熱惱」，即除煩惱也。破暗見道，謂「識妄」也。「戒」下兩句，即對二喻。「業」謂七支，「惱」謂煩惱；「道」即諦理。「佛」中，「九道」，謂三乘六趣。
【譯文】【記文】在解釋譬喻的部分，列出四種。初、國王喻，又分兩層：初、以喻對合；「然」字以下，是簡別與法王相混濫的地方。「梵」王就是色界初禪的天主，「魔」王就是六欲天的天主。「輪」王有四種，即金、銀、銅、鐵四輪王；金輪王統治四天下，其餘三種依次遞減，可以推知。大海取兩個比喻，即「弘廣」與「包含」，就是前面所引八德中的兩種。月喻也有兩層：《涅槃經》說「能除熱惱」，就是除去煩惱；「破暗見道」，就是所說的「識妄」。「戒」字以下兩句，就是對應這兩個比喻。「業」指身口七支的造作，「惱」指煩惱，「道」指四諦之理。「佛」這一句中，「九道」是指三乘與六趣。

【167-0031】02_戒疏/02c_卷一上之二#68
【原文】【記】初答中。上二句通示。「說法」，別指制戒。制戒之意，非止一端，豈唯四喻，而能盡理。故經律中，廣有譬喻，如《鈔．標宗》，尋之可見。
【譯文】【記文】在第一種回答的段落中。前面兩句是普遍的說明。「說法」特別是指制定戒律。佛陀制戒的意旨絕非僅有一端，哪裡是僅僅四個比喻就能完全道盡其義理的呢？因此經藏與律藏之中廣泛設有各種譬喻，正如《行事鈔．標宗顯德篇》所記載的，翻閱該書即可知曉。
