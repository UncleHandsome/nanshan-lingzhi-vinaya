# 校閱材料　第899檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【899-0001】03_業疏/19b_卷四之二#62
【原文】次問意謂既許聞戒，罪何不脫？答中有二：初約眾自二行對明：自行據體，有犯隨治；眾行取和，不疑許聽，無犯疑有，約心不開。又下次單就自行以辨，實犯謂無，理須舉悔；不犯謂有，義不妄施。前下決上律文，且為護眾，仍簡僧殘次死須救，故逼無諍也
【譯文】接著提問，意在指出既然准許聽聞說戒，罪過為何不能脫免？答文中分為兩層：首先約大眾行與個人自行相對辨明：自行依據戒體，有犯就隨律治罪；大眾行取僧團和合，自無疑惑者准許聽戒，本無犯而起疑為有犯者，依其心態不予開許。自「又」以下，單就個人自行來辨析：確實犯了卻自認未犯，理應舉發懺悔；未犯卻自認有犯，義理上不可隨便施予治罰。自「前」以下決斷前引律文之意，暫時不逼是為了護持僧眾和合，進一步簡別僧殘罪是僅次於四棄之重罪，必須救治，因此縱使逼問也不會有諍訟。

【899-0002】03_業疏/19b_卷四之二#63
【原文】尼請教法，就文差緣，應白二下，後往僧相。文行略法廣者，闕矣
【譯文】比丘尼請求教誡的儀法，依經文派遣的因緣，應當行白二羯磨差遣，隨後前往僧眾的儀態相狀。經文中實行略法，廣法就付闕省略了。

【899-0003】03_業疏/19b_卷四之二#64
【原文】尼請法中，初科就文差緣，即前羯磨「應白二下」，即後注文「往僧相」者，尼往僧中之儀式也。廣法即僧中請人作法差往教誡等，法律本具之，當世不行，故但存略。今時廣略俱廢，止可聞知，用為來習耳
【譯文】在比丘尼請法的內容中，第一科依文說明派遣的因緣，即前述羯磨中的「應白二」以下文句；隨後的注文「往僧相」，是比丘尼前往比丘僧中的儀式。廣法是指比丘僧中請人、作法差遣前往教誡等，戒律本來完備具足，但當時已經不施行，所以只保留略法。如今這個時代，廣法與略法都已廢弛，只能聽聞知曉其事，留作未來修習的借鑑罷了。

【899-0004】03_業疏/19b_卷四之二#65
【原文】云「各滿五人方羯磨差」者，以尼被差，即所為故，非數攝也。僧雖有五，一須具德二十夏者，若無此夏，雖復多人，亦不合受，以德不滿故
【譯文】文中所說「各自滿五人方可行羯磨差遣」，是因為被差遣的比丘尼，就是羯磨所為之人，不計入羯磨法定人數之中。比丘僧雖然有五人，其中一人必須具備德行且滿二十戒臘；如果沒有這個戒臘，即使人數再多，也不符合接受請法（或接受差遣教誡）的資格，因為德行戒臘不圓滿的緣故。

【譯文】其次一科說明，尼眾僧中差派使者、比丘僧中必定差派教誡師，這兩者都是羯磨的所為之人，都不計入出席法定人數，所以各自都必須有五人方能成辦羯磨。如果只是施行略法，就不必比丘僧人數滿額。

【譯文】關於在兩處教誡中都列出上座，是指本律的原文；因為身為眾首的比丘統領持維法務，每逢有事情傳達，無不承受撫慰，正如前文所述之代佛行化。

【899-0007】03_業疏/19b_卷四之二#68
【原文】次座上法教尼中，初文兩處教誡，即注中前云上座作略教法，後云上座有教勑。指本律者，示所據也。以下出所以，達至也，承領撫恤，以應前事
【譯文】其次在座上如法教誡比丘尼的文段中，初文所說「兩處教誡」，即注文中前文所說「上座作略教法」，後文所說「上座有教敕」。指明出自本律，是顯示所依據的教典。自此以下說明緣由：「達」是到達，「承」是承受領受，「撫」是撫恤，用以應對前面的事務。

【899-0016】03_業疏/19b_卷四之二#77
【原文】答：不須說也。前告淨者，元未預聞；此已陳默，不勞重告。若更須說，即座惡覺，亦須說耶？佛制心念在眾聞露，雖有此難，無文制說。然是後來餘不聞者，及有憶過不告，皆犯。不同在座有開心念，各有所以，任兩通之
【譯文】答：不需要陳告。前面需要陳告清淨的人，是原本未曾參與聽聞；此人此前已經以靜默陳述了清淨，不需要重複陳告。如果此人還需要陳告，那麼在座時心生惡尋思（惡覺），也必須陳告嗎？佛制可以在大眾中心念發露並聽戒。雖然有這種難問，但律文中並沒有規定必須再次陳告。然而若是後來進入而其餘戒條未曾聽聞的人，以及憶起自己有過犯而不陳告的人，都構成犯戒。這不同於在座時開許可以心念發露的情形，二者各有其道理，不妨兩說並通。

【899-0017】03_業疏/19b_卷四之二#78
【原文】釋中初約不須釋，已經三問，默應淨故。惡覺念起，律制犯吉，聽在眾露，不令再告，故舉為難，例知不須。雖下次約必須釋，初縱上難詞，然下奪歸今義。餘不聞者，即中間諸篇，及憶過者，謂說欲出外方憶犯也。各下雙結，文無去取，準說為長

【899-0030】03_業疏/19b_卷四之二#91
【原文】三種略中初科，初斥非；「就」下示法，初通敘略法之要；「常」下正釋所出之法，意謂臨時緣來，即須戒師觀緣而略。今依《母論》，乃是冬夏寒熱等緣預先備擬之法，故曰「容所敘致可廣始終」者，始即前序，終即滅諍，下文既非急難，容可廣也；而略中廣，即中間七篇略題篇目，是所略也。是則前後自廣，中間名略。問：七滅諍為通略否？答：八篇皆略，何有不得？準如《尼鈔》，滅諍亦略。若爾，文何不略？答：《母論》略緣但止眾學，又滅諍不長，容可廣說，引起後結，所以存之。問：《事鈔》分略却、略取，今文明略，為却為取？答：一言略者，則兼却、取。如云「諸大德是四夷法」，即取篇名，為略取也；「僧常聞」者，略去戒條而不說者，為略却也。《鈔》云「略取謂取諸八篇題首，略却謂諸篇種類是也」。自餘妄說，具如《資持》所破。
【譯文】在三種略說的第一科中，首先斥責非理的做法。自「就」以下指示作法：先普遍敘述略法的要旨；自「常」以下正式解釋所提出的方法，意思是指臨時有事緣降臨，就必須由說戒師審察事緣而行略說。現今依照《毘尼母論》，這是針對冬夏寒熱等因緣預先籌擬的方法，所以說「容所敘致，可廣始終」——「始」即是前面的序分，「終」即是最後的滅諍法；下文既然不是危急的大難，自可從容廣說；而「略中廣」，是指中間七篇只簡略題出篇目，這就是被省略的部分。如此則前後自然廣說，中間稱為略說。問：七滅諍法是否可以通通省略？答：八篇全部省略，又有何不可？依照《比丘尼鈔》，滅諍法也是可以省略的。若真如此，文中為何不省略？答：《毘尼母論》的省略因緣只截止於眾學法，況且滅諍法並不冗長，尚能從容廣說，以引出最後的結語，所以予以保留。問：《事鈔》中將略說分為「略卻」與「略取」，現在疏文說明略說，是指略卻還是略取？答：單說一個「略」字，則兼含「卻」與「取」。例如說「諸大德，此是四夷法」，就是提取篇名，這叫「略取」；說「僧常聞」，省略戒條而不宣說，這叫「略卻」。《事鈔》說：「略取是指提取八篇的首題，略卻是指省略各篇的細條種類。」其餘無根據的妄說，都正如《資持記》中所破斥的那樣。
