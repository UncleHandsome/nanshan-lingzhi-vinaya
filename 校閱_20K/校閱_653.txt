# 校閱材料　第653檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【653-0005】資持記/15e_下三#17
【原文】毀三寶及戒為四，五不利優婆塞住處〔遮部彼所受戒〕；六作他惡名稱；七欲辱彼住處；八以非法為正法，欺誑於人。〔或可此三，通以不利改之，故不別舉。〕若有此八，許令不敬，以無德故。若下，次教道不往俗。聚落亦爾者，上約一家；合聚皆嗔，比丘不往彼聚。《雜含》。示名實。
【譯文】毀謗佛、法、僧三寶以及毀犯戒法合為四項，第五項是不利於優婆塞的住處（遮止阻礙其所受之戒法）；第六是造作各種惡名聲；第七是企圖羞辱他們的住處；第八是以邪偽的非法冒充為正法來欺騙誑惑世人。（或者這後三項，都可以通融歸納為「不利」來概括改換，所以文中沒有單獨列出。）如果有這八種過失，佛陀就允許信徒不予恭敬，因為其人已無德行的緣故。自「若」字以下，接著教導道人不往俗家去之法。聚落也是如此的意思，上面是就一個家庭而言；若整個村落的人都對僧人懷有嗔怒，比丘就不要前往那個村落。《雜阿含經》。開示名分與實質相符的道理。

【653-0007】資持記/15e_下三#19
【原文】須臾恩者，懷抱長養，至於長大，經涉多時；百年勤苦，不報須臾，況多時乎！以道供俗，本是污家；唯許二親，故云聽也。得重罪者，違制，吉羅，業道重故。〔有云：逆蘭，詳之。〕二中。不信少經理者，逼令歸正故；經理，謂供給營幹也。有信恣與者，必無虛費故。
【譯文】須臾之恩的意思是：從幼小懷抱撫育撫養，直到長大成人，經歷了漫長的歲月；即使以百年勤苦辛勞來奉養，都報答不了片刻須臾的深恩，何況是那麼長久的歲月呢！以出家修道之物供奉在家俗人，本來屬於破壞白衣淨信的「污家」罪行；唯獨允許供養父母雙親，所以經文說「聽」（開許）。得重罪者，因為違背了佛制，結吉羅罪，這在業道上是十分嚴重的。（有人認為結蘭罪，應當詳細審核辨正。）第二段中。對沒有正信的父母稍微經理其生活，是為了逼令促使他們回歸正信；經理，是指供給物質並代為營辦勞作。對有正信的父母可以隨意給予，因為必定不會虛度浪費。

【譯文】開許將父母帶到寺院居住，是因為世上已沒有其他親人可以依止歸宿的緣故。為母親擦洗身體時不得肌膚相觸，是因為接觸之戒對親生母親也不得開許。待父親如同沙彌一樣，是指在生活供養上等同於小眾道人。《唐高僧傳》記載：敬脫法師平時挑擔，一頭挑著母親，一頭挑著經卷經典；到吃飯時，把母親安置在樹下，自己進村乞食，用來供給母親食用；又有北齊道紀禪師（原文訛作齋道紀），也是把經書、佛像以及老母親、掃帚一併挑擔在肩上雲遊；他常對人說：經上不是說嗎，掃平僧地即使大如閻浮提洲，還不如掃平佛地一掌之大的功德；

【653-0009】資持記/15e_下三#21
【原文】親供母者，與登地菩薩齊；人或助檐者，紀曰：吾母也，非他之母；形骸之累，並吾身也；有身必苦，何得以苦勞人；所以身為苦先，幸勿相助。此乃大度，豈比常途；雖教有小違，而理歸大順；酬恩竭力，今古無之。三中，《涅槃》。三寶一體，體無生滅，故皆常住。啟，開也。
【譯文】親自供養母親的人，功德與登地菩薩平等；有時有人要幫忙挑擔，道紀法師說：這是我自己的母親，不是別人的母親；這個形骸軀體的牽累，也全是我自己的身體；只要有身體就必定有勞苦，怎能拿自己的勞苦去勞累別人呢；所以我應當身體力行為母親吃苦在先，希望大家千萬不要幫忙。這乃是菩薩的大度胸懷，豈是尋常凡情所能相比；雖然行跡上對戒律有微小的相違，但在至理上卻契合了至高的大順；竭盡全力報答父母重恩，古往今來罕有人及。第三段中，引《涅槃經》。佛法僧三寶本具一體，法體無生亦無滅，所以全都是常住不滅的。啟，是啟開、開悟的意思。

【原文】愛道是佛姨母，佛生七日，摩耶命終，姨母乳養長大。愛道在俗，已證初果，故云況得淨信。是知生育恩大雖百年肩荷，不報須臾；三寶一聞，即酬重德。故唯佛法，可報劬勞；自外供須，終名直養。四中。彼經第一云：佛言：我於過去世時，波羅奈國，有長者子，名慈童女；父喪賣薪，日得兩錢，奉養老母；

【653-0016】資持記/15e_下三#28
【原文】田主如王，擁護由己〔得白在故〕。作是語已，田主歡喜；問言：汝取此󰝿何為？答言：有盲父母，願以奉之。佛言：鸚鵡者，我身是；田主者，舍利弗是；盲父母者，淨飯摩耶是。《增一》兩節，初校量功德。一生補處，即等覺菩薩。準知孝養，德唯降佛。《菩薩戒》云：孝順至道之法；儒書亦謂至德要道。
【譯文】而田主如同國王，保衛護持全由自己做主（因其能得自由自在的緣故）。說了這番話後，田主非常歡喜；問牠說：你摘取這些穀物做什麼用？小鸚鵡回答：家中有眼盲的父母，希望能拿回去奉養他們。佛說：那隻小鸚鵡，就是我的前身；那個田主，就是舍利弗；那對雙盲的父母，就是淨飯王和摩耶夫人。《增一阿含經》的兩段文，第一段校量功德。所謂一生補處，是指等覺菩薩。由此準照可知，孝養父母的功德，唯有佛陀果位能超越它。《菩薩戒》說：孝順是通達至道的根本大法；儒家經典也稱孝道為至德要道。

【653-0017】資持記/15e_下三#29
【原文】則萬善之總，百行之源。儒釋皆然，釋門尤切；常當思報，勿得背恩。文下，次明恩大。文合作又，並《增一》故。謂雖以善導，罔極難酬，故云不可報；或可教導餘人，可使報恩；父母有恩，故不望報。是下，結勸。五中。論舉盲病，餘病例然；又但闕所須，不必在病。
【譯文】由此可見孝道是萬種善法的總匯，是百種品行的根源。儒家與佛家都是如此，而佛門的要求尤為切要深切；身為佛子應當常念圖報親恩，萬萬不可背離辜負大恩。下文第二段，接著說明親恩無量廣大。經文中的「文」字應當作「又」字，因為兩處都是引用《增一阿含經》的緣故。意思是說雖然可以用善法引導父母，但父母昊天罔極的深恩依然難以徹底報盡，所以說「不可報」；或者也可以解釋為，教導外人尚且能指望對方知恩報答；但父母對兒女只有純粹的慈恩，從來不指望回報。自「是」字以下，結語勸誡。第五段中。論中雖然只舉出盲目與疾病為例，其餘的病苦都可準此類推；而且只要是缺乏生活所需，並不一定非要生病才可給予。
