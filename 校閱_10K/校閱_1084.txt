# 校閱材料　第1084檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1084-0001】資持記/06c_中一上#50
【原文】戒淨障業，惑待智亡；望分所除，故云別脫。〔此明近義。〕後智除惑，乃稱究竟解脫。〔此證遠義。〕下文指後，即戒體中發戒數量門；彼明境量等，即別脫之義，可見。四具緣門，敘意中，初示受法。末代唯羯磨者，以五受中，善來、三語、八敬，唯局佛在；
【譯文】持戒能清淨障道之惡業，煩惱惑障則有待智慧生起方能消亡；著眼於隨分所除滅的惡業而言，所以稱為「分別解脫」〔此明近義〕。日後智慧生發徹底掃除根本惑障，那才稱得上是究竟圓滿的大解脫〔此證遠義〕。下文指涉後面的章節，就是指戒體章當中的「發戒數量門」；該處闡明了所面對的境量界限等等深義，隨處個別解脫的義理，從那裡便可以清楚照見。在第四項「受戒具足因緣門」中，在「敘述宗旨意趣」的部分，首先揭示受戒的具體傳承法則。末法時代之所以唯獨採用「白四羯磨」的受戒法，是因為在佛陀時代所開許的五種受戒方式當中，佛喚一聲「善來比丘」、領受「三皈依語」、以及尼眾順從「八敬法」而得戒，這三種方式唯獨局限在佛陀在世時才能施行；

【1084-0002】資持記/06c_中一上#51
【原文】破結微通，稀而復隱故。藉因緣者，或發心為因，餘事名緣；或能受為因，所對為緣；或俱因緣，如前已辨。其下，明重述意。一門，即〈受戒篇〉。比丘大綱者，攝僧要故；佛法根本者，住持勝故。列緣中。此但撮前受法，徑示是非；分對解釋，前已具委；久聽既知，不喜煩釋；
【譯文】「破結微通」是指見諦破結而得戒，雖微細通於佛後，但極其稀少而且冥昧隱晦的緣故。所謂「藉助因緣」，或者指行者發起至誠的善心為「因」，其餘前方便與壇場事務稱為「緣」；或者以能發願受戒的行者自體為「因」，對境所面對的十師僧眾與壇場為「緣」；或者是彼此互為因緣，這在前面章節都已經詳細辨析過了。接下「其下」說明在此重新敘述的用意。所謂「一門」，就是指本鈔上卷的〈受戒篇〉。之所以稱為「比丘法統的根本大綱」，是因為它是統攝清淨僧團最關鍵的核心；之所以稱為「佛法傳承的命脈根本」，是因為它在住持延續正法上的功德最為超勝。在「列舉各項受戒因緣」中，此處僅僅是撮要擷取前面的受戒法規，直接明確地指示對與錯、合法與非法；逐條分門別類的詳細解釋，在前面章節已經詳細具備了；長久聽聞律學的人既然早已通達明白，自然不喜歡繁瑣重複的長篇解說；

【1084-0003】資持記/06c_中一上#52
【原文】新學未曉，自可尋之，故略點示耳。初列五緣，竝出《母論》。三中。初明受者知師，下至小罪；通望下，明十師互知，唯據重夷。心不具法，謂無戒者；如十三難，《十誦》白衣之類。雜相中。初又云者，懸取論意，或可引前受緣。五八戒下，竝略破重之言，故云乃至十戒等。二引論示。
【譯文】新進初學的人若尚未能通曉，自當回頭翻尋前面的詳細章節，所以在本處只是簡明扼要地提點開示而已。最初列出的「五種受戒因緣」，全都出自《毘尼母論》。在第三項因緣中，首先說明受戒者本人如果知道自己依止的戒師具有毀犯過失，即使犯的是極細微的輕罪也不能作師；接下「通望下」說明十師之間如果彼此察知對方的罪過，判定失格的標準唯獨局限於犯了波羅夷重罪。所謂「心靈不具足正法」，是指根本不具備戒體的破戒者；例如身犯十三難的障戒者，或者如同《十誦律》所說的未曾真正得戒的在家人之流。在「雜類受戒相狀」中，一開始說「又云」的文句，是預先採納該論典的深意，或者也可以理解為引述先前的受戒因緣。在「五戒與八戒」之下，全都略去了「毀破重戒」等具體文句，所以才說「乃至十戒」等等。第二段引述論著加以說明。

【1084-0004】資持記/06c_中一上#53
【原文】彼明六種戒，隨犯一重，餘皆絕分。文中，具舉五戒，餘竝略之，故云乃至等。八字寫訛，準論，合作十戒，即越過八戒也。不得如前者，同上五戒也。三結界中，初斥單結戒場。更下，不字疑是多寫，去之則義便。直結小界，即目戒場，對大言小；如前結法，可知。今下，次斥無緣結小界。
【譯文】該論著闡述有六種層次的戒律，隨意毀犯了其中任何一條根本重戒，對於其餘各級戒品便徹底斷絕了受戒獲益的可能。在論典原文中，完整列舉了在家五戒的相狀，其餘各戒則一概予以略過，所以說「乃至」等等。「八」這個字顯然是傳抄時的筆誤，依照論典的原義，應當改作「十戒」，也就是直接跨過八戒而晉升到沙彌十戒。所謂「不能如同前面一樣得戒」，是等同於上面所說的在五戒中已經失格的情況。第三項在「結界如法與否」中，首先斥責單純僅僅結出一個孤立的「戒場」。接下「更下」文句中的「不」字，我懷疑是傳抄時多寫出來的衍字，將它刪除之後文意反而更為通暢順達。直接僅僅結出「小界」，其實就是專指戒場，是相對於「大界」而言稱為小；這如同前面的結界法則所載，大家應當都知曉。接下「今下」接著斥責在毫無特殊法難因緣的情況下擅自結立小界。

【1084-0005】資持記/06c_中一上#54
【原文】此即三小，有難應法，無故為非。四中，初引論示心。重輕二心，難顯其相，非謂徒然懇惻而已；要在見境明白，上品要誓，方名增上重心。亦如前說，恐忘故重示耳。又下，約行顯相，初示得失。依論，即上《多論》，以期持奉即殷重。故下，引文證。
【譯文】這就是指「三種小界」，唯有在遭遇強盜、惡獸等危難因緣時，為了急迫行法才能合乎佛制，若是平白無故無難而結就是非法。在第四項中，首先引述論典來說明受戒時的心態。受戒時內心究竟是處於殷重還是輕率的狀態，這在心靈行相上極其微細而難以彰顯，絕非口頭上表面流露的懇切悲憫而已；最關鍵的核心在於面對一切善惡境界時內心必須清晰明白，發起至高無上的堅定誓願，這才能稱得上是「增上重心」。這也如同先前章節所說明的，只是因為擔憂後人遺忘，所以在此再次鄭重提示。接下「又下」是依據具體的實踐行持來顯發心相，首先揭示得戒與否的得失關鍵。依據論典的標準，也就是指上面提到的《薩婆多毘尼毘婆沙》，唯有立志終身奉持遵行的行者，才稱得上是殷重至誠的心態。因此接下「故下」引述律文予以證明。

【1084-0006】資持記/06c_中一上#55
【原文】律自釋云：共比丘者，共餘比丘受大戒，是共比丘義。〔此謂受體同，《刪定戒》改云共戒是也。〕；同戒者，釋云：結此戒已，寧死不犯，共餘比丘同，是同戒義〔隨行同也。〕此即律本淫戒中文，雖文局初戒，而義通二百五十。
【譯文】廣律自己解釋說：所謂「與比丘共同」，是指與僧團中的其餘比丘一同受持大戒，這就是「共比丘」的真意〔這是指受體同一，《刪定戒本》改作「共戒」指的就是這個意思〕；所謂「同戒者」，廣律解釋說：在如法受得這條戒法之後，寧可捨棄身命也絕不毀犯，這種堅守與僧團其餘比丘完全一致，這就是「同戒」的真意〔隨行同也〕。這段話本是出自律本中第一條「淫戒」的釋文，雖然文字上僅僅局限於第一條大戒，但其所貫通的法義卻通達整整兩百五十條戒。

【1084-0007】資持記/06c_中一上#56
【原文】所以戒首先標此者，意明必具受隨二戒，乃有持犯；非受則無隨，非隨則無受；此證願行相副，方成得戒明矣。願行，即受隨也。五時節中，初科。問：列四心，中略無記，故云乃至。無心者，論作入滅盡定；準《業疏》問：三性通得，則合無心入無記耳。
【譯文】之所以在戒相之首特別標出此點，意在說明必須同時具備「受戒」與「隨行」二戒，才有持戒與犯戒可言；沒有受戒之體就沒有隨順之行，沒有隨順之行則最初的受戒也形同虛設；這證明了唯有願（受體）與行（隨持）相互符合，才構成真正圓滿得戒，其理甚明。願與行，指的就是最初的「受戒之體」與後續的「隨順行持」。在第五項「受戒時節的心態」中，第一科提出問題：列舉了四種心態，中間略去了「無記心」，所以才說「乃至」。所謂「無心」，論典中是指進入「滅盡定」的境界；如果依照《業疏》中的提問：善、惡、無記三性都能通達得戒，那麼「無心」理應當被歸納進入「無記心」的範疇才對。
