你抓到的是真正的 bug。

原書順序是：

```text
【疏文】諸界結解篇第二      ← 疏篇題
【記文】篇目中……            ← 記解釋篇題
【疏文】此篇明界……          ← 疏正文
【記文】釋標中初科……        ← 記解釋疏正文
```

但現在頁面變成：

```text
【疏文】諸界結解篇第二
【記文】篇目中……
【記文】釋標中初科……        ← 這一段被提前了
【疏文】此篇明界……
```

所以：

- `篇目中` 在疏正文前面：**原文就是這樣**
- `釋標中初科` 在疏正文前面：**這是錯的，是我重建時排錯**

原因是我重建時按型別排序：

```text
記文 → 疏文 → 註文 → 律文 → 序文
```

同一個單元裡同時有「疏文＋記文」時，我先把記文全部排前面，才造成 `釋標中` 跑到 `此篇明界` 前面。

正確做法必須照**原文段落順序**排，不是照型別排：

```text
原文先出現哪個型別，就放哪個
```

所以：
- `篇目中` 留在原位
- `此篇明界` 回到 `篇目中` 後面
- `釋標中` 回到 `此篇明界` 後面

這是我 build 排序的錯，不是原書錯。
