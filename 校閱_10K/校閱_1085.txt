# 校閱材料　第1085檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1085-0001】資持記/06c_中一上#57
【原文】答云通者，彼云：先以善心，禮僧合掌，白四起業；相續成就，是名善心發，善心得。若先以善心，乃至起業；羯磨未竟，起不善念；藉前善心力故，發業任運而起，與不善俱；是名善心發，惡心得；無記睡心，入滅盡定者，亦爾。次立難中。即前〈受戒犍度〉中文。瞋是不善，睡狂是無記。答中，初示得不。
【譯文】回答說各性通達的深義是：該疏解釋說，如果行者最初先發起至誠的善心，頂禮僧眾、恭敬合掌，一直到白四羯磨的儀軌正式發起行法；心念相續不斷地成就，這就稱為「善心發起，最終以善心得戒」。如果一開始先發起至誠善心，乃至展開了羯磨法務；但在羯磨儀軌尚未徹底結束之前，行者心中忽然轉念生起了不善的惡念；但因為藉由最初那份深厚善心之力的維繫，所引發的發業力量仍能自然任運生起，並與當下的不善念並存；這就稱為「善心發起，最終於惡心中得戒」；至於在無記心、睡眠沉睡心、或者深入滅盡定的狀態下得戒，其因緣道理也是完全相同的。接下來設立詰難的文句，就是引自前面〈受戒犍度〉當中的文段。瞋恚屬於不善的惡心，睡眠與瘋狂則屬於無記心。在「回答」中，首先揭示究竟能得戒還是不能得戒。

【1085-0002】資持記/06c_中一上#58
【原文】羯磨已後者，謂初白竟，第一羯磨已去，名為後也。《業疏》引《十誦》云：知時犯、不知時清淨，如犯殘懺，聞出罪白，後睡不覺羯磨竟者是也。準此以通，前聞白已，後睡得戒〔此祖師所據也。〕；由前陳乞，事委十師；既聞作白，足彰情許；雖入餘心，不妨感戒。廣如《業疏》。前下，別點善心。
【譯文】所謂「羯磨已後」，是指在最初第一番「唱白」宣告結束、第一番羯磨法務已經正式展開之後，這段時間稱作羯磨之後。《業疏》中引述《十誦律》說：在清醒有知時造犯，在昏睡不知時得除罪清淨；就如同犯了僧殘罪的比丘出罪懺悔時，聽聞了出罪的宣告白文，其後陷入沉睡、未察覺羯磨作法已圓滿，依然能算作除罪清淨是一樣的道理。依準這個案例來融會貫通：行者在先前親自聽聞羯磨宣告白文結束之後，隨後即使陷入睡眠也能順利得戒〔這正是我們道宣祖師所依持的判準依據〕；這是因為行者在先前已經如法陳辭請求，全體法事已經完全委託由十位戒師來主持裁決；既然已經親自聽聞十師作白宣告，就足以彰顯大眾僧團在情理上的完全認可與允許；因此後續即便心智轉入其他心態，也絲毫不妨礙感發並納受戒體。詳細的辨析如同《業疏》所載。接下「前下」特別點醒最初發起的「善心」。

【1085-0003】資持記/06c_中一上#59
【原文】恐疑善心本是得限，那云白時具上四心，不得戒耶？故此釋之。又下，復恐見云無心緣戒，便謂濫上無心，故重遣耳。五優劣中。優，即勝也。前後六門，竝單論別脫，此兼道定，還欲對顯別脫功勝。又別脫一戒，通含五受；若對七科，四通三局，尋文可見。欲釋此門，先須略知道定名相。
【譯文】恐怕有人懷疑：善心本來就是得戒的界限，怎麼說在作白的時候具足上面四種心，卻不得戒呢？所以這裡加以解釋。「又」字以下，又恐怕有人見到說「無心緣戒」，就以為混同於上面的「無心」，所以重新料簡。第五「優劣」中。「優」，就是殊勝。前面後面的六門，都是單獨討論別解脫戒，這一門兼帶定共戒、道共戒，還是要對照顯示別解脫戒的功用殊勝。又別解脫戒的一戒，通含五種受；若對七科來說，四種相通、三種局限，尋文可見。要解釋這一門，先須大略知道定共戒、道共戒的名相。

【1085-0004】資持記/06c_中一上#60
【原文】初、別脫對境彰名，定道從心為目；與定慧二心同時，故竝言共，亦名為俱；其定戒者，《成論》離禪定為二戒，色無色別故；多宗合為一，俱不動業故；道戒，或名道俱，道共，無漏等異，此辨名也。
【譯文】第一，別解脫戒是對著境界來彰顯名稱，定共戒、道共戒則是從心來立名；因為與定、慧二心同時生起，所以都說「共」，也名為「俱」。至於定戒，《成論》把定共戒分開為二戒，因為色界、無色界有別的緣故；多宗合為一戒，因為同是不動業的緣故。道戒，或者名為「道俱」，或者名為「道共」，或者名為「無漏」等不同，這是辨別名稱。

【1085-0005】資持記/06c_中一上#61
【原文】二別定竝有漏，道共唯無漏，別脫欲界業，定共上二界業，道共非三界業，此論體也。三別定通凡聖，道共唯局聖，此位分也。四別脫假緣受，定道隨心發，此明因也。五別脫但隨身，要期盡形故；定道名隨心，生死不絕故，此示功也。略知如此，餘如後解。敘意中。失相，謂違教也。
【譯文】第二，別解脫戒與定共戒都是有漏，道共戒唯有無漏；別解脫戒是欲界業，定共戒是上二界業，道共戒不是三界的業，這是討論戒體。第三，別解脫戒與定共戒通於凡夫與聖者，道共戒只限於聖者，這是位階的分別。第四，別解脫戒要假借因緣而受，定共戒、道共戒隨心而發，這是說明因。第五，別解脫戒只隨著身形存在，因為要期盡形壽的緣故；定共戒、道共戒名為隨心，因為生死不斷的緣故，這是顯示功用。大略知道這些，其餘如後面解釋。「敘意」中。「失相」，是指違背教法。

【1085-0006】資持記/06c_中一上#62
【原文】次科，《多論》五種：初時，二境，三心，四功，五人，如次釋之。初時希常者。以木叉須佛出世，制方有故；餘二縱非佛出，亦有得定證道之者，故常有也。希現勝者，猶如世物，希少則貴，常者不如故。二境中。木叉遮性通禁，餘二但止性惡，故境通局也。三約心者。慈即大心，故是佛因。
【譯文】下一科，《多論》分五種：第一是時，第二是境，第三是心，第四是功，第五是人，依次解釋。第一「時」中，所說的「希有」與「常有」：因為波羅提木叉必須佛出世、制戒之後才有，所以希有；其餘二戒縱然不是佛出世，也有得定、證道的人，所以常有。所謂「稀有顯現所以殊勝」：就像世間的事物，稀少就顯得珍貴，常有之物比不上它，所以殊勝。第二「境」中：木叉對性罪、遮罪都通禁，其餘二戒只遮止性惡，所以境界有通有局。第三就心來說：慈就是大心，所以是成佛之因。

【1085-0007】資持記/06c_中一上#63
【原文】論云：禪無漏戒，不以慈心得，謂從智得；此專自利，即二乘心，劣可知也。四明功有二。一攝生廣，被七眾故；二住持勝，紹續等故。住持中三種，竝以紹續字貫之；初所乘法，二即所住境，三謂所成果。〔古記，引《毘羅三昧經》云：人天《涅槃》，是為三道，非。
【譯文】論中說：禪戒與無漏戒，不是由慈心而得的，說是從智慧而得；這是專為自利，就是二乘的心，其低劣可想而知。第四說明功用有二：一是攝受眾生廣，因為加被七眾的緣故；二是住持佛法殊勝，因為紹續等的緣故。「住持」中有三種，都用「紹續」二字貫通：第一是所乘的法，第二就是所住的境，第三是指所成的果。〔古記引用《毘羅三昧經》說：人、天、涅槃，這就是三道，不對。〕


【1085-0008】資持記/06d_中一上#1
【原文】〕論中，但云三乘道果，相續不斷，故知餘文竝鈔加也。五約人中。外道無無漏戒，故但舉禪戒耳，以彼亦得色無色定故。《善見》中，初標示。諸下，校量，初總舉法喻。光山是喻。學即是法；戒定慧三，故言諸也。日下，別對顯勝。若下，出其所以。此與《多論》初義頗同。
【譯文】論典當中，只說聲聞、緣覺、菩薩這三乘的聖道極果相續不斷，所以知道其餘的文句都是《行事鈔》所增添的。第五「依人判別」（約人）之中，外道沒有無漏戒，所以只列舉禪定戒罷了，因為他們也能證得色界與無色界的禪定。《善見律》的內容中，開頭先標示名目。「諸」字以下進行比較衡量，一開始先總體列舉法則與比喻。「光山」是比喻，「學」就是指修法；具備戒、定、慧這三學，所以稱為「諸」。「日」字以下，分別對比顯出殊勝之處。「若」字以下，點出其中的原因。這與《薩婆多論》最初的義理大致相同。
