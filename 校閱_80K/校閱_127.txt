# 校閱材料　第127檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【127-0001】資持記/06a_中一上#52
【原文】疏引彼文，初二兩篇，各有遠近方便〔彼唯立二方便〕，位分三階；初篇近者，界內僧懺〔上品〕；初篇遠者，二篇近者，界外四人悔〔同是中品〕；二篇遠者，一人前悔〔下品。〕準持犯中三罪，則依《了論》，遠者重吉，此據本宗；次近二蘭，全取《十誦》。
【譯文】戒疏引用該律的文句，第一篇與第二篇各自有遠方便與近方便（該律唯獨建立兩種方便），位次劃分為三個等階：第一篇的近方便，在結界內面對僧眾懺悔（上品）；第一篇的遠方便，與第二篇的近方便，在界外對四位清淨僧悔過（同屬於中品）；第二篇的遠方便，在一同修前悔過（下品）。若是依照持犯篇中的三種罪，則是依據《戒了論》，遠方便是重突吉羅，這是依據本宗；次方便與近方便兩種偷蘭遮，則完全取自《十誦律》。

【127-0002】資持記/06a_中一上#53
【原文】然下，會同次罪。《十誦》中蘭，《了論》重吉；今欲用蘭替吉，略示令知，餘指如後。凡定罪體，必約懺論；中蘭據法，雖對小眾；正捨本罪，還同吉羅，一人對滅故。體通彼此者，即指兩文。類解者，令較二罪。第二僧殘，《善見》中。唯就行懺，釋其名義。僧伽是通，貫於前後；
【譯文】從「然下」開始，會通次一等的罪名。《十誦律》定為中品偷蘭遮，《戒了論》定為重突吉羅；如今想要用偷蘭遮替代突吉羅，略作提示讓大家知曉，其餘指明如後文所示。凡是判定罪體，必定依照懺悔的方法來論定；中品偷蘭遮依據法軌，雖然要面對四人小眾；但真正捨除罪業本體時，還是如同突吉羅一般，只要對一人發露便能滅除。所謂「體性通於彼此」，是指這兩部文獻。「依類理解」，是令人去比較這兩種罪過。第二「僧伽婆尸沙（僧殘）」，在《善見律毘婆沙》中，唯獨從實行懺悔的角度，來解釋它的名義。「僧伽」是通稱，貫穿在整個懺悔過程的前與後；

【127-0003】資持記/06a_中一上#54
【原文】初殘是別，即命懺時首尾二法，以攝中間。合云：僧伽為眾；然此所尚，呼人為僧；故此諸文，用梵顯梵，非相翻也。言從境者，境即所對人也。《婆沙》中，名義。與下《四分》、《母論》大同。初別釋僧義，同前。殘字目罪，言犯此罪，少有餘行故。有下，合結。《四分》中，初指同。
【譯文】「初」與「殘」則是個別之義，即指命其行懺時的一頭一尾兩種僧法，以此收攝中間的行法。合起來應當說：僧伽翻譯為「眾」；然而此地一般崇尚，習慣將出家人稱為「僧」；所以這些文字，是用梵文來說明梵文，並不是中梵互翻。所謂「依從境界」，境界就是指所面對的懺罪對象僧眾。《薩婆多毘尼毘婆沙論》中對名義的解釋，與下文《四分律》、《毘尼母論》大體相同。起初分別解釋「僧」的含義，與前文相同。「殘」字是指罪過，意指犯了此罪，尚有微少殘餘的戒行生命可以挽救。從「有下」開始，總結收束。在《四分律》中，首先指明與彼相同之處。

【127-0004】資持記/06a_中一上#55
【原文】又下，示異。有餘，亦即殘義。行法，對上無餘，合云眾法，疑是寫誤；亦可行通眾別，此據眾行。《母論》，初牒名。如下，喻釋，上三句喻殘。理下一句喻僧。此望初篇，名為斷頭，不可救故。故下，引律助顯。強與，即是早救；餘罪不然，從彼自悔爾。僧尼中。六異者，弄觸二麁二房；
【譯文】從「又下」開始，指出相異之處。「有餘」，也就是殘存的含義。「行法」，對應上面的無餘，合該稱作「眾法」，懷疑是傳抄筆誤；或者也可以說「行」通指大眾作法與個別修持，這裡是指大眾的羯磨行法。《毘尼母論》首先列出罪名。從「如下」開始，運用譬喻解釋，前三句比喻殘存之命。從「理下一句」開始，比喻僧伽醫王。這對照第一篇而言，第一篇名為斷頭，根本無法救治。所以下文引律文助顯其義。強行給予救治，就是指及早施救；其餘罪過就不是這樣，聽任犯者自己去悔過即可。在比丘與比丘尼戒的對比中，六條相異的戒是：手弄陰相、摩觸、兩條粗惡語、兩條作房戒；

【127-0005】資持記/06a_中一上#56
【原文】七同者，媒嫁二謗四諫，此約僧戒對尼為言。若以尼望僧，則有十異：一言人，二四獨，三度賊女，四解舉，五受染心男子食，六勸受，七相覆違諫，八勸同惡住違諫，九小恚捨正違諫，十喜諍謗僧違諫。〔尋尼戒本對之。〕下指廣者，即〈別行篇〉。罪數中，引論。
【譯文】七條相同的戒是：媒嫁、兩條毀謗戒、四條諫戒，這是依據比丘戒對比比丘尼戒而言。若是用比丘尼戒對照比丘戒，則有十條相異：一是說人陰事，二是四獨（獨行、獨宿等），三是度盜賊女出家，四是解免被舉比丘尼，五是接受染心男子飲食，六是勸他人接受飲食，七是互相覆藏違抗僧諫，八是勸人同惡相濟住違抗僧諫，九是因小瞋恚捨棄正法違抗僧諫，十是好起諍端毀謗僧伽違抗僧諫。（查閱比丘尼戒本便可比對出。）下文指示詳盡之處，就是指〈尼眾別行篇〉。在罪過數量中，引證論典。

【127-0006】資持記/06a_中一上#57
【原文】五十二罪者，十三根本，一一各有三方便故，吉羅為遠，下蘭為次，中蘭為近。胝字，竹尼反。疏解中，初科。三義者，一僧殘，二救，三勝。《婆論》止有初釋，故云一義同也。次科。解云者，疏引彼解也。初釋僧伽，上二句標示，由下簡異。戒見事和，定慧理和；
【譯文】所謂五十二種罪，是因為十三條根本戒，每一條各自具備三種前方便，突吉羅為遠方便，下品偷蘭遮為次方便，中品偷蘭遮為近方便。「胝」字，音「竹尼反」。在戒疏的解釋中，第一科判。三種含義分別是：一、僧殘，二、救護，三、殊勝。《毘婆沙論》只採用了第一種解釋，所以說「只有一種義理相同」。第二個科判中。所謂「解釋說」，是戒疏引用該論的解釋。首先解釋「僧伽」，前兩句標明指陳，從「由下」開始揀別差異。戒和與見和屬於「事相和合」，定與慧則屬於「理體和合」；

【127-0007】資持記/06a_中一上#58
【原文】今但取事，不取理故。文中多上不字，曾以古本校勘，復對下釋，寫錯不疑。〔舊記不知，隨文謬解。〕佛下，別釋。可解。次婆尸沙。乃約所得利養之餘，以釋殘義。此即求懺行別住者，若犯不懺，不同僧利。後釋二名者。以僧伽之義，該通三法；波利婆沙，此云別住；文雖不列，義見上文；
【譯文】如今僧事羯磨只取事相和合，不取理體和合。文中多出了一個「不」字，曾經用古抄本勘校，再對照下文的解釋，是抄寫錯誤無疑。（舊時的注釋書不知情，順著錯字妄作解釋。）從「佛下」開始，各別解釋，義理容易理解。其次解釋「婆尸沙」，是依據所得的利養殘餘，來解釋「殘」的含義。這就是指祈求懺悔而遵行別住的人，如果犯了戒不肯懺悔，就不能享受與清淨僧同等的利養。後文解釋兩個名稱，是因為「僧伽」的義理，涵蓋了三種作法；「波利婆沙」，此處譯為別住；正文中雖然沒有列出，但其義理在前面的文句中已經顯現；

【127-0008】資持記/06a_中一上#59
【原文】故但出二法，即六夜出罪也。引正量中。指同釋別，尋文可見。三偷蘭聚，《善見》中，初翻名。障善道者，即罪之力用也；下翻罪，惡過者，就罪之當體也。後下，釋義。惡能障善，從業為名。〔古云調達破僧，令法輪不轉，名障善者，一暗文相，二成局狹。〕從下，出所以。又下，出異名。《聲論》。
【譯文】所以論中只提出兩項法軌，也就是六夜摩那埵與出罪羯磨。引用正量部的文獻中，指明相同之處、解釋相異之處，循著文字便可看出。第三「偷蘭遮聚」，在《善見律毘婆沙》中，首先翻譯名稱。「障礙善道」，是指這項罪過所產生的破壞力用；下文翻譯為罪、「粗重的過患」，是依據罪過的當下體質而言。從「後下」開始，解釋其義理。惡業能夠障礙善法，這是依循業用來立名。（古人說調達破壞僧團，使得法輪無法轉動，名為障善，這是一者昧於文字相貌，二者使得義理變得偏頗狹隘。）從「從下」開始，說明立名的因由。從「又下」開始，指出異名。引《聲論》。

【原文】通前即欲界六天也，此墮眾合地獄。人間二百年，為天一日，六千年為一月，七萬二千年為一年，七十二萬年為十年，七百二十萬年為百年，七千二百萬年為千年，十四千四百萬年為二千歲。〔千萬為億，成十四億；十萬為千，成四十千；檢經本作二十四億，二字錯，合作四字；鈔云：二十一者，據算甚差，必應傳誤矣。

【127-0065】資持記/06b_中一上#52
【原文】次《涅槃》中，初引經。忉利天，即三十三天；日月歲數，亦約人間計之。與下，通會。俗中算數，十十為百，十百為千，十千為萬，十萬為億，十億為兆〔此為小數〕；或以百百為千，千千為萬，萬萬為億等〔此為大數〕。前經據其大數，《涅槃》從小數；
【譯文】接著在引用《大般涅槃經》的段落中，首先引錄經文。忉利天就是指三十三天；日月與歲數的計算，同樣是依據人間的標準來折算的。從「與」字往下的文段進行融會貫通。世俗中的算術算法，十個十是一百，十個百是一千，十個千是一萬，十個萬是一億，十個億是一兆〔這是小數的算法〕；或者以百百為一千，千千為一萬，萬萬為一億等等〔這是大數的算法〕。前一部經文是依據大數算法，《涅槃經》則是採用小數算法；

【127-0066】資持記/06b_中一上#53
【原文】然二經對天不同，九百八百之異，未可和會。勸信中，初指經。是佛說者，人可信也；《目連問經》，即漢安世高譯；《涅槃》，是北涼曇無讖譯。藏中經有失譯，謂無譯主名字；又有疑經，謂真偽難明；復有偽經，淺近可別者。猶恐愚者雖見經文，意謂時賖土異，傳文至此，焉知佛說；故特遮之。
【譯文】然而這兩部經所對照的天界並不相同，對於九百年與八百年的差異，目前暫時無法強行調和歸一。在勸導大眾深信的段落中，首先指明出自經典。經文之所以標明是佛所說，是因為翻譯的人（譯師）足堪信賴；《目連問經》是由東漢安世高法師所翻譯；《涅槃經》則是由北涼曇無讖法師所翻譯。在大藏經中有「失譯」的經典，是指遺失了譯師的姓名；又有「疑經」，是指真偽難以考證的典籍；更有「偽經」，文辭淺陋粗俗一眼即可辨別。作者唯恐愚昧之人雖然見到了經文，心中卻以為年代久遠、地域懸隔，經文輾轉傳譯至此，哪裡還能確信是佛陀親說；因此特地加以駁斥防範。

【127-0067】資持記/06b_中一上#54
【原文】今時多同此見，率墮邪林，良用悲痛。勿下，正勸。不反知者，謂不省己過。刑科，謂六獄受苦。長劫者，《智論》云：如大城，方四千里，滿中芥子，有長壽仙，百年取一芥；城雖空，劫猶未盡。又方四千里石，百年一拂；石雖摩盡，劫亦未盡，此喻時劫不可窮也。斥愚中，初科。
【譯文】當今時代有很多人抱持這種成見，紛紛墮入邪知邪見的險林之中，這實在非常令人痛心。從「勿」字往下的文段是正式勸勉。所謂「不知反省警覺」，是指不肯反觀自照檢討自己的過錯。所謂「刑科」，是指在六大地獄中遭受刑罰之苦。所謂「漫長大劫」，《大智度論》說：如同有一座大城，方圓四千里，裡面裝滿了芥菜子，有一位長壽仙人，每一百年取走一顆芥子；這座大城的芥子即使取盡空了，一個大劫的時間卻還沒有結束。又有一塊方圓四千里的巨石，每一百年用細軟衣服拂拭一次；這塊巨石即使被磨損殆盡了，一個大劫的時間也還沒有結束，這是用來比喻時間長遠到不可窮盡。在斥責愚昧無知的段落中，進入第一科。
