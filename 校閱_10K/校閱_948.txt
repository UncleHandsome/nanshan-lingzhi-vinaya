# 校閱材料　第948檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【948-0001】資持記/02d_上一下#53
【原文】人語者，即曹魏僧鎧翻譯時加。律中轉欲則無，前既準律，故云正本。明乖錯中。稱字去呼。謂對說時，與前詞句不相稱可；以餘眾別羯磨，不許落非；獨此欲詞，有成法義，故立此問。〔古作平呼，謂不稱欲緣，且上既云不稱正本，何乃反問成否，於理不然。〕答中，初句斷成。由下，釋所以。
【譯文】所謂「後人加入的話」，就是指曹魏時期僧鎧翻譯時所附加的。律文中轉傳欲意則沒有這段話，前面既然是依照戒律，所以說是「正本」。在說明差錯相違中。「稱」字讀去聲（讀作「秤」，意為相稱）。是指面對僧眾宣說時，與前面的言詞句子不相稱合；因為其餘大眾與個別的羯磨法，絕不允許出現絲毫差錯；唯獨這個交付欲意的言詞，有其成辦僧法的義理，所以設立這個問答。〔古人讀作平聲，認為是「不稱說欲的因緣」，然而上面既然已經說不稱正本，為何在此反而問成否？在道理上根本說不通。〕在回答中，第一句判定可以成辦。從「由」以下，解釋原因。

【948-0002】資持記/02d_上一下#54
【原文】如結界唱相，受懺陳乞，既牒入法，不可有乖。欲但通情，既不入法，有乖許得。律中下，引證甚明。文如後引。欲淨同異者，即第四句。據本非同，欲生後義，假設來問。答中，初分示。由律緣起欲淨各傳；從文而釋，猶同昔義。故《業疏》云：有人言等。後出今解云：欲者，表心無貳，以應僧體。
【譯文】如同結界唱出界相、受戒懺悔時陳述乞求，既然已經列入正法詞句中，就絕對不能有任何差違。交付欲意只是通達心意，既然沒有列入正法詞句，就算有些許差違也是開許可以成辦的。從「律中」以下，引證得非常清楚。文句如同後文所引用。所謂欲意與清淨是同是異，這是指第四句。按照原本的意旨並非相同，為了引出後面的義理，才假設提出這個問題。在回答中，起初分別說明。由於戒律中緣起由來，交付欲意與交付清淨是各自傳達的；順著文字來解釋，依然如同往昔的見解。故《業疏》說：有人言等。其後列出現在的正確解釋說：欲意，代表內心沒有二念，用來相應於僧伽全體的和合。

【948-0003】資持記/02d_上一下#55
【原文】〔三業中心口集即相和也。〕清淨表行無玷，實通假用〔戒見利同即體和，僧體、假用，名之異耳。〕，據此義通一切羯磨，不可偏配。唯自恣時，希僧舉罪，不敢陳淨，但云與欲自恣耳。若下，明合說。律本各傳，因六群與欲不與清淨，僧中有事起；
【譯文】〔在身口意三業中，心與口二業集會就是相貌上的和合。〕清淨代表行持沒有瑕疵，在實質上通於僧團作法的任用〔戒同、見同、利同就是體質上的和合，僧伽本體與假名任用，只是名詞上的差異罷了。〕，依照這個道理，這通於一切羯磨法，不可以偏廢單配。唯獨在自恣的時候，希望僧眾舉發自己的罪過，不敢自陳清淨，所以只說「交付欲意並交付自恣」罷了。從「若」以下，說明合併宣說。律本中原先是分開傳達，因為六群比丘只給了欲意卻不給清淨，僧中又有突發事務產生；

【948-0004】資持記/02d_上一下#56
【原文】持欲者言我持欲來，不得清淨，稽留說戒；佛言：自今已去，與欲時應與清淨；從此雙傳，故云正制。不下，簡濫。亦由昔人執彼行事，故此簡之。彼云：時集與清淨〔半月說戒常定故〕，非時集與欲〔餘羯磨不定故〕。此即《四分》所廢之教。釋如法中，初牒釋。下指非緣。
【譯文】持欲的比丘說：我帶著欲意前來，但沒有得到清淨，以致耽擱拖延了說戒法事；佛陀說：從今以後，交付欲意時應當連同清淨一起交付；從此之後兩者同時傳達，所以說是「正式制定」。從「不」以下，簡別混濫。這也是由於往昔有人執著於那種做法，所以在此予以簡別。他們說：定期集會時交付清淨〔因為半月說戒是恆常固定的〕，非定期集會時只交付欲意〔因為其餘羯磨是不定期的〕。這就是《四分律》中所廢除的教條。在解釋「如法」之中，起初提出並解釋。下文指出不合法的因緣。

【948-0005】資持記/02d_上一下#57
【原文】如〈眾網〉者，彼列二十餘件，乃至科索酒肉媒嫁淨人賣買奴婢。如是等並不須與。此下顯通。律中亦因六群稱事〔謂僧中事，如云為受戒事與欲等。〕，僧中有餘事起，稽留法事。佛言不應稱事，聽如法僧事與欲清淨。諸法事者，須簡結界。轉欲，敘緣中，初二句結前標後。
【譯文】如同〈眾網篇〉所載，那裡列出了二十多項，乃至包括索討酒肉、為媒作嫁、役使淨人、買賣奴婢等。像這類事一概不需要交付欲意。從「此」以下顯示通於一切。律中也因為六群比丘指稱具體事務〔是指僧中的具體事務，例如說「為了受戒這件事而交付欲意」等。〕，僧中又有其餘事情發生，耽誤了法事。佛說不應當指稱特定事務，聽憑在「如法僧事」中交付欲意與清淨。這裡所說的「諸法事」，必須簡別排除結界法。在轉傳欲意、敘述因緣中，前面兩句總結前文並標示後文。

【948-0006】資持記/02d_上一下#58
【原文】謂下，釋開意。律云：持欲比丘自有事起，佛言聽授與餘比丘。毘尼下，引證。彼云七相應法，受已轉與一人，如是至七皆成。文但至七，已外應閉。《僧祇》、《十誦》，若轉即失，部計不同。疏云：或是異宗所廢，且從當部。詞句中。六句。初後四句同前。受某甲下一句，牒前欲詞；
【譯文】所謂「謂」以下，解釋開許的用意。律文說：帶著欲意的比丘自己突發緊急事務，佛說聽憑轉授交給其餘的比丘。從「毘尼」以下引證。那裡說：轉至七人皆屬如法，接受之後轉交給一人，像這樣遞轉轉傳直到第七人都能成辦。經文只說到第七人為止，七人之外應當禁止。《僧祇律》、《十誦律》中，如果轉傳隨即失效，部派的主張見解各有不同。《業疏》說：這或許是其他宗派已經廢止的說法，姑且順從我們當前部派的教法。在言詞句子中。共有六句。前面與後面的四句與前文相同。從「受某甲」以下的一句，是陳述轉引前面的欲詞；

【948-0007】資持記/02d_上一下#59
【原文】若轉多人，須一一別牒人名；或忘姓相，但云與眾多比丘受欲清淨。餘詞並同。彼下一句，自他雙牒以付後傳。問成否中。律中五種，而世濫行，故作此問。答中，初文三，先明律緣。律中本為病人開故。具即一廣，缺即四略。良下，示具缺所以。文下，二引示。
【譯文】如果是轉傳給多個人，必須逐一分別宣讀每個人的名號；或者忘記了法名與外相，只要說「為眾多比丘接受欲意與清淨」即可。其餘的言詞完全相同。從「彼」以下的一句，是把自己與對方同時列出，以交付給後續傳達的人。在詢問成辦與否中。律中列有五種，而世間多有混亂妄用，所以設立這個問答。在回答中，第一段文字分為三部分，先說明戒律中的因緣。律中本來是為病患開許的緣故。「具」就是指一種廣說，「缺」就是指四種略說。從「良」以下，指示廣說與略說的原由。從「文」以下，第二是引證提示。

【948-0008】資持記/02d_上一下#60
【原文】〈說戒〉中云：有比丘白佛，有病比丘不來；佛言自今已去，聽與欲；若言與汝欲，成與欲〔鈔以此句在下，又汝字作我，復多說字；《注羯磨》同律，可驗鈔中傳寫錯倒。〕；若言我說欲，成與欲〔即鈔初句〕；餘三並同，下皆云成與欲。《業疏》分二，四略一廣；
【譯文】〈說戒犍度〉中說：有比丘向佛稟告，有生病的比丘不能前來；佛說從今以後，聽許交付欲意；如果說「給你欲意」，構成交付欲意〔行事鈔將這句放在下方，又將「汝」字寫成「我」字，而且多出一個「說」字；《注羯磨》與律文一致，可見行事鈔中的文字是傳抄時發生錯倒。〕；如果說「我說欲意」，構成交付欲意〔也就是行事鈔的第一句〕；其餘三句都相同，下文都說「構成交付欲意」。《業疏》分為兩種，四種略說與一種廣說；
