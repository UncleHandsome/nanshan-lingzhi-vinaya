# 校閱材料　第191檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【191-0001】01_行事鈔/09a_卷下之一#18
【原文】夫形居世累，必假威儀；障蔽塵染，勿過衣服。若受用有方，則不生咎戾；必領納乖式，便自陷深愆。故初總分制聽，後依門而解。何名為制？謂三衣六物，佛制令畜；通諸一化，並制服用，有違結罪。何名為聽？謂百一衣財，隨報開許；逆順無過，通道濟乏也。就初分三，謂三衣、坐具、漉水袋也。後中分四，謂百一諸長、糞掃、俗施、亡五眾衣，輕重等例。
【譯文】身處世間塵累之中，必定要憑藉威儀來防護身心；而要遮蔽風塵染污，沒有比衣服更切要的了。如果受用享用合乎法則，就不會產生過咎罪戾；若是領納享用違背軌範，便會讓自己陷入深重的罪愆。因此，首先總體區分「制」（佛陀制定必須遵守之律）與「聽」（佛陀慈悲開許之法），然後依照各門類加以解釋。什麼叫做「制」？就是指三衣六物，佛陀制定規定必須蓄持；通行於佛陀一期的教化之中，並且都規定必須穿著服用，若有違背便結罪。什麼叫做「聽」？就是指百一衣財（隨身所需之各類衣料物件），隨順僧眾各自的果報差異而予以開許；無論處於順境或逆境都不致招致過失，乃是為了通達道業、救濟匱乏。在前半部的「制」之中分為三種，即三衣、坐具、漉水袋。在後半部的「聽」之中分為四類，即百一各類長物（多餘之衣物）、糞掃衣、俗人布施之衣、亡故五眾的遺衣，以及輕物重物等各項條例。

【原文】今解初制。
【譯文】現在先解釋第一部分「制」。

【191-0003】01_行事鈔/09a_卷下之一#20
【原文】前明三衣，分二：初明衣法，後攝衣法。初中分四：一制意、釋名、功用。二作衣方法。三加受持法。四雜出料簡。
【譯文】首先說明三衣，分為兩部分：一是說明衣法（製作與受持之法），二是說明攝衣法（結界護衣之法）。在第一部分「明衣法」中分為四個項目：第一、制定之意旨、名稱之解釋與功德效用；第二、製作衣服的方法；第三、加法受持的方法；第四、雜項問題的審核辨析（料簡）。

【191-0004】01_行事鈔/09a_卷下之一#21
【原文】言制意者。《薩婆多》云：欲現未曾有法故；一切九十六種外道，無此三名，為異外道故。《分別功德論》：為三時故，制有三衣；冬則著重，夏則著輕，春則著中。亦為諸蟲故。《智論》云：佛聖弟子，住於中道，故著三衣；外道裸身無恥，白衣多貪重著也。《十誦》：為異外道故，便以刀截，知是慚愧人衣。《雜含》云：修四無量者，並剃鬚髮，服三法衣出家也。準此而名，則慈悲者之服。《華嚴》云：著袈裟者，捨離三毒等。《四分》云：懷抱於結使，不應披袈裟等。《薩婆多》五意制三衣也：一一衣不能障寒，三衣能障故；二不能有慚愧；三不中入聚落；四乃至道行不生善；五威儀不清淨故。制令畜三，便具上義。《僧祇》云：三衣者，賢聖沙門標幟；鉢是出家人器，非俗人所為；應執持三衣瓦鉢，即是少欲少事等。當宗外部，多為寒故制三。《四分》又云：三世如來，並著如是衣故。
【譯文】談到制定三衣的意旨。《薩婆多論》（《薩婆多部毘尼摩得勒伽》）說：是為了顯現未曾有之法的緣故；一切九十六種外道，都沒有這三種衣服的名稱，是為了有別於外道的緣故。《分別功德論》說：是為了適應一年三季的氣候，所以制定有三衣；冬天穿著厚重之衣，夏天穿著輕薄之衣，春天則穿著適中之衣。同時也是為了防護各類昆蟲叮咬的緣故。《大智度論》說：佛陀的聖弟子安住於中道，所以穿著三衣；外道赤身裸體毫不知恥，在家人（白衣）貪心深重而重疊穿著。《十誦律》說：為了有別於外道，所以用刀剪截碎布縫合，讓人知道這是知慚愧之人的衣服。《雜阿含經》說：修持四無量心（慈、悲、喜、捨）的人，都剃除鬚髮，穿著三種法衣出家。依照這段經文的含義，袈裟便是慈悲者的服裝。《華嚴經》說：穿著袈裟的人，能捨離三毒（貪、瞋、癡）等煩惱。《四分律》說：內心若懷抱著結使（煩惱），就不應該披著袈裟等等。《薩婆多論》提到制定三衣有五種用意：第一、單穿一件衣服無法禦寒，三衣合用則能禦寒；第二、只穿一衣無法生起充分的慚愧心；第三、不適合穿著進入聚落村莊；第四、乃至在道路上行走時不能生起善心；第五、威儀不夠清淨的緣故。制定令比丘蓄持三衣，便能具備上述五種意義。《摩訶僧祇律》說：三衣是聖賢沙門的標幟；鉢是出家人的器具，不是在家人所當使用的；應當執持三衣瓦鉢，這就是少欲少事等等。本宗（《四分律》）及其他各部派律典，多數是為了禦寒的緣故而制定三衣。《四分律》又說：過去、現在、未來三世諸佛如來，都穿著這樣的法衣的緣故。

【191-0005】01_行事鈔/09a_卷下之一#22
【原文】次釋名者。《增一》云：如來所著衣，名曰袈裟；所食者，名為法食。《四分》云：聽以刀截成，沙門衣不為怨賊所劫。應作安陀會，儭體著；欝多羅僧、僧伽梨，入聚落著。而此三名，諸部無正翻。今以義譯。《慧上菩薩經》：五條名中著衣，七條名上衣，大衣名眾集時衣。義翻多種：大衣云雜碎衣，以條數多故；若從用，名入王宮聚落衣。七條者，名中價衣；從用入眾衣。五條者名下衣；從用院內道行雜作衣。若就條數，便云十九、十七，乃至九條、七條、五條等。律中無五七九名，但云安陀會乃至僧伽梨；人名七九條也。若就通相，亦有縵僧伽梨；則隨力所辨，隨用分三。非無大分宗體。
【譯文】其次解釋名稱。《增一阿含經》說：如來所穿的衣服，名叫袈裟；所吃的食物，稱為法食。《四分律》說：聽許（准許）用刀剪截裁製而成，沙門的衣服便不會被怨家賊寇所搶劫掠奪。應當製作安陀會（五條衣），貼身穿著；欝多羅僧（七條衣）與僧伽梨（大衣），則在進入聚落時穿著。然而這三種名稱，各部派律典都沒有直接對應的音義定翻，如今依據其含義來意譯。《慧上菩薩經》記載：五條衣稱為「中著衣」（內著衣），七條衣稱為「上衣」，大衣稱為「眾集時衣」（大眾聚集時穿的衣服）。意譯有多種：大衣稱為「雜碎衣」，因為拼接的條數多的緣故；如果依其功用而言，稱為「入王宮聚落衣」。七條衣稱為「中價衣」；依其功用稱為「入眾衣」（加入僧眾法會時穿著）。五條衣稱為「下衣」；依其功用稱為「寺院內經行巡道及各項勞作之衣」。若依照條數來說，便稱為十九條、十七條，乃至九條、七條、五條等。律藏原文中並沒有「五條」、「七條」、「九條」這樣的名稱，只稱「安陀會」乃至「僧伽梨」；是後人稱之為七條衣、九條衣的。若就整體的通則而言，也有不割截條幅的縵僧伽梨（縵大衣）；這都是隨各人力量所能籌辦備辦，依照不同的用途而區分為三種衣服。並非沒有大體上的主旨與體制。

【191-0006】01_行事鈔/09a_卷下之一#23
【原文】三明功用者。《大悲經》云：但使性是沙門，污沙門行，形是沙門，披著袈裟者，於彌勒佛乃至樓至佛所，得入涅槃，無有遺餘。《悲華經》云：如來於寶藏佛所發願，成佛時我袈裟有五功德：一入我法中，或犯重邪見等四眾，於一念中敬心尊重，必於三乘受記。二者天龍人鬼，若能恭敬此人袈裟少分，即得三乘不退。三者若有鬼神，諸人得袈裟乃至四寸，飲食充足。四者若眾生共相違反，念袈裟力，尋生悲心。五者若在兵陣，持此少分恭敬尊重，常得勝他。若我袈裟無此五力，則欺十方諸佛。《僧祇》云：僧尼有戒德，俗人索破袈裟段，欲禳災者，得與小者等。
【譯文】第三、說明功德效用。《大悲經》說：只要本性是沙門，即使玷污了沙門梵行，只要形相上仍是沙門，披著袈裟者，在彌勒佛乃至樓至佛出世之處，都能得以證入涅槃，無一人遺漏。《悲華經》說：如來在寶藏佛前發願，成佛時我的袈裟具有五種功德：第一、進入我的佛法中，或者犯了重戒、墮入邪見等的出家在家四眾弟子，若能於一念之中生起敬重心，必定能在三乘道中獲得授記。第二、天神、龍族、人類、鬼神，若能恭敬此人袈裟的一小部分，就能於三乘佛法中得不退轉。第三、若有鬼神及各類人等，能得到袈裟哪怕只有四寸大小，飲食便能豐足。第四、若眾生彼此違逆爭鬥，憶念袈裟的神力，隨即能生起慈悲心。第五、若在戰陣兵戈之中，手持這一小塊袈裟恭敬尊重，便常能戰勝他人。如果我的袈裟沒有這五種功德神力，我便是在欺誑十方諸佛。《摩訶僧祇律》說：僧尼若具有戒德，俗人求索破裂的袈裟布片以求消災禳禍，可以把小塊的布片給他等等。
