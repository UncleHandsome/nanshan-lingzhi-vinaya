# 校閱材料　第862檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【862-0001】02_戒疏/21a_卷四下之三#140
【原文】【疏】言「毗尼」者，此云「律」也。「律」者，分也，筆也。謂須商度，據量有在，若律呂之分氣故也。又如世法據刑約制，道法亦爾，依根附教，各有差降，不可乖越，故曰「法」也。「律」字安「聿」，「聿」者筆也。必審教驗情，在筆投斷，如斯面對，故曰「毗尼」。如初解也。
【譯文】【疏文】所謂「毗尼（Vinaya）」，在漢地翻譯為「律」。「律」有劃分（分）以及筆錄定斷（筆）的意涵。意思是必須經過審度商量，掌握客觀的分寸尺度，就如同音樂律呂劃分陰陽二十四節氣一樣不差。又如同世俗法律必須依據刑名條文來規範約束，出世間的佛法也是如此，依據當事人的見聞疑三根、附順於律藏聖教，各有其等級輕重差異，不可乖違踰越，所以稱為「法」。「律」字旁邊安立了「聿」字，「聿」本來就是筆的意思。必定要詳審聖教法意、查核內心深淺，掌握在執筆下筆的定斷之中，像這樣當面相對來判定是非，所以稱為「毗尼」。就如同最初所作的解釋。

【862-0002】02_戒疏/21a_卷四下之三#141
【原文】【記】次科。翻名示義。「謂」下，別釋。初釋分義。一年十二月，奇月為「律」，偶月為「呂」。「律」為陽，「呂」為陰。一律一呂，各有二氣，六律六呂，共二十四節氣。故今喻「據量」，判斷無濫。「又」下，次釋筆義。初約俗律釋，上卷云「筆即法家之象」是也。「據刑」，謂刑名；「約制」，即條制。「依根」，即三根；「附教」，即律文。「律」下，正合筆義。從人從聿，象人執筆，《說文》曰「聿，所以書也。楚謂之『聿』，吳謂之『不律』，燕謂之『弗』，秦謂之『筆』」。「審教」，謂詳法制重輕；「驗情」，謂察用意深淺。俗中判斷，落筆定刑，況今律乘，準判即決。舉彼類此，故曰「如斯」。言「面對」者，即「現前」義。「如初解」者，指上三、五現前。
【譯文】【記文】次一科。翻出名目以顯示義理。「謂」字以下，是分別解釋。首先解釋「分」的意義。一年有十二個月，單數月為「律」，雙數月為「呂」。「律」屬陽，「呂」屬陰。一「律」一「呂」各有二氣，六律六呂合起來共二十四節氣。所以現在用它來比喻「據量」（依準度量），判斷而沒有氾濫差錯。「又」字以下，其次解釋「筆」的意義。首先就世俗的律法來解釋，上卷說「筆即法家之象」（筆是法家的象徵），就是這個意思。「據刑」，是說刑名；「約制」，就是條制。「依根」，就是三根；「附教」，就是律文。「律」字以下，正式會合「筆」的意義。字形從「人」從「聿」，象徵人執筆，《說文》說：「聿，所以書也（聿，是書寫的工具）。楚地稱它為『聿』，吳地稱為『不律』，燕地稱為『弗』，秦地稱為『筆』。」「審教」，是說詳細審定法制的輕重；「驗情」，是說考察（犯者）用意的深淺。世俗中判斷案件，落筆就定下刑罰，何況現在所講的律乘，依準判斷就立即裁決。舉世俗的事來類比此事，所以說「如斯」（如此）。所說的「面對」，就是「現前」的意思。說「如初解」，是指上面所說的三種現前與五種現前。

【862-0005】02_戒疏/21a_卷四下之三#144
【原文】【註】佛在舍衛國。時，迦留陀夷與六群在河浴，迦留陀夷誤著彼衣而去。六群比丘後謂彼盜，便不現前與滅擯羯磨。迦留陀夷以緣白佛。便訶責已，因制此法。有三種現前，法、毗尼、人也。有五種現前，法、毗尼、人、僧、界也。云何法現前？所持法滅諍者是。云何毗尼現前？所持毗尼滅諍者是。云何人現前？言議往反者是。云何僧現前？應來者來，應與欲者與欲，得訶人不訶者是。云何界現前？唱羯磨作制限者是。此現前法，通一切羯磨。若別人對首、心念，三種現前即得。若四人、五人已上僧法，若作羯磨，必須五法現前。以羯磨所起，必在作法界故，唯除結界自然界中也。
【譯文】【註文】佛陀駐錫於舍衛國。當時迦留陀夷尊者與六群比丘在河中沐浴，迦留陀夷誤穿了對方的衣服離開。六群比丘事後指控他偷盜，隨即便在迦留陀夷不在現場的情況下，私自作羯磨將他驅逐出僧團（滅擯羯磨）。迦留陀夷將事情始末稟告佛陀。佛陀呵責了六群比丘之後，因而制定了這項法則。有所謂的三種現前，即法現前、戒律現前（毗尼現前）、當事人現前。有所謂的五種現前，即法、戒律（毗尼）、當事人、僧團、結界全體現前。什麼叫做「法現前」？是指依法所持誦用以平息諍論的教理羯磨文句。什麼叫做「毗尼現前」？是指依所受持的毗尼（戒律教法）來平息諍論（準照律制裁斷爭端）。什麼叫做「人現前」？是指當事雙方當面進行問答辯駁。什麼叫做「僧現前」？是指該出席的僧眾都已出席，應當委託同意權（與欲）的皆已委託，有權提出異議者沒有提出異議。什麼叫做「界現前」？是指依規定宣告唱誦界限圍繞的作法空間。這種現前法則，通融貫穿於一切僧團羯磨法事。如果是別人之對首法或是獨自心念法，只要具備三種現前就可以成就。若是四人、五人以上共同舉行的僧團法事，如果要作羯磨，就必須五種法則全部現前。因為羯磨所發起推展的範圍，必然是在法定的結界之內，唯獨在結界當下所依託的自然界中可以例外。

【862-0006】02_戒疏/21a_卷四下之三#145
【原文】【疏】就解分二：初緣，後相。就初，由在屏處作滅法，不召犯人問「何心取」，法是人非，何名實覈？所以制約，須面對論。「三」、「五」兩相，義如前解。又言「此現前法，通諸羯磨」，以類傍通，文相可解。
【譯文】【疏文】關於這段注文的解釋分為兩部分：先說明制戒緣起，後說明法相內涵。在第一部分，由於六群比丘是在私下隱蔽之處逕自作成驅逐重罰的羯磨，沒有傳召涉嫌的比丘親口查問「當時究竟是抱持什麼心思拿走衣物」，作法雖看似有條文，但程序與被懲罰者都不合律制，這怎麼稱得上是查明實情？所以佛陀特別規範制約，必須當面對質公決。「三種」與「五種」的具體法相，義理如同前面所解釋的那樣。文中又說「這種現前之法，貫通所有羯磨」，這是以相通的原則擴大類推，文義相當清楚易懂。

【862-0007】02_戒疏/21a_卷四下之三#146
【原文】【記】釋注中。初二句分文。從初至「羯磨」是敘緣；「迦留白佛」下，即列相。「就」下，別釋為二。初釋緣。「滅法」，即是滅擯。心為業本，故必「問心」。「所」下，釋相，指前可解。「又」下，點後文。本制滅諍，兼該一切眾別羯磨，故云「傍通」等。
【譯文】【記文】在解釋隨文注文的段落中。前面兩句劃分科判。從開頭到「滅擯羯磨」是敘述緣起；自「迦留陀夷以緣白佛」以下，即是列舉具體法相。自「就解」以下，分別解說為兩部分。首先解釋緣起。「滅法」就是指滅擯羯磨。起心動念是一切善惡業的根本，所以必須當面「審問動機」。自「所以制約」以下是解釋法相，指涉前文內容，容易明瞭。自「又言」以下，點出注文末段的意涵。本戒原先是為了平息爭議而制定，但實際上它兼攝涵蓋了全體僧眾或個別比丘的一切羯磨法事，所以說「擴大類推」等語。

【862-0008】02_戒疏/21a_卷四下之三#147
【原文】【律】應與憶念毗尼，當與憶念毗尼。
【譯文】【律文】應當給予「因憶念無犯而裁決（憶念毗尼）」的，就應當給予「因憶念無犯而裁決」。
