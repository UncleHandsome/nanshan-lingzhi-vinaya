# 校閱材料　第1570檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？

【1570-0001】03_業疏/01b_卷一之一#38
【原文】次謂中事，中猶通也，法雖眾多，微通大小。謂對首羯磨必假境緣，若無所對，分通心念；眾法治懺，是所常行，必界僧少，兼通對首。故此一法，分通大小
【譯文】第二種稱為「中事」，「中」有相通之意，教法雖然繁多，卻稍通於大事與小事之間。這意思是說，對首羯磨必定要假借外在對境的人緣，如果沒有所對的同修，在特定情況下便可通容改作心念法；僧眾法中的治罰懺悔等，是僧團中常行之事，如果該結界之內僧人太少不足成眾，也可以兼通改用對首法。因此這一中法，在不同分位下可變通銜接大、小二法。

【1570-0002】03_業疏/01b_卷一之一#39
【原文】中事中，初訓字；「法」下釋義，初通示；「謂」下別釋為二：初釋通小，「眾」下次釋通大。「眾法治懺」，且據說恣、捨墮等法，故下結示
【譯文】在「中事」的解說中，最初是訓釋字詞；自「法」字以下解釋義理，先是普遍指示；自「謂」字以下分別解釋為兩個層面：首先解釋如何通向小法，自「眾」字以下接著解釋如何通向大法。所謂「眾法治懺」，是暫且依據說戒、自恣、懺除捨墮等法而言，所以在此之下作了總結指示。

【1570-0003】03_業疏/01b_卷一之一#40
【原文】後謂大事，如住持眾德、匡攝僧儀、息邪靜謗、悔除極法，自非僧位，莫能辨之，故曰大事也
【譯文】後者所說的大事，例如住持僧眾的德行、匡正統攝僧眾的威儀、止息邪行並平息毀謗、懺悔消除極重之罪等，若不是以僧伽之位，無人能夠成辦，所以稱為大事。

【譯文】在大事的第一科中，「住持眾德」是指受戒、結界、說戒、自恣；「匡攝僧儀」是指各類治罰的羯磨；「息邪靜謗」是指各類諫勸的羯磨；「悔除極法」是指懺悔波羅夷、僧殘等極重之罪。

【1570-0005】03_業疏/01b_卷一之一#42
【原文】然僧得自在，通塞適緣，上得兼下，下非僭上。故說戒自恣，事通僧別，乃至心念亦通辨之。雖作法或乖，而表淨是一，良以戒法相攝，自他雙被故也。餘有不通者，或是事重，或是被機，情事相投，義須堪濟，故限當位，不通彼此
【譯文】然而僧眾行事能夠自在無礙，其通達與遮塞皆契合因緣，上位能夠兼辦下位之事，下位則不可僭越上位之事。因此說戒與自恣，其事體通於僧眾與個人，乃至心念法也通於成辦。雖然作法的儀軌或有不同，但表顯清淨的實質是相同的，這確實是因為戒律之法互相攝受、自他雙方皆蒙覆被的緣故。其餘有所不通的，有的是因為事體重大，有的是因為所被之機，必須人情與事體互相契合，義理上必須具備承擔濟拔的能力，所以限制在相應的位次，不能彼此互通。

【1570-0006】03_業疏/01b_卷一之一#43
【原文】次文初總標，處判成否，一出僧命，故得自在，此即律本開解戒堂之語，適猶稱也。「上」下別釋又二：初釋通者，大事通對、念，中事通心念，故上得兼下；小、中二事不通上法，故下不僭上。「下」舉說恣顯示兼通，「作法乖」者，辭句異故；「表淨一」者，所為同故；「良以」等者，示通意故，且約說恣，餘見後文。「餘」下次簡塞者，「事重」如受、懺、治、諫等；「被機」如諸差、結等；「情事」等者，示不通意
【譯文】第二段文中，起初是總標，裁處判定法事的成辦與否，完全出自僧團的敕命，所以能夠自在，這就是律本中開許解結戒堂之處的用語，「適」就是稱合的意思。自「上」以下是分別解釋，又分為兩部分：第一是解釋「通」，大事通於對首、心念，中事通於心念，所以上位能夠兼辦下位；小事與中事不能通於上位之法，所以下位不可僭越上位。自「下」以下舉出說戒與自恣來顯示兼通，「作法乖」是指言辭章句有所差異；「表淨一」是指所要達成的目的相同；「良以」等句是顯示通達之意，此處暫且就說戒與自恣而言，其餘見於後文。自「餘」以下則是甄別遮塞的情況，「事重」如受戒、懺罪、治罰、諫勸等；「被機」如各類差派、結界等；「情事」等句則是顯示不通互用的意義。
