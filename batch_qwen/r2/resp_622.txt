以下按「必改／建議」分級逐條檢視。整體說來譯筆通順，術語處理也大致到位，但有幾處**增字解經**與**術語誤判**會影響義理，宜優先修正。

---

## 一、優先必改（涉及義理或原文無據）

### 1. 【0011】「無作」誤作「無作戒體」★最要緊
> 原譯：藉由他人的身業為相異的外緣**發起無作戒體之虧損**

- 此處「無作」是**犯戒的無作業（無作罪）**，不是受戒所得的「無作戒體」；「虧損」更是譯者自行添加。南山業論中，教人成犯是：能教者**口業**為作，藉**所教者身業**為異緣，事成時能教者發**無作罪**，故下句才說「三性之中，任運成犯」（無作罪通善惡無記，任運續起）。
- 建議：「藉他人（受教者）的身業作為異緣，發起（我的）無作業罪，成就我口業教令之犯。」

### 2. 【0001】「同」下 → 憑空補成「同住」★
原文只引一個「同」字（承上疏文「同犯」之語），譯文補「住」字，變成「同住」，所引文句與釋義都走樣。建議照錄「從『同』以下」，必要时括注（同犯）。

### 3. 【0002】「應犯有七」譯為「應當犯戒的有七條」★
語氣變成「應該去犯」。「應犯」是「（就現前僧同犯而言）相應可構成犯戒的」。
建議：「就現前僧（同犯）而言，可構成同犯的有七條。」
另，「綿衣」宜註明即**蠶綿臥具（敷具）戒**，與下文「五敷」相呼應，否則讀者會誤以為是衣服。

### 4. 【0004】【0005】「增三」的處理★
- 0004 譯作「**增三律**」：「增三」是本律中的一段（增一法中之增三），並非別有一部律，宜作「〈增三〉之文」。
- 0005 括注「**增法犍度增三**」：《四分律》二十犍度中並無此名，此語疑為譯者臆加，**請核查出處**（一般作〈毗尼增一〉中之增三），或直接刪去括注。
- 0005「故云『**姑且應當**』」不成話，且丟了賓語。「且應」是「姑且（對）應於增三中『若僧』之位」。建議：「所以才說『且應（增三）』。」0004 同步改為「姑且對應於〈增三〉中『若僧』的情況」。

### 5. 【0005】【0016】【0017】律文誤稱「經文」★
「文云」「如前所引」「引證」所指皆《四分律》文，白話一律作「經文」「經證」不妥，應改「**律文**」「**律證**」。

### 6. 【0004】「若不同作，為作不犯」加料過多★
> 原譯：如果不是**全體**共同去作，縱使有人去作了，其餘**不知者**亦不犯戒

「全體」「不知者」原文皆無；「不知」只是下文舉例中的情節，不能寫進判準（判準是「是否同作」，不是「知不知情」）。
建議：「若不是共同去作，即使有人作了，其餘的人也不同犯。」
另「在寺院留守的人」→「留在住處（未同行）的人」，「寺院」亦是添加。

### 7. 【0011】「使人亦犯」補為「也犯**重罪**」★
此處「重」是相對於吉羅的**本罪（尼薩耆波逸提／捨墮）**，逕譯「重罪」極易與四重（波羅夷）混淆。0012「成重」亦然。
建議：「指使他人也犯（本罪捨墮）」；「次科，成重（成本罪）」並加註說明。

## 二、語意偏差（建議修正）

| 條號 | 問題 | 建議 |
|---|---|---|
| 0001 | 「長物**同分**」譯「共同分取」——同分是「共同有分／共有」，非分配取用 | 「長物可以共有（同有其分）」 |
| 0001 | 「共使」譯「共同使役」過於空泛 | 「共同指使（尼浣衣）」，與「共奪（衣）」對舉 |
| 0001 | 「受持無共」縮為「受持之**衣**」 | 受持物含衣、缽，宜作「受持之物」 |
| 0006 / 0007 | 「諸」字前後不一致：0006 把「例諸」的諸當成「其餘」，0007 又依記文說它是語辭 | 0006 改「可以此為例，類推其餘」；0007「諸」為語助詞（無實義），不宜逕稱「語尾助詞」 |
| 0007 | 「三位犯」譯「三種犯戒**位階**」——三位是類別分位，非高低階級 | 「僧、眾多、一人三種分位的犯相」 |
| 0007 | 「約心有無」加「**完全**取決於」 | 刪「完全」，作「依当初有心、無心而判」 |
| 0008 | 「教人多少」加「**輕重**」——門名只問戒數多寡 | 「第三門，教人（代作）成犯的戒數多少」 |
| 0010 | 「吉羅犯通三十」直譯易被讀成「三十條都是吉羅罪」 | 「（教他不為己而得）吉羅的情形，通於三十條戒」 |
| 0011 | 「浣**故**衣」漏「故」 | 「浣洗舊衣（故衣）」 |
| 0011 | 「讚織」譯「讚美織師」——所讚是織作（勸令好織而增價） | 「讚歎（勸勉）織師令好織增價」 |
| 0011 | 「乞縷驅織」的「驅」譯「逼迫」太重 | 「自乞縷線，驅使（非親）織師織衣」 |
| 0011 | 「五敷」「受寶」未展開 | 五敷宜列出：蠶綿、黑毛、白毛、減六年臥具、不揲坐具；受寶即畜金銀寶戒 |
| 0012 | 「本、異合論」的「異」包含《多論》（論非律） | 「本律與他部律論合併計算」 |
| 0013 | 「未必稱心」譯成「即使……也未必稱心遂意」，變成讓步句 | 「教人為自己去作，未必能稱合本意（故不成本罪），只得小罪（突吉羅）」 |
| 0016 | 「此物現在數用」的「現在」是「現前存在（未捨）」，譯「在當下」偏虛 | 「這些物品現前存在，屢次作（用），便重複結犯」 |
| 0017 | 「餘三類通」譯「其餘三種」易與「三事」混淆 | 明作「其餘**三戒**（擔毛、擘毛、雨衣）依此類通」 |

## 三、白話語感（可潤）

1. **0003**「在次論現前僧的一節中」生硬 → 「其次，明現前僧（同犯）中，最初這七戒……」。
2. **0006**「佛陀就不制令犯戒」 → 「佛便不制其犯（不結罪）」。
3. **0006**「則不欽後說」譯「不能顯出後人解釋的可貴」，主客移位；「欽」是敬重 → 「就不能令人敬重後出的新說」。
4. **0016**「打捶」宜作「捶打（打衣）」。
5. **「教唆」一詞**（0008、0009、0011、0013）帶刑事貶義，律文「教人／使人」只是指使他人代作，建議統一作「**教人（指使他人）**」，較合律疏語境。
6. **0007**「第二位法師」：此為古師異說中的第二家律師，作「**第二家（古師）之說**」更貼切。

## 四、需查證的兩處

1. **【0007】「受持，如上五戒」**——譯文照字面作「就像上述的五條戒」雖安全，但讀者極易與 0001 的「五長」混為一談（五長是長物，非受持）。建議回查前文所指究竟是哪五戒，並加註區分，否則此句在義理上會與「受持無共／長物同分」打架。
2. **【0005】「增法犍度」**——如前所述，出處名稱待覈。

## 五、修訂示例（挑兩則最關鍵者）

**【0001】**
> 其次七戒，文分兩段：先是總體提示；從「同」字以下，分別解釋。先明五種長物，其同犯、別犯之義容易理解。所謂「五長」，即十日長衣、月望衣、急施衣，以及長缽、七日藥。後明奪衣、浣衣二戒。受持之物不能共有（故無同犯）；長物可以共有，若共同指使（尼浣）、共同奪取，便有同犯。

**【0011】**
> 在「為己」的情況中，有十三戒：教他人為自己而作，事成之時，藉彼（受教者）身業為異緣，發起無作業罪，成就我口業（教令）之犯；此無作罪於善、惡、無記三性心中，任運成犯。本律有「五敷」（蠶綿、黑毛、白毛、減六年臥具、不揲坐具）、奪衣、受寶共七戒；《僧祇》有使人取尼衣、浣故衣、擘毛、過限索衣、乞縷驅織五戒；《薩婆多論》說：「讚織（勸織師增價）一戒，指使他人也犯本罪。」

---

**總結**：全篇最需處理的是 ①「無作」誤作戒體、②「同」下補字、③「增三」與「經文」的文獻稱名、④「重罪」與四重混淆、⑤「應犯／且應」的語氣與賓語殘缺。其餘多屬增字與潤飾，改後即可達到可讀又不失義理的水準。
