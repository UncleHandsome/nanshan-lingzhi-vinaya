以下按「義理錯譯 → 詞語訓解 → 增譯與體例 → 建議改譯」四層來看。整體譯筆流暢、律學名相（棄＝波羅夷、偷蘭＝偷蘭遮、無盡財、二種常住／二種現前）掌握得不錯，主要問題集中在**僧物那一段的「時／非時」判準**，以及最後一句的語意斷裂。

---

## 一、義理層面：必須修正的地方

### 1.（最嚴重）「鳴稚同時，即預食分；若惡戒及時，有德非時，非法而用，並結偷蘭」

**譯文**：「凡敲擊犍稚之時，即得參與均分食用；若戒行惡劣者趕赴其時，或有德之人非時而來，不如法而取用者，都結偷蘭遮。」

問題有二：

- **漏掉「同時」**：原文是「鳴稚（而）同時（至）者，即預食分」，即以「打犍稚時是否及時趕到（在界內）」為分食資格，不是「凡打犍稚時就可以分食」。
- **把對比句譯成犯罪主體**：「惡戒及時／有德非時」是《資持記》所謂「簡濫」的**互文對舉**——分食標準只看「時／非時」，**不問持戒破戒**：破戒者及時到，仍應給分；有德者非時到，也不得分。譯文寫成「惡戒者趕上時間、有德者非時而來……都結偷蘭」，讀者會誤以為這兩種人本身犯罪，正好把原文要立的原則譯反／譯失了。「非法而用」才是結罪處，指的是**違此制而分與或受用者（主事分食者與受用者）**。

**建議改譯**：
> 「十方常住物（如每日供僧的常住食），打犍稚集眾時，凡及時（同時刻在界內）到的僧人就有分食之份。因此，即使是破戒之人，只要及時趕到，也應給他食分；即使是有德之人，若非時才到，也不得分食。若違此制而非法分用，都結偷蘭遮罪。」

### 2. 末句「就輕重二物，斷割非文；違者，雙結二罪」

**譯文**：「就輕物與重物而言，若處分判定違背律文；違背者，雙雙結犯兩種罪過。」

- 句子語法斷裂（「若……；違背者……」重複且無主句），讀者不知所云。
- 「輕重二物」未交代：僧物中**重物**（寺舍、床褥、田園、鐵木器等，屬四方僧，不可分）與**輕物**（可分之現前物）。「斷割」＝裁斷分配。
- 「雙結二罪」是哪二罪，宜查《資持記》後加注（一般理解為非法處分之違制罪＋損僧物之盜罪），不宜含糊譯作「兩種罪過」。

**建議改譯**：
> 「又就重物、輕物兩類僧物而言，若裁斷分配不合律文（例如把不可分的重物分了），違者同時結犯兩罪〔按：二罪所指宜依《資持記》加注〕。」

### 3.「二種互用，通和得不，準上可知」——漏譯「和」

譯文只作「是否可通融互用」，把「和（僧和合／羯磨）」丟了。原文是問：這二種常住物可否互用、**能否經僧眾和合而通融**。宜補：「能否互用、可否由僧眾羯磨和合而通融，比照上文可知。」

同理，法物段「餘三**得不**」是「可否（互用迴改）」，譯作「是否可行」語意太泛，宜作「其餘三種能否互用改轉」。

### 4.「一切天人供養」→「一切天人所當供養」

原文是說這些佛園坐具「（乃是）一切天人所供養之物」，屬**敘述其體性**（故不得輒用）；譯文加「所當」變成**規範語氣**（天人應該去供養），語意偏移。建議：「這是一切天人所供養之物，不得隨便取用，因為都同於佛塔的緣故。」

### 5.「不得賣佛身上繒，與佛作衣」

譯文「不得變賣佛像身上的綵綢，用來為佛重新作衣」易被讀成兩件事（賣繒／作衣）。原文重點是：**即使目的是為佛作新衣，也不得變賣佛受用物**（故說「不得互易」）。建議加「即使……也不得」的句式。

### 6.「準此，迴改作故，不轉變本質」＋《大論》例

「雖可改作**他用**」宜作「改作**其他佛事之用**」（供養佛物只能迴作佛事，不能變成非佛事用途）。另《大論》「一以不好故壞，得福」宜補出動機：「一人因畫得不好、想改畫更好的而毀壞它，得福；一人以惡心毀壞，便得罪」——這樣才接得上「不轉變本質（存心與物體歸屬不變）」的判準。

### 7.「僧物，文中例同」

上文引的是《十誦》《僧祇》**律**，譯作「經文」不當，應作「律文中依例相同」。

## 二、詞語訓解可議處

| 原文 | 譯文 | 檢討 |
|---|---|---|
| 匱簏 | 書櫃、書囊 | 「簏」是竹編箱籠，非「囊」。宜「櫃子、竹箱」 |
| 巾帖 | 包巾、標籤 | 「帖」在此多解作經帙／書套之類，「標籤」是猜測，宜改並加注存疑 |
| 曾經置設 | 曾經安置陳設過 | 宜「曾經用來安置（盛放）經典的」，重點在「已作法受用」 |
| 治塔人 | 修繕佛塔的人 | 過窄。「治」含清掃、維護、看守，宜「整治維護佛塔的人」 |
| 佛旛 | 幡蓋 | 原文只有「旛（幡）」，「蓋」是增字 |
| 分明唱記 | 分明唱名登記 | 「唱」是宣唱、「記」是記錄，非「唱名」。宜「明白宣唱、記錄（借貸事項）」 |
| 付囑後人 | 付託囑咐後人 | 「後人」易誤讀為後代，宜「後任（接任的知事人）」 |
| 別人得貸塔僧物 | 個別特定之人 | 宜點出對比：「個人（相對於僧團整體）」 |
| 若死，計直輸還塔僧 | 折算其價值如數償還 | 主語不明，宜補「（從其遺物中）估價償還塔、僧」 |
| 牛畜 | 牛馬牲畜 | 「馬」為增字，可作「牛等牲畜」 |
| 畜寶戒 | 蓄積寶物戒 | 宜注明「（三十捨墮中的）畜寶戒，即蓄積金銀錢寶之戒」 |
| 無盡財（公積基金） | 尚可 | 建議補「本金不動、取息供養」，才與第二段「出息取利，還著無盡財」相呼應 |
| 比丘客作佛像書經，得物不得取 | 所得財物不得私取 | 此條列在「施屬佛物」下，宜補理由：「（所得之物應歸屬佛，故）不得自取」，並可加「客作＝受雇做工」小注 |

## 三、增譯與體例

1. **兩個科文標題完全沒譯**：
 - 「四隨相物中自互」建議：「第四、隨各類三寶物之相，說明**同類物內部彼此互用（迴轉）** 的問題。」——這句是全段綱領（有別於前段三寶之間互用），不譯讀者無法掌握為何佛／法／僧各分四種、能不能互換。
 - 「三出貸三寶物」建議：「第三、關於出借（放貸）三寶物。」
2. **未標示的增譯**：「不可分割」（初之常住）、「痊癒後」（病人貸三寶物）、「便得**大**罪」（原文僅「得罪」）、「幡**蓋**」、「牛**馬**」。其中「不可分割」於義無誤，但《善生經》條的「痊癒後」純屬推測，建議刪除或加括號／注標示為補譯。
3. **書名不統一**：同一段內《五百問事》→《五百問經》；建議首見作「《五百問事》（《目連問戒律中五百輕重事經》）」，後統一簡稱。
4. **引號內含句號**：「第一是「佛受用物。」」應作「第一是「佛受用物」。」（四處）。
5. 「與律不同，疑是俗中二眾，文似出家五眾」譯得不錯，可再加一句點明這是道宣**存疑未決**（故不敢據《善生》十倍償之說通用於出家眾），避免讀者以為已有定論。

## 四、關鍵段落建議改譯（可直接替換）

**（僧物段）**
> 第三、說明僧物。若屬二種常住物（常住常住、十方常住），處所既已限定，就不可移轉他處，如上文所說；若要通融濟助其他寺院，須經僧眾羯磨和合同意方可。第一種「常住常住」，僧眾只能受用（不得分割買賣）。「十方常住」，打犍稚集眾時，凡及時同時到的僧人即有分食之份；所以即使破戒之人，及時趕到也應給分；即使有德之人，非時才到也不得分食。若違此制而非法分用，都結偷蘭遮罪。這二種常住物能否互用、可否由僧眾和合而通融，比照上文可知。常住的僕役、牲畜絕不可買賣，依經文其罪極重，但諸部律中並無明文；所以《僧祇律》說：有人以婢女布施僧眾，僧眾都不應接受——由此可以類推而知。若論二種現前物（現前現前、十方現前），互用結罪的情形同上。又就重物、輕物二類僧物而言，若裁斷分配不合律文，違者同時結犯兩罪〔二罪所指宜依《資持記》加注〕。

**（出貸段開頭）**
> 第三、關於出借（放貸）三寶物。《僧祇律》說：塔物與僧物互相借貸，須明白立下借券記錄，寫明何時貸、何時還；若知事人交接，應在僧眾中宣讀疏記，明白宣唱登記，交付囑咐後任者；違者結罪。……僧物（放貸），律文中依例相同。三者所屬不得混雜。

---

**小結**：兩段中真正會誤導讀者的是「惡戒及時／有德非時」一處（原則被譯反），其次是末句「斷割非文、雙結二罪」語意未成，再來是「通和」漏「和」、「唱記」誤作「唱名」、「文中」誤作「經文」。其餘多屬增字、譯名與體例問題，修訂後即可用。
