# 校閱材料　第1700檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1700-0001】03_業疏/10a_卷二之四#103
【原文】多論云：龍受三歸為優婆塞。又云：龍畜生攝，以業障故，無所曉知，無受戒法。雖經中說受八齋法，但得善心功德，不得齋也。四分龍受三歸及賈人等，皆翻邪歸，非得戒也。成實云：餘道眾生得戒律儀，經說諸龍亦受一日戒故。善見中諸龍及神得三歸五戒也
【譯文】《薩婆多論》說：龍領受三歸而成為優婆塞。論中又說：龍歸屬於畜生道，由於業障深重、毫無所知的緣故，沒有受戒之法。雖然經中說龍受八關齋法，但只是獲得善心功德，並未真正得到齋戒戒體。《四分律》中龍受三歸以及商人等受三歸，都屬於翻邪三歸，並非得到戒體。《成實論》說：其餘道的眾生能夠獲得戒律儀，因為佛經中說諸龍也曾受持一日之戒。《善見論》中則認為諸龍以及鬼神，都能夠獲得三歸與五戒。

【1700-0002】03_業疏/10a_卷二之四#104
【原文】次科，《多論》初明唯許受歸；「又下次」明不聽受戒。無所曉者，畜類多愚，不堪持奉。準下得歸，亦取知解。「雖經等者」，即《善生》中龍受八戒，論家防難，以意釋之。齋即八戒，然是《成論》所據，即如下引。《四分》佛初成道，賈客獻蜜，初受三歸，次為龍受，今正明龍畜，因引之耳。下引二論，歸、戒皆開。《善見》神者，即是鬼趣
【譯文】就下一科而言，《薩婆多論》起初說明只准許領受三歸；自「又下」其次說明不聽許受戒。所謂「無所曉」，是因畜生類大多愚鈍，不堪承受持守。依照下文能夠得成三歸來看，也是取其具有知解能力的緣故。所謂「雖經等者」，即指《優婆塞戒經》（善生經）中記載龍受八戒，論師為了防禦詰難，因而依自意加以解釋。「齋」就是指八戒，但這是《成實論》所依據的說法，正如隨後所引。《四分律》中佛陀剛成道時，商客奉獻蜜糖，最初受了三歸，隨後又為龍傳授三歸，如今正要說明龍等畜生道眾生，因而順帶引證。下文引用兩部論典，三歸與戒法全都開許。《善見論》所說的「神」，指的就是鬼趣。

【1700-0003】03_業疏/10a_卷二之四#105
【原文】義準多論據無知者，人猶不得，何況鬼畜？如餘得者，謂有知解。律中制罪，尚結偷蘭，以能變化、知解人語，可以類也
【譯文】在義理上準照《薩婆多論》所論，是依據毫無知解的眾生而言，若是人道無知尚且不能得受，何況是鬼神與畜生呢？如果像其餘論典說能得受的，是指具有知解能力者。律典中判定罪名，對這類眾生尚且結為偷蘭遮罪，因為牠們能變化形相、懂得人類語言，由此可以類推知曉。

【1700-0004】03_業疏/10a_卷二之四#106
【原文】三中義準總判諸文。初判《多論》，「如下次」釋《成》、《見》二論。律中殺畜提，盜、妄竝吉，若有知解，通結偷蘭。由能奉持，故開得戒
【譯文】在第三部分中，以「義準」總體判定各家文獻。先判定《薩婆多論》的觀點，自「如下」其次解釋《成實論》、《善見論》二論。律制中殺害普通畜生結波逸提罪，對其行盜或妄語都結突吉羅罪；如果該畜生具有知解能力，則一概結偷蘭遮罪。正因為牠們能通曉奉持，所以開許可以得受戒法。

【1700-0005】03_業疏/10a_卷二之四#107
【原文】二、就文中，初標後受
【譯文】第二、就疏文正文中，先是標示名目，後是正式傳授。

【1700-0006】03_業疏/10a_卷二之四#108
【原文】初中受三歸者，但得法被身，為佛弟子，無戒可持。文中多論已下，顯本從魔，歸心正覺。具列三寶體者，以妄作者多故，偏列云知真歸也。又引善見者，釋成作法不易，依緣而受亦不難也
【譯文】在起初「受三歸」中，只是獲得正法披加於身，成為佛陀的弟子，並無特定的戒條需要持守。文中自引用《薩婆多論》以下，是彰顯眾生原本盲從惡魔，如今歸心於正覺（佛寶）。具足列出三寶體性，是因為妄加造作者繁多的緣故，特意列出是為了讓人知道真正的所歸之境。又引用《善見論》文，是為了解釋作法並不草率容易，但若能依憑具足的因緣來領受，也並非難事。

【1700-0007】03_業疏/10a_卷二之四#109
【原文】次解中標文三段：初示立法分齊。次釋《多論》，「歸正覺」者，對上從魔，且明佛寶，正覺即華言也；妄作多者，人師授法，不知體相，故三寶多種，唯明理體，故云偏列，簡住持、化相，故曰真歸，如上義門真偈中說。又下三釋《善見》，難易成否在於明昧，故須師學始可授人
【譯文】在隨後的解釋中標示疏文有三段：第一、明示立法的界限分齊。第二、解釋《薩婆多論》，「歸正覺」是相對於前面的盲從魔王，暫且用以闡明佛寶，「正覺」就是梵語佛陀的漢譯；「妄作者多」，是指各處的傳戒師在傳授教法時，不知曉三寶的體相，所以三寶雖然有多種，此處只闡明理體三寶，所以說是特意列出，甄別淘汰了住持三寶與化相三寶，所以稱為真正的歸依，如同上述義門真偽偈語中所說。自「又下」第三、解釋《善見論》，其難易與成否全在於內心的明了或愚昧，所以必須從師修學通達，才可以為人傳授。

【1700-0008】03_業疏/10a_卷二之四#110
【原文】授法文列得法屬己者，明作法之時，知三說已，無作便生，故能所不昧於作業也
【譯文】傳授之法文句中列出「得法屬己」（使正法歸屬於自身）的內容，是說明在作法的時候，明了三番宣說完畢時，無作戒體便即刻生起，因此能授與所授雙方都不昧於所造作的業體。

【1700-0009】03_業疏/10a_卷二之四#111
【原文】次釋授法初科。「三說已」者，此據初念已前，通名為作；「無作便生」，即約次念，徹至盡報也。能授所受知業成處，故不昧也
【譯文】其次解釋傳授之法的第一科。「三說已」，這是依最初一念以前而言，通稱為「作」（表業）；「無作便生」，就是就緊接著的第二念起，一直貫徹延續到壽命窮盡之時。能授師與所受者都能明了業體成辦之處，所以稱為不昧。

【1700-0010】03_業疏/10a_卷二之四#112
【原文】後三結者，囑授叮嚀，令持在懷，不濫承奉。故經云：歸依於佛者，真名優婆塞，終不更歸依其餘諸天神
【譯文】其後的三結，是鄭重囑託傳授、再三叮嚀，使其銘記持守在心懷之中，不妄加盲目信奉奉侍。所以經中說：真正歸依於佛陀的人，才是真正的優婆塞，終究不再歸依其餘的諸天鬼神。

【1700-0011】03_業疏/10a_卷二之四#113
【原文】次科，初示結意。「故下」引證。西土外道多事天神，今既向佛，故云「不歸」等
【譯文】下一科中，首先明示三結的用意。自「故」字以下引用證明。印度西土的外道大多事奉奉祀天神，如今既然歸向佛陀，所以說「不再歸依」等語。

【1700-0012】03_業疏/10a_卷二之四#114
【原文】下釋有歸無戒者，為除世疑。受五戒者，但依前誦，止是翻邪，無戒可得。又引母論，的處灼然，不容晦惑，彼我無益也
【譯文】底下解釋「只有三歸而無戒」的情況，是為了破除世人的疑惑。受五戒的人，如果只是依循前面的三歸文誦念，這只算是翻邪三歸，並不能得戒。此外又引《毘尼母論》，其明確的標準昭然若揭，不容昏昧惑亂，否則對傳授者與領受者雙方都毫無益處。

【1700-0013】03_業疏/10a_卷二之四#115
【原文】三中，初釋除疑。有人用此授人五戒，故特決之。「又下次」釋引證。初二句點文，有加無加，用分歸戒，即此誠文是準的之處。灼，明也。下二句誡斥。晦，暗也
【譯文】在第三部分中，首先解釋破除疑惑。有人拿這種三歸儀軌來為人授五戒，所以特別加以裁決判定。自「又引母論」以下，是解釋引文作證。前兩句點明論文，說明是否有附加誓句，以此區分是單純三歸還是受戒，而這段確實的論文正是準確的依據標準。「灼」，是明了的意思。後兩句是告誡斥責。「晦」，是昏暗的意思。

【1700-0014】03_業疏/10a_卷二之四#116

【譯文】第二、說明受五戒之法，在義理上分為五門：第一、戒德高尚殊勝；第二、甄別根器與堪能；第三、作法的時限長短；第四、發得戒體的時節；第五、依循戒相顯明持戒。

【譯文】在第二項說明受五戒所列出的義門中，預先立下這五種義理科判，其論文相貌如下文所配合對應。

【1700-0017】03_業疏/10a_卷二之四#119
【原文】就初標中受五戒法，計是能授，文列所受，故隨列也
【譯文】在最初標題中的「受五戒法」，按理應當屬於能授之法，但文中列出的是所受之法，所以便隨順標列。
