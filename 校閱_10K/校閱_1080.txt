# 校閱材料　第1080檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1080-0001】資持記/06c_中一上#22
【原文】次引《四分》，示佛制意本為聖道。調毒令盡，即是果成。後文，即本律〈說戒犍度〉釋波羅提木叉文。〔〈標宗〉亦引，有言《善生》者，非。〕上句喻顯。根喻生長，面首喻高勝。下二句法合。集眾善者，統萬行也；三昧成者，資禪觀也；具斯二義，故同根首。反顯中，初引論示。下引經證。
【譯文】次引《四分律》的文句，顯示佛陀制戒的最初意趣本來就是為了證得聖道。將心中的煩惱毒素調伏至窮盡無餘，這就是菩提果位的成就。後段引文，就是引自本律〈說戒犍度〉中解釋「波羅提木叉」的文字〔在〈標宗顯勝篇〉中也曾引述，有人認為出自《善生經》，那是錯誤的說法〕。上一句用譬喻來顯發義理。「根」比喻功德的生長延續，「面首」比喻地位的崇高殊勝。下兩句則是法義相應的配合。所謂「積集一切善法」，是統攝了萬種善行修持；所謂「成就種種三昧」，是為了資助長養禪觀修持；因為同時具備了這兩種深遠意義，所以才如同植物的根部與人體的顏面一樣重要。在反面顯發的文句中，首先引述論著開示，隨後引述經文印證。

【1080-0002】資持記/06c_中一上#23
【原文】亦《遺教》文，如〈標宗〉委釋。此明無戒，具諸過失；本基之義，於此彌彰。指略中。彼第一云：為道制戒，本非世福。又云：若原制意，為道方便；三乘學人，必由斯迹；廣文如彼，餘自尋之。次科。下敘功能，而首標大用者；良由有用，方見功能；功由用彰，所以先舉。
【譯文】這也是引自《佛遺教經》的文句，如同在〈標宗顯勝篇〉中所詳細解釋的一樣。這段文字說明如果缺乏戒律，就會具足種種過失與失誤；戒律作為修道根本基礎的道理，在此處顯得格外透徹明瞭。在「指略」的文段中，該疏（《戒本疏》）第一卷說：為了求取聖道而制定戒律，本來就不是為了求取世間的有漏福報。又說：如果探求佛陀最初制戒的意趣，是作為趣向聖道的修行方便；三乘的一切修學之人，必定都要循著這個軌跡前行；詳細的論述如同該書所載，其餘內容請自行查閱尋求。接下來是第二科。下面敘述戒律的功能，而一開頭就標明其「大用」；這是因為唯有具備深廣的作用，才能彰顯其巨大的功能；功德是由作用所彰顯出來的，所以必須最先提出。

【1080-0003】資持記/06c_中一上#24
【原文】略舉中二，初通敘教旨；夫下，別彰戒功。初中，上二句總示三藏，須約通別二意釋之；若就別從強，經論二藏，斷證功高；毘尼一法，住持最勝。從通兼具，經論並列流通住持，毘尼特彰絕縛元始；義雖兩通，文從別意，故云並有等也。明義別者，通示三藏不同也。須略舉者，獨標律藏也。
【譯文】在「略舉大用」中分為兩部分，首先通體敘述三藏教典的大旨；接下「夫下」分別彰顯戒律的特殊功德。在第一部分中，前兩句總體指示出經、律、論三藏，必須依照「共通」與「個別」兩種意旨來解釋；如果就「個別」且從強烈的特色來看，經藏與論藏在斷除煩惱與證得真理上的功德極為崇高；而毘尼戒法在住持佛法傳承上的功能則最為殊勝。如果從「共通」並行具備的角度來看，經藏與論藏同樣具有流通佛法與住持法脈的功用，而毘尼戒法也同樣彰顯出斷絕煩惱繫縛的最初起源；義理雖然在兩方面都能通達，但文句是依據個別特勝的意旨來發揮，所以才說「並有」等等。闡明「義別」，是通盤指出三藏各具不同的宗旨。說明「須略舉」，是單獨特別標舉出律藏。

【1080-0004】資持記/06c_中一上#25
【原文】言略有二：一對餘藏，此不明故；二就律藏，但舉要故。別彰中，前四句別舉；必下，通結，貫上諸句。初句住持義，次句軌物義。九道者，除佛道外，三聖六凡，皆被戒訓故。若準《涅槃》，我亦有師，所謂法也。又《戒經》云：三世諸佛，皆尊敬戒；是知戒法，佛猶師奉；
【譯文】所謂「略」有兩層含義：第一相對於其他兩藏而言，此處並不詳述經論的深義；第二是就律藏自身而言，也僅僅摘錄其最核心的要點。在「個別彰顯戒功」中，前四句是逐條分舉；接下「必下」進行通盤總結，貫穿了上面的所有文句。第一句體現「住持」的義理，第二句體現「規範眾生軌則」的義理。所謂「九道」，是指除去佛道之外的三乘聖者與六道凡夫，全部都要接受戒律教誨規範的緣故。如果依照《涅槃經》的說法，連佛陀自己都說「我亦有師，所謂法也」。此外《戒經》也說：過去、現在、未來三世諸佛，都極其恭敬尊崇戒法；由此可知對於戒法，佛陀尚且如同對待恩師一般遵奉；

【1080-0005】資持記/06c_中一上#26
【原文】今望無非可治，故云九道耳。三發趣義，四本基義。此之四句，攝盡戒功；比於餘藏，優劣見矣。次引證中，初引本律，通證餘三義；後引《善見》，別證初義；又律序偈，明越度生死；戒本偈，明能至佛道。準律序偈，先舉喻云：如人欲度河，用手及浮囊；雖深無沒憂，便能到彼岸。
【譯文】如今考慮到佛陀自身已沒有過非需要由戒來整治，所以才只說教誡九道而已。第三句體現「激發趣向」的義理，第四句體現「根本基石」的義理。這四個句子，徹底涵蓋了戒律的所有殊勝功德；與經論其餘二藏相比，優劣長短便清晰可見了。在接下來的引證中，首先引述本律的文句，普遍印證其餘三種義理；隨後引述《善見律毘婆沙》，特別印證第一種住持義理；此外律序中的偈頌，說明戒律能超越度脫生死輪迴；戒本中的偈頌，則說明戒律能引領行者抵達佛道終點。依照律序的偈頌，首先舉出譬喻說：好比有人想要橫渡大河，必須借助雙手划動以及浮囊的浮力；雖然水流深廣卻沒有沉溺滅頂的憂慮，很快就能順利抵達對岸。

【1080-0006】資持記/06c_中一上#27
【原文】鈔引合法，對喻可知。戒本偈中。初句召行人，次句明本志，第三示行法；正法，即指戒也；下句除惑倒。舉結集中，初文，上二句彰勝。善下，引示。有情之類，色心存亡，依乎壽命；佛法興廢，實在毘尼。此即論家顯示當時結集之意。推釋中，初句總徵。餘下，別釋，先經後律；
【譯文】本鈔引述合喻的法說文句，對照前面的譬喻自然就能明白。在戒本的偈頌中，第一句是在呼喚修行者，第二句是彰顯修行者最初的志向，第三句是揭示具體的修行法則；所謂「正法」，就是直接指稱戒律；最後一句則是破除種種煩惱與顛倒妄念。在「舉出結集因緣」中，前段文句的前兩句用來彰顯其殊勝地位。接下「善下」引述文獻予以明示。一切有情眾生的種類，其色身與心識的存在與滅亡，完全依賴於壽命的長短；而佛法的興盛與衰亡，核心關鍵完全在於毘尼戒法。這就是論師在為我們彰顯揭示佛陀滅度後最初結集律藏的深遠用意。在推究解釋的文句中，第一句是總體提問徵尋原因。接下「餘下」分別深入解釋，先解釋經藏，後解釋律藏；

【1080-0007】資持記/06c_中一上#28
【原文】經中又二，初四句，示詮相虛通。化跡，謂往昔因緣；因果，即三世報應。事隨理者，事別理通，經宗理故；設有事相，融歸於理；故有一多互入，大小相容；況意在忘言，隨立隨遣，故者言無寄也。意下六句，顯幽深難學。猶恐愚者，不體今意，妄生輕重，故此遮之。筌，即取魚之器，喻言教也。
【譯文】在經藏的部分又分為兩層，前四句揭示經典所詮釋的法相屬於通達無礙、依理融通的特質。所謂「化跡」，是指佛陀在往昔因地中的教化因緣；所謂「因果」，就是指過去、現在、未來三世的業報應對。所謂「事相順隨理性」，是因為事相各有差別而真理圓融貫通，經藏是以發顯理性為宗旨；縱使談論到具體事相，最終也都會融攝回歸於真理；所以會有一即是多、多即是一的互融互入，也能有大中容小、小中納大的圓通無礙；更何況佛陀說法用意在於引導眾生超越文字語言的執著，隨立隨破、隨說隨除，所以文字語言根本無從附著定著。接下「意下」六句，顯發經藏教理極其幽玄深奧、難以修學。這是因為擔憂愚鈍之人無法體會這裡的用意，錯誤地產生對經律的輕重偏執，所以特地在此防微杜漸、預加遮護。所謂「筌」，就是捕魚所使用的竹器工具，用來比喻藉以得理的文字言教。
