# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【238-0001】02_戒疏/11c_卷三上之二#45
【原文】【疏】問：「一奪入手，更無重奪，何故《律》文『或藏諸處』者？」
【譯文】【疏文】提問：「一經奪取到手，就沒有重複奪取的道理，為什麼《律》文中卻說『或者藏在各處』呢？」

【238-0002】02_戒疏/11c_卷三上之二#46
【原文】【疏】答：「此謂不面、現前，故有二奪之異。立法須爾，犯事不然。」
【譯文】【疏文】回答：「這是指背著人奪取與當面奪取的區別，因此有兩種奪取的不同犯相。制定法規必須如此嚴謹，但在實際犯戒的事實上並非重複犯罪。」

【238-0003】02_戒疏/11c_卷三上之二#47
【原文】【記】問中。以《律》云「若自奪及教人奪而藏者，犯墮」，又云「若著樹上等處，離處犯墮」。文似重犯，故問釋之。答中，奪有二判：若對面奪，約藏論犯；若不面奪，約離處犯。文中「不面」即後判，「現前」即初判。《律》出犯相，故云「立法須爾」。而非重犯，故云「犯事不然」。
【譯文】【記文】在提問中，是因為《律》文說「如果自己奪取或指使他人奪取而藏匿起來的，犯捨墮」，又說「如果放在樹上等處，一離開原處就犯捨墮」。文意看似重複犯戒，所以提出問難予以解釋。回答中，奪取有兩種判定：若是當面奪取，是以藏匿來論定犯戒；若非當面奪取，則以離開原地來論定犯戒。文中的「不面」就是後一種判定，「現前」就是前一種判定。《律》文只是列出犯戒行相，所以說「立法須爾」；但並非重疊結罪，所以說「犯事不然」。

【238-0004】02_戒疏/11c_卷三上之二#48

【譯文】【疏文】第五門，說明捨財與懺罪的方法。隨順名目行相，雖然有許多種類，但收攝歸納起來，只有三種捨法：

【238-0005】02_戒疏/11c_卷三上之二#49

【譯文】【疏文】第一，說明捨棄財物，這是脫離犯戒的境緣。如果沒有這項財物，罪業也不會生起，所以先說明捨財。

【238-0006】02_戒疏/11c_卷三上之二#50

【譯文】【疏文】第二，說明捨棄犯罪之心，這是脫離犯戒的根本動因。正是由於貪心與傲慢，才導致違背聖人的教誡。

【原文】【記】第五門，標分中。財是生犯之境，故名「罪緣」。心是造業之本，故名「罪因」。罪即入道之障，故云「障業」。

【238-0010】02_戒疏/11c_卷三上之二#54
【原文】【疏】初、不對境捨。如綿衣非法，體是損生，若不斬壞，此貪何竭？二、對境中，道俗分別。如畜、貿二寶，體貴長貪，殊非出家之所畜用。令捨與俗，顯非道習。自餘諸捨，並在道位，通別不同。廣如《鈔》也。
【譯文】【疏文】第一、不對著境界而捨。好比蠶綿衣不合戒法，其本質是傷害生命，如果不予以剪截毀壞，這份貪愛如何斷絕？第二、在對著境界捨當中，又有出家僧與在俗人的分別。好比蓄存、買賣金銀二寶，其質地貴重且滋長貪念，絕不是出家人所應蓄積使用的，所以制令捨給在俗之人，以表明這不是修道者的習氣。其餘各項捨財，都在出家僧人的範圍內，通於全體僧眾或個別受捨而各有不同。詳細情況正如《事鈔》中所說。

【238-0011】02_戒疏/11c_卷三上之二#55

【譯文】【記文】捨財有五種，這是第一科。第一、不對境而捨，只有蠶綿衣這一項，其餘都要對境。第二、對境當中，二寶對俗人捨，其餘都對僧眾捨。乞缽這一條戒，必須在僧團中行缽，不通於對個人；其餘則通於僧團、眾多、個人三種，所以說「通別不同」。

【238-0012】02_戒疏/11c_卷三上之二#56

【原文】【記】五中。初「轉還」，即蠶綿斬壞也，《義鈔》作「壞還」，恐此字誤。四中，「入僧入俗」，并「還主」，即三判也。五中。除上五種，餘「並還主」。其中長物，或隔宿還，或展轉還，餘並即座直還。
【譯文】【記文】第五項中。第一「轉變形態歸還」，就是把蠶綿剪碎，《義鈔》作「毀壞後歸還」，恐怕此處字有訛誤。第四種當中，「入僧入俗」並「歸還原主」，就是指三種判決方式。第五種當中，除了上面五種情況之外，其餘「全都歸還原主」。這當中屬於長物的，有的隔夜歸還，有的轉手歸還，其餘都是在座上當場直接歸還。

【譯文】【疏文】以上是依據本律論述的五種不同行相。如果依照其他部派律典，凡捨入僧團而不歸原主受用的那些財物，現在有犯戒的人，不思量自己的業障深重，就只想草草捨財懺罪，把作法當成走過場而已。犯罪的心念既然不捨棄，哪裡還能稱得上是清淨的佛子呢？現在無法廣泛列舉其他部派的規定，姑且就金錢寶物來說，世人多受其害，看看其他部派律典是如何決斷的。
