# 校閱材料　第1539檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1539-0001】05_拾毗尼義鈔/04a_卷中之二#6
【原文】第四僧尼差別者九十中六十九戒僧尼同犯下尼律有文不煩更數有二十一戒與尼不同有三種別一有無不同謂輒教尼說法至日暮譏訶教授師此三尼無次第相生無意可解有十三戒輕重不同故頌言作衣持屏坐三期受讚食勸足美牙角過量覆三衣此之十三作事同罪有階降故曰輕重不同之義如律中解次有五戒犯同緣異頌言背請足外道與年雨浴衣如此五戒得罪處齊名為犯同緣異故落在不同戒中廣如律說文雖如是今就義更立應有三一牽他出春冬房僧尼同犯夏房僧吉尼提二毀呰尼通二眾僧輕重別三覆藏一戒二篇同尼初篇覆尼重僧輕諸部不同如別章解。
【譯文】第四門、比丘與比丘尼戒條的差別：九十條戒當中，有六十九條戒比丘與比丘尼共同犯，在下卷比丘尼律中有明文，不必再贅述。有二十一條戒比丘與比丘尼不同，包含三種差別：第一種是有無不同：指擅自教誡比丘尼、說法直到日落、譏嫌訶責教授師，這三條戒比丘尼沒有相應的戒相生起，不用費心即可理解。第二種是輕重不同：偈頌說：作衣（為尼作衣戒）、持（持衣與尼戒）、屏處坐（與尼屏處坐戒）、三期（往尼住處過三期戒）、受讚歎食、勸足食、美食、牙角針筒、過量牀足、覆藏粗罪、三衣等。這十三條戒，造作之事相同，但結罪有階層高低降等，所以稱為輕重不同的義理，如同律文中的解釋。第三種是所犯相同而因緣各異：偈頌說：背請食、足食、外道自手給食、與未滿二十歲人受具、雨浴衣。這五條戒得罪的處所是一致的，稱為犯同緣異，因此被歸列在互不相同的戒條中，詳如律文所說。文句雖然如此，現在依據義理重新建立，應當有三條戒：一、牽引他人出春天與冬天的房舍，比丘與比丘尼同犯；夏天房舍則比丘犯突吉羅，比丘尼犯單墮罪。二、毀呰戒：比丘尼造犯則辱罵僧尼二眾皆結單墮罪，比丘造犯則對二眾輕重有別。三、覆藏一戒在二篇中相同；比丘尼覆藏初篇重罪，比丘尼犯重（波羅夷），比丘犯輕（單墮）。諸部律派不同，如另一章篇中詳細解釋。

【1539-0003】05_拾毗尼義鈔/04a_卷中之二#8
【原文】第六隨難問答者問故作為重戲即犯輕何故藏他衣鉢二俱犯提答妄語非惱境故有情過犯戲即無情過論藏惱境雖能藏者心有輕重前人受惱不殊是故俱犯問下眾猶是惱境故應犯提答同類比丘受惱情重復能礙於布薩故重提異類設令毀破受惱未有諍訟不能障礙僧事所以犯輕。
【譯文】第六門、隨順難點問答：問：故意造作妄語是重罪，開玩笑嬉戲妄語就犯輕罪；為什麼藏匿他人的衣鉢，無論是故意還是開玩笑嬉戲，兩者都同樣犯單墮罪？答：妄語並不是直接惱亂外境的實事，所以有犯意的情緒才結重罪，嬉戲開玩笑就沒有深重的情過。而藏匿衣鉢是直接惱亂對方的實境，雖然藏匿者的心意有輕重之分，但對方所承受的惱亂卻沒有兩樣，因此兩者同樣犯單墮罪。問：下位的大眾（如沙彌、式叉摩那等）依然是能受惱亂的對象，為什麼不犯單墮罪而只犯輕罪？答：同類的比丘受惱亂，其情勢嚴重，而且能夠障礙半月布薩僧事，所以判為較重的單墮罪；不同類的下眾，縱使毀辱破損其心，其受惱亂還不至於引發大諍訟，不能障礙僧事，所以結罪較輕。

【1539-0004】05_拾毗尼義鈔/04a_卷中之二#9
【原文】問謗戒中七聚謗罪階降何故毀呰一提答謗既損惱有增微故結罪階降毀呰直就受惱邊制問若爾我以四重毀受惱重吉羅毀亦應輕答毀呰有二惡法皆提善法皆吉其謗中唯有惡法謗無善法謗故不相竝問若爾毀呰惡法中何故無階降答謗本有三義一為損惱二為治罰三要對人前毀呰唯有損惱闕無治罰故無階降。
【譯文】問：誹謗戒當中，依據七聚罪名來誹謗，得罪有階層高低；為什麼毀呰辱罵戒卻一律只結一個單墮罪？答：誹謗罪既然損害惱亂有加深與微細的差別，所以結罪有高低等級；毀呰辱罵則是直接就對方「承受惱亂」這一邊來制定，所以不分階降。問：如果是這樣，我用犯四波羅夷重罪來毀呰罵人，對方受惱亂很重，如果用犯突吉羅來毀呰，也應當結罪較輕才對？答：毀呰罵人有二種：罵他人有惡法都犯單墮罪，罵他人有善法都犯突吉羅罪。而誹謗戒中只有誹謗他人犯惡法，沒有誹謗他人修善法的，所以兩者不能相提並論。問：如果是這樣，毀呰他人有惡法當中，為什麼沒有罪名的階降呢？答：誹謗本來具備三種意義：一為了損害惱亂，二為了引發僧團治罰，三一定要當著他人面前說。而毀呰罵人只有損害惱亂，缺少了引發治罰的意義，所以沒有罪名階降。

【1539-0005】05_拾毗尼義鈔/04a_卷中之二#10
【原文】問謗通二眾如何尼毀比丘及尼別人提僧局同類答謗據擯治毀呰有尊卑上下違敬之咎故有輕重尼罵大僧眾吉為之義稀應可僧罵尼眾提為之數故若爾謗大僧稀亦應輕答以別人相惱數故大僧知法罵眾義稀故二眾俱吉。
【譯文】問：誹謗通於二眾，為什麼比丘尼辱罵比丘以及辱罵比丘尼個別一人時皆犯單墮罪，而大僧（比丘）辱罵他人卻局限於辱罵同類比丘才犯單墮罪？答：誹謗是依據將人擯除治罰來結罪；毀呰辱罵則有尊卑上下違背恭敬的過咎，所以罪有輕重。比丘尼辱罵大僧僧團只得突吉羅罪，是因為這種事理極少發生；難道比丘辱罵比丘尼僧團應當犯單墮罪，是因為發生的次數較頻繁嗎？問：如果是這樣，比丘尼誹謗大僧僧團的事也很稀少，也應當判輕罪才對？答：因為個別比丘尼相互惱亂很頻繁，大僧知法懂理，辱罵僧團的事極為稀有，所以僧尼二眾互罵僧團都只結突吉羅罪。

【1539-0006】05_拾毗尼義鈔/04a_卷中之二#11
【原文】問妄語戒著於大眾中餘戒何故不著答妄語七眾俱犯提毀呰兩舌等唯比丘提餘皆輕所以不著。
【譯文】問：妄語戒文當中明確標註『於大眾中』，其餘各戒為什麼不標註？答：妄語是七眾弟子造作都同樣犯單墮罪，而毀呰、兩舌等戒，只有比丘犯單墮罪，其餘大眾造作都較輕，所以不列在七眾通用之中。
