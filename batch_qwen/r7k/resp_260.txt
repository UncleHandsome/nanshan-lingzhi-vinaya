整體看下來，這批譯文方向大致掌握得住（十門的科判、二持二犯的架構都對），但有**幾處實質性誤讀**和**幾处括號註解疑似自撰出處**，另有術語處理不一致的問題。以下分「必改」「宜斟酌」「通則」三層說。

---

## 一、必改（意思讀錯或邏輯讀反）

### ★ 0003「三就人」→ 譯成「所對之人」（方向錯）
原文「七眾相望，乃至大比丘戒」，明擺著是就**能持者的受戒身分**（比丘、比丘尼、式叉、沙彌、沙彌尼、優婆塞、優婆夷）比較，不是持犯四緣中「所對境」的那個「人」。
→ 應作「就**能持之人（七眾身分）** 而言」。

### ★ 0003 括注「即阿毘達磨所稱之比丘無願律儀」（疑為杜撰）
「無願毘尼」是《行事鈔》此處的僻語，**查不到「阿毘達磨所稱比丘無願律儀」這樣一個現成術語**，這個括注等於替讀者安了一個假出處，比不註更糟。
→ 建議：先查《資持記》對應記文與《行事鈔》校勘（此語有無異讀），查到再註；暫時保留原詞＋「（義待考）」即可。

### ★ 0012 兩重「相望」被譯成自相矛盾
原文是**兩組比較**：
1. 無學 ↔ 三果：無學誤犯故輕，三果故犯故重。
2. 三果 ↔ 內凡：三果無漏力強，雖犯亦輕；內凡道劣故重。

譯文用「**然而**三果聖人無漏之力強大，縱有違犯亦算輕微」，讀起來像前面說重、後面又翻案。
→ 必須把「這是無學望三果／再是三果望內凡」的层次譯出來，「然而」要刪。

### ★ 0010「在持守各種篇聚罪名時」（動賓搭配錯）
「罪名」不是「持守」的對象。原意是：六聚罪有上下輕重，**持令不犯**之行亦互有強弱。
→ 「就六聚（五篇七聚）罪的上下輕重而言，持守不犯之強弱亦互有差別。」

### ★ 0015「四戒威儀」（斷詞可疑）
此處「戒威儀」很可能是 **「戒」與「威儀」二類**（重篇名戒、輕聚名威儀），故下句才說「篇聚上下，輕重可知」。譯成偏正詞「戒律威儀」，與下句的「上下輕重」就脫節了。
→ 建議「第四、就**戒與威儀**分：篇聚上下，輕重可知。」並核《資持記》科文。
（另：原文只作「篇聚」，譯文一律加「六聚」，宜標為補註。）

### ★ 0005「三時（受前、受時、受後）」
律中「三時」就淫戒受樂說，指**始受樂、正受樂、受樂已**三時皆無染心方名不犯。「受前」尚未受樂，立不住。
→ 「於受樂的初、中、後三時皆不染著」。

## 二、宜斟酌（不算錯，但失真或不足）

| 條 | 問題 | 建議 |
|---|---|---|
| 0001 | 「持威儀戒**功德**較弱」 | 原文「弱／勝」指持戒力用強弱，非單指功德；且「三品」宜點明＝外凡／內凡／聖人 |
| 0001 | 道共戒註「無漏**智慧**相應」 | 應作「與無漏**聖道**俱生之戒」（道共＝隨道而生，非僅慧） |
| 0002 | 「企求聖道尚未止息」 | 「企求」重點在**進求斷惑未息（有學）**，可補「尚未斷盡煩惱，仍有進求」 |
| 0002 | 「內凡、外凡互相比望則漸次減弱」 | 語意含糊，宜寫成「內凡不及有學，外凡不及內凡，逐層遞減」 |
| 0004 | 「這是從**斷過**的輕重相比」 | 原文「離過」，止持只是不作，未必已斷；改「所離過失的輕重」 |
| 0005 | 「無記心持戒＝無意識狀態下**未作惡**」 | 「未作惡」是譯者補義，宜入括號或加「按」 |
| 0005 | 「若以作持來互相校量，則有上中下不等」 | 未說清是**三心**分上中下；宜「若就作持（策修）義校量此三心，則分上中下三品」 |
| 0006 | 「四種**境界**」 | 「分齊」＝界限／等類，譯「境界」易與六塵境混；宜「四種等類（分齊）」並略釋「賊分齊」得名之由 |
| 0006 | 道分齊只譯「由戒得解」 | 本門是「所求」，須點出「**為求聖道解脫**而持戒」 |
| 0007 | 「因為此處煩惱深重」 | 讀者會反問：煩惱重何以反勝？宜補「境惡難持而能持，對治力強故勝」；並可註「北洲無受戒義故不論」 |
| 0008 | 典故只說「詢問老比丘尼之事」 | 宜補故事大要（老尼試威儀，六群入而油不溢、羅漢入反溢），並核出處（《付法藏因緣傳》《阿育王傳》系統）後作註 |
| 0009 | 「持守兩者各有強弱差異」 | 「互持強弱」是**二者相較**有強有弱，譯文像在說各自內部有強弱 |
| 0014 | 「本卷初篇」 | 「如卷初篇」所指宜查對（卷首某篇？前文三性說？），不宜含混帶過 |
| 0016 | 「即便懺悔」 | 補得對，但屬譯者補義（制罪可懺除、性罪業報不除），宜括號標示 |
| 0017 | 「可以推理解了」 | 生硬；改「準前『持戒門』所說即可知」 |

## 三、幾條改寫示例

**0003**
> 第三、就「能持之人（七眾身分）」而言。七眾互相比較，乃至大比丘戒，以「無願毘尼」最為殊勝。〔按：「無願毘尼」釋義待考，暫不作解。〕

**0005**
> 第五、就「心」而言，有三種：一是善心持戒，即修習離染的清淨行；如就根本重戒的惡境說，縱被怨賊強逼，於受樂的初、中、後三時皆無染著等。二是不善心持戒，即為名聞利養、求世間福報等而持戒。三是無記心持戒，即狂亂、睡眠等（非善非惡、無所覺知）狀態中自然不作惡。若就作持（策修）之義校量此三心，則有上中下三品之別；若只就隨順佛制、不違教而言，則無不是持戒，不再分別三心。

**0012**
> 第一、就「果位」分。無學唯有誤犯（無故犯），故輕；三果尚有故犯，故重——此是無學與三果相望。再以三果望內凡：三果無漏道力強，雖犯亦輕；內凡道力劣弱，故重。乃至外凡，層層相比，其理可知。

**0015**
> 第四、就「戒與威儀」分。篇聚上下（重篇為戒、輕聚為威儀），罪行輕重自可了知。

## 四、通則建議

1. **括號補註要分兩類**：屬於原詞的訓釋（如「別解脫律儀」）可直接括注；屬於譯者補足的義理（「即便懺悔」「未作惡」「因為煩惱重所以對治強」）建議統一用〔按〕或另立註腳，避免讀者誤認為原文所有。
2. **不要替僻語安出處**：0003 那句「阿毘達磨所稱」是最需要處理的一點。這類鈔文僻語應以《資持記》為第一查證對象。
3. **「勝／劣」全系列統一譯法**：目前時而「功德」、時而「殊勝」、時而「較弱」，建議一律用「（持戒力用）強／弱」或「勝／劣」，因為十門讲的是**相望**的比較，不是絕對價值判斷。
4. **「相望」二字务必譯出比較雙方**：0002、0009、0012 都因省略比較項而語意打結，這是本段最容易出錯的句型。
5. 篇聚、六聚、五篇七聚等術語，全文宜一致，且不要以「篇章」對譯「篇」。
