# 校閱材料　第719檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【719-0001】04_比丘尼鈔/06b_卷下之下#12
【原文】六負債者若佛法別人負亡人亡人負佛法別人輕重物者若有則相當還無則交絡還所以須索者以重物入常住僧輕物入現前僧先負亡人輕物者今索得重物還須博輕物分若先負亡人重物今索得重物者入重以本是重物者入重以本是輕物令僧分常住僧負亡人重物者不須索取以還入常住故若負輕物索取現前僧分若別人負輕重二物俱須索取以重物入常住輕物入現前十誦云生時負三寶物應歸若三寶貸亡人物索取入現前故須並索依本而斷乃至四方現前客舊互負之物亦同上說十誦云生時賖取他酒未還價便死佛言取衣鉢還若無物歸應取僧物還恐出諸比丘惡聲故義準若負餘物不生譏過者不還無罪以亡人無物故有物者應還十誦云先與他衣價死時還索取取他衣未與價若死還本衣無者賣衣鉢還母論云若有息物在外遣淨人推求取入此寺常住僧義準此文若負物在白衣家同四分無住處死五眾先見者得其重物隨前見者處分五百問事云比丘借人物前人死要須白僧得取本物不白得罪若不與強取或僧知而不還自他二俱得罪僧祇云若索債者當看前人持戒可信者與不可信者不應與若可信人證明者應與反此不得。
【譯文】第六門清償債務（負債），若佛、法、僧個別之人積欠亡人財物，或亡人積欠佛、法、僧個別之人輕重物品，若有原本之物則以原物抵還，若無原物則交錯折抵歸還；之所以必須索取，是因為重物歸常住僧，輕物歸現前僧；若原先積欠亡人輕物，如今索討得重物，仍須換回輕物分發給僧眾；若原先積欠亡人重物，如今索討得重物則入重物，若原本是輕物則讓僧眾分發；若常住僧積欠亡人重物，不必索討，因為終究歸還常住；若欠輕物，則索取出來分給現前僧；若個別之人欠亡人輕重二物，皆必須索討，因為重物歸常住，輕物歸現前；《十誦律》說生前積欠三寶之物應當歸還，若三寶借貸亡人物品，應索取歸入現前僧，因此必須一併索討，依其原本性質來裁決，乃至十方僧、現前僧、客僧、舊僧之間互相積欠之物，也如同上述處理；《十誦律》說，生前賒買他人酒尚未還錢便死去，佛說應當變賣其衣缽來償還，若無物品可還，應取僧物償還，因為害怕招致對諸比丘的譏嫌惡名，義理上比照若欠其餘物品而不生譏謗過失者，不還亦無罪，因為亡人已無財物，若有財物則應償還；《十誦律》說，先前預付他人衣服價款，死時應索討回價款，若拿了他人衣服尚未付款便死去，應歸還原衣，若衣服不在則變賣衣缽償還；《毘尼母論》說若有生利息之財物在外，派遣淨人追查取回歸入此寺常住僧，比照此文，若所欠財物在俗人家中，等同《四分律》在無常住處死亡之例，五眾出家人中最先見到者獲得其重物，隨最先見者之意處置；《五百問事》說，比丘將物品借給他人，借物之人死去，必須向僧團稟白才能取回原物，若不稟白而取即得罪，若僧眾不肯給還而比丘強行奪取，或僧眾明知而不歸還，自他雙方皆得罪；《僧祇律》說索取債務時，應當觀察對方是否持戒可信，可信者才給予，不可信者不應給予，若有可信之人作證明則應給予，反之則不可。

【719-0002】04_比丘尼鈔/06b_卷下之下#13
【原文】第七賞勞者此律有二五德初五德者病人難看表瞻病者德滿一病人所不應食而欲食不肯服藥二看病人有至心而不如實語三應住不住等四身有苦痛而不能忍五身堪能而不作抑他作又不能靜坐止息內心第二五德者明看病人自行德滿一知病人可食不可食可食應與二不惡賤病人大小便利唾吐三有慈悲心不為衣食故看四能經理湯藥乃至差若命終五能為病人說法令病人歡喜己身於善法增長有二五德者應與看病人衣物若小瞻病無好至心佛判不與僧祇云有四種看病不合賞物一暫作看不懷久意二僧次差看三自樂福德不憐愍四邪命而看止為利養並不合得若欲饒益病者欲令速差之意下至然一燈見命終者應得此律莫問德之優劣應與受持衣若不知何者是受持衣應量瞻病人有上中下若極上看病與上三衣中下看者與中下三衣十誦先問看病人受持何衣鉢一一別問或不知或不信者應與中六物此律賞勞六物者三衣為三鉢盂為四坐具為五鍼筩為六又文加十盛衣貯器者盛衣者猶是盛衣袋及五衣襆貯器者猶是鉢袋及函等此並通入賞勞也義準一德物並具二德具物不具此二合賞三物具德不具四德物俱不具此二不合賞而看病辛苦而欲優饒者束入現前作羯磨訖後量德優劣三唱口和僧隨多少賞之五分十誦比丘病時七眾應看二眾合得衣謂比丘及沙彌雖父母兄弟看而不應與勞不滿德故伽論云白衣看應與少許義準若多尼式叉沙彌尼看病者應與究竟者若齊究竟者應與一人已屏處分等十誦云若看病者出行為病人乞衣藥合得三衣者應留待身還與亦可攝入現前唱和付亦得若餘處比丘來看病亦與賞。
【譯文】第七門酬勞看病者（賞勞），本律有兩種「五德」：第一種五德是病人難以照料，以此顯彰看病者功德圓滿：一是病人不該吃的食物卻想吃，且不肯服藥；二是看病人具足至誠之心，病人卻不如實以告；三是該留處不留等；四是身體有痛苦而不能忍耐；五是身體尚有體力卻不做，反而勉強他人去做，自己又不能靜坐止息內心；第二種五德是說明看病者自身的德行圓滿：一是知道病人何者可食、何者不可食，可食者便給予；二是不嫌棄厭惡病人的大小便與唾吐污物；三是具備慈悲心，不為了衣食利益而照料；四是能調配照料湯藥，直至病人痊癒或命終；五是能為病人說法，使病人歡喜，並使自己於善法有所增長；具備這兩種五德之人，僧團應將衣物賞給看病者，若是短暫看病且無良好至誠之心，佛判定不給予；《僧祇律》說有四種看病不應賞物：一是短暫照料並無長久之意；二是依僧團次序差派輪流看顧；三是只為自己求福德而非憐憫病人；四是為了邪命利養而照料，皆不應得賞；若是為了饒益病患、盼其速疾痊癒之心，甚至低至只點燃一盞燈照看直至命終者，也應得賞；依照本律，不論德行高低，皆應給予受持衣，若不知何者是受持衣，應衡量看病者德行有上中下三等，若是極上等的看病者給予上常三衣，中下等的看病者給予中下等三衣；《十誦律》說先詢問看病者，亡人生前受持何種衣缽，逐一分別查問，若不知或不足採信者，應給予中等六物；本律賞勞的六物為：三衣算作三種、缽盂為第四、坐具為第五、針筒為第六，律文又加上盛衣貯器十種，盛衣者即盛衣袋及五衣袱，貯器者即缽袋及函箱等，這些都可列入賞勞之物；義理上判定：一德與物皆具備，二德具而物不具備，這兩種情況應當酬賞；三物具備而德不具備，四德與物皆不具備，這兩種情況不應酬賞；若看病極其辛苦而大眾欲給予優待者，可歸入現前僧物作羯磨完畢後，衡量其德行優劣，大眾三唱口頭和合，隨僧團決定多少賞給他；《五分律》與《十誦律》說，比丘患病時七眾皆應照看，其中二眾有資格得衣，即比丘與沙彌，父母兄弟雖來照看亦不應給予，因其功勞未達律定德行之故；《摩得勒伽論》說俗人看病應給予少許；比照義理，若有多位比丘尼、式叉摩那、沙彌尼照看病人，應給予照顧到最後（究竟）的人，若同樣照顧到最後，應先交付給其中一人，交付後再於私下隱蔽處平均分給眾人；《十誦律》說看病者若外出為病人乞求衣藥，其應得的三衣，應當保留等待其本人返回再給予，亦可歸入現前僧物唱和交付；若是其餘寺處的比丘前來看病，亦應給予酬賞。

【719-0003】04_比丘尼鈔/06b_卷下之下#14
【原文】第八時節者僧祗云若病人死不應即開其戶彼有弟子持戒可信者與戶鈎若不可信持戶鈎付僧知事人已先供養舍利料理竟弟子持戒可信者使出衣物若不可信應使知事人出衣物然後僧分十誦就屍邊分衣屍起護衣佛言待屍去後或在異處應分。

【719-0005】04_比丘尼鈔/06b_卷下之下#16
【原文】第一羯磨中五人得作賞勞分衣羯磨若四人者止得分衣不成賞勞以僧不滿故寧可羯磨後將衣物口和賞勞母論云由四人中牒一人入羯磨餘三不成僧故今立法者令瞻病人將亡人輕重二物並集僧中重物不可勝舉多者知數已直付僧庫亦得晝日作法彌善不得閉門限約客尼以通十方理無私背故婆論云白日閉門已不打鐘打鼓食者名盜僧食罪又此分衣不成而此物者人人各有分而有心限約客者各犯微塵數偷蘭遮故善生經云盜亡比丘衣物者若未羯磨望十方僧得罪若羯磨已望同羯磨僧滿五得夷不滿偷蘭看病人應近物邊長跪執物捨之若無看病尼維那捨之亦得。
【譯文】第一節羯磨法中，必須五人以上才能作「賞勞分衣羯磨」；若是四人，則只能作分衣羯磨，不能成就賞勞羯磨，因為僧數不足之故；寧可在分衣羯磨之後，將衣物以口頭和合的方式進行賞勞；《毘尼母論》說因為四人之中指定一人列入羯磨受賞，其餘三人即不能構成法定僧數之故；如今立法程序，應命照料病人的尼僧將亡人的輕重二種物品全部集合到僧眾之中，重物若多至無法全數搬動，點清數目後直接交付僧庫亦可；在白天作法最為合宜，絕對不得緊閉門戶以限制或排除客僧尼，因為僧物通於十方僧，理應公允無私偏背之故；《薩婆多論》說白天閉門，且不鳴鐘擊鼓而受食者，名為盜取僧食罪；又如此分衣即不能成立，且這些物品人人皆有一份，若起心限制客僧參與，每個人皆犯微塵數的偷蘭遮罪；因此《優婆塞戒經》說，偷盜亡故比丘衣物者，若尚未作羯磨，對著十方僧得罪，若已作羯磨，對著一同作羯磨之僧，（盜物價值）滿五錢得波羅夷罪，不滿五錢得偷蘭遮罪；看病尼應當靠近物品邊，長跪手持衣物捨給僧團；若無看病尼，由維那代為捨物亦可。

【719-0011】04_比丘尼鈔/06b_卷下之下#22
【原文】義云應隨物多少稱不得依文總誦恐無事不稱羯磨名為非法羯磨雖成仍獲小罪如二沙彌一時受戒一有難一無難無難者自成無妨小罪乃得婆論云三衣餘處索來此賞若此德不具即隨彼分若依十誦沙彌死時羯磨應云。
【譯文】教理認為：應當依照物品實際多少來稱念其名，不得照搬條文一概通誦，恐怕有名無實不相符合，導致羯磨成為非法羯磨；即使形式成立，仍會招致小罪，如同二位沙彌同時受戒，一人有遮難、一人無遮難，無難者戒體自然成就無妨，但作法者仍得小罪；《薩婆多論》說，三衣若在別處索取回來的，即在此處賞受，若此人德行不具備，即隨彼處大眾分發；若依《十誦律》，沙彌尼死時羯磨應當說：
