# 校閱材料　第1223檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1223-0001】資持記/11b_中四上#10
【原文】二下，釋通，初句總示。對破古解。古謂不學可懺，作心欲學，斷相續故；無知不可懺，欲知未了，無有斷義，故不可懺；後緣得解，即是解惑相除，復不須懺。〔由解除惑，罪無依故，相字平乎。〕今直出正解，古解如《義鈔》引之。如下，別顯，初明先犯。若下，明後斷。以纔起心學，即無無知；
【譯文】在「二」字以下進行解釋會通，第一句作總體指示，用以破除古德的見解。古德認為不學罪可以懺悔，因為一旦下決心想要學戒，就斷除了相續造業的心；無知罪則不可懺悔，因為想了解卻仍不明白，沒有中斷罪過的意思，所以不可懺悔；後來若遇緣明白了，便是正解與迷惑互相消除，也就不需要再懺了〔因為藉由正解消除迷惑，罪過無所依附，「相」字讀作平聲〕。現在直接提出正確的解釋，古德之說如《律學義鈔》所引。在「如下」一句，個別顯明，先說明先前造犯。在「若」字以下，說明後來斷絕。因為剛一起心要學，當下就不再屬於無知了；

【1223-0002】資持記/11b_中四上#11
【原文】二俱有斷，故皆可懺。六明優劣，持犯各十門，初持十門。一一門中，皆通二持，竝見優劣之義。約法中，初科。威儀者，隨境別護，禁身口故；護根者，通攝六根，制於心故；定共，與禪定俱發故；道共，斷或證道，同時得故。上二散業，三是定業，四無漏業。據戒唯有三位，上二竝得別脫；
【譯文】兩種罪都有斷除的時候，所以全都可以懺悔。第六「明優劣門」，持戒與犯戒各有十個門類，先看持戒的十個門類。在每一個門類中，都貫通作持與止持，都能顯現出優劣的涵義。在依據法門（約法）中，第一科。所謂「威儀」，是隨著具體境緣個別防護，用以禁制身口二業；所謂「護根」，是通盤收攝六根，用以制伏自心；所謂「定共戒」，是伴隨禪定境界同時引發的；所謂「道共戒」，是在斷惑證道時同時獲得的。前兩種屬於散心善業，第三種是禪定業，第四種是無漏業。若依戒律而言只有三種階位，前兩種都屬於別解脫戒；

【1223-0003】資持記/11b_中四上#12
【原文】但約內外兩凡，麁細分之。威儀通凡聖，道共唯局聖；中二相望，通局可知。次科，初以四戒，配對三位。外凡散修事觀，未緣諦理，無實德故，名為假名；即五停心總別相念，及薄地凡夫也。內凡多在定心，緣四諦境，分見真理，名為和合，即煖、頂、忍、世第一也。
【譯文】只是依內凡、外凡二位，以粗淺與細微來區分。威儀戒通於凡夫與聖人，道共戒則唯局限於聖人；介於中間的兩者互相比對，其普遍與局限之範圍便可知曉。下一科，首先以這四種戒，配對三個階位。外凡夫以散亂心修習事相觀想，尚未緣於真諦之理，沒有真實功德，所以稱為「假名」；也就是指修五停心觀、總相念住、別相念住的行者，以及煩惱粗重的薄地凡夫。內凡夫大多處於禪定心之中，緣於四聖諦之境，已部分見到真理，稱為「和合」，也就是指煖位、頂位、忍位、世第一位。

【1223-0004】資持記/11b_中四上#13
【原文】初果已去，證真諦理，號真實僧。德下，父約三位，顯示優劣。初劣後勝，中二兩通。乃至者，略於定法；內凡兩戒，復須分之。次門。初約四聖以分道共，自有優劣。三果，謂三位果人，比降漸劣。企，望也；望上進求，德未圓故。次內凡中二戒通四人，世第一為勝，煖位為劣，中二可知。
【譯文】證得初果以上，證悟了真諦之理，稱為「真實僧」。在「德」字以下，又（原文『父』為『又』之訛）依照這三個階位，顯示持戒的優劣。最初的外凡最劣，最後的聖人最勝，中間內凡的兩種戒則兩相通融。文中說「乃至」，是省略了禪定戒；內凡所具的兩戒，也必須加以區分。下一個門類。最初依四種聖人來區分道共戒，自身便有優劣之差。所謂「三果」，是指前三位果位的聖人，依序遞降而漸漸稍劣。「企」是盼望的意思；因為向著更高境界進修求證，功德尚未圓滿。其次，內凡所具的中間二戒（護根戒與定共戒）通於四位（煖、頂、忍、世第一），世第一位最勝，煖位最劣，中間的頂位與忍位依此可知。

【1223-0005】資持記/11b_中四上#14
【原文】外凡威儀，三位亦爾。若約通論，唯無學為優，五停至劣；中間九位，可以比知。問：二門竝明人法，如何取別？答：前是約位顯法，後即就位細分。第三門。前通凡聖四法為言，此局下凡別脫以辨。別脫又四，五八對在家二眾，十戒對下三眾，具戒對僧尼二眾。約體，四位雖同；
【譯文】外凡夫的威儀戒，在三個位階中也是如此。如果通盤而論，唯有無學果（阿羅漢）為最優，五停心位為最劣；中間的九個位階，可以按次序比對推知。有人問：這兩個門類都說明了人與法，該如何區別？回答：前一門是依照階位來彰顯戒法，後一門則是就具體階位進行細緻劃分。第三門。前一門通括凡聖四種法來論述，此門則局限於下位凡夫的別解脫戒來辨明。別解脫戒又分四種：五戒與八戒對應在家二眾，十戒對應出家下三眾（沙彌、沙彌尼、式叉摩那），具足戒則對應出家僧尼二眾。若論戒體，這四種位階雖相同；

【1223-0006】資持記/11b_中四上#15
【原文】就人，七眾乃別；初劣後勝，中間可知。四中。前通道俗，此下七門，據文雖通，約義在道。文中分二，初約所犯輕重。二約能治難易。五中，初科。善心且約治婬，餘皆類準。離染淨行，即不淨觀。不善心者，為求名聞利養，人天樂報。然戒序中，名譽利養，死得生天；彼謂持戒冥感，非是惡求。
【譯文】但若就受持的人而言，七眾便有差別；初階最劣，後階最勝，中間的優劣以此可知。第四門中。前面通論道人與俗人，此處以下的七個門類，依照文字雖然通涉，依義理而言則重心在出家修道人。文中分為二部分：第一是依所違犯的輕重；第二是依能對治的難易。第五門中，第一科。善心姑且以對治淫欲為例，其餘戒條皆依此類推。遠離染污的清淨行，就是指不淨觀。所謂不善心，是指為了求取名聞利養，或是為了得生人天福樂之果報。然而戒經的序文中提到「名譽及利養，死得生天上」，那是說明持戒所自然感得的冥冥回報，並不是指蓄意為此而惡求。

【1223-0007】資持記/11b_中四上#16
【原文】無記且舉狂睡；不緣善惡，泛爾奉持，竝無記攝。次科，上二句示優劣。言作持者，作即行心起護，通該二持。〔舊以作持一行釋者，為名誤也。〕謂取作心比校，故有三品優劣；善心為上，不善為中，無記非業為下。若下，會同。以三心約業，優劣乃珠；二持就制，順教無異。六中。
【譯文】無記心姑且舉發狂與睡眠為例；心中不執著善惡，泛泛然隨順奉持，都屬於無記心所攝。下一科，前兩句指示優劣。所謂「作持」，「作」是指發動內心起而防護，通括作持與止持二者〔過去有人用『作持』這一種修行來解釋，是被名相所誤導〕。這是指拿造作之心來互相比對，所以有上中下三品優劣；善心為上位，不善心為中位，無記非善惡業為下位。在「若」字以下，進行融通。因為三種心從造業的角度來看，優劣大不相同；但從二種持戒的防制意義而言，順應佛陀教法並無差別。第六門中。

【1223-0008】資持記/11b_中四上#17
【原文】四種皆約標心期限，故名分齊。初劣後優，中二可會。若論業行，初不善業，竝四趣因；二三世善，人天分之；四無漏業，三乘因本。初謂邪諂希利，有如賊焉；望教無違，亦名持戒。二謂常畏罪報，無別所求。三據戒序。四準律序，彼云：除結無罣礙，傳著由此解；
【譯文】四種情況都是就內心設定的期限目標而論，所以稱為「分齊」。第一種最劣，最後一種最優，中間兩種可以融會推知。若就所修業行而言：第一種是不善業，全都是墮入四惡趣之因；第二、第三種是世間善業，由人道與天道所分受；第四種是無漏業，為三乘聖道的根本因。第一種是指用諂媚邪惡之心希求利益，行為如同盜賊一般；但對照教法並未違背，所以也名為持戒。第二種是指常懷畏懼惡道罪報之心，沒有其他更高的追求。第三種是依據戒經序文所說。第四種是依據律序所說，律序云：「斷除結縛無所罣礙，相傳執持皆由此而解脫」；
