# 校閱材料　第1517檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1517-0001】05_拾毗尼義鈔/02a_卷上之二#28
【原文】第四破僧時處者調達初立邪三寶能破因成未即究竟故諸比丘白佛佛言汝莫破僧又如來依法略有二種一行依者四依八正是也二眾法者說戒羯磨是也今調達學佛亦說二依一立邪五法以為行法反破如來八正四依二立非法羯磨以為眾法反破如來正眾法故處所者以王舍忍可五法始破行法後至伽耶羯磨說戒反破眾法始是究竟破正義備故僧祇云調達向伽耶佛使阿難喚即語阿難我不去吾從今日後不共佛法僧事布薩自恣說戒等欲學不學自從我意阿難作是念此是害事出是惡聲將壞僧耶二反喚後六羣比丘自相謂言瞿曇沙門必當三喚我各正意先作羯磨馳譽後世即布薩竟及至三喚說戒已竟佛自聞之便說清淨如滿月頌等告阿難言非法眾已作布薩如法人自作布薩去以斯證故破在伽耶問調達得喚不喚盡集別亦不犯四伴同僧不犯逆罪不喚應犯別何得不犯答非罪重故便是不犯但一破已後邪正不相足數各作無妨故言不犯問調達行法與正既異眾法云何答眾法亦異故僧祇云調達欲破僧非前序已四夷乃至滅諍隨順法不制者制制者不制又復七羯磨開制不同道俗共行九部經等更作異句義味各異文辭自說誦習亦持教人既知眾法異云何羯磨異耶或可共作多白不作羯磨或作羯磨不作白或先羯磨後作白或單白說或文為增減顛倒首尾是名非法羯磨若諸比丘信受二法始是具足破正義備方成逆罪。
【譯文】第四部分，關於破僧的時間與地點。調達最初豎立邪三寶的旗幟時，能破的因緣雖然形成，但破僧的惡業尚未徹底究竟，所以諸比丘向佛報告時，佛陀告誡調達說「你不要破僧」。又如來依止的正法大略有兩種：一是「修行所依」，即四依止法與八正道；二是「僧事大眾法」，即布薩說戒與羯磨法事。現在調達仿效如來，也宣說了兩種依止：第一是標立五種邪法作為修行法則，徹底反叛破壞如來的八正道與四依止；第二是標立非法羯磨作為大眾軌則，徹底反叛破壞如來的正法僧事。至於破僧的地點：起初在王舍城，眾人印可了五種邪法，這才開始破壞修行正法；後來到了伽耶山，實際舉行非法羯磨與說戒，徹底破壞了大眾僧事，破除正法的行徑這才算究竟完備。所以《僧祇律》說：調達前往伽耶山，佛陀派遣阿難去喚他回來，調達隨即對阿難說「我不回去，我從今天起，不再參與佛法僧的一切僧事、布薩、自恣、說戒等；戒律想學不想學，全憑我自己的意思」。阿難心想「這是大禍害事，竟然發出如此惡言，難道真要分裂僧團了嗎？」在兩次呼喚之後，六群比丘彼此私下議論說「瞿曇沙門必定會派人來第三次呼喚，我們各自端正心意，搶先舉行羯磨，名揚後世！」隨即完成了非法布薩；等到阿難第三次前來呼喚時，他們的邪說戒法已經圓滿。佛陀親自得知此事後，便說了「清淨如滿月」等偈頌，並告訴阿難說「非法的大眾已經舉行了他們的布薩，隨順如法的大眾自己去作我們的布薩吧」。以此為憑據，可知真正究竟破僧是在伽耶山。有人問：調達受到佛陀召喚卻不肯應召，僧眾集合時他擅自別立大眾，難道不算犯了別眾罪嗎？其餘四位同伴同是僧眾，並不犯逆罪，若佛陀召喚時不前往，理應犯別眾之罪，為什麼說他不犯？回答：並非罪行深重就不算犯戒，而是因為僧團一旦破裂之後，邪派與正派彼此互不計入法定人數，各自舉行僧事已互不相干，所以說他不犯別眾。又問：調達的修行法既然與正法相悖，他的大眾僧事又是如何呢？回答：僧事法軌同樣變異了。所以僧祇律說：調達企圖破僧，否定了前述的波羅提木叉序文，從四波羅夷乃至滅諍法、隨順法，把佛所不制約的擅自制約，佛所制約的擅自廢止；又將七種羯磨的開許與限制任意更改，把道俗共同遵行的九部經等教典隨意竄改文句，義理意趣各自變調，自創文辭來宣說，並以此受持傳習、教導他人。既然知道大眾法軌變異，羯磨又如何變異呢？有時是只作多次白文而不作羯磨，有時是只作羯磨而不作白文，有時是先羯磨後作白，有時只作單白就當作定案，或者在文句上隨意增減、首尾顛倒，這都叫做非法羯磨。如果僧眾信受依從這兩種邪法，破除正法的惡行才算徹底具足，這才真正結成無間逆罪。
