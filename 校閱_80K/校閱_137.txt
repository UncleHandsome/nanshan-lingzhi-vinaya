# 校閱材料　第137檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【137-0001】資持記/08d_中二#31
【原文】三結罪中，初明二重。綿不入淨，此據成衣相者；褥同重物，亦不入淨，應是小者。餘下，明六輕。言畜少者，謂事稀故。四交貿中有五，初二句以八易衣。犯販賣故。以下四句，以衣易八。得寶即犯貿寶。綿毺俗邊犯販賣。若以下四句，上明二自相貿。
【譯文】在第三項結算罪名的段落中，首先說明兩種重犯情況。絲綿本不入說淨之例，此處判違淨施得墮是據已經製成衣服樣式者而言；墊褥等同重物本亦不入說淨，此處應當是指尺寸較小的坐褥。從「餘」字以下，說明六種情節較輕的罪相。說它蓄存罪較輕，是因為這類雜事發生的機率較為稀少。在第四項物資相互交易的行為中分為五種，前兩句說明用八種不淨物去換取僧衣。這犯了販賣罪。從「以」字以下四句，說明用僧衣去換取八種不淨物。換得了金銀珍寶就犯以物換寶罪。換得絲綿或毛毯，若是在俗人處換得則犯販賣罪。從「若以」以下四句，前半段說明前面兩種物品私自相互交易。

【137-0002】資持記/08d_中二#32
【原文】衣易衣犯販賣，寶易寶犯貿寶。下明以二貿六，得輕，可知。六下四句，六種自貿。或對貿，或互易，並吉。又以六易二，販貿二墮，準上可明。此下，點上販賣，對人輕重。上云犯捨，且據俗論。明說淨中，初明淨財易物。衣鉢百一，入受持故。
【譯文】用衣服換衣服犯販賣罪，用金寶換金寶犯換寶罪。後半段說明用這兩種物品去換取其餘六種輕物，結得輕罪（突吉羅），其理可知。從「六」字以下四句，是指六種物品內部相互交易。無論是同類對換，還是互換種類，全都犯突吉羅罪。如果用六種輕物去換取前兩種重物，則會觸犯販賣或換寶的兩種墮罪，依照上面的原則即可明白。從這裡以下，特別點出上述販賣行為，面對出家人與在家人所結罪名的輕重差異。上面所說要受到捨財處罰，暫時只是針對面對在家人時而論的。在說明「說淨」的法度中，首先說明用合法的淨資財物去換取其他物品。僧衣、缽具等百一資身用品，因為已經納入個人受持的法規之中。

【137-0003】資持記/08d_中二#33
【原文】已外說者，若準《業疏》，並不須說，即入淨故。若下，明犯長錢寶，未懺，先用易物。後但悔罪，物不須捨；準有輒用，吉羅；悔於僧中，句絕。已外須說者，既已入淨，則應淨法。解本戒中，初科。以舊戒本云：若自手捉錢，若金銀等，語濫後戒，故須簡之。
【譯文】超出百一之外需要作說淨的物品，如果依照《業疏》的觀點，全都不需要再做說淨，因為它們本來就已經合法納入淨物之中了。從「若」字以下，說明非法蓄存超額的錢寶，尚未懺悔罪過，就先拿去換取生活物資。事後只要懺悔私蓄之罪，換得的物資不需要沒收捨棄；但是依照規定擅自挪用，要犯突吉羅罪；鈔文到『悔於僧中』處句讀斷斷（句絕）。超出範圍之外必須作說淨法，是因為既然已經納入清淨資財，就應當依法履行說淨的軌範程序。在解釋本條戒律的內文中，第一個科判。因為舊版戒本經文寫道：「若自手捉錢，若金銀等」，在文詞上容易與後面一條戒律混淆不清，所以必須加以辨析揀別。

【137-0004】資持記/08d_中二#34
【原文】《刪定戒》中，改捉為受，則無濫矣。別時意者，畜中言捉，犯後戒故。準作四句：一是畜非捉，唯犯前戒〔教人口受〕；二是捉非畜，但犯後戒〔觸自淨寶及他人寶，捉金像等。〕；三亦畜亦捉，前後俱犯〔手受而畜〕；四二非無犯〔如法受淨〕。次科，斥濫中，先敘貪畜之意。內即是志，外謂為行。
【譯文】在《刪定戒本》之中，將「捉持」改為「接受」，這樣就不會與後面的戒條互相混雜了。所謂「別時意語」，是因為在蓄存戒中若提到用手捉持，就會同時犯了後面的捉持寶物戒。依照戒律可以推演出四種情況：第一種是蓄存而非捉持，只觸犯前面這條蓄寶戒【例如口頭指使人接受】；第二種是捉持而非蓄存，只觸犯後面這條捉持戒【例如觸碰自己已經說淨的寶物、他人的寶物，或者捉持金屬佛像等】；第三種是既蓄存又捉持，前後兩條戒律同時觸犯【例如親手收受並加以私藏】；第四種是既不蓄存也不捉持，完全沒有違犯【例如依照法度辦理說淨手續】。第二個科判，在斥責虛妄濫用的段落中，先陳述貪圖私蓄的內心動機。內心存著貪求的名利志向，外表表現出奔逐的造作行為。

【137-0005】資持記/08d_中二#35
【原文】不思聖誡即慢法，縱貪癡是自任。故下，引證；初引本律，準明失戒。非弟子者，不稟師教故；非沙門者，不修淨行故；非釋子者，不係聖族故；今多受畜，為教所揀。雖自剃染，即魔外之徒。又云下，佛告珠髻大臣之詞。次引《雜含》。以五欲法，非善功德，復非清淨。
【譯文】不顧念佛陀神聖的遺誡就是輕慢戒法，縱容自己的貪欲與愚癡就是放任自流。從「故」字以下，引述經教證明；首先引用本宗《四分律》，明確指出這樣做會徹底喪失戒體。所謂「非我弟子」，是因為不遵從根本恩師的教誨；所謂「非沙門」，是因為不再修習清淨的梵行；所謂「非釋子」，是因為不再歸屬於釋迦如來的神聖家族；如今僧眾大多貪圖接受蓄積財物，早已被佛陀聖教所擯除淘汰。即便私下剃髮身披染衣，本質上也只不過是魔王與外道的黨徒罷了。經文又說，下文是佛陀親自告誡珠髻大臣的沉痛法語。接著引用《雜阿含經》。經中指出世間的五欲之法，根本不是良善的功德，更談不上絲毫的清淨。

【137-0006】資持記/08d_中二#36
【原文】今畜財寶，正是順欲；若許受畜，反成功德，亦應清淨。此顯出家絕欲求道。反為欲縛，深非所宜；後引《增一》。彼云梵志超術，欲以金錢奉定光佛；自念我有書名《禮記》云：若是如來，必不受金寶；遂易蓮華五莖，用上彼佛。〔釋迦因行，從此獲記。
【譯文】如今蓄藏世俗財寶，完全就是在順從世間的貪欲；如果允許比丘接受並蓄藏財寶，反而能成就聖道功德，那麼五欲也應當被視為清淨之法了。這正彰顯出家本是為了斷絕貪欲而專心求取菩提。如今反而被財欲死死綑綁，實在是極度不相稱、不合宜的事情；最後引用《增一阿含經》。經中記載有位名叫超術的婆羅門，想要將珍貴的金錢供養給定光佛；心中暗想：我所讀的書名叫《禮記》，書中說：如果是如來，必定不會接受金銀寶物；於是他在市集上用金錢換取了五莖青蓮華，用來供養定光佛。〔釋迦如來因地修行，從此（定光佛）獲得授記。〕

【137-0007】資持記/08d_中二#37
【原文】故下，結示引意。前文敘誡，並據誠教，故云非濫。述誡中，初科，初敘制戒之意。棄鄙業者，謂捨惡也。遠超等者，謂增善也。今下，斥其違制。劇，甚也。行商坐賈，皆求利者；今僧貪積，往往過之，故云甚也。烟雲者，律云：日月有四患故，不明不淨，不能有所照，亦無威神；謂阿修羅、烟雲、塵、霧；
【譯文】所以從這裡以下，總結指示引述經典的深意。前面的文字敘述佛陀的嚴厲戒誡，全都依據佛陀真誠無訛的教導，所以說絕非無端附會或濫作引申。在陳述誡勸的段落中，第一個科判，首先陳述佛陀制訂這條戒律的根本深意。「捨棄鄙陋的行業」，是指斷除世俗一切惡法。「遠遠超越世俗」等話語，是指不斷增長清淨善行。從「今」字以下，嚴厲斥責出家人違背戒制的行徑。所謂「劇」，就是劇烈、嚴重到了極點的意思。四處奔波的行商與開張設店的坐賈，全都是為了追逐暴利之人；如今出家僧人貪圖蓄積錢財，其貪婪程度往往超過了世俗商人，所以說是極為嚴重。所謂「煙雲」，律中記載：太陽與月亮因為有四種禍患的緣故，失去了明亮與清淨，無法普照天地，也沒有了光輝威神；這四種禍患就是阿修羅王、煙雲、塵埃與大霧；

【137-0008】資持記/08d_中二#38
【原文】沙門有四大患，飲酒、婬欲、持金銀、邪命，能令沙門不明不淨，不能有所照，亦無威神。今謂沙門行淨，則佛法光輝；行既鄙穢，則能障蔽，故如烟雲。反下，責其謗法，初敘謗詞。排，毀也。出下，斥僣濫。矜謂自高，持謂執以為是。

【譯文】文中所說的「轉易」，是指標明這條戒律的核心名稱。從這裡以下，詳細簡別本戒與後面的經商販賣戒。所說的五種相異之處全如《戒疏》所說，疏中指出：第一是對待的對象不同，寶物貿易戒無論面對出家還是受戒七眾都會構成犯戒，而衣物販賣戒則唯有面對在家男女二眾才會構成違犯；第二是寶物貿易戒無論是自己親手做還是教唆別人做，只要是為了謀取私利就一律同罪，除非是為了常住三寶的利益才不犯，而衣物販賣戒只要差遣在家人去辦理，比丘自身就不犯重罪；第三是寶物貿易戒一經制定便毫無開許，而衣物販賣戒則開許以酥、油互相交換；第四是依法捨棄時面對的對象道俗有別【違犯販賣衣物是面對出家修道人捨棄，違犯貿易寶物則是必須面對世俗在家人當面捨棄】；第五是捨棄之後返還的財物本體不同【衣物捨棄還元物故云本，寶物捨棄換成清淨物故非本】。

【原文】此戒不對僧捨，恐隨別悔，故特遮之。以過重故。不犯中。唯開三寶，餘無所通。二十。〔佛在舍衛，跋難陀往無住處村，以生薑易食；又共外道博衣，悔而不還，譏訶因制。〕戒名。準疏分三：為利故收，為利故出，諍語而高，為販也。為利而取，故減前價，名買也。
【譯文】這條戒所涉及的錢寶不可在僧眾面前捨棄（因僧人不捉寶，須對在家人捨），但悔罪則必須對僧團發露，唯恐比丘私下隨便對個別比丘懺悔，所以特地加以遮止禁止。這是因為違犯這條戒律的過失實在太過沉痛深重的緣故。在不犯戒的特例中。唯獨開許為了常住三寶的弘法與修繕利益而進行調換，其餘一切個人私用皆絕對不在開許之列。第二十條戒【佛在舍衛，跋難陀往無住處村，以生薑易食；又共外道博衣，悔而不還，譏訶因制】。戒律的具體名稱。依照《戒疏》的剖析分為三種型態：為了謀取暴利而大肆收購，為了謀取暴利而高價賣出，在交易過程中討價還價爭吵喧鬧，這就叫做「販」。為了謀取暴利而買進，所以拼命壓低對方的原始價格，這就叫做「買」。
