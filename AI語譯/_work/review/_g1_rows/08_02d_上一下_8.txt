== PROBLEM ==
術語與數目誤解。「五十祇中」是指《僧祇律》受戒時的「五人僧」與「十人僧」（即邊地五人、中國十人之僧數），和尚不計入五人或十人之中（和尚在數外）。譯文誤譯為「五種與十種《僧祇律》眾」，將僧人人數誤解為僧眾種類。

== SUGGESTION ==
改為「在《僧祇律》的五人僧與十人僧受戒中，和尚都是算在法定人數之外；」

== ORIG ==
`五十祇中，和尚在外；《四分》限定中國十人。《十誦》一人。`

== CURRENT ==
在那裡不算足數的內容中，前後兩次出現上述這些人；在別眾犍度中出現過一次，全都說如果自己陳述犯了邊罪、污染比丘尼等。《十誦律》的說法，見於第三個例項。在破斥古師觀點中，起初列出他們的解釋。由於執著於本體，就與受戒四句的教法相衝突，於是曲折解釋說：那種不知情而得戒的，是指在大眾計數之外。從「此」以下一句話直接破除。從「何」以下，作雙重的責難。上面是就不知情來難破其違背本宗，下文則是就知情而言難破其違背教法。在五種與十種《僧祇律》眾中，和尚是算在計數之外；《四分律》則限定在中國（中印度）必須十人。《十誦律》只加一人。
