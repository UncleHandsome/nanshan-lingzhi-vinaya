# 校閱材料　第047檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【047-0001】01_行事鈔/03b_卷上之三#17
【原文】二須依止人十種。《四分》云：一和尚命終；二和尚休道；三和尚決意出界；四和尚捨畜眾；五弟子緣離他方；六弟子不樂住處，更求勝緣；七未滿五夏；八不諳教網。文云：若愚癡無智者，盡壽依止。此約行教明之。《十誦》：受戒多歲，不知五法，盡形依止：一不知犯，二不知不犯，三不知輕，四不知重，五不誦廣戒通利。《毘尼母》：若百臘不知法者，應從十臘者依止。《僧祇》中四法：不善知毘尼，不能自立，不能立他，盡形依止。九或愚或智。愚謂性戾癡慢，數犯眾罪；智謂犯已即知，依法懺洗，志非貞正，依止於他。十不誦戒本。《毘尼母》：不誦戒人，若故不誦、先誦後忘、根鈍誦不得者，此三人不得離依止。前之七人未滿五夏，故須依止；若滿不須。後之三人位過五夏，要行德兼備，便息依他。然五歲失依止，約教相而言；據其自行，終須師誨。《律》云：五分法身成立，方離依止。更通諸教，佛亦有師，所謂法也。如是廣說。
【譯文】第二、必須依止師長的人有十種。《四分律》列舉：一、和尚命終圓寂；二、和尚還俗休道；三、和尚決意離開結界遠走他方；四、和尚捨棄不再收蓄徒眾；五、弟子因因緣必須遠離他方；六、弟子不樂居現前住處，為求勝緣而另覓他處；七、受戒未滿五個夏臘；八、不熟悉通曉戒律教綱。律文說：如果愚癡缺乏智慧者，必須盡形壽（終生）依止師長。這是就修持戒教而言。《十誦律》說：受戒雖已歷經多年，若不通達五法，必須終生依止師長：一不知道何為犯戒，二不知道何為不犯，三不知道戒罪之輕，四不知道戒罪之重，五不能背誦詳盡的廣戒本使其通利流暢。《毘尼母經》說：即使有一百夏臘之高年若不懂律法，也應當跟隨十個夏臘的通法者依止修學。《僧祇律》列出四種情況：若不善知毘尼（律藏），不能自行立身持戒，不能教立他人，就必須終生依止師長。第九種、或者性質頑愚、或者知過善變者。「愚」是指性情乖戾愚癡傲慢、屢屢毀犯諸罪；「智」是指雖有微智，犯過後隨即知曉並依法懺悔洗滌，但心志不夠貞固端正，仍須依止他人以求策勵。第十種、不能背誦戒本。《毘尼母經》說：不誦戒本的人，無論是故意不背誦、先前會背後來遺忘、或是天資魯鈍背誦不下來者，這三種人皆不得脫離依止。前面所說的前七種人，是因為未滿五夏，所以必須依止；若滿五夏則不必依止。後面三種人即使年資已過五夏，但必須行持道德皆已兼備，方可免除依止他人。然而說「滿五夏便免除依止」，只是就一般教誡名相而言；若是據其實際個人自修實踐，始終需要師長的教誨引導。《四分律》說：必須戒、定、慧、解脫、解脫知見這「五分法身」圓滿成就，方能徹底脫離依止。若進一步貫通各部經教，連佛陀也是有師父的，那便是妙法。經論中即是如此廣為宣說的。

【047-0002】01_行事鈔/03b_卷上之三#18
【原文】二明依止正行，分二：一七種共行法，二三種別行法。
【譯文】第二項、明示依止時的具體正行，分為兩部分：一是師徒共同修行的七種「共行法」，二是弟子承事依止師的三種「別行法」。

【047-0003】01_行事鈔/03b_卷上之三#19
【原文】初中七法者：一眾僧與師作治罰，弟子於中當如法料理，令和尚順從於僧；設作，令如法不違逆，求除罪，令僧疾與解罪。二若和尚犯僧殘，弟子當如法勸化令其發露己；為集僧，作覆藏六夜出罪等。三和尚得病，弟子當瞻視，若令餘人看，乃至差，若命終。四和尚不樂住處，弟子當自移，若教人移。《僧祇》：能說出家修梵行無上沙門果，雖無衣食，盡壽不應離和尚。若欲遊方者，和尚應送。若老病，應囑人。當教云：汝可遊方，多有功德，禮諸塔廟，見好徒眾，多所見聞；我不老者亦復欲去等。五和尚有疑事，弟子當以法以律，如法教除。六若惡見生，弟子教令捨惡見，住善見。七弟子當以二事將護：法護者，應教增戒增心增慧，學問誦經；衣食護者，當與衣食醫藥，隨力所堪為辦。此七種法，諸部多同。《僧祇》和尚闍梨有非法事，弟子不得麁語，如教誡法；應耎語諫師，應作是、不應作是。若和尚不受語者，應捨遠去；若依止師，當持衣鉢，出界一宿還。若和尚能除貪等三毒，此名醍醐，最上最勝，不得離之。餘廣如後。《五分》中：若師犯僧殘，求僧乞羯磨，弟子應掃灑、敷座、集僧、求羯磨人。
【譯文】在第一部分「七種共行法」中：第一、若大眾僧依法對師父處以治罰羯磨，弟子在其中應當如法妥善調停照應，引導和尚順從大眾僧之決定；即使僧團處以治罰，也應勸師父如法順受不相違抗，並代求除免罪過，促使僧團儘快為其解脫羯磨罪罰。第二、如果和尚犯了僧殘罪，弟子應當如法勸勉開導令師父自行發露懺悔；並為師父召集僧眾，依法作覆藏、行六夜摩那埵（六夜親悅眾僧）、乃至作二十大僧出罪羯磨等。第三、和尚若染患疾病，弟子應當親自照看護理，或者安排其他人看護，直到疾病痊癒，或者照料到命終為止。第四、和尚若厭倦現前住處而不樂安住，弟子應當親自為其遷徙安頓，或者請託他人協助搬遷。《僧祇律》說：和尚若能演說出家修梵行、成就無上沙門聖果之法，那麼即使缺乏衣食資具，弟子終其一生也不應當離開和尚。如果弟子想要出外遊方，和尚應當相送。如果師父年老多病不能親送，應當囑託他人代為照料送行，師父並應當教誨弟子說：「你可前往遊方參學，多有廣大功德，可以禮拜諸佛塔廟，參見良善徒眾法侶，廣長見聞；我若非年邁力衰，也定當與你一同前往」等語。第五、和尚若對法義律法生起疑惑，弟子應當依據佛法與毘尼律藏，如法提請開導以消除師長的疑難。第六、和尚若生起不正邪惡的見解，弟子應當善加勸諫令師長捨棄惡見，安住於正法善見之中。第七、弟子應當以兩件事來護持照顧師父：所謂「法護」，應當啟請互勉增長增上戒學、增上心學（定）、增上慧學，精勤修學與讀誦經典；所謂「衣食護」，應當供奉給予衣服、飲食、醫藥，隨自己能力所能及者盡力為師長籌辦。這七種共行法，各大律部大多記載相同。《僧祇律》說：若和尚或阿闍梨有行非法之事，弟子不得以粗言惡語相向，如同訓誡晚輩那樣；而應當以柔和順適的言語勸諫師父：「此法應當作，此法不應當作。」如果和尚始終不接受規勸，弟子應當捨離和尚遠去他方；若是對依止阿闍梨，則應當手持衣鉢走出結界外過宿一晚然後再返回。如果和尚能夠除去弟子的貪瞋癡等三毒煩惱，這就稱之為至高無上的法乳「醍醐」，最尊最勝，弟子無論如何不得背離這樣的善師。其餘詳情廣如後文所載。《五分律》中記載：如果師父犯了僧殘罪，向僧團乞求作解罪羯磨，弟子應當主動打掃灑水、敷設坐席、召集僧眾、物色迎請主持羯磨的具德僧人。

【047-0004】01_行事鈔/03b_卷上之三#20
【原文】二明別行法三種。
【譯文】第二項、明示弟子的三種別行法。
