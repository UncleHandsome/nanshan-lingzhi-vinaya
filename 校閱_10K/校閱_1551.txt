# 校閱材料　第1551檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1551-0001】05_拾毗尼義鈔/04b_卷中之二#26
【原文】第二定體異者且論現前必有五法五法者何起諍名人秉法名僧僧住處名界軌用名法能滅名毗尼此有四解一解五名四體人僧界別有名體法與毗尼更無別體軌用邊名作法滅諍名為毗尼第二解五名四體少異言毗尼無別體用上四法為體故第三解五名五體既言五法故以調逆進不名法正殄於諍名毗尼問有法起時名作毗尼毗尼起時有法已息如何乃言五法現前答雖不竝頭而有相續在現故言現前第四解能所相對在現前故言五法僧界法毗尼是其能起諍者是其所要以能對所方有滅諍義得名現前毗尼故問為當四人已上作法一向具五法為當亦有不具者答義即不定如伽論云十種羯磨不現前但具四法何者覆鉢捨學家捨作房擯沙彌顛狂不禮不共語不供養等是也唯有僧界法毗尼毗尼者遠有諍義又說戒自恣等唯有僧界法如結大小界唯有僧法若三人已下作能滅者但須三種現除僧界設四人已上但使不秉羯磨者亦有三問五法中能斷通僧人但與一僧名所為通僧人隱僧彰人何答秉法故存僧名所中就數分實有僧別之位皆不秉法故從別名人問五中能所別故使僧人立二名者如三中亦有能所別何故不從能所立僧人答若就數分實應僧人立二但以別人及僧不秉羯磨處齊故同作人名若與僧名恐濫於作法故問瞻波中一人舉一人乃至僧舉僧皆不如法何故上云一人乃至為僧僧為僧皆如法者答瞻波中對羯磨治人是故皆非此中直是定理是非非治人故所以如法問既知五法未知五法中法毗尼人與三法中法毗尼人有何差別答五中法指羯磨法三中法者或是言語定是非為法或自言懺法名法三中人者起諍人及判諍人通名人現五中人者但取起諍人不取於僧其毗尼者勿不皆是諍無之處此是正體故五三同也若就詮相三五皆異何者五法中無指羯磨判滅為無名毗尼三法中無者言語判滅為無名毗尼或以自言懺滅名為毗尼汎論五三異者五法是寬三法是狹何者五法獨滅於言諍若配餘六通滅四諍三法不通故廣如別章。
【譯文】第二、判定滅諍法體的差異：若論「現前」，必定具備五法。何謂五法？一、引發諍端之人稱為「人」；二、秉持如法羯磨者稱為「僧」；三、僧團所居之處稱為「界」；四、運作的軌範法則稱為「法」；五、能止息爭端者稱為「毘尼」。對此有四種解釋：第一種解釋認為是五名四體，「人、僧、界」三者有名稱且有各自的體性，「法」與「毘尼」則沒有個別獨立的體性，在軌範運作方面稱為「作法」，在滅除爭諍方面稱為「毘尼」。第二種解釋同樣是五名四體但微有不同，認為毘尼沒有單獨的法體，是以前面四法的整體運作作為其法體。第三種解釋認為是五名五體，既然名為五法，便以「能調順、折伏、進退等儀軌」稱為法，以「正能斷絕消滅爭諍」稱為毘尼。問：作法生起之時稱為運作毘尼，當毘尼完全顯發時法事已經止息，如何能說五法同時現前？答：雖然不是在同一剎那並列，但有因果相續呈現在當前，所以稱為現前。第四種解釋是以「能治」與「所治」相對呈現在當前，所以稱為五法；僧、界、法、毘尼是能治，引發爭諍的人是所治；必定要以能治對應所治，才具有滅除爭端的作用，所以得名為「現前毘尼」。問：凡是四人以上的作法，是一概都具備這五法，還是也有不具備的情況？答：義理並不固定。如《伽論》說：有十種羯磨是人不現前而作，只具備四法：例如覆鉢、捨學家、捨造房、擯沙彌、顛狂（狂羯磨）、不禮拜、不共語、不供養等羯磨即是。這些羯磨只有僧、界、法、毘尼，所謂毘尼只是遠遠具有防諍止諍的意思。又如說戒、自恣等法，只有僧、界、法；如同結大界、結小界，只有僧與法。如果是三人以下進行滅諍，只需三種現前，去除「僧」與「界」；假使有四人以上，但只要不秉作羯磨，也只有三法。問：五法之中，「能斷諍」貫通僧團與個別之人，卻只給予「僧」的名稱；「所處理」的對象也貫通僧與人，為何隱去僧名而只標示為「人」？答：因為實際秉持戒法的是僧團，所以保留僧的名義；在被處理的對象中，就人數來分固然有僧眾與別人之位，但都不處於秉法之位，所以順從個別之稱而稱為人。問：五法中由於能治與所治有別，所以分立「僧」與「人」二名；而在三法之中同樣有能治與所治的分別，為何不依據能所立出僧、人二名？答：若就人數來分，確實應該分立僧與人二名；但因為此處個人與僧團皆不秉作羯磨，其地位平等，所以一律稱為人；若給予僧的名義，恐會與如法作羯磨的僧團相混淆。問：《瞻波羯磨》中說一人舉發一人乃至僧舉發僧，皆是不如法的；為何上文卻說一人乃至僧舉發僧都是如法的？答：《瞻波羯磨》所對治的是以羯磨來治罰人，所以那種做法都是不如法的；此處純粹是論定是非曲直，並非治罰當事人，所以是如法的。問：既然已知五法，不知道五法中的「法、毘尼、人」與三法中的「法、毘尼、人」有何差別？答：五法中的「法」專指羯磨法；三法中的「法」或是指以言教斷定是非之法，或是指自言懺悔之法。三法中的「人」包括引起爭端之人與裁斷爭端之人，通稱為人現前；五法中的「人」只取引起爭端之人，不包含作法的僧眾。至於「毘尼」，無一不是指爭諍止息的無諍境界，這是兩者共通的正體，所以五法與三法在這一點上相同；但如果就表現出來的儀相而言，三與五皆不相同：五法中的無諍，是指藉由羯磨裁決斷滅為無，稱為毘尼；三法中的無諍，是以言論判斷滅除為無稱為毘尼，或是以自言懺悔滅罪稱為毘尼。泛論五法與三法的差異：五法範疇較寬，三法範疇較狹。為什麼呢？因為五法能單獨滅除言諍，若配搭其餘六滅，通滅四種諍端；三法在此則無法通達，詳細如別章所明。
