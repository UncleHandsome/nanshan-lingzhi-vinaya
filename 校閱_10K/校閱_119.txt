# 校閱材料　第119檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【119-0001】01_行事鈔/06b_卷中之二#22
【原文】取非親尼衣戒四。具五緣：一是比丘尼。簡下二眾，取得吉羅。二非親里。律云：親里者，父母親里七世有親也。《善見》：父親者，伯叔兄弟兒孫；母親者，舅姨乃至兒孫。皆謂同氣義親，不雜異姓。又云：出家婦者，非親里也。伯叔之婦例同。《十誦》云：若是親里，少尚持與，何況不足而取。《五分》：若親里尼犯戒，取衣者吉羅。三應量衣。律中，五衣中取一衣，故為犯緣。《僧祇》：若取鉢及餘小小物，得無犯。四虛心送與，除乞得，無犯。《僧祇》：尼借比丘衣，得著破還，無犯。若尼與下二眾及俗人衣，云汝持此衣與某甲比丘，可得福德；取者，無犯。五領受已。《伽論》：尼放衣置地，寄大德，隨意用！便捨去；比丘作同意用，無犯。《僧祇》：使人受同犯。《十誦》、《多論》：十僧取尼一衣，十僧皆墮；十尼持一衣與一僧，得十墮。《十誦》：若尼先請，若為說法故與，一切無犯。《五分》：諸尼以衣鉢施比丘，若先無心求，彼自布施者，當觀，有長者得取。準此，犯戒止在貪心，制戒之意可見。《四分》亦云：佛告尼言，當畜五衣完堅者，餘衣隨意淨施，若與人。既云與人，則何簡於道俗。律不犯中，若從親里比丘尼邊取衣，若貿易，為佛圖及僧取者，皆不犯。
【譯文】取非親尼衣戒四。具五緣：第一是比丘尼。簡別於式叉摩那、沙彌尼這下二眾，從她們處索取衣服只得突吉羅（惡作）。第二是非親里。律文說：親里，是指父母親族在七世之內有血親者。《善見律毘婆沙》說：父親方面的親族，是指伯父、叔父、兄弟、兒孫；母親方面的親族，是指舅父、姨母乃至兒孫。都是指同氣連枝的直系宗親，不摻雜外姓姻親。又說：出家前原本的妻子，不屬於親里。伯父、叔父的妻子以此類推。《十誦律》說：如果是親戚，衣服少尚且要拿給她，何況是她不足時卻還去索取。《五分律》說：如果親戚比丘尼犯了戒，從她那裡取衣者得突吉羅。第三是合乎度量的應量衣。律中指在比丘尼五衣之中索取任何一件衣服，所以構成犯戒的因緣。《摩訶僧祇律》說：如果拿取的是缽以及其餘微小物品，得以無犯。第四是比丘尼出於謙下不求果報之誠心（虛心）而主動贈與；若是比丘主動求乞而得到的，則歸另一條乞衣戒結罪，本戒無犯。《摩訶僧祇律》說：比丘尼借比丘的衣服，穿破損了歸還，不犯。如果比丘尼把衣服交給下二眾或俗人，說「你把這件衣服送給某甲比丘，可以得到福德」；比丘接受的，不犯。第五是已經領納接受。《薩婆多毘尼摩得勒伽》說：比丘尼把衣服放在地上，說「寄放在大德處，請隨意使用！」說完便離去；比丘當作「同意用（以親友意取用）」而使用的，不犯。《摩訶僧祇律》說：差遣他人代替接受，同犯捨墮。《十誦律》、《薩婆多論》說：十個僧人共同接受一個比丘尼的一件衣服，十個僧人都犯捨墮；十個比丘尼拿一件衣服給一個僧人，該僧人得十個捨墮罪。《十誦律》說：如果比丘尼事先邀請請求，或者為了答謝比丘說法而贈與，一切都不犯。《五分律》說：比丘尼們以衣缽布施給比丘，若比丘事先無心索求，是對方主動布施，應當觀察，若有多餘長物便可接受。由此看來，犯戒關鍵純在貪心，制戒之意由此可見。《四分律》也說：佛陀告訴比丘尼，應當蓄存完整堅固的五衣，其餘衣服隨意作淨施，或贈送給他人。既然說了「給予他人」，何須分別僧道與俗人？律文不犯條款中：若從親族比丘尼處取衣，或進行貿易交換，或是替佛塔及僧團索取者，都不犯戒。

【119-0002】01_行事鈔/06b_卷中之二#23
【原文】使非親尼浣故衣戒五。浣、染、打，實是三戒，同由一衣生。此戒業重。律云：語使浣染打，若作者，三尼薩耆波逸提。五緣成：一是比丘尼。若是下二眾，律結小罪。二非親里。《善見》：令出家婦浣染亦犯；若使尼煖水覓樵鑽火，一切吉羅。《五分》：令非親尼浣，而親里浣；如是互作，五句皆墮。《僧祇》：若使尼為師浣者，吉羅。今或有人畜尼弟子，多令浣縫；以非俗親，皆犯捨墮；亦誤弟子因交致染，遂犯重罪，深須慎哉。三是己故衣。律云：乃至一經身著者。《僧祇》云：乃至一枕頭。《善見》：若革屣囊，無犯。《伽》中，乃至尼師壇，亦犯捨墮。四自使浣打。《僧祇》：自與使與等四句皆犯。若使親尼浣，而弟子為浣，不犯；若云，遣汝弟子為我浣者，犯。若著垢膩衣入尼寺，為浣者，不犯；若先有方便心者，犯捨。《十誦》：若犯捨衣與浣，犯小罪。準此無重犯。一衣無過有重犯。《僧祇》：若為車馬灒污，使尼湔，亦犯捨；不可截故，全捨。五浣染打竟，便犯。《四分》：使浣打新衣，及使尼家二眾，俱吉羅。《善見》云：若浣竟，比丘言未淨，重使尼浣，比丘尼薩耆、吉羅。不犯中，律云：若病，若為佛僧，若借他衣而尼浣等，不犯。
【譯文】使非親尼浣故衣戒五。洗滌、染色、捶打，實際上是三條戒，同由同一件衣服引發。這條戒的罪業很重。律文說：吩咐使喚其洗滌、染色、捶打，如果全做了，得三個尼薩耆波逸提。具足五種因緣構成：第一是比丘尼。如果是式叉摩那、沙彌尼這下二眾，律中結犯小罪（突吉羅）。第二是非親里。《善見律毘婆沙》說：命令出家前的妻子洗染也犯；如果支使比丘尼燒熱水、找柴火、鑽木取火，一切都犯突吉羅。《五分律》說：吩咐非親屬比丘尼洗，而由親屬比丘尼洗；像這樣互相替換操作，五種句型全都犯捨墮。《摩訶僧祇律》說：如果支使比丘尼為自己的剃度師父洗衣者，得突吉羅。如今有的人蓄養比丘尼弟子，多半差遣她們洗衣縫紉；因為並非俗家的血親，全都犯捨墮；同時也耽誤害了弟子，因為往來接觸而招致染污心，以致犯下重罪，深切需要審慎警惕啊！第三是自己的舊衣。律文說：甚至只要穿過在身上一次的就算。《摩訶僧祇律》說：甚至只墊過一次頭當枕頭的就算。《善見律毘婆沙》說：如果是皮鞋袋，不犯。《薩婆多毘尼摩得勒伽》中說，甚至坐具（尼師壇），也犯捨墮。第四是親自支使去洗滌或捶打。《摩訶僧祇律》說：親自交給、吩咐他人轉交等四句都犯。如果吩咐親屬比丘尼洗，而由她的弟子代為洗滌，不犯；但若說「打發你的弟子為我洗」，就犯戒。如果穿著油垢骯髒的衣服進入比丘尼寺，對方主動為之洗滌的，不犯；如果比丘事先就存有誘導對方幫忙的企圖心，便犯捨墮。《十誦律》說：如果拿已經犯了捨墮的衣服交給她洗，只犯小罪。照此看來不會有重複犯重罪的情況。這一衣戒則屬於「無過而有重犯」之例。《摩訶僧祇律》說：如果被車馬濺起泥水弄髒，支使比丘尼洗滌污漬，也犯捨墮；因為衣服不能裁剪，所以整件衣服都要捨棄。第五是洗滌、染色、捶打完畢，便構成犯戒。《四分律》說：支使洗滌捶打新衣服，以及支使比丘尼寺中的下二眾，都得突吉羅。《善見律毘婆沙》說：如果洗滌完畢，比丘說還不乾淨，重新支使比丘尼再洗，比丘得尼薩耆波逸提及突吉羅。在不犯條款中，律文說：如果生病，如果是為了供養佛或僧團，如果是借別人的衣服而比丘尼主動幫忙洗滌等，不犯。
