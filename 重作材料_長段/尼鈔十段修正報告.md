### 01　key `06`（序文，443 字）

| 問題 | 修正 |

| 「齊魯二變」譯成兩國各經兩番轉變 | 改依《論語》「齊一變至於魯，魯一變至於道」，明為循序漸進 |
| 「故逆止於內心，恐將生於外結」譯成「在心裡遮止」 | 改讀「逆止於內，心恐將生於外結」：預先遮止不令出家，心裡顧慮她們在外境生起結縛 |
| 時序讀成「先減五百，再阿難憂泣」 | 「正法理合千年……減其五百」作插敘評論；阿難請度以「先是」追述，時序不再倒錯 |

### 02　key `158`（式叉摩那行法）

- 結尾懸空冒號 → 「……長跪合掌，作如是說。」（原文以「云。」收，不譯成「說：」）。
- 「此律」統一譯《四分律》。
- 「除火淨、五生種、取金銀」改寫為**授食職務邊界**：「作火淨、淨五生種、取金銀這三類事不在授食的職務範圍之內」，不再讀成三條個人禁忌。
- 第七（布薩日）、第八（自恣日）分列，不再合寫成「第七、第八」。

### 03　key `333`（受囑教誡）

- 結尾懸空冒號 → 「打靜之後，作白。」。

### 04　key `438`（攝受法）

- 「本律《四分律》」→《四分律》（全篇統一）。
- 《善見論》→《見論》，《五分》→《五分律》，《僧祇》→《僧祇律》，《十誦》→《十誦律》。

### 05　key `472`（汙家擯謗違諫戒）

### 06　key `521`（剃三處毛戒）

- 「剃三處毛」補夾注：「（三處指大小便處及腋下）」。
- 「若斷一一毛，一一吉羅」與「若斷餘毛，一一偷蘭」分開：前者是木刀刮汗斷毛的突吉羅，後者是剃頭毛以外之毛的偷蘭遮。
- 「若髮長者」→「頭髮長了」（條件句，不是「頭髮長的人」）。
- 刪去「刮除刀上的污垢」——《資持記》釋《行事鈔》「刮刀」之語，尼鈔原文無此句；「手上波」只譯「在手掌上如波浪般往復翻動」。
- 《毘尼母論》→《母論》，《涅槃經》→《涅槃》，《五分》→《五分律》，《十誦》→《十誦律》，「此律」→《四分律》。
- 補夾注「今時多有僧尼諂心求利，受俗驅使，敗壞善法、增長惡業，沒有超過這些人的」。

### 07　key `640`（乞懺）

### 08　key `720`（供侍病人）

- 「犯重」→「犯重罪」二處（原文只作「犯重」）。
- 「此律」→《四分律》，《善生經》→《善生》，《五百問事經》→《五百問事》。

### 09　key `769`（僧物五類）
