== PROBLEM ==
典籍名稱譯錯、張冠李戴。原文「《伽論》三人」指《薩婆多部毘尼摩得勒伽論》（簡稱《伽論》或《摩得勒伽論》）列出三人，譯文誤譯為「《僧祇律》列出三人」，導致與後句「《僧祇》」重複混淆。

== SUGGESTION ==
將前句「《僧祇律》列出三人」更正為「《摩得勒伽論》（伽論）列出三人」。

== ORIG ==
`具二者，瘂聾兼也。……《伽論》三人。取其異者，同則指前。然彼有轉根人，即落第二尼中，故不重引。《僧祇》。前五如後解。`

== CURRENT ==
具備兩種情況的，是啞與聾兼具之人。結語文字抄寫有誤，應當說是十一人；然而彼處實際上載有十二人，而白衣居士一人，由於戒體非法的緣故，被抽離歸入後面的科判。其餘情況如同後文的解釋。《僧祇律》列出三人。選取其中不同之處，相同者則指向前文。然而彼處有轉根之人，那就歸入了第二條例的比丘尼之中，所以不再重複引用。《僧祇律》中所列的，前五種情況如同後文的解釋。所謂互相更替而違犯，就是在四種威儀中隨舉一種威儀來作法，其餘三種便形成別眾；那麼一種威儀就有三種相違，歷遍推算便為十二種；
