# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【259-0001】02_戒疏/13b_卷三下之一#101
【原文】【疏】「僧作羯磨」者，此得法離，開前無法也。「明相未出」下「至擲石所及處」，反解上開也。「若奪想」者，衣實現在，忘起奪想，經宿失受，約心無罪。決心謂失，即是捨心；無情過故，不犯捨也。「若水陸道斷」者，乃至「強執」，並隔礙也。「或命梵難」下，此情染礙故不會，非是慢情故令隔絕。
【譯文】【疏文】「僧眾作羯磨法」這一條，屬於得法離衣，是為了開許前面沒有如法儀軌即不得分離的規定。「天明未出」以下到「至擲石所及處」，是反過來解釋上文開許的條件。「若奪想」這一條，是指衣物實際上還在，卻妄生已被搶奪的念頭，經過一夜便失去了受持，但依據其心理來說並無犯罪之意。既然下定決心認為衣物已失，當下就是捨衣之心；因為沒有放逸放任的過失，所以不犯捨墮罪。「若水陸道斷」乃至「強者所執」，都屬於外在環境的隔絕障礙。「或命難、梵行難」以下，這是因為貪染危難等心理障礙而無法前去交會，並不是出於怠慢放逸的心情而故意隔絕。

【259-0002】02_戒疏/13b_卷三下之一#102
【原文】【記】牒釋中。初科五段。初釋羯磨。「開前無法」，即上犯位。二、釋奔護。「反解上開」，即前注中已列三緣，開通覆示，故云「反解」。三、釋奪想。失法無罪，亦同隔塞望斷之義。「忘」合作妄，謂虗想也。四五二段，即約三礙，配之可見。
【譯文】【記文】在引述解釋中，第一科分為五段。首先解釋羯磨。「開許前面無法」，是指上面的犯戒情境。第二、解釋奔走防護。「反過來解釋上文開許」，是指前面注文中已經列出三種因緣，此處反覆推求開示，所以說是「反解」。第三、解釋奪想。失去受持之法卻無罪，也等同於道路隔絕斷絕指望的意思。「忘」字應作「妄」，是指虛妄的猜想。第四與第五兩段，就是依照三種障礙來配對解釋，理路清晰可見。

【259-0004】02_戒疏/13b_卷三下之一#104
【原文】【疏】答：「此相極多。今以情過行相急緩。若恒謹攝，無思離犯，忽遇難緣人衣乃異，無心捨離但為事壅，據此論心則不名犯。若情慢惰，諸緣捨受，隨衣所離有捨有犯。如上《母論》說淨無限之科。」
【譯文】【疏文】回答：「這種情況極其繁多。現在應當依據內心過失與行持緩急之相狀來判定。如果平時行持極為嚴謹檢點，從無違犯離衣戒的想法，忽然遭遇險難導致人與衣物分處異地，心中絕無捨離之意，純粹是因為客觀事緣的壅塞阻隔，依據這種心態來論斷，就不稱作犯戒。如果心情怠慢懶惰，藉著各種由頭放棄受持，那麼隨著衣物脫離所在，有的失法、有的犯戒。這就如同上面《毘尼母論》所判定說淨無限期的科則一樣。」

【259-0005】02_戒疏/13b_卷三下之一#105
【原文】【記】問中。「失與犯者」，「失」謂失法，「犯」即犯罪。答中。初通示。「若」下，別釋。初約行急通開。「壅」，即礙也。「若情」下，次約行緩還制。文中二「捨」字，即是「失」也。「如」下，引類。《母論》不行說淨，不開十日。
【譯文】【記文】在提問之中。「失與犯」，「失」是指失去受持之法，「犯」是指構成犯罪。在回答之中，首先通盤說明。從「如果平時」以下，個別進行解釋。首先就精進急迫的行持來通融開許。「壅」，就是阻礙。「如果心情」以下，接著就鬆散遲緩的行持回歸戒律制約。文中出現的兩個「捨」字，其實就是「失去」的意思。從「這就如同」以下，引用同類例子。《毘尼母論》規定若不實行說淨，就不能開許長衣十天的期限。

【259-0010】02_戒疏/13b_卷三下之一#110
【原文】【疏】答：「亦如兩望。必勤奉持，忘非可學，夜忽憶得，取會無緣，明即求取，非捨非犯。若作失捨，則心隔境異，故失非犯，犯隨情教，本忘非違。」
【譯文】【疏文】回答：「這也同樣取決於兩種希望與心態。若是平日精勤奉持戒律之人，遺忘並非刻意所學，半夜忽然想起來，在現實因緣下無法趕去交會，天亮便立刻前往尋取，這種情況既不失法也不犯戒。如果心中作失落想或捨棄想，則心念已隔絕、對境已異，所以只算失去受持之法而不犯戒。罪責是隨著放任的情思而判定的，原本出於遺忘並非故意違犯。」

【259-0011】02_戒疏/13b_卷三下之一#111
【原文】【記】次問中。欲以長忘例開離衣，故申此問。答中，「亦兩望」者，準前勤、墯也。此復有二。初明緣礙。心不斷故，非失非犯。「若」下，次明想失。即前望斷，失法非犯。準知墮者，亦失亦犯。
【譯文】【記文】接著在提問之中，提問者想要以長衣因忘開許的例子，來類推離衣戒的開許，所以提出此問。在回答之中，「同樣取決於兩種」，是指比照前面所說的勤奮與懈怠。這又分為兩種情況：首先說明客觀緣由造成的障礙。因為守護之心並未中斷，所以既不失法也不犯戒。從「如果心中」以下，接著說明猜想遺失的情形。這就是前面所說的斷絕指望，只失去受持之法而不算犯戒。由此可知若是懈怠放逸之人，則是既失法又犯戒。

【259-0012】02_戒疏/13b_卷三下之一#112
【原文】【疏】但衣、食兩戒，疏者偏懷，末代相持，唯斯二矣。自餘諸戒，多或離之。衣食之間，無日不奉，奉者如法，蓋不足言。莫怪多及。意所未盡，如所撰《事鈔》及《羯磨疏》中，衣、食二緣，廣有誠教。自餘約略，僅知而已。
【譯文】【疏文】只是衣與食這兩條大戒，疏主偏加留意關懷；末法時代所共持護的，唯獨這二戒而已。自餘各戒，多可離而不犯。於衣食二事之間，無日不須奉持，能如法奉持者本不足言多（實極少見），故莫怪多所涉獵。意猶未盡之處，正如我所撰寫的《事鈔》以及《羯磨疏》之中，關於衣、食二緣，廣有真實明確之教誡。其餘戒條則約略敘述，使人勉強得知大意而已。

【259-0013】02_戒疏/13b_卷三下之一#113
【原文】【記】結誥中。二，初明須廣之意。「衣食戒」者，提下諸篇多由衣食，一則貪情因發，二乃日別常行。凡此等戒，委曲辨之，故云「偏懷」，言最留意也。「相持」，謂隨事攝護，即前所謂「遺法所重，唯相及行」是也。「自餘諸戒」，即非衣食制者。「多或離之」，言其過境非數見故。「奉者如法不足言」者，反明少能如法，故須言也。「莫」下，二、顯略。《事鈔》離、長、別眾等戒，并下卷《二衣》、《四藥》、《赴請》等，《疏》即衣、食二界，并《衣藥受淨》等，文皆繁廣。已聽者可知，未聽則自檢。「僅」，纔也

【259-0017】02_戒疏/14a_卷三下之二#4
【原文】【疏】制意者。凡為資身，隨時受服。雖有故者，不堪著用，但止受持，故聖開畜，擬換故者，少而不足，為待滿故，重開一月，足即成衣。既同衣足，理宜受替，乃畜過限，違反聖教，壞少欲法，所以制也。
【譯文】【疏文】制戒旨趣：大凡資助身體的衣物，應當順隨時節領取穿著。雖然舊衣已不堪穿用，但因只能依法受持三衣，所以聖者佛陀開許蓄留布料，預備替換破舊衣物；若所得布料過少不足以製成一衣，為等待籌足的緣故，特別再次開許蓄留一個月，只要籌足便應裁製成衣。既然布料已經足夠製衣，理應受持新衣以替換舊衣，卻蓄留超過規定期限，這就違背了聖者教法，敗壞少欲之德，因此制定此戒。

【259-0019】02_戒疏/14a_卷三下之二#6
【原文】【疏】五緣成：一、本有故爛三衣，若新好者，畜犯前戒；二、聽畜餘財，擬替故者；三、同財已足，故不割截；四、無因緣；五、過限犯。
【譯文】【疏文】具備五緣構成犯相：第一、原本就具備破舊的三衣，若是新好之衣，蓄留則犯前一條長衣戒；第二、聽許蓄留多餘布料，預備替換舊衣；第三、同類布料已經齊足，所以不再剪裁留待；第四、無有障礙因緣；第五、蓄留超過期限即構成犯戒。

【259-0020】02_戒疏/14a_卷三下之二#7
【原文】【記】具緣中。初緣。此戒本由衣壞替換，故開一月。衣若新好，則非所開。又三衣中，隨有一壞則開，不必俱壞。第三，「同財」，謂體、色同者。言「已足」者，準下三位。此據初、二兩位。若第三位，無問同不同、足不足，皆犯也。餘並如下。
【譯文】【記文】在具緣說明中。第一緣。這條戒原本是因衣物破壞需要替換，所以開許蓄留一個月。衣物若是新好完整，就不是開許的對象。此外，三衣之中，只要有一件破壞就開許，不必然三件全部破壞。第三緣，「同財」，是指布料材質、顏色相同的資具。所謂「已足」，依照下文所分的三個時期來判定。此處是依據第一、第二兩個時期而言。如果是第三個時期，無論同不同、足不足，蓄留過期都算犯戒。其餘各緣皆如下文所釋。

【259-0021】02_戒疏/14a_卷三下之二#8
【原文】【註】佛在舍衛國。但三衣比丘有僧伽棃故爛，十日中間便不能辨，聽畜長衣，為滿足故。六群比丘取同衣不足者，浣染點淨，寄人遊行。比丘舉過，佛訶制戒。
【譯文】【註文】佛陀在舍衛國。當時有位唯持三衣的比丘，僧伽梨（大衣）破爛了，十天之內無法籌齊足夠布料，佛陀聽許他蓄留多餘的長衣布料，為了籌足所需。六群比丘便拿同類材質但尚不足製衣的布料，予以清洗、染色並作淨點，寄託他人處而四處遊行。其他比丘揭發此過失，佛陀予以訶責並制定此戒。

【259-0022】02_戒疏/14a_卷三下之二#9
【原文】【疏】就緣起中。本是「但三衣」人，為衣破故，縱得衣財，十日之內不足不成，所以齊月來畜，「為滿足故」。六群聞之，因遂起過，取「同衣不足者」。如《十誦》云「以色不同，體不相似，故犯」。今制但令得作，何待色、體俱同也？
【譯文】【疏文】在制戒緣起中。最初是「唯持三衣」的頭陀行者，因為衣物破損，縱然得到做衣的布料，十天之內仍不足以裁縫成衣，所以限定在一個月內蓄留，「為了籌足所需」。六群比丘聽聞此例，便藉此生起過失，收取「同類材質但不足製衣」的布料。如同《十誦律》所說「因為顏色不同，材質不相類似，所以犯戒」。如今這條戒的規定，只要能做成衣服即可，何必非得顏色、材質完全相同呢？

【259-0023】02_戒疏/14a_卷三下之二#10
【原文】【記】釋戒緣中。初敘本開。「但三衣人」不畜餘長，故特開之。畜長比丘，此教不被，則無有犯。「如」下，引釋同衣。彼云「若得青衣，後得黃、赤衣」，是「色不同」，又「初得麻，乃至後得欽婆羅、劫貝」，即「體不相似」，皆犯。「今」下，準上《十誦》以決戒緣。
【譯文】【記文】解釋制戒緣起中。起初敘述原本開許的由來。「唯持三衣的人」平時不蓄留多餘長衣，所以特別對他們開許。若是平時本就蓄長衣的比丘，此條教敕不適用於他們，也就不會犯這條戒。「如」字以下，引律文解釋同類布料。彼處說「若先得青衣，後來得到黃、赤色衣」，就是「顏色不同」；又「起初得到麻布，乃至後來得到欽婆羅毯、棉布」，就是「材質不相類似」，這都會犯戒。「今」字以下，標準依據前引《十誦律》來裁斷戒緣。
