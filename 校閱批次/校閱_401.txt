# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【401-0001】02_戒疏/21b_卷四下之三#63
【原文】【記】二、正宗分，第一佛，上半偈中，初科又二。初釋上句。前通列三忍：「法思惟」者，謂於諸法，安忍思擇，而不勞倦；二、「他不益」者，彼怨加害，而不反報；三、「安苦」者，眾苦逼迫，安然忍受。今釋「忍辱」，即當第二，梵語「羼提」，此翻「忍辱」。「行功強」者，《經》云：「忍之為德，持戒苦行，所不能及。」、「因不」下，次釋下句。「無為」即目涅槃自體。「諸相」即生、住、異、滅四相，簡諸有為，隨相遷變，有壞滅故。
【譯文】【記文】第二科正宗分，第一尊佛，前半首偈中，第一科又分為兩部分。起初解釋上半句。前面普遍列出三種忍辱：「法思惟」是指對於諸法，安住耐受而審慎思擇，而不疲倦懈怠；第二「他不益」是指他人怨恨加害時，絕不尋求報復；第三「安苦」是指種種痛苦逼迫時，能夠安然忍受。現在解釋「忍辱」，正當於第二種，梵語「羼提」，此處翻譯為「忍辱」。「行功強」，佛經說：「忍辱的功德，持戒與苦行都無法比擬。」從「因不」以下，接著解釋下半句。「無為」就是指涅槃的自體。「諸相」就是指生、住、異、滅四相，簡別所有有為法隨著這些行相變異遷流，具有毀壞滅亡的特質。

【401-0010】02_戒疏/21b_卷四下之三#72
【原文】【疏】「此是毗婆尸」者，顯前所說有劫佛名也。此佛在賢劫前九十一劫出世。由中間劫空，故遠取有劫佛，以成七世也。乃至後彌勒佛興，即以尸棄為第七之祖也。如是廣知。本曰「毗婆尸」，或曰「婆沙」、「鉢沙」，此譯同為廣說也。
【譯文】【疏文】「這是毗婆尸」這句，是標明前面所說的有劫時代的佛陀名字。這位佛在賢劫之前的第九十一劫出世。因為中間歷經了空劫，所以遠遠選取有住劫時期的佛，以湊成七世之數。乃至將來彌勒佛出世時，就以尸棄佛為第七代祖師。其餘情況依此類推。梵文原本稱為「毗婆尸」，或者稱為「婆沙」、「缽沙」，此處翻譯都同樣是指廣博說法的意思。

【401-0011】02_戒疏/21b_卷四下之三#73
【原文】【記】題名中。初總示。「毗婆尸」，如下自翻。「此」下，別釋。初明劫數，此依《長阿含經》所列，下六並爾。此佛出世，三會說法，度三十四萬八千人。「賢劫」者，慈恩《劫章》云：「即此住劫稱賢劫，二十劫中第九劫。」此界成後，有千佛出世，既多賢聖，故名「賢劫」。「在前九十一劫」者，謂跨過空劫，逆數壞、住、成，更跨一空劫，復取壞為八十劫，即當前住劫第十劫，故云「遠取有劫」等。欲順世諦，以「七」為祖故也。彌勒興時，除毗婆尸，故「以尸棄為第七」。若據相承，合云「第一」，此約從親至踈，以釋迦為始，遠劫為第七也。乃至後佛出世，第減亦然。「本」下，翻名。梵言三別，「毗」字並同，故下二不舉，《智論》亦云「鞞婆尸」，此翻種種具。
【譯文】【記文】在標示名字中。起初總體明示。「毗婆尸」，如同底下自身的翻譯。「此」以下，個別解釋。起初說明劫數，這是依據《長阿含經》所排列，底下六尊佛也是如此。這位佛出世時，舉辦了三次法會宣說法要，度化了三十四萬八千人。「賢劫」，慈恩大師《劫章》說：「當前的住劫稱為賢劫，是二十劫中的第九劫。」這個世界成就之後，有一千尊佛出世，既然多有賢聖，所以名為「賢劫」。「在前九十一劫」，是指跨過空劫，逆向推算壞劫、住劫、成劫，再跨過一個空劫，又取壞劫算為八十劫，正相當於前一個住劫的第十劫，所以說是「遠遠選取有住劫」等。這是為了順應世間觀念，以「七」代為宗祖的緣故。彌勒佛出世時，除去了毗婆尸佛，所以「以尸棄佛為第七代」。如果根據歷史傳承，理應稱為「第一代」，但這裡是由近至遠推溯，以釋迦佛為起點，遠劫的佛則退居第七。乃至未來佛出世，依序遞減推移也是如此。「本」以下，翻譯名字。梵語有三種音差，「毗」字都相同，所以下面兩種不再列舉，《大智度論》也稱為「鞞婆尸」，翻譯為具備種種圓滿。

【401-0012】02_戒疏/21b_卷四下之三#74
【原文】【疏】二、「如來、無所著、等正覺」者，佛德難窮，略陳三號，解釋如常。
【譯文】【疏文】第二、「如來、無所著、等正覺」這句，佛陀的功德無窮無盡，此處簡略陳列三種德號，其解釋如同通常所說。

【401-0013】02_戒疏/21b_卷四下之三#75
【原文】【記】次舉號中。《成論》云：「乘如實道，來成正覺，故名『如來』。」此謂從真垂應為名。結惑永盡，故名「無所著」。道同三世，故名「等正覺」。若對三身：初應，二報，三法。亦即解脫、般若、法身三種德也。若對十號，彼無第二，又「等正覺」即彼佛號，華、梵各舉耳。
【譯文】【記文】接著在舉出德號中。《成實論》說：「乘著如實的正道，來成就正等正覺，所以稱為『如來』。」這是指從真如法身顯現應身而得名。結縛煩惱永遠斷盡，所以稱為「無所著（阿羅漢）」。所證悟的大道與三世諸佛平等無異，所以稱為「等正覺」。如果對應於三身：第一是應身，第二是報身，第三是法身。也就是解脫、般若、法身這三種功德。如果對照十種通號，那裡並沒有第二個名號，而且「等正覺」就是那尊佛的德號，只是漢語與梵語各自並列舉出而已。

【401-0033】02_戒疏/21b_卷四下之三#95
【原文】【疏】同住檢行，稱根而舉，名「不謗」。又解，稱法而談，無顛倒過，不非聖說，故曰「不謗」。見他名利，口無譏毀，名「不嫉」也。二過既無，理資行本，故「當奉戒」也。
【譯文】【疏文】同住檢察行為時，能稱合實情根由而舉發過失，稱為「不謗」。另一種解釋，是稱合正法而宣談，沒有顛倒過失，不違背聖者所說，所以稱為「不謗」。見到別人的名譽利益，口中沒有譏評毀損，稱為「不嫉」。這兩種口過既然都已免除，在道理上就能資助修行的根本，所以「應當奉持戒律」。

【401-0034】02_戒疏/21b_卷四下之三#96
【原文】【記】第三佛，初止行，上半中。初釋「不謗」有二義。前約舉罪釋，後約說法釋。「顛倒」、「非聖」，即名「謗法」，高座講說，寧不慎乎？「見」下，次釋「不嫉」。「行本」，即目「戒」也。
【譯文】【記文】第三尊佛，起初止惡修行，前半首中。起初解釋「不謗」有兩種含義：前面是依據舉發罪過來解釋，後面是依據宣說教法來解釋。「顛倒」、「非聖」，就稱為「謗法」，登上高座講經說法，難道能不謹慎嗎？「見」以下，接著解釋「不嫉」。「行本」，就是指「戒律」。
