# 校閱材料（含提示詞）

以下提示詞請連同材料一起貼給 AI：

律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【段N】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【編號與來源】
材料每段的編號形如【01-0150】，橫線前是第幾檔、後面是該檔內序號，全書唯一。
回報時標題要同時抄下編號與來源，例如：
### 01-0150｜資持記/01c_上一上#18｜P0｜類型
- 編號與來源都要原樣複製，不可只寫「段150」，也不可自行重編。
- 同一段有多個問題時，重複使用同一個編號與來源。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### 段NNN｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

批次結尾固定寫兩行：
已檢查 N／M 段（M 是本檔實際段數，請先數一遍材料有幾段）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單，不許略過不寫。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例

【166-0001】02_戒疏/08b_卷二下之一#61
【原文】【記】釋改觀中，初科。「禪法」亦即觀門，故以「觀」釋。但止心名禪，照境為觀，不淨、數息，並具二門。而注文前後異者，以不淨正取照境，數息偏在止心故也。
【譯文】【記文】在解釋改換觀法的第一小科中。「禪法」也就是觀門的一種，所以用「數息觀」來解釋。只是止歇妄心稱為「禪」，覺照境相稱為「觀」，不淨觀與數息觀，實際上兩者都具備止與觀兩門。而注文在前後用詞上有所不同，是因為不淨觀主要著重在覺照境相，數息觀則偏重在止息妄心。

【166-0002】02_戒疏/08b_卷二下之一#62
【原文】【疏】所以改觀者。前對多貪，故說不淨，思覺之人，本非彼治，故說數息。或前觀色是麤，今觀心是細也。
【譯文】【疏文】之所以變換觀法的原因。前面是針對貪欲深重之人，所以宣說不淨觀；對於心懷尋思覺知、散亂不定的人，不淨觀本來就不是對治良藥，所以改說數息觀。或者也可以說，前面觀照色身是粗糙的境界，現在觀照心念是微細的境界。

【166-0003】02_戒疏/08b_卷二下之一#63
【原文】【記】顯意中，有二。初約機宜對病加藥，「或」下，次就所觀以分麤細。了色求心，先麤後細，自淺至深，故宜改也。
【譯文】【記文】在顯露立教意趣中，包含兩點。首先是就根機適合與否，對應病症換用藥石；從「或前觀色」往下，則是就所觀照的對象區分粗與細。看破色身進而省察心念，先從粗顯到細微，由淺顯漸入深妙，所以應當改換。

【166-0004】02_戒疏/08b_卷二下之一#64
【原文】【疏】就明數息，如《論》廣之，一數、二隨、三止、四觀、五還、六淨。並息亂法，以漸調心。
【譯文】【疏文】具體說明數息的方法，如同論典所廣泛闡述的，分為：一、數息，二、隨息，三、止息，四、觀息，五、還息，六、淨息。這六個步驟全都是止息散亂的法門，以此循序漸進地調伏心性。

【166-0005】02_戒疏/08b_卷二下之一#65
【原文】【記】示法中。大小乘論，並有觀法，故今通指，但云「如論」。今依《成論》釋，云「數」者，名出、入息，從一至十。數有三種：若等，若過若減。「隨」者，心隨息出入。「止」，謂令心止住出入息也。「觀」，謂見息繫身，如珠中縷。「還」，亦云轉，謂轉身緣心，令心現前。「淨」，謂離一切煩惱諸難，心得清淨。「並」下，總結觀意。
【譯文】【記文】在開示修法中。大乘與小乘的論典，都包含這套觀法，所以此處通泛指出，只說「如論典所說」。現在依據《成實論》來解釋，所謂「數」，是指稱念出入之氣息，從一數到十。數法有三種：剛好相應、數得過多、數得不足。「隨」，是指心念緊緊跟隨呼吸出入。「止」，是指讓心念凝止安住在呼吸的進出上。「觀」，是指覺照觀見氣息繫縛在肉身之上，就像貫穿在珠串中的細繩。「還」，也叫做轉，是指將緣取身息的心念轉移回來，使本心清明現前。「淨」，是指遠離一切煩惱染污與各種障難，自心獲得徹底清淨。從「並息亂法」往下，總結說明修觀的根本宗旨。

【166-0010】02_戒疏/08b_卷二下之一#70
【原文】【疏】答：「佛說不淨，令厭苦本，若欲修斷，必識身因。如何未斷集因，即除苦本？非唯果不可盡，乃使迷因轉深。故使修行非道，大可訶也。如經說身有苦，不說厭離於身，斯良證矣。」
【譯文】【疏文】回答：「佛陀宣說不淨觀，是為了讓人厭離苦難的根本；如果要修行斷除它，就必須深切了知這個肉身的因緣本末。為什麼在還沒有斷除招致痛苦的集因之前，就急於去消滅這個受苦的報身根本呢？這樣不僅無法斷盡苦果，反而會使人對因果業報的執迷更加深重。導致修行走入邪僻盲目的歧途，這太值得嚴厲喝責了。就像佛經中說肉身存在無量痛苦，但絕沒有說過要直接厭棄毀滅這個肉身，這就是極好的明證。」

【166-0011】02_戒疏/08b_卷二下之一#71
【原文】【記】呵責中。問中，隨順無違，反遭呵責，義似非當，故問決之。答中，為四。初明教旨，「如何」下，顯過。今亦有僧，不知所以，自投焚溺，欲冀超昇。苦因未除，寧亡三有之報？死而無悔，實唯一勇之夫。將謂永滅不生，焉知此沒彼出？固當勤修三學，廣運四弘，誦持方等大乘，繫念諸佛嘉號。冀龍花而得度，指安養為所歸。深厭死生，善識因果，欲「除苦本」，其要在茲。「故使」下，明合呵。「如經」下，引證。通標「經」者，大小皆明，不可別指。《遺教》云「此是應捨罪惡之物」，乃至云「唯有智者得除滅」等。
【譯文】【記文】在喝斥過患的一段中。問難中提到，比丘們順從佛令毫無違逆，反而遭到痛責，在道理上似乎不合理，所以發問以決斷疑難。回答中分為四層。首先闡明佛陀立教的真實意旨；從「如何未斷」往下，顯露比丘尋死的重大過失。現今世上也有一些僧人，不明白法義真諦，自己投火自焚或跳水溺死，企圖以此超脫昇天。招致痛苦的業因根本尚未除盡，又豈能擺脫三界輪迴的苦報？死而無悔，充其量不過是一個匹夫之勇的莽夫而已。自以為死後永恆寂滅不再受生，哪裡知道此處命終隨即又在他處投胎受生？理當勤勉修持戒定慧三學，廣泛發起四弘誓願，讀誦受持方等大乘經典，念念繫住諸佛萬德洪名。期盼在龍華三會上蒙受度化，指引西方安養極樂世界作為依歸之處。深切厭離生死輪迴，善於了悟明察因果法則，若想要徹底「拔除苦痛之本」，關鍵正在於此。從「故使」往下，說明確實應當遭受喝斥。從「如經說」往下，引經據典以資證明。泛稱「經」的，是因為大乘小乘經論都有明文，無法單獨指定某一經。《佛遺教經》說「這個身體是應當捨棄的罪惡聚合之物」，乃至說「唯有智者才能如法除滅」等等。

【166-0019】02_戒疏/08b_卷二下之一#79
【原文】【註】所謂行殺也。若自殺，若教殺，若遣使殺，若往來使殺，若重使殺，若展轉便殺，若求男子殺，若教人求男子殺，若求持刀人殺，若教人求持刀人殺，若身現相，若口說，若身、口現相，若教使歎，若遣書，若教遣書，若坑陷，若倚撥，若與藥，若安殺具，及餘方便殺者是也。
【譯文】【註文】所謂實施殺害。無論是自己動手殺，或是教唆別人殺，或是派遣使者去殺，或是派遣往返來回的使者去殺，或是反覆派使者去殺，或是輾轉相傳遣使去殺，或是尋找勇士男子去殺，或是教唆別人去尋找勇士男子去殺，或是尋找操刀劊子手去殺，或是教唆別人去尋找操刀劊子手去殺，或是以肢體做出暗示殺相，或是以言語煽動唆使，或是身形與語言同時顯露殺相，或是教唆使者去讚揚死亡，或是寄送書信殺人，或是教唆別人寄送催命書信，或是設置陷阱讓人跌落，或是倚靠暗置刀杖讓人觸發，或是給予毒藥，或是安置殺生用具，以及其餘一切用來達成殺害目的的方法，都算在其中。

【166-0020】02_戒疏/08b_卷二下之一#80
【原文】【疏】注中，廣列所行殺相，相分為二。初、自殺有八：一、自殺；二、身相；三、口說；四、身口俱；五、坑陷；六、倚撥；七、與藥；八、安殺具。就教他中有十一：初、遣使；二、往來使；三、重使；四、展轉使；五、求人；六、教求人；七、求持刀；八、教求持刀；九、遣書；十、教遣書；十一、遣使歎也。
【譯文】【疏文】注文中，廣泛列舉了實施殺害的各種相狀，這些相狀可以分為兩大類。首先，親自實施殺害的有八種：第一、自己動手殺；第二、肢體顯露殺相；第三、言語唆使；第四、身行與言語同時顯露；第五、設陷阱坑害；第六、倚暗器傷人；第七、給予致命藥物；第八、安置殺生器具。在教唆他人的類別中共有十一種：第一、派遣使者；第二、派遣往返使者；第三、重疊派遣使者；第四、輾轉遞相派遣；第五、尋找壯漢；第六、教人尋找壯漢；第七、尋找持刀劊子手；第八、教人尋找劊子手；第九、寄送書信；第十、教唆寄送書信；第十一、派遣使者去讚歎死亡。

【166-0024】02_戒疏/08b_卷二下之一#84
【原文】【疏】言「教殺」者，或教人殺，或但教人死之方便。言「遣使殺」者，指示所殺在其方所，而往害也。言「往來使」者，受語往害，至彼還來，重復往者是也。言「重」者，隨續使人，乃至百千，害一人者。言「展轉使」者，初使往害，彼使不去更使人往，如是展轉，乃至百千，最後一人斷彼命者，隨前而使，皆同一重。乃至上列往來重使，皆例同犯。餘有契要不同，心不如意，竝如前竪義中說。下有四求，皆教人相。
【譯文】【疏文】所說的「教唆殺」，或者是直接教人動手殺人，或者只是教導他人促成死亡的方便手段。所說的「派遣使者殺」，是指明白指示所要殺害的目標及其所在方位地點，讓使者前往加害。所說的「往返使者」，是指受命前去行害，到了那裡又返回稟報，然後再次前往行害者。所說的「重疊派使」，是指連續不斷派遣使者，甚至多達百人千人，共同去殺害同一個目標。所說的「輾轉派使」，是指最初的使者前去行害，該使者沒有動手又轉派其他人前去，像這樣輾轉相派，乃至達到百人千人，只要最後一個人斷絕了目標的生命，那麼從最初發起而後輾轉派遣的人，全都結犯相同的重罪。甚至上面所列的往返使者、重疊使者，全都照例結犯相同的重罪。其餘如果有約定條件不相符，執行結果不如主使者本意的，全都如前面立論的法義中所說明。注文下面列出的四種求人，全都屬於教唆他人的相狀。

【166-0025】02_戒疏/08b_卷二下之一#85
【原文】【記】教人八種。據文似九，前總分中，不列教殺。則知注中，此句通標，下列別相耳。「展轉」中，「乃至」下，決通前二，「例皆同犯」，遣使可知，故不點之。「餘」下，指餘不同。「如前」者，即「自作教人」門中，「或能教者剋，所使意異，或時節早晚、坐立乖契、顛狂捨戒等，教者不犯；漫心無寄，隨作皆犯」。「下」下，略示「四求」。「求男子」者，謂欲得勇士，往害於他；「持刀人」者，即旃陀羅輩。兩是自求，兩令人求，並非自殺，故云「皆教人者」。
【譯文】【記文】教唆他人的八種相狀。根據注文文字表面看似九種，前面總體分類中，沒有單獨列出「教殺」。由此可知在注文中，這句話是總體標明，下面所列的則是分別相狀。「輾轉派使」一段中，從「乃至」往下，通貫決斷前面的往返與重疊兩種使者，「全比例相同結犯重罪」，單純派遣使者當然也是如此，所以不必特別點出。從「餘有」往下，指明其餘不同的情況。「如前所說」的內容，就是指在「自作與教人」的專門門類中提到，「如果能教唆者限定條件，而所差遣者的意思產生分歧，或者時辰早晚有別、坐立形態與約定相違、或者差遣者發狂發癲、捨戒退位等，教唆者不結根本重罪；如果是泛漫之心沒有限定目標，無論如何造作皆犯重罪」。從「下有」往下，略微提示「四種尋求」。「尋求男子」，是指企圖尋找勇猛兇殘之士，前往殺害對方；「持刀人」，就是指印度專司宰殺執刑的旃陀羅之流。其中兩種是自己親自尋求，兩種是教唆別人去尋求，全都不是自己親手直接殺人，所以說「都是教唆他人的相狀」。

【166-0026】02_戒疏/08b_卷二下之一#86
【原文】【疏】言「身現相」者，或令怖畏，墜墮溝壑，或示死相等。言「口」現相者，或以言說，歎勸其死，或以大聲恐喝，令他死者。即如世中有厭身者，或投火墜巖，或刀解繩縊。不知教者，合掌唱善，或扶接登山，或為辦繩具。斯即教、歎，正符犯法，「身口俱現」，即此之流。
【譯文】【疏文】所說的「肢體顯露殺相」，或者是使人驚慌恐怖，以致墜落山溝深壑，或者是在肢體上示範自殺的姿態等等。所說的「口說顯露殺相」，或者是用言論去讚美勸導死亡，或者是以極大聲音厲聲恐嚇，使對方受驚嚇而死。就如同世俗之中有些厭惡肉身的人，或者是投身火海、跳下懸崖，或者是用刀自刎、懸梁自縊。不知戒律法度的僧人，見狀便合掌稱頌叫好，或者攙扶接引他們攀登險峰，或者替他們準備繩索工具。這就是教唆與讚歎，完全符合違犯殺戒的罪狀，「身口二業同時顯露」，指的就是這一類事情。
