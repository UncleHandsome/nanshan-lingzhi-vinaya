# 校閱材料　第1640檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【1640-0001】03_業疏/06a_卷一之六#61
【原文】今義中，初斥諸解。然此七非體相各立，那得相對但分二耶？誠為未當，不足疑矣。次示今義。「情」即屬人，「緣」收事處。「住」即是止，由是得訶人訶，故止、不止皆成別眾。然止順呵故法不非，即如法別；不止違呵故兼法非，同非法別。此之兩相，即非體矣
【譯文】在今家所立正義中，首先駁斥諸家的解釋。這七非的體相各自獨立確立，哪裡能互相對照而僅僅劃分為兩種呢？確實是不妥當的，不值得懷疑。接著闡明今家的義理。「情」就屬於人，「緣」則收攝事與處。「住」就是停止，由於是有資格抗議的人提出異議，所以無論停止或不停止，都構成別眾。然而停止是順從了抗議，所以法不算過非，即成為如法別眾；不停止則是違抗了抗議，所以兼帶法非，等同於非法別眾。這兩種行相，就是第七非的自體。

【譯文】第四門：攝收是非相（總攝如法與非法的行相）。

【1640-0003】03_業疏/06a_卷一之六#63
【原文】然是非之緣，依情而起，想見紛馳，何由限約？且約緣數以位束之，為慧解之由途，顯行事之通塞耳。就分為五：一、人是非，二、法是非，三、事是非，四、明違順，五、明通雜。並是前義，但為散落不聚，致相難顯，今以義收，相比而攝
【譯文】然而，是非的因緣是依據情念而生起的，妄想偏見紛亂奔馳，從何處加以限定約束呢？姑且依照各類因緣的條目，以品位來加以約束歸類，作為生起智慧解了的途徑，用以顯明僧團行事的通達或阻滯而已。其中分為五項：第一、人的是非；第二、法的是非；第三、事的是非；第四、闡明違順；第五、闡明通雜。這些都是前面已有的義理，只是因為散落各處而未匯聚，導致行相難以彰顯，現在以義理加以收攝，互相對比而包攬綜攝。

【1640-0004】03_業疏/06a_卷一之六#64
【原文】四攝非相初敘意中，「紛馳」謂雜亂也。「緣數」即下人法事等。「慧解」、「行事」，目足相須，一不可缺。「就」下分章。「並」下點示
【譯文】在第四門總攝是非相最初的敘述意旨中，「紛馳」是指雜亂的意思。「緣數」即指下文的人、法、事等條目。「慧解」與「行事」，如同眼目與雙足互相依賴，缺一不可。「就」字以下是劃分章目。「並」字以下則是提點指示。

【1640-0007】03_業疏/06a_卷一之六#67
【原文】言體非者，如尼等四人、十三難、二滅之徒，體是非數，不合僧收。三舉亦然，戒同治隔，不比難者，本無戒故。二滅戒存，行缺一生。舉法少時，解竟復本
【譯文】所謂自體是非（體非），例如比丘尼等四眾、十三難人、二滅（已滅擯與應滅擯）之流，其自體屬於「非數」，不應當被僧伽收攝入數。三舉（三種被舉處罰的比丘）也是如此，雖然戒體相同，但因受到治罰而被隔絕於僧眾之外；這不同於十三難之人，因為難人本來就沒有戒體。二滅之人雖然戒體本在，但一生的戒行已經殘缺。三舉之法只是暫時性的，羯磨處罰解除之後即恢復原狀。

【1640-0017】03_業疏/06a_卷一之六#77
【原文】如狂等三人、睡、定、中邊、癡鈍不了，如上非數，斯類最多。雖初身集，心無非欲，口默不訶，三業未開，俱遊捨性，是非不知，實乖相務。以羯磨文云「大德僧聽」，誡其身也；「諸長老忍」，勸其心也；「不忍者說」，動其口也。斯等兀爾，識無行路，言聲激對，非復情通，法假僧弘，相乖僧體，不應六和，又乖四準
【譯文】例如發狂等三種人、睡眠、入定、中國人與邊地人（語言不通者）、愚癡愚鈍無法明了者，如同前述的非數，這類情況最多。雖然起初身體到會和集，心裡也沒有非法的與欲，口中沉默不抗議，但三業神識未曾開通，都處於無記捨性之中，對於是非一概不知，確實違背了行事的相貌與職務。因為羯磨文說「大德僧聽」，是告誡其身業要諦聽；「諸長老忍」，是勸勉其心業要安忍可決；「不忍者說」，是發動其口業提出異議。這些人昏昧木然，心識沒有運作的途徑，言語聲音的激盪對答，已不再能情意互通；羯磨之法有賴僧伽來弘傳，其行相既違乖僧伽自體，便不符合六和敬，又違背了四位僧準。

【1640-0018】03_業疏/06a_卷一之六#78
【原文】釋中初科，初列相，且舉七人，餘指如上，即憒亂、瘂聾、重病等類。「雖」下次顯意。初敘三業雖順而乖，開即是明，捨性即無記。「以」下次舉羯磨顯其非用。兀爾，昏塞之貌。六和則具兼德用，四僧則必簡解能，故須解行雙全，呵足俱得。今既昏庸，故乖斯二。僧有四位，攝法軌定，故云「四準
【譯文】解釋中的初科，起初列舉行相，暫且舉出七種人，其餘則指同前文，即昏憒錯亂、啞聾、重病等類。「雖」字以下，接著顯發其意旨。首先敘述其三業雖然看似順應卻實質違乖，「開」就是明了，「捨性」即是無記性。「以」字以下，接著舉出羯磨文來顯明他們無法發揮功用。「兀爾」是昏昧閉塞的樣子。六和敬必須兼具道德與體用，四位僧伽則必定要揀擇其具有理解與行事之能，因此必須解行雙全，能提出抗議且能充當足數。如今這些人既然昏昧庸碌，所以違背了這兩者。僧伽有四個品位，攝受僧法的軌度皆有定規，所以稱為「四準」。
