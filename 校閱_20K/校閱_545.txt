# 校閱材料　第545檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

# 材料開始

【545-0001】資持記/08b_中二#26
【原文】淫重由成，故云惡業次第也。一屏處不定。〔佛在舍衛，迦留陀夷與優婆夷共屏覆坐，說非法語；毘舍佉母見白佛。因制。〕犯緣中。隨作犯者。若論所犯，各自如篇，此中但制令俗生疑；正篇犯吉，疏云：緣通七聚，犯唯在吉。斯明證也。釋中，本宗文有三，初簡境。
【譯文】淫欲重罪由此而滋生，所以說是「惡業次第也」。第一條屏處不定戒。〔佛在舍衛國時，迦留陀夷與優婆夷在隱蔽覆蓋的處所共坐，談論非法的言語；鹿子母毘舍佉看見後向佛稟告，佛陀因此制戒。〕犯緣之中。「隨作犯者」，如果論述實際所犯的罪名，各自依照相應的篇章來定罪，此處只是限制其行為免得令俗人生疑；屬於本篇的違犯只結突吉羅罪，《戒疏》說：「犯緣雖然通於七聚罪，但本戒違犯只在突吉羅。」這便是明確的證明。在解釋文中，本宗律文分為三段：首先簡別對象境緣。

【545-0002】資持記/08b_中二#27
【原文】人女，簡非畜，有智簡幼小狂睡，未終簡死壞。獨下，二明所造事。望人有二，男女各一，故名為獨。在下，三釋屏處又四，初明二屏。但取他人兩不見聞，不必房室。常語者，聲不大小也。覆處。蓋者，文不指物，隨有皆成。障處。樹等事局，故云及餘，無不收也。可作處者，具上三故。
【譯文】人類女子，是簡別非人與畜生；具有智力，是簡別幼童、瘋狂者與熟睡者；尚未斷氣，是簡別死屍毀壞。在「獨」字以下，第二說明所造作的事相。針對人數而言有兩人，男女各佔一人，所以稱為「單獨」。「在」字以下，第三解釋隱蔽之處又分為四點：首先說明兩種隱蔽，只要能讓他人既看不見又聽不到即可，不一定非要在房屋室內。所謂「平常言語」，是指聲音不大也不小。「覆處」，所謂覆蓋，經文並未限定是何物，只要有覆蓋物遮蔽就算符合。「障處」，樹木等物事體局限，所以說「以及其餘」，便無所不包。「可作處」，就是同時具備上述三種條件。

【545-0003】資持記/08b_中二#28
【原文】他部中，初科；前列諸境，以遮疑濫。設下，明第三人，皆無辨識。縱多非證。《善見》。文釋初緣，義兼第三；以盲聾等非明證故。言多女者，同類喜聞，容相隱覆；雖復聞見，猶非證人。結示中。即指《篇眾》。二露處不定。〔國土犯人竝同前戒，唯露處為別。〕初句標名。
【譯文】在他部律文中，第一科，前面列出各種境緣，是用來防範疑惑與混淆。「設」字以下，說明若是第三者，都缺乏辨別識別的能力，縱使人數再多也不能作證。《善見律》文中解釋最初的犯緣，義理兼及第三項；因為盲人、聾人等無法提供明確證明。所謂「婦女眾多」，因為同類之人喜好窺聽，容易互相隱瞞包庇；即便她們親眼看見或親耳聽見，依然不能充當合格的證人。結語指示中，就是指引參閱〈篇眾〉。第二條露處不定戒。〔國土與犯戒之人皆同前戒，只有處在顯露處有所不同。〕第一句標示名稱。

【545-0004】資持記/08b_中二#29
【原文】次句指同。犯緣亦四，唯改第一為露處，餘三並同。今更辨異：一所在異，即戒兩分；二所作異，謂可淫不可淫；三所說異，前唯說淫，後通麁語；四所疑異，前三後二，並如戒本。三十捨墮，名兼罪懺，律本隨戒並列悔法。故獨此篇指懺；如後，即懺篇也。初戒。〔佛在舍衛，六群畜多長衣；彼常經營莊嚴衣服，積而藏舉，因制。〕制意中。
【譯文】第二句指出與前戒相同。犯緣同樣有四條，只需將第一條改為「顯露之處」，其餘三條完全相同。現在進一步辨別差異：第一是處所不同，也就是戒律劃分為二；第二是所作行為不同，即可能行淫與不可行淫的差別；第三是所說言辭不同，前者僅指談論淫欲，後者通於粗俗言語；第四是所懷疑的罪名不同，前戒有三種罪名可疑，後戒只有二種，都如同戒本所載。三十捨墮，其名稱兼具罪名與懺悔兩重含意，律本在每條戒後都列出懺悔之法。因此唯獨在這一篇中指明懺悔法；所謂「如後」，就是指後文的懺罪篇。第一條戒。〔佛在舍衛國時，六群比丘蓄積過多的長衣；他們常常經營裝飾衣服，積蓄並收藏起來，佛陀因此制戒。〕制戒意圖中：

【545-0005】資持記/08b_中二#30
【原文】功德財者，財喻戒法，能齊貧苦；若貪世利，必喪道財；欲富道財，須遠世利。初是增惑，二即長業，三違教行。第一緣中，初科，上句定所屬。謂下示名體。三衣外者，若受百一，則百一外為長。簡辨中，初科，前引二文定量。若下，次辨犯相，初明應量。下引《多論》，明不應量。
【譯文】所謂「功德財」，是以財寶比喻戒法，能夠救濟資助貧困痛苦；如果貪求世間財利，必定會喪失修道法財；想要道財豐足，必須遠離世俗私利。第一是增長惑業，第二是滋長業障，第三是違背教法行持。在第一個犯緣中，第一科，上一句確定所屬歸宿。「謂」字以下展示名目與實體。在三衣之外的衣物，如果受持了一百一長衣，那麼一百一之外的就屬於長衣。簡別辨析中，第一科，前面引述兩段律文來確定應有的標準尺寸。「若」字以下，其次辨析違犯相狀，首先說明符合標準尺寸的情況。下文引述《薩婆多論》，說明不符合標準尺寸的情況。

【545-0006】資持記/08b_中二#31
【原文】昔人據律，不應非犯；今據聖論，罪分提吉，犯懺不殊。簡濫中。此據正加受者為言；必在受外，通須淨施。三中又三，初不受無犯者，無別長故。缺壞二罪，逐日隨結。若下，用長為受，上明加受失淨。無長防者，以淨本防長，今非長故。下明捨受重說。恐謂已淨，後不須故。
【譯文】過去律師依據律文，認為不符合標準尺寸就不構成違犯；現在依據聖論，罪名雖然區分為單提與吉羅，但犯戒與懺悔的法度並無差別。簡別混淆中，這是依據正式受持的法衣而言；如果是受持之外的衣物，全都需要行作淨施之法。在第三項中又分三點：第一種情況，未正式受持便不犯捨墮，因為並無額外的長衣。但缺少法衣或損壞法衣這兩種罪，會隨著日子逐日結罪。「若」字以下，拿長衣來當作受持的法衣，前文說明正式加受後便失去了原先的說淨效力。沒有防備長衣過犯的功效，是因為作淨施本是為了防範長衣，現在它已不是長衣了。下文說明捨棄此衣另受他衣時，前衣須重新說淨。唯恐有人以為前衣原先已經作過淨施，被捨下後便不需要再作說淨的緣故。

【545-0007】資持記/08b_中二#32
【原文】又下，指擬非長。即入三衣數故。問：後用加持不？答：指但免長，不即加持。故知衣成別自加受。下約肘量者，則明量外非法服限。文舉一衣，餘二類準。褻本音薛，字當作褻，音㲲，即布帛也。問中。以月望衣，從十一日至二十九，隨足即成；已出十日，不容更開；但線絣裁割，即免長過〔便加受故〕。
【譯文】又有一說，指明預定用途的衣物便不屬於長衣，因為它已經計入三衣的數量之中。有人發問：日後使用時還需要加持受法嗎？回答說：指明用途只是免除長衣之過，並不等同於正式加持受法。因此可知法衣縫製完成後，必須另外自行加持受法。下文依照肘量來論述，則是說明尺寸之外不合標準法服的界限。文中列舉了一種衣，其餘兩種法衣依此類推。「褻」原本音同「薛」，此處字應當作「氎」（或「𣰆」），讀音為「疊（dié）」，指細棉布帛。在提問中：因為望月而求取法衣，從十一日到二十九日，只要湊足布料便做成衣服；如果已經超過十天，便不允許再開許寬限；只要劃線剪裁，就能免除長衣的過失〔因為隨即加受的緣故〕。

【545-0008】資持記/08b_中二#33
【原文】此則與上指作用違，故須會通。答中，約先有無以分兩別，初明月望。彼因但三衣比丘伽梨故爛，十日不辦，遂開一月；故知先有明矣。上下，決上指作，不開本有。結中。須是己者，簡示他物非所犯故。
【譯文】這就與上文指明預定用途的作法相違背，所以必須融會貫通。回答中，依據原先有無衣物來劃分兩種區別，首先說明望月求衣的情形。那是因為唯有三衣的比丘其僧伽梨法衣破損，十天內無法辦妥，於是開許一個月寬限；因此可知他預先有衣是顯而易見的。上文以下，決斷上文指明預定用途的作法，並不開許原本就擁有的衣物。結語中，必須是屬於自己的衣物，這是簡別展示他人物品並非此戒所犯的對象。

【545-0009】資持記/08b_中二#34
【原文】下引證者，彼約日數以分四衣，大衣為五日衣，七條為四日衣，五條為二日衣，長衣為一日衣。彼恐營衣癈業，故約日限之，則明非他物矣。餘緣中，初科。第二屬己定者，雖是己長，忘等緣差，容不定屬故。言忘等者，即下八門不犯，皆非定也。三中，注綿毛者，此約不成衣相者為言。

【譯文】解釋第三個犯緣，在說明時限的分界中：所謂「地了」，就是天明之相顯現，方位地平清晰可辨的時候。指出與前文相同的，就是上文所說的超過期限便作吉羅罪懺悔。下一科判中：捆綁束縛在一起的，不論財物實體相同或相異、數量多少，都算作同一個物件。沒有捆綁束縛的，縱使放在同一個地方，也隨各個物件分別結罪。說淨時是一併作還是分開作，道理也是一樣的。在相互染污中：第一天得到的衣物，稱為「能染」；後九天內得到的，都稱為「所染」。唯恐有人以為財物大小不同，就不會相互染污；
