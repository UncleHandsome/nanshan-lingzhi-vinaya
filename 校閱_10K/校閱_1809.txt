# 校閱材料　第1809檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【1809-0001】03_業疏/16b_卷三之五#108
【原文】徵釋中，「同善行」者，持戒、布施同六度故。答中初敘施局，如經說慈，即《涅槃經》，謂親中三品：一、上親，二、中親，三、下親；怨亦三品：一、上怨，二、中怨，三、下怨；不怨不親為一品。於此七種等行慈心，止局現境，明非普徧。「戒」下次顯戒通。初、對簡施、慈，一非通徧，二不須受。「要普周」者，三世十方無不該故，則知本體微惡不容，纖塵莫立，比於明鏡，喻若瑠璃，眾聖所稱，良由此於。「無論善惡」，好者惡者無所擇故。「故」下二、引文示，即《俱舍》文。若不盡斷，則有二過：一、惡心不死，二、隨戒增減，後自引之。「由」下三、申所以，上二句明功，下二句彰異。別善即世福，戒是道分，故不同之。
【譯文】在審問與解釋中，「同善行」是指持戒與布施同屬於六度。回答中首先敘述布施有局限，如經中所說的慈心，即出自《大般涅槃經》，是指親屬中有三品：一、上親，二、中親，三、下親；怨敵也有三品：一、上怨，二、中怨，三、下怨；不怨不親的中庸者為一品。對這七種人平等推行慈心，也只局限在現前的境界，顯明它不是真正普遍的。從「戒」字以下，其次顯明戒法的普遍性。第一、對比揀別布施與慈心，布施慈心一則不普遍，二則不需要受戒而得。「要普周」是指三世十方無不包賅的緣故，由此可知戒體容不得微細之惡，纖細之塵也不能留存，比喻如同明鏡，又猶如琉璃，諸聖所讚歎宣說的，確實是由於這個緣故。「無論善惡」，是指對好的對象與壞的對象一無揀擇。從「故」字以下第二、引述經論文字以作開示，即《俱舍論》的文句。若不全部斷除，則有兩種過失：一是惡心未死，二是心念隨戒境而有增減，後文自會引用。從「由」字以下第三、申明其所以然，上面兩句顯明功德，下面兩句彰顯差異。個別的善行只是世間福報，戒則是出世菩提道之分，所以兩者不同。

【1809-0008】03_業疏/16b_卷三之五#115
【原文】答：緣在懸對，未即不起，願欲斷除，不妨緣義。若論其防，正在敵對。現在之境，不定說非，六塵為妙行，可唯無學？一境有異見，乃通人畜。興治有功，非不能陵，防未非也；治弱非壯，不說能防。依教懺蕩，名防過非，故無現非
【譯文】答：攀緣是在於遙懸對境，未起的罪過自然不起，誓願想要斷除它，這並不妨礙緣取的含義。但若論及防範，則正在於當面對敵相抗。現在的境界，並不能定性地稱之為過非，以六塵作為勝妙修行之境，難道只有無學聖人才能做到嗎？同一個境界因眾生而有不同的知見，乃通於人與畜生等各趣。興起對治有了功效，過非便不能侵犯，這是防範未來的過非；對治力量微弱而過非勢盛，就不能稱作防範。依循教法懺悔蕩除，稱作防範過去的過非，所以並沒有現在的過非可防。

【1809-0009】03_業疏/16b_卷三之五#116
【原文】正答中，初敘緣境通；「若」下次釋防非局。初明現境無非。「六塵為妙行」，謂觀境空寂；「可唯無學」，謂不專極聖；「一境異見」，如人見水、天見瑠璃、鬼見膿河、魚見窟宅，此明現境或見為空，或隨心異，不定為非，故無可防也。「興」下次明過未有非。陵謂侵陵
【譯文】在正答之中，首先敘述所緣境界通於三世；從「若」字以下，其次解釋防非局限於過去與未來。首先闡明現在境沒有過非。「六塵為妙行」，是說觀照境界本來空寂；「可唯無學」，是說這不唯獨是極聖阿羅漢才能做到；「一境異見」，比如同一處水，人見為水、天人見為琉璃、餓鬼見為膿血之河、魚類見為窟宅舍宇，這說明現在境界或者被照見為空，或者隨著心念而顯現不同，並非固定就是過非，所以沒有過非可防。從「興」字以下，其次說明過去與未來有過非存在。「陵」是指侵陵侮慢。

【1809-0010】03_業疏/16b_卷三之五#117

【譯文】再次重新舉證說明：現在世中惡事若尚未生起則不能稱為罪，剛一造起便已謝落入過去，隨即就稱作過去之非。所以經文說「現在念念不住」，因此可以分明照見此理。

【1809-0011】03_業疏/16b_卷三之五#118
【原文】重舉中，即明現境不立，還落二世。「故」下引證，即《涅槃》文。彼云：色有三種，過去、未來、現在；過現不可害，何以故？過去過去故，現在念念滅故；遮未來故，名之為殺。前念過去，後念未來，此理益明，故云可見
【譯文】在重舉之中，就是闡明現在境不能獨立安立罪過，終究歸落於過去與未來二世。從「故」字以下引經作證，即引用《大般涅槃經》的文句。那裡說：色法有三種，即過去、未來、現在；過去世與現在世的色法不可殺害，為什麼呢？因為過去的已經過去，現在的念念生滅；正因為阻斷了其未來世的相續，才稱之為殺害。前念已經過去，後念屬於未來，這個道理越發分明，所以說由此可見。

【1809-0016】03_業疏/16b_卷三之五#123
【原文】昔解毗尼防已起非，據七毗尼；戒防未起，謂壇場受體，此局論耳。今解毗尼亦除已未，何者是耶？如四諍對除，是殄已起；明觀正斷，應起不起，即絕未非
【譯文】古人解釋毗尼防除已生起之非，是依據七滅諍毗尼而言；戒防範未起之非，是指戒壇上所得的受體，這只是局限一隅的偏論罷了。如今解釋毗尼也是兼除已生與未生兩者，具體是怎樣的呢？例如面對四種諍事加以遣除，是滅除已經生起的過非；了知戒法之人修持明利觀照而予以正斷，使本應生起的惡業不再生起，這就是斷絕未來的過非。

【1809-0017】03_業疏/16b_卷三之五#124
【原文】次科初敘古局見。七毗尼即七滅諍。「今」下申今通解。戒防已未如上已明，此中但出毗尼通二世耳。知法之人謂之明觀，如教而滅，故云正斷
【譯文】在下一段中，首先敘述古人偏狹局促的見解。七毗尼就是指七滅諍法。從「今」字以下，申述現今圓融通達的解釋。戒法防範已起與未起如上文已經闡明，此處只是指出毗尼同樣通於已、未二世。深明戒法之人稱作「明觀」，依照教敕而加以滅除，所以稱為「正斷」。
