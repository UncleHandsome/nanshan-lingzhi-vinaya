# 校閱材料　第200檔

以下提示詞請連同材料一起貼給 AI：

你是漢文佛教律典的校勘者。你的工作是逐段核對白話譯文與原文，找出「意思不符」的地方，不是潤飾文筆。

【輸入】
每段格式：
【NNN-NNNN】
【原文】……
【譯文】……
一段對一段，段數固定。原文可能是鈔、記、疏或律本；譯文是現行白話。

【什麼才算錯】只有下列情況才算：
1. 意思相反：把肯定譯成否定、把「應」譯成「不應」、把開許譯成禁止、把「得」譯成「不得」。
2. 主詞或施受關係錯：把甲做的事掛到乙身上；被動譯成主動；「為他」譯成「為己」；「能遣」與「所遣」、「能秉」與「所為」互換。
3. 範圍改變：把「一切」縮成「部分」、把某一類擴成全部、把此處擴成他處、把「偏門」擴成「法門」。
4. 因果或條件顛倒：把「因為 A 所以 B」譯成「因為 B 所以 A」；把假設譯成事實；把「若…則…」的條件丟掉。
5. 術語錯：律宗專名、羯磨術語、罪相名目、衣藥器具名，被譯成普通詞或另一概念。
6. 程序錯：羯磨、結界、受戒、說戒、自恣、安居、懺罪的次第顛倒、漏步驟、或多出步驟。
7. 漏譯或增譯：整句未譯；譯文出現原文沒有的主詞、因果、形容、結論。
8. 半譯：一段之中前半仍是文言、後半才是白話；或整段只是抄原文再加幾句。
9. 標點與體例：引號、括號、夾注不成對；引文與夾注混為一談；书名号、人名線未閉合。

【方法】
第一遍：完整讀原文與譯文，先不要找關鍵詞。每段寫出「誰→做什麼→對誰→在什麼條件下」，再核對譯文是否一致。
第二遍：標出原文的科判語與引文界線，逐一確認譯文沒有把它們當成內容。
  - 「X下」「X中」「X末」是指示段落位置的詞，義為「自 X 以下」「在 X 這一段中」，不是實詞。
  - 「初X」「次X」「三X」是科判序，不是「初次」「三次」。
  - 「約X」「此約」是「就 X 而言」，不是「依據」。
  - 「」內是引文，（）〔〕內是夾注；引文的字要留，夾注的話要譯。
第三遍：一致性。同一術語在本批前後是否兩種譯法；同一段在鈔、記兩處是否譯法不同（不同則至少一處錯）。


【自我對抗（每一條都要做，不要跳過）】
報出任何一條之前，先反駁自己：
1. 原文有沒有另一種讀法，支持現在的譯文？如果有，撤回或降級。
2. 我引的原文句子，真的能證明譯文錯嗎？引不出來就不要報 P0。
3. 這個問題是「譯錯」還是「譯得不好」？只是語感差異，不報。
4. 主詞、範圍、因果、程序，四項我都真的比對過了嗎？

全部掃完後，再用「對抗視角」快速回看每一段一遍，只問一句：
「這段譯文有沒有把原文說反、說窄、或把甲的事掛到乙身上？」
有疑慮但無法確定 → 列入「存疑」，不要硬報，也不要直接放過。


【同段多錯】
同一段可能有多個錯誤，分別落在不同句子。若發現兩處以上：
- 每一處各寫一條，標題可重複使用同一編號與來源；
- 在「問題」開頭標明是哪一句（引該句前 6–10 字）；
- 不要把多處合併成一句模糊的描述，也不要只報第一處就停。

【回報格式：必附來源標籤】
每條意見的標題必須原樣抄下該段在材料裡的來源標籤，例如：
### 資持記/15c_下三#28｜P0｜類型
這個標籤就印在【段NNN】後面，請整段複製，不要只寫「段28」。
- 不可自行重新編號，不可把段號改成你閱讀時的序號。
- 不必整段複製原文與譯文；只要在「原文起首」寫該段前 10–15 字即可（用來確認你讀的是哪一段）。
- 若同一段有多個問題，仍使用同一個來源標籤，分行列出。

【定位自檢】
1. 標籤裡的 chunk 名稱是否與材料該段完全一致？
2. 你引的原文是否與材料【原文】逐字相同？
3. 若你把好幾份材料合併閱讀，是否仍保留每段原本的標籤？

【輸出】只寫有問題的段；沒問題的不要寫。
### NNN-NNNN｜書/chunk#段｜P0｜類型
- 原文起首：（該段前 10–15 字）
- 問題：一句話說清楚錯在哪
- 依據：原文哪一句可以證明（P0 必填；引不出就降 P1 或不報）
- 建議：只改錯處的最小修改
- 信心：高／中／低

P0：讀者依譯文會得到相反或錯誤的結論。術語錯若會改變制度事實——誰能做、誰在場、什麼身份、什麼程序、什麼界、什麼罪——算 P0；只是名相替換而不影響事實者，P1。
P1：術語或語意偏差，不至於反義，但會誤導。
P2：標點、錯字、格式、引號。

【每檔結尾固定輸出，零問題也要寫】
=== 本檔結束 ===
檔案編號：<本檔第一個編號> ～ <本檔最後一個編號>
已檢查 N／M 段（M 是本檔實際段數，請先數一遍）
P0 x、P1 y、P2 z；存疑 k 條（列編號）
若 N 小於 M，必須另列「未檢查」的編號清單。
即使整檔完全沒有問題，也必須輸出這四行——否則無法確認這個檔看過了。

【禁止】
- 不合併、不拆分、不增刪段數。
- 不整段重寫；只改錯的地方，其餘照原譯。
- 沒有原文依據，不報 P0。
- 不編造原文、出處或記文沒說的話。
- 不把「譯得不好」當「譯錯」；純語感差異不報。
- 不因句式與原文相近就判半譯，先確認是否為引文。
- 不跳過沒有命中任何類型的段。

【輸出前自檢】
1. 每條 P0 都寫得出原文依據嗎？
2. 主詞、範圍、因果、程序，四項都核對過了嗎？
3. 有沒有把科判語當成實詞？
4. 有沒有只抓明顯的詞，漏掉整句未譯或自行加出的內容？
5. 建議譯文有沒有改動段數或引號體例？

【200-0001】03_業疏/09a_卷二之三#87
【原文】問：結淨地中不竪方相者？答：古人不尋文也。如上已明，須知分齊，護宿、煑過，何得不也？古人有言：「以食望僧，是攝是障。」謂僧、食兩望也，淨地結意，攝食障僧，恐相染汙。又云：「以僧望僧，非攝非障。」謂僧住望淨地也，作眾法時，同須赴集；唯攝宿煑，不攝別眾，可不然也
【譯文】問：結淨地時不樹立四方界相，這是何意？答：那是古人沒有細究文意。如上文已經辨明的，必須明白界限範圍，以防護內宿與內煮的過失，怎能不立標相呢？古人曾說：「以食對待僧，是攝受又是障礙。」這是指將僧眾與飲食兩相對待而言，結淨地的用意，在於攝受食物而障隔於僧，唯恐互相染汙。古人又說：「以僧對待僧，非攝受亦非障礙。」這是指僧眾住處與淨地相對而言，作僧眾羯磨法時，同樣都必須前往集合；淨地只攝持防護內宿與內煮，並不攝受僧人形成獨立別界（不可藉此免除集會，否則便成別眾），豈能不是這樣呢？

【200-0002】03_業疏/09a_卷二之三#88
【原文】次不竪相中，初問，由古不立，故假問通之。答中，初斥古；「如」下顯今，指如上者，即顯相中。「古」下，引證。此則別有一師立句，簡辨二界同異，今此取證各攝分齊。文為兩段：前段初二句引古，「謂」下今釋，謂以淨地望大界，則各攝不通也；「又」下第二段初二句引古，「謂」下今釋，謂以大界望淨地，則攝僧義一也
【譯文】在第二「不竪相」段落中，首先提問，因古人不立標相，所以設問來加以通解。回答之中，先斥責古人之說；「如」以下顯明現今正義，指如上述者，即指標明界相之中。「古」以下引證，這是另有一位律師立句，以簡別辨明二界的同與異，現在引用此說來證明各自攝持的界限範圍。文分為兩段：前段前兩句引用古說，「謂」以下是現今的解釋，指以淨地對望大界，則各有所攝而不相通；「又」以下第二段前兩句引用古說，「謂」以下是現今的解釋，指以大界對望淨地，則攝受僧眾的意義是相同的。

【譯文】文中所說結定東側廂房廚院，若依照律文，只說「某處」；如《僧祇律》中所載，則在西南方。現在依照各方水土之崇尚，並無不可行之處。祇洹等諸寺的大門都向東開，中印度崇尚太陽初升之方，所以大門在東邊為尊上，而且那裡多吹東風，便於吹散氣味。東土論方位，也以東方為始，崇尚陽氣，以北極星居中來定位，所以把廚房設在東方。因此《大智度論》說：「隨順世俗並無過失，總不能把白天當成黑夜吧。」

【200-0004】03_業疏/09a_卷二之三#90
【原文】三釋東廂中初示諸部不同四分不定僧祗如前今下次明隨方安立初二句通示祇桓下別釋初釋西土尚東一為尚日二則當風寺門東向故厨在西南二明此土尚東四方四時皆以東為始以北為終以定北辰者爾雅釋天云北極謂之北辰郭璞曰北極天之中以正四時然則極中也辰時也以其居天之中故曰北極以正四時故曰北辰然此土寺門多是南向尚於正陽故厨廁宜在東北亦以多南風故也故下引證彼明佛法不免從俗但不從彼見且如晝夜是世俗定法豈得不隨耶。
【譯文】第三「釋東廂」之中，首先指出諸部律典規定不同：《四分律》未作定論，《僧祇律》則如前所述；「今」以下，接著說明隨順地域而安立。前兩句通體指明，「祇洹」以下分別解釋：先解釋西方印度崇尚東方，一者因為崇尚太陽，二者為了順應風向，寺門朝東，所以廚房設在西南方；第二、說明此土崇尚東方，四方與四時都以東為始、以北為終。「以定北辰」者，《爾雅·釋天》說「北極稱為北辰」，郭璞注說「北極乃天之中樞，用以正定四時」，由此可見，「極」就是中樞，「辰」就是時令，因其居於天之中樞故稱北極，因其正定四時故稱北辰。然而此土寺院大門多朝向南方，崇尚正陽之氣，因此廚房與廁所適宜設在東北方，這也是因為多吹南風的緣故。「故」以下引文為證，那裡說明佛法難免順從世俗，但只是不盲從其邪見；而且就像晝夜是世俗既定的法則，豈能不隨順呢？

【原文】初一須翻，餘三不須。如遇緣觸、宿，染穢由生；律制儉開，乞求易得，私順通文，便自宿、煑；縱實依難，遇豐須閇，因循不絕，是緣不淨；或可時沾緣淨扶持器具之例，後須息心，仍事不歇；或縱心把捉，謂無罪累，知而故為，竝須翻也
